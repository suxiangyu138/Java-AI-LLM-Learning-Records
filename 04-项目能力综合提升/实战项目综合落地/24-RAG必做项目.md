# RAG 实战项目清单

## 一、核心能力

RAG 是大模型应用开发的核心落地方向，必须掌握：

- 文档解析与分块
- 向量化与向量存储
- 相似度检索与混合检索
- 多轮对话与上下文感知
- 权限隔离与答案溯源
- Java 工程化与私有化部署

---

## 二、技术能力拆解

- 文档层：PDF / TXT / MD / 网页正文解析
- 处理层：清洗 / 分块 / 去重 / 元数据绑定
- 向量层：Embedding / Chroma / Milvus
- 检索层：向量检索 / 关键词检索 / 重排序
- 生成层：Prompt 拼接 / 溯源引用 / 幻觉控制
- 对话层：历史压缩 / 问题改写 / 多轮上下文
- 工程层：SpringBoot / Spring AI / Redis / Docker

---

## 三、必做项目（求职优先级）

### 1. 单 PDF 文档极简 RAG 问答系统
**技术栈**：LangChain / Spring AI + Ollama + Chroma

**实现**：
- 单份 PDF 上传
- 文档解析
- 文本分块
- 向量化
- Chroma 存储
- 相似度检索
- 答案生成
- 引用来源标注

**核心知识点**：
- RAG 完整链路
- 中文分块策略
- 基础嵌入模型
- 简单答案溯源

**产出**：
- 最小可运行 RAG Demo

**耗时**：2天

---

### 2. 多文档通用知识库 RAG
**技术栈**：LangChain + Milvus + Ollama

- 增量入库
- 向量库持久化
- 重复数据去重

**核心知识点**：
- 批量入库
