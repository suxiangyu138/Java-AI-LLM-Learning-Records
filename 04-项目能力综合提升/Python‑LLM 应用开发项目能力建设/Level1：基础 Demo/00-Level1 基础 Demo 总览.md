## 3. 学习路线推荐

**标准路径（2-3 周，每天 1-2 小时）**：按 01→10 顺序推进。01-02 快速过（有 Python 基础可各压到半天），03 之后进入 AI 新知识区放慢（每个 2 天），08 闭环留 2-3 天打磨。每个 Demo 的完成标准是"**能独立重写一遍**"，而不是"跑通了"——重写过程中卡住的地方就是面试会被追问的地方。

**加速路径（已有 Python + 调模型经验，1 周）**：01、02 直接跳过，从 03 开始；04 快速过；重点在 06-08 的 RAG 与闭环链路。

**查漏路径（面试前补基础）**：只做 03 与 08，把 LLM 调用与最小闭环跑通，其余回仓库「Python 异步 + FastAPI」「Function Calling」「RAG 拓展优化深化」等体系补知识。

**每日节奏建议**：每次学习以一个"可运行的小目标"收尾（今天让终端打出模型回答、今天让网页出现聊天框），而不是"看完一节"——Demo 期最有价值的是连续的正反馈：每 30-60 分钟有一次"跑通了"的体验。卡住超过 30 分钟先查 09 篇速查表，再卡就跳过或问人，不要在一处死磕——时间应该花在"覆盖全链路"上，深度留给 Level2。

## 4. 核心概念速查

| 概念 | 一句话速查 |

| Demo 层定位 | 打通技术链路即可，不追求工程化规范 |

| Function Calling | 模型不执行代码，只声明要调哪个工具并给参数，由程序执行 |
| 最小闭环 | 上传文档 → 向量入库 → 提问 → 带知识库上下文回答 |

## 5. Level1 在能力建设中的定位

三级结构的逻辑是**递进收口**：Level1 用最小成本建立"Python + AI 全链路能跑通"的信心与技术底座；Level2 把链路工程化（FastAPI 化、测试、日志、部署、LangChain/LangGraph 引入）并沉淀成简历核心项目；Level3 在项目上叠加多 Agent、推理优化、高并发等加分能力。Level1 容易犯的两个方向性错误要提前避免：**一是追求工程化**——Demo 阶段写单元测试、搞 CI、上消息队列都是过度投入，Level2 再做；**二是跳过基础**——直接抄 Level2 的项目代码，结果每个组件都不理解，面试追问全崩。Level1 的正确产出不是"能运行的代码"，而是**"每个环节都亲手写过的理解"**。

与仓库其他体系的关系：01-02 对应「Python 虚拟环境」「01-Python语言」体系，本层是它们的动手验证层；03-07 对应「Function Calling 函数调用」「RAG 拓展优化深化」「主流 Agent 范式」体系，本层是它们的入门实践层——那些体系讲"是什么、为什么"，本层讲"怎么亲手跑通"。

与「Java‑AI 后端项目能力建设」的对称关系：两个能力建设目录是同一张蓝图的两半——Java 目录用 Spring Boot + Spring AI 实现后端与 AI 集成，本目录用 Python + openai SDK 实现同样的 AI 能力（RAG、Agent）。**建议先做 Java 侧再做本目录**：Java 侧是业务底座，且做完 Java 侧再来写 Python Demo，会发现 RAG、Function Calling 全是同一套思想换语言重写，Python 侧会快一倍。两套都完成后，把两端拼起来就是「双栈联合实战」的完整项目。

前置要求说明：本层假设读者**会一点 Python 基础语法**（变量、函数、列表字典）与**基本的终端操作**（在目录里敲命令）。01-02 篇会快速补齐环境与高频语法，不会 Python 的新手按顺序走也能跟上（进度放慢即可，语法细节随时查仓库「01-Python语言」体系）。AI 部分（03 篇起）零基础可学——本层每篇都从"为什么需要它"讲起，先把链路跑通，理论深潜交给对应体系。

## 7. 使用建议

每个 Demo 模块的结构一致：**目标 → 前置 → 步骤 → 代码 → 验证 → 常见坑**。学习时建议"先自己写、再对照文档"——先不看代码，根据模块开头"目标与验收"独立实现，卡住 30 分钟再翻代码，理解差异后再重写一遍。遇到环境或网络问题先查 09 篇速查表。全部完成后对照 10 篇的毕业检查单逐项打勾，全部通过再进入 Level2——**Level1 的坑不填平，Level2 会加倍偿还**。

与双栈学习搭配时的排期建议：如果按推荐顺序先做了 Java 侧 Level1，本层 03-07 篇可以压缩（模型调用、RAG、工具调用都是同一套思想，代码换语言重写一遍即可，每篇 1 天足矣），把省下的时间投给 08 闭环与调优记录；如果直接做本层，03 之后按标准节奏走，Java 侧留到 Level2 完成后回头补——**两套 Level1 不必都精做，各跑通一轮、理解到位即可**，真正的产出是「双栈联合实战」里的整合。学习期间随时可以把进度和疑问记进笔记——本仓库每个知识体系都配有总览与导航，回来复习时按图索骥即可。

> 🎯 **核心要点**：Level1 的唯一目标是**亲手打通每一条链路**：能让 Python 调通大模型、能做出带界面的对话、能做出 RAG 问答、能让模型调用工具。代码可以简陋，理解必须到位——这是 Level2 一切工程化的地基。
