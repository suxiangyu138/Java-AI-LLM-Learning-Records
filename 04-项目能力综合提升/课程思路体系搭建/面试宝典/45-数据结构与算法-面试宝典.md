## 一、基础概念速答（15-20题）

> 面试开场高频题，考察对基础数据结构的掌握深度。回答时先给出定义，再用一句话说明核心特征。

### 1.1 数组 vs 链表

| 维度 | 数组 | 链表 |
|------|------|------|
| 内存布局 | 连续内存 | 离散节点，通过指针连接 |
| 随机访问 | O(1) | O(n) |
| 插入/删除（头部） | O(n) | O(1) |
| 插入/删除（尾部） | O(1)（不考虑扩容） | O(n)（需遍历）/ O(1)（带尾指针） |
| 缓存友好 | 是（空间局部性） | 否 |
| 额外内存 | 几乎无 | 每个节点存储指针 |

> 💡 **面试话术**："数组和链表是两种最基本的线性存储结构。数组在内存中连续存储，支持O(1)随机访问但插入删除需要移动元素；链表通过指针连接节点，插入删除只需修改指针但无法随机访问。实际使用时数组更缓存友好，链表则适合频繁增删的场景。"

### 1.2 二分查找

**标准版核心逻辑**：
```java
public int binarySearch(int[] arr, int target) {
    int left = 0, right = arr.length - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;  // 防溢出
        if (arr[mid] == target) return mid;
        else if (arr[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return -1;
}
```

| 版本 | 区间定义 | 循环条件 | mid计算 | 适用场景 |
|------|----------|----------|---------|----------|
| 标准版 | [left, right] | left <= right | left + (right - left) / 2 | 精确查找 |
| 左边界版 | [left, right) | left < right | left + (right - left) / 2 | 查找第一个 >= target |
| 右边界版 | (left, right] | left < right | left + (right - left + 1) / 2 | 查找最后一个 <= target |
| 平衡版 | [left, right] | left + 1 < right | left + (right - left) / 2 | 减少比较次数 |

> ⚠️ **注意事项**：`mid = (left + right) / 2` 在 left+right 超过 `Integer.MAX_VALUE` 时会溢出，必须使用 `left + (right - left) / 2`。

### 1.3 队列、栈与双端队列

| 数据结构 | 核心原则 | 底层实现 | 主要操作 |
|----------|----------|----------|----------|
| 栈（Stack） | LIFO（后进先出） | 数组 / 链表 | push, pop, peek |
| 队列（Queue） | FIFO（先进先出） | 链表 / 环形数组 | offer, poll, peek |
| 双端队列（Deque） | 两端均可入出 | 双向链表 / 环形数组 | addFirst, addLast, removeFirst, removeLast |

**环形数组队列实现要点**：
```java
class CircularQueue<E> {
    private E[] array;
    private int head = 0, tail = 0;  // tail 指向下一个空位
    private int size = 0;

    public CircularQueue(int capacity) {
        array = (E[]) new Object[capacity];
    }

    public boolean offer(E value) {
        if (isFull()) return false;
        array[tail] = value;
        tail = (tail + 1) % array.length;
        size++;
        return true;
    }

    public E poll() {
        if (isEmpty()) return null;
        E value = array[head];
        head = (head + 1) % array.length;
        size--;
        return value;
    }

    public boolean isEmpty() { return size == 0; }
    public boolean isFull() { return size == array.length; }
}
```

### 1.4 栈的经典应用

- **括号匹配**（LeetCode 20）：遍历字符串，左括号入栈，右括号匹配则出栈
- **表达式求值**：中缀转后缀（调度场算法），后缀表达式求值
- **函数调用栈**：递归调用、方法调用链
- **浏览器的前进后退**：两个栈实现

### 1.5 二叉树遍历

| 遍历方式 | 访问顺序 | 递归实现 | 非递归实现 | 典型应用 |
|----------|----------|----------|------------|----------|
| 前序 | 根 → 左 → 右 | 最简单 | 栈 + 循环 | 树结构序列化、复制树 |
| 中序 | 左 → 根 → 右 | 最常用 | 栈 + 指针 | BST输出有序序列 |
| 后序 | 左 → 右 → 根 | 需注意顺序 | 双栈 / 单栈+prev | 删除树、表达式求值 |
| 层序 | 逐层从左到右 | BFS思想 | 队列 | 求树宽、ZigZag |

> 🎯 **记忆口诀**："前序根左右，中序左根右，后序左右根，层序逐层扫。"

### 1.6 堆的定义与性质

- **最大堆**：每个节点 >= 左右孩子，根最大
- **最小堆**：每个节点 <= 左右孩子，根最小
- 底层用**数组存储**，下标 i 的左孩子 `2i+1`，右孩子 `2i+2`，父节点 `(i-1)/2`
- 建堆 O(n)，插入 O(log n)，删除堆顶 O(log n)
- 堆排序 O(n log n)，**不稳定**

> 💡 **TopK思路**：求前K大元素 → 维护大小为K的最小堆；求前K小元素 → 维护大小为K的最大堆。

### 1.7 栈与队列的相互实现

| 实现方式 | 操作复杂度 | 要点 |
|----------|------------|------|
| 双栈模拟队列 | push O(1), poll 均摊 O(1) | 一个栈负责入队，一个栈负责出队 |
| 单队列模拟栈 | push O(n), poll O(1) | 每次push后将前面全部元素重新入队 |

### 1.8 阻塞队列

| 对比维度 | 单锁实现 | 双锁实现 |
|----------|----------|----------|
| 锁粒度 | 一把锁保护所有操作 | 读锁 + 写锁分离 |
| 生产者-消费者并发 | 不能同时操作 | 可以同时操作两端 |
| 实现复杂度 | 简单 | 较复杂 |
| 典型应用 | ArrayBlockingQueue | LinkedBlockingQueue |

## 二、深度原理剖析（10-15题）

> 面试中考察理解深度的核心环节，需要讲清楚"为什么"。

### 2.1 二分查找为什么每次能排除一半？

二分查找每次将搜索范围缩小为原来的一半，经过 k 次比较后搜索范围变为 n/2^k。当 n/2^k = 1 时，k = log₂(n)，因此时间复杂度为 O(log n)。前提条件是数据必须**有序**且支持**随机访问**。

> 💡 **变种考点**："在旋转有序数组中查找"（LeetCode 33）—— 先判断 mid 落在哪一侧有序，再决定搜索方向。

### 2.2 动态数组扩容策略

| 扩容策略 | 扩容因子 | 均摊复杂度 | 空间浪费 |
|----------|----------|------------|----------|
| ArrayList | 1.5倍 | O(1) | 约33%空余 |
| 精确扩容 | +1 | O(n) | 最小 |
| 固定倍数 | 2倍 | O(1) | 约50%空余 |

> ⚠️ 1.5倍扩容 vs 2倍扩容：2倍扩容会导致无法复用的内存碎片，1.5倍扩容在时间与空间上更均衡。

### 2.3 递归的时间复杂度分析

| 方法 | 适用场景 | 示例 |
|------|----------|------|
| 主定理 | T(n) = aT(n/b) + f(n) | 归并排序 T(n) = 2T(n/2) + O(n) |
| 递归树展开 | 各层递归规模不同 | 快速排序平均情况 |
| 代入法 | 已知猜测复杂度 | 斐波那契 O(2^n) |

**主定理公式**：对于 T(n) = aT(n/b) + f(n)：
- 若 f(n) = O(n^(log_b a - ε))，则 T(n) = Θ(n^(log_b a))
- 若 f(n) = Θ(n^(log_b a) log^k n)，则 T(n) = Θ(n^(log_b a) log^(k+1) n)
- 若 f(n) = Ω(n^(log_b a + ε))，则 T(n) = Θ(f(n))

> 🎯 **斐波那契优化**：普通递归O(2^n) → 记忆化O(n) → 动态规划O(n) → 矩阵快速幂O(log n)。

### 2.4 尾递归与栈溢出

```java
// 非尾递归 — 会后置操作，无法优化
public int factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);  // 乘操作在递归返回后执行
}

// 尾递归 — 编译器可以优化为循环（JVM不会默认做此优化）
public int factorialTail(int n, int acc) {
    if (n <= 1) return acc;
    return factorialTail(n - 1, n * acc);
}
```

> ⚠️ Java默认不支持尾递归优化，深层递归在Java中仍可能爆栈。可以用循环或迭代方式替代。

### 2.5 BST（二叉搜索树） vs AVL vs 红黑树

| 对比维度 | BST | AVL | 红黑树 |
|----------|-----|-----|--------|
| 平衡条件 | 无 | 左右子树高度差 <= 1 | 5条红黑规则 |
| 查找复杂度 | O(n) 最坏 | O(log n) | O(log n) |
| 插入/删除 | O(n) 最坏 | O(log n)，但旋转次数多 | O(log n)，旋转次数少 |
| 应用场景 | 仅教学 | 查询密集场景 | 通用、语言底层实现 |
| Java中的使用 | TreeSet/TreeMap | 无原生实现 | HashMap(>=8)、TreeMap |

**红黑树的5条性质**：
1. 每个节点是红色或黑色
2. 根节点是黑色
3. 叶子节点（NIL）是黑色
4. 红色节点的两个子节点都是黑色（不能有连续红节点）
5. 从任一节点到其每个叶子的所有路径包含相同数目的黑色节点

### 2.6 AVL树的四种失衡情况

| 失衡类型 | 判定条件 | 旋转方式 | 旋转次数 |
|----------|----------|----------|----------|
| LL（左左） | 左子树高且左孩子的左子树高 | 右旋 | 1次 |
| RR（右右） | 右子树高且右孩子的右子树高 | 左旋 | 1次 |
| LR（左右） | 左子树高且左孩子的右子树高 | 左旋 + 右旋 | 2次 |
| RL（右左） | 右子树高且右孩子的左子树高 | 右旋 + 左旋 | 2次 |

### 2.7 红黑树插入的三种情况

| 情况 | 描述 | 处理方式 |
|------|------|----------|
| Case 1 | 叔叔节点为红色 | 变色：父、叔变黑，祖父变红，向上递归 |
| Case 2 | 叔叔为黑色且当前节点与父节点同侧 | 旋转父节点 + 变色 |
| Case 3 | 叔叔为黑色且当前节点与父节点异侧 | 旋转当前节点（转化为Case 2） |

### 2.8 缓存与局部性原理

```text
数组连续存储 → CPU缓存预取下一个元素 → 缓存命中率高
链表离散存储 → 节点在内存中分散 → 频繁cache miss
```

> **空间局部性**：访问 arr[i] 后很可能访问 arr[i+1]，缓存一次加载64字节（cache line）。
> **时间局部性**：循环内的变量被反复访问，L1缓存命中。

### 2.9 双向环形链表为什么带哨兵（dummy node）？

- 消除头节点和尾节点的特殊处理逻辑
- 空表和非空表操作统一
- 插入/删除无需判断 `head == null`
- 遍历边界判断：`current.next == sentinel`

### 2.10 为什么HashMap在链表长度>=8时转为红黑树？

| 参数 | 含义 | 原因 |
|------|------|------|
| 阈值 8 | 链表转红黑树 | 泊松分布下链表超过8的概率极低（约0.00000006） |
| 阈值 6 | 红黑树转链表 | 防止频繁转换（hysteresis） |
| 最小容量64 | 可树化的最小数组长度 | 避免数组过小时先扩容而非树化 |

> 💡 **红黑树 vs AVL的选择**：红黑树插入/删除后至多旋转3次，AVL最多需要O(log n)次旋转。HashMap这种写操作频繁的场景，红黑树更合适。

### 3.1 【阿里】LRU缓存实现

**题目**：设计一个LRU（最近最少使用）缓存，支持 get 和 put 操作，时间复杂度均为 O(1)。

**解法**：HashMap + 双向链表

```java
class LRUCache {
    static class Node {
        int key, value;
        Node prev, next;
        Node(int key, int value) { this.key = key; this.value = value; }
    }

    private final int capacity;
    private final Map<Integer, Node> map = new HashMap<>();
    private final Node head = new Node(-1, -1);  // 哨兵
    private final Node tail = new Node(-1, -1);

    public LRUCache(int capacity) {
        this.capacity = capacity;
        head.next = tail;
        tail.prev = head;
    }

    public int get(int key) {
        Node node = map.get(key);
        if (node == null) return -1;
        remove(node);
        addFirst(node);
        return node.value;
    }

    public void put(int key, int value) {
        Node node = map.get(key);
        if (node != null) {
            node.value = value;
            remove(node);
            addFirst(node);
        } else {
            if (map.size() == capacity) {
                Node last = tail.prev;
                remove(last);
                map.remove(last.key);
            }
            Node newNode = new Node(key, value);
            addFirst(newNode);
            map.put(key, newNode);
        }
    }

    private void addFirst(Node node) {
        node.next = head.next;
        node.prev = head;
        head.next.prev = node;
        head.next = node;
    }

    private void remove(Node node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }
}
```

### 3.2 【字节】反转链表（多种解法）

```java
// 解法1：迭代（双指针）
public ListNode reverseList(ListNode head) {
    ListNode prev = null, curr = head;
    while (curr != null) {
        ListNode next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }
    return prev;
}

// 解法2：头插法（带哨兵）
public ListNode reverseList(ListNode head) {
    ListNode sentinel = new ListNode(-1);
    sentinel.next = null;
    while (head != null) {
        ListNode next = head.next;
        head.next = sentinel.next;
        sentinel.next = head;
        head = next;
    }
    return sentinel.next;
}

// 解法3：递归
public ListNode reverseList(ListNode head) {
    if (head == null || head.next == null) return head;
    ListNode newHead = reverseList(head.next);
    head.next.next = head;
    head.next = null;
    return newHead;
}
```

### 3.3 【腾讯】判断括号字符串是否有效

```java
public boolean isValid(String s) {
    Map<Character, Character> map = Map.of(')', '(', ']', '[', '}', '{');
    Deque<Character> stack = new ArrayDeque<>();  // 推荐，比 Stack 快
    for (char c : s.toCharArray()) {
        if (map.containsKey(c)) {
            if (stack.isEmpty() || stack.pop() != map.get(c)) return false;
        } else {
            stack.push(c);
        }
    }
    return stack.isEmpty();
}
```

> 💡 用 `ArrayDeque` 代替 `Stack`，因为 `Stack` 继承自 `Vector`，有锁开销。

### 3.4 【美团】二叉树最大深度

```java
// 递归（DFS）
public int maxDepth(TreeNode root) {
    if (root == null) return 0;
    return 1 + Math.max(maxDepth(root.left), maxDepth(root.right));
}

// 非递归（BFS层序遍历）
public int maxDepthBFS(TreeNode root) {
    if (root == null) return 0;
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    int depth = 0;
    while (!queue.isEmpty()) {
        int size = queue.size();
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        depth++;
    }
    return depth;
}
```

### 3.5 【字节】二叉树的ZigZag层序遍历

```java
public List<List<Integer>> zigzagLevelOrder(TreeNode root) {
    List<List<Integer>> result = new ArrayList<>();
    if (root == null) return result;
    Deque<TreeNode> deque = new LinkedList<>();
    deque.offer(root);
    boolean leftToRight = true;
    while (!deque.isEmpty()) {
        int size = deque.size();
        LinkedList<Integer> level = new LinkedList<>();
        for (int i = 0; i < size; i++) {
            TreeNode node = deque.poll();
            if (leftToRight) level.addLast(node.val);
            else level.addFirst(node.val);
            if (node.left != null) deque.offer(node.left);
            if (node.right != null) deque.offer(node.right);
        }
        result.add(level);
        leftToRight = !leftToRight;
    }
    return result;
}
```

### 3.6 【阿里】合并K个有序链表

```java
public ListNode mergeKLists(ListNode[] lists) {
    if (lists == null || lists.length == 0) return null;
    // 最小堆，按节点值排序
    PriorityQueue<ListNode> pq = new PriorityQueue<>((a, b) -> a.val - b.val);
    for (ListNode node : lists) {
        if (node != null) pq.offer(node);
    }
    ListNode sentinel = new ListNode(-1), curr = sentinel;
    while (!pq.isEmpty()) {
        ListNode node = pq.poll();
        curr.next = node;
        curr = curr.next;
        if (node.next != null) pq.offer(node.next);
    }
    return sentinel.next;
}
```

> 💡 **分治合并**的时间复杂度也是 O(n log k)，但堆解法更直观。注意堆解法空间 O(k)，分治 O(1)。

### 3.7 【字节】TopK 问题的三种解法

| 解法 | 时间复杂度 | 空间复杂度 | 适用场景 |
|------|------------|------------|----------|
| 全局排序 | O(n log n) | O(1) | n较小 |
| 最小堆 | O(n log k) | O(k) | 数据量大，k较小 |
| 快速选择（QuickSelect） | 平均O(n)，最坏O(n²) | O(1) | 数据可一次性载入内存 |

```java
// 堆解法：求第K大元素
public int findKthLargest(int[] nums, int k) {
    // 最小堆，堆顶就是第K大
    PriorityQueue<Integer> pq = new PriorityQueue<>(k);
    for (int num : nums) {
        if (pq.size() < k) {
            pq.offer(num);
        } else if (num > pq.peek()) {
            pq.poll();
            pq.offer(num);
        }
    }
    return pq.peek();
}
```

### 3.8 【腾讯】判断对称二叉树

```java
public boolean isSymmetric(TreeNode root) {
    if (root == null) return true;
    return check(root.left, root.right);
}

private boolean check(TreeNode left, TreeNode right) {
    if (left == null && right == null) return true;
    if (left == null || right == null) return false;
    return left.val == right.val
        && check(left.left, right.right)
        && check(left.right, right.left);
}
```

### 3.9 【美团】链表判环（快慢指针）

```java
public boolean hasCycle(ListNode head) {
    if (head == null || head.next == null) return false;
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) return true;
    }
    return false;
}

// 进阶：找到环的入口
public ListNode detectCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) {
            slow = head;
            while (slow != fast) {
                slow = slow.next;
                fast = fast.next;
            }
            return slow;
        }
    }
    return null;
}
```

> 🎯 **总结**：快慢指针是链表问题的核心技巧。判环（快2慢1）、找中点（快2慢1）、找倒数第K个（快先走K）。

### 4.1 快排（高频，几乎所有公司都考）

```java
public void quickSort(int[] arr, int left, int right) {
    if (left >= right) return;
    int pivot = partition(arr, left, right);
    quickSort(arr, left, pivot - 1);
    quickSort(arr, pivot + 1, right);
}

private int partition(int[] arr, int left, int right) {
    int pivot = arr[right];  // 选最右为基准
    int i = left - 1;        // i 指向最后一个小于等于 pivot 的元素
    for (int j = left; j < right; j++) {
        if (arr[j] <= pivot) {
            i++;
            swap(arr, i, j);
        }
    }
    swap(arr, i + 1, right);
    return i + 1;
}

private void swap(int[] arr, int i, int j) {
    int tmp = arr[i];
    arr[i] = arr[j];
    arr[j] = tmp;
}
```

> ⚠️ 快排不稳定，最坏 O(n²)（已有序数组 + 固定选pivot），优化方式：随机pivot / 三数取中法。

### 4.2 堆排序

```java
public void heapSort(int[] arr) {
    // 1. 建堆 O(n)
    for (int i = arr.length / 2 - 1; i >= 0; i--) {
        heapify(arr, i, arr.length);
    }
    // 2. 排序 O(n log n)
    for (int i = arr.length - 1; i > 0; i--) {
        swap(arr, 0, i);           // 堆顶（最大）移到末尾
        heapify(arr, 0, i);        // 剩余元素重新堆化
    }
}

private void heapify(int[] arr, int i, int size) {
    int largest = i;
    int left = 2 * i + 1;
    int right = 2 * i + 2;
    if (left < size && arr[left] > arr[largest]) largest = left;
    if (right < size && arr[right] > arr[largest]) largest = right;
    if (largest != i) {
        swap(arr, i, largest);
        heapify(arr, largest, size);
    }
}
```

### 4.3 判断二叉搜索树合法性

```java
// 解法1：中序遍历非递归（空间 O(n)）
public boolean isValidBST(TreeNode root) {
    List<Integer> list = new ArrayList<>();
    Deque<TreeNode> stack = new LinkedList<>();
    TreeNode curr = root;
    while (curr != null || !stack.isEmpty()) {
        while (curr != null) {
            stack.push(curr);
            curr = curr.left;
        }
        curr = stack.pop();
        if (!list.isEmpty() && curr.val <= list.get(list.size() - 1)) {
            return false;
        }
        list.add(curr.val);
        curr = curr.right;
    }
    return true;
}

// 解法2：上下界递归（最优）
public boolean isValidBST(TreeNode root) {
    return validate(root, Long.MIN_VALUE, Long.MAX_VALUE);
}

private boolean validate(TreeNode node, long min, long max) {
    if (node == null) return true;
    if (node.val <= min || node.val >= max) return false;
    return validate(node.left, min, node.val)
        && validate(node.right, node.val, max);
}
```

### 4.4 根据前序+中序遍历重建二叉树

```java
public TreeNode buildTree(int[] preorder, int[] inorder) {
    if (preorder.length == 0) return null;
    Map<Integer, Integer> map = new HashMap<>();
    for (int i = 0; i < inorder.length; i++) map.put(inorder[i], i);
    return build(preorder, 0, preorder.length - 1,
                 inorder, 0, inorder.length - 1, map);
}

private TreeNode build(int[] pre, int preL, int preR,
                       int[] in, int inL, int inR,
                       Map<Integer, Integer> map) {
    if (preL > preR) return null;
    int rootVal = pre[preL];
    TreeNode root = new TreeNode(rootVal);
    int rootIdx = map.get(rootVal);
    int leftSize = rootIdx - inL;
    root.left = build(pre, preL + 1, preL + leftSize,
                      in, inL, rootIdx - 1, map);
    root.right = build(pre, preL + leftSize + 1, preR,
                       in, rootIdx + 1, inR, map);
    return root;
}
```

### 4.5 中缀表达式转后缀并求值

```java
// 定义运算符优先级
private static final Map<Character, Integer> PREC = Map.of(
    '+', 1, '-', 1, '*', 2, '/', 2
);

public List<String> infixToPostfix(String expr) {
    List<String> output = new ArrayList<>();
    Deque<Character> stack = new LinkedList<>();
    for (char c : expr.toCharArray()) {
        if (Character.isDigit(c)) {
            output.add(String.valueOf(c));
        } else if (c == '(') {
            stack.push(c);
        } else if (c == ')') {
            while (!stack.isEmpty() && stack.peek() != '(')
                output.add(String.valueOf(stack.pop()));
            stack.pop(); // 弹出 '('
        } else { // 运算符
            while (!stack.isEmpty() && stack.peek() != '('
                   && PREC.get(stack.peek()) >= PREC.get(c)) {
                output.add(String.valueOf(stack.pop()));
            }
            stack.push(c);
        }
    }
    while (!stack.isEmpty()) output.add(String.valueOf(stack.pop()));
    return output;
}

public int evalRPN(String[] tokens) {
    Deque<Integer> stack = new ArrayDeque<>();
    for (String token : tokens) {
        switch (token) {
            case "+" -> stack.push(stack.pop() + stack.pop());
            case "-" -> { int b = stack.pop(); int a = stack.pop(); stack.push(a - b); }
            case "*" -> stack.push(stack.pop() * stack.pop());
            case "/" -> { int b = stack.pop(); int a = stack.pop(); stack.push(a / b); }
            default -> stack.push(Integer.parseInt(token));
        }
    }
    return stack.pop();
}
```

### 5.1 设计一个海量数据日志系统（生产者-消费者模式）

**需求**：多个线程写日志，一个线程将日志刷到磁盘，不丢失、不阻塞。

**方案**：阻塞队列 + 批量刷盘

```java
public class AsyncLogger {
    private final BlockingQueue<LogEvent> queue = new ArrayBlockingQueue<>(4096);
    private volatile boolean running = true;

    public AsyncLogger() {
        new Thread(() -> {
            List<LogEvent> batch = new ArrayList<>(512);
            while (running) {
                batch.clear();
                // Drain: 批量取出，减少锁竞争
                int count = queue.drainTo(batch, 512);
                if (count == 0) {
                    try { batch.add(queue.take()); } // 阻塞等待
                    catch (InterruptedException e) { break; }
                }
                batch.forEach(LogEvent::writeToDisk);
            }
        }, "logger-writer").start();
    }

    public void log(String msg) {
        queue.offer(new LogEvent(msg)); // 非阻塞
    }
}
```

> 💡 双锁阻塞队列（类似 LinkedBlockingQueue）比单锁性能更好：生产者锁和消费者锁分离，可以同时入队和出队。

### 5.2 设计一个实时排行榜系统

**需求**：用户积分实时更新，快速查询Top N。

| 方案 | 优点 | 缺点 |
|------|------|------|

```java
class Leaderboard {
    // 最小堆，堆顶是第K名
    private final PriorityQueue<Integer> minHeap;
    private final Map<Integer, Integer> playerScore;
    private final int k;

    public Leaderboard(int k) {
        this.k = k;
        this.minHeap = new PriorityQueue<>(k);
        this.playerScore = new HashMap<>();
    }

    public void addScore(int playerId, int score) {
        playerScore.merge(playerId, score, Integer::sum);
        int total = playerScore.get(playerId);
        if (minHeap.size() < k) {
            minHeap.offer(total);
        } else if (total > minHeap.peek()) {
            minHeap.poll();
            minHeap.offer(total);
        }
    }

    public List<Integer> topK() {
        List<Integer> result = new ArrayList<>(minHeap);
        result.sort(Collections.reverseOrder());
        return result;
    }
}
```

### 5.3 设计一个支持过期淘汰的缓存系统

继承 LRU 思想，加上 TTL 过期机制：

```java
class ExpiringLRUCache<K, V> {
    static class CacheEntry<V> {
        V value;
        long expireAt;
        CacheEntry(V value, long ttlMs) {
            this.value = value;
            this.expireAt = System.currentTimeMillis() + ttlMs;
        }
        boolean isExpired() { return System.currentTimeMillis() > expireAt; }
    }

    private final int capacity;
    private final LinkedHashMap<K, CacheEntry<V>> cache;

    public ExpiringLRUCache(int capacity) {
        this.capacity = capacity;
        this.cache = new LinkedHashMap<>(capacity, 0.75f, true) {
            @Override
            protected boolean removeEldestEntry(Map.Entry<K, CacheEntry<V>> eldest) {
                return size() > capacity; // 超过容量移除最久未使用的
            }
        };
    }

    public V get(K key) {
        CacheEntry<V> entry = cache.get(key);
        if (entry == null) return null;
        if (entry.isExpired()) {
            cache.remove(key);
            return null;
        }
        return entry.value;
    }

    public void put(K key, V value, long ttlMs) {
        cache.put(key, new CacheEntry<>(value, ttlMs));
    }
}
```

### 5.4 设计一个在线编译器评测队列

**场景**：用户提交代码，评测系统需要支持优先级（付费用户优先）、限流、超时取消。

**架构**：优先级阻塞队列 + 定时器

```java
class JudgeQueue {
    // 按优先级排序的阻塞队列
    private final PriorityBlockingQueue<JudgeTask> queue =
        new PriorityBlockingQueue<>(11,
            Comparator.comparingInt(JudgeTask::getPriority).reversed()
                      .thenComparingLong(JudgeTask::getSubmitTime));

    private final ScheduledExecutorService timer = Executors.newScheduledThreadPool(4);

    public void submit(JudgeTask task) {
        queue.offer(task);
        // 超时自动取消
        timer.schedule(() -> {
            if (queue.remove(task)) task.setStatus("TIMEOUT");
        }, task.getTimeLimit(), TimeUnit.MILLISECONDS);
    }

    public JudgeTask take() throws InterruptedException {
        JudgeTask task = queue.take();
        task.setStatus("RUNNING");
        return task;
    }
}
```

## 七、面试回答模板（Top 5）

### 7.1 如何衡量算法好坏？

> "评价一个好算法应该从**时间维度**和**空间维度**两方面衡量。时间上使用大O表示法描述时间复杂度，关注**最坏情况**下的执行时间增长趋势；空间上关注除输入数据外额外的内存消耗。在时间换空间的权衡中，Java 8+的HashMap引入红黑树就是典型——链表在hash冲突严重时O(n)退化，引入红黑树后降为O(log n)，用额外的节点信息换取时间。此外还要考虑**实际场景**：比如Redis的ziplist用连续存储节省空间，虽然读写变慢，但在小数据量下是可接受的设计取舍。"

### 7.2 说说你对递归的理解

> "递归满足三个条件：**1）大问题可以拆分为子问题**；**2）子问题和大问题解法相同**；**3）存在递归终止条件**。递归的优点是代码简洁、逻辑清晰（如树的DFS遍历），缺点是函数调用栈可能溢出、额外空间开销O(n)。可以用**主定理**分析复杂度，用**尾递归**或**循环**优化。工程上需要注意，Java默认不做尾递归优化，深度递归建议用栈模拟。"

### 7.3 HashMap的底层结构（延伸红黑树）

> "HashMap基于**数组+链表+红黑树**实现。put流程：1）计算key的hash，找到桶位置；2）桶为空直接插入；3）不为空则遍历链表查找，找到则覆盖，未找到则尾插；4）链表长度 >= TREEIFY_THRESHOLD(8) 且数组长度 >= 64 时转为红黑树。选择红黑树而非AVL是因为红黑树插入/删除至多旋转3次，更适合HashMap这种写操作频繁的场景。引入树化的阈值8来自泊松分布，理论上链表长度达到8的概率极低。"

### 7.4 如何解决海量数据TopK问题

> "TopK问题常用的有四种策略：**1）最小堆** O(n log k)，适合k较小且数据量很大的场景（如100亿数据找前100个），内存只需O(k)；**2）快速选择** 平均O(n)，但需要全部数据在内存，且最坏O(n²)；**3）分治** 将数据分片到多台机器，每台求TopK，再合并，适合数据无法单机存放；**4）计数排序/桶排序**，当数据范围有限时（如统计年龄TopK），可以O(n)完成。面试中最常用堆解法，因为易于理解、实现简单且内存友好。"

### 7.5 红黑树和AVL树的区别

> "AVL是**严格平衡**，左右子树高度差不超过1，查找效率更高（最坏O(log n)）。红黑树是**近似平衡**，最长路径不超过最短路径的2倍（通过5条红黑规则保证）。**插入/删除性能**：AVL最多需要O(log n)次旋转，红黑树至多3次。**应用场景**：AVL适合**查询密集**的场景（如数据库索引），红黑树适合**写操作较多**的场景（如TreeMap、HashMap内部）。Java的TreeMap和C++ STL map都选择红黑树就是考虑到实际应用中插入删除操作较频繁。"
