# 6-8 个月 AI 大模型落地式学习路线（Java 后端 + AI 融合）

> **适用人群**：Java 后端开发，具备 Spring Boot/MySQL/Redis 基础，想转型 AI 大模型方向
> **学习策略**：每阶段对应 1 个可提交简历的实战项目，拒绝纯理论堆砌
> **预估时长**：在校学生每天 2-3 小时，6-8 个月完成核心四阶段

---

## 总览

```
阶段一 (1-1.5月)          阶段二 (1.5-2月)          阶段三 (1.5-2月)
Python基础 + API调用  →   RAG知识库应用开发    →    Agent智能体开发
    │                        │                        │
    智能聊天机器人            技术文档问答系统          智能运维Agent
                                │                        │
    阶段四 (1-1.5月)  ←────────┴────────────────────────┘
    大模型微调与部署            阶段五 (1月, 可选)           阶段六 (持续)
    │                       多模态大模型应用              企业级工程实践
    Java代码审查助手          智能简历生成器               SpringBoot AI融合
```

## 阶段一：Python 基础 + 大模型 API 实践（1-1.5 个月）

### 核心目标
快速掌握 Python 语法，调用大模型 API 构建第一个智能应用，获得**正反馈**。

### 技术清单

| 模块 | 内容 | 参考文档 |
|------|------|----------|
| Python 速通 | 变量/数据类型/控制流/函数/类/模块（10-20 小时） | `Python速通-大模型开发必备语法.md` |
| 大模型 API 调用 | OpenAI API / DeepSeek API / 通义千问 API，HTTP POST、JSON 解析、流式输出 | `大模型API调用实践.md` |
| Prompt Engineering | Zero-shot / Few-shot / CoT 思维链提示技巧 | `Zero-Shot-Few-Shot-CoT提示技巧实战.md` |

### 实战项目：智能聊天机器人
- 调用 DeepSeek API 实现多轮对话
- 添加上下文记忆功能（滑动窗口 / 摘要记忆）
- 部署到 Web 界面（Flask / Gradio）
- **简历关键词**：LLM API 集成、多轮对话、上下文管理、Web 部署

### 工具推荐
- VSCode + Python 插件
- 国内 API 平台：DeepSeek（极低成本）/ 智谱 AI / 通义千问（免费额度充足）
- 学习资源：Datawhale《动手学大模型应用开发》

---

## 阶段二：RAG 知识库应用开发（1.5-2 个月）

### 核心目标
让 AI 拥有**私域知识库**，解决大模型"幻觉"和知识过时问题——企业级应用刚需。

### 技术清单

| 模块 | 内容 | 参考文档 |
|------|------|----------|
| 向量数据库 | Chroma / FAISS / Milvus，Embedding 向量化、相似度检索 | `Chroma与FAISS入门实战.md` |
| LangChain 框架 | Document Loaders / Text Splitters / Retrieval / Chain | 已有 `LangChain详细知识点.md` |
| 文档处理 | PDF 解析（PyPDF2）/ Markdown 解析 / 网页爬取（BeautifulSoup） | `文档处理与解析实战.md` |

### 实战项目：个人技术文档问答系统
- 上传 Java 学习笔记 / Spring 官方文档构建知识库
- 支持多轮对话 + 引用溯源（显示答案来自哪个文档段落）
- 进阶：混合检索（关键词 + 向量）+ Rerank 重排序
- **简历关键词**：RAG、向量检索、LangChain、文档问答、引用溯源

### 进阶方向
- 混合检索（BM25 + 向量相似度）→ 见 `RAG混合检索与Rerank优化.md`
- Rerank 重排序优化检索精度
- 文档更新自动同步（定时任务 + 增量索引）

---

## 阶段三：Agent 智能体开发（1.5-2 个月）

### 核心目标
让 AI 拥有**自主解决问题的能力**——调用工具、规划任务、迭代优化。2025 年是 Agent 元年。

### 技术清单

| 模块 | 内容 | 参考文档 |
|------|------|----------|
| LangChain Agent | ReAct 模式 / Function Calling / Tool Use | `ReAct模式与Function-Calling实战.md` |
| LangGraph 框架 | 状态图管理、条件路由、多 Agent 协作 | `LangGraph状态图与多Agent协作.md` |
| 工具集成 | 搜索引擎（Tavily）/ 数据库查询 / API 调用 / 代码执行器 | 已有 `AI Agent核心知识点.md` |

### 实战项目：智能运维助手
- 输入"分析服务器日志找出异常"→ Agent 自动执行：
  - 读取日志 → 正则提取错误 → 查询 StackOverflow / 内部知识库 → 生成修复方案
- 进阶：多 Agent 协作（开发 Agent + 测试 Agent + 运维 Agent）
- **简历关键词**：AI Agent、ReAct、Function Calling、LangGraph、自动化运维

### 企业级方向
- 多 Agent 协作（规划 Agent + 执行 Agent + 审核 Agent）
- 人机协同审核机制（关键操作需人工确认）
- 成本控制与 Token 消耗监控

## 阶段四：大模型微调与部署（1-1.5 个月）

### 核心目标
掌握**私有化部署**和**垂直领域微调**，降低成本、保护数据隐私。

### 技术清单

| 模块 | 内容 | 参考文档 |
|------|------|----------|
| 本地部署 | Ollama 快速部署开源模型（Qwen / LLaMA），量化原理（GGUF / GPTQ） | `Ollama本地部署与量化模型实战.md` |
| Fine-Tuning 微调 | LoRA / QLoRA 参数高效微调，数据集准备 → 训练 → 评估完整流程 | `LoRA与QLoRA参数高效微调实战.md` |
| 模型评估 | BLEU / ROUGE 指标，人工评测流程设计 | `模型评估指标与实践.md` |

### 实战项目：Java 代码审查助手
- 收集 Java 代码审查数据（GitHub PR review comments）
- 用 LoRA 微调 Qwen 模型，实现：
  - 代码质量检测（命名规范、复杂度）
  - 性能优化建议（SQL 优化、缓存策略）
  - 安全漏洞扫描（SQL 注入、XSS）
- **简历关键词**：LoRA 微调、QLoRA、模型量化、Ollama、代码审查 AI

### 工具推荐
- Ollama：一键部署本地大模型
- Transformers 库（Hugging Face 生态）
- ModelScope / Hugging Face：开源模型社区

### 技术清单

### 实战项目：智能简历生成器

- **简历关键词**：多模态 AI、Stable Diffusion、OCR、文档智能

### 核心能力

| 模块 | 内容 | 参考文档 |
|------|------|----------|
| 系统设计 | 高并发处理、流式响应、异步任务队列（Celery / RabbitMQ） | `AI项目企业级部署与运维.md` |

| 监控运维 | 日志追踪（LangSmith / LangFuse）、性能指标、A/B 测试 | `AI项目企业级部署与运维.md` |

### Java 后端融合
将 AI 能力**嵌入 Spring Boot 项目**：
- RESTful API 封装 AI 服务
- Redis 缓存对话历史
- MySQL 存储用户反馈
- Docker 容器化部署
- 参见 `SpringBoot集成AI服务实战.md`

### 综合实战项目：智能客服系统
- **后端**：Spring Boot + Spring AI + Redis + MySQL
- **AI 层**：RAG 知识库（产品文档） + Agent（订单查询 / 退款处理）
- **部署**：Docker Compose 一键部署
- **简历关键词**：Spring AI、全栈 AI 应用、高并发、Docker 部署
