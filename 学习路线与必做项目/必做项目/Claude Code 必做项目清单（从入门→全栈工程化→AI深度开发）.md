# Claude Code 必做项目清单（从入门 → 全栈工程化 → AI 深度开发）

---

## 一、入门必做（Claude Code 核心基础能力）

### 1. 单文件极速开发：Java / Python 工具类与组件

**核心能力**  
- 长上下文下生成高质量可运行代码  
- 自动补充异常处理、参数校验、日志与边界检查  
- 同步生成单元测试与典型 / 边界用例  

**项目场景**  
- Java：加密工具、日期时间工具、IO 工具、HTTP 客户端封装  
- Python：数据清洗脚本、RAG 工具函数、基础爬虫组件  

**实战要求**  
- 一句话需求 → 生成完整代码 + 测试用例  

**预计耗时**：0.5 天  

---

### 2. 精准 Debug 与疑难问题定位

**核心能力**  
- 仓库级分析 Bug，跨文件定位问题  
- 结合日志、堆栈排查并发安全、内存泄漏、事务异常  
- 输出「根因分析 → 修复方案 → 预防策略」  

**项目场景**  
- SpringBoot：空指针、事务失效、慢 SQL、循环依赖  
- Python：异步死锁、依赖冲突、RAG 检索异常  

**预计耗时**：0.5 天  

---

### 3. 代码重构与架构规范化

**核心能力**  
- 统一命名与代码风格，批量消除坏味道  
- 按分层架构 / 设计模式对项目进行解耦重构  
- 老旧项目模块化改造、依赖升级  

**项目场景**  
- 混乱 Java 项目重构为清晰 MVC / 分层架构  
- Python 脚本重构为模块化、可配置工程  

**预计耗时**：1 天  

---

## 二、进阶必做（全栈项目极速搭建）

### 4. SpringBoot 企业级后端项目一键生成

**核心能力**  
- 基于表结构或需求说明生成 Entity / Mapper / Service / Controller / DTO / VO  
- 自动集成 MyBatis-Plus、全局异常、参数校验、统一返回体、接口文档  
- 支持多模块拆分和基础权限架构  

**项目场景**  
- 用户管理、订单系统、商品模块、权限管理系统  

**预计耗时**：1 天  

---

### 5. 前后端分离全栈项目开发

**核心能力**  
- 同时生成 Java 后端与 Vue3 前端代码  
- 自动对接接口、配置跨域、统一数据结构与错误码  
- 生成前端路由、表单、表格、权限控制逻辑  

**项目场景**  
- 企业管理后台、知识库平台、电商管理后台  

**预计耗时**：2 天  

---

### 6. 算法题高阶解题与优化

**核心能力**  
- 提供接近最优时间 / 空间复杂度的解法  
- 输出多种解法 + 复杂度分析 + 边界测试用例  
- 生成可读性强、适合面试讲解的代码与思路  

**项目场景**  
- LeetCode 中等 / 困难题（DP、图论、搜索等）  

**预计耗时**：1 天

**项目场景**  
- PDF 知识库问答、多文档混合检索、图文 RAG  

**预计耗时**：2 天

**项目场景**  
- 代码生成 Agent、办公自动化 Agent、联网搜索 Agent  

**预计耗时**：2 天  

---

**项目场景**  
- 企业内部知识库问答、日志检索问答、系统文档问答  

**预计耗时**：2 天

## 七、Claude Code 实战公式（使用模板）

1. 精准生成  
   - 需求 + 技术栈 + 规范约束 + 输出格式  

2. 全项目重构  
   - 仓库上下文 + 目标架构风格 + 性能 / 可读性要求  

3. 疑难 Debug  
   - 错误日志 + 复现步骤 + 关键代码 + 预期行为  

4. 架构设计  
   - 业务需求 + 非功能指标 + 技术选型 + 期望产出物  

---

## 八、落地标准

1. 重复性编码尽量交给 Claude Code，人工主要负责审查与决策  
2. 为仓库编写 `CLAUDE.md` 说明项目背景与规范  
3. 生成代码必须包含异常处理、参数校验、日志与基础测试  
4. 固定流程：AI 生成 → 本地运行与测试 → 人工审查微调 → 让 AI 批量应用
