# MySQL 实战项目清单

## 一、核心能力

MySQL 是 Java 后端最核心的关系型数据库，必须掌握：

- SQL 基础 CRUD
- 多表关联查询
- 数据库设计规范
- 事务与锁机制
- 索引与性能调优
- 企业级架构能力

---

## 二、技术能力拆解

- 语法层：DDL / DML / DCL / DQL
- 设计层：主键 / 外键 / 范式 / ER 图
- 查询层：联表 / 子查询 / 分组 / 分页
- 事务层：ACID / 隔离级别 / 回滚
- 优化层：索引 / EXPLAIN / 慢查询
- 架构层：主从复制 / 分库分表

## 九、MySQL vs MongoDB 选型

| 特性 | MySQL | MongoDB |
|------|-------|---------|
| 数据模型 | 关系型 | 文档型 |
| Schema | 固定 | 灵活 |
| 事务 | 强 | 支持但弱于 MySQL |
| 联表查询 | 强 | 弱 |
| 适用场景 | 订单 / 支付 / 权限 | 内容 / 日志 / 非结构化数据 |
