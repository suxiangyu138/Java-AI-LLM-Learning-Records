OpenClaw 核心知识点
一、基础定义
OpenClaw（圈内别称小龙虾）是国产轻量化、可私有化部署的AI Agent智能体开发框架，专为企业级Agent落地设计，聚焦大模型工具调用、智能体调度、业务系统融合，是国内Agent开发领域的热门开源方案。
二、核心定位
1. 解决大模型能力边界局限，实现自主思考、工具调用、任务闭环
2. 支持本地化私有化部署，数据不出本地，适配企业安全合规需求
3. 提供标准化开发范式，快速搭建垂直领域AI智能体、个人助理、业务机器人
三、核心能力
1. Agent本地化极速部署
一键私有化部署，兼容Ollama，脱离公网依赖，快速落地专属智能体。
2. LLM工具调用（Tool Use）
标准化协议让大模型调用代码、接口、数据库、本地文件等外部能力，突破大模型原生边界。
3. 自研核心调度引擎
负责Agent「意图识别→任务拆解→工具编排→结果整合」全链路运行，是智能体的核心大脑。
4. Skill插件生态
Skill为标准化扩展单元，支持插件热插拔，可快速给Agent新增联网、代码执行、数据分析等能力。
5. 垂直领域定制开发
支持从零搭建办公、教育、金融、政务等行业专属AI智能体。
6. 高扩展性架构
统一规范实现「万物皆可Skill」，兼容多主流大模型、企业业务系统无缝集成。
四、核心技术架构
1. 大模型适配层：兼容Ollama、Claude、OpenAI、通义千问等全品类主流大模型
2. Agent调度内核：智能体思考循环、任务调度、决策逻辑的核心模块
3. Skill插件系统：标准化开发规范，支撑自定义能力扩展
4. 业务融合层：打通数据库、中间件、企业内部系统，实现业务数据联动
五、核心开发概念
1. Agent：具备自主思考、工具调用、任务执行能力的完整智能体
2. Skill：Agent的技能单元，对应具体工具/业务能力
3. 调度引擎：驱动Agent运行的核心，实现多步骤复杂任务拆解与执行
4. 本地化部署：依托Ollama实现大模型本地私有化，保障数据安全
六、核心应用场景
1. 个人专属AI助理、垂直领域对话机器人
2. 企业级业务智能体、自动化办公Agent
3. 私有化RAG知识库、本地大模型智能应用
4. 开发者Agent开发实战、AI大模型应用工程化落地
