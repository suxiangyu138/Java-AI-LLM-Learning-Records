Dify 核心知识点
一、基础定义
Dify 是一款开源、一站式 AI 应用开发平台，定位为 AI 应用的低代码/无代码开发工具。
- 核心使命：降低 AI 应用开发门槛，让不懂代码的人也能快速搭建 AI 应用，同时给开发者提供完整的工程化能力。
- 核心定位：LLMOps + 低代码 AI 应用开发平台
- 核心价值：可视化搭建、Prompt 管理、RAG 知识库、Agent 智能体、API 全链路管理
二、核心架构
1. 前端可视化工作台
零代码拖拽式开发，可视化配置 Prompt、知识库、工作流，无需编写代码。
2. 后端核心引擎
负责 LLM 调用、数据处理、权限管理、API 网关、日志监控。
3. 向量知识库引擎
内置 RAG 核心能力，支持文档解析、文本分割、向量化、检索增强。
4. Agent 工作流引擎
可视化编排 Agent 任务流程，支持工具调用、条件分支、循环执行。
5. 多模型适配层
兼容 OpenAI、Claude、通义千问、Ollama 等几乎所有主流大模型。
三、核心能力
1. 可视化 Prompt 工程
- 可视化 Prompt 编辑器，支持变量、模板、版本管理
- 测试、调优、一键发布，告别纯手写 Prompt
- 支持 Prompt A/B 测试，自动评估效果
2. 企业级 RAG 知识库
- 支持 PDF、Word、TXT、网页、Excel 等全格式文档解析
- 自动文本分割、清洗、向量化
- 支持关键词检索 + 向量检索混合模式
- 支持私有化向量库部署（Milvus、Qdrant、Weaviate）
3. 可视化 Agent 工作流
- 零代码编排 Agent 任务流程
- 支持工具调用、条件判断、循环、分支、子流程嵌套
- 内置海量工具插件，支持自定义代码工具、API 工具
4. 多模型统一接入
- 一键接入主流公有大模型
- 支持 Ollama 本地模型私有化部署
- 统一模型调用接口，无缝切换模型
5. API 全链路管理
- 一键生成 RESTful API，对接业务系统
- 完整的 API 密钥、权限、限流、日志监控
- 支持 Webhook、第三方系统集成
6. 数据安全与私有化部署
- 开源可私有化部署，数据完全可控
- 细粒度权限管理、团队协作、审计日志
- 支持 Docker、K8s 一键部署
四、核心产品形态
1. AI 对话应用：聊天机器人、智能客服、企业知识库问答
2. AI 工作流：自动化办公、数据处理、多步骤复杂任务
3. AI API 服务：为业务系统提供标准化 AI 接口
4. 私有化知识库：企业内部文档、资料、数据的智能问答
五、适用场景
1. 个人开发者：快速搭建 AI 应用、学习 RAG/Agent 开发
2. 企业内部：搭建企业知识库、智能客服、自动化办公机器人
3. 产品运营：零代码开发 AI 工具，快速验证产品创意
4. 政企单位：私有化部署，保障数据安全，合规使用大模型
六、Dify vs 同类产品
产品 核心优势 定位 
Dify 开源免费、私有化部署、可视化强、Agent 能力完善 一站式 AI 应用开发平台 
Coze 字节旗下、生态强、插件多 面向 C 端的 AI Bot 搭建平台 
Flowise 纯低代码工作流、开源 专注 Agent 可视化编排 
LangChain 代码驱动、生态最强 开发者级 AI 开发框架 
核心结论：
- 想零代码快速做 AI 应用：选 Dify
- 想纯代码深度开发：选 LangChain
- 想做 C 端社交 Bot：选 Coze
七、一句话总结
Dify = 开源低代码 AI 应用开发平台，一站式搞定 Prompt、RAG、Agent、API 管理，兼顾易用性与工程化能力，是个人和企业快速落地 AI 应用的首选工具。
