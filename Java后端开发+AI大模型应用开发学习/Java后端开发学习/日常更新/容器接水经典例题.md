容器接水经典例题
例题1（入门必做）
题目：有2升桶、7升桶，无限水，凑出5升水。
答案：
1. 7装满，2空
2. 7倒满2 → 7剩5升
✅ 直接完成
 
例题2（经典变式）
题目：4升桶、9升桶，凑出6升水。
步骤：
1. 9装满，4空
2. 9倒满4 → 9剩5，4满
3. 4倒空
4. 9中5倒满4 → 9剩1，4满
5. 4倒空
6. 9中1倒入4 → 4有1，9空
7. 9装满
8. 9倒满4（还能装3）→ 9剩6
✅
 
例题3（高频面试）
题目：5升桶、8升桶，凑出2升水。
步骤：
1. 8装满，5空
2. 8倒满5 → 8剩3，5满
3. 5倒空
4. 8中3倒入5 → 5有3
5. 8装满
6. 8倒满5（还能装2）→ 8剩6
7. 5倒空
8. 8中6倒满5 → 8剩2
✅
 
例题4（中等难度）
题目：3升桶、7升桶，凑出5升水。
提示：用余数叠加逻辑。
 
例题5（三桶经典题）
题目：有一个满的8升水桶，空的5升、3升桶，把8升水平分成4升、4升。
 
例题6（思维拔高）
题目：6升桶、10升桶，能不能凑出3升水？
答案：不能。
原因：gcd(6,10)=2，3不是2的倍数，数学上无解。
