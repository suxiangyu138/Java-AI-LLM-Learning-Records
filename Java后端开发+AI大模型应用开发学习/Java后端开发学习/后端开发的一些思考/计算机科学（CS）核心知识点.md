计算机科学（CS）核心知识点
计算机科学 8 大核心模块
1. 计算机基础与数学
- 高等数学、线性代数、概率论与数理统计
- 离散数学（集合、逻辑、图论、组合数学）
- 数字逻辑、计算机组成原理
2. 程序设计基础
- C / C++ / Java / Python 至少一门精通
- 数据类型、控制结构、函数、面向对象
- 调试、工程规范、版本控制（Git）
3. 数据结构与算法（核心中的核心）
- 线性结构：数组、链表、栈、队列、字符串
- 树形结构：二叉树、BST、堆、哈夫曼树
- 图结构：图遍历、最短路径、最小生成树
- 排序与查找：冒泡、快排、归并、二分等
- 算法思想：递归、分治、贪心、动态规划、回溯
- 复杂度分析：时间/空间复杂度
4. 计算机组成与体系结构
- CPU 结构、指令系统、流水线
- 存储器层次：寄存器 → Cache → 内存 → 外存
- 总线、I/O、中断、异常
- 浮点数表示、汇编基础
5. 操作系统
- 进程与线程、并发、死锁
- 内存管理、分页、分段、虚拟内存
- 文件系统、磁盘管理
- 调度算法、同步互斥（锁、信号量）
6. 计算机网络
- 五层/七层模型
- 传输层：TCP/UDP
- 网络层：IP、路由
- 应用层：HTTP/HTTPS、DNS、FTP
- 网络安全基础
7. 数据库系统
- 关系型数据库：MySQL、Oracle
- SQL 语言、索引、事务 ACID
- 范式、锁、MVCC、查询优化
- 非关系型数据库：Redis、MongoDB 入门
8. 软件工程与高级方向
- 软件工程：需求、设计、测试、维护
- 设计模式、系统设计、微服务
- 编译原理、编程语言原理
- 人工智能、机器学习、计算机视觉、大数据、云计算、网络安全等方向基础
 
极简学习路线（最稳）
1. 编程语言
2. 数据结构与算法
3. 计算机组成
4. 操作系统
5. 计算机网络
6. 数据库
7. 选一个方向深耕（后端/前端/AI/安全/大数据）
