计算机领域常用数与公式总结
------------------------------------------------------------------------------------------------
一、 数制相关（底层存储与计算）
1. 数制转换公式
- 十进制转二进制/八进制/十六进制：除基取余，逆序排列（基分别为2、8、16）
- 二进制转十进制：D=\sum_{i=-m}^{n-1}k_i \times 2^i（k_i为二进制位，n整数位，m小数位）
- 二进制转八进制：3位分组（不足补0），每组转对应八进制数
- 二进制转十六进制：4位分组（不足补0），每组转对应十六进制数
2. 机器数运算（补码核心）
- 正数补码 = 原码 = 反码
- 负数补码 = 反码 + 1
- 补码加法公式：[X+Y]_补 = [X]_补 + [Y]_补（模 2^n）
 ------------------------------------------------------------------------------------------------
二、 算法复杂度（算法效率评估）
1. 时间复杂度：描述算法执行时间随数据规模增长的趋势，记为 O(f(n))
- 常数阶：O(1)（如访问数组单个元素）
- 对数阶：O(\log_2n)（如二分查找）
- 线性阶：O(n)（如顺序查找）
- 线性对数阶：O(n\log_2n)（如快速排序、归并排序）
- 平方阶：O(n^2)（如冒泡排序、选择排序）
- 指数阶：O(2^n)（如汉诺塔递归算法）
2. 空间复杂度：描述算法占用空间随数据规模增长的趋势，记为 S(f(n))
- 常数空间：S(1)（如原地排序）
- 线性空间：S(n)（如递归深度为n的栈空间、额外数组存储）
 ------------------------------------------------------------------------------------------------
三、 组合数学（算法计数与排列）
1. 排列公式
- 选排列：P_n^k = \frac{n!}{(n-k)!}（从n个元素取k个有序排列）
- 全排列：P_n^n = n! = n\times(n-1)\times\cdots\times1
- 可重复排列：n^k（从n个元素取k个，允许重复）
2. 组合公式
- 不重复组合：C_n^k=\binom{n}{k}=\frac{n!}{k!(n-k)!}
- 性质：\binom{n}{k}=\binom{n}{n-k}；\binom{n}{k}+\binom{n}{k-1}=\binom{n+1}{k}
- 可重复组合：\binom{n+k-1}{k}
3. 递推公式
- 斐波那契数列：F_n=F_{n-1}+F_{n-2}（F_1=1,F_2=1）
- 汉诺塔移动次数：H(n)=2H(n-1)+1，通项 H(n)=2^n-1
 ------------------------------------------------------------------------------------------------
四、 信息论（数据压缩与传输）
1. 自信息：I(x)=-\log_2P(x)（P(x)为事件x发生概率，单位：比特）
2. 信息熵：H(X)=-\sum_{i=1}^nP(x_i)\log_2P(x_i)（信源平均信息量）
3. 信道容量：C=W\log_2\left(1+\frac{S}{N}\right)（W带宽，S/N信噪比）
4. 交叉熵：H(P,Q)=-\sum_{i=1}^nP(x_i)\log_2Q(x_i)（机器学习分类损失函数）
 ------------------------------------------------------------------------------------------------
五、 图论（路径规划与网络）
1. 图的基本参数
- 无向图边数：m=\frac{1}{2}\sum_{i=1}^n d(v_i)（d(v_i)为顶点v_i的度数）
- 有向图边数：m=\sum_{i=1}^n d^+(v_i)=\sum_{i=1}^n d^-(v_i)（入度d^-，出度d^+）
2. 最短路径相关
- 迪杰斯特拉算法：求解单源最短路径，时间复杂度 O(n^2)（邻接矩阵）
- 弗洛伊德算法：求解任意两点最短路径，时间复杂度 O(n^3)
 ------------------------------------------------------------------------------------------------
六、 密码学（数据安全）
1. 哈希函数：h:M\rightarrow D（M为任意长度明文，D为固定长度哈希值）
2. RSA 密钥生成
- 选两个大质数p,q，计算n=p\times q
- 计算欧拉函数\varphi(n)=(p-1)(q-1)
- 选公钥e（1<e<\varphi(n)，且e与\varphi(n)互质）
- 计算私钥d（d\times e \equiv 1 \pmod{\varphi(n)}）
 ------------------------------------------------------------------------------------------------
七、 计算机网络（传输与协议
1. 带宽与传输速率
- 比特率：单位时间传输的比特数，单位 bps
- 波特率：单位时间传输的码元数，比特率 = 波特率 × 每个码元的比特数
2. HTTP 状态码分类
- 1xx：100~199（提示）
- 2xx：200~299（成功）
- 3xx：300~399（重定向）
- 4xx：400~499（客户端错误）
- 5xx：500~599（服务器错误）
