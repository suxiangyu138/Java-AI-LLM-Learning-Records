操作系统核心知识点
一、 操作系统概述
1. 操作系统定义：操作系统是管理计算机硬件与软件资源的系统软件，是用户与计算机硬件之间的接口，同时也是计算机系统的内核与基石。
2. 操作系统的目标与功能：目标包括方便性、有效性、可扩充性、开放性；核心功能有处理机管理、存储器管理、设备管理、文件管理、用户接口管理。
3. 操作系统的特征：并发（多个程序在一段时间内同时运行，与并行区分，并行是同一时刻同时运行）、共享（系统资源被多个并发程序共同使用，分为互斥共享和同时共享）、虚拟（通过时分复用、空分复用等技术将物理资源抽象为逻辑资源，如虚拟内存、虚拟处理器）、异步（程序执行是走走停停的，以不可预知的速度推进）。
4. 操作系统的发展历程：从无操作系统的手工操作阶段，到单道批处理系统、多道批处理系统，再到分时系统、实时系统，最后发展为通用操作系统；其中多道批处理系统的出现标志着操作系统的成熟，分时系统实现了人机交互。
5. 操作系统的分类：按使用环境分为批处理系统、分时系统、实时系统（硬实时、软实时）；按用户数量分为单用户系统、多用户系统；按硬件结构分为单机操作系统、网络操作系统、分布式操作系统。

二、 进程管理
1. 进程的基本概念：进程是程序在计算机中的一次执行过程，是系统进行资源分配和调度的基本单位；进程与程序的区别在于，程序是静态的指令集合，进程是动态的执行过程，进程有生命周期，程序没有。
2. 进程的状态与转换：进程的基本状态包括就绪态（进程已分配到除CPU外的所有资源，等待调度执行）、运行态（进程占用CPU，正在执行）、阻塞态（进程因等待某事件如I/O完成而暂停执行）；状态转换包括就绪→运行（调度程序调度）、运行→就绪（时间片到或有更高优先级进程进入就绪队列）、运行→阻塞（进程请求I/O或等待同步信号）、阻塞→就绪（等待的事件完成）。
3. 进程控制块（PCB）：PCB是进程存在的唯一标志，包含进程标识符、进程状态、CPU状态信息、进程调度信息、资源分配信息、进程控制信息等；操作系统通过管理PCB来管理进程。
4. 进程控制：由操作系统内核的原语实现，包括进程创建（创建新进程，分配资源，初始化PCB）、进程撤销（终止进程，回收资源，删除PCB）、进程阻塞、进程唤醒等操作；原语是不可中断的操作序列。
5. 进程同步与互斥：
- 互斥：多个进程共享临界资源时，同一时刻只允许一个进程访问临界资源，访问临界资源的代码段称为临界区；实现互斥的原则包括空闲让进、忙则等待、有限等待、让权等待。
- 同步：多个进程为完成共同任务，按预定的先后次序执行，即进程间的直接制约关系。
- 实现机制：包括信号量机制（整型信号量、记录型信号量）、管程机制；信号量是一个整型变量，通过P操作（申请资源，减1，若小于0则阻塞）和V操作（释放资源，加1，若大于等于0则唤醒等待进程）实现同步与互斥；经典同步问题包括生产者-消费者问题、读者-写者问题、哲学家进餐问题。
6. 进程通信：进程间交换信息的方式，分为低级通信（如信号量机制，传递少量控制信息）和高级通信（传递大量数据）；高级通信方式包括共享存储区、消息传递系统（直接通信、间接通信）、管道通信（半双工通信，基于文件系统）。
7. 线程：线程是进程中的一个执行单元，是CPU调度和分派的基本单位；线程不拥有独立的资源，只拥有少量运行时必需的资源，与同属一个进程的其他线程共享进程的资源；线程的分类包括用户级线程（由用户程序管理，内核不感知）和内核级线程（由内核管理）；多线程程序的优势是并发性更高、开销更小、通信更便捷。

三、 处理机调度
1. 调度的层次：分为作业调度（高级调度，从外存的后备队列中选择作业调入内存，创建进程）、进程调度（低级调度，从就绪队列中选择进程分配CPU）、中级调度（内存调度，将暂时不运行的进程调至外存，释放内存空间，需要时再调回内存）。
2. 调度的目标：CPU利用率高、吞吐量（单位时间内完成的作业数）大、周转时间（作业从提交到完成的时间）短、响应时间（从用户提交请求到系统首次产生响应的时间）快、公平性。
3. 进程调度算法：
- 先来先服务（FCFS）：按进程到达就绪队列的先后顺序调度，算法简单，公平，但不利于短作业，会导致短作业等待长作业。
- 短作业优先（SJF）：选择估计运行时间最短的进程优先调度，能降低平均周转时间，但难以准确估计作业运行时间，会导致长作业饥饿。
- 优先级调度：为每个进程分配优先级，选择优先级最高的进程调度；优先级分为静态优先级（创建时确定，运行中不变）和动态优先级（运行中根据进程状态调整）；可分为非抢占式和抢占式。
- 时间片轮转（RR）：将CPU的处理时间划分为固定长度的时间片，就绪队列中的进程轮流占用CPU，时间片到则进程让出CPU，回到就绪队列；时间片的大小会影响系统性能，时间片过小会导致调度开销大，过大则退化为FCFS。
- 多级反馈队列调度：设置多个就绪队列，每个队列的时间片大小不同，优先级越高的队列时间片越小；进程先进入最高优先级队列，按时间片轮转调度，若时间片到未完成则转入下一级队列，依次类推；该算法兼顾了短作业、长作业和交互型作业的需求。

四、 存储器管理
1. 存储器管理的目标：提高内存利用率、方便用户使用、提供足够的存储空间、保护内存中的程序和数据不被破坏。
2. 程序的装入与链接：
- 装入方式：绝对装入（将程序装入到指定的内存地址，适用于单道程序）、可重定位装入（装入时将逻辑地址转换为物理地址，地址变换在装入时完成，适用于多道程序）、动态运行时装入（地址变换在程序运行时完成，需要硬件支持，灵活性高）。
- 链接方式：静态链接（程序运行前将所有目标模块和库函数链接为一个完整的可执行文件）、装入时动态链接（装入内存时边装入边链接）、运行时动态链接（程序运行时需要某模块才进行链接）。
3. 连续分配存储管理方式：为进程分配连续的内存空间，包括单一连续分配（适用于单用户单任务系统）、固定分区分配（将内存划分为若干个固定大小的分区，每个分区装入一个进程，存在内部碎片）、动态分区分配（根据进程大小动态划分分区，不存在内部碎片，但存在外部碎片）；动态分区分配算法包括首次适应算法、循环首次适应算法、最佳适应算法、最坏适应算法。
4. 分页存储管理方式：
- 将内存划分为大小相等的物理块（页框），将进程的逻辑地址空间划分为与物理块大小相等的页面；进程的页面装入到内存的物理块中，页面与物理块无需连续。
- 逻辑地址结构为页号+页内偏移量，通过页表实现逻辑地址到物理地址的转换；页表存放在内存中，每个进程有一张页表，页表项包含页号和对应的物理块号。
- 为提高地址变换速度，引入快表（联想寄存器），存放近期访问的页表项，实现高速缓存。
5. 分段存储管理方式：
- 按程序的逻辑结构将进程的地址空间划分为若干个段，每个段有自己的段名和段长，段内地址连续，段间地址不连续。
- 逻辑地址结构为段号+段内偏移量，通过段表实现地址转换；段表项包含段号、段长、段的基地址；分段存储便于程序的模块化设计和共享，便于动态增长。
6. 段页式存储管理方式：结合分页和分段的优点，先将进程划分为段，再将每个段划分为页面；需要段表和页表两级表实现地址转换，段表项包含段号和页表的基地址，页表项包含页号和物理块号。
7. 虚拟内存：
- 基本概念：基于局部性原理（时间局部性、空间局部性），通过虚拟内存技术，为进程提供比实际内存更大的地址空间；虚拟内存的大小由地址总线的位数决定。
- 实现方式：请求分页存储管理、请求分段存储管理、请求段页式存储管理；核心是按需调页（段），即进程运行时，只将部分页面（段）装入内存，需要时再调入所需页面（段）。
- 页面置换算法：当内存空间不足时，选择部分页面调出内存，常用算法包括最佳置换算法（OPT，选择未来最久不使用的页面调出，理论最优但不可实现）、先进先出置换算法（FIFO，选择最先装入的页面调出，可能出现Belady异常）、最近最少使用置换算法（LRU，选择最近最少使用的页面调出，性能接近OPT）、时钟置换算法（CLOCK，基于页面的使用位，开销小，易于实现）。

五、 设备管理
1. 设备的分类：按设备的使用特性分为存储设备（如磁盘、U盘）和I/O设备（如键盘、打印机）；按传输速率分为低速设备、中速设备、高速设备；按信息交换单位分为字符设备（以字符为单位传输）和块设备（以数据块为单位传输）；按设备的共享属性分为独占设备（如打印机，同一时刻只能被一个进程使用）、共享设备（如磁盘，可被多个进程同时使用）、虚拟设备（通过SPOOLing技术将独占设备抽象为共享设备）。
2. 设备管理的目标与功能：目标是提高设备利用率、方便用户使用、提高I/O效率；功能包括设备分配、设备处理、缓冲管理、设备独立性。
3. I/O控制方式：
- 程序直接控制方式：CPU不断轮询设备状态，直到I/O完成，CPU利用率极低。
- 中断驱动方式：设备完成I/O后发送中断信号，CPU响应中断并处理，CPU利用率提高。
- DMA方式：DMA控制器直接控制内存与设备之间的数据传输，CPU只需在传输开始和结束时参与，减少CPU干预。
- 通道方式：通道是专门的硬件，能独立执行通道程序，管理I/O操作，CPU只需向通道发送命令，进一步提高CPU利用率。
4. 缓冲管理：引入缓冲区（内存中的一块区域），缓解CPU与I/O设备之间的速度差异，提高CPU和I/O设备的并行性；缓冲的类型包括单缓冲、双缓冲、循环缓冲、缓冲池。
5. 设备分配：设备分配的原则是设备独立性（用户使用逻辑设备名，系统映射为物理设备名）、安全性（避免死锁）；设备分配的数据结构包括设备控制表（DCT）、控制器控制表（COCT）、通道控制表（CHCT）、系统设备表（SDT）。
6. SPOOLing技术：即假脱机技术，利用外存（通常是磁盘）模拟脱机I/O，将独占设备转换为共享设备；核心是输入井和输出井，输入井存放从输入设备读入的数据，输出井存放要输出到输出设备的数据；SPOOLing技术提高了设备利用率，实现了虚拟设备。
7. 磁盘管理：磁盘是典型的块设备，磁盘的性能指标包括寻道时间（磁头移动到指定磁道的时间）、旋转延迟时间（磁道上的扇区旋转到磁头下方的时间）、传输时间（数据从磁盘传输到内存的时间）；磁盘调度算法的目标是减少寻道时间，常用算法包括先来先服务（FCFS）、最短寻道时间优先（SSTF）、扫描算法（SCAN，又称电梯算法）、循环扫描算法（CSCAN）。

六、 文件管理
1. 文件与文件系统的基本概念：文件是具有符号名的一组相关信息的集合；文件系统是操作系统中负责管理和存取文件的软件集合，提供文件的创建、删除、读、写等操作，为用户提供统一的文件访问接口。
2. 文件的分类：按用途分为系统文件、用户文件、库文件；按文件的保护级别分为只读文件、读写文件、可执行文件；按文件的逻辑结构分为有结构文件（记录式文件，如数据库文件）和无结构文件（流式文件，如文本文件）；按文件的物理结构分为顺序文件、链接文件、索引文件。
3. 文件的逻辑结构：
- 有结构文件：分为定长记录文件和变长记录文件；组织方式包括顺序结构、索引结构、索引顺序结构。
- 无结构文件：由字符流组成，没有固定的记录结构，是最常用的文件结构。
4. 文件的物理结构：
- 顺序结构：文件的信息连续存储在磁盘的若干个连续的物理块中，优点是访问速度快，缺点是不利于文件的动态增长，存在外部碎片。
- 链接结构：文件的信息存储在磁盘的若干个不连续的物理块中，通过指针将物理块链接起来，优点是利于文件的动态增长，不存在外部碎片，缺点是随机访问速度慢。
- 索引结构：为文件建立一张索引表，索引表中记录了文件的每个逻辑块对应的物理块号，文件的目录项指向索引表；优点是支持随机访问，利于文件的动态增长，缺点是需要额外的空间存储索引表。
5. 文件目录：文件目录是文件控制块（FCB）的集合，FCB是文件存在的唯一标志，包含文件名、文件的物理位置、文件的存取控制信息、文件的属性等；目录结构分为一级目录结构（简单，但文件名不能重名）、二级目录结构（分为主目录和用户目录，解决了重名问题）、多级目录结构（树形目录结构，如Windows、Linux的文件系统，便于文件的分类管理和共享）。
6. 文件存储空间的管理：常用的管理方法包括空闲表法（适用于连续分配方式）、空闲链表法（分为空闲盘块链和空闲盘区链）、位示图法（用二进制位表示磁盘块的空闲状态，占用空间小，管理高效）、成组链接法（UNIX系统采用的方法，结合了空闲表法和空闲链表法的优点）。
7. 文件的存取控制：为保证文件的安全性，文件系统提供存取控制功能，规定不同用户对文件的访问权限；常用的存取控制方法包括存取控制矩阵、存取控制表、用户权限表、口令和密码。
8. 文件的操作：基本操作包括创建文件、删除文件、打开文件、关闭文件、读文件、写文件；文件的打开操作是将文件的FCB调入内存，建立用户与文件的关联；关闭操作是将内存中的FCB写回外存，解除用户与文件的关联。

七、 操作系统接口
1. 用户接口：分为命令接口和程序接口；命令接口是用户与操作系统交互的接口，分为联机命令接口（交互式，如Linux的Shell命令）和脱机命令接口（批处理，用户提交作业说明书）；程序接口又称系统调用，是应用程序请求操作系统服务的接口，应用程序通过系统调用获取操作系统的底层服务，如进程控制、文件操作、设备管理等.
2. 图形用户接口（GUI）：以图形化的方式为用户提供操作界面，如Windows的桌面、图标、菜单等，直观便捷，是目前主流的用户接口。

八、 死锁
1. 死锁的基本概念：多个进程因竞争资源而造成的一种僵局，若无外力作用，这些进程将永远无法继续执行；死锁产生的必要条件包括互斥条件（资源只能被一个进程占用）、请求和保持条件（进程持有资源的同时请求新资源）、不剥夺条件（进程已持有的资源不能被强行剥夺）、环路等待条件（若干进程形成环形的资源等待链）。
2. 死锁的处理策略：
- 预防死锁：破坏死锁的四个必要条件之一，如采用静态分配策略破坏请求和保持条件，采用剥夺式分配策略破坏不剥夺条件，采用资源有序分配策略破坏环路等待条件。
- 避免死锁：在资源分配过程中，通过银行家算法等方法，判断资源分配是否安全，若安全则分配，否则拒绝分配；银行家算法的核心是检查系统是否处于安全状态（存在一个进程执行序列，使得所有进程都能顺利完成）。
- 检测与解除死锁：允许死锁发生，通过死锁检测算法（如资源分配图化简法）检测死锁，检测到死锁后，通过撤销进程、剥夺资源等方式解除死锁。
