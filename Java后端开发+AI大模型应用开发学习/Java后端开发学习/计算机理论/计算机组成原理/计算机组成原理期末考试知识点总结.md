计算机组成原理期末考试知识点总结
本文围绕计算机组成原理期末考试核心考点，按“核心概念→硬件模块→工作机制→性能指标”的逻辑梳理，重点标注高频考点、易混点和必考题型相关知识点，助力高效复习，规避易错点。
一、计算机系统概述（基础必考点）
1.1 计算机系统层次结构（高频考点）
核心层次（从下到上）：硬件层→微程序层→机器语言层→操作系统层→汇编语言层→高级语言层，重点掌握“硬件层（裸机）”与“操作系统层”的接口（系统调用）。
易混点：区分“计算机系统”与“计算机硬件系统”——计算机系统 = 硬件系统 + 软件系统（系统软件+应用软件），硬件系统是核心，软件系统是灵魂。
考点延伸：简述计算机系统层次结构的意义（隔离不同层次功能，降低开发复杂度，便于模块化设计）。
1.2 计算机的基本组成（必考）
冯·诺依曼体系结构核心（三大核心+两大特点）：
三大核心部件：运算器、控制器、存储器（补充：输入设备、输出设备，合称五大部件）。
两大核心特点：① 存储程序：将指令和数据一起存储在存储器中，计算机自动依次执行指令；② 指令和数据采用二进制表示。
易考点：运算器的核心是ALU（算术逻辑单元），控制器的核心是CU（控制单元），存储器分为主存（内存）和辅存（外存）。
1.3 计算机的性能指标（高频计算题考点）
核心指标：
字长：计算机一次能处理的二进制数据的位数（如32位、64位），决定运算精度和寻址能力。
主频（时钟频率）：CPU的时钟周期的倒数，单位GHz，主频越高，CPU运算速度越快（注意：主频≠运算速度，需结合CPI）。
CPI（每条指令的平均时钟周期数）：CPI越小，指令执行效率越高，运算速度越快。
MIPS（每秒百万条指令）：运算速度指标，计算公式：MIPS = 主频（Hz） / (CPI × 10⁶)。
必考计算题：已知主频、CPI，计算MIPS；或已知MIPS、主频，计算CPI。
二、存储器系统（重点难点，占分比高）
2.1 存储器的分类（高频考点）
分类依据
具体类别
核心特点（考点）
按存储介质
半导体存储器、磁表面存储器、光存储器
半导体存储器（主存）：速度快、易失性；磁表面（辅存）：容量大、非易失性；光存储（光盘）：容量中等、非易失性。
按存取方式
随机存取（RAM）、顺序存取（磁带）、直接存取（磁盘）
RAM：可随机访问任意地址，速度快（主存核心）；顺序存取：需按顺序查找，速度慢；直接存取：先定位磁道，再顺序查找，速度介于两者之间。
按易失性
易失性存储器（RAM）、非易失性存储器（ROM、辅存）
RAM：断电丢失数据（如DDR内存）；ROM：断电不丢失，用于存储BIOS等固定程序（PROM、EPROM、EEPROM的区别需了解）。
2.2 主存储器（内存）的组成与工作原理
核心组成：存储体（核心，存储二进制数据）、地址译码器（将地址信号转换为存储单元地址）、控制电路（控制读写操作）、数据缓冲寄存器（DR）、地址寄存器（AR）。
读写过程（必考）：
读操作：CPU将地址送入AR→地址译码器选中对应存储单元→控制电路发出读命令→存储单元数据送入DR→DR将数据送入CPU。
写操作：CPU将地址送入AR、数据送入DR→地址译码器选中对应存储单元→控制电路发出写命令→DR中的数据写入存储单元。
易混点：区分DR（数据缓冲寄存器）和AR（地址寄存器）的功能，避免混淆。
2.3 存储体系结构（重点难点）
核心逻辑：分层存储，解决“速度、容量、成本”三者的矛盾（速度：主存>辅存；容量：辅存>主存；成本：辅存<主存）。
三级存储体系：Cache（高速缓冲存储器）→主存→辅存
Cache：位于CPU与主存之间，速度最快（接近CPU）、容量最小、成本最高，用于缓存CPU频繁访问的数据和指令，减少CPU访问主存的次数，提升系统速度。
主存：核心存储，CPU可直接访问，速度、容量、成本居中。
辅存：用于持久化存储大量数据，CPU不能直接访问，需通过主存中转（如磁盘、SSD）。
Cache的核心考点：
命中率：Cache命中次数 / 总访问次数，命中率越高，系统速度越快。
映射方式（必考）：直接映射、全相联映射、组相联映射（重点掌握每种映射的特点、优缺点）。
直接映射：简单、速度快，但命中率低；
全相联映射：命中率高，但结构复杂、速度慢；
组相联映射：兼顾前两者优点，是实际应用中最常用的方式。
2.4 辅存储器（外存）核心考点
常见辅存：磁盘（机械硬盘）、SSD（固态硬盘）、U盘、光盘。
磁盘核心参数（计算题考点）：
磁道：磁盘表面的同心圆，每个磁道有相同的扇区数。
扇区：磁盘的最小存储单元（通常512字节）。
磁盘容量计算公式：容量 = 磁头数 × 磁道数（ cylinders ） × 每磁道扇区数 × 每扇区字节数。
易考点：SSD与机械磁盘的区别（SSD基于闪存，无机械部件，速度快、功耗低；机械磁盘有磁头、电机，速度慢、功耗高）。
三、运算器（基础重点，必考运算逻辑）
3.1 运算器的组成
核心组成：ALU（算术逻辑单元）、累加器（AC）、通用寄存器组、状态寄存器（PSW）。
ALU：核心部件，执行算术运算（加、减、乘、除）和逻辑运算（与、或、非、异或）。
累加器（AC）：用于存放操作数和运算结果，是运算器中最常用的寄存器。
状态寄存器（PSW）：存放运算结果的状态（如进位标志CF、溢出标志OF、零标志ZF、符号标志SF），考点：各标志位的含义及判断方法。
3.2 定点数运算（必考计算题）
定点数分类：定点整数（小数点在最低位之后）、定点小数（小数点在符号位之后）。
核心运算：
定点加法/减法：采用补码运算（重点！），规则：[X±Y]补 = [X]补 ± [Y]补（减法转换为加法，[ -Y ]补 = 对[Y]补求反加1）。
溢出判断（高频考点）：
方法1：符号位判断法——两个正数相加，结果为负；两个负数相加，结果为正，即为溢出。
方法2：进位判断法——最高位进位与次高位进位不同，即为溢出。
必考计算题：给定两个定点数，用补码计算加法/减法，并判断是否溢出。
3.3 浮点数运算（难点，高频考点）
浮点数表示：N = 尾数M × 基数R^阶码E（通常R=2），格式：符号位 + 阶码 + 尾数。
核心考点：
浮点数的规格化：尾数最高位为1（正数）或100...0（负数补码），目的是提高精度、统一表示形式。
浮点数加法/减法步骤（必考）：① 对阶（使两个数的阶码相等，小阶向大阶看齐，尾数右移）；② 尾数相加/减；③ 规格化；④ 舍入（避免精度损失）；⑤ 判溢出（阶码溢出，浮点数溢出）。
易混点：浮点数溢出与定点数溢出的区别——浮点数溢出是阶码溢出，定点数溢出是数值本身超出表示范围。
四、控制器（难点，核心考点）
4.1 控制器的组成与功能
核心组成：CU（控制单元）、程序计数器（PC）、指令寄存器（IR）、指令译码器（ID）、时序产生器。
核心功能：取指令、分析指令、执行指令，控制计算机各部件协调工作。
各部件功能（必考）：
PC：存放当前要执行的指令地址，指令执行后自动加1（或按转移指令修改），是“程序计数器”，决定程序执行顺序。
IR：存放当前正在执行的指令，供译码器分析。
ID：对IR中的指令进行译码，确定指令的操作类型和操作数地址。
CU：根据译码结果，产生控制信号，控制各部件执行对应操作。
时序产生器：产生统一的时钟信号，同步各部件的工作（如机器周期、节拍）。
4.2 指令执行过程（必考，流程题）
指令执行的完整流程（以冯·诺依曼体系为例），分三个阶段，每个阶段的核心操作必须牢记：
取指令阶段：
CPU将PC中的指令地址送入主存地址寄存器（AR）；
控制电路发出读命令，主存将对应地址的指令送入数据缓冲寄存器（DR）；
DR将指令送入指令寄存器（IR），同时PC自动加1，指向下一步要执行的指令地址。
分析指令阶段：
指令译码器（ID）对IR中的指令进行译码，分析指令的操作码（确定操作类型）和地址码（确定操作数地址）；
根据地址码，获取操作数（若操作数在主存，需访问主存读取；若在寄存器，直接从寄存器读取）。
执行指令阶段：
控制单元（CU）根据译码结果，产生控制信号，控制运算器、存储器等部件执行对应操作（如算术运算、逻辑运算、数据存储）；
将运算结果存入指定寄存器或主存，更新状态寄存器（PSW）的标志位。
考点延伸：指令周期（执行一条指令的时间）= 取指周期 + 分析周期 + 执行周期，不同指令的指令周期不同。
4.3 控制器的控制方式（高频考点）
三种控制方式，重点掌握特点和适用场景：
同步控制方式：所有部件按统一的时钟信号工作，控制简单、速度快，适用于指令周期固定的场景（如RISC架构）。
异步控制方式：各部件按自身速度工作，通过“握手信号”同步，控制灵活、适应不同速度的部件，适用于指令周期不固定的场景（如外设交互）。
联合控制方式：结合同步和异步的优点，大部分指令采用同步控制，特殊指令（如I/O指令）采用异步控制，是实际计算机中最常用的方式。
五、输入输出（I/O）系统（基础考点，易考简答题）
5.1 I/O系统的组成
组成：I/O设备（输入设备：键盘、鼠标；输出设备：显示器、打印机）、I/O接口、I/O控制器。
I/O接口的作用（必考）：连接CPU与I/O设备，解决CPU与I/O设备之间“速度不匹配、信号格式不兼容、时序不一致”的问题，是两者之间的桥梁。
I/O接口的核心功能：数据缓冲、信号转换、地址译码、控制逻辑、中断控制。
5.2 I/O传输方式（高频考点，简答题+选择题）
四种传输方式，重点掌握每种方式的特点、优缺点和适用场景：
程序查询方式（PIO）：CPU主动查询I/O设备是否就绪，若未就绪，CPU一直等待（阻塞），控制简单，但CPU利用率极低，适用于低速、少量I/O设备（如键盘）。
程序中断方式：I/O设备就绪后，主动向CPU发出中断请求，CPU暂停当前程序，处理I/O请求，处理完成后返回原程序，CPU利用率提升，适用于中速I/O设备（如打印机）。
DMA方式（直接内存访问）：CPU发起I/O请求后，由DMA控制器直接控制I/O设备与主存之间的数据传输，CPU无需参与，仅在传输完成后接收通知，CPU利用率最高，适用于高速、大量数据传输（如磁盘、SSD）。
通道方式：独立于CPU的专用硬件，负责管理I/O设备与主存之间的传输，可同时控制多个I/O设备，适用于大型计算机、多外设场景。
易考点：区分四种传输方式的CPU利用率，从低到高：程序查询方式 < 程序中断方式 < DMA方式 < 通道方式。
5.3 中断系统（重点）
中断的定义：I/O设备或其他异常事件（如电源故障、运算溢出）发生时，暂停CPU当前程序，转去处理该事件，处理完成后返回原程序的过程。
中断处理流程（必考）：① 中断请求（I/O设备发出中断信号）；② 中断响应（CPU暂停当前程序，保存断点和状态）；③ 中断判优（确定优先级最高的中断）；④ 中断服务（执行中断服务程序）；⑤ 中断返回（恢复断点和状态，返回原程序）。
中断优先级：不同中断的优先级不同，CPU优先处理优先级高的中断（如电源故障中断优先级高于I/O中断）。
六、总线系统（基础考点）
6.1 总线的定义与分类
定义：连接计算机各部件（CPU、存储器、I/O设备）的公共传输线路，用于传输地址、数据和控制信号，实现各部件的信息交换。
分类（按传输信号类型，必考）：
地址总线（AB）：传输地址信号，决定主存的寻址空间（地址总线位数越多，寻址空间越大，如32位地址总线，寻址空间为2³²字节）。
数据总线（DB）：传输数据信号，数据总线位数与CPU字长一致（如64位CPU，数据总线通常为64位）。
控制总线（CB）：传输控制信号（如读命令、写命令、中断请求信号），协调各部件工作。
6.2 总线的性能指标
核心指标：总线宽度（数据总线位数）、总线频率（总线的工作频率，单位MHz）、总线带宽（总线每秒传输的数据量，计算公式：带宽 = 总线宽度 × 总线频率 / 8，单位MB/s）。
必考计算题：已知总线宽度和总线频率，计算总线带宽。
七、高频易错点与必考题型总结
7.1 易错点梳理（规避丢分）
混淆“主存”与“Cache”：Cache不是主存的一部分，是独立于主存的高速缓冲存储器，CPU访问数据时，先访问Cache，再访问主存。
定点数补码运算的溢出判断：注意符号位和进位的关系，避免误判。
指令执行过程中PC的变化：取指后PC自动加1，转移指令会修改PC的值，指向转移目标地址。
I/O传输方式的区别：尤其是DMA方式与程序中断方式的区别——DMA方式CPU不参与数据传输，程序中断方式CPU需要参与数据传输。
总线分类：地址总线、数据总线、控制总线的功能，避免混淆传输的信号类型。
7.2 必考题型汇总
计算题：① 计算机性能指标（MIPS、CPI）计算；② 磁盘容量计算；③ 总线带宽计算；④ 定点数补码加法/减法（含溢出判断）；⑤ 浮点数规格化与加法/减法。
简答题：① 计算机系统层次结构的组成及意义；② 冯·诺依曼体系结构的核心特点；③ Cache的映射方式及优缺点；④ 指令执行的完整流程；⑤ I/O四种传输方式的特点及适用场景。
流程题：① 主存的读写流程；② 中断处理流程；③ 指令执行流程。
选择题：重点考查各模块的核心概念、易混点（如存储器分类、控制器组成、总线分类等）。
复习建议：重点掌握“存储器系统”“运算器”“控制器”三大模块，牢记核心概念和流程，多做计算题和流程题，规避易错点，确保基础题不丢分，难点题多拿分。
