信息论核心知识点总结
------------------------------------------------------------------------------------------------
一、 核心基础概念
1. 信息的定义
信息是消除不确定性的量，未知事件的不确定性越高，其包含的信息量越大；确定发生的事件（概率为1）信息量为0。
2. 自信息
单个离散随机事件 x 的信息量，公式为：
I(x) = -\log_2 P(x)
单位为比特（bit），事件概率 P(x) 越小，自信息越大。
3. 信息熵（信源熵）
信源的平均信息量，反映信源的整体不确定性，是所有可能事件自信息的数学期望，公式为：
H(X) = -\sum_{i=1}^n P(x_i)\log_2 P(x_i)
关键性质：等概率分布时熵最大；某事件概率为1时熵为0。
计算机应用：决策树的纯度衡量、数据压缩的理论极限。
4. 相对熵（KL散度）与交叉熵
- 相对熵：衡量两个概率分布 P 和 Q 的差异，公式为 D_{KL}(P||Q)=\sum P(x)\log\frac{P(x)}{Q(x)}，非对称。
- 交叉熵：衡量预测分布与真实分布的匹配程度，公式为 H(P,Q)=-\sum P(x)\log Q(x)，是机器学习分类任务的常用损失函数。
 ------------------------------------------------------------------------------------------------
二、 信息编码与数据压缩
1. 编码核心目标
用最少的比特数表示信源信息，同时保证无失真恢复（无损压缩）或可接受失真（有损压缩）。
2. 香农无损编码定理
离散信源的无损压缩平均码长下界为信源熵，即 L_{avg} \ge H(X)，无法突破该极限。
3. 经典编码算法
- 哈夫曼编码：根据事件概率分配不等长码字，概率高的事件用短码，使平均码长接近熵，用于 ZIP、PNG 等无损压缩。
- 算术编码：将整个信源序列映射为 [0,1) 区间的小数，压缩效率高于哈夫曼编码，用于 JPEG 等标准。
 ------------------------------------------------------------------------------------------------
三、 信道传输与可靠性
1. 信道容量
信道单位时间内可传输的最大信息量，香农信道容量公式为：
C = W\log_2\left(1+\frac{S}{N}\right)
其中 W 为信道带宽，S/N 为信噪比；提升带宽或信噪比可增大信道容量。
2. 信道编码
通过添加冗余信息实现检错或纠错，保证噪声信道下的可靠传输。
- 检错编码：奇偶校验、CRC 循环冗余校验，仅能发现错误。
- 纠错编码：汉明码、卷积码，可自动纠正部分错误，用于网络通信、卫星传输。
 ------------------------------------------------------------------------------------------------
四、 计算机领域核心应用
1. 数据压缩：所有压缩算法的理论基础，如文本、图像、音视频压缩。
2. 机器学习：交叉熵作为分类损失函数、信息增益用于决策树特征选择。
3. 密码学：分析加密算法安全性，衡量密钥的信息量。
4. 通信协议：网络传输的差错控制、流量控制机制设计。
