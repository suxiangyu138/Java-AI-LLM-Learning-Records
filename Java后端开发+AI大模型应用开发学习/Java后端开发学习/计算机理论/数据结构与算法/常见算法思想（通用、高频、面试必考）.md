常见算法思想（通用、高频、面试必考）
说明：以下为面试中最常考察的18种算法思想，每个思想包含核心定义、核心特点及典型例题，简洁凝练，适配面试背诵与解题应用，重点标注高频考点。
1. 暴力枚举（Brute Force）
核心：遍历所有可能的解，逐一验证是否满足题目约束条件，无需复杂逻辑推导。
特点：简单直接、编码难度低，但时间复杂度极高（通常为O(n²)及以上），仅适合数据规模极小的场景。
典型例题：查找数组中的目标值（小规模）、判断水仙花数、简单组合验证。
2. 分治法（Divide and Conquer）
核心：将原问题分解为若干个规模相等、结构相同、相互独立的子问题，递归求解每个子问题，最后合并子问题的结果，得到原问题的解。
特点：分而治之，子问题独立无重叠，适合大规模问题拆分，常与递归结合。
典型例题：归并排序、快速排序、二分查找、大数乘法、矩阵乘法。
3. 动态规划（Dynamic Programming, DP）
核心：将复杂问题分解为重叠的子问题，通过存储子问题的最优解（记忆化），避免重复计算，最终合并得到全局最优解。
核心三要素：状态定义（明确dp数组/矩阵的含义）、状态转移方程（子问题间的关联）、边界条件（基础子问题的解）。
典型例题：斐波那契数列、最长公共子序列（LCS）、0-1背包、完全背包、编辑距离、最大子数组和。
4. 贪心算法（Greedy）
核心：每一步都做出当前状态下的局部最优选择，不考虑未来影响，逐步累积局部最优解，试图得到全局最优解。
关键：需满足“贪心选择性质”（局部最优可推出全局最优），否则会得到次优解；与DP的核心区别是不存储子问题解。
典型例题：哈夫曼编码、活动安排问题、最小生成树（Kruskal算法、Prim算法）、硬币找零（面额合理场景，如1/5/10/20元）。
5. 回溯法（Backtracking）
核心：基于深度优先搜索（DFS），尝试所有可能的解题路径，当探索到某一步发现不满足约束条件时，立即回退到上一步，换一条路径继续探索，直至找到所有可行解或确定无解。
特点：带有“剪枝”优化（减少无效探索），本质是“试错”，适合求解“所有可行解”类问题。
典型例题：全排列、子集（含重复元素/无重复元素）、N皇后问题、电话号码的字母组合、解数独。
6. 深度优先搜索（DFS）
核心：优先往解题路径的深处探索，直到无法继续（到达边界），再回溯到上一个节点，选择其他路径，常用递归或栈实现。
特点：空间复杂度取决于递归深度或栈的大小，适合遍历有分支、有层次的结构（树、图）。
典型例题：二叉树的前/中/后序遍历、图的遍历（无向图/有向图）、迷宫求解、岛屿数量。
7. 广度优先搜索（BFS）
核心：按“层”遍历解题路径，先探索当前节点的所有相邻节点（同层），再依次探索下一层节点，常用队列实现。
特点：不回溯，能找到无权图的最短路径，空间复杂度取决于队列的大小（同层节点数最大值）。
典型例题：二叉树的层序遍历、无权图的最短路径、拓扑排序（辅助）、打开转盘锁。
8. 双指针（Two Pointers）
核心：用两个指针（同向/反向）遍历数组、链表等线性结构，通过指针的移动减少循环次数，优化时间复杂度。
分类：同向指针（如滑动窗口辅助）、反向指针（如有序数组查找）、快慢指针（如链表环判断）。
典型例题：两数之和（有序数组）、三数之和、四数之和、快慢指针判断链表环、链表反转（双指针版）。
9. 滑动窗口（Sliding Window）
核心：在数组/字符串中维护一个“窗口”（连续的子区间），通过动态调整窗口的左、右边界，筛选出满足条件的最优子区间。
特点：本质是双指针的延伸，将嵌套循环优化为单循环，时间复杂度从O(n²)降至O(n)。
典型例题：最长无重复子串、最小覆盖子串、子数组和为k（进阶）、滑动窗口最大值（结合单调队列）。
10. 前缀和（Prefix Sum）
核心：预处理数组，构造前缀和数组，通过前缀和快速计算任意区间的和，避免重复计算区间内元素。
分类：一维前缀和（数组）、二维前缀和（矩阵），核心公式：区间和 = 前缀和[右] - 前缀和[左-1]。
典型例题：子数组和为k、二维矩阵的子矩阵和、数组区间和查询（多次查询）。
11. 位运算（Bit Manipulation）
核心：利用二进制数的运算特性（与、或、异或、左移、右移等）简化计算，优化时间和空间复杂度。
常用技巧：异或去重、左移等价于乘2、右移等价于除2（向下取整）、与运算判断奇偶。
典型例题：只出现一次的数字（异或）、快速幂（位运算优化）、状态压缩（如N皇后的位运算实现）、二进制中1的个数。
12. 单调栈/单调队列
核心：维护一个栈（或队列），保证栈内/队列内元素的单调性（递增或递减），快速找到每个元素的前后最值（如 Next Greater Element）。
特点：时间复杂度O(n)，每个元素入栈/出栈一次，适合处理“找最值”类问题。
典型例题：下一个更大元素（I/II）、滑动窗口最大值（单调队列）、柱状图中最大的矩形（单调栈）、接雨水（单调栈）。
13. 哈希（Hash）
核心：通过哈希函数将任意长度的输入（key）映射到固定长度的哈希值，利用哈希表存储键值对，实现O(1)级别的查找、插入、删除。
关键：处理哈希碰撞（链地址法、开放定址法），常用哈希结构：哈希表（HashMap）、哈希集合（HashSet）。
典型例题：两数之和（哈希表存差值）、数组中重复元素判断、字符频率统计、四数相加II。
14. 拓扑排序（Topological Sort）
核心：对有向无环图（DAG）进行排序，使得对于每一条有向边u→v，节点u都在节点v之前，本质是“依赖关系排序”。
常用实现：Kahn算法（基于BFS，统计入度）、DFS拓扑排序（标记节点状态）。
典型例题：课程表（判断是否可完成所有课程）、任务调度（按依赖关系安排任务）、项目管理（依赖顺序）。
15. 并查集（Union-Find / Disjoint Set Union, DSU）
核心：一种用于管理集合的数据结构，支持两个核心操作：合并两个集合（Union）、查询一个元素所在的集合（Find），通过路径压缩和按秩合并优化效率。
特点：高效处理“连接性”问题，时间复杂度接近O(1)。
典型例题：朋友圈（统计连通分量）、岛屿连接（最小连接成本）、最小生成树（Kruskal算法辅助）、判断图中是否有环。
16. 二分答案（Binary Search on Answer）
核心：不直接求解问题，而是先确定答案的取值范围，对范围进行二分，每次验证当前中间值是否为可行解，逐步缩小范围，最终找到最优解。
关键：答案需满足“单调性”（可行解的范围是连续的），且验证可行解的过程需高效。
典型例题：珂珂吃香蕉（求最小进食速度）、寻找峰值、最小最大距离（如房屋分配）、分割数组的最大值。
17. 记忆化搜索（Memoization）
核心：结合递归和缓存（如哈希表、数组），将递归过程中计算过的子问题结果存储起来，避免重复计算，本质是“递归版的动态规划”。
特点：编码简洁，适合递归思路清晰但子问题重叠的场景，与DP可相互转换。
典型例题：斐波那契数列（递归优化）、爬楼梯、最长递增子序列（递归版）、目标和（递归优化）。
18. 模拟（Simulation）
核心：严格按照题目给出的规则、流程，一步步模拟执行，将抽象的题目要求转化为具体的代码逻辑。
特点：编码难度取决于题目规则的复杂程度，无需复杂算法思想，重点考察代码实现能力。
典型例题：螺旋矩阵（I/II）、生命游戏、字符串模拟（如罗马数字转整数）、机器人运动范围。
面试重点提示：动态规划、双指针、滑动窗口、哈希、回溯、DFS/BFS是高频中的高频，需熟练掌握核心逻辑及典型例题；并查集、拓扑排序、二分答案是中等难度常考，需掌握模板；其余思想需了解核心、熟记典型例题，应对基础提问。
