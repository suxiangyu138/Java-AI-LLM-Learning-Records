后端开发常用算法
一、排序算法 (Sorting Algorithms)
冒泡排序 (Bubble Sort)
- 思想：重复遍历数组，比较相邻元素，若逆序则交换；每一趟遍历都会将最大/最小元素“冒泡”到未排序部分的末尾。
- 时间复杂度：平均 O(n²) / 最好 O(n)（已排序） / 最坏 O(n²)
- 空间复杂度：O(1)
- 稳定性：稳定
- Java 实现要点：嵌套循环，外层控制遍历趟数，内层执行相邻元素的比较与交换。
选择排序 (Selection Sort)
- 思想：每一趟从未排序部分选择最小/最大元素，将其放到已排序部分的末尾。
- 时间复杂度：平均 O(n²) / 最好 O(n²) / 最坏 O(n²)
- 空间复杂度：O(1)
- 稳定性：不稳定
- Java 实现要点：外层循环划定已排序区域边界，内层循环查找未排序区域的最小/最大值索引，最后交换边界元素与最值元素。
插入排序 (Insertion Sort)
- 思想：将未排序元素逐个取出，插入到已排序部分的正确位置。
- 时间复杂度：平均 O(n²) / 最好 O(n)（已排序） / 最坏 O(n²)
- 空间复杂度：O(1)
- 稳定性：稳定
- Java 实现要点：从第二个元素开始，向前与已排序元素比较，找到插入位置后移动元素并完成插入。
 希尔排序 (Shell Sort)
- 思想：插入排序的改进版，按指定步长将数组分组，对每组执行插入排序；步长逐渐减小至 1，最终完成整体排序。
- 时间复杂度：平均 O(n log n) ~ O(n²)（取决于步长序列）
- 空间复杂度：O(1)
- 稳定性：不稳定
- Java 实现要点：定义步长序列（如 n/2 递减），对每个步长执行分组插入排序。
归并排序 (Merge Sort)
- 思想：分治法核心，将数组递归拆分为两半，分别排序后，合并两个有序子数组得到完整有序数组。
- 时间复杂度：平均 O(n log n) / 最好 O(n log n) / 最坏 O(n log n)
- 空间复杂度：O(n)（需要临时数组存储合并结果）
- 稳定性：稳定
- Java 实现要点：递归分割数组，合并阶段创建临时数组存放有序结果，再复制回原数组；Java `Arrays.sort()` 对对象排序时基于此思想（TimSort）。
快速排序 (Quick Sort)
- 思想：分治法，选择一个基准元素，将数组划分为小于、等于、大于基准的三部分，递归排序左右两部分。
- 时间复杂度：平均 O(n log n) / 最好 O(n log n) / 最坏 O(n²)（基准选择不当）
- 空间复杂度：O(log n) ~ O(n)（递归栈空间）
- 稳定性：不稳定
- Java 实现要点：优化基准选择（如三数取中），实现 partition 分区过程，递归处理子数组；Java `Arrays.sort()` 对基本类型排序时使用双轴快速排序变体。
堆排序 (Heap Sort)
- 思想：将数组构建为最大/最小堆，反复提取堆顶元素（最值）并调整堆结构，最终得到有序数组。
- 时间复杂度：平均 O(n log n) / 最好 O(n log n) / 最坏 O(n log n)
- 空间复杂度：O(1)
- 稳定性：不稳定
- Java 实现要点：从最后一个非叶子节点开始构建堆，交换堆顶与未排序部分末尾元素，重新调整堆。
计数排序 (Counting Sort)
- 思想：非比较排序，统计每个元素出现的次数，基于统计结果直接生成有序数组。
- 时间复杂度：O(n + k)（k 为数据取值范围）
- 空间复杂度：O(k)
- 稳定性：稳定
- Java 实现要点：需已知数据范围，创建计数数组统计频次，累加计数数组确定元素位置，反向填充结果数组。
桶排序 (Bucket Sort)
- 思想：将数据分配到有限数量的桶中，对每个桶内数据单独排序（如插入排序），最后合并所有桶的结果。
- 时间复杂度：O(n + k)（k 为桶的数量）
- 空间复杂度：O(n + k)
- 稳定性：稳定
- Java 实现要点：根据数据分布设计桶的范围和数量，桶内可复用其他排序算法。
 基数排序 (Radix Sort)
- 思想：非比较排序，按低位到高位（或反之）依次对每一位执行稳定排序（通常用计数排序）。
- 时间复杂度：O(d * (n + b))（d 为数字位数，b 为基数，如 10）
- 空间复杂度：O(n + b)
- 稳定性：稳定
- Java 实现要点：从最低位到最高位，逐位对数组执行计数排序。
排序算法选择建议
- 小规模数据/基本有序：插入排序
- 追求稳定且时间效率：归并排序
- 追求平均效率且不要求稳定：快速排序
- 数据范围已知且较小：计数排序、桶排序
- Java 标准库：`Arrays.sort()`（基本类型用双轴快排，对象用 TimSort）；`Collections.sort()`（List 排序，基于 TimSort）

 二、查找算法 (Searching Algorithms)
线性查找 (Linear Search)
- 思想：从数组第一个元素开始，逐个与目标值比较，直到找到目标或遍历结束。
- 时间复杂度：平均 O(n) / 最好 O(1) / 最坏 O(n)
- 空间复杂度：O(1)
- 适用场景：无序数组、小规模数据
- Java 实现要点：简单 for 循环遍历数组即可。
二分查找 (Binary Search)
- 思想：在有序数组中，每次取中间元素与目标比较，缩小一半搜索范围，直到找到目标或范围为空。
- 时间复杂度：平均 O(log n) / 最好 O(1) / 最坏 O(log n)
- 空间复杂度：O(1)
- 适用场景：有序数组/列表、静态/少变动数据
- Java 实现要点：注意循环条件（low <= high），计算 mid 用 `low + (high - low) / 2` 避免溢出；可直接使用 `Arrays.binarySearch()`。
 插值查找 (Interpolation Search)
- 思想：二分查找的改进，根据目标值在数据范围内的预估位置计算中点，适合均匀分布数据。
- 时间复杂度：平均 O(log log n) / 最好 O(1) / 最坏 O(n)
- 空间复杂度：O(1)
- 适用场景：有序且数据分布均匀的数组
- Java 实现要点：mid 计算公式：`low + ((target - arr[low]) * (high - low)) / (arr[high] - arr[low])`。
斐波那契查找 (Fibonacci Search)
- 思想：利用黄金分割点划分搜索区间，是二分查找的变体。
- 时间复杂度：O(log n)
- 空间复杂度：O(1)
- 适用场景：有序数组、对 mid 计算有特殊要求的场景
- Java 实现要点：预先计算斐波那契数列，基于斐波那契数 F[k] 划分搜索区间。
哈希查找 (Hash Search)
- 思想：通过哈希函数将键映射到存储位置，直接访问目标位置。
- 时间复杂度：平均 O(1) / 最好 O(1) / 最坏 O(n)（哈希冲突严重）
- 空间复杂度：O(n)（存储哈希表）
- 适用场景：需要快速查找、插入、删除，不要求数据有序
- Java 实现要点：使用 `HashMap`/`HashSet`，注意哈希函数设计和冲突解决（如链地址法）。
树表查找 (Tree-based Search)
- 思想：在平衡二叉搜索树（AVL、红黑树）或 B/B+ 树中执行查找。
- 时间复杂度：平均/最坏 O(log n)
- 空间复杂度：O(n)（树结构存储）
- 适用场景：有序存储、动态数据、范围查询、多路查找
- Java 实现要点：`TreeMap`/`TreeSet` 内部基于红黑树实现；数据库索引常用 B+ 树。

三、图算法 (Graph Algorithms)
深度优先搜索 (DFS)
- 思想：尽可能深地遍历图的分支，无法继续时回溯。
- 时间复杂度：邻接表 O(V + E) / 邻接矩阵 O(V²)
- 空间复杂度：O(V)（递归栈/显式栈）
- 应用场景：路径查找、连通性判断、拓扑排序、强连通分量
- 实现提示：使用递归或显式栈，通过 visited 数组标记已访问节点。
广度优先搜索 (BFS)
- 思想：从起点开始，逐层向外遍历图的节点。
- 时间复杂度：邻接表 O(V + E) / 邻接矩阵 O(V²)
- 空间复杂度：O(V)（队列）
- 应用场景：无权图最短路径、层次遍历、连通性判断
- 实现提示：使用队列存储待遍历节点，配合 visited 数组。
 Dijkstra 算法
- 思想：求解单源最短路径，适用于非负权有向/无向图，贪心策略为每次选择距离起点最近的节点。
- 时间复杂度：O((V+E)logV)（优先队列实现）
- 空间复杂度：O(V)
- 应用场景：网络路由、地图导航
- 实现提示：使用最小堆（优先队列），执行“松弛操作”更新节点距离。
Bellman-Ford 算法
- 思想：求解单源最短路径，支持负权边，可检测负权环。
- 时间复杂度：O(VE)
- 空间复杂度：O(V)
- 应用场景：含负权边的图、金融套利检测
- 实现提示：对所有边执行 V-1 次松弛；第 V 次松弛若仍能更新距离，说明存在负权环。
Floyd-Warshall 算法
- 思想：求解所有节点对之间的最短路径，基于动态规划。
- 时间复杂度：O(V³)
- 空间复杂度：O(V²)
- 应用场景：稠密图、全源最短路径、传递闭包
- 实现提示：三层循环，以 k 为中转点，更新 `dp[i][j] = min(dp[i][j], dp[i][k] + dp[k][j])`。
Prim 算法
- 思想：求解最小生成树（MST），适用于稠密图，贪心选择离当前 MST 最近的节点加入。
- 时间复杂度：O(E log V)（优先队列）/ O(V²)（邻接矩阵）
- 空间复杂度：O(V)
- 应用场景：网络设计、电路布线
- 实现提示：从任意节点开始，维护 MST 节点集合，逐步扩展。
Kruskal 算法
- 思想：求解最小生成树（MST），适用于稀疏图，按边权从小到大排序，用并查集判断是否成环。
- 时间复杂度：O(E log E) = O(E log V)
- 空间复杂度：O(V)（并查集）
- 应用场景：网络设计、图像分割
- 实现提示：边排序 + 并查集判环，不成环则将边加入 MST。
拓扑排序 (Topological Sort)
- 思想：将有向无环图（DAG）的顶点排成线性序列，保证所有有向边 u->v 中 u 在 v 之前。
- 时间复杂度：O(V + E)
- 空间复杂度：O(V)
- 应用场景：任务调度、课程安排、依赖关系处理
- 实现提示：DFS 后序遍历结果逆序；或 Kahn 算法（入度为 0 的节点入队）。
Kahn 算法（拓扑排序）
- 思想：计算节点入度，入度为 0 的节点入队，出队时减少邻接点入度，新入度为 0 的节点入队。
- 时间复杂度：O(V + E)
- 空间复杂度：O(V)
- 应用场景：同拓扑排序
- 实现提示：核心是入度数组 + 队列，遍历过程中统计已处理节点数，判断是否存在环。
 A* 算法 (A Star)
- 思想：启发式搜索，在 BFS 基础上引入估价函数 `f(n) = g(n) + h(n)`（g 为已走成本，h 为预估成本）。
- 时间复杂度：取决于启发函数 h(n)，通常 O(b^d)（b 分支因子，d 深度）
- 空间复杂度：O(b^d)
- 应用场景：游戏 AI、机器人路径规划、地图导航
- 实现提示：维护 open list（优先队列）和 closed list，按 f(n) 排序选择节点。
并查集 (Union-Find / DSU)
- 思想：高效管理不相交集合的合并与查询，支持路径压缩和按秩合并优化。
- 时间复杂度：接近 O(1)（优化后）
- 空间复杂度：O(n)
- 应用场景：Kruskal 算法、连通性判断、动态连通性问题
- 实现提示：维护 parent 数组，find 方法（路径压缩）+ union 方法（按秩/大小合并）。
四、动态规划 (Dynamic Programming - DP)
核心思想
将复杂问题拆解为重叠子问题，存储子问题的解（记忆化/制表）避免重复计算；分为自顶向下（记忆化搜索）和自底向上（制表）两种实现方式。
关键步骤
1. 定义状态：明确 `dp[i]`/`dp[i][j]` 代表的业务含义；
2. 状态转移方程：推导如何从已知状态得到当前状态；
3. 初始条件：确定最小子问题的解；
4. 计算顺序：保证计算当前状态前，依赖的子问题已求解。
经典问题
- 背包问题（0-1 背包、完全背包、多重背包）
- 最长公共子序列（LCS）、最长递增子序列（LIS）
- 编辑距离、爬楼梯、打家劫舍、零钱兑换
- 三角形最小路径和、最大子序和（Kadane 算法）
- 股票买卖系列问题
五、贪心算法 (Greedy Algorithms)
核心思想
每一步选择当前状态下的最优解，期望通过局部最优得到全局最优；关键是证明贪心策略的正确性。
 经典问题
- 活动选择问题、霍夫曼编码
- 最小生成树（Prim、Kruskal 算法）
- Dijkstra 算法（单源最短路径）
- 找零钱问题（特殊面额）、区间覆盖问题

六、回溯算法 (Backtracking)
### 核心思想
试错式搜索算法，分步解决问题；若当前步骤无法得到有效解，则回溯到上一步，尝试其他路径；通常结合 DFS + 剪枝优化。
### 经典问题
- N 皇后问题、数独求解
- 全排列、组合、子集
- 单词搜索、迷宫问题、正则表达式匹配
---
 七、分治算法 (Divide and Conquer)
核心思想
将大问题拆分为若干规模较小的相同子问题，分别求解后合并结果，即“分解 → 解决 → 合并”。
 经典问题
- 归并排序、快速排序、二分查找
- 大整数乘法（Karatsuba 算法）、Strassen 矩阵乘法
- 汉诺塔、最近点对问题

 八、字符串算法 (String Algorithms)
朴素字符串匹配
- 思想：遍历文本串所有起始位置，逐字符匹配模式串。
- 时间复杂度：O(n*m)（n 文本长，m 模式长）
- 空间复杂度：O(1)
- 应用：短模式匹配、简单场景
- 实现：两层循环，分别遍历文本和模式串。
KMP 算法
- 思想：利用部分匹配表（前缀表），匹配失败时跳过不必要的比较，避免文本指针回退。
- 时间复杂度：O(n + m)
- 空间复杂度：O(m)
- 应用：单模式串高效匹配（如文本编辑器搜索）
- 实现：先构建前缀表，再基于前缀表执行匹配。
Boyer-Moore 算法
- 思想：从模式串末尾开始比较，通过坏字符规则、好后缀规则大幅跳跃，减少比较次数。
- 时间复杂度：平均亚线性 / 最坏 O(n*m)
- 空间复杂度：O(m + k)（k 字符集大小）
- 应用：长模式串匹配（实际场景高效）
- 实现：构建坏字符表 + 好后缀表，从右向左比较。
Rabin-Karp 算法
- 思想：通过哈希函数计算模式串和文本子串的哈希值，哈希值相等时再精确匹配。
- 时间复杂度：平均 O(n + m) / 最坏 O(n*m)（哈希冲突）
- 空间复杂度：O(1)
- 应用：多模式串匹配、滚动哈希场景
- 实现：计算模式串哈希，滚动计算文本子串哈希，哈希匹配时逐字符验证。
Trie（字典树/前缀树）
- 思想：多叉树结构，逐字符存储字符串，高效检索前缀/完整字符串。
- 时间复杂度：插入/查找 O(L)（L 字符串长度）
- 空间复杂度：O(ALPHABET_SIZE * L * N)（N 键数量）
- 应用：自动补全、拼写检查、IP 路由、词频统计
- 实现：节点包含子节点数组/映射 + 结束标志，逐字符插入/查找。
AC 自动机
- 思想：多模式串匹配的 KMP 扩展，基于 Trie 树添加失败指针，形成有限状态自动机。
- 时间复杂度：O(n + z)（z 匹配总数）
- 空间复杂度：O(m)（m 所有模式串总长度）
- 应用：一次扫描文本，找出所有模式串位置
- 实现：构建 Trie 树 → BFS 计算失败指针 → 扫描文本执行状态转移。
字符串哈希
- 思想：将字符串映射为整数，快速比较子串/整串。
- 时间复杂度：子串哈希计算 O(1)
- 空间复杂度：O(n)（存储前缀哈希）
- 应用：子串比较、回文判断、字符串去重
- 实现：多项式滚动哈希，前缀哈希 + 子串哈希公式计算。
 Manacher 算法
- 思想：线性时间内查找最长回文子串，利用回文半径数组和中心扩展优化。
- 时间复杂度：O(n)
- 空间复杂度：O(n)
- 应用：高效查找最长回文子串
- 实现：预处理字符串（插入分隔符），利用已计算的回文信息避免重复扩展。
 Z 函数（Z-Algorithm）
- 思想：计算每个位置后缀与原字符串的最长公共前缀（LCP）长度。
- 时间复杂度：O(n)
- 空间复杂度：O(n)
- 应用：模式匹配、子串出现次数、LCP 问题
- 实现：维护 [l, r] 区间，分情况计算 z[i]。

 九、其他重要算法/技术
位运算
- 操作：与 (&)、或 (|)、异或 (^)、取反 (~)、左移 (<<)、右移 (>>/>>>)。
- 应用：状态压缩、权限控制、快速计算、布隆过滤器。
布隆过滤器 (Bloom Filter)
- 特性：空间高效的概率型数据结构，判断元素是否在集合中；可能假阳性，无假阴性。
- 应用：缓存穿透防护、海量数据存在性判断。
LRU 缓存 (Least Recently Used)
- 实现：哈希表 + 双向链表，缓存满时淘汰最久未使用的项。
- 应用：缓存系统、页面置换算法。
 LFU 缓存 (Least Frequently Used)
- 实现：哈希表 + 多双向链表/平衡树，缓存满时淘汰使用频率最低的项。
- 应用：高频访问优先的缓存场景。
 蓄水池抽样 (Reservoir Sampling)
- 思想：从未知长度的数据流中随机选择 k 个样本，保证每个样本等概率。
- 应用：海量数据流随机抽样。
 洗牌算法 (Fisher-Yates Shuffle)
- 思想：生成有限集合的随机排列，保证每个排列等概率。
- 应用：随机打乱数组、游戏随机抽卡。
单调栈/单调队列
- 单调栈：栈内元素保持单调，解决 Next Greater Element、柱状图最大矩形等问题。
- 单调队列：队列内元素保持单调，解决滑动窗口最值问题。
 线段树/树状数组
- 线段树：处理区间查询（和/最值）、单点/区间更新，时间复杂度 O(log n)。
- 树状数组（Fenwick Tree）：高效计算前缀和、单点更新，比线段树简洁，功能稍少。
 快速幂/模幂
- 思想：高效计算 a^b mod m，时间复杂度 O(log b)。
- 应用：大数幂运算、密码学。
 数论相关
- 欧几里得算法：计算最大公约数（GCD）。
- 扩展欧几里得算法：求解 ax + by = gcd(a, b)。
- 中国剩余定理（CRT）：解决同余方程组。
- Miller-Rabin 素性测试：判断大整数是否为素数。
- Pollard's Rho 算法：分解大整数质因数。
---
 总结
1. 排序算法中，小规模/有序数据优先选插入排序，通用高效选快速排序，稳定排序选归并排序；Java 标准库对基本类型用双轴快排，对象用 TimSort。
2. 查找算法的核心是“有序”：无序用线性查找，有序用二分查找，高频读写用哈希查找，有序动态数据用树表查找。
3. 算法思想层面，分治（拆分子问题）、贪心（局部最优）、动态规划（重叠子问题+最优子结构）、回溯（试错+剪枝）是四大核心思路，需结合场景选择。
