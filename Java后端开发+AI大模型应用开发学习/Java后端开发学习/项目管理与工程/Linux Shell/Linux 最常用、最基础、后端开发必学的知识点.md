Linux 最常用、最基础、后端开发必学的知识点
--------------------------------------------------------------------------------------------------------------------------------------
一、Linux 是什么
Linux 是一款多用户、多任务、稳定安全的操作系统
服务器领域几乎全部使用 Linux
Java 后端开发必须掌握，因为项目部署、日志排查、服务器操作都要用
常见发行版：CentOS、Ubuntu、RedHat
--------------------------------------------------------------------------------------------------------------------------------------
二、Linux 目录结构
Linux 没有 C 盘 D 盘，一切都是文件和目录
/ 根目录，所有文件的起点
/bin 常用命令
/etc 系统配置文件
/home 普通用户的家目录
/root 管理员 root 的家目录
/var 日志、数据文件
/usr 安装的软件
/tmp 临时文件
/opt 第三方软件存放目录
--------------------------------------------------------------------------------------------------------------------------------------
三、文件管理常用命令
1. ls 查看目录下文件
ls -l 详细信息
ls -a 显示隐藏文件
2. cd 切换目录
cd / 进入根目录
cd ~ 进入家目录
cd .. 返回上一级
cd 目录名 进入对应目录
3. pwd 查看当前所在路径
4. mkdir 创建目录
mkdir test 创建文件夹
mkdir -p a/b/c 递归创建
5. rm 删除文件或目录
rm 文件 删除文件
rm -r 目录 删除目录
rm -rf 强制删除，谨慎使用
6. cp 复制
cp 源文件 目标位置
7. mv 移动或重命名
mv 原文件 新名字 重命名
mv 文件 目标路径 移动
8. touch 创建空文件
9. cat 查看文件全部内容
10. less 分页查看大文件
上下键翻页，q 退出
11. head 查看文件开头
head -n 10 文件 查看前10行
12. tail 查看文件结尾
tail -f 文件 实时刷新查看日志
--------------------------------------------------------------------------------------------------------------------------------------
四、文件权限
Linux 权限分三类：所有者、所属组、其他用户
权限分三种：读 r、写 w、执行 x
查看权限
ls -l 显示的第一位是文件类型，后面9位是权限
数字表示
r=4 w=2 x=1
7=4+2+1 读+写+执行
6=4+2 读+写
5=4+1 读+执行
修改权限
chmod 755 文件
修改所有者
chown 用户名:组名 文件
--------------------------------------------------------------------------------------------------------------------------------------
五、用户与用户组
useradd 用户名 创建用户
passwd 用户名 设置密码
su 切换用户
whoami 查看当前用户
groupadd 组名 创建组
id 查看用户信息
--------------------------------------------------------------------------------------------------------------------------------------
六、系统管理命令
ps 查看进程
ps -ef 查看所有进程
kill 杀死进程
kill -9 进程号 强制杀死
top 实时查看系统资源
df -h 查看磁盘使用情况
free -h 查看内存使用情况
ifconfig 查看网络信息
ip addr 也是查看网络
netstat -anp 查看端口占用
systemctl 服务管理
systemctl start 服务名 启动
systemctl stop 停止
systemctl restart 重启
systemctl enable 开机自启
--------------------------------------------------------------------------------------------------------------------------------------
七、查找与搜索
find 查找文件
find / -name 文件名
grep 在文件中搜索内容
grep 关键词 文件
管道符 |
把前一个命令结果传给后一个
ps -ef | grep java 查找java进程
--------------------------------------------------------------------------------------------------------------------------------------
八、压缩与解压
tar 命令最常用
tar -zcvf 压缩名.tar.gz 要压缩的文件
tar -zxvf 压缩包名 解压
--------------------------------------------------------------------------------------------------------------------------------------
九、Vim 编辑器使用
vim 文件名 进入编辑
三种模式
命令模式、输入模式、底行模式
i 进入编辑
esc 退回命令模式
:w 保存
:q 退出
:wq 保存退出
:q! 强制不保存退出

十、环境变量
配置文件
/etc/profile
~/.bashrc
生效命令
source 配置文件
查看环境变量
echo $PATH

十一、后台运行程序
后端常用，让程序在后台运行不退出
nohup java -jar xxx.jar &
运行后会把日志输出到 nohup.out

十二、Linux 常用技巧
1. Tab 键自动补全命令或文件名
2. 上下键查看历史命令
3. clear 清屏
4. Ctrl+C 终止当前命令
5. Ctrl+Z 挂起程序
6. ll 等于 ls -l（部分系统支持）
