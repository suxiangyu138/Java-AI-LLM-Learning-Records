Java 后端 + AI 大模型应用 · 必学技术全景图（校招+工作通用版）
 
按优先级 → 用途 → 必须学到什么程度给你排死，只学有用的，不碰玄学。
一、核心饭碗（必学满，面试 80% 来源）
1. Java 基础
集合、IO、并发、线程池、JVM、锁、反射
2. Spring 全家桶
Spring Boot、Spring MVC、Spring Cloud
3. MySQL
索引、事务、锁、SQL优化、主从
4. Redis
缓存、分布式锁、消息、持久化、集群
5. 算法与数据结构
链表、双指针、DP、滑动窗口、二叉树、图（你正在刷）
 
二、微服务 & 中间件（必学，决定你能不能进中大厂）
6. Nginx
7. RabbitMQ / RocketMQ
8. Kafka（AI 方向重点）
9. Elasticsearch
10. Nacos / Eureka（注册&配置中心）
11. Sentinel / Hystrix（限流熔断）
 
三、云原生 & 部署运维（你问的同类技术，加分王）
12. Docker（必须精通）
13. Jenkins / GitHub Actions（CI/CD）
14. K8s（基础必学，不用太深）
15. Prometheus + Grafana（监控）
16. SkyWalking / Zipkin（链路追踪）
17. ELK/EFK（日志收集）
18. MinIO（对象存储，AI 常用）
 
四、AI 大模型配套（你独有的优势，拉开差距）
19. 大模型 API 调用（OpenAI、文心一言、通义千问）
20. RAG 知识库构建
21. 向量数据库（Chroma、Milvus、FAISS）
22. LangChain / Coze 简单使用
23. AI 服务容器化部署
 
五、学习路线时间表（你每天 6 小时版）
大二下～大三上
1～10 项打满 → 能做项目、能应付笔试面试
大三上～大三下
11～18 项学完 → 具备云原生+部署+监控能力，简历直接起飞
大四前
19～23 项掌握 → 成为稀缺的 Java后端 + AI应用 双栈人才
