一、AI Coding 到底是什么
不是单纯“帮你写代码”
核心三件事：
1. 自然语言转代码（一句话生成完整功能）
2. 代码补全、纠错、重构、优化
3. 解释代码、查Bug、写注释、写测试用例、写文档
主流工具：
- 云端：GPT-4o、豆包、通义灵码、Kimi
- 本地IDE插件：GitHub Copilot、通义灵码、CodeGeeX
- 客户端：Cursor、IDE内置AI（IDEA/VSCode）
 
二、新手立刻能用的 6 个核心能力
1. 一句话生成完整代码
模板万能句式：
plaintext
请用 Java / Python 实现：xxx功能
要求：
1. 企业级规范
2. 结构清晰
3. 附带简单测试用例
 
例子：
用Java写一个Redis工具类，实现增删改查
2. 代码补全 & 联想
写一半函数、循环、判断，AI自动补全剩余逻辑
适合：循环嵌套、集合处理、IO流、正则、复杂算法
3. Bug 定位 + 修复
粘贴报错堆栈 + 出错代码：
帮我分析这段代码报错原因，给出修改后完整代码
4. 代码重构 / 降级优化
- 烂代码 → 规范化、分层、解耦
- 冗余代码 → 精简、抽取工具方法
- 同步代码 → 改异步
- 普通写法 → 设计模式写法
5. 跨语言转换
Java ↔ Python ↔ Go ↔ SQL 一键互转
对你Java后端+Python数据分析极度实用
6. 生成配置/脚本
Maven/Gradle配置、Dockerfile、Nginx配置、Bat脚本、Linux命令

六、最重要：AI Coding 正确使用原则（防止废人）
✅ 正确用法
1. 自己先想思路，让AI写实现
2. AI代码必须逐行看懂、校验
3. 复杂业务自己设计架构，AI只写细节
4. 用AI学不会的知识点，反向提问理解原理
❌ 错误用法
1. 完全不动脑，直接复制粘贴上线
2. 不问原理，只会抄代码
3. 复杂业务全靠AI瞎写，架构混乱
