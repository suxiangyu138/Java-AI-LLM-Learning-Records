# 大模型基础核心知识点：语言模型基础

## 一、语言模型（LM）核心定义

语言模型是一种**基于概率统计或深度学习**，能够理解、生成人类语言，并判断语言序列合理性的模型。核心目标是：给定一段文本（词/字序列），计算该序列出现的概率，或基于前文预测下一个词/字，本质是“学习语言的规律”。

简单来说，语言模型就是“懂语言的计算器”，能判断“我吃饭”是合理表达，“饭吃我”是不合理表达，也能根据“今天天气很好，我打算去”，预测下一个词可能是“公园”“散步”等。

## 二、核心核心分类（按技术路线）

### 1. 传统语言模型（统计型）

基于统计方法，核心是“计数统计”，通过计算词与词之间的共现频率来判断序列概率，代表模型有N-gram模型。

关键特点：结构简单、训练速度快，但存在“数据稀疏”问题（罕见词组合无法统计），只能捕捉短距离语言依赖，无法理解上下文语义（比如无法区分“苹果手机”和“苹果水果”）。

### 2. 现代语言模型（深度学习型）

基于神经网络，核心是“语义建模”，能捕捉长距离语言依赖和上下文语义，是当前大模型（如GPT、LLaMA）的基础，分为两大核心方向：

- 循环神经网络（RNN）类：包括RNN、LSTM、GRU，通过“循环结构”记忆前文信息，解决了N-gram的短距离依赖问题，但训练速度慢，易出现“梯度消失/爆炸”，难以处理超长文本。
- Transformer类：2017年提出，核心是“自注意力机制”，能同时关注文本中所有词的关联（无论距离远近），是大模型的核心架构。优势是并行训练效率高、能捕捉长上下文，目前主流大模型（GPT系列、BERT）均基于Transformer构建。

## 三、核心核心概念（必掌握）

### 1. 自注意力机制（Transformer核心）

核心作用：让模型在处理每个词时，都能“关注”到文本中其他相关词，从而理解上下文语义。比如处理“他喜欢打篮球，每天都玩它”，模型能通过自注意力，判断“它”指代“篮球”。

简单理解：相当于阅读时，眼睛会同时扫到与当前句子相关的其他内容，形成完整的语义关联，而非逐字逐句孤立理解。

### 2. 预训练与微调（大模型训练核心流程）

预训练（Pre-training）：用海量无标注文本（如网页、书籍）训练模型，让模型学习通用的语言规律（比如语法、语义、常识），相当于“打基础”，得到基础语言模型（如GPT-3的预训练模型）。

微调（Fine-tuning）：用特定任务的标注数据（如情感分析、问答），在预训练模型基础上微调，让模型适配具体任务，相当于“专项训练”（比如将通用预训练模型微调为客服问答模型）。

### 3. 生成式 vs 判别式语言模型

生成式模型（如GPT系列）：核心是“生成文本”，能基于前文预测下一个词，连续生成连贯的句子，可用于写文案、对话、翻译等场景，本质是“概率生成序列”。

判别式模型（如BERT系列）：核心是“判断/分类”，不生成文本，而是对输入文本进行判断（如判断句子情感、判断两个句子是否语义一致），本质是“对语言序列做分类决策”。

## 四、基础核心应用场景

语言模型是所有NLP（自然语言处理）任务的基础，核心应用包括：

- 文本生成：文案、诗歌、代码、对话（生成式模型核心场景）；
- 文本理解：情感分析、文本分类、命名实体识别（判别式模型核心场景）；
- 语言转换：翻译、文本摘要、语气转换；
- 交互辅助：智能问答、语音转文字（需结合语音模型）。

## 五、关键总结（快速记忆）

1. 核心定位：语言模型 = 学习语言规律，计算序列概率/预测下一个词；
2. 技术迭代：统计型（N-gram）→ 深度学习型（RNN→Transformer）；
3. 大模型基础：Transformer+自注意力+预训练-微调流程；
4. 核心区分：生成式（能写）、判别式（能判）。
