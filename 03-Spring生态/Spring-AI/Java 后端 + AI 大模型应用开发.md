 Java 后端 + AI 大模型应用开发
一、Java 后端基本功（必须稳）
这是你的立身之本，AI 只是加分项，后端不行直接 pass。
1. Java 基础
    - 集合、多线程、JVM、异常、IO
    - 反射、注解、泛型
2. 框架与生态
    - Spring Boot / Spring MVC
    - Spring Cloud（微服务基础）
    - MyBatis / MyBatis-Plus
3. 数据库能力
    - MySQL 索引、事务、锁、执行计划
    - 常见 SQL 优化、分库分表思想
4. 中间件
    - Redis（缓存、分布式锁）
    - MQ（RabbitMQ/RocketMQ）
    - 简单了解 Elasticsearch
    展示方式：
    写一个完整后端项目（管理系统 / 商城 / 博客），突出：
    - RESTful 接口
    - 全局异常处理
    - JWT 登录
    - AOP、线程池、Redis 缓存
    二、算法与数据结构（计算机科班底线）
    后端 + AI 岗都非常看重。
    重点准备：
    - 数组、链表、栈队列、二叉树
    - 动态规划（LCS、背包、股票系列你刚刷的那些）
    - 二分、双指针、BFS/DFS
    - 贪心、模拟
    展示方式：
    - LeetCode 200+
    - 算法题能讲思路 + 复杂度
    - 能手写经典 DP / 双指针
    三、AI 大模型应用能力（你的差异化优势）
    这是你比纯后端多的竞争力。
    1. 大模型基础认知
    - 懂 LLM 是什么、RAG 是什么、Agent 是什么
    - 懂提示词工程（Prompt Engineering）
    - 懂文本向量、Embedding、相似度检索
    2. 能落地的 AI 项目能力（面试官最爱）
    - 基于 Java 调用大模型 API（通义千问、百炼、DeepSeek）
    - 实现 RAG 检索增强生成（企业知识库问答）
    - 做简单 AI Agent（工具调用、流程编排）
    - 文本分类、抽取、总结、对话机器人
    3. 向量数据库
    了解：
    - Milvus / FAISS / Chroma（一个就行）
    - 知道怎么存向量、做相似度检索
    四、项目经历（最关键：必须是 Java + AI 结合）
    你需要至少 1 个“Java后端 + AI”的完整项目，比如：
    1. AI 智能问答系统
    - Java 后端
    - MySQL 存储业务
    - Redis 缓存
    - 对接大模型 API
    - RAG 知识库（PDF/文档导入）
    - 向量数据库检索
    2. AI 面试辅助 / 简历优化助手
    3. AI 客服机器人
    4. AI 数据分析 + 报表生成（ChatBI）
    项目里要写清楚：
    - 你负责后端接口
    - 对接大模型
    - 实现 RAG
    - 做了接口优化、并发控制、异常处理
    五、工程化能力（体现你“能干活”）
    - Git 使用规范
    - Maven / Gradle
    - Linux 基础部署
    - Docker 简单使用
    - 接口文档（Swagger/Knife4j）
    - 单元测试
    这些能让面试官觉得：
    “这学生招进来能直接写业务，不用从头教。”
    六、软实力（校招非常加分）
    - 学习能力（自学 AI、刷算法、做项目）
    - 问题拆解能力
    - 表达清晰，能讲清楚项目架构
    - 有明确职业规划（Java 后端 + AI 应用）
 
极简总结（你背这个就行）
找 Java 后端 + AI 岗，你只需要展示 6 点：
1. Java 后端扎实（框架 + 数据库 + 中间件）
2. 算法过关（200+ LeetCode）
3. 会调用大模型 API
4. 懂 RAG、向量库、提示词
5. 有 Java + AI 结合的真实项目
6. 工程规范、能落地、能写业务
