课程整体解读
技术栈
1. 后端框架：Node.js + Koa2
2. 数据库：MongoDB + Mongoose ODM
3. 认证方案：JWT
4. 部署工具：Git、Nginx、PM2
5. 规范标准：RESTful API 完整设计规范
项目实战目标
从零搭建仿知乎后端服务，完整覆盖：用户、资料、关注、话题、问题、答案、多级评论、图片上传、点赞收藏、分页检索等社区类产品全部业务接口，同时掌握生产级项目的参数校验、全局异常处理、权限中间件、服务器整套部署流程。
学习价值
1. 吃透REST架构六大约束，规范接口设计，面试高频考点
2. 掌握Koa洋葱模型、自定义中间件开发，理解Node.js异步服务核心
3. 学会MongoDB非关系型数据库建模、一对多/多对多关联设计
4. 掌握JWT无状态登录、权限鉴权工业级实现方案
5. 完整学会Linux服务器后端项目上线全流程，可直接用于个人项目/简历项目
