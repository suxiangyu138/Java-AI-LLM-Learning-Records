## 1. 环境准备

| 组件 | 版本要求 | 说明 |
|------|----------|------|
| JDK | 8+ | 运行需要 JVM |
| OS | Linux/macOS | 生产强烈建议 Linux |
| 内存 | Broker ≥ 4GB | 堆内存 + 直接内存 + OS 缓存 |
| 磁盘 | SSD 推荐 | CommitLog 顺序写 |
| Maven | 3.5+ | 编译控制台时需要 |

**下载 RocketMQ：**

```bash
# 下载 4.9.x（稳定版）
wget https://dlcdn.apache.org/rocketmq/4.9.8/rocketmq-all-4.9.8-bin-release.zip
unzip rocketmq-all-4.9.8-bin-release.zip
cd rocketmq-all-4.9.8-bin-release

# 或 5.x
wget https://dlcdn.apache.org/rocketmq/5.3.0/rocketmq-all-5.3.0-bin-release.zip
```

## 2. 单机部署

### 2.1 启动 NameServer

```bash
# 修改 JVM 参数（可选）
# 编辑 bin/runserver.sh
JAVA_OPT="${JAVA_OPT} -server -Xms512m -Xmx512m -Xmn256m"

# 启动 NameServer
nohup sh bin/mqnamesrv &
tail -f ~/logs/rocketmqlogs/namesrv.log
# 看到 "The Name Server boot success." 表示成功
```

### 2.2 启动 Broker

```bash
# 修改 Broker JVM 参数（可选）
# 编辑 bin/runbroker.sh
JAVA_OPT="${JAVA_OPT} -server -Xms1g -Xmx1g -Xmn512m"

# 修改 Broker 配置 conf/broker.conf
brokerClusterName=DefaultCluster
brokerName=broker-a
brokerId=0                                    # 0=Master, >0=Slave
deleteWhen=04
fileReservedTime=48                           # 文件保留 48 小时
brokerRole=ASYNC_MASTER                       # ASYNC_MASTER / SYNC_MASTER / SLAVE
flushDiskType=ASYNC_FLUSH                     # ASYNC_FLUSH / SYNC_FLUSH
namesrvAddr=localhost:9876
autoCreateTopicEnable=true

# 启动 Broker
nohup sh bin/mqbroker -c conf/broker.conf &
tail -f ~/logs/rocketmqlogs/broker.log
# 看到 "boot success." 表示成功
```

### 2.3 验证

```bash
# 测试发送/消费
export NAMESRV_ADDR=localhost:9876

# 生产者测试
sh bin/tools.sh org.apache.rocketmq.example.quickstart.Producer

# 消费者测试
sh bin/tools.sh org.apache.rocketmq.example.quickstart.Consumer
```

## 3. 集群部署（双主双从）

### 3.1 拓扑规划

```text
双主双从（异步复制）— 最经典的生产配置

┌─────────────────────────────────────────────────┐
│  NameServer (部署 2~3 台)                        │
│  node1:9876, node2:9876                         │
├─────────────────────────────────────────────────┤
│  Broker-a (Master)  │  Broker-a-s (Slave)       │
│  node1, brokerId=0  │  node2, brokerId=1        │
│  brokerRole=        │  brokerRole=SLAVE         │
│    ASYNC_MASTER     │                           │
├─────────────────────────────────────────────────┤
│  Broker-b (Master)  │  Broker-b-s (Slave)       │
│  node2, brokerId=0  │  node1, brokerId=1        │
│  brokerRole=        │  brokerRole=SLAVE         │
│    ASYNC_MASTER     │                           │
└─────────────────────────────────────────────────┘
```

### 3.2 Broker 配置

**Broker-a Master (node1)** — `conf/2m-2s-async/broker-a.properties`：

```properties
brokerClusterName=DefaultCluster
brokerName=broker-a
brokerId=0
namesrvAddr=node1:9876;node2:9876
listenPort=10911
storePathRootDir=/data/rocketmq/store
storePathCommitLog=/data/rocketmq/store/commitlog
brokerRole=ASYNC_MASTER
flushDiskType=ASYNC_FLUSH
```

**Broker-a Slave (node2)** — `conf/2m-2s-async/broker-a-s.properties`：

```properties
brokerClusterName=DefaultCluster
brokerName=broker-a
brokerId=1
namesrvAddr=node1:9876;node2:9876
listenPort=10911
storePathRootDir=/data/rocketmq/store
storePathCommitLog=/data/rocketmq/store/commitlog
brokerRole=SLAVE
flushDiskType=ASYNC_FLUSH
```

### 3.3 Broker 角色配置

| 参数 | 可选值 | 说明 |
|------|--------|------|
| `brokerRole` | ASYNC_MASTER | 异步复制 Master |
| | SYNC_MASTER | 同步复制 Master |
| | SLAVE | 从节点 |
| `flushDiskType` | ASYNC_FLUSH | 异步刷盘（性能优先） |
| | SYNC_FLUSH | 同步刷盘（可靠性优先） |
| `brokerId` | 0 | Master |
| | ≥1 | Slave |

## 4. Docker-Compose 部署

```yaml
# docker-compose.yml — 单节点 RocketMQ 4.x
version: '3.8'
services:
  namesrv:
    image: apache/rocketmq:4.9.8
    container_name: rmq-namesrv
    ports:
      - "9876:9876"
    command: sh mqnamesrv
    environment:
      JAVA_OPT_EXT: "-server -Xms512m -Xmx512m"

  broker:
    image: apache/rocketmq:4.9.8
    container_name: rmq-broker
    ports:
      - "10909:10909"
      - "10911:10911"
    command: sh mqbroker -n namesrv:9876
    environment:
      JAVA_OPT_EXT: "-server -Xms1g -Xmx1g"
    depends_on:
      - namesrv

  dashboard:
    image: apacherocketmq/rocketmq-dashboard:latest
    container_name: rmq-dashboard
    ports:
      - "8080:8080"
    environment:
      JAVA_OPTS: "-Drocketmq.namesrv.addr=namesrv:9876"
    depends_on:
      - namesrv
```

```bash
docker-compose up -d
# 控制台：http://localhost:8080
```

## 5. DLedger 高可用部署

> DLedger 是 RocketMQ 4.5+ 引入的基于 Raft 的自动主从切换方案，解决传统主从手动切换问题。

```properties
# DLedger Broker 配置
brokerClusterName=DefaultCluster
brokerName=RaftNode00
listenPort=30911
namesrvAddr=node1:9876;node2:9876;node3:9876

# DLedger 相关(替代 brokerRole)
enableDLegerCommitLog=true
dLegerGroup=RaftNode00
dLegerPeers=n0-node1:40911;n1-node2:40912;n2-node3:40913
dLegerSelfId=n0                                    # 当前节点在 peers 中的 ID
storePathRootDir=/data/rocketmq/store
```

```text
DLedger vs 传统主从：

┌──────────────────┬──────────────┬──────────────┐
│                  │  传统主从     │   DLedger    │
├──────────────────┼──────────────┼──────────────┤
│  选主             │  手动/脚本   │  自动(Raft)  │
│  切换时间         │  分钟级       │  秒级        │
│  数据一致性       │  Async/Sync  │  Raft 强一致  │
│  部署复杂度       │  中等         │  中等        │
│  最小节点数       │  2           │  3           │
└──────────────────┴──────────────┴──────────────┘
```

## 6. 5.x Controller 模式

> RocketMQ 5.x 引入 Controller 模式 — 独立的 Controller 进程管理 Broker 主备切换，是 DLedger 的升级替代。

```text
Controller 模式架构：

┌────────────────────────────────────────────────────┐
│                 Controller 集群（Raft）              │
│   Controller-1     Controller-2     Controller-3   │
│        ↓ 管理 Broker 主备切换                        │
├────────────────────────────────────────────────────┤
│           Broker 集群（纯存储，无选主逻辑）            │
│   Broker-A1(M)   Broker-A2(S)                      │
│   Broker-B1(M)   Broker-B2(S)                      │
└────────────────────────────────────────────────────┘

优势：
  ✅ 选主逻辑与存储分离
  ✅ 支持更多 Broker（DLedger 有扩展瓶颈）
  ✅ 更快的故障切换
```

```bash
# 启动 Controller
nohup sh bin/mqcontroller -c conf/controller/cluster-3n-independent/controller-01.conf &
```

## 7. 控制台安装

### 7.1 RocketMQ Dashboard

```bash
# 克隆源码编译
git clone https://github.com/apache/rocketmq-dashboard.git
cd rocketmq-dashboard
mvn clean package -DskipTests

# 启动（指定 NameServer 地址）
java -jar target/rocketmq-dashboard-2.0.1.jar \
  --rocketmq.namesrv.addr=localhost:9876

# 访问 http://localhost:8080
```

### 7.2 Dashboard 功能

| 模块 | 功能 |
|------|------|
| **OPS** | NameServer 列表、Broker 状态 |
| **Topic** | 创建/删除/查看 Topic、消息查询 |
| **Consumer** | 消费组管理、消费进度、重置 Offset |
| **Producer** | 生产者连接信息 |
| **Message** | 按 Key/MessageId/Tag 查询消息 |

## 8. 命令行工具实战

### 8.1 mqadmin 工具

```bash
# 设置 NameServer 地址环境变量
export NAMESRV_ADDR=localhost:9876

# ===== Topic 管理 =====
# 创建 Topic
sh bin/mqadmin updateTopic -n localhost:9876 -t MyTopic -c DefaultCluster \
  -a +message.type=NORMAL

# 查看 Topic 列表
sh bin/mqadmin topicList -n localhost:9876

# 查看 Topic 详情
sh bin/mqadmin topicStatus -n localhost:9876 -t MyTopic

# 删除 Topic
sh bin/mqadmin deleteTopic -n localhost:9876 -t MyTopic

# ===== 集群管理 =====
# 查看集群
sh bin/mqadmin clusterList -n localhost:9876

# 查看 Broker 状态
sh bin/mqadmin brokerStatus -n localhost:9876 -b broker-a

# ===== 消费组管理 =====
# 查看消费组
sh bin/mqadmin consumerProgress -n localhost:9876 -g my-group

# 重置消费位点
sh bin/mqadmin resetOffsetByTime -n localhost:9876 -g my-group -t MyTopic -s 0
```

### 8.2 消息发送/消费测试

```bash
# 生产者（发送消息）
sh bin/tools.sh org.apache.rocketmq.example.quickstart.Producer

# 消费者
sh bin/tools.sh org.apache.rocketmq.example.quickstart.Consumer
```

## 9. 常见故障排查

### 9.1 Broker 启动失败

```bash
# 1. 检查 NameServer 是否已启动
netstat -tlnp | grep 9876

# 2. 检查日志
tail -f ~/logs/rocketmqlogs/broker.log

# 常见错误：
# "connect to namesrv failed" → NameServer 未启动或地址错误
# "No route info of this topic" → autoCreateTopicEnable=false 且 Topic 未创建
# "Disk full" → 磁盘空间不足
```

### 9.2 发送消息失败

```bash
# 检查 Topic 路由
sh bin/mqadmin topicRoute -n localhost:9876 -t MyTopic

# 检查 Broker 是否可写
# perm=6 表示可读可写，perm=4 表示只读
sh bin/mqadmin brokerStatus -n localhost:9876 -b <brokerName>
```

### 9.3 消费不到消息

```bash
# 检查消费组积压
sh bin/mqadmin consumerProgress -n localhost:9876 -g my-group

# 注意：group 名不要用 "DEFAULT_CONSUMER"（系统内置）
# group 名格式：建议业务模块名
```

### 9.4 磁盘空间不足

```bash
# 检查磁盘
df -h

# 紧急：修改保留时间
# conf/broker.conf
fileReservedTime=24  # 改为只保留 24 小时（单位：小时）

# 或手动清理（慎用！）
rm -rf /data/rocketmq/store/commitlog/*.bak
```
