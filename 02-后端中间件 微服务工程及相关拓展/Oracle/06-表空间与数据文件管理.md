## 1. 表空间管理

```sql
-- 创建表空间（自动扩展）
CREATE TABLESPACE app_data
    DATAFILE '/u01/oradata/app_data01.dbf' SIZE 10G
    AUTOEXTEND ON NEXT 1G MAXSIZE 50G
    EXTENT MANAGEMENT LOCAL AUTOALLOCATE
    SEGMENT SPACE MANAGEMENT AUTO;

-- 添加数据文件（在线扩容！）
ALTER TABLESPACE app_data
    ADD DATAFILE '/u01/oradata/app_data02.dbf' SIZE 10G;

-- 查看表空间使用率
SELECT tablespace_name,
       ROUND(SUM(bytes)/1024/1024/1024, 2) AS total_gb,
       ROUND(SUM(bytes - NVL(free_bytes,0))/1024/1024/1024, 2) AS used_gb,
       ROUND(SUM(bytes - NVL(free_bytes,0))/SUM(bytes)*100, 1) AS pct_used
FROM (SELECT tablespace_name, SUM(bytes) bytes FROM dba_data_files GROUP BY tablespace_name) df
LEFT JOIN (SELECT tablespace_name, SUM(bytes) free_bytes FROM dba_free_space GROUP BY tablespace_name) fs
USING (tablespace_name)
GROUP BY tablespace_name;
```

## 2. UNDO 与 TEMP 表空间

```text
UNDO 表空间：
  → 保存修改前的数据（用于回滚 + 一致性读）
  → 满了 → 无法回滚 → ORA-01555 快照过旧
  → 建议大小 = 最大事务 × 2

TEMP 表空间：
  → 排序/分组/Hash Join 的临时空间
  → 满了 → ORA-01652 无法扩展 TEMP 段
  → 建议大小 = 最大并发 × 单次排序量
```

```sql
-- UNDO 配置
SHOW PARAMETER undo;
ALTER SYSTEM SET undo_retention = 900;  -- UNDO 保留 15 分钟

-- TEMP 扩展
ALTER TABLESPACE temp ADD TEMPFILE '/u01/oradata/temp02.dbf' SIZE 5G;

-- 查看 TEMP 使用
SELECT tablespace_name,
       ROUND(SUM(bytes_used)/1024/1024/1024, 2) AS used_gb,
       ROUND(SUM(bytes_free)/1024/1024/1024, 2) AS free_gb
FROM v$temp_space_header GROUP BY tablespace_name;
```

## 3. 日常维护脚本

```sql
-- 1. 检查所有表空间使用率
SELECT tablespace_name,
       ROUND(used_percent, 1) AS pct
FROM dba_tablespace_usage_metrics
WHERE used_percent > 80;

-- 2. 查看数据文件
SELECT file_name, tablespace_name,
       ROUND(bytes/1024/1024/1024, 2) AS gb,
       autoextensible, maxbytes
FROM dba_data_files;

-- 3. 收缩表空间
ALTER TABLESPACE app_data SHRINK SPACE KEEP 10G;

-- 4. 移动数据文件（在线！Oracle 12c+）
ALTER DATABASE MOVE DATAFILE '/old/path/data01.dbf' TO '/new/path/data01.dbf';

-- 5. 重新分配表空间（整理碎片）
ALTER TABLE large_table MOVE TABLESPACE app_data;
ALTER INDEX idx_large REBUILD TABLESPACE app_idx;
```

## 核心要点回顾

- 表空间 = 逻辑容器，数据文件 = 物理存储
- `AUTOEXTEND ON` 防止空间耗尽（但设上限防止磁盘爆满）
- UNDO 不足 → ORA-01555（经典错误）
- TEMP 不足 → ORA-01652（排序/Join 失败）
- Oracle 12c+ 数据文件在线移动（不停机！）
