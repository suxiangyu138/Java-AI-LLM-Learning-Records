## 1. 面试题全景 TOP 20

### 语言与 JVM（01 篇）

**Q1: HashMap 底层原理？**
```
数组+链表+红黑树；put 流程（hash→定位→插入→树化）；
扩容（hash&oldCap 重定位）；JDK7 头插死循环 vs JDK8 尾插。
```

**Q2: 线程池参数与拒绝策略？**
```
七参数（核心/最大/存活/队列/工厂/策略）；
四策略（Abort/CallerRuns/Discard/Oldest）；
IO 密集 ≈ 2 倍核数。
```

**Q3: JVM 内存结构与 OOM？**
```
五区（堆/方法区/栈/本地栈/PC）；
OOM 四类（堆/栈/元空间/直接内存）；
HeapDump + MAT 排查。
```

### Spring（02 篇）

**Q4: IoC 和 AOP 原理？**
```
IoC：容器管理对象 + DI；Bean 生命周期 + 三级缓存；
AOP：动态代理（JDK/CGLIB）+ 切面五要素；
同类调用失效是经典坑。
```

**Q5: Spring Boot 自动配置原理？**
```
@EnableAutoConfiguration → imports 清单 → 条件装配；
Starter = 依赖 + 自动配置；@ConditionalOnMissingBean 允许覆盖。
```

### 数据与缓存（03 篇）

**Q6: MySQL 索引为什么用 B+Tree？**
```
非叶子只存 key（树矮）+ 叶子链表（范围查询）；
3 层支撑千万级；聚簇/二级/覆盖/最左前缀。
```

**Q7: MVCC 怎么实现可重复读？**
```
隐藏列（事务 ID/回滚指针）+ undo 版本链 +
ReadView（RR 首次生成复用/RC 每次新生成）。
```

**Q8: 缓存穿透/击穿/雪崩？**
```
穿透（布隆/空值）、击穿（互斥/逻辑过期）、
雪崩（随机过期/集群）。
```

### 分布式（05 篇）

**Q9: 分布式锁怎么实现？**
```
Redis setnx + 过期 + Lua 释放 + Redisson 看门狗；
高一致 ZooKeeper；三要点（原子加/原子放/续期）。
```

**Q10: 分布式事务方案？**
```
强一致：TCC/2PC；最终一致：可靠消息/本地表/Seata AT；
大多数业务最终一致足够。
```

**Q11: 消息不丢失？**
```
生产 Confirm + 服务端持久化 + 消费手动 ACK；
重复消费靠幂等；顺序靠单队列/分区。
```

### 性能与稳定性（07 篇）

**Q12: 高并发优化思路？**
```
五层：前端（CDN）→ 网络（HTTP2）→ 应用（缓存/异步）→
数据（索引/读写分离）→ 架构（集群/限流）。
```

**Q13: 限流熔断降级？**
```
限流（令牌桶）防超载、熔断（三态）防雪崩、
降级（缓存/默认）保核心；Sentinel 一体。
```

**Q14: 线上故障排查流程？**
```
告警 → 指标（CPU/连接/GC）→ 日志链路（traceId）→
处置（回滚/限流）；慢 SQL/死循环/泄漏分类定位。
```

### 安全与工程（06/08 篇）

**Q15: 认证授权方案？**
```
Session（可失效）/JWT（无状态）/OAuth2（授权）；
RBAC 授权模型；Spring Security + JWT 标准组合。
```

**Q16: SQL 注入/XSS/CSRF 防御？**
```
注入：参数化；XSS：转义 + HttpOnly + CSP；
CSRF：SameSite + Token；服务端校验不信任前端。
```

**Q17: CI/CD 流程设计？**
```
每次提交 CI（编译/测试/扫描 5 分钟反馈）→
质量门禁 → CD（蓝绿/金丝雀 + 自动回滚）。
```

## 2. 系统设计题

### 2.1 经典设计题

| 题目 | 考察点 | 关键答案 |
|------|--------|---------|
| 设计秒杀系统 | 削峰/防超卖 | 缓存预热 + MQ 削峰 + Redis 原子扣减 |
| 设计短链系统 | 编码/存储 | 62 进制 ID + 读写分离 |
| 设计热搜榜 | 有序/实时 | ZSet + 定时聚合 |
| 设计分布式 ID | 全局唯一 | 雪花算法 |
| 设计消息推送 | 长连接/推拉 | WebSocket + 消息队列 |

### 2.2 设计题方法论

```
系统设计五步：
  ① 需求澄清（规模/一致性/延迟）
  ② 估算（QPS/存储）
  ③ 架构草图（组件图）
  ④ 核心模块（缓存/消息/分片）
  ⑤ 瓶颈与优化

⚠️ 面试必答：
"设计题五步——澄清 → 估算 → 架构 →
 核心 → 优化；
 '先说规模再谈方案'是第一原则。"
```

## 3. 学习路线推荐

### 路线 A：新人入门（3-6 个月）

```
Java 基础（01）→ Spring Boot（深度体系）
→ MySQL/Redis（数据）→ 工程化（Maven/Git）
→ 实战项目 → 面试题（09）
```

### 路线 B：进阶提升（1-2 年）

```
并发/JVM 深挖 → 分布式（05）→ 消息中间件（04）
→ 性能优化（07）→ 微服务实战 → 源码阅读
```

### 路线 C：架构师方向（3 年+）

```
系统设计题 → 企业级标准体系 → 高可用架构
→ 云原生（K8s）→ AI 集成（Java AI 体系）
→ 技术选型与团队
```
