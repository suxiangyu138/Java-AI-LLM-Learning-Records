## 1. 版本与依赖管理

```xml
<!-- ⭐ 使用 BOM 统一版本，子模块不写版本号 -->
<dependencyManagement>
    <dependencies>
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-dependencies</artifactId>
            <version>3.2.0</version>
            <type>pom</type>
            <scope>import</scope>
        </dependency>
        <dependency>
            <groupId>org.springframework.cloud</groupId>
            <artifactId>spring-cloud-dependencies</artifactId>
            <version>2023.0.0</version>
            <type>pom</type>
            <scope>import</scope>
        </dependency>
        <dependency>
            <groupId>com.alibaba.cloud</groupId>
            <artifactId>spring-cloud-alibaba-dependencies</artifactId>
            <version>2023.0.1.0</version>
            <type>pom</type>
            <scope>import</scope>
        </dependency>
    </dependencies>
</dependencyManagement>
```

> ⚠️ **关键原则**：Spring Boot / Cloud / Alibaba 版本必须对应！混用版本是生产故障的头号根源。

## 2. 统一异常处理

```java
// ⭐ 定义全局统一返回格式
@Data
@AllArgsConstructor
public class Result<T> {
    private int code;
    private String msg;
    private T data;

    public static <T> Result<T> ok(T data) { return new Result<>(200, "success", data); }
    public static <T> Result<T> fail(int code, String msg) { return new Result<>(code, msg, null); }
}

// ⭐ 全局异常拦截
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(BizException.class)
    public Result<?> handleBiz(BizException e) {
        return Result.fail(e.getCode(), e.getMessage());
    }

    @ExceptionHandler(FeignException.class)
    public Result<?> handleFeign(FeignException e) {
        log.error("Feign 调用失败: {}", e.getMessage());
        return Result.fail(500, "服务调用失败");
    }

    @ExceptionHandler(Exception.class)
    public Result<?> handleUnknown(Exception e) {
        log.error("未知异常", e);
        return Result.fail(500, "服务器内部错误");
    }
}
```

## 3. 优雅上下线

```yaml
server:
  shutdown: graceful              # ⭐ 优雅关闭

spring:
  lifecycle:
    timeout-per-shutdown-phase: 30s
  cloud:
    nacos:
      discovery:
        # 下线时立即注销（K8s preStop 也适用）
        ephemeral: true
```

```java
// ⭐ 应用关闭前注销服务
@Component
public class GracefulShutdown implements ApplicationListener<ContextClosedEvent> {
    @Override
    public void onApplicationEvent(ContextClosedEvent event) {
        log.info("正在下线，等待请求处理完成...");
        // Spring 会自动等待请求处理完毕（server.shutdown=graceful）
    }
}
```

```yaml
# K8s 优雅下线
spec:
  terminationGracePeriodSeconds: 60
  containers:
    lifecycle:
      preStop:
        exec:
          command: ["/bin/sh","-c","sleep 15"]  # 等待流量排干
```

## 4. 全局唯一 TraceId

```java
// Feign 拦截器透传 TraceId
@Component
public class TraceRequestInterceptor implements RequestInterceptor {
    @Override
    public void apply(RequestTemplate template) {
        String traceId = MDC.get("traceId");
        if (traceId == null) {
            traceId = UUID.randomUUID().toString().replace("-", "");
            MDC.put("traceId", traceId);
        }
        template.header("X-Trace-Id", traceId);
    }
}

// Gateway 全局过滤器生成 TraceId
@Component
public class TraceIdFilter implements GlobalFilter, Ordered {
    @Override
    public Mono<Void> filter(ServerWebExchange exchange, GatewayFilterChain chain) {
        String traceId = exchange.getRequest().getHeaders()
            .getFirst("X-Trace-Id");
        if (traceId == null) traceId = IdUtil.fastSimpleUUID();

        exchange.getResponse().getHeaders().add("X-Trace-Id", traceId);
        MDC.put("traceId", traceId);

        return chain.filter(exchange);
    }
}
```

## 5. 性能优化 Checklist

| 优化项 | 配置/做法 | 效果 |
|--------|----------|------|
| Feign 连接池 | `feign.httpclient.enabled=true` (Apache HttpClient) | 连接复用 |
| Feign 压缩 | `feign.compression.request.enabled=true` | 减少传输量 |
| 序列化 | 用 Protobuf 替代 JSON | 体积小 5×、速度快 3× |
| 数据库连接池 | HikariCP max=50, idle-timeout=30s | 连接复用 |
| Nacos 缓存 | 本地文件缓存兜底 | 注册中心挂了服务还能调 |
| Sentinel 规则 | 持久化到 Nacos | 重启不丢失 |
| 日志级别 | 生产 INFO，开发 DEBUG | 减少 IO |

```yaml
# Feign 使用 Apache HttpClient 连接池
spring:
  cloud:
    openfeign:
      httpclient:
        hc5:
          enabled: true
        max-connections: 200
        max-connections-per-route: 50
```

## 6. 生产 Checklist

| 分类 | 检查项 | 说明 |
|------|--------|------|
| **版本** | Boot/Cloud/Alibaba 版本对应 | 大版本不混用 |
| **注册** | Nacos 集群 + MySQL | 单机模式仅开发用 |
| **配置** | 敏感信息加密（Jasypt） | 数据库密码不入 Git |
| **容错** | Sentinel 规则持久化 | 规则存 Nacos/配置中心 |
| **熔断** | 所有 Feign 接口配 fallback | 下游挂了有兜底 |
| **网关** | 鉴权 + 限流 + CORS | 统一在网关层处理 |
| **追踪** | TraceId 全链路 + Feign 透传 | 排查问题不瞎猜 |
| **日志** | JSON 格式 + 含 TraceId | ELK 索引更方便 |
| **健康** | /actuator/health 可探活 | K8s liveness/readiness |
| **优雅** | graceful shutdown + preStop | 0 流量中断 |

> 🎯 **生产铁律**：BOM 管版本、Feign 配 fallback、Sentinel 规则持久化、TraceId 全链路、Nacos 集群+MySQL。这 5 条不到位，别上线。
