## 5. 核心概念速查

| 概念 | 一句话解释 |
|------|-----------|
| **逻辑时钟** | 用计数器替代物理时间定义「先后」（Lamport/向量时钟） |
| **脑裂** | 网络分区后多主并存——需要 quorum/仲裁机制 |
| **雪花算法** | 时间戳+机器ID+序列号生成 64 位趋势递增 ID |
| **号段模式** | DB 批量发号（step 步长），Leaf-segment 的省 DB 方案 |
| **Redisson 看门狗** | 30s 租约 + 10s 续期——业务执行多久锁活多久 |
| **Redlock** | 5 节点过半数加锁算法——Kleppmann vs Antirez 世纪争论 |
| **缓存三兄弟** | 穿透（查不存在）/击穿（热点过期）/雪崩（批量过期） |
| **延迟双删** | 更新 DB 后删缓存 + 延迟再删——双写一致性的工程折中 |
| **Seata AT 模式** | 无侵入回滚：前置镜像 + 后置镜像 + 全局锁 |
| **TCC** | Try-Confirm-Cancel 业务补偿，三阶段显式确认 |
| **分片键** | 决定数据落哪张表——选错=查询全部路由 |
| **幂等** | 同请求多次执行结果一致——唯一键/状态机/去重表 |
| **采样率** | 链路追踪只记录部分请求（100%→1%）平衡成本 |
