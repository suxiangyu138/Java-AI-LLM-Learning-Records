## 1. OWASP Top 10 概览

```
OWASP Top 10（Web 安全权威清单）核心：
  ① 失效访问控制（越权）
  ② 加密失败（明文传输/存储）
  ③ 注入（SQL/命令）
  ④ 不安全设计
  ⑤ 安全配置错误
  ⑥ 脆弱组件（依赖漏洞）
  ⑦ 认证失败
  ⑧ 数据完整性失败（反序列化）
  ⑨ 日志监控不足
  ⑩ SSRF 服务端请求伪造

⚠️ 面试必答：
"OWASP 高频三件——越权、注入、XSS；
 企业防御按清单逐项自查
 （安全基线 + 扫描工具）。"
```

## 2. SQL 注入

### 2.1 攻击原理

```java
// ❌ 拼接 SQL（注入入口）
String sql = "SELECT * FROM user WHERE name = '" + name + "'";
// 输入：' OR '1'='1
// 执行：SELECT * FROM user WHERE name = '' OR '1'='1   ← 全表泄露！

// ✅ 参数化（预编译）
// MyBatis：#{} 预编译；JPA：参数绑定
```

### 2.2 防御体系

```
SQL 注入防御四层：
  ① 参数化查询（根本防线，MyBatis #{}）
  ② 输入校验（白名单/格式）
  ③ 最小权限（DB 账号只读所需）
  ④ WAF（网络层兜底）

⚠️ 面试必答：
"SQL 注入防线 = 参数化（根本）+
 校验 + 最小权限 + WAF；
 '永远不要拼接 SQL'是铁律。"
```

## 3. XSS 跨站脚本

### 3.1 攻击原理与类型

```
XSS = 注入恶意脚本执行

三类：
  存储型：恶意脚本存数据库（评论区）⚠️ 最危险
  反射型：URL 参数回显脚本
  DOM 型：前端 DOM 操作注入

⚠️ 面试必答：
"XSS 三类——存储（最危险，持久）、
 反射（URL 触发）、DOM（前端注入）。"
```

### 3.2 防御体系

```
XSS 防御三层：
  ① 输出转义（前端框架默认转义 {{}}）
  ② Cookie HttpOnly（脚本读不到会话）
  ③ CSP 内容安全策略（限制脚本来源）

⚠️ 面试必答：
"XSS 防线——输出转义（框架默认）、
 HttpOnly（保会话）、CSP（限脚本来源）；
 后端对用户输入'存储时过滤、输出时转义'。"
```

## 4. CSRF 跨站请求伪造

### 4.1 攻击原理

```
CSRF = 借用户 Cookie 发伪造请求
  用户已登录（Cookie 有效）
  访问恶意网站 → 恶意页面自动发请求（带 Cookie）
  服务器以为是用户操作 → 执行转账/改密

前提：请求靠 Cookie 认证（会话场景）

⚠️ 面试必答：
"CSRF 利用'浏览器自动带 Cookie'——
 恶意站伪造请求借用户身份；
 前提是 Cookie 认证（JWT 放 Header 天然免疫）。"
```

### 4.2 防御方案

```
CSRF 防御三方案：
  ① SameSite Cookie（Lax/Strict）✅ 现代默认
  ② CSRF Token（表单隐藏字段校验）
  ③ 二次验证（支付密码/验证码）

⚠️ 面试必答：
"CSRF 防线——SameSite（现代首选）、
 Token 校验（传统）、二次验证（高危操作）；
 JWT 走 Header 无 Cookie 依赖 → 免疫。"
```

## 5. 认证与授权安全

### 5.1 认证最佳实践

```
认证安全规范：
  密码：BCrypt 哈希（不存明文）
  登录：限流（防暴力破解）+ 验证码
  会话：短时效 + 登出失效
  MFA：敏感系统双因素

⚠️ 面试必答：
"认证安全——BCrypt 存密码、
 登录限流防爆破、会话短时效、
 高危系统 MFA。"
```

### 5.2 授权与越权防护

```
越权两类：
  水平越权：看别人的数据（BOLA）
  垂直越权：低权限用户操作高权限功能（BFLA）

防御：
  ① 服务端校验（不信任前端）
  ② RBAC 角色权限模型
  ③ 资源属主校验（数据级）
  ④ 接口权限注解（@PreAuthorize）

⚠️ 面试必答：
"越权 = 水平（同级别看别人）+
 垂直（越级操作）——
 服务端每次资源操作校验属主与权限
 是根本防线（不信任前端隐藏）。"
```

## 6. 安全头与纵深防御

### 6.1 安全头配置

```
响应安全头五件套：
  Content-Security-Policy：CSP（防 XSS 脚本）
  Strict-Transport-Security：HSTS（强制 HTTPS）
  X-Frame-Options：防点击劫持（iframe 嵌入）
  X-Content-Type-Options：防 MIME 嗅探
  Referrer-Policy：控制来源泄露

⚠️ 面试必答：
"安全头五件套——CSP/HSTS/Frame/ContentType/Referrer；
 一行配置、防御一类攻击，成本极低。"
```

### 6.2 纵深防御模型

```
Web 安全纵深四层：
  ① 网络层：WAF、防火墙、限流
  ② 框架层：参数校验、安全框架（Security）
  ③ 应用层：业务校验、权限模型
  ④ 数据层：加密、脱敏、审计

⚠️ 面试必答：
"纵深防御四层——网络 WAF → 框架校验 →
 应用权限 → 数据加密；
 单层被突破仍有下层兜底。"
```

---

> 🎯 **核心要点**：Web 安全 = **OWASP 清单**（越权/注入/XSS 高频）+ **SQL 注入**（参数化铁律）+ **XSS**（转义 + HttpOnly + CSP）+ **CSRF**（SameSite + Token + 二次验证）+ **认证授权**（BCrypt + RBAC + 属主校验）+ **纵深防御**（四层 + 安全头五件套）。"服务端校验不信任前端"是越权防护第一原则。
