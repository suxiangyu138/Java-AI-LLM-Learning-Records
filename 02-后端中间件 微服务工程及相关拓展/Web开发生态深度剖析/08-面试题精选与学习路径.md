## 1. 面试题精选 TOP 10

**Q1: 描述一次完整的 HTTP 请求过程？**
```
DNS 解析 → TCP 三次握手（HTTPS 加 TLS）→
HTTP 请求 → Nginx（静态/转发）→ Tomcat →
DispatcherServlet → Controller → Service → 数据层 →
响应返回 → 浏览器渲染。链路见 00 篇。
```

**Q2: HTTP 与 HTTPS 的区别？**
```
HTTPS = HTTP + TLS：证书验身份（非对称）
+ 密钥加密数据（对称）；握手交换密钥。
HTTP 明文可被窃听/篡改。
```

**Q3: GET 和 POST 的区别？**
```
语义：查 vs 建；幂等：GET 幂等可重试、POST 不幂等；
缓存：GET 可缓存、POST 不可；传参：URL vs Body。
⚠️ 不是"长度/安全"区别（都可以带 Body）。
```

**Q4: Session 和 JWT 的区别？怎么选？**
```
Session 服务端存（可立即失效）、JWT 客户端存（无状态）；
选型分界 = 能否立即失效——
封号/改密场景 Session/Redis Token、
微服务无状态 JWT。
```

**Q5: Cookie 和 Session 的关系？**
```
Session 数据在服务端、Cookie 只传会话 ID（JSESSIONID）；
Cookie 属性（HttpOnly/Secure/SameSite）是安全关键。
```

**Q6: 什么是跨域？怎么解决？**
```
同源策略（协议+域名+端口）；跨域 = CORS 头配置
或 Nginx 反向代理（同源化）；生产白名单限定域名。
```

**Q7: SQL 注入怎么防？**
```
参数化查询（MyBatis #{}）是根本 + 输入校验 +
最小权限 + WAF；永远不拼接 SQL。
```

**Q8: 缓存穿透/击穿/雪崩？**
```
穿透（空值缓存/布隆）、击穿（互斥锁/逻辑过期）、
雪崩（随机过期/集群）。三连问必背。
```

**Q9: 接口幂等怎么保证？**
```
幂等键（Redis 去重）+ 数据库唯一约束 + 状态机校验；
资金类接口必须幂等（POST 重复创建/重复扣款）。
```

**Q10: 高并发下系统怎么优化？**
```
五层优化——前端（CDN/懒加载）、网络（HTTP2/Gzip）、
应用（缓存/异步/线程池）、数据（索引/连接池/读写分离）、
架构（集群/限流熔断/分库分表）。
```

## 2. 高频手写题

### 2.1 手写防抖节流

```java
// Java 侧：Web 场景少手写（前端为主）
// 前端 JS 版（见前端体系 08 篇）
// Java 侧常见手写：限流器
class RateLimiter {
    private final long capacity;      // 桶容量
    private final long refillRate;    // 每秒补充
    private double tokens;
    private long lastRefill;

    public synchronized boolean tryAcquire() {
        long now = System.currentTimeMillis();
        tokens = Math.min(capacity,
            tokens + (now - lastRefill) / 1000.0 * refillRate);
        lastRefill = now;
        if (tokens >= 1) { tokens -= 1; return true; }
        return false;
    }
}
// 令牌桶手写 = 面试高频（限流原理验证）
```

### 2.2 手写 LRU / 简单缓存

```java
// LRU 缓存（HashMap + LinkedList，见设计体系）
// 或简化版：LinkedHashMap accessOrder
class LRUCache<K, V> extends LinkedHashMap<K, V> {
    private final int max;
    LRUCache(int max) {
        super(max, 0.75f, true);      // accessOrder = true
        this.max = max;
    }
    @Override protected boolean removeEldestEntry(Map.Entry<K, V> eldest) {
        return size() > max;
    }
}
```

> 🎯 **要点**：Web 面试手写三件套——令牌桶限流、LRU 缓存、幂等判断（Redis setIfAbsent）——都是"缓存与并发"的组合考察。

## 3. 学习路线推荐

### 路线 A：面试冲刺（3-5 天）

```
08 面试题 → 01 HTTP（状态码/HTTPS）→
03 会话（Session/JWT）→ 04 安全（注入/XSS/CSRF）
→ 06 缓存（三难）→ 07 高可用（三板斧）
```

### 路线 B：系统学习（2-3 周）

```
00 总览（全链路地图）→ 01 协议 → 02 容器框架
→ 03 会话 → 04 安全 → 05 协作 → 06 性能 → 07 高可用
→ 深入各专题体系（Tomcat/SpringBoot/中间件）
```

### 路线 C：架构方向

```
07 高可用 → 06 性能 → 结合中间件体系
（Redis/MySQL/消息）→ 分布式架构体系
```
