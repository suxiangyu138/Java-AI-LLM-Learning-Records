## 5. 核心概念速查

| 概念 | 一句话解释 |
|------|-----------|
| **服务器** | 7×24 小时持续对外提供服务的计算机（性能/可靠性/可扩展） |
| **冯诺依曼架构** | 存储程序原理：输入→存储→运算→输出 五大部件 |
| **CPU** | 中央处理器——核心频率×核心数决定算力；2026 主流 64-136 核 |
| **内存 DDR5** | 数据暂存区——断电即失，速度是磁盘的 10 万倍级 |
| **SSD vs HDD** | 固态（闪存，快）vs 机械（盘片，便宜）——服务器 SSD 主流 |
| **RAID** | 多磁盘冗余阵列——RAID1 镜像/RAID10 镜像+条带 |
| **内核 Kernel** | 操作系统核心：进程调度/内存管理/文件系统/网络 |
| **虚拟内存** | 进程地址空间与物理内存映射——隔离 + 超卖 |
| **TCP/IP 协议栈** | 从网卡到应用的分层协议（链路→网络→传输→应用） |
| **端口** | 服务器上区分服务的编号（80/443/3306/8080） |
| **epoll** | Linux 高并发 I/O 多路复用——Nginx/Netty 的基石 |
| **零拷贝** | 数据不经用户态直达网卡——sendfile/mmap |
| **虚拟机 vs 容器** | VM 虚拟化硬件（Guest OS 完整）vs 容器共享内核 |
| **裸金属** | 无虚拟化的物理机——高性能/高安全场景 |
| **CXL 3.0** | 内存池化互连标准（2026 AI 服务器标配趋势） |
