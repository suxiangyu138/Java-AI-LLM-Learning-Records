## 2. Cursor

```text
核心竞争力：Tab 补全体验行业第一

  Tab 补全     → 预测整块 diff，全项目感知，<100ms
  ⌘K 行内编辑  → 选中代码→⌘K→"改写为Stream API"→预览diff
  Composer     → 多文件编辑预览
  Agent 模式   → 自主规划+执行+验证
  Cloud Agent  → 后台异步执行长任务

最佳场景：日常编码、全栈开发、新项目搭建
```

---

## 3. Windsurf

```text
核心竞争力：$15/月 → 性价比最高

  Cascade 代理     → 可视化执行计划，流式交互延迟低
  自研 SWE-1.5 模型 → 轻量任务不消耗昂贵API额度
  Supercomplete    → 行/块级补全 + 自动索引

最佳场景：前端开发、预算有限、想尝试 AI IDE
```

---

## 4. GitHub Copilot

```text
核心竞争力：最广 IDE 覆盖 + 最成熟企业功能

  IDE 覆盖   → VS Code、JetBrains、VS、Xcode、Neovim
  生态深度   → PR/Issue 自动生成、Copilot Chat
  企业级功能 → SSO、审计日志、IP侵权赔偿、代码泄露防护

最佳场景：多IDE团队、GitHub生态、企业合规需求
```
