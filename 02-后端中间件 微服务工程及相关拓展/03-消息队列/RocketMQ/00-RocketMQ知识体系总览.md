## 4. 版本说明

| 版本 | 关键变化 |
|------|----------|
| **3.x** | 阿里内部版本，支撑双十一 |
| **4.0.x** | 捐献 Apache，首次开源 |
| **4.5.x** | DLedger 自动主从切换，事务消息增强 |
| **4.7.x** | 支持轻量级 ACL、Request-Reply 模式 |
| **4.9.x** | Pop 消费模式、批量消息大小限制 |
| **5.0.x** | Controller 模式（替代 DLedger）、Proxy 模块 |
| **5.1.x** | gRPC Proxy 稳定、分级存储（Tiered Storage） |

> 💡 本文档基于 RocketMQ 4.9.x/5.x 编写，覆盖 5.x 新特性（Controller 模式、Proxy）。

## 5. 与 Kafka 的核心差异

| 维度 | RocketMQ | Kafka |
|------|----------|-------|
| **定位** | 业务消息（金融级） | 数据管道（大数据） |
| **事务消息** | ✅ 半消息机制 | ⚠️ 需要事务 Producer |
| **延迟消息** | ✅ 18 个级别 | ❌ 需自行实现 |
| **消息过滤** | ✅ Tag + SQL92 | ❌ 客户端过滤 |
| **存储模型** | CommitLog + ConsumeQueue | Partition LogSegment |
| **注册中心** | NameServer（无状态） | KRaft / ZooKeeper |
| **顺序消息** | ✅ 全局/分区都有 | ⚠️ 仅分区内有序 |
| **重试机制** | ✅ 重试队列（内置） | ❌ 需业务自己实现 |
