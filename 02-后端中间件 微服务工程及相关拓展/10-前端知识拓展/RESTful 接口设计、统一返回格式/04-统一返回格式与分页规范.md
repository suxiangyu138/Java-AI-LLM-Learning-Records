## 1. 统一返回格式 Result\<T\>

```json
// 成功
{
  "code": 200,
  "msg": "success",
  "data": { "id": 1, "name": "张三" },
  "timestamp": 1705315200000
}

// 失败
{
  "code": 400,
  "msg": "用户名不能为空",
  "data": null,
  "timestamp": 1705315200000
}

// 列表
{
  "code": 200,
  "msg": "success",
  "data": [
    { "id": 1, "name": "张三" },
    { "id": 2, "name": "李四" }
  ],
  "timestamp": 1705315200000
}
```

```java
@Data
@JsonInclude(JsonInclude.Include.NON_NULL)
public class Result<T> {
    private int code;
    private String msg;
    private T data;
    private Long timestamp = System.currentTimeMillis();

    private Result(int code, String msg, T data) {
        this.code = code;
        this.msg = msg;
        this.data = data;
    }

    public static <T> Result<T> ok(T data) {
        return new Result<>(200, "success", data);
    }

    public static <T> Result<T> fail(int code, String msg) {
        return new Result<>(code, msg, null);
    }
}
```

> ⚠️ **Result\<T\> 只包裹业务数据，不包裹 HTTP 错误**：401/403/500 由全局异常处理返回，Controller 只关心业务成功路径。

## 2. 分页返回规范

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "list": [
      { "id": 1, "name": "张三" },
      { "id": 2, "name": "李四" }
    ],
    "page": 1,
    "size": 20,
    "total": 156,
    "totalPages": 8
  }
}
```

```java
@Data
public class PageResult<T> {
    private List<T> list;        // 数据
    private int page;            // 当前页
    private int size;            // 每页大小
    private long total;          // 总记录数
    private int totalPages;      // 总页数

    public static <T> PageResult<T> of(Page<T> page) {
        PageResult<T> result = new PageResult<>();
        result.list = page.getContent();
        result.page = page.getNumber() + 1;    // Page 从 0 开始 → API 从 1 开始
        result.size = page.getSize();
        result.total = page.getTotalElements();
        result.totalPages = page.getTotalPages();
        return result;
    }
}
```

```java
@GetMapping("/users")
public Result<PageResult<UserDTO>> list(
    @RequestParam(defaultValue = "1") int page,
    @RequestParam(defaultValue = "20") int size) {
    Page<User> userPage = userService.findAll(PageRequest.of(page - 1, size));
    return Result.ok(PageResult.of(userPage.map(UserDTO::from)));
}
```

### 分页字段命名约定

| 字段 | 推荐 | 备选 | 说明 |
|------|------|------|------|
| 数据 | `list` | `items`, `records` | 数组 |
| 页码 | `page` | `pageNum` | 从 1 开始 |
| 每页大小 | `size` | `pageSize` | — |
| 总数 | `total` | `totalCount` | — |
| 总页数 | `totalPages` | `pages` | — |

## 3. 错误码设计

```text
错误码分段设计（参考 HTTP 状态码分层）：

  1xxx — 通用错误
  2xxx — 用户模块
  3xxx — 订单模块
  4xxx — 商品模块
  9xxx — 系统错误

示例：
  1001: 参数校验失败
  1002: 资源不存在
  2001: 用户名已存在
  2002: 密码错误
  2003: 用户已被禁用
  3001: 订单不存在
  3002: 订单已取消，不能支付
  9001: 系统繁忙
  9999: 未知错误
```

```java
// 枚举统一管理错误码
@AllArgsConstructor
@Getter
public enum ErrorCode {
    SUCCESS(200, "success"),
    PARAM_ERROR(1001, "参数校验失败"),
    NOT_FOUND(1002, "资源不存在"),
    USER_EXISTS(2001, "用户名已存在"),
    USER_NOT_FOUND(2002, "用户不存在"),
    ORDER_NOT_FOUND(3001, "订单不存在"),
    SYSTEM_ERROR(9999, "系统繁忙");

    private final int code;
    private final String msg;
}

// 使用
throw new BizException(ErrorCode.USER_EXISTS);
```

## 4. HATEOAS 简介

> HATEOAS（Hypermedia as the Engine of Application State）：响应中包含可执行的链接。

```json
{
  "id": 1,
  "name": "张三",
  "_links": {
    "self": { "href": "/api/users/1" },
    "orders": { "href": "/api/users/1/orders" },
    "avatar": { "href": "/api/files/avatar-1.jpg" }
  }
}
```

```java
// Spring HATEOAS
@GetMapping("/users/{id}")
public EntityModel<User> getUser(@PathVariable Long id) {
    User user = userService.getById(id);
    return EntityModel.of(user,
        linkTo(methodOn(UserController.class).getUser(id)).withSelfRel(),
        linkTo(methodOn(OrderController.class).getOrders(id)).withRel("orders"));
}
```

| 适用场景 | 不适用场景 |
|----------|-----------|
| 公开 API，前端动态发现能力 | 内部微服务 RPC（固定契约） |
| 复杂业务流程导航 | 简单 CRUD |

> 🎯 **统一返回铁律**：始终用 Result\<T\> 包裹、code/msg/data 三字段、分页用 PageResult、错误码分段管理。HATEOAS 是加分项非必选项。
