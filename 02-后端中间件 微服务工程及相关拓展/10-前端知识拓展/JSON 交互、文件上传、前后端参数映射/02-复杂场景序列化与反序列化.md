## 1. 泛型反序列化

```java
// ❌ 错误：泛型信息丢失，反序列化为 LinkedHashMap
List<User> users = objectMapper.readValue(json, List.class);
// → users 实际是 List<LinkedHashMap>，get(0).getName() 报错

// ✅ 方式1：TypeReference（最常用）
List<User> users = objectMapper.readValue(json,
    new TypeReference<List<User>>() {});

// ✅ 方式2：JavaType
JavaType type = objectMapper.getTypeFactory()
    .constructCollectionType(List.class, User.class);
List<User> users = objectMapper.readValue(json, type);

// ✅ 方式3：RestTemplate 泛型（ParameterizedTypeReference）
ResponseEntity<Result<List<User>>> response = restTemplate.exchange(
    url, HttpMethod.GET, null,
    new ParameterizedTypeReference<Result<List<User>>>() {});
```

### Feign 调用中泛型返回

```java
// Feign 接口直接返回 Result<T>
@FeignClient("user-service")
public interface UserClient {
    @GetMapping("/users/{id}")
    Result<User> getUser(@PathVariable Long id);        // ✅ 自动处理

    @GetMapping("/users")
    Result<List<User>> listUsers();                      // ✅ 自动处理
}
// Spring Cloud Feign 内部使用 ParameterizedTypeReference 自动处理泛型
```

## 2. 多态序列化

```java
// 场景：Animal 可能是 Cat 或 Dog
@JsonTypeInfo(use = JsonTypeInfo.Id.NAME, property = "type")
@JsonSubTypes({
    @JsonSubTypes.Type(value = Cat.class, name = "cat"),
    @JsonSubTypes.Type(value = Dog.class, name = "dog")
})
public abstract class Animal { ... }

// JSON 输出: { "type": "cat", "name": "咪咪", "meowSound": "喵" }
// JSON 输入时根据 type 字段自动反序列化为 Cat
```

## 3. 循环引用处理

```java
// 场景：User → Orders → User 循环引用
@Data
public class User {
    private Long id;
    @JsonManagedReference              // ⭐ 主引用 — 序列化
    private List<Order> orders;
}

@Data
public class Order {
    private Long id;
    @JsonBackReference                 // ⭐ 反向引用 — 不序列化
    private User user;
}

// 输出: User { orders: [ Order { id: 1 } ] }  ← Order 中无 user 字段
```

```java
// 或全局配置（推荐）
@JsonIdentityInfo(generator = ObjectIdGenerators.PropertyGenerator.class, property = "id")
@Data
public class User {
    private Long id;
    private List<Order> orders;      // 第二次出现时仅输出 id
}
// 输出: 第一次完整 User { id:1, orders: [...] }, 之后仅 User 1
```

## 4. 自定义序列化器

```java
// 自定义脱敏 — 手机号中间四位变 ****
public class PhoneSerializer extends JsonSerializer<String> {
    @Override
    public void serialize(String value, JsonGenerator gen,
                          SerializerProvider serializers) throws IOException {
        if (value != null && value.length() == 11) {
            gen.writeString(value.substring(0, 3) + "****" + value.substring(7));
        } else {
            gen.writeString(value);
        }
    }
}

@Data
public class User {
    @JsonSerialize(using = PhoneSerializer.class)
    private String phone;    // 13812345678 → 138****5678
}

// JSON null → Java null（前端不发字段 ≠ null）
@JsonSetter(nulls = Nulls.SKIP)
public void setName(String name) {
    if (name != null) this.name = name;   // 防止被 null 覆盖
}
```

## 5. JSON 字段速查测试

```java
@SpringBootTest
class JacksonTest {

    @Autowired private ObjectMapper mapper;

    @Test
    void testSerialize() throws Exception {
        String json = mapper.writeValueAsString(new User());
        // 检查 null 字段是否被忽略
        assertThat(json).doesNotContain("null");
        // 检查驼峰→下划线
        assertThat(json).contains("user_name");
    }
}
```

| 测试场景 | 检查点 |
|----------|--------|
| 驼峰→下划线 | `userName` → `user_name` |
| null 忽略 | JSON 中无值为 null 的字段 |
| 日期格式 | `2024-01-15 10:30:00` 而非毫秒时间戳 |
| 枚举 code | `0` 而非 `"PENDING"` |
| 密码排除 | JSON 中无 `password` 字段 |

> 🎯 **记住**：泛型反序列化用 `TypeReference`、循环引用用 `@JsonManagedReference/@JsonBackReference`、脱敏用自定义 `JsonSerializer`、金额用 `String` 而非 `Double`（精度问题）。
