## 1. CSS 是什么

```
CSS（Cascading Style Sheets）= 层叠样式表
  控制 HTML 的表现（布局、颜色、动画）

三件套分工：
  HTML = 结构、CSS = 表现、JS = 行为

⚠️ 面试必答：
"CSS 负责表现层——选择器匹配元素、
 声明块描述样式、层叠规则解决冲突。
 'Cascading（层叠）'是它的核心机制。"
```

### 1.1 引入方式

```html
<!-- ① 外链（推荐） -->
<link rel="stylesheet" href="style.css">

<!-- ② 内联 style 属性（最高优先级，慎用） -->
<div style="color: red;">红字</div>

<!-- ③ 嵌入 <style>（单页小样式） -->
<style>
    p { color: blue; }
</style>
```

## 2. 层叠与继承

### 2.1 层叠规则（CSS 冲突如何解决）

```
同一元素同一属性多个声明 → 按"优先级 + 顺序"裁决：

优先级（从低到高）：
  通配符 *            （0,0,0,0）
  标签选择器 p         （0,0,0,1）
  类/属性/伪类 .a      （0,0,1,0）
  ID 选择器 #a         （0,1,0,0）
  内联 style           （1,0,0,0）
  !important           （🚀 最高，慎用）

同优先级 → 后写的生效（源码顺序）

⚠️ 面试必答：
"层叠裁决 = 优先级四元组（内联, ID, 类, 标签）
 + 源码顺序；!important 是最后手段
 （破坏可维护性）。"
```

### 2.2 优先级计算示例

```css
/* #header .nav a          → (0,1,1,1) */
/* .nav a:hover            → (0,0,2,1) */
/* #header a               → (0,1,0,1) */
/* 第一个胜出（ID 权重最高） */
```

### 2.3 继承

```
可继承属性（文字相关）：
  color、font-*、line-height、text-*、letter-spacing

不可继承（布局相关）：
  margin、padding、border、width、height、background、display

控制继承：
  inherit  （强制继承父值）
  initial  （重置为初始值）
  unset    （可继承则继承，否则初始值）
  revert   （回退浏览器默认）

⚠️ 面试必答：
"'文字属性继承、布局属性不继承'——
 继承与层叠是 CSS 的两大基础机制。"
```

## 3. 盒模型

### 3.1 两种盒模型

```
标准盒模型（content-box，默认）：
  实际宽度 = width + padding + border + margin

替代盒模型（border-box）：
  实际宽度 = width（padding/border 包含在内）

⚠️ 全局重置（现代工程标配）：
  * , *::before, *::after { box-sizing: border-box; }
```

### 3.2 盒模型组成

```
┌─────────────── margin（外边距）──────────────┐
│ ┌─────────── border（边框）───────────┐      │
│ │ ┌──────── padding（内边距）────────┐ │      │
│ │ │ ┌──────── content（内容）───────┐ │ │      │
│ │ │ │                              │ │ │      │
│ │ │ └──────────────────────────────┘ │ │      │
│ │ └──────────────────────────────────┘ │      │
│ └──────────────────────────────────────┘      │
└────────────────────────────────────────────────┘
```

| 属性 | 作用 | 易错点 |
|------|------|--------|
| margin | 外边距 | 垂直 margin 折叠 |
| border | 边框 | border-box 下计入宽 |
| padding | 内边距 | 计入盒尺寸 |
| margin 折叠 | 相邻垂直 margin 取大值 | BFC 可解决 |

> 🎯 **要点**：`box-sizing: border-box` 全局设置是现代 CSS 第一约定——宽高语义符合直觉，避免 padding 撑破布局。

## 4. 单位与颜色

### 4.1 单位体系

| 类型 | 单位 | 说明 |
|------|------|------|
| 绝对 | px | 屏幕像素（最常用） |
| 相对字体 | em / rem | em 相对父、rem 相对根（html） |
| 视口 | vw / vh / vmin / vmax | 视口宽度/高度百分比 |
| 容器 | cqw / cqi | 容器查询单位（2023+） |
| 比例 | % | 相对父元素 |
| 动态 | clamp() | 流体字号 |

```css
/* rem 与 em 的选择 */
html { font-size: 16px; }
.text { font-size: 1.5rem; }   /* 24px，相对根 */
.child { font-size: 1.5em; }   /* 相对父字号 */

/* 流体字号（现代推荐） */
h1 { font-size: clamp(1.5rem, 4vw, 3rem); }
```

> 🎯 **要点**：全局字号用 rem（可统一缩放）、局部相对用 em、流体排版用 clamp()。px 用于边框/阴影等不随字体变化的量。

### 4.2 颜色

```css
/* 现代写法：HSL（更直觉） + 透明度 */
color: #ff0000;                    /* 十六进制 */
color: rgb(255, 0, 0);             /* RGB */
color: hsl(0, 100%, 50%);          /* 色相/饱和度/明度 */
color: rgba(255, 0, 0, 0.5);       /* 带透明度 */
color: hsl(0 100% 50% / 0.5);      /* 现代空格语法 */
color: color-mix(in srgb, red, blue 50%);  /* 颜色混合（2023+） */
```

## 5. 选择器体系

### 5.1 选择器分类

| 类型 | 示例 | 说明 |
|------|------|------|
| 基础 | `p`、`.class`、`#id`、`*` | 标签/类/ID/通配 |
| 组合 | `div p`（后代）、`div > p`（子）、`a + b`（兄弟）、`a ~ b`（后续兄弟） | 关系组合 |
| 属性 | `[type="text"]`、`[href^="https"]` | 属性匹配 |
| 伪类 | `:hover`、`:first-child`、`:nth-child(2n)` | 状态/位置 |
| 伪元素 | `::before`、`::after`、`::first-line` | 元素内部 |
| 现代 | `:has()`、`:is()`、`:where()` | 2023+ 广泛支持 |

### 5.2 现代选择器（面试加分）

```css
/* :has() 父选择器（2023 Baseline）——按子元素选父 */
.card:has(.badge) { border-color: gold; }
form:has(input:invalid) { border-color: red; }

/* :is() / :where()——分组选择器（:where 优先级为 0） */
:is(h1, h2, h3) { margin: 0; }
:where(.card, .panel) p { color: gray; }   /* 不增加优先级 */

/* :nth-child 进阶 */
li:nth-child(2n)      /* 偶数 */
li:nth-child(-n+3)    /* 前 3 个 */
```

> 🎯 **要点**：`:has()` 让"父选择器"成为现实（表单校验态、卡片徽章）；`:where()` 零优先级便于覆盖——2026 年面试高频新考点。
