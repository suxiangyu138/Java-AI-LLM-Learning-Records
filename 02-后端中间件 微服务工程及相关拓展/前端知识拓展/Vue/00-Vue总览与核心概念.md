## 1. Vue 是什么

```
Vue = 渐进式 JavaScript 框架（构建用户界面）

渐进式 = 按需使用：
  只渲染 → 模板语法
  单页应用 → 路由/状态管理
  大型工程 → 工程化全家桶

核心卖点：
  响应式（数据变 → 视图自动更新）
  组件化（复用 + 组合）
  学习曲线低（模板语法接近 HTML）

⚠️ 面试必答：
"Vue 是渐进式框架——从模板渲染到
 全家桶按需引入；响应式是其灵魂
 （数据驱动视图，无需手动 DOM 操作）。"
```

## 2. Vue 3 核心思想

### 2.1 三大核心

```
① 响应式系统：数据变化自动更新视图
   （Proxy 拦截 + 依赖收集 + 触发更新）

② 组件系统：UI 复用单元
   （模板 + 逻辑 + 样式封装）

③ 虚拟 DOM：渲染性能优化
   （diff 算法最小化真实 DOM 操作）

⚠️ 面试必答：
"Vue 三大核心——响应式（数据驱动）、
 组件化（复用）、虚拟 DOM（性能）。
 响应式是区别于命令式框架的根本。"
```

### 2.2 声明式 vs 命令式

```javascript
// 命令式（手动操作 DOM）
const count = 0;
btn.addEventListener('click', () => {
    count++;
    el.textContent = count;      // 手动更新
});

// 声明式（Vue：描述"是什么"）
const count = ref(0);
<button @click="count++">{{ count }}</button>   // 自动更新
```

## 3. 版本现状（2026-07）

```
版本线：
  Vue 2（2023-12 已 EOL）
  Vue 3.x（当前主流，组合式 API 时代）
  Vue 4（Vapor Mode 预览，开发中）

Vue 4 的 Vapor Mode（蒸汽模式）：
  编译为直接操作 DOM 的代码，绕开虚拟 DOM
  更小更快（benchmark：创建 1K 行 31.2 ops/s）

⚠️ 面试必答：
"Vue 3 组合式 API 是当前标准；
 Vue 4 的 Vapor Mode 是无虚拟 DOM 编译
 （类似 Solid），预览阶段。"
```

## 4. Vue vs React 对比

| 维度 | Vue 3 | React 19 |
|------|:---:|:---:|
| 数据流 | 响应式（自动追踪） | 状态驱动（显式 setState） |
| 模板 | 模板语法（HTML 友好） | JSX（JS 内嵌） |
| 响应式原理 | Proxy 依赖收集 | 编译器自动 memo（React Compiler） |
| 状态更新 | 自动（细粒度） | 显式（setState） |
| 学习曲线 | 低（模板接近 HTML） | 中（JSX + Hooks 心智） |
| 生态 | 官方全家桶（Router/Pinia） | 社区生态（最大） |
| 性能 | 细粒度 + Vapor 演进 | 编译器优化 + RSC |

```
⚠️ 面试必答：
"Vue 响应式自动追踪（Proxy）、React 显式状态
 + 编译器 memo；模板 vs JSX 是书写范式差异；
 生态：Vue 官方全家桶、React 社区最大。"
```
