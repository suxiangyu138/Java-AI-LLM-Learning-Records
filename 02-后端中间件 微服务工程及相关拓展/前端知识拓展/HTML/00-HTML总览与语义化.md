## 1. HTML 是什么

```
HTML（HyperText Markup Language）= 网页结构语言
  标记（标签）描述内容的语义与结构
  与 CSS（样式）、JavaScript（行为）组成前端三件套

⚠️ 版本现状（2026）：
  HTML 已无版本号——Living Standard（活标准）持续演进
  由 WHATWG 维护，浏览器按标准实现

⚠️ 面试必答：
"HTML 是网页的结构层——标签定义语义，
 CSS 负责表现、JS 负责行为；
 现代 HTML 是 WHATWG 的 Living Standard。"
```

## 2. HTML 文档骨架

```html
<!DOCTYPE html>              <!-- 文档类型声明（必须第一行） -->
<html lang="zh-CN">          <!-- 根元素 + 语言声明（SEO/无障碍） -->
<head>
    <meta charset="UTF-8">   <!-- 字符编码 -->
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">  <!-- 移动端视口 -->
    <title>页面标题</title>   <!-- 标题（SEO 重要） -->
    <meta name="description" content="页面描述">  <!-- 摘要 -->
</head>
<body>
    <!-- 可见内容 -->
</body>
</html>
```

| 要素 | 作用 | 易错点 |
|------|------|--------|
| DOCTYPE | 触发标准模式 | 缺失 → 怪异模式 |
| lang | 语言声明 | 影响屏幕阅读器发音 |
| charset | 字符编码 | UTF-8 必须 |
| viewport | 移动端适配 | 缺失 → 移动端缩放过小 |
| title/description | SEO 与分享 | 每个页面唯一 |

> 🎯 **核心要点**：骨架五要素——DOCTYPE、lang、charset、viewport、title。移动端页面缺 viewport 是最常见错误。

## 3. 语义化标签体系

### 3.1 页面结构标签

```
页面级结构（HTML5）：
  <header>     页头（logo、导航）
  <nav>        导航区
  <main>       主内容（每页唯一）
  <article>    独立内容（文章/帖子）
  <section>    内容分区（带标题）
  <aside>      侧栏（相关但独立）
  <footer>     页脚
  <h1>-<h6>    标题层级（h1 每页一个）

典型布局：
  ┌──────────────────┐
  │ <header>         │
  ├──────┬───────────┤
  │ <nav>│ <main>    │
  │      │ <article> │
  │      │ <section> │
  ├──────┴───────────┤
  │ <aside> 侧栏     │
  ├──────────────────┤
  │ <footer>         │
  └──────────────────┘
```

### 3.2 内容语义标签

| 标签 | 语义 | 对比 |
|------|------|------|
| `<strong>` | 重要 | vs `<b>`（纯加粗） |
| `<em>` | 强调 | vs `<i>`（纯斜体） |
| `<mark>` | 高亮标记 | 搜索关键词 |
| `<figure>/<figcaption>` | 插图 + 标题 | 图片说明 |
| `<time>` | 时间 | 机器可读 |
| `<address>` | 联系信息 | 作者/组织 |
| `<blockquote>` | 长引用 | vs `<q>`（行内） |
| `<code>/<pre>` | 代码块 | 保留空白 |
| `<abbr>` | 缩写 | 带 title 全称 |

```
⚠️ 面试必答：
"'div 套 div'是旧时代的写法——
 语义化标签让结构可被机器理解
 （搜索引擎、屏幕阅读器、爬虫）。"
```

## 4. 语义化的价值

### 4.1 三大收益

| 收益 | 说明 |
|------|------|
| SEO | 搜索引擎理解内容结构（h1/article 权重） |
| 可访问性 | 屏幕阅读器按语义朗读（a11y） |
| 可维护性 | 结构自解释，团队协作成本低 |

```
⚠️ 面试必答：
"语义化 = 机器可理解的结构——
 SEO 排名、无障碍访问、代码可维护
 三赢。div 是最后手段。"
```

### 4.2 语义化检查清单

```
✅ 每页一个 h1
✅ main 唯一
✅ 导航用 nav（不是 div+class）
✅ 列表用 ul/ol（不是 div 堆叠）
✅ 按钮用 button（不是 div 点击）
✅ 图片有 alt
✅ 表单控件有 label

⚠️ 面试必答：
"'语义化检查'是前端面试常问——
 从 h1/main/nav/button/alt/label 六项
 自查页面是否语义正确。"
```
