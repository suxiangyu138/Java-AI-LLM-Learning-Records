## 1. exec vs spawn vs fork

| 方法 | 缓冲 | 适用 | Java 等价 |
|------|:---:|------|------|
| **exec** | ✅ 全部缓冲 | 短命令（返回值小） | `Runtime.exec()` |
| **spawn** | ❌ 流式 | 长命令/大数据 | `ProcessBuilder` |
| **fork** | ❌ 流式 | 专门的 Node 子进程 | N/A（Node 特有） |

### exec：一次性返回

```javascript
import { exec } from 'child_process';
import { promisify } from 'util';

const execAsync = promisify(exec);

// 执行短命令，获取全部输出
const { stdout, stderr } = await execAsync('git log --oneline -5');
console.log(stdout);

// ⚠️ exec 有 1MB 输出上限！大输出用 spawn
```

### spawn：流式处理大输出

```javascript
import { spawn } from 'child_process';

// 执行长时间命令，流式处理输出
const python = spawn('python', ['train.py', '--epochs', '10']);

python.stdout.on('data', (data) => {
    console.log(`[Python] ${data}`);
});

python.stderr.on('data', (data) => {
    console.error(`[Error] ${data}`);
});

python.on('close', (code) => {
    console.log(`Python 进程退出，状态码: ${code}`);
});

// 向子进程发送数据
python.stdin.write('input data\n');
```

### 常用模式

```javascript
// 1. 执行并检查结果
async function runCommand(cmd, args = []) {
    return new Promise((resolve, reject) => {
        const child = spawn(cmd, args, { shell: true });
        let stdout = '', stderr = '';

        child.stdout.on('data', d => stdout += d);
        child.stderr.on('data', d => stderr += d);

        child.on('close', code => {
            if (code === 0) resolve(stdout);
            else reject(new Error(`Exit ${code}: ${stderr}`));
        });
    });
}

const commits = await runCommand('git', ['log', '--oneline', '-5']);
```

## 2. 调用 Python 脚本

```javascript
// 场景：Node.js MCP Server 需要调用 Python AI 模型

async function runPythonInference(prompt: string): Promise<string> {
    return new Promise((resolve, reject) => {
        const python = spawn('python', ['-c', `
import sys, json
# 这里是你的 Python AI 代码
result = {"answer": f"处理了: ${prompt}"}
print(json.dumps(result))
        `]);

        let output = '';
        python.stdout.on('data', d => output += d);
        python.on('close', code => {
            if (code === 0) resolve(JSON.parse(output).answer);
            else reject(new Error(`Python exit ${code}`));
        });
    });
}
```

## 3. 与 Java 后端交互

```javascript
// 场景：Node.js 前端 → 调用 Java JAR 做批处理

async function runJavaJar(jarPath, args = []) {
    const java = spawn('java', ['-jar', jarPath, ...args]);

    java.stdout.on('data', (data) => {
        console.log(`[Java] ${data}`);
    });

    return new Promise((resolve, reject) => {
        java.on('close', code => {
            code === 0 ? resolve() : reject(new Error(`Java exit ${code}`));
        });
    });
}

// 调用
await runJavaJar('batch-processor.jar', ['--input', 'data.csv']);
```

## 核心要点回顾

- exec = 小输出（< 1MB），一次性返回
- spawn = 大输出/长时间，流式处理
- 始终监听 stderr 和 close 事件
- 调用 Python 用 spawn（不要 exec）
- `shell: true` 支持管道和通配符（但注意安全风险）
