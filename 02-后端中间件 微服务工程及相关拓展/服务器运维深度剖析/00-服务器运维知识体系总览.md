## 4. 核心概念速查

| 概念 | 一句话解释 |
|------|-----------|
| **监控阈值** | CPU >85%/内存 >90%/磁盘 >85%——告警红线 |
| **Prometheus + Grafana** | 主流监控方案（Node Exporter 采集四类指标） |
| **内核参数** | /etc/sysctl.conf（网络/内存/文件系统调优） |
| **tuned** | 按场景切换性能配置集（virtual-guest 等） |
| **journalctl** | systemd 日志查询（-p 级别/--since 时间/-u 服务） |
| **logrotate** | 日志轮转（防磁盘被日志填满） |
| **3-2-1 备份** | 3 份副本/2 种介质/1 份异地——备份铁律 |
| **IO 瓶颈三层排查** | iostat → pidstat → lsof（设备→进程→文件） |
| **四层安全防线** | 防火墙→SSH 加固→SELinux→审计更新 |
| **fail2ban** | 失败次数超限自动封禁 IP |
| **主动巡检** | 每日标准化巡检（资源/服务/端口/网络） |
| **Keepalived VIP** | 主备切换（虚拟 IP 漂移） |
