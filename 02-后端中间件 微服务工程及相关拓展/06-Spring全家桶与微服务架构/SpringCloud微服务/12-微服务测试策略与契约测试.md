## 1. 微服务测试金字塔

```
          ┌──────┐
          │ E2E  │  少量，验证核心业务链路
         ┌┴──────┴┐
         │ Contract│  验证 Provider 满足 Consumer 期望
        ┌┴────────┴┐
        │Integration│  DB/Cache/MQ 集成正常
       ┌┴───────────┴┐
       │  Unit Tests  │  大量，快速反馈，业务逻辑
      └───────────────┘
```

| 层级 | 范围 | 速度 | 数量 | 工具 |
|------|------|:---:|:---:|------|
| **单元测试** | 单个类/方法 | ms | 最多 | JUnit5 + Mockito |
| **集成测试** | 数据库/缓存/Feign | s | 中等 | Testcontainers / H2 |
| **契约测试** | Provider ↔ Consumer 接口 | s | 中等 | Pact / Spring Cloud Contract |
| **E2E** | 全链路 | min | 最少 | Selenium / API 自动化 |

## 2. 单元测试与 Mock

```java
@ExtendWith(MockitoExtension.class)
class OrderServiceTest {

    @Mock private UserClient userClient;
    @Mock private OrderRepository orderRepository;
    @InjectMocks private OrderService orderService;

    @Test
    void shouldCreateOrder() {
        // Given
        Long userId = 1L;
        User mockUser = new User(userId, "张三", "");
        when(userClient.getUser(userId)).thenReturn(mockUser);
        when(orderRepository.save(any())).thenReturn(new Order(1L, userId, 100));

        // When
        Order order = orderService.createOrder(userId, 100);

        // Then
        assertThat(order.getId()).isEqualTo(1L);
        verify(userClient).getUser(userId);
        verify(orderRepository).save(any());
    }
}
```

## 3. 集成测试

```java
// ⭐ Testcontainers — 真实 MySQL/Redis，非 H2 模拟
@SpringBootTest
@Testcontainers
class UserRepositoryTest {

    @Container
    static MySQLContainer<?> mysql = new MySQLContainer<>("mysql:8.0")
        .withDatabaseName("user_db")
        .withUsername("test")
        .withPassword("test");

    @DynamicPropertySource
    static void configure(DynamicPropertyRegistry registry) {
        registry.add("spring.datasource.url", mysql::getJdbcUrl);
        registry.add("spring.datasource.username", mysql::getUsername);
        registry.add("spring.datasource.password", mysql::getPassword);
    }

    @Autowired private UserRepository userRepository;

    @Test
    void shouldFindById() {
        User user = new User(null, "张三", "zhangsan@example.com");
        userRepository.save(user);

        Optional<User> found = userRepository.findById(user.getId());
        assertThat(found).isPresent();
    }
}
```

## 4. 契约测试（Pact）

> 💡 解决"Provider 改了接口，Consumer 不知道"的问题。

```text
Consumer 端（消费方）— 定义期望：
  "当我调用 GET /users/1 时，我期望返回 {id: 1, name: '张三'}"
  → 生成 Pact 契约文件

Provider 端（提供方）— 验证契约：
  "根据契约文件，我的 /users/{id} 接口要能返回符合格式的数据"
  → 执行契约验证测试

CI Pipeline：
  Consumer 发布契约 → Provider 拉取验证 → 不通过阻止部署
```

### Consumer 端（定义契约）

```java
@ExtendWith(PactConsumerTestExt.class)
@PactTestFor(providerName = "user-service", port = "8081")
class OrderServicePactTest {

    @Pact(consumer = "order-service")
    public V4Pact getUserPact(PactDslWithProvider builder) {
        return builder
            .given("User 1 exists")
            .uponReceiving("GET user by id 1")
                .path("/users/1")
                .method("GET")
            .willRespondWith()
                .status(200)
                .body("""{"id":1,"name":"张三","email":"zhangsan@example.com"}""")
            .toPact(V4Pact.class);
    }

    @Test
    @PactTestFor(pactMethod = "getUserPact")
    void shouldGetUser(MockServer mockServer) {
        UserClient client = Feign.builder()
            .target(UserClient.class, mockServer.getUrl());
        User user = client.getUser(1L);
        assertThat(user.getName()).isEqualTo("张三");
    }
}
```

### Provider 端（验证契约）

```java
@Provider("user-service")
@PactBroker(url = "http://pact-broker:9292")
@SpringBootTest(webEnvironment = WebEnvironment.RANDOM_PORT)
class UserServicePactVerificationTest {

    @LocalServerPort int port;

    @BeforeEach
    void setup(PactVerificationContext context) {
        context.setTarget(new HttpTestTarget("localhost", port));
    }

    @TestTemplate
    @ExtendWith(PactVerificationInvocationContextProvider.class)
    void pactVerificationTestTemplate(PactVerificationContext context) {
        context.verifyInteraction();
    }

    @State("User 1 exists")
    void user1Exists() {
        userRepository.save(new User(1L, "张三", "zhangsan@example.com"));
    }
}
```

## 5. 端到端测试

```java
// REST Assured — 真实 HTTP 请求验收核心链路
@SpringBootTest(webEnvironment = WebEnvironment.RANDOM_PORT)
class OrderE2ETest {

    @LocalServerPort int port;

    @Test
    void shouldCreateAndGetOrder() {
        // 创建订单
        String orderId = given()
            .port(port)
            .contentType(ContentType.JSON)
            .body("""{"userId":1,"amount":100}""")
        .when()
            .post("/api/orders")
        .then()
            .statusCode(200)
            .body("code", equalTo(200))
            .extract().path("data.id").toString();

        // 查询订单
        given()
            .port(port)
        .when()
            .get("/api/orders/" + orderId)
        .then()
            .statusCode(200)
            .body("data.userId", equalTo(1));
    }
}
```

> 🎯 **测试策略**：单元测试覆盖业务逻辑（80%+ 行覆盖率），Testcontainers 测数据库集成，WireMock 测 Feign 调用，Pact 测接口契约，REST Assured E2E 验核心链路。CI Pipeline 中按速度排序执行，单元→集成→契约→E2E。
