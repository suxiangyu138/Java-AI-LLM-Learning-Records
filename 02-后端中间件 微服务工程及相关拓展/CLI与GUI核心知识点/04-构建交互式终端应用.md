# 04 - 构建交互式终端应用

> 🎯 命令行不止是"执行-返回" — 进度条、彩色输出、表格、交互式选择器，让 CLI 工具用起来更专业

---

## 1. 彩色输出（ANSI 转义码）

```java
public class AnsiColors {
    public static final String RESET  = "[0m";
    public static final String RED    = "[31m";
    public static final String GREEN  = "[32m";
    public static final String YELLOW = "[33m";
    public static final String BLUE   = "[34m";
    public static final String BOLD   = "[1m";

    public static void main(String[] args) {
        System.out.println(GREEN + "✓ 成功" + RESET);
        System.out.println(RED   + "✗ 失败" + RESET);
        System.out.println(YELLOW + "⚠ 警告" + RESET);
        System.out.println(BLUE  + BOLD + "标题" + RESET);
    }
}

// ⭐ 用 Jansi 库（自动处理 Windows 兼容）
// System.out.println(Ansi.ansi().fgRed().a("错误").reset());
```

## 2. 进度条

```java
// 简单进度条（\r 回到行首）
for (int i = 0; i <= 100; i += 5) {
    int bars = i / 5;
    String bar = "█".repeat(bars) + "░".repeat(20 - bars);
    System.out.printf("\r[%s] %d%%", bar, i);
    Thread.sleep(200);
}
System.out.println();    // 换行

// ⭐ 使用 Meeny 库（更美观）
// ProgressBar bar = new ProgressBar("下载", 100);
// bar.stepBy(25);
```

## 3. 表格输出

```java
// 手动对齐
System.out.printf("%-5s %-20s %-10s %-8s%n", "ID", "Name", "Status", "Port");
System.out.printf("%-5d %-20s %-10s %-8d%n", 1, "user-service", "UP", 8080);
System.out.printf("%-5d %-20s %-10s %-8d%n", 2, "order-service", "DOWN", 8081);

// 输出：
// ID    Name                 Status     Port
// 1     user-service         UP         8080
// 2     order-service        DOWN       8081
```

## 4. 交互式输入

```java
// ⭐ JLine — 支持历史记录/自动补全
ConsoleReader reader = new ConsoleReader();
reader.setPrompt("> ");
String line;
while ((line = reader.readLine()) != null) {
    if ("exit".equals(line)) break;
    System.out.println("你输入了: " + line);
}
```

## 5. Spinner（旋转加载动画）

```java
String[] spinner = {"⠋", "⠙", "⠹", "⠸", "⠼", "⠴", "⠦", "⠧", "⠇", "⠏"};
int i = 0;
while (!done) {
    System.out.printf("\r%s 处理中...", spinner[i++ % spinner.length]);
    Thread.sleep(100);
}
System.out.println("\r✓ 完成！    ");
```

> 🎯 **交互式 CLI 三板斧**：彩色输出（ANSI 码）、进度条（\r 覆盖）、JLine 交互输入。加上 Picocli 参数解析 = 专业级命令行工具。
