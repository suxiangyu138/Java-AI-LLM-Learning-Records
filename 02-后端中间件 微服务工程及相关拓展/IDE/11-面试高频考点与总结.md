## 1. 高频面试题

### Q1: 怎么调试线上环境的 Bug？

> 1. 看日志（ELK/Grafana）→ 定位时间范围和错误类型
> 2. 复现（能复现的 Bug 已经解决了一半）
> 3. 远程调试（测试/预发环境，不是生产！）
> 4. 如果无法复现 → 加监控埋点 + 等待下次出现
> 5. 终极方案：Dump 线程堆栈 (`jstack`) + 堆内存 (`jmap`)

### Q2: 你常用的 IDEA 快捷键有哪些？

> - `Ctrl+Shift+F` 全局搜索（最快找代码）
> - `Ctrl+Alt+Shift+U` 查看依赖图
> - `Alt+Enter` 万能修复键
> - `Ctrl+D` 对比文件差异
> - `Shift+Shift` 搜索一切（文件/类/Action）
> - `Ctrl+W/Ctrl+Shift+W` 扩大/缩小选中范围

### Q3: 怎么排查 Maven 依赖冲突？

> 1. Maven Helper 插件 → 查看冲突
> 2. `mvn dependency:tree` → 查看完整依赖树
> 3. 在冲突处右键 → Exclude
> 4. 优先使用 `<dependencyManagement>` 统一版本

### Q4: IDE 的 Git 操作和命令行的选择？

> - 日常操作（commit/push/pull）→ IDE 更高效（可视化 diff）
> - 冲突解决 → IDE 三栏视图（比命令行直观 10 倍）
> - 复杂操作（rebase -i / cherry-pick / bisect）→ 命令行更灵活
> - Annotate/Blame → IDE 最方便

### Q5: 你怎么用 AI 工具提升编程效率？

> - GitHub Copilot → 代码补全（节省 20-30% 编码时间）
> - Cursor Composer → 多文件重构（一个模块一次性生成）
> - AI Chat → 解释陌生代码 / 写单元测试 / Debug
> - 原则：AI 是副驾驶，最终决策权在我
