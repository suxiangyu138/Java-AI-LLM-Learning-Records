## 4. IDE 选择速查

| 场景 | 推荐 IDE | 原因 |
|------|---------|------|
| Java 后端主力 | **IntelliJ IDEA** | Java 生态最完善 |
| AI 开发/前端 | **VS Code** | 轻量+AI 插件最丰富 |
| AI Agent 编程 | **Cursor** | 2025 最热 AI IDE |
| Java EE 老项目 | Eclipse | Spring Tools 4 + 免费 |
| 远程开发 | VS Code Remote | SSH/容器/隧道 |
