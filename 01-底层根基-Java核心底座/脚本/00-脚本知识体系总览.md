## 4. 核心概念速查 {#4}

| 概念 | 一句话解释 | 出现位置 | 典型场景 |
|------|-----------|---------|---------|
| **Shebang** | `#!/usr/bin/env jshell` 让 Java 脚本可直接执行 | JShell | 单文件工具脚本 |
| **JSR 223** | Java 脚本引擎标准 API，统一多语言脚本执行 | javax.script | 规则引擎、插件系统 |
| **ScriptEngine** | JSR 223 核心接口，管理脚本语言引擎 | javax.script | 动态脚本执行 |
| **Nashorn** | JDK 8-14 内置 JavaScript 引擎（已移除） | JDK 历史 | 遗留系统维护 |
| **GraalVM** | 多语言运行时，现代 JavaScript 引擎替代方案 | 03-模块 | 高性能脚本执行 |
| **Wrapper** | mvnw/gradlew，锁定构建工具版本的脚本 | 04-模块 | 团队协作、CI/CD |
| **mvnw.cmd / gradlew.bat** | Maven/Gradle Wrapper 的 Windows Batch 入口 | 06-模块 | Windows 下零安装构建 |
| **JEP 330** | 单文件源码程序，`java Hello.java` 直接运行 | JShell | 快速原型、教学 |
| **JEP 495** | 简化 main 方法，隐式类声明 (JDK 23+) | JShell | 极简 Java 脚本 |
| **JBang** | 零配置 Java 脚本工具，`//DEPS` 声明依赖 | 03-模块 | 快速原型、工具脚本 |
| **GroovyShell** | Groovy 交互式执行器 | Groovy | DSL 执行、动态配置 |
| **Jenkinsfile** | Jenkins Pipeline 声明式/脚本式流水线定义 | 04-模块 | 持续集成 |
| **BATS** | Bash Automated Testing System | 05-模块 | Shell 脚本单元测试 |
| **沙箱** | 限制脚本权限的安全执行环境 | 05-模块 | 不可信脚本执行 |

## 5. 学习路线推荐 {#5}

### 🟢 初级路线：Java 开发必备脚本能力（2-3 周）

```
Shell 脚本基础 → Java 环境变量管理 → 构建 Wrapper 使用 → JShell 入门
```

> 目标：能用脚本完成日常编译、运行、打包操作，会用 JShell 快速验证代码片段。

### 🟡 中级路线：自动化工程能力（4-6 周）

```
Shell 高级脚本 → JShell 深度应用 → Groovy/Kotlin 脚本 → CI/CD 流水线编写
```

> 目标：能编写自动化构建部署脚本，搭建 CI/CD 流水线，用 JVM 脚本语言提升效率。

### 🔴 高级路线：脚本架构与治理（6-8 周）

```
JSR 223 深入 → GraalVM 多语言集成 → 脚本安全沙箱 → 脚本平台化治理
```

> 目标：能设计企业级脚本执行平台，制定脚本治理规范，构建安全的脚本运行环境。

## 6. 工具选型决策树 {#6}

```
需要什么类型的脚本？
│
├── 操作系统层的自动化（文件/进程/系统命令）
│   ├── Linux/macOS → Bash / Zsh
│   └── Windows      → PowerShell（优先）/ Batch
│
├── 快速验证 Java 代码片段 / 学习探索
│   └── → JShell（JDK 9+ 内置，零配置）
│
├── 编写可执行的 Java 工具脚本
│   ├── 无外部依赖          → JShell Shebang 或 JEP 330 单文件
│   ├── 有 Maven 依赖       → JBang（//DEPS 声明依赖）
│   └── 需要完整项目结构    → Gradle/Maven + 标准项目
│
├── 在 Java 应用中嵌入脚本引擎
│   ├── 执行 JavaScript     → GraalVM JS Engine
│   ├── 执行动态规则/DSL    → Groovy ScriptEngine
│   ├── 类型安全的脚本      → Kotlin Scripting
│   └── 通用多语言支持      → JSR 223 + GraalVM Polyglot
│
├── 构建与依赖管理
│   ├── XML 配置偏好        → Maven + mvnw
│   ├── DSL/Groovy 偏好     → Gradle + gradlew (Groovy DSL)
│   ├── 类型安全偏好        → Gradle + gradlew (Kotlin DSL)
│   └── 单文件快速构建      → JBang
│
└── CI/CD 流水线
    ├── 自建 Jenkins        → Jenkinsfile (Groovy)
    ├── GitHub 项目         → GitHub Actions YAML
    ├── GitLab 项目         → .gitlab-ci.yml
    └── 容器化环境          → Dockerfile + Shell
```
