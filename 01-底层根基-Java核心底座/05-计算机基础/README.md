## 🎯 学习路线建议

### 入门阶段
1. **计算机导论与学习路径** → 了解专业全貌，建立学习计划
2. **计算机组成原理** → 理解计算机如何工作（CSAPP 为主线）
3. **数据结构与算法** → 编程基本功，面试核心

### 进阶阶段
4. **操作系统** → 理解并发、内存、IO，后端开发基石
5. **计算机网络** → TCP/IP 协议栈 + Java 网络编程实战
6. **数据库** → 从 SQL 到分布式，后端"吃饭技能"

### 深造阶段
7. **数学基础** → 线代、概率论、优化理论，AI/ML 基础
8. **分布式系统理论** → 微服务、一致性、CAP 定理
9. **计算机安全理论** → 安全编码、攻防基础
