## 一、操作系统 Operating System (OS)

### 1. 进程与线程

| 子主题 | 核心内容 | 易错点 |
|--------|----------|--------|
| 进程三态 | 就绪、运行、阻塞；+挂起态、僵尸态 | 状态转换条件 |
| PCB 六大信息 | PID、状态、程序计数器、寄存器、内存指针、I/O 状态 | PCB 是进程唯一标识 |
| 线程模型 | 用户级、内核级、混合；轻量级线程 LWP | 用户级线程对内核透明 |
| 经典问题 | 生产者-消费者、读者-写者、哲学家就餐 | PV 操作顺序 |
| 死锁 | 互斥、占有、非剥夺、循环等待——四条件缺一不可 | 线程共享地址空间 ≠ 共享栈 |

> **口诀：** 互斥、占有、非剥夺、循环等待——死锁四字诀。

### 2. CPU 调度

- **批处理**：FCFS、SJF、HRRN
- **交互式**：RR、多级反馈队列、CFS
- **实时**：EDF、RMS
- **指标**：周转时间、响应时间、吞吐率、CPU 利用率
- **易错**：时间片过大退化为 FCFS；SJF 可导致饥饿

### 3. 内存管理

- **连续分配**：单一连续、固定分区、动态分区
- **离散分配**：分页、分段、段页式；页表级数 2/3/4 级
- **虚拟内存**：按需调页、页面置换算法（FIFO、LRU、CLOCK）
- **快表 TLB**：命中率计算；缺页中断流程
- **易错**：页面大小 4 KB → 12 位页内偏移；逻辑地址拆分位数算反

### 4. 文件与 I/O

- **文件逻辑结构**：流式、记录式
- **物理结构**：连续、链式、索引
- **目录实现**：FCB、索引节点 inode；硬链接 vs 软链接
- **磁盘调度**：FCFS、SSTF、SCAN、C-SCAN；旋转延迟公式
- **缓存**：Buffer Cache、Page Cache；写回 vs 写通
- **易错**：inode 不存文件名；硬链接计数为 0 才真正删除

### 5. 同步机制

- **信号量**：整型、记录型；PV 操作成对出现
- **锁**：互斥锁、读写锁、自旋锁、乐观锁
- **管程**：Monitor、条件变量
- **经典算法**：Dekker、Peterson、面包店算法
- **易错**：PV 操作顺序颠倒造成死锁；使用自旋锁不关闭中断

## 二、计算机组成原理 Computer Organization (CO)

### 1. 数据的表示

- **进位制**：2→10→16 互化；小数部分乘权求和
- **编码**：原码、反码、补码；补码加减溢出判断
- **浮点**：IEEE754 格式；阶码移码 127(+127)；规格化隐含 1
- **校验**：奇偶、CRC、海明码距离 3 纠 1 位
- **易错**：补码 1000 0000 表示 −128；浮点精度 EPSILON

### 2. 运算方法与 ALU

- **加法器**：串行、并行先行进位 CLA
- **乘除法**：BOOTH 一位乘、恢复余数除法
- **逻辑运算**：与、或、非、异或；位运算技巧（清 0、置 1、反转）
- **易错**：BOOTH 编码 0→+1, 1→−1；除法余数符号同被除数

### 3. 存储系统

- **层次结构**：寄存器 → Cache → 主存 → 辅存；速度容量价格反比
- **Cache 映射**：直接、全相联、组相联；替换 LRU；写策略（写回/写通）
- **地址映射**：主存地址 = Tag + Index + Offset；命中率公式
- **虚拟存储**：页表基址寄存器 PTBR；快表缺失两级页表
- **易错**：Cache 行大小 64 B → Offset 6 位；组相联路数 2^Index

### 4. 指令系统

- **指令格式**：定长/变长；操作码扩展技术
- **寻址方式**：立即、直接、间接、寄存器、相对、基址、变址
- **CISC vs RISC**：指令条数、周期数 CPI 比较
- **易错**：相对寻址 PC+Offset；基址与变址区别"谁可变"

### 5. CPU 结构与流水线

- **五段流水**：IF-ID-EX-MEM-WB；数据相关 RAW/WAR/WAW；控制相关
- **冒险解决**：前递（forwarding）、气泡（bubble）、延迟分支
- **超标量**：多发射端口；动态调度 Tomasulo
- **易错**：流水线时钟周期 = 最慢段延时；吞吐率公式

## 三、计算机网络 Computer Networks (CN)

### 1. 网络分层模型

| 模型 | 层数 | 分层 |
|------|------|------|
| OSI 七层 | 7 | 物理层、数据链路层、网络层、传输层、会话层、表示层、应用层 |
| TCP/IP 四层 | 4 | 网络接口层、网络层、传输层、应用层 |

- **PDU 名称**：比特（物理层）、帧（数据链路层）、包（网络层）、段（传输层）、数据（应用层）
- **封装与解封装**：每层加首部；MTU 1500 B

### 2. 数据链路层

- **成帧**：字符计数、字节填充、比特填充 HDLC
- **差错控制**：CRC-32 多项式模 2 除；ARQ（停等、GBN、SR）
- **流量控制**：滑动窗口大小 = 2ⁿ−1；信道利用率 U = 1/(1+2a)
- **MAC 协议**：CSMA/CD 冲突检测；CSMA/CA 无线；二进制指数退避
- **以太网帧格式**：7B 前导 + 1B 定界 + 14B 首部 + 46-1500B 数据 + 4B CRC
- **易错**：CRC 校验和不能纠错；CSMA/CD 最小帧长 64 B

### 3. 网络层

| 主题 | 核心内容 |
|------|----------|
| IP 地址 | IPv4 32 位点分十进制；子网掩码与 CIDR /24 |
| 路由算法 | 距离向量 RIP（最大跳数 15）、链路状态 OSPF、路径向量 BGP |
| NAT | 私有地址 192.168.x.x；端口映射 PAT |
| ICMP | ping 回显请求/应答；Traceroute TTL 递增 |
| IPv6 | 128 位，冒号十六进制，零压缩 |

- **易错**：子网划分借位后主机位 = 32−掩码；全 0 全 1 地址不可用

### 4. 运输层

| 协议 | 特点 | 首部 | 典型应用 |
|------|------|------|----------|
| UDP | 无连接、不可靠 | 8 B | DNS、DHCP、流媒体 |
| TCP | 可靠传输、面向连接 | 20-60 B | HTTP、FTP、SMTP |

- **TCP 核心机制**：三次握手、四次挥手、流量控制（滑动窗口）、拥塞控制（慢开始、拥塞避免、快重传、快恢复）
- **序号与确认号**：SYN=1 消耗一个序号；RTT 估算 Karn 算法
- **易错**：TCP 窗口大小单位字节；慢开始阈值 ssthresh 减半

### 5. 应用层

| 协议 | 端口 | 说明 |
|------|------|------|
| HTTP | 80 | 请求报文结构、状态码 1xx-5xx |
| HTTPS | 443 | HTTP + TLS 加密握手 |
| DNS | 53 (UDP) | 递归查询、迭代查询；A 记录、CNAME、MX |
| FTP | 21(控制) / 20(数据) | 控制连接与数据连接分离 |
| SMTP | 25/587 | 邮件发送协议 |
| POP3 | 110 | 邮件接收协议 |
| IMAP | 143 | 邮件接收协议（支持在线操作） |

- **易错**：HTTPS 在 TCP 之上；DNS 基于 UDP 53

## 四、数据结构与算法 Data Structure & Algorithm (DSA)

### 1. 线性结构

| 结构 | 特点 | 核心操作复杂度 |
|------|------|----------------|
| 数组 | 随机访问 O(1)，插入/删除 O(n) | 动态数组扩容 ×2 |
| 链表 | 单链表、双链表、循环链表 | 哨兵节点简化边界 |
| 栈 | 后进先出 LIFO | 括号匹配、表达式求值、单调栈 |
| 队列 | FIFO | 普通队列、循环队列、双端队列 |

- **易错**：链表空指针；队列判空/判满 (rear+1)%size == front

### 2. 树与二叉树

- **遍历**：前序、中序、后序、层序；递归 + 迭代栈
- **二叉搜索树**：插入、删除、查找 O(h)；极端退化链表
- **平衡树**：AVL 旋转（LL/LR/RL/RR）；红黑树五特性
- **堆**：大顶堆、小顶堆；建堆 O(n)，堆排序 O(n log n)
- **Trie 树**：字符串前缀统计；压缩 Trie 基数树
- **易错**：递归深度导致栈溢出；AVL 删除后回溯平衡因子

### 3. 图

- **存储**：邻接矩阵 O(n²)、邻接表 O(n+e)
- **遍历**：DFS 栈/递归，BFS 队列；拓扑排序（入度表）
- **最短路径**：Dijkstra（非负权）、SPFA（可负权）、Floyd 多源
- **最小生成树**：Prim 加点、Kruskal 加边并查集
- **关键路径**：AOE 网最长路径；拓扑 + 动态规划
- **易错**：DFS 判环需三色标记；Dijkstra 不能有负权

### 4. 哈希与字符串

- **哈希函数**：除留余数法、MAD、随机数法
- **冲突解决**：链地址、开放寻址
- **字符串匹配**：BF、KMP next 数组、BM Sunday
- **易错**：哈希表装载因子 > 0.75 需扩容；KMP next[-1] = -1 边界

### 5. 查找与排序

**查找算法：** 顺序、折半、插值、斐波那契、分块、哈希

**排序复杂度口诀：**

```
O(n log n)   快归堆
O(n²)        插冒选
O(n)         基数桶
```

| 排序算法 | 平均时间复杂度 | 空间复杂度 | 稳定性 |
|----------|---------------|-----------|--------|
| 快排 | O(n log n) | O(log n) | 不稳定 |
| 归并排序 | O(n log n) | O(n) | 稳定 |
| 堆排序 | O(n log n) | O(1) | 不稳定 |
| 插入排序 | O(n²) | O(1) | 稳定 |
| 冒泡排序 | O(n²) | O(1) | 稳定 |
| 选择排序 | O(n²) | O(1) | 不稳定 |

- **易错**：快排 pivot 选首元素最坏 O(n²)；归并空间 O(n)

### 6. 动态规划

| 类型 | 经典问题 |
|------|----------|
| 背包 DP | 0-1、完全、多重、分组 |
| 区间 DP | 石子合并、矩阵连乘 |
| 线性 DP | LIS、LCS、编辑距离 |
| 树形 DP | 树上最大独立集、换根 DP |

- **易错**：状态未包含全部维度；边界初始化 0/-∞ 错用

### 7. 贪心与分治

- **贪心**：活动安排、Huffman 编码、Prim/Kruskal
- **分治**：归并排序、快速幂、棋盘覆盖、最近点对
- **易错**：贪心需证明最优子结构；分治递归出口漏写

### 8. 高级主题

- **并查集**：路径压缩 + 按秩合并；带权并查集判奇环
- **线段树**：点更新、区间更新 lazy tag；离散化
- **树状数组**：单点更新区间求和；二维树状数组
- **易错**：线段树区间 [l, r] 闭区间；lazy tag 下传顺序

## 附：易错速记口诀

```
OS：  互斥占有非剥夺，循环等待死锁决。
CO：  补码加减溢位看最高进位异或。
CN：  三次握手 SYN-SYN/ACK-ACK，四次挥手 FIN-ACK-FIN-ACK。
DSA： 快排不稳归并稳，哈希冲突链开放。
```

1. **考研/软考**：按模块做思维导图 → 刷真题 → 对照口诀查漏补缺。
