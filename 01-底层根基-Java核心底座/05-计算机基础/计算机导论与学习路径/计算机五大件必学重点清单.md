## 一、计算机网络（后端最重要）

> 没有之一。只学这些，别的全放掉。

1. **TCP/IP 四层模型**（应用/传输/网络/链路）
2. **TCP**
   - 三次握手、四次挥手（必须能画、能讲）
   - 滑动窗口、拥塞控制（简单理解即可）
3. **HTTP / HTTPS**
   - GET/POST 区别
   - 状态码 200/301/302/400/401/403/404/500
   - HTTPS 加密流程（非对称 + 对称）
4. **DNS、Cookie/Session、Token**
5. **常见网络问题**
   - 跨域 CORS
   - 长连接、短连接
   - 超时、重传、重试

> **目标**：能讲清一次 HTTP 请求完整流程。

## 二、操作系统（后端高频）

> 只学重点。

| 重点 | 关键内容 |
|------|----------|
| 进程 vs 线程 | 必问考点 |
| 线程状态、锁、死锁 | 四大条件、死锁预防 |
| 内存管理 | 堆、栈、虚拟内存；JVM 内存结构（和 Java 强相关） |
| I/O 模型 | BIO / NIO / AIO；阻塞/非阻塞；同步/异步 |
| Linux 基础命令 | `ps`、`top`、`netstat`、`grep`、`find`、`chmod`、`curl` |

> **目标**：能解释清楚 Java 多线程为什么安全/不安全。

---

## 三、数据结构与算法（面试核心）

> 只学高频 15 个，足够应付 90% 面试。

1. **数组、链表、栈、队列**
2. **二叉树**、前/中/后序遍历
3. **哈希表**（HashMap 原理）
4. **堆**（优先队列）
5. **排序**：快排、归并、冒泡（理解思想）
6. **常见算法题模板**
   - 双指针
   - 滑动窗口
   - BFS / DFS
   - 动态规划（简单题即可）
   - 二分查找

> **目标**：LeetCode 简单题 + 中等题能写出来。

---

## 四、计算机组成原理（后端几乎不学）

> 真的只学这两个就够。

| 重点 | 说明 | 学习目标 |
|------|------|----------|
| CPU 缓存、缓存一致性 | 面试偶尔问 | 知道"为什么 volatile 能禁止指令重排"即可 |
| 大小端、内存对齐 | 底层概念了解 | 理解基本概念 |

---

## 五、数据库（Java 后端吃饭家伙）

> 必须精通，比语言还重要。

1. **SQL 语句**：`SELECT` / `JOIN` / 子查询 / 索引
2. **索引原理**：B+ 树、最左匹配、回表、覆盖索引
3. **事务**：ACID、隔离级别
4. **锁机制**：行锁、表锁、间隙锁
5. **慢查询优化、分库分表**（了解）

> **目标**：能独立写复杂查询，能讲清索引为什么快。

## 时间来不及的终极优先级

| 优先级 | 模块 | 原因 |
|--------|------|------|
| 1（最重要） | 计算机网络 | 必须最先学 |
| 2 | 数据库 | 必须精通 |
| 3 | 数据结构与算法 | 必须刷 |
| 4 | 操作系统 | 重点学线程、内存、IO |
| 5（次重要） | 计算机组成原理 | 随便看看就行 |

## 2 个月突击路线

> 每天 2 小时，足够吊打大部分校招。

| 时间段 | 学习内容 |
|--------|----------|
| 第 1 个月 | 网络 + 数据库 |
| 第 2 个月 | 算法 + 操作系统 |
