# 计算机导论：后端必备基础

## 一、操作系统

### 1. 进程与线程

| 维度 | 核心概念 | 后端关联 |
|------|----------|----------|
| 进程与线程 | 进程（资源分配的基本单位）、线程（CPU 调度的基本单位） | Java 多线程编程（Thread、线程池） |
| 进程间通信（IPC） | 管道、消息队列、共享内存 | 分布式系统中的进程协作 |
| 线程同步 | 互斥锁、信号量、synchronized / Lock 原理 | Tomcat 线程模型 |

### 2. 内存管理

| 核心概念 | 后端关联 |
|----------|----------|
| 内存分区（栈、堆、方法区） | JVM 内存模型（堆、栈、元空间） |
| 虚拟内存、内存分页/分段 | 垃圾回收机制 |
| 内存泄漏与溢出 | 防止程序内存溢出的代码编写 |

### 3. I/O 模型

| 模型 | 说明 | 后端关联 |
|------|------|----------|
| BIO | 同步阻塞 | 传统 Java IO |
| NIO | 同步非阻塞 | Java NIO 编程、Netty 框架原理 |
| AIO | 异步非阻塞 | 高并发服务的 IO 模型选型 |

### 4. 文件系统

| 核心概念 | 后端关联 |
|----------|----------|
| 文件目录结构、文件权限 | 日志文件读写 |
| 磁盘 IO 原理 | 配置文件加载、Linux 服务器上的文件操作 |

## 二、计算机网络

### 1. TCP/IP 协议簇

| 核心概念 | 后端关联 |
|----------|----------|
| 四层模型（应用层/传输层/网络层/网络接口层） | 理解网络通信的底层流程 |
| IP 地址与子网划分 | 排查跨服务器调用的网络问题 |
| ARP 协议（IP 转 MAC）、ICMP 协议（网络诊断） | 网络故障诊断 |

### 2. 传输层协议

| 协议 | 核心机制 | 后端关联 |
|------|----------|----------|
| TCP | 三次握手、四次挥手、可靠传输、流量控制、拥塞控制 | HTTP 基于 TCP 的原理、RPC 框架的传输协议选择 |
| UDP | 无连接、不可靠、低延迟 | 即时通讯功能的 UDP 应用 |

### 3. 应用层协议

| 协议 | 核心内容 | 后端关联 |
|------|----------|----------|
| HTTP/HTTPS | 请求/响应结构、状态码、请求头、HTTPS 加密原理 | 接口开发（RESTful API）、HTTPS 配置 |
| DNS | 域名解析 | 网关的协议转发 |
| FTP / SMTP | 文件传输、邮件传输 | Cookie/Session 会话管理 |

### 4. 网络编程

| 核心概念 | 后端关联 |
|----------|----------|
| Socket 套接字 | 理解 Java Socket 编程 |
| TCP 服务端/客户端通信流程 | 框架底层的网络通信实现 |

## 三、数据结构与算法

### 1. 基础数据结构

| 类别 | 结构 | 后端关联 |
|------|------|----------|
| 线性结构 | 数组、链表（单链表/双向链表/循环链表）、栈、队列、哈希表（哈希函数、冲突解决） | Java 集合框架底层（ArrayList、LinkedList、HashMap） |
| 非线性结构 | 树（二叉树、二叉搜索树、红黑树、B 树/B+ 树）、图（邻接矩阵/邻接表） | MySQL 索引的 B+ 树原理 |

### 2. 核心算法

| 类别 | 算法 | 后端关联 |
|------|------|----------|
| 排序算法 | 冒泡排序、快速排序、归并排序、堆排序（时间/空间复杂度、稳定性） | 业务代码中的逻辑优化 |
| 查找算法 | 顺序查找、二分查找、哈希查找 | 接口性能优化 |
| 其他算法 | 递归、分治、动态规划、贪心算法、DFS/BFS、Dijkstra | 算法题刷题（面试必备） |

## 四、数据库原理

### 1. 关系型数据库核心

| 维度 | 核心概念 | 后端关联 |
|------|----------|----------|
| 关系模型 | 表、行、列、主键/外键 | MySQL 表设计 |
| 索引 | 聚簇索引/非聚簇索引 | SQL 优化 |
| 事务 | ACID 特性、隔离级别（读未提交、读已提交、可重复读、串行化） | 事务处理、解决幻读/脏读问题 |
| 锁机制 | 行锁/表锁 | 并发控制 |

### 2. 数据库存储与查询

| 核心概念 | 后端关联 |
|----------|----------|
| SQL 执行计划、查询优化器 | 慢查询优化 |
| 分库分表、读写分离 | 分布式数据库的设计 |
| MyBatis 动态 SQL | 执行原理 |

### 3. 非关系型数据库原理

| 维度 | 核心内容 | 后端关联 |
|------|----------|----------|
| NoSQL 分类 | 键值型/文档型/列族型/图型 | Redis 缓存设计 |
| Redis 持久化 | RDB / AOF | 缓存淘汰策略 |
| 缓存问题 | 缓存穿透/击穿/雪崩 | 缓存方案设计 |
