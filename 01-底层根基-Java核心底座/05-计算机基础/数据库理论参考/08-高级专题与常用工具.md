## 1. 特种数据库

### 1.1 时空数据库

处理时间和空间维度数据的数据库：

| 数据类型 | 示例 | 使用场景 |
|----------|------|----------|
| 空间数据 | 坐标、区域、多边形 | GIS 地图、位置服务 |
| 时间数据 | 时间序列、时间区间 | 股票、监控日志 |
| 时空数据 | 移动轨迹（位置+时间） | 物流跟踪、出行记录 |

**空间索引**：R 树、四叉树、网格索引。

```sql
-- MySQL 空间扩展
SELECT * FROM places WHERE ST_Distance_Sphere(point, ST_GeomFromText('POINT(116.4 39.9)')) < 1000;
```

### 1.2 基于对象的数据库

将面向对象编程的概念融入数据库：

| 特性 | 说明 | 示例 |
|------|------|------|
| 用户自定义类型 | 定义复杂数据类型 | `CREATE TYPE Address AS (street, city, zip)` |
| 方法 | 类型关联的方法 | `type.getName()` |
| 继承 | 类型之间的继承关系 | `Student IS UNDER Person` |
| 引用 | 对象之间的引用 | `REF` 类型 |

### 1.3 XML 数据库

处理 XML 数据的数据库：

```sql
-- MySQL XML 函数
SELECT ExtractValue(xml_data, '/book/title') FROM books;
```

### 1.4 信息检索与全文搜索

| 概念 | 说明 |
|------|------|
| 倒排索引 | 单词 → 文档列表的映射，搜索引擎的核心 |
| TF-IDF | 词频-逆文档频率，衡量单词在文档中的重要程度 |
| 相似度度量 | Cosine 相似度、Jaccard 相似度 |

```sql
-- MySQL 全文搜索
SELECT * FROM articles WHERE MATCH(title, content) AGAINST('database' IN NATURAL LANGUAGE MODE);
```

## 2. 数据仓库与数据挖掘

### 2.1 数据库 vs 数据仓库

| 维度 | 数据库（OLTP） | 数据仓库（OLAP） |
|------|---------------|-----------------|
| 用途 | 日常业务处理 | 数据分析、决策支持 |
| 操作 | 大量小事务（增删改查） | 大批量数据加载、复杂查询 |
| 数据 | 最新的当前数据 | 历史数据、汇总数据 |
| 设计 | E-R 模型、3NF | 星型/雪花型模型、维度建模 |
| 典型操作 | INSERT/UPDATE/DELETE | SELECT、聚合、分析 |

### 2.2 数据仓库架构

```
数据源（OLTP 系统） → ETL（抽取/转换/加载） → 数据仓库 → OLAP 分析 → 报表/仪表盘
```

| 组件 | 说明 |
|------|------|
| ETL | 从源系统抽取数据，清洗转换后加载到数据仓库 |
| 数据立方体 | 多维数据模型（如按时间+产品+地区的销售分析） |
| 数据挖掘 | 从大量数据中发现隐藏的模式和知识 |

### 2.3 数据挖掘任务

| 任务 | 说明 | 示例 |
|------|------|------|
| 分类 | 将数据分为预定义的类别 | 邮件分类（垃圾/正常） |
| 聚类 | 将数据分为未知的组别 | 用户分群 |
| 关联规则 | 发现数据之间的关联关系 | "买了尿布的人也买了啤酒" |
| 异常检测 | 发现不符合预期模式的异常数据 | 信用卡欺诈检测 |

// 1. 加载驱动（JDBC 4.0+ 自动注册）

## 4. DBeaver 使用指南

### 4.1 简介

DBeaver 是一款**免费、开源、跨平台**的通用数据库管理工具，支持 MySQL、PostgreSQL、Oracle、SQL Server 等几乎所有主流数据库。

### 4.2 安装

1. 从 [dbeaver.io](https://dbeaver.io) 下载（Community 版免费）
2. 选择对应操作系统版本（Windows → exe、macOS → dmg、Linux → tar.gz）
3. 默认安装即可

### 4.3 连接 MySQL

1. 打开 DBeaver → 数据库 → 新建连接 → 选择 MySQL
2. 填写主机（localhost）、端口（3306）、数据库名、用户名、密码
3. 测试连接 → 完成

### 4.4 常用功能

| 功能 | 操作 | 说明 |
|------|------|------|
| SQL 编辑器 | 右键数据库 → SQL 编辑器 | 编写和执行 SQL |
| 查看表数据 | 右键表 → 查看数据 | 快速浏览表内容 |
| ER 图 | 右键数据库 → 查看 ER 图 | 可视化数据库结构 |
| 导入/导出 | 右键数据库 → 导出数据 | 备份或迁移数据 |
| 执行计划 | 在 SQL 前加 `EXPLAIN` | 分析查询性能 |

## 5. Navicat 使用指南

### 5.1 简介

Navicat 是一款**商业级**数据库管理工具，提供更友好的图形界面和更丰富的功能。支持 MySQL、PostgreSQL、Oracle、SQL Server、Redis 等。

### 5.2 连接 MySQL

1. 连接 → MySQL → 填写连接信息（主机/端口/用户名/密码）
2. 测试连接 → 确定

### 5.3 常用功能

| 功能 | 说明 |
|------|------|
| 数据传输 | 在不同数据库之间迁移数据 |
| 数据同步 | 保持两个数据库的数据一致性 |
| 查询创建工具 | 可视化构建 SQL 查询 |
| 备份/恢复 | 定期备份数据库 |
| 模型设计 | 可视化设计 E-R 图 |
| 报表生成 | 生成数据库报告 |

## 6. 常用 SQL 语句速查

```sql
-- 数据库管理
CREATE DATABASE db_name CHARACTER SET utf8mb4;
DROP DATABASE db_name;
USE db_name;

-- 表管理
CREATE TABLE t (id INT PRIMARY KEY, name VARCHAR(50));
ALTER TABLE t ADD COLUMN age INT;
DROP TABLE t;

-- CRUD
INSERT INTO t (id, name) VALUES (1, 'Alice'), (2, 'Bob');
SELECT * FROM t WHERE id = 1;
UPDATE t SET name = 'Charlie' WHERE id = 1;
DELETE FROM t WHERE id = 1;

-- 聚合
SELECT COUNT(*), AVG(age), MAX(salary) FROM employees;

-- JOIN
SELECT a.*, b.* FROM a LEFT JOIN b ON a.id = b.a_id;

-- 窗口函数
SELECT ROW_NUMBER() OVER (PARTITION BY dept ORDER BY salary DESC) FROM emp;

-- 索引
CREATE INDEX idx_name ON t(name);
DROP INDEX idx_name ON t;

-- 用户与权限
CREATE USER 'user'@'localhost' IDENTIFIED BY 'pass';
GRANT SELECT ON db.* TO 'user'@'localhost';
FLUSH PRIVILEGES;
```

> 🎯 **工具是辅助，SQL 是核心**——再好的可视化工具也不能替代扎实的 SQL 功底。
