## 4. 核心概念速查

| 术语 | 含义 |
|------|------|
| **CIA 三要素** | Confidentiality(机密性)、Integrity(完整性)、Availability(可用性) |
| **AAA** | Authentication(认证)、Authorization(授权)、Auditing(审计) |
| **PKI** | Public Key Infrastructure，公钥基础设施 |
| **TLS** | Transport Layer Security，传输层安全协议 |
| **OAuth 2.0** | 授权框架，允许第三方应用获取有限访问权限 |
| **SDL** | Security Development Lifecycle，安全开发生命周期 |
