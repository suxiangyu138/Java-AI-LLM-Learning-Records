## 1. 渗透测试方法论

```text
PTES (Penetration Testing Execution Standard) 七阶段：

1. 前期交互   → 确定范围、规则、授权（必须合法！）
2. 信息收集   → 域名/DNS/子域名/端口/服务版本
3. 威胁建模   → 分析攻击路径，确定优先级
4. 漏洞分析   → 扫描已知漏洞，验证可利用性
5. 漏洞利用   → 获取访问权限（shell/控制台）
6. 后渗透     → 提权、横向移动、数据窃取（权限范围内）
7. 报告       → 漏洞列表 + 风险评级 + 修复建议
```

## 2. 信息收集

```bash
# 被动信息收集（不直接接触目标）
whois example.com                    # 域名注册信息
dig example.com ANY                  # DNS 记录
shodan search "org:target"           # 互联网设备扫描
crt.sh → %.example.com              # 证书透明度日志 → 子域名

# 主动信息收集（直接探测目标）
# ⚠️ 仅对授权目标！
nmap -sV -sC target.com              # 端口扫描 + 服务版本
nmap -p- --min-rate=1000 target.com  # 全端口快速扫描
dirb http://target.com /usr/share/wordlists/dirb/common.txt  # 目录枚举
nikto -h http://target.com           # Web 服务器漏洞扫描
```

## 3. 常用工具速查

| 工具 | 用途 | 关键命令 |
|------|------|---------|
| **nmap** | 端口扫描 | `nmap -sV -sC -p- target` |
| **Burp Suite** | Web 渗透测试 | 拦截/修改 HTTP 请求 |
| **OWASP ZAP** | Web 漏洞扫描（免费） | 自动化扫描 + 爬虫 |
| **Metasploit** | 漏洞利用框架 | `search exploit`, `use`, `set RHOSTS` |
| **sqlmap** | SQL 注入自动化 | `sqlmap -u "url" --dbs` |
| **Hydra** | 暴力破解 | `hydra -l admin -P pass.txt ssh://target` |
| **John** | 密码破解 | `john --wordlist=rockyou.txt hash.txt` |
| **Wireshark** | 网络抓包分析 | 查看明文协议（HTTP/FTP） |

### Burp Suite 核心操作

```text
Burp Suite 测试流程：
1. 配置浏览器代理 → 127.0.0.1:8080
2. Proxy → Intercept → 拦截请求 → 修改参数
3. Repeater → 手动修改+重放请求
4. Intruder → 自动化爆破（参数/目录/密码）
5. Scanner → 自动漏洞扫描
```

## 4. 防御视角

```text
从攻击者视角看防御：

攻击者的路径：
  信息收集 → 寻找弱点 → 漏洞利用 → 提权 → 持久化

防御者的对策：
  1. 减少攻击面：关闭不用端口、隐藏服务版本信息
  2. 增加攻击成本：WAF + IDS/IPS + 蜜罐
  3. 快速检测：日志监控 + 异常行为告警
  4. 限制损害范围：最小权限 + 网络隔离

红队 vs 蓝队 vs 紫队：
  红队 = 攻击方（模拟真实攻击）
  蓝队 = 防御方（检测+响应）
  紫队 = 红蓝协作（攻防一体，共同改进）
```

## 核心要点回顾

- 渗透测试必须授权！未经授权的测试 = 违法行为
- 信息收集占 60% 的时间（找弱点最关键的阶段）
- Burp Suite = Web 渗透第一工具
- 防御思路 = 减少攻击面 + 增加成本 + 快速检测 + 限制损害
- 最好的防御培训 = 自己去做一次渗透测试
