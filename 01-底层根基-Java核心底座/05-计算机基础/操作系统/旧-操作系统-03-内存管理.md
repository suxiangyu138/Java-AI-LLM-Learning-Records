# 内存管理

## 📌 课程定位
内存管理是OS最精巧的设计之一——虚拟内存让你同时跑几十个程序而不担心地址冲突。malloc底层、OOM、JVM GC、Redis内存淘汰……都建立在这套机制上。

## 🎯 核心章节

### 1. 内存管理基础
- **逻辑地址 vs 物理地址**：程序用逻辑地址(虚拟地址)，运行时由MMU翻译为物理地址
- **程序装入**：绝对装入、可重定位装入（静态重定位）、动态运行时装入（动态重定位）
- **链接方式**：静态链接、装入时动态链接、运行时动态链接（DLL/.so）

### 2. 连续分配方式
- **单一连续分配**：内存分系统区和用户区，只存一个用户程序
- **固定分区**：预先划分固定大小的分区——内部碎片
- **动态分区**：按需分配——外部碎片
  - 分配算法：首次适应(First Fit)、最佳适应(Best Fit)、最坏适应(Worst Fit)、邻近适应(Next Fit)
  - 碎片解决：紧凑/压缩(Compaction)

### 3. 离散分配——分页（⭐ 现代OS主流）
- **基本思想**：逻辑空间分页、物理空间分帧（页框），页可映射到任意帧
- **地址结构**：`[页号P | 页内偏移W]`
- **页表**：每个进程一张，存页号→帧号的映射
- **地址转换（必会计算）**：
  1. 虚拟地址A，页大小L → 页号P = A/L，偏移W = A%L
  2. 查页表→帧号F
  3. 物理地址 = F×L + W
- **快表TLB**：页表的硬件缓存，命中率通常>99%
- **多级页表**：减少页表本身的连续内存占用（页表本身也分页存放）
- **页大小权衡**：小页→内部碎片小但页表大；大页→页表小但内部碎片大。典型4KB

### 4. 离散分配——分段
- **按逻辑单元分段**：代码段、数据段、栈段各有自己的段
- **段表**：段号→段长+段基址
- **分页 vs 分段**：分页对程序员透明（提高内存利用率），分段按逻辑划分（方便共享和保护）
- **段页式**：先分段，每段内部分页——Intel x86采用

### 5. 虚拟内存（⭐ 重点）
- **思想**：程序不需要全部装入内存就能运行——只装入当前需要的部分
- **局部性原理**：时间局部性 + 空间局部性 → 虚拟内存可行
- **请求分页**：需要时加载页面，可能触发缺页中断

### 6. 页面置换算法（⭐ 必掌握所有算法）
- **OPT（最佳置换）**：淘汰未来最长时间不用的页——理论最优，无法实现
- **FIFO**：淘汰最先进入的页——Belady异常（分配的帧多反而缺页更多？有可能！）
- **LRU（最近最久未使用）**：淘汰最长时间没被访问的——接近OPT但实现成本高
- **Clock / NRU（时钟算法）**：访问位+修改位，指针循环扫描——Linux实际使用
- **改进Clock**：先淘汰(0,0)→再(0,1)→回到(0,0)，给修改过的页一次机会

### 7. 内存分配与回收
- **buddy system（伙伴系统）**：Linux内核的内存分配基础——2的幂次分配，合并相邻空闲块
- **slab分配器**：内核对象缓存，减少频繁分配释放的开销
- **malloc/free 用户态实现**：brk()（小块内存）、mmap()（大块内存）

## ✅ 学习建议
- 地址转换计算题必须熟练（虚拟地址→物理地址，给定页表）
- LRU和Clock算法的流程能画图讲解
- 结合Linux命令实践：`free -h`、`cat /proc/meminfo`、`vmstat` 查看内存使用
