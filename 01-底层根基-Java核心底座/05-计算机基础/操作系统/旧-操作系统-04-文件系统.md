# 文件系统

## 📌 课程定位
文件系统是数据的"永久之家"。理解inode、目录结构、文件分配方式，是数据库设计、存储系统开发的后端基础。ext4、NTFS、FAT32的区别不只是名字。

## 🎯 核心章节

### 1. 文件与文件系统基础
- **文件属性**：名称、类型、大小、位置（路径）、保护信息、时间戳
- **文件操作**：create、open、read、write、lseek（定位）、close、delete
- **文件类型**：普通文件、目录文件、设备文件（块/字符）、管道、符号链接

### 2. 文件的逻辑结构与物理结构
- **逻辑结构**：无结构(流式文件，Unix一切皆文件) vs 有结构(记录式文件)
- **物理结构（⭐ 核心）**：
  - **连续分配**：文件在磁盘上连续存放——读取快但外部碎片严重，CD-ROM采用
  - **链接分配**：每个块存下一块的指针——无外部碎片但随机访问慢
    - FAT（文件分配表）：把指针集中管理——MS-DOS/Windows FAT32
  - **索引分配**：每个文件一个索引块，存所有数据块指针——Unix/Linux inode设计
    - 多级索引：直接块→一级间接→二级间接→三级间接（兼顾小文件和大文件）

### 3. 目录管理
- **目录本质**：目录文件 = 文件名→文件控制块(FCB/inode号)的映射表
- **目录结构**：单级→两级→树形(多级)→无环图(共享文件/硬链接)
- **硬链接 vs 软链接（符号链接）**：
  | 硬链接 | 软链接 |
  |--------|--------|
  | 同inode，同文件 | 不同inode，存目标路径 |
  | 不能跨文件系统 | 可以跨文件系统 |
  | 不能链接目录 | 可以链接目录 |
  | ln file link | ln -s file link |

### 4. 文件存储空间管理
- **空闲表法**（连续空闲块）
- **空闲链表法**（成组链接法——Unix采用）
- **位示图法**：每个块用1位标记空闲/占用——简单高效
- **超级块**：存文件系统元信息（总块数、空闲块数、inode数等）

### 5. 文件系统层次结构
```
用户接口（open/read/write等系统调用）
    ↓
文件目录系统（目录查找、路径解析）
    ↓
存取控制模块（权限检查）
    ↓
逻辑文件系统（文件逻辑块号→物理块号）
    ↓
物理文件系统（磁盘驱动）
```
- **VFS（虚拟文件系统）**：Linux支持多种文件系统的关键——提供统一接口层

### 6. 磁盘调度算法
- **FCFS**：按请求顺序
- **SSTF（最短寻道时间优先）**：离当前磁头最近的先服务——可能饥饿
- **SCAN（电梯算法）**：来回扫描，遇到请求就服务
- **C-SCAN**：单向扫描，到头后快速回起点的过程中不服务
- **LOOK/C-LOOK**：SCAN的优化——不到最边缘，到最远请求处就折返

## ✅ 学习建议
- 重点理解 inode 的设计（直接块+多级间接块）——兼顾存储效率和访问速度
- 动手操作：`ls -li` 查看inode号，`ln` 创建硬链接观察相同inode号
- 磁盘调度算法了解即可——现代存储用SSD无需寻道，SCAN等逐渐退出历史
