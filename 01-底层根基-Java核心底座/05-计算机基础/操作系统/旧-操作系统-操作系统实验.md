# 操作系统实验

## 课程概述
- **课程性质**：专业核心必修课（配套实验课）
- **适用专业**：计算机类各专业
- **开课学期**：与操作系统理论课同步
- **考核方式**：实验报告 + 上机考核 + 综合项目

## 核心知识点

### 实验一：Linux系统调用
- 文件I/O系统调用
  - open：打开/创建文件，返回文件描述符fd（-1表示失败）
    - 标志：O_RDONLY(只读)、O_WRONLY(只写)、O_RDWR(读写)、O_CREAT(创建)、O_APPEND(追加)、O_TRUNC(截断)
    - 权限：S_IRUSR|S_IWUSR|S_IRGRP|S_IROTH（八进制0644）
  - read：ssize_t read(int fd, void *buf, size_t count)，返回实际读取字节数（0=EOF）
  - write：ssize_t write(int fd, const void *buf, size_t count)，返回实际写入字节数
  - close：关闭文件描述符，释放内核资源
  - lseek：移动文件偏移量（SEEK_SET/SEEK_CUR/SEEK_END）
  - stat/fstat：获取文件元信息（大小、权限、修改时间、inode号）
- 目录操作
  - opendir/readdir/closedir：遍历目录项
  - getcwd/chdir：获取/改变当前工作目录
  - mkdir/rmdir：创建/删除目录
- 实验：实现文件拷贝程序(类似cp命令)，支持大文件和错误处理

### 实验二：进程管理
- 进程创建与执行
  - fork()：创建子进程
    - 父进程fork返回子进程PID（>0），子进程fork返回0
    - 子进程是父进程的几乎完整复制（代码段、数据段、堆栈、打开的文件描述符等）
    - 写时复制(Copy-on-Write)：fork时不立即复制内存，父子共享页面标记为只读，写入时触发缺页复制
    - fork失败返回-1（如进程数达上限）
  - exec系列函数：替换当前进程的映像
    - execl/execlp/execle：参数以变参形式传递，l=list
    - execv/execvp/execve：参数以数组形式传递，v=vector
    - p后缀：在PATH中搜索可执行文件
    - e后缀：可指定环境变量
    - exec成功后不返回，失败返回-1
  - wait/waitpid：等待子进程结束
    - wait(&status)：等待任意子进程，阻塞
    - waitpid(pid, &status, options)：等待指定PID，支持非阻塞(WNOHANG)
    - 宏WIFEXITED(status)/WEXITSTATUS(status)/WIFSIGNALED(status)解析status
- 孤儿进程与僵尸进程
  - 孤儿进程：父进程先于子进程退出，子进程被init(pid=1)收养
  - 僵尸进程：子进程已退出但父进程未调用wait回收，PCB残留在进程表中
  - 危害：僵尸进程占用PID和少量内核资源，大量僵尸会导致无法创建新进程
  - 处理：父进程调用wait或signal(SIGCHLD, SIG_IGN)忽略子进程退出信号
- 守护进程(daemon)
  - fork后父进程退出→子进程setsid创建新会话→再次fork确保脱离终端→chdir到根目录→重定向标准IO到/dev/null

### 实验三：进程通信(IPC)
- 管道(Pipe)
  - 无名管道：int pipe(int fd[2])，fd[0]读端，fd[1]写端，仅限父子/兄弟进程
  - 阻塞特性：读空管道→读端阻塞；写满管道→写端阻塞（管道容量通常64KB）
  - 管道破裂：所有写端关闭→读端read返回0
  - 命名管道(FIFO)：mkfifo()创建，通过文件路径通信，任意进程可访问
- 共享内存
  - shmget(key, size, IPC_CREAT|0666)：创建或获取共享内存段
  - shmat(shmid, addr, 0)：将共享内存附加(映射)到进程地址空间
  - shmdt(addr)：解除映射
  - shmctl(shmid, IPC_RMID, NULL)：删除共享内存段
  - 优缺点：最快IPC方式（零拷贝），但需额外同步机制（信号量）
- 消息队列
  - msgget(key, IPC_CREAT|0666)：创建或获取消息队列
  - msgsnd(msgid, &msg, size, 0)：发送消息（按类型）
  - msgrcv(msgid, &msg, size, msgtype, 0)：接收指定类型的消息
  - 特性：消息有类型和边界，内核维护，支持优先级
- 信号(Signal)
  - 常见信号：SIGINT(Ctrl+C)、SIGTERM(终止)、SIGKILL(不可捕获/忽略的强制终止)、SIGSTOP(暂停)、SIGCHLD(子进程状态改变)、SIGALRM(定时器)、SIGSEGV(段错误)、SIGPIPE(写破裂管道)
  - signal(signum, handler)设置信号处理器
  - sigaction更可靠：可获取发送方信息，支持阻塞信号集
  - kill(pid, signum)：向指定进程发送信号

### 实验四：多线程与同步
- POSIX线程(pthread)
  - pthread_create(&tid, &attr, func, arg)：创建线程
  - pthread_join(tid, &retval)：等待线程结束并获取返回值
  - pthread_exit(retval)：线程退出
  - 线程与进程的区别：共享地址空间（堆、全局变量） vs 独立地址空间
- 互斥锁(Mutex)
  - pthread_mutex_init/lock/unlock/destroy
  - 解决临界区(Critical Section)互斥访问
  - 死锁的四条件和使用互斥锁时的注意事项
- 条件变量(Condition Variable)
  - pthread_cond_init/wait/signal/broadcast/destroy
  - pthread_cond_wait：原子地释放mutex并进入等待
  - 被signal唤醒后：重新获取mutex然后返回
  - 经典应用：生产者-消费者
    - 生产者：生产→lock→放入缓冲区→signal消费者→unlock
    - 消费者：lock→while(空)→wait→取出→unlock→消费
    - 注意用while而非if防止虚假唤醒
- 信号量(Semaphore)
  - sem_init(&sem, pshared, value)：初始化，value指定初始资源数
  - sem_wait(&sem)：P操作，value-1，value<0时阻塞
  - sem_post(&sem)：V操作，value+1，唤醒等待者
  - sem_destroy(&sem)：销毁信号量

### 实验五：内存管理模拟
- 页表地址转换模拟
  - 输入：16位逻辑地址（页号6位+页内偏移10位，页面大小1KB）
  - 页表：每个页表项包含物理页框号(~5位) + 有效位
  - TLB（快表）模拟：16个条目，相联存储，LRU替换
  - 转换过程：TLB命中→直接得物理地址；TLB未命中→查页表→更新TLB→得物理地址
  - 统计TLB命中率
- 页面置换算法模拟
  - 输入：页面访问序列（如 1,2,3,4,1,2,5,1,2,3,4,5），物理页框数(如3)
  - FIFO：队列维护进入顺序，替换队首页面
    - Belady异常：页框数增加缺页率反而可能增加
  - LRU（最近最久未使用）：
    - 精确实现：每次访问记录时间戳或维护链表（访问时移到表尾，替换时取表头）
  - OPT（最佳置换/未来最远）：理论上最优但无法实现，用于对比基准
  - 统计各算法的缺页率，分析页面访问序列的特征对算法性能的影响

### 实验六：文件系统模拟
- 磁盘模拟
  - 用大文件模拟磁盘：将文件按块(如512B/4KB)划分
  - 封装read_block(block_no)和write_block(block_no, data)
- 简易文件系统结构
  - 超级块（块0）：磁盘总块数、inode区起止、数据区起止、空闲块位图位置
  - inode区：每个inode含文件类型/大小/权限/数据块索引（直接+一级间接+二级间接）
  - 数据区：存储文件内容和目录项
- 实现操作
  - 创建文件：分配inode→写目录项→返回
  - 打开文件：查目录→读inode→建立打开文件表项
  - 读文件：inode→数据块索引→读块→返回数据
  - 写文件：分配新块（从空闲块位图找）→修改inode索引→写数据→更新inode大小
  - 删除文件：释放数据块→释放inode→删除目录项

### 实验七：Shell模拟器
- 命令解析
  - 分割命令：按空格分割，处理引号内的空格
  - 识别管道(|)和重定向(>、<、>>)
  - 识别后台运行(&)
- 内置命令（不需要fork）
  - cd：用chdir()改变当前目录
  - exit：退出Shell
  - help：列出支持的命令
- 外部命令执行
  - fork子进程 → execvp执行命令 → 父进程wait
  - 路径搜索：在PATH环境变量中的目录查找可执行文件
- 管道实现
  - pipe()创建管道 → fork两个子进程
  - 子进程1：将stdout重定向到管道写端(dup2) → exec左边命令
  - 子进程2：将stdin重定向到管道读端(dup2) → exec右边命令
  - 父进程关闭管道两端并wait两个子进程
- 重定向实现
  - >输出重定向(覆盖)：open文件O_WRONLY|O_CREAT|O_TRUNC → dup2使fd=1指向该文件
  - <输入重定向：open文件O_RDONLY → dup2使fd=0指向该文件
  - >>追加重定向：open文件O_WRONLY|O_CREAT|O_APPEND

## 重点难点
- **重点**：fork/exec/wait的正确使用、管道+重定向+进程组合、线程同步(PV操作/条件变量)
- **难点**：Shell中多管道+重定向的组合实现、死锁的预防和调试、文件系统的完整实现
