## 一、核心理论：操作系统虚拟化的本质

### 1.1 虚拟化的核心逻辑

```
物理硬件 → 虚拟化层（Hypervisor / 容器引擎）→ 虚拟环境
                ↓                    ↓
           资源抽象              环境隔离
```

### 1.2 硬件虚拟化 vs 容器虚拟化

| 对比维度 | 硬件虚拟化（VM） | 容器虚拟化（Docker） |
|----------|-----------------|---------------------|
| 虚拟化层位置 | 物理硬件之上 | 物理机 OS 之上，共享 OS 内核 |
| 隔离性 | **极强**（完全隔离） | 中等（共享内核） |
| 资源开销 | 大（需运行完整 OS） | **小**（仅包含应用及依赖） |
| 启动速度 | 慢（分钟级） | **快**（秒级） |
| 部署复杂度 | 高 | **低**（镜像打包，一键部署） |

### 1.3 Java 与虚拟化的关联

| 概念 | 说明 |
|------|------|
| **JVM** | 应用级虚拟机，解决 Java 跨平台问题 |
| **Docker/VM** | 系统级虚拟化，为 JVM 提供独立、一致的运行环境 |

> **误区纠正**：Java 是跨平台的，不需要关注虚拟化技术？错误。JVM 与虚拟化是协同关系：JVM 解决语言跨平台，Docker/VM 解决运行环境跨平台。

## 二、核心技术：云计算的本质与核心服务

### 2.1 云计算的核心定义

**云计算**：通过网络将虚拟化后的计算、存储、网络等资源整合，以"按需分配、弹性伸缩、按量付费"的模式提供服务。

### 2.2 三大服务模式（IaaS、PaaS、SaaS）

| 服务模式 | 云厂商提供 | 用户负责 | Java 后端常见场景 |
|----------|-----------|----------|-------------------|
| **IaaS** | ECS、OSS、虚拟网络 | OS 安装、环境配置、服务部署 | 单体服务、定制化环境 |
| **PaaS** | 运行环境（JVM）、数据库、中间件 | 业务代码开发、应用部署 | 微服务、弹性伸缩 |
| **SaaS** | 现成软件（数据库、中间件） | API 调用 | 云数据库、云中间件 |

### 2.3 云计算核心特征

| 特征 | Java 后端实战关联 |
|------|-------------------|
| **弹性伸缩** | 根据流量自动扩容/缩容，应对流量峰值 |
| **按需付费** | 避免资源浪费，降低部署成本 |
| **高可用** | 多可用区、故障转移 |
| **可扩展性** | 快速集成 OSS、短信等云服务 |

## 三、Java 后端实战：虚拟化与云的落地应用

### 3.1 Docker 部署 Spring Boot 服务

#### Dockerfile

```dockerfile
# 基础镜像：与本地开发环境一致
FROM openjdk:8-jdk-alpine

WORKDIR /app

# 复制 JAR 包
COPY target/spring-boot-demo-0.0.1-SNAPSHOT.jar app.jar

EXPOSE 8080

# 启动命令
ENTRYPOINT ["java", "-jar", "app.jar"]
```

#### 构建与运行

```bash
# 构建镜像
docker build -t spring-boot-demo:v1.0 .

# 运行容器
docker run -d -p 8080:8080 --name demo-container spring-boot-demo:v1.0

# 推送至云仓库
docker tag spring-boot-demo:v1.0 registry.cn-hangzhou.aliyuncs.com/xxx/spring-boot-demo:v1.0
docker push registry.cn-hangzhou.aliyuncs.com/xxx/spring-boot-demo:v1.0
```

### 3.2 ECS 部署 Java 服务

```bash
# 安装 Docker
yum install -y yum-utils device-mapper-persistent-data lvm2
yum-config-manager --add-repo http://mirrors.aliyun.com/docker-ce/linux/centos/docker-ce.repo
yum install docker-ce docker-ce-cli containerd.io
systemctl start docker
systemctl enable docker

# 拉取并运行镜像
docker pull registry.cn-hangzhou.aliyuncs.com/xxx/spring-boot-demo:v1.0
docker run -d -p 8080:8080 --restart=always --name demo-container spring-boot-demo:v1.0
```

#### Nginx 反向代理配置

```nginx
server {
    listen 80;
    server_name 你的域名或ECS公网IP;
    location / {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

### 3.3 PaaS 部署（阿里云 SAE）

1. 将 Spring Boot 服务打包为 Docker 镜像，推送至阿里云 ACR
2. 在 SAE 控制台创建应用，选择容器镜像部署
3. 配置弹性伸缩：CPU ≥70% 扩容，CPU ≤30% 缩容

#### 集成云服务

```java
@Service
public class OssService {
    @Value("${aliyun.oss.endpoint}")
    private String endpoint;
    @Value("${aliyun.oss.accessKeyId}")
    private String accessKeyId;
    @Value("${aliyun.oss.accessKeySecret}")
    private String accessKeySecret;
    @Value("${aliyun.oss.bucketName}")
    private String bucketName;

    public String uploadFile(MultipartFile file) throws IOException {
        OSS ossClient = new OSSClientBuilder().build(endpoint, accessKeyId, accessKeySecret);
        String fileName = UUID.randomUUID().toString() + file.getOriginalFilename();
        ossClient.putObject(bucketName, fileName, file.getInputStream());
        ossClient.shutdown();
        return "https://" + bucketName + "." + endpoint + "/" + fileName;
    }
}
```

## 四、实战避坑

| 坑点 | 原因 | 解决方案 |
|------|------|----------|
| **Docker 中 Java OOM** | 容器内存限制 + JVM 未设置内存参数 | `docker run -e JAVA_OPTS="-Xms1g -Xmx1g"` |
| **环境不一致** | 本地 JDK 版本与镜像 JDK 版本不同 | Dockerfile 基础镜像与本地一致 |
| **安全组未开放端口** | 云服务器端口限制 | 添加入方向规则，开放 80/8080 端口 |
| **单点故障** | 仅部署一个实例 | 多可用区部署 + 负载均衡 |
| **资源浪费** | 实例配置过高 | 按需付费 + 弹性伸缩 |
