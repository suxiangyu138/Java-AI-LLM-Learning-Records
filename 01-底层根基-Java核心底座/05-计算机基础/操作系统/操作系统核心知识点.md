## 一、操作系统概述

### 1.1 定义与功能

操作系统是管理计算机硬件与软件资源的系统软件。**核心功能**：处理机管理、存储器管理、设备管理、文件管理、用户接口管理。

### 1.2 四大特征

| 特征 | 说明 |
|------|------|
| **并发** | 多个程序在一段时间内同时运行（区别于并行：同一时刻同时运行） |
| **共享** | 系统资源被多个并发程序共同使用（互斥共享 / 同时共享） |
| **虚拟** | 通过时分复用、空分复用将物理资源抽象为逻辑资源 |
| **异步** | 程序执行以不可预知的速度推进，走走停停 |

### 1.3 发展历程

```
无 OS（手工） → 单道批处理 → 多道批处理 → 分时系统 → 实时系统 → 通用 OS
```

多道批处理系统的出现标志着操作系统的成熟。

### 1.4 分类

| 分类维度 | 类型 |
|----------|------|
| 使用环境 | 批处理系统、分时系统、实时系统（硬实时 / 软实时） |
| 用户数量 | 单用户系统、多用户系统 |
| 硬件结构 | 单机 OS、网络 OS、分布式 OS |

## 二、进程管理

### 2.1 进程的基本概念

- **进程**：程序在计算机中的一次执行过程，系统进行资源分配和调度的基本单位
- **进程 vs 程序**：程序是静态指令集合，进程是动态执行过程，有生命周期

### 2.2 进程的状态与转换

```
创建 → 就绪 ──调度→ 运行 ──时间片到→ 就绪
                 运行 ──I/O请求→ 阻塞 ──I/O完成→ 就绪
                 运行 ──终止→ 终止
```

### 2.3 PCB（进程控制块）

进程存在的唯一标志，包含：进程标识符、状态、CPU 状态信息、调度信息、资源分配信息等。

### 2.4 进程同步与互斥

| 概念 | 说明 |
|------|------|
| **互斥** | 同一时刻只允许一个进程访问临界资源 |
| **同步** | 多个进程按预定先后次序执行 |

**实现机制**：

- 信号量（P/V 操作）
- 管程机制
- 经典问题：生产者-消费者、读者-写者、哲学家进餐

### 2.5 进程通信

| 方式 | 说明 |
|------|------|
| 共享存储区 | 最快 IPC |
| 消息传递系统 | 直接通信 / 间接通信 |
| 管道通信 | 半双工，基于文件系统 |

### 2.6 线程

- 进程中的一个执行单元，CPU 调度和分派的基本单位
- 不拥有独立资源，共享进程资源
- 分类：**用户级线程**（用户程序管理）和**内核级线程**（内核管理）

## 三、处理机调度

### 3.1 调度层次

| 层次 | 说明 |
|------|------|
| **高级调度**（作业调度） | 外存→内存，创建进程 |
| **中级调度**（内存调度） | 挂起/激活，释放内存 |
| **低级调度**（进程调度） | 就绪队列→CPU，最频繁 |

### 3.2 调度算法

| 算法 | 核心思想 | 特点 |
|------|----------|------|
| **FCFS** | 按到达顺序 | 简单公平，不利于短作业 |
| **SJF** | 优先短作业 | 降低平均周转时间，长作业饥饿 |
| **优先级调度** | 最高优先级 | 静态 / 动态优先级 |
| **时间片轮转（RR）** | 固定时间片轮流 | 时间片大小影响性能 |
| **多级反馈队列** | 多队列 + 动态调整 | 兼顾短/长/交互型作业 |

## 四、存储器管理

### 4.1 程序的装入与链接

**装入方式**：绝对装入 → 可重定位装入 → 动态运行时装入

**链接方式**：静态链接 → 装入时动态链接 → 运行时动态链接

### 4.2 分页存储管理

- 内存划分为大小相等的**物理块**（页框）
- 进程逻辑地址划分为与物理块大小相等的**页面**
- 通过**页表**实现逻辑地址→物理地址转换
- 引入**快表（TLB）**加速地址变换

### 4.3 分段存储管理

- 按程序逻辑结构划分**段**（代码段、数据段）
- 通过**段表**实现地址转换
- 便于模块化设计和共享

### 4.4 虚拟内存

基于**局部性原理**（时间局部性、空间局部性），按需调页（段）。

**页面置换算法**：

| 算法 | 说明 |
|------|------|
| **OPT** | 置换未来最久不使用的页面（理论最优，不可实现） |
| **FIFO** | 置换最先装入的页面（可能出现 Belady 异常） |
| **LRU** | 置换最近最少使用的页面（性能接近 OPT） |
| **Clock** | 基于使用位，开销小 |

## 五、设备管理

### 5.1 I/O 控制方式

| 方式 | CPU 参与度 | 效率 |
|------|-----------|------|
| 程序直接控制 | 持续轮询 | 极低 |
| 中断驱动 | 仅在完成时响应 | 较高 |
| DMA | 仅在开始和结束时参与 | 高 |
| 通道 | 仅需发送命令 | 最高 |

### 5.2 SPOOLing 技术

假脱机技术，利用外存模拟脱机 I/O，将独占设备转换为共享设备。

### 5.3 磁盘调度算法

| 算法 | 目标 |
|------|------|
| FCFS | 按请求顺序 |
| SSTF | 最短寻道时间优先 |
| SCAN（电梯算法） | 单向扫描 |
| CSCAN | 循环扫描 |

## 六、文件管理

### 6.1 文件物理结构

| 结构 | 优点 | 缺点 |
|------|------|------|
| **顺序结构** | 访问速度快 | 不利于动态增长 |
| **链接结构** | 利于动态增长 | 随机访问慢 |
| **索引结构** | 支持随机访问 | 额外空间存索引表 |

### 6.2 目录结构

一级目录 → 二级目录 → **多级目录（树形）**

### 6.3 存储空间管理

空闲表法、空闲链表法、位示图法、成组链接法（UNIX）。

## 八、死锁

### 8.1 定义与必要条件

多个进程因竞争资源陷入僵局，无法继续执行。

| 必要条件 | 说明 |
|----------|------|
| 互斥 | 资源只能被一个进程占用 |
| 请求和保持 | 持有资源同时请求新资源 |
| 不剥夺 | 已持有资源不能被强行剥夺 |
| 环路等待 | 形成环形资源等待链 |

### 8.2 处理策略

| 策略 | 方法 |
|------|------|
| **预防** | 破坏四个必要条件之一 |
| **避免** | 银行家算法 |
| **检测 + 解除** | 资源分配图化简法，撤销进程或剥夺资源 |
