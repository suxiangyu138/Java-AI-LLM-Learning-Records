## 4. 核心概念速查

| 概念 | 一句话解释 | 详见 |
|------|-----------|------|
| **WSL1 vs WSL2** | WSL1 是系统调用翻译层（无内核），WSL2 是 Hyper-V 轻量 VM（完整 Linux 内核） | 模块01 |
| **Hyper-V 轻量 VM** | WSL2 使用的虚拟机技术，比传统 VM 快（<2s 启动，内存动态分配） | 模块01 |
| **wsl --install** | 一条命令安装 WSL2 + 默认 Ubuntu | 模块02 |
| **.wslconfig** | 全局配置文件（内存限制、处理器数、Swap），放在 `%USERPROFILE%` | 模块02 |
| **wsl.conf** | 单发行版配置（自动挂载、网络、DNS、启动命令） | 模块02 |
| **/mnt/c/** | WSL2 中访问 Windows C 盘的标准路径 | 模块04 |
| **\\\\wsl$\\** | Windows 资源管理器中访问 WSL2 文件的网络路径 | 模块04 |
| **跨文件系统性能** | WSL2 中操作 `/mnt/c/` 下文件比 Linux 原生文件系统慢 10-50x | 模块04 |
| **localhost 转发** | WSL2 中监听的端口自动映射到 Windows localhost | 模块05 |
| **Mirrored 网络** | Win11 22H2+ 新特性，WSL2 与 Windows 共享网络（替代 NAT） | 模块05 |
| **SDKMAN in WSL2** | 在 WSL2 Linux 中安装 SDKMAN，管理多 JDK 版本 | 模块03 |
| **systemd** | WSL2 0.67.6+ 支持 systemd，可运行 MySQL/Redis/Docker 等系统服务 | 模块06 |
