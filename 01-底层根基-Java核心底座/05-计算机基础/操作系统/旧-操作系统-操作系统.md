# 操作系统

## 课程概述
- **课程性质**：专业核心必修课
- **适用专业**：计算机类各专业
- **开课学期**：大三学年
- **考核方式**：考试（闭卷）+ 实验 + 平时成绩

## 课程目标
1. 理解操作系统的基本概念、功能和体系结构
2. 掌握进程管理、内存管理、文件系统和设备管理的核心原理
3. 理解并发与同步机制
4. 能够分析操作系统中的典型算法和策略

## 核心知识点

### 第一章：操作系统概述
- 操作系统的定义与四大功能：进程管理、内存管理、文件管理、设备管理
- OS的基本类型：批处理、分时、实时、网络操作系统
- 内核态（核心态）与用户态
- 中断驱动机制（外中断→进入内核→中断处理→返回）
- 系统调用（用户程序请求OS服务的接口）

### 第二章：进程管理
- 进程的概念：运行中的程序，进程实体 = PCB + 程序段 + 数据段
- 进程的状态与转换：就绪态→运行态→阻塞态（三态模型）、创建/终止（五态模型）
- 进程控制块(PCB)：进程标识、状态、优先级、寄存器、内存指针等
- 进程同步：
  - 临界资源与临界区
  - 信号量机制（P/V操作，或wait/signal）
  - 经典同步问题：生产者-消费者、读者-写者、哲学家进餐
- 进程通信：共享内存、消息传递、管道
- 线程：用户级线程与内核级线程、多线程模型
- 处理机调度：
  - 作业调度（高级调度）、进程调度（低级调度）
  - 调度算法：先来先服务(FCFS)、短作业优先(SJF)、高响应比优先、时间片轮转(RR)、多级反馈队列
  - 实时调度

### 第三章：死锁
- 死锁的定义与四个必要条件：互斥、请求保持、不可剥夺、循环等待
- 死锁预防（破坏四个必要条件之一）
- 死锁避免：银行家算法（安全状态判定）
- 死锁检测与解除

### 第四章：内存管理
- 连续分配：
  - 固定分区、动态分区
  - 分区分配算法：首次适应(FF)、最佳适应(BF)、最差适应(WF)
  - 碎片问题（外部碎片与内部碎片）
- 离散分配：
  - 分页存储管理：页表、页号、页内偏移、地址变换
  - 快表(TLB)加速地址变换
  - 两级页表与多级页表
  - 分段存储管理
  - 段页式存储管理（Windows/Linux实际采用的方案）

### 第五章：虚拟内存
- 局部性原理（时间局部性、空间局部性）
- 请求分页系统
- 页面置换算法：最佳置换(OPT)、先进先出(FIFO)、最近最久未使用(LRU)、时钟算法(CLOCK)
- 页面分配策略
- 抖动（thrashing）与工作集理论

### 第六章：文件系统
- 文件的概念与属性
- 文件逻辑结构（流式文件、记录式文件）
- 文件目录结构（单级、两级、树形、无环图）
- 文件物理结构：连续分配、链接分配(隐式链接FAT)、索引分配(i-node)
- 空闲空间管理：空闲表法、空闲链表法、位示图法、成组链接法
- 文件共享与保护

### 第七章：设备管理
- IO设备分类：块设备（磁盘）、字符设备（键盘/打印机）
- IO控制方式：程序直接控制→中断驱动→DMA→通道控制
- 缓冲技术：单缓冲、双缓冲、循环缓冲、缓冲池
- SPOOLing技术（假脱机）：将独占设备改造为共享设备
- 磁盘调度算法：FCFS、最短寻道时间优先(SSTF)、扫描算法(SCAN)、循环扫描(C-SCAN)

## 重点难点
- **重点**：进程同步(PV操作)、处理机调度、分页存储管理、页面置换算法、文件系统结构
- **难点**：PV操作的应用设计、银行家算法、虚存管理、磁盘调度

## 学习方法与建议
1. 理论结合Linux源码阅读或实践加深理解
2. 多画图理解（内存分配图、进程状态转换图等）
3. 动手写多线程程序，实践进程同步
4. 关注历年考研408真题（操作系统部分）
