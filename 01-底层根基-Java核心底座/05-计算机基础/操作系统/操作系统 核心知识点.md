## 一、操作系统概述

### 1.1 定义

管理计算机软硬件资源、提供用户与硬件交互接口、合理组织任务调度的系统软件。

### 1.2 核心目标

资源管理、系统并发、抽象封装、安全隔离。

### 1.3 三大特征

| 特征 | 说明 |
|------|------|
| **并发** | 宏观同时执行，微观交替切换 |
| **共享** | 软硬件资源被多进程共同使用 |
| **虚拟** | 时分复用 / 空分复用，物理资源逻辑虚拟化 |

### 1.4 操作系统分类

批处理系统、分时系统、实时系统、分布式系统、嵌入式系统。

## 二、进程与线程（高频核心）

### 2.1 进程

- **定义**：资源分配的**最小单位**，程序的一次动态执行过程。
- **进程三态**：就绪态、运行态、阻塞态（等待态）+ 新建、终止两状态。
- **PCB（进程控制块）**：进程唯一标识，保存 PID、状态、寄存器、内存指针、优先级等核心信息。

### 2.2 线程

- **定义**：调度执行的**最小单位**，轻量级进程。
- **特点**：共享进程地址空间、切换开销小、独立栈与寄存器。

#### 进程 vs 线程

| 维度 | 进程 | 线程 |
|------|------|------|
| 资源 | 独立 | 共享进程资源 |
| 切换开销 | 大 | 极小 |
| 隔离性 | 完全隔离 | 通信更简单 |

### 2.3 进程通信 IPC

| 类别 | 方式 |
|------|------|
| 低级通信 | 信号、管道（匿名 / 有名） |
| 高级通信 | 消息队列、共享内存、信号量、Socket |

### 2.4 进程同步与互斥

- **临界资源**：同一时刻仅允许一个进程访问的资源
- **临界区**：访问临界资源的代码段
- **经典问题**：生产者-消费者、读者-写者、哲学家就餐

#### 同步工具

| 工具 | 说明 |
|------|------|
| **互斥锁** | 保证同一时刻单一执行流进入临界区 |
| **信号量** | PV 操作，实现同步 + 互斥 |
| **管程** | 封装共享数据与操作，自带互斥 |

### 2.5 死锁

#### 四大必要条件

1. 互斥
2. 请求保持
3. 不可剥夺
4. 环路等待

#### 解决策略

| 策略 | 方法 |
|------|------|
| **预防** | 破坏四大条件之一 |
| **避免** | 银行家算法 |
| **检测 + 解除** | 资源分配图、进程终止 / 资源抢占 |

## 三、处理机调度

### 3.1 调度层级

| 层级 | 说明 |
|------|------|
| **高级调度**（作业调度） | 外存 → 内存 |
| **中级调度**（内存调度） | 挂起 / 激活，平衡负载 |
| **低级调度**（进程调度） | CPU 分配，最频繁 |

### 3.2 经典调度算法

| 算法 | 特点 |
|------|------|
| 先来先服务（FCFS） | 按到达顺序 |
| 短作业优先（SJF） | 优先短作业 |
| 时间片轮转（RR） | 分时系统核心 |
| 优先级调度 | 按优先级执行 |
| **多级反馈队列** | 现代 OS 默认 |

## 四、内存管理

### 4.1 核心需求

内存空间分配、地址转换、内存隔离、内存扩容。

### 4.2 地址分类

| 类型 | 说明 |
|------|------|
| **逻辑地址**（虚拟地址） | 程序编译生成 |
| **物理地址**（内存地址） | 硬件实际内存地址 |

### 4.3 内存分配方式

| 方式 | 说明 |
|------|------|
| **连续分配** | 固定分区、动态分区（碎片问题） |
| **非连续分配** | 分页、分段、段页式 |

### 4.4 分页管理

- **页**：固定大小，逻辑地址拆分【页号 + 页内偏移】
- **页表**：映射页号与物理块号
- **快表 TLB**：缓存常用页表项，加速地址转换

### 4.5 分段管理

- **段**：逻辑单位（代码段、数据段），大小不固定，便于共享与保护

### 4.6 虚拟内存

- **原理**：局部性原理（时间局部性、空间局部性）
- **核心**：部分装入、请求调入、页面置换

### 4.7 页面置换算法

| 算法 | 说明 |
|------|------|
| OPT | 最优置换（理论不可实现） |
| FIFO | 先进先出（有 Belady 异常） |
| **LRU** | 最近最少使用 |
| Clock | 时钟算法 |

### 4.8 抖动

频繁缺页、大量页面置换，系统效率暴跌。

## 六、设备管理

### 6.1 设备分类

独占设备、共享设备、虚拟设备。

### 6.2 I/O 控制方式

| 方式 | 说明 |
|------|------|
| 程序直接控制 | CPU 轮询，效率低 |
| **中断驱动** | 设备完成后发中断 |
| **DMA** | 直接内存访问 |
| **通道** | 专用硬件管理 I/O |

### 6.3 缓冲技术

单缓冲、双缓冲、循环缓冲，缓解 CPU 与 I/O 速度差。

### 6.4 SPOOLing

假脱机技术，将独占设备转为共享设备。

## 七、中断与异常

### 7.1 中断

外部设备触发，**异步**（时钟中断、I/O 中断）。

### 7.2 异常

CPU 内部错误，**同步**（除零、缺页、非法指令）。

### 7.3 中断流程

```
中断请求 → 中断响应 → 中断处理 → 中断返回
```

## 八、现代操作系统核心机制

1. **内核态 / 用户态**：权限隔离，系统调用完成状态切换
2. **系统调用**：用户进程访问内核资源的唯一入口
3. **缓存机制**：CPU 缓存、页缓存、文件缓存，提升 I/O 性能
