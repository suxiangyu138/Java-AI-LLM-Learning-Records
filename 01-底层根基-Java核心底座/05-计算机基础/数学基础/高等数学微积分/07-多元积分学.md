## 1. 二重积分：定义与计算

### 1.1 定义

```text
∬_D f(x,y) dA = lim(分割细化) Σ f(ξᵢ, ηᵢ)·ΔAᵢ

几何：z = f(x,y) 曲面与 D 之间的"体积"（f ≥ 0 时）
物理：面密度 ρ(x,y) 在区域 D 上的总质量

可积性：f 在闭区域 D 上连续 → 可积
```

### 1.2 直角坐标计算（累次积分）

```text
X 型区域（竖线穿过）：D = {(x,y) | a≤x≤b, φ₁(x)≤y≤φ₂(x)}
  ∬_D f dA = ∫ₐᵇ [∫_(φ₁(x))^(φ₂(x)) f(x,y) dy] dx
  → 先对 y 积分（x 当常数），再对 x 积分

Y 型区域（横线穿过）：
  ∬_D f dA = ∫꜀ᵈ [∫_(ψ₁(y))^(ψ₂(y)) f(x,y) dx] dy

选择原则：看区域"哪方向切割简单" + 被积函数"哪方向先积容易"
  ⚠️ 交换积分次序是常考题：画区域 → 换视角重写边界
```

```text
例：D = {0≤x≤1, 0≤y≤x}，∬_D x·e^(y) dA
  先 y 后 x：∫₀¹ [∫₀ˣ x·e^y dy]dx = ∫₀¹ x(e^x − 1)dx = (e−2)/2
```

## 2. 极坐标下的二重积分

### 2.1 何时用极坐标

```text
识别信号：
  区域是圆/环/扇形（边界含 x²+y² = r²）
  被积函数含 x²+y²
  → 极坐标：x = r·cosθ，y = r·sinθ

关键：面积元的变换
  dA = r·dr·dθ（雅可比行列式 |∂(x,y)/∂(r,θ)| = r）

公式：∬_D f dA = ∫_(θ₁)^(θ₂) ∫_(r₁(θ))^(r₂(θ)) f(r cosθ, r sinθ)·r dr dθ
  ⚠️ 千万别丢 "r"（最常见的积分错误）
```

### 2.2 经典例子（高斯积分）

```text
∬ e^(−(x²+y²)) dA 全平面 = ∫₀^(2π)∫₀^∞ e^(−r²)·r dr dθ
  = 2π · (1/2) = π
  → 又因为 e^(−(x²+y²)) = e^(−x²)·e^(−y²) 可分离：
  (∫e^(−x²)dx)² = π → ∫₋∞^∞ e^(−x²)dx = √π
  → 高斯积分的最美证明（05 章提过结论，此处给证明路径）
  → 正态分布归一化常数的来源
```

> 🎯 **核心要点**：极坐标的本质 = 换元（雅可比 r）；它把"圆形对称"的问题化为"矩形"（θ 与 r 直交），是高斯积分、概率论、场论的第一工具。

## 3. 三重积分

### 3.1 直角坐标

```text
∭_V f dV = 逐层积分（先一重再二重）
  投影法：∭_V f dV = ∬_D [∫_(z₁(x,y))^(z₂(x,y)) f dz] dA
  → 先 z 后平面（先算"竖杆"积分，再对投影区域二重积分）

物理：体密度 ρ 在 V 上的总质量；质心 = (1/M)∭ρ·x dV
```

### 3.2 柱坐标与球坐标

| 坐标系 | 变换 | 体积元 | 适用 |
|--------|------|--------|------|
| 柱坐标 | x=r cosθ, y=r sinθ, z=z | dV = r dr dθ dz | 圆柱/旋转体 |
| 球坐标 | x=ρ sinφ cosθ, y=ρ sinφ sinθ, z=ρ cosφ | dV = ρ² sinφ dρ dφ dθ | 球/锥 |

```text
记忆：每多一个"角度坐标"就多一个雅可比因子
  极坐标：r（一次角度）
  柱坐标：r（θ 角度）
  球坐标：ρ² sinφ（θ、φ 两个角度）
  → 单位检查法：物理量纲必须一致（积分结果=体积/质量）

经典例：半径为 R 的球体积
  V = ∫₀^(2π)∫₀^π∫₀^R ρ² sinφ dρ dφ dθ = (4/3)πR³
```

## 4. 曲线积分

### 4.1 两类曲线积分

```text
第一类（对弧长）：∫_L f(x,y) ds —— 与方向无关
  例：曲线 L 的线密度 f → 总质量
  计算：参数化 x=x(t), y=y(t)：
    ds = √(x'² + y'²)dt → ∫f(x(t),y(t))·√(x'²+y'²)dt

第二类（对坐标/功）：∫_L P dx + Q dy —— 与方向有关（换向变号）
  物理：变力沿路径做的功 W = ∫(P dx + Q dy)
  计算：参数化后 dx = x'dt，dy = y'dt 代入

两类关系：第二类 = 第一类 · 切向分量（∮F·dr 形式）
```

### 4.2 格林公式（联系线积分与二重积分）

```text
∮_L P dx + Q dy = ∬_D (∂Q/∂x − ∂P/∂y) dA
（L 为 D 的正向边界，P、Q 一阶连续偏导）

威力：
  ① 曲线积分 ⇄ 二重积分互换（选简单的算）
  ② 判断保守场：∂Q/∂x = ∂P/∂y → 积分与路径无关
     → 存在势函数 u：F = ∇u（梯度场）
  ③ 面积公式：A = (1/2)∮_L (x dy − y dx)

工程：向量场旋度 ∮F·dr = ∬(旋度 F) dA——场论的基础
```

## 5. 曲面积分概述

```text
第一类曲面积分（对面积）：∬_Σ f dS
  曲面 Σ：z = z(x,y) → dS = √(1 + z_x² + z_y²) dxdy
  例：面密度 f 的曲面总质量

第二类曲面积分（对坐标/通量）：∬_Σ P dy∧dz + Q dz∧dx + R dx∧dy
  物理：流速场穿过曲面的通量
  单位法向量 n → 通量 = ∬ F·n dS

高斯公式（散度定理）：
  ∯_Σ F·dS = ∭_V (div F) dV
  → 通量 = 内部散度的总和（麦克斯韦方程的数学形态）

斯托克斯公式：∮_L F·dr = ∬_Σ (curl F)·dS
  → 环路积分 = 旋度的面积分

定位：多元积分的"收官"——场论（电磁学/流体力学/图形学）的数学语言
```

## 6. 多元积分在概率中的应用

```text
联合分布：P((X,Y) ∈ D) = ∬_D f(x,y) dxdy
  → 二元正态分布的椭圆等高线（协方差矩阵）

边缘密度：f_X(x) = ∫ f(x,y) dy（"固定一个，积掉另一个"）
独立 ⇔ f(x,y) = f_X(x)·f_Y(y)（可分离 = 独立）

期望与协方差：
  E[g(X,Y)] = ∬ g(x,y)·f(x,y) dxdy
  Cov(X,Y) = E[XY] − E[X]E[Y]（= ∬xy·f dxdy − μxμy）

意义：多元积分 = 概率论的"求和引擎"——所有边缘化/期望/方差计算
```

## 7. 数值方法：多重积分的蒙特卡洛

```text
高维积分的困境：
  梯形/辛普森在高维灾难性失效：
  每维 n 个采样点 → d 维 = n^d（维度诅咒！）
  d=10，n=10 → 10^10 个点（不可行）

蒙特卡洛方法（随机采样）：
  ∬_D f dA ≈ (面积/点数) · Σ f(随机点)
  误差 ∝ 1/√N（与维度无关！）
  → 高维积分唯一可行方案

应用：
  金融期权定价（高维资产组合）
  贝叶斯推断（MCMC）
  渲染（蒙特卡洛路径追踪——图形学标准）
  深度学习的 Dropout/Batch 采样思想同源

对比：
  低维（≤3）：辛普森等确定性方法（精度高）
  高维：蒙特卡洛（维度无关误差）
```

## 8. 核心要点与思考题

> 🎯 **本章三句话总结**：
> 1. 二重积分 = 累次积分（先内后外，边界定限）；极坐标带雅可比 r——丢 r 是头号错误，高斯积分是极坐标的最佳回报；
> 2. 三重积分按区域形状选坐标系（直角/柱 r/球 ρ²sinφ）；曲线/曲面积分 + 格林/高斯/斯托克斯构成场论语言；
> 3. 高维积分用蒙特卡洛（误差 1/√N 与维度无关）——金融、贝叶斯、渲染的标准做法。

**思考题**：

1. 极坐标积分为什么多一个 r？（→ 2.1 雅可比）
2. 高斯积分 √π 与正态分布的关系？（→ 2.2 + 05 章）
3. 格林公式在什么条件下能化简曲线积分？（→ 4.2 保守场）
4. 为什么高维积分必须用蒙特卡洛？（→ 7 维度诅咒）
