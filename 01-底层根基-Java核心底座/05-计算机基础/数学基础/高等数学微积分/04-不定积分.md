# 不定积分

> 不定积分是求导的"逆运算"：已知导数找原函数。换元法（凑微分/变量替换）与分部积分法是两大核心武器，有理函数积分是集大成者——积分技巧的熟练度决定定积分、概率统计与物理应用的落地能力

## 1. 原函数与不定积分

```text
定义：F'(x) = f(x) → F 是 f 的一个原函数
不定积分 = 全体原函数：∫f(x)dx = F(x) + C

三个关键事实：
  ① 原函数不唯一（差一个常数 C）
  ② 连续函数必有原函数（存在性定理）
  ③ ∫ 与 d 互逆：d[∫f dx] = f dx；∫dF = F + C

线性性质：∫[af(x) + bg(x)]dx = a∫f + b∫g（拆分积分的基本依据）
```

> 🎯 **核心要点**：不定积分没有"求导法则"那样的机械化流程——它靠**识别**（反着找导数公式）与**变形**（换元/分部）。熟练度 = 基本积分表 + 两类换元 + 分部，三件套缺一不可。

## 2. 基本积分表

| ∫f dx | 结果 | | ∫f dx | 结果 |
|-------|------|-|-------|------|
| ∫x^n dx | x^(n+1)/(n+1) + C（n≠−1） | | ∫sin x dx | −cos x + C |
| ∫1/x dx | ln\|x\| + C | | ∫cos x dx | sin x + C |
| ∫e^x dx | e^x + C | | ∫sec²x dx | tan x + C |
| ∫a^x dx | a^x/ln a + C | | ∫1/(1+x²) dx | arctan x + C |
| ∫1/√(1−x²) dx | arcsin x + C | | ∫1/√(1−x²)·(−1)... | arccos x + C |
| ∫tan x dx | −ln\|cos x\| + C | | ∫cot x dx | ln\|sin x\| + C |

```text
记忆要点：
  ∫1/x = ln|x|（绝对值不能丢——定义域为负时仍成立）
  x^n 的"缺 n=−1 特例"= 1/x → ln
  反三角函数导数 ↔ 积分对：1/(1+x²)↔arctan、1/√(1−x²)↔arcsin
```

## 3. 第一换元法：凑微分

### 3.1 原理

```text
思想：把被积函数"看成"复合函数求导的展开结果
  ∫f(g(x))·g'(x)dx = ∫f(u)du（令 u = g(x)）

操作：观察被积式中是否存在 "内层函数" 与 "其导数的影子"
  ∫2x·e^(x²)dx：u = x²，du = 2x dx → ∫e^u du = e^(x²) + C
  ∫cos(3x)dx：u = 3x，du = 3dx → (1/3)∫cos u du = (1/3)sin(3x) + C
```

### 3.2 常见凑微分模式

| 被积结构 | 凑法 |
|---------|------|
| ∫f(xⁿ)·xⁿ⁻¹dx | 凑 xⁿ（1/n 系数） |
| ∫f(e^x)·e^x dx | 凑 e^x |
| ∫f(ln x)·(1/x)dx | 凑 ln x |
| ∫f(sin x)·cos x dx | 凑 sin x |
| ∫f(cos x)·sin x dx | 凑 cos x（负号） |
| ∫f(tan x)·sec²x dx | 凑 tan x |

```text
判定口诀：看到"内层函数的导数因子"出现 → 直接凑微分
  例：∫sin³x·cos x dx → u = sin x → ∫u³ du
```

## 4. 第二换元法：变量替换

### 4.1 原理

```text
反向操作：令 x = φ(t)（引入新变量），dx = φ'(t)dt
  ∫f(x)dx → ∫f(φ(t))·φ'(t)dt（化简后积分，最后回代 x）

用途：根式/复杂结构通过替换"脱根"或"三角化"
```

### 4.2 三类三角替换

| 被积含 | 替换 | 依据 |
|--------|------|------|
| √(a² − x²) | x = a·sin t | 1 − sin²t = cos²t |
| √(a² + x²) | x = a·tan t | 1 + tan²t = sec²t |
| √(x² − a²) | x = a·sec t | sec²t − 1 = tan²t |

```text
例：∫√(1−x²)dx
  x = sin t → dx = cos t dt → ∫cos²t dt = (1/2)∫(1+cos2t)dt
  = (1/2)(t + sin2t/2) + C → 回代 x：arcsin x + x√(1−x²)/2 + C
```

### 4.3 根式替换

```text
含 √(ax+b) → 令 t = √(ax+b)（直接去根）
含 √(x)/(x+1) 型 → 令 t = √x
倒代换：x = 1/t（分母幂次高于分子时）
```

## 5. 分部积分法

### 5.1 公式与推导

```text
来源：乘积法则的逆运算
  (uv)' = u'v + uv' → uv' = (uv)' − u'v
  ∫u dv = uv − ∫v du

选择 u 的优先顺序（LIATE 记忆法）：
  L（对数）> I（反三角）> A（代数 x^n）> T（三角）> E（指数）
  → u 取"求导后变简单"的；dv 取"积分后不复杂"的
```

### 5.2 三大典型模式

```text
① 幂 × 指数/三角（消幂）：
   ∫x·e^x dx：u=x, dv=e^x dx → x·e^x − e^x + C
   ∫x·sin x dx：u=x → −x·cos x + sin x + C

② 幂 × 对数/反三角（消对数）：
   ∫x·ln x dx：u=ln x, dv=x dx → (x²/2)ln x − x²/4 + C

③ 循环回归（指数 × 三角）：
   ∫e^x·sin x dx：分部两次回到自身 → 移项解出
   I = e^x sin x − e^x cos x − I → I = (e^x/2)(sin x − cos x) + C

④ 递推公式：∫sinⁿx dx → n·Iₙ = −sinⁿ⁻¹x·cos x + (n−1)·Iₙ₋₂
   （华里士公式的来源，定积分专题常用）
```

> 🎯 **核心要点**：分部积分 = "把一个积分换成另一个更简单的积分"——选择 u 的黄金法则是"**求导会变简单**（消幂/消对数）"；循环型要敢"移项解方程"。

## 6. 有理函数积分

### 6.1 部分分式分解

```text
∫P(x)/Q(x)dx 的处理流程：
  ① 假分式（分子次数 ≥ 分母）→ 多项式除法 → 真分式 + 多项式
  ② 真分式 → 因式分解分母 → 拆成部分分式之和：

  (x+1)/((x−1)(x+2)) = A/(x−1) + B/(x+2)
  解 A、B：通分对比系数（或代入特殊值）

  ⚠️ 不可约二次因子（x²+px+q）→ 分子设为 Ax+B：
    (x+2)/((x²+1)(x−1)) = (Ax+B)/(x²+1) + C/(x−1)
```

### 6.2 四种基本分式的积分

```text
① ∫1/(x−a) dx = ln|x−a| + C
② ∫1/(x−a)ⁿ dx = −1/((n−1)(x−a)ⁿ⁻¹) + C
③ ∫1/(x²+a²) dx = (1/a)·arctan(x/a) + C
④ ∫x/(x²+a²) dx = (1/2)ln(x²+a²) + C
```

## 7. 三角与根式积分专题

| 结构 | 方法 | 示例 |
|------|------|------|
| ∫sinⁿx·cosᵐx dx（奇次） | 留一个，换元 | ∫sin³x·cos²x dx → u=cos x |
| ∫sinⁿx·cosᵐx dx（偶次） | 降幂公式 | sin²x = (1−cos2x)/2 |
| ∫sin ax·cos bx dx | 积化和差 | sin a cos b = [sin(a+b)+sin(a−b)]/2 |
| ∫1/(1+cos x) dx | 万能公式 t=tan(x/2) | 全部化为有理式 |
| ∫1/(sin x + cos x) dx | 辅助角/万能 | 同上 |

```text
工程提示：实际计算（计算机）不做这些技巧——
  数值积分（05/09 章）与符号积分库（SymPy/Wolfram）替代手工
  但理解积分结构（换元/分部/分解）是设计数值算法与理解公式的前提
```

## 8. 核心要点与思考题

> 🎯 **本章三句话总结**：
> 1. 不定积分 = 原函数族（+C）；技巧 = 基本表 + 凑微分（第一换元）+ 变量替换（第二换元）+ 分部积分；
> 2. 分部积分选 u 口诀：求导变简单者优先（LIATE）；循环型用移项解方程；
> 3. 有理函数积分 = 部分分式分解 + 四种基本分式——工程上由数值/符号库代劳，但结构理解仍必要。

**思考题**：

1. 为什么 ∫1/x dx 必须带绝对值？（→ 2 记忆要点）
2. 什么时候该用三角替换？（→ 4.2 三类根式）
3. ∫e^x·sin x dx 为什么能"解出来"？（→ 5.2 循环回归）
4. 假分式为什么要先做多项式除法？（→ 6.1）
