## 4. 核心概念速查

| 概念 | 一句话定义 | 关键要点 |
|------|-----------|---------|
| 极限 | 函数值"无限接近"某值的过程 | ε-δ 严格语言；趋近 ≠ 到达 |
| 连续 | 极限值 = 函数值 | 可导必连续，连续未必可导 |
| 导数 | 变化率的极限（差商） | f'(x) = lim Δy/Δx；几何=切线斜率 |
| 微分 | 线性主部近似 | dy = f'(x)dx |
| 中值定理 | 存在某点导数 = 平均变化率 | 拉格朗日：f(b)−f(a) = f'(ξ)(b−a) |
| 洛必达法则 | 0/0、∞/∞ 型极限求法 | 分子分母分别求导（有条件） |
| 泰勒公式 | 用多项式逼近函数 | 一阶=切线；带余项才精确 |
| 原函数 | 导数为 f 的函数 F | ∫f dx = F + C |
| 定积分 | 黎曼和极限（面积） | ∫ₐᵇ f dx = F(b) − F(a) |
| 偏导数 | 多元函数对单变量求导 | 其余变量视为常数 |
| 梯度 | 偏导向量（上升最快方向） | 梯度下降 = 沿负梯度走 |
| 海森矩阵 | 二阶偏导矩阵 | 判断极值类型（凸性） |
| 拉格朗日乘数法 | 约束下极值 | ∇f = λ∇g |
| 收敛半径 | 幂级数收敛区间 | 比值/根值法求 |
| 自动微分 | 链式法则的程序化 | 反向传播 = 反向模式 AD |
