# 微积分与计算机科学

> 计算机不会"求极限"——它用三种替代方案与微积分共处：数值微分（有限差分，有误差）、数值积分（采样求和）、自动微分（链式法则的程序化，**精确且高效**）。反向传播 = 反向模式自动微分，这是深度学习训练的全部数学引擎；2026 年矩阵微积分与隐式微分正成为新趋势

## 1. 三种计算导数的思路

```text
计算机要 f'(x)，三条路线：

① 数值微分（有限差分）：定义式直接近似
    f'(x) ≈ [f(x+h) − f(x)]/h，h 取小量
    → 有截断误差（h 不够小）+ 舍入误差（h 太小）——天生不精确

② 符号微分：把求导规则写成符号变换（如 SymPy）
    → 精确但表达式膨胀：f = 大函数链时导数表达式指数级膨胀

③ 自动微分（AD）：把函数拆成基本运算，运行时用链式法则
    逐层累乘局部导数
    → 精确（无近似误差）+ 高效（每层 O(1) 工作量）
    → "AD 更像计算机科学而非数学"（MIT 18.063 课程评语）

深度学习的答案：自动微分（PyTorch/TensorFlow/JAX 的 autograd）
```

## 2. 数值微分：有限差分

### 2.1 三种格式

| 格式 | 公式 | 截断误差 |
|------|------|:---:|
| 前向差分 | [f(x+h) − f(x)]/h | O(h) |
| 后向差分 | [f(x) − f(x−h)]/h | O(h) |
| **中心差分** | [f(x+h) − f(x−h)]/(2h) | **O(h²)** |

### 2.2 误差的两难

```text
截断误差：h 越大误差越大（泰勒展开丢项）—— O(h²) 随 h 减小
舍入误差：h 太小 → f(x+h)−f(x) 差值被浮点精度淹没 —— O(1/h)

最优 h ≈ √(ε_machine) ≈ 1e-8（双精度）—— 精度天花板 ~1e-8

用途定位：
  验证 AD/解析梯度的正确性（梯度检查 gradient checking）
  无法解析/无法 AD 的场景（黑盒函数）
  绝不用于训练（有误差 + 每参数一次额外前向 = O(n) 成本）
```

## 3. 符号微分：表达式膨胀

```text
机制：把导数作为符号表达式递归生成（d/dx(x·sin x) = sin x + x·cos x）

膨胀问题（expression swell）：
  f(x) = x·sin(x)·e^x 的导数链多层嵌套时，表达式指数级膨胀
  → 内存爆炸 + 计算缓慢

与 AD 的关键区别：
  符号微分：整体替换表达式树（生成"导数表达式"再求值）
  AD：对**数值**逐层计算（不求表达式，直接算数）
  → AD 保留程序控制流（if/循环），符号微分不能

定位：数学研究/公式推导（SymPy）；不适合作业生产训练
```

## 4. 自动微分：链式法则的程序化

### 4.1 核心思想

```text
把复合函数看作"计算图"（一系列基本运算）：
  y = f(x) = sin(x²) + e^x

计算图（前向）：
  v₁ = x²
  v₂ = sin(v₁)
  v₃ = e^x
  y = v₂ + v₃

链式法则逐层：
  ∂y/∂v₁ = ∂v₂/∂v₁ = cos(v₁)      （局部导数，当场算数）
  ∂y/∂x = ∂y/∂v₁·∂v₁/∂x + ∂y/∂v₃·∂v₃/∂x
        = cos(x²)·2x + e^x

关键：每个基本运算（+、×、sin、exp...）的局部导数已知
     → 沿图传播乘积——精确到机器精度，无截断误差
```

### 4.2 基本运算的局部导数表

| 运算 | 输出 | 局部导数 |
|------|------|---------|
| z = x + y | z | ∂z/∂x = 1, ∂z/∂y = 1 |
| z = x·y | z | ∂z/∂x = y, ∂z/∂y = x |
| z = x/y | z | ∂z/∂x = 1/y, ∂z/∂y = −x/y² |
| z = eˣ | z | ∂z/∂x = eˣ |
| z = sin x | z | ∂z/∂x = cos x |
| z = max(0,x)（ReLU） | z | ∂z/∂x = 1（x>0）, 0（x≤0） |

> 🎯 **核心要点**：AD 的一切 = **基本运算表 + 链式法则传播**。它比数值微分精确（无近似），比符号微分高效（无膨胀），比手推可扩展（任意复杂计算图）——所以它是深度学习的唯一选择。

## 5. 前向模式 vs 反向模式

| 维度 | 前向模式（forward） | 反向模式（reverse） |
|------|:---:|:---:|
| 传播方向 | 输入 → 输出 | 输出 → 输入 |
| 一次运行 | 算 1 个输入的导数（全输出） | 算 1 个输出的导数（全输入） |
| 成本 | O(n) 次前向（n = 输入数） | **O(1) 次前向 + O(1) 次反向** |
| 适用 | 输入少输出多 | **输入多输出少（深度学习！）** |
| 内存 | 小（即时传播） | 需存前向中间值（反向回放） |
| 代表 | JAX jvp | **PyTorch backward / 反向传播** |

```text
选择直觉：
  深度学习：参数千万个（输入）、损失 1 个（输出）
    → 反向模式一次得到全部参数的梯度 = 反向传播
  科学计算：f(x₁,...,xₙ) 只要 d f/dx₁？
    → 前向模式一次搞定（更省内存）
  → 深度学习的"反向传播"名字来源：反向模式 AD
```

## 6. 反向传播 = 反向模式 AD

```text
训练一层的完整链路（数学 ↔ 代码）：
  前向：x → a₁ → a₂ → ... → loss（逐层算并缓存中间值）
  反向：∂loss/∂a_last → ∂loss/∂a₂ → ∂loss/∂a₁（逐层回传）

  ∂loss/∂Wᵢ = ∂loss/∂aᵢ · ∂aᵢ/∂Wᵢ

  aᵢ = σ(Wᵢaᵢ₋₁ + bᵢ)
  ∂aᵢ/∂Wᵢ = σ'(zᵢ)·aᵢ₋₁ᵀ（局部导数 × 上游梯度）

工程要点（为何高效）：
  每个中间张量只算一次局部梯度
  矩阵化：批量样本一次前向/反向（GPU 并行）
  缓存前向值（activation）→ 反向用——显存换速度的权衡
```

```java
// 最小自动微分（Java 示例：前向模式对偶数）
public class Dual {
    final double v; final double d;           // 值 + 导数
    Dual(double v, double d) { this.v = v; this.d = d; }
    Dual add(Dual o) { return new Dual(v + o.v, d + o.d); }
    Dual mul(Dual o) { return new Dual(v * o.v, d * o.v + v * o.d); }
    // f(x) = x² + 3x 在 x=2 的导数：
    // x = new Dual(2, 1); f = x.mul(x).add(new Dual(3,0).mul(x));
    // f.d = 4 + 3 = 7 ✓
}
```

## 7. 对偶数：AD 的代数本质

```text
对偶数（dual number）：x + ε·d，其中 ε² = 0（与复数 i² = −1 对称）

为什么 ε² = 0：
  (a + bε)(c + dε) = ac + (ad + bc)ε + bd·ε² = ac + (ad+bc)ε
  → 一次项系数恰好 = 乘法法则的导数形式（ad + bc）

推论：在对偶数环上执行任意函数 f(x + ε)：
  f(x + ε) = f(x) + f'(x)·ε（泰勒展开，ε² 及更高阶消失）
  → AD 是"精确代数运算"而非数值近似（2026 学术观点）

工程意义：
  JAX/Julia 的前向模式 = 对偶数实现
  硬件趋势：GPU 的 grad_scale 指令、TPU 编译期不变量（2026 报道）
  → AD 从"技巧"升格为"代数/编译器语义"
```

## 9. 数值积分与高维蒙特卡洛

```text
（05/07 章已给方法，此处给统一视角）

确定性方法（低维）：
  梯形 O(1/n²)、辛普森 O(1/n⁴) —— 适合 1-3 维

高维（d ≥ 4）：
  蒙特卡洛：误差 O(1/√N)，与维度无关
  应用：期权定价、贝叶斯 MCMC、渲染（路径追踪）、粒子滤波

联系深度学习的采样：
  Dropout（训练期随机丢弃 = 蒙特卡洛式集成）
  VAE 的重参数化采样（期望 = 蒙特卡洛估计）
  扩散模型训练（噪声采样 = 期望估计）
  → 深度学习的"随机性"大量是蒙特卡洛积分的化身
```

## 10. 核心要点与思考题

> 🎯 **本章三句话总结**：
> 1. 三条求导路线：数值（有误差，做验证）、符号（膨胀，做推导）、自动微分（精确+高效，做训练）——深度学习选 AD；
> 2. 反向模式 AD（一次反向得全部梯度）> 前向模式（一次正向得单输入导数）——反向传播 = 反向模式 AD 在计算图上的执行；
> 3. 2026 趋势：矩阵微积分课程化（MIT 18.063）、隐式微分、可微编程、AD 进入编译器/硬件语义——微分不再只是"求导技巧"而是计算基础设施。

3. 对偶数 ε²=0 与导数的关系？（→ 7 乘法法则自动出现）
