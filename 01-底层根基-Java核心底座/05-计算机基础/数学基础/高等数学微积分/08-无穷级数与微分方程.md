## 1. 数项级数：定义与判敛

### 1.1 定义

```text
级数 = 无限项求和：Σ aₙ = a₁ + a₂ + a₃ + ...

收敛性：部分和 Sₙ = a₁+...+aₙ 的极限存在 → 级数收敛
  Σ 1/2ⁿ = 1（几何级数收敛）
  Σ 1/n = ∞（调和级数发散——"1/n 之和发散"是著名反直觉事实）

必要条件：收敛 ⇒ aₙ → 0
  ⚠️ 逆命题不成立（调和级数 aₙ→0 但发散）
  → 首查：aₙ 不趋于 0 → 必发散（最快判断）
```

### 1.2 两类基础级数（判敛的"标尺"）

```text
几何级数：Σ rⁿ —— |r|<1 收敛，|r|≥1 发散
  → 收敛和 = a/(1−r)（等比求和公式的极限）

p-级数：Σ 1/nᵖ —— p>1 收敛，p≤1 发散
  p=1 调和（发散）；p=2（收敛于 π²/6）
  → 与反常积分 ∫1/xᵖ 同敛散（积分判别法的对象）
```

## 2. 五大判敛法

| 方法 | 适用 | 规则 | 例子 |
|------|------|------|------|
| 比较判别 | 正项级数 | aₙ ≤ bₙ 且 Σb 收敛 → Σa 收敛 | Σ1/n² 与 Σ1/nᵖ |
| 极限比较 | 正项级数 | lim aₙ/bₙ = c>0 → 同敛散 | 与 p-级数对标 |
| 比值判别（达朗贝尔） | 含阶乘/指数 | lim aₙ₊₁/aₙ = ρ：ρ<1 收敛，ρ>1 发散 | Σn!/nⁿ |
| 根值判别（柯西） | 含 n 次幂 | lim ⁿ√aₙ = ρ：同上 | Σ(1+1/n)^(n²) |
| 积分判别 | 单调正项 | ∫f dx 与 Σf(n) 同敛散 | Σ1/(n ln n) |

```text
交错级数（莱布尼茨判别）：
  Σ(−1)ⁿ bₙ，bₙ 单调递减趋于 0 → 收敛
  → 条件收敛 vs 绝对收敛：
     Σ|aₙ| 收敛 = 绝对收敛（最强的收敛）
     |aₙ| 发散但 Σaₙ 收敛 = 条件收敛（如 Σ(−1)ⁿ/n）
  绝对收敛 ⇒ 收敛；重排性质只在绝对收敛下保持
```

## 3. 幂级数与收敛半径

```text
幂级数：Σ cₙ(x−a)ⁿ —— 以 a 为中心的"多项式级数"

收敛半径 R（比值/根值法求）：
  R = lim |cₙ/cₙ₊₁|（或 1/lim ⁿ√|cₙ|）
  收敛区间：|x−a| < R 内绝对收敛；|x−a| > R 发散；端点需单独判断

性质（收敛区间内"像多项式一样好用"）：
  可逐项求导/积分（导数与积分的级数形式）
  和函数连续
  → 幂级数是"函数的无限多项式表示"——泰勒级数的容器
```

## 4. 泰勒级数与函数展开

### 4.1 展开

```text
泰勒级数（03 章泰勒公式的"无穷阶"版本）：
  f(x) = Σ f⁽ⁿ⁾(a)/n! · (x−a)ⁿ（收敛域内）

麦克劳林展开（a=0）五条基础（03 章记忆过）：
  e^x、sin x、cos x、ln(1+x)、1/(1−x)

展开技巧：
  复合：e^(−x²) = Σ (−1)ⁿx^(2ⁿ)/n!（代入法）
  积分：∫e^(−x²)dx = Σ (−1)ⁿx^(2n+1)/(n!(2n+1))（逐项积分）
  → 非初等函数的"幂级数表示"——数值计算的原料
```

### 4.2 工程价值

```text
函数库实现：数学库（Math.exp/sin/cos）背后 = 截断泰勒/多项式近似
  截断误差 = 余项估计（拉格朗日余项给出误差上界）
  → 保证"算得快且足够准"的数学依据

计算机精度视角：e^x 的实现 = 多项式 + 区间约化（range reduction）
  → 理解数值算法 = 理解级数收敛与截断
```

## 5. 傅里叶级数

```text
思想：周期函数 = 正弦/余弦的叠加（与泰勒"多项式展开"互补）

傅里叶级数：
  f(x) ~ a₀/2 + Σ[aₙcos(nx) + bₙsin(nx)]
  系数（正交性提取）：
    aₙ = (1/π)∫₋π^π f(x)cos(nx)dx
    bₙ = (1/π)∫₋π^π f(x)sin(nx)dx

收敛：周期连续可导（分段光滑）→ 收敛到函数值
  间断点处收敛到左右极限平均（吉布斯现象：跳变处过冲 ~9%）

工程地位：
  信号处理 = 傅里叶分析的天下（FFT = 快速傅里叶变换）
  音频/图像压缩（JPEG 的 DCT = 余弦变换）
  谱分析、滤波器设计
  → 计算机科学中微积分最"实"的分支
```

> 🎯 **核心要点**：两种"分解世界观"——泰勒把函数分解为幂（xⁿ，局部逼近），傅里叶把函数分解为频率（cos/sin，全局周期逼近）。前者服务数值计算，后者服务信号处理。

## 6. 微分方程总览

```text
微分方程 = 含导数的方程（描述"变化率与状态的关系"）
  dy/dx = ky（指数增长：人口/复利/衰减）
  d²y/dt² + ω²y = 0（简谐振动：弹簧/LC 电路）

分类：
  阶数：最高导数的阶（一阶/二阶）
  线性：y、y'、y'' 都是一次（非线性如 y²、yy' 难解）
  常微分方程（ODE）vs 偏微分方程（PDE，含多元偏导）

意义：自然界的规律 = 变化率关系 → 万物皆微分方程
  → AI 视角：残差网络是离散化的 ODE（第 9 节）
```

## 7. 一阶微分方程

| 类型 | 形式 | 解法 |
|------|------|------|
| 可分离变量 | dy/dx = f(x)g(y) | 分离：∫dy/g(y) = ∫f(x)dx |
| 齐次方程 | dy/dx = φ(y/x) | 令 u = y/x 化为可分离 |
| 一阶线性 | y' + P(x)y = Q(x) | **积分因子法**（见下） |
| 伯努利 | y' + Py = Qyⁿ | 令 z = y^(1−n) 化线性 |

```text
一阶线性（最重要）：
  y' + P(x)y = Q(x)
  积分因子 μ = e^(∫P dx)
  通解：y = (1/μ)·∫μ·Q dx + C/μ

应用模型（经典）：
  增长模型 dy/dt = ky → y = Ce^(kt)（指数增长/衰减）
  逻辑斯蒂模型 dy/dt = ky(1 − y/M)（人口饱和增长，S 曲线）
  RC 电路、牛顿冷却、药物代谢——全部一阶线性/可分离
```

## 8. 二阶线性微分方程

### 8.1 齐次方程（核心）

```text
y'' + py' + qy = 0（p、q 常数）
特征方程：r² + pr + q = 0

三种情形（对应三种通解形态）：
  ① 两实根 r₁ ≠ r₂：y = C₁e^(r₁x) + C₂e^(r₂x)
  ② 重根 r₁ = r₂：y = (C₁ + C₂x)e^(r₁x)
  ③ 共轭复根 r = α ± βi：y = e^(αx)(C₁cosβx + C₂sinβx)
     → 情形③ = 振动/振荡（阻尼弹簧、RLC 电路）
```

### 8.2 非齐次方程

```text
y'' + py' + qy = f(x)
通解 = 齐次通解 + 特解

待定系数法（f 为多项式/指数/三角时）：
  f(x) = e^(kx)·Pₘ(x) 类 → 特解形如 x^s·e^(kx)·Qₘ(x)
  s = k 作为特征根的重数（0/1/2）
  → "共振"的来源：f 与齐次解同形时特解要乘 x^s
```

### 8.3 应用

```text
弹簧振子：mx'' + cx' + kx = F(t)（质量-阻尼-刚度）
  → 无阻尼自由振动 = 情形③（sin/cos 解）
  → 受迫振动 + 共振 = 待定系数特解形态

RLC 电路：Lq'' + Rq' + q/C = E(t)（与弹簧完全同构！）
  → 微分方程的统一性：机械与电气共享同一数学

2026 AI 视角：扩散模型 = 随机微分方程（SDE）——第 9 节
```
