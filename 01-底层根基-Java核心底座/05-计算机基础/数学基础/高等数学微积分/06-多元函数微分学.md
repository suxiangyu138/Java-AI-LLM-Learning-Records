## 1. 多元函数与偏导数

### 1.1 多元函数

```text
f: Rⁿ → R：n 个输入，一个输出
  f(x, y) = x² + y²（二元）
  loss(w₁, w₂, ..., wₙ)（损失函数 = n 元函数）

几何：二元函数是曲面（z = f(x,y)）；等高线 = 截面
```

### 1.2 偏导数

```text
∂f/∂x = lim(h→0) [f(x+h, y) − f(x,y)] / h
  → 把 y 当常数，对 x 求导（"固定其他，动一个"）

示例：f(x,y) = x²y + sin(xy)
  ∂f/∂x = 2xy + y·cos(xy)
  ∂f/∂y = x² + x·cos(xy)

二阶偏导：∂²f/∂x²、∂²f/∂y²、混合 ∂²f/∂x∂y
  ⚠️ 混合偏导与顺序无关（克莱罗定理，f 足够光滑时）
  ∂²f/∂x∂y = ∂²f/∂y∂x
```

> 🎯 **核心要点**：偏导 = "一次只看一个维度"的导数——深度学习里对参数 wᵢ 求梯度，就是逐个偏导。向量化后：∇f = (∂f/∂x₁, ..., ∂f/∂xₙ) 梯度向量。

## 2. 全微分

```text
全微分：所有方向变化的线性叠加
  dz = (∂z/∂x)dx + (∂z/∂y)dy

可微的充分条件：偏导数连续 → 可微
（偏导存在 ⇏ 可微：如 f = xy/√(x²+y²) 在原点偏导存在但不可微）

几何：全微分 = 切平面近似（曲面上一点的切平面）
  z ≈ z₀ + ∂z/∂x·Δx + ∂z/∂y·Δy

工程价值：误差传播
  物理测量 x、y 有误差 → 结果误差 ≈ |∂f/∂x|Δx + |∂f/∂y|Δy
  → 机器学习中梯度范数 = 损失对输入扰动的敏感度（对抗攻击的理论）
```

## 3. 多元链式法则

### 3.1 公式

```text
情形一：z = f(x,y)，x = x(t), y = y(t)
  dz/dt = (∂f/∂x)(dx/dt) + (∂f/∂y)(dy/dt)

情形二：z = f(x,y)，x = x(s,t), y = y(s,t)
  ∂z/∂s = (∂f/∂x)(∂x/∂s) + (∂f/∂y)(∂y/∂s)
  ∂z/∂t = (∂f/∂x)(∂x/∂t) + (∂f/∂y)(∂y/∂t)

本质：沿依赖路径逐项求导求和（"链式求和"）
```

### 3.2 与反向传播的对应

```text
神经网络 loss = L(a₃)，a₃ = f₃(W₃a₂)，a₂ = f₂(W₂a₁)，a₁ = f₁(W₁x)

计算图视角：
  ∂loss/∂a₁ = ∂loss/∂a₃ · ∂a₃/∂a₂ · ∂a₂/∂a₁   （逐层连乘）

反向传播 = 从输出往输入，把每条路径的局部导数相乘并求和
  → 多元链式法则在"计算图"上的系统化执行
  → 每个节点只需算"局部梯度"（∂节点/∂输入），全局梯度 = 路径乘积之和
```

## 4. 方向导数与梯度

### 4.1 方向导数

```text
∂f/∂l = lim [f(x+cosα·t, y+cosβ·t) − f(x,y)] / t
  → 函数沿方向 l（单位向量 u = (cosα, cosβ)）的变化率

计算公式：∂f/∂l = ∇f · u（梯度与方向向量的点积）
```

### 4.2 梯度的核心性质

```text
∇f = (∂f/∂x, ∂f/∂y)

三大性质（深度学习的地基）：
  ① 方向：梯度指向函数"上升最快"的方向
     → 负梯度 = 下降最快 → 梯度下降法的理论依据
  ② 大小：|∇f| = 最大方向导数值（变化率上限）
  ③ 垂直：梯度垂直于等高线（切向方向导数 = 0）

梯度下降更新：w ← w − η·∇L(w)
  从当前点沿负梯度走一小步（η 学习率），反复迭代
  → 深度学习训练的全部数学内核
```

> 🎯 **核心要点**：梯度 = "函数增长最快的方向与速率"。梯度下降"沿负梯度走"不是约定而是**最优**（一阶信息下的最优步进方向）；梯度与等高线垂直解释了为什么参数更新垂直于损失曲面。

## 5. 海森矩阵与二阶条件

### 5.1 定义

```text
H = [∂²f/∂x₁²   ∂²f/∂x₁∂x₂  ... ]
    [∂²f/∂x₂∂x₁  ∂²f/∂x₂²   ... ]
    ...
    （对称矩阵：混合偏导相等）

几何：描述曲面的"弯曲程度"（曲率）
  H 正定（所有特征值 > 0）→ 局部极小
  H 负定（所有特征值 < 0）→ 局部极大
  H 不定（特征值异号）→ 鞍点
```

### 5.2 鞍点与深度学习

```text
鞍点：某些方向极小、某些方向极大（马鞍形状）
  f(x,y) = x² − y² 在 (0,0) 是鞍点（H 不定）

深度学习的现实：
  高维损失函数中鞍点数量远超局部极小（统计结论）
  → 梯度在鞍点附近"停滞"（所有方向导数≈0）
  → 动量法/Adam 的动量项 = 冲出鞍点的工程手段
  → 这是理解"深度学习优化为何难"的数学根源
```

## 6. 多元函数的极值

```text
求极值流程：
  ① 必要条件（驻点）：∇f = 0（梯度为零向量）
  ② 充分条件：海森矩阵判定
     H 正定 → 极小；H 负定 → 极大；H 不定 → 鞍点；H 半定 → 需进一步

与一元对照：
  一元 f'=0 且 f''>0 → 极小（02/03 章）
  多元 ∇f=0 且 H 正定 → 极小
  → 一维的"二阶导符号"推广为"海森正定性"

全局 vs 局部：
  f 为凸函数（H 半正定恒成立）→ 驻点即全局最小
  非凸 → 只能保证局部（深度学习的现实）
```

## 7. 拉格朗日乘数法：条件极值

### 7.1 原理

```text
问题：约束 g(x,y) = 0 下，求 f(x,y) 的极值

构造拉格朗日函数：
  L(x, y, λ) = f(x, y) − λ·g(x, y)

求驻点：∇L = 0
  ∂L/∂x = 0，∂L/∂y = 0，∂L/∂λ = 0（= g = 0 约束本身）

几何直觉：极值点处，目标函数等高线与约束曲线相切
  → 两者梯度平行：∇f = λ∇g（λ 是比例系数）
```

### 7.2 典型应用

```text
经典例题：求 x+y = 1 约束下 x²+y² 的最小值
  L = x²+y² − λ(x+y−1)
  2x = λ，2y = λ → x = y = 1/2 → 最小值 1/2

工程应用：
  支持向量机（SVM）的约束优化（间隔最大化 = 约束极值）
  信息论：最大熵模型（约束下熵最大化）
  经济学：效用最大化（预算约束下）
  深度学习正则化视角：L2 正则 ≈ 权重范数约束的拉格朗日形式
```

## 8. 从多元微积分到深度学习

```text
完整映射表：
  偏导数        ↔ 损失对单个参数的敏感度
  梯度 ∇L       ↔ 参数更新方向（负梯度下降）
  多元链式法则   ↔ 反向传播（计算图路径乘积求和）
  海森矩阵 H     ↔ 损失曲率（Adam 的自适应步长/二阶优化）
  鞍点           ↔ 高维优化的停滞点（动量/Adam 的动机）
  拉格朗日乘数法 ↔ 约束优化（SVM/最大熵）
  凸性（H≥0）    ↔ 收敛性保证（非凸 = 训练难的理论根源）

2026 趋势（09 章续）：
  矩阵微积分成为 ML 课程一等公民（MIT 18.063）
  自动微分从反向传播扩展到隐式微分/一阶 AD
```

## 9. 核心要点与思考题

> 🎯 **本章三句话总结**：
> 1. 偏导=固定其他看一个维度，梯度=上升最快方向（下降走负梯度），多元链式法则=反向传播的数学本体；
> 2. 海森矩阵判断极值类型（正定极小/负定极大/不定鞍点）——高维鞍点多是深度学习优化的数学根源；
> 3. 拉格朗日乘数法处理约束极值（∇f = λ∇g 相切条件），是 SVM/最大熵/正则化的理论工具。

**思考题**：

1. 为什么梯度下降走"负梯度"而不是任意方向？（→ 4.2 方向导数最大值）
2. 鞍点处梯度为零，为什么优化会卡住？（→ 5.2）
3. 反向传播如何体现"多元链式法则"？（→ 3.2）
4. 拉格朗日乘数法里 λ 的几何意义？（→ 7.1 梯度平行）
