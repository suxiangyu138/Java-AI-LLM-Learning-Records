## 1. 极限的定义：ε-δ 语言

### 1.1 直观与严格

```text
直观：x 越来越接近 x0 时，f(x) 无限接近常数 L —— 记为 lim f(x) = L (x→x0)

严格（ε-δ 定义，柯西）：
  对任意 ε > 0，存在 δ > 0，使得当 0 < |x − x0| < δ 时，恒有 |f(x) − L| < ε

理解：无论你把误差要求（ε）放得多小，
      我都能找到一个"邻域半径"（δ），让该邻域内的所有 x 都满足要求
      —— "逼近"是过程的性质，与"x0 处有没有定义"无关！

关键：极限考察 x0 的"去心邻域"（0 < |x−x0|），不要求 f(x0) 存在
      → 这解释了"可去间断点"：极限存在但函数值缺失/不同
```

### 1.2 单侧极限与极限存在的充要条件

```text
lim f(x) = L  ⟺  lim⁻ f(x) = L 且 lim⁺ f(x) = L
（左极限 = 右极限 = L，三者相等）

常用结论：|x|、分段函数在分段点的极限必须分侧讨论
```

## 2. 极限的性质与运算法则

```text
四则运算（极限都存在时）：
  lim(f±g) = lim f ± lim g
  lim(f·g) = lim f · lim g
  lim(f/g) = lim f / lim g（lim g ≠ 0）
  → 分母为 0 时不能直接用（需变形/洛必达，03 章）

复合函数极限：lim f(g(x)) = f(lim g(x))（f 连续时）
夹逼准则（Squeeze）：
  g(x) ≤ f(x) ≤ h(x) 且 lim g = lim h = L → lim f = L
  → 证明重要极限 sinx/x 的工具

单调有界定理：单调递增（减）且有上（下）界 → 极限存在
  → 证明数列收敛（如 e 的定义）的工具
```

> 🎯 **核心要点**：极限计算的"三把刀"——四则运算（分母非零）、夹逼准则（不等关系）、单调有界（数列收敛）。后续的等价无穷小替换与洛必达是它们的速算化。

## 3. 两个重要极限

### 3.1 第一个：lim(x→0) sinx/x = 1

```text
几何证明（夹逼）：单位圆中 sinx < x < tanx → cosx < sinx/x < 1 → 夹逼得 1

推论（等价无穷小，x→0）：
  sinx ~ x   tanx ~ x   arcsinx ~ x
  e^x − 1 ~ x   ln(1+x) ~ x   (1+x)^n − 1 ~ nx
  1 − cosx ~ x²/2

工程价值：计算机图形学/数值计算中，小角度近似 sinθ ≈ θ 就是这个极限
```

### 3.2 第二个：lim(1 + 1/n)^n = e

```text
单调有界：数列 (1+1/n)^n 单调递增且有上界 → 收敛，记作 e ≈ 2.71828

推广：lim(1 + x)^(1/x) = e（x→0）；lim(1 + a/x)^x = e^a（x→∞）

e 的地位：指数函数 e^x 是"导数等于自身"的唯一函数
  → 深度学习中的 softmax/sigmoid、自然对数、熵全部以 e 为底
```

## 4. 无穷小与无穷大

### 4.1 定义与比较

```text
无穷小：极限为 0 的变量（x→x0 时 α(x)→0）
无穷大：|f(x)| 无限增大（记为 ∞，不是数）

无穷小的阶（比较收敛速度）：
  lim α/β = 0        → α 是 β 的高阶无穷小（α 更快到 0）
  lim α/β = ∞        → α 是 β 的低阶无穷小
  lim α/β = c ≠ 0    → 同阶无穷小
  lim α/β = 1        → 等价无穷小（记 α ~ β）

等价无穷小替换（乘除可换，加减慎用！）：
  lim α/β = 1 时，计算 lim f·α/g·β 可把 α、β 替换为更简单形式
  ⚠️ 加减项中直接替换会出错（如 sinx − x ≠ 0，需泰勒展开到高阶）
```

### 4.2 高阶无穷小的记号

```text
o(x^n)：比 x^n 高阶的无穷小（x→0）
  → 泰勒公式的余项记号（03 章）
  e^x = 1 + x + x²/2 + o(x²)：x² 以上的项都可忽略
```

## 5. 函数的连续性

```text
连续定义：lim(x→x0) f(x) = f(x0)
  三条件缺一不可：
  ① f(x0) 有定义
  ② lim f(x) 存在（左右极限相等）
  ③ 极限值 = 函数值

连续性的运算：连续函数的四则/复合/反函数仍连续
基本初等函数在其定义域内连续（多项式/指数/对数/三角）
→ 求连续函数极限 = 直接代入（lim f(x) = f(x0)）
```

## 6. 间断点的分类

| 类型 | 条件 | 例子 |
|------|------|------|
| **可去间断点** | 左右极限存在且相等，但 ≠ 函数值/无定义 | f(x) = sinx/x 在 x=0 |
| **跳跃间断点** | 左右极限存在但不相等 | 取整函数 [x]、分段函数 |
| **第二类间断点** | 至少一侧极限不存在（无穷/振荡） | 1/x 在 0（无穷）；sin(1/x) 在 0（振荡） |

```text
记忆：第一类 = 左右极限都存在（可去/跳跃）
      第二类 = 至少一侧不存在（无穷/振荡）
```

## 7. 闭区间连续函数的三大性质

```text
设 f 在 [a,b] 连续：
① 有界性：f 在 [a,b] 上有界（闭区间连续 → 必有界）
② 最值定理：f 在 [a,b] 上必取得最大值 M 与最小值 m
③ 介值定理：对任意 η ∈ (m, M)，存在 ξ ∈ (a,b) 使 f(ξ) = η
   推论（零点定理）：f(a)·f(b) < 0 → 存在 ξ ∈ (a,b) 使 f(ξ) = 0
   → 二分法求根的数学依据！（计算机数值分析）

工程价值：
  零点定理 → 二分法（每迭代一次区间减半）
  介值定理 → 保证"连续过程的中间状态必经过"（如温度渐变必经过每个中间温度）
```

## 8. 极限计算的常见错误与速算技巧

### 8.1 五大高频错误

| 错误 | 反例 | 正确做法 |
|------|------|---------|
| 直接代入 0/0 | (x²−1)/(x−1) 在 x=1 | 先因式分解再代入 |
| 等价无穷小替换加减项 | sinx − x ≠ 0（x→0） | 泰勒展开到高阶（03 章） |
| 忽略左右极限 | 1/x 在 x=0 两侧不同 | 分段讨论 |
| 0·∞ 直接乘 | x·(1/x²) 形式 | 化为 0/0 或 ∞/∞ |
| 1^∞ 当 1 处理 | (1+1/n)^n → e（不是 1！） | 取对数（重要极限②） |

### 8.2 速算技巧清单

```text
① 多项式比：lim(x→∞) P(x)/Q(x) = 首项系数比（次数相同）/ 0 / ∞
② 根式有理化：(√(x+1) − √x) → 分子有理化（乘共轭）
③ 等价无穷小链（x→0）：sinx~x~tanx~arcsinx；e^x−1~x；ln(1+x)~x
④ 夹逼配合：|sin(1/x)| ≤ 1 → x·sin(1/x) → 0
⑤ 洛必达兜底：0/0 或 ∞/∞ 且导数比极限存在（03 章）

⚠️ 速算 ≠ 乱算：每步都要有定理依据（等价替换条件、洛必达条件）
```

### 8.3 计算机视角：数值极限的陷阱

```text
计算机"算极限"用逼近（代入小 h）——浮点陷阱：
  f'(x) ≈ (f(x+h) − f(x))/h：h 太小 → 相减抵消（微积分 09 章）
  → 数值极限有"最优步长"（√ε ≈ 1e-8）
  → 工程上：能解析求极限就别数值逼近；数值逼近要报告误差
```

## 9. 核心要点与思考题

> 🎯 **本章三句话总结**：
> 1. 极限是"去心邻域"上的逼近过程（与 x0 处定义无关），ε-δ 语言是严格化；
> 2. 计算三工具：四则（分母非零）、夹逼、单调有界；两个重要极限派生全部等价无穷小；
> 3. 连续三条件（定义/极限存在/相等）；闭区间连续 ⇒ 有界+最值+介值——零点定理是二分法的数学保证。

**思考题**：

1. 为什么"可去间断点"处极限存在但函数不连续？（→ 1.1/6）
2. sinx − x 在 x→0 时为什么不能直接替换成 0？（→ 4.1 加减慎用）
3. 二分法找根依赖哪个定理？（→ 7 零点定理）
4. lim(1+1/n)^n 的收敛性靠什么保证？（→ 3.2 单调有界）
