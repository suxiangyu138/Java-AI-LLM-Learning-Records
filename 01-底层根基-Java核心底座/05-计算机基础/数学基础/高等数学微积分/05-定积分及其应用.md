## 1. 定积分的定义：黎曼和

### 1.1 构造过程（四步）

```text
∫ₐᵇ f(x)dx 的构造：
  ① 分割：[a,b] 切成 n 份（Δxᵢ）
  ② 取样：每份取一点 ξᵢ
  ③ 求和：Σ f(ξᵢ)·Δxᵢ（矩形面积和 = 黎曼和）
  ④ 取极限：max Δxᵢ → 0 时黎曼和的极限 = 定积分

几何：曲线与 x 轴围成的"带符号面积"（x 轴下方为负）
物理：速度曲线的积分 = 位移（v(t)dt 累加 = 路程）
```

### 1.2 存在性

```text
可积的充分条件：f 在 [a,b] 连续（或只有有限个第一类间断点）
→ 连续函数必可积；可积未必连续（分段常值函数可积）
```

## 2. 牛顿-莱布尼茨公式

### 2.1 公式（微积分基本定理）

```text
∫ₐᵇ f(x)dx = F(b) − F(a)     其中 F' = f

意义：把"无限求和"化为"找原函数代入"——定积分计算的唯一主通道
  计算步骤：求不定积分 → 上下限代入 → 相减

变上限积分（原函数的构造）：
  Φ(x) = ∫ₐˣ f(t)dt → Φ'(x) = f(x)
  → 任何连续函数的原函数都存在（积出来），即使"算不出初等表达式"
  → 如 e^(−x²) 的原函数（正态分布！）无法用初等函数表示，
    但 Φ(x) 存在——概率论中正态分布函数就是这样定义的
```

### 2.2 变限积分求导（考试与工程常用）

```text
d/dx ∫ₐ^(g(x)) f(t)dt = f(g(x))·g'(x)
d/dx ∫_(h(x))^(g(x)) f(t)dt = f(g(x))g'(x) − f(h(x))h'(x)
```

> 🎯 **核心要点**：牛顿-莱布尼茨是"定积分=找原函数"的桥梁；但**不是所有原函数都存在初等表达式**（e^(−x²)、sinx/x）——这类积分只能数值求解（第 8 节），这是计算机科学介入微积分的入口。

## 3. 定积分的性质

```text
线性：∫(af+bg) = a∫f + b∫g
区间可加：∫ₐᵇ = ∫ₐᶜ + ∫꜀ᵇ（c 在区间内）
方向性：∫ₐᵇ = −∫ᵇₐ（换上下限变号）
保号性：f ≥ 0 → ∫f ≥ 0；f ≤ g → ∫f ≤ ∫g
估值定理：m(b−a) ≤ ∫ₐᵇ f ≤ M(b−a)（m、M 为最值）
对称性（速算利器）：
  f 为奇函数：∫₋ₐᵃ f = 0
  f 为偶函数：∫₋ₐᵃ f = 2∫₀ᵃ f
周期性：∫₀ᵀ f = ∫ₐ^(a+T) f（周期 T）
```

## 4. 定积分的换元与分部

```text
换元（注意换限！）：
  ∫ₐᵇ f(x)dx，令 x = φ(t)：
  = ∫_(φ⁻¹(a))^(φ⁻¹(b)) f(φ(t))·φ'(t)dt
  → 上下限随变量一起换（无需回代 x！——与不定积分的差别）

分部：∫ₐᵇ u dv = [uv]ₐᵇ − ∫ₐᵇ v du

经典定积分（华里士公式）：
  ∫₀^(π/2) sinⁿx dx = (n−1)!!/n!! · (π/2 或 1)
  n 偶 → ×π/2；n 奇 → ×1
  → 概率论中的球体积分、高斯积分的计算工具

高斯积分（概率论核心）：
  ∫₋∞^∞ e^(−x²) dx = √π
  → 正态分布密度函数的归一化常数
```

## 5. 反常积分

### 5.1 两类

```text
① 无穷限：∫ₐ^∞ f dx = lim(b→∞) ∫ₐᵇ f dx
  ∫₁^∞ 1/x^p dx：p>1 收敛，p≤1 发散（p-积分判别）
  例：∫₁^∞ 1/x² dx = 1（收敛）；∫₁^∞ 1/x dx = ∞（发散）

② 瑕积分（无界函数）：f 在端点趋于 ∞
  ∫₀¹ 1/x^p dx：p<1 收敛，p>1 发散
  例：∫₀¹ 1/√x dx = 2（收敛）；∫₀¹ 1/x² dx = ∞（发散）

收敛性判断（不必求出原函数）：
  比较判别法：|f| ≤ g 且 ∫g 收敛 → ∫f 收敛
  极限比较：lim f/g = c → 同敛散
  → 概率密度是否"可归一化"的判断工具
```

### 5.2 工程意义

```text
概率论：密度函数 ∫f = 1（归一化）——期望/方差都靠反常积分
信息论/机器学习：∫p(x)ln p(x)dx（熵）、高斯/拉普拉斯积分
信号处理：傅里叶变换 = 反常积分（08 章级数 + 应用）
```

## 6. 几何应用：面积、体积与弧长

| 应用 | 公式 | 说明 |
|------|------|------|
| 平面面积 | A = ∫ₐᵇ [f(x) − g(x)]dx | 两曲线围成（上减下） |
| 极坐标面积 | A = (1/2)∫ r²(θ)dθ | 极坐标扇形 |
| 旋转体体积 | V = π∫ₐᵇ [f(x)]²dx | 绕 x 轴（圆盘法） |
| 壳层法 | V = 2π∫ₐᵇ x·f(x)dx | 绕 y 轴 |
| 弧长 | L = ∫ₐᵇ √(1+[f'(x)]²)dx | 曲线长度 |
| 旋转曲面面积 | S = 2π∫ₐᵇ f(x)√(1+f'²)dx | 绕 x 轴 |

```text
统一思想：一切几何量 = "微元 × 累加"：
  面积微元 dA = 高·宽；体积微元 dV = 截面·厚；弧长微元 ds = √(dx²+dy²)
  → 定积分 = 微元累加的极限（工程建模的核心思维）
```

## 7. 物理与工程应用

```text
运动学：位移 = ∫v dt；v = ∫a dt（初速条件定 C）
做功：W = ∫F(x)dx（变力做功）
液体压力：P = ρg∫h·dA
质心/形心：(∫x·f dx)/(∫f dx)
概率：期望 E[X] = ∫x·f(x)dx；方差 = ∫(x−μ)²f(x)dx
电流/电荷：Q = ∫I(t)dt
→ 微积分是物理建模的统一语言；CS 侧数值模拟 = 对上述积分离散化
```

## 8. 数值积分：计算机的定积分

### 8.1 为什么需要

```text
① 原函数无初等表达式（e^(−x²)、sinx/x）
② 被积函数来自实验数据（只有采样点，无解析式）
→ 数值积分用"采样点加权求和"近似定积分
```

### 8.2 三种基本方法

| 方法 | 思想 | 精度 | 公式（等分 n 段） |
|------|------|:---:|------|
| 矩形法 | 每段取常数 | O(1/n) | Σf(xᵢ)·Δx |
| 梯形法 | 每段取直线 | O(1/n²) | (Δx/2)[f₀ + 2f₁ + ... + 2fₙ₋₁ + fₙ] |
| 辛普森法 | 每两段取抛物线 | **O(1/n⁴)** | (Δx/3)[f₀+4f₁+2f₂+...+fₙ] |

```text
精度对比（1/n⁴ vs 1/n）：辛普森用 10 段 ≈ 梯形用 10000 段的精度
误差分析：梯形误差 ∝ f'' 最大值；辛普森 ∝ f⁽⁴⁾
自适应方法：误差大的区间加密（工业实现的基础）
```

### 8.3 Java 实现示例（梯形法）

```java
// 梯形法求 ∫₀¹ e^(−x²)dx（正态分布积分的经典用例）
public static double trapezoid(Function<Double, Double> f,
                               double a, double b, int n) {
    double h = (b - a) / n;
    double sum = (f.apply(a) + f.apply(b)) / 2;
    for (int i = 1; i < n; i++) {
        sum += f.apply(a + i * h);
    }
    return sum * h;
}
// e^(−x²) 在 [0,1] 无初等原函数 → 数值积分是唯一通用解
```

> 🎯 **核心要点**：数值积分是"采样求和"的艺术——矩形/梯形/辛普森是精度阶梯（O(1/n) → O(1/n²) → O(1/n⁴)）；工业级实现用自适应加密。这是微积分与计算机科学的第一个直接接口（09 章续）。

## 9. 核心要点与思考题

> 🎯 **本章三句话总结**：
> 1. 定积分 = 黎曼和的极限（带符号面积）；牛顿-莱布尼茨把求和化为找原函数；
> 2. 非初等原函数（e^(−x²)）迫使数值积分登场：梯形 O(1/n²)、辛普森 O(1/n⁴)；
> 3. 反常积分判敛（p-积分/比较判别）是概率归一化与信号处理的基础工具。

**思考题**：

1. 定积分换元与不定积分换元的最大差别？（→ 4 换限无需回代）
2. 为什么 ∫₋∞^∞ e^(−x²)dx = √π 重要？（→ 5.2 概率归一化）
3. 辛普森法为什么比梯形法快这么多？（→ 8.2 精度阶）
4. 偶函数在对称区间积分的速算？（→ 3 对称性）
