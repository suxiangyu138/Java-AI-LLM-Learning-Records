# 导数与微分

> 导数是"变化率"：瞬时速度、边际成本、梯度——全是导数。微分是"线性逼近"：在一点附近用切线代替曲线。求导法则（四则、复合、隐函数）是微积分的"计算基本功"，深度学习的反向传播本质就是复合函数求导的规模化

## 1. 导数的定义与几何意义

### 1.1 定义

```text
f'(x0) = lim(Δx→0) [f(x0+Δx) − f(x0)] / Δx
       = lim(x→x0) [f(x) − f(x0)] / (x − x0)

导数 = 差商（平均变化率）的极限 = 瞬时变化率

三种等价形式（解题常换着用）：
  ① f'(x0) = lim[h→0] [f(x0+h) − f(x0)] / h
  ② f'(x0) = lim[x→x0] [f(x) − f(x0)] / (x − x0)
  ③ f'(x0) = lim[Δx→0] Δy / Δx
```

### 1.2 几何意义与物理意义

```text
几何：f'(x0) = 曲线 y=f(x) 在点 (x0, f(x0)) 处切线的斜率
  切线方程：y − f(x0) = f'(x0)(x − x0)

物理：位移 s(t) → v(t) = s'(t)（速度）；v(t) → a(t) = v'(t)（加速度）

经济学：总成本 C(x) → 边际成本 C'(x)（多产一件的增量成本）
```

## 2. 可导与连续的关系

```text
定理：可导 ⇒ 连续（导数的存在蕴含差商极限有限 → 函数必连续）
反例：连续 ⇏ 可导 —— 尖点处不可导！

经典反例：f(x) = |x| 在 x=0 连续但不可导
  左导数 = −1，右导数 = +1，两侧不相等 → 尖点无切线

推论（判断不可导的常见点）：
  尖点（|x|）、垂直切线点（x^(1/3) 在 0）、振荡点（x·sin(1/x) 在 0）
```

> 🎯 **核心要点**：可导比连续"严格"——连续是"不断开"，可导还要"不尖"。深度学习里 ReLU 在 0 点不可导（次梯度 0 或 1 任取），正是这个事实的工程处理。

## 3. 基本求导公式表

| f(x) | f'(x) | | f(x) | f'(x) |
|------|-------|-|------|-------|
| C（常数） | 0 | | sin x | cos x |
| x^n | n·x^(n−1) | | cos x | −sin x |
| e^x | e^x | | tan x | sec²x |
| a^x | a^x·ln a | | arcsin x | 1/√(1−x²) |
| ln x | 1/x | | arccos x | −1/√(1−x²) |
| logₐx | 1/(x·ln a) | | arctan x | 1/(1+x²) |
| √x | 1/(2√x) | | 1/x | −1/x² |

```text
记忆技巧：
  ① e^x 是唯一"导数=自身"的函数（03 章 e 的定义推论）
  ② 指数函数求导多乘 ln a；对数求导多除 ln a
  ③ 三角函数对（sin/cos、tan/cot、sec/csc）导数互为"交叉"
```

## 4. 求导法则：四则与复合

```text
四则法则（可导时）：
  (u ± v)' = u' ± v'
  (u·v)' = u'v + uv'          ← 乘积法则（"前导后不导 + 前不导后导"）
  (u/v)' = (u'v − uv') / v²   ← 商法则（"上导下不导 − 上不导下导，除以分母平方"）
  [f(g(x))]' = f'(g(x)) · g'(x)  ← 链式法则（见第 5 节）

乘积法则的直觉（矩形面积模型）：
  A = u·v，两边同时微增：
  ΔA ≈ u'v·Δx + uv'·Δx + u'v'·(Δx)²（高阶项丢弃）
  → A' = u'v + uv'
```

## 5. 链式法则：微积分最重要的公式

### 5.1 公式

```text
复合函数 y = f(g(x))：
  dy/dx = (dy/du)·(du/dx)   其中 u = g(x)

一层一层"穿糖葫芦"：从外到内，逐层求导相乘
  (sin(x²))' = cos(x²) · 2x
  (e^(3x))' = e^(3x) · 3
  (ln(1+x²))' = (1/(1+x²)) · 2x
```

### 5.2 链式法则 = 反向传播的数学本质

```text
神经网络 = 巨型复合函数：
  loss = L(a3)，a3 = f3(W3·a2)，a2 = f2(W2·a1)，a1 = f1(W1·x)
  → loss 对 W1 的梯度 = 链式法则连乘：

  ∂loss/∂W1 = ∂loss/∂a3 · ∂a3/∂a2 · ∂a2/∂a1 · ∂a1/∂W1

反向传播 = "从输出往输入逐层应用链式法则"（高效复用中间导数）
  → 前向一次算出所有 aᵢ，反向一次累乘出所有 ∂loss/∂Wᵢ
  → 这正是自动微分的"反向模式"（09 章详述）
```

> 🎯 **核心要点**：**深度学习训练 = 链式法则的工程化**。理解"外层导 × 内层导"的逐层传递，就理解了反向传播为什么高效（每层只算局部导数，复用中间结果）。

## 6. 隐函数与参数方程求导

### 6.1 隐函数求导

```text
例：x² + y² = 1（圆），求 dy/dx
  两边对 x 求导（y 视为 y(x)，用链式法则）：
  2x + 2y·y' = 0 → y' = −x/y
  → 隐函数求导的通用做法：等式两边同时对 x 求导，解出 y'

适用：y 无法显式解出的关系（椭圆、双曲线、复杂乘积方程）
技巧：对数求导法——y = u^v 型，先取 ln 再求导
  y = x^x → ln y = x·ln x → y'/y = ln x + 1 → y' = x^x(ln x + 1)
```

### 6.2 参数方程求导

```text
x = φ(t), y = ψ(t) → dy/dx = ψ'(t) / φ'(t)（消去 t）

例：x = cos t, y = sin t（单位圆参数方程）
  dy/dx = cos t / (−sin t) = −cot t
二阶：d²y/dx² = (dy'/dt) / (dx/dt)（对 t 求导后再除以 dx/dt）
```

## 7. 高阶导数

```text
定义：f'' = (f')'，f⁽ⁿ⁾ = (f⁽ⁿ⁻¹⁾)'

常用高阶导数（记忆）：
  (e^x)⁽ⁿ⁾ = e^x
  (sin x)⁽ⁿ⁾ = sin(x + n·π/2)
  (cos x)⁽ⁿ⁾ = cos(x + n·π/2)
  (x^m)⁽ⁿ⁾ = m(m−1)...(m−n+1)·x^(m−n)
  (1/x)⁽ⁿ⁾ = (−1)ⁿ·n!·x^(−(n+1))
  (ln(1+x))⁽ⁿ⁾ = (−1)^(n−1)·(n−1)!/(1+x)ⁿ

莱布尼茨公式（乘积的高阶导）：
  (uv)⁽ⁿ⁾ = Σ C(n,k)·u⁽ᵏ⁾·v⁽ⁿ⁻ᵏ⁾（与二项式展开同构）

工程价值：
  二阶导数 → 凹凸性/海森矩阵（06 章）；泰勒公式展开（03 章）
```

## 8. 微分：线性逼近

### 8.1 定义

```text
Δy = f(x0+Δx) − f(x0) ≈ f'(x0)·Δx（当 Δx 很小时）
记：dy = f'(x)dx（微分 = 导数 × 自变量增量）

几何：dy 是切线方向的高度变化，Δy 是曲线实际变化
  → Δy − dy = 高阶无穷小 o(Δx)（切线的"最佳线性逼近"性质）
```

### 8.2 应用：近似计算与误差估计

```text
线性逼近公式：f(x0 + Δx) ≈ f(x0) + f'(x0)·Δx
  √4.01 ≈ 2 + (1/(2·2))·0.01 = 2.0025
  e^0.01 ≈ 1 + 0.01 = 1.01
  sin(0.1) ≈ 0.1（第一个重要极限的工程形态）

误差分析：
  测量误差 Δx → 结果误差 |dy| = |f'(x0)|·|Δx|
  → 相对误差 = |dy|/|y| = |f'(x0)/f(x0)|·|Δx|

工程价值：
  数值计算中的一阶近似（牛顿法、梯度下降的每次迭代都是线性逼近）
  这是"优化 = 反复线性逼近"思想的源头（03 章泰勒/牛顿法）
```

## 9. 核心要点与思考题

> 🎯 **本章三句话总结**：
> 1. 导数 = 差商极限 = 瞬时变化率；可导 ⇒ 连续，反之不成立（尖点反例）；
> 2. 链式法则是最重要的公式——反向传播 = 链式法则的规模化复用；
> 3. 微分 = 线性逼近（dy = f'dx），近似计算、误差估计、数值优化（牛顿法/梯度下降）全部建立其上。

**思考题**：

1. 为什么 ReLU 在 0 点"不可导"却能被深度学习使用？（→ 2 + 次梯度）
2. 反向传播为什么比"对每个参数独立求导"高效？（→ 5.2 中间结果复用）
3. √4.01 ≈ 2.0025 的依据是什么？（→ 8.2 线性逼近）
4. 隐函数求导时 y 为什么"多一个 y'"？（→ 6.1 链式法则）
