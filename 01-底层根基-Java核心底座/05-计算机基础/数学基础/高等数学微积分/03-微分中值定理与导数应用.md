## 1. 三大中值定理

### 1.1 罗尔定理（基础）

```text
条件：f 在 [a,b] 连续，在 (a,b) 可导，且 f(a) = f(b)
结论：存在 ξ ∈ (a,b)，使 f'(ξ) = 0

几何：两端等高的光滑曲线，中间必有水平切线
直觉：从 f(a) 到 f(b) 走"回头路"，必有一刻停下（导数为 0）
```

### 1.2 拉格朗日中值定理（核心）

```text
条件：f 在 [a,b] 连续，在 (a,b) 可导
结论：存在 ξ ∈ (a,b)，使 f(b) − f(a) = f'(ξ)(b − a)
      → 平均变化率 = 某点瞬时变化率

几何：曲线上必有一点，其切线平行于两端点连线
推论：f'(x) ≡ 0 → f 为常数；f'(x) > 0 → f 单调递增

工程价值：误差估计的理论基石
  数值计算中 |f(b) − f(a)| ≤ M·|b − a|（M = |f'| 上界）
```

### 1.3 柯西中值定理（推广）

```text
条件：f、g 在 [a,b] 连续、可导，g'(x) ≠ 0
结论：存在 ξ，使 [f(b)−f(a)]/[g(b)−g(a)] = f'(ξ)/g'(ξ)

定位：拉格朗日的"参数形式"——洛必达法则的证明基础
```

> 🎯 **核心要点**：中值定理链 = 罗尔（基础）→ 拉格朗日（桥梁）→ 柯西（推广）。它们共同回答"导数信息如何反推函数信息"——是证明题与误差分析的理论底座。

## 2. 洛必达法则

```text
适用：lim f(x)/g(x) 为 0/0 型或 ∞/∞ 型
法则：lim f/g = lim f'/g'（若右端极限存在）

条件三件套（易错！）：
  ① f、g 可导
  ② f'/g' 的极限存在（或为 ∞）
  ③ 原极限是 0/0 或 ∞/∞ 型（其他型先变形）
  ⚠️ 不满足条件时结论可能错——每次用前检查型

变形技巧：
  0·∞ 型 → 化为 0/0 或 ∞/∞（取倒数）
  ∞ − ∞ 型 → 通分/有理化
  1^∞、0⁰、∞⁰ 型 → 取对数（化为 0·∞）

何时失效（需换方法）：
  反复求导仍 0/0 但无尽头（如 sinx/x 用夹逼更好）
  导数比极限不存在但原极限存在（如 (x+sinx)/x：f' 比无极限，原极限=1）
```

## 3. 泰勒公式：用多项式逼近一切

### 3.1 公式（带余项）

```text
f(x) = f(x0) + f'(x0)(x−x0) + f''(x0)/2!·(x−x0)² + ... 
     + f⁽ⁿ⁾(x0)/n!·(x−x0)ⁿ + Rₙ(x)

余项两种形式：
  佩亚诺余项：Rₙ = o((x−x0)ⁿ)（x→x0 的局部近似，用于极限计算）
  拉格朗日余项：Rₙ = f⁽ⁿ⁺¹⁾(ξ)/(n+1)!·(x−x0)ⁿ⁺¹（用于误差估计）
```

### 3.2 麦克劳林级数（x0=0，记忆五条）

```text
e^x = 1 + x + x²/2! + x³/3! + ...
sin x = x − x³/3! + x⁵/5! − ...（奇函数，只奇次）
cos x = 1 − x²/2! + x⁴/4! − ...（偶函数，只偶次）
ln(1+x) = x − x²/2 + x³/3 − ...
1/(1−x) = 1 + x + x² + ...（等比，|x|<1）

通用性质：
  截断到一阶 = 切线（02 章线性逼近）
  展开到 n 阶：精度 o(xⁿ)，用于极限计算与近似
```

### 3.3 工程价值（CS/AI 视角）

```text
① 极限计算：sinx − x ~ −x³/6（等价无穷小替换失效时用泰勒）
② 数值计算：sin/cos/exp 的函数库实现 = 多项式近似（截断+余项界）
③ 深度学习：softmax 的 log-sum-exp 稳定性、sigmoid 的近似、量化误差分析
④ 优化理论：梯度下降/牛顿法的收敛性分析基于二阶泰勒展开
   （牛顿法 = 用二阶泰勒的极小点做下一步）
```

## 4. 函数的单调性与极值

### 4.1 单调性判定

```text
f'(x) > 0 于 (a,b) → f 严格递增
f'(x) < 0 于 (a,b) → f 严格递减
判定流程：求导 → 解 f'(x)=0 与不可导点 → 划分区间 → 各区间取点判号
```

### 4.2 极值判定（两大判别法）

```text
第一判别法（导数变号）：
  x0 左侧 f'>0、右侧 f'<0 → 极大值（峰）
  x0 左侧 f'<0、右侧 f'>0 → 极小值（谷）
  两侧同号 → 非极值（驻点但非极值，如 x³ 在 0）

第二判别法（二阶导）：
  f'(x0)=0 且 f''(x0) < 0 → 极大值
  f'(x0)=0 且 f''(x0) > 0 → 极小值
  f''(x0) = 0 → 失效（用第一判别法）

⚠️ 极值 ≠ 最值：
  极值是"局部"性质（邻域内最大/小）
  最值 = 比较所有极值点 + 端点（闭区间）
```

## 5. 凹凸性与拐点

```text
凹凸性（二阶导符号）：
  f''(x) > 0 → 凹（向上弯，U 形）—— 割线在曲线上方
  f''(x) < 0 → 凸（向下弯，∩ 形）—— 割线在曲线下方
  ⚠️ 中西术语相反注意：中文"凸函数"= f''>0（开口向上）=
     英文 convex（下凸）；考试/阅读以 f'' 符号为准

拐点：凹凸性改变处（f'' 变号点）
  必要条件：f''(x0) = 0 或不存在；充分：两侧变号

与优化的联系（关键！）：
  f''(x) ≥ 0 恒成立 → f 是凸函数 → 局部极小 = 全局极小
  → 凸优化理论的地基（损失函数设计/收敛性保证）
  → 深度学习的损失函数非凸（有鞍点/局部极小），这是训练困难的理论根源
```

## 6. 渐近线与函数作图

```text
三类渐近线：
  水平：lim(x→∞) f(x) = L → y = L
  垂直：lim(x→a⁺/⁻) f(x) = ∞ → x = a（分母零点/无定义点）
  斜渐近线：lim f(x)/x = k 且 lim [f(x) − kx] = b → y = kx + b

作图流程（八步）：
  定义域 → 对称性/周期性 → 渐近线 → 单调性 → 极值
  → 凹凸性 → 拐点 → 描点成图
```

## 7. 最值问题：从数学到优化

```text
闭区间最值的标准解法：
  ① 求所有驻点/不可导点处的函数值
  ② 求端点值
  ③ 比较取最大/最小

工程问题形态（应用建模）：
  利润最大化：R(x) − C(x) 求导 = 0 → 边际收益 = 边际成本
  面积/体积优化、成本最小化、库存优化（EOQ 模型）
  约束最值 → 拉格朗日乘数法（06 章）

→ 优化理论（数学基础 12-优化理论）的起点：
  无约束：梯度下降/牛顿法（03 章泰勒 + 09 章自动微分）
  有约束：拉格朗日乘数法（06 章）
```

## 8. 核心要点与思考题

> 🎯 **本章三句话总结**：
> 1. 中值定理连接"导数→函数"：拉格朗日是核心（平均=瞬时），罗尔/柯西是其特例与推广；
> 2. 洛必达三条件（0/0 或 ∞/∞、可导、导数比极限存在）；泰勒公式 = 多项式逼近 + 余项控制——极限计算、函数库实现、优化分析的共同底座；
> 3. 极值判定看导数变号；f''≥0 ⇒ 凸函数 ⇒ 局部最优=全局最优——深度学习的非凸性正源于此。

**思考题**：

1. 洛必达法则为什么"每次用前检查型"？（→ 2 条件三件套）
2. sinx − x 的极限用泰勒怎么处理？（→ 3.2 高阶展开）
3. 凸函数的局部极小为什么等于全局极小？（→ 5 凸性）
4. 闭区间最值为什么要比较端点？（→ 4.2 极值≠最值）
