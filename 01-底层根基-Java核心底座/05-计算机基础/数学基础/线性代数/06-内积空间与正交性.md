## 1. 内积、范数与夹角

```text
内积（点积，Rⁿ）：
  x·y = x₁y₁ + x₂y₂ + ... + xₙyₙ = xᵀy

范数（长度）：||x|| = √(x·x)
夹角：cos θ = (x·y) / (||x||·||y||)
正交：x·y = 0（垂直，θ = 90°）

柯西-施瓦茨不等式：|x·y| ≤ ||x||·||y||（夹角余弦 ∈ [−1,1] 的保证）
三角不等式：||x+y|| ≤ ||x|| + ||y||

内积的意义（机器学习）：
  内积 = "相似度"度量（余弦相似度 = 归一化内积）
  词嵌入的相似检索 = 内积排序
  注意力机制 = 查询与键的内积（Transformer 的核心运算！）
```

> 🎯 **核心要点**：内积把"几何直觉"（长度/角度/垂直）带入数据空间——**一切"相似度"计算（余弦、内积、注意力权重）都是内积的工程化**。

## 2. 正交与正交补

```text
正交向量组：两两内积为 0 → 必线性无关（正交 ⇒ 无关）
正交补空间：
  V^⊥ = {w | w·v = 0, ∀v ∈ V}（与 V 中所有向量垂直的全体）

基本定理（四个子空间的"十字正交"，01 章呼应）：
  C(Aᵀ) ⊥ N(A)（行空间与零空间正交，且互为正交补）
  C(A) ⊥ N(Aᵀ)（列空间与左零空间正交）

维度：dim V + dim V^⊥ = n（正交补的维度守恒）
分解：Rⁿ = V ⊕ V^⊥（任意向量唯一分解为 V 分量 + 垂直分量）

工程意义：
  "信号 + 噪声"的分解 = 信号空间与其正交补
  回归残差与拟合值正交 = 最小二乘的性质（第 5 节）
```

## 3. 正交基与格拉姆-施密特

```text
正交基：两两正交的基（不含单位化要求）
标准正交基：正交 + 单位长度（Q 矩阵的列）

格拉姆-施密特过程（造正交基）：
  u₁ = v₁
  u₂ = v₂ − proj_{u₁}(v₂)        （减掉 v₂ 在 u₁ 上的分量）
  u₃ = v₃ − proj_{u₁}(v₃) − proj_{u₂}(v₃)
  ...（逐向量减去在已得方向上的投影）
  最后单位化 → 标准正交基

数值注意：古典格拉姆-施密特数值不稳定
  → 改进版 MGS（修正的格拉姆-施密特）或 Householder 反射（QR 的实际算法）
  → 07 章 QR 分解的"正交化"视角正是从这里来
```

## 4. 投影定理

```text
投影：b 到子空间 V 的投影 p = 使 ||b − p|| 最小的 V 中向量
  → "子空间里离 b 最近的点"（最优逼近）

投影矩阵（V = C(A) 时）：
  P = A(AᵀA)⁻¹Aᵀ
  性质：P² = P（幂等）；Pᵀ = P（对称）；Pb ∈ V；b − p ⊥ V

特殊情形：
  一维投影：proj_a(b) = (a·b)/(a·a)·a
  正交矩阵列（Q）：P = QQᵀ（无需求逆！正交性的红利）

几何总结：
  投影 = 分解：b = p + e（p ∈ V 拟合部分，e = b − p 残差，e ⊥ V）
  → 这是最小二乘的完整几何（第 5 节）
```

## 5. 最小二乘：投影的工程化身

### 5.1 问题与解

```text
超定方程组 Ax = b（m > n，一般无解，04 章）
目标：min ||Ax − b||²（残差平方和最小）

解法一（法方程）：
  AᵀAx̂ = Aᵀb → x̂ = (AᵀA)⁻¹Aᵀb

解法二（几何/正交性）：
  b 投影到 C(A) 得 p = Ax̂，残差 e = b − Ax̂ ⊥ C(A)
  → Aᵀ(b − Ax̂) = 0 → 同一法方程

解法三（QR 分解，数值首选）：
  A = QR → x̂ = R⁻¹Qᵀb（无需求 AᵀA，数值稳定——07 章）
```

### 5.2 与线性回归的关系

```text
线性回归 y = Xw + ε：
  X = 特征矩阵（每行一个样本），y = 标签
  → min ||Xw − y||² 的最小二乘解就是回归系数

  几何：预测值 ŷ = Xw = 投影（y 到 C(X) 的投影）
  残差 e = y − ŷ ⊥ 特征空间（"无法被特征解释的部分"）
  性质：残差均值 = 0、与特征正交 —— 回归诊断的数学根基

  概率视角：高斯噪声最大似然 = 最小二乘（统计回归的等价性）
```

> 🎯 **核心要点**：**线性回归 = 把标签向量投影到特征空间**——预测 = 投影，残差 = 正交部分。这个几何图景贯通线性代数、统计与机器学习；而"投影矩阵 = X(XᵀX)⁻¹Xᵀ"就是"帽子矩阵"（hat matrix）。

## 6. 正定矩阵

```text
定义：对称矩阵 A，对任意 x ≠ 0：xᵀAx > 0

等价条件（选记）：
  ① 所有特征值 > 0
  ② 所有顺序主子式 > 0
  ③ A = BᵀB（B 列线性无关——格拉姆矩阵）且 B 满列秩
  ④ 存在可逆 P 使 A = PᵀP

半正定：xᵀAx ≥ 0（特征值 ≥ 0）——协方差矩阵/格拉姆矩阵

二次型视角：f(x) = xᵀAx（
  A 正定 → f 是凸函数 → 唯一极小点（与微积分 06 章海森呼应）
  → 优化理论的核心条件

工程意义：
  正则化：xᵀAx + λ||x||²（L2 正则 = 加正定项保证可逆）
  马氏距离：(x−μ)ᵀΣ⁻¹(x−μ)（协方差逆 = 正定）
  Cholesky 分解：A = LLᵀ（正定矩阵的 LU 特化，07 章）
```

## 7. 应用：从线性回归到机器学习

```text
① 线性回归/岭回归：
   w = (XᵀX + λI)⁻¹Xᵀy（λI = 正则化正定修正）

② PCA（05 章）：协方差 = 对称半正定 → 特征分解

③ 核方法：核矩阵 K = φ(X)φ(X)ᵀ（半正定——Mercer 条件）

④ 注意力机制：attention = softmax(QKᵀ/√d)·V（内积 = 相似度）
   → Transformer 的一切都是内积与投影

⑤ 相似度检索：余弦 = 归一化内积（embedding 检索）

⑥ 最小二乘的工程形态（数值）：
   法方程 (AᵀA)⁻¹ 病态（平方条件数）→ 用 QR/SVD（07 章）
```

## 8. 内积空间的工程应用：注意力与相似度

### 8.1 注意力机制 = 内积的规模化（Transformer）

```text
缩放点积注意力（07 章微积分呼应）：
  Attention(Q, K, V) = softmax(QKᵀ/√d)·V

映射到本体系：
  内积 QKᵀ = 查询与所有键的相似度（06 章 1 节：内积 = 相似度）
  softmax 归一化 = 相似度 → 概率权重（概率体系）
  V 加权求和 = 投影/凸组合（01 章线性组合）

→ Transformer 的一切核心运算 = 内积空间的正交与投影思想
```

### 8.2 相似度检索的工程实践

```text
向量检索（embedding 相似度）：
  精确：全量内积（n 大时慢——每查询 O(n·d)）
  近似：ANN（HNSW/IVF）——牺牲精度换速度
  度量选择：余弦（归一化内积，推荐）/ 欧氏距离 / 内积

⚠️ 工程注意：
  高维内积的"维数灾难"：随机向量内积集中（夹角 ~90°）
  → 余弦相似度在高维区分度下降 → 需降维（PCA/量化）
```

### 8.3 正交性的工程价值汇总

```text
□ 正交矩阵：数值稳定（保范数）、求逆零成本（QR/SVD/FFT）
□ 正交基：系数独立（回归诊断无共线性，08 章）
□ 正交补：信号/噪声分解（滤波、去噪）
□ 格拉姆-施密特：正交化工具（数值用 MGS/Householder）
→ "正交" = 信息不重叠，是工程上最受欢迎的性质
```

## 9. 核心要点与思考题

> 🎯 **本章三句话总结**：
> 1. 内积 = 相似度（余弦/注意力）；正交 = 信息不重叠；四个子空间两两正交互补；
> 2. 投影 = 子空间最近点（P = A(AᵀA)⁻¹Aᵀ）——**最小二乘 = 投影**，线性回归 = 标签投影到特征空间；
> 3. 正定矩阵 = 特征值全正 = 凸性保证；数值上（AᵀA）病态 → 用 QR/SVD 求最小二乘。

**思考题**：

1. 为什么"正交 ⇒ 线性无关"？（→ 2）
2. 最小二乘解为什么满足 Aᵀ(b − Ax̂) = 0？（→ 5.1 正交性）
3. 回归残差为什么与特征正交？（→ 5.2）
4. 法方程为什么不数值稳定？（→ 5.1 解法三 + 09 章条件数）
