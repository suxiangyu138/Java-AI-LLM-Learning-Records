## 3. 学习路线推荐

### 路线一：快速入门（1-2 周）——AI 学习者

01 → 02 → 04 → 06 → 07，重点掌握：

- 矩阵乘法与向量空间直觉（前向传播 = 矩阵乘法）
- 高斯消元与秩（解线性系统的思维）
- 投影与最小二乘（线性回归的数学）
- SVD 与低秩（压缩/降维/推荐的统一工具）

### 路线二：系统学习（4-6 周）——完整线性代数

01 → 02 → 03 → 04 → 05 → 06 → 07 → 08，配合资源：

- [MIT 18.06（Gilbert Strang 线性代数）](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/)——四大子空间与 SVD 的权威讲法
- 3Blue1Brown《Essence of Linear Algebra》系列（几何直觉）
- [《Deep Learning》花书第 2 章（线性代数）](https://www.deeplearningbook.org/)

### 路线三：CS/AI 深化（配合 09 章）

- 数值线性代数：Trefethen《Numerical Linear Algebra》
- [MIT IAP 2026: Matrix Calculus for ML and Beyond](https://math.mit.edu/academics/iap2026.html)

## 4. 核心概念速查

| 概念 | 一句话定义 | 关键要点 |
|------|-----------|---------|
| 向量 | 有大小方向的量（n 元组） | 可加、可缩放 |
| 线性相关 | 一组向量可被线性组合表示 | 相关 ⇔ 有冗余 |
| 基 | 张成空间的最小无关组 | 基的个数 = 维数 |
| 子空间 | 对加法和缩放封闭的集合 | 必须含零向量 |
| 矩阵 | 线性变换的数值表示 | 乘法 = 复合变换 |
| 秩 | 线性无关的行/列最大数 | 秩 = 列空间维数 = 行空间维数 |
| 行列式 | 有向体积（缩放因子） | det=0 ⇔ 奇异（不可逆） |
| 特征值 | Ax = λx 的 λ | 变换的"固有缩放" |
| 对角化 | A = PDP⁻¹ | 可对角化 ⇔ n 个线性无关特征向量 |
| 内积 | 向量夹角与长度的度量 | 正交 ⇔ 内积 = 0 |
| 投影 | 到子空间的最近点 | 最小二乘 = 正交投影 |
| SVD | A = UΣVᵀ 万能分解 | 任意矩阵可分解；低秩近似之王 |
| 条件数 | 误差放大倍数 | 数值稳定性的度量 |
| 正定矩阵 | 二次型恒正（xᵀAx>0） | 特征值全正；凸性的保证 |
