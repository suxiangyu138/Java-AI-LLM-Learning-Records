# 线性变换与几何

> 线性变换 = "保持直线与原点"的映射——旋转、缩放、剪切、投影都是它的特例。矩阵就是变换的"数字身份证"：复合变换 = 矩阵乘法（顺序相反！）、核与像刻画"压扁多少、留下多少"、基变换 = 换坐标系——图形学与深度学习的几何直觉都在这里

## 1. 线性变换的定义

```text
T: V → W 是线性变换，若（两条性质）：
  ① 可加性：T(u + v) = T(u) + T(v)
  ② 齐次性：T(cu) = c·T(u)

本质：保持线性结构（直线仍直、原点不动、网格平行）
  → "线性变换 = 把网格变形但保持网格线平直"

非线性反例：平移（原点动了）、平方（直线变弯）
  → 平移不是线性变换！→ 齐次坐标的动机（第 8 节）

工程视角：
  神经网络层（无激活）= 线性变换；激活函数 = 引入非线性
  → 深度学习的"线性部分"全是线性变换的复合
```

## 2. 变换矩阵：从映射到数字

```text
核心事实：有限维线性变换 ⇔ 矩阵（一一对应）

构造：T 由"基向量的像"完全决定
  T(e₁)、T(e₂)、...、T(eₙ) 作为矩阵的列
  → T(x) = Ax（x 是坐标，A 的列 = 基向量的像）

例：T = 逆时针旋转 90°：T(e₁) = (0,1)，T(e₂) = (−1,0)
  → A = [0 −1; 1 0] ✓（02 章见过的旋转矩阵）

推论：
  "研究变换" = "研究矩阵"（两者同构）
  → 前面的所有矩阵理论（秩/特征值/分解）都是变换的语言
```

## 3. 基本变换族

| 变换 | 矩阵（R²） | 几何效果 | 特征值 |
|------|-----------|---------|--------|
| 缩放 | [s 0; 0 t] | 拉伸/压缩 | s, t |
| 旋转 θ | [cosθ −sinθ; sinθ cosθ] | 绕原点转 | e^±iθ（复数） |
| 剪切 | [1 k; 0 1] | 横向错动 | 1（重根） |
| 反射 | [1 0; 0 −1] | 关于 x 轴对称 | 1, −1 |
| 投影 | [1 0; 0 0] | 压到 x 轴 | 1, 0（幂等！） |

```text
特征值视角回顾（05 章）：
  缩放 = 特征值即缩放系数（对角阵直读）
  旋转 = 实特征值不存在（都"转向"了）
  投影 = 特征值 0 和 1（方向被保留或被压扁）
  → 特征值 = "变换的固有行为"在几何上的直接呈现
```

> 🎯 **核心要点**：五种基本变换构成"变换字母表"——任何线性变换（及其 SVD 分解）都是"旋转 × 缩放 × 旋转"的组合（07 章），这就是几何与分解的统一图景。

## 4. 复合变换与矩阵乘法

```text
先 T₁ 后 T₂：T₂(T₁(x)) = (T₂T₁)(x) = (BA)x
  → 复合 = 矩阵乘法，但注意顺序！
    "先旋转再缩放" vs "先缩放再旋转" ≠

  ⚠️ 矩阵乘法的顺序与书写相反：
  变换作用顺序：先 A 后 B → 矩阵 = BA（右乘先执行）
  → 图形学 API（OpenGL）中矩阵"后乘"的语义来源

例：先旋转 90° 再横向放大 2 倍
  B·A = [2 0; 0 1]·[0 −1; 1 0] = [0 −2; 1 0]
  先放大再旋转 → A·B 结果不同 ✓（验证 AB ≠ BA）

工程注意：复合顺序错误 = 图形学最常见的 bug
```

## 5. 核与像

```text
核（零空间）：ker(T) = {x | T(x) = 0}
  → "被变换压扁成零的输入"（信息消失）
像（值域/列空间）：im(T) = {T(x) | x ∈ V}
  → "变换能到达的输出"（信息保留）

对应（01 章四个子空间）：
  ker(T) = N(A)（零空间）
  im(T) = C(A)（列空间）

解方程组的新语言：
  Ax = b 有解 ⇔ b ∈ im(A)
  解的自由度 = dim ker(A)（04 章秩-零化度）

直觉：变换 = "压扁（核）+ 保留（像）"的分解
  → 低秩矩阵 = 核很大、像很小 = 强压缩（07 章低秩）
```

## 6. 维数定理

```text
维数定理（秩-零化度定理的变换语言）：
  dim V = dim ker(T) + dim im(T)

  n（输入维度）= 压扁的维度（核）+ 保留的维度（像）

推论（同维度映射 T: V → V）：
  单射（ker = {0}）⇔ 满射（im = V）⇔ 可逆
  → "方阵三选一"：满秩可逆、否则既不满射也不单射

几何直觉：
  三维空间的投影（压到平面）：核 = 一维直线（法向），像 = 平面
  1（核）+ 2（像）= 3 ✓

工程意义：
  数据降维 = 故意制造大核（丢弃方向）
  特征工程 = 扩大像空间（保留信息）
```

## 7. 基变换与相似

```text
同一变换在不同基下的矩阵 = 相似矩阵：
  B = P⁻¹AP（P = 基变换矩阵，05 章相似）

流程：换基 = 先"翻译坐标"（P⁻¹）→ 应用变换（A）→ 翻回（P）
  观察者（坐标系）不同，变换本质不变（特征值相同）

对角化的几何意义（05 章）：
  特征向量基下，变换 = 纯缩放（对角阵 D）
  → "找对坐标系，复杂变换变简单"

工程：
  选"好基" = 让矩阵变简单（对角/稀疏/正交）
  → 快速傅里叶变换（FFT）= 在特殊基下的高效表示
  → 流形学习/谱方法 = 找数据的好坐标系
```

## 8. 几何应用：图形学与数据

```text
① 图形学变换流水线：
  缩放/旋转/平移 → 齐次坐标（加一维）把平移变成线性：
  [x; y; 1] → 平移矩阵 [1 0 tx; 0 1 ty; 0 0 1]（非线性变线性）
  透视投影 = 齐次坐标除法（3D → 2D）
  → OpenGL/WebGL 的 MVP 矩阵全链

② 深度学习：
  线性层 Wx + b：平移 b 使"仿射"（线性+平移）——没有齐次坐标的简化
  批归一化 = 逐维缩放+平移（对角变换）
  嵌入层 = 查表（特殊线性映射）

③ 数据流形：
  数据近似分布在一个低维子空间（线性流形）
  → PCA = 找"数据所在子空间的正交基"（05/07 章）
  → 特征值分解 = 找"数据变化最大的方向"
```

## 9. 变换的数值实践：四元数与仿射

### 9.1 四元数：旋转的数值稳定表示

```text
问题：旋转矩阵的数值漂移（累积误差 → 不再正交）
  → 正交化修正麻烦；插值困难（矩阵插值不平滑）

四元数 q = (w, x, y, z)，||q|| = 1：
  表示旋转（4 个数 vs 矩阵 9 个数）
  组合 = 四元数乘法（比矩阵乘法快）
  插值：slerp（球面线性插值——动画的关键帧平滑）
  ⚠️ 必须归一化（非单位四元数 = 缩放 + 旋转）

工程地位：3D 游戏/动画/机器人的旋转标配
  → 图形学面试高频："为什么用四元数"——漂移/插值/效率
```

### 9.2 仿射变换与齐次坐标

```text
仿射 = 线性变换 + 平移（08 章已提齐次坐标，此处补全）：
  [x'; y'; 1] = [a b tx; c d ty; 0 0 1]·[x; y; 1]

性质：
  仿射保持：直线（仍直）、平行（仍平行）、比例（长度比不变）
  不保持：长度/角度（会变形）
  应用：2D 图形（平移/旋转/缩放/剪切统一为矩阵乘法）

复合顺序的实践（OpenGL 惯例）：
  先缩放 → 再旋转 → 最后平移（SRT 顺序）
  → 矩阵 = T·R·S（右乘先执行，08 章第 4 节）
```

### 9.3 变换矩阵的调试技巧

```text
□ 验证：单位矩阵 → 不变；正交矩阵 → 保长度
□ 分解：任意矩阵 = 缩放·旋转·缩放（SVD，07 章）——诊断"变换到底做了什么"
□ 逆变换：几何上"撤销"（图形学坐标反变换）
□ 数值：大量复合后检查 det/正交性漂移（四元数替代旋转矩阵）
```

## 10. 核心要点与思考题

> 🎯 **本章三句话总结**：
> 1. 线性变换 = 保直线保原点；矩阵 = 变换的身份证（列 = 基向量的像）；五种基本变换（缩放/旋转/剪切/反射/投影）是变换字母表；
> 2. 复合 = 矩阵乘法（顺序相反！）；核与像 = 压扁与保留（维数守恒）；基变换 = 换坐标系（相似矩阵共享特征值）；
> 3. 图形学靠齐次坐标把平移线性化；深度学习 = 线性变换 + 非线性的交替；PCA = 找数据子空间的好基。

**思考题**：

1. 平移为什么不是线性变换？（→ 1 原点不动）
2. "先旋转后缩放"的矩阵怎么写？（→ 4 右乘先执行）
3. 投影变换的核是什么？（→ 5/6 压扁方向）
4. 齐次坐标解决什么问题？（→ 8 平移线性化）
