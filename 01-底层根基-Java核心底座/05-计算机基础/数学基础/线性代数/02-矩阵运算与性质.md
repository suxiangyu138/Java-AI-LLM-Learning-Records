## 1. 矩阵：数字的矩形与变换的化身

```text
矩阵 A（m×n）：m 行 n 列
  数据视角：表格（数据集 = 行样本，列特征）
  变换视角：把 Rⁿ 的向量映射到 Rᵐ（线性变换，08 章）
  → "矩阵乘向量 = 变换应用"

记号：Aᵢⱼ（第 i 行第 j 列）；方阵 m = n；对角阵 D

机器学习视角：
  权重矩阵 W：把输入特征变换到隐藏层（线性层 = 矩阵乘法）
  整个前向传播 = 一串矩阵乘法（+非线性激活）
```

## 2. 矩阵乘法：三种视角

### 2.1 逐元素视角（定义）

```text
(AB)ᵢⱼ = Σₖ Aᵢₖ·Bₖⱼ（A 的第 i 行 点乘 B 的第 j 列）

要求：A 的列数 = B 的行数（内维一致）
  A(m×k)·B(k×n) = C(m×n)
```

### 2.2 行/列视角（理解关键）

```text
列视角（最重要的直觉）：
  AB 的每一列 = A 作用于 B 的对应列
  → AB 的列空间 ⊆ A 的列空间（信息不增加）

  A·[b₁ b₂ ... bₙ] = [Ab₁ Ab₂ ... Abₙ]
  → "A 变换 B 的所有列"

行视角：AB 的每一行 = Bᵀ 作用于 A 的对应行
分块视角：大矩阵按块划分，块当作元素相乘（GPU 分块计算的依据）
```

### 2.3 计算复杂度

```text
朴素乘法：O(m·k·n)（三层循环）
  → 1000×1000 矩阵：10⁹ 次乘加 —— 单核要秒级

优化路径：
  ① 分块 + 缓存友好（BLAS 库的 dgemm）
  ② 矩阵乘法的 Strassen 算法 O(n^2.807)
  ③ GPU 并行（深度学习：矩阵乘法是唯一核心运算）
  → 深度学习训练速度 ≈ 矩阵乘法速度（GPU 厂商的军备竞赛）
```

> 🎯 **核心要点**：矩阵乘法 = 复合变换 + 数据运算的双重身份。列视角（AB 的列是 A 变换 B 的列）解释了一切"信息不增"的直觉；GPU 之所以统治深度学习，是因为矩阵乘法天然可并行。

## 3. 矩阵乘法的关键性质

```text
不满足交换律（最重要的差异）：
  AB ≠ BA（一般）——变换顺序不可交换！先旋转后平移 ≠ 先平移后旋转

满足结合律：A(BC) = (AB)C（复合变换的结合）
满足分配律：A(B+C) = AB + AC

⚠️ AB = 0 不推出 A = 0 或 B = 0（零因子存在）
  （零矩阵不可逆的唯一"原因"之一……实际上任何奇异矩阵都是零因子）

转置的反序： (AB)ᵀ = BᵀAᵀ
逆的反序：   (AB)⁻¹ = B⁻¹A⁻¹
```

## 4. 逆矩阵

```text
定义：A⁻¹A = AA⁻¹ = I（存在条件：方阵 + 满秩）

可逆（非奇异）的等价条件（选记四条）：
  ① det(A) ≠ 0
  ② rank(A) = n（满秩）
  ③ Ax = 0 只有零解（零空间 = {0}）
  ④ 列向量线性无关（列空间 = Rⁿ）

求法：
  ① 伴随矩阵：A⁻¹ = adj(A)/det(A)（理论用，2×2 手算）
  ② 初等行变换：[A | I] → [I | A⁻¹]（手算/教学）
  ③ 数值：高斯-约当消元（计算机，04 章）

2×2 公式：[a b; c d]⁻¹ = [d −b; −c a]/(ad−bc)

工程视角：
  解方程组 Ax = b 用 x = A⁻¹b 是"理论表达"
  实际计算绝不求逆（数值不稳定 + 慢）——用高斯消元/分解（04/07 章）
  → "能不求逆就不求逆"是数值线性代数的铁律
```

## 5. 转置与对称矩阵

```text
转置：(Aᵀ)ᵢⱼ = Aⱼᵢ（行列互换）；(AB)ᵀ = BᵀAᵀ

对称矩阵：Aᵀ = A（Aᵢⱼ = Aⱼᵢ）
  → 协方差矩阵、海森矩阵、邻接矩阵（无向图）天然对称

反对称：Aᵀ = −A

关键构造：对任意矩阵 A，AAᵀ 与 AᵀA 都是对称矩阵
  → SVD 与 PCA 的出发点（07 章）
  → Gram 矩阵 G = XᵀX（特征内积，核方法的入口）

对称矩阵的伟大性质（05 章详述）：
  特征值全为实数；可正交对角化（谱定理）
  → 协方差矩阵的特征分解 = 主成分分析（PCA）
```

## 6. 秩的多种计算

```text
秩的定义：线性无关的最大行数 = 最大列数（两者相等！）

计算方法：
  ① 高斯消元：化成行阶梯形 → 非零行数（最实用）
  ② 行列式：所有 r 阶子式不全为零的最大 r
  ③ 特征值：非零特征值个数（方阵）

性质：
  0 ≤ rank(A) ≤ min(m, n)
  rank(Aᵀ) = rank(A)
  rank(AB) ≤ min(rank A, rank B)（信息不增的代数版）
  rank(A + B) ≤ rank A + rank B

低秩的工程意义：
  rank(A) << min(m,n) → A 可压缩（SVD 截断，07 章）
  LoRA：ΔW = BA 显式构造低秩更新（09 章）
```

## 7. 迹

```text
迹：tr(A) = Σ Aᵢᵢ（主对角线之和，方阵）

性质：
  tr(A+B) = tr(A) + tr(B)
  tr(AB) = tr(BA)（循环不变性：tr(ABC) = tr(BCA) = tr(CAB)）
  tr(A) = Σ 特征值（05 章——特征值的"和守恒"）

工程意义：
  深度学习中的权重衰减正则化 = tr(WWᵀ) = Σ wᵢⱼ²（Frobenius 范数平方）
  损失函数里的"矩阵能量"度量
```

## 8. 特殊矩阵家族

| 矩阵 | 定义 | 用途 |
|------|------|------|
| 对角矩阵 D | 非主对角全 0 | 缩放变换；特征值分解的中间形态 |
| 单位矩阵 I | 对角全 1 | 乘法单位元 |
| 上/下三角 | 对角线一侧全 0 | LU 分解（07 章） |
| 正交矩阵 Q | QᵀQ = I（列正交单位） | 旋转/反射；数值稳定（QR/SVD） |
| 对称矩阵 | Aᵀ = A | 协方差/海森/谱定理 |
| 正定矩阵 | xᵀAx > 0（∀x≠0） | 凸性/最小二乘正则化（06 章） |
| 幂等矩阵 | A² = A | 投影矩阵（06 章） |
| 稀疏矩阵 | 大部分元素为 0 | 图/大规模线性系统（专门存储与算法） |

```text
正交矩阵的特殊性（数值与应用双重重要）：
  列互相正交且单位化 → Q 保持长度与夹角（等距变换）
  逆 = 转置：Q⁻¹ = Qᵀ（求逆零成本）
  → QR 分解/SVD/FFT 全部依赖正交性（07 章）
```

## 9. 核心要点与思考题

> 🎯 **本章三句话总结**：
> 1. 矩阵乘法 = 复合变换（不交换！）；列视角"AB 的列 = A 变换 B 的列"解释信息不增；
> 2. 可逆 ⇔ det≠0 ⇔ 满秩 ⇔ 零空间平凡；计算上"能不求逆就不求逆"；
> 3. 特殊矩阵各有使命：对称（谱定理）、正交（稳定与等距）、对角（缩放）——SVD/PCA/LoRA 都建立在它们之上。

**思考题**：

1. 为什么 AB ≠ BA？（→ 3 变换顺序）
2. 求解 Ax = b 为什么不该真的算 A⁻¹？（→ 4 工程视角）
3. AAᵀ 为什么总是对称的？（→ 5 关键构造）
4. 正交矩阵为什么"求逆零成本"？（→ 8）
