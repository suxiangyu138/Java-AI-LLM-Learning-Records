## 1. 数值线性代数：条件数与稳定性

### 1.1 条件数

```text
条件数 κ(A) = σ_max/σ_min（最大/最小奇异值之比，07 章 SVD）

含义：误差放大倍数
  κ 大 → 病态（ill-conditioned）：输入微小误差 → 解的巨大误差
  κ 小（接近 1）→ 良态

例：解 Ax = b，b 有 1e-6 误差：
  κ = 1e6 → 解的误差可能放大到 1
  → "数学上可解" ≠ "数值上可解"

病态信号：AᵀA 的条件数 = κ(A)²（法方程的病灶，06/07 章）
  → QR/SVD 避免构造 AᵀA 的根本原因
```

### 1.2 数值稳定性要点

```text
① 部分主元选择（LU/消元）：避免小主元放大舍入误差
② 正交化（QR/SVD）：变换不放大误差（正交 = 保范数）
③ 避免求逆、避免 AᵀA、避免 det 判定奇异（用条件数/SVD）
④ 计算顺序：先缩放/预条件（preconditioning）
⑤ 浮点误差：矩阵乘法误差 ∝ n·ε_machine（可分析，可预测）

铁律汇总：
  解方程组：LU（主元）
  最小二乘：QR / SVD（不用法方程）
  判奇异：SVD 最小奇异值（不用 det）
  算特征值：QR 迭代 / SVD（不算特征多项式）
```

## 2. 数值算法与库

```text
工业标准：LAPACK（解方程组/最小二乘/特征值/SVD 的全部实现）
  BLAS（基础线性代数子程序：GEMM 等）——性能地基

Java 生态：
  Apache Commons Math（教学/简单场景）
  EJML（轻量）
  ND4J（深度学习）
  JBLAS/Netlib（LAPACK 绑定，性能优先）

Python 生态（AI 主力）：
  NumPy（BLAS/LAPACK 封装——底层 C/Fortran）
  SciPy（linalg 全套）
  PyTorch/JAX（GPU 上的张量代数 + 自动微分）

工程选型要点：
  性能关键路径必须走 BLAS/LAPACK（自写三重循环 = 慢 10-100 倍）
  矩阵库选择 = 性能需求 × 生态集成
```

## 3. GPU 与矩阵乘法的算力时代

```text
为什么 GPU 统治深度学习：深度学习计算 ≈ 大规模矩阵乘法
  GPU = 数千核心并行执行同一指令（SIMT）
  矩阵乘法天然可并行（分块 + 每块独立乘加）

关键数字（量级参考）：
  A100：~312 TFLOPS（FP16 矩阵乘）
  H100：~1000 TFLOPS（张量核心）
  → 大模型训练 = 亿级 TFLOPS 的矩阵乘

张量核心（Tensor Core）：为 4×4 矩阵乘设计的专用硬件
  → "矩阵乘法"成为芯片架构的一等公民
  → 量化（FP16/BF16/FP8）在矩阵乘上验证精度（存储与带宽考量）
```

## 4. 应用一：图形学与几何计算

```text
（08 章已给变换，此处给工程全景）
  模型矩阵（M）：对象位置/旋转/缩放（4×4 齐次坐标）
  视图矩阵（V）：相机位置
  投影矩阵（P）：透视/正交投影
  → MVP 变换：顶点 × P·V·M（矩阵链的经典用例）

网格处理（几何算法）：
  顶点坐标 = 矩阵；变形/蒙皮 = 线性插值（凸组合）
  法向量的变换 = 逆转置矩阵（(M⁻¹)ᵀ）——图形学的经典细节
  SDF（符号距离场）/网格简化（QSlim）= 特征值/最小二乘

图形学 = 线性代数的"最大消费者"之一：
  刚体运动（旋转+平移）、四元数（旋转的数值稳定表示）
```

## 5. 应用二：PageRank 与网络分析

```text
（05 章已给原理，此处给算法工程）
PageRank = 转移矩阵的主特征向量（幂法迭代）：
  r ← β·M·r + (1−β)/N（β=0.85 阻尼因子）

幂法（power iteration）——特征值计算的经典数值方法：
  x ← Ax/||Ax|| 反复迭代 → 收敛到主特征向量
  收敛速度由 |λ₂/λ₁| 决定（第二大特征值之比）

图谱理论（spectral graph theory）：
  邻接矩阵/拉普拉斯矩阵的特征值 → 图的结构信息
  谱聚类 = 拉普拉斯特征向量做聚类
  → 社交网络/社区发现的标准工具

网络分析的线性代数语言：
  图 = 邻接矩阵；路径计数 = 邻接矩阵的幂
  中心性（PageRank/特征向量中心性）= 特征向量
```

## 6. 应用三：推荐系统矩阵分解

```text
问题：用户×物品评分矩阵 R（m×n，极度稀疏——99% 缺失）
目标：预测缺失评分

SVD 视角：R ≈ UₖΣₖVₖᵀ = P·Qᵀ
  P（用户×隐因子 k）、Q（物品×隐因子 k）
  → 隐因子 = 潜在偏好维度（风格/题材/价格敏感度）

工程实现（不是直接 SVD——矩阵稀疏）：
  交替最小二乘（ALS）：固定 Q 解 P（最小二乘），交替迭代
  或梯度下降（SGD）逐个观测值更新
  → Spark MLlib ALS、Netflix Prize 的经典解法

与 Eckart-Young 的联系（07 章）：
  低秩假设 = "评分矩阵近似低秩"（用户偏好由少量因子决定）
  → 推荐 = 低秩近似的工程实现
```

## 7. 应用四：深度学习与张量

```text
张量（tensor）= 多维数组（矩阵的推广）
  标量 0 维、向量 1 维、矩阵 2 维、批数据 3 维（batch, 特征）、
  Transformer 注意力 4 维（batch, head, seq, dim）

深度学习的线性代数清单：
  前向传播 = 矩阵乘法 + 逐元素非线性（01/02 章）
  反向传播 = 转置矩阵乘法（雅可比传递，微积分 09 章）
  注意力 = QKᵀ 内积 + softmax + V 加权（06 章内积）
  批归一化 = 逐维缩放平移（对角变换，08 章）
  权重初始化/正交初始化 = 控制谱半径（05 章 RNN 稳定性）

梯度爆炸/消失的代数根源：
  Wᵏ 的行为由特征值决定（05 章 7.3）
  → 残差连接/归一化/初始化 = 控制谱半径的工程手段
```

## 8. 2026 趋势：SVD 低秩与 LLM

```text
（2026-08 检索，LLM 压缩/微调的主战场）

① 截断 SVD 压缩（权重矩阵低秩近似）：
  朴素 SVD 压缩的 2026 进化：
  Duo-SVD（列保留 + 低秩近似的混合）
  Zero Sum SVD（2026-02：激活白化 + 全局奇异分量选择，
    自动给出异构秩分配）
  SigmaScale（2026-06：学习缩放矩阵，降低有效秩熵）
  SAES-SVD（CEALC/ACES：逐层误差抑制——LLaMA-7B 上
    20% 压缩率下精度损失减少 58%）
  Swift-SVD（2026-04：多步 SVD 融合，压缩提速数倍）

② 低秩微调（PEFT）：
  LoRA：ΔW = BA（A: r×n, B: m×r，r << min(m,n)）
  → "权重更新是低秩的"（低秩假设——Eckart-Young 的实践）
  2026 新方法：
  CORA（2026-06：逐片相干正交旋转，参数仅为 LoRA 的 1/4-1/8，性能更优）
  PiSSA/MiLoRA/LoftQ/SVFT（SVD 初始化的 PEFT 家族）

③ 理论视角：
  Asymmetric Kernel SVD（IEEE 主题报告：与注意力机制的耦合）
  ICLR 2026：Transformer 做线性代数运算（RangeFormer）
  有效秩（effective rank）成为模型可压缩性的度量

→ 一句话：SVD 低秩从"经典数学工具"变成"LLM 时代的效率基础设施"
```

## 9. 核心要点与思考题

> 1. 数值铁律：条件数定"准不准"（κ=σmax/σmin），LU 解方程、QR/SVD 最小二乘、SVD 判奇异——避开 AᵀA 与求逆；
