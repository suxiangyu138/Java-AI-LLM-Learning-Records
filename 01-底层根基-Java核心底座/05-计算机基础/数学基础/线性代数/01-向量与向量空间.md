> 向量是数据的最小容器，向量空间是"所有可能数据"的结构化描述：线性组合决定"能到达哪里"，基决定"怎么描述"，子空间把矩阵的信息切成四块（四个基本子空间）——线性代数的一切都从这些概念长出来

## 1. 向量：数据与几何的双重身份

```text
代数身份：n 元组（有序数组）
  v = (3, 4)；x = (x₁, x₂, ..., xₙ)——特征向量（机器学习的数据）

几何身份：有方向的箭头（从原点出发）
  (3, 4) = 3 个单位 x + 4 个单位 y

两种运算（封闭性要求）：
  加法：v + w（对应分量相加）
  数乘：c·v（每个分量缩放）
  → "向量空间"就是这两种运算封闭的集合

机器学习的视角：
  一条数据 = 一个向量（像素、词嵌入、特征）
  整个数据集 = 向量集合（矩阵的行）
  → 数据的所有代数操作（平均、回归、分类）都是向量运算
```

## 2. 线性组合与张成空间

```text
线性组合：c₁v₁ + c₂v₂ + ... + cₙvₙ（缩放后相加）

张成空间 span{v₁,...,vₙ}：所有线性组合的集合
  → "用这些向量能到达的所有点"
  → 几何：两条不平行的向量张成一个平面

例子：
  span{(1,0), (0,1)} = 整个 R²（标准基张成）
  span{(1,0)} = x 轴（一条线）
  span{(1,1), (2,2)} = 一条线（第二个向量是冗余的！）

工程直觉：
  嵌入（embedding）的语义空间 = 向量张成的空间
  "向量越独立，能表达的语义越丰富"
```

> 🎯 **核心要点**：线性组合是"向量世界的构造规则"——**矩阵乘法 = 列向量的线性组合**（02 章），**神经网络层 = 输入向量的线性组合 + 偏置**。理解组合就理解了深度学习的代数本质。

## 3. 线性相关与线性无关

```text
线性相关：存在不全为零的 cᵢ 使 Σcᵢvᵢ = 0
  → 至少一个向量是其余向量的线性组合（有冗余）
线性无关：唯一使 Σcᵢvᵢ = 0 的方式是全部 cᵢ = 0
  → 每个向量都带来"新方向"

判断方法（列向量）：
  把向量排成矩阵 → 高斯消元（04 章）
  有自由变量（零列/零行）→ 相关；全主元 → 无关

几何直觉：
  两个向量：平行 = 相关；不平行 = 无关
  三个向量：共面 = 相关；张成立体 = 无关

工程意义：
  特征工程中"相关特征" = 信息冗余（可降维）
  词向量的无关性 = 语义维度丰富度
```

## 4. 基与维数

```text
基：向量空间的一组"最小生成集"——
  ① 线性无关
  ② 能张成整个空间

维数：基中向量的个数（所有基的个数相同）
  dim(Rⁿ) = n；一条直线的维数 = 1；一个平面 = 2

标准基：e₁ = (1,0,...,0), ..., eₙ

向量在基下的坐标：
  任何向量 = 基向量的唯一线性组合
  → 坐标 = 组合系数（"描述方式"依赖基的选择）

工程意义：
  特征空间的维数 = 描述数据需要的独立方向数
  降维 = 找"更小的基"来近似描述数据（SVD/主成分，07 章）
```

## 5. 向量空间与子空间

```text
向量空间定义（八条公理，核心两条）：
  ① 加法封闭：v, w ∈ V → v + w ∈ V
  ② 数乘封闭：v ∈ V, c ∈ R → cv ∈ V
  （其余：结合律、交换律、零向量、负向量、分配律……）

子空间：向量空间的"封闭子集"（也满足两条封闭性）
  判定：含零向量 + 对加法数乘封闭

R² 的子空间：过原点的直线、R² 本身、{0}
  → "不过原点的直线不是子空间"（经典判断点）

工程直觉：
  子空间 = "数据的合法区域"
  → 线性回归的解空间、PCA 的主成分子空间都是子空间
```

## 6. 四个基本子空间

```text
矩阵 A（m×n）定义四个子空间（Strang 的著名框架）：

① 列空间 C(A) ⊆ Rᵐ：A 的列向量张成（= Ax 的所有可能结果）
   → "A 能到达的输出空间"；解存在性：b ∈ C(A)

② 零空间 N(A) ⊆ Rⁿ：Ax = 0 的所有解
   → "被 A 映射到零的输入"；解的"自由度"

③ 行空间 C(Aᵀ) ⊆ Rⁿ：A 的行向量张成（= 列空间转置）
   → 与零空间正交补（06 章正交性）

④ 左零空间 N(Aᵀ) ⊆ Rᵐ：Aᵀy = 0 的解
   → 与列空间正交补

维度关系（秩 r = rank(A)）：
  dim C(A) = dim C(Aᵀ) = r
  dim N(A) = n − r（零化度）
  dim N(Aᵀ) = m − r
```

## 7. 秩-零化度定理

```text
核心等式：dim N(A) + rank(A) = n（A 的列数）

含义：输入空间的维度 = 保留的维度（秩）+ 消失的维度（零空间）

  Ax 把 Rⁿ 映射到 Rᵐ：
  秩 = 输出子空间（列空间）的维数 = "信息保留多少"
  零化度 = 输入中被压扁的维度 = "信息损失多少"

推论（线性方程组解的结构，04 章）：
  齐次 Ax = 0：解空间维数 = n − r（自由变量数）
  非齐次 Ax = b：无解（b ∉ C(A)）、唯一解（r = n）、无穷多解（r < n）

工程视角：
  低秩矩阵 = 信息集中在少数方向（可压缩——LoRA/SVD 的依据）
  → 有效秩（effective rank）衡量"实际信息量"（09 章）
```

## 8. 向量空间的工程应用：嵌入与子空间

### 8.1 词嵌入 = 向量空间的语义

```text
词嵌入（Word2Vec/GloVe/BERT）：每个词 = 高维向量（如 768 维）
  → 词的"语义空间"就是向量空间（第 1 节视角）
  → 语义运算 = 向量运算：
     king − man + woman ≈ queen（类比推理 = 线性组合！）
  → 相似度 = 内积/余弦（内积空间，06 章）

向量空间性质的应用：
  词向量张成的子空间 = "可表达的语义范围"
  嵌入维度 = 语义自由度（维数选择，第 4 节）
  → 嵌入的"有效秩"（09 章）衡量语义冗余
```

### 8.2 子空间在机器学习中的角色

```text
① 数据子空间假设：数据近似落在低维子空间
   → PCA = 找该子空间的正交基（05/07 章）
   → 降维 = 投影到子空间（信息保留最大化）
② 信号与噪声分解：信号子空间 ⊕ 噪声子空间（正交补，06 章）
   → 滤波/去噪的几何解释
③ 流形假设：数据在低维流形上（子空间的非线性推广）
   → 流形学习/自编码器

⚠️ 工程警示：
  高维空间的"维数灾难"：体积集中在边界，距离度量失真
  → 高维数据先降维再分析（PCA/嵌入）
```

### 8.3 判断子空间的快速练习

```text
判断下列集合是否是 R²/R³ 的子空间（答案自证）：
  ① 过原点的直线         → 是（封闭）
  ② 不过原点的直线       → 否（不含零向量）
  ③ 第一象限（x≥0,y≥0）  → 否（数乘负数出界）
  ④ 平面 z = 0           → 是（xy 平面）
  ⑤ 单位圆上的点         → 否（加法不封闭）
  → 判定口诀：含零向量 + 加法数乘封闭（第 5 节）
```

## 9. 核心要点与思考题

> 🎯 **本章三句话总结**：
> 1. 向量 = 数据与几何的双重载体；线性组合是构造规则（矩阵乘法、神经网络层都是组合）；
> 2. 基 = 最小生成集（无关 + 张成），维数 = 基的大小——降维就是换更小的基；
> 3. 四个基本子空间切分矩阵信息：秩（保留）+ 零化度（消失）= 列数；低秩 = 可压缩。

**思考题**：

1. 为什么"不过原点的直线"不是子空间？（→ 5）
2. Ax = b 有解的充要条件（用子空间语言）？（→ 6 b ∈ C(A)）
3. 秩-零化度定理为什么叫"守恒律"？（→ 7 维度守恒）
4. 低秩矩阵为什么能压缩？（→ 7 工程视角）
