# 行列式

> 行列式是"变换的有向体积缩放因子"：det = 0 判奇异、det 连乘分解、克拉默法则解方程组、几何上表示面积/体积的缩放——行列式的性质比计算更重要（计算机从不按定义算行列式，但每个性质都在算法里被利用）

## 1. 行列式的定义：三条公理

```text
行列式 det(A)（|A|）是"输入矩阵、输出标量"的函数，由三条性质唯一确定：

① 单位矩阵的行列式 = 1：det(I) = 1
② 行交换变号：交换两行 → 行列式取反
③ 线性（对每行）：
   一行乘以 c → 行列式 ×c
   一行 = 两行之和 → 行列式 = 两行列式之和（固定其他行）

从公理推导出的核心事实：
  det = 0 ⇔ 矩阵奇异（不可逆）——行列式的第一身份是"奇异性检测器"
  行操作对 det 的影响完全由这三条决定（第 4 节）

展开定义（排列形式，理论用）：
  det(A) = Σ σ(p)·a₁ₚ₁·a₂ₚ₂···aₙₚₙ（所有排列求和）
  → 计算量 n! —— 计算机绝不按此计算（第 4 节）
```

## 2. 2×2 与 3×3 速算

```text
2×2：[a b; c d] → det = ad − bc
  [1 2; 3 4] → 1·4 − 2·3 = −2

3×3（对角线法则，只对 3×3 有效！）：
  [a b c; d e f; g h i] → aei + bfg + cdh − ceg − bdi − afh
  ⚠️ 对角线法则不能推广到 4×4（超立方体项的符号不同）——最常见的错误

工程：实际计算用手算展开（按某行/列）+ 初等变换（第 4 节）
```

## 3. 行列式的十大性质

```text
① 转置不变：det(Aᵀ) = det(A)（行性质 ⇔ 列性质通用）
② 行交换变号（公理）
③ 某行乘 c → det ×c；某行加另一行的 k 倍 → det 不变（消元不改变 det！）
④ 某行全 0 → det = 0
⑤ 两行成比例/相等 → det = 0
⑥ 三角矩阵：det = 主对角元素乘积（高斯消元的计算出口）
⑦ det(AB) = det(A)·det(B)（乘法拆解）
⑧ det(A⁻¹) = 1/det(A)
⑨ det(A) = Σ 特征值乘积（05 章）
⑩ det(cA) = cⁿ·det(A)（n 阶方阵——别漏掉 n 次幂）

推论（考试高频）：
  det(Aⁿ) = det(A)ⁿ；det(AᵀA) = det(A)² ≥ 0
```

> 🎯 **核心要点**：性质③+⑥给出**计算方法**（消元变三角，det 不变，再乘对角线）；性质⑦⑧⑨是"代数守恒"（乘法拆解、逆的倒数、特征值之积）。计算机算 det 就是消元到三角再乘对角线——O(n³) 而非 O(n!)。

## 4. 计算方法

### 4.1 初等变换法（实用首选）

```text
流程：高斯消元 → 上三角 → det = 主对角乘积 × 符号修正

行操作对 det 的影响（对照第 3 节）：
  交换两行：×(−1)（记录次数）
  某行 ×c：÷c 后继续（或最后乘回）
  行加 k 倍另一行：det 不变（消元主力，零成本）

例：[1 2; 3 4] → 行2−3×行1 → [1 2; 0 −2] → det = 1×(−2) = −2 ✓
```

### 4.2 按行展开（余子式）

```text
余子式 Mᵢⱼ：去掉第 i 行第 j 列后的行列式
代数余子式 Aᵢⱼ = (−1)^(i+j)·Mᵢⱼ

按第 i 行展开：det(A) = Σⱼ aᵢⱼ·Aᵢⱼ
选"零最多"的行/列展开 → 计算量最小（稀疏矩阵的利器）

技巧：先做初等变换制造零，再展开
```

### 4.3 数值算法

```text
计算机实现 = 高斯消元（带部分主元选择）：
  det ≈ 消元后对角乘积 × 行交换符号
  ⚠️ 大矩阵行列式数值溢出（指数级）→ 实际用"对数行列式"或直接不计算
  → 工程上 det 只用于"判奇异"（等价于检查秩/条件数，09 章）
```

## 5. 克拉默法则

```text
解线性方程组 Ax = b（n 个方程 n 个未知数）：
  xᵢ = det(Aᵢ)/det(A)
  其中 Aᵢ = 用 b 替换 A 的第 i 列

价值：理论意义（解的显式公式）> 计算意义
  计算量 O(n!·n) vs 高斯消元 O(n³)
  → 计算机解方程组绝不使用克拉默（考试/教学工具）
  但它完美展示了"行列式与解的关系"
```

## 6. 伴随矩阵与逆

```text
伴随矩阵 adj(A)：代数余子式矩阵的转置
  adj(A)ᵢⱼ = Aⱼᵢ（余子式）

求逆公式：A⁻¹ = adj(A)/det(A)

2×2 验证：[a b; c d] 的 adj = [d −b; −c a] → 除以 det → 与 02 章公式一致

用途：小矩阵手算、理论推导（如矩阵求导公式）
数值上：仅 2×2/3×3 实用；大矩阵用消元/分解（07 章）
```

## 7. 几何意义：有向体积

```text
核心直觉：det(A) = 线性变换 A 对"体积"的缩放因子（带符号）

  R²：det = 平行四边形有向面积（两列向量张成）
  R³：det = 平行六面体有向体积（三列向量张成）
  负号 = 变换翻转了方向（镜像）

推论：
  det = 0 → 体积压扁为 0 → 变换降维（信息丢失）→ 不可逆
  |det| > 1 → 放大；< 1 → 缩小
  det = 1 → 保体积变换（旋转/剪切）

概率论视角：
  y = Ax（随机向量线性变换）→ 密度函数的雅可比因子 |det(A)|
  → 概率变换公式、正态分布线性变换的归一化系数
```

## 8. 行列式的数值与工程实践

### 8.1 数值陷阱

```text
① 溢出：det 随阶数指数级增长
  100×100 矩阵的 det 可达 10^100（远超 double 范围）
  → 工程上几乎从不"算 det 值"，只关心"是否为 0"
② 判定奇异用 det 不可靠：
  det 极小 ≠ 奇异（可能是缩放导致的）
  ✅ 正确判定：SVD 的最小奇异值 / 条件数（09 章）
③ 消元累积误差：部分主元选择同样适用于 det 计算
```

### 8.2 工程上"用行列式"的正确姿势

| 需求 | 正确工具 | 错误工具 |
|------|---------|---------|
| 判可逆 | 条件数/SVD 最小奇异值 | det ≠ 0（误判率高） |
| 解方程组 | LU/消元（O(n³)） | 克拉默（O(n!·n)） |
| 求逆 | 消元/分解 | 伴随矩阵（大矩阵爆炸） |
| 体积/面积计算 | det 直接用 | —（几何意义可靠） |
| 雅可比变换 | det 直接用 | —（概率/积分必需） |

### 8.3 几何意义的工程应用

```text
① 图形学：三角形面积 = (1/2)|det|（顶点坐标矩阵）
   叉积 = det 的 3D 推广（法向量计算）
② 概率：线性变换的雅可比因子 |det(A)|（06 章）
   → 正态分布变换、变量替换积分的归一化
③ 几何判定：三点共线 ⇔ det = 0；多边形方向（det 符号）
   → 计算几何的"定向测试"（orientation test）标准做法
```

## 9. 核心要点与思考题

> 🎯 **本章三句话总结**：
> 1. det 由三条公理唯一确定；第一身份是"奇异性检测器"（det=0 ⇔ 不可逆）；
> 2. 计算方法 = 消元到三角（det 不变）再乘对角线——O(n³)；克拉默/伴随是理论工具而非数值工具；
> 3. 几何 = 有向体积缩放：det=0 压扁（信息丢失），|det| 是体积因子——概率论雅可比、图形学判向都靠它。

**思考题**：

1. 为什么计算机不算"按定义的行列式"？（→ 1 n! 爆炸）
2. 消元为什么"不改变 det"（除了行交换）？（→ 3 性质③）
3. det(AB) = det A · det B 的几何含义？（→ 7 复合变换体积缩放）
4. 为什么说克拉默法则"理论>计算"？（→ 5）
