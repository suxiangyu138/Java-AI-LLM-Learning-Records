# 特征值与特征向量

> 特征值 = 变换的"固有缩放"：Ax = λx 说"这个方向被变换后只缩放不转向"。特征分解把矩阵拆成"方向×缩放"——主成分分析（PCA）、PageRank、动力系统稳定分析、谱聚类全部建立其上；对称矩阵的谱定理让 PCA 成为可能

## 1. 定义与几何直觉

```text
定义：Ax = λx（x ≠ 0）
  λ = 特征值（eigenvalue）——缩放因子
  x = 特征向量（eigenvector）——"不变方向"（被变换后仍在原直线）

几何：对矩阵 A 代表的变换，
  特征向量 = "方向不变"的向量（只被拉长/压缩/反向）
  特征值 = 拉长倍数

  [2 0; 0 3]：特征向量 (1,0)、(0,1)，特征值 2、3（对角阵直接读）
  旋转 90° 矩阵 [0 −1; 1 0]：实域无特征值（都转向了 → 特征值为虚数 ±i）

物理直觉：
  主振动方向（振型的模态分析）
  主成分方向（数据变化最大的方向——PCA）
  长期行为方向（动力系统收敛到的模式）
```

> 🎯 **核心要点**：特征向量 = "变换的不变方向"，特征值 = "该方向上的强度"。对角化（第 4 节）之后，矩阵的幂、指数、求逆全部变成"逐特征值操作"——这是特征分解最大的工程价值。

## 2. 特征值的计算

```text
特征方程：
  det(A − λI) = 0（n 次多项式，n 个根——含重根与复根）

例：[2 1; 1 2]：
  det[2−λ 1; 1 2−λ] = (2−λ)² − 1 = 0 → λ = 1, 3
  特征向量（解 (A−λI)x = 0，04 章齐次方程组）：
    λ=3：−x+y=0 → x=(1,1)
    λ=1：x+y=0 → x=(1,−1)

⚠️ 高次特征多项式无求根公式（阿贝尔定理，n≥5）
  → 计算机算特征值**从不**求多项式——用 QR 迭代（07 章数值方法）
  → 3×3 以下手算，以上交给 LAPACK
```

## 3. 特征值的关键性质

```text
① 迹守恒：tr(A) = λ₁ + λ₂ + ... + λₙ（特征值之和）
② 行列式守恒：det(A) = λ₁·λ₂·...·λₙ（特征值之积）
   → det=0 ⇔ 有零特征值 ⇔ 奇异
③ 特征向量线性无关 ⇔ 特征值互不相同（充分条件）
④ 幂与逆的特征值：
   Aᵏ 的特征值 = λᵏ（特征向量不变）
   A⁻¹ 的特征值 = 1/λ（若可逆）
⑤ 平移：A + cI 的特征值 = λ + c（特征向量不变）
⑥ 特征向量的"方向不变性"：A⁵x = λ⁵x —— 幂次计算的捷径

数值注意：矩阵小扰动 → 特征值敏感（条件数相关，09 章）
```

## 4. 对角化

```text
定义：A = PDP⁻¹（P = 特征向量矩阵，D = 特征值对角阵）

可对角化的充要条件：n 个线性无关特征向量
  （特征值互异 ⇒ 可对角化；有重特征值要检查几何重数）

对角化的威力（幂次计算的本质）：
  Aᵏ = PDᵏP⁻¹ —— 对角阵的幂 = 逐元素 λᵏ！
  例：人口增长模型、马尔可夫链长期行为（PageRank！）
  eᴬ = P·diag(e^λᵢ)·P⁻¹（矩阵指数——微分方程组求解）

不能对角化的矩阵：缺特征向量（如 [1 1; 0 1] 只有一个特征向量）
  → 约当标准形处理（更一般的理论，工程少见）
```

## 5. 相似矩阵

```text
定义：B = P⁻¹AP（P 可逆）→ A 与 B 相似
性质：相似矩阵共享特征值（特征多项式相同）

几何：相似 = "同一个变换，不同坐标系下的表示"
  P = 坐标变换矩阵（08 章基变换）

对角化 = 找"把变换变成纯缩放"的坐标系（特征向量基）
  → 在特征向量基下，矩阵就是对角阵 D

工程意义：
  特征值相同 = 本质相同（换个坐标系而已）
  谱聚类/流形学习 = 找好的坐标系使结构显现
```

## 6. 对称矩阵与谱定理

```text
谱定理（对称矩阵的完整理论）：
  Aᵀ = A ⟹ A 可正交对角化：
    A = QΛQᵀ（Q 正交，Λ 特征值对角阵）

三大推论（PCA 的全部依据）：
  ① 特征值全为实数（虚数不可能出现在对称矩阵）
  ② 特征向量可正交归一（不同特征值对应的特征向量自动正交）
  ③ 特征分解 = 正交对角化（Q⁻¹ = Qᵀ，求逆零成本）

正定对称矩阵：特征值全正
  半正定：特征值 ≥ 0（协方差矩阵/格拉姆矩阵）

工程路线：
  协方差矩阵 Σ = XᵀX/n（对称半正定）
  → 特征分解 Σ = QΛQᵀ
  → 最大特征值方向 = 数据方差最大方向 = 第一主成分
  → 这就是 PCA 的完整数学（09 章）
```

## 7. 应用：PCA、PageRank 与动力系统

### 7.1 PCA（主成分分析）

```text
流程：数据中心化 → 协方差矩阵 → 特征分解 → 取前 k 大特征值方向
  X(原始) → X̃(中心化) → Σ = X̃ᵀX̃/n → Σ = QΛQᵀ
  → 投影到前 k 个特征向量（主成分）→ 降维

意义：特征值 = 该方向的方差大小（信息量）
  保留前 k 个 = 保留最大信息量的低维表示
  应用：可视化、去噪、压缩、特征工程
```

### 7.2 PageRank

```text
马尔可夫链长期状态 = 特征值为 1 的特征向量（主特征向量）
  r = M·r（稳态条件）→ r 是 M 的 Perron 特征向量
  → Google 的 PageRank：网页重要性 = 转移矩阵主特征向量

幂法（power iteration）：r ← M·r 反复迭代收敛到主特征向量
  → 特征值计算的经典数值方法（07 章）在大规模问题上的应用
```

### 7.3 动力系统

```text
xₖ₊₁ = Axₖ → xₖ = Aᵏx₀ = Σ cᵢλᵢᵏvᵢ
  |λᵢ| > 1 → 发散（不稳定）
  |λᵢ| < 1 → 衰减（稳定）
  |λᵢ| = 1 → 保持（振荡/边界）

→ 稳定性分析 = 看特征值模长（谱半径 ρ(A) = max|λᵢ|）
  深度学习：权重矩阵的谱半径影响梯度爆炸/消失（09 章）
  RNN 梯度消失的根本原因：Wᵏ 的行为由特征值决定！
```

## 8. 特征值的数值计算与工程注意

### 8.1 为什么不算特征多项式

```text
05 章已提：n≥5 无求根公式（阿贝尔定理）
更实际的原因：
  特征多项式系数对矩阵元素极敏感（数值病态）
  → 从多项式求根得特征值 = 双重误差放大

✅ 工业算法（LAPACK 标准）：
  幂法（Power Iteration）：x ← Ax/||Ax|| 迭代 → 主特征值
    （PageRank 的算法，05 章 7.2）
  QR 迭代（07 章）：连续 QR 分解 → 收敛到拟三角 → 对角 = 特征值
  对称矩阵：雅可比旋转/分治法（更快更稳）
  → 复杂矩阵交给库（NumPy eigvals / LAPACK dsyev）
```

### 8.2 特征值的敏感度

```text
⚠️ 特征值对矩阵扰动可能极其敏感：
  [0 1; 0 0] 的微小扰动 ε → 特征值变化 √ε（远大于 ε！）
  → 近奇异/重特征值矩阵的特征值不可靠
  → 工程判据：条件数（09 章）评估可信度

工程习惯：
  □ 判断"是否有零特征值"（奇异）→ 用 SVD 最小奇异值
  □ 报告特征值同时报告敏感度（或改用 SVD）
```

### 8.3 深度学习中的谱分析速查

```text
□ 权重矩阵谱半径 ρ(W) = max|λ|：RNN 梯度爆炸/消失的判据（05 章 7.3）
□ 协方差谱（PCA）：特征值 = 各方向方差（衰减快 = 可压缩）
□ 拉普拉斯谱：图聚类/谱归一化（09 章）
□ 初始化：正交初始化控制谱半径（保证梯度流动）
→ "谱"是深度学习的体检指标：训练前看谱、训练中看谱、调参看谱
```

## 9. 核心要点与思考题

> 🎯 **本章三句话总结**：
> 1. 特征值/向量 = 变换的固有缩放与不变方向；特征多项式无求根公式（n≥5）→ 计算机用 QR 迭代；
> 2. 对角化 = 特征向量坐标系下的纯缩放：Aᵏ = PDᵏP⁻¹ 是幂次计算的本质；相似 = 换坐标系不换本质；
> 3. 对称矩阵谱定理（实特征值 + 正交对角化）→ 协方差分解 = PCA；PageRank = 主特征向量；谱半径决定动力系统与 RNN 的稳定性。

**思考题**：

1. 为什么计算机不算特征多项式？（→ 2 阿贝尔定理）
2. Aᵏ 为什么能"逐特征值"算？（→ 4 对角化威力）
3. PCA 为什么取"最大特征值方向"？（→ 7.1 方差=特征值）
4. RNN 梯度消失与谱半径什么关系？（→ 7.3）
