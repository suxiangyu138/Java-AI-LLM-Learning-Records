# 矩阵分解：LU、QR 与 SVD

> 分解 = 把矩阵拆成"好算的因子"：LU 是消元的因子化（解方程组）、QR 是正交化（数值稳定最小二乘）、SVD 是万能分解（任意矩阵 × 方向 × 强度——低秩近似之王）。Eckart-Young 定理保证"截断 SVD 是最优低秩近似"——它是压缩、推荐、LoRA 的数学根基

## 1. 为什么需要分解

```text
原问题（直接算）          分解后（拆成好算的）
解 Ax = b                A = LU → 两次三角回代（快且稳）
最小二乘 min||Ax−b||²     A = QR → x = R⁻¹Qᵀb（无 AᵀA 病态）
求特征值                  A = QΛQᵀ（对称）/ SVD（一般）
压缩/降维                 A = UΣVᵀ → 截断保留前 k 项

统一思想：把"复杂矩阵"拆成"结构简单因子"（三角/正交/对角）
  → 简单因子的运算有 O(n²)/O(n) 快速算法
```

## 2. LU 分解：高斯消元的因子化

```text
分解：A = LU（L 下三角单位阵，U 上三角）
  高斯消元的每一步行操作 = 左乘一个初等矩阵
  → 所有操作合并 = L⁻¹；消元结果 = U
  → LU 就是"消元过程的记录"

带部分主元：PA = LU（P 为置换矩阵——行交换的记录）
  → LAPACK dgesv 的标准形态（数值稳定性必需）

解方程组的威力（多次右端项）：
  第一次：分解 PA = LU（O(n³)）
  之后每次 Ax = bᵢ：两次三角回代（O(n²)）
  → 同矩阵多右端项场景（仿真/优化迭代）效率提升

变体：
  LDLᵀ（对称矩阵，无平方根）
  Cholesky：A = LLᵀ（正定矩阵——最快的对称分解，06 章）
```

## 3. QR 分解：正交化

```text
分解：A = QR（Q 正交，R 上三角）
  列视角：A 的列 = Q 列的线性组合（Q 是 A 列空间的"标准正交化"）

三种算法：
  ① 格拉姆-施密特（06 章——古典版数值不稳定）
  ② 修正格拉姆-施密特（MGS，稳定性改善）
  ③ Householder 反射（工业标准——每次反射消去一列的下方）

QR 的核心价值（最小二乘）：
  法方程 AᵀAx = Aᵀb 病态（条件数平方，09 章）
  QR 解：x = R⁻¹Qᵀb（条件数不变——数值稳定）
  → 工业最小二乘 = QR（或 SVD）

特征值计算：QR 迭代（连续 QR 分解收敛到三角阵 → 对角线 = 特征值）
  → 计算机算特征值的标准方法（05 章呼应）
```

## 4. SVD：奇异值分解（重点）

### 4.1 定义

```text
任意矩阵 A（m×n）都可分解：
  A = U Σ Vᵀ

  U（m×m 正交）：左奇异向量（列空间 C(A) 的正交基）
  Σ（m×n 对角）：奇异值 σ₁ ≥ σ₂ ≥ ... ≥ σᵣ > 0（r = rank）
  V（n×n 正交）：右奇异向量（行空间 C(Aᵀ) 的正交基）

奇异值与特征值的关系（第 5 节）：
  σᵢ² = AᵀA 的特征值（λᵢ）

几何：任意线性变换 = 旋转（Vᵀ）→ 缩放（Σ）→ 旋转（U）
  → "最一般的变换分解"：方向分解 × 强度分解
```

### 4.2 为什么 SVD 是"万能"

| 特性 | 说明 |
|------|------|
| 任意矩阵 | 非方阵/奇异/秩亏都能分解（特征分解只限可对角化方阵） |
| 数值稳定 | 无需计算 AᵀA（避免平方条件数） |
| 秩可见 | 非零奇异值个数 = 秩 |
| 低秩近似 | 截断前 k 个奇异值 = 最优近似（Eckart-Young） |
| 逆与伪逆 | A⁺ = VΣ⁺Uᵀ（摩尔-彭罗斯伪逆——最小二乘的统一解） |

### 4.3 工程应用全景

```text
① 压缩：图像 SVD（保留前 k% 奇异值 → 质量近似的压缩）
② 推荐系统：矩阵分解（用户×物品 = UΣVᵀ，隐因子模型）
③ 降维/PCA：SVD(X) 比特征分解(XᵀX) 数值更稳
④ 信息检索：LSA（潜在语义分析 = 词-文档矩阵 SVD）
⑤ 伪逆解最小二乘：x = A⁺b（秩亏也适用）
⑥ LLM 压缩与微调（2026 主战场，09 章）：LoRA/截断 SVD 压缩
```

## 5. SVD 与特征分解的关系

```text
联系（通过 AᵀA 与 AAᵀ）：
  AᵀA = VΣᵀΣVᵀ（对称 → 特征分解 = 谱定理）
  AAᵀ = UΣΣᵀUᵀ
  → 右奇异向量 = AᵀA 的特征向量
  → 左奇异向量 = AAᵀ 的特征向量
  → 奇异值 = 对应特征值的平方根

区别（为什么 SVD 更通用）：
  特征分解：只对方阵；A = QΛQ⁻¹（Q 不必正交）
  SVD：任意矩阵；A = UΣVᵀ（U、V 恒正交）
  → 对称矩阵时两者重合（SVD = 谱分解的推广）

数值结论：求特征值先算 SVD（不构造 AᵀA——避免平方病态）
```

## 6. Eckart-Young 定理

```text
定理（低秩近似的黄金定理）：
  在 Frobenius 范数（元素平方和）下，
  截断 SVD 是 A 的最优 k 秩近似：
  Aₖ = UₖΣₖVₖᵀ（保留前 k 个奇异值）
  ||A − Aₖ||_F = √(σₖ₊₁² + ... + σᵣ²)（丢掉的能量）

含义：
  "信息量" = 奇异值大小（σ₁ ≥ σ₂ ≥ ...）
  保留前 k 个 = 用最小误差换取最大信息保留
  奇异值衰减越快 → 矩阵"越低秩" → 压缩率越高

工程推论：
  奇异值快速衰减的矩阵（自然图像/词向量/权重矩阵）
  → 可大幅压缩（LLM 压缩的前提！）
  LoRA 的 ΔW = BA 低秩假设 = "权重更新是低秩的"（09 章）
```

> 🎯 **核心要点**：SVD 是"信息解构"：奇异值 = 各方向的能量（信息量），Eckart-Young 保证截断最优。**一切低秩方法（压缩、推荐、LoRA、PCA 的稳定版）都是截断 SVD 的化身**——2026 年 LLM 压缩/微调的主战场也在此（09 章）。

## 7. 三种分解的定位对照

| 分解 | 形式 | 适用问题 | 数值特性 | 复杂度 |
|------|------|---------|:---:|:---:|
| LU | PA = LU | 解方程组 Ax = b | 需主元选择 | O(n³) |
| Cholesky | A = LLᵀ | 正定系统/最小二乘法方程 | 稳定且最快 | O(n³/3) |
| QR | A = QR | 最小二乘、特征值迭代 | 稳定（无平方条件数） | O(n³) |
| SVD | A = UΣVᵀ | 低秩近似/伪逆/压缩/降维 | 最稳定（但最贵） | O(mn²) |

```text
选型口诀：
  解方程组 → LU/Cholesky
  最小二乘 → QR（数值）/ SVD（秩亏）
  低秩/压缩/降维 → SVD（无可替代）
  特征值 → 对称用谱分解，一般用 QR 迭代/SVD
```

## 8. 分解的工程选型与实现

### 8.1 数值库中的分解（LAPACK 函数对照）

| 需求 | LAPACK 例程 | 说明 |
|------|------------|------|
| 解方程组 | dgesv（LU+主元+回代） | 工业标准 |
| 最小二乘 | dgels（QR）/ dgelsd（SVD） | 秩亏用 SVD |
| 特征值（对称） | dsyev | 谱分解 |
| 奇异值 | dgesvd | 完整/经济 SVD |
| 正定系统 | dpotrf（Cholesky） | 最快 |

```text
Java 生态选择：
  教学/轻量：Apache Commons Math（EJML）
  性能关键：JBLAS/Netlib（LAPACK 绑定）
  AI：ND4J / DJL（深度学习张量库）
  ⚠️ 永远不要自己写三重循环矩阵乘（性能差 10-100 倍）
```

### 8.2 分解的数值稳定性层级

```text
稳定性排序（同一问题）：
  SVD（最稳）> QR > LU（带主元）> 法方程 AᵀA（最差）

代价排序（同一问题）：
  SVD（最贵，O(mn²)）> QR（O(n³)）> LU（O(n³) 系数小）

选型权衡（工程决策）：
  明确满秩、规模大 → LU（快且稳）
  可能秩亏、要诊断 → SVD（稳但贵）
  最小二乘 → QR（精度与速度平衡）；秩亏时 SVD
```

### 8.3 快速回忆：三种分解"一句话定位"

```text
LU   = 高斯消元的"账本"（解方程组的引擎）
QR   = 正交化（数值稳定最小二乘 + 特征值迭代）
SVD  = 万能分解（任意矩阵 × 方向 × 强度，低秩近似之王）
→ 面试答"矩阵分解"：先给定位，再给选型，最后给复杂度
```

## 9. 核心要点与思考题

> 🎯 **本章三句话总结**：
> 1. LU = 消元因子化（解方程组、多右端项 O(n²) 复用）；QR = 正交化（数值稳定最小二乘、QR 迭代算特征值）；
> 2. SVD = 任意矩阵的"旋转×缩放×旋转"，非零奇异值个数 = 秩，伪逆统一最小二乘；
> 3. Eckart-Young：截断 SVD 是最优低秩近似——压缩/推荐/LoRA 的数学根基；奇异值衰减越快越可压缩。
