# 线性方程组与高斯消元

## 1. 线性方程组的矩阵形式

```text
n 个未知数 m 个方程：
  a₁₁x₁ + a₁₂x₂ + ... + a₁ₙxₙ = b₁
  ...
  aₘ₁x₁ + ... + aₘₙxₙ = bₘ

矩阵形式：Ax = b（A: m×n，x: n×1，b: m×1）
增广矩阵：[A | b]（消元的操作对象）

分类：
  m = n 方阵（经典：唯一解/无解/无穷解）
  m < n 欠定（未知数多于方程——解不唯一）
  m > n 超定（方程多于未知数——一般无精确解 → 最小二乘）
```

## 2. 高斯消元：手工与算法

### 2.1 三种行操作

```text
① 交换两行
② 某行乘非零常数
③ 某行加另一行的 k 倍（消元主力）

目标：化成行阶梯形（每行首元在上一行首元右侧，下方全 0）

例：x + 2y = 5, 2x + 3y = 8
  [1 2 | 5]     行2 − 2×行1 →  [1 2 | 5]
  [2 3 | 8]                    [0 −1 | −2]
  回代：−y = −2 → y = 2；x + 4 = 5 → x = 1
```

### 2.2 主元与算法要点

```text
主元（pivot）：消元过程中"领头"的非零元素
  → 主元全非零 = 消元顺利进行（行阶梯无零行）
  → 主元出现零 → 换行（部分主元选择——数值稳定性关键）

高斯-约当消元（求逆标准流程）：
  [A | I] → 消元 → [I | A⁻¹]（02 章）
  计算量：O(n³)（乘法），O(n²) 存储

数值算法注意事项（09 章展开）：
  部分主元选择（避免小主元放大误差）
  条件数大 → 结果不可信（数值病态）
  → 工业实现 = LAPACK 的 dgesv（LU + 回代）
```

> 🎯 **核心要点**：高斯消元 = 唯一"学一次用一生"的线性代数算法——解方程组、求逆、算行列式、算秩、LU 分解（07 章）全部是它的变形。复杂度 O(n³) 是"解线性系统"的基准成本。

## 3. 解的存在性：秩判定

```text
Ax = b 解的存在性（用秩语言）：
  有解 ⇔ rank(A) = rank([A | b])（b 落在列空间 C(A)）
  ⚠️ 不一致方程组（rank 增大了）= 无解

解的个数（有解时）：
  唯一解 ⇔ rank(A) = n（列满秩，零空间只有 0）
  无穷多解 ⇔ rank(A) < n（有自由变量，零空间非平凡）

方阵（m = n）的特化：
  det(A) ≠ 0（满秩）→ 唯一解 x = A⁻¹b
  det(A) = 0 → 无解或无穷多解（看 b 是否在列空间）
```

| 情形 | rank 条件 | 解 |
|------|----------|-----|
| 方阵满秩 | r = m = n | 唯一解 |
| 方阵奇异 | r < n | 无解 或 无穷多解 |
| 超定（m>n） | 一般 r = n < m | 一般无解 → 最小二乘 |
| 欠定（m<n） | r < n | 无穷多解（n−r 个自由变量） |

## 4. 解的结构：特解 + 零空间

```text
非齐次 Ax = b 的通解 = 特解 + 齐次通解
  x = xₚ + xₕ（xₚ 任意一个解；xₕ 遍历零空间 N(A)）

几何：解集 = "零空间平移到特解处"（仿射子空间）
  → 零空间是"自由度"的来源：自由变量任意取值都仍满足方程

求法流程：
  ① 消元 → 行阶梯 → 识别主元列/自由列
  ② 特解：自由变量取 0，解主元变量
  ③ 零空间基：每个自由变量取 1（其余 0），解出基向量
  ④ 通解 = xₚ + c₁v₁ + c₂v₂ + ...
```

## 5. 齐次方程组

```text
Ax = 0（b = 0）：
  永远有解（x = 0 平凡解）
  非平凡解 ⇔ rank(A) < n ⇔ 列线性相关

解空间 = 零空间 N(A)：维数 = n − rank(A)（秩-零化度定理，01 章）

判定（方阵）：
  det(A) = 0 ⇔ 有非平凡解
  例：求 λ 使 (A − λI)x = 0 有非零解 —— 这就是特征值问题的本体！（05 章）

工程意义：
  特征向量 = 齐次方程组的非平凡解
  网络流/电路 = 齐次方程组（基尔霍夫定律的矩阵形式）
```

## 6. 消元法 vs 逆矩阵 vs 克拉默

| 方法 | 复杂度 | 数值稳定性 | 用途 |
|------|:---:|:---:|------|
| 高斯消元 | O(n³) | 好（带主元选择） | **计算机唯一选择** |
| 逆矩阵 x = A⁻¹b | O(n³)（求逆更贵） | 差（两次误差放大） | 理论表达 |
| 克拉默 | O(n!·n) | 差 | 教学/理论 |

```text
铁律重申（02 章）：能不求逆就不求逆
  解一次 Ax = b：消元一次 O(n³)
  求 A⁻¹ 再乘：求逆 O(n³) + 乘法 O(n²)——更贵且更不稳
  解多次 Ax = bᵢ（同 A 不同 b）：LU 分解一次 + 每次回代 O(n²)（07 章）
```

## 7. 最小二乘的衔接：超定方程组

```text
现实：观测数据远超未知数（m > n），Ax = b 一般无精确解
  → 求"最好的近似解"：min ||Ax − b||²（残差平方和最小）

解的存在性：b ∉ C(A)，但可投影到列空间（06 章详述）
  法方程：AᵀAx̂ = Aᵀb（正规方程）
  解：x̂ = (AᵀA)⁻¹Aᵀb（理论形式；实际用 QR/SVD，07 章）

线性回归就是超定方程组的最小二乘解：
  y = Xw（X 是特征矩阵）→ w = (XᵀX)⁻¹Xᵀy
  → 机器学习线性模型的数学本体（06/09 章）
```

## 8. 迭代法：大规模线性系统的现实解法

### 8.1 为什么需要迭代法

```text
直接法（高斯消元）O(n³)：
  n = 1000 → 10⁹ 次运算（可行）
  n = 10⁶（有限元/电网/大规模网络）→ 10¹⁸（不可行！）

且：稀疏矩阵（每行仅 5-20 个非零元）——消元会"填满"（fill-in）
  → 稀疏性被破坏 → 内存爆炸

迭代法：从初值出发，逐步逼近解（只做矩阵乘法/向量运算）
  → 每步 O(非零元数)，稀疏结构天然友好
```

### 8.2 两种经典迭代

```text
雅可比迭代（Jacobi）：
  xₖ₊₁ = D⁻¹(b − (L+U)xₖ)（D 对角部分）
  收敛条件：严格对角占优（|aᵢᵢ| > Σ|aᵢⱼ|）——充分非必要

高斯-赛德尔（Gauss-Seidel）：
  立即使用新值（收敛更快，约 2 倍于雅可比）
  → 逐行更新：xᵢ 新值参与后续行的计算

共轭梯度（CG）：对称正定矩阵的最优迭代（每步 O(n²) 稀疏版更快）
  → 大规模 PDE/优化的工业标准
```

### 8.3 工程要点

```text
□ 收敛判据：残差 ||Axₖ − b|| 小于阈值（不是看 x 的变化）
□ 预条件（preconditioning）：缩放矩阵加速收敛（M⁻¹Ax = M⁻¹b）
□ 收敛速度依赖条件数（09 章）——病态系统迭代很慢
□ 工程库：LAPACK（直接法）/ PETSc、Eigen（迭代法）

选型：n < 10⁴ 直接法；n > 10⁵ 稀疏 → 迭代法
```

## 9. 核心要点与思考题

> 🎯 **本章三句话总结**：
> 1. Ax = b 全貌由秩决定：有解 ⇔ rank 不增；唯一解 ⇔ 列满秩；通解 = 特解 + 零空间；
> 2. 高斯消元（O(n³)）是解方程组的唯一数值选择——逆矩阵与克拉默只是理论表达；
> 3. 超定方程组没有精确解 → 最小二乘（正规方程）——线性回归的数学起点。
