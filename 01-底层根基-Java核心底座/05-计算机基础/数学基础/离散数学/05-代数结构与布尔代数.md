## 1. 代数系统的定义

### 1.1 代数系统的组成

```
代数系统 = (集合 S, 运算 *, 常数, 公理)

例：整数加法系统 (Z, +)
  运算封闭：a+b ∈ Z
  满足公理：结合律、单位元 0、逆元 −a

工程直觉：代数系统 = "类型 + 操作 + 契约"
  Java 的接口 + 实现 = 代数系统的软件表达
```

### 1.2 运算的基本性质

| 性质 | 定义 | Java 对应 |
|------|------|-----------|
| 封闭性 | 运算结果仍在集合内 | 类型安全（编译期） |
| 结合律 | (a∘b)∘c = a∘(b∘c) | 并行归约可任意分组 |
| 交换律 | a∘b = b∘a | 加/并集（可乱序执行） |
| 单位元 | a∘e = e∘a = a | 加法 0、乘法 1、String 拼接 "" |
| 逆元 | a∘a⁻¹ = e | 加法的负数、乘法的倒数 |
| 分配律 | a∘(b⊕c) = (a∘b)⊕(a∘c) | 乘法对加法 |

> 🎯 结合律的工程价值常被低估：**归约（reduce）能否并行化，取决于运算是否满足结合律**——`sum` 可并行（结合律），`平均数的平均 ≠ 平均数`（不可并行）。Java Stream 并行归约的正确性契约正是结合律+单位元。

## 2. 群：最核心的代数结构

### 2.1 群的定义

```
群 (G, ∘)：封闭 + 结合 + 单位元 + 逆元

例子：
  整数加法群 (Z, +)
  模 n 乘法群：与 n 互素的剩余类（RSA 的数学基础！）
  置换群：排列的复合（对称性的数学）
  旋转群：图形旋转的组合

性质：单位元唯一、逆元唯一、消去律
  （ab=ac ⟹ b=c —— 群运算可"约分"）
```

### 2.2 子群与同态

```
子群：子集在运算下仍是群（如偶数在加法下）
同态：保运算的映射 f(a∘b) = f(a)∘f(b)
同构：双射同态 —— 结构完全相同

工程意义：
  同态 = 抽象接口的实现（保持"契约"的映射）
  Java：`Comparable` 的 compareTo 要保持传递性/一致性
    —— 这就是"排序关系是同态/偏序"的工程要求
```

### 2.3 循环群与生成元

```
循环群：所有元素都是某元素 g 的幂（gⁿ）
  例：模 7 乘法群 {1,2,3,4,5,6} 生成元 3：
    3¹=3, 3²=2, 3³=6, 3⁴=4, 3⁵=5, 3⁶=1（遍历全体）

工程应用：
  伪随机数（线性同余的循环结构）
  Diffie-Hellman 密钥交换（生成元 + 离散对数）
  —— 详见 密码学/ 目录
```

## 3. 环与域

### 3.1 层级结构

```
群（1 个运算）⊂ 环（加乘 2 个运算）⊂ 域（乘法可逆）

环 (R, +, ×)：加法成群、乘法半群、分配律
  例：整数环 Z、模 n 环 Zₙ、多项式环

域 (F, +, ×)：加法和乘法都成群（非零元可逆）
  例：有理数 Q、实数 R、模素数 p 的 Zₚ（有限域！）
```

### 3.2 有限域与工程

```
有限域 GF(p) = 模素数 p 的算术（加/乘/逆都可算）
  p=7：3⁻¹ = 5（3×5≡1 mod 7）

工程应用：
  ① 哈希：多项式哈希在有限域上运算（无溢出、可逆）
  ② 纠错码：Reed-Solomon 码在 GF(2⁸) 上构造（硬盘/QR 码）
  ③ 椭圆曲线密码：GF(p) 上的群运算（现代密码学主力）
  ④ AES：字节运算在 GF(2⁸) 上定义（S 盒构造）

—— 全部细节见 密码学/ 与 信息论/ 目录
```

> 💡 观察：抽象代数离工程并不远——**AES 加密、Reed-Solomon 纠错、ECC 公钥**每天都在每个设备上运行，它们都是有限域上的算术。这也是"最抽象的数学 = 最底层的工程"的绝佳例证。

## 4. 布尔代数

### 4.1 定义与基本运算

```
布尔代数 (B, ∧, ∨, ¬)：B = {0, 1}
  满足：交换、结合、分配、吸收、德摩根、补元

与命题逻辑一一对应（01 模块的代数化）：
  ∧ ↔ AND、∨ ↔ OR、¬ ↔ NOT、0 ↔ false、1 ↔ true
```

### 4.2 位运算 = 布尔代数的工程形态

```java
// Java 位运算就是布尔代数运算
int x = 0b1010, y = 0b1100;
x & y  // 0b1000   ∧ 逐位与
x | y  // 0b1110   ∨ 逐位或
x ^ y  // 0b0110   异或（对称差！）
~x     // 补码取反 ¬

// 位运算的经典技巧（全来自布尔代数恒等式）
x & (x - 1)       // 清除最低位 1（数 1 的个数）
x & (-x)          // 提取最低位 1（lowbit）
x ^ y ^ y == x    // 异或自反：无临时变量交换
(x + y) & 1       // 奇偶判断
```

| 位技巧 | 布尔代数解释 |
|--------|-------------|
| `x&(x-1)` 清最低位 | 借位传播的补码性质 |
| `x^(y^y)=x` | 异或群：每个元素是自己的逆元 |
| 状态压缩 | 用 n 位二进制表示 n 个开关 = 幂集与 2ⁿ 的对应 |

> 🎯 工程重点：**状态压缩 DP 与位掩码 = 幂集 + 布尔代数的工程实现**——n 位整数表示集合（第 i 位=元素 i 是否在集合中），子集枚举 = 二进制计数，这就是"计算机用位表示集合"的数学本质。

## 5. 逻辑电路与卡诺图

### 5.1 从布尔代数到电路

```
逻辑门 = 布尔运算的物理实现：
  AND 门 ↔ ∧、OR 门 ↔ ∨、NOT 门 ↔ ¬
  NAND 门：万能的（任何逻辑都可由 NAND 构造！）

加法器的布尔设计（半加器）：
  S = A ⊕ B（和），C = A ∧ B（进位）
  —— 加法 = 布尔代数 + 进位传播
```

### 5.2 卡诺图化简

```
目的：把逻辑表达式化简到最简与或式（电路最省门）

方法：2ⁿ 方格图，相邻 1 的方格合并（2、4、8 个一组）
  合并规则：互补的变量消去

工程意义：布尔表达式化简 = 代码条件逻辑的化简
  if ((a && b) || (a && c)) ≡ if (a && (b || c))
  —— 提取公因式就是布尔分配律
```

### 5.3 与现代 AI 的呼应

```
Shannon 定理（1938）：任何布尔函数可实现为电路
  2025 应用：布尔函数最小化 ↔ 神经网络结构剪枝
  （逻辑电路最小化思想迁移到模型压缩）

可满足性问题（SAT）：布尔公式求赋值
  工程：约束求解器（Z3）→ 程序验证、调度、密码分析
```

## 6. 代数结构的工程应用

### 6.1 应用总表

| 代数结构 | 工程形态 |
|---------|---------|
| 群 | 变换组合、对称性、加密协议（Diffie-Hellman） |
| 环 | 整数/多项式算术、哈希多项式 |
| 域 | 有限域 → AES、RS 纠错、ECC |
| 布尔代数 | 位运算、状态压缩、逻辑电路、SAT |
| 格 | 类型系统（泛型上界/下界）、数据流分析 |

### 6.2 结合律驱动的并行化（重点）

```
Java Stream 并行归约的正确性条件：
  reduce(identity, accumulator) 要求：
  ① accumulator 满足结合律
  ② identity 是单位元

✅ 可并行：sum、max、count（结合 + 单位元）
❌ 不可并行：average（非结合）、"排名"类（依赖顺序）

数学结论：并行 = 结合律的工程红利
  —— MapReduce 的正确性证明同样是结合律
```

### 6.3 半群/幺半群与现代架构

```
幺半群（Monoid）= 结合 + 单位元（无逆元）
  工程：日志聚合、指标累加（可合并计数器）
  2025 分布式系统：CRDT（收敛数据结构）就是
    "可合并操作满足结合律+交换律+幂等"的代数设计

从代数结构看系统设计：
  "能合并的"（结合/交换）→ 可分布式
  "不能合并的"（顺序依赖）→ 必须集中
```

> 🎯 **核心要点**：代数结构是"运算的契约"——群告诉你能约分，域告诉你能除，布尔代数告诉你位运算的规则，结合律告诉你能否并行。**设计系统前先问：这个运算是什么代数结构？** 这是从"会用 API"到"设计系统"的分水岭思维。

## 7. 小结

| 问题 | 答案 |
|------|------|
| 群的定义？ | 封闭+结合+单位元+逆元（可"约分"的运算） |
| 环 vs 域？ | 环=加群×半群；域=非零元都可逆 |
| 有限域有什么用？ | AES/纠错码/ECC 全部基于 GF(p) |
| 布尔代数 ↔ 工程？ | 位运算、状态压缩、逻辑门、SAT |
| 并行化的数学条件？ | 结合律 + 单位元（reduce 契约） |
| 抽象代数离工程远吗？ | 不远——每个设备的 AES/ECC 都在跑有限域算术 |
