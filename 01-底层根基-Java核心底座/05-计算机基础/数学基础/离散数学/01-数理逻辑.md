## 1. 命题逻辑基础

### 1.1 命题与联结词

**命题**：有确定真假值的陈述句。如"2 是素数"（真）、"1 > 2"（假）；疑问句、感叹句不是命题。

| 联结词 | 符号 | 读法 | 真值条件 |
|:---:|:---:|------|---------|
| 否定 | ¬ | 非 | p 假时真 |
| 合取 | ∧ | 且 | 两者皆真 |
| 析取 | ∨ | 或 | 至少一真 |
| 蕴含 | → | 若…则… | **仅当 p 真 q 假时为假** |
| 等价 | ↔ | 当且仅当 | 真假相同 |

### 1.2 蕴含的"反直觉"——真值表

```
p → q 的真值表（重点记忆第 3、4 行）：
  p=T q=T → T
  p=T q=F → F   ← 唯一的假
  p=F q=T → T   ← "假前提蕴含任何结论"（空真）
  p=F q=F → T

直觉理解：把 p→q 看作承诺"如果 p 成立我就保证 q"
  承诺只在 p 成立而 q 不成立时被违背（假）
  p 不成立时承诺未被检验（约定为真）
```

> 💡 工程对应：`if (p) then q` 的语义正是蕴含——条件判断的"真空真"让 `if (false) ...` 永远合法。这也是数据库 CHECK 约束、断言设计的逻辑基础。

### 1.3 联结词的优先级与复合命题

```
优先级：¬ > ∧ > ∨ > → > ↔
示例：p ∨ q ∧ ¬r  = p ∨ (q ∧ (¬r))
```

## 2. 等值演算

### 2.1 常用等值律（必须背熟）

| 名称 | 公式 |
|------|------|
| 双重否定 | ¬¬p ⇔ p |
| 德摩根律 | ¬(p∧q) ⇔ ¬p∨¬q；¬(p∨q) ⇔ ¬p∧¬q |
| 交换/结合/分配 | 与代数同类 |
| 蕴含等值 | p→q ⇔ ¬p∨q |
| 假言易位 | p→q ⇔ ¬q→¬p（逆否） |
| 吸收律 | p∨(p∧q) ⇔ p |

```
德摩根律的工程含义：
  !(a && b) == (!a || !b)   ← Java/所有语言通用
  这是"取反时翻转 AND/OR"规则的数学来源
```

### 2.2 用等值演算验证

```text
证明：¬(p→q) ⇔ p ∧ ¬q

  ¬(p→q)
  ⇔ ¬(¬p∨q)        蕴含等值
  ⇔ ¬¬p ∧ ¬q       德摩根
  ⇔ p ∧ ¬q         双重否定       ∎

工程含义："若 p 则 q"失败 = p 成立且 q 没成立 ——
  这正是测试用例设计（断言失败条件）的逻辑表达
```

### 2.3 可满足性与重言式

| 概念 | 定义 | 工程意义 |
|------|------|---------|
| 重言式（永真） | 所有赋值下为真 | 逻辑恒成立：`x || !x` |
| 矛盾式（永假） | 所有赋值下为假 | 不可满足的约束：`x && !x` |
| 可满足式 | 存在赋值为真 | 约束求解（SAT）的基础 |

## 3. 推理规则与证明

### 3.1 核心推理规则

| 规则 | 形式 | 别名 |
|------|------|------|
| 假言推理 | p→q, p ⟹ q | Modus Ponens |
| 拒取式 | p→q, ¬q ⟹ ¬p | Modus Tollens |
| 三段论 | p→q, q→r ⟹ p→r | 传递 |
| 析取三段论 | p∨q, ¬p ⟹ q | — |
| 合取引入 | p, q ⟹ p∧q | — |

### 3.2 证明方法谱系

| 方法 | 思路 | 适用 |
|------|------|------|
| 直接证明 | 假设前提，推出结论 | 常规命题 |
| 反证法 | 假设结论假，推出矛盾 | 证明无解/无穷（如 √2 无理） |
| 归纳法 | 基础步 + 归纳步 | 与自然数相关的命题 |
| 构造性证明 | 构造出满足条件的对象 | 存在性命题 |

> 🎯 工程意义：反证法 = 测试中的"破坏性验证"；归纳法 = 递归程序正确性的数学依据（循环不变量）。**写递归前先想归纳证明，是高级程序员与初学者的分水岭。**

## 4. 谓词逻辑与量词

### 4.1 从命题到谓词

```
命题只能表达"固定句子"；谓词引入"变量与论域"：
  P(x)："x 是素数" —— x 取具体值才是命题
  ∀x P(x)   全称：论域内所有 x 都满足
  ∃x P(x)   存在：至少一个 x 满足
```

### 4.2 量词的性质

```
① 量词交换不可随意：∀x∃y ≠ ∃y∀x
   "∀x∃y(x+y=0)"（每个 x 都有相反数）为真
   "∃y∀x(x+y=0)"（存在一个数使所有 x 加它都为 0）为假！

② 量词否定：¬∀xP(x) ⇔ ∃x¬P(x)；¬∃xP(x) ⇔ ∀x¬P(x)
   "不是所有人都通过" = "存在人没通过" —— 测试报告的否定语义

③ 嵌套量词的工程例：SQL 的 ALL 与 EXISTS 正是 ∀ 与 ∃
```

### 4.3 谓词逻辑的推理

```
全称实例化：∀xP(x) ⟹ P(c)
存在实例化：∃xP(x) ⟹ P(c)（c 为新常量）
泛化规则：P(c)（任意 c）⟹ ∀xP(x)

工程例：类型系统验证、定理证明器（Coq/Lean）的核心机制
```

## 5. 范式与逻辑电路

### 5.1 析取范式（DNF）与合取范式（CNF）

```
任何命题公式可化为标准范式：
  DNF：若干"合取项"的析取 —— 每个合取项 = 一组文字（命题或其否定）
  CNF：若干"析取项"的合取

示例（三人表决器）：
  F = (A∧B) ∨ (A∧C) ∨ (B∧C)   ← DNF：至少两人同意

工程意义：
  CNF → SAT 求解器的输入标准格式
  DNF → 直接映射为逻辑电路（见下）
```

### 5.2 范式 → 电路（Shannon 定理）

```
任何布尔函数都可以用与/或/非门实现（2025 AI 研究仍然引用）
  DNF 中每个合取项 = 一个 AND 门组
  DNF 整体 = OR 门汇合

现代意义：神经网络的"布尔函数可表达性"、
          电路最小化（卡诺图）与模型压缩的数学基础
```

## 6. 逻辑的工程应用

### 6.1 SQL 与逻辑

| SQL 构造 | 逻辑对应 |
|---------|---------|
| WHERE a AND b | a ∧ b |
| WHERE a OR b | a ∨ b |
| NOT EXISTS | ¬∃ |
| ALL / EVERY | ∀ |
| CHECK 约束 | 蕴含（违反即失败） |

```sql
-- 德摩根律在 SQL 优化中的应用：改写等价的谓词
-- WHERE NOT (a > 10 AND b < 5)  ≡  WHERE a <= 10 OR b >= 5
-- 优化器据此选择索引路径
```

### 6.2 规则引擎与专家系统

```
规则 = 蕴含式：if (条件) then (动作)   ⇔  条件 → 动作
  前向链（Forward chaining）：由事实触发规则（Drools 默认）
  后向链（Backward chaining）：由目标反查事实（Prolog）

Java 生态：Drools / Easy Rules 的规则即蕴含集合；
  规则冲突消解 = 命题演算的可满足性判定
```

### 6.3 逻辑与 LLM（2025 前沿）

```
现实：LLM 在严格逻辑任务上会出错（三段论、量词陷阱）
解法（Logic-LM 等研究）：
  ① 把问题翻译成符号逻辑（命题/谓词公式）
  ② 交给外部符号求解器（Z3 等）验证/求解
  ③ 结果回填给 LLM 校正回答

工程含义：RAG 检索的可信性校验、Agent 规划的合法性检查、
          提示词中的"逻辑约束注入"都源于谓词逻辑
  详见本目录 [07-在算法与AI中的应用](07-在算法与AI中的应用.md)
```

> 🎯 **核心要点**：逻辑是"计算的语法"——所有条件判断、约束、规则、推理都建立在命题/谓词逻辑之上。掌握等值演算（德摩根、蕴含改写）与量词语义，等于拿到读懂 SQL 优化器、规则引擎和 LLM 符号增强论文的钥匙。
