## 1. 集合基础与运算

### 1.1 基本概念

```
集合：元素的全体（无序、不重复）
表示：列举法 A={1,2,3}；描述法 A={x | x 是素数}
关系：∈（属于）、⊆（子集）、⊂（真子集）、∅（空集）

基数 |A|：元素个数（有限）或势（无限）
幂集 P(A)：A 的所有子集组成的集合，|P(A)| = 2^|A|
```

### 1.2 集合运算

| 运算 | 符号 | 定义 | Java 对应 |
|------|:---:|------|----------|
| 并 | A∪B | 属于任一集合 | `addAll` |
| 交 | A∩B | 同属两个集合 | `retainAll` |
| 差 | A−B | 属 A 不属 B | `removeAll` |
| 补 | Ā | 论域中不属于 A | 取反过滤 |
| 对称差 | A⊕B | 恰属其一 | `symmetricDifference` |

```
核心恒等式（与逻辑等值律一一对应）：
  德摩根：¬(A∪B) = Ā∩B̄；¬(A∩B) = Ā∪B̄
  分配律：A∩(B∪C) = (A∩B)∪(A∩C)

记忆：集合运算 = 逻辑运算的"宏观版"
  ∩ ↔ ∧、∪ ↔ ∨、补 ↔ 否定 —— 同一套代数结构
```

### 1.3 容斥原理（引子）

```
|A∪B| = |A| + |B| − |A∩B|
|A∪B∪C| = |A|+|B|+|C| − |A∩B|−|A∩C|−|B∩C| + |A∩B∩C|
（详见 04-组合数学的完整展开）
```

> 🎯 工程直觉：`Set.union` 实现就是集合运算；"两个集合去重后的大小"直接用容斥——**面试题"统计同时满足多个条件的人数"全是容斥的变形**。

## 2. 关系：集合的笛卡尔积子集

### 2.1 定义

```
有序对 (a,b)：顺序敏感
笛卡尔积 A×B = {(a,b) | a∈A, b∈B}（所有有序对）
二元关系 R ⊆ A×B：笛卡尔积的任意子集
  aRb 表示 (a,b)∈R
```

```
工程对应：
  关系 = 表的行集（数据库关系模型的本名！）
  (a,b) ∈ R = 一行记录（外键指向）
  A×B = 笛卡尔积（SQL CROSS JOIN）
  R ⊆ A×B = 一个表是行集的子集约束
```

### 2.2 关系的表示与运算

| 表示法 | 说明 |
|--------|------|
| 有序对集合 | R = {(1,2), (2,3)} |
| 关系矩阵 | 行×列 0/1 矩阵（布尔矩阵） |
| 关系图 | 有向图：a→b 当且仅当 aRb |

```
复合关系：R∘S = {(a,c) | ∃b: aRb 且 bSc}
关系幂：R^n = R 复合 n 次
传递闭包 R*：R 复合任意次 —— 图的可达性！
```

> 💡 传递闭包的工程价值 = **图的可达性查询**（"A 能间接影响 B 吗"）：社交网络二度人脉、权限继承链、Maven 依赖传递——全是最短路径/闭包计算的变体（见 03-图论）。

## 3. 关系的性质

### 3.1 三大性质判定

| 性质 | 定义 | 判定 | 工程例 |
|------|------|------|--------|
| 自反 | 所有 aRa | 对角线上全 1 | `equals` 与自身为真 |
| 对称 | aRb ⟹ bRa | 矩阵对称 | 好友关系（双向） |
| 传递 | aRb 且 bRc ⟹ aRc | 矩阵自乘含于原 | 大小比较、继承链 |

### 3.2 组合性质

| 组合 | 名称 | 工程对应 |
|------|------|---------|
| 自反+对称+传递 | **等价关系** | 哈希一致性（见下节） |
| 自反+反对称+传递 | **偏序关系** | 依赖/优先顺序（见第 5 节） |
| 全部元素两两可比 | 全序/线序 | 排序的数学前提 |

> ⚠️ 常见混淆：对称 ≠ 反对称。反对称：aRb 且 bRa 则必须 a=b（如 ≤）。一个关系可以既不对称也不反对称（如"整除"对 {1,2,4} 是偏序）。

## 4. 等价关系与划分

### 4.1 等价类与商集

```
等价关系 → 把集合划分为等价类：
  [a] = {x | xRa}（与 a 等价的全体）
  划分性质：等价类两两不交、并集为全集
  A/R = 商集（所有等价类的集合）

示例：模 3 同余关系 ≡₃ 把整数分为 [0],[1],[2] 三类
  0,3,6… 同余 0；1,4,7… 同余 1 —— 三个等价类
```

### 4.2 工程核心：哈希与等价

```
HashMap 的数学本质：
  equals 定义等价关系（自反/对称/传递必须满足！）
  hashCode 契约：等价的对象必须同哈希值
    —— 否则违反"等价类 → 同一桶"的划分性质

经典 bug：equals 不满足传递性（如"按年龄相等"）→ 等价类破坏
经典 bug：可变对象的 hashCode 变化 → 对象从桶中"消失"
```

### 4.3 其他应用

```
并查集（Union-Find）：动态维护等价类的数据结构
  合并操作 = 合并两个等价类；查找 = 所属等价类代表
  最小生成树（Kruskal）的核心数据结构

数据库去重、日志聚合（同 key 聚合 = 等价类归并）
```

## 5. 偏序与哈斯图

### 5.1 偏序与可比

```
偏序 ≤：自反 + 反对称 + 传递
  可比：a≤b 或 b≤a 至少一个成立
  不可比：两者都不成立（偏序的"偏"）

示例：集合包含 ⊆ 是偏序（{1} 与 {2} 不可比）；
     实数 ≤ 是全序（任意两数可比）
```

### 5.2 哈斯图（Hasse Diagram）

```
画法：去掉自环与传递边，只画"直接覆盖"关系，小在下大在上

例：{1,2,3} 的幂集按 ⊆：
          {1,2,3}
     {1,2} {1,3} {2,3}
    {1}   {2}   {3}
          ∅
```

### 5.3 工程应用

| 概念 | 工程对应 |
|------|---------|
| 偏序 | 依赖关系（任务依赖、编译顺序） |
| 拓扑排序 | 偏序的线性化（见 03-图论） |
| 极元/最元 | 构建顺序中的"无依赖任务" |
| 格（Lattice） | 类型系统的最小上界/最大下界（Java 泛型推断） |

## 6. 函数：特殊的关系

### 6.1 函数的性质

函数 f: A→B：每个 a∈A 恰对应一个 b∈B（右唯一的关系）。

| 性质 | 定义 | 工程意义 |
|------|------|---------|
| 单射（一对一） | 不同 x 映不同 y | 唯一索引 |
| 满射（到上） | 每个 y 都有原像 | 覆盖性 |
| 双射 | 单射且满射 | 可逆映射（编码/解码） |

### 6.2 计数与工程

```
|A|=m, |B|=n：
  函数总数 = n^m
  单射数 = n!/(n−m)!（m≤n）
  双射数 = n!（m=n）

工程对应：
  函数 = 方法签名（入参→出参）
  双射 = 无损编解码（Base64、序列化-反序列化）
  单射 = 幂等键（一输入一输出，如 HashMap 的键值）
```

### 6.3 基数与无限

```
可数无限：与自然数一一对应（整数、有理数）
不可数无限：实数、幂集（对角线论证）
工程含义：浮点数离散化、"无限"的抽象（流式处理
  用"可数遍历"代替"全部装载"）
```

## 7. 集合论的应用：RAG 与数据库

### 7.1 集合建模 RAG（2025 研究共识）

```
RAG 的集合论视角：
  语料库 = 文档集合 D
  检索 = 相似度阈值过滤 → 子集 S ⊆ D
  多路检索合并 = 并集/交集/对称差操作
  （SQL 式：UNION 合并上下文、INTERSECT 找共性）
  去重 = 集合消重（同一段落多个来源命中）

工程：2025 年知识图谱 RAG 论文把"检索+过滤+合并"
  显式建模为集合运算 —— 集合论直接成为 AI 工程语言
```

### 7.2 数据库的关系模型

```
关系（表）= 属性的笛卡尔积的子集
主键 = 函数（元组→唯一标识，单射性保证）
外键 = 关系引用（复合）
连接（JOIN） = 关系运算（自然连接 = 公共属性相等的元组组合）

SQL 代数（SELECT/WHERE/JOIN）= 关系代数的工程实现
  —— 集合论不是"数学课作业"，是数据库的底层契约
```

### 7.3 Bloom Filter：用集合思想省空间

```
问题：判断元素是否在集合中（允许少量误报）
解法：位数组 + k 个哈希函数（不是存元素，是存"指纹"）
  插入：k 位全置 1；查询：k 位全 1 则"可能在"
  （误报率 = 位冲突概率，鸽巢原理的工程化，见 04 模块）

工程：Redis Bloom、缓存穿透防护、去重漏斗
```

> 🎯 **核心要点**：集合论是"容器的数学"——HashSet 是集合运算、表是关系、外键是关系复合、主键是函数。**你在工程里写的每一个 Set/Map/SQL 语句，都在执行集合论的公理。**
