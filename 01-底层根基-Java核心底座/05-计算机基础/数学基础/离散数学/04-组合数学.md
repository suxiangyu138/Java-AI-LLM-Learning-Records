## 1. 两大计数原理

### 1.1 加法原理与乘法原理

```
加法原理（或）：完成 A 有 m 种方式，B 有 n 种方式（互斥）→ m+n
乘法原理（且）：第一步 m 种，第二步 n 种（独立）→ m×n

示例：
  密码 6 位数字：10⁶（乘法）
  选 1 门课（3 门数学或 4 门计算机）：7（加法）

工程直觉：加法 = 分支（switch 各分支计数），乘法 = 嵌套（循环相乘）
```

### 1.2 树图与决策树

```
计数问题可画成树：根到叶的每条路径 = 一种方式
  树的分支因子相乘 = 总数

工程对应：递归调用的执行路径总数、状态空间大小估计
  8 皇后：决策树剪枝前 = 64! 级；剪枝后仅 92 解
```

## 2. 排列与组合

### 2.1 核心公式

```
排列 P(n,k) = n!/(n−k)!（有序选取）
组合 C(n,k) = n!/(k!(n−k)!)（无序选取）

判断口诀：顺序有关 → 排列；顺序无关 → 组合
示例：
  10 人选 3 人排值班（顺序）→ P(10,3) = 720
  10 人选 3 人组队（无序）→ C(10,3) = 120
```

### 2.2 变体问题

| 类型 | 公式 | 示例 |
|------|------|------|
| 可重排列 | n^k | 密码、车牌 |
| 可重组合 | C(n+k−1, k) | 买 5 个水果 3 种可选 |
| 圆排列 | (n−1)! | 圆桌会议座次 |
| 不全相异排列 | n!/(n₁!n₂!...) | 单词字母重排 |
| 邻接约束 | 捆绑法/插空法 | 男女相邻排列 |

```
经典套路（面试必会）：
  捆绑法：要求相邻的元素先捆成一组再排列
  插空法：不相邻元素先排其余，再插空
  隔板法：正整数解的个数 = C(n−1, k−1)
    x₁+x₂+x₃=10 的正整数解 = C(9,2) = 36
```

### 2.3 Java 工程中的组合

```java
// 生成全部组合（回溯模板，leetcode 78/77）
void backtrack(int start, int k, List<Integer> cur) {
    if (cur.size() == k) { res.add(new ArrayList<>(cur)); return; }
    for (int i = start; i < n; i++) {
        cur.add(i);
        backtrack(i + 1, k, cur);
        cur.remove(cur.size() - 1);
    }
}
// 组合计数大数注意：C(50,25) ≈ 1.26×10¹⁴ 溢出 int/long
// → 用 BigInteger 或模运算（见 06 模块）
```

> 🎯 组合数的工程意义：**算法题"有多少种方案"全是组合计数**——动态规划的"状态数"、回溯的"剪枝效率"、概率题的分母，都依赖组合公式快速估算。

## 3. 二项式定理与组合恒等式

### 3.1 二项式定理

```
(a+b)ⁿ = Σ C(n,k)·a^(n−k)·b^k

推论：
  ① Σ C(n,k) = 2ⁿ（令 a=b=1）—— n 元素子集总数
  ② Σ (−1)^k C(n,k) = 0（a=1,b=−1）—— 奇偶子集数相等
  ③ (1+x)ⁿ 的生成函数形式 —— 组合与生成函数的桥梁
```

### 3.2 必背恒等式

| 恒等式 | 形式 | 记忆 |
|--------|------|------|
| 对称性 | C(n,k) = C(n, n−k) | 选 k 个 = 排除 n−k 个 |
| Pascal | C(n,k) = C(n−1,k−1) + C(n−1,k) | 杨辉三角递推 |
| 吸收律 | k·C(n,k) = n·C(n−1,k−1) | 选队长技巧 |
| Vandermonde | Σ C(n,i)C(m,k−i) = C(n+m,k) | 两队取人 |

```
Pascal 恒等式的工程形式 = 动态规划：
  dp[i][j] = dp[i-1][j-1] + dp[i-1][j]   ← 组合数 DP 表格
  （杨辉三角就是 C(n,k) 的 DP 表）
```

## 4. 鸽巢原理

### 4.1 基本形式

```
n+1 个物体放入 n 个盒子 → 至少一盒 ≥2 个
加强版：n 个盒子放 m 个物体 → 至少一盒 ≥ ⌈m/n⌉ 个

示例：
  367 人必有同年同月同日生（365 盒）
  任意 13 人必有两人同月生日
```

### 4.2 证明类应用（竞赛/面试）

```
经典证明题：
  ① 5 个点在 2×3 矩形内，必有两点距离 ≤ √2
     （分成 4 个 1×1.5 格子 → 鸽巢）
  ② 任意 6 人，必有 3 人互相认识或 3 人互相不认识
     （鸽巢 + 拉姆齐 R(3,3)=6）
  ③ 序列中必有某个前缀和被 n 整除（前缀和模 n 的鸽巢）
```

### 4.3 工程应用

| 场景 | 鸽巢含义 |
|------|---------|
| 哈希冲突 | 16 桶存 17 元素必有冲突（冲突必然性的数学证明） |
| 抽屉原理（DDoS 防护） | 流量必集中到有限资源 → 限流必要性 |
| 生日攻击（密码学） | √N 次碰撞概率过半 → 哈希强度设计（见 密码学/） |
| 负载均衡 | 任务 > 节点数时必有节点多任务 |

> 💡 鸽巢原理的工程价值不是"证明存在"，而是**预告必然性**：哈希冲突不可避免、碰撞攻击 √N 即可得手——知道"必然发生"才能提前设计应对（链表/红黑树、加盐）。

## 5. 容斥原理

### 5.1 二项与三项

```
|A∪B| = |A| + |B| − |A∩B|
|A∪B∪C| = Σ|单个| − Σ|两两交| + |三交|

推广：加奇减偶（奇数个集合的交集相加，偶数个相减）
```

### 5.2 经典应用

```
问题：1-100 中 3 或 5 的倍数有几个？
  |A| = ⌊100/3⌋ = 33，|B| = ⌊100/5⌋ = 20，|A∩B| = ⌊100/15⌋ = 6
  → 33 + 20 − 6 = 47

问题：错排问题 D(n)（n 封信装错信封）
  D(n) = n!·Σ(−1)^k/k! ≈ n!/e
  D(3)=2, D(4)=9 —— 面试经典"全都错位"计数
```

### 5.3 工程应用

```
统计去重：多个条件分别计数后合并（SQL 统计报表的容斥）
  例：注册用户 ∩ 下单用户 ∩ 活跃用户 的数量
概率重叠：A 事件或 B 事件概率 = P(A)+P(B)−P(A∩B)
  测试覆盖率：语句覆盖 ∪ 分支覆盖 的并集计算
```

## 6. 递推关系

### 6.1 常系数线性递推

```
形式：aₙ = c₁·aₙ₋₁ + c₂·aₙ₋₂（二阶为例）
特征方程：r² = c₁r + c₂ → 解出 r₁, r₂ → 通项 aₙ = A·r₁ⁿ + B·r₂ⁿ

经典：斐波那契 Fₙ = Fₙ₋₁ + Fₙ₋₂
  特征根：φ = (1+√5)/2，Fₙ = (φⁿ − (−φ)⁻ⁿ)/√5
  —— O(1) 公式 vs O(n) 循环 vs O(log n) 矩阵快速幂
```

### 6.2 递推的工程形态

```
① 动态规划 = 递推 + 最优子结构
   dp[i] = f(dp[i-1], ...)  ← 就是递推关系的工程实现
② 矩阵快速幂：递推加速到 O(log n)
   [Fₙ  ]   [1 1]^n   [F₁]
   [Fₙ₋₁] = [1 0]  ×  [F₀]
③ 生成函数：把递推变成代数方程
   G(x) = Σ aₙxⁿ → 用形式幂级数求通项（竞赛/理论）
```

### 6.3 常见递推序列

| 序列 | 递推 | 通项/特性 | 场景 |
|------|------|----------|------|
| 斐波那契 | Fₙ=Fₙ₋₁+Fₙ₋₂ | φⁿ 指数增长 | 分治、兔子问题 |
| 卡特兰数 | Cₙ=ΣCₖCₙ₋₁₋ₖ | Cₙ=C(2n,n)/(n+1) | 括号、二叉数、出栈序列 |
| 错排 | Dₙ=(n−1)(Dₙ₋₁+Dₙ₋₂) | ≈ n!/e | 全错位 |
| 约瑟夫环 | J(n,k) 递推 | O(n) 解 | 报数出圈 |

> 🎯 工程结论：**递推 = 动态规划的数学骨架**。看到 DP 状态转移方程，本质就是在解递推关系；而矩阵快速幂让"第 10¹⁸ 项"可解——这是斐波那契类题 O(log n) 解法的数学来源。

## 7. 组合数学的工程应用

### 7.1 算法复杂度与组合计数

```
组合数在算法分析中的角色：
  ① 子集总数 2ⁿ → 指数算法复杂度（状态压缩 DP 的 2ⁿ 来源）
  ② 排列 n! → 全排列穷举的复杂度
  ③ 组合 C(n,k) → "选 k 个"类问题的状态空间
  ④ 树形结构计数（卡特兰数）→ 括号匹配问题数

"复杂度怎么来的" = "组合数学在数状态空间"
```

### 7.2 信息论与编码（引子）

```
不同符号排列数 = 信息量的计数基础：
  2ⁿ 个二进制串 = n 位信息容量
  Huffman 编码的最优性证明 = 组合计数 + 贪心

（深入见 信息论/ 与 密码学/ 目录）
```

### 7.3 2025 AI 场景中的组合思想

| 场景 | 组合数学角色 |
|------|-------------|
| 采样与检索 | 从语料组合出上下文的方案数（检索组合爆炸） |
| 数据增强 | 组合变换（替换/删除/重排）的计数与采样 |
| 实验设计 | A/B 组合的试验次数（因子组合） |
| Tokenizer 词表 | 组合生成子词（BPE 的贪心合并 = 组合优化） |

> 🎯 **核心要点**：组合数学是"数数"的科学——数清方案数，才能分析复杂度、设计概率、证明必然性。面试中"有多少种方案"的题目，本质都是组合数学的实战演练。
