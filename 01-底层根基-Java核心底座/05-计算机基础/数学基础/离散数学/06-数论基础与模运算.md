## 1. 整除与素数

### 1.1 整除基础

```
a | b：a 整除 b（存在整数 k：b = ka）
性质：传递性、线性组合（a|c 且 a|d ⟹ a|(mc+nd)）

算术基本定理：任何整数唯一分解为素数幂
  360 = 2³·3²·5 —— 唯一分解是数论的基石
```

### 1.2 素数判定与筛法

```
试除法：√n 以内验证（O(√n)）
埃氏筛：O(n log log n) 求 1..n 全部素数
线性筛（欧拉筛）：O(n) 且每个合数只被筛一次（工程首选）

Java 示例（线性筛模板）：
  int[] primes = new int[n];
  boolean[] comp = new boolean[n+1];
  int cnt = 0;
  for (int i = 2; i <= n; i++) {
      if (!comp[i]) primes[cnt++] = i;
      for (int j = 0; j < cnt && i * primes[j] <= n; j++) {
          comp[i * primes[j]] = true;
          if (i % primes[j] == 0) break;   // 关键：保证只筛一次
      }
  }

素数定理：π(n) ≈ n/ln n —— 随机选数约 1/ln n 概率为素数
  → RSA 找素数的依据（随机试 + Miller-Rabin）
```

> 💡 素数在工程中的地位：哈希表容量选素数可减少分布模式（经典经验）；RSA 的 p、q 是大素数；Miller-Rabin 概率素性测试是密码学的默认工具（详见 `密码学/`）。

## 2. gcd 与欧几里得算法

### 2.1 欧几里得算法（辗转相除法）

```
gcd(a, b) = gcd(b, a mod b)
终止：gcd(a, 0) = a

示例：gcd(252, 105)
  252 = 2×105 + 42
  105 = 2×42 + 21
  42 = 2×21 + 0
  → gcd = 21
```

```java
// 迭代实现（工程标准）
int gcd(int a, int b) {
    while (b != 0) {
        int t = a % b;
        a = b;
        b = t;
    }
    return Math.abs(a);
}
// 复杂度：O(log min(a,b)) —— 每两步至少减半
```

### 2.2 扩展欧几里得：求逆元的关键

```
求 ax ≡ 1 (mod m) 的解（a 的模逆元）：
  扩展欧几里得在求 gcd 的同时回代出 x, y：
  ax + by = gcd(a, b)

应用：模逆元 = 有限域除法（见 05 模块）
  Java: BigInteger.modInverse() 底层就是扩展欧几里得
```

### 2.3 工程场景

| 场景 | gcd 角色 |
|------|---------|
| 分数约分 | 分子分母除 gcd |
| 最小公倍数 | lcm = a·b / gcd |
| 环形队列对齐 | 步长与长度的 gcd 决定遍历路径数 |
| 整数坐标共线 | 斜率约分为最简（方向向量） |

## 3. 模运算

### 3.1 同余

```
a ≡ b (mod m)：m | (a − b)（同余 = 同余类）
性质（模运算四则）：
  (a+b) mod m = ((a mod m) + (b mod m)) mod m
  (a×b) mod m = ((a mod m) × (b mod m)) mod m

工程核心：模运算可"边算边取模"避免溢出
  —— 大数乘法的标准姿势
```

```java
// 防溢出的模乘（Java 常见 bug 场景）
// long 乘法可能溢出：10⁹ × 10⁹ > 2⁶³
long modMul(long a, long b, long m) {
    long r = 0;
    a %= m;
    while (b > 0) {            // 二进制拆分 b
        if ((b & 1) == 1) r = (r + a) % m;
        a = (a << 1) % m;
        b >>= 1;
    }
    return r;
}
```

### 3.2 模运算的工程形态

| 场景 | 模运算角色 |
|------|-----------|
| 哈希取模 | `hash & (n-1)`（2 的幂优化）或 `% n` |
| 环形队列/数组 | `(head + 1) % capacity` |
| 循环调度 | 轮询取模（负载均衡） |
| 时间/日期 | 星期计算（mod 7）、闰年规则 |
| 密码学 | RSA/ECC 全部基于模算术（见 密码学/） |

### 3.3 模运算与哈希的深层关系

```
HashMap 扩容的数学：
  容量 n 为 2 的幂 → index = hash & (n−1)（位运算等价取模，快）
  扩容 ×2 → 元素要么留在原位，要么 +oldCap
  —— 这是"只靠低位索引"的数学前提

哈希冲突分布：模素数减少规律性冲突
  （经典经验：容量取素数避免同余模式，Java HashMap 已改 2 幂+扰动）
```

## 4. 快速幂

### 4.1 二进制幂算法

```
aⁿ mod m 的快速计算：把 n 拆成二进制，指数二进制分解
  a¹³ = a⁸·a⁴·a¹（13 = 1101₂）
  → 每次平方，遇 1 就乘 → O(log n) 次乘法
```

```java
long modPow(long a, long n, long m) {
    long r = 1 % m;
    a %= m;
    while (n > 0) {
        if ((n & 1) == 1) r = r * a % m;   // 当前位是 1
        a = a * a % m;                      // 平方递进
        n >>= 1;
    }
    return r;
}
// 对比朴素循环：O(log n) vs O(n) —— n=10⁹ 时毫秒 vs 秒
```

### 4.2 快速幂的三大用途

```
① 大指数模运算：a^(10¹⁸) mod m —— RSA 加密/解密的引擎
② 矩阵快速幂：递推加速（斐波那契 O(log n)，见 04 模块）
   把"数平方"换成"矩阵平方"即可
③ 原根/离散对数：密码协议的基础运算
```

> 🎯 工程重点：**RSA 解密 = 一次超大指数的模幂运算**——`c^d mod n` 里 d 是 2048 位整数，没有快速幂算法加密/解密要算到宇宙热寂。这是"O(log n) 复杂度拯救了公钥密码学"的经典故事。

## 5. 同余方程与逆元

### 5.1 模逆元

```
ax ≡ 1 (mod m) 的解 x 称为 a 的模逆元（记 a⁻¹）
存在条件：gcd(a, m) = 1（互素）

求法：
  ① 扩展欧几里得（通用）
  ② 费马小定理（m 为素数）：a^(m−2) mod m
     —— 快速幂直接求逆元！

费马小定理：m 素数且 a 不被 m 整除 ⟹ a^(m−1) ≡ 1 (mod m)
  应用：素性测试（反证：若 a^(n−1) ≢ 1 则 n 必为合数）
```

### 5.2 中国剩余定理（CRT）

```
求解同余方程组：
  x ≡ a₁ (mod m₁)，x ≡ a₂ (mod m₂)，…（mᵢ 两两互素）
解的存在唯一性（模 M = Πmᵢ 下）

工程应用：
  RSA-CRT：把 2048 位模分解为两个 1024 位运算 → 解密快 4 倍
  （OpenSSL 默认开启）
  大数表示：用互素模数表示数字（冗余算术）
```

### 5.3 丢番图方程

```
ax + by = c 有整数解 ⟺ gcd(a,b) | c
（扩展欧几里得给出特解，通解 = 特解 + 周期项）

工程：线性同余伪随机数（LCG）、坐标格点问题
```

## 6. 数论的应用

### 6.1 应用总表

| 领域 | 数论工具 |
|------|---------|
| 哈希 | 模运算、素数容量 |
| 校验与纠错 | 模校验（ISBN/信用卡 Luhn 算法 = mod 10） |
| 随机数 | 线性同余（LCG）、模算术 |
| 密码学 | gcd、逆元、快速幂、CRT、费马小定理（详见 密码学/） |
| 算法题 | 快速幂、gcd、筛法、模逆元（组合数取模） |

### 6.2 组合数取模（工程高频）

```
C(n,k) mod p（p 为素数，n 巨大）：
  ① 预处理阶乘 + 逆元数组：O(n) 预处理、O(1) 查询
     C(n,k) = fact[n] · inv(fact[k]) · inv(fact[n−k]) mod p
  ② Lucas 定理：n、k 按 p 进制分解，逐位组合
     —— n 达到 10¹⁸ 时唯一可行解

工程：概率 DP、组合计数题目的大数处理标准答案
```

### 6.3 校验和的数论本质

```
Luhn 算法（银行卡号）：
  从右往左，奇数位 ×2（>9 减 9），求和，要求 mod 10 = 0
  —— 本质是"可检测单个数字错误"的模 10 编码

CRC（循环冗余校验）：
  模 2 多项式除法（GF(2) 上的多项式）→ 检错码
  —— 数论在链路层的日常应用
```

> 🎯 **核心要点**：数论是"整数的代数"——gcd 是最小公共单位、模运算是循环世界里的算术、快速幂让超大指数可算。**哈希、校验、随机数、加密**四大工程领域共享同一套数论工具箱；深入密码应用见同父级的 `密码学/`、`初等数论/` 目录。
