## 3. 学习路线推荐

**路线 A：CS 基础补齐（3-4 天，推荐给后端工程师）**
02 → 01 → 03 → 06。这四条线直接对应日常工程：集合框架、SQL 逻辑、图算法（最短路径/拓扑）、哈希与取模。每个模块配 5-10 道手写练习题（等值演算、图遍历手推、gcd 手算）。

**路线 B：算法竞赛/面试冲刺（1-2 周）**
路线 A + 04。组合数学是算法面试的"计数题"理论根基（排列组合、鸽巢、容斥），与 LeetCode 的组合类题目一一对应。

**路线 C：AI 与理论研究（面向 AI 工程师/研究者）**
路线 A + 05 + 07。聚焦逻辑与 AI 推理（Logic-LM）、图论与知识图谱 RAG、自动机与形式语言——这是 2025 年 LLM 可信推理研究的数学底座。

> 💡 与知识库关系：03 图论与 03-AI 层的 `02-RAG检索增强生成`（知识图谱 RAG）直接衔接；06 数论与同父级的 `密码学/` 衔接；08 模块把全部数学概念映射到 Java 生态，是"数学 → 工程"的最后一公里。

## 4. 核心概念速查

| 概念 | 一句话定义 | 工程对应物 |
|------|-----------|-----------|
| 命题 | 有真假值的陈述句 | 条件表达式、断言 |
| 蕴含 p→q | "若 p 则 q"（假仅当 p 真 q 假） | SQL WHERE、if-else |
| 量词 ∀/∃ | 全称/存在量化 | SQL 的 ALL/EXISTS |
| 集合 | 无序不重复的元素全体 | HashSet、Redis Set |
| 关系 | 集合间元素的有序对集合 | 外键、知识图谱三元组 |
| 等价关系 | 自反+对称+传递 → 划分 | 哈希桶（同值同桶） |
| 偏序 | 自反+反对称+传递 | 依赖排序、拓扑排序 |
| 图 | 顶点+边的结构 | 社交网络、知识图谱 |
| 树 | 连通无环图 | 二叉树、文件系统 |
| 排列/组合 | 有序/无序选取 | 订单组合、索引选择 |
| 鸽巢原理 | n+1 物放 n 盒必有重复 | 哈希冲突的必然性 |
| 模运算 | 除法余数的代数 | 哈希取模、环形队列 |
| 群 | 封闭+结合+单位+逆元 | 变换组合、对称性 |
| 布尔代数 | 0/1 的逻辑代数 | 位运算、条件逻辑 |

> 🎯 **核心要点**：离散数学 = 计算机科学的"语法书"——计算机只能处理离散对象（位、整数、图、逻辑真值），所以描述计算世界的语言就是离散数学。**每个数学概念都能在工程中找到直接对应物**：集合→HashSet、关系→外键、图→知识图谱、模运算→哈希取模。带着"这个概念对应什么工程"的问题学习，效率翻倍。
