## 1. 图的基本概念与表示

### 1.1 图的定义

```
图 G = (V, E)：顶点集 V + 边集 E
  无向图：边 {u,v}（无序）
  有向图：边 (u,v)（有序，u→v）
  带权图：边附权重（距离、成本、相似度）

相关概念：度（无向：相邻边数；有向：入度/出度）
  握手定理：所有顶点度数之和 = 2|E|
  推论：奇数度顶点个数必为偶数
```

### 1.2 图的表示

| 表示 | 原理 | 查询边 | 空间 | 适用 |
|------|------|:---:|:---:|------|
| 邻接矩阵 | V×V 布尔/权值 | O(1) | O(V²) | 稠密图 |
| 邻接表 | 每顶点存邻居列表 | O(deg) | O(V+E) | 稀疏图（现实主流） |

```java
// Java 邻接表表示（图论题标准模板）
List<List<Integer>> graph = new ArrayList<>();
for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
graph.get(u).add(v);          // 无向图再加 graph.get(v).add(u)
```

### 1.3 特殊图

| 图类 | 定义 | 工程场景 |
|------|------|---------|
| 完全图 K_n | 任意两点相连 | 全连接计算 |
| 二部图 | 顶点分两组，边只跨组 | 匹配问题（任务分配） |
| 树 | 连通无环 | 层级结构 |
| DAG | 有向无环图 | 依赖图、拓扑序 |

> 🎯 工程直觉：**万物皆图**——社交网络（好友边）、依赖管理（Maven DAG）、知识图谱（三元组）、状态机（状态+转移）、微服务调用链（有向图）。图论是数据结构课的天花板，也是工程建模的通用语言。

## 2. 图的遍历

### 2.1 BFS 与 DFS

| 遍历 | 数据结构 | 特性 | 典型应用 |
|------|:---:|------|---------|
| BFS（广度优先） | 队列 | 最短路径（无权图） | 层级遍历、最短跳数 |
| DFS（深度优先） | 栈/递归 | 路径探索、回溯 | 拓扑序、连通分量、环检测 |

```
BFS 求无权图最短路径：
  dist[s] = 0；逐层扩展：dist[v] = dist[u] + 1
  → 首次到达即最短（分层性质）

DFS 的三大衍生：
  ① 环检测：DFS 树中遇到"回边"即环
  ② 拓扑排序：DAG 的 DFS 完成序逆序
  ③ 强连通分量：Tarjan / Kosaraju
```

### 2.2 复杂度与实现要点

```
BFS/DFS：O(V + E)（邻接表）
  内存：visited 数组防重复访问（树不需要，图必须！）
  递归深度：DFS 大图会栈溢出 → 用显式栈或 BFS

Java 工程注意：递归 DFS 深 10 万层会 StackOverflowError
  —— 工程图遍历优先迭代式 BFS
```

## 3. 连通性与欧拉/哈密顿

### 3.1 连通性

```
无向图连通：任意两点有路径
有向图：弱连通（忽略方向连通）/ 强连通（双向可达）
连通分量：极大连通子图（并查集是动态维护工具！）

桥（割边）与割点：删除后连通分量数增加
  工程：网络拓扑的"单点故障"分析
```

### 3.2 欧拉路径（一笔画）

```
欧拉路径：经过每条边恰好一次
判定（无向）：
  欧拉回路：所有顶点度数为偶数
  欧拉路径：恰好两个奇数度顶点

工程应用：
  邮递员问题（中国邮路）、电路板布线、
  一笔画游戏（leetcode 经典题）
```

### 3.3 哈密顿路径

```
哈密顿路径：经过每个顶点恰好一次（NPC 问题！）
  无多项式判定算法 —— 与欧拉路径（P）形成鲜明对比

工程意义：旅行商问题（TSP）是哈密顿回路的加权版
  现实解法：近似算法（2-opt）、动态规划（Held-Karp O(2ⁿ·n²)）
  这是"图论告诉哪些问题能快速解决、哪些不能"的经典案例
```

> ⚠️ P vs NP 的分界线：欧拉（边一次）容易、哈密顿（点一次）难——**同一句话换个对象，难度天壤之别**。理解这个对照，就理解了算法设计的边界感。

## 4. 树：图的特殊形态

### 4.1 树的等价定义

```
以下说法等价（n 个顶点）：
  ① 连通且无环
  ② 边数 = n − 1 且连通
  ③ 任意两点有唯一路径
  ④ 连通但删任意边即不连通

推论：树是"最省边的连通图" —— 最小生成树的候选形态
```

### 4.2 生成树与最小生成树（MST）

```
生成树：含全部顶点且连通的无环子图（n−1 条边）
最小生成树：总权重最小的生成树

Kruskal：按权值排序 + 并查集判环（O(E log E)）
Prim：从一个顶点贪心扩展（O(V²) 或堆优化 O(E log V)）

工程应用：网络布线、聚类（单链接聚类 = MST 的切边）、
         电路设计的最短连通
```

### 4.3 树结构的工程形态

| 树类型 | 用途 |
|--------|------|
| 二叉树/AVL/红黑树 | 有序集合（TreeMap） |
| 堆（完全二叉树） | 优先队列 |
| 字典树（Trie） | 前缀匹配、敏感词 |
| 后缀树/数组 | 全文检索 |
| 决策树 | 机器学习模型 |

## 5. 最短路径与关键算法

### 5.1 算法谱系

| 算法 | 适用 | 复杂度 | 核心思想 |
|------|------|--------|---------|
| BFS | 无权图 | O(V+E) | 逐层扩展 |
| Dijkstra | 非负权 | O((V+E)logV) | 贪心 + 优先队列 |
| Bellman-Ford | 含负权（可判负环） | O(VE) | 松弛 V−1 轮 |
| Floyd-Warshall | 全源（小图） | O(V³) | 动态规划 |

```java
// Dijkstra 模板（Java 工程最常用）
PriorityQueue<int[]> pq = new PriorityQueue<>((a,b) -> a[1]-b[1]);
pq.offer(new int[]{s, 0});
int[] dist = new int[n];
Arrays.fill(dist, Integer.MAX_VALUE);
dist[s] = 0;
while (!pq.isEmpty()) {
    int[] cur = pq.poll();
    if (cur[1] > dist[cur[0]]) continue;   // 惰性删除
    for (int[] e : graph.get(cur[0])) {
        if (dist[cur[0]] + e[1] < dist[e[0]]) {
            dist[e[0]] = dist[cur[0]] + e[1];
            pq.offer(new int[]{e[0], dist[e[0]]});
        }
    }
}
```

### 5.2 拓扑排序

```
DAG 的线性化：每个顶点在其后继之前
  Kahn 算法：入度 0 的顶点入队，逐层移除
  或 DFS 完成序逆序

工程应用：任务调度、编译依赖、包管理、课程安排
  判环：拓扑排序完的顶点数 < n ⟹ 有环（依赖死锁检测！）
```

> 💡 依赖冲突检测 = 环检测：Maven 循环依赖、任务 DAG 死锁、微服务调用环——全部归约为"拓扑排序能否完成"。

## 6. 平面图与着色

### 6.1 平面图

```
可画在平面上且边不相交的图
欧拉公式：V − E + F = 2（顶点−边+面 = 2）
  推论：K₅（5 完全图）与 K₃,₃ 非平面 —— 平面性判定标准

工程：PCB 布线（单层电路）、地图绘制、图的可视化布局
```

### 6.2 图着色

```
顶点着色：相邻顶点不同色，最少色数 = 色数 χ(G)
  定理：平面图 χ ≤ 4（四色定理，1976 计算机辅助证明首例！）
  判定 3 色是否可行 = NPC

工程应用：
  寄存器分配（图着色分配器！见 寄存器/07 模块）
  考试排期（冲突图着色）
  无线频率分配（相邻基站不同频）
```

> 🎯 跨模块呼应：编译器的寄存器分配正是图着色——**变量冲突图着色 K 色**。数学课上"四色定理"在工程里的真身是"寄存器够不够用"。

## 7. 图论的应用：知识图谱与 RAG

### 7.1 知识图谱 = 图的工程化

```
知识图谱：三元组 (头实体, 关系, 尾实体) = 有向带标签图
  (北京, 首都, 中国)；张坤, 治疗, 肺结咳(示例)
  存储：图数据库（Neo4j）或 RDF 三元组表

2025 状态：知识图谱 + LLM 的 RAG 组合成为可信检索主流
  GraphRAG：先建图 → 社区检测 → 社区摘要 → 增强检索
```

### 7.2 图算法在 RAG/AI 的直接应用（2025 检索）

| 图算法 | AI 场景 |
|--------|---------|
| BFS/DFS | 知识图谱多跳检索（"A 的关联实体"） |
| 最短路径（Dijkstra/Floyd） | 概念间推理链的最优路径 |
| 社区检测（Louvain） | GraphRAG 的社区摘要（实体聚类） |
| PageRank/图嵌入 | 实体重要性排序、链接预测 |
| 环检测 | 防止 LLM 生成重复循环的推理链 |
| 生成树 | 检索结果的去冗余骨架 |

```
2025 论文共识（知识图谱增强 LLM）：
  检索不再只是"向量相似度"，而是"图上行走"：
  起点实体 → 图遍历候选 → 子图构建 → 拼入上下文
  —— 图论从算法课走进 RAG 生产管线
```

### 7.3 图与 GNN

```
图神经网络：用消息传递（邻居特征聚合）学习图结构
  GCN：邻居特征加权求和
  2025：RDF 知识图谱 + GNN 推荐系统、链接预测成为标配

数学基础：GNN 的"邻居聚合" = 图上的卷积（谱图论）
  —— 离散图结构 × 连续神经网络的中介是图谱理论
```

> 🎯 **核心要点**：图论是"结构的数学"——遍历、最短路、树、着色分别对应工程中的搜索、路径优化、层级组织与资源分配。2025 年它又成为知识图谱 RAG 的骨架，从经典算法走向 AI 生产前线。
