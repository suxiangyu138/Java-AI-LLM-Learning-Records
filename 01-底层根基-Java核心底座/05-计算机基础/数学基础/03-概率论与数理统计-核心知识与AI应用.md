## 2. 概率基础

### 2.1 基本概念

| 概念 | 符号 | 定义 | 示例 |
|------|------|------|------|
| 样本空间 | Ω | 所有可能结果的集合 | 掷硬币：Ω = {H, T} |
| 事件 | A ⊆ Ω | 样本空间的子集 | "正面朝上" A = {H} |
| 概率 | P(A) | 事件发生的可能性，0 ≤ P(A) ≤ 1 | P(H) = 0.5 |
| 条件概率 | P(A\|B) | B 发生条件下 A 的概率 | — |
| 独立事件 | P(A∩B)=P(A)P(B) | A 和 B 互不影响 | 两次独立抛硬币 |

### 2.2 核心公式三条

```text
① 条件概率：     P(A|B) = P(A∩B) / P(B)
② 乘法公式：     P(A∩B) = P(A|B)·P(B) = P(B|A)·P(A)
③ 全概率公式：   P(A) = Σᵢ P(A|Bᵢ)·P(Bᵢ)     （Bᵢ 是 Ω 的一个划分）
```

### 2.3 全概率公式的应用场景

> 当直接求 P(A) 困难时，将 A 分解到互斥且穷尽的各个条件 Bᵢ 下分别计算。

## 3. 随机变量与分布

### 3.1 离散型 vs 连续型

| 属性 | 离散型随机变量 | 连续型随机变量 |
|------|--------------|--------------|
| 取值 | 有限或可数无限个 | 不可数无限个（区间） |
| 描述函数 | PMF（概率质量函数） | PDF（概率密度函数） |
| 概率计算 | `P(X=k) = p(k)` | `P(a≤X≤b) = ∫ₐᵇ f(x)dx` |
| 累积分布 | `F(x) = P(X≤x) = Σ p(k)` | `F(x) = ∫₋∞ˣ f(t)dt` |

### 3.2 常见离散分布

| 分布 | PMF | 参数 | 典型场景 | AI 应用 |
|------|-----|------|---------|---------|
| **伯努利** | `P(X=1)=p` | p | 硬币、点击 | 二分类标签 |
| **二项** | `C(n,k)pᵏ(1-p)ⁿ⁻ᵏ` | n, p | n 次独立试验成功次数 | 模型准确率分布 |
| **泊松** | `λᵏe^{-λ}/k!` | λ | 单位时间到达次数 | 请求速率建模 |
| **多项** | 多类别版二项 | n, (p₁,...,pₖ) | k 个类别的计数 | **多分类采样** |
| **分类 (Categorical)** | `P(X=i)=pᵢ` | (p₁,...,pₖ) | 单次多类别 | **下一个 token 采样** |

### 3.3 常见连续分布

| 分布 | PDF | 参数 | 典型场景 | AI 应用 |
|------|-----|------|---------|---------|
| **均匀** | `f(x)=1/(b-a)` | a,b | 等可能性 | 随机采样 |
| **正态 (高斯)** | `f(x)=exp(-(x-μ)²/(2σ²))/(σ√(2π))` | μ,σ² | 自然现象 | **权重初始化、扩散噪声** |
| **指数** | `f(x)=λe^{-λx}` | λ | 等待时间 | 时间衰减 |
| **Gamma** | 复杂 | α,β | 贝叶斯先验 | 共轭先验 |
| **Beta** | 复杂 | α,β | (0,1) 上的分布 | Thompson 采样 |

### 3.4 正态分布：AI 中最核心的分布

```text
为什么正态分布无处不在？

中心极限定理：大量独立随机变量之和趋近正态分布
→ 现实中的很多数据近似正态（身高、测量误差...）

AI 中的关键应用：
  ① 权重初始化：Xavier/He 从 N(0, σ²) 采样权重
  ② 扩散模型：前向过程逐步添加 N(0, I) 噪声
  ③ VAE：编码器输出 μ, σ² → 隐变量 z ~ N(μ, σ²)
  ④ BatchNorm：强制每层激活值近似 N(0, 1)
  ⑤ LayerNorm：Transformer 中稳定训练的标配
```

## 4. 数字特征

### 4.1 期望、方差、协方差

| 特征 | 离散 | 连续 | 含义 |
|------|------|------|------|
| **期望 E[X]** | `Σ x·p(x)` | `∫ x·f(x)dx` | 随机变量的"中心" |
| **方差 Var(X)** | `E[(X-μ)²]` | `E[(X-μ)²]` | 随机变量的"离散程度" |
| **标准差 σ** | `√Var(X)` | `√Var(X)` | 与 X 同单位 |
| **协方差 Cov** | `E[(X-μₓ)(Y-μᵧ)]` | 同左 | X 和 Y 的共变关系 |

### 4.2 关键性质

```text
期望的线性性：    E[aX + bY] = aE[X] + bE[Y]       （永远成立，无论是否独立）
方差的传递：      Var(aX + b) = a²·Var(X)
独立时方差可加：  Var(X+Y) = Var(X) + Var(Y)        （仅当 X, Y 独立）
协方差公式：      Cov(X,Y) = E[XY] - E[X]E[Y]
相关系数：        ρ = Cov(X,Y) / (σₓ·σᵧ) ∈ [-1, 1]
```

### 4.3 常见分布的数字特征速查

| 分布 | E[X] | Var(X) |
|------|------|--------|
| 伯努利 B(p) | p | p(1-p) |
| 二项 B(n,p) | np | np(1-p) |
| 泊松 P(λ) | λ | λ |
| 均匀 U(a,b) | (a+b)/2 | (b-a)²/12 |
| 正态 N(μ,σ²) | μ | σ² |
| 指数 Exp(λ) | 1/λ | 1/λ² |

## 5. 贝叶斯定理

### 5.1 核心公式

```
P(H|E) = P(E|H) · P(H) / P(E)

术语：
  P(H)     = 先验概率（prior）     — 看到证据前的信念
  P(E|H)   = 似然（likelihood）    — 假设下证据出现的概率
  P(H|E)   = 后验概率（posterior） — 看到证据后更新的信念
  P(E)     = 边缘似然（evidence）  — 归一化因子 = Σ P(E|Hᵢ)P(Hᵢ)
```

### 5.2 经典直觉：疾病检测悖论

```text
已知：发病率 P(D)=0.01，灵敏度 P(+|D)=0.95，特异性 P(-|¬D)=0.90

问：检测为阳性，真正患病的概率？

P(D|+) = P(+|D)·P(D) / P(+)
       = 0.95×0.01 / (0.95×0.01 + 0.10×0.99)
       ≈ 0.0876 → 仅 8.76%！

直觉：即使准确的检测（95% 灵敏度），由于疾病非常罕见，
      阳性结果仍有超过 90% 的假阳性率。
```

### 5.3 朴素贝叶斯分类器

```
核心假设：给定类别下，所有特征条件独立

P(Cₖ | x₁,...,xₙ) ∝ P(Cₖ) · Πᵢ P(xᵢ | Cₖ)

优点：简单、快速、小数据表现好、可解释
缺点：特征独立假设在现实中往往不成立
应用：垃圾邮件过滤、文本分类、情感分析
```

### 5.4 贝叶斯深度学习思想

```
传统 DL：      学到一个确定的参数 θ* = argmin L(θ)
贝叶斯 DL：    学到参数的后验分布 P(θ|Data)

优势：
  ① 天然的不确定性量化（后验方差 = 置信度）
  ② 避免过拟合（先验 = 正则化）
  ③ 小样本下更鲁棒
```

## 6. 大数定律与中心极限定理

### 6.1 大数定律（LLN）

```
弱大数定律：
  X̄ₙ = (X₁+...+Xₙ)/n → E[X]  （依概率收敛）

含义：样本够多时，样本均值 → 总体均值

AI 含义：训练数据够多时，经验风险 → 期望风险
  → 经验风险最小化（ERM）的理论基础
```

### 6.2 中心极限定理（CLT）

```
(X̄ₙ - μ) / (σ/√n) → N(0, 1)  （分布收敛）

含义：无论总体分布是什么，样本均值的分布趋近正态

应用：
  ① A/B 测试：n≥30 即可用正态近似做假设检验
  ② 置信区间：X̄ ± z_{α/2}·σ/√n
  ③ BatchNorm 的理论依据：mini-batch 均值近似正态
```

## 7. 信息论基础

### 7.1 核心概念

| 概念 | 公式 | 直觉 |
|------|------|------|
| **自信息** | `I(x) = -log₂ P(x)` | 罕见事件含更多信息 |
| **熵 H(P)** | `H(P) = -Σ P(x)·log₂ P(x)` | 分布的不确定性（bit） |
| **交叉熵 H(P,Q)** | `H(P,Q) = -Σ P(x)·log₂ Q(x)` | 用 Q 编码 P 需要的 bit 数 |
| **KL 散度 Dₖₗ(P‖Q)** | `Dₖₗ = Σ P(x)·log(P(x)/Q(x))` | 用 Q 近似 P 损失的信息 |
| **困惑度 PPL** | `PPL = 2^{H(P,Q)}` | 模型"困惑"的程度（越低越好） |

### 7.2 交叉熵 = 深度学习损失函数

```
分类任务：
  P = 真实分布（one-hot）：P(正确类别)=1, P(其他)=0
  Q = 模型预测分布：Q(i) = softmax(logits)ᵢ

  H(P,Q) = -Σ P(i)·log Q(i) = -log Q(正确类别)
         = 交叉熵损失（Cross-Entropy Loss）

LLM 训练 = 对每个 token 位置的交叉熵求均值
```

### 7.3 KL 散度在 AI 中的关键应用

| 应用 | 怎么用 |
|------|--------|
| **VAE 损失** | `Loss = Reconstruction + β·KL( N(μ,σ²) ‖ N(0,I) )` |
| **知识蒸馏** | `Loss = CE(student, teacher) + T²·KL( softmax(teacher/T) ‖ softmax(student/T) )` |
| **RLHF** | `Loss = -reward + β·KL( π_θ ‖ π_ref )` 防止策略偏离太远 |
| **GAN** | 判别器最小化真实分布与生成分布的 JS 散度 |

## 8. 统计推断

### 8.1 最大似然估计（MLE）

```
问题：已知数据 {x₁,...,xₙ}，哪个参数 θ 最可能生成这些数据？

θ̂_MLE = argmax_θ Πᵢ f(xᵢ|θ)
       = argmax_θ Σᵢ log f(xᵢ|θ)     （取对数后求和，更易计算）

AI 关联：交叉熵损失 → 分类问题中的 MLE
        MSE 损失    → 假设高斯噪声下的 MLE
```

### 8.2 假设检验流程

```text
① 建立假设： H₀（原假设）vs H₁（备择假设）
② 选择检验统计量
③ 计算 p 值 = P(观测到当前或更极端结果 | H₀ 为真)
④ 决策：p < α（通常 0.05）→ 拒绝 H₀
```

### 8.3 两类错误

| | H₀ 为真 | H₀ 为假 |
|------|---------|---------|
| 拒绝 H₀ | **第一类错误 (α)** | ✅ 正确 |
| 不拒绝 H₀ | ✅ 正确 | **第二类错误 (β)** |

### 8.4 A/B 测试（后端高频场景）

```java
// 独立双样本比例 Z 检验
double zTest(double p1, int n1, double p2, int n2) {
    double pPool = (p1 * n1 + p2 * n2) / (n1 + n2);
    double se = Math.sqrt(pPool * (1 - pPool) * (1.0 / n1 + 1.0 / n2));
    return (p1 - p2) / se;  // |Z| > 1.96 → p < 0.05
}

// 应用：对比新旧推荐算法的点击率
// p1 = 0.15 (新算法 15% CTR, n1=10000)
// p2 = 0.12 (旧算法 12% CTR, n2=10000)
// Z ≈ 6.2 → p < 0.001 → 新算法显著更优
```

## 9. AI 大模型中的概率论

### 9.1 LLM 输出的本质：条件概率分布

```text
LLM 的生成过程：
  P(tokenₜ | token₁, token₂, ..., token_{t-1})

每个时间步，模型输出一个 |V| 维的概率向量（|V| = 词汇表大小，通常 32K-256K）

解码策略（temperature τ 控制分布的"尖锐程度"）：
  τ → 0   : 退化为 argmax → 确定性输出
  τ = 1   : 原始分布 → 有一定随机性
  τ → ∞   : 均匀分布 → 完全随机

核采样 (nucleus sampling / top-p)：
  只从累积概率 ≥ p 的 token 中采样，截断低概率长尾
```

### 9.2 扩散模型（Diffusion Model）的概率视角

```text
前向过程（q）：逐步加噪
  q(xₜ|x_{t-1}) = N(xₜ; √(1-βₜ)·x_{t-1}, βₜ·I)
  经过 T 步后：x_T ≈ N(0, I)

反向过程（p_θ）：学习去噪
  p_θ(x_{t-1}|xₜ) = N(x_{t-1}; μ_θ(xₜ,t), σₜ²·I)
  训练目标：最小化 KL( q(x_{t-1}|xₜ,x₀) ‖ p_θ(x_{t-1}|xₜ) )

翻译成人话：
  前向 = 慢慢把图片变成纯噪声（固定过程，不需要学）
  反向 = 学会从噪声中逐步恢复图片（用神经网络学去噪）
```

### 9.3 各类模型的概率对应

| 模型 | 概率基础 |
|------|----------|
| 逻辑回归 | 伯努利分布 + MLE |
| 朴素贝叶斯 | 贝叶斯定理 + 条件独立 |
| GMM（高斯混合模型） | 多个正态分布的组合 |
| VAE | 变分推断 + 高斯隐变量 + KL 散度 |
| Diffusion | 逐步加噪去噪 + 高斯转移核 |
| GAN | JS 散度 / Wasserstein 距离 |
| LLM | 链式条件概率 + 分类分布 |
| RLHF | 策略梯度 + KL 约束 |

```java
import org.apache.commons.math3.stat.inference.TTest;
import org.apache.commons.math3.distribution.NormalDistribution;

// 1. 描述性统计
DescriptiveStatistics stats = new DescriptiveStatistics();
double[] responseTimes = {120, 135, 118, 200, 145, 128, 132, 140};
for (double t : responseTimes) stats.addValue(t);

double mean   = stats.getMean();               // 均值
double std    = stats.getStandardDeviation();   // 标准差
double p95    = stats.getPercentile(95);        // P95

// 2. 置信区间（95%）
double z = 1.96;  // 正态分布 97.5% 分位数
double margin = z * std / Math.sqrt(stats.getN());
double ciLow  = mean - margin;
double ciHigh = mean + margin;

// 3. 正态分布
NormalDistribution normal = new NormalDistribution(0, 1);
double cdf = normal.cumulativeProbability(1.96);  // P(Z ≤ 1.96) ≈ 0.975
double pdf = normal.density(0);                    // N(0,0) 密度 = 0.399

// 4. t 检验（两组延迟是否有显著差异）
TTest tTest = new TTest();
double pValue = tTest.tTest(
    new double[]{120, 135, 118, 140, 130},
    new double[]{150, 160, 145, 155, 148}
);
// p < 0.05 → 两组存在显著差异
```

### 10.2 softmax 与采样实现

```java
import java.util.Random;

public class ProbabilityUtils {
    private static final Random rng = new Random();

    // softmax
    public static double[] softmax(double[] logits) {
        double[] probs = new double[logits.length];
        double max = Double.NEGATIVE_INFINITY;
        for (double x : logits) max = Math.max(max, x);  // 数值稳定

        double sum = 0;
        for (int i = 0; i < logits.length; i++) {
            probs[i] = Math.exp(logits[i] - max);
            sum += probs[i];
        }
        for (int i = 0; i < probs.length; i++) probs[i] /= sum;
        return probs;
    }

    // 温度采样
    public static double[] withTemperature(double[] logits, double tau) {
        double[] scaled = new double[logits.length];
        for (int i = 0; i < logits.length; i++) scaled[i] = logits[i] / tau;
        return softmax(scaled);
    }

    // 按概率分布的类别采样（Categorical Sampling）
    public static int sample(double[] probs) {
        double r = rng.nextDouble();
        double cumsum = 0;
        for (int i = 0; i < probs.length; i++) {
            cumsum += probs[i];
            if (r <= cumsum) return i;
        }
        return probs.length - 1;  // 浮点精度保护
    }

    // 核采样（top-p / nucleus sampling）
    public static int topPSample(double[] logits, double p) {
        // 1. softmax
        double[] probs = softmax(logits);
        // 2. 按概率降序排序
        int[] indices = IntStream.range(0, probs.length)
            .boxed().sorted((a,b) -> Double.compare(probs[b], probs[a]))
            .mapToInt(i -> i).toArray();
        // 3. 累积到 p 截断
        double cumsum = 0;
        int cut = 0;
        for (int i = 0; i < indices.length; i++) {
            cumsum += probs[indices[i]];
            cut = i;
            if (cumsum >= p) break;
        }
        // 4. 在截断集上重新归一化并采样
        double[] truncated = new double[cut + 1];
        double total = 0;
        for (int i = 0; i <= cut; i++) {
            truncated[i] = probs[indices[i]];
            total += truncated[i];
        }
        for (int i = 0; i <= cut; i++) truncated[i] /= total;
        return indices[sample(truncated)];
    }
}
```
