## 1. 课程定位与资源

### 1.1 为什么 AI/后端工程师需要优化理论

| 场景 | 优化理论对应 | 不学透的后果 |
|------|------------|-------------|
| **模型训练** | 无约束优化、SGD/Adam | 不会调参、训练不收敛 |

| **推荐系统** | 约束优化 | 无法平衡多目标 |

## 2. 优化问题的基本概念

### 2.1 标准形式

```
最小化问题：
  minimize  f(x)        ← 目标函数
  subject to:
    gᵢ(x) ≤ 0  (i=1,...,m)  ← 不等式约束
    hⱼ(x) = 0  (j=1,...,p)  ← 等式约束

其中 x ∈ Rⁿ 是决策变量（神经网络中 = 所有参数）
```

### 2.2 核心概念

| 概念 | 定义 | 说明 |
|------|------|------|
| **可行域** | 满足所有约束的 x 的集合 | 约束划定的搜索空间 |
| **全局最优** | `f(x*) ≤ f(x), ∀x` | 整个空间的最小值 |
| **局部最优** | `∃ε>0, f(x*) ≤ f(x), ∀‖x-x*‖<ε` | 邻域内的最小值 |
| **鞍点** | 某些方向是极小，某些方向是极大 | 高维深度学习的关键挑战 |
| **凸函数** | `f(λx+(1-λ)y) ≤ λf(x)+(1-λ)f(y)` | 局部最优 = 全局最优 |

### 2.3 最优性条件

```
一阶必要条件（光滑无约束）：
  ∇f(x*) = 0
  梯度为零 → 可能是极值点/鞍点

二阶充分条件：
  若 ∇f(x*) = 0 且 Hessian H(x*) 正定
  → x* 是严格局部极小值

约束优化的一阶条件（KKT 条件）：
  ∇f(x*) + Σ λᵢ∇gᵢ(x*) + Σ μⱼ∇hⱼ(x*) = 0
  λᵢ ≥ 0, λᵢ·gᵢ(x*) = 0（互补松弛）
  gᵢ(x*) ≤ 0, hⱼ(x*) = 0
```

## 3. 凸优化基础

### 3.1 凸集与凸函数

```
凸集：
  若 x, y ∈ C，则对任意 λ∈[0,1]，λx+(1-λ)y ∈ C
  直观：集合中任意两点的连线仍在集合内

凸函数：
  f(λx+(1-λ)y) ≤ λf(x)+(1-λ)f(y)
  直观：函数图像上任意两点的连线在图像上方

判别（二阶条件）：
  Hessian 矩阵 H(x) 半正定 → 函数是凸的
```

### 3.2 凸优化的"免费午餐"定理

```
凸优化问题中：
  局部最优 = 全局最优！
  任何满足 KKT 条件的点 = 全局最优！

→ 不需要担心"困在局部最优"的问题
→ 凸优化问题有成熟高效的求解算法
```

### 3.3 常见凸函数

| 函数 | 公式 | 凸性 | AI 中作为 |
|------|------|------|----------|
| MSE | `‖y-Xw‖²` | 严格凸 | 回归损失 |
| L1 正则 | `‖w‖₁` | 凸（非严格） | 稀疏正则 |
| L2 正则 | `‖w‖₂²` | 严格凸 | 权重衰减 |
| Huber | 分段二次+线性 | 凸 | 鲁棒回归 |
| Hinge | `max(0, 1-y·f(x))` | 凸 | SVM 损失 |
| 交叉熵 | `-log softmax` | 凸（logit 空间） | 分类损失 |

> 重要区分：神经网络的损失函数在前向输出 `f(x)` 上是凸的，但在参数 `θ` 上通常非凸（因为有非线性激活）。深度学习才需要非凸优化的技巧。

## 4. 梯度下降及其变体

### 4.1 基本梯度下降

```
梯度下降：    x_{t+1} = x_t - η·∇f(x_t)
随机梯度下降： x_{t+1} = x_t - η·g_t    （g_t 是无偏梯度估计）

每次迭代保证：E[f(x_{t+1})] < f(x_t)，只要 η 足够小
```

### 4.2 现代优化器对比

| 优化器 | 更新规则 | 特点 | 使用场景 |
|--------|---------|------|---------|
| **SGD** | `θ -= η·g` | 简单，噪声大 | 需要强正则化时 |
| **SGD+Momentum** | `v=βv-ηg; θ+=v` | 惯性加速 | CV 经典模型 |
| **NAG** | `v=βv-η∇f(θ+βv); θ+=v` | 提前看一步 | 凸问题加速 |
| **AdaGrad** | `θ -= η·g/√(Σg²)` | 自适应学习率 | 稀疏特征 |
| **RMSprop** | `θ -= η·g/√(β·v+(1-β)g²)` | 移动平均归一化 | RNN 训练 |
| **Adam** | 动量 + RMSprop + 偏差校正 | **最主流** | 大多数 DL 任务 |
| **AdamW** | Adam + 解耦权重衰减 | **LLM 训练标配** | GPT、Llama 等 |

### 4.3 Adam 的完整更新

```
m_t = β₁·m_{t-1} + (1-β₁)·g_t        (动量，一阶矩)
v_t = β₂·v_{t-1} + (1-β₂)·g_t²       (RMS，二阶矩)

m̂_t = m_t / (1-β₁^t)                   (偏差校正)
v̂_t = v_t / (1-β₂^t)

θ_t = θ_{t-1} - η·m̂_t / (√v̂_t + ε)
```

### 4.4 学习率调度

| 策略 | 公式 | 适用 |
|------|------|------|
| **阶梯** | 每 N 步 ×因子 | 简单粗暴 |
| **余弦退火** | `η_t = η_min + ½(η_max-η_min)(1+cos(π·t/T))` | **LLM 训练标配** |
| **线性预热** | 前 N 步从 0 线性增长到 η | 防止训练初期不稳定 |
| **Warmup + Cosine** | 线性预热 + 余弦衰减 | GPT 系列标准配置 |

## 5. 约束优化与拉格朗日乘子法

### 5.1 拉格朗日乘子法

```
问题：min f(x)  s.t. h(x) = 0

拉格朗日函数：L(x, λ) = f(x) + λ·h(x)

最优条件：∇_x L = 0, ∇_λ L = h(x) = 0

几何直觉：f 的梯度与约束曲面的法向量平行 → λ 衡量约束的"紧度"
```

### 5.2 KKT 条件（不等式约束）

```
问题：min f(x)  s.t. g(x) ≤ 0, h(x) = 0

KKT 条件（一阶必要条件）：
  ① ∇f(x*) + Σ μᵢ∇hᵢ(x*) + Σ λⱼ∇gⱼ(x*) = 0  （平稳性）
  ② hᵢ(x*) = 0                                   （原始可行性）
  ③ gⱼ(x*) ≤ 0                                   （原始可行性）
  ④ λⱼ ≥ 0                                       （对偶可行性）
  ⑤ λⱼ·gⱼ(x*) = 0                                （互补松弛条件）

若问题是凸的，KKT 条件是充要条件
```

### 5.3 AI 中的应用

```text
SVM（支持向量机）：
  min ½‖w‖²  s.t. yᵢ(wᵀxᵢ+b) ≥ 1
  → 拉格朗日对偶 → 仅依赖内积 → 核技巧

RLHF：
  max reward  s.t. KL(π||π_ref) ≤ ε
  → KL 约束防止策略偏离太大

公平性约束：
  min loss  s.t. 不同群体的准确率差 ≤ ε
  → 约束优化保证公平性
```

## 6. 线性规划

### 6.1 标准形式

```
minimize  cᵀx
subject to:
  Ax = b
  x ≥ 0

其中 c ∈ Rⁿ, A ∈ R^{m×n}, b ∈ Rᵐ
```

### 6.2 核心性质

```
可行域是多面体（凸集）
最优解一定在可行域的某个极点上取得（关键！）
→ 不需要检查内部点，只需遍历极点

单纯形法：
  从一个极点出发，沿边走到相邻的更优极点
  最坏 O(2ⁿ) 但实践中非常快
```

### 6.3 对偶性

```
原始问题 (P)：min cᵀx  s.t. Ax ≥ b, x ≥ 0
对偶问题 (D)：max bᵀy  s.t. Aᵀy ≤ c, y ≥ 0

弱对偶：cᵀx ≥ bᵀy（对偶提供了原始的下界）
强对偶（一定条件下）：min P = max D

对偶的价值：
  ① 提供最优性证明（gap=0 → 已最优）
  ② 有时对偶问题更容易求解
  ③ 影子价格（对偶变量 y = 约束的边际价值）
```

## 7. 整数规划与组合优化

### 7.1 问题类型

| 问题 | 典型应用 | 难度 |
|------|---------|------|
| 0-1 背包 | 资源分配、预算规划 | NP-complete（动态规划可解） |
| 旅行商 (TSP) | 物流路径规划 | NP-hard |
| 集合覆盖 | 选址问题 | NP-complete |
| 指派问题 | 任务分配 | 多项式（匈牙利算法） |
| 装箱问题 | 容器调度 | NP-hard |

### 7.2 求解策略

```text
精确算法（小规模）：
  分支定界 (Branch & Bound)
  割平面法
  动态规划

近似算法（大规模）：
  贪心算法（有近似保证）
  元启发式：遗传算法、模拟退火、蚁群优化

对 AI 的意义：
  Neural Architecture Search (NAS) → 组合优化
  模型编译的算子融合 → 图划分优化
```

## 8. 优化在 AI 中的核心应用

### 8.1 深度学习训练的理解层次

```text
层次 1（API 调用者）：  optimizer.step()
层次 2（实践者）：      什么时候用 Adam？什么时候用 SGD？warmup？
层次 3（研究者）：      Adam 的收敛性证明？如何设计新优化器？

目标层次：至少到层次 2（调参能力），理想层次 3（改进算法）
```

### 8.2 损失函数的优化视角

| 损失函数 | 凸性 | 光滑性 | 数值问题 |
|----------|------|--------|---------|
| MSE | 强凸 | Lipschitz 梯度 | 对异常值敏感 |
| MAE (L1) | 凸 | 不光滑（0 点） | 需次梯度方法 |
| Huber | 凸 | 光滑 | 综合 MSE 和 MAE 优点 |
| 交叉熵 | 凸（logit 空间） | 光滑 | 配合 softmax 梯度极简 |

### 8.3 模型压缩中的优化

```
量化感知训练（QAT）：
  min E[loss(f_Q(x; θ_Q), y)]  s.t. θ_Q ∈ 有限集合（如 INT8）

→ 本质上是一个约束优化问题
→ 用直通估计器 (STE) 近似梯度

剪枝：
  min loss(θ)  s.t. ‖θ‖₀ ≤ K（至多 K 个非零参数）

→ L0 约束 → NP-hard
→ 用 L1 正则化松弛 → 凸近似 → 软阈值/迭代剪枝
```

### 8.4 超参优化

| 方法 | 原理 | 特点 |
|------|------|------|
| **网格搜索** | 穷举离散组合 | 维度灾难 |
| **随机搜索** | 随机采样 | 比网格搜索好 |
| **贝叶斯优化** | 高斯过程代理模型 | **最有效的通用方法** |
| **Hyperband** | 早停 + 资源分配 | 适合大规模超参 |

## 9. Java 实现

### 9.1 梯度下降框架

```java
import java.util.function.Function;

public class Optimizers {

    // SGD with Momentum
    public static double[] sgdMomentum(
            Function<double[], double[]> gradFn,  // 梯度函数
            double[] params, double lr, double momentum, int epochs) {

        double[] velocity = new double[params.length];

        for (int epoch = 0; epoch < epochs; epoch++) {
            double[] grad = gradFn.apply(params);
            for (int i = 0; i < params.length; i++) {
                velocity[i] = momentum * velocity[i] - lr * grad[i];
                params[i] += velocity[i];
            }
        }
        return params;
    }

    // Adam
    public static double[] adam(
            Function<double[], double[]> gradFn,
            double[] params, double lr, int epochs,
            double beta1, double beta2, double eps) {

        double[] m = new double[params.length]; // 一阶矩
        double[] v = new double[params.length]; // 二阶矩

        for (int t = 1; t <= epochs; t++) {
            double[] grad = gradFn.apply(params);
            for (int i = 0; i < params.length; i++) {
                m[i] = beta1 * m[i] + (1 - beta1) * grad[i];
                v[i] = beta2 * v[i] + (1 - beta2) * grad[i] * grad[i];

                double mHat = m[i] / (1 - Math.pow(beta1, t));
                double vHat = v[i] / (1 - Math.pow(beta2, t));

                params[i] -= lr * mHat / (Math.sqrt(vHat) + eps);
            }
        }
        return params;
    }
}
```

### 9.2 线性规划（Apache Commons Math）

```java
import org.apache.commons.math3.optim.*;
import org.apache.commons.math3.optim.linear.*;
import org.apache.commons.math3.optim.nonlinear.scalar.GoalType;

// 问题：min 3x + 5y  s.t. 2x + 8y ≥ 10, x,y ≥ 0
LinearObjectiveFunction f = new LinearObjectiveFunction(
    new double[]{3, 5}, 0
);

ArrayList<LinearConstraint> constraints = new ArrayList<>();
constraints.add(new LinearConstraint(
    new double[]{2, 8}, Relationship.GEQ, 10
));
constraints.add(new LinearConstraint(
    new double[]{1, 0}, Relationship.GEQ, 0
));
constraints.add(new LinearConstraint(
    new double[]{0, 1}, Relationship.GEQ, 0
));

SimplexSolver solver = new SimplexSolver();
PointValuePair solution = solver.optimize(
    new LinearConstraintSet(constraints),
    f,
    GoalType.MINIMIZE,
    new NonNegativeConstraint(true)
);
// solution.getPoint() → 最优 x, y
```

## 关键公式速记卡

| 公式 | 用途 |
|------|------|
| `x_{t+1} = x_t - η·∇f(x_t)` | 梯度下降 |
