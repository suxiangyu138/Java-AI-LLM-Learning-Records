## 1. 从香农到语义：范式的转换

### 1.1 香农三层问题

```text
香农（1948）把通信问题分为三个层次：
  ① 技术层：符号如何精确传输（香农信息论解决）
  ② 语义层：传输的符号如何传达含义（未被形式化）
  ③ 效用层：接收到的含义如何影响行为/任务（未被形式化）

香农理论只回答第 ① 层 —— 70 多年里工程止步于此
2020s 转折：任务导向通信（自动驾驶/AR/无人机）要求"只传有用的"
  → 第 ②③ 层的理论化成为 6G 研究核心
```

### 1.2 为什么现在才转向语义

| 驱动 | 说明 |
|------|------|
| 6G 场景需求 | xURLLC（超高可靠低延迟）不允许传无用冗余 |
| 深度学习成熟 | 语义特征可自动学习（端到端） |
| 算力进步 | 编码/解码端的神经网络推理可行 |
| 带宽瓶颈 | 频谱有限 → 必须在"语义压缩"上找空间 |

> 🎯 核心认知：香农理论说"传比特最多能多快"；语义通信问"传含义最少需要多少比特"——后者是前者的"压缩革命"。

## 2. 语义信息论：同义性与语义熵

### 2.1 张平团队的语义信息论（2023-2025）

```text
核心概念：同义性（Synonymity）——同一语义可由多个语法形式表达
  例："今天天气不错"与"今天天气挺好"——不同语法、相同语义
  → 语义编码只需传"同义类"而非逐字

定义的度量体系：
  语义熵（Semantic Entropy）：语义层面的平均不确定性
  语义互信息、语义信道容量、语义率失真函数

三条核心定理（与香农对应）：
  ① 语义无损信源编码定理（语义熵 = 语义压缩下限）
  ② 语义信道编码定理
  ③ 语义率失真编码定理
```

### 2.2 关键结果：语义熵 ≤ 香农熵

```text
定理：语义熵 ≤ 香农熵，等号当且仅当每个同义类只有一个元素
  → 传语义永远比传比特高效（或持平）
  → 经典香农理论是语义理论的特例（同义类退化时）

工程推论：语义压缩的增益 = 语言冗余 + 任务冗余的合并
  例：一张图传"猫在沙发上"（语义）vs 传全部像素（比特）
  语义路径可省 100-1000 倍比特（任务相关场景）
```

### 2.3 与香农理论的对照表

| 维度 | 香农信息论 | 语义信息论 |
|------|-----------|-----------|
| 对象 | 符号/比特 | 语义（同义类） |
| 基本量 | 熵 H(X) | 语义熵 H_s(X) |
| 压缩极限 | H ≤ 码率 | H_s ≤ 码率 |
| 关键关系 | 语法等价类 | 语义等价类（同义） |
| 编码单位 | bit | Seb（语义基） |
| 适用 | 通用传输 | 任务导向/人机通信 |

## 3. 联合信源信道编码（JSCC）

### 3.1 分离定理 vs 联合设计

```text
经典框架（分离定理，03 模块）：先压缩后纠错，渐进最优
  前提：码长足够长 + 统计特性已知

现实问题：
  ① 短码/低延迟（URLLC）时分离不是最优
  ② 无线信道时变（统计未知）→ 静态编码失配
  ③ 任务导向：只需传"任务相关"信息，不必重建源

JSCC 路线：端到端联合学习编码（深度神经网络）
  编码器：源 → 特征 → 信道符号（直出）
  解码器：信道符号 → 任务结果（不重建原始）
```

### 3.2 深度 JSCC（DJSCC）的 2025 状态

| 方向 | 进展（2025 检索） |
|------|------------------|
| 鲁棒 DJSCC | KL 正则化训练：噪声信道下后验与无噪后验对齐（Globecom 2025） |
| 多任务语义通信 | CMT-SemCom：公共编码单元 + 任务专属单元共享 |
| 生成式 JSCC | 稳定扩散 + 熵模型神经压缩（带宽压缩比高且抗噪） |
| 感知任务 | 自动驾驶/AR 的 xURLLC 语义传输 |

```text
DJSCC 的优势：
  无需精确信道统计（端到端训练隐含适配）
  语义压缩（跳过冗余重建）
  联合优化（不再受分离定理的短码损失）

挑战：标准化缺失、可扩展性、跨场景泛化
```

## 4. KL 散度在新通信系统中的角色

### 4.1 三个 2025 应用场景

| 场景 | KL 角色 |
|------|---------|
| 速率受限语义编码 | 码率约束建模为 KL（密度比技巧 + 隐式最优先验） |
| 鲁棒 JSCC 训练 | KL(噪声后验‖无噪后验) 作为正则损失（Fisher 信息近似） |
| 信道模拟/联邦学习 | 迭代减小 P 与 Q 的 KL → 通信量降 37%（联邦学习） |

### 4.2 LLM 采样通信的 16× 压缩

```text
2025 研究（信道模拟方向）：
  传统：把 LLM 采样出的样本按熵编码传输
  新法：直接传"分布 Q"，接收端重采样（信道模拟）
  → 与目标分布 P 的 KL 逐步降低
  → 相比熵编码压缩，传输 LLM 样本的比特数降低 16 倍

启示：通信从"传数据"变成"传分布"——KL 是分布级通信的度量
```

## 5. ComAI：6G 原生智能

### 5.1 张平团队提出的 ComAI 范式

```text
ComAI（Communication + AI）：通信与 AI 深度融合的空口设计
  核心：发射端与接收端共享"语义知识库"
  → 只需传"语义增量"，知识库部分不重复传输

技术组件：
  Seb（语义基）：语义的最小表示单元（类比比特）
  SVI（同义变分推断）：语义特征的变分推断
  NTSCC：非线性变换信源信道联合编码（含熵模型变速率）
  MDMA（模型分多址）：按模型/语义区分接入
  SDD（语义全双工）：语义层面同时收发

状态：部分方案已进入 3GPP 6G 标准化讨论
```

### 5.2 语义知识库的工程本质

```text
知识库 = 共享先验（收发端都有的"字典"）
  类比：没有字典的对话（逐字传）vs 有字典的对话（传索引）

信息论视角：知识库把"熵"从传输侧移到共享侧
  传输的比特 = 语义索引（远小于原始内容）
  —— 这正是"语义熵 ≤ 香农熵"的工程化

挑战：知识库的更新同步、多用户一致性、安全（知识库泄漏）
```

## 6. LLM 与编码的融合

### 6.1 GenAI 参与信源/信道编码（2025）

```text
研究趋势（B5G/6G 联合源信道编码）：
  ① 生成式信源编码：用生成模型重建（传语义描述，本地生成）
  ② LLM 驱动的 JSCC：语义理解参与编码决策
  ③ 条件生成：接收端用上下文生成缺失内容（智能丢包补偿）

示例：图像传输 → 传"语义提示词" → 接收端 Stable Diffusion 重建
  带宽压缩比大幅提升，对信道噪声鲁棒

局限：生成内容与真实内容的保真度差异（任务相关性决定可行性）
```

### 6.2 语义噪声与安全

```text
语义噪声：信道噪声导致"语义漂移"（传"猫"收到"狗"）
  语法错可能不大但语义全错 —— 语义层的纠错需求

语义安全：语义信道被劫持/注入的威胁模型
  → 语义认证、语义加密成为 6G 安全研究新课题
```
