## 1. 自信息：单个事件的度量

### 1.1 信息量的直觉

信息量应当满足三条直觉公理：

| 公理 | 含义 |
|------|------|
| 单调性 | 概率越小的事件，发生带来的信息越大 |
| 可加性 | 独立事件同时发生的信息 = 各自信息之和 |
| 非负性 | 信息量不为负 |

**定义**：事件 x（概率 p(x)）的**自信息**为：

I(x) = −log₂ p(x)（单位：比特 bit）

```text
验证公理：
  单调性：p = 1/2 → I = 1 bit；p = 1/8 → I = 3 bit ✓
  可加性：独立事件 p(xy) = p(x)p(y) →
    I(xy) = −log p(x)p(y) = −log p(x) − log p(y) = I(x) + I(y) ✓
  唯一性：香农证明满足三公理的函数必为对数形式（常数倍）∎

直觉对照：抛硬币（1/2）结果的信息 = 1 bit（一个 yes/no 问题）
  掷骰子（1/6）：log₂6 ≈ 2.58 bit
```

> 🎯 核心认知：**信息 = 不确定性的消除**——越不可能的事件，一旦发生越"值钱"。对数底数决定单位：log₂ 用 bit，ln 用 nat，log₁₀ 用 Hartley。

## 2. 熵：平均自信息

### 2.1 定义

随机变量 X 的**熵**（entropy）是其自信息的期望：

H(X) = −Σ p(x)·log p(x)

```text
示例：公平硬币
  H = −(1/2·log(1/2) + 1/2·log(1/2)) = 1 bit

示例：有偏硬币 p(正) = 0.9
  H = −(0.9·log 0.9 + 0.1·log 0.1) ≈ 0.469 bit
  → 结果更可预测，信息更少 ✓
```

### 2.2 熵的解读

| 视角 | 解读 |
|------|------|
| 平均信息量 | 观察 X 平均获得的信息 |
| 不确定性 | X 的剩余不确定性（先验） |
| 压缩极限 | 无损压缩 X 的最小编码长度（信源编码定理，04 模块） |
| 问题数 | 平均需要多少个 yes/no 问题确定 X 的值 |

> 💡 三种解读对应三个应用领域：**信息量（通信）、不确定性（统计/AI）、压缩极限（编码）**——同一个数学对象，三副面孔。

### 2.3 二元熵函数

对只有两个结果（p, 1−p）的变量：H(p) = −p·log p − (1−p)·log(1−p)。

```text
H(p) 的图像要点：
  p = 0 或 1 → H = 0（确定事件，零信息）
  p = 1/2 → H = 1（最大不确定性，1 bit）
  曲线对称于 p = 1/2
```

## 3. 联合熵与条件熵

### 3.1 联合熵

H(X, Y) = −ΣΣ p(x,y)·log p(x,y)

两变量的联合不确定性。**链式法则**：

H(X, Y) = H(X) + H(Y | X)

```text
含义：联合不确定性 = X 的不确定性 + 已知 X 后 Y 的剩余不确定性
推广：H(X₁…Xₙ) = Σ H(Xᵢ | X₁…Xᵢ₋₁)（条件链式法则）
```

### 3.2 条件熵

H(Y | X) = Σ p(x)·H(Y | X = x)

已知 X 后 Y 的**平均剩余不确定性**。

| 关系 | 含义 |
|------|------|
| H(Y\|X) < H(Y) | X 提供了 Y 的信息（一般情形） |
| H(Y\|X) = H(Y) | X、Y 独立（无信息） |
| H(Y\|X) = 0 | Y 完全由 X 决定（确定性关系） |

```text
示例：X = 今天是否下雨，Y = 是否带伞
  H(Y) = 1 bit（带不带伞各半）
  若 H(Y|X) = 0.2 bit → 知道天气后不确定性大减
  减少量 0.8 bit = 互信息（02 模块的主角）
```

## 4. 熵的性质

| 性质 | 内容 |
|------|------|
| 非负性 | H(X) ≥ 0（等号当且仅当 X 确定） |
| 有界性 | H(X) ≤ log|χ|（|χ| 为取值数），均匀分布取等号 |
| 均匀分布最大 | 熵度量"分散程度"——最均匀 = 最不确定 |
| 凹性 | H 是 p 的凹函数（混合分布熵更大） |
| 条件熵单调 | H(Y\|X) ≤ H(Y)；H(X,Y) ≥ H(X)（信息不减） |
| 独立分解 | X、Y 独立时 H(X,Y) = H(X) + H(Y) |

> 🎯 **最大熵原理**（工程高频）：均匀分布熵最大 → 在没有额外约束时，熵最大的分布是最"诚实"的假设——这就是最大熵模型（逻辑回归的起源）、LSTM/Transformer 训练里"均匀先验"的理论依据。

## 5. 熵的计算示例

### 5.1 手算练习

```text
问题：信源发出 4 个符号，概率 {1/2, 1/4, 1/8, 1/8}
  H = −(1/2·1 + 1/4·2 + 1/8·3 + 1/8·3)
    = 0.5 + 0.5 + 0.375 + 0.375 = 1.75 bit

验证直觉：若 4 符号均匀（各 1/4），H = 2 bit
  非均匀（1.75）< 均匀（2）—— 熵最小化正是压缩的目标 ✓
```

### 5.2 Java 实现熵计算

```java
// 计算一个字符串的香农熵（信息论入门实现）
double entropy(String s) {
    Map<Character, Long> freq = new HashMap<>();
    for (char c : s.toCharArray())
        freq.merge(c, 1L, Long::sum);
    double h = 0;
    for (long f : freq.values()) {
        double p = (double) f / s.length();
        h -= p * (Math.log(p) / Math.log(2));
    }
    return h;
}
// 英文文本熵约 4-5 bit/字符；均匀随机串熵 = 8 bit/字节
```

### 5.3 熵与压缩的直觉对照

| 数据 | 熵（bit/字节） | 说明 |
|------|:---:|------|
| 全零文件 | 0 | 完全可预测 → 压到极小 |
| 英文文本 | ~4-5 | 强冗余 → gzip 可压 3-4 倍 |
| 已压缩文件 | ~8 | 熵已最大化 → 再压无效 |
| 加密数据 | ~8 | 伪随机 → 压缩无用（先压后加密的顺序原因！） |

## 6. 熵的工程形态

| 场景 | 熵的角色 |
|------|---------|
| 数据压缩 | 压缩比上限 = 数据的熵（Huffman/gzip 逼近） |
| 随机性检测 | 熵不足 = 弱随机（密码学强随机源检测） |
| 决策树 | 信息增益 = 熵的减少（ID3/C4.5 算法核心） |
| 特征选择 | 互信息排序（02 模块） |
| 异常检测 | 低概率事件 = 高自信息 = 异常信号 |
| LLM 困惑度 | perplexity = 2^H（每 token 平均不确定性，07 模块） |

> 🎯 **核心要点**：熵是"不确定性的货币"——压缩按熵付费、决策树按熵选特征、LLM 按熵评估困惑度。掌握熵的三种解读（信息/不确定性/压缩极限）与两条性质（均匀最大、条件不减），信息论的其余部分都是它的展开。

## 7. 小结

| 问题 | 答案 |
|------|------|
| 自信息为什么是对数？ | 三公理（单调/可加/非负）唯一决定对数形式 |
| 熵是什么？ | 平均自信息 = 不确定性 = 压缩极限 |
| 均匀分布熵最大？ | 最分散 = 最不确定（最大熵原理） |
| 条件熵含义？ | 已知 X 后 Y 的剩余不确定性 |
| 链式法则？ | H(X,Y) = H(X) + H(Y\|X) |
| 工程对应？ | 压缩上限、随机检测、决策树信息增益、LLM 困惑度 |
