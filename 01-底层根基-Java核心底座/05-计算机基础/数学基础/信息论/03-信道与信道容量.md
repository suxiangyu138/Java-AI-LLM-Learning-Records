## 1. 信道模型

### 1.1 什么是信道

**信道**是"输入到输出的随机映射"：输入 X，输出 Y，由条件分布 p(y|x) 描述（含噪声）。

```text
信道三要素：输入字母表、输出字母表、转移概率矩阵

示例（二元对称信道 BSC）：
  输入 {0, 1}，输出 {0, 1}
  P(输出 = 输入) = 1 − ε（正确）
  P(输出 ≠ 输入) = ε（翻转）
  转移矩阵：[1−ε  ε; ε  1−ε]
```

### 1.2 典型信道家族

| 信道 | 描述 | 参数 | 工程场景 |
|------|------|------|---------|
| 无噪信道 | 输出 = 输入 | 无 | 理想化模型 |
| **BSC**（二元对称） | 比特翻转概率 ε | ε | 数字通信教学基准 |
| **BEC**（二元删除） | 比特丢失（？）概率 ε | ε | 丢包网络、5G 设计 |
| 高斯信道 | 加性高斯噪声 | SNR | 无线/有线真实信道 |
| 记忆信道 | 输出依赖历史 | 状态 | 衰落信道、磁盘 |

```text
BEC 示例：输入 {0,1}，输出 {0, 1, ?}
  P(? | 0) = P(? | 1) = ε（比特被删除）
  网络丢包正是"删除"——BEC 是互联网的天然模型
```

## 2. 信道容量：定义

### 2.1 定义

**信道容量** C = max_{p(x)} I(X; Y)

在所有输入分布中，最大化输入输出互信息——**信道能可靠传输的最大速率（bit/信道使用）**。

```text
直觉：容量 = 信道"能塞进多少信息"的天花板
  无噪信道：C = log|X|（输入字母表全用）
  完全噪声信道（Y 与 X 独立）：C = 0（传不了任何信息）
```

### 2.2 容量的两个层面

| 层面 | 含义 |
|------|------|
| 数学定义 | 最大化互信息（优化问题） |
| 工程意义 | 低于 C 的速率存在可靠编码；高于 C 一定失败（香农定理） |

> 🎯 关键认知：容量不是"测出来的速率"，而是"存在性定理"——它宣告可靠通信的可行性边界，但不告诉你编码方法（信道编码定理的工程实践见 05 模块）。

## 3. 三类典型信道的容量

### 3.1 BSC 的容量

C = 1 − H(ε) = 1 + ε·log ε + (1−ε)·log(1−ε)

```text
数值直觉：
  ε = 0（无噪）→ C = 1 bit/使用
  ε = 0.1 → C ≈ 0.53 bit/使用
  ε = 0.5（全噪）→ C = 0

含义：10% 的比特翻转信道，每用一次只能可靠传 0.53 bit
  —— 需要大量冗余编码（05 模块）
```

### 3.2 BEC 的容量

C = 1 − ε

```text
直觉：ε 比例的比特被删除 → 剩下 1−ε 可传
  ε = 0.1 → C = 0.9 bit/使用（比 BSC 同 ε 高得多！）

对比启示：删除（知道哪里错了）比翻转（不知道哪里错了）好修
  —— 这解释了为什么网络协议优先检测并丢弃坏包
```

### 3.3 高斯信道的容量（香农公式）

C = ½·log₂(1 + P/N) bit/信道使用（P 信号功率，N 噪声功率）

工程常用的带宽形式：

C = B·log₂(1 + S/N) bit/s（B 为带宽，S/N 为信噪比）

```text
带宽-功率互换：带宽增加 → 容量线性增长（但噪声也随带宽变大）
  极限：B → ∞ 时 C → 1.44·P/N₀（功率决定极限，带宽不无限买容量）

数字直觉（信噪比）：
  S/N = 30 dB（1000 倍）→ C/B = log₂(1+1000) ≈ 9.97 bit/s/Hz
  S/N = 10 dB（10 倍）→ C/B ≈ 3.46 bit/s/Hz
```

## 4. 香农公式

### 4.1 公式（1948）

C = B·log₂(1 + S/N)

| 变量 | 含义 | 工程对应 |
|------|------|---------|
| C | 信道容量（bit/s） | 理论速率上限 |
| B | 带宽（Hz） | 频谱资源 |
| S | 信号功率 | 发射功率 |
| N | 噪声功率 | 干扰与底噪 |

### 4.2 公式的三条推论（工程界圣经）

| 推论 | 内容 | 影响 |
|------|------|------|
| 容量上限 | 任何技术无法超过 C | 衡量 4G/5G/6G 的"达成率" |
| 带宽换功率 | 降低 S 可用加大 B 弥补 | 扩频通信、CDMA |
| 功率换带宽 | 编码增益可等效降低功率 | 信道编码（LDPC/极化码） |

```text
现代应用：5G 实测速率 vs 香农上限
  （编码技术已把信道编码做到离容量 0.1 dB 以内——
   这是"编码接近极限"的工程里程碑）
```

## 5. 香农定理与分离定理

### 5.1 信道编码定理

**定理**：对容量为 C 的信道，任何速率 R < C 的传输都存在编码使错误率任意小；R > C 时任何编码的错误率都远离 0。

```text
意义：
  ① 噪声并不可怕——冗余编码可无限逼近无错（不是"几乎"而是任意小）
  ② 速率超过容量 = 物理不可能（不信则测试协议超载）
  ③ 存在性 vs 构造性：定理不告诉你码怎么构造
     —— 从 1948 到 1993（Turbo 码）到 2009（极化码），
       工程用了 60 年才真正逼近这个极限
```

### 5.2 信源-信道分离定理

**定理**：信源编码（压缩）与信道编码（纠错）可以独立最优设计——先压到熵，再以低于容量的速率传输。

```text
工程意义：
  ① "先压缩后加冗余"的顺序是正确的（Zip 后加纠错，而不是反过来）
  ② 模块化设计合法：压缩器与纠错器可独立优化
  ③ 例外（2025 前沿）：联合信源信道编码（JSCC）在
     语义通信/端到端学习中的复兴 —— 见 08 模块
```

> ⚠️ 重要注记：分离定理是"渐进最优"（码长无限时）；实际系统中码长有限，联合设计（JSCC）在短码与语义场景反而更优——这是 2025 年语义通信研究的重要动机。

## 6. 工程推论

| 场景 | 香农框架的角色 |
|------|----------------|
| 网络带宽规划 | 容量公式估算链路极限（10G 光模块 vs 物理上限） |
| 无线系统设计 | 调制阶数选择（QPSK/16QAM 按 SNR 选） |
| 编码增益预算 | LDPC/极化码的 dB 收益直接换算速率/覆盖 |
| 存储系统 | 磁盘/SSD 的信道模型（RLL 码、LDPC 固件） |
| 加密与压缩顺序 | 先压后加密（熵已满的密文无法再压） |
| 速率匹配 | 5G 的 AMC（自适应调制编码）实时逼近容量 |

### 编码增益的直观概念

```text
无编码传输：误码率 10⁻³ 需要 S/N = X dB
加 LDPC 后：同样误码率只需 S/N = X − 3 dB
  → 编码增益 3 dB：等效发射功率翻倍、覆盖距离 ×√2
  → 这就是"编码是无线系统的免费功率"的由来
```

> 🎯 **核心要点**：信道容量是"噪声世界的物理定律"——香农公式给出一切传输系统的速度上限，分离定理给出系统设计的分层合法性。工程的全部努力（调制、编码、波束赋形）都是在逼近 C，而 2025 年的语义通信则尝试重新定义"要传什么"（08 模块）。
