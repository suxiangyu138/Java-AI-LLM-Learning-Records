## 1. 交叉熵：一切监督学习的损失

### 1.1 从最大似然到交叉熵

```text
监督学习（分类/语言模型）统一目标：
  最大化 log P(真实标签 | 输入) = 最小化交叉熵 H(P, Q)

推导链：
  最大似然 ⟺ 最小化 −Σ log q(yᵢ|xᵢ)（对数损失）
  ⟺ 最小化交叉熵（P = 经验分布，Q = 模型分布）
  ⟺ 最小化 KL(P‖Q)（H(P) 固定时等价）

结论：交叉熵损失 = 信息论的最优性 + 统计的似然性，同一件事
```

### 1.2 分类任务的标准形式

```java
// 交叉熵损失（PyTorch 语义，Java 工程可对照实现）
// loss = −Σ y_i · log(softmax(logits)_i)
double crossEntropy(double[] logits, int label) {
    // softmax 数值稳定：减去最大值再 exp
    double max = Arrays.stream(logits).max().orElse(0);
    double sum = 0;
    for (double v : logits) sum += Math.exp(v - max);
    return -(logits[label] - max - Math.log(sum));
}
```

### 1.3 为什么交叉熵优于均方误差（分类）

```text
MSE + sigmoid：梯度饱和（两侧梯度趋零 → 学习停滞）
交叉熵 + softmax：梯度 = 预测 − 真实（永不饱和，始终有推动力）
  ∂loss/∂z = q(y|x) − 1(y = 真实)  —— 干净、高效
信息论解释：分类输出是概率分布 → 用"分布距离"（KL/交叉熵）而非"数值距离"（MSE）
```

## 2. KL 散度：分布拟合与模型蒸馏

### 2.1 生成模型的统一目标

| 模型 | 目标函数中的 KL |
|------|----------------|
| VAE | ELBO 中的 KL(q(z\|x)‖p(z))（正则项） |
| GAN（理论） | JS/散度最小化（分布匹配） |
| 扩散模型 | 每步去噪的 KL 上界 |
| 模型蒸馏 | KL(教师‖学生)（软标签拟合） |

```text
统一视角：生成模型 = "让模型分布逼近数据分布"
  目标 = 最小化某种分布距离（KL 家族）
  区别只在：显式密度（VAE/扩散）vs 隐式采样（GAN）
```

### 2.2 知识蒸馏（LLM 时代的核心技巧）

```text
硬标签训练：学习 one-hot（信息量小——只告诉"对的"）
软标签蒸馏：学习教师分布的完整概率（信息量丰富）

蒸馏损失 = 交叉熵（硬标签）+ λ·KL(教师‖学生)（软标签）
  温度 T：softmax 除以 T 软化分布，放大"次优类别"的差异
  效果：学生模型用 1/10 参数达到接近教师的质量

工程（2025）：小模型蒸馏是边缘部署的标配路径
  （DeepSeek-R1 的蒸馏系列、Phi 系列均用 KL 蒸馏）
```

### 2.3 KL 在正则化中的角色

```text
RLHF 的 KL 惩罚：策略更新时约束与参考策略的距离
  reward = r(θ) − β·KL(πθ‖πref)
  防止"奖励黑客"（模型为了奖励牺牲语言质量）
  β 控制探索与稳定 —— 2025 年 RLHF/GRPO 的标准件
```

## 3. LLM 训练管线中的信息论

### 3.1 全流程盘点

| 阶段 | 信息论工具 | 角色 |
|------|-----------|------|
| Tokenizer 训练 | 熵/编码 | 词表切分使序列熵最小 |
| 预训练 | 交叉熵损失 | 预测下一个 token |
| 指令微调 | 交叉熵 | 同上（带模板） |
| RLHF/DPO | KL 惩罚项 | 约束策略漂移 |
| 蒸馏 | KL(教师‖学生) | 小模型压缩 |
| 评估 | 困惑度 2^H | 模型质量度量 |

### 3.2 困惑度（Perplexity）详解

```text
困惑度 = 2^H = 模型对每个 token 的"平均候选数"
  H = 2.5 → 困惑度 ≈ 5.66（模型认为平均 5.7 个候选）

数值对比（2025 量级）：
  英文分词后困惑度：小型模型 15-30，前沿大模型 5-10
  中文：通常更低（分词差异）

注意：困惑度 ≠ 下游质量
  低困惑度可能来自"记忆"而非"理解"（知识问答场景的已知偏差）
  → 评估必须结合任务基准（如 MMLU、RAG 评测）
```

### 3.3 Tokenizer 的熵视角

```text
BPE 分词：合并高频字节对直到词表预算
  信息论目标：让 token 序列的熵最低（每 token 信息量最大）
  → 同样参数量下"信息密度"更高
  → 跨语言词表平衡（中文分词 vs 英文）本质是熵分配问题
```

## 4. 互信息与表征学习

### 4.1 对比学习的 InfoNCE

```text
对比学习（SimCLR/CLIP 等）：最大化正样本对的一致性

InfoNCE 损失：
  L = −log[ exp(sim(zᵢ,zⱼ)/τ) / Σ exp(sim(zᵢ,zₖ)/τ) ]
  信息论解读：InfoNCE 是互信息 I(Z; X) 的下界估计
  （softmax 归一化 = 互信息的变分估计）

温度 τ 的作用：缩放分布锐度 → 控制"困难负样本"权重
  —— 超参数 τ 其实在调互信息估计的偏差-方差
```

### 4.2 互信息与特征选择

```text
特征选择：I(标签; 特征) 排序取前 k（非线性相关捕捉）
  对比皮尔逊相关：只测线性；互信息测任意依赖
  代价：连续变量的互信息估计需要分箱/核估计

工程：sklearn.mutual_info_classif、文本分类的卡方/互信息加权
```

### 4.3 自监督学习的信息论解释

```text
MAE/BERT 掩码重建 = 最大化"可见部分与掩码部分"的互信息
  对比方法 = 最大化增广视图间的互信息
  冗余最小化（Barlow Twins） = 最小化表征维度间的互信息

统一视角（2025 共识）：
  表征学习 = 保留任务相关互信息、丢弃冗余（信息瓶颈的具体化）
```

## 5. 信息瓶颈与压缩正则

### 5.1 信息瓶颈（IB）框架

```text
目标：max I(T; Y) − β·I(X; T)
  第一项：表征 T 保留标签信息（相关）
  第二项：压缩输入（去冗余、防过拟合）

洞察：
  泛化与压缩的关系（2020s 研究热点）：
  压缩越强 → 泛化越好（丢弃噪声细节）
  —— 与"奥卡姆剃刀"的信息论表述一致

争议与现状：IB 作为理论框架解释深度学习仍活跃
  （严格 IB 曲线在深度网络中的验证仍是开放问题）
```

### 5.2 信息论正则化工具

| 技术 | 信息论形式 |
|------|-----------|
| Dropout | 隐式降噪（去冗余） |
| 权重衰减 | 参数熵惩罚 |
| 量化感知训练 | 率失真权衡（码率 = 位宽） |
| 剪枝 | 信息量排序保留 |
| 熵正则（RL） | 策略熵惩罚（防坍缩） |

## 6. 扩散模型的信息论视角

### 6.1 扩散 = 分级率失真

```text
前向过程：逐步加噪（信息逐步丢失）
逆向过程：逐步去噪（逐步重建信息）

信息论解读：
  每步去噪 = 率失真框架的一级量化
  步数越多 → 每步失真越小 → 采样质量越高但更慢

2025 研究：率失真最优的步数分配、蒸馏步数压缩
  （把 50 步蒸馏到 1-4 步的本质 = 更激进的率失真权衡）
```

### 6.2 流匹配与连续熵

```text
流匹配（Flow Matching）/整流流（Rectified Flow）：
  用最优传输路径替代扩散的随机路径
  信息论：更短"信息路径"→ 更少步数 → 更快采样

SD3/FLUX 等 2025 模型已采用 —— 信息路径优化的工程胜利
```

> 🎯 **核心要点**：信息论是深度学习的"会计语言"——交叉熵记账损失、KL 记账拟合、互信息记账相关、率失真记账压缩。2025 年的 LLM 管线（预训练/RLHF/蒸馏/评估）每个环节都是信息论度量的直接应用；看不懂损失函数，往往是信息论视角缺位。

## 7. 工程落地清单

| 问题 | 信息论答案 |
|------|-----------|
| 分类损失选什么？ | 交叉熵（梯度不饱和 + 概率语义） |
| 蒸馏怎么做？ | 软标签 + KL（温度软化分布） |
| RLHF 怎么防漂移？ | KL 惩罚（β 权衡） |
| 模型好不好？ | 困惑度 2^H + 任务基准（双轨） |
| 特征怎么选？ | 互信息排序（非线性相关） |
| 表征怎么学？ | 对比互信息最大化（InfoNCE） |
| 压缩怎么省？ | 率失真权衡（量化/蒸馏/剪枝） |

> 🎯 **核心要点**：信息论给 AI 提供的是"最优性的语言"——每个学习目标都能翻译成"最小化/最大化某个信息量"；反过来，看不懂的损失函数也都能还原成信息论形式。掌握交叉熵 = H+KL、InfoNCE = 互信息下界、RLHF 惩罚 = KL 约束，就掌握了读懂 2025 年 AI 论文的主干语法。
