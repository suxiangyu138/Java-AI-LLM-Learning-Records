## 1. 互信息

### 1.1 定义

**互信息** I(X; Y) 度量"知道 Y 后，X 的不确定性减少了多少"：

I(X; Y) = H(X) − H(X | Y) = H(Y) − H(Y | X)

等价形式（对称性）：I(X; Y) = H(X) + H(Y) − H(X, Y)

```text
直觉：
  I = 0 → X、Y 独立（Y 不提供 X 的任何信息）
  I = H(X) → Y 完全确定 X（信息全给）
  互信息是对称的：X 给 Y 的信息 = Y 给 X 的信息
```

### 1.2 计算示例

```text
问题：X = 掷硬币（均匀），Y = 观察结果是否与 X 相同（Y = X）
  H(X) = 1，H(X|Y) = 0 → I(X;Y) = 1 bit
  （Y 就是 X 的拷贝，信息完全传递）

问题：X 均匀硬币，Y = 与 X 无关的噪声
  H(X|Y) = H(X) = 1 → I(X;Y) = 0 ✓
```

### 1.3 互信息的特征选择应用

```text
特征选择：对每个特征 f 计算 I(标签; f)，按互信息降序取前 k 个
  优点：非线性相关也能捕捉（区别于皮尔逊相关）
  工程：sklearn 的 mutual_info_classif 就是它

性质：I(X;Y) 只依赖联合分布，与单调变换无关（比相关更鲁棒）
```

## 2. KL 散度：相对熵

### 2.1 定义

**KL 散度**（Kullback-Leibler divergence）度量"用分布 Q 近似真实分布 P 的额外代价"：

KL(P‖Q) = Σ p(x)·log(p(x)/q(x))

| 性质 | 内容 |
|------|------|
| 非负性 | KL ≥ 0，等号当且仅当 P = Q（吉布斯不等式） |
| 不对称 | KL(P‖Q) ≠ KL(Q‖P)（不是距离！） |
| 不满足三角不等式 | 不是度量 |
| 凸性 | 对分布对 (P,Q) 是凸函数 |

```text
直观理解：
  KL(P‖Q) = "以 Q 为假设时的平均惊讶 - 以 P 为假设时的平均惊讶"
  = 用错误分布编码真实分布时的额外比特数

示例：P 均匀（1/2, 1/2），Q 有偏（0.9, 0.1）
  KL(P‖Q) = 0.5·log(0.5/0.9) + 0.5·log(0.5/0.1) ≈ 0.51 bit
  （用 Q 的编码方案传 P 的数据，平均多花 0.51 bit）
```

### 2.2 为什么 KL 是"距离"的替身

```text
虽然不对称，但 KL 有明确的工程语义：
  "从 Q 学习 P 的代价" —— 这正是分布拟合的目标函数
  最小化 KL(P‖Q) = 最大似然估计（对参数化 Q）！

机器学习中的方向约定：
  前向 KL(P‖Q)：Q 覆盖 P 的支撑（mode-averaging，训练生成模型常用）
  反向 KL(Q‖P)：Q 聚焦 P 的一个 mode（mode-collapse，VAE 后验常用）
  —— 这解释了 GAN 训练不稳定的部分数学根源
```

## 3. 交叉熵

### 3.1 定义与关系

**交叉熵** H(P, Q) = −Σ p(x)·log q(x)

与熵、KL 的精确关系（**必背**）：

H(P, Q) = H(P) + KL(P‖Q)

```text
含义：用 Q 的编码来编码 P 的平均代价
  = P 自身的最优代价（熵）+ 用错分布的额外代价（KL）

推论：
  H(P, Q) ≥ H(P)（交叉熵不小于熵，等号当 Q = P）
  最小化 H(P,Q)（固定 P）⟺ 最小化 KL(P‖Q) ⟺ 最大似然
```

### 3.2 交叉熵是 LLM 的损失函数（07 模块预告）

```text
语言模型训练：P = 真实词分布（one-hot 或平滑后）
                 Q = 模型预测分布
  损失 = H(P, Q) = −log q(真实词)（单样本形式）
  最小化交叉熵 ⟺ 最大似然 ⟺ 让模型分布逼近数据分布

困惑度（perplexity）= 2^H —— LLM 评估的核心指标
  例：H = 2.5 bit/token → perplexity = 2^2.5 ≈ 5.66
```

## 4. JS 散度与距离家族

### 4.1 JS 散度

**JS 散度**（Jensen-Shannon）：KL 的对称化版本

JS(P‖Q) = ½·KL(P‖M) + ½·KL(Q‖M)，其中 M = (P+Q)/2

| 性质 | 内容 |
|------|------|
| 对称 | JS(P‖Q) = JS(Q‖P) |
| 有界 | 0 ≤ JS ≤ log 2（归一化后可当距离用） |
| 使用 | GAN 损失（原始 GAN 用 JS 变体，后来被 Wasserstein 取代） |

### 4.2 散度家族全景

| 度量 | 对称 | 有界 | 三角不等式 | 主要用途 |
|------|:---:|:---:|:---:|---------|
| KL 散度 | ❌ | ❌ | ❌ | 分布拟合、模型蒸馏 |
| JS 散度 | ✅ | ✅ | ❌ | GAN 理论分析 |
| 总变差距离 | ✅ | ✅ | ✅ | 理论分析 |
| Wasserstein 距离 | ✅ | ✅ | ✅ | GAN 改进（WGAN） |
| 互信息（度量相关） | ✅ | ✅ | — | 特征选择、表征学习 |

## 5. 链式法则与数据处理不等式

### 5.1 链式法则

互信息的链式法则（多变量分解）：

I(X₁, X₂, …, Xₙ; Y) = Σ I(Xᵢ; Y | X₁…Xᵢ₋₁)

```text
含义：联合变量与 Y 的总信息 = 逐个变量提供的信息之和
  （条件互信息 = 在已知前面变量后新增的信息）

应用：信息瓶颈（IB）方法、多模态融合的信息论分析
```

### 5.2 数据处理不等式（DPI）

若 X → Y → Z 构成马尔可夫链（Z 只依赖 Y），则：

I(X; Z) ≤ I(X; Y)

```text
含义：数据处理不能创造信息——加工只会丢失信息（或持平）
  Z = f(Y)：对数据的任何确定性加工都不会增加关于 X 的信息

三大推论（AI 工程高频）：
  ① 特征工程的上限 = 原始数据的信息量（特征无法无中生有）
  ② 中间表示的信息损失不可逆（贪心逐层压缩的代价）
  ③ 数据增强/降维的信息论合法性检查：是否违背 DPI
```

> 🎯 **核心要点**：DPI 是"信息论的守恒定律"——它给出一切机器学习方法的理论边界：模型不可能从数据中学到比数据包含的更多信息（对目标）。理解 DPI，就理解了"为什么加再多的层也补不回丢弃的信息"。

## 6. 四大度量的关系总图

```text
              H(X, Y)  联合熵
             /        \
        H(X)            H(Y)
        |   \          /   |
        |   I(X;Y)    /    |
        |       \    /     |
        H(X|Y)      H(Y|X)
        (条件熵)    (条件熵)

关系：
  H(X, Y) = H(X) + H(Y|X)
  I(X; Y) = H(X) − H(X|Y)
  H(X) = I(X;Y) + H(X|Y)
  H(P,Q) = H(P) + KL(P‖Q)

记忆口诀：联合 = 各减其条件 + 交集；互信息 = 交叠部分
```

## 7. 工程应用

| 场景 | 度量 |
|------|------|
| LLM 训练损失 | 交叉熵 H(P,Q)（逐 token） |
| 模型蒸馏 | KL(教师‖学生)（软标签分布拟合） |
| RLHF 奖励 | 参考策略 KL 惩罚项（防止漂移） |
| 特征选择 | 互信息 I(标签; 特征) |
| 变分推断（VAE） | ELBO = 重构 − KL(后验‖先验) |
| 扩散模型 | KL 的连续版本（去噪损失） |
| 异常检测 | KL(窗口分布‖基准分布) 漂移检测 |
| 联邦学习 | 客户端分布 KL 加权（2025 前沿，08 模块） |

> 🎯 **核心要点**：02 模块是 AI 时代信息论的"使用手册"——交叉熵当损失、KL 当拟合目标、互信息当相关性、JS/Wasserstein 当分布距离。这五个度量及其关系（尤其 H(P,Q) = H(P) + KL）是读懂任何 ML 论文损失函数的钥匙。
