## 3. 学习路线推荐

**路线 A：AI 工程师必读（2 天，推荐）**
01 → 02 → 07。交叉熵与 KL 散度是深度学习的第一数学工具：损失函数、模型蒸馏、RLHF、扩散模型全部建立在这三个度量上。**看不懂 LLM 论文的损失函数？先补这一条线。**

**路线 B：通信/系统方向（1 周）**
路线 A + 03 → 04 → 05 → 06。理解"信息传输的极限"：压缩能压到什么程度（熵）、传输能多可靠（容量）、有损能损失多少（率失真）——三大定理撑起整个通信与存储工程。

**路线 C：前沿研究（面向研究者）**
路线 B + 08。语义信息论与 6G：语义熵、JSCC、ComAI——香农框架在"传含义"时代的新扩展。

> 💡 与知识库关系：07 模块与 03-AI 大模型层的全部模块（LLM 训练、RLHF、RAG 重排）直接咬合；04 模块的 Huffman 与 `初等数论/` 的编码思想呼应；08 模块的语义熵与 `离散数学/07` 的逻辑应用同样服务于 AI 可信性。

## 4. 核心概念速查

| 概念 | 一句话定义 | 关键事实 |
|------|-----------|---------|
| 自信息 I(x) | 事件 x 发生带来的信息量 = −log p(x) | 概率越小信息越大 |
| 熵 H(X) | 随机变量的平均自信息 | 0 ≤ H ≤ log n |
| 条件熵 H(X\|Y) | 已知 Y 后 X 的剩余不确定性 | 平均减少 = 互信息 |
| 互信息 I(X;Y) | Y 提供了关于 X 的多少信息 | 对称、非负、≤ 各自熵 |
| KL 散度 | 用 Q 近似 P 的额外代价 | 非负、不对称 |
| 交叉熵 | H(P,Q) = H(P) + KL(P‖Q) | LLM 损失函数本体 |
| 信道容量 C | 可靠传输的最大速率 | 香农公式 C = B·log(1+S/N) |
| Huffman 编码 | 最优前缀码 | 熵的 ±1 位近似 |
| CRC/汉明码 | 检错/单比特纠错 | 数据链路标配 |
| LDPC/极化码 | 逼近容量的现代纠错码 | 5G/6G 物理层 |
| 率失真函数 | 给定失真下的最小码率 | 有损压缩的极限 |
| 语义熵 | 语义层面的信息量（2025） | 语义熵 ≤ 香农熵 |

> 🎯 **核心要点**：信息论回答三个问题——**信息怎么度量（熵）、最多能压多小（信源编码）、最多能传多快（信道容量）**。一切现代 AI（交叉熵损失）、通信（5G 编码）、存储（压缩/纠错）都是这三个问题的工程展开。香农 1948 年的论文至今是这些领域的"宪法"。
