## 2. 核心必修课程（AI 大模型 + 计算机基础）

### 2.1 线性代数

| 维度 | 说明 |
|------|------|
| **推荐课程** | MIT 18.06 (Gilbert Strang) / 3Blue1Brown 《线性代数的本质》 |
| **重点章节** | 向量与矩阵运算、线性方程组、特征值与特征向量、奇异值分解 (SVD) |
| **AI 关联** | Transformer Self-Attention = 矩阵乘法；Embedding = 向量空间映射 |
| **Java 工具** | ND4J、Apache Commons Math、EJML |
| **预计耗时** | 4-6 周 |

### 2.2 微积分

| 维度 | 说明 |
|------|------|
| **推荐课程** | MIT 18.01（单变量）+ 18.02（多变量）/ 可汗学院微积分系列 |
| **重点章节** | 导数与偏导数、链式法则、梯度下降法、泰勒展开 |
| **AI 关联** | 反向传播 = 链式法则的工程实现；梯度下降 = 偏导数的迭代应用 |
| **Java 工具** | ND4J 自动微分、DJL GradientCollector |
| **预计耗时** | 4-6 周 |

### 2.3 概率论与数理统计

| 维度 | 说明 |
|------|------|
| **推荐课程** | Harvard STAT110 (Joe Blitzstein) / 可汗学院统计与概率 |
| **重点章节** | 概率分布、条件概率与贝叶斯定理、期望与方差、最大似然估计 |
| **AI 关联** | LLM 输出 = 概率分布；扩散模型 = 高斯噪声；交叉熵 = 损失函数 |
| **Java 工具** | Apache Commons Math Statistics |
| **预计耗时** | 4-6 周 |

## 6. 推荐学习顺序

### 6.1 四阶段学习法

```
第一步（0 → 1）：建立直觉（2-3 周）
├── 3Blue1Brown《线性代数的本质》   → 可视化理解向量、矩阵、特征值
├── 3Blue1Brown《微积分的本质》      → 可视化理解导数、积分、极限
└── 3Blue1Brown《概率论》           → 可视化理解贝叶斯、分布

第二步（系统学习）：MIT/Harvard 公开课 + 习题（12-16 周）
├── 线性代数：MIT 18.06 (Strang)    → 4-6 周
├── 微积分：MIT 18.01 + 18.02       → 4-6 周
└── 概率统计：Harvard STAT110       → 4-6 周

第三步（计算机基础强化）：离散 + 数论 + 数值（6-10 周）
├── 离散数学：MIT 6.042J             → 3-4 周，结合 Java 集合框架
├── 数论基础：MIT 6.042J 数论部分    → 2-3 周，结合 BigInteger
└── 数值计算：MIT 18.330             → 2-3 周，结合 BigDecimal

第四步（AI 理论深化）：信息论 + 优化 + 自动机（按需选择）
├── 信息论       → 理解 Loss/困惑度/VAE
├── 优化理论     → 深入理解训练过程
└── 形式语言     → 编译器/DSL 方向
```

### 6.2 按角色的学习路径

| 角色 | 必学 | 建议学 | 按需学 |
|------|------|--------|--------|
| **AI 大模型工程师** | 01 线代 + 02 微积分 + 03 概率统计 | 11 信息论 + 12 优化理论 | 04 离散数学 |
| **Java 后端 + AI 复合** | 01 + 02 + 03 + 04 离散数学 | 11 信息论 + 12 优化理论 | 05 数值 + 10 数论 |
| **纯 Java 后端** | 04 离散数学 | 05 数值计算 + 10 数论基础 | 01 线代基础 |
| **安全/密码学方向** | 04 离散数学 + 10 数论基础 | 03 概率统计 | — |
| **编译/语言方向** | 04 离散数学 + 08 形式语言 | 12 优化理论 | — |
| **算法竞赛** | 04 离散数学 + 10 数论 + 09 组合数学 | 03 概率统计 | 12 优化理论 |

### 6.3 一个提醒

> 多数 Java 开发者因为能直接调用 `Math.random()` 或 `ArrayList`，会觉得学这些"用不上"。但在大模型开发中，你需要手动实现向量搜索、处理梯度爆炸/消失、设计自定义损失函数，这时缺乏数学基础就会寸步难行。建议边写代码边推导简单公式，效果更好。
