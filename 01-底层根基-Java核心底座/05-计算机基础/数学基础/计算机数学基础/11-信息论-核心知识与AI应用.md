## 2. 自信息与熵

### 2.1 自信息（Self-Information）

```
I(x) = -log₂ P(x)

含义：事件 x 发生带来的"信息量"

性质：
  P(x) = 1  → I(x) = 0     （必然事件，零信息 → "太阳从东边升起"）
  P(x) → 0  → I(x) → ∞     （罕见事件，巨量信息 → "中彩票"）
  P(x) = 1/2 → I(x) = 1 bit （公平硬币，1 bit 信息）

单位：bit（以 2 为底）、nat（以 e 为底）、hartley（以 10 为底）
  1 nat ≈ 1.44 bit
```

### 2.2 熵（Entropy）

```
H(X) = -Σ_x P(x)·log₂ P(x) = E[I(X)]
     = 自信息的期望值

含义：随机变量的"平均不确定性"

性质：
  0 ≤ H(X) ≤ log₂|X|（取值个数）

  H(X) = 0                 → 确定性（P(某个值)=1）
  H(X) = log₂|X|            → 完全随机（均匀分布）

示例（硬币）：
  公平硬币 P(H)=0.5：  H = -0.5·log₂0.5 - 0.5·log₂0.5 = 1 bit
  偏斜硬币 P(H)=0.9：  H = -0.9·log₂0.9 - 0.1·log₂0.1 ≈ 0.47 bit
  确定的 P(H)=1：      H = -1·log₂1 - 0 = 0 bit
```

### 2.3 为什么用 log₂？

```
用 log₂ → 熵的单位 = bit

直观连接：
  1 bit = 回答一个"是/否"问题所需的信息量
  H(X) bit = 平均需要 H(X) 个是/否问题才能确定 X 的值

这就是信息压缩的理论极限。
```

## 3. 联合熵、条件熵、互信息

### 3.1 联合熵

```
H(X, Y) = -Σ_x Σ_y P(x,y)·log₂ P(x,y)

含义：X 和 Y 一起的不确定性
性质：H(X,Y) ≤ H(X) + H(Y)（等号成立当且仅当 X,Y 独立）
```

### 3.2 条件熵

```
H(Y|X) = -Σ_x P(x)·Σ_y P(y|x)·log₂ P(y|x)
       = H(X,Y) - H(X)

含义：已知 X 后，Y 还剩下的不确定性
性质：H(Y|X) ≤ H(Y)（信息不会因已知而增加）
```

### 3.3 互信息

```
I(X; Y) = H(X) + H(Y) - H(X, Y)
        = H(X) - H(X|Y)
        = H(Y) - H(Y|X)
        = Σ_x Σ_y P(x,y)·log₂(P(x,y) / (P(x)P(y)))

含义：X 和 Y 共享的信息量 = 知道 X 后 Y 减少的不确定性

性质：
  I(X;Y) ≥ 0
  I(X;Y) = 0 ↔ X, Y 独立
  I(X;Y) = I(Y;X)（对称性）

机器学习中：互信息 = 特征与标签的信息增益
```

### 3.4 关系图

```
        H(X,Y)
    ┌──────┴──────┐
    │  ┌───────┐  │
    │  │I(X;Y) │  │
    │  └───────┘  │
    │  /       \  │
 H(X|Y)       H(Y|X)
    │           │
    └─────┬─────┘
       H(X), H(Y)
```

## 4. 交叉熵与 KL 散度

### 4.1 交叉熵

```
H(P, Q) = -Σ_x P(x)·log₂ Q(x)

含义：用分布 Q 编码分布 P 所需的平均 bit 数

关键：H(P, Q) ≥ H(P)（用错误分布编码，总是效率更低）

深度学习中：
  P = 真实分布（标签的 one-hot）
  Q = 模型预测分布（softmax 输出）

  训练目标：min H(P, Q) → 让模型的预测分布逼近真实分布
```

### 4.2 KL 散度（相对熵）

```
D_KL(P || Q) = Σ_x P(x)·log₂(P(x) / Q(x))
             = H(P, Q) - H(P)

含义：用 Q 近似 P 时的"信息损失"

性质：
  D_KL(P||Q) ≥ 0（吉布斯不等式）
  D_KL(P||Q) = 0 ↔ P = Q
  D_KL(P||Q) ≠ D_KL(Q||P)（非对称！）

深度学习中：
  交叉熵 = 熵 + KL 散度
  最小化交叉熵 = 最小化 KL 散度（因为 H(P) 固定）
```

### 4.3 KL 散度的非对称性

```text
D_KL(P||Q) ≠ D_KL(Q||P) — 方向很重要！

D_KL(P||Q)：用 Q 逼近 P 时"覆盖不足"惩罚重
  → Q 在 P 概率高的地方必须也有概率 → Q 覆盖 P 所有模式

D_KL(Q||P)：用 Q 逼近 P 时"虚假模式"惩罚重
  → Q 在 P 概率为零的地方不能有概率 → Q 不能瞎编

VAE 用 D_KL(q(z|x) || p(z))：
  → 要求后验逼近先验（通常是 N(0,I)），正则化隐空间
```

## 5. 信道与编码

### 5.1 香农信道容量

```
C = W·log₂(1 + S/N)

  C：信道容量（bps）
  W：带宽（Hz）
  S/N：信噪比（线性值，非 dB）
  S/N(dB) = 10·log₁₀(S/N)

含义：任何可靠通信的速率 ≤ 信道容量
  → 香农定理给出了通信的理论极限
  → LDPC/Polar 码已接近香农极限
```

### 5.2 熵编码

```text
哈夫曼编码：
  最优前缀码，平均码长 L 满足：
    H(X) ≤ L < H(X) + 1

  高频符号 → 短码，低频符号 → 长码
  → 无损压缩的理论基础

算术编码：
  将整个消息编码为一个 [0,1) 区间中的小数
  更接近熵极限
  → 7z（LZMA）、JPEG2000、H.264（CABAC）等使用；
    gzip/bzip2 采用 Huffman 编码（Huffman 足够高效且更快）
```

### 5.3 编码在 AI 中的应用

```
词表编码（Tokenizer）：
  Byte-Pair Encoding (BPE) → 高频词/子词用短 token
  → 本质上是固定码表大小的熵编码思想

模型压缩：
  熵编码用于无损压缩模型权重
  → 梯度量化 + 熵编码 = 无损压缩的变分方法
```

## 6. 信息论在 AI 中的核心应用

### 6.1 决策树的信息增益

```
信息增益 = H(D) - H(D|A) = I(D; A)

D：数据集标签，A：候选特征

分裂准则（ID3/C4.5）：
  选择信息增益最大的特征作为分裂节点
  → 该特征能最大程度"解释"标签的不确定性

增益率（C4.5 改进）：
  GainRatio = Gain / SplitInfo（用分裂信息量归一化，避免偏向多值特征）
```

### 6.2 困惑度（Perplexity）

```
PPL = 2^{H(P,Q)} = 2^{-(1/N)·Σ log₂ P(tokenᵢ|context)}

含义：模型在每次预测时，平均需要从多少个选项中"猜"一个

示例：
  均匀分布的词汇表（50000 词）：PPL = 50000（最差）
  好模型的 PPL ≈ 5-20
  GPT-4 级别 ≈ <5

越低越好：PPL 越小 → 模型对文本越确定 → 生成的文本越流畅
```

### 6.3 VAE 损失函数的信息论解析

```
Loss = Reconstruction Loss + KL(q(z|x) || p(z))

Reconstruction：-E_q[log p(x|z)]  → 重建的负对数似然（交叉熵）
KL 项：D_KL(q(z|x) || N(0,I))    → 约束隐空间接近标准正态

信息论视角：
  压缩：q(z|x) 提取 x 的最少信息（互信息最小化）
  重建：p(x|z) 从 z 中恢复 x（失真最小化）
  → VAE 在"压缩"和"重建"之间寻找平衡
```

### 6.4 RLHF 中的 KL 约束

```
loss = -reward + β·KL(π_θ || π_ref)

  π_θ：当前策略（微调后的模型）
  π_ref：参考策略（原始模型）

含义：
  -reward：最大化奖励（人类的偏好）
  KL 项：不要偏离原始模型太远

→ 防止"奖励黑客"：模型学会钻奖励函数的漏洞而输出无意义文本
  KL 约束保证模型仍然像正常的语言模型
```

## 7. Java 实现

### 7.1 熵与交叉熵计算

```java
public class InformationTheory {

    // 熵 H(X)
    public static double entropy(double[] probs) {
        double h = 0;
        for (double p : probs) {
            if (p > 0) h -= p * Math.log(p) / Math.log(2); // log₂
        }
        return h;
    }

    // 交叉熵 H(P, Q)
    public static double crossEntropy(double[] p, double[] q) {
        double h = 0;
        for (int i = 0; i < p.length; i++) {
            if (p[i] > 0) h -= p[i] * Math.log(q[i]) / Math.log(2);
        }
        return h;
    }

    // KL 散度 D_KL(P||Q)
    public static double klDivergence(double[] p, double[] q) {
        return crossEntropy(p, q) - entropy(p);
        // 等价于 Σ p[i] * log(p[i]/q[i])
    }

    // 困惑度
    public static double perplexity(double crossEntropy) {
        return Math.pow(2, crossEntropy);
    }

    // 互信息 I(X;Y) = H(X) + H(Y) - H(X,Y)
    public static double mutualInformation(double[][] jointProb, 
                                           double[] pX, double[] pY) {
        double hX = entropy(pX);
        double hY = entropy(pY);
        double hXY = 0;
        for (int i = 0; i < jointProb.length; i++)
            for (int j = 0; j < jointProb[i].length; j++)
                if (jointProb[i][j] > 0)
                    hXY -= jointProb[i][j] * Math.log(jointProb[i][j]) / Math.log(2);
        return hX + hY - hXY;
    }
}
```

### 7.2 决策树信息增益

```java
// 信息增益 = 分裂前的熵 - 分裂后的条件熵
public static double informationGain(
        double[] labels,          // 所有样本的标签分布
        double[][] featureDist,   // featureDist[value][label] = 条件概率
        double[] featureProb) {   // 每个特征值的边际概率

    double hBefore = entropy(labels);

    double hAfter = 0;
    for (int v = 0; v < featureProb.length; v++) {
        hAfter += featureProb[v] * entropy(featureDist[v]);
    }

    return hBefore - hAfter;  // = I(Label; Feature)
}
```

### 7.3 信道容量计算

```java
// 香农公式：C = W·log₂(1 + S/N)
public static double channelCapacity(double bandwidthHz, 
                                     double snrLinear) {
    return bandwidthHz * Math.log(1 + snrLinear) / Math.log(2);
}

// 从 dB 转换
public static double dbToLinear(double db) {
    return Math.pow(10, db / 10.0);
}

// 示例：WiFi 信道
// 带宽 = 20 MHz = 2e7 Hz, SNR = 20 dB
double C = channelCapacity(20_000_000, dbToLinear(20));
// ≈ 1.33×10⁸ bps = 133 Mbps
```

## 关键公式速记卡

| 公式 | 用途 |
|------|------|
| `H(X) = -Σ P(x)·log₂ P(x)` | 熵——不确定性度量 |
| `H(P,Q) = -Σ P(x)·log₂ Q(x)` | 交叉熵——深度学习损失函数 |
| `D_KL(P‖Q) = Σ P·log(P/Q)` | KL 散度——分布差异 |

| `C = W·log₂(1+S/N)` | 香农信道容量 |
| `I(X;Y) = H(X)+H(Y)-H(X,Y)` | 互信息——信息增益 |
