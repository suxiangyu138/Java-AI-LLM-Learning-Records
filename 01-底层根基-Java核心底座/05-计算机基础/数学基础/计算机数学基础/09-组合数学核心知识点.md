## 1. 基本概念

### 1.1 集合基础

```
集合：具有互异性、无序性的元素集体
  N = {0, 1, 2, ...}    自然数集
  Z = {..., -2, -1, 0, 1, 2, ...}  整数集

基本运算：
  A ∩ B = {x | x∈A ∧ x∈B}    交集
  A ∪ B = {x | x∈A ∨ x∈B}    并集
  A - B = {x | x∈A ∧ x∉B}    差集
  A̅ = {x | x∈U ∧ x∉A}       补集（U 为全集）
  P(A)                       幂集（所有子集的集合）
  |A|                        基数（元素个数）
```

### 1.2 排列 vs 组合的核心区别

```
排列：考虑顺序  → "选出来并排序"
组合：不考虑顺序 → "只选出来"
```

## 2. 排列与组合

### 2.1 公式总表

| 类型 | 公式 | 条件 | 示例 |
|------|------|------|------|
| **全排列** | `n!` | n 个不同元素全部取 | 3 本书排一排 = 6 种 |
| **选排列** | `P(n,k) = n!/(n-k)!` | n 选 k，有序 | 5 人选 3 人排队 = 60 种 |
| **组合** | `C(n,k) = n!/(k!(n-k)!)` | n 选 k，无序 | 5 人选 3 人组队 = 10 种 |
| **可重复排列** | `nᵏ` | n 选 k，有序，可重复 | 3 位密码锁 = 10³ = 1000 |
| **可重复组合** | `C(n+k-1, k)` | n 选 k，无序，可重复 | — |
| **圆排列** | `(n-1)!` | n 个元素围成圆 | 5 人圆桌 = 24 种 |
| **多重集排列** | `n!/(n₁!·n₂!·...·nₘ!)` | 有相同元素 | "MISSISSIPPI" 排列数 |

### 2.2 组合数的关键性质

```
对称性：  C(n, k) = C(n, n-k)
加法（帕斯卡公式）：C(n, k) + C(n, k-1) = C(n+1, k)
行求和：  Σₖ C(n, k) = 2ⁿ
```

### 2.3 Java 实现

```java
// 组合数：递推法（杨辉三角）
// 优点：O(n²) 预处理，O(1) 查询，整数不溢出
long[][] binomial = new long[n+1][n+1];
for (int i = 0; i <= n; i++) {
    binomial[i][0] = binomial[i][i] = 1;
    for (int j = 1; j < i; j++)
        binomial[i][j] = binomial[i-1][j-1] + binomial[i-1][j];
}

// 全排列生成（Heap 算法）
void generatePermutations(int[] arr, int n, List<int[]> result) {
    if (n == 1) { result.add(arr.clone()); return; }
    for (int i = 0; i < n; i++) {
        generatePermutations(arr, n - 1, result);
        if (n % 2 == 0) swap(arr, i, n - 1);
        else            swap(arr, 0, n - 1);
    }
}
```

## 3. 二项式定理

### 3.1 核心公式

```
(a + b)ⁿ = Σ_{k=0}^{n} C(n,k) · aⁿ⁻ᵏ · bᵏ

二项式系数 C(n,k) 对应杨辉三角的第 n+1 行
```

### 3.2 常用推论

```
(1) Σₖ C(n,k) = 2ⁿ                          （令 a=b=1）
    → n 元集合的所有子集数量 = 2ⁿ

(2) Σₖ (-1)ᵏ · C(n,k) = 0                  （令 a=1, b=-1）

(3) C(n,0) + C(n,2) + ... = C(n,1) + C(n,3) + ... = 2ⁿ⁻¹
    → 偶子集数 = 奇子集数
```

## 4. 容斥原理

### 4.1 公式

```
两个集合：|A ∪ B| = |A| + |B| - |A ∩ B|

三个集合：|A ∪ B ∪ C| = |A| + |B| + |C|
                      - |A∩B| - |A∩C| - |B∩C|
                      + |A∩B∩C|

n 个集合：|⋃ᵢ Aᵢ| = Σᵢ|Aᵢ| - Σ_{i<j}|Aᵢ∩Aⱼ| + Σ_{i<j<k}|Aᵢ∩Aⱼ∩Aₖ| - ...
                  + (-1)^{n+1}|A₁∩...∩Aₙ|
```

### 4.2 经典应用

```
问题：1-100 中能被 2 或 3 或 5 整除的数有多少个？

A₂ = {能被 2 整除}, |A₂| = 50
A₃ = {能被 3 整除}, |A₃| = 33
A₅ = {能被 5 整除}, |A₅| = 20

|A₂∩A₃| = ⌊100/6⌋ = 16
|A₂∩A₅| = ⌊100/10⌋ = 10
|A₃∩A₅| = ⌊100/15⌋ = 6

|A₂∩A₃∩A₅| = ⌊100/30⌋ = 3

答案 = 50+33+20-16-10-6+3 = 74
```

## 5. 鸽巢原理

### 5.1 基本形式

```
基本：n+1 个物体放入 n 个盒子 → 至少一个盒子有 ≥2 个物体
推广：k 个物体放入 n 个盒子 → 至少一个盒子有 ≥⌈k/n⌉ 个物体
```

### 5.2 计算机应用

```
① 哈希冲突：
   任意哈希函数 h: K→{0,1}ⁿ（输出空间有限）
   只要 |K| > 2ⁿ，冲突必然存在
   → 哈希表必须处理冲突（拉链法/开放寻址法）

② 数据压缩：
   无损压缩不可能对所有输入都压缩
   → 鸽巢原理保证：必然存在输入变长

③ 负载均衡：
   n 个请求分配到 m 个服务节点
   → 至少一个节点接收 ≥⌈n/m⌉ 个请求
```

## 6. 递推关系

### 6.1 经典递推

| 问题 | 递推式 | 初值 | 通解 |
|------|--------|------|------|
| 斐波那契 | `Fₙ = Fₙ₋₁ + Fₙ₋₂` | F₀=0, F₁=1 | `Fₙ = (φⁿ-ψⁿ)/√5` |
| 汉诺塔 | `Tₙ = 2Tₙ₋₁ + 1` | T₁=1 | `Tₙ = 2ⁿ-1` |
| 爬楼梯 | `Sₙ = Sₙ₋₁ + Sₙ₋₂` | S₀=1, S₁=1 | 同斐波那契偏移 |
| 最大子数组切分 | `dp[i] = max(dp[i-1]+a[i], a[i])` | — | 动态规划 |

### 6.2 递推 vs 递归 vs 动态规划

| 方法 | 方向 | 复杂度 | 适用 |
|------|------|--------|------|
| **递推** | 自底向上 | O(n) | 线性递推 |
| **递归（朴素）** | 自顶向下 | O(2ⁿ) | 仅教学用 |
| **记忆化递归** | 自顶向下 + 缓存 | O(n) | 状态空间不规律 |
| **动态规划** | 自底向上 + 填表 | O(n) 或 O(n²) | 多维递推 |
