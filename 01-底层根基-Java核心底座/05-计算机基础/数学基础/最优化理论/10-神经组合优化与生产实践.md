# 神经组合优化与生产实践
> 2026 年优化领域最大的变化：神经网络不再"绕过"求解器，而是**住进求解器内部**——学习分支变量选择、预测最优值边界、加速分支定界（Neural MIP）；本体系的终点是把"问题分类 → 方法匹配 → 工具选型"炼成一张可执行的决策树。

## 1. Neural MIP：学习如何"住进"求解器

**神经组合优化（Neural Combinatorial Optimization）**的三代演进：**端到端学习**（2015 年起：Pointer Network 直接"生成"TSP 解——泛化差、无保证，2026 年已被边缘化）→ **强化学习搜索**（学策略指导局部搜索——仍无保证）→ **学习增强求解器**（2020 年起的主流：**不改求解器算法，只学求解器内部组件的决策**）。2026 年的核心组件级应用四个：

- **分支变量选择（branching）**：图神经网络（GNN）学习"该优先分支哪个变量"——替代启发式规则，把分支树缩小；GIN-BGE（2026）用"二分图熵"自适应估计嵌入维度，在四类 MILP 上比 SOTA 平均提速 **25.5% 时间、28.9% 节点**
- **预测与搜索（predict-and-search）**：学习预测"最优解长什么样"，把预测解当热启动（MIPStart）或引导原始启发式——SHARP（2026）集成进 Gurobi/SCIP，主间隙曲线全面优于对比方法
- **最优值预测（objective prediction）**：学习预测问题的最优值，用于分支定界的"提前剪枝"（下界太差直接剪掉）与停机判断
- **割平面选择**：学习从割池里选"最有效的割"——割平面质量决定下界紧度（04 篇），学习选择是 2026 年最活跃的方向

**2026 年的代表性工作**：MILPnet（ICLR 2026）用计算几何视角把 MILP 序列化成 token 交给多尺度注意力网络——**能区分 GNN 无法区分的"可折叠 MILP"（表达能力超越二分图 GNN）**，同时支持可行性/目标值/解三类预测；双注意力骨干（arXiv 2601.04509）用变量-约束双注意力做全局信息交换。**总判断：GNN 是 2025 年前的默认骨架，2026 年注意力/超图/几何序列架构正在接管**（表达力与可扩展性双提升）。

## 2. 学习的边界：增强而非替代

必须划清的边界（防止"AI 取代求解器"的叙事陷阱）：

- **性能现实**：学习增强的收益是"常数级"（节点数 25-30% 的改善），不是"复杂度级"（MIP 依然 NP 困难）；**Gurobi/CP-SAT 仍是事实标准**，学习组件是"求解器里的智能插件"
- **泛化风险**：GNN 学的是"同类分布的问题"——训练集分布变了（新的约束结构、新的规模范围），收益快速衰减；**换问题族必须重训**
- **验证依赖**：学习方法的每一步（分支/预测/割选择）都要用"纯求解器基线"做对比实验（SHARP/GIN-BGE 的标准做法）——**"学来的加速"必须先证明不是"基线调差了的错觉"**
- **理论保证**：深度展开/学习分支的收敛与最优性保证弱于经典算法——高精度、合规场景（投标、审计）仍以经典求解器为准

**工程姿势（2026）**：把学习当"锦上添花"——同一问题族反复求解（工业排产、网络优化）时，用学习组件加速（数据可以积累）；一次性问题直接用求解器。**"能复用的学习"才值得学习**。

## 3. 生产实践：选型决策树（全体系收束）

把 02-09 篇收束成一张决策树（本体系的"毕业考试"）：

```text
问题来了
├─ 能写数学形式？
│   ├─ 连续变量？
│   │   ├─ 凸？ → 凸优化体系（LP/QP/SOCP/SDP + 内点/一阶）
│   │   └─ 非凸？ → 02 篇：多起点/BB（低维）→ 元启发式（高维黑盒）
│   ├─ 整数/混合？
│   │   ├─ 线性主导 + 数值结构 → MIP：分支定界（03）+ 割平面（04）
│   │   │   └─ Gurobi/HiGHS（商用/开源）
│   │   ├─ 逻辑/排班/装箱 → CP-SAT（05）——2026 年组合事实标准
│   │   └─ 图结构明显？ → 网络流/匹配（06）——LP 免费拿整数解
│   └─ 多个目标？ → 07 篇：线性结构 ε-约束 + MIP；黑盒 NSGA/代理
├─ 参数不确定？
│   ├─ 知道分布 → 随机规划（08 篇，两阶段 + SAA）
│   ├─ 只知范围 → 鲁棒优化（08 篇，预算集 + LP/SOCP 重构）
│   └─ 分布也不确定 → DRO（Wasserstein）
├─ 算不动（精确方法超时）→ 09 篇：元启发式（多次运行取最优）
└─ 反复求解同类问题 → 10 篇：学习增强组件（Neural MIP）
```

两条总纪律：**结构优先**（认出凸/图/网络结构 → 免费的理论与算法）；**精确优先、启发兜底**（求解器 5 分钟，撑不住再上元启发式）。

### 4.1 从零搭建一个优化项目的五步流程

把决策树落地成项目执行流程，五步走：**第一步，问题访谈与建模**（占一半时间）：和业务方把"目标、约束、数据、决策变量、时间粒度"问清楚——写数学模型（哪怕草稿）是访谈的产物，不是访谈的前提；**第二步，结构识别与家族定位**（01 篇分类学）：凸/整数/图/多目标/不确定——用第 3 节决策树跑一遍，定"问题族 → 候选方法 → 候选工具"；**第三步，基线求解**（最快路径）：用最简单的方法拿一个"说得过去的解"当基线（贪心、或 CP-SAT 原型、或求解器默认参数）——**没有基线的优化项目会迷失在"调参优化"里**；**第四步，迭代改进**：按"差距"选改进方向——差距在解质量：换更紧的模型（MIP/割平面）或更强的搜索（ALNS）；差距在速度：预处理、热启动、并行、求解器参数；每一步单变量变更并记录；**第五步，交付与运维**：解校验器（约束检查）、容差与状态码记录（凸优化体系 08 篇同款纪律）、性能与业务指标双报告（间隙与 KPI）、模型维护手册（数据变了怎么重训重求）。**五步流程的底层哲学**：优化项目的失败九成死于建模错误与基线缺失，一成死于算法选择——**先建模、再基线、后改进**，比任何高级算法都重要。

最后给一条学习落地的建议：**本体系的实践入口是"小型运筹项目"**——用 OR-Tools（CP-SAT + 内置 MIP）实现一个真实的排班或路径问题（几十行代码），再换 Gurobi/HiGHS 实现同一个问题的 MIP 形式，对比两种建模的代码量、求解时间与解质量——**"同一问题双工具对比"是一次完成的毕业设计**：它同时训练建模、求解器选型、间隙解读三项核心技能；2026 年 LLM 辅助建模（凸优化 10 篇的三红线）在这里同样适用——让 LLM 生成 OR-Tools 草稿、自己验证约束完整性。**优化能力是"做出来"的不是"读出来"的**——五步流程（第 4.1 节）走完一个小项目，胜过读十篇综述。

> 🎯 **核心要点**：2026 年神经组合优化的成熟形态是"学习住进求解器"——分支选择（GIN-BGE 提速 25%+）、预测热启动（SHARP）、最优值预测、割选择四大组件，GNN 骨架正被注意力/超图/几何序列架构超越（MILPnet，ICLR 2026）；边界清晰：常数级加速而非复杂度级、分布泛化受限、必须以纯求解器为基线验证——"增强而非替代"；生产实践的毕业考试是一张决策树：结构优先、精确优先、启发兜底、反复求解才值得学习——两套优化体系（凸 + 广义）至此合拢为完整的优化世界观。
