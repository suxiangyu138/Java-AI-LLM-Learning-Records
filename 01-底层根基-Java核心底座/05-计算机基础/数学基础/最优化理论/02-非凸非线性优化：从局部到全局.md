# 非凸非线性优化：从局部到全局
> 凸优化保证全局最优，非凸优化只能"追求"——局部方法（梯度/牛顿）快速但会陷入局部极小，全局方法（多起点、分支定界、采样）试图找到全局最优但代价指数——2026 年的理论突破（扩散式平滑）正在给采样方法补上收敛保证。

## 1. 非凸问题的困难本质：局部极小与鞍点

非凸问题的目标函数有多个局部极小点，梯度类方法只能保证收敛到"最近的谷底"——你不知道是不是最深的那个。两个额外困难：

- **鞍点**（悬崖口）比局部极小更常见：高维空间的函数几乎处处是鞍点——梯度在鞍点附近停滞（梯度为零但不是极值），深度学习训练的"平台期"就是它；2026 年理论（如 DIDA 与扩散平滑）把鞍点与局部极小的处理统一进"平滑"框架（第 4 节）
- **非光滑**：绝对值、阶跃、分段函数让梯度不存在——次梯度与近端方法（凸优化 07 篇）可用，但全局最优性的保证更弱

工程现实：**纯局部方法在非凸问题上的表现高度依赖起点**——"多起点 + 选最好的"是最朴素也最有效的全局化策略（第 2 节）。理解"局部 vs 全局"的边界，是使用非凸工具的第一课：梯度下降在非凸上承诺的只有"收敛到驻点"，别把驻点当最优。

## 2. 全局优化的方法谱系：确定性路线

追求"找到全局最优（或带误差界）"的方法分两大类，先看确定性路线：

- **多起点局部搜索**：随机撒多个起点，各跑局部方法（梯度/拟牛顿），取最优——简单、可并行，但无保证（N 个起点只覆盖 N 个盆地）；改进版（clustering 聚类法、MLSL 多层单连接）把"撒点"做成"按盆地覆盖"的自适应流程
- **分支定界全局优化（BB）**：把连续可行域递归划分（分支）成小方块，每块算目标下界（界）剪掉不可能含全局最优的块——**对凹函数、Lipschitz 函数等有"可算下界"的问题类有效**（如凹最小化、Lipschitz 优化）；下界质量决定效率，工程上常与区间算术结合（区间分支定界，INTLAB/Julia 的区间工具）
- **填充函数与隧道法**：从局部极小出发，"挖掉"当前盆地（填充函数）或"穿越"到别处（隧道法），迭代逼近全局——技巧性强，适用于中等维度

确定性格局总结：**低维（≤10）且有下界可算 → 分支定界可以"证明全局最优"**；否则多起点是性价比之王。2026 年没有根本改变——全局优化依然是"结构 + 运气"的博弈。

## 3. 全局优化的方法谱系：随机/采样路线

另一条路线完全放弃"证明"，用随机采样 + 智能搜索逼近全局最优：

- **模拟退火**（1983）：按温度接受劣解，温度从高到低——早期"任意跑"（逃离局部极小），后期"收敛"；理论保证：温度按对数律下降时收敛到全局最优（几乎必然，但速度慢得不可用——理论价值大于实践价值）
- **遗传算法/差分进化/粒子群**：种群式搜索，靠变异、交叉、协作探索——见 09 篇（元启发式的完整展开）
- **交叉熵方法（CE）**：迭代估计"好解所在区域的分布"并按它采样——把优化变成统计估计问题；**2026 年理论突破把它与扩散模型统一**（第 4 节）
- **量子启发式（QIEO，2026）**：用量子叠加启发的概率表示保持全局视野，"隧穿"局部最优——在稀疏信号恢复与鲁棒回归上报告优于 ADAM 与遗传算法（研究前沿，工程验证未完）

随机路线的共同问题：**无收敛保证、结果不可复现（随机种子敏感）**——2026 年理论界正在补这个短板（第 4 节），工程界则用"多次运行取最优 + 基准测试"来补偿。

## 4. 2026 前沿：扩散式平滑与采样优化的收敛理论

2026 年最值得关注的理论进展，把"采样优化"与"扩散模型"两个世界统一了：**把采样式非凸优化重新诠释为"平滑目标上的梯度下降"**（类似扩散模型的噪声条件分数上升）——每次采样相当于对目标做一次随机平滑，平滑扩大全局最小点附近的局部凸区域，让景观变"良性"；代价是引入最优性间隙（覆盖-最优性权衡）。基于此提出的 **DIDA（扩散启发双退火）算法**被证明收敛到全局最优，性能优于其他无梯度方法。

三个工程含义：**平滑是"逃离局部极小"的通用机制**（加噪声、多尺度、随机重启在理论上同源）；**扩散模型与优化共享同一数学骨架**（难怪 2026 年优化与生成的论文互相引用暴涨）；**采样方法的"经验有效"开始有理论背书**——但收敛保证是渐进式的，有限预算下的实际行为仍靠实验（09 篇元启发式的存在理由不变）。**趋势判断：未来两年，"带保证的采样优化"会从理论走向实用工具**。

## 5. 非凸优化的工程工作流与实战案例

用一个真实案例串起非凸优化的完整工作流：**化工配方设计**——目标（产率）对配方比例高度非线性、有多个局部最优、且实验室评估昂贵。**工作流五步**：**第一步**，先跑局部方法（多起点 L-BFGS，50 个随机起点）摸清"有几个盆地、盆地间差距多大"——成本几乎为零的信息量最大；**第二步**，评估"是否值得全局"：如果 50 个起点的结果差异小于 5%，直接用局部解；差异大，说明全局结构重要；**第三步**，选全局策略：低维（≤10）且有区间下界可算 → 分支定界证明全局；高维 → 差分进化（09 篇，连续优化的稳健选择）；**第四步**，代理加速：仿真昂贵时用高斯过程代理（09 篇代理辅助），进化在代理上跑、关键候选真实评估；**第五步**，验证与交付：最优解做实验验证加领域专家审查——"数学最优"可能在物理上不可行，配方比例的工艺约束是建模时最容易漏的。

**案例的工程启示**：非凸优化的正确姿势不是"选个高级算法"，而是**"分层逼近 + 多工具协作"**——局部方法摸地形、全局方法攻盆地、代理方法省钱、专家验证兜底。这也是 2026 年工业界的普遍做法：没有任何单一算法解决非凸，但组合拳总能给出工程可用的答案。

补充一个实践提醒：**非凸优化的"次数"思维**——一次求解的运气成分很大，三次求解是底线、十次是常态（09 篇元启发式的"多次运行取最优"纪律在非凸同样适用）；随机种子、起点分布、收敛记录要写进实验日志，否则"这次比上次好"无法归因（是算法改进还是运气波动？）——**非凸世界的工程结论必须建立在"多次运行的分布"上，不是单次运行的点**。

> 🎯 **核心要点**：非凸优化的本质困难是局部极小与鞍点——局部方法只承诺"收敛到驻点"；全局优化两条路线：确定性（多起点、分支定界——低维可证明、区间下界是武器）与随机（模拟退火/交叉熵/量子启发——无保证但实用）；2026 年扩散式平滑理论给采样方法补上收敛证明（DIDA 收敛到全局最优），并揭示"平滑是逃离局部极小"的统一机制——趋势是从"经验有效"走向"带保证"。
