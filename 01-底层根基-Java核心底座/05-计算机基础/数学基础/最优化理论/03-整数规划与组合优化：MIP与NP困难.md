# 整数规划与组合优化：MIP 与 NP 困难
> 当决策变量必须是整数——装多少箱、派哪辆车、建不建仓库——优化就进入了 NP 困难的领地：线性松弛给出下界，分支定界用"树搜索 + 剪枝"把这个下界逼向最优——所有现代求解器的骨架，就是这两件武器。

## 1. 整数规划：连续世界的"整数化"

**整数规划（IP）**：线性规划加上"变量取整数值"约束；**混合整数规划（MIP）**：部分变量连续、部分整数——工程上最常见的形态（排产、调度、选址、切割、网络设计几乎全是 MIP）。整数变量来自三类现实：**计数**（车辆数、机器台数、工人数）、**二元决策**（建/不建、选/不选——0-1 变量）、**逻辑结构**（"如果 A 则 B"用大 M 法线性化）。

关键认知：**"整数"不是小改动，而是跃迁**——线性规划是多项式的，整数规划是 NP 困难的；同一组数据，LP 秒解、MIP 可能算到天荒地老。原因几何化：整数约束把连续多面体"挖"成离散点集，**最优解不再在顶点上，而在"离顶点最近的格点"上**——顶点最优的线性理论（凸优化 02 篇）整个失效。

### 1.1 三个经典问题：背包、旅行商、指派

- **背包问题**：N 件物品选哪些装进容量 W 的包使价值最大——最简单的整数规划（0-1 变量加一条容量约束），却是 NP 困难；它的"分数松弛"（允许装一部分）有贪心解，松弛与最优的差距是研究了一甲子的课题（近似比 1/2 的贪心、FPTAS 全多项式近似）
- **旅行商问题（TSP）**：访问 N 个城市各一次并回到起点的最短环——组合优化的"皇后"；约束"每个城市进出一次"（指派结构）加"无子环"（MTZ/子环消除约束），后者正是割平面（04 篇）的经典战场；50 城以下求解器秒解，1000 城是研究级难题
- **指派问题**：N 个任务分给 N 个人使总成本最小——**多项式可解**（匈牙利算法），因为约束矩阵全幺模、LP 松弛自动整数——"看似组合实则易"的代表，与背包（看似简单实则难）形成绝佳对照

## 2. NP 困难性：为什么"算不动"不是工程问题

**P vs NP** 是计算机科学最重要的未解问题，对优化的直接含义：**NP 困难问题没有多项式时间算法（除非 P=NP）**——背包、TSP、绝大多数调度问题的规模每翻一倍，精确求解时间可能指数增长。2026 年的工程现实：**NP 困难不是"算不了"的判决书，而是"策略分层"的说明书**：

- **精确方法（保证最优）**：分支定界加割平面——问题规模小或结构好时，实际求解速度远好于最坏情况（"最坏指数、平均好用"是求解器的常态）
- **近似方法（保证接近最优）**：有近似比的算法——TSP 的 1.5 近似（Christofides）、背包的 FPTAS；适合"证明难但结构有规律"的问题
- **启发式（不保证）**：贪心、局部搜索、元启发式（09 篇）——规模大且预算紧时的唯一选择

**工程判断框架：规模 × 结构 × 时间预算决定策略层**——"求解器先跑 5 分钟，不行上元启发式"是最常见的组合拳（10 篇决策树）。

## 3. 分支定界：树搜索加剪枝的精确框架

**分支定界（Branch & Bound）**是 MIP 求解器的骨架，四步循环：

1. **松弛**：丢掉整数约束，解 LP 松弛（凸问题，秒解）——得到下界
2. **分支**：松弛解里某个变量 x=2.3，则分成两个子问题（x≤2 与 x≥3）——把"连续解"逼回"整数格点"
3. **定界**：每个子问题继续解松弛，更新全局最优下界与当前最好整数解（上界）
4. **剪枝**：子问题下界 ≥ 当前上界 → 该子树不可能含更优解，整棵剪掉——**剪枝效率决定一切**

性能密码：**上界越好（找到好的可行解越早）、下界越紧（松弛质量越高），剪枝越多**——于是演化出两条增强线：**下界增强**（割平面，04 篇）与**上界增强**（原始启发式——用贪心/局部搜索快速找可行解，Gurobi 里默认开着）。**分支策略**（选哪个变量分叉：最伪分数/强分支/机器学习预测分支——10 篇 Neural MIP 的主战场）也直接决定树的大小。**2026 年的求解器竞争，本质是这三条线的工程竞赛**：Gurobi 12、HiGHS 1.14、SCIP 10 的差距在节点数、割平面池与启发式调度的微调（04 篇展开）。

## 4. 建模技巧：把现实问题写成 MIP

MIP 建模是工程核心技能，五个高频技巧：

- **大 M 法**：逻辑约束"如果 x>0 则 y=1"写成 x ≤ M·y——M 取最小可行值（太大毁数值，太小漏解）
- **指示变量**：分段线性成本（快递首重/续重）用二元变量加辅助变量线性化——"能线性化就不非线性"
- **对称性破除**：相同机器的调度问题加对称约束（第 1 台机器编号 ≤ 第 2 台）——对称性会让分支树爆炸，破除后提速数量级
- **子环消除**：TSP 类问题用"逐轮加割"（lazy constraint）而非一次性列全——04 篇割平面的应用场景
- **大 M 的数值纪律**：M 与系数同量级、避免 M 与 1 混用导致的条件数爆炸——"建模质量 = 求解速度的一半"

### 4.1 分支定界小例子：一次手算

用手算演示分支定界的完整过程（整数规划）：最大化 x + y，约束 2x + 3y ≤ 12、x - y ≤ 1、x,y ≥ 0 整数。**根节点**：解 LP 松弛得 x=3, y=2（目标 5）——松弛解恰好整数，**直接结束：这就是最优**。换一组约束让松弛解带分数：2x + 3y ≤ 11.5 时松弛解约 x=2.9, y=1.9（目标 4.8，非整数）→ **分支**：x≤2 与 x≥3 两个子问题；**子问题一**（x≤2）：松弛得 x=2, y=2.5（目标 4.5，仍分数）→ 再分支 y≤2 得整数解 (2,2) 目标 4——**当前最优（上界）4**；**子问题二**（x≥3）：松弛得 x=3, y=1.833（目标 4.833）→ 分支 y≤1 得整数解 (3,1) 目标 4——**与上界持平，无改善**；两子树的下界都不超过 4，**剪枝，全局最优 = 4**（两组解）。**这个手算展示了全部四要素**：松弛（定下界）、分支（逼格点）、整数解更新（抬上界）、剪枝（下界 ≥ 上界砍树）——一行行手算过一遍，分支定界就不再是黑盒。**实战提示**：真实求解器里这个规模的问题毫秒级完成，手算的价值在教学——把"树"画出来，你会理解为什么"上界好"（启发式）与"下界紧"（割平面）决定一切（04 篇）。

建模练习建议（把技巧变成肌肉记忆）：手写三个模型的完整 MIP 形式——**选址**（开哪些仓库：二元变量 + 需求分配：连续变量 + 大 M 连接）、**生产批量**（每期生产多少：整数变量 + 库存平衡：线性等式 + 启动成本：指示变量）、**员工排班**（谁哪天值班：二元变量 + 需求计数 + 连续天数的滑动窗口约束族）——每个模型写完都自检五个技巧是否用全（大 M 有没有最小化、指示变量有没有必要、对称性要不要破除、子环要不要惰性、系数尺度是否一致）；**能十分钟内写出并解释这三个模型，MIP 建模就算入门**——这三个模型也是面试"优化建模"的常驻考题。

> 🎯 **核心要点**：整数变量是"跃迁"——LP 变 MIP 即进入 NP 困难；背包/TSP/指派三题展示了"看似像实则异"（背包难、TSP 皇、指派易）；NP 困难不是判决书而是策略分层说明书（精确/近似/启发式按规模结构选）；分支定界的骨架是"松弛定下界、分支逼格点、剪枝控规模"，性能密码是"下界紧 + 上界好"；大 M、指示变量、对称破除、lazy 割是 MIP 建模的五大技巧——建模质量决定求解速度的一半。
