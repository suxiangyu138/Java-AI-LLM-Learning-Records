## 1. 知识体系导图

```
最优化理论（连续 → 离散 → 随机 → 智能 → 神经）
│
├── 01-起源与全景
│     优化光谱与分类学 → 与凸优化分工 → 没有免费午餐定理
│
├── 02-非凸非线性优化
│     局部方法的局限 → 全局优化（多起点/分支定界/采样）→ 2026 扩散平滑理论
│
├── 03-整数规划与组合优化
│     整数规划形式 → NP 困难性 → 背包/TSP/指派 → 分支定界
│
├── 04-割平面与求解器内幕
│     Gomory 割 → 分支切割框架 → 预处理与启发式 → Gurobi 12/HiGHS/SCIP
│
├── 05-约束规划与 CP-SAT
│     约束传播 → 回溯搜索 → CP vs MIP → OR-Tools CP-SAT（2026 冠军）
│
├── 06-图与网络优化
│     最短路/生成树/最大流/匹配 → 网络单纯形 → Dijkstra/Kruskal/Ford-Fulkerson
│
├── 07-多目标优化
│     Pareto 前沿 → 加权和/ε-约束 → NSGA-II/III → MOEA/D → 应用
│
├── 08-随机与鲁棒优化
│     两阶段随机规划 → 机会约束 → 鲁棒不确定集 → 分布鲁棒 DRO
│
├── 09-元启发式与进化算法
│     模拟退火/禁忌/遗传/差分进化/粒子群 → ALNS → 2026 代理辅助与量子启发
│
└── 10-神经组合优化与生产实践
      Neural MIP（GNN/注意力）→ MILPnet/GIN-BGE → 选型决策树 → 面试题
```

模块间依赖：01 是分类学（全体系的索引）；02-06 是确定性方法的五条主线（连续全局、整数、割平面、约束规划、图网络）；07/08 是"目标多"与"数据不确定"两个维度的扩展；09 是"不保证最优但保证找到好解"的实用派；10 收束"学习 + 求解"的 2026 前沿与生产决策。与同级 `凸优化/` 分工：那里把"凸的完备理论 + 求解器"展开到底，这里补上凸之外的全部——非凸、整数、组合、多目标、随机、元启发式；与 `线性代数/`、`概率论与数理统计/` 互为前置；与 `算法/数据结构`、`机器学习` 应用互文。

## 3. 学习路线推荐

**路线 A：搞懂"优化世界的全貌"（半天）**
01 → 03 → 06。分类学加两大经典分支（整数与图）——适合所有工程师建立"问题属于哪类、用什么工具"的直觉，看懂运筹学相关的业务选型。

**路线 B：系统学习（2-3 天，推荐）**
路线 A + 02 + 04 + 05 + 09。补上全局优化、求解器内幕、约束规划与元启发式——形成"确定性方法 + 智能方法"双工具箱。**配合 `凸优化/` 体系对照阅读**：凸的看那套，凸之外看这套。

**路线 C：AI 与算法工程师视角（面向 2026 前沿）**
路线 B + 07 + 08 + 10。聚焦多目标调优、鲁棒决策与神经组合优化——**与 `深度学习/`、`机器学习` 应用互文**，理解"学习 + 求解"融合的现状与边界。

> 💡 与知识库关系：02 篇的全局优化与 `凸优化/06` 的局部方法衔接；03/04 篇的 MIP 与求解器 `凸优化/08` 互补；05 篇 CP-SAT 是 2026 年最优约束满足工具；06 篇与 `数据结构与算法/` 的图算法重叠但视角不同（这里讲建模与网络流理论）；09 篇元启发式与 07 篇多目标常组合使用（NSGA-II 就是多目标进化算法）。

### 阅读时的三个常见误区

1. **"优化 = 凸优化"**：凸优化只是光谱上"最幸运"的一段——大多数现实问题（排产、路线、选址、设计）要么是离散的（整数规划）、要么是非凸的（全局优化）、要么是数据不确定的（随机/鲁棒）——本体系的全部篇幅都在凸之外的广袤地带（01/03/08 篇）
2. **"元启发式是万能的"**：元启发式（遗传、退火、粒子群）不保证最优、不保证收敛到同一解，2026 年的行业共识是"**先试精确方法（MIP/CP），规模撑不住再上元启发式**"——90% 的实战问题可以用求解器加建模技巧解决，元启发式是最后手段（09/10 篇）
3. **"神经网络会取代求解器"**：Neural MIP（2026 年进展迅猛）的定位是"**增强**求解器"——学习变量选择、预测边界、加速分支定界，而不是替代；Gurobi/CP-SAT 仍是事实标准，学习的角色是"求解器里的智能组件"（10 篇）

带着三个误区读完全书，会发现每一篇都在回答同一个问题：**当问题不再凸、不再连续、不再确定，优化还剩下什么**。

## 4. 核心概念速查

| 概念 | 一句话定义 | 关键事实（2026） |
|------|-----------|---------------------|
| MIP | 混合整数规划（部分变量取整数值） | Gurobi 12/HiGHS 1.14/SCIP 10 竞逐 |
| NP 困难 | 无法多项式时间求解（除非 P=NP） | TSP/背包/调度均为 NP 困难 |
| 分支定界 | 树搜索 + 上下界剪枝的精确框架 | 所有 MIP 求解器的骨架 |
| 割平面 | 用线性不等式收紧松弛解 | Gomory 割、分支切割框架 |
| CP-SAT | 约束规划求解器（OR-Tools） | 2026 MiniZinc Challenge 四金 |
| 约束传播 | 用约束缩小变量域 | 与回溯搜索结合的引擎 |
| 网络流 | 图上最大流/最小割/匹配 | 全幺模结构，LP 解即整数解 |
| Pareto 前沿 | 多目标下的非劣解集 | NSGA-II/III、MOEA/D 主流 |
| 两阶段随机规划 | 先决策后补偿的随机模型 | 样本平均近似（SAA）是主算法 |
| 鲁棒优化 | 不确定集内的最坏情况最优 | 与凸优化 SOCP/SDP 直接衔接 |
| 元启发式 | 无保证的智能搜索框架 | 遗传/退火/粒子群，最后手段 |
| Neural MIP | 用 GNN/注意力增强 MIP 求解 | MILPnet（ICLR 2026）、GIN-BGE 提速 25%+ |
| NFL 定理 | 没有免费午餐：无万能算法 | 选型的理论依据 |

> 🎯 **核心要点**：最优化理论的全部叙事压缩为一句话——**凸优化承诺"保证最优"，而现实问题的大多数（整数、非凸、不确定、多目标）拿不到这个承诺，于是有了分支定界与割平面（精确但指数）、元启发式（快但不保证）、鲁棒与随机（对付不确定）三层武器，2026 年神经网络以"求解器增强件"的身份加入战局**；与凸优化体系合在一起，才是优化的完整世界。

**"学完凸优化还要学最优化理论吗？"** 要——凸优化是"最好算的那部分"，而现实问题（排产、调度、选址、路线）的默认形态是整数与组合，属于本体系的领地；两套体系合起来才是完整的优化世界观：凸的看那套（保证最优），凸之外的看这套（妥协的艺术）。面试被问"优化"相关问题时，只懂凸、不懂整数规划，等于只学了半本教材。

**"最优化理论和算法竞赛/数据结构什么关系？"** 图与网络优化（06 篇）与算法竞赛的图论重叠，但视角不同：竞赛问"怎么算最快"，优化问"怎么建模成可解问题"——前者是算法实现，后者是问题翻译；两者的共同点是"认出结构"：竞赛认数据结构，优化认凸/图/网络/整数结构。

### 体系速读版（30 秒版）

- **为什么有它**：现实问题不凸、不连续、不确定（01 篇）
- **离散怎么办**：MIP + 分支定界 + 割平面（03/04），或约束规划 CP-SAT（05）
- **图上怎么办**：网络流与匹配（06）
- **多个目标/不确定怎么办**：Pareto（07）、随机/鲁棒（08）
- **算不动怎么办**：元启发式（09）；2026 年还有"学习增强求解器"（10 篇）
