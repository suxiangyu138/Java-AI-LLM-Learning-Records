# 多目标优化：Pareto 与进化多目标
> 现实决策几乎总是多目标的：成本、质量、时间、风险互相冲突——多目标优化不追求"唯一最优"而追求 Pareto 前沿（非劣解集合）；2026 年的主流工具仍是进化多目标（NSGA-II/III、MOEA/D），但前沿的"解集"与标量化方法的组合正在成为工业实践。

## 1. 多目标问题的本质：Pareto 最优与前沿

多目标优化（MOP）：同时最小化 m 个目标 f₁(x),...,fₘ(x)——通常不存在"全目标都最优"的解，而是**权衡的集合**。核心概念：

- **支配（dominance）**：解 A 支配解 B，当且仅当 A 在所有目标上不劣于 B 且至少一个目标严格更优——"A 全面碾压 B"
- **Pareto 最优**：不被任何解支配的解；所有 Pareto 最优解的集合叫 **Pareto 前沿**（Pareto frontier）——**决策者在前沿上做最终取舍（哪个权衡可接受），优化者负责把前沿"算出来"**
- **前沿的几何**：两个目标时前沿是一条"左下边界曲线"；三个目标是曲面；高维（>3）前沿是流形——**维数越高，"算前沿"越贵**（前沿体积指数增长）

**为什么不能"加权求和解决一切"**：加权求和（min Σwᵢfᵢ）只能得到前沿上的**凸部分**——凹部分的前沿点永远不是任何加权和的解（"前沿有凹痕时权重法失效"）；且权重是决策者的先验偏好，加权求解等于"替决策者做选择"。多目标方法的两种使命：**生成前沿供人选择**（进化方法）与**按偏好直接求解**（标量化方法）。

## 2. 标量化方法：把多目标"翻译"成单目标

**标量化（scalarization）**：构造单目标代理函数，用成熟单目标求解器（MIP/凸优化）求解。四个经典：

- **加权和**：Σwᵢfᵢ——最简，但只能覆盖凸前沿（上面的缺陷）
- **ε-约束法**：保留一个目标，其余转成约束（fᵢ ≤ εᵢ）——**能生成凹前沿部分**，是"必须用 MIP/凸求解器"场景的首选（约束是现成的）
- **加权切比雪夫（加权 Chebyshev）**：min maxᵢ wᵢ|fᵢ - zᵢ*|（z* 是理想点）——**能覆盖全部前沿（含凹部）**，且能定位"贴近理想点的解"（决策者偏好"接近理想"的合理解读）
- **字典序**：先优化最重要的目标，再在保持其最优的约束下优化次目标——工程上"成本优先、其次时间"的决策就是字典序

标量化的价值：**与精确求解器无缝衔接**（多目标 MIP 的实用路径是"ε-约束 + 求解器循环"）；局限是**一次求解只给一个点**，要覆盖前沿需循环求解多次（每次换权重/ε）。

## 3. 进化多目标：NSGA-II/III 与 MOEA/D

当问题非凸、不可导、黑盒（仿真评估）时，进化算法是生成前沿的主力：

- **NSGA-II（2002）**：**非支配排序**（按支配层级分组）+ **拥挤距离**（同层内保持解的多样性）——选择压力同时照顾"靠近前沿"与"铺满前沿"；至今仍是工业默认
- **NSGA-III（2014）**：用**参考点**替代拥挤距离——高维目标（≥3）下保持前沿均匀性，是 2026 年高维多目标的事实标准
- **MOEA/D（2007）**：把多目标分解为若干单目标子问题（加权切比雪夫），子问题间协作进化——**"分解"思想让它在高维与非凸上都强**
- **2026 状态**：算法框架成熟（pymoo/Platypus 库开箱即用），研究热点转向"代理模型辅助"（仿真昂贵时用高斯过程近似评估，与 09 篇的代理辅助进化同源）与"决策者偏好嵌入"（交互式方法）

**进化的局限**：无收敛保证、评估次数需求随维度爆炸、前沿的"均匀覆盖"在高维是伪命题——工程上"进化 + 标量化混合"（先用进化找前沿轮廓，再用 ε-约束精修决策点）是 2026 年工业实践的主流。

## 4. 工程应用与选型：三个真实场景

- **超参数调优（机器学习）**：精度 vs 推理时延 vs 内存——**多目标贝叶斯优化**（Optuna 的 MOTPE）是 2026 年 ML 工程的标准工具，本质是"代理模型 + 标量化"的组合（不是进化）
- **资源分配与调度**：成本 vs 碳排放 vs 交付周期——**ε-约束 + MIP**（约束是现成的，求解器保证最优）；三目标以上再考虑 NSGA-III
- **工程设计（黑盒仿真）**：性能 vs 能耗 vs 成本——仿真昂贵，**代理辅助进化**（Kriging/GP 代理 + NSGA 变体）是唯一现实选择

选型口诀（2026）：**可求导/可建线性模型 → ε-约束 + 精确求解器；黑盒且评估便宜 → NSGA-II/III 或 MOEA/D；黑盒且评估昂贵 → 代理辅助进化或多目标贝叶斯；目标是"决策者已有偏好" → 直接标量化**——多目标优化的工程答案从来不是"一个算法"，而是"目标数量 × 问题结构 × 评估成本"的组合决策。

### 4.1 超参数调优的多目标实战

机器学习超参数调优是 2026 年工程师接触多目标优化最频繁的入口：**问题**——训练模型调（学习率、层宽、丢弃率、批量大小），同时想要"高精度 + 低推理时延 + 小显存占用"——三个目标天然冲突。**为什么默认方案不是 NSGA**：训练评估昂贵（一次训练几小时），进化需要上百次评估——**多目标贝叶斯优化（Optuna 内置的多目标 TPE）是 2026 年的标准答案**：代理模型预测"精度-时延-显存的 Pareto 前沿"，每次只评估"最有希望改善前沿"的配置（第 4 节"评估昂贵 → 代理辅助"）；**什么时候用 NSGA**：评估便宜（小模型、快速训练）、或需要探索大而奇异的配置空间（神经架构搜索的低成本场景）——进化对搜索空间的覆盖更野；**工程姿势**：先用多目标贝叶斯找到前沿轮廓（前 50 次评估），再对"前沿上的配置"做验证集精调；**前沿的使用**：Pareto 前沿给决策（部署选时延优先还是精度优先），不是"一个最优"——**把前沿画出来（时延-精度散点）是向老板汇报的标准图**；**与单目标调优的关系**：单目标（只调精度）是前沿的特例——多目标一次调优覆盖所有部署场景，省的是"每种场景重调一遍"的时间。**三个反直觉经验**：目标越多前沿越难铺满——超过 4 个目标时别追求完整前沿，用加权和或参考点（NSGA-III 的用途）定向求解；时延类目标常被代理模型低估——实际部署前必须真实测量（代理误差在边界点最大）；调优预算要写进实验记录——多目标方法没有自然停止点，预算管理比算法选择更重要。**多目标调优的失败案例几乎都死于"预算失控"而非"算法不对"**。

多目标方法的边界最后提醒：**"前沿完整"是伪目标**——真实前沿不可知（非凸黑盒）、采样覆盖有偏（进化偏好凸部）、高维前沿无法可视化（3 目标以上画不出图）——工程上"够用的前沿"定义是"决策者在前沿上能找到满意的权衡点"；**Pareto 前沿只是决策支持，不是决策本身**——最终取舍（要精度还是时延）永远是人做的，算法只负责"把选项摆出来"；这个定位决定了多目标优化的交付物：**前沿图 + 每个前沿点的配置明细 + 灵敏度说明**，而不是"一个最优解"。

> 🎯 **核心要点**：多目标优化不求唯一最优而求 Pareto 前沿——支配关系定义非劣解，前沿让决策者做最终权衡；加权和只能覆盖凸前沿，ε-约束与加权切比雪夫能覆盖凹部（且与精确求解器无缝衔接）；NSGA-II/III 与 MOEA/D 是黑盒/高维场景的进化主力（2026 年转向代理辅助与偏好嵌入）；工程选型按"目标数 × 结构 × 评估成本"组合：线性结构 ε-约束加 MIP、黑盒便宜 NSGA、黑盒昂贵代理辅助——多目标决策是"优化 + 决策者"的协作，不是算法独舞。
