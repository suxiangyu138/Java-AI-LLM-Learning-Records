# 凸函数：定义与性质
> 凸函数是凸优化的心脏：定义只有一句"图像位于割线下方"，但一阶条件（切线是全函数的下界）、二阶条件（Hessian 半正定）、Jensen 不等式与共轭函数四件套，让它成为可验证、可操作的强大工具。

## 1. 定义与三种等价刻画

函数 f: Rⁿ→R 是凸的，当且仅当定义域是凸集，且对任意 x,y 与 θ∈[0,1]：

```text
f(θx + (1-θ)y) ≤ θf(x) + (1-θ)f(y)
```

几何直觉：**函数图像上任意两点的连线（割线）不低于图像本身**——图像"鼓起来"（像碗）。这个定义有三个工程上更实用的等价刻画：

- **一阶条件**（可微时）：对定义域内任意 x,y，f(y) ≥ f(x) + ∇f(x)ᵀ(y-x)——**切线/切平面是全函数的下界**（全局下界，不是局部的！）。这条性质是一切"用线性近似迭代"的算法（梯度下降）收敛证明的起点：每步都有可验证的下界
- **二阶条件**（二阶可微时）：Hessian 矩阵 ∇²f(x) 半正定（所有特征值 ≥0）。这是**判定凸性最常用的工具**：算 Hessian、检查特征值/主行列式。线性函数 Hessian 为零（凸）、二次函数 xᵀPx 凸当且仅当 P 半正定、指数函数 e^x 的 Hessian 恒正（凸）、log 函数凹
- **Jensen 不等式**：f(E[X]) ≤ E[f(X)]——凸函数作用于期望 ≤ 期望作用于凸函数。这是信息论（熵的凹性）、概率论（矩不等式）、统计（EM 算法）的核心不等式，也是"为什么凸函数是天然的损失函数"的原因

一阶条件的威力怎么强调都不为过：**它是"如何证明一个算法收敛"的万能起点**——梯度下降每步保证目标值至少下降某个量，靠的就是"切线是全局下界"。

## 2. 保凸运算：函数版组合语法

与 02 篇的集合保凸运算平行，凸函数也有组合规则库（建模时最实用）：

- **非负加权和**：凸函数的非负线性组合是凸的——损失 = 数据项 + 正则项（λ 倍凸项）天然凸
- **与仿射映射复合**：f(Ax+b) 保持凸——**几乎所有 ML 损失都是"凸函数 ∘ 线性层"**：逻辑回归的 log-sum-exp 与线性预测的组合正是如此
- **逐点取最大**：max(f₁,...,fₙ) 凸——"最坏情况"模型（鲁棒优化、SVM 的 hinge 损失 max(0, 1-y·wᵀx)）天然凸
- **透视复合**：g(x,t)=tf(x/t) 凸（t>0）——相对熵、KL 散度、透视函数的凸性由此而来
- **共轭函数**：f*(y)=sup_x(yᵀx - f(x)) 恒为凸函数（无论 f 是否凸）——对偶理论的主角

组合规则的实战意义：**建模时不必证明每个新函数的凸性，只需把它拆成"已知凸构件 + 保凸运算"**——这正是 CVXPY 的 DCP（Disciplined Convex Programming）规则自动校验的原理（08 篇）：编译器检查你的表达式树是否符合这套语法，不符合就报错"这不是凸的"。

## 3. 共轭函数与拟凸函数：两个重要扩展

**共轭函数** f*(y)=sup_x(yᵀx-f(x))：给定"斜率"y，求最大"截距"。几何上，共轭函数用切线族重新编码了函数信息——**f 与 f* 互相唯一确定（凸闭函数时 f**=f）**。共轭在工程上的三个用途：拉格朗日对偶的抽象（对偶函数是"最小化部分共轭"）、约束的松弛化（用共轭重写目标）、ML 里的 Fenchel 对偶（SVM 的核技巧就是对偶形式的副产物）。**学会"用共轭重写问题"是进阶凸优化的核心技能**——很多看起来非凸的目标，共轭之后变成可处理的凸形式。

**拟凸（quasiconvex）函数**：放宽凸性——只要求下水平集 {x | f(x)≤α} 是凸集（图像像"丘陵"而非"碗"，可能有多个局部极小但不影响水平集凸性）。拟凸函数没有一阶条件的全局下界，但可以二分搜索求解（每步验证一个水平集是否与可行域相交）——**工程价值：鲁棒最小最大问题、分式线性目标（线性分式规划）都是拟凸而非凸**，识别"这是拟凸、可以用二分"能省大量弯路。

## 4. 从函数到问题：凸问题的完整定义

把 02 篇的集合与本节函数合起来，凸优化问题的标准形式：

```text
minimize    f₀(x)
subject to  fᵢ(x) ≤ 0, i=1..m     （不等式约束，fᵢ 凸）
            Ax = b                （等式约束，线性）
```

三个构成要件：**目标函数凸、不等式约束函数凸、等式约束线性**（线性等式是"仿射"，只有它不会破坏可行域凸性）。这个标准形式是 04 篇所有问题族（LP/QP/SOCP/SDP）的母版——每一族都是"特定形式的 fᵢ 与 f₀"。**判断一个实际问题是否凸的流程**：把每个函数拆成构件（线性/二次/指数/范数/…），查保凸运算表，全部是凸组合 → 问题凸；有任何一步违反（例如等式约束里出现非线性）→ 问题非凸，需要松弛或换工具（10 篇）。

### 4.1 从函数到算法的桥梁：光滑性与强凸性

判断一个凸函数"好不好优化"，除了凸性还有两个参数——**光滑性**与**强凸性**，它们是 06 篇所有收敛率分析的原料：

- **L-光滑**：梯度 Lipschitz 连续——"山坡不会突然变陡"。梯度下降的步长安全上限是 1/L，收敛率里的条件数正是光滑常数与强凸常数的比值
- **μ-强凸**：函数值不低于"切线 + 二次项"——"山谷有确定的最低点曲率"。强凸保证最优解唯一、一阶方法线性收敛；l₂ 正则就是给问题"注入强凸性"的标准手段（把弱凸的问题变成强凸）
- **两个极端**：光滑但不强凸（只有线性正则）——收敛慢但可接受；既不光滑又不强凸（l₁ 或更差的函数）——必须换近端/次梯度工具（07 篇近端算子）

工程判断：**看到"正则项"就想到"强凸性注入"，看到"步长"就想到"1/L 上限"，看到"收敛慢"就先查条件数**——这三个参数的诊断价值超过 90% 的调参技巧。2026 年的训练配方（AdamW + warmup）里，warmup 的作用之一就是"在光滑常数估计不准时保护早期迭代"——凸分析的语言已经渗透到训练工程的每一行。

### 4.2 常用函数凸性速查

建模时直接查表的常用函数：**凸**——线性函数、二次函数（矩阵半正定时）、对数求和指数（log-sum-exp）、范数、负熵、相对熵与 KL 散度、最大值函数、Huber 损失；**凹**——log、熵、几何平均、行列式的对数（半定规划的对数障碍）；**既非凸也非凹**——正弦、绝对值的三次方、大部分神经网络输出。判定时注意两个高频陷阱：**"负号翻转折"**——凸函数取负是凹函数，凹函数取负是凸函数（log 是凹的，负对数似然是凸的——逻辑回归的损失正是"凹函数取负"的实例）；**"复合方向"**——凸函数与凸函数的复合不一定凸（凸函数复合线性映射才保持凸），凸函数与凹函数的复合（log 套 exp）反而凸。**这张表加保凸规则，能覆盖九成建模场景**——剩余的一成用数值试验验证凸性（沿随机直线取样本检查函数图像）。

最后一句提醒：**凸性的验证要落实到"定义域"上**——很多函数在扩展定义域上凸、在受限定义域上不凸（或反之），CVXPY 的 DCP 检查会自动处理定义域，手算时最容易漏掉的就是这一步（例如 log 函数只在正数定义域上有意义，建模时忘加 x>0 约束会导致求解器报错或静默出错）。

> 🎯 **核心要点**：凸函数的三件套——一阶条件（切线是全局下界，算法收敛证明的起点）、二阶条件（Hessian 半正定，判定凸性的最实用工具）、Jensen 不等式（凸函数与期望的天然亲和）；保凸运算（非负和/仿射复合/逐点最大/透视/共轭）提供组合式判凸语法，CVXPY 的 DCP 规则就是它的自动化；共轭函数是对偶的主角，拟凸函数是"没有全局下界但可二分"的实用放宽；凸问题的标准形式（凸目标 + 凸不等式约束 + 线性等式约束）是全部问题族的母版。
