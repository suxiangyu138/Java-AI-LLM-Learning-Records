# 凸集：几何基础
> 凸优化的可行域必须凸，而"凸"首先是几何概念：集合里任意两点的连线还落在集合内——这个看似天真的条件，加上"分离超平面"这把几何手术刀，构成了整个凸分析的地基。

## 1. 三类基本集合：仿射集、凸集、锥

从线性代数出发，三组概念层层递进：

- **仿射集**：过任意两点的**直线**仍在集合内。几何直觉：集合是一个"线性子空间 + 平移"。直线、平面、超平面都是仿射集；仿射集是"解集"（Ax=b 的解集总是仿射的）
- **凸集**：过任意两点的**线段**仍在集合内。几何直觉：集合"没有凹陷"。线段、多边形、球、椭球、半空间都是凸集；**凸集 = 仿射集的"线段版"**——放宽了"直线"到"线段"，允许有边界
- **凸锥**：对任意 x∈C 与 θ≥0，θx∈C（对非负缩放封闭），且同时是凸集。直觉：从原点出发的"无限扇形"。非负象限、半定矩阵锥（S⁺ⁿ）、二阶锥都是凸锥

用定义验证集合凸性的标准流程（对新手最重要的一步）：任取两点 x,y，构造 z=θx+(1-θ)y，代入集合约束验证是否恒成立。**大多数集合的凸性证明只需要这一招**——例如半空间 {x | aᵀx ≤ b}：aᵀ(θx+(1-θ)y) = θaᵀx+(1-θ)aᵀy ≤ θb+(1-θ)b = b，成立。而椭球、多面体、锥的凸性都是这一招的变体。

### 1.1 为什么可行域必须凸

凸问题的定义要求可行域是凸集，原因在 01 篇承诺一里已经埋下：**"局部=全局"的证明依赖"可行域内任意两点的连线还在可行域内"**——算法在可行域里走直线移动，凸性保证移动路径不越界。反过来，如果可行域凹陷（例如"圆环"可行域），即使目标函数是凸的，也可能存在多个局部最优——**凸集是凸问题的地基，地基不凸，上面的理论全部失效**。

## 2. 凸包与凸组合：把非凸集合"凸化"

给定任意集合 S（可能非凸），定义它的**凸包 conv(S)**：S 中任意有限个点的凸组合（加权平均，权重非负且和为 1）的全体。凸包是"包含 S 的最小凸集"，是把非凸集合凸化的标准操作——**凸化后的问题是最佳凸近似**，其最优值是非凸问题最优值的一个下界（对最小化问题），这就是 10 篇"凸松弛"的几何来源。

**Carathéodory 定理**（直觉版）：n 维空间里，凸包中的任意点都能用至多 n+1 个 S 中的点表示——这个"维数 + 1"的界是凸包理论最精妙的结果之一，它保证了凸组合的表示不需要无限项。在机器学习里，凸包的直觉无处不在：**概率单纯形（概率分布的全体）是标准基向量的凸包**，混合模型的"权重为凸组合"就是在这个凸包里取值。

## 3. 保凸运算：判断凸性的"组合语法"

逐点验证凸性很笨重，工程上更实用的是**保凸运算**——从已知凸集构造新凸集的规则库：

- **交集**：任意个凸集的交集是凸集（最常见的构造：可行域 = 多个约束半空间的交集，天然凸）
- **仿射变换与逆变换**：凸集在仿射映射（Ax+b）下的像与原像都是凸集——投影、缩放、平移不破坏凸性
- **透视函数**：(x,t) → x/t（t>0）把凸集映为凸集；透视与线性分数变换是"分式线性规划"能保持凸性的原因
- **直接和 / 闵可夫斯基和**：两个凸集的并集不一定凸，但**和集**（x₁+x₂）一定凸——"凸 + 凸 = 凸"在集合层面的版本

这套语法对应着 03 篇"凸函数的保凸运算"——**集合与函数两个层面各有同一套组合规则**，建模时先用已知构件（半空间、球、锥、多面体）搭集合，再用保凸运算验证组合，比逐点验证高效得多。

## 4. 分离超平面与支撑超平面：凸集的"几何手术刀"

凸集理论最深刻的工具是**分离定理**：如果两个凸集不相交（或一个点是闭凸集外的点），那么存在一个超平面把两者严格分开——**超平面一侧是集合 A，另一侧是集合 B**。几何直觉：两个"鼓起来的"互不相碰的凸体之间，总能插入一块"平板"。

分离定理的三大应用：

- **支撑超平面**：过凸集边界点的任意支撑面，凸集完全位于其一侧——"凸集 = 其所有支撑超平面半空间的交集"，这是凸集的另一种等价刻画
- **对偶理论的基石**：05 篇的拉格朗日对偶、KKT 条件、Farkas 引理（不可行性检测），全部建立在分离定理上——**对偶不是代数技巧，而是几何分离**：原问题与对偶问题的最优值之差，正是"两块凸体之间的距离"
- **几何直觉训练**：判断"两个凸集是否相交"等价于"是否存在分离超平面"——把代数问题翻译成几何问题，是凸分析最重要的思维方式

## 5. 高维几何直觉：球、椭球与多面体

凸集的几何直觉建立在三件"标准家具"上：**球**（范数约束，各向同性——梯度下降一步到位的理想地形）、**椭球**（矩阵二次约束，主轴方向被拉伸或压缩——条件数就是最长轴与最短轴之比）、**多面体**（有限个半空间的交集——线性规划的可行域，顶点数可以指数多但"角点"结构天然）。工程上三条直觉：

**第一，条件数是凸几何的核心数字**。椭球的"扁"程度直接决定梯度下降的步数（06 篇），预处理（把椭球"吹圆"）等价于换坐标系，牛顿法每步都在做这件事——**读论文看到 condition number，就是在看"这个问题在几何上有多难"**。

**第二，多面体的顶点等于组合结构**。线性规划的最优解总在顶点上（"角点"定理），单纯形法沿着顶点走——组合优化（网络流、分配问题）的"整数"味道藏在多面体的顶点里；整数规划的线性松弛（丢掉整数约束）就是在多面体上找"最近的顶点"。**看到"多面体"就想"顶点"，看到"顶点"就想"组合"**，这条直觉贯穿优化与组合两门课。

**第三，高维的直觉经常骗人**。二维的"球"在高维里几乎全部体积集中在球壳表面（维度灾难的几何根源）；两个随机高维向量几乎必然正交（高维稀疏性的来源）——凸优化的大规模时代（百万变量）要求把"二维几何直觉"升级为"高维概率直觉"，这既是优化也是机器学习的共同功课。

### 5.1 凸集判定实战：五个例子

用第 1 节的"任取两点代入"方法练五个典型例子：**例一**，半空间是凸的（前面已证）；**例二**，多面体（有限半空间交集）凸——由保凸运算"交集"直接得出；**例三**，单位球凸——范数三角不等式两行证明；**例四**，整数点集（棋盘格）**不是**凸集——两点连线上的中点不在集合内，这正是整数规划困难性的几何来源；**例五**，单位圆环（内外圆之间）**不是**凸集——但注意"补集"视角：圆环可写成两个凸集之差（外球减内球），引出"凸差集"（DC 集）的概念（10 篇 DC 分解的几何版）。五个例子覆盖了判定的三种路径：直接代入、保凸运算、找反例——**实战中先试"找反例"（最快），再试保凸运算（最省力），最后才逐点验证**。

> 🎯 **核心要点**：凸集是"任意两点的线段仍在集合内"的集合，仿射集/凸集/凸锥三级递进；验证凸性的标准流程是"任取两点代入约束"；凸包是把非凸集合凸化的最小凸近似（凸松弛的几何来源）；保凸运算（交集/仿射/透视/和集）提供组合式判凸语法；分离定理是凸集理论的手术刀——它证明"两块互不相交的凸体间必可插入平板"，进而导出支撑超平面刻画与整个对偶理论，凸分析的深度由此展开。
