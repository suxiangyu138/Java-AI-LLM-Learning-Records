# 前沿与生产实践：非凸的凸化与深度展开
> 凸优化的前沿不是"更快的凸算法"，而是两件事：把更多非凸问题**凸化**（松弛、DC 分解、参数化），以及让求解器本身**可学习**（深度展开）——2026 年，优化与深度学习的边界正在双向消失。

## 1. 凸化工具箱：非凸问题的四条出路

面对非凸问题，2026 年工程界有四条成熟路线：

- **凸松弛**（09 篇已述）：放宽约束或替换目标——l₁ 换 l₀、核范数换秩、SDP 松弛组合问题。有近似保证（0.878 等），是"理论最干净"的路线
- **DC 分解（Difference of Convex）**：把非凸函数写成两个凸函数之差 f = g - h，用凸化迭代（DCA，DC Algorithm）交替求解——**凡是"凸 - 凸"形态的问题（很多非凸损失、多变量耦合项）都能进这个框架**；DCA 每步只解凸子问题，实践上常收敛到很好的局部解
- **分块坐标下降（BCD）**：一次只优化一个变量块（其余固定）——非凸整体被"逐块凸化"；**交替最小二乘（ALS，矩阵分解/推荐系统的引擎）、期望最大化（EM）**都是 BCD 的特例；"整体非凸、每块凸"是工程里最常见的隐藏结构
- **参数化/变量替换**：把非凸项通过单调变换变成凸（GP 的对数变换 04 篇）或引入辅助变量（e.g. x²=y, y≥0 把二次等式约束凸化）——技巧性最强、收益也最大

选型顺序：**先问"能不能整体凸化"（GP/变量替换）→ 再问"能不能松弛"（有界则松弛）→ 然后问"能不能分块"（BCD/EM）→ 最后才是 DC 与启发式**——"凸化的层级"决定了问题从"难"到"可算"的距离。

## 2. 深度展开：把迭代算法变成神经网络

2026 年最热的前沿是**深度展开（Deep Unfolding）**：把迭代优化算法的每一步"展开"成神经网络的一层，用数据学习步长、正则参数甚至迭代结构：

- **原理**：近端梯度法的每一步 = "梯度步 + 近端步"，恰好是一个网络层（近端算子可微化后就是激活函数）——把 K 步迭代展开成 K 层网络，**用反向传播学习"最优的超参数序列"**（步长、正则强度、甚至阈值），再前向一次就是"学习过的优化"
- **代表工作（2026）**：Deep FlexQP（ICLR 2026）——用 ℓ₁ 弹性松弛 + LSTM 反馈策略自动调节 QP 求解参数，在组合优化/分类/回归基准上超越现有 learned QP 求解器，可扩展至上万变量；嵌入 SQP 后求解非线性轨迹优化**比 OSQP 快 4-16 倍**并大幅减少安全违规
- **工程含义**：**"求解器"从固定算法变成"可微调参的模型"**——同一个问题族（MPC 控制、信号恢复、稀疏重构）用历史数据训一个展开网络，推理时一次前向即可，把"每次求解"变成"查表级"成本

边界同样要讲清楚：深度展开的网络是**针对问题族学习**的（换问题族要重训）；理论保证（收敛性、最优性）目前弱于经典算法，高精度需求场景仍需内点法兜底——**展开方法抢的是"实时 + 近似"赛道**（MPC、在线恢复、嵌入式推理）。

## 3. LLM 与优化工具：2026 年的建模革命（及其边界）

LLM 对优化工程的影响是 2026 年最实际的变量（08 篇已详述），此处收束三点：**能做**——自然语言 → CVXPY 草稿、求解失败（不可行/数值问题）的调试辅助、对偶解的业务解读；**不能做**——算法突破（底层仍是 MOSEK/SCS/Gurobi）、数值可靠性（幻觉约束静默出错）、业务语义验证（领域专家不可替代）；**做对的前提**——懂 DCP（识别 LLM 生成的伪凸约束）、懂数值（病态缩放检查）、懂对偶（验证 LLM 对影子价格的解释）。**结论：2026 年"LLM 生成 + 工程师验证"是最优工作流，工程师的验证能力来自本体系 01-08 篇。**

## 4. 生产实践清单：十个可执行建议

1. **建模纪律**：先用 04 篇"结构最硬的约束"定问题家族，再选求解器；能窄不宽
2. **凸性自检**：每个新损失/约束写下来后跑一遍 DCP 检查（CVXPY 一行），非凸立即知道
3. **预处理优先**：问题缩放、变量归一、去冗余约束——先预处理再换求解器
4. **对偶必读**：任何约束优化的解，务必看对偶值（影子价格）——业务瓶颈的免费诊断
5. **选型基准**：同问题跑 HiGHS/MOSEK/SCS 三件套对比精度与时间（CVXPY 换求解器一行代码）
6. **数值体检**：检查条件数、求解器返回状态（optimal/infeasible/unbounded），不可行时用不可行性分析定位矛盾约束
7. **规模预判**：SDP 别超过千级、LP/QP 百万级、更大规模转 ADMM/一阶（04/07 篇）
8. **LLM 三保险**：DCP 检查 + 小数据试算 + 领域审查（08/10 篇红线）
9. **跟踪前沿**：CVXPY Workshop 的求解器基准、ICLR/NeurIPS 的深度展开工作（2026 年 Deep FlexQP 值得跟进）

### 4.1 何时该用凸优化：决策检查表

把本体系收束成一个可执行的决策检查表（项目立项与面试都能用）：

**该用凸优化**（多数命中）：问题有清晰的目标函数与约束（可写数学形式）；目标与约束是凸构件组合（03 篇保凸表查一遍）；规模在求解器甜区（线性二次规划百万级、二阶锥十万级、半定千级，04/07 篇）；需要"可验证的最优"或"灵敏度分析"（对偶值驱动决策，05 篇）。

**不该用凸优化**（任一点命中则换路线）：本质组合爆炸且无凸松弛保证（整数规划硬核场景→分支定界）；目标函数无可用的凸近似（黑盒仿真、博弈均衡→元启发式或采样）；规模超出所有凸算法（超大半定规划→低秩分解或启发式）；只需要"够用就行"且问题太小（几十行代码的贪心，凸建模的边际成本不值）。

**模糊地带的三条出路**：凸松弛加舍入（有界就做）；凸化加局部搜索（DC/分块坐标下降，第 1 节工具箱）；把凸子问题嵌入更大的启发式框架（组合搜索里的线性规划子问题——**分支定界的下界就是线性松弛**，凸优化在整数规划里当"下界引擎"用）。**检查表的意义：不把凸优化当"万能钥匙"，也不当"理论玩具"——它是一把用得最多的手术刀，但什么时候开刀，得先看病人**。

> 🎯 **核心要点**：凸优化的前沿是双向的——把更多非凸问题凸化（松弛/DC/分块/变量替换四级选择）与让求解器可学习（深度展开：迭代算法变神经网络，Deep FlexQP 2026 年比 OSQP 快 4-16 倍，抢"实时+近似"赛道）；LLM 把建模门槛压到分钟级但三条红线（幻觉约束/数值病态/语义偏差）要求三保险；生产实践十条纪律的核心是"建模纪律 → 预处理 → 对偶解读 → 数值体检"的闭环——凸优化的真正战场，始终在"认出凸结构"的建模能力上。
