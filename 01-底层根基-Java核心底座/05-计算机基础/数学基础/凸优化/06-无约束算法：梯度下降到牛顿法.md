# 无约束算法：梯度下降到牛顿法
> 无约束优化是全部算法的基础课：梯度下降用一阶信息线性收敛、牛顿法用二阶信息二次收敛、L-BFGS 在两者之间做工程权衡——收敛率的数量级差异，就是"为什么换算法"的全部理由。

## 1. 线搜索与梯度下降：最朴素也最耐用的算法

**梯度下降**（GD）的更新规则：x_{k+1} = x_k - t_k ∇f(x_k)——沿负梯度方向（下降最快的方向）走步长 t_k。两个工程问题：**步长怎么定**（线搜索：回溯法 Armijo 条件——不断减半步长直到目标值充分下降；或精确线搜索：一维最小化）、**收敛多快**（光滑凸函数：线性收敛，误差按因子（1-1/κ）衰减，κ 是函数的条件数）。

关键洞察：**收敛速度由条件数 κ（Hessian 最大/最小特征值比）决定**——κ=1（完美球形）时一步到位；κ=1000（扁椭球）时需要约 1000 步才降一个数量级误差。这就是"梯度下降慢"的数学根源：**它不是不收敛，而是被问题的"形状"拖慢**。由此引出两大改进方向：**加动量**（动量法/Nesterov 加速，把收敛因子从 (1-1/κ) 提升到 (1-1/√κ)，这是"加速"的质变——Nesterov 加速在光滑凸问题上达到最优下界，任何一阶方法都超不过它）与**换坐标系**（预处理：用对角缩放或曲率信息校正梯度方向，即走向二阶方法）。

## 2. 牛顿法：用曲率校正方向

**牛顿法**：x_{k+1} = x_k - [∇²f(x_k)]⁻¹∇f(x_k)——用 Hessian 的逆"校正"梯度方向。几何直觉：**梯度下降在椭球山谷里走"之字形"，牛顿法把椭球"拉伸成球"再走**。两大特性：

- **收敛率质变**：局部二次收敛（误差平方级衰减：0.1 → 0.01 → 0.0001），只需几步就达到机器精度——梯度下降要几百步的事，牛顿法 5-10 步完成
- **代价对称**：每步要算 Hessian（n² 存储）并解线性系统（n³ 计算）——**n 大时牛顿法不可行**，这是"为什么大问题不用牛顿"的全部原因

工程上的分水岭：**小问题（n≤1000）用牛顿/拟牛顿，大问题（n≥10⁵）用一阶方法**。2026 年这个分水岭依然清晰：凸小中规模问题（L-BFGS）与大规模 ML 训练（SGD 家族）分属两个世界，中间地带（n=10³-10⁵）由拟牛顿与共轭梯度填补。

## 3. 拟牛顿与共轭梯度：两个折中方案

**L-BFGS（Limited-memory BFGS）**：不显式构造 Hessian，只维护最近 m 步的梯度差（m 通常 5-20），用它们近似"Hessian 逆 × 梯度"——**复杂度降到 O(n·m)，收敛率接近牛顿法**（超线性收敛）。这是"免费午餐"最典型的工程案例：以不到牛顿法 1% 的每步成本，获得接近牛顿法的收敛。2026 年的适用场景依然明确：**凸小中规模问题、逻辑回归/CRF 等经典模型的训练默认选型**（SciPy 的 minimize(method='L-BFGS-B') 是事实标准入口）。

**共轭梯度（CG）**：针对二次目标（或牛顿法的内层系统）设计——沿"共轭方向"走，n 步内收敛到精确解（无舍入误差时）。两个角色：**直接解大规模正定线性系统**（比稀疏 Cholesky 内存友好）与**牛顿法的内层求解器**（牛顿-CG/截断牛顿：不构造 Hessian，只用 Hessian×向量积，配合自动微分可处理大规模）。**CG 是"大问题里偷用二阶信息"的桥梁**——TRON、L-BFGS 的矩阵向量积变体都受益于此。

### 3.1 收敛率对比表（光滑凸函数，条件数 κ）

| 算法 | 每步成本 | 收敛率 | 适合规模 |
|------|:---:|:---:|:---:|
| 梯度下降 | O(n) | 线性 (1-1/κ) | 大规模（简单） |
| Nesterov 加速 | O(n) | 线性 (1-1/√κ) | 大规模（理论最优） |
| 共轭梯度 | O(n) | 线性（二次目标 n 步精确） | 中大规模（线性系统） |
| L-BFGS | O(n·m) | 超线性 | 中规模（工程甜点） |
| 牛顿法 | O(n³) | 二次 | 小规模（最高精度） |

## 4. 工程选型：按规模与精度定价

无约束算法的选型决策树（2026 年实践）：

- **n ≤ 10³ 且要高精度**：牛顿法（SciPy `minimize` 的 `Newton-CG`/`trust-ncg`）
- **n ≤ 10⁵ 且函数光滑**：L-BFGS（默认首选——逻辑回归、岭回归、CRF 训练的事实标准）
- **n ≥ 10⁵ 或样本巨大**：SGD 家族（09 篇展开——随机梯度把每步成本从 O(n) 降到 O(1)，是机器学习训练的唯一选择）
- **二次目标 + 大规模**：共轭梯度（或预处理 CG）
- **非光滑（l₁ 正则）**：近端梯度/FISTA（07 篇近端算子——梯度下降在非光滑点失效，投影/近端是扩展）

一个反直觉但重要的工程事实：**"更高级的算法"不总是更好**——梯度下降的鲁棒性（对噪声、对参数不敏感）让它在大规模场景反而比精细算法稳；L-BFGS 对非光滑项会震荡；牛顿法对病态 Hessian 直接崩溃。**选型先看规模与光滑性，再看收敛率**，这是"算法比较"最容易被忽视的第一课。

### 4.1 一个直观的实验：条件数如何杀死梯度下降

用二维二次函数做个思想实验：Hessian 为对角矩阵（条件数 1000 的"扁椭球"，02/03 篇的几何）。梯度下降的行为：在"陡"的方向（曲率大的轴）大步来回震荡，在"缓"的方向（曲率小的轴）缓慢爬行——**之字形路径**。收敛因子约 0.999：每步误差只降 0.1%，降一个数量级需要约 2300 步。

三个改进的实验对照：**对角线缩放**（每坐标除以曲率，条件数变为 1，一步到位——这就是"预处理"的本质，也是 AdaGrad/Adam 逐坐标自适应的先声，09 篇）；**Nesterov 动量**（因子提升到约 0.968，约 71 步降一个数量级——加速近 32 倍，一阶方法的理论极限）；**牛顿法**（一步精确到达极小点，二次收敛的极端体现）。**同一个问题，三个算法的差距是 2300 步 vs 71 步 vs 1 步**——这个数量级对比就是"为什么选算法"的全部理由。2026 年深度学习训练里"学习率分块设置"（特征尺度差异大）与"warmup 防早期震荡"，本质都是在对抗"隐式条件数"——**凸优化的几何直觉直接解释深度学习的调参现象**。

### 4.2 一阶 vs 二阶：一张决策表

把选型规则压缩成一张可记忆的表：**只要一阶**（梯度下降/SGD）：规模巨大、精度要求低（1e-3 级）、函数光滑或可随机化——机器学习训练唯一选择；**一阶加加速**（Nesterov/近端）：需要理论最优收敛率、含非光滑项（l₁）；**拟牛顿**（L-BFGS）：中规模、光滑、要精度（1e-6 级）、Hessian 不可得——科学计算与经典 ML 的默认；**二阶**（牛顿/牛顿-CG）：小规模、要机器精度、Hessian 可得——内点法的内层引擎；**共轭梯度**：二次目标或作为二阶内层——线性系统的场景。判断顺序：**先问规模（10⁵ 分界）→ 再问光滑性（有 l₁ 就靠近端）→ 最后问精度（1e-6 以上才考虑二阶）**。一个经验法则：**"求解器换算法的时间应该用分钟计，问题建模的时间应该用小时计"**——算法选型是 10 分钟的决定，建模质量才是性能的九成。

### 4.3 停止准则：什么时候算收敛

"迭代多久停"是工程上比"选哪个算法"更常被问的问题。三条准则：**梯度范数**（‖∇f‖ ≤ ε——凸问题里这直接给出函数值误差界，因为一阶条件是全局下界，03 篇）；**步长/位移**（‖x_{k+1}-x_k‖ ≤ ε——最常用但最不可靠，平坦区域会过早触发）；**目标值变化**（|f(x_{k+1})-f(x_k)| ≤ ε——注意目标值可能"平坦但未收敛"）。实践建议：**小问题用梯度准则（1e-6），大问题用目标值加梯度混合（1e-4 到 1e-5），并设最大迭代上限**（一阶方法的收敛是渐进的，预算有限时上限比容差更重要）；2026 年 ML 训练里的"早停"（early stopping）本质是"目标值在验证集上变化过小就停"——同样的停止准则逻辑，只是监督信号换成了泛化误差。

> 🎯 **核心要点**：无约束算法的谱系由"每步成本 vs 收敛率"的权衡决定——梯度下降 O(n) 线性收敛但被条件数拖慢，Nesterov 加速达到一阶方法最优下界，牛顿法二次收敛但每步 O(n³)，L-BFGS 用 O(n·m) 换超线性收敛是工程甜点，共轭梯度是"大规模偷用二阶信息"的桥梁；选型决策树按"规模 → 光滑性 → 精度"排序：小规模牛顿、中规模 L-BFGS、大规模 SGD、非光滑走近端——"更高级"不等于"更合适"，这是算法比较的第一课。
