## 3. 学习路线推荐

**路线 A：搞懂"凸优化是什么"（半天）**
01 → 02 → 03 → 04。从定义到几何直觉再到问题分类——适合所有工程师建立"什么是凸、为什么凸好算"的直觉，看懂优化相关的论文与新闻。

**路线 B：系统学习（2-3 天，推荐）**
路线 A + 05 + 06 + 08。补上 KKT/对偶与两大算法线，配合 CVXPY 动手求解真实小问题——形成"建模 → 求解 → 解读对偶"的完整闭环。**配合 `线性代数/` 与 `计算机数学基础/` 查阅矩阵论与微积分基础**。

**路线 C：机器学习视角（面向 AI 工程师/算法岗）**
路线 B + 07 + 09 + 10。聚焦训练优化器（SGD 家族/AdamW）、凸松弛技巧与 2026 年"深度展开 + LLM 辅助"的前沿——**与 `深度学习/` 体系对照阅读**，理解"训练为什么用 AdamW、损失函数为什么能设计成凸的"。

> 💡 与知识库关系：04 篇的 LP/QP 与 `最优化理论/` 交叉；09 篇的 SVM/核方法与机器学习内容互文；10 篇的深度展开与 `深度学习/` 呼应；矩阵基础回查 `线性代数/`，微积分回查 `高等数学微积分/`。

### 阅读时的三个常见误区

1. **"凸优化 = 所有优化问题的子集，学了用处有限"**：恰恰相反——凸优化是"能保证全局最优 + 有成熟算法"的唯一大类，而**绝大多数工程问题的核心子问题可以凸化**（松弛、对偶、分块）；机器学习里损失函数与正则项几乎全是凸的（01/04/09 篇）
2. **"凸问题不用学算法，丢给求解器就行"**：求解器只解决"已建模"的问题——建模错误（非凸当凸）、病态数值、规模失控才是真实战场；理解算法（内点法的复杂度、SGD 的收敛率）是判断"求解器为什么慢/为什么不收敛"的前提（06/07/08 篇）
3. **"深度学习是非凸的，凸优化与 AI 无关"**：训练是非凸的，但训练用的**每一件工具都是凸优化的**——AdamW 的构造源自凸分析、SGD 的收敛理论是凸理论、凸松弛是神经网络理论化的第一步（09/10 篇）

带着三个误区读完全书，会发现每一篇都在回答同一个问题：**为什么"凸"这一个性质，能换来"全局最优 + 可靠算法"两个承诺**。

## 4. 核心概念速查

| 概念 | 一句话定义 | 关键事实（2026） |
|------|-----------|---------------------|
| 凸集 | 集合内任意两点的连线仍在集合内 | 可行域的凸性是全局最优的前提 |
| 凸函数 | 函数图像位于割线下方 | 一阶条件：f(y) ≥ f(x) + ∇f(x)ᵀ(y-x) |
| 局部=全局 | 凸问题任意局部最优即全局最优 | 凸优化"已解决"的理论根基 |
| LP | 线性规划 | 单纯形法 1947；HiGHS 是领先开源求解器 |
| QP | 二次规划 | 投资组合、SVM 双问题、MPC 的核心 |
| SOCP/SDP | 二阶锥/半定规划 | 鲁棒优化、信号处理、控制综合 |
| KKT | 约束最优性充要条件 | 凸 + Slater 时充要；对偶理论的顶点 |
| 对偶 | 原问题的"另一面" | 弱对偶恒成立，强对偶给下界与灵敏度 |
| 内点法 | 障碍函数 + 牛顿迭代 | 多项式时间；LP/QP/SOCP/SDP 通用引擎 |
| ADMM | 交替方向乘子法 | 可分解大问题的分布式求解 |
| SGD/AdamW | 随机一阶方法家族 | 大模型训练默认：AdamW + warmup + 余弦退火 |
| CVXPY | 凸优化建模语言 | 2026 举办 Workshop；DCP 规则自动校验凸性 |
| 凸松弛 | 把非凸问题放宽为凸问题 | Lasso/核方法/组合优化的标准手法 |
| 深度展开 | 把迭代算法展开成网络 | Deep FlexQP（ICLR 2026）比 OSQP 快 4-16 倍 |

> 🎯 **核心要点**：凸优化的全部价值压缩为一句话——**"凸性"这一个性质同时买来两个承诺：任意局部最优都是全局最优（理论保证），且有多项式时间的可靠算法（计算保证）**；从 1947 年单纯形法到 2026 年 AdamW 与深度展开求解器，七十多年的主线都是"把问题变凸、再把凸问题算得快"——它既是运筹学的基石，也是机器学习的隐形引擎。

**"凸优化和神经网络训练是什么关系？训练明明是梯度下降啊？"** 训练的目标函数是非凸的，但"用什么方法更新参数"这件事的全部理论来自凸优化：SGD 的收敛性证明、动量与自适应步长的构造、学习率退火的必要性——**凸优化提供的是"训练算法"的说明书，不是"训练目标"本身**；而模型里的每一个凸子问题（损失项、正则项、最后的线性层）都在直接消费凸优化（09 篇）。

**"做后端开发，凸优化有什么用？"** 三个直接入口：资源调度（容器/带宽/预算分配是 LP/QP，04 篇）、推荐与定价（矩阵补全/鲁棒优化）、理解训练成本（读懂为什么 AdamW 配退火、为什么量化要调优化器——训练成本的每一次波动都有凸理论的影子）；2026 年 LLM 辅助建模让"把业务问题写成优化问题"成为后端工程师的新技能（08/10 篇）。

### 体系速读版（30 秒版）

- **为什么研究它**：局部=全局 + 算法可靠，优化世界里唯一"基本解决"的类（01 篇）
- **长什么样**：凸集约束 + 凸目标（02/03 篇），LP/QP/SOCP/SDP 五族标准形式（04 篇）
- **怎么判断最优**：KKT 条件 + Slater（05 篇）
- **怎么算**：无约束梯度/牛顿（06），约束内点/ADMM（07），求解器 CVXPY/Gurobi（08）
- **与 AI 的关系**：SVM/逻辑回归是凸的；训练优化器源自凸理论；2026 年深度展开让求解器"可学习"（09/10 篇）
