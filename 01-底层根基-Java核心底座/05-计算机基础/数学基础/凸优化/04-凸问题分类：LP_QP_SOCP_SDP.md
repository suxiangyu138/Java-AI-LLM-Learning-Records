# 凸问题分类：LP / QP / SOCP / SDP
> 凸优化不是一个问题而是五族问题：线性规划、二次规划、二阶锥规划、半定规划与几何规划——从 LP 到 SDP 层层推广，每一族都有自己的标准形式、经典算法与专属应用场景，识别"问题属于哪一族"是建模的第一步。

## 1. 五族问题的标准形式

凸问题的标准形式（03 篇第 4 节）按目标与约束的具体形式，分出五个经典家族：

```text
LP    ：min cᵀx            s.t. Ax ≤ b, Fx = g          （全线性）
QP    ：min ½xᵀPx + qᵀx    s.t. Ax ≤ b                  （二次目标+线性约束）
QCQP  ：QP + 二次不等式约束（凸时要求 P 及约束矩阵半正定）
SOCP  ：min cᵀx            s.t. ‖Ax+b‖₂ ≤ cᵀx+d        （二阶锥约束）
SDP   ：min tr(CX)         s.t. tr(AᵢX)=bᵢ, X ≽ 0      （矩阵变量半定约束）
GP    ：min f₀(x)          s.t. fᵢ(x)≤1, x>0           （正项式，对数变换后凸）
```

包含关系呈金字塔：**LP ⊂ QP ⊂ SOCP ⊂ SDP**（线性约束是二次的特例，二次约束是锥约束的特例，二阶锥又是半定锥的特例）；GP 经过对数变换（tᵢ=log xᵢ）后化为凸问题，自成一支。理解这个包含链有实操价值：**能建模成更"底层"家族的问题，求解越快越稳**（LP 比 SDP 快几个数量级），所以建模的第一原则是"尽量用最窄的家族装下你的问题"。

## 2. 各家族的经典算法与复杂度

每个家族都有相匹配的成熟算法，2026 年仍是这些引擎在撑场面：

- **LP（单纯形法 1947 / 内点法 1984）**：单纯形法实践上几乎线性时间（最坏指数，但现实极少触发）；内点法多项式时间。开源标杆 HiGHS（2016 年起）被业界称为"全球最好的开源线性优化软件"，Gurobi/MOSEK 是商用双雄——LP 是"求解器最成熟、规模最大"的家族，百万变量日常可解
- **QP（活动集法 / 内点法）**：凸 QP 由内点法统一处理；**投资组合优化（马科维茨）、SVM 对偶、模型预测控制（MPC）**三大应用让 QP 成为工程出镜率最高的家族；小规模高速场景还有 OSQP（一阶方法，2026 年被深度展开方法挑战，见 10 篇）
- **SOCP（内点法）**：鲁棒优化（参数不确定的线性规划）、**二阶锥约束的统计问题**（岭回归的约束版）、椭球约束最小二乘；内点法处理 SOCP 与 LP 同框架，只是每步的牛顿系统更贵
- **SDP（内点法）**：**矩阵变量问题——半定矩阵锥约束**。应用：协方差估计、传感器网络定位、控制理论（LMI 线性矩阵不等式）、组合优化的 SDP 松弛（MaxCut 的 0.878 近似来自 SDP 松弛）；代价是内点法每步要解大线性系统，规模上限远低于 LP/QP——**SDP 是最贵也最深的家族**
- **GP（对数变换 + LP/凸优化）**：**设计优化**（电路尺寸、天线、机械结构）、通信功率控制——正项式约束在对数坐标下变成凸约束，把"看起来非凸的乘性约束"变成凸问题，是"变凸"技巧的教科书案例

## 3. 应用地图：什么场景属于哪一族

工程上"认出问题家族"比"求解"更重要，因为选错家族 = 用最贵的工具解最简单的题。2026 年的典型映射：

| 场景 | 家族 | 为什么 |
|------|:---:|------|
| 运输/排产/资源分配 | LP | 线性成本 + 线性约束 |
| 投资组合（马科维茨） | QP | 二次风险 + 线性预算 |
| 模型预测控制（MPC） | QP（实时毫秒级） | 二次状态误差 + 线性动力学 |
| 鲁棒调度（参数不确定） | SOCP | 不确定集 → 二阶锥描述 |
| 压缩感知/稀疏重构 | LP/SOCP | l₁ 范数 → LP；l₂ 约束 → SOCP |
| 协方差估计/定位 | SDP | 矩阵半正定约束是问题本质 |
| 电路/天线尺寸设计 | GP | 乘性约束在对数坐标变凸 |
| 分类（SVM） | QP（对偶） | 二次目标 + 线性约束 |

记忆口诀：**线性结构找 LP，二次目标找 QP，范数/不确定找 SOCP，矩阵结构找 SDP，乘性约束找 GP**——先按"结构最硬的约束"定家族，再选求解器（08 篇）。

## 4. 工程上的三条选型纪律

**第一，能窄不宽**：同一个问题（如含 l₂ 范数约束的线性规划）可以建模成 LP、SOCP 甚至 SDP——但求解成本逐级上升，建模时优先找"最窄的凸家族"；CVXPY 的 DCP 检查会提示"这其实是 SOCP"，用好这个提示。

**第二，注意约束的凸性陷阱**：二次等式约束（xᵀPx = 1）**不是凸约束**（可行域是椭球表面，非凸）——它看似"二次"实则是非凸问题；同理，|x|≤1 的等价形式要写成两个线性约束而不是"绝对值等式"。**建模时最容易犯的错，就是把非凸约束伪装成凸约束**（2026 年 LLM 辅助建模的最大风险就在此，10 篇）。

**第三，规模决定家族**：问题规模（变量数 × 约束数）与家族共同决定"能不能算"——LP/QP 轻松百万级，SOCP 十万级，SDP 只敢做千级；2026 年的工程现实是"SDP 的规模墙"促使研究者转向低秩分解与一阶方法（07 篇 ADMM 处理大规模 SDP 的典型路线）。

### 4.1 一个完整的建模案例：运输问题

用一个经典问题串起"识别家族 → 建模 → 求解 → 解读"的完整流程：**运输问题**——m 个工厂（产能 aᵢ）、n 个门店（需求 bⱼ），单位运输成本 cᵢⱼ，求总成本最小的调运方案 xᵢⱼ。

**第一步，识别结构**：目标 Σcᵢⱼxᵢⱼ 是线性的；约束"工厂产能"与"门店需求"是线性的；运量非负——**全线性结构，LP 家族**（口诀：线性找 LP）。**第二步，建模**：直接写线性规划；供需不平衡时加"虚拟工厂/门店"化为标准形式；注意运输问题的约束矩阵是全幺模的（0/1 结构），**线性规划的最优解自动是整数解**——"线性结构 + 全幺模矩阵 = 整数规划免费"是凸化层级（10 篇）的经典案例。**第三步，求解与解读**：小规模用 CVXPY + HiGHS 一行代码；大规模（万级）用网络单纯形（线性规划的特化）；解出后看对偶值——**每个门店约束的影子价格就是"这个门店每多要一单位货，总成本增加多少"**，是扩容选址决策的直接依据（05 篇）。**第四步，扩展**：加容量约束还是 LP；加固定成本（开一条线就付一笔钱）变成混合整数规划（丢出凸类，交给分支定界）；加不确定需求，鲁棒版本变二阶锥问题——**同一业务问题沿"结构改变"在问题家族间游走**，建模者要能看出"加了什么结构、跳到了哪一族"。

### 4.2 求解器黑盒背后：预处理的角色

同样的问题族，求解器之间能差出 10-100 倍，秘密大多在**预处理**（presolve）而不是算法：现代求解器（Gurobi/HiGHS/MOSEK）在正式求解前先做一轮"体检"——**固定变量**（约束里被锁死的变量直接定值）、**去掉冗余约束**（被其他约束包含的行）、**尺度缩放**（把系数与右端项归一化到相近量级）、**行重排**（减少填充，加速稀疏分解）——预处理后的问题往往小一个量级，病态性也大幅缓解。工程含义：**"建模质量"决定求解器发挥**——变量尺度差 10⁶ 倍的问题（一个变量是"元"、一个变量是"吨"），不预处理直接喂求解器，数值误差会把最优解搅浑；建模时主动做变量归一化（让所有变量同量级）与约束缩放（右端项同量级），比事后调求解器参数有效得多。2026 年 CVXPY Workshop 的求解器基准主题，测的就是"同一问题不同预处理与算法组合的表现"——**预处理是建模者与求解器之间的第一道接口**。

> 🎯 **核心要点**：凸问题五家族 LP/QP/SOCP/SDP 呈包含链（LP⊂QP⊂SOCP⊂SDP），GP 经对数变换入列；每族有专属算法与规模上限（LP 百万级、SDP 千级）；应用映射的口诀是"线性找 LP、二次找 QP、范数/不确定找 SOCP、矩阵找 SDP、乘性找 GP"；三条纪律——能窄不宽（成本逐级上升）、警惕二次等式等非凸伪装、规模决定家族——识别问题家族是比求解更值钱的建模能力。
