# 机器学习中的凸优化
> 深度学习训练是非凸的，但训练所用的每一件工具都是凸的：逻辑回归与 SVM 本身就是凸问题，SGD/AdamW 的收敛理论源自凸分析，Lasso 的稀疏性是凸松弛的胜利——凸优化是机器学习的隐形引擎。

## 1. 经典模型的凸性：逻辑回归与 SVM

机器学习里最早的一批模型，恰好是凸优化的完美案例：

**逻辑回归**：负对数似然损失 ℓ(w) = Σlog(1+exp(-yᵢwᵀxᵢ))——log-sum-exp 是凸函数（03 篇保凸运算：凸函数 ∘ 线性映射 + 非负和），加上 l₂ 正则项仍凸。**无约束凸问题，直接上 L-BFGS 或 SGD**；最优解唯一（严格凸时）、全局最优、有收敛保证——"机器学习模型为什么可训练"的第一个答案。

**SVM**：hinge 损失 max(0, 1-yᵢwᵀxᵢ)（凸） + 二次正则 ½‖w‖²（凸）——原问题是凸 QP；对偶形式（05 篇）给出核技巧：K(xᵢ,xⱼ) 替换内积，把线性分类器变成高维隐式空间里的分类器——**"核方法"整套是凸对偶的副产物**。互补松弛的"支持向量"解读（活跃约束的样本）是凸分析给 ML 的免费几何直觉。

两个模型的共同点：**损失是"凸函数 ∘ 线性层"的复合，正则项是非负凸项**——这正是 03 篇保凸运算在 ML 里的标准配方。设计新模型时，检查"损失 + 正则"的凸性，就是检查"能否保证收敛到全局最优"。

## 2. SGD 家族：从随机梯度到 AdamW

大规模训练的唯一选择是随机一阶方法（每步只看一个小批量，O(1) 成本）：

- **SGD**：w ← w - η·Ĝ（Ĝ 为小批量梯度）——随机梯度的期望是无偏的（E[Ĝ]=∇f），收敛理论建立在"噪声均值 + 步长衰减"上（凸情形 O(1/√k) 收敛率，强凸 O(1/k)）
- **动量（Momentum）**：累积"速度"v ← βv + Ĝ——抑制震荡、加速穿越（在凸问题上等价于预处理后的梯度下降，Nesterov 动量有一阶最优收敛率）
- **AdaGrad → RMSProp → Adam**：逐坐标自适应步长（除以梯度历史平方根）——AdaGrad 让稀疏特征（词频不均）获得更大步长；RMSProp 用滑动平均解决 AdaGrad 步长过快衰减；Adam 融合动量 + 自适应，是 2015 年后的默认
- **AdamW（2019）**：把权重衰减（l₂ 正则）从自适应步长中解耦——**大模型训练的工业默认**（09 篇主线：训练工具的每一项都源自凸分析，连"正则与自适应的相互作用"都是在凸框架里研究的）

2026 年训练配方（工业共识）：**AdamW + warmup（学习率先升后降）+ 余弦退火 + 梯度裁剪**——这套配方里的"warmup"（先升）与"退火"（后降）都是凸优化步长策略（步长衰减保证收敛）在大模型场景的工程化；"为什么 AdamW 配余弦退火"是凸收敛理论（步长 → 0 保证收敛到驻点）的直接推论。

## 3. 凸松弛：把非凸问题"放宽"成凸问题

机器学习与组合优化里，凸优化最锋利的武器是**凸松弛**：非凸问题难解，把它放宽（放松约束/替换目标）成凸问题，用凸解作为近似或上/下界：

- **Lasso（l₁ 正则）**：l₀ 稀疏（非凸组合问题）放松为 l₁ 范数（凸）——**"l₁ 是 l₀ 的最佳凸近似"**（l₁ 球的角点恰好落在坐标轴上，天然产生稀疏解）；再配合近端梯度（07 篇软阈值）高效求解——压缩感知"从 O(n) 次测量恢复稀疏信号"的理论（RIP 条件）整个建立在 l₁ 凸松弛上
- **秩最小化 → 核范数**：矩阵补全（推荐系统）的秩函数非凸，凸松弛为核范数（奇异值之和）——Netflix 竞赛以来推荐系统的标准手法
- **MaxCut → SDP 松弛**：组合优化的经典例子——MaxCut 的 SDP 松弛给出 0.878 近似比（Goemans-Williamson 定理），是"凸松弛带近似保证"的黄金标准
- **非凸深度网络的理论第一步**：分析"神经网络的凸松弛"（如 wide 网络的核化），是 2026 年神经网络理论化的重要方向

**凸松弛的使用流程**：确认原问题非凸 → 找到"最优凸近似"（松弛目标或约束）→ 解凸问题 → 用界或舍入恢复原问题解（松弛解 → 投影/随机舍入）→ 验证近似比。**识别"哪里能凸化"是高级建模技能**，也是 10 篇"非凸的凸化"专题的入口。

## 4. 训练之外的凸优化：模型选择与强化学习

凸优化在 ML 里的身影不止训练：**交叉验证**（网格搜索是"离散优化"的朴素版，凸视角下是模型选择问题的松弛）；**模型平均与蒸馏**（权重为凸组合——概率单纯形上的优化）；**RL 的策略优化**（策略梯度是非凸的，但策略评估与线性规划形式是凸的——2026 年 ICLR 的 Log-barrier LP 方法把 MDP 的 LP 形式通过障碍函数改写成无约束强凸目标，用梯度下降指数收敛求解，衍生出 Log-barrier DQN/DDPG）；**鲁棒优化**（最坏情况损失是凸的——minimax 结构的凸松弛是 GAN 与鲁棒 ML 的共同语言）。**结论：凸优化不是 ML 的"历史包袱"，而是它的活语法**——每当研究者需要"保证"（收敛、最优、界），凸性就是最顺手的工具。

### 4.1 凸优化的局限与深度学习的非凸现实

诚实地划清边界：**深度学习训练本身不是凸问题**——神经网络的损失函数对参数非凸（对称性、置换不变性导致大量等价极小），凸理论的"全局最优"保证不适用。但 2026 年研究界的共识是：**"非凸的丛林里依然有凸的路径"**——三条证据：**线性网络与宽网络的"凸面"**（当宽度趋于无穷，训练动力学近似凸或核方法，NTK 理论）；**局部极小"大多数等价"**（经验上深层网络的局部极小值之间性能差距很小，凸理论的"唯一最优"放宽为"很多差不多好的最优"）；**损失景观可视化**（低维投影下训练路径像"下山"，鞍点主导而非局部极小主导——逃离鞍点的处理正是凸分析里"强凸性"的镜像问题）。

工程结论三条：**不要用凸工具硬解非凸问题**（收敛保证失效，近端与内点在非凸上可能发散）；**但可以把凸工具用在非凸训练的每个环节**（正则注入、步长策略、逐块凸化、子问题求解——第 2 节主线）；**理解"凸"与"非凸"的边界，是理解深度学习"为什么能训练"的前提**——2026 年的训练理论（特征学习、隐式正则化）大量借用凸分析的词汇（曲率、Hessian、条件数）。**边界清晰，工具箱才用得准**。

### 4.2 优化器选择的实用对照

给优化器选型一张最终对照：**SGD**：基线，需手动调学习率，泛化好但慢；**SGD 加动量**：抑制震荡、跨过浅谷；**AdaGrad**：稀疏特征场景（词频不均的 NLP）好用，但累积平方根使步长过快衰减；**RMSProp**：AdaGrad 的滑动平均修正，RNN 训练经典；**Adam**：动量加自适应，默认首选，但调参空间大；**AdamW**：权重衰减解耦——大模型事实标准（第 2 节）；**L-BFGS**：凸小规模与经典模型（逻辑回归、条件随机场）的高精度选项；**Sophia 等新族（2024-2026）**：二阶信息的轻量近似，大模型场景有报道但工业验证未完——**选型口诀：大模型 AdamW、经典模型 L-BFGS、稀疏特征 AdaGrad 系、RNN 用 RMSProp、基线 SGD**；而无论选谁，学习率调度（warmup 加退火）的骨架都来自凸优化的步长理论（03 篇 4.1 光滑性）。

> 🎯 **核心要点**：深度学习训练是非凸的，但工具全是凸的——逻辑回归/SVM 本身就是凸问题（凸损失 + 凸正则的标准配方），SGD/动量/AdamW 的收敛理论源自凸分析（大模型配方"AdamW + warmup + 余弦退火"是步长策略的工程化）；凸松弛是 ML 最锋利的武器（l₁=l₀ 的凸近似、核范数=秩的凸近似、MaxCut 的 0.878 近似）；2026 年连强化学习都在用凸方法（MDP 的 LP 形式 + 对数障碍）——"每当需要保证，凸性就是最顺手的工具"。
