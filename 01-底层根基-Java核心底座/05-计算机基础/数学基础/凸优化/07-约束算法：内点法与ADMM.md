# 约束算法：内点法与 ADMM
> 约束优化的两条主流路线：内点法把约束"溶进"目标（障碍函数 + 牛顿迭代，高精度但贵），ADMM 把大问题"拆开算"（分解 + 近端算子，可扩展但精度有限）——一个要精度，一个要规模，2026 年的求解器与机器学习分别站在两边。

## 1. 障碍函数法：把约束"溶进"目标

内点法（Interior-Point Method）的第一性思路：**与其被约束"挡"在可行域外，不如让目标在边界处"自己爆炸"**。对数障碍函数把不等式约束 fᵢ(x)≤0 改写为惩罚项：

```text
min  f₀(x) - (1/t)·Σ log(-fᵢ(x))     （t 为障碍参数）
```

当 x 靠近边界（fᵢ→0⁻）时，-log(-fᵢ)→+∞——**目标自动把迭代点"推"回可行域内部**；参数 t 越大，惩罚越轻、解越接近真实最优。算法流程：从一个严格可行点出发，对固定的 t 做牛顿迭代求近似解，然后增大 t（障碍函数"变薄"）再迭代——**层层逼近边界上的最优解，这就是"内点"的含义：始终在可行域内部走，不触碰边界**。

复杂度与精度的账：内点法的迭代次数 ~ √n·log(1/ε)（n 为维度），**与问题规模几乎无关、与精度对数相关**——这是多项式时间保证的具体形态（01 篇承诺二）；代价是每步的牛顿系统（解一个 n×n 线性方程组，O(n³)）——**高精度与中规模（n≤10⁵）是内点法的甜区**，Gurobi/MOSEK/HiGHS 的 LP/QP/SOCP/SDP 引擎全部基于它。

## 2. 原始-对偶内点法：现代求解器的标准件

纯障碍方法有一个工程缺陷：每轮要精确求解子问题（外层迭代慢）。**原始-对偶内点法**直接同时迭代原始变量 x 与对偶变量（λ,ν），把 KKT 条件（05 篇）当成"带平滑的方程组"用牛顿法解——**内层外层合一，实践上快 10-100 倍**。现代求解器（Gurobi/MOSEK/SCS）的内部就是它：维护一个"中心路径"（满足"扰动互补松弛" λᵢfᵢ(x) = -1/t 的点列），沿路径滑向 KKT 解。

2026 年状态：内点法仍是高精度求解的王者——**Gurobi 11 与 MOSEK 的 LP/QP 性能提升主要来自预处理与并行，不是算法换代**；数值稳定性（病态问题、大条件数）是内点法的软肋，预处理（缩放、重新排序）与求解器容差设置是工程重点。

## 3. 近端算子：把"不可微"变"可解"

约束与正则项的常见形态是**非光滑凸函数**（l₁ 范数、指示函数 δ_集合 = 0/∞），梯度下降直接失效。**近端算子**是扩展：prox_g(v) = argmin_x (g(x) + ½‖x-v‖²)——"在保持接近 v 的前提下最小化 g"。两个关键事实：**近端算子是"广义投影"**（g=指示函数时 prox = 投影到该集合）；**很多常用 g 的近端算子有闭式解**（l₁ 的软阈值、l₂ 的块收缩、单纯形上的投影——O(n log n)）。**近端梯度法**（PGM/FISTA）：x_{k+1} = prox_{t·g}(x_k - t·∇f(x_k))——光滑项走梯度、非光滑项走近端，**把 06 篇的梯度下降家族无缝扩展到 l₁ 正则与约束问题**；FISTA（加速版）达到 O(1/k²) 收敛率（一阶方法的理论最优）。

工程意义：**近端算子是"分解"的原子操作**——任何能写出近端算子的函数都能进入 ADMM/近端框架，这是 2026 年分布式与大规模优化的公共语言。

## 4. ADMM：把大问题拆成小问题

**ADMM（交替方向乘子法）**的出发点：把目标拆成可分离的两块 f(x)+g(z)，用线性约束 x=z 连接，构造增广拉格朗日，然后**交替更新 x、z 与乘子**：

```text
x_{k+1} = argmin_x (f(x) + (ρ/2)‖x - z_k + u_k‖²)     （x 步：近端型更新）
z_{k+1} = argmin_z (g(z) + (ρ/2)‖x_{k+1} - z + u_k‖²)   （z 步：近端型更新）
u_{k+1} = u_k + x_{k+1} - z_{k+1}                       （对偶上升）
```

核心洞察：**把"一个难问题"换成"两个简单子问题 + 一个乘子更新"**——每个子问题都可以并行、可以用近端算子闭式解、可以只做近似（不精确 ADMM 也收敛）。经典应用：**分布式共识优化**（数据分片各算各的，乘子协调）、**大规模 SDP 的秩分解**（把 SDP 拆成低秩子问题）、**l₁+l₂ 的稀疏回归**（两项各走各的近端）、**联邦学习**（每设备本地近端步 + 中心聚合）。

代价与边界：ADMM 是**一阶方法**——每步便宜、迭代数多（通常需要上千步才能高精度收敛），对精度要求极高的问题不如内点法；超参数 ρ 影响收敛速度（2026 年自适应 ρ 仍是研究热点）；**"拆得开"是前提**——问题没有可分离结构时 ADMM 无从下手。选型口诀：**要精度选内点（Gurobi/MOSEK），要规模/分布式选 ADMM，要"稀疏 + 正则"选近端梯度**。

### 4.1 ADMM 实战案例：分布式 LASSO

用分布式 LASSO 展示 ADMM 的完整工作流（联邦学习/数据分片场景的原型）：数据分布在 K 台机器上，全局目标是最小二乘加 l₁ 正则，无法直接求（矩阵太大或隐私约束）。

**ADMM 的拆法**：引入全局变量，把目标改写为"每台机器各自的损失之和 + 全局正则项"，并用线性约束把每台机器的局部变量与全局变量连接——**x 步（每台机器）**：用本地数据解一个小最小二乘（可并行）；**z 步（中心）**：对所有局部变量的平均做软阈值（l₁ 的近端算子，第 3 节——闭式解，一行代码）；**u 步（中心）**：乘子更新，把"机器间分歧"反馈给下一轮。收敛后所有局部变量收敛到全局解——这就是"分解 + 近端 + 乘子"三件套的完整演示。

工程启示四点：**并行是白送的**（x 步天然可拆分，2026 年联邦学习与分布式训练的骨架与它同构）；**每步都是简单闭式解**（最小二乘与软阈值，无需内部迭代）；**只传"模型"不传"数据"**（隐私友好的附带收益）；**精度有限**（一阶方法，高精度场景不敌内点法，选型口诀见第 4 节）。**看懂这个案例，就看懂了 ADMM 家族的全部套路**：找可分离结构 → 写增广拉格朗日 → 交替近端步 → 乘子协调。

### 4.2 规模-精度地图：内点 vs 一阶

把 06/07 两篇的算法放进一张"规模 × 精度"地图：**横轴是问题规模（变量数），纵轴是所需精度**。**左上象限（小规模、高精度）**：内点法统治——线性/二次规划的 1e-8 精度只有它给得起，Gurobi/MOSEK 在这里无敌；**右下象限（大规模、低精度）**：一阶方法统治——百万变量的 1e-3 精度，ADMM/SCS/近端梯度是唯一选择；**对角线（中规模、中精度）**：竞争地带——L-BFGS、OSQP 与内点各有千秋，用基准说话（08 篇三件套对比）；**左下（小、低精度）**：任何方法都行，选最简单的；**右上（大、高精度）**：无人区——**这正是 2026 年研究的热点**：深度展开（10 篇）与专用分解方法都想攻下这个象限。这张地图的价值：**拿到问题先定位象限，再选工具**——"用内点法跑百万变量"与"用一阶方法跑 1e-8 精度"都是把工具用错象限的典型。

### 4.3 路径跟踪：内点法为什么"稳"

内点法有一个常被低估的工程优势——**路径跟踪（path-following）**：障碍参数逐级增大时，最优解沿一条连续曲线（中心路径）平滑移动，**每个中间点都是可行解**——这意味着：随时可以提前终止拿到一个"可行的近似解"（对实时场景友好）；热启动（warm start）有效（上一个参数的解作为下一个参数的初值，牛顿法只需一两步）；不可行性几乎不会发生（迭代点始终在可行域内部）。对比一阶方法：ADMM 的迭代点在收敛前通常不可行（约束违反量随迭代衰减），提前终止拿到的解"不可用"——**实时约束优化（MPC 控制、安全滤波）选内点法（或其截断版）而非一阶方法，路径跟踪是最硬的理由之一**。

> 🎯 **核心要点**：约束优化双路线——内点法（障碍函数 + 原始对偶牛顿）把约束溶进目标，迭代数与维度弱相关、精度对数级，是中规模高精度的王者（Gurobi/MOSEK/HiGHS 的引擎）；近端算子把非光滑项变成"广义投影"原子（软阈值/投影都有闭式解），让一阶方法无缝扩展；ADMM 用"拆解 + 交替 + 乘子"把大问题化成可并行的近端子问题，换取规模但牺牲精度；选型口诀——要精度内点、要规模 ADMM、要稀疏近端——三条路构成 2026 年约束优化的完整工具箱。
