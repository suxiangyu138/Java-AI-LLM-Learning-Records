## 4. 核心概念速查

| 概念 | 一句话定义 | 关键要点 |
|------|-----------|---------|
| 概率 | 事件发生的可能性（公理化） | 0 ≤ P ≤ 1，全空间 = 1 |
| 条件概率 | 已知 B 下 A 的概率 | P(A\|B) = P(AB)/P(B) |
| 独立 | A 发生不影响 B | P(AB) = P(A)P(B) |
| 贝叶斯公式 | 由果推因 | P(H\|D) ∝ P(D\|H)·P(H) |
| 随机变量 | 试验结果的数值化 | 离散（PMF）/连续（PDF） |
| 期望 | 加权平均（一阶矩） | E[X] = Σx·p(x) = ∫x·f(x)dx |
| 方差 | 离均差的期望（二阶中心矩） | Var = E[(X−μ)²] |
| 协方差 | 两变量联合变动 | Cov = E[XY] − E[X]E[Y] |
| 大数定律 | 均值收敛于期望 | 频率 → 概率 |
| 中心极限定理 | 大量独立和的分布 → 正态 | 一切均值近似正态 |
| 极大似然估计 | 最"解释"数据的参数 | MLE = 交叉熵的来源 |
| p 值 | 原假设下观测到该结果的概率 | p < α → 拒绝原假设 |
| 置信区间 | 参数的可能范围（带置信度） | 95% CI 的统计含义 |
| 最小二乘 | 残差平方和最小 | 回归 = 条件期望的近似 |
