## 1. 总体、样本与统计量

```text
总体：研究对象的全体（分布未知——要推断的东西）
样本：随机抽取的 n 个观测（独立同分布 i.i.d.，01 章）
统计量：样本的函数（不含未知参数）
  样本均值 X̄ = (1/n)ΣXᵢ
  样本方差 S² = (1/(n−1))Σ(Xᵢ−X̄)²（注意 n−1！）

样本方差为什么除 n−1：
  样本均值"消耗"一个自由度 → 无偏修正
  E[S²] = σ²（06 章与 04 章呼应——无偏性）

两类问题：
  参数估计：总体分布形态已知，参数未知（本章）
  非参数方法：分布形态也未知（经验分布/核密度）
```

## 2. 点估计的两大方法

### 2.1 矩估计（method of moments）

```text
思想：样本矩 ≈ 总体矩（大数定律的工程化）
  一阶矩：样本均值 → 总体期望
  二阶矩：样本二阶矩 → 总体 E[X²]（可解出方差）

做法：列方程（矩数 = 参数个数），解出参数估计

例（均匀分布 U(0, θ)）：E[X] = θ/2 → θ̂ = 2X̄
优：简单、无需分布精确假设
劣：效率低于 MLE（不利用全部分布信息）
```

### 2.2 极大似然估计（MLE）

```text
思想：选择"最可能产生这组数据"的参数
  L(θ) = Π p(xᵢ; θ)（似然 = 样本联合概率，视为 θ 的函数）
  θ̂ = argmax L(θ)

计算（对数化——乘积变求和）：
  ℓ(θ) = ln L(θ) = Σ ln p(xᵢ; θ)
  求导 = 0 解方程（微积分极值）

例（正态 N(μ, σ²)）：
  μ̂ = X̄（样本均值）
  σ̂² = (1/n)Σ(Xᵢ−X̄)²（注意：MLE 是除 n，无偏版除 n−1）
```

> 🎯 **核心要点**：MLE = "让数据最可能"的参数——它是统计推断的默认选择（有最优渐近性质），且与机器学习损失函数天然同构（第 7 节）。

## 3. 极大似然估计（MLE）深潜

```text
MLE 的渐近性质（大样本，05 章 CLT 基础）：
  ① 一致性：θ̂ → θ（n → ∞，大数定律）
  ② 渐近正态：√n(θ̂ − θ) → N(0, I(θ)⁻¹)（CLT）
     I(θ) = Fisher 信息量（分布携带的参数信息）
  ③ 渐近有效：方差达到克拉美-罗下界（最优）

似然的直觉（贝叶斯视角，01 章）：
  MLE = 均匀先验下的 MAP（后验最大）
  → 贝叶斯推断的"无先验特例"

数值计算：
  解析解（正态/泊松等简单情形）
  无解析解 → 梯度上升/EM 算法（GMM，03 章）

⚠️ 数值下溢：大样本似然乘积 → 必须用对数似然
```

## 4. 估计量的三大评价标准

| 标准 | 定义 | 直觉 |
|------|------|------|
| **无偏性** | E[θ̂] = θ | 平均来看不偏不倚 |
| **有效性** | 方差最小（同无偏类中） | 波动最小 |
| **一致性** | θ̂ → θ（n → ∞） | 样本越多越准（LLN） |

```text
经典例子（无偏性）：
  样本均值 X̄：无偏（E[X̄] = μ）——线性性直接给出
  样本方差除 n：有偏（偏小）；除 n−1：无偏
  标准差 S（取根号）：仍有偏（√ 的凸性）——理论细节

偏 vs 方差权衡（机器学习核心概念）：
  无偏 ≠ 最好（方差可能巨大）
  有偏但方差小（正则化/岭回归）常优于无偏
  → 偏差-方差权衡是统计与机器学习共同的核心思想
```

## 5. 区间估计与置信区间

```text
问题：点估计只有"一个数"，没有不确定性信息
置信区间：构造区间 [L, U] 使 P(θ ∈ [L, U]) = 1 − α

⚠️ 置信区间的正确理解（最易错）：
  不是"θ 有 95% 概率在区间里"（θ 是常数！）
  而是"反复抽样构造区间，95% 的区间覆盖 θ"
  → 置信度属于"构造过程"，不属于区间本身

构造方法（正态总体均值）：
  X̄ ± z_{α/2}·(σ/√n)（σ 已知，Z 区间）
  X̄ ± t_{α/2, n−1}·(S/√n)（σ 未知，t 区间——更常用）
  宽度 ∝ 1/√n（样本量换精度——CLT，05 章）
```

## 6. 常用置信区间

| 场景 | 区间 | 分布 |
|------|------|------|
| 正态均值（σ 已知） | x̄ ± z·σ/√n | Z |
| 正态均值（σ 未知） | x̄ ± t·S/√n | t(n−1) |
| 比例 p（大样本） | p̂ ± z·√(p̂(1−p̂)/n) | Z（CLT） |
| 方差 σ² | (n−1)S²/χ² 分布 | χ²(n−1) |
| 两均值差 | (x̄₁−x̄₂) ± t·SE | t（合并/韦尔奇） |

```text
工程要点：
  比例区间（民意调查 ±3%）= 最常被引用的区间（05 章）
  区间的宽窄 = 精度；精度提升靠样本量（√n 关系）
  自举法（Bootstrap）：不假设分布的重采样区间（09 章）
```

## 7. MLE 与机器学习的联系

```text
监督学习 = 条件分布的参数估计：
  回归（高斯假设）：y ~ N(f(x), σ²)
    MLE ⇔ 最小化 Σ(yᵢ − f(xᵢ))² = 最小二乘！（08 章）
    → 平方损失 = 高斯似然的负对数
  分类（多项分布假设）：y ~ Categorical(softmax)
    MLE ⇔ 最小化 −Σ log p(yᵢ|xᵢ) = 交叉熵！
    → 交叉熵损失 = 多项 MLE 的等价形式

映射表：
  损失函数         统计对应
  均方误差 MSE    高斯 MLE
  交叉熵 CE       多项分布 MLE
  L2 正则化       高斯先验的 MAP（贝叶斯）
  L1 正则化       拉普拉斯先验的 MAP

2026 视角：LLM 训练 = 极大化 token 序列的似然
  （自回归语言模型 = 条件分布的 MLE——09 章）
```

## 8. 估计的数值计算与工程实战

### 8.1 数值下溢与对数化

```java
// 大样本似然乘积 → 数值下溢（乘积 → 0）
// 例：1000 个概率 0.5 的乘积 ≈ 10^-301 → double 下溢

// ✅ 正确实现：对数似然（乘积变求和）
double logLikelihood = 0;
for (double p : probs) {
    logLikelihood += Math.log(p);   // 求和不溢出
}
// 机器学习交叉熵损失 = −平均对数似然（06 章 MLE 同构）
```

### 8.2 MLE 的数值求解

```text
闭式解（正态/泊松等简单情形）：直接公式
无闭式解（逻辑回归等）：
  梯度上升/牛顿法（微积分 06 章 + 优化理论）
  → 逻辑回归的"训练"就是 MLE 的数值优化
  → 深度学习 = 巨大参数空间的 MLE/MAP 数值求解

⚠️ 局部最优：非凸似然（混合模型）→ 多起点/EM 算法（03 章 GMM）
```

### 8.3 工程实战清单

```text
□ 点估计 + 区间估计成对报告（单点数会误导）
□ 样本量报告（n 与置信区间宽度直接相关，05 章）
□ 无偏性 vs 方差的权衡：正则化（岭回归）故意引入偏差换方差（06 章）
□ 自助法（Bootstrap，09 章）：分布未知时的区间替代
□ 报告口径统一：估计值、标准误、置信区间三者齐备
```

## 9. 核心要点与思考题

> 🎯 **本章三句话总结**：
> 1. 点估计两法：矩估计（样本矩=总体矩）、MLE（最可能的参数）——MLE 有最优渐近性质且与 ML 损失同构；
> 2. 三性评价：无偏（平均不偏）、有效（方差最小）、一致（LLN 收敛）；偏差-方差权衡是统计与 ML 的共同核心；
> 3. 置信区间：过程性的 95% 覆盖（不是 θ 的概率）；σ 未知用 t 分布；宽度 ∝ 1/√n。

**思考题**：

1. 样本方差为什么除 n−1？（→ 1 无偏修正）
2. 置信区间的"95%"到底指什么？（→ 5）
3. 交叉熵损失为什么是 MLE？（→ 7 多项分布）
4. L2 正则化对应的统计解释？（→ 7 高斯先验 MAP）
