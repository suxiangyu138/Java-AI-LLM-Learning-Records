# 数字特征：期望与方差

> 分布太"重"，数字特征提取精华：期望 = 中心位置（一阶矩），方差 = 离散程度（二阶中心矩），协方差 = 依赖方向——机器学习的目标函数（均方误差、交叉熵）本质都是期望的估计；切比雪夫不等式连接"矩"与"概率"

## 1. 期望：分布的中心

```text
定义（加权平均）：
  离散：E[X] = Σ xᵢ·p(xᵢ)
  连续：E[X] = ∫x·f(x)dx（微积分 05 章反常积分）

函数期望：E[g(X)] = ∫g(x)·f(x)dx（不必先求 g(X) 的分布！）

物理直觉：质心（概率 = 质量分布）

六大分布期望（速记）：
  伯努利 p、二项 np、泊松 λ
  均匀 (a+b)/2、指数 1/λ、正态 μ

⚠️ 期望未必存在（柯西分布 E 不存在——厚尾）
  → 金融数据的"期望不存在"风险
```

## 2. 期望的性质

```text
① 线性性：E[aX + bY] = aE[X] + bE[Y]
   （无任何条件！加法不要求独立）

② 乘积：E[XY] = E[X]E[Y]  ⇐ 需要 X、Y 独立
   （独立才可拆；否则 E[XY] ≠ E[X]E[Y] 一般）

③ 常数：E[c] = c

推论（方差计算的前置）：
  E[X²] ≠ (E[X])² 一般（除非 X 退化）
  E[X²] − (E[X])² = Var(X) ≥ 0

线性性的威力（蒙特卡洛/线性回归的数学基础）：
  E[平均值] = 平均值（无偏估计的直接证明，06 章）
```

> 🎯 **核心要点**：期望线性性无条件成立、乘积拆分要独立——这是"期望计算"的两条黄金法则；所有"平均/回归/预测"的期望视角都源于线性性。

## 3. 方差与标准差

```text
定义：Var(X) = E[(X − μ)²]（离均差的期望）
标准差：σ = √Var(X)（与原量纲一致——更常用）

计算式：Var(X) = E[X²] − (E[X])²

六大分布方差（速记）：
  伯努利 p(1−p)、二项 np(1−p)、泊松 λ
  均匀 (b−a)²/12、指数 1/λ²、正态 σ²

直觉：方差 = 不确定性/风险的量化
  → 投资组合的波动率、模型的预测不确定性
```

## 4. 方差的性质与计算

```text
① Var(c) = 0
② Var(aX) = a²Var(X)（系数平方！）
③ Var(X + Y) = Var(X) + Var(Y) + 2Cov(X,Y)
   → 独立时：Var(X+Y) = Var(X) + Var(Y)（协方差项消失）

⚠️ 高频错误：Var(X+Y) = Var(X) + Var(Y) 无条件成立
  → 只有独立（或不相关）才成立！
  → 相关时多出的 2Cov 项可能是正的（放大）或负的（对冲）

推论（均值方差的经典结果）：
  X₁,...,Xₙ 独立同分布：
  Var(均值) = σ²/n → 平均值的波动随 n 减小
  → "样本量增大估计更准"的数学来源（大数定律/CLT，05 章）
```

## 5. 矩与切比雪夫不等式

```text
矩：E[Xᵏ]（k 阶原点矩）；E[(X−μ)ᵏ]（k 阶中心矩）
  一阶原点矩 = 期望；二阶中心矩 = 方差
  偏度（三阶）：分布不对称性
  峰度（四阶）：厚尾程度（正态 = 3）

切比雪夫不等式（矩 → 概率的桥梁）：
  P(|X − μ| ≥ ε) ≤ Var(X)/ε²

  → 只用期望方差就能界住"离均值多远"的概率
  → 不依赖分布形态（最保守的界）
  → 大数定律证明的工具（05 章）

例：ε = 2σ → P(|X−μ| ≥ 2σ) ≤ 1/4
  （正态实际 ≈ 4.6%——切比雪夫是保守上界）
```

## 6. 条件期望

```text
定义：E[Y|X] = ∫y·f(y|x)dy（给定 X 下的平均）

两个关键性质（重期望/全期望公式）：
  ① E[Y] = E[E[Y|X]]（先条件平均，再平均——分层估计）
  ② 条件期望是最优预测：
     对任意函数 g：E[(Y − g(X))²] ≥ E[(Y − E[Y|X])²]
     → 均方误差意义下，条件期望 = 最优回归函数
     → 线性回归 = 条件期望的线性近似（08 章）

方差分解（总方差定律）：
  Var(Y) = E[Var(Y|X)] + Var(E[Y|X])
  组内方差 + 组间方差——方差分析（ANOVA）的理论基础
```

## 7. 期望在机器学习中的角色

```text
① 损失函数 = 期望的估计：
  均方误差 MSE = E[(y − ŷ)²]（回归损失 = 期望形式）
  交叉熵 = E[−log p(y|x)]（分类损失 = 负对数似然期望）
  → 训练 = 最小化"期望损失"（用样本均值近似，09 章蒙特卡洛）

② 无偏估计（06 章）：
  样本均值 E[X̄] = μ（线性性的直接应用）
  样本方差除 n−1：E[S²] = σ²（无偏修正）

③ 风险与不确定性：
  期望 = 点预测；方差 = 不确定性量化
  → 深度学习的不确定性 = 预测分布的方差估计（09 章）

④ 强化学习：
  值函数 = 期望回报；贝尔曼方程 = 条件期望方程
```

## 8. 常见分布的期望方差速查与数值陷阱

### 8.1 速查表（工程最常用 6 个）

| 分布 | 参数 | E[X] | Var(X) | 使用提示 |
|------|------|:---:|:---:|---------|
| 伯努利 | p | p | p(1−p) | 单次 0/1 |
| 二项 B(n,p) | n, p | np | np(1−p) | n 次独立试验 |
| 泊松 P(λ) | λ | λ | **λ**（均值=方差） | 稀有事件计数 |
| 均匀 U(a,b) | a, b | (a+b)/2 | (b−a)²/12 | 随机数 |
| 指数 Exp(λ) | λ | 1/λ | 1/λ² | 无记忆性 |
| 正态 N(μ,σ²) | μ, σ | μ | σ² | CLT 归宿 |

### 8.2 数值计算陷阱（计算机实现）

```text
陷阱一：方差计算的灾难性抵消
  公式 Var = E[X²] − (E[X])² 在 μ 很大时精度崩溃：
  E[X²] 与 (E[X])² 都是大数，相减得小差 → 浮点精度全丢
  ✅ 正确实现（Welford 算法）：增量式更新
    mean += (x − mean)/n
    M2 += (x − mean_old)·(x − mean_new)
  → 数值稳定的方差计算是统计库的标配

陷阱二：期望不存在的分布
  柯西分布 E 不存在（厚尾）→ 样本均值不收敛
  → 工程上先看数据厚尾程度（金融收益）再用均值

陷阱三：量纲与归一化
  标准差与原数据同量纲（方差是平方）→ 报告用 σ
  → 标准化（z-score）= (x − μ)/σ 是特征工程的标配
```

### 8.3 矩与机器学习特征的对应

```text
偏度（三阶矩）：分布不对称 → 特征工程中"对数化"的动机
峰度（四阶矩）：厚尾 → 异常检测（尾部事件概率）与风险建模

实践提示：
  建模前先看矩（偏度/峰度）——决定数据变换与模型选择（02 章 8 节）
  报告均值同时报告标准差（单报均值会误导——Anscombe 教训，08 章）
```

## 9. 核心要点与思考题

> 🎯 **本章三句话总结**：
> 1. 期望线性无条件、乘积拆分要独立；方差"系数平方 + 独立才可加"——两条最常错的规则；
> 2. 切比雪夫不等式用矩界住概率（不依赖分布）；均值方差 = σ²/n 是"样本量换精度"的数学；
> 3. 条件期望 = 最优预测（最小均方误差）——回归、方差分解、强化学习的共同地基；损失函数 = 期望的样本估计。

**思考题**：

1. E[XY] = E[X]E[Y] 什么时候成立？（→ 2）
2. Var(X+Y) 为什么不一定等于 Var(X)+Var(Y)？（→ 4）
3. 为什么样本量越大均值越准？（→ 4 推论）
4. 回归为什么用条件期望？（→ 6 最优预测）
