## 1. 随机数生成：模拟的地基

```text
伪随机数（PRNG）：确定性算法产生"统计上像随机"的序列
  Java：java.util.Random（LCG）/ ThreadLocalRandom
  ⚠️ 安全性：加密场景必须 SecureRandom（可预测的 PRNG = 漏洞）

伪随机 ≠ 真随机：
  种子相同 → 序列相同（可复现实验！）
  周期有限（高质量 PRNG 周期极长：梅森旋转 2^19937−1）
  → 随机种子管理：固定种子 = 可复现；随机种子 = 无偏

分布采样（变换法）：
  均匀 U(0,1) → 任意分布：
  逆变换：X = F⁻¹(U)（指数：X = −ln(1−U)/λ）
  Box-Muller：U₁, U₂ → 标准正态（极坐标变换，03 章雅可比）
  拒绝采样：接受-拒绝包装（复杂分布）
```

## 2. 采样方法

| 方法 | 思想 | 适用 |
|------|------|------|
| 逆变换采样 | F⁻¹(U) | 分布函数可逆（指数/柯西） |
| Box-Muller | 极坐标变换 | 正态（教科书标准） |
| 拒绝采样 | 提议分布 + 接受概率 | 任意分布（效率取决于匹配度） |
| 重要性采样 | 加权修正 | 稀有事件/方差缩减 |
| 吉布斯采样 | 逐维条件采样 | 高维联合分布（MCMC 家族） |
| 重参数化 | 噪声 + 确定性变换 | 深度学习（VAE 的采样技巧） |

```text
深度学习的采样连接：
  Dropout = 伯努利采样（训练期随机丢弃神经元）
  VAE 重参数化 = 高斯采样 + 梯度可导（绕开采样不可微）
  扩散模型 = 高斯噪声的逐步去噪（采样 = 生成过程）
```

## 3. 蒙特卡洛：计算机的概率引擎

```text
（05 章已给原理，此处给工程全景）

蒙特卡洛估计 = 样本均值近似期望（大数定律保证）
  E[f(X)] ≈ (1/n)Σf(Xᵢ)

四大应用域：
  ① 数值积分：高维积分唯一方案（微积分 07 章）
  ② 随机模拟：排队系统/库存/供应链（离散事件模拟）
  ③ 金融定价：期权（几何布朗运动路径模拟）
  ④ 统计推断：Bootstrap（第 6 节）/MCMC（第 5 节）

误差与改进：
  误差 ∝ σ/√n（CLT）——与维度无关
  方差缩减：重要性采样/对偶变量/分层采样（常数级改善）
  收敛诊断：样本量 n 与置信区间（06 章）

⚠️ 蒙特卡洛 ≠ 精确：结果是"统计近似"——需要报告误差
```

> 🎯 **核心要点**：蒙特卡洛 = "用随机性解决确定性难题"——高维积分、模拟、推断的统一范式。它与深度学习的连接：训练梯度 = 小批量蒙特卡洛估计（期望损失的样本近似）。

## 4. A/B 测试：决策的标准流程

```text
A/B 测试 = 假设检验（07 章）的产品化流程

完整流程八步：
  ① 明确指标（主指标 + 护栏指标）
  ② 提出假设（H₀/H₁，07 章）
  ③ 计算样本量（功效 80%、α 5%、最小效应）
  ④ 随机分组（分层随机/桶化——防分组偏差）
  ⑤ 运行测试（覆盖完整周期；防偷看）
  ⑥ 分析结果（显著性 + 效应量 + 置信区间）
  ⑦ 决策（上线/放弃/继续收集）
  ⑧ 复现验证（长期指标跟踪）

统计要点回顾（07 章）：
  两样本 t 检验（转化率用 Z 比例检验）
  多重比较校正（多指标/多版本）
  停止规则：预先定好的样本量或序贯方法（防 p-hacking）

工程形态：
  特征开关（feature flag）+ 实验平台（分层流量）
  护栏指标（延迟/崩溃率）防"指标优化但体验恶化"
```

## 5. 贝叶斯推断与 MCMC

### 5.1 贝叶斯推断框架（01 章公式的工程化）

```text
后验 ∝ 似然 × 先验：P(θ|D) ∝ P(D|θ)·P(θ)

与频率主义的差异：
  频率：θ 是固定常数（置信区间是过程的性质）
  贝叶斯：θ 是随机变量（后验分布给出"θ 的完整信念"）

共轭先验（闭式解）：
  伯努利 θ ~ Beta(α,β)：后验仍 Beta（02 章）
  正态均值 ~ 正态：后验正态
  → 点击率估计/AB 测试的贝叶斯版（Thompson 采样！）

Thompson 采样（强化学习/推荐）：
  每个臂维护 Beta 后验 → 从后验采样选臂
  → 探索-利用的自动平衡（"概率匹配"）
```

### 5.2 MCMC：一般后验的采样

```text
问题：复杂后验无法解析 → 用采样近似

MCMC（马尔可夫链蒙特卡洛）：
  构造一条"以目标分布为稳态"的马尔可夫链
  采样点（丢弃 burn-in 后）≈ 后验样本

  梅特罗波利斯-黑斯廷斯（MH）：提议 + 接受/拒绝
  吉布斯采样：逐维条件分布更新（高维高效）

工程要点：
  收敛诊断（链的混合/有效样本量）
  现代工具：NumPyro/Stan/PyMC（概率编程语言）
  ⚠️ 计算贵（万级采样）——大模型时代用变分近似（VI）替代
```

## 6. 自举法（Bootstrap）

```text
思想：重采样（有放回抽样）近似"抽样分布"
  不用假设总体分布（非参数方法！）

流程：
  ① 从样本 n 中有放回抽 n 个（Bootstrap 样本）
  ② 计算统计量（均值/中位数/回归系数）
  ③ 重复 B 次（如 1000）→ 得到统计量的经验分布
  ④ 取分位数 → 置信区间（如 2.5% ~ 97.5%）

价值：
  无分布假设（厚尾/未知分布都行）
  模型无关（任何统计量都能用）
  小样本的救命稻草（医学/工程小数据）

⚠️ 假设：样本代表总体（有偏样本 → Bootstrap 无济于事）
```

## 7. 机器学习中的概率视角

```text
概率 = 机器学习的统一语言：

监督学习 = 条件分布建模：
  分类：P(y|x)（softmax = 多项分布的参数化）
  回归：P(y|x) = N(f(x), σ²)（高斯）
  训练 = MLE/MAP（06 章损失函数映射）

生成模型 = 联合分布建模：
  GMM（03 章）、VAE（隐变量 + 变分推断）、扩散模型（SDE）
  → 2025-2026 生成式 AI 的统计骨架

不确定性量化（UQ）：
  偶然不确定性（aleatoric）：数据本身噪声（不可消除）
  认知不确定性（epistemic）：模型知识不足（可加数据消除）
  → 可靠部署（医疗/自动驾驶）的必备组件

信息论衔接（信息论体系）：
  交叉熵 = 概率分布的"惊讶度"期望（训练损失）
  熵 = 不确定性的度量
  KL 散度 = 分布距离（变分推断/扩散模型的损失）
```

## 8. 2026 趋势：LLM 与 token 概率

```text
（2026-08 检索，LLM 概率视角的三个方向）

① 训练 = 序列似然最大化：
  自回归 LLM：P(x₁x₂...xₙ) = Π P(xₜ|x<t)（链式法则，01 章）
  训练损失 = 交叉熵 = 负对数似然（06 章 MLE 同构）
  → "LLM 就是巨型条件概率分布"

② 不确定性量化（贝叶斯方法回到中心）：
  TokUR（ICLR 2026）：注意力权重的低秩扰动构造贝叶斯集成，
    token 级分解不确定性（总/偶然/认知三成分）
  Textual Bayes（ICLR 2026）：把提示词当"文本参数"，
    MCMC（MHLP）做贝叶斯推断——提升准确率与校准
  CoCoA（NeurIPS 2025）：最小贝叶斯风险框架统一
    "置信度（token 概率）"与"一致性（多次采样语义一致）"
  → 校准（calibration）：预测概率 = 真实频率的程度

③ 已知局限（2026 综述）：
  LLM 擅长模式识别/MLE，但**违反条件独立与柯尔莫哥洛夫公理**
  （概率"一致性"差——自相矛盾的 token 概率）
  最佳校准来源 = 隐式 softmax 概率（而非显式文本概率估计）
  → 概率论为 LLM 可靠性的评估与改进提供理论语言
```

## 9. 核心要点与思考题

> 🎯 **本章三句话总结**：
> 1. 计算机的概率三件套：随机数（可复现模拟）、蒙特卡洛（期望近似，误差 σ/√n）、采样（MCMC/Bootstrap——无分布假设的推断）；
> 2. A/B 测试 = 假设检验的产品化（预先注册 + 功效计算 + 防 p-hacking）；贝叶斯（共轭先验/Thompson 采样）提供决策的另一语言；
> 3. 机器学习 = 概率建模（监督 = 条件分布，生成 = 联合分布）；2026 年 LLM 的 token 概率与贝叶斯不确定性量化（TokUR/Textual Bayes）把概率论推到生成式 AI 中心。

**思考题**：

1. 为什么深度学习用"固定种子"复现实验？（→ 1 PRNG 可复现）
2. A/B 测试为什么必须预先算样本量？（→ 4 功效）
3. Bootstrap 与中心极限定理的关系？（→ 6 非参数替代）
4. LLM 的"置信度"（token 概率）为什么不总是校准的？（→ 8 已知局限）
