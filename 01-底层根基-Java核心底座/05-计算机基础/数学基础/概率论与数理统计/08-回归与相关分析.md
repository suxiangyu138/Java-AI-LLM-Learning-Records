# 回归与相关分析

> 回归回答"X 怎么影响 Y"（建模），相关回答"X 与 Y 关联多强"（度量）——最小二乘是两者的计算核心（线性代数投影的统计形态），R² 是拟合优度，回归诊断保证结论可信——**线性回归是统计学通向机器学习的桥梁**

## 1. 相关与回归的区别

| 维度 | 相关（correlation） | 回归（regression） |
|------|:---:|:---:|
| 回答 | 关联有多强（对称） | X 如何预测/影响 Y（不对称） |
| 输出 | ρ ∈ [−1,1]（无量纲） | 预测方程 y = f(x) |
| 变量角色 | 不分主次 | 明确 X（解释）、Y（被解释） |
| 数学 | Cov 归一化 | 条件期望的建模（03 章） |

```text
⚠️ 相关 ≠ 因果（03 章已强调，此处给出判断工具）：
  混淆变量（冰淇淋 ↔ 溺水 ← 温度）
  双向因果（锻炼 ↔ 健康）
  伪相关（随机巧合——"相关性军备竞赛"的笑话素材）
  → 因果推断需要实验设计/因果方法（工具变量/倾向得分）
```

## 2. 线性回归模型

```text
模型：Y = β₀ + β₁X + ε
  β₀ 截距、β₁ 斜率（回归系数）、ε 随机误差

误差假设（高斯-马尔可夫条件）：
  ① E[ε] = 0（无系统偏差）
  ② Var(ε) = σ²（同方差）
  ③ ε 相互独立
  ④ ε ~ N(0, σ²)（正态——推断需要，估计不需要）

系数含义：X 每增加 1 单位，Y 平均变化 β₁
  → 业务语言："广告费每多 1 万，销量平均多 β₁ 万"

矩阵形式（线性代数衔接）：
  y = Xβ + ε（X 为设计矩阵）
  → 最小二乘解 β̂ = (XᵀX)⁻¹Xᵀy（06 章线性代数投影）
```

> 🎯 **核心要点**：回归系数 = "X 变化 1 单位时 Y 的条件期望变化"——回归是**条件期望的建模**（03 章 E[Y|X] 的线性近似），这是它与机器学习预测模型的共同理论根源。

## 3. 最小二乘估计

```text
目标：min Σ(yᵢ − β₀ − β₁xᵢ)²（残差平方和最小）

求解（一元闭式解）：
  β̂₁ = Σ(xᵢ−x̄)(yᵢ−ȳ) / Σ(xᵢ−x̄)² = Cov(x,y)/Var(x)
  β̂₀ = ȳ − β̂₁x̄

两条路径殊途同归（体系呼应）：
  ① 代数：求偏导 = 0（微积分极值，06 章）
  ② 几何：ŷ = Xβ̂ = 投影（线性代数 06 章，y 到列空间的投影）
  → "统计 = 微积分 × 线性代数的交汇点"

MLE 视角（06 章）：高斯误差假设下，最小二乘 = MLE
  → 最小二乘不是"拍脑袋"的准则，而是正态假设的自然结论
```

## 4. 相关系数与决定系数 R²

```text
皮尔逊相关系数（03 章）：
  r = Cov(x,y)/(sₓ·sᵧ)（样本版）
  r² = 回归解释的方差比例

决定系数 R²（拟合优度）：
  R² = 1 − SSE/SST（SSE 残差平方和，SST 总平方和）
     = 回归平方和/总平方和
  含义：Y 的方差中，被 X 解释的比例（0 ≤ R² ≤ 1）

解读规范：
  R² = 0.8：80% 的 Y 变动可由 X 解释（好模型）
  ⚠️ R² 高 ≠ 因果；R² 低 ≠ 模型无用（预测精度另说）
  R² = 1 警惕过拟合（数据点全在线上——几乎必然有异常）
  R² 与 r 的关系（一元）：R² = r²（相关与回归的统一）

对比直觉：r 描述"线性关系的强度"，R² 描述"解释力"
```

## 5. 回归的统计推断

```text
回归系数的检验（07 章假设检验应用）：
  H₀：β₁ = 0（X 与 Y 无线性关系）
  t = β̂₁/SE(β̂₁) ~ t(n−2)
  → p < 0.05 → X 显著解释 Y

置信区间：
  β̂₁ ± t_{α/2}·SE(β̂₁)（系数的不确定性）
  预测区间（新观测 y）> 置信区间（均值 E[Y|X]）——预测更不确定

方差分解（ANOVA 表）：
  SST = SSR + SSE（总 = 回归解释 + 残差）
  回归 F 检验 = 模型整体显著性（多元回归用 F 而非单个 t）
```

## 6. 回归诊断

```text
残差分析（检验第 2 节假设是否成立）：
  ① 残差 vs 拟合值：随机散布 ✓ / 喇叭形 ✗（异方差）
  ② 残差 QQ 图：直线 ✓ / 弯曲 ✗（非正态）
  ③ 残差 vs 时间/顺序：无模式 ✓ / 趋势 ✗（自相关）

影响点与异常点：
  杠杆值（leverage）：X 极端点（对拟合影响大）
  残差大：异常值（数据错误/真实特例）
  库克距离：综合"杠杆×残差"的影响度量

经典案例（Anscombe 四重奏）：
  四组数据 r、R² 相同，散点图完全不同（线性/曲线/异常点/垂直）
  → 永远先画图再回归！数字会骗人
```

> ⚠️ **工程教训**：R² 高、t 显著 ≠ 模型可信——**回归诊断（残差图）是统计的"体检"**，跳过诊断的回归结论不可靠（Anscombe 四重奏是最好的教学警示）。

## 7. 多元线性回归

```text
模型：Y = β₀ + β₁X₁ + ... + βₚXₚ + ε
  每个 βⱼ 的解释：其他变量固定时，Xⱼ 每增 1 单位的平均变化
  → "控制变量"的统计意义（偏效应）

关键概念：
  多重共线性：Xⱼ 间高度相关 → 系数估计不稳定（方差膨胀 VIF）
    → 相关矩阵诊断（03 章）、正则化（岭回归）缓解
  交互项：β·X₁X₂（X₂ 改变 X₁ 的效应）
  多项式项：X²（非线性趋势的线性化）

模型选择（奥卡姆剃刀）：
  调整 R²（惩罚参数个数）、AIC/BIC、交叉验证
  → 避免"加变量就提高 R²"的过拟合陷阱
```

## 8. 方差分析概述

```text
ANOVA（方差分析）：多个组均值是否相等的检验
  H₀：μ₁ = μ₂ = ... = μₖ（各组无差异）

思想（04 章总方差定律）：
  总方差 = 组间方差（B） + 组内方差（W）
  F = (组间/自由度)/(组内/自由度)
  → 组间差异远大于组内波动 → 拒绝 H₀

与回归的统一：ANOVA 是"分类变量回归"的特例（虚拟变量）
  → 线性模型框架（GLM）统一了回归与 ANOVA

应用：多版本 A/B/C 测试、实验分组比较
  ⚠️ 多组比较用 ANOVA 而非两两 t 检验（多重比较误差，07 章）
```

## 9. 从回归到机器学习

```text
线性回归 = 机器学习的"第一课"（理论与实现的完美起点）：

相同点：
  目标函数：最小二乘/交叉熵 = 期望损失最小化（04 章）
  推断框架：MLE/MAP（06 章）
  预测 = 条件期望近似（03 章）

演进路径（从统计到 ML）：
  线性回归（参数化，闭式解）
    → 岭/套索（正则化 = 偏差-方差权衡，06 章）
    → 广义线性模型（逻辑回归——分类）
    → 非线性（核方法/树/神经网络——自动特征）

关键差异（统计 vs ML 视角）：
  统计关注"推断"（系数是否显著/置信区间）
  ML 关注"预测"（泛化误差/交叉验证）
  → 两者互补：统计给可信度，ML 给预测力
```

## 10. 核心要点与思考题

> 🎯 **本章三句话总结**：
> 1. 回归建模条件期望（系数 = 平均变化），最小二乘 = 投影 = 高斯 MLE——微积分×线性代数×统计的三方交汇；
> 2. R² 是解释力（方差比例），显著 ≠ 因果 ≠ 实际重要；残差诊断是回归的体检（Anscombe 警示）；
> 3. 多元回归引入共线性/模型选择；ANOVA 是分类回归的特例；线性回归是通往机器学习的标准桥梁。

4. 多组比较为什么用 ANOVA 而非两两 t 检验？（→ 8 多重比较）
