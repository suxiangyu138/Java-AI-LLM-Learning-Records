# 多维随机变量

> 现实的数据是"多维的"：联合分布描述变量间的依赖，边缘分布"积掉"无关维度，条件分布"给定信息后的分布"，协方差与相关系数量化依赖强度——多元正态分布 + 协方差矩阵是机器学习（PCA/高斯混合/卡尔曼滤波）的统一语言

## 1. 联合分布与边缘分布

```text
联合分布（离散）：P(X=xᵢ, Y=yⱼ) = pᵢⱼ（二维表）
联合密度（连续）：f(x, y) ≥ 0，∬f(x,y)dxdy = 1

边缘分布（"积掉"另一个变量）：
  离散：P(X=xᵢ) = Σⱼ pᵢⱼ（按行求和）
  连续：f_X(x) = ∫f(x,y)dy（微积分 07 章多元积分）

例子（考试成绩 X、作业分 Y 的联合表）：
  边缘 X 的分布 = 行和；边缘 Y = 列和
  → 边缘分布"丢掉"了变量间的关系信息

机器学习含义：
  特征 x 与标签 y 的联合 P(x,y) = 数据的完整统计
  生成模型建模 P(x,y)；判别模型直接建模 P(y|x)
```

> 🎯 **核心要点**：边缘化 = "把不关心的维度积掉"——这是统计推断的日常操作（如从联合分布求单个特征分布）；生成模型的采样与预测都围绕联合/边缘展开。

## 2. 条件分布

```text
定义（连续）：f(y|x) = f(x,y)/f_X(x)（X=x 已知时的 Y 分布）
  条件密度 = 联合 ÷ 边缘（固定 x 的"切片"归一化）

条件分布与回归的联系：
  E[Y|X=x] = ∫y·f(y|x)dy —— 条件期望（04 章）
  → 回归函数 = E[Y|X]：最优预测（均方误差意义下）
  → 线性回归 = 用线性函数近似条件期望（08 章）

条件方差：Var(Y|X=x) = E[Y²|X=x] − (E[Y|X=x])²
  → 不确定性随条件变化（异方差）

贝叶斯视角（01 章延续）：
  后验分布 = 条件分布 P(θ|数据)
  → 贝叶斯推断 = 计算条件分布（09 章 MCMC）
```

## 3. 独立性（多维视角）

```text
联合分解：X、Y 独立 ⇔ f(x,y) = f_X(x)·f_Y(y)
  （联合 = 边缘之积——"可分离"）

独立的推论：
  E[XY] = E[X]·E[Y]（乘积期望可拆）
  Cov(X,Y) = 0（不相关）

⚠️ 重要方向性（高频考点）：
  独立 ⇒ 不相关（Cov = 0）
  不相关 ⇏ 独立（Cov = 0 但存在非线性依赖！）
  例：X ~ U(−1,1)，Y = X² → Cov(X,Y) = E[X³] = 0（不相关）
      但 Y 完全由 X 决定（强依赖，不独立）

机器学习含义：
  独立同分布（i.i.d.）假设 = 样本可分解
  特征独立 → 朴素贝叶斯（01 章）
  特征相关 → 冗余（降维的必要性）
```

## 4. 协方差与相关系数

```text
协方差：Cov(X,Y) = E[(X−μₓ)(Y−μᵧ)] = E[XY] − E[X]E[Y]
  > 0：同向变动；< 0：反向；= 0：无线性关系

相关系数（归一化）：ρ = Cov(X,Y)/(σₓσᵧ) ∈ [−1, 1]
  |ρ| 接近 1 → 强线性关系（正/负）
  ρ = ±1 ⇔ Y = aX + b（完全线性）

协方差矩阵（多元推广，线性代数衔接）：
  Σ = [Var(X₁)  Cov(X₁,X₂) ...; Cov(X₂,X₁) Var(X₂) ...; ...]
  对称、半正定（特征值 ≥ 0——PCA 的前提）
  → 对角元 = 方差，非对角 = 依赖

工程要点：
  相关性 ≠ 因果性（"冰淇淋销量与溺水率相关"）
  相关矩阵 = 特征选择/多重共线性诊断的工具
```

## 5. 随机变量的函数

```text
问题：Y = g(X) 的分布是什么？

一维（分布函数法）：
  F_Y(y) = P(g(X) ≤ y) = P(X ∈ g⁻¹(−∞, y])
  例：Y = X²（X 标准正态）→ 卡方分布 χ²(1)

多维（卷积——和的分布）：
  Z = X + Y（X、Y 独立）→ f_Z(z) = ∫f_X(x)·f_Y(z−x)dx
  → 独立正态之和仍正态（02 章性质）
  → 中心极限定理的"求和结构"（05 章）

变换技巧（雅可比）：
  Y = g(X)，g 单调 → f_Y(y) = f_X(g⁻¹(y))·|(g⁻¹)'(y)|
  （与微积分 07 章换元同构）

工程：采样变换（09 章 Box-Muller 用均匀生成正态）
```

## 6. 多元正态分布

```text
X ~ N(μ, Σ)（μ 均值向量，Σ 协方差矩阵）：
  f(x) = (1/((2π)^(n/2)|Σ|^(1/2)))·exp(−(x−μ)ᵀΣ⁻¹(x−μ)/2)

核心性质（为什么它是"王冠分布"）：
  ① 边缘分布仍正态（任意子向量）
  ② 条件分布仍正态（给定部分，其余仍正态）
  ③ 线性变换仍正态：AX + b ~ N(Aμ+b, AΣAᵀ)
  ④ 不相关 ⇔ 独立（正态的独有性质！）
  ⑤ 二次型 (x−μ)ᵀΣ⁻¹(x−μ) ~ χ²(n)（马氏距离）

几何：等高线 = 椭圆（Σ 特征向量为轴，特征值为轴长平方）
  → 与线性代数 05 章谱定理的直接呼应

工程地位：
  PCA 的高斯假设、高斯混合模型（GMM）、卡尔曼滤波、
  VAE 的隐空间、高斯过程回归——全部以多元正态为骨架
```

## 7. 应用：PCA 与高斯混合模型

### 7.1 PCA（主成分分析，线性代数视角回顾）

```text
数据 X（中心化）→ 协方差 Σ = XᵀX/n（对称半正定）
→ 特征分解 Σ = QΛQᵀ（谱定理）
→ 主成分 = 最大特征值方向（方差最大方向）

概率视角：
  高斯假设下，主成分 = 数据方差最大的方向（信息量）
  降维 = 投影到前 k 个主成分（最优线性近似）

与 SVD：PCA = 中心化数据的 SVD（数值更稳，线性代数 07 章）
```

### 7.2 GMM（高斯混合模型）

```text
数据来自 K 个高斯分布的混合：
  P(x) = Σ πₖ·N(x|μₖ, Σₖ)（πₖ 混合权重）

EM 算法（期望最大化）：
  E 步：计算每个点属于各成分的后验（软分配）
  M 步：按加权更新 μₖ、Σₖ、πₖ
  → 聚类（软聚类）、密度估计、异常检测

与 K-Means 的关系：
  K-Means = GMM 的特殊情形（Σₖ = σ²I 且 σ → 0 的极限）
```

## 8. 多维数据的工程实践

### 8.1 协方差矩阵的应用清单

```text
① 特征相关性诊断（建模前体检）：
   相关矩阵热力图 → 高相关特征对（冗余）→ 降维/剔除
② PCA（07 章）：协方差特征分解 → 主成分
③ 马氏距离（异常检测）：
   d² = (x−μ)ᵀΣ⁻¹(x−μ)（考虑相关性的距离——比欧氏更合理）
   → 多变量异常检测的标准工具
④ 风险管理：组合方差 = wᵀΣw（投资组合）

⚠️ 数值注意：
  样本协方差的秩 ≤ n−1（样本少于特征时奇异）
  → 正则化（加 λI）/ 收缩估计（shrinkage）
```

### 8.2 条件概率在分类中的工程形态

```text
判别式 vs 生成式（01 章 6.3 展开）：
  判别式：直接建模 P(y|x)（逻辑回归/神经网络）——边界优化
  生成式：建模 P(x|y)·P(y)（朴素贝叶斯/GMM）——可解释、可生成

贝叶斯决策（损失视角）：
  argmax P(y|x) = 最小化误分类率（0-1 损失下）
  带成本：argmax Σ 成本(y, y')·P(y'|x)（风控/医疗的阈值调整）
  → 分类阈值的选择 = 先验与成本的贝叶斯决策（01 章 7.3）
```

### 8.3 随机向量与深度学习

```text
□ 批量数据 = 随机向量（batch, 特征）——每行一个样本
□ 嵌入层 = 查表映射（确定性）；噪声注入 = 随机向量（正则化）
□ 变分推断：隐变量 z ~ N(μ, Σ)（多元正态，06 章）
□ 高斯过程：函数空间的多元正态（贝叶斯优化的基础）
→ 多维随机变量是"数据 × 模型 × 推断"的统一框架
```

## 9. 核心要点与思考题

> 🎯 **本章三句话总结**：
> 1. 联合/边缘/条件 = 三维操作（描述/积掉/固定）；回归 = 条件期望 E[Y|X]；
> 2. 独立 ⇒ 不相关，反之不然（Y=X² 反例）；相关系数只测线性；
> 3. 多元正态四大性质（边缘/条件/线性/不相关⇔独立）使其成为统计机器学习的骨架——PCA、GMM、卡尔曼滤波都是它的应用。

**思考题**：

1. Cov=0 为什么不代表独立？（→ 3 反例）
2. 回归函数为什么是最优预测？（→ 2 条件期望）
3. 正态的"不相关 ⇔ 独立"为什么特殊？（→ 6 性质④）
4. K-Means 与 GMM 的关系？（→ 7.2）
