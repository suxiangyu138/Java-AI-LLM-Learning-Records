## 1. 随机变量与分布函数

```text
随机变量 X：把样本空间 Ω 映射到实数（试验结果的数值化）
  X = 骰子点数；X = 服务时间；X = 网页点击次数

分布函数（完备描述）：
  F(x) = P(X ≤ x)
  性质：单调不减、右连续、F(−∞)=0、F(∞)=1

两类随机变量：
  离散：取值可数（PMF 描述）—— 掷骰子、计数
  连续：取值不可数（PDF 描述）—— 时间、长度、温度
  混合（罕见）：既有离散又有连续部分
```

## 2. 离散随机变量与 PMF

```text
概率质量函数（PMF）：p(x) = P(X = x)
  条件：Σ p(x) = 1，p(x) ≥ 0

分布函数与 PMF 的关系：
  F(x) = Σ_{xᵢ ≤ x} p(xᵢ)（累积）

例（二项分布 X ~ B(n, p)）：
  p(k) = C(n,k)·pᵏ(1−p)^(n−k)，k = 0..n
  = n 次独立试验中成功 k 次的概率
```

## 3. 连续随机变量与 PDF

```text
概率密度函数（PDF）：f(x) ≥ 0，∫f(x)dx = 1
  P(a ≤ X ≤ b) = ∫ₐᵇ f(x)dx（概率 = 曲线下面积）

关键认知（连续分布的"零概率"悖论）：
  P(X = a) = 0（单点概率为零！）
  → 连续变量谈论"在某区间"而非"等于某值"
  → 密度值 f(a) 不是概率（可以 > 1），是"概率浓度"

分布函数：F(x) = ∫₋∞ˣ f(t)dt；f(x) = F'(x)（微积分衔接）

⚠️ 经典错误：把 f(x) 当概率（f 可大于 1——如 U(0, 0.5) 的密度 = 2）
```

## 4. 离散分布家族

| 分布 | 参数 | PMF 要点 | 场景 |
|------|------|---------|------|
| 伯努利 | p | X ∈ {0,1} | 单次试验（点击/不点击） |
| 二项 B(n,p) | n, p | C(n,k)pᵏ(1−p)^(n−k) | n 次独立试验成功次数 |
| 泊松 P(λ) | λ | e^(−λ)λᵏ/k! | **稀有事件计数**（点击率/故障数） |
| 几何 | p | (1−p)^(k−1)p | 首次成功所需次数 |
| 均匀（离散） | a..b | 1/(b−a+1) | 等可能整数 |

```text
泊松分布（工程最高频离散分布）：
  应用：事件发生率 λ 恒定下的计数（呼叫到达/故障/请求）
  二项近似：n 大 p 小（np = λ）时 B(n,p) ≈ P(np)
  性质：E[X] = Var[X] = λ（均值=方差是泊松的指纹）

机器学习：
  softmax 分类的交叉熵损失 ↔ 多项分布
  计数型特征（词频）常用泊松/负二项建模
```

## 5. 连续分布家族

| 分布 | 参数 | PDF 要点 | 场景 |
|------|------|---------|------|
| 均匀 U(a,b) | a, b | 1/(b−a) | 随机数、先验无知 |
| 指数 Exp(λ) | λ（率） | λe^(−λx)（x>0） | **无记忆性**：服务/寿命时间 |
| 正态 N(μ, σ²) | μ, σ | 钟形曲线 | 测量误差、大量独立和（CLT） |
| 伽马 Γ(k,θ) | k, θ | 指数的一般化 | 等待 k 个事件的时间 |
| 贝塔 Beta(α,β) | α, β | [0,1] 上 | 概率的先验（贝叶斯） |

```text
指数分布（无记忆性——唯一连续无记忆分布）：
  P(X > s + t | X > s) = P(X > t)
  → "已经等了 10 分钟，再等 5 分钟的概率 = 从零开始等 5 分钟"
  → 泊松过程的到达间隔（服务时间建模的默认选择）

贝塔分布（贝叶斯推断的"共轭先验"）：
  伯努利参数的先验 → Beta(α,β)，后验仍 Beta（共轭性）
  → 点击率估计的经典工具（09 章）
```

## 6. 正态分布深潜

### 6.1 定义与性质

```text
X ~ N(μ, σ²)：
  f(x) = (1/(σ√(2π)))·e^(−((x−μ)²)/(2σ²))

标准正态：Z = (X − μ)/σ ~ N(0,1)（标准化）
  3σ 法则：P(μ−σ < X < μ+σ) ≈ 68.3%
            P(μ−2σ) ≈ 95.4%
            P(μ−3σ) ≈ 99.7%
  → 质量管理（六西格玛）与异常检测的标尺

分位数：z_α 满足 P(Z ≤ z_α) = 1−α
  z_0.025 = 1.96（95% 置信区间的常数）
  → 统计推断的通用常数表
```

### 6.2 为什么"万物皆正态"

```text
中心极限定理（05 章）：大量独立同分布变量之和 → 正态
  → 测量误差、均值估计、噪声——一切"多次累加"都趋向正态

正态的代数性质：
  正态变量的线性组合仍正态
  独立正态之和：N(μ₁+μ₂, σ₁²+σ₂²)
  → 高斯过程/随机游走/卡尔曼滤波的数学基础

机器学习中的正态：
  高斯噪声假设 → 最小二乘 = MLE（08 章）
  高斯混合模型（GMM）、变分自编码器（VAE）的隐变量假设
  权重初始化/批归一化后的激活分布近似正态
```

## 7. 分布选择直觉

```text
选择流程图（建模第一步）：
  数据是什么类型？
  ├─ 计数（0,1,2,...）→ 泊松/负二项（稀有）或二项（固定试验次数）
  ├─ 二元（0/1）→ 伯努利（参数估计用贝塔先验）
  ├─ 正实数（时间/长度）→ 指数/伽马/对数正态
  ├─ 实数（任意）→ 正态（默认起点）/学生 t（厚尾）
  └─ [0,1] 比例 → 贝塔分布

判据：
  均值 ≈ 方差 → 泊松嫌疑
  厚尾（极端值多）→ 学生 t / 对数正态（金融数据）
  无记忆性要求 → 指数

⚠️ 模型选择 ≠ 猜分布：用数据检验（QQ 图/假设检验，07 章）
  分布假设错误 → 后续推断全错（GIGO）
```

## 8. 分布拟合与检验：假设要验证

### 8.1 为什么"看着像正态"不够

```text
分布假设错误 → 后续推断全错（GIGO）：
  正态假设下算的置信区间/检验在厚尾数据上完全失真
  → 必须用数据验证分布假设（07 章检验思想）

三种验证手段：
  ① QQ 图：分位数对比（数据分位 vs 理论分位）
     → 直线 = 拟合良好；弯曲 = 拒绝假设
  ② 假设检验：Shapiro-Wilk（正态性检验，小样本首选）
     KS 检验（任意分布对比）
  ③ 描述统计：偏度 ≈ 0、峰度 ≈ 3（正态指纹）
```

### 8.2 实战流程（以点击率数据为例）

```text
□ 1. 数据画像：直方图/描述统计（偏度/峰度）
□ 2. 假设：点击计数 → 泊松候选（均值≈方差？）
□ 3. 验证：泊松 QQ 图 / 卡方拟合优度检验（07 章）
□ 4. 备选：过离散（方差 >> 均值）→ 负二项分布
□ 5. 结论：分布 + 参数（MLE 估计，06 章）

⚠️ 大样本的"显著性陷阱"：
  n 大时微小偏离也"显著拒绝"——统计显著 ≠ 实际偏离
  → 结合图形判断（QQ 图的偏离程度）
```

### 8.3 工程注意

```text
□ 厚尾检测先行（金融/日志时间）——正态假设最危险的场景
□ 数据变换（对数/Box-Cox）可使数据"更正态"（再建模）
□ 分布选择的最终检验 = 下游任务的性能（预测/风险），
  不只看拟合优度（过拟合分布的"学术正确"）
```

## 9. 核心要点与思考题

> 🎯 **本章三句话总结**：
> 1. 随机变量数值化结果，分布函数完备描述；连续变量单点概率为零（密度不是概率）；
> 2. 六大分布各有指纹：泊松（均值=方差）、指数（无记忆）、正态（CLT 的归宿、3σ 标尺）、贝塔（概率的先验）；
> 3. 分布选择 = 建模第一步：按数据类型走流程图，再用数据验证假设（QQ 图/检验）。

**思考题**：

1. 连续密度 f(a) > 1 可能吗？（→ 3）
2. "均值=方差"提示什么分布？（→ 4 泊松）
3. 指数分布的无记忆性意味着什么？（→ 5）
4. 为什么测量误差总是近似正态？（→ 6.2 CLT）
