# 大数定律与中心极限定理

> 两大极限定理是"频率主义统计"的基石：大数定律说"均值收敛于期望"（为什么统计可行），中心极限定理说"大量独立和的分布趋向正态"（为什么正态无处不在）——蒙特卡洛方法、置信区间、A/B 测试的全部依据都在这里

## 1. 极限定理的意义

```text
概率论的核心悖论：概率是"理论的"，观测是"随机的"
  → 极限定理桥接两者：

  大数定律（LLN）：样本均值 → 期望（频率 → 概率）
  中心极限定理（CLT）：样本均值的分布 → 正态

两者地位：
  LLN 保证"估计会准"（一致性，06 章）
  CLT 保证"误差的分布可知"（置信区间/假设检验的基础）

直觉一句话：
  大数定律 = "量的积累达到确定性"
  中心极限定理 = "大量的独立随机性叠加出正态性"
```

## 2. 大数定律

```text
弱大数定律（切比雪夫形式）：
  X₁, X₂, ... 独立同分布（期望 μ，方差有限）
  样本均值 X̄ₙ = (X₁+...+Xₙ)/n
  → 对任意 ε > 0：P(|X̄ₙ − μ| ≥ ε) → 0（n → ∞）

  含义：n 足够大时，均值"几乎必然"接近期望
  → 频率（n 次试验的成功比例）→ 概率（伯努利情形的推论）
  → "统计能行的根本保证"：样本信息收敛于总体规律

证明骨架（切比雪夫不等式，04 章）：
  P(|X̄ₙ − μ| ≥ ε) ≤ Var(X̄ₙ)/ε² = σ²/(nε²) → 0
  → 方差 σ²/n 是收敛速度（样本量换精度）
```

> 🎯 **核心要点**：大数定律是"频率主义"的合法性证明——**用样本估计总体不是信仰，是定理**。它的工程推论：样本量决定估计精度（σ²/n）。

## 3. 三种大数定律

| 定律 | 条件 | 结论 | 用途 |
|------|------|------|------|
| 切比雪夫 | 独立同分布、方差有限 | 均值依概率收敛于期望 | 一般理论 |
| 伯努利 | 独立重复试验 | 频率 → 概率 | 频率主义基础 |
| 辛钦 | 独立同分布、期望存在 | 均值 → 期望（无需方差！） | 放宽条件 |

```text
强弱之别（了解即可）：
  弱 LLN：依概率收敛（概率趋向 0）
  强 LLN：几乎必然收敛（更严格）
  工程上弱 LLN 足够（统计推断都用它）
```

## 4. 中心极限定理

### 4.1 列维-林德伯格定理（i.i.d. 版本）

```text
X₁,...,Xₙ 独立同分布（期望 μ，方差 σ²）：
  标准化和：Zₙ = (X̄ₙ − μ)/(σ/√n) → N(0, 1)（n → ∞）

  含义：无论原始分布是什么，
        "样本均值（标准化后）的分布"趋向标准正态

  实际近似：n ≥ 30 时已相当好（经验法则；厚尾需更大 n）

例：掷骰子（均匀分布！）100 次的均值 → 近似正态
  → 均匀分布的标准差 σ = √((b−a)²/12)，μ = 3.5
  → 均值 ~ N(3.5, σ²/100)
```

### 4.2 为什么 CLT 是"统计学的王冠"

```text
① 置信区间（06 章）：
  均值估计的误差分布已知 → 构造区间
  x̄ ± z_α/2·(σ/√n)

② 假设检验（07 章）：
  检验统计量在零假设下近似正态 → 计算 p 值

③ 正态分布"无处不在"的解释（02 章）：
  测量误差 = 大量独立小误差之和 → 正态
  → "误差是正态的"不是假设而是定理推论

④ 蒙特卡洛误差分析（第 6 节）
```

## 5. 二项分布的正态近似

```text
棣莫弗-拉普拉斯定理（CLT 的二项特例）：
  X ~ B(n, p)，n 大时：X ≈ N(np, np(1−p))

  标准化：Z = (X − np)/√(np(1−p)) ≈ N(0,1)

  连续性修正（提升精度）：P(X = k) ≈ P(k−0.5 < X < k+0.5)

精度经验：
  np ≥ 5 且 n(1−p) ≥ 5 时可用（泊松近似条件 np 小）
  二项 → 泊松（np 小）→ 正态（np 大）——分布的近似谱系

应用：民意调查误差 ±3% 的计算依据：
  比例估计的标准误 = √(p(1−p)/n)
  → n = 1067 时 ±3%（95% 置信）
```

## 6. 蒙特卡洛：极限定理的工程化

### 6.1 原理

```text
蒙特卡洛估计期望：
  E[g(X)] ≈ (1/n)·Σ g(Xᵢ)（样本均值）
  → 大数定律保证收敛（一致性）
  → CLT 给出误差分布（正态，σ/√n）

  → 积分计算（微积分 07 章）：
  ∫f dx ≈ 均值 × 区间长度（随机采样的数值积分）
```

### 6.2 误差与维度

```text
误差：~σ/√n（与维度无关！）
  → 高维积分唯一可行方案（微积分 07 章呼应）

⚠️ 注意：σ/√n 是"统计误差"——n 增大误差减小但慢（√n）
  精度提高 10 倍 → 样本量 ×100（代价）
  方差缩减技术（重要采样/对偶变量）改善常数

工程应用：
  期权定价、路径规划、渲染（路径追踪）、
  机器学习（Dropout/采样梯度/强化学习）
```

## 7. 统计推断的极限定理基础

```text
参数估计（06 章）：
  一致性：估计量收敛于真值（LLN 的直接推论）
  渐近正态：估计量分布 → 正态（MLE 的渐近理论）

置信区间（06 章）：
  x̄ ± z·(σ/√n)——CLT 保证误差分布已知

假设检验（07 章）：
  Z 统计量、t 统计量——CLT/正态假设下的检验

A/B 测试（09 章）：
  两组均值差的分布 → 正态（CLT）
  → 显著性判断（p 值）的数学依据

中心极限定理的"温柔陷阱"：
  厚尾分布（金融收益）收敛极慢——"n=30 够用"失效
  → 大样本 ≠ 自动正态（分布选择仍关键，02 章）
```

## 8. 极限定理的工程应用清单

### 8.1 置信区间与样本量的实战计算

```text
场景：估计 App 次日留存率 p（目标：95% 置信，误差 ±1%）
  标准误 = √(p(1−p)/n) ≤ 0.01
  最坏情况 p = 0.5（方差最大）→ n ≥ (1.96/0.01)²·0.25 ≈ 9604

工程要点：
  □ 比例估计的样本量公式：n = z²·p(1−p)/e²（p 取 0.5 最保守）
  □ 先定精度（e）再算样本量（不是"越多越好"——成本约束）
  □ 事后报告：n、置信区间、效应量（06/07 章规范）
```

### 8.2 蒙特卡洛在工程中的典型形态

```text
① 概率估计（重抽样）：Bootstrap（09 章）——分布未知的区间
② 期望估计（积分）：期权定价、贝叶斯 MCMC（09 章）
③ 系统模拟：排队/库存/可靠性（离散事件模拟）
④ 机器学习：小批量梯度 = 蒙特卡洛估计（04 章期望视角）

⚠️ 收敛警示：
  误差 σ/√n——"减半误差要 4 倍样本"
  方差缩减优先（重要性采样）再堆样本（成本意识）
```

### 8.3 CLT 的"陷阱"清单

```text
□ 独立假设：时间序列（自相关）不满足 → CLT 失效
  → 序列数据用块自助/平稳性方法
□ 厚尾分布：收敛极慢（柯西分布根本不收敛）
  → 金融/极端事件数据先用厚尾模型（02 章）
□ 小样本：n < 30 且分布偏斜 → CLT 近似差
  → 用 t 分布/非参数方法（Bootstrap）
□ "大样本 = 一定正态"：错——CLT 说的是"均值"的分布，
  不是"数据本身"的分布（数据仍可厚尾）
```

## 9. 核心要点与思考题

> 🎯 **本章三句话总结**：
> 1. 大数定律：均值 → 期望（σ²/n 的收敛速度）——统计"能行"的合法性证明；
> 2. 中心极限定理：标准化的均值 → N(0,1)——置信区间、假设检验、正态"无处不在"的全部依据；
> 3. 蒙特卡洛 = LLN（收敛）+ CLT（误差正态）的工程化：误差 σ/√n 与维度无关，高维积分唯一方案。

**思考题**：

1. 为什么"频率 → 概率"是定理而非信仰？（→ 2 伯努利 LLN）
2. CLT 为什么说"均匀分布掷骰子均值也正态"？（→ 4 任何分布）
3. 民意调查 ±3% 的 n 是怎么算的？（→ 5 标准误）
4. 蒙特卡洛为什么适合高维积分？（→ 6.2 维度无关）
