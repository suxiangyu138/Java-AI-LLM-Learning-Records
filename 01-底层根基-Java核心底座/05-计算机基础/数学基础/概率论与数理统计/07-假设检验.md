## 1. 检验的思想：反证 + 概率

```text
假设检验 = "概率版的归谬法"：
  ① 先假设原假设 H₀ 成立（如"新算法没有提升"）
  ② 计算"在当前假设下，观测到这么极端数据"的概率（p 值）
  ③ 概率太小（p < α）→ 数据与 H₀ 矛盾 → 拒绝 H₀
     概率不小 → 无法拒绝 H₀（不等于接受！）

一句话：小概率事件发生了 → 假设值得怀疑

与日常推理的区别：
  数学反证：矛盾 → 结论确定
  统计检验：概率极低 → 结论"带风险"（α 就是风险上限）
```

## 2. 原假设与备择假设

```text
原假设 H₀（null）：待检验的"保守立场"
  = "没有效果"（新药无效、A/B 无差异、参数等于某值）
备择假设 H₁：与原假设对立的"研究立场"
  = "有效果"（新药有效、有差异）

为什么"默认保守"：
  证明"有效果"需要强证据（宁可错杀，不可误放）
  → 与法律"无罪推定"同构（H₀ = 无罪）

检验方向：
  双侧：H₁: μ ≠ μ₀（有无差异）
  单侧：H₁: μ > μ₀（是否更大）——需先验理由才用单侧

A/B 测试映射：
  H₀：新版本转化率 ≤ 旧版本（无提升）
  H₁：新版本转化率 > 旧版本（有提升）
```

> 🎯 **核心要点**：H₀ 的选取决定了"举证责任"——想证明"有提升"就把"无提升"放 H₀，让数据说话；**"不能拒绝 H₀" ≠ "H₀ 为真"**（证据不足 ≠ 无效果）。

## 3. 两类错误

| 错误 | 名称 | 含义 | 概率 | 类比 |
|:---:|------|------|:---:|------|
| 第一类 | 弃真（Type I） | H₀ 为真却被拒绝 | α（显著性水平） | 无罪判有罪 |
| 第二类 | 纳伪（Type II） | H₀ 为假却未拒绝 | β | 有罪判无罪 |

```text
关键关系：
  ① α 与 β 此消彼长（样本量固定时）：α 越小 → β 越大
  ② 增大样本量 → α、β 同时减小（两全其美的唯一途径）
  ③ 惯例：α = 0.05（5%）；β 常取 0.2（功效 0.8）

工程意义：
  第一类错误：误报（上线了没用的功能）——可容忍但别频繁
  第二类错误：漏报（错过了真正有效的改动）——A/B 测试的主要风险
  → 样本量计算（第 7 节）就是在 α、β、效应量之间做平衡
```

## 4. 检验统计量与拒绝域

```text
检验统计量：数据 → 一个数（其分布在 H₀ 下已知）
  例（均值检验）：Z = (X̄ − μ₀)/(σ/√n) ~ N(0,1)（σ 已知，CLT）
                  t = (X̄ − μ₀)/(S/√n) ~ t(n−1)（σ 未知）

拒绝域：统计量落在极端区域 → 拒绝 H₀
  双侧：|Z| > z_{α/2}
  单侧：Z > z_α（或 Z < −z_α）

流程四步：
  ① 设定 H₀/H₁ 与 α
  ② 计算检验统计量
  ③ 查临界值 / 计算 p 值
  ④ 比较裁决：p < α 拒绝；p ≥ α 不拒绝
```

## 5. p 值的正确解读

```text
p 值定义：H₀ 为真时，观测到"当前或更极端"结果的概率

✅ 正确解读：
  "在'无效果'的假设下，出现这种数据的概率是 3%"
  → 数据与 H₀ 不兼容 → 拒绝（p = 0.03 < 0.05）

❌ 高频误读（面试/论文审查必问）：
  "p = 0.03 意味着 H₀ 为真的概率是 3%" ✗
  （p 值假设 H₀ 为真，不能反推 H₀ 的概率——那需要贝叶斯）
  "p = 0.03 意味着效果有 97% 可能真实" ✗（同上）
  "p > 0.05 意味着没有效果" ✗（证据不足 ≠ 无效果）

p 值与显著性：
  p < α → "统计显著"（statistically significant）
  ⚠️ 统计显著 ≠ 实际重要（大样本下微小差异也显著）
  → 显著性看 p，重要性看效应量（第 7 节）
```

> 🎯 **核心要点**：p 值是"数据在 H₀ 下的稀有度"，不是"H₀ 的概率"——这个区分是统计素养的试金石。报告规范：p 值 + 效应量 + 置信区间三者齐备，不单报 p。

## 6. 三大经典检验：Z / t / 卡方

### 6.1 Z 检验与 t 检验（均值）

| 情形 | 统计量 | 分布 | 适用 |
|------|--------|------|------|
| σ 已知（罕见） | Z = (X̄−μ₀)/(σ/√n) | N(0,1) | 理论教学 |
| σ 未知（常态） | t = (X̄−μ₀)/(S/√n) | t(n−1) | **实际首选** |
| 两样本（独立） | t = (X̄₁−X̄₂)/SE | t（合并/韦尔奇） | **A/B 测试** |
| 配对样本 | t = D̄/(S_D/√n) | t(n−1) | 前后对比 |

```text
t vs Z：σ 未知用 S 估计 → 分布更"胖尾"（t）
  n 大时 t → Z（t 分布的极限）
  → 实际中几乎都用 t（统计软件默认）
```

### 6.2 卡方检验（分类数据）

```text
拟合优度：观测频数 vs 理论频数
  χ² = Σ (Oᵢ − Eᵢ)²/Eᵢ ~ χ²(k − 1)

独立性检验（列联表）：
  H₀：两分类变量独立（如性别与购买行为）
  Eᵢⱼ = 行和×列和/总数 → χ² 统计量
  → A/B 测试中转化率比较的离散版
```

## 7. 功效与样本量

```text
功效（power）= 1 − β = 正确拒绝 H₀ 的概率
  → "真有效果时能检测出来的概率"

功效四要素（互相关联）：
  ① α（显著性）：α 大 → 功效大（代价：误报多）
  ② 效应量（effect size）：效果越明显 → 功效越大
  ③ 样本量 n：越大 → 功效越大
  ④ 变异性 σ：越小 → 功效越大

样本量计算（A/B 测试上线前的必备步骤）：
  n ≈ 2·(z_{α/2} + z_β)²·σ²/δ²（δ = 最小可检测效应）

工程示例：转化率 5% → 6%（δ = 1%）：
  功效 80%、α = 5% → 每组约需 3 万+ 样本
  → 先算样本量再开测试（否则测试"没功效"白跑）
```

## 8. 常见误区与规范

| 误区 | 正确认知 |
|------|---------|
| "p < 0.05 就发表/上线" | 显著性 + 效应量 + 实际意义三者结合 |
| "不显著 = 没效果" | 可能功效不足（样本太少） |
| 中途偷看数据就停 | 多次检验 inflate α（p-hacking） |
| 多个指标取显著者 | 多重比较需校正（Bonferroni/FDR） |
| 单侧检验无理由 | 双侧更保守，单侧需先验 |
| 显著就复制 | 需独立复现（复制危机教训） |

```text
A/B 测试的统计规范（09 章展开）：
  预先注册：假设、指标、样本量先定（防 p-hacking）
  运行时长：覆盖完整周期（周末/工作日）
  多重比较：主指标优先，其余做校正
  结果报告：p 值 + 置信区间 + 效应量
```

## 9. 核心要点与思考题

> 🎯 **本章三句话总结**：
> 1. 假设检验 = 概率反证：p < α 拒绝 H₀；"不能拒绝" ≠ "H₀ 为真"；
> 2. 两类错误此消彼长（α/β），样本量是两全其美的唯一途径；功效 = 1−β 决定测试"能不能检测出效果"；
> 3. p 值是"数据在 H₀ 下的稀有度"不是"H₀ 的概率"；统计显著 ≠ 实际重要——报告要 p + 效应量 + 置信区间。

**思考题**：

1. 为什么"不显著"不等于"没效果"？（→ 7 功效）
2. p = 0.03 的正确解读是什么？（→ 5）
3. A/B 测试上线前为什么必须算样本量？（→ 7）
4. 多次偷看数据为什么危险？（→ 8 p-hacking）
