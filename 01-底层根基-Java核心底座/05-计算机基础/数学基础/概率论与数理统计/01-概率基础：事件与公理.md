## 1. 样本空间与事件

```text
样本空间 Ω：一次试验所有可能结果的集合
 掷骰子：Ω = {1,2,3,4,5,6}
 抛两次硬币：Ω = {HH, HT, TH, TT}

事件 = Ω 的子集（一组结果的集合）
  事件 A = "掷出偶数" = {2,4,6}
  事件 B = "掷出 ≥ 4" = {4,5,6}

事件运算（与集合运算同构）：
  并 A∪B（至少一个发生）
  交 A∩B（同时发生）
  补 Aᶜ（不发生）
  互斥：A∩B = ∅（不能同时）

计数基础（组合数学衔接）：
  古典概率 P(A) = |A|/|Ω|（等可能模型）
  → 排列组合是概率计算的基本工具
```

## 2. 概率的三条公理

```text
Kolmogorov 公理（概率 = 集合上的测度）：
  ① 非负性：P(A) ≥ 0
  ② 规范性：P(Ω) = 1
  ③ 可列可加：互斥事件 A₁, A₂, ... → P(∪Aᵢ) = ΣP(Aᵢ)

由公理推出的基本性质：
  P(∅) = 0
  P(Aᶜ) = 1 − P(A)
  P(A∪B) = P(A) + P(B) − P(AB)（容斥——别漏交）
  A ⊆ B → P(A) ≤ P(B)

频率 vs 概率：
  频率 = 试验中的比值（随机波动）
  概率 = 公理化的理论值（频率的极限——大数定律，05 章）
```

> 🎯 **核心要点**：概率三公理看似平凡，却是"一切概率计算"的地基——容斥公式（P(A∪B)）、补集转换（P(Aᶜ)=1−P(A)）都是日常计算的第一手段。

## 3. 条件概率

```text
定义：P(A|B) = P(AB)/P(B)（P(B) > 0）
  含义：已知 B 发生，A 的概率（"信息更新"）

性质（B 已知下的"小概率空间"）：
  P(A₁∪A₂|B) = P(A₁|B) + P(A₂|B) − P(A₁A₂|B)（同构）
  P(Aᶜ|B) = 1 − P(A|B)

乘法公式：P(AB) = P(A|B)·P(B) = P(B|A)·P(A)
  链式法则（多事件）：P(A₁A₂A₃) = P(A₃|A₁A₂)·P(A₂|A₁)·P(A₁)
  → 序列模型的概率分解基础（语言模型！）

经典问题（蒙提霍尔）：
  三门问题——换门赢的概率 2/3（条件概率更新）
  → 展示"条件概率反直觉"的教学案例
```

## 4. 独立性

```text
定义：P(AB) = P(A)·P(B) ⇔ A、B 独立
  （等价：P(A|B) = P(A)——B 的信息不改变 A）

多个事件独立（强条件）：
  任意子集组合都满足乘积公式（两两独立不够！）

独立 vs 互斥（高频混淆）：
  互斥：不能同时发生（AB = ∅，交集为空）
  独立：互不影响（乘积成立）
  两个非平凡事件**既互斥又独立不可能**（P(AB)=0 ≠ P(A)P(B)>0）
  → 独立是"信息"，互斥是"排他"——完全不同的概念

机器学习意义：
  朴素贝叶斯的"条件独立假设"（特征在类别下独立）
  独立同分布（i.i.d.）样本假设——统计推断的地基
```

## 5. 全概率公式

```text
设 B₁, B₂, ..., Bₙ 是 Ω 的一个分割（互斥且并集 = Ω）：

  P(A) = Σ P(A|Bᵢ)·P(Bᵢ)

含义：把 A 的概率按"成因"Bᵢ 分解加权求和
  → "先按原因分类，再按原因加权"

例：三个工厂（各占 30%/50%/20%）次品率 1%/2%/3%
  总次品率 = 0.3×1% + 0.5×2% + 0.2×3% = 1.9%

应用：混合模型（GMM）、分层抽样估计、错误率分解
```

## 6. 贝叶斯公式

### 6.1 公式

```text
P(H|D) = P(D|H)·P(H) / P(D)
        = P(D|H)·P(H) / Σ P(D|Hᵢ)·P(Hᵢ)

术语：
  P(H)       先验（prior）——看到数据前的信念
  P(D|H)     似然（likelihood）——假设下数据的概率
  P(H|D)     后验（posterior）——数据更新后的信念
  P(D)       证据（evidence）——归一化常数

一句话：后验 ∝ 似然 × 先验（更新信念）
```

### 6.2 例子：疾病检测

```text
患病率 0.1%（先验），检测灵敏度 99%，误报率 1%
阳性后真患病的概率：
  P(患病|阳性) = 0.99×0.001 / (0.99×0.001 + 0.01×0.999)
               ≈ 9%（远低于直觉的 99%！）
→ "先验极低时，阳性结果大多是误报"——贝叶斯最经典的反直觉

工程含义：
  罕见事件检测（欺诈/入侵）必须建模先验
  精确率-召回率的权衡与先验直接相关
```

### 6.3 贝叶斯 = 机器学习的数学形式

```text
监督学习视角：
  P(y|x) = P(x|y)·P(y) / P(x)（后验 = 分类决策的依据）
  朴素贝叶斯分类器：P(y|x) ∝ P(y)·ΠP(xᵢ|y)（条件独立简化）
  生成模型：建模 P(x|y)（GPT/扩散模型学习数据分布）
  MLE = 极大化似然；MAP = 极大化后验（带先验的 MLE）

2026 视角：LLM 的不确定性量化 = 对 P(答案|提示) 的贝叶斯估计
  （09 章：Token 概率、贝叶斯模型平均）
```

## 7. 经典悖论与思维训练

### 7.1 蒙提霍尔（三门问题）详解

```text
三扇门，一扇后有车；选一扇后，主持人（知道答案）打开一扇空门，
问：换门还是不换？

条件概率分析：
  P(车在初选门) = 1/3
  主持人打开空门的行为"透露信息"：
  → 车在另一扇未开门 = 1 − 1/3 = 2/3 → 换！

关键：主持人的行为不是随机的（他永远开空门）
  → 信息更新（条件概率）改变了概率
  → 若主持人随机开门（可能开到车），概率才是 1/2

工程启示：信息（条件）会改变概率判断——贝叶斯更新的直觉
```

### 7.2 生日悖论与哈希碰撞

```text
问题：多少人的群体中，至少两人同生日的概率 > 50%？
直觉答案：183 人；正确答案：仅 23 人！

计算：P(无碰撞) = Π(1 − i/365)，i = 1..n
  23 人时 P(有碰撞) ≈ 50.7%

工程意义（哈希碰撞的安全含义）：
  碰撞概率 ≈ n²/(2·空间大小)（生日悖论的近似）
  64 位哈希：2^32 次尝试就有 50% 碰撞概率（不是 2^64！）
  → 安全哈希必须 128/256 位（密码学体系呼应）
  → 反直觉的"平方根规律"是安全设计的核心直觉
```

### 7.3 贝叶斯与"罕见事件"思维

```text
（第 6 节疾病检测的推广）
  先验极低的事件，即使检测"灵敏"，阳性也大概率是误报
  → 安全告警（入侵检测/风控）的"误报率 vs 检出率"权衡
  → 异常检测阈值的设定 = 先验 × 成本函数的贝叶斯决策
```

## 8. 核心要点与思考题

> 🎯 **本章三句话总结**：
> 1. 概率 = 集合测度（三公理）；容斥与补集是计算第一手段；独立是"信息"、互斥是"排他"——两者不同且不可兼得；
> 2. 全概率 = 按成因分解加权；贝叶斯 = 后验 ∝ 似然 × 先验——由果推因的推断语言；
> 3. 机器学习 = 贝叶斯框架的工程化：分类靠后验、生成建模 P(x)、MLE/MAP 是参数估计的特例；罕见事件检测必须先验建模。
