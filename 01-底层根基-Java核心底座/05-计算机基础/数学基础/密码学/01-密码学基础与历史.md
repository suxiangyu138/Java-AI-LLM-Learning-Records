## 1. 密码学的目标

### 1.1 四大安全目标（CIA+）

| 目标 | 定义 | 工具 |
|------|------|------|
| 机密性 | 未授权者读不到 | 对称/非对称加密 |
| 完整性 | 数据未被篡改 | 哈希、MAC、签名 |
| 可用性 | 合法用户可访问 | 协议设计（非密码学） |
| 认证性 | 确认身份与来源 | 签名、MAC、证书 |

```text
加解密的基本要素：
  明文 P → 加密 E → 密文 C → 解密 D → 明文 P
  密钥 K：E_K(P) = C，D_K(C) = P

现代密码的铁律：算法公开（Kerckhoffs），秘密只在密钥
```

### 1.2 密码学术语速查

| 术语 | 含义 |
|------|------|
| 明文/密文 | 加密前/后的数据 |
| 密钥空间 | 所有可能密钥的集合（大小 = 2^位数） |
| 密码分析 | 不靠密钥破译密文的学问 |
| 暴力破解 | 穷举密钥空间（现代 128 位起不可行） |
| 密码套件 | 加密+MAC+密钥交换的组合（TLS 中） |

## 2. Kerckhoffs 原则与安全模型

### 2.1 Kerckhoffs 原则（1883）

**系统保密性应只依赖密钥，不依赖算法保密。**

```text
推论：
  ① 算法公开是常态（AES/SHA 全球审查后更安全）
  ② "保密算法"（security by obscurity）必被攻破
  ③ 密钥管理成为安全体系的全部重点

反例教训：专有算法（DVD 的 CSS、WEP）全部被快速破解
  —— 公开审查是密码质量的必要条件
```

### 2.2 攻击模型

| 攻击类型 | 攻击者拥有 | 强度 |
|---------|-----------|:---:|
| 唯密文攻击 | 仅密文 | 最弱 |
| 已知明文攻击 | 若干明文-密文对 | 中 |
| 选择明文攻击 | 任意选择明文获得密文 | 强 |
| 选择密文攻击 | 任意选择密文获得明文 | 最强（现代标准） |

> 🎯 现代安全模型以**选择明文/密文攻击**为基准设计——"攻击者能控制你的输入"是互联网的现实（如 API 可被任意调用）。能扛住最强模型的算法才能进标准。

## 3. 古典密码：替换与换位

### 3.1 替换密码

| 密码 | 原理 | 弱点 |
|------|------|------|
| 凯撒密码 | 字母平移 k 位 | 仅 25 种可能，秒破 |
| 单表替换 | 任意字母置换表 | 频率分析（英文 e 最多） |
| 维吉尼亚密码 | 多表替换（密钥重复） | 卡西斯基测试找密钥周期 |

```text
频率分析的力量：
  英文中 e 约 12.7%、t 9.1%、a 8.2%
  单表替换后，密文中最高频字母 ≈ e
  → 只要密文够长（几百字符），替换表必然暴露

教训：语言的结构性冗余（信息论的熵！）让简单替换必死
```

### 3.2 换位密码

```text
栅栏密码：按行写入、按列读出（打乱顺序，不改变字母）
  缺点：频率分布原样保留 → 频率分析直接定位字母
  → 单独使用同样不堪一击

工程结论：古典密码（替换+换位）全部可被频率/结构分析攻破
  现代密码必须"混淆+扩散"（见 02 模块的 SPN 结构）
```

## 4. Enigma 的教训

### 4.1 Enigma 与图灵

```text
Enigma（二战德国军用）：转子机 + 插线板，密钥空间 10²³ 量级
  当时被认为"不可破解"（暴力搜索不可行）

图灵等人的破解路径（非暴力）：
  ① 已知明文：天气报告、固定开头格式
  ② 转子的数学结构：借位/反馈关系缩小搜索空间
  ③ 图灵炸弹机：利用"明文-密文对"快速排除转子配置

教训 1：大密钥空间 ≠ 安全（结构漏洞比暴力更致命）
教训 2：可预测明文（crib）是攻击者的朋友
教训 3：机器可破解"人为设计"——自动化密码分析诞生
```

### 4.2 历史给现代的三条铁律

| 铁律 | 出处 |
|------|------|
| 算法公开 + 密钥保密 | Kerckhoffs（1883） |
| 结构安全 > 密钥空间 | Enigma（1940s） |
| 可预测输入 = 攻击杠杆 | Enigma crib、现代选择明文模型 |

## 5. 香农的完美保密

### 5.1 完美保密定义

**完美保密**：密文不泄露明文的任何信息——I(明文; 密文) = 0（互信息为零，见 信息论/02）。

```text
含义：攻击者看到密文后的明文概率分布 = 先验分布
  任何攻击（哪怕无限算力）都无法区分哪个明文更可能
```

### 5.2 一次一密（One-Time Pad）

**OTP 方案**：密钥与明文等长、完全随机、只使用一次，密文 = 明文 ⊕ 密钥。

| 性质 | 内容 |
|------|------|
| 完美保密 | 香农证明：OTP 满足 I(P;C) = 0 |
| 密钥要求 | 与明文等长 + 真随机 + 一次性 |
| 致命弱点 | 密钥分发 = 明文分发（鸡生蛋问题） |
| 实际使用 | 极少（外交热线等极端场景） |

```text
工程启示：OTP 证明"完美保密存在但不可用"
  → 现代密码用"计算安全"：密钥 128 位随机 + 算法足够强
  → 攻击者算力有限 → 实际不可破（非理论上不可破）
```

### 5.3 计算安全 vs 信息论安全

| 维度 | 信息论安全 | 计算安全 |
|------|-----------|---------|
| 假设 | 无限算力 | 多项式算力 |
| 例子 | OTP | AES、RSA |
| 密钥长度 | 等于消息 | 128-256 位 |
| 现实性 | 不可用 | 全部现代密码 |

> 🎯 **核心要点**：古典密码死于"结构冗余"，现代密码生于"计算复杂度假设"。三条铁律（算法公开、结构安全、可预测输入警惕）从 19 世纪至今未变；而 2026 年的后量子迁移（08 模块）正在改变"计算安全"的算力假设本身——量子计算让 RSA/ECC 的计算安全失效。

## 6. 现代密码学的分层

### 6.1 分层全景（本目录的导航图）

```text
第 1 层 原语：AES、ChaCha20、SHA-256、RSA、ECC
第 2 层 组合：GCM 模式、HMAC、OAEP、ECDHE 密钥交换
第 3 层 协议：TLS 1.3、SSH、JWT、X.509
第 4 层 体系：PKI 信任链、证书透明度、合规（CNSA 2.0）
第 5 层 迁移：后量子混合、算法敏捷性（2024-2035）
```

### 6.2 原语的安全强度对照

| 算法族 | 推荐参数 | 安全强度（位） |
|--------|---------|:---:|
| 对称加密 | AES-128/256 | 128/256 |
| 哈希 | SHA-256/384 | 128/192 |
| RSA | 2048-3072 位 | 112-128 |
| ECC | P-256/P-384 | 128/192 |
| 后量子 | ML-KEM-768 | ~192（格假设） |

> 🎯 **核心要点**：密码学 = 原语（数学）→ 组合（模式）→ 协议（工程）三层搭建，每层都有自己的失败模式。2026 年的特殊之处：第三层（TLS 混合密钥交换）先行量子化，第一层（证书签名）殿后——理解这个分层，就理解了整个迁移地图。
