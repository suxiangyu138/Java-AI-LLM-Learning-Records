## 1. 知识体系导图

```
密码学（攻防对称的工程科学）
│
├── 01-密码学基础与历史
│     Kerckhoffs 原则 → 安全模型 → 古典密码 → 一次一密
│
├── 02-对称密码：分组密码与AES
│     Feistel/SPN 结构 → AES 内部 → 工作模式 → AEAD
│
├── 03-流密码与随机数
│     ChaCha20 → 随机数三类（TRNG/PRNG/CSPRNG）→ 熵与播种
│
├── 04-哈希函数与消息认证
│     SHA-2/SHA-3 → Merkle-Damgård → 生日攻击 → HMAC → 口令哈希
│
├── 05-公钥密码：RSA与ECC
│     RSA 数学 → OAEP 填充 → 椭圆曲线 → ECDH/ECDSA → 安全强度
│
├── 06-数字签名与公钥基础设施
│     签名方案 → X.509 证书 → PKI 信任链 → 证书透明度 → TLS
│
├── 07-密码协议与工程实践
│     TLS 1.3 → JWT/SSH → 侧信道 → 密钥管理 → 常见错误清单
│
└── 08-后量子密码与2026迁移
      NIST 标准 → 混合 TLS（RFC 9794）→ 迁移阻点 → 时间线
```

模块间依赖：01 为概念基础；02-04 为对称世界；05-06 为非对称世界；07 依赖 02-06（工程集成）；08 依赖全部（时代迁移）。与 `初等数论/`（RSA/ECC 的数学）、`信息论/`（香农安全理论、熵）构成"数学 → 密码 → 协议"三级链路。

## 3. 学习路线推荐

**路线 A：安全工程师入门（2-3 天，推荐）**
01 → 02 → 04 → 07。掌握对称加密、哈希与工程实践（TLS/JWT/口令哈希），足以处理 90% 后端安全需求。

**路线 B：密码学完整体系（1 周）**
路线 A + 03 + 05 + 06。补齐非对称世界（RSA/ECC/PKI）——理解 HTTPS 与证书体系的全貌，能读懂 TLS 握手日志。

**路线 C：后量子前沿（面向架构师/安全负责人）**
路线 B + 08。理解 2026 年正在发生的密码迁移：混合 TLS、NIST 标准、CNSA 2.0 合规时间线——这是未来 5 年最重要的安全工程任务。

> 💡 与知识库关系：数学基础在 `初等数论/`（欧拉定理、有限域、DLP——RSA/ECC 的引擎）与 `信息论/`（熵、香农安全）；工程落地在 03-AI 层（JWT 认证、TLS 配置、密码安全编码）与 `计算机安全理论/` 目录。

## 4. 核心概念速查

| 概念 | 一句话定义 | 关键事实（2026） |
|------|-----------|-----------------|
| Kerckhoffs 原则 | 安全性只依赖密钥，不依赖算法保密 | 现代密码的基石 |
| 对称密码 | 加解密同密钥（AES-256） | 快，用于数据加密 |
| 非对称密码 | 公钥加密/私钥解密（RSA/ECC） | 慢，用于密钥交换/签名 |
| AEAD | 加密+认证一体（AES-GCM/ChaCha20-Poly1305） | 现代 TLS 默认 |
| 哈希 | 单向不可逆（SHA-256） | 完整性、口令存储 |
| HMAC | 密钥化哈希（消息认证） | JWT 签名的传统方案 |
| RSA/ECC | 两大公钥体系 | RSA-2048 与 P-256 同级 |
| 数字签名 | 私钥签名、公钥验证 | 证书、代码签名 |
| PKI | 证书签发与信任链体系 | X.509、CA、CT |
| TLS 1.3 | 传输层安全协议 | 现代 Web 安全默认 |
| 侧信道 | 从时序/功耗等旁路窃密 | Spectre 家族（2025 仍活跃） |
| 后量子密码 | 抗量子攻击的密码（ML-KEM 等） | 2024-08 NIST 定稿，2026 迁移中 |
| 混合 TLS | 经典+量子双轨密钥交换（X25519MLKEM768） | RFC 9794，Chrome 默认 |

> 🎯 **核心要点**：密码学是"对抗性工程"——每个设计决策都要回答"攻击者会怎么攻"。2026 年的主线是**后量子迁移**：会话密钥已经量子安全（混合 TLS 铺开），但证书签名仍是经典算法（RSA/ECDSA）——"密钥先行、签名殿后"是当下迁移的真实节奏。理解这条不对称，就抓住了 2026 密码学的脉搏。
