## 1. 欧几里得算法

### 1.1 辗转相除法

**定理**：gcd(a, b) = gcd(b, a mod b)，且 gcd(a, 0) = a。

```text
算法核心：反复用余数替换较大的数，直到余数为 0

示例：gcd(252, 105)
  252 = 2×105 + 42
  105 = 2×42 + 21
  42  = 2×21 + 0
  → gcd = 21
```

```java
// 迭代实现（工程标准，避免递归深度）
int gcd(int a, int b) {
    while (b != 0) {
        int t = a % b;
        a = b;
        b = t;
    }
    return Math.abs(a);
}
```

### 1.2 为什么正确

```
若 d | a 且 d | b，则 d | (a − bq) = r（余数）
若 d | b 且 d | r，则 d | (bq + r) = a
→ a、b 的公因数集合与 b、r 的公因数集合完全相同
→ gcd 不变
```

> 💡 工程直觉：gcd 是"约分、坐标约化、分数简化"的通用工具——任何需要"最简形式"的地方都需要它。

## 2. 复杂度分析

### 2.1 O(log min(a,b)) 的证明

**引理（拉梅定理）**：每两次除法迭代，数至少减半。

```text
斐波那契数是"最坏情况"：
  gcd(Fₙ₊₁, Fₙ) 需要 n 次除法（F：斐波那契数列）
  → 迭代次数 ≈ log_φ(min(a,b))（φ ≈ 1.618）
  → 1024 位整数只需约 1500 次除法，毫秒级
```

| 实现 | 复杂度 | 说明 |
|------|:---:|------|
| 朴素循环 | O(log min(a,b)) | 标准 |
| 位运算版（Stein） | O(log n) | 只做移位与减法，适合大数 |
| BigInteger.gcd | O(n²) 级别 | Java 内置（Knuth 算法） |

## 3. 扩展欧几里得算法

### 3.1 目标

在求 gcd(a, b) 的同时，找出整数 x、y 使得：

ax + by = gcd(a, b)

**贝祖定理**：上述方程恒有解（x、y 存在），这是整个不定方程理论的基石。

### 3.2 手工推演

```text
求 252 与 105 的贝祖系数：
  252 = 2×105 + 42   → 42 = 252 − 2×105
  105 = 2×42 + 21    → 21 = 105 − 2×42
  42  = 2×21 + 0

  回代：21 = 105 − 2×(252 − 2×105)
       = 105 − 2×252 + 4×105
       = (−2)×252 + 5×105
  → x = −2, y = 5，验证：−2×252 + 5×105 = −504 + 525 = 21 ✓
```

### 3.3 迭代实现

```java
// 扩展欧几里得：返回 {gcd, x, y}，满足 ax + by = gcd
long[] exgcd(long a, long b) {
    long x0 = 1, y0 = 0, x1 = 0, y1 = 1;
    while (b != 0) {
        long q = a / b;
        long t = a % b;
        a = b; b = t;
        long tx = x0 - q * x1; x0 = x1; x1 = tx;
        long ty = y0 - q * y1; y0 = y1; y1 = ty;
    }
    return new long[]{a, x0, y0};   // a = gcd，x0、y0 为贝祖系数
}
```

### 3.4 求模逆元的直接应用

```text
求 47 模 120 的逆元（即解 47x ≡ 1 (mod 120)）：
  展开：47x + 120y = 1 的贝祖系数
  120 = 2×47 + 26
  47  = 1×26 + 21
  26  = 1×21 + 5
  21  = 4×5  + 1
  5   = 5×1  + 0
  回代：1 = 21 − 4×5 = 21 − 4×(26−21) = 5×21 − 4×26
       = 5×(47−26) − 4×26 = 5×47 − 9×26
       = 5×47 − 9×(120−2×47) = 23×47 − 9×120
  → x = 23（47⁻¹ ≡ 23 (mod 120)，验证 47×23 = 1081 ≡ 1 mod 120 ✓）
```

## 4. 线性丢番图方程

### 4.1 可解性判定

方程 ax + by = c 有整数解 ⟺ gcd(a, b) | c。

```text
证明方向（必背）：
  必要性：gcd(a,b) 整除左边每一项 ⟹ 整除 c
  充分性：贝祖定理给出 ax₀ + by₀ = gcd(a,b)，
         乘以 c/gcd(a,b) 即得一组特解
```

### 4.2 通解结构

设 (x₀, y₀) 为一组特解，g = gcd(a, b)，则全部解为：

x = x₀ + (b/g)·t，y = y₀ − (a/g)·t（t 为任意整数）

```text
示例：6x + 9y = 15（gcd = 3 | 15，可解）
  特解：x₀ = −1, y₀ = 7/3？不对——先除以 g：2x + 3y = 5
  特解 x₀ = 1, y₀ = 1：2×1 + 3×1 = 5 ✓
  通解：x = 1 + 3t，y = 1 − 2t
  验证 t=1：x=4, y=−1：8 − 9 = −1？→ 2×4 + 3×(−1) = 5 ✓（注意除以 g 后系数）
```

### 4.3 正整数解问题（竞赛高频）

```text
求 ax + by = c 的正整数解个数：
  先求特解 → 用通解参数 t 的范围限制：
  x₀ + (b/g)t > 0 且 y₀ − (a/g)t > 0 → 解出 t 的整数区间长度
  例：求 3x + 5y = 100 的正整数解个数
  （通解后 t 的可行区间 → 计数，详见练习）
```

## 5. 模逆元的求法对比

| 方法 | 条件 | 复杂度 | 适用 |
|------|------|:---:|------|
| 扩展欧几里得 | gcd(a,m)=1 即可 | O(log m) | 通用首选 |
| 费马小定理 | m 为素数 | O(log m) | 素数模（组合数取模） |
| 打表（线性求逆） | m 为素数 | O(m) 预处理、O(1) 查询 | 批量逆元（1..n） |

```java
// 批量求 1..n 的模 p 逆元（p 素数，O(n) 递推）
long[] inv = new long[n + 1];
inv[1] = 1;
for (int i = 2; i <= n; i++)
    inv[i] = (p - p / i) * inv[(int) (p % i)] % p;
// 递推来源：p = ⌊p/i⌋·i + (p mod i) → 两边取模移项
```

> 🎯 工程结论：求单个逆元用扩展欧几里得（不要求素数）；组合数取模的预处理用费马+批量递推——两种场景两套方案。

## 6. 连分数入门

### 6.1 连分数与欧几里得算法的关系

辗转相除法的商序列 (q₁, q₂, …, qₖ) 恰好构成有理数 a/b 的**连分数展开**：

```text
252/105 = [2; 2, 2]（商序列 2, 2, 2）
展开式：252/105 = 2 + 1/(2 + 1/2)

性质：连分数是"最优有理逼近"工具
  √2 = [1; 2, 2, 2, …]（无限循环连分数）
```

### 6.2 工程应用

| 场景 | 连分数角色 |
|------|-----------|
| 最优逼近 | 用分母小的分数近似无理数（音律、天文历法） |
| 丢番图逼近 | 连分数收敛子给出最优解 |
| RSA 攻击 | Wiener 攻击：d 过小时用连分数逼近 e/n 破解（08 模块） |

## 7. 工程应用

| 场景 | 欧几里得/不定方程角色 |
|------|---------------------|
| 模逆元 | RSA 密钥计算、组合数取模、有限域除法 |
| 分数约分 | gcd 化简 |
| 坐标约化 | 方向向量最简形式（整数共线判断） |
| 线性同余求解 | 解 ax ≡ c (mod m)（见 04 模块） |
| 轮询调度 | 步长与容量的 gcd 决定遍历路径 |
| 加密密钥 | RSA 求 e 的逆元 d（扩展欧几里得） |

> 🎯 **核心要点**：扩展欧几里得是"一个算法三用"的典范——求 gcd、求贝祖系数、求模逆元。RSA 密钥生成中"选 e 后求 d ≡ e⁻¹ (mod φ(n))"正是它的直接应用；理解它的回代过程，就理解了逆元"为什么存在且可算"。
