## 1. 核心数论函数

| 函数 | 定义 | 含义 |
|------|------|------|
| 欧拉函数 φ(n) | 1..n 中与 n 互素的个数 | 简化剩余系大小 |
| 除数函数 τ(n)（d(n)） | n 的正因数个数 | 因数计数 |
| 除数和 σ(n) | n 的全部正因数和 | 因数求和 |
| 莫比乌斯函数 μ(n) | 见第 4 节 | 容斥系数 |
| 完全数函数 σ(n)=2n | σ(n) = 2n 的 n | 完全数 |
| 常数函数 1(n) | 恒等于 1 | 卷积单位元之一 |
| 单位函数 ε(n) | n=1 时 1，否则 0 | **卷积的单位元** |
| 恒等函数 id(n) | 等于 n | 幂和公式的基础 |

```text
示例：n = 12 = 2²·3
  φ(12) = 12·(1/2)·(2/3) = 4
  τ(12) = 3·2 = 6（因数 1,2,3,4,6,12）
  σ(12) = 1+2+3+4+6+12 = 28
  μ(12) = 0（含平方因子 2²）
```

## 2. 积性函数

### 2.1 定义

f 是**积性函数** ⟺ gcd(m, n) = 1 时 f(mn) = f(m)·f(n)。

**完全积性**：任意 m、n 都成立（不要求互素），如 id(n) = n。

### 2.2 重要积性函数

| 函数 | 积性 | 线性筛可求 |
|------|:---:|:---:|
| φ(n) | ✅ | ✅ |
| τ(n)、σ(n) | ✅ | ✅ |
| μ(n) | ✅ | ✅ |
| id(n)、1(n) | ✅（完全） | — |
| 欧拉判别相关 (a/n) | ✅ | — |

> 💡 积性函数的工程价值：**只需在素数幂上定义，全体值由唯一分解展开**——线性筛一边筛一边算 φ/μ/τ/σ 正是利用这点。

## 3. 狄利克雷卷积

### 3.1 定义

(f * g)(n) = Σ_{d|n} f(d)·g(n/d)

即对 n 的所有因数求和配对。

### 3.2 代数结构

卷积构成**交换幺半群**（单位元为 ε(n)）：结合律、交换律、分配律均成立。

**关键恒等式**（必背）：

- 1 * μ = ε（1 与 μ 互逆——莫比乌斯反演的卷积形态）
- φ = μ * id（φ(n) = Σ_{d|n} μ(d)·(n/d)）
- τ = 1 * 1；σ = 1 * id

```text
验证 φ = μ * id：n = 6
  Σ_{d|6} μ(d)·(6/d) = μ(1)·6 + μ(2)·3 + μ(3)·2 + μ(6)·1
  = 6 − 3 − 2 + 1 = 2 = φ(6) ✓
```

## 4. 莫比乌斯函数

### 4.1 定义

μ(n) = 1（n = 1）；0（n 含平方因子）；(−1)^k（n 为 k 个不同素因子之积）。

```text
示例：μ(1)=1, μ(2)=−1, μ(3)=−1, μ(6)=+1, μ(4)=0, μ(12)=0
```

### 4.2 核心性质

**基本和式**：Σ_{d|n} μ(d) = 1（n=1 时）；0（n>1 时）。

```text
验证 n = 6：μ(1)+μ(2)+μ(3)+μ(6) = 1 − 1 − 1 + 1 = 0 ✓
含义：μ 是"因数上的容斥系数"——和为 1 只在 n=1 成立
```

### 4.3 与其他函数的联系

- φ(n) = Σ_{d|n} μ(d)·(n/d)（上面验证过）
- μ 是 1 的卷积逆元：1 * μ = ε

## 5. 莫比乌斯反演

### 5.1 定理

若 g(n) = Σ_{d|n} f(d)，则 f(n) = Σ_{d|n} μ(d)·g(n/d)。

**卷积形式**：g = f * 1 ⟹ f = g * μ（两边同卷 μ）。

```text
示例：g(n) = n（因数和恒等式：n = Σ_{d|n} φ(d)）
  反演得：φ(n) = Σ_{d|n} μ(d)·(n/d) ✓ 与 4.2 一致

反向方向（d 的倍数版本）：
  若 G(n) = Σ_{n|d} F(d)（n 的倍数求和）
  则 F(n) = Σ_{n|d} μ(d/n)·G(d)
```

### 5.2 反演的等价形式（工程最常用）

若 g(n) = Σ_{d|n} f(d)（因数和式），f 可通过枚举倍数反演：

```text
f(n) = Σ_{d|n} μ(d) · g(n/d)
实现：先求 g（通常好求），再枚举因子组合 μ 系数
```

## 6. 反演的应用技巧

### 6.1 经典求和：互素对计数

```text
问题：1 ≤ i ≤ n，1 ≤ j ≤ m 中 gcd(i,j) = 1 的对数
直接计数：O(nm) 不可行

反演解法（三步）：
  Step 1  设 F(k) = gcd(i,j) 是 k 的倍数的对数 = ⌊n/k⌋·⌊m/k⌋
  Step 2  设 f(k) = gcd(i,j) 恰好等于 k 的对数
          F(k) = Σ_{k|d} f(d)（倍数方向的和式）
  Step 3  反演：f(1) = Σ_{d≥1} μ(d)·F(d)
          = Σ μ(d)·⌊n/d⌋·⌊m/d⌋
  复杂度：O(min(n,m))（预处理 μ 的前缀和可加速）

示例：n = m = 6
  f(1) = Σ μ(d)·⌊6/d⌋²
  = 36 − 9 − 4 + 1 = 24
  验证：互素对 (1..6, 1..6) 共 24 对 ✓
```

### 6.2 数值分块加速

```text
⌊n/d⌋ 在 d 的区间上取相同值（整除分块）：
  例：n = 10：⌊10/d⌋ = 10,5,3,2,2,1,1,1,1,1
  只有 O(√n) 个不同取值 → 求和复杂度 O(√n)
  配合 μ 前缀和 → 大规模 gcd 计数问题秒解
```

### 6.3 应用总表

| 场景 | 反演角色 |
|------|---------|
| gcd 计数 | 互素对、gcd=k 对（莫比乌斯反演经典） |
| 因子和求值 | Σ_{d|n} f(d) 与 f 的互转 |
| LCM 计数 | 转化到 gcd 后反演 |
| 容斥统一 | μ 是"因子容斥"的通用系数 |
| 数论筛 | μ/φ 的线性筛（莫比乌斯反演的前置） |

## 7. 工程实现

### 7.1 线性筛求 μ 与 φ

```java
// 线性筛同时求 μ 与 φ（O(n)）
long[] mu = new long[n + 1], phi = new long[n + 1];
boolean[] comp = new boolean[n + 1];
int[] primes = new int[n];
int cnt = 0;
mu[1] = 1; phi[1] = 1;
for (int i = 2; i <= n; i++) {
    if (!comp[i]) {
        primes[cnt++] = i;
        mu[i] = -1;          // 素数：一个素因子 → μ = −1
        phi[i] = i - 1;      // 素数：φ = p−1
    }
    for (int j = 0; j < cnt && (long) i * primes[j] <= n; j++) {
        int p = primes[j];
        comp[i * p] = true;
        if (i % p == 0) {    // p 已整除 i：出现平方因子
            mu[i * p] = 0;
            phi[i * p] = phi[i] * p;   // φ(p·i) = φ(i)·p
            break;
        } else {
            mu[i * p] = -mu[i];        // 新素因子：μ 取反
            phi[i * p] = phi[i] * (p - 1);
        }
    }
}
```

### 7.2 反演求和模板

```java
// 计算 f(1) = Σ μ(d)·⌊n/d⌋·⌊m/d⌋，整除分块 O(√n)
long coprimePairs(long n, long m) {
    long ans = 0;
    for (long l = 1, r; l <= Math.min(n, m); l = r + 1) {
        r = Math.min(n / (n / l), m / (m / l));   // 分块右端点
        long sumMu = prefixMu[(int) r] - prefixMu[(int) l - 1];
        ans += sumMu * (n / l) * (m / l);
    }
    return ans;
}
```

> 🎯 **核心要点**：莫比乌斯反演是"因数世界的傅里叶变换"——把难算的因数和式与易算的倍数和式互转。μ 函数就是这套变换的"频率基"：配上限性筛与整除分块，O(nm) 的暴力问题变成 O(√n)。这是竞赛数论与应用统计（如容斥类问题）的通用武器。

## 8. 小结

| 问题 | 答案 |
|------|------|
| 四大数论函数？ | φ（互素计数）、τ（因数个数）、σ（因数和）、μ（容斥系数） |

| 复杂度？ | 线性筛 O(n) + 整除分块 O(√n) |
