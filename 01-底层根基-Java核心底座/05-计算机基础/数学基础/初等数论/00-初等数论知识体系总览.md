## 3. 学习路线推荐

**路线 A：算法与工程基础（3-4 天，推荐）**
01 → 02 → 03 → 04。覆盖面试与工程最高频数论：gcd、模运算、快速幂、逆元、CRT、组合数取模。每个模块配手算练习（如 gcd 手推、逆元手算）。

**路线 B：密码学深潜（1 周）**
路线 A + 05 + 08。补上离散对数与素性测试后，可完整读懂 RSA/DH/ElGamal 的数学证明，再衔接 `密码学/` 目录的工程实现。

**路线 C：数论理论进阶（面向研究者）**
路线 A + 06 + 07。二次互反律与莫比乌斯反演是数论两大"经典武器"，也是进入解析数论与代数数论的入口。

> 💡 与知识库关系：`离散数学/06` 是本目录的"30 分钟速览版"；`密码学/` 是应用落地（RSA 工程实现、侧信道防御）；08 模块的格密码部分与 2025 年 NIST 后量子标准（ML-KEM/ML-DSA）直接衔接，是 AI/云安全方向的重要储备。

## 4. 核心概念速查

| 概念 | 一句话定义 | 工程对应 |
|------|-----------|---------|
| 整除 a\|b | 存在 k 使 b=ka | 模校验、整除判断 |
| 素数 | 只有 1 和自身的正因数 | RSA 的 p、q、哈希容量 |
| 唯一分解 | 整数唯一分解为素数幂 | 因数分解、LCM/gcd |
| 同余 a≡b (mod m) | m 整除 a−b | 哈希取模、循环结构 |
| 剩余系 | 模 m 的代表元集合 | 哈希桶、环形队列 |
| gcd | 最大公因数 | 分数约分、坐标约化 |
| 扩展欧几里得 | 求 ax+by=gcd(a,b) | 模逆元、RSA 密钥计算 |
| 模逆元 | ax≡1 (mod m) 的解 | 有限域除法、组合数取模 |
| 费马小定理 | p 素数时 a^(p−1)≡1 | 快速逆元、素性测试 |
| 欧拉定理 | a^φ(m)≡1（互素） | RSA 解密正确性证明 |
| CRT | 同余方程组唯一解 | RSA-CRT 加速 4×、秘密共享 |
| 原根 | 生成整个循环群的元素 | Diffie-Hellman 密钥交换 |
| 离散对数 | 求 a^x≡b 的解 x | ElGamal 签名、ECC 类比 |
| 二次互反律 | 两素数互反符号乘积公式 | 平方剩余快速判定 |
| 莫比乌斯反演 | 和式的因式反转工具 | 容斥计数、筛法加速 |

> 🎯 **核心要点**：初等数论是"整数的代数"——一切从整除与同余两条主线展开：整除线（因子、素数、gcd）回答"数怎么拆"，同余线（剩余系、幂、方程）回答"循环世界里怎么算"。现代密码学的每一行代码，都是这两条线的直接产物。
