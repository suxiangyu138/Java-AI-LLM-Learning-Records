## 1. 平方剩余的定义

### 1.1 定义

设 p 为奇素数，若同余方程 x² ≡ a (mod p) 有解，则 a 称为模 p 的**平方剩余**；否则为**平方非剩余**。

```text
示例：模 7 的平方
  1²=1, 2²=4, 3²=2, 4²=2, 5²=4, 6²=1 (mod 7)
  平方剩余集：{1, 2, 4}；平方非剩余：{3, 5, 6}
```

### 1.2 基本事实

| 事实 | 内容 |
|------|------|
| 数量 | 恰好 (p−1)/2 个平方剩余、(p−1)/2 个非剩余 |
| 对称性 | 若 a 是平方剩余，则 −a 的平方根为 x 与 p−x |
| 判别记号 | a ≡ 0 (mod p) 单独处理（平方剩余但不是非零元） |

> 🎯 直觉：模 p 下"开平方"只在半数的数上可行——平方剩余就是"可开方"的数。这是"哪些整数是真平方数"在循环世界的版本。

## 2. 欧拉判别准则

### 2.1 定理

设 p 为奇素数，gcd(a, p) = 1，则：

- a 是平方剩余 ⟺ a^((p−1)/2) ≡ 1 (mod p)
- a 是平方非剩余 ⟺ a^((p−1)/2) ≡ −1 (mod p)

```text
验证：p = 7，a = 2（平方剩余）
  2³ = 8 ≡ 1 (mod 7) ✓
  a = 3（非剩余）：3³ = 27 ≡ −1 (mod 7) ✓
```

### 2.2 证明要点

```text
① a^(p−1) ≡ 1（费马），故 a^((p−1)/2) 的平方为 1
   → 其值只能是 ±1
② 若 a = b²，则 a^((p−1)/2) = b^(p−1) ≡ 1 ✓
③ 方程 x^((p−1)/2) = 1 至多有 (p−1)/2 个根（拉格朗日），
   平方剩余恰好 (p−1)/2 个 → 一一对应 ∎
```

### 2.3 工程应用

欧拉判别 = 平方剩余的"暴力判定"（快速幂实现，O(log p)）——小模数首选。

## 3. 勒让德符号

### 3.1 定义

勒让德符号 (a/p)（p 为奇素数）定义为：

- (a/p) = 1，a 是平方剩余
- (a/p) = −1，a 是平方非剩余
- (a/p) = 0，p | a

### 3.2 性质

| 性质 | 公式 |
|------|------|
| 欧拉准则 | (a/p) ≡ a^((p−1)/2) (mod p) |
| 完全积性 | (ab/p) = (a/p)·(b/p) |
| 分母不变 | (a/p) 只依赖 a mod p |
| 特殊值 | (1/p) = 1；(−1/p) = (−1)^((p−1)/2) |

```text
(−1/p) 的展开（必背）：
  p ≡ 1 (mod 4) → (−1/p) = 1（−1 可开平方）
  p ≡ 3 (mod 4) → (−1/p) = −1（−1 不可开平方）

验证：p=5：4² ≡ 1 (mod 5)？(−1/p) = 1 且 2² = 4 = −1 ✓
```

## 4. 二次互反律

### 4.1 定理（"黄金定理"）

设 p、q 为不同的奇素数，则：

(p/q)·(q/p) = (−1)^(((p−1)/2)·((q−1)/2))

等价表述：p、q 中至少一个 ≡ 1 (mod 4) 时 (p/q) = (q/p)；两数都 ≡ 3 (mod 4) 时 (p/q) = −(q/p)。

```text
验证：p = 7, q = 11（都 ≡ 3 mod 4）
  (7/11)：(7/11) ？先算直接值：x² ≡ 7 (mod 11)
  5² = 25 ≡ 3，8² = 64 ≡ 9，… 手算发现无解 → (7/11) = −1
  (11/7)：(11/7) = (4/7) = 1（4 是平方）
  互反律：(−1)^(3×5) = −1 → 验证 −1·1 = −1 ✓
```

### 4.2 为什么重要

| 意义 | 说明 |
|------|------|
| 计算革命 | 判定 (a/p) 无需枚举平方——只需分解 a + 欧拉判别的组合 |
| 例：判定 (123/997) | 展开 (3/997)(41/997)，用互反律翻转分母，只需算小素数的符号 |
| 理论地位 | 高斯称其为"黄金定理"；是进入代数数论（二次域）的入口 |
| 算法价值 | 与大数分解一样，是"看似困难实则优雅"的典范 |

### 4.3 组合判定流程（计算 (a/p) 的完整算法）

```text
计算 (a/p)（p 奇素数）：
  Step 1  a mod p → 若为 0 返回 0
  Step 2  从 a 中提取因子 2：(2/p) = (−1)^((p²−1)/8)
           p ≡ ±1 (mod 8) → 1；p ≡ ±3 (mod 8) → −1
  Step 3  剩余奇数因子用互反律翻转（p、q 都 ≡3 mod 4 时取负）
  Step 4  分母取模继续，直到分母为 1 或分子为小素数
  —— 类似"辗转相除"的符号版本！

(2/p) 速记：p ≡ ±1 (mod 8) 时 2 是平方剩余（如 p=7：3²=9≡2 ✓）
```

## 5. 雅可比符号

### 5.1 定义（勒让德符号的推广）

对奇合数 n = p₁^e₁…pₖ^eₖ，定义雅可比符号 (a/n) = Π (a/pᵢ)^eᵢ。

```text
注意：雅可比符号 = 1 不代表 a 是平方剩余！
  （每个素因子都是剩余才真正可开方，符号 1 只是"偶数个 −1"）

示例：(2/15) = (2/3)·(2/5) = (−1)·(−1) = 1
  但 x² ≡ 2 (mod 15) 无解（模 3 无解）—— 符号 1 是假阳性
```

### 5.2 性质与价值

| 性质 | 说明 |
|------|------|
| 仍可计算 | 分子分母约化 + 互反律的扩展（对合数分母同样适用） |
| 复杂度 | O(log² n)，无需分解分母！ |
| 判定用途 | 符号 = −1 可**确定**非剩余；= 1 需进一步验证 |
| 素数判定 | Solovay-Strassen 素性测试 = 雅可比符号与欧拉准则比对 |

## 6. 模素数的平方根

### 6.1 两类情形

| 情形 | 解法 |
|------|------|
| p ≡ 3 (mod 4) | x ≡ ±a^((p+1)/4)（快速幂直接求！） |
| p ≡ 1 (mod 4) | Tonelli-Shanks 算法（通用，竞赛标准） |

```text
p ≡ 3 (mod 4) 时的推导：
  (a^((p+1)/4))² = a^((p+1)/2) = a·a^((p−1)/2) ≡ a·1 = a ✓
  （利用 a 是平方剩余 → a^((p−1)/2) ≡ 1）

验证：解 x² ≡ 5 (mod 7)（7 ≡ 3 mod 4）
  x ≡ ±5^((7+1)/4) = ±5² = ±25 ≡ ±4 (mod 7)
  4² = 16 ≡ 2？不对——5 不是模 7 的平方剩余！先判再解
```

### 6.2 求解流程（完整）

```text
解 x² ≡ a (mod p)：
  Step 1  欧拉判别：a^((p−1)/2) ≡ 1？否 → 无解
  Step 2  p ≡ 3 (mod 4) → x = ±a^((p+1)/4)
  Step 3  否则 Tonelli-Shanks（找非剩余构造辅助元）
```

## 7. 应用

| 场景 | 平方剩余/互反律角色 |
|------|-------------------|
| 密码学 | 二次剩余假设（QRP）：判定 a 是否为平方剩余本身可做困难问题（Goldwasser-Micali 加密） |
| Rabin 加密 | 基于"模合数开平方困难"（等价于分解 n） |
| Cipolla/Tonelli | 椭圆曲线密码中点运算的平方根需求 |
| 素性测试 | Solovay-Strassen 与 Miller-Rabin 的互证 |
| 竞赛题 | "判定 x²≡a 是否有解"类题的标准工具 |

> 🎯 **核心要点**：二次互反律是"符号计算"的皇冠——它把"枚举开方"变成"欧几里得式的翻转算法"，复杂度从 O(p) 降到 O(log² p)。它的两个工程孪生兄弟（Rabin 加密、Goldwasser-Micali）则把"平方剩余的困难性"直接变成加密强度——又一次"定理→安全"的转化。

## 8. 小结

| 问题 | 答案 |
|------|------|
| 平方剩余是什么？ | x² ≡ a (mod p) 有解的 a，恰好 (p−1)/2 个 |
| 怎么快速判定？ | 欧拉判别 a^((p−1)/2) ≡ ±1 |
| 勒让德符号？ | 三值函数（1/−1/0），完全积性 |
| 二次互反律？ | (p/q)(q/p) = (−1)^((p−1)(q−1)/4)，翻转分母 |
| 雅可比符号？ | 合数分母版；=1 是必要非充分 |
| 怎么开平方？ | p≡3 mod 4 直接公式；否则 Tonelli-Shanks |
