## 1. 经典公钥密码的数论内核

### 1.1 三大体系一览

| 体系 | 数学难题 | 数论工具 | 密钥长度 |
|------|---------|---------|:---:|
| RSA | 大整数分解 | 欧拉定理、逆元、CRT、快速幂 | 2048-4096 位 |
| Diffie-Hellman/ElGamal/DSA | 离散对数（DLP） | 原根、费马、safe prime | 2048 位 |
| ECC | 椭圆曲线离散对数 | 有限域、阶、群论 | 256 位 |

### 1.2 RSA 全链路（数论工具盘点）

| 步骤 | 数论工具 |
|------|---------|
| 选 p、q | Miller-Rabin 素性测试 + 素数定理 |
| n = pq，φ(n) = (p−1)(q−1) | 欧拉函数 |
| 选 e，求 d ≡ e⁻¹ (mod φ(n)) | 扩展欧几里得（模逆元） |
| 加密 c = m^e mod n | 快速幂 |
| 解密 m = c^d mod n | 欧拉定理（正确性）+ 快速幂 |
| 加速 | CRT（拆 p、q 两路，4×） |

> 🎯 一份 RSA 实现 = 本目录 01-06 模块的"期末综合应用"——每一个工具都在这张表里出现。

### 1.3 安全参数选择的数论规则

```text
① p、q 相差不能太小（费马分解攻击）
② p−1、q−1 需含大素因子（Pollard p−1 攻击的防御）
③ e 通常取 65537（费马数，快速幂友好且抗低指数攻击）
④ 随机数必须真随机（弱随机 = 可预测私钥）
⑤ 参数校验：接收方验证 g 的阶（防小子群攻击）
```

## 2. 素性测试与安全素数

### 2.1 测试方法分层

| 方法 | 类型 | 复杂度 | 用途 |
|------|------|--------|------|
| 试除法 | 确定性 | O(√n) | 小整数 |
| Miller-Rabin | 概率/确定性基 | O(k log³n) | 工程标准（64 位内确定性） |
| Baillie-PSW | 概率 | O(log³n) | 无已知反例 |
| AKS | 确定性 | O(log⁶n) | 理论（多项式但常数巨大） |
| ECPP | 确定性 | 亚指数 | 密码级证书（大素数证明） |

### 2.2 Safe Prime（安全素数）

**定义**：p = 2q + 1 且 p、q 都是素数。

```text
为什么需要：Pohlig-Hellman 攻击的防御
  若 p−1 只含小素因子，离散对数可快速求解
  → DH/ElGamal 要求 p−1 = 2q（q 为大素数）→ 唯一大素因子
  2048 位 safe prime 的 q 也有 2047 位 → DLP 安全

工程：OpenSSL 的 dhparam 默认生成 safe prime 参数
```

## 3. 大整数分解的现状

### 3.1 分解算法族

| 算法 | 复杂度 | 目标 |
|------|--------|------|
| 试除法 | O(√n) | ≤ 10¹² |
| Pollard-Rho | O(n^¼) | ≤ 10¹⁸ |
| 二次筛（QS） | 亚指数 | ≤ 100 位 |
| 数域筛（NFS） | 亚指数（最优） | RSA-1024 级 |

### 3.2 RSA 分解记录（2025 现状）

```text
RSA-250（829 位，2020 年分解）→ 安全性按位估
RSA-2048 分解所需：约 10²³ 量级操作（NFS 理论估计）
  现有算力（含 GPU 集群）远不可行 → 2048 位仍安全

教训：量子威胁之外，经典分解算法持续改进
  → 密钥长度每十年上调（1024→2048→3072 位建议）
```

## 4. 量子威胁：Shor 算法

### 4.1 Shor 算法原理（数论视角）

```text
Shor 算法把整数分解转化为"找阶"问题（量子傅里叶变换找周期）：
  Step 1  随机选 a，求 ord_n(a)（量子相位估计）
  Step 2  若 ord 为偶数：a^(ord/2) ± 1 可能给出非平凡因子
  Step 3  gcd(a^(ord/2)−1, n) 与 gcd(a^(ord/2)+1, n) 检验

关键：RSA/DH/ECC 依赖的难题（分解、DLP、ECDLP）
  在量子计算机上都可多项式时间求解 → 全线失效
```

### 4.2 威胁时间线（2025 共识）

| 阶段 | 状态 |
|------|------|
| 当前 | 逻辑量子比特 ~10³ 级，Shor 需 ~10⁶-10⁷ 级（未实现） |
| 中期（2025-2035） | "Harvest now, decrypt later"——现在窃取加密流量，未来解密 |
| 行动 | NIST 已发布后量子标准（2024-08 正式化） |

> ⚠️ 对开发者的现实影响：**即便量子计算机还需 10 年，今天传输的数据（TLS 会话）可能被记录并在未来解密**——这就是 2025 年起密码迁移紧迫性的来源。

## 5. 后量子密码：格基路线

### 5.1 为什么是格（Lattice）

```text
格 = 高维空间中的离散点集（类似"晶体结构"）
难题假设（LWE/SIS）：
  找"最近的格点"（CVP）或"最短向量"（SVP）极其困难
  量子加速对这些问题的改进有限 → 抗量子

优势：安全证明更扎实（最坏情形归约）、运算并行友好
```

### 5.2 NIST 后量子标准（2024-08 定稿）

| 标准 | 用途 | 基础 | 对应 |
|------|------|------|------|
| ML-KEM（FIPS 203） | 密钥封装（替代 RSA 密钥交换） | 格（Module-LWE） | CRYSTALS-Kyber |
| ML-DSA（FIPS 204） | 数字签名 | 格（Module-SIS） | CRYSTALS-Dilithium |
| SLH-DSA（FIPS 205） | 签名（备用） | 哈希 | SPHINCS+ |
| FN-DSA（FIPS 206，2025） | 签名（Falcon 类） | NTRU 格 | Falcon |

### 5.3 格密码的数学部件（与初等数论的衔接）

| 部件 | 说明 |
|------|------|
| 多项式环 Z_q[X]/(Xⁿ+1) | 环结构（05 模块的代数结构） |
| **NTT（数论变换）** | 模素数 q 上的快速多项式乘法（下一节） |
| 模算术 | 所有运算在 Z_q 上（02 模块） |
| 采样与舍入 | 高斯采样、取整（概率论工具） |

## 6. 数论变换（NTT）

### 6.1 什么是 NTT

NTT 是 FFT 的有限域版本：在模素数 q 的剩余系上做离散傅里叶变换。

```text
FFT 用复数单位根 e^(2πi/n)；NTT 用模 q 的原根 ω（05 模块！）
条件：q ≡ 1 (mod 2n)（保证 n 次单位根存在）

用途：多项式乘法的 O(n log n) 加速
  格密码中的核心运算（Kyber/Dilithium/FHE 全用它）
```

### 6.2 工程地位（2025 实证）

```text
ML-KEM 与 ML-DSA 的每次运算都含 NTT
FHE（全同态加密）中 NTT 占运算时间 50%+
2025 研究（IACR ePrint 2025/768）：
  "不完整 NTT" 变体优化多项式乘法
  → ML-KEM 密文更短、FHE 计算提速 6-42%
硬件加速：高基/混合基 NTT 架构（Fermat 模数）
  → DSP 面积-时间积降低 30-85%（IEEE TC 2025）
```

### 6.3 NTT 与数论概念的对应

| NTT 组件 | 数论概念 |
|---------|---------|
| 模素数 q | 有限域 GF(q)（05 模块） |
| 单位根 ω | 原根（05 模块） |
| 变换可逆性 | ω⁻¹ 存在（模逆元，03 模块） |
| 长度约束 2n \| (q−1) | 原根存在定理（05 模块） |

> 🎯 NTT 是"初等数论直接变成芯片"的活例：原根、有限域、模逆元——本科数论第一学期的概念，构成了 2025 年全球后量子密码迁移的算力底座。

## 7. 2025-2026 前沿

### 7.1 数论活跃方向（检索实证）

| 方向 | 2025 进展 | 数论角色 |
|------|----------|---------|
| 全同态加密（FHE） | 隐私保护机器学习的核心；NTT 优化 6-42% | 多项式环、NTT、采样 |
| 零知识证明 | 多项式环上的亚线性证明（ePrint 2025/199） | 环结构、群论 |
| VRF/OPRF | 格假设下的抗量子可验证随机函数 | LWE/SIS、范围证明 |
| 混合迁移 | TLS 混合密钥交换（经典 + ML-KEM 双轨） | 双体系共存 |
| 数论教育 | 2025 课程把数论与 ZK/区块链深度结合 | 生态扩张 |

### 7.2 对开发者的行动清单

```text
① 密码库升级：Java 21+ 的 JCA 已支持 ML-KEM/ML-DSA
   （KeyAgreement "ML-KEM"、Signature "ML-DSA"）
② TLS 配置：启用混合密钥交换（hybrid KEX）档位
③ 数据分级：高敏数据"现在加密，考虑 2030 解密窗口"
④ 继续学数论：格密码与 NTT 是理解新标准的唯一捷径
   —— 没有数论背景看 FIPS 203 规范如读天书
```

### 7.3 数论与 AI 的交汇

```text
① FHE × 机器学习：加密数据上的推理（隐私 AI）
   2025 年 FHE 推理已可跑小型 Transformer
② 格密码的采样与舍入：与向量量化（AI 压缩）共享数学
③ NTT 硬件：AI 加速器与 PQC 加速器可共享 FFT 引擎
—— 数论不再只是"安全部门的知识"，而是 AI 时代基础设施
```

> 🎯 **核心要点**：初等数论的命运曲线——RSA 时代它是一切公钥密码的内核，量子时代它让位于格（但环、域、原根、NTT 依然是新密码的语法）。**数论没有过时，它只是换了战场**：从"分解难题"转向"格难题"与"多项式环"，而工具箱（模算术、原根、逆元、NTT）原样传承。
