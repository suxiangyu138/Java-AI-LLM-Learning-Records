## 1. 元素的阶

### 1.1 定义

设 gcd(a, m) = 1，满足 aᵈ ≡ 1 (mod m) 的最小正整数 d 称为 a 模 m 的**阶**（order），记 ord_m(a)。

```text
示例：模 7 下
  2¹=2, 2²=4, 2³=1 → ord₇(2) = 3
  3¹=3, 3²=2, 3³=6, 3⁴=4, 3⁵=5, 3⁶=1 → ord₇(3) = 6
```

### 1.2 阶的性质

| 性质 | 内容 |
|------|------|
| 整除性 | ord(a) 整除 φ(m)（**拉格朗日定理推论**） |
| 幂的阶 | ord(a^k) = ord(a)/gcd(ord(a), k) |
| 同幂判定 | a^i ≡ a^j ⟺ i ≡ j (mod ord(a)) |
| 周期 | a 的幂序列以 ord(a) 为周期循环 |

> 🎯 关键直觉：阶 = "循环周期"——a 的幂在模 m 下形成一个循环，循环长度就是阶。所有"幂序列何时回到 1"的问题都归约到阶。

## 2. 原根

### 2.1 定义

若 ord_m(g) = φ(m)，则 g 是模 m 的**原根**（primitive root）。

原根的幂序列遍历整个简化剩余系——即模 m 的乘法群是**循环群**，g 是生成元。

```text
示例：模 7 的原根是 3（ord = 6 = φ(7)）
  3 的幂：1, 3, 2, 6, 4, 5 —— 恰好遍历 {1,2,3,4,5,6} 全体
```

### 2.2 原根存在定理

模 m 有原根 ⟺ m ∈ {2, 4, pᵏ, 2pᵏ}（p 为奇素数，k ≥ 1）。

```text
有原根：2, 3, 4, 5, 7, 9, 10, 11, 13, 14, 17, 18, 19, 22, 23…
无原根：8（非 pᵏ 形式）、12、15…

工程注意：Diffie-Hellman 使用的模数必须是有原根的（素数或 2pᵏ）
```

### 2.3 原根的个数

若模 m 有原根，则原根个数 = φ(φ(m))。

```text
示例：模 7 有 φ(6) = 2 个原根：3 和 5
  验证：5¹=5, 5²=4, 5³=6, 5⁴=2, 5⁵=3, 5⁶=1 ✓
```

## 3. 原根的判定与求法

### 3.1 判定条件

g 是模 m（m = p^k 或 2p^k）的原根 ⟺ 对 φ(m) 的每个素因子 qᵢ：

g^(φ(m)/qᵢ) ≢ 1 (mod m)

```text
判定示例：g=2 是否为模 13 的原根？
  φ(13) = 12，素因子 {2, 3}
  2⁶ = 64 ≡ 12 ≢ 1 ✓；2⁴ = 16 ≡ 3 ≢ 1 ✓
  → 2 是原根

求法：枚举 g = 2, 3, … 逐个判定（原根通常很小）
  已知原根后，其他原根 = g^k（gcd(k, φ(m)) = 1）
```

### 3.2 算法流程

```text
求模 p 的一个原根：
  Step 1  分解 φ(p) = p−1 的素因子
  Step 2  for g = 2, 3, …：
            if 对所有素因子 q：g^((p−1)/q) ≢ 1 (mod p) → 返回 g
  复杂度：O(素数因子数 × log p × 尝试次数)，g 通常 ≤ 20 即中
```

## 4. 离散对数问题

### 4.1 定义

给定原根 g 与元素 b（模 m），求满足 g^x ≡ b (mod m) 的 x，记 x = log_g(b)。

**离散对数问题（DLP）**：求逆（由幂求指数）极其困难——这是 Diffie-Hellman 与 ElGamal 的安全基石。

### 4.2 与普通对数的对照

| 维度 | 实数对数 | 离散对数 |
|------|---------|---------|
| 环境 | 实数域 | 模 m 循环群 |
| 计算 | 表格/算法 | 无多项式算法 |
| 性质 | log(ab) = log a + log b | log_g(ab) ≡ log_g a + log_g b (mod φ(m)) |

### 4.3 已知算法

| 算法 | 复杂度 | 说明 |
|------|--------|------|
| 暴力枚举 | O(n) | 不可用 |
| BSGS（大步小步） | O(√n) | 经典面试/竞赛算法，见下 |
| Pollard-Rho（离散对数） | O(√n) | 内存更省 |
| 指标计算（Pohlig-Hellman） | 取决于因子分解 | p−1 光滑时极快（安全参数选择的依据！） |

```java
// BSGS：求 g^x ≡ b (mod p) 的 x，O(√p)
// 思想：x = i·m − j，拆成大步（i）与小步（j）两张表
long bsgs(long g, long b, long p) {
    long m = (long) Math.sqrt(p) + 1;
    Map<Long, Long> table = new HashMap<>();   // 小步表: b·g^j → j
    long cur = 1;
    for (long j = 0; j < m; j++) {
        table.putIfAbsent(cur * b % p, j);
        cur = cur * g % p;
    }
    long gm = modPow(g, m, p), factor = 1;     // 大步：g^(i·m)
    for (long i = 1; i <= m; i++) {
        factor = factor * gm % p;
        if (table.containsKey(factor))
            return i * m - table.get(factor);
    }
    return -1;
}
```

> ⚠️ 安全参数结论：DLP 的困难度与 p 的位数挂钩——Pohlig-Hellman 提示"p−1 必须有大素因子"（否则容易），这是 2048 位 DH 参数必须满足 "safe prime"（p = 2q+1，q 素数）的数学原因。

## 5. 指标与指数表

### 5.1 指标（Index）

给定原根 g，每个 b 对应唯一的 x = log_g(b)，称为 b 的**指标**。

**指标的对数法则**（与普通对数同构）：

- log_g(ab) ≡ log_g a + log_g b (mod φ(m))
- log_g(a^k) ≡ k·log_g a (mod φ(m))
- log_g(1) = 0，log_g(g) = 1

### 5.2 指数表（工程应用）

预计算"底数 → 指标"表，可把乘法变成加法：

```text
模 7（原根 3）的指数表：
  数   1  2  3  4  5  6
  指标 0  2  1  4  5  3

应用：解 x⁴ ≡ 4 (mod 7)
  → 4·log₃x ≡ log₃4 = 4 (mod 6)
  → log₃x ≡ 4·4⁻¹ = 4·4 ≡ 4 (mod 6)（4⁻¹ mod 6 = 4）
  → x ≡ 3⁴ = 4 (mod 7)  ✓

工程形式：解高次同余 x^k ≡ b (mod p) 的标准套路
```

## 6. 密码学应用

### 6.1 Diffie-Hellman 密钥交换

```text
公开参数：素数 p 与原根 g
  Alice 选 a，发 A = g^a mod p
  Bob 选 b，发 B = g^b mod p
  双方密钥：K = B^a = g^(ab) = A^b (mod p)

安全性：窃听者只知道 g, p, A, B —— 求 ab 需要离散对数（DLP）
  计算 g^(ab) 而不先求 a/b（CDH 假设）
```

### 6.2 ElGamal 加密

```text
公钥 (p, g, y)，私钥 x（y = g^x mod p）
加密 m：选随机 k，输出 (c₁, c₂) = (g^k, m·y^k)
解密：m ≡ c₂ · c₁^(−x) (mod p)
  （c₁^x = g^(kx) = y^k 还原随机因子）

特点：概率加密（同明文两次加密不同）、
      密文两倍长 —— 工程上 ElGamal 通常做混合加密
```

### 6.3 与 ECC 的对应

| 概念 | 模 p 乘法群 | 椭圆曲线群 |
|------|------------|-----------|
| 生成元 | 原根 g | 基点 G |
| 离散对数 | x = log_g(b) | k = 满足 [k]G = P 的 k |
| 难题 | DLP | ECDLP |
| 密钥长度 | 2048 位 | 256 位（同安全级） |

> 💡 重要认知：**ECC 不是新数学，是"换了群的同一套密码"**——把模 p 乘法群换成椭圆曲线点群，离散对数假设依然成立，但密钥短 8 倍。理解 DLP 就理解了现代公钥密码的大半。

## 7. 工程与安全视角

| 工程要点 | 说明 |
|---------|------|
| 安全参数 | 2048 位 p 需为 safe prime（p−1 含大素因子） |
| 群验证 | 接收方需验证 g 的阶确实为大素数（防小子群攻击） |
| 随机数 | 私钥 a/b 必须真随机（弱随机数 = 可破解） |
| 协议攻击 | 中间人攻击需认证；参数替换攻击需校验群元素 |
| 后量子视角 | DLP 被 Shor 算法攻破 → 格基密码接管（08 模块） |

> 🎯 **核心要点**：原根与离散对数揭示密码学的核心不对称——**正向计算（幂）容易，逆向求解（对数）困难**。所有"基于离散对数"的密码协议（DH、ElGamal、DSA、ECC）都是这个不对称性的工程化；而安全的本质是参数选择（safe prime、群阶验证）而非算法本身。

## 8. 小结

| 问题 | 答案 |
|------|------|
| 阶是什么？ | a 的幂回到 1 的最短周期（整除 φ(m)） |
| 原根是什么？ | 阶 = φ(m) 的元素（循环群生成元） |
| 何时有原根？ | m ∈ {2, 4, pᵏ, 2pᵏ} |

| 安全参数注意？ | p−1 要大素因子（safe prime），防 Pohlig-Hellman |
