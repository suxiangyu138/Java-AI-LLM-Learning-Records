## 1. 同余的定义与性质

### 1.1 定义

若 m | (a − b)，则称 a 与 b **模 m 同余**，记作：

a ≡ b (mod m)

等价表述：a 和 b 除以 m 的余数相同。

```text
示例：17 ≡ 5 (mod 12)；−3 ≡ 9 (mod 12)
（时钟算术：17 点 = 下午 5 点，−3 点 = 晚 9 点）
```

### 1.2 同余的运算性质（模运算四则）

| 性质 | 公式 |
|------|------|
| 加减 | a≡b, c≡d ⟹ a±c ≡ b±d (mod m) |
| 乘法 | a≡b, c≡d ⟹ ac ≡ bd (mod m) |
| 幂 | a≡b ⟹ aⁿ ≡ bⁿ (mod m) |
| 同除（条件） | ac≡bc 且 gcd(c,m)=1 ⟹ a≡b |
| 模数约化 | a≡b (mod m) ⟹ a≡b (mod d)，d|m |

> ⚠️ 除法不能直接做：ac ≡ bc 时，只有 c 与模数互素才能"约分 c"。这引出模逆元的概念（04 模块详述）。

### 1.3 模运算的防溢出工程

```text
(a + b) mod m 可以直接模（结果在合理范围内）
(a × b) mod m 在 Java long 下可能溢出：
  10⁹ × 10⁹ = 10¹⁸ < 2⁶³ ≈ 9.2×10¹⁸ 勉强安全
  更大必须用 BigInteger 或二进制拆分乘法（见 03 模块）
```

## 2. 剩余系

### 2.1 同余类与剩余类

**同余类**：模 m 把所有整数分成 m 个类（余数 0, 1, …, m−1），类内两两同余。任取每类一个代表元组成 **完全剩余系**（如 {0, 1, …, m−1}）。

**简化剩余系**：完全剩余系中与 m 互素的代表元集合，元素个数 = φ(m)。

```text
示例：m = 8
  完全剩余系：{0,1,2,3,4,5,6,7}
  简化剩余系：{1,3,5,7}，φ(8) = 4

工程对应：哈希桶 = 完全剩余系；互素限制在 RSA 中无处不在
```

### 2.2 剩余系的性质

- 完全剩余系中元素两两不同余
- 与 m 互素的剩余类个数 = φ(m)（欧拉函数）
- 简化剩余系在乘法下封闭（互素数的乘积仍与 m 互素）

## 3. 模运算的代数结构

### 3.1 模 n 的环结构

模 n 的整数集在加、乘下构成**环** Zₙ：

| 结构 | 成立条件 | 意义 |
|------|---------|------|
| 加法群 | 恒成立 | 模加法可逆（逆元 = −a） |
| 乘法半群 | 恒成立 | 乘法封闭但非全部可逆 |
| 乘法群 | n 为素数 | 非零元全部可逆 → **域 GF(p)** |

> 💡 工程要点：模素数 p 时，所有非零元都有逆元——这就是"有限域 GF(p)"（`离散数学/05` 模块），AES、ECC 的算术基础。模合数时只有互素元可逆。

### 3.2 循环群视角

模 p 的乘法群（p 素数）是**循环群**：存在原根 g，使群中每个元素都是 g 的幂（05 模块详述）。循环性 = Diffie-Hellman 的数学基础。

## 4. 费马小定理

### 4.1 定理内容

若 p 为素数且 gcd(a, p) = 1，则：

a^(p−1) ≡ 1 (mod p)

**证明思路**（必背）：对简化剩余系 {1, 2, …, p−1} 逐个乘以 a，得到同一集合的置换；连乘后约去公共因子得 a^(p−1) ≡ 1。

### 4.2 三大推论

| 推论 | 公式 | 用途 |
|------|------|------|
| 快速求逆元 | a^(p−2) ≡ a⁻¹ (mod p) | 组合数取模的逆元计算 |
| 幂约化 | aⁿ ≡ a^(n mod (p−1)) (mod p) | 大指数快速计算 |
| 素性必要条件 | 若 a^(p−1) ≢ 1 则 p 必为合数 | Miller-Rabin 的起点 |

```java
// 费马小定理求逆元（p 为素数）：inv(a) = a^(p-2) mod p
long invFermat(long a, long p) {
    return modPow(a, p - 2, p);   // 快速幂（06 模块）
}
// 复杂度 O(log p) —— 比扩展欧几里得实现更简单（但要求 p 为素数）
```

## 5. 欧拉定理

### 5.1 定理内容（费马小定理的推广）

若 gcd(a, m) = 1，则：

a^φ(m) ≡ 1 (mod m)

其中 φ(m) 为欧拉函数（1..m 中与 m 互素的整数个数）。

```text
特例：m 为素数时 φ(p) = p−1 → 费马小定理
      m = pq（两素数乘积）时 φ(pq) = (p−1)(q−1) —— RSA 的核心！
```

### 5.2 欧拉函数的计算

| 情形 | φ 值 |
|------|------|
| 素数 p | p − 1 |
| 素幂 p^e | p^e − p^(e−1) = p^(e−1)(p−1) |
| 互素乘积 | φ(ab) = φ(a)·φ(b)（积性） |
| 一般 n | n·Π(1 − 1/pᵢ) |

```text
示例：φ(2026)？先分解 2026 = 2 × 1013（1013 为素数）
  φ(2026) = 2026 × (1−1/2) × (1−1/1013) = 1012
```

### 5.3 RSA 解密正确性的证明（教科书级）

```text
RSA：n = pq，e·d ≡ 1 (mod φ(n))
加密：c ≡ m^e (mod n)
解密：m ≡ c^d (mod n)

证明：c^d ≡ m^(ed) ≡ m^(1 + k·φ(n)) ≡ m·(m^φ(n))^k (mod n)
    由欧拉定理 m^φ(n) ≡ 1 (mod n)（gcd(m,n)=1 时）
    ⟹ c^d ≡ m  ∎
```

> 🎯 这一页是"数论为什么是密码学基础"的最佳答案：**RSA 的正确性完全建立在欧拉定理上**，安全性建立在"分解 n 困难"上——一个定理负责正确，一个难题负责安全。

## 6. 威尔逊定理

**定理**：p 为素数当且仅当 (p−1)! ≡ −1 (mod p)。

```text
验证：p=5：(4)! = 24 ≡ −1 (mod 5) ✓
反例：p=6：(5)! = 120 ≡ 0 (mod 6)，而 6 是合数 ✓

工程用途：极小规模素性判定、数论理论证明（勒让德符号等）
```

## 7. 模运算的工程形态

| 场景 | 模运算角色 |
|------|-----------|
| 哈希取模 | `hash & (n−1)`（2 幂容量）或 `% n` |
| 环形队列/数组 | `(head + 1) % capacity` |
| 轮询调度 | `(i + 1) % nodeCount`（负载均衡） |
| 星期计算 | 世纪年份同余（蔡勒公式） |
| 加密体系 | RSA/ECC/DH 全部基于模算术 |
| 大数幂 | 边算边模防溢出（快速幂） |
| 校验 | Luhn（mod 10）、CRC（模 2 多项式） |

### 工程陷阱：负数的模

```java
// Java 的 % 结果与被除数同号（数学余数应为非负）
int r = -7 % 3;        // -1（数学上应为 2）
int r2 = ((a % m) + m) % m;   // 统一转为 [0, m) 的标准写法
```

> 🎯 **核心要点**：同余把"整数世界"折叠成"循环世界"——所有工程中的取模、环形结构、加密运算都在这个循环世界里进行。费马/欧拉定理则是"循环世界里求幂"的捷径：指数可以模 φ(m) 约化，这让 RSA 的 2048 位指数运算变得可行。
