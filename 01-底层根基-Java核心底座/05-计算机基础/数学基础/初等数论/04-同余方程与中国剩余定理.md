## 1. 线性同余方程

### 1.1 定义与转化

形如 ax ≡ b (mod m) 的方程称为线性同余方程。

**关键转化**：ax ≡ b (mod m) ⟺ 存在 y 使 ax + my = b（线性丢番图方程！）

→ 上一模块的工具直接复用：有解 ⟺ gcd(a, m) | b。

### 1.2 求解流程

```text
求解 ax ≡ b (mod m)：
  Step 1  计算 g = gcd(a, m)
  Step 2  若 g ∤ b → 无解（结束）
  Step 3  三边同除 g：(a/g)x ≡ (b/g) (mod m/g)，此时互素
  Step 4  求逆元：(a/g)⁻¹ mod (m/g)（扩展欧几里得）
  Step 5  x ≡ (b/g)·(a/g)⁻¹ (mod m/g)

示例：6x ≡ 15 (mod 21)
  g = gcd(6,21) = 3，3 | 15 ✓
  → 2x ≡ 5 (mod 7)，2⁻¹ ≡ 4 (mod 7)
  → x ≡ 20 ≡ 6 (mod 7)
  解集：x = 6, 13, 20 (mod 21) —— 共 3 个解
```

### 1.3 解的个数规律

| 情形 | 解个数 |
|------|:---:|
| gcd(a,m) ∤ b | 0 |
| gcd(a,m) = 1 | 1（模 m 下唯一） |
| gcd(a,m) = g > 1 且 g \| b | g 个（模 m 下） |

## 2. 解的结构与个数

### 2.1 统一表述

方程 ax ≡ b (mod m) 的解（若有）在模 m 下恰有 g = gcd(a, m) 个：

x ≡ x₀ + (m/g)·k，k = 0, 1, …, g−1

```text
示例：6x ≡ 15 (mod 21) 的解
  x₀ = 6，步长 m/g = 7
  → x ≡ 6, 13, 20 (mod 21)  ✓ 与 1.2 结果一致
```

### 2.2 与逆元的统一视角

互素时 ax ≡ b (mod m) 的唯一解 x ≡ b·a⁻¹ (mod m)——**逆元是线性同余方程的"除法"**。

## 3. 中国剩余定理（CRT）

### 3.1 定理内容

设 m₁, m₂, …, mₖ 两两互素，则同余方程组：

x ≡ a₁ (mod m₁)，x ≡ a₂ (mod m₂)，…，x ≡ aₖ (mod mₖ)

在模 M = m₁m₂…mₖ 下有**唯一解**。

### 3.2 构造性解法（必背）

```text
Step 1  M = m₁·m₂·…·mₖ；Mᵢ = M / mᵢ
Step 2  求 Mᵢ 模 mᵢ 的逆元 tᵢ（扩展欧几里得，互素保证存在）
Step 3  x ≡ Σ aᵢ·Mᵢ·tᵢ (mod M)

示例：x ≡ 2 (mod 3)，x ≡ 3 (mod 5)，x ≡ 2 (mod 7)
  M = 105
  M₁ = 35：35⁻¹ mod 3 → 2⁻¹ ≡ 2，项 = 2×35×2 = 140
  M₂ = 21：21⁻¹ mod 5 → 1⁻¹ ≡ 1，项 = 3×21×1 = 63
  M₃ = 15：15⁻¹ mod 7 → 1⁻¹ ≡ 1，项 = 2×15×1 = 30
  x ≡ 140 + 63 + 30 = 233 ≡ 23 (mod 105)
  验证：23 ≡ 2 (mod 3)，23 ≡ 3 (mod 5)，23 ≡ 2 (mod 7) ✓
```

```java
// 中国剩余定理（模数两两互素）
long crt(long[] a, long[] m) {
    long M = 1, x = 0;
    for (long mi : m) M *= mi;
    for (int i = 0; i < a.length; i++) {
        long Mi = M / m[i];
        long ti = modInverse(Mi % m[i], m[i]);   // 扩展欧几里得
        x = (x + a[i] * Mi % M * ti) % M;
    }
    return (x % M + M) % M;
}
```

### 3.3 为什么正确（证明要点）

```text
对第 i 个方程：Mᵢ·tᵢ ≡ 1 (mod mᵢ)，且 Mⱼ ≡ 0 (mod mᵢ)（j≠i）
  → x 的构造式中第 i 项 ≡ aᵢ (mod mᵢ)，其余项 ≡ 0
  → x 满足每个方程 ✓
唯一性：假设两解 x₁, x₂，则 mᵢ | (x₁−x₂) 对全部 i
  → M | (x₁−x₂)（互素乘积整除）→ 模 M 下唯一
```

## 4. CRT 的扩展：模数不互素

### 4.1 判定条件

方程组 x ≡ a₁ (mod m₁)，x ≡ a₂ (mod m₂) 有解 ⟺ a₁ ≡ a₂ (mod gcd(m₁, m₂))。

### 4.2 合并两个方程

```text
x ≡ a₁ (mod m₁)，x ≡ a₂ (mod m₂)：
  令 x = a₁ + m₁·t 代入第二个方程：
  m₁·t ≡ a₂ − a₁ (mod m₂)
  设 g = gcd(m₁, m₂)，可解（g | (a₂−a₁) 时）
  → 求出 t ≡ t₀ (mod m₂/g)
  → x ≡ a₁ + m₁·t₀ (mod lcm(m₁, m₂))   ← 合并结果

工程用法：逐对合并 → 得到单一同余式（或发现无解）
```

## 5. 高次同余方程

### 5.1 一般形式

形如 aₙxⁿ + … + a₁x + a₀ ≡ 0 (mod m) 的方程。

**通用策略**：分解模数为素数幂 → 逐解 → CRT 重组：

```text
解 f(x) ≡ 0 (mod m)：
  m = p₁^e₁…pₖ^eₖ（分解）
  对每个素数幂解 f(x) ≡ 0 (mod pᵢ^eᵢ)
  → 解的笛卡尔积组合 → CRT 合并成模 m 的解

这是"模合数问题 → 模素数幂问题"的标准降维手段
```

### 5.2 素数模情形的简单版

- 一次式：已解决（第 1-2 节）
- 二次式：见 06 模块（平方剩余）
- 一般多项式：f(x) ≡ 0 (mod p) 至多有 deg(f) 个解（**拉格朗日定理**）

## 6. 素数幂情形的提升

### 6.1 Hensel 提升（Lifting）

若 x₀ 是 f(x) ≡ 0 (mod p^k) 的解，可尝试提升到模 p^(k+1) 的解：

```text
设 x = x₀ + p^k·t，代入 f(x) ≡ 0 (mod p^(k+1))：
  f(x₀) + p^k·t·f'(x₀) ≡ 0 (mod p^(k+1))
  → 若 f'(x₀) ≢ 0 (mod p)：t 唯一（可解）
  → 若 f'(x₀) ≡ 0：要么无提升，要么全部 t 都可
  （与微积分"牛顿法"同构的离散版！）

示例：解 x² ≡ 2 (mod 49)
  mod 7：x₀ = 3（3² = 9 ≡ 2）
  提升：f'(3) = 6 ≡ 6 ≢ 0 (mod 7) → 唯一提升
  x = 3 + 7t，代入 9 + 42t + 49t² ≡ 2 (mod 49) → 42t ≡ −7 ≡ 42 (mod 49) → t ≡ 1
  → x ≡ 10 (mod 49)
```

> 💡 Hensel 提升是"从模 p 的解爬到模 p^k 的解"的标准工具，竞赛与理论数论均高频出现——它与牛顿迭代的相似性是"离散化微积分"的绝佳范例。

## 7. CRT 的工程应用

| 场景 | CRT 角色 |
|------|---------|
| **RSA-CRT** | 私钥解密拆成模 p、模 q 两路（快 4 倍），见下 |
| 秘密共享 | 把秘密拆成多个同余条件（阈值共享的变形） |
| 冗余数系（RNS） | 大数用互素模表示，加减乘并行（AI 推理加速硬件） |
| 大整数运算 | 用 CRT 把大模数运算拆小（如 1024 位 RSA 内部） |
| 周期同步 | 多个周期事件找公共时刻（日历问题） |
| 竞赛题 | "找同时满足多个同余条件的数" |

### RSA-CRT 解密加速（必知工程细节）

```text
标准解密：m = c^d mod n（2048 位指数，慢）
CRT 加速：利用 n = p·q
  m₁ = c^d₁ mod p（d₁ = d mod (p−1)）
  m₂ = c^d₂ mod q（d₂ = d mod (q−1)）
  组合：m = (m₁·q·q⁻¹ + m₂·p·p⁻¹) mod n（CRT 构造）
  效果：指数减半 + 模数减半 → 约 4 倍加速（OpenSSL 默认）

安全注意：CRT 实现需防"故障注入攻击"
  （注错一路结果可反推出 p、q —— 实际攻击案例存在）
```

> 🎯 **核心要点**：CRT 是"分而治之"的数论形态——大模数问题拆成小模数问题并行解决再重组。它在 RSA 加速（4×）、RNS 硬件（AI 加速器）、秘密共享三个领域都是核心技术，是初等数论"最实用"的定理之一。
