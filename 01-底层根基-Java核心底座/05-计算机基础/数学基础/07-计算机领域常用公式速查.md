## 1. 数制与编码

### 1.1 数制转换

| 转换 | 方法 |
|------|------|
| 十进制 → 二进制 | 除 2 取余，逆序排列 |
| 十进制 → 八进制 | 除 8 取余，逆序排列 |
| 十进制 → 十六进制 | 除 16 取余，逆序排列 |
| 二进制 → 十进制 | `D = Σ kᵢ × 2ⁱ`（kᵢ 为第 i 位） |
| 二进制 → 八进制 | 3 位一组转八进制 |
| 二进制 → 十六进制 | 4 位一组转十六进制 |

### 1.2 补码运算

```
正数：补码 = 原码 = 反码
负数：补码 = 反码 + 1

补码加法：[X+Y]_补 = [X]_补 + [Y]_补 （模 2ⁿ）
补码减法：[X-Y]_补 = [X]_补 + [-Y]_补

8-bit 范围：
  原码：-127 ~ +127
  补码：-128 ~ +127（多一个负数）
```

### 1.3 IEEE 754 浮点数

```
float (32-bit)：  1 符号 + 8 指数 + 23 尾数  → ≈7 位有效数字
double (64-bit)： 1 符号 + 11 指数 + 52 尾数 → ≈16 位有效数字

值 = (-1)^sign × (1 + mantissa) × 2^(exponent - bias)
  bias_float  = 127
  bias_double = 1023

特殊值：
  全 0 → ±0
  指数全 1，尾数全 0 → ±∞
  指数全 1，尾数非 0 → NaN
```

## 2. 算法复杂度

### 2.1 时间复杂度

| 量级 | 记号 | n=10 | n=100 | n=10⁶ | 典型算法 |
|------|------|------|-------|-------|---------|
| 常数 | O(1) | 1 | 1 | 1 | 数组随机访问 |
| 对数 | O(log n) | 3 | 7 | 20 | 二分查找 |
| 线性 | O(n) | 10 | 100 | 10⁶ | 顺序遍历 |
| 线性对数 | O(n log n) | 33 | 664 | 2×10⁷ | 归并排序、快速排序 |
| 平方 | O(n²) | 100 | 10⁴ | 10¹² | 冒泡排序、选择排序 |
| 立方 | O(n³) | 1000 | 10⁶ | 10¹⁸ | Floyd-Warshall |
| 指数 | O(2ⁿ) | 1024 | 巨大 | — | 汉诺塔递归 |

### 2.2 空间复杂度

| 级别 | 典型场景 |
|------|---------|
| O(1) | 原地排序、变量交换 |
| O(log n) | 二分查找的递归栈 |
| O(n) | 辅助数组、哈希表 |
| O(n²) | 邻接矩阵 |

### 2.3 递归复杂度主定理

```
T(n) = a·T(n/b) + f(n)

情况1：f(n) = O(n^{log_b a - ε})  → T(n) = Θ(n^{log_b a})
情况2：f(n) = Θ(n^{log_b a})      → T(n) = Θ(n^{log_b a}·log n)
情况3：f(n) = Ω(n^{log_b a + ε})  → T(n) = Θ(f(n))

示例：
  二分查找：T(n) = T(n/2) + O(1)      → O(log n)    （a=1,b=2）
  归并排序：T(n) = 2T(n/2) + O(n)    → O(n log n) （a=2,b=2）
  矩阵乘法（朴素）：T(n) = 8T(n/2) + O(n²) → O(n³)
```

## 3. 组合数学

### 3.1 排列与组合

| 概念 | 公式 | 说明 |
|------|------|------|
| 排列 | `P(n,k) = n!/(n-k)!` | 有序选取 k 个 |
| 组合 | `C(n,k) = n!/(k!(n-k)!)` | 无序选取 k 个 |
| 可重复排列 | `nᵏ` | 允许重复的有序选取 |
| 可重复组合 | `C(n+k-1, k)` | 允许重复的无序选取 |
| 多重集排列 | `n!/(n₁!·n₂!·...·nₘ!)` | 含相同元素 |
| 圆排列 | `(n-1)!` | 环形排列 |

### 3.2 二项式定理

```
(a+b)ⁿ = Σₖ C(n,k)·aⁿ⁻ᵏ·bᵏ

推论：
  Σₖ C(n,k) = 2ⁿ              （n 元集合的子集总数）
  Σₖ (-1)ᵏ·C(n,k) = 0
```

### 3.3 容斥原理

```
|A ∪ B| = |A| + |B| - |A ∩ B|

|A ∪ B ∪ C| = |A| + |B| + |C|
             - |A∩B| - |B∩C| - |A∩C|
             + |A∩B∩C|
```

### 3.4 经典数列

| 数列 | 递推 / 公式 | 前几项 |
|------|-----------|--------|
| 斐波那契 | `Fₙ = Fₙ₋₁ + Fₙ₋₂` | 0, 1, 1, 2, 3, 5, 8, 13... |
| 卡特兰数 | `Cₙ = C(2n,n)/(n+1)` | 1, 1, 2, 5, 14, 42, 132... |
| 汉诺塔 | `Tₙ = 2ⁿ - 1` | 1, 3, 7, 15, 31... |
| 阶乘 | `n! = n·(n-1)!` | 1, 1, 2, 6, 24, 120... |

## 4. 信息论

### 4.1 核心公式

| 概念 | 公式 | 说明 |
|------|------|------|
| **自信息** | `I(x) = -log₂ P(x)` | 事件 x 的信息量（bit） |
| **熵** | `H(X) = -Σ P(x)·log₂ P(x)` | 信源的平均信息量 |
| **联合熵** | `H(X,Y) = -ΣΣ P(x,y)·log₂ P(x,y)` | 两个变量的总不确定性 |
| **条件熵** | `H(Y\|X) = -ΣΣ P(x,y)·log₂ P(y\|x)` | 已知 X 后 Y 的不确定性 |
| **互信息** | `I(X;Y) = H(X) + H(Y) - H(X,Y)` | X 和 Y 共享的信息 |
| **交叉熵** | `H(P,Q) = -Σ P(x)·log₂ Q(x)` | 用 Q 近似 P 的代价（**ML 损失函数**） |
| **KL 散度** | `Dₖₗ(P‖Q) = Σ P(x)·log(P(x)/Q(x))` | Q 相对 P 的信息损失 |
| **困惑度** | `PPL = 2^{H(P,Q)}` | 模型不确定性的直观度量 |

### 4.2 关系链

```
H(P,Q) = H(P) + Dₖₗ(P‖Q)

交叉熵 = 真实分布的熵 + KL 散度

训练时 H(P) 固定 → 最小化交叉熵 = 最小化 KL 散度
```

### 4.3 信道容量

```
香农公式：C = W·log₂(1 + S/N)

  C：信道容量（bps）
  W：带宽（Hz）
  S/N：信噪比（线性值，非 dB）

dB 转线性：S/N = 10^(dB/10)
```

## 5. 图论

### 5.1 基本定理

| 定理/公式 | 说明 |
|-----------|------|
| `Σ deg(v) = 2E` | 握手定理（无向图） |
| `Σ deg⁺(v) = Σ deg⁻(v) = E` | 有向图出入度相等 |
| `E ≤ V(V-1)/2` | 简单无向图最大边数 |
| `E = V-1` | 树的最小边数（连通且无环） |

### 5.2 最短路径算法

| 算法 | 适用条件 | 时间复杂度 |
|------|----------|-----------|
| Dijkstra | 非负权 | `O((V+E) log V)` |
| Bellman-Ford | 允许负权 | `O(VE)` |
| Floyd-Warshall | 全源 | `O(V³)` |
| A* | 有启发函数 | 取决于启发函数质量 |

### 5.3 最小生成树

| 算法 | 时间复杂度 | 适合 |
|------|-----------|------|
| Kruskal（并查集） | `O(E log E)` | 稀疏图 |
| Prim（堆优化） | `O((V+E) log V)` | 稠密图 |

## 6. 密码学

### 6.1 RSA 密钥生成

```
1. 选两大素数 p, q
2. n = p × q
3. φ(n) = (p-1)(q-1)
4. 选 e（1 < e < φ(n)，且 gcd(e, φ(n)) = 1）
5. 计算 d：d × e ≡ 1 (mod φ(n))

公钥：(n, e)
私钥：(n, d)

加密：c = m^e mod n
解密：m = c^d mod n
```

### 6.2 Diffie-Hellman 密钥交换

```
公开参数：大素数 p，生成元 g

Alice：选私钥 a → 发送 A = g^a mod p
Bob：  选私钥 b → 发送 B = g^b mod p

共享密钥：K = B^a mod p = A^b mod p = g^{ab} mod p
```

## 7. 计算机网络

### 7.1 传输性能

| 公式 | 说明 |
|------|------|
| `传输延迟 = 数据量 / 带宽` | 数据量（bit）/ 带宽（bps） |
| `传播延迟 = 距离 / 信号速度` | 距离（m）/ 速度（~2×10⁸ m/s） |
| `RTT = 2 × 传播延迟` | 往返时间（理想情况） |
| `吞吐率 ≤ min(带宽, 窗口/RTT)` | TCP 窗口限制 |
| `带宽延迟积 = 带宽 × RTT` | 管道容量 |

### 7.2 HTTP 状态码

| 范围 | 含义 | 常见值 |
|------|------|--------|
| 1xx | 信息 | 100 Continue, 101 Switching |
| 2xx | 成功 | 200 OK, 201 Created, 204 No Content |
| 3xx | 重定向 | 301 Moved, 302 Found, 304 Not Modified |
| 4xx | 客户端错误 | 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found, 429 Too Many Requests |
| 5xx | 服务端错误 | 500 Internal, 502 Bad Gateway, 503 Unavailable, 504 Gateway Timeout |

### 7.3 IP 地址

```
IPv4：32-bit，约 43 亿个地址
  分类：A 类 (0.0.0.0-127.255.255.255)
        B 类 (128.0.0.0-191.255.255.255)
        C 类 (192.0.0.0-223.255.255.255)

子网掩码：
  /24 = 255.255.255.0 → 254 个可用主机
  /16 = 255.255.0.0   → 65534 个可用主机

CIDR 表示：192.168.1.0/24
  网络号位数 = 24
  主机号位数 = 8
  可用地址数 = 2⁸ - 2 = 254（去掉网络地址和广播地址）
```
