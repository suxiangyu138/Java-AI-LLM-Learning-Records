# 数字逻辑实验

## 课程概述
- **课程性质**：专业基础必修课（配套实验课）
- **适用专业**：计算机类各专业
- **开课学期**：与数字逻辑理论课同步
- **考核方式**：实验操作 + 实验报告 + 期末操作考核

## 课程目标
1. 掌握常用数字集成电路的使用方法
2. 熟悉数字逻辑电路的搭建与测试
3. 学会使用数字逻辑实验箱和相关仪器
4. 验证和加深对数字逻辑理论的理解

## 核心实验项目

### 实验一：门电路逻辑功能测试
- 常用TTL门电路芯片的认识（74LS00、74LS04、74LS08、74LS32等）
- 门电路逻辑功能的验证
- 真值表的实测

### 实验二：组合逻辑电路设计
- 用门电路实现指定逻辑函数
- 设计多数表决电路（三人/五人）
- 逻辑函数化简与电路实现的对应关系

### 实验三：编码器与译码器
- 74LS148（8-3线优先编码器）功能测试
- 74LS138（3-8线译码器）功能测试
- 用译码器实现逻辑函数
- 数码管显示驱动（74LS48/74LS47）

### 实验四：数据选择器
- 74LS151（8选1数据选择器）功能测试
- 74LS153（双4选1数据选择器）
- 用数据选择器实现逻辑函数

### 实验五：加法器
- 半加器电路设计
- 全加器电路设计
- 74LS283（4位超前进位加法器）
- 多位加减法电路

### 实验六：触发器功能测试
- 基本RS触发器的测试
- D触发器（74LS74）功能测试
- JK触发器（74LS76）功能测试
- 触发器之间的相互转换

### 实验七：寄存器与计数器
- 74LS194（4位双向移位寄存器）及移位操作
- 74LS161（4位同步二进制计数器）
- 任意进制计数器的设计（置数法和复位法）
- 74LS290（十进制计数器）

### 实验八：综合设计
- 简易数字钟设计
- 交通灯控制器
- 多路抢答器
- 简易频率计

## 重点难点
- **重点**：常用IC芯片的使用、组合逻辑电路设计
- **难点**：电路故障排查、时序电路的调试

## 实验仪器
- 数字逻辑实验箱
- 双踪示波器/逻辑分析仪
- 万用表
- 集成芯片（74LS/74HC系列）

## 学习方法与建议
1. 实验前仔细阅读芯片手册（datasheet），了解引脚功能
2. 连线前先画好电路连接图，核对无误再动手
3. 遇到电路不工作，按"电源→输入→关键节点→输出"的顺序排查
4. 注意芯片的电源和地线不要漏接
