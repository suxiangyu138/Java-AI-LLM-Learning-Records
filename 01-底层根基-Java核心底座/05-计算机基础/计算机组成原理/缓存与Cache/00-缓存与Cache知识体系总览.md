## 3. 学习路线推荐

**路线 A：入门速成（半天）**
01 → 02 → 04 的核心小节。目标是建立"缓存 = 小而快的存储 + 局部性利用"的心智模型，能读懂 AMAT 公式与 Cache 结构图。适合刚接触计算机组成原理的学习者。

**路线 B：系统进阶（2-3 天，推荐）**
01 → 02 → 03 → 04 → 05 全链路。每个模块做 1-2 道计算题（地址分解、AMAT、替换序列模拟）。掌握后能够解释：为什么循环交换能提速、为什么多线程共享变量会慢、伪共享为什么存在。**这是后端工程师理解性能问题的必经路线。**

**路线 C：前沿探索（面向研究者/硬件爱好者）**
在路线 B 基础上加读 06 与 07，重点关注：替换算法从 LRU 到学习型策略的演进（SRRIP→Hawkeye→PACIPV）、3D 堆叠缓存与 CXL 如何重塑缓存层次、侧信道攻防对微架构设计的反作用力。

## 4. 核心概念速查

| 概念 | 一句话定义 | 关键数据/要点 |
|------|-----------|--------------|
| Cache Line | 缓存与主存交换的最小单位 | 现代 CPU 统一 **64 字节** |
| 命中率 / 缺失率 | 命中次数 / 访问总次数 | 缺失率 = 1 − 命中率 |
| 缺失惩罚 (Miss Penalty) | 一次缺失额外付出的时间 | L1 缺失约 10-15 周期；DRAM 缺失约 200-500 周期 |
| AMAT | 平均访存时间 = 命中时间 + 缺失率 × 缺失惩罚 | 衡量缓存性能的第一公式 |
| Set / Way | 组相联中的"组"与"路" | Zen 5 L1D：48KB、12-way → 64 组 |
| Tag/Index/Offset | 地址分解的三个字段 | offset = log₂(行长)，index = log₂(组数) |
| Write-Through / Write-Back | 写策略两极端：直写内存 / 延迟回写 | 现代 CPU 多级缓存普遍 write-back |
| Write-Allocate | 写缺失时是否把行调入缓存 | 与 write-back 搭配为默认组合 |
| MESI / MOESI / MESIF | 一致性协议状态集合 | M=修改、E=独占、S=共享、I=无效、O=拥有、F=转发 |
| 伪共享 (False Sharing) | 不同核心改同一行的不同字段导致的一致性震荡 | 行内 padding 可消除 |
| 替换策略 | 组满时驱逐哪一行 | 硬件用 pseudo-LRU / RRIP 近似；研究用学习型策略 |
| 3D V-Cache | TSV 堆叠 SRAM 到 CPU 上 | 9800X3D L3 = 96MB（32+64） |
| 内存侧缓存 | 内存控制器旁的 DRAM 缓存 | Lunar Lake 8MB；CXL 设备侧缓存 |
| Spectre/Meltdown | 利用乱序/推测执行的时间侧信道 | 需软件+微码双线缓解 |

> 🎯 **核心要点**：缓存的所有设计——结构、算法、协议、安全——都由"存储墙"这一物理现实驱动：CPU 速度与 DRAM 延迟差距太大，只能靠局部性赌"下一访问大概率还在缓存里"。理解了这个赌局，就理解了 Cache 的一切。
