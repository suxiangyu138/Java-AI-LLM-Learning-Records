# 计算机组成与体系结构（一）实验

## 课程概述
- **课程性质**：专业核心必修课（配套实验课）
- **适用专业**：计算机类各专业
- **开课学期**：与组成原理理论课同步
- **实验环境**：Vivado/Quartus + FPGA开发板 或 Logisim仿真
- **硬件描述语言**：Verilog HDL 或 VHDL
- **考核方式**：实验操作 + 实验报告 + 验收答辩

## 核心知识点

### 实验一：运算器(ALU)设计
- ALU功能需求
  - 支持运算：加(ADD)、减(SUB)、与(AND)、或(OR)、异或(XOR)、逻辑左移(SLL)、逻辑右移(SRL)、比较(SLT)
  - 8位或32位操作数
  - 输出：运算结果result + 零标志ZF(结果为零) + 溢出标志OF(有符号溢出)
- 模块化设计
  - 加法器：行波进位加法器→分析关键路径延迟
  - 超前进位加法器(CLA)：并行计算进位，减少延迟
  - 逻辑运算单元：位与门/或门/异或门
  - 移位器：用多路选择器实现
  - 减法实现：A - B = A + (~B + 1)（补码取反加一）
- 仿真验证
  - 编写testbench：遍历多种运算和边界值（如最大+1溢出）
  - 检查运算结果和标志位的正确性

### 实验二：寄存器组(Register File)设计
- 寄存器组规格
  - 32个32位通用寄存器（R0-R31，其中R0硬连线为0）
  - 两个读端口（同时读两个寄存器的值）
  - 一个写端口（写入一个寄存器）
- 硬件实现
  - 用二维数组：reg [31:0] reg_file [31:0]
  - 读操作：assign rd_data1 = reg_file[rd_addr1]（组合逻辑直接读）
  - 写操作：always @(posedge clk) if (we) reg_file[wr_addr] <= wr_data（时序逻辑写）
  - R0特殊处理：读R0始终返回0，写R0被忽略
- 仿真验证
  - 先写入几个寄存器的值
  - 同时读取两个寄存器，验证数据正确
  - 验证R0不可写、R0读始终为0

### 实验三：程序计数器(PC)与指令存储器
- 程序计数器(PC)
  - 功能：保存下一条指令的地址，每个时钟周期更新
  - 输入：next_pc（下一条指令地址）
  - 输出：pc（当前指令地址）
  - 实现：always @(posedge clk or posedge rst) if(rst) pc <= 0; else pc <= next_pc
- 指令存储器
  - 用BRAM或分布式RAM实现
  - 初始化：从文件加载机器码（$readmemh("program.hex", mem)）
  - 读操作：组合逻辑，ins = mem[pc]（取指阶段）
- 简单的PC更新逻辑
  - 顺序执行：next_pc = pc + 4（每条指令4字节）
  - 无条件跳转：next_pc = jump_target
  - 条件分支：next_pc = branch_taken ? branch_target : pc+4

### 实验四：单周期CPU数据通路
- 数据通路组成
  - PC → 指令存储器 → 指令字
  - 指令字 → 译码：opcode/rs/rt/rd/immediate
  - 译码 → 寄存器组读 → ALU运算 → 数据存储器访问 → 写回
- 关键模块互联
  - PC→指令存储器地址
  - 指令存储器→控制单元(opcode+funct)
  - 寄存器组→ALU两个操作数
  - ALU→数据结果（或作为访存地址）
  - 数据存储器→写回数据
- 多路选择器
  - ALUSrc_MUX：选择ALU第二个操作数（寄存器值 / 立即数）
  - MemtoReg_MUX：选择写回寄存器的来源（ALU结果 / 内存读出数据）
  - PCSrc_MUX：选择PC的来源（PC+4 / 分支目标地址 / 跳转目标地址）
- 控制信号生成
  - 根据指令的opcode和funct字段生成各控制信号
  - 寄存器堆：RegWrite（写使能）
  - ALU：ALUOp（运算类型选择）
  - 数据存储器：MemRead, MemWrite
  - 多路选择器：ALUSrc, MemtoReg
  - 分支控制：Branch, Jump

### 实验五：控制单元设计
- 硬布线控制器
  - 基于指令真值表设计组合逻辑
  - 输入：opcode(6位) + funct(6位)
  - 输出：各控制信号
  - 实现方法：用always @(*) case(opcode)，对应每种指令给出各控制信号值
- RISC风格指令集（以MIPS为参考）
  - R-type（寄存器操作）：ADD, SUB, AND, OR, SLT
    - opcode=000000, funct指定具体操作
    - 控制：RegWrite=1, ALUSrc=0, MemtoReg=0
  - I-type（立即数操作）：ADDI, ORI, LW, SW, BEQ
    - 控制信号随具体指令变化
    - LW：RegWrite=1, ALUSrc=1, MemtoReg=1, MemRead=1
    - SW：RegWrite=0, ALUSrc=1, MemWrite=1
    - BEQ：Branch=1, RegWrite=0
  - J-type：JMP
    - Jump=1, RegWrite=0

### 实验六：单周期CPU集成与测试
- 所有模块集成
  - 实例化：PC、指令存储器、寄存器组、ALU、数据存储器、控制单元
  - 顶层模块连接所有子模块的端口
- 测试程序编写
  - 用汇编编写简单程序（如1+2+...+10求和、斐波那契数列、数组拷贝）
  - 手动编译为机器码并加载到指令存储器
- 仿真验证
  - 观察关键信号波形：PC、指令字、寄存器值、ALU结果、数据存储器读写
  - 单步执行，检查每一步是否正确
  - 直至程序结束，检查最终结果（寄存器值或存储器值）
- 上板验证
  - 将CPU综合并下载到FPGA开发板
  - 用开关输入、LED/数码管输出观察运行结果
  - 或用UART输出结果到PC端显示

### 实验七：五级流水线CPU设计（进阶）
- 流水线寄存器插入
  - IF/ID寄存器：PC+4、指令字
  - ID/EX寄存器：控制信号、寄存器值1/2、立即数、rs/rt/rd编号
  - EX/MEM寄存器：Branch/MemRead/MemWrite/RegWrite/MemtoReg、ALU结果、写入数据
  - MEM/WB寄存器：RegWrite/MemtoReg、读出的内存数据、ALU结果、目标寄存器rd
- 数据冒险处理
  - 前推(Forwarding)：
    - EX/MEM的rd == ID/EX的rs → 前推ALU结果
    - MEM/WB的rd == ID/EX的rs → 前推内存/WB数据
    - 前推多路选择器：新增ForwardA/ForwardB控制
  - 加载使用冒险(Load-Use Hazard)：
    - lw后紧接使用该寄存器 → 必须插入一个气泡(stall)
- 控制冒险处理
  - 静态分支预测：预测不跳转
  - 预测错误：冲刷(flush)IF/ID中的指令
  - 分支在ID阶段解析：减少冲刷损失
- 流水线暂停(Stall)和冲刷(Flush)逻辑
  - Stall：保持PC和IF/ID寄存器不变，ID/EX寄存器清零(NOP)
  - Flush：将IF/ID寄存器置为零指令(NOP)
