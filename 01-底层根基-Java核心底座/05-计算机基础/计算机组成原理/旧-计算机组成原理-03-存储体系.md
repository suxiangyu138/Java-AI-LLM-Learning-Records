# 存储体系

## 📌 课程定位
理解存储层次是写出cache-friendly代码的基础。从寄存器→Cache→内存→磁盘，每一层差一个数量级的速度，知道数据在哪里、怎么流动，决定了程序的真实性能。

## 🎯 核心章节

### 1. 存储器层次结构（⭐ 记忆金字塔）
```
[寄存器]     ← 1 cycle,  ~1ns
[L1 Cache]   ← 2-4 cycles, ~1ns
[L2 Cache]   ← 10-20 cycles, ~3-5ns
[L3 Cache]   ← 30-70 cycles, ~10-20ns
[主存/RAM]   ← 100-300 cycles, ~50-100ns
[SSD]        ← ~10,000-100,000 cycles
[HDD]        ← ~10,000,000 cycles (~10ms)
```
**核心规律**：越快越小越贵，越慢越大越便宜。局部性是这座金字塔能工作的原因。

### 2. 主存储器（RAM）
- **SRAM（静态RAM）**：6个晶体管存1位，快但贵——用于Cache
- **DRAM（动态RAM）**：1个晶体管+1个电容存1位，需要刷新——用于内存条
  - DDR4/DDR5，内存频率（如3200MHz）
- **ROM家族**：PROM(可编程一次)、EPROM(紫外线擦除)、EEPROM(电擦除)、Flash(闪存)

### 3. Cache（高速缓存，⭐ 核心）
- **局部性原理（两大基石）**：
  - **时间局部性**：刚访问的数据很可能再次被访问
  - **空间局部性**：刚访问数据附近的数据很可能被访问
- **Cache映射方式**：
  - **直接映射**：每个内存块只能放到唯一的Cache行——简单但冲突多
  - **全相联映射**：任意位置——灵活但比较电路复杂
  - **组相联映射（折中）**：Cache分组，组内全相联，组间直接映射——主流方案
- **替换算法**：LRU（最近最少使用）、随机、FIFO
- **写策略**：
  - **写直达（Write-Through）**：同时写Cache和内存——简单但慢
  - **写回（Write-Back）**：只写Cache，被替换时写回内存——主流方案
- **Cache 友好代码**：
  ```c
  // ✅ Cache友好：按行遍历
  for(i=0;i<N;i++) for(j=0;j<M;j++) sum+=a[i][j];
  // ❌ Cache不友好：按列遍历（每次跨一整行）
  for(j=0;j<M;j++) for(i=0;i<N;i++) sum+=a[i][j];
  ```

### 4. 虚拟内存（⭐ 与操作系统衔接）
- **虚拟地址 vs 物理地址**：每个进程有独立虚拟地址空间
- **页表 + MMU**：CPU发出虚拟地址→MMU查页表→翻译为物理地址
- **TLB（快表）**：页表的Cache，加速地址翻译
- **缺页中断**：要访问的页不在内存→OS从磁盘加载（页面置换算法）

### 5. 磁盘存储
- **机械硬盘（HDD）**：盘面、磁道、扇区、寻道时间+旋转延迟
- **固态硬盘（SSD）**：基于NAND Flash，无机械部件，随机读快
- **RAID**：多磁盘冗余阵列——RAID0（条带化）、RAID1（镜像）、RAID5（分布式奇偶校验）
