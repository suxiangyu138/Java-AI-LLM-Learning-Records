## 1. 为什么 GPU 赢了 AI

### 1.1 深度学习的数学恰是 GPU 的强项

```
神经网络的核心运算：矩阵乘法 + 逐元素激活
  C[i][j] = Σ A[i][k] × B[k][j]     ← 密集、规则、可并行

GPU 的天赋：
  ① 数万核并行（矩阵天然可切块）
  ② Tensor Core 直连矩阵乘（硬件级融合）
  ③ 高带宽喂饱计算（权重流式读取）

对照：CPU 的 4-24 核 + 窄 SIMD → 吞吐差 10-100 倍
```

### 1.2 Tensor Core 革命的本质

```
Volta（2017）：把"矩阵乘"从软件循环变成硬件指令
  一次指令完成 4×4 矩阵乘 → 精度/能耗/面积同时优化
演进：TF32 → FP16 → FP8 → FP4（精度下降，吞吐翻倍）
  2025 的推理主力：FP4（Blackwell）/ FP6（AMD）——精度与吞吐的甜点

算力演进（H100→B200→Rubin）：989 TF → 9 PF → 50 PF FP4
  三年 50 倍 —— 全靠"低精度 + 更专的硬件"
```

### 1.3 生态飞轮

```
GPU 赢的不只是硬件：CUDA + cuDNN + PyTorch = 20 年软件积累
  新模型框架第一天就支持 CUDA → 研发节奏取决于 NVIDIA
  这就是 MI350 "硬件接近、生态追赶"困境的根源
```

## 2. 训练 vs 推理：两种硬件需求

### 2.1 需求的根本差异

| 维度 | 训练 | 推理 |
|------|------|------|
| 核心矛盾 | 算力（要快） | **带宽 + 容量**（要便宜） |
| 瓶颈 | 矩阵乘吞吐 | 权重读取带宽（KV Cache 容量） |
| 精度 | FP16/BF16（梯度稳定） | FP8/FP4/INT8（够用即可） |
| 规模 | 千卡-万卡集群 | 单卡-机柜，延迟敏感 |
| 商业模式 | 资本开支（训练一次） | 运营成本（每 token 收钱） |

### 2.2 推理的带宽经济学

```
生成 1 个 token：读取全部权重 + 处理 KV Cache
  70B 模型 FP8：每个 token 读 70GB → 每秒 token 数 ≈ 带宽 / 模型大小
  H100（3.5TB/s）：~50 token/s
  Rubin（22TB/s）：~300 token/s  ← 带宽 6×，吞吐 6×

推论（行业共识）：
  推理吞吐 ∝ 显存带宽 —— 这就是 Blackwell→Rubin
  把带宽翻 2.75× 而算力只翻 2.8× 的原因（同步涨价）
```

### 2.3 新产品形态：KV Cache 专用卡

```
Rubin CPX：GDDR7 显存、专为长上下文推理设计
  （KV Cache 要大容量而非高带宽 —— 分工细化）
2025 现象：推理专用卡/芯片（Groq LPU 等）挑战通用 GPU
  通用 GPU 的应法：FP4 + 大显存 + 机柜内直连
```

## 3. 集群级互联：从单卡到 NVL72

### 3.1 训练为什么需要"一个逻辑 GPU"

```
千亿参数模型训练：单卡 192GB 装不下 → 模型切到多卡
  每步迭代都要全卡同步（梯度 AllReduce）
  → 卡间通信速度 = 训练效率天花板

NVIDIA 方案：NVLink 机柜域
  NVL72：72 GPU 全互联（1.8TB/s/卡）→ 软件视角像"一块巨型 GPU"
  GB200 时代交换机从 3 层减到 0 层

对照：传统 8 卡服务器 + InfiniBand 网络
  跨节点通信走以太/IPoIB → 慢 10-100 倍
```

### 3.2 互联的演进

| 世代 | 互连 | 带宽/GPU | 集群形态 |
|------|------|:---:|---------|
| Hopper | NVLink 4 + IB | 900 GB/s | 8 卡 DGX + 交换机 |
| Blackwell | NVLink 5 | 1.8 TB/s | NVL72 机柜直连 |
| Rubin | NVLink 6 | 3.6 TB/s | NVL144/576 |
| AMD/开放 | UALink | 300 GB/s | 72 GPU 域（2026） |

### 3.3 互联背后的物理现实

```
铜背板 vs 光模块：
  NVLink 5/6 走铜背板（短距离、低延迟、低功耗）
  Ultra 互连（跨机柜）走光（CX9 28.8TB/s）

功耗分布（NVL72 机柜 ~120kW）：
  GPU 计算 ~60%、HBM ~20%、互连 ~15%、其他 ~5%
  → 液冷不是可选项，是唯一解
```

## 4. 算力经济学：GPU 是资产

### 4.1 GPU 的金融属性

```
2025 现实：GPU 从"硬件"变"资产"
  云厂商 backlog 360 万卡；B200 售罄至 2026 年中
  英伟达 FY2025 收入 $130.5B（+114%）
  算力租赁（CoreWeave 等）估值暴涨 —— GPU 是"算力时代的土地"

经济学链条：
  模型变大 → 训练/推理需求↑ → GPU 需求↑ → 供给瓶颈（HBM/封装）
  → 租金上涨 → 云厂商囤卡 → 需求进一步↑（自我强化）

风险：泡沫论（算力过剩 vs 需求永续）—— 2025-2026 的行业大辩论
```

### 4.2 单位成本的核心指标

```
训练：$/PF-day（每 PFLOPS 一天的租金）
推理：$/M tokens（每百万 token 成本）—— Rubin 声称 -10×

换算直觉：
  DeepSeek-R1 一次训练 ≈ 数百万美元（2025 实况）
  每 token 成本 0.001 元级 → 万亿 token 应用 = 十亿元级成本
  → 成本优化（FP4、KV 压缩、缓存）直接决定 AI 应用的商业模式
```

### 4.3 降本三路径（2025-2026）

| 路径 | 手段 | 效果 |
|------|------|------|
| 硬件换代 | FP4/FP6、更大带宽 | token 成本每代 -50%+ |
| 软件优化 | 量化、投机解码、KV 缓存 | 再 -30-50% |
| 芯片多元化 | 推理专用卡、CPU 推理、端侧 NPU | 长尾负载分流 |

## 5. 供应链：HBM 与 CoWoS 的瓶颈

### 5.1 三大瓶颈

| 瓶颈 | 现状（2025-2026） | 影响 |
|------|------------------|------|
| **HBM 产能** | 海力士/三星/美光全被包圆，涨价 20%+ | GPU 成本 50%+ 在显存 |
| **CoWoS 封装** | TSMC 2026-27 产能预留给 NVIDIA | 出货量天花板 |
| **电力** | 单机柜 120kW+，数据中心改造 | 建设周期 2-3 年 |

### 5.2 HBM 的地缘博弈

```
中国特供市场：H200/H20 重启生产（2025）
  出口管制 → 中国自研 HBM 追赶（长江存储等）
  2026 看点：中国 AI 芯片（昇腾等）的 HBM 供应是最大变量

全球格局：HBM 三强（韩 2 + 美 1）→ 高度集中的上游
  GPU 厂商议价权弱于内存厂 —— 罕见的上游强势
```

### 5.3 供应链学习要点（AI 工程视角）

```
① 采购周期：旗舰 GPU 从下单到货 6-12 个月 —— 算力规划要提前
② 显存即成本：选 GPU 先算"每 GB 显存能换多少 token"
③ 液冷改造：2026 起新机房默认液冷 —— 风冷时代结束
④ 区域差异：电力/补贴决定 GPU 集群选址（中东/冰岛成为算力中心）
```

## 6. 2026 产业格局与未来

### 6.1 三足与两超

```
NVIDIA（~80%+）：年更节奏 + 机柜系统 + 生态锁定 —— 霸主
AMD（第二）：MI400 vs Rubin 正面对决（2026）—— 挑战者
自研阵营（TPU/昇腾/定制）：云巨头与主权算力 —— 分流者
开放标准（UALink/UDNA）：反锁定联盟 —— 变量

2026 判断：
  ① Rubin 放量主导高端（HBM4 供应是关键）
  ② MI400 首次"规格上不落后"（432GB/19.6TB/s）
  ③ 推理专用形态扩散（CPX 类产品 + 端侧 NPU 分流）
```

### 6.2 未来三年技术主线

| 方向 | 内容 | 时间 |
|------|------|:---:|
| 带宽军备 | HBM4/HBM4e，22 TB/s → 更高 | 2026-28 |
| 机柜巨型化 | NVL144 → NVL576 | 2026-27 |
| 精度下沉 | FP4 普及、INT4 化、块浮点 | 2026- |
| 近存计算 | 逻辑叠 HBM（3D）| 2027+ |
| 软件智能 | 编译器/调度自动优化（Triton 类） | 持续 |

### 6.3 对 AI 应用开发者的启示

```
① 算力预算思维：模型选型 = 显存容量 × 带宽 × 成本三角
   （3-AI 应用层的 DeepSeek 部署方案正是这个三角的工程化）
② 推理优化是核心技能：KV 缓存、量化、投机解码 ——
   本质都是"少读权重、多复用计算"
③ 端侧与云端分工：NPU 跑小模型、GPU 跑大模型 ——
   混合推理是 2026 架构主流
④ 硬件直觉：读 GPU 发布先看"带宽/容量/每 token 成本"，
   再看算力数字（营销常把 FP4 峰值当卖点）
```

> 🎯 **核心要点**：AI 时代的 GPU = 算力经济学的主角。理解"推理 ∝ 带宽、训练 ∝ 互联、成本 ∝ 显存"三条铁律，就能看懂 2026 年的每一次产品发布、每一次涨价、每一次供应链新闻——它们全是这三条铁律的展开。
