## 3. 学习路线推荐

**路线 A：建立 GPU 认知（半天）**
01 → 02 → 03。理解"GPU 为什么和 CPU 长得不一样"：SIMT 单指令多线程、带宽为王的存储设计、用线程切换隐藏延迟。

**路线 B：软硬结合（2 天，推荐）**
路线 A + 04。加上 CUDA 编程模型后，你能解释：为什么合并访问（coalesced）快、为什么分支发散慢、为什么共享内存这么快——**这些是 AI 推理优化（FlashAttention、KV Cache）的底层依据**。

**路线 C：产业与架构前沿（面向 AI 工程/架构师）**
路线 B + 05 + 06 + 07。理解 2025-2026 的 GPU 产业：Blackwell 售罄、Rubin 翻倍、HBM 供应链、液冷机柜——为什么 GPU 是 AI 时代的"石油"。

## 4. 核心概念速查

| 概念 | 一句话定义 | 关键数据（2025-2026） |
|------|-----------|---------------------|
| SIMT | 单指令多线程：一条指令驱动 32 个线程 | NVIDIA warp = 32 线程 |
| SM / CU | GPU 的最小计算单元（流式多处理器） | H100 132 SM；MI355X 256 CU |
| 线程块 (Block) | 映射到 SM 的线程集合 | 上限 1024 线程 |
| 占用率 (Occupancy) | 驻留线程 / 最大线程的比例 | 寄存器与共享内存是杠杆 |
| 分支发散 | warp 内线程走向不同分支 | 串行执行各路，性能杀手 |
| 合并访问 | warp 同周期访问连续内存 | 命中率高 10-100 倍 |
| 共享内存 | SM 内可编程高速存储 | ~100-228KB/SM，带宽 TB/s 级 |
| HBM | 高带宽内存（3D 堆叠） | B200 192GB/8TB/s；Rubin 22TB/s |
| Tensor Core | 矩阵乘专用单元 | Volta 引入，AI 算力的主力 |
| 带宽墙 | 计算翻倍快于带宽翻倍 | 存储层次设计全为带宽服务 |
| FP4/FP8 | 低精度数据格式 | 2025 起推理主力（Blackwell FP4） |
| 液冷 | 1000W+ GPU 的散热方案 | GB200 NVL72 整机 2.7kW |

> 🎯 **核心要点**：GPU 的全部设计围绕一句话——**用大量并行线程掩盖访存延迟，用带宽替代延迟**。CPU 用"乱序+缓存"把单线程做快，GPU 用"万线程+调度"把吞吐做满；理解这个哲学差异，就理解了 GPU 的一切结构选择。
