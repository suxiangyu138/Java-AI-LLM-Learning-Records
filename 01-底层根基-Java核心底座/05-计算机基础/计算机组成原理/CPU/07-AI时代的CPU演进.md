## 1. NPU：CPU 里的 AI 加速器

### 1.1 为什么 CPU 需要 NPU

```
传统路径：AI 推理在 CPU 上跑（AVX-512 等 SIMD 硬算）→ 慢且费电
专用路径：GPU 大而贵，不适合端侧/嵌入
新答案：NPU（Neural Processing Unit）—— 集成进 CPU/SoC 的低功耗 AI 单元
```

| 方案 | 能效 | 适用场景 |
|------|:---:|---------|
| CPU SIMD 硬算 | 低（10-50 TOPS/kW） | 偶发小模型 |
| GPU | 高（但功耗大） | 训练/大推理 |
| **NPU** | 极高（100+ TOPS/kW） | 端侧持续 AI（语音、图像、Copilot） |

### 1.2 NPU 做什么

```
端侧 AI 场景（无需上云）：
  语音助手本地识别、实时翻译、AI 摄像头处理、
  代码补全（Copilot 本地模型）、OCR、背景虚化……

设计特征：
  低功耗持续运行（几十 TOPS、几瓦级）
  与 CPU/GPU 共享内存（无需拷贝）
  通过 SDK（ONNX Runtime、OpenVINO、DirectML）编程
```

## 2. AI PC：定义与算力门槛

### 2.1 AI PC 的算力竞赛（2024-2026）

| 平台 | 算力（平台 NPU 部分） | 备注 |
|------|:---:|------|
| Intel Lunar Lake | 48 TOPS | AI PC 起步 |
| AMD Strix Point | 50 TOPS | |
| **Intel Panther Lake** | **180 TOPS（平台总量）** | 18A 首发，CPU+GPU+NPU 合计 |
| Qualcomm Snapdragon X | 45-75 TOPS | ARM AI PC |
| Apple M4 系 | 38 TOPS（Neural Engine） | 长期端侧 AI 先行者 |

> ⚠️ 注意口径：营销上的"TOPS"常为 **平台总算力**（NPU+GPU+CPU），实际 AI 任务多数只用 NPU 部分——对比时看"NPU TOPS"而非宣传数字。

### 2.2 AI PC 的定义之争

```
微软定义（2024 起）：NPU ≥40 TOPS + Copilot 键 + 特定 Windows 功能
行业现实：40 TOPS 只是"跑得动本地小模型"的门槛
未来：模型每代翻倍，AI PC 的算力要求同步水涨船高
  → 2026 年 Panther Lake 的 180 TOPS 平台算力是新一代门槛
```

### 2.3 对开发者的影响

```
端侧 AI 开发栈（2025-2026 主流）：
  ONNX Runtime + NPU 后端（Windows ML / OpenVINO / TFLite）
  Java 生态：JNI 调 ONNX Runtime，或走 Spring AI 的本地模型适配
  模型：Phi-3/4、Llama 3.2 1B-8B、Gemma 3 等端侧可跑

工程注意：NPU 内存带宽是瓶颈 —— 模型权重要常驻（量化 + 缓存）
```

## 3. 异构计算的权力转移

### 3.1 计算权力的再分配

```
2010s：CPU 是唯一主角（通用计算）
2020s：GPU 抢走训练、NPU 抢走端侧推理 —— CPU 被"围剿"到剩什么？

CPU 的保留地（2025）：
  ① 控制/调度：所有任务的编排者（异构系统的"大脑"）
  ② 单线程延迟敏感负载：数据库、微服务、编译
  ③ 通用计算兜底：没有专用加速器的任何负载
```

### 3.2 CPU 的应对：自己也 AI 化

```
① 指令集 AI 化：AVX-512（x86）、SVE2/SME2（ARM，Neoverse V3 强制 SVE2）
  → 服务器 CPU 直接跑 AI 推理（int8 吞吐翻倍）
② 集成 NPU：端侧 AI 不掉队（第 1-2 节）
③ CXL 内存池化：AI 工作负载的大内存需求 → CPU 主导内存扩展
④ EPYC 的 AI 定位：Turin 的 +37% HPC/AI IPC —— 服务器 CPU 抢 AI 推理单
```

> 💡 业界判断（2025）：AI 推理的"长尾"（小模型、低延迟、高并发）仍属 CPU/异构芯片，只有训练与超大推理属 GPU——CPU 不是被淘汰，而是换角色。

## 4. SMT 存废之争

### 4.1 争论的背景（2025-2026）

```
传统认知：SMT 是"免费"的多线程（+30% 吞吐、成本小）
新现实（2026）：
  ① 核心数爆炸：EPYC 192 核、Diamond Rapids 192-256 核
     → 线程密度可由物理核直接满足
  ② SMT 的隐藏成本：两线程互踢缓存、调度复杂、侧信道放大
  ③ 云厂商早就禁了超线程（AWS 长期默认关闭）
```

### 4.2 Diamond Rapids 的决定

```
Intel Diamond Rapids（Xeon 7，2026 中）：首发**不支持 SMT**
  → 业界首次在服务器旗舰上放弃超线程
  → 理由：核数足够 + SMT 复杂度不值（Intel CFO 口径）
  → 后续 Coral Rapids（2027-28）重新引入 SMT —— 说明是"战术放弃"
```

### 4.3 何时 SMT 还有意义

| 场景 | SMT 价值 |
|------|:---:|
| 核心数少（桌面 8-16 核） | 高（线程不够用） |
| 核心数多（服务器 100+） | 低（物理核已足） |
| 云租户隔离 | 负价值（安全/公平性） |
| 延迟敏感单线程 | 负价值（互踢缓存） |

> 🎯 结论：SMT 是"核数不足时代的补偿品"——核数充足后，物理核 > SMT 成为新共识。这是 2026 年 CPU 架构最重要的信号之一。

## 5. x86 / ARM / RISC-V 三极格局

### 5.1 三极的 2025-2026 态势

| 阵营 | 主场 | 2025-2026 关键事件 | 软肋 |
|------|------|------------------|------|
| x86 | 桌面/服务器/遗产生态 | APX 32 寄存器（Diamond Rapids）；AMD 服务器份额持续扩大 | 功耗、单核效率 |
| ARM | 移动/笔电/云服务器 | M4 效率王；Neoverse 服务器渗透；Snapdragon AI PC | 软件生态仍略欠 |
| RISC-V | 嵌入式/AI 加速器 | 服务器核（Ventana/Tenstorrent/玄铁）初步落地 | 生态最薄、性能仍低 |

### 5.2 力量对比的量化视角

```
服务器市场（2025）：
  x86 仍占大头（AMD 份额上升最快）
  ARM 云核（Graviton/Ampere）持续扩张 —— 按核数计占比可观
  RISC-V 服务器核开始出现，但量产有限

客户端（2025）：
  x86 AI PC（Intel/AMD）vs ARM AI PC（Snapdragon/Apple）正面对撞
  性能差距在缩小，每瓦差距 ARM 仍优
```

### 5.3 RISC-V 的追赶路径

```
优势：开源 ISA、无授权费、可定制（AI 加速可加指令）
现状：核性能落后 2-3 代（对标 2020-2022 的 x86/ARM 水平）
路线：从嵌入式/AI 加速器切入（指令集自由是 AI 场景的杀手锏）
关键变量：软件生态（编译器/OS/应用）的补课速度
```

> ⚠️ 2025-2026 的重要观察：RISC-V 的 AI 叙事（自定义指令 + 开源）在推理加速器中已经赚钱，但通用 CPU 市场（跑 Windows/Linux 生态）仍需 5 年+。

## 6. AI 时代 CPU 的未来

### 6.1 三个确定性趋势

| 趋势 | 表现 | 驱动因素 |
|------|------|---------|
| 异构化 | CPU+GPU+NPU 同封装成标配 | Panther Lake 三件套平台 180 TOPS |
| 每瓦竞争 | 效率从"加分项"变"生死线" | 云成本、端侧电池 |
| 内存变革 | CXL 内存池化 + 更大缓存 | EPYC 9755 的 512MB L3，AI 负载吃内存 |

### 6.2 对软件开发的深层影响

- **Java/后端**：性能瓶颈从 CPU 频率转向内存带宽与缓存亲和
- **端侧 AI**：NPU 编程成为系统工程师新技能（ONNX Runtime / OpenVINO）
- **数据库**：192 核 + 512MB 缓存的服务器改变容量规划假设

### 6.3 学习建议（面向未来 5 年）

1. **掌握微架构框架**（本目录 01-04 模块）—— 判断任何新 CPU 的能力底牌
2. **关注 ISA 演进**（APX/SME2/RVV）—— 编译器与 JIT 的优化新空间
3. **理解异构编程**（CPU+NPU 协作）—— 端侧 AI 的工程主旋律
4. **用"每瓦性能 + 场景化基准"替代"频率/核数崇拜"**

> 🎯 **核心要点**：AI 时代 CPU 的剧本是——**CPU 失去垄断但守住控制**：AI 负载被 NPU/GPU 分走，但 CPU 的调度权、通用性、生态粘性使其仍是异构系统的枢纽；同时 CPU 自身通过指令集与缓存向 AI 倾斜（SVE2、超大 L3、APX）。三极格局 + 异构计算 = 未来十年的 CPU 主旋律。
