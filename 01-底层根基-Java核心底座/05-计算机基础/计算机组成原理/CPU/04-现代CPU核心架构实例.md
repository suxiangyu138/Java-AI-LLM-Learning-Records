## 1. AMD Zen 5：均衡派代表

### 1.1 定位与成绩（2024-2025）

Zen 5 是 AMD 近十年最重要的核心迭代，全面应用于：

| 产品线 | 代表 | 核心配置 |
|--------|------|---------|
| 桌面 | Ryzen 9000（Ryzen 9 9950X） | 16 核 Zen 5 |
| 移动 | Strix Point / Krackan | 12 核（Zen 5 + Zen 5c 混合） |
| 服务器 | **EPYC 9005 "Turin"** | **最高 192 核** |

IPC 提升：云/企业负载 **+17%**，HPC/AI 负载 **+37%**（对比 Zen 4）。

### 1.2 核心设计要点

| 设计 | 参数 | 说明 |
|------|:---:|------|
| 发射宽度 | 8（6 整数 + 4 FP） | 宽发射阵营 |
| 乱序窗口 | 500+ 条 | 大窗口藏延迟 |
| L1D | 48KB 12-way | 3 周期命中 |
| L1I | 32KB 8-way | 配合 TAGE 预测器 |
| L2 | 1MB 16-way | 每核私有 |
| L3 | 32MB/CCD（X3D 96MB） | CCD 内共享 |
| SMT | 2 | 服务器/桌面均支持 |
| 分支预测 | TAGE + 循环预测器 | >97% |

### 1.3 设计哲学

```
"均衡快"：L2 小但 L3 快、DRAM 路径短（~484 周期）
  → 依赖"快速存储层次"而非超大 L2（对比 Intel 的大 L2 路线）
6 ALU：整数吞吐优先，编译器友好
FMA 4×128 位：AVX-512 双周期执行（折中功耗与吞吐）
```

> 💡 实测启示：Zen 5 在内存敏感负载（数据库、游戏）中优势明显——因为它的 L3/DRAM 路径快；这正是"缓存层次设计决定负载表现"的活例（详见 `缓存与Cache/04` 模块）。

## 2. Intel Lion Cove / Cougar Cove

### 2.1 Lion Cove（2024-2025 在售）

Intel 自 2015 年 Skylake 以来最大核心改版，用于 Lunar Lake / Arrow Lake：

| 设计 | 参数 | 说明 |
|------|:---:|------|
| 发射宽度 | 8-10 | 最宽 x86 核心之一 |
| 乱序窗口 | 500+（ROB 大） | 大量调度器队列 |
| L0D | 48KB 12-way | 全新第 0 级 |
| L1D（L1.5） | 192KB 12-way | 两级数据缓存，实测吸收大量 L1D 缺失 |
| L1I | 64KB 16-way | |
| L2 | 2.5-3MB/核 | Arrow Lake 3MB——x86 最大每核 L2 |
| L3 | 12-36MB | 共享 |
| 特色 | 宽译码、双宽取指 | 前端带宽拉满 |

### 2.2 已知弱点与修复方向

```
实测弱点（Chips and Cheese 等 2025 分析）：
  ① L3 延迟 80+ 周期（环形总线扩展性问题）
  ② DRAM 延迟 565+ 周期（内存控制器分离封装）
  ③ 超大 L2 的命中延迟偏高
对策：L1.5 吸收局部缺失；Nova Lake 换代解决（见下）

Intel 官方承认：Arrow Lake 在高性能台式机市场"战略失误"
  → Nova Lake 被寄予"扳回平衡"的厚望（2026 下半年，Zen 6 对手）
```

### 2.3 Cougar Cove / Coyote Cove（路线图）

| 核心 | 应用 | 时间 | 定位 |
|------|------|:---:|------|
| Cougar Cove | Panther Lake（移动/轻薄） | 2025 底 | 18A 首款客户端核 |
| Coyote Cove | **Nova Lake**（台式机） | 2026 H2 | 全新设计，52 核顶配 |
| Panther Cove | Diamond Rapids（服务器） | 2026 中 | P 核独占，无 SMT 首发 |

> ⚠️ 注意区分：**Panther Lake（CPU 产品）** 用 Cougar Cove 核；**Panther Cove（核心名）** 用于 Diamond Rapids——两个"Panther"易混。

## 3. ARM Cortex-X925

### 3.1 定位

Armv9.2-A 旗舰性能核，面向旗舰手机与轻薄本，2025 年商用（联发科天玑 9400：1×X925 + 3×X4 + 4×A720）。

### 3.2 核心参数

| 设计 | 参数 | 说明 |
|------|:---:|------|
| 单线程性能 | **+36% vs Cortex-X4** | 近年最大跨代提升 |
| 发射宽度 | 8 | 宽发射 |
| 乱序窗口 | 加大 | 强化内存级并行 |
| L1D | 128KB | 移动端最大 L1 之一 |
| L2 | 2MB 起 | 可配置 |
| 分支预测 | 强化 TAGE | +8% 分支预测面积 |
| SMT | 无 | 移动端不用 SMT（功耗/面积不划算） |

### 3.3 设计哲学

```
单核冲刺：X 系列 = 峰值性能导向（牺牲面积/功耗）
与 A720/A520 组成 DynamIQ 异构集群：
  X925（大核爆发）+ A720（持续负载）+ A520（待机）
同一集群内共享 L3 —— 调度器按需迁移线程
```

> 💡 移动端启示：ARM 靠"异构核 + 弹性频率"而非 SMT 覆盖并行度——同一套 SoC 在不同负载形态下自动切换，这是 x86 桌面（同构大核 + SMT）之外的另一条路。

## 4. Apple M 系大核

### 4.1 定位

Apple 自研 Armv9.2 定制核，M4 系列（2024-2025）达到每瓦性能巅峰。

### 4.2 核心特点

| 设计 | 参数 | 说明 |
|------|:---:|------|
| 发射宽度 | 9-10 | 所有 CPU 中最宽之一 |
| 乱序窗口 | 600+ | 极致藏延迟 |
| 每瓦性能 | 业界第一梯队 | 10W 内做 4-5GHz 级吞吐 |
| 布局 | 4 大 + 6 小（M4 基础版） | big.LITTLE 路线 |
| SMT | 无 | Apple 始终不用超线程 |

### 4.3 为什么 M 系快且省

```
① 宽度极致：9-10 发射 + 超大窗口 → 单线程指令级并行吃满
② 架构定制自由：不受 x86 兼容包袱、不受外部生态约束
③ 频率务实：不冲 5GHz，在 ~4.4GHz 稳定运行（省功耗）
④ 存储层次协同：超大 L1/L2 + 低延迟内存（统一内存架构）

对照：x86 核心 30%+ 面积花在"兼容"与"预测错误回滚"上
```

> ⚠️ 注意：Apple 核的参数（发射宽度、窗口）来自第三方分析（AnandTech/Chips and Cheese 拆解），非官方披露——数字用于理解量级即可。

## 5. Neoverse V3：服务器 ARM

### 5.1 定位与成绩

Arm 基础设施旗舰核（Armv9.2-A），主打每线程性能 + 向量/AI 负载：

| 特性 | 说明 |
|------|------|
| SVE2/SME2 | 原生向量/矩阵支持（AI 推理/训练） |
| 每线程性能 | Arm 服务器阵营最高 |
| 对标 | Intel/AMD 大核（服务器） |
| 落地 | NVIDIA Grace 后继、云厂商自研（AmpereOne 等） |

### 5.2 家族对照

| 核 | 侧重 | 场景 |
|------|------|------|
| Neoverse V3 | 每线程性能 + 向量 | HPC、AI、高频交易 |
| Neoverse N3 | 性能功耗平衡 | 云扩容、网络、存储 |
| V3AE | 车规增强 | 自动驾驶、ADAS |

### 5.3 ARM 服务器的 2025 现状

```
市场份额：云数据中心 ARM 占比持续上升（AWS Graviton 系是大头）
路线：vCPU 密度与功耗效率是卖点（核多、每瓦吞吐高）
挑战：软件生态（虽已大幅成熟）、单线程极致性能仍逊 x86 旗舰
AmpereOne：192 自定义核，Armv8.6-A+ —— 核心密度路线代表
```

## 6. 五大核心全景对比

| 维度 | Zen 5 | Lion Cove | Cortex-X925 | Apple M 大核 | Neoverse V3 |
|------|:---:|:---:|:---:|:---:|:---:|
| ISA | x86-64 | x86-64 | Armv9.2 | Armv9.2 定制 | Armv9.2 |
| 发射宽度 | 8 | 8-10 | 8 | 9-10 | 8 |
| 乱序窗口 | 500+ | 500+ | 加大 | 600+ | 大 |
| L1D | 48KB | 48+192KB | 128KB | 192KB | ~64-128KB |
| L2/核 | 1MB | 2.5-3MB | 2MB+ | 4-16MB(簇) | 大容量 |
| SMT | 2 | 2 | 无 | 无 | 2 |
| 每瓦性能 | 高 | 中 | 高 | **极高** | 高 |
| 招牌 | 快 L3/DRAM 路径 | 超大 L2 + L1.5 | 单核 +36% | 宽度×效率 | SVE2/SME2 |
| 代表产品 | EPYC 9965 192 核 | ARL 285K | 天玑 9400 | M4 系列 | NVIDIA Grace 后继 |

**趋势总结（2025-2026）**：

```
① 宽度竞赛：8-10 发射成新常态（2015 年的 4-6 已是过去式）
② 大窗口成标配：500+ 乱序窗口才能喂饱宽发射
③ 缓存层次个性化：L1.5（Intel）、快速 L3（AMD）、大 L1（ARM）各显神通
④ SMT 出现分化：x86 服务器在"核多了还要不要 SMT"上摇摆
⑤ 每瓦性能成为新战场：Apple/ARM 以效率围剿 x86 的绝对性能
```

> 🎯 **核心要点**：2025 年的 CPU 竞争 = "宽度 × 窗口 × 存储层次 × 每瓦效率"的四维竞赛。看懂这张表，就能解读任何新一代 CPU 发布的新闻稿——那些百分比背后都是这四个维度的变化。
