## 1. 三大基础指标：IPC、频率、核数

### 1.1 性能公式

```
单线程性能 ≈ IPC × 频率
多线程性能 ≈ IPC × 频率 × 核数 × SMT 收益 × 扩展效率
```

| 指标 | 定义 | 2025 量级 |
|------|------|-----------|
| IPC | 每时钟周期完成的指令数 | 3-5（现代宽发射核） |
| 频率 | 时钟周期速率 | 3.5-5.7 GHz |
| 核数 | 物理核心数 | 4-192 核 |

### 1.2 三者关系与误区

```
误区 1："5.7GHz 一定比 5.0GHz 快"
  → 不对：还要看 IPC（Zen 5 的 5.7 vs 低频 X3D，后者游戏反胜）

误区 2："16 核 = 8 核的两倍"
  → 不对：多核扩展有天花板（内存带宽、一致性流量、调度）
  → 扩展效率：通用负载 70-90%，内存敏感负载可能 40%

误区 3："核多就是强"
  → 服务器比的是 核数 × IPC × 每瓦，Turin 192 核的杀手锏是
    "同功耗下更多核 + 更高 IPC"
```

### 1.3 频率的真相：Boost 与功耗绑定

```
标称频率（Base）：所有核满载时保证的频率
睿频（Boost）：单核/少核时拉高（受功耗与散热预算约束）
  9950X：基频 4.3GHz，单核 boost 5.7GHz —— 差额来自功耗预算再分配

注意：笔记本/迷你机受散热限制，boost 持续时间短（秒级就回落）
  → 同 CPU 在不同散热环境下表现差异巨大
```

## 2. 功耗与散热：TDP 的真实含义

### 2.1 TDP 不是"实测功耗"

```
TDP（热设计功耗）：散热器需处理的设计热功率 —— 不是真实功耗上限！
  9950X：TDP 170W，实测峰值可到 230W（PPT 限制下）
  EPYC 9965：TDP 500W（整 CPU 的散热设计值）

三个容易混淆的功耗值：
  TDP（散热设计）< PPT（封装功耗上限）≤ 实测峰值
  笔记本上：TDP 常常只是"标称"，实际由 PL1/PL2 动态控制
```

### 2.2 每瓦性能：新时代的王道

```
效率 = 性能 / 功耗
  同性能下功耗减半 → 散热/电费/密度（云）全面受益
  云厂商真实账本：每瓦性能决定机柜能塞多少 vCPU

2025 实证：
  Apple M4：同性能下功耗约为 x86 旗舰的 1/3
  ARM 服务器（Neoverse/AmpereOne）：同功耗下核数翻倍
  AMD/Intel 服务器：每瓦性能之争是 Turin vs Granite Rapids 的主战场
```

### 2.3 选购视角的功耗判断

```
① 台式机：看 PPT/实测，不看 TDP（散热按实测配）
② 笔记本：看 PL1/PL2 与模具散热评测（同 U 不同机差异巨大）
③ 服务器：看每瓦性能与 TCO（3 年电费可能超过 CPU 价格）
```

## 3. 基准测试：SPEC 与消费级榜单

### 3.1 基准的层次

| 层次 | 代表 | 特点 | 用途 |
|------|------|------|------|
| 微基准 | 单指令延迟、内存延迟 | 测硬件能力 | 架构分析 |
| 行业标准 | **SPEC CPU 2017** | 30+ 真实程序编译运行 | 官方 IPC/性能对比 |
| 综合跑分 | Geekbench、Cinebench | 混合负载快速评分 | 媒体/消费者 |
| 真实应用 | 游戏、编译、数据库 | 端到端体验 | 购买决策 |

### 3.2 SPEC：业界黄金标准

```
SPEC CPU 2017：整型 10 项 + 浮点 13 项（真实应用：编译器、物理引擎、AI）
  指标：SPECrate（吞吐）与 SPECspeed（单任务延迟）
  用途：厂商 IPC 声明都基于它（Zen 5 的 +17%/+37% 即 SPEC 结果）

注意：SPEC 需付费授权、配置严格 —— 消费者拿不到，媒体才有
```

### 3.3 消费级跑分的局限

| 跑分 | 问题 |
|------|------|
| Geekbench | 测的是"峰值快"，负载时间短、忽略持续性能 |
| Cinebench | 渲染负载单一，不代表游戏/数据库 |
| 任何单跑分 | 不能代表"你的工作负载" |

> 💡 正确用法：跑分用于"筛掉离谱选项"，最终用**你的真实负载**验证（后端场景：JVM 基准、数据库压测、编译时间）。

## 4. 读规格书的正确姿势

### 4.1 一份规格书的字段解剖（以 EPYC 9755 为例）

| 字段 | 值 | 解读 |
|------|:---:|------|
| 核心/线程 | 128C/256T | 128 核 × SMT 2 |
| 基频/睿频 | 2.7 / 4.1 GHz | 128 核满载 2.7 |
| L3 缓存 | **512MB** | 超大缓存 = 内存敏感负载王牌 |
| TDP | 500W | 需液冷/强风冷 |
| 内存 | 12 通道 DDR5-6400 | 带宽 ≈ 12 × 51.2GB/s |
| PCIe | 128 条 Gen5 / CXL 2.0 | I/O 扩展能力 |
| 制程 | 4nm/3nm CCD | 工艺决定效率 |

### 4.2 隐藏信息：别只看大数字

```
① 缓存容量 vs 延迟：大缓存≠快（还要看层次设计）
② 通道数 × 内存频率 = 真实带宽（12×6400MT/s 是单内存控制器时代 4 倍）
③ 睿频的持续能力：服务器看全核睿频，桌面看单核睿频
④ 核间延迟：同簇/跨簇/跨 socket 三级数字（NUMA 拓扑）
⑤ 指令集扩展：AVX-512/APX/SME2 决定特定负载上限
```

## 5. 评测方法论：别被数字骗了

### 5.1 对比的公平性清单

```
① 功耗对齐了吗？（X3D 低频 vs 高频非 X3D —— 比的是场景不是强弱）
② 内存同规格？（DDR5-5600 vs 6400 可差 5-8%）
③ 散热环境？（台式机水冷 vs 笔记本默认 → 不同结论）
④ 驱动/BIOS 版本？（一年前的评测可能已过时）
⑤ 样本数？（单次跑分 ≠ 统计显著）
```

### 5.2 你自己的评测法

```bash
# 服务器/后端视角的最小评测集
# ① 单线程：计算密集型循环（编译、正则、加密）
# ② 多线程：真实服务的压测（吞吐与 P99）
# ③ 内存敏感：大工作集哈希/数据库扫描
# ④ 功耗：同一负载下的功耗曲线（时间×功耗积分）
```

```
判断题模板："CPU A 比 B 快多少？"
  → 先问：什么负载？单核还是全核？功耗预算多少？散热如何？
  → 再答：给出场景化结论，而不是单一百分比
```

> 🎯 核心方法论：**性能是一个函数，不是一维数字**——CPU 性能 = f(负载, 核数利用, 功耗预算, 存储层次, 软件优化)。评测的最大错误是拿一个数字当真理。

## 6. 2025-2026 旗舰实测一览

数据来源：各厂商发布与第三方实测（检索于 2026-08，均为量级数据）。

| 产品 | 核/线程 | 频率 | 缓存 | TDP | 定位 |
|------|:---:|:---:|:---:|:---:|------|
| Ryzen 9 9950X | 16C/32T | 4.3/5.7GHz | L3 64MB | 170W | 桌面旗舰 |
| Ryzen 9 9950X3D | 16C/32T | 4.3/5.7GHz | **L3 192MB** | 170W | 游戏+生产力 |
| EPYC 9965 (Turin) | **192C/384T** | 2.6/3.7GHz | L3 384MB | 500W | 服务器王者 |
| EPYC 9755 | 128C/256T | 2.7/4.1GHz | **L3 512MB** | 500W | 大缓存服务器 |
| Core Ultra 9 285K | 24C/24T | 3.7/5.7GHz | L2+L3 39MB+ | 250W | 桌面（8P+16E） |
| Core Ultra 9 275HX | 24C | — | — | 55W | 移动旗舰 |
| Apple M4 Max | 16C | ~4.5GHz | — | ~50-80W | 效率旗舰 |
| 天玑 9400 (X925) | 8C | ~3.6GHz | — | 手机级 | 移动性能 |

```
三个关键观察（2025）：
  ① 服务器核数战：Turin 192 核 vs Diamond Rapids 传闻 192-256 核
  ② 缓存军备：X3D 192MB L3 / EPYC 512MB L3 —— 缓存=服务器新武器
  ③ 效率碾压：M4 Max 用 1/3 功耗达到 x86 旗舰级多核性能
```

## 7. 小结

| 问题 | 答案 |
|------|------|
| 单线程性能公式？ | IPC × 频率（核数只影响多线程） |
| TDP 是什么？ | 散热设计值，不是功耗上限（PPT 才是） |
| 权威基准？ | SPEC CPU 2017（厂商 IPC 声明都源于它） |
| 读规格看什么？ | 全核睿频、内存通道、缓存层次、指令集 |
| 评测铁律？ | 场景化对比 + 功耗对齐，别信单一数字 |
