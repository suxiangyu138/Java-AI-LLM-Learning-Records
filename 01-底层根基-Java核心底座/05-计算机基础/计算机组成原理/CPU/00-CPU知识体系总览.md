## 3. 学习路线推荐

**路线 A：建立整体认知（半天）**
01 → 06。理解 CPU 的组成与"怎么衡量 CPU 好坏"——适合选购、面试基础、后端性能调优前导。

**路线 B：体系结构系统学习（2-3 天，推荐）**
01 → 02 → 03 → 04。这条线回答"CPU 内部如何让一条指令变快、让许多指令并行"：从流水线到乱序到现代核心解剖。**配合 `寄存器/` 与 `缓存与Cache/` 目录阅读**，形成完整底层认知闭环。

**路线 C：前沿实战（面向硬件/AI 从业者）**
路线 B + 05 + 07。聚焦 chiplet 制造经济学、AI 时代的 NPU 集成与 ISA 竞争——这是 2025-2026 行业叙事的核心。

> 💡 与知识库关系：03 模块与 `寄存器/05-重命名` 深度互补（重命名是 OoO 的前提）；04 模块的缓存数据与 `缓存与Cache/04` 呼应；07 模块衔接 03-AI 大模型层的硬件推理话题（NPU 是 AI 应用开发的底层底座）。

## 4. 核心概念速查

| 概念 | 一句话定义 | 关键事实（2025-2026） |
|------|-----------|---------------------|
| ISA | 指令集架构：软件可见的 CPU 契约 | x86 / ARM / RISC-V 三大阵营 |
| 微架构 | ISA 的具体硬件实现 | 同 ISA 不同代际的核心设计 |
| 流水线 | 指令分阶段重叠执行 | 现代核心 15-25 级 |
| 冒险 (Hazard) | 阻止流水线前进的冲突 | 结构/数据/控制三类 |
| 转发 (Forwarding) | 结果直送后续指令，免等写回 | 消除大部分 RAW |
| 分支预测 | 猜分支走向，错了回滚 | 现代预测器准确率 >95% |
| 超标量 | 每周期发射多条指令 | 宽度 6-10 条 |
| 乱序执行 | 无依赖的指令先执行 | 窗口 200-500 条 |
| SMT/超线程 | 一核两线程共享执行资源 | Diamond Rapids 竟弃用（2026） |
| Chiplet | 多芯粒封装成大芯片 | Zen 5 / Panther Lake 标配 |
| NPU | 神经网络加速单元 | Panther Lake 平台 180 TOPS |
| IPC | 每周期执行指令数 | Zen 5 较 Zen 4 +17%（云负载） |

> 🎯 **核心要点**：CPU 性能的全部秘密可压缩为一句话——**把一条指令的延迟压短（流水线），把多条指令的吞吐做大（超标量+乱序），再把猜错的代价降到最低（分支预测+回滚）**。所有架构创新都是这三件事的排列组合。
