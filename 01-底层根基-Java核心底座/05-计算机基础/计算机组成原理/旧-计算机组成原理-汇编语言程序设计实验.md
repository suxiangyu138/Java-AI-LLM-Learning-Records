# 汇编语言程序设计实验

## 课程概述
- **课程性质**：专业核心必修课（配套实验课）
- **适用专业**：计算机类各专业
- **开课学期**：与汇编语言理论课同步
- **考核方式**：实验报告 + 上机考核 + 综合设计

## 核心知识点

### 实验一：汇编环境搭建与第一个程序
- 汇编开发环境搭建
  - MASM32/NASM汇编器安装
  - 文本编辑器(VS Code/Notepad++) + 汇编器 + 链接器的工具链
- 汇编→链接→执行的完整流程
  - 汇编：masm hello.asm → hello.obj（将汇编源码翻译为目标文件）
  - 链接：link hello.obj → hello.exe（解析外部引用，生成可执行文件）
  - 执行与调试：运行exe或用Debug调试
- Debug调试器使用
  - R：查看/修改寄存器(如 R AX 1234)
  - D：查看内存内容(如 D DS:0)
  - E：修改内存(如 E DS:0 41)
  - U：反汇编(如 U CS:0)
  - T：单步执行(执行一条指令后显示寄存器状态)
  - G：运行到断点或程序结束
  - Q：退出Debug
- 第一个程序：Hello World
  - 数据段定义字符串（以'$'结尾，供INT 21H的09H号功能使用）
  - 代码段：MOV AH, 09H → LEA DX, msg → INT 21H → MOV AH, 4CH → INT 21H

### 实验二：顺序与分支程序设计
- 数据传送与算术运算
  - 简单计算器实现：从键盘输入两个一位十进制数 → 计算加减乘除 → 输出结果
  - 输入数字：INT 21H的01H号功能 → 字符→数字(SUB AL, 30H)
  - 多位运算：注意进位和借位(ADC/SBB)
  - 乘法结果存放：MUL → DX:AX（双字结果），8位乘→AX
  - 除法：DIV → AH=余数, AL=商(8位除)；DX=余数, AX=商(16位除)
- 分支结构实现
  - CMP指令 + 条件跳转实现 if-else
    - 等于：JE/JZ（ZF=1跳转）
    - 不等于：JNE/JNZ（ZF=0跳转）
    - 大于/小于：JG/JL（有符号），JA/JB（无符号），注意区分！
  - 实现分段函数：不同区间用不同的计算公式
  - 成绩等级判定：90-100→A, 80-89→B, 70-79→C, 60-69→D, <60→F

### 实验三：循环程序设计
- 单层循环
  - 计算 1+2+...+N：初始化CX=N, AX=0，循环体 ADD AX, CX, LOOP
  - LOOP指令：自动 CX=CX-1，CX≠0时跳转
- 嵌套循环
  - 输出九九乘法表：外循环控制乘数，内循环控制被乘数
  - 注意保存和恢复CX（PUSH CX / POP CX）
- 移位与乘除法
  - 左移 SHL：SHL AX, 1 等价于 AX*2（更快）
  - 右移 SHR：SHR AX, 1 等价于 AX/2（无符号）
  - 算术右移 SAR：SAR AX, 1 保留符号位
  - 移位实现乘以10：AX*10 = AX*8 + AX*2 = SHL AX,3 + SHL AX,1
- 数组处理
  - SI/DI变址寄存器遍历数组
  - 统计数组中的正数/负数/零个数
  - 求最大值/最小值/平均值
  - 大小写字母转换：大写→小写 ADD AL, 20H，小写→大写 SUB AL, 20H

### 实验四：子程序设计与堆栈
- 子程序定义与调用
  - PROC/ENDP 定义子程序
  - CALL 调用（将返回地址IP压栈）
  - RET 返回（从栈中弹出IP）
  - NEAR调用（段内） vs FAR调用（段间）
- 参数传递方式
  - 寄存器传参：调用前将参数放入约定寄存器(BX=数1, CX=数2)
  - 堆栈传参（标准方式）：
    - 调用前 PUSH参数（从右向左依次入栈）
    - CALL（自动压入返回地址）
    - 子程序内：PUSH BP → MOV BP, SP → 用 [BP+4] 访问第一个参数（跳过返回地址和保存的BP）
    - 返回前：MOV SP, BP → POP BP → RET N（N为参数字节数，调用者清理堆栈）
  - 返回值：通常放 AX（16位）或 DX:AX（32位）
- 现场保护与恢复
  - 子程序开始时PUSH将被修改的寄存器
  - 子程序结束前按相反顺序POP恢复
- 递归子程序
  - 阶乘 n! 递归实现：n==0或1→返回1，否则 n*(n-1)!
  - 每次递归调用在栈上建立新的栈帧
  - 注意递归深度限制（栈溢出）

### 实验五：数制转换与输入输出
- 键盘输入数字串
  - INT 21H 的 0AH 号功能：缓冲输入字符串
  - 输入缓冲格式：首字节=缓冲大小，次字节=实际输入字符数，后续=输入的字符
  - 字符串→二进制数的转换：逐位乘10累加
- 数字输出
  - 二进制数→十进制字符串：反复除10取余（倒序排列即为各位数字）
  - 二进制→十六进制输出：每4位一组查表("0123456789ABCDEF")
- 综合：输入十进制数→内部二进制计算→输出十进制/二进制/十六进制结果

### 实验六：字符串与数组操作
- 串操作指令
  - MOVSB/MOVSW：字节/字串传送，配合REP重复前缀
  - 方向标志DF：CLD(DF=0，SI/DI递增)、STD(DF=1，SI/DI递减)
  - STOSB：将AL存入ES:DI，DI自动调整 → 用于填充
  - LODSB：从DS:SI读取到AL，SI自动调整 → 用于遍历
  - SCASB：AL与ES:DI比较，影响标志位 → 用于查找
  - CMPSB：DS:SI与ES:DI比较 → 用于字符串比较
- 经典算法实现
  - 排序：冒泡排序（内外双层循环，CMP+交换）
  - 查找：线性查找、二分查找（有序数组）
  - 字符串加密/解密：XOR每个字符与密钥

### 实验七：图形与声音编程
- BIOS中断 INT 10H 显示功能
  - AH=00H：设置显示模式(AL=03H→80×25文本模式，AL=13H→320×200 256色图形模式)
  - AH=02H：设置光标位置(DH=行，DL=列，BH=页号)
  - AH=0CH：写像素点(AL=颜色，CX=列，DX=行)
- 简单图形绘制
  - 画直线（Bresenham算法汇编实现）
  - 画矩形/填充矩形
  - 实现简单的动画（画→延时→擦除→移动位置→再画）

### 实验八：综合设计
- 学生成绩管理系统
  - 功能：录入成绩→计算平均分/最高分/最低分→排序→按学号查询→显示成绩单
  - 数据结构：用结构体数组存储学生信息（姓名+学号+各科成绩）
  - 模块化：录入模块、计算模块、排序模块、查询模块、显示模块
  - 菜单驱动的主程序
- 或汇编实现的计算器
  - 支持 +、-、×、÷ 四则运算
  - 支持多位整数运算
  - 带括号的表达式求值（中缀→后缀→计算）

## 重点难点
- **重点**：寄存器操作、寻址方式的灵活运用、子程序堆栈传参、循环与分支的汇编实现
- **难点**：堆栈帧的正确建立和参数访问、递归实现的栈管理、多模块程序的链接
