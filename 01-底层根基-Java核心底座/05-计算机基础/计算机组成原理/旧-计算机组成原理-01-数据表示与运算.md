# 数据表示与运算

## 📌 课程定位
理解数据在计算机中如何存储和运算是计组的第一步——从二进制补码到IEEE754浮点数，这些知识直接影响你写代码时对溢出、精度、类型转换的判断力。

## 🎯 核心章节

### 1. 数制与编码
- **进位计数制**：二进制、八进制、十六进制间的转换（手算 + 计算器验证）
- **BCD码**：8421码（每4位表示一个十进制数字）、余三码
- **ASCII码**：7位编码，常见字符的码值（'0'=48, 'A'=65, 'a'=97）
- **汉字编码**：GB2312、GBK、Unicode、UTF-8（变长编码——1~4字节）

### 2. 定点数表示
- **无符号数**：直接二进制值，n位表示范围 0 ~ 2ⁿ-1
- **有符号数（⭐ 核心）**：
  - **原码**：最高位符号位（0正1负），有两个0（+0和-0）
  - **反码**：正数反码=原码，负数反码=符号位不变其余取反
  - **补码（现代计算机统一使用）**：正数补码=原码，负数补码=反码+1
    - 补码优势：0唯一、减法变加法（[A-B]补 = [A]补 + [-B]补）
    - 8位补码范围：-128 ~ 127
  - **移码**：补码符号位取反，用于浮点数阶码
- **算数移位 vs 逻辑移位**：有符号数右移是算术移位（补符号位），无符号是逻辑移位（补0）

### 3. 定点数运算
- **加法器**：半加器(无进位输入)、全加器(有进位输入)、串行进位加法器、超前进位加法器
- **补码加减**：全部按加法做，符号位参与运算，超过位宽的进位丢弃
- **溢出判断**：
  - 单符号位法：正+正=负 或 负+负=正则溢出
  - 双符号位法：00正常，01上溢，10下溢
- **乘法**：原码一位乘（Booth算法了解）

### 4. 浮点数（⭐ IEEE754 必须掌握）
- **表示格式**：N = (-1)^S × 1.M × 2^(E-bias)
  - float(32位)：1b符号 + 8b阶码(bias=127) + 23b尾数
  - double(64位)：1b符号 + 11b阶码(bias=1023) + 52b尾数
- **规格化数**：默认尾数最高位为1（隐含）→ 提高一位精度
- **特殊值**：0(全0)、∞(阶码全1尾数全0)、NaN(阶码全1尾数非0)
- **浮点加减步骤**：对阶(小向大看齐) → 尾数加减 → 规格化 → 舍入 → 判溢出

## ✅ 学习建议
- 反复练习原码/反码/补码转换，直到不假思索
- 理解 float 为什么 0.1+0.2≠0.3：十进制小数转二进制可能是无限循环小数
- 用C语言验证：`printf("%d", (char)128)` 看补码的溢出效果
