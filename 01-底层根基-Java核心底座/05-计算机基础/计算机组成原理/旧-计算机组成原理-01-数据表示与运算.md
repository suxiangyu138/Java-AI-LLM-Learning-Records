## 1. 数制与编码

### 1.1 进位计数制

| 进制 | 基数 | 表示 | 转换要点 |
|------|:----:|------|----------|
| 二进制 | 2 | `0b` | 每 3 位 → 八进制，每 4 位 → 十六进制 |
| 八进制 | 8 | `0` | — |
| 十进制 | 10 | — | 整数除 2 取余，小数乘 2 取整 |
| 十六进制 | 16 | `0x` | — |

### 1.2 编码

| 编码 | 说明 | 关键值 |
|------|------|--------|
| **BCD 码（8421 码）** | 每 4 位表示一个十进制数字 | — |
| 余三码 | 8421 码 + 3 | — |
| **ASCII 码** | 7 位编码 | `'0'`=48, `'A'`=65, `'a'`=97 |
| **汉字编码** | GB2312 → GBK → Unicode → UTF-8（变长 1-4 字节） |

## 2. 定点数表示

### 2.1 四种表示法

| 表示法 | 正数 | 负数 | 特点 |
|--------|------|------|------|
| **原码** | 符号位 0 + 数值 | 符号位 1 + 数值 | 有两个 0（+0 和 -0） |
| **反码** | = 原码 | 符号位不变，其余取反 | — |
| **补码（⭐ 现代计算机统一使用）** | = 原码 | 反码 + 1 | 0 唯一、减法变加法 `[A-B]补 = [A]补 + [-B]补` |
| **移码** | 补码符号位取反 | — | 用于浮点数阶码 |

### 2.2 补码核心认知

| 特性 | 说明 |
|------|------|
| 8 位范围 | `-128 ~ 127` |
| 核心优势 | 0 唯一、减法变加法 |
| 算术移位 | 右移补符号位（算术右移）；左移补 0 |
| 逻辑移位 | 无符号数，右移补 0 |

## 3. 定点数运算

### 3.1 加法器

| 类型 | 特点 |
|------|------|
| 半加器 | 无进位输入，2 输入 2 输出 |
| 全加器 | 有进位输入，3 输入 2 输出 |
| 串行进位加法器 | 结构简单，速度慢 |
| 超前进位加法器 | 并行进位，速度快 |

### 3.2 溢出判断

| 方法 | 判断规则 |
|------|----------|
| **单符号位法** | 正+正=负 或 负+负=正 → 溢出 |
| **双符号位法** | 00=正常，01=上溢，10=下溢 |

### 3.3 乘法

> 原码一位乘（Booth 算法了解即可）

## 4. 浮点数（IEEE754）

### 4.1 表示格式

$$N = (-1)^S \times 1.M \times 2^{E - bias}$$

| 类型 | 位数 | 符号 S | 阶码 E | 尾数 M | bias |
|------|:----:|:------:|:------:|:------:|:----:|
| **float** | 32 | 1 位 | 8 位 | 23 位 | 127 |
| **double** | 64 | 1 位 | 11 位 | 52 位 | 1023 |

### 4.2 特殊值

| 值 | 阶码 E | 尾数 M |
|----|:------:|:------:|
| 0 | 全 0 | 全 0 |
| ∞ | 全 1 | 全 0 |
| NaN | 全 1 | 非 0 |

### 4.3 浮点加减步骤

```text
对阶（小阶向大阶看齐）→ 尾数加减 → 规格化 → 舍入 → 判溢出
```

### 4.4 精度陷阱

> `0.1 + 0.2 ≠ 0.3`：十进制小数转二进制可能是无限循环小数，导致精度丢失。
