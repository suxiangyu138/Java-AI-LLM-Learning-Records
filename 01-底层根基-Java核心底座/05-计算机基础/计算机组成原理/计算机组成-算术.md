## 一、计算机算术基础：二进制与数据表示

### 1.1 二进制：计算机算术的底层语言

计算机的所有数据存储与运算均基于二进制（0 和 1）。Java 的基本数据类型均基于二进制存储：

| 类型 | 位数 | 取值范围 |
|------|------|---------|
| `byte` | 8 | [-128, 127] |
| `short` | 16 | [-32768, 32767] |
| `int` | 32 | [-2³¹, 2³¹-1] |
| `long` | 64 | [-2⁶³, 2⁶³-1] |
| `float` | 32（IEEE 754） | 单精度浮点数 |
| `double` | 64（IEEE 754） | 双精度浮点数 |

### 1.2 原码、反码、补码

计算机中整数以**补码**形式存储，目的是统一加减法的硬件实现：

| 编码 | 正数 | 负数 |
|------|------|------|
| **原码** | 符号位 0 + 数值位 | 符号位 1 + 数值位 |
| **反码** | 与原码相同 | 符号位不变，其余位取反 |
| **补码** | 与原码相同 | 反码 + 1 |

> **实战意义**：补码机制直接导致整数溢出。`int` 最大值 2147483647 加 1 后变为 -2147483648（最小值），这是金融、计数场景中必须规避的风险。

### 1.3 进制转换

```java
// Java 进制转换常用方法
Integer.toBinaryString(int i)       // 十进制转二进制
Integer.toHexString(int i)          // 十进制转十六进制
Integer.parseInt(String s, 2)      // 二进制转十进制
Integer.parseInt(String s, 16)     // 十六进制转十进制
```

## 二、整数运算

### 2.1 整数运算的底层实现

Java 中的整数运算基于二进制补码，由 CPU 的 ALU 直接执行。

| 运算 | 底层实现 | 效率 |
|------|---------|------|
| 加减法 | 二进制按位运算，减法用补码加法实现 | 最快 |
| 乘法 | 移位 + 加法 | 中等 |
| 除法 | 移位 + 减法，涉及取整与余数 | 最慢 |

> **优化技巧**：高并发场景中优先用加减法、位运算替代乘除法。

### 2.2 整数溢出

整数溢出是运算结果超出数据类型取值范围，导致数值错误。

```java
int max = Integer.MAX_VALUE; // 2147483647
int res = max + 1;           // 结果 -2147483648（溢出）
```

**防护方案**：

| 方案 | 实现 |
|------|------|
| 升级数据类型 | `int` 改用 `long`，`long` 改用 `BigInteger` |
| 安全运算方法 | `Math.addExact()`、`Math.multiplyExact()` 溢出时抛异常 |
| 分布式场景 | Redis 原子计数器（INCR/INCRBY） |

### 2.3 取模运算

取模运算应用广泛：哈希分片、奇偶判断、循环计数。

> **优化**：模数为 2 的幂时，位运算 `n & (mod-1)` 效率更高，如 `n % 8` 等价于 `n & 7`。

## 三、浮点数运算

### 3.1 IEEE 754 标准

Java 的 `float`、`double` 遵循 IEEE 754 标准：

| 类型 | 符号位 | 指数位 | 尾数位 |
|------|--------|--------|--------|
| `float` | 1 位 | 8 位 | 23 位 |
| `double` | 1 位 | 11 位 | 52 位 |

**精度丢失原因**：
1. 十进制小数无法精确转为二进制小数（如 0.1 是无限循环二进制小数）
2. 尾数位长度有限，只能存储近似值

```java
double a = 0.1 + 0.2; // 结果 0.30000000000000004，非 0.3
```

### 3.2 Java 后端精度解决方案

#### 3.2.1 BigDecimal：高精度十进制运算

```java
// 禁止用 double 构造，必须用 String
BigDecimal num1 = new BigDecimal("0.1");
BigDecimal num2 = new BigDecimal("0.2");
BigDecimal sum = num1.add(num2); // 精确结果 0.3
```

#### 3.2.2 整数化运算

将小数转为整数（如金额单位"元"改"分"），用 `long` 存储，无精度丢失。

```java
// 10.50 元 → 1050 分（long）
long amount = 1050;
```

#### 3.2.3 浮点数比较规范

```java
double a = 0.1 + 0.2;
double b = 0.3;
boolean eq = Math.abs(a - b) < 1e-6; // 误差小于 1e-6 视为相等
```

## 四、位运算

### 4.1 位运算核心类型

| 运算 | 规则 | 用途 |
|------|------|------|
| 按位与（`&`） | 同位均为 1 则为 1 | 清零、取指定位、判断奇偶 |
| 按位或（`|`） | 同位有 1 则为 1 | 设置指定位、权限组合 |
| 按位异或（`^`） | 同位不同则为 1 | 交换变量、加密、去重 |
| 按位取反（`~`） | 0 变 1，1 变 0 | 取反码、生成掩码 |
| 左移（`<<`） | 低位补 0，等价于 ×2ⁿ | 快速乘法 |
| 右移（`>>` / `>>>`） | 带符号/无符号右移 | 快速除法、数据分片 |

### 4.2 位运算后端实战应用

#### 4.2.1 权限管理

```java
int READ = 1 << 0;   // 0001
int WRITE = 1 << 1;  // 0010
int perm = READ | WRITE;          // 赋予读写权限
boolean hasWrite = (perm & WRITE) != 0; // 判断权限
```

#### 4.2.2 高性能分片与计数

```java
// Redis 槽位计算
int slot = crc16(key) & 16383;

// 判断 2 的幂
boolean isPowerOfTwo = n & (n - 1) == 0;

// 线程池核心数
int corePoolSize = Runtime.getRuntime().availableProcessors() << 1;
```

## 五、高精度运算

### 5.1 BigInteger：大整数运算

`BigInteger` 底层基于 `int` 数组存储二进制数据，支持任意精度整数运算。

```java
BigInteger a = new BigInteger("12345678901234567890");
BigInteger b = new BigInteger("98765432109876543210");
BigInteger result = a.multiply(b);
```

**实战场景**：区块链交易计算、RSA 加密、超大数统计。

### 5.2 BigDecimal：金融场景必备

```java
BigDecimal price = new BigDecimal("99.99");
BigDecimal finalPrice = price.multiply(new BigDecimal("0.8"))
    .setScale(2, RoundingMode.HALF_UP); // 四舍五入保留两位小数
```

**最佳实践**：
1. 用 `String` 构造，禁止使用 `double`
2. 运算指定舍入模式，避免异常
3. 复用常量（`BigDecimal.ZERO`、`BigDecimal.ONE`）

## 六、并发算术

### 6.1 并发运算的线程安全问题

多线程下，普通整数运算 `count++` 分为"读-改-写"三步，非原子操作。

```java
private int count = 0;
public void inc() { count++; } // 线程不安全
```

### 6.2 原子类：无锁并发算术

| 类 | 特点 | 适用场景 |
|----|------|---------|
| `AtomicInteger` / `AtomicLong` | 基于 CAS 的原子运算 | 中等并发计数 |
| `LongAdder` | 分段 CAS，减少竞争 | 高并发计数（首选） |

```java
// 高并发计数
private LongAdder counter = new LongAdder();
public void add() { counter.increment(); }
public long get() { return counter.sum(); }
```

### 6.3 CAS 原理

Compare-And-Swap：内存值（V）、旧值（A）、新值（B），V == A 则更新为 B，否则重试。CPU 原语保证原子性。

## 七、分布式算术

### 7.1 Redis 原子计数器

Redis 单线程模型保证 `INCR`/`INCRBY` 原子性：

```java
jedis.incr("order_count"); // 分布式原子自增
```

### 7.2 分布式锁保证一致性

```java
RLock lock = redisson.getLock("stock");
lock.lock();
try {
    // 扣减库存逻辑
} finally {
    lock.unlock();
}
```

## 八、性能优化

### 8.1 运算类型优先级

```
位运算 > 整数运算 > 浮点数运算 > 高精度运算（BigDecimal/BigInteger）
```

### 8.2 避坑指南

1. 循环中避免频繁创建 `BigDecimal`，复用对象
2. 金融场景禁用 `float`/`double`，强制使用 `BigDecimal`
3. 整数运算用 `Math.addExact()` 等安全方法防溢出
4. 高并发计数优先 `LongAdder`，其次 `AtomicLong`

### 8.3 硬件优化

- 用 JNI 调用 CPU SIMD 指令，提升并行运算
- 选择高主频、大缓存 CPU，加速 ALU 运算
- 减少类型转换，降低 CPU 指令开销

## 九、总结

计算机算术是 Java 后端开发的底层基石，从二进制存储到分布式计算，从性能优化到线程安全，所有数值相关业务都依赖算术原理。

**核心学习路径**：
1. 掌握二进制、补码、基本运算原理
2. 熟练运用位运算、BigDecimal、原子类
3. 结合金融、高并发场景实战优化
4. 拓展分布式计算、密码学大数运算
