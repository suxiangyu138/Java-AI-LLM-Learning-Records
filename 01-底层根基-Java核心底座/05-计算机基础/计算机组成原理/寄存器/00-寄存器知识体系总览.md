**路线 A：快速建立概念（半天）**

## 4. 核心概念速查

| 概念 | 一句话定义 | 关键事实 |
|------|-----------|---------|
| 寄存器 (Register) | CPU 内部最快存储，1-2 周期访问 | 容量合计 <1KB，数量 16-32 个 |
| 寄存器堆 (Register File) | 全部寄存器构成的存储阵列 | 多端口：同周期 3 读 1 写是标配 |
| 架构寄存器 | ISA 定义、软件可见的寄存器 | 程序员眼里"寄存器就这些" |
| 物理寄存器 | 硬件实际存储，多于架构寄存器 | 支撑乱序执行与重命名 |
| 通用寄存器 (GPR) | 可存数据/地址的通用存储 | x86-64 16 个、ARM64 31 个、RISC-V 32 个 |
| 标志寄存器 | 记录运算结果的标志位 | x86 的 RFLAGS、ARM 的 NZCV |
| 调用约定 (ABI) | 参数/返回/保存者的寄存器分工协议 | 平台不同：SysV vs Windows |
| 寄存器重命名 | 把架构寄存器映射到物理寄存器 | 消除 WAR/WAW 假依赖 |
| 溢出 (Spilling) | 寄存器不够时变量被迫存内存 | 编译器性能的最大损失点之一 |
| xsave | 保存全部扩展状态的指令 | 处理 AVX-512/AMX 的大状态（8KB+） |
| APX | Intel 的 32 个 GPR 扩展 | R16-R31，Diamond Rapids 首发 |
| ZA 矩阵寄存器 | ARM SME 的二维矩阵状态 | 规模 = SVL² 位，最大 16KB+ |

> 🎯 **核心要点**：寄存器是"编译器控制的缓存"——它的访问延迟（~1 周期）与 Cache 的硬件自动管理形成鲜明对比：**凡是能留在寄存器里的数据，永远不会被 Cache 驱逐、不需要寻址、不需要一致性**。理解寄存器，就理解了"为什么 CPU 设计的第一原则是尽量少碰内存"。
