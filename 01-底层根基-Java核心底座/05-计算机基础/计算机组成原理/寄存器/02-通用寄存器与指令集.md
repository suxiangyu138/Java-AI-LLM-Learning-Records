## 1. x86-64：16+2 个通用寄存器

### 1.1 十六个通用寄存器全表

| 64 位 | 低 32 位 | 低 16 位 | 低 8 位 | 传统用途（64 位模式下多为历史遗留） |
|-------|---------|---------|--------|--------------------------------|
| RAX | EAX | AX | AL/AH | 累加器、返回值 |
| RBX | EBX | BX | BL/BH | 基址（历史） |
| RCX | ECX | CX | CL/CH | 计数器、循环 |
| RDX | EDX | DX | DL/DH | 数据、除法余数 |
| RSI | ESI | SI | SIL | 源索引（字符串操作） |
| RDI | EDI | DI | DIL | 目的索引 |
| RBP | EBP | BP | BPL | 帧指针（栈帧基址） |
| RSP | ESP | SP | SPL | **栈指针（专用）** |
| R8-R15 | R8D-R15D | R8W-R15W | R8B-R15B | 新增通用寄存器 |

### 1.2 两个隐藏寄存器

| 寄存器 | 作用 | 特点 |
|--------|------|------|
| **RIP** | 指令指针（当前指令地址） | 无法直接读写；`call`/`jmp` 自动修改；支持 RIP 相对寻址 |
| **RFLAGS** | 标志寄存器 | 逐位含义见 [03-标志寄存器](03-标志寄存器与系统寄存器.md) |

### 1.3 编码规律

```text
REX 前缀：x86-64 新增 8 个寄存器（R8-R15），通过 REX.R 位扩展编码
REX2/EVEX：APX 再扩 16 个（R16-R31），用新前缀（见 08-前沿扩展）
8 位寄存器注意：AH/BH/CH/DH 与 SPL/BPL/SIL/DIL 编码重叠（REX 位区分）
```

## 2. ARM64：31 个通用寄存器

### 2.1 全表（X0-X30）

| 寄存器 | 别名 | 约定用途（AAPCS64） |
|--------|------|--------------------|
| X0-X7 | 参数寄存器 | 函数参数/返回值（X0） |
| X8 | 间接结果寄存器 | 返回大型结构体的指针 |
| X9-X15 | 临时寄存器 | 调用者保存 |
| X16 | IP0 | 内部调用暂存（PLT 跳板） |
| X17 | IP1 | 内部调用暂存 |
| X18 | 平台寄存器 | 平台保留（OS 专用） |
| X19-X28 | 被调用者保存 | 需保存/恢复 |
| X29 | FP | 帧指针 |
| X30 | LR | 返回地址 |
| X31 | SP / XZR | **栈指针或零寄存器（编码共享）** |

### 2.2 两个精妙设计

```
① X31 双身份：同一编码，按指令上下文解释为 SP 或 XZR
   → 零寄存器：mov xzr, x5 恒为 0，无需专门"清零"指令
   → 用 ZR 参与运算自动丢弃结果（如 cmp 就是 sub 的丢结果版）

② 无字节/半字通用寄存器：ARM64 最小通用寄存器是 W（32 位）
   → 消灭"部分写"的架构复杂度（见第 4 节）
```

### 2.3 其他寄存器组（简述，详细见 03）

| 组 | 内容 |
|----|------|
| V0-V31 | SIMD/FP 寄存器（128 位，可作 B/H/S/D/Q 视图） |
| Z0-Z31 + P0-P15 | SVE 可伸缩向量 + 谓词寄存器（见 08） |
| ZA | SME 二维矩阵寄存器（见 08） |
| PSTATE | 标志：NZCV、DAIF（中断掩码）等 |

## 3. RISC-V：32 个通用寄存器

### 3.1 全表（x0-x31 与 ABI 名字）

| 编号 | ABI 名 | 用途 | 保存者 |
|:---:|--------|------|:---:|
| x0 | **zero** | 硬连线 0（可写但写无效） | — |
| x1 | ra | 返回地址 | 调用者 |
| x2 | sp | 栈指针 | 被调用者 |
| x3 | gp | 全局指针 | — |
| x4 | tp | 线程指针 | — |
| x5-7 | t0-t2 | 临时 | 调用者 |
| x8 | s0/fp | 保存/帧指针 | 被调用者 |
| x9 | s1 | 保存 | 被调用者 |
| x10-17 | a0-a7 | 参数/返回值 | 调用者 |
| x18-27 | s2-s11 | 保存 | 被调用者 |
| x28-31 | t3-t6 | 临时 | 调用者 |

### 3.2 设计特点

```
① x0 硬连线零：任何向 x0 的写入被忽略
   → 省去专用比较指令：sub 结果写 x0 即"比较"
② 无 x86 式"部分写"陷阱：RV64 最小操作单元是 32 位（但符号扩展规则清晰）
③ 寄存器数量与编号即"规范"：32 个 × 5 位编码，指令格式统一简单
```

### 3.3 向量与浮点扩展（简述）

| 扩展 | 寄存器 | 说明 |
|------|--------|------|
| F/D/Q（浮点） | f0-f31 | 32/64/128 位浮点 |
| V（向量，2019 冻结、2021 批准） | v0-v31 + vl/vtype | 长度可伸缩，见 08 |

## 4. 子寄存器与部分写问题

### 4.1 问题定义

x86 允许写 32 位 EAX 而不动 RAX 高 32 位？——**不**，x86-64 规定：写 EAX 会自动清零 RAX 高 32 位；但写 8 位 AL 只改低 8 位，高 56 位保留。

```asm
mov eax, 1          ; RAX = 0x0000000000000001（高 32 位自动清零）
mov al, 0x2          ; RAX = 0x0000000000000002（高 56 位保留）
xor ah, ah          ; 部分写，产生"寄存器融合依赖"
```

### 4.2 硬件为何痛恨部分写

```
部分写 → 寄存器重命名单元无法把新旧值区分开
      → 需插入"合并微操作"（merge uop）把旧高位与新低位拼起来
      → 现代 CPU 干脆：写 AL 后本寄存器后续读要等合并 → 性能惩罚

经典案例：strlen 用 al 循环 vs 用 rax 一次处理 8 字节 → 5-10 倍差距
```

### 4.3 各 ISA 的解法对比

| ISA | 部分写行为 | 代价 |
|-----|-----------|------|
| x86-64 | 32→64 清零；8/16→64 保留 | 8/16 位写有重命名惩罚 |
| ARM64 | 无 8/16 位通用寄存器（W 最小 32 位） | 无部分写问题 |
| RISC-V | RV64 用 32 位作最小操作，符号扩展规则清晰 | 轻微（SEXT 规则统一） |

> 💡 教训：性能敏感代码避免 x86 的 8/16 位子寄存器写；这正是"64 位代码比 32 位代码快"的隐藏原因之一。

## 5. 三种 ISA 的寄存器设计哲学

| 维度 | x86-64 | ARM64 | RISC-V |
|------|--------|-------|--------|
| GPR 数量 | 16（APX 后 32） | 31（+SP/XZR） | 32（含 x0） |
| 最小 GPR | 8 位（部分写） | 32 位 | 32 位 |
| 特殊设计 | RIP/RFLAGS/段 | XZR 双身份、LR | x0 硬连线零、gp/tp |
| 编码 | 3-4 位（历史）→REX 扩展 | 5 位 | 5 位 |
| 哲学 | 兼容性包袱最重 | 干净 + 实用折中 | 极简主义、零包袱 |
| 保存者约定 | 见 04 模块 | 见 04 模块 | 见 04 模块 |

> 🎯 **核心要点**：寄存器命名不是随意的——每个"专用名"背后都是一段架构历史（x86 的累加器/计数器来自 8086）或一个工程决策（ARM 的 XZR、RISC-V 的 x0 都是为了省指令）。读懂命名，就读懂了 ISA 的基因。

## 6. 寄存器速查卡与记忆法

### 6.1 三大 ISA 一表流

| 功能 | x86-64 | ARM64 | RISC-V |
|------|--------|-------|--------|
| 通用寄存器 | RAX-R15（16 个） | X0-X30（31 个） | x0-x31（32 个） |
| 零寄存器 | 无（xor rax,rax） | XZR（与 SP 共用编码） | x0（硬连线） |
| 栈指针 | RSP | SP（X31） | x2 (sp) |
| 返回地址 | 栈（call 压栈） | X30 (LR) | x1 (ra) |
| 帧指针 | RBP（可省略） | X29 (FP) | x8 (s0/fp) |
| 参数（前 N 个） | RDI RSI RDX RCX R8 R9 | X0-X7 | x10-x17 (a0-a7) |
| 返回值 | RAX | X0 | x10 (a0) |
| 标志 | RFLAGS | PSTATE.NZCV | 无标志（比较指令写 x0） |
| 向量 | XMM0-31（AVX-512） | V0-V31 / Z0-Z31 (SVE) | f0-f31 / v0-v31 (V) |

### 6.2 记忆口诀

```text
x86-64 参数顺序："D D C C 8 9" —— RDI RSI RDX RCX R8 R9（首字母记忆：DDCC89）

RISC-V 保存者划分：
  t = temporary（调用者保存，临时工）
  s = saved（被调用者保存，正式工要"收拾好再走"）
  a = argument（参数，天生调用者保存）

ARM64 高编号 = 被调用者保存：X19-X28 与 RISC-V 的 s 寄存器一一对应，
  跨 ISA 迁移时只要记住"大编号+长生命"规律
```

### 6.3 速查用法

```text
① 读反汇编时：看到 push rbx/r12 → 函数要改被调用者保存寄存器
② 看崩溃栈：先查 RIP（崩在哪）→ RDI/RSI（是什么参数）→ RAX（返回值）
③ 写内联汇编/FFI：先查本模块表确认参数寄存器顺序（04 模块有 ABI 细则）
④ 面试问答：被问"x86 有哪些寄存器"——按 16 GPR + RIP/RFLAGS + 段 +
   CR/MSR 分层回答，展示体系化记忆
```

> 💡 学习建议：不要死记硬背所有寄存器——先记住**参数/返回/保存者三类**（ABI 高频），再记**栈指针/帧指针/返回地址**（调用链），最后按需查表（控制寄存器等系统寄存器见 03 模块）。
