## 1. 标志寄存器：条件码与状态位

### 1.1 为什么需要标志位

```
cmp rax, rbx       ; 减法但不写回结果，只更新标志
jne .label         ; 读标志决定跳转
```

分支指令不直接比较数值，而是读**比较指令留下的标志**——这样 `cmp` 只需一个周期，且结果可被多个分支复用。标志寄存器是"指令间通信的隐式通道"。

### 1.2 标志的分类

| 类别 | 功能 | 例子 |
|------|------|------|
| 条件码（算术标志） | 记录上次运算结果的性质 | ZF/SF/CF/OF（x86）、NZCV（ARM） |
| 控制位 | 配置 CPU 行为 | DF（方向）、IF（中断使能） |
| 系统位 | 描述 CPU 模式/状态 | VM、IOPL、NT |

## 2. x86 的 RFLAGS 逐位解读

### 2.1 位图（64 位 RFLAGS，低 32 位使用）

| 位 | 名称 | 含义 | 典型用途 |
|:---:|------|------|---------|
| 0 | CF | 进位标志：无符号溢出/借位 | `jc/jb`、多精度加法 |
| 2 | PF | 奇偶标志：低 8 位 1 的个数为偶 | 串行通信校验 |
| 4 | AF | 辅助进位：BCD 运算 | 十进制调整指令 |
| 6 | ZF | 零标志：结果为零 | `jz/je` |
| 7 | SF | 符号标志：结果为负 | `js` |
| 8 | TF | 陷阱标志：单步调试 | 调试器单步 |
| 9 | IF | 中断使能标志 | `sti/cli` |
| 10 | DF | 方向标志：字符串指令方向 | `cld/std` |
| 11 | OF | 溢出标志：有符号溢出 | `jo/jno` |
| 12-13 | IOPL | I/O 特权级 | 权限控制 |
| 14 | NT | 嵌套任务 | 任务切换 |
| 16 | RF | 恢复标志 | 调试异常 |
| 17 | VM | 虚拟 8086 模式 | 兼容运行 |
| 18 | AC | 对齐检查 | 数据对齐检测 |
| 19 | VIF | 虚拟中断 | 虚拟化 |
| 20 | VIP | 虚拟中断挂起 | 虚拟化 |
| 21 | ID | CPUID 支持位 | CPUID 检测 |

### 2.2 实战：无符号 vs 有符号的比较

```asm
cmp rax, rbx
; 无符号比较读 CF/ZF：jb（below）→ CF=1；je → ZF=1
; 有符号比较读 SF/OF：jl（less）→ SF≠OF
; 一个 cmp，两套条件码并行计算，支撑两种语义 —— 无需额外指令
```

> 💡 记忆技巧：无符号看 **CF**（进位），有符号看 **OF**（溢出）+ **SF**（符号）。`jb` 是 below（无符号），`jl` 是 less（有符号）——b=无符号、l=有符号。

### 2.3 陷阱：标志的隐式修改

```asm
add rax, rbx        ; 修改 CF/ZF/SF/OF...
lea rcx, [rax+rbx]  ; 不修改任何标志！（地址计算指令）
mov rdx, rax        ; 不修改标志
inc rax             ; 修改 CF（不同于 add 1？不，inc 不修改 CF）
```

编译器优化常用 LEA 做加法，正是因为它不污染标志位。

## 3. ARM 的 PSTATE 与 NZCV

### 3.1 PSTATE：处理器状态

ARM64 没有独立"标志寄存器"，标志是 **PSTATE**（处理器状态）中的字段：

| 字段 | 含义 |
|------|------|
| N/Z/C/V | 负数/零/进位/溢出（与 x86 的 SF/ZF/CF/OF 对应） |
| DAIF | 调试/SError/IRQ/FIQ 中断掩码 |
| EL | 当前异常级别（0-3） |
| SPsel | 当前使用哪个栈指针 |
| PAN/UAO 等 | 内存访问控制 |

### 3.2 与 x86 的关键差异

```
x86：add 总是更新标志；lea/mov 不更新
ARM64：默认 add/cmp 等指令更新标志（S 后缀可选项较少）
     条件码通过条件后缀执行：csel（条件选择）、ccmp（条件比较）
     分支指令使用标志：b.eq / b.ne / b.lt...

差异核心：ARM 把"比较+选择"合并成一条指令（csel），
        x86 用"比较+分支"两条指令 —— ARM 对分支惩罚更敏感（流水线更浅）
```

## 4. 控制寄存器与系统寄存器

### 4.1 x86 控制寄存器（CR0-CR8）

| 寄存器 | 关键位 | 职责 |
|--------|--------|------|
| CR0 | PE（保护模式）、PG（分页）、WP（写保护） | 全局模式控制 |
| CR2 | 页错误线性地址 | 缺页处理（只读） |
| CR3 | 页表基址 | 地址空间切换（进程切换核心动作之一） |
| CR4 | PAE、PGE、OSFXSR、SMEP/SMAP 等 | 功能开关（20+ 位） |
| CR8 | 任务优先级 | 中断优先级控制 |

```asm
; 切换地址空间（内核路径核心操作）
mov cr3, rax        ; 只需一条指令，但后续所有 TLB 条目失效（PCID 可部分保留）
```

### 4.2 ARM64 的系统寄存器

```
TTBR0_EL1/TTBR1_EL1：用户/内核页表基址（地址空间按高低位分区，无需切换）
SCTLR_EL1：系统控制（类似 CR0）
MAIR_EL1：内存属性映射（缓存策略配置）
VBAR_EL1：异常向量表基址
```

> 💡 设计对比：x86 用 CR3 切换整个地址空间；ARM64 用 TTBR0/1 双基址实现"用户/内核永不切换页表"——这是 ARM64 系统调用比 x86 快的重要原因之一。

## 5. MSR：模型专属寄存器

### 5.1 什么是 MSR

MSR（Model Specific Register）是 x86 的"杂项寄存器池"，用 `rdmsr/wrmsr` 访问，`ecx` 指定编号。数百个寄存器涵盖性能、电源、虚拟化、安全等领域。

### 5.2 常见 MSR

| MSR | 编号示例 | 用途 |
|-----|---------|------|
| IA32_EFER | 0xC0000080 | LME（长模式使能）、NXE（不可执行页）、SCE（syscall） |
| IA32_TSC | 0x10 | 时间戳计数器（rdtsc 读取） |
| IA32_PAT | 0x277 | 页属性表（缓存策略：WB/WC/UC） |
| IA32_APIC_BASE | 0x1B | APIC 基址与使能 |
| IA32_MISC_ENABLE | 0x1A0 | 各种功能开关 |
| IA32_PERF_CTR 系列 | 0xC1+ | 硬件性能计数器 |

```text
访问权限：仅 CPL0（内核态）可写；部分可读
虚拟化：VM-exit 时虚拟化宿主需保存/恢复一批 MSR（VMCS 自动或手动）
性能调优：perf 工具底层即读 PERF MSR + 固定计数器
```

## 6. 段寄存器与描述符表

### 6.1 段寄存器的历史与现状

| 段寄存器 | 32 位时代角色 | 64 位模式角色 |
|---------|--------------|--------------|
| CS | 代码段选择子 | 部分仍生效（RPL 决定 CPL 特权级） |
| SS | 栈段 | 语义保留但地址不参与计算 |
| DS/ES | 数据段 | 基本废弃 |
| FS/GS | 通用段 | **仍活跃：TLS、per-CPU 数据** |
| TR | 任务寄存器 | 指向 TSS（内核栈切换用） |

```
64 位模式：段基址全部视为 0（除 FS/GS 可加载基址）
FS/GS 用途：Linux 的 FS 存 TLS（线程局部存储）、GS 存 per-CPU 数据
         → 访问 per-CPU 变量只需一条指令：mov rax, gs:[offset]
```

### 6.2 描述符表寄存器

| 寄存器 | 内容 | 作用 |
|--------|------|------|
| GDTR | GDT 基址+界限 | 全局描述符表 |
| IDTR | IDT 基址+界限 | 中断描述符表 |
| LDTR | LDT 选择子 | 局部描述符表（现代 OS 基本不用） |
| TR | TSS 选择子 | 任务状态段（内核栈地址、IO 位图） |

> ⚠️ 面试常考：中断发生时 CPU 如何找到内核栈？→ 从 TSS 读 RSP0 字段（内核栈指针）——TR/TSS 在现代 OS 的**唯一**主要用途。

## 7. 小结

| 问题 | 答案 |
|------|------|
| 标志寄存器干什么？ | 记录运算性质，供分支/条件指令使用（隐式通信通道） |
| CF 与 OF 的区别？ | CF=无符号溢出，OF=有符号溢出 |
| ARM 的对应物？ | PSTATE.NZCV（+DAIF 中断掩码） |
| 系统寄存器谁在用？ | 内核/虚拟化：CR3 换地址空间、EFER 开长模式 |
| MSR 是什么？ | x86 杂项功能寄存器池，内核用 rdmsr/wrmsr 访问 |
| 段寄存器还活着吗？ | FS/GS 活跃（TLS/per-CPU），TR 指向 TSS |
