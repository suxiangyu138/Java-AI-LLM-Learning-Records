# 总线与 I/O 系统

## 📌 课程定位
I/O是计算机与外界交互的窗口。理解总线、中断、DMA，是后端开发中理解网络I/O模型（阻塞/非阻塞/多路复用/异步）的底层基础。

## 🎯 核心章节

### 1. 总线
- **总线分类**：片内总线、系统总线（数据+地址+控制）、通信总线（USB/PCIe）
- **总线仲裁**：多个主设备竞争总线使用权
  - 菊花链式、计数器定时查询、独立请求
- **总线标准**：PCI、PCIe（点对点串行）、USB

### 2. I/O 接口
- **功能**：数据缓冲、信号转换、设备选择、中断管理
- **I/O 端口 vs 内存映射I/O**：独立编址(x86的IN/OUT指令) vs 统一编址(ARM把外设寄存器映射到内存地址空间)

### 3. I/O 控制方式（⭐ 四种方式递进）
- **程序查询**：CPU不断轮询设备状态——CPU全程参与，效率最低
- **程序中断**：设备就绪时发中断信号，CPU响应后处理——CPU无需等待
  - 中断向量表、中断优先级、中断屏蔽
- **DMA（直接存储器访问）**：DMA控制器接管总线，数据直接在设备和内存间传输，CPU只参与开始和结束——适合大批量数据传输
- **通道/I/O处理器**：专用的I/O处理芯片，独立执行通道程序

### 4. 中断系统
- **中断类型**：内中断（异常、陷阱、故障）vs 外中断（I/O中断、时钟中断）
- **中断响应过程**：关中断→保存断点(PC+PSW)→取中断向量→执行中断服务程序→恢复现场→开中断→返回
- **中断嵌套**：高优先级中断可打断低优先级——通过中断屏蔽实现

## ✅ 学习建议
- 理解四种I/O方式递进关系，这和网络编程的BIO/NIO/AIO演化逻辑一致
- 中断是操作系统实现抢占式调度的硬件基础
