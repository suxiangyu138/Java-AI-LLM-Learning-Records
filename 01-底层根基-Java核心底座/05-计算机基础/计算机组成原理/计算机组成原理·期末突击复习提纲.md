## 一、计算机系统概述

### 1.1 计算机的 5 大基本部件

- **运算器、控制器、存储器、输入设备、输出设备**
- 运算器 + 控制器 = **CPU**

### 1.2 冯·诺依曼计算机思想

| 核心要点 | 说明 |
|---------|------|
| 采用二进制 | 数据和指令均用二进制表示 |
| 存储程序 | 程序和数据预先存放在存储器中 |
| 程序控制 | 自动从存储器中读取指令并执行 |
| 五大部件 | 运算器、控制器、存储器、输入设备、输出设备 |

### 1.3 计算机层次

```
微程序层 → 机器语言层 → 操作系统层 → 汇编语言层 → 高级语言层
```

## 二、数制与编码（必考）

### 2.1 进制转换

- 二 ↔ 十 ↔ 十六进制互转
- 小数：乘 2 取整

### 2.2 机器数表示

| 编码 | 正数 | 负数 |
|------|------|------|
| **原码** | 符号位 0 + 绝对值 | 符号位 1 + 绝对值 |
| **反码** | 与原码相同 | 符号位不变，其余取反 |
| **补码** | 与原码相同 | 反码 + 1 |
| **移码** | 补码符号位取反 | 多用于浮点数阶码 |

### 2.3 定点与浮点

| 类型 | 表示 |
|------|------|
| **定点数** | 整数 / 小数 |
| **浮点数** | N = M × R^E（M 为尾数，E 为阶码） |

**IEEE 754 浮点数（必考）**：

| 位数 | 符号位 | 阶码 | 尾数 |
|------|--------|------|------|
| 32 位 | 1 位 | 8 位 | 23 位 |
| 64 位 | 1 位 | 11 位 | 52 位 |

> 阶码用移码，尾数隐藏最高位 1。

## 三、运算方法与运算器

### 3.1 补码加减法

```
[A+B]补 = [A]补 + [B]补
[A-B]补 = [A]补 + [-B]补
```

### 3.2 溢出判断

| 双符号位 | 含义 |
|---------|------|
| 00 | 正数 |
| 11 | 负数 |
| 01 | 上溢 |
| 10 | 下溢 |

### 3.3 ALU 的功能

- 算术运算 + 逻辑运算
- 核心：加法器（串行/并行进位）

### 3.4 乘法、除法

| 算法 | 说明 |
|------|------|
| **原码乘** | 符号位单独处理 |
| **补码乘** | Booth 算法（考试常考） |

## 四、存储器系统（大题重点）

### 4.1 层次结构

```
寄存器 → Cache → 主存 → 辅存
（速度快、容量小） → （速度慢、容量大）
```

### 4.2 主存分类

| 类型 | 特点 |
|------|------|
| **RAM** | 随机存取，断电丢失 |
| **ROM** | 只读，不丢失 |

### 4.3 存储器扩展

| 扩展方式 | 说明 |
|---------|------|
| **位扩展** | 位数不够 |
| **字扩展** | 字数不够 |

> 考试常给芯片，让你画连接图、算地址线。

### 4.4 Cache 原理

| 要点 | 说明 |
|------|------|
| **目的** | 解决 CPU 与主存速度不匹配 |
| **依据** | 局部性原理（时间局部性、空间局部性） |

### 4.5 Cache 三种映射

| 映射方式 | 特点 |
|---------|------|
| **直接映射** | 简单，冲突率高 |
| **全相联映射** | 冲突少，成本高 |
| **组相联映射** | 折中（最常用） |

### 4.6 替换算法

- FIFO
- **LRU（最常考）**
- 随机

## 五、指令系统

### 5.1 指令格式

```
操作码 OP + 地址码 A
```

地址类型：零地址、一地址、二地址、三地址

### 5.2 寻址方式（必考）

| 寻址方式 | 说明 |
|---------|------|
| **立即寻址** | A 就是数 |
| **直接寻址** | A 是地址 |
| **间接寻址** | A 是地址的地址 |
| **寄存器寻址** | 操作数在寄存器中 |
| **寄存器间接寻址** | 寄存器存放地址 |
| **变址/基址/相对寻址** | 地址偏移计算 |

### 5.3 CISC & RISC

| 特性 | CISC | RISC |
|------|------|------|
| 指令 | 复杂指令 | 精简指令 |
| 实现 | 微程序实现 | 硬布线 |
| 特点 | 功能强，速度慢 | 流水线高效，寄存器多 |

### 6.1 CPU 基本组成

- 运算器
- 控制器

### 6.2 指令执行过程

```
取指 → 分析 → 执行
```

| 方式 | 特点 |

### 7.1 5 段经典流水线

```
IF → ID → EX → MEM → WB
```

### 7.2 三种冲突

| 冲突类型 | 说明 |
|---------|------|
| **结构冲突** | 硬件资源竞争 |

## 八、总线与输入输出

### 8.1 总线分类

| 类型 | 说明 |
|------|------|
| 片内总线 | CPU 内部 |
| 系统总线 | 数据、地址、控制 |
| I/O 总线 | 连接外设 |

### 8.2 总线仲裁

| 方式 | 说明 |
|------|------|
| **集中式** | 链式查询、计数器、独立请求 |
| **分布式** | 各设备自行仲裁 |

### 8.3 I/O 控制方式

| 方式 | 特点 | CPU 利用率 |
|------|------|-----------|
| **程序查询** | CPU 轮询 | 极低 |
| **程序中断** | 中断驱动 | 中等 |
| **DMA** | 直接内存访问 | 高 |
| **通道** | 独立 I/O 处理器 | 最高 |

### 8.4 中断过程

```
中断请求 → 判优 → 响应 → 保护现场 → 中断服务 → 恢复现场 → 返回
```

### 8.5 DMA

- 直接内存访问，不占 CPU
- 常用于：磁盘、显卡等高速设备
