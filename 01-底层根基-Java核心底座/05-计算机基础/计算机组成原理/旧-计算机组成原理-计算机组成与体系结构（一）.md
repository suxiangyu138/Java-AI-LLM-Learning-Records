# 计算机组成与体系结构（一）

## 课程概述
- **课程性质**：专业核心必修课
- **适用专业**：计算机类各专业
- **开课学期**：大二下学期或大三上学期
- **考核方式**：考试（闭卷）+ 实验 + 平时成绩

## 课程目标
1. 理解计算机硬件系统的基本组成和工作原理
2. 掌握数据在计算机中的表示和运算方法
3. 理解CPU的数据通路和控制器设计
4. 掌握指令系统的设计原理
5. 理解存储层次结构和I/O系统

## 核心知识点

### 第一章：计算机系统概论
- 计算机系统的层次结构（微程序级→机器语言级→操作系统级→汇编语言级→高级语言级）
- 冯·诺依曼计算机的特点：五大部件、存储程序、指令顺序执行
- 计算机的性能指标：主频、CPI、MIPS、FLOPS
- CPU执行时间 = 指令数 × CPI × 时钟周期

### 第二章：数据的表示与运算
- 定点数的表示：原码、反码、补码、移码
- 补码加减运算及溢出判断（双符号位法、单符号位法）
- 原码/补码一位乘法（Booth算法）
- 原码/补码除法（恢复余数法、不恢复余数法）
- 浮点数表示（IEEE 754标准）：
  - 单精度(32位)：1位符号 + 8位阶码(偏置127) + 23位尾数
  - 双精度(64位)：1位符号 + 11位阶码(偏置1023) + 52位尾数
  - 规格化、溢出、特殊值（无穷大、NaN）
- 浮点数加减运算步骤：对阶→尾数运算→规格化→舍入→溢出判断
- ALU（算术逻辑单元）的基本结构

### 第三章：存储系统
- 存储器的分类与层次结构
- SRAM（六管静态存储单元）vs DRAM（单管+电容，需刷新）
- 主存与CPU的连接（地址线、数据线、控制线）
- 双口RAM与多模块存储器（交叉编址提高带宽）
- Cache（高速缓冲存储器）：
  - 程序访问的局部性原理
  - Cache与主存的映射方式：
    - 直接映射：Cache行号 = 主存块号 mod Cache行数
    - 全相联映射：任意主存块放任意Cache行
    - 组相联映射：Cache行号 = 主存块号 mod 组数（组内全相联）
  - Cache写策略：写回法(Write Back) vs 写穿法(Write Through)
  - Cache替换算法：LRU、FIFO、随机
- 虚拟存储器（下一章展开）

### 第四章：指令系统
- 指令格式：操作码(OP) + 地址码(A)
- 按操作数个数分类：零地址、一地址、二地址、三地址指令
- 操作码扩展技术（定长操作码 vs 扩展操作码）
- 寻址方式：
  - 立即寻址：操作数在指令中
  - 直接寻址：EA = A
  - 间接寻址：EA = (A)
  - 寄存器寻址：EA = Ri
  - 寄存器间接寻址：EA = (Ri)
  - 变址寻址：EA = (IX) + A
  - 基址寻址：EA = (BR) + A
  - 相对寻址：EA = (PC) + A
  - 堆栈寻址

### 第五章：中央处理器（CPU）
- CPU的功能与基本结构（ALU、寄存器组、控制器、内部总线）
- 数据通路：运算器与寄存器的连接
- 指令周期（取指→间址→执行→中断）
- 时序系统：机器周期、时钟周期
- 微操作序列分析
- 控制器设计方法：
  - 硬布线控制器（组合逻辑实现）
  - 微程序控制器（微指令、微操作实现）
- 指令流水线（Pipelining）：
  - 五级流水线：取指IF→译码ID→执行EX→访存MEM→写回WB
  - 流水线冒险：结构冒险、数据冒险（前推/旁路解决）、控制冒险（分支预测）
  - 流水线性能计算

### 第六章：总线
- 总线的基本概念与分类
- 总线仲裁：集中仲裁（链式查询、计数器定时查询、独立请求）
- 总线通信控制：同步通信、异步通信（不互锁、半互锁、全互锁）

### 第七章：输入输出系统
- I/O接口的功能与基本结构
- I/O端口及其编址（统一编址 vs 独立编址）
- 程序查询方式（CPU轮询）
- 程序中断方式：
  - 中断请求→中断判优→中断响应→中断服务→中断返回
  - 中断向量表
  - 多重中断
- DMA方式（直接存储器访问）：
  - DMA传送的三种方式：停止CPU访问、周期挪用、交替访问
  - DMA传送过程

## 重点难点
- **重点**：数据表示（浮点数）、Cache映射方式、指令寻址方式、指令流水线、中断与DMA
- **难点**：浮点数规格化、组相联Cache、流水线冒险与解决、DMA与中断的区别

## 学习方法与建议
1. 与数字逻辑课程紧密关联，理解电路到系统级的设计思路
2. 多看CPU架构图，建立从指令到执行的完整通路理解
3. 结合考研408真题练习
4. 关注RISC-V等现代指令集资料
