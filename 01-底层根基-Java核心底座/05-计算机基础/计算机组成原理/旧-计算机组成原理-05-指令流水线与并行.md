# 指令流水线与并行处理

## 📌 课程定位
现代CPU的性能靠的是各种并行技术——流水线、超标量、SIMD、多核。理解这些是写出高性能代码、进行性能调优的理论根基。

## 🎯 核心章节

### 1. 指令流水线进阶
- **流水线性能公式**：吞吐率 = 1 / max(各阶段时间)（受最慢阶段制约）
- **超标量（Superscalar）**：同时发射多条指令到不同功能单元——IPC>1
- **超流水线**：进一步细分流水级数，提高时钟频率
- **动态调度**：Tomasulo算法——寄存器重命名+保留站，允许乱序执行但顺序提交
- **分支预测**：
  - 静态预测：永远不跳转 / 永远跳转
  - 动态预测：1位/2位饱和计数器、基于历史的分支预测

### 2. SIMD（单指令多数据）
- **思想**：一条指令同时操作多个数据
- **Intel实现**：MMX → SSE(128位) → AVX(256位) → AVX-512(512位)
- **应用场景**：向量运算、图像处理、矩阵乘法（AI推理加速）
- **编程接口**：编译器自动向量化、intrinsics函数、OpenMP

### 3. 多核与多处理器
- **多核处理器**：一个芯片上集成多个CPU核心——共享L3 Cache和内存
- **多处理器（SMP）**：多个CPU芯片通过总线连接——NUMA架构
- **Cache一致性（⭐ 难点）**：
  - **MESI协议**：Modified(已修改)、Exclusive(独占)、Shared(共享)、Invalid(无效)
  - 写无效 vs 写更新策略
- **内存屏障（Memory Barrier）**：阻止编译器/CPU的指令重排——并发编程的基础

### 4. GPU 与异构计算
- **CPU vs GPU 架构差异**：CPU少量强核控制复杂，GPU大量弱核适合数据并行
- **CUDA编程模型**：Grid→Block→Thread，SIMT执行模型
- **AI训练为什么用GPU**：矩阵乘法的天然并行性——上千核同时计算
