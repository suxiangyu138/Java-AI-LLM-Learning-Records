# CPU 架构与指令系统

## 📌 课程定位
理解CPU如何执行指令，是理解程序性能的根本。从冯诺依曼结构到流水线，从CISC到RISC——这些都是后端性能优化和架构设计的底层理论。

## 🎯 核心章节

### 1. 冯·诺依曼结构
- **五大部件**：运算器、控制器、存储器、输入设备、输出设备
- **核心思想**：存储程序（指令和数据同等存放在存储器中）
- **冯诺依曼瓶颈**：CPU和内存间的单一总线限制了吞吐量（CPU快而内存慢）

### 2. CPU 核心部件
- **运算器（ALU）**：执行算术/逻辑运算、移位操作
- **控制器（CU）**：取指令 → 译码 → 执行 → 访存 → 写回
- **寄存器组（⭐ 了解关键寄存器）**：
  - 通用寄存器：EAX, EBX, ECX, EDX（x86）
  - **PC（程序计数器）**：存放下一条指令的地址
  - **IR（指令寄存器）**：存放当前正在执行的指令
  - **SP（栈指针）**：指向栈顶
  - **PSW/FLAGS（状态寄存器）**：ZF(零标志)、CF(进位)、OF(溢出)、SF(符号)

### 3. 指令系统
- **指令格式**：操作码(OP) + 地址码(A)（零地址/一地址/二地址/三地址指令）
- **寻址方式（⭐ 重点）**：
  - 立即寻址：操作数在指令中 → `MOV AX, 5`
  - 直接寻址：指令中给出有效地址 → `MOV AX, [1000H]`
  - 间接寻址：指令中给出寄存器的地址，寄存器里才是操作数地址
  - 寄存器寻址：操作数在寄存器中
  - 基址+变址+偏移（复杂的x86寻址模式）
- **CISC vs RISC**：
  | CISC（x86） | RISC（ARM/MIPS/RISC-V） |
  |------------|------------------------|
  | 指令复杂、变长 | 指令简单、定长 |
  | 一条指令做多件事 | 一条指令做一件事 |
  | 微程序控制 | 硬布线控制 |
  | 编译器容易 | 编译器需要做更多优化 |

### 4. 指令执行过程
- **取指周期**：PC→MAR→存储器→MDR→IR，PC+1
- **间址周期**：取操作数有效地址
- **执行周期**：ALU运算
- **中断周期**：保存断点、关中断、转入中断服务程序

### 5. 指令流水线（⭐ 现代CPU核心）
- **五级流水**：取指(IF) → 译码(ID) → 执行(EX) → 访存(MEM) → 写回(WB)
- **流水线冒险（Hazards）**：
  - **结构冒险**：硬件资源冲突（同一周期IF和MEM都要访问内存）
  - **数据冒险**：后一条指令依赖前一条的结果（RAW、WAR、WAW）
    - 解决方法：旁路（Forwarding）、流水线停顿（Stall）
  - **控制冒险**：分支指令导致预取的指令失效
    - 解决方法：分支预测（静态/动态）、延迟分支
- **流水线性能指标**：吞吐率、加速比、效率
