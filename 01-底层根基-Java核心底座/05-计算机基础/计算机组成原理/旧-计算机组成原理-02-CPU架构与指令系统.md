## 1. 冯·诺依曼结构

### 1.1 五大部件

```text
输入设备 → 存储器 ←→ 运算器
              ↕
           控制器
              ↕
          输出设备
```

| 部件 | 功能 |
|------|------|
| 运算器 | 算术/逻辑运算 |
| 控制器 | 取指令 → 译码 → 控制执行 |
| 存储器 | 存储指令和数据 |
| 输入/输出设备 | 人机交互 |

### 1.2 核心思想与瓶颈

| 概念 | 说明 |
|------|------|
| **存储程序** | 指令和数据同等存放在存储器中 |
| **冯诺依曼瓶颈** | CPU 和内存间单一总线限制吞吐量（CPU 快、内存慢） |

## 2. CPU 核心部件

### 2.1 关键寄存器

| 寄存器 | 用途 | 说明 |
|--------|------|------|
| **PC**（程序计数器） | 存放下一条指令地址 | 自动 +1 |
| **IR**（指令寄存器） | 存放当前执行的指令 | — |
| **SP**（栈指针） | 指向栈顶 | — |
| **PSW / FLAGS**（状态寄存器） | ZF/CF/OF/SF 标志位 | 条件跳转依据 |
| EAX/EBX/ECX/EDX | 通用寄存器（x86） | — |

### 2.2 标志位速查

| 标志 | 含义 | 触发条件 |
|------|------|----------|
| **ZF** | 零标志 | 结果为 0 |
| **CF** | 进位标志 | 最高位进位/借位 |
| **OF** | 溢出标志 | 有符号数溢出 |
| **SF** | 符号标志 | 结果为负 |

## 3. 指令系统

### 3.1 指令格式

```text
操作码 (OP)  +  地址码 (A)
  │               │
  └── 做什么        └── 对谁做
```

| 类型 | 特点 | 示例 |
|------|------|------|
| 零地址指令 | 操作数隐含（如 `RET`） | 栈操作 |
| 一地址指令 | 一个操作数/目标 | `INC AX` |
| 二地址指令 | 源 + 目标 | `MOV AX, BX` |
| 三地址指令 | 两个源 + 一个目标 | RISC 常见 |

### 3.2 寻址方式（⭐ 重点）

| 寻址方式 | 说明 | 示例 |
|----------|------|------|
| **立即寻址** | 操作数在指令中 | `MOV AX, 5` |
| **直接寻址** | 指令给出有效地址 | `MOV AX, [1000H]` |
| **间接寻址** | 寄存器内存的是操作数地址 | `MOV AX, [BX]` |
| **寄存器寻址** | 操作数在寄存器中 | `MOV AX, BX` |
| 基址+变址+偏移 | x86 复杂寻址 | `MOV AX, [BX+SI+100]` |

### 3.3 CISC vs RISC

| 维度 | CISC（x86） | RISC（ARM/MIPS/RISC-V） |
|------|------------|------------------------|
| 指令格式 | 复杂、变长 | 简单、定长 |
| 指令功能 | 一条做多件事 | 一条做一件事 |
| 控制方式 | 微程序控制 | 硬布线控制 |
| 编译器负担 | 低 | 高（需更多优化） |
| 代表 | Intel/AMD | ARM、RISC-V |

## 4. 指令执行过程

### 4.1 四大周期

```text
取指周期：PC → MAR → 存储器 → MDR → IR，PC+1
间址周期：取操作数有效地址
执行周期：ALU 运算
中断周期：保存断点 → 关中断 → 转入中断服务程序
```

## 5. 指令流水线

### 5.1 五级流水

```text
IF（取指）→ ID（译码）→ EX（执行）→ MEM（访存）→ WB（写回）
```

### 5.2 流水线冒险（Hazards）

| 冒险类型 | 原因 | 解决方案 |
|----------|------|----------|
| **结构冒险** | 硬件资源冲突（同一周期 IF 和 MEM 都访问内存） | 分离指令/数据 Cache |
| **数据冒险** | 后一条指令依赖前一条结果（RAW/WAR/WAW） | 旁路（Forwarding）、流水线停顿（Stall） |
| **控制冒险** | 分支指令导致预取指令失效 | 分支预测（静态/动态）、延迟分支 |

### 5.3 性能指标

| 指标 | 公式 |
|------|------|
| 吞吐率 | 单位时间完成指令数 |
| 加速比 | 流水线时间 / 非流水线时间 |
| 效率 | 加速比 / 流水线段数 |
