# 计算机接口技术实验

## 课程概述
- **课程性质**：专业核心选修课（配套实验课）
- **适用专业**：计算机类各专业
- **实验环境**：微机原理实验箱（含8255/8253/8259/ADC/DAC等芯片） + PC
- **考核方式**：实验操作 + 实验报告 + 综合设计

## 核心知识点

### 实验一：I/O端口地址译码
- 实验目的
  - 理解I/O端口独立编址方式
  - 掌握地址译码电路的设计方法
- 核心原理
  - 8086/8088的I/O地址空间：16位地址→64K个I/O端口
  - 片选信号的产生：高位地址线→译码器→使能对应芯片
  - 3-8译码器（74LS138）：3位输入→8位输出（每次仅一位有效）
  - 与门/或门组合也可实现地址译码
- 实验内容
  - 用74LS138实现地址译码：A5/A6/A7→138输入，Y0-Y7→8个片选信号
  - 每个片选对应8个连续端口地址（A0-A3连到芯片内部）
  - 用万用表/逻辑笔测量译码输出端电平
  - 改变地址线输入，验证不同输出端被选中

### 实验二：8255A并行接口
- 8255A内部结构与工作方式
  - 3个8位I/O端口：PA口、PB口、PC口（可拆为PC上4位和PC下4位）
  - 方式0（基本I/O）：无条件输入输出，无联络信号，PA/PB/PC都可工作
  - 方式1（选通I/O）：有联络信号(STB/IBF/OBF/ACK/INTR)，仅PA/PB工作，PC用于联络
  - 方式2（双向I/O）：仅PA口支持，数据双向传输，PC作联络
  - 控制字寄存器：D7=1（方式选择）→ 方式选择控制字；D7=0 → PC位操作控制字
- 方式0实验
  - 初始化编程：向控制寄存器写入方式字（如 10000000B = PA口方式0输出，PB口方式0输入，PC口方式0输出）
  - PA口→8个LED灯（输出：写数据至PA口即可控制LED亮灭）
  - PB口→8个拨码开关（输入：读PB口数据即可获取开关状态）
  - 实验：读入开关状态，根据状态控制LED（如LED显示开关状态的二进制值）
- 方式1实验（选通I/O）
  - PA口作为输出口(OBF/ACK握手)
    - OBF(Output Buffer Full)：8255通知外设"数据已准备好"
    - ACK(Acknowledge)：外设通知8255"已取走数据"
  - PB口作为输入口(STB/IBF握手)
    - STB(Strobe)：外设通知8255"有新数据"
    - IBF(Input Buffer Full)：8255通知CPU"数据已锁存待读取"

### 实验三：七段数码管显示
- 数码管原理
  - 共阴极：所有LED阴极接地，段选高电平点亮
  - 共阳极：所有LED阳极接VCC，段选低电平点亮
  - 段码表：0-9和A-F对应的8位段码（DP/G/F/E/D/C/B/A）
- 静态显示
  - 每个数码管独占一个I/O口（如一个8255的PA口控制一个数码管）
  - 优点：亮度高，编程简单
  - 缺点：占用I/O资源多
- 动态扫描显示
  - 硬件：所有数码管段选并联→一个I/O口（段码口），位选各自独立→另一个I/O口（位选口）
  - 软件：轮流选通一位数码管→输出对应段码→延时1-2ms→切换到下一位
  - 扫描周期 < 20ms（利用视觉暂留效应，人眼看起来像同时亮）
  - 8255的PA口→段码，PB口→位选
  - 编程要点：定时器中断触发扫描，或主循环延时扫描

### 实验四：8253/8254定时器
- 8253内部结构与工作方式
  - 3个独立16位减1计数器（计数器0、计数器1、计数器2）
  - 每个计数器有：CLK(时钟输入)、GATE(门控)、OUT(输出)
  - 控制字格式：D7D6(选择计数器)、D5D4(读/写方式)、D3D2D1(工作方式)、D0(数制)
- 六种工作方式
  - 方式0：计数结束中断 — 写入初值→OUT变低→开始计数→计数到0→OUT变高
  - 方式1：可编程单稳 — GATE上升沿触发→OUT变低→计数→到0→OUT变高
  - 方式2：频率发生器(分频器) — 连续产生负脉冲，周期=初值×CLK周期
  - 方式3：方波发生器 — 连续方波：初值为偶数→对称方波；初值为奇数→(N+1)/2高+(N-1)/2低
  - 方式4：软件触发选通 — 写入初值后计数，到0产生一个负脉冲
  - 方式5：硬件触发选通 — GATE上升沿触发计数，到0产生一个负脉冲
- 实验内容
  - 方式3方波发生器：用示波器观察OUT端输出波形，验证频率
  - 级联实验：计数器0输出→计数器1时钟，实现大范围分频
  - 用8253产生1秒定时中断：1.19318MHz（PC机标准时钟）→分频得到指定频率
  - 用8253+8255实现可调频率的LED闪烁

### 实验五：中断系统与8259A
- 8259A可编程中断控制器
  - 功能：管理8级硬件中断（可级联到64级），优先级判决，向CPU发送中断请求
  - 8259A内部寄存器
    - IRR(中断请求寄存器)：记录正在请求的中断
    - ISR(服务中寄存器)：记录正在被服务的中断
    - IMR(中断屏蔽寄存器)：对应位=1屏蔽该中断
  - 初始化命令字(ICW)
    - ICW1：触发方式(边沿/电平)、单片/级联
    - ICW2：中断类型号基值(如IRQ0对应08H，则IRQ1=09H...)
    - ICW3：主片/从片标识（级联时使用）
    - ICW4：特殊全嵌套方式、自动/正常EOI
  - 操作命令字(OCW)
    - OCW1：设置IMR屏蔽字
    - OCW2：EOI命令（中断结束通知）和优先级设置
    - OCW3：读取IRR/ISR状态
- 中断处理程序编写
  - 保存中断向量：用INT 21H的35H号功能读取原向量并保存
  - 设置新中断向量：用INT 21H的25H号功能写入自定义中断服务程序地址
  - 中断服务程序(ISR)结构：
    ```
    保护现场(PUSH寄存器)
    STI（开中断，允许嵌套）
    ... 中断处理核心代码 ...
    CLI（关中断）
    发送EOI（向8259A的OCW2写入20H）
    恢复现场(POP寄存器)
    IRET（中断返回）
    ```
  - 恢复中断向量：程序退出前恢复原中断向量
- 实验内容
  - 用8253产生定时中断（IRQ0，中断号08H）
  - ISR中实现秒计数 + 更新LED数码管显示
  - 实现一个简易电子时钟

### 实验六：串行通信
- 8251A可编程串行通信接口
  - 发送器和接收器独立，全双工
  - 初始化顺序：模式字 → 命令字（必须先写模式字）
  - 模式字：波特率因子(×1/×16/×64)、字符长度(5-8位)、校验(奇/偶/无)、停止位(1/1.5/2)
  - 命令字：发送使能、接收使能、DTR/RTS、错误复位等
  - 状态字：TxRDY(发送就绪)、RxRDY(接收就绪)等，通过读状态口获取
- RS-232C标准
  - 逻辑电平：-12V=1(MARK)，+12V=0(SPACE)，需要MAX232芯片与TTL电平转换
  - DB9连接器引脚：TXD(3脚，发送)、RXD(2脚，接收)、GND(5脚)
  - 最简单的三线制连接：TXD→RXD，RXD→TXD，GND→GND
- 实验内容
  - 8251A初始化（9600bps, 8数据位, 无校验, 1停止位）
  - 查询方式收发：轮询状态字TxRDY/RxRDY位
  - 中断方式收发：利用8251A的TxRDY/RxRDY触发中断
  - 双机通信：两台实验箱通过RS-232交叉线连接，实现相互收发

### 实验七：A/D与D/A转换
- D/A转换（DAC0832）
  - 分辨率：8位（2^8=256个等级）
  - 输出形式：
    - 单极性：Vout = -Vref × (数字量/256)，范围 0 到 -Vref
    - 双极性：加运放电路实现 ±Vref 输出
  - 实验内容
    - 产生锯齿波：数字量从0→255→0循环输出，示波器观察
    - 产生方波：交替输出0和255
    - 产生正弦波：查表法输出预存的正弦波数字量
    - 调节频率：改变每次D/A转换的延时时间
- A/D转换（ADC0809）
  - 分辨率：8位，8通道模拟输入
  - 转换原理：逐次逼近型（SAR），8次比较完成一次转换
  - 启动转换：向START引脚发正脉冲
  - 转换结束：EOC引脚变高
  - 读取结果：OE引脚使能后读取数据线
  - 实验内容
    - 用电位器产生0-5V可调模拟电压→A/D转换→显示数字量
    - 实现简易数字电压表
    - 实现数据采集系统：定时采集→存储→分析

### 实验八：综合设计
- 多功能信号发生器
  - D/A输出波形选择（正弦波/方波/三角波/锯齿波）
  - 按键切换波形类型和频率
  - 数码管显示当前频率
- 简易数据采集与控制系统
  - ADC采集传感器数据（温度/光敏等）→ 处理 → 数码管显示
  - 根据采集值判断 → 控制设备（如超温报警→LED+蜂鸣器）
- 电子琴
  - 按键对应不同音符（不同频率方波驱动扬声器）
  - 用8253产生精确频率
  - 多个按键同时或先后按下的处理

## 重点难点
- **重点**：8255并行接口编程、8253定时器方式3、中断向量的正确设置、中断服务程序编写
- **难点**：8259A的初始化流程(ICW1-ICW4的顺序和含义)、中断服务程序与主程序的数据共享、硬件电路故障排查
