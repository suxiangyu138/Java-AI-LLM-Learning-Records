# 数字逻辑

## 课程概述
- **课程性质**：专业基础必修课
- **适用专业**：计算机类各专业
- **开课学期**：大一下学期或大二上学期
- **考核方式**：考试（闭卷）+ 实验 + 平时成绩

## 课程目标
1. 掌握数字逻辑电路的基本理论和分析方法
2. 理解布尔代数和逻辑函数化简
3. 掌握组合逻辑电路和时序逻辑电路的设计
4. 为后续计算机组成原理等课程打基础

## 核心知识点

### 第一章：数制与编码
- 数制转换（二进制、八进制、十六进制、十进制）
- 二进制算术运算（加减乘除）
- 常用编码：8421BCD码、余3码、格雷码
- ASCII码和奇偶校验码

### 第二章：布尔代数
- 基本逻辑运算：与(AND)、或(OR)、非(NOT)
- 复合逻辑运算：与非(NAND)、或非(NOR)、异或(XOR)、同或(XNOR)
- 布尔代数的基本定律：交换律、结合律、分配律、吸收律、反演律（德摩根定律）
- 逻辑函数的表示方法：真值表、逻辑表达式、卡诺图、逻辑图
- 最大项与最小项

### 第三章：逻辑门电路
- 基本逻辑门的符号和功能
- TTL与CMOS门电路的基本特性
- 三态门与漏极开路门
- 门电路的电气特性（电压、电流、扇入/扇出、传输延迟）

### 第四章：组合逻辑电路
- 组合逻辑电路的分析方法（由电路图→函数表达式→真值表→功能描述）
- 组合逻辑电路的设计方法（由功能描述→真值表→化简→电路图）
- 常用组合逻辑模块：
  - 编码器（8-3线编码器、优先编码器）
  - 译码器（3-8线译码器、七段显示译码器）
  - 数据选择器（多路复用器MUX）
  - 加法器（半加器、全加器、超前进位加法器）
  - 数值比较器

### 第五章：触发器
- 时序逻辑电路的基本概念（现态、次态、状态表、状态图）
- 基本RS触发器（或非门、与非门构成）
- 时钟触发器：
  - RS触发器
  - D触发器（数据锁存器）
  - JK触发器（功能最全）
  - T触发器（翻转功能）
- 触发器的触发方式：电平触发、边沿触发（上升沿/下降沿）
- 触发器的特性方程

### 第六章：时序逻辑电路
- 时序逻辑电路的分析方法（写驱动方程→状态方程→状态转换表→状态转换图→功能分析）
- 同步时序电路的设计方法
- 常用时序逻辑模块：
  - 寄存器：数码寄存器、移位寄存器（串入串出、串入并出、并入串出、并入并出）
  - 计数器：同步计数器、异步计数器、任意进制计数器
  - 顺序脉冲发生器

### 第七章：半导体存储器
- ROM（只读存储器）：掩膜ROM、PROM、EPROM、EEPROM
- RAM（随机存取存储器）：SRAM（六管静态）、DRAM（单管动态）
- 用ROM实现组合逻辑函数

### 第八章：脉冲波形的产生与整形
- 555定时器的结构与原理
- 用555实现单稳态触发器
- 用555实现多谐振荡器（方波发生器）
- 施密特触发器

## 重点难点
- **重点**：布尔代数与逻辑函数化简、组合逻辑电路设计、触发器特性方程、同步时序电路设计
- **难点**：时序逻辑电路的设计（特别是原始状态图→状态化简→状态编码→输出方程和驱动方程）

## 学习方法与建议
1. 多用卡诺图进行逻辑函数化简（5变量以内）
2. 组合逻辑电路：分析题按"电路→函数→真值表→功能"，设计题反推
3. 时序电路：熟练掌握状态图和状态表的转换
4. 动手做实验，在面包板或FPGA上验证电路
