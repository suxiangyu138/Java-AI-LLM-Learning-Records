## 1. 接口技术基础

### I/O 端口编址方式

| 方式 | 指令 | 特点 | 代表 |
|------|------|------|------|
| **独立编址**（I/O 映射） | `IN`/`OUT` | I/O 和内存地址空间分离 | x86 |
| **统一编址**（内存映射） | `MOV` | I/O 和内存统一编址 | ARM/RISC-V |

### I/O 接口功能

```text
数据缓冲 → 信号转换 → 电平匹配 → 时序控制 → 地址译码
```

## 2. 总线技术

### 系统总线

```text
地址总线 (AB) + 数据总线 (DB) + 控制总线 (CB)
```

### 总线操作周期

```text
总线请求 → 仲裁 → 寻址 → 数据传送 → 释放
```

| 通信方式 | 特点 |
|----------|------|
| **同步通信** | 统一时钟 |
| **异步通信** | 握手信号 |

| 总线类型 | 说明 |
|----------|------|
| ISA / PCI / PCIe | 系统总线标准 |
| **USB** | 分层结构，4 种传输类型（控制/批量/中断/等时） |

## 3. 中断系统

### 3.1 中断处理流程

```text
中断请求 → 中断判优 → 中断响应(INTR/INTA) → 保护断点
→ 中断服务 → 恢复 → 返回
```

### 3.2 中断向量表

| 属性 | 说明 |
|------|------|
| 起始地址 | 内存 `0000:0000` |
| 每个向量 | 4 字节（IP:CS） |
| 总数 | 256 个向量 |

### 3.3 8259A 可编程中断控制器（PIC）

| 特性 | 说明 |
|------|------|
| 输入 | 8 级中断 |
| 扩展 | 可级联 9 片（1 主 + 8 从）→ 64 级 |
| 寄存器 | IRR（请求）、ISR（服务中）、IMR（屏蔽） |
| 初始化 | ICW1-ICW4（初始化命令字） |
| 操作 | OCW1-OCW3（操作命令字） |

## 4. 并行接口

### 8255A 可编程并行接口

| 端口 | 宽度 | 说明 |
|------|:----:|------|
| PA | 8 位 | 端口 A |
| PB | 8 位 | 端口 B |
| PC | 8 位 | 端口 C（可拆为两个 4 位） |

### 工作方式

| 方式 | 说明 |
|:----:|------|
| 方式 0 | 基本 I/O |
| 方式 1 | 选通 I/O |
| 方式 2 | 双向（仅 PA） |

### 控制字

| D7 | 类型 | 用途 |
|:--:|------|------|
| 1 | 方式选择控制字 | 配置工作方式和端口方向 |
| 0 | PC 位操作控制字 | 对 PC 口某一位置位/复位 |

## 5. 定时器/计数器

### 8253/8254 核心参数

| 属性 | 说明 |
|------|------|
| 计数器数量 | 3 个独立 16 位计数器 |
| 六种工作方式 | 方式 0-5 |

### 六种工作方式

| 方式 | 名称 | 特点 |
|:----:|------|------|
| **0** | 计数结束中断 | 写入初值→输出低→计数→结束输出高 |
| **1** | 可编程单稳 | 门控触发 |
| **2** | 频率发生器（分频器） | ⭐ 计满自动重装 |
| **3** | 方波发生器 | ⭐ 对称/近似对称方波 |
| 4 | 软件触发选通 | — |
| 5 | 硬件触发选通 | — |

### PC 机中的应用

| 计数器 | 用途 |
|:------:|------|
| 计数器 0 | 日时钟中断（18.2Hz） |
| 计数器 1 | DRAM 刷新 |
| 计数器 2 | 扬声器 |

## 6. 串行通信

### 通信方式

| 方式 | 方向 |
|------|------|
| 单工 | 单向 |
| 半双工 | 双向但不同时 |
| 全双工 | 双向同时 |

### 异步串行帧格式

```text
起始位(1位0) + 数据位(5-8位) + 校验位(可选) + 停止位(1/1.5/2位1)
```

### RS-232C 标准

| 特性 | 说明 |
|------|------|
| 逻辑 1 | -12V |
| 逻辑 0 | +12V |
| 连接器 | DB9 |

## 7. DMA 控制器

### 8237A 参数

| 属性 | 说明 |
|------|------|
| 通道 | 4 个独立 DMA 通道 |
| 传送能力 | 64KB |

### DMA 传送模式

| 模式 | 说明 |
|------|------|
| 单字节 | 每次传送一个字节 |
| 块字节 | 连续传送直到完成 |
| 请求 | 根据外设请求 |
| 级联 | 多片 8237 级联 |

> DMA 优先级高于 CPU。

## 8. 模数/数模转换

### D/A 转换器

| 芯片 | 参数 |
|------|------|
| DAC0832 | 8 位，分辨率 = FS/256 |
| 输出形式 | 单极性 / 双极性 |

### A/D 转换器

| 类型 | 原理 |
|------|------|
| **逐次逼近型** | D/A → 比较器 → 逐次逼近寄存器（从 MSB 开始） |

| 芯片 | 参数 |
|------|------|
| ADC0809 | 8 位 8 通道 A/D |

| 关键参数 | 说明 |
|----------|------|
| 分辨率 | 位数 |
| 转换时间 | 一次转换耗时 |
| 精度 | 误差范围 |
