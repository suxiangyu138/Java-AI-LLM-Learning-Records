# 计算机接口技术

## 课程概述
- **课程性质**：专业核心选修课
- **适用专业**：计算机类各专业

## 核心知识点

### 第一章：接口技术基础
- I/O接口的功能：数据缓冲、信号转换、电平匹配、时序控制、地址译码
- I/O端口的编址方式：
  - 独立编址（I/O映射）：IN/OUT指令访问，x86采用
  - 统一编址（内存映射）：MOV指令访问，ARM/RISC-V采用
- I/O端口地址译码：用译码器（74LS138）+门电路产生片选信号

### 第二章：总线技术
- 系统总线结构：地址总线、数据总线、控制总线
- 总线操作周期：总线请求→仲裁→寻址→数据传送→释放
- 同步通信（统一时钟）与异步通信（握手信号）
- ISA/PCI/PCIe总线基本概念
- USB（通用串行总线）：分层结构、四种传输类型（控制/批量/中断/等时）

### 第三章：中断系统
- 中断处理流程：中断请求→中断判优→中断响应(INTR/INTA)→保护断点→中断服务→恢复→返回
- 中断向量表：从内存0000:0000开始，每个向量4字节(IP:CS)，共256个向量
- 8259A可编程中断控制器(PIC)：
  - 8级中断输入，可级联9片扩展到64级（1主+8从）
  - 寄存器：IRR(中断请求)、ISR(服务中)、IMR(屏蔽)
  - ICW1-ICW4（初始化命令字）+ OCW1-OCW3（操作命令字）

### 第四章：并行接口
- 8255A可编程并行接口芯片：
  - 3个8位端口（PA、PB、PC），PC可拆为两个4位
  - 三种工作方式：方式0（基本I/O）、方式1（选通I/O）、方式2（双向）
  - 控制字格式：方式选择控制字（D7=1）+ PC位操作控制字（D7=0）
- 并行打印机接口（Centronics标准）：数据线(Data1-8)+控制信号（STROBE/ACK/BUSY）

### 第五章：定时器/计数器
- 8253/8254可编程定时器/计数器：
  - 3个独立16位计数器（计数器0、1、2）
  - 6种工作方式：
    - 方式0：计数结束中断（写入初值→输出低→计数→结束时输出高）
    - 方式1：可编程单稳（门控触发）
    - 方式2：频率发生器（分频器，计满自动重装）
    - 方式3：方波发生器（对称或近似对称方波）
    - 方式4：软件触发选通
    - 方式5：硬件触发选通
  - 读写方式：锁存读/低字节/高字节/先低后高字
- PC机中的应用：计数器0→日时钟中断(18.2Hz)、计数器1→DRAM刷新、计数器2→扬声器

### 第六章：串行通信接口
- 并行通信 vs 串行通信
- 串行通信方式：单工、半双工、全双工
- 同步通信与异步通信
- 异步串行通信帧格式：起始位(1位0)+数据位(5-8位)+校验位(可选)+停止位(1/1.5/2位1)
- 8251A可编程串行接口芯片：发送器、接收器、模式字与命令字
- RS-232C标准：电气特性（-12V=逻辑1，+12V=逻辑0）、DB9连接器

### 第七章：DMA控制器
- DMA方式与程序控制/中断方式的效率对比
- 8237A DMA控制器：4个独立DMA通道、64KB传送能力
- DMA传送模式：单字节、块字节、请求、级联
- DMA与CPU的优先级（DMA优先于CPU）

### 第八章：模数/数模转换
- D/A转换器(数字→模拟)：
  - 工作原理：将数字量转换为成比例的模拟电压/电流
  - DAC0832：8位D/A，分辨率为FS/256
  - 输出形式：单极性/双极性
- A/D转换器(模拟→数字)：
  - 逐次逼近型原理：D/A→比较器→逐次逼近寄存器(从MSB开始)
  - ADC0809：8位8通道A/D
  - 主要参数：分辨率、转换时间、精度

## 重点难点
- **重点**：8255A并行接口、8253/8254定时器、中断系统、串行通信
- **难点**：可编程接口芯片的工作方式与初始化编程、中断向量的正确设置
