# 汇编语言程序设计

## 课程概述
- **课程性质**：专业核心必修课
- **适用专业**：计算机类各专业
- **教学平台**：通常基于x86（MASM/NASM）或MIPS/RISC-V

## 核心知识点

### 第一章：汇编语言基础
- 汇编语言与机器语言的对应关系
- 汇编程序的工作过程：汇编→链接→执行
- 80x86寄存器组（以x86为例）：
  - 通用寄存器：EAX(AX,AH,AL)、EBX、ECX、EDX
  - 变址寄存器：ESI（源变址）、EDI（目标变址）
  - 指针寄存器：EBP（基址指针）、ESP（堆栈指针）
  - 段寄存器：CS、DS、SS、ES
  - 指令指针：EIP
  - 标志寄存器(EFLAGS)：OF(溢出)、SF(符号)、ZF(零)、CF(进位)、PF(奇偶)、AF(辅助进位)

### 第二章：汇编语言程序结构
- 分段结构：数据段(.data)、代码段(.code)、堆栈段(.stack)
- 汇编语句格式：[标号:] 操作码 [操作数] [;注释]
- 伪指令（不产生机器码）：DB(字节)、DW(字)、DD(双字)、DUP(重复)、EQU(等值)、SEGMENT/ENDS、ASSUME

### 第三章：寻址方式
- 立即寻址：MOV AX, 1234H（操作数在指令中）
- 寄存器寻址：MOV AX, BX
- 直接寻址：MOV AX, [2000H]
- 寄存器间接寻址：MOV AX, [BX]
- 变址寻址：MOV AX, [SI+10H]
- 基址变址寻址：MOV AX, [BX+SI]

### 第四章：指令系统
- 数据传送指令：MOV、XCHG（交换）、PUSH/POP（堆栈）、LEA（取偏移地址）、XLA（查表）
- 算术运算指令：
  - ADD/ADC(带进位加)、SUB/SBB(带借位减)
  - MUL(无符号乘)、IMUL(有符号乘)
  - DIV(无符号除)、IDIV(有符号除)
  - INC/DEC(加1/减1)、NEG(取负)
  - CBW/CWD(字节扩展为字/字扩展为双字)
- 逻辑运算指令：AND、OR、XOR、NOT、TEST（与AND相同但不保存结果）
- 移位指令：SHL/SHR（逻辑左/右移）、SAL/SAR（算术左/右移）、ROL/ROR（循环左/右移）、RCL/RCR（带进位循环）
- 程序控制指令：
  - JMP（无条件跳转）
  - 条件跳转：JE/JZ(等/零)、JNE/JNZ、JG/JL(大小)、JA/JB(高于/低于)、JC/JNC(有/无进位)、JO/JNO(有/无溢出)
  - LOOP（循环，ECX-1→ECX，≠0则跳转）
  - CALL/RET（过程调用/返回）
- 串操作指令：MOVS(串传送)、STOS(串存储)、LODS(串读取)、CMPS(串比较)、SCAS(串扫描)、REP重复前缀
- 输入输出指令：IN/OUT

### 第五章：子程序设计
- 子程序定义：PROC/ENDP
- 参数传递方式：
  - 寄存器传参（快，但寄存器数量有限）
  - 堆栈传参（最常用，EBP+偏移访问参数）
  - 全局变量传参
- 保护现场与恢复现场（PUSH/POP关键寄存器）
- 递归子程序（堆栈帧的建立）

### 第六章：中断与DOS系统调用
- 中断的概念：INT n指令，中断向量表（内存最低1KB）
- BIOS中断调用：INT 10H（显示器）、INT 16H（键盘）
- DOS系统功能调用：INT 21H（AH=功能号）
  - AH=01H：键盘输入并回显
  - AH=02H：显示字符
  - AH=09H：显示字符串（以'$'结尾）
  - AH=0AH：键盘输入字符串
  - AH=4CH：程序结束返回DOS

### 第七章：宏汇编
- 宏定义：MACRO/ENDM
- 宏与子程序的区别：宏是代码展开（无调用开销但占空间），子程序是调用（省空间但开调用销）
- 重复汇编：REPT、IRP、IRPC

### 第八章：汇编与C语言的混合编程
- C中内联汇编（inline assembly）
- 汇编调用C函数（遵循C调用约定_cdecl：参数从右向左入栈，调用者清理堆栈）
- C调用汇编函数（EXTERN声明，C函数名在汇编中以下划线开头）

## 重点难点
- **重点**：寄存器结构、寻址方式、常用指令、子程序参数传递、DOS功能调用
- **难点**：堆栈帧的建立与参数访问、标志位对条件跳转的影响、混合编程的调用约定
