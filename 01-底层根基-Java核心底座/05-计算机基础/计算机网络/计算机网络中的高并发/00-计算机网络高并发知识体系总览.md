## 3. 学习路线推荐

### 路线一：入门（1-2 天）——建立全貌

- C10K 问题为什么存在（每连接线程的代价）

## 4. 核心概念速查

| 概念 | 一句话定义 | 关键要点 |
|------|-----------|---------|
| C10K | 1999-2001 年提出的"1 万并发连接"问题 | 线程模型 vs 事件驱动模型的分水岭 |
| 多路复用 | 一个线程同时监视多个 fd 的可读/可写事件 | select/poll/epoll/io_uring |
| epoll | Linux 2.6 的事件驱动复用器 | 红黑树 + 就绪链表，O(1) 通知 |
| LT / ET | 水平触发 vs 边缘触发 | ET 需一次性读完，否则丢事件 |
| Reactor | 就绪通知模式（事件循环） | Netty/Tomcat NIO/Redis 单线程模型 |
| Proactor | 完成通知模式（异步） | io_uring/AIO 的对应模型 |
| 零拷贝 | 数据不经过用户态缓冲区直达 | mmap/sendfile/transferTo |
| TIME_WAIT | 主动关闭方等待 2MSL | 高并发短连接下端口耗尽之源 |
| 队头阻塞 | 一个包丢失阻塞后续数据 | HTTP/2 over TCP 的痛，QUIC 的卖点 |
| QUIC | 基于 UDP 的可靠传输（RFC 9000） | 1-RTT/0-RTT、连接迁移、无队头阻塞 |
| keep-alive | 长连接复用（HTTP） | 减少握手与连接建立开销 |
| 负载均衡 | 把流量分发到多台服务器 | 四层（LVS）/七层（Nginx） |
| io_uring | Linux 5.1 的异步 I/O 框架 | SQ/CQ 环形队列，2026 数据库标配 |
