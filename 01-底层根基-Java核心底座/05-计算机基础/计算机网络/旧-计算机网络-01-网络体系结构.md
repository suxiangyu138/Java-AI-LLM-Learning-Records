# 网络体系结构

## 📌 课程定位
计算机网络体系结构是一切网络知识的框架。OSI七层和TCP/IP四层模型是理解网络分层设计思想的基石，面试和日常工作中最频繁被引用的模型。

## 🎯 核心章节

### 1. 计算机网络基础概念
- **计算机网络定义**：自主计算机通过通信设备和传输介质互联，按协议进行数据通信，实现资源共享
- **分类**：按范围(PAN/LAN/MAN/WAN)、按拓扑(星型/总线/环型/网状)、按传输技术(广播/点对点)
- **性能指标**：
  - **带宽**：信道最大数据传输速率（bps）
  - **吞吐量**：实际有效数据传输速率
  - **时延**：发送时延 + 传播时延 + 处理时延 + 排队时延
  - **时延带宽积**：管道中可容纳的比特数
  - **往返时间RTT**：数据从发送到收到确认的往返时间——TCP超时重传的关键参数
  - **利用率**：信道利用率不是越高越好——过高导致排队时延剧增

### 2. OSI 七层参考模型（理论标准）
```
7 应用层：为用户程序提供网络服务接口（HTTP, FTP, SMTP, DNS）
6 表示层：数据格式转换、加密解密、压缩
5 会话层：建立/管理/终止会话
4 传输层：端到端可靠/不可靠传输、差错控制、流量控制（TCP, UDP）
3 网络层：路由选择、拥塞控制、跨网络寻址（IP, ICMP, ARP）
2 数据链路层：相邻节点间可靠传输、成帧、差错检测（Ethernet, PPP）
1 物理层：定义接口的机械/电气/功能特性，在物理介质上传输比特
```
**口诀**：All People Seem To Need Data Processing（应用表示会话传输网络数据链路物理）

### 3. TCP/IP 四层模型（实际标准）
```
应用层  ← OSI 5-7层合并（HTTP, DNS, SMTP, FTP）
传输层  ← OSI 第4层（TCP, UDP）
网际层  ← OSI 第3层（IP, ICMP, ARP）
网络接口层 ← OSI 1-2层合并（Ethernet, PPP）
```

### 4. 五层参考模型（教学用，⭐ 按此学习）
```
应用层 → 传输层 → 网络层 → 数据链路层 → 物理层
```
这就是贯穿后续所有章节的分析框架——每层做什么、提供什么服务、有哪些协议。

### 5. 协议与服务的区别
- **协议是"水平"的**：同一层次间对等实体通信的规则（语法+语义+时序）
- **服务是"垂直"的**：本层为上层提供的功能，通过层间接口（SAP服务访问点）调用
- **协议数据单元（PDU）**：每层有自己的PDU——帧(链路层)、包/数据报(网络层)、段(传输层)、消息(应用层)

### 6. 封装与解封装（⭐ 核心理解）
```
发送方（自上而下封装）：
应用层数据 → [TCP头|数据] → [IP头|TCP头|数据] → [帧头|IP头|TCP头|数据|帧尾] → 比特流

接收方（自下而上解封装）：
比特流 → 剥帧头尾 → 剥IP头 → 剥TCP头 → 应用层数据
```
每一层只看和自己同层的头部，这就是分层设计的精髓——解耦。

## ✅ 学习建议
- 五层模型要能画出每一层及对应协议
- 数据封装过程是理解网络传输的核心——"像俄罗斯套娃"
- 面试高频：输入URL到页面显示的全过程（涉及所有层）
- 推荐教材：谢希仁《计算机网络》+ 《TCP/IP详解》卷一（Stevens经典）
