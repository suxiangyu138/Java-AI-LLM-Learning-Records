## 3. 学习路线推荐

### 路线一：入门（1-2 天）——协议骨架

01 → 02 → 05，重点掌握：

- TCP 头部与可靠字节流语义
- 三次握手为什么不是两次/四次
- 四次挥手与 TIME_WAIT 的意义

### 路线二：进阶（2-4 天）——机制与算法

03 → 04 → 06，重点掌握：

- 滑动窗口/流量控制与拥塞控制的区别
- 慢启动→拥塞避免→快速恢复的完整曲线
- CUBIC 与 BBR 的思路差异（丢包 vs 带宽测量）

### 路线三：专家（1 周+）——排障与前沿

07 → 08 + 前沿资料：

- [RFC 9293: TCP](https://www.rfc-editor.org/rfc/rfc9293)
- [draft-ietf-ccwg-bbr（BBR IETF 草案）](https://datatracker.ietf.org/doc/draft-ietf-ccwg-bbr/)
- [ISOC Pulse: IPv6 Reaches Majority（2026-04）](https://pulse.internetsociety.org/en/blog/2026/04/18-years-later-ipv6-reaches-majority/)

## 4. 核心概念速查

| 概念 | 一句话定义 | 关键要点 |
|------|-----------|---------|
| 可靠字节流 | TCP 把数据看作有序字节流，保证交付 | 序列号 + 确认 + 重传 |
| 三次握手 | 建立连接的三步交换 | SYN → SYN+ACK → ACK |
| 四次挥手 | 释放连接的四步交换 | FIN ×2 + ACK ×2（可合并） |
| TIME_WAIT | 主动关闭方等待 2MSL | 防旧报文串扰（正确性设计） |
| 滑动窗口 | 接收方通告的接收能力 | 流量控制（不占网络状态） |
| 拥塞控制 | 感知网络负载调整发送速率 | cwnd 与丢包/延迟信号 |
| 慢启动 | 指数增长探路 | 1 → 2 → 4 → 8 ...（直到阈值） |
| CUBIC | 默认拥塞控制（三次函数） | 高带宽长时延场景优化 |
| BBR | 基于带宽/延迟测量而非丢包 | v3 尚未入主线默认（2026） |
| MSS | 最大段大小（1460 典型） | 与 MTU 的关系 |
| 窗口缩放 | 16 位窗口的扩展选项 | 高 BDP 必需 |
| SACK | 选择性确认（丢哪些报哪些） | 高效重传 |
| MTU | 最大传输单元（1500 典型） | 分片与 PMTUD 的依据 |
| IPv6 | 128 位地址的新一代 IP | 2026-03 全球采用突破 50% |
