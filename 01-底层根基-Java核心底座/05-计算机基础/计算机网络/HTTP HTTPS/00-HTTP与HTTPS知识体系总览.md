## 4. 核心概念速查

| 概念 | 一句话定义 | 关键要点 |
|------|-----------|---------|
| HTTP | 无状态的应用层文本协议 | 状态由 Cookie/Token 在报文层模拟 |
| 幂等 | 重复执行效果相同 | GET/PUT/DELETE 幂等；POST 不幂等 |
| 强缓存 | 未过期直接使用本地副本 | `Cache-Control: max-age` 决定 |
| 协商缓存 | 带条件请求让服务器判定 | `ETag`/`Last-Modified` → 304 |
| Cookie | 客户端存储的键值对 | HttpOnly/Secure/SameSite 三属性 |
| SameSite | 跨站请求是否携带 Cookie | Lax 默认；CSRF 防御第一道闸 |
| CORS | 浏览器同源策略的放宽机制 | 服务器 `Access-Control-*` 响应头 |
| 队头阻塞 | 前一个响应阻塞后续 | HTTP/1.1 管线化、HTTP/2 连接内 |
| HPACK | HTTP/2 头部压缩 | 静态表+动态表+哈夫曼 |
| TLS 1.3 | 当前主流握手协议 | 1-RTT/0-RTT、前向保密 |
| 后量子混合 | 经典+量子密钥交换叠加 | X25519MLKEM768（2026 浏览器默认） |
| HSTS | 强制 HTTPS 的响应头 | `max-age` + 预加载列表 |
