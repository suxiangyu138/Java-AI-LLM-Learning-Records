# 网络原理

## 课程概述
- **课程性质**：专业核心必修课
- **适用专业**：计算机类各专业
- **开课学期**：大三学年
- **考核方式**：考试（闭卷）+ 实验 + 平时成绩

## 课程目标
1. 掌握计算机网络的基本概念和体系结构
2. 理解TCP/IP协议栈各层的协议原理
3. 掌握IP地址、路由、拥塞控制等核心机制
4. 能够分析实际网络应用中的问题

## 核心知识点

### 第一章：计算机网络概述
- 计算机网络的定义与分类
- 性能指标：带宽、时延（发送时延、传播时延、处理时延、排队时延）、时延带宽积
- OSI七层模型（物理层→数据链路层→网络层→传输层→会话层→表示层→应用层）
- TCP/IP四层模型（网络接口层→网际层→传输层→应用层）

### 第二章：物理层
- 数据通信基础：信号、信道、码元、波特率与比特率
- 奈奎斯特定理（无噪声信道）：最大数据传输率 = 2W log₂V
- 香农定理（有噪声信道）：最大数据传输率 = W log₂(1 + S/N)
- 传输媒体：双绞线、同轴电缆、光纤
- 信道复用：FDM（频分）、TDM（时分）、WDM（波分）、CDM（码分）

### 第三章：数据链路层
- 数据链路层功能：成帧、差错控制、流量控制
- 组帧方法：字符计数法、字符填充法、零比特填充法
- 差错检测：奇偶校验、CRC循环冗余校验
- 流量控制与可靠传输：
  - 停止等待协议（Stop-and-Wait）
  - 后退N帧协议(GBN)
  - 选择重传协议(SR)
  - 滑动窗口机制
- 介质访问控制(MAC)：
  - CSMA/CD（以太网）：先听后发、边听边发、冲突停发、随机延迟后重发
  - CSMA/CA（无线局域网）
- MAC地址（48位）
- 以太网帧格式
- 交换机的工作原理（自学习、转发）

### 第四章：网络层
- 网络层提供的两种服务：虚电路服务 vs 数据报服务
- IP协议：
  - IPv4地址（32位）：分类编址、子网划分、CIDR无分类编址
  - 子网掩码、网络地址、广播地址
  - ARP地址解析协议（IP→MAC）
  - DHCP动态主机配置协议
  - ICMP因特网控制报文协议（ping/traceroute）
  - NAT网络地址转换
- IP数据报格式（首部20字节固定+可变部分）
- 路由选择协议：
  - 内部网关协议(IGP)：RIP（距离向量算法）、OSPF（链路状态算法，Dijkstra）
  - 外部网关协议(EGP)：BGP（路径向量协议）
- 路由器工作原理（路由表、转发）
- IPv6简介（128位地址）

### 第五章：传输层
- 传输层的功能：进程间通信、复用与分用、差错控制
- 端口号（16位，0-65535）：熟知端口0-1023
- UDP协议：
  - 无连接、尽最大努力交付
  - UDP首部格式（8字节）
  - 校验和计算（伪首部+UDP数据报）
- TCP协议：
  - 面向连接、可靠交付、全双工
  - TCP首部格式（20字节固定）
  - TCP连接管理：三次握手、四次挥手
  - 可靠传输机制：序号、确认号、超时重传
  - 流量控制：滑动窗口（接收方控制）
  - 拥塞控制：慢开始、拥塞避免、快重传、快恢复
  - TCP连接释放的半关闭状态(TIME_WAIT)

### 第六章：应用层
- DNS域名系统：域名解析过程（递归查询+迭代查询）
- FTP文件传输协议：控制连接(21) + 数据连接(20)
- 电子邮件：SMTP(发送)、POP3/IMAP(接收)
- HTTP协议：请求/响应、状态码、持久连接(HTTP/1.1)、HTTP/2
- 万维网(WWW)与URL

## 重点难点
- **重点**：IP地址与子网划分、TCP可靠传输与拥塞控制、路由协议原理
- **难点**：CIDR子网划分聚合、TCP拥塞控制算法、OSPF的LSA泛洪与最短路径计算

## 学习方法与建议
1. 使用Wireshark抓包分析各层协议的实际交互
2. 画协议交互时序图辅助理解
3. 多做子网划分的计算练习
4. TCP状态转换图需要烂熟于心
