## 4. 核心概念速查

| 概念 | 一句话定义 | 关键要点 |
|------|-----------|---------|
| DNS | 域名 → IP 的分布式目录服务 | 全球最大的分布式 KV |
| 递归查询 | 解析器替客户端查到底 | 客户端 → 递归器 |
| 迭代查询 | 递归器逐级问权威 | 递归器 → 根/TLD/权威 |
| FQDN | 完整域名（`www.example.com.`） | 以点结尾 |
| TTL | 记录在缓存中的存活时间 | 越小越灵活，越大越快 |
| CNAME | 别名（指向另一域名） | 不能与 A 记录共存 |
| MX | 邮件路由 | 有优先级权重 |
| EDNS(0) | UDP 包扩大的扩展机制 | 现代 DNS 必需 |
| 缓存投毒 | 伪造应答污染递归缓存 | Kaminsky 攻击 |
| DNSSEC | 签名验证 DNS 应答 | 2026 校验率 ~36% |
| Anycast | 同一 IP 多地点发布 | 就近接入 + 抗 DDoS |
| DoH/DoT | 加密 DNS 传输 | 2026 加密流量 ~20% |
| GSLB | 按地理位置调度流量 | CDN/云负载均衡基础 |
