计算机网络是现代信息社会的基石，通过将不同地理分布的计算机、终端及网络设备，借助传输介质和通信协议连接，实现数据传输、资源共享与协同工作。其相关技术体系庞大，涵盖基础架构、核心协议、传输介质、拓扑结构、安全防护及前沿演进等多个维度。

## 一、计算机网络基础分类技术

### （一）按覆盖范围分类

| 类型 | 覆盖范围 | 核心特点 | 典型应用 |
|------|----------|----------|----------|
| **广域网（WAN）** | ≥100公里 | 传输速率较低，延迟较高 | 互联网、跨国企业专网 |
| **城域网（MAN）** | 10~100公里 | 速率中等，延迟低于广域网 | 城市宽带骨干网 |
| **局域网（LAN）** | ≤10公里 | 传输速率高，延迟极低（<1ms） | 家庭WiFi、企业内网 |
| **个人区域网（PAN）** | ≤10米 | 低功耗、短距离 | 蓝牙耳机、智能手表 |

### （二）按拓扑结构分类

| 拓扑类型 | 优点 | 缺点 | 典型应用 |
|----------|------|------|----------|
| **星型拓扑** | 故障排查简单、扩展方便 | 中心节点故障全网瘫痪 | 家庭WiFi、企业局域网 |
| **总线型拓扑** | 成本低、结构简单 | 总线故障全网瘫痪 | 基本被星型替代 |
| **环型拓扑** | 延迟稳定、无数据冲突 | 扩展困难、单点故障 | 令牌环网、工业控制网络 |
| **树型拓扑** | 易于扩展、集中管理 | 层级越高延迟越大 | 校园网 |
| **网状型拓扑** | 可靠性极高、抗毁性强 | 成本高、配置复杂 | 互联网骨干网 |

### （三）其他核心分类

| 分类维度 | 类型 |
|----------|------|
| **按传输介质** | 有线网络（双绞线、光纤、同轴电缆）、无线网络（WiFi、蓝牙、5G） |
| **按传输技术** | 广播式网络、点对点网络 |
| **按使用场景** | 公用网络、专用网络、存储区域网（SAN）、工业控制网络 |

## 二、计算机网络核心协议体系

### （一）OSI七层模型（理论模型）

| 层次 | 功能 | 核心协议/设备 |
|------|------|---------------|
| 物理层 | 比特流传输 | 中继器、集线器 |
| 数据链路层 | 帧传输与MAC地址管理 | 以太网协议、交换机 |
| 网络层 | IP寻址与路由选择 | IP协议、路由器 |
| 传输层 | 端到端可靠传输 | TCP（可靠）、UDP（高效） |
| 会话层 | 会话管理与同步 | NetBIOS协议 |
| 表示层 | 数据格式转换、加密解密 | JPEG、ASCII编码 |
| 应用层 | 面向用户应用服务 | HTTP、FTP、DNS |

### （二）TCP/IP四层模型（实际应用模型）

| 层次 | 核心协议 |
|------|----------|
| **网络接口层** | 对应OSI物理层+数据链路层，处理硬件连接和帧传输 |
| **网络层** | IP（核心）、ARP、RARP、ICMP、NAT |
| **传输层** | TCP（面向连接、可靠）、UDP（无连接、低延迟） |
| **应用层** | HTTP/HTTPS、DNS、FTP、SMTP/POP3/IMAP |

## 三、核心网络技术与设备

### （一）传输介质技术

**有线传输介质：**

| 介质 | 特点 | 适用场景 |
|------|------|----------|
| **双绞线** | 成本低，传输距离≤100米 | 家庭、企业桌面连接 |
| **光纤** | 速率极高，传输距离远，抗干扰强 | 互联网骨干网、城域网 |
| **同轴电缆** | 抗干扰能力较强 | 逐渐被替代 |

**无线传输介质：**

| 技术 | 特点 | 适用场景 |
|------|------|----------|
| **WiFi**（802.11系列） | 2.4GHz/5GHz频段 | 家庭、办公室无线覆盖 |
| **蓝牙** | 短距离，传输距离≤10米 | 个人设备互联 |
| **蜂窝网络**（2G/3G/4G/5G） | 覆盖范围广 | 移动互联网、物联网 |
| **卫星通信** | 全球覆盖 | 偏远地区、航空 |

### （二）核心网络设备

| 设备 | 工作层次 | 核心功能 |
|------|----------|----------|
| **路由器** | 网络层 | 路由选择、跨网络互联、NAT转换 |
| **交换机** | 数据链路层 | 帧转发和过滤（MAC地址识别） |
| **集线器（HUB）** | 物理层 | 信号放大和广播转发（已基本被替代） |
| **网关** | 多层 | 协议转换、不同网络连接 |
| **防火墙** | 网络层/应用层 | 非法流量过滤 |

### （三）关键支撑技术

| 技术 | 说明 |
|------|------|
| **路由技术** | 通过RIP、OSPF、BGP等协议构建路由表，实现最优路径转发 |
| **交换技术** | 分组交换（当前主流）、电路交换、报文交换 |
| **NAT技术** | 私有IP转换为公有IP，解决IPv4地址短缺 |
| **VPN技术** | 加密隧道实现安全的远程访问 |

## 四、网络性能优化与安全技术

### （一）网络性能优化技术

| 技术 | 说明 |
|------|------|
| **带宽扩容技术** | 升级传输介质和网络设备 |
| **流量调度技术** | QoS优先级划分，AI原生网络动态调度 |
| **边缘计算技术** | 计算资源部署在网络边缘，降低延迟 |
| **数字孪生网络（DTN）** | 虚拟空间1:1映射物理网络，预验证新策略 |
| **确定性网络技术** | TSN与DetNet时隙调度，实现极低抖动和零丢包 |

### （二）网络安全技术

| 技术 | 说明 |
|------|------|
| **加密技术** | 对称加密（AES）、非对称加密（RSA、ECC） |
| **防火墙与IDS/IPS** | 过滤非法流量，监测和阻断恶意攻击 |
| **零信任架构** | "永不信任，始终验证"原则 |
| **病毒与恶意软件防护** | 杀毒软件、终端安全管理系统 |
| **数据备份与恢复技术** | 定期备份，建立应急恢复机制 |

## 五、计算机网络前沿发展趋势

| 趋势 | 说明 |
|------|------|
| **AI原生网络** | 大模型嵌入网络控制平面，支持自然语言意图驱动 |
| **高速以太网升级** | 800G已规模部署，1.6T标准预计2026年冻结 |
| **空天地海一体化网络** | 低轨卫星与5G/6G融合，三层架构 |
| **算网融合** | 网络与计算深度耦合，算力最优调度 |
| **绿色网络** | CPO、液冷、AI节能算法，目标<1nJ/bit |
| **语义通信** | 6G核心方向，仅传输"语义差异" |
| **IPv6普及** | 逐步替代IPv4，解决地址枯竭问题 |
