# 物理层与数据链路层

## 📌 课程定位
物理层关注"怎么传比特"，数据链路层关注"怎么可靠传帧"。虽然不直接写网络设备驱动，但理解CSMA/CD、MAC地址、交换机原理是网络问题排查的基础。

## 🎯 核心章节

### 第一部分：物理层

### 1. 通信基础
- **信号**：模拟信号(连续) vs 数字信号(离散)
- **码元**：代表一个离散值的基本波形——波特率(码元/秒) ≠ 比特率(bps)
- **奈奎斯特准则**：无噪声信道，最大码元速率 = 2W Baud（W=带宽Hz）
- **香农定理**：有噪声信道，C = Wlog₂(1+S/N)，S/N为信噪比——带宽越大、信噪比越高，信息传输速率越高

### 2. 传输介质
- **双绞线**：STP(屏蔽)/UTP(非屏蔽)——最常见LAN介质，Cat5e/Cat6/Cat7
- **光纤**：单模(远距离/高带宽/激光)、多模(近距离/LED)——核心网和IDC主干
- **无线**：WiFi(2.4G/5G)、蓝牙、卫星

### 3. 编码与调制
- **编码**（数字→数字）：NRZ、曼彻斯特编码(位中间跳变)、差分曼彻斯特
- **调制**（数字→模拟）：ASK(调幅)、FSK(调频)、PSK(调相)、QAM(混合——WiFi 6/5G的核心)

### 第二部分：数据链路层

### 4. 三大基本功能
- **成帧**：比特流→帧。字符计数法、字节填充法(PPP)、比特填充法(HDLC的01111110标志)
- **差错检测**：CRC循环冗余校验（接收方用相同生成多项式除，余数为0则无误）
- **流量控制**：停等协议、滑动窗口协议（后退N帧GBN、选择重传SR）

### 5. 介质访问控制（MAC）
- **信道划分**：FDM(频分)、TDM(时分)、WDM(波分)、CDMA(码分)
- **随机访问**：
  - **ALOHA**：想发就发，碰撞后随机重发——纯ALOHA吞吐率18%，时隙ALOHA 36%
  - **CSMA**：发前先听——1-坚持/非坚持/p-坚持
  - **CSMA/CD（以太网核心）**：边发边听，检测到碰撞立刻停止→强化碰撞→二进制指数退避算法

### 6. MAC 地址与 ARP
- **MAC地址**：48位（6字节），全球唯一，网卡出厂固化——前3字节OUI厂商标识
- **ARP协议**：根据IP地址找MAC地址
  1. 主机广播ARP请求(FF:FF:FF:FF:FF:FF)
  2. 目标主机单播ARP响应，告知自己的MAC
  3. 结果缓存到ARP表（`arp -a` 查看）
- **ARP欺骗**：伪造ARP响应，中间人攻击——交换机防御

### 7. 以太网（Ethernet）
- **帧格式**（⭐ 重点）：目的MAC(6B) | 源MAC(6B) | 类型(2B) | 数据(46-1500B) | FCS/CRC(4B)
- **最小帧长 64B**：由CSMA/CD的碰撞检测窗口决定（10Mbps以太网，2.5km最大距离）
- **交换式以太网**：交换机根据MAC地址表转发——每个端口是独立冲突域
- **VLAN（虚拟局域网）**：802.1Q标签，逻辑隔离广播域

## ✅ 学习建议
- CRC的原理了解即可——知道是检错码不是纠错码
- ARP的工作过程要能完整讲出——局域网通信基础，面试常考
- 以太网帧格式记住：源MAC在目的MAC后面（先知道发给谁再知道谁发的）
