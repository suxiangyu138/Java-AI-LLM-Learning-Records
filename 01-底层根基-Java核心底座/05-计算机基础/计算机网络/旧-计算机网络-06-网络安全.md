# 网络安全

## 📌 课程定位
安全不是"附加功能"，而是在设计之初就要考虑的基础要素。理解常见攻击方式和防御手段，是写出安全代码的前提。

## 🎯 核心章节

### 1. 网络安全基础
- **CIA三要素**：机密性(Confidentiality)、完整性(Integrity)、可用性(Availability)
- **威胁模型**：窃听、篡改、伪造、否认
- **Kerckhoffs原则**：系统的安全性应依赖于密钥的保密，而非算法的保密

### 2. 密码学基础
- **对称加密**：加密解密同一密钥——AES(128/256位)、DES(已废弃)、ChaCha20
  - 块加密模式：ECB(不安全)、CBC(需IV)、CTR(流式)、GCM(认证加密)
- **非对称加密**：公私钥对——RSA(大数分解)、ECC(椭圆曲线)
  - 公钥加密→私钥解密(加密通信)；私钥签名→公钥验签(数字签名)
- **哈希函数**：SHA-256、SHA-3、BLAKE3
  - 性质：单向性、抗碰撞、雪崩效应
  - 应用：密码存储(bcrypt/scrypt/argon2)、文件校验、数字签名
- **密钥交换**：Diffie-Hellman——双方在不安全信道协商共享密钥

### 3. Web 常见攻击（⭐ OWASP Top 10）

**XSS（跨站脚本攻击）**：
- 存储型：攻击脚本存入数据库→其他用户访问时执行
- 反射型：恶意脚本在URL中→受害者点击链接触发
- DOM型：客户端JS动态插入恶意代码
- **防御**：输出编码(HTML实体转义)、CSP(内容安全策略)、HttpOnly Cookie

**CSRF（跨站请求伪造）**：
- 攻击者诱导用户点击链接→以用户身份发请求(利用已登录的Cookie)
- **防御**：CSRF Token、SameSite Cookie、Referer/Origin校验

**SQL注入**：
- 拼接SQL语句时插入恶意SQL片段——`' OR '1'='1`
- **防御**：参数化查询/预编译语句(PreparedStatement)、ORM框架、最小权限原则

**SSRF（服务端请求伪造）**：
- 攻击者诱导服务器向内网发请求——读内部文件、探内网端口
- **防御**：URL白名单、禁止内网IP、禁用不必要的协议(file://, dict://)

### 4. DDoS 与防御
- **SYN Flood**：大量SYN占用半连接队列——SYN Cookie防御
- **HTTP Flood**：大量HTTP请求耗尽服务器资源——WAF+限流
- **DNS放大攻击**：伪造源IP发小DNS请求→大响应打到受害者

### 5. 防火墙与入侵检测
- **包过滤防火墙**：基于IP/端口/协议规则过滤——网络层
- **状态检测防火墙**：跟踪连接状态——transport层
- **应用层防火墙(WAF)**：解析HTTP语义，检测SQL注入/XSS等
- **IDS/IPS**：入侵检测/防御——基于特征或异常检测

## ✅ 学习建议
- OWASP Top 10 每年更新，至少了解排名前5的攻击方式
- 密码存储永远用 bcrypt/scrypt/argon2，绝对不要用 MD5/SHA直接存储
- 安全的核心原则：永远不信任用户输入——所有输入都需要校验和清理
