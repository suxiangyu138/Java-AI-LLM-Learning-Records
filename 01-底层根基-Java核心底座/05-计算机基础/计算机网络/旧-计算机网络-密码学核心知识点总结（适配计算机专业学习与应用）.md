# 密码学核心知识点总结（适配计算机专业学习与应用）
密码学是研究信息加密、解密及安全认证的技术科学，核心目标是保障信息在传输和存储过程中的机密性、完整性、可用性、不可否认性，广泛应用于网络通信、数据安全、身份认证等领域。
## 一、 密码学核心目标
1. 机密性：确保信息仅被授权方读取，未授权方无法理解内容（如 HTTPS 加密传输数据）。
2. 完整性：保证信息在传输或存储中未被篡改、伪造（如文件校验和、数字签名）。
3. 身份认证：验证通信双方的真实身份（如登录密码、U 盾、生物识别）。
4. 不可否认性：防止发送方否认已发送的信息（如数字签名可证明消息来源）。
## 二、 密码学分类
1.  对称密码学（对称密钥加密）
- 核心特点：加密和解密使用同一把密钥，密钥需严格保密。
- 优点：加密速度快、效率高，适合大批量数据加密。
- 缺点：密钥分发困难，多人通信时密钥管理复杂度高（n 人通信需 n(n-1)/2 个密钥）。
- 经典算法
- DES：早期对称加密标准，密钥长度 56 位，安全性低，已被淘汰。
- AES：目前主流标准（高级加密标准），支持 128/192/256 位密钥，安全性高，广泛用于磁盘加密、网络传输。
- RC4：流密码算法，用于早期 WEP 协议，现因安全性问题逐渐被弃用。
- 工作模式：ECB（电子密码本，相同明文加密出相同密文，不安全）、CBC（密码分组链接，引入初始化向量 IV，安全性更高）、CTR（计数器模式，支持并行加密）。
2.  非对称密码学（公钥密码学）
- 核心特点：加密和解密使用一对密钥——公钥（公开传播）和私钥（严格保密）；公钥加密的内容只能用私钥解密，私钥加密的内容（数字签名）只能用公钥验证。
- 优点：解决了对称加密的密钥分发问题，支持身份认证。
- 缺点：加密速度慢，不适合大批量数据加密。
- 经典算法
- RSA：基于大整数分解难题，可用于加密和数字签名，是应用最广泛的公钥算法。
- ECC（椭圆曲线密码学）：基于椭圆曲线离散对数难题，相同安全性下密钥长度远小于 RSA（如 256 位 ECC 等效于 3072 位 RSA），适合移动端、物联网等资源受限场景。
- DSA：专门用于数字签名，不支持加密。
- 典型应用：HTTPS 握手阶段的密钥交换、数字签名、区块链钱包地址生成。
3.  哈希函数（散列函数）
- 核心特点：将任意长度的输入（明文）映射为固定长度的输出（哈希值/摘要），具有单向性（无法从哈希值反推明文）、抗碰撞性（难以找到两个不同明文生成相同哈希值）。
- 核心作用：验证数据完整性、存储密码摘要、数字签名前置处理。
- 经典算法
- MD5：输出 128 位哈希值，因存在碰撞漏洞，仅用于非安全场景（如文件校验）。
- SHA 系列：
- SHA-1：输出 160 位，安全性不足，已被淘汰；
- SHA-256/SHA-512：输出 256/512 位，安全性高，广泛用于区块链、数字签名；
- SHA-3：新一代哈希标准，抗碰撞性更强。
- 应用场景：用户密码存储（存储哈希值而非明文）、Git 版本控制的文件校验、区块链的区块哈希计算。
## 三、 密码学核心应用技术
1. 数字签名
- 原理：发送方用私钥对消息哈希值加密，接收方用发送方公钥解密验证；既能验证身份，又能保证消息完整性。
- 作用：防篡改、防抵赖，是电子合同、数字货币的核心技术。
2. 数字证书
- 原理：由权威机构（CA）颁发，包含用户公钥、身份信息及 CA 签名；解决“公钥归属问题”，防止公钥被伪造。
- 应用：HTTPS 协议中，服务器通过数字证书证明自身公钥的合法性。
3. 密钥交换协议
- 作用：在不安全信道中，安全地交换对称加密密钥（因对称加密效率高，实际传输数据用对称加密，仅交换密钥用非对称加密）。
- 经典协议：DH 密钥交换（基于离散对数难题）、ECDHE（椭圆曲线版本，支持前向保密）。
4. 消息认证码（MAC）
- 原理：结合密钥和消息计算出固定长度的校验值，验证消息完整性和真实性（需共享密钥）。
- 常用算法：HMAC（基于哈希函数的 MAC，如 HMAC-SHA256）。
## 四、 密码学在计算机领域的典型应用
1. 网络通信安全：HTTPS 协议（结合非对称加密、对称加密、数字证书）、VPN 加密隧道。
2. 数据存储安全：磁盘加密（BitLocker、FileVault）、数据库敏感数据加密（如用户手机号、银行卡号加密存储）。
3. 身份认证：密码哈希存储（如 bcrypt、Argon2 算法，加盐哈希防止彩虹表攻击）、U 盾（基于非对称加密）、OAuth 授权协议。
4. 区块链与数字货币：比特币的地址生成（ECC 算法）、交易签名（数字签名）、区块哈希校验（SHA-256）。
## 五、 常见攻击手段与防御
1. 暴力攻击：枚举所有可能的密钥破解密码；防御：使用长密钥（如 AES-256、RSA-2048 以上）。
2. 中间人攻击：拦截并篡改通信双方的数据；防御：使用数字证书验证身份、采用密钥交换协议（如 ECDHE）。
3. 彩虹表攻击：预计算常见密码的哈希值破解密码；防御：密码加盐（Salt）哈希，使用慢哈希算法（如 bcrypt）。
4. 侧信道攻击：通过功耗、时间等信息破解密钥；防御：优化算法实现，增加噪声干扰。
