## 一、网络基础概念

### 核心定义

计算机网络：通过通信设备与线路，将分散独立的计算机互连，实现**资源共享、数据通信**。

### 三大性能指标

- **带宽**：单位时间最大数据传输速率
- **时延**：发送时延 + 传播时延 + 处理时延 + 排队时延
- **丢包率、吞吐量**

### 网络分类

覆盖范围：局域网 LAN、城域网 MAN、广域网 WAN

### 网络拓扑

星型、总线型、环型、网状

## 二、OSI七层 & TCP/IP五层模型（必背）

### 分层对照

| OSI七层 | TCP/IP五层 | 核心协议/设备 |
|---------|------------|---------------|
| 应用层 | 应用层 | HTTP、HTTPS、FTP、DNS、SMTP |
| 表示层 | - | 加密、解密、编码转换 |
| 会话层 | - | 会话建立、维持、断开 |
| 传输层 | 传输层 | TCP、UDP；端口 |
| 网络层 | 网络层 | IP、ICMP、ARP；路由器 |
| 数据链路层 | 数据链路层 | MAC、PPP、CSMA/CD；交换机 |
| 物理层 | 物理层 | 比特流、网线、集线器 |

### 分层核心思想

> 下层为上层提供服务，**协议对等通信，服务垂直调用**。

## 三、物理层 & 数据链路层

### 物理层

- 传输单位：比特
- 核心：接口标准、信号调制、传输介质（双绞线、光纤）

### 数据链路层

- 传输单位：帧
- **MAC地址**：48位物理地址，全球唯一
- **关键机制**：
  - CRC 循环冗余校验（检错）
  - CSMA/CD 载波监听多路访问 + 冲突检测（以太网）
  - ARP：IP地址 → MAC地址映射

---

## 四、网络层（核心）

### IP地址

- IPv4：32位，点分十进制；IPv6：128位
- 分类：A/B/C/D/E类、私有IP、公网IP
- 子网划分、子网掩码、网关

### 核心协议

| 协议 | 作用 |
|------|------|
| **IP** | 无连接、不可靠、尽力交付 |
| **ICMP** | 网络探测，ping、tracert 底层协议 |
| **ARP** | IP转MAC |
| **NAT** | 网络地址转换，内网穿透、节省公网IP |

### 路由

- 路由选择：静态路由、动态路由
- 路由转发原理：最长前缀匹配

## 五、传输层（面试高频）

### 端口

- 范围：0~65535
- 知名端口：80(HTTP)、443(HTTPS)、21(FTP)、53(DNS)

### UDP 协议

> 特点：无连接、不可靠、面向报文、开销小

- 适用：直播、语音、DNS
- 无拥塞控制、无重传机制

### TCP 协议（重中之重）

> 特点：**面向连接、可靠传输、面向字节流、拥塞控制**

**可靠传输三大核心：**
1. 确认应答 ACK
2. 超时重传
3. 滑动窗口（流量控制）

**关键机制：**
- **三次握手**：建立连接，防止失效报文段
- **四次挥手**：断开连接，双方独立关闭
- **拥塞控制**：慢启动、拥塞避免、快重传、快恢复

## 六、应用层

### HTTP/HTTPS

| 特性 | HTTP | HTTPS |
|------|------|-------|
| 传输方式 | 明文 | HTTP + SSL/TLS |
| 端口 | 80 | 443 |
| 安全性 | 无 | 加密认证 |

- HTTP请求方法：GET/POST/PUT/DELETE
- **状态码**：2xx 成功、3xx 重定向、4xx 客户端错误、5xx 服务端错误

### DNS 域名解析

- 作用：域名解析为IP
- 递归查询、迭代查询

### 其他协议

- **FTP**：文件传输
- **SMTP/POP3**：邮件收发

## 七、关键核心机制（必背）

| 机制 | 说明 |
|------|------|
| **TCP 流量控制** | 通过**接收窗口rwnd**，防止发送方发送过快淹没接收方 |
| **TCP 拥塞控制** | 通过**拥塞窗口cwnd**，防止网络过载 |
| **套接字 Socket** | IP + 端口，唯一标识网络中进程 |
| **DNS 解析全过程** | 浏览器缓存→系统缓存→本地DNS→根域名服务器→顶级域名→权威服务器 |
