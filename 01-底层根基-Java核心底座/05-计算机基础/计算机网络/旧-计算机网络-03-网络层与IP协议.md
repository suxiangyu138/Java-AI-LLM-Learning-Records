# 网络层与 IP 协议

## 📌 课程定位
网络层是互联网的"物流系统"——IP协议定义了全球统一的寻址方式，路由协议决定了数据包走哪条路。这是网络中最核心的一层。

## 🎯 核心章节

### 1. IP 寻址（⭐ 核心基础）
- **IPv4 地址**：32位，4字节点分十进制（如192.168.1.1）
- **分类编址（有类）**：
  - A类：0.x.x.x ~ 127.x.x.x，默认掩码/8（前8位网络号）
  - B类：128.x.x.x ~ 191.x.x.x，默认掩码/16
  - C类：192.x.x.x ~ 223.x.x.x，默认掩码/24
  - D类：多播地址；E类：保留
- **CIDR（无类域间路由）**：a.b.c.d/x 格式——IP地址/前x位是网络号
  - 例如：192.168.1.0/24 表示前24位网络号，后8位主机号
- **子网划分（必会计算）**：借主机位做子网号
  - 子网掩码、网络地址(主机位全0)、广播地址(主机位全1)
  - 可用主机数 = 2^(主机位数) - 2（排除网络地址和广播地址）

### 2. 特殊 IP 地址
- **127.0.0.1**：回环地址(localhost)——本机内部通信，不进物理网卡
- **0.0.0.0**：本机所有IP；**255.255.255.255**：受限广播
- **私有地址（RFC 1918）**：
  - 10.0.0.0/8（A类私有）
  - 172.16.0.0/12（B类私有）
  - 192.168.0.0/16（C类私有——家用路由器最常见）

### 3. IPv4 首部格式（⭐ 重点）
```
0       4       8       12      16      20      24      28      31
|版本|首部长|服务类型|        总长度(16位)        |
|    标识(16位)    |标志|     片偏移(13位)       |
|  TTL(8位)   |   协议(8位)   |     首部校验和(16位)      |
|                   源IP地址(32位)                    |
|                  目的IP地址(32位)                    |
|              选项(可选, 最长40字节)                  |
```
- **TTL**：每跳减1，归0丢弃——防数据包在网络中无限循环
- **协议字段**：6=TCP, 17=UDP, 1=ICMP——告诉上层该交给谁

### 4. NAT（网络地址转换）
- **原理**：私有地址↔公网地址的转换——一个公网IP让整个家庭/公司上网
- **NAPT**：端口映射，多台内网设备共用一个公网IP——家用路由器的工作方式
- **NAT穿透**：STUN/TURN——WebRTC、P2P需要解决的问题

### 5. ICMP 协议
- 互联网控制报文协议——差错报告(不可达/超时)+网络诊断
- **ping**：ICMP回显请求+回显应答——测试连通性
- **traceroute**：利用TTL逐跳探索路径（发TTL=1,2,3...的数据包）
- ICMP被攻击者利用：Smurf攻击(放大攻击)、ICMP隧道

### 6. 路由协议
- **自治系统(AS)**：同一管理机构下的网络集合
- **内部网关协议(IGP)**：
  - **RIP**：距离向量(最多15跳)，简单但收敛慢——小网络用
  - **OSPF**：链路状态(SPF/Dijkstra算法)——企业网主流
- **外部网关协议(EGP)**：
  - **BGP**：路径向量协议——互联网的核心，连接各个AS
  - 核心思想：通告路由可达性，选择AS跳数最短的路径

### 7. IPv6
- **128位地址（相比IPv4的32位）**：根本上解决地址枯竭
- 表示：冒号十六进制，如 `2001:0db8:85a3::8a2e:0370:7334`
- **优势**：无需NAT(地址足够)、IPSec内置、更简洁的首部
- **过渡技术**：双栈(同时跑v4和v6)、隧道(v6报文封装在v4中)

## ✅ 学习建议
- 子网划分计算必须熟练——运维、网络岗面试必考
- IP首部字段不需要全背，但TTL、协议、分片相关字段要记住
- ping/tracert 是每个后端工程师的日常排障工具，了解背后的ICMP原理
