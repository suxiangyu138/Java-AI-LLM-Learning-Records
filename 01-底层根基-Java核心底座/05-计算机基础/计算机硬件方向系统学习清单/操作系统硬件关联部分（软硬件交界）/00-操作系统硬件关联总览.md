## 4. 核心概念速查

| 概念 | 一句话本质 | 硬件支撑 |
|------|-----------|---------|
| 内核态/用户态 | CPU 用特权级隔离软件信任边界 | Ring0/3（x86）、EL1/0（ARM） |
| 中断 | 硬件异步通知 CPU"有事件" | APIC、MSI-X、INT pin |
| 系统调用 | 用户程序请求内核服务 | syscall/sysenter 指令 |
| 虚拟内存 | 进程看到"假地址"，硬件翻译 | MMU + 多级页表 + TLB |
| 上下文切换 | CPU 从一个进程换到另一个 | CR3 换页表、寄存器换血 |
| DMA | 外设绕过 CPU 直接读写内存 | DMA 引擎 + IOMMU 隔离 |
| 时钟中断 | 内核的时间心跳，驱动调度 | APIC timer、HPET |
| 原子操作 | 硬件保证"读-改-写"不可分割 | LOCK 前缀、AMO 指令 |
| 内存屏障 | 约束指令/缓存的重排序 | fence 指令族 |
| UEFI | 现代固件标准，替代 BIOS | NVRAM、安全启动 |
| EPT | 虚拟机的二级页表（影子页表淘汰者） | VT-x/AMD-V 硬件 |

### 4.1 十组易混概念辨析

| 易混对 | 区别一句话 |
|--------|-----------|
| 中断 vs 异常 | 中断是硬件异步敲门，异常是 CPU 同步报警 |
| 系统调用 vs 函数调用 | 系统调用切特权级+切栈+进内核，函数调用只在用户态 |
| 用户态 vs 内核态 | 不是两个进程，是同一执行流的权限状态切换 |
| 虚拟内存 vs 物理内存 | 虚拟=进程看到的地址空间（靠页表映射），物理=DRAM 真实容量 |
| TLB 失效 vs cache 失效 | TLB 是地址翻译缓存（几十周期），cache 是数据缓存（几周期） |
| 上下文切换 vs 模式切换 | 切换换进程（寄存器+页表全换），模式切换换权限（同进程） |
| MMIO vs DMA | MMIO 是 CPU 读写设备寄存器，DMA 是设备自己读写内存 |
| 中断 vs 轮询 | 中断有 ~5-20μs 固定开销但省 CPU，轮询零开销但占满核 |
| 时钟中断 vs 定时器 | 时钟中断是周期性 tick（调度心跳），定时器是单次到期事件 |
| MESI 一致性 vs 内存屏障 | 一致性管"缓存视图同步"，屏障管"执行顺序约束" |

### 4.2 本体系覆盖 vs 不覆盖

| 覆盖（本体系） | 不覆盖（其他体系） |
|---------------|-------------------|
| 特权级、中断、系统调用、MMU/TLB | CPU 流水线、指令集、微架构（→ 计算机组成原理） |
| 调度、切换、IO 路径、时钟 | 内存硬件物理特性、内存墙（→ 内存墙） |

### 6.1 常见误区清单

| 误区 | 正解 |
|------|------|
| "用户态和内核态是两个进程" | 同一执行流在不同特权级之间切换 |
| "系统调用就是函数调用" | 系统调用切特权级+切栈，函数调用只在用户态 |
| "虚拟内存=物理内存的映射，所以 128TB 很浪费" | 多级页表按需建立，只映射用到的部分 |
| "volatile 保证原子性" | volatile 只保证可见性和有序性，不保证原子性 |
| "线程切换只要换寄存器" | 还要换栈+（跨进程）CR3/TLB/cache 冷启动 |
| "中断处理越快越好，所以尽量少开中断" | 关中断太久反而让系统失去实时性（连时钟都不准） |
| "THP 开了就一定更快" | 大页提升 TLB 命中，但合并/分裂有停顿风险，需实测 |
| "容器比虚拟机安全" | 容器共享内核（攻击面更大），虚拟机有硬件隔离 |
| "timeout 用 currentTimeMillis 就行" | NTP 回拨会破坏墙钟计时，超时必须用单调时钟 |
| "机密计算=加密磁盘" | 机密计算是"运行中内存"加密+证明，不是静态加密 |

> 🎯 **使用建议**：以上十条是面试高频陷阱，也是把概念落到工程实践的试金石——全部能对答如流，即可进入 10 篇的面试冲刺。
