## 3. 学习路线推荐

**路线 A：看懂"GPU 为什么快"（半天）**
01 → 02 → 03。从设计哲学到 SM 解剖再到执行模型——解决"芯片上到底发生了什么"的基本疑问。

**路线 B：软硬打通（2-3 天，推荐）**
路线 A + 04 + 05 + 06。理解存储层次、调度与矩阵引擎后，你就能解释 FlashAttention 为什么快、KV Cache 为什么占带宽、量化为什么能提速——**这些是 AI 推理优化的全部底层依据**。配合 `量化背后硬件约束/` 阅读，那套体系把 06 篇的 Tensor Core 展开到 11 篇的深度。

**路线 C：架构前沿与生产（面向性能/架构工程师）**
路线 B + 07 + 08 + 09 + 10。掌握 2026 年三大架构事实：Blackwell Ultra 的 160 SM 与 tcgen05、Rubin 的 224 SM 与 HBM4 22TB/s、MI355X 的 8 XCD 芯粒设计——并用 Roofline 与占用率模型指导实际部署决策。

> 💡 与知识库关系：本体系与 `内存墙/`（HBM 带宽与容量约束）、`量化背后硬件约束/`（Tensor Core 与数值格式）构成 AI 性能三件套；01 篇与 `CPU/` 对照阅读；04 篇与 `缓存与Cache/`、`计算机组成原理/GPU/` 互补；06 篇的矩阵指令是 `量化背后硬件约束/03` 的硬件侧根源。

### 阅读时的三个常见误区

1. **"GPU 就是核多的 CPU"**：错——GPU 用面积换吞吐，单线程性能远低于 CPU，它快在"同时处理 1 万线程"，靠的是把晶体管投给执行单元而非缓存与控制（01/03 篇）
2. **"算力就是一切"**：2026 年 B300 的 FP4 标称 15 PFLOPS，但真实推理性能同时被 HBM 带宽（8TB/s）、NVLink 互连（1.8TB/s）与占用率锁死——Roofline 之下 GPU 多数时间是带宽受限（04/05/10 篇）
3. **"看标称就能比 GPU"**：同一张卡 FP4/FP8/FP16 算力差 4 倍、稀疏再翻倍，厂商惯用 FP4 峰值做宣传——选型必须回到实际精度的可复现基准（08/09/10 篇）

带着三个误区读完全书，会发现每篇都在回答同一个问题：**晶体管到底被投到了哪里、数据如何在芯片内流动、瓶颈卡在哪一级**。

## 4. 核心概念速查

| 概念 | 一句话定义 | 关键事实（2026） |
|------|-----------|---------------------|
| SIMT | 单指令多线程：一条指令驱动 32 线程 | warp = 32 线程锁步执行 |
| SM | 流式多处理器，GPU 最小计算单元 | B300 共 160 个 SM，每 SM 128 CUDA 核 |
| Warp 调度器 | 每周期从就绪 warp 中选一发射 | 每 SM 4 个（Ampere 起） |
| 寄存器堆 | 每 SM 的线程私有寄存器存储 | 256KB/SM，延迟 ~0 周期 |
| TMEM | Blackwell+ 张量内存（累加器） | 256KB/SM，B300 共 40MB |
| Tensor Core | 矩阵乘加速单元 | 5 代 tcgen05 指令族，B300 640 个 |
| HBM | 堆叠式高带宽内存 | B300 288GB/8TB/s；Rubin HBM4 22TB/s |
| 合并访问 | 32 线程访问连续地址合并为一次事务 | 带宽利用的前提 |
| 占用率 | 活跃 warp 数 / 最大可驻留 warp 数 | 隐藏时延的关键指标 |
| 2:4 稀疏 | 每 4 元素 2 非零的结构化稀疏 | 矩阵算力标称翻倍 |
| NVLink | GPU 间高速互连 | 5.0 = 1.8TB/s；6.0 = 3.6TB/s |
| XCD / LDS | AMD 计算芯粒 / 局部数据共享 | MI355X 8×XCD、LDS 160KB/CU |
| MMA | 矩阵乘加速指令族 | mma → wgmma → tcgen05 三代演进 |
| GPC | 图形处理簇，版图重复单元 | B300 8 GPC × 20 SM |

> 🎯 **核心要点**：GPU 硬件架构的全部矛盾压缩为一句话——**用吞吐换时延：把绝大部分晶体管投给执行单元与带宽，靠 1 万个并发线程互相掩护来隐藏内存延迟**；2026 年的性能由"SM 微架构 × Tensor Core × HBM 带宽 × NVLink 互连"四元决定，任何单项标称都骗不了 Roofline——掌握这套四元分析框架，任何一张新卡的规格都能自己拆解成可执行的部署判断。

### 体系速读版（30 秒版）

- **为什么长这样**：吞吐优先哲学 + 面积预算，晶体管分给执行而非控制（01 篇）
- **执行单元**：SM 内 4 调度器 × 128 CUDA 核 × 4 Tensor Core，warp 锁步（02/03 篇）
- **性能从哪来**：存储层次少搬数据（04）、多 warp 调度藏延迟（05）、矩阵引擎算得快（06）
- **怎么连起来**：片上 NoC + HBM 控制器，机内 NVLink 5.0，机柜 NVL72 无阻塞（07 篇）
- **2026 现状**：Blackwell Ultra 量产、Rubin 首发、MI355X 追平 GB200（08/09 篇）
- **怎么决策**：Roofline 定瓶颈 → 占用率定配置 → 显存定容量 → 实测定选型（10 篇）
