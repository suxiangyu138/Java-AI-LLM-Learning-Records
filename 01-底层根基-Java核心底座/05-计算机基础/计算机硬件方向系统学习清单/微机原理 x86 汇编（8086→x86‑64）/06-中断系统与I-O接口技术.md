# 中断系统与 I/O 接口技术
> 中断是 CPU 与外部世界的对话机制，接口芯片是对话的物理通道——从中断向量表、8259A 到端口编址，这一篇打通"微机原理"课程的核心实验面。

## 1. 中断的分类与优先级

中断让 CPU 不必轮询外设——外设有事时"主动打断"。8086 的中断分两类：**内部中断**（CPU 内部条件触发：除法错 0 号、单步 1 号、INTO 溢出 4 号、INT n 指令）与**外部中断**（NMI 不可屏蔽中断——内存奇偶错等致命事件；INTR 可屏蔽中断——经 8259A 送来的外设请求）。优先级从高到低：内部中断（除单步）> NMI > INTR > 单步。IF 标志控制 INTR 的响应（CLI 关闭、STI 开放），但关中断挡不住 NMI 与内部中断——"不可屏蔽"的含义正在于此。

## 2. 中断向量表

中断向量表位于内存最低的 1KB（00000H-003FFH），共 256 项，每项 4 字节存入口地址（低字偏移、高字段址），按中断号索引。INT 21H 的向量在 84H 处（21H×4），DOS 启动时写入。两层系统的分工：**BIOS 中断**（INT 10H/16H/13H...）由 ROM-BIOS 提供底层硬件服务，**DOS 中断**（INT 21H）在其上提供文件、内存等高层服务——两层中断体系是 PC 兼容性的基础。向量表直接映射物理地址的事实，使"查表→转移"成为中断响应最直接的解释。

## 3. 中断响应过程

CPU 响应 INTR 时的自动动作（硬件完成）：FLAGS、CS、IP 依次压栈（保护断点）→ 清 IF 和 TF → 读取中断号（8259A 在第二个总线周期送出）→ 查向量表取出入口 → 转移。编写中断服务程序 ISR 的规范步骤：保护现场（PUSH 被用到的寄存器）→ 按需 STI 重新开中断（允许嵌套）→ 处理 → 送 EOI 结束命令给 8259A → 恢复现场 → IRET（弹出 IP/CS/FLAGS）。与子程序调用的本质区别：**中断是被动打断、随时可能发生**，所以 ISR 必须假设"任何寄存器都可能被破坏"，现场保护一个不能少。一个完整模板：

```asm
; 中断服务程序模板（实模式，IRQ 经 8259A 到达）
MY_ISR PROC FAR
       PUSH AX
       PUSH DS
       STI               ; 允许更高优先级中断嵌套
       ; ...服务逻辑...
       MOV AL, 20H
       OUT 20H, AL       ; 向 8259A 发送 EOI 结束命令
       POP DS
       POP AX
       IRET              ; 恢复 FLAGS/CS/IP
MY_ISR ENDP
```

两个细节：**EOI 必须显式发送**——8259A 收到后才解除对该中断级的屏蔽，漏发 EOI 会导致同级中断全部失效（"中断丢死"的经典故障）；PROC FAR 对应远返回，确保跨段返回正确。

## 4. 可编程中断控制器 8259A

8259A 管理外部中断：单片管理 8 级（IR0-IR7），级联最多 9 片 64 级。编程分两阶段：**ICW 初始化字**（ICW1 送 20H 端口、ICW2 送 21H 端口定义中断类型号基址、ICW3 级联配置、ICW4 工作方式）与 **OCW 操作字**（OCW1 屏蔽寄存器 IMR、OCW2 送 EOI 结束命令、OCW3 读取状态）。PC 中的经典配置：ICW2=08H，即 IR0 对应中断类型 08H（系统时钟，每秒 18.2 次）、IR1=09H（键盘）、IR3=0BH（串口）。优先级管理有固定优先级与循环优先级两种，EOI 通知"本次中断服务结束"。还有一个容易被忽视的点：8259A 的端口地址在 PC 上固定为 20H/21H，但 ICW1 与 OCW2/OCW3 共用 20H 端口——区分它们靠写入顺序与指令特征位，这也是可编程接口芯片的通用设计模式。8259A 的全部价值在于：**它把 8 个外设请求合并成一个 INTR 信号，并用中断号告诉 CPU 是谁在请求**——现代 APIC（高级可编程中断控制器）的前身。

## 5. I/O 端口编址

8086 的 I/O 空间独立编址：64KB 端口（0000H-FFFFH），用 IN/OUT 指令访问（IN AL, DX——从 DX 指定的端口读；端口号超过 255 必须用 DX）。与存储器映射 I/O 的对比：独立编址不占用内存空间、指令短（IN/OUT 是单字节指令），但需要专门指令；存储器映射可直接用全部内存指令但占地址空间——两种方案至今并存（x86 用独立编址，ARM 用内存映射）。PC 上著名端口：21H/A0H（8259A）、60H（键盘）、3F8H（串口 COM1）。

## 6. 经典接口芯片速览

- **8255A 并行接口**：三个 8 位端口 A/B/C，方式 0（基本 I/O）、方式 1（选通 I/O，握手信号）、方式 2（双向）；PC 键盘的列选扫描即用 8255A 实现。编程 = 控制字（工作方式）写入 + 端口读写
- **8253/8254 定时/计数器**：三个 16 位独立计数器，六种工作方式（方式 0 计数结束中断、方式 3 方波发生器等）；PC 中计数器 0 接 8259A 的 IR0 产生系统时钟、计数器 1 控制刷新、计数器 2 驱动扬声器
- **8251A 串行接口**：异步/同步串行通信，PC 串口的硬件基础（简识即可）

接口编程的共同模式：**初始化（写控制字）→ 查询状态（读状态字）→ 数据交换**——理解了这个模式，8255/8253/8251 只是参数不同。

## 7. 与操作系统的接缝

中断机制在保护模式下被 IDT（中断描述符表）取代：实模式的向量表入口是 4 字节段:偏移，IDT 的入口是 8 字节门描述符（含特权级检查）；8259A 被 APIC 取代；INT 21H 被系统调用门/指令（Linux 的 syscall）取代。但机制骨架未变：**外设事件 → 中断号 → 查表 → 特权转移 → 处理 → 返回**。理解 8086 中断，等于理解了操作系统"事件驱动"的地基——这也是 07 篇保护模式的桥头堡。

> 🎯 **核心要点**：中断体系回答三个问题——**中断从哪来**（内部/外部、NMI/INTR）、**怎么找到处理程序**（向量表 = 中断号×4 的查表）、**处理完怎么收尾**（EOI + IRET）；8259A 与端口编址把"中断"从软件概念落到硬件实体——这四者的组合（向量表、ISR 规范、8259A、IN/OUT）是"微机原理"实验课的全部核心，也是操作系统中断子系统的 1:1 原型。
