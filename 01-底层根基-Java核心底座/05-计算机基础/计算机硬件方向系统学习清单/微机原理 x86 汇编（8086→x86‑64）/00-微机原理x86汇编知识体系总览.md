## 1. 知识体系导图

```
微机原理 x86 汇编（8086 → x86-64）
│
├── 01-8086 总体结构与工作方式
│     EU/BIU 分工 → 14 个 16 位寄存器 → 20 位物理地址合成 → 总线周期 → 最小/最大模式
│
├── 02-8086 寻址方式
│     七种寻址方式 → 默认段规则 → 物理地址计算 → 与高级语言指针的映射
│
├── 03-8086 指令系统
│     数据传送/算术/逻辑/串操作/控制转移/处理器控制 → MOV 铁律 → 条件转移语义
│
├── 04-汇编语言程序结构
│     伪指令与段定义 → 完整程序模板 → INT 21H 系统调用 → DEBUG 调试 → 宏
│
├── 05-汇编程序设计
│     顺序/分支/循环 → 子程序与四种参数传递 → 模块化 → 算法模板
│
├── 06-中断系统与 I/O 接口
│     中断分类与向量表 → 响应过程 → 8259A → 端口编址 → 8255A/8253 速览
│
├── 07-从 8086 到 x86-64：架构演进路线图
│     80286/80386/80486/Pentium → 保护模式/分页/虚拟 8086 → AMD64 的逆袭
│
├── 08-x86-64 体系结构深潜
│     长模式 → 16 个 64 位寄存器 → RIP 相对寻址 → REX 前缀 → x86-64-v1~v4
│
├── 09-调用约定与工具链实战
│     SysV AMD64 ABI → Windows x64 → 红区/栈帧 → NASM 3.02 → objdump/gdb
│
└── 10-前沿演进与学习路线
       APX R16-R31 寄存器翻倍 → AVX10.2 全核 512 位 → 学习路线与面试题
```

模块间依赖：01 → 02 → 03 → 04 → 05 是严格的 8086 主线（先懂硬件结构，再学会读写程序），也是高校"微机原理"课程的主干；06 是硬件接口面（中断与 I/O）；07 把视野拉向 32 位架构演进；08/09 是 2026 年现代 x86 的落地面（长模式、ABI、工具链）；10 收束前沿（APX/AVX10）与学习路线。与同级 `计算机组成原理（重中之重）/` 互补（那里讲通用体系结构，这里专讲 x86 一脉）；与 `操作系统硬件关联部分（软硬件交界）/` 构成对照（中断、保护模式、进程切换在那里从 OS 视角复现）。

## 3. 学习路线推荐

**路线 A：读懂任何 8086 汇编（1 天）**
01 → 02 → 03。先掌握硬件结构和指令语义，就能读懂王爽《汇编语言》前 10 章的绝大多数程序——适合"只想看懂汇编"的开发者。

**路线 B：微机原理应试主线（2-3 天，推荐）**
路线 A + 04 + 05 + 06。补齐程序编写与接口实验面，覆盖高校《微机原理与接口技术》课程主干：段寻址计算、指令系统、程序设计、中断与 8259A。

**路线 C：现代 x86 体系（进阶）**
01-05 快读（跳过 06 的实验细节）+ 07 → 08 → 09 → 10。从架构演进理解"为什么 x86-64 长这样"，再落 ABI 与工具链实战——这是 2026 年做底层优化、安全分析、OS 内核开发的必经之路。

> 💡 与知识库关系：07 篇保护模式/分页与 `操作系统硬件关联部分（软硬件交界）/` 深度互补；09 篇 ABI 与 `需要掌握的关键硬件‑软件映射/` 的调用链视角呼应；10 篇向量指令与 `GPU 硬件架构/` 对照（x86 是 SIMD、GPU 是 SIMT）；`RISCV 基础（了解即可）/` 可作为对照系——RISC 的简洁 vs x86 的兼容包袱。

### 阅读时的三个常见误区

1. **"汇编已死，不用学"**：编译器的确生成了 99% 的汇编，但"看懂汇编"依然是调试崩溃、反汇编分析、性能优化、安全漏洞研判的底层能力——2026 年的 ABI、APX、ROP 攻击研究全部发生在汇编层面
2. **"8086 是过时古董"**：8086 的段寻址、指令集、中断机制是现代 x86 的完整胚胎——x86-64 的每个特性都能在 8086 里找到前身（REX 前缀之于段超越前缀、长模式之于保护模式）
3. **"学完 8086 就等于学会现代汇编"**：差得远——8086 是 16 位分段模型，现代 x86-64 是 64 位扁平寻址 + ABI 约定，07/08/09 篇的跨越才是关键；只学 8086 不学 ABI，等于只学了"单词"没学"语法"

## 4. 核心概念速查

| 概念 | 一句话定义 | 关键事实（2026） |
|------|-----------|---------------------|
| 8086 | x86 家族起点，16 位 CPU | 1978-06-08 发布，售价 $86.65，5 MHz |
| 物理地址 | 段地址×16+偏移地址合成 | 20 位寻址 1MB，段起始 16 字节对齐 |
| 段寄存器 | CS/DS/SS/ES 四段 | 段最大 64KB，BIU 内地址加法器合成 |
| 预取队列 | BIU 提前取指令 | 6 字节队列，取指与执行重叠 |
| 寻址方式 | 操作数定位规则 | 七种，无比例缩放（80386 才有） |
| MOV 铁律 | 数据传送的限制 | 不能 mem→mem、立即数不能送段寄存器 |
| 中断向量表 | 中断入口索引 | 1KB 存 256 个入口，每项 4 字节 |
| 8259A | 可编程中断控制器 | 单片 8 级，级联 64 级 |
| 保护模式 | 80286 引入的隔离机制 | 80386 完善：分页+特权级+虚拟 8086 |
| 虚拟 8086 | 保护模式里跑 8086 程序 | Windows 3.x/95 的 DOS 虚拟机核心 |
| 长模式 | x86-64 的核心模式 | = 64 位模式 + 兼容模式 |
| RIP 相对寻址 | 相对指令指针寻址 | PIC 代码基石，x86-64 默认 |
| REX 前缀 | 64 位扩展前缀 | W/R/X/B 四位置，寄存器 8→16 |
| SysV ABI | Unix 系调用约定 | rdi/rsi/rdx/rcx/r8/r9 传参，128 字节红区 |
| x86-64-v3 | 微架构级别第三档 | ≈Haswell：AVX2/FMA/BMI；v4 才含 AVX-512 |
| APX | 下一代 x86 扩展 | R16-R31 寄存器翻倍，2026 末首发 |
| AVX10.2 | 向量指令收敛版 | Nova Lake 全核 512 位，2026 首发 |

> 🎯 **核心要点**：这套体系的全部矛盾压缩为一句话——**x86 用四十六年做了一件事：把 8086 的"窄寄存器 + 分段寻址"不断加宽、加模式、加兼容层，直到 2026 年的 APX 把通用寄存器翻倍到 32 个；学它的正确姿势是从 8086 的种子出发，看它如何长出 x86-64 这棵大树，而不是把两者当两门课**。

### 体系速读版（30 秒版）

- **8086 长什么样**：16 位寄存器 + 20 位地址总线，段×16+偏移合成物理地址（01 篇）
- **怎么读写程序**：七种寻址方式 × 六类指令 → 三种程序结构 + 子程序（02-05 篇）
- **怎么与外部对话**：中断向量表 + 8259A + I/O 端口（06 篇）
- **中间发生了什么**：80286 保护模式 → 80386 分页与虚拟 8086 → AMD64 长模式（07 篇）
- **现代 x86 长什么样**：16 个 64 位寄存器、RIP 相对寻址、SysV/Windows ABI（08-09 篇）
- **下一步是什么**：APX 寄存器翻倍、AVX10.2 全核 512 位（10 篇）
