## 4. 核心概念速查

| 概念 | 一句话定义 |
|---|---|
| 冯诺依曼结构 | 存储程序 + 程序控制：指令与数据同存、按地址访问、顺序执行 |
| 存储程序原理 | 程序预先存入存储器，机器自动逐条取指执行 |
| 层次结构 | 寄存器→Cache→主存→辅存，速度递减、容量递增、价格递减 |
| 局部性原理 | 时间局部性（近期访问会再访问）+ 空间局部性（邻近地址会访问） |
| 原码/补码 | 补码 = 原码取反加一，统一加减运算，溢出可检测 |
| IEEE 754 | 浮点标准：符号+阶码(移码)+尾数，单精度 32 位/双精度 64 位 |
| CPI | 每条指令平均时钟周期数，性能 = 指令数 × CPI × 时钟周期 |
| Amdahl 定律 | 加速比受不可并行部分限制：S = 1/((1-f)+f/n) |
| 数据通路 | 指令执行的物理路径：寄存器、ALU、总线、多路选择器的连接 |
| 流水线冒险 | 结构/数据/控制三类冒险破坏流水线连续流动 |
| DMA | 外设与内存直接交换数据，不经过 CPU 逐字干预 |
| CXL 3.2 | 2026 量产的内存扩展协议：内存池化、分层内存（PCIe 6.0 承载） |

### 5.1 学习本体系的三条原则

第一，**结论必须能推导**：补码为什么这样设计、Cache 为什么用组相联、Amdahl 为什么是上限——每个结论背后都有"硬件约束 → 设计选择 → 权衡"的推理链，背结论在面试一问"为什么"就露馅。第二，**画图胜过看文**：冯诺依曼结构图、单周期数据通路图、流水线时空图是三个必画图，画出来才算真懂——文字描述会掩盖结构理解的缺失。第三，**新旧对照学**：每个经典机制都找一个现代对应物（Cache 映射 → CPU 实际配置、总线 → PCIe 6.0、控制器 → x86 µop 翻译），新旧对照让经典知识活起来，也让前沿问题有根基。三条原则贯穿本体系全部 11 篇。

## 6. 常见误区速排

| 误区 | 事实 |
|---|---|
| "组成原理过时了" | 2026 前沿（CXL/PCIe6/Chiplet）全部建立在经典结构之上 |
| "和 CSAPP 体系重复" | 本体系是硬件视角主课，CSAPP 是软件视角，互补 |
| "背结论就行" | 组成原理考的是"为什么"，每个结论都要能推导 |
| "硬件和 Java 无关" | 数组/Cache、伪共享、零拷贝全是组成原理的直接输出 |

> 🎯 **核心要点**：组成原理主课 = 一条主线（指令如何被机器执行）+ 三大支柱（存储层次/Cache/流水线决定性能）+ 2026 锚点（CXL 内存池化/PCIe 6.0/DDR5 8000MT/s/Chiplet）。与 CSAPP 体系的分工：那边讲"程序视角的系统"，这边讲"硬件视角的机器"——两套合起来才是完整图景。学习顺序建议"正向建框架、反向找考点"。
