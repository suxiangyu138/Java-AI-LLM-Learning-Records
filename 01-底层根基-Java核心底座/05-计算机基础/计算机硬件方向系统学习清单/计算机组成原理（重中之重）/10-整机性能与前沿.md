## 1. 性能模型：Amdahl 与 CPI

Amdahl 定律是性能优化的"第一不等式"：

```text
S = 1 / ((1 - f) + f/n)
f = 可并行/可加速部分占比，n = 加速倍数

推论 1：f=0.9、n=∞ → S=10（上限被不可加速的 10% 锁死）
推论 2：先优化占比最大的部分（f 最大项）
```

CPI 模型把性能拆成可优化的三个因子：

```text
CPU 时间 = 指令数 × CPI × 时钟周期
  指令数 ← 编译器与 ISA（RISC 指令多但简单）
  CPI ← 流水线/超标量/Cache（08/05 篇）
  时钟周期 ← 工艺/微架构深度
```

两个模型的工程含义：**Amdahl 决定"优化哪里"**（先动占比大的）、**CPI 模型决定"怎么度量"**（指标拆解到可行动作）。组合使用：先 Amdahl 定方向，再 CPI 逐项优化，最后实测验证。

## 2. 并行体系分类

Flynn 分类法（指令流 × 数据流）：

| 类型 | 含义 | 代表 |
|---|---|---|
| SISD | 单指令单数据 | 传统单核 CPU |
| SIMD | 单指令多数据 | 向量单元、GPU（SIMT 变体） |
| MISD | 多指令单数据 | 冗余容错系统（罕见） |
| MIMD | 多指令多数据 | 多核 CPU、多机集群 |

并行的两种粒度：**指令级并行（ILP，单核内流水线/超标量）与线程级并行（TLP，多核/多机）**。现代系统是混合：多核 MIMD 每个核内部又用 ILP，GPU 用 SIMD 大规模并行——"并行不是一种技术，是一个连续谱"。

## 3. 多核与异构

| 形态 | 说明 | 2026 现状 |
|---|---|---|
| 同构多核 | 相同核心（x86 多核） | 主流 |
| 大小核异构 | 高性能核 + 能效核（ARM big.LITTLE） | Intel/AMD 跟进（P/E 核） |
| 异构计算 | CPU + GPU + NPU 各司其职 | AI 时代标准配置 |
| Chiplet | 多芯片先进封装（2.5D/3D） | 龙芯龙链、AMD EPYC、Intel 均采用 |

异构计算的核心思想：**每个工作负载形态配最合适的计算单元**——通用逻辑走 CPU、并行向量走 GPU、矩阵运算走 NPU。Chiplet 的意义：**用成熟制程拼出高性能**（小芯片各自最优工艺，再封装互连），降低对单一先进制程的依赖——2026 年国产 CPU 的重要技术路径。

## 4. 2026 硬件前沿

| 技术 | 状态 | 影响 |
|---|---|---|
| CXL 3.2 | 2026-07 澜起试产 MXC | 内存池化/分层内存，突破单机容量墙 |
| PCIe 6.0 | 64 GT/s（PAM4） | I/O 总线新基线，CXL 的物理层 |
| DDR5 | 最高 8000 MT/s | 主存基线 |
| HBM | AI 服务器标配 | GPU 显存主力，3D 堆叠 |
| Chiplet | 国产/国际厂商全面采用 | 降低制程依赖，提升集成度 |
| RISC-V | 嵌入式/边缘崛起 | ISA 开源，打破私有指令集垄断 |
| 存算一体 | 研究到早期产品 | 消灭数据搬运，AI 推理先行 |

趋势主线一句话：**内存与互连成为新瓶颈，系统级设计（内存池化/异构/Chiplet）取代单部件优化**——组成原理的"结构决定性能"在这一轮被放大到系统尺度。

## 5. 组成原理与软件工程

组成原理对 Java 后端工程师的七个直接落点：

```text
① 数据布局 = Cache 命中率（数组 vs 链表）
② 分支预测 → 有序数据遍历快
③ 伪共享 → @Contended / padding
④ 内存带宽 → 大对象/批量处理要避免缓存污染
⑤ DMA/中断 → NIO/Netty 零拷贝的硬件基础
⑥ 存储层次 → 缓存设计（本地缓存 > Redis > DB 的硬件逻辑）
⑦ 指令集 → JIT 编译（C2/Graal）做机器码优化的依据
```

结论：**后端优化的每一次"反直觉"（数组比链表快、有序比随机快、零拷贝快），根因都在组成原理**——这是本体系对"Java 后端 + AI"知识栈的最终输出。

### 5.1 2026 前沿的组成原理读法

前沿技术都可以用本体系的经典框架"翻译"：CXL 内存池化 = 存储层次的横向扩展（层次从"机器内"延伸到"系统内"）；Chiplet = 系统级的分层设计（总线互连思想在多芯片间复用）；存算一体 = "计算下移"的激进形态（存储墙应对的第三招）；RISC-V = ISA 层的开源（06 篇 ISA 兼容性讨论的新变量）；PCIe 6.0 = 总线带宽的又一轮翻倍（09 篇总线性能公式的应用）。这种"翻译"能力是学习前沿的最快路径：**经典框架给坐标，前沿技术只是坐标上的新点**——这也是本体系名为"重中之重"的原因：它是理解一切硬件新事物的坐标系。

补充一个判断工具：**用"瓶颈位置"给前沿技术分类**——CXL 解决容量/池化（存储瓶颈）、HBM 解决带宽（带宽瓶颈）、Chiplet 解决制造/集成（工艺瓶颈）、存算一体解决搬运（能耗瓶颈）、RISC-V 解决生态/成本（商业模式瓶颈）——每个前沿都对应一个具体瓶颈，判断一项技术是否重要，先问"它解决哪个瓶颈"。

### 5.2 性能工程的闭环

把本体系所有性能知识收拢成一个闭环：**度量（CPI 模型与实测）→ 定位（Amdahl 找占比大的项）→ 优化（存储层次/Cache/流水线/并行四张牌）→ 验证（回到度量）**。这个闭环在硬件与软件层通用——Java 性能优化的"先测再调"与 CPU 设计的"先建模再优化"是同一个方法论。掌握闭环 = 掌握性能工程的通用能力，这也是 10 篇作为收尾篇的用意：前面 9 篇是牌，这一篇是打法。

## 6. 常见误区速排

| 误区 | 事实 |
|---|---|
| "加核一定加速" | Amdahl：不可并行部分锁死上限 |
| "Chiplet 是偷工减料" | 成熟制程拼高性能，降低对单一先进制程依赖 |
| "存算一体已成熟" | 仍处研究到早期产品阶段，AI 推理先行 |
| "前沿与经典无关" | CXL 建立在 PCIe 上，PCIe 建立在总线上——经典是地基 |
