## 3. 学习路线推荐

**路线 A：搞懂"RISC-V 是什么"（半天，本体系定位）**
01 → 02 → 03 → 04。从哲学到骨架到 ABI——适合所有后端工程师建立"第三条指令集"的认知，读懂新闻与选型不再靠猜。

**路线 B：系统了解（1-2 天，推荐）**
路线 A + 05 + 08 + 10。补上特权架构、软件生态与学习路径，形成"能跑 OS、能用工具链"的完整图景。**配合 `微机原理 x86 汇编/` 对照阅读**，把两套指令集的差异用已学的 x86 知识锚定。

**路线 C：AI 与国产化视角（面向 AI 工程师/关注自主可控）**
路线 B + 06 + 07 + 09。聚焦 2026 年的核心叙事：RVV/Matrix 单核跑 AI、CoVE 机密计算、玄铁/香山国产服务器芯——**与 `GPU 硬件架构/`、`NPU 概念/` 对照阅读**，理解"CPU 重回 AI 计算 C 位"的底层逻辑。

> 💡 与知识库关系：03 篇的 ABI 与 `微机原理 x86 汇编/` 的调用约定对照记忆；05 篇的特权级与 Linux 体系交叉；06 篇向量与 `深度学习/`、`NPU 概念/` 呼应；09 篇玄铁 C930 与 `量化背后硬件约束/` 的 INT4/FP8 引擎数字共享同一套规格。

### 阅读时的三个常见误区

1. **"RISC-V 是又一个开源处理器"**：RISC-V 不是处理器、不是芯片，而是**指令集规范（ISA）**——它不定义微架构，只定义"软件与硬件的接口契约"。开源的是规范，处理器实现可以是开源的（香山）也可以是商业闭源的（SiFive、玄铁）——01/02 篇
2. **"指令集越强越好"**：RISC-V 的哲学恰恰是"越少越好"——基础指令集只有四十多条，功能全由扩展叠加（向量、原子、浮点、压缩）。指令少 = 硬件简单 = 实现自由度大，性能来自微架构而非指令集——01/02/04 篇
3. **"RISC-V 会取代 x86/ARM"**：2026 年的现实是三种架构并行——x86 统治服务器存量、ARM 统治移动端、RISC-V 从嵌入式与边缘 AI 切入并向上蚕食，2026 年才刚摸到服务器门槛（RVA23 服务器规范 1.0 发布）。取代是十年尺度的话题，"了解即可"恰恰是最合适的姿态——09/10 篇

带着三个误区读完全书，会发现每一篇都在回答同一个问题：**一个免费、简洁、模块化的指令集，凭什么在 2026 年成为三大核心赛道的主角**。

## 4. 核心概念速查

| 概念 | 一句话定义 | 关键事实（2026） |
|------|-----------|---------------------|
| ISA | 指令集架构，软硬件契约 | RISC-V 规范免费开放，任何人可实现 |
| RV64I | 64 位基础整数指令集 | 32 个 GPR、40+ 条指令、六种格式 |
| 扩展字母表 | M/A/F/D/C/V/H 等模块 | 组合字符串 = 处理器"身份证" |
| RVA23 | 应用处理器 profile（2024 批准） | 2026 "RVA 芯片元年"：强制 RVV+虚拟化 |
| ABI | 应用程序二进制接口 | a0-a7 传参、a0 返回、s 寄存器被调者保存 |
| 特权级 | M/S/U 三层硬件权限 | M 跑固件/SBI、S 跑内核、U 跑应用 |
| SBI | 监督者二进制接口 | OpenSBI 是 M 模式固件事实标准 |
| RVV 1.0 | 向量扩展 | VLEN 可配置；玄铁 512-bit + 8 TOPS Matrix |
| CoVE | 机密虚拟机扩展 | 对标 AMD SEV/Intel TDX，2026 推进 1.0 |
| PMP | 物理内存保护 | 无 MMU 场景的 TEE 基础原语 |
| 空间多线程 | 静态分区的 SMT 替代 | 玄铁 2026-07 发布，上下文切换 -23% |
| 玄铁 C950 | 国产服务器级 CPU IP | SPECint2006 >70，对标 Neoverse V2 |
| 香山 | 开源高性能处理器 | 昆明湖 V3 三方联合研发（2026-03） |

> 🎯 **核心要点**：RISC-V 的全部叙事压缩为一句话——**一个把"指令集"从商业授权变成开放规范的免费标准，用"极简基础 + 模块化扩展"同时满足从单片机到服务器的全部需求，2026 年借 RVA23 统一碎片化、借向量扩展切入 AI、借自主可控吃下国产化红利**；"了解即可"的定位，是让你拥有第三条路线的判断力，而不是成为汇编专家。

**"我是 Java 后端，学 RISC-V 有什么用？"** 三层价值：读懂选型（信创项目与云厂商的 CPU 决策）、看懂新闻（2026 年 RISC-V 报道密度剧增）、建立"指令集-编译器-运行时"的底层认知——与 JVM 的字节码-解释器分层是同一思维模型，10 篇的学习路径适合周末入门。

**"RISC-V 和单片机（STM32/ESP32）什么关系？"** 单片机是芯片形态，RISC-V 是指令集——2026 年大量新 MCU 已采用 RISC-V 核（低成本、免版税），ARM Cortex-M 的替代叙事正在展开；嵌入式是 RISC-V 份额最大、最成熟的领地，33.7% 的 2031 年份额预测底色就来自这里（09 篇）。

**"中国为什么力推 RISC-V？"** 三重逻辑：架构主权（无出口管制风险、规范可审计，07 篇）、成本（免授权费，芯片成本结构直接优化）、生态机遇（x86/ARM 的存量已固化，新架构才有重新洗牌的空间）——玄铁与香山的量产是这三重逻辑的落地（09 篇）。

**"RISC-V 的指令集规范看什么版本？"** 规范的"版本"有两层：ISA 规范本身的版本（如 RV64I 2.1、RVV 1.0，每份规范独立编号）与 profile 版本（RVA22/RVA23，规定组合基线）——看芯片参数时认 profile（RVA23 是 2026 年应用处理器的及格线），看指令细节时认各规范版本号；两者都可在 RISC-V 官网免费查阅。

**"学完这套体系，能直接写 RISC-V 汇编吗？"** 能读、能改、能写简单程序（03/04 篇给了骨架与解码方法），但完整汇编能力需要 10 篇学习路径的动手阶段——本体系的承诺是"判断力"：读懂反汇编、看懂新闻、答得出面试；动手深度留给 RARS 模拟器与真实硬件（Milk-V 等几百元开发板）。

### 体系速读版（30 秒版）

- **为什么有它**：x86/ARM 的指令集授权封闭，2010 年 Berkeley 决定"重做一遍"（01 篇）
- **长什么样**：40+ 条基础指令 + M/A/F/D/C/V/H 扩展 + 32 个寄存器（02/03/04 篇）
- **凭什么能跑 OS/AI/机密**：M/S/U 特权级（05）、RVV 向量（06）、PMP/CoVE（07）
- **2026 现状**：RVA23 芯片元年、服务器规范 1.0、Ubuntu 全面支持、玄铁批量出货（08/09 篇）
- **怎么学**：RARS 模拟器入门 → QEMU 跑 Linux → 对比 x86 汇编收束（10 篇）
