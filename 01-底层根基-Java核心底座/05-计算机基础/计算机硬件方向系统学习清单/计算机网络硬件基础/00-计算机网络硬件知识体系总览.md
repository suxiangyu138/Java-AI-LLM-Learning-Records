## 3. 学习路线推荐

**路线 A：入门速成（半天）**
01 → 02 → 03 → 04。建立"网络 = 硬件链路 + 每站转发决策"的心智模型：数据从网卡出发，走什么线，过哪些交换机，最终到达对端网卡；能看懂链路速率、交换容量、线速等数字。

**路线 B：系统进阶（2-3 天，推荐）**
01 → 02 → 03 → 04 → 05 → 07 → 11 全链路。理解交换机为什么能"线速转发"而 CPU 不行、网卡卸载到底卸掉了什么、DPDK/XDP 解决什么问题、服务器网络性能从哪来。这是后端工程师排查"网络慢、CPU 中断高、连接数上不去"的根本弹药。

**路线 C：AI 集群与前沿深化（AI / 后端工程师）**
在路线 B 基础上加 06、08、09、10：WiFi 7/8 硬件、RDMA 与 RoCE、DPU 为什么成为第三大计算支柱、800G 光模块与叶脊拓扑、UEC 与 InfiniBand 之争。这是面试"AI 集群网络架构""为什么训练要 InfiniBand""DPU 是什么"的弹药库。

> 💡 与知识库其他模块的关系：本体系讲"网络硬件设备"，`02-.../运维/网络问题排查` 讲"网络故障排查方法论"，`02-.../09-Web开发全流程/Web 高阶知识` 讲"HTTP/TLS 等协议层"，`01-.../计算机组成原理` 讲 CPU/内存等计算硬件——四者互补：硬件提供物理基础，协议决定行为，排查与 Web 知识在应用层运用。`05-计算机基础/计算机硬件方向系统学习清单/` 下的 PCIe 带宽、存储硬件（NVMe-oF 与 RDMA 相关）、操作系统硬件关联部分与本体系直接衔接。

## 4. 核心概念速查

| 概念 | 一句话定义 | 关键数据/要点 |
|------|-----------|--------------|
| 线速转发 | 端口满速率转发而不丢包 | 64B 小包下 100G 端口需约 148.8 Mpps |
| 交换容量 | 交换机所有端口带宽之和 | 2026 单芯片最高 102.4 Tbps（Tomahawk 6） |
| MAC 地址 | 数据链路层 48 位标识 | OUI 前 24 位归厂商；交换机靠它自学习转发 |
| 自学习 | 交换机学习源 MAC 建表 | 表项老化默认 300s；未命中则泛洪 |
| VLAN | 二层广播域划分 | 标准 0-4095，Trunk 携带 802.1Q 标签 |
| LPM | 最长前缀匹配路由查找 | 硬件用 TCAM 或前缀树实现，纳秒级查表 |
| 控制面/数据面 | 路由计算 vs 逐包转发 | 数据面必须线速，故用 ASIC 而非 CPU |
| 卸载 Offload | 把包处理从 CPU 挪到网卡 | checksum/TSO/GRO/RSS 是四大基础卸载 |
| RSS | 接收侧多队列散列 | 按五元组哈希分队列，配多核并行收包 |
| 中断聚合 | 攒一批包再中断一次 | 高 PPS 下降低 CPU 开销，牺牲少量延迟 |
| 内核旁路 | 绕过内核协议栈直接收包 | DPDK 用户态驱动可达数千万 PPS |
| RDMA | 远程内存直接访问 | 内核旁路+零拷贝+网卡卸载，微秒级延迟 |
| RoCEv2 | RDMA over 以太网 | UDP 封装；依赖 PFC/ECN 实现无损 |
| DPU | 数据处理单元 | Arm 核+网络引擎+加速器；BlueField-4 达 800Gb/s |
| 叶脊拓扑 | 两层全互联 Clos 网络 | 任意两点最多经 2 跳，ECMP 全链路负载 |
| 光模块 | 电-光转换可插拔器件 | 2026：800G 出货约 4000 万只，1.6T 元年 |
| 硅光/LPO/CPO | 光互联三种演进路线 | LPO 去 DSP 降功耗 50%；CPO 与芯片共封装 |
| PAM4 | 4 电平脉冲调制 | 一个符号 2 bit；100G 起全线采用 |
| SerDes | 串行收发器 | 2026 主流 112G/224G 每通道 |
| WiFi 7 | 802.11be | 320MHz+4096-QAM+MLO，理论峰值 46Gbps |
| WiFi 8 | 802.11bn（UHR） | 重可靠性不重峰值；标准预计 2028 年完成 |
| 胖树 | 越靠根链路越粗的无阻塞架构 | 1:1 收敛比下任意端口全速互达 |
| MLO | WiFi 7 多链路操作 | 同时用多个频段，降延迟抗干扰 |
| PFC | 优先级流控 | RoCEv2 无损网络基石，但易引发队头阻塞 |
| ECMP | 等价多路径 | 叶脊网络把所有链路同时用满的关键 |
| Jumbo Frame | 巨型帧 | MTU 9000 减少包数，PPS 压力大减 |

> 🎯 **核心要点**：网络硬件的全部设计由三个物理事实驱动——**线速要求**（每端口必须满速率转发，CPU 逐包处理远不够，所以用专用 ASIC）、**成本-延迟-带宽三角**（铜、光、无线各有距离甜区，数据中心按距离分层选介质）、**CPU 税**（每收一个包都要消耗主机 CPU 周期，从卸载、多队列到 DPU，全部优化本质上都是"把包处理从 CPU 挪走、或让 CPU 处理得更便宜"）。理解了这三点，整个体系的设备、芯片、协议就串成了一条线。

## 5. 概念层次辨析与面试速览

**四层概念辨析**（网络硬件领域最大的术语混乱来源，务必分清）：

| 层次 | 含义 | 例子 | 辨析要点 |
|------|------|------|---------|
| 介质 | 比特的物理载体 | 双绞线、光纤、空气 | 决定速率与距离的物理上限 |
| 器件 | 独立物理单元 | 光模块、网卡、天线 | 可插拔、可更换 |
| 设备 | 完成网络功能的整机 | 交换机、路由器、AP | 由器件+芯片+软件组成 |
| 接口/协议 | 设备间的约定 | 以太网、PCIe、RoCE | 硬件之上的契约，决定兼容性 |

典型混淆：把"网卡速率"当成"网络带宽"（网卡 100G 只是主机出口，跨机房仍是百 G 骨干）、把"光模块速率"当成"光纤速率"（同样一根 OS2 光纤，模块从 100G 换到 1.6T 不用换线）、把"交换机交换容量"当成"端口速率之和"（还要看是否线速、单端口满配）。

## 6. 版本基准与术语对照

**2026-08 版本基准**（本体系所有数据以该基准为准）：以太网 800G 规模部署（IEEE 802.3df）、1.6T 商业化元年（802.3dj 推进中）；交换芯片 Broadcom Tomahawk 6（102.4T）量产出货、Tomahawk 7（200T）流片中；NIC：NVIDIA ConnectX-8/Thor Ultra 800G、华为 SP560、Intel E835；DPU：BlueField-4（2026-01 发布）、AMD Pensando Salina、Intel IPU E2200、AWS Nitro v6；AI 网络：UEC 1.0 已发布、硬件 2026-2027 出货，Spectrum-X 800G 已出货；WiFi：7 已正式定标（802.11be，2025-07）、8 处于标准阶段（802.11bn，预计 2028 年完成）；光模块：800G 年出货约 4000 万只、硅光 1.6T 份额约 72%、LPO 商用、CPO 2027 年后规模化。

## 8. 各篇一句话记忆点

| 篇目 | 一句话记忆点 |
|------|------------|
| 01 全景 | 网络硬件 = 五类设备 × 三条约束（线速/介质极限/CPU 税），控制面软件思考、数据面硬件转发 |
| 02 介质 | 光进铜退但分层共存：DAC 守机柜内、Cat6A 守接入、多模守机房、单模守骨干 |
| 03 网卡 | 四大卸载（checksum/TSO/GRO/RSS）是主机网络性能的全部来源 |
| 04 交换机 | 自学习 + ASIC 流水线 = 免配置的线速转发；2026 芯片 102.4T |
| 05 路由器 | LPM/TCAM 纳秒查表是"线速路由"的唯一物理答案 |
| 06 无线 | 介质共享让"实测 < 峰值"是常态；WiFi 8 从更快转向更稳 |
| 07 加速 | 卸载谱系：硬件卸载 → XDP → DPDK → RDMA；粒度宁小勿大 |
| 08 DPU | 用一颗专用芯片换回十几颗通用核；第三大计算支柱 |
| 09 AI 网络 | RDMA 三实现 + 无损保障 + GPUDirect；IB/Spectrum-X/UEC 三角竞争 |
| 10 数据中心 | 叶脊等距 + ECMP 全链路工作；800G 光模块是最硬瓶颈 |
| 11 度量 | 五指标先分型再查因；80% 的"网络慢"是主机配置问题 |
