## 1. 快捷键学习的三个阶段

> **背景**：快捷键不是「背下来」而是「用出来」——分阶段养成肌肉记忆。
> **目的**：制定可持续的学习路线，避免「背了 100 个用了 5 个」。
> **适用范围**：任何快捷键学习者。
> **不适用场景**：追求立即全部掌握（不现实——按需渐进）。

```text
三阶段学习法
├── 第一阶段：生存（第 1 周）——高频 7 个
│   Ctrl+C/V/Z、Alt+Tab、Win+E、Win+Shift+S、Ctrl+Shift+Esc
│   目标：基本操作键盘化（每天用）
├── 第二阶段：提效（第 2-4 周）——每类 10 个
│   ① 文本编辑：词级选择/移动/查找
│   ② 系统：Win+R/D/L、分屏
│   ③ IDE：导航/重构/搜索
│   目标：核心工作流键盘化（每周加 3-5 个）
└── 第三阶段：精通（持续）——按需扩展
    ① 终端：Ctrl+R/补全
    ② 浏览器：标签/DevTools
    ③ 个性化：AutoHotkey/PowerToys
    目标：90% 操作不碰鼠标（盲操作）

核心原则
├── ① 每周只加 3-5 个（不贪多）
├── ② 刻意不用鼠标：卡住时查快捷键而非点鼠标
├── ③ 频率驱动：先学高频（每天用的），低频按需
└── ④ 复盘：每周回顾「哪个操作还在用鼠标」→ 查对应快捷键
```

## 2. 冲突处理

### 2.1 冲突的来源

```text
快捷键冲突三大来源
├── ① 应用间冲突：同一快捷键不同含义
│   └── Ctrl+D：浏览器收藏 vs IDE 多光标
├── ② 输入法抢占：Ctrl+Space（中英切换）等被输入法占用
├── ③ 全局工具冲突：截图软件/录屏软件占用系统键
└── 金句：冲突不可避免——关键是「知道冲突在哪 + 会调整」
```

### 2.2 冲突排查与解决

```text
冲突排查四步
├── ① 确认现象：快捷键没反应/触发错误功能
├── ② 定位抢占者：逐个关闭可疑应用测试
├── ③ 检查输入法：快捷键被输入法拦截（最常见！）
│   └── 输入法设置 → 按键设置 → 关闭/改键
├── ④ 应用内调整：改自定义快捷键（见第 3 节）
└── ⑤ 全局工具检查：截图/录屏/手势软件占用

典型冲突解决
├── 微信 Alt+A 截图 vs IDE：微信设置改快捷键
├── 输入法 Ctrl+Space vs IDE 补全：输入法改 Ctrl+Shift
├── VS Code Ctrl+Shift+P vs 中文输入法：输入法设置
└── 录音软件 F8/F9 vs 系统：软件内修改
```

## 3. 应用内自定义

### 3.1 IDE 自定义（IDEA / VS Code）

```text
IDEA 自定义（Settings → Keymap）
├── ① 搜索快捷键：Keymap 界面 Ctrl+F 搜索
├── ② 修改：右键操作 → Add Keyboard Shortcut
├── ③ 冲突检测：设置时自动提示冲突（红色标记）
├── ④ 常用修改：Ctrl+Shift+F 全局搜索等
├── ⑤ 导出/导入：File → Export Settings（换机同步）
└── ⑥ 预设方案：VS Code 风格/ReSharper 风格切换

VS Code 自定义（File → Preferences → Keyboard Shortcuts）
├── ① Ctrl+K Ctrl+S 打开快捷键面板
├── ② 搜索操作 → 点击铅笔图标 → 输入新快捷键
├── ③ keybindings.json 高级配置（when 条件）
├── ④ 冲突显示：面板中红色表示冲突
└── ⑤ 键位方案：keymap 扩展（IntelliJ/Atom 风格）
```

### 3.2 浏览器与其他

```text
浏览器自定义
├── Chrome：chrome://extensions/shortcuts（扩展快捷键）
├── 内置快捷键不可改（多数）
├── Edge 同理（内核相同）
└── 替代：用扩展实现自定义（Vimium 等）

系统级自定义
├── Windows：PowerToys（见第 5 节）
├── 第三方：AutoHotkey（见第 4 节）
└── 键盘厂商：雷蛇/罗技驱动（宏键/自定义键）
```

## 4. AutoHotkey：自定义快捷键

### 4.1 什么是 AutoHotkey

> **背景**：AutoHotkey（AHK）是 Windows 自动化脚本工具——把任意键组合映射为任意操作（甚至宏/自动化）。
> **目的**：突破应用限制，实现系统级自定义快捷键。
> **适用范围**：Windows 重度用户/高频重复操作的自动化。
> **不适用场景**：仅需少量修改（PowerToys 更简单）；macOS（用 Karabiner-Elements）。

### 4.2 基础脚本

```ahk
; 常用快捷键重映射（myhotkeys.ahk）
; 用 CapsLock 组合（避开输入法冲突）
CapsLock & h::Send {Left}          ; CapsLock+h = 左移（Vim 风格）
CapsLock & j::Send {Down}          ; CapsLock+j = 下移
CapsLock & k::Send {Up}
CapsLock & l::Send {Right}

; 快捷键直达（Win+Space 打开终端）
#Space::Run wt

; 常用文本展开（缩写 → 完整）
::br::最佳实践
::todo::TODO: 待办事项

; 窗口操作
#Up::WinMaximize, A              ; Win+↑ 最大化
!x::WinClose, A                  ; Alt+x 关闭窗口
```

### 4.3 实战场景

```text
AutoHotkey 的实战价值
├── ① 系统级快捷键统一：让所有应用行为一致
├── ② 避开输入法冲突：用 CapsLock 组合替代 Ctrl 组合
├── ③ 文本展开：常用代码/文字缩写秒出
├── ④ 窗口管理自动化：快捷键控制窗口布局
├── ⑤ 启动器：快捷键直达常用工具
└── ⑥ 防止误触：CapsLock 改功能键（很多人从不使用 CapsLock）

使用注意
├── ⚠️ 脚本开机自启：Startup 文件夹放 .ahk 或编译 exe
├── ⚠️ 冲突管理：AHK 映射与系统冲突时 AHK 优先
├── ⚠️ 学习成本：语法简单但需时间
└── ✅ 2026 现状：AHK v2 已成熟（推荐 v2 语法）
```

## 5. PowerToys：微软官方效率工具

### 5.1 PowerToys 是什么

> **背景**：微软官方开源效率工具集——2026 已集成多项生产力功能。
> **目的**：系统级增强（分屏/启动器/取色/批量重命名）。
> **适用范围**：Windows 10/11 用户。
> **不适用场景**：功能已被系统覆盖的场景。

### 5.2 核心模块（快捷键相关）

```text
PowerToys 核心模块（2026）
├── ① FancyZones：分屏布局管理器
│   ├── 自定义分屏区域（Win+Shift+方向 或 Shift+拖拽）
│   ├── 预设布局（编辑器+终端+浏览器组合）
│   └── 比系统分屏更灵活（任意区域大小）
├── ② PowerToys Run：快速启动器（Alt+Space）
│   ├── 启动应用/搜索文件/计算器/命令
│   └── 比 Win+R 更强（模糊搜索）
├── ③ 文本提取器（Win+Shift+T）：屏幕文字 OCR 复制
├── ④ 颜色选择器（Win+Shift+C）：取色（前端开发）
├── ⑤ 键盘管理器：按键重映射/快捷键重映射
├── ⑥ 批量重命名（PowerRename）
└── ⑦ 预览增强（Peek）：Win+Space 快速预览文件

开发场景
├── FancyZones：IDE + 终端 + 浏览器固定布局（一键归位）
├── PowerToys Run：秒开工具（比 Win+R 模糊匹配）
├── 颜色选择器：前端取色（Win+Shift+C）
└── 文本提取器：截图中的文字直接复制
```

## 6. 学习效果评估

### 6.1 效率自测（月度）

```text
快捷键熟练度自测（每月一次）
├── [ ] 7 个生存快捷键：秒按（<1 秒反应）
├── [ ] 文本编辑：词级选择/移动/查找（不碰鼠标）
├── [ ] 系统操作：Win+R/D/E/L、截图、分屏
├── [ ] IDE：打开文件/跳定义/全局搜索/重命名/运行
├── [ ] 终端：Ctrl+R/补全/清屏/进程控制
├── [ ] 浏览器：标签管理/地址栏/DevTools
├── [ ] 冲突处理：遇到冲突能自行排查解决
└── 评估：≥6 项达标 = 键盘驱动使用者
```

### 6.2 持续优化

```text
持续优化三问（每周复盘）
├── ① 今天哪个操作还在用鼠标？（→ 查对应快捷键）
├── ② 哪个快捷键总按错？（→ 练习或改键）
├── ③ 有什么重复操作？（→ AutoHotkey/PowerToys 自动化）
└── 金句：快捷键的终点是「个性化」——工具适应你，而非你适应工具
```

## 7. 核心要点

> 🎯 **核心要点**：
> 1. 三阶段学习：生存 7 个（第 1 周）→ 提效每类 10 个（第 2-4 周）→ 精通按需——**每周只加 3-5 个**
> 2. 冲突三大来源：应用间/输入法抢占/全局工具——**输入法是最高频抢占者**
> 3. 应用内自定义：IDEA Keymap / VS Code keybindings.json——冲突检测 + 导出同步
> 4. AutoHotkey：系统级自定义（CapsLock 组合避开输入法冲突 + 文本展开）
> 5. PowerToys：FancyZones 分屏布局 / PowerToys Run 启动器 / 取色器——微软官方效率套装
> 6. 月度自测 + 每周三问（还在用鼠标的操作？）——**工具适应你，而非你适应工具**
