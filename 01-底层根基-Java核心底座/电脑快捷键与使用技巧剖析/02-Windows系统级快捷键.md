## 1. Win 键组合总览

> **背景**：Win 键（⊞）是 Windows 的「系统键」——所有系统级操作以它为前缀。
> **目的**：脱离鼠标完成系统操作（运行/搜索/截图/桌面管理）。
> **适用范围**：Windows 10/11（2026 以 Win 11 为主，Win 10 支持已于 2025.10 结束）。
> **不适用场景**：Linux/macOS（对应 Super/Cmd 键，键位不同）。

```text
Win 键组合分类
├── 文件与启动：Win+E（资源管理器）/ Win+R（运行）/ Win+S（搜索）
├── 窗口与桌面：Win+D（桌面）/ Win+M（最小化）/ Win+方向（分屏）
├── 截图与剪贴板：Win+Shift+S（截图）/ Win+V（剪贴板历史）
├── 系统设置：Win+I（设置）/ Win+A（操作中心）/ Win+X（高级菜单）
├── 虚拟桌面：Win+Ctrl+D（新建）/ Win+Ctrl+方向（切换）
└── 安全：Win+L（锁屏）/ Win+P（投影）
```

## 2. 高频六件套（最先记住）

> 🎯 **2026 必备六件套**——入门者先记住这 6 个，覆盖 80% 系统操作：

| 快捷键 | 功能 | 场景 |
|:---:|------|------|
| `Win+E` | 打开文件资源管理器 | 找文件/进项目目录 |
| `Win+R` | 打开运行窗口 | 启动工具（cmd/notepad/mstsc） |
| `Win+D` | 显示/隐藏桌面 | 快速回桌面/再按恢复 |
| `Win+S`（或 Q） | 打开搜索 | 搜应用/文件/设置 |
| `Win+Shift+S` | 区域截图 | 文档/提 Bug/记录 |
| `Win+V` | 剪贴板历史 | 复用多条复制内容 |

```text
Win+R 运行命令速查（开发高频）
├── cmd          命令行
├── notepad      记事本
├── mstsc        远程桌面
├── taskmgr      任务管理器
├── services.msc 服务管理
├── regedit      注册表
├── sysdm.cpl    系统属性（环境变量入口）
├── ncpa.cpl     网络连接
├── control      控制面板
└── winver       系统版本
→ 金句：Win+R 是「命令启动器」——记住常用命令 = 秒开一切
```

## 3. 截图体系

### 3.1 四种截图方式

| 快捷键 | 功能 | 适用 |
|:---:|------|------|
| `PrtScn` | 全屏截图（到剪贴板） | 简单场景 |
| `Win+PrtScn` | 全屏截图（自动保存） | 需要保存 |
| `Alt+PrtScn` | 当前窗口截图（到剪贴板） | 单窗口 |
| `Win+Shift+S` | **区域截图（2026 首选）** | 任意区域 |

### 3.2 Win+Shift+S 的进阶（2026）

```text
Win+Shift+S 区域截图
├── ① 按快捷键 → 屏幕变暗 → 选择区域
├── ② 截图进入剪贴板（自动）→ Ctrl+V 粘贴
├── ③ 截图工具窗口弹出 → 可标注/保存
├── ④ 截图模式：矩形/自由/窗口/全屏（顶部工具栏切换）
└── ⑤ 开发场景：提 Bug 附截图、文档配图、记录报错

组合工作流（排障场景）
├── Win+Shift+S 截图报错
├── Win+V 粘贴到文档/聊天
├── Ctrl+S 保存留档
└── 金句：截图 + 快捷键 = 信息记录三秒完成
```

## 4. 虚拟桌面

### 4.1 虚拟桌面是什么

> **背景**：一个桌面放不下所有窗口——虚拟桌面提供「多桌面」隔离不同任务。
> **目的**：任务/环境隔离（工作桌面 vs 个人桌面 vs 项目桌面）。
> **适用范围**：多任务开发、工作生活分离、项目隔离。
> **不适用场景**：窗口不多的人（额外管理成本）。

### 4.2 虚拟桌面快捷键

| 快捷键 | 功能 |
|:---:|------|
| `Win+Tab` | 打开任务视图（总览所有桌面/窗口） |
| `Win+Ctrl+D` | **新建虚拟桌面** |
| `Win+Ctrl+←/→` | 切换虚拟桌面 |
| `Win+Ctrl+F4` | 关闭当前虚拟桌面 |

### 4.3 开发场景实践

```text
虚拟桌面的开发用法
├── 桌面 1：IDE（专注编码）
├── 桌面 2：终端 + 日志（运行监控）
├── 桌面 3：浏览器 + 文档（查资料）
├── 桌面 4：聊天 + 邮件（通信）
└── 切换：Win+Ctrl+方向——任务间零干扰切换

优点
├── ① 窗口隔离：每个桌面窗口少（不混乱）
├── ② 专注：切到 IDE 桌面 = 进入编码状态
└── ③ 隐私：个人桌面与工作桌面分离
```

## 5. 任务栏与多任务

### 5.1 任务栏操作

| 快捷键 | 功能 |
|:---:|------|
| `Win+1~9` | 打开任务栏固定位置的应用 |
| `Win+T` | 任务栏应用间循环 |
| `Win+B` | 聚焦系统托盘 |
| `Win+Home` | 最小化除当前窗口外的所有窗口 |
| `Win+M` | 最小化所有窗口 |
| `Win+Shift+M` | 恢复最小化窗口 |

### 5.2 分屏操作（Win+方向）

```text
分屏四方向（2026 核心效率）
├── Win+←/→   窗口贴靠左/右半屏
├── Win+↑     最大化
├── Win+↓     最小化/还原
├── Win+Alt+↑/↓  贴靠上/下半屏（Win 11）
└── 悬停窗口标题栏拖动到边缘也可分屏

开发场景
├── 左屏 IDE + 右屏浏览器（查文档）
├── 左屏代码 + 右屏终端（运行日志）
├── 上屏代码 + 下屏测试结果
└── 多屏用户：Win+Shift+←/→ 窗口跨显示器移动
```

## 6. 系统工具直达

### 6.1 系统级快捷键

| 快捷键 | 功能 | 场景 |
|:---:|------|------|
| `Ctrl+Shift+Esc` | **任务管理器直达**（绕过 Ctrl+Alt+Del） | 卡死秒开 |
| `Win+L` | 锁屏 | 离开工位必用 |
| `Win+I` | 设置 | 系统配置 |
| `Win+A` | 操作中心（通知/蓝牙/WiFi） | 快速开关 |
| `Win+X` | 高级用户菜单 | 设备管理器/终端等 |
| `Win+P` | 投影/多屏模式 | 演示/扩展屏 |
| `Win+K` | 投屏/蓝牙设备 | 无线投屏 |
| `Win+U` | 辅助功能 | 放大镜等 |
| `Win+.` | Emoji/符号面板 | 快速输入符号 |
| `Win+Shift+↑` | 窗口垂直最大化 | 长文档 |

### 6.2 任务管理器的使用技巧

```text
任务管理器（Ctrl+Shift+Esc）排障技巧
├── ① 性能页：CPU/内存/磁盘/网络实时曲线（卡顿定位）
├── ② 进程页：按 CPU/内存排序 → 找占用大户
├── ③ 启动页：禁用无用启动项（加速开机）
├── ④ 详细信息：PID 匹配端口占用进程
├── ⑤ 结束进程：右键 → 结束任务（⚠️ 先确认）
└── 开发场景：端口被占 → 任务管理器找 java/node 进程
```

## 7. Windows 11 新特性（2026）

### 7.1 Win 11 快捷键变化

```text
Windows 11 的快捷键变化（2026）
├── ① Win+C：打开 Microsoft Copilot（AI 助手）
├── ② Win+W：Widgets 小组件
├── ③ Win+Z：Snap Layouts（分屏布局选择器——贴靠增强）
├── ④ Win+N：通知中心（替代 Win+A 部分功能）
├── ⑤ Win+Shift+C：语音输入（听写）
└── ⑥ 经典快捷键全部保留（Win 10 → 11 无缝迁移）

Snap Layouts（Win+Z）——2026 分屏增强
├── ① 按 Win+Z → 弹出布局选择（2 分/3 分/4 分屏）
├── ② 一键选择预设布局
├── ③ 多屏协同布局记忆
└── 场景：IDE + 终端 + 浏览器 + 测试 四格布局
```

## 8. 核心要点

> 🎯 **核心要点**：
> 1. Win 键体系：文件（E）/运行（R）/搜索（S）/截图（Shift+S）/剪贴板（V）——高频六件套先记
> 2. Win+R 是「命令启动器」——cmd/mstsc/taskmgr 等秒开一切
> 3. 截图首选 Win+Shift+S（区域截图 + 自动剪贴板）——提 Bug/记录三秒完成
> 4. 虚拟桌面（Win+Ctrl+D）任务隔离：IDE/终端/浏览器/通信四个桌面
> 5. 分屏（Win+方向/Win+Z Snap Layouts）——IDE+终端+浏览器同屏工作
> 6. Ctrl+Shift+Esc 任务管理器直达 + Win+L 锁屏——排障与安全习惯
> 7. Win 11 新特性：Win+C Copilot / Win+Z 布局——经典快捷键无缝迁移
