## 1. 窗口管理全景

> **背景**：多窗口是开发常态（IDE/终端/浏览器/文档）——窗口管理的效率 = 多任务切换的效率。
> **目的**：秒级切换 + 合理布局，减少「找窗口」的时间。
> **适用范围**：所有 Windows 用户；开发场景尤甚。
> **不适用场景**：单窗口专注场景（无需管理）。

```text
窗口管理四层能力
├── ① 切换：Alt+Tab（应用间）/ Ctrl+Tab（标签内）
├── ② 布局：分屏（Win+方向）/ Snap Layouts（Win+Z）
├── ③ 隔离：虚拟桌面（Win+Ctrl+D）/ 任务视图（Win+Tab）
└── ④ 多屏：跨显示器移动（Win+Shift+方向）
→ 金句：窗口管理 = 切换 + 布局 + 隔离——三层配合才是完整效率
```

## 2. Alt+Tab 切换的艺术

### 2.1 基础用法

```text
Alt+Tab 的完整操作
├── ① 按住 Alt → 按一下 Tab：切到上一个窗口
├── ② 按住 Alt → 连按 Tab：循环切换（预览缩略图）
├── ③ 按住 Alt → 按 Shift+Tab：反向切换
├── ④ 松开 Alt：确认切换
└── ⑤ 按住 Alt 不松：可用方向键选择（精细控制）

进阶技巧
├── ⑥ 切换时按住 Ctrl：固定预览（松开 Alt 不关闭）
└── ⑦ Win+Tab：任务视图（大预览 + 虚拟桌面总览）
```

### 2.2 切换效率对比

```text
三种切换方式
├── 鼠标点击任务栏：需要精确点（慢 + 打断）
├── Alt+Tab：键盘秒切（常用切换首选）
├── Win+数字：直达任务栏固定应用（最稳定！）
└── 开发场景组合：
    ├── IDE 固定任务栏 1 位 → Win+1 直达
    ├── 终端固定 2 位 → Win+2
    ├── 浏览器固定 3 位 → Win+3
    └── 三键直达三个核心应用（0 思考成本）
```

## 3. 窗口控制快捷键

### 3.1 窗口操作全集

| 快捷键 | 功能 |
|:---:|------|
| `Alt+F4` | 关闭当前窗口 |
| `Alt+Space` | 窗口系统菜单（最大化/最小化/移动） |
| `Ctrl+W` | 关闭标签/文档（浏览器/IDE） |
| `Ctrl+Tab` | 标签页切换（前） |
| `Ctrl+Shift+Tab` | 标签页切换（后） |
| `F11` | 全屏切换 |
| `Win+↑` | 最大化 |
| `Win+↓` | 最小化/还原 |
| `Win+Home` | 最小化其他所有窗口 |
| `Esc` | 取消当前操作 |

### 3.2 窗口控制的高频场景

```text
场景 1：演示/分享
├── Win+P 选择投影模式 → Win+↑ 最大化内容
└── Alt+Tab 切换演示内容

场景 2：专注模式
├── Win+Home：只留当前窗口（其他全最小化）
├── Win+↑：当前窗口最大化
└── 虚拟桌面：切到专注桌面

场景 3：快速对比
├── Win+← 左半屏 + Win+→ 右半屏（两窗口对比）
└── 常见：代码 vs 文档 / 需求 vs 实现
```

## 4. 分屏体系

### 4.1 分屏方式对比

| 方式 | 操作 | 特点 |
|------|------|------|
| **Win+方向** | 四方向贴靠 | 最快（键盘） |
| **拖拽到边缘** | 鼠标拖到屏幕边缘 | 直观（鼠标） |
| **Win+Z**（Win 11） | Snap Layouts 布局选择 | 预设布局（最灵活） |
| **Win+Alt+方向** | 上/下半屏 | 垂直分屏 |

### 4.2 开发分屏布局（2026 推荐）

```text
开发常用布局
┌─────────────────────────────────────┐
│ 布局 A：双屏对比                      │
│ ┌───────────────┬─────────────────┐ │
│ │ IDE（左半屏）  │ 浏览器/文档（右） │ │
│ └───────────────┴─────────────────┘ │
│ Win+← 然后 Win+→（或拖拽）            │
├─────────────────────────────────────┤
│ 布局 B：四格工作台（Win+Z）           │
│ ┌────────┬────────┬────────┐        │
│ │ IDE    │ 终端   │ 浏览器  │        │
│ ├────────┴────────┴────────┤        │
│ │ 测试/日志（底部）           │        │
│ └──────────────────────────┘        │
└─────────────────────────────────────┘
```

### 4.3 分屏的边界

```text
分屏注意事项
├── ⚠️ 屏幕太小分屏拥挤（建议 27 寸+ 或高分屏）
├── ⚠️ 高分屏缩放（150%+）分屏内容变小
├── ⚠️ 多屏 + 分屏组合：分屏只作用于当前屏
├── ✅ 替代：虚拟桌面隔离（窗口多时分桌面）
└── 选择：窗口 2-3 个 → 分屏；窗口 5+ → 虚拟桌面
```

## 5. 多显示器协作

### 5.1 多屏模式

| 快捷键 | 功能 |
|:---:|------|
| `Win+P` | 投影/显示模式（仅电脑/复制/扩展/仅第二屏） |
| `Win+Shift+←/→` | 窗口跨显示器移动 |
| `Win+方向` | 窗口在当前屏分屏 |

### 5.2 开发多屏布局（经典配置）

```text
双屏开发布局（2026 主流）
┌─────────────────────┬──────────────────────┐
│ 主屏（正前方）        │ 副屏（侧面）          │
│ IDE（主力工作）       │ 浏览器/文档/聊天      │
│ 代码编辑区           │ 查文档/看需求/通信    │
└─────────────────────┴──────────────────────┘
配合：
├── Win+Shift+←/→ 窗口快速跨屏
├── 主屏固定 IDE（Win+1 直达）
└── 副屏固定浏览器（Win+2）

三屏（进阶）：主屏 IDE + 副屏 1 浏览器 + 副屏 2 终端/监控
```

### 5.3 多屏的常见问题

```text
多屏排障
├── ⚠️ 鼠标跨屏不顺 → 设置中调整显示器排列
├── ⚠️ 分辨率不一致 → 光标卡顿（对齐缩放）
├── ⚠️ 窗口记忆位置：拔掉副屏后窗口找不到
│   → Win+方向 拉回主屏 / Win+Shift+方向
├── ⚠️ 分屏不记忆 → 第三方工具（FancyZones 等）
└── ✅ 工具推荐：Microsoft PowerToys（FancyZones 分屏增强）
```

## 6. 任务视图与虚拟桌面配合

### 6.1 任务视图（Win+Tab）

```text
Win+Tab 任务视图
├── ① 总览所有桌面 + 每个桌面的窗口
├── ② 拖拽窗口到其他桌面（跨桌面移动）
├── ③ 新建虚拟桌面
├── ④ 时间线（旧版功能已移除）
└── 使用场景：窗口太多时总览管理
```

### 6.2 窗口/桌面配合工作流

```text
多任务管理工作流（2026 推荐）
├── ① 场景隔离：工作桌面 / 个人桌面（Win+Ctrl+D）
├── ② 窗口归位：任务视图拖拽或右键窗口 → 移动到桌面
├── ③ 快速切换：Win+Ctrl+方向（桌面间）
├── ④ 总览管理：Win+Tab（窗口过多时）
└── ⑤ 关闭清理：Win+Ctrl+F4（桌面用完即关）

金句：窗口是「应用单元」、桌面是「任务单元」——
├── 应用间切换：Alt+Tab
├── 任务间切换：Win+Ctrl+方向
└── 两者配合 = 多任务管理的完整体系
```

## 7. 窗口管理的效率习惯

### 7.1 习惯清单

```text
窗口管理习惯（培养目标）
├── ① 核心应用固定任务栏（Win+数字直达）
├── ② 两个窗口对比用分屏（Win+方向）
├── ③ 多任务用虚拟桌面（Win+Ctrl+D）
├── ④ 频繁切换用 Alt+Tab（键盘秒切）
├── ⑤ 窗口乱时 Win+Tab 总览整理
├── ⑥ 用完后关窗口（Ctrl+W）保持桌面干净
└── ⑦ 多屏用户：固定主屏 IDE/副屏文档
```

### 7.2 效率自测

```text
自测（1 分钟内能否完成）
├── [ ] 从 IDE 切到浏览器再切回（Alt+Tab/Win+数字）
├── [ ] 打开两个窗口左右分屏（Win+← + Win+→）
├── [ ] 新建虚拟桌面并切换（Win+Ctrl+D + 方向）
├── [ ] 窗口跨屏移动（Win+Shift+方向）
├── [ ] 关闭所有多余窗口只留当前（Win+Home）
└── 5 项全过 = 窗口管理合格；有卡壳 = 回看对应章节
```

## 8. 核心要点

> 🎯 **核心要点**：
> 1. 窗口管理 = 切换（Alt+Tab）+ 布局（分屏）+ 隔离（虚拟桌面）三层体系
> 2. **Win+数字直达固定应用**（IDE=1/终端=2/浏览器=3）——零思考成本切换
> 3. 开发分屏：双屏对比（Win+←/→）+ 四格工作台（Win+Z Snap Layouts）
> 4. 多屏协作：Win+Shift+方向跨屏移动 + 主屏 IDE/副屏文档布局
> 5. 窗口是应用单元、桌面是任务单元——Alt+Tab 应用切换 + Win+Ctrl+方向 任务切换
> 6. 多屏排障：PowerToys FancyZones 增强分屏；拔屏后窗口 Win+方向拉回
