## 1. 实战模式总览

> **背景**：Stream 的实战价值 = 用声明式替代嵌套循环——报表/清洗/分页/聚合是高频场景。
> **目的**：提供可直接复用的实战模板。
> **适用范围**：Java 后端日常开发。
> **前提假设**：已掌握基础操作（01-03 篇）。

```text
八大实战模式
├── ① 报表统计：分组 + 聚合（summarizing）
├── ② 数据清洗：过滤 + 转换 + 去重
├── ③ 分页排序：skip + limit + sorted
├── ④ 关联聚合：两个集合关联（Map 索引）
├── ⑤ Top N：排序 + limit
├── ⑥ 批量操作：分批 + 处理
├── ⑦ 对象转换：DO → DTO（map）
└── ⑧ 树结构：递归构建/扁平化
```

## 2. 模式一：报表统计

```java
// 场景：订单报表——按状态统计金额、数量、平均
public class OrderReport {
    // 按状态全统计（一次遍历）
    public Map<OrderStatus, IntSummaryStatistics> statsByStatus(List<Order> orders) {
        return orders.stream()
            .collect(Collectors.groupingBy(Order::getStatus,
                     Collectors.summarizingInt(Order::getAmount)));
        // 结果：{PAID: {count=100, sum=50000, avg=500, max=..., min=...}}
    }

    // 多维度报表：状态 × 渠道
    public Map<OrderStatus, Map<String, Long>> byStatusAndChannel(List<Order> orders) {
        return orders.stream()
            .collect(Collectors.groupingBy(Order::getStatus,
                     Collectors.groupingBy(Order::getChannel, Collectors.counting())));
    }

    // 时段统计（按小时）
    public Map<Integer, Long> countByHour(List<Order> orders) {
        return orders.stream()
            .collect(Collectors.groupingBy(
                o -> o.getCreatedAt().getHour(), Collectors.counting()));
    }
}

// 使用（Controller/Service 直接调用）
Map<OrderStatus, IntSummaryStatistics> report = orderReport.statsByStatus(orders);
```

## 3. 模式二：数据清洗

```java
// 场景：清洗用户导入数据（去空/去重/规范化）
public List<User> cleanUsers(List<User> rawUsers) {
    return rawUsers.stream()
        .filter(Objects::nonNull)                        // ① 去 null
        .filter(u -> u.getName() != null && !u.getName().isBlank())  // ② 去空名
        .filter(u -> u.getPhone() != null)               // ③ 去无手机
        .distinct()                                      // ④ 去重（按 equals）
        .map(u -> u.withName(u.getName().trim()))        // ⑤ 规范化（trim）
        .sorted(Comparator.comparing(User::getId))       // ⑥ 排序
        .toList();
}

// 日志解析清洗
public List<LogEntry> parseLogs(Stream<String> lines) {
    return lines
        .filter(line -> !line.isBlank())                  // 去空行
        .filter(line -> !line.startsWith("#"))            // 去注释
        .map(LogParser::parse)                            // 解析
        .filter(Optional::isPresent)                      // 过滤解析失败
        .map(Optional::get)
        .toList();
}
```

## 4. 模式三：分页与排序

```java
// 场景：列表分页（内存分页——小数据量）
public PageResult<Order> pageOrders(List<Order> all, int page, int size) {
    // ① 排序（按时间倒序）
    List<Order> sorted = all.stream()
        .sorted(Comparator.comparing(Order::getCreatedAt).reversed())
        .toList();

    // ② 总数
    long total = sorted.size();

    // ③ 分页（skip + limit）
    List<Order> pageData = sorted.stream()
        .skip((long) page * size)
        .limit(size)
        .toList();

    return new PageResult<>(total, pageData);
}

// 多条件筛选 + 排序 + 分页（组合）
public PageResult<Order> searchOrders(List<Order> all,
        OrderStatus status, BigDecimal minAmount, int page, int size) {
    List<Order> filtered = all.stream()
        .filter(o -> status == null || o.getStatus() == status)   // 条件筛选
        .filter(o -> minAmount == null || o.getAmount() >= minAmount)
        .sorted(Comparator.comparing(Order::getCreatedAt).reversed())
        .toList();

    return new PageResult<>(filtered.size(),
        filtered.stream().skip((long) page * size).limit(size).toList());
}

// ⚠️ 大数据量：内存分页不适用（用数据库分页——LIMIT/OFFSET）
```

## 5. 模式四：关联与聚合

```java
// 场景：订单关联用户（两集合关联——避免 N+1 查询）
public List<OrderVO> joinOrdersWithUsers(List<Order> orders, List<User> users) {
    // ① 用户转 Map（索引——O(1) 查找）
    Map<String, User> userMap = users.stream()
        .collect(Collectors.toMap(User::getId, u -> u, (a, b) -> a));

    // ② 关联（每个订单查用户——避免嵌套循环）
    return orders.stream()
        .map(o -> new OrderVO(
            o,
            userMap.getOrDefault(o.getUserId(), User.UNKNOWN)   // 缺失兜底
        ))
        .toList();
}

// 场景：订单聚合商品（flatMap 展开）
public Map<String, Integer> totalQuantity(List<Order> orders) {
    return orders.stream()
        .flatMap(o -> o.getItems().stream())          // 展开商品
        .collect(Collectors.groupingBy(
            Item::getSkuId, Collectors.summingInt(Item::getQuantity)));
}

// 场景：标签聚合（多对多）
public Map<String, Long> countByTag(List<Article> articles) {
    return articles.stream()
        .flatMap(a -> a.getTags().stream())           // 展开标签
        .collect(Collectors.groupingBy(t -> t, Collectors.counting()));
}
```

## 6. 模式五：Top N 与排行

```java
// 场景：Top N 订单（金额）
public List<Order> topOrders(List<Order> orders, int n) {
    return orders.stream()
        .sorted(Comparator.comparing(Order::getAmount).reversed())
        .limit(n)
        .toList();
}

// 场景：热销商品排行（先聚合再排）
public List<Map.Entry<String, Integer>> hotSkus(List<Order> orders, int n) {
    return orders.stream()
        .flatMap(o -> o.getItems().stream())
        .collect(Collectors.groupingBy(Item::getSkuId,
                 Collectors.summingInt(Item::getQuantity)))
        .entrySet().stream()
        .sorted(Map.Entry.<String, Integer>comparingByValue().reversed())
        .limit(n)
        .toList();
}

// 场景：用户消费排行 Top 10
public List<UserRank> topUsers(List<Order> orders, int n) {
    return orders.stream()
        .collect(Collectors.groupingBy(Order::getUserId,
                 Collectors.summingInt(Order::getAmount)))
        .entrySet().stream()
        .sorted(Map.Entry.<String, Integer>comparingByValue().reversed())
        .limit(n)
        .map(e -> new UserRank(e.getKey(), e.getValue()))
        .toList();
}

// ⚠️ 性能：Top N 全量排序后取 N——大数据量用「堆/优先队列」更优
// （Stream 无内置 TopN 操作——sorted+limit 简单但非最优）
```

## 7. 模式六：批量操作

```java
// 场景：分批处理（如批量入库——防一次性大事务）
public void batchProcess(List<Order> orders, int batchSize) {
    // 分片（IntStream 生成批次索引）
    int total = orders.size();
    IntStream.range(0, (total + batchSize - 1) / batchSize)
        .forEach(i -> {
            List<Order> batch = orders.stream()
                .skip((long) i * batchSize)
                .limit(batchSize)
                .toList();
            orderRepository.batchInsert(batch);   // 每批入库
        });
}

// 场景：批量校验 + 汇总错误
public ValidationResult validateOrders(List<Order> orders) {
    List<Order> valid = orders.stream()
        .filter(o -> validate(o).isOk())
        .toList();
    List<String> errors = orders.stream()
        .map(o -> validate(o))
        .filter(r -> !r.isOk())
        .map(ValidationResult::getMessage)
        .toList();
    return new ValidationResult(valid.size(), errors);
}

// 场景：批量通知（先过滤成功再发）
public void notifyPaidUsers(List<Order> orders) {
    orders.stream()
        .filter(o -> o.getStatus() == PAID)
        .map(Order::getUserId)
        .distinct()
        .forEach(userService::notify);
}
```

## 9. 模式八：树结构处理

```java
// 场景：扁平列表 → 树（递归构建）
public List<TreeNode> buildTree(List<TreeNode> flatList) {
    Map<String, TreeNode> nodeMap = flatList.stream()
        .collect(Collectors.toMap(TreeNode::getId, n -> n, (a, b) -> a));

    return flatList.stream()
        .filter(n -> n.getParentId() == null)          // 根节点
        .map(n -> attachChildren(n, nodeMap))
        .toList();
}

private TreeNode attachChildren(TreeNode node, Map<String, TreeNode> nodeMap) {
    node.setChildren(nodeMap.values().stream()
        .filter(c -> node.getId().equals(c.getParentId()))
        .map(c -> attachChildren(c, nodeMap))          // 递归
        .toList());
    return node;
}

// 场景：树 → 扁平（DFS 遍历）
public List<TreeNode> flattenTree(List<TreeNode> roots) {
    return roots.stream()
        .flatMap(root -> Stream.concat(
            Stream.of(root),
            flattenTree(root.getChildren()).stream()))  // 递归展开
        .toList();
}

// 场景：层级路径（递归拼接）
public List<String> paths(List<TreeNode> roots) {
    return roots.stream()
        .flatMap(root -> pathOf(root, "").stream())
        .toList();
}
// ⚠️ 深层树注意递归深度（Stream 递归也是调用栈）
```

## 10. 核心要点

> 🎯 **核心要点**：
> 1. 八大实战模式：报表/清洗/分页/关联/TopN/批量/转换/树——覆盖 Java 后端 80% 数据场景
> 2. 报表 = groupingBy + summarizing（一次遍历全统计）
> 3. 关联用 Map 索引（避免嵌套循环/N+1）——toMap + getOrDefault 兜底
> 4. 分页：内存用 skip+limit（小数据）；大数据走数据库分页
> 5. Top N：sorted+limit 简单但全量排序——超大数据用优先队列
> 6. 树结构：Map 索引 + 递归 attach；注意递归深度
> 7. 实战要点：Optional 兜底（orElseThrow）、null 过滤（Objects::nonNull）
