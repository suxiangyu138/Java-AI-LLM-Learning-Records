## 1. 面试高频题与答题框架

### 1.1 调试方法论类

**Q1：你平时怎么调试前端 JS？断点还是 console.log？**

```text
① 断点优先（2026 共识）：零污染 + 完整运行时信息
② 断点流程：F12 → Sources → 设断点 → 刷新 → F10/F11 单步
③ 高级断点：条件断点（循环 N 次）/日志断点（线上零污染）
④ console.log 的场景：快速验证/线上无调试器环境
⑤ 金句：console.log 是「猜」、断点是「看」
⑥ 加分：Call Stack 先看「我从哪来」
```

**Q2：页面样式不对，你怎么排查？**

```text
① F12 → Ctrl+Shift+C 点击元素定位
② Elements 看样式：被覆盖（高优先级）/没生效（选择器）
③ 数值微调：↑↓ 实时预览（Shift 大步进/Alt 细步进）
④ 伪类问题：Force state 强制 hover
⑤ 动态元素：Ctrl+F 搜索选择器 + DOM 断点
⑥ 金句：DevTools 改样式是临时的——改完复制到源码
```

**Q3：接口报错你怎么排查？**

```text
① Network 面板 → 过滤找到请求（/ 输入 URL）
② 状态码分流：4xx 前端（参数/URL/Token）/5xx 后端
③ 四步看：状态码 → Headers → Payload → Response
④ 复现：Copy as cURL（终端/后端复现）/Replay XHR
⑤ 缓存问题：Disable cache + Ctrl+Shift+R
⑥ 加分：CORS 看 Response Headers 的 Access-Control-*
```

**Q4：断点没触发是什么原因？**

```text
① 没刷新页面（改代码后 Ctrl+R）
② 生产构建无 Source Map（开发模式调试）
③ webRoot 配置不对（VS Code）
④ 断点位置代码没执行（条件不满足）
⑤ 压缩混淆代码（需要 Source Map）
⑥ 缓存：强制刷新 Ctrl+Shift+R
```

### 1.2 工具类

**Q5：DevTools 的 Ctrl+Shift+P 命令菜单有什么用？**

```text
① 「上帝模式」：执行任何菜单功能
② 高频：Capture node screenshot（元素截图）
③ Show Coverage（代码覆盖率）
④ Disable JavaScript（无 JS 测试）
⑤ Network conditions（网络模拟）
⑥ 金句：记不住的位置搜索直达——比翻菜单快 10 倍
```

**Q6：$0 在 Console 里是什么？**

```text
① $0 = 当前 Elements 选中的 DOM 节点
② $1-$4：最近选中的节点（历史）
③ $_：上一次表达式结果
④ 用法：$0.style.color / $0.textContent / $0.click()
⑤ 金句：$0 是「选中元素的快捷手柄」——Elements 与 Console 联动
```

**Q7：React 组件状态不对怎么排查？**

```text
① React DevTools → Components 面板
② 选中组件看 Props/Hooks/State（实际值）
③ 修改 Props 实时验证
④ Profiler 看渲染耗时与重渲染原因
⑤ 结合断点：组件文件设断点看执行
⑥ 加分：状态更新不生效 → Hooks 面板看 useState 实际值
```

**Q8：页面加载慢怎么排查？**

```text
① Network 瀑布图：哪个请求慢/串行/体积大
② Performance 录制：长任务（Long Tasks）
③ React/Vue Profiler：组件重渲染
④ Lighthouse：整体评分（性能基线）
⑤ 优化方向：懒加载/压缩/缓存/并发
⑥ 金句：性能排查 = Network + Performance + Profiler 三件套
```

### 1.3 场景类

**Q9：线上问题怎么调试（无法本地复现）？**

```text
① 日志断点：Add logpoint（不修改代码）
② Overrides：本地覆盖线上资源调试
③ Console 保留日志：Preserve log
④ 接口对比：本地 vs 线上请求差异
⑤ 数据/环境差异定位
⑥ 金句：线上绝不改源码调试——零污染原则
```

**Q10：移动端样式问题怎么排查？**

```text
① Ctrl+Shift+M 设备模拟
② 视口检查：viewport meta
③ 媒体查询断点：调整模拟宽度
④ 触摸事件：click 延迟/touch 事件
⑤ 真机验证：局域网访问
⑥ 加分：网络模拟慢速 3G（移动网络体验）
```

**Q11：VS Code 怎么调试浏览器代码？**

```text
① 安装 Debugger for Chrome 扩展
② launch.json 配置（url/webRoot）
③ F5 启动 → 编辑器内断点
④ 变量/Watch/调用栈面板
⑤ TypeScript 通过 Source Map 直接断点
⑥ 加分：attach 模式连已开 Chrome（端口 9222）
```

**Q12：怎么提一个高质量的前端 Bug 单？**

```text
① 复现步骤：精确到操作序列（3-5 步）
② 环境信息：浏览器版本/系统/设备
③ 截图/录屏：Win+Shift+S 区域截图
④ 控制台报错：完整报错信息
⑤ Network 请求：Copy as cURL / HAR 导出
⑥ 期望 vs 实际：明确描述
⑦ 加分：附带最小复现（代码片段/线上 URL）
```

## 2. 速查表

### 2.1 DevTools 核心速查

```text
打开与导航
├── F12 / Ctrl+Shift+I  DevTools
├── Ctrl+Shift+J       Console 直达
├── Ctrl+Shift+C       元素选择器
├── Ctrl+Shift+M       设备模拟
├── Ctrl+Shift+P       命令菜单
├── Ctrl+[ / ]         面板切换

调试
├── F8   继续 / F10 单步跳过 / F11 单步进入 / Shift+F11 跳出
├── F9   切换断点
├── Ctrl+P   打开文件（:行号）
├── Ctrl+Shift+F  全局搜索

Console
├── Shift+Enter  多行 / Ctrl+L 清屏
├── $0 选中元素 / $_ 上次结果

Network
├── Ctrl+E 录制 / / 过滤 / Ctrl+F 搜索
├── Replay XHR 重放 / Copy as cURL
```

### 2.2 排查流程速查

```text
样式 Bug：F12 → Ctrl+Shift+C → Styles 微调 → 复制源码
JS Bug：Ctrl+Shift+J 看报错 → 设断点 → F10/F11 → Call Stack
接口 Bug：Network → 状态码 → Headers/Payload/Response → cURL
性能：Network 瀑布 → Performance 录制 → Profiler
移动端：Ctrl+Shift+M → 视口/断点 → 真机
线上：日志断点 + Overrides（零污染）
```

## 3. 五大常见误区

| # | 误区 | 真相 |
|---|------|------|
| 1 | 「console.log 够用了」 | 断点提供完整上下文且零污染——断点优先 |
| 2 | 「DevTools 改的样式会保留」 | 临时的！改完必须复制到源码 |
| 3 | 「刷新后 Console 日志还在」 | 默认清空——需要勾选 Preserve log |
| 4 | 「生产环境能断点」 | 生产构建无 Source Map——用日志断点/Overrides |
| 5 | 「报错只看最后一个」 | 看第一个错误（后续是连锁反应） |

```text

03 Sources：F8/F10/F11 断点控制/条件断点/日志断点
04 Console+Network：$0 快捷引用/请求四步排查
05 框架工作流：VS Code 调试/Live Server/React·Vue DevTools
06 组合技：六大排障场景键盘流 SOP
07 面试：12 题框架 + 速查表 + 避坑
```

> 🎯 **系列总结**：Web 开发快捷键 = **DevTools（面板操作）× 断点（调试核心）× 工作流（框架集成）× 组合技（场景 SOP）** 四维能力。2026 年调试标准答案：**断点优先于 console.log、复现优先于猜测、线上零污染（日志断点/Overrides）**——掌握这套体系，前端排障从「瞎试」变成「流程化」。
