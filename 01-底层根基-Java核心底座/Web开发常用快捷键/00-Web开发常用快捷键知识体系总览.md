## 4. 核心概念速查

| 概念 | 一句话解释 |
|------|-----------|
| **F12 / Ctrl+Shift+I** | 打开 DevTools（前端第一键） |
| **Ctrl+Shift+C** | 元素选择器（点击页面定位 DOM） |
| **Ctrl+Shift+J** | 直接打开 Console |
| **Ctrl+Shift+P** | DevTools 命令菜单（「上帝模式」——执行一切） |
| **Ctrl+P** | 快速打开文件（app.js:120 直接跳行） |
| **F8/F10/F11** | 继续/单步跳过/单步进入（断点调试三键） |
| **F9 / Ctrl+B** | 切换断点 |
| **条件断点** | 右键断点设条件（循环第 N 次才停） |
| **日志断点** | 不中断只打印（线上无副作用调试） |
| **$0** | Console 引用当前选中的 DOM 节点 |
| **Ctrl+Shift+M** | 设备模拟模式（移动端调试） |
| **Live Server** | VS Code 热更新服务器（Alt+L Alt+O） |
| **Overrides** | DevTools 本地覆盖线上资源直接调试 |

## 5. 一图看懂：前端排障主流程

```text
前端 Bug 排障键盘流（全程不碰鼠标）
┌─────────────────────────────────────────────┐
│ ① F12 打开 DevTools                          │
│ ② Ctrl+Shift+C 点击问题元素 → 定位 DOM       │
│ ③ Elements 面板看样式/结构（↑↓ 调整样式值）  │
│ ④ Ctrl+Shift+J 切 Console 看报错            │
│ ⑤ Ctrl+P 打开对应 JS 文件 → 设置断点（F9）   │
│ ⑥ 刷新页面 → 断点暂停 → F10/F11 单步跟踪    │
│ ⑦ Ctrl+Shift+F 全局搜索相关代码              │
│ ⑧ 修复 → Ctrl+R 刷新验证                     │
└─────────────────────────────────────────────┘
```
