## 4. 核心概念速查

| 概念 | 一句话解释 |
|------|-----------|
| **数组 + 链表 + 红黑树** | HashMap 底层结构（JDK 8+）——桶数组 + 冲突链表/树 |
| **初始容量** | 默认 16（2 的幂） |
| **负载因子** | 默认 0.75——时间与空间的折中 |
| **扩容阈值** | 容量 × 负载因子（默认 12）——超过触发扩容 |
| **扰动函数** | `hash ^ (hash >>> 16)`——高 16 位与低 16 位异或 |
| **索引计算** | `(n - 1) & hash`——位运算代替取模（容量 2 的幂） |
| **树化阈值** | 链表 ≥ 8 且容量 ≥ 64 才转红黑树 |
| **退化阈值** | 节点 ≤ 6 红黑树退链表（6-8 缓冲防震荡） |
| **尾插法** | JDK 8 链表尾部插入（修复 JDK 7 头插法死循环） |
| **高低位拆分** | 扩容时 `(hash & oldCap) == 0` 决定去留——免重算 |
| **懒初始化** | 第一次 put 才创建数组（JDK 8+） |
| **ConcurrentHashMap** | 并发替代方案（CAS + synchronized 锁头节点） |

## 5. 一图看懂：HashMap 整体结构

```text
HashMap 结构（JDK 8+）
┌─────────────────────────────────────────────────────┐
│ 数组 table（默认 16，2 的幂）                          │
│ ┌───┬───┬───┬───┬───┬───┬───┬───┐                   │
│ │ 0 │ 1 │ 2 │ 3 │...│ 7 │...│ 15│                   │
│ └─┬─┴───┴─┬─┴───┴─┬─┴───┴─┬─┴───┘                   │
│   │       │       │       │                          │
│   ▼       ▼       ▼       ▼                          │
│ Node    Node    Node    Node（桶）                    │
│   │       │       │       │                          │
│   ▼       ▼       ▼       ▼                          │
│ Node    null    Node    Node（链表 ≤8）               │
│   │              │       │                          │
│   ▼              ▼       ▼                          │
│ null          Node    TreeNode（红黑树 ≥8）           │
└─────────────────────────────────────────────────────┘
- 平均 O(1) 查询；树化最坏 O(log n)
- null key 允许（hash=0 存桶 0）
```
