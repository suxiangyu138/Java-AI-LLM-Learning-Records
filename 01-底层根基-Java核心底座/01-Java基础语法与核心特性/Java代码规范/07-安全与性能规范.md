## 1. SQL 注入防御

### 1.1 参数化查询

```java
// ✅ PreparedStatement 自动转义
String sql = "SELECT * FROM user WHERE username = ? AND password = ?";
PreparedStatement ps = conn.prepareStatement(sql);
ps.setString(1, username);
ps.setString(2, password);
ResultSet rs = ps.executeQuery();

// MyBatis #{} 自动参数化
<select id="findByUsername">
    SELECT * FROM user WHERE username = #{username}
</select>

// ❌ 危险：字符串拼接
String sql = "SELECT * FROM user WHERE username = '" + username + "'";
// 攻击者输入: admin' OR '1'='1
// 实际 SQL: SELECT * FROM user WHERE username = 'admin' OR '1'='1'
```

### 1.2 动态表名/排序字段白名单

```java
// ❌ 危险：动态表名无法参数化
String sql = "SELECT * FROM " + tableName + " ORDER BY " + sortField;

// ✅ 白名单校验
Set<String> allowedTables = Set.of("user", "order", "product");
Set<String> allowedSortFields = Set.of("id", "create_time", "amount");

if (!allowedTables.contains(tableName)) {
    throw new IllegalArgumentException("非法表名: " + tableName);
}
if (!allowedSortFields.contains(sortField)) {
    throw new IllegalArgumentException("非法排序字段: " + sortField);
}
```

## 2. XSS 防御

### 2.1 输出编码

```java
// ❌ 危险：直接输出用户输入
String comment = request.getParameter("comment");
response.getWriter().write("<p>" + comment + "</p>");
// 攻击者输入: <script>alert('XSS')</script>

// ✅ HTML 转义
import org.springframework.web.util.HtmlUtils;

String comment = request.getParameter("comment");
String safe = HtmlUtils.htmlEscape(comment);
response.getWriter().write("<p>" + safe + "</p>");
// 输出: &lt;script&gt;alert('XSS')&lt;/script&gt;
```

### 2.2 前端框架自动转义

```vue
<!-- Vue: {{ }} 自动转义 -->
<p>{{ userComment }}</p>

<!-- React: JSX 自动转义 -->
<p>{userComment}</p>

<!-- ⚠️ 危险：使用 v-html 或 dangerouslySetInnerHTML -->
<div v-html="userComment"></div>  <!-- 不转义，有 XSS 风险 -->
```

### 2.3 CSP 策略

```java
// HTTP 响应头
response.setHeader("Content-Security-Policy", 
    "default-src 'self'; script-src 'self' https://trusted.cdn.com");
```

## 3. CSRF 防御

### 3.1 CSRF Token

```java
// Spring Security 默认开启 CSRF 保护
// 表单自动包含 _csrf 隐藏字段
<form th:action="@{/transfer}" method="post">
    <input type="hidden" name="${_csrf.parameterName}" value="${_csrf.token}"/>
    <input type="text" name="amount"/>
    <button type="submit">转账</button>
</form>

// 服务端校验 Token
@PostMapping("/transfer")
public String transfer(@RequestParam String amount) {
    // Spring Security 自动校验 _csrf token
    // ...
}
```

### 3.2 GET 请求不应有副作用

```java
// ❌ 危险：GET 请求修改数据
@GetMapping("/delete")
public String delete(@RequestParam Long id) {
    userService.delete(id);  // ❌ GET 应该幂等、无副作用
    return "redirect:/list";
}

// ✅ 使用 POST/DELETE
@DeleteMapping("/user/{id}")
public String delete(@PathVariable Long id) {
    userService.delete(id);
    return "redirect:/list";
}
```

### 3.3 SameSite Cookie

```java
// 设置 Cookie 的 SameSite 属性
response.setHeader("Set-Cookie", 
    "sessionId=abc123; Path=/; HttpOnly; Secure; SameSite=Strict");
```

## 4. 敏感信息处理

### 4.1 日志脱敏

```java
// ❌ 泄露敏感信息
log.info("用户登录: username={}, password={}", username, password);
log.info("身份证号: {}", idCard);
log.info("手机号: {}", phone);

// ✅ 脱敏
log.info("用户登录: username={}", username);
log.info("身份证号: {}***{}", idCard.substring(0, 4), idCard.substring(14));
log.info("手机号: {}****{}", phone.substring(0, 3), phone.substring(7));
```

### 4.2 密码加密存储

```java
// ✅ BCrypt 加密
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;

BCryptPasswordEncoder encoder = new BCryptPasswordEncoder();
String encodedPassword = encoder.encode(rawPassword);

// 校验
boolean matches = encoder.matches(rawPassword, encodedPassword);

// ❌ 明文存储
user.setPassword(rawPassword);  // 绝对禁止

// ❌ 弱哈希（MD5/SHA1 容易被破解）
String md5 = DigestUtils.md5Hex(rawPassword);  // 不推荐
```

### 4.3 配置文件加密

```yaml
# ❌ 明文密码
spring:
  datasource:
    password: mypassword

# ✅ Jasypt 加密
spring:
  datasource:
    password: ENC(nrmZtkF7T0kdG1wZjQfHrQ==)

# 启动时传入密钥
# java -jar app.jar --jasypt.encryptor.password=secret
```

### 4.4 传输加密

```text
✅ 必须使用 HTTPS/TLS
❌ 禁止 HTTP 传输敏感数据（密码、身份证、银行卡）
```

## 5. 资源释放规范

### 5.1 try-with-resources

```java
// ✅ 自动关闭
try (InputStream in = new FileInputStream("file.txt");
     BufferedReader reader = new BufferedReader(new InputStreamReader(in))) {
    return reader.readLine();
}

// ❌ 手动关闭容易遗漏
InputStream in = new FileInputStream("file.txt");
try {
    // ...
} finally {
    in.close();  // 如果 in 为 null 会 NPE
}
```

### 5.2 数据库连接归还

```java
// ✅ 连接池自动管理
@Autowired
private JdbcTemplate jdbcTemplate;

public User findById(Long id) {
    return jdbcTemplate.queryForObject(
        "SELECT * FROM user WHERE id = ?",
        new BeanPropertyRowMapper<>(User.class),
        id
    );
}

// ❌ 手动管理容易泄漏
Connection conn = dataSource.getConnection();
try {
    // ...
} catch (SQLException e) {
    // 如果这里抛异常，conn 不会关闭
}
conn.close();
```

## 6. 大文件与大数据量处理

### 6.1 流式读取

```java
// ✅ 流式读取，内存占用小
try (BufferedReader reader = Files.newBufferedReader(path)) {
    String line;
    while ((line = reader.readLine()) != null) {
        process(line);
    }
}

// ❌ 一次性加载到内存
List<String> lines = Files.readAllLines(path);  // 大文件会 OOM
```

### 6.2 分批处理

```java
// ✅ 分批处理
int batchSize = 1000;
int total = userMapper.count();
for (int offset = 0; offset < total; offset += batchSize) {
    List<User> batch = userMapper.selectBatch(offset, batchSize);
    process(batch);
}

// ❌ 一次性加载所有
List<User> allUsers = userMapper.selectAll();  // 数据量大时 OOM
```

### 6.3 Excel 大文件读取

```java
// ✅ EasyExcel 流式读取
EasyExcel.read("users.xlsx", User.class, new AnalysisEventListener<User>() {
    @Override
    public void invoke(User user, AnalysisContext context) {
        process(user);
    }
}).sheet().doRead();

// ❌ POI 一次性加载
Workbook workbook = WorkbookFactory.create(new File("users.xlsx"));  // 大文件 OOM
```

## 7. 并发性能规范

### 7.1 避免锁竞争

```java
// ❌ 粗粒度锁
public synchronized void process() {
    // 整个方法加锁
    validate();
    calculate();
    save();
}

// ✅ 细粒度锁
public void process() {
    validate();
    synchronized (this) {
        calculate();  // 只锁必要部分
    }
    save();
}
```

### 7.2 避免频繁创建对象

```java
// ❌ 循环里创建对象
for (int i = 0; i < 10000; i++) {
    SimpleDateFormat sdf = new SimpleDateFormat("yyyy-MM-dd");
    String date = sdf.format(new Date());
}

// ✅ 对象复用或线程安全替代
private static final DateTimeFormatter FORMATTER = 
    DateTimeFormatter.ofPattern("yyyy-MM-dd");

for (int i = 0; i < 10000; i++) {
    String date = LocalDate.now().format(FORMATTER);
}
```

### 7.3 字符串拼接

```java
// ❌ 循环里用 + 拼接
String result = "";
for (int i = 0; i < 1000; i++) {
    result += i;  // 每次创建新 String 对象
}

// ✅ StringBuilder
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 1000; i++) {
    sb.append(i);
}
String result = sb.toString();
```

## 8. 缓存使用规范

### 8.1 缓存穿透

```java
// 问题：查询不存在的数据，每次都打到数据库
User user = cache.get(key);
if (user == null) {
    user = db.query(key);  // 每次都查库
    cache.put(key, user);  // 查不到就不缓存
}

// ✅ 方案 1：缓存空值
if (user == null) {
    cache.put(key, "NULL", 60);  // 缓存空值 60 秒
    return null;
}

// ✅ 方案 2：布隆过滤器
if (!bloomFilter.mightContain(key)) {
    return null;  // 肯定不存在
}
```

### 8.2 缓存击穿

```java
// 问题：热点 key 过期瞬间，大量请求打到数据库

// ✅ 互斥锁
public User getUser(Long id) {
    User user = cache.get(id);
    if (user == null) {
        String lockKey = "lock:" + id;
        if (redis.setnx(lockKey, "1", 10)) {
            try {
                user = db.query(id);
                cache.put(id, user);
            } finally {
                redis.del(lockKey);
            }
        } else {
            Thread.sleep(50);
            return getUser(id);  // 重试
        }
    }
    return user;
}
```

### 8.3 缓存雪崩

```java
// 问题：大量 key 同时过期，请求全部打到数据库

// ✅ 随机过期时间
int baseExpire = 3600;
int randomExpire = ThreadLocalRandom.current().nextInt(300);  // 0-5 分钟随机
cache.put(key, value, baseExpire + randomExpire);
```

## 9. 接口性能规范

### 9.1 超时设置

```java
// ✅ 设置连接超时和读超时
RestTemplate restTemplate = new RestTemplate();
restTemplate.setRequestFactory(factory);
factory.setConnectTimeout(3000);   // 连接超时 3s
factory.setReadTimeout(5000);      // 读超时 5s

// ❌ 不设置超时，可能无限等待
```

### 9.2 接口限流

```java
// ✅ Guava RateLimiter
RateLimiter limiter = RateLimiter.create(100);  // 每秒 100 个请求

public void handleRequest() {
    if (limiter.tryAcquire()) {
        // 处理请求
    } else {
        throw new TooManyRequestsException("请求过于频繁");
    }
}
```

### 9.3 接口幂等性

```java
// ✅ 唯一索引
CREATE UNIQUE INDEX uk_order_no ON `order` (order_no);

// ✅ Token 机制
@PostMapping("/order")
public String createOrder(@RequestParam String token) {
    if (!redis.del(token)) {
        return "请勿重复提交";
    }
    // 创建订单
}
```

### 9.4 熔断降级

```java
// ✅ Resilience4j
@CircuitBreaker(name = "userService", fallbackMethod = "fallback")
public User getUser(Long id) {
    return userService.getUser(id);
}

public User fallback(Long id, Throwable t) {
    return User.DEFAULT;  // 降级返回默认值
}
```

## 10. 常见反模式

| 反模式 | 问题 | 正确做法 |
|--------|------|---------|
| 密码明文存储 | 数据泄露即事故 | BCrypt 加密 |
| 日志打印敏感信息 | 合规风险 | 脱敏处理 |
| SQL 拼接用户输入 | SQL 注入 | 参数化查询 |
| 资源未关闭 | 资源泄漏 | try-with-resources |
| 大对象频繁创建 | GC 压力大 | 对象池/缓存 |
| 缓存无过期时间 | 内存无限增长 | 设置过期时间 |
| 不设置超时 | 无限等待 | 设置连接/读超时 |
| 缓存穿透/击穿/雪崩 | 数据库被打爆 | 空值缓存/互斥锁/随机过期 |

## 11. 动手练习

### 练习 1：修复安全问题

```java
@PostMapping("/login")
public String login(@RequestParam String username, @RequestParam String password) {
    log.info("用户登录: username={}, password={}", username, password);
    
    String sql = "SELECT * FROM user WHERE username='" + username + "' AND password='" + password + "'";
    User user = jdbcTemplate.queryForObject(sql, new BeanPropertyRowMapper<>(User.class));
    
    if (user != null) {
        return "success";
    }
    return "fail";
}
```

<details>
<summary>参考答案</summary>

问题：
1. 日志打印密码（敏感信息泄露）
2. SQL 拼接（注入风险）
3. 密码明文比对

修复：
```java
@PostMapping("/login")
public String login(@RequestParam String username, @RequestParam String password) {
    log.info("用户登录: username={}", username);  // 不打印密码
    
    String sql = "SELECT * FROM user WHERE username = ?";
    User user = jdbcTemplate.queryForObject(sql, new BeanPropertyRowMapper<>(User.class), username);
    
    if (user != null && passwordEncoder.matches(password, user.getPassword())) {
        return "success";
    }
    return "fail";
}
```

</details>
