## 1. 内置注解与元注解

```java
// Spring 常用内置注解
@Override           // 编译期检查
@Deprecated         // 标记废弃
@FunctionalInterface // 确保函数式接口
@SuppressWarnings   // 压制警告
@SafeVarargs        // 安全可变参数

// 元注解（注解的注解）
@Target(ElementType.METHOD)     // 可以用在哪（方法/类/字段）
@Retention(RetentionPolicy.RUNTIME)  // 保留到什么时候
@Documented
@Inherited
```

## 2. 自定义注解 + AOP

```java
// 1. 定义注解
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface LogExecution {
    String value() default "";
    boolean logArgs() default true;
    boolean logResult() default false;
}

// 2. AOP 切面处理注解
@Aspect
@Component
public class LogAspect {
    @Around("@annotation(logExecution)")
    public Object around(ProceedingJoinPoint pjp, LogExecution logExec) throws Throwable {
        long start = System.nanoTime();
        if (logExec.logArgs()) {
            System.out.println("Args: " + Arrays.toString(pjp.getArgs()));
        }
        Object result = pjp.proceed();
        long elapsed = (System.nanoTime() - start) / 1_000_000;
        System.out.println(logExec.value() + " took " + elapsed + "ms");
        return result;
    }
}

// 3. 使用
@LogExecution("查询用户")
public User getUser(Long id) { return repo.findById(id); }
```

## 3. 反射实战

```java
// 反射的核心 API
Class<?> clazz = User.class;

// 构造实例
Constructor<?> ctor = clazz.getDeclaredConstructor(String.class, int.class);
User user = (User) ctor.newInstance("Alice", 25);

// 访问字段（包括 private）
Field field = clazz.getDeclaredField("name");
field.setAccessible(true);               // 突破 private
field.set(user, "Bob");

// 调用方法
Method method = clazz.getDeclaredMethod("greet", String.class);
method.setAccessible(true);
method.invoke(user, "Hello");

// 获取注解信息
for (Field f : clazz.getDeclaredFields()) {
    if (f.isAnnotationPresent(Column.class)) {
        String columnName = f.getAnnotation(Column.class).name();
    }
}
```

```java
// 实战：通用 Bean 复制器
public static <T> T copyProperties(Object source, Class<T> targetClass) {
    T target = targetClass.getDeclaredConstructor().newInstance();
    for (Field srcField : source.getClass().getDeclaredFields()) {
        srcField.setAccessible(true);
        Field tgtField = targetClass.getDeclaredField(srcField.getName());
        tgtField.setAccessible(true);
        tgtField.set(target, srcField.get(source));
    }
    return target;
}
```

## 核心要点回顾

- `@Retention(RUNTIME)` = 反射可读（Spring 全靠它）
- 自定义注解 + AOP = 非侵入式横切逻辑（日志/权限/缓存/重试）
- 反射 = `getDeclaredField/Method` + `setAccessible(true)`
- 反射有性能开销，高频调用要缓存（Spring 内部已经缓存了）
