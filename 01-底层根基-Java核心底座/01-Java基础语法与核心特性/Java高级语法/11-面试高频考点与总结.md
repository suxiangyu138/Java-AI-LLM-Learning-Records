## 1. 高频面试题

### Q1（⭐⭐⭐⭐⭐）: Stream 的中间操作和终端操作有什么区别？

> 中间操作（filter/map/sorted）返回 Stream，惰性执行，直到终端操作触发
> 终端操作（collect/forEach/reduce）触发实际计算
> 核心：没有终端操作，Stream 不会执行

### Q2: Optional 的 orElse 和 orElseGet 的区别？

```java
// orElse: 参数总会被计算（即使 Optional 有值！）
String x = opt.orElse(expensiveDefault());  // expensiveDefault() 总执行 ❌

// orElseGet: 参数只有在 Optional 为空时才计算
String y = opt.orElseGet(() -> expensiveDefault());  // 惰性求值 ✅
```

### Q3: `? extends T` 和 `? super T` 的区别？（PECS）

> Producer Extends（? extends T）：只能读，适合作为"数据源"
> Consumer Super（? super T）：只能写，适合作为"数据接收方"
> 典型用法：`Collections.copy(List<? super T> dest, List<? extends T> src)`

### Q4: Record 和普通类的区别？

> Record 自动生成构造器、getter、equals、hashCode、toString
> 不可变（字段都是 final），不能继承，不能被继承
> 适用：DTO/VO/API Response/配置

### Q5: 虚拟线程和平台线程的区别？什么时候用？

> 虚拟线程廉价（百万级），适合 I/O 密集（API调用/DB查询）
> 平台线程昂贵（几千），适合 CPU 密集
> Spring Boot 3.2+: `spring.threads.virtual.enabled=true`

### Q6: Switch 模式匹配的优势？

> 替代 instanceof 链 → 更简洁
> 编译器穷举检查（配合密封类）→ 更安全
> Record 解构 → 直接提取字段
> `when` 守卫条件 → 加筛选而不破坏穷举
