## 1. 反射基础

### 1.1 什么是反射？

反射指在**运行时**获取、检查和操作类、方法、字段等成员的能力。

```
编译器 (javac)             运行时 (JVM)
  ┌─────────────┐         ┌──────────────────┐
  │ .java → .class│        │ Class Object      │
  │ 编译期类型检查 │        │ 反射 API          │
  │ 静态绑定     │        │ 动态调用         │
  └─────────────┘         └──────────────────┘
                           │
                           ├─ 检查任意类的结构
                           ├─ 创建任意类的对象
                           ├─ 调用任意方法
                           └─ 访问任意字段
```

### 1.2 反射的核心类和入口

```java
/**
 * 反射的核心类：
 * ┌─────────────────┬──────────────────────────────┐
 * │ Class<?>        │ 类的元数据                    │
 * │ Constructor<?>  │ 构造器                        │
 * │ Method          │ 方法                          │
 * │ Field           │ 字段                          │
 * │ Annotation      │ 注解                          │
 * │ Parameter       │ 参数 (JDK 8+)                 │
 * │ Type            │ 泛型类型接口                   │
 * └─────────────────┴──────────────────────────────┘
 */
```

## 2. 获取 Class 对象

### 2.1 三种方式的对比

```java
/**
 * 获取 Class 对象的三种方式 —— 等价但不完全相同
 */
public class GetClassDemo {

    public static void main(String[] args) throws Exception {
        // 方式 1: 类字面常量（最安全、最高效、编译期检查）
        Class<String> clazz1 = String.class;
        // 这种方式不会触发 static 初始化（安全）

        // 方式 2: 对象的 getClass() 方法
        String str = "hello";
        Class<? extends String> clazz2 = str.getClass();
        // 需要已有实例，运行时多态

        // 方式 3: Class.forName() — 最灵活，可加载未知类
        Class<?> clazz3 = Class.forName("java.lang.String");
        // 会触发 static 初始化！(除非使用 forName(name, false, loader))
        Class<?> clazz4 = Class.forName("java.lang.String", false,
                Thread.currentThread().getContextClassLoader());

        // 三种方式获取的 Class 是同一个（在同一个 ClassLoader 中）
        System.out.println(clazz1 == clazz2); // true
        System.out.println(clazz2 == clazz3); // true

        // 基本类型和数组也有 Class 对象
        Class<Integer> intClass = int.class;
        Class<int[]> arrayClass = int[].class;
        // int.class == Integer.TYPE (true)
        System.out.println(int.class == Integer.TYPE); // true
    }
}
```

## 3. 操作类结构

### 3.1 检查类的元信息

```java
/**
 * 通过反射查看类的完整结构
 */
@SuppressWarnings("unused")
public class ClassInspector {

    public static void inspectClass(String className) throws Exception {
        Class<?> clazz = Class.forName(className);

        System.out.println("=== Class: " + clazz.getName() + " ===");
        System.out.println("Simple Name: " + clazz.getSimpleName());
        System.out.println("Package: " + clazz.getPackageName());
        System.out.println("Modifiers: " + Modifier.toString(clazz.getModifiers()));

        // 父类
        System.out.println("Superclass: " + clazz.getSuperclass());

        // 接口
        System.out.println("Interfaces: ");
        for (Class<?> i : clazz.getInterfaces()) {
            System.out.println("  - " + i.getName());
        }

        // 构造器
        System.out.println("Constructors: ");
        for (Constructor<?> c : clazz.getDeclaredConstructors()) {
            System.out.println("  " + Modifier.toString(c.getModifiers())
                    + " " + c.getName() + "(" + paramsToString(c.getParameterTypes()) + ")");
        }

        // 方法（包括继承的）
        System.out.println("Public Methods: ");
        for (Method m : clazz.getMethods()) {
            System.out.println("  " + m.getReturnType().getSimpleName()
                    + " " + m.getName() + "(" + paramsToString(m.getParameterTypes()) + ")");
        }

        // 字段
        System.out.println("Declared Fields: ");
        for (Field f : clazz.getDeclaredFields()) {
            System.out.println("  " + Modifier.toString(f.getModifiers())
                    + " " + f.getType().getSimpleName() + " " + f.getName());
        }
    }

    private static String paramsToString(Class<?>[] params) {
        return Arrays.stream(params)
                .map(Class::getSimpleName)
                .collect(Collectors.joining(", "));
    }

    public static void main(String[] args) throws Exception {
        inspectClass("java.util.ArrayList");
    }
}
```

### 3.2 getMethods vs getDeclaredMethods

```java
/**
 * 关键区别：
 *
 * getXxx()            — 返回 public 成员（包括继承的）
 * getDeclaredXxx()    — 返回所有访问修饰符的成员（不包括继承的）
 */
public class MethodAccessibilityDemo {

    public static void main(String[] args) {
        Class<Sub> clazz = Sub.class;

        // getMethods(): 所有 public 方法（包括继承的）
        System.out.println("=== getMethods() ===");
        for (Method m : clazz.getMethods()) {
            System.out.println("  " + m.getName());
            // 包含 Object 的: toString, equals, hashCode, wait, notify, getClass
        }

        // getDeclaredMethods(): 本类所有方法（包括 private）
        System.out.println("=== getDeclaredMethods() ===");
        for (Method m : clazz.getDeclaredMethods()) {
            System.out.println("  " + m.getName());
            // 只包含 Sub 定义的方法
        }
    }

    static class Base {
        public void publicBase() {}
        private void privateBase() {}
    }

    static class Sub extends Base {
        public void publicSub() {}
        private void privateSub() {}
    }
}
```

## 4. 创建对象与调用方法

### 4.1 反射创建对象

```java
/**
 * 反射创建对象
 */
public class ReflectiveCreationDemo {

    public static class User {
        private final String name;
        private final int age;

        public User() {
            this.name = "default";
            this.age = 0;
        }

        public User(String name, int age) {
            this.name = name;
            this.age = age;
        }

        @Override
        public String toString() {
            return "User{name='" + name + "', age=" + age + "}";
        }
    }

    public static void main(String[] args) throws Exception {
        Class<?> clazz = User.class;

        // 方式 1: Class.newInstance() — JDK 9 标记为 deprecated
        // 仅能调用无参构造器
        User user1 = (User) clazz.getDeclaredConstructor().newInstance();
        System.out.println(user1);

        // 方式 2: Constructor.newInstance() — 推荐
        Constructor<?> constructor = clazz.getDeclaredConstructor(String.class, int.class);
        User user2 = (User) constructor.newInstance("Alice", 25);
        System.out.println(user2);

        // 方式 3: 根据参数动态查找构造器
        Constructor<?> matchingConstructor = findMatchingConstructor(clazz, "Bob", 30);
        if (matchingConstructor != null) {
            User user3 = (User) matchingConstructor.newInstance("Bob", 30);
            System.out.println(user3);
        }
    }

    private static Constructor<?> findMatchingConstructor(
            Class<?> clazz, Object... args) {
        for (Constructor<?> c : clazz.getDeclaredConstructors()) {
            Class<?>[] paramTypes = c.getParameterTypes();
            if (paramTypes.length == args.length) {
                boolean match = true;
                for (int i = 0; i < paramTypes.length; i++) {
                    if (!paramTypes[i].isInstance(args[i])) {
                        match = false;
                        break;
                    }
                }
                if (match) return c;
            }
        }
        return null;
    }
}
```

### 4.2 反射调用方法

```java
/**
 * 反射调用方法
 */
public class MethodInvokeDemo {

    static class Calculator {
        public int add(int a, int b) {
            return a + b;
        }

        private int multiply(int a, int b) {
            return a * b;
        }

        public static String greet(String name) {
            return "Hello, " + name;
        }
    }

    public static void main(String[] args) throws Exception {
        Class<?> clazz = Calculator.class;
        Object obj = clazz.getDeclaredConstructor().newInstance();

        // 调用 public 方法
        Method addMethod = clazz.getMethod("add", int.class, int.class);
        Object result = addMethod.invoke(obj, 3, 4);
        System.out.println("add(3,4) = " + result); // 7

        // 调用 private 方法（需要 setAccessible）
        Method multiplyMethod = clazz.getDeclaredMethod("multiply", int.class, int.class);
        multiplyMethod.setAccessible(true); // 绕过访问检查
        Object product = multiplyMethod.invoke(obj, 5, 6);
        System.out.println("multiply(5,6) = " + product); // 30

        // 调用 static 方法（第一个参数传 null）
        Method greetMethod = clazz.getMethod("greet", String.class);
        Object greeting = greetMethod.invoke(null, "World");
        System.out.println(greeting); // Hello, World
    }
}
```

## 5. 访问私有成员

```java
/**
 * setAccessible(true) 的原理与风险
 *
 * 原理：修改 JVM 中类可访问性标志位（suppressAccessChecks）
 * 风险：破坏封装性，可能绕过安全检查
 * 在模块化系统 (JPMS) 中：需要 --add-opens 权限
 */
public class PrivateFieldAccessDemo {

    static class SecretHolder {
        private String secret = "This is secret";
        private static final String STATIC_SECRET = "static secret";
    }

    public static void main(String[] args) throws Exception {
        Class<?> clazz = SecretHolder.class;
        Object obj = clazz.getDeclaredConstructor().newInstance();

        // 1. 读取私有字段
        Field secretField = clazz.getDeclaredField("secret");
        secretField.setAccessible(true); // ⚠️ 关键在于这里
        String value = (String) secretField.get(obj);
        System.out.println("Before: " + value);

        // 2. 修改私有字段
        secretField.set(obj, "modified secret");
        System.out.println("After: " + secretField.get(obj));

        // 3. 访问静态私有字段
        Field staticField = clazz.getDeclaredField("STATIC_SECRET");
        staticField.setAccessible(true);
        String staticValue = (String) staticField.get(null); // null for static
        System.out.println("Static: " + staticValue);

        // 4. 修改 final 字段（有风险，不推荐）
        // 使用 Field 的 modifiers 反射来移除 final 标志
        Field modifiersField = Field.class.getDeclaredField("modifiers");
        modifiersField.setAccessible(true);
        modifiersField.setInt(staticField, staticField.getModifiers() & ~Modifier.FINAL);
        staticField.set(null, "modified static");
        // 注意：inline 的 final 常量（编译期常量）不会被修改
    }
}
```

## 6. 反射性能与优化

### 6.1 反射的性能成本

```java
/**
 * 反射为什么慢？
 *
 * 1. 动态查找：Method.invoke() 需要解析方法，不像直接调用是固定的
 * 2. 类型检查：参数类型需要装箱/拆箱
 * 3. 安全检查：AccessibleObject 的权限检查
 * 4. JIT 无法内联：反射调用阻碍 JIT 优化
 * 5. 基本类型装箱：int → Integer 产生额外对象
 */
public class ReflectionPerformanceDemo {

    // 被调用的方法
    public static int add(int a, int b) {
        return a + b;
    }

    @BenchmarkMode(Mode.Throughput)
    @OutputTimeUnit(TimeUnit.MILLISECONDS)
    @Fork(1)
    @Warmup(iterations = 2, time = 1)
    @Measurement(iterations = 3, time = 1)
    public static class Bench {

        private static final Method REFLECTIVE_METHOD;
        static {
            try {
                REFLECTIVE_METHOD = ReflectionPerformanceDemo.class
                        .getMethod("add", int.class, int.class);
                REFLECTIVE_METHOD.setAccessible(true);
            } catch (NoSuchMethodException e) {
                throw new ExceptionInInitializerError(e);
            }
        }

        @Benchmark
        public int directCall() {
            return add(1, 2);
        }

        @Benchmark
        public int reflectiveCall() throws Exception {
            return (int) REFLECTIVE_METHOD.invoke(null, 1, 2);
        }

        @Benchmark
        public int reflectiveCallCached() throws Exception {
            return (int) REFLECTIVE_METHOD.invoke(null, 1, 2);
        }
        // 结果（大致倍数）：
        // directCall:          ~500M ops/s
        // reflectiveCall:      ~30M  ops/s (慢 15 倍)
    }
}
```

### 6.2 优化技巧

```java
/**
 * 反射优化技巧
 */
public class ReflectionOptimization {

    // 1. setAccessible(true) —— 跳过安全检查
    //    如果无此调用，慢 10 倍以上
    public static void optimizeSetAccessible() throws Exception {
        Method method = MyClass.class.getMethod("doSomething");
        method.setAccessible(true); // 关键优化
    }

    // 2. 缓存 Method/Field 对象 —— 避免重复查找
    private static final Map<String, Method> METHOD_CACHE = new ConcurrentHashMap<>();

    public static Object invokeCached(String className, String methodName,
                                       Object obj, Object... args) throws Exception {
        String key = className + "#" + methodName;
        Method method = METHOD_CACHE.computeIfAbsent(key, k -> {
            try {
                Method m = Class.forName(className).getMethod(methodName);
                m.setAccessible(true);
                return m;
            } catch (Exception e) {
                throw new RuntimeException(e);
            }
        });
        return method.invoke(obj, args);
    }

    // 3. 使用 MethodHandle（比反射快）
    //    见下一节

    // 4. 批量处理时减少反射调用
    //    不好的写法：
    public void badBatch(List<Item> items) throws Exception {
        Method m = Item.class.getMethod("process");
        for (Item item : items) {
            m.invoke(item); // 反复查找 Method
        }
    }

    //    好的写法：
    public void goodBatch(List<Item> items) throws Exception {
        Method m = Item.class.getMethod("process");
        m.setAccessible(true);
        for (Item item : items) {
            m.invoke(item); // Method 已缓存
        }
    }

    // 5. 使用 LambdaMetafactory（JIT 可内联）
    //    见下节示例

    static class MyClass {
        public void doSomething() {}
    }

    static class Item {
        public void process() {}
    }
}
```

### 7.1 MethodHandle

```java
import java.lang.invoke.*;

/**
 * MethodHandle (JDK 7+)
 *
 * 与反射对比：
 * - MethodHandle 更快（JIT 可内联）
 * - 反射是"模拟 Java 代码"，MethodHandle 是"模拟字节码"
 * - 反射检查可见性，MethodHandle 只检查类型
 */
public class MethodHandleDemo {

    public String greet(String name) {
        return "Hello, " + name;
    }

    public static void main(String[] args) throws Throwable {
        MethodHandles.Lookup lookup = MethodHandles.lookup();

        // 1. 查找 MethodHandle
        MethodType mt = MethodType.methodType(String.class, String.class);
        MethodHandle handle = lookup.findVirtual(
                MethodHandleDemo.class, "greet", mt);

        // 2. 调用（三种方式）
        MethodHandleDemo demo = new MethodHandleDemo();

        // 方式 A: invoke (自动类型适配)
        String result1 = (String) handle.invoke(demo, "World");
        System.out.println(result1);

        // 方式 B: invokeExact (严格类型匹配)
        String result2 = (String) handle.invokeExact(demo, "World");
        System.out.println(result2);

        // 方式 C: invokeWithArguments (参数数组)
        String result3 = (String) handle.invokeWithArguments(demo, "World");

        // 3. bindTo — 绑定接收者
        MethodHandle boundHandle = handle.bindTo(demo);
        String result4 = (String) boundHandle.invoke("Bound");
        System.out.println(result4);

        // 4. 性能比较：反射 vs MethodHandle vs 直接调用
```

### 7.2 VarHandle (JDK 9+)

```java
/**
 * VarHandle — 替代 AtomicXxxFieldUpdater
 * 提供对字段的原子操作
 */
public class VarHandleDemo {
    private volatile int counter = 0;
    private static final VarHandle COUNTER;

    static {
        try {
            COUNTER = MethodHandles.lookup()
                    .findVarHandle(VarHandleDemo.class, "counter", int.class);
        } catch (Exception e) {
            throw new ExceptionInInitializerError(e);
        }
    }

    public void increment() {
        // CAS 操作
        int current;
        do {
            current = (int) COUNTER.getVolatile(this);
        } while (!COUNTER.compareAndSet(this, current, current + 1));
    }

    // 其他 VarHandle 操作：
    // get/set — volatile 语义
    // getVolatile/setVolatile — 完整 volatile 语义
    // getOpaque/setOpaque — 防止重排序但不保证可见性
    // compareAndSet — CAS
    // getAndSet — 原子获取并设置
    // getAndAdd — 原子增加

    public static void main(String[] args) {
        VarHandleDemo demo = new VarHandleDemo();
        demo.increment();
        System.out.println((int) COUNTER.getVolatile(demo)); // 1
    }
}
```

## 9. 运行时注解处理

```java
/**
 * 运行时注解处理器 —— 表单验证框架示例
 */
public class AnnotationValidator {

    /**
     * 验证对象的所有字段
     */
    public static List<String> validate(Object obj) {
        List<String> errors = new ArrayList<>();
        Class<?> clazz = obj.getClass();

        for (Field field : clazz.getDeclaredFields()) {
            field.setAccessible(true);

            try {
                Object value = field.get(obj);

                // 处理 @NotNull
                NotNull notNull = field.getAnnotation(NotNull.class);
                if (notNull != null && value == null) {
                    errors.add(field.getName() + ": " + notNull.message());
                    continue;
                }

                // 处理 @Length（仅针对 String）
                Length length = field.getAnnotation(Length.class);
                if (length != null && value instanceof String) {
                    String str = (String) value;
                    if (str.length() < length.min() || str.length() > length.max()) {
                        errors.add(field.getName() + ": " + length.message()
                                + " (当前长度: " + str.length()
                                + ", 要求: " + length.min() + "-" + length.max() + ")");
                    }
                }

            } catch (IllegalAccessException e) {
                errors.add(field.getName() + ": 无法访问");
            }
        }

        return errors;
    }

    public static void main(String[] args) {
        UserForm validUser = new UserForm("Alice", "123456");
        UserForm invalidUser = new UserForm("A", "12");

        System.out.println("=== Valid User ===");
        validate(validUser).forEach(System.out::println); // 无错误

        System.out.println("=== Invalid User ===");
        validate(invalidUser).forEach(System.out::println); // 有错误
    }
```

## 11. 动态代理

### 11.1 JDK 动态代理

```java
import java.lang.reflect.InvocationHandler;
import java.lang.reflect.Method;
import java.lang.reflect.Proxy;

/**
 * JDK 动态代理 — 基于接口
 *
 * 原理：
 * 1. 运行时生成 $Proxy0.class（实现目标接口）
 * 2. 代理类将所有方法调用转发给 InvocationHandler
 * 3. 只能代理接口（需要 implements 某个接口）
 */
public class JdkProxyDemo {

    // 1. 接口
    interface GreetingService {
        String greet(String name);
        String farewell(String name);
    }

    // 2. 真实实现
    static class GreetingServiceImpl implements GreetingService {
        @Override
        public String greet(String name) {
            return "Hello, " + name;
        }

        @Override
        public String farewell(String name) {
            return "Goodbye, " + name;
        }
    }

    // 3. InvocationHandler
    static class LoggingHandler implements InvocationHandler {
        private final Object target;

        LoggingHandler(Object target) {
            this.target = target;
        }

        @Override
        public Object invoke(Object proxy, Method method, Object[] args) throws Throwable {
            System.out.println("[LOG] Before: " + method.getName());
            long start = System.nanoTime();

            Object result = method.invoke(target, args);

            long duration = (System.nanoTime() - start) / 1_000_000;
            System.out.println("[LOG] After: " + method.getName()
                    + " took " + duration + "ms");

            return result;
        }
    }

    // 4. 使用
    public static void main(String[] args) {
        // 设置：保存生成的 $Proxy0.class 文件到磁盘
        System.setProperty("sun.misc.ProxyGenerator.saveGeneratedFiles", "true");

        GreetingService target = new GreetingServiceImpl();
        GreetingService proxy = (GreetingService) Proxy.newProxyInstance(
                GreetingService.class.getClassLoader(),
                new Class<?>[]{GreetingService.class},
                new LoggingHandler(target)
        );

        // 调用代理方法
        System.out.println(proxy.greet("Alice"));
        System.out.println(proxy.farewell("Bob"));

        // 查看代理类信息
        System.out.println("Proxy class: " + proxy.getClass().getName());
        // com.sun.proxy.$Proxy0
    }
}
```

### 11.2 CGLIB 动态代理

```java
/**
 * CGLIB — 基于子类继承（不需要接口）
 *
 * 原理：
 * 1. 生成目标类的子类
 * 2. 重写目标类的非 final 方法
 * 3. 方法调用转发给 MethodInterceptor
 *
 * Spring AOP 自动选择：
 * - 有接口 → JDK 动态代理
 * - 无接口 → CGLIB 代理
 * Spring Boot 2.x+：默认使用 CGLIB
 */
public class CglibDemo {

    // 1. 不需要接口的类
    static class UserService {
        public void createUser(String name) {
            System.out.println("Creating user: " + name);
        }

        public final void doNotProxy() {
            // final 方法不会被 CGLIB 代理
        }
    }

    // 2. MethodInterceptor
    static class TransactionInterceptor implements MethodInterceptor {
        @Override
        public Object intercept(Object obj, Method method, Object[] args,
                                MethodProxy proxy) throws Throwable {
            System.out.println("[TX] Begin transaction");

            // 调用父类（目标类）同名方法
            Object result = proxy.invokeSuper(obj, args);

            System.out.println("[TX] Commit transaction");
            return result;
        }
    }

    // 3. 使用
    public static void main(String[] args) {
        // 需要引入 cglib 依赖
        Enhancer enhancer = new Enhancer();
        enhancer.setSuperclass(UserService.class);
        enhancer.setCallback(new TransactionInterceptor());

        UserService proxy = (UserService) enhancer.create();
        proxy.createUser("Alice");

        // 输出：
        // [TX] Begin transaction
        // Creating user: Alice
        // [TX] Commit transaction

        // 注意：final 方法不会被代理
        // proxy.doNotProxy(); // 直接调用，无拦截
    }
}
```

### 11.3 JDK 代理 vs CGLIB

| 对比维度 | JDK 动态代理 | CGLIB |
|---------|-------------|-------|
| 原理 | 实现接口的代理类 | 继承目标类的子类 |
| 要求 | 必须有接口 | 无接口限制 |
| 目标方法 | 任何接口方法 | 非 final 方法 |
| 性能（生成） | 快 | 慢（需生成字节码） |
| 性能（调用） | 略慢 | 略快 |
| Spring 默认 | 有接口时 | Boot 2.x+ 默认 |
| 依赖 | JDK 内置 | CGLIB (asm) |

### 12.1 简易 ORM 框架

```java
/**
 * 反射实战：简易 ORM 框架
 */
public class SimpleORM {

    // 1. 注解定义
    @Retention(RetentionPolicy.RUNTIME)
    @Target(ElementType.TYPE)
    @interface Table {
        String name();
    }

    @Retention(RetentionPolicy.RUNTIME)
    @Target(ElementType.FIELD)
    @interface Column {
        String name();
        boolean primaryKey() default false;
    }

    // 2. 实体类
    @Table(name = "users")
    static class User {
        @Column(name = "id", primaryKey = true)
        private Long id;

        @Column(name = "username")
        private String username;

        @Column(name = "email")
        private String email;

        // getters/setters...
        public Long getId() { return id; }
        public void setId(Long id) { this.id = id; }
        public String getUsername() { return username; }
        public void setUsername(String username) { this.username = username; }
        public String getEmail() { return email; }
        public void setEmail(String email) { this.email = email; }
    }

    // 3. 反射构建 SQL
    public static class QueryBuilder {
        public static String buildInsert(Object entity) {
            Class<?> clazz = entity.getClass();
            Table table = clazz.getAnnotation(Table.class);
            StringBuilder sb = new StringBuilder("INSERT INTO ");
            sb.append(table.name()).append(" (");

            List<String> columns = new ArrayList<>();
            List<String> values = new ArrayList<>();

            for (Field field : clazz.getDeclaredFields()) {
                Column column = field.getAnnotation(Column.class);
                if (column == null) continue;

                columns.add(column.name());
                field.setAccessible(true);
                try {
                    Object value = field.get(entity);
                    if (value instanceof Number) {
                        values.add(value.toString());
                    } else {
                        values.add("'" + value + "'");
                    }
                } catch (IllegalAccessException e) {
                    throw new RuntimeException(e);
                }
            }

            sb.append(String.join(", ", columns));
            sb.append(") VALUES (");
            sb.append(String.join(", ", values));
            sb.append(")");
            return sb.toString();
        }
    }

    public static void main(String[] args) {
        User user = new User();
        user.setId(1L);
        user.setUsername("alice");
        user.setEmail("alice@example.com");

        String sql = QueryBuilder.buildInsert(user);
        System.out.println(sql);
        // INSERT INTO users (id, username, email) VALUES (1, 'alice', 'alice@example.com')
    }
}
```

### 12.2 简易 DI 容器

```java
/**
 * 反射实战：简易依赖注入容器
 */
public class SimpleDI {

    @Retention(RetentionPolicy.RUNTIME)
    @Target(ElementType.FIELD)
    @interface Inject {}

    @Retention(RetentionPolicy.RUNTIME)
    @Target(ElementType.TYPE)
    @interface Component {}

    // 容器
    static class Container {
        private final Map<Class<?>, Object> beans = new HashMap<>();

        public <T> T getBean(Class<T> clazz) {
            return clazz.cast(beans.computeIfAbsent(clazz, this::createBean));
        }

        private Object createBean(Class<?> clazz) {
            try {
                // 创建实例
                Constructor<?> constructor = clazz.getDeclaredConstructor();
                Object instance = constructor.newInstance();

                // 注入依赖
                for (Field field : clazz.getDeclaredFields()) {
                    if (field.isAnnotationPresent(Inject.class)) {
                        field.setAccessible(true);
                        Object dependency = getBean(field.getType());
                        field.set(instance, dependency);
                    }
                }

                return instance;
            } catch (Exception e) {
                throw new RuntimeException("Failed to create bean: " + clazz, e);
            }
        }
    }

    // 使用
    @Component
    static class DatabaseConnection {
        public void connect() {
            System.out.println("Connected to database");
        }
    }

    @Component
    static class UserRepository {
        @Inject
        private DatabaseConnection db;

        public void findAll() {
            db.connect();
            System.out.println("Querying users...");
        }
    }

    public static void main(String[] args) {
        Container container = new Container();
        UserRepository repo = container.getBean(UserRepository.class);
        repo.findAll();
        // Connected to database
        // Querying users...
    }
}
```

## 13. 面试经典问题

### 基础问题

**Q1: 获取 Class 对象的三种方式？区别是什么？**
- 类名.class（安全，不触发 static 块）
- obj.getClass()（需要实例）
- Class.forName()（最灵活，触发 static 块）

**Q2: getMethods 和 getDeclaredMethods 的区别？**
- getMethods()：返回 public 方法（含继承的）
- getDeclaredMethods()：返回本类所有方法（不含继承的）

**Q3: @Retention 的三个值有什么区别？**
- SOURCE：只在源码（编译丢弃）
- CLASS：在 class 文件中（JVM 不加载）
- RUNTIME：JVM 加载（可通过反射获取）

**Q4: JDK 动态代理和 CGLIB 的区别？**
- JDK：基于接口，生成 Proxy 实现类
- CGLIB：基于继承，生成子类
- Spring AOP：有接口用 JDK，无接口用 CGLIB

### 进阶问题

**Q5: 反射的性能开销在哪里？如何优化？**
- 动态查找、类型检查、安全检查、JIT 无法内联
- 优化：setAccessible(true)、缓存 Method/Field、MethodHandle、减少装箱

**Q6: @Inherited 注解的作用？**
- 让子类继承父类的注解（仅类继承有效，接口/方法不继承）

**Q7: APT 和运行时注解处理的区别？**
- APT：编译时处理，适合代码生成（Lombok, MapStruct）
- 运行时反射：运行时处理，适合动态行为（Spring, Hibernate）

**Q8: InvocationHandler 的 invoke 方法做了什么？**
- 代理对象的所有方法调用都会转发到这里
- 可以添加额外逻辑（日志、事务、权限等）
- 最后通过 method.invoke(target, args) 调用真实对象

**Q9: MethodHandle 和 Method 有什么区别？**
- MethodHandle 更快（JIT 可内联）
- Method 是"大而全"的反射 API，MethodHandle 是"轻量级"方法引用
- MethodHandle 有类型签名（MethodType），编译期即确定

**Q10: 如何实现一个自定义注解的处理器？**
- 运行时：读取注解 → 反射处理
- 编译时：extends AbstractProcessor → 注册 → 生成代码
