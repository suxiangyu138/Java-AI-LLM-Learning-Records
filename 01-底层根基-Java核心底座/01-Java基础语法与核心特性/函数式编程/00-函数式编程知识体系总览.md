# 函数式编程知识体系总览

> 函数式编程在 Java 里不是一门"新语言"，而是一种**范式层思维**：用纯函数、不可变数据、函数组合与"错误即值"重新组织代码，把副作用赶到系统边界。与同级「Lambda表达式」（语法层）、「Java流Stream」（数据流层）、「Java高级语法」（特性层）分工互补，共同回答"Java 为什么值得用函数式思维写"以及"怎么写"

## 3. 学习路线推荐

### 路线一：入门（1 天）——先建立范式心智

01 → 02 → 03，重点掌握：

- 纯函数、引用透明、不可变三大支柱各自的"为什么"
- 副作用边界模式：哪些代码该纯、哪些该留在边界
- Record + 不可变集合的日常用法

### 路线二：进阶（2-3 天）——组合与错误处理

04 → 05 → 06，重点掌握：

- andThen/compose 组合子与管线设计
- 自定义函数式接口的受检异常与泛型坑
- Optional 链式与 sealed interface 实现 Result 模式

### 路线三：专家（1 周+）——数据流与并发

07 → 08 → 09 → 10，结合源码与官方文档：

- [JEP 485: Stream Gatherers](https://openjdk.org/jeps/485)（JDK 24 定稿）与 [Oracle Stream Gatherers 文档](https://docs.oracle.com/en/java/javase/26/core/stream-gatherers.html)
- [JEP 506: Scoped Values](https://openjdk.org/jeps/506)（JDK 25 定稿）、[JEP 525: Structured Concurrency](https://openjdk.org/jeps/525)（JDK 26 第 6 预览）
- [JDK 26 性能改进（Inside.java, 2026-06）](https://inside.java/2026/06/09/jdk-26-performance-improvements/)

## 4. 核心概念速查

| 概念 | 一句话定义 | 关键要点 |
|------|-----------|---------|
| 纯函数 | 输出只依赖参数、无任何副作用的函数 | 可缓存、可并行、可测试 |
| 引用透明 | 表达式可被其值安全替换 | 纯函数 + 不可变数据的必然结果 |
| 副作用 | 函数体对外部世界的影响 | IO/可变状态/异常/随机/时间/日志/缓存 |
| effect boundary | 确定性核心与副作用外壳的边界 | 纯逻辑在内、IO/落库在外 |
| 不可变对象 | 创建后状态永不改变 | Record、final 字段、不可变集合 |
| 高阶函数 | 接收函数参数或返回函数 | 组合子的基础 |
| 函数组合 | 用 andThen/compose 拼接函数 | 管线 = 函数链 |
| 柯里化 | 多参函数拆成单参函数链 | Java 需手工嵌套实现 |
| Optional | 可空值的类型化容器 | 链式 map/flatMap，禁作字段 |
| Result/Either | 把错误当作值返回 | sealed interface 实现，Java 原生版 Option |
| Stream Gatherers | 自定义中间操作的扩展点 | JEP 485，JDK 24 定稿 |
| 尾递归 | 递归调用在尾部、可复用栈帧 | JVM 无优化，深递归需 trampoline |
| 惰性求值 | 用到才计算 | Supplier/Lazy、Stream 中间操作 |

```text
│

│   └── 03 方法引用 —— :: 语法

│   └── 中间操作/终止操作/并行流/性能 —— API 细节
│   └── 本体系 07 只讲"范式如何结合"，细节交叉引用
├── Java高级语法/（特性层）
│   ├── 03 Optional 与空安全编程 —— Optional API 用法
│   ├── 07 Record 与密封类 —— 数据建模语法
│   └── 09 模式匹配与 Switch 表达式 —— 解构与分支
│   └── 本体系 03/06 从范式角度复用这些特性
├── 泛型 反射 注解/（类型系统）
│   └── 函数式接口与泛型擦除交汇（重载冲突、TypeToken）
├── JUC高并发编程/（并发层）
│   └── CompletableFuture 源码与线程池 —— 09 章的底层细节
└── 计算机组成原理/（硬件层）
    └── 装箱拆箱性能 —— 函数式风格引入的装箱成本（见 03/10 章）
```

> 💡 **体系定位**：同级四体系各管一层——「Lambda表达式」管**语法**（怎么写），「Java流Stream」管**数据流 API**（怎么操作集合），「Java高级语法」管**特性**（Record/Optional/模式匹配的用法），本体系管**范式**（为什么这样写、怎么组织副作用、怎么组合、怎么处理错误）。同一行代码，四个视角各有答案。

## 6. 版本演进时间线

| 版本 | 函数式相关变化 | 状态 |
|:---:|----------------|:---:|
| Java 8（2014） | **函数式元年**：Lambda、函数式接口、Stream、Optional、方法引用、CompletableFuture | ✅ 已定稿 |
| Java 9 | `Optional::stream`、`Stream.takeWhile/dropWhile/ofNullable` | ✅ |
| Java 10 | 局部变量 `var`（配合 lambda 简化声明） | ✅ |
| Java 14 | switch 表达式定稿（JEP 361） | ✅ |
| Java 16 | Record 定稿（JEP 395）、instanceof 模式匹配（JEP 394）——不可变数据建模革命 | ✅ |
| Java 17 | LTS；sealed 类定稿（JEP 409）——Result/Either 模式基石 | ✅ |
| Java 21 | LTS；switch 模式匹配定稿（JEP 441）、虚拟线程（JEP 444）、顺序集合（JEP 431） | ✅ |
| Java 24 | **Stream Gatherers 定稿（JEP 485）**——自定义中间操作 | ✅ |
| Java 25 | LTS（2025-09-16）；Scoped Values 定稿（JEP 506）、Compact Object Headers（JEP 519，堆减 10-20%） | ✅ |
| Java 26 | GA（2026-03-17，短期版）；结构化并发第 6 预览（JEP 525）、primitive 模式匹配第 4 预览（JEP 530）、Lazy Constants 第 2 预览（JEP 526） | 预览中 |
| 远期 | Valhalla 值类（JEP 401，首个预览计划 JDK 28）——未来不可变值类型的内存红利 | 计划中 |

> ⚠️ **版本窗口**：本体系以 **JDK 26**（2026-03-17 GA）与 **JDK 25 LTS**（2025-09-16）为基线；预览特性以 openjdk.org 公告为准（本文基于 2026-08 检索）。
