# 面向对象程序设计实验

## 课程概述
- **课程性质**：专业核心必修课（配套实验课）
- **适用专业**：计算机类各专业
- **开课学期**：与面向对象程序设计理论课同步
- **教学语言**：C++ 或 Java
- **考核方式**：实验报告 + 上机考核 + 综合项目

## 核心知识点

### 实验一：类与对象基础（C++版）
- 类的定义
  - 成员变量（属性）+ 成员函数（方法）
  - 访问控制符：public（公开）、private（私有，仅类内访问）、protected（受保护，子类也可访问）
- 构造函数
  - 默认构造函数：无参数，创建对象时自动调用
  - 带参构造函数：初始化对象时传入参数
  - 拷贝构造函数：ClassName(const ClassName& obj)，用于对象复制
  - 初始化列表：ClassName(int a, int b) : x(a), y(b) { }
- 析构函数
  - ~ClassName()，对象销毁时自动调用
  - 用于释放对象占用的资源（动态分配的堆内存、文件句柄等）
- 对象创建
  - 栈对象：ClassName obj;（自动析构）
  - 堆对象：ClassName *p = new ClassName(); ... delete p;（手动管理）
  - 对象数组：ClassName arr[10]; 或 new ClassName[10] + delete[] arr
- 练习：设计一个日期类 Date
  - 属性：年、月、日
  - 方法：设置日期、显示日期、判断闰年、计算下一天的日期

### 实验二：继承
- 继承语法
  - class Derived : public Base { ... };
  - 三种继承方式：
    - public继承：基类public→派生类public，基类protected→派生类protected
    - protected继承：基类public+protected→派生类protected
    - private继承（默认）：基类public+protected→派生类private
- 派生类构造函数
  - 初始化列表调用基类构造：Derived(params) : Base(base_params), own_member(init) { }
  - 构造顺序：基类构造→派生类成员构造→派生类构造函数体
  - 析构顺序：派生类析构→派生类成员析构→基类析构（与构造相反）
- 同名成员处理
  - 派生类定义了与基类同名的成员函数→隐藏基类同名函数（包括所有重载版本）
  - 访问基类同名函数：Base::func()
- 练习：
  - 定义基类 Animal（name, age, speak()）
  - 派生类 Dog（+ breed, speak()输出"汪汪"）和 Cat（+ color, speak()输出"喵喵"）
  - 创建对象数组，演示调用各自的speak()

### 实验三：多态与虚函数
- 虚函数
  - 声明：基类中用 virtual 关键字声明函数
  - 重写(Override)：派生类中重新定义虚函数（函数签名必须一致）
  - 动态绑定：通过基类指针/引用调用虚函数时，运行时根据实际对象类型调用对应的重写版本
  - override关键字：明确标记重写意图，编译器会检查是否正确重写
- 多态的条件
  1. 有继承关系
  2. 子类重写父类虚函数
  3. 通过父类指针或引用调用虚函数
- 虚函数表(vtable)机制
  - 含有虚函数的类在内存中有一个指向虚函数表的指针(vptr)
  - vtable存储该类所有虚函数的实际地址
  - 调用虚函数时通过 vptr → vtable → 函数地址 查找
- 纯虚函数与抽象类
  - 纯虚函数：virtual void func() = 0;（没有函数体）
  - 抽象类：含有纯虚函数的类，不能实例化对象
  - 派生类必须实现所有纯虚函数才能成为具体类
- 虚析构函数
  - 基类析构函数应为virtual：delete基类指针时确保调用派生类析构函数
- 练习：设计图形类层次
  - 抽象基类 Shape（纯虚函数 area() 和 perimeter()）
  - 派生类：Circle(半径)、Rectangle(长宽)、Triangle(三边)
  - 用 Shape* 数组统一求面积和周长

### 实验四：运算符重载（C++）
- 运算符重载规则
  - 不能重载的运算符：. .* :: ?: sizeof
  - 不能创建新的运算符
  - 重载后优先级和结合性不变
- 成员函数重载
  - 格式：返回类型 operator运算符(参数) { ... }
  - + 重载：Complex operator+(const Complex& other)
  - = 重载：注意自赋值检查和深拷贝
- 友元函数重载
  - 用于左操作数不是本类对象的情况
  - << 重载（输出流）：friend ostream& operator<<(ostream& os, const ClassName& obj)
  - >> 重载（输入流）：friend istream& operator>>(istream& is, ClassName& obj)
- 练习：设计复数类 Complex
  - 重载 + - * /（四则运算）
  - 重载 == !=（关系运算）
  - 重载 << >>（流输入输出）

### 实验五：模板与STL（C++）
- 函数模板
  - template<typename T> T max(T a, T b) { return a > b ? a : b; }
  - 编译器根据实参自动推导类型参数
- 类模板
  - template<typename T> class Stack { T data[100]; int top; ... };
  - 实例化：Stack<int> intStack; Stack<string> strStack;
- STL容器
  - vector：动态数组，push_back/pop_back、随机访问[]
  - list：双向链表，push_front/pop_back、splice拼接，不支持随机访问[]
  - map：键值对（红黑树实现），有序，[]会插入新元素
  - set：不重复元素集合（红黑树实现），insert/erase/find
  - stack/queue：适配器，底层默认用deque
- STL算法
  - sort(v.begin(), v.end())：排序，可传自定义比较函数
  - find(v.begin(), v.end(), value)：查找
  - for_each(v.begin(), v.end(), func)：对每个元素执行func
- 练习：用vector+map实现词频统计器

### 实验六：异常处理与文件IO（C++）
- 异常处理
  - try { 可能抛异常的代码; } catch (异常类型 e) { 处理; }
  - throw 抛出异常对象（可以是任意类型）
  - 标准异常类：std::exception、std::runtime_error、std::out_of_range
  - 栈展开(Stack Unwinding)：异常抛出时沿调用链向上寻找catch，途中析构局部对象
- 文件IO流
  - ofstream写文件：open→<<写入→close
  - ifstream读文件：open→>>或getline读取→检查eof()→close
  - fstream读写：可同时打开读写模式
  - 二进制读写：write((char*)&obj, sizeof(obj))/read()
- 练习：实现可数据持久化的学生管理系统（使用文件存储）

### 实验七：综合项目
- 小型图书馆管理系统
  - 实体：Book(书号/书名/作者/状态)、Reader(读者号/姓名/最多借3本)、BorrowRecord(书号/读者号/借书日期/还书日期)
  - 功能：增删图书、读者注册、借书(检查库存+读者上限)、还书(计算逾期)、查询
  - 技术点：类层次设计、STL容器、文件持久化、异常处理
