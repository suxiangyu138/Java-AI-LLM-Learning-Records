## 3. 2026 面试趋势与备考路线

### 3.1 趋势判断

| 趋势 | 说明 | 应对 |
|------|------|------|
| 基础权重不降反升 | 基础/集合/并发/JVM 仍占 40%+ 权重 | 本大全 01-04 模块 |
| "为什么"式追问 | 少问"是什么"，多问"为什么这样设计" | 每个答案补"设计动机" |
| 场景题比例上升 | 不再单问 HashMap，而是"高并发下为什么选 CHM" | 06 场景实战模块 |
| 新特性进入面试 | Java 21+（虚拟线程）已成高频考点 | 05 新特性模块 |
| 八股+实战融合 | 原理讲不清、代码写不出都不行 | 答案含代码 + 记忆点 |

## 5. 核心概念速查

| 高频考点 | 一句话答案 |
|----------|-----------|
| Java 值传递？ | 只有值传递，引用类型传的是地址值 |
| String 为什么不可变？ | final 类 + private final char[] + 不暴露修改入口 |
| HashMap 底层？ | 数组+链表+红黑树，负载因子 0.75，扩容 2 倍 |
| 为什么 HashMap 线程不安全？ | 并发 put 数据丢失、扩容死循环（JDK7 头插） |
| synchronized 原理？ | 对象头 Mark Word → Monitor，锁升级：偏向→轻量→重量 |
| volatile 能保证原子性吗？ | 不能，只保证可见性 + 有序性 |
| ThreadLocal 为什么内存泄漏？ | key 弱引用、value 强引用，必须 remove() |
| 线程池参数？ | core/max/keepAlive/queue/threadFactory/handler |
| 双亲委派？ | 先父后子加载，防止重复加载 + 沙箱安全 |
| 新生代 GC 为什么用复制算法？ | 存活率低，复制成本小 |
| G1 vs CMS？ | G1 分区 + 可预测停顿，CMS 标记清除有碎片 |
| 虚拟线程？ | M:N 调度，轻量级，适合高并发 IO 场景 |
