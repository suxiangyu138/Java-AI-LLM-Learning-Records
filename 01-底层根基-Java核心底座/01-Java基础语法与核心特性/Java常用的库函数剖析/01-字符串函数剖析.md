## 1. String 不可变性与常量池

**String 不可变**（final 类 + final 字段）——由此推出三个行为：

```java
String s1 = "hello";
String s2 = "hello";
String s3 = new String("hello");

s1 == s2;        // true（常量池复用同一对象）
s1 == s3;        // false（new 创建新对象）
s1.equals(s3);   // true（值相等）

s1 = s1 + " world";   // 不是修改 s1，而是创建新字符串
```

**常量池的规则**（面试必答）：

```text
① 字面量（"hello"）→ 常量池（编译期确定）
② new String("hello") → 堆中新对象（常量池中的字面量仍存在）
③ intern()：手动放入常量池（返回池中对象）
④ 拼接 "+"：编译期常量折叠（"a"+"b" → "ab" 在常量池）
   运行时拼接（变量）→ new StringBuilder（见第 5 节）
```

> 🎯 **核心要点**：String 不可变 → **"=="比的是引用、equals 比的是值**——常量池让字面量共享；`new String()` 与 intern 是面试经典题；拼接底层见第 5 节。

## 2. 切割与拼接：split / join / concat

```java
// split：按正则切割
String csv = "a,b,,c";
csv.split(",");                 // [a, b, , c]（空串保留！）
csv.split(",", -1);             // [a, b, , c]（-1 保留尾部空）
csv.split("[,]");               // 正则字符类
csv.split("\\.");               // 点号必须转义（正则元字符！）
// ⚠️ 坑：split(".") 切不出任何东西（. 是任意字符正则）

// 拼接
String.join(",", "a", "b");     // "a,b"（JDK 8+）
String.join(",", list);          // 集合拼接
"a" + "b";                      // 简单拼接
"a".concat("b");                // concat（只接受 String）
```

**split 的三个坑**（面试高频）：

| 坑 | 现象 | 解法 |
|----|------|------|
| 正则元字符 | `split(".")` 无效 | 转义 `split("\\.")` 或 `Pattern.quote` |
| 尾部空串丢弃 | `"a,".split(",")` → [a] | 负 limit：`split(",", -1)` |
| 空串保留 | `"a,,b"` → 含空串 | 事后过滤（`filter`） |

> 🎯 **核心要点**：split = "**按正则切 + 三个坑（元字符/尾部空/空串）**"——**记忆：`split("\\.", -1)` 是"保留一切"的稳妥写法**；join 是 split 的反操作（JDK 8+）。

## 3. 查找与替换：contains / replace 家族

```java
// 查找
"hello".contains("ell");         // true（子串）
"hello".startsWith("he");        // true
"hello".endsWith("lo");          // true
"hello".indexOf("l");            // 2（首次出现；-1 = 不存在）
"hello".lastIndexOf("l");        // 3

// 替换家族（区分：字面量 vs 正则）
"a-b-c".replace("-", "+");        // "a+b+c"（字面量替换）
"a-b-c".replaceAll("-", "+");     // 同上（但 - 是正则元字符！这里恰好等效）
"a1b2".replaceAll("\\d", "x");    // "axbx"（正则替换）
"a-b".replaceFirst("-", "+");     // "a+b"（只替换第一个）

// ⚠️ 经典坑：replaceAll 的第一参数是正则
"a.b.c".replaceAll(".", "x");     // "xxx"！. 匹配任意字符
// 正确：replace(".", "x")（字面量）或 replaceAll("\\.", "x")
```

**replace vs replaceAll 速查**：

| 方法 | 第一参数 | 替换范围 | 场景 |
|------|---------|---------|------|
| replace(char, char) | 字符 | 全部 | 字符替换 |
| replace(CharSequence, CharSequence) | **字面量** | 全部 | 字符串替换（首选） |
| replaceAll | **正则** | 全部 | 正则替换（需转义） |
| replaceFirst | 正则 | 第一个 | 只替换一次 |

> 🎯 **核心要点**：替换家族 = "**replace 字面量、replaceAll 正则**"——**"`replaceAll(".")` 全变 x"是最高频面试坑**；日常字符串替换用 `replace`（免转义）。

## 4. substring / strip / trim 的边界

```java
// substring：左闭右开
"hello".substring(1, 3);       // "el"（[1,3)）
"hello".substring(2);          // "llo"（[2, 末尾)）
// ⚠️ 边界：substring(0, 0) = ""；substring(5) = ""；越界抛 IndexOutOfBounds

// 去空白：trim vs strip（JDK 11 重要差异）
"  hi  ".trim();               // "hi"（只去 ≤ U+0020 空格）
"  hi ".trim();           // "  hi"（NBSP 不去除！）
"  hi ".strip();          // "hi"（JDK 11+：去所有 Unicode 空白 ✅）
"  hi  ".stripLeading();       // "hi  "（去前导）
"  hi  ".stripTrailing();      // "  hi"（去尾部）

// 空判断
"".isEmpty();                  // true
"   ".isEmpty();               // false（长度 3）
"   ".isBlank();               // true（JDK 11：全空白）
```

**trim vs strip 速查（面试必答）**：

| 方法 | 版本 | 去除范围 | 典型场景 |
|------|:----:|---------|---------|
| trim() | 一直 | 仅 ≤ U+0020 | 老代码 |
| strip() | JDK 11 | **所有 Unicode 空白** | **现代首选**（含 NBSP） |
| isBlank() | JDK 11 | 全空白判断 | 替代 isEmpty+trim 组合 |

> 🎯 **核心要点**：边界三兄弟 = "**substring 左闭右开 + trim 只去 ASCII 空格 + strip 去 Unicode 空白（JDK 11 首选）**"——**"trim 不去 NBSP"是最易踩的隐藏坑**；isBlank 是 isEmpty+trim 的现代替代。

## 5. StringBuilder 与拼接效率

**字符串拼接的底层**：

```text
① 编译期常量："a" + "b" → 编译期折叠为 "ab"（常量池）
② 运行时变量：s + "x" → new StringBuilder().append(s).append("x").toString()
③ 循环拼接：每次迭代 new StringBuilder → 性能灾难！
```

```java
// ❌ 循环拼接（每次迭代创建 StringBuilder）
String s = "";
for (int i = 0; i < 10000; i++) {
    s += i;                 // 每次创建新对象 → O(n²) 复制
}

// ✅ StringBuilder（一个对象复用）
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 10000; i++) {
    sb.append(i);
}
String result = sb.toString();
```

**三个类的选择**：

| 类 | 线程安全 | 场景 | 注意 |
|----|:-------:|------|------|
| String | ✅ 不可变 | 少量拼接/常量 | 循环拼接勿用 |
| StringBuilder | ❌ | **单线程拼接（默认）** | 容量预估 `new StringBuilder(size)` |
| StringBuffer | ✅ 同步 | 多线程共享拼接 | 性能差，极少用 |
| StringJoiner | ❌ | **带分隔符拼接** | `join` 的底层 |

```java
// StringJoiner：带分隔符（join 的底层实现）
StringJoiner sj = new StringJoiner(", ", "[", "]");
sj.add("a").add("b");
sj.toString();        // "[a, b]"
```

> 🎯 **核心要点**：拼接效率 = "**循环用 StringBuilder（一个对象）而非 +=（每次新建）**"——**O(n²) vs O(n) 的差距**是面试必答；StringBuffer 只在多线程共享时用（罕见）。

## 6. 正则相关：matches / replaceAll / split

**String 的三个正则入口**：

```java
// ① matches：整个字符串是否匹配（隐式 ^...$）
"13812345678".matches("1\\d{10}");      // true（全匹配）
// ⚠️ 坑：matches 是全匹配，部分匹配用 Pattern 的 find()

// ② replaceAll/replaceFirst：正则替换（见第 3 节）
// ③ split：正则切割（见第 2 节）

// 底层：每次调用都编译 Pattern（性能）
// 高频场景应预编译：
private static final Pattern PHONE = Pattern.compile("1\\d{10}");
PHONE.matcher(s).matches();              // 复用编译结果 ✅
```

**正则性能与坑**：

```text
① 预编译：高频正则用 Pattern 常量（String.matches 每次都编译）
② 回溯灾难：复杂正则（嵌套量词）可能指数回溯（ReDoS）
③ 转义：Java 字符串中 \ 要写 \\（"\\d" 才是 \d）
④ 全匹配 vs 部分：matches（全）vs find（部分）
```

> 🎯 **核心要点**：正则入口 = "**matches 全匹配 + 预编译 Pattern（性能）**"——**"String.matches 每次都编译"是隐藏性能坑**；复杂正则有回溯风险（ReDoS 在 `Java有关Hash的一切/05` 有安全视角）。

## 7. 函数速查表

**String 高频函数速查**（开发/面试快查）：

| 函数 | 作用 | 坑点 |
|------|------|------|
| equals/equalsIgnoreCase | 值比较/忽略大小写 | == 比引用 |
| contains/indexOf | 子串判断/定位 | indexOf 返回 -1 |
| startsWith/endsWith | 前后缀 | — |
| substring(a,b) | 截取 [a,b) | 越界异常 |
| split(regex) | 正则切割 | 元字符/尾部空串 |
| join(delim, ...) | 拼接（JDK 8+） | — |
| replace/replaceAll | 字面量/正则替换 | replaceAll 需转义 |
| trim/strip/isBlank | 去空白/空判断 | trim 不去 Unicode 空白 |
| matches(regex) | 全匹配 | 每次编译 Pattern |
| toLowerCase/UpperCase | 大小写 | 有 Locale 重载（土耳其 i 问题） |
| valueOf(x) | 转字符串 | 与 toString 区别（null 安全） |
| format(fmt, args) | 格式化 | %s/%d 类型匹配 |

**一句话总结**：

```text
String 的核心认知：
  不可变（== vs equals）+ 常量池（字面量共享）
  split 正则三坑 + replace 字面量首选
  strip 优于 trim（JDK 11）+ isBlank 空判断
  循环拼接用 StringBuilder（O(n) 而非 O(n²)）
```

> 🎯 **核心要点**：速查表 12 函数 = "**String 日常使用的完整清单**"——**每个坑点都是面试细节题来源**；记忆主线 = "不可变 + 正则转义 + 现代替代（strip/isBlank）"。
