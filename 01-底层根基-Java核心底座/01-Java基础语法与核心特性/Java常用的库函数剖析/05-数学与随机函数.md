## 1. Math 家族：取整/极值/floorMod

```java
// 取整三兄弟（区别在负数）
Math.round(3.5);        // 4（四舍五入，返回 long）
Math.ceil(3.1);         // 4.0（向上取整）
Math.floor(3.9);        // 3.0（向下取整）
Math.round(-3.5);       // -3（⚠️ 四舍五入：-3.5 → -3！）
// 注意：Math.round 是"加 0.5 后向下取整"→ 负数行为反直觉

// 极值
Math.max(3, 5);         // 5
Math.min(3, 5);         // 3

// 取模：floorMod vs %（负数差异）
-3 % 5;                 // -3（Java 的 % 结果与左操作数同号）
Math.floorMod(-3, 5);   // 2（✅ 数学意义上的模，结果与除数同号）
// 应用：循环索引、哈希散列（负数友好）

// 幂与根
Math.pow(2, 10);        // 1024.0（double）
Math.sqrt(16);          // 4.0
Math.abs(-5);           // 5（⚠️ Integer.MIN_VALUE 的 abs 还是负的！）

// 常量
Math.PI; Math.E;
```

**abs 的溢出陷阱**：

```java
Math.abs(Integer.MIN_VALUE);   // -2147483648（还是负的！溢出）
// 安全：long 转换或 Math.absExact（JDK 15+，溢出抛异常）
Math.absExact(Integer.MIN_VALUE);   // ❌ ArithmeticException（JDK 15+）
```

> 🎯 **核心要点**：Math = "**round 负数反直觉 + floorMod 负数友好 + abs 溢出**"三个坑——**"Math.abs(Integer.MIN_VALUE) 仍是负"与"round(-3.5) = -3"**是面试细节题；floorMod 是数学模的正确姿势。

## 2. 浮点陷阱：0.1 + 0.2

**浮点二进制表示的精度问题**（面试必答）：

```java
0.1 + 0.2;              // 0.30000000000000004（不是 0.3！）
1.0 - 0.9;              // 0.09999999999999998
0.1 * 3;                // 0.30000000000000004

// 原因：0.1 的二进制是无限循环小数（IEEE 754 无法精确表示）
// 比较浮点：
double a = 0.1 + 0.2;
a == 0.3;               // false！

// 阈值比较（容忍误差）
Math.abs(a - 0.3) < 1e-9;    // true（工程比较法）

// 精确场景（金额）：BigDecimal（见下节）
```

**浮点使用规范**：

```text
① 精确值（金额/分数）→ BigDecimal（绝不用 double）
② 科学计算/性能 → double（接受误差）
③ 比较 → 阈值（epsilon）而非 ==
④ 显示 → DecimalFormat 或 String.format（格式化而非计算）
```

> 🎯 **核心要点**：浮点陷阱 = "**0.1+0.2 != 0.3（二进制无法精确表示）**"——**"金额用 BigDecimal、科学用 double、比较用阈值"**三条规范；这是 Java 面试的"入场题"。

## 3. BigDecimal：精度与四个构造器

**BigDecimal 的四个构造器**（精度差异巨大）：

```java
// ① double 构造：不精确（危险！）
new BigDecimal(0.1);        // 0.1000000000000000055511151231257827...（double 的完整值）

// ② String 构造：精确（✅ 首选）
new BigDecimal("0.1");      // 0.1（精确）

// ③ 静态 valueOf：精确（推荐）
BigDecimal.valueOf(0.1);    // 0.1（内部用字符串表示 ✅）

// ④ int/long 构造：精确
new BigDecimal(10);         // 10

// 结论：金额场景一律 new BigDecimal(String) 或 valueOf
BigDecimal bd = new BigDecimal("19.99");   // ✅
BigDecimal bd2 = BigDecimal.valueOf(19.99); // ✅（valueOf 接受 double 但内部转字符串）
```

**为什么 new BigDecimal(0.1) 不精确**：

```text
double 0.1 本身就不精确（二进制近似）
→ new BigDecimal(0.1) 是"把不精确的 double 值完整展开"
→ 而 "0.1" 字符串是精确的十进制表示
→ 记忆：构造器入参选 String/valueOf，绝不用 double
```

> 🎯 **核心要点**：BigDecimal 构造 = "**String/valueOf 精确、double 构造不精确**"——**"new BigDecimal(0.1) 与 new BigDecimal('0.1') 的区别"是必考**；金额场景铁律 = String 构造。

## 4. BigDecimal 运算与取舍模式

```java
// 运算（不可变：每次返回新对象）
BigDecimal a = new BigDecimal("10.5");
BigDecimal b = new BigDecimal("3");
a.add(b);                 // 13.5
a.subtract(b);            // 7.5
a.multiply(b);            // 31.5
a.divide(b, 2, RoundingMode.HALF_UP);   // 3.50（除法必须指定精度+模式！）

// ⚠️ 除法坑：不指定精度抛 ArithmeticException（无限小数）
// a.divide(b) → ❌ Non-terminating decimal expansion

// 比较（⚠️ equals 与 compareTo 不同）
new BigDecimal("1.0").equals(new BigDecimal("1.00"));    // false（scale 不同！）
new BigDecimal("1.0").compareTo(new BigDecimal("1.00")); // 0（数值相等 ✅）
// → 排序/比较用 compareTo，别用 equals

// 取舍模式（RoundingMode）
RoundingMode.HALF_UP;     // 四舍五入（默认，账务常用）
RoundingMode.HALF_DOWN;   // 五舍六入
RoundingMode.HALF_EVEN;   // 银行家舍入（偶数优先）
RoundingMode.DOWN;        // 向零截断
RoundingMode.UP;          // 远离零

// 金额格式化
BigDecimal amount = new BigDecimal("1234.5");
amount.setScale(2, RoundingMode.HALF_UP);   // 1234.50（保留两位）
```

**BigDecimal 使用规范**（2026 金额场景）：

```text
① 构造：String/valueOf（不用 double）
② 除法：必须指定 scale + RoundingMode
③ 比较：compareTo（equals 含 scale 语义）
④ 存储：数据库 DECIMAL、JSON 字符串（防精度丢失）
⑤ 性能：高频场景注意（BigDecimal 慢于 double 一个量级）
```

> 🎯 **核心要点**：BigDecimal = "**除法必带精度 + compareTo 而非 equals + setScale 格式化**"——**"equals vs compareTo（1.0 vs 1.00）"是最高频坑**；金额三规范（String 构造/除法精度/compareTo）是面试标准答案。

## 5. BigInteger：超大整数

**BigInteger：任意精度整数**（超过 long 范围时）：

```java
BigInteger big = new BigInteger("123456789012345678901234567890");
BigInteger a = BigInteger.valueOf(100);        // 从 long 构造

// 运算
big.add(BigInteger.TEN);
big.multiply(big);
big.pow(10);

// 常用常量与方法
BigInteger.ZERO; BigInteger.ONE; BigInteger.TEN;
big.compareTo(other);         // 比较（-1/0/1）
big.isProbablePrime(100);     // 素性测试（密码学）

// 与 long 互转
big.longValue();              // 溢出截断（⚠️ 超范围丢失精度）
big.toString();               // 十进制字符串

// 应用场景：加密（RSA）、超大数计算（阶乘）、哈希
```

> 🎯 **核心要点**：BigInteger = "**任意精度整数（long 不够时）**"——**"longValue 溢出截断"是坑**（超范围前先 compareTo 检查）；加密与超大数计算是主场（`Java有关Hash的一切/07` 密码学联动）。

## 6. 随机数三兄弟

**Random 家族的三种选择**（2026 实践）：

```java
// ① Random：默认（线程安全但竞争）
Random r = new Random();
r.nextInt(100);          // [0, 100) 随机整数
r.nextDouble();          // [0.0, 1.0)
r.nextInt(10) + 1;       // [1, 10]（偏移）

// ② ThreadLocalRandom：✅ 现代首选（每线程独立，无竞争）
ThreadLocalRandom.current().nextInt(100);
ThreadLocalRandom.current().nextLong();

// ③ SecureRandom：密码学安全（加密场景）
SecureRandom sr = new SecureRandom();
sr.nextBytes(buffer);    // 安全随机字节（Token/密钥）

// JDK 17+：RandomGenerator 统一接口
RandomGenerator g = RandomGenerator.getDefault();   // 现代入口
```

**三兄弟选择速查**：

| 类 | 线程安全 | 密码学安全 | 场景 |
|----|:-------:|:---------:|------|
| Random | ✅（竞争） | ❌ | 通用（遗留） |
| ThreadLocalRandom | ✅（无竞争） | ❌ | **通用首选** |
| SecureRandom | ✅ | ✅ | Token/密钥 |

**随机数其他函数**：

```java
// 集合随机（Collections 联动）
Collections.shuffle(list);           // 打乱
list.get(new Random().nextInt(list.size()));   // 随机取元素（注意空集合）

// 随机整数安全：nextInt(n) 边界 [0, n)
// 取 [min, max]：min + r.nextInt(max - min + 1)
```

> 🎯 **核心要点**：随机三兄弟 = "**ThreadLocalRandom（通用首选）+ SecureRandom（安全场景）+ Random（遗留）**"——**"安全随机必须 SecureRandom"**（Random 可预测）；`nextInt(n)` 的半开区间边界是细节考点。

## 7. 函数速查表

**数学与随机速查**（开发/面试快查）：

| 场景 | 函数 | 坑点 |
|------|------|------|
| 取整 | Math.round/ceil/floor | round 负数反直觉 |
| 取模 | Math.floorMod | % 负数与左操作数同号 |
| 绝对值 | Math.abs / absExact(15+) | MIN_VALUE 溢出 |
| 精确小数 | BigDecimal(String) | double 构造不精确 |
| 除法 | divide(b, scale, mode) | 不指定精度抛异常 |
| 比较 | compareTo | equals 含 scale |
| 超大数 | BigInteger | longValue 截断 |
| 通用随机 | ThreadLocalRandom | 首选 |
| 安全随机 | SecureRandom | 密码学必须 |
| 浮点比较 | 阈值（epsilon） | == 永远不可靠 |

**一句话总结**：

```text
Math 三坑：round 负数、floorMod、abs 溢出
浮点：0.1+0.2 != 0.3 → 金额 BigDecimal
BigDecimal 四则：String 构造 + 除法精度 + compareTo
随机三兄弟：ThreadLocalRandom 首选、SecureRandom 安全
```

> 🎯 **核心要点**：数值速查 10 项 = "**Math 三坑 + BigDecimal 四则 + 随机三选**"——**"金额 BigDecimal + 比较用阈值"两条铁律**覆盖大多数正确性问题；每个坑都是面试细节题。
