## 学习建议

### 章节路线图

```text
第 1 章（入门铺垫）──► 第 2 章（基本计算）──► 第 3-4 章（流程控制）
                                                      │
                                                      ▼
第 7 章（数组）◄────────── 第 5-6 章（类与方法）◄──────┘
    │
    ▼
第 8 章（继承/多态/接口）──► 第 9 章（异常处理）──► 第 10 章（IO/网络）
    │
    ▼
第 11 章（递归）──► 第 12 章（数据结构/泛型）
```

### 按学习阶段分类

| 阶段 | 章节 | 核心目标 |
|------|------|----------|
| **入门** | 第 1-4 章 | 建立 Java 编程基础：变量、表达式、分支、循环 |
| **核心** | 第 5-8 章 | 掌握面向对象：类、方法、继承、多态、接口、数组 |
| **进阶** | 第 9-10 章 | 异常处理 + IO/网络编程 |
| **高级** | 第 11-12 章 | 递归思想 + 数据结构与泛型 |

### 与《Java 编程思想》互补阅读

| 本书侧重 | 《Java 编程思想》侧重 |
|----------|----------------------|
| 问题求解导向，注重算法与程序设计 | 编程哲学导向，注重底层机制与设计 |
| 适合初学者建立编程思维 | 适合有一定基础后深入理解 Java |
| 案例驱动，实操性强 | 原理驱动，理论体系完整 |
