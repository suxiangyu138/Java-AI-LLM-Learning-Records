## 1. JVM 基本概念

| 维度 | 说明 |
|------|------|
| 定义 | 运行 Java 字节码（`.class`）的虚拟计算机 |
| 核心作用 | 加载执行字节码、管理内存（分配/回收）、GC 机制、解释/编译执行 |
| 关键价值 | 屏蔽操作系统和硬件差异，实现跨平台 |

## 2. JVM 整体结构

```text
JVM
├── 类加载子系统
│   ├── 加载 → 验证 → 准备 → 解析 → 初始化（5 阶段）
│   ├── 类加载器：启动类 / 扩展类 / 应用类 / 自定义
│   └── 双亲委派模型：避免重复加载，保证核心类安全
│
├── 运行时数据区（内存结构）
│   ├── 线程私有
│   │   ├── 程序计数器：当前线程字节码行号，唯一不 OOM 区域
│   │   ├── 虚拟机栈：栈帧（局部变量表/操作数栈/动态链接/返回地址）
│   │   └── 本地方法栈：为 Native 方法服务
│   └── 线程共享
│       ├── 堆：最大内存区域，对象实例，GC 主战场
│       └── 方法区：类信息/常量/静态变量（JDK 8+ 元空间替代永久代）
│
├── 执行引擎
│   ├── 解释器：逐行解释，启动快、执行慢
│   ├── JIT 编译器：热点代码编译为机器码
│   └── 垃圾回收器：GC
│
└── 本地方法接口（JNI）
    └── 连接 Java 与本地代码（C/C++）
```

## 3. 运行时数据区

### 3.1 内存区域速查

| 区域 | 线程 | 存储内容 | 异常 |
|------|:----:|----------|------|
| **程序计数器** | 私有 | 字节码行号 | ❌ 唯一不抛 OOM 的区域 |
| **虚拟机栈** | 私有 | 栈帧（局部变量表、操作数栈等） | `StackOverflowError`（深度不足）/ `OOM` |
| **本地方法栈** | 私有 | Native 方法 | 同虚拟机栈 |
| **堆** | 共享 | 对象实例、数组 | `OOM`（GC 主战场） |
| **方法区** | 共享 | 类信息、常量、静态变量、JIT 代码 | `OOM`（JDK 8+ 元空间用本地内存） |

### 3.2 堆内存结构

```text
堆（Heap）
├── 新生代（Young Generation）
│   ├── Eden 区（默认 8）
│   ├── Survivor 0（From，默认 1）
│   └── Survivor 1（To，默认 1）
└── 老年代（Old Generation）
```

### 3.3 方法区演进

| JDK 版本 | 实现 | 位置 |
|----------|------|------|
| JDK 7 及之前 | 永久代（PermGen） | JVM 内存 |
| JDK 8+ | **元空间（Metaspace）** | 本地内存（默认无上限） |

## 4. 垃圾回收（GC）

### 4.1 垃圾判定算法

| 算法 | 原理 | 优缺点 |
|------|------|--------|
| **引用计数法** | 通过对象引用数判断 | ❌ 无法解决循环引用 |
| **可达性分析**（主流） | 以 GC Roots 为起点，不可达 = 垃圾 | ✅ 准确 |

**GC Roots 包括**：虚拟机栈引用的对象、方法区静态变量/常量引用的对象、本地方法栈引用的对象。

### 4.2 垃圾回收器速查

| 回收器 | 线程 | 目标 | 特点 | 适用场景 |
|--------|:----:|------|------|----------|
| **Serial GC** | 单线程 | — | 简单高效 | 单核、小内存（客户端） |
| **Parallel GC** | 多线程 | 吞吐量 | JDK 8 默认 | 后台计算任务 |
| **CMS GC** | 并发 | 低延迟 | 并发标记清除 | 互联网应用（⚠️ 内存碎片） |
| **G1 GC** | 并发 | 吞吐+延迟 | 区域化分代式，JDK 9 默认 | 大内存场景 |
| **ZGC / Shenandoah** | 并发 | 超低延迟 | 毫秒级停顿 | 超大内存、低延迟 |

### 4.3 GC 算法

| 算法 | 过程 | 优点 | 缺点 |
|------|------|------|------|
| **标记-清除** | 标记垃圾 → 清除 | 简单 | 内存碎片 |
| **标记-整理** | 标记垃圾 → 清除 → 移动存活对象 | 无碎片 | 耗时 |
| **复制** | 内存分两块 → 复制存活到另一块 | 无碎片、高效 | 空间利用率低（50%） |

### 4.4 回收器选择指南

```text
小内存 / 客户端  → Serial GC
追求吞吐量      → Parallel GC
低延迟          → CMS GC（JDK 8）/ G1 GC（JDK 9+）
超大内存 + 低延迟 → ZGC / Shenandoah
```

## 5. 常用 JVM 参数

### 5.1 堆内存参数

| 参数 | 说明 | 示例 |
|------|------|------|
| `-Xms` | 初始堆内存 | `-Xms512m` |
| `-Xmx` | 最大堆内存 | `-Xmx1024m`（建议与 `-Xms` 相同值） |
| `-Xmn` | 新生代内存 | `-Xmn256m` |
| `-XX:SurvivorRatio` | Eden/Survivor 比例 | `-XX:SurvivorRatio=8`（默认 8:1:1） |

### 5.2 GC 参数

| 参数 | 回收器 |
|------|--------|
| `-XX:+UseSerialGC` | Serial GC |
| `-XX:+UseParallelGC` | Parallel GC |
| `-XX:+UseConcMarkSweepGC` | CMS GC |
| `-XX:+UseG1GC` | G1 GC |
| `-XX:+UseZGC` | ZGC |

### 5.3 监控参数

| 参数 | 说明 |
|------|------|
| `-XX:+PrintGCDetails` | 打印 GC 详细日志 |
| `-XX:+PrintGCTimeStamps` | 打印 GC 时间戳 |
| `-Xloggc:gc.log` | GC 日志输出到文件 |

## 6. 常见问题与排查

| 问题 | 原因 | 排查方向 |
|------|------|----------|
| **堆 OOM** | 大量对象无法回收 | `-Xmx` 调大、dump 分析大对象、检查内存泄漏 |
| **栈 OOM** | 栈深度过大 / 线程过多 | 检查递归深度、调整 `-Xss` |
| **方法区 OOM** | 加载过多类（动态代理、频繁热部署） | 调整元空间大小 `-XX:MaxMetaspaceSize` |
| **StackOverflowError** | 递归调用过深 | 检查递归终止条件、优化为迭代 |
| **内存泄漏** | 对象无用但被引用（如静态集合持有） | dump 分析引用链、解除不必要的引用 |

## 总结

```text
JVM 三大核心
├── 运行时数据区：堆（GC 主战场） + 栈（方法调用） + 方法区（类元数据）
├── 垃圾回收：可达性分析 + 分代回收 + 按场景选回收器
└── 参数调优：合理分配堆内存 + 选合适回收器 + 避免 OOM 和内存泄漏
```

> 🎯 **面试重点**：内存结构（堆/栈/方法区区别）、GC 算法与回收器对比、类加载双亲委派模型、OOM 排查思路。
