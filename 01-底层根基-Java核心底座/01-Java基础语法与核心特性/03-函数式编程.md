# 函数式编程

## 📌 定位
**课外自学 | 第三~四梯队 | 编程思维扩展**

函数式编程是一种编程范式——强调无副作用、不可变数据、高阶函数。即使你主要用Java，FP思想也能显著提升代码质量（Java 8+ Stream就是FP）。

## 🎯 核心章节

### 1. 函数式编程核心思想
- **纯函数**：相同输入永远得到相同输出，无副作用(不修改外部状态、不打印、不发网络请求)
  - 好处：可缓存、可并行、易于测试、容易推断行为
- **不可变数据**：创建新数据而非修改原数据——Java中`String`/`LocalDate`就是不可变的
- **函数是一等公民**：函数可以赋给变量、作为参数、作为返回值
- **声明式 vs 命令式**：关注"做什么"而非"怎么做"

### 2. 核心抽象
- **map**：对每个元素应用函数—— `[1,2,3].map(x=>x*2) → [2,4,6]`
- **filter**：保留满足条件的元素
- **reduce/fold**：将列表归约为一个值—— `[1,2,3].reduce((a,b)=>a+b, 0) → 6`
- **flatMap**：扁平化合并——Scala/Java Stream的核心操作
- **柯里化（Currying）**：f(a,b,c) → f(a)(b)(c)——部分应用，创建特化函数

### 3. Java中的函数式特性
- **Lambda**：`(x, y) -> x + y`——本质是函数式接口的匿名实现
- **Stream API**：`list.stream().filter(x->x>0).map(String::valueOf).collect(toList())`
- **Optional**：避免null——`optional.map(x->x*2).orElse(0)`——Monad的最简化版
- **CompletableFuture**：`future.thenApplyAsync(x->x*2).thenAccept(System.out::println)`——异步的FP

### 4. 了解一门纯FP语言：Scala
- **Scala特点**：混血——JVM语言，融合OOP+FP，Spark/Kafka的编写语言
- **case class**：不可变数据类——自动生成equals/hashCode/copy
- **模式匹配**：`x match { case 0 => "zero"; case _ => "other" }`
- **隐式转换/implicit**：类型类(Typeclass)范式

### 5. 函数式 vs 面向对象
| 函数式 | 面向对象 |
|--------|----------|
| 数据与行为分离 | 数据与行为封装在一起 |
| 通过不可变数据+纯函数组合 | 通过对象之间的消息传递 |
| 易于并行、易于测试 | 易于建模现实世界 |

## ✅ 学习建议
- 不用从头学一门纯FP语言——先把Java的Stream+Lambda用到极致
- 理解"不可变性"的重要性——避免了多少并发Bug
- 了解Monad/Applicative/Traverse这些概念：它们是FP模式的高度抽象，但不是入门必需
