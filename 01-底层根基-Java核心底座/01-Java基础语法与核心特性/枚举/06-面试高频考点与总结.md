## 1. 必背考点：十二问

### 1.1 枚举的本质是什么？

**答题链**：**继承 `java.lang.Enum` 的特殊类**（隐式 final）→ 每个常量 = 静态实例（单例）→ 构造器必须私有（实例集合固定）→ 自动实现 Comparable/Serializable → **"枚举是类"推导出一切能力（字段/方法/接口）与限制（不可继承/不可 new）**。

### 1.2 values() / valueOf() / ordinal()？

**答题链**：values()（全部常量数组，**每次新建**）、valueOf(String)（按名取，不存在抛异常）、name()（名字字符串）、**ordinal()（声明序，依赖位置——不可持久化）**→ 持久化用显式 code。

### 1.3 枚举能做什么不能做什么？

**答题链**：能做（字段/方法/私有构造器/接口/抽象方法/静态成员）→ 不能做（被继承/继承其他类/new/泛型枚举）→ **"类是子集 + 实例固定"的语义边界**。

### 1.4 成员类体是什么？

**答题链**：每个常量带自己的类体（重写方法）→ **编译为匿名子类** → 抽象方法 + 成员类体 = 枚举版多态（策略）→ **替代外部 switch 分派**（编译期强制 + 行为内聚）。

### 1.5 枚举状态机怎么做？

**答题链**：状态 = 常量、转移 = next 方法（成员类体）、动作 = 类体内逻辑 → 非法转移抛 IllegalStateException → **新增状态编译期强制实现 next** → 订单/审批流程标准答案。

### 1.6 JDK 21 的枚举 switch 新能力？

**答题链**（时效性）：**穷尽性检查（可省略 default，漏常量编译报错）**→ 守卫（`when`，无守卫 case 必须在后）→ null 分支（不再 NPE）→ 与 JDK 14 箭头语法叠加（表达式化）→ **"手动安全 → 编译器保证安全"**。

### 1.7 为什么枚举单例最安全？

**答题链**：四种单例 vs 枚举 → **反射攻击（Enum 构造器直接抛异常）** → **序列化（JVM 保证返回同一实例）** → 线程安全（类加载）→ Effective Java 推荐。

### 1.8 EnumSet 的底层？

**答题链**：**位向量（long 位掩码，≤64 常量一个 long）** → 枚举序即 bit 位 → 所有操作 = 位运算 → 比 HashSet 快 5-10 倍、内存少 30 倍 → 静态工厂创建。

### 1.9 EnumMap 的底层？

**答题链**：**数组（按枚举序索引）** → get/put = 数组下标 → 无哈希计算/碰撞/扩容 → 迭代顺序 = 枚举声明序 → 枚举键场景首选。

### 1.10 错误码为什么用枚举？

**答题链**：类型安全（vs 字符串）→ 集中管理（vs 散落）→ 携带消息（defaultMessage）→ 编译期检查 → 分段管理 + 稳定契约（新增只增不改）。

### 1.11 Jackson 怎么处理枚举？

**答题链**：默认枚举名 → **@JsonValue（输出 code）+ @JsonCreator（读回 code）** → code 是稳定契约 → 未知值容错配置。

### 1.12 MyBatis 怎么处理枚举？

**答题链**：IEnum / @EnumValue 标注数据库值 → 实体直接枚举类型 → 自动转换（数据库 0/1 ↔ Java 枚举）→ 业务零魔法数字。

## 2. 高频陷阱题 12 连问

1. **对错**：枚举可以被继承。（❌ 隐式 final）
2. **对错**：枚举构造器可以 public。（❌ 必须私有——外部无法 new）
3. **结果**：`Day.valueOf("MONDAY")` 与 `Day.valueOf("monday")`？（后者抛 IllegalArgumentException——大小写敏感）
4. **对错**：`ordinal()` 可以用于数据库持久化。（❌ 依赖声明顺序——插入常量即错位）
5. **结果**：JDK 21 枚举 switch 省略 default 的条件？（穷尽性——所有常量已覆盖，漏一个编译报错）
6. **对错**：`case Day.MONDAY` 在传统 switch 中合法。（JDK 5-20 ❌ 写 `case MONDAY`；JDK 21+ ✅ 限定常量）
7. **结果**：枚举的 `==` 比较安全吗？（✅ 单例保证——`equals` 等价但 `==` 更快）
8. **对错**：EnumSet 可以 new。（❌ 静态工厂 of/allOf/range）
9. **结果**：反射能创建枚举新实例吗？（❌ 抛 IllegalArgumentException——Enum 构造禁止）
10. **对错**：枚举实现接口必须实现所有抽象方法。（✅ 每个常量都要实现（或成员类体））
11. **结果**：`values()` 的性能问题？（每次调用新建数组——高频场景缓存）
12. **对错**：枚举单例反序列化会创建新实例。（❌ JVM 保证返回同一实例）

## 3. 高频追问速答

| 追问 | 速答 |
|------|------|
| 枚举和常量类的区别？ | 枚举类型安全 + 自带方法 + 行为绑定；常量类仅静态值 |
| 枚举能和 record 一起用？ | 互补：record 管数据载体、枚举管有限状态集合（如 record 字段类型） |
| 什么时候不用枚举？ | 需要动态扩展的"类型"（插件系统）、值集合不固定 |
| 枚举 vs sealed 接口？ | 都是"受控集合"：枚举固定实例、sealed 允许子类型（可与枚举组合） |
| 枚举字段可以不是 final 吗？ | 可以但强烈不建议（破坏单例一致性）——反模式 |
| 怎么反查（code → 枚举）？ | 静态 `fromCode` 遍历 + 容错（抛异常或兜底） |
| 枚举能实现多个接口吗？ | ✅ 与类一致 |
| 枚举里有泛型方法可以吗？ | ✅（枚举本身不能泛型，但方法可以） |
| 大型枚举（>64 常量）怎么办？ | EnumSet 自动切 JumboEnumSet（long[]）；设计上考虑拆分 |
| 前端要小写枚举名？ | @JsonProperty 别名或 @JsonValue 输出 code |

## 4. 场景题：状态机与错误码设计

**题目**：设计订单状态机 + 错误码体系（枚举实现），要求合法转移可控、非法操作有明确报错。

**答题框架**（按评分点展开）：

```text
① 状态枚举（状态 + 转移 + 动作一体）：
   enum OrderState {
       PENDING { next(Event) { PAY_SUCCESS -> PAID; CANCEL -> CANCELLED; ... } },
       PAID { next(Event) { SHIP -> SHIPPED; REFUND -> REFUNDED; ... } },
       ...（终态 next 抛 IllegalStateException）
   }
   → 非法转移立即报错（非静默）
   → 新增状态编译期强制实现 next

② 错误码枚举（与状态机联动）：
   enum ErrorCode {
       ORDER_ILLEGAL_STATE("ORDER_ILLEGAL_STATE", "订单状态不允许该操作"),
       ORDER_NOT_FOUND("ORDER_NOT_FOUND", "订单不存在"), ...
   }
   → 状态机异常携带 ErrorCode → 全局异常处理器转响应

③ 持久化：
   状态存 code（显式字段，非 ordinal）
   MyBatis IEnum / Jackson @JsonValue+@JsonCreator

④ 加分点：
   - 谈 JDK 21 switch 穷尽性（状态转移的 switch 可省 default）
   - 谈 EnumSet 做"可取消状态集合"查询
   - 谈"行为归属"设计（转移入枚举 vs 外部 switch 的取舍）
```

## 5. 面试加分项：架构视角

**面试官追问"你们状态/类型怎么建模"时的完整作答框架**：

```text
① 状态建模：枚举状态机（状态 + 转移 + 动作一体）
   → 非法转移编译期/运行期可控
② 类型建模：枚举（固定集合）/ sealed 接口（受控子类型）/ record（数据载体）
   → 三选一按"集合是否固定"判断
③ 持久化：code 显式字段（非 ordinal）+ MyBatis IEnum
④ 序列化：Jackson @JsonValue/@JsonCreator（code 契约）
⑤ 集合操作：EnumSet（权限组合）/ EnumMap（处理器注册表）
⑥ 与异常联动：错误码枚举 → 业务异常 → 全局处理器
```

**三个"谈资级"观点**：

| 观点 | 展开 |
|------|------|
| "枚举是编译器可检查的建模工具" | 穷尽性（JDK 21）让"漏分支"从运行时变编译期 |
| "枚举单例是语言级单例" | 反射/序列化免疫是语言保证而非防御代码 |
| "枚举与 record 是互补" | record 管"数据是什么"、枚举管"状态有哪些"——状态机 record 载荷 + 枚举状态 |

## 6. 记忆口诀

```text
枚举是类不是表：继承 Enum、隐式 final、构造私有实例定。
成员类体是子类：每个常量能重写，抽象方法做分派。
状态机三合一：状态、转移、动作——非法转移立即报。
switch 三升级：14 箭头、21 穷尽 + 守卫 + null。
单例选枚举：反射抛异常、序列化同实例——语言级安全。
EnumSet 位向量、EnumMap 数组：枚举集合快一个数量级。
错误码用枚举：类型安全 + 集中管 + 携带消息。
持久化记牢：用 code 不用 ordinal。
Jackson 两注解：@JsonValue 出、@JsonCreator 回。
MyBatis 两方案：IEnum、@EnumValue——数据库数值、Java 枚举。
```
