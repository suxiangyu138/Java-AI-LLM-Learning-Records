## 1. I/O 体系总览

```
                    +---------------------+
                    |   I/O Stream        |
                    +----------+----------+
                               |
              +----------------+----------------+
              |                                 |
     +--------v--------+               +--------v--------+
     |  Byte Streams   |               |  Character      |
     | (字节流)         |               |  Streams        |
     +-----------------+               | (字符流)         |
              |                        +-----------------+
     +--------+--------+               +--------+--------+
     | InputStream     |               | Reader          |
     | OutputStream    |               | Writer          |
     +-----------------+               +-----------------+
              |                                 |
     +--------+--------+               +--------+--------+
     | FileInputStream |               | FileReader      |
     | FileOutputStream|               | FileWriter      |
     | BufferedInput   |               | BufferedReader  |
     | BufferedOutput  |               | BufferedWriter  |
     | ObjectInput     |               | InputStreamReader|
     | ObjectOutput    |               | OutputStreamWriter|
     +-----------------+               +-----------------+
```

| 类型 | 基类 | 面向 | 单位 | 典型场景 |
|------|------|------|------|---------|
| 字节流 | InputStream/OutputStream | 二进制数据 | byte | 图片、视频、压缩包 |
| 字符流 | Reader/Writer | 文本数据 | char | 文本文件、配置文件 |
| 桥接流 | InputStreamReader/OutputStreamWriter | 字节→字符 | char | 指定编码读取文本 |

## 2. File 类 vs Path 接口

### 2.1 java.io.File（传统方式）

```java
public class FileDemo {

    public static void main(String[] args) {
        // 创建 File 对象（不代表真实存在，只是路径抽象）
        File file = new File("D:/data/test.txt");
        File dir = new File("D:/data");
        File parent = new File("D:/data", "test.txt");

        // 路径信息
        System.out.println("文件名: " + file.getName());       // "test.txt"
        System.out.println("路径: " + file.getPath());          // "D:\data\test.txt"
        System.out.println("绝对路径: " + file.getAbsolutePath());
        System.out.println("父目录: " + file.getParent());     // "D:\data"

        // 文件状态
        System.out.println("是否存在: " + file.exists());
        System.out.println("是否是文件: " + file.isFile());
        System.out.println("是否是目录: " + file.isDirectory());
        System.out.println("是否可读: " + file.canRead());
        System.out.println("是否可写: " + file.canWrite());
        System.out.println("是否隐藏: " + file.isHidden());
        System.out.println("文件大小: " + file.length() + " bytes");
        System.out.println("最后修改: " + new Date(file.lastModified()));

        // 目录操作
        dir.mkdir();            // 创建单级目录
        dir.mkdirs();           // 创建多级目录（推荐）
        String[] list = dir.list();           // 列出文件名
        File[] files = dir.listFiles();       // 列出 File 对象

        // 过滤
        File[] txtFiles = dir.listFiles((d, name) -> name.endsWith(".txt"));

        // 文件操作
        boolean created = file.createNewFile();   // 创建新文件
        boolean deleted = file.delete();           // 删除文件
        file.deleteOnExit();                       // JVM 退出时删除
        boolean renamed = file.renameTo(new File("D:/data/new.txt"));

        System.out.println("根目录: " + Arrays.toString(File.listRoots()));
    }
}
```

**File 类的局限性**:
- 大多数方法返回 boolean，操作失败时原因不明
- 不支持符号链接处理
- 列表文件时性能差（大目录）
- 方法集有限（没有 copy/move/walk 等）

### 2.2 java.nio.file.Path（NIO.2，JDK 7+）

```java
import java.nio.file.*;
import java.nio.file.attribute.*;

public class PathDemo {

    public static void main(String[] args) {
        // 创建 Path
        Path path = Paths.get("D:/data/test.txt");
        Path path2 = Paths.get("D:", "data", "test.txt");
        Path path3 = FileSystems.getDefault().getPath("D:/data", "test.txt");

        // 路径信息
        System.out.println("文件名: " + path.getFileName());          // "test.txt"
        System.out.println("根路径: " + path.getRoot());              // "D:\"
        System.out.println("父路径: " + path.getParent());            // "D:\data"
        System.out.println("名称数: " + path.getNameCount());         // 2
        System.out.println("第 0 级: " + path.getName(0));            // "data"

        // 路径解析
        Path relative = Paths.get("data", "test.txt");
        Path absolute = relative.toAbsolutePath();
        Path normalized = path.normalize();                // 规范化（解析 . 和 ..）
        Path resolved = path.resolve("sub/file.txt");     // 拼接
        Path sibling = path.resolveSibling("new.txt");    // 同级替换

        // 路径比较
        Path p1 = Paths.get("D:/data/../data/test.txt");
        Path p2 = Paths.get("D:/data/test.txt");
        System.out.println(p1.equals(p2));                 // false
        System.out.println(p1.normalize().equals(p2));    // true

        // Path 转 File
        File file = path.toFile();
        Path back = file.toPath();

        // 处理 . 和 ..  路径
        Path complex = Paths.get("D:/data/./sub/../test.txt");
        System.out.println(complex.normalize());            // "D:\data\test.txt"

        // 相对化
        Path base = Paths.get("D:/a/b");
        Path target = Paths.get("D:/a/b/c/d/file.txt");
        System.out.println(base.relativize(target));        // "c/d/file.txt"
    }
}
```

### 2.3 File vs Path 对比

| 特性 | java.io.File | java.nio.file.Path |
|------|-------------|-------------------|
| 引入版本 | JDK 1.0 | JDK 7 |
| 是否支持符号链接 | 有限 | 完整（readSymbolicLink） |
| 异常信息 | 返回 boolean | 抛出 IOException（有详细信息） |
| 文件操作 | 少（create/delete/rename） | 丰富（copy/move/walk/find） |
| 文件属性 | 基本属性 | 完整属性（ACL、权限、时间） |
| 性能 | 大目录下慢 | 优化良好 |
| 推荐度 | 不推荐 | 强烈推荐 |

> **阿里巴巴规范**: 在 JDK 7+ 中，推荐使用 `java.nio.file.Files` 和 `java.nio.file.Path` 替代 `java.io.File`。

## 3. 字节流（Byte Streams）

### 3.1 InputStream / OutputStream

```java
public class ByteStreamDemo {

    public static void main(String[] args) {
        // 最基本的文件复制（逐字节读取，极慢！）
        copyFileByteByByte("source.bin", "dest.bin");

        // 使用缓冲区的文件复制（推荐）
        copyFileWithBuffer("source.bin", "dest.bin");

        // 使用 BufferedInputStream（自动缓冲区）
        copyFileBuffered("source.bin", "dest.bin");

        // JDK 8+ 使用 Files（最简单）
        copyFileNIO("source.bin", "dest.bin");
    }

    // 逐字节复制（不推荐，极慢）
    public static void copyFileByteByByte(String src, String dest) {
        try (FileInputStream in = new FileInputStream(src);
             FileOutputStream out = new FileOutputStream(dest)) {
            int b;
            while ((b = in.read()) != -1) {     // 每次读取一个 byte
                out.write(b);                    // 每次写入一个 byte
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }

    // 缓冲区复制（推荐）
    public static void copyFileWithBuffer(String src, String dest) {
        try (FileInputStream in = new FileInputStream(src);
             FileOutputStream out = new FileOutputStream(dest)) {
            byte[] buffer = new byte[8192];      // 8KB 缓冲区
            int bytesRead;
            while ((bytesRead = in.read(buffer)) != -1) {
                out.write(buffer, 0, bytesRead); // 写入实际读取的字节数
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }

    // 使用 BufferedInputStream（内部有 8192 字节缓冲区）
    public static void copyFileBuffered(String src, String dest) {
        try (BufferedInputStream in = new BufferedInputStream(new FileInputStream(src));
             BufferedOutputStream out = new BufferedOutputStream(new FileOutputStream(dest))) {
            byte[] buffer = new byte[8192];
            int bytesRead;
            while ((bytesRead = in.read(buffer)) != -1) {
                out.write(buffer, 0, bytesRead);
            }
            out.flush();  // 确保所有数据写入
        } catch (IOException e) {
            e.printStackTrace();
        }
    }

    // Files.copy（最简单，JDK 7+）
    public static void copyFileNIO(String src, String dest) {
        try {
            Files.copy(Paths.get(src), Paths.get(dest), StandardCopyOption.REPLACE_EXISTING);
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

### 3.2 常用字节流类

```java
public class ByteStreamClassesDemo {

    public static void main(String[] args) throws IOException {
        // 1. FileInputStream / FileOutputStream
        try (FileOutputStream fos = new FileOutputStream("test.bin")) {
            fos.write(65);               // 写入 byte 'A'
            fos.write(new byte[]{66, 67, 68});  // "BCD"
        }

        try (FileInputStream fis = new FileInputStream("test.bin")) {
            int b;
            while ((b = fis.read()) != -1) {
                System.out.print((char) b);  // ABCD
            }
        }

        // 2. BufferedInputStream / BufferedOutputStream（带缓冲区，提高性能）
        try (BufferedOutputStream bos = new BufferedOutputStream(new FileOutputStream("buffer.bin"))) {
            bos.write("Hello".getBytes());
            bos.flush();  // 强制刷新缓冲区
        }

        // 3. DataInputStream / DataOutputStream（读写基本类型）
        try (DataOutputStream dos = new DataOutputStream(new FileOutputStream("data.bin"))) {
            dos.writeInt(42);
            dos.writeDouble(3.14);
            dos.writeUTF("Hello World");
        }

        try (DataInputStream dis = new DataInputStream(new FileInputStream("data.bin"))) {
            int i = dis.readInt();       // 42
            double d = dis.readDouble();  // 3.14
            String s = dis.readUTF();    // "Hello World"
        }

        // 4. ByteArrayInputStream / ByteArrayOutputStream（内存中读写）
        byte[] source = {1, 2, 3, 4, 5};
        try (ByteArrayInputStream bais = new ByteArrayInputStream(source);
             ByteArrayOutputStream baos = new ByteArrayOutputStream()) {
            byte[] buffer = new byte[2];
            int len;
            while ((len = bais.read(buffer)) != -1) {
                baos.write(buffer, 0, len);
            }
            byte[] result = baos.toByteArray();  // {1, 2, 3, 4, 5}
        }

        // 5. PipedInputStream / PipedOutputStream（线程间通信）
        // 通常用于一个线程读取另一个线程写入的数据
    }
}
```

## 4. 字符流（Character Streams）

### 4.1 Reader / Writer

```java
public class CharacterStreamDemo {

    public static void main(String[] args) {
        // 字符流：专门处理文本文件，自动处理字符编码
        readTextWithBuffer();
        writeTextWithBuffer();
    }

    // 使用 BufferedReader 按行读取文本（推荐）
    public static void readTextWithBuffer() {
        try (BufferedReader reader = new BufferedReader(new FileReader("test.txt"))) {
            String line;
            while ((line = reader.readLine()) != null) {  // 按行读取
                System.out.println(line);
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }

    // 使用 BufferedWriter 写入文本（推荐）
    public static void writeTextWithBuffer() {
        try (BufferedWriter writer = new BufferedWriter(new FileWriter("output.txt", true))) {
            // FileWriter 第二个参数 append=true 表示追加模式
            writer.write("第一行");
            writer.newLine();      // 写入换行符（跨平台）
            writer.write("第二行");
            writer.newLine();
            writer.flush();
        } catch (IOException e) {
            e.printStackTrace();
        }
    }

    // 传统方式：按字符读取（不推荐）
    public static void readCharByChar() {
        try (FileReader reader = new FileReader("test.txt")) {
            int ch;
            while ((ch = reader.read()) != -1) {
                System.out.print((char) ch);
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }

    // 使用 char[] 缓冲区
    public static void readWithBufferArray() {
        try (FileReader reader = new FileReader("test.txt")) {
            char[] buffer = new char[1024];
            int charsRead;
            while ((charsRead = reader.read(buffer)) != -1) {
                System.out.print(new String(buffer, 0, charsRead));
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

## 5. 桥接流（字符编码处理）

### 5.1 InputStreamReader / OutputStreamWriter

```java
public class BridgeStreamDemo {

    public static void main(String[] args) {
        // 桥接流：将字节流转换为字符流，同时指定编码
        // 因为文件存储在磁盘上是字节，需要指定编码来解码为字符

        // 指定编码读取文件
        readWithEncoding("data.txt", "UTF-8");

        // 指定编码写入文件
        writeWithEncoding("data_output.txt", "UTF-8", "你好，世界！");

        // 不同编码处理
        convertEncoding("gbk.txt", "GBK", "utf8.txt", "UTF-8");
    }

    // 指定编码读取
    public static void readWithEncoding(String path, String charset) {
        try (BufferedReader reader = new BufferedReader(
                new InputStreamReader(
                    new FileInputStream(path), charset))) {
            String line;
            while ((line = reader.readLine()) != null) {
                System.out.println(line);
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }

    // 指定编码写入
    public static void writeWithEncoding(String path, String charset, String content) {
        try (BufferedWriter writer = new BufferedWriter(
                new OutputStreamWriter(
                    new FileOutputStream(path), charset))) {
            writer.write(content);
            writer.newLine();
        } catch (IOException e) {
            e.printStackTrace();
        }
    }

    // 转换文件编码
    public static void convertEncoding(String srcPath, String srcCharset,
                                       String destPath, String destCharset) {
        try (BufferedReader reader = new BufferedReader(
                new InputStreamReader(
                    new FileInputStream(srcPath), srcCharset));
             BufferedWriter writer = new BufferedWriter(
                new OutputStreamWriter(
                    new FileOutputStream(destPath), destCharset))) {
            String line;
            while ((line = reader.readLine()) != null) {
                writer.write(line);
                writer.newLine();
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }

    // 获取文件编码（推测）
    public static String guessCharset(Path path) throws IOException {
        byte[] bytes = Files.readAllBytes(path);
        // 检查 BOM
        if (bytes.length >= 3 && bytes[0] == (byte)0xEF && bytes[1] == (byte)0xBB && bytes[2] == (byte)0xBF) {
            return "UTF-8";
        } else if (bytes.length >= 2 && bytes[0] == (byte)0xFF && bytes[1] == (byte)0xFE) {
            return "UTF-16LE";
        } else if (bytes.length >= 2 && bytes[0] == (byte)0xFE && bytes[1] == (byte)0xFF) {
            return "UTF-16BE";
        }
        return "UTF-8";  // 默认返回 UTF-8
    }
}
```

### 5.2 编码选择指南

| 编码 | 特点 | 推荐场景 |
|------|------|---------|
| UTF-8 | 变长编码（1-4 bytes），兼容 ASCII | 跨平台文本文件、网络传输、JSON/XML |
| UTF-16 | 定长/变长，Java 内部使用 | Java 内部字符串表示 |
| GBK | 中文 2 bytes，兼容 GB2312 | 中文 Windows 系统、遗留系统 |
| ISO-8859-1 | 单字节，不支持中文 | 西欧语言 |
| ASCII | 7-bit，仅英文 | 纯英文字符 |

> **阿里巴巴规范**: 所有文本文件统一使用 UTF-8 编码，避免编码问题。

## 6. 序列化（Serialization）

### 6.1 基本序列化

```java
import java.io.*;

/**
 * 序列化：将对象转换为字节序列，用于存储或网络传输
 */
public class SerializationDemo {

    public static void main(String[] args) {
        // 序列化
        User user = new User(1L, "张三", "zhangsan@example.com", 25);
        serializeUser(user, "user.ser");

        // 反序列化
        User deserializedUser = deserializeUser("user.ser");
        System.out.println(deserializedUser);
    }

    public static void serializeUser(User user, String filePath) {
        try (ObjectOutputStream oos = new ObjectOutputStream(
                new FileOutputStream(filePath))) {
            oos.writeObject(user);
            System.out.println("序列化成功");
        } catch (IOException e) {
            e.printStackTrace();
        }
    }

    public static User deserializeUser(String filePath) {
        try (ObjectInputStream ois = new ObjectInputStream(
                new FileInputStream(filePath))) {
            return (User) ois.readObject();
        } catch (IOException | ClassNotFoundException e) {
            e.printStackTrace();
            return null;
        }
    }
}

/**
 * 可序列化的类必须实现 Serializable 接口（标记接口）
 */
class User implements Serializable {

    private static final long serialVersionUID = 1L;
    // serialVersionUID 用于版本控制：
    // 反序列化时验证序列化对象的版本与类的版本是否兼容
    // 如果不声明，JVM 会根据类结构自动生成（不同编译器可能不同）

    private Long id;
    private String name;
    private String email;

    // transient：该字段不参与序列化
    // 反序列化后为默认值（对象 null，数字 0）
    private transient int age;

    // static 字段不参与序列化（属于类，不属于对象）
    private static String company = "Example Corp";

    public User(Long id, String name, String email, int age) {
        this.id = id;
        this.name = name;
        this.email = email;
        this.age = age;
    }

    // getter/setter 省略

    @Override
    public String toString() {
        return "User{" +
            "id=" + id +
            ", name='" + name + '\'' +
            ", email='" + email + '\'' +
            ", age=" + age +           // transient，反序列化后为 0
            ", company=" + company +
            '}';
    }
}
```

### 6.2 serialVersionUID 的重要性

```java
// serialVersionUID 规则：
// 1. 如果类没有显式声明 serialVersionUID，JVM 根据类结构自动生成
// 2. 如果类的结构发生变化（增删字段），自动生成的 UID 会改变
// 3. 反序列化时，如果类的 UID 与序列化数据中的 UID 不匹配，
//    抛出 InvalidClassException
// 4. 显式声明 serialVersionUID，可以在类结构变化后仍兼容旧数据

public class VersionedUser implements Serializable {
    // 显式声明：确保版本兼容性
    private static final long serialVersionUID = 1L;

    private Long id;
    private String name;
    // private String email;    // 删除字段：兼容（新类忽略该字段）
    // private String phone;    // 新增字段：兼容（默认值为 null）
}
```

### 6.3 transient 关键字

```java
public class TransientDemo {
    public static void main(String[] args) {
        Credentials cred = new Credentials("admin", "password123", "sensitive_key");
        serializeAndDeserialize(cred);
    }
}

class Credentials implements Serializable {
    private static final long serialVersionUID = 1L;

    private String username;
    private transient String password;      // 不序列化密码
    private transient String secretKey;     // 不序列化密钥

    public Credentials(String username, String password, String secretKey) {
        this.username = username;
        this.password = password;
        this.secretKey = secretKey;
    }

    // 自定义序列化：可以控制 transient 字段的处理
    private void writeObject(ObjectOutputStream oos) throws IOException {
        oos.defaultWriteObject();
        // 加密后写入 transient 字段
        oos.writeObject(encrypt(password));
    }

    private void readObject(ObjectInputStream ois) throws IOException, ClassNotFoundException {
        ois.defaultReadObject();
        this.password = decrypt((String) ois.readObject());
    }

    private String encrypt(String data) { return "encrypted:" + data; }
    private String decrypt(String data) { return data.replace("encrypted:", ""); }
}
```

### 6.4 Externalizable 接口

```java
/**
 * Externalizable：完全自定义序列化
 * 相比 Serializable（默认自动序列化所有 non-transient 字段）
 * Externalizable 需要手动实现 writeExternal/readExternal
 * 优势：可以控制序列化格式，更高效
 */
class CustomUser implements Externalizable {
    private static final long serialVersionUID = 1L;

    private Long id;
    private String name;
    private String email;
```

```java
public class FileWalkDemo {

    public static void main(String[] args) throws IOException {
        Path start = Paths.get("D:/project");

        // ---- walk：递归遍历（Java 8+ Stream）----
        // 遍历所有文件和目录
        try (Stream<Path> stream = Files.walk(start, Integer.MAX_VALUE)) {
            stream.filter(Files::isRegularFile)
                  .filter(p -> p.toString().endsWith(".java"))
                  .forEach(System.out::println);
        }

        // ---- find：带条件的遍历 ----
        int maxDepth = 10;
        BiPredicate<Path, BasicFileAttributes> matcher = (path, attrs) ->
            attrs.isRegularFile() && path.toString().endsWith(".java");
        try (Stream<Path> stream = Files.find(start, maxDepth, matcher)) {
            stream.forEach(System.out::println);  // 递归查找所有 .java 文件
        }

        // ---- list：仅遍历直接子项（不递归）----
        try (Stream<Path> entries = Files.list(start)) {
            entries.filter(Files::isDirectory)
                   .forEach(System.out::println);  // 列出所有直接子目录
        }

        // ---- DirectoryStream：传统遍历方式（适合大量文件）----
        try (DirectoryStream<Path> stream = Files.newDirectoryStream(start, "*.{java,xml}")) {
            for (Path entry : stream) {
                System.out.println(entry.getFileName());
            }
        }

        // ---- FileVisitor：更灵活的文件遍历 ----
        Files.walkFileTree(start, new SimpleFileVisitor<Path>() {
            @Override
            public FileVisitResult visitFile(Path file, BasicFileAttributes attrs) {
                System.out.println("文件: " + file);
                return FileVisitResult.CONTINUE;
            }

            @Override
            public FileVisitResult preVisitDirectory(Path dir, BasicFileAttributes attrs) {
                System.out.println("进入目录: " + dir);
                return FileVisitResult.CONTINUE;
            }

            @Override
            public FileVisitResult visitFileFailed(Path file, IOException exc) {
                System.err.println("访问失败: " + file + " - " + exc.getMessage());
                return FileVisitResult.CONTINUE;  // 继续遍历
            }

            @Override
            public FileVisitResult postVisitDirectory(Path dir, IOException exc) {
                System.out.println("离开目录: " + dir);
                return FileVisitResult.CONTINUE;
            }
        });
    }
```

### 7.3 文件监控（WatchService）

```java
import java.nio.file.*;

/**
 * 文件监控：检测目录中的文件创建、修改、删除事件
 * 企业应用：配置文件热加载、日志文件监控、上传文件处理
 */
public class WatchServiceDemo {

    public static void main(String[] args) throws IOException, InterruptedException {
        Path dir = Paths.get("D:/watch_dir");
        Files.createDirectories(dir);

        // 创建 WatchService
        try (WatchService watchService = FileSystems.getDefault().newWatchService()) {
            // 注册感兴趣的事件
            dir.register(watchService,
                StandardWatchEventKinds.ENTRY_CREATE,
                StandardWatchEventKinds.ENTRY_MODIFY,
                StandardWatchEventKinds.ENTRY_DELETE);

            System.out.println("开始监控目录: " + dir);
            System.out.println("按 Ctrl+C 停止");

            // 事件循环
            while (true) {
                // 获取事件（阻塞，可指定超时）
                WatchKey key = watchService.take();  // 阻塞直到有事件

                // 处理事件
                for (WatchEvent<?> event : key.pollEvents()) {
                    WatchEvent.Kind<?> kind = event.kind();

                    if (kind == StandardWatchEventKinds.OVERFLOW) {
                        continue;  // 事件丢失，跳过
                    }

                    WatchEvent<Path> ev = (WatchEvent<Path>) event;
                    Path fileName = ev.context();  // 发生变化的文件名

                    System.out.printf("事件: %s, 文件: %s, 发生次数: %d%n",
                        kind.name(), fileName, ev.count());

                    // 根据事件类型做业务处理
                    if (kind == StandardWatchEventKinds.ENTRY_CREATE) {
                        System.out.println("新文件创建: " + fileName);
                        // 处理新文件（如解析、导入）
                    } else if (kind == StandardWatchEventKinds.ENTRY_MODIFY) {
                        System.out.println("文件修改: " + fileName);
                        // 重新加载配置
                    } else if (kind == StandardWatchEventKinds.ENTRY_DELETE) {
                        System.out.println("文件删除: " + fileName);
                    }
                }

                // 重置 key，如果失败则停止监控
                if (!key.reset()) {
                    break;
                }
            }
        }
    }
}
```

## 9. 大文件高效处理

```java
public class LargeFileDemo {

    public static void main(String[] args) throws IOException {
        Path largeFile = Paths.get("D:/large_file.log");

        // ---- 方式 1：Files.lines（Stream，惰性加载）推荐 ----
        // 不会将整个文件加载到内存
        try (Stream<String> lines = Files.lines(largeFile)) {
            lines.filter(line -> line.contains("ERROR"))
                 .limit(100)
                 .forEach(System.out::println);
        }

        // ---- 方式 2：BufferedReader 按行读取 ----
        try (BufferedReader reader = Files.newBufferedReader(largeFile)) {
            String line;
            int lineCount = 0;
            while ((line = reader.readLine()) != null) {
                // 逐行处理
                lineCount++;
                if (lineCount % 10000 == 0) {
                    System.out.println("已处理 " + lineCount + " 行");
                }
            }
        }

        // ---- 方式 3：FileChannel（NIO，最高性能）----
        try (FileChannel channel = FileChannel.open(largeFile, StandardOpenOption.READ)) {
            ByteBuffer buffer = ByteBuffer.allocateDirect(8192);  // 直接缓冲区
            while (channel.read(buffer) != -1) {
                buffer.flip();    // 切换到读模式
                // 处理 buffer 中的数据
                buffer.clear();   // 切换到写模式
            }
        }
    }

    // ---- 大文件复制（使用 FileChannel 零拷贝）----
    public static void copyLargeFile(String src, String dest) throws IOException {
        try (FileChannel in = FileChannel.open(Paths.get(src), StandardOpenOption.READ);
             FileChannel out = FileChannel.open(Paths.get(dest),
                 StandardOpenOption.CREATE, StandardOpenOption.WRITE)) {

            // 零拷贝：数据从内核空间直接传输，不经过用户空间
            long position = 0;
            long size = in.size();
            while (position < size) {
                position += in.transferTo(position, 1024 * 1024, out);
            }
        }
    }

    // ---- 多线程处理大文件（分块读取）----
    public static void parallelProcess(String path) throws IOException {
        try (Stream<String> lines = Files.lines(Paths.get(path))) {
            // 并行流处理（内部使用 ForkJoinPool）
            long errorCount = lines.parallel()
                .filter(line -> line.contains("ERROR"))
                .count();
            System.out.println("错误行数: " + errorCount);
        }
    }
}
```

```java
/**
 * 文件锁定：防止多个进程同时写同一个文件
 * 企业应用：日志文件、配置文件、数据文件的并发安全
 */
public class FileLockingDemo {

    public static void main(String[] args) throws IOException, InterruptedException {
        Path path = Paths.get("D:/shared/file.txt");
        Files.createDirectories(path.getParent());

        // 获取文件锁
        try (FileChannel channel = FileChannel.open(path,
                StandardOpenOption.WRITE, StandardOpenOption.CREATE);
             FileLock lock = channel.lock()) {          // 阻塞直到获取锁

            System.out.println("获取文件锁成功");

            // 写入数据
            channel.write(ByteBuffer.wrap("共享数据".getBytes()));

            // 模拟长时间操作
            Thread.sleep(5000);

            // 锁在 try-with-resources 结束时自动释放
            System.out.println("释放文件锁");
        }

        // 非阻塞尝试获取锁
        try (FileChannel channel = FileChannel.open(path,
                StandardOpenOption.WRITE, StandardOpenOption.CREATE)) {
            FileLock lock = channel.tryLock();  // 立即返回，不阻塞
            if (lock != null) {
                System.out.println("获取锁成功");
                lock.release();  // 显式释放
            } else {
                System.out.println("文件被其他进程锁定");
            }
        }
    }

    // 锁定文件的特定区域
    public static void lockRegion(Path path) throws IOException {
        try (FileChannel channel = FileChannel.open(path, StandardOpenOption.WRITE)) {
            // 锁定文件的 0-1024 字节范围（共享锁）
            FileLock lock = channel.lock(0, 1024, true);  // true = 共享锁
            // 操作锁定区域
            lock.release();
        }
    }
}
```

```java
public class BatchFileProcessor {

    private final Path inputDir;
    private final Path archiveDir;
    private final Path errorDir;
    private final String filePattern;

    public BatchFileProcessor(Path inputDir, Path archiveDir,
                              Path errorDir, String filePattern) {
        this.inputDir = inputDir;
        this.archiveDir = archiveDir;
        this.errorDir = errorDir;
        this.filePattern = filePattern;

            log.warn("输入目录不存在: {}", inputDir);
            return;

            for (Path file : stream) {
                try {
                    processFile(file);
                    // 处理成功：移动到归档目录
                    Files.move(file, archiveDir.resolve(file.getFileName()),
                        StandardCopyOption.REPLACE_EXISTING);
                    log.info("文件处理成功并归档: {}", file.getFileName());
                } catch (Exception e) {
                    log.error("文件处理失败: {}", file.getFileName(), e);
                    // 处理失败：移动到错误目录
                    Files.move(file, errorDir.resolve(file.getFileName()),
                        StandardCopyOption.REPLACE_EXISTING);
                }
            }
        }
    }

    private void processFile(Path file) {
        // 具体的业务处理逻辑
        // 解析文件内容、数据校验、写入数据库等
        log.info("处理文件: {}", file.getFileName());
    }

    public void watchAndProcess() throws IOException, InterruptedException {
        // 结合 WatchService 实现实时处理
        WatchService watcher = FileSystems.getDefault().newWatchService();
        inputDir.register(watcher, StandardWatchEventKinds.ENTRY_CREATE);

                Path fullPath = inputDir.resolve(fileName);
                processFile(fullPath);
            }

        }
```

```java
/**
 * 配置文件热加载：监听配置文件变更并自动重新加载

public class ConfigFileWatcher {

    private Path configPath;
    private Properties properties;
    private long lastModified;

    public ConfigFileWatcher(String configFilePath) {
        this.configPath = Paths.get(configFilePath);
        loadConfig();
    }

    public synchronized String getProperty(String key, String defaultValue) {
        // 每次访问检查文件是否更新
        checkReload();
        return properties.getProperty(key, defaultValue);
    }

    private void checkReload() {
        try {
            long currentModified = Files.getLastModifiedTime(configPath).toMillis();
            if (currentModified > lastModified) {
                log.info("配置文件已变更，重新加载");
                loadConfig();
            }
        } catch (IOException e) {
            log.warn("检查配置文件状态失败", e);
        }
    }

    private void loadConfig() {
        Properties newProps = new Properties();
        try (BufferedReader reader = Files.newBufferedReader(configPath)) {
            newProps.load(reader);
            this.properties = newProps;
            this.lastModified = Files.getLastModifiedTime(configPath).toMillis();
            log.info("配置文件加载成功: {}", configPath);
        } catch (IOException e) {
            log.error("配置文件加载失败", e);
        }
    }
}
```

## 12. 常见面试题

1. **字节流和字符流的区别？**
   - 字节流处理二进制数据（byte），字符流处理文本（char）
   - 字符流自动处理编码，字节流需要手动指定

2. **File 和 Path 的区别？为什么推荐 Path？**
   - Path 提供更多方法（copy/move/walk/find）
   - Path 抛出 IOException 提供详细信息
   - Path 支持符号链接、文件属性等高级特性

3. **序列化中 serialVersionUID 的作用？**
   - 版本控制，反序列化时验证兼容性
   - 不声明则 JVM 自动生成，类结构变化后 UID 改变

4. **transient 关键字的作用？**
   - 标记字段不参与序列化，反序列化后为默认值

5. **try-with-resources 的原理？**
   - 编译后转为 try-finally，自动调用 close()
   - 资源必须实现 AutoCloseable 接口
   - 抑制异常机制

6. **如何高效处理大文件？**
   - 使用缓冲区（BufferedInputStream）
   - 按行读取（BufferedReader readLine）
   - 使用 Stream 惰性加载（Files.lines）
   - 使用 FileChannel 零拷贝（transferTo）

7. **FileInputStream 和 BufferedInputStream 的关系？**
   - 装饰器模式：BufferedInputStream 包装 FileInputStream，提供缓冲区
   - 默认缓冲区 8192 字节

8. **NIO.2 相比传统 I/O 的优势？**
   - Files 工具类提供大量便捷方法
   - 支持文件属性、符号链接
   - WalkFileTree / DirectoryStream 高效遍历
   - WatchService 文件监控
   - FileChannel 高性能
