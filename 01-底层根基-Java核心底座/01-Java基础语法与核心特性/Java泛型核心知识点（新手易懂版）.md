## 1. 泛型是什么

| 维度 | 说明 |
|------|------|
| 定义 | Java 中带 `<>` 尖括号的语法，JDK 5 引入 |
| 本质 | **类型参数化**——把数据类型当作参数传递 |
| 适用对象 | 类、接口、方法 |
| 核心价值 | 适配多种数据类型，编译期约束类型，避免运行时类型转换异常 |

> 💡 集合、工具类、通用组件里的 `<>` 全都是泛型，吃透这些核心知识点，就能彻底看懂相关代码。

---

## 2. 泛型的核心作用

| 作用 | 说明 | 对比 |
|------|------|------|
| **提高安全性** | 编译阶段校验数据类型 | `ClassCastException` 从运行期 → 编译期 |
| **消除强转** | 取出数据无需手动强转 | `(String) list.get(0)` → `list.get(0)` |
| **代码复用** | 一套代码处理多种类型 | 不用为每种类型单独写类或方法 |
| **提升可读性** | `<>` 直接看出容器/方法能处理的类型 | 一眼看懂代码用途 |

## 3. 基础语法与常用占位符

### 3.1 基础语法

```java
// 标准写法
List<String> list = new ArrayList<String>();

// 菱形语法（JDK 7+，推荐）
List<String> list = new ArrayList<>();

// ❌ 错误：泛型不支持基本类型
List<int> list = new ArrayList<>();
```

> ⚠️ 类型只能写引用类型（类、接口、数组），基本类型（`int`、`long`、`boolean`）需替换为包装类（`Integer`、`Long`、`Boolean`）。

### 3.2 常用泛型占位符

> 占位符只是字母标识，无强制规定，但日常开发遵循通用约定。

| 占位符 | 含义 | 典型场景 | 示例 |
|--------|------|----------|------|
| `E` | Element（元素） | 集合存储的元素类型 | `List<E>` |
| `T` | Type（类型） | 普通任意类型 | `class Generic<T>` |
| `K` | Key（键） | Map 的键 | `Map<K, V>` |
| `V` | Value（值） | Map 的值 | `Map<K, V>` |
| `U` / `R` | 其他额外类型 | 多参数场景 | `<T, U, R>` |

## 4. 泛型的三大分类

### 4.1 泛型类

> 在类名后加 `<占位符>`，整个类内都可以使用该泛型类型。

```java
// 定义泛型类
public class Result<T> {
    private T data;

    // 泛型方法参数
    public void setData(T data) {
        this.data = data;
    }

    // 泛型返回值
    public T getData() {
        return data;
    }
}

// 使用泛型类
Result<String> result1 = new Result<>();           // 指定 String
Result<MenuComponent> result2 = new Result<>();    // 指定自定义类
```

**适用场景**：通用工具类（如统一响应体 `Result<T>`）、业务基类。

---

### 4.2 泛型接口

> 在接口名后加 `<占位符>`，实现类可指定具体类型或保留泛型。

```java
// 定义泛型接口
public interface BaseService<T> {
    T getById(Long id);
}

// 实现类指定具体类型
public class UserServiceImpl implements BaseService<User> {
    @Override
    public User getById(Long id) {
        // ...
        return null;
    }
}
```

---

### 4.3 泛型方法

> 在方法返回值前加 `<占位符>`，仅当前方法使用泛型。

```java
public class GenericMethod {
    // 泛型方法：返回值、参数都用泛型 T
    public static <T> T getFirstElement(List<T> list) {
        if (list == null || list.isEmpty()) {
            return null;
        }
        return list.get(0);
    }
}

// 调用泛型方法，自动识别类型
List<String> strList = new ArrayList<>();
String str = GenericMethod.getFirstElement(strList);
```

> ⚠️ **静态方法必须用泛型方法**，不能使用类的泛型（静态方法属于类，类泛型属于实例）。

### 三大分类对比

| 类型 | 定义位置 | 作用范围 | 典型场景 |
|------|----------|----------|----------|
| 泛型类 | 类名后 `<T>` | 整个类 | 通用工具类、业务基类 |
| 泛型接口 | 接口名后 `<T>` | 接口 + 实现类 | 通用服务接口 |
| 泛型方法 | 返回值前 `<T>` | 仅当前方法 | 静态工具方法 |

## 5. 泛型在集合中的使用

> 日常开发和设计模式代码中，泛型 **90%** 用在集合里，核心是约束集合存储的元素类型。

### 常用集合泛型

| 集合类型 | 约束方式 | 示例 |
|----------|----------|------|
| `List` | 单类型元素约束 | `List<String>` 只能存字符串 |
| `Set` | 去重单类型约束 | `Set<Integer>` 只能存不重复整数 |
| `Map` | 双类型约束（键 + 值） | `Map<String, MenuComponent>` 键 String + 值 菜单对象 |

### 设计模式中的实际代码

```java
// 组合模式：约束容器只能存菜单组件
private List<MenuComponent> childMenuList = new ArrayList<>();

// 享元模式：约束享元池的键和值类型
private static final Map<String, RoleFlyweight> FLYWEIGHT_POOL
        = new ConcurrentHashMap<>();
```

## 6. 泛型通配符

> 通配符用 `?` 表示，代表任意类型，解决泛型无法协变的问题。

### 三种通配符

| 通配符 | 含义 | 读写规则 | 适用场景 |
|--------|------|----------|----------|
| `?` | 无界通配符，任意类型 | 只读，不能添加（除 `null`） | 遍历/打印集合 |
| `? extends T` | 上界通配符，T 或 T 的子类 | 只读不写 | 读取数据 |
| `? super T` | 下界通配符，T 或 T 的父类 | 可写不可读 | 添加数据 |

### PECS 原则速记

> **P**roducer **E**xtends, **C**onsumer **S**uper

```java
// 上界通配符：只读（生产者）
public void printNumbers(List<? extends Number> list) {
    for (Number n : list) {  // ✅ 可读
        System.out.println(n);
    }
    // list.add(1);          // ❌ 不可写
}

// 下界通配符：可写（消费者）
public void addNumbers(List<? super Integer> list) {
    list.add(1);             // ✅ 可写
    // Integer n = list.get(0); // ❌ 不可读（返回 Object）
}
```

## 7. 核心限制与注意事项

> ⚠️ 必记避坑清单

| 限制 | 说明 | 解决方案 |
|------|------|----------|
| **不支持基本类型** | `int` → `Integer`、`long` → `Long` | 使用包装类 |
| **不能创建泛型对象** | 不能 `new T()`，JVM 无法识别具体类型 | 通过反射或工厂模式 |
| **静态方法不能用类泛型** | 静态方法属于类，不属于实例 | 单独定义泛型方法 |
| **运行时类型擦除** | 编译后 `<>` 消失，字节码中变回原始类型 | 理解机制，编码时注意 |
| **不能创建泛型数组** | 禁止 `new List<String>[]` | 用 `ArrayList` 替代 |
| **泛型不参与继承** | `List<Object>` 不是 `List<String>` 的父类 | 使用通配符 |
| **异常类不能定义泛型** | 泛型异常无法被精准捕获 | 语法不支持，无需纠结 |

### 类型擦除图解

```text
编译前：List<String> list = new ArrayList<>();
         ↓ 编译（类型擦除）
编译后：List list = new ArrayList();    // <> 消失，变回原始类型
```

> 💡 Java 泛型是"伪泛型"——类型擦除的目的是兼容 JDK 5 之前的旧代码。

## 8. 常见误区

| 误区 | 真相 |
|------|------|
| 菱形语法是空指针？ | ❌ 不是！是 JDK 7+ 简化写法，自动匹配左侧类型 |
| 泛型可以存任意类型？ | ❌ 一旦指定类型，只能存该类型及子类对象 |
| `List<?>` 和 `List<Object>` 一样？ | ❌ `List<?>` 只读不可添加，`List<Object>` 可添加任意对象 |
| 泛型会影响运行性能？ | ❌ 不会！编译后泛型被擦除，运行时无额外性能损耗 |

## 9. 设计模式中的泛型

泛型在设计模式中的典型应用：

| 设计模式 | 泛型用法 | 作用 |
|----------|----------|------|
| **组合模式** | `List<MenuComponent>` | 约束容器只能存菜单组件，保证树形结构规范 |
| **享元模式** | `Map<String, RoleFlyweight>` | 约束享元池键值类型，确保共享对象类型统一 |
| **装饰模式** | 泛型接口定义通用规范 | 适配不同类型的被装饰对象 |
| **适配器模式** | 泛型接口定义通用规范 | 一套代码适配多种类型 |
