## 1. Java 程序结构

### 1.1 基本程序骨架

```java
package com.example.demo;  // 包声明，必须位于第一行（非注释）

import java.util.Scanner;  // 导入语句，位于包声明之后

/**
 * 类注释：描述类的功能和用途
 * @author Zhang San
 * @version 1.0
 */
public class HelloWorld {  // 类定义：public class 类名

    // 主方法：程序入口点
    public static void main(String[] args) {
        // 输出到控制台
        System.out.println("Hello, World!");

        // 创建对象并调用方法
        HelloWorld hw = new HelloWorld();
        hw.greet("Java");
    }

    /**
     * 实例方法注释
     * @param name 要问候的名字
     */
    public void greet(String name) {
        System.out.println("Hello, " + name + "!");
    }
}
```

### 1.2 编译与运行

```bash
# 编译 Java 源文件 -> 生成 .class 字节码文件
javac HelloWorld.java

# 运行字节码（不要加 .class 后缀）
java HelloWorld

# 带包名的编译运行
javac -d . com/example/demo/HelloWorld.java
java com.example.demo.HelloWorld
```

### 1.3 包（Package）机制

- **命名规范**: 域名倒置（如 `com.company.project.module`），全小写
- **作用**: 命名空间隔离、组织代码、控制访问权限
- **目录结构**: 与包名一一对应

```java
// 推荐包名结构
package com.alibaba.project.user;     // 用户模块
package com.alibaba.project.order;    // 订单模块
package com.alibaba.project.common;   // 公共工具
```

### 1.4 主方法详解

```java
public static void main(String[] args) {
    // public:      JVM 需要访问 main 方法，因此必须公开
    // static:      JVM 无需创建对象即可调用 main
    // void:        main 方法没有返回值
    // String[]:    命令行参数数组
}
```

> **阿里巴巴编程规范**: 所有类都必须添加创建者、日期、功能描述的注释。

## 2. 注释

Java 提供三种注释方式：

```java
// 1. 单行注释：用于简单说明

/*
 * 2. 多行注释：用于多行说明
 * 第二行
 */

/**
 * 3. Javadoc 注释：用于生成 API 文档
 * @author 作者
 * @param 参数说明
 * @return 返回值说明
 * @throws 异常说明
 * @since 版本号
 */
public String getInfo(String key) {
    return "value";
}
```

> **企业规范**: Javadoc 注释必须完整，每个 public 方法都应有 Javadoc。单行注释不要写与代码重复的内容，应解释"为什么"而非"是什么"。

## 3. 变量与数据类型

### 3.1 基本数据类型（Primitive Types）

Java 有 8 种基本数据类型，它们存储在栈内存中，不是对象：

| 类型 | 关键字 | 大小 | 范围 | 默认值 | 示例 |
|------|--------|------|------|--------|------|
| 字节型 | byte | 1 byte (8-bit) | -128 ~ 127 | 0 | `byte b = 100;` |
| 短整型 | short | 2 bytes (16-bit) | -32,768 ~ 32,767 | 0 | `short s = 1000;` |
| 整型 | int | 4 bytes (32-bit) | -2^31 ~ 2^31-1 | 0 | `int i = 100000;` |
| 长整型 | long | 8 bytes (64-bit) | -2^63 ~ 2^63-1 | 0L | `long l = 100000L;` |
| 单精度 | float | 4 bytes (32-bit) | +/- 3.4E-38 ~ +/- 3.4E+38 | 0.0f | `float f = 3.14f;` |
| 双精度 | double | 8 bytes (64-bit) | +/- 1.7E-308 ~ +/- 1.7E+308 | 0.0d | `double d = 3.14159;` |
| 字符型 | char | 2 bytes (16-bit) | 0 ~ 65,535 (Unicode) | 空字符 | `char c = 'A';` |
| 布尔型 | boolean | JVM 依赖 | true / false | false | `boolean flag = true;` |

**注意事项**:
- `long` 字面量必须加 `L` 后缀（大小写均可，推荐大写）
- `float` 字面量必须加 `f` 后缀
- `char` 使用 Unicode 编码，可以存储中文：`char ch = '中';`
- `boolean` 不能与数字类型互转（不像 C 语言）

```java
// 正确的字面量写法
int decimal = 100;            // 十进制
int octal = 0144;             // 八进制（0开头）
int hex = 0x64;               // 十六进制（0x开头）
int binary = 0b1100100;       // 二进制（0b开头，JDK 7+）

long big = 100_000_000_000L;  // 数值中可以加下划线增强可读性（JDK 7+）
float pi = 3.141_592_653f;    // 下划线分隔
```

### 3.2 引用数据类型（Reference Types）

引用类型包括：**类（Class）**、**接口（Interface）**、**数组（Array）**、**枚举（Enum）**、**注解（Annotation）**。

引用类型变量存储的是对象的引用（内存地址），而非对象本身。

```java
String str = new String("Hello"); // str 是引用，指向堆中的对象
String str2 = str;                // str2 指向同一个对象
str = null;                       // 断开引用，对象等待 GC 回收
```

### 3.3 类型转换

#### 自动类型转换（隐式转换）

`byte -> short -> int -> long -> float -> double`

`char -> int`

规则：小范围类型自动转换为大范围类型（宽化转换，安全）。

```java
int i = 100;
long l = i;          // int 自动转为 long
float f = l;         // long 自动转为 float（可能有精度损失）
double d = f;        // float 自动转为 double

char c = 'A';
int code = c;        // char 自动转为 int，code = 65 (Unicode)
```

#### 强制类型转换（显式转换）

大范围 -> 小范围可能导致数据溢出或精度损失。

```java
double d = 3.14159;
int i = (int) d;           // i = 3（截断小数部分）

long l = 100000L;
int i2 = (int) l;          // 安全转换

long big = 3_000_000_000L;  // 超出 int 范围
int overflow = (int) big;   // 数据溢出，得到负值
System.out.println(overflow); // -1294967296（丢失高位数据）

// float/double 转 int 是直接截断小数，不是四舍五入
System.out.println((int) 3.99);  // 3，不是 4
```

#### 表达式中的类型提升

```java
short s1 = 10, s2 = 20;
// int result = s1 + s2;     // 必须用 int，short 运算时自动提升为 int
// short result = s1 + s2;   // 编译错误：lossy conversion

byte b = 1;
// b = b + 1;                // 编译错误
b += 1;                     // 隐含类型转换，等同于 b = (byte)(b + 1)
```

### 3.4 `var` 关键字（JDK 10+）

局部变量类型推断，编译器根据初始化值推断类型。仅能用于局部变量，不能用于字段、方法参数或返回值。

```java
var str = "Hello";              // 推断为 String
var list = new ArrayList<String>();  // 推断为 ArrayList<String>
var map = new HashMap<String, List<Integer>>();  // 简写泛型

// 不能这样用
// var x;                       // 编译错误：必须初始化
// var y = null;                // 编译错误：无法推断类型
// var lambda = x -> x + 1;     // 编译错误：Lambda 需要显式目标类型
```

> **阿里巴巴规范**: 推荐在明确变量类型的情况下使用 `var`，但不要滥用。当代码可读性受影响时（如赋值为复杂泛型），应显式声明类型。

## 4. 运算符

### 4.1 算术运算符

| 运算符 | 描述 | 示例 | 结果 |
|--------|------|------|------|
| `+` | 加法/字符串连接 | `5 + 3`, `"a" + "b"` | `8`, `"ab"` |
| `-` | 减法 | `5 - 3` | `2` |
| `*` | 乘法 | `5 * 3` | `15` |
| `/` | 除法 | `7 / 3`, `7.0 / 3` | `2` (整数), `2.333...` |
| `%` | 取模（余数） | `7 % 3` | `1` |
| `++` | 自增 | `i++`, `++i` | 先取值后加 / 先加后取值 |
| `--` | 自减 | `i--`, `--i` | 先取值后减 / 先减后取值 |

**整数除法陷阱**:

```java
System.out.println(5 / 2);    // 2（截断小数）
System.out.println(5 / 2.0);  // 2.5（浮点数除法）
System.out.println(5.0 / 2);  // 2.5

// 浮点数精度问题
System.out.println(0.1 + 0.2); // 0.30000000000000004
// 解决方案：使用 BigDecimal
```

**自增/自减细节**:

```java
int i = 1;
int a = i++;    // a = 1, i = 2（先赋值再加）
int b = ++i;    // b = 3, i = 3（先加再赋值）
```

**字符串连接**:

```java
System.out.println(1 + 2 + "3");   // "33"（左结合：1+2=3，再+"3"="33"）
System.out.println("1" + 2 + 3);   // "123"（左结合："1"+2="12"，再+3="123"）
System.out.println("1" + (2 + 3)); // "15"（括号优先）
```

### 4.2 关系运算符

| 运算符 | 描述 | 示例 | 结果 |
|--------|------|------|------|
| `==` | 等于 | `5 == 3` | `false` |
| `!=` | 不等于 | `5 != 3` | `true` |
| `>` | 大于 | `5 > 3` | `true` |
| `<` | 小于 | `5 < 3` | `false` |
| `>=` | 大于等于 | `5 >= 5` | `true` |
| `<=` | 小于等于 | `5 <= 3` | `false` |

**引用类型比较陷阱**:

```java
String s1 = new String("hello");
String s2 = new String("hello");
System.out.println(s1 == s2);        // false（比较引用地址）
System.out.println(s1.equals(s2));   // true（比较内容）

Integer a = 127;
Integer b = 127;
System.out.println(a == b);          // true（Integer 缓存 -128~127）

Integer c = 128;
Integer d = 128;
System.out.println(c == d);          // false（超出缓存范围，新建对象）
```

### 4.3 逻辑运算符

| 运算符 | 描述 | 示例 | 说明 |
|--------|------|------|------|
| `&&` | 短路与 | `a && b` | a 为 false 时不计算 b |
| `||` | 短路或 | `a || b` | a 为 true 时不计算 b |
| `!` | 非 | `!a` | 取反 |
| `&` | 非短路与 | `a & b` | 无论 a 是什么都计算 b |
| `^` | 异或 | `a ^ b` | 相同为 false，不同为 true |

**短路运算的重要性**:

```java
String str = null;
// if (str != null && str.length() > 0)  // 安全：短路避免 NPE
// if (str != null & str.length() > 0)   // 危险：会执行 str.length() -> NullPointerException

// 短路与的经典用法
boolean success = validate(input) && saveToDb(input) && sendNotify(input);
// 如果 validate 失败，后面的操作不会执行
```

### 4.4 位运算符

主要用于底层编程、权限控制、性能优化等场景。

| 运算符 | 描述 | 示例 | 结果 |
|--------|------|------|------|
| `&` | 按位与 | `5 & 3` (0101 & 0011) | `1` (0001) |
| `|` | 按位或 | `5 | 3` (0101 | 0011) | `7` (0111) |
| `^` | 按位异或 | `5 ^ 3` (0101 ^ 0011) | `6` (0110) |
| `~` | 按位取反 | `~5` | `-6` |
| `<<` | 左移 | `5 << 2` | `20` (5*4) |
| `>>` | 右移（符号位填充） | `-5 >> 2` | `-2` |
| `>>>` | 无符号右移（零填充） | `-5 >>> 2` | `1073741822` |

**高效运算技巧**:

```java
// 左移/右移替代乘除 2 的幂
int x = 100;
int times4 = x << 2;      // 100 * 4 = 400
int divide8 = x >> 3;     // 100 / 8 = 12

// 判断奇偶
boolean isOdd = (n & 1) == 1;

// 取模（2 的幂）
int mod = hash & (size - 1);  // HashMap 中就用这个技巧

// 交换两个数（炫技，实际推荐用临时变量）
a ^= b;
b ^= a;
a ^= b;
```

### 4.5 三元运算符

```java
// 语法：condition ? valueIfTrue : valueIfFalse
int max = (a > b) ? a : b;

// 嵌套使用（可读性差，不推荐）
int result = (a > b) ? ((a > c) ? a : c) : ((b > c) ? b : c);

// 推荐方式
int max2;
if (a > b) {
    max2 = (a > c) ? a : c;
} else {
    max2 = (b > c) ? b : c;
}
```

> **阿里巴巴规范**: 三元运算符嵌套不要超过 3 层，超过时用 if-else 替代。

### 4.6 instanceof 模式匹配（JDK 16+）

```java
// 传统方式
if (obj instanceof String) {
    String s = (String) obj;  // 需要显式强转
    System.out.println(s.length());
}

// JDK 16+ 模式匹配
if (obj instanceof String s) {  // 直接声明变量 s
    System.out.println(s.length());
}

// 组合条件
if (obj instanceof String s && s.length() > 5) {
    System.out.println(s.toUpperCase());
}
```

## 5. 控制流

### 5.1 if-else 语句

```java
// 基本结构
if (condition) {
    // 条件为 true 时执行
} else if (anotherCondition) {
    // 另一个条件
} else {
    // 以上都不满足
}

// 良好的编码习惯
String result;
if (score >= 90) {
    result = "优秀";
} else if (score >= 80) {
    result = "良好";
} else if (score >= 60) {
    result = "及格";
} else {
    result = "不及格";
}

// 阿里巴巴规范：if-else 嵌套不超过 3 层，超过用卫语句、策略模式或表驱动

// 不推荐：深层嵌套
if (condition1) {
    if (condition2) {
        if (condition3) {
            // ...
        }
    }
}

// 推荐：卫语句提前返回
if (!condition1) return;
if (!condition2) return;
if (!condition3) return;
// 主逻辑...
```

### 5.2 switch 语句与表达式

#### 传统 switch 语句（fall-through 陷阱）

```java
// 每个 case 末尾必须有 break，否则会穿透（fall-through）
int day = 3;
String dayName;
switch (day) {
    case 1:
        dayName = "周一";
        break;          // 忘记 break 会继续执行 case 2 的代码
    case 2:
        dayName = "周二";
        break;
    case 3:
        dayName = "周三";
        break;
    default:
        dayName = "未知";
        break;
}
```

#### Switch 表达式（JDK 14+ 标准化，JDK 17+ 模式匹配）

```java
// JDK 14+ 箭头语法：没有 fall-through，不用写 break
String dayName = switch (day) {
    case 1 -> "周一";
    case 2 -> "周二";
    case 3 -> "周三";
    case 4 -> "周四";
    case 5 -> "周五";
    case 6, 7 -> "周末";  // 多个常量合并
    default -> "未知";
};

// 带 yield 的复杂分支
String result = switch (score) {
    case 100 -> "满分!";
    case 90, 95 -> "优秀";
    case 80 -> {
        System.out.println("良好成绩");
        yield "良好";     // yield 返回值
    }
    default -> "继续努力";
};

// JDK 17+ 模式匹配 + 守卫（when）
Object obj = "Hello";
String info = switch (obj) {
    case Integer i when i > 0 -> "正整数: " + i;
    case Integer i -> "非正整数: " + i;
    case String s -> "字符串长度: " + s.length();
    case null -> "null 值";     // JDK 17+ 支持 null
    default -> "未知类型";
};

// 穷举风格枚举 switch（编译器可检查是否穷举）
enum Color { RED, GREEN, BLUE }
String hex = switch (color) {
    case RED -> "#FF0000";
    case GREEN -> "#00FF00";
    case BLUE -> "#0000FF";
    // 不需要 default，已穷举所有情况
};
```

### 5.3 循环结构

#### for 循环

```java
// 基本 for 循环
for (int i = 0; i < 10; i++) {
    System.out.println(i);
}

// 逗号操作符（多个变量）
for (int i = 0, j = 10; i < j; i++, j--) {
    System.out.println(i + " - " + j);
}

// 死循环
for (;;) {
    // 等效于 while(true)
}

// 增强 for-each 循环（JDK 5+）
int[] numbers = {1, 2, 3, 4, 5};
for (int num : numbers) {
    System.out.println(num);
}

// 注意：for-each 不能在循环中修改集合结构
List<String> list = new ArrayList<>(Arrays.asList("a", "b", "c"));
for (String s : list) {
    // list.remove(s);  // ConcurrentModificationException
}
// 使用 Iterator 或 removeIf
list.removeIf(s -> s.equals("b"));  // JDK 8+
```

#### while 和 do-while 循环

```java
// while：先判断后执行，可能一次都不执行
int i = 0;
while (i < 5) {
    System.out.println(i);
    i++;
}

// do-while：先执行后判断，至少执行一次
int j = 0;
do {
    System.out.println(j);
    j++;
} while (j < 5);

// 典型用法：用户输入验证
Scanner scanner = new Scanner(System.in);
String input;
do {
    System.out.print("请输入 yes/no: ");
    input = scanner.nextLine().trim();
} while (!input.equals("yes") && !input.equals("no"));
```

### 5.4 break 和 continue

```java
// break：终止整个循环
for (int i = 0; i < 10; i++) {
    if (i == 5) break;     // 循环在 i=5 时终止
    System.out.print(i);   // 输出: 01234
}

// continue：跳过本次循环剩余语句
for (int i = 0; i < 10; i++) {
    if (i % 2 == 0) continue;  // 跳过偶数
    System.out.print(i);       // 输出: 13579
}

// 标签 break 和 continue（跳出多层循环）
outer:
for (int i = 0; i < 5; i++) {
    for (int j = 0; j < 5; j++) {
        if (i * j > 6) {
            break outer;      // 直接跳出外层循环
        }
        System.out.println(i + "," + j);
    }
}

// 阿里巴巴规范：避免使用标签 break，可抽取为方法替代
```

## 6. 数组

### 6.1 声明与初始化

```java
// 声明方式
int[] arr1;           // 推荐风格
int arr2[];           // C 风格，不推荐

// 初始化方式 1：静态初始化（声明时赋值）
int[] numbers = {1, 2, 3, 4, 5};
int[] empty = {};     // 空数组

// 初始化方式 2：动态初始化（指定长度，默认值填充）
int[] arr = new int[10];      // 默认值为 0
String[] names = new String[5];  // 默认值为 null
boolean[] flags = new boolean[3]; // 默认值为 false

// 引用类型数组初始化
String[] fruits = new String[]{"Apple", "Banana", "Cherry"};
```

### 6.2 数组常用操作

```java
int[] arr = {5, 2, 8, 1, 9};

// 遍历
for (int i = 0; i < arr.length; i++) {
    System.out.println(arr[i]);
}
for (int n : arr) {
    System.out.println(n);
}

// 复制
int[] copy = Arrays.copyOf(arr, arr.length);           // 完整复制
int[] partial = Arrays.copyOfRange(arr, 1, 4);         // 部分复制 [1,4)
System.arraycopy(arr, 0, copy, 0, arr.length);         // 本地方法，效率最高

// 排序
Arrays.sort(arr);                                      // 快排优化，O(n log n)
Arrays.parallelSort(arr);                              // 并行排序，大数据量时更快

// 搜索（必须先排序）
int index = Arrays.binarySearch(arr, 5);               // 二分查找

// 填充
Arrays.fill(arr, 0);                                   // 全部填充 0
Arrays.fill(arr, 2, 5, 0);                             // [2,5) 填充 0

// 比较
boolean isEqual = Arrays.equals(arr1, arr2);           // 一维数组
boolean isDeepEqual = Arrays.deepEquals(arr3, arr4);   // 多维数组

// 转换为字符串
System.out.println(Arrays.toString(arr));              // 输出: [1, 2, 5, 8, 9]
System.out.println(Arrays.deepToString(matrix));       // 多维数组

// 转为 List（固定大小，不可增删）
List<Integer> list = Arrays.asList(1, 2, 3, 4, 5);
```

### 6.5 数组常见陷阱


### 7.2 方法重载（Overloading）

**规则**：方法名相同，参数列表不同（类型、个数、顺序至少一个不同）。返回值类型不能区分重载。

```java
public class MathUtils {

    // 根据参数类型自动匹配
    public int add(int a, int b) {
        return a + b;
    }

    public double add(double a, double b) {
        return a + b;
    }

    public int add(int a, int b, int c) {       // 参数个数不同
        return a + b + c;
    }

    // 编译错误：仅返回值不同不算重载
    // public long add(int a, int b) { return a + b; }
}

// 自动装箱导致的重载陷阱
public void print(Integer i) { System.out.println("Integer"); }
public void print(int i)    { System.out.println("int"); }

print(42);        // 输出 "int"，精确匹配优先于自动装箱
print(Integer.valueOf(42)); // 输出 "Integer"
```

### 7.3 Java 是值传递（Pass-by-Value）—— 核心考点

**Java 中方法参数永远是值传递**。对基本类型，传递的是值的副本。对引用类型，传递的是引用的副本（即内存地址的副本）。

```java
public static void main(String[] args) {
    // 场景 1：基本类型
    int x = 10;
    modifyPrimitive(x);
    System.out.println(x);  // 10 --- 原变量不变

    // 场景 2：引用类型
    StringBuilder sb = new StringBuilder("Hello");
    modifyReference(sb);
    System.out.println(sb);  // "Hello World" --- 对象内容被改变

    // 场景 3：引用重新赋值
    StringBuilder sb2 = new StringBuilder("Hello");
    modifyReferenceReassign(sb2);
    System.out.println(sb2); // "Hello" --- 引用本身没变

    // 场景 4：String 的特殊性
    String str = "Hello";
    modifyString(str);
    System.out.println(str); // "Hello" --- String 不可变
}

public static void modifyPrimitive(int x) {
    x = 20;  // 修改的是副本，不影响原变量
}

public static void modifyReference(StringBuilder sb) {
    sb.append(" World");  // 通过引用修改了对象内容
}

public static void modifyReferenceReassign(StringBuilder sb) {
    sb = new StringBuilder("New Object");  // 只修改了局部引用变量
}

public static void modifyString(String s) {
    s = s + " World";  // 创建新 String 对象，局部变量指向新对象
}
```

**图示说明**:

```
Before: modifyReference(sb)
  [main]      [modifyReference]
  sb -----> +-----------+ <---- sb (副本)
            | "Hello"    |
            +-----------+

After: sb.append(" World")
  [main]      [modifyReference]
  sb -----> +-----------+ <---- sb (副本)
            |"Hello World"|
            +-----------+
```

### 8.4 阿里巴巴 Java 开发手册核心条款

## 9. 完整示例：学生成绩计算系统

```java
package com.example.demo;

import java.util.Arrays;
import java.util.Scanner;

/**
 * 学生成绩计算系统 --- 综合运用变量、运算符、控制流、数组和方法
 */
public class GradeCalculator {

    private static final int PASS_THRESHOLD = 60;

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        // 输入学生人数
        System.out.print("请输入学生人数: ");
        int count = scanner.nextInt();
        scanner.nextLine();  // 消费换行符

        // 动态创建数组
        String[] names = new String[count];
        double[] scores = new double[count];

        // 录入成绩
        for (int i = 0; i < count; i++) {
            System.out.printf("请输入第 %d 个学生的姓名: ", i + 1);
            names[i] = scanner.nextLine();

            System.out.printf("请输入 %s 的成绩: ", names[i]);
            scores[i] = scanner.nextDouble();
            scanner.nextLine();  // 消费换行符

            // 输入验证
            if (scores[i] < 0 || scores[i] > 100) {
                System.out.println("成绩必须在 0~100 之间，请重新输入");
                i--;  // 重新输入当前学生
            }
        }

        scanner.close();

        // 计算统计信息
        double average = calculateAverage(scores);
        double max = findMax(scores);
        double min = findMin(scores);
        int passCount = countPass(scores);

        // 排序并输出排名
        sortByScore(names, scores);

        // 输出结果
        System.out.println("\n===== 成绩统计 =====");
        System.out.printf("平均分: %.2f%n", average);
        System.out.printf("最高分: %.2f%n", max);
        System.out.printf("最低分: %.2f%n", min);
        System.out.printf("及格人数: %d (%.1f%%)%n", passCount, 100.0 * passCount / count);
        System.out.printf("不及格人数: %d (%.1f%%)%n", count - passCount, 100.0 * (count - passCount) / count);

        System.out.println("\n===== 成绩排名 =====");
        for (int i = 0; i < count; i++) {
            String level = getGradeLevel(scores[i]);
            System.out.printf("第 %d 名: %s - %.1f 分 (%s)%n",
                            i + 1, names[i], scores[i], level);
        }
    }

    /** 计算平均分 */
    public static double calculateAverage(double[] scores) {
        double sum = 0;
        for (double score : scores) {
            sum += score;
        }
        return sum / scores.length;
    }

    /** 查找最高分 */
    public static double findMax(double[] scores) {
        double max = scores[0];
        for (double score : scores) {
            if (score > max) max = score;
        }
        return max;
    }

    /** 查找最低分 */
    public static double findMin(double[] scores) {
        double min = scores[0];
        for (double score : scores) {
            if (score < min) min = score;
        }
        return min;
    }

    /** 计算及格人数 */
    public static int countPass(double[] scores) {
        int count = 0;
        for (double score : scores) {
            if (score >= PASS_THRESHOLD) count++;
        }
        return count;
    }

    /** 根据成绩排序（冒泡排序） */
    public static void sortByScore(String[] names, double[] scores) {
        for (int i = 0; i < scores.length - 1; i++) {
            for (int j = 0; j < scores.length - 1 - i; j++) {
                if (scores[j] < scores[j + 1]) {
                    double tempScore = scores[j];
                    scores[j] = scores[j + 1];
                    scores[j + 1] = tempScore;

                    String tempName = names[j];
                    names[j] = names[j + 1];
                    names[j + 1] = tempName;
                }
            }
        }
    }

    /** 根据分数返回等级 */
    public static String getGradeLevel(double score) {
        if (score >= 90) {
            return "优秀";
        } else if (score >= 80) {
            return "良好";
        } else if (score >= 70) {
            return "中等";
        } else if (score >= 60) {
            return "及格";
        } else {
            return "不及格";
        }
    }
}
```

## 10. 常见陷阱与最佳实践

### 陷阱清单

| 陷阱 | 问题 | 正确做法 |
|------|------|---------|
| 整数除法 | `5 / 2 = 2` | 使用 `5 / 2.0` 或 `5f / 2` |
| 浮点数精度 | `0.1 + 0.2 != 0.3` | 用 `BigDecimal` 处理精确计算 |
| switch 穿透 | 忘记 break | 用 JDK 14+ 箭头语法 |
| `==` 比较字符串 | `new String("a") == new String("a")` -> false | 用 `equals()` |
| Integer 缓存 | `Integer.valueOf(128) == Integer.valueOf(128)` -> false | 用 `equals()` |
| 数组越界 | `arr[arr.length]` | 索引 0~length-1 |
| for-each 修改集合 | `ConcurrentModificationException` | 用 Iterator 或 removeIf |
| 方法参数误解 | 以为引用类型是传引用 | Java 永远是传值 |
| `=` 与 `==` 混淆 | `if (x = 5)` | 编译器会检查 boolean 类型 |
| 资源未关闭 | 文件流/数据库连接泄露 | 用 try-with-resources |

### 最佳实践总结

1. **命名清晰胜过注释**：好的变量名、方法名能自解释
2. **尽早返回**（卫语句）：减少嵌套，提升可读性
3. **避免魔法数字**：使用具名常量
4. **防御性编程**：检查空值、边界条件
5. **方法长度控制**：一屏能看完（不超过 80 行）
6. **优先使用 for-each**：除非需要索引
7. **使用 StringBuilder 拼接字符串**：循环中尤其重要
8. **敏感信息用 char[] 而非 String**：String 不可变，char[] 可清除

## 11. 常见面试题

### 基础篇

1. **Java 语言的主要特性有哪些？**
   - 面向对象、跨平台（JVM）、自动内存管理（GC）、多线程、丰富的 API

2. **JDK、JRE、JVM 的区别是什么？**
   - JDK = JRE + 开发工具（javac、jar 等）
   - JRE = JVM + 类库
   - JVM = 运行时虚拟机（执行字节码）

3. **`==` 和 `equals()` 的区别？**
   - `==` 比较引用地址（基本类型比较值）
   - `equals()` 通常比较内容（Object 的默认实现也是 `==`，String 等类重写了）

4. **Java 是值传递还是引用传递？请举例说明。**
   - 永远是值传递。基本类型传值的副本，引用类型传引用地址的副本

5. **`int` 和 `Integer` 的区别？**
   - `int` 是基本类型，`Integer` 是包装类（对象）
   - `Integer` 有缓存（-128~127）
   - `Integer` 可以为 null

6. **`String` 为什么是不可变的？**
   - 安全性（类加载、网络连接等场景）
   - 字符串池可以共享
   - 线程安全
   - 哈希缓存（String 的 hashCode 被缓存）

7. **`StringBuilder` 和 `StringBuffer` 的区别？**
   - `StringBuffer` 是线程安全的（方法用 `synchronized`）
   - `StringBuilder` 非线程安全，但性能更好
   - 单线程场景优先用 `StringBuilder`

8. **数组和 ArrayList 的区别？**
   - 数组长度固定，ArrayList 动态扩容
   - 数组可以存基本类型，ArrayList 只能存对象
   - 数组性能更好，ArrayList 提供了更多方法

### 进阶篇

9. **Java 中的 `final` 关键字有哪些用法？**
   - 修饰类：不能被继承
   - 修饰方法：不能被重写
   - 修饰变量：值不能被修改（引用类型的引用不可变，但对象内容可变）

10. **`static` 关键字的作用？**
    - 静态变量：类级别共享，所有实例共用一个副本
    - 静态方法：不需要实例即可调用，只能访问静态成员
    - 静态代码块：类加载时执行一次

11. **`switch` 语句支持哪些数据类型？**
    - `byte`、`short`、`char`、`int`（JDK 5+ 支持枚举）
    - `String`（JDK 7+）
    - 各种类型 + 模式匹配（JDK 17+）

12. **什么是自动装箱和拆箱？有哪些陷阱？**
    - 自动装箱：`Integer i = 100;`（编译器调用 `Integer.valueOf()`）
    - 自动拆箱：`int n = i;`（编译器调用 `i.intValue()`）
    - 陷阱：循环中大量装箱产生对象；`Integer` 为 null 时拆箱会 NPE

13. **`transient` 关键字的作用？**
    - 修饰的字段在序列化时被忽略

14. **`volatile` 关键字的作用？**
    - 保证可见性（每次读取从主存中读取）
    - 禁止指令重排序
    - 不保证原子性

15. **`i++` 和 `++i` 的区别？**
    - `i++` 先取值再自增（表达式的值是原值）
    - `++i` 先自增再取值（表达式的值是新值）
