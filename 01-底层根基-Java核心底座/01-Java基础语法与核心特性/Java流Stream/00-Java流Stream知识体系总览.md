# 00 - Java 流 Stream 知识体系总览

> 🌊 Stream 是 Java 8 的函数式数据处理范式——过滤、转换、分组、聚合一条流水线搞定。但「优雅」≠「快」：Stream 不会让代码变快，性能取决于惰性求值、短路能力、并行潜力。2026 年心法：**测量而非直觉，简单 for 循环有时才是最佳方案**

> 🎯 本系列共 **8 篇**，从核心原理到操作全集、从并行流到性能优化、从陷阱排查到面试考点，覆盖 Stream 全链路

## 4. 核心概念速查

| 概念 | 一句话解释 |
|------|-----------|
| **Stream** | 元素序列的函数式处理管道（不存数据只处理） |
| **惰性求值** | 中间操作不执行——遇到终止操作才触发计算 |
| **中间操作** | filter/map/sorted——返回新 Stream（惰性） |
| **终止操作** | collect/forEach/count——触发实际计算 |
| **短路操作** | limit/findFirst/anyMatch——结果确定即停止 |
| **原始类型流** | IntStream/LongStream/DoubleStream——免装箱 |
| **Collector** | 收集器（supplier/accumulator/combiner/finisher） |
| **并行流** | parallelStream——默认 commonPool（ForkJoinPool） |
| **commonPool** | 全局共享线程池——⚠️ 一个阻塞影响所有并行流 |
| **Gatherers** | Java 22 有状态流处理（滑动窗口/mapConcurrent） |
| **虚拟线程** | Java 21 IO 密集型场景（≠ 并行流的数据并行） |
| **effectively final** | Lambda 捕获的变量必须不可变 |

## 5. 一图看懂：Stream 流水线

```text
Stream 流水线（惰性求值）
┌────────┐  中间操作（惰性——不执行）  ┌────────┐  终止操作（触发）  ┌────────┐
│ 数据源  │ → filter → map → sorted → │ 管道构建 │ ──────────────→ │ 结果    │
│ List    │   （返回新 Stream）        │         │   collect/forEach│         │
└────────┘                           └────────┘                   └────────┘

执行时序（关键认知）：
├── 中间操作只是「构建管道」（不碰数据）
├── 终止操作触发后：数据流经管道（逐元素处理）
├── 短路：limit(3) 找到 3 个就停（不全量处理）
└── 金句：没有终止操作的 Stream = 什么都没发生
```
