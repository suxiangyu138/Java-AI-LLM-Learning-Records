# 面向对象程序设计

## 课程概述
- **课程性质**：专业核心必修课
- **适用专业**：计算机类各专业
- **开课学期**：大二学年
- **考核方式**：考试（闭卷）+ 实验 + 平时成绩
- **教学语言**：通常为C++或Java

## 课程目标
1. 理解面向对象程序设计的基本思想和三大特性
2. 掌握C++(或Java)的面向对象特性
3. 能够运用面向对象方法分析和设计程序
4. 培养面向对象的系统设计能力

## 核心知识点

### 第一章：面向对象概述
- 面向过程 vs 面向对象
- OOP三大特性：封装、继承、多态
- 类与对象的基本概念

### 第二章：类与对象（C++为例）
- 类的定义：数据成员 + 成员函数
- 访问控制：public、private、protected
- 对象的创建与使用
- this指针
- 构造函数（默认、带参、拷贝构造）
- 析构函数
- 深拷贝与浅拷贝（需要深拷贝时）

### 第三章：继承
- 继承的基本语法与访问控制
- 三种继承方式：public、protected、private继承
- 派生类的构造与析构顺序（先基类后派生，析构反之）
- 同名成员的访问（作用域限定符::）
- 虚基类（virtual inheritance）解决菱形继承问题

### 第四章：多态
- 多态的实现条件：
  1. 有继承关系
  2. 子类重写父类虚函数
  3. 父类指针/引用指向子类对象
- 虚函数（virtual）：动态绑定（运行时多态）
- 纯虚函数与抽象类：`virtual void func() = 0;`
- 虚函数表（vtable）机制（内部原理）
- 函数重载（编译时多态）
- 运算符重载（operator overloading）

### 第五章：友元与静态成员
- 友元函数与友元类（打破封装）
- 静态数据成员（所有对象共享）
- 静态成员函数（只能访问静态成员）

### 第六章：模板与泛型编程（C++）
- 函数模板：`template<typename T> T max(T a, T b)`
- 类模板：`template<typename T> class Stack { ... }`
- STL（标准模板库）概述：
  - 容器：vector、list、deque、map、set
  - 迭代器（Iterator）
  - 算法：sort、find、for_each

### 第七章：异常处理
- try-catch-throw机制
- 标准异常类
- 自定义异常类

### 第八章：输入输出流
- 标准IO流：cin、cout、cerr
- 文件流：ifstream、ofstream、fstream
- 字符串流：stringstream

## 重点难点
- **重点**：封装/继承/多态的理解与实现、构造函数与析构函数、动态多态
- **难点**：虚函数表机制、菱形继承与虚基类、模板元编程入门

## 学习方法与建议
1. 从C过渡到C++，理解OOP解决了C的什么问题
2. 多写代码，特别是继承链和多态的设计练习
3. 阅读小型开源C++/Java项目，学习OOP设计
4. 学习UML类图辅助面向对象分析与设计
