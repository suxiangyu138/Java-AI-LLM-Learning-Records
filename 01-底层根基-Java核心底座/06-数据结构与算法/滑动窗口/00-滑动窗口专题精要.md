## 1. 核心概念

### 1.1 本质与前提

> 滑动窗口：双指针维护**连续区间**，右扩探索、左缩修正，增量维护窗口状态 → O(n)。

```
成立前提：条件单调性
  扩窗更难满足条件、缩窗更易满足条件
  （等价于子集继承性）

⚠️ 失效场景（面试必答）：
  含负数的子数组和（560）→ 条件不单调
  → 改前缀和 + 哈希

判定口诀："连续看单调，单调看维护，维护看结构"
```

### 1.2 识别信号

```
"连续子数组/子串" + "最长/最短/恰好/至多" → 滑窗
  3 无重复最长子串
  76 最小覆盖子串
  209 最小子数组

⚠️ 决策口诀：
  "连续看单调，单调看维护，维护看结构"
  连续子串 → 检查单调性 → 滑窗
```

### 1.3 为什么是 O(n)

```
两个指针都单调递增、永不回退
  每个元素最多进出窗口各一次 → O(2n)

对比暴力：枚举所有 (l,r) 对 → O(n²)

⚠️ 面试必答：
"右扩左缩 + 增量维护——每个元素
 进窗口一次出窗口一次 → O(n)。"
```

## 2. 完整代码模板

### 2.1 不定长通用模板（核心）

```java
/**
 * 滑动窗口通用模板（不定长）
 * 口诀："右扩左缩，先进后出；最长在外更新，最短在内更新"
 */
public int slidingWindowTemplate(int[] nums, 条件) {
    int left = 0;
    int answer = 0;
    // 窗口状态：计数数组/哈希表/和等

    for (int right = 0; right < nums.length; right++) {
        // ① 扩窗：加入 nums[right]，更新状态
        add(nums[right]);

        // ② 缩窗：while 窗口不合法（必须 while 不是 if！）
        while (窗口不合法) {
            remove(nums[left]);       // 移除左边界
            left++;
        }

        // ③ 更新答案
        //    求最长 → while 外更新（窗口已合法，取最大）
        //    求最短 → while 内更新（窗口刚合法，取最小）
        answer = Math.max(answer, right - left + 1);
    }
    return answer;
}
// ⚠️ 三要点：
//   ① 缩窗必须 while（if 缩一次可能仍不合法）
//   ② 更新位置：最长外/最短内
//   ③ 状态增量维护（不重复计算）
```

### 2.2 3. 无重复字符的最长子串

```java
/**
 * LeetCode 3. 无重复字符的最长子串（Hot 100 最高频）
 */
public int lengthOfLongestSubstring(String s) {
    int[] count = new int[128];         // ASCII 频次
    int left = 0;
    int maxLen = 0;

    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        count[c]++;                     // ① 扩窗：加入右字符

        while (count[c] > 1) {          // ② 缩窗：有重复
            count[s.charAt(left)]--;    //    移除左字符
            left++;
        }

        maxLen = Math.max(maxLen, right - left + 1);   // ③ while 外更新
    }
    return maxLen;
}
// 推演 "abcabcbb"：
//   right=0..2：窗口 [a],[ab],[abc] → max=3
//   right=3(a)：count[a]=2 → 缩到 [bca] → max=3
//   ... 答案 3 ✓
// ⚠️ 缩窗必须 while：可能连续移除多个字符
```

### 2.3 76. 最小覆盖子串（最短型）

```java
/**
 * LeetCode 76. 最小覆盖子串（Hard 必考）
 * valid 记录"已满足的字符种类数"（不是数量！）
 */
public String minWindow(String s, String t) {
    int[] need = new int[128];
    for (char c : t.toCharArray()) need[c]++;

    int required = 0;
    for (int x : need) if (x > 0) required++;   // t 的种类数

    int left = 0, valid = 0, minLen = Integer.MAX_VALUE, start = 0;

    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        if (need[c] > 0) {
            need[c]--;
            if (need[c] == 0) valid++;          // 该类满足
        }

        while (valid == required) {             // ⚠️ 合法就缩（最短型）
            if (right - left + 1 < minLen) {
                minLen = right - left + 1;
                start = left;
            }
            char out = s.charAt(left);
            if (need[out] > 0) {
                if (need[out] == 0) valid--;    // 满足被破坏
                need[out]++;
            }
            left++;
        }
    }
    return minLen == Integer.MAX_VALUE ? ""
        : s.substring(start, start + minLen);
}
// ⚠️ 为什么用"种类数"而非"数量"？
//   种类满足 O(1) 判断（valid == required）
//   数量判断需逐个字符检查（128 次）
```

## 3. 四大子模型

### 3.1 子模型总览

| 子模型 | 缩窗触发 | 答案更新 | 代表题 | 记忆点 |
|------|------|------|:---:|------|
| **定长** | 窗口长度恰为 K | 恰 K 时 | 438/567/643 | 先建首窗 |
| **不定长求最长** | while 窗口不合法 | **while 外**取 max | 3/1004/424 | 合法后更新 |
| **不定长求最短** | while 窗口合法 | **while 内**取 min | 76/209 | 合法时更新 |
| **恰好型** | while 超过限制 | while 外累加 | 992/930 | atMost 容斥 |

```
核心公式（恰好型）：
  exactlyK = atMost(K) - atMost(K-1)
  "恰好 K" 不满足单调性 → 转化为"至多 K"两个窗口相减
```

### 3.2 定长窗口模板

```java
/**
 * 定长窗口：先建首窗再滑动
 * ⚠️ 常见错误：忘记处理第一个窗口！
 */
public int fixedWindow(int[] nums, int k) {
    // ① 先建第一个窗口 [0, k-1]
    int sum = 0;
    for (int i = 0; i < k; i++) sum += nums[i];
    int answer = sum;                     // ⚠️ 首窗也要判断！

    // ② 滑动：加新尾，去旧头
    for (int i = k; i < nums.length; i++) {
        sum += nums[i];                   // 加新尾
        sum -= nums[i - k];               // 去旧头（⚠️ i-k 不是 k-i）
        answer = Math.max(answer, sum);
    }
    return answer;
}
// 应用：643 最大平均、438 异位词、567 排列
// ⚠️ 记忆："先建首窗 + 加新尾去旧头"
```

### 3.3 恰好型（992 K 个不同整数）

```java
/**
 * LeetCode 992. K 个不同整数的子数组（恰好型）
 * exactlyK = atMost(K) - atMost(K-1)
 */
public int subarraysWithKDistinct(int[] nums, int k) {
    return atMostK(nums, k) - atMostK(nums, k - 1);
}

private int atMostK(int[] nums, int k) {
    Map<Integer, Integer> count = new HashMap<>();
    int left = 0, total = 0;

    for (int right = 0; right < nums.length; right++) {
        count.merge(nums[right], 1, Integer::sum);

        while (count.size() > k) {          // 种类太多 → 缩
            int leftVal = nums[left];
            count.merge(leftVal, -1, Integer::sum);
            if (count.get(leftVal) == 0) count.remove(leftVal);
            left++;
        }
        total += right - left + 1;          // ⚠️ 以 right 结尾的合法数
    }
    return total;
}
// 为什么 atMost 能用滑窗？"至多 K"满足单调性！
// "恰好 K"不单调 → 容斥转化为两个"至多"
```

## 4. 滑窗的失效场景

### 4.1 含负数的子数组和（最经典反例）

```
nums = [-1, 1, 0, -2, 2], 找和为 0 的子数组个数（560 题）

❌ 滑窗为什么失效？
  窗口和 < 0 时无法判断该缩窗还是扩窗：
    扩窗加负数 → 和更小；缩窗减负数 → 和变大
    → 条件不单调 → 指针移动无法预测

✅ 正确解法：前缀和 + 哈希表
  prefix[j] - prefix[i] = 0 → 找相同前缀和出现次数

⚠️ 面试必答：
"滑动窗口要求条件单调；含负数时
 窗口和不单调 → 用前缀和+哈希。"
```

### 4.2 其他失效场景

| 场景 | 失效原因 | 替代解法 |
|------|------|------|
| 含负数子数组和 | 窗口和不单调 | 前缀和+哈希 (560) |
| 异或和为 K | 异或无单调性 | 前缀异或+哈希 |
| 中位数类问题 | 中位数不增量维护 | 双堆 (480) |
| 区间最大值 | 需历史信息 | 单调队列 (239) |

### 4.3 单调性判定方法

```
拿到连续子数组/子串题 → 问：
  ① 窗口扩大时，条件"更不容易满足"吗？
  ② 窗口缩小时，条件"更容易满足"吗？
  都成立 → 滑动窗口
  不成立 → 前缀和/DP

⚠️ 记忆："连续看单调，单调看维护，维护看结构"
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"这是连续子串问题 + 单调条件 → 滑动窗口：
 右指针扩展（加入字符，更新频次），
 左指针收缩（不合法时 while 缩到合法）。
 窗口状态增量维护——扩窗加一、缩窗减一。
 最长在外更新（缩完后取最大）。
 每个元素进出各一次 → O(n)。
 暴力枚举所有子串是 O(n²)。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 为什么 O(n)？ | 双指针单调递增，每元素进出各一次 |
| 2 | 缩窗为什么 while？ | 缩一次可能仍不合法（多个重复） |
| 3 | 最长/最短更新位置？ | 最长外（缩完合法）；最短内（刚合法） |
| 4 | 什么时候用滑窗？ | 连续子串 + 条件单调；含负数失效 |
| 5 | 恰好 K 怎么处理？ | 容斥：atMost(K) - atMost(K-1) |
| 6 | valid 是什么？ | 已满足的字符种类数（O(1) 判断） |
| 7 | 定长模板注意？ | 先建首窗 + i-k 去旧头 |
| 8 | 与前缀和选型？ | 单调 → 滑窗；含负数/计数 → 前缀和+哈希 |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 缩窗用 if | 仍不合法 | 用 while |
| 更新位置反 | 答案错 | 最长外最短内 |
| 忘处理首窗 | 漏窗口 | 先建首窗 |
| i-k 写反 | 去错元素 | nums[i-k] |
| 恰好型直接滑 | 答案错 | atMost 容斥 |

> 🎯 **核心要点**：滑窗 = **右扩左缩 + 条件单调 + 增量维护**。三大细节（while 缩窗、更新位置、恰好容斥）+ 239 单调队列是面试全部考点。口诀："右扩左缩，先进后出；最长在外，最短在内；恰好等于至多减至多"。
