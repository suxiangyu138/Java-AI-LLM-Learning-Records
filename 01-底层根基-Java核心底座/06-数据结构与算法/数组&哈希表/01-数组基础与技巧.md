## 1. 数组的本质特性

### 1.1 内存模型

```
数组 = 连续内存块存储相同类型元素

int[] arr = new int[5];
地址：base, base+4, base+8, base+12, base+16

随机访问 arr[i] = base + i × 元素大小
→ O(1) 访问任何位置 ✓（最大的优势）

代价：插入/删除需移动元素 → O(n)
    容量固定（Java 数组不可变长）
```

### 1.2 三大特性

| 特性 | 含义 | 影响 |
|------|------|------|
| **连续内存** | 地址相邻 | 缓存友好、O(1) 随机访问 |
| **定长** | 创建后长度不变 | 扩容需新建数组拷贝 |
| **同类型** | 元素类型一致 | 寻址公式简单 |

## 2. 数组 vs 链表

| 维度 | 数组 | 链表 |
|------|:---:|:---:|
| 随机访问 | **O(1)** | O(n) |
| 头部插入/删除 | O(n)（移动） | **O(1)**（改指针） |
| 内存 | 连续 | 分散 + 指针开销 |
| 缓存友好 | ✅ 高 | ❌ 低 |
| 大小 | 固定 | 动态 |
| 适用 | 频繁查询/访问 | 频繁增删 |

> 💡 实际工程（ArrayList vs LinkedList）：Java 中 ArrayList 几乎总是更优——数组缓存友好 + 自动扩容；LinkedList 节点分散，缓存命中差，且需要额外存储指针。

## 3. 数组遍历模板

```java
// ① 基本遍历
for (int i = 0; i < arr.length; i++) {
    // 访问 arr[i]
}

// ② 从两端向中间（对撞指针）
int left = 0, right = arr.length - 1;
while (left < right) {
    // 处理 arr[left] 和 arr[right]
    left++;
    right--;
}

// ③ 同向双指针（快慢）
int slow = 0;
for (int fast = 0; fast < arr.length; fast++) {
    if (满足条件(arr[fast])) {
        arr[slow++] = arr[fast];   // 原地覆盖
    }
}

// ④ 遍历二维数组
for (int i = 0; i < rows; i++) {
    for (int j = 0; j < cols; j++) {
        // 访问 arr[i][j]
    }
}
// 遍历顺序：先行后列（row-major，缓存友好）
```

## 4. 原地算法思想

### 4.1 什么是原地算法

```
原地算法（In-place）：O(1) 额外空间修改数组
  不申请与 n 成比例的额外数组
  面试加分点：空间从 O(n) → O(1)

典型例子：
  283. 移动零：快慢指针原地覆盖
  75. 颜色分类：三指针原地交换
  48. 旋转图像：转置+翻转（先原地转置）
  189. 旋转数组：三段反转（reverse 三次）
```

### 4.2 旋转数组的原地技巧（189 题）

```java
/**
 * LeetCode 189. 旋转数组（原地 O(1) 空间）
 * 技巧：三次反转
 *   原始：[1,2,3,4,5,6,7], k=3
 *   ① 整体反转 → [7,6,5,4,3,2,1]
 *   ② 前 k 个反转 → [5,6,7,4,3,2,1]
 *   ③ 后 n-k 个反转 → [5,6,7,1,2,3,4] ✓
 */
public void rotate(int[] nums, int k) {
    int n = nums.length;
    k %= n;                        // ⚠️ k 可能大于 n
    reverse(nums, 0, n - 1);       // ① 整体反转
    reverse(nums, 0, k - 1);       // ② 前 k 个反转
    reverse(nums, k, n - 1);       // ③ 后 n-k 个反转
}

private void reverse(int[] arr, int lo, int hi) {
    while (lo < hi) {
        int tmp = arr[lo]; arr[lo] = arr[hi]; arr[hi] = tmp;
        lo++; hi--;
    }
}
```

### 4.3 原地算法的识别

```
题目关键词："原地修改" / "O(1) 额外空间" / "不使用额外数组"
常见手法：
  双指针覆盖（283 移动零）
  交换（75 颜色分类）
  三次反转（189 旋转数组）
  转置+翻转（48 旋转图像）
  标记法（73 矩阵置零：用首行首列做标记）
```

## 5. 边界处理：面试失分重灾区

### 5.1 高频边界 Bug

| 场景 | Bug | 修正 |
|------|------|------|
| 空数组 | 直接 arr[0] 越界 | `if (arr.length == 0) return ...` |
| 单元素 | 循环边界越界 | 特殊处理 n==1 |
| k 取模 | 旋转 k > n 时错 | `k %= n` |
| 下标访问 | 忘记 last = n-1 | 画图标注 |
| 二维边界 | 行/列搞混 | `arr[i].length` 是列数 |
| 负数处理 | 未考虑负数下标 | 偏移或特判 |

### 5.2 数组题通用自检流程

```
写完代码 → 用三个用例自查：
① 空数组 / 空字符串
② 单元素 / 双元素
③ 全部相同 / 包含负数 / 最大边界值

例：两数之和的边界
  nums = [] → 题目保证有解
  nums = [3,3], target=6 → 不能返回 [0,0]（先查后插解决）
```

### 数组题第一反应

```
拿到数组题 → 按顺序问：
  ① 有序吗？→ 双指针/二分
  ② 要求 O(1) 空间吗？→ 原地算法
  ③ 连续子数组吗？→ 滑动窗口/前缀和
  ④ 要找"两个数/是否存在"？→ 哈希表
  ⑤ 求区间和？→ 前缀和
```

> 🎯 **核心要点**：数组是算法的第一语言——记住**O(1) 随机访问、O(n) 增删**的本质，掌握**双指针/前缀和/原地算法**三大基本技巧，**边界先行**（空数组/单元素/取模）是面试不失分的关键。数组题的"第一反应清单"能帮你 30 秒定位题型。
