## 1. 283. 移动零：快慢指针

### 1.1 完整实现（原地 O(1) 空间）

```java
/**
 * LeetCode 283. 移动零
 * 把 0 移到数组末尾，保持非零元素相对顺序，原地操作
 * [0,1,0,3,12] → [1,3,12,0,0]
 *
 * 快慢指针：
 *   slow：下一个非零元素该放的位置
 *   fast：遍历数组
 *   遇到非零 → 放到 slow 位置，slow++
 *   遍历完 → slow 后面全部补 0
 */
public void moveZeroes(int[] nums) {
    int slow = 0;
    for (int fast = 0; fast < nums.length; fast++) {
        if (nums[fast] != 0) {
            nums[slow++] = nums[fast];   // 非零前移
        }
    }
    while (slow < nums.length) {
        nums[slow++] = 0;                // 末尾补零
    }
}

// 优化版：交换而非覆盖（保持数组原地"置换"语义）
public void moveZeroes_Swap(int[] nums) {
    int slow = 0;
    for (int fast = 0; fast < nums.length; fast++) {
        if (nums[fast] != 0) {
            int tmp = nums[slow];        // 交换
            nums[slow] = nums[fast];
            nums[fast] = tmp;
            slow++;
        }
    }
}
```

### 1.2 推演：nums = [0, 1, 0, 3, 12]

```
slow=0, fast=0: nums[0]=0 → 跳过
fast=1: nums[1]=1 ≠ 0 → nums[0]=1, slow=1 → [1,1,0,3,12]
fast=2: nums[2]=0 → 跳过
fast=3: nums[3]=3 ≠ 0 → nums[1]=3, slow=2 → [1,3,0,3,12]
fast=4: nums[4]=12 ≠ 0 → nums[2]=12, slow=3 → [1,3,12,3,12]
补零：nums[3]=0, nums[4]=0 → [1,3,12,0,0] ✓
```

## 2. 75. 颜色分类：荷兰国旗三指针

### 2.1 完整实现（原地 O(n)）

```java
/**
 * LeetCode 75. 颜色分类（荷兰国旗问题）
 * 只有 0/1/2 三种值，原地排序（不能调用库排序）
 *
 * 三指针：
 *   p0：0 的右边界（0 区间末尾）
 *   p2：2 的左边界（2 区间开头）
 *   curr：当前扫描位置
 *
 * 循环不变量：
 *   [0, p0) 全是 0，[p2, n) 全是 2，中间待处理
 */
public void sortColors(int[] nums) {
    int p0 = 0, p2 = nums.length - 1, curr = 0;

    while (curr <= p2) {
        if (nums[curr] == 0) {
            swap(nums, curr, p0);    // 0 交换到左边
            p0++;
            curr++;                  // ⚠️ curr 也要前进（换过来的必是 0 或 1）
        } else if (nums[curr] == 2) {
            swap(nums, curr, p2);    // 2 交换到右边
            p2--;                    // ⚠️ curr 不前进！（换过来的可能还是 2）
        } else {
            curr++;                  // 1 直接跳过
        }
    }
}

private void swap(int[] nums, int i, int j) {
    int tmp = nums[i]; nums[i] = nums[j]; nums[j] = tmp;
}
```

### 2.2 为什么 curr 有时不前进？

```
遇到 2 时：把 2 换到右边，但换回来的元素可能是 0/1/2
  → curr 不能直接前进，要再检查一次换回来的值！
遇到 0 时：把 0 换到左边，换回来的元素只可能是 0/1（p0 区间已排好）
  → curr 可以前进

这是三指针题最容易写错的地方，面试必讲！
```

## 3. 48. 旋转图像：转置+翻转

### 3.1 完整实现（原地 O(1) 空间）

```java
/**
 * LeetCode 48. 旋转图像（顺时针 90°）
 * n×n 矩阵原地旋转。
 *
 * 两步法：
 *   ① 转置：沿主对角线交换 (i,j) ↔ (j,i)
 *   ② 水平翻转：每行左右交换
 *
 * 数学原理：旋转 90° = 转置 + 水平翻转
 *   （逆时针 = 转置 + 垂直翻转）
 */
public void rotate(int[][] matrix) {
    int n = matrix.length;

    // ① 转置
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {   // ⚠️ j 从 i+1 开始（对角线不用换）
            int tmp = matrix[i][j];
            matrix[i][j] = matrix[j][i];
            matrix[j][i] = tmp;
        }
    }

    // ② 水平翻转（每行左右交换）
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n / 2; j++) {
            int tmp = matrix[i][j];
            matrix[i][j] = matrix[i][n - 1 - j];
            matrix[i][n - 1 - j] = tmp;
        }
    }
}
```

### 3.2 推演：3×3 矩阵

```
原始:           转置后:         水平翻转后:
1 2 3           1 4 7           7 4 1
4 5 6    →      2 5 8    →      8 5 2
7 8 9           3 6 9           9 6 3
                                  = 顺时针旋转 90° ✓
```

## 4. 54. 螺旋矩阵：边界模拟

### 4.1 完整实现

```java
/**
 * LeetCode 54. 螺旋矩阵
 * 按顺时针螺旋顺序输出矩阵元素
 *
 * 四边界模拟：
 *   top/bottom/left/right 四个边界
 *   每走完一条边收缩对应边界，边界交叉时结束
 */
public List<Integer> spiralOrder(int[][] matrix) {
    List<Integer> res = new ArrayList<>();
    int top = 0, bottom = matrix.length - 1;
    int left = 0, right = matrix[0].length - 1;

    while (top <= bottom && left <= right) {
        // ① 上边：左 → 右
        for (int j = left; j <= right; j++) {
            res.add(matrix[top][j]);
        }
        top++;                                  // 上边界收缩

        // ② 右边：上 → 下
        for (int i = top; i <= bottom; i++) {
            res.add(matrix[i][right]);
        }
        right--;

        // ⚠️ 单行/单列时需判断（防止重复）
        if (top > bottom || left > right) break;

        // ③ 下边：右 → 左
        for (int j = right; j >= left; j--) {
            res.add(matrix[bottom][j]);
        }
        bottom--;

        // ④ 左边：下 → 上
        for (int i = bottom; i >= top; i--) {
            res.add(matrix[i][left]);
        }
        left++;
    }
    return res;
}
```

### 4.2 关键避坑

```
⚠️ 单行/单列矩阵（如 [[1,2,3]]）：
  走完上边后 top > bottom → 必须 break
  否则下边循环会重复添加元素

推演 [[1,2,3]]：
  上边：1,2,3 → top=1 > bottom=0 → break ✓
  不加判断：下边循环 j=right→left 会重复加 3,2,1 ❌
```

## 5. 238. 除自身以外数组的乘积

### 5.1 完整实现（O(1) 空间进阶版）

```java
/**
 * LeetCode 238. 除自身以外数组的乘积
 * 返回 answer[i] = 除 nums[i] 外所有元素的乘积
 * 要求：不能用除法！O(n) 时间
 *
 * 思路：answer[i] = 左边乘积 × 右边乘积
 *  ① 第一次遍历：answer[i] 存左边乘积
 *  ② 第二次遍历：右边乘积累乘进去
 */
public int[] productExceptSelf(int[] nums) {
    int n = nums.length;
    int[] answer = new int[n];

    // ① 左边乘积：answer[i] = nums[0..i-1] 的乘积
    answer[0] = 1;                    // 最左边没有元素 → 1
    for (int i = 1; i < n; i++) {
        answer[i] = answer[i - 1] * nums[i - 1];
    }

    // ② 右边乘积：从右往左累乘
    int rightProduct = 1;
    for (int i = n - 1; i >= 0; i--) {
        answer[i] *= rightProduct;    // 左边积 × 右边积
        rightProduct *= nums[i];      // 更新右边积
    }
    return answer;
}
```

### 5.2 推演：nums = [1, 2, 3, 4]

```
① 左边积：answer = [1, 1, 2, 6]
② 右边积：
   i=3: answer[3]=6×1=6,  rightProduct=4   → [1,1,2,6]
   i=2: answer[2]=2×4=8,  rightProduct=12  → [1,1,8,6]
   i=1: answer[1]=1×12=12, rightProduct=24 → [1,12,8,6]
   i=0: answer[0]=1×24=24 → [24,12,8,6] ✓
```

## 6. 73. 矩阵置零：原地标记

### 6.1 完整实现（O(1) 空间）

```java
/**
 * LeetCode 73. 矩阵置零
 * 元素为 0 时，把它所在的行和列全部置 0
 * 要求 O(1) 额外空间
 *
 * 原地标记法：
 *   用"首行首列"作为标记位
 *   matrix[i][0] 标记第 i 行是否需要置零
 *   matrix[0][j] 标记第 j 列是否需要置零
 *   （首行首列本身的置零用两个额外变量记录）
 */
public void setZeroes(int[][] matrix) {
    int m = matrix.length, n = matrix[0].length;
    boolean firstRowZero = false, firstColZero = false;

    // ① 记录首行首列是否需要置零
    for (int j = 0; j < n; j++) if (matrix[0][j] == 0) firstRowZero = true;
    for (int i = 0; i < m; i++) if (matrix[i][0] == 0) firstColZero = true;

    // ② 用首行首列标记其他行列
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            if (matrix[i][j] == 0) {
                matrix[i][0] = 0;    // 标记第 i 行
                matrix[0][j] = 0;    // 标记第 j 列
            }
        }
    }

    // ③ 根据标记置零
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            if (matrix[i][0] == 0 || matrix[0][j] == 0) {
                matrix[i][j] = 0;
            }
        }
    }

    // ④ 处理首行首列本身
    if (firstRowZero) Arrays.fill(matrix[0], 0);
    if (firstColZero) {
        for (int i = 0; i < m; i++) matrix[i][0] = 0;
    }
}
```

> 🎯 **核心要点**：数组技巧题的本质是"画图 + 边界"——**快慢指针**（移动零）、**三指针不变量**（颜色分类，2 交换后 curr 不前进）、**转置+翻转**（旋转图像）、**四边界模拟**（螺旋矩阵，单行判断）、**前后缀积**（除自身乘积，两次遍历）、**首行首列标记**（矩阵置零）。每个技巧都有 1-2 个关键细节，面试时主动讲出这些细节就是加分。
