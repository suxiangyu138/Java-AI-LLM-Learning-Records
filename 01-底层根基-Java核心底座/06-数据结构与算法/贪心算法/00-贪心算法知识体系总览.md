## 1. 知识体系导图

```
贪心算法 (Greedy)
│
├── 核心思想 ──────────────────────────────────────────────
│   ├── 局部最优 → 全局最优（每一步做当下最好的选择）
│   ├── 两大性质：贪心选择性质 + 最优子结构
│   ├── 不可反悔：贪心一步定型，无法回退（vs DP 可回退）
│   └── 证明方法：数学归纳法 / 交换论证法
│
├── 判定标准 ──────────────────────────────────────────────
│   ├── 能用贪心：选择局部最优不影响后续决策
│   ├── 不能用贪心：0-1 背包、奇葩硬币找零、负权边最短路
│   └── 90% 贪心题需要排序
│
├── 经典题型 ──────────────────────────────────────────────
│   │
│   ├── 🟢 分配类
│   │   ├── 455. 分发饼干（最小满足最小）
│   │   ├── 135. 分发糖果（两趟遍历）
│   │   └── 1005. K 次取反（贪心排序）
│   │
│   ├── 🟡 区间类（教科书级）
│   │   ├── 435. 无重叠区间（按结束排序）
│   │   ├── 452. 用最少箭引爆气球（端点处理）
│   │   ├── 253. 会议室 II（按开始+堆）
│   │   └── 56. 合并区间
│   │
│   ├── 🟡 序列/构造类
│   │   ├── 763. 划分字母区间（最后出现位置）
│   │   ├── 738. 单调递增的数字
│   │   └── 122. 买卖股票 II（贪心累加）
│   │
│   ├── 🟡 数学类
│   │   ├── 462. 最少移动使数组相等（中位数）
│   │   ├── 991. 坏了的计算器（逆向思维）
│   │   └── 870. 优势洗牌（排序不等式）
│   │
│   └── 🔴 反悔贪心（进阶）
│       ├── 630. 课程表 III（堆 + 反悔）
│       └── 517. 超级洗衣机（交换论证）
│
├── 与 DP 的关系 ──────────────────────────────────────────
│   ├── 贪心 = DP 的特例（无需比较所有子问题）
│   ├── 贪心不可反悔 vs DP 可回退
│   └── 反例识别：0-1 背包 / 硬币找零
│
└── Java 实战 ─────────────────────────────────────────────
    ├── 四步解题法：分解 → 阶段 → 策略 → 证明
    ├── 排序是贪心的前提
    └── 面试话术：策略 + 反例论证
```

## 3. 学习路线推荐

### 🟢 路线 A：零基础入门（1 周）
```
01 核心原理 → 455 分发饼干 → 122 买卖股票 II
→ 1005 K 次取反 → 860 柠檬水找零
```
- **目标**：理解"局部最优"思想，简单题独立 AC
- **题量**：约 8 题

### 🟡 路线 B：面试冲刺（1-2 周）
```
01 快速过 → 03 区间类全部（5题）→ 02 分配类（3题）
→ 04 序列数学（4题）→ 05 高频复盘
```
- **目标**：区间调度全吃透，能证明贪心策略
- **题量**：约 15-18 题

### 🔴 路线 C：全面掌握（2-3 周）
```
完整 01→05 + 每类 5-8 题 + 反例分析
→ 630 课程表 III（反悔贪心+堆）
→ 517 超级洗衣机（交换论证）
→ 870 优势洗牌（排序不等式）
```
- **目标**：贪心 + 证明能力齐备，Hard 题有突破
- **题量**：约 25 题

## 4. 核心概念速查

| 概念 | 一句话解释 | 典型例题 |
|------|-----------|------|
| **贪心选择性质** | 局部最优选择不影响后续最优 | 所有贪心题 |
| **最优子结构** | 全局最优包含子问题最优 | 所有贪心题 |
| **交换论证** | 任意解交换两步后不更差 → 贪心最优 | 435/517 |
| **数学归纳法** | 第一步贪心正确 + 归纳推进 | 455 |
| **区间调度** | 按结束时间排序，优先保留早结束的 | 435/452 |
| **两趟遍历** | 左到右 + 右到左解决双向依赖 | 135 |
| **中位数原理** | 绝对值不等式最优解是中位数 | 462 |
| **逆向思维** | 从结果倒推回起点 | 991 |
| **排序不等式** | 同序和最大、逆序和最小 | 870 |
| **反悔贪心** | 堆保存历史选择，差时替换 | 630 |
| **反例识别** | 局部最优 ≠ 全局最优的情况 | 0-1 背包 |
