## 2. 三大模板速查（默写版）

```java
// ═══════════ 模板一：树 DFS（前序/后序）══════════════
// 适用：104/257/124
int dfs(TreeNode node) {                   // 后序：返回子树信息
    if (node == null) return 0;
    int left = dfs(node.left);             // 先递归
    int right = dfs(node.right);
    return 合并(left, right, node);        // 后处理
}

// ═══════════ 模板二：网格 DFS（沉岛）════════════════
// 适用：200/695/79/130
void dfs(char[][] grid, int i, int j) {
    if (越界(i, j)) return;                 // ① 越界
    if (grid[i][j] != '1') return;          // ② 条件
    grid[i][j] = '0';                       // ③ 标记（递归前！）
    dfs(grid, i + 1, j);                    // ④ 四方向
    dfs(grid, i - 1, j);
    dfs(grid, i, j + 1);
    dfs(grid, i, j - 1);
}

// ═══════════ 模板三：记忆化 DFS ═════════════════════
// 适用：62/329
int dfs(int i, int j, int[][] memo) {
    if (基础情况) return 基础值;
    if (memo[i][j] != -1) return memo[i][j];   // 查缓存
    int result = 递归计算;
    return memo[i][j] = result;                // 存缓存
}
```

## 3. 面试解题话术

```
📣 第 1 步：识别 (15秒)
"求连通块 → DFS。一条路走到底，遇到边界回头。"

📣 第 2 步：说模板 (30秒)
"网格 DFS 四步：越界判断 → 条件判断 →
 标记（沉岛）→ 四方向递归。
 标记必须在递归前，否则相邻格子来回递归会栈溢出。"

📣 第 3 步：说空间优化 (15秒)
"我用沉岛（改成 0）代替 visited 数组，
 省 O(mn) 额外空间。"

📣 第 4 步：复杂度 (15秒)
"每个格子最多访问一次 → O(mn)，空间 O(mn)
 （递归栈最坏深度）。"

📣 第 5 步：验证 (30秒)
"用示例网格推演一次沉岛过程。"
```

## 4. 高频追问与标准回答

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | DFS 和 BFS 怎么选？ | 所有方案/连通块/存在性 → DFS；最短/最少 → BFS |
| 2 | 网格 DFS 标记为什么在递归前？ | 标记太晚，相邻格子会互相发现对方 → 来回递归 → 栈溢出 |
| 3 | 沉岛和 visited 有什么区别？ | 沉岛原地改值（省空间），visited 不改原数组（不破坏输入）；需要恢复的用 visited+回溯 |
| 4 | 什么时候需要回溯撤销？ | 找特定路径（79 单词搜索）需要撤销以探索其他路径；连通块计数不需要 |
| 5 | 图 DFS 为什么必须 visited？ | 图可能有环/共享节点，不标记会无限递归或重复处理 |
| 6 | 颜色法判环原理？ | 0 未访问、1 访问中、2 已完成；递归中遇到"访问中"说明当前路径回到自己 → 有环 |
| 7 | 记忆化和 DP 什么关系？ | 记忆化 = DP 的自顶向下实现（递归+缓存）；表格 DP 是自底向上 |
| 8 | 329 为什么不需要 visited？ | 路径严格递增 → 不可能走回已访问格子 → 天然无环 |
| 9 | 递归栈溢出怎么办？ | 转显式栈迭代（空间仍在堆上），或说明递归深度 = 树高/路径长 |
| 10 | DFS 空间复杂度？ | 递归栈深度：树 O(h)、网格最坏 O(mn)（长蛇形路径） |

## 5. 高频题深度复盘

### 5.1 79. 单词搜索（回溯 DFS 综合）

```java
public boolean exist(char[][] board, String word) {
    for (int i = 0; i < board.length; i++) {
        for (int j = 0; j < board[0].length; j++) {
            if (dfs(board, word, 0, i, j)) return true;
        }
    }
    return false;
}

private boolean dfs(char[][] board, String word, int idx, int i, int j) {
    if (idx == word.length()) return true;         // 匹配完成
    if (越界 || board[i][j] != word.charAt(idx)) return false;

    char temp = board[i][j];
    board[i][j] = '\0';                            // 标记（省 visited）
    boolean found = dfs(board, word, idx+1, i+1, j)
                 || dfs(board, word, idx+1, i-1, j)
                 || dfs(board, word, idx+1, i, j+1)
                 || dfs(board, word, idx+1, i, j-1);
    board[i][j] = temp;                            // 撤销（回溯）
    return found;
}
```

**复盘要点**：
- 标记用 `'\0'` 省 visited 数组（与 200 沉岛同理）
- **必须撤销**：路径搜索需要探索其他方向
- 短路或 `||`：找到即返回，剪枝无效分支

### 5.2 329. 矩阵最长递增路径（Hard 突破）

```java
public int longestIncreasingPath(int[][] matrix) {
    int m = matrix.length, n = matrix[0].length;
    int[][] memo = new int[m][n];
    int max = 0;
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            max = Math.max(max, dfs(matrix, i, j, memo));
    return max;
}

private int dfs(int[][] matrix, int i, int j, int[][] memo) {
    if (memo[i][j] != 0) return memo[i][j];        // 查缓存
    int best = 1;
    for (int[] d : new int[][]{{0,1},{0,-1},{1,0},{-1,0}}) {
        int ni = i + d[0], nj = j + d[1];
        if (越界 || matrix[ni][nj] <= matrix[i][j]) continue;
        best = Math.max(best, 1 + dfs(matrix, ni, nj, memo));
    }
    return memo[i][j] = best;                      // 存缓存
}
```

**复盘要点**：
- 递增无环 → 不需要 visited（面试必讲）
- 记忆化 → 每个格子只算一次 → O(mn)
- 与 DP 的关系：自顶向下 DP

## 6. 调试技巧与自检清单

### 6.1 DFS 自检三步法

```
第 1 步：标记检查
  □ 标记在递归前吗？（否则栈溢出）
  □ 需要撤销吗？（路径搜索要，连通块不要）
  □ 撤销写全了吗？（成对恢复）

第 2 步：边界检查
  □ 递归出口正确吗？（越界/空/目标）
  □ 空网格 / 单格子 / 全相同
  □ 图不连通 → 遍历所有起点了吗？

第 3 步：复杂度检查
  □ 有重叠子问题吗？→ 需要记忆化吗？
  □ 每个节点/格子访问几次？（应恰好一次）
  □ 递归深度会栈溢出吗？（考虑显式栈）
```

### 6.2 高频 Bug 速查表

| Bug | 原因 | 修复 |
|------|------|------|
| 栈溢出 | 标记在递归后 | 标记移到递归前 |
| 死循环 | 图没 visited | 加 visited |
| 结果重复 | 路径搜索忘撤销 | 成对标记/恢复 |
| 漏连通分量 | 图不连通只从一个点搜 | 遍历所有未访问起点 |
| 记忆化无效 | 忘查缓存或忘存缓存 | 查+存缺一不可 |
| 克隆图无限递归 | 先递归再 put map | 先 put 再递归 |
| 判环误判 | 用简单 visited 而非三色 | 颜色法 0/1/2 |

### 6.3 面试手写 Checklist

