## 1. 溢出与精度坑

| 坑 | 错误写法 | 正确写法 | 为什么 |
|------|------|------|------|
| int 求和溢出 | `int sum += x` | `long sum` | 1e9 级两数相加即溢出（int 上限 2.1e9） |
| 乘法溢出 | `int res = a * b` | `long` / 逐项乘除 | 1e5² = 1e10 超 int |
| 绝对值溢出 | `Math.abs(Integer.MIN_VALUE)` | `long` 接住 | 结果仍为负！ |
| 负数转正溢出 | `-n`（n = MIN_VALUE） | `long exp = n; exp = -exp` | 快速幂负指数经典坑 |
| 浮点相等 | `if (a == b)`（double） | 差值比较 `\|a-b\| < 1e-9` | 浮点表示误差 |
| 浮点精度 | 大数用 double 求和 | `BigDecimal` / long 整数运算 | 精度丢失累积 |
| 除法截断 | `(a + b) / 2`（负数） | `a + (b - a) / 2` | 负数时截断方向不同 |
| 整除性误判 | `a / b * b == a` 判整除 | `a % b == 0` | 溢出后恒真 |

### 1.1 溢出自查公式

| 运算 | 安全上界（int → long） | 说明 |
|------|------|------|
| 加法 | 两数绝对值 < 2^30 | long 下基本安全 |
| 乘法 | 两数 < 3×10⁹ 时积 < 1e19 > long 上限！ | 超 1e9 相乘用快速乘 |
| 阶乘 | 20! ≈ 2.4e18 接近 long 上限 | 21! 溢出 |
| 组合数 | C(60,30) ≈ 1.2e17 安全 | C(67,33) 溢出 long |

### 1.2 浮点题的标准处理

| 场景 | 做法 |
|------|------|
| 判相等 | 误差 < 1e-9（相对误差更稳） |
| 输出 | `printf("%.6f")` 固定位数 |
| 二分实数 | 固定迭代 100 次，别用误差判停 |
| 概率期望 | 分数取模（逆元）替代 double |

## 2. 取模坑

| 坑 | 错误 | 正确 | 场景 |
|------|------|------|------|
| 负数取模 | `a % m` | `(a % m + m) % m` | Java 中 `-3 % 5 == -3` |
| 忘记取模 | 只最后取一次 | 每步运算后取模 | 中途即溢出 |
| 除法取模 | `(a / b) % p` | `a * b⁻¹ % p`（逆元） | 模意义下无除法 |
| 合数模费马 | `a^(p-2)` 当 p 合数 | exgcd / exLucas | 逆元可能不存在 |
| 指数模错 | 指数模 p | 指数模 φ(p) | 费马/欧拉降幂 |
| 系数指数混模 | 矩阵快速幂系数指数同模 | 系数模 p、指数模 p-1 | 乘积型递推 |
| 取模对象是负值 | `(a-b) % p` | `((a-b) % p + p) % p` | 减法必须先防负 |
| 0 的逆元 | 对 0 求逆 | 判 `b % p == 0` 提前处理 | 逆元不存在 |

### 2.1 取模三问（每次写取模题先问）

```text
① 模的是什么？      系数模 p；指数模 φ(p)——两者不同！
② 模数质数吗？      质数 → 费马逆元；合数 → exgcd/exLucas
③ 中途要不要模？   计数/组合题每步取模，不能攒到最后
```

> 🎯 取模三问都答对，取模坑就没了。三问答错任何一个，WA 是必然的。

## 3. 输入输出坑

| 坑 | 错误 | 正确 | 影响 |
|------|------|------|:---:|
| 慢读 | `Scanner` 读 10⁶ 数据 | `BufferedReader + StringTokenizer` | TLE |
| 慢输出 | 循环 println | 攒 `StringBuilder` 一次输出 | TLE |
| 读不完行 | `split(" ")` 遇连续空格 | `StringTokenizer` | 读错 |
| 首行多余 | 多组数据首行读了但没用 | 看清 T 语义 | WA |
| 字符读入 | `next()` 读单字符 | `charAt(0)` | 语义错 |
| 换行干扰 | 数字后读字符串 | 先 `nextLine()` 吞掉残留 | 空串 |

### 3.1 快读模板（竞赛标配）

```java
/** 快读：整数流，10⁶ 级输入必备 */
static java.io.BufferedReader br = new java.io.BufferedReader(new java.io.InputStreamReader(System.in));
static java.util.StringTokenizer st;

static long nextLong() throws Exception {
    while (st == null || !st.hasMoreTokens()) st = new java.util.StringTokenizer(br.readLine());
    return Long.parseLong(st.nextToken());
}
```

## 4. 索引与循环坑

| 坑 | 错误 | 正确 |
|------|------|------|
| 含不含上界 | `for (i = 0; i <= n; i++)` 访问 a[i] | 明确 a[n-1] 是最后元素 |
| 双指针相遇 | `l <= r` 处理重复 | 看清取不取等 |
| 滑动窗口 | 先加后缩 vs 先缩后加 | 保证窗口合法再更新答案 |
| 二维索引 | `dp[i][j]` 与 `dp[j][i]` 混 | 明确 i 行 j 列 |
| 旋转数组 | `(i + k) % n` | 记得先 `k %= n` 防 k > n |
| 二进制位 | 位 0 是最低位 | 从 0 编号还是从 1 |
| 字符串索引 | `s.length()` 与 `s.charAt(i)` | 与数组下标一致 |

## 5. 数学算法专属坑

### 5.1 数论与组合数学

| 坑 | 错误 | 正确 |
|------|------|------|
| Lucas 表大小 | 阶乘表开到 n | 只开到 p-1（p 小质数） |
| Lucas 低位越界 | `C(n%p, m%p)` 忘判 m>n | 该位返回 0 |
| 卡特兰除法 | `C(2n,n)/(n+1)` 取模 | 差分式 `C(2n,n)-C(2n,n+1)` |
| 逆元批量 | 逐个快速幂 | 前缀积 + 一次快速幂 |
| 线性递推逆元 | n ≥ p 还用递推 | 递推要求 n < p 且 p 质数 |
| 质因数分解 | 只除到 √n 忘掉剩余大质因子 | `if (n > 1)` 剩余因子 |
| 欧拉函数 | 重复乘同一质因子 | 除尽后再换下一个 |
| 快速幂溢出 | `a*a` 不取模 | 每步 `% p` |
| 概率期望 | 直接用 double 存期望 | 分数取模（逆元） |

### 5.2 组合数四大求法的选择坑

| 场景 | 错误选择 | 正确选择 |
|------|------|------|
| n ≤ 10³ | 阶乘逆元（浪费） | 杨辉递推 |
| n ≤ 10⁶ 质数模 | Lucas（表开不了） | 阶乘 + 逆元 |
| n ≤ 10¹⁸ 小质数模 | 阶乘（开不了） | Lucas |
| 合数模 | 费马逆元 | exLucas / CRT |

### 5.3 卡特兰数识别坑

| 信号 | 误判 | 正解 |
|------|------|------|
| 括号/出栈/路径 | 普通 DP | 「任意前缀 A ≥ B」→ 卡特兰 |
| 「任何时候前缀不越界」 | 组合数直接乘 | Catₙ = C(2n,n)-C(2n,n+1) |
| 二叉树形态数 | 递归枚举 | 卡特兰公式 O(1) |
| 模数整除 n+1 | 通项式取模 | 换差分式 |

### 5.4 快速幂的指数角色坑（高频追问）

| 角色 | 模什么 | 例子 |
|------|------|------|
| 系数 | 模 p | `a^b mod p` 的底数 |
| 指数 | 模 φ(p) | 费马降幂：指数模 p-1 |
| 矩阵指数 | 模 φ(p) | HDU 4549 乘积递推 |

### 5.5 典型取模计算演练（1e9+7）

```text
① (1/2) mod 1e9+7 = 2^(1e9+5) mod 1e9+7 = 500000004
   验证：500000004 × 2 = 1000000008 ≡ 1 (mod 1e9+7) ✓
② C(10, 4) mod 1e9+7：
   fac[10] = 3628800，invfac[4] × invfac[6] 查表
   = 3628800 × 逆元(24) × 逆元(720) = 210 ✓
③ (-3) mod 5：Java 得 -3 → ( -3 % 5 + 5 ) % 5 = 2 ✓
记忆点：手算一遍这三个，取模语义就固化了
```

> 🎯 **核心要点**：通用坑 = 三个习惯（**全 long、防负取模、快读快写**）；数学坑 = 三个记住（**逆元是取模除法唯一解、Lucas 表只开 p、卡特兰用差分式**）。本类坑占比约 15% 但一次踩中就是全错——先背第 2 节三问，再按 5.4 区分指数与系数的模数，最后用 5.5 的手算演练固化语义。
