## 1. 数组与字符串高频坑

| 题 | 坑 | 错误形态 | 修正 |
|------|------|------|------|
| LC 15 三数之和 | 去重时机 | 只对结果去重（TLE/重复） | 排序后**指针移动时跳过重复值** |
| LC 1 两数之和 | 补数查重 | 用自身当答案（2×target） | 边插边查：先查再插 |
| LC 53 最大子数组 | 初始化 | `dp[0]=nums[0]` 忘 | 首元素即状态初值 |
| LC 42 接雨水 | 双指针方向 | 只按一侧算 | 左右双指针维护两侧最高 |
| LC 11 盛水 | 移动判断 | 移动较高的边 | 移动较矮的一边 |
| LC 3 无重复子串 | 窗口收缩 | 收缩后忘更新频次 | 移出窗口必须减频 |
| LC 344 反转字符串 | 位运算交换 | 无 | 双指针相遇条件 `l < r` |
| LC 5 最长回文 | 中心扩展 | 奇偶中心分开写错 | 统一：中心 i 与 i/i+1 各跑一次 |

### 1.1 三数之和标准去重写法

```java
// 排序后：外层 i 跳过重复；内层 l/r 找到后各自跳过重复
if (i > 0 && nums[i] == nums[i-1]) continue;
// 找到一组后：
while (l < r && nums[l] == nums[l+1]) l++;
while (l < r && nums[r] == nums[r-1]) r--;
l++; r--;
```

### 1.2 LC 3 的窗口收缩细节

```java
// ⚠️ 收缩时移出窗口的字符必须减频次，否则「假重复」阻塞窗口
while (freq[s.charAt(r)] > 0) {
    freq[s.charAt(l)]--;              // 移出窗口
    l++;
}
```

## 2. 链表与栈队列高频坑

| 题 | 坑 | 错误形态 | 修正 |
|------|------|------|------|
| LC 206 反转链表 | 断链 | 先动 cur.next 丢后继 | 先存 next 再改指向 |
| LC 21 合并链表 | 收尾 | 一方耗尽忘接 | 尾部接剩余整链 |
| LC 141 环检测 | 快指针 | `fast.next.next` 空指针 | 判 `fast != null && fast.next != null` |
| LC 19 删倒数第 n | 哑节点 | 头节点特判漏 | dummy 统一 |
| LC 20 有效括号 | 栈空 | 右括号时栈空 | 先判空再 pop |
| LC 232 用栈队列 | 转移时机 | 每次操作都搬 | peek/pop 时栈空才搬 |
| LC 155 最小栈 | 同步栈 | 只记当前最小 | 双栈（数据 + 最小值）同步 |
| LC 239 滑动窗口最大 | 单调队列出队 | 过期元素没出 | 先判 `q.front() <= i-k` |

### 2.1 LC 206 反转链表的正确顺序

```java
public ListNode reverseList(ListNode head) {
    ListNode prev = null, cur = head;
    while (cur != null) {
        ListNode next = cur.next;     // ① 先存后继
        cur.next = prev;              // ② 改指向
        prev = cur;                   // ③ 前进
        cur = next;
    }
    return prev;                      // ⚠️ 返回 prev 不是 cur（cur 已 null）
}
```

## 3. 树与图高频坑

| 题 | 坑 | 错误形态 | 修正 |
|------|------|------|------|
| LC 104 最大深度 | 空树 | `root==null` 返回 -1 | 返回 0 |
| LC 102 层序 | 层快照 | 每层忘记录 size | `int s = q.size()` 循环内用 s |
| LC 98 验证 BST | 只验左右子树 | 漏上/下界传递 | 传 `min/max` 边界递归 |
| LC 236 最近公共祖先 | 空判定 | 一个节点是另一个的祖先 | 后序：`l != null && r != null → root` |
| LC 200 岛屿数量 | 越界 | 方向数组越界 | 先判边界再递归 |
| LC 207 课程表 | 入度 | 忘初始化入度数组 | 建图同时统计入度 |
| LC 994 腐烂橘子 | 多源 BFS | 未先入队全部源 | 先扫一遍所有烂橘子入队 |

### 3.1 BST 验证的边界传递

```java
/** LC 98：必须传上下界，不能只比较相邻节点 */
boolean dfs(TreeNode root, long min, long max) {
    if (root == null) return true;
    if (root.val <= min || root.val >= max) return false;
    return dfs(root.left, min, root.val) && dfs(root.right, root.val, max);
}
// ⚠️ 用 long：节点值可到 Integer 边界，int 传参会溢出
// 反例：[5,4,6,null,null,3,7]——只比较相邻节点会误判合法
```

## 4. DP 与贪心高频坑

| 题 | 坑 | 错误形态 | 修正 |
|------|------|------|------|
| LC 70 爬楼梯 | 边界 | n=1 越界 | 提前返回 / 数组开 n+2 |
| LC 198 打家劫舍 | 初始化 | dp[1] 忘取 max | `dp[1] = max(nums[0], nums[1])` |
| LC 322 零钱兑换 | 不可达 | -1 与 0 混 | 初始化为大数，最后判不可达 |
| LC 62 不同路径 | 溢出 | 组合数乘法溢出 | 逐项乘除 / DP |
| LC 300 最长递增 | 二分边界 | 等值处理 | 严格递增用 `lowerBound` 替换 |
| LC 55 跳跃游戏 | 覆盖范围 | 只跳最远 | 维护 `maxReach`，`i > maxReach` 即失败 |
| LC 121 股票 | 顺序 | 先卖后买 | 先更新最小值再算利润 |
| LC 152 最大乘积 | 负负得正 | 只记最大 | 同时维护最大/最小（负号翻转） |

### 4.1 股票类统一套路

```text
dp[i][0] 第 i 天不持有 / dp[i][1] 持有
转移：dp[i][0] = max(dp[i-1][0], dp[i-1][1] + price)
      dp[i][1] = max(dp[i-1][1], dp[i-1][0] - price)
⚠️ 交易次数限制 → 状态加维度「已交易次数」
```

### 4.2 LC 322 的 INF 初始化（本节最高频坑）

```java
public int coinChange(int[] coins, int amount) {
    int INF = amount + 1;                     // ⚠️ 用 amount+1 当 INF，防溢出
    int[] dp = new int[amount + 1];
    Arrays.fill(dp, INF);
    dp[0] = 0;
    for (int c : coins)
        for (int j = c; j <= amount; j++)     // 完全背包：正序
            dp[j] = Math.min(dp[j], dp[j - c] + 1);
    return dp[amount] == INF ? -1 : dp[amount]; // ⚠️ 不可达返回 -1 不是 0
}
```

## 6. 高频坑的统一规律

| 规律 | 代表 | 预防 |
|------|------|------|
| 边界初始化错 | dp 首值、空树空栈 | 写代码前先写边界三行 |
| 状态维护时机错 | BFS 入队即标记、窗口进出同步 | 模板骨架（入队标记/先缩后统） |
| 溢出与取模错 | long、φ(p)、Lucas 表 | 60 秒清单前 4 项 |
| 去重/排序时机错 | 三数之和、区间贪心 | 排序依据先验证 |
| 语义混淆 | 0 vs -1 vs INF | 「不可达」语义统一成一种写法 |

> 🎯 **核心要点**：高频题坑的三个共性——**① 边界初始化**（dp 首值、空树空栈）、**② 状态维护时机**（BFS 入队即标记、窗口进出同步）、**③ 溢出与取模**（long、φ(p)、Lucas 表）。每题提交前用「总览篇 60 秒清单」过一遍，本表是这些坑的高频题落地版。LC 322 的 INF 写法（4.2）值得背下来——「不可达」语义贯穿一半 DP 题。
