# 1. 链表篇

链表题的核心技巧：

| 技巧 | 说明 | 适用场景 |
|------|------|---------|
| **哑节点（Dummy Node）** | 在 head 前加一个虚拟节点，避免处理头节点为空或头节点被修改的边界情况 | LC 21, LC 19, 几乎所有修改头节点的题 |
| **三指针** | prev/cur/next 三个指针控制翻转 | LC 206, LC 92, LC 25 |
| **快慢指针** | 一个走一步，一个走两步 | LC 141, LC 142, LC 234 |
| **先走/后走** | 一个指针先走 n 步，另一个再同步走 | LC 19 |
| **归并思维** | 分治合并有序链表 | LC 21, LC 23, LC 148 |

## 1.1 LC 206 反转链表 ★★★

> 一句话核心思路：**三指针迭代**（prev/cur/next）或 **递归**，每次将 cur.next 指向 prev。必须两种写法都能闭眼写出。

### 题目描述

给你单链表的头节点 `head`，反转链表，并返回反转后的链表头。

### 完整 Java 代码

```java
public class LC206ReverseLinkedList {
    // 解法一：迭代（三指针）—— 推荐，空间 O(1)
    public ListNode reverseList(ListNode head) {
        ListNode prev = null;
        ListNode cur = head;
        while (cur != null) {
            ListNode next = cur.next;   // 保存下一个节点
            cur.next = prev;            // 反转当前节点的指针
            prev = cur;                 // prev 前移
            cur = next;                 // cur 前移
        }
        return prev;                    // prev 就是新头
    }
}
```

```java
    // 解法二：递归
    public ListNode reverseListRecursive(ListNode head) {
        if (head == null || head.next == null) {
            return head;   // 递归出口：空链表或只有一个节点
        }
        ListNode newHead = reverseListRecursive(head.next);
        head.next.next = head;  // head.next 是 oldTail，指向 head 完成反转
        head.next = null;       // 断掉原指向
        return newHead;
    }
}

class ListNode {
    int val;
    ListNode next;
    ListNode() {}
    ListNode(int val) { this.val = val; }
    ListNode(int val, ListNode next) { this.val = val; this.next = next; }
}
```

### 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 |
|-----|-----------|-----------|
| 迭代（三指针） | O(n) | O(1) |
| 递归 | O(n) | O(n) — 递归栈空间 |

### 面试官追问

**Q：递归解法中，为什么 `head.next.next = head` 能反转？**  
A：递归返回后，`head.next` 是反转后的链表尾部，将 `head.next.next` 指向 `head`，相当于把当前节点挂在末尾。画图理解最直观。

**Q：反转链表的前 n 个节点怎么写？**  
A：本质是 LC 92（反转链表 II）的子问题，需要记录第 n+1 个节点的位置并在反转后接上。

> ⚠️ **易错点**：
> - 迭代写法中 `cur.next = prev` 后要小心丢失 `cur.next` 引用，务必先保存到 `next`
> - 递归写法不要漏掉 `head.next = null`，否则链表成环
> - 返回的是 `prev`（新头）而非 `head`

## 1.2 LC 92 反转链表 II ★★☆

> 一句话核心思路：**穿针引线法** —— 找到 left 前驱节点和 right 节点，反转中间段后再接回。关键是用 dummy 节点处理 left=1 的情况。

### 题目描述

给你单链表的头指针 `head` 和两个整数 `left` 和 `right`（`left <= right`），反转从位置 `left` 到位置 `right` 的链表节点，返回反转后的链表。

### 完整 Java 代码

```java
public class LC92ReverseLinkedListII {
    public ListNode reverseBetween(ListNode head, int left, int right) {
        // 哑节点，统一处理 left = 1 的情况
        ListNode dummy = new ListNode(-1);
        dummy.next = head;

        // 1. 找到 left 的前驱节点 pre
        ListNode pre = dummy;
        for (int i = 0; i < left - 1; i++) {
            pre = pre.next;
        }
        ListNode cur = pre.next;   // 待反转段的第一个节点

        // 2. 穿针引线：头插法反转区间
        // 每次将 cur.next 插入到 pre 后面
        for (int i = 0; i < right - left; i++) {
            ListNode next = cur.next;       // 要移到前面的节点
            cur.next = next.next;           // cur 跳过 next
            next.next = pre.next;           // next 指向 pre 后的第一个
            pre.next = next;                // pre 指向 next
        }

        return dummy.next;
    }
}
```

### 复杂度分析

| 维度 | 值 |
|------|----|
| 时间复杂度 | O(n) — 一次遍历到 right |
| 空间复杂度 | O(1) |

### 面试官追问

**Q：头插法反转区间和传统的三指针反转有什么区别？**  
A：头插法将每个节点插入到 pre 之后，不用完全断开后再接回，代码更简洁。三指针法需要先反转子链表再接回两端，各有优劣。

> 💡 **易错点**：
> - 必须用 dummy 节点，否则 `left = 1` 时 pre 为空
> - 头插法的指针操作顺序很关键：先动 cur.next，再连 next.next 和 pre.next
> - 循环次数是 `right - left`，不是 `right - left + 1`

## 1.3 LC 25 K 个一组翻转链表 ★★★

> 一句话核心思路：**分段反转 + 递归/迭代** —— 先找到第 k+1 个节点作为下一段起点，反转当前 k 个节点，再递归处理剩余部分。

### 题目描述

给你链表的头节点 `head`，每 `k` 个节点一组进行翻转，返回翻转后的链表。如果节点总数不是 k 的整数倍，则保持最后的原有顺序。

### 完整 Java 代码

```java
public class LC25ReverseNodesInKGroup {
    public ListNode reverseKGroup(ListNode head, int k) {
        if (head == null || k <= 1) return head;

        // 1. 检查是否有 k 个节点，同时找到第 k+1 个节点
        ListNode tail = head;   // 第 k+1 个节点（或不足 k 时的 null）
        for (int i = 0; i < k; i++) {
            if (tail == null) return head;  // 不足 k 个，不反转
            tail = tail.next;
        }

        // 2. 反转从 head 到 tail 之间的 k 个节点
        ListNode newHead = reverse(head, tail);

        // 3. 递归处理后续部分，head 现在是反转后的末尾
        head.next = reverseKGroup(tail, k);

        return newHead;
    }

    // 反转 [head, tail) 区间，即反转前 k 个节点
    private ListNode reverse(ListNode head, ListNode tail) {
        ListNode prev = null;
        ListNode cur = head;
        while (cur != tail) {
            ListNode next = cur.next;
            cur.next = prev;
            prev = cur;
            cur = next;
        }
        return prev;  // 返回新的头
    }
}
```

### 复杂度分析

| 维度 | 值 |
|------|----|
| 时间复杂度 | O(n) — 每个节点被遍历和反转一次 |
| 空间复杂度 | O(n/k) — 递归深度，平均 O(n/k) |

### 面试官追问

**Q：如果不使用递归，如何迭代实现？**  
A：在外层用 while 循环，每次处理一组前先记录 pre 和 tail，反转后将 pre 与反转后的头相连，反转后的尾与 tail 相连，然后移动 pre 到下一组的前驱。

**Q：如果 k=2 且链表很长，这种写法会不会栈溢出？**  
A：会。递归深度 = n/k，可能栈溢出。生产环境建议用迭代实现。

> ⚠️ **易错点**：
> - `reverse(head, tail)` 是左闭右开区间 `[head, tail)`，画图时注意
> - 反转后 `head` 变成了尾节点，`head.next` 指向下一段
> - 不足 k 个节点时要直接返回，不做反转

## 1.4 LC 21 合并两个有序链表 ★★☆

> 一句话核心思路：**归并思想** —— 双指针比较，谁小指向谁，dummy 节点简化头节点处理。

### 题目描述

将两个升序链表合并为一个新的 **升序** 链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。

### 完整 Java 代码

```java
public class LC21MergeTwoSortedLists {
    // 解法一：迭代（推荐）
    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        ListNode dummy = new ListNode(-1);
        ListNode cur = dummy;

        while (list1 != null && list2 != null) {
            if (list1.val < list2.val) {
                cur.next = list1;
                list1 = list1.next;
            } else {
                cur.next = list2;
                list2 = list2.next;
            }
            cur = cur.next;
        }

        // 处理剩余部分
        cur.next = (list1 != null) ? list1 : list2;

        return dummy.next;
    }
}
```

```java
    // 解法二：递归（优雅）
    public ListNode mergeTwoListsRecursive(ListNode list1, ListNode list2) {
        if (list1 == null) return list2;
        if (list2 == null) return list1;

        if (list1.val < list2.val) {
            list1.next = mergeTwoListsRecursive(list1.next, list2);
            return list1;
        } else {
            list2.next = mergeTwoListsRecursive(list1, list2.next);
            return list2;
        }
    }
}
```

### 复杂度分析

| 维度 | 值 |
|------|----|
| 时间复杂度 | O(m + n) |
| 空间复杂度 | O(1) 迭代 / O(m+n) 递归 |

> 💡 **易错点**：
> - 迭代法最后别忘了处理剩余链表（有一个为 null 时，直接接上另一个）
> - dummy 节点只是占位，返回 `dummy.next`
> - 递归法注意返回的是值较小的那个节点

## 1.5 LC 23 合并 K 个升序链表 ★★★

> 一句话核心思路：**PriorityQueue（最小堆）** —— 将所有链表的头入堆，每次弹出最小节点，将其 next 入堆；或 **分治归并** 两两合并。

### 题目描述

给你一个链表数组，每个链表都已经按升序排列。请你将所有链表合并到一个升序链表中，返回合并后的链表。

### 完整 Java 代码

```java
import java.util.PriorityQueue;

public class LC23MergeKSortedLists {
    // 解法一：PriorityQueue（推荐）
    public ListNode mergeKLists(ListNode[] lists) {
        if (lists == null || lists.length == 0) return null;

        // 最小堆，按节点值排序
        PriorityQueue<ListNode> pq = new PriorityQueue<>(
                (a, b) -> a.val - b.val
        );

        // 所有链表的头节点入堆
        for (ListNode node : lists) {
            if (node != null) pq.offer(node);
        }

        ListNode dummy = new ListNode(-1);
        ListNode cur = dummy;

        while (!pq.isEmpty()) {
            ListNode min = pq.poll();
            cur.next = min;
            cur = cur.next;
            if (min.next != null) {
                pq.offer(min.next);
            }
        }

        return dummy.next;
    }
}
```

```java
// 解法二：分治归并
public class LC23MergeKSortedListsDivideConquer {
    public ListNode mergeKLists(ListNode[] lists) {
        if (lists == null || lists.length == 0) return null;
        return merge(lists, 0, lists.length - 1);
    }

    private ListNode merge(ListNode[] lists, int left, int right) {
        if (left == right) return lists[left];
        int mid = left + (right - left) / 2;
        ListNode l1 = merge(lists, left, mid);
        ListNode l2 = merge(lists, mid + 1, right);
        return mergeTwoLists(l1, l2);
    }

    private ListNode mergeTwoLists(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode(-1);
        ListNode cur = dummy;
        while (l1 != null && l2 != null) {
            if (l1.val < l2.val) {
                cur.next = l1;
                l1 = l1.next;
            } else {
                cur.next = l2;
                l2 = l2.next;
            }
            cur = cur.next;
        }
        cur.next = (l1 != null) ? l1 : l2;
        return dummy.next;
    }
}
```

### 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 |
|-----|-----------|-----------|
| PriorityQueue | O(n log k) — n 总节点数，k 链表数 | O(k) |
| 分治归并 | O(n log k) | O(log k) — 递归栈 |

### 面试官追问

**Q：PriorityQueue 解法中，为什么入堆所有头节点而非全入？**  
A：每个链表只入堆头节点保证堆大小为 k，每次 poll 后入堆该链表的下一个节点。如果同时将链表全部节点入堆，堆大小为 n，复杂度为 O(n log n)。

> 💡 **易错点**：
> - 入堆前检查 `node != null`，避免空链表导致 NullPointerException
> - 大根堆/小根堆别混淆（此题当然用小根堆）
> - 分治法递归终止条件是 `left == right` 而非 `left > right`

## 1.6 LC 141/142 环形链表 I + II ★★★

> 一句话核心思路：**快慢指针** —— 快指针每次两步，慢指针每次一步。如果能相遇则有环（LC 141）。找环入口：相遇后，一个从 head、一个从相遇点同步走，再次相遇即为入口（LC 142）。

### 题目描述

**LC 141**：判断链表是否有环。  
**LC 142**：如果有环，返回环的入口节点。

### 完整 Java 代码

```java
public class LC141LinkedListCycle {
    // LC 141：判断是否有环
    public boolean hasCycle(ListNode head) {
        if (head == null || head.next == null) return false;
        ListNode slow = head;
        ListNode fast = head;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
            if (slow == fast) return true;
        }
        return false;
    }
}
```

```java
public class LC142LinkedListCycleII {
    // LC 142：找环入口
    public ListNode detectCycle(ListNode head) {
        if (head == null || head.next == null) return null;

        // 1. 快慢指针找相遇点
        ListNode slow = head;
        ListNode fast = head;
        boolean hasCycle = false;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
            if (slow == fast) {
                hasCycle = true;
                break;
            }
        }
        if (!hasCycle) return null;

        // 2. 找入口：一个从 head，一个从相遇点，同步走
        ListNode p1 = head;
        ListNode p2 = fast;   // 相遇点
        while (p1 != p2) {
            p1 = p1.next;
            p2 = p2.next;
        }
        return p1;
    }
}
```

### 复杂度分析

| 维度 | 值 |
|------|----|
| 时间复杂度 | O(n) — 线性时间内相遇 |
| 空间复杂度 | O(1) |

### 面试官追问

**Q：为什么快慢指针一定能相遇？**  
A：当 slow 进入环时，fast 已经在环内某处。每次移动，fast 与 slow 的距离减少 1，因此一定会相遇。

**Q：为什么从 head 和相遇点同步走能在入口相遇？**  
A：设 head 到入口距离为 a，入口到相遇点距离为 b，相遇点到入口距离为 c。slow 走的距离 = a + b，fast 走的距离 = a + b + c + b = a + 2b + c。因为 fast 走的距离 = 2 * slow 走的距离，所以 a + 2b + c = 2(a + b) => c = a。所以从 head 和相遇点同步走，相遇点即为入口。

> ⚠️ **易错点**：
> - LC 141 和 LC 142 唯一区别是 LC 142 在相遇后用 `head` 和相遇点同步走
> - while 条件检查 `fast != null && fast.next != null`，缺一不可
> - 判断有环后才继续找入口，无环返回 null

## 1.7 LC 19 删除链表倒数第 N 个节点 ★★☆

> 一句话核心思路：**快慢指针 + 哑节点** —— fast 先走 n+1 步，然后 slow 和 fast 同步走，fast 到末尾时 slow 指向待删节点的前驱。

### 题目描述

给你一个链表，删除链表的倒数第 `n` 个节点，返回链表的头节点。

### 完整 Java 代码

```java
public class LC19RemoveNthFromEnd {
    public ListNode removeNthFromEnd(ListNode head, int n) {
        ListNode dummy = new ListNode(-1);
        dummy.next = head;

        ListNode fast = dummy;
        ListNode slow = dummy;

        // 1. fast 先走 n+1 步（保持 slow 和 fast 间隔 n 个节点）
        for (int i = 0; i <= n; i++) {
            fast = fast.next;
        }

        // 2. slow 和 fast 同步走，直到 fast 为 null
        while (fast != null) {
            slow = slow.next;
            fast = fast.next;
        }

        // 3. slow 指向待删节点的前驱
        slow.next = slow.next.next;

        return dummy.next;
    }
}
```

### 复杂度分析

| 维度 | 值 |
|------|----|
| 时间复杂度 | O(n) — 一次遍历 |
| 空间复杂度 | O(1) |

### 面试官追问

**Q：为什么要用哑节点？**  
A：如果要删除的是头节点（倒数第 n 个节点就是 head），需要统一处理。哑节点简化了 head 被删除的情况。

**Q：fast 先走 n+1 步还是 n 步？**  
A：n+1 步。因为 slow 从 dummy 出发，要保持 slow 和 fast 之间间隔 n 个节点（即 slow 指向待删节点的前驱）。当 fast 为 null 时，slow 在待删节点的前驱。

> 💡 **易错点**：
> - fast 走 n+1 步不是 n 步，这是常见的边界错误
> - 删除操作是 `slow.next = slow.next.next`，不需要 `slow.next = slow.next.next; slow.next.next = null`

## 1.8 LC 234 回文链表 ★★☆

> 一句话核心思路：**找中点 + 反转后半段 + 比较** —— 快慢指针找中点，反转后半段链表，然后比较前后两半是否相同（比较完可恢复）。

### 题目描述

给你一个单链表的头节点 `head`，请判断该链表是否为回文链表。

### 完整 Java 代码

```java
public class LC234PalindromeLinkedList {
    public boolean isPalindrome(ListNode head) {
        if (head == null || head.next == null) return true;

        // 1. 快慢指针找中点（slow 指向前半段末尾）
        ListNode slow = head, fast = head;
        while (fast.next != null && fast.next.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }

        // 2. 反转后半段链表
        ListNode secondHalf = reverse(slow.next);
        ListNode p1 = head;
        ListNode p2 = secondHalf;

        // 3. 比较前半段和反转后的后半段
        boolean isPalindrome = true;
        while (p2 != null) {
            if (p1.val != p2.val) {
                isPalindrome = false;
                break;
            }
            p1 = p1.next;
            p2 = p2.next;
        }

        // 4. 恢复后半段（可选）
        slow.next = reverse(secondHalf);

        return isPalindrome;
    }

    private ListNode reverse(ListNode head) {
        ListNode prev = null, cur = head;
        while (cur != null) {
            ListNode next = cur.next;
            cur.next = prev;
            prev = cur;
            cur = next;
        }
        return prev;
    }
}
```

### 复杂度分析

| 维度 | 值 |
|------|----|
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |

### 面试官追问

**Q：能否用 O(n) 空间但更简单的解法？**  
A：可以。将链表值复制到数组中，再用双指针从两端向中比较。面试时可以先说这个简单解，再优化到 O(1) 空间。

> ⚠️ **易错点**：
> - 找中点时 while 条件用 `fast.next != null && fast.next.next != null`，这样 slow 会停在中间偏左
> - 反转后半段后要记得比较完可以恢复原链表（好的工程习惯）
> - 奇数长度时，中间节点属于前半段

## 1.9 LC 2 两数相加 ★★☆

> 一句话核心思路：**模拟加法竖式** —— 逐位相加，记录进位，构建新链表节点。注意两个链表长度可能不同。

### 题目描述

给你两个 **非空** 的链表，表示两个非负的整数。它们每位数字都是按照 **逆序** 的方式存储的（即个位在头），并且每个节点只能存储 **一位** 数字。将这两个数相加，返回一个新的链表。

### 完整 Java 代码

```java
public class LC02AddTwoNumbers {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode(-1);
        ListNode cur = dummy;
        int carry = 0;  // 进位

        while (l1 != null || l2 != null || carry != 0) {
            int sum = carry;

            if (l1 != null) {
                sum += l1.val;
                l1 = l1.next;
            }
            if (l2 != null) {
                sum += l2.val;
                l2 = l2.next;
            }

            carry = sum / 10;           // 更新进位
            cur.next = new ListNode(sum % 10);  // 创建当前位节点
            cur = cur.next;
        }

        return dummy.next;
    }
}
```

### 复杂度分析

| 维度 | 值 |
|------|----|
| 时间复杂度 | O(max(m, n)) — 遍历较长的链表 |
| 空间复杂度 | O(1)（不计输出空间） / O(max(m,n)) 算输出 |

### 面试官追问

**Q：如果链表是正序存储（高位在头）怎么办？**  
A：先反转两个链表，再用本方法相加，最后反转结果。

**Q：为什么 while 条件要包含 `carry != 0`？**  
A：防止最高位相加后仍有进位被遗漏（如 5 + 5 = 10，最后要输出一个值为 1 的节点）。

> 💡 **易错点**：
> - while 条件用 `||` 而非 `&&`，因为两个链表可能不等长
> - 别忘了包含 `carry != 0` 处理最高位进位
> - 每次用 `new ListNode(sum % 10)` 创建新节点，不要复用原节点

## 1.10 LC 148 排序链表 ★★☆

> 一句话核心思路：**归并排序链表版** —— 用快慢指针找中点分割，递归排序两半，合并两个有序链表。

### 题目描述

给你链表的头节点 `head`，在 **O(n log n)** 时间复杂度和 **常数级** 空间复杂度下，对链表进行排序。

### 完整 Java 代码

```java
public class LC148SortList {
    public ListNode sortList(ListNode head) {
        // 递归出口：空链表或只有一个节点
        if (head == null || head.next == null) return head;

        // 1. 快慢指针找中点，断开链表
        ListNode slow = head, fast = head;
        ListNode prev = null;      // 记录 slow 的前驱，用于断开
        while (fast != null && fast.next != null) {
            prev = slow;
            slow = slow.next;
            fast = fast.next.next;
        }
        prev.next = null;          // 断开成两段：head 和 slow 分别是两段头

        // 2. 递归排序两半
        ListNode left = sortList(head);
        ListNode right = sortList(slow);

        // 3. 合并两个有序链表
        return merge(left, right);
    }

    private ListNode merge(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode(-1);
        ListNode cur = dummy;
        while (l1 != null && l2 != null) {
            if (l1.val < l2.val) {
                cur.next = l1;
                l1 = l1.next;
            } else {
                cur.next = l2;
                l2 = l2.next;
            }
            cur = cur.next;
        }
        cur.next = (l1 != null) ? l1 : l2;
        return dummy.next;
    }
}
```

### 复杂度分析

| 维度 | 值 |
|------|----|
| 时间复杂度 | O(n log n) — 归并排序 |
| 空间复杂度 | O(log n) — 递归栈空间（非"常数级"，但可接受） |

### 面试官追问

**Q：题目要求常数空间，这个解法用了递归栈空间 O(log n)，如何进一步优化？**  
A：用 **自底向上的归并排序**（迭代法）。先按长度为 1 的子链表两两合并，再按长度为 2、4... 直到全部合并。

> ⚠️ **易错点**：
> - 断开链表时用 `prev.next = null`，否则递归会陷入无限循环
> - 快慢指针找中点时，初始值 `slow = head, fast = head`，循环条件 `fast.next != null && fast.next.next != null`
> - 归并排序需要额外实现 `merge` 方法，复用 LC 21 的思路

## 2.1 LC 20 有效的括号 ★★★

> 一句话核心思路：左括号入栈，右括号匹配栈顶。遍历结束后栈为空则有效。

### 题目描述

给定一个只包括 `'('`, `')'`, `'{'`, `'}'`, `'['`, `']'` 的字符串 `s`，判断字符串是否有效。有效括号需满足左括号必须用相同类型的右括号闭合，且按正确顺序闭合。

### 完整 Java 代码

```java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.Map;

public class LC20ValidParentheses {
    public boolean isValid(String s) {
        if (s.length() % 2 != 0) return false;  // 奇数长度一定无效

        Deque<Character> stack = new ArrayDeque<>();
        Map<Character, Character> map = Map.of(
                ')', '(',
                '}', '{',
                ']', '['
        );

        for (char c : s.toCharArray()) {
            if (map.containsKey(c)) {
                // 右括号：检查栈顶是否匹配
                if (stack.isEmpty() || stack.pop() != map.get(c)) {
                    return false;
                }
            } else {
                // 左括号：入栈
                stack.push(c);
            }
        }
        return stack.isEmpty();
    }
}
```

### 复杂度分析

| 维度 | 值 |
|------|----|
| 时间复杂度 | O(n) — 一次遍历 |
| 空间复杂度 | O(n) — 栈空间 |

> 💡 **易错点**：
> - 遇到右括号时先检查栈是否为空，避免空栈 pop
> - 用 Map 存储括号映射关系使代码更简洁
> - 返回条件：栈必须为空（`stack.isEmpty()`），不要直接 return true

## 2.2 LC 155 最小栈 ★★☆

> 一句话核心思路：**辅助栈法** —— 用一个辅助栈同步记录当前最小值。也可以用一个栈存差值。

### 题目描述

设计一个支持 `push`、`pop`、`top` 操作，并能在 **常数时间** 内检索到最小元素的栈。

### 完整 Java 代码

```java
import java.util.ArrayDeque;
import java.util.Deque;

// 解法一：辅助栈（最易理解，推荐）
public class MinStack {
    private Deque<Integer> stack;       // 数据栈
    private Deque<Integer> minStack;    // 辅助栈，栈顶是当前最小值

    public MinStack() {
        stack = new ArrayDeque<>();
        minStack = new ArrayDeque<>();
    }

    public void push(int val) {
        stack.push(val);
        // 辅助栈：与当前最小比较，push 较小值
        if (minStack.isEmpty() || val <= minStack.peek()) {
            minStack.push(val);
        }
        // 另一种写法：始终 push 当前最小值
        // int min = minStack.isEmpty() ? val : Math.min(val, minStack.peek());
        // minStack.push(min);
    }

    public void pop() {
        if (stack.pop().equals(minStack.peek())) {
            minStack.pop();
        }
    }

    public int top() {
        return stack.peek();
    }

    public int getMin() {
        return minStack.peek();
    }
}
```

```java
// 解法二：单栈存差值（节省空间）
public class MinStackDiff {
    private Deque<Long> stack;   // 存 当前值 - 当前最小值 的差值
    private long min;

    public MinStackDiff() {
        stack = new ArrayDeque<>();
    }

    public void push(int val) {
        if (stack.isEmpty()) {
            stack.push(0L);
            min = val;
        } else {
            stack.push((long) val - min);
            if (val < min) min = val;
        }
    }

    public void pop() {
        long diff = stack.pop();
        if (diff < 0) {
            // 被 pop 的是最小值，恢复上一个最小值
            min = min - diff;
        }
    }

    public int top() {
        long diff = stack.peek();
        if (diff < 0) return (int) min;
        return (int) (min + diff);
    }

    public int getMin() {
        return (int) min;
    }
}
```

### 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 |
|-----|-----------|-----------|
| 辅助栈 | O(1) | O(n) |
| 差值法 | O(1) | O(n) — 但实际占用更少 |

### 面试官追问

**Q：辅助栈中为什么用 `<=` 而不是 `<`？**  
A：如果 push 的值等于当前最小值，辅助栈也要 push。否则 pop 时可能出现数据栈的最小值被 pop 了，但辅助栈的最小值也被 pop 了，导致 getMin 错误。例如序列 `push(1), push(1), pop()`。

> 💡 **易错点**：
> - 辅助栈的同步逻辑要严谨，建议用"始终 push 当前最小值"的写法，更不容易出错
> - pop 时注意 `Integer` 用 `equals()` 比较而非 `==`
> - 差值法需要注意整型溢出，使用 `long`

## 2.3 LC 394 字符串解码 ★★☆

> 一句话核心思路：**双栈法** —— 数字栈存重复次数，字符串栈存前缀结果。遇到 `[` 入栈，遇到 `]` 出栈拼字符串。

### 题目描述

给定一个经过编码的字符串，返回它解码后的字符串。编码规则为：`k[encoded_string]`，表示方括号内部的字符串重复 k 次。

### 完整 Java 代码

```java
import java.util.ArrayDeque;
import java.util.Deque;

public class LC394DecodeString {
    public String decodeString(String s) {
        Deque<Integer> numStack = new ArrayDeque<>();   // 数字栈
        Deque<StringBuilder> strStack = new ArrayDeque<>();  // 字符串栈
        StringBuilder cur = new StringBuilder();        // 当前正在拼接的字符串
        int num = 0;

        for (char c : s.toCharArray()) {
            if (Character.isDigit(c)) {
                // 处理多位数：如 "12[abc]"
                num = num * 10 + (c - '0');
            } else if (c == '[') {
                // 入栈，重置
                numStack.push(num);
                strStack.push(cur);
                cur = new StringBuilder();
                num = 0;
            } else if (c == ']') {
                // 出栈拼接
                int repeat = numStack.pop();
                StringBuilder prev = strStack.pop();
                for (int i = 0; i < repeat; i++) {
                    prev.append(cur);
                }
                cur = prev;
            } else {
                // 普通字符，追加到当前字符串
                cur.append(c);
            }
        }
        return cur.toString();
    }
}
```

### 复杂度分析

| 维度 | 值 |
|------|----|
| 时间复杂度 | O(n) — 每个字符遍历一次，拼接时总次数不超过输出长度 |
| 空间复杂度 | O(n) — 栈空间 |

### 面试官追问

**Q：如果嵌套 `3[a2[c]]` 如何处理？**  
A：解法天然支持嵌套。遇到 `[` 时当前状态入栈，遇到 `]` 时从栈中取出上一层的字符串和重复次数，拼接后作为新的当前字符串。

> ⚠️ **易错点**：
> - 数字可能不止一位（如 `12[abc]`），需要用 `num = num * 10 + digit`
> - 字符串栈存的是 `StringBuilder` 而非 `String`，避免重复创建对象
> - 每个 `[` 对应入栈，每个 `]` 对应出栈，保证栈操作正确

## 2.4 LC 739 每日温度 ★★★

> 一句话核心思路：**单调递减栈** —— 栈中存下标，对应的温度是递减的。遇到比栈顶温度高的值，出栈并计算天数差。

### 题目描述

给定一个整数数组 `temperatures`，表示每天的温度，返回一个数组 `answer`，其中 `answer[i]` 是指对于第 `i` 天，下一个更高温度出现在几天后。如果气温不会升高，用 `0` 代替。

### 完整 Java 代码

```java
import java.util.ArrayDeque;
import java.util.Deque;

public class LC739DailyTemperatures {
    public int[] dailyTemperatures(int[] temperatures) {
        int n = temperatures.length;
        int[] answer = new int[n];
        Deque<Integer> stack = new ArrayDeque<>();  // 存下标，温度单调递减

        for (int i = 0; i < n; i++) {
            // 当前温度 > 栈顶温度，说明找到了下一个更高温度
            while (!stack.isEmpty()
                    && temperatures[i] > temperatures[stack.peek()]) {
                int prev = stack.pop();
                answer[prev] = i - prev;  // 天数差
            }
            stack.push(i);  // 当前下标入栈
        }
        // 栈中剩余元素对应 0（没有更高温度），数组默认已为 0

        return answer;
    }
}
```

### 复杂度分析

| 维度 | 值 |
|------|----|
| 时间复杂度 | O(n) — 每个元素入栈一次、出栈最多一次 |
| 空间复杂度 | O(n) — 栈空间 |

### 面试官追问

**Q：单调栈的单调性如何确定？**  
A：找"下一个更大元素"用 **单调递减栈**（栈底到栈顶递减）。当前元素 > 栈顶时出栈，表示找到了栈顶元素的下一个更大元素。反之，找下一个更小元素用单调递增栈。

**Q：如果求的是"下一个更小"的距离？**  
A：将 while 条件改为 `temperatures[i] < temperatures[stack.peek()]`，即单调递增栈。

> 💡 **易错点**：
> - 栈中存的是 **下标** 而非温度值，通过下标取值和计算距离
> - while 循环是当前温度 > 栈顶温度时持续出栈，这个条件不要写反
> - 剩余未出栈的元素默认距离为 0，Java 数组已初始化好

## 2.5 LC 84 柱状图中最大的矩形 ★★★

> 一句话核心思路：**单调递增栈** —— 维护一个递增下标栈。当当前高度 < 栈顶高度时，以栈顶为高的矩形可以确定了（右边界是当前下标，左边界是新栈顶）。在数组末尾加一个高度 0 的哨兵，确保所有元素出栈。

### 题目描述

给定 n 个非负整数，用来表示柱状图中各个柱子的高度。每个柱子彼此相邻，且宽度为 1。求在该柱状图中，能够勾勒出来的矩形的最大面积。

### 完整 Java 代码

```java
import java.util.ArrayDeque;
import java.util.Deque;

public class LC84LargestRectangleInHistogram {
    public int largestRectangleArea(int[] heights) {
        int n = heights.length;
        // 扩展数组：末尾加一个高度 0 的哨兵
        int[] h = new int[n + 1];
        System.arraycopy(heights, 0, h, 0, n);
        h[n] = 0;  // 哨兵，确保所有元素出栈

        Deque<Integer> stack = new ArrayDeque<>();  // 存下标，高度单调递增
        int maxArea = 0;

        for (int i = 0; i < h.length; i++) {
            // 当前高度 < 栈顶高度，出栈计算面积
            while (!stack.isEmpty() && h[i] < h[stack.peek()]) {
                int height = h[stack.pop()];          // 矩形高度
                int left = stack.isEmpty() ? -1 : stack.peek();  // 左边界
                int width = i - left - 1;             // 宽度 = 右边界 - 左边界 - 1
                maxArea = Math.max(maxArea, height * width);
            }
            stack.push(i);
        }
        return maxArea;
    }
}
```

### 复杂度分析

| 维度 | 值 |
|------|----|
| 时间复杂度 | O(n) — 每个元素入栈出栈各一次 |
| 空间复杂度 | O(n) — 栈空间 |

### 面试官追问

**Q：为什么加一个高度 0 的哨兵？**  
A：不加哨兵的话，遍历结束后栈中可能还有元素，需要额外的循环处理。加哨兵确保所有正常柱子都能被弹出计算面积。

**Q：如何确定矩形宽度 `i - left - 1`？**  
A：当前下标 `i` 是右边界（第一个比栈顶矮的柱子），栈顶出栈后的新栈顶 `left` 是左边界（第一个比出栈柱子矮的柱子）。之间的所有柱子高度都 ≥ 出栈柱子的高度，因此宽度为 `i - left - 1`。

**Q：LC 42 接雨水和 LC 84 的单调栈解法有什么区别？**  
A：LC 42（接雨水）用 **单调递减栈**，找左右两侧比底部高的挡板；LC 84（最大矩形）用 **单调递增栈**，找左右两侧比当前柱子矮的边界。两种栈相反，要注意区分。

> ⚠️ **易错点**：
> - 单调递增栈 vs 单调递减栈容易混淆，明确场景：最大矩形用递增，接雨水用递减
> - 宽度计算公式 `i - left - 1` 中的 left 是出栈后的新栈顶（可能为 -1 表示左边界在 -1）
> - 哨兵高度 0 确保所有元素出栈，但哨兵本身不入栈情况的分析——不用分析，哨兵只是为了触发最后的出栈

## 2.6 LC 42 接雨水（栈解法，与 02 文件呼应）

> 一句话核心思路：**单调递减栈** —— 维护一个递减栈。遇到比栈顶高的柱子，弹出栈顶作为凹槽底部，计算当前层的积水量。

### 完整 Java 代码

```java
import java.util.ArrayDeque;
import java.util.Deque;

public class LC42TrappingRainWaterStack {
    public int trap(int[] height) {
        Deque<Integer> stack = new ArrayDeque<>();  // 存下标，栈底到栈顶递减
        int water = 0;

        for (int i = 0; i < height.length; i++) {
            // 当前高度 > 栈顶高度，形成凹槽
            while (!stack.isEmpty() && height[i] > height[stack.peek()]) {
                int bottom = stack.pop();          // 凹槽底部高度
                if (stack.isEmpty()) break;        // 左侧无挡板，无法积水
                int left = stack.peek();           // 左挡板下标
                int w = i - left - 1;              // 宽度
                int h = Math.min(height[left], height[i]) - height[bottom]; // 高度
                water += w * h;
            }
            stack.push(i);
        }
        return water;
    }
}
```

> 💡 **与双指针解法的对比**：双指针解法 O(1) 空间更优，单调栈解法更通用（能处理更复杂的变体）。面试时建议 **先说双指针解**（O(1) 空间），再补充单调栈解。

## 2.7 LC 32 最长有效括号 ★★☆

> 一句话核心思路：**栈**解法 —— 栈底存最后一个未匹配右括号的下标（初始为 -1），匹配成功时计算长度；**DP**解法 —— dp[i] 表示以 i 结尾的最长有效括号长度。

### 题目描述

给你一个只包含 `'('` 和 `')'` 的字符串，找出最长有效（格式正确且连续）括号子串的长度。

### 完整 Java 代码

```java
import java.util.ArrayDeque;
import java.util.Deque;

public class LC32LongestValidParentheses {
    // 解法一：栈（推荐，O(n) 时间 + O(n) 空间）
    public int longestValidParentheses(String s) {
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(-1);  // 栈底存最后一个未匹配右括号的下标

        int maxLen = 0;
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '(') {
                stack.push(i);  // 左括号入栈
            } else {
                stack.pop();    // 匹配一个左括号
                if (stack.isEmpty()) {
                    stack.push(i);  // 栈空，说明当前右括号无法匹配，作为新基准
                } else {
                    maxLen = Math.max(maxLen, i - stack.peek());
                }
            }
        }
        return maxLen;
    }
}
```

```java
// 解法二：动态规划
public class LC32LongestValidParenthesesDP {
    public int longestValidParentheses(String s) {
        int n = s.length();
        int[] dp = new int[n];  // dp[i] 表示以 i 结尾的最长有效括号长度
        int maxLen = 0;

        for (int i = 1; i < n; i++) {
            if (s.charAt(i) == ')') {
                if (s.charAt(i - 1) == '(') {
                    // 情况 1: "...()" 形式
                    dp[i] = (i >= 2 ? dp[i - 2] : 0) + 2;
                } else {
                    // 情况 2: "...))" 形式，检查 i-1 是否形成有效括号对
                    if (i - dp[i - 1] - 1 >= 0
                            && s.charAt(i - dp[i - 1] - 1) == '(') {
                        dp[i] = dp[i - 1] + 2
                                + (i - dp[i - 1] - 2 >= 0
                                    ? dp[i - dp[i - 1] - 2] : 0);
                    }
                }
                maxLen = Math.max(maxLen, dp[i]);
            }
        }
        return maxLen;
    }
}
```

### 面试官追问

**Q：为什么栈底要初始化 -1？**  
A：-1 表示第一个有效括号之前的基准位置。当整个字符串都是有效括号时（如 "()()"），`i - (-1)` 得到正确长度。

**Q：DP 解法中为什么有 `i - dp[i - 1] - 1`？**  
A：这是找到与当前右括号匹配的左括号位置。`i - dp[i - 1] - 1` 是在跳过 i-1 结尾的有效括号段后，再往左找一个位置，检查是否匹配。

> ⚠️ **易错点**：
> - 栈解法：pop 后如果栈为空，说明当前右括号无匹配，将其入栈作为新基准
> - DP 解法：需要考虑 `i - dp[i - 1] - 2 >= 0` 的边界条件，容易数组越界
> - 两种解法边界条件都很多，建议先掌握栈解法（更直观）
