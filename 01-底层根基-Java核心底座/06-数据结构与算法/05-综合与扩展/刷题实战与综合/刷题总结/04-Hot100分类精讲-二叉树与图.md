## 1. 二叉树遍历与性质

### 1.1 LC 94/144/145 二叉树的前中后序遍历 ★★★

**题目描述**：分别实现二叉树的前序遍历（根左右）、中序遍历（左根右）、后序遍历（左右根）。

**核心思路**：

| 方法 | 时间复杂度 | 空间复杂度 | 关键点 |
|------|-----------|-----------|--------|
| 递归 | O(n) | O(n) 栈空间 | 最简单，面试够用 |
| 迭代（栈） | O(n) | O(n) 显式栈 | 手动模拟递归过程 |
| Morris | O(n) | O(1) | 线索二叉树，利用空闲右指针 |

**完整Java代码 — 递归写法（以中序为例）**：

```java
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        dfs(root, res);
        return res;
    }

    private void dfs(TreeNode node, List<Integer> res) {
        if (node == null) return;
        dfs(node.left, res);   // 左
        res.add(node.val);     // 根
        dfs(node.right, res);  // 右
    }
}
// 前序：res.add → dfs(left) → dfs(right)
// 后序：dfs(left) → dfs(right) → res.add
```

**完整Java代码 — 迭代写法（中序）**：

```java
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode cur = root;

        while (cur != null || !stack.isEmpty()) {
            while (cur != null) {       // 一直往左走
                stack.push(cur);
                cur = cur.left;
            }
            cur = stack.pop();          // 弹出
            res.add(cur.val);           // 访问
            cur = cur.right;            // 转向右子树
        }
        return res;
    }
}
```

**完整Java代码 — Morris中序遍历（O(1)空间，加分项）**：

```java
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        TreeNode cur = root, predecessor;

        while (cur != null) {
            if (cur.left == null) {
                res.add(cur.val);
                cur = cur.right;
            } else {
                // 找左子树的最右节点（前驱）
                predecessor = cur.left;
                while (predecessor.right != null && predecessor.right != cur) {
                    predecessor = predecessor.right;
                }
                // 第一次到达：建立线索
                if (predecessor.right == null) {
                    predecessor.right = cur;
                    cur = cur.left;
                }
                // 第二次到达：删除线索并访问
                else {
                    predecessor.right = null;
                    res.add(cur.val);
                    cur = cur.right;
                }
            }
        }
        return res;
    }
}
```

**复杂度**：
- 递归/迭代：时间 O(n)，空间 O(n)
- Morris：时间 O(n)，空间 O(1)

> 💡 **追问**：前序/后序的迭代怎么写？Morris 能不能写前序/后序？
> - 前序迭代：类似中序，在 `stack.push` 时就 `res.add`
> - 后序迭代：`根右左` 再 `reverse`，或者用两个栈
> - Morris 前序：第一次到达时 `res.add`
> - Morris 后序：需要在每次删除线索时，逆序打印左子树的右边界

> ⚠️ **易错点**：
> 1. 递归 `return` 条件别漏了 `node == null`
> 2. 迭代写法中 `while` 条件要同时判断 `cur` 和 `stack`
> 3. Morris 遍历第二次到达时一定要删除线索，否则树结构被破坏

### 1.2 LC 102 二叉树层序遍历 ★★★

**题目描述**：给你二叉树的根节点 `root`，返回其节点值的**层序遍历**（逐层从左到右访问，每层一个 List）。

**核心思路**：BFS 队列模板。每轮循环处理一层的所有节点，`size = queue.size()` 控制分层。

**完整Java代码**：

```java
class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> res = new ArrayList<>();
        if (root == null) return res;

        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            int size = queue.size();
            List<Integer> level = new ArrayList<>();

            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                level.add(node.val);
                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
            res.add(level);
        }
        return res;
    }
}
```

**复杂度**：时间 O(n)，空间 O(n)（队列最大宽度）

> 💡 **追问**：
> 1. 之字形/Zigzag 遍历（LC 103）怎么做？ → 加一个 `boolean leftToRight`，每层决定是否 reverse
> 2. 自底向上层序遍历（LC 107）？ → `Collections.reverse(res)`

> ⚠️ **易错点**：`size` 必须在循环外先取好，因为循环内 queue 长度会变。

### 1.3 LC 104 二叉树最大深度 ★★★

**题目描述**：给定二叉树，求其最大深度（根节点到最远叶子节点的路径上的节点数）。

**核心思路**：

| 方法 | 思路 | 代码 |
|------|------|------|
| DFS 递归 | `maxDepth(root) = 1 + max(maxDepth(left), maxDepth(right))` | 3 行 |
| BFS 层序 | 每遍历一层 depth++ | 模板复用 |

**完整Java代码 — DFS**：

```java
class Solution {
    public int maxDepth(TreeNode root) {
        if (root == null) return 0;
        return 1 + Math.max(maxDepth(root.left), maxDepth(root.right));
    }
}
```

**完整Java代码 — BFS**：

```java
class Solution {
    public int maxDepth(TreeNode root) {
        if (root == null) return 0;
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        int depth = 0;

        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
            depth++;
        }
        return depth;
    }
}
```

**复杂度**：时间 O(n)，空间 DFS O(n) / BFS O(n)

> 💡 **追问**：N 叉树的最大深度（LC 559）？ → 遍历所有子节点递归

> ⚠️ **易错点**：空树深度为 0，递归终止条件不能遗漏。

### 1.4 LC 226 翻转二叉树 ★★☆

**题目描述**：翻转一棵二叉树，即交换每个节点的左右子树。

**核心思路**：递归交换左右子树。先翻转左右子树，再交换当前节点的左右子节点。

**完整Java代码**：

```java
class Solution {
    public TreeNode invertTree(TreeNode root) {
        if (root == null) return null;

        TreeNode left = invertTree(root.left);   // 翻转左子树
        TreeNode right = invertTree(root.right); // 翻转右子树

        root.left = right;  // 交换
        root.right = left;

        return root;
    }
}
```

**复杂度**：时间 O(n)，空间 O(h)

> 💡 **追问**：能否用 BFS/迭代实现？ → 可以，层序遍历时交换每个节点的左右子节点即可。

> ⚠️ **易错点**：递归时如果直接交换 `root.left` 和 `root.right` 再分别递归，会导致一边重复翻转。推荐先保存翻转后的结果再赋值。

### 1.5 LC 101 对称二叉树 ★★☆

**题目描述**：给定二叉树，检查它是否是镜像对称的。

**核心思路**：双指针递归。定义两个指针同时遍历，`p` 往左时 `q` 往右，`p` 往右时 `q` 往左，比较值是否相等。

**完整Java代码 — 递归**：

```java
class Solution {
    public boolean isSymmetric(TreeNode root) {
        if (root == null) return true;
        return isMirror(root.left, root.right);
    }

    private boolean isMirror(TreeNode t1, TreeNode t2) {
        if (t1 == null && t2 == null) return true;
        if (t1 == null || t2 == null) return false;
        return t1.val == t2.val
            && isMirror(t1.left, t2.right)
            && isMirror(t1.right, t2.left);
    }
}
```

**完整Java代码 — 迭代（队列）**：

```java
class Solution {
    public boolean isSymmetric(TreeNode root) {
        if (root == null) return true;
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root.left);
        queue.offer(root.right);

        while (!queue.isEmpty()) {
            TreeNode t1 = queue.poll();
            TreeNode t2 = queue.poll();
            if (t1 == null && t2 == null) continue;
            if (t1 == null || t2 == null) return false;
            if (t1.val != t2.val) return false;
            queue.offer(t1.left);
            queue.offer(t2.right);
            queue.offer(t1.right);
            queue.offer(t2.left);
        }
        return true;
    }
}
```

**复杂度**：时间 O(n)，空间 O(n)

> 💡 **追问**：如何判断一棵树是否和另一棵树相同（LC 100）？ → 去掉镜像对称的交叉比较，改成 `isSameTree(p.left, q.left) && isSameTree(p.right, q.right)`

> ⚠️ **易错点**：递归停止条件要处理 `t1==null && t2==null`（对称）和只有一边为 null（不对称）。

### 1.6 LC 543 二叉树的直径 ★★☆

**题目描述**：给定二叉树，计算其直径——任意两个节点路径长度中的最大值。路径长度 = 经过的节点数 - 1，即边的数量。

**核心思路**：后序遍历 + 全局变量。对于每个节点，经过它的最长路径 = 左子树深度 + 右子树深度，用全局变量记录最大值。

**完整Java代码**：

```java
class Solution {
    private int maxDiameter = 0;

    public int diameterOfBinaryTree(TreeNode root) {
        depth(root);
        return maxDiameter;
    }

    private int depth(TreeNode node) {
        if (node == null) return 0;

        int leftDepth = depth(node.left);   // 左子树深度
        int rightDepth = depth(node.right); // 右子树深度

        // 更新直径：经过当前节点的最长路径
        maxDiameter = Math.max(maxDiameter, leftDepth + rightDepth);

        // 返回当前节点的深度
        return 1 + Math.max(leftDepth, rightDepth);
    }
}
```

**复杂度**：时间 O(n)，空间 O(h)

> 💡 **追问**：如果路径不一定经过根节点怎么办？ → 这正是全局变量的意义，在递归过程中每个节点都会被考虑。

> ⚠️ **易错点**：
> 1. 直径是边的数量，不是节点数。代码中 `leftDepth + rightDepth` 就是边的数量（深度是从当前节点往下数节点数，减掉根节点即边数）
> 2. 全局变量要在类级别而非方法级别定义，否则递归会重置

### 2.1 LC 105 从前序与中序遍历构造二叉树 ★★★

**题目描述**：给定前序遍历和中序遍历数组，构造二叉树。假设无重复元素。

**核心思路**：分治递归。
- 前序：`[根 | 左子树 | 右子树]`
- 中序：`[左子树 | 根 | 右子树]`

前序第一个元素是根，在中序中找到根的位置，左边的就是左子树，右边的是右子树。用 HashMap 存储中序值到索引的映射，O(1) 查找。

**完整Java代码**：

```java
class Solution {
    private Map<Integer, Integer> inorderMap = new HashMap<>();
    private int preIndex = 0;

    public TreeNode buildTree(int[] preorder, int[] inorder) {
        for (int i = 0; i < inorder.length; i++) {
            inorderMap.put(inorder[i], i);
        }
        return build(preorder, 0, inorder.length - 1);
    }

    private TreeNode build(int[] preorder, int inLeft, int inRight) {
        if (inLeft > inRight) return null;

        int rootVal = preorder[preIndex++];
        TreeNode root = new TreeNode(rootVal);
        int inIndex = inorderMap.get(rootVal);

        // 先递归左子树（前序中左子树元素在右子树之前）
        root.left = build(preorder, inLeft, inIndex - 1);
        root.right = build(preorder, inIndex + 1, inRight);

        return root;
    }
}
```

**复杂度**：时间 O(n)，空间 O(n)

> 💡 **追问**：
> 1. 从中序+后序构造（LC 106）？ → 思路相同，但后序从尾部开始取根
> 2. 含重复元素怎么办？ → 需要额外的处理逻辑，通常可以借助下标而非值来区分

> ⚠️ **易错点**：
> 1. 必须先用 HashMap 建立中序值→索引映射
> 2. 先递归左子树再递归右子树，因为前序遍历中左子树元素紧跟在根之后
> 3. 递归终止条件 `inLeft > inRight`

### 2.2 LC 98 验证二叉搜索树 ★★★

**题目描述**：给定二叉树，判断其是否为二叉搜索树（BST）。BST 定义：左子树所有节点 < 根 < 右子树所有节点。

**核心思路**：

| 方法 | 思路 | 空间 |
|------|------|------|
| 递归传范围 | 每个节点传入 (min, max) 区间约束 | O(h) |
| 中序遍历 | BST 中序遍历一定是升序序列 | O(n) |

**完整Java代码 — 递归传范围**：

```java
class Solution {
    public boolean isValidBST(TreeNode root) {
        return isValid(root, Long.MIN_VALUE, Long.MAX_VALUE);
    }

    private boolean isValid(TreeNode node, long min, long max) {
        if (node == null) return true;
        if (node.val <= min || node.val >= max) return false;
        return isValid(node.left, min, node.val)
            && isValid(node.right, node.val, max);
    }
}
```

**完整Java代码 — 中序遍历**：

```java
class Solution {
    private TreeNode prev = null;

    public boolean isValidBST(TreeNode root) {
        if (root == null) return true;

        // 检查左子树
        if (!isValidBST(root.left)) return false;

        // 检查当前节点
        if (prev != null && root.val <= prev.val) return false;
        prev = root;

        // 检查右子树
        return isValidBST(root.right);
    }
}
```

**复杂度**：时间 O(n)，空间 O(h)

> 💡 **追问**：
> 1. 为什么用 `Long.MIN_VALUE` 而不是 `Integer.MIN_VALUE`？ → 因为节点的值可能正好是 `Integer.MIN_VALUE`
> 2. 中序遍历判断 BST 的缺点？ → 不能检测子树中的值重复问题，但 BST 定义本身不允许重复值

> ⚠️ **易错点**：
> 1. 只判断 `left.val < root.val < right.val` 不够！必须保证左子树所有节点都小于根，右子树所有节点都大于根
> 2. 中序遍历用 `prev` 时要定义为成员变量，递归过程中持续跟踪

### 2.3 LC 297 二叉树的序列化与反序列化（前序）★★☆

**题目描述**：设计算法实现二叉树的序列化（→字符串）和反序列化（字符串→树）。用 `#` 表示 null 节点，`,` 分隔。

**核心思路**：前序遍历，遇到 null 用 `#` 标记。反序列化时用队列按前序顺序重建。

**完整Java代码**：

```java
public class Codec {
    // 序列化
    public String serialize(TreeNode root) {
        StringBuilder sb = new StringBuilder();
        serializeHelper(root, sb);
        return sb.toString();
    }

    private void serializeHelper(TreeNode node, StringBuilder sb) {
        if (node == null) {
            sb.append("#,");
            return;
        }
        sb.append(node.val).append(",");
        serializeHelper(node.left, sb);
        serializeHelper(node.right, sb);
    }

    // 反序列化
    public TreeNode deserialize(String data) {
        Queue<String> queue = new LinkedList<>(Arrays.asList(data.split(",")));
        return deserializeHelper(queue);
    }

    private TreeNode deserializeHelper(Queue<String> queue) {
        String val = queue.poll();
        if (val.equals("#")) return null;

        TreeNode node = new TreeNode(Integer.parseInt(val));
        node.left = deserializeHelper(queue);
        node.right = deserializeHelper(queue);
        return node;
    }
}
```

**复杂度**：时间 O(n)，空间 O(n)

> 💡 **追问**：
> 1. 如果用层序遍历序列化怎么做？ → BFS 序列化，同样标记 null，但要注意最后一层 null 的处理
> 2. LeetCode 上用的什么格式？ → 就是这种 `[1,2,3,null,null,4,5]` 格式，本质是层序

> ⚠️ **易错点**：
> 1. 序列化分隔符要统一，不能用逗号混用其他符号
> 2. 反序列化时拆分的字符串注意空字符串的处理
> 3. null 节点必须显式标记，否则无法重建树结构

### 2.4 LC 114 二叉树展开为链表 ★★☆

**题目描述**：将二叉树就地（in-place）展开为单链表，顺序与前序遍历相同。右指针作为 next，左指针置为 null。

**核心思路**：后序遍历变体。先递归展开左右子树，再把右子树接到左子树的最右节点后面，最后把左子树移到右边。

**完整Java代码**：

```java
class Solution {
    public void flatten(TreeNode root) {
        if (root == null) return;

        flatten(root.left);
        flatten(root.right);

        // 后序位置
        TreeNode left = root.left;
        TreeNode right = root.right;

        // 左子树移到右边
        root.left = null;
        root.right = left;

        // 找到原左子树的最右节点，接上原右子树
        TreeNode cur = root;
        while (cur.right != null) {
            cur = cur.right;
        }
        cur.right = right;
    }
}
```

**复杂度**：时间 O(n)，空间 O(h)

> 💡 **追问**：可以用前序遍历 + 额外 List 存储节点然后串联吗？ → 可以，但那样空间复杂度为 O(n)。本题要求就地展开

> ⚠️ **易错点**：
> 1. 操作顺序：必须先展开左右子树，再处理当前节点（后序遍历）
> 2. 找到左子树最右节点时要用 while 循环
> 3. 记得把 `root.left` 置为 null

## 3. 二叉树进阶

### 3.1 LC 236 二叉树的最近公共祖先 ★★★

**题目描述**：给定二叉树和两个节点 p、q，找到它们的最近公共祖先（LCA）。

> 字节跳动面试必问题目。

**核心思路**：后序遍历。
- 如果当前节点是 p 或 q，返回当前节点
- 递归在左右子树中查找
- 如果左右子树都找到了（非 null），说明当前节点是 LCA
- 如果只在一边找到了，返回那一边的结果

**完整Java代码**：

```java
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        if (root == null || root == p || root == q) return root;

        TreeNode left = lowestCommonAncestor(root.left, p, q);
        TreeNode right = lowestCommonAncestor(root.right, p, q);

        if (left != null && right != null) return root;  // p,q 分别在左右子树
        return left != null ? left : right;               // 都在一边或没找到
    }
}
```

**复杂度**：时间 O(n)，空间 O(h)

> 💡 **追问**：
> 1. 如果树是 BST（LC 235）？ → 利用 BST 性质，根值在 p 和 q 之间即可判定
> 2. 如果要找多个节点的 LCA？ → 思路相同，计数匹配即可
> 3. 如果 p、q 不确定在树中？ → 需要先遍历确认节点存在

> ⚠️ **易错点**：
> 1. 后序遍历的返回值含义要明确：要么是 null（没找到），要么是找到的节点或 LCA
> 2. 递归终止条件 `root == p || root == q` 隐含了一个优化：如果 p 是 q 的祖先，直接返回 p

### 3.2 LC 124 二叉树中的最大路径和 ★★★

**题目描述**：二叉树中，路径被定义为节点序列（不一定经过根节点），路径和是路径上节点值的和。求最大路径和。

> LeetCode 123 道 hard 题之一，字节、美团高频题。

**核心思路**：后序遍历 + 全局最大值。对于每个节点，计算：
- 经过当前节点并可以向父节点贡献的最大单边路径和（用于递归）
- 经过当前节点的完整路径和（左 + 右 + 当前，用于更新全局最大值）

**完整Java代码**：

```java
class Solution {
    private int maxSum = Integer.MIN_VALUE;

    public int maxPathSum(TreeNode root) {
        maxGain(root);
        return maxSum;
    }

    // 返回从当前节点出发能往父节点贡献的最大单边路径和
    private int maxGain(TreeNode node) {
        if (node == null) return 0;

        // 递归计算左右子树的最大单边路径和（负数就舍弃，取 0）
        int leftGain = Math.max(0, maxGain(node.left));
        int rightGain = Math.max(0, maxGain(node.right));

        // 经过当前节点的完整路径和
        int currentPathSum = node.val + leftGain + rightGain;
        maxSum = Math.max(maxSum, currentPathSum);

        // 返回可以贡献给父节点的最大单边路径和
        return node.val + Math.max(leftGain, rightGain);
    }
}
```

**复杂度**：时间 O(n)，空间 O(h)

> 💡 **追问**：
> 1. 如果路径可以重复经过节点怎么办？ → 那就不是树的问题了，变成图
> 2. 如果节点值全是负数？ → `Math.max(0, ...)` 保证了即使负数也可不选，但 `maxSum` 初始为 `Integer.MIN_VALUE` 保证至少选一个节点

> ⚠️ **易错点**：
> 1. `maxSum` 初始化为 `Integer.MIN_VALUE` 而非 0，因为所有节点都可能为负
> 2. `maxGain` 返回值是单边贡献，不是完整路径和
> 3. 负值子树要剪掉：`Math.max(0, leftGain)` 而非直接取 leftGain

### 3.3 LC 437 路径总和 III ★★☆

**题目描述**：给定二叉树和目标值 targetSum，求路径和等于 targetSum 的路径数量。路径只能从上往下（父→子），不要求从根开始或到叶子结束。

**核心思路**：前缀和 + HashMap。在 DFS 遍历过程中维护当前路径的前缀和，用 HashMap 存储前缀和出现的次数。对于当前节点，查找 `当前前缀和 - targetSum` 出现过几次。

**完整Java代码**：

```java
class Solution {
    private int count = 0;

    public int pathSum(TreeNode root, int targetSum) {
        // 前缀和 → 出现次数
        Map<Long, Integer> prefixSumMap = new HashMap<>();
        prefixSumMap.put(0L, 1);  // 前缀和为 0 的有 1 个（空路径）
        dfs(root, 0L, targetSum, prefixSumMap);
        return count;
    }

    private void dfs(TreeNode node, long currentSum, int targetSum,
                     Map<Long, Integer> prefixSumMap) {
        if (node == null) return;

        currentSum += node.val;

        // 查找有多少个前缀和满足 currentSum - targetSum
        count += prefixSumMap.getOrDefault(currentSum - targetSum, 0);

        // 将当前前缀和加入 Map
        prefixSumMap.put(currentSum, prefixSumMap.getOrDefault(currentSum, 0) + 1);

        // 递归
        dfs(node.left, currentSum, targetSum, prefixSumMap);
        dfs(node.right, currentSum, targetSum, prefixSumMap);

        // 回溯：移除当前前缀和
        prefixSumMap.put(currentSum, prefixSumMap.get(currentSum) - 1);
    }
}
```

**复杂度**：时间 O(n)，空间 O(n)

> 💡 **追问**：
> 1. 如果必须从根节点开始呢？ → 简单递归，`rootSum + pathSum(left) + pathSum(right)`
> 2. 如果必须到叶子节点结束呢？ → 在 `count += ` 条件后加 `node.left == null && node.right == null` 判断

> ⚠️ **易错点**：
> 1. 前缀和可能很大，用 `long` 而非 `int`
> 2. 回溯时必须 `count--` 或移除 Map 中的计数
> 3. `prefixSumMap.put(0L, 1)` 是关键的哨兵值

### 3.4 LC 538 把二叉搜索树转换为累加树 ★★☆

**题目描述**：给定 BST，将其转换为累加树（Greater Tree），使每个节点的值等于原树中所有大于等于该节点值的节点值之和。

**核心思路**：反中序遍历。BST 的中序遍历是升序，反中序遍历（右→根→左）就是降序。在降序遍历过程中累加节点值即可。

**完整Java代码**：

```java
class Solution {
    private int sum = 0;

    public TreeNode convertBST(TreeNode root) {
        if (root == null) return null;

        // 先遍历右子树
        convertBST(root.right);

        // 处理当前节点
        sum += root.val;
        root.val = sum;

        // 再遍历左子树
        convertBST(root.left);

        return root;
    }
}
```

**复杂度**：时间 O(n)，空间 O(h)

> 💡 **追问**：如何用迭代（栈）实现反中序遍历？ → 类似中序迭代，但调换左右方向

> ⚠️ **易错点**：理解了反中序遍历的原理，代码就很简单。关键是要想到 "反中序" 这个思路。

### 4.1 LC 200 岛屿数量 ★★★

**题目描述**：二维网格地图，`'1'` 表示陆地，`'0'` 表示水，求岛屿数量（相连的 1 组成一个岛屿，上下左右四方向相连）。

**核心思路**：

| 方法 | 思路 | 空间 |
|------|------|------|
| DFS | 遇到陆地就 DFS 淹没整个岛屿 | O(m×n) 递归栈 |
| BFS | 遇到陆地就 BFS 遍历岛屿 | O(min(m,n)) 队列 |
| 并查集 | 将相邻的陆地 union，统计集合数 | O(m×n) |

**完整Java代码 — DFS（最简洁）**：

```java
class Solution {
    public int numIslands(char[][] grid) {
        int count = 0;
        for (int i = 0; i < grid.length; i++) {
            for (int j = 0; j < grid[0].length; j++) {
                if (grid[i][j] == '1') {
                    dfs(grid, i, j);
                    count++;
                }
            }
        }
        return count;
    }

    private void dfs(char[][] grid, int i, int j) {
        if (i < 0 || i >= grid.length || j < 0 || j >= grid[0].length
            || grid[i][j] == '0') {
            return;
        }
        grid[i][j] = '0';  // 淹没
        dfs(grid, i - 1, j);
        dfs(grid, i + 1, j);
        dfs(grid, i, j - 1);
        dfs(grid, i, j + 1);
    }
}
```

**完整Java代码 — 并查集**：

```java
class Solution {
    public int numIslands(char[][] grid) {
        int m = grid.length, n = grid[0].length;
        UnionFind uf = new UnionFind(grid);
        int[][] dirs = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == '1') {
                    for (int[] d : dirs) {
                        int ni = i + d[0], nj = j + d[1];
                        if (ni >= 0 && ni < m && nj >= 0 && nj < n
                            && grid[ni][nj] == '1') {
                            uf.union(i * n + j, ni * n + nj);
                        }
                    }
                }
            }
        }
        return uf.getCount();
    }

    class UnionFind {
        private int[] parent;
        private int count;

        public UnionFind(char[][] grid) {
            int m = grid.length, n = grid[0].length;
            parent = new int[m * n];
            count = 0;
            for (int i = 0; i < m; i++) {
                for (int j = 0; j < n; j++) {
                    if (grid[i][j] == '1') {
                        parent[i * n + j] = i * n + j;
                        count++;
                    }
                }
            }
        }

        public int find(int x) {
            if (parent[x] != x) {
                parent[x] = find(parent[x]);  // 路径压缩
            }
            return parent[x];
        }

        public void union(int x, int y) {
            int rootX = find(x), rootY = find(y);
            if (rootX != rootY) {
                parent[rootX] = rootY;
                count--;
            }
        }

        public int getCount() { return count; }
    }
}
```

**复杂度**：时间 O(m×n)，空间 O(m×n)

> 💡 **追问**：
> 1. 如果四方向改为八方向怎么改？ → 方向数组增加对角线
> 2. 岛屿的最大面积（LC 695）？ → 类似，DFS 返回面积
> 3. 统计封闭岛屿数量（LC 1254）？ → 排除边界相连的陆地

> ⚠️ **易错点**：
> 1. 网格中的字符是 `'1'` 和 `'0'`，不是数字 1 和 0！
> 2. DFS 淹没时一定要先修改 `grid[i][j] = '0'` 再递归，否则会无限递归
> 3. 并查集 1D 数组映射：`index = i * n + j`

### 4.2 LC 207 课程表（拓扑排序）★★★

**题目描述**：共有 n 门课程，给定先修关系 `[a, b]` 表示学 a 之前必须先学 b。判断是否能完成所有课程的学习。

**核心思路**：

| 方法 | 思路 | 特点 |
|------|------|------|
| BFS（Kahn 算法） | 统计入度，入度为 0 的入队 | 直观，得到拓扑序 |
| DFS 三色标记 | 0=未访问，1=访问中，2=已结束 | 检测环，空间略好 |

**完整Java代码 — BFS 入度法**：

```java
class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        // 建图 + 入度表
        List<List<Integer>> graph = new ArrayList<>();
        int[] inDegree = new int[numCourses];

        for (int i = 0; i < numCourses; i++) {
            graph.add(new ArrayList<>());
        }

        for (int[] pre : prerequisites) {
            int course = pre[0], prerequisite = pre[1];
            graph.get(prerequisite).add(course);  // 先修 → 后修
            inDegree[course]++;
        }

        // 入度为 0 的入队
        Queue<Integer> queue = new LinkedList<>();
        for (int i = 0; i < numCourses; i++) {
            if (inDegree[i] == 0) queue.offer(i);
        }

        // 拓扑排序
        int visited = 0;
        while (!queue.isEmpty()) {
            int cur = queue.poll();
            visited++;
            for (int next : graph.get(cur)) {
                inDegree[next]--;
                if (inDegree[next] == 0) queue.offer(next);
            }
        }

        return visited == numCourses;
    }
}
```

**完整Java代码 — DFS 三色标记**：

```java
class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < numCourses; i++) graph.add(new ArrayList<>());
        for (int[] pre : prerequisites) {
            graph.get(pre[1]).add(pre[0]);
        }

        int[] visited = new int[numCourses]; // 0=未访问, 1=访问中, 2=已结束

        for (int i = 0; i < numCourses; i++) {
            if (visited[i] == 0 && hasCycle(graph, visited, i)) {
                return false;
            }
        }
        return true;
    }

    private boolean hasCycle(List<List<Integer>> graph, int[] visited, int cur) {
        if (visited[cur] == 1) return true;  // 访问中 → 有环
        if (visited[cur] == 2) return false; // 已结束 → 无环

        visited[cur] = 1; // 标记访问中
        for (int next : graph.get(cur)) {
            if (hasCycle(graph, visited, next)) return true;
        }
        visited[cur] = 2; // 标记已结束
        return false;
    }
}
```

**复杂度**：时间 O(V+E)，空间 O(V+E)

> 💡 **追问**：
> 1. 如何输出拓扑排序结果（LC 210）？ → BFS 每次出队时添加到结果列表
> 2. 如果课程很多（100k 级别）用哪个方法？ → BFS 入度法更安全（DFS 递归栈可能溢出）

> ⚠️ **易错点**：
> 1. 建图时方向不要搞反：`prerequisite → course`
> 2. BFS 中 `inDegree[next]--` 后要检查是否为 0 再入队，每个节点只会入队一次
> 3. DFS 三色标记中，`visited[cur] == 1` 表示当前路径又回到自己 → 有环

### 4.3 LC 994 腐烂的橘子 ★★☆

**题目描述**：网格中 `0` 空单元格，`1` 新鲜橘子，`2` 腐烂橘子。每分钟腐烂橘子会让上下左右相邻的新鲜橘子腐烂，求全部腐烂所需分钟数。如果无法全部腐烂返回 -1。

**核心思路**：多源 BFS。所有初始腐烂橘子同时开始向外扩散，BFS 层数就是分钟数。

**完整Java代码**：

```java
class Solution {
    public int orangesRotting(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        Queue<int[]> queue = new LinkedList<>();
        int freshCount = 0;

        // 统计初始状态
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 2) {
                    queue.offer(new int[]{i, j});
                } else if (grid[i][j] == 1) {
                    freshCount++;
                }
            }
        }

        if (freshCount == 0) return 0; // 没有新鲜橘子

        int minutes = 0;
        int[][] dirs = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};

        while (!queue.isEmpty()) {
            int size = queue.size();
            boolean rotted = false;

            for (int i = 0; i < size; i++) {
                int[] cur = queue.poll();
                for (int[] d : dirs) {
                    int ni = cur[0] + d[0], nj = cur[1] + d[1];
                    if (ni >= 0 && ni < m && nj >= 0 && nj < n && grid[ni][nj] == 1) {
                        grid[ni][nj] = 2;
                        queue.offer(new int[]{ni, nj});
                        freshCount--;
                        rotted = true;
                    }
                }
            }

            if (rotted) minutes++;
        }

        return freshCount == 0 ? minutes : -1;
    }
}
```

**复杂度**：时间 O(m×n)，空间 O(m×n)

> 💡 **追问**：
> 1. 如果用 DFS 行吗？ → DFS 不适合这种 "同时扩散" 的场景，BFS 是自然的选择
> 2. 如何记录时间而不用分层 BFS？ → 可以在 queue 中存 `[i, j, time]`，用 `time + 1` 赋值给下一层

> ⚠️ **易错点**：
> 1. `freshCount` 必须在 BFS 过程中实时更新
> 2. BFS 结束后需要检查是否还有新鲜橘子（`freshCount > 0`）
> 3. 如果没有新鲜橘子直接返回 0，不要误返回 -1

### 4.4 LC 79 单词搜索 ★★☆

**题目描述**：二维网格中搜索单词，单词由相邻（上下左右）单元格的字母组成，同一个单元格不能重复使用。

**核心思路**：DFS + 回溯。遍历每个格子作为起点，DFS 匹配单词。已匹配的字符暂时标记为 `'#'` 防止重复使用，回溯时恢复。

**完整Java代码**：

```java
class Solution {
    public boolean exist(char[][] board, String word) {
        int m = board.length, n = board[0].length;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (dfs(board, word, i, j, 0)) return true;
            }
        }
        return false;
    }

    private boolean dfs(char[][] board, String word, int i, int j, int index) {
        if (index == word.length()) return true;           // 匹配完成
        if (i < 0 || i >= board.length || j < 0 || j >= board[0].length) return false;
        if (board[i][j] != word.charAt(index)) return false; // 不匹配

        // 标记已访问
        char temp = board[i][j];
        board[i][j] = '#';

        boolean found = dfs(board, word, i - 1, j, index + 1)
                     || dfs(board, word, i + 1, j, index + 1)
                     || dfs(board, word, i, j - 1, index + 1)
                     || dfs(board, word, i, j + 1, index + 1);

        // 回溯恢复
        board[i][j] = temp;
        return found;
    }
}
```

**复杂度**：时间 O(m×n×3^L)（每个方向三个选择，L 为单词长度），空间 O(L) 递归栈

> 💡 **追问**：
> 1. 数量级优化？ → 可以先用字符频率统计做剪枝（如果 board 中字符不够直接返回 false）
> 2. 优化搜索起点？ → 从 word 的首尾字符中选择出现较少的那个作为搜索起点

> ⚠️ **易错点**：
> 1. DFS 要回溯：将当前字符暂时替换为 `#`，但回溯后要恢复
> 2. `index == word.length()` 是成功条件，要在越界检查之前
> 3. 二维数组的行列索引不要搞混

### 5.1 二叉树核心模板


| 后序 | 先递归左右，再处理当前 | 树形 DP、LCA、最大路径和 |

**BFS 层序模板**：

```java
Queue<TreeNode> queue = new LinkedList<>();

    int size = queue.size();
    for (int i = 0; i < size; i++) {
        TreeNode node = queue.poll();
        // 处理节点
        if (node.left != null) queue.offer(node.left);
        if (node.right != null) queue.offer(node.right);
    }
}
```
