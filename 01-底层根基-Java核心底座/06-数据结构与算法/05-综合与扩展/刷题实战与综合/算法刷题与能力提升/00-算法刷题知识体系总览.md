## 4. Java 算法工具速查

| 工具 | 用法 |
|------|------|
| `Arrays.sort()` | 数组排序（快排/归并） |
| `Collections.sort()` | 集合排序 |
| `PriorityQueue` | 堆（默认小顶堆） |
| `ArrayDeque` | 栈/队列（比 Stack/LinkedList 快） |
| `TreeMap/TreeSet` | 有序集合（红黑树） |
| `HashSet/HashMap` | O(1) 查找 |
| `StringBuilder` | 字符串拼接（比 String + 快 100x） |

## 5. 复杂度速查

| 数据结构 | 查找 | 插入 | 删除 | 空间 |
|---------|:---:|:---:|:---:|:---:|
| 数组 | O(1) | O(n) | O(n) | O(n) |
| 链表 | O(n) | O(1) | O(1) | O(n) |
| 哈希表 | O(1) | O(1) | O(1) | O(n) |
| 二叉搜索树 | O(log n) | O(log n) | O(log n) | O(n) |
| 堆 | O(1)peek | O(log n) | O(log n) | O(n) |
