# 06 - 贪心与双指针

> 🎯 贪心 = 每一步选当前最优（不回溯），双指针 = 用两个指针的移动替代嵌套循环。这两种思路看似简单，但在正确场景下能将 O(n²) 降到 O(n)

## 1. 双指针全景

```java
// 类型 1：相向双指针（有序数组）
// 盛最多水的容器
public int maxArea(int[] height) {
    int left = 0, right = height.length - 1, max = 0;
    while (left < right) {
        int area = Math.min(height[left], height[right]) * (right - left);
        max = Math.max(max, area);
        if (height[left] < height[right]) left++;
        else right--;
    }
    return max;
}

// 类型 2：快慢指针（链表/数组去重）
// 移动零
public void moveZeroes(int[] nums) {
    int slow = 0;
    for (int fast = 0; fast < nums.length; fast++) {
        if (nums[fast] != 0) {
            int tmp = nums[slow]; nums[slow] = nums[fast]; nums[fast] = tmp;
            slow++;
        }
    }
}
```

## 2. 贪心经典题型

```java
// 跳跃游戏：每次选能跳最远的
public boolean canJump(int[] nums) {
    int maxReach = 0;
    for (int i = 0; i < nums.length; i++) {
        if (i > maxReach) return false;  // 当前位置不可达
        maxReach = Math.max(maxReach, i + nums[i]);
    }
    return true;
}

// 无重叠区间：按结束时间排序 + 贪心选最早结束的
public int eraseOverlapIntervals(int[][] intervals) {
    Arrays.sort(intervals, (a, b) -> a[1] - b[1]);  // 按结束时间排序
    int end = intervals[0][1], count = 0;
    for (int i = 1; i < intervals.length; i++) {
        if (intervals[i][0] < end) count++;  // 重叠 → 删除
        else end = intervals[i][1];
    }
    return count;
}
```

## 3. 滑动窗口模板

```java
// 滑动窗口统一模板
public int slidingWindow(String s) {
    Map<Character, Integer> window = new HashMap<>();
    int left = 0, right = 0, result = 0;

    while (right < s.length()) {
        char c = s.charAt(right);
        right++;                    // 1. 扩大窗口
        window.merge(c, 1, Integer::sum);

        while (窗口需要收缩) {       // 2. 收缩条件
            char d = s.charAt(left);
            left++;                 // 3. 缩小窗口
            window.merge(d, -1, Integer::sum);
        }
        result = Math.max(result, right - left);  // 4. 更新结果
    }
    return result;
}

// 无重复字符的最长子串
public int lengthOfLongestSubstring(String s) {
    Set<Character> seen = new HashSet<>();
    int left = 0, max = 0;
    for (int right = 0; right < s.length(); right++) {
        while (seen.contains(s.charAt(right))) {
            seen.remove(s.charAt(left++));
        }
        seen.add(s.charAt(right));
        max = Math.max(max, right - left + 1);
    }
    return max;
}
```

## 核心要点回顾

- 相向指针 = 有序数组 + 两步移动（谁小谁走）
- 快慢指针 = 数组原地修改 + 链表找中点/环
- 滑动窗口 = right 扩大 + while 收缩 + 更新结果
- 贪心证明 = "最优子结构"（全局最优 = 局部最优组合）
- 贪心误区 = 不是所有"看起来像贪心"的问题都能用贪心
