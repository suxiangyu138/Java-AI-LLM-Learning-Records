## 1. 递归三要素

```text
1. 终止条件（base case）：什么时候停止递归
2. 递推关系：大问题如何分解为子问题
3. 返回值：子问题的结果如何组合

示例：斐波那契
  base: f(0)=0, f(1)=1
  relation: f(n) = f(n-1) + f(n-2)
  return: 子问题之和
```

## 2. 回溯模板与题型

```java
// 回溯统一模板
void backtrack(路径, 选择列表) {
    if (满足终止条件) {
        result.add(new ArrayList<>(路径));
        return;
    }
    for (选择 in 选择列表) {
        做选择;
        backtrack(路径, 新的选择列表);
        撤销选择;   // ← 回溯的精髓
    }
}

// 全排列
public List<List<Integer>> permute(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    backtrack(res, new ArrayList<>(), nums, new boolean[nums.length]);
    return res;
}

private void backtrack(List<List<Integer>> res, List<Integer> path,
                       int[] nums, boolean[] used) {
    if (path.size() == nums.length) {
        res.add(new ArrayList<>(path));
        return;
    }
    for (int i = 0; i < nums.length; i++) {
        if (used[i]) continue;
        used[i] = true;          // 做选择
        path.add(nums[i]);
        backtrack(res, path, nums, used);
        path.removeLast();       // 撤销选择（Java 21+）
        used[i] = false;
    }
}
```

## 3. 动态规划五步法

```text
1. 定义 dp[i] 含义
2. 找递推公式（状态转移方程）
3. dp 数组如何初始化
4. 确定遍历顺序
5. 举例推导 dp 数组（debug 用）
```

```java
// 爬楼梯：dp[n] = dp[n-1] + dp[n-2]
public int climbStairs(int n) {
    if (n <= 2) return n;
    int[] dp = new int[n + 1];
    dp[1] = 1; dp[2] = 2;
    for (int i = 3; i <= n; i++) {
        dp[i] = dp[i - 1] + dp[i - 2];
    }
    return dp[n];
}

// 0-1 背包：dp[j] = max(dp[j], dp[j-w] + v)
public int knapsack(int[] weights, int[] values, int capacity) {
    int[] dp = new int[capacity + 1];
    for (int i = 0; i < weights.length; i++) {
        for (int j = capacity; j >= weights[i]; j--) {  // 倒序！
            dp[j] = Math.max(dp[j], dp[j - weights[i]] + values[i]);
        }
    }
    return dp[capacity];
}
```

## 核心要点回顾

- 递归三要素 = base + 递推 + 汇总
- 回溯 = 递归 + for 选择 + 做/撤选择
- DP 五步法 = 定义 → 递推 → 初始化 → 遍历 → 验证
- 0-1 背包必须倒序遍历（防止物品重复使用）
- 能用递归解的先想递归 → 加备忘录 = DP → 优化空间
