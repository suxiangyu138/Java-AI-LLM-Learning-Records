### 🏷️ 前缀和
| 维度 | 内容 |
|------|------|
| **定位** | pre[i] 预处理，区间和 O(1) 查询 |
| **模板题** | 303 区域和检索、560 和为 K 子数组、974 可被 K 整除 |
| **核心技巧** | `pre[j]-pre[i]` = 区间和；**前缀和+哈希**解决"和=K 计数" |

```
前缀和+哈希模板（560）：
Map<Integer, Integer> prefixCount = new HashMap<>();
prefixCount.put(0, 1);                       // ⚠️ 空前缀
for (int x : nums) {
    sum += x;
    count += prefixCount.getOrDefault(sum - k, 0);
    prefixCount.put(sum, prefixCount.getOrDefault(sum, 0) + 1);
}
应用：和为 K 计数、可被 K 整除（mod K）、矩阵子矩阵和
```

```
数据流中位数（295）双堆模板：

复杂度：插入 O(log n)，取中位数 O(1)
```

## 3. 学习优先级建议

### 🟢 第一梯队（面试核心，2-3 周）
```
双指针 → 滑动窗口 → 前缀和 → 位运算 → 排序（快排/归并/堆排）
```

### 🟡 第二梯队（高频加分，1-2 周）
```
位掩码（状态压缩）→ 计数（TopK）→ 数据流（双堆）→ 快速选择
```

### 🔴 第三梯队（理论储备）
```
计数排序 → 桶排序 → 基数排序
（了解原理与适用场景即可，手撕优先级低）
```

### 技巧选型总览

```
连续子串 → 滑动窗口
有序数组 → 双指针/二分
区间和 → 前缀和
集合状态 → 位掩码
找落单 → 位运算
TopK → 堆/快速选择/计数
在线数据 → 堆/数据流
```

> 🎯 **核心要点**：数组技巧标签是面试效率优化主战场——**双指针/滑窗/前缀和/位运算**是 Hot 100 最高频的四个技巧。排序标签抓住**快排/归并/堆排手撕三件套** + 复杂度速查表即可。技巧选型口诀："连续子串→滑窗、区间和→前缀和、TopK→堆、找落单→异或"——30 秒定位题型。
