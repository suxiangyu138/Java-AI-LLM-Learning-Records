## 2. 采样类（2 个）

### 🏷️ 水塘抽样
| 维度 | 内容 |
|------|------|
| **定位** | 流式数据等概率采样（不知总量） |
| **模板题** | 382 链表随机节点、398 随机数索引 |
| **核心技巧** | 第 i 个元素以 1/i 概率替换当前候选 |

```
水塘抽样核心（O(n) 时间 O(1) 空间）：
Random random = new Random();
int result = 0, count = 0;
while (stream.hasNext()) {
    int x = stream.next();
    count++;
    if (random.nextInt(count) == 0) result = x;   // 1/count 概率替换
}
// 数学保证：每个元素最终被选中的概率都是 1/n
```

### 🏷️ 拒绝采样
| 维度 | 内容 |
|------|------|
| **定位** | 通过"接受/拒绝"生成目标分布 |
| **模板题** | 470 用 Rand7 实现 Rand10、478 圆内随机点 |
| **核心技巧** | 生成均匀候选 → 不满足条件则拒绝重试（期望常数次） |

```
拒绝采样核心（470）：
int rand10() {
    while (true) {
        int x = (rand7()-1) * 7 + rand7();   // 1-49 均匀
        if (x <= 40) return x % 10 + 1;      // 接受（40/49 概率）
        // 否则拒绝重试（期望 ~1.2 次）
    }
}
```

## 4. 学习优先级建议

### 🟢 第一梯队（面试高频）
```
设计（LRU/最小栈/O(1) 随机）→ 多线程基础（交替打印）
```

### 🟡 第二梯队（加分储备）
```
水塘抽样 → 拒绝采样（概率技巧）
```

### 🔴 第三梯队（岗位相关）
```
数据库（后端岗）→ Shell（运维/DevOps 岗）→ 交互（偏竞赛）
```

> 🎯 **核心要点**：其他专项标签按岗位取舍——**设计题**是全员必考（LRU 最高频），**多线程/数据库**看岗位方向，**采样类**是概率技巧加分项。设计题掌握"识别结构+联动维护"套路，采样类背熟水塘抽样和拒绝采样两个模板即可。
