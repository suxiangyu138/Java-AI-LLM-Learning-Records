## 3. 学习路线推荐

### 🟢 基础期（4-6 周）：打牢地基
```
数组 → 字符串 → 哈希表 → 双指针 → 滑动窗口
→ 链表 → 栈/队列 → 二叉树 → DFS/BFS
→ 排序 → 二分查找
```
**目标**：11 个基础标签的模板题全部掌握

### 🟡 核心期（4-6 周）：面试主力
```
动态规划 → 回溯 → 贪心 → 位运算 → 前缀和
→ 堆/优先队列 → 单调栈 → 并查集 → 图遍历
```
**目标**：算法思想类标签的经典题型吃透

### 🔴 进阶期（4-6 周）：拉分项
```
树状数组/线段树 → 字典树 → 最短路 → 拓扑排序
→ 最小生成树 → 状态压缩 DP → 数论 → 字符串匹配
```
**目标**：竞赛级标签入门，Hard 题可解

## 5. 标签关联速查

### 高频组合标签

```
数组 + 哈希表 + 双指针        → Hot 100 基础三件套
树 + DFS/BFS + 递归           → 树遍历/路径问题
动态规划 + 记忆化 + 递归       → DP 三形态
图 + BFS + 拓扑排序           → 课程表系列
字符串 + 滑动窗口 + 哈希表     → 子串问题
堆 + 数据流 + 快速选择         → TopK 问题
位运算 + 位掩码 + 动态规划     → 状态压缩 DP
排序 + 分治 + 快速选择         → 排序算法族
```

### 标签粒度说明

```
粗粒度标签（数组/字符串/数学）：题量大、综合性强
细粒度标签（字典树/单调栈/扫描线）：套路固定、易掌握
建议：粗粒度靠"题型模式"刷，细粒度靠"模板"刷
```
