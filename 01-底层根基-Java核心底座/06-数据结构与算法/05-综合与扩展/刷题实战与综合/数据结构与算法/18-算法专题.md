## 一、多项式与快速傅里叶变换

> FFT 将多项式乘法从 `O(n^2)` 降至 `O(n log n)`，在大数据处理、加密算法、分布式计算等场景中是可落地的核心技术。

### 1.1 多项式表示与后端选型

设 n 次多项式 `A(x) = a_0 + a_1 x + ... + a_{n-1} x^{n-1}`：

| 表示方法 | 定义 | 加法复杂度 | 乘法复杂度 |
|---------|------|-----------|-----------|
| **系数表示** | 系数数组 `[a_0, a_1, ..., a_{n-1}]` | `O(n)` | `O(n^2)` |
| **点值表示** | 点集 `{(x_0, A(x_0)), ..., (x_{n-1}, A(x_{n-1}))}` | `O(n)` | `O(n)` |

> FFT 的核心价值是解决系数与点值之间的转换效率问题，让转换复杂度降至 `O(n log n)`。

**系数表示（适合小规模、高频修改场景）**：采用链表 + 自定义节点存储稀疏系数，避免无效内存占用。

```java
class PolynomialNode {
    double coefficient;
    int exponent;
    PolynomialNode next;
    // 构造、getter/setter 略
}

class SparsePolynomial {
    PolynomialNode head = new PolynomialNode(0, -1);

    void insertTerm(double coeff, int exp) {
        // 合并同类项逻辑
    }

    SparsePolynomial multiply(SparsePolynomial other) {
        SparsePolynomial result = new SparsePolynomial();
        // 传统 O(n^2) 乘法，适合 n < 1000
        return result;
    }
}
```

**点值表示（适合大规模、高频乘法场景）**：采用数组存储点值对，数据量大时可用 Java NIO 直接内存避免堆溢出。注意 n 必须满足 `n >= 两个多项式次数之和 + 1`（定理 30.1），且通常取 2 的幂为 FFT 做准备。

### 1.2 FFT 核心原理

FFT 利用单位复数根的性质，将多项式求值分治为两个规模减半的子问题：

```
A(x) = A_even(x^2) + x * A_odd(x^2)
omega_n^(k+n/2) = -omega_n^k      // 折半引理
```

递归拆解至规模为 1，回溯合并得到 n 个点值（DFT）；逆变换（IDFT）取共轭后归一化即可。

> 后端开发重点：分治逻辑的代码实现、复数运算封装、迭代优化（避免递归栈溢出）。

### 1.3 Java 实现 FFT

#### 复数类

```java
public class Complex {
    private final double re, im;

    public Complex(double re, double im) { this.re = re; this.im = im; }
    public Complex add(Complex o) { return new Complex(re + o.re, im + o.im); }
    public Complex sub(Complex o) { return new Complex(re - o.re, im - o.im); }
    public Complex mul(Complex o) {
        return new Complex(re * o.re - im * o.im, re * o.im + im * o.re);
    }
    public Complex conj() { return new Complex(re, -im); }
    public double abs() { return Math.hypot(re, im); }
    public double getRe() { return re; }
    public double getIm() { return im; }
}
```

#### 递归版 FFT（易理解，适合调试）

```java
public static Complex[] fftRecursive(Complex[] a) {
    int n = a.length;
    if (n == 1) return new Complex[]{a[0]};

    Complex[] aEven = new Complex[n / 2];
    Complex[] aOdd = new Complex[n / 2];
    for (int i = 0; i < n / 2; i++) {
        aEven[i] = a[2 * i];
        aOdd[i] = a[2 * i + 1];
    }
    Complex[] yEven = fftRecursive(aEven);
    Complex[] yOdd = fftRecursive(aOdd);

    Complex[] y = new Complex[n];
    for (int k = 0; k < n / 2; k++) {
        Complex omega = new Complex(Math.cos(2 * Math.PI * k / n), Math.sin(2 * Math.PI * k / n));
        Complex t = omega.mul(yOdd[k]);
        y[k] = yEven[k].add(t);
        y[k + n / 2] = yEven[k].sub(t);
    }
    return y;
}
```

#### 迭代版 FFT（高性能，适合生产环境）

通过位反转置换避免递归栈开销，再逐层蝶形运算合并。

```java
public static Complex[] fftIterative(Complex[] a) {
    int n = a.length;
    bitReverse(a);
    for (int len = 2; len <= n; len <<= 1) {
        for (int i = 0; i < n; i += len) {
            for (int k = 0; k < len / 2; k++) {
                Complex omega = new Complex(Math.cos(2 * Math.PI * k / len), Math.sin(2 * Math.PI * k / len));
                Complex t = omega.mul(a[i + k + len / 2]);
                Complex u = a[i + k];
                a[i + k] = u.add(t);
                a[i + k + len / 2] = u.sub(t);
            }
        }
    }
    return a;
}

private static void bitReverse(Complex[] a) {
    int n = a.length;
    for (int i = 1, j = 0; i < n; i++) {
        int bit = n >> 1;
        while ((j & bit) != 0) { j ^= bit; bit >>= 1; }
        j ^= bit;
        if (i < j) { Complex t = a[i]; a[i] = a[j]; a[j] = t; }
    }
}
```

#### IDFT 实现

IDFT 与 FFT 高度相似，取共轭后调用 FFT 再归一化即可：

```java
public static Complex[] ifft(Complex[] y) {
    int n = y.length;
    Complex[] conjY = new Complex[n];
    for (int i = 0; i < n; i++) conjY[i] = y[i].conj();
    Complex[] a = fftIterative(conjY);
    for (int i = 0; i < n; i++) a[i] = new Complex(a[i].getRe() / n, a[i].getIm() / n);
    return a;
}
```

#### 多项式乘法完整实现

```java
public class FftPolynomialMultiplier {
    private static int nextPowerOfTwo(int n) {
        int power = 1;
        while (power < n) power <<= 1;
        return power;
    }

    public static double[] multiply(double[] a, double[] b) {
        int lenA = a.length, lenB = b.length, n = nextPowerOfTwo(lenA + lenB - 1);

        Complex[] ca = new Complex[n], cb = new Complex[n];
        for (int i = 0; i < n; i++) {
            ca[i] = i < lenA ? new Complex(a[i], 0) : new Complex(0, 0);
            cb[i] = i < lenB ? new Complex(b[i], 0) : new Complex(0, 0);
        }

        Complex[] ya = fftIterative(ca);
        Complex[] yb = fftIterative(cb);
        Complex[] yc = new Complex[n];
        for (int i = 0; i < n; i++) yc[i] = ya[i].mul(yb[i]);

        Complex[] cc = ifft(yc);
        double[] result = new double[lenA + lenB - 1];
        for (int i = 0; i < result.length; i++) result[i] = Math.round(cc[i].getRe() * 100) / 100.0;
        return result;
    }
}
```

### 1.4 工程化优化

| 维度 | 方案 |
|------|------|
| **精度** | 四舍五入保留 2 位小数；设置误差阈值 `<1e-6` 视为 0；预计算单位复数根并缓存 |
| **性能** | 优先迭代版；大规模数据用多线程并行蝶形运算；使用 JTransforms/FFT4J 等成熟库 |
| **内存** | 大数组用 `DirectByteBuffer` 直接内存，避免 JVM 堆溢出 |

| 适合场景 | 不适合场景 |
|---------|-----------|
| 大数据量多项式乘法（分布式分片运算） | n < 1000 的小规模乘法（传统 O(n^2) 开销更低） |
| 信号处理中的卷积运算 | 系数频繁修改的场景 |
| 加密算法中的多项式运算（RSA 大数乘法、椭圆曲线） | — |

### 1.5 后端典型应用

**卷积运算**：通过系数反转将卷积转为多项式乘法（定理 30.2）。

```java
public class ConvolutionUtil {
    public static double[] convolution(double[] a, double[] b) {
        double[] revB = new double[b.length];
        for (int i = 0; i < b.length; i++) revB[i] = b[b.length - 1 - i];
        return FftPolynomialMultiplier.multiply(a, revB);
    }
}
```

**加密辅助**：RSA 大数乘法、椭圆曲线加密中，FFT 可显著提升大规模数据加密/解密效率。

**分布式分片**：将多项式拆分为多个分片，各节点独立执行 FFT，点值相乘后汇总执行 IDFT。

#### 基础篇（第 1-5 章）

**核心：** 算法基础、复杂度分析、分治法、递归式求解
**后端应用：** ArrayList 扩容评估、HashMap 重哈希分析、分库分表、归并排序（JDK 对象类型排序底层）

```java
// 归并排序（分治法）
public class MergeSort {
    public void sort(int[] arr, int[] temp, int left, int right) {
        if (left >= right) return;
        int mid = left + (right - left) / 2;
        sort(arr, temp, left, mid);
        sort(arr, temp, mid + 1, right);
        merge(arr, temp, left, mid, right);
    }

    private void merge(int[] arr, int[] temp, int left, int mid, int right) {
        int i = left, j = mid + 1, k = left;
        while (i <= mid && j <= right) temp[k++] = arr[i] <= arr[j] ? arr[i++] : arr[j++];
        while (i <= mid) temp[k++] = arr[i++];
        while (j <= right) temp[k++] = arr[j++];
        System.arraycopy(temp, left, arr, left, k - left);
    }
}
```

#### 排序与顺序统计（第 6-9 章）

**核心：** 堆排序、快排、线性时间排序（计数/桶/基数）、TopK
**后端应用：** `Arrays.sort`（双轴快排 + 归并排序）、外部排序、`PriorityQueue` 实现 TopK

```java
// 堆排序解决 TopK（PriorityQueue 底层）
public class TopK {
    public int findKthLargest(int[] nums, int k) {
        PriorityQueue<Integer> heap = new PriorityQueue<>();
        for (int num : nums) { heap.add(num); if (heap.size() > k) heap.poll(); }
        return heap.peek();
    }
}
```

#### 高级数据结构（第 10-14 章）

**核心：** 链表、栈、队列、BST、红黑树、散列表、并查集
**后端应用：** `TreeMap`/`TreeSet`（红黑树）、`HashMap`/`ConcurrentHashMap`（散列表）、并查集（网络连通性）

```java
// 并查集（路径压缩 + 按秩合并，均摊 O(alpha(n))）
public class DSU {
    private int[] parent, rank;
    public DSU(int n) {
        parent = new int[n]; rank = new int[n];
        for (int i = 0; i < n; i++) { parent[i] = i; rank[i] = 1; }
    }
    public int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }
    public void union(int x, int y) {
        int fx = find(x), fy = find(y);
        if (fx == fy) return;
        if (rank[fx] > rank[fy]) parent[fy] = fx;
        else { parent[fx] = fy; if (rank[fx] == rank[fy]) rank[fy]++; }
    }
    public boolean isConnected(int x, int y) { return find(x) == find(y); }
}
```

#### 动态规划与贪心（第 15-16 章）

**核心：** DP（重叠子问题、最优子结构）、贪心（局部最优 -> 全局最优）
**后端应用：** 缓存策略、资源调度、文本相似度（LCS）、任务调度、负载均衡

```java
// 最长公共子序列（LCS）
public class LCS {
    public int longestCommonSubsequence(String s1, String s2) {
        int m = s1.length(), n = s2.length();
        int[][] dp = new int[m + 1][n + 1];
        for (int i = 1; i <= m; i++)
            for (int j = 1; j <= n; j++)
                dp[i][j] = s1.charAt(i - 1) == s2.charAt(j - 1)
                    ? dp[i - 1][j - 1] + 1
                    : Math.max(dp[i - 1][j], dp[i][j - 1]);
        return dp[m][n];
    }
}
```

#### 摊还分析（第 17 章）

**核心：** 聚合分析、记账法、势能法、均摊复杂度
**后端应用：** ArrayList 扩容（摊还 O(1)）、HashMap 重哈希（摊还 O(1)）、LRU 缓存

```java
// LRU 缓存（LinkedHashMap，摊还 O(1)）
public class LRUCache {
    private final int capacity;
    private final LinkedHashMap<Integer, Integer> cache;

    public LRUCache(int capacity) {
        this.capacity = capacity;
        this.cache = new LinkedHashMap<>(capacity, 0.75f, true) {
            protected boolean removeEldestEntry(Map.Entry<Integer, Integer> e) {
                return size() > capacity;
            }
        };
    }
    public int get(int key) { return cache.getOrDefault(key, -1); }
    public void put(int key, int value) { cache.put(key, value); }
}
```

#### 图算法（第 22-26 章）

**核心：** DFS/BFS、拓扑排序、最短路径（Dijkstra/Bellman-Ford/Floyd）、MST（Kruskal/Prim）
**后端应用：** 网络路由、任务调度、集群拓扑优化、社区发现

```java
// 拓扑排序（Kahn 算法）
public class TopologicalSort {
    public List<Integer> sort(int n, List<List<Integer>> adj) {
        int[] inDegree = new int[n];
        for (int i = 0; i < n; i++) for (int neighbor : adj.get(i)) inDegree[neighbor]++;
        Queue<Integer> q = new LinkedList<>();
        for (int i = 0; i < n; i++) if (inDegree[i] == 0) q.offer(i);

        List<Integer> res = new ArrayList<>();
        while (!q.isEmpty()) {
            int cur = q.poll();
            res.add(cur);
            for (int neighbor : adj.get(cur))
                if (--inDegree[neighbor] == 0) q.offer(neighbor);
        }
        return res.size() == n ? res : new ArrayList<>();
    }
}
```

### 3.3 实战结合建议

1. **每学一个算法，对应 Java 集合类底层实现**：堆排序 -> `PriorityQueue`；红黑树 -> `TreeMap`/`TreeSet`；哈希表 -> `HashMap`/`ConcurrentHashMap`
2. **LeetCode 刷题巩固**：重点刷 DP、图论、排序类，每道题分析复杂度并思考后端场景
3. **项目落地**：并查集做连通性检测、LRU 缓存优化热点数据、拓扑排序实现编排引擎、FFT 优化大数据量运算
4. **渐进式节奏**：前期（1-2 月）基础 + 数据结构入门题；中期（2-4 月）DP + 图算法中等题；后期（4-6 月）摊还分析 + FFT + 系统设计

> 学习《算法导论》的策略应当是"理论 + 实战 + 面试"三位一体：理论构建底层认知，实战验证算法价值，面试检验学习成果。对于 Java 后端开发者，核心是将理论算法转化为可落地的代码，结合业务场景取舍优化，让算法真正为业务赋能——这将是成为高级后端工程师的必备素养。
