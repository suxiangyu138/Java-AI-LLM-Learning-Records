## 第一部分：贪心算法

## 1. 贪心核心思想

### 1.1 定义

**每一步做当前看起来最优的选择**，期望最终达到全局最优。

```java
// 贪心算法的通用框架
Result greedy(Problem p) {
    init result;
    while (未达到终止条件) {
        选择当前最优的决策;
        if (选择合法) 加入结果;
    }
    return result;
}
```

### 1.2 贪心选择性

**局部最优能推出全局最优**——这是贪心算法能正确工作的前提条件。

证明方法：
- **数学归纳法**：证明在每一步贪心选择后，剩余问题仍然是同构的子问题
- **交换论证法**：证明任意最优解都可以转化为贪心解而不降低质量

> ⚠️ **贪心不保证所有问题都正确**——必须能用数学证明贪心选择性成立。如 0-1 背包不能用贪心（部分背包可以）。

### 1.3 与 DP 的区别

| 维度 | 贪心 | DP |
|------|------|-----|
| **决策方式** | 每一步只做一个选择 | 考虑所有子问题的解 |
| **依赖关系** | 当前选择不影响后续子问题 | 子问题之间有重叠依赖 |
| **正确性** | 需证明贪心选择性 | 基于最优子结构，天然正确 |
| **效率** | 通常 O(n) 或 O(n log n) | 通常 O(n²) 或更高 |
| **典型标志** | "每次选最大的/最小的/最早的" | "求最大值/最小值/最少步数" |

---

## 2. 贪心与 DP 的辨识

| 问题 | 贪心能否解决 | 原因 |
|------|------------|------|
| 部分背包（可切割） | 能 | 每次拿单价最高的即可 |
| 0-1 背包（不可切割） | **不能** | 贪心选单价最高可能导致空间浪费 |
| 活动安排（区间调度） | 能 | 按结束时间最早选有最优子结构 |
| 找零钱（人民币 1-5-10-20-50-100） | 能 | 面额满足贪心选择性 |
| 找零钱（自定义面额 1-3-4） | **不能** | 如找 6 元，贪心 4+1+1（3枚），最优 3+3（2枚） |

> 💡 **关键判断**：子问题之间是否有依赖/冲突？有则用 DP，无则可考虑贪心。

## 3. 经典贪心问题

### 3.1 活动安排 / 区间调度

按结束时间排序，每次选最早结束的。

```java
public int activitySelection(int[][] intervals) {
    // 按结束时间排序
    Arrays.sort(intervals, (a, b) -> a[1] - b[1]);
    int count = 1;
    int lastEnd = intervals[0][1];
    for (int i = 1; i < intervals.length; i++) {
        if (intervals[i][0] >= lastEnd) { // 不重叠
            count++;
            lastEnd = intervals[i][1];
        }
    }
    return count;
}
```

**变体应用**：
- 无重叠区间（#435）：求移除最少区间使剩余互不重叠 = 总区间数 - 最大不重叠区间数
- 用最少数量的箭引爆气球（#452）：同样的区间排序 + 贪心思路

### 3.2 哈夫曼编码

每次取两棵权值最小的树合并——用最小堆实现。

```java
public HuffmanNode buildHuffmanTree(int[] weights) {
    PriorityQueue<HuffmanNode> pq = new PriorityQueue<>(
        (a, b) -> a.weight - b.weight);
    for (int w : weights) pq.offer(new HuffmanNode(w));
    while (pq.size() > 1) {
        HuffmanNode left = pq.poll();
        HuffmanNode right = pq.poll();
        HuffmanNode parent = new HuffmanNode(left.weight + right.weight);
        parent.left = left;
        parent.right = right;
        pq.offer(parent);
    }
    return pq.poll();
}
```

### 3.3 找零钱问题

人民币面额（1-5-10-20-50-100）满足贪心选择性。

```java
public int coinChangeGreedy(int[] coins, int amount) {
    // coins 必须满足贪心选择性（如人民币面额）
    Arrays.sort(coins);
    int count = 0;
    for (int i = coins.length - 1; i >= 0 && amount > 0; i--) {
        count += amount / coins[i];
        amount %= coins[i];
    }
    return amount == 0 ? count : -1;
}
```

### 3.4 跳跃游戏（#55）

```java
public boolean canJump(int[] nums) {
    int maxReach = 0; // 能到达的最远位置
    for (int i = 0; i <= maxReach; i++) {
        maxReach = Math.max(maxReach, i + nums[i]);
        if (maxReach >= nums.length - 1) return true;
    }
    return false;
}
```

- 贪心点：每一步记录能到达的最远位置，取最大值

### 3.5 部分背包

```java
// 部分背包——物品可切分，每次拿单价最高的
class Item {
    int weight, value;
    double ratio() { return (double) value / weight; }
}

public double fractionalKnapsack(Item[] items, int capacity) {
    Arrays.sort(items, (a, b) -> Double.compare(b.ratio(), a.ratio()));
    double totalValue = 0;
    for (Item item : items) {
        if (capacity >= item.weight) {
            totalValue += item.value;
            capacity -= item.weight;
        } else {
            totalValue += item.ratio() * capacity;
            break;
        }
    }
    return totalValue;
}
```

## 第二部分：回溯算法

## 4. 回溯核心思想

### 4.1 定义

**DFS + 状态重置** = 回溯——穷举（或剪枝后穷举）所有解。

- **解空间树**：每个决策是一个分支，回溯就是在这棵树上做 DFS
- **核心三步模板**：
  1. 做选择
  2. 递归进入下一层
  3. 撤销选择（状态重置）

### 4.2 回溯通用模板

```java
public void backtrack(路径, 选择列表) {
    if (满足终止条件) {
        记录结果;
        return;
    }
    for (选择 : 选择列表) {
        做选择;
        backtrack(新路径, 新选择列表);
        撤销选择; // 状态重置
    }
}
```

> 💡 **回溯 = DFS + 剪枝**。不加剪枝的回溯是穷举，加上剪枝才能高效。

## 5. 回溯三大母题（子集、组合、排列）

### 5.1 子集（#78）——每个元素选/不选

```java
public List<List<Integer>> subsets(int[] nums) {
    List<List<Integer>> result = new ArrayList<>();
    backtrackSubset(nums, 0, new ArrayList<>(), result);
    return result;
}

private void backtrackSubset(int[] nums, int start, List<Integer> path, List<List<Integer>> result) {
    result.add(new ArrayList<>(path)); // 记录当前路径
    for (int i = start; i < nums.length; i++) {
        path.add(nums[i]);
        backtrackSubset(nums, i + 1, path, result); // 不回头
        path.remove(path.size() - 1);
    }
}
```

**时间复杂度**：O(2ⁿ)

### 5.2 组合（#77）——从 n 选 k

```java
public List<List<Integer>> combine(int n, int k) {
    List<List<Integer>> result = new ArrayList<>();
    backtrackCombine(n, k, 1, new ArrayList<>(), result);
    return result;
}

private void backtrackCombine(int n, int k, int start, List<Integer> path, List<List<Integer>> result) {
    if (path.size() == k) {
        result.add(new ArrayList<>(path));
        return;
    }
    // 剪枝：剩余可选数 < 需要填充数时提前终止
    for (int i = start; i <= n - (k - path.size()) + 1; i++) {
        path.add(i);
        backtrackCombine(n, k, i + 1, path, result);
        path.remove(path.size() - 1);
    }
}
```

**时间复杂度**：O(C(n, k))

### 5.3 排列（#46）——全排列

```java
public List<List<Integer>> permute(int[] nums) {
    List<List<Integer>> result = new ArrayList<>();
    boolean[] used = new boolean[nums.length];
    backtrackPermute(nums, used, new ArrayList<>(), result);
    return result;
}

private void backtrackPermute(int[] nums, boolean[] used, List<Integer> path, List<List<Integer>> result) {
    if (path.size() == nums.length) {
        result.add(new ArrayList<>(path));
        return;
    }
    for (int i = 0; i < nums.length; i++) {
        if (used[i]) continue;
        used[i] = true;
        path.add(nums[i]);
        backtrackPermute(nums, used, path, result);
        path.remove(path.size() - 1);
        used[i] = false;
    }
}
```

**时间复杂度**：O(n!)

### 5.4 三大母题对比

| 问题 | 是否用 `start` 参数 | 是否用 `visited` 数组 | 时间复杂度 | 关键区别 |
|------|-------------------|---------------------|-----------|---------|
| 子集 | 是（避免回头） | 否 | O(2ⁿ) | 每个结点都记录结果 |
| 组合 | 是（避免回头） | 否 | O(C(n,k)) | 只记录长度 = k 的路径 |
| 排列 | 否（每个元素都可选） | 是（避免重复选） | O(n!) | 所有元素都用上 |

> 🎯 **这三个模板是所有回溯题的母题**，必须能手写。其余回溯题基本是在此基础上增加约束条件。

## 6. 经典回溯问题

### 6.1 N 皇后（#51）

```java
public List<List<String>> solveNQueens(int n) {
    List<List<String>> result = new ArrayList<>();
    char[][] board = new char[n][n];
    for (char[] row : board) Arrays.fill(row, '.');
    backtrackNQueens(board, 0, result);
    return result;
}

private void backtrackNQueens(char[][] board, int row, List<List<String>> result) {
    if (row == board.length) {
        result.add(construct(board));
        return;
    }
    for (int col = 0; col < board.length; col++) {
        if (isValid(board, row, col)) {
            board[row][col] = 'Q';
            backtrackNQueens(board, row + 1, result);
            board[row][col] = '.';
        }
    }
}

private boolean isValid(char[][] board, int row, int col) {
    // 检查列
    for (int i = 0; i < row; i++) {
        if (board[i][col] == 'Q') return false;
    }
    // 检查左上对角线
    for (int i = row - 1, j = col - 1; i >= 0 && j >= 0; i--, j--) {
        if (board[i][j] == 'Q') return false;
    }
    // 检查右上对角线
    for (int i = row - 1, j = col + 1; i >= 0 && j < board.length; i--, j++) {
        if (board[i][j] == 'Q') return false;
    }
    return true;
}
```

### 6.2 数独求解器（#37）

```java
public void solveSudoku(char[][] board) {
    solve(board);
}

private boolean solve(char[][] board) {
    for (int i = 0; i < 9; i++) {
        for (int j = 0; j < 9; j++) {
            if (board[i][j] != '.') continue;
            for (char c = '1'; c <= '9'; c++) {
                if (isValidSudoku(board, i, j, c)) {
                    board[i][j] = c;
                    if (solve(board)) return true;
                    board[i][j] = '.'; // 回溯
                }
            }
            return false; // 1-9 都不可填
        }
    }
    return true; // 所有格子填满
}
```

### 6.3 括号生成（#22）

```java
public List<String> generateParenthesis(int n) {
    List<String> result = new ArrayList<>();
    backtrack(n, n, new StringBuilder(), result);
    return result;
}

private void backtrack(int left, int right, StringBuilder sb, List<String> result) {
    if (left == 0 && right == 0) {
        result.add(sb.toString());
        return;
    }
    // 剪枝：剩余右括号必须 ≥ 左括号
    if (left > 0) {
        sb.append('(');
        backtrack(left - 1, right, sb, result);
        sb.deleteCharAt(sb.length() - 1);
    }
    if (right > left) {
        sb.append(')');
        backtrack(left, right - 1, sb, result);
        sb.deleteCharAt(sb.length() - 1);
    }
}
```

> 💡 **括号生成的剪枝条件**：`right > left` 确保已使用的右括号不超过左括号，保证序列合法。

## 7. 剪枝优化

### 7.1 剪枝类型对比

| 剪枝类型 | 含义 | 示例 |
|---------|------|------|
| **可行性剪枝** | 当前路径不可能产生合法解，直接返回 | N 皇后冲突检查 |
| **最优性剪枝** | 当前已比已知最优解差，放弃搜索 | 旅行商问题中路径长度已超最优 |
| **排序预处理** | 先排序使相同元素相邻，跳过重复 | 组合总和 II 中去重 |
| **记忆化搜索** | 中间状态保存，遇到重复直接查表 | 斐波那契、DP 自顶向下 |

### 7.2 去重剪枝示例（组合总和 II #40）

```java
public List<List<Integer>> combinationSum2(int[] candidates, int target) {
    List<List<Integer>> result = new ArrayList<>();
    Arrays.sort(candidates); // 排序使相同元素相邻
    backtrack(candidates, target, 0, new ArrayList<>(), result);
    return result;
}

private void backtrack(int[] nums, int remain, int start, List<Integer> path, List<List<Integer>> result) {
    if (remain == 0) {
        result.add(new ArrayList<>(path));
        return;
    }
    for (int i = start; i < nums.length; i++) {
        if (nums[i] > remain) break; // 可行性剪枝
        if (i > start && nums[i] == nums[i - 1]) continue; // 去重剪枝
        path.add(nums[i]);
        backtrack(nums, remain - nums[i], i + 1, path, result);
        path.remove(path.size() - 1);
    }
}
```

> 🎯 **剪枝是回溯的核心优化**——不加剪枝大部分回溯题会超时。排序预处理 + 可行性剪枝是最常用的组合。

## 8. 分支限界法

| 对比维度 | 回溯（Backtracking） | 分支限界（Branch & Bound） |
|---------|-------------------|--------------------------|
| **搜索方式** | DFS（深度优先） | BFS（广度优先）或优先队列 |
| **目标** | 寻找所有解 / 存在性判断 | 通常求最优解 |
| **结点管理** | 栈（递归） | 队列 / 优先队列 |
| **剪枝依据** | 约束条件 | 限界函数（下界/上界） |
| **经典问题** | N 皇后、子集、排列 | 旅行商（TSP）、任务分配 |

## 10. 学习建议

1. **回溯题重点在剪枝**——不加剪枝大部分会超时，排序预处理 + 可行性剪枝是最常用的组合
2. **排列/组合/子集三个回溯模板必须默写**——这是所有回溯题的母题
3. 贪心最难的部分是**证明正确性**，面试时至少要能说清"为什么局部最优能导致全局最优"
4. 区间调度类问题（活动安排、气球引爆）都是**按结束时间排序 + 贪心选择**

> 🎯 贪心和回溯代表了算法设计的两种极端——贪心追求极致的效率（但适用范围有限），回溯追求极致的完备（但代价是指数级时间）。掌握两者的权衡是算法设计的关键能力。
