## 1. 线性表抽象数据结构（ADT）

### 1.1 定义

线性表是 **n 个相同类型数据元素的有穷序列**，记作 `(a₁, a₂, ..., aₙ)`。

- n = 0 时称为**空表**
- a₁ 是**第一个元素**（表头），aₙ 是**最后一个元素**（表尾）
- 每个元素有且只有一个**直接前驱**（除第一个外）和**直接后继**（除最后一个外）

> 💡 线性表强调元素之间的**逻辑顺序**，而非物理存储顺序。顺序表与链表的不同就在物理存储方式上。

### 1.2 基本操作

| 操作 | 描述 | 典型实现 |
|------|------|---------|
| `InitList()` | 初始化空表 | 创建数组/链表头 |
| `Length()` | 返回表长度 | 维护 size 变量 |
| `GetElem(i)` | 按位查找，返回第 i 个元素 | 数组直接索引 / 链表遍历 |
| `LocateElem(v)` | 按值查找，返回第一个值为 v 的位置 | 遍历比较 |
| `Insert(i, v)` | 在第 i 个位置插入 v | 移动元素 / 修改指针 |
| `Delete(i)` | 删除第 i 个位置的元素 | 移动元素 / 修改指针 |
| `Traverse()` | 遍历所有元素 | for 循环 / while 循环 |

```java
// 线性表接口定义示例
public interface List<E> {
    int size();
    boolean isEmpty();
    E get(int index);
    int indexOf(E element);
    void add(int index, E element);
    E remove(int index);
    void clear();
}
```

## 2. 顺序表（数组实现）

### 2.1 存储结构

顺序表使用**连续的内存空间**存储数据元素，支持 **O(1) 随机访问**。

```java
public class ArrayList<E> {
    private static final int DEFAULT_CAPACITY = 10;
    private Object[] data;    // 底层数组
    private int size;         // 实际元素个数

    public ArrayList() {
        data = new Object[DEFAULT_CAPACITY];
        size = 0;
    }
}
```

### 2.2 插入操作

```java
public void add(int index, E element) {
    if (index < 0 || index > size) throw new IndexOutOfBoundsException();
    ensureCapacity(); // 检查是否需要扩容
    // 将 index 及之后的元素后移
    for (int i = size - 1; i >= index; i--) {
        data[i + 1] = data[i];
    }
    data[index] = element;
    size++;
}
```

- **平均时间复杂度**：移动 n/2 个元素，O(n)
- **最好情况**：尾部插入，O(1)
- **最坏情况**：头部插入，O(n)

### 2.3 删除操作

```java
@SuppressWarnings("unchecked")
public E remove(int index) {
    if (index < 0 || index >= size) throw new IndexOutOfBoundsException();
    E oldValue = (E) data[index];
    // 将 index 之后的元素前移
    for (int i = index; i < size - 1; i++) {
        data[i] = data[i + 1];
    }
    data[--size] = null; // 避免内存泄漏
    return oldValue;
}
```

- **平均时间复杂度**：移动 (n-1)/2 个元素，O(n)
- **最好情况**：尾部删除，O(1)

### 2.4 扩容策略

```java
private void ensureCapacity() {
    if (size == data.length) {
        int newCapacity = data.length * 2; // 倍增策略
        data = Arrays.copyOf(data, newCapacity);
    }
}
```

| 扩容策略 | 均摊时间复杂度 | 特点 |
|---------|--------------|------|
| 倍增（x2） | O(1) | 空间换时间，均摊高效 |
| 固定增量 | O(n) | 频繁扩容导致性能下降 |

> ⚠️ **注意**：Java `ArrayList` 默认扩容为原容量的 **1.5 倍**，而非 2 倍。这是在空间浪费与扩容次数之间的权衡。

### 2.5 优缺点

| 优点 | 缺点 |
|------|------|
| 随机存取快 O(1) | 插入/删除慢 O(n) |
| 空间局部性好，缓存友好 | 空间固定，需扩容 |
| 实现简单 | 扩容时需复制全部元素 |

## 3. 单链表

### 3.1 结点结构

单链表的结点包含**数据域**和**后继指针域**。

```java
public class ListNode<E> {
    E data;
    ListNode<E> next; // 后继指针

    public ListNode(E data) {
        this.data = data;
        this.next = null;
    }
}
```

### 3.2 头指针、头结点与首元结点

| 概念 | 说明 |
|------|------|
| **头指针** | 指向链表第一个结点的指针，链表存在的必要条件 |
| **头结点** | 在首元结点之前附加的一个结点，数据域可为空 |
| **首元结点** | 链表中存储第一个数据元素的结点 |

```java
// 带头结点的链表结构
public class LinkedList<E> {
    private ListNode<E> head; // 头结点（哨兵）
    private int size;

    public LinkedList() {
        head = new ListNode<>(null); // 头结点，data=null
        size = 0;
    }
}
```

> 💡 **头结点的好处**：无需单独处理在首元结点前插入或删除首元结点的特殊情况，操作逻辑统一。

### 3.3 头插法与尾插法

**头插法**：新结点插入头结点之后，逆序建立链表。

```java
public void addFirst(E element) {
    ListNode<E> newNode = new ListNode<>(element);
    newNode.next = head.next;
    head.next = newNode;
    size++;
}
```

**尾插法**：新结点插入链表尾部，顺序建立链表。

```java
public void addLast(E element) {
    ListNode<E> newNode = new ListNode<>(element);
    ListNode<E> cur = head;
    while (cur.next != null) {
        cur = cur.next;
    }
    cur.next = newNode;
    size++;
}
```

> 💡 尾插法通常维护一个尾指针 `tail`，使尾部插入达到 O(1)，避免每次遍历。

### 3.4 查找

```java
// 按位查找
public E get(int index) {
    if (index < 0 || index >= size) throw new IndexOutOfBoundsException();
    ListNode<E> cur = head.next; // 跳过头结点
    for (int i = 0; i < index; i++) {
        cur = cur.next;
    }
    return cur.data;
}
```

- **时间复杂度**：O(n)

### 3.5 插入与删除

```java
// 在指定位置插入
public void add(int index, E element) {
    if (index < 0 || index > size) throw new IndexOutOfBoundsException();
    ListNode<E> prev = head;
    for (int i = 0; i < index; i++) {
        prev = prev.next;
    }
    ListNode<E> newNode = new ListNode<>(element);
    newNode.next = prev.next;
    prev.next = newNode;
    size++;
}

// 删除指定位置
public E remove(int index) {
    if (index < 0 || index >= size) throw new IndexOutOfBoundsException();
    ListNode<E> prev = head;
    for (int i = 0; i < index; i++) {
        prev = prev.next;
    }
    ListNode<E> target = prev.next;
    prev.next = target.next;
    target.next = null;
    size--;
    return target.data;
}
```

- **已知前驱结点**时：插入/删除 O(1)
- **需定位前驱**时：定位 O(n) + 操作 O(1) = O(n)

### 3.6 反转链表（⭐ 必会）

**迭代法（三指针）**：

```java
public ListNode<E> reverse(ListNode<E> head) {
    ListNode<E> prev = null;
    ListNode<E> curr = head;
    while (curr != null) {
        ListNode<E> nextTemp = curr.next; // 保存下一个结点
        curr.next = prev;                 // 反转指针
        prev = curr;                      // 前移 prev
        curr = nextTemp;                  // 前移 curr
    }
    return prev; // 新的头结点
}
```

**递归法**：

```java
public ListNode<E> reverseRecursive(ListNode<E> head) {
    if (head == null || head.next == null) return head;
    ListNode<E> newHead = reverseRecursive(head.next);
    head.next.next = head;
    head.next = null;
    return newHead;
}
```

> ⚠️ **反转链表是面试最高频的链表题**，迭代和递归两种写法都必须能手写。

## 4. 双链表

### 4.1 结点结构

```java
public class DoublyListNode<E> {
    E data;
    DoublyListNode<E> prev; // 前驱指针
    DoublyListNode<E> next; // 后继指针

    public DoublyListNode(E data) {
        this.data = data;
        this.prev = null;
        this.next = null;
    }
}
```

### 4.2 优势与劣势

| 特性 | 单链表 | 双链表 |
|------|--------|--------|
| 指针数 | 1 个（next） | 2 个（prev + next） |
| 空间开销 | 小 | 大（多一个指针） |
| 双向遍历 | 不支持 | 支持 |
| 删除给定结点 | O(n)（需找前驱） | O(1)（直接通过 prev） |

```java
// 双链表删除指定结点（已知结点引用）
public void removeNode(DoublyListNode<E> node) {
    node.prev.next = node.next;
    if (node.next != null) {
        node.next.prev = node.prev;
    }
    // 断开 node 的引用（可选）
    node.prev = null;
    node.next = null;
}
```

## 5. 循环链表

### 5.1 循环单链表

尾结点的 `next` 指向头结点，形成环。

```java
// 判断是否为循环链表（快慢指针）
public boolean hasCycle(ListNode<E> head) {
    if (head == null || head.next == null) return false;
    ListNode<E> slow = head;
    ListNode<E> fast = head.next;
    while (slow != fast) {
        if (fast == null || fast.next == null) return false;
        slow = slow.next;
        fast = fast.next.next;
    }
    return true;
}
```

### 5.2 循环双链表

头结点的 `prior` 指向尾结点，尾结点的 `next` 指向头结点。

### 5.3 约瑟夫环问题

```java
// 约瑟夫环：n 个人围成一圈，从第一个人开始报数，数到 k 的人出列
public int josephus(int n, int k) {
    // 递推公式：f(n, k) = (f(n-1, k) + k) % n
    int survivor = 0; // f(1, k) = 0
    for (int i = 2; i <= n; i++) {
        survivor = (survivor + k) % i;
    }
    return survivor; // 返回存活者的索引（0-based）
}
```

> 💡 **循环链表的典型应用**：操作系统进程调度（时间片轮转）、约瑟夫环问题。

## 6. 静态链表

用**数组**模拟链表，通过**游标（cursor）** 替代指针。每个数组元素包含数据域和游标域（指向下一个元素的数组索引）。

```java
// 静态链表结点
class StaticListNode<E> {
    E data;
    int next; // 游标，指向下一个结点的数组下标，-1 表示尾
}
```

| 特性 | 说明 |
|------|------|
| 空间 | 连续数组空间 |
| 操作 | 插入/删除修改游标，不需移动元素 |
| 优点 | 无指针的语言（早期 FORTRAN）中使用 |
| 应用 | FAT 文件系统 |

## 7. 顺序表与链表的对比

| 对比维度 | 顺序表（数组） | 链表 |
|---------|--------------|------|
| **存储空间** | 连续，空间预分配 | 离散，动态分配 |
| **随机访问** | O(1) | O(n) |
| **头部插入** | O(n)（全量后移） | O(1) |
| **尾部插入** | O(1)（均摊） | O(1)（有尾指针） |
| **中间插入** | O(n) | O(1)（已知前驱时） |
| **空间效率** | 可能有内部碎片 | 有指针开销 |
| **缓存局部性** | 好 | 差 |
| **扩容代价** | 高（需复制） | 无需扩容 |

> 🎯 **选择依据**：频繁**查找**用顺序表，频繁**增删**用链表。

## 9. 学习建议

1. **手写链表全部基本操作**（增删改查），脱离 IDE 用白板写出正确代码
2. 链表的增删操作**画图理解**，防止指针丢失
3. **快慢指针**是解决链表类问题的核心技巧（找中点、环检测、倒数第 N 个）
4. 优先掌握迭代法反转链表，再理解递归写法

> 🎯 线性表是所有数据结构的基础，掌握顺序表和链表的差异及各自适用场景，是后续学习栈、队列、哈希表的基石。
