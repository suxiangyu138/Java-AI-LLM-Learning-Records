## 2. 图的遍历——DFS 与 BFS 核心总结

### 2.1 核心本质

| 遍历方式 | 本质 | 数据结构 | 搜索顺序 |
|---------|------|---------|---------|
| **DFS** | 一路到底，碰壁回溯；纵向搜索 | 栈（递归 / 手动栈） | 深度优先 |
| **BFS** | 层层扩散，按层遍历；横向搜索 | 队列 | 层次优先 |

- **DFS** 适合：枚举所有方案、连通块、回溯、树前后序、暴力搜索
- **BFS** 适合：无权图**最短路径**、最少步数、层序遍历、多源扩散
- **BFS 优点**：首次到达终点就是最优解
- **DFS 缺点**：不保证最短路径，深度大易栈溢出

### 2.2 关键对比

| 特性 | DFS | BFS |
|:--- |:--- |:--- |
| 数据结构 | 栈（递归 / Stack） | 队列（Queue） |
| 搜索顺序 | 深度优先 | 层次优先 |
| 最短路径 | 不保证 | 一定保证 |
| 访问标记 | 递归进入标记，回溯撤销 | 入队立即标记 |
| 代表题型 | 岛屿、子集、排列、回溯 | 单词接龙、迷宫、层序遍历 |

> 💡 **DFS 强调的是"回溯穷举"，BFS 强调的是"按层扩散求最短"**。

### 2.3 DFS 递归模板

```java
// DFS 递归模板（最常用）
void dfs(int x, int y) {
    // 1. 边界终止条件
    if (越界 / 不合法) return;
    // 2. 标记已访问
    visited[x][y] = true;
    // 3. 遍历所有方向/邻接节点
    for (方向) {
        int nx = x + dx[i];
        int ny = y + dy[i];
        if (合法且未访问) {
            dfs(nx, ny);
        }
    }
    // 4. 回溯（需要枚举所有方案时才撤销）
    visited[x][y] = false;
}
```

### 2.4 DFS 迭代模板（手动栈，防溢出）

```java
void dfsIterative(int start) {
    Stack<Integer> stack = new Stack<>();
    boolean[] visited = new boolean[n];
    stack.push(start);
    visited[start] = true;
    while (!stack.isEmpty()) {
        int cur = stack.pop();
        // 处理当前节点
        for (int neighbor : graph[cur]) {
            if (!visited[neighbor]) {
                visited[neighbor] = true;
                stack.push(neighbor);
            }
        }
    }
}
```

### 2.5 BFS 标准模板（最短路径专用）

```java
int bfs(int start, int target) {
    Queue<Integer> queue = new LinkedList<>();
    boolean[] visited = new boolean[n];
    queue.offer(start);
    visited[start] = true;
    int step = 0;
    while (!queue.isEmpty()) {
        // 按层遍历
        int size = queue.size();
        for (int i = 0; i < size; i++) {
            int cur = queue.poll();
            // 到达终点，直接返回步数
            if (cur == target) return step;
            for (int neighbor : graph[cur]) {
                if (!visited[neighbor]) {
                    visited[neighbor] = true;
                    queue.offer(neighbor);
                }
            }
        }
        // 一层遍历完，步数 +1
        step++;
    }
    return -1; // 不可达
}
```

### 2.6 刷题选择口诀

- 求**最短、最少步数、最小次数** → 无脑 BFS
- 求**所有方案、组合、排列、连通块** → 无脑 DFS
- 矩阵/网格类：两种都可，求最短用 BFS
- 数据量大、递归深度深 → 用迭代 DFS / BFS，避免栈溢出

### 2.7 DFS 应用场景

| 应用类别 | 说明 |
|---------|------|
| **树与二叉树遍历** | 前序、中序、后序；路径总和、根到叶路径 |
| **连通性问题** | 岛屿数量、封闭岛屿、最大连通面积、网格连通块 |
| **回溯类问题（高频）** | 全排列、组合总和、子集、N 皇后、括号生成 |
| **图论问题** | 无向/有向图遍历、判断环、拓扑排序、所有可达路径 |
| **暴力搜索/枚举** | 所有可行方案枚举、迷宫全部路径查找 |
| **特殊场景** | 深拷贝、文件系统深度遍历 |

### 2.8 BFS 应用场景

| 应用类别 | 说明 |
|---------|------|
| **最短路径问题（核心优势）** | 无权图最短路径、迷宫最短出口、单词接龙最短转换序列 |
| **树的层序遍历** | 二叉树层序遍历、最大/最小深度、锯齿层序遍历 |
| **最少操作次数** | 最小交换次数、最小变换步数、破解最少步骤类 |
| **多源扩散问题** | 腐烂的橘子、地图多起点同时扩散、洪水填充 |
| **圈层/距离问题** | 每个节点到起点的最短距离、01 矩阵距离、最近陆地 |
| **拓扑排序（广度写法）** | 课程表、入度表拓扑排序 |

### 2.9 图遍历完整示例

```java
// 岛屿数量（#200）——DFS 解法
public int numIslands(char[][] grid) {
    if (grid == null || grid.length == 0) return 0;
    int m = grid.length, n = grid[0].length;
    int count = 0;
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (grid[i][j] == '1') {
                count++;
                dfs(grid, i, j);
            }
        }
    }
    return count;
}

private void dfs(char[][] grid, int i, int j) {
    if (i < 0 || i >= grid.length || j < 0 || j >= grid[0].length || grid[i][j] != '1') return;
    grid[i][j] = '0'; // 标记已访问（沉岛）
    dfs(grid, i - 1, j);
    dfs(grid, i + 1, j);
    dfs(grid, i, j - 1);
    dfs(grid, i, j + 1);
}

// BFS 解法
public int numIslandsBFS(char[][] grid) {
    if (grid == null || grid.length == 0) return 0;
    int m = grid.length, n = grid[0].length;
    int count = 0;
    int[][] dirs = {{-1,0}, {1,0}, {0,-1}, {0,1}};
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (grid[i][j] == '1') {
                count++;
                Queue<int[]> queue = new LinkedList<>();
                queue.offer(new int[]{i, j});
                grid[i][j] = '0';
                while (!queue.isEmpty()) {
                    int[] cur = queue.poll();
                    for (int[] d : dirs) {
                        int nx = cur[0] + d[0], ny = cur[1] + d[1];
                        if (nx >= 0 && nx < m && ny >= 0 && ny < n && grid[nx][ny] == '1') {
                            grid[nx][ny] = '0';
                            queue.offer(new int[]{nx, ny});
                        }
                    }
                }
            }
        }
    }
    return count;
}
```

## 3. 最小生成树

### 3.1 Prim 算法

从任意点开始"生长"，每次选连接已选集合和未选集合的最小边。

```java
// Prim 算法——邻接矩阵实现 O(V²)
public int prim(int[][] graph) {
    int n = graph.length;
    int[] dist = new int[n];  // 到已选集合的最短距离
    boolean[] visited = new boolean[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[0] = 0;
    int totalWeight = 0;
    for (int i = 0; i < n; i++) {
        // 选距离最小的未访问顶点
        int u = -1;
        int minDist = Integer.MAX_VALUE;
        for (int j = 0; j < n; j++) {
            if (!visited[j] && dist[j] < minDist) {
                minDist = dist[j];
                u = j;
            }
        }
        if (u == -1) return -1; // 图不连通
        visited[u] = true;
        totalWeight += minDist;
        // 更新邻接点的距离
        for (int v = 0; v < n; v++) {
            if (!visited[v] && graph[u][v] < dist[v]) {
                dist[v] = graph[u][v];
            }
        }
    }
    return totalWeight;
}
```

| 实现方式 | 时间复杂度 |
|---------|-----------|
| 邻接矩阵朴素实现 | O(V²) |
| 二叉堆优化 | O(E log V) |
| 斐波那契堆优化 | O(E + V log V) |

### 3.2 Kruskal 算法

边按权值排序，用并查集判断是否成环，每次选最小不成环的边。

```java
class Edge implements Comparable<Edge> {
    int u, v, weight;
    Edge(int u, int v, int w) { this.u = u; this.v = v; this.weight = w; }
    public int compareTo(Edge o) { return this.weight - o.weight; }
}

// 并查集
class UnionFind {
    int[] parent;
    UnionFind(int n) { parent = new int[n]; for (int i = 0; i < n; i++) parent[i] = i; }
    int find(int x) { return parent[x] == x ? x : (parent[x] = find(parent[x])); }
    void union(int a, int b) { parent[find(a)] = find(b); }
}

public int kruskal(int n, List<Edge> edges) {
    Collections.sort(edges);
    UnionFind uf = new UnionFind(n);
    int totalWeight = 0;
    int edgeCount = 0;
    for (Edge e : edges) {
        if (uf.find(e.u) != uf.find(e.v)) {
            uf.union(e.u, e.v);
            totalWeight += e.weight;
            edgeCount++;
            if (edgeCount == n - 1) break;
        }
    }
    return edgeCount == n - 1 ? totalWeight : -1; // 不连通返回 -1
}
```

**时间复杂度**：O(E log E)（排序主导）

| 算法 | 思想 | 适用图 | 时间复杂度 |
|------|------|--------|-----------|
| Prim | 加点法 | 稠密图 | O(V²) / O(E log V) |
| Kruskal | 加边法 | 稀疏图 | O(E log E) |

## 4. 最短路径

### 4.1 Dijkstra（单源，非负权）

```java
// Dijkstra——堆优化 O(E log V)
public int[] dijkstra(List<int[]>[] graph, int start) {
    int n = graph.length;
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[start] = 0;
    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[1] - b[1]);
    pq.offer(new int[]{start, 0});
    while (!pq.isEmpty()) {
        int[] cur = pq.poll();
        int u = cur[0], d = cur[1];
        if (d > dist[u]) continue; // 过时记录，跳过
        for (int[] edge : graph[u]) {
            int v = edge[0], w = edge[1];
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.offer(new int[]{v, dist[v]});
            }
        }
    }
    return dist;
}
```

| 实现方式 | 时间复杂度 | 说明 |
|---------|-----------|------|
| 朴素 | O(V²) | 稠密图适用 |
| 堆优化 | O(E log V) | 稀疏图适用 |

> ⚠️ **Dijkstra 不能处理负权边**——已确定的最短距离可能被后续的负权边更新。
> 不能处理负权边的原因：贪心策略假设已选出的最短距离不会再变小，但负权边可能破坏这一假设。

### 4.2 Bellman-Ford（可处理负权边）

```java
public int[] bellmanFord(int n, int[][] edges, int start) {
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[start] = 0;
    // 对每条边松弛 V-1 轮
    for (int i = 0; i < n - 1; i++) {
        for (int[] edge : edges) {
            int u = edge[0], v = edge[1], w = edge[2];
            if (dist[u] != Integer.MAX_VALUE && dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
            }
        }
    }
    // 第 V 轮——检测负环
    for (int[] edge : edges) {
        int u = edge[0], v = edge[1], w = edge[2];
        if (dist[u] != Integer.MAX_VALUE && dist[u] + w < dist[v]) {
            throw new RuntimeException("存在负权环");
        }
    }
    return dist;
}
```

**时间复杂度**：O(VE)

### 4.3 SPFA（Bellman-Ford 队列优化）

```java
public int[] spfa(int n, List<int[]>[] graph, int start) {
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[start] = 0;
    boolean[] inQueue = new boolean[n];
    int[] count = new int[n]; // 记录入队次数，检测负环
    Queue<Integer> queue = new LinkedList<>();
    queue.offer(start);
    inQueue[start] = true;
    while (!queue.isEmpty()) {
        int u = queue.poll();
        inQueue[u] = false;
        for (int[] edge : graph[u]) {
            int v = edge[0], w = edge[1];
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                if (!inQueue[v]) {
                    queue.offer(v);
                    inQueue[v] = true;
                    count[v]++;
                    if (count[v] >= n) throw new RuntimeException("存在负权环");
                }
            }
        }
    }
    return dist;
}
```

**最坏时间复杂度**：O(VE)，平均远快于 Bellman-Ford

### 4.4 Floyd-Warshall（多源最短路径）

```java
// Floyd——DP 思想 O(V³)
public int[][] floyd(int[][] graph) {
    int n = graph.length;
    int[][] dist = new int[n][n];
    for (int i = 0; i < n; i++) Arrays.fill(dist[i], Integer.MAX_VALUE / 2);
    for (int i = 0; i < n; i++) {
        dist[i][i] = 0;
        for (int j = 0; j < n; j++) {
            if (graph[i][j] != 0) dist[i][j] = graph[i][j];
        }
    }
    // 三重循环：中间点 k → 起点 i → 终点 j
    for (int k = 0; k < n; k++) {
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (dist[i][k] + dist[k][j] < dist[i][j]) {
                    dist[i][j] = dist[i][k] + dist[k][j];
                }
            }
        }
    }
    return dist;
}
```

### 4.5 最短路径算法对比

| 算法 | 适用范围 | 时间复杂度 | 空间复杂度 |
|------|---------|-----------|-----------|
| Dijkstra（朴素） | 单源，非负权 | O(V²) | O(V) |
| Dijkstra（堆优化） | 单源，非负权 | O(E log V) | O(V + E) |
| Bellman-Ford | 单源，任意权 | O(VE) | O(V) |
| SPFA | 单源，任意权 | 平均 O(E)，最坏 O(VE) | O(V) |
| Floyd-Warshall | 多源，任意权 | O(V³) | O(V²) |

> 🎯 **选型建议**：稀疏图+非负权用堆优化 Dijkstra；稠密图+非负权用朴素 Dijkstra；有负权边用 Bellman-Ford/SPFA；求所有点对用 Floyd。

## 5. 拓扑排序

### 5.1 Kahn 算法（BFS 版）

```java
public int[] topologicalSort(int n, int[][] edges) {
    List<Integer>[] graph = new ArrayList[n];
    int[] inDegree = new int[n];
    for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
    for (int[] edge : edges) {
        graph[edge[0]].add(edge[1]);
        inDegree[edge[1]]++;
    }
    Queue<Integer> queue = new LinkedList<>();
    for (int i = 0; i < n; i++) {
        if (inDegree[i] == 0) queue.offer(i);
    }
    int[] order = new int[n];
    int idx = 0;
    while (!queue.isEmpty()) {
        int u = queue.poll();
        order[idx++] = u;
        for (int v : graph[u]) {
            inDegree[v]--;
            if (inDegree[v] == 0) queue.offer(v);
        }
    }
    return idx == n ? order : new int[0]; // 存在环则返回空数组
}
```

### 5.2 DFS 后序遍历逆序

```java
public int[] topologicalSortDFS(int n, List<Integer>[] graph) {
    boolean[] visited = new boolean[n];
    boolean[] onPath = new boolean[n];
    Deque<Integer> stack = new ArrayDeque<>();
    for (int i = 0; i < n; i++) {
        if (!visited[i]) {
            if (hasCycle(i, graph, visited, onPath, stack)) {
                return new int[0]; // 有环
            }
        }
    }
    int[] order = new int[n];
    for (int i = 0; i < n; i++) order[i] = stack.pop();
    return order;
}

private boolean hasCycle(int u, List<Integer>[] graph, boolean[] visited,
                         boolean[] onPath, Deque<Integer> stack) {
    visited[u] = true;
    onPath[u] = true;
    for (int v : graph[u]) {
        if (!visited[v]) {
            if (hasCycle(v, graph, visited, onPath, stack)) return true;
        } else if (onPath[v]) {
            return true; // 发现环
        }
    }
    onPath[u] = false;
    stack.push(u);
    return false;
}
```

**时间复杂度**：O(V + E)

| 方法 | 特点 |
|------|------|
| Kahn（BFS） | 入度表 + 队列，直观易理解 |
| DFS 逆序 | 利用递归的栈性质，代码简洁 |

> 💡 **拓扑排序的应用**：课程安排、构建系统依赖、任务调度、编译器的包依赖分析。

## 6. 关键路径（AOE 网）

### 6.1 基本概念

- **AOE 网**：边表示活动及其持续时间的带权有向无环图
- **顶点**表示事件（活动的开始/结束），**边**表示活动

### 6.2 关键参数

| 参数 | 含义 | 计算方法 |
|------|------|---------|
| ve(k) | 事件 k 的**最早发生时间** | 正向拓扑，取 max |
| vl(k) | 事件 k 的**最迟发生时间** | 逆向拓扑，取 min |
| e(i) | 活动 i 的**最早开始时间** | = ve(弧尾) |
| l(i) | 活动 i 的**最迟开始时间** | = vl(弧头) - 活动持续时间 |
| 关键活动 | e(i) = l(i) 的活动 | 不可延误，位于关键路径上 |

### 6.3 算法步骤

1. **正向拓扑**求 ve(k)：从源点开始，ve(源点) = 0
2. **逆向拓扑**求 vl(k)：从汇点开始，vl(汇点) = ve(汇点)
3. 对每条边计算 e(i) 和 l(i)
4. e(i) = l(i) 的活动即为关键活动，连成关键路径

> ⚠️ **关键路径上的活动不能延期**——任何关键活动延期都会导致整个项目延期。

## 8. 学习建议

1. **Dijkstra 和 Floyd** 手写实现，理解贪心 vs DP 的算法思想差异
2. 用**并查集**解决连通性问题（省份数量、冗余连接等题）
3. 图论题重在**建模**——把看似不是图的问题转化为图（如课程依赖、社交关系）
4. **DFS 回溯 + 状态重置** 是解决排列/组合/子集等问题的通用模板
5. **BFS 按层遍历** 是解决最短路径/最少步数问题的标准范式

> 🎯 图论面试的核心是**遍历（DFS/BFS）+ 最短路径（Dijkstra）+ 拓扑排序**，熟练掌握这三个模块即可应对绝大多数图论面试题。
