## 1. 搜索体系对比

### 1.1 DFS vs BFS

| 维度 | DFS | BFS |
|------|------|------|
| 结构 | 栈（递归/显式栈） | 队列 |
| 扩展方式 | 一条路走到底再回头 | 按层逐层扩展 |
| 最短路径 | 无权图不保证 | **无权图最短路**（首次到达即最短） |
| 空间 | O(深度)（深图差） | O(宽度)（宽图差） |
| 全解枚举 | 擅长（回溯基础） | 不擅长 |
| 适用 | 连通性、路径枚举、拓扑、二分图 | 最短路、层序、多源扩散 |

> 🎯 一句话分法：**问「最短几步」用 BFS；问「有没有路 / 多少条路」用 DFS**。识别信号：题面出现「最少步数」「逐层」「扩散」→ BFS。

### 1.2 为什么 BFS 首次到达即最短（面试追问）

```text
BFS 按层扩展：第 k 层节点 = 距离起点 k 步的节点
→ 节点第一次被访问时所在的层就是最短距离
若用 DFS，可能先走一条长路到达，之后才发现短路 → 需要回溯重算
对比 Dijkstra：BFS 是「无权」的特例，Dijkstra 用优先队列
按距离排序出队，把「层」换成「距离」。
```

### 1.3 递归 vs 迭代（DFS 实现双形态）

| 维度 | 递归 | 显式栈迭代 |
|------|------|------|
| 代码 | 简洁 | 繁琐（状态打包） |
| 栈深度 | 受 JVM 限制（约 1 万层） | 堆内存自由 |
| 适用 | 树/图深 ≤ 10⁴ | 链状树、大图 |
| 陷阱 | StackOverflow | 状态机复杂易错 |

## 2. 回溯、剪枝与分支限界对比

| 维度 | 回溯（Backtracking） | 剪枝 | 分支限界 |
|------|------|------|------|
| 本质 | DFS + 撤销的穷举 | 回溯的优化技巧 | 回溯 + 界函数 |
| 求什么 | **所有解** | 减少搜索量 | 最优解 |
| 核心 | 递归 + 撤销 | 提前判定死路 | 上下界剪枝 |
| 代表题 | 全排列、N 皇后、子集 | 组合去重 | 0-1 背包、旅行商 |

> 🎯 一句话分法：**回溯是「方法」，剪枝是「加速」，分支限界是「带界的回溯」**。求所有解 → 回溯；求最优且搜索巨大 → 分支限界。

### 2.1 回溯 vs DP（同为穷举家族）

| 维度 | 回溯 | DP |
|------|------|------|
| 枚举 | 显式尝试所有分支 | 隐式（子问题合并） |
| 子问题 | 不要求重叠 | **要求重叠**（记忆化才有意义） |
| 输出 | 所有方案 | 最优值/方案数 |
| 复杂度 | 指数（剪枝降） | 多项式 |
| 决策：重叠 → DP，不重叠 → 回溯 |

## 3. DP、贪心与分治三方对比

| 维度 | 分治 | 贪心 | DP |
|------|------|------|------|
| 子问题关系 | **独立** | 无子问题 | **重叠** |
| 决策方式 | 拆解合并 | 每步局部最优 | 全局最优递推 |
| 需要证明 | 合并正确 | **贪心选择性质** | 无后效性 |
| 典型 | 归并、快排、二分 | 区间调度、哈夫曼 | LIS、背包 |
| 反例形态 | — | 局部最优锁死全局 | 状态漏维度 |

### 3.1 三问一锤定音

| # | 问题 | 答案 |
|:---:|------|------|
| 1 | 子问题重叠吗？ | 重叠 → DP；独立 → 分治 |
| 2 | 每步决策能证明最优吗？ | 能 → 贪心；不能 → DP |
| 3 | 结果需要全部方案吗？ | 需要 → 回溯；只要值 → DP |

### 3.2 贪心 vs DP 的经典反例（硬币题）

| 硬币面值 | 目标 | 贪心结果 | 最优 |
|------|------|:---:|:---:|
| 1,5,11 | 15 | 11+1×4 = 5 枚 | 5×3 = 3 枚 |
| 1,5,10,25（标准） | 任意 | 最优 | 最优 |

> 💡 记忆锚点：**「先拿最大的」在 11/5/1 场景失效**——局部最优 ≠ 全局最优，这就是贪心必须证明的原因。

### 3.3 面试表达模板（贪心 vs DP）

```text
「贪心对每一步做局部最优选择且不回头，适合满足贪心选择
  性质的问题（能证明）。DP 通过保存所有子问题的最优解做
  全局决策，适合有重叠子问题的问题。反例：硬币面值 11/5/1
  求 15——贪心取 11+1×4 共 5 枚，但最优是 5×3 共 3 枚。
  所以无法证明贪心性质时，必须用 DP。」
```

## 4. 双指针家族对比

### 4.1 双指针 vs 滑动窗口 vs 快慢指针

| 类型 | 移动方式 | 窗口概念 | 典型题 |
|------|------|:---:|------|
| 双指针 | 两端向中间 | 无 | 两数之和（排序后）、反转、接雨水 |
| 滑动窗口 | 左右同向 | **有**（动态区间） | 无重复子串、子数组和 |
| 快慢指针 | 速度不同 | 无 | 环检测、链表中间节点 |

> 🎯 一句话分法：**有「连续区间约束」→ 滑动窗口；无区间概念的两端逼近 → 双指针；链表中点/环 → 快慢指针**。

### 4.2 滑动窗口 vs 前缀和（同为区间问题）

| 维度 | 滑动窗口 | 前缀和 |
|------|------|------|
| 适用条件 | 窗口约束单调可缩 | 任意区间和查询 |
| 复杂度 | O(n) 一次扫描 | O(n) 预处理 + O(1) 查询 |
| 负值 | 通常不适用（需单调） | **适用于负值** |
| 计数变体 | 「恰好 k」用窗口 | + 哈希表计数 |

> ⚠️ 关键差异：**数组含负数时滑动窗口失效**（窗口扩大不一定增大和）——此时转前缀和 + 哈希。

## 5. 二分 vs 双指针 vs 前缀和

| 维度 | 二分 | 双指针 | 前缀和 |
|------|------|------|------|
| 前提 | 单调性 | 指针单调移动 | 预处理 |
| 目的 | 找位置/答案 | 维护可行区间 | 快速算区间和 |
| 复杂度 | O(log n) | O(n) | O(1)/次查询 |
| 识别信号 | 「有序」「最大化最小」 | 「子数组」「两端逼近」 | 「区间和」「多次查询」 |

### 5.1 组合使用（难题套路）

```text
二分 + 前缀和：查「和 ≤ S 的子数组个数」→ 前缀和有序 + lowerBound
双指针 + 前缀和：求「和 ≥ S 的最短子数组」→ 窗口内前缀和
哈希 + 前缀和：求「和为 k 的子数组个数」→ 存前缀和出现次数
```

## 6. 递归 vs 迭代 vs 记忆化

| 维度 | 递归 | 迭代 | 记忆化 |
|------|------|------|------|
| 本质 | 函数调用自身 | 循环 | 递归 + 缓存 |
| 栈风险 | 有（深度限制） | 无 | 有（同递归） |
| 代码 | 最简洁 | 较繁琐 | 递归 + 缓存表 |
| 适用 | 树/分治/回溯 | 双指针/遍历 | 重叠子问题（DP 递归版） |

### 6.1 递归转迭代的两种方式

| 方式 | 做法 | 适用 |
|------|------|------|
| 显式栈 | 用栈模拟调用栈，状态打包 | DFS、树遍历 |
| 尾递归改写 | 递归在末尾 → 循环 | 累加/累乘类 |
| 递推填表 | 先算小子问题 → 大问题（DP 迭代版） | 一切 DP |

> 🎯 **核心要点**：思想类对比的规律——**每一个「像」都差在一个性质**：BFS/DFS 差在队列 vs 栈；贪心/DP 差在「局部能否证明」；窗口/双指针差在「有没有区间约束」；二分/双指针差在「对数 vs 线性」。面试被问「为什么不用 X」时，先说出差异性质，再给反例（第 3.3 节模板直接套用），就是满分回答。
