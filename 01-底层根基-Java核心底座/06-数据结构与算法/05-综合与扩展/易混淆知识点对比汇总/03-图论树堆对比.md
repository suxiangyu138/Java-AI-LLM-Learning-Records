## 1. 最短路算法四兄弟

| 算法 | 适用图 | 复杂度 | 单源/全源 | 负权 |
|------|------|:---:|:---:|:---:|
| BFS | 无权图 | O(V+E) | 单源 | — |
| Dijkstra（堆） | 非负权 | O((V+E) log V) | 单源 | ❌ |
| Bellman-Ford | 任意（可负） | O(VE) | 单源 | ✅（可判负环） |
| Floyd | 任意（稠密） | O(V³) | **全源** | ✅（负环检测） |

### 1.1 选型决策

```text
无权图（每步代价 1）→ BFS（最优，O(V+E)）
非负权 → Dijkstra + 堆（默认首选）
有负权 → Bellman-Ford（SPFA 是队列优化版，可判负环）
要所有点对最短 → Floyd（V ≤ 400 才敢用）
```

> 🎯 一句话分法：**BFS 是「不带权」的 Dijkstra；Dijkstra 是「正权」的 BFS**。负权一出现，Dijkstra 的贪心假设立刻失效——这是最经典的追问点。

### 1.2 Dijkstra vs BFS 的直觉差异

| 维度 | BFS | Dijkstra |
|------|------|------|
| 队列 | FIFO 队列 | 优先队列（按距离） |
| 出队条件 | 先入先出 | 距离最小先出 |
| 首次出队即最短 | ✅ | ✅（非负权保证） |
| 为什么正权必须堆 | — | 边权不同，先到的不一定近 |

### 1.3 Dijkstra 为什么不能处理负权（面试追问）

```text
Dijkstra 的假设：出队的节点距离已确定（不会再被更短路径更新）。
负权边可以「绕远路变近」：先走一条长路，再通过负权边抄近道
→ 已出队的节点可能被后来者更新 → 贪心失效。
例：A→B 权 1，A→C 权 3，C→B 权 -5：Dijkstra 先确定 B=1，
    但实际 A→C→B = -2 更短。
修复：Bellman-Ford 反复松弛 V-1 轮；SPFA 队列优化。
```

## 2. 最小生成树：Prim vs Kruskal

| 维度 | Prim | Kruskal |
|------|------|------|
| 思路 | 点扩展（每次并入最近点） | 边合并（全局最小边 + 并查集） |
| 数据结构 | 优先队列 / 邻接表 | 并查集 |
| 复杂度 | O((V+E) log V) | O(E log E) |
| 稠密图 | ✅ 更优 | 一般 |
| 稀疏图 | 一般 | ✅ 更优（E 小） |
| 依赖 | 图的邻接结构 | 只需边集 |

> 🎯 一句话分法：**稠密图（边多）用 Prim，稀疏图（边少）用 Kruskal**；Kruskal 的实现更简单（排序 + 并查集），是面试首选口述答案。

### 2.1 最小生成树 vs 最短路（高频混淆）

| 维度 | MST | 最短路 |
|------|------|------|
| 目标 | 连接所有点的**总代价最小** | 两点间**路径代价最小** |
| 性质 | 树（n-1 条边） | 路径（可多条边） |
| 反直觉 | MST 中两点路径 ≠ 两点最短路 | — |
| 识别 | 「连通所有点」「总成本最小」 | 「从 A 到 B」「最少时间」 |

### 2.2 反直觉例子（面试加分）

```text
三角形图：A-B 权 1，B-C 权 1，A-C 权 2
MST = {A-B, B-C} 总代价 2
但 A 到 C 的 MST 路径是 A→B→C = 2，直接边 A-C 也是 2
构造更明显的反例：A-B=1, B-C=1, A-C=100, 加 D 点连 C-D=1, A-D=1
MST 中 A 到 C 可能绕远——记住「MST 保证总代价，不保证任意两点
距离」，一句话即可答完追问。
```

## 3. 连通性判断三件套

| 工具 | 解决什么 | 复杂度 | 适用 |
|------|------|:---:|------|
| 并查集 | 动态加边的连通性 | O(α(n)) 近常数 | 在线、Kruskal |
| BFS/DFS | 静态图连通分量 | O(V+E) | 一次查询、分量划分 |
| 强连通分量（Tarjan） | 有向图 SCC | O(V+E) | 缩点、2-SAT |

> 🎯 一句话分法：**要「随时问是否连通」→ 并查集（在线）；要「划分所有连通块」→ BFS/DFS（离线）**。无向图连通用并查集/BFS，有向图强连通必须 Tarjan。

### 3.1 并查集 vs BFS 的差异细节

| 维度 | 并查集 | BFS |
|------|------|------|
| 信息 | 只答「是否连通」 | 能给距离、路径 |
| 修改 | 只增边（合并） | 结构变化需重跑 |
| 代价 | 近 O(1)/操作 | O(V+E)/次 |
| 记忆点 | 路径压缩必做 | visited 入队即标记 |

### 3.2 并查集的两种优化（面试必答）

```text
路径压缩：find 时把沿途节点直接指向根 → 均摊 O(α(n))
按秩合并：小树挂到大树 → 树高 O(log n)
两者都用：均摊近 O(1)，单次操作复杂度可视为常数
只压缩不按秩：最坏情况仍是 O(log n) 级别，工程可用
```

## 4. DAG 处理：拓扑排序 vs DFS

| 维度 | 拓扑排序（Kahn） | DFS 环检测 |
|------|------|------|
| 思路 | 入度为 0 的节点层层剥 | 三色标记（白/灰/黑） |
| 产出 | 合法线性序 / 判有环 | 判有环 + 拓扑序（逆后序） |
| 复杂度 | O(V+E) | O(V+E) |
| 环检测 | 出队数 < V 即有环 | 灰点再次访问即有环 |
| 附加能力 | 配 DP 求 DAG 最长路 | 配时间戳求 SCC |

> 🎯 一句话分法：**需要「依赖顺序」→ Kahn；只需要「有没有环」→ 三色 DFS**。拓扑排序后做 DP（最长路/方案数）是 DAG 题的固定组合。

### 4.1 拓扑排序 vs 最短路（差分约束提示）

```text
差分约束：xᵢ - xⱼ ≤ c → 建边 j→i 权 c → 最短路模型
⚠️ 常见混淆：差分约束用「最短路/最长路」，不用拓扑排序（负权环 = 无解）
```

## 5. 线段树 vs 树状数组 vs 稀疏表

| 维度 | 线段树 | 树状数组 | 稀疏表 ST |
|------|------|------|------|
| 区间和/最值 | ✅ | 和（最值也可） | 最值（不可修改） |
| 单点修改 | ✅ O(log n) | ✅ O(log n) | ❌ |
| 区间查询 | O(log n) | O(log n) | **O(1)** |
| 代码量 | 大（4n 数组） | 小（n+1） | 中（倍增） |
| 适用 | 在线 + 区间 + 修改 | 前缀类 + 修改（和） | 离线静态最值 |

### 5.1 选型决策

```text
要修改吗？
 ├─ 不需要 → 静态最值：稀疏表 O(1) 查询
 └─ 需要 →
      ├─ 区间和/前缀类 → 树状数组（代码最短）
      └─ 区间最值/复杂操作 → 线段树（懒标记）
```

### 5.2 面试追问：为什么树状数组只能做前缀类

```text
树状数组本质是「二进制分解的前缀树」：查询 [l, r] 用
sum(r) - sum(l-1)（差分思想），因此要求运算**可逆**。
求和可逆（减法还原），最值不可逆（max 减不回去）→
区间最值需要额外技巧或直接上线段树。
```

## 6. 图论选型的决策链

```text
问题类型？
 ├─ 最短路 → 无权？BFS；非负权？Dijkstra；负权？Bellman-Ford
 ├─ 最小生成树 → 稠密？Prim；稀疏？Kruskal
 ├─ 连通性 → 在线动态？并查集；划分分量？BFS/DFS；有向 SCC？Tarjan
 ├─ 依赖序 → Kahn 拓扑排序（可配 DP）
 ├─ 区间操作 → 要修改？线段树/树状数组；静态？稀疏表
 └─ 最值流 → 动态 TopK？堆
```

> 🎯 **核心要点**：图论与高级结构的选型都遵循「**复杂度换能力**」原则——BFS 最简单但只能无权，Dijkstra 加堆换正权，Bellman-Ford 再换负权，Floyd 用 O(V³) 换全源；线段树用代码量换「在线区间 + 修改」的完整能力。记住每条链的「加价购买的能力」，选型就不再靠背。两个必答追问：Dijkstra 负权失效的原因、MST 与最短路的反直觉差异。
