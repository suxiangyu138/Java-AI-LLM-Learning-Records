## 1. 依赖关系总图

```text
【地基层：几乎谁都依赖】
  线性结构 ───────────────→ 几乎所有结构类专题
  复杂度分析（05 刷题实战）──→ 一切选型的判据
  递归基础 ──→ 分治 / 回溯 / DP / 树的遍历

【结构 → 结构】
  树结构 ──→ 堆 / 并查集 / 线段树 / 红黑树（高级数据结构）
  哈希结构 ──→ HashMap 类专题 / 字典树 / 布隆过滤器（工程视角）
  图结构 ──→ 图论进阶（最短路 / 网络流 / 连通性）

【思想 → 思想】
  递归 ──→ 分治 ──→ 归并排序 / 快速排序 / CDQ 分治
  递归 ──→ 回溯 ──→ 搜索专题 / 高级搜索（A* / IDA*）
  暴力枚举 ──→ 剪枝 ──→ 回溯 / 分支限界
  贪心 ──→ DP（先懂"局部最优≠全局最优"，才懂 DP 的"全局子问题"）
  双指针 ──→ 滑动窗口 / 单调队列 / 快慢指针
  位运算 ──→ 状态压缩 DP / 异或技巧 / 组合数奇偶性（Kummer）

【思想 → 结构（用结构实现思想）】
  分治思想 ──→ 线段树（区间分治） / 树状数组
  二分思想 ──→ 二分答案（最大值最小化） / 平衡树 / 二叉搜索树
  搜索思想 ──→ BFS 最短路径 / DFS 拓扑 / 二分图染色

【专题 → 专题（跨层组合）】
  快速幂 ──→ 矩阵快速幂（DP 加速） / 费马逆元（组合数） / 欧拉降幂
  欧几里得/exgcd ──→ 线性同余方程 / CRT（exLucas 依赖） / 扩展欧几里得求逆
  素数筛 ──→ 欧拉函数 / 莫比乌斯反演 / 大数分解（Miller-Rabin + Pollard-rho）
  组合数 ──→ Lucas / exLucas / 卡特兰（依赖快速幂、exgcd、CRT）
  拓扑排序 ──→ 有向无环图 DP / 差分约束（最短路模型）
  最短路 ──→ 差分约束 / 费用流（图论进阶）
```

### 1.1 依赖图的三个层次

| 层次 | 含义 | 管理方式 |
|------|------|------|
| 地基层 | 几乎被所有专题依赖 | 必须最先学、学到扎实（线性结构/复杂度/递归） |
| 主干层 | 被同层或上层依赖 | 学习顺序跟随依赖箭头 |
| 叶层 | 不依赖他人、被少依赖 | 可按需学（几何、随机化） |

## 2. 核心依赖链速查表

| 目标专题 | 直接前置（必须先会） | 间接前置（建议掌握） | 依赖原因 |
|------|------|------|------|
| 动态规划 DP | 递归、暴力枚举 | 贪心（对比理解） | 状态转移本质是递归定义 |
| 状态压缩 DP | 位运算、DP 基础 | 二进制枚举 | 用位表示子集状态 |
| 树形 DP | 树的遍历、DP 基础 | 递归 | 以子树为子问题 |
| 二分查找专题 | 数组、单调性概念 | 复杂度分析 | 前提是「有序可判」 |
| 堆与 TopK | 树结构（完全二叉树） | 排序算法 | 堆是数组实现的完全二叉树 |
| 图论专题 | 图结构（存储）、搜索 | BFS/DFS 熟练 | 一切图算法都建立在遍历上 |
| 最短路 Dijkstra | 图结构、堆 | 贪心思想 | 贪心性质 + 堆优化 |
| 网络流 | 图论、BFS/DFS | 最大流算法 | 增广路基于搜索 |
| 线段树/树状数组 | 分治、二叉树 | 二分 | 区间拆分即分治 |
| KMP/AC 自动机 | 字符串基础 | 双指针思想 | 失配指针利用前缀匹配 |
| 组合数、逆元 | 快速幂（费马逆元） | exgcd、素数筛 | 逆元是取模除法的基础设施 |
| exLucas | Lucas、CRT、exgcd | 欧拉函数 | 合数模 = 分解 + CRT |
| 卡特兰数 | 组合数、DP | 计数原理 | 卷积递推与 DP 同源 |
| 概率与期望 | 组合数、分数取模 | DP（期望 DP） | 期望题 = 概率 × 权重求和 |
| 随机算法 | 快速幂、素数筛 | 概率基础 | Miller-Rabin 依赖幂与概率判定 |
| 工程视角（05） | 全部结构类 | Java 集合源码 | 数据结构在 JDK 的落地 |

### 2.1 依赖链的「断裂检测」：学不动时的诊断

| 症状 | 依赖链断在哪 | 补救动作 |
|------|------|------|
| 卡特兰题看不懂 | 组合数 C(n,m) 不熟 | 回「组合数、逆元」00 精要 |
| DP 优化题卡住 | 单调队列/矩阵不熟 | 回 02 层双指针 + 快速幂进阶 |
| 线段树区间修改不会 | 分治思想没内化 | 先手写归并排序讲清分治 |
| 网络流看不懂 | BFS/DFS 增广路不熟 | 先刷 03 层搜索专题 |
| exLucas 崩溃 | CRT/exgcd 不熟 | 回「欧几里得 exgcd」01 篇 |

## 3. 交叉知识点地图

同一知识点在不同专题反复出现——认识交叉点，学习效率翻倍：

| 知识点 | 出现的专题 | 角色 |
|------|------|------|
| 单调栈 | 专题 3 栈队列、专题 1 数组字符串 | 「下一个更大元素」类 |
| 单调队列 | 专题 8 DP（滑动窗口最值优化）、专题 3 栈队列 | DP 优化 O(n) |
| 前缀和/差分 | 专题 1 数组、专题 8 DP、数学专题（组合数整除判定 P2822） | 区间查询标配 |
| 快慢指针 | 专题 2 链表、专题 5 堆、搜索思想 | 环检测 / 中位数 |
| 逆元 | 组合数、快速幂、概率期望、工程（分数取模） | 取模除法统一工具 |
| 矩阵快速幂 | 快速幂专题、DP 优化、图论（邻接矩阵幂 = 路径计数） | 线性递推加速 |
| 拓扑排序 | 专题 11 图、图论进阶、DP | DAG 依赖序 |
| 二分答案 | 二分专题、贪心、高级 DP | 「最大化最小」通用套路 |
| 并查集 | 树结构、图论、Kruskal | 连通性判断 |
| 欧拉函数 | 数论、快速幂（降幂）、组合数学 | 模运算的周期 |

### 3.1 交叉知识点的正确学习姿势

```text
第一次遇到（如在专题 3 见到单调栈）→ 当新知识点学透
第二次遇到（如 DP 优化里再见单调队列）→ 复习 + 记「新角色」
第三次遇到（如工程视角 Redis 里再见跳表）→ 建立跨域连接
⚠️ 误区：每次遇到都从头学 → 浪费时间；只当新知 → 断层
```

## 4. 按目标反推依赖：面试高频组合

面试难题 = 两个基础技能的「乘法」，最常见的组合有八组：

| 组合 | 代表题形态 | 破解思路 |
|------|------|------|
| DP + 单调队列 | 滑动窗口最大值的 DP 优化 | 状态转移是「固定窗口最值」时换单调队列 |
| DP + 矩阵快速幂 | 大 n 线性递推 | 转移写成矩阵，幂次加速 |
| 二分 + 贪心 | 最大化最小值 | 二分答案 + 检查函数 |
| 树形 DP + 背包 | 树上选点问题 | 子树做分组背包 |
| 图论 + DP | DAG 最长路、状态压缩旅行商 | 拓扑序保证无后效性 |
| 数论 + 组合 | 组合数取模全家桶 | Lucas/exLucas + CRT |
| 哈希 + 二分 | 字符串哈希判定回文/子串 | 哈希 O(1) 比较 + 二分长度 |
| 双指针 + 前缀和 | 子数组和恰好为 k | 哈希表存前缀和出现次数 |

> 💡 反推方法：遇到不会的难题，先问「这题 = 哪个基础技能 × 哪个进阶技能」——大多数压轴题都能拆成已知组合。拆成功 = 思路成型；拆不出来 = 缺前置，回 2.1 节诊断。

## 5. 依赖图谱的两大用途

### 5.1 用途一：规划学习顺序（正向）

```text
① 选定目标专题（如卡特兰数）
② 查「核心依赖链速查表」找直接前置（组合数、DP）
③ 前置缺什么补什么（组合数 → 快速幂 → exgcd/素数筛）
④ 学完目标后，回「交叉知识点地图」登记新出现的交叉点
```

### 5.2 用途二：拆解难题（逆向）

```text
① 读题 → 识别题面信号（前缀约束 → 卡特兰；最大化最小 → 二分答案）
② 拆组合：这题 = 信号 A × 信号 B（如「树上 + 选点」= 树形 DP + 背包）
③ 分别回忆两个技能的标准模板
④ 组合模板 → 伪代码 → 编码
```

### 5.3 依赖图谱的使用边界

| 边界 | 说明 |
|------|------|
| 不是权威拓扑 | 依赖顺序是「建议」不是「强制」——部分人可并行学习 |
| 不是全部关系 | 只收录「明显依赖」，弱关联（如排序与图）未列出 |
| 随体系演进 | 04 层新专题加入后需更新图谱 |

> 🎯 **核心要点**：依赖图谱的价值 = **规划学习顺序**（先学被依赖的）+ **拆解难题**（新题拆成已知依赖组合）。48 个主题中真正独立的概念不超过 15 个，其余都是它们的组合——掌握依赖链，等于把 671 篇文档压缩成 15 个源头。学不动时先查 2.1 断裂诊断，而不是硬啃。
