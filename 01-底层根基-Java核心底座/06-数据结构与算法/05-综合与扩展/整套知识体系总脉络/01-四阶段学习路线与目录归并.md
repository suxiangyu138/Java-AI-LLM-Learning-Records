## 2. 阶段一：前置基础（01 层）

### 2.1 目录归并：6 主题 → 4 块

| 归并块 | 主题目录 | 核心内容 | 必须掌握的三问 |
|------|------|------|------|
| 线性结构 | 线性结构 | 数组、链表、栈、队列、双端队列 | 连续 vs 链式？随机访问 vs 插入删除？场景？ |
| 树形结构 | 树结构 | 二叉树、BST、AVL、红黑树、堆、并查集 | 遍历顺序？退化条件？平衡如何达成？ |
| 图与散列 | 图结构 + 哈希（散列）结构 | 图的存储、遍历前置；哈希冲突 | 邻接表 vs 矩阵？冲突解决方式？ |
| 特殊载体 | 矩阵 + 字符串基础 | 二维结构；字符串不可变性与操作 | 下标变换？不可变影响？ |

### 2.2 每块的学习动作（具体到可执行）

| 块 | 动手练习 | 完成标志 |
|------|------|------|
| 线性结构 | 手写单链表增删改查；用数组模拟栈/队列 | 无参考能写出，且能讲清「栈空/栈满」处理 |
| 树形结构 | 手写四种遍历（递归 + 迭代）；手写并查集 | 中序遍历迭代版（显式栈）能 AC |
| 图与散列 | 手写邻接表建图；设计一个哈希冲突方案 | 能画出「链地址法」插入过程 |
| 特殊载体 | 矩阵转置/旋转手写；字符串常用 API 过一遍 | 旋转 90° 矩阵 10 分钟内完成 |

### 2.3 阶段终点自测（30 秒口试）

| 题目 | 标准答案要点 |
|------|------|
| HashMap 冲突怎么解决？ | 链地址（+ JDK8 树化），讲清负载因子 0.75 |
| BST 退化条件？ | 按有序序列插入 → 斜树 O(n)；平衡树解决 |
| 堆的性质？ | 完全二叉树、父 ≤ 子（小顶）、堆顶极值 O(1) |
| 链表 vs 数组选型？ | 随机访问数组 O(1)；头部增删链表 O(1) |
| 图的两种存储？ | 邻接矩阵 O(V²) 空间、邻接表 O(V+E) 空间 |

## 3. 阶段二：基础思想（02 层）

### 3.1 目录归并：14 主题 → 6 块

| 归并块 | 主题目录 | 学习顺序 | 块内依赖 |
|------|------|:---:|------|
| 暴力起点 | 暴力枚举（Brute Force） | 1 | 一切正确性的基准 |
| 递归与迭代 | 递归基础、迭代 | 2 | 递归先于分治/回溯 |
| 分治二分 | 分治思想、二分思想 | 3 | 归并排序是最佳练习 |
| 搜索体系 | 搜索思想、回溯算法、分支限界 | 4 | 回溯 = 搜索 + 撤销 |
| 贪心与 DP | 贪心算法、动态规划 DP | 5 | 贪心先行，DP 承接 |
| 指针与位运算 | 双指针、滑动窗口、位运算、排序算法 | 6 | 滑动窗口 = 双指针变种 |

### 3.2 各思想一句话定位与边界（本阶段最重要的产出）

| 思想 | 一句话 | 与相邻思想的边界 | 反例/坑 |
|------|------|------|------|
| 暴力 | 枚举所有可能，先保证正确 | 一切优化的起点 | 不优化直接交 → TLE |
| 递归 | 大问题化同构子问题 | 递归是「栈」的天然朋友 | 忘递归出口 → 爆栈 |
| 分治 | 拆 → 解 → 合 | 子问题**互相独立**；依赖则不是分治 | 合并逻辑错 = 全错 |
| 二分 | 单调性换对数时间 | 答案二分 vs 下标二分的区分 | mid 死循环 |
| 回溯 | DFS + 剪枝的穷举 | 求**所有解**用回溯，求**一个最优**用 DP/贪心 | 忘撤销 = 状态污染 |
| 贪心 | 每步局部最优 | 局部最优 = 全局最优才成立（需证明） | 硬币 11/5/1 反例 |
| DP | 重叠子问题 + 记忆化 | 有重叠子问题用 DP，无重叠用分治 | 状态漏维度 |
| 双指针 | 单调区间滑动 | 有窗口约束用滑动窗口，无约束用双指针 | 指针越界 |
| 位运算 | 二进制层面的技巧 | 状态压缩 DP 的前置 | 符号位右移 |

### 3.3 阶段终点自测（14 选 7 抽查）

| 题目 | 标准答案要点 |
|------|------|
| 快排为什么不稳定？ | 分区交换打乱相等元素相对序 |
| 贪心和 DP 的区别？ | 贪心无回头，DP 保留全部子问题解 |
| 什么时候用 BFS？ | 无权最短路、逐层扩散 |
| 递归转迭代的两种方法？ | 显式栈、尾递归 |
| 二分的前提？ | 单调性（或答案的检查函数单调） |
| 位运算求奇偶？ | `x & 1` |
| 分治的复杂度公式？ | T(n) = aT(n/b) + f(n)，主定理 |

## 5. 阶段四：中高级专题（04 层）

### 5.1 目录归并：7 专题 → 2 条线

| 主线 | 专题 | 定位 |
|------|------|------|
| 难度扩展线 | 1 高级 DP（树形/状压/数位）、2 高级搜索（A*/IDA*）、5 图论进阶（网络流/连通性） | 把三阶段的「思想」推向竞赛难度 |
| 知识补盲线 | 3 字符串高级算法（KMP/AC 自动机/后缀）、4 高级数据结构（线段树/树状数组/平衡树）、6 数学 & 概率（数论/组合/概率）、7 随机化与杂题 | 补齐面试涉及但高频层未覆盖的领域 |

### 5.2 数学专题内部脉络（04 层专题 6 的 12 个子专题）

```text
素数筛（线性筛） → 欧几里得/exgcd（逆元·CRT 基础） → 快速幂（费马逆元·矩阵加速）
→ 组合数、逆元（Lucas/exLucas/卡特兰） → 组合数学（生成函数/计数）
→ 数论（同余/CRT/欧拉） → 概率与统计（期望/随机过程）
→ 几何、博弈、随机算法（计算几何/博弈论/随机化）
```

依赖方向：**数论是地基（模运算、互质、同余），组合是主干（计数、选型、卡特兰），概率是应用（期望 DP、随机算法）**。这 12 个子专题在目录里分布为「专题 6：数学 & 概率算法」下的 12 个独立目录 + 相邻的同名目录。

### 5.3 阶段终点自测

| 检查项 | 达标线 |
|------|------|
| 模板题 | Lucas、线段树、KMP、Dijkstra、网络流独立 AC |
| 边界认知 | 每个高级算法能说出适用边界与退化场景（线段树 vs 树状数组） |
| 组合能力 | 能把压轴题拆成「基础技能 × 进阶技能」的组合 |

### 6.3 目录归并说明（48 → 33 主题）

四层 39 个主题目录中，语义重叠者归并后约 33 个主题：

| 归并逻辑 | 示例 |
|------|------|
| 思想 + 专题重复 | 「滑动窗口」并入「双指针」；「二分思想」与「专题 10 二分查找」合一 |
| 结构 + 专题重复 | 「树结构」与「专题 4 树」分层学习、合题复习 |
| 跨层同题 | 「数学 & 概率」目录下 12 子专题与「数论」「组合数学」等独立目录互相对应 |

> 💡 归并的目的不是删目录，而是**避免重复学习**：思想层学「为什么」，专题层学「怎么考」，横向层学「怎么串」。同一知识出现三次是设计，不是冗余。

> 🎯 **核心要点**：四阶段 = 6 + 14 + 12 + 7 的推进顺序，每阶段有明确的自测题与完成标志。路线不是「目录顺序」，而是**依赖链顺序**——阶段一给阶段二载体，阶段二给阶段三思维，阶段三给阶段四套路。用本文的「自测表」卡进度：答不出自测题就补该阶段，答得出再进下一阶段，路线就不会走歪。
