## 4. 层级定位与设计逻辑

### 4.1 为什么这样分五层

| 设计原则 | 说明 |
|------|------|
| 结构先于思想 | 没见过二叉树，谈何遍历？01 层保证「载体」齐备 |
| 思想先于专题 | 不懂 DP 的状态定义，专题题解只是背答案；02 层解决「思维工具」 |
| 专题对齐面试 | 03 层按面试出题频率组织，每专题固定「精要→进阶→题解」三段式 |
| 高级层保上限 | 04 层覆盖竞赛与压轴题：Lucas、网络流、后缀数组、随机化等 |
| 横向层做减法 | 05 层把四层的知识「去重、对比、串线」，防止学了就忘 |

### 4.2 三层递进关系（知识 → 技能 → 素养）

| 层面 | 对应层级 | 产出物 | 检验标准 |
|------|:---:|------|------|
| 知识 | 01 + 02 | 概念与原理 | 能讲清定义、复杂度、适用边界 |
| 技能 | 03 + 04 | 解题模板与套路 | 独立 AC 高频题，说清选型理由 |
| 素养 | 05 | 方法论与工程观 | 面对新题有完整分析流程，不背模板也能推理 |

### 4.3 层级边界的判定（防止「该学的没学、不该学的学歪」）

| 判断问题 | 判定 |
|------|------|
| 这道题属于哪个层级的知识？ | 结构题 → 01；思想题 → 02；套路题 → 03；难题 → 04 |
| 学不会时去哪查？ | 思想不懂查 02 层对应目录；模板不懂查 03 层专题 |
| 哪些内容不在这五层里？ | 语言细节（集合源码）→ 工程视角扩展 01 篇；数据库 → 03 篇 |

| 算法常见坑点汇总 | 排雷：哪里容易错、怎么写对 | [算法常见坑点汇总](../算法常见坑点汇总/00-算法常见坑点总览.md) |
| 易混淆知识点对比汇总 | 辨析：两个概念到底差在哪 | [易混淆知识点对比汇总](../易混淆知识点对比汇总/00-易混淆知识点对比总览.md) |
| 工程视角扩展 | 落地：算法在 JDK/中间件/数据库里怎么用 | [工程视角扩展](../工程视角扩展/00-工程视角扩展总览.md) |

### 5.1 五个横向系统的配合方式

```text
学习时（纵向）：01 → 02 → 03 → 04 逐层推进
复盘时（横向）：
  刚学完一个专题 → 查「易混淆对比」（概念分清了吗）
  刚做完一套题   → 查「坑点汇总」（该踩的坑踩了吗）
  卡在某类题    → 查「做题分析流程」（五步法哪步断了）
  面试前一周    → 通读「总脉络」+ 五系统 00 篇
  进阶后端      → 走「工程视角扩展」四篇
```

> 💡 使用建议：横向层不是学习负担，是防遗忘的锚点——**每学完一个专题，回 05 层对应的汇总表「对一遍账」**。
