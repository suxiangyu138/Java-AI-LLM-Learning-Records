## 一、堆排序

### 1.1 堆的核心概念

| 类型 | 定义 |
|------|------|
| **完全二叉树** | 除最后一层外，所有层节点填满，最后一层靠左排列 |
| **大顶堆** | 父节点 >= 子节点，堆顶为最大值 |
| **小顶堆** | 父节点 <= 子节点，堆顶为最小值 |

### 1.2 堆的存储（数组）

| 节点 | 下标计算 |
|------|----------|
| 左子节点 | 2i + 1 |
| 右子节点 | 2i + 2 |
| 父节点 | (i - 1) / 2 |

### 1.3 核心操作

| 操作 | 说明 | 时间复杂度 |
|------|------|------------|
| **堆化（heapify）** | 维护堆性质 | O(log n) |
| **建堆（build-heap）** | 将数组转为堆 | O(n) |
| **堆排序** | 循环取堆顶 + 堆化 | O(n log n) |

### 1.4 堆排序完整实现

```java
public class HeapSort {
    public void sort(int[] arr) {
        if (arr == null || arr.length <= 1) return;
        int n = arr.length;
        // 1. 建堆：从最后一个非叶子节点向上堆化
        for (int i = n / 2 - 1; i >= 0; i--) {
            heapify(arr, n, i);
        }
        // 2. 排序：交换堆顶与末尾，堆化剩余元素
        for (int i = n - 1; i > 0; i--) {
            swap(arr, 0, i);
            heapify(arr, i, 0);
        }
    }

    private void heapify(int[] arr, int len, int i) {
        int largest = i;
        int left = 2 * i + 1;
        int right = 2 * i + 2;
        if (left < len && arr[left] > arr[largest]) largest = left;
        if (right < len && arr[right] > arr[largest]) largest = right;
        if (largest != i) {
            swap(arr, i, largest);
            heapify(arr, len, largest);
        }
    }

    private void swap(int[] arr, int i, int j) {
        int temp = arr[i]; arr[i] = arr[j]; arr[j] = temp;
    }
}
```

#### TopK 问题（高频面试）

| 维度 | 说明 |
|------|------|
| **场景** | 求前 K 大/小元素、热点排行、热门搜索 |
| **复杂度** | O(n log k)，远优于全排序 O(n log n) |

```java
public int findKthLargest(int[] nums, int k) {
    PriorityQueue<Integer> heap = new PriorityQueue<>();
    for (int num : nums) {
        heap.add(num);
        if (heap.size() > k) heap.poll();
    }
    return heap.peek();
}
```

| 场景 | 说明 |
|------|------|
| **海量数据排序** | 原地排序 O(1) 空间，适合内存受限场景 |
| **流式数据处理** | 实时维护堆结构，支持实时排行榜 |
| **外部排序优化** | 多路归并 + 堆排序加速合并阶段 |

> 堆排序时间复杂度稳定 O(n log n)、空间 O(1)，适合内存受限场景和 TopK，但实际速度慢于快排（常数因子较大），且不稳定。

## 二、快速排序

### 2.1 分治三步骤

| 步骤 | 说明 |
|------|------|
| **分解** | 选取 pivot，将数组划分为小于 pivot、等于 pivot、大于 pivot 三部分 |
| **解决** | 递归排序左右子区间 |
| **合并** | 子区间有序则整体有序，无需额外合并 |

### 2.2 分区方式

| 分区方式 | 说明 | 特点 |
|----------|------|------|
| **单向分区** | 单指针遍历，将小于 pivot 元素交换到左侧 | 简单直观 |
| **双向分区（推荐）** | 双指针相向遍历，减少交换次数 | 效率更高 |
| **随机基准** | 随机选择 pivot，避免最坏情况 | 保证期望 O(n log n) |

### 2.3 完整实现（随机基准 + 双向分区）

```java
public class QuickSort {
    public void sort(int[] arr) {
        if (arr == null || arr.length <= 1) return;
        quickSort(arr, 0, arr.length - 1);
    }

    private void quickSort(int[] arr, int left, int right) {
        if (left >= right) return;
        int pivotIndex = randomPartition(arr, left, right);
        quickSort(arr, left, pivotIndex - 1);
        quickSort(arr, pivotIndex + 1, right);
    }

    private int randomPartition(int[] arr, int left, int right) {
        int randomIndex = left + (int) (Math.random() * (right - left + 1));
        swap(arr, randomIndex, right);
        return partition(arr, left, right);
    }

    private int partition(int[] arr, int left, int right) {
        int pivot = arr[right];
        int i = left - 1;
        for (int j = left; j < right; j++) {
            if (arr[j] <= pivot) {
                i++;
                swap(arr, i, j);
            }
        }
        swap(arr, i + 1, right);
        return i + 1;
    }

    private void swap(int[] arr, int i, int j) {
        int temp = arr[i]; arr[i] = arr[j]; arr[j] = temp;
    }
}
```

### 2.4 JDK 双轴快排

JDK `Arrays.sort()` 对基础类型采用双轴快排（Dual-Pivot QuickSort）：

| 优化手段 | 说明 |
|----------|------|
| **双基准** | 选取两个 pivot，划分为三区间，减少递归深度 |
| **插入排序优化** | 小规模数据（<= 47）直接用插入排序，常数因子更小 |
| **哨兵机制** | 避免边界检查，提升效率 |

### 2.5 快速选择算法（QuickSelect）

基于快排分区思想，平均 O(n) 找第 K 大/小元素：

```java
public int findKthSmallest(int[] arr, int k) {
    return quickSelect(arr, 0, arr.length - 1, k - 1);
}

private int quickSelect(int[] arr, int left, int right, int k) {
    if (left == right) return arr[left];
    int pivot = randomPartition(arr, left, right);
    if (k == pivot) return arr[k];
    else if (k < pivot) return quickSelect(arr, left, pivot - 1, k);
    else return quickSelect(arr, pivot + 1, right, k);
}
```

### 2.6 优化策略

| 优化手段 | 说明 |
|----------|------|
| **随机基准** | 避免已排序/逆序输入导致最坏情况 |
| **三向切分** | 处理大量重复元素，接近 O(n) |
| **插入排序兜底** | n <= 47 时切换到插入排序 |
| **尾递归优化** | 减少递归栈深度 |

**三向切分（Dutch National Flag）：**

```java
private void threeWayPartition(int[] arr, int left, int right) {
    int pivot = arr[left];
    int lt = left, gt = right, i = left + 1;
    while (i <= gt) {
        if (arr[i] < pivot) swap(arr, lt++, i++);
        else if (arr[i] > pivot) swap(arr, i, gt--);
        else i++;
    }
    quickSort(arr, left, lt - 1);
    quickSort(arr, gt + 1, right);
}
```

### 2.7 性能分析

| 情况 | 条件 | 复杂度 |
|------|------|--------|
| **最好情况** | 平衡分区 | O(n log n) |
| **平均情况** | 随机基准 | O(n log n) |
| **最坏情况** | 极端分区 | O(n^2)（概率可忽略） |

| 维度 | 值 |
|------|----|
| 空间复杂度 | O(log n)（递归栈） |
| 稳定性 | **不稳定** |

> 快速排序是工程中综合性能最优的内部排序算法，实际运行速度远超堆排序和归并排序，是 JDK 基础类型排序的首选实现。

## 三、线性时间排序

线性时间排序不依赖元素比较，利用元素值分布特性实现排序，可突破 O(n log n) 下限达到 O(n)。

### 3.1 计数排序（Counting Sort）

```java
public class CountingSort {
    public void sort(int[] arr) {
        if (arr == null || arr.length <= 1) return;
        int max = arr[0], min = arr[0];
        for (int num : arr) { max = Math.max(max, num); min = Math.min(min, num); }
        int range = max - min + 1;
        int[] count = new int[range];
        for (int num : arr) count[num - min]++;
        // 前缀和（保证稳定性）
        for (int i = 1; i < range; i++) count[i] += count[i - 1];
        // 逆序遍历（保证稳定性）
        int[] res = new int[arr.length];
        for (int i = arr.length - 1; i >= 0; i--) {
            int num = arr[i];
            res[count[num - min] - 1] = num;
            count[num - min]--;
        }
        System.arraycopy(res, 0, arr, 0, arr.length);
    }
}
```

### 3.2 桶排序（Bucket Sort）

```java
public class BucketSort {
    public void sort(int[] arr) {
        if (arr == null || arr.length <= 1) return;
        int max = arr[0], min = arr[0];
        for (int num : arr) { max = Math.max(max, num); min = Math.min(min, num); }
        int bucketNum = arr.length;
        List<List<Integer>> buckets = new ArrayList<>(bucketNum);
        for (int i = 0; i < bucketNum; i++) buckets.add(new ArrayList<>());
        for (int num : arr) {
            int index = (num - min) * (bucketNum - 1) / (max - min);
            buckets.get(index).add(num);
        }
        int idx = 0;
        for (List<Integer> bucket : buckets) {
            Collections.sort(bucket);
            for (int num : bucket) arr[idx++] = num;
        }
    }
}
```

### 3.3 基数排序（Radix Sort）

```java
public class RadixSort {
    public void sort(int[] arr) {
        if (arr == null || arr.length <= 1) return;
        int max = arr[0];
        for (int num : arr) max = Math.max(max, num);
        for (int exp = 1; max / exp > 0; exp *= 10) {
            countingSortByDigit(arr, exp);
        }
    }

    private void countingSortByDigit(int[] arr, int exp) {
        int[] count = new int[10];
        int[] res = new int[arr.length];
        for (int num : arr) count[(num / exp) % 10]++;
        for (int i = 1; i < 10; i++) count[i] += count[i - 1];
        for (int i = arr.length - 1; i >= 0; i--) {
            int digit = (arr[i] / exp) % 10;
            res[count[digit] - 1] = arr[i];
            count[digit]--;
        }
        System.arraycopy(res, 0, arr, 0, arr.length);
    }
}
```

### 3.4 性能对比

| 算法 | 适用场景 | 优势 | 局限 |
|------|---------|------|------|
| **计数排序** | 整数范围小（如 0~1000） | 实现简单、速度最快 | 范围过大空间开销高 |
| **桶排序** | 数据分布均匀 | 可并行化 | 分布不均退化为 O(n log n) |
| **基数排序** | 位数固定的整数/字符串 | 范围大仍高效 | 实现较复杂 |

### 3.5 后端选型原则

1. **整数范围小（k <= n）**：计数排序
2. **数据分布均匀**：桶排序
3. **位数固定的整数/字符串**：基数排序
4. **通用场景**：快排 / 归并排序

## 四、中位数和顺序统计量

**顺序统计量**指集合中第 k 小元素。**中位数**是特殊顺序统计量：n 为奇数取第 `(n+1)/2` 小元素，偶数取第 `n/2` 和第 `n/2+1` 小元素的平均值。

> 核心理念：无需全量排序即可快速定位目标元素。

### 4.1 最小值 / 最大值查找

```java
public class MinMaxUtils {
    public static <T extends Comparable<T>> T findMin(Collection<T> c) {
        if (c == null || c.isEmpty()) throw new IllegalArgumentException("集合不能为空");
        T min = null;
        for (T e : c) {
            if (e == null) continue;
            if (min == null || e.compareTo(min) < 0) min = e;
        }
        if (min == null) throw new IllegalArgumentException("无有效元素");
        return min;
    }

    // 同时查找最小值和最大值（优化比较次数）
    public static <T extends Comparable<T>> MinMax<T> findMinAndMax(Collection<T> c) {
        if (c == null || c.isEmpty()) throw new IllegalArgumentException("集合不能为空");
        T min = null, max = null;
        int count = 0;
        for (T e : c) {
            if (e == null) continue;
            if (count == 0) { min = e; max = e; count++; continue; }
            if (e.compareTo(min) < 0) min = e;
            else if (e.compareTo(max) > 0) max = e;
        }
        if (min == null || max == null) throw new IllegalArgumentException("无有效元素");
        return new MinMax<>(min, max);
    }

    public static class MinMax<T> {
        private final T min; private final T max;
        public MinMax(T min, T max) { this.min = min; this.max = max; }
        public T getMin() { return min; } public T getMax() { return max; }
    }
}
```

### 4.2 随机化选择算法（RANDOMIZED-SELECT）

基于快排分区思想，期望时间复杂度 O(n)。

```java
public class RandomizedSelectUtils {
    private static final Random RANDOM = new Random();

    public static int findKthSmallest(int[] arr, int k) {
        if (arr == null || arr.length == 0) throw new IllegalArgumentException("数组不能为空");
        int n = arr.length;
        if (k < 1 || k > n) throw new IllegalArgumentException("k 超出范围");
        int[] copyArr = Arrays.copyOf(arr, arr.length);
        return randomizedSelect(copyArr, 0, n - 1, k - 1);
    }

    private static int randomizedSelect(int[] arr, int left, int right, int k) {
        if (left == right) return arr[left];
        int pivotIndex = randomizedPartition(arr, left, right);
        if (pivotIndex == k) return arr[pivotIndex];
        else if (pivotIndex > k) return randomizedSelect(arr, left, pivotIndex - 1, k);
        else return randomizedSelect(arr, pivotIndex + 1, right, k);
    }

    private static int randomizedPartition(int[] arr, int left, int right) {
        int r = left + RANDOM.nextInt(right - left + 1);
        swap(arr, r, right);
        return partition(arr, left, right);
    }

    private static int partition(int[] arr, int left, int right) {
        int pivot = arr[right];
        int i = left - 1;
        for (int j = left; j < right; j++) {
            if (arr[j] <= pivot) swap(arr, ++i, j);
        }
        swap(arr, i + 1, right);
        return i + 1;
    }

    private static void swap(int[] arr, int i, int j) {
        int t = arr[i]; arr[i] = arr[j]; arr[j] = t;
    }

    // 查找中位数（自动处理奇偶长度）
    public static double findMedian(int[] arr) {
        int n = arr.length;
        if (n % 2 == 1) return findKthSmallest(arr, (n + 1) / 2);
        else return (findKthSmallest(arr, n / 2) + findKthSmallest(arr, n / 2 + 1)) / 2.0;
    }
}
```

### 4.3 流式数据中位数（双堆模型）

大顶堆存左半部分，小顶堆存右半部分，插入 O(log n)，查询 O(1)：

```java
public class StreamingMedian {
    private final PriorityQueue<Integer> maxHeap = new PriorityQueue<>((a, b) -> b - a);
    private final PriorityQueue<Integer> minHeap = new PriorityQueue<>();

    public void addNum(int num) {
        maxHeap.offer(num);
        if (!minHeap.isEmpty() && maxHeap.peek() > minHeap.peek()) {
            minHeap.offer(maxHeap.poll());
        }
        if (maxHeap.size() - minHeap.size() > 1) {
            minHeap.offer(maxHeap.poll());
        } else if (minHeap.size() - maxHeap.size() > 1) {
            maxHeap.offer(minHeap.poll());
        }
    }

    public double findMedian() {
        if (maxHeap.size() == minHeap.size()) {
            return (maxHeap.peek() + minHeap.peek()) / 2.0;
        }
        return maxHeap.size() > minHeap.size() ? maxHeap.peek() : minHeap.peek();
    }
}
```

### 4.4 两个有序数组的中位数

使用分治思想，时间复杂度 O(log min(m, n))：

```java
public class MedianOfTwoSortedArrays {
    public double findMedianSortedArrays(int[] nums1, int[] nums2) {
        if (nums1.length > nums2.length) return findMedianSortedArrays(nums2, nums1);
        int m = nums1.length, n = nums2.length;
        int left = 0, right = m;
        while (left <= right) {
            int i = (left + right) / 2;
            int j = (m + n + 1) / 2 - i;
            int maxLeft1 = (i == 0) ? Integer.MIN_VALUE : nums1[i - 1];
            int minRight1 = (i == m) ? Integer.MAX_VALUE : nums1[i];
            int maxLeft2 = (j == 0) ? Integer.MIN_VALUE : nums2[j - 1];
            int minRight2 = (j == n) ? Integer.MAX_VALUE : nums2[j];
            if (maxLeft1 <= minRight2 && maxLeft2 <= minRight1) {
                if ((m + n) % 2 == 1) return Math.max(maxLeft1, maxLeft2);
                else return (Math.max(maxLeft1, maxLeft2) + Math.min(minRight1, minRight2)) / 2.0;
            } else if (maxLeft1 > minRight2) right = i - 1;
            else left = i + 1;
        }
        throw new IllegalArgumentException("输入数组不是有序数组");
    }
}
```

### 5.3 后端场景选型

| 场景 | 推荐算法 | 原因 |
|------|----------|------|
| **基础类型大规模数据** | 双轴快排（JDK 默认） | 高效、原地排序 |
| **对象排序（需稳定）** | 归并排序 / TimSort | 稳定、适合对象比较 |
| **内存受限场景** | 堆排序 | 原地排序，空间 O(1) |
| **TopK 问题** | 堆排序 / 快速选择 | O(n log k) / O(n) |
| **整数范围集中数据** | 计数排序 | 线性时间复杂度 |
| **近乎有序数据** | 插入排序 | 最好 O(n)，效率极高 |
| **海量数据外部排序** | 归并排序 | 分治策略支持分块 |

> **生产环境优先使用 JDK 内置排序**（`Arrays.sort()` / `Collections.sort()`）。面试重点掌握：快排实现（随机基准 + 双向分区）、堆排原理（建堆 + 堆化 + TopK）、归并排序（分治 + 合并）、计数排序（前缀和 + 稳定），以及中位数与顺序统计量的快速选择算法和双堆模型。
