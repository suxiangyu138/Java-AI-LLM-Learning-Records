## 3. 学习路线推荐

### 🟢 路线 A：零基础入门（1 周）
```
01 基础 → 344 反转 → 125 回文 → 14 公共前缀
→ 242 异位词 → 151 单词反转
```
- **目标**：掌握字符串基础操作与双指针应用
- **题量**：约 8-10 题

### 🟡 路线 B：面试冲刺（1-2 周）
```
01 速过 → 02 双指针回文（5题）
→ 滑窗类（3 无重复/76 覆盖）→ DP 类（5 回文/1143 LCS）
→ 05 高频复盘
```
- **目标**：四大模式覆盖 70% 字符串题
- **题量**：约 15-20 题

### 🔴 路线 C：全面掌握（2-3 周）
```
完整 01→05 + KMP 手撕（28 题）
→ Manacher（5 题最优解）
→ 滚动哈希（214/686）
→ 字符串 DP 专项（10 正则/44 通配符）
```
- **目标**：字符串全部经典算法可手写
- **题量**：约 25-30 题

## 4. 核心概念速查

| 概念 | 一句话解释 | 典型例题 |
|------|-----------|------|
| **不可变性** | String 创建后不可改 | 拼接用 StringBuilder |

| **计数数组** | 26 字符频次比较 | 242/49 |
