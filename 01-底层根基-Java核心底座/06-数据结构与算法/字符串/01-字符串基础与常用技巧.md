## 1. String 的不可变性

### 1.1 什么是不可变

```
Java String 是 final 类，创建后内容不可修改
  每次"修改"都是创建新对象

String s = "hello";
s = s + " world";     // ⚠️ 创建了新字符串 "hello world"
                      // 原来的 "hello" 变成垃圾

内存影响：
  拼接 n 次 → 创建 n 个中间对象 → O(n²) 时间和 GC 压力
```

### 1.2 为什么 String 设计成不可变？

| 原因 | 说明 |
|------|------|
| **安全** | 网络地址/文件路径等不可篡改 |
| **缓存** | hashCode 缓存（字符串池） |
| **线程安全** | 不可变天然线程安全 |
| **字符串池** | 相同字面量共享同一对象 |

### 1.3 面试必答：三种拼接对比

```java
// ❌ 循环内 + 拼接（O(n²) 性能杀手）
String s = "";
for (int i = 0; i < 10000; i++) {
    s += i;              // 每次都创建新对象！
}

// ✅ StringBuilder（O(n) 推荐）
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 10000; i++) {
    sb.append(i);
}
String result = sb.toString();

// ✅ StringBuffer = StringBuilder + 线程安全（同步开销）
// 单线程场景用 StringBuilder，多线程用 StringBuffer
```

## 2. StringBuilder 高效拼接

### 2.1 常用 API

```java
StringBuilder sb = new StringBuilder();       // 空
StringBuilder sb2 = new StringBuilder("abc"); // 初始内容

sb.append("x");              // 追加 → "abcx"
sb.insert(1, "Y");           // 插入 → "aYbcx"
sb.delete(1, 3);             // 删除 [1,3) → "ax"
sb.reverse();                // 反转 → "xa"
sb.setCharAt(0, 'Z');        // 改字符 → "Za"
sb.length();                 // 长度
sb.toString();               // 转 String

// 回溯常用（配合回溯算法体系）
sb.setLength(sb.length() - 1);   // 删除最后一个字符（撤销选择）
```

### 2.2 面试高频用法

```java
// ① 反转字符串
String reversed = new StringBuilder(s).reverse().toString();

// ② 回溯路径拼接（回溯体系常用）
void backtrack(StringBuilder path) {
    path.append(c);
    backtrack(path);
    path.setLength(path.length() - 1);    // 撤销
}

// ③ 字符频率统计键（49 题异位词）
StringBuilder key = new StringBuilder();
for (int i = 0; i < 26; i++) key.append('#').append(count[i]);
```

## 3. 字符串与数组/数字转换

### 3.1 字符串 ↔ 字符数组

```java
// String → char[]
char[] chars = s.toCharArray();       // 最常用
char c = s.charAt(i);                 // 单字符访问

// char[] → String
String s1 = new String(chars);
String s2 = String.valueOf(chars);

// ⚠️ 注意：charAt 返回基本类型，toCharArray 返回引用
// 修改 char[] 不影响原字符串（不可变性！）
```

### 3.2 字符串 ↔ 数字

```java
// String → int/long/double
int num = Integer.parseInt("123");
long big = Long.parseLong("9999999999");
double d = Double.parseDouble("3.14");

// int/long → String
String s = Integer.toString(123);
String s2 = String.valueOf(123);       // 通用（对象/基本类型都行）
String s3 = 123 + "";                  // 隐式转换（面试可写）

// ⚠️ 溢出防护：大数用 Long.parseLong
// 边界：parseInt("") 抛 NumberFormatException → 先判空
```

### 3.3 进制转换

```java
// 十进制 → 其他进制
String bin = Integer.toBinaryString(10);    // "1010"
String hex = Integer.toHexString(255);      // "ff"
String oct = Integer.toOctalString(8);      // "10"

// 其他进制 → 十进制
int num = Integer.parseInt("1010", 2);      // 10
int hexNum = Integer.parseInt("ff", 16);    // 255

// 面试题：手动进制转换（7 进制/26 进制）
```

## 4. 常用 API 速查

### 4.1 String 核心 API

```java
s.length();                    // 长度（不是 size！）
s.isEmpty();                   // 判空
s.charAt(i);                   // 取字符
s.substring(1, 3);             // 子串 [1,3)
s.indexOf("bc");               // 查找首次出现
s.lastIndexOf('c');            // 查找最后出现
s.contains("bc");              // 是否包含
s.startsWith("a");             // 前缀
s.endsWith("z");               // 后缀
s.equals("abc");               // 内容比较（不是 ==！）
s.equalsIgnoreCase("ABC");     // 忽略大小写
s.compareTo("abd");            // 字典序比较
s.toUpperCase();               // 转大写
s.toLowerCase();               // 转小写
s.trim();                      // 去首尾空格
s.replace('a', 'b');           // 替换字符
s.replaceAll("\\d", "#");      // 正则替换
s.split(",");                  // 分割
s.toCharArray();               // 转字符数组
```

### 4.2 高频坑：equals vs ==

```java
// == 比较引用（地址），equals 比较内容
String a = "abc";
String b = "abc";
a == b        // true（字符串池共享同一对象）
String c = new String("abc");
a == c        // false！不同对象
a.equals(c)   // true 内容相同

// ⚠️ 面试必答：String 比较永远用 equals
```

### 4.3 字符操作

```java
Character.isLetter(c);        // 是否字母
Character.isDigit(c);         // 是否数字
Character.isLetterOrDigit(c); // 字母或数字（125 题用）
Character.isWhitespace(c);    // 是否空白
Character.toLowerCase(c);     // 转小写
Character.toUpperCase(c);     // 转大写
c - 'a';                      // 字母转下标（0-25）
(char)('a' + i);              // 下标转字母
c - '0';                      // 数字字符转 int
```

## 5. 高频操作模板

### 5.1 字符计数模板（异位词判断）

```java
// 统计字符频次（26 数组或 HashMap）
int[] count = new int[26];
for (char c : s.toCharArray()) {
    count[c - 'a']++;
}

// 比较两个字符串是否异位词（242 题）
boolean isAnagram = Arrays.equals(count1, count2);
```

### 5.2 字符串分割处理模板

```java
// 按分隔符分割 + 过滤空串
String[] parts = path.split("/");
for (String part : parts) {
    if (part.isEmpty()) continue;      // 跳过空段（71 题）
}

// 单词反转（151 题）
String[] words = s.trim().split("\\s+");   // 多个空格
```

### 5.3 遍历模板

```java
// 基本遍历
for (int i = 0; i < s.length(); i++) {
    char c = s.charAt(i);
}

// 增强 for（需转数组）
for (char c : s.toCharArray()) { ... }

// 反向遍历
for (int i = s.length() - 1; i >= 0; i--) { ... }
```

> 🎯 **核心要点**：字符串基础的核心是**不可变性**（拼接用 StringBuilder）和**常用 API**（substring/split/equals）。面试手写字符串题时：比较内容用 `equals`、拼接用 `StringBuilder`、字符转下标用 `c-'a'`、数字转换用 `parseInt`（注意溢出与空串）。这些细节决定了手写代码的质量分。
