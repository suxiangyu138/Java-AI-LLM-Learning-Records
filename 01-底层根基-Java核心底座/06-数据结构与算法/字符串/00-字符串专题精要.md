## 1. 核心概念

### 1.1 字符串的特点

```
不可变（Java String）→ 拼接用 StringBuilder
子串/字符操作 O(n)
编码：ASCII/Unicode/UTF-8

⚠️ 70% 字符串题可归为四大模式：
  滑动窗口 / 双指针 / DP / 回溯
  → 先识别模式再套模板（通用方法论）
```

### 1.2 识别信号

```
"最长/最短子串" → 滑动窗口（3/76）
"两个串的关系" → DP（1143/72）
"所有组合/分割" → 回溯（17/131）
"反转/回文验证" → 双指针（344/125）
"匹配/查找" → KMP/哈希（28）
"异位词/频率" → 计数（242/49）

⚠️ 模式识别是字符串题的灵魂
```

### 1.3 面试定位

```
字符串与数组并驾齐驱的核心考点
  （字节/美团/腾讯/百度）

高频题：3 无重复子串、5 最长回文、125 回文验证
进阶：76 最小覆盖、72 编辑距离、28 KMP

⚠️ 准备策略：
  四大模式模板 + 三大专项（KMP/Manacher/滚动哈希）
```

## 2. 完整代码模板

### 2.1 字符串基础操作

```java
// ═══════════ String 核心 API ═════════════════════
s.length();                    // 长度（不是 size！）
s.charAt(i);                   // 取字符
s.substring(1, 3);             // 子串 [1,3)
s.indexOf("bc");               // 查找
s.equals("abc");               // ⚠️ 内容比较（不是 ==！）
s.equalsIgnoreCase("ABC");     // 忽略大小写
s.split(",");                  // 分割（正则）
s.toCharArray();               // 转字符数组

// ═══════════ StringBuilder（拼接）════════════════
// ⚠️ 循环拼接必须用 StringBuilder（+ 是 O(n²)）
StringBuilder sb = new StringBuilder();
sb.append("x");                // 追加
sb.insert(1, "Y");             // 插入
sb.reverse();                  // 反转
sb.setLength(sb.length() - 1); // 删除最后一个（回溯用）

// ═══════════ 字符技巧 ════════════════════════════
c - 'a';                       // 字母转下标（0-25）
(char)('a' + i);               // 下标转字母
c - '0';                       // 数字字符转 int
Character.isLetterOrDigit(c);  // 字母数字判断（125 用）
```

### 2.2 字符计数模板

```java
// ═══════════ 242. 有效异位词（计数数组）══════════
public boolean isAnagram(String s, String t) {
    if (s.length() != t.length()) return false;
    int[] count = new int[26];
    for (int i = 0; i < s.length(); i++) {
        count[s.charAt(i) - 'a']++;    // s 加
        count[t.charAt(i) - 'a']--;    // t 减
    }
    for (int c : count) {
        if (c != 0) return false;
    }
    return true;
}
// 一次遍历双向计数 → O(n)/O(1)
// ⚠️ 值域大（Unicode）→ 改 HashMap
```

### 2.3 中心扩展（回文基础）

```java
/**
 * 中心扩展：2n-1 个中心（n 奇数 + n-1 偶数）
 * 最长回文子串（5 题）的基础
 */
private int expand(String s, int left, int right) {
    while (left >= 0 && right < s.length()
           && s.charAt(left) == s.charAt(right)) {
        left--;
        right++;
    }
    return right - left - 1;      // 回文长度
}

// 每个中心取最大：
public String longestPalindrome(String s) {
    int start = 0, maxLen = 0;
    for (int i = 0; i < s.length(); i++) {
        int len1 = expand(s, i, i);         // 奇数中心
        int len2 = expand(s, i, i + 1);     // 偶数中心
        int len = Math.max(len1, len2);
        if (len > maxLen) {
            maxLen = len;
            start = i - (len - 1) / 2;      // 计算起点
        }
    }
    return s.substring(start, start + maxLen);
}
// O(n²) 时间 O(1) 空间（标准答案）
// 追问"更快" → Manacher O(n)（见专项）
```

## 3. 四大核心模式

### 3.1 模式一：滑动窗口（子串最优）

```
"最长/最短/恰好子串" → 滑窗
  3 无重复最长子串（右扩左缩）
  76 最小覆盖子串（valid 种类数）
  567 字符串排列（定长窗口）

⚠️ 模板要点：
  右扩左缩 + 条件单调 + 增量维护
  缩窗用 while；最长外更新最短内更新
（详见滑动窗口专题）
```

### 3.2 模式二：双指针（回文/反转）

```
"反转/回文验证/单词处理" → 对撞/快慢
  344 反转字符串（对撞交换）
  125 验证回文串（对撞+跳过）
  151 单词反转（split 逆序）

⚠️ 细节：
  忽略大小写用 toLowerCase
  跳过非法用 isLetterOrDigit
  比较用 equals 不用 ==
```

### 3.3 模式三：DP（双序列）

```
"两个串的 LCS/编辑距离" → 双序列 DP
  1143 最长公共子序列
  72 编辑距离（三操作 min）
  10 正则表达式匹配（* 分支）

⚠️ 模板：
  dp[i][j] = s1 前 i 个 与 s2 前 j 个的关系
  转移：相等走对角；不等取 max/min
（详见动态规划体系）
```

### 3.4 模式四：回溯（组合/分割）

```
"所有组合/分割方案" → 回溯
  17 电话号码组合（index 定位）
  22 生成括号（左右计数）
  131 分割回文串（切点）

⚠️ 模板：
  选择-递归-撤销 + path 拷贝
（详见回溯体系）
```

## 4. 三大字符串专项

### 4.1 KMP（28 strStr）

```
next 数组（最长公共前后缀）+ 主串不回溯
  O(n+m)（暴力 O(n×m)）

⚠️ 面试定位：
  "思想要懂，手撕看公司"
  大厂可能要求手撕或讲清 next 数组
（完整实现见字符串匹配专题）
```

### 4.2 Manacher（5 题最优解）

```
利用回文对称性 → O(n) 最长回文
  插入分隔符统一奇偶
  center/right 最右回文 + 对称复用

⚠️ 面试定位：
  中心扩展 O(n²) 是标准答案
  Manacher 是加分项（深度展示）
（完整实现见字符串体系-04）
```

### 4.3 滚动哈希（1044 最长重复子串）

```
多项式哈希 + 窗口 O(1) 滚动
  配合二分 → O(n log n) 查重

⚠️ 选型：
  单模式匹配 → KMP（确定）
  子串查重 → 滚动哈希（Set 利器）
（完整实现见滚动哈希专题）
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"最长无重复子串 → 滑动窗口：
 右指针扩展加入字符，左指针收缩到无重复。
 窗口状态用频次数组维护，O(1) 增量更新。
 最长在 while 外更新。O(n) 时间。
 追问匹配题：可以用 KMP——预处理 next 数组，
 主串不回溯，O(n+m)。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 字符串题总体策略？ | 70% 归四大模式，先识别模式再套模板 |
| 2 | 为什么不可变？ | 安全/缓存/线程安全；拼接用 StringBuilder |
| 3 | == 和 equals？ | == 比引用；equals 比内容；String 用 equals |
| 4 | 循环拼接为什么慢？ | 每次 + 创建新对象 O(n²)；StringBuilder O(n) |
| 5 | KMP 核心？ | next 数组 + 主串不回溯（O(n+m)） |
| 6 | 最长回文最优？ | 中心扩展 O(n²) 标准；Manacher O(n) 加分 |
| 7 | 滚动哈希？ | 子串 O(1) 比较 + 查重；冲突概率 1/10⁹ |
| 8 | 边界注意？ | 空串/单字符/大小写/空格/Unicode |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 拼接用 + | O(n²) | StringBuilder |
| 比较用 == | 结果错 | equals |
| substring 边界 | 越界 | 左闭右开 |
| 忘处理空串 | 越界 | 前置判断 |
| split 忘转义 | 分割错 | split("\\s+") |

> 🎯 **核心要点**：字符串 = **模式识别**（70% 归四大模式）+ **三大专项**（KMP/Manacher/滚动哈希）+ **Java 细节**（不可变/equals/StringBuilder）。3/5/125/28 四道必背题 + 模式识别框架，字符串题从 Easy 到 Hard 全覆盖。
