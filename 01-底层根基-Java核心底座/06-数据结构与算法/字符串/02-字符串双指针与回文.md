## 1. 344. 反转字符串

### 1.1 完整实现（对撞交换）

```java
/**
 * LeetCode 344. 反转字符串
 * 原地反转字符数组（O(1) 额外空间）
 *
 * 对撞指针：左右交换，向中间收缩
 */
public void reverseString(char[] s) {
    int left = 0, right = s.length - 1;
    while (left < right) {
        char temp = s[left];
        s[left] = s[right];
        s[right] = temp;
        left++;
        right--;
    }
}
```

### 1.2 变体：541. 反转字符串 II

```java
/**
 * LeetCode 541. 反转字符串 II
 * 每 2k 个字符反转前 k 个，剩余不足 k 全反转
 * "abcdefg", k=2 → "bacdfeg"
 */
public String reverseStr(String s, int k) {
    char[] chars = s.toCharArray();
    for (int i = 0; i < chars.length; i += 2 * k) {
        int left = i;
        int right = Math.min(i + k - 1, chars.length - 1);   // ⚠️ 边界
        while (left < right) {
            char temp = chars[left];
            chars[left++] = chars[right];
            chars[right--] = temp;
        }
    }
    return new String(chars);
}
```

## 2. 125. 验证回文串

### 2.1 完整实现（对撞 + 跳过）

```java
/**
 * LeetCode 125. 验证回文串
 * 忽略大小写和非字母数字字符，判断是否回文
 * "A man, a plan, a canal: Panama" → true
 *
 * 对撞指针 + 跳过非法字符 + 忽略大小写
 */
public boolean isPalindrome(String s) {
    int left = 0, right = s.length() - 1;

    while (left < right) {
        // 跳过非字母数字（两个 while）
        while (left < right && !Character.isLetterOrDigit(s.charAt(left))) {
            left++;
        }
        while (left < right && !Character.isLetterOrDigit(s.charAt(right))) {
            right--;
        }
        // 比较（忽略大小写）
        if (Character.toLowerCase(s.charAt(left))
            != Character.toLowerCase(s.charAt(right))) {
            return false;
        }
        left++;
        right--;
    }
    return true;
}
```

### 2.2 变体：680. 验证回文串 II

```java
/**
 * LeetCode 680. 验证回文串 II
 * 最多删除一个字符，判断是否回文
 *
 * 对撞 + 分叉：遇到不匹配时
 *   check(left+1, right) 或 check(left, right-1)
 *   （删左边或删右边，任一可行即可）
 */
public boolean validPalindrome(String s) {
    int left = 0, right = s.length() - 1;
    while (left < right) {
        if (s.charAt(left) != s.charAt(right)) {
            // 分叉检查：删左边 或 删右边
            return isPalindromeRange(s, left + 1, right)
                || isPalindromeRange(s, left, right - 1);
        }
        left++;
        right--;
    }
    return true;
}

private boolean isPalindromeRange(String s, int lo, int hi) {
    while (lo < hi) {
        if (s.charAt(lo++) != s.charAt(hi--)) return false;
    }
    return true;
}
```

 */
public String reverseWords_Backward(String s) {

    int i = s.length() - 1;
    while (i >= 0) {

        }
    }
    return sb.toString().trim();
}

## 4. 14. 最长公共前缀

### 4.1 完整实现（纵向扫描）

```java
/**
 * LeetCode 14. 最长公共前缀
 * ["flower","flow","flight"] → "fl"
 *
 * 纵向扫描：以第一个字符串为基准
 *   逐列比较所有字符串的同一位置
 *   发现不同/越界 → 返回已匹配前缀
 */
public String longestCommonPrefix(String[] strs) {
    if (strs.length == 0) return "";

    String first = strs[0];
    for (int i = 0; i < first.length(); i++) {
        char c = first.charAt(i);
        for (int j = 1; j < strs.length; j++) {
            // ⚠️ 越界 或 字符不同 → 前缀结束
            if (i >= strs[j].length() || strs[j].charAt(i) != c) {
                return first.substring(0, i);
            }
        }
    }
    return first;                    // 第一个字符串就是公共前缀
}
```

### 4.2 三种解法对比

| 解法 | 思路 | 复杂度 |
|------|------|:---:|
| 纵向扫描 | 逐列比较 | O(S)（S = 总字符数） |
| 横向扫描 | 两两求公共前缀 | O(S) |
| 二分查找 | 前缀长度二分 | O(S log n) |

### 5.2 中心扩展（5/647 的基础）

```java
/**
 * 中心扩展法：每个字符和每对相邻字符作为回文中心
 * 向两边扩展直到不匹配
 * 奇数中心 n 个 + 偶数中心 n-1 个 = 2n-1 个中心
 */
private int expand(String s, int left, int right) {
    while (left >= 0 && right < s.length()
           && s.charAt(left) == s.charAt(right)) {
        left--;
        right++;
    }
    return right - left - 1;      // 回文长度
}
// 最长回文子串：对每个中心取最大
// 复杂度 O(n²)/O(1)，比 DP 省空间
```
