## 5. 高频题深度复盘

### 5.1 5. 最长回文子串（中心扩展标准答案）

```java
public String longestPalindrome(String s) {
    int start = 0, maxLen = 0;
    for (int i = 0; i < s.length(); i++) {
        int len1 = expand(s, i, i);         // 奇数中心
        int len2 = expand(s, i, i + 1);     // 偶数中心
        int len = Math.max(len1, len2);
        if (len > maxLen) {
            maxLen = len;
            start = i - (len - 1) / 2;      // 计算起点
        }
    }
    return s.substring(start, start + maxLen);
}

private int expand(String s, int left, int right) {
    while (left >= 0 && right < s.length()
           && s.charAt(left) == s.charAt(right)) {
        left--;
        right++;
    }
    return right - left - 1;
}
```

**复盘要点**：
- 2n-1 个中心（n 个奇数 + n-1 个偶数）
- 起点公式：`i - (len-1)/2`（记忆）
- 追问 Manacher 时讲"对称性 + 右边界复用"

### 5.2 28. strStr（KMP 手撕）

```java
public int strStr(String haystack, String needle) {
    int n = haystack.length(), m = needle.length();
    if (m == 0) return 0;
    int[] next = new int[m];
    int j = 0;
    for (int i = 1; i < m; i++) {          // 构建 next
        while (j > 0 && needle.charAt(i) != needle.charAt(j)) j = next[j - 1];
        if (needle.charAt(i) == needle.charAt(j)) j++;
        next[i] = j;
    }
    j = 0;
    for (int i = 0; i < n; i++) {          // 匹配
        while (j > 0 && haystack.charAt(i) != needle.charAt(j)) j = next[j - 1];
        if (haystack.charAt(i) == needle.charAt(j)) j++;
        if (j == m) return i - m + 1;
    }
    return -1;
}
```

**复盘要点**：
- 构建与匹配两段结构相同（while 回退 + 相等推进）
- 面试先说定义（next[i] = 前 i 个字符的最长公共前后缀）
- 手撕前先跑一遍 "ABAB" 的 next 构建

## 6. 调试技巧与自检清单

### 6.1 字符串自检三步法

```
第 1 步：边界检查
  □ 空字符串（"" 和 null 区分！）
  □ 单字符 / 全相同字符
  □ 大小写混合 / 含特殊字符
  □ 空格处理（首尾/中间/多个连续）

第 2 步：API 检查
  □ 比较用 equals 而不是 ==
  □ 拼接用 StringBuilder（循环内）
  □ substring 边界（[start, end) 左闭右开）
  □ split 的转义（"\\s+" 而不是 "\s+"）

第 3 步：算法检查
  □ KMP：while 回退写对了吗？
  □ 中心扩展：奇偶中心都覆盖了吗？
  □ 滚动哈希：取模防负数了吗？
```

### 6.2 高频 Bug 速查表

| Bug | 原因 | 修复 |
|------|------|------|
| 拼接 O(n²) | 循环内用 + | StringBuilder |
| 比较出错 | 用 == 比较内容 | equals |
| 越界 | substring 边界算错 | 左闭右开记忆 |
| KMP 死循环 | 回退用 if | 用 while |
| 回文漏偶数 | 只考虑奇数中心 | 两个 expand 都做 |
| 哈希负数 | 取模前为负 | `(h % mod + mod) % mod` |
| split 错误 | 没转义正则 | `split("\\s+")` |
