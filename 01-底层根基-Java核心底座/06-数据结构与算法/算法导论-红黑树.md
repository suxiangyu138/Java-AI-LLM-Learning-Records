## 一、红黑树核心定义（后端视角）

**红黑树（Red-Black Tree）** 是一种自平衡二叉搜索树，通过颜色规则与旋转操作维持黑色高度平衡，保证最坏情况下的时间复杂度为 O(logn)。

| 指标 | 值 |
|------|----|
| 最坏情况时间复杂度 | O(logn) |
| 空间复杂度 | O(n) |
| 插入旋转次数 | 最多 2 次 |
| 删除旋转次数 | 最多 3 次 |

> **后端意义**：红黑树是 Java TreeMap/TreeSet 以及 HashMap（链表转树）的底层实现，是后端有序存储、范围查询、动态排序的核心数据结构。

---

## 二、红黑树五大性质（算法导论）

红黑树在满足 BST 性质的基础上，增加了以下 5 个着色规则来保持平衡：

| 编号 | 性质 | 说明 |
|------|------|------|
| **性质1** | 每个节点非红即黑 | 节点只有两种颜色 |
| **性质2** | 根节点为黑色 | 树根始终为黑色 |
| **性质3** | 所有叶子节点（空节点）为黑色 | NIL 节点视为黑色 |
| **性质4** | 红色节点的两个子节点均为黑色 | 不允许连续红色节点 |
| **性质5** | 从任意节点到每个叶子节点的路径包含相同数量的黑色节点 | 黑色高度平衡 |

> **核心目的**：这 5 个规则确保树的高度不超过 `2 * log(n+1)`，从而保证所有操作稳定在 O(logn)。

## 三、红黑树核心操作（Java 实现）

### 节点定义

```java
class RBNode {
    int val;
    RBNode left, right, parent;
    boolean color; // true 红, false 黑

    RBNode(int val) {
        this.val = val;
        this.color = true; // 新节点默认红色
    }
}
```

### 红黑树完整实现

```java
public class RedBlackTree {
    private static final boolean RED = true;
    private static final boolean BLACK = false;
    private RBNode root;

    // 左旋
    private void leftRotate(RBNode x) {
        RBNode y = x.right;
        x.right = y.left;
        if (y.left != null) y.left.parent = x;
        y.parent = x.parent;
        if (x.parent == null) root = y;
        else if (x == x.parent.left) x.parent.left = y;
        else x.parent.right = y;
        y.left = x;
        x.parent = y;
    }

    // 右旋
    private void rightRotate(RBNode y) {
        RBNode x = y.left;
        y.left = x.right;
        if (x.right != null) x.right.parent = y;
        x.parent = y.parent;
        if (y.parent == null) root = x;
        else if (y == y.parent.right) y.parent.right = x;
        else y.parent.left = x;
        x.right = y;
        y.parent = x;
    }

    // 插入后修复
    private void insertFixup(RBNode z) {
        while (z.parent != null && z.parent.color == RED) {
            if (z.parent == z.parent.parent.left) {
                RBNode y = z.parent.parent.right;
                if (y != null && y.color == RED) {
                    // 情况1：叔节点为红色，变色处理
                    z.parent.color = BLACK;
                    y.color = BLACK;
                    z.parent.parent.color = RED;
                    z = z.parent.parent;
                } else {
                    // 情况2：叔节点为黑色，旋转处理
                    if (z == z.parent.right) {
                        z = z.parent;
                        leftRotate(z);
                    }
                    z.parent.color = BLACK;
                    z.parent.parent.color = RED;
                    rightRotate(z.parent.parent);
                }
            } else {
                // 对称处理
                RBNode y = z.parent.parent.left;
                if (y != null && y.color == RED) {
                    z.parent.color = BLACK;
                    y.color = BLACK;
                    z.parent.parent.color = RED;
                    z = z.parent.parent;
                } else {
                    if (z == z.parent.left) {
                        z = z.parent;
                        rightRotate(z);
                    }
                    z.parent.color = BLACK;
                    z.parent.parent.color = RED;
                    leftRotate(z.parent.parent);
                }
            }
        }
        root.color = BLACK;
    }

    // 插入
    public void insert(int val) {
        RBNode z = new RBNode(val);
        RBNode y = null;
        RBNode x = root;
        while (x != null) {
            y = x;
            if (z.val < x.val) x = x.left;
            else x = x.right;
        }
        z.parent = y;
        if (y == null) root = z;
        else if (z.val < y.val) y.left = z;
        else y.right = z;
        insertFixup(z);
    }
}
```

## 四、红黑树复杂度分析

| 操作 | 最坏时间复杂度 | 平均时间复杂度 |
|------|--------------|--------------|
| **插入** | O(logn) | O(logn) |
| **删除** | O(logn) | O(logn) |
| **查找** | O(logn) | O(logn) |
| **空间** | O(n) | O(n) |

| 旋转次数 | 数值 |
|---------|------|
| 插入最多旋转 | 2 次 |
| 删除最多旋转 | 3 次 |

## 五、Java 后端核心应用场景

### 1. TreeMap / TreeSet

| 特性 | 说明 |
|------|------|
| **底层结构** | 红黑树 |
| **核心功能** | 有序键值对、范围查询、subMap、headMap、tailMap |
| **应用场景** | 排行榜、时间序列、区间统计 |

### 2. HashMap（JDK 1.8+）

| 特性 | 说明 |
|------|------|
| **触发条件** | 链表长度 >= 8 时转为红黑树 |
| **回退条件** | 节点数 <= 6 时转回链表 |
| **核心目的** | 避免哈希冲突退化为 O(n) |
| **效果** | 保证最坏情况下查找为 O(logn) |

### 3. 并发有序结构

| 实现 | 底层 | 适用场景 |
|------|------|---------|
| **ConcurrentSkipListMap** | 跳表 | 高并发下替代 TreeMap |
| **应用** | 分布式有序存储 | 高并发有序缓存 |

## 六、红黑树 vs AVL 树（后端选型）

| 对比维度 | AVL 树 | 红黑树 |
|---------|--------|--------|
| **平衡标准** | 高度差 <= 1 | 黑色高度平衡 |
| **旋转频率** | 更频繁 | 较少 |
| **查询性能** | 略快 | 略慢 |
| **插入/删除性能** | 较差 | 更好（旋转少） |
| **后端工程选型** | 不常用 | TreeMap 选择红黑树 |

> **后端选型**：后端工程中优先选择红黑树（TreeMap），因为插入删除更高效，且查询性能也在可接受范围内。

---

## 七、红黑树 vs 跳表（后端选型）

| 对比维度 | 红黑树 | 跳表 |
|---------|--------|------|
| **内存占用** | 更紧凑 | 指针多，内存略大 |
| **范围查询** | 高效 | 高效 |
| **实现复杂度** | 复杂（旋转+着色） | 简单 |
| **并发友好度** | 较差 | 好 |
| **后端选型** | 单机有序 | 高并发场景 |

> **后端选型**：高并发选跳表（Redis ZSet、ConcurrentSkipListMap），单机有序选红黑树（TreeMap）。

---

## 八、总结（后端红黑树核心要点）

1. 红黑树是自平衡 BST，保证最坏情况 O(logn)
2. 五大性质 + 旋转 + 变色维持平衡
3. Java 核心应用：TreeMap、HashMap 树化
4. 适合有序存储、范围查询、动态排序
5. 是后端高级数据结构的基础
