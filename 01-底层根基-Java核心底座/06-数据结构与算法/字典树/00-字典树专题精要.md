## 1. 核心概念

### 1.1 什么是字典树

> 字典树（Trie / 前缀树）：多叉树结构，**从根到节点的路径 = 一个前缀**，共享公共前缀的单词共用节点路径。

```
插入 apple, app, apply, bat：

        根
       /   \
      a     b
     /       \
    p         a
   /           \
  p             t
 / \
p   l
|   |
e   y

特性：
  查询单词：O(长度)（与词库大小无关！）
  前缀匹配：O(长度)（天然支持前缀查询）
  空间：前缀共享 → 比哈希省空间（有公共前缀时）
```

### 1.2 核心操作

```
① insert(word)：沿路径走，缺节点则建，末尾标记 isEnd
② search(word)：沿路径走，最后节点是 isEnd（完整词）
③ startsWith(prefix)：能走到末尾即存在该前缀
④ 删除（少见）：递归 + 子树计数（count 维护）

⚠️ search vs startsWith 的区别：
  search 要求 isEnd = true（完整单词）
  startsWith 只要求路径存在（前缀）
```

### 1.3 何时用 Trie

```
① 前缀查询（自动补全/搜索建议/词典）
② 大量字符串共享前缀（节省空间）
③ 需要字典序遍历（有序输出）
④ 词频统计（节点加 count 字段）
⑤ 多模式匹配剪枝（212 单词搜索 II）

识别信号："前缀" 关键词 + 大量字符串操作
```

## 2. 完整代码模板

### 2.1 基础实现（208. 实现 Trie）

```java
/**
 * LeetCode 208. 实现 Trie（字典树标准模板）
 * 三操作：insert / search / startsWith
 */
class Trie {
    private TrieNode root;

    class TrieNode {
        TrieNode[] children = new TrieNode[26];   // 26 个孩子
        boolean isEnd;                            // 是否单词结尾
        // 可扩展字段：
        // int count      词频统计
        // int prefixCount 经过次数（前缀计数）
    }

    public Trie() { root = new TrieNode(); }

    // 插入：沿路径走，缺节点则建
    public void insert(String word) {
        TrieNode node = root;
        for (char c : word.toCharArray()) {
            int idx = c - 'a';
            if (node.children[idx] == null) {
                node.children[idx] = new TrieNode();
            }
            node = node.children[idx];
        }
        node.isEnd = true;                        // ⚠️ 标记结尾
    }

    // 查找：完整单词（必须 isEnd）
    public boolean search(String word) {
        TrieNode node = find(word);
        return node != null && node.isEnd;        // ⚠️ 必须 isEnd！
    }

    // 前缀匹配：能走到末尾即可
    public boolean startsWith(String prefix) {
        return find(prefix) != null;
    }

    // 沿路径查找，返回末节点（不存在返回 null）
    private TrieNode find(String word) {
        TrieNode node = root;
        for (char c : word.toCharArray()) {
            int idx = c - 'a';
            if (node.children[idx] == null) {
                return null;                      // 路径中断
            }
            node = node.children[idx];
        }
        return node;
    }
}
// 复杂度：全部操作 O(L)（L = 词长）
// 空间：O(总字符数)（前缀共享后）
```

### 2.2 通配符搜索（211. 添加与搜索单词）

```java
/**
 * LeetCode 211. 添加与搜索单词（Trie + DFS 通配）
 * 支持 '.' 匹配任意字母
 */
public boolean search(String word) {
    return dfs(root, word, 0);
}

private boolean dfs(TrieNode node, String word, int index) {
    if (index == word.length()) {
        return node.isEnd;                        // 走完 → 是单词？
    }

    char c = word.charAt(index);
    if (c != '.') {
        // 普通字符：走对应孩子
        int idx = c - 'a';
        return node.children[idx] != null
            && dfs(node.children[idx], word, index + 1);
    }

    // ⚠️ '.'：遍历所有孩子（26 个分支）
    for (TrieNode child : node.children) {
        if (child != null && dfs(child, word, index + 1)) {
            return true;                          // 任一分支可行
        }
    }
    return false;
}
// 复杂度：无 '.' O(L)；有 '.' 最坏 O(26^L)（剪枝后实际快）
```

### 2.3 词频统计（扩展字段）

```java
// 插入时维护 count：
public void insert(String word) {
    TrieNode node = root;
    for (char c : word.toCharArray()) {
        int idx = c - 'a';
        if (node.children[idx] == null) {
            node.children[idx] = new TrieNode();
        }
        node = node.children[idx];
        node.prefixCount++;            // ⚠️ 经过即计数
    }
    node.isEnd = true;
    node.count++;                      // 完整词计数（可重复插入）
}
// 应用：统计前缀出现次数、词典中第 K 小（配合遍历）
```

## 3. Trie 的进阶变体

### 3.1 01 Trie（二进制前缀树）

```java
/**
 * 01 Trie：用二进制位建 Trie（每个节点 0/1 两个孩子）
 * 应用：求最大异或值（421. 数组中两个数的最大异或）
 *
 * 核心思路：
 *   贪心：高位尽量取反（1^0 或 0^1 → 异或为 1 更大）
 *   每个数从高位到低位插入 + 查询最优配对
 */
class BinaryTrie {
    class Node {
        Node[] children = new Node[2];   // 0 和 1
    }
    private Node root = new Node();

    // 插入 32 位二进制
    public void insert(int num) {
        Node node = root;
        for (int i = 31; i >= 0; i--) {      // 高位 → 低位
            int bit = (num >> i) & 1;
            if (node.children[bit] == null) {
                node.children[bit] = new Node();
            }
            node = node.children[bit];
        }
    }

    // 查询与 num 异或最大的数（贪心走相反位）
    public int maxXor(int num) {
        Node node = root;
        int result = 0;
        for (int i = 31; i >= 0; i--) {
            int bit = (num >> i) & 1;
            int want = 1 - bit;              // 想要相反位（异或大）
            if (node.children[want] != null) {
                result |= (1 << i);          // 该位异或为 1
                node = node.children[want];
            } else {
                node = node.children[bit];   // 没有相反位 → 走同位
            }
        }
        return result;
    }
}
// 421 题：逐个插入 + 查询 → O(32n)
```

## 4. Trie vs 其他字符串结构

| 维度 | Trie | HashMap | 后缀数组 |
|------|:---:|:---:|:---:|
| 查找 | O(L) | O(L)（哈希） | O(L log n) |
| 前缀查询 | ✅ 天然 | ❌ 遍历 | 二分 |
| 有序遍历 | ✅ 字典序 | ❌ 无序 | ✅ |
| 空间 | 前缀共享 | 哈希表开销 | O(n) |
| 构建 | 逐词插入 | 逐词 put | O(n log n) |
| 适用 | 前缀/多模式 | 通用查找 | 子串统计 |

```
选型：
  前缀匹配/自动补全 → Trie（唯一自然解）
  通用键值 → HashMap（更快更简单）
  子串复杂统计 → 后缀数组（竞赛级）
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"多个单词匹配网格，我用 Trie 优化：
 ① 所有单词先建字典树（前缀共享）；
 ② 网格 DFS 时同时走 Trie——
    前缀不匹配立即剪枝；
 ③ 找到单词标记 isEnd=false 防重复。
 相比对每个单词单独 DFS，总复杂度
 从 O(词数×mn×3^L) 降到 O(mn×3^L)。
 每个操作 O(L)，构建 O(总字符数)。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | Trie 查找为什么 O(L)？ | 每层 O(1) 查子节点（数组下标），L 层；与词库大小 n 无关 |
| 2 | search vs startsWith 区别？ | search 要求 isEnd（完整词）；startsWith 只要路径存在 |
| 3 | 内存优化？ | children[26] 每节点 26 引用 → 稀疏用 HashMap 子节点 |
| 4 | '.' 通配怎么处理？ | DFS 遍历所有孩子（26 分支），其余正常走 |
| 5 | 01 Trie 是什么？ | 二进制位建 Trie，贪心走相反位求最大异或（421） |
| 6 | Trie vs 哈希表？ | 前缀查询/有序遍历 Trie 天然支持；通用查找哈希更简单 |
| 7 | 删除单词怎么实现？ | 节点加 count/prefixCount，删除时计数减；或递归标记 |
| 8 | 与 AC 自动机关系？ | AC = Trie + KMP 失配指针（多模式匹配），竞赛级 |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| search 忘检查 isEnd | "app" 匹配 "apple" | node.isEnd 判断 |
| 插入忘建节点 | 空指针 | 缺节点先 new |
| 通配 DFS 忘剪枝 | 指数爆炸 | 空孩子直接跳过 |
| 212 忘标记 isEnd=false | 重复收集单词 | 收集后清除 |
| 前缀计数忘维护 | 计数错误 | 每层经过都 +1 |

> 🎯 **核心要点**：Trie = **children 数组 + isEnd 标记**三操作模板（insert/search/startsWith）。价值在**前缀查询 O(L)** 与**多模式匹配剪枝**（212）。进阶：01 Trie（421 最大异或）、通配 DFS（211）。识别信号："前缀匹配、自动补全、多单词联合搜索"。
