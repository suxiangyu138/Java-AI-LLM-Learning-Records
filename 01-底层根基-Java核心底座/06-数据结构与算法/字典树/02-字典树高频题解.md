## 1. 212. 单词搜索 II（Trie + 网格 DFS）

### 1.1 题目与思路

```
网格找字典所有单词（多模式）
字典建 Trie → 网格每个格子 DFS → Trie 剪枝
⚠️ 01 模块 3 节剪枝三件套
```

### 1.2 完整代码

```java
/**
 * LeetCode 212. 单词搜索 II（Trie + DFS）
 */
class Solution {
    private static class TrieNode {
        TrieNode[] children = new TrieNode[26];
        String word;                        // ⚠️ 单词结尾存完整词（省拼接）
    }

    private final List<String> result = new ArrayList<>();
    private final int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};

    public List<String> findWords(char[][] board, String[] words) {
        // ① 字典建 Trie
        TrieNode root = new TrieNode();
        for (String w : words) {
            TrieNode cur = root;
            for (char c : w.toCharArray()) {
                if (cur.children[c - 'a'] == null)
                    cur.children[c - 'a'] = new TrieNode();
                cur = cur.children[c - 'a'];
            }
            cur.word = w;                   // ⚠️ 结尾存词
        }

        // ② 网格每个格子 DFS
        int m = board.length, n = board[0].length;
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                dfs(board, i, j, root);

        return result;
    }

    private void dfs(char[][] board, int i, int j, TrieNode node) {
        char c = board[i][j];
        if (c == '#' || node.children[c - 'a'] == null) return;  // ⚠️ 剪枝

        TrieNode next = node.children[c - 'a'];
        if (next.word != null) {            // ⚠️ 找到单词
            result.add(next.word);
            next.word = null;               // 去重（防止重复收集）
        }

        board[i][j] = '#';                  // ⚠️ 沉没（visited）
        for (int[] d : dirs) {
            int ni = i + d[0], nj = j + d[1];
            if (ni >= 0 && ni < board.length && nj >= 0 && nj < board[0].length)
                dfs(board, ni, nj, next);
        }
        board[i][j] = c;                    // ⚠️ 还原
    }
}
// 推演 board=[["o","a"],["e","t"]], words=["oath","eat"]：
//   从 (0,0) o → (1,0) a? 不——o → a（右上）→ t → h ✓ "oath"
//   (1,0) e → (1,1) a → (0,1) t ✓ "eat"
// ⚠️ 复杂度：O(m×n×4^L)（剪枝后远小）
// ⚠️ 面试必答："212 = Trie 压缩模式 + 网格 DFS——
//   不存在的分支直接剪、找到词去重（word=null）、
//   沉没防环。对比朴素逐个单词搜快一个数量级。"
```

## 2. 421. 数组中两个数的最大异或

### 2.1 题目与思路

```
01 Trie：插入所有数 → 查询每个数的最大异或配对
⚠️ 完整推导见字典树/01 模块 2 节
```

### 2.2 完整代码

```java
/**
 * LeetCode 421. 数组中两个数的最大异或
 */
public int findMaximumXOR(int[] nums) {
    int[][] trie = new int[nums.length * 31][2];   // ⚠️ 01 Trie（0/1 两分支）
    int nodeCount = 0;
    int maxXor = 0;

    for (int x : nums) {
        int node = 0, query = 0;
        for (int bit = 30; bit >= 0; bit--) {      // ⚠️ 高位到低位
            int b = (x >> bit) & 1;

            // 插入
            if (trie[node][b] == 0) trie[node][b] = ++nodeCount;

            // 查询：贪心走相反位
            int want = b ^ 1;
            if (trie[node][want] != 0) {
                query |= 1 << bit;                 // 该位异或为 1
                node = trie[node][want];
            } else {
                node = trie[node][b];              // 无奈走同位
            }
        }
        maxXor = Math.max(maxXor, query);
    }
    return maxXor;
}
// 推演 [3,10,5,25,2,8]：
//   3(00011) 与 25(11001)：异或 26？——25^5=28 是最大
//   查询 5(00101)：贪心高位找相反 → 25(11001) → 28 ✓
// ⚠️ 复杂度：O(31n)
// ⚠️ 面试必答："421 = 01 Trie 高位贪心——
//   每步走相反位（0↔1），最高位优先
//   保证异或最大；31 位循环。"
```

## 3. 648. 单词替换（前缀匹配）

### 3.1 题目与思路

```
句子中的单词若以字典词为前缀 → 替换为最短前缀词
Trie 前缀匹配：查单词时遇到 isEnd 即返回（最短前缀）
```

### 3.2 完整代码

```java
/**
 * LeetCode 648. 单词替换（Trie 最短前缀）
 */
public String replaceWords(List<String> dictionary, String sentence) {
    // ① 建 Trie（isEnd 标记）
    TrieNode root = new TrieNode();
    for (String w : dictionary) {
        TrieNode cur = root;
        for (char c : w.toCharArray()) {
            if (cur.children[c - 'a'] == null)
                cur.children[c - 'a'] = new TrieNode();
            cur = cur.children[c - 'a'];
        }
        cur.isEnd = true;
    }

    // ② 每个单词查最短前缀
    StringBuilder sb = new StringBuilder();
    for (String word : sentence.split(" ")) {
        TrieNode cur = root;
        String prefix = "";
        for (char c : word.toCharArray()) {
            if (cur.children[c - 'a'] == null) break;   // ⚠️ 无分支 → 无前缀
            cur = cur.children[c - 'a'];
            prefix += c;
            if (cur.isEnd) break;              // ⚠️ 最短前缀（第一个 isEnd）
        }
        sb.append(cur.isEnd ? prefix : word).append(" ");
    }
    return sb.toString().trim();
}
// 推演 dict=["cat","bat","rat"], sentence="the cattle was rattled"
//   cattle → cat（最短前缀）✓；rattled → rat ✓
// ⚠️ 面试必答："648 = 前缀匹配——
//   查单词时第一个 isEnd 即最短前缀；
//   无分支则保留原词。"
```

## 4. 720. 词典中最长的单词

### 4.1 题目与思路

```
字典中最长单词（可由其他词逐字母前缀构成）
Trie 逐级判断：插入后 DFS 检查"每个前缀都是单词"
⚠️ 条件：路径上每个节点都是 isEnd
```

### 4.2 完整代码

```java
/**
 * LeetCode 720. 词典中最长的单词（Trie 逐级判断）
 */
public String longestWord(String[] words) {
    TrieNode root = new TrieNode();
    for (String w : words) {                 // 插入全部
        TrieNode cur = root;
        for (char c : w.toCharArray()) {
            if (cur.children[c - 'a'] == null)
                cur.children[c - 'a'] = new TrieNode();
            cur = cur.children[c - 'a'];
        }
        cur.isEnd = true;
    }
    return dfs(root, "");
}

/** ⚠️ DFS：只有"每个前缀都是单词"的路径才继续 */
private String dfs(TrieNode node, String path) {
    String best = path;
    for (int i = 0; i < 26; i++) {
        TrieNode child = node.children[i];
        if (child != null && child.isEnd) {  // ⚠️ 前缀必须是单词
            String candidate = dfs(child, path + (char) ('a' + i));
            // ⚠️ 更长优先；等长字典序小优先
            if (candidate.length() > best.length()
                    || (candidate.length() == best.length()
                        && candidate.compareTo(best) < 0)) {
                best = candidate;
            }
        }
    }
    return best;
}
// 推演 ["a","banana","app","appl","ap","apply","apple"]：
//   "apple" 路径 a→ap→app→appl→apple 全 isEnd ✓
//   "banana" 前缀 b 不是单词 ✗ → 答案 "apple" ✓
// ⚠️ 复杂度：O(总字符数)
// ⚠️ 面试必答："720 = Trie DFS——
//   只有 isEnd 节点才继续深入（每个前缀
//   必须是单词）；长度优先 + 字典序次之。"
```

## 5. 1268. 搜索推荐系统（Trie + TopK）

### 5.1 题目与思路

```
每个前缀输入 → 推荐以该前缀开头的 Top3 单词（字典序）
Trie + 前缀收集：
  ① 建 Trie（节点存该节点下的 Top3？或 DFS 收集）
  ② 每输入一个字符 → 走到节点 → 收集子树单词取 Top3
⚠️ 优化：节点缓存 Top3（每个节点存排序后的推荐）
```

### 5.2 完整代码（节点缓存 Top3）

```java
/**
 * LeetCode 1268. 搜索推荐系统（Trie 节点缓存 Top3）
 */
class Solution {
    private static class TrieNode {
        TrieNode[] children = new TrieNode[26];
        List<String> top3 = new ArrayList<>();   // ⚠️ 节点缓存推荐
    }

    public List<List<String>> suggestedProducts(String[] products, String searchWord) {
        Arrays.sort(products);               // ⚠️ 字典序排序（Top3 的前提）
        TrieNode root = new TrieNode();

        // ① 插入并维护节点 Top3
        for (String p : products) {
            TrieNode cur = root;
            for (char c : p.toCharArray()) {
                if (cur.children[c - 'a'] == null)
                    cur.children[c - 'a'] = new TrieNode();
                cur = cur.children[c - 'a'];
                if (cur.top3.size() < 3) cur.top3.add(p);   // ⚠️ 排序后前 3 个
            }
        }

        // ② 逐字符查询
        List<List<String>> result = new ArrayList<>();
        TrieNode cur = root;
        for (char c : searchWord.toCharArray()) {
            if (cur != null) cur = cur.children[c - 'a'];
            result.add(cur == null ? new ArrayList<>() : cur.top3);
        }
        return result;
    }
}
// 推演 products=["mobile","mouse","moneypot","monitor","mousepad"], search="mouse"
//   排序后：mobile,moneypot,monitor,mouse,mousepad
//   "m" 节点 Top3：[mobile,moneypot,monitor]
//   "mo" 同；"mou"：[mouse,mousepad]...
// ⚠️ 复杂度：O(总字符数)（Top3 缓存免重复收集）
// ⚠️ 面试必答："1268 = Trie 节点缓存 Top3——
//   排序后插入，每个节点缓存前 3 个经过词；
//   查询逐字符走节点直接取缓存。"
```

## 6. 字典树方法论总结

### 6.1 解题框架

```
① 识别：前缀/多模式/自动补全 → Trie
② 设计节点：children + isEnd/word/top3（按题扩展）
③ 核心操作：插入（逐字符）、查询（走分支）
④ 高级融合：
   多模式 → Trie + DFS 剪枝
   二进制 → 01 Trie 贪心
   TopK → 节点缓存
⑤ 复杂度：O(L)/操作

⚠️ 识别信号：
  "前缀/自动补全/词典" → Trie
  "最大异或" → 01 Trie
  "网格找字典词" → Trie + DFS
```

### 6.2 模板速查表

| 题型 | 形态 | 代表题 |
|------|------|--------|
| 多模式搜索 | Trie + DFS 剪枝 | 212 |
| 最大异或 | 01 Trie 贪心 | 421 |
| 最短前缀 | isEnd 即返回 | 648 |
| 逐级构成 | isEnd 才深入 | 720 |
| 推荐 TopK | 节点缓存 | 1268 |

### 6.3 自测清单

```
□ isEnd 语义（前缀 vs 单词）？
□ 数组/Map 选型（字符集）？
□ 01 Trie 位方向（高位→低位）？
□ 212 沉没还原？
□ 去重（word=null）？
□ Top3 缓存排序前提？
□ 复杂度 O(L)？
```
