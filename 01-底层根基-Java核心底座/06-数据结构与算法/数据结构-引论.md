## 数据结构与算法的本质

### 数据结构

数据的组织方式，解决 **"如何存"** 的问题。

- **核心目标：** 高效存储、访问、修改数据

### 算法

解决问题的步骤，解决 **"如何算"** 的问题。

- **核心目标：** 高效执行、降低时间/空间开销

### 关系

| 维度 | 说明 |
|------|------|
| 数据结构是算法的基础 | 没有数据结构，算法无从下手 |
| 算法是数据结构的应用 | 没有算法，数据结构失去意义 |
| 二者共同决定程序性能 | 选对结构+设计好算法=高性能程序 |

## 为什么 Java 后端必须掌握

### 1. 性能优化

高并发场景下，数据结构决定**吞吐量**，算法决定**执行效率**。接口响应、缓存设计、数据库查询等核心场景均依赖对数据结构的深入理解。

### 2. 框架底层

主流框架底层大量使用树、哈希、队列、堆等数据结构：

| 框架/中间件 | 关键数据结构 |
|-------------|-------------|
| Spring | 缓存、容器中的树/哈希结构 |
| MyBatis | 缓存、SQL 解析 |
| Redis | 哈希表、跳表、压缩列表 |
| Kafka | 队列、日志结构 |

### 3. 面试核心

- 大厂必考：复杂度分析、高频算法题
- 是区分**初级**与**高级**开发的关键能力

### 4. 问题解决

海量数据处理、分布式调度、性能瓶颈定位 —— 算法思维是解决复杂问题的**核心能力**。

## 数据结构分类

### 1. 线性结构

| 结构 | 特点 |
|------|------|
| 数组、链表、栈、队列、哈希表 | 一对一关系，顺序访问 |

### 2. 树形结构

| 结构 | 特点 |
|------|------|
| 二叉树、红黑树、B+树、堆 | 一对多关系，层级存储 |

### 3. 图形结构

| 结构 | 特点 |
|------|------|
| 有向图、无向图、拓扑排序 | 多对多关系，复杂关联 |

### 4. 集合结构

| 结构 | 特点 |
|------|------|
| Set、Map、List | 快速去重、键值映射 |

## 算法复杂度分析（核心）

### 1. 时间复杂度

执行次数与数据规模的关系。常见复杂度排序：

```
O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)
```

### 2. 空间复杂度

内存占用与数据规模的关系，重点关注：

- 临时变量
- 递归栈深度
- 辅助数据结构

### 3. 最优、最坏、平均情况

> **重点分析最坏情况** —— 这是系统稳定性的保障。

## Java 后端常用数据结构

### 1. 基础容器

| 容器 | 底层结构 | 核心特性 |
|------|----------|----------|
| ArrayList | 动态数组 | 随机访问快，增删慢 |
| LinkedList | 双向链表 | 增删快，随机访问慢 |
| HashMap | 数组+链表/红黑树 | O(1) 查找，线程不安全 |
| TreeMap | 红黑树 | 有序存储，O(log n) |
| PriorityQueue | 堆（完全二叉树） | 优先级队列 |

### 2. 并发容器

- `ConcurrentHashMap` —— 分段锁/CAS+ synchronized
- `ConcurrentLinkedQueue` —— 无锁并发队列
- `BlockingQueue` —— 阻塞队列（线程池核心）

### 3. 数据库索引

| 索引类型 | 底层结构 | 适用引擎 |
|----------|----------|----------|
| B+树索引 | 多路平衡查找树 | MySQL InnoDB |
| 哈希索引 | 哈希表 | Memory 引擎 |

## Java 后端常用算法

| 算法类别 | 典型算法 | 后端应用场景 |
|----------|----------|-------------|
| 排序 | 快速排序、归并排序、堆排序 | 数据分页、排行榜 |
| 查找 | 二分查找、哈希查找 | 缓存查询、索引检索 |
| 贪心 | 任务调度、负载均衡 | 资源分配优化 |
| 动态规划 | 最优路径、状态转移 | 复杂决策问题 |
| 图算法 | Dijkstra、拓扑排序 | 最短路径、依赖调度 |

## 学习路径

### 1. 基础阶段

复杂度分析 → 线性结构（数组、链表、栈、队列）→ 树 → 哈希

### 2. 进阶阶段

堆 → 图 → 高级树结构（红黑树、B+树）

### 3. 实战阶段

- LeetCode 刷题（Top 100 高频题）
- 框架源码分析（HashMap、TreeMap）
- 项目性能优化实践
