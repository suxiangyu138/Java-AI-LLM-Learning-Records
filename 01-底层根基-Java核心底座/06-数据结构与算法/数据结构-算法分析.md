## 二、复杂度分析基础

### 1. 时间复杂度

描述算法执行时间随数据规模增长的趋势。表示为 `T(n) = O(f(n))`，`n` 为数据规模。

### 2. 空间复杂度

描述算法内存占用随数据规模增长的趋势。关注临时变量、递归栈、辅助数据结构。

### 3. 复杂度等级（从优到劣）

| 复杂度 | 名称 | 说明 |
|--------|------|------|
| O(1) | 常数阶 | 执行时间不随数据规模变化 |
| O(log n) | 对数阶 | 增长速度极慢 |
| O(n) | 线性阶 | 与数据规模成正比 |
| O(n log n) | 线性对数阶 | 高效排序的主流复杂度 |
| O(n²) | 平方阶 | 双重循环，效率较低 |
| O(2ⁿ) | 指数阶 | 效率极低，需避免 |

> **核心记忆公式：** O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ)

## 三、常见复杂度场景（Java后端）

### 1. O(1)：常数时间

- 数组随机访问、HashMap基本操作
- 例：`list.get(0)`、`map.get(key)`

### 2. O(log n)：对数时间

- 二分查找、平衡树操作
- 例：`TreeMap`查找、B+树索引查询

### 3. O(n)：线性时间

- 数组遍历、链表查找
- 例：`ArrayList`遍历、`LinkedList`查找

### 4. O(n log n)：线性对数时间

- 高效排序算法
- 例：快速排序、归并排序、堆排序

### 5. O(n²)：平方时间

- 简单排序、双重循环
- 例：冒泡排序、插入排序

## 四、最好、最坏、平均复杂度

| 类型 | 定义 | 说明 |
|------|------|------|
| **最好情况** | 最优输入下的复杂度 | 理想状态，参考价值有限 |
| **最坏情况** | 最差输入下的复杂度 | **重点关注**，保证系统稳定性 |
| **平均情况** | 随机输入下的期望复杂度 | 反映一般场景下的性能 |

> **典型案例：HashMap查找**
> - 最好 O(1) —— 无哈希冲突
> - 最坏 O(n) —— 所有元素冲突形成链表
> - 平均 O(1) —— 哈希函数设计合理

---

## 五、均摊复杂度（Java后端重点）

### 1. 定义

连续多次操作后，单次操作的平均复杂度。适用于动态扩容场景。

### 2. 典型应用

| 数据结构 | 操作 | 均摊复杂度 |
|----------|------|-----------|
| `ArrayList` | 扩容 | 每次扩容翻倍，均摊 **O(1)** |
| `HashMap` | rehash操作 | 均摊 **O(1)** |

## 六、Java后端实战分析案例

### 1. ArrayList vs LinkedList

| 操作 | `ArrayList` | `LinkedList` |
|------|-------------|--------------|
| 随机访问 | O(1) | O(n) |
| 头部插入 | O(n) | O(1) |
| 遍历 | O(n) | O(n) |

### 2. HashMap vs TreeMap

| 指标 | `HashMap` | `TreeMap` |
|------|-----------|-----------|
| 查找 | O(1) | O(log n) |
| 有序遍历 | 不支持 | O(n) |
| 内存 | 更低 | 更高 |

### 3. 数据库索引

| 索引类型 | 查询复杂度 | 特点 |
|----------|-----------|------|
| **B+树** | O(log n) | 范围查询高效 |
| **哈希索引** | O(1) | 不支持范围查询 |

## 七、算法优化原则（Java后端）

### 1. 空间换时间

缓存数据、预计算结果。
- 例：Redis缓存、本地缓存Caffeine

### 2. 时间换空间

减少内存占用，适用于内存受限场景。
- 例：流式处理、分批加载

### 3. 避免重复计算

缓存中间结果、使用记忆化。
- 例：动态规划、LRU缓存

## 八、复杂度分析实战步骤

1. **确定数据规模 n**

3. **忽略常数项与低阶项**
4. **确定最坏复杂度**
5. **结合业务场景验证**
