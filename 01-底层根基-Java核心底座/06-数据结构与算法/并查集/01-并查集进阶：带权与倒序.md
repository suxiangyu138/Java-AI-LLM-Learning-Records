## 1. 带权并查集：节点到根的距离

### 1.1 基本并查集的局限

```
基本并查集只回答："两个元素是否连通？"
带权并查集回答："两个元素的数值关系是什么？"

例（399 除法求值）：
  a/b = 2.0 → a = 2b
  b/c = 3.0 → b = 3c
  问 a/c = ? → 6.0

问题：需要维护"节点到根的倍率"
  根作为基准 → 每个节点记录与根的比值
```

### 1.2 带权并查集的数据结构

```java
class WeightedUnionFind {
    int[] parent;         // 父节点
    double[] weight;      // ⚠️ 节点到父节点的倍率（node = weight[node] × parent）

    // find 返回根，同时压缩路径并更新权重
    public int find(int x) {
        if (parent[x] != x) {
            int origin = parent[x];          // 记录原父
            parent[x] = find(parent[x]);     // 递归找根
            weight[x] *= weight[origin];     // ⚠️ 权重累乘
        }
        return parent[x];
    }

    // union：建立 x 与 y 的关系 x = ratio × y
    public void union(int x, int y, double ratio) {
        int rx = find(x), ry = find(y);
        if (rx == ry) return;
        // 数学推导：x = weight[x]×rx，y = weight[y]×ry
        // x = ratio×y → weight[x]×rx = ratio×weight[y]×ry
        // → rx = (ratio×weight[y]/weight[x]) × ry
        parent[rx] = ry;
        weight[rx] = ratio * weight[y] / weight[x];
    }

    // 查询 x/y 的比值（同根时才有意义）
    public double query(int x, int y) {
        if (find(x) != find(y)) return -1.0;
        return weight[x] / weight[y];        // x = weight[x]/weight[y] × y
    }
}
```

### 1.3 权重更新的本质

```
关键理解：
  weight[x] 表示 x 与父节点的倍率
  路径压缩时：weight[x] *= weight[原父]（累乘）
  → 压缩后 weight[x] = x 与根的直接倍率

union 的推导：
  已知 x = ratio × y（新关系）
  x = weight[x] × rx，y = weight[y] × ry
  → weight[x] × rx = ratio × weight[y] × ry
  → rx = (ratio × weight[y] / weight[x]) × ry
  即 weight[rx] = ratio × weight[y] / weight[x]
```

## 2. 399. 除法求值（带权经典）

### 2.1 完整实现

```java
/**
 * LeetCode 399. 除法求值（带权并查集标准题）
 * equations: [["a","b"],["b","c"]], values: [2.0, 3.0]
 * queries: [["a","c"]] → 6.0
 *
 * 建模：变量 = 节点，a/b=2 → a = 2b（带权边）
 * 查询 a/c：同根 → weight[a]/weight[c]
 */
public double[] calcEquation(List<List<String>> equations,
                             double[] values,
                             List<List<String>> queries) {
    // ① 字符串 → 节点编号
    Map<String, Integer> id = new HashMap<>();
    int n = 0;
    for (List<String> eq : equations) {
        for (String s : eq) {
            if (!id.containsKey(s)) id.put(s, n++);
        }
    }

    // ② 初始化带权并查集
    int[] parent = new int[n];
    double[] weight = new double[n];
    for (int i = 0; i < n; i++) {
        parent[i] = i;
        weight[i] = 1.0;
    }

    // ③ 合并所有等式
    for (int i = 0; i < equations.size(); i++) {
        int a = id.get(equations.get(i).get(0));
        int b = id.get(equations.get(i).get(1));
        union(parent, weight, a, b, values[i]);
    }

    // ④ 处理查询
    double[] result = new double[queries.size()];
    for (int i = 0; i < queries.size(); i++) {
        Integer a = id.get(queries.get(i).get(0));
        Integer b = id.get(queries.get(i).get(1));
        if (a == null || b == null) {
            result[i] = -1.0;                // 变量不存在
        } else if (find(parent, weight, a) != find(parent, weight, b)) {
            result[i] = -1.0;                // 不连通
        } else {
            result[i] = weight[a] / weight[b];
        }
    }
    return result;
}

// find：路径压缩 + 权重累乘
private int find(int[] parent, double[] weight, int x) {
    if (parent[x] != x) {
        int origin = parent[x];
        parent[x] = find(parent, weight, origin);
        weight[x] *= weight[origin];         // ⚠️ 累乘
    }
    return parent[x];
}

// union：建立 x = ratio × y 的关系
private void union(int[] parent, double[] weight,
                   int x, int y, double ratio) {
    int rx = find(parent, weight, x);
    int ry = find(parent, weight, y);
    if (rx == ry) return;
    parent[rx] = ry;
    weight[rx] = ratio * weight[y] / weight[x];
}
```

### 2.2 推演验证

```
equations: a/b=2, b/c=3 → a=2b, b=3c

union(a, b, 2)：
  parent[a]=b, weight[a]=2（a=2b）
union(b, c, 3)：
  parent[b]=c, weight[b]=3（b=3c）

query(a, c)：
  find(a) → 路径：a→b→c
  压缩时 weight[a] = 2×3 = 6（a = 6c）
  weight[c] = 1（根）
  → a/c = 6/1 = 6.0 ✓
```

## 3. 倒序并查集：删除反转添加

### 3.1 核心思想

```
场景：并查集只支持"合并"，不支持"删除"
  题目要"删除节点/边后统计连通分量"

倒序技巧：
  把删除操作全部反转 → 变成"添加"
  从最终状态开始，倒着处理操作
  → 全程只有合并 → 并查集可用

经典题：1970. 最后一天能过河
  洪水淹没格子（删除）→ 倒序变"陆地恢复"（添加）
```

### 3.2 305. 岛屿数量 II（动态加边）

```java
/**
 * LeetCode 305. 岛屿数量 II（并查集在线处理）
 * 网格初始全水，逐个位置变成陆地（添加操作）
 * 每次添加后返回当前岛屿数
 *
 * 为什么必须并查集？
 *   DFS/BFS 每次全图扫描 O(mn) → 总 O(k×mn)
 *   并查集：添加时只处理 4 邻居 → O(k×α)
 */
public List<Integer> numIslands2(int m, int n, int[][] positions) {
    UnionFind uf = new UnionFind(m * n);
    boolean[][] isLand = new boolean[m][n];
    int count = 0;                       // 当前岛屿数
    List<Integer> result = new ArrayList<>();

    int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};
    for (int[] pos : positions) {
        int i = pos[0], j = pos[1];
        int id = i * n + j;              // 二维 → 一维

        if (!isLand[i][j]) {             // 新陆地
            isLand[i][j] = true;
            count++;                     // 先假设独立成岛

            for (int[] d : dirs) {       // 检查四邻居
                int ni = i + d[0], nj = j + d[1];
                if (ni < 0 || ni >= m || nj < 0 || nj >= n) continue;
                if (isLand[ni][nj]) {    // 邻居是陆地
                    int nid = ni * n + nj;
                    if (!uf.connected(id, nid)) {
                        uf.union(id, nid);
                        count--;         // ⚠️ 合并 → 岛屿数-1
                    }
                }
            }
        }
        result.add(count);
    }
    return result;
}
```

## 4. 路径压缩的两种实现

```java
// ═══════════ 递归版（简洁，深链可能栈溢出）══════════
public int find(int x) {
    if (parent[x] != x) {
        parent[x] = find(parent[x]);     // 递归 + 压缩
    }
    return parent[x];
}

// ═══════════ 迭代版（两遍，防栈溢出）══════════════
public int find_Iterative(int x) {
    // ① 第一遍：找根
    int root = x;
    while (parent[root] != root) root = parent[root];

    // ② 第二遍：路径压缩（沿途节点直接挂根）
    while (parent[x] != x) {
        int next = parent[x];
        parent[x] = root;
        x = next;
    }
    return root;
}

// ═══════════ 面试选择 ═══════════════════════════════
// 递归：代码短（面试首选）
// 迭代：深链安全（大数据量/嵌套深时）
// 讲清两者差异 = 面试加分
```

## 5. 进阶应用总结

### 5.1 带权并查集的应用场景

| 场景 | 权重含义 | 代表题 |
|------|------|:---:|
| 除法关系 | 倍率 | 399 除法求值 |
| 距离关系 | 差值 | 721 账户合并（变体） |
| 游戏关系 | 胜负 | 1813 句子相似性 III（变体） |

```
带权 vs 普通：
  普通：连通性（boolean）
  带权：关系数值（weight 累乘/累加）
  识别信号："给出 A/B 的比值求 A/C" → 带权
```

### 5.2 倒序并查集的应用场景

| 场景 | 反转方式 | 代表题 |
|------|------|:---:|
| 删除边 | 倒序加边 | 1569 网络延迟（变体） |
| 淹没陆地 | 倒序恢复 | 1970 最后一天过河 |
| 删除节点 | 倒序添加 | 1738 第 K 大值（变体） |

```
识别信号："删除操作 + 统计连通/可达" → 倒序
  先处理完所有删除 → 从最终状态倒推
  （并查集只支持合并，反转删除为添加）
```

### 5.3 面试话术

```
"这题是带权并查集：除了 parent 还维护 weight
 （节点到父的倍率），find 时权重累乘，
 union 时用数学推导更新根节点的权重。
 查询 A/B：同根时 weight[A]/weight[B]。
 复杂度 O(α(n)) 近似常数。"
```

> 🎯 **核心要点**：并查集进阶两大武器——**带权**（weight 累乘，399 除法求值）与**倒序**（删除反转添加，305 动态加边）。识别信号："比值查询"→ 带权；"删除操作"→ 倒序。find 的权重更新与 union 的数学推导是核心难点。
