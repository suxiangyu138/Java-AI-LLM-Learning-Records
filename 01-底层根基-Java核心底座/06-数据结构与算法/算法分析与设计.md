## 1. 算法基础

### 1.1 算法五特性

| 特性 | 说明 |
|------|------|
| 有穷性 | 有限步后终止 |
| 确定性 | 每一步精确定义 |
| 可行性 | 每步可执行 |
| 输入 | 0 个或多个 |
| 输出 | 至少 1 个 |

### 1.2 渐进记号

| 记号 | 含义 | 说明 |
|:----:|------|------|
| **O**（大 O） | 上界 | 最坏情况 |
| **Ω**（大 Ω） | 下界 | 最好情况 |
| **Θ**（大 Θ） | 紧确界 | O 和 Ω 一致时 |

### 1.3 递推方程求解

| 方法 | 适用场景 |
|------|----------|
| **代入法** | 猜测解 → 数学归纳法证明 |
| **递归树法** | 画树展开，逐层求和 |
| **主定理** | T(n) = aT(n/b) + f(n) 型 |

## 2. 分治策略

```text
分解（Divide）→ 求解（Conquer）→ 合并（Combine）
```

| 算法 | 递推式 | 复杂度 |
|------|--------|:------:|
| 归并排序 | T(n) = 2T(n/2) + O(n) | O(n log n) |
| 快速排序 | T(n) = 2T(n/2) + O(n) | O(n log n) 平均 |
| 二分查找 | T(n) = T(n/2) + O(1) | O(log n) |
| Karatsuba 大整数乘法 | T(n) = 3T(n/2) + O(n) | O(n^1.585) |
| Strassen 矩阵乘法 | T(n) = 7T(n/2) + O(n²) | O(n^2.807) |
| 最近点对 | — | O(n log n) |

## 3. 动态规划

### 3.1 核心要素

| 要素 | 说明 |
|------|------|
| **最优子结构** | 问题最优解包含子问题最优解 |
| **重叠子问题** | 子问题被重复求解（区别于分治） |

### 3.2 DP vs 分治

| 维度 | 分治 | DP |
|------|:----:|:--:|
| 子问题 | 独立、不重叠 | 重叠 |
| 求解方式 | 递归 | 填表（自底向上）/ 记忆化搜索（自顶向下） |

### 3.3 经典 DP 问题

| 问题 | 状态定义 | 转移方程 |
|------|----------|----------|
| **矩阵连乘** | `m[i][j]`：A[i..j] 最小乘法次数 | `m[i][j] = min(m[i][k] + m[k+1][j] + p[i-1]*p[k]*p[j])` |
| **LCS** | `dp[i][j]`：X[0..i-1] 和 Y[0..j-1] 的 LCS 长度 | 相等→`dp[i-1][j-1]+1`；不等→`max(dp[i-1][j], dp[i][j-1])` |
| **LIS** | `dp[i]`：以第 i 个元素结尾的最长递增子序列 | `dp[i] = max(dp[j] + 1)`，`j < i 且 a[j] < a[i]` |
| **0/1 背包** | `dp[i][w]`：前 i 个物品、容量 w 的最大价值 | `max(dp[i-1][w], dp[i-1][w-w_i] + v_i)` |
| **编辑距离** | `dp[i][j]`：word1[0..i] → word2[0..j] | 插入/删除/替换取最小 |

### 3.4 背包问题对比

| 类型 | 物品 | 贪心可得最优 |
|------|------|:-----------:|
| 部分背包 | 可分割 | ✅ |
| 0/1 背包 | 不可分割 | ❌（需 DP） |

## 4. 贪心算法

### 4.1 基本要素

| 要素 | 说明 |
|------|------|
| **贪心选择性质** | 局部最优 → 全局最优 |
| **最优子结构** | 贪心选择后的子问题最优解 = 原问题最优解 |

### 4.2 经典贪心算法

| 问题 | 贪心策略 | 复杂度 |
|------|----------|:------:|
| 活动安排 | 按结束时间升序，优先选最早结束 | O(n log n) |
| 哈夫曼编码 | 每次取最小频率两结点合并 | O(n log n) |
| **Prim** | 每次选连接已访问集合的最小权边 | O(n²) |
| **Kruskal** | 边排序 + 并查集判环 | O(e log e) |
| **Dijkstra** | 每次选未访问中 dist 最小的点松弛 | O(n²) / O((V+E) log V) |
| 部分背包 | 按单位价值降序 | O(n log n) |

## 5. 回溯法

### 5.1 核心思想

```text
深度优先搜索解空间树 + 剪枝函数
├── 约束函数：去不满足约束的分支
└── 限界函数：去不可达最优的分支
```

### 5.2 解空间树类型

| 类型 | 大小 | 典型问题 |
|------|:----:|----------|
| 子集树 | O(2ⁿ) | 0/1 背包、装载问题 |
| 排列树 | O(n!) | N 皇后、TSP |

### 5.3 经典问题

| 问题 | 剪枝策略 |
|------|----------|
| **N 皇后** | 不同列 + 不同对角线 |
| **图着色** | 相邻顶点颜色不同；按度降序排列 |
| **0/1 背包（回溯）** | 约束：当前重量 ≤ 容量；限界：剩余价值上界 |
| **TSP** | 当前路径长度 + 剩余下界 ≥ 最优解 → 剪枝 |

## 6. 分支限界法

### 6.1 vs 回溯法

| 维度 | 回溯法 | 分支限界法 |
|------|--------|-----------|
| 搜索策略 | 深度优先 | 广度优先 / 最小成本优先 |
| 目标 | 找所有解 | 找最优解 |
| 队列 | — | FIFO 队列式 / 优先队列式 |

## 8. NP 完全性理论

### 8.1 问题分类

| 类别 | 含义 | 示例 |
|------|------|------|
| **P** | 多项式时间可解 | 排序、最短路径 |
| **NP** | 多项式时间可验证 | TSP 的验证 |
| **NPC** | NP 中最难的问题，任意 NP 问题可归约到它 | SAT、TSP、哈密顿回路 |
| **NP-Hard** | 至少和 NPC 一样难，但不一定在 NP 中 | 停机问题 |

### 8.2 常见 NPC 问题

| 问题 | 说明 |
|------|------|
| SAT | Cook 定理证明 SAT 是第一个 NPC |
| TSP（判定版） | 是否存在长度 ≤ k 的回路 |
| 顶点覆盖 | 是否存在大小 ≤ k 的顶点覆盖 |
| 哈密顿回路 | 是否存在经过每个点一次的回路 |
| 子集和 | 是否存在子集和为指定值 |

### 8.3 NPC 问题应对

> 不追求精确最优解 → 用**近似算法**或**启发式算法**。
