# 算法分析与设计

## 课程概述
- **课程性质**：专业核心必修课
- **适用专业**：计算机类各专业
- **开课学期**：大三学年
- **考核方式**：考试（闭卷）+ 实验 + 平时成绩

## 课程目标
1. 掌握算法设计与分析的基本方法
2. 理解分治、贪心、动态规划、回溯、分支限界等经典算法策略
3. 能够分析算法的正确性和复杂度
4. 具备解决复杂算法问题的能力

## 核心知识点

### 第一章：算法基础
- 算法的定义与特性（有穷性、确定性、可行性、输入、输出）
- 时间复杂度分析：最好/最坏/平均情况、渐进记号（O、Ω、Θ）
- 递推方程求解：代入法、递归树法、主定理
- 空间复杂度分析

### 第二章：分治策略
- 分治法的基本思想：分解→求解→合并
- 经典分治算法：
  - 归并排序：T(n) = 2T(n/2) + O(n) = O(n log n)
  - 快速排序：平均O(n log n)，最坏O(n²)
  - 二分查找：O(log n)
  - 大整数乘法（Karatsuba算法）
  - 矩阵乘法的Strassen算法
  - 最近点对问题

### 第三章：动态规划
- 动态规划的基本要素：最优子结构、重叠子问题
- 与分治法的区别：子问题是否重叠
- 经典DP问题：
  - 矩阵连乘：最优加括号顺序（m[i][j] = min{m[i][k]+m[k+1][j]+p_{i-1}p_k p_j}）
  - 最长公共子序列(LCS)：c[i][j] = c[i-1][j-1]+1 或 max(c[i-1][j], c[i][j-1])
  - 最长递增子序列(LIS)
  - 0/1背包问题：dp[i][w] = max(dp[i-1][w], dp[i-1][w-w_i] + v_i)
  - 最优二叉搜索树
  - 编辑距离

### 第四章：贪心算法
- 贪心算法的基本要素：贪心选择性质、最优子结构
- 与动态规划的区别
- 经典贪心算法：
  - 活动安排问题
  - 哈夫曼编码
  - 最小生成树（Prim、Kruskal）
  - 单源最短路径（Dijkstra算法）
  - 部分背包问题（贪心可得最优解，0/1背包不可）
  - 硬币找零问题

### 第五章：回溯法
- 回溯法的基本思想：深度优先搜索解空间树
- 剪枝函数：约束函数（去不满足约束的）+ 限界函数（去不可达最优的）
- 解空间组织：子集树O(2ⁿ) vs 排列树O(n!)
- 经典回溯问题：
  - N皇后问题
  - 图的m着色问题
  - 0/1背包问题的回溯解法
  - 旅行商问题(TSP)
  - 装载问题

### 第六章：分支限界法
- 与回溯法的区别：广度优先/最小成本优先 + 限界函数
- FIFO队列式与优先队列式
- 经典问题：0/1背包、TSP、单源最短路径、装载问题

### 第七章：算法设计进阶专题
- 随机化算法：随机快速排序、蒙特卡洛与拉斯维加斯算法
- 摊还分析
- 在线算法

### 第八章：NP完全性理论
- P类问题（多项式时间可解）
- NP类问题（多项式时间可验证）
- NP完全问题(NPC)与NP难问题(NP-Hard)
- Cook定理：SAT是NPC
- 常见NPC问题：SAT、TSP、顶点覆盖、哈密顿回路、子集和
- NPC问题的近似算法

## 重点难点
- **重点**：动态规划、贪心策略选择、回溯法的剪枝
- **难点**：DP状态定义与转移方程、NP完全性证明

## 学习方法与建议
1. 每种算法策略至少做5道经典题
2. 在LeetCode/洛谷上按Tag刷题
3. DP重在培养状态定义和状态转移的感觉
4. 为准备面试和竞赛，建议系统刷题300+
