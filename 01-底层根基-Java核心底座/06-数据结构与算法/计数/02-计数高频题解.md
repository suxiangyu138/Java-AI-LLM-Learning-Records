## 1. 242. 有效的字母异位词

### 1.1 题目与思路

```
两个字符串是否为字母异位词（相同字母不同排列）
计数数组：长度 26，s 加、t 减 → 最终全 0 即异位词
⚠️ 单数组 +- 法（省一个数组）
```

### 1.2 完整代码

```java
/**
 * LeetCode 242. 有效的字母异位词
 * ⚠️ 一个计数数组 +- 抵消
 */
public boolean isAnagram(String s, String t) {
    if (s.length() != t.length()) return false;    // 长度不同直接否

    int[] count = new int[26];
    for (int i = 0; i < s.length(); i++) {
        count[s.charAt(i) - 'a']++;                // s 加
        count[t.charAt(i) - 'a']--;                // t 减
    }
    for (int c : count)
        if (c != 0) return false;                  // ⚠️ 全 0 才异位词
    return true;
}
// 推演 s="anagram", t="nagaram"：每位 +- 后全 0 ✓
// ⚠️ 复杂度：O(n) 时间，O(1) 空间（26 固定）
// ⚠️ 变体 438 找到字符串中所有异位词：窗口滑动 + 计数数组对比
//   （窗口内频次与目标一致 → 命中）
```

> 🎯 **要点**：异位词判定 = "频次向量相等"。计数数组 +- 抵消是 O(1) 空间的经典手法；大字符集用哈希键（49 题的分组键）。

## 2. 387. 字符串中的第一个唯一字符

### 2.1 题目与思路

```
第一个只出现一次的字符下标
两遍扫描：
  ① 计数数组统计频次
  ② 再次扫描找第一个频次 = 1 的
⚠️ "第一遍计数、第二遍查询"是计数题的标准两步
```

### 2.2 完整代码

```java
/**
 * LeetCode 387. 字符串中的第一个唯一字符
 */
public int firstUniqChar(String s) {
    int[] count = new int[26];
    for (char c : s.toCharArray()) count[c - 'a']++;    // ① 计数

    for (int i = 0; i < s.length(); i++) {
        if (count[s.charAt(i) - 'a'] == 1) return i;    // ② 首个频次 1
    }
    return -1;
}
// 推演 s="loveleetcode"：l:2, o:1, v:1, e:4, t:1, c:1, d:1
//   扫描：l(2)✗, o(1)✓ → 返回 1 ✓
// ⚠️ 变体 451（全量重排）与 347（TopK）都是"计数 + 处理"两步
// ⚠️ 大字符集（Unicode）→ 哈希计数；流式 → 维护首现位置数组
```

## 3. 347. 前 K 个高频元素（频次桶完整版）

### 3.1 题目与思路

```
前 K 高频元素（00 已有模板，此处给出完整版 + 边界处理）
两步：哈希计数 → 频次桶（下标 = 频次）→ 从高到低取 K 个
⚠️ 频次桶是"免排序的频次降序"
```

### 3.2 完整代码

```java
/**
 * LeetCode 347. 前 K 个高频元素（频次桶完整版）
 */
public int[] topKFrequent(int[] nums, int k) {
    // ① 哈希计数（值域未知 → 不能数组）
    Map<Integer, Integer> freq = new HashMap<>();
    for (int x : nums) freq.merge(x, 1, Integer::sum);

    // ② 频次桶：buckets[f] = 频次为 f 的元素列表
    @SuppressWarnings("unchecked")
    List<Integer>[] buckets = new List[nums.length + 1];   // ⚠️ 大小 n+1
    for (var e : freq.entrySet()) {
        int f = e.getValue();
        if (buckets[f] == null) buckets[f] = new ArrayList<>();
        buckets[f].add(e.getKey());
    }

    // ③ 从高频桶向下取 K 个
    int[] res = new int[k];
    int idx = 0;
    for (int f = nums.length; f >= 1 && idx < k; f--) {    // ⚠️ 高频优先
        if (buckets[f] != null) {
            for (int v : buckets[f]) {
                res[idx++] = v;
                if (idx == k) break;
            }
        }
    }
    return res;
}
// 推演 [1,1,1,2,2,3], k=2：
//   freq = {1:3, 2:2, 3:1}
//   桶[3]=[1]，桶[2]=[2]，桶[1]=[3]
//   从 f=6 向下：f=3 → [1]，f=2 → [2] → 结果 [1,2] ✓
// ⚠️ 复杂度：O(n)（计数 O(n) + 桶遍历 O(n)），空间 O(n)
// ⚠️ 对比：堆解法 O(n log k)；快选 O(n) 期望（见分治/03）
```

## 4. 451. 根据字符出现频率排序

### 4.1 题目与思路

```
按频率降序重排字符串（同频率任意顺序）
与 347 同构：哈希计数 + 频次桶 + 降序展开
⚠️ 区别：347 取前 K 个；451 全量重排
```

### 4.2 完整代码

```java
/**
 * LeetCode 451. 根据字符出现频率排序
 */
public String frequencySort(String s) {
    int[] freq = new int[128];                       // ⚠️ ASCII 用数组
    for (char c : s.toCharArray()) freq[c]++;

    @SuppressWarnings("unchecked")
    List<Character>[] buckets = new List[s.length() + 1];
    for (int i = 0; i < 128; i++) {
        if (freq[i] > 0) {
            if (buckets[freq[i]] == null) buckets[freq[i]] = new ArrayList<>();
            buckets[freq[i]].add((char) i);
        }
    }

    StringBuilder sb = new StringBuilder();
    for (int f = s.length(); f >= 1; f--) {          // 降序展开
        if (buckets[f] != null) {
            for (char c : buckets[f])
                for (int i = 0; i < f; i++) sb.append(c);   // 展开 f 次
        }
    }
    return sb.toString();
}
// 推演 s="tree"：freq{t:1,r:1,e:2}
//   桶[2]=[e]，桶[1]=[t,r] → "eetr" 或 "eert" ✓
// ⚠️ 复杂度：O(n)（免排序），空间 O(n)
// ⚠️ 与 347 模板对比：同一个"频次桶"模式，一个取 K 一个全排
```

## 5. 383. 赎金信

### 5.1 题目与思路

```
能否用 magazine 的字符构造 ransomNote（每个字符只能用一次）
计数数组：magazine 加 + ransomNote 减 → 检查是否够用
⚠️ 与 242 的区别：242 要求"恰好相等"；383 要求"够用即可"
```

### 5.2 完整代码

```java
/**
 * LeetCode 383. 赎金信
 * ⚠️ magazine 是"供给"，ransomNote 是"需求"
 */
public boolean canConstruct(String ransomNote, String magazine) {
    int[] count = new int[26];
    for (char c : magazine.toCharArray()) count[c - 'a']++;   // 供给
    for (char c : ransomNote.toCharArray()) {
        if (count[c - 'a'] == 0) return false;    // ⚠️ 不够用
        count[c - 'a']--;                         // 消耗一个
    }
    return true;
}
// 推演 ransomNote="aa", magazine="aab"：a 供给 2 需求 2 ✓
// 推演 ransomNote="aa", magazine="ab"：第二个 a 不够 → false ✓
// ⚠️ 变体 409 最长回文串（字符计数 + 奇偶处理）：
//   每字符取 2×⌊count/2⌋，若有奇数频次再加 1（中心）
```

## 6. 217/219. 存在重复元素

### 6.1 题目与思路

```
217：是否存在重复元素（Set 判重，O(n)）
219：是否存在下标距离 ≤ k 的重复元素（滑动窗口 + Set）
⚠️ 判重 = 计数的退化形态（出现次数 ≥ 2 即重复）
```

### 6.2 双题完整代码

```java
/** 217. 存在重复元素：Set 判重（计数 ≥ 2） */
public boolean containsDuplicate(int[] nums) {
    Set<Integer> seen = new HashSet<>();
    for (int x : nums)
        if (!seen.add(x)) return true;      // ⚠️ add 返回 false = 已存在
    return false;
}

/** 219. 存在重复元素 II：滑动窗口 + Set（窗口大小 k） */
public boolean containsNearbyDuplicate(int[] nums, int k) {
    Set<Integer> window = new HashSet<>();
    for (int i = 0; i < nums.length; i++) {
        if (!window.add(nums[i])) return true;    // 窗口内有重复
        if (i >= k) window.remove(nums[i - k]);   // ⚠️ 窗口滑动
    }
    return false;
}
// 推演 [1,2,3,1], k=3：
//   i=0 加入 1；i=1 加入 2；i=2 加入 3；i=3：1 已在窗口 → true ✓
// ⚠️ 219 的窗口维护：HashMap<值, 最近下标> 也常见——
//   值 → 下标，检查 |i - last| ≤ k（等价写法）
```

## 7. 453. 最小操作次数使数组元素相等

### 7.1 题目与思路

```
每次给 n-1 个元素 +1，最少多少次使全部相等
数学转换：给 n-1 个 +1 ≡ 给 1 个 -1（等价操作！）
→ 目标：所有元素减到最小值
  次数 = Σ(nums[i] - min)
⚠️ "差分视角"把"加多数"变成"减少数"——经典数学化简
```

### 7.2 完整代码

```java
/**
 * LeetCode 453. 最小操作次数使数组元素相等
 * ⚠️ 核心等价：n-1 个 +1 ⟺ 1 个 -1
 */
public int minMoves(int[] nums) {
    int min = Integer.MAX_VALUE;
    for (int x : nums) min = Math.min(min, x);      // 找最小值

    int moves = 0;
    for (int x : nums) moves += x - min;            // 每个元素降到 min
    return moves;
}
// 推演 [1,2,3]：min=1 → (1-1)+(2-1)+(3-1) = 0+1+2 = 3 ✓
//   验证：+1,+1 → [2,3,3]；+1,+1 → [3,4,3]；+1,+1 → [4,4,4] ✓ 3 次
// ⚠️ 变体 462 最少移动次数使数组元素相等 II：
//   "一次移动 ±1" → 中位数（不是平均值！）
//   差 |x - median| 之和（中位数的性质：绝对差和最小）
// ⚠️ 462 与 453 的区别：453 是"批量 +1"（min 目标）；
//   462 是"单元素 ±1"（中位数目标）
```

## 8. 计数题方法论总结

### 8.1 解题框架

```
① 判定值域：小（字符/整数）→ 计数数组；大 → 哈希
② 统计频次：一次遍历（计数/哈希计数）
③ 组织频次：需要排序/TopK → 频次桶（免排序）
④ 处理答案：二次遍历 / 桶降序 / 数学化简

⚠️ 识别信号：
  "频次/出现次数/重复/唯一" → 计数
  "前 K 高频/按频率排序" → 计数 + 频次桶
  "是否够用/恰好相等" → 计数对比
```

### 8.2 题型模板速查

| 题型 | 模板 | 代表题 |
|------|------|--------|
| 相等判断 | 计数 +- 抵消 | 242 |
| 唯一性 | 计数 + 二次扫描 | 387 |
| 频率 TopK | 哈希计数 + 频次桶 | 347 |
| 频率重排 | 频次桶降序展开 | 451 |
| 供给消耗 | 计数 + 消耗检查 | 383 |
| 判重 | Set / 滑动窗口 | 217、219 |
| 数学化简 | 差分视角（min/中位数） | 453、462 |

### 8.3 自测清单

```
□ 值域判断（数组 vs 哈希）？
□ 负数/大值域偏移或换哈希？
□ 频次桶大小 n+1（防越界）？
□ 双题变体的差异（242 vs 383；453 vs 462）？
□ 复杂度表达 O(n)/O(n+k)？
□ 稳定性需要时从后往前放置？
```

---

> 🎯 **核心要点**：计数题 = **值域选型**（数组/哈希）+ **频次处理**（抵消/二次扫描/频次桶）+ **数学化简**（差分视角）。七题覆盖全部模式：判断（242）、定位（387）、TopK（347）、重排（451）、供给（383）、判重（217/219）、化简（453）——计数是"统计型问题"的第一武器。
