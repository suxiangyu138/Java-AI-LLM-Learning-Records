## 1. 核心概念

### 1.1 BFS 的本质

> 广度优先搜索（BFS）：从起点出发，**逐层向外扩散**——先访问距离 1 的所有节点，再访问距离 2 的节点。像洋葱一层层剥开。

```
       起点 S
      /  |  \
    A    B    C        ← 第 1 层（距离 1）
   / \        / \
  D   E      F   G     ← 第 2 层（距离 2）

BFS 访问顺序：S → A,B,C → D,E,F,G
（按距离从小到大）

为什么用队列？
  先进入的（更近）先处理 → FIFO 天然匹配
  对比 DFS 用栈/递归（深度优先）
```

### 1.2 识别信号

```
"最短/最少步数" → BFS（994/1091/127）
"扩散到所有位置" → BFS（994 腐烂橘子）
"层序/分层" → BFS（102 二叉树层序）
"依赖顺序（拓扑）" → BFS（Kahn，207）

⚠️ 核心优势：无权图第一次到达即最短
  （BFS 存在的前提：每条边代价相同）
```

### 1.3 为什么第一次到达即最短

```
BFS 按层扩散：第 k 层节点 = 距离起点 k 步

归纳证明：
  第 0 层：起点（距离 0）✓
  第 1 层：起点邻居（距离 1）✓
  第 k 层：所有"距离 k 且未被访问"的节点
    —— 若有更短路径（< k 步）→ 会在更早的层被访问
  → 第一次被访问时的层数 = 最短距离 ✓

⚠️ 带权图不能用 BFS（每条边代价不同）
  → 用 Dijkstra（见最短路专题）
```

## 2. 完整代码模板

### 2.1 基础模板（求最短距离）

```java
/**
 * BFS 通用模板
 */
public int bfs(Node start, Node target) {
    Queue<Node> queue = new LinkedList<>();
    Set<Node> visited = new HashSet<>();   // 或 boolean[]

    queue.offer(start);
    visited.add(start);        // ⚠️ 入队即标记！
    int steps = 0;

    while (!queue.isEmpty()) {
        int size = queue.size();           // ⚠️ 固定本层大小
        for (int i = 0; i < size; i++) {
            Node cur = queue.poll();
            if (cur == target) return steps;   // 到达目标

            for (Node next : cur.neighbors) {  // 遍历邻居
                if (!visited.contains(next)) {
                    queue.offer(next);
                    visited.add(next);         // 入队即标记
                }
            }
        }
        steps++;                             // 一层扩散完成
    }
    return -1;                               // 不可达
}
// 模板四要素：
//   ① Queue（FIFO 逐层）
//   ② visited（入队时标记！）
//   ③ size 分层（层数 = 步数）
//   ④ steps 每层 +1
```

### 2.2 网格 BFS（方向数组）

```java
/**
 * 网格 BFS：方向数组 + 越界判断 + 入队即标记
 */
public int gridBFS(int[][] grid, int[] start) {
    int m = grid.length, n = grid[0].length;
    int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};   // 四方向
    // 8 方向加对角：{{1,1},{1,-1},{-1,1},{-1,-1}}

    Queue<int[]> queue = new LinkedList<>();
    boolean[][] visited = new boolean[m][n];
    queue.offer(start);
    visited[start[0]][start[1]] = true;   // 入队即标记

    int steps = 0;
    while (!queue.isEmpty()) {
        int size = queue.size();
        for (int i = 0; i < size; i++) {
            int[] cur = queue.poll();
            for (int[] d : dirs) {
                int nx = cur[0] + d[0], ny = cur[1] + d[1];
                // ① 越界判断
                if (nx < 0 || nx >= m || ny < 0 || ny >= n) continue;
                // ② 障碍/已访问判断
                if (grid[nx][ny] == 1 || visited[nx][ny]) continue;

                visited[nx][ny] = true;
                queue.offer(new int[]{nx, ny});
            }
        }
        steps++;                          // 一层 = 一步
    }
    return steps;
}
```

### 2.3 状态 BFS（隐式图）

```java
/**
 * 状态 BFS：状态 = 节点，操作 = 边
 * 例：752 转盘锁（8 种拨动）
 */
public int openLock(String[] deadends, String target) {
    Set<String> dead = new HashSet<>(Arrays.asList(deadends));
    if (dead.contains("0000")) return -1;

    Queue<String> queue = new LinkedList<>();
    Set<String> visited = new HashSet<>();
    queue.offer("0000");
    visited.add("0000");

    int steps = 0;
    while (!queue.isEmpty()) {
        int size = queue.size();
        for (int i = 0; i < size; i++) {
            String cur = queue.poll();
            if (cur.equals(target)) return steps;

            for (String next : getNeighbors(cur)) {   // 8 种下一状态
                if (dead.contains(next)) continue;
                if (visited.contains(next)) continue;
                visited.add(next);
                queue.offer(next);
            }
        }
        steps++;
    }
    return -1;
}
// ⚠️ 状态数评估（面试第一句）：
//   "状态空间 10⁴，每状态 8 转移 → O(8×10⁴) 可行"
```

## 3. 五种形态详解

### 3.1 形态一：分层 BFS（二叉树层序）

```java
// 102 层序遍历：size 固定本层
public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> result = new ArrayList<>();
    if (root == null) return result;
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);

    while (!queue.isEmpty()) {
        int size = queue.size();         // ⚠️ 固定本层
        List<Integer> level = new ArrayList<>();
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            level.add(node.val);
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        result.add(level);
    }
    return result;
}
// 变体：199 右视图（每层最后一个）、103 锯齿形（奇偶反转）
```

### 3.2 形态二：多源 BFS（994 腐烂橘子）

```java
// 多源 BFS：所有起点同时入队（等价超级源点）
// 一次 BFS 解决多起点问题（逐个 BFS 是 O(k×mn)）

// 要点：
//   ① 所有源点（烂橘子）同时入队
//   ② 分层扩散计时（每层 = 1 分钟）
//   ③ 同时统计剩余目标（fresh）→ 结束判断

// 应用：994 腐烂、542 01 矩阵、1162 地图分析
// ⚠️ 面试表达："多源 = 虚拟超级源点连所有源"
```

### 3.3 形态三：状态 BFS（127 单词接龙）

```
状态 = 单词；转移 = 改一个字母
边按需生成（隐式图）：
  每个词生成 26L 个候选 → HashSet 查存在
  → O(n×26L) 而非 O(n²L) 建边

⚠️ 状态 BFS 三要素：
  ① 状态定义（当前局面）
  ② 转移枚举（一次操作）
  ③ 目标判定（到达终点）
```

### 3.4 形态四：双向 BFS（127 优化）

```
双向：同时从起点和终点扩散
  状态数：b^d → 2×b^(d/2)（开根号级别减少）

要点：
  ① 两个 Set 分别记录两端当前层
  ② 每次扩散"较小"的一侧
  ③ 两侧集合相交 → 找到最短路径

⚠️ 面试表达：
"双向 BFS 把状态数从 b^d 降到 2×b^(d/2)——
 平方级减少，适合分支因子大的场景。"
```

### 3.5 形态五：Kahn 拓扑（207 课程表）

```java
// Kahn（BFS 版）：
//   ① 统计入度
//   ② 入度 0 入队（无前置依赖）
//   ③ 出队 → 后继入度-1 → 减到 0 再入队
//   ④ 处理数 == n → 无环

// 判环原理：环上节点入度永远 ≥ 1 → 无法入队
// ⚠️ 完整实现见拓扑排序专题
```

## 4. BFS vs DFS

### 4.1 对比表

| 维度 | BFS | DFS |
|------|:---:|:---:|
| 数据结构 | 队列 | 栈/递归 |
| 遍历顺序 | 按层（广度） | 一条路走到底 |
| 最短路径 | ✅ 无权图第一次到达即最短 | ❌ 需全部搜索 |
| 所有方案 | 不擅长 | ✅ 天然适合 |
| 空间 | 大（存整层） | 小（存路径） |
| 连通块 | 可以 | 可以 |
| 拓扑 | Kahn（BFS） | 颜色法（DFS） |

### 4.2 选择标准

```
"最短/最少/最近" → BFS（994/1091/127）
"所有方案/路径" → DFS/回溯（79/131）
"连通块大小" → 两者皆可（200 两种都能写）
"层级信息" → BFS（102）
"路径记录" → DFS（路径在递归栈中）

⚠️ 面试表达：
"这是最短步数问题 → BFS。无权图 BFS
 逐层扩散，第一次到达目标就是最短距离。
 DFS 需要搜索所有路径才能确定最短，效率低。"
```

### 4.3 空间复杂度对比

```
BFS 空间 = 最大层宽（可能 O(V)）
  ⚠️ 树退化为链表：BFS 队列 O(1) 但 DFS 栈 O(n)
  完全二叉树：BFS O(n/2) 但 DFS O(log n)

选型：空间敏感时分析最坏层宽 vs 深度
  ⚠️ 面试可提："BFS 空间 O(层宽)，DFS O(深度)，
    按图的结构选择"
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"求最短步数 → BFS。用队列逐层扩散，
 visited 入队时标记（防重复入队死循环），
 每轮固定 size 分层，steps++ 计步。
 第一次到达目标即最短——BFS 按层扩散
 的性质保证。复杂度 O(V+E)（网格 O(mn)）。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 为什么 BFS 找到最短？ | 按层扩散，第 k 层距离 k；第一次到达即最短 |
| 2 | visited 为什么入队时标记？ | 出队才标记 → 重复入队 → 死循环 |
| 3 | BFS vs DFS 选型？ | 最短 → BFS；所有方案 → DFS |
| 4 | 多源 BFS 原理？ | 所有源同时入队 = 虚拟超级源点 |
| 5 | 双向 BFS？ | 两端扩散 → 状态数 b^d → 2×b^(d/2) |
| 6 | 带权图能 BFS 吗？ | 不能（代价不同）→ Dijkstra |
| 7 | 空间复杂度？ | O(最大层宽)（vs DFS O(深度)） |
| 8 | 状态 BFS 可行性？ | 状态数 × 转移数可控（先评估） |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| visited 出队才标记 | 重复入队死循环 | 入队即标记 |
| 忘 size 分层 | 层数错误 | int size = q.size() |
| 网格忘越界 | 数组越界 | 边界先行 |
| 多源忘全入队 | 结果错误 | 所有源入队 |
| 状态数爆炸 | 超时 | 先评估 2ⁿ |

> 🎯 **核心要点**：BFS = **队列 + 入队即标记 + size 分层**。识别信号："最短/最少/扩散/层序"。五种形态（分层/网格/多源/状态/拓扑）+ 双向优化是面试全部考点；"第一次到达即最短"的论证与"入队即标记"铁律是两个必答点。
