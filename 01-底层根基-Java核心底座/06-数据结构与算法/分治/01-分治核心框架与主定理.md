## 1. 分治的三类形态

### 1.1 不是所有递归都是分治

```
分治的判定标准（缺一不可）：
  ① 拆分：问题能被分成多个独立子问题
  ② 解决：子问题递归解决（或直接求解）
  ③ 合并：子问题的解能组合成原问题的解

⚠️ 反例：
  二叉树遍历 → 是递归但不是分治（没有"合并"步骤）
  斐波那契   → 不是分治（子问题重叠，合并无意义）
```

### 1.2 三类分治形态（按"合并"划分）

| 形态 | 合并代价 | 代表 | 复杂度特征 |
|------|:---:|------|-----------|
| 二分查找型 | O(1)（无需合并，只进一侧） | 二分查找、QuickSelect | T(n)=T(n/2)+O(1) → O(log n) |
| 归并型 | O(n)（合并需要扫描） | 归并排序、逆序对计数 | T(n)=2T(n/2)+O(n) → O(n log n) |
| 跨边界型 | O(n)（需额外扫描跨中点） | 最大子序和 53、区间和 327 | T(n)=2T(n/2)+O(n) → O(n log n) |

```
⚠️ 形态决定复杂度：
  二分查找型：只递归一侧 → log n
  归并型：递归两侧 + 线性合并 → n log n
  跨边界型：归并型 + 每层额外 O(n) 扫描 → n log n（常数更大）

识别口诀："看合并——不合并（单侧）、线性合并、跨边界合并"
```

### 1.3 分治的三大隐藏难点

| 难点 | 说明 | 应对 |
|------|------|------|
| 跨边界 | 最优解横跨分界点 | 递归子问题 + 专门扫描跨边界情况 |
| 合并语义 | 合并时返回值含义不清 | 先定义"子问题返回什么"再写代码 |
| 重复子问题 | 拆分的子问题重叠 | 加记忆化（退化为自顶向下 DP） |

## 2. 通用模板与跨边界处理

### 2.1 归并型通用模板（最常用）

```java
/**
 * 归并型分治通用框架（返回值语义：区间 [lo, hi] 的答案）
 */
int dc(int[] nums, int lo, int hi) {
    // ① 基线：最小规模直接求解
    if (lo == hi) return 直接结果(lo);

    // ② 拆分：取中点，递归两侧
    int mid = lo + (hi - lo) / 2;
    int leftAns = dc(nums, lo, mid);
    int rightAns = dc(nums, mid + 1, hi);

    // ③ 合并：组合两侧答案（可能含跨边界扫描）
    int crossAns = 跨边界计算(nums, lo, mid, hi);   // ⚠️ 可选步骤
    return 合并(leftAns, rightAns, crossAns);
}
```

### 2.2 跨边界计算的两种形态

```
形态一：扫描型（53 最大子序和）
  从 mid 向左扩展取最大和；从 mid+1 向右扩展取最大和
  跨中点答案 = leftMax + rightMax
  复杂度：每层 O(区间长度) → 总 O(n log n)

形态二：归并计数型（493 翻转对 / 315 右侧更小）
  合并前先统计"跨左右两半的满足条件的对"
  统计完再正常归并（排序是为了统计正确且高效）
  复杂度：每层 O(n) → 总 O(n log n)，但额外常数小
```

### 2.3 基线规模的选择

```
基线可以不止是"单个元素"：
  lo == hi：单元素（最常用）
  hi - lo <= 1：两个元素直接比较（省一层递归）
  规模小于阈值 k：暴力求解（工程优化，减少递归开销）

⚠️ 面试表达：
"基线是递归的终止条件——单元素直接返回。
 工程上可以设阈值，小于阈值用暴力，
 减少递归调用开销（如归并排序的 InsertionSort 优化）。"
```

## 3. 主定理完整版

### 3.1 三情形（Master Theorem）

```
T(n) = a·T(n/b) + f(n)     （a ≥ 1, b > 1）

设 c = log_b(a)（关键比较指数）：
  情形 1：f(n) = O(n^(c-ε))   → T(n) = Θ(n^c)          （合并轻于子问题）
  情形 2：f(n) = Θ(n^c)       → T(n) = Θ(n^c · log n)   （同阶）
  情形 3：f(n) = Ω(n^(c+ε))   → T(n) = Θ(f(n))          （合并重于子问题）
```

### 3.2 经典实例对照

| 递推方程 | a | b | c=log_b(a) | f(n) | 情形 | 复杂度 |
|---------|---|---|:---:|------|:---:|--------|
| T(n)=2T(n/2)+O(1) | 2 | 2 | 1 | O(1)=n⁰ | ① | O(n) |
| T(n)=2T(n/2)+O(n) | 2 | 2 | 1 | O(n) | ② | O(n log n) |
| T(n)=2T(n/2)+O(n²) | 2 | 2 | 1 | O(n²) | ③ | O(n²) |
| T(n)=T(n/2)+O(1) | 1 | 2 | 0 | O(1)=n⁰ | ② | O(log n) |
| T(n)=T(n/2)+O(n) | 1 | 2 | 0 | O(n) | ③ | O(n) |
| T(n)=3T(n/2)+O(n) | 3 | 2 | log₂3≈1.58 | O(n) | ① | O(n^1.58) |
| T(n)=4T(n/2)+O(n) | 4 | 2 | 2 | O(n) | ① | O(n²) |

```
⚠️ 情形判断技巧：先算 c = log_b(a)，再看 f(n) 与 n^c 谁大
  f(n) 更小 → 子问题主导 → n^c
  同阶      → 乘 log n
  f(n) 更大 → 合并主导 → f(n)
```

### 3.3 主定理的局限（面试加分）

```
① 要求 f(n) 是多项式级差距（相差 n^ε）——对数级差距不适用
② a、b 必须是常数（子问题数/缩小倍数固定）
③ 不适用：子问题重叠（那是 DP 的场景）
④ 不适用：快速排序（每次分点不固定，需概率分析）

⚠️ 面试表达：
"主定理处理'规整'的递推；快排的划分位置随机，
 不能用主定理，要用期望分析（每次期望减半 → O(n log n)）。"
```

## 4. 递归树分析实战

### 4.1 四棵经典递归树

```
① 归并排序 T(n) = 2T(n/2) + n：
   层 0：1 节点，代价 n
   层 1：2 节点，各 n/2，总 n
   层 k：2^k 节点，各 n/2^k，总 n
   共 log n 层 → 总 O(n log n) ✓

② 最大子序和 T(n) = 2T(n/2) + n：
   树形同归并 → O(n log n)

③ 快选 T(n) = T(n/2) + n（只递归一侧）：
   链式：n + n/2 + n/4 + ... = 2n → O(n) ✓

④ 朴素斐波那契 T(n) = T(n-1) + T(n-2)：
   满二叉树 2^n 个节点 → O(2^n)（无分治可言）
```

### 4.2 递归树的画法要点

```
① 每层标注：节点数 × 单节点代价 = 该层总代价
② 求和：各层总代价之和 = 总复杂度
③ 关键判断：层间代价"等比"（每层相同 → n·log n）
             还是"递减"（首项主导 → n）
④ 直觉：层数 log n 是分治的"特征数"，
         每层代价决定总复杂度形态
```

> 🎯 **面试必答句**："分治复杂度两问：层数是多少（log n 层），每层代价是多少（O(1)/O(n)）。两者相乘即复杂度。"

## 5. 分治的空间复杂度

### 5.1 递归栈 vs 辅助空间

```
分治空间 = 递归栈 + 辅助数组

归并排序：
  递归栈 O(log n) + 辅助数组 O(n) → 总 O(n)
  ⚠️ 辅助数组主导（合并需要临时数组）

快速排序：
  递归栈 O(log n)（期望）→ 总 O(log n)
  ⚠️ 原地分区无需辅助数组 → 空间更省

⚠️ 面试易错：归并排序空间说成 O(log n) ❌
  辅助数组 O(n) 是大头 → 说 O(n) 才对
```

### 5.2 空间优化的思路

```
① 归并排序：共享一个临时数组（全程复用）而非每层新建
   → 空间从 O(n log n) 降为 O(n)（实现细节）
② 原地归并（O(1) 辅助）：手摇算法，常数大，工程不实用
③ 自底向上归并：迭代版，省递归栈（空间仍 O(n)）
④ 快排：优先递归小半、迭代大半 → 栈深度压到 O(log n)

⚠️ 面试表达：
"归并空间 O(n) 来自辅助数组，递归栈只有 O(log n)；
 快排空间 O(log n) 来自递归栈，分区是原地的。"
```

## 6. 分治 vs 分块/回溯/二分

### 6.1 思想对比矩阵

| 思想 | 拆分方式 | 子问题处理 | 代表 |
|------|---------|-----------|------|
| 分治 | 对半/多份，递归解决 | 全部递归 + 合并 | 归并/快排/最大子序和 |
| 二分查找 | 对半，丢弃一侧 | 只递归一侧（单侧分治） | 二分/快选 |
| 分块（块状） | 分块维护，块内暴力 | 块内直接算 + 块间合并 | 莫队、分块求和 |
| 回溯 | 枚举决策树 | 逐层尝试 + 撤销 | 排列组合、N 皇后 |
| 动态规划 | 拆重叠子问题 | 缓存避免重复 | 背包、序列 DP |

```
⚠️ 关系澄清：
  二分查找 = 分治的特例（只进一侧，合并 O(1)）
  分块 = 分治的"静态版"（块数固定，块内暴力）
  回溯 = 递归 + 撤销（枚举所有方案，非"合并"）

面试表达：
"二分是单侧分治——它丢弃一半搜索空间；
 分治一般递归两侧再合并。快速选择就是二分思想的
 分治应用（只递归包含答案的一侧）。"
```

### 6.2 分治的选择依据

```
什么时候该用分治（决策链）：
  问题可对半拆？────── 否 → 考虑 DP/贪心/模拟
      ↓ 是
  子问题独立？─────── 否 → 重叠 → DP（记忆化）
      ↓ 是
  合并有定义？─────── 否 → 无法分治
      ↓ 是
  分治合并 < 其他方案？ 否 → 用更优算法（如 Kadane）
      ↓ 是
  → 分治（归并型/跨边界型/二分型）
```

## 7. 面试要点与追问

### 7.1 面试话术模板

```
"这题满足分治三条件：可对半拆、子问题独立、可合并。
 我用【形态】分治：基线是【...】，递归两侧，
 合并时【跨边界/归并计数】。递推方程 T(n)=【...】，
 主定理情形【一/二/三】→ O(【...】)。"
```

### 7.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 分治和递归什么关系？ | 分治是思想（拆-解-合），递归是实现机制 |
| 2 | 三类分治形态？ | 二分型（单侧）、归并型（线性合并）、跨边界型 |
| 3 | 主定理怎么用？ | 算 c=log_b(a)，比较 f(n) 与 n^c 定情形 |
| 4 | 快排为什么不用主定理？ | 分点随机，用期望分析（每次期望减半） |
| 5 | 归并空间复杂度？ | O(n)：辅助数组主导，递归栈仅 O(log n) |
| 6 | 子问题重叠怎么办？ | 加记忆化 → 退化为自顶向下 DP |
| 7 | 分治什么时候不是最优？ | 有专门算法更优时（Kadane O(n) vs 分治 O(n log n)） |
| 8 | 跨边界怎么识别？ | 最优解可能不完整落在某半 → 必须专门扫描 |

### 7.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 子问题重叠不分治 | 指数爆炸 | 记忆化 → DP |
| 跨边界漏计算 | 漏最优解 | 每层加跨中点扫描 |
| 主定理误用（快排） | 复杂度说错 | 期望分析 |
| 空间答 O(log n)（归并） | 面试减分 | 辅助数组 O(n) |
| 基线漏处理 | 无限递归 | lo == hi / 空区间判断 |

> 🎯 **核心要点**：分治理论三件套——**形态识别**（二分型/归并型/跨边界型决定复杂度）、**主定理**（c=log_b(a) 三情形比较）、**递归树**（层数 × 每层代价）。空间复杂度注意归并的辅助数组 O(n) 陷阱。
