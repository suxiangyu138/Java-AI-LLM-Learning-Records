## 1. 1. 两数之和（母题）

### 1.1 完整实现（先查后插）

```java
/**
 * LeetCode 1. 两数之和（面试第一题）
 * 关键细节：先检查再插入（防自匹配）
 */
public int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> map = new HashMap<>();   // 值 → 下标

    for (int i = 0; i < nums.length; i++) {
        int complement = target - nums[i];          // 补数
        if (map.containsKey(complement)) {
            return new int[]{map.get(complement), i};
        }
        map.put(nums[i], i);                        // ⚠️ 先查后插！
    }
    return new int[0];
}
// 推演 nums=[3,3], target=6：
//   i=0：补数 3 不在 map（还没存自己）→ 存 {3:0}
//   i=1：补数 3 在 map → 返回 [0,1] ✓
// ⚠️ 先插后查：i=0 时补数 3 在 map（自己！）→ [0,0] ✗
// ⚠️ 面试必答："先查后插防止元素匹配自身"
```

### 1.2 变体家族

```
167 有序版：对撞指针 O(n)/O(1)
15 三数之和：排序 + 固定 + 双指针
653 BST 版：中序有序 + 双指针
⚠️ 识别：有序 → 双指针；无序 → 哈希
```

## 2. 217. 存在重复元素

### 2.1 完整实现（三种解法）

```java
/**
 * LeetCode 217. 存在重复元素
 */
// 解法一：HashSet（推荐，O(n)）
public boolean containsDuplicate(int[] nums) {
    Set<Integer> set = new HashSet<>();
    for (int x : nums) {
        if (!set.add(x)) return true;   // ⚠️ add 返回 false = 已存在
    }
    return false;
}

// 解法二：排序（O(n log n)，O(1) 空间）
public boolean containsDuplicate_Sort(int[] nums) {
    Arrays.sort(nums);
    for (int i = 1; i < nums.length; i++) {
        if (nums[i] == nums[i - 1]) return true;
    }
    return false;
}
// ⚠️ 面试追问："HashSet.add 返回值？"
//   返回 boolean：false = 集合中已存在（未加入）
// ⚠️ 变体：219 存在重复 II（下标差 ≤ k → Map 存最新下标）
```

## 3. 242. 有效的字母异位词

### 3.1 完整实现（计数数组）

```java
/**
 * LeetCode 242. 有效的字母异位词
 * "anagram" vs "nagaram" → true
 * 计数数组双向加减 → 全部为 0 则异位词
 */
public boolean isAnagram(String s, String t) {
    if (s.length() != t.length()) return false;

    int[] count = new int[26];
    for (int i = 0; i < s.length(); i++) {
        count[s.charAt(i) - 'a']++;    // s 加
        count[t.charAt(i) - 'a']--;    // t 减
    }
    for (int c : count) {
        if (c != 0) return false;      // ⚠️ 任何计数不为 0 → 不同
    }
    return true;
}
// O(n) 时间 O(1) 空间（固定 26）
// ⚠️ 为什么双向加减？
//   一个数组完成比较（省一个数组 + 一次遍历）
// ⚠️ 值域大（Unicode）→ 改 HashMap
```

## 4. 49. 字母异位词分组

### 4.1 完整实现（两种键）

```java
/**
 * LeetCode 49. 字母异位词分组
 * 核心：找"规范键"（异位词共享的标识）
 */

// 方法一：排序键（直观）
public List<List<String>> groupAnagrams_Sort(String[] strs) {
    Map<String, List<String>> map = new HashMap<>();
    for (String s : strs) {
        char[] chars = s.toCharArray();
        Arrays.sort(chars);                 // 排序做键
        String key = new String(chars);     // "eat"→"aet"
        map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
    }
    return new ArrayList<>(map.values());
}
// 复杂度：O(n × k log k)（k = 词长）

// 方法二：计数键（更优，免排序）
public List<List<String>> groupAnagrams(String[] strs) {
    Map<String, List<String>> map = new HashMap<>();
    for (String s : strs) {
        int[] count = new int[26];
        for (char c : s.toCharArray()) count[c - 'a']++;

        StringBuilder key = new StringBuilder();
        for (int x : count) key.append('#').append(x);  // "#1#1#1#0..."
        map.computeIfAbsent(key.toString(),
            k -> new ArrayList<>()).add(s);
    }
    return new ArrayList<>(map.values());
}
// 复杂度：O(n × k)（免排序）
// ⚠️ 面试必答："计数键比排序键更优——
//   O(k) 而非 O(k log k)；面试讲两种方案 = 加分"
```

## 5. 128. 最长连续序列

### 5.1 完整实现（起点剪枝）

```java
/**
 * LeetCode 128. 最长连续序列（O(n)！）
 * 核心优化：起点剪枝——只有"没有前驱"的数才作为起点
 */
public int longestConsecutive(int[] nums) {
    Set<Integer> set = new HashSet<>();
    for (int x : nums) set.add(x);

    int maxLen = 0;
    for (int x : set) {                       // ⚠️ 遍历 set（去重后）
        if (!set.contains(x - 1)) {           // 剪枝：不是起点就跳过
            int cur = x, len = 1;
            while (set.contains(cur + 1)) {   // 向后扩展
                cur++;
                len++;
            }
            maxLen = Math.max(maxLen, len);
        }
    }
    return maxLen;
}
// 推演 [100,4,200,1,3,2]：
//   1 是起点（0 不在）→ 1,2,3,4 → len=4
//   3 不是起点（2 在）→ 跳过
//   → 答案 4 ✓
// ⚠️ 为什么 O(n)？
//   只有起点开始统计 → 每个数最多被统计一次
//   朴素做法（每个数都 while）→ O(n²)
// ⚠️ 面试必答："起点剪枝保证每个数只统计一次"
```

## 6. 560. 和为 K 的子数组

### 6.1 完整实现（前缀和 + 哈希）

```java
/**
 * LeetCode 560. 和为 K 的子数组
 * ⚠️ 为什么不用滑动窗口？
 *   含负数 → 扩窗不单调 → 滑窗失效
 *   → 前缀和 + 哈希
 */
public int subarraySum(int[] nums, int k) {
    Map<Integer, Integer> prefixCount = new HashMap<>();
    prefixCount.put(0, 1);        // ⚠️ 空前缀和为 0

    int sum = 0, count = 0;
    for (int x : nums) {
        sum += x;                            // 当前前缀和
        count += prefixCount.getOrDefault(sum - k, 0);   // 找 pre[r]-k
        prefixCount.put(sum, prefixCount.getOrDefault(sum, 0) + 1);
    }
    return count;
}
// 推演 [1,1,1], k=2：
//   初始化 {0:1}
//   x=1: sum=1, 查 -1 → 0；存 {0:1,1:1}
//   x=1: sum=2, 查 0 → 1（[1,1]）；存 {2:1}
//   x=1: sum=3, 查 1 → 1（[1,1]）；存 {3:1}
//   → 2 ✓
// ⚠️ 数学转化：
//   sum(l,r)=k ⇔ pre[r]-pre[l-1]=k ⇔ 找 pre[l-1]=pre[r]-k
// ⚠️ {0:1} 处理"从开头开始的和为 K 的子数组"
```

## 7. 347. 前 K 个高频元素

### 7.1 完整实现（频次桶）

```java
/**
 * LeetCode 347. 前 K 个高频元素
 * 频次桶：下标 = 频次 → 免排序 O(n)
 */
public int[] topKFrequent(int[] nums, int k) {
    // ① 计数
    Map<Integer, Integer> freq = new HashMap<>();
    for (int x : nums) freq.merge(x, 1, Integer::sum);

    // ② 频次桶
    List<Integer>[] buckets = new List[nums.length + 1];
    for (var e : freq.entrySet()) {
        int f = e.getValue();
        if (buckets[f] == null) buckets[f] = new ArrayList<>();
        buckets[f].add(e.getKey());
    }

    // ③ 从高频往低频收集
    int[] result = new int[k];
    int idx = 0;
    for (int f = buckets.length - 1; f > 0 && idx < k; f--) {
        if (buckets[f] != null) {
            for (int x : buckets[f]) result[idx++] = x;
        }
    }
    return result;
}
// 推演 [1,1,1,2,2,3], k=2：
//   freq: 1→3, 2→2, 3→1
//   桶[3]=[1], 桶[2]=[2], 桶[1]=[3]
//   从 3 收集：1；从 2 收集：2 → [1,2] ✓
// ⚠️ 对比堆 O(n log k)：频次桶 O(n) 更快（静态数组）
```

## 8. 146. LRU 缓存

### 8.1 完整实现（设计题之王）

```java
/**
 * LeetCode 146. LRU 缓存（哈希表 + 双向链表）
 * 哈希定位 O(1) + 链表排序 O(1)
 */
class LRUCache {
    class Node {
        int key, value;
        Node prev, next;
        Node(int k, int v) { key = k; value = v; }
    }

    private final int capacity;
    private final Map<Integer, Node> map = new HashMap<>();
    private final Node head = new Node(-1, -1);   // 虚拟头
    private final Node tail = new Node(-1, -1);   // 虚拟尾

    public LRUCache(int capacity) {
        this.capacity = capacity;
        head.next = tail;
        tail.prev = head;
    }

    public int get(int key) {
        Node node = map.get(key);
        if (node == null) return -1;
        moveToHead(node);              // ⚠️ 使用过 → 移到头部
        return node.value;
    }

    public void put(int key, int value) {
        Node node = map.get(key);
        if (node != null) {
            node.value = value;        // 更新值
            moveToHead(node);
        } else {
            node = new Node(key, value);
            map.put(key, node);
            addToHead(node);
            if (map.size() > capacity) {
                Node removed = removeTail();   // 淘汰最久未用
                map.remove(removed.key);       // ⚠️ 同步删哈希
            }
        }
    }

    // ── 双向链表四件套 ──────────────────────────
    private void addToHead(Node node) {
        node.next = head.next;
        node.prev = head;
        head.next.prev = node;
        head.next = node;
    }

    private void removeNode(Node node) {     // O(1) 任意删除！
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }

    private void moveToHead(Node node) {
        removeNode(node);
        addToHead(node);
    }

    private Node removeTail() {
        Node node = tail.prev;
        removeNode(node);
        return node;
    }
}
// ⚠️ 面试必答三问：
//   ① 为什么双向？删任意节点 O(1)（单链需找前驱）
//   ② 为什么节点存 key？删尾后同步删哈希
//   ③ 为什么虚拟头尾？边界统一免判空
```

## 9. 380. O(1) 时间插入、删除和获取随机元素

### 9.1 完整实现（尾删换顶）

```java
/**
 * LeetCode 380. O(1) 插入/删除/随机获取
 * 哈希定位 + 数组随机访问 + 尾删换顶
 */
class RandomizedSet {
    Map<Integer, Integer> indexMap = new HashMap<>();   // 值 → 下标
    List<Integer> values = new ArrayList<>();
    Random random = new Random();

    public boolean insert(int val) {
        if (indexMap.containsKey(val)) return false;
        indexMap.put(val, values.size());   // 记录下标
        values.add(val);
        return true;
    }

    public boolean remove(int val) {
        if (!indexMap.containsKey(val)) return false;

        int idx = indexMap.get(val);              // 待删下标
        int last = values.get(values.size() - 1); // 末尾元素

        values.set(idx, last);                    // ① 末尾补位
        indexMap.put(last, idx);                  // ② ⚠️ 更新补位者下标
        values.remove(values.size() - 1);         // ③ 删末尾 O(1)
        indexMap.remove(val);                     // ④ 删映射
        return true;
    }

    public int getRandom() {
        return values.get(random.nextInt(values.size()));
    }
}
// ⚠️ 为什么"尾删换顶"？
//   数组删中间 O(n)（移动）；换末尾再删 O(1)
// ⚠️ 关键：被换元素的下标要同步更新（哈希）
// ⚠️ 面试必答："哈希负责定位，数组负责随机，
//   删除用尾删换顶保持 O(1)"
```
