## 1. 核心概念

### 1.1 什么是线段树

> 线段树：二叉树结构，**每个节点代表一个区间**，叶子是单个元素，父节点是子区间合并结果。支持区间查询/区间更新的 O(log n) 操作。

```
数组 [1, 3, 5, 7, 9] 的线段树（存区间和）：

                [0,4]:25
              /         \
        [0,2]:9        [3,4]:16
        /     \        /     \
    [0,1]:4  [2,2]:5 [3,3]:7 [4,4]:9
    /     \
[0,0]:1  [1,1]:3

节点数：4n（数组存储，下标 1 开始）
  左孩子 = 2*i，右孩子 = 2*i+1

操作：
  build：O(n) 自底向上
  query(l, r)：O(log n) 区间覆盖
  update(pos, val)：O(log n) 单点
  update(l, r)：O(log n) 区间 + 懒标记
```

### 1.2 为什么是 4n 空间？

```
完全二叉树节点数 ≤ 2×2^ceil(log n) ≤ 4n
  下标 1 开始 + 2i/2i+1 孩子
  → 4n 安全（冗余但简单）

⚠️ 数组实现的常见错误：
  长度 2n 不够（只对"完美"情况）
  递归越界（hi 参数传递）
```

### 1.3 三大区间数据结构对比

| 结构 | 区间查询 | 区间更新 | 适用 |
|------|:---:|:---:|------|
| 前缀和 | O(1) | O(n)（重建） | 只查不改 |
| 树状数组 | O(log n) | O(log n) | 单点改+前缀查 |
| **线段树** | O(log n) | **O(log n)** | 区间改+区间查 |

```
记忆：前缀和"查快改慢"；线段树"改查都快"
  需要区间更新 → 线段树（含懒标记）
  只要单点更新 → 树状数组更简单
```

## 2. 完整代码模板

### 2.1 标准实现（区间和 + 单点更新）

```java
/**
 * LeetCode 307. 区域和检索 - 数组可修改（线段树版）
 * build / update / query 三递归，结构相同
 */
class SegmentTree {
    private int[] tree;          // 4n 数组
    private int n;

    public SegmentTree(int[] nums) {
        n = nums.length;
        tree = new int[4 * n];          // ⚠️ 4n 空间
        build(nums, 1, 0, n - 1);       // 从根 [0, n-1] 建树
    }

    private void build(int[] nums, int node, int lo, int hi) {
        if (lo == hi) {
            tree[node] = nums[lo];      // 叶子：单个元素
            return;
        }
        int mid = lo + (hi - lo) / 2;
        build(nums, node * 2, lo, mid);          // 左半
        build(nums, node * 2 + 1, mid + 1, hi);  // 右半
        tree[node] = tree[node * 2] + tree[node * 2 + 1];  // 合并
    }

    // 单点更新：nums[index] = val
    public void update(int index, int val) {
        update(1, 0, n - 1, index, val);
    }

    private void update(int node, int lo, int hi,
                        int index, int val) {
        if (lo == hi) {
            tree[node] = val;           // 叶子更新
            return;
        }
        int mid = lo + (hi - lo) / 2;
        if (index <= mid) {
            update(node * 2, lo, mid, index, val);      // 左
        } else {
            update(node * 2 + 1, mid + 1, hi, index, val);  // 右
        }
        tree[node] = tree[node * 2] + tree[node * 2 + 1];   // 回溯更新
    }

    // 区间查询 [l, r] 的和
    public int sumRange(int l, int r) {
        return query(1, 0, n - 1, l, r);
    }

    private int query(int node, int lo, int hi, int l, int r) {
        if (l <= lo && hi <= r) {
            return tree[node];          // ① 完全覆盖 → 直接返回
        }
        if (r < lo || hi < l) {
            return 0;                   // ② 不相交 → 返回单位元
        }
        int mid = lo + (hi - lo) / 2;
        return query(node * 2, lo, mid, l, r)      // ③ 部分覆盖
             + query(node * 2 + 1, mid + 1, hi, l, r);
    }
}
// 三个操作均 O(log n)
// 三递归结构相同：node/lo/hi 参数 + 二分区间
```

### 2.2 查询三分支的理解

```
query 的三种情况：
  ① 完全覆盖（l ≤ lo && hi ≤ r）→ 节点值直接可用
  ② 完全不相交（r < lo || hi < l）→ 返回 0（单位元）
  ③ 部分覆盖 → 递归两半

⚠️ 合并语义（单位元）：
  求和：0
  最大值：Integer.MIN_VALUE
  最小值：Integer.MAX_VALUE
  → 单位元必须与"合并操作"匹配
```

### 2.3 线段树的可定制性

```
节点存什么由合并操作决定：
  区间和：tree = left + right（合并 +）
  区间最大：tree = max(left, right)（合并 max）
  区间最大公约数：tree = gcd(left, right)
  区间乘积：tree = left × right

⚠️ 只改 build/update 的合并行即可复用框架
  → 线段树是"区间可合并信息"的通用工具
```

## 3. 懒标记详解

### 3.1 区间更新的问题

```
区间更新（如 [l, r] 全部 +v）：
  朴素：逐点 update → O(n log n) 太慢

懒标记思想：
  区间完全覆盖节点时：只更新节点值 + 打标记
  （"欠着"子节点：将来需要时再下推）
  访问子节点前先"下推"（pushDown）
  → 区间更新 O(log n)
```

### 3.2 懒标记模板（区间加 + 区间和）

```java
/**
 * 带懒标记的线段树（区间加 + 区间求和）
 * ⚠️ 懒标记是线段树最难部分，面试了解原理即可
 */
class LazySegmentTree {
    private long[] tree;      // 区间和
    private long[] lazy;      // 懒标记（待下推的增量）
    private int n;

    // 区间 [l, r] 全部 +val
    public void rangeAdd(int node, int lo, int hi, int l, int r, int val) {
        if (l <= lo && hi <= r) {
            tree[node] += (long) val * (hi - lo + 1);
            lazy[node] += val;             // ⚠️ 打标记（欠着子节点）
            return;
        }
        pushDown(node, lo, hi);            // ⚠️ 先下推再递归
        int mid = lo + (hi - lo) / 2;
        if (l <= mid) rangeAdd(node*2, lo, mid, l, r, val);
        if (r > mid)  rangeAdd(node*2+1, mid+1, hi, l, r, val);
        tree[node] = tree[node*2] + tree[node*2+1];
    }

    // 下推：把懒标记分给两个孩子
    private void pushDown(int node, int lo, int hi) {
        if (lazy[node] != 0) {
            int mid = lo + (hi - lo) / 2;
            tree[node*2] += lazy[node] * (mid - lo + 1);
            lazy[node*2] += lazy[node];
            tree[node*2+1] += lazy[node] * (hi - mid);
            lazy[node*2+1] += lazy[node];
            lazy[node] = 0;                // ⚠️ 清空标记
        }
    }
}
// 区间更新 O(log n)：完全覆盖打标记，部分覆盖下推
```

### 3.3 懒标记的核心理解

```
"打标记 = 记账，下推 = 还账"
  完全覆盖：记在节点上（不实际更新子节点）
  需要子节点时：先还账（下推）再操作

⚠️ 面试表达：
  "区间更新用懒标记：完全覆盖时 O(1) 更新
   节点并打标记，需要访问子节点时先下推。
   这样区间更新也是 O(log n)。
   懒标记是实现细节，面试通常不要求手写
   完整版，能讲原理即可。"
```

## 4. 线段树 vs 树状数组

### 4.1 对比表

| 维度 | 线段树 | 树状数组 |
|------|:---:|:---:|
| 区间查询 | ✅ 任意区间 | ⚠️ 只能前缀 |
| 区间更新 | ✅ 懒标记 | 差分技巧 |
| 代码量 | 多（三递归） | 少（三行） |
| 常数 | 大 | 小 |
| 可扩展 | 任意可合并信息 | 和/异或等可逆 |

```
选型：
  任意区间 + 区间更新 → 线段树
  单点更新 + 前缀查询 → 树状数组（更简单）
  面试手写优先树状数组（代码短）
```

### 4.2 什么时候必须线段树

```
① 任意区间查询（非前缀）：
   树状数组只能查 [1, i]（前缀）
   任意 [l, r] → 线段树
② 区间更新 + 区间查询：
   树状数组需要差分技巧（较绕）
③ 不可逆合并（max/min）：
   树状数组依赖可逆性（和/异或）
   max 查询 → 线段树

⚠️ 记忆："树状数组 = 前缀 + 可逆；线段树 = 全能"
```

### 4.3 离散化（值域压缩）

```
值域大（负数/10⁹）时不能直接开数组：
  排序去重 → 排名映射（0..k-1）
  线段树只关心"相对大小"
  → 空间 O(k) 而非 O(值域)

⚠️ 应用：315 右侧更小、327 区间和个数
  面试必提："值域大先离散化"
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"这题需要区间查询 + 单点更新 → 线段树：
 4n 数组存区间和，build 自底向上 O(n)，
 查询/更新都是区间二分 O(log n)。
 相比前缀和（更新 O(n)），线段树两种操作
 都 O(log n)，适合动态数组。
 值域大时先离散化。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 为什么 4n 空间？ | 完全二叉树 ≤ 2×2^ceil(log n) ≤ 4n（下标 1 起） |
| 2 | 什么时候选线段树？ | 任意区间 + 更新组合；树状数组只能前缀 |
| 3 | 懒标记是什么？ | 完全覆盖打标记（O(1)），需要子节点时下推 |
| 4 | 与树状数组选型？ | 单点+前缀 → 树状（简单）；区间+任意 → 线段树 |
| 5 | 离散化？ | 值域大 → 排名映射（空间 O(k)） |
| 6 | 合并操作可定制？ | 求和/max/gcd 只改合并行 |
| 7 | 单位元是什么？ | 求和 0、max MIN_VALUE（与合并匹配） |
| 8 | 面试需要手写吗？ | 简单版（单点+区间）要会；懒标记讲原理 |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 数组长度 2n | 越界 | 4n 安全 |
| 忘处理不相交 | 递归错误 | query 先判相交 |
| 单位元用错 | 结果错 | 匹配合并操作 |
| 懒标记忘清空 | 重复下推 | pushDown 后 lazy=0 |
| 边界 hi 传错 | 越界 | mid+1 正确传递 |

> 🎯 **核心要点**：线段树 = **4n 数组 + build/query/update 三递归**。识别信号："区间查询 + 数组可修改"。简单版（单点更新）面试要会写，懒标记（区间更新）讲原理即可；数据范围大记得离散化。
