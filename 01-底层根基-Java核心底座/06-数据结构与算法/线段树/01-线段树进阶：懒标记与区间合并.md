## 1. 线段树的结构与操作

### 1.1 结构

```
线段树 = 完全二叉树的区间划分：
  根 = 全区间 [1, n]
  每个节点 = 左半 + 右半
  叶子 = 单点

⚠️ 空间：4n（数组版，安全上界）
⚠️ 高度：O(log n)

⚠️ 面试必答：
"线段树把区间操作拆成 O(log n) 段——
 查询/更新都是'区间递归'，每层至多
 访问 4 个节点。"
```

### 1.2 三大基础操作

```java
/** 线段树数组版（求和为例） */
class SegmentTree {
    int[] tree;                              // 4n
    int n;

    SegmentTree(int[] nums) {
        n = nums.length;
        tree = new int[4 * n];
        build(nums, 1, 0, n - 1);
    }

    /** 建树：叶子存单点，内部合并 */
    void build(int[] nums, int node, int l, int r) {
        if (l == r) { tree[node] = nums[l]; return; }
        int mid = (l + r) / 2;
        build(nums, node * 2, l, mid);               // 左半
        build(nums, node * 2 + 1, mid + 1, r);       // 右半
        tree[node] = tree[node * 2] + tree[node * 2 + 1];   // ⚠️ 合并
    }

    /** 单点更新：递归定位叶子 */
    void update(int node, int l, int r, int idx, int val) {
        if (l == r) { tree[node] = val; return; }
        int mid = (l + r) / 2;
        if (idx <= mid) update(node * 2, l, mid, idx, val);
        else update(node * 2 + 1, mid + 1, r, idx, val);
        tree[node] = tree[node * 2] + tree[node * 2 + 1];   // 回溯合并
    }

    /** 区间查询：三种情况（完全覆盖/部分/无交集） */
    int query(int node, int l, int r, int ql, int qr) {
        if (ql <= l && r <= qr) return tree[node];     // ⚠️ 完全覆盖
        int mid = (l + r) / 2;
        int sum = 0;
        if (ql <= mid) sum += query(node * 2, l, mid, ql, qr);       // 左半有交集
        if (qr > mid) sum += query(node * 2 + 1, mid + 1, r, ql, qr); // 右半
        return sum;
    }
}
// ⚠️ 复杂度：build O(n)、update/query O(log n)
// ⚠️ 面试必答："线段树三操作——建树（递归合并）、
//   更新（定位叶子回溯）、查询（完全覆盖即返回）。"
```

## 2. 节点信息设计：可合并性

### 2.1 合并信息的核心

```
线段树的节点必须"可合并"：
  parent 的值 = f(left, right)

⚠️ 可合并的信息：
  求和、最大值、最小值、计数、异或
  （前缀和/频次等"可结合"运算）

⚠️ 不可直接合并：
  中位数、众数（需要全局信息）

⚠️ 面试必答：
"线段树节点存'可合并信息'——
 和/最值/计数是标准；中位数等
 不可合并信息不适合线段树。"
```

### 2.2 复杂合并：区间最大子段和

```
53 最大子序和的线段树版：
  节点存 4 个量：
    sum（区间和）
    maxL（从左开始的最大子段）
    maxR（从右结束的最大子段）
    maxM（区间最大子段）

合并公式：
  sum = L.sum + R.sum
  maxL = max(L.maxL, L.sum + R.maxL)
  maxR = max(R.maxR, R.sum + L.maxR)
  maxM = max(L.maxM, R.maxM, L.maxR + R.maxL)

⚠️ 面试必答：
"'可合并'是关键——53 的 4 元组
 是'信息足够合并'的最小集合；
 这就是分治与线段树的统一视角。"
```

## 3. 区间更新与懒标记

### 3.1 懒标记（Lazy Propagation）

```
区间更新（如 [l, r] 全部 +v）：
  朴素：递归更新每个叶子 → O(n log n) 太慢
  懒标记：完全覆盖时只更新节点 + 打标记，不递归
  需要时才"下推"标记到子节点

⚠️ 面试必答：
"懒标记 = 更新'停在上层'——
 完全覆盖时记标记不下传；
 访问子节点时再下推（pushDown）。
 区间更新从 O(n log n) 降到 O(log n)。"
```

### 3.2 懒标记实现要点

```java
/** 懒标记核心：下推（pushDown） */
long[] tree, lazy;                           // lazy[node] = 待下推的增量

void pushDown(int node, int l, int r) {
    if (lazy[node] != 0 && l != r) {         // ⚠️ 有标记且非叶子
        int mid = (l + r) / 2;
        apply(node * 2, l, mid, lazy[node]);         // 左孩子
        apply(node * 2 + 1, mid + 1, r, lazy[node]); // 右孩子
        lazy[node] = 0;                      // ⚠️ 标记清空
    }
}

void apply(int node, int l, int r, long v) {
    tree[node] += v * (r - l + 1);           // 更新区间和
    lazy[node] += v;                         // ⚠️ 打标记（未下传）
}

/** 区间更新 */
void rangeUpdate(int node, int l, int r, int ql, int qr, long v) {
    if (ql <= l && r <= qr) { apply(node, l, r, v); return; }   // ⚠️ 完全覆盖：懒
    pushDown(node, l, r);                    // ⚠️ 先下推再递归
    int mid = (l + r) / 2;
    if (ql <= mid) rangeUpdate(node * 2, l, mid, ql, qr, v);
    if (qr > mid) rangeUpdate(node * 2 + 1, mid + 1, r, ql, qr, v);
    tree[node] = tree[node * 2] + tree[node * 2 + 1];
}
// ⚠️ 面试必答："懒标记三要点——完全覆盖打标、
//   递归前下推、回溯后合并。
//   '标记不下传'是 O(log n) 的关键。"
```

## 4. 动态开点线段树

### 4.1 为什么需要

```
静态 4n 数组的问题：
  值域巨大（1e9）→ 4n 数组不可行
  但实际访问的节点很少（稀疏）

动态开点：用到哪个节点才创建（指针/Map）
  ⚠️ 空间从 O(4n) 降到 O(访问节点数)

⚠️ 面试必答：
"动态开点 = 按需建节点——
 值域 1e9 也能线段树（只建访问路径）；
 实现用节点数组 + 左右孩子下标。"
```

### 4.2 动态开点要点

```java
/** 动态开点：节点数组 + 左右指针 */
class Node {
    long val, lazy;
    int left, right;                         // ⚠️ 孩子下标（0 = 未创建）
}
Node[] nodes = new Node[MAX_NODES];          // 预分配上限
int nodeCount = 0;

int newNode() {
    nodes[++nodeCount] = new Node();
    return nodeCount;
}
// ⚠️ 查询/更新时若孩子为 0 → 先创建
// ⚠️ 应用：值域巨大区间题（如 1e9 的区间赋值）
```

## 5. 离散化与坐标压缩

### 5.1 为什么需要

```
线段树的下标要求连续：
  坐标 1e9 的区间 → 无法直接建树
  离散化：把出现过的坐标压缩到 1..m

⚠️ 与树状数组的离散化一致（见树状数组/01）
⚠️ 注意：区间类问题离散化后是"点"还是"段"
  → 段要用"左闭右开"或"点间空隙"处理

⚠️ 面试必答：
"离散化把大坐标压到出现值的排名——
 线段树/树状数组都能用；
 区间题注意'点 vs 段'的边界处理。"
```

### 5.2 离散化模板

```java
/** 坐标离散化：值 → 排名（1 基） */
int[] discretize(int[] coords) {
    int[] sorted = coords.clone();
    Arrays.sort(sorted);
    int m = 1;
    for (int i = 1; i < sorted.length; i++)
        if (sorted[i] != sorted[m - 1]) sorted[m++] = sorted[i];
    int[] rank = new int[coords.length];
    for (int i = 0; i < coords.length; i++)
        rank[i] = Arrays.binarySearch(sorted, 0, m, coords[i]) + 1;
    return rank;
}
// ⚠️ 复杂度：O(n log n)（排序 + 二分）
```

## 6. 线段树 vs 树状数组 vs 平衡树

### 6.1 三方案对比

| 维度 | 线段树 | 树状数组 | 平衡树 |
|------|:---:|:---:|:---:|
| 区间和/最值 | ✅ | 和（不可最值） | 和（慢） |
| 区间更新 | ✅ 懒标记 | ⚠️ 差分变体 | ❌ |
| 有序性操作（第 K 小） | ⚠️ 复杂 | ✅ 值域版 | ✅ |
| 代码量 | ★★★ | ★ | ★★ |
| 空间 | 4n/动态 | n | n |

```
⚠️ 选型：
  区间更新 + 区间查 → 线段树（懒标记）
  单点改 + 区间和 → 树状数组（最简）
  需要有序集合操作 → 平衡树（TreeSet）

⚠️ 面试必答：
"'区间更新'是线段树的独门（懒标记）；
 纯求和用树状数组（代码最短）；
 有序操作（floor/ceiling）用平衡树。
 选型看'需要什么操作'。"
```

### 6.2 简单工具优先原则

```
⚠️ 工程原则：先问"有没有更简单的工具"
  729 日程表：TreeMap floor/ceiling 即可
    （线段树是杀鸡用牛刀）
  220 存在重复 III：桶/有序集合更直接

⚠️ 面试必答：
"'能用简单工具就不用线段树'——
 面试先给最简解，线段树作为
 '区间更新'场景的答案。"
```

## 7. 面试要点与追问

### 7.1 面试话术模板

```
"线段树 = 区间操作的 O(log n) 工具。
 三操作：建树（合并）、更新（回溯）、
 查询（完全覆盖返回）。
 节点信息必须'可合并'（和/最值/4 元组）。
 区间更新用懒标记（覆盖打标、递归前下推）。
 值域大用动态开点/离散化。
 选型：区间更新线段树、纯求和树状数组、
 有序操作平衡树。"
```

### 7.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 空间？ | 4n（数组版） |
| 2 | 三操作？ | 建/更/查 O(log n) |
| 3 | 节点存什么？ | 可合并信息 |
| 4 | 懒标记？ | 覆盖打标 + 下推 |
| 5 | 值域大？ | 动态开点/离散化 |
| 6 | vs 树状数组？ | 区间更新 vs 纯求和 |
| 7 | vs 平衡树？ | 有序操作用平衡树 |
| 8 | 什么时候不用？ | 有更简单工具时 |

### 7.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 数组开 2n | 越界 | 4n |
| 查询忘完全覆盖判断 | 重复计算 | 三种情况 |
| 懒标记忘下推 | 子节点旧值 | pushDown |
| 区间更新忘回溯 | 父节点错 | 合并 |
| 复杂信息合并公式错 | 结果错 | 4 元组验证 |
