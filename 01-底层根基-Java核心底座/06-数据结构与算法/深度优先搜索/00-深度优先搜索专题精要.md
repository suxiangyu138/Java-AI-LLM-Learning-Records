## 1. 核心概念

### 1.1 DFS 的本质

> DFS = **一条路走到底**，走不通回退换路。栈/递归实现，天然适合"路径/连通块"问题。

```
前序（自顶向下）：根信息传叶子 → 路径题
后序（自底向上）：子树信息聚合 → 属性题

判定："左右孩子给我答案能合并？"
  能 → 后序；不能 → 前序

DFS vs BFS：
  所有方案/存在/连通 → DFS
  最短/最少/层序 → BFS
```

### 1.2 识别信号

```
"所有方案/路径" → DFS（257/79）
"连通块大小/数量" → DFS（200/695）
"是否存在路径" → DFS（841）
"树的属性" → DFS（104/124）
"图判环/染色" → DFS 颜色法（207/785）

⚠️ 一句话："存在性/枚举/聚合 → DFS；最短/最少 → BFS"
```

### 1.3 DFS vs BFS 对比

| 维度 | DFS | BFS |
|------|:---:|:---:|
| 数据结构 | 栈/递归 | 队列 |
| 顺序 | 深度优先 | 逐层 |
| 最短路径 | ❌ | ✅ 无权图 |
| 所有方案 | ✅ | 不擅长 |
| 空间 | O(深度)（小） | O(层宽)（大） |
| 连通块 | ✅ | ✅ |

```
选型口诀：
  "最短/最少/最近" → BFS
  "所有方案/存在/连通" → DFS
```

## 2. 完整代码模板

### 2.1 树 DFS 模板

```java
/**
 * 树 DFS 通用模板
 * 要素：递归出口（null 判断）+ 处理逻辑 + 递归调用
 */
public void treeDFS(TreeNode root, 参数) {
    if (root == null) return;              // ① 递归出口

    处理当前节点(root);                     // ② 前序处理

    treeDFS(root.left, 新参数);            // ③ 递归左
    treeDFS(root.right, 新参数);           // ④ 递归右
}

// 后序（需要子树信息）：
int postorder(TreeNode node) {
    if (node == null) return 0;
    int left = postorder(node.left);       // 先递归
    int right = postorder(node.right);
    return 合并(left, right, node);        // 后处理
}
// 例：104 最大深度 = max(左,右)+1
```

### 2.2 网格 DFS 模板（沉岛）

```java
/**
 * 网格 DFS 四步模板
 * ① 越界 → ② 条件 → ③ 标记（递归前！）→ ④ 四方向
 */
public void gridDFS(char[][] grid, int i, int j) {
    int m = grid.length, n = grid[0].length;

    // ① 越界判断
    if (i < 0 || i >= m || j < 0 || j >= n) return;
    // ② 条件（障碍/已访问）
    if (grid[i][j] != '1') return;

    // ③ 标记（⚠️ 必须在递归前！）
    grid[i][j] = '0';

    // ④ 四方向递归
    gridDFS(grid, i + 1, j);
    gridDFS(grid, i - 1, j);
    gridDFS(grid, i, j + 1);
    gridDFS(grid, i, j - 1);
}
// ⚠️ 标记太晚 → 相邻格子来回递归 → 栈溢出！
// 沉岛（1→0）代替 visited → O(1) 额外空间
```

### 2.3 图 DFS 模板（颜色法判环）

```java
/**
 * 图 DFS：visited 数组 + 颜色法判环
 * ⚠️ 图与树不同：树无环免 visited，图必须！
 */
public void graphDFS(List<List<Integer>> graph, int node,
                     boolean[] visited) {
    visited[node] = true;                  // 标记

    for (int next : graph.get(node)) {
        if (!visited[next]) {
            graphDFS(graph, next, visited);
        }
    }
}
// ⚠️ 图可能不连通 → for 循环遍历所有起点

/**
 * 颜色法判环（207 课程表）：
 * 颜色：0 未访问 / 1 访问中 / 2 已完成
 * 递归中遇到"访问中"(1) → 有环！
 */
private boolean hasCycle(List<List<Integer>> graph, int node, int[] color) {
    color[node] = 1;                     // 访问中（在递归栈上）
    for (int next : graph.get(node)) {
        if (color[next] == 1) return true;      // ⚠️ 环！
        if (color[next] == 0 && hasCycle(graph, next, color)) return true;
    }
    color[node] = 2;                     // 已完成
    return false;
}
```

## 3. 三大形态详解

### 3.1 形态一：树 DFS（遍历/属性）

```
前序（传参）：路径总和、所有路径
后序（聚合）：深度、直径、平衡、LCA

⚠️ 有状态模式：
  返回值 = 子树信息（给父节点）
  外部变量 = 全局答案（直径/路径和）
  例：直径可能不经过根 → 必须全局记录
```

### 3.2 形态二：网格 DFS（沉岛/回溯）

```
沉岛（永久标记）：连通块计数（200/695）
  → 标记后不用恢复（岛永久消失）

回溯（标记+撤销）：路径搜索（79 单词搜索）
  → 需要探索其他方向 → 必须恢复

⚠️ 关键问题："需要恢复吗？"
  计数/连通 → 不恢复（沉岛）
  路径搜索 → 恢复（回溯）
```

### 3.3 形态三：图 DFS（遍历/染色/判环）

```
visited：防重复访问（图有环/共享节点）
颜色法：0/1/2 三态判环（207）
染色：两色互斥判二分图（785）

⚠️ 面试必答：
"图必须 visited——图可能有环，
 不标记会无限递归。
 判环用颜色法（区分访问中与已完成）。"
```

## 4. DFS 的关键技巧

### 4.1 标记的时机（最大坑）

```
⚠️ 标记必须在递归前：
  标记太晚 → 相邻格子互相发现 → 来回递归 → 栈溢出

✅ 正确顺序：
  越界判断 → 条件判断 → 标记 → 递归四方向

⚠️ 面试必答：
"网格 DFS 标记必须在递归前——
 否则相邻格子会互相递归，直接栈溢出。"
```

### 4.2 记忆化 DFS（重叠子问题）

```
DFS + 缓存 = 记忆化搜索（DP 的递归形态）
  重叠子问题 → 缓存 → O(状态数)

⚠️ 何时不需要 visited？
  转移"单调"（递增/减少）→ 天然无环
  例：329 递增路径（只走向更大的值）

⚠️ 面试必答：
"记忆化防重复计算；visited 防重复访问。
 递增场景天然无环 → 只需记忆化。"
```

### 4.3 递归深度与栈溢出

```
递归深度分析：
  树高 h → 深度 h
  链表长度 n → 深度 n（危险）
  网格最坏 m×n

应对：显式栈迭代（堆内存）

⚠️ 面试表达：
"DFS 递归深度可能 O(mn)，
 可以转显式栈迭代防栈溢出。"
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"求连通块 → DFS。一条路走到底，遇到边界回头。
 网格 DFS 四步：越界判断 → 条件判断 →
 标记（沉岛）→ 四方向递归。
 标记必须在递归前，否则相邻格子来回递归
 会栈溢出。
 我用沉岛（改成 0）代替 visited 数组，
 省 O(mn) 额外空间。
 每个格子最多访问一次 → O(mn)。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | DFS 和 BFS 怎么选？ | 所有方案/连通 → DFS；最短 → BFS |
| 2 | 标记为什么在递归前？ | 标记太晚 → 来回递归 → 栈溢出 |
| 3 | 沉岛 vs visited vs 回溯？ | 计数不恢复；路径搜索要恢复 |
| 4 | 图为什么必须 visited？ | 图有环/共享节点（树无环才不用） |
| 5 | 颜色法判环？ | 0/1/2 三态；遇到访问中即环 |
| 6 | 记忆化 vs visited？ | 记忆化防重算；visited 防回访 |
| 7 | 递归深度？ | O(深度)；过大转显式栈 |
| 8 | 与回溯关系？ | 回溯 = DFS + 撤销 |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 标记在递归后 | 栈溢出 | 标记前移 |
| 图忘 visited | 无限递归 | 加 visited |
| 路径搜索忘撤销 | 结果重复 | 成对恢复 |
| 漏连通分量 | 结果少 | for 遍历起点 |
| 记忆化忘查缓存 | 重复计算 | 查+存 |

> 🎯 **核心要点**：DFS = **模板（树/网格/图/记忆化）+ 两个关键问题**（"标记在递归前吗？""需要恢复吗？"）+ **判环三色法**。200/79/207 三题覆盖沉岛、回溯、判环三大形态。DFS 是回溯、记忆化 DP、树形 DP 的公共底盘。
