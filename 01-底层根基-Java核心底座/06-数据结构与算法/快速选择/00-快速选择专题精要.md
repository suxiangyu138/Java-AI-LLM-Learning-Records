## 1. 核心概念

### 1.1 什么是快速选择

> 快速选择（Quick Select）：基于快排的 partition 操作，**只递归包含答案的一侧**，平均 O(n) 找第 K 大/小元素。

```
partition 后：
  pivot 左侧 < pivot，右侧 > pivot
  pivot 下标 = k → 找到答案
  pivot 下标 < k → 答案在右侧（只递归右侧！）
  pivot 下标 > k → 答案在左侧

⚠️ 必须随机化基准（或三数取中）：
  有序数组 + 固定基准 → 每次只排除一个 → O(n²)
  随机基准 → 期望 O(n)
```

### 1.2 与快排的关系

```
快排：partition 后递归两侧（排序全部）
快选：partition 后只递归一侧（只找第 K）

复杂度差异：
  快排：T(n) = 2T(n/2) + O(n) → O(n log n)
  快选：T(n) = T(n/2) + O(n) → O(n)（等比求和）

记忆："快排排全部，快选选一个"
```

### 1.3 识别信号

```
"第 K 大/第 K 小/中位数/前 K 个" + 静态数组
→ 快速选择（或堆）

选型：
  静态数组（全量已知）→ 快速选择 O(n)
  数据流/在线 → 堆 O(n log k)
  不允许修改数组 → 堆（快选会原地交换）
```

## 2. 完整代码模板

### 2.1 标准实现（215. 数组中的第 K 个最大元素）

```java
/**
 * LeetCode 215. 数组中的第 K 个最大元素（快速选择版）
 * 第 K 大 = 排序后第 n-K 个位置（0-indexed）
 */
public int findKthLargest(int[] nums, int k) {
    return quickSelect(nums, 0, nums.length - 1, nums.length - k);
}

private int quickSelect(int[] arr, int lo, int hi, int target) {
    if (lo == hi) return arr[lo];

    // ① ⚠️ 随机化基准（防有序数组退化）
    int randomIdx = lo + new Random().nextInt(hi - lo + 1);
    swap(arr, randomIdx, hi);

    // ② partition：小于基准的放左边
    int pivot = arr[hi];
    int i = lo - 1;
    for (int j = lo; j < hi; j++) {
        if (arr[j] < pivot) {
            swap(arr, ++i, j);
        }
    }
    swap(arr, i + 1, hi);              // 基准归位
    int pivotIdx = i + 1;

    // ③ ⚠️ 只递归一侧
    if (pivotIdx == target) {
        return arr[pivotIdx];
    } else if (pivotIdx < target) {
        return quickSelect(arr, pivotIdx + 1, hi, target);   // 右侧
    } else {
        return quickSelect(arr, lo, pivotIdx - 1, target);   // 左侧
    }
}

private void swap(int[] arr, int i, int j) {
    int tmp = arr[i]; arr[i] = arr[j]; arr[j] = tmp;
}
```

### 2.2 推演：nums = [3, 2, 1, 5, 6, 4], k = 2

```
第 2 大 = 第 4 小（n-k = 4，0-indexed）
假设随机基准选 4（交换到末尾后 partition）：

pivot=4：partition 后 [3,2,1,4,6,5]，pivotIdx=3
  3 < 4 → 递归右侧 [5,6]（下标 4-5）
  ⚠️ 只递归一侧！左侧 [3,2,1] 完全跳过

右侧 partition：随机基准 5 → [5,6]，pivotIdx=4 == target
  → 返回 5 ✓（第 2 大 = 5）
```

### 2.3 迭代版（防递归栈）

```java
/**
 * 迭代版快选（无递归栈风险）
 */
public int quickSelectIterative(int[] arr, int k) {
    int lo = 0, hi = arr.length - 1;
    int target = arr.length - k;         // 第 k 大位置

    while (lo < hi) {
        // 随机基准 + partition（同上）
        int pivotIdx = partition(arr, lo, hi);

        if (pivotIdx == target) break;
        else if (pivotIdx < target) lo = pivotIdx + 1;
        else hi = pivotIdx - 1;
    }
    return arr[target];
}
```

## 3. 复杂度分析

### 3.1 平均 O(n) 的推导

```
每轮 partition O(n)，只递归一侧：
  T(n) = T(n/2) + O(n)   （理想：均匀划分）
       = n + n/2 + n/4 + ...
       = 2n（等比数列求和）
  → 平均 O(n)

对比：
  堆：O(n log k)
  排序：O(n log n)
  快选是找第 K 的最快平均算法
```

### 3.2 最坏 O(n²) 与随机化

```
最坏场景：每次 partition 极度不平衡
  有序数组 + 固定基准（首/尾）：
  每次只排除一个元素 → T(n) = T(n-1) + O(n) = O(n²)

随机化基准：
  任何输入下 pivot 位置均匀分布
  → 期望划分均衡 → 期望 O(n)
  → 最坏概率 = (1/n)^n 趋近 0

⚠️ 面试必答："我随机化基准，防止有序数组
  退化成 O(n²)——这是快选/快排的经典陷阱。"
```

### 3.3 空间复杂度

```
递归版：O(log n)（递归栈，期望深度）
迭代版：O(1)
⚠️ 注意：快选会原地修改数组（partition 交换）
  不可变数组场景 → 用堆
```

## 4. 快速选择 vs 堆

### 4.1 对比表

| 维度 | 快速选择 | 堆 |
|------|:---:|:---:|
| 平均复杂度 | **O(n)** | O(n log k) |
| 最坏 | O(n²)（随机化缓解） | O(n log k) 稳定 |
| 空间 | O(log n) 递归 | O(k) |
| 数据流 | ❌ 需全量数组 | ✅ 在线 |
| 修改数组 | ✅ 原地交换 | 只读 |
| 实现 | 稍复杂 | 简单 |

### 4.2 选型决策

```
静态数组（全量已知）→ 快速选择（更快）
数据流/在线 → 堆（必须在线）
不允许修改 → 堆（快选破坏原数组）
k 极小/极大 → 堆可能更简单

面试话术：
"两种方案我都掌握——快选平均 O(n) 更快
 但需全量数组且会修改；堆 O(n log k) 稳定
 且支持在线。这题是【静态/流式】，
 我选【...】。"
```

### 4.3 中位数 = 快选的特例

```
找中位数 = 第 n/2 小的快选 → 平均 O(n)

应用：462 最少移动使相等（中位数原理）
     324 摆动排序 II（中位数 + 三路重排）

⚠️ 快选返回的是"值"不是"下标"
  需要中位数下标 → 记录 partition 结果
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"第 K 大用快速选择：
 ① partition 后基准位置 == 目标 → 返回；
 ② 否则只递归包含答案的一侧；
 ③ 每轮 O(n) 且区间减半 → 平均 O(n)；
 ④ 随机化基准防有序数组退化 O(n²)。
 对比堆：快选 O(n) 更快但需全量数组。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 为什么平均 O(n)？ | 只递归一侧：n + n/2 + n/4... = 2n |
| 2 | 为什么要随机基准？ | 有序 + 固定基准 → 每次排除 1 个 → O(n²) |
| 3 | 第 K 大 vs 第 K 小？ | 第 K 大 = 第 n-K 小（下标换算） |
| 4 | 快选会改数组吗？ | 会（原地 partition）；不可变场景用堆 |
| 5 | 与堆怎么选？ | 静态快选 O(n)；流式/只读堆 O(n log k) |
| 6 | 中位数怎么做？ | 快选第 n/2 小 → 平均 O(n) |
| 7 | 递归栈溢出？ | 深度期望 O(log n)；可写迭代版 |
| 8 | 与快排关系？ | 快排递归两侧；快选只递归一侧 |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 忘随机化基准 | 有序输入超时 | 随机交换到 hi |
| 递归两侧 | 退化成快排 O(n log n) | 只递归一侧 |
| 第 K 大下标错 | 返回错误值 | target = n - k |
| 比较方向反 | 第 K 大变第 K 小 | 确认排序方向 |
| 忘处理 lo==hi | 无限递归 | 基线判断 |

> 🎯 **核心要点**：快速选择 = **随机化 partition + 只递归一侧**。识别信号："第 K 大/小、中位数、TopK"（静态数组）。与堆的选型（快/改数组 vs 稳/只读）是面试必答点。平均 O(n) 推导（等比求和）要能讲。
