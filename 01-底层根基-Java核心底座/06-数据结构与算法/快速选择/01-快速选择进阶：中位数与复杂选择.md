## 1. 中位数：第 K 大的特例

### 1.1 中位数与第 K 的关系

```
中位数 = 第 ⌈n/2⌉ 大（或第 (n+1)/2 小）
  → 快选一次即可 O(n) 期望

⚠️ 中位数的重要性：
  ① 绝对差和最小（462 题的核心性质）
  ② 稳健统计量（不受极端值影响，均值相反）
  ③ 双堆数据流的流式答案（295）

⚠️ 面试表达：
"中位数是快选最经典的调用——第 (n+1)/2 小。
 它的性质'绝对差和最小'来自排序后
 中位数两侧对称。"
```

### 1.2 中位数的数学性质

```
性质一（462）：Σ|xi - m| 在 m = 中位数时最小
  证明：排序后中位数两侧元素数相等
  → 向左/向右移动 m 一位：一边 +k 一边 -k 抵消

性质二（稳健性）：中位数不受极端值影响
  [1,2,3,100] 中位数 2.5 vs 均值 26.5

性质三（流式）：数据流中位数可用双堆维护
  （见 02 模块 295）

⚠️ 面试必答：
"Σ|xi - m| 最小化 → m 取中位数（不是均值！）
 均值最小化平方和，中位数最小化绝对差。"
```

### 1.3 中位数 vs 平均数的选择

| 场景 | 选 | 原因 |
|------|:---:|------|
| 绝对差最小 | 中位数 | 数学性质 |
| 平方差最小 | 均值 | 数学性质 |
| 有极端值 | 中位数 | 稳健 |
| 数据正态 | 均值 | 效率最高 |

## 2. 重复元素与分区稳定性

### 2.1 重复元素对快选的影响

```
大量重复值（如全是 5）：
  普通 Lomuto 分区 → 全挤一侧 → 每次只排除一个 → O(n²)

三路分区（荷兰国旗）解决：
  < pivot | == pivot | > pivot
  等于区直接归位 → 重复多时一次排除大片 → 接近 O(n)

⚠️ 面试表达：
"重复元素是快选的隐形杀手——普通分区
 每次只缩小 1 个。三路分区把等于区
 一次性排除，重复数据下从 O(n²) 回到 O(n)。"
```

### 2.2 三路快速选择实现

```java
/** 三路快选（重复元素优化）——返回第 k 小（0 基） */
int quickSelect3(int[] nums, int k) {
    int lo = 0, hi = nums.length - 1;
    Random rand = new Random();
    while (lo <= hi) {
        // 随机基准
        int pIdx = lo + rand.nextInt(hi - lo + 1);
        int pivot = nums[pIdx];

        // ⚠️ 三路分区：< pivot | == pivot | > pivot
        int lt = lo, gt = hi, i = lo;
        while (i <= gt) {
            if (nums[i] < pivot) swap(nums, i++, lt++);
            else if (nums[i] > pivot) swap(nums, i, gt--);
            else i++;
        }
        // 等于区 [lt, gt]：判断 k 落在哪
        if (k < lt) hi = lt - 1;
        else if (k > gt) lo = gt + 1;
        else return pivot;                  // ⚠️ k 在等于区 → 答案
    }
    return -1;
}
// 推演 [5,5,5,1,5,5], k=0：pivot=5 → 三路 → <区 [1]，==区 [5×5]
//   k=0 < lt → hi=lt-1 → 只剩 [1] → 返回 1 ✓（一趟搞定）
// ⚠️ 对比普通分区：每次排除 1 个 vs 一次排除大片
```

### 2.3 稳定性与快选

```
快选不稳定（交换破坏顺序）——需要"第 K 大 + 保持原序"的场景？
  ⚠️ 快选只回答"值"，不回答"位置/原序"
  需要原序的 TopK → 堆 + 下标绑定 / 排序 + 下标

⚠️ 面试表达：
"快选返回'第 K 大的值'；若需要'哪些元素'
 （前 K 个本身）快选也能给（partition 后前 K 已就位）
 但顺序是乱序的。要保序就排序或堆。"
```

## 3. 第 K 大的变体设计

### 3.1 变体矩阵

| 变体 | 转换 | 关键 |
|------|------|------|
| 第 K 大 | target = n - k | 下标转换 |
| 第 K 小 | 直接 k-1 | 原生 |
| 第 K 个最大频率 | 频率数组快选 | 先哈希统计 |
| 第 K 近点 | 距离数组快选 | 比较函数替换 |
| 数据流第 K 大 | 堆（快选不可在线） | 无法重排 |
| 第 K 大且去重 | 先去重 | 值域处理 |

```
⚠️ 快选的通用化：
  "把元素映射成可比键（距离/频率），快选不变"
  → 973（距离）、347（频率）、692（字典序）

⚠️ 面试表达：
"快选模板的输入是'键数组'——距离平方、频率、
 字典序都行。抽象出比较键，一个模板走天下。"
```

### 3.2 有界 vs 流式（关键分界）

```
静态数组（可交换）→ 快选 O(n) 期望 ✅
数据流（不可重排）→ 堆 O(n log k) ✅
数组不可修改 → 堆（不能交换）

⚠️ 面试必答：
"快选要求'原地交换'——数组可改才可用。
 流式数据（每来一个元素查 TopK）只能堆：
 堆维护当前 TopK，O(log k)/元素。"
```

## 4. BFPRT 确定性算法

### 4.1 为什么快选是"期望"而非"确定"

```
随机基准 → 期望每次砍半 → O(n)
但最坏（每轮恰好分 1 个）→ O(n²)（概率趋近 0）

BFPRT（中位数的中位数）→ 确定性 O(n)：
  ① 每 5 个一组排序，取每组中位数
  ② 递归求中位数数组的中位数 → 作 pivot
  ③ 保证：≥ 3n/10 元素 ≤ pivot（另一侧同理）
  ④ 每轮至少去掉 30% → T(n) = T(7n/10) + O(n) → O(n)
```

### 4.2 数学保证的推导

```
每 5 分组排序取中位数 → m = ⌈n/5⌉ 个中位数
这些中位数的中位数 pivot：
  ≥ m/2 个中位数 ≤ pivot（每组中位数 ≤ pivot 的组）
  每组中位数 ≤ pivot → 该组 5 个中至少 3 个 ≤ pivot
  → 至少 3·(m/2) ≥ 3n/10 个元素 ≤ pivot

∴ 每轮剔除 ≥ 3n/10 → 剩余 ≤ 7n/10
  T(n) = T(7n/10) + O(n) → O(n) ✓（等比求和）
```

### 4.3 工程评估

```
优点：确定性最坏 O(n)（对抗性输入安全）
缺点：常数巨大（每层 5 分组 + 递归中位数）
工程现实：随机化快选又快又简单
  → BFPRT 是"理论保证"，工程不用

⚠️ 面试表达：
"BFPRT 用中位数的中位数保证每轮去掉 30%，
 确定 O(n)；常数大是代价。
 实际生产用随机化——最坏 O(n²) 概率趋近 0，
 且无法被构造（种子随机）。"
```

## 5. 快选 vs 堆 vs 排序：完整决策树

### 5.1 三方案全维度对比

| 维度 | 快选 | 堆 | 排序 |
|------|:---:|:---:|:---:|
| 时间 | O(n) 期望 | O(n log k) | O(n log n) |
| 空间 | O(log n) | O(k) | O(1) |
| 数组可改 | 需要 | 不需要 | 需要 |
| 在线 | ❌ | ✅ | ❌ |
| 结果顺序 | 无序 | 有序（弹出） | 全序 |
| 保序 | ❌ | 不稳定 | 视排序 |
| 代码 | 中等 | 简单 | 最简单 |

### 5.2 决策树

```
数据流/在线？────────── 是 → 堆
    ↓ 否
数组不可交换？──────── 是 → 堆
    ↓ 否
只需要第 K 个值？───── 是 → 快选（O(n)）
    ↓ 否
需要前 K 有序？─────── 是 → 堆（弹出有序）/排序
    ↓ 否
静态 + 只要值 → 快选

⚠️ 面试表达：
"'只要值、数组可改' → 快选最优（O(n)）；
 '要顺序/在线/不可改' → 堆。
 两者都答并说清边界 = 满分。"
```

## 6. 中位数原理的应用

### 6.1 462 最少移动（绝对值性质）

```
最少移动使所有数相等（每次 ±1）：
  目标 = 中位数（非均值！）
  总移动 = Σ|xi - median|

⚠️ 推导：
  排序后任意相邻移动成对抵消
  目标向左/右移动 1 → 左侧 k 个 +1、右侧 n-k 个 -1
  差值变化 = k - (n-k) → k = n/2 时最小 → 中位数

⚠️ 面试必答：
"462 的目标是中位数：Σ|xi-m| 在中位数最小。
 写成'绝对差'立刻想到中位数——这是
 快选/中位数的标志性应用。"
```

### 6.2 295 流式中位数（双堆）

```
数据流中位数 → 两个堆：
  大顶堆（左半） + 小顶堆（右半）
  平衡：|左| - |右| ≤ 1
  中位数 = 堆顶之一（或平均）

⚠️ 与快选的关系：
  静态数组 → 快选 O(n) 一次
  流式 → 双堆 O(log n)/元素（堆在线优势）
  → 完整实现见 02 模块

⚠️ 面试表达：
"中位数两个场景两种算法：静态快选、
 流式双堆。'一次 vs 持续'决定选型。"
```

## 7. 面试要点与追问

### 7.1 面试话术模板

```
"第 K 大 → 快选：partition 后单侧递归。
 期望 O(n)（几何级数），随机化防退化。
 重复元素多 → 三路分区（等于区一次排除）。
 需要在线/保序 → 堆。静态 + 只要值 → 快选。
 中位数 = 第 (n+1)/2 小，性质：绝对差和最小。"
```

### 7.2 高频追问 TOP 8
