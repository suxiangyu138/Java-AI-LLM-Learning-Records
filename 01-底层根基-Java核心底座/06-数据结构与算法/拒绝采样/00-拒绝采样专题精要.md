## 1. 核心概念

### 1.1 什么是拒绝采样

> 拒绝采样（Rejection Sampling）：生成一个**简单均匀分布的候选**，若不满足目标条件则**拒绝并重试**，直到接受。用"重试"换"正确分布"。

```
通用框架：
  while (true) {
      候选 = 生成简单分布的随机数;
      if (满足目标条件) return 候选;
      // 否则拒绝，重新生成
  }

经典例：Rand7() → Rand10()
  生成 1-49 均匀数 → 接受 ≤ 40 的 → 取模得 1-10
  接受概率 40/49 → 期望 49/40 ≈ 1.2 次重试

价值：用"期望常数次重试"实现任意可描述分布
```

### 1.2 识别信号

```
"用 X 实现 Y 随机（X 范围小、Y 范围大）" → 拒绝采样
"区域内随机点（圆/三角形）" → 拒绝采样
"生成特定分布" → 拒绝采样

⚠️ 关键判断：
  接受概率 p 大（> 1/2）→ 高效（1-2 次）
  接受概率 p 小（< 1/10）→ 低效 → 换方案
```

### 1.3 为什么能保证均匀？

```
拒绝采样不改变"候选的均匀性"：
  只保留满足条件的候选（拒绝其他）
  剩余候选在原分布上仍然均匀
  → 条件分布 = 原分布的条件化 ✓

⚠️ 关键：候选必须来自"均匀分布"
  不均匀的候选 → 拒绝后仍不均匀
```

## 2. 完整代码模板

### 2.1 470. 用 Rand7 实现 Rand10

```java
/**
 * LeetCode 470. 用 Rand7 实现 Rand10（拒绝采样经典）
 * rand7() 已给出（返回 1-7 均匀）
 */
public int rand10() {
    while (true) {
        // ① 生成 1-49 均匀数（两个 rand7 组合）
        int x = (rand7() - 1) * 7 + rand7();   // 1-49 均匀

        // ② 接受 ≤ 40 的部分（拒绝 41-49）
        if (x <= 40) {
            return x % 10 + 1;                 // 1-10 均匀
        }
        // ③ 拒绝 → 重试（期望 49/40 ≈ 1.2 次）
    }
}
// 为什么 49 取 40？
//   40 是 10 的倍数 → 取模均匀
//   41-49 拒绝 → 剩余 40 个均匀映射 1-10
// ⚠️ 不能取 49（49 % 10 + 1 会不均匀：9 出现 5 次，1 出现 4 次）

// 推演验证：
//   x=1..40 → 1-10 各 4 次（均匀）
//   x=41..49 → 拒绝重试
//   → 返回的 1-10 严格均匀 ✓
```

### 2.2 优化版（复用拒绝值）

```java
/**
 * 优化：利用拒绝的 9 个数（期望降到 ~1.17）
 * 拒绝值 x ∈ [41,49] → 映射到 [0,8] → 再乘 rand7
 */
public int rand10_optimized() {
    while (true) {
        int a = rand7(), b = rand7();
        int x = (a - 1) * 7 + b;               // 1-49

        if (x <= 40) return x % 10 + 1;        // 接受（40/49）

        // ⚠️ 复用拒绝部分：x-40 ∈ [1,9] → 组合成 [0,62]
        int y = (x - 40) * 7 + rand7() - 1;    // 0-62
        if (y < 60) return y % 10 + 1;         // 接受（60/63）
        // 可继续嵌套（理论期望趋近 1）
    }
}
// 面试加分：展示"拒绝值复用"的优化思路
```

### 2.3 478. 圆内随机点（几何拒绝）

```java
/**
 * LeetCode 478. 圆内随机点（正方形内拒绝）
 */
public double[] randPoint() {
    while (true) {
        double x = 2 * random.nextDouble() - 1;   // [-1, 1]
        double y = 2 * random.nextDouble() - 1;

        if (x * x + y * y <= 1) {                 // ⚠️ 圆内才接受
            return new double[]{centerX + radius * x,
                                centerY + radius * y};
        }
        // 圆外拒绝重试
    }
}
// 接受概率 = 圆面积/正方形面积 = π/4 ≈ 78.5%
// 期望重试 ≈ 1.27 次

// 更优方案：极坐标（无拒绝，O(1) 确定时间）
//   r = radius × √rand  （⚠️ 开方保证面积均匀）
//   θ = 2π × rand
// 面试加分："拒绝采样简单；极坐标无拒绝更优"
```

## 3. 期望重试次数分析

### 3.1 几何分布

```
每次独立尝试，成功概率 p：
  期望尝试次数 = 1/p（几何分布）

推导：
  E = p×1 + (1-p)×(1+E)
  → E = 1/p

例：470 → p = 40/49 → E ≈ 1.2
    478 → p = π/4 → E ≈ 1.27

⚠️ 面试必答：
"接受概率 p，期望重试 1/p 次——
 这是几何分布的期望，常数级可行。"
```

### 3.2 接受概率的评估

```
p > 1/2 → 高效（1-2 次）✓
p ~ 1/3 → 可接受（3 次）
p < 1/10 → 低效（10+ 次）→ 换方案

⚠️ 提升接受概率的方法：
  ① 扩大接受区域（49 取 40 而非 7）
  ② 复用拒绝值（优化版 470）
  ③ 换数学方法（极坐标替代正方形拒绝）
```

### 3.3 最坏情况分析

```
理论上可能无限重试（几何分布无上界）
  概率趋近 0：P(重试 k 次) = (1-p)^k → 0

期望常数：E = 1/p（与输入规模无关）
  → 复杂度 O(1) 期望（算法分析中可接受）

⚠️ 面试表达：
"虽然最坏可能重试多次，但期望 1/p 次
 是常数——几何分布的期望，实践中
 几乎总是 1-2 次完成。"
```

## 4. 拒绝采样 vs 其他采样

### 4.1 对比表

| 方法 | 适用 | 复杂度 | 特点 |
|------|------|:---:|------|
| 拒绝采样 | 可描述条件 | 期望 O(1/p) | 简单，可能重试 |
| 水塘抽样 | 流式等概率 | O(n) | 一次扫描 |
| 前缀和+二分 | 权重已知 | O(log n) | 确定性 |
| 极坐标 | 圆/球 | O(1) | 数学变换 |

```
选型：
  条件简单可描述 → 拒绝采样
  流式未知总量 → 水塘
  权重已知 → 前缀和 + 二分（528）
  有数学变换 → 极坐标/映射（无拒绝）
```

### 4.2 528. 按权重随机选择（确定性方案）

```java
/**
 * LeetCode 528. 按权重随机选择
 * 权重 [1,3] → 1 的概率 1/4，3 的概率 3/4
 *
 * 前缀和 + 二分（无拒绝，确定性 O(log n)）
 */
class Solution {
    private int[] prefix;
    private int total;
    private Random random = new Random();

    public Solution(int[] w) {
        prefix = new int[w.length];
        prefix[0] = w[0];
        for (int i = 1; i < w.length; i++) {
            prefix[i] = prefix[i - 1] + w[i];   // 前缀和
        }
        total = prefix[w.length - 1];
    }

    public int pickIndex() {
        int target = random.nextInt(total) + 1;  // [1, total]
        // ⚠️ 二分：第一个 prefix[i] ≥ target
        int lo = 0, hi = prefix.length - 1;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (prefix[mid] >= target) hi = mid;
            else lo = mid + 1;
        }
        return lo;
    }
}
// 权重 [1,3]：prefix=[1,4]，total=4
//   target=1 → 0；target=2,3,4 → 1
//   → 概率 1/4 与 3/4 ✓
```

### 4.3 拒绝 vs 确定性的选型

```
拒绝采样：
  实现简单（while 循环）
  期望常数时间（p 大时）
  ⚠️ 需要"可描述的条件"

确定性（前缀和+二分/数学变换）：
  无重试（严格 O(log n)/O(1)）
  需要数学构造

⚠️ 面试表达：
"拒绝采样简单通用（期望常数次）；
 有数学构造时确定性方案更优（无重试）。"
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"Rand7 到 Rand10：组合两个 rand7 得 1-49 均匀，
 取 40（10 的倍数）内的数取模得 1-10，
 41-49 拒绝重试。接受概率 40/49，
```

| 1 | 为什么 49 取 40？ | 40 是 10 的倍数 → 取模均匀 |
| 2 | 期望重试次数？ | 1/p（几何分布）；470 ≈ 1.2 次 |
| 3 | 什么时候拒绝采样不好？ | p < 1/10 → 重试太多 → 换数学方案 |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 取模不均匀 | 分布偏差 | 取基数倍数后取模 |
| 候选不均匀 | 拒绝后仍不均 | 候选必须均匀源 |
| 接受率太低硬用 | 性能差 | 评估 p 换方案 |
| 圆内忘开方 | 点聚中心 | r = √rand |
| 边界处理漏 | 越界/偏差 | 范围检查 |

> 🎯 **核心要点**：拒绝采样 = **生成候选 → 条件检查 → 拒绝重试**。识别信号："用 X 实现 Y 随机、区域内随机点"。接受概率与期望重试次数（1/p）分析是面试表达核心；"取基数倍数取模"与"几何 √"是两个关键细节。
