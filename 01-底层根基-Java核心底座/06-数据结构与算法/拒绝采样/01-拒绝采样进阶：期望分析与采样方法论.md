## 1. 期望重试次数的完整推导

### 1.1 几何分布的期望

```
每次尝试独立、成功概率 p → 重试次数 T 服从几何分布：
  P(T = k) = (1-p)^(k-1)·p

期望推导（全期望公式）：
  E[T] = p·1 + (1-p)·(1 + E[T])
  → E[T] = 1/p

⚠️ 直觉：接受率 50% → 平均试 2 次
  接受率 80% → 平均试 1.25 次

⚠️ 面试必答：
"拒绝采样的期望尝试次数 = 1/接受率——
 几何分布的期望。所以优化采样 = 提高接受率。"
```

### 1.2 标准差的含义

```
Var(T) = (1-p)/p²，标准差 ≈ 1/p（p 大时）

⚠️ 含义：期望 2 次的采样，单次可能试 5-10 次
  → 工程上要设"最大尝试次数"（防极端情况）

⚠️ 面试表达：
"期望 1/p 但方差不小——拒绝采样是
 '大概率快、小概率慢'的算法；
 极端场景需要重试上限或退路方案。"
```

### 1.3 多个条件的复合接受率

```
多个独立条件（如圆内 + 距离约束）：
  总接受率 = 各接受率相乘
  ⚠️ 条件越多 → 接受率指数下降 → 重试次数飙升

例：正方形内采样 + 圆内 + 再过滤 x>0.5：
  π/4 × 0.5 → 期望 2.5 次

⚠️ 优化思路：合并条件 / 缩小采样区域 / 换分布
```

## 2. 接受率与采样的几何直觉

### 2.1 接受率 = 面积比

```
拒绝采样 = 在"包围区域"采样，接受落在"目标区域"的点：
  接受率 = 目标区域面积 / 包围区域面积

例：圆（半径 r）内均匀采样，正方形包围：
  接受率 = πr² / (2r)² = π/4 ≈ 78.5%
  → 期望 1.27 次尝试

⚠️ 优化方向：包围区域越贴近目标 → 接受率越高
  圆 → 用外接正方形（π/4）
  圆 → 用内切圆外八边形 → 更高
  扇形 → 用包围它的矩形

⚠️ 面试表达：
"接受率 = 面积比。想提高接受率就选
 '更贴合目标区域'的包围形状——
 圆用正方形是 π/4，换八边形能更高。"
```

### 2.2 维度诅咒

```
高维均匀采样（球/超球）：
  超球体积 / 超立方体体积 → 随维度指数下降！
  3 维球：π/6 ≈ 52%
  10 维超球：≈ 0.25%！→ 拒绝采样在高维失效

⚠️ 工程含义：
  高维采样必须用"直接构造"（极坐标/Box-Muller）
  而非拒绝采样

⚠️ 面试表达：
"拒绝采样有维度诅咒——高维空间里
 目标体积占比指数下降。低维（≤3）好用，
 高维换逆变换/马尔可夫链（MCMC）。"
```

## 3. 拒绝采样 vs 逆变换采样

### 3.1 两种采样方法对比

| 维度 | 拒绝采样 | 逆变换采样 |
|------|---------|-----------|
| 原理 | 包围区采样 + 接受/拒绝 | CDF 反函数 |
| 要求 | 有包围分布即可 | 有解析 CDF 反函数 |
| 接受率 | 面积比（<1） | 100%（无重试） |
| 复杂度 | 期望 O(1/p) | O(1) |
| 适用 | 任意形状区域 | 连续分布（指数/正态） |

```
逆变换采样（Inverse Transform）：
  ① 求 CDF F(x)
  ② 采样 u ~ U(0,1)
  ③ 返回 F⁻¹(u)

例：指数分布 F(x) = 1-e^(-λx) → F⁻¹(u) = -ln(1-u)/λ

⚠️ 面试表达：
"逆变换需要 CDF 有解析反函数（指数/均匀/柯西）；
 拒绝采样只需要'判断点在不在区域内'——
 所以几何题（圆/矩形/多边形）用拒绝采样更自然。"
```

### 3.2 极坐标法：第三种采样

```
圆内均匀采样（无需拒绝）：
  r = R·√u₁（⚠️ 平方根！）
  θ = 2π·u₂

⚠️ 为什么 r 要 √u：
  面积 ∝ r² → 半径分布 CDF = r²/R² → 反函数 r = R·√u
  （直接 r = R·u → 中心密集，不均匀）

⚠️ 对比：
  拒绝采样：接受率 π/4，实现最直观
  极坐标：一次生成无重试，但公式容易记错

⚠️ 面试必答：
"'圆内均匀采样'的极坐标半径必须 √u——
 否则中心密度高（面积与半径平方成正比）。"
```

### 3.3 采样方法选择树

```
目标区域规则（圆/矩形）？
  ├─ 是 → 极坐标/直接构造（无重试）优先
  └─ 否 → 拒绝采样（包围 + 接受）
需要解析分布（指数/正态）？
  ├─ 是 → 逆变换 / Box-Muller
  └─ 否 → 拒绝采样 / MCMC（高维）
```

## 4. 几何概率与多维采样

### 4.1 几何概率

```
几何概率 = 面积/体积之比（连续等可能）：
  P(落在区域 A) = 面积(A) / 面积(全体)

⚠️ 应用：
  布丰投针（π 的估计）
  蒙特卡洛求面积/π（采样计数比 = 面积比）

⚠️ 面试表达：
"拒绝采样与蒙特卡洛一体两面——
 采样计数比估计面积比（π ≈ 4×圆内/总数）。
 接受率分析同样是面积比。"
```

### 4.2 三维/多维采样

```
球内均匀采样：
  拒绝采样：立方体包围 → 接受率 π/6 ≈ 52%
  极坐标：r = R·∛u（⚠️ 立方根！体积 ∝ r³）+ 两角度

环形区域（大圆挖小圆）：
  拒绝采样最自然：大圆内采样 → 拒绝小圆内
  接受率 = 环面积 / 大圆面积

⚠️ 面试表达：
"多维采样要小心'体积量纲'——球用 ∛u、
 圆用 √u、环用拒绝。公式维度错了分布就错了。"
```

## 5. 非拒绝替代：黑名单映射

### 5.1 拒绝的代价与替代

```
拒绝采样的问题：期望重试（最坏无限）
替代方案：把"不可接受值"映射到"可接受值"（零重试）

⚠️ 典型：710 黑名单随机（[0,n) 中排除黑名单后等概率随机）
  方案一（拒绝）：随机到黑名单 → 重试 → 黑名单多时极慢
  方案二（映射）：把黑名单值映射到尾部白名单值 → O(1) 一次

⚠️ 面试表达：
"当'拒绝区域'占比很大时，拒绝采样的期望
 重试次数爆炸——改用'映射'：
 把不可用值映射到可用值，一次完成。"
```

### 5.2 映射方法的设计

```
映射的通用思路（710 模式）：
  ① 把 [0, n) 分成 [0, n-m) 可用区与尾部
  ② 黑名单中 < n-m 的值 → 映射到尾部白名单
  ③ 随机 [0, n-m) → 查映射（被映射过用映射值，否则原值）

⚠️ 正确性：映射是双射（黑名单值 ↔ 尾部白名单值一一对应）
  可用区随机 + 映射 = [0,n) 排除黑名单的均匀分布

⚠️ 工程结论：
  "拒绝 vs 映射"的选型标准：
  拒绝区域占比 < 50% → 拒绝采样（简单）
  拒绝区域占比大 → 映射（O(1) 保证）
```

## 6. 拒绝采样的工程评估

### 6.1 适用性清单

| 场景 | 拒绝采样合适？ | 原因 |
|------|:---:|------|
| 圆/环/多边形内采样 | ✅ | 面积比可控（π/4） |
| Rand7→Rand10 | ✅ | 接受率 81.6% |
| 黑名单占比大 | ❌ | 重试爆炸 → 映射 |
| 高维采样 | ❌ | 维度诅咒 |
| 流式不可重放 | ⚠️ | 拒绝需重新生成源 |
| 实时性要求高 | ⚠️ | 期望快但方差大 |

### 6.2 工程铁律

```
① 计算接受率（面积比/计数比）→ 预判重试成本
② 设重试上限（防极端：10×期望次数）
③ 高维/低接受率 → 换方法（映射/极坐标/逆变换）
④ 随机数生成器质量（SecureRandom vs Random 场景区分）

⚠️ 面试表达：
"拒绝采样评估三件事：接受率多少（期望次数）、
 重试上限设多少（方差兜底）、
 有没有更好的替代（映射/直接构造）。"
```

## 7. 面试要点与追问

### 7.1 面试话术模板

```
"拒绝采样：在包围区域采样，落在目标区域才接受。
 期望重试次数 = 1/接受率（几何分布）。
 接受率 = 面积比（圆/正方形 = π/4）。
 高维/低接受率场景改用映射或直接构造。
 工程上设重试上限防极端延迟。"
```

### 7.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 期望重试次数？ | 1/接受率（几何分布） |
| 2 | 接受率怎么算？ | 目标面积 / 包围面积 |
| 3 | 怎么提高接受率？ | 包围形状更贴合目标 |
| 4 | 高维为什么不行？ | 维度诅咒（体积占比指数下降） |
| 5 | 与极坐标法？ | 极坐标一次完成但公式易错（√u） |
| 6 | 与逆变换？ | 逆变换需 CDF 反函数；拒绝只要判定 |
| 7 | 黑名单大怎么办？ | 映射（710 模式）而非拒绝 |
| 8 | 工程注意？ | 重试上限 + 接受率预判 |

### 7.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 极坐标 r 忘 √u | 中心密集 | 面积反函数 |
| 接受率算错 | 预判失误 | 面积比 |
| 高维硬拒绝 | 重试爆炸 | 换方法 |
| 无重试上限 | 极端卡死 | 上限 = 10×期望 |
| 映射非双射 | 分布不均 | 一对一映射验证 |
