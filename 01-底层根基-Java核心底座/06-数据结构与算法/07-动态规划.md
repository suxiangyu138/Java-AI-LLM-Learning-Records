## 1. DP 核心思想三要素

### 1.1 最优子结构

**问题的最优解包含子问题的最优解**。

- 示例：从 A 到 C 的最短路径经过 B，那么 A→B 一定是 A 到 B 的最短路径
- 反例：最长简单路径问题——子路径不一定是最优的

### 1.2 无后效性

状态确定后，**后续决策不受之前路径的影响**。

- 当前状态包含了所有历史信息，不需要知道是如何到达当前状态的
- 示例：斐波那契数列中，f(5) 的计算只需 f(4) 和 f(3)，不需要知道它们是如何计算出来的

### 1.3 重叠子问题

大量子问题被反复计算 → 用**表存储**，避免重复。

```java
// 无 DP：指数级重复计算
int fib(int n) {
    if (n <= 1) return n;
    return fib(n - 1) + fib(n - 2); // 重复计算无数子问题
}

// 有 DP：O(n)，记忆化
int fibDP(int n) {
    if (n <= 1) return n;
    int[] dp = new int[n + 1];
    dp[0] = 0; dp[1] = 1;
    for (int i = 2; i <= n; i++) {
        dp[i] = dp[i - 1] + dp[i - 2];
    }
    return dp[n];
}
```

> 💡 **DP 的本质**：用**空间换时间**——用一个表存储子问题的解，避免重复计算。

## 2. DP vs 分治 vs 贪心

| 方法 | 子问题关系 | 求解方向 | 典型例子 |
|------|-----------|---------|---------|
| **分治** | 独立、不重叠 | 自顶向下 | 归并排序、二分查找 |
| **DP** | 重叠 | 自底向上（或自顶向下+记忆化） | 斐波那契、背包、LCS |
| **贪心** | 做一个选择后只剩一个子问题 | 自顶向下 | Dijkstra、Huffman |

> ⚠️ 区分 DP 和贪心：如果当前选择会影响后续可选的子问题（即子问题之间有依赖/共享），通常用 DP；否则可考虑贪心。

## 3. DP 解题五步法

| 步骤 | 说明 | 示例（爬楼梯） |
|------|------|--------------|
| **1. 定义状态** | dp[i] 或 dp[i][j] 的含义 | dp[i] = 爬到第 i 阶的方法数 |
| **2. 状态转移方程** | f(n) = g(f(n-1), f(n-2), ...) | dp[i] = dp[i-1] + dp[i-2] |
| **3. 确定初始值/边界** | dp[0]、dp[1] 等 | dp[0]=1, dp[1]=1 |
| **4. 确定遍历顺序** | i从1到n？i和j从n到1？ | i从2到n |
| **5. 推导答案** | 最终是 dp[n] 还是 max(dp)？ | dp[n] |

```java
// 爬楼梯（#70）——五步法完整实现
public int climbStairs(int n) {
    // 1. 定义状态
    // dp[i] = 爬到第 i 阶楼梯的方法数
    int[] dp = new int[n + 1];
    // 3. 初始值
    dp[0] = 1;
    dp[1] = 1;
    // 4. 遍历顺序
    for (int i = 2; i <= n; i++) {
        // 2. 状态转移
        dp[i] = dp[i - 1] + dp[i - 2];
    }
    // 5. 答案
    return dp[n];
}
```

## 4. 线性 DP

### 4.1 爬楼梯 / 斐波那契（#70, #509）

```java
public int climbStairs(int n) {
    if (n <= 1) return 1;
    int prev2 = 1, prev1 = 1; // 滚动变量优化空间
    for (int i = 2; i <= n; i++) {
        int cur = prev1 + prev2;
        prev2 = prev1;
        prev1 = cur;
    }
    return prev1;
}
```

- 状态：`dp[i] = 爬到第 i 阶的方法数`
- 转移：`dp[i] = dp[i-1] + dp[i-2]`
- 空间优化：O(n) → O(1)

### 4.2 最大子数组和（#53）

```java
public int maxSubArray(int[] nums) {
    int dp = nums[0]; // 以当前元素结尾的最大子数组和
    int max = nums[0];
    for (int i = 1; i < nums.length; i++) {
        dp = Math.max(nums[i], dp + nums[i]); // 要么从当前重新开始，要么与前面连接
        max = Math.max(max, dp);
    }
    return max;
}
```

- 状态：`dp[i] = 以 nums[i] 结尾的最大子数组和`
- 转移：`dp[i] = max(nums[i], dp[i-1] + nums[i])`
- 答案：`max(dp[0..n-1])`

> 💡 核心技巧：`dp[i]` 代表以 i **结尾**的子数组，最终答案是所有 `dp[i]` 的最大值。

### 4.3 最长递增子序列 LIS（#300）

```java
public int lengthOfLIS(int[] nums) {
    int n = nums.length;
    int[] dp = new int[n];
    Arrays.fill(dp, 1);
    int maxLen = 1;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < i; j++) {
            if (nums[j] < nums[i]) {
                dp[i] = Math.max(dp[i], dp[j] + 1);
            }
        }
        maxLen = Math.max(maxLen, dp[i]);
    }
    return maxLen;
}
```

- 状态：`dp[i] = 以 nums[i] 结尾的 LIS 长度`
- 转移：`dp[i] = max(dp[j] + 1)` for `j < i` and `nums[j] < nums[i]`
- 时间复杂度：O(n²)
- 优化：O(n log n) 版本——维护一个递增序列，用二分查找确定位置

## 5. 背包问题

### 5.1 0-1 背包

每种物品**只有 1 个**，选或不选。

```java
public int knapsack01(int[] weights, int[] values, int capacity) {
    int n = weights.length;
    int[] dp = new int[capacity + 1]; // 一维优化
    for (int i = 0; i < n; i++) {
        // 逆序遍历容量——保证每个物品只用一次
        for (int w = capacity; w >= weights[i]; w--) {
            dp[w] = Math.max(dp[w], dp[w - weights[i]] + values[i]);
        }
    }
    return dp[capacity];
}
```

| 维度 | 状态 | 说明 |
|------|------|------|
| 二维 | `dp[i][w]` | 前 i 个物品，容量 w 的最大价值 |
| 一维（优化） | `dp[w]` | 容量 w 的最大价值，**容量逆序**遍历 |

> ⚠️ **0-1 背包必须逆序遍历容量**——保证每个物品只被选一次。正序遍历会变成完全背包。

### 5.2 完全背包

每种物品**无限次**使用。

```java
public int knapsackComplete(int[] weights, int[] values, int capacity) {
    int n = weights.length;
    int[] dp = new int[capacity + 1];
    for (int i = 0; i < n; i++) {
        // 正序遍历容量——允许重复使用
        for (int w = weights[i]; w <= capacity; w++) {
            dp[w] = Math.max(dp[w], dp[w - weights[i]] + values[i]);
        }
    }
    return dp[capacity];
}
```

| 背包类型 | 容量遍历方向 | 区别 |
|---------|------------|------|
| 0-1 背包 | **逆序** w from C down to wt[i] | 每个物品只选一次 |
| 完全背包 | **正序** w from wt[i] to C | 物品可无限使用 |

### 5.3 多重背包

每种物品**有限次数**。

```java
// 二进制拆分优化
public int knapsackMultiple(int[] weights, int[] values, int[] counts, int capacity) {
    List<Integer> wList = new ArrayList<>();
    List<Integer> vList = new ArrayList<>();
    // 二进制拆分：将 count 拆分为 1,2,4,...,remain
    for (int i = 0; i < weights.length; i++) {
        int count = counts[i];
        for (int k = 1; k <= count; k *= 2) {
            wList.add(weights[i] * k);
            vList.add(values[i] * k);
            count -= k;
        }
        if (count > 0) {
            wList.add(weights[i] * count);
            vList.add(values[i] * count);
        }
    }
    // 转换为 0-1 背包求解
    int[] dp = new int[capacity + 1];
    for (int i = 0; i < wList.size(); i++) {
        for (int w = capacity; w >= wList.get(i); w--) {
            dp[w] = Math.max(dp[w], dp[w - wList.get(i)] + vList.get(i));
        }
    }
    return dp[capacity];
}
```

> 💡 **背包问题面试核心**：0-1 背包和完全背包的区分（逆序 vs 正序），以及「恰好装满」和「不超过容量」的初始化差异。

## 6. 区间 DP

### 6.1 最长回文子串（#5）

```java
public String longestPalindrome(String s) {
    int n = s.length();
    boolean[][] dp = new boolean[n][n];
    int start = 0, maxLen = 1;
    // 所有长度为 1 的子串都是回文
    for (int i = 0; i < n; i++) dp[i][i] = true;
    // 按长度从小到达遍历
    for (int len = 2; len <= n; len++) {
        for (int i = 0; i <= n - len; i++) {
            int j = i + len - 1;
            if (s.charAt(i) == s.charAt(j)) {
                if (len == 2) dp[i][j] = true;
                else dp[i][j] = dp[i + 1][j - 1]; // 依赖内部子串
            }
            if (dp[i][j] && len > maxLen) {
                start = i;
                maxLen = len;
            }
        }
    }
    return s.substring(start, start + maxLen);
}
```

- 状态：`dp[i][j] = s[i..j]` 是否为回文串
- 转移：`dp[i][j] = (s[i] == s[j]) && dp[i+1][j-1]`
- 遍历顺序：按**子串长度从小到大**

### 6.2 矩阵链乘法

```java
// 矩阵链乘最小计算次数
public int matrixChainOrder(int[] p) {
    int n = p.length - 1; // 矩阵个数
    int[][] dp = new int[n][n];
    for (int len = 2; len <= n; len++) { // 链长
        for (int i = 0; i <= n - len; i++) {
            int j = i + len - 1;
            dp[i][j] = Integer.MAX_VALUE;
            for (int k = i; k < j; k++) {
                int cost = dp[i][k] + dp[k + 1][j] + p[i] * p[k + 1] * p[j + 1];
                dp[i][j] = Math.min(dp[i][j], cost);
            }
        }
    }
    return dp[0][n - 1];
}
```

> 💡 **区间 DP 核心**：大区间依赖小区间，按区间长度从小到大遍历。

## 7. 二维 DP

### 7.1 不同路径（#62）

```java
public int uniquePaths(int m, int n) {
    int[][] dp = new int[m][n];
    for (int i = 0; i < m; i++) dp[i][0] = 1;
    for (int j = 0; j < n; j++) dp[0][j] = 1;
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
        }
    }
    return dp[m - 1][n - 1];
}
```

- 状态：`dp[i][j] = 到达 (i,j) 的路径数`
- 转移：`dp[i][j] = dp[i-1][j] + dp[i][j-1]`

### 7.2 编辑距离（#72）

```java
public int minDistance(String word1, String word2) {
    int m = word1.length(), n = word2.length();
    int[][] dp = new int[m + 1][n + 1];
    for (int i = 0; i <= m; i++) dp[i][0] = i;
    for (int j = 0; j <= n; j++) dp[0][j] = j;
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                dp[i][j] = dp[i - 1][j - 1];
            } else {
                dp[i][j] = 1 + Math.min(Math.min(
                    dp[i - 1][j],     // 删除
                    dp[i][j - 1]),    // 插入
                    dp[i - 1][j - 1]  // 替换
                );
            }
        }
    }
    return dp[m][n];
}
```

### 7.3 最长公共子序列 LCS（#1143）

```java
public int longestCommonSubsequence(String text1, String text2) {
    int m = text1.length(), n = text2.length();
    int[][] dp = new int[m + 1][n + 1];
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }
    return dp[m][n];
}
```

| DP 类型 | 状态定义 | 常用优化 |
|---------|---------|---------|
| 不同路径 | `dp[i][j]` 二维网格 | 可优化为一维数组 |
| 编辑距离 | `dp[i][j]` 字符串对齐 | 多一个操作维度 |
| LCS | `dp[i][j]` 双序列匹配 | 空间可优化为 O(min(m,n)) |

## 8. 树形 DP

### 8.1 打家劫舍 III（#337）

```java
public int rob(TreeNode root) {
    int[] result = robHelper(root);
    return Math.max(result[0], result[1]);
}

// 返回 [不选当前的最大值, 选当前的最大值]
private int[] robHelper(TreeNode root) {
    if (root == null) return new int[]{0, 0};
    int[] left = robHelper(root.left);
    int[] right = robHelper(root.right);
    // 不选当前 = 左右子树各自选取较大值的和
    int notRob = Math.max(left[0], left[1]) + Math.max(right[0], right[1]);
    // 选当前 = 当前值 + 左右子树不选
    int rob = root.val + left[0] + right[0];
    return new int[]{notRob, rob};
}
```

- 状态：`dp[0] = 不选当前的最大值`，`dp[1] = 选当前的最大值`
- 转移：树上后序遍历，子树先计算

## 9. DP 优化技巧

### 9.1 状态压缩 / 滚动数组

当 `dp[i]` 只依赖 `dp[i-1]` 时，用滚动变量代替整个数组。

| 优化前 | 优化后 | 空间节省 |
|--------|--------|---------|
| `int[] dp = new int[n]` | `int prev1, prev2` | O(n) → O(1) |
| `int[][] dp = new int[m][n]` | `int[] dp = new int[n]` | O(mn) → O(n) |

### 9.2 单调队列优化

适用于形如 `dp[i] = max(dp[j] + f(j)) + g(i)` 且 j 属于滑动窗口的 DP。

### 9.3 斜率优化

适用于决策单调性问题——维护一个凸包，用二分或双端队列加速。

## 11. 学习建议

1. DP 不是背模板，是理解**如何从子问题推导当前问题**的递推思维
2. 强烈建议按分类刷题：线性 DP（打基础）→ 背包（经典）→ 区间 → 二维 → 树形
3. 每道题先**手推 dp 表**，理解转移，再写代码——不要直接抄答案
4. 遇到不会的 DP 题，先想暴力递归（自顶向下），再转化为 DP（自底向上）

> 🎯 DP 是算法能力的"分水岭"——**理解 DP 意味着真正掌握了递推思维**。五步法（定义状态→转移方程→初始值→遍历顺序→答案）是解决一切 DP 问题的通用框架。
