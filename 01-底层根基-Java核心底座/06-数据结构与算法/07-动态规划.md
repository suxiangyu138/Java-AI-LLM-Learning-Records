# 动态规划

## 📌 课程定位
DP是算法竞赛和面试中区分度的核心考点。它解决的是"最优化问题"，核心是**最优子结构 + 重叠子问题**。理解DP意味着真正掌握了递推思维。

## 🎯 核心章节

### 1. DP 核心思想三要素
- **最优子结构**：问题的最优解包含子问题的最优解
- **无后效性**：状态确定后，后续决策不受之前路径影响
- **重叠子问题**：大量子问题被反复计算 → 用表存储，避免重复

### 2. DP vs 分治 vs 贪心
| 方法 | 子问题关系 | 典型例子 |
|------|-----------|---------|
| 分治 | 独立、不重叠 | 归并排序 |
| DP | 重叠 | 斐波那契、背包、LCS |
| 贪心 | 做一个选择后只剩一个子问题 | Dijkstra、Huffman |

### 3. DP 解题五步法
1. **定义状态（dp数组含义）**：dp[i] 或 dp[i][j] 代表什么？
2. **推导状态转移方程**：f(n) = g(f(n-1), f(n-2), ...)
3. **确定初始值/边界**：dp[0]、dp[1] 的值
4. **确定遍历顺序**：i从1到n？i和j从n到1？
5. **推导答案**：最终答案是 dp[n] 还是 max(dp)？

### 4. 经典DP模型（⭐ 必须掌握）

**线性DP**：
- 爬楼梯/斐波那契（#70, #509）——dp[i] = dp[i-1] + dp[i-2]
- 最大子数组和（#53）——dp[i] = max(nums[i], dp[i-1]+nums[i])
- 最长递增子序列 LIS（#300）——dp[i] = max(dp[j]+1) for j<i & nums[j]<nums[i]

**背包问题（核心中的核心）**：
- **0-1背包**：dp[i][w] = max(dp[i-1][w], dp[i-1][w-wt[i]]+val[i])，可优化为一维（逆序）
- **完全背包**：每件物品无限次 → 一维正序遍历
- **多重背包**：每件物品有限次数 → 二进制拆分优化

**区间DP**：
- 最长回文子串（#5）——dp[i][j] = s[i]==s[j] && dp[i+1][j-1]
- 矩阵链乘法

**二维DP**：
- 不同路径（#62）——dp[i][j] = dp[i-1][j] + dp[i][j-1]
- 编辑距离（#72）——增删改最少步数
- 最长公共子序列 LCS（#1143）——经典双序列DP

**树形DP**：
- 打家劫舍III（#337）——在树上做DP，分选/不选当前节点

### 5. DP优化技巧
- **状态压缩**：dp[i] 只依赖 dp[i-1] → 滚动数组/滚动变量
- **单调队列优化**：滑动窗口最大值求dp
- **斜率优化**：决策单调性问题

## ✅ 学习建议
- DP不是背模板，是理解"如何从子问题推导当前问题"的思维
- 强烈建议按分类刷题：先线性DP（打基础）→背包（经典）→区间→二维→树形
- 每道题先手推dp表，理解转移，再写代码——不要直接抄答案
