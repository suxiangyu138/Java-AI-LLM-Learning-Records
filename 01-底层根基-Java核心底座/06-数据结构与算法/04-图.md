# 图

## 📌 课程定位
图是最灵活的数据结构，能建模几乎所有复杂关系——社交网络、地图导航、推荐系统、编译器依赖分析、网络路由。

## 🎯 核心章节

### 1. 图的基本概念与存储
- **基本术语**：弧/边、入度/出度、连通分量、强连通分量、生成树、网（带权图）
- **邻接矩阵**：`g[i][j]` 存是否存在边/权重——空间O(V²)，适合稠密图
- **邻接表**：每个顶点维护一个出边链表——空间O(V+E)，适合稀疏图
- **链式前向星/十字链表/邻接多重表**：竞赛常用优化存储方式

### 2. 图的遍历
- **DFS（深度优先）**：递归/栈实现，类似树的前序遍历
  - 应用：连通分量统计、拓扑排序、环检测、寻找桥&割点（Tarjan算法）
- **BFS（广度优先）**：队列实现，类似树的层序遍历
  - 应用：无权图最短路径、社交网络N度关系

### 3. 最小生成树（⭐ 重点）
- **Prim算法**：从任意点开始"生长"，每次选连接已选集合和未选集合的最小边
  - 邻接矩阵实现 O(V²)，堆优化 O(E log V)
- **Kruskal算法**：边按权值排序，用并查集判断是否成环，每次选最小不成环的边
  - 并查集实现 O(E log E)

### 4. 最短路径（⭐ 面试核心）
- **Dijkstra**：单源最短路径，要求非负权
  - 朴素O(V²)，堆优化O(E log V)
  - 不能处理负权边（已确定的"最短"可能被后续负权更新）
- **Bellman-Ford**：可处理负权边，O(VE)
  - 对每条边松弛V-1轮，第V轮还能松弛说明存在负环
- **SPFA**：Bellman-Ford的队列优化，最坏O(VE)
- **Floyd-Warshall**：多源最短路径，DP思想 O(V³)
  - 三重循环：`for k for i for j: dist[i][j] = min(dist[i][j], dist[i][k]+dist[k][j])`

### 5. 拓扑排序
- **AOV网**：顶点表示活动，边表示先后关系
- **Kahn算法**（BFS）：选入度为0的点输出，删除其所有出边，重复
- **DFS后序遍历逆序**：DFS完后压入结果栈，最后逆序输出
- **应用**：课程安排、构建系统依赖、任务调度

### 6. 关键路径（AOE网）
- **AOE网**：边表示活动及其持续时间
- **ve(k)**：事件最早发生时间——正向拓扑求max
- **vl(k)**：事件最迟发生时间——逆向拓扑求min
- **关键活动**：e(i)=l(i) 的活动，位于关键路径上——不能延期的任务
