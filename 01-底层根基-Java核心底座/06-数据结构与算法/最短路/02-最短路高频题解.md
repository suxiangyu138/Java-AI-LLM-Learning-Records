## 1. 743. 网络延迟时间（Dijkstra 标准）

### 1.1 题目与思路

```
从 k 出发到达所有节点的最大延迟（最短路的最大值）
标准 Dijkstra（堆优化）
```

### 1.2 完整代码

```java
/**
 * LeetCode 743. 网络延迟时间（Dijkstra 标准）
 */
public int networkDelayTime(int[][] times, int n, int k) {
    List<int[]>[] graph = new List[n + 1];
    for (int i = 1; i <= n; i++) graph[i] = new ArrayList<>();
    for (int[] t : times) graph[t[0]].add(new int[]{t[1], t[2]});

    int[] dist = new int[n + 1];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[k] = 0;

    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
    pq.offer(new int[]{0, k});

    while (!pq.isEmpty()) {
        int[] cur = pq.poll();
        int d = cur[0], u = cur[1];
        if (d > dist[u]) continue;           // ⚠️ 懒删除
        for (int[] e : graph[u]) {
            int v = e[0], w = e[1];
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.offer(new int[]{dist[v], v});
            }
        }
    }

    int max = 0;
    for (int i = 1; i <= n; i++) {
        if (dist[i] == Integer.MAX_VALUE) return -1;   // ⚠️ 不可达
        max = Math.max(max, dist[i]);
    }
    return max;
}
// 推演 times=[[2,1,1],[2,3,1],[3,4,1]], n=4, k=2：
//   dist：2=0，1=1，3=1，4=2 → 最大 2 ✓
// ⚠️ 复杂度：O(E log V)
// ⚠️ 面试必答："743 = Dijkstra 标准模板——
//   最短距离取最大 + 不可达返回 -1；
//   是'最短路的骨架题'。"
```

## 2. 1514. 概率最大的路径（Dijkstra 变体）

### 2.1 题目与思路

```
边带概率，求 s → t 概率最大的路径
Dijkstra 变体：距离 = 概率乘积（单调递减），最大堆
⚠️ 01 模块 2 节变体推导
```

### 2.2 完整代码

```java
/**
 * LeetCode 1514. 概率最大的路径（Dijkstra 最大堆）
 */
public double maxProbability(int n, int[][] edges,
                             double[] succProb, int start, int end) {
    List<int[]>[] graph = new List[n];
    for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
    for (int i = 0; i < edges.length; i++) {
        graph[edges[i][0]].add(new int[]{edges[i][1], i});   // 存边下标（取概率）
        graph[edges[i][1]].add(new int[]{edges[i][0], i});
    }

    double[] prob = new double[n];           // ⚠️ 到达概率（取最大）
    prob[start] = 1.0;

    // ⚠️ 最大堆：概率大的先出（贪心保证）
    PriorityQueue<Integer> pq = new PriorityQueue<>(
            (a, b) -> Double.compare(prob[b], prob[a]));
    pq.offer(start);

    while (!pq.isEmpty()) {
        int u = pq.poll();
        if (u == end) return prob[u];        // 最大概率已确定
        for (int[] e : graph[u]) {
            int v = e[0];
            double p = prob[u] * succProb[e[1]];   // ⚠️ 概率相乘
            if (p > prob[v]) {               // 松弛（取 max）
                prob[v] = p;
                pq.offer(v);
            }
        }
    }
    return 0.0;
}
// 推演 edges=[[0,1],[1,2],[0,2]], prob=[0.5,0.5,0.2], 0→2：
//   0→2 直接 0.2；0→1→2 = 0.25 → 取 0.25 ✓
// ⚠️ 复杂度：O(E log V)
// ⚠️ 面试必答："1514 = Dijkstra 改最大堆——
//   距离 = 概率乘积（单调递减 → 贪心成立），
//   松弛取 max；最大堆保证先处理高概率。"
```

## 3. 787. K 站中转最便宜（BF 限步）

### 3.1 题目与思路

```
最多 k 次中转的最便宜机票
Bellman-Ford 限步：k+1 轮松弛 + 快照
⚠️ 01 模块 3 节快照推导
```

### 3.2 完整代码

```java
/**
 * LeetCode 787. K 站中转最便宜（BF 限步快照）
 */
public int findCheapestPrice(int n, int[][] flights, int src, int dst, int k) {
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[src] = 0;

    for (int i = 0; i <= k; i++) {           // ⚠️ k 次中转 = k+1 段
        int[] next = dist.clone();           // ⚠️ 快照（必须基于上轮）
        for (int[] f : flights) {
            if (dist[f[0]] != Integer.MAX_VALUE) {
                next[f[1]] = Math.min(next[f[1]], dist[f[0]] + f[2]);
            }
        }
        dist = next;
    }
    return dist[dst] == Integer.MAX_VALUE ? -1 : dist[dst];
}
// 推演 n=3, [[0,1,100],[1,2,100],[0,2,500]], src=0, dst=2, k=1：
//   轮 0：dist=[0,100,500]
//   轮 1（快照）：1 更新 2：dist[1]=100 + 100 = 200 < 500 → 200
//   结果 200 ✓（0→1→2 中转 1 次）
// ⚠️ 若不用快照：轮 1 内 0→1 更新后立刻 1→2 → 200
//   但若路径 0→1→2→3（需要 2 段）会在 1 轮内串联 → 超步数
// ⚠️ 面试必答："787 = BF 限步快照——
//   k+1 轮、每轮基于上轮快照；
//   快照防止'一轮内多段串联'超步数。"
```

## 4. 847. 访问所有节点的最短路径（状态压缩 BFS）

### 4.1 题目与思路

```
从任意节点出发访问所有节点的最短路径
状态 = (节点, 已访问集合) → BFS 最短
⚠️ 状态压缩 BFS：visited[node][mask] 防重复
⚠️ 状态数 n × 2^n
```

### 4.2 完整代码

```java
/**
 * LeetCode 847. 访问所有节点的最短路径（状压 BFS）
 */
public int shortestPathLength(int[][] graph) {
    int n = graph.length;
    int full = (1 << n) - 1;
    boolean[][] visited = new boolean[n][1 << n];   // ⚠️ 节点 + 状态
    Deque<int[]> queue = new ArrayDeque<>();        // {节点, 掩码}

    // ⚠️ 多源起点：每个节点都可以出发
    for (int i = 0; i < n; i++) {
        queue.offer(new int[]{i, 1 << i});
        visited[i][1 << i] = true;
    }

    int steps = 0;
    while (!queue.isEmpty()) {
        int size = queue.size();
        for (int i = 0; i < size; i++) {
            int[] cur = queue.poll();
            int node = cur[0], mask = cur[1];
            if (mask == full) return steps;  // ⚠️ 全访问

            for (int next : graph[node]) {
                int nextMask = mask | (1 << next);
                if (!visited[next][nextMask]) {
                    visited[next][nextMask] = true;
                    queue.offer(new int[]{next, nextMask});
                }
            }
        }
        steps++;                             // 每层一步
    }
    return -1;
}
// 推演 [[1],[0,2,4],[1,3,4],[2],[1,2]]（5 节点图）：
//   BFS 状态扩展直到 mask = 全 1 → 最短步数 4 ✓
// ⚠️ 复杂度：O(n·2^n)（状态数）
// ⚠️ 面试必答："847 = 状压 BFS——
//   状态 = (节点, 已访问掩码)；
//   visited 二维防环、多源起点。"
```

## 5. 1631. 最小体力消耗路径（max 变体）

### 5.1 题目与思路

```
路径上最大高度差最小
Dijkstra max 变体：effort = 路径最大边差
⚠️ 01 模块 2 节；也可二分 + BFS（答案二分）
```

### 5.2 完整代码

```java
/**
 * LeetCode 1631. 最小体力消耗路径（Dijkstra max 变体）
 */
public int minimumEffortPath(int[][] heights) {
    int m = heights.length, n = heights[0].length;
    int[][] effort = new int[m][n];          // 到达该点的最小"最大差"
    for (int[] row : effort) Arrays.fill(row, Integer.MAX_VALUE);
    effort[0][0] = 0;

    // ⚠️ 优先队列：{effort, i, j}
    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
    pq.offer(new int[]{0, 0, 0});
    int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};

    while (!pq.isEmpty()) {
        int[] cur = pq.poll();
        int e = cur[0], i = cur[1], j = cur[2];
        if (e > effort[i][j]) continue;
        if (i == m - 1 && j == n - 1) return e;   // ⚠️ 终点首次出队即最优

        for (int[] d : dirs) {
            int ni = i + d[0], nj = j + d[1];
            if (ni < 0 || ni >= m || nj < 0 || nj >= n) continue;
            // ⚠️ 松弛：新 effort = max(当前, 边差)
            int newEffort = Math.max(e, Math.abs(heights[ni][nj] - heights[i][j]));
            if (newEffort < effort[ni][nj]) {
                effort[ni][nj] = newEffort;
                pq.offer(new int[]{newEffort, ni, nj});
            }
        }
    }
    return 0;
}
// 推演 [[1,2,2],[3,8,2],[5,3,5]]：
//   路径 (0,0)→(0,1)→(0,2)→(1,2)→(2,2)：
//   边差 1,0,6,3 → 最大 6？另一路 (0,0)→(1,0)→(2,0)→(2,1)→(2,2)：
//   2,2,2,0 → 最大 2 ✓ 答案 2
// ⚠️ 面试必答："1631 = Dijkstra max 变体——
//   松弛用 max（路径代价 = 最大边）；
//   '最小化最大值'是 max 变体的识别信号。"
```

## 6. 最短路方法论总结

### 6.1 解题框架

```
① 识别：最短路问题 → 选型（边权 + 查询）
② 选算法：
   无权 → BFS
   非负 → Dijkstra（堆）
   限步 → BF 快照
   多源 → Floyd
   状压 → BFS + mask
③ 变体：距离语义（概率/max/费用）
④ 边界：不可达、INF 防溢出
⑤ 复杂度：O(E log V) 等

⚠️ 识别信号：
  "最短时间/费用" → Dijkstra/BF
  "最大概率" → Dijkstra max 堆
  "最多 K 次" → BF 限步
  "访问所有" → 状压 BFS
```

| 题型 | 算法 | 代表题 |

| 标准最短 | Dijkstra 堆 | 743 |
