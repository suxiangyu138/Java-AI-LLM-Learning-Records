## 1. 核心概念

### 1.1 最短路问题分类

```
单源最短路径（一个起点到所有点）：
  无权图 → BFS（O(V+E)）
  带权正边 → Dijkstra（O((V+E) log V)）★ 面试必考
  带负权边 → Bellman-Ford（O(VE)）/ SPFA

全源最短路径（任意两点间）：
  Floyd-Warshall（O(V³)），适合稠密小图

选型口诀：
  无权 → BFS；正权 → Dijkstra；负权 → Bellman-Ford
  V 小全源 → Floyd

⚠️ 负权边最短路为什么难？
  负权让"已确定"的节点可能被更短路径再次松弛
  → 贪心失效（见 1.3 反例）
```

### 1.2 Dijkstra 的核心思想

```
贪心 + 松弛：
  ① 从未确定最短路的节点中取"当前距离最小"的
     （最小堆加速取最小）
  ② 用它松弛邻居：
     dist[v] = min(dist[v], dist[u] + w)
  ③ 重复直到所有节点确定

正确性（为什么贪心是对的）：
  堆顶 u 的 dist[u] 已是最短——
  所有到 u 的路径都经过"已确定"的节点
  或未确定节点（其距离 ≥ dist[u]）
  → 不可能有更短路径（正权保证）

⚠️ 前提：所有边权 ≥ 0
```

### 1.3 负权反例（面试必答）

```
      A
   5 / \ -3
  起点   B
    \   /
     1  C → 2 → A

Dijkstra 流程：
  dist[起点]=0，松弛 A=5, C=1
  取 C（最小）→ 松弛 B=3
  取 B（3）→ 松弛 A：3 + (-3) = 0 < 5 → ⚠️ A 应该更新！
  但 A 可能已被"确定"（5）→ 更新失败 → 答案错误

结论：Dijkstra 不能处理负权边（贪心失效）
  → 负权用 Bellman-Ford（松弛 n-1 轮）
```

## 2. Dijkstra 完整模板

### 2.1 堆优化版（面试标准答案）

```java
/**
 * Dijkstra 模板（堆优化）——面试必背
 * 输入：graph 邻接表（List<List<int[]>>，int[] = {to, weight}）
 * 返回：dist[] 从 start 到所有节点的最短距离
 */
public int[] dijkstra(List<List<int[]>> graph, int n, int start) {
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[start] = 0;

    // 最小堆：(节点, 当前最短距离)
    PriorityQueue<int[]> pq =
        new PriorityQueue<>((a, b) -> a[1] - b[1]);
    pq.offer(new int[]{start, 0});

    while (!pq.isEmpty()) {
        int[] cur = pq.poll();
        int u = cur[0], d = cur[1];

        // ⚠️ 过期记录跳过（该节点已有更短路径）
        if (d > dist[u]) continue;

        // 松弛邻居
        for (int[] edge : graph.get(u)) {
            int v = edge[0], w = edge[1];
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.offer(new int[]{v, dist[v]});
            }
        }
    }
    return dist;
}
// 复杂度：O((V+E) log V)，空间 O(V+E)
// 模板三要点：
//   ① 堆按距离排序
//   ② 过期跳过（d > dist[u]）防重复松弛
//   ③ 松弛条件：dist[u] + w < dist[v]
```

### 2.2 推演：743 网络延迟时间

```
graph: 2→1(1), 2→3(1), 3→4(1), n=4, start=2

初始：dist[2]=0, 堆[(2,0)]
弹 (2,0)：松弛 1→1, 3→1 → 堆[(1,1),(3,1)]
弹 (1,1)：无出边
弹 (3,1)：松弛 4→2 → 堆[(4,2)]
弹 (4,2)：无出边
dist = [INF, 1, 0, 1, 2]（下标 1 起）
→ 最远 2，全部可达 → 返回 2 ✓
```

### 2.3 为什么"过期跳过"必要？

```
同一节点可能入堆多次（每次松弛更新）：
  第一次 dist[v]=10 → 入堆 (v,10)
  后来发现 dist[v]=5 → 再入堆 (v,5)
  → 堆里有两个 v 的记录

弹出 (v,10) 时：10 > dist[v](5) → 过期 → 跳过
  → 避免用旧距离重复松弛（不影响正确性但省时间）

记忆："过期跳过 = 惰性删除（堆不支持 O(1) 更新）"
```

## 3. 三种算法的选型

### 3.1 算法对比表

| 算法 | 适用 | 复杂度 | 特点 |
|------|------|:---:|------|
| **BFS** | 无权图 | O(V+E) | 层扩散，第一次到达即最短 |
| **Dijkstra** | 正权 | O((V+E) log V) | 贪心+堆，面试首选 |
| Bellman-Ford | 负权 | O(VE) | 松弛 n-1 轮，可判负环 |
| Floyd | 全源 | O(V³) | DP，适合 V ≤ 500 |
| SPFA | 负权（平均快） | 期望 O(E) | 队列优化 BF，可被卡 |

### 3.2 Bellman-Ford 模板（负权场景）

```java
/**
 * Bellman-Ford：松弛 n-1 轮
 * 第 k 轮后 dist = 最多 k 条边的最短路径
 * 第 n 轮还能松弛 → 有负环
 */
public int[] bellmanFord(int n, int[][] edges, int start) {
    // edges: [u, v, w]
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[start] = 0;

    for (int i = 0; i < n - 1; i++) {        // n-1 轮
        for (int[] e : edges) {
            int u = e[0], v = e[1], w = e[2];
            if (dist[u] != Integer.MAX_VALUE
                && dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;       // 松弛
            }
        }
    }
    return dist;
}
// 判负环：第 n 轮仍能松弛 → 存在负环
// ⚠️ 787 限步数航班 = BF 变体（只松弛 k 轮）
```

### 3.3 Floyd 模板（全源）

```java
/**
 * Floyd：dp[k][i][j] = 经过前 k 个节点的最短路
 * 空间优化：滚动 k → 二维
 */
public int[][] floyd(int n, int[][] graph) {
    int[][] dist = graph.clone();            // 邻接矩阵

    for (int k = 0; k < n; k++) {            // ⚠️ 中转点外层
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (dist[i][k] + dist[k][j] < dist[i][j]) {
                    dist[i][j] = dist[i][k] + dist[k][j];
                }
            }
        }
    }
    return dist;
}
// O(V³)：只适合 V ≤ 500 的稠密图
```

## 4. Dijkstra 变体详解

### 4.1 变体一：最大概率路径（1514）

```java
/**
 * LeetCode 1514. 概率最大的路径
 * 边权 = 概率，求 successProb 最大
 *
 * 变形：
 *   dist 存"最大概率"（初始 0，起点 1）
 *   松弛：dist[v] = max(dist[v], dist[u] × prob)
 *   堆：按概率降序（大根堆）→ 等价取最大
 *
 * 本质：乘法取 log 变加法 → 仍是最短路框架
 */
// PriorityQueue<int[]> pq = new PriorityQueue<>((a,b) -> b[1]-a[1]);
// ⚠️ 比较器方向反转（取概率最大）
```

### 4.2 变体二：最小最大边（1631 体力消耗）

```java
/**
 * LeetCode 1631. 最小体力消耗路径
 * 边权 = 高度差绝对值，求"路径中最大边权"最小
 *
 * 变形：
 *   dist[v] = min(dist[v], max(dist[u], 高度差))
 *   → 不再是求和，而是"最大值最小化"
 *
 * 三种解法：
 *  ① Dijkstra 变体（dist 存最大差值）★ 面试
 *  ② 二分答案 + BFS/DFS（check 最大差值 ≤ mid）
 *  ③ 并查集（边按差值排序，连通即答案）
 */
```

### 4.3 变体三：限步数（787）

```java
/**
 * LeetCode 787. K 站中转最便宜航班
 * 最多 K 次中转 → 最多 K+1 条边
 *
 * Bellman-Ford 变体：只松弛 K+1 轮！
 *   dist[k][v]：k 条边内到达 v 的最低价
 *   ⚠️ 每轮用上一轮的快照（防同一轮内连环松弛）
 */
public int findCheapestPrice(int n, int[][] flights,
                             int src, int dst, int k) {
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[src] = 0;

    for (int i = 0; i <= k; i++) {           // K+1 轮
        int[] temp = dist.clone();           // ⚠️ 快照！
        for (int[] f : flights) {
            int u = f[0], v = f[1], w = f[2];
            if (dist[u] != Integer.MAX_VALUE) {
                temp[v] = Math.min(temp[v], dist[u] + w);
            }
        }
        dist = temp;                         // 用快照更新
    }
    return dist[dst] == Integer.MAX_VALUE ? -1 : dist[dst];
}
// 为什么快照？同一轮内不能"边传边用"（会超过步数限制）
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"这是带权图单源最短路，用 Dijkstra + 最小堆：
 ① dist 初始化，起点 0；
 ② 堆取当前距离最小节点（贪心）；
 ③ 松弛邻居（dist[u]+w < dist[v] → 更新入堆）；
 ④ 过期记录跳过。
 每个节点入堆出堆各一次 → O((V+E) log V)。
 边权全为正，Dijkstra 贪心正确；
 若有负权要换 Bellman-Ford。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 为什么堆优化？ | 朴素版取最小扫全数组 O(V)；堆 O(log V) → 总 O((V+E) log V) |
| 2 | 为什么不能处理负权？ | 负权让"已确定"节点被更短路径再次松弛 → 贪心失效 |
| 3 | BFS vs Dijkstra？ | BFS 是 Dijkstra 特例（边权相同 → 层数即距离） |
| 4 | 过期跳过是什么？ | 堆存的是旧记录（d > dist[u]）→ 跳过防重复松弛 |
| 5 | 变体怎么识别？ | 边权 = 自定义函数（最大差/概率）→ 改松弛公式 |
| 6 | 负环怎么判？ | BF 第 n 轮仍能松弛 → 有负环（无限变小） |
| 7 | 多源最短路？ | 超级源点连所有源（边权 0）→ 一次 Dijkstra |
| 8 | 何时用 Floyd？ | 全源 + V ≤ 500（O(V³) 可接受） |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 比较器写反 | 取最大当最小 | (a,b) -> a[1]-b[1] 小根堆 |
| 忘过期跳过 | 重复松弛慢 | if (d > dist[u]) continue |
| dist 未初始化 MAX | 松弛判断错 | Arrays.fill(MAX) |
| 787 忘快照 | 超过步数限制 | 每轮 temp = dist.clone() |
| 负权用 Dijkstra | 答案错误 | 换 Bellman-Ford |

> 🎯 **核心要点**：Dijkstra = **堆 + dist 数组 + 松弛 + 过期跳过**四要素。识别信号："带权图最短路径、最小代价到达"。选型口诀（无权 BFS/正权 Dijkstra/负权 BF）与三个变体（最大概率/最大差/限步数）是面试全部考点。
