## 1. 模板不变量：二分正确性的根基

```text
不变量（invariant）: 循环过程中始终保持的性质——
  二分正确性的证明都建立在"答案永远在 [l, r] 内"

闭区间模板的不变量:
  [l, r] 内始终包含 target 的可能位置
  → l > r 时区间空 → 未找到（返回 -1）

左闭右开模板的不变量:
  [l, r) 内始终包含"候选答案"（lower_bound 语义）
  → l == r 时收敛到唯一候选（返回 l）

⚠️ 指针更新的依据:
  闭区间: 排除 mid（±1）——mid 已比较过
  左闭右开: r = mid 不排除（mid 可能是候选）

面试表达:
  "我的不变量是【答案永远在 [l,r] 内】，
   所以每次更新都保持它——循环结束时答案自然浮现。"
```

> 🎯 **核心认知**："**不变量是二分的'宪法'——每次指针更新都必须保持'答案在区间内'**。死循环、漏检、越界，全部是不变量被破坏的表现。能说出自己的不变量，二分就从'背模板'升级为'懂原理'。"

## 2. 死循环的三大根因

### 2.1 根因一：区间不缩小（left = mid）

```java
// ❌ 死循环经典:
while (l < r) {
    int mid = l + (r - l) / 2;    // mid 可能 == l（区间只剩 2 个时）
    if (条件) l = mid;            // ⚠️ l 不前进 → [l, r] 永不缩小 → 死循环
    else r = mid;
}
// 例: [0, 1] 区间 → mid = 0 → 条件成立 → l = 0 → 死循环！

// ✅ 修复: 保证区间严格缩小
if (条件) l = mid + 1;            // 左指针必须前进
// 或 mid = l + (r - l + 1) / 2（上取整，配合 l = mid）
```

```text
判据: "每次循环后，区间长度必须严格减小"
  l = mid + 1 → 长度减
  r = mid     → 长度减（mid < r 恒成立？）
  l = mid     → 长度可能不减（mid == l 时）→ 死循环

⚠️ 记忆: "左指针用 mid+1 安全；非要用 l = mid 时，
   mid 必须上取整（l + (r−l+1)/2）"
```

### 2.2 根因二：循环条件与指针不匹配

```text
闭区间 <= 配 r = mid − 1（mid 已排除）
左闭右开 < 配 r = mid（mid 是候选）

❌ 混用: 闭区间循环 + r = mid → mid 永不排除 → 死循环
❌ 混用: 左闭右开循环 + r = mid − 1 → 可能漏掉 mid

⚠️ 记忆: "开闭一致——循环条件、指针更新、区间语义
   必须来自同一个模板"
```

### 2.3 根因三：比较方向反

```text
❌ nums[mid] < target 时 r = mid − 1（应该 l = mid + 1）
   → 方向反 → 区间收缩错 → 死循环或错误结果

✅ 自检: "小于 → 去右（l 动）；大于 → 去左（r 动）"
```

> 🎯 **死循环三连**："**死循环 = 区间不缩小（l=mid）/ 开闭混用（r 语义错）/ 方向反（指针动错边）**——三大根因都能用'不变量'解释：答案跑出区间或区间永不缩小。排查顺序：先查指针更新、再查循环条件、最后查比较方向。"

## 3. lower_bound/upper_bound 语义

### 3.1 定义与代码

```text
lower_bound(target): 第一个 >= target 的下标
upper_bound(target): 第一个 > target 的下标

用途:
  34 找范围: lower = 左边界、upper − 1 = 右边界
  35 插入位置: lower_bound 就是答案
  统计个数: upper − lower

实现（左闭右开语义最自然）:
  while (l < r) {
      mid = l + (r - l) / 2;
      if (nums[mid] < target) l = mid + 1;   // lower: < 去右
      else r = mid;                          //       >= 保留（r 收缩）
  }
  return l;                                  // 第一个 >= target

  // upper: 把 < 改成 <= 即可
```

### 3.2 为什么 lower_bound 用左闭右开

```text
关键区别: 精确查找失败时"两边都能收缩"；
          lower_bound 中 r 始终是"候选答案"——
          nums[mid] >= target 时 mid 可能是答案 → r = mid 保留

⚠️ 面试表达:
  "lower_bound 用左闭右开——r 指向'候选答案'不能排除，
   循环到 l == r 时唯一候选即答案。
   精确查找用闭区间——mid 已比较，±1 排除。"
```

## 4. 两个模板的统一视角

### 4.1 统一：都是"排除一半 + 保持不变量"

```text
闭区间 [l, r]:
  排除: mid 已比较 → l = mid+1 / r = mid−1
  结束: l > r（区间空）
  语义: 精确查找 / 记录型（34）

左闭右开 [l, r):
  排除: mid 已比较但可能是候选 → r = mid
  结束: l == r（收敛到候选）
  语义: 边界查找 / 谓词二分 / 二分答案

⚠️ 转化技巧: 同一题两种模板都能写——
  闭区间写 34（记录 bound）、左闭右开写 278/875
  "会一种 + 能转化另一种" = 完整掌握
```

## 5. 越界与漏检的边界检查

### 5.1 越界检查清单

```text
① 34 找完左边界: left 可能 == nums.length（target 大于全部）
   → 检查 left < nums.length && nums[left] == target
② 空数组: l=0 > r=-1 → 循环不进 → 返回 -1/left=0（35 应返回 0）
③ mid 计算: l + (r−l)/2 永不越界（l ≤ mid ≤ r）
④ 旋转数组: right 更新后仍 ≥ 0（闭区间语义保证）

⚠️ 面试表达: "写完检查三个边界——
   空数组、target 超出范围（左右两端）、重复元素"
```

### 5.2 漏检检查

```text
"最后一个元素被检查了吗？"
  闭区间: l <= r 保证最后一个元素也会被 mid 命中或排除
  左闭右开: 循环到 l == r，最后一个候选就是答案

"target 等于边界值被漏了吗？"
  33 的范围判断必须用 <=（边界值合法）
  34 的判据必须用 >= / <=（含等号）

⚠️ 自查模板: 小样例走 3 遍（命中中间/命中边界/未命中）
```

## 6. 二分正确性验证方法

### 6.1 三样例验证法

```text
① 命中中间: target 在数组中间 → 正常返回
② 命中边界: target 等于首/尾元素 → 检查 <= 细节
③ 未命中: target 不在数组 → 返回 -1 / 插入位置正确

再加两个:
④ 空数组 / 单元素
⑤ 重复元素（34 的边界定位）

⚠️ 性质验证: 循环结束后检查不变量——
  "l 右侧全 >= target、l 左侧全 < target"（35/34 的 left 语义）
```

### 6.2 复杂度与空间

```text
时间: O(log n)——每次减半（T(n) = T(n/2) + O(1)）
空间: 迭代 O(1)；递归 O(log n)

⚠️ 面试表达:
  "每次循环排除一半 → log₂n 次 → O(log n)。
   迭代版空间 O(1) 优于递归版 O(log n)。"
```

## 7. 易错总表

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 混用开闭区间 | 模板一致性（#1 bug） | 死循环/漏检 |
| 2 | `l = mid` 不前进 | `l = mid + 1` 或 mid 上取整 | 死循环 |
| 3 | 比较方向反 | `<` 去右、`>` 去左 | 结果错误 |
| 4 | 34 忘越界检查 | `l < n && nums[l] == target` | 越界崩溃 |
| 5 | 33 范围判断用 `<` | 用 `<=`（边界值合法） | 漏检边界 |
| 6 | 二分答案用 `<=` 循环 | `<`（l==r 即答案） | 死循环 |
| 7 | 不变量说不清 | "答案永远在 [l,r] 内" | 追问失分 |

> 🎯 **核心要点**：边界深潜通关四件事——**① 不变量意识**（答案永远在区间内）；**② 死循环三根因**（l=mid/混用/方向反）；**③ lower_bound 语义**（r 是候选不能排除）；**④ 三样例验证**（中/边/miss + 空/重）。**二分的全部陷阱都能用'不变量'解释——会说'我的不变量是……'，就是二分从'会写'到'懂'的分水岭**。
