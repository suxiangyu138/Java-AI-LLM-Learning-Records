## 1. 二分本质：一次比较排除一半

```text
二分查找的本质不是"数组必须有序"，
而是"一次比较能排除一半搜索范围":

  比较 nums[mid] 与 target →
  根据大小关系，目标只可能在左半或右半 →
  每次排除一半 → O(log n)

前提条件: 单调性（有序数组 / 单调函数 / 二段性）

⚠️ 核心认识:
  "只要能找到'一次比较排除一半'的判断条件，
   就能二分——旋转数组（局部有序）、峰值（趋势）、
   二分答案（谓词单调）都是这个本质的变体"
```

> 🎯 **核心认知**："**'一次比较排除一半'是二分的灵魂——数组有序只是最常见的实现方式，不是必要条件**。理解这一点，旋转数组、峰值、二分答案就都通了。"

## 2. 闭区间模板（新手首选，2 分钟默写）

### 2.1 完整模板

```java
/**
 * 二分查找闭区间模板 [left, right]
 * 循环条件 l <= r（l > r 时区间为空）
 * 时间 O(log n)，空间 O(1)
 */
int binarySearch(int[] nums, int target) {
    int left = 0, right = nums.length - 1;

    while (left <= right) {                    // ① 闭区间: l > r 结束
        int mid = left + (right - left) / 2;   // ② ⚠️ 防溢出写法
        if (nums[mid] == target) {
            return mid;                        // ③ 命中
        } else if (nums[mid] < target) {
            left = mid + 1;                    // ④ 排除 mid 及左侧
        } else {
            right = mid - 1;                   // ⑤ 排除 mid 及右侧
        }
    }
    return -1;                                 // ⑥ 未找到
}
```

### 2.2 三个关键细节

```text
① mid 防溢出: l + (r − l) / 2 而非 (l + r) / 2——
   (l + r) 在数组接近 Integer.MAX_VALUE 时溢出
② 指针更新: 命中区间 [l, mid−1] / [mid+1, r]——
   mid 已被排除，所以 ±1（与左闭右开的 r=mid 不同！）
③ 循环条件: l <= r——l > r 才结束（闭区间语义）

⚠️ 记忆: "闭区间三件套: <= 循环、±1 更新、防溢出 mid"
```

## 3. 704 二分查找（标准版）

### 3.1 题目与思路

**题**：有序数组查找 target（返回下标或 -1）。

```java
/**
 * LeetCode 704. 二分查找
 * 闭区间模板直接套
 * 时间 O(log n)，空间 O(1)
 */
public int search(int[] nums, int target) {
    int left = 0, right = nums.length - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] == target) return mid;
        else if (nums[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return -1;
}
// 推演 [-1,0,3,5,9,12], target=9：
//   mid=2(3) < 9 → left=3；mid=4(9) → 返回 4 ✓
// 边界: 空数组（l=0 > r=-1 → 直接 -1）✓
```

> 💡 **704 的定位**："**704 是二分的手撕入场券——闭区间模板 2 分钟默写**。面试先写它热身，再上变体（35/34）展示边界能力。"

## 4. 35 搜索插入位置（返回 left）

### 4.1 题目与思路

**题**：有序数组找插入位置（target 存在返回下标，否则返回应插入的位置）。

**找不到时 left 就是插入位置**：

```java
/**
 * LeetCode 35. 搜索插入位置
 * 关键: 循环结束时 left = 第一个 >= target 的位置
 * 时间 O(log n)，空间 O(1)
 */
public int searchInsert(int[] nums, int target) {
    int left = 0, right = nums.length - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] == target) return mid;
        else if (nums[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return left;                               // ① 插入位置 = left
}
// 推演 [1,3,5,6], target=2：
//   mid=1(3) > 2 → right=0；mid=0(1) < 2 → left=1
//   l=1 > r=0 结束 → 返回 1 ✓（2 应插在 1 和 3 之间）
// ⚠️ 为什么是 left: 循环结束时 left 停在"第一个 >= target 的位置"——
//   left 右侧全 >= target、左侧全 < target（不变量）
```

> 🎯 **35 的边界价值**："**'返回 left'是二分模板向边界题的桥梁——left 的语义 = 第一个 ≥ target 的位置**。理解了这个不变量，34/278/lower_bound 全部水到渠成。"

## 5. 34 查找首尾位置（边界二分）

### 5.1 题目与思路

**题**：有序数组（含重复）中 target 的首尾下标。

**拆两次二分**：`>=` 找左边界、`<=` 找右边界——**找到后不停止，记录并继续缩**：

```java
/**
 * LeetCode 34. 在排序数组中查找元素的第一个和最后一个位置
 * 两次二分: >= 找左边界、<= 找右边界
 * 时间 O(log n)，空间 O(1)
 */
public int[] searchRange(int[] nums, int target) {
    int left = findBound(nums, target, true);    // ① 左边界（>= 判据）
    int right = findBound(nums, target, false);  // ② 右边界（<= 判据）
    if (left <= right && right < nums.length
        && nums[left] == target) {               // ③ ⚠️ 越界 + 存在性检查
        return new int[]{left, right};
    }
    return new int[]{-1, -1};
}

private int findBound(int[] nums, int target, boolean isLeft) {
    int l = 0, r = nums.length - 1;
    int bound = -1;
    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (isLeft) {
            // ④ 左边界: >= target 才收缩右指针（记录并继续找更左）
            if (nums[mid] >= target) { bound = mid; r = mid - 1; }
            else l = mid + 1;
        } else {
            // ⑤ 右边界: <= target 才收缩左指针（记录并继续找更右）
            if (nums[mid] <= target) { bound = mid; l = mid + 1; }
            else r = mid - 1;
        }
    }
    return bound;
}
// 推演 [5,7,7,8,8,10], target=8：
//   左边界: mid=2(7) < 8 → l=3；mid=4(8) >= 8 → bound=4, r=3
//   mid=3(8) >= 8 → bound=3, r=2 → 返回 3 ✓
//   右边界: 类似 → 返回 4 ✓ → [3,4] ✓
// ⚠️ 与 704 的区别: 命中不返回——"记录 bound 继续缩"才能找边界
```

> 🎯 **34 的必考点**："**'命中不返回、记录继续缩'是边界二分与精确二分的唯一区别**——704 命中即返、34 命中记录后继续向边界收缩。两个判据（>= 左、<= 右）+ 越界检查，就是 34 的全部。"

## 6. 278 第一个错误版本（布尔谓词）

### 6.1 题目与思路

**题**：版本序列从某个版本开始全错（isBadVersion 单调），找第一个坏版本。

**布尔谓词二分**（二段性：前好后坏）：

```java
/**
 * LeetCode 278. 第一个错误的版本
 * 二段性二分: 前段 false（好）、后段 true（坏）
 * 时间 O(log n)，空间 O(1)
 */
public int firstBadVersion(int n) {
    int left = 1, right = n;
    while (left < right) {                     // ① < 循环（left == right 即答案）
        int mid = left + (right - left) / 2;
        if (isBadVersion(mid)) {
            right = mid;                       // ② mid 是坏的 → 答案在 [left, mid]
        } else {
            left = mid + 1;                    // ③ mid 是好的 → 答案在 [mid+1, right]
        }
    }
    return left;                               // ④ 第一个坏版本
}
// 推演 n=5, 坏版本从 4 开始：
//   mid=3(好) → l=4；mid=4(坏) → r=4 → 返回 4 ✓
// ⚠️ 左闭右开语义: right = mid（mid 可能是答案，不排除）——
//   与精确查找的 r = mid − 1 不同！
```

> 💡 **278 与 704 的模板切换**："**278 是'边界查找'——用左闭右开语义（r = mid 不排除）而非闭区间（r = mid−1）**。'候选答案不能排除'是边界二分的核心，与 34 的'记录继续缩'同一哲学。"

## 7. 模板选择与易错点

### 7.1 模板选择表

| 场景 | 模板 | 指针更新 |
|------|:---:|------|
| 精确查找（704） | 闭区间 `<=` | `r = mid − 1` |
| 插入位置（35） | 闭区间 `<=` | 返回 left |
| 边界查找（34） | 闭区间 + 记录 | `>=`/`<=` 判据 |
| 布尔谓词（278） | 左闭右开 `<` | `r = mid`（不排除） |
| lower_bound | 左闭右开 `<` | `r = mid` |

### 7.2 易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 混用开闭区间 | 选定一种保持到底 | #1 bug 来源 |
| 2 | mid 用 `(l+r)/2` | `l + (r−l)/2` | int 溢出 |
| 3 | 34 命中即返回 | 记录 bound 继续缩 | 找不到边界 |
| 4 | 34 忘越界检查 | `left < n && nums[left] == target` | 数组越界 |
| 5 | 278 用 `r = mid − 1` | `r = mid`（不排除候选） | 漏掉答案 |
| 6 | 35 返回 right | 返回 left（第一个 ≥） | 插入位置错 |
| 7 | 死循环 `l = mid` | `l = mid + 1`（区间必缩小） | 死循环 |

> 🎯 **核心要点**：二分模板通关四件事——**① 闭区间模板 2 分钟默写**（<= 循环、±1 更新、防溢出）；**② 35 的 left 语义**（第一个 ≥ 的位置）；**③ 34 两次二分**（>= 左、<= 右、命中继续缩）；**④ 278 的 r = mid**（候选不排除）。**'区间定义 + 排除一半'双段式 + 模板一致性，就是二分基础的全部**。
