## 1. 二维二分模型：展平 vs 结构化

```text
二维矩阵的两种二分思路:

  ① 展平二分（74）: 矩阵"行递增且行首大于前行尾"
     → 整体可视为一维有序数组 → 下标映射展平二分

  ② 结构化搜索（240）: 矩阵"行递增 + 列递增"（每行/列内有序）
     → 从右上角出发，Z 字行走——每次排除一行或一列

选型判断:
  "严格展平有序（74）" → 展平二分 O(log(mn))
  "仅行列有序（240）" → Z 字搜索 O(m+n)

⚠️ 区分: 74 的"下一行首 > 本行尾"是展平前提——
  240 没有这个性质（下一行首可能小于本行尾）
```

> 🎯 **核心认知**："**74 与 240 的差异 = '能否展平'——74 行间也衔接有序（可展平）、240 只有行列内有序（只能结构化走位）**。识别'整体有序 vs 局部有序'是二维二分的第一判断。"

## 2. 74 搜索二维矩阵（展平二分）

### 2.1 题目与思路

**题**：矩阵"行递增 + 行首 > 前行尾"（整体有序），查找 target。

**下标映射展平**：一维下标 → 二维坐标：

```java
/**
 * LeetCode 74. 搜索二维矩阵
 * 展平二分: 一维下标 ↔ 二维坐标映射
 * 时间 O(log(mn))，空间 O(1)
 */
public boolean searchMatrix(int[][] matrix, int target) {
    int m = matrix.length, n = matrix[0].length;
    int left = 0, right = m * n - 1;             // ① 展平为一维区间

    while (left <= right) {
        int mid = left + (right - left) / 2;
        int row = mid / n;                       // ② 一维 → 行
        int col = mid % n;                       // ③ 一维 → 列
        if (matrix[row][col] == target) return true;
        else if (matrix[row][col] < target) left = mid + 1;
        else right = mid - 1;
    }
    return false;
}
// 推演 matrix=[[1,3,5,7],[10,11,16,20],[23,30,34,60]], target=3：
//   mid=5(11) > 3 → r=4；mid=2(5) > 3 → r=1；mid=0(1) < 3 → l=1
//   mid=1(3) == 3 → true ✓
// ⚠️ 映射公式: row = mid / n、col = mid % n——
//   "展平下标 ↔ 二维坐标"是 74 的唯一新知识
```

> 💡 **展平的通用性**："**'展平下标 ↔ 二维坐标'（row = idx/n、col = idx%n）是 74 的核心——矩阵整体有序时，一维二分 + 坐标映射即解**。这个映射在 378 有序矩阵第 K 小（二分答案 + 计数）中也复用。"

## 3. 240 搜索二维矩阵 II（Z 字搜索）

### 3.1 题目与思路

**题**：矩阵"行递增 + 列递增"（无整体有序），查找 target（O(m+n)）。

**从右上角 Z 字走**：当前 < target → 下移（行排除）；> target → 左移（列排除）：

```java
/**
 * LeetCode 240. 搜索二维矩阵 II
 * Z 字搜索: 从右上角出发，每次排除一行或一列
 * 时间 O(m+n)，空间 O(1)
 */
public boolean searchMatrix2(int[][] matrix, int target) {
    int row = 0, col = matrix[0].length - 1;     // ① 右上角起点

    while (row < matrix.length && col >= 0) {
        if (matrix[row][col] == target) return true;
        else if (matrix[row][col] < target) {
            row++;                               // ② 当前 < target → 下移（本行全小）
        } else {
            col--;                               // ③ 当前 > target → 左移（本列全大）
        }
    }
    return false;
}
// 推演 [[1,4,7,11,15],[2,5,8,12,19],[3,6,9,16,22],[10,13,14,17,24],[18,21,23,26,30]], target=5：
//   (0,4)=15 > 5 → col=3；(0,3)=11 > 5 → col=2；(0,2)=7 > 5 → col=1
//   (0,1)=4 < 5 → row=1；(1,1)=5 == 5 → true ✓
// ⚠️ 为什么右上角: 它是"行的最大 + 列的最小"——
//   向下变大、向左变小，两个方向都有确定语义！
```

> 🎯 **240 的起点选择**："**右上角（或左下角）是 Z 字搜索的唯一正确起点——它同时是'行最大'与'列最小'，让'下移排除行、左移排除列'的语义成立**。左上角（行列都最小）和右下角（都最大）都没有这个性质。"

## 4. 611 有效三角形的个数（排序 + 二分）

### 4.1 题目与思路

**题**：数组能组成三角形的三元组个数。

**固定最长边 + 双指针/二分**：排序后 `a + b > c` 单调性：

```java
/**
 * LeetCode 611. 有效三角形的个数
 * 排序 + 双指针: 固定最长边，利用单调性批量统计
 * 时间 O(n²)，空间 O(1)
 */
public int triangleNumber(int[] nums) {
    Arrays.sort(nums);                           // ① 排序（单调性前提）
    int count = 0;
    for (int c = nums.length - 1; c >= 2; c--) { // ② 固定最长边
        int a = 0, b = c - 1;
        while (a < b) {
            if (nums[a] + nums[b] > nums[c]) {   // ③ a + b > c 成立
                // ④ ⚠️ 批量统计: a 从 0 到 b−1 都满足（nums[a] 递增）
                count += b - a;
                b--;                             // ⑤ 缩小 b 再试
            } else {
                a++;                             // ⑥ a + b ≤ c → 增大 a
            }
        }
    }
    return count;
}
// 推演 [2,2,3,4]：c=3(4): a=0(2)+b=2(3)=5 > 4 → count += 2, b=1
//   a=0(2)+b=1(2)=4 ≤ 4 → a=1 → 结束 → count=2
//   c=2(3): a=0(2)+b=1(2)=4 > 3 → count += 1 → 总数 3 ✓
//   （[2,2,3][2,3,4][2,3,4]——去重后 3 个，含重复元素共 3 组）
// ⚠️ 批量统计的正确性: 排序后 nums[a] 递增——
//   nums[b] 与 nums[c] 固定时，a 越大和越大；
//   一旦 a+b > c 成立，a..b−1 全部成立（一次加 b−a 个）
```

> 💡 **批量统计的思维**："**'固定一端 + 单调性批量计数'把 O(n³) 暴力降到 O(n²)——611 用双指针、378 用二分计数**。'一次排除/统计一批'是二分与双指针共享的效率哲学。"

## 5. 综合应用：二分 + 其他思想

### 5.1 二分 × 其他算法

| 组合 | 代表题 | 思路 |
|------|:---:|------|
| 二分 + 贪心 | 410 分割 | 二分答案 + 贪心分段验证 |
| 二分 + 计数 | 378 矩阵第 K 小 | 二分答案 + 每行二分计数 |
| 二分 + 双指针 | 611 三角形 | 排序 + 固定端 + 批量统计 |
| 二分 + DP | 410 双解 | DP O(m·n²) vs 二分 O(n log sum) |

### 5.2 378 有序矩阵中第 K 小的元素（二分答案 + 计数）

```java
/**
 * LeetCode 378. 有序矩阵中第 K 小的元素
 * 二分答案: 猜值 mid，统计 ≤ mid 的个数（每行二分/双指针）
 * 时间 O(n·log(max−min))，空间 O(1)
 */
public int kthSmallest(int[][] matrix, int k) {
    int n = matrix.length;
    int left = matrix[0][0], right = matrix[n - 1][n - 1];  // ① 值域

    while (left < right) {
        int mid = left + (right - left) / 2;
        int count = countLessEqual(matrix, mid);  // ② 统计 ≤ mid 的个数
        if (count >= k) {
            right = mid;                         // ③ 个数够了 → 值可能更小
        } else {
            left = mid + 1;                      // ④ 不够 → 值必须更大
        }
    }
    return left;
}

private int countLessEqual(int[][] matrix, int target) {
    int n = matrix.length, count = 0;
    int row = n - 1, col = 0;                    // ⑤ 从左下角走（同 240 思想）
    while (row >= 0 && col < n) {
        if (matrix[row][col] <= target) {
            count += row + 1;                    // ⑥ 本列上行全 ≤ target
            col++;                               //    右移
        } else {
            row--;                               //    上移
        }
    }
    return count;
}
// ⚠️ 378 = 二分答案（值域）+ 240 的走位计数——
//   "计数单调"（mid 越大 count 越大）→ 可二分！
```

> 🎯 **378 的组合价值**："**378 是'二分答案 + 矩阵走位计数'的组合题——count(mid) 随 mid 单调，二分值域；计数用 240 的 Z 字走位 O(n)**。'二分答案 + 高效计数'是矩阵第 K 大类题的标准配方。"

## 6. 二维与综合易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 74 映射公式反 | `row = mid / n`、`col = mid % n` | 坐标错位 |
| 2 | 240 从左下/左上起 | 右上（或左下）角 | 排除语义失效 |
| 3 | 240 用 `<=` 越界 | `row < m && col >= 0` | 数组越界 |
| 4 | 611 忘排序 | 先排序 | 单调性失效 |
| 5 | 611 批量统计写错 | `count += b − a`（一次加一批） | 计数漏/重 |
| 6 | 378 值域用下标 | 用值域 [min, max] | 二分对象错 |
| 7 | 378 计数忘走位 | Z 字走位（左下起） | O(n²) 退化 |

> 🎯 **核心要点**：二维与综合通关四件事——**① 展平 vs 结构化**（74 展平二分、240 Z 字走位）；**② 右上角起点**（行最大 + 列最小的双语义）；**③ 批量统计**（611 的 b−a、378 的 row+1）；**④ 组合意识**（二分 × 贪心/计数/双指针）。**二分的二维与综合应用 = '排除一半'思想的延伸——展平、走位、批量，都是'一次排除一批'的不同形态**。
