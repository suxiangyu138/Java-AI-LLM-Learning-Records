## 1. 四大战场识别（10 秒定位）

### 1.1 战场 → 模板 → 代表题

| 战场 | 识别信号 | 模板 | 代表题 |
|------|------|------|:---:|
| 基础查找 | "有序数组 + 查找" | 闭区间 <= | 704/35 |
| 边界定位 | "第一个/最后一个/插入" | 边界二分（>=/<=） | 34/278 |
| 旋转/特殊 | "旋转/峰值/缺失" | 二段性（先找有序区间） | 33/153/162 |
| 二分答案 | "最小 X 满足条件" | 值域二分 + can() | 69/875/1011/410 |

### 1.2 识别口诀

```text
"有序查找用闭区间，
 边界定位记继续缩，
 旋转数组找有序半，
 求值单调二分答案"

⚠️ 关键判断（10 秒）:
  答案在"数组里" → 传统二分
  答案在"值域里"（速度/容量/天数）→ 二分答案
  数组有特殊结构（旋转/峰值）→ 二段性
```

> 🎯 **识别是第一步**："**二分题 50% 的分数在'战场识别'——识别对了模板一填就通**。'答案在数组还是值域'是第一判断：数组 → 传统二分；值域 → 二分答案。"

## 3. 答题流程与话术模板

### 3.1 答题三步骤

```text
① 识别战场（10 秒）: 数组二分 / 边界二分 / 二段性 / 二分答案？
② 选模板（30 秒）: 闭区间 or 左闭右开 + 不变量声明
③ 写码 + 验证（5 分钟）: 模板 + 三样例（中/边/miss）+ 越界

⚠️ 面试官期待:
  "先声明区间与不变量，再写码——
   '我的不变量是答案永远在 [l,r] 内'一句，
   比 20 行正确代码更显功底"
```

### 3.2 话术模板

```text
"这是【战场】二分——【识别信号】。
模板: 【闭区间/左闭右开】，不变量: 【答案永远在区间内】。
（写码）mid 防溢出、指针更新保持不变量。
复杂度: O(log n)/O(1)。
（验证）三样例: 命中中间、命中边界、未命中；边界: 空/重复。"

例: "二分答案——'最小速度满足条件'。
    值域 [1, max(piles)]，can(mid) 模拟耗时（向上取整）。
    O(n·log(max))/O(1)。
    验证: 速度 4 可行、3 不可行 → 答案 4。"
```

## 4. 高频追问 TOP 10

| # | 追问 | 标准回答 |
|:---:|------|---------|
| 1 | 二分的本质？ | "一次比较排除一半"——有序只是常见实现，不是前提 |
| 2 | 闭区间 vs 左闭右开？ | 闭区间 ±1 排除 mid；左闭右开 r=mid 保留候选——选定不混用 |
| 3 | 为什么 mid 防溢出？ | `(l+r)/2` 在大数组溢出 int；`l+(r−l)/2` 安全 |
| 4 | 死循环怎么排查？ | 三根因: l=mid 不前进 / 开闭混用 / 方向反——先查指针更新 |
| 5 | 34 为什么两次二分？ | 左边界用 >= 判据、右边界用 <=——命中不返回、记录继续缩 |
| 6 | 33 为什么能二分？ | mid 切开至少一半有序——先找有序区间再判断 |
| 7 | 二分答案的前提？ | 可行性随答案单调——can(mid) 从 false 变 true 只一次 |
| 8 | lower_bound 是什么？ | 第一个 >= target——r 是候选不能排除（左闭右开语义） |
| 9 | 410 为什么二分比 DP 好？ | 二分答案 O(n log sum) vs DP O(m·n²)——值域二分 + 贪心验证 |
| 10 | 复杂度证明？ | T(n) = T(n/2) + O(1) → O(log n)；迭代空间 O(1) |

## 5. 面试实战演练：三道真题全程

### 5.1 真题一：搜索旋转排序数组（二段性考察）

```text
面试过程示范:
  ① 识别: "旋转数组 → 二段性——mid 切开至少一半有序"
  ② 声明: "闭区间模板，不变量: target 可能位置在 [l,r]"
  ③ 手撕: 33 模板（先找有序区间，<= 细节）
  ④ 边界: "范围判断用 <=——边界值本身合法，< 会漏检"
  ⑤ 追问: "153 最小值？" → 与 right 比较 + r=mid
```

### 5.2 真题二：爱吃香蕉的珂珂（二分答案）

```text
面试过程示范:
  ① 识别: "最小速度 → 二分答案（速度单调 → 耗时单调）"
  ② 值域: "[1, max(piles)]——速度下界 1、上界最大堆"
  ③ 手撕: 875 模板（can(mid) 模拟 + 向上取整）
  ④ 关键: "(p + speed − 1) / speed 向上取整 + 提前剪枝"
  ⑤ 追问: "1011 变体？" → 载重二分 + 贪心装船（同模板换 can）
```

### 5.3 真题三：查找元素首尾位置（边界二分）

```text
面试过程示范:
  ① 识别: "第一个/最后一个 → 边界二分（命中不返回）"
  ② 手撕: 34 模板（>= 找左、<= 找右，两次二分）
  ③ 边界: "左边界可能 == n（target 大于全部）——
     检查 left < n && nums[left] == target"
  ④ 追问: "lower_bound 是什么？" → 左边界就是 lower_bound
```

> 🎯 **核心要点**：面试实战通关 = **四大战场 10 秒识别 + 15 题三梯队 + 话术（区间 + 不变量 + 验证）+ 追问 TOP 10 + 三场演练（二段性/二分答案/边界）**。二分面试的完整答案 = **模板一致性 + 不变量声明 + 三样例验证**——"答案永远在 [l,r] 内"这一句，就是二分功底的最好证明。
