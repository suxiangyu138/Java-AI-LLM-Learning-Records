## 1. 知识体系导图

```text
二分查找（Binary Search）
│
├── 核心本质 ──────────────────────────────────────────────
│   ├── = "一次比较能排除一半搜索范围"
│   ├── 前提: 单调性（有序数组 / 单调函数 / 二段性）
│   ├── 复杂度: O(log n) 时间、O(1) 迭代空间
│   └── ⚠️ 不是"数组必须有序"——只要能二分排除即可
│
├── 基础模板 ──────────────────────────────────────────────
│   ├── 闭区间 [l, r]: while (l <= r) + mid 防溢出
│   ├── 左闭右开 [l, r): while (l < r) + right = mid
│   └── ⚠️ 混用开闭区间 = #1 bug 来源（选定一种保持到底）
│
├── 边界变体 ──────────────────────────────────────────────
│   ├── 35 插入位置（返回 left）
│   ├── 34 首尾位置（>= 找左、<= 找右，两次二分）
│   ├── 278 第一个错误版本（boolean 谓词）
│   └── lower_bound / upper_bound（C++ 语义）
│
├── 旋转数组与特殊有序 ────────────────────────────────────
│   ├── 33 旋转数组搜索（先找有序区间，<= 细节）
│   ├── 153 旋转最小值（nums[mid] vs nums[right]）
│   ├── 162 峰值（无序也能二分——趋势指引）
│   └── 二段性: 值 = 下标（缺失数字）
│
├── 二分答案（值域二分）──────────────────────────────────
│   ├── 69 平方根（解空间 [0, x] 二分）
│   ├── 875 香蕉 / 1011 包裹（谓词单调 → 二分）
│   ├── 410 分割数组（minimize max 经典）
│   └── 本质: 把"求值"转成"可行性判断"
│
├── 二维与综合 ────────────────────────────────────────────
│   ├── 74 有序矩阵（展平二分 / 行二分）
│   ├── 240 搜索矩阵（Z 字搜索）
│   └── 611 三角形计数（排序 + 二分/双指针）
│
└── 实战与面试 ────────────────────────────────────────────
    ├── 手写: 704/35/34 模板（2 分钟）
    ├── 易错: 混用区间、死循环 left=mid、越界检查
    ├── 复杂度: O(log n)——每次减半的数学直觉
    └── 话术: "区间定义 + 排除一半"双段式
```

## 4. 核心概念速查

| 概念 | 一句话解释 | 说明 |
|------|-----------|------|
| **二分查找** | 一次比较排除一半 | 前提 = 单调性/二段性 |
| **闭区间** | `[l, r]` + `while (l <= r)` | 新手最稳模板 |
| **左闭右开** | `[l, r)` + `while (l < r)` | right = mid（不排除） |
| **防溢出 mid** | `l + (r − l) / 2` | (l+r) 可能溢出 int |
| **lower_bound** | 第一个 ≥ target 的位置 | 边界二分的基础 |
| **二段性** | 前段满足、后段不满足 | 旋转数组/缺失数字 |
| **旋转数组** | 有序数组旋转，局部有序 | mid 切开至少一半有序 |
| **二分答案** | 值域二分 + 可行性判断 | 谓词单调即可 |
| **minimize max** | 最大化最小/最小化最大 | 410 分割经典 |
| **Z 字搜索** | 右上/左下行走 | 240 矩阵 O(m+n) |

## 5. 模板模式速查

### 5.1 两大模板对照

| 维度 | 闭区间 [l, r] | 左闭右开 [l, r) |
|------|:---:|:---:|
| 循环条件 | `l <= r` | `l < r` |
| 区间空判定 | l > r | l == r |
| 右指针更新 | `r = mid − 1` | `r = mid` |
| 适用 | 精确查找（704） | 边界查找（lower_bound） |
| 推荐 | **新手首选（90% 场景）** | 边界/二分答案常用 |

### 5.2 四大战场识别

```text
"有序数组查找" → 精确二分（704）
"第一个/最后一个/插入位置" → 边界二分（34/35）
"旋转/峰值/缺失" → 二段性二分（33/153/162）
"求值但谓词单调" → 二分答案（69/875/1011）
```

> 🎯 **一句话定位**："**二分 = '一次比较排除一半'——基础模板管查找、边界变体管定位、旋转数组管二段性、二分答案管值域**。O(log n) 的优雅背后，'区间定义一致性'是全部陷阱的总开关。"

## 6. 常见误区速查

| 误区 | 正解 |
|------|------|
| "二分只能用于有序数组" | ❌ 本质是"一次比较排除一半"——峰值（162）无序也能二分 |
| "混用开闭区间没事" | ❌ 混用 = #1 bug 来源——选定一种保持到底 |
| "mid 用 (l+r)/2" | ❌ 用 `l + (r−l)/2` 防溢出（大数组 l+r 溢出） |
| "死循环是玄学" | ❌ 根因 = `l = mid`（区间不缩小）或循环条件错 |
| "34 找到 target 就返回" | ❌ 找边界要"记录位置继续缩"（>=/<= 判据） |
| "33 用 < 判断范围" | ❌ 用 `<=`（边界值本身合法，< 会漏检） |
| "153 用 <= 循环" | ❌ 用 `<`（l==r 即答案，<= 死循环） |
| "二分答案只能二分数组" | ❌ 值域二分（69 平方根 [0,x]）——谓词单调即可 |
| "二分结果不用验越界" | ❌ 34 找完要查 `l < n && nums[l] == target` |
| "旋转数组必须整体有序" | ❌ 局部有序即可——mid 切开至少一半有序 |
