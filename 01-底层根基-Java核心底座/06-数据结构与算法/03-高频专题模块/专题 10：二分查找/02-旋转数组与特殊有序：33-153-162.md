## 1. 二段性模型：有序不是前提

```text
二段性: 数组/序列被某个性质分成"前段满足、后段不满足"（或反之）

旋转数组的二段性:
  [4,5,6,7,0,1,2] —— mid 切开后，至少有一半是完整有序的
  例: mid=7 → 左半 [4,5,6,7] 有序、右半 [0,1,2] 有序

峰值的二段性:
  nums[mid] < nums[mid+1] → 右侧有上升趋势 → 峰值在右
  nums[mid] > nums[mid+1] → 左侧有上升趋势 → 峰值在左

缺失数字的二段性:
  "值 == 下标"前段成立、后段不成立（缺哪个，从哪开始不成立）

⚠️ 核心: 二分的本质是"一次比较排除一半"——
  有序性只是最常见的二段性来源，不是唯一
```

> 🎯 **核心认知**："**旋转数组/峰值/缺失数字共享同一个模型：'二段性'——找到那个把数组切成'前段满足、后段不满足'的性质，就能二分**。'先找有序区间再判断'是旋转数组的具体化。"

## 2. 33 搜索旋转排序数组（先找有序区间）

### 2.1 题目与思路

**题**：旋转后的有序数组查找 target（O(log n)）。

**策略**：mid 切开后**至少一半有序**——先判断哪半有序，再决定 target 是否在其中：

```java
/**
 * LeetCode 33. 搜索旋转排序数组
 * 时间 O(log n)，空间 O(1)
 * ⚠️ 核心: mid 切开至少一半有序——"先找有序区间，再判断 target"
 */
public int search(int[] nums, int target) {
    int left = 0, right = nums.length - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] == target) return mid;

        if (nums[left] <= nums[mid]) {           // ① 左半有序（⚠️ 用 <=）
            if (nums[left] <= target && target < nums[mid]) {
                right = mid - 1;                 // ② target 在左半 → 收缩右
            } else {
                left = mid + 1;                  // ③ 否则去右半
            }
        } else {                                 // ④ 右半有序
            if (nums[mid] < target && target <= nums[right]) {
                left = mid + 1;                  // ⑤ target 在右半
            } else {
                right = mid - 1;
            }
        }
    }
    return -1;
}
// 推演 [4,5,6,7,0,1,2], target=0：
//   mid=3(7): 左半 [4..7] 有序；0 不在 [4,7) → left=4
//   mid=5(1): 左半 [0..1] 有序；0 在 [0,1) → right=4
//   mid=4(0) == 0 → 返回 4 ✓
// ⚠️ <= 的两个细节: nums[left] <= nums[mid]（区间只剩 1-2 元素时）
//   target <= nums[right]（边界值本身合法，< 会漏检）
```

> 🎯 **33 的必考点**："**'先找有序区间、再判断 target 是否在内'是旋转搜索的标准策略**——`<=` 的边界细节（左半判定与范围判定都含等号）是 33 的失分重灾区，面试主动指出 = 加分。"

## 3. 153 寻找旋转数组最小值（与 right 比较）

### 3.1 题目与思路

**题**：旋转数组的最小值（O(log n)）。

**与 right 比较**：`nums[mid] > nums[right]` → 最小在右半；否则最小在左半（含 mid）：

```java
/**
 * LeetCode 153. 寻找旋转排序数组中的最小值
 * 时间 O(log n)，空间 O(1)
 * ⚠️ 循环用 <（l == r 即答案）；与 right 比较
 */
public int findMin(int[] nums) {
    int left = 0, right = nums.length - 1;
    while (left < right) {                       // ① < 循环（防死循环）
        int mid = left + (right - left) / 2;
        if (nums[mid] > nums[right]) {
            left = mid + 1;                      // ② mid 在左半段 → 最小在右
        } else {
            right = mid;                         // ③ mid 在右半段 → 最小在 [l, mid]
        }
    }
    return nums[left];                           // ④ l == r 即最小值
}
// 推演 [3,4,5,1,2]：
//   mid=2(5) > nums[r]=2 → l=3；mid=3(1) < 2 → r=3 → 返回 1 ✓
// 未旋转 [1,2,3,4,5]：mid=2(3) < 5 → r=2；mid=1(2) < 3 → r=1
//   mid=0(1) < 2 → r=0 → 返回 1 ✓（完全有序也正确）
// ⚠️ 为什么 r = mid 而非 mid − 1: mid 可能就是最小值（旋转点）
//   → 候选不能排除（与 278 的 r = mid 同一哲学）
```

> 💡 **153 的"与 right 比较"**："**`nums[mid] vs nums[right]` 是旋转最小值的判据——mid > right 说明旋转点（最小值）在右侧；否则在左侧（含 mid）**。不变量：最小值永远在 [l, r] 内，循环到 l == r。"

## 4. 162 寻找峰值（趋势指引）

### 4.1 题目与思路

**题**：任意峰值（nums[i] > 左右邻居），数组无序也可二分。

**趋势指引**：`nums[mid] < nums[mid+1]` → 右侧上升必有峰值；否则左侧（含 mid）有峰值：

```java
/**
 * LeetCode 162. 寻找峰值
 * 时间 O(log n)，空间 O(1)
 * ⚠️ 无序也能二分——趋势（单调性）指引方向
 */
public int findPeakElement(int[] nums) {
    int left = 0, right = nums.length - 1;
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] < nums[mid + 1]) {
            left = mid + 1;                      // ① 右侧上升 → 峰值必在右
        } else {
            right = mid;                         // ② 左侧上升 → 峰值在 [l, mid]
        }
    }
    return left;                                 // ③ 收敛到峰值
}
// 推演 [1,2,3,1]：mid=1(2) < 3 → l=2；mid=2(3) > 1 → r=2 → 返回 2 ✓
//   [1,2,1,3,5,6,4]：峰值 2 或 5 任一 ✓
// ⚠️ 为什么"右侧上升必有峰值": 序列右端是 -∞（题设）——
//   上升趋势终会遇到"下降或边界"→ 其间必有峰值
```

> 🎯 **162 的模型价值**："**162 证明'无序也能二分'——'趋势'就是它的二段性**。'nums[mid] 与 nums[mid+1] 的关系'一次比较排除一半，与有序数组的模板完全同构。面试讲 162 时点出这点，二分本质就立住了。"

## 5. 二段性应用：缺失数字

### 5.1 题目与思路

**题**：0..n 中缺失的数字（数组长度 n，值范围 0..n）。

**值 = 下标二段性**：前段 `nums[i] == i` 成立，缺谁就从哪开始不成立：

```java
/**
 * 0~n 缺失数字（二分版）
 * 二段性: nums[i] == i 前段成立、后段不成立
 * 时间 O(log n)，空间 O(1)
 * ⚠️ 前提: 数组有序（否则排序或异或）
 */
public int missingNumber(int[] nums) {
    int left = 0, right = nums.length - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] == mid) {
            left = mid + 1;                      // ① 前段正常 → 缺在右
        } else {
            right = mid - 1;                     // ② 出现错位 → 缺在左
        }
    }
    return left;                                 // ③ 第一个错位处 = 缺失值
}
// 推演 [0,1,3]（缺 2）：mid=1(1)==1 → l=2；mid=2(3)!=2 → r=1 → 返回 2 ✓
// 推演 [0,1,2]（缺 3）：mid=1(1)==1 → l=2；mid=2(2)==2 → l=3 → 返回 3 ✓
// ⚠️ 异或解法 O(n)/O(1) 也常见——二分版展示"二段性"思维
```

> 💡 **二段性的统一**："**旋转数组（有序性分段）、峰值（趋势分段）、缺失数字（值=下标分段）——三个看似无关的题，共享'找到分界性质'这一个模型**。能讲出这个统一，就是二分思想的深度。"

## 6. 三题模板对照

| 题 | 判据 | 循环 | 指针更新 |
|:---:|------|:---:|------|
| 33 旋转搜索 | 左半有序？target 在左半？ | `<=` | `r = mid−1` / `l = mid+1` |
| 153 最小 | `nums[mid] > nums[right]` | `<` | `r = mid`（候选保留） |
| 162 峰值 | `nums[mid] < nums[mid+1]` | `<` | `r = mid`（候选保留） |

```text
⚠️ 规律:
  "找'精确值'（33）→ 闭区间 ±1；
   找'极值/边界'（153/162）→ < 循环 + r = mid（候选不能排除）"
```

## 7. 旋转数组易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 33 左半判定用 `<` | `nums[left] <= nums[mid]` | 区间剩 1-2 元素时误判 |
| 2 | 33 范围判定用 `<` | `target <= nums[right]` | 边界值漏检 |
| 3 | 153 用 `<=` 循环 | `<`（l==r 即答案） | 死循环 |
| 4 | 153 用 `r = mid − 1` | `r = mid`（mid 可能是答案） | 漏掉最小值 |
| 5 | 162 反向判断 | `mid < mid+1` → 去右；否则去左 | 峰值方向错 |
| 6 | 缺失数字判据反 | `nums[mid] == mid` 才右移 | 定位错 |
| 7 | 旋转数组当普通二分 | 先判断哪半有序 | 直接误判 |

> 🎯 **核心要点**：旋转数组通关四件事——**① 二段性模型**（有序不是二分前提）；**② 33 策略**（先找有序区间，<= 细节）；**③ 153/162 的 r = mid**（候选不排除，< 循环）；**④ 缺失数字**（值=下标分段）。**旋转数组是'排除一半'本质的试金石——'先找有序区间'五个字，就是 33 家族的钥匙**。
