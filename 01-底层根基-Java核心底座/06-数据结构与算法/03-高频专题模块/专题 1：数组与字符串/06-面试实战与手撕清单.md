## 1. 面试题解流程：30 秒定位模型

### 1.1 五步解题框架

```text
① 读题 10 秒: 数据载体（数组/字符串）+ 约束（连续？有序？原地？）
② 定位 10 秒: 按识别信号选模型
③ 确认 5 秒: 复杂度要求（O(n)？O(1) 空间？）
④ 手撕: 模板 + 状态设计
⑤ 验证: 小样例走一遍 + 边界（空/单元素/全相同）

识别信号速查:
  "两元素关系" → 双指针（对撞）/ 哈希
  "连续区间 + 条件" → 滑动窗口 / 前缀和
  "区间和 = K" → 前缀和 + 哈希
  "原地修改/去重" → 快慢指针
  "回文/反转" → 对撞 / 三次反转
  "字符计数/异位词" → 计数数组
  "最长/最短 + 子串" → 滑动窗口（更新时机分题型）
```

> 🎯 **核心认知**："**面试考察的不是'会不会这题'，而是'30 秒内能不能定位到模型'**——模型定位对了，模板一填就是 O(n) 解；定位错了，写再对也是 O(n²) 的次优解。识别信号表是全部手撕能力的加速器。"

## 3. 话术模板与复杂度速答

### 3.1 通用话术模板

```text
"这题是【模型名】题，因为【识别信号】。
我的方案是【模板描述】，时间 O(【复杂度】)，空间 O(【复杂度】）。
（写完代码后）验证样例：……，边界：空数组/单元素/全相同元素。

例: "这是滑动窗口题——'连续子数组 + 最短'是窗口的识别信号。
    右指针扩展窗口和，while 收缩找最短，最短题先记录再收缩。
    时间 O(n)（每元素进出窗口一次），空间 O(1)。"
```

### 3.2 复杂度速答表

| 模型 | 时间 | 空间 | 关键前提 |
|------|:---:|:---:|------|
| 对撞指针 | O(n) | O(1) | 有序性或可排序 |
| 快慢指针 | O(n) | O(1) | 原地修改语义 |
| 滑动窗口 | O(n) | O(1)/O(字符集) | 窗口状态可增删 |
| 单调队列 | O(n) | O(k) | 窗口极值 |
| 前缀和 | O(n) 预 + O(1) 查 | O(n) | 可累积运算 |
| 前缀和 + 哈希 | O(n) | O(n) | 区间和 = K 类 |
| 摩尔投票 | O(n) | O(1) | 出现 > n/2 |
| 三次反转 | O(n) | O(1) | 轮转/反转语义 |
| KMP | O(n + m) | O(m) | 单串匹配 |

## 4. 高频追问 TOP 10

| # | 追问 | 标准回答 |
|:---:|------|---------|
| 1 | 什么时候用滑动窗口？ | "连续子数组/子串 + 最长/最短/满足条件"，且窗口状态可 O(1) 增删 |
| 2 | 最长题与最短题区别？ | 最长先收缩后更新（窗口合法才计长）；最短先记录再收缩 |
| 3 | 前缀和 vs 滑动窗口？ | 窗口和单向变化用窗口；可增可减（如含负数）用前缀和+哈希 |
| 4 | 560 为什么是 O(n)？ | "区间和 = K" 转 "历史前缀和 = 当前 − K"，哈希查历史 O(1) |
| 5 | 快慢指针能做什么？ | 链表环/中点 + 数组原地修改（读写指针去重/移除） |
| 6 | 88 为什么从尾部合并？ | 正序会覆盖未处理元素；逆序天然免疫，O(1) 额外空间 |
| 7 | 摩尔投票为什么正确？ | 多数元素 > n/2 → 与其他元素两两抵消后必剩 |
| 8 | 计数数组 vs 哈希表？ | 字符集有限（26/128）用数组：O(1) 空间、更快、无装箱 |
| 9 | KMP 的核心思想？ | 失配时主串指针不回退，模式串回退到最长公共前后缀（next） |
| 10 | 239 为什么是 O(n)？ | 单调队列每个元素进出各一次（摊还），队首恒为窗口最大 |

## 5. 笔试题型与常见陷阱

### 5.1 笔试高频题型

| 题型 | 示例 | 注意 |
|------|------|------|
| 手撕基础模板 | 反转字符串/移动零 | 边界与 O(1) 空间 |
| 模型识别题 | "描述思路即可" | 识别信号 + 复杂度论证 |
| 边界设计题 | atoi/atoi 溢出 | 边界四连（空格/符号/数字/溢出） |
| 优化题 | "O(n²) 能否到 O(n)" | 哈希/前缀和/窗口三板斧 |
| 组合题 | "字符串 + 窗口 + 哈希" | 76/438 类（状态设计） |

### 5.2 常见陷阱

```text
① 滑动窗口收缩用 if —— 必须 while（一次收缩可能仍不合法）
② 560 忘 put(0, 1) —— 漏掉从头开始的子数组
③ 189 忘 k %= n —— 反转错位
④ 15 漏去重 —— 三元组重复
⑤ atoi 溢出判定用乘法 —— 必须除法预判
⑥ 42 只想到 O(n²) 暴力 —— 对撞 O(1) 是加分答案
⑦ 输出格式（返回长度 vs 返回数组）—— 先读清题

⚠️ 通用原则: 写完代码 30 秒"走样例 + 查边界"再交——
  空数组、单元素、全相同、最大规模（溢出）
```

## 6. 面试实战演练：三道真题全程

### 6.1 真题一：三数之和（对撞 + 去重）

```text
面试过程示范:
  ① 定位: "找三元素和 = 0 → 排序 + 固定一个 + 对撞找两数"（10 秒）
  ② 复杂度: O(n²)（排序 O(n log n) + n 轮对撞 O(n)）
  ③ 手撕: 15 题完整代码（01 文件）
  ④ 边界: 数组长度 < 3 → 空；去重三连防重复
  ⑤ 追问: "为什么排序后能对撞？" → 有序性让指针移动有方向
```

### 6.2 真题二：和为 K 的最短子数组（模型转换）

```text
面试过程示范:
  ① 定位: "连续子数组 + 和 = K" → 前缀和 + 哈希（560 模板）
  ② 变形: 要"最短" → 哈希存"最早出现位置"而非计数
  ③ 手撕: prefix 遍历，查 sum−K 的最早位置，取最小长度
  ④ 陷阱: 含负数 → 窗口失效，必须前缀和（主动指出 = 加分）
  ⑤ 追问: "为什么不能滑动窗口？" → 负数让窗口和不单调
```

### 6.3 真题三：字符串旋转（反转思想迁移）

```text
面试过程示范:
  ① 定位: "旋转/轮转" → 三次反转（189 的迁移）
  ② 变形: 判断 s2 是否 s1 的旋转 → s1+s1 包含 s2（KMP/contains）
  ③ 手撕: 双解（三次反转 + 拼接包含）
  ④ 追问: "s1+s1 为什么成立？" → 旋转 = 从某点切开交换两段
            → 拼接后所有旋转形态都是其子串
```

> 🎯 **核心要点**：面试实战通关 = **30 秒定位（识别信号表）+ 15 题清单（三梯队）+ 话术模板（模型/复杂度/边界三段式）+ 三场演练（对撞/前缀和/反转迁移）**。数组与字符串是面试的第一道关卡——**模型识别速度决定第一印象，第一梯队 5 题的肌肉记忆决定手撕通过率**。把这六篇吃透，Hot 100 的数组/字符串部分就是你的舒适区。
