## 5. 解题模型速查

### 5.1 识别信号表（核心方法论）

| 题目特征 | 首选模型 | 代表题 |
|------|------|------|
| "有序数组" + "找两个元素" | 对撞指针 | 167/15 |
| "原地修改/去重/移除" | 快慢指针（读写指针） | 283/26/27 |
| "连续子数组/子串" + "最长/最短" | 滑动窗口 | 3/76/209 |
| "连续子数组" + "和 = K/区间查询" | 前缀和 + 哈希 | 560/303 |
| "找两个数"（无序） | 哈希映射 | 1 |
| 对称性/回文/两端 | 对撞指针 | 344/125 |
| 相邻比较 + 维护极值 | 单调队列/单调栈 | 239 |
| 字符串匹配 | KMP / 滑动窗口 | 28/76 |

### 5.2 双指针 vs 滑动窗口 vs 前缀和

| 维度 | 双指针 | 滑动窗口 | 前缀和 |
|------|:---:|:---:|:---:|
| 指针方向 | 相向 / 同向 | 严格同向 | 无指针 |
| 适用 | 两元素关系/原地修改 | 连续区间 + 状态维护 | 区间和查询 |
| 状态变化 | 无（只看两个位置） | 单向（窗口和只能增/减） | 可增可减 |
| 复杂度 | O(n) / O(n log n) | O(n) | O(n) 预处理 + O(1) 查询 |

> 🎯 **模型选择口诀**："**两元素关系用双指针，连续区间用滑动窗口，区间求和用前缀和，无序查找用哈希**"——30 秒定位模型的依据就是这四句。

## 6. 常见误区速查

| 误区 | 正解 |
|------|------|
| "滑动窗口 = 双指针" | ❌ 滑动窗口是双指针的特例（同向 + 连续区间 + 状态维护），但模板与更新时机有专属套路 |
| "可变窗口收缩用 if 就行" | ❌ 必须用 while——一次收缩可能仍不合法 |
| "最长题和最短题更新时机一样" | ❌ 最长题先修复窗口再更新；最短题先记录答案再收缩 |
| "前缀和只用于求和" | ❌ 前缀思想可用于乘积（238）、异或、差值（股票）等一切可累积运算 |
| "560 直接用前缀和数组" | ❌ 要"前缀和 + 哈希表"组合——O(n²) 双循环会超时 |
| "238 可以用除法" | ❌ 题目明确禁止除法（0 的处理）；用前后缀乘积两次遍历 |
| "快慢指针只能用于链表" | ❌ 数组的原地修改（读写指针）是快慢指针的最大应用面 |
| "轮转数组用循环移位" | ❌ O(n·k) 超时；三次反转 O(n) 是标准解 |
| "摩尔投票只能解决 169" | ❌ 推广：出现次数 > n/3 的元素（两候选版） |
| "字符串题必须用哈希表" | ❌ 字符计数数组（128 槽）更省更快，异位词判定首选 |
