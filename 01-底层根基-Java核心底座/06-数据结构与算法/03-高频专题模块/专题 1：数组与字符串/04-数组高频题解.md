## 1. 88 合并两个有序数组（逆序双指针）

### 1.1 题目与思路

**题**：nums1 长度 m+n（尾部预留 0），把 nums2 合并进 nums1（原地 O(1) 额外空间）。

**逆序双指针**：从尾部向前合并——**避免覆盖 nums1 前部未处理元素**：

```java
/**
 * LeetCode 88. 合并两个有序数组
 * 从尾部合并: 大者放最后，不会覆盖未处理元素
 * 时间 O(m+n)，空间 O(1) 额外
 */
public void merge(int[] nums1, int m, int[] nums2, int n) {
    int i = m - 1, j = n - 1, k = m + n - 1;      // ① 三个尾部指针
    while (i >= 0 && j >= 0) {
        if (nums1[i] > nums2[j]) nums1[k--] = nums1[i--];   // ② 大者放尾部
        else                     nums1[k--] = nums2[j--];
    }
    while (j >= 0) nums1[k--] = nums2[j--];       // ③ 只需处理 nums2 剩余
    // nums1 剩余元素天然已在正确位置（原位）
}
// 推演 nums1=[1,2,3,0,0,0], nums2=[2,5,6]：
//   3 vs 6 → 尾 6；3 vs 5 → 5；3 vs 2 → 3；2 vs 2 → 2(nums2)；1 vs 2 → 2；剩 1 → 原位
//   → [1,2,2,3,5,6] ✓
```

> 🎯 **逆序双指针的通法**："**'从后往前'是原地合并类题的万能钥匙**——正序会覆盖未处理元素，逆序天然免疫。88 会了，同族题（21 链表合并、977 有序数组平方）全部打通。"

## 2. 169 多数元素（摩尔投票）

### 2.1 题目与思路

**题**：出现次数 > n/2 的元素（O(n)/O(1) 要求）。

**摩尔投票**：候选 + 计数——**"不同则抵消，相同则累加"**，最后剩下的一定是多数：

```java
/**
 * LeetCode 169. 多数元素（摩尔投票）
 * 核心: 多数元素与其他元素两两抵消后必然剩下
 * 时间 O(n)，空间 O(1)
 */
public int majorityElement(int[] nums) {
    int candidate = nums[0], count = 1;          // ① 候选 + 计数
    for (int i = 1; i < nums.length; i++) {
        if (count == 0) {                        // ② 计数归零 → 换候选
            candidate = nums[i];
            count = 1;
        } else if (nums[i] == candidate) {
            count++;                             // ③ 相同累加
        } else {
            count--;                             // ④ 不同抵消
        }
    }
    return candidate;
}
// 推演 [2,2,1,1,1,2,2]：候选 2，计数 1→2→1→0(换 1)→1→0(换 2)→1 → 答案 2 ✓
// ⚠️ 正确性: 多数元素 > n/2 → 抵消后计数必为正 → 必剩多数
// 推广: 出现 > n/3 的元素（两候选版）——最多 2 个
```

> 💡 **为什么是 O(1) 空间**："排序取中位 O(n log n)、哈希计数 O(n) 空间、摩尔投票 O(n)/O(1)——**'抵消'思想让它成为多数元素的唯一最优解**。'不同则抵消'的直觉：多数元素比所有其他元素加起来还多，抵消不完。"

## 3. 189 轮转数组（三次反转）

### 3.1 题目与思路

**题**：数组右移 k 位（O(1) 额外空间）。

**三次反转**：`k %= n` → 整体反转 → 前 k 个反转 → 后 n−k 个反转：

```java
/**
 * LeetCode 189. 轮转数组（三次反转）
 * 时间 O(n)，空间 O(1)
 */
public void rotate(int[] nums, int k) {
    int n = nums.length;
    k %= n;                                     // ① 取模（k ≥ n 时等价）
    reverse(nums, 0, n - 1);                    // ② 整体反转
    reverse(nums, 0, k - 1);                    // ③ 前 k 个反转
    reverse(nums, k, n - 1);                    // ④ 后 n−k 个反转
}

private void reverse(int[] nums, int lo, int hi) {
    while (lo < hi) {
        int tmp = nums[lo]; nums[lo] = nums[hi]; nums[hi] = tmp;
        lo++; hi--;
    }
}
// 推演 [1,2,3,4,5,6,7]，k=3：
//   整体反转 → [7,6,5,4,3,2,1]
//   前 3 反转 → [5,6,7,4,3,2,1]
//   后 4 反转 → [5,6,7,1,2,3,4] ✓
```

> 💡 **为什么三次反转成立**："右移 k 位 = 把后 k 个元素移到前面——**整体反转让'前后两段'就位，再各自反转还原段内顺序**。两次反转能做的事，三次反转解决得更优雅（151 反转单词也是同款）。"

## 4. 121 买卖股票的最佳时机（一次遍历）

### 4.1 题目与思路

**题**：一次买卖的最大利润（只能买卖一次）。

**一次遍历**：记录"历史最低价"，每天算"当天卖出的利润"取最大：

```java
/**
 * LeetCode 121. 买卖股票的最佳时机（一次交易）
 * 时间 O(n)，空间 O(1)
 * ⚠️ 贪心: 只关心"历史最低买入 + 当天卖出"——不需要知道未来
 */
public int maxProfit(int[] prices) {
    int minPrice = Integer.MAX_VALUE;           // ① 历史最低价
    int best = 0;
    for (int price : prices) {
        minPrice = Math.min(minPrice, price);   // ② 更新历史最低
        best = Math.max(best, price - minPrice);// ③ 当天卖出的利润
    }
    return best;
}
// 推演 [7,1,5,3,6,4]：min: 7→1；利润: 0,0,4,2,5,3 → 答案 5 ✓
// ⚠️ 为什么贪心成立: 任意一天的最佳买入 = 之前的最低点
//   → 每天只比较"历史最低"即可，无需回溯
// 变体: 122 可多次交易（累加所有上升段）；123 最多两次（前后缀分段）
```

## 5. 55 跳跃游戏（贪心区间）

### 5.1 题目与思路

**题**：能否跳到末尾（每个位置可跳最大步数）。

**贪心可达区间**：维护"最远可达位置"，逐步扩展：

```java
/**
 * LeetCode 55. 跳跃游戏（贪心）
 * 时间 O(n)，空间 O(1)
 * ⚠️ 核心: 最远可达区间 [0, farthest]——区间内所有位置都可达
 */
public boolean canJump(int[] nums) {
    int farthest = 0;                           // ① 最远可达
    for (int i = 0; i <= farthest && i < nums.length; i++) {
        farthest = Math.max(farthest, i + nums[i]);   // ② 扩展可达区间
        if (farthest >= nums.length - 1) return true; // ③ 已到末尾
    }
    return false;
}
// 推演 [2,3,1,1,4]：i=0 → far=2；i=1 → far=4 → true ✓
//   [3,2,1,0,4]：i=0 → far=3；i=3 → far=3（跳不动）→ false ✓
// ⚠️ 变体: 45 最少跳跃次数（区间分段贪心/BFS）
```

## 6. 380 O(1) 插入删除随机（哈希 + 数组）

### 6.1 题目与思路

**题**：O(1) 插入/删除/随机获取（元素不重复）。

**数组 + 哈希**：数组存值（随机 O(1)），哈希存"值 → 下标"（查找 O(1)），**删除用"末尾交换法"**：

```java
/**
 * LeetCode 380. O(1) 时间插入、删除和获取随机元素
 * 数组（随机访问）+ 哈希表（值 → 下标）+ 末尾交换删除
 */
class RandomizedSet {
    private final List<Integer> list = new ArrayList<>();
    private final Map<Integer, Integer> index = new HashMap<>();
    private final Random random = new Random();

    public boolean insert(int val) {
        if (index.containsKey(val)) return false;
        index.put(val, list.size());            // ① 哈希记下标
        list.add(val);                          // ② 数组尾插
        return true;
    }

    public boolean remove(int val) {
        Integer pos = index.remove(val);
        if (pos == null) return false;
        int last = list.get(list.size() - 1);   // ③ 末尾交换法
        list.set(pos, last);                    //    被删位置 ← 末尾元素
        index.put(last, pos);                   //    更新其哈希
        list.remove(list.size() - 1);           //    弹出末尾
        return true;
    }

    public int getRandom() {
        return list.get(random.nextInt(list.size()));   // ④ 数组随机 O(1)
    }
}
```

> 🎯 **380 的设计价值**："**'数组 + 哈希 + 末尾交换'是 O(1) 容器的经典配方**——数组保证随机 O(1)、哈希保证查找 O(1)、末尾交换让删除 O(1)（避免数组中间删除的 O(n) 搬移）。这个配方在 LRU/线程池/数据库设计中反复出现。"

## 7. 135 分发糖果与 134 加油站（双向/环形贪心）

### 7.1 135 分发糖果（双向遍历）

```java
/**
 * LeetCode 135. 分发糖果
 * 双向贪心: 先从左向右（右比左大 → +1），再从右向左（左比右大 → 取 max）
 * 时间 O(n)，空间 O(n)
 */
public int candy(int[] ratings) {
    int n = ratings.length;
    int[] candies = new int[n];
    Arrays.fill(candies, 1);                    // ① 每人至少 1 颗

    for (int i = 1; i < n; i++) {               // ② 左 → 右
        if (ratings[i] > ratings[i - 1])
            candies[i] = candies[i - 1] + 1;
    }
    for (int i = n - 2; i >= 0; i--) {          // ③ 右 → 左（取 max 兼顾两侧）
        if (ratings[i] > ratings[i + 1])
            candies[i] = Math.max(candies[i], candies[i + 1] + 1);
    }
    int total = 0;
    for (int c : candies) total += c;
    return total;
}
// 推演 [1,0,2]：左→右 [1,1,2]；右→左 [2,1,2] → 5 ✓
// ⚠️ 双向遍历是"两侧约束"题的通用解（左看左约束、右看右约束）
```

### 7.2 134 加油站（环形贪心）

```java
/**
 * LeetCode 134. 加油站（环形）
 * 核心: 总油 < 总耗 → 无解；否则从"最低点之后"起步必可走完
 * 时间 O(n)，空间 O(1)
 */
public int canCompleteCircuit(int[] gas, int[] cost) {
    int total = 0, current = 0, start = 0;
    for (int i = 0; i < gas.length; i++) {
        total += gas[i] - cost[i];              // ① 全局判定
        current += gas[i] - cost[i];
        if (current < 0) {                      // ② 从 i 起步不行 → 换 i+1
            start = i + 1;
            current = 0;
        }
    }
    return total < 0 ? -1 : start;              // ③ 全局可行 → start 必可行
}
// ⚠️ 证明直觉: 若总油 ≥ 总耗，存在唯一"最低前缀和点"，
//   从它的下一点起步，全程油量不会为负
```
