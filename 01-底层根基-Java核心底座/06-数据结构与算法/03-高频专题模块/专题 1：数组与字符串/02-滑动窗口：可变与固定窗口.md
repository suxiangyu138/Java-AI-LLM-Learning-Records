## 1. 滑动窗口模型：连续区间 + 状态维护

```text
滑动窗口 = 双指针特例（严格同向）+ 连续区间 + 状态维护

三要素:
  ① 窗口状态: 计数 / 和 / 匹配数 / 最大值（需要能快速增删）
  ② 合法性: 窗口"合法"的定义（无重复 / 覆盖 / 和达标）
  ③ 更新时机: 何时记录答案（最长题 vs 最短题不同）

为什么 O(n):
  每个元素最多"进窗一次 + 出窗一次"
  → 右指针扫一遍 + 左指针扫一遍 = O(n)

识别信号:
  "连续子数组/子串" + "最长/最短/满足条件" → 滑动窗口
  ⚠️ 前缀和也能做区间问题，但窗口内条件需要"单向变化"才适用
```

> 🎯 **核心动作三连**：**右进（扩展窗口 + 更新状态）→ while 收缩（不合法时左出 + 回退状态）→ 更新答案（时机按题型）**。"右指针负责找可行解，左指针负责优化解"——窗口状态必须支持 O(1) 增删，这是选择计数数组/哈希表/单调队列的依据。

## 2. 可变窗口模板（面试标准答案）

### 2.1 通用模板（2025 标准版）

```java
/**
 * 可变窗口通用模板
 * 节奏: 右进 → while 收缩 → 更新答案
 */
int slidingWindow(int[] nums, int k) {
    Map<Integer, Integer> state = new HashMap<>();   // ① 窗口状态（计数/和/匹配）
    int left = 0, answer = 0;

    for (int right = 0; right < nums.length; right++) {
        // ② 右进: 加入 nums[right]，更新状态
        add(nums[right], state);

        // ③ 收缩: 窗口不合法时，left 右移直到合法（必须 while！）
        while (!isValid(state)) {
            remove(nums[left], state);               // 回退状态
            left++;
        }

        // ④ 更新答案（时机见第 7 节三原则）
        answer = Math.max(answer, right - left + 1);
    }
    return answer;
}
```

### 2.2 模板三问（面试必答）

```text
① 窗口状态是什么？ —— 计数数组 / 哈希表 / 和 / 匹配数
② 合法性怎么判？ —— 无重复？覆盖 target？和 ≥ s？
③ 更新时机在哪？ —— 最长题在收缩后；最短题在收缩前记录

⚠️ 收缩必须用 while:
  一次左出可能仍不合法（多个重复字符要逐个移出）
  用 if 只收缩一步 → 窗口状态错误
```

## 3. 3 无重复字符的最长子串（最长题）

### 3.1 题目与思路

**题**：无重复字符的最长子串（O(n)）。

**状态**：字符计数；**合法性**：无字符计数 > 1；**更新**：收缩合法后记录最长：

```java
/**
 * LeetCode 3. 无重复字符的最长子串
 * 时间 O(n)，空间 O(字符集)（128 计数数组）
 */
public int lengthOfLongestSubstring(String s) {
    int[] count = new int[128];                  // ① 字符计数数组
    int left = 0, best = 0;
    for (int right = 0; right < s.length(); right++) {
        count[s.charAt(right)]++;                // ② 右进
        while (count[s.charAt(right)] > 1) {     // ③ 有重复 → 收缩到无重复
            count[s.charAt(left)]--;             //    左出并回退计数
            left++;
        }
        best = Math.max(best, right - left + 1); // ④ 收缩后更新（最长题）
    }
    return best;
}
// 推演 "abcabcbb"：right 到第二个 a 时窗口 "abca" → 收缩去 a → "bca"
//   best: 3 → 3 → 3 ✓（答案 3）
// ⚠️ 进阶: 用 Map<Character,Integer> 记"最后出现位置"，left 直接跳到
//   max(left, last+1)——省去 while 收缩（O(n) 常数更小）
```

> 💡 **最长题要点**："**先收缩到合法，再更新答案**——窗口合法时才能计长。进阶版用'最后出现位置'让左指针直接跳跃，是 3 题的最优常数写法。"

## 4. 76 最小覆盖子串（最短题）

### 4.1 题目与思路

**题**：包含 t 中所有字符（含数量）的最短子串（O(n)）。

**三变量计数**：`need`（还差多少种）、`window`（窗口内每种字符计数）、`valid`（已满足的字符种类数）：

```java
/**
 * LeetCode 76. 最小覆盖子串
 * 时间 O(n)，空间 O(字符集)
 * ⚠️ 最短题: 先记录答案，再收缩！
 */
public String minWindow(String s, String t) {
    int[] need = new int[128], window = new int[128];
    for (char c : t.toCharArray()) need[c]++;

    int left = 0, valid = 0;                   // valid: 已满足的字符种类
    int minLen = Integer.MAX_VALUE, start = 0;

    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        if (need[c] > 0) {                     // ① 只关心 t 中的字符
            window[c]++;
            if (window[c] == need[c]) valid++; // ② 某字符数量达标
        }
        while (valid == needCount(t)) {        // ③ 全部达标 → 尝试收缩
            if (right - left + 1 < minLen) {   // ④ 先记录答案（最短题！）
                minLen = right - left + 1;
                start = left;
            }
            char d = s.charAt(left);
            if (need[d] > 0) {                 // ⑤ 左出并回退 valid
                if (window[d] == need[d]) valid--;
                window[d]--;
            }
            left++;
        }
    }
    return minLen == Integer.MAX_VALUE ? "" : s.substring(start, start + minLen);
}
// 推演 S="ADOBECODEBANC", T="ABC"：答案 "BANC"（经典例）
```

> 🎯 **最短题 vs 最长题的分水岭**："**最短题先记录答案再收缩**（记录的是'当前合法窗口'）；**最长题先收缩再更新**（更新的是'收缩后的合法窗口'）。76 的 valid 计数是'种类达标'而非'字符达标'——need/window/valid 三变量是覆盖类题的标配。"

## 5. 209 长度最小的子数组（最短题变体）

### 5.1 题目与思路

**题**：和 ≥ target 的最短连续子数组。

**状态**：窗口和（单向增长 → 典型窗口题）；**最短题**：先记录再收缩：

```java
/**
 * LeetCode 209. 长度最小的子数组
 * 时间 O(n)，空间 O(1)
 */
public int minSubArrayLen(int target, int[] nums) {
    int left = 0, sum = 0, minLen = Integer.MAX_VALUE;
    for (int right = 0; right < nums.length; right++) {
        sum += nums[right];                    // ① 右进（窗口和只能增）
        while (sum >= target) {                // ② 达标 → 收缩找最短
            minLen = Math.min(minLen, right - left + 1);   // ③ 先记录（最短题）
            sum -= nums[left];                 // ④ 左出
            left++;
        }
    }
    return minLen == Integer.MAX_VALUE ? 0 : minLen;
}
// 推演 [2,3,1,2,4,3]，target=7：窗口 [2,3,1,2] 和 8 ≥ 7 → 记录 4
//   收缩 → [3,1,2] 和 6 < 7 → 右进 4 → [3,1,2,4] 和 10 → 记录 4
//   收缩 → [1,2,4] 和 7 → 记录 3 → [2,4] 和 6 → 右进 3 → [2,4,3] 和 9 → 记录 3
//   收缩 → [4,3] 和 7 → 记录 2 ✓（答案 2）
```

## 6. 固定窗口：438 异位词与 239 最大值

### 6.1 438 找到字符串中所有字母异位词（固定窗口 + 计数数组）

```java
/**
 * LeetCode 438. 找到字符串中所有字母异位词
 * 固定窗口: 长度恒为 p.length()，进一出
 * 时间 O(n)，空间 O(1)（26/128 计数数组）
 */
public List<Integer> findAnagrams(String s, String p) {
    int[] need = new int[26], window = new int[26];
    for (char c : p.toCharArray()) need[c - 'a']++;

    List<Integer> result = new ArrayList<>();
    for (int right = 0; right < s.length(); right++) {
        window[s.charAt(right) - 'a']++;               // ① 进
        if (right >= p.length()) {
            window[s.charAt(right - p.length()) - 'a']--;  // ② 出（固定长度）
        }
        if (Arrays.equals(need, window)) {             // ③ 计数相等 = 异位词
            result.add(right - p.length() + 1);
        }
    }
    return result;
}
// ⚠️ 固定窗口无需 while 收缩——长度恒定，进出对称
//   Arrays.equals(26 位数组) 是 O(26) 常数，可接受
```

### 6.2 239 滑动窗口最大值（固定窗口 + 单调队列）

```java
/**
 * LeetCode 239. 滑动窗口最大值
 * 单调递减队列: 队首 = 窗口最大值；新元素弹出队尾所有更小的
 * 时间 O(n)（每元素进出队列各一次），空间 O(k)
 */
public int[] maxSlidingWindow(int[] nums, int k) {
    Deque<Integer> deque = new ArrayDeque<>();     // 存下标，值单调递减
    int[] result = new int[nums.length - k + 1];
    for (int i = 0; i < nums.length; i++) {
        // ① 弹出队尾所有 ≤ 当前值的（它们永远当不了最大值）
        while (!deque.isEmpty() && nums[deque.peekLast()] <= nums[i]) {
            deque.pollLast();
        }
        deque.offerLast(i);                        // ② 入队
        if (deque.peekFirst() <= i - k) deque.pollFirst();  // ③ 出窗
        if (i >= k - 1) {
            result[i - k + 1] = nums[deque.peekFirst()];   // ④ 队首 = 最大
        }
    }
    return result;
}
// 推演 [1,3,-1,-3,5,3,6,7]，k=3：结果 [3,3,5,5,6,7] ✓
// ⚠️ 单调队列: 每个元素入队/出队各一次 → O(n) 摊还
```

> 🎯 **固定窗口要点**："**固定窗口 = 进一出 + 无 while**——438 用计数数组对拍，239 用单调队列保极值。单调队列的'弹出队尾所有更小'是 O(n) 的摊还魔法：每个元素只被弹一次。"

## 7. 更新时机三原则与易错点

### 7.1 更新时机三原则（面试必答）

| 题型 | 更新时机 | 原因 | 代表 |
|------|------|------|------|
| 最长题 | 收缩合法**后**更新 | 窗口要合法才能计长 | 3、424 |
| 最短题 | 收缩**前**记录 | 记录的是当前合法窗口 | 76、209 |
| 固定窗口 | 进出对称后直接更新 | 窗口天然合法 | 438、239 |

```text
口诀: "最长先修后记，最短先记后修，固定进出对称"
```

### 7.2 手写易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 收缩用 `if` | `while`（一次可能不够） | 窗口状态残留非法 |
| 2 | 左出忘记回退状态 | `count[left]--` 同步 | 状态失真 → 错误结果 |
| 3 | 最短题在收缩后记录 | 收缩前记录 | 漏掉最短窗口 |
| 4 | 239 存值不存下标 | 存下标（判断出窗） | 无法判断窗口过期 |
| 5 | 438 用 `HashMap` | 计数数组（26/128） | 常数大、易错 |
| 6 | 76 的 valid 计数错 | 种类达标（==need[c]）而非 ≥ | 误判覆盖 |
| 7 | 窗口状态不支持 O(1) 删除 | 选对结构（数组/哈希/双端队列） | 复杂度退化 O(n²) |

> 🎯 **核心要点**：滑动窗口通关四件事——**① 通用模板烂熟**（右进 → while 收缩 → 更新）；**② 更新时机三原则脱口而出**（最长先修后记/最短先记后修/固定进出对称）；**③ 四题全会**（3 计数收缩、76 三变量、209 窗口和、438 固定窗口）；**④ 239 单调队列理解 O(n) 摊还**。它是"连续区间 + 条件"类题的最优解模板，也是字符串题与数组题的公共语言。
