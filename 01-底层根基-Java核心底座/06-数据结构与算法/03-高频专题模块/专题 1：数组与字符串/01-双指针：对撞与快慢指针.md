## 1. 双指针全景：三种模式

```text
模式一: 对撞指针（左右指针）——首尾相向
  适用: 有序数组找两元素、回文、容器、接雨水
  代表: 167、15、11、42、344、125

模式二: 快慢指针（同向）——速度或职责不同
  适用: 链表环/中点、数组原地修改（读写指针）
  代表: 283、26、27、80、141、19

模式三: 滑动窗口（同向 + 连续区间）——02 文件专讲
  适用: 连续子数组/子串
  代表: 3、76、209、438

识别信号:
  "有序 + 两元素和/差" → 对撞（可排序化 → 对撞）
  "原地修改/去重/移除" → 快慢（读写指针）
  "连续区间 + 条件" → 滑动窗口
```

> 🎯 **核心认知**："双指针的本质是**用 O(1) 空间替代 O(n) 辅助结构**——对撞指针利用有序性剪枝，快慢指针利用职责分工完成原地修改。能写出 O(n)/O(1) 的双指针解，就是面试的及格线。"

## 2. 对撞指针：167 两数之和 II

### 2.1 题目与思路

**题**：有序数组找两数之和 = target（O(n) 要求）。

**对撞剪枝**：两数和 < target → 左指针右移（和变大）；> target → 右指针左移（和变小）：

```java
/**
 * LeetCode 167. 两数之和 II（有序数组）
 * 时间 O(n)，空间 O(1)
 */
public int[] twoSum(int[] numbers, int target) {
    int left = 0, right = numbers.length - 1;
    while (left < right) {
        int sum = numbers[left] + numbers[right];
        if (sum == target) return new int[]{left + 1, right + 1};
        else if (sum < target) left++;    // ① 和太小 → 左移变大
        else right--;                     // ② 和太大 → 右移变小
    }
    return new int[]{-1, -1};
}
// 推演 [2,7,11,15]，target=9：
//   (2+15)=17>9 → right-- → (2+11)=13>9 → right--
//   (2+7)=9 ✓ → [1,2]
// ⚠️ 正确性: 每步排除一行/一列（矩阵视角）——不会漏解
```

> 💡 **正确性直觉**："两数之和的对撞 = **在虚拟矩阵中排除行/列**——(left, right) 和大于 target 时，right 右侧所有组合都更大，整列排除；小于时 left 左侧整行排除。每步排除一行一列 → O(n)。"

## 3. 对撞指针：11 盛最多水的容器

### 3.1 题目与思路

**题**：两根柱子之间盛水面积 = min(h[l], h[r]) × (r−l) 最大化。

**贪心剪枝**：面积被短边限制——**移动短边**（可能遇到更高的柱子），移动长边面积只减不增：

```java
/**
 * LeetCode 11. 盛最多水的容器
 * 时间 O(n)，空间 O(1)
 * ⚠️ 核心: 总是移动短边——长边移动后面积必然更小
 */
public int maxArea(int[] height) {
    int left = 0, right = height.length - 1, best = 0;
    while (left < right) {
        int area = Math.min(height[left], height[right]) * (right - left);
        best = Math.max(best, area);
        // 移动短边（关键剪枝！）
        if (height[left] < height[right]) left++;
        else right--;
    }
    return best;
}
// 推演 [1,8,6,2,5,4,8,3,7]：答案 49（8 与 7 之间）
// ⚠️ 正确性: 短边若不动，面积永远被它限制 → 移动短边不丢最优解
```

## 4. 对撞指针：42 接雨水（O(1) 空间）

### 4.1 题目与思路

**题**：柱子间能接多少雨水。

**三解法递进**：

```text
① 暴力: 每个位置 min(左最大, 右最大) − height → O(n²)
② 前后缀数组: 预计算 leftMax/rightMax → O(n)/O(n)
③ 对撞指针: 边走边维护两边最大 → O(n)/O(1) ⭐ 最优
```

### 4.2 对撞版完整代码

```java
/**
 * LeetCode 42. 接雨水（对撞指针版）
 * 时间 O(n)，空间 O(1)
 * ⚠️ 核心: 哪边 max 小，哪边的水位就被它决定 → 处理那边
 */
public int trap(int[] height) {
    int left = 0, right = height.length - 1;
    int leftMax = 0, rightMax = 0, water = 0;
    while (left < right) {
        leftMax = Math.max(leftMax, height[left]);    // ① 更新左最大
        rightMax = Math.max(rightMax, height[right]); // ② 更新右最大
        if (leftMax < rightMax) {                     // ③ 左水位被左最大决定
            water += leftMax - height[left];          //    接水量 = 水位 − 柱子
            left++;
        } else {
            water += rightMax - height[right];
            right--;
        }
    }
    return water;
}
// 推演 [0,1,0,2,1,0,1,3,2,1,2,1]：答案 6（经典教材例）
```

> 🎯 **对撞指针的本质**："对撞指针 = **利用'两侧边界信息'逐步收缩**——接雨水中 leftMax < rightMax 时，left 位置的水位已被 leftMax 决定（右边再高也帮不上忙），可以放心结算。**'哪边确定就处理哪边'是对撞题的通法**。"

## 5. 对撞指针：15 三数之和（去重三连）

### 5.1 题目与思路

**题**：数组中三个数和 = 0（不重复三元组）。

**套路**：排序（可对撞的前提）→ 固定一个 → 剩下用对撞指针 → **去重三连**：

```java
/**
 * LeetCode 15. 三数之和
 * 时间 O(n²)（排序 O(n log n) + n 轮对撞 O(n)），空间 O(1) 额外
 */
public List<List<Integer>> threeSum(int[] nums) {
    Arrays.sort(nums);                        // ① 排序（对撞的前提）
    List<List<Integer>> result = new ArrayList<>();
    for (int i = 0; i < nums.length - 2; i++) {
        if (i > 0 && nums[i] == nums[i - 1]) continue;  // ② 去重一: 固定位
        int left = i + 1, right = nums.length - 1;
        while (left < right) {
            int sum = nums[i] + nums[left] + nums[right];
            if (sum == 0) {
                result.add(Arrays.asList(nums[i], nums[left], nums[right]));
                while (left < right && nums[left] == nums[left + 1]) left++;   // ③ 去重二: 左指针
                while (left < right && nums[right] == nums[right - 1]) right--;// ④ 去重三: 右指针
                left++; right--;
            } else if (sum < 0) left++;
            else right--;
        }
    }
    return result;
}
// 推演 [-1,0,1,2,-1,-4]：排序后 [-4,-1,-1,0,1,2] → 结果 [[-1,-1,2],[-1,0,1]]
```

> 💡 **去重三连口诀**："**固定位去重（与前一个相同跳过）+ 左指针去重 + 右指针去重**"——三个去重缺一不可，漏掉任何一环就出重复三元组。这是 15 题最大的失分点。

## 6. 快慢指针：283 移动零与 26/80 去重模板

### 6.1 283 移动零（快慢 = 读写指针）

```java
/**
 * LeetCode 283. 移动零
 * 快慢指针（读写指针）: slow 指向下一个非零应放的位置
 * 时间 O(n)，空间 O(1)，稳定（非零相对顺序保持）
 */
public void moveZeroes(int[] nums) {
    int slow = 0;                                 // 写指针
    for (int fast = 0; fast < nums.length; fast++) {   // 读指针
        if (nums[fast] != 0) {
            int tmp = nums[slow]; nums[slow] = nums[fast]; nums[fast] = tmp;
            slow++;
        }
    }
}
// 推演 [0,1,0,3,12]：fast=1 → 换(0,1) → [1,0,0,3,12]；fast=3 → 换(1,3) → [1,3,0,0,12]；fast=4 → 换(2,4) → [1,3,12,0,0] ✓
```

### 6.2 26/80 去重模板（通用：允许保留 k 个）

```java
/**
 * LeetCode 80. 删除有序数组中的重复项 II（通用模板: 允许保留 k 个）
 * LeetCode 26 是 k=1 的特例
 * 时间 O(n)，空间 O(1)
 */
public int removeDuplicates(int[] nums) {
    int k = 2;                                   // ① 允许保留 k 个
    int write = 0;                               // ② 写指针
    for (int read = 0; read < nums.length; read++) {
        // ③ 前 k 个直接写；之后"与 k 步前的不同"才写
        if (write < k || nums[read] != nums[write - k]) {
            nums[write++] = nums[read];
        }
    }
    return write;                                // ④ 新长度
}
// 推演 [1,1,1,2,2,3]，k=2：
//   read=0,1 直接写 → [1,1,...]；read=2(1) vs nums[0](1) 相同 → 跳过
//   read=3(2) vs nums[1](1) 不同 → 写 → [1,1,2,...]；read=4(2) vs nums[2](2)? 不同 → 写
//   read=5(3) vs nums[3](2) 不同 → 写 → 长度 5 ✓
```

> 🎯 **通用模板的威力**："**`nums[read] != nums[write−k]` 一行同时解决 26（k=1）与 80（k=2）**——把'与前一个比'推广为'与 k 步前比'，就是去重题的通用解。记住这个模板，去重家族全部拿下。"

## 7. 识别信号与手写易错点

### 7.1 识别信号表

| 信号 | 模式 | 代表题 |
|------|------|------|
| 有序数组 + 找两元素 | 对撞 | 167、15 |
| 两端向中间（容器/回文/反转） | 对撞 | 11、42、344 |
| 原地修改/去重/移除 | 快慢（读写） | 283、26、27、80 |
| 链表环/中点/倒数第 K | 快慢 | 141、19 |
| 连续区间 + 条件 | 滑动窗口（02 文件） | 3、76、209 |

### 7.2 手写易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 对撞循环条件 `<=` | `left < right` | 越界/重复处理 |
| 2 | 移动短边写成移动长边 | 11 题移动短边 | 剪枝失效（结果仍对但 O(n²) 思路） |
| 3 | 15 题漏去重 | 去重三连 | 结果重复 |
| 4 | 快慢指针忘了先判空 | 链表 `fast != null && fast.next != null` | 空指针异常 |
| 5 | 80 题比较对象错 | `nums[read] != nums[write−k]` | 去重逻辑错 |
| 6 | 283 交换写成覆盖 | 交换（保顺序） | 非零顺序被打乱 |

> 🎯 **核心要点**：双指针通关四件事——**① 三种模式脱口而出**（对撞/快慢/滑动窗口）与识别信号；**② 对撞五题全会**（167 矩阵排除视角、11 移动短边、42 哪边确定处理哪边、15 去重三连）；**③ 快慢读写模板烂熟**（283 交换、26/80 的 `write−k` 一行通杀）；**④ 复杂度永远是 O(n)/O(1)**。**"两元素关系用对撞、原地修改用快慢"是数组题的万能起点**。
