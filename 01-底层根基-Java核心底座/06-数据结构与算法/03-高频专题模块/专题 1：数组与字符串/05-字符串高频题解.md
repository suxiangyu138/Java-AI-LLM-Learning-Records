## 1. 344 反转字符串与 151 反转单词（反转系列）

### 1.1 344 反转字符串（对撞指针）

```java
/**
 * LeetCode 344. 反转字符串（原地）
 * 对撞指针: 首尾交换直到相遇
 * 时间 O(n)，空间 O(1)
 */
public void reverseString(char[] s) {
    int left = 0, right = s.length - 1;
    while (left < right) {
        char tmp = s[left]; s[left] = s[right]; s[right] = tmp;
        left++; right--;
    }
}
```

### 1.2 151 反转字符串中的单词（三次反转思想）

```java
/**
 * LeetCode 151. 反转字符串中的单词
 * 思路: 去多余空格 → 整体反转 → 逐词反转（189 的三次反转思想）
 * 时间 O(n)，空间 O(n)（不可变字符串）
 */
public String reverseWords(String s) {
    // ① 按空白切分并逆序拼接（简单版；进阶版用"整体反转 + 逐词反转"）
    String[] words = s.trim().split("\\s+");
    StringBuilder sb = new StringBuilder();
    for (int i = words.length - 1; i >= 0; i--) {
        sb.append(words[i]);
        if (i > 0) sb.append(" ");
    }
    return sb.toString();
}
// 推演 "  the sky  is blue " → ["the","sky","is","blue"] → "blue is sky the" ✓
// ⚠️ 进阶（O(1) 空间，可变字符数组）: 三次反转——
//   去空格 → 整体反转 → 逐词反转（与 189 轮转数组同款）
```

> 🎯 **反转系列通法**："**'整体反转 + 局部反转'是反转题的万能两步**——189 轮转数组、151 反转单词、186 反转单词 II 全部同构。会一个就会三个。"

### 2.2 242 有效字母异位词（计数数组）

```java
/**
 * LeetCode 242. 有效的字母异位词
 * 字符计数数组: 一个加、一个减，最终全为 0
 * 时间 O(n)，空间 O(1)（26 槽位）
 */
public boolean isAnagram(String s, String t) {
    if (s.length() != t.length()) return false;
    int[] count = new int[26];
    for (int i = 0; i < s.length(); i++) {
        count[s.charAt(i) - 'a']++;            // ① s 加
        count[t.charAt(i) - 'a']--;            // ② t 减
    }
    for (int c : count) if (c != 0) return false;   // ③ 全零 = 异位词
    return true;
}
// ⚠️ 为什么不用 HashMap: 字符集固定 26 → 数组 O(1) 空间、
//   访问比哈希快 5-10 倍 → 字符串题的默认武器
```

> 💡 **计数数组 vs 哈希表**："**字符集有限（26/128/256）时永远优先计数数组**——O(1) 空间、缓存友好、无装箱开销。异位词家族四题的公共武器就是它。"

## 3. 125 验证回文与 5 最长回文子串（回文双解法）

### 3.1 125 验证回文（对撞指针）

```java
/**
 * LeetCode 125. 验证回文串（忽略大小写与非字母数字）
 * 对撞指针: 跳过非字母数字，首尾比较
 * 时间 O(n)，空间 O(1)
 */
public boolean isPalindrome(String s) {
    int left = 0, right = s.length() - 1;
    while (left < right) {
        while (left < right && !Character.isLetterOrDigit(s.charAt(left))) left++;
        while (left < right && !Character.isLetterOrDigit(s.charAt(right))) right--;
        if (Character.toLowerCase(s.charAt(left)) !=
            Character.toLowerCase(s.charAt(right))) return false;
        left++; right--;
    }
    return true;
}
```

### 3.2 5 最长回文子串（中心扩展）

```java
/**
 * LeetCode 5. 最长回文子串（中心扩展）
 * 每个位置（及相邻对）向两边扩展，奇偶两种中心
 * 时间 O(n²)，空间 O(1)
 */
public String longestPalindrome(String s) {
    int start = 0, maxLen = 0;
    for (int i = 0; i < s.length(); i++) {
        // ① 奇数中心（单字符）
        int len1 = expand(s, i, i);
        // ② 偶数中心（相邻对）
        int len2 = expand(s, i, i + 1);
        int len = Math.max(len1, len2);
        if (len > maxLen) {
            maxLen = len;
            start = i - (len - 1) / 2;        // ③ 由长度反推起点
        }
    }
    return s.substring(start, start + maxLen);
}

private int expand(String s, int left, int right) {
    while (left >= 0 && right < s.length()
           && s.charAt(left) == s.charAt(right)) {
        left--; right++;
    }
    return right - left - 1;                  // 回文长度
}
// 推演 "babad"：中心 b → "bab"（3）→ 答案 "bab" ✓
// ⚠️ 进阶: Manacher 算法 O(n)（面试提及即可，手撕不要求）
```

> 🎯 **回文双解法**："**验证用对撞（O(n)/O(1)），找最长用中心扩展（O(n²)）**——中心扩展的'奇偶双中心'是必背细节；Manacher O(n) 知道存在即可。"

## 5. 28 字符串匹配（KMP 思想）

### 5.1 题目与思路

**题**：在 haystack 中找 needle 首次出现的位置。

**KMP 核心**：**失配时利用已匹配部分的前后缀信息跳跃**——next 数组是灵魂：

```java
/**
 * LeetCode 28. 找出字符串中第一个匹配项的下标（KMP）
 * 时间 O(n + m)，空间 O(m)
 * ⚠️ 核心: next[i] = 子串 s[0..i] 的最长相等前后缀长度
 */
public int strStr(String haystack, String needle) {
    int[] next = buildNext(needle);            // ① 构建 next 数组
    int j = 0;                                 // ② 模式串指针
    for (int i = 0; i < haystack.length(); i++) {
        while (j > 0 && haystack.charAt(i) != needle.charAt(j)) {
            j = next[j - 1];                   // ③ 失配回退到最长前缀后
        }
        if (haystack.charAt(i) == needle.charAt(j)) j++;
        if (j == needle.length()) return i - j + 1;   // ④ 匹配完成
    }
    return -1;
}

private int[] buildNext(String p) {
    int[] next = new int[p.length()];
    int j = 0;                                 // 当前最长前后缀长度
    for (int i = 1; i < p.length(); i++) {
        while (j > 0 && p.charAt(i) != p.charAt(j)) j = next[j - 1];
        if (p.charAt(i) == p.charAt(j)) j++;
        next[i] = j;
    }
    return next;
}
// 推演 haystack="sadbutsad", needle="sad"：首位置 0 ✓
// ⚠️ KMP 的意义: 朴素匹配 O(n·m) → KMP O(n+m)——
//   失配时主串指针不回退（i 只前进），回退的是模式串
```

> 🎯 **KMP 面试定位**："**KMP 的面试地位 = '理解思想 + 能说清 next 语义'**——手撕完整 KMP 的概率低，但'为什么主串指针不回退'是高频追问。next 数组的构建（模式串自我匹配）是理解门槛，讲清楚'失配回退到最长公共前后缀'就过了。"

## 6. 13/12 罗马数字转换与 8 字符串转整数

### 6.1 13 罗马数字转整数（特殊规则）

```java
/**
 * LeetCode 13. 罗马数字转整数
 * 核心: 小数在大数前 = 相减（IV=4），否则相加
 * 时间 O(n)，空间 O(1)
 */
public int romanToInt(String s) {
    Map<Character, Integer> map = Map.of(
        'I', 1, 'V', 5, 'X', 10, 'L', 50, 'C', 100, 'D', 500, 'M', 1000);
    int result = 0;
    for (int i = 0; i < s.length(); i++) {
        int cur = map.get(s.charAt(i));
        if (i + 1 < s.length() && cur < map.get(s.charAt(i + 1))) {
            result -= cur;                     // ① 小数在前 → 减
        } else {
            result += cur;                     // ② 否则加
        }
    }
    return result;
}
// 推演 "MCMXCIV"：M=1000, C<M → -100, M=1000, X<C → -10, C=100, I<V → -1, V=5
//   → 1000−100+1000−10+100−1+5 = 1994 ✓
```

### 6.2 8 字符串转换整数（atoi，边界四连）

```java
/**
 * LeetCode 8. 字符串转换整数（atoi）
 * 边界四连: 前导空格 → 符号 → 数字 → 溢出截断
 */
public int myAtoi(String s) {
    int i = 0, n = s.length(), sign = 1, result = 0;
    while (i < n && s.charAt(i) == ' ') i++;          // ① 前导空格
    if (i < n && (s.charAt(i) == '+' || s.charAt(i) == '-')) {
        sign = (s.charAt(i) == '-') ? -1 : 1;         // ② 符号
        i++;
    }
    while (i < n && Character.isDigit(s.charAt(i))) { // ③ 数字
        int digit = s.charAt(i) - '0';
        if (result > (Integer.MAX_VALUE - digit) / 10) {   // ④ 溢出检查
            return sign == 1 ? Integer.MAX_VALUE : Integer.MIN_VALUE;
        }
        result = result * 10 + digit;
        i++;
    }
    return result * sign;
}
// ⚠️ 溢出检查的写法: result > (MAX − digit) / 10 提前判定，
//   避免 result*10+digit 本身溢出（面试必考边界）
```
