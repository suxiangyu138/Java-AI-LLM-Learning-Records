## 1. 前缀和模型：区间和的 O(1) 查询

```text
前缀和数组: prefix[i] = nums[0] + nums[1] + … + nums[i−1]（前 i 个和）

区间和查询: sum(l, r) = prefix[r+1] − prefix[l]   → O(1)
  例: prefix = [0, 2, 5, 9, 12]（nums = [2,3,4,3]）
      sum(1,2) = prefix[3] − prefix[1] = 9 − 2 = 7 ✓

为什么比滑动窗口强:
  滑动窗口的和只能"单向变化"（加右减左，且依赖单调性）
  前缀和可增可减、支持任意区间查询 → 更通用

识别信号:
  "连续子数组和 = K" / "区间和查询" / "二维矩阵区域和"
```

> 🎯 **核心动作三连**：**预处理（prefix 数组 O(n)）→ 公式查询（prefix[r+1] − prefix[l]）→ 组合优化（+ 哈希表把 O(n²) 降到 O(n)）**。前缀和的真正威力不在"查询"，而在"**用哈希表记录历史前缀和**"——这是 560 的灵魂。

## 2. 303 区域和检索（基础）

```java
/**
 * LeetCode 303. 区域和检索
 * 预处理 O(n)，每次查询 O(1)
 */
class NumArray {
    private final int[] prefix;               // prefix[i] = 前 i 个元素和

    public NumArray(int[] nums) {
        prefix = new int[nums.length + 1];    // ① 长度 +1（prefix[0]=0 哨兵）
        for (int i = 0; i < nums.length; i++) {
            prefix[i + 1] = prefix[i] + nums[i];
        }
    }

    public int sumRange(int left, int right) {
        return prefix[right + 1] - prefix[left];   // ② O(1) 区间和
    }
}
// ⚠️ prefix[0]=0 哨兵: 让"从头开始"的区间统一公式，免去特判
```

> 💡 **哨兵细节**："prefix 长度 = n+1 且 prefix[0]=0——**这个哨兵让 sumRange(0, r) 不用特判**，是前缀和实现的标准写法。"

## 3. 560 和为 K 的子数组（前缀和 + 哈希，必会）

### 3.1 题目与思路

**题**：连续子数组和为 K 的个数（O(n)）。

**核心转化**：`sum(l, r) = K ⇔ prefix[r+1] − prefix[l] = K ⇔ prefix[l] = prefix[r+1] − K`

→ **遍历前缀和时，用哈希表记录"每种前缀和出现了几次"，每次查"当前前缀和 − K"在历史上出现过几次**：

```java
/**
 * LeetCode 560. 和为 K 的子数组
 * 前缀和 + 哈希表: 把"区间和 = K"转化为"历史前缀和 = 当前 − K"
 * 时间 O(n)，空间 O(n)
 */
public int subarraySum(int[] nums, int k) {
    Map<Integer, Integer> seen = new HashMap<>();
    seen.put(0, 1);                          // ① 哨兵: 空前缀和 = 0 出现 1 次
    int sum = 0, count = 0;

    for (int x : nums) {
        sum += x;                            // ② 当前前缀和
        count += seen.getOrDefault(sum - k, 0);   // ③ 查"补差"出现次数
        seen.merge(sum, 1, Integer::sum);    // ④ 记录当前前缀和
    }
    return count;
}
// 推演 [1,1,1]，k=2：
//   sum=1: seen 查 -1 → 0；记录 1:1 → {0:1, 1:1}
//   sum=2: 查 0 → 1 次 ✓；记录 2:1
//   sum=3: 查 1 → 1 次 ✓ → 总数 2 ✓（[1,1] × 2）
```

### 3.2 为什么"查历史"是对的

```text
sum(l, r) = K ⇔ prefix[r+1] − prefix[l] = K
  ⇔ prefix[l] = prefix[r+1] − K

固定 r: 所有满足条件的左端点 l 就是"历史上前缀和 = prefix[r+1] − K 的位置"
  → 数一数历史上出现过几次，就累加几个子数组
  → O(n) 而非 O(n²)（双循环枚举 l,r 是 O(n²)）

⚠️ 边界: 为什么 seen.put(0, 1)?
  l = 0 时 prefix[l] = 0——从头开始的子数组也要被统计
```

> 🎯 **560 的面试价值**："**'区间和 = K' → '前缀和之差 = K' → '查历史前缀和'**是前缀和+哈希的标准三步——560 会了，同族题（525 连续数组、974 可被 K 整除、523 连续子数组和）全部套同一个模板。"

## 4. 238 除自身以外数组的乘积（前后缀）

### 4.1 题目与思路

**题**：每个位置 = 除自己外所有元素乘积（**禁止除法**，O(1) 额外空间）。

**前后缀乘积**：答案[i] = 左边乘积 × 右边乘积，两次遍历：

```java
/**
 * LeetCode 238. 除自身以外数组的乘积
 * 时间 O(n)，空间 O(1) 额外（输出数组不算）
 * ⚠️ 禁止除法: 0 的存在让"总积 ÷ 自己"失效
 */
public int[] productExceptSelf(int[] nums) {
    int n = nums.length;
    int[] result = new int[n];

    // ① 第一遍: result[i] = 左侧所有元素乘积
    result[0] = 1;
    for (int i = 1; i < n; i++) {
        result[i] = result[i - 1] * nums[i - 1];
    }

    // ② 第二遍: 从右往左累积右侧乘积，边乘边写
    int rightProduct = 1;
    for (int i = n - 1; i >= 0; i--) {
        result[i] *= rightProduct;         // 左积 × 右积
        rightProduct *= nums[i];           // 累积右侧乘积
    }
    return result;
}
// 推演 [1,2,3,4]：
//   第一遍: result = [1, 1, 2, 6]（左积）
//   第二遍: i=3: 6×1=6；right=4；i=2: 2×4=8；right=12
//           i=1: 1×12=12；right=24；i=0: 1×24=24 → [24,12,8,6] ✓
```

> 💡 **"禁止除法"的考点**："238 禁用除法是刻意的——**0 的除法无定义，且'总积/自己'无法处理多个 0**。前后缀两次遍历是标准解；'左积 × 右积'用输出数组当左积容器 → O(1) 额外空间。"

## 5. 哈希映射三技巧：查找/计数/去重

### 5.1 技巧一：查找加速（1 两数之和）

```java
/**
 * LeetCode 1. 两数之和（无序数组）
 * 哈希表: 值 → 下标，边遍历边查补差
 * 时间 O(n)，空间 O(n)
 */
public int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> index = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        int complement = target - nums[i];
        if (index.containsKey(complement)) {        // ① 查补差
            return new int[]{index.get(complement), i};
        }
        index.put(nums[i], i);                      // ② 边遍历边记录
    }
    return new int[]{-1, -1};
}
// ⚠️ 无序数组不能对撞 → 哈希是唯一 O(n) 方案
//   （有序数组 → 对撞 O(1) 空间，见 01 文件 167）
```

### 5.2 技巧二：计数分组（49 字母异位词分组）

```java
/**
 * LeetCode 49. 字母异位词分组
 * 排序/计数归一化: 异位词 → 相同键
 * 时间 O(n·L·logL)（排序键）或 O(n·L)（计数键），空间 O(n·L)
 */
public List<List<String>> groupAnagrams(String[] strs) {
    Map<String, List<String>> groups = new HashMap<>();
    for (String s : strs) {
        char[] count = new char[26];               // ① 计数归一化
        for (char c : s.toCharArray()) count[c - 'a']++;
        String key = new String(count);            // ② 异位词同键
        groups.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
    }
    return new ArrayList<>(groups.values());
}
// 推演 ["eat","tea","tan","ate","nat","bat"]：
//   "eat"/"tea"/"ate" → 计数键相同 → 同组 ✓
```

### 5.3 技巧三：去重计数（128 最长连续序列）

```java
/**
 * LeetCode 128. 最长连续序列（O(n) 要求）
 * HashSet 去重 + 只从"序列起点"开始扩展
 * 时间 O(n)（每个元素最多进出一次），空间 O(n)
 */
public int longestConsecutive(int[] nums) {
    Set<Integer> set = new HashSet<>();
    for (int x : nums) set.add(x);

    int best = 0;
    for (int x : set) {
        if (set.contains(x - 1)) continue;         // ① 不是起点 → 跳过
        int len = 1;
        while (set.contains(x + len)) len++;       // ② 只从起点扩展
        best = Math.max(best, len);
    }
    return best;
}
// 推演 [100,4,200,1,3,2]：起点 1 → 1,2,3,4 → 4 ✓（100/200 孤立）
// ⚠️ O(n) 的魔法: 非起点直接跳过——总扩展次数 = 总序列长度
```

> 🎯 **哈希三技巧**："**查找用'边遍历边记录'（1）、计数用'归一化键'（49）、去重用'起点剪枝'（128）**——哈希不是工具，是三种思维模式。"

## 6. 前缀和 vs 滑动窗口：选型对比

| 维度 | 滑动窗口 | 前缀和 |
|------|:---:|:---:|
| 适用 | 窗口条件"单向变化"（和只能增/减） | 任意区间查询（可增可减） |
| 状态 | 实时窗口（和/计数/匹配） | 历史前缀（数组/哈希记录） |
| 复杂度 | O(n) + O(1)/O(字符集) 空间 | O(n) 预处理 + O(n) 哈希空间 |
| 代表题 | 3/76/209/438 | 303/560/238/525 |
| 反面信号 | 窗口和"可增可减"（如负数）→ 窗口失效 | 条件依赖单调性 → 前缀和替代 |

```text
选型口诀:
  "和单调变化 → 滑动窗口；和任意变化 → 前缀和；
   要查'出现次数' → 前缀和 + 哈希表"
  ⚠️ 典型陷阱: 560 若数组含负数，滑动窗口立刻失效
     （窗口和不再单调）→ 必须前缀和 + 哈希
```

## 7. 手写易错点与高频变体

### 7.1 易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 560 忘 `put(0, 1)` | 哨兵初始化 | 漏掉从头开始的子数组 |
| 2 | 560 先查后记顺序反 | 先查补差、再记录当前 | 重复计数自己 |
| 3 | 238 第二遍顺序错 | 先写 result 再累积 right | 右侧乘积错位 |
| 4 | 303 长度不加 1 | `prefix[0]=0` 哨兵 | 区间公式越界 |
| 5 | 128 遍历原数组 | 遍历 set（去重后） | 重复扩展浪费 |
| 6 | 49 用排序键 | 计数键（O(L) vs O(L log L)） | 常数更大 |

### 7.2 高频变体（同一模板家族）

| 题 | 变形 | 模板 |
|:---:|------|------|
| 525 连续数组 | 0/1 数组，和 = 0 最长 | 前缀和 + 哈希（记录最早位置） |
| 974 和可被 K 整除 | 前缀和 mod K 计数 | 前缀和 + 哈希（取模键） |
| 523 连续子数组和 | 倍数 K 且长度 ≥ 2 | 前缀和 mod + 位置差 |
| 304 二维区域和 | 二维前缀和（容斥） | prefix 二维 + 公式 |
| 437 路径总和 III | 树上前缀和 | 前缀和 + 哈希（DFS 回溯） |

> 🎯 **核心要点**：前缀和与哈希通关四件事——**① 560 三步转化烂熟**（区间和 = K → 前缀差 = K → 查历史）；**② 238 前后缀两次遍历**（左积 × 右积，O(1) 空间）；**③ 哈希三技巧**（查找/归一化键/起点剪枝）；**④ 选型判断**（和单调用窗口、任意变化用前缀和+哈希）。**前缀和+哈希是"把 O(n²) 区间枚举降到 O(n)"的通用引擎**——560 家族五连题一个模板全吃。
