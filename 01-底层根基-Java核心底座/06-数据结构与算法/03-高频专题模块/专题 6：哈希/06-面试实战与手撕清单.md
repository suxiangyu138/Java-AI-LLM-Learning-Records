## 3. HashMap 八股十问（Java 后端必背）

| # | 追问 | 标准回答 |
|:---:|------|---------|
| 1 | 底层结构？ | JDK8: 数组 + 链表 + 红黑树（链表 ≥8 且容量 ≥64 树化） |
| 2 | 为什么 2 的幂？ | 位运算替代取模 + n−1 低位全 1 分布均匀 + 扩容高低链拆分 |
| 3 | 扰动函数？ | `h ^ (h >>> 16)`——高位混入低位，降冲突概率 |
| 4 | 为什么 0.75？ | 时间与空间的折中；泊松分布下桶内分布最优 |
| 5 | 为什么树化 8/退化 6？ | 泊松概率千万分之六（防哈希洪水）；6-8 缓冲防抖动；容量 <64 先扩容 |
| 6 | 扩容机制？ | size > threshold（容量×0.75）→ 翻倍；`hash & oldCap` 拆高低链免重算 |
| 7 | JDK7 vs JDK8？ | 头插→尾插（修死循环）；链表→红黑树（修 O(n)）；高低链（修扩容） |
| 8 | 线程安全？ | JDK8 只修死循环，仍覆盖丢数据；并发用 ConcurrentHashMap（CAS+锁单桶） |
| 9 | 自定义 key？ | equals + hashCode 一起重写且一致；用不可变类；字段别改 |
| 10 | 性能？ | 平均 O(1)，最坏 O(log n)（树化）/O(n)（无树化）；O(1) 是期望非绝对 |

```text
八股主线背诵:
  "数组定位 → 冲突处理（拉链/树化）→ 扩容迁移（高低链）
   → 极端优化（扰动/树化防洪水）——四件事决定 HashMap 性能"
```

## 4. 话术模板与复杂度速答

### 4.1 通用话术模板

```text
"这题是哈希【用法】题——【识别信号】。
方案: 【模板】。时间 O(【复杂度】)，空间 O(【复杂度】）。
（写完）验证样例；边界: 空/重复/自配对。
（主动引出）"这里用哈希 O(1) 查找——Java HashMap 底层
 是数组 + 链表 + 红黑树……""

例: "哈希查找题——无序找两数。边遍历边记录，先查后记防自配对。
    O(n)/O(n)。顺带一提 HashMap 的扰动函数……"
```

### 4.2 复杂度速答表

| 用法 | 时间 | 空间 | 关键 |
|------|:---:|:---:|------|
| 查找（1） | O(n) | O(n) | 先查后记 |
| 计数（242/347） | O(n) | O(26)/O(n) | 数组 vs 哈希 |
| 去重（128） | O(n) | O(n) | 起点剪枝 |
| 前缀和（560） | O(n) | O(n) | 先查后加 + 哨兵 |
| 组合（146） | O(1) 全操作 | O(cap) | 哈希 + 双向链表 |
| 手写哈希表 | 平均 O(1) | O(n) | 链地址 + 扩容 |

## 5. 面试实战演练：三道真题全程

### 5.1 真题一：两数之和（母题 + 八股引出）

```text
面试过程示范:
  ① 定位: "无序找两数 → 哈希边遍历边记录，O(n)"
  ② 手撕: 1 题模板（先查补差 → 记当下）
  ③ 边界: [3], target=6 —— "先查后记防止自己配自己"
  ④ 八股引出: "哈希 O(1) 查找依赖好的哈希函数——
     Java HashMap 用扰动函数 + 2 的幂容量……"
  ⑤ 追问: "有序数组怎么办？" → 对撞指针 O(1) 空间（专题 1）
```

### 5.2 真题二：和为 K 的子数组（前缀和 + 哈希）

```text
面试过程示范:
  ① 定位: "区间和 = K → 前缀和 + 哈希，O(n)"
  ② 转化: "sum(l,r)=K ⇔ prefix[l] = prefix[r+1]−K——查历史"
  ③ 手撕: 560 模板（哨兵 put(0,1) + 先查后加）
  ④ 陷阱: "k=0 时必须先查后加，否则自配对答案偏大"
  ⑤ 追问: "525 变体？" → 0 记 −1、记录最早位置（记位置 vs 记次数）
```

### 5.3 真题三：LRU 缓存（组合设计 + 八股）

```text
面试过程示范:
  ① 选型: "哈希查找 O(1) + 双向链表删除 O(1) + 哨兵免边界"
  ② 手撕: 146 完整类（Node + map + head/tail + 四操作）
  ③ 边界: 容量 1 / 更新已存在 key / 超容淘汰
  ④ 追问: "为什么双向？" → 删任意节点 O(1) 需要前驱
  ⑤ 追问: "LinkedHashMap 实现？" → accessOrder=true +
     removeEldestEntry——"先手写再提内置，展示两层理解"
```

> 🎯 **核心要点**：面试实战通关 = **双线备考（四用法 + 八股主线）+ 15 题清单 + 八股十问 + 三场演练（母题/前缀和/LRU）**。哈希专题的完整体验是"**手撕题答出 O(1) 思维，八股题讲出'为什么'**"——算法线练到肌肉记忆，八股线背到脱口而出，Java 后端的哈希就圆满了。
