## 4. 核心概念速查

| 概念 | 一句话解释 | 说明 |
|------|-----------|------|
| **DFS** | 一条路走到黑再回头 | 递归/栈实现 |
| **前/中/后序** | 处理时机不同（前/中/后） | 二叉树专属 |
| **方向数组** | 四方向 {{1,0},...} | 网格 DFS 的邻域 |
| **沉岛** | grid[i][j]='2' 原地标记 | 免 visited 数组 |
| **flood fill** | 洪水填充（连通块染色） | 岛屿系列核心 |
| **visited** | 访问标记防重复/死循环 | 图/网格必需，树不需要 |
| **环检测** | 判断图是否有环 | 有向/无向两种 |
| **拓扑排序** | 无环图的线性序 | Kahn（BFS）/DFS 两版 |
| **染色法** | 相邻异色判定二分图 | 785 |
| **显式栈** | 迭代 DFS（防栈溢出） | 深树/大图 |

### 5.2 识别信号（DFS vs BFS）

```text
"所有方案/是否存在路径/连通块大小" → DFS
"最少几步/最短路径/扩散" → BFS
"遍历所有节点" → 两者皆可
"路径天然在递归栈里" → DFS（枚举路径）

⚠️ 判断口诀:
  "枚举所有 → DFS；求最短 → BFS"
```

> 🎯 **一句话定位**："**DFS = '一条路走到黑'的递归搜索——树/网格/图三大载体 + 遍历/路径/连通/拓扑四大任务**。一套'处理当前 → 递归子问题 → 整合结果'的框架通吃全部，差异只在'相邻节点怎么找'和'要不要 visited'。"

## 6. 常见误区速查

| 误区 | 正解 |
|------|------|
| "树 DFS 也要 visited" | ❌ 树天然无环——不需要标记；图/网格才需要 |
| "先递归再标记当前" | ❌ 标记必须**前置**——否则相邻格子来回递归死循环 |
| "网格先访问再判越界" | ❌ 先判越界再访问数组（越界检查前置） |
| "无向图不需要防回父" | ❌ 必须传 parent 参数或标记——否则父子来回走 |
| "DFS 求最短路径" | ❌ 求最短步数用 BFS（首次到达即最短）；DFS 会绕远 |
| "拓扑排序只能 BFS" | ❌ Kahn（BFS）与 DFS 后序反转两版都行 |
| "递归深度无所谓" | ❌ 深树/大图栈溢出——改显式栈（迭代 DFS） |
| "岛屿计数重复数" | ❌ 每座岛只计一次——DFS 后整岛沉掉 |
| "递归和迭代 DFS 一样简单" | ❌ 迭代要显式栈 + 入栈顺序注意（前序好写，中序难） |
| "DFS 复杂度 O(N)" | ❌ 树 O(N)/O(H)（H 最坏 N）；图 O(V+E)；矩阵 O(mn) |
