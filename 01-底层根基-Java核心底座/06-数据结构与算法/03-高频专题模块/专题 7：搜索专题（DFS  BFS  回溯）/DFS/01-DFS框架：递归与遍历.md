## 1. DFS 模型：一条路走到黑

```text
DFS（深度优先搜索）:
  访问一个节点 → 立即递归第一个未访问邻居
  → 一路深入直到无法继续 → 回溯到上一节点继续其他分支

实现: 递归（系统栈）或显式栈（迭代）
直觉: 走迷宫——一条道走到黑，撞墙回头换路

适用场景（识别信号）:
  "所有方案 / 是否存在路径 / 连通块大小" → DFS
  "路径天然在递归栈里"（枚举路径时 DFS 最顺手）

⚠️ 与 BFS 的分工:
  DFS: 枚举所有 / 连通性（递归栈天然保存路径）
  BFS: 最短步数（按层推进，首次到达即最短）
```

> 🎯 **核心认知**："**DFS 的灵魂是'递归栈即路径'——走到哪、路径就在栈里**。这就是'枚举所有路径'类题选 DFS 的根本原因；而 BFS 的队列不保存路径，只保距离。"

## 2. 通用框架（2 分钟默写）

### 2.1 三段式框架

```java
/**
 * DFS 通用框架（树/网格/图通吃）: 处理当前 → 递归子问题 → 整合结果
 */
void dfs(节点, 状态) {
    // ① 终止/越界检查（前置！）
    if (越界 || 不合法) return;

    // ② 处理当前节点（标记 visited / 记录 / 剪枝）
    visited.add(节点);

    // ③ 递归所有邻居（子问题）
    for (邻居 : 相邻节点) {
        if (未访问) dfs(邻居, 更新状态);
    }

    // ④ 整合结果（返回值型 DFS 在这里汇总）
}
```

### 2.2 两种返回形态

```text
void 型（遍历/标记）: 结果收集在外部容器
  例: 200 岛屿（沉岛）、257 所有路径（收集到 result）

返回值型（计算）: 子问题结果向上整合
  例: 695 最大面积（1 + 四方向之和）、104 树高

⚠️ 判断口诀:
  "只访问/收集 → void；要计算/汇总 → 返回值"
```

> 🎯 **框架的核心**："**三段式 = 先判边界 → 处理当前 → 递归邻居**——顺序不能乱：越界检查必须在访问数组之前（否则越界崩溃）；标记必须在递归之前（否则死循环）。这两条是 DFS 的全部纪律。"

## 3. 二叉树遍历：前/中/后序（递归版）

### 3.1 三序代码（差异只有一行位置）

```java
/**
 * 二叉树三序遍历（递归版）
 * 前序: 根 → 左 → 右；中序: 左 → 根 → 右；后序: 左 → 右 → 根
 * 时间 O(N)，空间 O(H)（H = 树高，最坏 O(N)）
 */
public void preorder(TreeNode root, List<Integer> result) {
    if (root == null) return;
    result.add(root.val);                    // ① 前序: 处理在递归前
    preorder(root.left, result);
    preorder(root.right, result);
}

public void inorder(TreeNode root, List<Integer> result) {
    if (root == null) return;
    inorder(root.left, result);
    result.add(root.val);                    // ② 中序: 处理在两递归之间
    inorder(root.right, result);
}

public void postorder(TreeNode root, List<Integer> result) {
    if (root == null) return;
    postorder(root.left, result);
    postorder(root.right, result);
    result.add(root.val);                    // ③ 后序: 处理在递归之后
}
// 推演 [1,2,3]（1 的左 2、右 3）：
//   前序 [1,2,3]；中序 [2,1,3]；后序 [2,3,1] ✓
// ⚠️ 三序只差"处理时机"——同一段递归骨架
```

### 3.2 三序的应用场景（面试必答）

```text
前序: 需要"先父后子"的信息流（复制树、序列化、938 剪枝）
中序: BST 的升序输出（94 验证 BST 的基础）
后序: 需要"先子后父"的整合（104 树高、114 展开、打家劫舍 III）

⚠️ 一句话: "先序管向下传参，后序管向上汇总，中序管有序"
```

## 4. 二叉树遍历：迭代版（显式栈）

### 4.1 前序迭代（最简单）

```java
/**
 * 前序遍历（迭代版）——显式栈
 * 时间 O(N)，空间 O(H)
 */
public List<Integer> preorderIterative(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    Deque<TreeNode> stack = new ArrayDeque<>();
    if (root != null) stack.push(root);

    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();         // ① 弹栈即处理（前序）
        result.add(node.val);
        if (node.right != null) stack.push(node.right);   // ② 右先入（左后出）
        if (node.left != null) stack.push(node.left);
    }
    return result;
}
// ⚠️ 入栈顺序: 右先入、左后入 → 出栈顺序: 左先出 ✓
//   （栈是 LIFO——想"先左后右"处理就要"先右后左"入栈）
```

### 4.2 中序迭代（指针 + 栈）

```java
/**
 * 中序遍历（迭代版）——指针 + 栈
 */
public List<Integer> inorderIterative(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode cur = root;

    while (cur != null || !stack.isEmpty()) {
        while (cur != null) {                // ① 一路向左入栈
            stack.push(cur);
            cur = cur.left;
        }
        cur = stack.pop();                   // ② 弹栈即处理
        result.add(cur.val);
        cur = cur.right;                     // ③ 转向右子树
    }
    return result;
}
// ⚠️ 中序迭代是"指针 + 栈"模式——与递归的"先左后根后右"完全对应
```

> 💡 **递归 vs 迭代**："**递归 O(H) 系统栈简洁、迭代显式栈可控**——深树（H 很大）递归可能栈溢出，迭代是逃生通道。面试先写递归，追问'深度大怎么办'再给迭代版。"

## 5. 网格 DFS 与图 DFS：载体差异

### 5.1 三大载体对比

| 维度 | 二叉树 | 网格（矩阵） | 图 |
|------|:---:|:---:|:---:|
| 节点 | TreeNode | (i, j) 坐标 | 邻接表节点 |
| 相邻 | left/right 固定 | 四方向数组 | 邻接表动态 |
| visited | 不需要（无环） | 需要（沉岛/标记） | 需要（防环/防回父） |
| 终止 | root == null | 越界判断 | 邻居集合空 |
| 复杂度 | O(N)/O(H) | O(mn)/O(mn) | O(V+E)/O(V) |

### 5.2 网格 DFS 模板（03 文件详讲）

```java
// 网格 DFS 四件套: 越界 → 标记 → 四方向 → 撤销（如需）
int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};   // 方向数组
void dfs(char[][] grid, int i, int j) {
    if (i < 0 || i >= grid.length || j < 0 || j >= grid[0].length) return;  // ① 越界先判
    if (grid[i][j] != '1') return;             // ② 不是目标跳过
    grid[i][j] = '2';                          // ③ ⚠️ 标记前置（沉岛）！
    for (int[] d : dirs) dfs(grid, i + d[0], j + d[1]);  // ④ 四方向递归
}
// ⚠️ 标记必须前置: 先递归再标记 → 相邻格子来回递归 → 死循环/栈溢出
```

> 🎯 **载体的核心差异**："**树免标记（无环）、网格沉岛（原地改值）、图 visited（三色标记）**——'要不要标记'由'有没有环'决定。网格的'沉岛'技巧免掉 visited 数组，是岛屿题的标准手法。"

## 6. 复杂度分析：树/图/矩阵三口径

| 载体 | 时间 | 空间 | 说明 |
|------|:---:|:---:|------|
| 二叉树 | O(N) | O(H) | H = 树高；斜树最坏 O(N) |
| 网格 m×n | O(mn) | O(mn) | 全陆地时递归栈最深 |
| 图（邻接表） | O(V+E) | O(V) | 每节点每边各访问一次 |

```text
面试表达:
  "树 DFS 时间 O(N)、空间 O(H)——高度决定栈深；
   图 DFS 时间 O(V+E)——每个顶点和每条边恰好访问一次；
   网格 DFS 时间 O(mn)——每个格子最多访问一次。"
```

## 7. 手写易错点与调试技巧

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 越界检查放访问后 | 越界先判（前置） | 数组越界崩溃 |
| 2 | 标记放递归后 | 标记前置 | 死循环/栈溢出 |
| 3 | 网格手写四个递归 | 方向数组循环 | 漏方向/代码冗余 |
| 4 | 前序迭代入栈顺序反 | 右先入左后入 | 遍历顺序错 |
| 5 | 中序迭代指针丢失 | cur = cur.right 在弹栈后 | 死循环 |
| 6 | 图 DFS 忘 visited | 入栈/递归前标记 | 重复访问 |
| 7 | 无向图忘防回父 | 传 parent 参数 | 父子来回走 |

**调试技巧**：

```text
① 小样例验证: 三序遍历 [1,2,3] 对照结果
② 标记验证: 打印访问顺序——应无重复节点
③ 边界验证: 空树/单节点/斜树（H=N 最坏深度）
④ 栈溢出验证: 大输入递归报错 → 改显式栈迭代版
```

> 🎯 **核心要点**：DFS 框架通关四件事——**① 三段式烂熟**（先判边界 → 处理当前 → 递归邻居）；**② 三序只差一行**（处理时机前/中/后）；**③ 迭代双版**（前序右先入、中序指针+栈）；**④ 复杂度三口径**（树 O(N)/O(H)、图 O(V+E)、矩阵 O(mn)）。**DFS 的全部纪律只有两条：越界先判、标记前置——记住它们，四大战场随便打**。
