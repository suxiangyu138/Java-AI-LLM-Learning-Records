⚠️ 组合识别: 79 = 网格 + 回溯；337 = 树 + 记忆化——
  中档题常是战场混合体，逐层拆解

## 3. 答题流程与话术模板

### 3.1 答题三步骤（面试标准流程）

```text
① 识别战场（10 秒）:
   树/网格/图？要不要标记？任务是什么？
② 套模板（2 分钟）:
   三段式（边界 → 处理 → 递归邻居）
③ 验证（30 秒）:
   小样例 + 边界（空/单节点/全陆地）

⚠️ 面试官期待:
  "先判越界 → 标记前置 → 四方向递归"的纪律性——
  顺序颠倒（先递归后标记）是最大的扣分点
```

### 3.2 话术模板

```text
"这题是【战场】DFS——【识别信号】。
（写码）越界先判、标记前置、递归邻居。
复杂度: 【树 O(N)/O(H) | 图 O(V+E) | 网格 O(mn)】。
（被追问）深度大可以改显式栈迭代版；
   重叠子问题可以加 memo 记忆化。"

例: "网格 DFS——岛屿计数。方向数组 + 沉岛标记。
    每格最多访问一次 → O(mn)，空间 O(mn)。
    边界：空矩阵返回 0、全陆地只有 1 座岛。"
```

## 4. 高频追问 TOP 10

| # | 追问 | 标准回答 |
|:---:|------|---------|
| 1 | DFS vs BFS？ | 枚举/连通/路径 → DFS；最短步数 → BFS（首次到达即最短） |
| 2 | 为什么网格标记要前置？ | 先递归再标记 → 相邻格子来回递归 → 死循环/栈溢出 |
| 3 | 树为什么不需要 visited？ | 树天然无环（每节点唯一父）——图/网格可能有环才需要 |
| 4 | 三色标记是什么？ | 0 未访问/1 访问中/2 已访问——遇到"访问中"= 环 |
| 5 | 拓扑排序怎么用 DFS？ | 后序收集 + 反转（先修在后的顺序反转成先修在前） |
| 6 | 沉岛 vs 撤销？ | 岛屿归属固定不撤销；搜索路径可复用格子必须撤销 |
| 7 | 递归栈溢出怎么办？ | 改显式栈迭代版（堆内存无系统栈限制） |
| 8 | DFS 复杂度？ | 树 O(N)/O(H)、图 O(V+E)、网格 O(mn) |
| 9 | 与回溯/记忆化的边界？ | 回溯 = DFS+撤销（所有方案）；记忆化 = DFS+缓存（重叠最优） |
| 10 | 二分图判定？ | 染色法：邻居染反色，冲突 = 奇环 = 非二分图 |

## 5. 面试实战演练：三道真题全程

### 5.1 真题一：岛屿数量（网格母题）

```text
面试过程示范:
  ① 识别: "网格 + 连通块计数 → 沉岛 DFS"
  ② 手撕: 200 模板（越界先判 → 沉岛 → 四方向）
  ③ 纪律: "标记前置——先递归再标记会来回递归死循环"
  ④ 复杂度: O(mn)/O(mn)
  ⑤ 追问: "695 最大面积？" → 返回值型（1 + 四方向之和）
```

### 5.2 真题二：课程表（环检测）

```text
面试过程示范:
  ① 识别: "依赖关系 + 能否完成 → 有向图环检测"
  ② 建模: "邻接表（先修 → 后续）+ 三色标记"
  ③ 手撕: 207 模板（访问中 = 环）
  ④ 关键: "为什么三态不是两态——
     已访问（2）说明子树无环可跳过；访问中（1）才是环"
  ⑤ 追问: "210 要顺序？" → 后序收集 + 反转
```

### 5.3 真题三：二叉树所有路径（路径类）

```text
面试过程示范:
  ① 识别: "树 + 所有路径 → 前序 DFS（路径在递归栈）"
  ② 手撕: 257 模板（String 拼接免撤销）
  ③ 关键: "叶子判定 left==null && right==null——
     不是 root==null（那是空位不是叶子）"
  ④ 追问: "113 要路径和？" → List 版（撤销 + 深拷贝收集）
```

> 🎯 **核心要点**：面试实战通关 = **四大战场 10 秒识别 + 15 题三梯队 + 答题三步骤（识别→模板→验证）+ 追问 TOP 10 + 三场演练（网格/图/树）**。DFS 是搜索家族的地基——**两大纪律（越界先判、标记前置）+ 四大战场模板，就是全部 DFS 面试的完整答案**。
