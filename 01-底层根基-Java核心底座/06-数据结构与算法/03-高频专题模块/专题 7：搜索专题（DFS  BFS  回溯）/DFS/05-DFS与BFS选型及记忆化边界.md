## 1. 搜索家族全景：DFS/BFS/回溯/记忆化

```text
搜索家族的四种形态:
  DFS: 一条路走到黑（遍历/枚举的基础）
  BFS: 按层推进（最短路径）
  回溯: DFS + 撤销选择（枚举所有"解"）
  记忆化: DFS + 缓存（重叠子问题的"最优值"）

演化关系:
  回溯 = DFS 的"解收集版"
  记忆化 = DFS 的"去重版"
  BFS = DFS 的"镜像"（栈换队列）

⚠️ 一句话区分:
  "回溯要'所有方案'（撤销选择让分支独立）
   记忆化要'最优值'（缓存去重让状态只算一次）
   BFS 要'最短步数'（队列保证距离单调）"
```

> 🎯 **核心认知**："**搜索家族共享 DFS 的递归骨架，差异全在'回'字上——回溯回退选择、记忆化返回缓存、BFS 根本不回**。识别题目要'什么'（方案/最优/最短），家族成员就定位了。"

## 2. DFS vs BFS 选型表

| 目标 | 选型 | 原因 |
|------|:---:|------|
| 遍历所有节点 | 皆可 | 只要不重复访问 |
| 连通块面积/数量 | DFS | 递归天然统计，代码短 |
| 求无权图最短步数 | **BFS** | 按层推进，首次到达即最短 |
| 枚举所有路径 | DFS | 路径天然在递归栈里 |
| 层序遍历 | BFS | 队列按层处理 |
| 环检测 | 皆可 | 三色标记（DFS）/ 入度（BFS） |
| 拓扑排序 | 皆可 | 后序反转（DFS）/ Kahn（BFS） |

```text
识别口诀:
  "最少几步 / 最短路径 / 扩散 / 层序" → BFS
  "所有方案 / 是否存在 / 连通块 / 枚举" → DFS

⚠️ 面试表达:
  "求最短步数用 BFS——队列按层推进，首次到达即最短；
   DFS 会一条路走到黑，可能绕远。
   枚举所有路径用 DFS——递归栈天然保存路径。"
```

> 💡 **为什么 BFS 首次到达即最短**："**BFS 按'距离层'推进——第 k 层处理完才进第 k+1 层**，任何节点首次被访问时，它的距离就是最短的（不可能有更短的绕路）。DFS 没有这个性质（可能先走长路）。"

## 3. DFS vs 回溯：撤销选择的边界

### 3.1 关键差异

```text
DFS（纯遍历）: 只走不撤——访问过就标记，不需要恢复
  例: 200 岛屿（沉岛不撤销）、连通分量

回溯: 走完要撤销——每条路径独立，恢复现场
  例: 46 排列（path 弹出 + used 重置）

判定: 题目要"一条路径的结果"还是"所有路径的集合"？
  只要连通/存在 → DFS（不撤销）
  要枚举所有方案 → 回溯（撤销）

⚠️ 典型混淆: 79 单词搜索——
  它"找一条路径"但要"尝试所有起点和方向"→ 需要撤销
  （同一格可能被不同路径尝试 → 标记必须恢复）
```

> 🎯 **撤销的判定**："**'格子/状态是否可能被再次使用'决定要不要撤销**——岛屿每格归属固定（不撤销）、搜索每格可被多路径尝试（撤销）。'沉岛 vs 撤销'一句话就是 DFS 与回溯的边界。"

## 4. DFS vs 记忆化：重叠子问题的边界

### 4.1 关键差异

```text
纯 DFS: 每状态算一次（无重叠）——重复计算 = 浪费
  例: 200 岛屿（每格一次）、树遍历

记忆化: 重叠子问题 → 缓存结果（DFS + memo）
  例: 62 路径数（(i,j) 被多条路径到达）、打家劫舍 III

判定: 递归树中相同状态出现多次？
  出现 → 记忆化（否则指数级爆炸）
  不出现 → 纯 DFS 就够（加了缓存也没用）

⚠️ 升级路径:
  "暴力 DFS → 发现重叠 → 加 memo → 记忆化
   → 转递推 → 表格 DP"
  （记忆化的完整演化链见记忆化目录）
```

> 💡 **面试表达**："**这题子问题重叠（(i,j) 被多条路径到达）→ 加 memo 缓存 → O(指数) 变 O(mn)**。纯 DFS 与记忆化的分界线就是'重不重叠'——不重叠加缓存是白加。"

## 5. 栈溢出处理：显式栈迭代 DFS

### 5.1 什么时候需要

```text
递归 DFS 的空间 = O(递归深度):
  树: O(H)（H = 树高，斜树 H = N）
  网格: O(mn)（全陆地时深度 = mn）
  图: O(V)

深度过大（如 10⁴+）→ 系统栈溢出（StackOverflowError）
→ 改显式栈迭代版（堆内存无此限制）

⚠️ 识别信号: 深树/大网格/递归报错——
  面试先说"递归版简洁"，被追问"深度大怎么办"再给迭代版
```

### 5.2 前序迭代模板（显式栈）

```java
/**
 * 前序迭代 DFS（显式栈）——树/网格通用思路
 * 树: 右先入左后入（01 文件）
 * 网格: 存坐标 (i,j)，出栈处理四方向
 */
public void dfsIterative(TreeNode root) {
    Deque<TreeNode> stack = new ArrayDeque<>();
    if (root != null) stack.push(root);
    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();
        // 处理 node...
        if (node.right != null) stack.push(node.right);   // 右先入
        if (node.left != null) stack.push(node.left);     // 左后入 → 左先出
    }
}
// ⚠️ 中序迭代需要"指针 + 栈"（01 文件）——比前序复杂
//   后序迭代可用"前序变体 + 反转"（先右后左入栈）
```

> 🎯 **递归 vs 迭代**："**递归 O(深度) 系统栈、迭代显式栈可控**——面试先写递归（简洁），被问'栈溢出'再给迭代版（工程稳健）。'能讲清两种实现的取舍'就是完整的 DFS 答案。"

## 6. 混合模式：BFS+DFS 与 网格双向

### 6.1 混合应用

```text
① 双向 BFS（最短路径加速）:
   起点终点同时 BFS → 相遇即最短（BFS 目录详讲）

② DFS + 记忆化（树 DP）:
   打家劫舍 III = 后序 DFS + memo（每节点两状态）

③ BFS 求层 + DFS 求路径:
   层数用 BFS、路径枚举用 DFS——各取所长

④ 网格 + 回溯（79 单词搜索）:
   网格 DFS 模板 + 撤销选择（03 文件）

⚠️ 混合的本质: 一个题目可能同时命中多个家族——
   "求最短 + 要路径" → BFS 求距 + DFS 回溯路径
```

> 💡 **混合识别的价值**："**中档题常是'家族混合体'——79 是'网格 DFS + 回溯'、337 是'树 DFS + 记忆化'**。能拆出'哪个部分用哪个家族'，就是对搜索全景的真正掌握。"

## 7. 选型决策总表

### 7.1 快速决策表

| 题目特征 | 选型 |
|------|------|
| "最短/最少步数" | BFS |
| "连通块/岛屿/遍历" | DFS（不撤销） |
| "所有方案/排列组合" | 回溯（DFS + 撤销） |
| "重叠子问题/最优值" | 记忆化（DFS + 缓存） |
| "是否存在路径" | DFS / BFS 皆可 |
| "层序/扩散" | BFS |
| "环/拓扑" | 三色 DFS 或 Kahn BFS |
| "深度极大" | 迭代 DFS / BFS |

### 7.2 一句话总结

```text
"枚举走 DFS、最短走 BFS、
 方案要撤销（回溯）、重叠要缓存（记忆化）"

⚠️ 面试开场白:
  "这题要【目标】，所以选【家族】——
   因为【原因】。"（30 秒完成选型论述）
```

> 🎯 **核心要点**：选型通关四件事——**① 家族全景**（DFS/BFS/回溯/记忆化四兄弟）；**② 选型表烂熟**（枚举 vs 最短）；**③ 两个边界**（撤销与否、缓存与否）；**④ 栈溢出逃生**（显式栈迭代版）。**搜索家族的边界地图只有四句话——'枚举 DFS、最短 BFS、方案撤销、重叠缓存'，记住它，搜索题 30 秒定位**。
