## 1. 知识体系导图

```text
记忆化搜索（Memoization）
│
├── 核心本质 ──────────────────────────────────────────────
│   ├── = 递归（DFS）+ 缓存（memo）——"分治 + 缓存"的结合
│   ├── 每个状态只算一次 → 指数级 → 多项式级
│   ├── 本质 = DP 的自顶向下实现（与表格 DP 数学等价）
│   └── 演化路径: 暴力回溯 → 记忆化 → 递推 DP
│
├── 三步模板 ──────────────────────────────────────────────
│   ├── ① base case（终止条件）
│   ├── ② 查缓存（memo 命中直接返回）
│   └── ③ 计算 + 存缓存（算完写入 memo）
│
├── 识别信号 ──────────────────────────────────────────────
│   ├── "递归会超时 + 重叠子问题" → 记忆化
│   ├── "状态可索引/可哈希"（坐标/参数/掩码）
│   ├── 无重叠子问题 → 记忆化无意义（归并排序不需要）
│   └── 判断法: 递归树中相同状态出现多次？
│
├── 状态设计（核心考点）───────────────────────────────────
│   ├── 状态 = 递归参数的最小完备集（缺参数 → 结果错）
│   ├── 一维/二维/三维（数组）/ 复杂状态（HashMap/掩码）
│   ├── 状态压缩: 余额/计数/掩码让阶乘级变可解
│   └── 单调转移（递增/递减）→ 天然无环 → 免 visited
│
├── vs 表格 DP ───────────────────────────────────────────
│   ├── 自顶向下 vs 自底向上；递归 vs 循环
│   ├── 记忆化: 状态稀疏高效、顺序免显式、递归自然
│   ├── 表格: 全状态计算、滚动数组、无栈溢出
│   └── 面试: 先写记忆化验证 → 转表格优化空间
│
└── 实战与面试 ────────────────────────────────────────────
    ├── 母题: 62 不同路径、329 最长递增路径（Hard 变 Medium）
    ├── 进阶: 403 青蛙过河、576 出界路径、464 掩码
    ├── 陷阱: 缓存初值 -1、忘查/忘存、栈溢出转递推
    └── 话术: "状态数 × 转移代价"复杂度表达
```

## 4. 核心概念速查

| 概念 | 一句话解释 | 说明 |
|------|-----------|------|
| **记忆化** | 递归 + 缓存去重 | DP 的自顶向下形态 |
| **重叠子问题** | 递归树中相同状态多次出现 | 记忆化的前提条件 |
| **memo** | 缓存容器（数组/HashMap） | 初值必须 ≠ 结果可能值 |
| **查缓存** | 递归开头命中即返回 | 不查 = 每次重算 |
| **存缓存** | 算完写入 memo | 不存 = 白算 |
| **状态** | 递归参数的最小完备集 | 缺参数 → 状态错误 |
| **base case** | 递归终止条件 | 必须明确（越界/边界） |
| **表格 DP** | 自底向上循环实现 | 与记忆化数学等价 |
| **位掩码** | 整数二进制表示子集 | 子集型记忆化状态 |
| **visited** | 防重复访问（防环） | 单调转移时不需要 |

## 5. 复杂度与特性速查表

| 场景 | 暴力 DFS | 记忆化 | 说明 |
|------|:---:|:---:|------|
| Fibonacci | O(2ⁿ) | **O(n)** | 状态数 n × O(1) |
| 网格路径（62） | O(2^(m+n)) | **O(mn)** | 状态数 mn |
| 青蛙过河（403） | 指数级 | **O(n²)** | 状态数 n² |
| 出界路径（576） | 指数级 | **O(mn·k)** | 三维状态 |

**复杂度公式（面试必答）**：

```text
时间 = 状态数 × 单状态转移代价
空间 = memo 大小 + 递归栈深度

⚠️ 两个"不一定":
  记忆化不一定比递推省空间（递归栈额外 O(深度)）
  记忆化不一定更快（递归调用开销 > 循环）
  → 选型看"状态稀疏度"与"栈深度"
```

> 🎯 **一句话定位**："**记忆化 = '分治 + 缓存'——把指数级暴力降到多项式级，是 DP 思想最自然的入口**。面试中掌握'状态设计 → 转移 → 边界 → 复杂度'主线，就能应对大多数 DP 类题（2025-2026 面试共识）。"

## 6. 常见误区速查

| 误区 | 正解 |
|------|------|
| "记忆化是新算法" | ❌ 就是递归 + 缓存，DP 的自顶向下写法 |
| "任何递归都能记忆化" | ❌ 必须有重叠子问题——归并排序加了也没用 |
| "缓存初值用 0 就行" | ❌ 结果可能为 0（计数类）→ 用 -1 或 boolean 标记 |
| "查缓存和存缓存二选一" | ❌ 缺一不可：只查不存 = 每次重算；只存不查 = 永不命中 |
| "记忆化可以代替 visited" | ❌ 记忆化缓存"结果"，visited 防"回访"——有环时递归不会结束 |
| "记忆化空间一定比递推省" | ❌ 递归栈额外 O(深度)，可能更费 |
| "记忆化一定比递推快" | ❌ 递归调用开销 > 循环；状态密集时递推更好 |
| "缓存键少个参数没事" | ❌ 状态不完备 → 结果错误 |
| "递增路径也要 visited" | ❌ 严格递增 → 不可能走回 → 天然无环，免 visited |
| "栈溢出就加缓存" | ❌ 深度过大（n=10⁴）必须转递推，缓存救不了栈 |
