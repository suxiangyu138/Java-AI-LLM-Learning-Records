## 1. 记忆化模型：递归 + 缓存

### 1.1 为什么朴素递归会超时

```text
fib(5) 的递归树:
  fib(3) 算 2 次、fib(2) 算 3 次、fib(1) 算 5 次……
  总调用 O(2ⁿ) —— 指数爆炸

重叠子问题: 同一状态（如 fib(3)）被反复计算
  → 记忆化: 第一次算完存入 memo[3]，之后 O(1) 直接取
  → fib 从 O(2ⁿ) 降到 O(n)（2025 面试共识的经典开场）
```

### 1.2 记忆化是什么

```text
记忆化（Memoization）= 递归（DFS）+ 缓存（memo）

三步:
  ① 递归分解（与暴力 DFS 相同）
  ② 查缓存（状态已算过 → 直接返回）
  ③ 存缓存（算完写入 memo）

本质 = 动态规划的自顶向下实现
  分治（分解）+ 缓存（去重）→ 每个状态只算一次

⚠️ 前提: 必须存在重叠子问题——
  归并排序的子问题不重叠 → 记忆化无意义
  判断法: 画递归树，相同状态出现多次？
```

> 🎯 **核心动作三连**：**base case（终止）→ 查缓存（命中即返）→ 存缓存（算完写入）**。"查"与"存"缺一不可——只查不存等于每次重算，只存不查等于白存。

## 2. 三步模板（2 分钟默写）

### 2.1 通用模板

```java
/**
 * 记忆化通用模板（三步: base case → 查缓存 → 存缓存）
 */
public int solve(int[] args) {
    int[][] memo = new int[m][n];            // ① 缓存（-1 = 未算）
    for (int[] row : memo) Arrays.fill(row, -1);
    return dfs(args, memo);
}

private int dfs(状态参数, int[][] memo) {
    if (基础情况) return 基础值;              // ② base case

    if (memo[i][j] != -1) return memo[i][j]; // ③ ⚠️ 查缓存（命中即返）

    int result = 计算(递归调用);              // ④ 递归计算
    return memo[i][j] = result;              // ⑤ ⚠️ 存缓存（算完写入）
}
```

### 2.2 模板三问（面试必答）

```text
① 状态是什么？ —— 递归参数的最小完备集（(i,j)？剩余步数？掩码？）
② base case 是什么？ —— 终止条件 + 返回值（越界 0？终点 1？）
③ memo 初值是什么？ —— 必须 ≠ 结果可能值（用 -1 而非 0！）

⚠️ 初值陷阱: 计数类题目结果可能是 0
  → 初值 0 无法区分"未算"与"结果为 0"
  → 必须用 -1（或 boolean 标记）——2025 面试高频扣分点
```

## 3. 62 不同路径（记忆化入门）

### 3.1 题目与思路

**题**：m×n 网格从左上到右下（只能右/下），多少条路径。

**朴素 DFS O(2^(m+n)) → 记忆化 O(mn)**：

```java
/**
 * LeetCode 62. 不同路径（记忆化）
 * 时间 O(mn)，空间 O(mn)
 */
public int uniquePaths(int m, int n) {
    int[][] memo = new int[m][n];
    for (int[] row : memo) Arrays.fill(row, -1);   // ① -1 = 未算
    return dfs(m, n, 0, 0, memo);
}

private int dfs(int m, int n, int i, int j, int[][] memo) {
    if (i == m - 1 && j == n - 1) return 1;        // ② base: 到终点 1 条路
    if (i >= m || j >= n) return 0;                // ③ base: 越界 0 条路

    if (memo[i][j] != -1) return memo[i][j];       // ④ 查缓存

    memo[i][j] = dfs(m, n, i + 1, j, memo)         // ⑤ 右
               + dfs(m, n, i, j + 1, memo);        //    下
    return memo[i][j];                             // ⑥ 存缓存
}
// 推演 3×3：从 (2,2) 出发 = 1（终点）
//   (2,1) = 1；(1,2) = 1；(1,1) = 2 …
//   memo 填充后每个格子只算一次 → O(mn)
// ⚠️ 状态 = (i, j)；base case 两行（终点/越界）缺一不可
```

> 💡 **为什么这题是入门**："**62 的状态（坐标）、转移（右/下）、base case（终点/越界）全部直观**——记忆化的四要素在这题里各就各位，是完美的教学载体。63 不同路径 II（加障碍）只是加一个跳过判断。"

## 4. 329 最长递增路径（经典 Hard）

### 4.1 题目与思路

**题**：矩阵中最长递增路径长度（四方向，严格递增）。

**memo[i][j] = 从 (i,j) 出发的最长递增路径**：

```java
/**
 * LeetCode 329. 矩阵中的最长递增路径（Hard → 记忆化后 Medium）
 * 时间 O(mn)，空间 O(mn)
 * ⚠️ 严格递增 → 无环 → 不需要 visited！
 */
public int longestIncreasingPath(int[][] matrix) {
    int m = matrix.length, n = matrix[0].length;
    int[][] memo = new int[m][n];            // 0 = 未计算（路径 ≥ 1，安全）

    int maxLen = 0;
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            maxLen = Math.max(maxLen, dfs(matrix, i, j, memo));   // ① 从每个格子出发
        }
    }
    return maxLen;
}

private int dfs(int[][] matrix, int i, int j, int[][] memo) {
    if (memo[i][j] != 0) return memo[i][j];      // ② 查缓存

    int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};
    int best = 1;                                // ③ 自己至少 1

    for (int[] d : dirs) {
        int ni = i + d[0], nj = j + d[1];
        if (ni < 0 || ni >= matrix.length || nj < 0 || nj >= matrix[0].length) continue;
        if (matrix[ni][nj] <= matrix[i][j]) continue;   // ④ 非递增跳过

        best = Math.max(best, 1 + dfs(matrix, ni, nj, memo));   // ⑤ 四方向取最大
    }
    return memo[i][j] = best;                    // ⑥ 存缓存
}
// 每个格子算一次 → O(mn)
// ⚠️ 面试必讲: 为什么不需要 visited？
//   路径严格递增 → 不可能走回已访问格子 → 天然无环
//   这是 329 从"网格 DFS"升华为"记忆化"的关键
```

> 🎯 **329 的面试价值**："**'Hard 变 Medium'的经典案例——朴素 DFS 指数级，记忆化后 O(mn)**。'为什么免 visited'（严格递增天然无环）是必答点，'从每个格子出发 + 取最大'是唯一的新结构。"

## 5. 记忆化 vs 表格 DP

### 5.1 对比表

| 维度 | 记忆化（自顶向下） | 表格 DP（自底向上） |
|------|:---:|:---:|
| 方向 | 递归分解 | 循环递推 |
| 计算范围 | **只算用到的状态** | 通常算全部 |
| 遍历顺序 | 无需显式 | 必须确定 |
| 栈风险 | 深度大可能溢出 | 无 |
| 状态稀疏 | ✅ 高效 | 浪费 |
| 滚动数组 | 不适用 | ✅ |
| 代码直觉 | 递归思路直接加缓存 | 需设计转移方程 |

### 5.2 选型决策与面试表达

```text
✅ 选记忆化:
  状态空间稀疏（只算用到的）
  遍历顺序难确定（329 递增路径）
  树形/递归结构天然（树 DP）

✅ 选表格 DP:
  所有状态都需要（二维表格）
  需要滚动数组优化空间
  状态转移顺序明确

⚠️ 面试表达:
  "这题我写记忆化搜索——DFS + memo 缓存，
   与 DP 本质等价，只是自顶向下实现。
   状态稀疏时只算用到的，更高效。
   （被追问空间优化）可以转表格 DP + 滚动数组
   把空间从 O(mn) 压到 O(n)。"
```

> 💡 **面试手写顺序**："**先写记忆化（思路直观、快速验证），面试官要求优化空间时再转表格**——'记忆化 → 表格'的转换三步骤：识别状态与依赖方向 → 确定遍历顺序 → 循环实现 + 滚动数组。"

## 6. 设计要点：初值、visited、缓存键

### 6.1 缓存初值选择

| 场景 | 初值 | 原因 |
|------|:---:|------|
| 结果 ≥ 1（329 路径长度） | 0 | 0 可安全表示"未算" |
| 结果可能为 0（62 计数） | -1 | 0 会被误判为"已算" |
| 布尔结果（464 我能赢吗） | null | 用 Boolean[] 包装类 |

> ⚠️ **铁律**："**缓存初值一定不能等于结果的可能值**——否则'未算'与'算过'无法区分，记忆化失效（2025 面试高频扣分点）。"

### 6.2 记忆化 vs visited

```text
需要 visited 吗？
  ① 状态转移"单调"（递增/减少）→ 无环 → 不需要
     例: 329 递增路径（只走向更大的值）
  ② 状态可能回访（无单调性）→ 需要 visited
     例: 79 单词搜索（可走回已访问格子）
  ③ 记忆化能代替 visited 吗？
     ⚠️ 不行！记忆化缓存"结果"，visited 防"回访"
     有环时递归根本不会结束 → 无法缓存

⚠️ 面试必答:
  "记忆化防重复计算；visited 防重复访问。
   递增场景天然无环 → 只需记忆化。"
```

### 6.3 缓存键完备性

```text
缓存键必须包含全部状态参数:
  一维 → int[] memo
  二维 → int[][] memo
  三维 → int[][][] memo
  复杂 → HashMap<参数组合, 结果>
    例: 403 青蛙过河 → 位置 + 上一步跳跃距离
        464 我能赢吗 → 位掩码

⚠️ 少一个参数 → 状态不完整 → 不同状态共用一个缓存 → 结果错误
   （2025 面试陷阱: "缓存键漏参数"是最隐蔽的 bug）
```

## 7. 手写易错点与调试技巧

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 忘查缓存 | 递归开头查 memo | 每次重算（白记忆化） |
| 2 | 忘存缓存 | 算完写 memo | 永不命中（白存） |
| 3 | 初值用 0（结果可能为 0） | 用 -1 或 boolean | 未算被误判已算 |
| 4 | 缓存键漏参数 | 含全部状态参数 | 状态污染结果错 |
| 5 | 有环用记忆化 | 先分析单调性 | 无限递归 |
| 6 | base case 漏越界 | 越界返回 0 | 数组越界/死循环 |
| 7 | 栈溢出（深度 10⁴） | 转表格递推 | 递归栈爆 |

**调试技巧**：

```text
① 小样例验证: fib(5)=5、3×3 网格路径 = 6（手推对照）
② 命中率验证: 加计数器统计"查缓存命中次数"——
   命中 0 次 = 忘存或状态不重叠
③ 复杂度验证: 打印 memo 填充格子数——应等于状态数
④ 边界验证: 空输入 / 单元素 / 全相等（329 应返回 1）
```

> 🎯 **核心要点**：记忆化通关四件事——**① 三步模板烂熟**（base case → 查缓存 → 存缓存）；**② 62/329 母题全会**（入门模板 + 免 visited 论证）；**③ 三大设计要点**（初值 -1、单调免 visited、缓存键完备）；**④ 与表格 DP 等价**（自顶向下 vs 自底向上，面试先记忆化后转表格）。**记忆化是"暴力 DFS 到工程 DP"的桥梁——会写它，指数级焦虑就结束了**。
