## 1. 知识体系导图

```text
回溯算法（Backtracking）
│
├── 核心本质 ──────────────────────────────────────────────
│   ├── = DFS + 状态回退（撤销选择）
│   ├── 三要素: 路径 / 选择列表 / 结束条件
│   ├── "选 → 递 → 回"三步曲（做选择 → 递归 → 撤销）
│   └── 本质 = 暴力枚举所有决策路径（剪枝优化）
│
├── 五大题型（面试分布）───────────────────────────────────
│   ├── 组合（30%+）: 77/39/40/17/216 —— startIndex 控制
│   ├── 排列（20%+）: 46/47 —— used[] 标记 + 去重
│   ├── 子集（15%+）: 78/90 —— 每个节点都记录
│   ├── 切割（10%+）: 131/93 —— startIndex = 切割点
│   └── 棋盘（15%+）: 51/37 —— 行列对角线多维剪枝
│
├── 去重核心 ──────────────────────────────────────────────
│   ├── 前提: 先排序让重复元素相邻
│   ├── 组合/子集去重: i > startIndex && nums[i] == nums[i-1]
│   ├── 排列去重: !used[i-1]（同层）而非 used[i-1]（同路径）
│   └── ⚠️ 同层 vs 同路径是去重第一易错点
│
├── 剪枝优化 ──────────────────────────────────────────────
│   ├── 和约束: 排序后 sum + nums[i] > target → break
│   ├── 剩余数量: i <= n − (k − path.size()) + 1
│   ├── N皇后: 行递归 + 列/对角线检查（C(64,8)→2000 节点）
│   └── 复杂度不变（O(2ⁿ)/O(n!)），剪枝只减实际时间
│
└── 实战与面试 ────────────────────────────────────────────
    ├── 手写: 三母题（46 排列/78 子集/77 组合）2 分钟
    ├── 避坑: 深拷贝、忘撤销、子集记录时机、传 i vs i+1
    ├── 复杂度: 组合/子集 O(2ⁿ)、排列 O(n!)、空间 O(n)
    └── 话术: "画递归树 → 套模板 → 剪枝"三步答题
```

## 4. 核心概念速查

| 概念 | 一句话解释 | 说明 |
|------|-----------|------|
| **回溯** | DFS + 撤销选择 | 暴力枚举的优化版 |
| **路径** | 已做的选择 | 递归参数 path |
| **选择列表** | 当前可选项 | 组合用 startIndex、排列用 used |
| **结束条件** | 到达决策树底部 | 长度达标/和达标 |
| **三步曲** | 选 → 递 → 回 | 做选择、递归、撤销 |
| **startIndex** | 组合/子集的起点控制 | 防止 [1,2] 与 [2,1] 重复 |
| **used[]** | 排列的已选标记 | 从 0 开始遍历 |
| **同层去重** | 跳过同一层重复选择 | 先排序 + 条件跳过 |
| **剪枝** | 提前终止不可能分支 | 和约束/剩余数量/对角线 |
| **深拷贝** | `new ArrayList<>(path)` | 直接 add(path) 会污染结果 |

## 5. 题型模式速查

### 5.1 五大题型 → 模板变体 → 代表题

| 题型 | 控制方式 | 记录时机 | 代表题 |
|------|------|------|:---:|
| 组合 | startIndex（传 i+1） | 结束条件（长度/和达标） | 77/39/40 |
| 排列 | used[]（从 0 遍历） | 结束条件（长度 = n） | 46/47 |
| 子集 | startIndex | **递归开头**（每节点都记） | 78/90 |
| 切割 | startIndex = 切割点 | 递归开头（段合法即记） | 131/93 |
| 棋盘 | 行递归 + 位置约束 | 结束条件（放满 n 行） | 51/37 |

### 5.2 通用模板（面试标准答案）

```java
void backtrack(路径, 选择列表) {
    if (结束条件) {
        result.add(new ArrayList<>(path));   // ⚠️ 深拷贝！
        return;
    }
    for (选择 : 选择列表) {
        做选择;                               // ① 选
        backtrack(新路径, 新选择列表);         // ② 递
        撤销选择;                             // ③ 回（关键！）
    }
}
```

> 🎯 **一句话定位**："**回溯 = '选→递→回'三步曲 + 五大题型各一套控制方式**——组合管起点（startIndex）、排列管已选（used）、子集管记录时机（每节点）、切割管切点、棋盘管位置约束。**五大题型的区别全在'选择列表怎么生成'，模板骨架完全一致**。"

## 6. 常见误区速查

| 误区 | 正解 |
|------|------|
| "回溯和 DFS 一样" | ❌ 回溯 = DFS + 撤销选择——DFS 只管走，回溯管"走完回来" |
| "忘撤销选择" | ❌ path 不 pop / used 不重置 → 分支间状态污染（第一 bug） |
| "直接 add(path)" | ❌ 引用传递 → 结果集全被污染；必须 `new ArrayList<>(path)` 深拷贝 |
| "子集在结束条件记录" | ❌ 子集在**递归开头**记录（每个节点都是子集） |
| "组合传 i 还是 i+1 分不清" | ❌ 可重复选传 i（39）；不可重复传 i+1（40/77） |
| "排列去重用 used[i-1]" | ❌ 同层去重用 `!used[i-1]`（前一个未用才跳）；`used[i-1]` 是同路径去重会漏解 |
| "不排序直接去重" | ❌ 去重必须先排序让重复元素相邻 |
| "剪枝改变复杂度" | ❌ 理论复杂度不变（O(2ⁿ)/O(n!)），剪枝只减实际时间 |
| "回溯只能穷举" | ❌ 剪枝 + 约束传播（N皇后/数独）让它能解决组合爆炸问题 |
| "结果集合顺序无关紧要" | ❌ 某些题要求字典序（切割/IP）——注意收集顺序 |
