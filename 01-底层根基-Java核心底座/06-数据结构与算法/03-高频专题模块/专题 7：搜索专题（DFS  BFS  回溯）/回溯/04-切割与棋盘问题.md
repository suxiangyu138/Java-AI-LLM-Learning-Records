## 1. 约束型回溯：从枚举到筛选

```text
组合/排列: 枚举"所有可能"，约束只有长度/和
切割/棋盘: 枚举 + 强约束筛选——
  切割: 段必须合法（回文/IP 段）
  棋盘: 位置必须互不冲突（列/对角线）

约束型回溯的共性:
  ① 在"选"之前先检查合法性（剪枝前置）
  ② 不合法 → 跳过该选择（continue）而非继续递归
  ③ 合法 → 做选择 → 递归 → 撤销

⚠️ 识别信号:
  "分割/切割" → startIndex 当切点（每段合法才切）
  "棋盘/放置" → 行递归 + 位置约束（每行放一个）
```

> 🎯 **核心认知**："**约束型回溯把'枚举'升级为'筛选'——合法性检查放在'选'之前，让决策树大幅收缩**。切割的'段合法'、棋盘的'列/对角线不冲突'，都是同一件事：把不可能的分支在进入前砍掉。"

## 2. 131 分割回文串（startIndex = 切割点）

### 2.1 题目与思路

**题**：把字符串分割成若干回文子串，返回所有方案。

**startIndex = 切割点** + 段合法（回文）才切：

```java
/**
 * LeetCode 131. 分割回文串
 * startIndex 当切割点: 每段 [start, i] 是回文才切
 * 时间 O(n·2ⁿ)，空间 O(n)
 */
public List<List<String>> partition(String s) {
    List<List<String>> result = new ArrayList<>();
    backtrack(s, 0, new ArrayList<>(), result);
    return result;
}

private void backtrack(String s, int start,
                       List<String> path, List<List<String>> result) {
    if (start == s.length()) {                   // ① 切割完整个串
        result.add(new ArrayList<>(path));
        return;
    }
    for (int i = start; i < s.length(); i++) {
        if (!isPalindrome(s, start, i)) continue;   // ② 段 [start,i] 非回文 → 跳过
        path.add(s.substring(start, i + 1));        // ③ 切下合法段
        backtrack(s, i + 1, path, result);          // ④ 从 i+1 继续切
        path.remove(path.size() - 1);               // ⑤ 回
    }
}

private boolean isPalindrome(String s, int lo, int hi) {
    while (lo < hi) {
        if (s.charAt(lo++) != s.charAt(hi--)) return false;
    }
    return true;
}
// 推演 "aab" → [["a","a","b"],["aa","b"]] ✓
// ⚠️ 切割的本质: 每段 [start..i] 是"组合的选择"，
//   切完一段后 start 跳到 i+1（与组合的 i+1 同款）
```

> 💡 **切割与组合的同构**："**切割 = 组合的'段版'——startIndex 从'选元素起点'变成'切割起点'**，'段合法'是唯一的额外检查。会 77 组合就能 5 分钟写 131。"

## 3. 93 复原 IP 地址（三段切割）

### 3.1 题目与思路

**题**：字符串分割成合法 IPv4 地址（4 段，每段 0-255 且无前导零）。

**切割 + 段合法性三重检查**：

```java
/**
 * LeetCode 93. 复原 IP 地址
 * 切割 + 段合法三条件: 0-255、无前导零、1-3 位
 */
public List<String> restoreIpAddresses(String s) {
    List<String> result = new ArrayList<>();
    backtrack(s, 0, 0, new ArrayList<>(), result);   // ① 段数也做参数
    return result;
}

private void backtrack(String s, int start, int segCount,
                       List<String> path, List<String> result) {
    if (segCount == 4) {                         // ② 4 段用完
        if (start == s.length()) {               //    且串用完 → 合法地址
            result.add(String.join(".", path));
        }
        return;
    }
    if (start >= s.length()) return;             // ③ 串用完段没用完 → 剪枝

    for (int len = 1; len <= 3 && start + len <= s.length(); len++) {
        String seg = s.substring(start, start + len);
        if (!isValid(seg)) continue;             // ④ 段合法性三检查
        path.add(seg);
        backtrack(s, start + len, segCount + 1, path, result);
        path.remove(path.size() - 1);
    }
}

private boolean isValid(String seg) {
    if (seg.length() > 1 && seg.charAt(0) == '0') return false;  // ⑤ 无前导零
    int val = Integer.parseInt(seg);
    return val >= 0 && val <= 255;               // ⑥ 0-255 范围
}
// 推演 "25525511135" → ["255.255.11.135","255.255.111.35"] ✓
// ⚠️ 与 131 的差异: 段长限 1-3、段数限 4——
//   两个"硬约束"都体现在参数与循环边界上
```

> 🎯 **93 的剪枝意识**："**'段数用完串没用完 / 串用完段没用完'两个提前返回**是 93 的隐藏剪枝——无效分支在深入前被砍掉。切割题的约束（段长/段数/合法性）全部前置检查。"

## 4. 51 N 皇后（行递归 + 对角线剪枝）

### 4.1 题目与思路

**题**：n×n 棋盘放 n 个皇后，互不攻击（不同行/列/对角线）。

**行递归 + 三数组剪枝**（列、正对角线、反对角线）：

```java
/**
 * LeetCode 51. N 皇后
 * 行递归（每行放一个）+ 列/对角线三数组剪枝
 * 时间 O(n!)，空间 O(n)
 */
public List<List<String>> solveNQueens(int n) {
    List<List<String>> result = new ArrayList<>();
    boolean[] cols = new boolean[n];              // ① 列占用
    boolean[] diag1 = new boolean[2 * n - 1];     // ② 正对角线 (row−col) 恒定
    boolean[] diag2 = new boolean[2 * n - 1];     // ③ 反对角线 (row+col) 恒定
    char[][] board = new char[n][n];
    for (char[] row : board) Arrays.fill(row, '.');
    backtrack(n, 0, cols, diag1, diag2, board, result);
    return result;
}

private void backtrack(int n, int row,
                       boolean[] cols, boolean[] diag1, boolean[] diag2,
                       char[][] board, List<List<String>> result) {
    if (row == n) {                               // ④ 放满 n 行
        List<String> list = new ArrayList<>();
        for (char[] r : board) list.add(new String(r));
        result.add(list);
        return;
    }
    for (int col = 0; col < n; col++) {
        int d1 = row - col + n - 1;               // ⑤ 正对角线索引（防负偏移）
        int d2 = row + col;                       // ⑥ 反对角线索引
        if (cols[col] || diag1[d1] || diag2[d2]) continue;   // ⑦ 三方向冲突 → 跳过

        cols[col] = diag1[d1] = diag2[d2] = true; // ⑧ 选（标记三方向）
        board[row][col] = 'Q';
        backtrack(n, row + 1, cols, diag1, diag2, board, result);
        board[row][col] = '.';                    // ⑨ 回（撤销）
        cols[col] = diag1[d1] = diag2[d2] = false;
    }
}
// 推演 n=4 → 2 个解 ✓（"行递归"保证不同行，三数组保证列与对角线）
// ⚠️ 对角线数学:
//   正对角线 row−col 恒定（范围 −(n−1)..n−1 → 加 n−1 偏移）
//   反对角线 row+col 恒定（范围 0..2n−2）
```

> 🎯 **N 皇后的剪枝价值**："**'行递归 + 列/对角线三数组'让 N=8 的搜索从 C(64,8)≈4.4×10⁹ 缩到约 2000 个节点（6 个数量级）**——约束前置的威力在棋盘题上体现得最极致（05 文件详讲）。"

## 5. 37 解数独（约束传播）

### 5.1 题目与思路

**题**：填满 9×9 数独（行/列/3×3 宫不重复）。

**逐格回溯 + 三组布尔数组**（行/列/宫的占用表）：

```java
/**
 * LeetCode 37. 解数独
 * 逐格填数 + 行/列/宫三组布尔数组（O(1) 合法性检查）
 * 时间 O(9^81) 最坏（剪枝后实际远小），空间 O(81)
 */
public void solveSudoku(char[][] board) {
    boolean[][] rows = new boolean[9][10];        // ① 行占用（数字 1-9）
    boolean[][] cols = new boolean[9][10];        // ② 列占用
    boolean[][] boxes = new boolean[9][10];       // ③ 宫占用
    for (int i = 0; i < 9; i++) {
        for (int j = 0; j < 9; j++) {
            if (board[i][j] != '.') {
                int num = board[i][j] - '0';
                rows[i][num] = cols[j][num] = boxes[boxIndex(i, j)][num] = true;
            }
        }
    }
    backtrack(board, 0, 0, rows, cols, boxes);
}

private boolean backtrack(char[][] board, int i, int j,
                          boolean[][] rows, boolean[][] cols, boolean[][] boxes) {
    if (i == 9) return true;                      // ④ 全部填完
    int ni = (j == 8) ? i + 1 : i;                // ⑤ 下一格（换行处理）
    int nj = (j == 8) ? 0 : j + 1;
    if (board[i][j] != '.') {                     // ⑥ 已填 → 跳过
        return backtrack(board, ni, nj, rows, cols, boxes);
    }
    for (int num = 1; num <= 9; num++) {
        int box = boxIndex(i, j);
        if (rows[i][num] || cols[j][num] || boxes[box][num]) continue;  // ⑦ 冲突跳过
        board[i][j] = (char) ('0' + num);         // ⑧ 填数
        rows[i][num] = cols[j][num] = boxes[box][num] = true;
        if (backtrack(board, ni, nj, rows, cols, boxes)) return true;   // ⑨ 找到即返回
        board[i][j] = '.';                        // ⑩ 回（撤销）
        rows[i][num] = cols[j][num] = boxes[box][num] = false;
    }
    return false;                                 // ⑪ 无解回溯
}

private int boxIndex(int i, int j) { return (i / 3) * 3 + j / 3; }   // ⑫ 宫编号
// ⚠️ 与前面题目的差异: 返回 boolean（找"一个解"而非"所有解"）——
//   找到解立即 return true 向上传播（无需收集所有解）
```

> 💡 **37 的返回类型**："**数独是'求一个解'——回溯函数返回 boolean，找到即层层 return true**（与'求所有解'的 void + 收集不同）。'求一个 vs 求所有'决定返回类型，是回溯题的第一设计决策。"

## 6. 四题对比与易错点

### 6.1 约束型回溯对比

| 题 | 递归维度 | 约束 | 收集时机 |
|:---:|------|------|------|
| 131 回文切割 | start（切割点） | 段是回文 | 串切完 |
| 93 IP 地址 | start + 段数 | 段 1-3 位/0-255/无前导零 | 4 段且串完 |
| 51 N 皇后 | 行 | 列/对角线三数组 | 放满 n 行 |
| 37 数独 | 格（i,j） | 行/列/宫三组 | 填满（求一个解） |

### 6.2 易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 131 忘回文检查 | 段合法才切 | 输出非回文段 |
| 2 | 93 忘前导零检查 | `"01"` 不合法 | IP 段错误 |
| 3 | 51 对角线索引负值 | `row−col+n−1` 偏移 | 数组越界 |
| 4 | 51 忘撤销三数组 | 撤销要成对 | 状态污染 |
| 5 | 37 找解用 void | 返回 boolean + 提前 return | 找不到/全收集 |
| 6 | 37 宫编号公式错 | `(i/3)*3 + j/3` | 宫冲突漏检 |
| 7 | 93 段长超 3 | `len <= 3` 限制 | 段超长 |

> 🎯 **核心要点**：切割棋盘通关四件事——**① 切割 = 组合 + 段合法**（131/93 的 startIndex 切点）；**② 棋盘 = 行递归 + 多维数组剪枝**（51 的列/对角线数学）；**③ 约束前置**（'选'之前检查合法性）；**④ 求一个 vs 求所有**（37 的 boolean 返回）。**约束型回溯是回溯的进阶形态——'把不可能的分支在进入前砍掉'这一句，就是它与暴力枚举的分水岭**。
