## 1. 五大题型识别（10 秒定位）

### 1.1 题型 → 控制方式 → 代表题

| 题型 | 关键词信号 | 控制方式 | 代表题 |
|------|------|------|:---:|
| 组合 | "组合/取 k 个/和为 target" | startIndex | 77/39/40/216 |
| 排列 | "排列/顺序不同算不同" | used[] | 46/47 |
| 子集 | "子集/所有可能" | startIndex + 开头记录 | 78/90 |
| 切割 | "分割/切割/复原" | startIndex 当切点 | 131/93 |
| 棋盘 | "放置/棋盘/数独" | 行递归 + 约束 | 51/37 |

### 1.2 识别口诀

```text
"顺序敏感 → used[]（排列）
 顺序无关 → startIndex（组合/子集）
 所有中间状态 → 开头记录（子集/切割）
 只取叶子 → 结束记录（组合/排列）
 强约束 → 选之前检查（棋盘/数独）"

⚠️ 组合 vs 排列的一词之差:
  "取 k 个" → 组合；"排列" 二字 → 排列
  读题先抓这两个词，10 秒定题型
```

> 🎯 **识别是第一步**："**回溯题 60% 的分数在'题型识别'——识别对了模板一填就通，识别错了写再多也是错的方向**。五大题型关键词背熟，10 秒定位不是夸张。"

## 3. 答题流程与话术模板

### 3.1 答题三步骤（面试标准流程）

```text
① 画递归树（30 秒）:
   状态参数 / 结束条件 / 剪枝条件——画清楚再写码
② 套模板（2 分钟）:
   三要素（路径/选择列表/结束）→ "选→递→回"三步曲
③ 写剪枝（1 分钟）:
   和约束 / 去重 / 约束前置——先保证正确再优化

⚠️ 面试官期待:
  "先画递归树"是回溯题的标准开场——不画直接写 = 减分
```

### 3.2 话术模板

```text
"这题是【题型】题——【识别信号】。
状态是【参数】，结束条件是【条件】，选择列表由【控制方式】生成。
（写码）选 → 递 → 回，撤销必须做。
复杂度: 节点数 × 每节点代价 = 【O(2ⁿ)/O(n!)】，空间 O(n) 递归深度。
（被追问）可以剪枝: 【剪枝方案】不减复杂度但实际快很多。"

例: "组合题——'取 k 个'是标志。
    startIndex 控制起点防 [1,2]≡[2,1]，结束条件是长度 k。
    O(C(n,k)·k)，空间 O(k)。
    定长可加剩余数量剪枝：n−i+1 < k−path.size() 时 break。"
```

## 4. 高频追问 TOP 10

| # | 追问 | 标准回答 |
|:---:|------|---------|
| 1 | 回溯与 DFS 的区别？ | 回溯 = DFS + 撤销选择——DFS 管走、回溯管回来 |
| 2 | 组合 vs 排列？ | 组合 startIndex（顺序无关）；排列 used[]（顺序敏感） |
| 3 | 为什么必须深拷贝？ | 直接 add(path) 存引用，path 一变结果全变 |
| 4 | 忘记撤销的后果？ | 分支间状态污染——path 残留/used 未重置 |
| 5 | 可重复选传 i 还是 i+1？ | 可重复传 i（39）；不可重复传 i+1（40/77） |
| 6 | 排列去重为什么 !used[i-1]？ | 前一个用完 = 同层重复 = 跳过；used[i-1] 会误删同路径合法重复 |
| 7 | 剪枝改复杂度吗？ | 不改最坏（O(2ⁿ)/O(n!)），只减实际搜索树 |
| 8 | 子集为什么开头记录？ | 每个节点都是子集（2ⁿ 个全部）；组合只记达标叶子 |
| 9 | N皇后剪枝效果？ | 行+列+对角线：C(64,8)≈4.4×10⁹ → 约 2000 节点 |
| 10 | 求一个解 vs 所有解？ | 求一个 → boolean 返回 + 提前 return（37）；求所有 → void + 收集 |

## 5. 面试实战演练：三道真题全程

### 5.1 真题一：全排列（母题考察）

```text
面试过程示范:
  ① 识别: "排列 → used[] + 从 0 遍历"
  ② 画树: 第一层 3 选、第二层 2 选、第三层 1 选
  ③ 手撕: 46 模板（used 标记 + 撤销成对）
  ④ 复杂度: O(n·n!)，空间 O(n)
  ⑤ 追问: "有重复元素？" → 排序 + !used[i-1]（47）
```

### 5.2 真题二：组合总和 II（去重考察）

```text
面试过程示范:
  ① 识别: "组合 + 和为 target + 有重复 → 排序去重"
  ② 手撕: 40 模板（排序 + i>start 同层去重 + 传 i+1 + 和剪枝 break）
  ③ 关键点: "为什么 i>start 而非 i>0——
     同层去重、跨层保留（[1,1,6] 的两个 1 分属两层）"
  ④ 追问: "可重复选版？" → 39（传 i 不传 i+1）
```

### 5.3 真题三：N 皇后（剪枝考察）

```text
面试过程示范:
  ① 识别: "棋盘放置 → 行递归 + 约束数组"
  ② 数学: "正对角线 row−col 恒定（加偏移）、反对角线 row+col 恒定"
  ③ 手撕: 51 模板（列/两对角线三数组 + 撤销成对）
  ④ 剪枝论述: "行递归 + 三数组把 C(64,8)≈4.4×10⁹ 缩到约 2000 节点"
  ⑤ 追问: "n 更大怎么办？" → 位运算优化（整数掩码替代布尔数组）
```

> 🎯 **核心要点**：面试实战通关 = **10 秒题型识别（五大题型关键词）+ 15 题三梯队 + 答题三步骤（画树→套模板→剪枝）+ 追问 TOP 10 + 三场演练（母题/去重/剪枝）**。回溯占后端面试中等题 60%+——**模板化备考完胜随机刷题：三母题肌肉记忆 + 去重两条件 + 剪枝三连，五大题型全部覆盖**。
