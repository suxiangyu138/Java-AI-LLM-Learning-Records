## 1. 回溯模型：三要素

```text
回溯 = DFS + 状态回退（撤销选择）

三要素:
  ① 路径（path）: 已做的选择（递归参数）
  ② 选择列表: 当前可选项——
     组合/子集: [startIndex..n]（起点控制防重复）
     排列: 所有未 used 的元素（全量可选项）
  ③ 结束条件: 到达决策树底部——
     长度达标 / 和达标 / 放满棋盘

递归树:
  [1,2,3] 全排列的决策树——
  第一层选 1/2/3，第二层选剩余……
  叶子 = 完整排列；回溯 = 从叶子"撤销"回父节点

⚠️ 本质: 暴力枚举所有决策路径——
  组合/子集 O(2ⁿ)、排列 O(n!)（05 文件讲复杂度）
```

> 🎯 **核心认知**："**回溯的'回'是灵魂——递归返回后必须撤销选择（path 弹出、used 重置），否则状态污染**。三要素决定'怎么走'，撤销决定'怎么回来'，两者缺一不可。"

## 2. 通用模板与三步曲（2 分钟默写）

### 2.1 通用模板

```java
/**
 * 回溯通用模板（三步曲: 选 → 递 → 回）
 */
void backtrack(List<Integer> path, 选择列表参数) {
    if (结束条件) {
        result.add(new ArrayList<>(path));   // ① ⚠️ 深拷贝！
        return;
    }
    for (选择 : 选择列表) {
        path.add(选择);                       // ② 选（做选择）
        backtrack(path, 更新后的选择列表);     // ③ 递（递归）
        path.remove(path.size() - 1);         // ④ 回（撤销选择）！
    }
}
```

### 2.2 三步曲口诀

```text
"选 → 递 → 回":
  选: 把当前选择加入路径（path.add）
  递: 递归进入下一层（选择列表更新）
  回: 撤销选择（path.remove）—— 漏了它 = 状态污染

⚠️ 两大铁律:
  ① 深拷贝: result.add(new ArrayList<>(path))
     —— 直接 add(path) 存的是引用，path 一变结果全变
  ② 撤销必做: 递归返回后立即撤销
     —— 不撤销 = 不同分支共享污染的状态
```

> 🎯 **面试手撕节奏**："**先画递归树（状态/结束条件/剪枝），再套模板，最后写剪枝**——这是回溯题的标准答题顺序（2025 面试共识）。模板 2 分钟默写，剩下的就是'选择列表怎么生成'的题型差异。"

## 3. 46 全排列（母题一）

### 3.1 题目与思路

**题**：数组的全排列（n! 个）。

**used[] 标记已选**（排列的选择列表 = 所有未选元素）：

```java
/**
 * LeetCode 46. 全排列
 * 排列: used[] 标记已选，从 0 遍历所有未选元素
 * 时间 O(n·n!)，空间 O(n)（递归深度 + path）
 */
public List<List<Integer>> permute(int[] nums) {
    List<List<Integer>> result = new ArrayList<>();
    boolean[] used = new boolean[nums.length];
    backtrack(nums, used, new ArrayList<>(), result);
    return result;
}

private void backtrack(int[] nums, boolean[] used,
                       List<Integer> path, List<List<Integer>> result) {
    if (path.size() == nums.length) {          // ① 结束: 长度 = n
        result.add(new ArrayList<>(path));     // ② ⚠️ 深拷贝
        return;
    }
    for (int i = 0; i < nums.length; i++) {    // ③ 从 0 遍历（排列！）
        if (used[i]) continue;                 // ④ 已选跳过
        used[i] = true;                        // ⑤ 选
        path.add(nums[i]);
        backtrack(nums, used, path, result);   // ⑥ 递
        path.remove(path.size() - 1);          // ⑦ 回（撤销选择）
        used[i] = false;                       //    撤销标记！
    }
}
// 推演 [1,2,3]：第一层 3 种选择 → 第二层 2 种 → 第三层 1 种
//   共 3×2×1 = 6 个排列 ✓
// ⚠️ 排列 vs 组合的标志: 每层从 0 开始（非 startIndex）
```

## 4. 78 子集（母题二）

### 4.1 题目与思路

**题**：数组的所有子集（2ⁿ 个，含空集）。

**startIndex 控制起点** + **递归开头记录**（每个节点都是子集）：

```java
/**
 * LeetCode 78. 子集
 * 子集: startIndex 控制 + 递归开头记录（每节点都是子集）
 * 时间 O(n·2ⁿ)，空间 O(n)
 */
public List<List<Integer>> subsets(int[] nums) {
    List<List<Integer>> result = new ArrayList<>();
    backtrack(nums, 0, new ArrayList<>(), result);
    return result;
}

private void backtrack(int[] nums, int start,
                       List<Integer> path, List<List<Integer>> result) {
    result.add(new ArrayList<>(path));         // ① ⚠️ 递归开头记录！
    for (int i = start; i < nums.length; i++) {   // ② startIndex 控制
        path.add(nums[i]);                     // ③ 选
        backtrack(nums, i + 1, path, result);  // ④ 递（i+1 防重复）
        path.remove(path.size() - 1);          // ⑤ 回
    }
}
// 推演 [1,2,3]：递归树每个节点都进 result——
//   [] → [1] → [1,2] → [1,2,3] → [1,3] → [2] → [2,3] → [3]
//   共 8 个子集 ✓
// ⚠️ 记录时机: 开头（每节点）而非结束条件——
//   子集是"所有中间状态"，不是"只有叶子"
```

> 💡 **子集 vs 组合的差异**："**子集记'每个节点'（2ⁿ 个全部），组合只记'达标叶子'**（长度=k 的）——记录时机的差异是两题唯一不同，模板骨架一样。"

## 5. 77 组合（母题三）

### 5.1 题目与思路

**题**：1..n 中取 k 个数的所有组合。

**startIndex + 结束条件（长度 = k）**：

```java
/**
 * LeetCode 77. 组合
 * 组合: startIndex 控制 + 结束条件（长度 = k）
 * 时间 O(C(n,k)·k)，空间 O(k)
 */
public List<List<Integer>> combine(int n, int k) {
    List<List<Integer>> result = new ArrayList<>();
    backtrack(n, k, 1, new ArrayList<>(), result);
    return result;
}

private void backtrack(int n, int k, int start,
                       List<Integer> path, List<List<Integer>> result) {
    if (path.size() == k) {                    // ① 结束: 长度达标
        result.add(new ArrayList<>(path));
        return;
    }
    for (int i = start; i <= n; i++) {         // ② startIndex 起点
        path.add(i);                           // ③ 选
        backtrack(n, k, i + 1, path, result);  // ④ 递（i+1 防 [1,2]≡[2,1]）
        path.remove(path.size() - 1);          // ⑤ 回
    }
}
// 推演 n=4, k=2：[1,2][1,3][1,4][2,3][2,4][3,4] 共 6 个 ✓
// ⚠️ startIndex 的作用: 下一层只能从 i+1 开始——
//   [1,2] 出现后 [2,1] 不可能出现（2 层起点 ≥ 2）
```

> 🎯 **三母题对照**："**77 组合 = 78 子集 + 结束条件（长度=k）**——startIndex 同款、记录时机不同。三母题的关系：**排列管 used、子集记节点、组合等叶子**，三句话记住全部框架。"

## 6. 三母题对比：控制方式的本质

| 维度 | 46 全排列 | 78 子集 | 77 组合 |
|------|:---:|:---:|:---:|
| 遍历起点 | 0（全量） | startIndex | startIndex |
| 已选控制 | used[] | 隐式（起点之后） | 隐式（起点之后） |
| 记录时机 | 结束（长度 n） | **开头（每节点）** | 结束（长度 k） |
| 下一层参数 | 无（used 管） | i+1 | i+1 |
| 结果数 | n! | 2ⁿ | C(n,k) |

```text
本质规律:
  "顺序敏感（排列）→ used[]；顺序无关（组合/子集）→ startIndex
   全部中间状态（子集）→ 开头记录；只取叶子（组合/排列）→ 结束记录"

⚠️ 识别信号:
  "排列" 关键词 / 顺序不同算不同 → used[]
  "子集" / 任意长度 → 开头记录
  "组合 / 取 k 个" → 结束记录
```

## 7. 手写易错点与调试技巧

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 忘撤销（path 不弹） | 递归后 `path.remove(...)` | 分支状态污染 |
| 2 | 排列忘重置 used | `used[i] = false` | 后续分支全错 |
| 3 | 直接 `add(path)` | `new ArrayList<>(path)` 深拷贝 | 结果集全被污染 |
| 4 | 子集在结束记录 | 递归开头记录 | 漏掉中间子集 |
| 5 | 组合遍历从 0 | 从 start 开始 | [1,2] 与 [2,1] 重复 |
| 6 | 排列用 startIndex | 排列用 used[]（从 0） | 漏掉排列 |
| 7 | 递归参数引用污染 | path 每层新建或撤销 | 结果错误 |

**调试技巧**：

```text
① 小样例验证: n=3 排列应 6 个、子集应 8 个（对照结果数公式）
② 画递归树: 每层分支数 = 选择列表长度——分支错 = 控制方式错
③ 撤销验证: 打印 path 长度——递归返回后必须恢复原样
④ 深拷贝验证: 结果集任一元素修改后不影响其他元素
```

> 🎯 **核心要点**：回溯框架通关四件事——**① 三要素 + 三步曲烂熟**（选→递→回，撤销是灵魂）；**② 三母题默写**（46 used、78 开头记录、77 startIndex）；**③ 深拷贝铁律**（`new ArrayList<>(path)`）；**④ 控制方式识别**（顺序敏感用 used、顺序无关用 startIndex）。**三母题是全部回溯题的骨架——组合/子集/排列的区别只在'选择列表怎么生成'，模板永远不变**。
