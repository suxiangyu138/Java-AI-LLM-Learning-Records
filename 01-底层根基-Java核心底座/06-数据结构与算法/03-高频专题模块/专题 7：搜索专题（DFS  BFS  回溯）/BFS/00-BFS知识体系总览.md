## 1. 知识体系导图

```
BFS（广度优先搜索）
│
├── 核心原理 ──────────────────────────────────────────────
│   ├── 队列 + 逐层扩散（洋葱模型）
│   ├── 第一次到达 = 最短路径（无权图天然保证）
│   ├── visited 入队时标记（不是出队时！）
│   └── 层数记录：int size = q.size() 分层
│
├── 适用场景 ──────────────────────────────────────────────
│   ├── "最短/最少步数" → BFS（994/1091/127）
│   ├── "扩散到全部" → BFS（994 腐烂橘子）
│   ├── 层序相关 → BFS（102 二叉树层序）
│   └── 拓扑排序 → BFS（Kahn 算法，207/210）
│
├── 经典题型 ──────────────────────────────────────────────
│   │
│   ├── 🟢 基础 BFS
│   │   ├── 102. 二叉树层序遍历（分层模板）
│   │   ├── 199. 右视图（每层最后一个）
│   │   └── 107. 自底向上层序
│   │
│   ├── 🟡 网格 BFS
│   │   ├── 200. 岛屿数量（也可 DFS）
│   │   ├── 994. 腐烂的橘子（多源 BFS）
│   │   ├── 1091. 二进制矩阵最短路径（8 方向）
│   │   └── 1293. 网格最短路径（状态扩展）
│   │
│   ├── 🟡 多源 BFS
│   │   ├── 994. 腐烂的橘子（所有源同时入队）
│   │   ├── 542. 01 矩阵（距离最近 0）

│   ├── 🟡 状态 BFS

│   └── 🔴 双向 BFS（优化）

├── 与 DFS 的对比 ─────────────────────────────────────────
│   ├── BFS：队列/最短/空间大
│   ├── DFS：栈/路径枚举/空间小
│   └── 选择标准："最短"→BFS，"所有方案"→DFS

└── Java 实战 ─────────────────────────────────────────────

    ├── visited 入队即标记
    └── 面试话术：为什么 BFS 能找到最短
```

## 4. 核心概念速查

| 概念 | 一句话解释 | 典型例题 |
|------|-----------|------|
| **逐层扩散** | 队列按层处理（洋葱模型） | 102 层序 |
| **分层模板** | `int size = q.size()` 固定本层 | 所有 BFS |
| **入队即标记** | visited 在入队时设置（防重复入队） | 网格 BFS |
| **第一次到达即最短** | 无权图 BFS 的最短性保证 | 1091 |
| **多源 BFS** | 所有源同时入队（等价超级源点） | 994/542 |
| **状态 BFS** | 状态作为节点，转移作为边 | 127/752 |
| **双向 BFS** | 两端同时扩散，相遇即最短 | 127 优化 |
| **Kahn 拓扑** | 入度 0 入队 → 减入度 | 207/210 |
| **8 方向** | 对角也算邻居（1091） | 1091 |
| **方向数组** | `{{0,1},{0,-1},{1,0},{-1,0}}` | 网格模板 |

> 📊 基于 2025-2026 年大厂面试面经统计

| 维度 | 数据 |
|------|------|

| 最高频题 | 102 层序遍历、200 岛屿数量、994 腐烂橘子 |
