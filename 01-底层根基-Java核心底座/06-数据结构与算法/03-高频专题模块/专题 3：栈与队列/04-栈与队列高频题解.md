## 1. 394 字符串解码（双辅助栈）

### 1.1 题目与思路

**题**：`3[a2[c]]` → `accaccacc`（数字 × 括号内字符串）。

**双辅助栈**：数字栈 + 字符串栈，遇 `[` 入栈、遇 `]` 出栈拼装：

```java
/**
 * LeetCode 394. 字符串解码
 * 数字栈 + 字符串栈: 遇 [ 入栈保存现场，遇 ] 出栈还原
 * 时间 O(n)（输出长度），空间 O(n)
 */
public String decodeString(String s) {
    Deque<Integer> numStack = new ArrayDeque<>();
    Deque<StringBuilder> strStack = new ArrayDeque<>();
    StringBuilder cur = new StringBuilder();
    int num = 0;

    for (char c : s.toCharArray()) {
        if (Character.isDigit(c)) {
            num = num * 10 + (c - '0');          // ① 多位数累积
        } else if (c == '[') {
            numStack.push(num);                  // ② 保存倍数
            strStack.push(cur);                  // ③ 保存括号前字符串
            num = 0;                             // ④ 重置
            cur = new StringBuilder();
        } else if (c == ']') {
            int times = numStack.pop();
            StringBuilder prev = strStack.pop();
            for (int i = 0; i < times; i++) prev.append(cur);   // ⑤ 重复拼装
            cur = prev;                          // ⑥ 还原现场
        } else {
            cur.append(c);                       // ⑦ 普通字符
        }
    }
    return cur.toString();
}
// 推演 "3[a2[c]]"：
//   遇 [ : 存(3, "")；遇 [ : 存(2, "a")；遇 ] : cur = "a"+"cc" = "acc"
//   遇 ] : cur = "" + "acc"×3 = "accaccacc" ✓
```

> 🎯 **双栈的"现场保存"思维**："**遇 `[` 把'倍数 + 之前的字符串'入栈保存现场，遇 `]` 出栈还原拼装**——这是嵌套结构的通用栈解法（与括号匹配同构，多了数字栈）。"

## 2. 71 简化路径

### 2.1 题目与思路

**题**：Unix 路径简化（`.` 忽略、`..` 回退、`//` 合并）。

**栈模拟**：按 `/` 切分，普通段入栈、`..` 弹栈：

```java
/**
 * LeetCode 71. 简化路径
 * 时间 O(n)，空间 O(n)
 */
public String simplifyPath(String path) {
    Deque<String> stack = new ArrayDeque<>();
    for (String part : path.split("/")) {        // ① 按 / 切分
        if (part.isEmpty() || part.equals(".")) continue;  // ② 空/当前目录忽略
        if (part.equals("..")) {                 // ③ 上级目录
            if (!stack.isEmpty()) stack.pop();   //    回退（栈空则忽略）
        } else {
            stack.push(part);                    // ④ 普通目录入栈
        }
    }
    StringBuilder sb = new StringBuilder("/");
    // ⑤ 栈底 → 栈顶拼接（注意顺序）
    for (String dir : stack) { ... }             // 用 Deque 迭代顺序 = 栈底到栈顶
    return sb.toString();
}
// 推演 "/a//b/./../c"：
//   段: a 入、b 入、. 忽略、.. 弹 b、c 入 → /a/c ✓
// ⚠️ 细节: Java 的 Deque 迭代（for-each）顺序 = 栈底 → 栈顶
```

> 💡 **切分技巧**："**`split("/")` 把 `//`、`.、`..` 全部变成独立段**——题目的所有特殊情况都转化为三段规则（忽略/回退/入栈），边界处理大幅简化。"

## 3. 735 行星碰撞（配对消去进阶）

### 3.1 题目与思路

**题**：行星沿直线移动（正 = 向右、负 = 向左），相撞时大者存活、相等同归于尽。

**栈模拟**：只处理"向右的与向左的相遇"（栈顶 > 0 且当前 < 0）：

```java
/**
 * LeetCode 735. 行星碰撞
 * 时间 O(n)，空间 O(n)
 */
public int[] asteroidCollision(int[] asteroids) {
    Deque<Integer> stack = new ArrayDeque<>();

    for (int x : asteroids) {
        // ① 碰撞条件: 栈顶向右(>0) 且 当前向左(<0)
        while (!stack.isEmpty() && stack.peek() > 0 && x < 0) {
            int top = stack.peek();
            if (top < -x) {                      // ② 栈顶更小 → 被撞碎
                stack.pop();
                continue;                        //    继续与下一个栈顶比较
            } else if (top == -x) {              // ③ 相等 → 同归于尽
                stack.pop();
            }
            x = 0;                               // ④ 当前行星消失（或已处理）
            break;
        }
        if (x != 0) stack.push(x);               // ⑤ 存活则入栈
    }
    return stack.stream().mapToInt(Integer::intValue).toArray();
}
// 推演 [5,10,-5]：5,10 入；-5 撞 10 → 10 存活 → [5,10] ✓
//   [8,-8]：8 入；-8 撞 8 → 相等同归于尽 → [] ✓
// ⚠️ 同向（都正/都负）永不碰撞——条件里明确"栈顶 > 0 且当前 < 0"
```

> 🎯 **碰撞题的循环细节**："**'当前行星可能撞碎多个栈顶'→ 用 while + continue**——撞碎一个继续比下一个；'栈顶存活'则当前消失（x=0 不入栈）。这是 735 最容易写错的地方。"

## 4. 227 基本计算器 II（运算符优先级）

### 4.1 题目与思路

**题**：含 `+ - * /` 的表达式求值（无括号）。

**栈存中间结果**：加减号把操作数入栈（带符号），乘除号立即计算：

```java
/**
 * LeetCode 227. 基本计算器 II
 * 栈存中间结果: 加减入栈（带符号），乘除立即算
 * 时间 O(n)，空间 O(n)
 */
public int calculate(String s) {
    Deque<Integer> stack = new ArrayDeque<>();
    int num = 0;
    char sign = '+';                             // ① 当前操作数前的符号

    for (int i = 0; i < s.length(); i++) {
        char c = s.charAt(i);
        if (Character.isDigit(c)) {
            num = num * 10 + (c - '0');          // ② 累积数字
        }
        // ③ 遇到运算符或末尾 → 结算上一个操作数
        if ((!Character.isDigit(c) && c != ' ') || i == s.length() - 1) {
            switch (sign) {
                case '+': stack.push(num); break;                 // 加 → 入栈
                case '-': stack.push(-num); break;                // 减 → 负入栈
                case '*': stack.push(stack.pop() * num); break;   // 乘 → 立即算
                case '/': stack.push(stack.pop() / num); break;   // 除 → 立即算
            }
            sign = c;                            // ④ 更新符号
            num = 0;
        }
    }
    int result = 0;
    for (int x : stack) result += x;             // ⑤ 栈内全部相加
    return result;
}
// 推演 "3+2*2"：3 入；2 入；*2 → 弹 2 乘 2 = 4 入 → 3+4 = 7 ✓
//   " 3/2 " → 3 入；/2 → 3/2 = 1（整除截断）✓
```

> 💡 **优先级处理**："**'加减延迟入栈、乘除立即计算'让栈顶始终是'可直接相加的中间结果'**——无需处理运算符优先级比较。224（带括号）在其上加括号栈，面试可提。"

## 5. 剑指 31 栈的压入、弹出序列（栈模拟）

### 5.1 题目与思路

**题**：给定压入序列，判断弹出序列是否可能。

**模拟**：按压入序列入栈，栈顶 == 弹出序列当前 → 出栈：

```java
/**
 * 剑指 Offer 31. 栈的压入、弹出序列
 * 模拟: 入栈 → 栈顶匹配弹出序列 → 出栈
 * 时间 O(n)，空间 O(n)
 */
public boolean validateStackSequences(int[] pushed, int[] popped) {
    Deque<Integer> stack = new ArrayDeque<>();
    int j = 0;                                   // 弹出序列指针

    for (int x : pushed) {
        stack.push(x);                           // ① 按压入序列入栈
        // ② 栈顶 == 弹出序列当前 → 弹出（可能连续弹）
        while (!stack.isEmpty() && stack.peek() == popped[j]) {
            stack.pop();
            j++;
        }
    }
    return stack.isEmpty();                      // ③ 全部弹出 = 序列可行
}
// 推演 pushed=[1,2,3,4,5], popped=[4,5,3,2,1]：
//   入 1,2,3,4 → 栈顶 4 == popped[0] → 弹 4；入 5 → 弹 5 → 弹 3,2,1 ✓ true
//   popped=[4,3,5,1,2]：弹 4,3；入 5 弹 5；栈 [1,2] 顶 2 ≠ 1 → false ✓
```

## 6. 994 腐烂的橘子（多源 BFS）

### 6.1 题目与思路

**题**：腐烂橘子每分钟感染相邻新鲜橘子，求全部腐烂所需分钟（不可能则 -1）。

**多源 BFS + 层数**：所有烂橘子同时入队，扩散层数 = 分钟数：

```java
/**
 * LeetCode 994. 腐烂的橘子（多源 BFS）
 * 时间 O(m×n)，空间 O(m×n)
 */
public int orangesRotting(int[][] grid) {
    int m = grid.length, n = grid[0].length;
    Deque<int[]> queue = new ArrayDeque<>();
    int fresh = 0;

    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (grid[i][j] == 2) queue.offer(new int[]{i, j});  // ① 所有烂橘子入队
            else if (grid[i][j] == 1) fresh++;                  // ② 统计新鲜数
        }
    }
    if (fresh == 0) return 0;                    // ③ 无新鲜 → 0 分钟

    int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};
    int minutes = 0;
    while (!queue.isEmpty()) {
        int size = queue.size();                 // ④ 长度快照（每分钟一层）
        minutes++;
        for (int i = 0; i < size; i++) {
            int[] cur = queue.poll();
            for (int[] d : dirs) {
                int ni = cur[0] + d[0], nj = cur[1] + d[1];
                if (ni >= 0 && ni < m && nj >= 0 && nj < n && grid[ni][nj] == 1) {
                    grid[ni][nj] = 2;            // ⑤ 感染
                    fresh--;
                    queue.offer(new int[]{ni, nj});
                }
            }
        }
    }
    return fresh == 0 ? minutes - 1 : -1;        // ⑥ 有残留 → -1
}
// ⚠️ 层数 = 分钟: 用长度快照分层，感染完全部时 minutes−1 为答案
```
