## 1. 单调栈模型：为什么是 O(n)

```text
问题: 找每个元素的"右边第一个比它大的元素"（下一个更大）
暴力: 每个元素向后扫 → O(n²)

单调栈: 维护栈内元素单调（递减栈 = 栈底到栈顶递减）——
  "当前元素 > 栈顶"时，当前元素就是栈顶的"下一个更大"
  → 弹出栈顶并记录答案 → 当前元素入栈

为什么 O(n):
  每个元素最多入栈一次、出栈一次 → 摊还 O(n)

⚠️ 三条铁律:
  ① 存下标不存值（既要值也要位置——算距离/宽度）
  ② 出栈用 while（当前元素可能大于多个栈顶）
  ③ 单调性选择:
     递减栈（栈顶最小）→ 找下一个更大元素
     递增栈（栈顶最大）→ 找下一个更小元素 / 直方图
```

> 🎯 **核心认知**："**单调栈 = 用'延迟结算'替代'立即扫描'**——栈顶元素暂时找不到答案就留着，等它的'下一个更大'到来时一起结算。**每个元素被结算一次，这就是 O(n) 的来源**。"

## 2. 739 每日温度（母题）

### 2.1 题目与思路

**题**：每个温度要等几天才出现更高温度。

**递减栈**：当前温度 > 栈顶温度 → 弹出并结算天数差：

```java
/**
 * LeetCode 739. 每日温度（单调栈母题）
 * 时间 O(n)，空间 O(n)
 */
public int[] dailyTemperatures(int[] temperatures) {
    int n = temperatures.length;
    int[] result = new int[n];
    Deque<Integer> stack = new ArrayDeque<>();   // 存下标，值递减

    for (int i = 0; i < n; i++) {
        // ① 当前温度 > 栈顶温度 → 栈顶的"下一个更大"就是今天
        while (!stack.isEmpty()
               && temperatures[i] > temperatures[stack.peek()]) {
            int idx = stack.pop();
            result[idx] = i - idx;               // ② 结算天数差
        }
        stack.push(i);                           // ③ 当前下标入栈
    }
    return result;                               // ④ 栈里剩下的 = 无更高（0）
}
// 推演 [73,74,75,71,69,72,76,73]：
//   i=1(74): 弹出 0(73) → ans[0]=1；i=2(75): 弹出 1 → ans[1]=1
//   i=5(72): 弹出 4(69)→ans[4]=1；弹出 3(71)→ans[3]=2
//   i=6(76): 弹出 5(72)→ans[5]=1；弹出 2(75)→ans[2]=4
//   最终 [1,1,4,2,1,1,0,0] ✓
```

> 🎯 **739 的母题地位**："**739 是单调栈的入门与总纲**——'弹出结算'的节奏在 496/503/901/42/84 中全部复用。能 5 分钟默写 739，单调栈家族就过了一半。"

## 3. 496 下一个更大元素 I（单调栈 + 哈希）

### 3.1 题目与思路

**题**：nums1 是 nums2 的子集，求 nums1 每个元素在 nums2 中的下一个更大。

**单调栈处理 nums2 + 哈希记录答案**：一次遍历算出 nums2 所有元素的下一个更大，存进映射：

```java
/**
 * LeetCode 496. 下一个更大元素 I
 * 单调栈处理 nums2 + HashMap 记录每个元素的下一个更大
 * 时间 O(m+n)，空间 O(n)
 */
public int[] nextGreaterElement(int[] nums1, int[] nums2) {
    Map<Integer, Integer> nextGreater = new HashMap<>();
    Deque<Integer> stack = new ArrayDeque<>();

    for (int x : nums2) {
        while (!stack.isEmpty() && x > stack.peek()) {
            nextGreater.put(stack.pop(), x);     // ① 弹出者 → 答案 x
        }
        stack.push(x);
    }
    // ② 栈里剩余的没有更大 → 默认 -1（getOrDefault）

    int[] result = new int[nums1.length];
    for (int i = 0; i < nums1.length; i++) {
        result[i] = nextGreater.getOrDefault(nums1[i], -1);
    }
    return result;
}
// 推演 nums2=[4,1,2], nums1=[1,2]：
//   nextGreater: {1:2, 2:-1(不入映射), 4:-1}
//   → [2, -1] ✓
```

> 💡 **变体意识**："**496 = 739 的模板 + 哈希映射**——'先算全量答案再查表'是'子集查询'类题的标配（与专题 1 的哈希技巧同源）。"

## 4. 503 下一个更大元素 II（循环取模）

### 4.1 题目与思路

**题**：循环数组（末尾接开头）的下一个更大。

**取模模拟环**：遍历 2n 次，下标用 `i % n`：

```java
/**
 * LeetCode 503. 下一个更大元素 II（循环数组）
 * 遍历 2n 次 + i % n → 每个元素在环中都有机会遇到"下一个更大"
 * 时间 O(n)，空间 O(n)
 */
public int[] nextGreaterElements(int[] nums) {
    int n = nums.length;
    int[] result = new int[n];
    Arrays.fill(result, -1);                       // ① 默认 -1（无更大）
    Deque<Integer> stack = new ArrayDeque<>();

    for (int i = 0; i < 2 * n; i++) {              // ② 环 = 遍历两遍
        int idx = i % n;
        while (!stack.isEmpty() && nums[idx] > nums[stack.peek()]) {
            result[stack.pop()] = nums[idx];       // ③ 结算（覆盖无害——同值）
        }
        if (i < n) stack.push(idx);                // ④ 只在第一遍入栈（防重复）
    }
    return result;
}
// 推演 [1,2,1]：
//   第一遍: ans[0]=2；第二遍 i=3(idx=0,1): 栈顶 2(1) < 1? 否 → 不动
//   i=4(idx=1,2): 弹出 2(1) → ans[2]=2；弹出 0(1) → ans[0]=2（覆盖同值）
//   最终 [2,-1,2] ✓
// ⚠️ 只在第一遍入栈: 防止同一元素入栈两次导致重复结算
```

## 5. 84 柱状图中最大的矩形（递增栈 + 补 0）

### 5.1 题目与思路

**题**：直方图中最大矩形面积（O(n)）。

**递增栈**：找每个柱子的"左右第一个更矮"——弹出时结算：`高 = 柱子高，宽 = 右边界 − 左边界 − 1`：

```java
/**
 * LeetCode 84. 柱状图中最大的矩形
 * 递增栈（找左右第一个更矮）+ 首尾补 0
 * 时间 O(n)，空间 O(n)
 * ⚠️ 头补 0: 免栈空判断；尾补 0: 强制弹出所有剩余柱子
 */
public int largestRectangleArea(int[] heights) {
    int n = heights.length;
    int[] h = new int[n + 2];                      // ① 首尾补 0
    System.arraycopy(heights, 0, h, 1, n);

    Deque<Integer> stack = new ArrayDeque<>();     // 递增栈（存下标）
    int best = 0;
    for (int i = 0; i < h.length; i++) {
        while (!stack.isEmpty() && h[i] < h[stack.peek()]) {
            int height = h[stack.pop()];           // ② 弹出的柱子
            int left = stack.peek();               // ③ 左边界 = 新栈顶
            int width = i - left - 1;              // ④ 右边界 = i
            best = Math.max(best, height * width); // ⑤ 结算面积
        }
        stack.push(i);
    }
    return best;
}
// 推演 [2,1,5,6,2,3]（补 0 → [0,2,1,5,6,2,3,0]）：
//   i=5(2): 弹出 4(6): 高6, 左=3, 宽=1 → 6；弹出 3(5): 高5, 左=2, 宽=2 → 10
//   i=7(0): 弹出 6(3): 高3, 左=5, 宽=1 → 3；弹出 5(2): 高2, 左=2, 宽=4 → 8
//            弹出 2(1): 高1, 左=0, 宽=6 → 6
//   最大 = 10 ✓
```

> 🎯 **84 的教科书价值**："**'弹出即结算 + 左右边界取自栈'是直方图题的标准姿势**——首尾补 0 的两个作用（免空栈/强制清栈）是面试必答细节。84 会了，85 最大矩形（二维转一维）直接套。"

## 6. 42 接雨水（单调栈横向累加）

### 6.1 题目与思路

**题**：柱子间接雨水量（O(n) 单调栈版；对撞 O(1) 版见专题 1）。

**递减栈 + 横向累加**：当前柱子 > 栈顶 → 栈顶是凹槽底，弹出后新栈顶是左壁、当前是右壁：

```java
/**
 * LeetCode 42. 接雨水（单调栈版）
 * 递减栈: 当前 > 栈顶 → 栈顶是凹底，弹出后新栈顶是左壁
 * 时间 O(n)，空间 O(n)（横向逐层累加）
 */
public int trap(int[] height) {
    Deque<Integer> stack = new ArrayDeque<>();     // 递减栈（存下标）
    int water = 0;

    for (int i = 0; i < height.length; i++) {
        while (!stack.isEmpty() && height[i] > height[stack.peek()]) {
            int bottom = height[stack.pop()];      // ① 凹槽底
            if (stack.isEmpty()) break;            // ② 左边无墙 → 接不住
            int left = stack.peek();               // ③ 左壁
            int h = Math.min(height[left], height[i]) - bottom;  // ④ 水位高
            int w = i - left - 1;                  // ⑤ 槽宽
            water += h * w;                        // ⑥ 横向逐层累加
        }
        stack.push(i);
    }
    return water;
}
// 推演 [0,1,0,2,1,0,1,3,2,1,2,1]：
//   i=3(2): 弹出 2(0): 底0, 左=1(1), 高=min(1,2)-0=1, 宽=1 → +1
//   i=6(1): 弹出 5(0): 高=1, 宽=1 → +1
//   i=7(3): 弹出 6(1): 高=0；弹出 4(1): 底1, 左=3(2), 高=min(2,3)-1=1, 宽=3 → +3
//   i=10(2): 弹出 9(1): 底1, 左=8(2), 高=1, 宽=1 → +1
//   累计 6 ✓
```

> 💡 **42 的双解法**："**对撞版 O(1) 空间（专题 1）与单调栈版 O(n) 空间是两种思维**——对撞是'哪边确定处理哪边'，单调栈是'凹槽逐层结算'。面试给单调栈版能顺便讲对撞版，就是双解法展示。"

## 7. 单调栈家族与易错点

### 7.1 家族一览

| 题 | 栈的单调性 | 结算时机 | 与母题关系 |
|:---:|:---:|------|------|
| 739 每日温度 | 递减 | 弹出时算距离 | 母题 |
| 496 下一个更大 I | 递减 | 弹出时记哈希 | 739 + 哈希 |
| 503 下一个更大 II | 递减 | 弹出时记数组 | 739 + 取模 |
| 901 股票跨度 | 递减 | 弹出时累计跨度 | 739 反向 |
| 84 最大矩形 | 递增 | 弹出时算面积 | 递增版 + 补 0 |
| 42 接雨水 | 递减 | 弹出时横向累加 | 739 + 凹槽结算 |
| 907 子数组最小值 | 递增 | 左右边界贡献 | 84 的贡献法 |

### 7.2 易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 栈里存值 | 存**下标** | 算不了距离/宽度 |
| 2 | 出栈用 if | 用 while | 多个栈顶漏结算 |
| 3 | 84 忘补 0 | 首尾补 0 | 栈空判断/剩余未结算 |
| 4 | 503 第二遍也入栈 | 只在第一遍入栈 | 重复结算 |
| 5 | 42 弹出后栈空仍算 | `if (stack.isEmpty()) break` | 虚增水量 |
| 6 | 单调性选反 | 找更大用递减、找更小用递增 | 答案全错 |
| 7 | 84 宽度公式错 | `i − 左边界 − 1` | 面积错 |

> 🎯 **核心要点**：单调栈通关四件事——**① 三条铁律烂熟**（存下标、while 弹出、单调性选择）；**② 739 母题 5 分钟默写**；**③ 84 补 0 技巧 + 宽度公式**（头免空栈、尾强制清栈）；**④ 42 凹槽结算**（底/左壁/右壁三要素）。**单调栈是把 O(n²) 暴力变成 O(n) 的窗口思维——'弹出即结算'这一句，就是整个家族的总纲**。
