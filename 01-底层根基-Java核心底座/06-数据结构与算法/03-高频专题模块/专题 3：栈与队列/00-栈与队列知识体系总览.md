## 5. 解题模式速查

### 5.1 六大模式 → 题 → 识别信号

| 模式 | 识别信号 | 核心技巧 | 代表题 |
|------|------|------|------|
| 配对消去 | "括号/相邻重复/碰撞" | 栈 + 对称性 | 20/1047/735 |
| 辅助栈 | "O(1) 求最值/互相实现" | 双栈协作 | 155/232/225 |
| 表达式求值 | "计算器/逆波兰" | 栈 + 优先级 | 150/227/394 |
| 单调栈 | "下一个更大/更小" | 存下标 + 踢破坏者 | 739/496/84 |
| 单调队列 | "窗口最值" | 队头过期 + 队尾踢小 | 239/1438 |
| 循环队列 | "设计/环形" | k+1 槽数组 | 622/641 |

### 5.2 栈 vs 队列选型

```text
栈（LIFO）: 配对、消除、逆序、回溯、嵌套匹配
队列（FIFO）: 顺序处理、BFS、滑动窗口、数据流

⚠️ 一句话: "要'最近配对'用栈，要'按序处理'用队列；
   找'下一个更大'用单调栈，取'窗口最值'用单调队列"
```

> 🎯 **一句话定位**："**栈解决'回溯/配对'，队列解决'顺序/扩散'，单调栈/单调队列是把 O(n²) 暴力优化到 O(n) 的窗口思维**——四大核心模式（配对/单调栈/单调队列/循环队列）覆盖栈队列 90% 的面试题。"

## 6. 常见误区速查

| 误区 | 正解 |
|------|------|
| "栈/队列弹出前不用判空" | ❌ 空栈取顶/出栈直接崩溃——弹前必判空（第一易错点） |
| "单调栈存值就行" | ❌ 存**下标**——既要值也要位置（算距离/宽度） |
| "单调栈出栈用 if" | ❌ 用 while——当前元素可能大于多个栈顶 |
| "239 的单调队列是通用队列" | ❌ 是"专用结构"——只为本题设计，不同题写法不同 |
| "循环数组题目要复制数组" | ❌ 取模模拟遍历（i % n），O(1) 额外空间 |
| "最小栈只用一个栈" | ❌ 辅助栈同步存最小值（push 用 <= 处理重复最小值） |
| "层序遍历不用快照" | ❌ 不记录长度会把下一层混进本层 |
| "栈只能用于括号题" | ❌ 单调栈（739/84/42）是栈的最大应用面 |
| "队列实现栈要两个队列" | ❌ 单队列旋转即可（前 n−1 个重入队尾） |
| "232 每次 pop 都倒数据" | ❌ 仅当 stOut 为空时才从 stIn 全量导入（摊还 O(1)） |
