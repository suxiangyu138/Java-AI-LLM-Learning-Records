## 1. 栈模型：LIFO 与配对消去

```text
栈 = 受限的线性表（只能栈顶进出）:
  push O(1) / pop O(1) / peek O(1) / isEmpty O(1)

两大直觉:
  ① 配对消去: 最近的两个"对称元素"互相抵消
     → 括号、相邻重复、行星碰撞、回文配对
  ② 回溯记录: 记住"上一个状态"，需要时回退
     → 路径、表达式、迭代遍历

实现: 数组（顺序栈，扩容 O(n) 摊还）或链表（链式栈）
  → Java 工程默认 ArrayDeque（栈应避免用 Stack 类——遗留类）
```

> 🎯 **核心动作三连**：**入栈（记录状态）→ 判栈顶（配对/比较）→ 出栈（消去/回退）**。栈题 80% 是"入栈 + 满足条件出栈"的节奏，剩下 20% 是单调栈（02 文件）。

## 2. 20 有效的括号（三种不匹配场景）

### 2.1 题目与思路

**题**：括号字符串是否有效（()[]{} 嵌套）。

**先分析三种不匹配场景**（写码前的关键步骤）：

```text
场景一（左括号多了）: "(()"  → 遍历完栈不为空
场景二（右括号多了）: "())"  → 匹配时栈已空
场景三（类型不匹配）: "(]"   → 栈顶与当前右括号不对应
```

### 2.2 完整代码（右括号入栈技巧）

```java
/**
 * LeetCode 20. 有效的括号
 * 技巧: 遇左括号入"对应的右括号"→ 遇右括号只需比栈顶
 * 时间 O(n)，空间 O(n)
 */
public boolean isValid(String s) {
    Deque<Character> stack = new ArrayDeque<>();
    for (char c : s.toCharArray()) {
        if (c == '(') stack.push(')');       // ① 左括号入对应右括号
        else if (c == '[') stack.push(']');
        else if (c == '{') stack.push('}');
        else {                               // ② 右括号
            if (stack.isEmpty() || stack.pop() != c) return false;
            // 场景二（空栈）+ 场景三（不匹配）一起判
        }
    }
    return stack.isEmpty();                  // ③ 场景一（左括号多）
}
// 推演 "([)]"：入 ')'（对应 '('）、入 ']'（对应 '['）
//   遇 ')' → 弹出 ']' ≠ ')' → false ✓（交叉嵌套被正确拒绝）
// 推演 "()[]{}"：逐对匹配 → 栈空 → true ✓

好，推演注释应该写：`"([)]"`：入 `)`、入 `]`；遇 `)` → 弹出 `]` ≠ `)` → false ✓（交叉嵌套被正确拒绝）。

## 3. 155 最小栈（辅助栈 + <= 细节）

### 3.1 题目与思路

**题**：O(1) 取最小值（普通栈做不到——栈顶不是最小）。

**辅助栈**：每次 push 同时把"当前最小值"压入辅助栈：

```java
/**
 * LeetCode 155. 最小栈（辅助栈）
 * 时间 O(1) 全操作，空间 O(n)
 */
class MinStack {
    private final Deque<Integer> stack = new ArrayDeque<>();
    private final Deque<Integer> minStack = new ArrayDeque<>();

    public void push(int val) {
        stack.push(val);
        // ⚠️ 用 <= 而非 <: 重复最小值也要入辅助栈，
        //   否则最小值出栈后辅助栈同步错误
        int min = minStack.isEmpty() ? val : Math.min(val, minStack.peek());
        minStack.push(min);
    }

    public void pop() {
        stack.pop();
        minStack.pop();                    // 同步弹出
    }

    public int top() { return stack.peek(); }

    public int getMin() { return minStack.peek(); }   // O(1)！
}
// 推演 push 2,3,1,1 → minStack: [2,2,1,1]
//   pop() → minStack 弹 1 → getMin() = 1（还有一个 1）✓
// ⚠️ 若用 < : push 2,3,1,1 → minStack: [2,2,1]（第二个 1 不入）
//   pop() 后 getMin() 应为 1 却返回 2 → 错误！
```

> 💡 **`<=` 细节的面试价值**："**重复最小值场景是 155 的隐藏考点**——push 用 `<=` 让辅助栈与主栈严格同步，pop 才不会错。能主动说出这个细节，比背代码高级。"

## 4. 232 用栈实现队列（摊还 O(1) 双栈）

### 4.1 题目与思路

**题**：用两个栈实现队列的 push/pop/peek（FIFO）。

**入出分离**：stIn 负责入队，stOut 负责出队——**仅当 stOut 为空时才从 stIn 全量倒入**：

```java
/**
 * LeetCode 232. 用栈实现队列
 * stIn 入队 / stOut 出队；stOut 空时才倒数据
 * 摊还 O(1)：每个元素只倒一次
 */
class MyQueue {
    private final Deque<Integer> stIn = new ArrayDeque<>();
    private final Deque<Integer> stOut = new ArrayDeque<>();

    public void push(int x) {
        stIn.push(x);                        // ① 入队只进 stIn
    }

    public int pop() {
        transfer();                          // ② 确保 stOut 有数据
        return stOut.pop();
    }

    public int peek() {
        transfer();
        return stOut.peek();
    }

    private void transfer() {
        // ⚠️ 仅当 stOut 为空才倒——保证 FIFO 顺序与摊还 O(1)
        if (stOut.isEmpty()) {
            while (!stIn.isEmpty()) stOut.push(stIn.pop());
        }
    }
}
// 推演 push 1,2,3；pop → transfer: stOut=[3,2,1] → pop=1 ✓
//   push 4 → stIn=[4]（stOut 还有 2,3 不倒！）
//   pop → stOut 弹 2 ✓（顺序不乱）✓
```

> 🎯 **摊还分析的面试价值**："**'stOut 空才倒'保证每个元素恰好被倒一次**——总 O(n) 摊到 n 次操作 = 每次 O(1)。如果每次 pop 都倒，最坏 O(n)。能讲出摊还论证，232 就是满分。"

## 5. 225 用队列实现栈（单队列旋转）

### 5.1 题目与思路

**题**：用队列实现栈（LIFO）。

**单队列旋转**：push 时把前面的元素重新排到新元素后面：

```java
/**
 * LeetCode 225. 用队列实现栈（单队列旋转）
 * 核心: push 后把前 n−1 个重新入队尾 → 队头即"栈顶"
 */
class MyStack {
    private final Deque<Integer> queue = new ArrayDeque<>();

    public void push(int x) {
        queue.offer(x);                      // ① 先入队
        // ② 旋转: 把前面的 n−1 个移到 x 后面
        for (int i = 0; i < queue.size() - 1; i++) {
            queue.offer(queue.poll());
        }
    }

    public int pop() { return queue.poll(); }        // 队头 = 栈顶
    public int top() { return queue.peek(); }
    public boolean empty() { return queue.isEmpty(); }
}
// 推演 push 1 → [1]；push 2 → [2,1]；push 3 → [3,2,1]
//   pop → 3 ✓（LIFO 达成！）
// ⚠️ push O(n)，其余 O(1)；也可以用双队列版（push O(1)，pop O(n)）
```

> 💡 **对比 232**："232 双栈（入 O(1)/出摊还 O(1)）比 225 单队列（入 O(n)）效率高——**'互相实现'题的本质是选择'让哪个操作 O(1)'**，面试要讲清这个权衡。"

## 6. 150 逆波兰表达式求值（弹出顺序陷阱）

### 6.1 题目与思路

**题**：后缀表达式求值（2 1 + 3 * = 9）。

**栈模拟**：数字入栈，遇运算符弹两个计算压回——**⚠️ 第一个弹出的是右操作数**：

```java
/**
 * LeetCode 150. 逆波兰表达式求值
 * 时间 O(n)，空间 O(n)
 */
public int evalRPN(String[] tokens) {
    Deque<Integer> stack = new ArrayDeque<>();
    for (String token : tokens) {
        switch (token) {
            case "+": {
                int b = stack.pop();         // ⚠️ 先弹的是右操作数！
                int a = stack.pop();         // 后弹的是左操作数
                stack.push(a + b);
                break;
            }
            case "-": {
                int b = stack.pop();
                int a = stack.pop();
                stack.push(a - b);           // ⚠️ a−b 不是 b−a！
                break;
            }
            case "*": {
                int b = stack.pop();
                int a = stack.pop();
                stack.push(a * b);
                break;
            }
            case "/": {
                int b = stack.pop();
                int a = stack.pop();
                stack.push(a / b);           // ⚠️ 整除截断
                break;
            }
            default:
                stack.push(Integer.parseInt(token));
        }
    }
    return stack.pop();
}
// 推演 ["2","1","-","3","*"]：
//   遇 - : b=1, a=2 → 2−1=1；遇 * : b=3, a=1 → 3 → 答案 3 ✓
// ⚠️ 易错: 除法/减法顺序反 → 结果错误（最常见失分点）
```

> 🎯 **弹出顺序的教训**："**'先弹右、后弹左'是栈模拟计算的通用规则**——150 的减法/除法顺序、227 计算器的操作数处理都是同一个坑。写出 `int b = pop(); int a = pop();` 的习惯性命名，就是防错的第一步。"

## 7. 配对消去家族与易错点

### 7.1 配对消去家族

| 题 | 配对规则 | 与 20 的关系 |
|:---:|------|------|
| 20 有效括号 | 左右括号对称 | 母题 |
| 1047 删除相邻重复 | 相邻相等消去 | 栈顶比较（更简单） |
| 735 行星碰撞 | 正负相遇消去 | 栈顶符号判断（04 文件） |
| 剑指 31 压入弹出 | 模拟 push/pop 序列 | 栈模拟（04 文件） |
| 394 字符串解码 | 数字与字符串配对 | 双辅助栈（04 文件） |

### 7.2 易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 弹出前不判空 | `if (stack.isEmpty()) return false` | 空栈崩溃 |
| 2 | 20 左括号直接入栈 | 入"对应右括号"（简化比较） | 多一次映射判断 |
| 3 | 155 辅助栈用 `<` | 用 `<=` | 重复最小值同步错误 |
| 4 | 232 每次 pop 都倒数据 | stOut 空才倒 | 最坏 O(n) |
| 5 | 150 减除法顺序反 | 先弹右、后弹左 | 结果错误 |
| 6 | 用 Stack 类 | ArrayDeque（Stack 是遗留类） | 性能差/官方不推荐 |
| 7 | 225 旋转次数错 | `size()−1` 次 | 栈序错误 |

> 🎯 **核心要点**：栈基础通关四件事——**① 20 括号三场景先分析后写码**（左多/右多/不匹配）；**② 双栈协作两题全会**（155 辅助栈 `<=` 细节、232 摊还论证）；**③ 150 弹出顺序烂熟**（先弹右后弹左）；**④ 弹前判空成肌肉记忆**。**配对消去是栈的第一直觉——20 会了，1047/735/剑指 31 全是它的变体**。
