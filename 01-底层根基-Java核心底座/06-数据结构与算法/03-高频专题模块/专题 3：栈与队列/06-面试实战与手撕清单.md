## 2. 话术模板与复杂度速答

### 2.1 通用话术模板

```text
"这题是【模式】题，因为【识别信号】。
我的方案: 【模板描述】。时间 O(【复杂度】)，空间 O(【复杂度】）。
（写完）验证样例: ……；边界: 空栈/满/单元素。

例: "这是单调栈题——找右边第一个更大的数。
    递减栈存下标，当前元素大于栈顶时弹出结算。
    O(n)（每元素入出栈各一次）。验证 [73,74,...]；边界：空数组。"
```

### 2.2 复杂度速答表

| 模式 | 时间 | 空间 | 关键 |
|------|:---:|:---:|------|
| 括号/配对 | O(n) | O(n) | 栈 + 对称 |
| 辅助栈（155） | O(1) 全操作 | O(n) | 同步最小 |
| 双栈队列 | O(1) 摊还 | O(n) | 空才倒 |
| 单调栈 | O(n) | O(n) | 存下标 + while |
| 单调队列 | O(n) | O(k) | 踢小 + 过期 |
| 循环队列 | O(1) 全操作 | O(k) | k+1 槽 |
| BFS | O(V+E) | O(V) | 队列 + 标记 |

## 3. 高频追问 TOP 10

| # | 追问 | 标准回答 |
|:---:|------|---------|
| 1 | 为什么单调栈是 O(n)？ | 每个元素入栈/出栈各一次，摊还 O(n) |
| 2 | 单调栈为什么存下标？ | 既要值也要位置（算距离/宽度）；重复值场景必须下标 |
| 3 | 739 与 84 的栈有什么区别？ | 739 递减栈（找更大）；84 递增栈（找更小/直方图） |
| 4 | 239 为什么"踢小"不丢答案？ | 更小且更旧的元素永远不可能成为窗口最大 |
| 5 | 239 队头过期判断？ | `deque.peekFirst() <= i − k` 弹出 |
| 6 | 622 为什么 k+1 槽？ | 牺牲一格换"空/满"用指针关系判定，免标志位 |
| 7 | 232 为什么摊还 O(1)？ | 每个元素只倒一次（stOut 空才倒） |
| 8 | 155 辅助栈为什么用 <=？ | 重复最小值也要同步，否则弹出后最小值错位 |
| 9 | BFS 与 DFS 怎么选？ | 最短路/按层 → BFS；路径枚举/回溯 → DFS |
| 10 | 20 括号三种不匹配？ | 左多（栈不空）/右多（空栈）/类型错（栈顶不匹配） |

## 4. 笔试题型与常见陷阱

### 4.1 笔试高频题型

| 题型 | 示例 | 注意 |
|------|------|------|
| 母题默写 | 20/155/102 | 2 分钟内，边界全覆盖 |
| 单调性变体 | 739→496/503/901 | 模板迁移（哈希/取模/跨度） |
| 设计题 | 622/641/232 | 选型论述 + 边界 |
| 计算题 | 中缀转后缀 | 优先级规则（227 变体） |
| 组合题 | 单调队列+DP（1696） | 结构组合意识 |

### 4.2 常见陷阱

```text
① 弹出前不判空 → 崩溃（第一 bug 源）
② 单调栈存值不存下标 → 算不了距离
③ 出栈用 if 不用 while → 多个栈顶漏结算
④ 84 忘补 0 → 空栈判断/剩余未结算
⑤ 层序忘快照 → 本层混入下一层
⑥ 232 每次 pop 都倒 → 摊还失效
⑦ 循环数组忘取模 → 越界
⑧ 150 减除法顺序反 → 结果错

⚠️ 通用原则: 写完 30 秒自查——
  ① 空栈/空队列路径判了吗？
  ② 栈里存的是值还是下标？
  ③ 环形操作取模了吗？
```

## 5. 面试实战演练：三道真题全程

### 5.1 真题一：每日温度（单调栈母题）

```text
面试过程示范:
  ① 定位: "找右边第一个更大的 → 单调递减栈存下标"
  ② 手撕: 739 模板（while 弹出结算 i−idx）
  ③ 复杂度: O(n) 摊还——"每个元素入出栈各一次"
  ④ 追问: "496/503 变体？" → 哈希记录 / 2n 遍历取模
  ⑤ 追问: "为什么递减？" → 栈顶最小，当前更大时即可结算
```

### 5.2 真题二：滑动窗口最大值（单调队列）

```text
面试过程示范:
  ① 定位: "窗口最值 → 单调递减队列（存下标）"
  ② 手撕: 239 模板（队尾踢小 → 入队 → 队头过期 → 取头）
  ③ 复杂度: O(n) 摊还——"每元素进出队列各一次"
  ④ 追问: "为什么不用堆？" → 堆 O(n log k) 且无法 O(1) 取窗口内过期元素
  ⑤ 追问: "1438 变体？" → 双单调队列（最大 + 最小）
```

### 5.3 真题三：设计循环队列（设计题）

```text
面试过程示范:
  ① 选型: "环形数组——O(1) 全操作；k+1 槽免标志位"
  ② 手撕: 622 完整类（head/tail + 取模 + 四方法）
  ③ 边界: 空/满/单元素/容量 1 逐一说
  ④ 追问: "641 双端怎么加？" → 头插退指针 + 尾删退指针
  ⑤ 追问: "生产者-消费者场景？" → 环形缓冲区 + 并发加锁（并发专题）
```
