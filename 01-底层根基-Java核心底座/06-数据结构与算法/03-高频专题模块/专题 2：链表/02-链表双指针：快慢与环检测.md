## 1. 快慢指针模板：为什么慢 1 快 2

```java
// 快慢指针统一模板（环检测/中点/倒数第 K 三合一）
ListNode slow = head, fast = head;
while (fast != null && fast.next != null) {   // ⚠️ 快指针双判空（防空指针）
    slow = slow.next;                          // 慢走 1 步
    fast = fast.next.next;                     // 快走 2 步
    // 环检测: if (slow == fast) return true;
}
// 结束后 slow 的位置依题而读: 中点 / 相遇点 / 目标前驱
```

**为什么速度差必须 = 1**：

```text
有环时: slow 进环后，fast 已经在环内（距离 d）
  每轮 fast 追近 slow 1 步（2−1）→ 必在 d 步内追上 → 必相遇 ✓

如果快指针走 3 步:
  每轮追近 2 步 → 相遇与否取决于 d 与环长的整除关系
  → 可能永远追不上（绕圈打转）→ 判圈失败

⚠️ 结论: "慢 1 快 2"不是随意选择——
  速度差 1 保证"无论环长和初始距离如何，必相遇"（2025 面试追问点）
```

> 🎯 **核心认知**："快慢指针的威力 = **同一个模板，四种读法**——判环读相遇、找中点读 slow、倒数第 K 改步差、相交换路读相遇。模板背熟，四题 10 分钟。"

## 2. 141 环形链表（Floyd 判圈）

### 2.1 完整代码

```java
/**
 * LeetCode 141. 环形链表（Floyd 判圈）
 * 慢 1 快 2: 有环必相遇，无环 fast 先到 null
 * 时间 O(n)，空间 O(1)
 */
public boolean hasCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {   // ① 双判空
        slow = slow.next;                         // ② 慢 1
        fast = fast.next.next;                    // ③ 快 2
        if (slow == fast) return true;            // ④ 相遇 = 有环
    }
    return false;                                 // ⑤ 到 null = 无环
}
// 边界: 空链表 / 单节点 / 双节点自环 全部覆盖（双判空 + slow==fast）
```

> 💡 **为什么不用哈希表**："141 要求 O(1) 空间——**哈希表 O(n) 空间不达标**；Floyd 用'速度差 1 必相遇'做到 O(1)。'快 2 慢 1'的必遇性证明是面试追问的加分点。"

## 3. 142 环形链表 II（找入口，数学推导）

### 3.1 两阶段法

```java
/**
 * LeetCode 142. 环形链表 II（找环入口）
 * 阶段一: 快慢找相遇点；阶段二: 重置 head，同速走，再遇 = 入口
 * 时间 O(n)，空间 O(1)
 */
public ListNode detectCycle(ListNode head) {
    ListNode slow = head, fast = head;

    // ① 阶段一: 找相遇点（同 141）
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) break;
    }
    if (fast == null || fast.next == null) return null;   // ② 无环

    // ③ 阶段二: slow 重置 head，两者同速走 1 步
    slow = head;
    while (slow != fast) {
        slow = slow.next;
        fast = fast.next;
    }
    return slow;                              // ④ 再遇点 = 环入口
}
```

### 3.2 数学推导（面试必答）

```text
设: 头到入口 = L，环长 = C，入口到相遇点（沿前进方向）= N

slow 路程 = L + N
fast 路程 = L + N + xC（多绕 x 圈）→ 且 fast = 2 × slow
  → L + N + xC = 2(L + N)
  → L = xC − N = (x−1)C + (C−N)

其中 (C−N) = 相遇点沿前进方向到入口的距离
  → L ≡ (C−N) (mod C)

所以: 重置 slow 到 head，两者同速走 L 步——
  slow 走 L 步到入口；fast 从相遇点走 L 步 = (x−1)C + (C−N) 步
  → 恰好绕 (x−1) 圈再走 (C−N) 到入口 → 两者在入口相遇 ✓
```

> 🎯 **142 的面试价值**："**'相遇后重置同速'背后的模运算推导是链表面试的深度试金石**——能现场推导 L ≡ (C−N) (mod C) 的候选人，链表功底一眼可见。背结论不推导，追问就露馅。"

## 4. 876 链表的中间结点（快慢找中点）

### 4.1 完整代码

```java
/**
 * LeetCode 876. 链表的中间结点
 * 慢 1 快 2: fast 到尾时 slow 即中点
 * 偶数长度: 返回第二个中间节点（题目的定义）
 * 时间 O(n)，空间 O(1)
 */
public ListNode middleNode(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;                    // ① 慢走 1
        fast = fast.next.next;               // ② 快走 2
    }
    return slow;                             // ③ 中点
}
// 推演 [1,2,3,4,5]：slow: 1→2→3；fast: 1→3→5(null 前) → 返回 3 ✓
//   [1,2,3,4,5,6]：slow: 1→2→3→4 → 返回 4（第二个中点）✓
// ⚠️ 变体: 若需"前半的尾"（143/148 用），fast 从 head.next 起步
//   → slow 停在第一个中点（左半尾）——见 04/05 文件
```

> 💡 **为什么中点重要**："**找中点是 143 重排、148 排序链表、234 回文的前置步骤**——一个 876 通吃三个组合题，是快慢指针的'基建'。"

## 5. 19 删除链表的倒数第 N 个结点

### 5.1 题目与思路

**题**：删除倒数第 N 个（哑结点必需——可能删头节点）。

**步差法**：fast 先走 N 步 → 快慢同步走 → fast 到尾时 slow 在目标前驱：

```java
/**
 * LeetCode 19. 删除链表的倒数第 N 个结点
 * 时间 O(n)，空间 O(1)
 * ⚠️ 哑结点必需: 删头节点（N == 长度）时统一处理
 */
public ListNode removeNthFromEnd(ListNode head, int n) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;

    ListNode fast = dummy, slow = dummy;     // ① 都从哑结点起步
    for (int i = 0; i < n; i++) fast = fast.next;  // ② fast 先走 N 步

    while (fast.next != null) {              // ③ 同步走到 fast 到尾
        fast = fast.next;
        slow = slow.next;
    }
    slow.next = slow.next.next;              // ④ 删除 slow 的后继
    return dummy.next;                       // ⑤ 返回真实头
}
// 推演 [1→2→3→4→5]，n=2：fast 先到 2；同步 → slow 停在 3（4 的前驱）
//   删除 4 → [1→2→3→5] ✓
// ⚠️ 边界: n = 长度（删头）→ fast 先走到 null 尾部，slow 停在 dummy
//   删除 dummy.next（原头）→ 哑结点优雅处理 ✓
```

> 🎯 **19 题的教科书价值**："**哑结点 + 步差快慢 = 删倒数第 N 的标准配方**——没有 dummy，删头节点的特判会毁掉代码简洁性。这题是'两大心法（哑结点 + 快慢指针）'的合体考题。"

## 6. 160 相交链表（换路遍历）

### 6.1 题目与思路

**题**：两链表首个相交节点（O(n)/O(1) 要求）。

**换路法**：指针走完自己的链表后跳到对方链表——**两指针总路程相等，必在相交点或 null 相遇**：

```java
/**
 * LeetCode 160. 相交链表（换路遍历）
 * 时间 O(m+n)，空间 O(1)
 * ⚠️ 核心: A 走完跳 B、B 走完跳 A → 总路程相同 → 必相遇
 */
public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
    ListNode a = headA, b = headB;
    while (a != b) {
        a = (a == null) ? headB : a.next;    // ① A 走完跳 B
        b = (b == null) ? headA : b.next;    // ② B 走完跳 A
    }
    return a;                                // ③ 相遇点（或 null）
}
// 推演 A=[4,1,8,4,5], B=[5,0,1,8,4,5]（交点 8）：
//   a: 4,1,8,4,5 → 跳 B: 5,0,1,8；b: 5,0,1,8,4,5 → 跳 A: 4,1,8
//   → 在 8 相遇 ✓（总路程 = lenA + lenB 中交点之前的公共部分）
// ⚠️ 无交点时: 都走完 lenA+lenB 步 → 同时到 null → 返回 null ✓
```

> 💡 **正确性直觉**："**'换路'让两指针的总路程相等**——有交点时，交点前 A 段 + B 段的总长度相同，走完必在交点相遇；无交点时同时走完到 null。路程相等 = 必然同步，这个思想还能解 141 的变体。"

## 7. 快慢指针四题总览与易错点

### 7.1 四题一个模板

| 题 | 模板变体 | 读法 |
|:---:|------|------|
| 141 判环 | 标准（head 起步） | slow == fast → 有环 |
| 142 找入口 | 标准 + 阶段二 | 重置同速再遇 = 入口 |
| 876 中点 | 标准 | 循环结束 slow = 中点 |
| 19 倒数第 N | fast 先走 N 步 + 哑结点 | slow 停在目标前驱 |
| 160 相交 | 无快慢，换路双指针 | a == b → 交点 |

### 7.2 易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 快指针只判 `fast != null` | `fast != null && fast.next != null` | fast.next.next 空指针 |
| 2 | 142 忘判无环 | `fast == null || fast.next == null` 返回 null | 阶段二死循环 |
| 3 | 19 fast 从 head 起步 | 从 dummy 起步（保步差语义） | 删错节点 |
| 4 | 876 偶数长度理解错 | 题目定义返回第二个中点 | 结果偏差（读题！） |
| 5 | 160 用长度差法忘记交换 | 换路法天然免疫 | 长度差法需先算长度 |
| 6 | 快慢指针用于非环链表题 | 判空边界 | 空指针异常 |
| 7 | 142 推导说不清 | L ≡ (C−N) (mod C) | 追问露馅 |

> 🎯 **核心要点**：快慢指针通关四件事——
> **① 统一模板烂熟**（慢 1 快 2 + 双判空）；
> **② 142 数学推导能现场做**（L = (x−1)C + (C−N)）；
> **③ 四题一模板脱口而出**（141/142/876/19，加 160 换路）；
> **④ 哑结点配合**（19 必需）。
> **快慢指针是链表第一通用武器——'速度差 1 必相遇'这一条证明，就能解释它全部的应用**。
