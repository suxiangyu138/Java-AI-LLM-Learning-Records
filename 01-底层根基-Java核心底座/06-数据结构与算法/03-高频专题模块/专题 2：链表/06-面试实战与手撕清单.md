## 2. 话术模板与复杂度速答

### 2.1 通用话术模板

```text
"这题是【模式】题，核心是【组件/技巧】。
（写代码）……先保存 next，翻转/接缝，前进……
（收尾）时间 O(【复杂度】)，空间 O(【复杂度】)（迭代）。
（验证）走一遍样例；边界：空链表/单节点/头节点被改。
（被追问）递归版更简洁但 O(n) 栈空间，迭代 O(1) 是工程选择。"

例: "这是反转题——三指针 prev/curr/next，保存 next 防断链。
    O(n)/O(1)。递归版回指 + 断尾但栈 O(n)。"
```

### 2.2 复杂度速答表

| 模式 | 时间 | 空间 | 关键 |
|------|:---:|:---:|------|
| 反转（迭代） | O(n) | O(1) | 三指针 |
| 反转（递归） | O(n) | O(n) 栈 | 回指 + 断尾 |
| 环检测 | O(n) | O(1) | 慢 1 快 2 |
| 找入口 | O(n) | O(1) | 重置同速 |
| 找中点/倒数 K | O(n) | O(1) | 步差 |
| 合并两链表 | O(m+n) | O(1) | 谁小接谁 |
| 合并 K 链表 | O(N log K) | O(K)/O(log K) | 堆/分治 |
| 排序链表 | O(n log n) | O(log n) | 归并 |
| LRU | O(1) 全操作 | O(capacity) | 哈希 + 双向 |

## 3. 高频追问 TOP 10

| # | 追问 | 标准回答 |
|:---:|------|---------|
| 1 | 为什么递归反转空间 O(n)？ | 递归栈深度 = 链表长度；大链表有栈溢出风险 → 迭代 O(1) 首选 |
| 2 | 141 为什么快指针走 2 步？ | 速度差 1 保证必相遇；差 >1 时相遇取决于距离与环长整除关系 |
| 3 | 142 为什么重置 head 再遇即入口？ | L = (x−1)C + (C−N)：头到入口 = 相遇点到入口（模环长） |
| 4 | 为什么删除倒数第 N 需要哑结点？ | 可能删头节点——哑结点让所有节点有前驱，免特判 |
| 5 | 23 堆版 vs 分治版？ | 时间都 O(N log K)；堆空间 O(K)、分治 O(log K)，K 大分治省空间 |
| 6 | 148 为什么不用快排？ | 无随机访问，partition 需双向遍历低效；归并只需 next 指针 |
| 7 | 146 为什么双向链表？ | 删除任意节点 O(1) 需要前驱指针；单向删中间要 O(n) 找前驱 |
| 8 | 876 偶数长度返回哪个？ | 题目定义返回第二个中点；若需左半尾则 fast 从 head.next 起步 |
| 9 | 160 换路法为什么正确？ | 两指针总路程相等（lenA + 公共段 = lenB + 公共段）→ 必同步相遇 |
| 10 | 链表题通用心法？ | 三大纪律：先保存引用、画图、边界（空/单/双/头被改） |

## 4. 笔试题型与常见陷阱

### 4.1 笔试高频题型

| 题型 | 示例 | 注意 |
|------|------|------|
| 母题默写 | 206/141/21 | 2 分钟内，边界全覆盖 |
| 变体迁移 | 92/25（206 的变形） | 讲清"206 + 接缝" |
| 组合拼装 | 143/148/234 | 拆步骤，每步 O(n) |
| 结构选型 | 146 LRU | 选型论述（为什么双向） |
| 边界设计 | 2 两数相加 | 不等长 + 进位残留 |

### 4.2 常见陷阱

```text
① 反转忘保存 next → 断链（第一 bug 源）
② 快指针只判 fast != null → 空指针（要双判空）
③ 143/148 忘断开两半 → 递归死循环
④ 23 空链表入堆 → 堆污染
⑤ 61 忘 k %= len → 超时
⑥ 86 忘大链表断尾 → 成环
⑦ 146 忘删哈希 → 脏数据
⑧ 返回 head 而非 dummy.next → 头被改时结果错

⚠️ 通用原则: 写完 30 秒自查——
  ① 有没有保存可能丢失的引用？
  ② 断开处会不会成环？
  ③ 头节点被删/被改返回对了吗？
```

## 5. 面试实战演练：三道真题全程

### 5.1 真题一：反转链表（母题考察）

```text
面试过程示范:
  ① 定位: "反转题——三指针迭代，O(n)/O(1)"
  ② 手撕: prev/curr/next 三指针（保存 → 翻转 → 前进）
  ③ 边界: 空链表 / 单节点（循环不进入，直接返回）
  ④ 追问: "递归版？" → 回指 + 断尾，主动提 O(n) 栈空间
  ⑤ 追问: "92 反转区间？" → dummy 找 left 前驱 + 区间内 206
```

### 5.2 真题二：环形链表 II（推导考察）

```text
面试过程示范:
  ① 定位: "快慢找相遇（141）→ 重置同速再遇 = 入口"
  ② 推导: "设头到入口 L、环长 C、入口到相遇点 N——
     fast = 2·slow → L = (x−1)C + (C−N) → L ≡ C−N (mod C)
     重置后同速走 L 步必在入口相遇"
  ③ 边界: 无环 → 返回 null（先判 fast 到 null）
  ④ 追问: "为什么慢 1 快 2？" → 速度差 1 必相遇
```

### 5.3 真题三：LRU 缓存（设计考察，senior）

```text
面试过程示范:
  ① 选型: "O(1) 查找 → 哈希；O(1) 删除任意 → 双向链表；
     淘汰最旧 → 链表尾部；哨兵免边界"
  ② 手撕: 完整类（Node + map + head/tail 哨兵 + 四操作）
  ③ 边界: 容量 1 / 更新已存在 key / 超容淘汰
  ④ 追问: "为什么不用单向？" → 删中间节点 O(1) 需要前驱
  ⑤ 追问: "Redis 怎么做？" → 近似 LRU（采样淘汰）+ 双向链表抽象
```

> 🎯 **核心要点**：面试实战通关 = **练习顺序（母题 → 高频 → 进阶 → senior）+ 话术模板（模式/复杂度/边界三段式）+ 追问 TOP 10 + 三场演练（反转/环推导/LRU 设计）**。链表面试"非常死板"是优势——**五大模式 + 两大心法 + 三大纪律全覆盖后，剩下的只是熟练度**。把母题练到肌肉记忆，链表面试就是送分题。
