## 1. 链表基础：节点结构与遍历心法

```java
public class ListNode {
    int val;
    ListNode next;
    ListNode(int val) { this.val = val; }
}
```

**链表题三大纪律**：

```text
① 操作指针前先保存可能丢失的引用（next 被改写前先存）
② 用画图理解每一步（不画图必错——面试官期待你画）
③ 边界优先: 空链表 / 单节点 / 双节点 / 头节点被改

遍历模板:
  ListNode cur = head;
  while (cur != null) { ...; cur = cur.next; }
⚠️ 快指针相关题目: while (fast != null && fast.next != null)
```

> 🎯 **核心认知**："链表题的本质是**指针的重新指向**——每个节点只有一个 next，改之前必须想清楚'谁还引用着它'。**三大纪律里'先保存'是断链 bug 的唯一解药**。"

## 2. 206 反转链表（迭代版，母题）

### 2.1 三指针迭代（面试标准答案）

```java
/**
 * LeetCode 206. 反转链表（迭代版）
 * 三指针: prev/curr/next —— "保存 next、翻转 next、前进"
 * 时间 O(n)，空间 O(1)
 */
public ListNode reverseList(ListNode head) {
    ListNode prev = null;                    // ① 前驱（新链表的头）
    ListNode curr = head;
    while (curr != null) {
        ListNode next = curr.next;           // ② 保存 next（防止断链）
        curr.next = prev;                    // ③ 翻转: 指向前驱
        prev = curr;                         // ④ 前进: prev → curr
        curr = next;                         // ⑤ 前进: curr → next
    }
    return prev;                             // ⑥ 新头 = 原尾
}
// 推演 [1→2→3→null]：
//   1 的 next → null（prev）；2 的 next → 1；3 的 next → 2
//   返回 3 → [3→2→1→null] ✓
```

> 💡 **口诀背诵**："**保存 next、翻转 next、前进**"——三指针反转是链表第一口诀，206 的迭代版是全部反转题（92/25/143/234）的公共组件。

## 3. 206 反转链表（递归版与面试对比）

### 3.1 递归版

```java
/**
 * 反转链表（递归版）
 * 思路: 先反转 head 之后的部分，再把 head 接到末尾
 * 时间 O(n)，空间 O(n)（递归栈）⚠️
 */
public ListNode reverseListRecursive(ListNode head) {
    if (head == null || head.next == null) return head;   // ① 基线
    ListNode newHead = reverseListRecursive(head.next);   // ② 反转后面
    head.next.next = head;      // ③ head 的下一个指向 head（回指）
    head.next = null;           // ④ 断尾
    return newHead;
}
// 推演 [1→2→3]：reverse(2→3) → 3→2；然后 2.next(3).next = 2 → 3→2→1? 
//   逐步: reverse(3) → 3；reverse(2): 3.next=2, 2.next=null → 3→2
//   reverse(1): 2.next=1, 1.next=null → 3→2→1 ✓
```

### 3.2 面试对比（必答）

| 维度 | 迭代 | 递归 |
|------|:---:|:---:|
| 空间 | **O(1)** | O(n) 栈（大链表栈溢出风险） |
| 可读性 | 指针三连，需画图 | 简洁优雅 |
| 面试推荐 | ✅ 首选 | 追问时展示理解 |

> ⚠️ **面试表达**："迭代版空间 O(1) 是工程选择；递归版代码优雅但最差 O(n) 栈空间——**链表很长时有栈溢出风险**（2025 面试高频追问点）。我写迭代版，但能讲清递归版的'回指'逻辑。"

## 4. 哑结点心法：让所有节点平等

### 4.1 什么是哑结点

```text
问题: 删除/插入"头节点"时需要特判（头节点没有前驱）
哑结点（dummy）: 在真实头前挂一个虚拟节点

  dummy → 真实链表
  dummy.next 始终指向"当前头"
  返回时 return dummy.next

收益: 所有真实节点都有前驱 → 统一操作，免特判
适用: 删除指定值（203）、删除倒数 N（19，必需）、反转（可用）
不适用: 环检测（只移动指针，无前驱操作）
```

### 4.2 哑结点模板（203 删除指定值）

```java
/**
 * LeetCode 203. 移除链表元素（哑结点模板）
 * 时间 O(n)，空间 O(1)
 */
public ListNode removeElements(ListNode head, int val) {
    ListNode dummy = new ListNode(0);        // ① 哑结点
    dummy.next = head;
    ListNode cur = dummy;                    // ② 从哑结点开始（有前驱）
    while (cur.next != null) {
        if (cur.next.val == val) {
            cur.next = cur.next.next;        // ③ 删除（跳过目标）
        } else {
            cur = cur.next;                  // ④ 前进
        }
    }
    return dummy.next;                       // ⑤ 返回真实头
}
// 推演 [1→2→6→3]，val=6：cur 从 dummy 走，删 6 → [1→2→3] ✓
// ⚠️ 无哑结点版本需要"头节点是 6 吗"特判——哑结点消灭它
```

> 🎯 **哑结点心法**："**dummy 让'头节点被删/被改'的边界消失**——所有节点统一用'cur.next 操作'。19 删倒数 N 没有 dummy 会非常痛苦，203/83 有了 dummy 代码直接简化一半。"

## 5. 92 反转链表 II（区间反转）

### 5.1 题目与思路

**题**：反转位置 left 到 right 的区间（进阶版反转）。

**三步**：dummy + 走到 left 前驱 → 区间内三指针反转 → 接回：

```java
/**
 * LeetCode 92. 反转链表 II
 * 时间 O(n)，空间 O(1)
 * ⚠️ 套路: dummy → 找 left 前驱 → 区间内 206 反转 → 接回
 */
public ListNode reverseBetween(ListNode head, int left, int right) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;

    // ① 走到 left 的前驱（prev）
    ListNode prev = dummy;
    for (int i = 1; i < left; i++) prev = prev.next;

    // ② 区间内三指针反转（反转 right−left+1 个节点）
    ListNode curr = prev.next;
    ListNode newTail = curr;                 // 反转后的区间尾 = 原区间头
    ListNode newHead = null;
    for (int i = 0; i <= right - left; i++) {
        ListNode next = curr.next;
        curr.next = newHead;
        newHead = curr;
        curr = next;
    }

    // ③ 接回: 区间尾接上剩余部分，前驱接上新区间头
    newTail.next = curr;
    prev.next = newHead;
    return dummy.next;
}
// 推演 [1→2→3→4→5]，left=2, right=4：
//   prev=1；区间 [2,3,4] 反转 → [4,3,2]
//   newTail(2).next = 5；prev(1).next = 4 → [1→4→3→2→5] ✓
```

> 💡 **区间反转套路**："**92 = 206 + 边界接缝**——区间内就是三指针反转，难点只在'找 left 前驱'和'接回两端的缝'。会 206 的 5 分钟内能写出来，是面试'变体考察'的标准姿势。"

## 6. 25 K 个一组翻转链表（进阶母题）

### 6.1 题目与思路

**题**：每 K 个节点一组翻转，不足 K 的保持原样（Meta/Amazon/Microsoft 高频 hard）。

**分层处理**：找 K 个（不足则停）→ 组内反转 → 接回 → 下一组：

```java
/**
 * LeetCode 25. K 个一组翻转链表
 * 时间 O(n)，空间 O(1)
 * ⚠️ 结构: 外层按组走，内层复用反转；每组用四个指针接缝
 */
public ListNode reverseKGroup(ListNode head, int k) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;
    ListNode prevGroupTail = dummy;          // ① 上一组的尾

    while (true) {
        // ② 检查剩余是否够 K 个
        ListNode kth = prevGroupTail;
        for (int i = 0; i < k; i++) {
            kth = kth.next;
            if (kth == null) return dummy.next;   // 不足 K → 结束
        }
        ListNode groupHead = prevGroupTail.next;  // ③ 本组头
        ListNode nextGroupHead = kth.next;        // ④ 下一组头（先保存！）

        // ⑤ 组内反转（把 groupHead 依次插到 kth 后 —— 头插法）
        ListNode prev = nextGroupHead, curr = groupHead;
        while (curr != nextGroupHead) {
            ListNode next = curr.next;
            curr.next = prev;
            prev = curr;
            curr = next;
        }
        // ⑥ 接回: 上组尾 → 本组新头（kth），本组尾（原 groupHead）→ 下一组
        prevGroupTail.next = kth;
        prevGroupTail = groupHead;           // ⑦ 更新上组尾 = 本组尾
    }
}
// 推演 [1→2→3→4→5]，k=2：→ [2→1→4→3→5] ✓
//   k=3：→ [3→2→1→4→5]（4,5 不足 3 保持原样）✓
```

> 🎯 **25 题的本质**："**K 个一组翻转 = 92 区间反转的循环版**——每组就是一个区间反转，关键在'先保存下一组头'与'接缝四指针'。它是反转系列的毕业题：206 是单组、92 是单区间、25 是全部区间。"

## 7. 反转思想迁移与易错点

### 7.1 反转思想迁移表

| 题 | 反转的应用 | 与 206 的关系 |
|:---:|------|------|
| 92 反转区间 | 区间内三指针 | 206 + 边界接缝 |
| 25 K 个一组 | 循环区间反转 | 206 × 多组 + 接缝 |
| 143 重排链表 | 反转后半段 | 206 + 快慢找中点（04 文件） |
| 234 回文链表 | 反转后半段比对 | 206 + 876（04 文件） |
| 151 反转单词 | 整体 + 局部反转 | 数组题的反转思想（专题 1） |

### 7.2 易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 反转忘保存 next | `ListNode next = curr.next` 先行 | 断链丢节点 |
| 2 | 206 返回 `curr` | 返回 `prev`（新头） | 返回 null/错头 |
| 3 | 递归版忘断尾 | `head.next = null` | 成环 |
| 4 | 25 忘保存下一组头 | `nextGroupHead = kth.next` 先存 | 组间断链 |
| 5 | 25 的循环条件错 | `curr != nextGroupHead`（含边界） | 死循环/丢组 |
| 6 | 92 找前驱步数错 | `for i < left` 走到 left−1 | 接缝错位 |
| 7 | 返回 head 而非 dummy.next | 头被删/改时返回错 | 结果缺头 |

> 🎯 **核心要点**：反转基础通关四件事——**① 206 迭代版 2 分钟默写**（三指针口诀"保存、翻转、前进"）；**② 递归版能讲**（回指 + 断尾，主动提 O(n) 栈空间）；**③ 哑结点心法烂熟**（删除/插入头节点场景的统一解法）；**④ 反转迁移链清晰**（206 → 92 → 25 → 143/234）。**反转是链表第一母题——所有"变形反转"都是 206 加接缝**。
