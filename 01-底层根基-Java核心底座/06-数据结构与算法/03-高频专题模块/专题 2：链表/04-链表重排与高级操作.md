## 2. 143 重排链表（中点 + 反转 + 交替合并）

### 2.1 题目与思路

**题**：L0→Ln→L1→Ln−1→L2→…（交错重排，O(1) 空间）。

**三步**：快慢找中点 → 反转后半 → 交替合并：

```java
/**
 * LeetCode 143. 重排链表
 * 三步: 876 找中点 → 206 反转右半 → 交替合并两半
 * 时间 O(n)，空间 O(1)
 */
public void reorderList(ListNode head) {
    if (head == null || head.next == null) return;

    // ① 快慢找中点（fast=head → slow 停在右半头的前驱）
    ListNode slow = head, fast = head;
    while (fast.next != null && fast.next.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    ListNode right = reverseList(slow.next);   // ② 反转右半（206）
    slow.next = null;                          // ③ 断开两半

    // ④ 交替合并: 左 [1,2,3]、右 [5,4] → 1,5,2,4,3
    ListNode left = head;
    while (right != null) {
        ListNode lNext = left.next;            // ⑤ 先保存后继
        ListNode rNext = right.next;
        left.next = right;                     // 左 → 右
        right.next = lNext;                    // 右 → 左的下一个
        left = lNext;
        right = rNext;
    }
}
// 推演 [1,2,3,4,5]：中点 3 → 右半 [4,5] 反转 [5,4]
//   交替: 1→5→2→4→3 ✓
```

> 💡 **三步拆解**："143 的面试表达 = '**先 876 找中点，再 206 反转右半，最后交替合并**'——每步都是已学组件，复杂度 O(n) 三遍。交替合并的'先保存 lNext/rNext'是唯一新细节（防断链）。"

## 3. 234 回文链表（中点 + 反转 + 比对）

### 3.1 题目与思路

**题**：判断链表是否回文（O(1) 空间）。

**三步**：找中点 → 反转后半 → 双指针比对（到 null 即回文）：

```java
/**
 * LeetCode 234. 回文链表
 * 三步: 876 找中点 → 206 反转右半 → 双指针比对
 * 时间 O(n)，空间 O(1)
 */
public boolean isPalindrome(ListNode head) {
    // ① 快慢找中点
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    // ② 反转右半（偶数长度时 slow 在右半头）
    ListNode right = reverseList(slow);

    // ③ 双指针比对
    ListNode left = head;
    while (right != null) {
        if (left.val != right.val) return false;
        left = left.next;
        right = right.next;
    }
    return true;
}
// 推演 [1,2,2,1]：中点 2（第二个）→ 反转 [2,1] → [1,2]
//   比对 1=1, 2=2 → true ✓
//   [1,2,3]：中点 2 → 反转 [3] → 比对 1=3? false ✓
```

> 🎯 **对比栈解法**："**栈/数组 O(n) 空间是次优解；中点 + 反转 O(1) 空间是标准答案**——'为什么不用栈'的回答：'空间 O(1) 要求，反转后半是链表题的标准手法'。"

## 4. 24 两两交换链表中的节点

### 4.1 题目与思路

**题**：每两个节点交换位置（1→2→3→4 → 2→1→4→3）。

**哑结点 + 三指针**：pre → a → b，交换 a、b 并接回：

```java
/**
 * LeetCode 24. 两两交换链表中的节点
 * 时间 O(n)，空间 O(1)
 */
public ListNode swapPairs(ListNode head) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;
    ListNode prev = dummy;                   // ① prev 指向待交换对的前驱

    while (prev.next != null && prev.next.next != null) {
        ListNode a = prev.next;              // ② 第一个
        ListNode b = a.next;                 // ③ 第二个

        // ④ 交换: prev → b → a → b 的原后继
        a.next = b.next;
        b.next = a;
        prev.next = b;

        prev = a;                            // ⑤ 前进到下一对前驱
    }
    return dummy.next;
}
// 推演 [1,2,3,4]：交换 (1,2) → [2,1,3,4]；交换 (3,4) → [2,1,4,3] ✓
// ⚠️ 本质: 每对就是一次"局部反转"——25 K=2 的特例
```

> 💡 **关系**："**24 = 25 题 K=2 的特例**——会 25（01 文件）的可以直接套；单独考 24 时用哑结点 + 三指针更直观。"

## 5. 61 旋转链表

### 5.1 题目与思路

**题**：链表右移 k 位（k 可能很大）。

**三步**：求长度 + 取模 + 断链重接（**不是逐位移**）：

```java
/**
 * LeetCode 61. 旋转链表
 * 时间 O(n)，空间 O(1)
 * ⚠️ 核心: k %= 长度；找新尾（len−k−1）断开，尾部接头部
 */
public ListNode rotateRight(ListNode head, int k) {
    if (head == null || head.next == null) return head;

    // ① 求长度并连成环（方便找断点）
    int len = 1;
    ListNode tail = head;
    while (tail.next != null) { len++; tail = tail.next; }
    tail.next = head;                          // ② 首尾相连成环

    // ③ 找新头/新尾（右移 k = 从倒数第 k 个断开）
    k %= len;                                  // ④ 取模（k ≥ len）
    ListNode newTail = head;
    for (int i = 0; i < len - k - 1; i++) newTail = newTail.next;
    ListNode newHead = newTail.next;
    newTail.next = null;                       // ⑤ 断开
    return newHead;
}
// 推演 [1,2,3,4,5]，k=2：成环 → 新尾 = 第 3 个（3）→ 断开
//   → [4,5,1,2,3] ✓
```

> 💡 **成环思路**："**先成环再断开**是旋转题的优雅解——不用考虑'末尾接头部'的接缝逻辑，一个环 + 一个断点解决。与数组 189 的三次反转是两种载体同思路。"

## 6. 83/82 删除重复与 86 分隔链表

### 6.1 83 删除排序链表中的重复元素（保留一个）

```java
/**
 * LeetCode 83. 删除排序链表中的重复元素（保留一个）
 * 时间 O(n)，空间 O(1)
 */
public ListNode deleteDuplicates(ListNode head) {
    ListNode cur = head;
    while (cur != null && cur.next != null) {
        if (cur.val == cur.next.val) {
            cur.next = cur.next.next;        // ① 跳过重复
        } else {
            cur = cur.next;                  // ② 前进
        }
    }
    return head;
}
```

### 6.2 82 删除重复元素 II（全删重复）

```java
/**
 * LeetCode 82. 删除排序链表中的重复元素 II（一个不留）
 * 哑结点必需（头节点可能被删）
 * 时间 O(n)，空间 O(1)
 */
public ListNode deleteDuplicatesII(ListNode head) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;
    ListNode prev = dummy;
    while (prev.next != null) {
        ListNode cur = prev.next;
        // ① 检测是否有重复段
        while (cur.next != null && cur.val == cur.next.val) {
            cur = cur.next;                  // ② 走到重复段末尾
        }
        if (cur != prev.next) {
            prev.next = cur.next;            // ③ 跳过整个重复段
        } else {
            prev = prev.next;                // ④ 无重复 → 前进
        }
    }
    return dummy.next;
}
// 推演 [1,2,3,3,4,4,5]：删 3 段和 4 段 → [1,2,5] ✓
```

### 6.3 86 分隔链表（partition 的链表版）

```java
/**
 * LeetCode 86. 分隔链表（小于 x 在前，大于等于在后，保序）
 * 双哑结点: 小于链表 + 大于等于链表，最后拼接
 * 时间 O(n)，空间 O(1)
 */
public ListNode partition(ListNode head, int x) {
    ListNode small = new ListNode(0), big = new ListNode(0);
    ListNode sp = small, bp = big;
    ListNode cur = head;
    while (cur != null) {
        if (cur.val < x) { sp.next = cur; sp = sp.next; }   // ① 小链表
        else             { bp.next = cur; bp = bp.next; }   // ② 大链表
        cur = cur.next;
    }
    bp.next = null;                           // ③ 大链表断尾（防环）
    sp.next = big.next;                       // ④ 拼接
    return small.next;
}
// 推演 [1,4,3,2,5,2]，x=3：小 [1,2,2]，大 [4,3,5] → [1,2,2,4,3,5] ✓
```

## 7. 组合题识别与易错点

### 7.1 组合题识别表

| 题 | 组件 | 新细节 |
|:---:|------|------|
| 143 重排 | 876 + 206 + 交替合并 | 交替合并保存 lNext/rNext |
| 234 回文 | 876 + 206 + 比对 | 偶数中点位置 |
| 24 两两交换 | 哑结点 + 局部反转 | prev.next.next 判空 |
| 61 旋转 | 求长 + 成环 + 断开 | k %= len |
| 82 全删重复 | 哑结点 + 重复段检测 | cur != prev.next 判定 |
| 86 分隔 | 双哑结点 + 拼接 | 大链表断尾防环 |

### 7.2 易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 143 忘断开两半 | `slow.next = null` | 合并死循环 |
| 2 | 143 交替合并忘保存 | 先存 lNext/rNext | 断链 |
| 3 | 234 偶数长度比对边界 | 反转后 right 短半 | 比对到 null 即停 |
| 4 | 61 忘 `k %= len` | 取模 | 超时/越界 |
| 5 | 86 忘大链表断尾 | `bp.next = null` | 成环 |
| 6 | 82 用 `prev.next.val` 比较 | 走 cur 到段尾再判 | 重复段删不干净 |
| 7 | 24 判空漏 `prev.next.next` | 双判空 | 空指针 |

> 🎯 **核心要点**：重排与高级操作通关四件事——**① 组合题识别**（两个以上关键词 → 拆组件）；**② 143/234 三步拼装烂熟**（876 + 206 + 合并/比对）；**③ 61 成环断开、86 双哑结点**（旋转与分区的优雅解）；**④ 82 重复段检测**（cur != prev.next 判定）。**中档链表题 = 原子组件 × 组合——会拼装比会背题重要**，这正是"链表面试很死板"的另一面：模式固定、变化有限。
