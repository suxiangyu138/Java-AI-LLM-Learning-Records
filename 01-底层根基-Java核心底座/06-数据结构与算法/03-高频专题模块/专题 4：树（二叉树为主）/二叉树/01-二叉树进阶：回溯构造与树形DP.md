## 1. 进阶套路总览

### 1.1 与基础体系的定位

```
基础六大模式（见 00 精要 / 树体系）：
  后序聚合 · 前序传参 · 层序 BFS · BST 专项 · 构造 · 同步遍历

本篇三大进阶套路（解决"基础模式不够用"的题）：
  ① 路径回溯   = 前序传参的"状态管理"升级（共享 path + 成对撤销）
  ② 树的构造   = 构造模式的完整体系化（根定位 + 子树划分）
  ③ 树形 DP    = 后序聚合的"返回值状态化"升级（单值 → 数组 → 状态机）
```

> 💡 与树体系分工：基础模式、Morris、迭代遍历见 [树进阶](../树/07-树进阶：遍历原理与模式识别.md)；本篇只讲三个进阶套路，母题题解见 [树体系题解](../树/08-树高频题解.md)。

```
"路径/从根到叶子/恢复现场"   → 路径回溯（113/437）
```

## 2. 套路一：路径回溯

### 2.1 为什么需要回溯

```
递归传参的两类对象：
  String / int（值类型）→ 传递副本 → 分支互不影响 → 无需回溯
  List（引用类型）      → 共享同一对象 → 左分支的 add 会污染右分支
    → 必须"进节点时 add，出节点时 remove"（成对撤销 = 回溯）

⚠️ 判断标准：
  "path 里装的元素在递归后还要继续用" → 引用共享 → 要回溯
```

### 2.2 回溯模板（113. 路径总和 II）

```java
/**
 * LeetCode 113. 路径总和 II（回溯模板题）
 * 找到所有根到叶子、和为 target 的路径
 */
public List<List<Integer>> pathSum(TreeNode root, int targetSum) {
    List<List<Integer>> res = new ArrayList<>();
    dfs(root, targetSum, new ArrayList<>(), res);
    return res;
}

private void dfs(TreeNode node, int remain,
                 List<Integer> path, List<List<Integer>> res) {
    if (node == null) return;
    path.add(node.val);              // ① 进入节点
    remain -= node.val;              //    状态随参数传递（值类型，自动回滚）

    if (node.left == null && node.right == null && remain == 0) {
        res.add(new ArrayList<>(path));  // ② 叶子且达标 → 拷贝快照！
    }

    dfs(node.left, remain, path, res);
    dfs(node.right, remain, path, res);
    path.remove(path.size() - 1);    // ③ 离开节点（成对撤销）
}
// 推演 target=22：
//   [5,4,11,2] ✓  [5,8,4,5] ✓
// ⚠️ 面试必答：
//   "res 里必须存 new ArrayList<>(path) 快照——
//    否则回溯后 path 变空，结果全成空列表；
//    remain 是值类型参数，无需手动回滚。"
```

### 2.3 复制 vs 回溯（代价对比）

| 方案 | 时间 | 空间 | 特点 |
|------|:---:|:---:|------|
| 每次 new List 传参 | O(n²) | O(n²) | 简单但浪费 |
| 共享 path + 回溯 | **O(n)** | O(h) | 标准做法 |

```
⚠️ 面试必答：
  "回溯 = 用 O(1) 的 remove 换掉 O(n) 的拷贝；
   树深 h → 栈内始终只有一条路径，空间 O(h)。"
```

### 2.4 前缀和回溯（437 原理）

```
从根到当前节点的路径上，连续段和 = target：
  连续段 = 当前前缀和 cur - 某祖先前缀和 pre
  → HashMap 记录各前缀和出现次数，查 cur - target

⚠️ 与数组"和为 K 的子数组"同构：
  数组是线性回溯，树是 DFS 路径回溯——
  离开节点必须撤销哈希表计数（防兄弟分支污染）
完整实现见 02-二叉树进阶高频题解 §1
```

## 3. 套路二：树的构造

### 3.1 构造题总览

| 题号 | 输入 | 唯一性 | 核心 |
|:---:|------|:---:|------|
| 105 | 前序 + 中序 | ✅ | 前序定根 + 中序划左右 |
| 106 | 中序 + 后序 | ✅ | 后序定根（末尾）+ 中序划左右 |
| 889 | 前序 + 后序 | ❌ 不唯一 | 需特判兄弟（根+左根推） |
| 108 | 有序数组 | ✅ BST | 中间为根 |
| 654 | 最大值数组 | ✅ | 最大值为根（单调栈/递归） |

### 3.2 核心原理：根定位 + 子树划分

```
构造题三步（套在每棵子树递归上）：
  ① 定根：前序第一个 / 后序最后一个 / 中间元素
  ② 划分：中序中根的位置 → 左 = [inLo, inRoot-1]，右 = [inRoot+1, inHi]
  ③ 递归：左右子树重复三步

⚠️ 必须有中序的原因：
  前序+后序只能确定"祖先-后代"关系，
  无法区分左右兄弟 → 二叉树不唯一（889 需特判）
```

### 3.3 105 完整实现

```java
/**
 * LeetCode 105. 从前序与中序遍历序列构造二叉树
 * 哈希表 O(1) 定位根在中序的位置
 */
public TreeNode buildTree(int[] preorder, int[] inorder) {
    Map<Integer, Integer> idx = new HashMap<>();
    for (int i = 0; i < inorder.length; i++) idx.put(inorder[i], i);
    return build(preorder, 0, 0, inorder.length - 1, idx);
}

private TreeNode build(int[] pre, int preRoot, int inLo, int inHi,
                       Map<Integer, Integer> idx) {
    if (inLo > inHi) return null;
    TreeNode root = new TreeNode(pre[preRoot]);       // ① 前序定根
    int inRoot = idx.get(pre[preRoot]);               // ② 中序定位
    int leftSize = inRoot - inLo;                     //    左子树大小

    root.left  = build(pre, preRoot + 1, inLo, inRoot - 1, idx);
    root.right = build(pre, preRoot + leftSize + 1, inRoot + 1, inHi, idx);
    return root;
}
// 推演 pre=[3,9,20,15,7], in=[9,3,15,20,7]：
//   根 3 → 左子树大小 1 → 右子树根 = preRoot+1+1 = 20 ✓
// O(n)（哈希表免去每次 O(n) 查找；不用哈希是 O(n²)）
// ⚠️ 面试必答：
//   "右子树根的 pre 位置 = preRoot + leftSize + 1；
//    先序推进顺序固定，必须先建左再建右。"
```

### 3.4 106 与 889 变体要点

```java
// 106 中序+后序：后序末尾 = 根，其余对称
//   preRoot → postRoot（从 post 末尾递减推进）
//   build(post, postRoot - rightSize - 1, ...)   // 先建右子树

// 889 前序+后序：不唯一
//   特判：pre[preL+1] 是左子树根 → 在后序里定位
//   ⚠️ 面试必答："只有前后序 → 兄弟顺序不明，
//     任意二叉树对应多种结构，题目必须保证输入合法。"
```

## 4. 套路三：树形 DP

### 4.1 树形 DP 的本质

```
后序聚合 + 状态设计：
  返回值从"单个数"升级为"状态集合"（数组/枚举/哨兵）
  父节点根据孩子的状态做转移决策

⚠️ 与基础后序的区别：
  基础：返回值 = 子树唯一答案（高度/节点数）
  树形DP：返回值 = 子树在"每种状态下的最优解"
```

### 4.2 状态设计三阶段演进

| 阶段 | 代表题 | 返回值 | 状态设计 |
|:---:|------|------|------|
| ① 简单聚合 | 104 深度 | int | 单值，直接 max+1 |
| ② 有状态聚合 | 543/124 | int + 外部变量 | 返回值单边 + 全局折弯（`max(0, x)` 砍负） |
| ③ 状态机 | 337/968 | 数组/枚举 | 返回值多态，父按状态转移 |

```
⚠️ 演进规律（面试话术）：
  "答案既要'穿过当前节点折弯'又要'向上传递单边'
   → 返回值与答案分离（543/124）；
   '选/不选受父约束' → 状态机数组（337）；
   '覆盖状态递推' → 枚举状态贪心（968）。"
```

### 4.3 337. 打家劫舍 III（状态机模板）

```java
/**
 * LeetCode 337. 打家劫舍 III（树形 DP 模板题）
 * 每个节点返回 {不选的最大, 选的最大}
 * 父子约束：选父 → 子只能不选；不选父 → 子随便
 */
public int rob(TreeNode root) {
    int[] res = dfs(root);
    return Math.max(res[0], res[1]);
}

private int[] dfs(TreeNode node) {
    if (node == null) return new int[2];
    int[] l = dfs(node.left), r = dfs(node.right);

    int notRob = Math.max(l[0], l[1]) + Math.max(r[0], r[1]);  // 不选：子自由
    int rob    = node.val + l[0] + r[0];                        // 选：子必须不选
    return new int[]{notRob, rob};
}
// 推演 [3,2,3,null,3,null,1]：
//   → 答案 7 = 根3 + 左孙3 + 右孙1 ✓
// O(n) 时间 O(h) 空间
// ⚠️ 面试必答：
//   "树形DP=后序 + 状态数组；转移方程就两行——
//    不选父累加子最优，选父必须锁死子的不选态。"
```

### 4.4 968. 监控二叉树（三状态贪心）

```java
/**
 * LeetCode 968. 监控二叉树（贪心 + 状态机）
 * 叶子优先由父覆盖 → 自底向上贪心
 * 状态：0 未覆盖 / 1 有相机 / 2 已被覆盖
 */
class Solution {
    int cameras = 0;

    public int minCameraCover(TreeNode root) {
        if (dfs(root) == 0) cameras++;   // ⚠️ 根未被覆盖 → 补一个
        return cameras;
    }

    private int dfs(TreeNode node) {
        if (node == null) return 2;              // 空节点视为已覆盖
        int l = dfs(node.left), r = dfs(node.right);

        if (l == 0 || r == 0) { cameras++; return 1; }  // 孩子未覆盖 → 装相机
        if (l == 1 || r == 1) return 2;                  // 孩子有相机 → 被覆盖
        return 0;                                        // 孩子均覆盖 → 交给父
    }
}
// 推演 [0,0,null,0,0]（根-左子-两个叶子）→ 1 ✓
// O(n) 时间 O(h) 空间
// ⚠️ 面试必答：
//   "贪心方向：叶子让父装相机最省（1 台覆盖 3 层）；
//    三状态递推：子未覆盖必装、子有相机即覆盖、
//    子全覆盖则等父 —— 根残留未覆盖最后兜底。"
```

## 5. 进阶总结

### 5.1 三套路速查

| 套路 | 核心机制 | 代表题 | 一句话记忆 |
|------|------|------|------|
| 路径回溯 | 共享 path 成对 add/remove | 113/437 | 进加出减，结果存快照 |
| 树的构造 | 根定位 + 子树划分 | 105/106 | 前定根、中划界、哈希定位 |
| 树形 DP | 返回值状态化 | 337/968 | 后序 + 状态数组 + 转移方程 |

### 5.2 面试话术模板

```
"这题是【回溯/构造/树形DP】套路：
 ① 机制【共享 path 成对撤销 / 前序定根+中序划分 /
    后序返回状态数组】；
 ② 关键细节【快照拷贝 / leftSize+1 定位右根 /
    选父锁子不选】；
 ③ 复杂度 O(n) 时间 O(h) 空间。"
```

### 5.3 易错点清单

| 错误 | 后果 | 修正 |
|------|------|------|
| 忘存 path 快照 | 结果全为空列表 | `new ArrayList<>(path)` |
| 忘撤销 path | 兄弟分支污染 | 成对 add/remove |
| 右子树根定位错 | 构造错乱 | `preRoot + leftSize + 1` |
| 337 状态混用 | 答案错 | 明确下标 0=不选 1=选 |
| 968 根漏判 | 少一台相机 | `dfs(root)==0` 兜底 |

> 🎯 **核心要点**：三大进阶套路 = **路径回溯**（共享 path + 成对撤销 + 快照）、**树的构造**（根定位 + 哈希划界 + leftSize 递推）、**树形 DP**（返回值状态化：543 单边 → 337 双态 → 968 三态）。基础六模式管 90% 的题，这三套是"拉开差距"的题区；与树体系互为补充，母题题解见 [02-二叉树进阶高频题解](02-二叉树进阶高频题解.md)。
