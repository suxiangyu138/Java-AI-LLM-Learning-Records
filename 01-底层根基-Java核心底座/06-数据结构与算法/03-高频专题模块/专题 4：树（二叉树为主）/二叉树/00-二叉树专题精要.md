## 1. 核心概念

### 1.1 二叉树的定义

```java
// LeetCode 标准定义
public class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode() {}
    TreeNode(int val) { this.val = val; }
    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val; this.left = left; this.right = right;
    }
}
```

### 1.2 二叉树类型速查

| 类型 | 定义 | 特点 |
|------|------|------|
| **满二叉树** | 每层都满 | 节点数 = 2^h - 1 |
| **完全二叉树** | 最后一层从左到右 | 数组存储（堆） |
| **二叉搜索树** | 左<根<右 | 中序有序 |
| **平衡二叉树** | 左右高度差 ≤ 1 | AVL/红黑树 |
| **完美二叉树** | 满且叶子同层 | — |

### 1.3 为什么树题适合递归

```
树是递归结构（子树也是树）
  → 递归天然匹配（代码 3-5 行）
  → 迭代需显式栈（中序迭代是必考）

⚠️ 树 vs 图：
  树天然无环 → 遍历无需 visited
  图可能有环 → 必须 visited
```

## 2. 完整代码模板

### 2.1 递归遍历三模板

```java
/**
 * 前/中/后序递归——只移动"处理"位置
 */
void preorder(TreeNode node) {          // 前序：根左右
    if (node == null) return;
    处理(node);                          // 前序处理
    preorder(node.left);
    preorder(node.right);
}

void inorder(TreeNode node) {           // 中序：左根右
    if (node == null) return;
    inorder(node.left);
    处理(node);                          // 中序处理
    inorder(node.right);
}

void postorder(TreeNode node) {         // 后序：左右根
    if (node == null) return;
    postorder(node.left);
    postorder(node.right);
    处理(node);                          // 后序处理
}
// 记忆："前中后指根的位置"
// 应用：前序传参（路径）、后序聚合（高度）
```

### 2.2 层序遍历（BFS）

```java
/**
 * 102. 层序遍历——size 分层模板
 */
public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> result = new ArrayList<>();
    if (root == null) return result;

    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);

    while (!queue.isEmpty()) {
        int levelSize = queue.size();      // ⚠️ 先固定本层节点数！
        List<Integer> level = new ArrayList<>();

        for (int i = 0; i < levelSize; i++) {
            TreeNode node = queue.poll();
            level.add(node.val);
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        result.add(level);
    }
    return result;
}
// 变体：107 自底向上（头插）、103 锯齿（反转）
//       199 右视图（每层最后一个）、513 左下角
```

### 2.3 中序迭代（面试必考）

```java
/**
 * 中序迭代：左探-回溯-右转
 * ⚠️ 递归转迭代的最高频考点
 */
public List<Integer> inorderTraversal(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode cur = root;

    while (cur != null || !stack.isEmpty()) {
        while (cur != null) {           // ① 左探：一路向左
            stack.push(cur);
            cur = cur.left;
        }
        cur = stack.pop();              // ② 回溯：弹出
        result.add(cur.val);            //     中序处理
        cur = cur.right;                // ③ 右转
    }
    return result;
}
```

## 3. 六大解题模式

### 3.1 模式一：自底向上（后序）

```
需要子树信息才能决策：
  "左右孩子给我答案后，我能合并出自己的答案？"
  能 → 后序

代表题：
  104 最大深度（max(左,右)+1）
  110 平衡判断（-1 哨兵）
  543 直径（外部变量记录）
  124 最大路径和（全局+单边）
  236 LCA（三情况）

⚠️ 有状态模式：直径/路径和用外部变量
  （返回值 = 子树信息；答案 = 全局比较）
```

### 3.2 模式二：自顶向下（前序）

```
信息从根流向叶子：
  状态（当前和/路径）作为递归参数传递

代表题：
  112/113 路径总和（减法）
  257 所有路径（字符串拼接）
  129 根到叶数字和

⚠️ 路径收集题：共享 path 成对 add/remove（回溯）
```

### 3.3 模式三：层序（BFS）

```
涉及"层/最近/最短"：
  102 层序、199 右视图、103 锯齿
  513 左下角、637 层平均值

⚠️ 层相关题的第一反应：BFS + size 分层
```

### 3.4 模式四：BST 专项

```
利用"中序有序"：
  98 验证（中序递增/区间约束）
  700/701 搜索插入（二分式）
  450 删除（三情况 + 后继顶替）
  230 第 K 小（中序计数）

⚠️ 完整见二叉搜索树专题
```

### 3.5 模式五：树的构造

```
105 前序+中序构造（哈希表定位）
106 中序+后序构造（对称）
297 序列化（# 占位）
108 有序数组转 BST（中间为根）

⚠️ 构造题核心：根定位 + 子树大小划分
```

### 3.6 模式六：同步遍历（两棵树）

```
100 相同树（同步比较）
101 对称树（镜像比较）
572 子树（100 复用）
226 翻转（交换左右）

⚠️ 同步遍历 = 两个指针同时走
```

## 4. 遍历的三种实现

### 4.1 递归 vs 迭代 vs Morris

| 实现 | 空间 | 特点 |
|------|:---:|------|
| 递归 | O(h) 系统栈 | 简洁，深链可能溢出 |
| 迭代（显式栈） | O(h) 堆内存 | 无溢出，中序必考 |
| Morris | O(1) | 利用空指针建线索（加分） |

```
面试策略：
  先写递归（快速）
  追问"栈溢出" → 显式栈
  追问"O(1) 空间" → Morris（讲原理即可）
```

### 4.2 前序/后序迭代

```java
// 前序迭代：先压右再压左（栈后进先出 → 先处理左）
Deque<TreeNode> stack = new ArrayDeque<>();
stack.push(root);
while (!stack.isEmpty()) {
    TreeNode node = stack.pop();
    result.add(node.val);
    if (node.right != null) stack.push(node.right);  // 右后压
    if (node.left != null) stack.push(node.left);    // 左先出
}

// 后序迭代：前序变体（根右左）反转
//   push 顺序反一下 → 结果反转 → 左右根
```

### 4.3 遍历选型口诀

```
"自底向上用后序，自顶向下用前序
 层相关用 BFS，有序性问题用中序"
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"这题需要子树信息 → 后序遍历。
 思路：返回高度，用外部变量记录直径。
 空节点返回 0。每个节点：
 左高度 + 右高度 更新全局答案，
 返回 max(左,右)+1 给父节点。
 O(n) 时间 O(h) 空间（h 为树高）。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 前中后序何时用？ | 后序聚合子树；前序传参；中序 BST；层序最近 |
| 2 | 递归转迭代？ | 前序先右后左压栈；中序左探-回溯-右转；后序变体反转 |
| 3 | 返回值 vs 外部变量？ | 直径不经过根 → 必须全局记录 |
| 4 | 平衡判断优化？ | -1 哨兵一次后序（避免 O(n²)） |
| 5 | 序列化为什么记空节点？ | 普通树无法唯一还原（# 占位） |
| 6 | 树为什么适合递归？ | 递归结构（子树也是树）天然匹配 |
| 7 | 树退化成链表？ | 递归 O(n) 栈 → 显式栈迭代 |
| 8 | 树 vs 图？ | 树无环免 visited；图必须 |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 基线返回 0/-1 混淆 | 高度错 | 高度 -1、计数 0 |
| 路径题忘回溯 | 路径污染 | 成对 add/remove |
| 有状态忘外部变量 | 漏全局最优 | int[] 记录 |
| 层序忘 size | 层混 | int size = q.size() |
| 平衡 O(n²) | 超时 | -1 哨兵 |

> 🎯 **核心要点**：二叉树 = **模式识别**（30 秒判断用哪种遍历）+ 模板默写。后序聚合/前序传递/层序扩散三模板 + 有状态外部变量 + 成对回溯覆盖 90% 树题；中序迭代是递归转迭代的必考考点。
