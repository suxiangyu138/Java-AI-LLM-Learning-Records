## 1. 二叉树基础概念

### 1.1 节点定义与术语

```java
// LeetCode 标准定义
public class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode() {}
    TreeNode(int val) { this.val = val; }
    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val; this.left = left; this.right = right;
    }
}
```

### 1.2 二叉树类型速查

| 类型 | 定义 | 特点 |
|------|------|------|
| **满二叉树** | 每层都满 | 节点数 = 2^h - 1 |
| **完全二叉树** | 最后一层从左到右填满 | 可用数组存储（堆） |
| **二叉搜索树 BST** | 左<根<右 | 中序有序（见 03 模块） |
| **平衡二叉树** | 左右高度差 ≤ 1 | AVL/红黑树基础 |
| **N 叉树** | 节点有 N 个子节点 | List<TreeNode> children |

### 1.3 高度 vs 深度

```
深度（Depth）：从根到该节点的边数（自顶向下数）
高度（Height）：从该节点到最远叶子的边数（自底向上数）

根节点深度 0，叶子高度 0
两者是"互补"视角：深度自顶向下，高度自底向上
树的深度 == 树的高度
```

## 2. 递归遍历三模板

### 2.1 前序（根左右）

```java
public void preorder(TreeNode root) {
    if (root == null) return;
    System.out.println(root.val);   // ① 访问根
    preorder(root.left);            // ② 左子树
    preorder(root.right);           // ③ 右子树
}
```

### 2.2 中序（左根右）

```java
public void inorder(TreeNode root) {
    if (root == null) return;
    inorder(root.left);             // ① 左子树
    System.out.println(root.val);   // ② 访问根
    inorder(root.right);            // ③ 右子树
}
// 对 BST 中序遍历 = 从小到大输出 ✓
```

### 2.3 后序（左右根）

```java
public void postorder(TreeNode root) {
    if (root == null) return;
    postorder(root.left);           // ① 左子树
    postorder(root.right);          // ② 右子树
    System.out.println(root.val);   // ③ 访问根（子树信息先就绪）
}
// 后序适合"需要子树信息"的问题：高度/直径/平衡判断
```

### 2.4 记忆口诀

```
前中后 = 根左右 / 左根右 / 左右根
"前、中、后"指根节点被访问的时机：
  前序根最先，中序根在中间，后序根最后
```

## 3. 迭代遍历：显式栈

### 3.1 前序迭代（先右后左入栈）

```java
/**
 * 前序迭代：栈模拟递归
 * 关键：先压右子树再压左子树（栈后进先出 → 先处理左）
 */
public List<Integer> preorderTraversal(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    if (root == null) return res;
    Deque<TreeNode> stack = new ArrayDeque<>();
    stack.push(root);

    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();
        res.add(node.val);              // 访问根
        if (node.right != null) stack.push(node.right);  // 右后入
        if (node.left != null) stack.push(node.left);    // 左先出
    }
    return res;
}
```

### 3.2 中序迭代（面试最高频考点）⭐

```java
/**
 * 中序迭代：核心循环"左探-回溯-右转"
 * while (cur != null || !stack.isEmpty())
 *   左探：一路向左压栈
 *   回溯：出栈访问
 *   右转：转向右子树
 */
public List<Integer> inorderTraversal(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode cur = root;

    while (cur != null || !stack.isEmpty()) {
        while (cur != null) {           // ① 左探：一路向左
            stack.push(cur);
            cur = cur.left;
        }
        cur = stack.pop();              // ② 回溯：弹出访问
        res.add(cur.val);
        cur = cur.right;                // ③ 右转
    }
    return res;
}
```

### 3.3 后序迭代（双栈/逆序技巧）

```java
/**
 * 后序迭代技巧：前序是"根左右"，把它改成"根右左"再反转 = "左右根"
 * 实现：先按 根-右-左 遍历（前序变体），结果反转
 */
public List<Integer> postorderTraversal(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    if (root == null) return res;
    Deque<TreeNode> stack = new ArrayDeque<>();
    stack.push(root);

    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();
        res.add(node.val);              // 根
        if (node.left != null) stack.push(node.left);   // ⚠️ 先左
        if (node.right != null) stack.push(node.right); // 后右
    }
    Collections.reverse(res);           // 根右左 → 反转 → 左右根
    return res;
}
```

### 3.4 迭代 vs 递归

| 维度 | 递归 | 迭代（显式栈） |
|------|:---:|:---:|
| 代码 | 简洁 3 行 | 繁琐 15 行 |
| 空间 | O(h)（系统栈） | O(h)（显式栈） |
| 栈溢出 | 树高过大可能 | 无风险 |
| 面试偏好 | 先写递归 | 中序迭代是**必考考点** |

> 💡 **面试策略**：先展示递归版（快），面试官要求迭代版时展示中序迭代模板——这是面试官最爱考察的"递归转迭代"能力。

## 4. 层序遍历 BFS

### 4.1 基础模板（102. 层序遍历）

```java
/**
 * LeetCode 102. 二叉树的层序遍历
 * 关键：每轮先记录 queue.size()，一次性处理完整层
 */
public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) return res;

    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);

    while (!queue.isEmpty()) {
        int levelSize = queue.size();      // ⚠️ 先固定本层节点数！
        List<Integer> level = new ArrayList<>();

        for (int i = 0; i < levelSize; i++) {
            TreeNode node = queue.poll();
            level.add(node.val);
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        res.add(level);
    }
    return res;
}
```

### 4.2 层序变式题速查

| 题号 | 变式 | 一行改动 |
|:---:|------|------|
| 107 | 自底向上层序 | `res.add(0, level)` 头插 |
| 103 | 锯齿形层序 | 奇偶层反转 level |
| 199 | 二叉树右视图 | 只取每层最后一个节点 |
| 513 | 左下角值 | 取最后一层第一个节点 |
| 637 | 层平均值 | 每层求和除以 size |

## 5. Morris 遍历：O(1) 空间

### 5.1 核心思想

```
Morris 遍历利用叶子节点的空指针（right）临时记录回溯路径：
  遍历到节点 cur 时：
  ① 若无左子树 → 访问 cur，转向右子树
  ② 若有左子树 → 找左子树的最右节点（cur 的前驱）pre：
       - pre.right == null → pre.right = cur（建立临时线索），访问 cur，转向左子树
       - pre.right == cur → pre.right = null（删除线索），转向右子树

效果：不用栈也能回溯！空间 O(1)
```

### 5.2 Morris 中序实现

```java
/**
 * Morris 中序遍历：O(n) 时间，O(1) 空间（面试加分项）
 */
public List<Integer> morrisInorder(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    TreeNode cur = root;

    while (cur != null) {
        if (cur.left == null) {          // ① 无左子树
            res.add(cur.val);            //    访问当前
            cur = cur.right;             //    转向右
        } else {                         // ② 有左子树
            // 找左子树的最右节点（前驱）
            TreeNode pre = cur.left;
            while (pre.right != null && pre.right != cur) {
                pre = pre.right;
            }
            if (pre.right == null) {     // 第一次到达：建线索
                pre.right = cur;
                cur = cur.left;          //    转向左
            } else {                     // 第二次到达：删线索
                pre.right = null;
                res.add(cur.val);        //    访问当前
                cur = cur.right;         //    转向右
            }
        }
    }
    return res;
}
```

> 💡 **面试定位**：Morris 属于加分项/知识拓展，面试通常不要求手写。能讲清原理（"利用空指针建线索"）即可，重点还是递归和迭代。

## 6. 四种遍历对比与选型

### 6.1 遍历适用场景速查

| 遍历 | 访问时机 | 典型应用 | 代表题 |
|------|------|------|:---:|
| 前序 | 先根后子树 | 复制树、序列化、路径记录、自顶向下传参 | 226/297/257 |
| 中序 | 左根右 | BST 有序输出、验证 BST、找第 K 小 | 98/230 |
| 后序 | 先子树后根 | 高度/直径/平衡/最大路径和、自底向上 | 104/543/124/110 |
| 层序 | 逐层 | 层相关/最短距离/最近 | 102/199/103 |

### 6.2 如何选择遍历？

```
判断口诀：
  需要"左右子树信息才能决策" → 后序（自底向上）
  需要"根的信息向叶子传递" → 前序（自顶向下）
  涉及"层/最近/最短" → 层序 BFS
  BST 相关有序性问题 → 中序

自检问题："左右孩子给我答案后，我能合并出自己的答案吗？"
  能 → 后序；不能 → 前序
```

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 递归基例返回 0/-1 混淆 | 深度/路径计算错误 | 高度用 -1，计数用 0 |
| 迭代前序先压左 | 遍历顺序错 | 先压右再压左 |
| 层序忘了固定 size | 层与层混在一起 | 每轮先 `int n = q.size()` |
| 把"空节点"当"叶子" | 路径题错误 | 路径类题目要区分两者 |

> 🎯 **核心要点**：遍历是树的地基——**递归三模板**（3 行搞定）、**中序迭代**（面试必考，"左探-回溯-右转"）、**层序 BFS**（size 分层）、**Morris**（加分项）。记住"自底向上用后序，自顶向下用前序，层相关用 BFS，有序性问题用中序"，接下来任何树题都是套模板。
