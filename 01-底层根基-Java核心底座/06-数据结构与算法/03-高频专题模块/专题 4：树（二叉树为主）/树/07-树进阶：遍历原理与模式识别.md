## 1. 遍历的完整体系

### 1.1 三种遍历的本质

```
前序（根左右）：根信息先处理 → 自顶向下传参
中序（左根右）：左子树后根 → BST 有序输出
后序（左右根）：子树信息先就绪 → 自底向上聚合

记忆："前中后指根被访问的时机"

⚠️ 关键认知：
  遍历不是"访问顺序"问题
  是"信息流动方向"问题：
    前序 = 根 → 叶（传参）
    后序 = 叶 → 根（聚合）
```

### 1.2 遍历的信息流动

```
前序（自顶向下）：
  处理(node) → 把"状态"传给子树
  例：路径总和（remain 递减传参）

后序（自底向上）：
  子树返回"信息" → 合并
  例：树高（max(左,右)+1）

⚠️ 选择标准：
  "左右孩子给我答案后，我能合并出自己的答案？"
  能 → 后序；不能 → 前序
```

### 1.3 遍历的时间/空间

```
时间：O(n)（每节点访问一次）
空间：
  递归：O(h)（系统栈，h = 树高）
  迭代：O(h)（显式栈）
  Morris：O(1)

⚠️ 树退化为链表时 h = n：
  递归可能栈溢出 → 转迭代
```

## 2. 迭代遍历的三种形态

### 2.1 前序迭代（先右后左入栈）

```java
/**
 * 前序迭代：栈模拟递归
 * ⚠️ 先压右再压左（栈后进先出 → 先处理左）
 */
public List<Integer> preorderTraversal(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    if (root == null) return result;

    Deque<TreeNode> stack = new ArrayDeque<>();
    stack.push(root);

    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();
        result.add(node.val);              // 前序处理
        if (node.right != null) stack.push(node.right);  // 右后压
        if (node.left != null) stack.push(node.left);    // 左先出
    }
    return result;
}
// ⚠️ 为什么先右后左？
//   栈 LIFO：后压的先出 → 右后压 → 左先出
//   → 处理顺序：根 → 左 → 右 ✓
```

### 2.2 中序迭代（左探-回溯-右转）

```java
/**
 * 中序迭代：面试最高频考点
 * 核心循环："左探-回溯-右转"
 */
public List<Integer> inorderTraversal(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode cur = root;

    while (cur != null || !stack.isEmpty()) {
        while (cur != null) {           // ① 左探：一路向左压栈
            stack.push(cur);
            cur = cur.left;
        }
        cur = stack.pop();              // ② 回溯：弹出
        result.add(cur.val);            //     中序处理
        cur = cur.right;                // ③ 右转
    }
    return result;
}
// 推演 [1,2,3]（1 无左，2 无左，3）：
//   左探：压 1,2 → cur=null
//   回溯：弹 2 → 处理 2 → 右转（null）
//   回溯：弹 1 → 处理 1 → 右转（3）
//   左探：压 3 → 回溯：弹 3 → 处理 3
//   结果 [2,1,3] ✓
```

### 2.3 后序迭代（前序变体反转）

```java
/**
 * 后序迭代技巧：前序变体 + 反转
 * 前序：根左右 → 改"根右左" → 反转 → 左右根
 */
public List<Integer> postorderTraversal(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    if (root == null) return result;

    Deque<TreeNode> stack = new ArrayDeque<>();
    stack.push(root);

    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();
        result.add(node.val);              // 根
        if (node.left != null) stack.push(node.left);   // ⚠️ 先左
        if (node.right != null) stack.push(node.right); // 后右
    }
    Collections.reverse(result);           // 根右左 → 反转 → 左右根
    return result;
}
// 推演 1→2→3：
//   栈序处理：1,3,2（根右左）
//   反转：2,3,1（左右根）✓
// ⚠️ 与"标准后序双栈"等价，此写法更简单
```

## 3. Morris 遍历：O(1) 空间

### 3.1 核心思想

```
Morris 遍历利用叶子节点的空指针（right）临时记录回溯路径：
  遍历到节点 cur 时：
  ① 无左子树 → 访问 cur，转向右子树
  ② 有左子树 → 找左子树的最右节点（cur 的前驱）pre：
       - pre.right == null → pre.right = cur（建立临时线索）
          访问 cur，转向左子树
       - pre.right == cur → pre.right = null（删除线索）
          转向右子树

效果：不用栈也能回溯！空间 O(1)

⚠️ 面试定位：加分项/知识拓展
  能讲清原理（"利用空指针建线索"）即可
  通常不要求手写
```

### 3.2 Morris 中序实现

```java
/**
 * Morris 中序遍历：O(n) 时间，O(1) 空间
 */
public List<Integer> morrisInorder(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    TreeNode cur = root;

    while (cur != null) {
        if (cur.left == null) {          // ① 无左子树
            result.add(cur.val);         //    访问当前
            cur = cur.right;             //    转向右
        } else {                         // ② 有左子树
            // 找左子树的最右节点（前驱）
            TreeNode pre = cur.left;
            while (pre.right != null && pre.right != cur) {
                pre = pre.right;
            }
            if (pre.right == null) {     // 第一次到达：建线索
                pre.right = cur;
                cur = cur.left;          //    转向左
            } else {                     // 第二次到达：删线索
                pre.right = null;
                result.add(cur.val);     //    访问当前
                cur = cur.right;         //    转向右
            }
        }
    }
    return result;
}
// ⚠️ 两种遍历对比：
//   递归/迭代：空间 O(h)
//   Morris：O(1)（但修改了树的结构——临时线索）
//   应用：树结构不可变时不能用 Morris
```

## 4. 六大模式识别框架

### 4.1 模式总览

| 模式 | 遍历 | 特征 | 代表题 |
|------|:---:|------|:---:|
| 自底向上 | 后序 | 需要子树信息 | 104/110/543/124/236 |
| 自顶向下 | 前序 | 根信息传叶 | 112/257/129 |
| 层序 | BFS | 层相关 | 102/199/103 |
| BST 专项 | 中序 | 有序性 | 98/230/450 |
| 构造 | 分治 | 根+子树划分 | 105/297 |
| 同步遍历 | 并行 | 两棵树比较 | 100/101/572 |

```
⚠️ 30 秒模式判定：
  ① 需要"层/最近/最短"？→ 层序
  ② 需要"子树信息合并"？→ 后序
  ③ 需要"根信息向下传"？→ 前序
  ④ BST 有序性？→ 中序
```

### 4.2 模式识别示例

```
例：543 二叉树的直径
  "每个节点需要左右子树高度合并" → 后序
  "答案可能不经过根" → 有状态（外部变量）

例：257 二叉树的所有路径
  "路径从根累积向下" → 前序
  "需要收集路径" → 回溯（成对 add/remove）

⚠️ 面试表达：
"这题我判断是【后序自底向上】模式——
 节点需要左右子树的高度才能合并答案，
 符合'左右孩子给我答案后能合并'的特征。"
```

## 5. 有状态 vs 无状态的本质

### 5.1 两类问题的区分

```
无状态：函数的返回值就是答案
  例：树高 —— max(left, right) + 1 直接返回

有状态：函数返回辅助信息，答案存外部变量
  例：直径 —— 函数返回高度，答案记录在外部变量
  原因：直径可能不穿过当前节点，无法用单一返回值表达

⚠️ 识别：
  "答案是否可能不经过当前节点？"
  可能 → 有状态（外部变量）
  不可能 → 无状态（直接返回）
```

### 5.2 有状态模式模板

```java
/**
 * 有状态模式（543 直径 / 124 路径和）
 * 函数返回"给父节点的信息"
 * 外部数组记录"全局答案"
 */
public int diameterOfBinaryTree(TreeNode root) {
    int[] diameter = new int[1];          // ⚠️ 外部变量（数组包裹）
    height(root, diameter);
    return diameter[0];
}

private int height(TreeNode node, int[] diameter) {
    if (node == null) return 0;

    int left = height(node.left, diameter);     // 后序
    int right = height(node.right, diameter);

    diameter[0] = Math.max(diameter[0], left + right);  // 全局更新

    return Math.max(left, right) + 1;          // 返回给父节点
}
// ⚠️ 为什么用 int[] 而非 int？
//   Java 值传递：int 参数修改不生效
//   数组引用传递 → 可以修改内容
//   （或用类字段/全局变量）
```

### 5.3 有状态的应用家族

| 题号 | 题目 | 返回值 | 外部变量 |
|:---:|------|:---:|------|
| 543 | 直径 | 高度 | 左+右 最大值 |
| 124 | 最大路径和 | 单边贡献 | 左+中+右 最大值 |
| 110 | 平衡判断 | 高度（-1 哨兵） | 无（返回值携带状态） |
| 968 | 监控二叉树 | 三状态 | 无 |
| 337 | 打家劫舍 III | 双状态数组 | 无 |

```
⚠️ 记忆口诀：
  "无状态直接返回，有状态外部记录"
  "返回值 = 子树信息，外部 = 全局比较"
```

## 6. 进阶总结

### 6.1 进阶要点速查

```
① 遍历 = 信息流动（前传后聚）
② 迭代三形态：前序先右后左 / 中序左探-回溯-右转 / 后序变体反转
③ Morris：O(1) 空间（建线索，加分项）
④ 六大模式：30 秒识别（层序/后序/前序/中序）
⑤ 有状态 vs 无状态：外部变量 vs 直接返回
```

### 6.2 面试话术模板

```
"这题是【模式】：
 ① 遍历选【后序】（需要子树信息合并）；
 ② 【有状态】——答案可能不经过当前节点，
    用外部数组记录全局，返回值给父节点；
 ③ 复杂度 O(n) 时间 O(h) 空间（h 为树高）。
 追问迭代版：【左探-回溯-右转】模板；
 追问 O(1) 空间：Morris 建线索（加分）。"
```

### 6.3 易错点清单

| 错误 | 后果 | 修正 |
|------|------|------|
| 前序先压左 | 顺序错 | 先右后左 |
| 中序忘右转 | 死循环 | cur = cur.right |
| 有状态用 int | 修改不生效 | int[] 包裹 |
| 层序忘 size | 层混 | 固定本层 |
| 递归深链 | 栈溢出 | 转迭代 |

> 🎯 **核心要点**：树进阶 = **遍历原理**（信息流动方向）+ **迭代三形态** + **Morris**（加分）+ **六大模式识别** + **有状态机制**（int[] 外部变量）。"前传后聚"是遍历本质；"答案可能不经过当前节点 → 有状态"是模式识别关键。
