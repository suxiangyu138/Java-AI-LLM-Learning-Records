## 2. 三大模式识别框架

### 2.1 30 秒模式判定

```
拿到树题 → 问自己三个问题：

① 需要"层/最近/最短"信息吗？
   是 → 层序 BFS（队列 + size 分层）
   否 ↓

② 需要"左右子树答案合并"才能决策吗？
   是 → 后序自底向上（返回值 = 子树信息）
   否 ↓

③ 需要"根的信息向叶子传递"吗？
   是 → 前序自顶向下（状态作参数传递）
   否 → 中序（BST 有序性）或同步遍历（两棵树）
```

### 2.2 模式与代码骨架对应

| 模式 | 代码骨架 | 代表题 |
|------|------|:---:|
| 后序 | `int dfs(node) { l=dfs(left); r=dfs(right); return merge(l,r,node); }` | 104/110/543 |
| 前序 | `void dfs(node, state) { use(state,node); dfs(left,newState); dfs(right,newState); }` | 112/257 |
| 层序 | `Queue + while + int size=q.size()` | 102/199 |
| 同步 | `boolean dfs(a,b) { 比较a,b; dfs(a.left,b.left); }` | 100/101 |
| 有状态 | `void dfs(node, int[] ans)` | 543/124 |

### 2.3 面试现场演示

```
"看到这题，我判断是后序自底向上模式：
 因为节点需要左右子树的高度才能判断是否平衡，
 符合'左右孩子给我答案后能合并出自己答案'的特征。
 我用 -1 哨兵值同时返回高度和平衡状态，一次遍历 O(n)。"
```

## 3. 面试解题话术

```
📣 第 1 步：模式识别 (15秒)
"这题需要子树信息 → 我用后序遍历。
 思路：返回高度，用外部变量记录直径。"

📣 第 2 步：说 Base Case (15秒)
"空节点返回 0。叶子节点自然到达递归出口。"

📣 第 3 步：说合并逻辑 (30秒)
"每个节点：左高度 + 右高度 更新全局答案，
 返回 max(左,右) + 1 给父节点。"

📣 第 4 步：复杂度 (10秒)
"每个节点访问一次：O(n)，递归栈空间 O(h)，h 是树高。"

📣 第 5 步：验证 (30秒)
"我用 [3,9,20,#,#,15,7] 推演一遍：... 结果正确。"
```

## 4. 高频追问与标准回答

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 前中后序遍历分别什么时候用？ | 后序：需要子树信息（高度/直径/平衡/LCA）；前序：根信息向叶子传（路径）；中序：BST 有序性；层序：层/最近/最短 |
| 2 | 递归转迭代怎么转？ | 前序：显式栈先右后左入栈；中序："左探-回溯-右转"循环；后序：前序变体反转 |
| 3 | 为什么中序迭代是必考？ | 考察"递归转迭代"能力 + 显式栈管理状态，是递归思想的逆向检验 |
| 4 | 平衡判断为什么用 -1 哨兵？ | 同时返回高度和状态，一次后序 O(n)，避免朴素解法 O(n²) |
| 5 | 直径为什么用外部变量？ | 路径可能不经过根节点，函数返回值只能表达"经过当前节点的路径"，全局最优需对比所有节点 |
| 6 | 序列化为什么要记空节点？ | 普通二叉树仅靠一种遍历无法唯一还原（如 [1,2,3] 有两种形态），# 占位才能唯一确定 |
| 7 | BST 验证为什么不能只比孩子？ | 左孩子的右子树里可能有大于根的值（如 5→1→4→6），需区间约束或中序递增 |
| 8 | 树为什么适合递归？ | 树是递归结构（子树也是树），递归天然匹配；迭代需显式栈模拟递归 |
| 9 | 树退化成链表怎么办？ | 有序插入 BST → O(n)；用平衡树（AVL/红黑树）保证 log n；Java TreeMap 用红黑树 |
| 10 | Morris 遍历原理？ | 利用叶子空指针建临时线索实现回溯，O(1) 空间；面试了解原理即可 |

## 5. 高频题深度复盘

### 5.1 124. 最大路径和（Hard 突破）

```java
public int maxPathSum(TreeNode root) {
    int[] maxSum = new int[]{Integer.MIN_VALUE};
    maxGain(root, maxSum);
    return maxSum[0];
}

private int maxGain(TreeNode node, int[] maxSum) {
    if (node == null) return 0;
    int left = Math.max(0, maxGain(node.left, maxSum));    // 负数舍弃
    int right = Math.max(0, maxGain(node.right, maxSum));
    maxSum[0] = Math.max(maxSum[0], left + node.val + right);  // T 字形
    return node.val + Math.max(left, right);               // 单边返回
}
```

**复盘要点**：
- `max(0, x)` 是灵魂：负数贡献舍弃，路径不"倒贴"
- 全局 vs 返回的区别：全局可走两边，返回只能走一边
- 初始化 `MIN_VALUE` 防全负数

### 5.2 105. 构造二叉树（Hard 突破）

```java
public TreeNode buildTree(int[] preorder, int[] inorder) {
    Map<Integer, Integer> map = new HashMap<>();
    for (int i = 0; i < inorder.length; i++) map.put(inorder[i], i);
    return build(preorder, 0, preorder.length - 1,
                 inorder, 0, inorder.length - 1, map);
}

private TreeNode build(int[] pre, int pl, int pr,
                       int[] in, int il, int ir, Map<Integer, Integer> map) {
    if (pl > pr) return null;
    int rootVal = pre[pl];
    TreeNode root = new TreeNode(rootVal);
    int rootIdx = map.get(rootVal);       // 中序定位根
    int leftSize = rootIdx - il;          // 左子树大小

    root.left = build(pre, pl + 1, pl + leftSize, in, il, rootIdx - 1, map);
    root.right = build(pre, pl + leftSize + 1, pr, in, rootIdx + 1, ir, map);
    return root;
}
```

**复盘要点**：
- 前序第一个 = 根；中序根左边 = 左子树
- `leftSize = rootIdx - il` 是划分的关键
- 哈希表 O(1) 定位中序下标

## 6. 调试技巧与自检清单

### 6.1 树题自检三步法

```
第 1 步：Base Case 检查
  □ 空节点返回什么？（0 / -1 / null / true？）
  □ 叶子节点能正确到达出口吗？
  □ 高度 vs 计数类返回值有没有混淆？

第 2 步：模式检查
  □ 用的遍历模式对吗？（需要子树信息 → 后序？）
  □ 有状态问题用外部变量了吗？
  □ 路径收集题 add/remove 成对了吗？

第 3 步：测试用例
  □ 空树
  □ 单节点树
  □ 只有左子树（或只有右子树）的树
  □ 满二叉树
  □ 用 [3,9,20,#,#,15,7] 标准树推演
```

### 6.2 高频 Bug 速查表

| Bug | 原因 | 修复 |
|------|------|------|
| 最小深度算错 | 直接把空子树当 0 | 单子树时特判（111 题） |
| 平衡判断 O(n²) | isBalanced 里重复算高度 | -1 哨兵一次遍历 |
| 直径少算 | 没考虑不经过根的路径 | 外部变量全局更新 |
| 路径和负数结果错 | 初始化 0 | 初始化为 MIN_VALUE |
| 路径收集污染 | 忘了回溯 remove | 成对 add/remove |
| BST 验证误判 | 只比较左右孩子 | 区间约束/中序递增 |
| 构造数组越界 | 左右子树边界算错 | 用 leftSize 推导边界 |

### 6.3 面试手写 Checklist

```
□ 说出模式（后序/前序/层序/同步）
□ Base Case 正确
□ 返回值 vs 外部变量分清
□ 递归终止条件正确
□ 有状态用数组包裹（int[] 而非 int）
□ 路径题成对回溯
□ 说出复杂度 O(n)/O(h)
□ 手动跑 1-2 个用例
```

> 🎯 **核心要点**：树的面试本质是**模式识别**——30 秒判断用哪种遍历，然后套模板。三大模式（后序聚合/前序传递/层序扩散）+ 有状态外部变量 + 成对回溯，覆盖 90% 树题。把 TOP 10 题练到闭眼能写，树的回答就有了"骨架感"，面试官最欣赏的就是这种清晰的模式化表达。
