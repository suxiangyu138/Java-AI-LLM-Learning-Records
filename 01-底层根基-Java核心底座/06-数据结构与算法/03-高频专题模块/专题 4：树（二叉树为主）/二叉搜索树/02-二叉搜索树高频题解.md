## 1. 501. BST 中的众数

### 1.1 题目与思路

```
找出 BST 中出现次数最多的值（可能有多个）
核心：中序有序 → 相同值连续出现 → 扫描一遍即可

两种做法：
  ① 中序收集 + 哈希计数：O(n) 空间
  ② 中序双指针（推荐）：O(1) 空间（不算递归栈）
⚠️ 多个众数都要返回（不是只返回一个！）
```

### 1.2 完整代码（O(1) 空间双指针）

```java
/**
 * LeetCode 501. BST 中的众数
 * ⚠️ 双指针：prev 指向中序前一个节点
 *   curCount 当前值连续次数、maxCount 全局最大
 */
List<Integer> modes = new ArrayList<>();
TreeNode prev = null;
int curCount = 0, maxCount = 0;

public int[] findMode(TreeNode root) {
    inorder(root);
    return modes.stream().mapToInt(Integer::intValue).toArray();
}

private void inorder(TreeNode node) {
    if (node == null) return;
    inorder(node.left);

    if (prev != null && prev.val == node.val) {
        curCount++;                        // 连续相同值
    } else {
        curCount = 1;                      // 新值开始
    }

    if (curCount > maxCount) {             // 刷新纪录
        modes.clear();
        modes.add(node.val);
        maxCount = curCount;
    } else if (curCount == maxCount) {     // 并列众数
        modes.add(node.val);
    }
    prev = node;                           // ⚠️ 双指针推进

    inorder(node.right);
}
// 推演 [1,null,2,2]：
//   中序 1(1) → 2(1) → 2(2) → maxCount=2 → 众数 [2] ✓
// ⚠️ 只有中序能这么写——乱序树相同值不连续，哈希才能做
```

## 2. 235. 二叉搜索树的最近公共祖先

### 2.1 题目与思路

```
BST 找 p、q 的最近公共祖先（LCA）
BST 性质秒解：
  p、q 都在左子树 → 去左
  p、q 都在右子树 → 去右
  分叉（一个左一个右）或等于其一 → 当前节点即 LCA

⚠️ 普通二叉树 LCA 需要递归后序（236）；
   BST 版利用有序性 O(h) 直下，是"性质降维"的典范
```

### 2.2 完整代码

```java
/**
 * LeetCode 235. BST 的 LCA（迭代版，O(h)）
 */
public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    TreeNode cur = root;
    while (cur != null) {
        if (p.val < cur.val && q.val < cur.val) {
            cur = cur.left;                    // ① 都在左子树
        } else if (p.val > cur.val && q.val > cur.val) {
            cur = cur.right;                   // ② 都在右子树
        } else {
            return cur;                        // ③ 分叉点 = LCA
        }
    }
    return null;
}
// 推演：树 6, p=2, q=8
//   6：2<6 且 8>6 → 分叉 → 返回 6 ✓
// 推演：p=2, q=4（2 在 4 的左子树，4 是右？）
//   6 → 都 <6 去左 → 2：p.val==cur.val → 分叉 → 返回 2 ✓
// ⚠️ 关键性质：从根向下走，第一个"介于 p、q 之间"的节点就是 LCA
//   （因为 BST 中 p、q 必然分属该节点两侧或就是该节点）
```

## 3. 530/783. 最小绝对差

### 3.1 题目与思路

```
BST 中任意两节点值差的最小绝对值
理论依据：有序序列中，最小相邻差一定出现在"相邻"元素之间
→ 中序遍历，比较相邻节点差

⚠️ 变体 783（节点值最小差）与 530 完全同题
```

### 3.2 完整代码

```java
/**
 * LeetCode 530. 二叉搜索树的最小绝对差
 * ⚠️ 中序相邻比较（双指针）
 */
int minDiff = Integer.MAX_VALUE;
TreeNode prev = null;

public int getMinimumDifference(TreeNode root) {
    inorder(root);
    return minDiff;
}

private void inorder(TreeNode node) {
    if (node == null) return;
    inorder(node.left);
    if (prev != null) {
        minDiff = Math.min(minDiff, node.val - prev.val);  // ⚠️ 相邻差
    }
    prev = node;                       // 双指针推进
    inorder(node.right);
}
// 推演 [4,2,6,1,3]：中序 1,2,3,4,6 → 相邻差 1,1,1,2 → 答案 1 ✓
// ⚠️ 为什么相邻差即答案？设 a<b<c 有序，c-a = (b-a)+(c-b) ≥ 任一相邻差
//   → 最小差值必在相邻元素之间，中序天然覆盖
```

> 🎯 **同族题**：783 同题；501 众数同一"中序双指针"模板；530 是"差值"，501 是"频次"——一个模板两种应用。

## 4. 669. 修剪二叉搜索树

### 4.1 题目与思路

```
删除所有值不在 [lo, hi] 内的节点，返回修剪后的 BST
⚠️ 与 450 删除的区别：450 删单点；669 是区间裁剪
⚠️ 裁剪后结构保持 BST（被裁掉的是整棵子树）

核心观察：
  root.val < lo → 左子树全 < lo → 整棵左子树裁掉 → 答案在右子树
  root.val > hi → 右子树全 > hi → 整棵右子树裁掉 → 答案在左子树
```

### 4.2 完整代码

```java
/**
 * LeetCode 669. 修剪二叉搜索树
 * ⚠️ 递归裁剪：节点本身不合规 → 其整侧子树必然不合规
 */
public TreeNode trimBST(TreeNode root, int lo, int hi) {
    if (root == null) return null;

    if (root.val < lo) {
        return trimBST(root.right, lo, hi);   // ⚠️ 左子树全 < lo，整棵丢弃
    }
    if (root.val > hi) {
        return trimBST(root.left, lo, hi);    // 右子树全 > hi，整棵丢弃
    }

    root.left = trimBST(root.left, lo, hi);   // 合规节点：分别裁剪两子树
    root.right = trimBST(root.right, lo, hi);
    return root;
}
// 推演 [3,0,4,null,2,null,null,1], lo=1, hi=3：
//   root 3 合规 → 左子树 0<1 → 丢弃，去其右子树 2
//     2 合规 → 左子树 1 合规 → 结果 [3,2,null,1] ✓
// ⚠️ 本质：利用 BST 有序性做"整侧剪枝"——这就是区间查询的剪枝思想
```

## 5. 96. 不同的二叉搜索树

### 5.1 题目与思路

```
1..n 能构成多少种不同 BST？（值无关，只看结构）
递推：以 i 为根 → 左子树用 [1..i-1]（i-1 个节点），右子树用 [i+1..n]（n-i 个节点）
  G(n) = Σ G(i-1) × G(n-i)      （i 从 1 到 n）
这就是卡特兰数（Catalan）：G(n) = C(2n, n)/(n+1)

⚠️ 关键认知：BST 结构数只与"节点个数"有关，与具体值无关
   → G(n) 只依赖节点数 n
```

### 5.2 完整代码（DP）

```java
/**
 * LeetCode 96. 不同的二叉搜索树
 * G(n) = Σᵢ₌₁ⁿ G(i-1)·G(n-i)   （卡特兰数 DP）
 */
public int numTrees(int n) {
    int[] G = new int[n + 1];
    G[0] = 1;                    // 空树 1 种
    G[1] = 1;                    // 单节点 1 种

    for (int len = 2; len <= n; len++) {       // ⚠️ 按长度递推
        for (int i = 1; i <= len; i++) {
            G[len] += G[i - 1] * G[len - i];   // 左 i-1 个 × 右 len-i 个
        }
    }
    return G[n];
}
// 推演 G(3) = G(0)G(2) + G(1)G(1) + G(2)G(0)
//        = 1×2 + 1×1 + 2×1 = 5 ✓（经典答案 5 种）
// ⚠️ 变体 95：返回所有树 → 同样递推，但缓存 List<TreeNode>
```

> 🎯 **卡特兰数识别信号**：二叉树计数、合法括号、出栈序列、凸多边形划分——都是卡特兰数：`C(2n,n)/(n+1)`。

## 6. 99. 恢复二叉搜索树

### 6.1 题目与思路

```
恰好两个节点被错误交换，恢复 BST（不改结构）
核心观察：中序应递增 → 交换两个节点后出现"逆序对"

两种情况：
  ① 相邻交换：一个逆序对（如 1,3,2,4）
  ② 不相邻交换：两个逆序对（如 3,2,1 中 3>2、2>1）
⚠️ 算法：中序遍历找逆序对，交换两个异常节点
```

### 6.2 完整代码

```java
/**
 * LeetCode 99. 恢复二叉搜索树（中序 + 逆序对）
 * ⚠️ 关键：找"第一个异常"（较大者）与"最后一个异常"（较小者）
 */
TreeNode prev = null;
TreeNode first = null, second = null;

public void recoverTree(TreeNode root) {
    inorder(root);
    // 交换两个异常节点
    int tmp = first.val;
    first.val = second.val;
    second.val = tmp;
}

private void inorder(TreeNode node) {
    if (node == null) return;
    inorder(node.left);

    if (prev != null && prev.val > node.val) {
        if (first == null) first = prev;   // ⚠️ 第一个逆序对：较大者是 first
        second = node;                     // ⚠️ 每次逆序都更新 second（较小者）
    }
    prev = node;

    inorder(node.right);
}
// 推演 中序 [1,3,2,4]（3、2 相邻交换）：
//   3>2 逆序 → first=3, second=2 → 交换 → [1,2,3,4] ✓
// 推演 [3,2,1]（1、3 不相邻交换）：
//   3>2 逆序 → first=3, second=2
//   2>1 逆序 → second=1（⚠️ 覆盖为更小的）
//   交换 3 与 1 → [1,2,3] ✓
// ⚠️ 思路一句话：第一个逆序对的"前者"+ 最后一个逆序对的"后者"
```

## 7. 109. 有序链表转二叉搜索树

### 7.1 题目与思路

```
升序链表（不能按下标访问）→ 高度平衡 BST
与 108（数组版）区别：链表取中点需要快慢指针 O(n)

两种方案：
  ① 快慢指针找中点（推荐）：每次 O(n)，总 O(n log n)
  ② 中序模拟（更优）：链表顺序 = 中序顺序 → 先构造左子树再取头节点
     → 总 O(n)，但需理解"中序即链表序"的性质
```

### 7.2 完整代码（中序模拟 O(n) 版）

```java
/**
 * LeetCode 109. 有序链表转二叉搜索树 —— 中序模拟版
 * ⚠️ 巧妙点：链表顺序 == BST 中序顺序
 *   → 按中序"左-根-右"顺序取链表节点，天然正确
 */
ListNode cur;                      // 链表游标（全局推进）

public TreeNode sortedListToBST(ListNode head) {
    int n = 0;
    for (ListNode p = head; p != null; p = p.next) n++;   // 长度
    cur = head;
    return build(0, n - 1);
}

private TreeNode build(int lo, int hi) {
    if (lo > hi) return null;
    int mid = lo + (hi - lo) / 2;
    TreeNode left = build(lo, mid - 1);        // ⚠️ 先建左子树
    TreeNode root = new TreeNode(cur.val);     // 中序：取链表头（当前最小值）
    cur = cur.next;                            // ⚠️ 链表推进
    root.left = left;
    root.right = build(mid + 1, hi);           // 再建右子树
    return root;
}
// 推演 [1,2,3]：build(0,2) → 左 build(0,0) → 左 build(0,-1) null
//   → root=1, cur→2；右 build(1,1) → root=2？不——
//   实际：build(0,2): 左=build(0,0)（左=null, root=1, cur→2, 右=null）
//   → root=2, cur→3 → 右=build(2,2)（root=3）
//   结果：2 为根，左 1 右 3 ✓
// 方案对比：快慢指针版 O(n log n) 好懂；中序模拟 O(n) 显功力
```

## 8. 1382. 将二叉搜索树变平衡

### 8.1 题目与思路

```
BST 可能不平衡（如按序插入构造）→ 重新平衡（保持 BST）
标准两步：
  ① 中序收集 → 有序数组（O(n)）
  ② 108 模板：中位数为根递归重建（O(n)）
⚠️ 思路价值：把"平衡"问题转化为"有序结构转换"问题
```

### 8.2 完整代码

```java
/**
 * LeetCode 1382. 将二叉搜索树变平衡
 * 中序收集 → 二分重建（两道模板的组合应用）
 */
public TreeNode balanceBST(TreeNode root) {
    List<Integer> sorted = new ArrayList<>();
    inorder(root, sorted);                    // ① 中序 → 有序列表
    return build(sorted, 0, sorted.size() - 1);  // ② 108 重建
}

private void inorder(TreeNode node, List<Integer> sorted) {
    if (node == null) return;
    inorder(node.left, sorted);
    sorted.add(node.val);                     // ⚠️ 中序 = 升序
    inorder(node.right, sorted);
}

private TreeNode build(List<Integer> sorted, int lo, int hi) {
    if (lo > hi) return null;
    int mid = lo + (hi - lo) / 2;             // 中位数根 → 天然平衡
    TreeNode root = new TreeNode(sorted.get(mid));
    root.left = build(sorted, lo, mid - 1);
    root.right = build(sorted, mid + 1, hi);
    return root;
}
// 复杂度：O(n)（中序 O(n) + 重建 O(n)）
// ⚠️ 通用思想："树结构问题 → 中序变数组 → 数组重建"
//   适用于：平衡、序列化（449）、恢复等一大家族
```

/** ⚠️ 万能中序双指针骨架（501/530/99 共用） */
TreeNode prev = null;

void inorder(TreeNode node) {

    inorder(node.left);
