## 1. 区间贪心模型：排序是前提

```text
区间题第一步永远相同: 按特定规则排序（无排序，无贪心）

三种排序规则（由目标决定）:
  右端点升序 → 选最多不重叠区间（435/452）——"最早结束留最大空间"
  左端点升序 → 合并重叠区间（56）——"按起点推进合并"
  其他（长度/右端）→ 按具体贪心目标定

核心模板（以"选最多不重叠"为例）:
  ① 按右端点升序排序
  ② 记录"已选区间右端点"（lastEnd）
  ③ 遍历: 左端点 ≥ lastEnd → 选（更新 lastEnd）；否则跳过

⚠️ 贪心论证（面试必答）:
  "选最早结束的区间，给后面留下的可选空间最大——
   如果最优解选了结束更晚的，换成最早的不会变差（交换论证）"
```

> 🎯 **核心认知**："**区间贪心的灵魂 = '排序规则 × 贪心策略'的配对**——'最早结束'配右端点升序、'合并推进'配左端点升序。排序字段选错，贪心策略直接失效，这是区间题第一失分点。"

## 2. 435 无重叠区间（右端点升序模板）

### 2.1 题目与思路

**题**：移除最少区间使剩余互不重叠。

**反问题**：先求"最多不重叠区间数"，总数减它：

```java
/**
 * LeetCode 435. 无重叠区间
 * 贪心: 按右端点升序，选最早结束的（留最大空间）
 * 时间 O(n log n)，空间 O(1)
 */
public int eraseOverlapIntervals(int[][] intervals) {
    Arrays.sort(intervals, (a, b) -> Integer.compare(a[1], b[1]));  // ① 右端点升序

    int count = 1;                             // ② 至少选第一个
    int lastEnd = intervals[0][1];
    for (int i = 1; i < intervals.length; i++) {
        if (intervals[i][0] >= lastEnd) {      // ③ 左端点 ≥ 已选右端 → 不重叠
            count++;                           //    选它
            lastEnd = intervals[i][1];         //    更新右端点
        }
        // ④ 重叠 → 跳过（保留 lastEnd 更小的——已是最优）
    }
    return intervals.length - count;           // ⑤ 移除数 = 总数 − 最多保留
}
// 推演 [[1,2],[2,3],[3,4],[1,3]]：排序 [1,2][1,3][2,3][3,4]
//   选 [1,2]；[1,3] 重叠跳过；[2,3] 选；[3,4] 选 → 保留 3 → 移除 1 ✓
// ⚠️ 排序比较器: Integer.compare(a[1], b[1]) 防极端坐标溢出
```

> 💡 **为什么右端点升序**："**结束越早 → 留给后面的空间越大 → 能选更多**——这是'最早结束'贪心的交换论证（05 文件详讲）。435 是区间贪心的母题模板。"

## 3. 56 合并区间（左端点升序）

### 3.1 题目与思路

**题**：合并所有重叠区间。

**左端点升序 + 合并推进**：

```java
/**
 * LeetCode 56. 合并区间
 * 贪心: 左端点升序，逐个合并（重叠则扩展右端）
 * 时间 O(n log n)，空间 O(n)（结果）
 */
public int[][] merge(int[][] intervals) {
    Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));  // ① 左端点升序

    List<int[]> result = new ArrayList<>();
    result.add(intervals[0]);                  // ② 先放第一个

    for (int i = 1; i < intervals.length; i++) {
        int[] last = result.get(result.size() - 1);
        if (intervals[i][0] <= last[1]) {      // ③ 左端 ≤ 已合并右端 → 重叠
            last[1] = Math.max(last[1], intervals[i][1]);  // ④ 扩展右端（取大）
        } else {
            result.add(intervals[i]);          // ⑤ 不重叠 → 新开一段
        }
    }
    return result.toArray(new int[0][]);
}
// 推演 [[1,3],[2,6],[8,10],[15,18]] → [[1,6],[8,10],[15,18]] ✓
// ⚠️ 为什么左端点升序: 保证"当前区间起点 ≥ 已合并起点"——
//   只需判断是否与"最后一个"重叠（前面的已全部合完）
```

> 💡 **左右端点的分工**："**435 右端点升序（选最多）、56 左端点升序（合并推进）**——'要选数'看右端、'要合并'看左端。排序字段的选择由贪心目标决定，这是区间题的核心判断。"

## 4. 452 用最少数量的箭引爆气球

### 4.1 题目与思路

**题**：最少的箭引爆所有气球（区间重叠可共射）。

**箭放右端点**（贪心：每箭射在"当前区间右端点"，覆盖最多后续）：

```java
/**
 * LeetCode 452. 用最少数量的箭引爆气球
 * 贪心: 箭放右端点——覆盖最多后续气球
 * 时间 O(n log n)，空间 O(1)
 */
public int findMinArrowShots(int[][] points) {
    Arrays.sort(points, (a, b) -> Integer.compare(a[1], b[1]));  // ① 右端点升序

    int arrows = 1;                            // ② 至少一箭
    int arrowPos = points[0][1];               // ③ 第一箭放第一个气球右端
    for (int i = 1; i < points.length; i++) {
        if (points[i][0] > arrowPos) {         // ④ 左端 > 箭位置 → 没被射到
            arrows++;                          //    需要新箭
            arrowPos = points[i][1];           //    新箭放当前右端
        }
        // ⑤ 左端 ≤ 箭位置 → 被覆盖（共射）
    }
    return arrows;
}
// 推演 [[10,16],[2,8],[1,6],[7,12]] → 2 支箭 ✓
//   （箭 6 射 [1,6][2,8]；箭 12 射 [7,12][10,16]）
// ⚠️ 与 435 的差异: 452 区间重叠可共射（左端 ≤ 箭位置即可）；
//   435 重叠要移除——"是否允许触碰"由题意决定
```

> 🎯 **452 的贪心论证**："**箭放右端点 = 在'最靠右还能覆盖当前'的位置射——这样能覆盖尽量多的后续气球**。与 435 的'最早结束'同一哲学：为后续留最大空间。"

## 5. 763 划分字母区间（贪心 + 最后位置）

### 5.1 题目与思路

**题**：把字符串划分成尽可能多的片段，每片段内字符不跨片段出现。

**贪心 + 最后出现位置**：先记每个字符最后位置，扫描时扩展当前片段边界：

```java
/**
 * LeetCode 763. 划分字母区间
 * 贪心: 每字符最后位置 = 片段边界下界，扫描扩展
 * 时间 O(n)，空间 O(26)
 */
public List<Integer> partitionLabels(String s) {
    int[] last = new int[26];                  // ① 每字符最后出现位置
    for (int i = 0; i < s.length(); i++) {
        last[s.charAt(i) - 'a'] = i;
    }

    List<Integer> result = new ArrayList<>();
    int start = 0, end = 0;
    for (int i = 0; i < s.length(); i++) {
        end = Math.max(end, last[s.charAt(i) - 'a']);   // ② 扩展片段边界
        if (i == end) {                        // ③ 到达边界 → 片段结束
            result.add(end - start + 1);
            start = end + 1;
        }
    }
    return result;
}
// 推演 "ababcbacadefegdehijhklij" → [9,7,8] ✓
// ⚠️ 贪心点: 每片段结束时"尽可能早"——在边界处立刻切
//   与区间贪心同构: 每个字符的 [首现, 末现] 是区间，找最多不重叠
```

> 💡 **763 与区间贪心的同构**："**763 = 区间贪心的字符串版——每字符的 [首现, 末现] 就是一个区间，划分 = 选最多不重叠区间**。识别'字符串区间化'是贪心进阶的标志。"

## 6. 区间四题模板对照

| 题 | 排序规则 | 贪心策略 | 判断条件 |
|:---:|:---:|------|------|
| 435 无重叠 | 右端点升序 | 选最早结束 | `左 ≥ lastEnd` 选 |
| 56 合并 | 左端点升序 | 合并推进 | `左 ≤ last[1]` 合并 |
| 452 气球 | 右端点升序 | 箭放右端 | `左 > arrowPos` 新箭 |
| 763 字母区间 | 无（字符末位） | 边界扩展 | `i == end` 切片 |

```text
⚠️ 模板记忆:
  "右端升序管'选'（435/452），左端升序管'并'（56）
   重叠判据: 435/56 用 ≤、452 用 >——边界是否允许触碰由题意定"
```

## 7. 区间贪心易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 忘排序 | 先排序再贪心 | 策略失效 |
| 2 | 排序字段选错 | 右端升序（435）/左端升序（56） | 答案错误 |
| 3 | 边界相等处理错 | 435 用 `>=`（可触碰）；452 用 `>`（触碰共射） | 边界误判 |
| 4 | 比较器溢出 | `Integer.compare(a[1], b[1])` | 极端坐标溢出 |
| 5 | 56 忘取 max 右端 | `last[1] = Math.max(...)` | 漏合并 |
| 6 | 空数组特判 | `intervals.length == 0` | 越界 |
| 7 | 763 忘初始化 last | 先扫一遍记末位 | 边界错误 |

> 🎯 **核心要点**：区间贪心通关四件事——**① 无排序无贪心**（排序字段由目标定）；**② 435 母题模板**（右端升序 + lastEnd）；**③ 56 合并**（左端升序 + 扩展右端）；**④ 452/763 变体**（箭放右端、字符串区间化）。**区间是贪心第一核心（35%+）——'右端管选、左端管并'八个字，四题全通**。
