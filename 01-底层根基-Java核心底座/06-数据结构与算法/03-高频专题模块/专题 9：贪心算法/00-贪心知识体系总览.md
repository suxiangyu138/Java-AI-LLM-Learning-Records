## 1. 知识体系导图

```text
贪心算法（Greedy）
│
├── 核心本质 ──────────────────────────────────────────────
│   ├── = 局部最优选择 + 逐步推导全局最优
│   ├── 无记录、不回看历史（与 DP 的本质区别）
│   ├── 两大性质: 贪心选择性质 + 最优子结构
│   └── 难点: 代码短，但"为什么当前选择不破坏全局"要能证明
│
├── 五大题型（面试分布）───────────────────────────────────
│   ├── 区间类（35%+ 第一核心）: 435/56/452/763 —— 排序是前提
│   ├── 数值分配/选择（20%+）: 455/135/860 —— 排序 + 双指针
│   ├── 序列构造/优化（15%+）: 376/402/738 —— 单调性
│   ├── 堆辅助贪心（15%+）: 621 任务调度/347 —— 贪心 + 堆
│   └── 经典贪心（15%+）: 55/45/134/121/122 —— 最远可达
│
├── 两大性质（面试必答）──────────────────────────────────
│   ├── 贪心选择性质: 全局最优可通过局部最优得到（不后悔）
│   ├── 最优子结构: 全局最优包含子问题最优（与 DP 共性）
│   └── 反例警示: 找零 [1,3,4] 凑 6 → 贪心 4+1+1 非最优 → 用 DP
│
├── 证明方法 ─────────────────────────────────────────────
│   ├── 交换论证: 贪心解可交换成不差于最优解
│   ├── 反证法: 假设贪心非最优 → 推出矛盾
│   └── 边界直觉: "选最早结束 = 留最大空间"（区间调度）
│
└── 实战与面试 ────────────────────────────────────────────
    ├── 手写: 区间三题模板 + 跳跃/股票（5 分钟）
    ├── 易错: 排序字段错、边界相等、贪心两头兼顾
    ├── 复杂度: O(n)（跳跃/股票）/ O(n log n)（区间/分配）
    └── 话术: "策略 + 为什么成立"双段式（只背模板会失分）
```

## 4. 核心概念速查

| 概念 | 一句话解释 | 说明 |
|------|-----------|------|
| **贪心** | 每步选局部最优，推导全局最优 | 无记录不回看 |
| **贪心选择性质** | 全局最优可通过局部最优得到 | 当下选最优，后续不后悔 |
| **最优子结构** | 全局最优包含子问题最优 | 与 DP 的共性 |
| **无后效性** | 决策只依赖当前状态 | 贪心可用的前提 |
| **区间调度** | 选最多不重叠区间 | 右端点升序 + 最早结束 |
| **最远可达** | 维护 farthest 边界 | 跳跃类核心 |
| **双向贪心** | 左右各贪一次 | 135 分糖果（每次只贪一个方向） |
| **交换论证** | 贪心解可交换成不差于最优 | 证明方法 |
| **找零反例** | [1,3,4] 凑 6 贪心非最优 | 贪心不适用的警示 |

## 5. 题型模式速查

### 5.1 五大题型 → 策略 → 代表题

| 题型 | 贪心策略 | 排序？ | 代表题 |
|------|------|:---:|:---:|
| 区间 | 最早结束/合并/箭在右端 | ✔ 必排序 | 435/56/452 |
| 分配 | 最小满足最不贪婪 | ✔ 双排序 | 455/135 |
| 跳跃/股票 | 最远可达/只加正差 | ✘ | 55/45/122 |
| 构造 | 单调性/字典序 | 部分 | 402/738/376 |
| 堆辅助 | 高频先做/冷却 | ✘（堆） | 621/347 |

### 5.2 识别信号

```text
"区间/重叠/气球" → 排序 + 区间贪心
"最多/最少 + 可达/步数" → 最远可达
"买卖/差价" → 只累加正差值
"分配/满足" → 排序 + 双指针
"贪心 vs DP 怎么选" → 有无后效性（05 文件）

⚠️ 关键判断: 问题能否"排序"或"维护当前最优边界"？
  能 → 大概率贪心；不能 → 考虑 DP
```

> 🎯 **一句话定位**："**贪心 = '每步最优 + 不后悔'——区间排序、跳跃划界、股票加正差、分配双指针**。代码短但证明难：面试只背模板不解释'为什么'，追问必失分（2025 面试共识）。"

## 6. 常见误区速查

| 误区 | 正解 |
|------|------|
| "贪心就是每次选最大的" | ❌ 要按题型策略（最早结束/最远可达/正差值），不是无脑最大 |
| "贪心题不用排序" | ❌ 区间/分配类**必须排序**——排序字段选错答案就错 |
| "135 一次遍历够" | ❌ 双向贪心——每次只贪一个方向，两次遍历取 max |
| "贪心 = DP" | ❌ 贪心不回看历史（无记录）；DP 依赖前面多个状态 |
| "所有题都能贪心" | ❌ 找零 [1,3,4] 凑 6 → 贪心非最优——先验证两大性质 |
| "452 箭在左端点也行" | ❌ 箭放右端点（覆盖更多后续气球） |
| "跳跃 II 每步跳最远" | ❌ 是"当前覆盖范围内再探一步的最远"（双边界） |
| "只背模板就行" | ❌ 追问"为什么贪心成立"答不出 = 失分（2025 面试共识） |
| "714 手续费重复扣" | ❌ 卖出后 `minPrice = price − fee` 防重复扣 |
| "贪心复杂度恒 O(n)" | ❌ 区间/分配含排序 O(n log n)；堆辅助 O(n log k) |
