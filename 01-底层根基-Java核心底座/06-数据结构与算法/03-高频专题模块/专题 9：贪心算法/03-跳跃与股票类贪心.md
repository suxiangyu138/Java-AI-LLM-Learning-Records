## 1. 边界维护模型：无排序贪心

```text
与前两类（区间/分配）不同，跳跃/股票类不需要排序——
它们共享"维护当前最优边界"的模型:

  ① 只关心"边界值"（最远可达 / 最低价 / 累计收益）
  ② 遍历时更新边界（O(n) 一次扫描）
  ③ 不排序、不回溯——边界信息足够决策

无后效性论证（面试必答）:
  "局部决策只保留对后续有用的信息（最远可达/最低价），
   不产生负面约束 → 后续决策不用回头看 → O(n)/O(1)"

⚠️ 识别信号:
  "最多/最少 + 可达/步数/利润" → 边界维护贪心
```

> 🎯 **核心认知**："**边界维护贪心 = '忘记过去，只留边界'——历史信息压缩成一个边界值，后续决策只看边界**。'无后效性'在这里体现得最纯粹：121 只留最低价、55 只留最远可达。"

## 2. 55 跳跃游戏（最远可达）

### 2.1 题目与思路

**题**：能否跳到末尾（每位置最大跳跃步数）。

**最远可达边界**：只关心"当前能覆盖到哪"，不关心具体从哪跳：

```java
/**
 * LeetCode 55. 跳跃游戏
 * 贪心: 维护最远可达位置，遍历范围内扩展
 * 时间 O(n)，空间 O(1)
 */
public boolean canJump(int[] nums) {
    int farthest = 0;                          // ① 最远可达
    for (int i = 0; i < nums.length; i++) {
        if (i > farthest) return false;        // ② 当前位置都到不了 → 失败
        farthest = Math.max(farthest, i + nums[i]);   // ③ 扩展可达边界
        if (farthest >= nums.length - 1) return true; // ④ 已覆盖末尾
    }
    return true;
}
// 推演 [2,3,1,1,4]：far: 0→2→4 → true ✓
//   [3,2,1,0,4]：i=3 时 far=3（跳不动）→ i=4 > 3 → false ✓
// ⚠️ 为什么正确: 可达范围 [0, farthest] 内所有位置都可达——
//   边界内任意点都能作为跳板，扩展是"累积"而非"单个"
```

> 🎯 **55 的贪心论证**："**'可达范围是连续的区间 [0, farthest]'——边界内的点都能到达，都能作为跳板**。这就是为什么只维护 farthest 一个值就够：区间性质让单点信息代表全部。"

## 3. 45 跳跃游戏 II（双边界最少步数）

### 3.1 题目与思路

**题**：最少跳跃次数到末尾（保证可达）。

**双边界**：`curEnd`（当前步数覆盖的最远）+ `farthest`（覆盖范围内再跳一步能到的最远）：

```java
/**
 * LeetCode 45. 跳跃游戏 II
 * 双边界: curEnd（当前步覆盖）+ farthest（再跳一步的最远）
 * 时间 O(n)，空间 O(1)
 */
public int jump(int[] nums) {
    int steps = 0, curEnd = 0, farthest = 0;

    for (int i = 0; i < nums.length - 1; i++) {   // ① 不遍历最后一位
        farthest = Math.max(farthest, i + nums[i]);   // ② 探一步的最远
        if (i == curEnd) {                       // ③ 当前步覆盖用尽
            steps++;                             //    必须多跳一步
            curEnd = farthest;                   //    新覆盖 = 探到的最远
        }
    }
    return steps;
}
// 推演 [2,3,1,1,4]：
//   i=0: far=2；i==curEnd(0) → steps=1, curEnd=2
//   i=1: far=4；i=2: far=4；i==curEnd(2) → steps=2, curEnd=4
//   结束 steps=2 ✓
// ⚠️ 为什么不是"每步跳最远": 局部最远可能浪费——
//   正确策略是"当前覆盖范围内，探一步的最远"（贪心于"下一步的覆盖"）
```

> 💡 **45 与 55 的关系**："**45 = 55 + 步数统计——55 只维护 farthest，45 加一个 curEnd 当'步数分界'**。'curEnd 用尽才加步'保证每步都物尽其用，这是 45 的核心直觉。"

## 4. 134 加油站（环形贪心）

### 4.1 题目与思路

**题**：环形加油站，找能走完全程的起点（唯一或 -1）。

**全局判定 + 局部重置**：总油 < 总耗 → 无解；否则"最低点之后"必可行：

```java
/**
 * LeetCode 134. 加油站
 * 时间 O(n)，空间 O(1)
 * ⚠️ 核心: 总油 ≥ 总耗 → 存在唯一起点；
 *   局部剩余为负 → 起点必在 i+1 之后
 */
public int canCompleteCircuit(int[] gas, int[] cost) {
    int total = 0, current = 0, start = 0;
    for (int i = 0; i < gas.length; i++) {
        total += gas[i] - cost[i];              // ① 全局判定
        current += gas[i] - cost[i];
        if (current < 0) {                      // ② 从 start 走到 i 不行
            start = i + 1;                      //    起点必在 i+1 之后
            current = 0;                        //    重置局部剩余
        }
    }
    return total < 0 ? -1 : start;              // ③ 全局可行 → start 必可行
}
// 推演 gas=[1,2,3,4,5], cost=[3,4,5,1,2]：
//   total=0 ≥ 0 → 有解；current: -2,-2,-2,3,6 → start=3 ✓
// ⚠️ 证明直觉: 总油 ≥ 总耗时，存在"唯一最低前缀和点"——
//   从它下一点起步，全程油量不会为负
```

> 🎯 **134 的环形思维**："**'全局可行 + 局部重置'两步——总油判定有无解、负剩余重置起点**。环形题的经典套路：先证明存在性（全局），再定位起点（局部）。"

## 5. 股票家族：121/122/714

### 5.1 家族全景

| 题 | 交易次数 | 贪心策略 | 复杂度 |
|:---:|:---:|------|:---:|
| 121 一次 | 1 | 维护历史最低价 | O(n)/O(1) |
| 122 多次 | ∞ | 只累加正差值 | O(n)/O(1) |
| 714 多次+手续费 | ∞ | 正差值 − 手续费（防重复扣） | O(n)/O(1) |
| 309 冷冻期 | ∞ | 需要状态 → **DP**（贪心失效） | O(n) |

### 5.2 714 含手续费（贪心 + 防重复扣）

```java
/**
 * LeetCode 714. 买卖股票的最佳时机含手续费
 * 贪心: 利润 > 手续费才卖；卖出后最低价调整为 price−fee（防重复扣）
 * 时间 O(n)，空间 O(1)
 */
public int maxProfit(int[] prices, int fee) {
    int minPrice = prices[0];                   // ① 当前"有效买入价"
    int profit = 0;
    for (int i = 1; i < prices.length; i++) {
        if (prices[i] < minPrice) {
            minPrice = prices[i];               // ② 更低价 → 更新买入点
        } else if (prices[i] > minPrice + fee) {   // ③ 利润 > 手续费 → 卖
            profit += prices[i] - minPrice - fee;
            minPrice = prices[i] - fee;         // ④ ⚠️ 防重复扣手续费
        }
    }
    return profit;
}
// 推演 [1,3,2,8,4,9], fee=2 → 8 ✓
// ⚠️ minPrice = price − fee 的含义: 把"已卖"视为"以扣除手续费后的
//   价格重新买入"——后续若继续涨，不再重复扣手续费
```

> 💡 **714 的陷阱**："**'卖出后把买入价调整为 price−fee'是 714 的灵魂**——不加这行，连续上涨会被重复扣手续费（如 1→5→9 手续费扣两次）。这个细节是股票家族的进阶考点。"

## 6. 跳跃与股票对比

| 维度 | 跳跃（55/45） | 股票（121/122） |
|------|:---:|:---:|
| 边界信息 | 最远可达 | 最低价 / 累计利润 |
| 遍历 | 一次扫描 | 一次扫描 |
| 排序 | 不需要 | 不需要 |
| 无后效性 | 区间可达性 | 只留最低价 |
| 变体方向 | 最少步数（双边界） | 手续费/冷冻期（714 贪心、309 转 DP） |

```text
⚠️ 边界提示:
  309 冷冻期 → 贪心失效 → 必须 DP（状态机三态）
  45 变体（可回退）→ 复杂化 → 考虑 DP
  → "贪心能解是幸运，DP 是保底"——面试主动说清边界
```

## 7. 边界维护易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 55 先更新 far 再判 i>far | 先判 i>far 再扩展 | 越界位置被"覆盖" |
| 2 | 45 遍历到最后一位 | `i < n−1`（最后不需跳） | 多计一步 |
| 3 | 45 每步跳最远 | 覆盖范围内探一步最远 | 步数虚增 |
| 4 | 134 忘全局判定 | `total < 0` 返回 -1 | 误报起点 |
| 5 | 714 忘防重复扣 | `minPrice = price − fee` | 手续费重复扣 |
| 6 | 121 更新顺序反 | 先 min 后利润 | 利润错 |
| 7 | 309 用贪心 | 转 DP（状态机） | 答案错误 |

> 🎯 **核心要点**：跳跃与股票通关四件事——**① 无后效性论证**（只留边界）；**② 55/45 双边界**（curEnd 分界步数）；**③ 134 环形**（全局可行 + 局部重置）；**④ 股票家族**（121 最低价/122 正差值/714 防重复扣）。**边界维护贪心是 O(n)/O(1) 的典范——'历史压缩成边界'这一句，就是它的全部哲学**。
