## 1. 为什么需要证明

```text
贪心题的特性: 代码 10 行、证明 10 分钟——
  写对容易，写"为什么对"难

面试真相（2025 共识）:
  "只背模板不解释为什么，容易在追问里失分"
  → 贪心题的完整答案 = 策略 + 证明（双段式）

三大证明工具:
  ① 交换论证: 贪心解可交换成不差于最优解（最常用）
  ② 反证法: 假设贪心非最优 → 推出矛盾
  ③ 边界直觉: 直观解释"留最大空间/高位优先"

⚠️ 证明的粒度:
  面试不需要严格数学证明——讲清"为什么当前选择
  不会堵死后续最优"的直觉论证即可
```

> 🎯 **核心认知**："**贪心证明的本质 = 回答'为什么局部最优不破坏全局最优'**——交换论证是主力（可构造性）、反证是兜底、边界直觉是速答。三选一讲清楚，贪心题就完整了。"

## 2. 证明一：交换论证（最常用）

### 2.1 方法框架

```text
交换论证四步:
  ① 假设最优解 OPT（不按贪心策略）
  ② 找到贪心选择与 OPT 的第一个不同点
  ③ 证明"把 OPT 的该选择换成贪心选择"不会变差（交换）
  ④ 反复交换 → OPT 可变成贪心解且不差 → 贪心最优

经典案例（区间调度 435）:
  ① OPT 选了 [3,5]，贪心选了最早结束的 [1,2]
  ② 第一个不同: OPT 的第一个区间不是最早结束的
  ③ 交换: 把 [3,5] 换成 [1,2]——
     [1,2] 结束更早 → 给后续留的空间 ≥ 原方案 → 不差
  ④ 反复交换 → OPT 可转化为贪心解 → 贪心最优 ✓
```

### 2.2 面试表达模板

```text
"假设最优解第一个区间不是最早结束的 [1,2] 而是 [3,5]——
  把 [3,5] 换成 [1,2] 后：
  ① [1,2] 与后续区间不冲突（结束更早，冲突只会更少）
  ② 剩余区间可选的起点更早（空间更大）
  所以交换后方案不差 → 反复交换 → 贪心解就是最优。"

⚠️ 通用句式: "把最优解的第一个不同点换成贪心选择，
   不会变差（理由：______）→ 贪心最优"
```

> 🎯 **交换论证的万能性**："**'找到第一个不同点 → 交换不差 → 反复交换'是证明贪心最优的通用引擎**——435 换区间、455 换饼干、452 换箭位全部适用。面试被问'为什么贪心对'，交换论证是最稳的回答。"

## 3. 证明二：反证法

### 3.1 方法框架

```text
反证法三步:
  ① 假设贪心解不是最优（存在更好的解 G'）
  ② 分析贪心解与 G' 的差异，推出矛盾
  ③ 矛盾 → 假设不成立 → 贪心最优

经典案例（55 跳跃）:
  ① 假设存在更少步数的方案
  ② 任何方案的每一步，其"可达范围"不超过贪心的 farthest——
     贪心在每一步都取最大 farthest（覆盖一切可能）
  ③ 贪心的覆盖范围 ⊇ 任何方案的覆盖范围
     → 贪心可达，其他方案必可达 → 不存在更优 → 贪心最优 ✓
```

### 3.2 适用场景

```text
交换论证难构造时 → 反证:
  边界维护类（55/45/134）——贪心解是"最大覆盖"，
  证明"任何方案都超不过"即可

⚠️ 识别: "维护最大/最小边界"的贪心 → 反证更自然
   （"覆盖一切可能"的论证方式）
```

> 💡 **反证的直觉**："**边界维护贪心的反证 = '贪心覆盖一切可能'**——最远可达已经是上界，任何方案都不可能超过它。'上界论证'是反证法在贪心里的标准形态。"

## 4. 证明三：边界直觉

### 4.1 三个高频直觉论证

```text
① "最早结束 = 留最大空间"（435/452）
   选结束更早的区间，后面可选的空间只会更大

② "高位优先 = 权重最大"（402/738）
   数字的高位权重远大于低位——修高位收益最大

③ "最不通用先用 = 保通用资源"（860）
   10 元只能找 20、5 元什么都能找——先用 10 保 5

⚠️ 使用时机: 面试时间紧/题目直观——
   "直觉 + 一句'可交换论证严格化'"即可
```

### 4.2 直觉 vs 严格

```text
面试答法分层:
  简单题: 边界直觉（30 秒）
  中档题: 直觉 + "交换论证可严格化"（1 分钟）
  hard/追问: 完整交换论证（2 分钟）

⚠️ 原则: 讲不出严格证明，至少给出直觉——
  "不说为什么"是贪心面试的绝对禁区
```

## 5. 贪心 vs DP：无后效性判据

### 5.1 完整对比

| 维度 | 贪心 | 动态规划 |
|------|:---:|:---:|
| 决策 | 当前一步直接选 | 依赖前面多个状态 |
| 历史 | 不回看（压缩成边界） | dp[] 保存全部子问题 |
| 后效性 | 必须无后效性 | 允许有后效性（状态表达） |
| 复杂度 | 常 O(n)/O(n log n) | 常 O(n²)/O(n·k) |
| 证明 | 贪心选择性质 | 最优子结构 + 重叠子问题 |
| 代表 | 区间/跳跃/分配 | 背包/子序列/编辑距离 |

### 5.2 无后效性判定（面试必答）

```text
问自己: "当前的决策会影响'以后'的决策空间吗？"
  不影响（决策只产生对后续有用的信息）→ 贪心
  影响（决策限制了后续选择）→ DP

例:
  121 股票: 只留最低价 → 无后效 → 贪心 ✓
  背包: 选了物品 A 占容量 → 影响后续 → DP ✓
  309 冷冻期: 卖了要等一天 → 状态影响后续 → DP ✓

⚠️ 一句话: "无后效 → 贪心（快）；有后效 → DP（稳）"
```

> 🎯 **选型决策**："**'无后效性'是贪心与 DP 的分水岭——贪心把历史压缩成边界、DP 把历史存进状态数组**。面试被问'为什么不用 DP'：'这题无后效性，贪心 O(n) 就够了，DP 是保底但不是最优'。"

## 6. 找零反例深潜：贪心何时成立

### 6.1 反例回顾

```text
[1, 3, 4] 凑 6:
  贪心: 4+1+1 = 3 枚；最优: 3+3 = 2 枚 → 贪心失效

为什么 [1, 5, 10, 25] 贪心成立:
  大面额是小面额的倍数（25=5×5、10=5×2、5=5×1）
  → 大面额"严格优于"若干小面额（5 枚 5 分 = 1 枚 25 分，枚数更多）
  → 贪心选择性质成立

⚠️ 结论: "面额呈倍数关系 → 贪心成立；
   否则（如 [1,3,4]）→ 必须 DP（完全背包）"
```

### 6.2 面试表达

```text
"找零贪心的成立条件 = 面额之间的倍数关系——
  [1,5,10,25] 每枚大硬币都可被小硬币'无损替代'，
  贪心'尽量用大面额'必然最少；
  [1,3,4] 凑 6 时 4 不是 3 的倍数，贪心选 4 堵死了 3+3。
  所以找零默认 DP，特殊面额才贪心。"
```

> 💡 **反例的体系价值**："**找零反例是'贪心需要验证'的最佳教材——它同时展示了两大性质的含义**：贪心选择性质不满足（选 4 后悔了）。面试主动举它，说明你理解贪心的边界。"

## 7. 可贪 vs 不可贪决策表

### 7.1 经典题清单

| 题 | 贪心？ | 原因 |
|:---:|:---:|------|
| 435 区间调度 | ✔ | 最早结束交换论证 |
| 55/45 跳跃 | ✔ | 最远可达覆盖一切 |
| 121/122 股票 | ✔ | 只留边界（无后效） |
| 455 饼干 / 860 找零 | ✔ | 排序 + 通用性 |
| 135 糖果 / 376 摆动 | ✔ | 双向/趋势 |
| 402/738 单调构造 | ✔ | 高位优先 |
| 背包 0/1 | ✘ | 容量占用有后效 → DP |
| 编辑距离 | ✘ | 依赖多状态 → DP |
| 找零 [1,3,4] | ✘ | 无倍数关系 → DP |
| 309 冷冻期股票 | ✘ | 状态机 → DP |
| TSP 旅行商 | ✘ | 全局强耦合 → 搜索/近似 |

### 7.2 快速决策流程

```text
① 能排序或维护边界？ → 尝试贪心
② 无后效性？ → 贪心成立（O(n)/O(n log n)）
③ 有后效/局部冲突？ → 退回 DP 或搜索

⚠️ 面试保险: 写贪心前 30 秒验证——
  "我先验证贪心是否成立：小样例 + 无后效性判断；
   若不成立退回 DP。"（展示严谨性 = 加分）
```

> 🎯 **核心要点**：证明与选型通关四件事——**① 三大证明工具**（交换论证主力/反证兜底/直觉速答）；**② 无后效性判据**（贪心 vs DP 分水岭）；**③ 找零反例**（倍数关系 = 贪心成立条件）；**④ 可贪清单**（区间/跳跃/股票可贪，背包/编辑距离不可）。**贪心面试的最后一公里是证明——'策略 + 为什么成立'双段式，就是贪心题的完整答案**。
