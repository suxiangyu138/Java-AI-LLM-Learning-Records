## 1. 五大题型识别（10 秒定位）

### 1.1 题型 → 策略 → 代表题

| 题型 | 识别信号 | 贪心策略 | 代表题 |
|------|------|------|:---:|
| 区间 | "区间/重叠/气球" | 排序 + 最早结束/合并 | 435/56/452 |
| 跳跃 | "最多/最少 + 可达" | 最远可达边界 | 55/45/134 |
| 股票 | "买卖/差价/利润" | 只加正差值/最低价 | 121/122/714 |
| 分配 | "分配/满足/找零" | 排序 + 双指针/面额 | 455/135/860 |
| 构造 | "最大/最小数/序列" | 单调性/趋势 | 402/738/376 |

### 1.2 识别口诀

```text
"区间必排序，跳跃管边界，
 股票加正差，分配双指针，
 构造看单调"

⚠️ 关键判断（10 秒）:
  能排序？→ 区间/分配
  能维护边界？→ 跳跃/股票
  要构造序列？→ 单调构造
  都不能？→ 考虑 DP（05 文件）
```

> 🎯 **识别是第一步**："**贪心题 40% 的分数在题型识别与策略选择——识别对了模板 5 分钟、识别错了方向全错**。'排序/边界/正差/双指针/单调'五个关键词就是五大题型的指纹。"

## 3. 答题流程与话术模板（策略 + 证明双段式）

### 3.1 答题三步骤

```text
① 识别题型（10 秒）: 区间/跳跃/股票/分配/构造？
② 确定策略（30 秒）: 排序规则 + 贪心点
③ 写码 + 验证（5 分钟）: 模板 + 小样例 + 边界

⚠️ 面试官期待:
  "写码前说策略（30 秒），写码后说证明（30 秒）——
   只写码不解释 = 追问必失分（2025 面试共识）"
```

### 3.2 双段式话术模板

```text
策略段:
  "这是【题型】贪心——【识别信号】。
   策略: 【排序规则 + 贪心点】。
   复杂度: O(n)/O(n log n)，空间 O(1)/O(n)。"

证明段（三选一）:
  "为什么成立: 交换论证——【第一个不同点 + 交换不差】"
  "或反证——【贪心覆盖一切可能】"
  "或直觉——【最早结束留最大空间/高位优先】"

例: "区间贪心——无重叠区间。按右端点升序选最早结束的。
    O(n log n)/O(1)。
    为什么对: 把最优解第一个区间换成最早结束的，
    结束更早 → 后续空间更大 → 交换不差 → 贪心最优。"
```

## 4. 高频追问 TOP 10

| # | 追问 | 标准回答 |
|:---:|------|---------|
| 1 | 贪心为什么成立？ | 交换论证/反证/直觉三选一（见第 3 节） |
| 2 | 两大性质？ | 贪心选择性质（局部→全局不后悔）+ 最优子结构 |
| 3 | 贪心 vs DP？ | 无后效 → 贪心（历史压缩成边界）；有后效 → DP（状态数组） |
| 4 | 贪心什么时候失效？ | 找零 [1,3,4] 凑 6——贪心选择性质不满足 |
| 5 | 为什么区间要排序？ | 无排序无贪心——有序性让"最早结束"可判定 |
| 6 | 135 为什么两次遍历？ | 每次只贪一个方向，两次取 max 兼顾两侧 |
| 7 | 45 为什么不是每步跳最远？ | 贪心于"下一步覆盖"而非"本步距离"（双边界） |
| 8 | 714 为什么 minPrice = price−fee？ | 卖出视为"扣费后重新买入"，防重复扣手续费 |
| 9 | 贪心复杂度？ | 区间/分配 O(n log n)（排序）；跳跃/股票 O(n)；堆辅助 O(n log k) |
| 10 | 贪心写错了怎么办？ | 退回 DP 保底（55 跳跃 DP 可解）；主动说"先验证贪心" |

## 5. 面试实战演练：三道真题全程

### 5.1 真题一：无重叠区间（区间母题 + 交换论证）

```text
面试过程示范:
  ① 识别: "区间 + 最多不重叠 → 右端点升序"
  ② 策略: "选最早结束的——给后续留最大空间"
  ③ 手撕: 435 模板（lastEnd + 计数）
  ④ 证明: "交换论证——最优解第一个区间换成最早结束的，
     结束更早 → 后续空间更大 → 交换不差 → 贪心最优"
  ⑤ 追问: "452 变体？" → 箭放右端（同样右端升序）
```

### 5.2 真题二：跳跃游戏 II（边界维护 + 反证）

```text
面试过程示范:
  ① 识别: "最少步数 + 可达 → 双边界贪心"
  ② 策略: "curEnd 当前步覆盖、farthest 探一步的最远"
  ③ 手撕: 45 模板（i==curEnd 才加步）
  ④ 证明: "贪心每步的覆盖范围 ⊇ 任何方案——最远可达是上界，
     任何方案都不可能超过 → 贪心步数必然最少"
  ⑤ 追问: "为什么不是每步跳最远？" → 局部最远可能浪费
```

### 5.3 真题三：分发糖果（双向贪心 + 边界讨论）

```text
面试过程示范:
  ① 识别: "分配 + 两侧约束 → 双向贪心"
  ② 策略: "每次只贪一个方向——左→右处理右高、右→左处理左高"
  ③ 手撕: 135 模板（两次遍历 + 取 max）
  ④ 关键: "为什么取 max——位置受两侧约束，
     第二次不能破坏第一次的结果"
  ⑤ 追问: "单次遍历为什么不行？" → 顾此失彼（[1,2,2] 反例）
```

> 🎯 **核心要点**：面试实战通关 = **五大题型 10 秒识别 + 15 题三梯队 + 双段式话术（策略 + 证明）+ 追问 TOP 10 + 三场演练（区间/跳跃/分配）**。贪心占面试高频考点 40%+——**代码 10 行、证明 10 分钟：'策略 + 为什么成立'双段式，就是贪心面试的完整答案**。
