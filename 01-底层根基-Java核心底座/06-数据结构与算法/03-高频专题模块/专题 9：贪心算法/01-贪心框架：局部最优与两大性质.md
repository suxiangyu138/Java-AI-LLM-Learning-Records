## 1. 贪心模型：每步最优，不后悔

```text
贪心（Greedy）:
  每一步做"当前看起来最优"的选择
  不记录历史、不回看、不后悔——一路选到底

对比 DP:
  贪心: 无记录，状态只有"当前最优边界"
  DP: 有记录，dp[] 保存所有子问题状态

对比回溯:
  贪心: 每步一个选择（不分支）
  回溯: 每步多个选择（全分支 + 撤销）

⚠️ 本质:
  "贪心是'最短路'式的思维——每一步都朝'看起来最优'走；
   正确性需要证明'当前选择不会堵死后续的最优'。"
```

> 🎯 **核心认知**："**贪心的代码往往很短，难点全在'为什么当前选择不影响全局最优'**——面试只写代码不解释策略，追问必卡（2025 面试共识）。'策略 + 证明'才是贪心题的完整答案。"

## 2. 两大性质：贪心成立的判据

### 2.1 贪心选择性质

```text
定义: 全局最优解可以通过一系列局部最优选择得到——
  每个局部最优选择不依赖后续决策结果（"当下选最优，后续不后悔"）

通俗: 第一步选了局部最优后，剩下的问题还是"同类型的最优子问题"
  → 可以继续贪心

例: 区间调度选"最早结束的区间"——
  选它给后面留下的空间最大 → 不会堵死后续 → 可继续贪心
```

### 2.2 最优子结构性质

```text
定义: 全局最优解包含其子问题的最优解（与 DP 的共性）

例: 跳跃游戏——能跳到末尾 ⇔ 在可达范围内存在"能跳到末尾"的点
  → 全局可达性由子问题（子位置可达性）构成

⚠️ 两个性质必须同时满足:
  贪心选择性质: 决定"能不能贪"（局部最优 → 全局最优）
  最优子结构: 决定"子问题独立"（与 DP 共享）
  缺一 → 贪心失效（见第 4 节反例）
```

> 🎯 **面试必答**："**贪心成立需要两大性质：贪心选择性质（局部最优可推导全局最优，不后悔）与最优子结构（全局最优包含子问题最优）**。验证方式：交换论证或反证（05 文件）——讲不出验证，就说'这题无后效性，局部决策不影响后续'。"

## 3. 识别信号：能不能贪心

### 3.1 判据清单

```text
可以尝试贪心的信号:
  ① 问题可以"排序"（区间/分配类）
  ② 可以维护"当前最优边界"（跳跃/股票类）
  ③ 局部决策"无后效性"（不堵死后续）

不适合贪心的信号:
  ① 需要"回看多个历史状态"（背包、编辑距离 → DP）
  ② 局部最优明显冲突（找零 [1,3,4]）
  ③ 全局约束强耦合（TSP、最长公共子序列）

⚠️ 快速验证:
  先写暴力/DP 小样例，再验证贪心结果一致？
  不一致 → 贪心不适用（面试可主动提"我先验证贪心是否成立"）
```

### 3.2 题型 → 贪心点

```text
区间: 排序后"最早结束"（给后续留最大空间）
跳跃: "最远可达"（只关心覆盖边界）
股票: "只加正差值"（涨就赚）
分配: "最小满足最不贪婪"（排序 + 双指针）
构造: "单调性"（高位尽可能小/大）

⚠️ 一句话: "能排序或能维护边界 → 大概率贪心"
```

## 4. 反例警示：找零问题

### 4.1 经典反例

```text
硬币面值 [1, 3, 4]，凑 6:
  贪心: 先取最大的 4 → 剩 2 → 取 1+1 → 共 3 枚（4+1+1）
  最优: 3+3 → 共 2 枚！

为什么贪心失效:
  面值 4 是"局部最大"但不是"最优第一步"——
  贪心选择性质不成立（选 4 堵死了 3+3 的路径）

什么情况下贪心对:
  面值 [1, 5, 10, 25]（美分硬币）→ 贪心正确
  （"大面值 = 倍数关系"时贪心成立——数学性质）

⚠️ 结论: 找零必须用 DP（完全背包）——
  贪心只在特殊面值组合下成立，不能默认
```

> 💡 **反例的面试价值**："**'找零 [1,3,4] 凑 6'是贪心失效的教科书反例**——面试被问'贪心什么时候不成立'，举它 + 解释'贪心选择性质不满足'，比抽象论述有说服力。"

## 5. 贪心 vs DP：无后效性

### 5.1 对比表

| 维度 | 贪心 | 动态规划 |
|------|:---:|:---:|
| 决策方式 | 当前一步直接选 | 依赖前面多个状态 |
| 是否回看历史 | 通常不回看 | 需要状态转移 |
| 记录 | 只有当前最优边界 | dp[] 保存全部子问题 |
| 证明重点 | 当前选择不破坏全局最优 | 最优子结构 + 重叠子问题 |
| 代表题 | 区间/跳跃/分配 | 背包/子序列/路径 |

### 5.2 同一题双解（55 跳跃）

```java
// 55 跳跃游戏——贪心版（最优）与 DP 版（正确但慢）都能解：
//   贪心: 维护最远可达 → O(n)/O(1)
//   DP: dp[i] = 可达性 → O(n²)/O(n)
//   → "能用贪心就用贪心，DP 是保底方案"

⚠️ 面试表达:
  "这题无后效性——局部决策（最远可达）只产生对后续有用的信息，
   不产生负面约束 → 贪心成立。
   若贪心验证失败，退回 DP 保底。"
```

> 🎯 **无后效性**："**贪心可用的前提 = 无后效性：局部决策只保留/积累对后续有用的信息（如 121 只保留最低价），不产生负面约束**。有后效性（如背包）→ 必须 DP。"

## 6. 入门三题：122/455/121

### 6.1 122 买卖股票 II（只加正差值）

```java
/**
 * LeetCode 122. 买卖股票的最佳时机 II（无限次交易）
 * 贪心: 只累加所有正差值（涨就赚）
 * 时间 O(n)，空间 O(1)
 */
public int maxProfit(int[] prices) {
    int profit = 0;
    for (int i = 1; i < prices.length; i++) {
        if (prices[i] > prices[i - 1]) {     // ① 上涨段
            profit += prices[i] - prices[i - 1];   // ② 只加正差值
        }
    }
    return profit;
}
// 推演 [7,1,5,3,6,4]：+4（1→5）+3（3→6）= 7 ✓
// ⚠️ "每天买卖"的等价: 拆成相邻差，正差累加——
//   连续上涨 [1,2,3] 拆成 (2-1)+(3-2) = 2 ≡ 3-1 ✓
```

### 6.2 455 分发饼干（最小满足最不贪婪）

```java
/**
 * LeetCode 455. 分发饼干
 * 排序 + 双指针: 最小饼干满足最小胃口
 * 时间 O(n log n)，空间 O(1)
 */
public int findContentChildren(int[] g, int[] s) {
    Arrays.sort(g);                          // ① 胃口升序
    Arrays.sort(s);                          // ② 饼干升序
    int i = 0;
    for (int cookie : s) {                   // ③ 每个饼干找能喂的孩子
        if (i < g.length && cookie >= g[i]) {
            i++;                             // ④ 最小满足最不贪婪
        }
    }
    return i;
}
// 推演 g=[1,2,3], s=[1,1] → 1 ✓（1 喂给胃口 1 的孩子）
// ⚠️ 贪心点: 不用大饼干喂小胃口（浪费）——
//   最小的合适饼干满足最不贪婪的孩子
```

### 6.3 121 买卖股票 I（一次交易）

```java
/**
 * LeetCode 121. 买卖股票的最佳时机（一次交易）
 * 贪心: 维护历史最低价，每天算"当天卖出的利润"
 * 时间 O(n)，空间 O(1)
 */
public int maxProfit(int[] prices) {
    int minPrice = Integer.MAX_VALUE;        // ① 历史最低
    int best = 0;
    for (int price : prices) {
        minPrice = Math.min(minPrice, price);   // ② 更新最低
        best = Math.max(best, price - minPrice); // ③ 当天卖出的利润
    }
    return best;
}
// 推演 [7,1,5,3,6,4]：min: 7→1；利润: 0,0,4,2,5,3 → 5 ✓
// ⚠️ 无后效性体现: 只保留"最低价"一个信息——
//   后续决策不需要看更早的历史
```

> 🎯 **入门三题的体系价值**："**122（正差值）、455（排序双指针）、121（最低价维护）覆盖贪心的三种基础形态——'累加收益/匹配分配/边界维护'**。三题 5 分钟默写，贪心手写就过关了。"

## 7. 手写易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 贪心题忘排序 | 区间/分配先排序 | 贪心策略失效 |
| 2 | 排序字段选错 | 右端点升序（435）/左端点（56） | 答案错误 |
| 3 | 122 加负差值 | 只加正差值 | 利润虚增 |
| 4 | 455 大饼干喂小胃口 | 最小满足最不贪婪 | 浪费饼干 |
| 5 | 121 更新顺序反 | 先更新 min 再算利润 | 利润计算错 |
| 6 | 区间边界相等处理错 | `[1,2]` 与 `[2,3]` 是否重叠要明确 | 边界误判 |
| 7 | 不问"为什么贪心成立" | 讲策略 + 论证 | 追问失分 |

> 🎯 **核心要点**：贪心框架通关四件事——**① 两大性质**（贪心选择 + 最优子结构，缺一不可）；**② 识别信号**（能排序/能维护边界/无后效性）；**③ 反例警示**（找零 [1,3,4]）；**④ 入门三题**（122/455/121 三种基础形态）。**贪心是'每步最优 + 不后悔'——会写是 30 秒，会证明才是满分**。
