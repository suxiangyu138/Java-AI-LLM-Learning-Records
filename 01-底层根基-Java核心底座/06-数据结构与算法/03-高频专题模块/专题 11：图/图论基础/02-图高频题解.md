## 1. 133. 克隆图（DFS/BFS + 哈希防环）

### 1.1 题目与思路

```
深拷贝图（含环！）
哈希：旧节点 → 新节点（防重复创建 + 防环）
DFS 或 BFS 遍历复制
```

### 1.2 完整代码（DFS 版）

```java
/**
 * LeetCode 133. 克隆图（DFS + 哈希）
 */
class Solution {
    private final Map<Node, Node> cloneMap = new HashMap<>();

    public Node cloneGraph(Node node) {
        if (node == null) return null;
        if (cloneMap.containsKey(node)) return cloneMap.get(node);  // ⚠️ 防环

        Node clone = new Node(node.val);
        cloneMap.put(node, clone);           // ⚠️ 先存再递归（防环关键）
        for (Node neighbor : node.neighbors) {
            clone.neighbors.add(cloneGraph(neighbor));   // 递归复制邻居
        }
        return clone;
    }
}
// ⚠️ 防环要点：先 put 再递归（否则环会无限递归）
// ⚠️ 面试必答："133 = DFS + 哈希映射——
//   '先存后递归'打破环；哈希保证每个
//   节点只克隆一次。"
```

## 2. 841. 钥匙和房间（DFS 可达性）

### 2.1 题目与思路

```
0 号房间开始，钥匙可达的房间能否全部访问
DFS 可达性 + visited
```

### 2.2 完整代码

```java
/**
 * LeetCode 841. 钥匙和房间（DFS 可达性）
 */
public boolean canVisitAllRooms(List<List<Integer>> rooms) {
    int n = rooms.size();
    boolean[] visited = new boolean[n];

    dfs(0, rooms, visited);
    for (boolean v : visited)
        if (!v) return false;                // ⚠️ 有房间不可达
    return true;
}

private void dfs(int room, List<List<Integer>> rooms, boolean[] visited) {
    visited[room] = true;
    for (int key : rooms.get(room)) {
        if (!visited[key]) dfs(key, rooms, visited);
    }
}
// 推演 [[1],[2],[3],[]]：0→1→2→3 全部可达 ✓
// 推演 [[1,3],[3,0,1],[2],[0]]：房间 2 可达？0→1→2 ✓ 全可达
// ⚠️ 复杂度：O(V+E)
// ⚠️ 面试必答："841 = 图可达性——
//   DFS 从 0 出发，visited 检查全覆盖。"
```

## 3. 997. 小镇法官（入度-出度）

### 3.1 题目与思路

```
法官 = 被所有人信任（入度 n-1）且不信任何人（出度 0）
度统计：trust 每条边更新入度/出度
⚠️ 这是"度即角色"的图论应用
```

### 3.2 完整代码

```java
/**
 * LeetCode 997. 小镇法官（入度-出度）
 */
public int findJudge(int n, int[][] trust) {
    int[] indegree = new int[n + 1];         // 被信任次数
    int[] outdegree = new int[n + 1];        // 信任别人次数

    for (int[] t : trust) {
        outdegree[t[0]]++;                   // ⚠️ 信任别人
        indegree[t[1]]++;                    // 被信任
    }
    for (int i = 1; i <= n; i++) {
        if (indegree[i] == n - 1 && outdegree[i] == 0)
            return i;                        // ⚠️ 法官特征
    }
    return -1;
}
// 推演 n=3, [[1,3],[2,3]]：
//   3 被信任 2 次（n-1）且不信任任何人 → 3 ✓
// ⚠️ 复杂度：O(n + trust)
// ⚠️ 面试必答："997 = 度统计——
//   法官 = 入度 n-1 + 出度 0；
//   题目保证最多一个法官。"
```

## 4. 1791. 找出星型图的中心节点

### 4.1 题目与思路

```
星型图（中心连所有节点）→ 找中心
妙解：前两条边找共同端点
⚠️ O(1) 解法（不需要建全图）
```

### 4.2 完整代码

```java
/**
 * LeetCode 1791. 星型图的中心节点
 * ⚠️ 中心节点出现在所有边中 → 前两条边的共同端点
 */
public int findCenter(int[][] edges) {
    // 前两条边共享的节点 = 中心
    if (edges[0][0] == edges[1][0] || edges[0][0] == edges[1][1])
        return edges[0][0];
    return edges[0][1];
}
// 推演 [[1,2],[2,3],[4,2]]：
//   边 0 (1,2)、边 1 (2,3)：共同点 2 → 中心 ✓
// ⚠️ 复杂度：O(1)
// ⚠️ 面试必答："1791 = 观察题——
//   中心在所有边中，前两条边的
//   公共端点即答案，O(1) 无需建图。"
```

## 5. 785. 判断二分图

### 5.1 题目与思路

```
染色法（01 模块 4 节完整推导）
BFS 染色 + 冲突检测 + 不连通处理
```

### 5.2 完整代码

```java
/**
 * LeetCode 785. 判断二分图（BFS 染色）
 */
public boolean isBipartite(int[][] graph) {
    int n = graph.length;
    int[] color = new int[n];                // 0 未染 / 1 / -1

    for (int i = 0; i < n; i++) {            // ⚠️ 不连通 → 逐起点
        if (color[i] != 0) continue;
        color[i] = 1;
        Deque<Integer> queue = new ArrayDeque<>();
        queue.offer(i);

        while (!queue.isEmpty()) {
            int u = queue.poll();
            for (int v : graph[u]) {
                if (color[v] == 0) {
                    color[v] = -color[u];    // 染相反色
                    queue.offer(v);
                } else if (color[v] == color[u]) {
                    return false;            // ⚠️ 相邻同色 → 非二分
                }
            }
        }
    }
    return true;
}
// 推演 [[1,3],[0,2],[1,3],[0,2]]：
//   四环染色成功 → true ✓
// 推演 [[1,2,3],[0,2],[0,1,3],[0,2]]：
//   0(1)→1(-1),2(-1),3(-1)；1 的邻居 2 已染 -1 == -1？冲突 ✗ ✓
// ⚠️ 面试必答："785 = 染色法——
//   未染染反色、已染查冲突；
//   不连通图每个分量独立染色。"
```

## 6. 207/210. 课程表 I & II（拓扑）

### 6.1 题目与思路

```
207 判环（boolean）/ 210 输出拓扑序
Kahn 算法（完整推导见拓扑/02）
```

### 6.2 双题完整代码

```java
/** 207. 课程表（Kahn 判环） */
public boolean canFinish(int numCourses, int[][] prerequisites) {
    List<Integer>[] graph = new List[numCourses];
    for (int i = 0; i < numCourses; i++) graph[i] = new ArrayList<>();
    int[] indegree = new int[numCourses];

    for (int[] p : prerequisites) {
        graph[p[0]].add(p[1]);
        indegree[p[1]]++;
    }

    Deque<Integer> queue = new ArrayDeque<>();
    for (int i = 0; i < numCourses; i++)
        if (indegree[i] == 0) queue.offer(i);

    int processed = 0;
    while (!queue.isEmpty()) {
        int u = queue.poll();
        processed++;
        for (int v : graph[u])
            if (--indegree[v] == 0) queue.offer(v);
    }
    return processed == numCourses;          // ⚠️ 处理数 = 总数 → 无环
}

/** 210. 课程表 II（输出拓扑序，有环返回空） */
public int[] findOrder(int numCourses, int[][] prerequisites) {
    // 建图入度同上
    int[] result = new int[numCourses];
    int idx = 0;
    Deque<Integer> queue = new ArrayDeque<>();
    for (int i = 0; i < numCourses; i++)
        if (indegree[i] == 0) queue.offer(i);
    while (!queue.isEmpty()) {
        int u = queue.poll();
        result[idx++] = u;                   // ⚠️ 出队顺序 = 拓扑序
        for (int v : graph[u])
            if (--indegree[v] == 0) queue.offer(v);
    }
    return idx == numCourses ? result : new int[0];   // 有环返回空
}
// ⚠️ 面试必答："207/210 = Kahn 双题——
//   判环看处理数、输出看出队序；
//   一个模板两种返回。"
```

## 7. 图方法论总结

### 7.1 解题框架

```
① 建模：节点/边/权/目标（四要素）
② 选存储：邻接表默认
③ 定算法：
   可达性 → DFS
   最短步数 → BFS
   依赖/环 → 拓扑
   二分性 → 染色
   角色/度 → 度统计
④ 防环 + 防不连通
⑤ 复杂度：O(V+E)

⚠️ 识别信号：
  "克隆/可达/连通" → 遍历
  "依赖/顺序" → 拓扑
  "二分/染色" → 染色法
  "信任/法官" → 度统计
```

### 7.2 模板速查表

| 题型 | 算法 | 代表题 |
|------|------|--------|
| 深拷贝 | DFS/BFS + 哈希 | 133 |
| 可达性 | DFS visited | 841 |
| 度角色 | 出入度统计 | 997 |
| 观察题 | 共同端点 | 1791 |
| 二分图 | 染色法 | 785 |
| 依赖 | Kahn 拓扑 | 207、210 |

### 7.3 自测清单

```
□ 建模四要素先答？

□ 染色冲突检测？
```
