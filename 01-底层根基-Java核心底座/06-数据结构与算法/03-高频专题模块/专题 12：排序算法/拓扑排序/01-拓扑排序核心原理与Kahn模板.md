## 1. 拓扑排序模型：依赖关系的线性化

```text
拓扑排序: 有向无环图（DAG）的线性排列——
  每条边 u→v，u 都排在 v 前面

课程依赖例:
  A → B（先修 A 再修 B）
  A → C，B → D，C → D
  拓扑序: A, B, C, D（或 A, C, B, D）

关键性质:
  ① 仅 DAG 有拓扑序（有环 → 无解）
  ② 拓扑序不唯一（入度 0 节点可任意顺序）
  ③ 有向图有拓扑序 ⇔ 无环（判环的依据）

⚠️ 常见误区: 拓扑排序不是排序算法——
  不比较大小，是"依赖关系"的线性化
```

> 🎯 **核心认知**："**拓扑排序 = '把依赖关系排成先后顺序'——先修课必须在后续课前面**。'仅 DAG 有解'与'序不唯一'是两个必答性质：有环无解、无环多解。"

## 2. Kahn 三步模板（2 分钟默写）

### 2.1 完整实现（面试标准答案）

```java
/**
 * Kahn 拓扑排序模板（BFS 版）——面试标准答案
 * 三步: 建图入度 → 入度 0 入队 → 减入度判环
 * 时间 O(V+E)，空间 O(V+E)
 */
public int[] kahn(int n, int[][] edges) {
    // ① 建图 + 统计入度
    List<List<Integer>> graph = new ArrayList<>();
    int[] indegree = new int[n];
    for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
    for (int[] e : edges) {
        graph.get(e[0]).add(e[1]);         // e[0] → e[1]
        indegree[e[1]]++;                  // ⚠️ 入度 +1（被指向方）
    }

    // ② 入度为 0 的节点入队（无前置依赖）
    Queue<Integer> queue = new LinkedList<>();
    for (int i = 0; i < n; i++) {
        if (indegree[i] == 0) queue.offer(i);
    }

    // ③ BFS 消解: 出队 → 后继入度减 1 → 减到 0 再入队
    int[] order = new int[n];
    int index = 0;
    while (!queue.isEmpty()) {
        int cur = queue.poll();
        order[index++] = cur;              // 加入拓扑序

        for (int next : graph.get(cur)) {
            if (--indegree[next] == 0) {   // ⚠️ 前置完成一个
                queue.offer(next);         // 可以处理了
            }
        }
    }

    return index == n ? order : new int[0];   // 判环: 处理数 < n → 有环
}
```

### 2.2 三步口诀

```text
"建图入度 → 零度入队 → 减度判环"
  ① 建图: 邻接表 + 入度数组（同步统计！）
  ② 入队: 入度 0 = 无前置 = 可立即处理
  ③ 消解: 出队加入拓扑序，后继入度 −1，归零再入队
  判环: 处理数 == n → 无环；< n → 有环

⚠️ 为什么"减到 0 才入队":
  入度 = 还没完成的前置数
  前置全完成（减到 0）→ 才轮到它
```

> 🎯 **Kahn 的灵魂**："**'入度 = 未完成前置数'——每完成一个前置就减 1，减到 0 才放行**。这个'消解依赖'的过程就是拓扑序的生成，'减到 0'是它唯一的入队条件。"

## 3. 逐步推演：n=4 全流程

**edges = [[0,1],[0,2],[1,3],[2,3]]**（0→1、0→2、1→3、2→3）

| 步骤 | 操作 | 队列 | 拓扑序 |
|:---:|------|:---:|------|
| 初始化 | 入度: 0:0, 1:1, 2:1, 3:2 | [0] | [] |
| 1 | 弹 0；后继 1、2 入度减 1 → 都变 0 | [1,2] | [0] |
| 2 | 弹 1；后继 3 入度 2→1（未到 0） | [2] | [0,1] |
| 3 | 弹 2；后继 3 入度 1→0 → 入队 | [3] | [0,1,2] |
| 4 | 弹 3 | [] | [0,1,2,3] |

**结果**：拓扑序 [0,1,2,3] ✓，处理数 4 == n → 无环。

```text
观察:
  ① 0 无前置 → 最先；3 前置最多 → 最后
  ② [0,1,2,3] 与 [0,2,1,3] 都合法——序不唯一
  ③ 每条边 u→v，u 都在 v 前面 ✓
```

## 4. 判环原理：为什么入度永远 ≥ 1

```text
Kahn 判环的原理:
  环上每个节点都有"环内前驱"
  → 环上节点的入度永远 ≥ 1（环内依赖消解不完）
  → 永远无法减到 0 → 永远无法入队
  → 处理数 < n → 有环！

例: 环 A→B→C→A:
  入度: A:1, B:1, C:1（互指）
  谁都无法"前置清零" → 全部卡死 → 处理 0 个

⚠️ 面试必答:
  "Kahn 判环 = 处理数 == 节点数才无环——
   环上节点入度永远 ≥ 1，无法入队，
   所以处理数不足就是有环的标志。"
```

> 🎯 **判环的直觉**："**环 = '互相等待'——A 等 B、B 等 C、C 等 A，谁的前置都清不完**。Kahn 把'互相等待'翻译成'入度永远 ≥ 1'，一次遍历就暴露环。"

## 5. 207/210 课程表（判环与输出）

### 5.1 207 课程表（boolean 判环）

```java
/**
 * LeetCode 207. 课程表
 * ⚠️ 边方向: prerequisites[i] = [ai, bi] 表示先修 bi → 建边 bi→ai
 */
public boolean canFinish(int numCourses, int[][] prerequisites) {
    List<List<Integer>> graph = new ArrayList<>();
    int[] indegree = new int[numCourses];
    for (int i = 0; i < numCourses; i++) graph.add(new ArrayList<>());
    for (int[] pre : prerequisites) {
        graph.get(pre[1]).add(pre[0]);     // ⚠️ bi → ai（先修 → 后续）
        indegree[pre[0]]++;
    }

    Queue<Integer> queue = new LinkedList<>();
    for (int i = 0; i < numCourses; i++)
        if (indegree[i] == 0) queue.offer(i);

    int processed = 0;
    while (!queue.isEmpty()) {
        int cur = queue.poll();
        processed++;                        // ① 计数（判环依据）
        for (int next : graph.get(cur)) {
            if (--indegree[next] == 0) queue.offer(next);
        }
    }
    return processed == numCourses;         // ② 处理数 == n → 无环
}
// 推演 2 门 [[1,0]]：0 入度 0 → 处理 1 → 0→1 → 处理 2 == 2 → true ✓
//   [[1,0],[0,1]]：0↔1 环 → 都入度 1 → 处理 0 < 2 → false ✓
```

### 5.2 210 课程表 II（输出拓扑序）

```java
/**
 * LeetCode 210. 课程表 II
 * 与 207 的差异: 记录 order（Kahn 出队顺序即拓扑序）
 */
public int[] findOrder(int numCourses, int[][] prerequisites) {
    // 建图 + 入度（同 207，方向 bi→ai）
    ...
    int[] order = new int[numCourses];
    int index = 0;
    while (!queue.isEmpty()) {
        int cur = queue.poll();
        order[index++] = cur;               // ① 出队顺序 = 拓扑序
        for (int next : graph.get(cur)) {
            if (--indegree[next] == 0) queue.offer(next);
        }

// ⚠️ 207 vs 210: 一个只判环（boolean）、一个输出序（数组）——
//   模板完全一致，差异只在"要不要记录 order"
```

> 🎯 **207/210 的面试价值**："**207 = Kahn 判环、210 = Kahn 输出序——同一模板的两个形态**。面试先写 207 讲判环，追问 210 加 3 行记录 order，就是'模板复用'的完整展示。"

## 7. 手写易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 边方向反了 | 先修 → 后续（bi→ai） | 拓扑序颠倒 |
| 2 | 忘统计入度 | 建图时同步 indegree++ | 全部/都不入队 |
| 3 | 判环忘计数比较 | `index == n` 才无环 | 有环误报成功 |
| 4 | 队列用栈 | 用队列（BFS） | 顺序错误 |
| 5 | 减入度用 if | `--indegree[next] == 0` 才入队 | 前置未清完放行 |
| 6 | 210 忘返回空 | 有环返回 new int[0] | 返回残缺序 |
| 7 | 图未初始化 | 每个节点 new ArrayList | 空指针 |

> 🎯 **核心要点**：Kahn 通关四件事——**① 三步模板 2 分钟默写**（建图入度 → 零度入队 → 减度判环）；**② 判环原理讲清**（环上入度永远 ≥ 1）；**③ 边方向正确**（先修 → 后续）；**④ 207/210 双形态**（判环 vs 输出序）。**Kahn 是拓扑排序的面试标准答案——'入度消解'四个字，就是依赖问题的全部解法**。
