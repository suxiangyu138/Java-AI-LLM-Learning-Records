## 1. 知识体系导图

```text
拓扑排序（Topological Sort）
│
├── 核心本质 ──────────────────────────────────────────────
│   ├── = 有向无环图（DAG）的线性排列
│   ├── 每条边 u→v，u 都排在 v 前面
│   ├── 仅 DAG 有拓扑序（有环 → 无解）
│   └── ⚠️ 不是排序算法——是"依赖关系的线性化"
│
├── 双模板 ────────────────────────────────────────────────
│   ├── Kahn（BFS）: 入度 0 入队 → 减入度 → 判环
│   ├── DFS 三色: 0/1/2 标记 → 遇"访问中"= 环
│   ├── 复杂度: 均 O(V+E)（理论最优下界）
│   └── 选型: 默认 Kahn（可输出拓扑序、免栈溢出）
│
├── 判环原理 ──────────────────────────────────────────────
│   ├── Kahn: 环上节点入度永远 ≥ 1 → 处理数 < n
│   ├── 颜色法: 递归栈上遇到自己 = 环
│   ├── 简单 visited 为什么不行: 无法区分"访问中/已完成"
│   └── 有向图有拓扑序 ⇔ 无环
│
├── 应用变形 ──────────────────────────────────────────────
│   ├── 输出拓扑序: 210（Kahn 出队顺序）
│   ├── 字典序最小: 队列换 PriorityQueue（269 火星词典）
│   ├── 分层拓扑: 每轮 size 快照（1136 并行课程）
│   ├── 剥叶子: 入度 1 层层删（310 最小高度树）
│   └── 拓扑 + DP: 最长路径/并行课程 III（2050）
│
├── 工程应用 ──────────────────────────────────────────────
│   ├── 依赖管理: Maven/Gradle/npm 循环依赖检测
│   ├── 任务调度: 课程排课、CI/CD 流水线、工作流引擎
│   ├── 编译系统: Makefile 编译顺序
│   └── 系统: systemd 服务启动顺序、数据库外键循环检测
│
└── 实战与面试 ────────────────────────────────────────────
    ├── 手写: Kahn 模板（2 分钟）+ 颜色法（追问版）
    ├── 考题: 207/210/1136/269/310/1462/2050
    ├── 易错: 边方向反、忘判环计数、颜色法忘置 2
    └── 话术: "建模 → 双模板 → 复杂度 → 扩展"四段式
```

## 4. 核心概念速查

| 概念 | 一句话解释 | 说明 |
|------|-----------|------|
| **拓扑排序** | DAG 的线性排列（u→v 则 u 在前） | 依赖关系的线性化 |
| **DAG** | 有向无环图 | 拓扑排序的唯一适用对象 |
| **入度** | 指向该节点的边数 | = 未完成的前置数 |
| **Kahn 算法** | 入度 0 入队 → 减入度 | BFS 版，最易手写 |
| **三色标记** | 0 未访问/1 访问中/2 已完成 | DFS 判环（遇 1 = 环） |
| **判环** | 拓扑序长度 < n ⇔ 有环 | Kahn 与颜色法共用结论 |
| **字典序拓扑** | 队列换优先队列 | 269 火星词典 |
| **分层拓扑** | 每轮 size 快照计层 | 1136 并行课程 |
| **剥叶子** | 入度 1 层层删除 | 310 最小高度树 |
| **传递闭包** | 可达性关系传递 | 1462 课程表 IV |

## 5. 模板模式速查

### 5.1 Kahn vs DFS 双模板

| 维度 | Kahn（BFS） | 颜色法（DFS） |
|------|:---:|:---:|
| 思路 | 入度 0 队列消解 | 递归栈三态判环 |
| 手写难度 | 固定模板（推荐） | 颜色数组（追问版） |
| 栈溢出 | 无（非递归） | 大图（10⁴+）可能 |
| 副产品 | **拓扑序** | 只能判环 |
| 复杂度 | O(V+E) | O(V+E) |

### 5.2 识别信号

```text
"先修/依赖/顺序/能否完成" → 拓扑排序（Kahn 优先）
"最小字典序" → 优先队列版
"最少学期/轮数" → 分层版
"最小高度树/剥叶子" → 入度 1 版
"依赖 + 权值/时长" → 拓扑 + DP（2050）
```

> 🎯 **一句话定位**："**拓扑排序 = '依赖关系的线性化'——Kahn 管'顺序'、三色管'判环'，O(V+E) 双实现**。课程表系列七题 + Maven 循环依赖检测，是面试与工程的双重考点。"

## 6. 常见误区速查

| 误区 | 正解 |
|------|------|
| "拓扑排序是排序算法" | ❌ 不比较大小——是依赖关系的线性化 |
| "有环也能拓扑" | ❌ 仅 DAG 有拓扑序——有环无解 |
| "边方向随便建" | ❌ `[ai,bi]` 表示先修 bi → 建边 bi→ai（反了结果全错） |
| "visited 能判环" | ❌ 必须三色——visited 无法区分"访问中/已完成" |
| "Kahn 判环忘计数" | ❌ 处理数 == 节点数才无环——不比较会误报成功 |
| "拓扑序唯一" | ❌ 不唯一；唯一 ⇔ 任意时刻入度 0 节点最多 1 个 |
| "拓扑要求连通" | ❌ 不连通也行（多个入度 0 分量各自入队） |
| "颜色法忘置 2" | ❌ 递归返回后必须置 2（已完成）——否则误判环 |
| "分层拓扑忘 size 快照" | ❌ 每轮固定 size——否则层数混 |
| "大图用 DFS" | ❌ 10⁴+ 节点递归爆栈——用 Kahn 或迭代 DFS |
