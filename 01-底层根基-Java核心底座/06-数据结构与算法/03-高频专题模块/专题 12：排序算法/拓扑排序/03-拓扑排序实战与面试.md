## 1. 207. 课程表（判环）

### 1.1 题目与思路

```
能否修完所有课程（依赖无环）
Kahn 判环：输出数 < 课程数 → 有环
```

### 1.2 完整代码

```java
/**
 * LeetCode 207. 课程表（Kahn 判环）
 */
public boolean canFinish(int numCourses, int[][] prerequisites) {
    List<Integer>[] graph = new List[numCourses];
    for (int i = 0; i < numCourses; i++) graph[i] = new ArrayList<>();
    int[] indegree = new int[numCourses];

    for (int[] p : prerequisites) {
        graph[p[0]].add(p[1]);               // ⚠️ p[0] → p[1]（先修 → 后修）
        indegree[p[1]]++;
    }

    Deque<Integer> queue = new ArrayDeque<>();
    for (int i = 0; i < numCourses; i++)
        if (indegree[i] == 0) queue.offer(i);

    int processed = 0;
    while (!queue.isEmpty()) {
        int u = queue.poll();
        processed++;
        for (int v : graph[u])
            if (--indegree[v] == 0) queue.offer(v);
    }
    return processed == numCourses;          // ⚠️ 全处理 = 无环
}
// 推演 [[1,0],[0,1]]（互相依赖）：
//   入度全 1 → 队列空 → processed=0 < 2 → false ✓
// ⚠️ 复杂度：O(V+E)
// ⚠️ 面试必答："207 = Kahn 判环——
//   处理数不足即环（环内入度永不归零）。"
```

## 2. 210. 课程表 II（输出拓扑序）

### 2.1 题目与思路

```
输出一种合法修课顺序（无解返回空）
Kahn 出队顺序即拓扑序
```

### 2.2 完整代码

```java
/**
 * LeetCode 210. 课程表 II
 */
public int[] findOrder(int numCourses, int[][] prerequisites) {
    // 建图 + 入度（与 207 相同）
    int[] result = new int[numCourses];
    int idx = 0;

    Deque<Integer> queue = new ArrayDeque<>();
    for (int i = 0; i < numCourses; i++)
        if (indegree[i] == 0) queue.offer(i);

    while (!queue.isEmpty()) {
        int u = queue.poll();
        result[idx++] = u;                   // ⚠️ 出队顺序 = 拓扑序
        for (int v : graph[u])
            if (--indegree[v] == 0) queue.offer(v);
    }
    return idx == numCourses ? result : new int[0];   // ⚠️ 有环返回空
}
// ⚠️ 与 207 的关系：207 判环（boolean），
//   210 输出序（数组）——一个模板两种返回
// ⚠️ 面试必答："210 = 207 + 记录出队顺序；
//   有环返回空数组（题目约定）。"
```

## 3. 1136. 并行课程（分层拓扑）

### 3.1 题目与思路

```
最少学期数（每学期可并行修所有无依赖课程）
分层 Kahn：每轮处理一整层（一个学期）
⚠️ 有环返回 -1
```

### 3.2 完整代码

```java
/**
 * LeetCode 1136. 并行课程（分层 Kahn）
 */
public int minimumSemesters(int n, int[][] relations) {
    List<Integer>[] graph = new List[n + 1];     // ⚠️ 1-indexed
    for (int i = 1; i <= n; i++) graph[i] = new ArrayList<>();
    int[] indegree = new int[n + 1];

    for (int[] r : relations) {
        graph[r[0]].add(r[1]);
        indegree[r[1]]++;
    }

    Deque<Integer> queue = new ArrayDeque<>();
    for (int i = 1; i <= n; i++)
        if (indegree[i] == 0) queue.offer(i);

    int semesters = 0, processed = 0;
    while (!queue.isEmpty()) {
        int size = queue.size();             // ⚠️ 当前层（一学期）
        for (int i = 0; i < size; i++) {
            int u = queue.poll();
            processed++;
            for (int v : graph[u])
                if (--indegree[v] == 0) queue.offer(v);
        }
        semesters++;                         // 每层一学期
    }
    return processed == n ? semesters : -1;  // ⚠️ 判环
}
// 推演 n=3, [[1,3],[2,3]]：
//   层 1：1,2（无依赖）；层 2：3 → 2 学期 ✓
// ⚠️ 面试必答："1136 = 分层 Kahn——
//   queue.size() 快照整层；层数 = 最少学期。"
```

## 4. 269. 火星词典（字符建边 + 字典序）

### 4.1 题目与思路

```
外星字典序（给定单词列表，推字符顺序）
建边：相邻单词逐字符比较，第一个不同处 → 边
拓扑排序输出（字典序用优先队列）
⚠️ 三个细节：前缀非法、孤立字符、字典序
```

### 4.2 完整代码

```java
/**
 * LeetCode 269. 火星词典
 */
public String alienOrder(String[] words) {
    // ① 字符集合
    Set<Character> chars = new HashSet<>();
    for (String w : words)
        for (char c : w.toCharArray()) chars.add(c);

    // ② 相邻单词建边
    Map<Character, Set<Character>> graph = new HashMap<>();
    Map<Character, Integer> indegree = new HashMap<>();
    for (char c : chars) {
        graph.put(c, new HashSet<>());
        indegree.put(c, 0);
    }
    for (int i = 0; i < words.length - 1; i++) {
        String a = words[i], b = words[i + 1];
        int len = Math.min(a.length(), b.length());
        boolean found = false;
        for (int j = 0; j < len; j++) {
            if (a.charAt(j) != b.charAt(j)) {
                char u = a.charAt(j), v = b.charAt(j);
                if (graph.get(u).add(v)) indegree.merge(v, 1, Integer::sum);
                found = true;
                break;
            }
        }
        // ⚠️ 前缀陷阱："ab" 在 "abc" 前 → 非法
        if (!found && a.length() > b.length()) return "";
    }

    // ③ 拓扑（优先队列 → 字典序）
    PriorityQueue<Character> queue = new PriorityQueue<>();
    for (var e : indegree.entrySet())
        if (e.getValue() == 0) queue.offer(e.getKey());

    StringBuilder sb = new StringBuilder();
    while (!queue.isEmpty()) {
        char u = queue.poll();
        sb.append(u);
        for (char v : graph.get(u))
            if (indegree.merge(v, -1, Integer::sum) == 0) queue.offer(v);
    }
    return sb.length() == chars.size() ? sb.toString() : "";
}
// 推演 ["wrt","wrf","er","ett","rftt"] → "wertf" ✓
// ⚠️ 面试必答："269 = 相邻单词提边 + 拓扑——
//   前缀特判（'ab' 在 'abc' 前非法）、
//   字典序输出（优先队列）是两个细节。"
```

## 5. 310. 最小高度树（反向剥层）

### 5.1 题目与思路

```
无向树中使高度最小的根（可能有多个）
反向拓扑：从叶子（度=1）逐层剥 → 最后剩下的节点
⚠️ 无向图版"拓扑"：度=1 入队（叶子）
⚠️ 剩 1 或 2 个节点时停止（答案）
```

### 5.2 完整代码

```java
/**
 * LeetCode 310. 最小高度树（反向剥层）
 */
public List<Integer> findMinHeightTrees(int n, int[][] edges) {
    if (n == 1) return List.of(0);           // ⚠️ 单节点特判

    List<Integer>[] graph = new List[n];
    for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
    int[] degree = new int[n];
    for (int[] e : edges) {
        graph[e[0]].add(e[1]);
        graph[e[1]].add(e[0]);
        degree[e[0]]++;
        degree[e[1]]++;
    }

    Deque<Integer> queue = new ArrayDeque<>();
    for (int i = 0; i < n; i++)
        if (degree[i] == 1) queue.offer(i);  // ⚠️ 叶子入队（度=1）

    int remaining = n;
    while (remaining > 2) {                  // ⚠️ 剩 ≤ 2 停止
        int size = queue.size();
        remaining -= size;
        for (int i = 0; i < size; i++) {     // 整层剥
            int leaf = queue.poll();
            for (int v : graph[leaf])
                if (--degree[v] == 1) queue.offer(v);
        }
    }
    return new ArrayList<>(queue);           // 剩下的 1-2 个 = 答案
}
// 推演 n=4, [[1,0],[1,2],[1,3]]（星型）：
//   叶子 0,2,3 入队 → 剥一层 → 剩 1 → 答案 [1] ✓
// ⚠️ 面试必答："310 = 反向拓扑——
//   叶子（度 1）逐层剥，剩 1-2 个即
//   树的重心（最小高度根）。"
```

## 6. 1462. 课程表 IV（传递闭包）

### 6.1 题目与思路

```
多次查询"u 是否是 v 的前置"（间接依赖也算）
传递闭包：拓扑序 + bitset 合并
  reachable[u] |= reachable[v]（u 的所有后继）
⚠️ 对比 Floyd（O(n³)）；拓扑 + bitset 更快
```

### 6.2 完整代码

```java
/**
 * LeetCode 1462. 课程表 IV（拓扑 + 传递闭包）
 */
public List<Boolean> checkIfPrerequisite(int n, int[][] prerequisites, int[][] queries) {
    List<Integer>[] graph = new List[n];
    for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
    int[] indegree = new int[n];
    for (int[] p : prerequisites) {
        graph[p[0]].add(p[1]);
        indegree[p[1]]++;
    }

    // 拓扑序
    Deque<Integer> queue = new ArrayDeque<>();
    for (int i = 0; i < n; i++)
        if (indegree[i] == 0) queue.offer(i);
    List<Integer> topo = new ArrayList<>();
    while (!queue.isEmpty()) {
        int u = queue.poll();
        topo.add(u);
        for (int v : graph[u])
            if (--indegree[v] == 0) queue.offer(v);
    }

    // ⚠️ 传递闭包：按拓扑序合并（前置先算）
    BitSet[] reach = new BitSet[n];
    for (int i = 0; i < n; i++) reach[i] = new BitSet(n);
    for (int u : topo) {
        for (int v : graph[u]) {
            reach[u].set(v);                 // 直接依赖
            reach[u].or(reach[v]);           // ⚠️ 间接依赖（位运算合并）
        }
    }

    List<Boolean> result = new ArrayList<>();
    for (int[] q : queries)
        result.add(reach[q[0]].get(q[1]));
    return result;
}
// ⚠️ 复杂度：O(n×E/64)（BitSet 位并行）
// ⚠️ 面试必答："1462 = 拓扑序 + BitSet 闭包——
//   按拓扑序把后继的可达集合合并进来；
//   位运算让合并 O(n/64)。"
```

## 7. 拓扑方法论总结

### 7.1 解题框架

```
① 识别：依赖/顺序 → 拓扑
② 判环：Kahn 输出数 / 三色
③ 选形态：
   输出序 → Kahn 出队序
   分层 → 整层处理
   字典序 → 优先队列
   反向 → 叶子剥层
   DP → 前置先算
   闭包 → BitSet 合并
④ 复杂度：O(V+E)

⚠️ 识别信号：
  "课程/依赖/前置" → 拓扑
  "并行/学期" → 分层
  "字典/顺序推理" → 字符建边
```

## 8. 面试话术与手撕清单

### 8.1 话术四段式（背下来）

```text
建模段: "这是依赖问题——课程是节点、先修关系是有向边。
        能学完 ⇔ 图无环 ⇔ 有拓扑序。"

方法段: "我用 Kahn 算法（BFS 版）:
         ① 统计入度；② 入度 0 入队；③ 出队减后继入度，
         减到 0 再入队。处理数 == 节点数 → 无环。"

复杂度段: "O(V+E) 时间与空间——每个节点和边各访问一次，
         理论最优下界。"

扩展段: "追问 DFS 版 → 三色法（0/1/2，遇'访问中'= 环）；
         字典序 → 队列换优先队列；分层 → size 快照。"

例: "207 课程表——Kahn 判环。O(V+E)。
    边方向注意: [ai,bi] 表示先修 bi，建边 bi→ai。
    DFS 版也能写: 三色标记，遇到访问中就是环。"
```

## 9. 高频追问与标准回答

| # | 追问 | 标准回答 |
|:---:|------|---------|
| 1 | Kahn 为什么能判环？ | 环上节点入度永远 ≥ 1 → 无法入队 → 处理数 < n |
| 2 | DFS 为什么必须三色？ | visited 无法区分"访问中/已完成"——遇访问中才是环 |
| 3 | 边方向怎么定？ | `[ai,bi]` 先修 bi → 建边 bi→ai（反了结果全错） |
| 4 | 字典序拓扑？ | 队列换 PriorityQueue（每次取最小） |
| 5 | 分层拓扑？ | 每轮 size 快照（BFS 分层技巧） |
| 6 | 拓扑序唯一吗？ | 不唯一；唯一 ⇔ 任意时刻入度 0 节点最多 1 个 |
| 7 | 不连通图可以吗？ | 可以——多个入度 0 分量各自入队 |
| 8 | 大图用哪个？ | Kahn（非递归免栈溢出）；10⁴+ 节点别用递归 DFS |
| 9 | 拓扑 + 权重？ | 顺序用拓扑、权重用 DP（2050 并行课程 III） |
| 10 | 工程应用？ | Maven/Gradle 循环依赖检测、Makefile 编译顺序、systemd 启动顺序 |

> 🎯 **核心要点**：拓扑题 = **Kahn/DFS 模板** + **七形态选型**（判环/分层/字典序/反向/DP/闭包）。六题覆盖全部形态——"有依赖求顺序"识别后套模板，判环是第一检查，形态扩展是加分项；面试完整答案 = **建模 → 双模板 → 复杂度 → 扩展**四段式。
