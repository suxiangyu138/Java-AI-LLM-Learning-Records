## 1. 家族总览：手撕三大件

| 算法 | 一句话记忆 | 2 分钟版本要点 |
|------|------|------|
| 快排 | 选基准 → 划分 → 递归 | partition 双指针 + pivot 归位 |
| 归并 | 拆排合 + 合并 | 二分递归 + 三 while merge |
| 堆排 | 建堆 → 取顶 | siftDown 下沉 + 头尾交换 |

```text
⚠️ 手撕定位（面试第一梯队）:
  快排 = 平均最快（JDK 基本类型底层）
  归并 = 稳定无退化（对象排序/TimSort 底层）
  堆排 = 最坏有界 + O(1) 空间（introsort 兜底）
```

> 🎯 **核心认知**："**三大件 = 手撕第一梯队——快排 Lomuto 2 分钟、归并三 while 2 分钟、堆排 siftDown 5 分钟**。面试手撕顺序：快排 → 归并 → 堆排，写完用 [1,3,2,5,4] 快速验证。"

## 2. 快速排序（Lomuto 版）

### 2.1 2 分钟模板

```java
/** 快速排序——Lomuto 划分，平均 O(n log n)/最坏 O(n²)，不稳定 */
void quickSort(int[] a, int lo, int hi) {
    if (lo >= hi) return;                        // ① 基线
    int p = partition(a, lo, hi);                // ② 划分（pivot 归位）
    quickSort(a, lo, p - 1);                     // ③ 递归左
    quickSort(a, p + 1, hi);                     // ④ 递归右
}

int partition(int[] a, int lo, int hi) {
    int pivot = a[hi];                           // ① 基准 = 末尾
    int i = lo;                                  // ② i = < pivot 边界
    for (int j = lo; j < hi; j++) {
        if (a[j] < pivot) {                      // ③ 小于基准 → 换到左区
            int t = a[i]; a[i] = a[j]; a[j] = t;
            i++;
        }
    }
    int t = a[i]; a[i] = a[hi]; a[hi] = t;       // ④ pivot 归位
    return i;                                    // ⑤ 返回 pivot 位置
}
// 记忆: "选末尾基准 → 双指针扫描 → pivot 归位"
```

### 2.2 面试要点

```text
复杂度: 平均 ≈1.39n log n（常数最小）/ 最坏 O(n²)（固定基准+有序）
稳定性: ✘（跨距离交换）
空间: O(log n) 递归栈（尾递归可保）

⚠️ 退化防御（追问必答）:
  ① 随机基准 / 三数取中（防有序退化）
  ② introsort 深度检测转堆排（JDK 阈值 64）
  ③ 三路划分（重复元素 → O(n)）
  ④ 小区间切插入（阈值 16~47）
```

## 3. 归并排序（递归版）

### 3.1 2 分钟模板

```java
/** 归并排序——拆排合，O(n log n)/O(n)，稳定 */
void mergeSort(int[] a) {
    mergeSort(a, 0, a.length - 1, new int[a.length]);  // ① 全局辅助数组
}

void mergeSort(int[] a, int lo, int hi, int[] tmp) {
    if (lo >= hi) return;                        // ② 基线
    int mid = lo + (hi - lo) / 2;                // ③ 对半拆（防溢出）
    mergeSort(a, lo, mid, tmp);                  // ④ 递归左
    mergeSort(a, mid + 1, hi, tmp);              // ⑤ 递归右
    merge(a, lo, mid, hi, tmp);                  // ⑥ 合并
}

void merge(int[] a, int lo, int mid, int hi, int[] tmp) {
    System.arraycopy(a, lo, tmp, lo, hi - lo + 1);   // ⑦ 拷贝辅助
    int i = lo, j = mid + 1, k = lo;
    while (i <= mid && j <= hi) {
        if (tmp[i] <= tmp[j]) a[k++] = tmp[i++];     // ⑧ <= 保稳定
        else a[k++] = tmp[j++];
    }
    while (i <= mid) a[k++] = tmp[i++];          // ⑨ 左剩余
    while (j <= hi) a[k++] = tmp[j++];           // ⑩ 右剩余
}
// 记忆: "二分递归 + 三 while 合并（主循环 + 左剩 + 右剩）"
```

### 3.2 面试要点

```text
复杂度: 最好=平均=最坏 O(n log n)（无退化！）
稳定性: ✔（merge 用 <=）
空间: O(n) 辅助数组（链表版 O(log n)）

⚠️ 必答细节:
  ① 全局辅助数组（每层新建 → O(n log n) 空间）
  ② mid 防溢出: lo + (hi−lo)/2
  ③ 稳定性: temp[i] <= temp[j] 相等取左
  ④ 链表归并 O(1) 额外空间（改指针）
```

## 4. 堆排序（siftDown 版）

### 4.1 5 分钟模板

```java
/** 堆排序——大顶堆升序，O(n log n)/O(1)，不稳定 */
void heapSort(int[] a) {
    int n = a.length;
    for (int i = (n - 2) / 2; i >= 0; i--) sink(a, i, n);   // ① 建堆（自底向上）
    for (int i = n - 1; i > 0; i--) {
        int t = a[0]; a[0] = a[i]; a[i] = t;    // ② 堆顶 ↔ 末尾
        sink(a, 0, i);                          // ③ 堆化 [0, i)
    }
}

void sink(int[] a, int i, int n) {              // ④ 下沉（灵魂）
    while (2 * i + 1 < n) {
        int c = 2 * i + 1;                      // 左孩子
        if (c + 1 < n && a[c + 1] > a[c]) c++;  // 选较大孩子
        if (a[i] >= a[c]) break;                // 已满足堆性质
        int t = a[i]; a[i] = a[c]; a[c] = t;    // 交换下沉
        i = c;
    }
}
// 记忆: "siftDown 是灵魂——建堆和取顶都调它"
```

### 4.2 面试要点

```text
复杂度: 最好=平均=最坏 O(n log n)（最坏有界！）
建堆: O(n)（Σ h·n/2^h < 2n）
稳定性: ✘（堆化交换跨距离）
空间: O(1)（原地）

⚠️ 必答细节:
  ① 建堆起点 (n−2)/2（最后非叶子）
  ② 升序用大顶堆（取最大放末尾）
  ③ 缓存不友好（下标 ×2 跳跃）→ 平均慢于快排
  ④ introsort 兜底角色（深度超限转堆排）
```

## 5. 三模板对照与选型

| 维度 | 快排 | 归并 | 堆排 |
|------|:---:|:---:|:---:|
| 平均 | O(n log n) 常数最小 | O(n log n) 常数中 | O(n log n) 常数大 |
| 最坏 | O(n²)（可防） | **O(n log n)** | **O(n log n)** |
| 空间 | O(log n) 栈 | O(n) 辅助 | **O(1)** |
| 稳定 | ✘ | ✔ | ✘ |
| 缓存 | 好 | 中 | 差 |
| 定位 | 通用数组（工程默认） | 稳定/链表/外部 | 最坏有界 + 内存受限 |

```text
⚠️ 选型一句话:
  "通用 → 快排；稳定/链表 → 归并；最坏有界 + O(1) → 堆排"
  JDK 答案: 基本类型双轴快排、对象 TimSort、introsort 堆排兜底
```

## 6. 退化与防御速查

| 算法 | 退化条件 | 防御手段 |
|:---:|------|------|
| 快排 | 固定基准 + 有序/逆序 | 随机基准/三数取中 + introsort + 三路划分 |
| 归并 | 无（结构固定） | 不需要 |
| 堆排 | 无（与数据无关） | 不需要 |

```text
⚠️ 面试必答:
  "快排最坏 O(n²) 可防——随机基准让退化不可构造、
   introsort 深度超限转堆排彻底兜底；
   归并/堆排最坏恒 O(n log n)（拆分与数据无关）。"
```

## 7. 易错点总表

| # | 算法 | 易错点 | 正确写法 |
|:---:|:---:|------|------|
| 1 | 快排 | 忘基线 `lo >= hi` | 无限递归 |
| 2 | 快排 | Lomuto 循环含 pivot | `j < hi`（不含末尾） |
| 3 | 快排 | 忘 pivot 归位 | 最后 swap(arr[i], arr[hi]) |
| 4 | 归并 | merge 用 `<` | `<=`（保稳定） |
| 5 | 归并 | 辅助数组每层新建 | 全局 tmp 复用 |
| 6 | 归并 | 剩余元素漏拷 | 两个 while 接尾 |
| 7 | 堆排 | 建堆起点 `n/2` | `(n−2)/2`（最后非叶子） |
| 8 | 堆排 | 忘 break | 死循环/多余下沉 |
| 9 | 堆排 | 升序用小顶堆 | 用大顶堆 |

> 🎯 **核心要点**：高级排序通关——**三大件手撕（快排 2 分钟/归并 2 分钟/堆排 5 分钟）+ 选型一句话（通用快排/稳定归并/有界堆排）+ 退化防御（快排可防、归并堆排无退化）**。它是手撕主战场——"会写三大件 + 讲清退化防御"，排序手撕的 70% 分数就到手了。
