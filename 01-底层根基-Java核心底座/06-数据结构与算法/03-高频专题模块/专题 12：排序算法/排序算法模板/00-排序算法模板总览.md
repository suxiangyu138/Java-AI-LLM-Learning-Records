## 4. 复杂度速查表

| 算法 | 最好 | 平均 | 最坏 | 空间 | 稳定 | 手撕优先级 |
|------|:---:|:---:|:---:|:---:|:---:|:---:|
| 插入 | O(n) | O(n²) | O(n²) | O(1) | ✔ | ★★★★ |
| 希尔 | O(n log n)~ | ≈O(n^1.3) | O(n²) | O(1) | ✘ | ★★ |
| 冒泡 | O(n) | O(n²) | O(n²) | O(1) | ✔ | ★★ |
| 选择 | O(n²) | O(n²) | O(n²) | O(1) | ✘ | ★★★ |
| 快排 | O(n log n) | O(n log n) | O(n²) | O(log n) | ✘ | ★★★★★ |
| 归并 | O(n log n) | O(n log n) | O(n log n) | O(n) | ✔ | ★★★★★ |
| 堆排 | O(n log n) | O(n log n) | O(n log n) | O(1) | ✘ | ★★★★ |
| 计数 | O(n+k) | O(n+k) | O(n+k) | O(k) | ✔ | ★★★ |
| 桶 | O(n) | O(n+k) | O(n²) | O(n+k) | 视桶内 | ★★ |
| 基数 | O(d(n+r)) | O(d(n+r)) | O(d(n+r)) | O(n+r) | ✔ | ★★★ |

> 🎯 **一句话记忆**："**冒插归基稳定，选快希堆不稳；快排最坏退化，归并稳定无退化**"——口诀背熟，稳定性与最坏全部拿下。

## 5. 选型决策树

```text
① 要稳定？
   ├─ 是 → 归并 / TimSort（对象排序）
   └─ 否 → 快排 / 堆排（基本类型）
② 内存受限（O(1)）？
   ├─ 是 → 堆排（最坏有界 + 原地）
   └─ 否 → 快排（平均最快）
③ 数据特征？
   ├─ 近乎有序 → 插入（O(n)）
   ├─ 值域小 → 计数（O(n+k)）
   ├─ 定长整数 → 基数（O(n)）
   └─ 外部数据 → 多路归并

⚠️ JDK 答案: 基本类型双轴快排、对象 TimSort——
  "工程选型的完整答案就是 JDK 的选法"
```

## 6. 手撕优先级与验收标准

### 6.1 手撕优先级（面试权重）

```text
第一梯队（必默写）: 快排 Lomuto、归并、堆排
第二梯队（高频）: 插入、选择、计数、基数
第三梯队（了解）: 希尔、冒泡、桶、多路归并

⚠️ 手撕顺序建议: 快排 → 归并 → 堆排 → 插入 → 计数
  （由易到难 + 权重从高到低）
```

### 6.2 三级验收标准（05 文件详讲）

```text
30 秒级: 插入 / 冒泡 / 选择（无脑默写）
2 分钟级: 快排 Lomuto / 归并 / 计数（核心模板）
5 分钟级: 堆排 / 基数 / 希尔（进阶模板）

⚠️ 验收方法: 写完立即自测——
  ① 小样例走一遍（[1,3,2,5,4]）
  ② 边界（空/单元素/全相等/逆序）
  ③ 复杂度脱口而出
```
