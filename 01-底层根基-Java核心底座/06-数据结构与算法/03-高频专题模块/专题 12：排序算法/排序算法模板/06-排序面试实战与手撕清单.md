## 1. 手撕清单（三级）

### 1.1 必默写清单

```text
30 秒级（热身）:
  □ 插入排序（key 备份 + 前驱后移）
  □ 冒泡排序（swapped 提前终止）
  □ 选择排序（找 min + 交换）

2 分钟级（主战场）:
  □ 快排 Lomuto（选基准 → 双指针 → pivot 归位）
  □ 归并排序（二分递归 + 三 while merge）
  □ 计数排序（频次 → 前缀和 → 倒序回填）
  □ 基数排序（按位循环 + 计数三连）

5 分钟级（进阶）:
  □ 堆排序（siftDown + 建堆 + 取顶）
  □ 希尔排序（gap 递减）
  □ K 路归并（入堆 → 弹最小 → 补位）
```

### 1.2 手撕顺序建议

```text
快排 → 归并 → 堆排 → 插入 → 计数 → 基数
（权重从高到低 + 由易到难）

⚠️ 每写完一个:
  ① [1,3,2,5,4] 走一遍
  ② 边界（空/单/逆序/全相等）
  ③ 复杂度脱口而出
```

> 🎯 **手撕策略**："**主战场是快排/归并/堆排三大件——2+2+5 分钟默写是硬指标**；线性三件（计数/基数）2 分钟；O(n²) 三件 30 秒热身。排序手撕没有捷径，只有模板肌肉记忆。"

## 2. 答题流程与话术模板

### 2.1 答题三步骤

```text
① 定位（10 秒）: 哪类排序？复杂度要求？稳定要求？
② 手撕（模板）: 对应模板默写 + 小样例验证
③ 论述（30 秒）: 复杂度 + 稳定性 + 选型理由

⚠️ 面试官期待:
  "写完主动讲'为什么用这个排序'——
   复杂度/稳定性/数据特征三要素齐备 = 完整答案"
```

### 2.2 话术模板

```text
"我用【算法】——【一句话原理】。
复杂度: 【三情形】；空间: 【X】；稳定: 【是/否】。
为什么选它: 【数据特征 → 选型理由】。
（被追问优化）【优化点】。"

例: "我用快速排序——选基准划分递归。
    平均 O(n log n)、最坏 O(n²)（可防）；O(log n) 栈；不稳定。
    选它因为通用数组平均最快、原地缓存友好；
    防御退化用随机基准 + 小区间切插入。
    JDK 基本类型排序正是双轴快排。"
```

## 3. 高频追问 TOP 10

| # | 追问 | 标准回答 |
|:---:|------|---------|
| 1 | 快排为什么平均最快？ | 原地无拷贝 + 缓存友好；比较常数 1.39n log n 虽略高但搬移成本远低 |
| 2 | 快排最坏什么时候？ | 固定基准 + 有序/逆序输入——随机基准/三数取中可防 |
| 3 | 归并为什么稳定无退化？ | 拆分只按位置（与数据无关）+ merge 用 <=（相等取左） |
| 4 | 堆排建堆为什么 O(n)？ | 底层节点多但下沉少——Σ h·n/2^h < 2n |
| 5 | JDK 用什么排序？ | 基本类型双轴快排（+归并/堆排兜底）；对象 TimSort（稳定） |
| 6 | 哪些排序稳定？ | "冒插归基"稳定；选择/快排/希尔/堆排不稳定 |
| 7 | 什么时候用计数/基数？ | 值域小 → 计数；定长整数 → 基数（线性 + 稳定） |
| 8 | 为什么对象排序不用快排？ | 快排不稳定——对象排序要求稳定 → TimSort |
| 9 | 外部排序核心？ | 分块生成段 + 多路归并——趟数 ⌈log_K m⌉ = I/O 次数 |
| 10 | 2025-2026 排序新进展？ | JDK-8266431 并行基数排序、Powersort 进 CPython、Onesweep 进 CUB |

## 4. 选型论述（面试加分）

### 4.1 选型三问

```text
① 稳定吗？ → 稳定归并/TimSort；不稳快排/堆排
② 内存够吗？ → 够归并 O(n)；紧堆排 O(1)
③ 数据什么特征？ → 近有序插入、值域小计数、定长键基数

⚠️ 一句话:
  "通用数组 → 快排；稳定/链表 → 归并；
   最坏有界 + 内存受限 → 堆排；数据特征 → 线性家族"
```

### 4.2 工程故事（2025-2026 谈资）

```text
① JDK-8266431（2026）: 双轴快排引入并行基数排序
② Powersort（2022）: TimSort 继任者，CPython 3.11+ 默认
③ Onesweep（CUB v1.10）: GPU 基数排序单趟前缀和
④ 跨语言基准（2026）: 堆排/归并是"与数据分布最一致"的 O(n log n)

⚠️ 面试表达: "排序领域没有永恒的王——
   快排统治 CPU 通用排序、基数统治 GPU、
   TimSort → Powersort 持续进化。"
```

## 5. 面试实战演练：三道真题全程

### 5.1 真题一：912 排序数组（三大件选型）

```text
面试过程示范:
  ① 定位: "n ≤ 5×10⁴ → O(n log n)，不要求稳定"
  ② 手撕: 快排 Lomuto（三数取中 + 小区间插入 = 工程版）
  ③ 论述: "平均最快 + 原地；退化防御三层齐备"
  ④ 追问: "归并/堆排？" → 稳定用归并、最坏有界用堆排
  ⑤ 追问: "JDK 怎么做？" → 双轴快排 + 47/64/286 决策树
```

### 5.2 真题二：手写堆排序（建堆 + 取顶）

```text
面试过程示范:
  ① 定位: "最坏有界 + O(1) 空间 → 堆排"
  ② 手撕: siftDown + 建堆 (n−2)/2 + 取顶循环
  ③ 关键: "建堆 O(n) 证明——Σ h·n/2^h < 2n"
  ④ 追问: "为什么升序用大顶堆？" → 取最大放末尾
  ⑤ 追问: "introsort 里堆排的角色？" → 深度超限兜底
```

### 5.3 真题三：合并 K 个升序链表（23 题）

```text
面试过程示范:
  ① 定位: "K 路归并 → 最小堆"
  ② 手撕: 入堆 → 弹最小 → 补位（ListNode 版）
  ③ 复杂度: O(N log K)/O(K)
  ④ 追问: "分治版？" → O(N log K)/O(log K) 空间
  ⑤ 追问: "外部排序怎么用它？" → 分块生成段 + K 路归并
```
