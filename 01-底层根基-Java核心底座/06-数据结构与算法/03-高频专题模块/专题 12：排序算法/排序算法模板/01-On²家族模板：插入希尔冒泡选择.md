## 1. 家族总览：四个 30 秒模板

| 算法 | 一句话记忆 | 30 秒版本要点 |
|------|------|------|
| 插入 | 扑克牌——取牌插到已排序区 | 三改动：key 备份、前驱后移、插入 |
| 希尔 | 插入的 gap 版 | 外层 gap 循环 + 三处改动 |
| 冒泡 | 相邻交换、大者上浮 | swapped 标记提前终止 |
| 选择 | 找最小放前面 | 双循环找 minIndex + 交换 |

```text
⚠️ 手撕定位:
  插入 = 唯一"工程有用"的 O(n²)（TimSort 组件）
  选择 = 交换次数 O(n)（写操作贵场景）
  冒泡 = 教学直观（提前终止可检测有序）
  希尔 = 插入的规模化（了解即可）
```

> 🎯 **核心认知**："**O(n²) 家族四模板 = 30 秒/个——插入是王者（稳定+适应+常数小）、选择交换最少、冒泡教学、希尔了解**。复杂度统一 O(n²)（插入/冒泡最好 O(n)），稳定性"插入冒泡稳、选择希尔不稳"。"

## 2. 插入排序（手撕首选）

### 2.1 30 秒模板

```java
/** 插入排序——扑克牌模型，O(n²)/O(1)，稳定 */
void insertionSort(int[] a) {
    for (int i = 1; i < a.length; i++) {
        int key = a[i], j = i - 1;             // ① 取牌备份
        while (j >= 0 && a[j] > key) {         // ② 严格大于才移动（稳定）
            a[j + 1] = a[j];                   // ③ 前驱后移
            j--;
        }
        a[j + 1] = key;                        // ④ 插入
    }
}
// 推演 [5,2,4]：2 → [2,5,4]；4 → [2,4,5] ✓
// 记忆: "取 key → 前驱后移 → 插入"三连
```

### 2.2 面试要点

```text
复杂度: 最好 O(n)（有序）/ 平均 O(n²) / 最坏 O(n²)
稳定性: ✔（严格大于才移动）
适应性: ✔（近乎有序 O(n)——TimSort 选它的原因）
常数: 最小（O(n²) 家族实际最快）

⚠️ 变体: 折半插入（比较降 O(n log n)、移动不变）
  哨兵版（软考格式: arr[0] 作哨兵省边界判断）
```

## 3. 希尔排序（gap 递减）

### 3.1 30 秒模板

```java
/** 希尔排序——插入的 gap 版，最坏 O(n²)，不稳定 */
void shellSort(int[] a) {
    for (int gap = a.length / 2; gap > 0; gap /= 2) {   // ① gap 递减
        for (int i = gap; i < a.length; i++) {          // ② 组间交叉
            int key = a[i], j = i;
            while (j >= gap && a[j - gap] > key) {      // ③ 组内插入
                a[j] = a[j - gap];
                j -= gap;
            }
            a[j] = key;
        }
    }
}
// 记忆: 插入排序改三处——加 gap 循环、i=gap、j-=gap
```

### 2.2 面试要点

```text
复杂度: 依增量序列（Sedgewick 平均 ≈ O(n^1.3)）
稳定性: ✘（跨组跳跃）
增量序列: 教学 Knuth / 小数据 Ciura / 大数据 Sedgewick
  避免 n/2（全偶增量奇偶隔离 → O(n²)）

⚠️ 面试定位: 了解原理即可，手撕优先级低于快排/归并
  深度专题: ②希尔排序（缩小增量排序）/
```

## 4. 冒泡排序（提前终止）

### 4.1 30 秒模板

```java
/** 冒泡排序——相邻交换 + 提前终止，O(n²)/O(1)，稳定 */
void bubbleSort(int[] a) {
    for (int i = 0; i < a.length - 1; i++) {
        boolean swapped = false;                       // ① 交换标记
        for (int j = 0; j < a.length - 1 - i; j++) {
            if (a[j] > a[j + 1]) {                     // ② 严格大于（稳定）
                int t = a[j]; a[j] = a[j + 1]; a[j + 1] = t;
                swapped = true;
            }
        }
        if (!swapped) return;                          // ③ 无交换 = 已有序
    }
}
// 记忆: "相邻交换 + swapped 提前终止"——有序输入一趟即停
```

### 4.2 面试要点

```text
复杂度: 最好 O(n)（提前终止）/ 平均 O(n²) / 最坏 O(n²)
稳定性: ✔（严格大于才交换）
交换次数: 最坏 n(n−1)/2（= 逆序对数量——软考考点）

⚠️ 变体: 鸡尾酒排序（双向）、梳排序（间隔递减）
  定位: 教学直观——"无交换 ⇔ 有序"是它唯一思想遗产
```

## 5. 选择排序（交换最少）

### 5.1 30 秒模板

```java
/** 选择排序——找最小交换，O(n²)/O(1)，不稳定 */
void selectionSort(int[] a) {
    for (int i = 0; i < a.length - 1; i++) {
        int min = i;                                   // ① 假设当前最小
        for (int j = i + 1; j < a.length; j++) {       // ② 扫描找最小
            if (a[j] < a[min]) min = j;
        }
        if (min != i) {                                // ③ 交换到前面
            int t = a[i]; a[i] = a[min]; a[min] = t;
        }
    }
}
// 记忆: "双循环找 minIndex + 交换"——交换次数恒 n−1
```

### 5.2 面试要点

```text
复杂度: 最好=平均=最坏 O(n²)（不适应性！）
稳定性: ✘（跨距离交换）
交换次数: 恒 n−1（O(n²) 家族最少——写操作贵场景）

⚠️ 定位: "交换 O(n) vs 不适应性 O(n²)"——
  大对象数组/闪存写入用；其余被插入/快排取代
```

## 6. 四模板对照与选型

| 维度 | 插入 | 希尔 | 冒泡 | 选择 |
|------|:---:|:---:|:---:|:---:|
| 最好 | O(n) | O(n log n)~ | O(n) | O(n²) |
| 平均/最坏 | O(n²) | ≈O(n^1.3)/O(n²) | O(n²) | O(n²) |
| 稳定 | ✔ | ✘ | ✔ | ✘ |
| 适应 | ✔ | 部分 | ✔ | ✘ |
| 交换/移动 | 移动少 | 中 | 最多 | **最少（n−1）** |
| 常数 | **最小** | 中 | 最大 | 中 |
| 定位 | 小数组/近有序 | 了解 | 教学 | 写操作贵 |

```text
⚠️ 选型一句话:
  "n < 64 或近乎有序 → 插入；
   写操作贵 → 选择；教学 → 冒泡；其余 → 高级排序"
```

## 7. 易错点总表

| # | 算法 | 易错点 | 正确写法 |
|:---:|:---:|------|------|
| 1 | 插入 | 忘 key 备份 | `int key = a[i]` 先存 |
| 2 | 插入 | `>=` 比较 | `>`（严格大于保稳定） |
| 3 | 希尔 | 内层 `j--` | `j -= gap`（步长是 gap） |
| 4 | 希尔 | `j >= 0` | `j >= gap`（防越界） |
| 5 | 冒泡 | 忘 swapped | 提前终止标记 |
| 6 | 冒泡 | 内层边界 | `j < n-1-i`（区间收缩） |
| 7 | 选择 | 忘判 `min != i` | 已有序时零交换 |
| 8 | 选择 | 交换位置错 | `a[i] ↔ a[min]` |

> 🎯 **核心要点**：O(n²) 家族通关——**四模板 30 秒默写 + 稳定性口诀（插入冒泡稳）+ 选型一句话（小插入/贵选择/教学冒泡/了解希尔）**。它是手撕的"热身区"——30 秒热完身，进入 02 的高级排序主战场。
