## 1. 家族总览：线性三兄弟

| 算法 | 一句话记忆 | 键要求 | 复杂度 |
|------|------|------|:---:|
| 计数 | 值 → 下标直接定位 | 值域小（整数） | O(n+k) |
| 桶 | 分桶 + 桶内任意排序 | 均匀分布 | O(n) 期望 |
| 基数 | 按位多次稳定计数 | 可分位（定长键） | O(d(n+r)) |

```text
⚠️ 共同本质: "值域索引"而非"比较"——
  用键值直接定位 → 突破比较排序下界 Ω(n log n)
  前提: 键可索引（计数）/可分位（基数）/分布可利用（桶）
```

> 🎯 **核心认知**："**线性三兄弟共享'值域索引'思想——计数是单轮索引、基数是分位多轮、桶是分布分区**。面试选型：值域小 → 计数、定长键 → 基数、均匀分布 → 桶。"

## 2. 计数排序（值域索引）

### 2.1 2 分钟模板（含稳定版）

```java
/** 计数排序——值域索引，O(n+k)/O(k)，稳定（倒序回填版） */
void countingSort(int[] a, int maxVal) {
    int[] count = new int[maxVal + 1];
    for (int x : a) count[x]++;                  // ① 频次统计

    for (int i = 1; i <= maxVal; i++)            // ② 前缀和（位置区间）
        count[i] += count[i - 1];

    int[] result = new int[a.length];
    for (int i = a.length - 1; i >= 0; i--) {    // ③ ⚠️ 倒序回填（稳定）
        result[--count[a[i]]] = a[i];
    }
    System.arraycopy(result, 0, a, 0, a.length);
}
// 记忆: "频次 → 前缀和 → 倒序回填"三连
// 非稳定简化版: 直接按值展开（count[i] 个 i 依次填）
```

### 2.2 面试要点

```text
复杂度: O(n+k)（k = 值域）——k 小时接近 O(n)
稳定性: ✔（倒序回填）/ 展开版 ✘
空间: O(k)

⚠️ 选型: 值域小（成绩 0-100）→ 计数；
  值域大（32 位整数）→ 计数空间爆炸 → 基数
  字符集小（26/128）→ 数组计数（哈希替代品）
```

## 3. 桶排序（分布分区）

### 3.1 模板（概念 + 核心代码）

```java
/** 桶排序——分桶 + 桶内排序，O(n) 期望，稳定性视桶内 */
void bucketSort(double[] a, int bucketCount) {
    List<List<Double>> buckets = new ArrayList<>();
    for (int i = 0; i < bucketCount; i++) buckets.add(new ArrayList<>());

    for (double x : a) {                         // ① 分桶（按值映射）
        int idx = (int) (x * bucketCount);       // [0,1) 均匀分布示例
        buckets.get(idx).add(x);
    }
    for (List<Double> bucket : buckets) {
        Collections.sort(bucket);                // ② 桶内排序（任意算法）
    }
    int idx = 0;
    for (List<Double> bucket : buckets)          // ③ 按桶序收集
        for (double x : bucket) a[idx++] = x;
}
// 记忆: "分桶 → 桶内排 → 按序收集"三连
```

### 3.2 面试要点

```text
复杂度: O(n) 期望（均匀分布）/ O(n²) 最坏（全进一桶）
稳定性: 视桶内排序（桶内稳定 → 整体稳定）
空间: O(n+k)

⚠️ 选型: 数据均匀分布 → 桶；
  非均匀（集中一桶）→ 退化为 O(n log n) → 换其他
  164 最大间距 = 桶思想的"只记 min/max"变体
```

## 4. 基数排序（按位稳定计数）

### 4.1 2 分钟模板（十进制 LSD）

```java
/** 基数排序——按位稳定计数，O(d(n+r))/O(n+r)，稳定 */
void radixSort(int[] a) {
    int max = 0;
    for (int x : a) max = Math.max(max, x);
    for (int exp = 1; max / exp > 0; exp *= 10) {   // ① 按位轮（个→十→百）
        countingByDigit(a, exp);                     // ② 每轮 = 稳定计数排序
    }
}

void countingByDigit(int[] a, int exp) {
    int[] count = new int[10];                   // 十进制 0-9
    int[] result = new int[a.length];
    for (int x : a) count[(x / exp) % 10]++;     // ① 该位频次
    for (int i = 1; i < 10; i++) count[i] += count[i - 1];  // ② 前缀和
    for (int i = a.length - 1; i >= 0; i--) {    // ③ 倒序回填（稳定！）
        result[--count[(a[i] / exp) % 10]] = a[i];
    }
    System.arraycopy(result, 0, a, 0, a.length);
}
// 记忆: "按位循环 + 每轮计数三连"——d 轮后完全有序
```

### 4.2 面试要点

```text
复杂度: O(d(n+r))——定长键（32 位 r=256 → 4 轮）即 O(n)
稳定性: ✔（每轮倒序回填）
空间: O(n+r)

⚠️ 选型: 定长整数/字符串 → 基数（线性且稳定）；
  负数 → 偏移或符号位变换（绝不绝对值）；
  工程 r=256（字节）4 轮完成 32 位整数
```

## 5. 三模板对照与选型

| 维度 | 计数 | 桶 | 基数 |
|------|:---:|:---:|:---:|
| 键要求 | 值域小 | 均匀分布 | 可分位 |
| 时间 | O(n+k) | O(n) 期望 | O(d(n+r)) |
| 空间 | O(k) | O(n+k) | O(n+r) |
| 稳定 | ✔（倒序回填） | 视桶内 | ✔ |
| 典型 | 成绩/频次 | 均匀随机数 | 32 位整数/字符串 |

```text
⚠️ 选型一句话:
  "值域小 → 计数；均匀分布 → 桶；定长键 → 基数；
   通用比较 → 快排/归并（非比较排序是'用键特性换线性'）"
```

## 6. 稳定性与实现细节

```text
稳定性是正确性关键（基数）:
  计数排序倒序回填 = 稳定写法（"从后往前扫、先减再用"）
  基数每轮必须稳定 → 高位相同时低位顺序不乱
  桶排序稳定性 = 桶内排序的稳定性

⚠️ 三个实现细节:
  ① 前缀和: count[i] += count[i−1]（定位区间）
  ② 负数: 偏移/符号位（计数/基数）；桶用值域映射
  ③ 字符集小 → 数组计数替代哈希（26/128 槽）
```

## 7. 易错点总表

| # | 算法 | 易错点 | 正确写法 |
|:---:|:---:|------|------|
| 1 | 计数 | 正序回填 | 倒序回填（保稳定） |
| 2 | 计数 | 忘前缀和 | count[i] += count[i-1] |
| 3 | 桶 | 桶数=0 | bucketCount ≥ 1 |
| 4 | 桶 | 非均匀硬用 | 退 O(n²) → 换算法 |
| 5 | 基数 | 忘稳定回填 | 每轮倒序回填 |
| 6 | 基数 | exp 边界错 | `max / exp > 0` |
| 7 | 基数 | 负数直接排 | 偏移/符号位变换 |

> 🎯 **核心要点**：线性排序通关——**三模板（计数 2 分钟/基数 2 分钟/桶概念）+ 稳定性细节（倒序回填是灵魂）+ 选型一句话（值域小计数/均匀桶/定长键基数）**。它是"突破 Ω(n log n) 下界"的家族——会写三兄弟 + 讲清键要求，线性排序手撕就稳了。
