## 1. 三级验收标准

### 1.1 30 秒级（无脑默写）

```text
□ 插入排序（key 备份 + 前驱后移 + 插入）
□ 冒泡排序（相邻交换 + swapped 提前终止）
□ 选择排序（双循环找 min + 交换）

验收: 小样例 [1,3,2,5,4] 一遍过 + 复杂度脱口而出
```

### 1.2 2 分钟级（核心模板）

```text
□ 快速排序 Lomuto（选基准 → 双指针 → pivot 归位）
□ 归并排序（二分递归 + 三 while merge）
□ 计数排序（频次 → 前缀和 → 倒序回填）
□ 基数排序（按位循环 + 每轮计数三连）

验收: 边界全覆盖（空/单/逆序/全相等）
```

### 1.3 5 分钟级（进阶模板）

```text
□ 堆排序（siftDown + 建堆 (n−2)/2 + 取顶）
□ 希尔排序（gap 递减 + 三处改动）
□ K 路归并（入堆 → 弹最小 → 补位）

验收: 能讲复杂度推导（建堆 O(n)、轮数公式）
```

> 🎯 **验收顺序**："**热身 30 秒三件 → 主战场 2 分钟三件 → 进阶 5 分钟三件**——每次面试前按这个顺序过一遍，排序手撕就稳了。"

## 2. 八大排序速查表

| 算法 | 最好 | 平均 | 最坏 | 空间 | 稳定 | 手撕级别 |
|------|:---:|:---:|:---:|:---:|:---:|:---:|
| 插入 | O(n) | O(n²) | O(n²) | O(1) | ✔ | 30 秒 |
| 希尔 | O(n log n)~ | ≈O(n^1.3) | O(n²) | O(1) | ✘ | 5 分钟 |
| 冒泡 | O(n) | O(n²) | O(n²) | O(1) | ✔ | 30 秒 |
| 选择 | O(n²) | O(n²) | O(n²) | O(1) | ✘ | 30 秒 |
| 快排 | O(n log n) | O(n log n) | O(n²) | O(log n) | ✘ | 2 分钟 |
| 归并 | O(n log n) | O(n log n) | O(n log n) | O(n) | ✔ | 2 分钟 |
| 堆排 | O(n log n) | O(n log n) | O(n log n) | O(1) | ✘ | 5 分钟 |
| 计数 | O(n+k) | O(n+k) | O(n+k) | O(k) | ✔ | 2 分钟 |
| 桶 | O(n) | O(n+k) | O(n²) | O(n+k) | 视桶内 | 概念 |
| 基数 | O(d(n+r)) | O(d(n+r)) | O(d(n+r)) | O(n+r) | ✔ | 2 分钟 |

```text
⚠️ 记忆口诀:
  "冒插归基稳，选快希堆不稳；
   快排最坏退化，归并稳定无退化；
   空间: 归并 O(n)、快排 O(log n) 栈、堆排 O(1)"
```

## 3. 稳定性口诀与证明

### 3.1 稳定家族

```text
✔ 稳定: 冒泡、插入、归并、基数（口诀"冒插归基"）
✘ 不稳: 选择、快排、希尔、堆排（口诀"选快希堆"）

为什么稳定/不稳:
  稳定: "严格大于/小于才移动"（插入/冒泡）
        "相等取左块"（归并）/ "倒序回填"（基数）
  不稳: "跨距离交换"（快排/选择/堆排）
        "跨组跳跃"（希尔）
```

### 3.2 稳定性的应用

```text
多关键字排序: 先按次关键字稳定排 → 再按主关键字稳定排
Java 对象排序: TimSort（稳定）——Arrays.sort(Object[])
基本类型: 双轴快排（不需要稳定）

⚠️ 面试必答:
  "稳定性由'交换/移动是否跨越相等元素'决定——
   相邻移动（插入/冒泡）稳、跨距离交换（快排/选择/堆）不稳"
```

## 4. 易错点总表（全部排序）

| # | 算法 | 易错点 | 正确写法 |
|:---:|:---:|------|------|
| 1 | 插入 | 忘 key 备份 / `>=` | `int key = a[i]` / `>` |
| 2 | 希尔 | `j--` 而非 `j -= gap` | 步长 = gap |
| 3 | 冒泡 | 忘 swapped | 提前终止标记 |
| 4 | 选择 | 忘判 min != i | 零交换优化 |
| 5 | 快排 | 忘基线 / 忘 pivot 归位 | `lo >= hi` / 最后 swap |
| 6 | 归并 | `<` 破坏稳定 / 辅助每层新建 | `<=` / 全局 tmp |
| 7 | 堆排 | 建堆起点 `n/2` / 升序小顶堆 | `(n−2)/2` / 大顶堆 |
| 8 | 计数 | 正序回填 | 倒序回填（稳定） |
| 9 | 基数 | 忘稳定回填 / 负数直接排 | 每轮倒序 / 偏移 |
| 10 | K 路 | 忘补位 / 空路入堆 | 弹出补位 / 判空 |

## 5. 手撕验证方法

### 5.1 四步验证

```text
① 小样例: [1,3,2,5,4] 手走一遍（对照期望 [1,2,3,4,5]）
② 边界: 空数组 / 单元素 / 全相等 / 逆序
③ 稳定性: 构造含相等元素数组，检查相对顺序
④ 复杂度: 写完立即说出三情形复杂度

⚠️ 时间控制: 30 秒题 30 秒内写完；
   2 分钟题 2 分钟内写完（含边界自查）
```

### 5.2 常见自测样例

```text
[5,2,4,6,1]（经典插入/冒泡样例）
[9,8,7,6,5,4,3,2]（逆序——最坏情形）
[1,1,1,1]（全相等——稳定性验证）
[1] / []（边界）
```

## 6. 复杂度推导要点

### 6.1 必背推导

```text
快排: T(n) = 2T(n/2) + O(n) → O(n log n)（平衡时）
  退化: T(n) = T(n−1) + O(n) → O(n²)（有序 + 固定基准）
归并: T(n) = 2T(n/2) + O(n) → O(n log n)（恒成立）
堆排: 建堆 O(n)（Σ h·n/2^h < 2n）+ n 次取顶 O(log n)
基数: O(d·(n+r))——定长键 d 恒定 → O(n)
希尔: 依增量序列（Sedgewick 平均 ≈ O(n^1.3)）
```

### 6.2 面试表达模板

```text
"这排序是【算法】——【一句话原理】。
复杂度: 【三情形】；空间: 【X】；稳定: 【是/否】。
（被追问最坏/退化）【退化条件与防御】。"

例: "快排——选基准划分递归。
    平均 O(n log n)（常数 1.39n log n）、最坏 O(n²)（固定基准+有序）；
    空间 O(log n) 栈；不稳定。
    退化可用随机基准 + introsort 防御——JDK 双轴快排正是这么做的。"
```

> 🎯 **核心要点**：手撕验收通关——**三级标准（30 秒/2 分钟/5 分钟）+ 八大速查表 + 稳定性口诀 + 易错总表（10 条）+ 四步验证**。排序手撕的完整闭环 = "会默写 + 会速答 + 会验证"——这张表就是面试前的最后 30 分钟复习页。
