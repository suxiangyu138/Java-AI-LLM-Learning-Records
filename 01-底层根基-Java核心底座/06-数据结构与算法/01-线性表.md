# 线性表

## 📌 课程定位
线性表是最基础的数据结构——栈、队列、哈希表都以它为基础。LeetCode 中超过30%的题目直接或间接用到线性表。

## 🎯 核心章节

### 1. 线性表抽象数据结构（ADT）
- **定义**：n个相同类型数据元素的有穷序列
- **基本操作**：初始化、求长度、按值查找、按位查找、插入、删除、遍历

### 2. 顺序表（数组实现）
- **存储结构**：连续内存空间、随机访问O(1)
- **插入操作**：平均移动n/2个元素，O(n)——尾部插入O(1)
- **删除操作**：平均移动(n-1)/2个元素，O(n)
- **扩容策略**：倍增（x2）或固定增量，倍增的均摊分析为O(1)
- **优缺点**：存取快、插入删除慢、空间固定

### 3. 单链表
- **结点结构**：数据域 + 后继指针域
- **头指针、头结点、首元结点**的区别
- **头插法建表**：逆序建立链表，O(n)
- **尾插法建表**：顺序建立链表（需尾指针），O(n)
- **按位查找**：从头遍历，O(n)
- **插入/删除**：知道前驱结点时O(1)，否则需O(n)定位前驱
- **反转链表（⭐ 必会）**：迭代法（三指针）、递归法

### 4. 双链表
- **结点结构**：前驱指针 + 数据域 + 后继指针
- **优势**：可双向遍历、删除结点时不需要前驱（O(1)）
- **缺点**：多一个指针的开销

### 5. 循环链表
- **循环单链表**：尾结点next指向头结点
- **循环双链表**：头结点的prior指向尾结点
- **应用**：约瑟夫环问题、操作系统进程调度队列

### 6. 静态链表（了解）
- 用数组模拟链表，通过游标（cursor）替代指针
- 用于不支持指针的语言（如早期的FORTRAN）或特定场景（FAT文件系统）

### 7. 核心算法题（LeetCode）
- 反转链表（#206）
- 合并两个有序链表（#21）
- 环形链表检测（#141——快慢指针）
- 删除链表倒数第N个结点（#19）
- 链表的中间结点（#876）
- 相交链表（#160）
- 回文链表（#234）

## ✅ 学习建议
- 手写链表全部基本操作（增删改查），脱离IDE用白板写出正确代码
- 链表的增删操作画图理解，防止指针丢失
- 顺序表vs链表的选择依据：频繁查找用顺序表，频繁增删用链表
