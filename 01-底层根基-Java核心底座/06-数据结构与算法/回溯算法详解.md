## 一、什么是回溯算法

回溯算法（Backtracking Algorithm），又称试探法，是一种在解空间中搜索可行解或最优解的经典算法思想，本质是深度优先搜索（DFS）的延伸，核心是 **"试错-回退-再试"** 的循环过程。它适用于求解组合数较大、需要枚举所有可能解的离散问题，尤其擅长处理约束满足和约束优化类问题，就像在迷宫中探索，尝试一条路径，走不通就退回到上一个分叉口，换另一条路继续尝试，直到找到出口（有效解）或遍历完所有路径（确认无有效解）。

> 简单来说，回溯算法是一种"暴力搜索"的优化版——它不会盲目遍历所有可能，而是在搜索过程中通过**剪枝**操作，提前排除不可能产生有效解的路径，减少无效搜索，从而提升效率。与单纯的暴力枚举相比，回溯的核心优势是"回溯"（撤销选择），能够高效地探索所有潜在解，同时避免重复计算。

## 二、核心思想与本质

回溯算法的核心思想可以概括为：**"选-探-撤"三步循环**，基于深度优先策略遍历解空间树，动态生成解空间并判断路径有效性。

1. **选择**：在当前状态下，从可选列表中选择一个候选元素，加入当前的"路径"（即部分解），记录当前选择的状态。
2. **探索**：基于当前选择，递归向下探索更深层次的路径，继续寻找下一个候选元素，逐步完善部分解。
3. **撤销（回溯）**：如果探索到某一步发现当前路径无法得到有效解（或已找到有效解），就撤销上一步的选择，回退到上一个状态，换另一个候选元素继续尝试，直到遍历完所有可能的选择。

其本质是：在解空间树中，从根节点出发，深度优先遍历所有子树；搜索至任一节点时，先判断该节点是否肯定不包含问题的解，若不包含，则跳过该子树的系统搜索，逐层回溯到祖先节点；若包含，则进入子树继续搜索。当求解所有解时，需回溯到根节点且遍历所有子树才结束；当求解任一解时，找到一个有效解即可终止搜索。

## 三、核心构成与通用步骤

### （一）核心构成

回溯算法的实现通常依赖以下 4 个核心部分，缺一不可：

| 构成 | 说明 |
| :--- | :--- |
| **路径** | 记录当前已经选择的候选元素，即部分解（如组合问题中已选中的数字集合） |
| **可选列表** | 当前状态下可以选择的候选元素，随着回溯过程动态变化 |
| **终止条件** | 判断当前路径是否已构成有效解，若满足则保存解并终止当前递归，开始回溯 |
| **剪枝条件** | 提前判断当前路径是否不可能构成有效解，若满足则直接跳过该路径，避免无效递归，提升效率 |

### （二）通用步骤

无论何种回溯问题，都可按照以下通用步骤实现，适配绝大多数场景：

1. **定义解空间**：明确问题的所有可能解的集合，通常以树或图的形式组织（即解空间树），解空间树分为子集树（适用于子集类问题）和排列树（适用于排列类问题）。
2. **确定解空间结构**：组织解空间的形式，确保能通过深度优先策略方便地遍历整个解空间。
3. **递归回溯**：
   - 判断终止条件：若当前路径是有效解，保存解并返回
   - 遍历可选列表：依次选择每个候选元素，加入路径
   - 剪枝优化：若当前路径不符合剪枝条件，递归探索下一层
   - 撤销选择：递归返回后，撤销当前选择，恢复状态，继续遍历下一个候选元素
4. **遍历结束**：所有路径探索完毕，返回所有有效解（或最优解）。

## 四、适用场景

回溯算法主要适用于需要枚举所有可能解的场景，尤其适合组合数较大、存在约束条件的问题，常见应用场景分为以下 4 类：

| 类别 | 说明 | 典型问题 |
| :--- | :--- | :--- |
| **组合/子集类问题** | 从给定元素中选取部分元素，不考虑顺序 | 组合、子集、组合总和 |
| **排列类问题** | 从给定元素中选取所有元素，考虑顺序 | 全排列、电话号码字母组合 |
| **约束满足问题** | 解需要满足一系列约束条件 | N 皇后、数独求解 |
| **路径/分割类问题** | 在图或字符串中寻找满足条件的路径或分割方式 | 迷宫寻路、分割回文串、复原 IP 地址 |

## 五、经典实例（附代码实现）

以下选取 3 个最具代表性的回溯问题，提供 Java 代码实现，清晰展示"选-探-撤"的核心逻辑，同时体现剪枝优化思路。

### 实例 1：组合问题（LeetCode 77. 组合）

**题目**：给定两个整数 n 和 k，返回 1 ~ n 中所有可能的 k 个数的组合。

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    // 存储所有有效解
    private List<List<Integer>> result = new ArrayList<>();
    // 存储当前路径（部分解）
    private List<Integer> path = new ArrayList<>();

    public List<List<Integer>> combine(int n, int k) {
        backtrack(n, k, 1);
        return result;
    }

    // start控制起点，避免重复组合
    private void backtrack(int n, int k, int start) {
        // 终止条件：路径长度等于k，保存解
        if (path.size() == k) {
            result.add(new ArrayList<>(path));
            return;
        }
        // 遍历可选列表，剪枝：剩余元素不足k-path.size()个时，直接退出
        for (int i = start; i <= n - (k - path.size()) + 1; i++) {
            // 选：将当前元素加入路径
            path.add(i);
            // 探：递归探索下一层，起点设为i+1（避免重复）
            backtrack(n, k, i + 1);
            // 撤：回溯，撤销当前选择
            path.remove(path.size() - 1);
        }
    }
}
```

> **说明**：通过 `start` 参数控制选择起点，避免生成重复组合；通过 `n - (k - path.size()) + 1` 剪枝，减少无效遍历，提升效率。

### 实例 2：全排列问题（LeetCode 46. 全排列）

**题目**：给定一个不含重复数字的数组 nums，返回其所有可能的全排列。

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    // 存储所有有效解
    private List<List<Integer>> result = new ArrayList<>();
    // 存储当前路径（部分解）
    private List<Integer> path = new ArrayList<>();
    // 标记元素是否已被选择，避免重复选择
    private boolean[] used;

    public List<List<Integer>> permute(int[] nums) {
        used = new boolean[nums.length];
        backtrack(nums);
        return result;
    }

    private void backtrack(int[] nums) {
        // 终止条件：路径长度等于数组长度，保存解
        if (path.size() == nums.length) {
            result.add(new ArrayList<>(path));
            return;
        }
        // 遍历所有元素（可选列表为未被选中的元素）
        for (int i = 0; i < nums.length; i++) {
            if (used[i]) { // 剪枝：跳过已被选择的元素
                continue;
            }
            // 选：标记元素为已使用，加入路径
            used[i] = true;
            path.add(nums[i]);
            // 探：递归探索下一层
            backtrack(nums);
            // 撤：回溯，撤销当前选择，恢复状态
            path.remove(path.size() - 1);
            used[i] = false;
        }
    }
}
```

> **说明**：通过 `used` 数组标记元素是否已被选择，避免同一排列中重复使用元素，严格遵循"选-探-撤"逻辑。

### 实例 3：分割回文串（LeetCode 131. 分割回文串）

**题目**：给你一个字符串 s，请你将 s 分割成一些子串，使每个子串都是回文串，返回所有可能的分割方案。

**核心思路**：将字符串分割问题转化为回溯问题，路径为当前已分割的回文子串，可选列表为当前位置开始的所有可能子串，终止条件为分割到字符串末尾，剪枝条件为当前子串不是回文串时，直接跳过该路径。

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    // 存储所有有效分割方案
    private List<List<String>> result = new ArrayList<>();
    // 存储当前分割路径（已分割的回文子串）
    private List<String> path = new ArrayList<>();

    public List<List<String>> partition(String s) {
        backtrack(s, 0);
        return result;
    }

    // start表示当前分割的起始位置，避免重复分割
    private void backtrack(String s, int start) {
        // 终止条件：分割到字符串末尾，保存当前分割方案
        if (start == s.length()) {
            result.add(new ArrayList<>(path));
            return;
        }
        // 遍历可选列表：从start位置开始，尝试所有可能的子串
        for (int i = start; i < s.length(); i++) {
            // 剪枝：判断当前子串（start到i）是否为回文串，不是则跳过
            if (isPalindrome(s, start, i)) {
                // 选：将当前回文子串加入路径
                path.add(s.substring(start, i + 1));
                // 探：递归探索下一层，起始位置设为i+1（避免重复分割）
                backtrack(s, i + 1);
                // 撤：回溯，撤销当前选择
                path.remove(path.size() - 1);
            }
        }
    }

    // 辅助方法：判断字符串s从left到right的子串是否为回文串
    private boolean isPalindrome(String s, int left, int right) {
        while (left < right) {
            if (s.charAt(left) != s.charAt(right)) {
                return false;
            }
            left++;
            right--;
        }
        return true;
    }
}
```

> **说明**：该实例是回溯算法在分割类问题中的典型应用，核心剪枝操作是"判断子串是否为回文串"，提前排除非回文子串的路径，减少无效递归；`start` 参数控制分割起始位置，避免重复分割同一部分，确保所有分割方案不重复、不遗漏。

## 六、回溯算法的优缺点

### （一）优点

| 优点 | 说明 |
| :--- | :--- |
| **思路简洁直观** | 核心是"选-探-撤"三步，适配各类枚举类问题，代码实现有固定模板，易于理解和编写 |
| **灵活性强** | 可通过剪枝操作灵活优化，根据问题约束条件调整剪枝逻辑，平衡效率和正确性 |
| **适用性广** | 可解决组合、排列、分割、约束满足等多种类型问题，尤其适合解空间较大但存在明显约束的场景 |

### （二）缺点

| 缺点 | 说明 |
| :--- | :--- |
| **时间复杂度高** | 本质是深度优先搜索，最坏情况下需遍历所有解空间，时间复杂度通常为 O(n!) 或 O(2^n)，不适用于解空间极大的场景 |
| **空间复杂度高** | 递归调用会占用栈空间，同时需要存储路径和有效解，空间复杂度通常为 O(n)（递归深度） |

---

## 七、总结

回溯算法的核心是 **"试错-回退"**，通过 **"选-探-撤"** 的循环遍历解空间，结合剪枝操作优化搜索效率，是解决枚举类、约束满足类问题的核心算法之一。其核心价值在于，用直观的思路解决复杂的枚举问题，即使时间复杂度较高，在解空间可控的场景下，仍是最优选择。

> 掌握回溯算法的关键是：明确 **路径、可选列表、终止条件、剪枝条件** 四大核心，熟记通用模板，结合具体问题调整剪枝逻辑和递归参数（如组合问题的 `start` 参数、排列问题的 `used` 数组）。通过练习组合、排列、分割等经典实例，可快速掌握其应用技巧，应对各类回溯相关问题。
