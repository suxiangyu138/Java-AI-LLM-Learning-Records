## 树的基础概念

### 1. 定义

树是 n (n ≥ 0) 个节点的有限集合：

- n = 0 为空树
- n > 0 时存在唯一根节点
- 子树互不相交，呈**层级结构**

### 2. 核心术语

| 术语 | 说明 |
|------|------|
| **根节点** | 顶层节点，没有父节点 |
| **父节点/子节点** | 直接关联的上下层节点 |
| **叶子节点** | 没有子节点的节点 |
| **深度** | 根到该节点的路径长度 |
| **高度** | 该节点到最远叶子节点的路径长度 |
| **度** | 节点的子节点数量 |

### 3. 存储结构

| 存储方式 | 适用场景 | 说明 |
|----------|----------|------|
| 顺序存储（数组） | 完全二叉树 | 紧凑，索引关系计算子节点 |
| 链式存储（指针） | 通用二叉树 | 左右孩子指针，灵活通用 |

```
        树结构示例：
              根节点 (深度0)
             /         \
         子节点        子节点 (深度1)
         /    \            \
      叶子    子节点       叶子 (深度2)
               /
            叶子 (深度3)
```

## 二叉树（核心）

### 1. 定义

每个节点**最多**有两个子节点（左子节点、右子节点）。

### 2. 特殊二叉树

| 类型 | 特点 | 示意图 |
|------|------|--------|
| **满二叉树** | 每层节点全满 | 每层完全填满 |
| **完全二叉树** | 除最后一层外全满，最后一层靠左 | 堆的实现基础 |
| **平衡二叉树（AVL）** | 左右子树高度差 ≤ 1 | 自动旋转保持平衡 |
| **二叉搜索树（BST）** | 左 < 根 < 右 | 中序有序 |

### 3. 遍历方式（高频考点）

| 遍历方式 | 顺序 | 实现方式 | 典型应用 |
|----------|------|----------|----------|
| **前序** | 根 → 左 → 右 | 递归/栈 | 序列化树、表达式树 |
| **中序** | 左 → 根 → 右 | 递归/栈 | BST 排序输出 |
| **后序** | 左 → 右 → 根 | 递归/栈 | 删除树、计算表达式 |
| **层序** | 按层级从上到下 | 队列（BFS） | 最短路径、层级打印 |

## Java 实现（二叉树）

### 节点定义

```java
class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;

    TreeNode(int val) {
        this.val = val;
    }
}
```

### 前序遍历（递归）

```java
public void preOrder(TreeNode root) {
    if (root == null) return;
    System.out.print(root.val + " ");
    preOrder(root.left);
    preOrder(root.right);
}
```

### 层序遍历（BFS + 队列）

```java
public void levelOrder(TreeNode root) {
    if (root == null) return;
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        TreeNode node = queue.poll();
        System.out.print(node.val + " ");
        if (node.left != null) queue.offer(node.left);
        if (node.right != null) queue.offer(node.right);
    }
}
```

## 高级树结构（Java 后端重点）

### 1. 二叉搜索树（BST）

| 特性 | 说明 |
|------|------|
| **规则** | 左子树所有节点 < 根节点 < 右子树所有节点 |
| **中序** | 中序遍历得到**升序序列** |
| **操作复杂度** | 插入、查找、删除均为 O(h)，h 为树高 |
| **缺点** | 极端情况退化为链表，O(n) |

### 2. 平衡二叉树（AVL）

| 特性 | 说明 |
|------|------|
| **平衡条件** | 任意节点左右子树高度差 ≤ 1 |
| **平衡手段** | 左旋、右旋、双旋 |
| **复杂度** | 所有操作 O(log n) |
| **缺点** | 插入/删除需要频繁旋转，开销大 |

### 3. 红黑树（Java 核心）

> 红黑树是 Java 集合框架的基石，广泛应用于 `TreeMap`、`TreeSet`、`HashMap`（JDK 8+）。它通过**染色**和**旋转**维持弱平衡，插入删除效率高于 AVL。

**5 条核心规则：**

1. 每个节点是红色或黑色
2. 根节点是黑色
3. 叶子节点（NIL）是黑色
4. 红色节点的子节点必须是黑色（不能有连续红节点）
5. 任意节点到其叶子节点的路径上，黑色节点数量相同

**应用：**

| Java 集合 | 底层结构 |
|-----------|----------|
| `TreeMap` | 红黑树 |
| `TreeSet` | 红黑树（基于 TreeMap） |
| `HashMap`（JDK 8+） | 数组 + 链表/红黑树 |

### 4. B 树 / B+ 树（数据库核心）

| 类型 | 特点 | 应用 |
|------|------|------|
| **B 树** | 多路平衡搜索树，减少磁盘 IO | MySQL MyISAM 索引 |
| **B+ 树** | 叶子节点链表连接，范围查询高效 | MySQL InnoDB 索引 |

> B+ 树相比 B 树的优势：**叶子节点形成有序链表**，范围查询只需遍历叶子节点即可，无需回溯。

## Java 后端实战场景

### 1. 数据存储

| 场景 | 使用的树结构 |
|------|-------------|
| 有序存储 | `TreeMap` / `TreeSet`（红黑树） |
| 哈希冲突优化 | `HashMap` 红黑树优化长链表 |

### 2. 数据库索引

| 数据库引擎 | 索引结构 |
|-----------|----------|
| InnoDB | B+ 树聚簇索引 |
| MyISAM | B 树非聚簇索引 |

### 3. 算法应用

| 算法 | 树结构 |
|------|--------|
| 堆排序 | 完全二叉树（堆） |
| 哈夫曼编码 | 最优二叉树（哈夫曼树） |
| 最近公共祖先（LCA） | 二叉树 |

## 复杂度分析

| 树结构 | 查找 | 插入 | 删除 | 遍历 |
|--------|------|------|------|------|
| 二叉树遍历 | — | — | — | O(n) |
| BST | O(h) | O(h) | O(h) | O(n) |
| AVL 树 | O(log n) | O(log n) | O(log n) | O(n) |
| 红黑树 | O(log n) | O(log n) | O(log n) | O(n) |
| B+ 树 | O(log n) | O(log n) | O(log n) | O(n) |

> h 为树的高度，极端情况下 BST 的 h = n；平衡树保证 h ≈ log n。

## 总结

1. **树**是层级数据结构的核心，**二叉树**是所有高级树结构的基础
2. **红黑树**和 **B+树**是 Java 后端的关键技术，广泛应用于集合框架和数据库索引
3. 掌握树结构能够有效提升**后端性能优化**能力与**面试竞争力**
