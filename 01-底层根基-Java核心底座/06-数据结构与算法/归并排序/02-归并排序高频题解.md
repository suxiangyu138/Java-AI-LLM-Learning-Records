## 1. 912. 排序数组（三版实现）

### 1.1 题目与思路

```
数组排序（归并版本）——排序题的标准练手
三版递进：
  版一 递归归并（直观）
  版二 迭代归并（无递归栈）
  版三 递归 + 小规模插入优化（工程版）
```

### 1.2 三版代码

```java
/** 版一：递归归并（面试标准答案） */
public int[] sortArray(int[] nums) {
    mergeSort(nums, 0, nums.length - 1, new int[nums.length]);
    return nums;
}
private void mergeSort(int[] nums, int lo, int hi, int[] tmp) {
    if (lo >= hi) return;
    int mid = lo + (hi - lo) / 2;
    mergeSort(nums, lo, mid, tmp);
    mergeSort(nums, mid + 1, hi, tmp);
    merge(nums, lo, mid, hi, tmp);
}

/** 版二：迭代归并（块长翻倍） */
public int[] sortArrayIter(int[] nums) {
    int n = nums.length;
    int[] tmp = new int[n];
    for (int len = 1; len < n; len <<= 1) {
        for (int lo = 0; lo < n; lo += len * 2) {
            int mid = Math.min(lo + len - 1, n - 1);
            int hi = Math.min(lo + len * 2 - 1, n - 1);
            if (mid < hi) merge(nums, lo, mid, hi, tmp);
        }
    }
    return nums;
}

/** 版三：递归 + 小规模插入（工程优化） */
private static final int THRESHOLD = 16;
private void mergeSortOpt(int[] nums, int lo, int hi, int[] tmp) {
    if (hi - lo <= THRESHOLD) {                    // ⚠️ 小段转插入排序
        insertionSort(nums, lo, hi);
        return;
    }
    int mid = lo + (hi - lo) / 2;
    mergeSortOpt(nums, lo, mid, tmp);
    mergeSortOpt(nums, mid + 1, hi, tmp);
    if (nums[mid] <= nums[mid + 1]) return;        // ⚠️ 已有序跳过合并
    merge(nums, lo, mid, hi, tmp);
}

// 共用的 merge：
private void merge(int[] nums, int lo, int mid, int hi, int[] tmp) {
    int i = lo, j = mid + 1, k = lo;
    while (i <= mid && j <= hi) {
        if (nums[i] <= nums[j]) tmp[k++] = nums[i++];
        else                    tmp[k++] = nums[j++];
    }
    while (i <= mid) tmp[k++] = nums[i++];
    while (j <= hi)  tmp[k++] = nums[j++];
    System.arraycopy(tmp, lo, nums, lo, hi - lo + 1);
}
// ⚠️ 面试表达："版三是 TimSort 的思想雏形——
//   小段用插入、有序段跳过、共享辅助数组。"
```

## 2. 88. 合并两个有序数组

### 2.1 题目与思路

```
nums1 长度 m+n（尾部预留 n 个 0），把 nums2 合并进 nums1（原地）
⚠️ 关键：从尾部向前合并——避免覆盖 nums1 前部未处理元素
```

### 2.2 完整代码

```java
/**
 * LeetCode 88. 合并两个有序数组（尾部合并）
 */
public void merge(int[] nums1, int m, int[] nums2, int n) {
    int i = m - 1, j = n - 1, k = m + n - 1;
    while (i >= 0 && j >= 0) {
        if (nums1[i] > nums2[j]) nums1[k--] = nums1[i--];   // ⚠️ 取大放尾部
        else                     nums1[k--] = nums2[j--];
    }
    while (j >= 0) nums1[k--] = nums2[j--];    // ⚠️ 只需处理 nums2 剩余
    // nums1 剩余元素天然已在正确位置（原位）
}
// 推演 nums1=[1,2,3,0,0,0] m=3, nums2=[2,5,6]：
//   i=2(3) vs j=2(6) → 尾 6；3 vs 5 → 5；3 vs 2 → 3
//   2 vs 2 → 2（nums2）；1 vs 2 → 2；nums2 剩 1？不——j=0(2) 已取
//   最后 j=-1 → nums1 的 1 原位 ✓ → [1,2,2,3,5,6] ✓
// ⚠️ 记忆：两指针倒着走，谁大放谁，nums2 剩余全拷
```

## 3. 21. 合并两个有序链表

### 3.1 题目与思路

```
递归版（简洁）与迭代版（空间 O(1)）双解
⚠️ 这是归并排序的"原子操作"——merge 的链表形态
```

### 3.2 双解法

```java
/** 递归版：选小头 + 递归合并剩余 */
public ListNode mergeTwoLists(ListNode l1, ListNode l2) {
    if (l1 == null) return l2;
    if (l2 == null) return l1;
    if (l1.val <= l2.val) {
        l1.next = mergeTwoLists(l1.next, l2);
        return l1;
    } else {
        l2.next = mergeTwoLists(l1, l2.next);
        return l2;
    }
}

/** 迭代版：哨兵 + 尾插（空间 O(1)） */
public ListNode mergeTwoListsIter(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(0), tail = dummy;
    while (l1 != null && l2 != null) {
        if (l1.val <= l2.val) { tail.next = l1; l1 = l1.next; }
        else                  { tail.next = l2; l2 = l2.next; }
        tail = tail.next;
    }
    tail.next = (l1 != null) ? l1 : l2;          // ⚠️ 接上剩余
    return dummy.next;
}
// ⚠️ 递归版空间 O(m+n)（调用栈）；迭代版 O(1) —— 面试两版都要会
```

## 4. 23. 合并 K 个升序链表

### 4.1 题目与思路

```
K 个有序链表 → 一个有序链表
两种归并思路：
  ① 分治两两合并：mergeKLists 递归对半 → 每层总 O(N)，log K 层 → O(N log K)
  ② 堆（多路归并）：K 个头入堆 → 弹出最小补位 → O(N log K)
⚠️ 对比：分治空间 O(log K)；堆空间 O(K)。K 大时堆占内存多
```

### 4.2 双解法

```java
/** 解法一：分治两两合并（复用 21） */
public ListNode mergeKLists(ListNode[] lists) {
    if (lists == null || lists.length == 0) return null;
    return mergeRange(lists, 0, lists.length - 1);
}
private ListNode mergeRange(ListNode[] lists, int lo, int hi) {
    if (lo == hi) return lists[lo];
    int mid = lo + (hi - lo) / 2;
    ListNode left = mergeRange(lists, lo, mid);
    ListNode right = mergeRange(lists, mid + 1, hi);
    return mergeTwoLists(left, right);          // 21 题模板
}
// 复杂度：O(N log K)，空间 O(log K)

/** 解法二：堆（多路归并） */
public ListNode mergeKListsHeap(ListNode[] lists) {
    PriorityQueue<ListNode> heap = new PriorityQueue<>((a, b) -> a.val - b.val);
    for (ListNode h : lists)
        if (h != null) heap.offer(h);           // ① K 个头入堆

    ListNode dummy = new ListNode(0), tail = dummy;
    while (!heap.isEmpty()) {
        ListNode node = heap.poll();            // ② 弹最小
        tail.next = node;
        tail = node;
        if (node.next != null) heap.offer(node.next);   // ③ 补位
    }
    return dummy.next;
}
// 复杂度：O(N log K)，空间 O(K)
// ⚠️ 面试表达："K 路归并两种实现——分治两两合并在
//   归并框架内自然发生；堆版是'取最小补位'的
//   多路归并。大数据量 K 很大时注意堆空间 O(K)。"
```

## 5. 剑指 51. 数组中的逆序对

### 5.1 题目与思路

```
求逆序对总数（i < j 且 a[i] > a[j]）
归并计数：合并时右块元素被取走 → 左块剩余全部大于它 → 批量计数
⚠️ 排序与统计一举两得：排序保证批量计数的正确性
```

### 5.2 完整推导代码

```java
/**
 * 剑指 Offer 51. 数组中的逆序对
 * ⚠️ 计数发生在"右块取走"时刻：count += mid - i + 1
 */
int count = 0;

public int reversePairs(int[] nums) {
    mergeSort(nums, 0, nums.length - 1, new int[nums.length]);
    return count;
}

private void mergeSort(int[] nums, int lo, int hi, int[] tmp) {
    if (lo >= hi) return;
    int mid = lo + (hi - lo) / 2;
    mergeSort(nums, lo, mid, tmp);
    mergeSort(nums, mid + 1, hi, tmp);

    int i = lo, j = mid + 1, k = lo;
    while (i <= mid && j <= hi) {
        if (nums[i] <= nums[j]) {
            tmp[k++] = nums[i++];               // 左块归位：无逆序
        } else {
            // ⭐ 右块元素 nums[j] 小于左块剩余 [i..mid] 全部
            count += mid - i + 1;               // 批量计数
            tmp[k++] = nums[j++];
        }
    }
    while (i <= mid) tmp[k++] = nums[i++];
    while (j <= hi)  tmp[k++] = nums[j++];
    System.arraycopy(tmp, lo, nums, lo, hi - lo + 1);
}
// 推演 [7,5,6,4]：
//   merge(7,5)：5 取走，i=0 → count += 1
//   merge(6,4)：count += 1
//   merge(5,7,4,6)：4 取走，i=0 → += 2；6 取走，i=1 → += 1
//   总 5 ✓（(7,5)(7,6)(7,4)(5,4)(6,4)）
// ⚠️ 为什么"批量"正确：左块已有序 → 剩余全 > nums[j] → 一次加完
```

## 6. 148. 排序链表

### 6.1 题目与思路

```
链表排序 O(n log n) → 归并是唯一自然解（快排需随机访问）
递归版：快慢指针拆半 + 递归排序 + 21 合并
⚠️ 空间 O(log n)（无辅助数组，链表合并原地改指针）
```

### 6.2 完整代码

```java
/**
 * LeetCode 148. 排序链表
 */
public ListNode sortList(ListNode head) {
    if (head == null || head.next == null) return head;   // 基线

    // ① 快慢指针找中点（slow 停在前半末尾）
    ListNode slow = head, fast = head.next;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    ListNode right = slow.next;
    slow.next = null;                            // ⚠️ 断开

    // ② 递归排序两半
    ListNode left = sortList(head);
    right = sortList(right);

    // ③ 合并（21 迭代版，O(1) 空间）
    ListNode dummy = new ListNode(0), tail = dummy;
    while (left != null && right != null) {
        if (left.val <= right.val) { tail.next = left; left = left.next; }
        else                       { tail.next = right; right = right.next; }
        tail = tail.next;
    }
    tail.next = (left != null) ? left : right;
    return dummy.next;
}
// 复杂度：O(n log n)，空间 O(log n)
// ⚠️ 对比数组归并：数组 O(n) 空间（辅助数组），链表 O(log n)（仅递归栈）
// ⚠️ 面试变体追问："快慢指针为什么 fast 从头节点的 next 开始？"
//   —— 保证 slow 停在"中点偏左"（偶数长度时左半末尾）
```

## 8. 归并解题方法论

### 8.1 归并三问框架

```
① 需要排序吗？——归并的基础能力（912/148）
  不需要排序也要"借排序"（逆序对/统计）
② 需要稳定吗？——相等取左（<=）即可
③ 需要计数吗？——合并时挂钩子（取走右块时批量计数）

⚠️ 识别信号：
  "合并两个有序结构" → 88/21/23
  "统计跨左右的关系" → 逆序对家族
  "链表排序" → 148
```

### 8.2 复杂度速答

```
时间：每层合并 O(n) × log n 层 = O(n log n)
空间：数组 O(n)（辅助数组）；链表 O(log n)（递归栈）
稳定：是（相等取左）
表达："T(n) = 2T(n/2) + O(n) → 主定理情形二 → O(n log n)"
```

### 8.3 自测清单

```
□ 合并时用 <=（保持稳定）？
□ 迭代版 min 边界正确？
□ 辅助数组全程复用（不每层新建）？
□ 计数在正确时机（右块取走 / 合并前双指针）？
□ 链表断开两半（slow.next = null）？
□ 88 题从尾部合并（防覆盖）？
```
