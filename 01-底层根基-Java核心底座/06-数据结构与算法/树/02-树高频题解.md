## 1. 104. 二叉树的最大深度

### 1.1 完整实现（后序 + BFS）

```java
/**
 * LeetCode 104. 二叉树的最大深度（树题第一题）
 * 后序：深度 = max(左深度, 右深度) + 1
 */
public int maxDepth(TreeNode root) {
    if (root == null) return 0;
    int left = maxDepth(root.left);
    int right = maxDepth(root.right);
    return Math.max(left, right) + 1;   // 合并答案
}

// BFS 版：层数 = 深度
public int maxDepth_BFS(TreeNode root) {
    if (root == null) return 0;
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    int depth = 0;
    while (!queue.isEmpty()) {
        int size = queue.size();
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        depth++;
    }
    return depth;
}
// 后序 O(n)/O(h)；BFS O(n)/O(w)（w = 最大层宽）
// ⚠️ 面试追问："深度 vs 高度？"
//   深度自顶向下（根 0），高度自底向上（叶 0）
```

## 2. 102. 二叉树的层序遍历

### 2.1 完整实现

```java
/**
 * LeetCode 102. 二叉树的层序遍历（BFS 模板题）
 * size 分层：每轮先固定本层节点数
 */
public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> result = new ArrayList<>();
    if (root == null) return result;

    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);

    while (!queue.isEmpty()) {
        int levelSize = queue.size();      // ⚠️ 固定本层！
        List<Integer> level = new ArrayList<>();

        for (int i = 0; i < levelSize; i++) {
            TreeNode node = queue.poll();
            level.add(node.val);
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        result.add(level);
    }
    return result;
}
// ⚠️ 为什么必须固定 size？
//   不固定 → 本层与下层的节点混在一起
//   固定后：处理完 size 个 → 恰好本层结束
```

public List<Integer> rightSideView(TreeNode root) {

    if (root == null) return result;
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        int size = queue.size();
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            if (i == size - 1) result.add(node.val);  // ⚠️ 最后一个
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
    }
    return result;
}
// ⚠️ 记忆："右视图 = 每层最后一个（i == size-1）"

## 3. 226. 翻转二叉树

### 3.1 完整实现（递归 + 迭代）

```java
/**
 * LeetCode 226. 翻转二叉树（Homebrew 作者面试名场面）
 * 递归：交换左右，再递归翻转子树
 */
public TreeNode invertTree(TreeNode root) {
    if (root == null) return null;
    TreeNode temp = root.left;       // 交换左右
    root.left = root.right;
    root.right = temp;
    invertTree(root.left);           // 递归翻转
    invertTree(root.right);
    return root;
}

// 迭代版（BFS）：
public TreeNode invertTree_BFS(TreeNode root) {
    if (root == null) return null;
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        TreeNode node = queue.poll();
        TreeNode temp = node.left;   // 交换
        node.left = node.right;
        node.right = temp;
        if (node.left != null) queue.offer(node.left);
        if (node.right != null) queue.offer(node.right);
    }
    return root;
}
// ⚠️ 面试追问："递归 vs 迭代？"
//   递归简洁 O(h) 空间；迭代 BFS O(w) 空间
```

## 4. 98. 验证二叉搜索树

### 4.1 完整实现（区间约束 + 中序）

```java
/**
 * LeetCode 98. 验证二叉搜索树
 * ⚠️ 只比较左右孩子是不够的！
 *   （左孩子的右子树里可能有大于根的值）
 *   → 必须区间约束或中序递增
 */
public boolean isValidBST(TreeNode root) {
    return validate(root, null, null);
}

private boolean validate(TreeNode node, Integer lo, Integer hi) {
    if (node == null) return true;

    if (lo != null && node.val <= lo) return false;   // 超下界
    if (hi != null && node.val >= hi) return false;   // 超上界

    return validate(node.left, lo, node.val)     // 左：上界收紧
        && validate(node.right, node.val, hi);   // 右：下界收紧
}
// 反例：5→1→4→3→6
//   只比孩子：1<5<4 误判合法
//   区间法：3 在根 5 的右子树 → 必须 > 5 → 捕获 ✓
// ⚠️ 为什么必须严格？
//   BST 定义：左 < 根 < 右（不含相等）
//   ⚠️ int 边界：用 null 表示无穷（不用 MAX/MIN）
```

### 4.2 中序递增版

```java
/**
 * 中序版：BST 中序必须严格递增
 */
public boolean isValidBST_Inorder(TreeNode root) {
    List<Integer> list = new ArrayList<>();
    inorder(root, list);
    for (int i = 1; i < list.size(); i++) {
        if (list.get(i) <= list.get(i - 1)) return false;  // ⚠️ 严格
    }
    return true;
}

private void inorder(TreeNode node, List<Integer> list) {
    if (node == null) return;
    inorder(node.left, list);
    list.add(node.val);
    inorder(node.right, list);
}
// 面试两种解法都能讲 = 加分
// ⚠️ 记忆："BST 验证 = 中序递增 或 区间约束"
```

## 5. 236. 二叉树的最近公共祖先

### 5.1 完整实现（后序三情况）

```java
/**
 * LeetCode 236. 二叉树的最近公共祖先
 * 后序三情况：
 *   ① root 是 p 或 q → root 就是 LCA
 *   ② p、q 分居左右 → root 就是 LCA
 *   ③ p、q 都在一侧 → 返回那侧找到的节点
 */
public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    if (root == null || root == p || root == q) {
        return root;                 // ① 找到 p/q 或空
    }

    TreeNode left = lowestCommonAncestor(root.left, p, q);
    TreeNode right = lowestCommonAncestor(root.right, p, q);

    if (left != null && right != null) {
        return root;                 // ② 分居两侧 → 当前是 LCA
    }
    return left != null ? left : right;  // ③ 都在一侧
}
// 推演：p=5, q=1（在 3 的两侧）：
//   左子树找到 5，右子树找到 1 → 两侧都非空 → 返回 3 ✓
// 推演：p=5, q=4（都在 5 的子树）：
//   5 的左右两侧都找到 → 返回 5 ✓
// ⚠️ 复杂度 O(n)：每个节点访问一次
// ⚠️ 变体：235 BST 的 LCA（利用有序 O(h)）
```

## 6. 543. 二叉树的直径

### 6.1 完整实现（有状态模式）

```java
/**
 * LeetCode 543. 二叉树的直径
 * 任意两节点间最长路径（可能不经过根！）
 *
 * 有状态模式：
 *   函数返回"单边高度"（给父节点用）
 *   外部变量记录"左+右"最大值（全局答案）
 */
public int diameterOfBinaryTree(TreeNode root) {
    int[] diameter = new int[1];          // ⚠️ 外部变量
    height(root, diameter);
    return diameter[0];
}

private int height(TreeNode node, int[] diameter) {
    if (node == null) return 0;

    int left = height(node.left, diameter);
    int right = height(node.right, diameter);

    diameter[0] = Math.max(diameter[0], left + right);   // 全局更新

    return Math.max(left, right) + 1;    // 返回给父节点
}
// 推演 [1,2,3,4,5]：
//   经过 2 的路径：1+1=2（4-2-5）
//   经过 1 的路径：2+1=3（4-2-1-3）
//   答案 3 ✓
// ⚠️ 为什么必须外部变量？
//   直径可能不经过根 → 单一返回值无法表达
//   "返回值 = 子树信息；外部 = 全局比较"
```

## 7. 124. 二叉树中的最大路径和

### 7.1 完整实现（Hard 经典）

```java
/**
 * LeetCode 124. 二叉树中的最大路径和
 * 路径可穿两边（T 字形）或单边（直线形）
 *
 * 核心：
 *   ① 函数返回"单边最大贡献"（负数舍弃 max(0,x)）
 *   ② 全局答案 = 左贡献 + node + 右贡献
 */
public int maxPathSum(TreeNode root) {
    int[] maxSum = new int[]{Integer.MIN_VALUE};
    maxGain(root, maxSum);
    return maxSum[0];
}

private int maxGain(TreeNode node, int[] maxSum) {
    if (node == null) return 0;

    // 负数贡献舍弃（max 0）→ 路径不"倒贴"
    int leftGain = Math.max(0, maxGain(node.left, maxSum));
    int rightGain = Math.max(0, maxGain(node.right, maxSum));

    // 全局路径：可以同时走两边（T 字形）
    maxSum[0] = Math.max(maxSum[0], leftGain + node.val + rightGain);

    // 返回：只能选一边向上（直线形）
    return node.val + Math.max(leftGain, rightGain);
}
// 推演 [-10,9,20,null,null,15,7]：
//   20 的贡献：15+20+7=42（全局）
//   返回 20 的单边：20+15=35
//   根：max(0,9) + (-10) + max(0,35) = 34
//   答案 42 ✓
// ⚠️ 记忆口诀：
//   "后序遍历·左 max(0,left)·右 max(0,right)
//    全局 = 左+中+右；返回 = 中+max(左,右)"
// ⚠️ 初始化 MIN_VALUE：全负数时正确
```

## 8. 105. 从前序与中序遍历序列构造二叉树

### 8.1 完整实现

```java
/**
 * LeetCode 105. 从前序与中序遍历序列构造二叉树
 * 原理：
 *   ① 前序第一个元素 = 根
 *   ② 中序中找根 → 左边是左子树，右边是右子树
 *   ③ 递归构造
 */
public TreeNode buildTree(int[] preorder, int[] inorder) {
    Map<Integer, Integer> idxMap = new HashMap<>();
    for (int i = 0; i < inorder.length; i++) {
        idxMap.put(inorder[i], i);           // ⚠️ 中序值→下标
    }
    return build(preorder, 0, preorder.length - 1,
                 inorder, 0, inorder.length - 1, idxMap);
}

private TreeNode build(int[] pre, int preLo, int preHi,
                       int[] in, int inLo, int inHi,
                       Map<Integer, Integer> idxMap) {
    if (preLo > preHi) return null;

    int rootVal = pre[preLo];                    // 前序第一个 = 根
    TreeNode root = new TreeNode(rootVal);
    int rootIdxIn = idxMap.get(rootVal);         // 中序中根的位置

    int leftSize = rootIdxIn - inLo;             // ⚠️ 左子树大小！

    root.left = build(pre, preLo + 1, preLo + leftSize,
                      in, inLo, rootIdxIn - 1, idxMap);
    root.right = build(pre, preLo + leftSize + 1, preHi,
                       in, rootIdxIn + 1, inHi, idxMap);
    return root;
}
// 推演 pre=[3,9,20,15,7], in=[9,3,15,20,7]：
//   根 3，中序位置 1 → leftSize=1
//   左子树：pre[9], in[9]；右子树：pre[20,15,7], in[15,20,7]
//   → 递归构造 ✓
// ⚠️ 关键：leftSize = rootIdxIn - inLo
//   （中序根左边元素个数 = 左子树大小）
// 复杂度 O(n)：哈希表 O(1) 定位
```

## 9. 297. 二叉树的序列化与反序列化

### 9.1 完整实现（前序 + # 占位）

```java
/**
 * LeetCode 297. 二叉树的序列化与反序列化（Hard）
 * ⚠️ 必须记录空指针（#）：
 *   普通树仅靠一种遍历无法唯一还原！
 *   例：[1,2,3] 有两种形态（2 是左孩子还是右孩子）
 */
public class Codec {

    // 序列化：前序 + # 占位
    public String serialize(TreeNode root) {
        StringBuilder sb = new StringBuilder();
        serializeHelper(root, sb);
        return sb.toString();
    }

    private void serializeHelper(TreeNode node, StringBuilder sb) {
        if (node == null) {
            sb.append("#,");                 // 空节点占位
            return;
        }
        sb.append(node.val).append(',');
        serializeHelper(node.left, sb);
        serializeHelper(node.right, sb);
    }
    // "1,2,#,#,3,4,#,#,5,#,#"

    // 反序列化：队列按顺序消费
    public TreeNode deserialize(String data) {
        Queue<String> queue = new LinkedList<>(
            Arrays.asList(data.split(",")));
        return deserializeHelper(queue);
    }

    private TreeNode deserializeHelper(Queue<String> queue) {
        String val = queue.poll();
        if (val.equals("#")) return null;    // 空节点

        TreeNode node = new TreeNode(Integer.parseInt(val));
        node.left = deserializeHelper(queue);    // 前序顺序：先左后右
        node.right = deserializeHelper(queue);
        return node;
    }
}
// ⚠️ 为什么中序不适合序列化？
//   根的位置随左子树结构偏移 → 无法定位
// ⚠️ 层序序列化也可（同样 # 占位）
```

## 10. 112/113. 路径总和 I & II

### 10.1 112. 路径总和（自顶向下）

```java
/**
 * LeetCode 112. 路径总和
 * 前序自顶向下：目标值逐层递减（减法）
 */
public boolean hasPathSum(TreeNode root, int targetSum) {
    if (root == null) return false;
    if (root.left == null && root.right == null) {
        return root.val == targetSum;    // 叶子判断
    }
    int remain = targetSum - root.val;
    return hasPathSum(root.left, remain)
        || hasPathSum(root.right, remain);
}
// ⚠️ 为什么用减法？
//   前序传参：把"剩余目标"传给子树
//   叶子时剩余 == 0（此处用 root.val == remain 等价）
```

### 10.2 113. 路径总和 II（收集路径）

```java
/**
 * LeetCode 113. 路径总和 II
 * 需要收集路径 → 共享 path + 回溯
 */
public List<List<Integer>> pathSum(TreeNode root, int targetSum) {
    List<List<Integer>> res = new ArrayList<>();
    dfs(root, targetSum, new ArrayList<>(), res);
    return res;
}

private void dfs(TreeNode node, int remain,
                 List<Integer> path, List<List<Integer>> res) {
    if (node == null) return;

    path.add(node.val);                         // 做选择
    if (node.left == null && node.right == null && remain == node.val) {
        res.add(new ArrayList<>(path));         // ⚠️ 拷贝！
    } else {
        dfs(node.left, remain - node.val, path, res);
        dfs(node.right, remain - node.val, path, res);
    }
    path.remove(path.size() - 1);               // ⚠️ 撤销（回溯）
}
// ⚠️ 避坑：共享 path 必须成对 add/remove
//   （否则路径互相污染）
// ⚠️ 与回溯算法的关系：完全一致的模式
```

## 11. 100/101. 相同树与对称树

### 11.1 100. 相同的树（同步遍历）

```java
/**
 * LeetCode 100. 相同的树
 * 同步遍历：两棵树同时走，比较每个对应节点
 */
public boolean isSameTree(TreeNode p, TreeNode q) {
    if (p == null && q == null) return true;    // 都空 → 相同
    if (p == null || q == null) return false;   // 一空 → 不同
    if (p.val != q.val) return false;           // 值不同
    return isSameTree(p.left, q.left)           // 同步递归
        && isSameTree(p.right, q.right);
}
```

### 11.2 101. 对称二叉树（镜像比较）

```java
/**
 * LeetCode 101. 对称二叉树
 * 镜像比较：左的左 vs 右的右；左的右 vs 右的左
 */
public boolean isSymmetric(TreeNode root) {
    return isMirror(root.left, root.right);
}

private boolean isMirror(TreeNode left, TreeNode right) {
    if (left == null && right == null) return true;
    if (left == null || right == null) return false;
    if (left.val != right.val) return false;
    return isMirror(left.left, right.right)     // ⚠️ 镜像位置！
        && isMirror(left.right, right.left);
}
// ⚠️ 与 100 的差异：比较的是"镜像位置"而非"同位置"
// 变体：572 子树（isSameTree 在 root 每个节点上调用）
```

## 12. 230. 二叉搜索树中第 K 小的元素

### 12.1 完整实现（中序计数）

```java
/**
 * LeetCode 230. 二叉搜索树中第 K 小的元素
 * 中序天然有序 → 第 k 个访问到的就是答案
 */
public int kthSmallest(TreeNode root, int k) {
    int[] count = new int[]{0};
    int[] result = new int[1];
    inorder(root, k, count, result);
    return result[0];
}

private void inorder(TreeNode node, int k, int[] count, int[] result) {
    if (node == null || count[0] >= k) return;   // 剪枝

    inorder(node.left, k, count, result);
    if (++count[0] == k) {
        result[0] = node.val;                    // 第 k 个访问到
        return;
    }
    inorder(node.right, k, count, result);
}
// O(k) 时间（剪枝后提前返回）
// ⚠️ 面试追问："频繁查询第 K 小怎么办？"
//   → 节点加"左子树大小"字段 → 搜索 O(log n)
// ⚠️ 变体：迭代版（栈模拟中序，k 次 next）
```

### 13.2 树题解题四步

```
① 模式识别：30 秒判断（后序/前序/层序/中序/同步）

③ 加细节：有状态（int[]）/ 回溯（成对）/ 剪枝

  说模式 → 写模板 → 讲细节 → 推演验证
```
