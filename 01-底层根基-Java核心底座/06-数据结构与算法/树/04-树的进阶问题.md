## 1. 236. 最近公共祖先 LCA

### 1.1 完整实现（后序经典）

```java
/**
 * LeetCode 236. 二叉树的最近公共祖先
 * p 和 q 的最近公共祖先：最深的、同时是 p 和 q 祖先的节点
 *
 * 后序三情况判断（自底向上）：
 *   ① root 是 p 或 q → root 就是 LCA（另一个在它子树中）
 *   ② p、q 分居左右 → root 就是 LCA
 *   ③ p、q 都在一侧 → 返回那侧找到的节点
 */
public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    if (root == null || root == p || root == q) {
        return root;                 // ① 找到 p/q 或空
    }

    TreeNode left = lowestCommonAncestor(root.left, p, q);
    TreeNode right = lowestCommonAncestor(root.right, p, q);

    if (left != null && right != null) {
        return root;                 // ② p、q 分居两侧 → 当前节点是 LCA
    }
    return left != null ? left : right;  // ③ 都在一侧 → 返回那侧结果
}
```

### 1.2 推演示例

```
       3
      / \
     5   1
    / \ / \
   6  2 0  8
     / \
    7   4

p=5, q=1：
  递归返回：左子树找到 5，右子树找到 1 → 两侧都非空 → 返回 3 ✓

p=5, q=4：
  左子树中：5 的子树里找到 5（根=5 直接返回）和 4
  → 5 的左右两侧都有结果 → 返回 5 ✓

p=7, q=4：
  2 的两侧找到 7 和 4 → 返回 2 ✓
```

### 1.3 变体：BST 的 LCA（更简单）

```java
/**
 * LeetCode 235. BST 的最近公共祖先
 * 利用 BST 性质 O(h)：p、q 都小于根 → 去左；都大于 → 去右
 */
public TreeNode lowestCommonAncestorBST(TreeNode root, TreeNode p, TreeNode q) {
    if (root.val > p.val && root.val > q.val) {
        return lowestCommonAncestorBST(root.left, p, q);   // 都在左
    }
    if (root.val < p.val && root.val < q.val) {
        return lowestCommonAncestorBST(root.right, p, q);  // 都在右
    }
    return root;    // 分叉点（一个在左一个在右，或就是自己）= LCA
}
```

## 2. 297. 序列化与反序列化

### 2.1 为什么必须记录空指针？

```
序列化：把树变成字符串（便于存储/传输）
反序列化：从字符串还原树

⚠️ 关键：普通二叉树仅靠前/中/后序任一种遍历无法唯一还原！
  [1,2,3] 可以是：
      1         1
     /           \
    2             2
   /               \
  3                 3
  → 必须用占位符（如 #）标记空节点

中序遍历不适合做序列化：根位置随左子树结构偏移
```

### 2.2 前序序列化实现

```java
/**
 * LeetCode 297. 二叉树的序列化与反序列化（前序法）
 * 序列化："1,2,#,#,3,4,#,#,5,#,#"（# = 空节点）
 * 反序列化：按前序顺序重建，遇到 # 建空节点
 */
public class Codec {

    // 序列化：前序 + # 占位
    public String serialize(TreeNode root) {
        StringBuilder sb = new StringBuilder();
        serializeHelper(root, sb);
        return sb.toString();
    }
    private void serializeHelper(TreeNode node, StringBuilder sb) {
        if (node == null) {
            sb.append("#,");                 // 空节点占位
            return;
        }
        sb.append(node.val).append(',');
        serializeHelper(node.left, sb);
        serializeHelper(node.right, sb);
    }

    // 反序列化：队列按顺序消费
    public TreeNode deserialize(String data) {
        Queue<String> queue = new LinkedList<>(
            Arrays.asList(data.split(",")));
        return deserializeHelper(queue);
    }
    private TreeNode deserializeHelper(Queue<String> queue) {
        String val = queue.poll();
        if (val.equals("#")) return null;    // 空节点
        TreeNode node = new TreeNode(Integer.parseInt(val));
        node.left = deserializeHelper(queue);    // 前序顺序：先左后右
        node.right = deserializeHelper(queue);
        return node;
    }
}
```

## 3. 同步遍历：相同树/对称树/子树

### 3.1 100. 相同的树

```java
/**
 * LeetCode 100. 相同的树
 * 同步遍历：两棵树同时走，比较每个对应节点
 */
public boolean isSameTree(TreeNode p, TreeNode q) {
    if (p == null && q == null) return true;    // 都空 → 相同
    if (p == null || q == null) return false;   // 一空一不空 → 不同
    if (p.val != q.val) return false;           // 值不同 → 不同
    return isSameTree(p.left, q.left)           // 同步递归左右
        && isSameTree(p.right, q.right);
}
```

### 3.2 101. 对称二叉树

```java
/**
 * LeetCode 101. 对称二叉树
 * 核心：比较"左的左"与"右的右"、"左的右"与"右的左"（镜像比较）
 */
public boolean isSymmetric(TreeNode root) {
    return isMirror(root.left, root.right);
}

private boolean isMirror(TreeNode left, TreeNode right) {
    if (left == null && right == null) return true;
    if (left == null || right == null) return false;
    if (left.val != right.val) return false;
    return isMirror(left.left, right.right)     // 镜像位置
        && isMirror(left.right, right.left);
}
```

### 3.3 572. 另一棵树的子树

```java
/**
 * LeetCode 572. 另一棵树的子树
 * 判断 subRoot 是否是 root 的子树
 * 思路：在 root 的每个节点上调用 isSameTree（100 题复用）
 *       + 自身空判断
 */
public boolean isSubtree(TreeNode root, TreeNode subRoot) {
    if (root == null) return false;             // 根空了，不可能有子树
    if (isSameTree(root, subRoot)) return true; // 当前节点开始相同
    return isSubtree(root.left, subRoot)        // 递归检查左子树
        || isSubtree(root.right, subRoot);      // 或右子树
}
```

## 4. 226. 翻转二叉树

### 4.1 递归 + 迭代

```java
/**
 * LeetCode 226. 翻转二叉树（Homebrew 作者面试名场面）
 * 翻转 = 交换每个节点的左右子树
 */
public TreeNode invertTree(TreeNode root) {
    if (root == null) return null;
    // 交换左右
    TreeNode temp = root.left;
    root.left = root.right;
    root.right = temp;
    // 递归翻转左右子树
    invertTree(root.left);
    invertTree(root.right);
    return root;
}

// 迭代版（BFS）
public TreeNode invertTree_BFS(TreeNode root) {
    if (root == null) return null;
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        TreeNode node = queue.poll();
        TreeNode temp = node.left;              // 交换
        node.left = node.right;
        node.right = temp;
        if (node.left != null) queue.offer(node.left);
        if (node.right != null) queue.offer(node.right);
    }
    return root;
}
```

## 5. N 叉树遍历

```java
// N 叉树节点定义
class Node {
    int val;
    List<Node> children;    // 子节点列表（代替 left/right）
}

// 前序（递归）：根 → 遍历所有孩子
public List<Integer> preorder(Node root) {
    List<Integer> res = new ArrayList<>();
    if (root == null) return res;
    res.add(root.val);
    for (Node child : root.children) {
        res.addAll(preorder(child));
    }
    return res;
}

// 层序（BFS）：与二叉树层序几乎相同，孩子全部入队
public List<List<Integer>> levelOrder(Node root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) return res;
    Queue<Node> queue = new LinkedList<>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        int size = queue.size();
        List<Integer> level = new ArrayList<>();
        for (int i = 0; i < size; i++) {
            Node node = queue.poll();
            level.add(node.val);
            queue.addAll(node.children);        // ⚠️ 全部孩子入队
        }
        res.add(level);
    }
    return res;
}
```

> 💡 N 叉树与二叉树唯一区别：`left/right` → `children` 列表。遍历模板几乎不变，把"两个孩子"换成"遍历孩子列表"即可。

## 6. 树与其他数据结构的关系

### 6.1 树家族图谱

```
树
├── 二叉树（最多两个孩子）
│   ├── 二叉搜索树 BST（左<根<右）
│   ├── 平衡树 AVL / 红黑树（保证 log n）
│   ├── 堆（完全二叉树，数组存储）
│   └── 线段树 / 树状数组（区间查询）
├── 多叉树
│   ├── 字典树 Trie（字符串前缀）
│   ├── B 树 / B+ 树（数据库索引）
│   └── N 叉树
└── 图（树 = 无环连通图）
```

### 6.2 树题与其他算法的交汇

| 交汇点 | 典型题 | 说明 |
|------|:---:|------|
| 树 + DP | 337 打家劫舍 III | 树形 DP（见动态规划体系） |
| 树 + 回溯 | 113 路径总和 II | 路径收集（见回溯体系） |
| 树 + BFS | 199 右视图 | 层序遍历（见 BFS 体系） |
| 树 + 栈 | 中序迭代 | 显式栈（见栈体系） |
| 树 + 序列化 | 297 | 字符串处理 |

> 🎯 **核心要点**：树的进阶问题掌握五个关键——**LCA 后序三情况**（分居两侧返回根）、**序列化必须记空指针**（否则无法唯一还原）、**同步遍历**（相同/对称/子树是同一个比较思路）、**N 叉树只是 children 列表**、**树是图/堆/Trie 等结构的基石**。236 和 297 是 Hard 突破的核心，值得反复手写。
