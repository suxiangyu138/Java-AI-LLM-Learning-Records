## 3. 学习路线推荐

### 🟢 路线 A：零基础入门（1 周）
```
01 遍历基础（前/中/后序递归+迭代 + 层序）
→ 104 最大深度 → 226 翻转 → 100 相同树 → 101 对称树
```
- **目标**：三种遍历闭眼能写，递归思维建立
- **题量**：约 10 题

### 🟡 路线 B：面试冲刺（2 周）
```
01 遍历速过 → 02 路径性质全部（8题）
→ 03 BST 专项（6题）→ 04 LCA + 序列化（2题）
→ 05 高频复盘
```
- **目标**：Hot 100 树题全覆盖，80% 题 1 分钟内识别模式
- **题量**：约 25-30 题

### 🔴 路线 C：全面掌握（3 周）
```
完整 01→05 + 每模式 5-8 题 + 同题三解（递归/迭代/Morris）
→ 105/106 构造 + 297 序列化（Hard 突破）
→ 后序自底向上专项（直径/路径和/LCA）
→ 交叉混合复习（锻炼模式识别）
```
- **目标**：任何树题 30 秒内判断属于哪种遍历模式
- **题量**：约 40-50 题

## 4. 核心概念速查

| 概念 | 一句话解释 | 典型例题 |
|------|-----------|------|
| **前序遍历** | 根→左→右，自顶向下传参 | 257 路径、297 序列化 |
| **中序遍历** | 左→根→右，BST 有序输出 | 98 验证 BST、230 第K小 |
| **后序遍历** | 左→右→根，自底向上聚合 | 104 深度、543 直径、236 LCA |
| **层序遍历** | 队列逐层处理 | 102、199 右视图 |
| **自底向上** | 需要子树信息才能决策 | 高度/直径/平衡 |
| **自顶向下** | 信息从根流向叶子 | 路径总和 |
| **无状态 vs 有状态** | 返回值即答案 vs 答案存外部变量 | 树高 vs 直径 |
| **BST 性质** | 左<根<右，中序有序 | 98/700/701 |
| **LCA** | 最近公共祖先 | 236 |
| **序列化** | 需记录空指针占位符 | 297 |
| **Morris** | 利用空指针 O(1) 空间遍历 | 94 中序 |

## 6. 复杂度速查表

| 问题 | 时间复杂度 | 空间复杂度 | 关键技巧 |
|------|:---:|:---:|------|
| 前/中/后序遍历 | O(n) | O(n) 栈/递归 | 三种遍历模板 |
| 中序迭代 | O(n) | O(n) | 左探-回溯-右转 |
| Morris 中序 | O(n) | **O(1)** | 前驱右空指针 |
| 层序遍历 | O(n) | O(n) | 队列 + size 分层 |
| 最大深度 (104) | O(n) | O(h) | 后序 max(left,right)+1 |
| 平衡判断 (110) | O(n) | O(h) | 后序高度返回 -1 标记 |
| 直径 (543) | O(n) | O(h) | 外部变量记录 |
| 最大路径和 (124) | O(n) | O(h) | 全局 + 单边贡献 |
| BST 搜索/插入 | O(h) | O(h) | h=log n（平衡时） |
| BST 删除 (450) | O(h) | O(h) | 三情况分类 |
| LCA (236) | O(n) | O(h) | 后序三情况 |
| 构造 (105) | O(n) | O(n) | 哈希表加速中序定位 |
| 序列化 (297) | O(n) | O(n) | 空指针占位符 |
