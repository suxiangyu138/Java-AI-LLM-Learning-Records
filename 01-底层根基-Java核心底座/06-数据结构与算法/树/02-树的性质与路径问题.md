## 1. 两大模式：自底向上 vs 自顶向下

### 1.1 模式判定

```
自底向上（后序）：
  节点需要左右子树的答案才能决策
  "左右孩子给我答案后，我能合并出自己的答案吗？" → 能
  代表：高度、直径、平衡、最大路径和、LCA

自顶向下（前序）：
  信息从根流向叶子，路径累积
  把状态（当前和、路径字符串）作为递归参数向下传
  代表：路径总和、所有路径、根到叶数字和
```

### 1.2 无状态 vs 有状态（关键区分）

```
无状态：函数的返回值就是答案
  例：树高 —— max(left, right) + 1 直接返回

有状态：函数返回辅助信息，答案存在外部变量
  例：直径 —— 函数返回高度，直径答案记录在外部变量
  原因：直径可能不穿过当前节点，无法用单一返回值表达
```

## 2. 104. 最大深度 / 111. 最小深度

### 2.1 最大深度（后序经典）

```java
/**
 * LeetCode 104. 二叉树的最大深度
 * 后序：深度 = max(左深度, 右深度) + 1
 */
public int maxDepth(TreeNode root) {
    if (root == null) return 0;
    int left = maxDepth(root.left);
    int right = maxDepth(root.right);
    return Math.max(left, right) + 1;   // 合并答案
}

// 层序解法：BFS 统计层数
public int maxDepth_BFS(TreeNode root) {
    if (root == null) return 0;
    Queue<TreeNode> q = new LinkedList<>();
    q.offer(root);
    int depth = 0;
    while (!q.isEmpty()) {
        int size = q.size();
        for (int i = 0; i < size; i++) {
            TreeNode node = q.poll();
            if (node.left != null) q.offer(node.left);
            if (node.right != null) q.offer(node.right);
        }
        depth++;
    }
    return depth;
}
```

### 2.2 最小深度（陷阱题）

```java
/**
 * LeetCode 111. 二叉树的最小深度
 * ⚠️ 陷阱：最小深度是"根到最近叶子节点"的距离！
 *   如果根只有右子树，最小深度不能算 1（根不是叶子）
 */
public int minDepth(TreeNode root) {
    if (root == null) return 0;
    if (root.left == null) return minDepth(root.right) + 1;   // 只有右子树
    if (root.right == null) return minDepth(root.left) + 1;   // 只有左子树
    return Math.min(minDepth(root.left), minDepth(root.right)) + 1;
}
```

> ⚠️ **面试必讲**：最大深度直接 max 没问题，但最小深度必须特判"单子树"情况——直接 min 会把 0（空子树）算进去，答案是错的。这是 111 题的核心考点。

## 3. 110. 平衡二叉树

### 3.1 完整实现（后序 + 剪枝）

```java
/**
 * LeetCode 110. 平衡二叉树
 * 左右子树高度差 ≤ 1 且子树自身也平衡
 *
 * 技巧：函数返回高度，-1 表示"不平衡"（哨兵值）
 *   → 一次后序遍历同时完成"判断平衡 + 计算高度"
 *   → 剪枝：发现不平衡立即返回 -1，不再向上计算
 */
public boolean isBalanced(TreeNode root) {
    return height(root) != -1;
}

private int height(TreeNode root) {
    if (root == null) return 0;

    int left = height(root.left);
    if (left == -1) return -1;          // 剪枝：左子树已不平衡

    int right = height(root.right);
    if (right == -1) return -1;         // 剪枝：右子树已不平衡

    if (Math.abs(left - right) > 1) return -1;  // 本节点不平衡

    return Math.max(left, right) + 1;   // 返回高度
}
```

### 3.2 为什么用 -1 哨兵？

```
朴素解法：isBalanced 里调 height，O(n²)（每层都重算高度）
优化解法：后序一次遍历，同时返回高度和平衡状态
  → 用 -1 哨兵值：正常返回高度 ≥ 0，不平衡返回 -1
  → O(n)，且剪枝提前终止
```

## 4. 543. 二叉树的直径

### 4.1 完整实现（有状态模式）

```java
/**
 * LeetCode 543. 二叉树的直径
 * 直径 = 任意两节点间最长路径的边数（可能不经过根节点！）
 *
 * 有状态模式：
 *   函数返回"以节点为端点向下的最大单边长"（供父节点使用）
 *   直径答案记录在外部变量（可能穿过当前节点左右子树）
 */
public int diameterOfBinaryTree(TreeNode root) {
    int[] diameter = new int[1];          // 外部变量记录答案
    height(root, diameter);
    return diameter[0];
}

private int height(TreeNode node, int[] diameter) {
    if (node == null) return 0;

    int left = height(node.left, diameter);
    int right = height(node.right, diameter);

    // 经过当前节点的路径长度 = 左高 + 右高
    diameter[0] = Math.max(diameter[0], left + right);

    // 返回给父节点的单边高度
    return Math.max(left, right) + 1;
}
// 推演 [1,2,3,4,5]：直径 = 2-1-3 或 4-2-1-3 等，最长 = 3（4-2-1-3）
```

### 4.2 为什么必须用外部变量？

```
直径可能不经过根：
  例：根只有左子树，最长路径全在左子树内部
  函数返回的高度只能表达"经过当前节点的路径"
  全局最优需要对比所有节点 → 外部变量记录最大值

记忆：无状态（高度）直接返回；有状态（直径）外部变量
```

## 5. 124. 二叉树最大路径和

### 5.1 完整实现（Hard 经典）

```java
/**
 * LeetCode 124. 二叉树中的最大路径和（困难经典题）
 * 路径可以穿过根也可以不穿过，可以走一边或两边
 *
 * 核心模型：
 *   ① 函数返回"单边最大贡献"：node + max(0, 左贡献, 右贡献)
 *      （负数贡献直接舍弃，用 max(0, x)）
 *   ② 全局答案 = 左贡献 + node.val + 右贡献（可穿两边）
 */
public int maxPathSum(TreeNode root) {
    int[] maxSum = new int[]{Integer.MIN_VALUE};
    maxGain(root, maxSum);
    return maxSum[0];
}

private int maxGain(TreeNode node, int[] maxSum) {
    if (node == null) return 0;

    // 负数贡献直接舍弃（max 0）→ 保证路径不"倒贴"
    int leftGain = Math.max(0, maxGain(node.left, maxSum));
    int rightGain = Math.max(0, maxGain(node.right, maxSum));

    // 全局路径：可以同时走左右两边（路径穿过当前节点）
    maxSum[0] = Math.max(maxSum[0], leftGain + node.val + rightGain);

    // 返回：只能选一边向上贡献（父节点只能接一条路）
    return node.val + Math.max(leftGain, rightGain);
}
```

### 5.2 记忆口诀

```
"后序遍历·左 max(0,left)·右 max(0,right)
 全局 = 左 + 中 + 右
 返回 = 中 + max(左, 右)"

关键理解：
  全局路径可以走两边（T 字形）
  返回给父节点只能走一边（直线形）
  —— 这是本题最容易想不通的点
```

## 6. 112/113. 路径总和 I & II

### 6.1 路径总和 I（自顶向下 + 减法和）

```java
/**
 * LeetCode 112. 路径总和
 * 是否存在根到叶子的路径，路径和 == targetSum
 *
 * 自顶向下：目标值逐层递减（减法），到叶子判断是否归零
 */
public boolean hasPathSum(TreeNode root, int targetSum) {
    if (root == null) return false;
    if (root.left == null && root.right == null) {   // 叶子
        return root.val == targetSum;
    }
    int remain = targetSum - root.val;
    return hasPathSum(root.left, remain)
        || hasPathSum(root.right, remain);   // 左右任一路径
}
```

### 6.2 路径总和 II（收集路径 + 回溯）

```java
/**
 * LeetCode 113. 路径总和 II
 * 找出所有根到叶子的路径，路径和 == targetSum
 * 需要收集路径 → 共享 path + 回溯（成对 add/remove）
 */
public List<List<Integer>> pathSum(TreeNode root, int targetSum) {
    List<List<Integer>> res = new ArrayList<>();
    dfs(root, targetSum, new ArrayList<>(), res);
    return res;
}

private void dfs(TreeNode node, int remain,
                 List<Integer> path, List<List<Integer>> res) {
    if (node == null) return;

    path.add(node.val);                         // 做选择
    if (node.left == null && node.right == null && remain == node.val) {
        res.add(new ArrayList<>(path));         // 叶子且和满足 → 收集
    } else {
        dfs(node.left, remain - node.val, path, res);
        dfs(node.right, remain - node.val, path, res);
    }
    path.remove(path.size() - 1);               // ⚠️ 撤销（回溯）
}
```

> ⚠️ **避坑**：共享 path 必须成对 add/remove（回溯），否则路径互相污染。与回溯算法的"选择-递归-撤销"完全一致。

## 7. 257. 二叉树的所有路径

### 7.1 完整实现（前序 + 路径拼接）

```java
/**
 * LeetCode 257. 二叉树的所有路径
 * 输出所有根到叶子的路径字符串："1->2->5"
 *
 * 前序（自顶向下）：路径作为参数传递（值传递 → 天然回溯，无需手动撤销）
 */
public List<String> binaryTreePaths(TreeNode root) {
    List<String> res = new ArrayList<>();
    dfs(root, "", res);
    return res;
}

private void dfs(TreeNode node, String path, List<String> res) {
    if (node == null) return;

    // 路径拼接
    String newPath = path.isEmpty()
        ? String.valueOf(node.val)
        : path + "->" + node.val;

    if (node.left == null && node.right == null) {
        res.add(newPath);               // 叶子 → 收集完整路径
        return;
    }
    dfs(node.left, newPath, res);
    dfs(node.right, newPath, res);
}
// 也可以用 StringBuilder + 回溯（与 113 相同模式）
```

### 7.2 自顶向下路径类题型速查

| 题号 | 题目 | 向下传的状态 | 收集条件 |
|:---:|------|------|------|
| 112 | 路径总和 I | 剩余和 | 叶子 && 剩余==0 |
| 113 | 路径总和 II | 剩余和 + path | 同上 + 收集路径 |
| 257 | 所有路径 | 路径字符串 | 叶子 |
| 129 | 根到叶数字和 | 累积数字 | 叶子累加 |
| 572 | 另一棵树的子树 | 树指针 | 结构相等 |

> 🎯 **核心要点**：树的性质与路径问题 = 两大模式的实战——**自底向上（后序）**解决高度/平衡/直径/路径和（需要子树信息），**自顶向下（前序）**解决路径累积（信息向下传）。记住"有状态模式用外部变量（直径/路径和），无状态直接返回值（高度）"，以及路径收集题的"成对 add/remove 回溯"铁律。
