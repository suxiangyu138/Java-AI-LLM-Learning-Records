## 1. 快慢指针总览

| 题目 | 快慢指针的角色 | 核心逻辑 |
|:---:|------|------|
| 141. 判环 | fast 追 slow | 相遇 → 有环 |
| 142. 找环入口 | fast 追 slow + 重置 | 相遇后重置 slow，同步走再相遇 = 入口 |
| 876. 找中点 | fast 2 步 slow 1 步 | fast 到头时 slow 在中点 |
| 19. 倒数第 N | fast 先走 N + 同步 | fast 到尾时 slow 在倒数第 N 前驱 |
| 160. 相交 | 双指针互换起点 | 消除长度差，同时到达交点 |
| 234. 回文 | 找中点 + 反转 + 比较 | 三个技巧组合 |

> 💡 **为什么走 2 步？** 快慢指针的相对速度是 1（每轮差距减 1），保证任何环长下必然相遇。走 3 步及以上时，相对速度可能跳过 slow，环长与步数不互质时永远追不上。

## 2. 141. 环形链表：Floyd 判圈

### 2.1 完整实现

```java
/**
 * LeetCode 141. 环形链表（Floyd 判圈算法）
 * 判断链表中是否有环。O(n) 时间，O(1) 空间。
 *
 * 循环条件：fast != null && fast.next != null
 *  （否则访问 fast.next.next 可能空指针）
 */
public boolean hasCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;          // 慢走 1 步
        fast = fast.next.next;     // 快走 2 步
        if (slow == fast) return true;   // 相遇 → 有环
    }
    return false;                  // fast 先到 null → 无环
}
```

### 2.2 为什么相遇必然发生？

```
无环：fast 先到达 null → 返回 false ✓
有环：slow 进入环后，fast 也在环内绕圈
  两者相对速度 = 2-1 = 1 步/轮
  环长 L，fast 最多领先 slow L-1 步
  → 最多 L-1 轮追上 → 必然相遇 ✓

类比：环形跑道上，快的人（2 倍速）迟早追上慢的人
```

## 3. 142. 环形链表 II：找环入口（数学推导）

### 3.1 完整实现

```java
/**
 * LeetCode 142. 环形链表 II
 * 返回链表开始入环的第一个节点；无环返回 null。
 *
 * 两阶段法：
 *   阶段 1：快慢指针找到相遇点
 *   阶段 2：slow 重置到 head，fast 留在相遇点，
 *           两指针同速走 1 步，再次相遇 = 环入口
 */
public ListNode detectCycle(ListNode head) {
    ListNode slow = head, fast = head;

    // 阶段 1：找相遇点
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) {
            // 阶段 2：重置 slow，同速走
            slow = head;
            while (slow != fast) {
                slow = slow.next;
                fast = fast.next;
            }
            return slow;          // 再次相遇 = 环入口
        }
    }
    return null;                  // 无环
}
```

### 3.2 数学推导（面试必讲）

```
设：
  a = 链表头到环入口的距离
  b = 环入口到相遇点的距离
  c = 相遇点到环入口的剩余距离（环长 L = b + c）

slow 走的距离 = a + b
fast 走的距离 = a + b + kL（k 圈，k ≥ 1）
且 fast = 2 × slow（速度 2 倍）

⇒ 2(a + b) = a + b + kL
⇒ a + b = kL
⇒ a = kL - b = (k-1)L + (L - b) = (k-1)L + c

结论：从 head 走 a 步 与 从相遇点走 a 步，最终都会到达环入口！

为什么阶段 2 同速走会相遇在入口：
  slow 从 head 出发走 a 步 → 到环入口
  fast 从相遇点出发走 a 步 = (k-1)L + c → 也在环入口 ✓
```

### 3.3 推演示例

```
1 → 2 → 3 → 4 → 5 → 回到 3（环入口=3，a=2，环长=3）

slow 和 fast 从 1 出发：
  slow: 1→2→3→4,  fast: 1→3→5→4   → 相遇在 4
  此时 slow 走 3 步（a+b = 2+1），fast 走 6 步（2×(2+1)）
  
阶段 2：slow 重置 1，fast 留在 4，同速：
  slow: 1→2→3,  fast: 4→5→3   → 相遇在 3 = 环入口 ✓
```

## 4. 876. 链表的中间结点

### 4.1 完整实现

```java
/**
 * LeetCode 876. 链表的中间结点
 * 偶数长度时返回第二个中间节点。
 * [1,2,3,4,5] → 3；[1,2,3,4] → 3（第二个中点）
 */
public ListNode middleNode(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    return slow;
}
// 奇数 [1,2,3,4,5]：slow 停在 3 ✓
// 偶数 [1,2,3,4]：slow 停在 3 ✓（fast 在 4 后到达 null）
```

### 4.2 找中点为什么重要？

```
找中点是很多链表题的第一步：
  回文链表 (234)：中点 → 反转后半
  重排链表 (143)：中点 → 断开 → 交替合并
  排序链表 (148)：中点 → 分治归并
  —— "先找中点"是链表分治思维的起点
```

## 5. 19. 删除链表的倒数第 N 个结点

### 5.1 完整实现（Dummy + 快慢指针）

```java
/**
 * LeetCode 19. 删除链表的倒数第 N 个结点
 *
 * 核心：让 fast 先走 N+1 步（或者先走 N 步然后判断 next），
 *      使 slow 停在待删节点的前驱 → 直接删除
 * 必须用 dummy：可能删除头节点
 */
public ListNode removeNthFromEnd(ListNode head, int n) {
    ListNode dummy = new ListNode(-1);
    dummy.next = head;

    ListNode fast = dummy, slow = dummy;

    // ① fast 先走 n+1 步
    for (int i = 0; i <= n; i++) {
        fast = fast.next;
    }

    // ② fast 和 slow 同步走，fast 到 null 时
    //    slow 恰好指向待删节点的前驱
    while (fast != null) {
        fast = fast.next;
        slow = slow.next;
    }

    // ③ 删除
    slow.next = slow.next.next;

    return dummy.next;
}
```

### 5.2 为什么 fast 先走 n+1 步？

```
倒数第 N 个节点 = 正数第 len-N+1 个
  前驱 = 正数第 len-N 个
fast 先走 n+1 步（到第 n+1 个节点）
slow 和 fast 同步走，fast 走 len-(n+1) 步到达 null
slow 共走 n+1+len-n-1 = len-n 步 → 正数第 len-n 个 = 前驱 ✓

如果不加 dummy，删除头节点（n == len）时前驱不存在 → 特判麻烦
Dummy 一劳永逸
```

## 6. 160. 相交链表

### 6.1 完整实现（双指针消除长度差）

```java
/**
 * LeetCode 160. 相交链表
 * 两个单链表相交，找交点；不相交返回 null。
 *
 * 核心技巧：
 *   pA 遍历完 A 后跳到 B 的头继续走
 *   pB 遍历完 B 后跳到 A 的头继续走
 *   两个指针总路程都 = lenA + lenB
 *   → 若相交，必在交点相遇；否则同时为 null
 */
public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
    ListNode pA = headA, pB = headB;

    while (pA != pB) {
        pA = (pA == null) ? headB : pA.next;   // A 走完跳 B
        pB = (pB == null) ? headA : pB.next;   // B 走完跳 A
    }
    return pA;   // 相遇点（相交）或 null（不相交）
}
```

### 6.2 为什么可行？

```
相交链表示例：
  A: 1→2→3→7→8→9        （交点 7）
  B: 4→5→7→8→9

pA 路径：1→2→3→7→8→9 →(跳B)→ 4→5→7   （在 7 相遇！）
pB 路径：4→5→7→8→9 →(跳A)→ 1→2→3→7   （在 7 相遇！）

总长度相同（lenA+lenB）→ 走完自己又走对方，正好同时到达交点
不相交：两指针最终同时为 null → pA==pB → 返回 null ✓
```

## 7. 234. 回文链表：快慢指针综合应用

### 7.1 完整实现（O(1) 空间）

```java
/**
 * LeetCode 234. 回文链表
 * 判断链表是否为回文（1→2→2→1 → true）
 *
 * 三步曲：
 *   ① 快慢指针找中点
 *   ② 反转后半段
 *   ③ 双指针从两端向中间比较
 */
public boolean isPalindrome(ListNode head) {
    // ① 找中点
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }

    // ② 反转后半段（从 slow 开始）
    ListNode secondHalf = reverse(slow);
    ListNode firstHalf = head;

    // ③ 比较前半段与反转后的后半段
    while (secondHalf != null) {
        if (firstHalf.val != secondHalf.val) return false;
        firstHalf = firstHalf.next;
        secondHalf = secondHalf.next;
    }
    return true;
}

// 三指针反转（206 的复用）
private ListNode reverse(ListNode head) {
    ListNode prev = null, curr = head;
    while (curr != null) {
        ListNode next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }
    return prev;
}
// 推演 [1,2,2,1]：中点 slow=2(第二个)
// 反转 [2,1] → [1,2]（新头 1）
// 比较：1==1, 2==2 → true ✓
```

### 7.2 快慢指针六大应用总结

| 应用 | 核心代码差异 | 记忆点 |
|------|------|------|
| 判环 141 | 相遇返回 true | 条件 `fast.next != null` |
| 找环入口 142 | 相遇后重置再走 | 数学公式 a = (k-1)L + c |
| 找中点 876 | 循环结束返回 slow | 偶数返回第二个中点 |
| 倒数第 N 19 | fast 先走 N+1 | 让 slow 停在前驱 |
| 相交 160 | 走完跳对方 | 总路程相等 |
| 回文 234 | 中点+反转+比较 | 三技巧组合 |

> 🎯 **核心要点**：快慢指针的六大应用都源于同一个"相对速度 1"的模型。**判环、找环入口（记住公式 a=(k-1)L+c）、找中点、倒数第 N（fast 先走 N+1）、相交（走完跳对方）、回文（三步组合）**——每道题的关键差异只在指针的初始位置和出发时机。142 的数学推导是面试加分必讲点。
