## 1. 21. 合并两个有序链表

### 1.1 迭代版（双指针 + dummy）

```java
/**
 * LeetCode 21. 合并两个有序链表
 * 将两个升序链表合并为一个新的升序链表。
 * O(m+n)，空间 O(1)（迭代版）
 */
public ListNode mergeTwoLists(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(-1);    // 哨兵头
    ListNode tail = dummy;                // 结果链表的尾指针

    while (l1 != null && l2 != null) {
        if (l1.val <= l2.val) {           // 取较小者
            tail.next = l1;
            l1 = l1.next;
        } else {
            tail.next = l2;
            l2 = l2.next;
        }
        tail = tail.next;                 // 尾指针前进
    }

    // 剩余部分直接接上（两个链至少一个已空）
    tail.next = (l1 != null) ? l1 : l2;

    return dummy.next;
}
```

### 1.2 递归版

```java
/**
 * 递归版：O(m+n)，空间 O(m+n)（递归栈）
 * 思路：取较小者为当前节点，剩余部分递归合并
 */
public ListNode mergeTwoListsRecursive(ListNode l1, ListNode l2) {
    if (l1 == null) return l2;            // 基线：一方为空
    if (l2 == null) return l1;

    if (l1.val <= l2.val) {
        l1.next = mergeTwoListsRecursive(l1.next, l2);
        return l1;
    } else {
        l2.next = mergeTwoListsRecursive(l1, l2.next);
        return l2;
    }
}
```

### 1.3 面试点评要点

```
"合并两个有序链表的思路是双指针 + 哨兵头：
 每次比较两链当前节点取较小者接入结果链，
 某链耗尽后直接把另一链剩余部分接上。
 迭代版 O(m+n) 空间 O(1)，递归版更简洁但空间 O(m+n)。
 推荐迭代版，因为链表可能很长，递归有栈溢出风险。"
```

## 2. 23. 合并 K 个升序链表

### 2.1 优先队列法（推荐）

```java
/**
 * LeetCode 23. 合并 K 个升序链表
 * 输入 k 个升序链表头数组，合并为一个升序链表。
 *
 * 核心思路（优先队列/最小堆）：
 *   ① 所有链表头节点入堆（按值排序）
 *   ② 每次弹出最小值接入结果链
 *   ③ 弹出节点的 next 入堆
 *   ④ 堆空则合并完成
 * 复杂度：O(N log K)（N 总节点数，K 链表数）
 */
public ListNode mergeKLists(ListNode[] lists) {
    if (lists == null || lists.length == 0) return null;

    // 最小堆：按节点值排序
    PriorityQueue<ListNode> pq =
        new PriorityQueue<>((a, b) -> a.val - b.val);

    // ① 所有头节点入堆
    for (ListNode node : lists) {
        if (node != null) pq.offer(node);
    }

    ListNode dummy = new ListNode(-1);
    ListNode tail = dummy;

    // ②③④ 循环取最小 + 补充后继
    while (!pq.isEmpty()) {
        ListNode min = pq.poll();          // 取最小值
        tail.next = min;
        tail = tail.next;
        if (min.next != null) {
            pq.offer(min.next);            // 后继入堆
        }
    }
    return dummy.next;
}
```

### 2.2 分治归并法（替代方案）

```java
/**
 * 分治：两两合并，每轮链表数量减半
 * 复杂度：O(N log K)，空间 O(log K)（递归栈）
 */
public ListNode mergeKLists_DivideConquer(ListNode[] lists) {
    if (lists == null || lists.length == 0) return null;
    return mergeRange(lists, 0, lists.length - 1);
}

private ListNode mergeRange(ListNode[] lists, int lo, int hi) {
    if (lo == hi) return lists[lo];
    int mid = lo + (hi - lo) / 2;
    ListNode left  = mergeRange(lists, lo, mid);      // 左半合并
    ListNode right = mergeRange(lists, mid + 1, hi);  // 右半合并
    return mergeTwoLists(left, right);                // 两两合并（21 题）
}

// 复杂度推导（分治）：
// 每轮合并总节点数 O(N)，共 log K 轮 → O(N log K)
```

### 2.3 三种方法对比

| 方法 | 时间复杂度 | 空间 | 适用 |
|------|:---:|:---:|------|
| 顺序两两合并 | O(K²N) | O(1) | ❌ 不推荐 |
| 优先队列 | O(N log K) | O(K) | ✅ 面试推荐 |
| 分治归并 | O(N log K) | O(log K) | ✅ 追问时展示 |

## 3. 148. 排序链表：归并排序

### 3.1 完整实现（归并排序 + 快慢指针）

```java
/**
 * LeetCode 148. 排序链表（进阶：O(n log n) 时间，O(1) 空间）
 * 对链表排序。数组的快排/堆排依赖随机访问，链表上最优解是归并。
 *
 * 归并排序三步：
 *   ① 快慢指针找中点，断开成两半
 *   ② 递归排序两半
 *   ③ 合并两个有序链表（21 题）
 */
public ListNode sortList(ListNode head) {
    if (head == null || head.next == null) return head;   // 基线

    // ① 找中点并断开
    ListNode slow = head, fast = head;
    while (fast.next != null && fast.next.next != null) {
        slow = slow.next;                  // 注意：慢指针走 1 步
        fast = fast.next.next;
    }
    ListNode secondHalf = slow.next;       // 右半头
    slow.next = null;                      // 断开！关键

    // ② 递归排序两半
    ListNode left  = sortList(head);
    ListNode right = sortList(secondHalf);

    // ③ 合并（复用 21 题）
    return mergeTwoLists(left, right);
}
```

### 3.2 为什么链表排序选归并？

| 排序 | 能否用于链表 | 原因 |
|------|:---:|------|
| 快速排序 | 可用但麻烦 | 链表无随机访问，partition 需遍历 O(n)；**易退化 O(n²)** |
| 堆排序 | ❌ 不推荐 | 依赖数组下标（堆是完全二叉树） |
| 归并排序 | ✅ **最优** | 只需 next 指针操作，天然适配；稳定 O(n log n) |

> 💡 **面试加分**：主动说出"数组排序默认快排，链表排序选归并——因为归并只需要 O(1) 额外空间（迭代版），且不依赖随机访问"。另外归并是**稳定排序**，二次排序场景（按学号再按分数）必须用它。

### 3.3 空间 O(1) 的迭代归并版（追问加分）

```java
/**
 * 迭代版归并（自底向上）：O(n log n) 时间，O(1) 空间
 * 思路：从 len=1 开始，每轮合并相邻的两个 len 长的有序段
 * 实现要点：记录 nextSegment 头，分段、合并、拼接
 */
public ListNode sortList_Iterative(ListNode head) {
    if (head == null || head.next == null) return head;

    // 统计长度
    int len = 0;
    for (ListNode p = head; p != null; p = p.next) len++;

    ListNode dummy = new ListNode(-1);
    dummy.next = head;

    for (int segLen = 1; segLen < len; segLen *= 2) {
        ListNode prev = dummy;      // 已合并部分的尾
        ListNode curr = dummy.next; // 当前段起点

        while (curr != null) {
            // 取第一段 [curr, 前 segLen 个]
            ListNode first = curr;
            ListNode second = cut(curr, segLen);       // 切出第二段头
            curr = cut(second, segLen);                // 切出下一轮起点

            prev.next = mergeTwoLists(first, second);  // 合并两段
            // 让 prev 指向合并结果的尾
            while (prev.next != null) prev = prev.next;
        }
    }
    return dummy.next;
}

// 从 head 开始切出 len 个节点，返回剩余部分头（并断开）
private ListNode cut(ListNode head, int len) {
    if (head == null) return null;
    for (int i = 1; i < len && head.next != null; i++) {
        head = head.next;
    }
    ListNode rest = head.next;
    head.next = null;    // 断开
    return rest;
}
```

## 4. 86. 分隔链表

### 4.1 完整实现（双 dummy）

```java
/**
 * LeetCode 86. 分隔链表
 * 将所有小于 x 的节点排在大于等于 x 的节点之前。
 * 要求保持两个分组内部相对顺序。
 * 例：1→4→3→2→5→2, x=3 → 1→2→2→4→3→5
 *
 * 思路：两个虚拟链表分别收集 <x 和 ≥x 的节点，最后拼接
 */
public ListNode partition(ListNode head, int x) {
    ListNode smallDummy = new ListNode(-1);
    ListNode largeDummy = new ListNode(-1);
    ListNode smallTail = smallDummy;
    ListNode largeTail = largeDummy;

    ListNode curr = head;
    while (curr != null) {
        if (curr.val < x) {
            smallTail.next = curr;      // 接入小链表
            smallTail = smallTail.next;
        } else {
            largeTail.next = curr;      // 接入大链表
            largeTail = largeTail.next;
        }
        curr = curr.next;
    }

    largeTail.next = null;              // ⚠️ 必须断开，防止成环！
    smallTail.next = largeDummy.next;   // 拼接两个链表
    return smallDummy.next;
}
```

> ⚠️ **关键坑**：`largeTail.next = null` 必须执行——否则原链表最后一个大节点可能还指向某个小节点，形成环。这是分隔类题目的经典 bug。

## 5. 82. 删除排序链表中的重复元素 II

### 5.1 完整实现（Dummy + 双指针）

```java
/**
 * LeetCode 82. 删除排序链表中的重复元素 II
 * 删除所有重复的节点，只保留原始链表中没有重复出现的数字。
 * 例：1→2→3→3→4→4→5 → 1→2→5
 *
 * 与 83 的区别：
 *   83 保留一个重复值 → 跳过重复节点
 *   82 删除全部重复值 → 跳过整个重复区间
 */
public ListNode deleteDuplicates(ListNode head) {
    ListNode dummy = new ListNode(-1);
    dummy.next = head;
    ListNode prev = dummy;      // 前驱（指向最后一个保留节点）

    while (prev.next != null) {
        ListNode curr = prev.next;
        // 检查 curr 是否在重复区间中
        if (curr.next != null && curr.val == curr.next.val) {
            // 跳过整个重复区间
            int dupVal = curr.val;
            while (curr != null && curr.val == dupVal) {
                curr = curr.next;
            }
            prev.next = curr;   // 直接连到区间后的第一个节点
        } else {
            prev = prev.next;   // 无重复，前驱前进
        }
    }
    return dummy.next;
}
```

### 5.2 83 vs 82 对比

| 题号 | 题目 | 策略 | 结果 |
|:---:|------|------|:---:|
| 83 | 删除排序重复 I | 保留一个 | 1→2→3→4→5 |
| 82 | 删除排序重复 II | 全部删除 | 1→2→5 |

```
83 的写法：只保留不重复的节点
  if (curr.val == curr.next.val) curr.next = curr.next.next;  // 跳过重复

82 的写法：整个重复区间都删
  while (curr != null && curr.val == dupVal) curr = curr.next;  // 跳到区间后
```

## 6. 合并与排序题型总结

### 6.1 全题型速查

| 题号 | 题目 | 核心技巧 | 复杂度 |
|:---:|------|------|:---:|
| 21 | 合并两个有序链 | 双指针 + dummy | O(m+n) |
| 23 | 合并 K 个链表 | 优先队列 / 分治 | O(N log K) |
| 148 | 排序链表 | 归并 + 快慢指针 | O(n log n) |
| 86 | 分隔链表 | 双 dummy + 断环 | O(n) |
| 82 | 删除重复 II | dummy + 跳过区间 | O(n) |
| 147 | 对链表插入排序 | 插入排序 | O(n²)（了解） |

### 6.2 归并思想的统一框架

```
"归并三件套"：
  ① 切分：快慢指针找中点（或切段）
  ② 递归/迭代处理子链
  ③ 合并：mergeTwoLists 复用

链表归并四题同源：
  21 合并两个（最小单元）
  23 合并 K 个（堆 or 分治）
  148 排序链表（先切后合）
  143 重排链表（切 + 反转 + 交替合并）
```

### 6.3 面试高频追问

| 追问 | 标准回答 |
|------|------|
| 为什么用优先队列合并 K 链？ | 每次取 k 个头中的最小值，堆插入/删除 O(log k)，总 O(N log K) |
| 链表排序为什么不用快排？ | 快排 partition 依赖随机访问，链表上每次分区 O(n) 且易退化 O(n²)；归并只需改 next 指针，稳定且无退化 |
| 归并排序的空间？ | 递归版 O(log n)（递归栈），迭代版（自底向上）O(1) |
| 分隔链表为什么最后要断链？ | 原链表的尾节点可能还指向别的节点，不断会成环 |

> 🎯 **核心要点**：链表上的"合并与排序"全部围绕归并思想——**切分（快慢指针）+ 合并（mergeTwoLists）**。23 用优先队列把两两合并扩展为 K 路，148 用归并解决了链表不能随机访问的排序难题。**分隔和删除题务必注意断环**（largeTail.next = null）。归并四题（21/23/148/143）练熟，链表合并排序系列就是送分题。
