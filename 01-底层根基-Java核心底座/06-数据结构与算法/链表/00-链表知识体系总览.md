## 3. 学习路线推荐

### 🟢 路线 A：零基础入门（1 周）
```
01 基础技巧 → 206 反转链表 → 21 合并有序链表
→ 141 环形链表 → 876 中点 → 19 删除倒数第 N
```
- **目标**：掌握四大技巧，独立写出基础操作
- **题量**：约 8-10 题

### 🟡 路线 B：面试冲刺（1-2 周）
```
01 技巧速过 → 02 反转系列全部（4题）
→ 03 快慢指针全部（6题）→ 04 合并排序（4题）
→ 05 高频复盘 + LRU 设计题
```
- **目标**：Hot 100 链表题全覆盖，手写零失误
- **题量**：约 15-18 题

### 🔴 路线 C：全面掌握（2-3 周）
```
完整 01→05 + 每类 5-8 题 + 迭代/递归双解法
→ 25 K个一组翻转 + 143 重排 + 138 随机复制（进阶）
→ 146 LRU 手写（面试设计题必考）
→ 画图复盘每个指针变化
```
- **目标**：所有链表题 30 秒内识别套路，进阶题独立 AC
- **题量**：约 25 题

## 4. 核心概念速查

| 概念 | 一句话解释 | 典型例题 |
|------|-----------|------|
| **Dummy 虚拟头** | 哨兵节点，统一头节点操作 | 19/86/82 |
| **快慢指针** | 快走 2 步慢走 1 步，找中点/判环 | 141/876 |
| **Floyd 判圈** | 快慢指针相遇 → 有环 | 141 |
| **入环点推导** | 相遇后 slow 重置 head，再同步走相遇即入环点 | 142 |
| **三指针反转** | prev/curr/next 三指针逐个反转 | 206 |
| **递归反转** | `head.next.next = head` 回溯反转 | 206 递归版 |
| **双指针消除长度差** | 两个链表相交检测 | 160 |
| **优先队列合并** | 最小堆取头节点，O(N log K) | 23 |
| **归并排序链表** | 快慢指针找中点 + 合并，O(n log n) | 148 |
| **回文检测** | 找中点 + 反转后半 + 双指针比较 | 234 |
| **哈希表+双向链表** | LRU 缓存设计，get/put 均 O(1) | 146 |

## 6. 复杂度速查表

| 问题 | 时间复杂度 | 空间复杂度 | 关键技巧 |
|------|:---:|:---:|------|
| 反转链表 (206) | O(n) | O(1) / O(n) 递归 | 三指针 / 递归 |
| 环形检测 (141) | O(n) | O(1) | 快慢指针 |
| 找环入口 (142) | O(n) | O(1) | Floyd 两阶段 |
| 链表中点 (876) | O(n) | O(1) | 快慢指针 |
| 删除倒数第 N (19) | O(n) | O(1) | 快慢指针 + dummy |
| 相交链表 (160) | O(m+n) | O(1) | 双指针消除长度差 |
| 回文链表 (234) | O(n) | O(1) | 中点 + 反转 + 比较 |
| 合并两有序链 (21) | O(m+n) | O(1) / O(m+n) 递归 | 双指针 + dummy |
| 合并 K 链 (23) | O(N log K) | O(K) | 优先队列 |
| 排序链表 (148) | O(n log n) | O(log n) | 归并 + 快慢指针 |
| K 个一组翻转 (25) | O(n) | O(1) | 区间反转 + 拼接 |
| LRU 缓存 (146) | O(1) 每次 | O(capacity) | 哈希表 + 双向链表 |
