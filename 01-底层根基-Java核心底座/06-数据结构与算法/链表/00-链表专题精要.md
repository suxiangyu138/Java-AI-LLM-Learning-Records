## 1. 核心概念

### 1.1 链表本质

```
节点 = 值 + next 指针（可加 prev）
  插入/删除 O(1)（有前驱时）
  随机访问 O(n)（必须遍历）

vs 数组：
  数组 O(1) 随机访问、O(n) 增删
  链表 O(n) 访问、O(1) 增删（有前驱）

⚠️ 链表题第一原则：画图！
  指针变化视觉化 → 不动笔等于没做
```

### 1.2 识别信号

```
"反转/翻转" → 三指针（206）
"环形/环" → 快慢（141/142）
"删除节点" → Dummy + 定位（19）
"合并/排序" → 双指针/归并（21/148）
"回文/中点" → 快慢（234/876）

⚠️ 链表题套路固定（反转/环形/合并/删除四大类）
  识别套路 → 套模板
```

### 1.3 四大核心技巧

```
① Dummy 虚拟头：统一头节点操作
② 快慢指针：判环/中点/倒数第 N
③ 三指针：反转链表
④ 递归：分解为"当前节点 + 剩余链"

⚠️ 铁律三句话：
  "修改链表先建 dummy，返回 dummy.next"
  "三指针反转先暂存 next（防断链）"
  "拼接后断环（largeTail.next = null）"
```

## 2. 完整代码模板

### 2.1 206. 反转链表（母题，三指针）

```java
/**
 * LeetCode 206. 反转链表（一切反转题的源头）
 */
public ListNode reverseList(ListNode head) {
    ListNode prev = null;          // 反转后的尾（初始为空）
    ListNode curr = head;

    while (curr != null) {
        ListNode next = curr.next;   // ① 暂存后继（防断链）
        curr.next = prev;            // ② 反转指针
        prev = curr;                 // ③ 前驱前进
        curr = next;                 // ④ 当前前进
    }
    return prev;                     // 新头 = 原链表的尾
}
// 推演 1→2→3→null：
//   ① next=2, ② 1.next=null, ③ prev=1, ④ curr=2
//   ① next=3, ② 2.next=1, ③ prev=2, ④ curr=3
//   ① next=null, ② 3.next=2, ③ prev=3, ④ curr=null
//   返回 3 → 3→2→1 ✓
// 递归版：head.next.next = head（空间 O(n)，追问时展示）
```

### 2.2 141. 环形链表（快慢指针）

```java
/**
 * LeetCode 141. 环形链表（Floyd 判圈）
 */
public boolean hasCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {  // ⚠️ 判空防越界
        slow = slow.next;            // 1 步
        fast = fast.next.next;       // 2 步
        if (slow == fast) return true;   // 相遇 → 有环
    }
    return false;                    // fast 先到 null → 无环
}
// 为什么走 2 步？相对速度 1 → 任何环长必然相遇
// 走 3 步以上可能跳过 slow 永远追不上

// 142 找环入口（两阶段）：
//   ① 快慢相遇 → ② slow 重置 head → 同速走 → 再相遇 = 入口
//   数学推导：a = (k-1)L + c（面试必讲）
```

### 2.3 21. 合并两个有序链表（Dummy + 双指针）

```java
/**
 * LeetCode 21. 合并两个有序链表
 */
public ListNode mergeTwoLists(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(-1);    // 哨兵头
    ListNode tail = dummy;                // 结果链表的尾

    while (l1 != null && l2 != null) {
        if (l1.val <= l2.val) {           // 取较小者
            tail.next = l1;
            l1 = l1.next;
        } else {
            tail.next = l2;
            l2 = l2.next;
        }
        tail = tail.next;
    }
    tail.next = (l1 != null) ? l1 : l2;   // 剩余直接接上

    return dummy.next;                    // 返回新头
}
// O(m+n) 时间 O(1) 空间（迭代版）
// 递归版更简洁但 O(m+n) 空间（追问时展示）
```

## 3. 三大核心技巧详解

### 3.1 技巧一：Dummy 虚拟头

```
问题：删除头节点需要特判（head = head.next）
Dummy 方案：
  dummy → [原链表]
  所有操作从 dummy.next 开始统一
  删除任何节点 = 删除"某个节点的后继"

⚠️ 适用场景：
  19 删除倒数第 N（可能删头）
  21 合并（结果头未定）
  86 分隔、82 去重（头可能变）

记忆："修改链表先建 dummy，返回 dummy.next"
```

### 3.2 技巧二：快慢指针

```java
// 统一模板：fast 走 2 步，slow 走 1 步
ListNode slow = head, fast = head;
while (fast != null && fast.next != null) {
    slow = slow.next;
    fast = fast.next.next;
}

// 应用：
//   判环（141）：相遇即有环
//   找中点（876）：fast 到头时 slow 在中点
//   倒数第 N（19）：fast 先走 N+1 步再同步
//   回文（234）：中点 + 反转后半 + 比较
// ⚠️ 为什么 2 步？相对速度 1 保证判环必相遇
```

### 3.3 技巧三：三指针反转

```
prev/curr/next 三指针：
  暂存 next（防断链）→ 反转 curr → 前进

扩展：
  92 反转区间（头插法）
  24 两两交换（三指针）
  25 K 个一组翻转（区间反转 + 拼接）

⚠️ K 个一组翻转的要点：
  先保存 nextGroupHead 再反转
  反转后 prev 即新头
```

## 4. 链表题的边界处理

### 4.1 边界清单

```
① 空链表（head == null）
② 单节点（head.next == null）
③ 删除头节点（Dummy 统一）
④ 尾部操作（next == null）
⑤ 快慢指针循环条件（fast 和 fast.next 判空）

⚠️ 手写后自检：
  空链表 → 不报错
  单节点 → 正确返回
  头节点 → Dummy 处理
```

### 4.2 常见断链错误

```
① 插入顺序反：先改 prev.next 再连新节点 → 断链
   正确：新节点先连后继，prev 再接新节点
② 反转忘暂存 next → 断链
③ 拼接忘断环 → 死循环（86/143）
④ 循环条件忘判 fast.next → 空指针

⚠️ 画图验证每个指针变化
```

### 4.3 迭代 vs 递归

```
迭代：空间 O(1)，面试主推
递归：空间 O(n)（栈），追问时展示

⚠️ 面试表达：
"迭代版 O(1) 空间更优；递归版简洁但
 O(n) 栈空间，链表很长时可能栈溢出，
 所以主推迭代。"
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"这题的核心技巧是【Dummy/快慢/三指针】：
 ① 边界先行：空链表、单节点、删除头节点
   用 Dummy 统一处理；
 ② 我习惯先画图推演指针变化，链表题
   不动笔等于没做；
 ③ 迭代版 O(1) 空间为主，递归版
   O(n) 栈空间作为备选。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 为什么要画图？ | 指针操作视觉化，画图推演防错 |
| 2 | Dummy 的作用？ | 统一头节点操作（删除/确定新头） |
| 3 | 快慢为什么走 2 步？ | 相对速度 1 保证判环必相遇 |
| 4 | 迭代 vs 递归？ | 迭代 O(1) 空间；递归 O(n) 可能溢出 |
| 5 | 142 数学推导？ | a=(k-1)L+c，重置同速走相遇即入口 |
| 6 | 为什么链表归并最优？ | 只需 next 指针，无需随机访问 |
| 7 | 断环什么时候？ | 拼接/分隔后（86/143）防死循环 |
| 8 | LRU 为什么双向？ | 删任意节点 O(1)（单链表需找前驱） |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 忘暂存 next | 断链 | 先存再反转 |
| 忘 dummy | 头节点特判 | 先建 dummy |
| 循环忘判空 | 空指针 | fast.next 判空 |
| 拼接忘断环 | 死循环 | 尾部 next=null |
| 返回错头 | 结果错 | 返回 dummy.next |

> 🎯 **核心要点**：链表 = **画图 + 四大技巧 + 边界**。206/141/21/19 四大必背母题，146 LRU 是设计题之王。三句话："修改先 dummy、反转暂存 next、拼接断环"；快慢指针"相对速度 1"论证与 142 数学推导是面试必答。
