## 1. 206. 反转链表（母题）

### 1.1 完整实现（迭代 + 递归）

```java
/**
 * LeetCode 206. 反转链表（一切反转题的源头）
 * 迭代：三指针 O(1) 空间
 * 递归：O(n) 空间（追问展示）
 */
public ListNode reverseList(ListNode head) {
    ListNode prev = null, curr = head;
    while (curr != null) {
        ListNode next = curr.next;   // ① 暂存后继（防断链）
        curr.next = prev;            // ② 反转指针
        prev = curr;                 // ③ 前驱前进
        curr = next;                 // ④ 当前前进
    }
    return prev;                     // 新头 = 原尾
}

public ListNode reverseListRecursive(ListNode head) {
    if (head == null || head.next == null) return head;
    ListNode newHead = reverseListRecursive(head.next);
    head.next.next = head;           // 后继指向自己
    head.next = null;
    return newHead;
}
// 面试表达："迭代 O(1) 空间主推；
//   递归简洁但 O(n) 栈空间，链表很长可能溢出"
```

## 2. 92. 反转链表 II（区间反转）

### 2.1 头插法完整实现

```java
/**
 * LeetCode 92. 反转链表 II
 * 反转 [left, right] 区间（1-indexed）
 * 头插法：每步把当前节点头插到 pre 之后
 */
public ListNode reverseBetween(ListNode head, int left, int right) {
    ListNode dummy = new ListNode(-1);   // ⚠️ 防止 left=1
    dummy.next = head;

    // ① 定位 pre（left 的前驱）
    ListNode pre = dummy;
    for (int i = 1; i < left; i++) {
        pre = pre.next;
    }

    // ② 头插法反转区间
    ListNode curr = pre.next;            // 区间第一个节点
    for (int i = left; i < right; i++) {
        ListNode next = curr.next;       // 待头插的节点
        curr.next = next.next;           // ① 跳过待插节点
        next.next = pre.next;            // ② 待插指向区间头
        pre.next = next;                 // ③ 插到 pre 后面
    }

    return dummy.next;
}
// 推演 1→2→3→4→5, left=2, right=4：
//   pre=1, curr=2
//   i=2：next=3 → 2→4；3→2；pre→3 → 1→3→2→4→5
//   i=3：next=4 → 2→5；4→3；pre→4 → 1→4→3→2→5 ✓
// ⚠️ 头插法 vs 三指针：
//   区间反转用头插法（pre 固定，逐个头插）
```

## 3. 141/142. 环形链表 I & II

### 3.1 141. 环形链表（Floyd 判圈）

```java
/**
 * LeetCode 141. 环形链表
 * 快慢相遇 → 有环
 * ⚠️ 相对速度 1 → 任何环长必然相遇
 */
public boolean hasCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {   // ⚠️ 判空！
        slow = slow.next;            // 1 步
        fast = fast.next.next;       // 2 步
        if (slow == fast) return true;   // 相遇 → 有环
    }
    return false;                    // fast 先到 null → 无环
}
// 面试追问："为什么走 2 步？"
//   → 相对速度 1，环长 L 最多 L 轮追上
```

### 3.2 142. 环形链表 II（找入口）

```java
/**
 * LeetCode 142. 环形链表 II
 * 两阶段：
 *   ① 快慢相遇（判环）
 *   ② slow 重置 head，同速走 → 再相遇 = 入口
 */
public ListNode detectCycle(ListNode head) {
    ListNode slow = head, fast = head;

    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) {              // 相遇
            slow = head;                 // ⚠️ 重置
            while (slow != fast) {       // 同速走
                slow = slow.next;
                fast = fast.next;
            }
            return slow;                 // 再次相遇 = 入口
        }
    }
    return null;                         // 无环
}
// 数学推导（面试必讲）：
//   a = 头到入口，b = 入口到相遇，c = 相遇到入口
//   fast = 2×slow → a = (k-1)L + c
//   → 从 head 走 a 步 与 从相遇点走 a 步 都到入口
```

## 4. 876. 链表的中间结点

### 4.1 完整实现

```java
/**
 * LeetCode 876. 链表的中间结点
 * fast 到头时 slow 恰在中点
 * ⚠️ 偶数长度返回第二个中点
 */
public ListNode middleNode(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    return slow;
}
// [1,2,3,4,5] → 3（奇数）
// [1,2,3,4] → 3（偶数第二个中点）
// ⚠️ 找中点的应用：

//   重排（143）：中点 → 断开 → 交替合并
//   排序（148）：中点 → 分治归并
```

## 5. 19. 删除链表的倒数第 N 个结点

### 5.1 完整实现（Dummy + 快慢）

```java
/**
 * LeetCode 19. 删除链表的倒数第 N 个结点
 * Dummy（可能删头）+ fast 先走 N+1（停在待删前驱）
 */
public ListNode removeNthFromEnd(ListNode head, int n) {
    ListNode dummy = new ListNode(-1);
    dummy.next = head;

    ListNode fast = dummy, slow = dummy;

    for (int i = 0; i <= n; i++) {       // ⚠️ 先走 n+1
        fast = fast.next;
    }
    while (fast != null) {               // 同步走
        fast = fast.next;
        slow = slow.next;
    }
    slow.next = slow.next.next;          // 删除

    return dummy.next;
}
// 推演 1→2→3→4→5, n=2：
//   fast 走 3 步 → 4；slow 停在 3（前驱）
//   → 删除 4 ✓
// ⚠️ 为什么先走 n+1 而非 n？
//   删除需要"前驱" → slow 停在待删前驱
//   （先走 n 会停在待删节点本身）
```

## 6. 21. 合并两个有序链表

### 6.1 完整实现（迭代 + 递归）

```java
/**
 * LeetCode 21. 合并两个有序链表
 * 迭代：双指针 + Dummy（O(1) 空间）
 * 递归：更简洁（O(m+n) 空间）
 */
public ListNode mergeTwoLists(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(-1);
    ListNode tail = dummy;

    while (l1 != null && l2 != null) {
        if (l1.val <= l2.val) {          // ⚠️ <= 稳定（可选）
            tail.next = l1;
            l1 = l1.next;
        } else {
            tail.next = l2;
            l2 = l2.next;
        }
        tail = tail.next;
    }
    tail.next = (l1 != null) ? l1 : l2;  // 剩余直接接上

    return dummy.next;
}

public ListNode mergeTwoListsRecursive(ListNode l1, ListNode l2) {
    if (l1 == null) return l2;
    if (l2 == null) return l1;
    if (l1.val <= l2.val) {
        l1.next = mergeTwoListsRecursive(l1.next, l2);
        return l1;
    } else {
        l2.next = mergeTwoListsRecursive(l1, l2.next);
        return l2;
    }
}
// 面试表达："迭代 O(1) 空间主推；
//   递归简洁但 O(m+n) 空间"
```

## 7. 23. 合并 K 个升序链表

### 7.1 优先队列法（推荐）

```java
/**
 * LeetCode 23. 合并 K 个升序链表
 * 优先队列：所有头入堆，取最小补后继
 * O(N log K)（N 总节点，K 链表数）
 */
public ListNode mergeKLists(ListNode[] lists) {
    if (lists == null || lists.length == 0) return null;

    PriorityQueue<ListNode> pq =
        new PriorityQueue<>((a, b) -> a.val - b.val);

    for (ListNode node : lists) {        // ① 所有头入堆
        if (node != null) pq.offer(node);
    }

    ListNode dummy = new ListNode(-1);
    ListNode tail = dummy;

    while (!pq.isEmpty()) {
        ListNode min = pq.poll();        // ② 取最小
        tail.next = min;
        tail = tail.next;
        if (min.next != null) {
            pq.offer(min.next);          // ③ 后继补入
        }
    }
    return dummy.next;
}
// 复杂度：N 个节点 × 堆操作 O(log K) = O(N log K)
// 空间 O(K)（堆大小）
```

### 7.2 分治法（替代方案）

```java
/**
 * 分治：两两合并，每轮数量减半
 * O(N log K) 时间，O(log K) 空间（递归栈）
 */
public ListNode mergeKLists_DivideConquer(ListNode[] lists) {
    if (lists == null || lists.length == 0) return null;
    return mergeRange(lists, 0, lists.length - 1);
}

private ListNode mergeRange(ListNode[] lists, int lo, int hi) {
    if (lo == hi) return lists[lo];
    int mid = lo + (hi - lo) / 2;
    ListNode left = mergeRange(lists, lo, mid);
    ListNode right = mergeRange(lists, mid + 1, hi);
    return mergeTwoLists(left, right);   // 复用 21 题
}
// 面试追问："两种方法对比？"
//   堆：O(N log K) 时间 O(K) 空间
//   分治：O(N log K) 时间 O(log K) 空间
```

## 8. 148. 排序链表

### 8.1 完整实现（归并 + 快慢）

```java
/**
 * LeetCode 148. 排序链表
 * 链表无随机访问 → 归并排序（O(n log n)）
 */
public ListNode sortList(ListNode head) {
    if (head == null || head.next == null) return head;   // 基线

    // ① 快慢指针找中点并断开
    ListNode slow = head, fast = head;
    while (fast.next != null && fast.next.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    ListNode second = slow.next;
    slow.next = null;                    // ⚠️ 断开！

    // ② 递归排序两半
    ListNode left = sortList(head);
    ListNode right = sortList(second);

    // ③ 合并（复用 21 题）
    return mergeTwoLists(left, right);
}
// 推演 4→2→1→3：
//   中点 2 → [4,2] 与 [1,3]
//   [4,2] → 中点 4 → [4] 与 [2] → 合并 [2,4]
//   [1,3] → 合并 [1,3]
//   合并 [2,4] 与 [1,3] → [1,2,3,4] ✓
// ⚠️ 为什么链表排序选归并？
//   快排 partition 需双向遍历（链表低效）
//   归并只需 next 指针（天然适配）
//   "归并是链表排序的最优解"（面试必答）
```

## 9. 160. 相交链表

### 9.1 完整实现（走完跳对方）

```java
/**
 * LeetCode 160. 相交链表
 * 双指针消除长度差：走完自己的跳对方的头
 * 总路程相同 → 必在交点相遇（或同时 null）
 */
public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
    ListNode pA = headA, pB = headB;

    while (pA != pB) {
        pA = (pA == null) ? headB : pA.next;   // A 走完跳 B
        pB = (pB == null) ? headA : pB.next;   // B 走完跳 A
    }
    return pA;   // 相遇点（相交）或 null（不相交）
}
// 推演 A: 1→2→3→7→8→9, B: 4→5→7→8→9（交点 7）：
//   pA: 1,2,3,7,8,9 → 跳 B: 4,5,7（相遇！）
//   pB: 4,5,7,8,9 → 跳 A: 1,2,3,7（相遇！）
//   总路程 = lenA + lenB（同时走完）
// ⚠️ 面试必答："两指针总路程相同，
//   若相交必在交点相遇；否则同时为 null"
```

## 10. 234. 回文链表

### 10.1 完整实现（O(1) 空间）

```java
/**
 * LeetCode 234. 回文链表
 * 三步曲：找中点 → 反转后半 → 双指针比较
 */
public boolean isPalindrome(ListNode head) {
    // ① 快慢指针找中点
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }

    // ② 反转后半段（从 slow 开始）
    ListNode secondHalf = reverse(slow);
    ListNode firstHalf = head;

    // ③ 比较前半与反转后的后半
    while (secondHalf != null) {
        if (firstHalf.val != secondHalf.val) return false;
        firstHalf = firstHalf.next;
        secondHalf = secondHalf.next;
    }
    return true;
}

private ListNode reverse(ListNode head) {   // 206 复用
    ListNode prev = null, curr = head;
    while (curr != null) {
        ListNode next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }
    return prev;
}
// 推演 [1,2,2,1]：中点 2 → 反转 [1,2] → [2,1]
//   比较 1==1, 2==2 → true ✓
// ⚠️ 三个技巧的组合（快慢 + 三指针 + 双指针）
```

## 11. 25. K 个一组翻转链表

### 11.1 完整实现（区间反转 + 拼接）

```java
/**
 * LeetCode 25. K 个一组翻转链表（Hard）
 * 每组反转 + 拼接；不足 K 保持原样
 */
public ListNode reverseKGroup(ListNode head, int k) {
    if (head == null || k == 1) return head;

    ListNode dummy = new ListNode(-1);
    dummy.next = head;
    ListNode prevGroup = dummy;                // 上一组的尾

    while (true) {
        // ① 检查剩余节点是否 ≥ k
        ListNode tail = prevGroup;
        for (int i = 0; i < k; i++) {
            tail = tail.next;
            if (tail == null) return dummy.next;   // 不足 K 结束
        }

        // ② 保存本组区间
        ListNode groupHead = prevGroup.next;
        ListNode nextGroupHead = tail.next;        // ⚠️ 先保存！

        // ③ 反转本组 [groupHead, tail]（三指针到 tail）
        ListNode prev = null, curr = groupHead;
        while (prev != tail) {
            ListNode next = curr.next;
            curr.next = prev;
            prev = curr;
            curr = next;
        }
        // 反转后：prev == tail（新头），curr == nextGroupHead

        // ④ 拼接回原链表
        prevGroup.next = prev;                     // 上组尾 → 本组新头
        groupHead.next = nextGroupHead;            // 本组旧头（新尾）→ 下组

        prevGroup = groupHead;                     // 本组尾成为下轮连接点
    }
}
// 推演 1→2→3→4→5, k=2：
//   第 1 组 [1,2] → 2→1；拼接 → 2→1→3→4→5
//   第 2 组 [3,4] → 4→3；拼接 → 2→1→4→3→5
//   剩余 [5] 不足 2 → 结束 ✓
// ⚠️ 关键：nextGroupHead 必须在反转前保存！
```

## 12. 146. LRU 缓存

### 12.1 完整实现（设计题之王）

```java
/**
 * LeetCode 146. LRU 缓存（哈希表 + 双向链表）
 * get/put 均 O(1)
 */
class LRUCache {
    class Node {
        int key, value;
        Node prev, next;
        Node(int k, int v) { key = k; value = v; }
    }

    private final int capacity;
    private final Map<Integer, Node> map = new HashMap<>();
    private final Node head = new Node(-1, -1);   // 虚拟头
    private final Node tail = new Node(-1, -1);   // 虚拟尾

    public LRUCache(int capacity) {
        this.capacity = capacity;
        head.next = tail;
        tail.prev = head;
    }

    public int get(int key) {
        Node node = map.get(key);
        if (node == null) return -1;
        moveToHead(node);              // 使用过 → 移到头部
        return node.value;
    }

    public void put(int key, int value) {
        Node node = map.get(key);
        if (node != null) {
            node.value = value;        // 更新值
            moveToHead(node);
        } else {
            node = new Node(key, value);
            map.put(key, node);
            addToHead(node);
            if (map.size() > capacity) {
                Node removed = removeTail();   // 淘汰最久未用
                map.remove(removed.key);       // ⚠️ 同步删哈希
            }
        }
    }

    // ── 双向链表四件套 ──────────────────────────
    private void addToHead(Node node) {
        node.next = head.next;
        node.prev = head;
        head.next.prev = node;
        head.next = node;
    }

    private void removeNode(Node node) {     // O(1) 任意删除！
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }

    private void moveToHead(Node node) {
        removeNode(node);
        addToHead(node);
    }

    private Node removeTail() {
        Node node = tail.prev;
        removeNode(node);
        return node;
    }
}
// ⚠️ 面试必答三问：
//   ① 为什么双向？删任意节点 O(1)（单链需找前驱）
//   ② 为什么节点存 key？删尾后同步删哈希
//   ③ 为什么虚拟头尾？边界统一免判空
```

> 🎯 **核心要点**：十二道母题覆盖链表全题型——**反转**（206/92/25）、**环形**（141/142）、**定位**（876/19）、**合并**（21/23）、**排序**（148）、**相交**（160）、**回文**（234）、**设计**（146）。每类的"关键细节"（暂存 next/先走 N+1/节点存 key）是面试得分点；"识别技巧 → 画图 → 边界先行"是零失误保障。
