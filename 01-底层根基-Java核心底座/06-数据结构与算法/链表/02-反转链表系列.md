## 1. 206. 反转链表：母题全解

### 1.1 迭代版（三指针）

```java
/**
 * LeetCode 206. 反转链表（最高频链表母题）
 * 1→2→3→4→5 → 5→4→3→2→1
 * 时间复杂度 O(n)，空间 O(1)
 */
public ListNode reverseList(ListNode head) {
    ListNode prev = null;          // 反转后的尾（初始为空）
    ListNode curr = head;

    while (curr != null) {
        ListNode next = curr.next;  // ① 暂存后继（防断链）
        curr.next = prev;           // ② 当前节点指向前驱
        prev = curr;                // ③ 前驱前进
        curr = next;                // ④ 当前前进
    }
    return prev;                    // 新头 = 原链表的尾节点
}
```

### 1.2 指针变化推演：1→2→3→null

```
初始: prev=null, curr=1
① next=2, ② 1.next=null, ③ prev=1, ④ curr=2
  → null ← 1    2→3→null          （1 已反转）

① next=3, ② 2.next=1, ③ prev=2, ④ curr=3
  → null ← 1 ← 2    3→null         （2 已反转）

① next=null, ② 3.next=2, ③ prev=3, ④ curr=null
  → null ← 1 ← 2 ← 3               （全部反转）

循环结束（curr=null）→ 返回 prev=3 ✓
```

### 1.3 递归版

```java
/**
 * 递归版：空间 O(n)（递归栈）
 * 思路：递归到末尾拿到 newHead，回溯时反转指针
 */
public ListNode reverseListRecursive(ListNode head) {
    // 递归出口：空链表或单节点
    if (head == null || head.next == null) return head;

    ListNode newHead = reverseListRecursive(head.next);  // 反转剩余部分
    head.next.next = head;   // 让后继指向自己（反转指针）
    head.next = null;        // 断开原前向连接
    return newHead;
}

// 以 1→2→3 推演：
// reverse(3) → 返回 3
// reverse(2) → newHead=3, 3.next=2, 2.next=null → 返回 3
// reverse(1) → newHead=3, 2.next=1, 1.next=null → 返回 3 ✓
// 最终 3→2→1
```

### 1.4 两种写法面试如何选？

```
迭代：空间 O(1)，无栈溢出风险 → 面试主推
递归：空间 O(n)，代码简洁 → 追问递归思维时展示

回答模板：
"反转链表我有两种写法。迭代版用三指针 prev/curr/next，
空间 O(1)；递归版空间 O(n) 有栈溢出风险，链表较长时
建议用迭代。我先写迭代版。"
```

## 2. 区间反转的思路框架

### 2.1 区间反转通用模型

```
反转区间 [left, right] 的节点，例如：
  [1]→[2]→[3]→[4]→[5], left=2, right=4
  → [1]→[4]→[3]→[2]→[5]

步骤分解：
  ① 找到 left 的前驱 pre（反转区间的前一个节点）
  ② 反转区间内的链表（用三指针或头插法）
  ③ 区间头和尾重新拼接：
       pre.next = 反转后的区间头
       区间尾.next = 原区间尾的后继

关键：pre 和 tail 的引用必须提前保存！
```

### 2.2 头插法（区间反转的推荐写法）

```
头插法原理：遍历区间内每个节点，依次插入到 pre 的后面
  pre → [1] → [2] → [3] → [4] → [5]
  （从左到右逐个头插）
  处理 3：pre → [3] → [1] → [2] → [4] → [5]
  处理 4：pre → [4] → [3] → [1] → [2] → [5]

每处理一个节点，它就被"提到"区间最前面
处理完区间内所有节点 → 区间自动反转 ✓
```

## 3. 92. 反转链表 II

### 3.1 头插法完整实现

```java
/**
 * LeetCode 92. 反转链表 II
 * 反转从位置 left 到 right 的链表节点（1-indexed）。
 *
 * 头插法四步：
 *   1. 定位 pre（left 的前驱）
 *   2. 遍历区间节点
 *   3. 每步将当前节点头插到 pre 之后
 *   4. 区间遍历完成即反转完成
 */
public ListNode reverseBetween(ListNode head, int left, int right) {
    ListNode dummy = new ListNode(-1);   // 防止 left=1 时头节点处理
    dummy.next = head;

    // ① 定位 pre：走 left-1 步
    ListNode pre = dummy;
    for (int i = 1; i < left; i++) {
        pre = pre.next;
    }

    // ② 头插法反转区间 [left, right]
    ListNode curr = pre.next;            // 区间第一个节点
    for (int i = left; i < right; i++) {
        ListNode next = curr.next;       // 待头插的节点
        curr.next = next.next;           // ① 跳过待插节点（先连后）
        next.next = pre.next;            // ② 待插节点指向区间头
        pre.next = next;                 // ③ 插入到 pre 后面
    }

    return dummy.next;
}
```

### 3.2 头插法推演：1→2→3→4→5, left=2, right=4

```
定位 pre=1, curr=2

循环 1（i=2）：
  next=3
  curr.next=3.next → 2→4
  next.next=pre.next → 3→2
  pre.next=3 → pre→[3]→[2]→[4]→[5]
  链表：1→3→2→4→5

循环 2（i=3）：
  next=4
  curr.next=4.next → 2→5
  next.next=pre.next → 4→3
  pre.next=4 → pre→[4]→[3]→[2]→[5]
  链表：1→4→3→2→5 ✓ 区间 [2,4] 反转完成
```

## 4. 24. 两两交换链表中的节点

### 4.1 迭代版（dummy + 三指针）

```java
/**
 * LeetCode 24. 两两交换链表中的节点
 * 1→2→3→4 → 2→1→4→3
 * 每两个相邻节点交换，不修改节点值，只修改指针。
 */
public ListNode swapPairs(ListNode head) {
    ListNode dummy = new ListNode(-1);
    dummy.next = head;
    ListNode prev = dummy;

    while (prev.next != null && prev.next.next != null) {
        ListNode first = prev.next;        // 第 1 个节点
        ListNode second = first.next;      // 第 2 个节点

        // 交换：prev → second → first → second.next
        prev.next = second;                // ① prev 指向 second
        first.next = second.next;          // ② first 指向 second 的后继
        second.next = first;               // ③ second 指向 first

        prev = first;                      // ④ prev 前进两组
    }
    return dummy.next;
}
```

### 4.2 递归版（更简洁）

```java
public ListNode swapPairsRecursive(ListNode head) {
    if (head == null || head.next == null) return head;

    ListNode second = head.next;           // 第 2 个节点
    head.next = swapPairsRecursive(second.next);  // 先处理后面的两两
    second.next = head;                    // 反转本对
    return second;                         // 新头 = second
}
```

## 5. 25. K 个一组翻转链表

### 5.1 完整实现（困难题）

```java
/**
 * LeetCode 25. K 个一组翻转链表（困难）
 * 每 k 个节点一组进行翻转，不足 k 个的保持原样。
 *
 * 思路：对每个 [head, tail] 区间：
 *   ① 检查剩余节点是否 ≥ k
 *   ② 反转区间内节点
 *   ③ 拼接回原链表
 */
public ListNode reverseKGroup(ListNode head, int k) {
    if (head == null || k == 1) return head;   // 边界

    ListNode dummy = new ListNode(-1);
    dummy.next = head;
    ListNode prevGroup = dummy;                // 上一组的尾（连接点）

    while (true) {
        // ① 检查剩余节点是否 ≥ k
        ListNode tail = prevGroup;
        for (int i = 0; i < k; i++) {
            tail = tail.next;
            if (tail == null) return dummy.next;   // 不足 k 个，结束
        }

        // ② 保存本组区间：head..tail
        ListNode groupHead = prevGroup.next;
        ListNode nextGroupHead = tail.next;        // 下一组的头（先保存）

        // ③ 反转本组 [groupHead, tail]：迭代三指针反转到 tail
        ListNode prev = null, curr = groupHead;
        while (prev != tail) {                     // 反转至 tail
            ListNode next = curr.next;
            curr.next = prev;
            prev = curr;
            curr = next;
        }
        // 反转后：prev == tail（新头），curr == nextGroupHead

        // ④ 拼接回原链表
        prevGroup.next = prev;                     // 上一组尾 → 本组新头
        groupHead.next = nextGroupHead;            // 本组旧头（新尾）→ 下组

        prevGroup = groupHead;                     // 本组尾成为下一轮的连接点
    }
}
```

### 5.2 推演：1→2→3→4→5, k=2

```
dummy → 1 → 2 → 3 → 4 → 5

第 1 轮：tail=2（走 2 步）
  反转 [1,2] → 2→1
  拼接：dummy→2→1→3→4→5, prevGroup=1

第 2 轮：tail=4
  反转 [3,4] → 4→3
  拼接：dummy→2→1→4→3→5, prevGroup=3

第 3 轮：tail 走 2 步 → 5→null，不足 2 个
  返回 dummy.next = 2→1→4→3→5 ✓
```
