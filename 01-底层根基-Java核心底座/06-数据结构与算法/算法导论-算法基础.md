## 一、算法的五大特性

| 特性 | 说明 |
|------|------|
| **有穷性** | 执行有限步骤后终止 |
| **确定性** | 每一步骤含义明确，无歧义 |
| **可行性** | 每一步可通过基本操作实现 |
| **输入** | 零个或多个外部输入 |
| **输出** | 一个或多个结果输出 |

## 二、算法效率的度量

### 1. 时间复杂度（渐近分析）

| 复杂度 | 含义 | Java 示例 |
|--------|------|-----------|
| O(1) | 常数时间 | `HashMap` 查找、`ArrayList` 随机访问 |
| O(log n) | 对数时间 | 二分查找、红黑树操作 |
| O(n) | 线性时间 | 数组遍历、链表操作 |
| O(n log n) | 线性对数时间 | 排序、分治算法 |
| O(n²) | 平方时间 | 暴力枚举（**后端慎用**） |

### 2. 空间复杂度

| 复杂度 | 含义 | 算法示例 |
|--------|------|----------|
| O(1) | 原地算法 | 堆排序、插入排序 |
| O(n) | 线性空间 | 归并排序、哈希表 |
| O(log n) | 递归栈空间 | 快速排序、二分查找 |

### 3. 最坏、最好、平均情况

| 情况 | 含义 | 后端意义 |
|------|------|----------|
| **最坏情况** | 算法上限 | 后端性能保障核心 |
| **最好情况** | 算法下限 | 参考意义较小 |
| **平均情况** | 实际运行预期 | 需概率分析 |

## 三、算法设计的核心思想

### 1. 分治法

**核心**：分解 → 解决 → 合并

**后端应用**：归并排序、快速排序、分布式计算、分库分表

**Java 实现：二分查找**

```java
public int binarySearch(int[] nums, int target) {
    int left = 0, right = nums.length - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] == target) return mid;
        else if (nums[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return -1;
}
```

### 2. 动态规划

**核心**：重叠子问题 + 最优子结构

**后端应用**：缓存策略、资源调度、最长公共子序列

**Java 实现：爬楼梯**

```java
public int climbStairs(int n) {
    if (n <= 2) return n;
    int a = 1, b = 2;
    for (int i = 3; i <= n; i++) {
        int c = a + b;
        a = b;
        b = c;
    }
    return b;
}
```

### 3. 贪心算法

**核心**：局部最优 → 全局最优

**后端应用**：活动选择、负载均衡、最小生成树

**Java 实现：活动选择**

```java
public int maxActivities(int[] start, int[] end) {
    int count = 1, lastEnd = end[0];
    for (int i = 1; i < start.length; i++) {
        if (start[i] >= lastEnd) {
            count++;
            lastEnd = end[i];
        }
    }
    return count;
}
```

### 4. 回溯法

**核心**：试探 + 回退，暴力枚举

**后端应用**：权限校验、组合查询、路径搜索

**Java 实现：全排列**

```java
public List<List<Integer>> permute(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    backtrack(nums, new boolean[nums.length], new ArrayList<>(), res);
    return res;
}

private void backtrack(int[] nums, boolean[] used, List<Integer> path, List<List<Integer>> res) {
    if (path.size() == nums.length) {
        res.add(new ArrayList<>(path));
        return;
    }
    for (int i = 0; i < nums.length; i++) {
        if (!used[i]) {
            used[i] = true;
            path.add(nums[i]);
            backtrack(nums, used, path, res);
            path.remove(path.size() - 1);
            used[i] = false;
        }
    }
}
```

## 四、算法正确性证明

### 1. 循环不变式

| 步骤 | 说明 |
|------|------|
| **初始化** | 循环第一次迭代前为真 |
| **保持** | 若某次迭代前为真，下次迭代前仍为真 |
| **终止** | 循环终止时，不变式给出算法正确性 |

### 2. 数学归纳法

- **基础步骤**：n = 1 时成立
- **归纳步骤**：假设 n = k 时成立，证明 n = k + 1 时成立

## 五、Java后端算法基础实战场景

### 1. 集合类操作

| 操作 | 数据结构 | 复杂度 |
|------|----------|--------|
| 动态扩容 | ArrayList | 摊还 O(1) |
| 哈希查找 | HashMap | O(1) |
| 堆操作 | PriorityQueue | O(log n) |

### 2. 高并发优化

| 场景 | 算法 | 复杂度 |
|------|------|--------|
| 限流 | 滑动窗口 | O(1) |
| 负载均衡 | 一致性哈希 | O(1) |
| 缓存 | LRU | O(1) |

### 3. 大数据处理

| 场景 | 算法 | 复杂度 |
|------|------|--------|
| 排序 | 快排、归并 | O(n log n) |
| 去重 | 布隆过滤器 | O(1) |
| TopK | 堆排序 | O(n log k) |

### 4. 网络与分布式

| 场景 | 算法 | 复杂度 |
|------|------|--------|
| 路由 | Dijkstra（最短路径） | O(E log V) |
| 调度 | 拓扑排序 | O(V + E) |
| 连通性 | 并查集 | O(α(n)) |
