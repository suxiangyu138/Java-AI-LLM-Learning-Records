## 1. 边界二分的完整体系

### 1.1 为什么需要边界二分

```
基础二分：找"任意一个" target（可能返回任意位置）
边界二分：找"第一个"或"最后一个" target

例：nums = [1,2,3,3,3,4,5], target = 3
  基础二分：可能返回 2/3/4
  左边界：2（第一个 3）
  右边界：4（最后一个 3）

⚠️ 错误做法：找到一个后线性扩展
  → 全是 target 时 O(n)（失去二分意义）
  → 面试官看到直接扣分
```

### 1.2 四种边界问题

| 问题 | 含义 | 返回 |
|------|------|:---:|
| lowerBound | 第一个 ≥ target | 位置或 n |
| upperBound | 第一个 > target | 位置或 n |
| 左边界 | 第一个 == target | 位置或 -1 |
| 右边界 | 最后一个 == target | 位置或 -1 |

```
关系：
  左边界 = lowerBound 且验证 nums[left]==target
  右边界 = upperBound - 1
  ⚠️ 一图四式（见下）
```

### 1.3 一图四式（面试默写）

```
═══════════ 找第一个 ≥ T（lowerBound）═══════════
while (left < right) {
    int mid = left + (right - left) / 2;        // 向下取整
    if (nums[mid] < T) left = mid + 1;
    else right = mid;                            // ⚠️ mid 可能是答案
}
return left;

═══════════ 找第一个 > T（upperBound）═══════════
// 把 < T 改成 <= T 即可

═══════════ 找第一个 == T（左边界）═══════════
// lowerBound + 验证 nums[left] == T

═══════════ 找最后一个 == T（右边界）═══════════
while (left < right) {
    int mid = left + (right - left + 1) / 2;    // ⚠️ 向上取整！
    if (nums[mid] > T) right = mid - 1;
    else left = mid;
}
return nums[left] == T ? left : -1;
```

## 2. lowerBound/upperBound 详解

### 2.1 lowerBound 完整实现

```java
/**
 * lowerBound：返回第一个 ≥ target 的位置
 * ⚠️ 所有边界二分的基石（35/34/278 都用它）
 *
 * 不变量：
 *   nums[0..left-1] 全部 < target
 *   nums[right..n-1] 全部 ≥ target
 *   → 循环结束时 left == right = 答案
 */
public int lowerBound(int[] nums, int target) {
    int left = 0, right = nums.length;       // ⚠️ 右开区间
    while (left < right) {
        int mid = left + (right - left) / 2; // 向下取整
        if (nums[mid] < target) {
            left = mid + 1;                  // 排除"小于"段
        } else {
            right = mid;                     // ⚠️ mid 可能是答案
        }
    }
    return left;
}
// 推演 [1,3,5,7], target=5：
//   mid=2(5≥5) → right=2；mid=1(3<5) → left=2 → 返回 2 ✓
// 推演 target=6（不存在）：
//   mid=2(5<6) → left=3；mid=3(7≥6) → right=3 → 返回 3 ✓
//   （返回"插入位置"——35 题直接用！）
```

### 2.2 为什么"right = mid"不会死循环

```
关键：mid 向下取整 + right = mid
  left=2, right=3 时：mid = 2（向下取整）
  → right = 2 → left == right → 结束 ✓

如果 mid 向上取整（left=2, right=3 → mid=3）：
  → right = 3 → 不变 → 死循环！

⚠️ 记忆：
  "right = mid"（保留 mid）必须配"向下取整"
  "left = mid"（保留 mid）必须配"向上取整"
```

### 2.3 34. 左右边界完整解法

```java
/**
 * LeetCode 34. 在排序数组中查找元素的第一个和最后一个位置
 * 组合法（推荐，不易错）
 */
public int[] searchRange(int[] nums, int target) {
    int left = lowerBound(nums, target);
    if (left == nums.length || nums[left] != target) {
        return new int[]{-1, -1};              // 不存在
    }
    int right = upperBound(nums, target) - 1;  // ⚠️ -1
    return new int[]{left, right};
}

private int lowerBound(int[] nums, int target) {
    int lo = 0, hi = nums.length;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (nums[mid] < target) lo = mid + 1;
        else hi = mid;
    }
    return lo;
}

private int upperBound(int[] nums, int target) {
    int lo = 0, hi = nums.length;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (nums[mid] <= target) lo = mid + 1;  // ⚠️ <= 找第一个 >
        else hi = mid;
    }
    return lo;
}
// 推演 [5,7,7,8,8,10], target=8：
//   lowerBound(8) = 3；upperBound(8) = 5 → [3,4] ✓
// 推演 target=6：lowerBound(6)=3，nums[3]=8≠6 → [-1,-1] ✓
// ⚠️ 记忆："左 = lowerBound；右 = upperBound - 1"
```

## 3. 答案二分的完整框架

### 3.1 答案二分的本质

```
直接求答案难，验证候选答案易：
  在"答案值域"上二分，check(mid) 判断可行性

识别信号：
  "最小 X 使条件成立" / "最大 X 使条件成立"
  "在 D 天内/至少 k 次/不超过 X"

⚠️ 前提：check(mid) 必须单调
  速度越大 → 时间越少（单调递减）
  → 可二分

⚠️ 面试第一句：
"直接求最优难，验证可行性易 →
 在答案值域上二分，check(mid) 单调。"
```

### 3.2 模板与方向对照

```java
/**
 * 答案二分模板（最小化问题）
 */
public int binarySearchAnswer(int lo, int hi) {
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (check(mid)) {
            hi = mid;            // 最小化：可行收 hi
        } else {
            lo = mid + 1;        // 最小化：不可行放 lo
        }
    }
    return lo;
}

/**
 * 最大化问题：方向反转
 *   可行 → lo = mid + 1（尝试更大）
 *   不可行 → hi = mid
 */

// ⚠️ 记忆：
//   最小化：可行收 hi（答案越小越好）
//   最大化：可行放 lo（答案越大越好）
```

### 3.3 check 函数设计三步

```
① 用候选答案 mid 模拟一遍问题场景
② 统计关键指标（天数/段数/总量/个数）
③ 与题目约束比较，返回 boolean

⚠️ 设计注意：
  溢出：累计用 long（875 的 hours）
  剪枝：提前返回（超过约束立即 false）
  边界：mid 的最小/最大值是否可达

⚠️ 面试表达：
"check(mid) 是灵魂——把'求最优'变成
 '验证可行性'。我模拟【场景】，统计【指标】，
 与【约束】比较。单调性确认后二分。"
```

### 3.4 875. 吃香蕉（最小化答案）

```java
/**
 * LeetCode 875. 爱吃香蕉的珂珂
 * 值域 [1, max(piles)]
 */
public int minEatingSpeed(int[] piles, int h) {
    int maxPile = 0;
    for (int p : piles) maxPile = Math.max(maxPile, p);

    int left = 1, right = maxPile;
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (canFinish(piles, h, mid)) right = mid;   // 可行 → 更小
        else left = mid + 1;
    }
    return left;
}

private boolean canFinish(int[] piles, int h, int speed) {
    long hours = 0;
    for (int p : piles) {
        hours += (p + speed - 1) / speed;   // ⚠️ 向上取整
        if (hours > h) return false;        // 提前剪枝
    }
    return hours <= h;
}
// 推演 piles=[3,6,7,11], h=8：
//   speed=4：1+2+2+3=8 ≤ 8 ✓ → 收 hi
//   speed=3：1+2+3+4=10 > 8 ✗ → 放 lo
//   → 答案 4 ✓
```

## 4. 旋转数组与峰值

### 4.1 旋转数组的本质

```
旋转数组 = 两段各自递增，且 B 段全部 < A 段
  [4,5,6,7,0,1,2]（旋转 3 次）

二段性在哪？
  以 nums[right] 为基准：
    nums[mid] > nums[right] → mid 在 A 段（较大段）
    nums[mid] < nums[right] → mid 在 B 段（较小段）
  → 可以判断 mid 所在段 → 收缩
```

### 4.2 153. 旋转数组最小值

```java
/**
 * LeetCode 153. 寻找旋转排序数组中的最小值
 * 以 nums[right] 为基准（未旋转也正确）
 */
public int findMin(int[] nums) {
    int left = 0, right = nums.length - 1;
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] > nums[right]) {
            left = mid + 1;    // mid 在 A 段 → 最小值在右
        } else {
            right = mid;       // mid 在 B 段 → 最小值在左或等于
        }
    }
    return nums[left];
}
// 推演 [4,5,6,7,0,1,2]：
//   mid=3(7>2) → left=4；mid=5(1<2) → right=5
//   mid=4(0<1) → right=4 → 返回 0 ✓
// 未旋转 [0,1,2,3]：mid=1(1<3) → right=1... → 返回 0 ✓
// ⚠️ 为什么不用 nums[left]？未旋转时会误判
```

### 4.3 33. 旋转数组搜索

```java
/**
 * LeetCode 33. 搜索旋转排序数组
 * 两步：判段归属 → target 与段边界比较
 */
public int search(int[] nums, int target) {
    int left = 0, right = nums.length - 1;

    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] == target) return mid;

        // 判断 mid 在左段还是右段（⚠️ 用动态 nums[left]）
        if (nums[mid] >= nums[left]) {
            // mid 在左段（递增段）
            if (target >= nums[left] && target < nums[mid]) {
                right = mid - 1;   // target 在左段前半
            } else {
                left = mid + 1;
            }
        } else {
            // mid 在右段（递增段）
            if (target > nums[mid] && target <= nums[right]) {
                left = mid + 1;    // target 在右段后半
            } else {
                right = mid - 1;
            }
        }
    }
    return -1;
}
// ⚠️ 关键细节：
//   ① 用动态 nums[left] 判段（随 left 变化）
//   ② 段内比较用"与端点比较"（target 是否在该段）
```

### 4.4 162. 寻找峰值

```java
/**
 * LeetCode 162. 寻找峰值
 * 两端视为 -∞ → 上坡必有顶
 *
 * 二段性：
 *   nums[mid] < nums[mid+1] → 右侧必有峰值
 *   nums[mid] > nums[mid+1] → 左侧必有峰值
 */
public int findPeakElement(int[] nums) {
    int left = 0, right = nums.length - 1;
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] < nums[mid + 1]) {
            left = mid + 1;      // 上坡 → 峰值在右
        } else {
            right = mid;         // 下坡 → 峰值在左或等于
        }
    }
    return left;
}
// 单调数组 [1,2,3,4,5] → 返回 4（5 是峰值，右端 -∞）
// 降序数组 [5,4,3,2,1] → 返回 0（5 是峰值，左端 -∞）
// ⚠️ 面试必答："每次收缩后新区间内必有峰值——
//   数学保证方向选择正确"
```

## 5. 二分的正确性论证

### 5.1 不变量论证（边界二分）

```
lowerBound 的不变量：
  循环中始终有：
    nums[0..left-1] < target（left 左侧全小于）
    nums[right..n-1] ≥ target（right 右侧全大于）

循环结束时 left == right：
  → 恰好是"分界点" = 第一个 ≥ target ✓

⚠️ 面试表达：
"我用不变量证明：left 左侧始终 < target，
 right 右侧始终 ≥ target——
 循环结束时两者重合即为答案。"
```

### 5.2 单调性论证（答案二分）

```
答案二分的正确性依赖 check(mid) 的单调性：
  若 mid 可行 → 所有更大的 mid 也可行（最小化问题）
  若 mid 不可行 → 所有更小的 mid 也不可行

→ 可行域是"后缀"（或前缀）→ 分界点 = 答案

⚠️ 面试必答：
"check 单调保证可行/不可行的分界
 存在且唯一——二分能找到它。"
```

### 5.3 复杂度证明

```
每轮区间减半：
  n → n/2 → n/4 → ... → 1
  轮数 = log₂n
  每轮 O(1)（比较/check）

→ O(log n)（答案二分 = O(log 值域 × check 代价)）

⚠️ 面试必答：
"二分 O(log n)——每轮排除一半，
 10⁹ 的数据只需 30 次比较。"
```

## 6. 进阶总结

### 6.1 进阶要点速查

```
① 边界二分：一图四式（lowerBound 是基石）
   "right=mid 配向下取整，left=mid 配向上取整"
② 答案二分：值域二分 + check 单调
   "最小化收 hi，最大化放 lo"
③ 旋转数组：nums[right] 判段（153）
   动态 nums[left] 判段 + 段内比较（33）
④ 峰值：nums[mid+1] 比较（上坡必有顶）
```

### 6.2 面试话术模板

```
"这是【边界/答案/旋转】二分：
 ① 搜索空间【下标/值域】，单调性【...】；
 ② 模板【...】（解释取整方向与保留规则）；
 ③ 正确性：【不变量/单调性】论证；
 ④ 复杂度 O(log n)。
 关键细节：【...】（防溢出/边界/方向）。"
```

### 6.3 易错点清单

| 错误 | 后果 | 修正 |
|------|------|------|
| 两种写法混用 | 死循环 | 选定一种 |
| 取整方向错 | 死循环 | right=mid 配向下 |
| check 不单调 | 答案错 | 先验证单调性 |
| 旋转用 nums[0] | 未旋转误判 | 用 nums[right] |
| mid 溢出 | 越界 | left+(right-left)/2 |

> 🎯 **核心要点**：二分进阶 = **边界体系**（lowerBound/upperBound 一图四式）+ **答案二分**（值域 + check 单调）+ **旋转/峰值**（段判定）。"取整方向配保留规则"是防死循环铁律；不变量/单调性论证是面试正确性表达。
