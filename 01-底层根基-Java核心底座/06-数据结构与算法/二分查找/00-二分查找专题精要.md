## 1. 核心概念

### 1.1 二分的本质

> 二分查找：搜索区间能明确划分为"满足/不满足"两部分（**二段性**）即可二分——数组有序只是最常见的二段性。

```
两类二段性：
  ① 下标单调：有序数组找 target
  ② 答案单调：check(mid) 可行性（答案二分）
    例：875 吃香蕉（速度越大时间越少）

三大模板：
  精确查找：left <= right
  左边界/下界：left < right + right = mid
  右边界：mid 向上取整 + left = mid
```

### 1.2 识别信号

```
"有序数组查找" → 二分（704）
"第一个/最后一个满足条件" → 边界二分（34/278）
"旋转数组" → 二分（33/153）
"最小速度/最大运力" → 答案二分（875/1011）
"峰值/山谷" → 二分（162）

⚠️ 面试必答：
"二分不要求有序，只要求二段性——
 满足/不满足可分。旋转数组、峰值、
 答案二分都不整体有序。"
```

### 1.3 关键细节

```
① mid 防溢出：left + (right - left) / 2
② 两种区间写法不要混用：
   左闭右闭 [L,R]：<= / mid±1
   左闭右开 [L,R)：< / right=mid
③ 边界二分命中后不返回，继续逼近
④ 右边界 mid 必须向上取整（防死循环）
```

## 2. 完整代码模板

### 2.1 基础二分（704）

```java
/**
 * LeetCode 704. 二分查找（左闭右闭模板）
 */
public int search(int[] nums, int target) {
    int left = 0, right = nums.length - 1;
    while (left <= right) {                    // ⚠️ <=：单元素也判断
        int mid = left + (right - left) / 2;   // 防溢出
        if (nums[mid] == target) return mid;
        else if (nums[mid] < target) left = mid + 1;   // mid 已排除
        else right = mid - 1;
    }
    return -1;
}
// 推演 [1,3,5,7,9], target=4：
//   mid=2(5)>4 → right=1；mid=0(1)<4 → left=1
//   mid=1(3)<4 → left=2 > right → -1 ✓
// 复杂度 O(log n)：每轮区间减半
```

### 2.2 左闭右开写法

```java
/**
 * 左闭右开 [left, right)
 * ⚠️ 与左闭右闭的区别：
 *   right = n（不包含）；left < right；right = mid
 */
public int searchHalfOpen(int[] nums, int target) {
    int left = 0, right = nums.length;         // ⚠️ 右开
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] == target) return mid;
        else if (nums[mid] < target) left = mid + 1;
        else right = mid;                      // ⚠️ 右开保留 mid
    }
    return -1;
}
// ⚠️ 两种写法不要混用（混用 = 死循环/漏检）
// 面试推荐左闭右闭（直觉）；边界题用左闭右开（STL 风格）
```

### 2.3 数值二分（69 平方根）

```java
/**
 * LeetCode 69. x 的平方根（整数二分）
 * 找最后一个满足 mid² ≤ x 的 mid
 * ⚠️ mid*mid 可能溢出 → 用 long
 */
public int mySqrt(int x) {
    if (x < 2) return x;

    int left = 1, right = x;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        long square = (long) mid * mid;        // ⚠️ long 防溢出
        if (square == x) return mid;
        else if (square < x) left = mid + 1;
        else right = mid - 1;
    }
    return right;                              // 最后一个 mid² ≤ x
}
// x=8：mid=4(16>8)→right=3；mid=2(4<8)→left=3
//   mid=3(9>8)→right=2 → 返回 2 ✓
```

## 3. 边界二分的细节

### 3.1 lowerBound（第一个 ≥ target）

```java
/**
 * lowerBound：返回第一个 ≥ target 的位置
 * ⚠️ 边界二分的基石（35/34 都用它）
 */
public int lowerBound(int[] nums, int target) {
    int left = 0, right = nums.length;
    while (left < right) {
        int mid = left + (right - left) / 2;   // 向下取整
        if (nums[mid] < target) {
            left = mid + 1;                    // 排除小于段
        } else {
            right = mid;                       // ⚠️ mid 可能是答案
        }
    }
    return left;
}
// 推演 [1,3,5,7], target=5：
//   mid=2(5≥5)→right=2；mid=1(3<5)→left=2 → 返回 2 ✓
// 推演 target=6（不存在）：
//   mid=2(5<6)→left=3；mid=3(7≥6)→right=3 → 返回 3 ✓
//   （返回"插入位置"——35 题直接用）
```

### 3.2 34. 找左右边界

```java
/**
 * LeetCode 34. 在排序数组中查找元素的第一个和最后一个位置
 * 左边界 = lowerBound(target)
 * 右边界 = upperBound(target) - 1
 */
public int[] searchRange(int[] nums, int target) {
    int left = lowerBound(nums, target);
    if (left == nums.length || nums[left] != target) {
        return new int[]{-1, -1};              // 不存在
    }
    int right = upperBound(nums, target) - 1;  // ⚠️ -1
    return new int[]{left, right};
}

private int upperBound(int[] nums, int target) {
    int left = 0, right = nums.length;
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] <= target) left = mid + 1;   // ⚠️ <= 找第一个 >
        else right = mid;
    }
    return left;
}
// [5,7,7,8,8,10], target=8：
//   lowerBound(8)=3；upperBound(8)=5 → [3,4] ✓
// ⚠️ 记忆："左 = lowerBound；右 = upperBound - 1"
```

### 3.3 直接找右边界（向上取整）

```java
/**
 * 直接找右边界（最后一个 = target）
 * ⚠️ 必须 mid 向上取整（防死循环）：
 *   left = mid 时，mid 向下取整可能 = left → 死循环
 */
public int rightBound(int[] nums, int target) {
    int left = 0, right = nums.length - 1;
    while (left < right) {
        int mid = left + (right - left + 1) / 2;   // ⚠️ 向上取整！
        if (nums[mid] > target) right = mid - 1;
        else left = mid;                           // mid 可能是答案
    }
    return nums[left] == target ? left : -1;
}
// 记忆："左边界向下取整 + right=mid；
//       右边界向上取整 + left=mid"
```

## 4. 答案二分详解

### 4.1 答案二分的本质

```
直接求答案难，验证候选答案易：
  在"答案值域"上二分，check(mid) 判断可行性

识别信号：
  "最小 X 使条件成立" / "最大 X 使条件成立"
  例：最小速度（875）、最小运力（1011）

⚠️ 前提：check(mid) 必须单调
  速度越大 → 时间越少（单调）
  → 可二分
```

### 4.2 875. 吃香蕉（答案二分模板）

```java
/**
 * LeetCode 875. 爱吃香蕉的珂珂
 * 值域 [1, max(piles)]，check(mid) = 能否在 h 小时内吃完
 */
public int minEatingSpeed(int[] piles, int h) {
    int maxPile = 0;
    for (int p : piles) maxPile = Math.max(maxPile, p);

    int left = 1, right = maxPile;
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (canFinish(piles, h, mid)) {
            right = mid;                 // 可行 → 尝试更小速度
        } else {
            left = mid + 1;              // 不可行 → 必须更快
        }
    }
    return left;
}

// check 函数：以 speed 速度能否在 h 小时内吃完
private boolean canFinish(int[] piles, int h, int speed) {
    long hours = 0;
    for (int p : piles) {
        hours += (p + speed - 1) / speed;   // ⚠️ 向上取整
        if (hours > h) return false;        // 提前剪枝
    }
    return hours <= h;
}
// 推演 piles=[3,6,7,11], h=8：
//   二分速度：4 可行（8 小时）→ 3 不可行（10 小时）
//   → 答案 4 ✓
// ⚠️ check 用 long 防溢出（hours 可能很大）
```

### 4.3 答案二分的通用模板

```java
/**
 * 答案二分万能模板
 * @param lo 答案下界（最大约束）
 * @param hi 答案上界（总和/最大可能）
 */
public int binarySearchAnswer(int lo, int hi) {
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (check(mid)) {
            hi = mid;            // 最小化：可行收 hi
            // 最大化：lo = mid + 1（可行放 lo）
        } else {
            lo = mid + 1;        // 最小化：不可行放 lo
            // 最大化：hi = mid
        }
    }
    return lo;
}
// check 设计三步：模拟候选 → 统计指标 → 与约束比较
// 应用：875 吃香蕉、1011 运包裹、410 分割数组
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"这是二分问题：搜索空间有单调性（二段性），
 每次排除一半 → O(log n)。
 我用左闭右闭模板：mid 防溢出、
 left<=right 循环、mid 排除后 ±1。
 边界题用 lowerBound/upperBound 组合
 （左 = lowerBound，右 = upperBound-1）。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 二分一定要求有序吗？ | 不——要求二段性（满足/不满足可分） |
| 2 | 为什么 O(log n)？ | 每轮区间减半 → log₂n 轮 |
| 3 | mid 为什么防溢出？ | (left+right)/2 可能溢出 int |
| 4 | 左右边界怎么写？ | lowerBound/upperBound 组合 |
| 5 | 右边界为什么向上取整？ | left=mid 时向下取整会死循环 |
| 6 | 答案二分前提？ | check(mid) 单调（可行性随 mid 单调） |
| 7 | 旋转数组为什么以 right 为基准？ | 未旋转场景也正确（left 会误判） |
| 8 | 循环条件 <= vs <？ | 区间为空定义不同（left>right vs left==right） |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 两种写法混用 | 死循环/漏检 | 选定一种 |
| mid 溢出 | 越界 | left+(right-left)/2 |
| 右边界向下取整 | 死循环 | 向上取整 |
| 边界二分命中即返回 | 找不到边界 | 继续逼近 |
| check 溢出 | 结果错 | long |

> 🎯 **核心要点**：二分 = **二段性识别 + 模板选择**。基础（<=）、边界（lowerBound/upperBound）、答案（check 函数）三模板默写；34/153/875 三道母题吃透，二分全题型可解。面试必答"二段性而非有序"。
