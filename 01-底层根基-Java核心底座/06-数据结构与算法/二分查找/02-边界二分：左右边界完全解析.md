## 1. 为什么需要边界二分

### 1.1 场景引入

```
nums = [1, 2, 3, 3, 3, 4, 5], target = 3

基础二分（704）：可能返回下标 2、3 或 4 中的任意一个（取决于 mid 的走向）
但我们需要的可能是：
  - 第一个 3 的位置 → 2（左边界）
  - 最后一个 3 的位置 → 4（右边界）
```

### 1.2 错误的做法：找到后线性扩展

```java
// ❌ 错误：找到一个后向左/右线性扩展
// 最坏情况全是 target → 时间复杂度退化为 O(n)
// 面试官看到这个解法会直接扣分——二分题要用二分思维解决
```

> 💡 **正确思路**：把"找左右边界"拆成**两次独立的二分**——每次二分仍然是 O(log n)，总复杂度 O(log n)。

## 2. lowerBound：找第一个 ≥ target 的位置

> 这是**所有边界二分的基石**。理解了 lowerBound，左右边界都是它的简单变形。

```java
/**
 * lowerBound：返回第一个 ≥ target 的位置（下标）
 * 若所有元素 < target，返回 nums.length
 *
 * 语义：nums[left] 始终保持 < target，nums[right] 始终保持 ≥ target
 *      （维护"左开右闭"的不变量）
 *
 * 注意：这里用的是左闭右开写法！
 *   right = nums.length（不包含）
 *   while (left < right)
 *   right = mid（mid 可能是答案，不能排除）
 *   mid 向下取整（配合 right = mid 不会死循环）
 */
public int lowerBound(int[] nums, int target) {
    int left = 0, right = nums.length;
    while (left < right) {
        int mid = left + (right - left) / 2;   // 向下取整
        if (nums[mid] < target) {
            left = mid + 1;   // nums[mid] 在"小于"段，排除
        } else {
            right = mid;      // nums[mid] ≥ target，可能是答案，保留
        }
    }
    return left;   // left == right，两者都是答案
}
```

### 不变量推演：nums = [1, 3, 5, 7], target = 5

```
初始:  left=0, right=4
mid=2 → nums[2]=5 ≥ 5 → right=2
mid=1 → nums[1]=3 < 5  → left=2
left=2 == right=2 → 返回 2 ✓ (第一个 ≥5 的位置)

// target=6（不存在）：
mid=2 → nums[2]=5 < 6 → left=3
mid=3 → nums[3]=7 ≥ 6 → right=3
返回 3 ✓ (第一个 ≥6 的位置，即 7 的位置)
```

## 3. upperBound：找第一个 > target 的位置

```java
/**
 * upperBound：返回第一个 > target 的位置（下标）
 * 与 lowerBound 唯一的区别：判断条件变成 nums[mid] <= target 时收缩左侧
 */
public int upperBound(int[] nums, int target) {
    int left = 0, right = nums.length;
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] <= target) {
            left = mid + 1;   // ≤ target 的都在"小于等于"段
        } else {
            right = mid;      // > target，可能是答案
        }
    }
    return left;
}
```

### lowerBound / upperBound 组合用法

```
nums = [1, 2, 3, 3, 3, 4, 5], target = 3

lowerBound(nums, 3) = 2    ← 第一个 ≥3 的位置
upperBound(nums, 3) = 5    ← 第一个 >3 的位置

区间 [lowerBound, upperBound) 内全部等于 target！
→ 左边界 = lowerBound = 2
→ 右边界 = upperBound - 1 = 4

一条公式解决 34 题：
  左边界 = lowerBound(target)
  右边界 = upperBound(target) - 1
```

## 4. 找左边界：第一个等于 target

### 4.1 直接法（mid 向下取整 + right = mid）

```java
/**
 * 找第一个等于 target 的位置，不存在返回 -1
 * 与 lowerBound 唯一的区别：最后要验证 left 位置的元素是否真的等于 target
 */
public int leftBound(int[] nums, int target) {
    int left = 0, right = nums.length;
    while (left < right) {
        int mid = left + (right - left) / 2;  // 向下取整
        if (nums[mid] < target) {
            left = mid + 1;
        } else {
            right = mid;   // ≥ target 都往左收，保证找到第一个
        }
    }
    // 越界或值不等于 target → 不存在
    if (left == nums.length || nums[left] != target) return -1;
    return left;
}
```

### 4.2 命中后不返回的关键

```
nums = [1, 3, 3, 3, 5], target = 3

第一次 mid=2 → nums[2]=3 == target
❌ 错误：立即返回 2
✅ 正确：执行 else 分支 → right = 2 → 继续向左逼近

mid=1 → nums[1]=3 ≥ 3 → right=1
mid=0 → nums[0]=1 < 3 → left=1
left=1 == right=1 → 返回 1 ✓ 第一个 3 的位置
```

## 5. 找右边界：最后一个等于 target

```java
/**
 * 找最后一个等于 target 的位置，不存在返回 -1
 * ⚠️ 注意与左边界的三处不同：
 *   1. mid 向上取整：left + (right - left + 1) / 2
 *   2. 命中后执行 left = mid（向左收缩改为向右）
 *   3. 判断条件反转
 */
public int rightBound(int[] nums, int target) {
    int left = 0, right = nums.length - 1;  // 注意：右闭！
    while (left < right) {
        int mid = left + (right - left + 1) / 2;  // ⚠️ 向上取整，防死循环
        if (nums[mid] > target) {
            right = mid - 1;   // 右半段排除
        } else {
            left = mid;        // ≤ target 都往右收，保证找到最后一个
        }
    }
    if (nums[left] != target) return -1;
    return left;
}
```

### 为什么右边界必须向上取整？

```
nums = [1, 3, 3, 5], target = 3, 初始 left=0, right=3

❌ 向下取整的致命错误：
  mid = (0+3)/2 = 1 → nums[1]=3 ≤ 3 → left = 1
  mid = (1+3)/2 = 2 → nums[2]=3 ≤ 3 → left = 2
  mid = (2+3)/2 = 2 → nums[2]=3 ≤ 3 → left = 2   ← 死循环！
  原因：left=2, right=3 时 mid 向下取整=2 = left，left 不动 → 死循环

✅ 向上取整解决：
  mid = (0+3+1)/2 = 2 → nums[2]=3 ≤ 3 → left = 2
  mid = (2+3+1)/2 = 3 → nums[3]=5 > 3 → right = 2
  left=2 == right=2 → 返回 2 ✓
```

> 🎯 **记忆口诀**：找左边界 → mid 向下取整 + `right=mid`；找右边界 → mid 向上取整 + `left=mid`；循环条件一律 `left < right`，最后用 `nums[left]` 验证。

## 6. 综合实战：34 查找元素的第一个和最后一个位置

### 6.1 题目与完整解法

```java
/**
 * LeetCode 34. 在排序数组中查找元素的第一个和最后一个位置
 * 给你一个按照非递减顺序排列的整数数组 nums，和一个目标值 target。
 * 找出给定目标值在数组中的开始位置和结束位置。
 * 如果数组中不存在目标值，返回 [-1, -1]。
 * 必须设计并实现时间复杂度为 O(log n) 的算法。
 */
public int[] searchRange(int[] nums, int target) {
    int[] result = {-1, -1};
    if (nums.length == 0) return result;

    // 方法一：lowerBound + upperBound 统一思路（推荐，不易错）
    result[0] = lowerBound(nums, target);
    if (result[0] == nums.length || nums[result[0]] != target) {
        return new int[]{-1, -1};       // 不存在
    }
    result[1] = upperBound(nums, target) - 1;
    return result;
}

private int lowerBound(int[] nums, int target) {
    int left = 0, right = nums.length;
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] < target) left = mid + 1;
        else right = mid;
    }
    return left;
}

private int upperBound(int[] nums, int target) {
    int left = 0, right = nums.length;
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] <= target) left = mid + 1;
        else right = mid;
    }
    return left;
}

// 方法二：直接找左右边界（注意右边界 mid 向上取整）
public int[] searchRange_Direct(int[] nums, int target) {
    int left = leftBound(nums, target);
    if (left == -1) return new int[]{-1, -1};
    int right = rightBound(nums, target);
    return new int[]{left, right};
}
```

### 6.2 测试用例演示

```
nums = [5, 7, 7, 8, 8, 10], target = 8
  lowerBound(8) = 3
  upperBound(8) = 5 → 右边界 = 4
  返回 [3, 4] ✓

nums = [5, 7, 7, 8, 8, 10], target = 6
  lowerBound(6) = 3 → nums[3]=8 ≠ 6 → 返回 [-1, -1] ✓

nums = [], target = 0 → 直接返回 [-1, -1] ✓

nums = [2, 2], target = 2
  lowerBound = 0, upperBound = 2 → 右边界 = 1 → [0, 1] ✓
```

### 6.3 面试官可能的追问

| 追问 | 回答 |
|------|------|
| 为什么不能找到一个后线性扩展？ | 全 target 时退化成 O(n)，失去二分的意义 |
| 两个二分能合并成一个吗？ | 逻辑上可以但极容易错，面试建议拆开，代码更清晰 |
| lowerBound 和 upperBound 的本质区别？ | 判断边界处是 `<` 还是 `<=`，决定了左侧段包含什么 |
| 找不到时 left 返回什么？ | lowerBound 返回插入位置（第一个 ≥ target），可用作 35 题的答案 |

## 7. 边界二分的统一思维模型

### 7.1 万能套路：一图记四式

```
                    找第一个 ≥ T   (lowerBound)
while (left < right) {
    int mid = left + (right - left) / 2;         // 向下取整
    if (nums[mid] < T) left = mid + 1;
    else right = mid;
}
return left;

                    找第一个 > T   (upperBound)
把 < T 改成 <= T 即可。

                    找第一个 == T  (左边界)
lowerBound + 末尾验证 nums[left] == T

                    找最后一个 == T  (右边界)
mid 向上取整 + 条件反转 + 末尾验证
```

### 7.2 变形题一网打尽

| 题目 | 本质 | 一句解法 |
|:---:|------|------|
| 35. 搜索插入位置 | lowerBound 直接返回 | `return lowerBound(nums, target)`（无需验证！） |
| 34. 查找元素位置 | lowerBound + upperBound | 左 = lowerBound，右 = upperBound-1 |
| 278. 第一个错误版本 | lowerBound（isBadVersion） | `if (!isBad(mid)) left=mid+1; else right=mid` |
| 69. x 的平方根 | 找最后一个 mid² ≤ x | 右边界变形：`if (mid² > x) right=mid-1; else left=mid` |
| 744. 找最小的大于 target 的字母 | upperBound | `lowerBound 变体：nums[mid] <= target → left` |

> 🎯 **核心要点**：所有边界二分本质上都是 lowerBound/upperBound 的变形。面试中记住两件事——**`right=mid` 意味着 mid 可能是答案不能排除**（所以要 `left<right` 循环 + mid 向下取整），**`left=mid` 意味着 mid 可能是答案**（所以要向上取整防死循环）。最后用 lowerBound 验证 + upperBound 减一的组合，可以通吃一切边界题。
