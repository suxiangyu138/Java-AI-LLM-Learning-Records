## 1. 知识体系导图

```
二分查找 (Binary Search)
│
├── 核心本质 ──────────────────────────────────────────────
│   ├── 不是"数组有序"，而是"二段性"（单调性）
│   ├── 数组单调：有序数组中找 target
│   ├── 答案单调：check(mid) 满足/不满足的临界点
│   └── 前提：搜索区间可明确划分"满足"与"不满足"两部分
│
├── 基础模板 ──────────────────────────────────────────────
│   ├── 左闭右闭 [left, right]：while(left <= right)
│   ├── 左闭右开 [left, right)：while(left < right), right = mid
│   ├── mid 防溢出：left + (right - left) / 2
│   └── 区间收缩：mid 已排除则 ±1，可能为答案则保留
│
├── 边界二分（面试真正的难点）─────────────────────────────
│   ├── 找左边界 (第一个 target)：mid 向下取整 + right = mid
│   ├── 找右边界 (最后一个 target)：mid 向上取整 + left = mid
│   ├── lowerBound/upperBound 统一思路
│   └── 命中后不直接返回，继续逼近
│
├── 经典变形 ──────────────────────────────────────────────
│   │
│   ├── 🟢 基础型
│   │   ├── 704. 二分查找（模板题）
│   │   └── 35. 搜索插入位置（找第一个 ≥ target）
│   │
│   ├── 🟡 边界型
│   │   ├── 34. 第一个和最后一个位置（左右边界合一）
│   │   ├── 278. 第一个错误版本（二段性本质）
│   │   └── 33. 搜索旋转排序数组（先定段再二分）
│   │
│   ├── 🟡 旋转数组型
│   │   ├── 153. 旋转数组最小值（以 nums[right] 为基准）
│   │   ├── 33. 无重复旋转搜索
│   │   └── 81. 含重复旋转搜索（退化 O(n) 场景）
│   │
│   ├── 🟡 峰值型
│   │   ├── 162. 寻找峰值（比较 mid 与 mid+1）
│   │   └── 852. 山脉数组峰顶索引
│   │
│   ├── 🟡 答案二分（check 函数型）
│   │   ├── 875. 爱吃香蕉的珂珂（最小速度）
│   │   ├── 1011. 在 D 天内送达包裹（最小运力）
│   │   ├── 410. 分割数组的最大值
│   │   └── 1283. 使结果不超过阈值的最小除数
│   │
│   └── 🟡 数值计算型
│       ├── 69. x 的平方根（整数二分）
│       └── 367. 有效的完全平方数
│
└── Java 实战 ──────────────────────────────────────────────
    ├── 模板一：查找精确值 (704)
    ├── 模板二：lowerBound 找左边界 (34)
    ├── 模板三：upperBound 找右边界 (34)
    ├── 模板四：答案二分 check 函数 (875)
    └── 面试话术：先搜索空间 → 单调性 → 区间含义 → 更新规则
```

## 4. 核心概念速查

| 概念 | 一句话解释 | 典型例题 |
|------|-----------|------|
| **二段性（单调性）** | 区间能明确分为"满足/不满足"两部分，二分成立的根本前提 | 所有二分题 |
| **左闭右闭** | `[left, right]` 区间，`while(left<=right)`，mid 排除后 ±1 | 704. 二分查找 |
| **左闭右开** | `[left, right)` 区间，`while(left<right)`，`right=mid` | STL lower_bound |
| **mid 防溢出** | `left + (right-left)/2` 而非 `(left+right)/2` | 所有题 |
| **左边界** | 第一个等于 target 的位置，mid 向下取整 + `right=mid` | 34. 左半部分 |
| **右边界** | 最后一个等于 target 的位置，mid 向上取整 + `left=mid` | 34. 右半部分 |
| **lowerBound** | 第一个 ≥ target 的位置（万能边界思路） | 35. 插入位置 |
| **upperBound** | 第一个 > target 的位置 | 34 的右边界实现 |
| **答案二分** | 答案在值域上二分，check(mid) 判断可行性 | 875. 珂珂吃香蕉 |
| **check 函数** | 验证候选解是否可行的模拟函数，是答案二分的灵魂 | 1011. 运包裹 |
| **旋转数组** | 有序数组旋转后仍是"两段有序"，以端点判断段 | 153/33/81 |
| **单调性退化** | 大量重复元素导致同时收缩，最坏 O(n) | 81. 旋转搜索 II |

## 6. 复杂度速查表

| 问题 | 时间复杂度 | 空间复杂度 | 关键技巧 |
|------|:---:|:---:|------|
| 基础二分 (704) | O(log n) | O(1) | 左闭右闭模板 |
| 左右边界 (34) | O(log n) | O(1) | 拆两次二分，各自独立 |
| 插入位置 (35) | O(log n) | O(1) | lowerBound 直接返回 |
| x 的平方根 (69) | O(log x) | O(1) | 整数二分 + mid² 防溢出 |
| 旋转数组最小值 (153) | O(log n) | O(1) | 以 nums[right] 为基准 |
| 旋转数组搜索 (33) | O(log n) | O(1) | 先定段再二分 |
| 旋转数组搜索 II (81) | O(log n)~**O(n)** | O(1) | 重复时左右同时收缩 |
| 寻找峰值 (162) | O(log n) | O(1) | 比较 mid 与 mid+1 |
| 珂珂吃香蕉 (875) | O(n log W) | O(1) | 答案二分 + 每小时吃速 check |
| 运送包裹 (1011) | O(n log S) | O(1) | 天数可行性 check |
