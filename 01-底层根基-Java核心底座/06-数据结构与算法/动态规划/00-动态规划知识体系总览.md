## 4. 核心概念速查

| 概念 | 一句话解释 | 典型例题 |
|------|-----------|------|
| **最优子结构** | 大问题的最优解包含子问题的最优解 | 最短路径、背包 |
| **重叠子问题** | 递归树中反复出现相同子问题 | 斐波那契、爬楼梯 |
| **无后效性** | 当前状态确定后，后续决策不受之前路径影响 | 所有 DP 问题前提 |
| **记忆化搜索** | 递归 + 缓存，自顶向下 | DFS + HashMap/数组 |
| **表格递推** | 循环填表，自底向上 | for 循环 dp 数组 |
| **状态定义** | `dp[i][j]` 代表什么含义 | 核心难点 |
| **状态转移方程** | `dp[i] = f(dp[i-1], dp[i-2], ...)` | DP 问题的灵魂 |
| **滚动数组** | 只保留必要的历史状态，降维 | `dp[i%2]` 或 `prev/curr` |
| **逆序遍历** | 0/1 背包防止物品重复使用 | `for j = target...nums[i]` |
| **正序遍历** | 完全背包允许物品重复使用 | `for j = nums[i]...target` |
| **状态压缩** | 用位掩码 (bitmask) 表示集合状态 | TSP 旅行商问题 |
| **区间 DP** | `dp[i][j]` 表示 `[i,j]` 区间的最优解 | 回文子串、石子合并 |

## 6. 复杂度速查表

| 问题 | 时间复杂度 | 空间复杂度 | 空间优化后 | 关键技巧 |
|------|:---:|:---:|:---:|------|
| 斐波那契 (DP) | O(n) | O(n) | **O(1)** | 只保留前两个状态 |
| 0/1 背包 | O(n×W) | O(n×W) | **O(W)** | 逆序遍历 |
| 完全背包 | O(n×W) | O(n×W) | **O(W)** | 正序遍历 |
| LCS | O(m×n) | O(m×n) | **O(min(m,n))** | 滚动数组取两行 |
| LIS | O(n²) / **O(n log n)** | O(n) | O(n) | 贪心 + 二分 |
| 编辑距离 | O(m×n) | O(m×n) | **O(min(m,n))** | 滚动数组 |
| 最长回文子串 | O(n²) | O(n²) / **O(1)** | O(1) | 中心扩展法 |
| 石子合并 | O(n³) | O(n²) | O(n²) | 区间 DP + 前缀和 |
| TSP (状态压缩) | O(n²×2ⁿ) | O(n×2ⁿ) | — | 位掩码枚举子集 |
