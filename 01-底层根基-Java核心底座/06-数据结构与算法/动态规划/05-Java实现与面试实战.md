## 2. 大厂面试 DP 解题话术

面试中 DP 题的关键不是默默写完代码，而是**让面试官跟随你的思路**。下面是对应五步法的标准话术模板。

### 2.1 通用话术模板

```
📣 第 1 步：识别与分析 (30秒)
"这道题有重叠子问题的特征——比如我们在计算较大输入时，会反复计算
相同的子问题。而且问题有最优子结构：全局最优解可以由子问题最优解推导出来。
所以我们可以用动态规划来解决。"

📣 第 2 步：状态定义 (30秒)
"我定义 dp[i] 表示...（一句话精确描述）。状态是 X 维度，因为...（解释为什么）"

📣 第 3 步：状态转移方程 (60秒) ⭐ 最关键
"对于状态 i，我们有以下选择：
 - 选择 A... → 转移来源是 dp[j]
 - 选择 B... → 转移来源是 dp[k]
所以 dp[i] = max/min(选择A对应的值, 选择B对应的值)
我可以在白板上画一下转移示意图..."

📣 第 4 步：Base Case 与边界 (15秒)
"最小子问题：当 i=0 时，dp[0] = ..."
"边界情况：数组长度为 0 或 1 时..."

📣 第 5 步：计算顺序与复杂度 (15秒)
"遍历顺序：i 从 1 到 n，时间复杂度 O(n)，空间复杂度 O(n)。
如果面试官要求优化，可以用滚动数组/两个变量降到 O(1)。"

📣 写代码时边说边写 (2-3分钟)
"我先用最清晰的写法实现 2D 版本，再展示优化..."
```

### 2.2 实战演示：以「零钱兑换」(322) 为例

> 以下是在面试中逐句演示的完整过程

```
面试官：给定不同面额硬币 coins 和总金额 amount，求最少硬币数。
       如果无法凑出返回 -1。每种硬币数量无限。

你："好的。首先识别——这是个 DP 问题。因为：
      凑 amount=11 的最优解可以用凑 amount=10 的答案推出来——重叠子问题。

      我定义 dp[i] = 凑出金额 i 所需的最少硬币数。

      转移方程：
        对每个硬币 coin，我们有两种选择：
        - 不用这个硬币 → dp[i] 保持不变
        - 用这个硬币   → dp[i - coin] + 1（凑 i-coin 后加一枚）
        所以 dp[i] = min(dp[i], dp[i-coin]+1)  对每个 coin

      Base Case：dp[0] = 0（凑 0 元需要 0 枚）
      其他初始化为 amount+1（一个不可能的值，方便取 min）

      遍历顺序：这是个完全背包（硬币无限），所以硬币内层正序遍历。
      先遍历硬币再遍历金额。

      复杂度：O(n × amount)，空间 O(amount)。"
```

> 🎯 **关键**：不要说"我直接用最优版本"，先说直观版本，再逐步优化——这展示的是**工程思维**。

## 3. Java DP 编码规范与优化清单

### 3.1 编码规范

```java
/**
 * 好的 DP 代码示例：清晰的命名、注释、边界处理
 *
 * Problem: 零钱兑换 (LeetCode 322)
 * Time: O(n × amount), Space: O(amount)
 */
public int coinChange(int[] coins, int amount) {
    // 1. 边界处理
    if (amount == 0) return 0;

    // 2. DP 数组定义：dp[i] = 凑出金额 i 的最少硬币数
    int max = amount + 1;
    int[] dp = new int[amount + 1];
    Arrays.fill(dp, max);
    dp[0] = 0;  // Base Case

    // 3. 状态转移：完全背包
    for (int coin : coins) {                    // 外层：每种硬币
        for (int j = coin; j <= amount; j++) {  // 内层：正序遍历容量
            dp[j] = Math.min(dp[j], dp[j - coin] + 1);
        }
    }

    // 4. 返回结果
    return dp[amount] > amount ? -1 : dp[amount];
}
```

### 3.2 优化等级清单

```java
// Level 0: 记忆化搜索 (快速验证思路)
// Level 1: 完整 2D/1D DP 数组 (清晰但非最优空间)
// Level 2: 滚动数组优化 (2D → 两行，1D → 两个变量)
// Level 3: O(1) 空间或高级优化 (Kadane, tails + 二分...)

// 面试策略：先写 Level 1 确保正确，面试官要求优化时再升到 Level 2/3
```

### 3.3 面试中必须准备的优化

| 原始写法 | 优化后 | 怎么解释 |
|------|------|------|
| `int[] dp = new int[n]` | 两个变量 `prev, curr` | "dp[i] 只依赖 dp[i-1] 和 dp[i-2]，所以只保留前两个状态" |
| `int[][] dp = new int[m][n]` | `int[2][n]` 交替 | "每行只依赖上一行，滚动数组" |
| `int[][] dp` 背包 2D | `int[] dp` 逆序遍历 | "内层逆序保证 dp[j-w] 来自上一轮" |
| LIS O(n²) | O(n log n) tails + 二分 | "贪心维护各长度最小末尾，tails 单调可二分" |

## 4. 高频题深度复盘（含面试追问）

### 4.1 最大子序和 (53) — 最常考

```java
public int maxSubArray(int[] nums) {
    int maxEndingHere = nums[0]; // dp[i]
    int maxSoFar = nums[0];      // 全局最优
    for (int i = 1; i < nums.length; i++) {
        maxEndingHere = Math.max(nums[i], maxEndingHere + nums[i]);
        maxSoFar = Math.max(maxSoFar, maxEndingHere);
    }
    return maxSoFar;
}
```

**常见面试追问**：

| 追问 | 回答要点 |
|------|------|
| 如何返回子数组本身？ | 维护 `start/end` 指针，当 `maxEndingHere` 重置为 `nums[i]` 时更新起点 |
| 有负数怎么办？ | Kadane 天然支持——`max(nums[i], dp[i-1]+nums[i])` 自动决定是否"另起炉灶" |
| 分治法怎么做？ | O(n log n)：跨中点的最大和 = 左半最大后缀 + 右半最大前缀 |
| 全负数数组呢？ | 正确返回最大负数（非 0），因为 Kadane 的 base 取的是 `nums[0]` |

### 4.2 编辑距离 (72) — 字节最爱

```java
public int minDistance(String word1, String word2) {
    int m = word1.length(), n = word2.length();
    int[][] dp = new int[m + 1][n + 1];

    for (int i = 0; i <= m; i++) dp[i][0] = i;  // 全删除
    for (int j = 0; j <= n; j++) dp[0][j] = j;  // 全插入

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                dp[i][j] = dp[i - 1][j - 1];      // 字符相同 → 免费
            } else {
                dp[i][j] = 1 + Math.min(
                    Math.min(dp[i - 1][j],         // 删 word1[i-1]
                             dp[i][j - 1]),       // 插入 word2[j-1]
                    dp[i - 1][j - 1]              // 替换
                );
            }
        }
    }
    return dp[m][n];
}
```

**常见面试追问**：

| 追问 | 回答要点 |
|------|------|
| 怎么返回操作序列？ | 反向追溯 dp 表：从 `dp[m][n]` 出发，看三个方向哪个给出了最小值，记录操作 |
| 三操作各自对应什么？ | 删 = 下移（i-1），插 = 右移（j-1），替 = 对角移（i-1, j-1）|
| LCS 和编辑距离的关系？ | 只能插/删时：编辑距离 = m+n-2×LCS（见 03 模块的证明） |
| 每个操作的代价不同怎么办？ | 只需把 `1+min(...)` 中的 1 替换为各操作的对应代价 |

### 4.3 分割等和子集 (416) — 背包入门必考

```java
// 核心：判断能否从数组中选出子集，使得和 = sum/2
// 转化为 0/1 背包可行性问题
public boolean canPartition(int[] nums) {
    int sum = 0;
    for (int x : nums) sum += x;
    if (sum % 2 != 0) return false;  // 奇数和不可能平分

    int target = sum / 2;
    boolean[] dp = new boolean[target + 1];
    dp[0] = true;  // 和为 0 总可以（不选任何元素）

    for (int num : nums) {
        for (int j = target; j >= num; j--) {  // 逆序：0/1背包
            dp[j] = dp[j] || dp[j - num];
        }
    }
    return dp[target];
}
```

### 4.4 二叉树最大路径和 (124) — 树形 DP 最高频

```java
// 关键心智模型：后序遍历返回"单边最大贡献"
// 全局答案 = 左单边 + 当前节点 + 右单边
int maxSum = Integer.MIN_VALUE;

public int maxPathSum(TreeNode root) {
    maxGain(root);
    return maxSum;
}

private int maxGain(TreeNode node) {
    if (node == null) return 0;
    // 负数贡献直接舍弃——和 0 取 max
    int leftGain = Math.max(0, maxGain(node.left));
    int rightGain = Math.max(0, maxGain(node.right));

    // 全局路径：可以走左右两边
    maxSum = Math.max(maxSum, leftGain + node.val + rightGain);

    // 返回：只能选一边向上贡献给父节点
    return node.val + Math.max(leftGain, rightGain);
}
```

**记忆口诀**：`后序遍历·左 max(0,left)·右 max(0,right)·全局=左+中+右·返回=中+max(左,右)`

## 6. 常见错误与调试技巧

### 6.1 DP 代码调试三步法

```
1. 打印 DP 表（小数据）：System.out.println(Arrays.toString(dp));
   观察表格是否符合预期——通常第一行/第一列就能暴露初始化错误

2. 手动运行 n=1,2,3 的 case：确保边界不出问题

3. 对比记忆化搜索的结果：用暴力递归验证递推版本的正确性
   → 如果一致，说明递推的遍历方向和状态定义是正确的
```

### 6.2 高频 Bug 速查

| Bug | 常见原因 | 修复 |
|------|------|------|
| `ArrayIndexOutOfBounds` | 未处理 n=0 或 i-2 越界 | 加 `if (n==0) return 0` 等前置判断 |
| 结果偏大/偏小 | Base Case 或 ∞ 初始化值不够大 | INF = `Integer.MAX_VALUE / 2` 防溢出 |
| 完全背包结果不对 | 正序/逆序搞反了 | 检查：无限选→正序，选一次→逆序 |
| 滚动数组结果错误 | `i%2` 和 `(i-1)%2` 写反 | 用 `cur/prev` 变量名代替 `i%2` |
| 打印 dp 表全是 0 | 忘了写状态转移 | 检查循环体内有没有对 `dp[i]` 赋值 |
| 答案总是 0 | 返回了 `dp[0]` 而非 `dp[n]` | 确认最终答案在 dp 数组的哪个位置 |

> 🎯 **核心要点**：大厂 DP 面试已经不再满足于"能写出代码"——你要在 15 分钟内完成从**问题识别 → 状态定义 → 转移推导 → 编码实现 → 复杂度分析 → 空间优化**的全链路演示。把五步法内化为本能，把 Top 10 题的题解练到闭眼能写，DP 反而会成为你最稳的得分项。
