## 1. 核心概念

### 1.1 什么是动态规划

> 动态规划（DP）：把大问题分解为**重叠的子问题**，缓存子问题解避免重复计算。DP = 记忆化搜索 → 表格递推。

```
三大性质：
  ① 最优子结构：大问题最优解含子问题最优解
  ② 重叠子问题：子问题被反复计算（DP 的价值）
  ③ 无后效性：状态确定后与历史路径无关

DP vs 贪心：贪心不可反悔，DP 可回退
DP vs 分治：DP 子问题重叠，分治子问题独立
```

### 1.2 识别信号

```
"求最大/最小/多少种方案/能否达到" + 有重叠子问题
→ DP 候选

⚠️ 反例识别：
  局部最优不影响全局 → 贪心更简单
  输出所有方案 → 回溯
  子问题独立不重叠 → 分治

⚠️ 面试第一句：
"这题有重叠子问题和最优子结构 →
 可以用动态规划。"
```

### 1.3 题型全景

```
① 一维线性 DP：爬楼梯、打家劫舍、最大子序和
② 序列 DP：LIS、LCS、编辑距离
③ 背包：0/1、完全、多重
④ 区间 DP：回文、石子合并
⑤ 树形 DP：打家劫舍 III
⑥ 状态压缩 DP：TSP（位掩码）
⑦ 数位 DP：按位统计
```

## 2. 五步解题法

### 2.1 五步框架（面试万能公式）

```
① 识别状态：什么在子问题间变化？
② 定义 dp：一句话描述 dp[...] 的含义
   ⚠️ 必须写注释："dp[i] 表示..."
③ 写转移方程：dp[当前] = f(dp[历史])
   ⚠️ 解释每个转移来源的含义
④ 确定 base case：最小子问题的答案
   ⚠️ 手动验证 n=0,1,2
⑤ 确定计算顺序与输出：遍历方向 + 答案位置
```

### 2.2 状态定义的模式

```java
// 模式 A：以 i 结尾（1D 最常用）
dp[i] = 以 arr[i] 结尾的某个最优值
  // LIS、最大子序和

// 模式 B：考虑前 i 个元素
dp[i] = 考虑 arr[0..i-1] 的某个最优值
  // 背包、打家劫舍

// 模式 C：双序列对应
dp[i][j] = s1[0..i-1] 与 s2[0..j-1] 的关系
  // LCS、编辑距离

// 模式 D：区间
dp[i][j] = arr[i..j] 上的最优值
  // 区间 DP

// 模式 E：选/不选（状态机）
dp[i][0/1] = 第 i 个位置选/不选的某个值
  // 打家劫舍、股票
```

### 2.3 面试表达模板

```
"定义 dp[i] = ...（一句话精确描述），
 转移是 dp[i] = max(...)，因为【解释】，
 base case 是 dp[0] = ...，
 计算顺序从 1 到 n（依赖方向），
 答案在 dp[n]。
 复杂度 O(n) 时间 O(n) 空间，
 可以滚动优化到 O(1)。"
```

## 3. 完整代码模板

### 3.1 198. 打家劫舍（一维 DP 母题）

```java
/**
 * LeetCode 198. 打家劫舍
 * 相邻房子不能都偷 → 选/不选状态机
 *
 * dp[i] = 偷前 i 个房子的最高金额
 * 转移：dp[i] = max(dp[i-1],        // 不偷第 i 个
 *                   dp[i-2] + nums[i])  // 偷第 i 个
 */
public int rob(int[] nums) {
    if (nums.length == 1) return nums[0];

    int prev2 = nums[0];                        // dp[i-2]
    int prev1 = Math.max(nums[0], nums[1]);     // dp[i-1]

    for (int i = 2; i < nums.length; i++) {
        int curr = Math.max(prev1, prev2 + nums[i]);
        prev2 = prev1;                          // 滚动
        prev1 = curr;
    }
    return prev1;                               // 输出
}
// 推演 [2,7,9,3,1]：
//   prev2=2, prev1=7
//   i=2: max(7, 2+9)=11 → prev2=7, prev1=11
//   i=3: max(11, 7+3)=11 → prev2=11, prev1=11
//   i=4: max(11, 11+1)=12 → 答案 12 ✓
```

### 3.2 1143. LCS（双序列模板）

```java
/**
 * LeetCode 1143. 最长公共子序列
 * dp[i][j] = text1[0..i-1] 与 text2[0..j-1] 的 LCS
 *
 * 转移：
 *   相等 → dp[i-1][j-1] + 1（对角）
 *   不等 → max(dp[i-1][j], dp[i][j-1])
 */
public int longestCommonSubsequence(String text1, String text2) {
    int m = text1.length(), n = text2.length();
    int[][] dp = new int[m + 1][n + 1];

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }
    return dp[m][n];
}
// O(mn) 时间 O(mn) 空间（可滚动到 O(min(m,n))）
// 面试追问：如何输出 LCS 序列？→ 反向追溯 dp 表
```

### 3.3 322. 零钱兑换（完全背包模板）

```java
/**
 * LeetCode 322. 零钱兑换
 * 硬币无限 → 完全背包
 * dp[i] = 凑出金额 i 的最少硬币数
 */
public int coinChange(int[] coins, int amount) {
    int[] dp = new int[amount + 1];
    Arrays.fill(dp, amount + 1);     // ⚠️ 不可能的大数
    dp[0] = 0;

    for (int coin : coins) {                    // 外层硬币
        for (int j = coin; j <= amount; j++) {  // ⚠️ 正序（完全背包）
            dp[j] = Math.min(dp[j], dp[j - coin] + 1);
        }
    }
    return dp[amount] > amount ? -1 : dp[amount];
}
// ⚠️ 0/1 背包逆序 vs 完全背包正序（见背包专题）
// 推演 coins=[1,2,5], amount=11 → 3（5+5+1）
```

## 4. DP 的空间优化

### 4.1 滚动数组的三种写法

```java
// ═══════════ 写法一：双变量（1D 最常用）══════════
// dp[i] 只依赖 dp[i-1]/dp[i-2]
int prev2 = ..., prev1 = ...;
for (int i = 2; i < n; i++) {
    int curr = f(prev2, prev1);
    prev2 = prev1;
    prev1 = curr;
}

// ═══════════ 写法二：交替行（2D → 两行）══════════
int[][] dp = new int[2][n + 1];
for (int i = 1; i <= m; i++) {
    for (int j = 0; j <= n; j++) {
        dp[i % 2][j] = f(dp[(i - 1) % 2][j], ...);
    }
}

// ═══════════ 写法三：逆序覆盖（背包 2D → 1D）══════
// 0/1 背包必须逆序（防重复使用）
int[] dp = new int[W + 1];
for (int item : items) {
    for (int j = W; j >= weight; j--) {   // ⚠️ 逆序！
        dp[j] = Math.max(dp[j], dp[j - weight] + value);
    }
}
```

### 4.2 空间优化的判断

```
什么时候能优化？
  dp[i] 只依赖"有限个历史状态"
  → 可以用变量/滚动数组替代完整数组

⚠️ 面试策略：
  先写完整数组（正确性优先）
  面试官要求优化时再展示滚动
  "我可以把空间从 O(n) 优化到 O(1)"（加分）
```

### 4.3 常见错误

```
① 状态定义模糊 → 先写注释
② base case 遗漏 → 手动跑 n=0,1,2
③ 遍历顺序错误 → 画表验证依赖方向
④ 背包方向写反 → 0/1 逆序、完全正序
⑤ 溢出 → long / 取模
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"这题是 DP：定义 dp[i] = ...（一句话），
 转移 dp[i] = max(...)（解释每个来源），
 base case dp[0] = ...。
 计算顺序从 1 到 n（依赖方向）。
 复杂度 O(n) 时间 O(n) 空间，
 滚动优化到 O(1)。
 先写记忆化验证思路，再转表格优化空间。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 先记忆化还是表格？ | 记忆化验证思路；表格优化空间（等价） |
| 2 | 怎么确定遍历顺序？ | 保证依赖的状态先计算（画表验证） |
| 3 | 空间优化？ | 只依赖有限历史 → 滚动数组 |
| 4 | 背包为什么逆序/正序？ | 0/1 防重复；完全允许重复 |
| 5 | 状态定义怎么想？ | 子问题间"变化的是什么" |
| 6 | 与贪心区别？ | 贪心不可反悔；DP 比较所有子问题 |
| 7 | 与回溯区别？ | DP 求最优/计数；回溯枚举所有方案 |
| 8 | 结果溢出？ | long / 取模（组合计数） |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 状态定义模糊 | 转移写不出 | 先写注释 |
| base case 遗漏 | 结果错 | 手动跑小 n |
| 遍历方向反 | 依赖未算 | 画表验证 |
| 背包正逆搞混 | 结果错 | 0/1 逆、完全正 |
| 忘空间优化 | 空间浪费 | 滚动数组 |

> 🎯 **核心要点**：DP 五步法（状态/定义/转移/边界/顺序）是万能框架。**背包**（逆序 vs 正序）、**序列 DP**（LIS/LCS）、**滚动数组**（空间优化）是三大高频考点。母题爬楼梯练熟后，DP 题就是"识别类型 → 套模板"的流程。
