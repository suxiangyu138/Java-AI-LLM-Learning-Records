## 1. 线性 DP 的定义与分类

> 线性 DP 是指状态转移沿着一维或二维序列线性推进的动态规划，是所有 DP 问题中占比最大的一类。

```
线性 DP 分类图谱：

一维线性 DP（dp[i]）
├── 递推型：dp[i] = f(dp[i-1], dp[i-2], ...)    → Fibonacci, 爬楼梯
├── 决策型：dp[i] = max/min(抉择1, 抉择2, ...)    → 打家劫舍, 股票
└── 划分型：dp[i] = max_{j<i} f(dp[j], ...)      → LIS, 单词拆分

二维线性 DP（dp[i][j]）
├── 双序列型：s1[0..i] 与 s2[0..j] 的关系       → LCS, 编辑距离
├── 区间型：arr[i..j] 上的最优决策               → 回文子串
└── 网格型：grid[i][j] 路径决策                  → 最小路径和
```

| 问题 | 状态维度 | 时间复杂度 | 空间优化 | 面试频率 |
|------|:---:|:---:|------|:---:|
| LIS | 1D | O(n²) → **O(n log n)** | O(n) | ⭐⭐⭐⭐⭐ |
| LCS | 2D | O(m×n) | O(min(m,n)) | ⭐⭐⭐⭐⭐ |
| 编辑距离 | 2D | O(m×n) | O(min(m,n)) | ⭐⭐⭐⭐⭐ |
| 最大子序和 | 1D | O(n) | O(1) | ⭐⭐⭐⭐ |
| 打家劫舍 | 1D | O(n) | O(1) | ⭐⭐⭐⭐ |
| 股票买卖 | 1D+状态 | O(n) / O(n×k) | O(1)/O(k) | ⭐⭐⭐⭐ |

## 2. 最长递增子序列 LIS

### 2.1 O(n²) 标准解法

```java
// dp[i] = 以 nums[i] 结尾的最长递增子序列长度
// 转移：dp[i] = max(1, max_{j<i, nums[j]<nums[i]} (dp[j] + 1))
public int lengthOfLIS(int[] nums) {
    int n = nums.length;
    int[] dp = new int[n];
    Arrays.fill(dp, 1);         // 每个元素自身构成长度为 1 的 LIS
    int maxLen = 1;

    for (int i = 0; i < n; i++) {
        for (int j = 0; j < i; j++) {
            if (nums[j] < nums[i]) {
                dp[i] = Math.max(dp[i], dp[j] + 1);
            }
        }
        maxLen = Math.max(maxLen, dp[i]);
    }
    return maxLen;
}
```

### 2.2 O(n log n) 贪心+二分优化 ⭐

```java
/**
 * 核心思想：维护一个 tails 数组，tails[i] = 长度为 i+1 的递增子序列的
 *           最小末尾值。tails 一定是严格递增的，可以在 tails 中二分查找。
 *
 * 直观理解：我们不是记录所有子序列，而是维护当前各种长度中
 *           "末尾值最小"的那一个——越小，越容易被后续元素扩展。
 */
public int lengthOfLIS_Optimized(int[] nums) {
    int[] tails = new int[nums.length];
    int len = 0;                          // 当前最长 LIS 长度

    for (int x : nums) {
        // 在 tails[0..len-1] 中二分查找第一个 ≥ x 的位置
        int lo = 0, hi = len;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (tails[mid] < x) lo = mid + 1;
            else hi = mid;
        }
        tails[lo] = x;                      // 替换或追加
        if (lo == len) len++;               // 扩展了 LIS 长度
    }
    return len;
}
// 演示：nums = [10,9,2,5,3,7,101,18]
// 10 → tails=[10], len=1
//  9 → tails=[9],  len=1   (替换 10)
//  2 → tails=[2],  len=1   (替换 9)
//  5 → tails=[2,5], len=2  (扩展)
//  3 → tails=[2,3], len=2  (替换 5)
//  7 → tails=[2,3,7], len=3
// 101→ tails=[2,3,7,101], len=4
// 18 → tails=[2,3,7,18], len=4 (替换 101)
```

> 🎯 **面试要点**：面试官可能会让你先写 O(n²) 版本，再追问能否优化。然后展示 O(n log n) 的贪心+二分解法——这通常是从"通过"到"优秀"的分水岭。

### 2.3 LIS 衍生题型

| 题目 | 技巧 |
|------|------|
| 最长递增子序列个数 (673) | 额外维护 `count[]` 记录方案数 |

## 3. 最长公共子序列 LCS

### 3.1 经典解法

```java
/**
 * dp[i][j] = text1[0..i-1] 与 text2[0..j-1] 的 LCS 长度
 * 转移：
 *   若 text1[i-1] == text2[j-1] → dp[i][j] = dp[i-1][j-1] + 1
 *   否则 → dp[i][j] = max(dp[i-1][j], dp[i][j-1])
 */
public int longestCommonSubsequence(String text1, String text2) {
    int m = text1.length(), n = text2.length();
    int[][] dp = new int[m + 1][n + 1];

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }
    return dp[m][n];
}
```

### 3.2 空间优化版（滚动数组）

```java
// 只依赖上一行和当前行左侧 → 用两行交替
public int longestCommonSubsequence_SpaceOpt(String t1, String t2) {
    int m = t1.length(), n = t2.length();
    int[][] dp = new int[2][n + 1];
    for (int i = 1; i <= m; i++) {
        int cur = i % 2, prev = 1 - cur;
        for (int j = 1; j <= n; j++) {
            if (t1.charAt(i - 1) == t2.charAt(j - 1))
                dp[cur][j] = dp[prev][j - 1] + 1;
            else
                dp[cur][j] = Math.max(dp[prev][j], dp[cur][j - 1]);
        }
    }
    return dp[m % 2][n];
}
```

### 3.3 LCS 与 LIS 的关系

```
当两个序列一个是 [1..n] 的排列、另一个是其重排时：
LCS 可以转化为 LIS —— 将 t2 中的每个元素映射为其在 t1 中的位置，
然后求映射数组的 LIS，复杂度 O(n log n)
```

## 4. 编辑距离

### 4.1 完整实现

```java
/**
 * 编辑距离（Levenshtein Distance）：将 word1 转换为 word2 的最少操作数
 * 允许操作：插入一个字符、删除一个字符、替换一个字符
 *
 * dp[i][j] = word1[0..i-1] → word2[0..j-1] 的最少操作数
 * 转移：
 *   若 word1[i-1] == word2[j-1] → dp[i][j] = dp[i-1][j-1]        (跳过)
 *   否则 → dp[i][j] = 1 + min(
 *            dp[i-1][j],    ← 删除 word1[i-1]
 *            dp[i][j-1],    ← 在 word1 末尾插入 word2[j-1]
 *            dp[i-1][j-1]   ← 替换 word1[i-1] → word2[j-1]
 *          )
 */
public int minDistance(String word1, String word2) {
    int m = word1.length(), n = word2.length();
    int[][] dp = new int[m + 1][n + 1];

    // Base Case：空串到非空串，需要逐个插入
    for (int i = 0; i <= m; i++) dp[i][0] = i;
    for (int j = 0; j <= n; j++) dp[0][j] = j;

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                dp[i][j] = dp[i - 1][j - 1];
            } else {
                dp[i][j] = 1 + Math.min(
                    Math.min(dp[i - 1][j], dp[i][j - 1]),
                    dp[i - 1][j - 1]
                );
            }
        }
    }
    return dp[m][n];
}
```

### 4.2 LCS 和编辑距离的兄弟关系

```
编辑距离 = m + n - 2 × LCS  (只能插入/删除，不能替换时)

证明思路：保留 LCS 部分不动，其余全部删除再插入 = (m-LCS) + (n-LCS) = m+n-2LCS
```

## 5. 最大子数组与 Kadane 算法

```java
// Kadane 算法：dp[i] = max(nums[i], dp[i-1] + nums[i])
// 空间优化到 O(1)
public int maxSubArray(int[] nums) {
    int maxSoFar = nums[0];
    int maxEndingHere = nums[0];
    for (int i = 1; i < nums.length; i++) {
        maxEndingHere = Math.max(nums[i], maxEndingHere + nums[i]);
        maxSoFar = Math.max(maxSoFar, maxEndingHere);
    }
    return maxSoFar;
}

// 衍生题：最大子数组和的分治解法 O(n log n) —— 跨中点 + 左右递归
// 衍生题：环形子数组最大和 (918) —— 两次 Kadane: maxSubArray + total-minSubArray
```

## 6. 打家劫舍系列（线性 + 环形）

```java
// 198. 打家劫舍 (线性)
public int rob(int[] nums) {
    int prev2 = 0, prev1 = 0;  // dp[i-2], dp[i-1]
    for (int x : nums) {
        int curr = Math.max(prev1, prev2 + x);
        prev2 = prev1;
        prev1 = curr;
    }
    return prev1;
}

// 213. 打家劫舍 II (环形 → 拆成两个线性)
// 要么不偷第一间，要么不偷最后一间
public int rob2(int[] nums) {
    int n = nums.length;
    if (n == 1) return nums[0];
    return Math.max(
        robRange(nums, 0, n - 2),   // 不偷最后一间
        robRange(nums, 1, n - 1)    // 不偷第一间
    );
}
private int robRange(int[] nums, int lo, int hi) {
    int prev2 = 0, prev1 = 0;
    for (int i = lo; i <= hi; i++) {
        int curr = Math.max(prev1, prev2 + nums[i]);
        prev2 = prev1; prev1 = curr;
    }
    return prev1;
}
```

| 题号 | 变体 | 核心变化 |
|:---:|------|------|
| 198 | 打家劫舍 I | 线性，一维 dp |
| 213 | 打家劫舍 II | 环形 → `max(rob[0,n-2], rob[1,n-1])` |
| 337 | 打家劫舍 III | 二叉树 → 树形 DP（见 04 模块） |
| 740 | 删除并获得点数 | 转为打家劫舍：元素值 = 房子编号，频率×值 = 金额 |

## 7. 股票买卖系列（状态机 DP）

```java
/**
 * 通用框架：dp[i][k][0/1]
 *   i: 第几天
 *   k: 已完成交易次数（一买一卖算一次）
 *   0/1: 是否持有股票
 *
 * 转移（状态机）：
 *   dp[i][k][0] = max(dp[i-1][k][0],           // 继续空仓
 *                     dp[i-1][k][1] + prices[i]) // 卖出
 *   dp[i][k][1] = max(dp[i-1][k][1],           // 继续持有
 *                     dp[i-1][k-1][0] - prices[i]) // 买入
 */

// 121. 买卖股票最佳时机 (k=1) → 只需记录最小价格
public int maxProfit(int[] prices) {
    int minPrice = Integer.MAX_VALUE, maxProfit = 0;
    for (int p : prices) {
        minPrice = Math.min(minPrice, p);
        maxProfit = Math.max(maxProfit, p - minPrice);
    }
    return maxProfit;
}

// 122. 买卖股票 II (k=∞) → 贪心：累加所有上涨区间
public int maxProfit2(int[] prices) {
    int profit = 0;
    for (int i = 1; i < prices.length; i++)
        if (prices[i] > prices[i - 1])
            profit += prices[i] - prices[i - 1];
    return profit;
}

// 123. 买卖股票 III (k=2) → 状态机 DP，用 4 个变量追踪
public int maxProfit3(int[] prices) {
    int buy1 = Integer.MIN_VALUE, sell1 = 0;
    int buy2 = Integer.MIN_VALUE, sell2 = 0;
    for (int p : prices) {
        buy1  = Math.max(buy1, -p);           // 第一次买入后剩余
        sell1 = Math.max(sell1, buy1 + p);    // 第一次卖出后收益
        buy2  = Math.max(buy2, sell1 - p);    // 第二次买入后剩余
        sell2 = Math.max(sell2, buy2 + p);    // 第二次卖出后收益
    }
    return sell2;
}
```

## 8. 回文相关问题

```java
// 5. 最长回文子串 → 中心扩展法 O(n²) / O(1)
public String longestPalindrome(String s) {
    int start = 0, maxLen = 0;
    for (int i = 0; i < s.length(); i++) {
        int len1 = expand(s, i, i);       // 奇数长度
        int len2 = expand(s, i, i + 1);   // 偶数长度
        int len = Math.max(len1, len2);
        if (len > maxLen) {
            maxLen = len;
            start = i - (len - 1) / 2;
        }
    }
    return s.substring(start, start + maxLen);
}
private int expand(String s, int l, int r) {
    while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) {
        l--; r++;
    }
    return r - l - 1;
}

// 516. 最长回文子序列 → 区间 DP
// dp[i][j] = s[i..j] 的最长回文子序列长度
// 若 s[i]==s[j]: dp[i][j] = dp[i+1][j-1] + 2
// 否则: dp[i][j] = max(dp[i+1][j], dp[i][j-1])
```

> 🎯 **核心要点**：线性 DP 的核心是**正确定义 dp[i] 或 dp[i][j] 的含义**。双序列问题统一用 `dp[i][j]` 表示 `s1前i个` 与 `s2前j个` 的关系；单序列决策问题要明确 dp[i] 是"以 i 结尾"还是"考虑前 i 个"——前者用于 LIS/MaxSubArray，后者用于打家劫舍/背包。
