## 1. 背包问题家族概览

| 类型 | 物品限制 | 转移核心 | 遍历顺序 | 典型题 |
|------|------|------|:---:|------|
| **0/1 背包** | 每件物品最多选 1 次 | `dp[j]=max(dp[j], dp[j-w]+v)` | 逆序 | 416.分割等和子集 |
| **完全背包** | 每件物品可选无限次 | `dp[j]=max(dp[j], dp[j-w]+v)` | **正序** | 322.零钱兑换 |
| **多重背包** | 第 i 件最多选 kᵢ 次 | 二进制拆分 → 0/1 背包 | 逆序 | — |
| **分组背包** | 每组最多选 1 件 | 组内互斥：先选组再选物品 | 逆序 | 1155.掷骰子 |
| **二维费用** | 两个容量约束 | `dp[a][b]` 两个维度都要逆序 | 双逆序 | 474.一和零 |

> 💡 **核心洞察**：所有背包问题的模板骨架是相同的——**外层遍历物品，内层遍历容量**。区别只在于遍历方向（逆序 vs 正序）和维度数量。

## 2. 0/1 背包：选或不选的哲学

### 2.1 问题定义

> 给定 n 件物品，每件重量 `w[i]`、价值 `v[i]`，背包容量 W。每件物品最多选一次，求最大总价值。

### 2.2 五步法分析

```
Step 1: 状态 → 前 i 件物品、背包容量 j
Step 2: 定义 → dp[i][j] = 考虑前 i 件物品、容量 j 时的最大价值
Step 3: 转移 → dp[i][j] = max(dp[i-1][j],              ← 不选第 i 件
                              dp[i-1][j-w[i]] + v[i])  ← 选第 i 件（前提 j ≥ w[i]）
Step 4: Base → dp[0][*] = 0（没有物品时价值为 0）
Step 5: 顺序 → i: 1→n, j: 0→W；答案 = dp[n][W]
```

### 2.3 二维实现

```java
// 标准 2D 实现：O(n×W) / O(n×W)
public int knapsack01_2D(int[] weights, int[] values, int W) {
    int n = weights.length;
    int[][] dp = new int[n + 1][W + 1];

    for (int i = 1; i <= n; i++) {
        int w = weights[i - 1], v = values[i - 1];
        for (int j = 0; j <= W; j++) {
            if (j < w) dp[i][j] = dp[i - 1][j];            // 放不下
            else dp[i][j] = Math.max(dp[i - 1][j],          // 不放
                                     dp[i - 1][j - w] + v); // 放
        }
    }
    return dp[n][W];
}
```

### 2.4 一维优化（滚动数组）⭐

```java
// 空间优化：O(W)，面试必写版本
public int knapsack01_1D(int[] weights, int[] values, int W) {
    int[] dp = new int[W + 1];
    for (int i = 0; i < weights.length; i++) {
        int w = weights[i], v = values[i];
        for (int j = W; j >= w; j--) {        // ⚠️ 必须逆序遍历！
            dp[j] = Math.max(dp[j], dp[j - w] + v);
        }
    }
    return dp[W];
}
```

### 2.5 逆序遍历到底为什么？

```
前 i 件物品时 dp[j] 依赖前 i-1 件的 dp[j-w]（两者都应该是 i-1 行的值）

错误演示（正序）：
  dp[0]=0, dp[1], dp[2], ... dp[10]
  处理第 1 件物品 w=3, v=5：
  j=3: dp[3] = max(dp[3], dp[0]+5) = 5     ✓
  j=6: dp[6] = max(dp[6], dp[3]+5) = 10    ✗ dp[3]是本轮刚算的！相当于用了两次

正确做法（逆序）：
  j=6: dp[6] = max(dp[6], dp[3]+5) = 5     ✓ dp[3]还是上一轮的 0
  j=3: dp[3] = max(dp[3], dp[0]+5) = 5     ✓

关键：逆序保证 dp[j-w] 读到的值来自「前 i-1 件物品」而非「本轮已更新的」
```

## 3. 完全背包：无限选取的世界

### 3.1 与 0/1 背包的区别

```java
// 0/1 背包 vs 完全背包 —— 仅遍历顺序不同！
// 完全背包：正序遍历 j，允许物品被重复使用
public int knapsackComplete(int[] weights, int[] values, int W) {
    int[] dp = new int[W + 1];
    for (int i = 0; i < weights.length; i++) {
        int w = weights[i], v = values[i];
        for (int j = w; j <= W; j++) {          // ⚠️ 正序遍历！
            dp[j] = Math.max(dp[j], dp[j - w] + v);
        }
    }
    return dp[W];
}
```

### 3.2 经典变体：零钱兑换 (322)

```java
// 凑成金额 amount 所需的最少硬币数（每种硬币无限）
public int coinChange(int[] coins, int amount) {
    int[] dp = new int[amount + 1];
    Arrays.fill(dp, amount + 1);  // 用不可能的大数初始化
    dp[0] = 0;                     // Base Case：凑 0 元需要 0 枚

    for (int coin : coins) {
        for (int j = coin; j <= amount; j++) {  // 正序：完全背包
            dp[j] = Math.min(dp[j], dp[j - coin] + 1);
        }
    }
    return dp[amount] > amount ? -1 : dp[amount];
}
```

### 3.3 零钱兑换 II (518) — 组合数

```java
// 凑成 amount 的组合数（不考虑顺序）
// ⚠️ 外层 coins 遍历保证不重：{1,2,5} 和 {2,1,5} 算同一种
public int change(int amount, int[] coins) {
    int[] dp = new int[amount + 1];
    dp[0] = 1;                    // 凑 0 元有 1 种方法
    for (int coin : coins) {      // 外层遍历硬币
        for (int j = coin; j <= amount; j++) {
            dp[j] += dp[j - coin];
        }
    }
    return dp[amount];
}

// 变体：排列数（考虑顺序）
// 将内外层循环交换：
// for (int j = 1; j <= amount; j++)
//     for (int coin : coins)
//         if (j >= coin) dp[j] += dp[j - coin];
```

> ⚠️ **关键区分**：外层硬币 → 组合数；外层金额 → 排列数。这是 518 vs 377(组合总和IV) 的唯一区别。

## 4. 多重背包：数量的限制与突破

### 4.1 朴素解法：添加第三层循环

```java
// dp[j] = max(dp[j], dp[j - k*w] + k*v)  for k ∈ [0, count[i]]
// 时间复杂度: O(n × W × max(count))
public int knapsackMultiple_Naive(int[] w, int[] v, int[] cnt, int W) {
    int n = w.length;
    int[] dp = new int[W + 1];
    for (int i = 0; i < n; i++) {
        for (int j = W; j >= w[i]; j--) {
            for (int k = 1; k <= cnt[i] && k * w[i] <= j; k++) {
                dp[j] = Math.max(dp[j], dp[j - k * w[i]] + k * v[i]);
            }
        }
    }
    return dp[W];
}
```

### 4.2 二进制优化 ⭐

```java
// 将每种物品按 1,2,4,8,... 份打包 → 变成 0/1 背包
// 时间复杂度: O(n × W × log(maxCount))
public int knapsackMultiple_Binary(int[] w, int[] v, int[] cnt, int W) {
    List<Integer> newW = new ArrayList<>();
    List<Integer> newV = new ArrayList<>();

    for (int i = 0; i < w.length; i++) {
        int k = 1;
        while (k <= cnt[i]) {
            newW.add(w[i] * k);        // k 个打包
            newV.add(v[i] * k);
            cnt[i] -= k;
            k <<= 1;                   // k = 1, 2, 4, 8, ...
        }
        if (cnt[i] > 0) {              // 剩余部分打包
            newW.add(w[i] * cnt[i]);
            newV.add(v[i] * cnt[i]);
        }
    }

    // 转化为 0/1 背包
    int[] dp = new int[W + 1];
    for (int i = 0; i < newW.size(); i++) {
        for (int j = W; j >= newW.get(i); j--) {  // 逆序！
            dp[j] = Math.max(dp[j], dp[j - newW.get(i)] + newV.get(i));
        }
    }
    return dp[W];
}
```

> 💡 **为何二进制有效**：1, 2, 4, 8 的组合可以表示任意 0~15 的整数。通过打包，每种物品拿任意数量的决策变成了"每个包裹选或不选"的 0/1 决策。

## 5. 背包问题的变形与应用

### 5.1 分组背包

```java
// 每组最多选 1 件物品
// 遍历次序：组 → 容量(逆序) → 组内物品
for (int[] group : groups) {              // 遍历每组
    for (int j = W; j >= 0; j--) {       // 逆序遍历容量
        for (int[] item : group) {       // 遍历组内物品
            int w = item[0], v = item[1];
            if (j >= w)
                dp[j] = Math.max(dp[j], dp[j - w] + v);
        }
    }
}
```

### 5.2 二维费用背包 (474. 一和零)

```java
// 字符串数组 strs，每个字符串有 m 个 '0' 和 n 个 '1'
// 找最大子集，使得 '0' 总数 ≤ m, '1' 总数 ≤ n
public int findMaxForm(String[] strs, int m, int n) {
    int[][] dp = new int[m + 1][n + 1];                  // 两个容量维度
    for (String s : strs) {
        int zeros = countChar(s, '0');
        int ones = s.length() - zeros;
        for (int i = m; i >= zeros; i--) {               // 双逆序
            for (int j = n; j >= ones; j--) {
                dp[i][j] = Math.max(dp[i][j], dp[i - zeros][j - ones] + 1);
            }
        }
    }
    return dp[m][n];
}
```

### 5.3 背包的三种问法

```java
// 问法 1: 能否恰好装满？→ 初始化 dp[0]=true, 其余 false
boolean[] dp = new boolean[W + 1];
dp[0] = true;
for (int w : weights) {
    for (int j = W; j >= w; j--) {
        dp[j] = dp[j] || dp[j - w];       // 416. 分割等和子集
    }
}

// 问法 2: 最多能装多少？→ 初始化全 0
int[] dp = new int[W + 1];
for (int w : weights) {
    for (int j = W; j >= w; j--) {
        dp[j] = Math.max(dp[j], dp[j - w] + w);  // 1049. 最后一块石头重量 II
    }
}

// 问法 3: 恰好装满有几种方法？→ 初始化 dp[0]=1, 其余 0
int[] dp = new int[W + 1];
dp[0] = 1;
for (int w : weights) {
    for (int j = W; j >= w; j--) {
        dp[j] += dp[j - w];               // 494. 目标和
    }
}
```

## 6. Java 通用背包模板

```java
/**
 * 背包问题统一模板
 * @param weights  物品重量/成本数组
 * @param values  物品价值数组 (求方案数时传 null)
 * @param W       背包容量
 * @param type    类型: "01" / "complete" / "multiple"
 * @param limits  多重背包时的数量限制 (可选)
 * @param objective 目标: "maxValue" / "maxWeight" / "countWays" / "canFill"
 */
public class KnapsackTemplate {

    public int solve(int[] weights, int[] values, int W, String type,
                     int[] limits, String objective) {
        if (type.equals("multiple") && limits != null) {
            return solveMultiple(weights, values, W, limits, objective);
        }

        int[] dp = new int[W + 1];
        // 初始化
        if (objective.equals("countWays") || objective.equals("canFill")) {
            dp[0] = 1;  // 或 true
        }

        boolean reverse = type.equals("01");
        for (int i = 0; i < weights.length; i++) {
            if (reverse) {
                for (int j = W; j >= weights[i]; j--) update(dp, j, weights[i], values, objective, i);
            } else {
                for (int j = weights[i]; j <= W; j++) update(dp, j, weights[i], values, objective, i);
            }
        }
        return dp[W];
    }

    private void update(int[] dp, int j, int w, int[] values, String obj, int i) {
        int v = (values != null) ? values[i] : w;
        switch (obj) {
            case "maxValue"  -> dp[j] = Math.max(dp[j], dp[j - w] + v);
            case "maxWeight" -> dp[j] = Math.max(dp[j], dp[j - w] + w);
            case "countWays" -> dp[j] += dp[j - w];
            case "canFill"   -> dp[j] = dp[j] || dp[j - w] == 1 ? 1 : 0;
        }
    }
    // ... solveMultiple 使用二进制优化
}
```

| 1155 | 掷骰子的N种方法 | 分组背包 | 🟡 | 每组(骰子)选一个面值 |

### 面试解题框架

```
拿到背包题 → 三步识别：
1. 有没有"选或不选"？→ 背包模型
2. 每件物品能用几次？→ 决定 0/1 (1次) / 完全 (∞次)
3. 问什么？→ 可行性 / 最值 / 计数 → 决定初始化方式

然后套模板，选对遍历方向，问题迎刃而解。
```

> 🎯 **核心要点**：背包问题的灵魂是**逆序 vs 正序**——0/1 背包逆序防止重复，完全背包正序允许重复。记住这个，所有变体都是模板的"换装"。初始化方式由问题目标决定：可行性用 false+dp[0]=true，计数用 0+dp[0]=1，最值用 0 或 INF。
