## 1. 状态设计的方法论

### 1.1 状态设计的本质

```
状态 = "当前局面"的完整描述
  什么信息决定了"剩余子问题"？
  → 这些信息就是状态

设计三问：
  ① 哪些参数决定剩余问题？（少一个 → 状态不完整）
  ② 参数范围多大？（决定数组大小）
  ③ 能压缩吗？（合并等价状态）

⚠️ 状态不完整 = 答案错误
  例：股票问题必须包含"是否持有"维度
  例：石子游戏 II 必须包含 M（会变化）
```

### 1.2 状态的维度选择

| 问题特征 | 维度 | 例子 |
|------|:---:|------|
| 单序列递推 | 1D | 爬楼梯、打家劫舍 |
| 双序列对应 | 2D | LCS、编辑距离 |
| 序列+约束 | 2D | 背包（容量） |
| 区间 | 2D | 回文、石子合并 |
| 位置+属性 | 2D+ | 股票（持有）、骑士（步数） |
| 集合 | 掩码 | TSP |

```
⚠️ 判断标准：
  "状态能否唯一决定未来？"
  能 → 维度够；不能 → 缺维度
```

### 1.3 状态定义的五种模式

```java
// 模式 A：以 i 结尾（1D 最常用）
dp[i] = 以 arr[i] 结尾的某个最优值
  // LIS、最大子序和
  // ⚠️ 好处：子序列连续性天然保证

// 模式 B：考虑前 i 个元素
dp[i] = 考虑 arr[0..i-1] 的某个最优值
  // 背包、打家劫舍
  // ⚠️ 好处：与"是否选第 i 个"决策分离

// 模式 C：双序列对应
dp[i][j] = s1[0..i-1] 与 s2[0..j-1] 的关系
  // LCS、编辑距离

// 模式 D：区间
dp[i][j] = arr[i..j] 上的最优值
  // 区间 DP（回文/合并）

// 模式 E：选/不选（状态机）
dp[i][0/1] = 第 i 个位置选/不选的值
  // 打家劫舍、股票买卖
```

## 2. 状态压缩与空间优化

### 2.1 滚动数组的三种形态

```java
// ═══════════ 形态一：变量滚动（1D → O(1)）══════════
// 适用：dp[i] 只依赖 dp[i-1]/dp[i-2]
// 例：198 打家劫舍
int prev2 = nums[0];
int prev1 = Math.max(nums[0], nums[1]);
for (int i = 2; i < n; i++) {
    int curr = Math.max(prev1, prev2 + nums[i]);
    prev2 = prev1;
    prev1 = curr;
}

// ═══════════ 形态二：交替行（2D → 2 行）══════════
// 适用：dp[i][j] 只依赖 dp[i-1][...]
// 例：LCS、编辑距离
int[][] dp = new int[2][n + 1];
for (int i = 1; i <= m; i++) {
    int cur = i % 2, prev = 1 - cur;
    for (int j = 1; j <= n; j++) {
        dp[cur][j] = f(dp[prev][j], dp[cur][j-1], ...);
    }
}

// ═══════════ 形态三：逆序覆盖（2D → 1D）══════════
// 适用：背包（0/1 逆序；完全正序）
// 例：416 分割等和子集
boolean[] dp = new boolean[target + 1];
dp[0] = true;
for (int num : nums) {
    for (int j = target; j >= num; j--) {   // ⚠️ 逆序！
        dp[j] = dp[j] || dp[j - num];
    }
}
```

### 2.2 状态压缩的适用判断

```
能压缩的条件：
  ① 当前行只依赖"有限历史行"
  ② 依赖关系"单向"（不回头）
  ③ 不需要回溯路径

⚠️ 什么时候不能压缩？
  需要输出最优方案（回溯 dp 表）→ 保留完整
  依赖所有历史（如最长公共子序列输出）→ 视情况

⚠️ 面试策略：
  先写完整数组（正确性优先）
  面试官要求优化时展示压缩（加分）
  "我可以把空间从 O(n²) 优化到 O(n)"
```

### 2.3 空间优化常见错误

```
① 逆序/正序写反 → 0/1 变完全背包
② 交替行忘记清空 → 旧值污染
③ 变量滚动顺序错 → 依赖被覆盖

⚠️ 记忆：
  0/1 背包 → 逆序（防重复使用）
  完全背包 → 正序（允许重复使用）
  交替行 → i%2 与 (i-1)%2 严格区分
```

## 3. 遍历顺序的决定

### 3.1 为什么顺序重要

```
DP 的前提：计算 dp[i] 时，所有依赖的状态已算好
  → 遍历顺序必须保证"依赖先算"

⚠️ 顺序错了 = 用到未初始化的值 = 答案错误
  例：区间 DP 按长度递增（小区间先算）
```

### 3.2 常见遍历模式

```java
// ═══════════ 一维顺序 ═════════════════════════════
// 依赖前驱：正序
for (int i = 1; i <= n; i++) { ... }

// 依赖后继（如股票）：
for (int i = n - 2; i >= 0; i--) { ... }

// ═══════════ 二维顺序 ═════════════════════════════
// 依赖上方+左方（网格 DP）：
for (int i = 1; i <= m; i++)
    for (int j = 1; j <= n; j++) { ... }

// ═══════════ 区间顺序（按长度）════════════════════
// 依赖更短区间：
for (int len = 2; len <= n; len++)          // 长度递增
    for (int i = 0; i + len - 1 < n; i++) {
        int j = i + len - 1;
        for (int k = i; k < j; k++) { ... }  // 分割点
    }

// ═══════════ 背包顺序 ════════════════════════════
// 0/1：外层物品 + 内层容量逆序
// 完全：外层物品 + 内层容量正序
// 分组：组 → 容量逆序 → 组内
```

### 3.3 判断顺序的方法

```
画表法：画 dp 表格，标出每个格子的依赖方向
  → 箭头指向：从左到右/从上到下/从短到长

⚠️ 面试表达：
"计算顺序从 1 到 n——因为 dp[i] 依赖
 dp[i-1]，必须保证依赖先算。
 我画表验证了依赖方向。"
```

## 4. DP 的六大进阶模型

### 4.1 模型一：状态机 DP（股票系列）

```java
/**
 * 股票买卖通用框架（123. 买卖股票 III）
 * dp[i][k][0/1]：第 i 天，完成 k 次交易，是否持有
 *
 * 转移：
 *   dp[i][k][0] = max(dp[i-1][k][0],          // 继续空仓
 *                     dp[i-1][k][1] + price)  // 卖出
 *   dp[i][k][1] = max(dp[i-1][k][1],          // 继续持有
 *                     dp[i-1][k-1][0] - price) // 买入
 *
 * ⚠️ 状态机思想：把"阶段"变成状态维度
 */
// 123 题简化（k=2，4 个变量）：
public int maxProfit(int[] prices) {
    int buy1 = Integer.MIN_VALUE, sell1 = 0;
    int buy2 = Integer.MIN_VALUE, sell2 = 0;
    for (int p : prices) {
        buy1  = Math.max(buy1, -p);
        sell1 = Math.max(sell1, buy1 + p);
        buy2  = Math.max(buy2, sell1 - p);
        sell2 = Math.max(sell2, buy2 + p);
    }
    return sell2;
}
// 应用：121（k=1）、122（k=∞）、123（k=2）、188（k 任意）
```

### 4.2 模型二：区间 DP（回文/合并）

```java
/**
 * 516. 最长回文子序列（区间 DP）
 * dp[i][j] = s[i..j] 的最长回文子序列长度
 *
 * 转移：
 *   s[i]==s[j] → dp[i+1][j-1] + 2
 *   否则 → max(dp[i+1][j], dp[i][j-1])
 */
public int longestPalindromeSubseq(String s) {
    int n = s.length();
    int[][] dp = new int[n][n];
    for (int i = 0; i < n; i++) dp[i][i] = 1;

    for (int len = 2; len <= n; len++) {           // ⚠️ 按长度
        for (int i = 0; i + len - 1 < n; i++) {
            int j = i + len - 1;
            if (s.charAt(i) == s.charAt(j)) {
                dp[i][j] = dp[i + 1][j - 1] + 2;
            } else {
                dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1]);
            }
        }
    }
    return dp[0][n - 1];
}
// 应用：5 回文子串、312 戳气球、1000 合并石头
```

### 4.3 模型三：背包类（0/1、完全、多重）

```
0/1：每件最多一次 → 逆序
完全：无限次 → 正序
多重：有限次 → 二进制优化转 0/1
分组：每组选一个 → 组/容量/组内

⚠️ 三种问法：
  能否装满 → boolean（dp[0]=true）
  最大价值 → int（dp 全 0）
  方案数 → 计数（dp[0]=1）
```

### 4.4 模型四：树形 DP（后序聚合）

```java
/**
 * 337. 打家劫舍 III（树形 DP）
 * dp[node][0/1]：不偷/偷 node 的最大收益
 * 后序：先算子树，再合并
 */
public int rob(TreeNode root) {
    int[] res = dfs(root);
    return Math.max(res[0], res[1]);
}

private int[] dfs(TreeNode node) {
    if (node == null) return new int[]{0, 0};
    int[] left = dfs(node.left);
    int[] right = dfs(node.right);
    int[] cur = new int[2];
    cur[0] = Math.max(left[0], left[1]) + Math.max(right[0], right[1]);
    cur[1] = node.val + left[0] + right[0];
    return cur;
}
// 应用：124 最大路径和、543 直径、968 监控二叉树
```

### 4.5 模型五：状态压缩 DP（集合）

```
dp[mask]：掩码表示的集合状态
  转移：加入/移除一个元素

应用：TSP（dp[mask][i]）、698 划分、464 博弈
⚠️ 前提：n ≤ 20（2ⁿ 状态可行）
```

### 4.6 模型六：数位 DP（按位统计）

```java
/**
 * 数位 DP 模板：统计 [0, n] 满足条件的数
 * 状态：(pos, tight, 附加条件)
 */
public int countDigit(int n) {
    char[] digits = String.valueOf(n).toCharArray();
    Integer[][][] memo = new Integer[digits.length][2][2];
    return dfs(digits, 0, true, true, memo);
}

private int dfs(char[] digits, int pos, boolean tight,
                boolean leadingZero, Integer[][][] memo) {
    if (pos == digits.length) return leadingZero ? 0 : 1;
    int t = tight ? 1 : 0, lz = leadingZero ? 1 : 0;
    if (memo[pos][t][lz] != null) return memo[pos][t][lz];

    int limit = tight ? digits[pos] - '0' : 9;
    int total = 0;
    for (int d = 0; d <= limit; d++) {
        total += dfs(digits, pos + 1,
            tight && d == limit, leadingZero && d == 0, memo);
    }
    return memo[pos][t][lz] = total;
}
// 应用：233 数字 1 的个数、902 最大为 N 的组合
```

## 5. DP 与其他算法的结合

### 5.1 DP + 二分（LIS 优化）

```
LIS 的 O(n log n)：
  贪心 + 二分（tails 数组）替代 DP 扫描
  ⚠️ 不是 DP 了，但解决的问题相同

⚠️ 面试表达：
"LIS 有 O(n²) DP 和 O(n log n) 贪心+二分
 两种解法——DP 直观，二分最优。"
```

### 5.2 DP + 单调队列（窗口最值优化）

```
转移需要窗口内最值：
  dp[i] = f(max(dp[i-k..i-1])) + cost
  → 单调队列 O(n)（见单调队列专题）

⚠️ 识别："最近 k 个状态的最值依赖"
```

### 5.3 DP + 位运算（状态压缩）

```
集合状态用掩码：
  dp[mask]（1 个 int 表示集合）
  转移用位运算（O(1)）

⚠️ 识别："已选集合" + n ≤ 20
```

### 5.4 DP + 前缀和（区间优化）

```
转移需要区间和：
  dp[i] = max(dp[j] + sum(j+1..i))
  → 前缀和 O(1) 求区间和

⚠️ 识别："转移中出现区间和"
```

## 6. 进阶总结

### 6.1 进阶要点速查

```
① 状态设计：状态 = 剩余问题的完整描述
   "少一个参数 = 状态不完整 = 答案错误"
② 空间优化：依赖有限历史 → 滚动
   0/1 逆序、完全正序、交替行
③ 遍历顺序：依赖先算（画表验证）
④ 六大模型：状态机/区间/背包/树形/压缩/数位
⑤ 结合：二分（LIS）、单调队列（窗口）、位（集合）
```

### 6.2 面试话术模板

```
"这题的状态是【...】——它完整描述了剩余问题。
 转移【...】，依赖方向【...】，所以遍历顺序【...】。
 空间上我可以【滚动优化】到【O(...)】。
 这是【状态机/区间/背包】模型，
 与【二分/单调队列】结合可以进一步优化。"
```

### 6.3 易错点清单

| 错误 | 后果 | 修正 |
|------|------|------|
| 状态缺维度 | 答案错误 | 完整描述剩余问题 |
| 背包正逆反 | 结果错 | 0/1 逆、完全正 |
| 遍历顺序错 | 用到未初始化 | 画表验证 |
| 区间不按长度 | 依赖未算 | len 外层递增 |
| 滚动忘清空 | 旧值污染 | 交替行严格区分 |

> 🎯 **核心要点**：DP 进阶 = **状态设计**（完整描述）+ **空间优化**（滚动三形态）+ **六大模型**（状态机/区间/背包/树形/压缩/数位）。"状态完整"是正确性的根，"依赖先算"是顺序的根；与二分/单调队列/位运算的结合是进阶加分。
