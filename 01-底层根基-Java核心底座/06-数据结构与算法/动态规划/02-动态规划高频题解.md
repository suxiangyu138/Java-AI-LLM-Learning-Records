## 1. 70. 爬楼梯（一维入门）

### 1.1 完整实现（三种写法）

```java
/**
 * LeetCode 70. 爬楼梯（DP 第一题）
 * 每次爬 1 或 2 阶 → 到达 n 阶的方法数
 *
 * dp[i] = dp[i-1] + dp[i-2]（斐波那契）
 * 解释：最后一步爬 1 阶（前 i-1 阶的方法数）
 *       或爬 2 阶（前 i-2 阶的方法数）
 */
public int climbStairs(int n) {
    if (n <= 2) return n;
    int prev2 = 1, prev1 = 2;          // dp[1], dp[2]
    for (int i = 3; i <= n; i++) {
        int curr = prev1 + prev2;
        prev2 = prev1;
        prev1 = curr;
    }
    return prev1;
}
// 推演 n=5：dp = [1,2,3,5,8] → 8 ✓
// 空间 O(1)：只保留前两个状态
// ⚠️ 变体：746 最小花费爬楼梯（min 替代 +）
```

### 1.2 面试五步法演示

```
① 状态：爬到第 i 阶
② dp[i] = 爬到第 i 阶的方法数
③ 转移：dp[i] = dp[i-1] + dp[i-2]
   最后一步爬 1 阶 或 2 阶（加法原理）
④ base：dp[1]=1, dp[2]=2
⑤ 顺序：i 从 3 到 n（依赖前驱）
   答案：dp[n]
```

## 2. 198/213. 打家劫舍 I & II

### 2.1 198. 打家劫舍（线性）

```java
/**
 * LeetCode 198. 打家劫舍
 * 相邻房子不能都偷
 * dp[i] = max(dp[i-1], dp[i-2] + nums[i])
 */
public int rob(int[] nums) {
    if (nums.length == 1) return nums[0];
    int prev2 = nums[0];
    int prev1 = Math.max(nums[0], nums[1]);
    for (int i = 2; i < nums.length; i++) {
        int curr = Math.max(prev1, prev2 + nums[i]);
        prev2 = prev1;
        prev1 = curr;
    }
    return prev1;
}
// 推演 [2,7,9,3,1]：dp = [2,7,11,11,12] → 12 ✓
// 转移解释：不偷（dp[i-1]）或偷（dp[i-2]+nums[i]）
```

### 2.2 213. 打家劫舍 II（环形）

```java
/**
 * LeetCode 213. 打家劫舍 II（环形）
 * 首尾相邻 → 拆成两个线性：
 *   ① 不偷第一间 → rob[1..n-1]
 *   ② 不偷最后一间 → rob[0..n-2]
 * 取较大者
 */
public int rob2(int[] nums) {
    int n = nums.length;
    if (n == 1) return nums[0];
    return Math.max(
        robRange(nums, 0, n - 2),   // 不偷最后一间
        robRange(nums, 1, n - 1)    // 不偷第一间
    );
}

private int robRange(int[] nums, int lo, int hi) {
    int prev2 = 0, prev1 = 0;
    for (int i = lo; i <= hi; i++) {
        int curr = Math.max(prev1, prev2 + nums[i]);
        prev2 = prev1;
        prev1 = curr;
    }
    return prev1;
}
// ⚠️ 环形处理套路："拆环成线，分别求解"
// 应用：740 删除并获得点数（转化为打家劫舍）
```

## 3. 53. 最大子序和（Kadane）

### 3.1 完整实现

```java
/**
 * LeetCode 53. 最大子序和（Kadane 算法）
 * dp[i] = 以 nums[i] 结尾的最大子序和
 * 转移：dp[i] = max(nums[i], dp[i-1] + nums[i])
 *   要么另起炉灶（只取自己），要么接入前面的
 */
public int maxSubArray(int[] nums) {
    int maxEndingHere = nums[0];   // dp[i]
    int maxSoFar = nums[0];        // 全局最优

    for (int i = 1; i < nums.length; i++) {
        maxEndingHere = Math.max(nums[i], maxEndingHere + nums[i]);
        maxSoFar = Math.max(maxSoFar, maxEndingHere);
    }
    return maxSoFar;
}
// 推演 [-2,1,-3,4,-1,2,1,-5,4]：
//   dp = [-2,1,-2,4,3,5,6,1,5] → 6 ✓
// ⚠️ 面试追问：全负数 → 正确返回最大负数
```

### 3.2 高频追问

```
① 如何返回子数组本身？
   维护 start/end 指针，dp 重置时更新起点
② 分治怎么做？
   左/右/跨中点三选一（O(n log n)）
③ 环形数组（918）？
   max(普通 Kadane, 总和 - minKadane)
```

## 4. 300. 最长递增子序列 LIS

### 4.1 O(n²) DP 版

```java
/**
 * LeetCode 300. 最长递增子序列（O(n²) DP）
 * dp[i] = 以 nums[i] 结尾的最长递增子序列长度
 * 转移：dp[i] = max(1, max(dp[j]+1)) 其中 j<i 且 nums[j]<nums[i]
 */
public int lengthOfLIS(int[] nums) {
    int[] dp = new int[nums.length];
    Arrays.fill(dp, 1);
    int maxLen = 1;

    for (int i = 0; i < nums.length; i++) {
        for (int j = 0; j < i; j++) {
            if (nums[j] < nums[i]) {
                dp[i] = Math.max(dp[i], dp[j] + 1);
            }
        }
        maxLen = Math.max(maxLen, dp[i]);
    }
    return maxLen;
}
// 推演 [10,9,2,5,3,7,101,18]：
//   dp = [1,1,1,2,2,3,4,4] → 4 ✓
```

### 4.2 O(n log n) 贪心+二分

```java
/**
 * LIS 优化：tails[i] = 长度为 i+1 的递增子序列的最小末尾
 * tails 单调递增 → 二分查找
 */
public int lengthOfLIS_Opt(int[] nums) {
    int[] tails = new int[nums.length];
    int len = 0;

    for (int x : nums) {
        // 二分：第一个 ≥ x 的位置
        int lo = 0, hi = len;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (tails[mid] < x) lo = mid + 1;
            else hi = mid;
        }
        tails[lo] = x;               // 替换或追加
        if (lo == len) len++;
    }
    return len;
}
// 推演 [10,9,2,5,3,7,101,18]：
//   tails: [10] → [9] → [2] → [2,5] → [2,3]
//          → [2,3,7] → [2,3,7,101] → [2,3,7,18] → 4 ✓
// ⚠️ 面试必答："tails 单调递增的原因——
//   末尾越小越容易被扩展"
```

## 5. 1143. 最长公共子序列 LCS

### 5.1 完整实现

```java
/**
 * LeetCode 1143. 最长公共子序列
 * dp[i][j] = text1[0..i-1] 与 text2[0..j-1] 的 LCS
 *
 * 转移：
 *   相等 → dp[i-1][j-1] + 1（对角+1）
 *   不等 → max(dp[i-1][j], dp[i][j-1])
 */
public int longestCommonSubsequence(String text1, String text2) {
    int m = text1.length(), n = text2.length();
    int[][] dp = new int[m + 1][n + 1];

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }
    return dp[m][n];
}
// 推演 "abcde" vs "ace"：
//   dp 表：相等时对角+1 → LCS = "ace" = 3 ✓
```

### 5.2 高频追问

```
① 如何输出 LCS 序列？
   反向追溯：从 dp[m][n] 出发
   相等 → 记录并走对角；不等 → 走向较大的
② 空间优化？
   dp 只依赖上一行 → 交替行 O(min(m,n))
③ 与 LIS 的关系？
   LCS 可转化为 LIS（排列时，O(n log n)）
```

## 6. 72. 编辑距离

### 6.1 完整实现

```java
/**
 * LeetCode 72. 编辑距离（字节最爱）
 * 允许：插入/删除/替换，各 1 代价
 * dp[i][j] = word1[0..i-1] → word2[0..j-1] 的最少操作
 *
 * 转移：
 *   相等 → dp[i-1][j-1]（免费）
 *   不等 → 1 + min(
 *       dp[i-1][j],    // 删除 word1[i-1]
 *       dp[i][j-1],    // 插入 word2[j-1]
 *       dp[i-1][j-1])  // 替换
 */
public int minDistance(String word1, String word2) {
    int m = word1.length(), n = word2.length();
    int[][] dp = new int[m + 1][n + 1];

    for (int i = 0; i <= m; i++) dp[i][0] = i;  // 全删除
    for (int j = 0; j <= n; j++) dp[0][j] = j;  // 全插入

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                dp[i][j] = dp[i - 1][j - 1];
            } else {
                dp[i][j] = 1 + Math.min(
                    Math.min(dp[i - 1][j], dp[i][j - 1]),
                    dp[i - 1][j - 1]);
            }
        }
    }
    return dp[m][n];
}
// 推演 "horse" → "ros" = 3 ✓
// 面试追问：
//   ① 返回操作序列？→ 反向追溯
//   ② 操作代价不同？→ 替换 1 为对应代价
//   ③ 与 LCS 关系？→ 只插删时 = m+n-2×LCS
```

## 7. 322/416. 背包两题

### 7.1 322. 零钱兑换（完全背包）

```java
/**
 * LeetCode 322. 零钱兑换
 * 硬币无限 → 完全背包
 * dp[i] = 凑出金额 i 的最少硬币数
 */
public int coinChange(int[] coins, int amount) {
    int[] dp = new int[amount + 1];
    Arrays.fill(dp, amount + 1);     // ⚠️ 不可能的大数
    dp[0] = 0;

    for (int coin : coins) {                    // 外层硬币
        for (int j = coin; j <= amount; j++) {  // ⚠️ 正序（完全背包）
            dp[j] = Math.min(dp[j], dp[j - coin] + 1);
        }
    }
    return dp[amount] > amount ? -1 : dp[amount];
}
// 推演 coins=[1,2,5], amount=11：
//   dp[11] = 3（5+5+1）✓
// ⚠️ 初始化 amount+1：区分"不可达"与"0"
```

### 7.2 416. 分割等和子集（0/1 背包）

```java
/**
 * LeetCode 416. 分割等和子集
 * 能否选出子集使和 = sum/2 → 0/1 背包可行性
 */
public boolean canPartition(int[] nums) {
    int sum = 0;
    for (int x : nums) sum += x;
    if (sum % 2 != 0) return false;    // 奇数和不可能平分

    int target = sum / 2;
    boolean[] dp = new boolean[target + 1];
    dp[0] = true;                      // 和为 0 总可以

    for (int num : nums) {
        for (int j = target; j >= num; j--) {  // ⚠️ 逆序（0/1）！
            dp[j] = dp[j] || dp[j - num];
        }
    }
    return dp[target];
}
// 推演 [1,5,11,5]：sum=22, target=11
//   逆序保证每个数只用一次 → dp[11] = true ✓
// ⚠️ 面试必答："逆序防止重复使用——
//   正序会让同一个 num 被用多次"
```

## 8. 5. 最长回文子串（区间 DP）

### 8.1 完整实现（DP 版）

```java
/**
 * LeetCode 5. 最长回文子串（区间 DP 版）
 * dp[i][j] = s[i..j] 是否回文
 * 转移：s[i]==s[j] && (j-i<=1 || dp[i+1][j-1])
 */
public String longestPalindrome(String s) {
    int n = s.length();
    boolean[][] dp = new boolean[n][n];
    int start = 0, maxLen = 1;

    for (int len = 1; len <= n; len++) {         // 按长度
        for (int i = 0; i + len - 1 < n; i++) {
            int j = i + len - 1;
            if (s.charAt(i) == s.charAt(j)
                && (len <= 2 || dp[i + 1][j - 1])) {
                dp[i][j] = true;
                if (len > maxLen) {
                    maxLen = len;
                    start = i;
                }
            }
        }
    }
    return s.substring(start, start + maxLen);
}
// O(n²) 时间 O(n²) 空间
// 对比：中心扩展 O(n²)/O(1)（面试更推荐）
// 追问"更快" → Manacher O(n)
```

## 9. 337. 打家劫舍 III（树形 DP）

### 9.1 完整实现

```java
/**
 * LeetCode 337. 打家劫舍 III（树形 DP）
 * 二叉树版打家劫舍：不能偷相邻层
 * dp[node][0/1]：不偷/偷 node 的最大收益
 */
public int rob(TreeNode root) {
    int[] res = dfs(root);
    return Math.max(res[0], res[1]);
}

private int[] dfs(TreeNode node) {
    if (node == null) return new int[]{0, 0};

    int[] left = dfs(node.left);       // 后序：先算子树
    int[] right = dfs(node.right);

    int[] cur = new int[2];
    // 不偷 node：孩子可偷可不偷
    cur[0] = Math.max(left[0], left[1]) + Math.max(right[0], right[1]);
    // 偷 node：孩子绝对不能偷
    cur[1] = node.val + left[0] + right[0];

    return cur;
}
// O(n) 时间 O(h) 空间（递归栈）
// ⚠️ 树形 DP 的套路：
//   后序聚合 + 每个节点返回"多种状态"
```

## 10. 62. 不同路径（网格 DP）

### 10.1 完整实现

```java
/**
 * LeetCode 62. 不同路径
 * 只能右/下 → dp[i][j] = dp[i-1][j] + dp[i][j-1]
 */
public int uniquePaths(int m, int n) {
    int[] dp = new int[n];             // 滚动：只保留一行
    Arrays.fill(dp, 1);                // 第一行全 1

    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            dp[j] += dp[j - 1];        // 上（dp[j] 旧值）+ 左（dp[j-1]）
        }
    }
    return dp[n - 1];
}
// O(mn) 时间 O(n) 空间（滚动优化）
// 组合公式：C(m+n-2, m-1)（数学解法）
// ⚠️ 变体：63 有障碍（障碍处 dp=0）
//   面试追问："数学解法更快，但障碍场景
//   只能用 DP（公式无法处理约束）"
```
