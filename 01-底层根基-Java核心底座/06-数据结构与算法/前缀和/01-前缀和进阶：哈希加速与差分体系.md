## 1. 前缀和的核心公式与形态

### 1.1 定义与公式

```
前缀和：pre[i] = 前 i 个元素之和（pre[0] = 0）
  子数组 [l, r) 之和 = pre[r] - pre[l]（O(1) 查询）

⚠️ 核心变换：区间和 → 前缀和差
  sum[l..r] = pre[r+1] - pre[l]
  任意区间和查询 O(1)（预计算 O(n)）

⚠️ 面试必答：
"前缀和把'任意区间和'从 O(n) 降到 O(1)——
 空间 O(n) 换时间。所有'多次区间查询'
 问题都先想到它。"
```

### 1.2 三种形态

| 形态 | 结构 | 应用 |
|------|------|------|
| 一维前缀和 | pre[i+1] = pre[i] + a[i] | 303 区间和查询 |
| 二维前缀和 | 容斥递推 | 304 矩阵区域和 |
| 差分数组 | diff[i] = a[i] - a[i-1] | 370 区间加法 |

```
⚠️ 与前缀和的互逆：
  前缀和：差分数组的前缀和 = 原数组
  差分：原数组的差分 = 区间修改的载体
  → 两者互为逆运算（01 模块 5 节详述）
```

### 1.3 前缀和的扩展

```
① 前缀异或：preXor[i]（异或无进位 → 区间异或 = preXor[r]^preXor[l]）
② 前缀计数：字符/值出现次数（见计数/01）
③ 前缀最大值/最小值（区间最值另有 RMQ 更优）
④ 前缀乘积（注意 0 的处理）

⚠️ 面试表达：
"前缀思想通用化：任何'可逆运算'都能做前缀——
 加减（和）、异或（自逆）、计数（频次）。"
```

## 2. 前缀和 + 哈希：和为 K 家族

### 2.1 核心模式（560）

```
问题：和为 K 的子数组个数
暴力：枚举所有子数组 O(n²)
前缀和 + 哈希：O(n)
  ⚠️ 关键公式：sum[l..r] = K ⟺ pre[r] - pre[l-1] = K
  ⟺ pre[l-1] = pre[r] - K
  → 遍历 r 时，查"历史前缀和中 pre[r]-K 的个数"

⚠️ 面试必答：
"和为 K 的判定等价于'找 pre[r]-K 在前缀和
 历史中出现几次'——一次遍历 + 哈希计数，
 O(n²) 降到 O(n)。"
```

### 2.2 完整模板

```java
/** 560. 和为 K 的子数组（前缀和 + 哈希） */
public int subarraySum(int[] nums, int k) {
    Map<Integer, Integer> count = new HashMap<>();
    count.put(0, 1);                       // ⚠️ pre[0]=0 出现 1 次（全前缀）
    int pre = 0, result = 0;

    for (int x : nums) {
        pre += x;                          // 当前前缀和
        // ⚠️ 找历史中 pre - k 出现的次数
        result += count.getOrDefault(pre - k, 0);
        count.merge(pre, 1, Integer::sum); // 记录当前前缀和
    }
    return result;
}
// 推演 [1,1,1], k=2：
//   pre=1：查 pre-2=-1 → 0；记 {0:1, 1:1}
//   pre=2：查 0 → 1（子数组 [1,1]）✓；记 {2:1}
//   pre=3：查 1 → 1（子数组 [1,1]）✓ → 结果 2 ✓
// ⚠️ 复杂度：O(n)（对比暴力 O(n²)）
// ⚠️ 变体：
//   325 最长和为 K 的子数组：Map 存"首次出现下标"（取最长）
//   525 连续数组（01 转换）：和 = 0 的子数组
//   930 和相同的二元子数组：同模板
```

### 2.3 家族变体对照

| 题号 | 变体 | 哈希存什么 |
|------|------|-----------|
| 560 | 和为 K 的个数 | 前缀和 → 出现次数 |
| 325 | 最长和为 K | 前缀和 → 首次下标 |
| 525 | 01 平衡 | 差值前缀和 → 首次下标 |
| 974 | 可被 K 整除 | 前缀和 mod K → 次数 |

## 3. 模运算：可整除子数组

### 3.1 974 的核心思想

```
可被 K 整除 ⟺ pre[r] ≡ pre[l] (mod K)
  （区间和 mod K = 0 ⟺ 两个前缀和同余）
→ 统计同余的前缀和配对

⚠️ Java 负数取模陷阱：
  -1 % 5 = -1（Java 结果非负才方便哈希）
  → 统一转换：(x % K + K) % K

⚠️ 面试必答：
"可整除 = 前缀和同余。Java 取模负数
 要转正：(x%K+K)%K，否则哈希键错乱。"
```

### 3.2 完整实现

```java
/** 974. 和可被 K 整除的子数组 */
public int subarraysDivByK(int[] nums, int k) {
    Map<Integer, Integer> count = new HashMap<>();
    count.put(0, 1);
    int pre = 0, result = 0;

    for (int x : nums) {
        pre += x;
        int mod = ((pre % k) + k) % k;     // ⚠️ 负数取模转正
        result += count.getOrDefault(mod, 0);
        count.merge(mod, 1, Integer::sum);
    }
    return result;
}
// 推演 [4,5,0,-2,-3,1], k=5：
//   pre mod: 4, 4, 4, 2, 4, 0
//   同余 4 出现 4 次 → C(4,2)=6 个配对 + mod 0 配对...
//   结果 7 ✓
// ⚠️ 变体 523 连续子数组和（长度 ≥ 2）：
//   记录"首次出现下标"，检查长度 ≥ 2

/** 523 变体要点： */
Map<Integer, Integer> firstPos = new HashMap<>();
firstPos.put(0, -1);
// 遍历时：if (firstPos.containsKey(mod) && i - firstPos.get(mod) >= 2) return true;
// ⚠️ 长度约束用"首次下标差"实现
```

## 4. 二维前缀和：容斥原理

### 4.1 递推与查询公式

```
二维前缀和：S[i][j] = 左上角 (0,0) 到 (i,j) 的矩形和
  递推：S[i][j] = S[i-1][j] + S[i][j-1] - S[i-1][j-1] + a[i][j]
  查询：(r1,c1)-(r2,c2) 区域和
    = S[r2][c2] - S[r1-1][c2] - S[r2][c1-1] + S[r1-1][c1-1]
⚠️ 容斥：加两块、减重叠、再加回双减
```

```java
/** 304. 二维区域和检索（容斥模板） */
class NumMatrix {
    private final int[][] pre;               // 前缀和矩阵（多一圈防越界）

    public NumMatrix(int[][] matrix) {
        int m = matrix.length, n = matrix[0].length;
        pre = new int[m + 1][n + 1];         // ⚠️ 多一圈：pre[i+1][j+1]
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                pre[i + 1][j + 1] = pre[i + 1][j] + pre[i][j + 1]
                        - pre[i][j] + matrix[i][j];   // ⚠️ 容斥递推
    }

    public int sumRegion(int r1, int c1, int r2, int c2) {
        return pre[r2 + 1][c2 + 1] - pre[r1][c2 + 1]
             - pre[r2 + 1][c1] + pre[r1][c1];         // ⚠️ 容斥查询
    }
}
// 推演 [[3,0,1],[5,6,3],[1,0,1]] 查询 (1,1)-(2,2)：
//   pre 计算后查询：6+1+0+1 = 8？(1,1)=6, (1,2)=3, (2,1)=0, (2,2)=1 → 10
//   公式：pre[3][3]-pre[1][3]-pre[3][1]+pre[1][1] ✓
// ⚠️ 面试表达："二维前缀和 = 容斥两遍——
//   递推时加两块减重叠；查询时同样容斥。
//   多开一圈（m+1 × n+1）免去边界特判。"
```

## 5. 差分数组：区间操作的利器

### 5.1 差分数组的定义

```
差分：diff[i] = a[i] - a[i-1]（diff[0] = a[0]）
  前缀和还原：a[i] = Σ diff[0..i]

⚠️ 区间加法的核心性质：
  对 [l, r] 区间 +v ⟺ diff[l] += v; diff[r+1] -= v
  一次 O(1) 修改 → 最后前缀和还原 O(n)

⚠️ 面试必答：
"'区间修改 + 单点查询'→ 差分数组：
 区间两端打标记（+v / -v），最后前缀和
 还原。多次区间操作从 O(n) 降到 O(1)。"
```

### 5.2 完整模板（370 区间加法）

```java
/** 370. 区间加法：diff[l]+=v, diff[r+1]-=v */
public int[] getModifiedArray(int length, int[][] updates) {
    int[] diff = new int[length + 1];        // ⚠️ +1 防 r+1 越界

    for (int[] u : updates) {
        diff[u[0]] += u[2];                  // 区间起点 +v
        diff[u[1] + 1] -= u[2];              // 区间终点后 -v
    }
    // 前缀和还原
    int[] result = new int[length];
    result[0] = diff[0];
    for (int i = 1; i < length; i++)
        result[i] = result[i - 1] + diff[i];
    return result;
}
// 推演 length=5, updates=[[1,3,2],[2,4,3]]：
//   diff：[0,2,3,-2,-3,0]
//   还原：[0,2,5,3,0] ✓（区间 1-3 +2 → [0,2,2,2,0]；2-4 +3 → [0,2,5,5,3]？）
//   ⚠️ 上推演：update1 [1,3]+2 → 位置 1,2,3 各 +2
//     update2 [2,4]+3 → 位置 2,3,4 各 +3 → [0,2,5,5,3] ✓
// ⚠️ 变体：1094 拼车（上下车区间）、1109 航班预订
//   1109：diff[start]+=k, diff[end+1]-=k → 同模板
```

### 5.3 差分 vs 前缀和的选型

| 场景 | 工具 |
|------|------|
| 多次区间查询 | 前缀和（预计算 O(n)，查询 O(1)） |
| 多次区间修改 | 差分（修改 O(1)，还原 O(n)） |
| 动态修改 + 查询 | 树状数组/线段树（两者都不够） |

```
⚠️ 面试表达：
"前缀和适合'查询多修改少'；差分适合
 '修改多查询少'；两者都动态 → 树状数组。
 互为逆运算是理解它们的关键。"
```

## 6. 前缀异或与位运算

### 6.1 异或的可逆性

```
异或自逆：a ^ a = 0 → 前缀异或的区间查询
  区间异或 [l, r] = preXor[r+1] ^ preXor[l]
  （与和不同：异或减法 = 异或自身）

⚠️ 面试必答：
"前缀异或与前缀和同构——异或的'逆'是
 自己（a^a=0）。1310 区间异或查询
 就是 preXor[r] ^ preXor[l-1]。"
```

### 6.2 1310 完整实现

```java
/** 1310. 子数组异或查询 */
public int[] xorQueries(int[] arr, int[][] queries) {
    int n = arr.length;
    int[] pre = new int[n + 1];              // ⚠️ 前缀异或
    for (int i = 0; i < n; i++)
        pre[i + 1] = pre[i] ^ arr[i];        // 异或递推

    int[] res = new int[queries.length];
    for (int i = 0; i < queries.length; i++) {
        int l = queries[i][0], r = queries[i][1];
        res[i] = pre[r + 1] ^ pre[l];        // ⚠️ 区间异或 = 前缀异或相消
    }
    return res;
}
// 推演 arr=[1,3,4,8], 查询 [0,1]：
//   pre=[0,1,2,6,14]；区间 [0,1] = pre[2]^pre[0] = 2^0 = 2 = 1^3 ✓
// ⚠️ 复杂度：O(n + q)
// ⚠️ 应用：异或性质题（找不同/只出现一次）可配前缀异或
```

## 7. 面试要点与追问

### 7.1 面试话术模板

```
"区间问题先想前缀：预计算 O(n) → 查询 O(1)。
 和为 K → 前缀和 + 哈希（查 pre-k 出现次数）。
 可整除 → mod K 同余（负数转正）。
 二维 → 容斥。区间修改 → 差分（两端打标）。
 前缀异或 → 区间异或相消。"
```

### 7.3 常见错误

| 错误 | 后果 | 修正 |
