## 1. 排列与子集的本质

### 1.1 三兄弟对比

| 题型 | 顺序相关 | 收集时机 | 防重手段 | 结果数 |
|------|:---:|------|------|:---:|
| **组合** | ❌ | 满足条件时（如长度=k） | startIndex | C(n,k) |
| **排列** | ✅ | 满足条件时（长度=n） | used 数组 | n! |
| **子集** | ❌ | **每层都收集**（进入即收集） | startIndex | 2ⁿ |

### 1.2 核心差异一句话

```
组合：选 k 个，不讲究顺序，用 start 防回头
排列：选全部，讲究顺序，用 used 防重复选
子集：选任意个，每个节点都是解，start 防回头 + 进入即收集
```

## 2. 46. 全排列：used 数组

### 2.1 完整实现

```java
/**
 * LeetCode 46. 全排列
 * 给定一个不含重复数字的数组 nums，返回其所有可能的全排列。
 *
 * 与组合模板的三处不同：
 *   1. 每层从 0 开始遍历（不是 start）
 *   2. 用 used[] 标记已选元素，跳过
 *   3. 结束条件：path.size() == nums.length
 */
public List<List<Integer>> permute(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    boolean[] used = new boolean[nums.length];
    backtrack(nums, used, new ArrayList<>(), res);
    return res;
}

private void backtrack(int[] nums, boolean[] used,
                       List<Integer> path, List<List<Integer>> res) {
    if (path.size() == nums.length) {          // ① 收集
        res.add(new ArrayList<>(path));
        return;
    }

    for (int i = 0; i < nums.length; i++) {    // ② 从 0 开始！
        if (used[i]) continue;                 // ③ 跳过已选

        used[i] = true;                        // ④ 标记
        path.add(nums[i]);
        backtrack(nums, used, path, res);
        path.remove(path.size() - 1);          // ⑤ 撤销
        used[i] = false;                       //    ⚠️ 标记也要撤销！
    }
}
```

### 2.2 为什么必须从 0 开始 + used？

```
排列 [1,2,3] 的第一层：
  选 1 → 剩余可 [2,3]（第二层从 0 扫：1 被 used 跳过 → 选 2/3）
  选 2 → 剩余可 [1,3]
  选 3 → 剩余可 [1,2]

如果用 startIndex：选 1 后第二层只能选 2/3，
  永远产生不了 [1,3,2]（第三层才回到 1 之前的位置）
  → start 是组合的"不回头"，排列需要"回头但不重复" → used 数组

撤销时必须同时恢复 used[i] = false —— 这是最常见的遗漏点
```

## 3. 47. 全排列 II：去重的艺术

### 3.1 完整实现

```java
/**
 * LeetCode 47. 全排列 II（26届秋招真实手撕题）
 * 给定含重复数字的数组，返回所有不重复的全排列。
 *
 * 去重核心（排列版）：
 *   if (i > 0 && nums[i] == nums[i-1] && !used[i-1]) continue;
 *
 * 理解：排序后，相同值相邻。当 nums[i]==nums[i-1] 且
 *   nums[i-1] 尚未被使用（!used[i-1]）时，
 *   —— 说明同一层已经用相同的值选过一次了 → 跳过
 *   （如果 used[i-1]=true，说明重复值在同一条路径上，是合法的）
 */
public List<List<Integer>> permuteUnique(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    Arrays.sort(nums);                        // ⚠️ 去重前提：排序
    boolean[] used = new boolean[nums.length];
    backtrack(nums, used, new ArrayList<>(), res);
    return res;
}

private void backtrack(int[] nums, boolean[] used,
                       List<Integer> path, List<List<Integer>> res) {
    if (path.size() == nums.length) {
        res.add(new ArrayList<>(path));
        return;
    }

    for (int i = 0; i < nums.length; i++) {
        if (used[i]) continue;

        // ⚠️ 排列去重：同层相同值只允许最左边那个先选
        if (i > 0 && nums[i] == nums[i - 1] && !used[i - 1]) continue;

        used[i] = true;
        path.add(nums[i]);
        backtrack(nums, used, path, res);
        path.remove(path.size() - 1);
        used[i] = false;
    }
}
```

### 3.2 为什么要 `!used[i-1]`？

```
nums = [1, 1, 2]，去重条件逐层推演：

第一层：
  i=0 选 nums[0]=1（used=[T,F,F]）→ 子树产生 {1,...}
  i=1: nums[1]==nums[0] && !used[0] → 跳过！
    （同层已经用 1 展开过，再展开完全重复）
  i=2 选 2 → 子树产生 {2,...}

path=[1] 的第二层（used=[T,F,F]）：
  i=0: used[0] → 跳过
  i=1: nums[1]==1 但 used[0]=true → 不跳过！合法！
    （这是路径上第二次用 1 → [1,1,2] 的一部分）
  i=2: 选 2 → [1,2] → 第三层选 1 → [1,2,1]

结论：!used[i-1] 区分"同层重复"（跳过）和"同路径重复"（保留）
```

### 3.3 两种写法对照

```java
// 写法 A（推荐）：i>0 && nums[i]==nums[i-1] && !used[i-1] → continue
// 保证同层相同值只用第一个，其他跳过

// 写法 B（等价）：i>0 && nums[i]==nums[i-1] && used[i-1] → continue
// 保留最后一个相同值。两种都行，但 A 更常见

// ⚠️ 千万别写：i>0 && nums[i]==nums[i-1] → continue（无条件）
// 这样会把同路径合法的 [1,1,...] 也剪掉！
```

## 4. 78. 子集：进入即收集

### 4.1 完整实现

```java
/**
 * LeetCode 78. 子集
 * 给定不含重复元素的数组，返回所有子集（含空集）。
 * nums = [1,2,3] → [[],[1],[2],[3],[1,2],[1,3],[2,3],[1,2,3]]
 *
 * 与组合的唯一区别：
 *   组合：只在 path 长度 == k 时收集
 *   子集：进入递归就收集 —— 每个节点都是合法子集！
 */
public List<List<Integer>> subsets(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    backtrack(nums, 0, new ArrayList<>(), res);
    return res;
}

private void backtrack(int[] nums, int start,
                       List<Integer> path, List<List<Integer>> res) {
    res.add(new ArrayList<>(path));          // ⚠️ 进入即收集（含空集）

    for (int i = start; i < nums.length; i++) {
        path.add(nums[i]);
        backtrack(nums, i + 1, path, res);
        path.remove(path.size() - 1);
    }
}
```

### 4.2 为什么"进入即收集"正好生成所有子集？

```
决策树（nums=[1,2,3]）：

            []  ← 根节点收集（空集）
     ┌──────┼──────┐
    [1]    [2]    [3]      ← 第一层收集
   ┌─┼─┐    └──┐
 [1,2] [1,3] [2,3]          ← 第二层收集
   │
 [1,2,3]                     ← 第三层收集

每个节点对应一个子集 → 节点总数 = 2³ = 8 = 子集数 ✓
（组合题只在叶子节点收集，所以少很多）
```

## 5. 90. 子集 II：排序去重

### 5.1 完整实现

```java
/**
 * LeetCode 90. 子集 II
 * 与 78 区别：数组含重复元素，返回不重复的子集。
 *
 * 去重：同 40 组合总和 II —— 排序 + 同层去重
 *   if (i > start && nums[i] == nums[i-1]) continue;
 */
public List<List<Integer>> subsetsWithDup(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    Arrays.sort(nums);                        // ⚠️ 排序
    backtrack(nums, 0, new ArrayList<>(), res);
    return res;
}

private void backtrack(int[] nums, int start,
                       List<Integer> path, List<List<Integer>> res) {
    res.add(new ArrayList<>(path));           // 进入即收集

    for (int i = start; i < nums.length; i++) {
        if (i > start && nums[i] == nums[i - 1]) continue;  // 同层去重

        path.add(nums[i]);
        backtrack(nums, i + 1, path, res);
        path.remove(path.size() - 1);
    }
}
// nums=[1,2,2] → [[],[1],[1,2],[1,2,2],[2],[2,2]]
// 注意：子集是组合的去重版本，用 i>start（而非排列的 !used[i-1]）
```

## 6. 491. 非递减子序列：Set 去重

### 6.1 为什么不能排序？

```java
/**
 * LeetCode 491. 非递减子序列
 * 找出数组中所有不同的非递减子序列，至少两个元素。
 *
 * ⚠️ 特殊点：不能排序！因为要求"原数组中的相对顺序"不变
 *   → 无法用"排序 + 相邻去重" → 每层用 Set 记录本层已用的值
 */
public List<List<Integer>> findSubsequences(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    backtrack(nums, 0, new ArrayList<>(), res);
    return res;
}

private void backtrack(int[] nums, int start,
                       List<Integer> path, List<List<Integer>> res) {
    if (path.size() >= 2) {                  // 至少两个元素
        res.add(new ArrayList<>(path));
    }

    Set<Integer> usedThisLevel = new HashSet<>();   // ⚠️ 本层去重 Set
    for (int i = start; i < nums.length; i++) {
        // 剪枝 1：保持非递减
        if (!path.isEmpty() && nums[i] < path.get(path.size() - 1)) continue;
        // 剪枝 2：本层已用过相同值 → 跳过
        if (usedThisLevel.contains(nums[i])) continue;

        usedThisLevel.add(nums[i]);
        path.add(nums[i]);
        backtrack(nums, i + 1, path, res);
        path.remove(path.size() - 1);
    }
}
```

### 6.2 Set 去重 vs 排序去重

| 方式 | 前提 | 用法 | 场景 |
|------|------|------|------|
| 排序 + 相邻去重 | 可以排序 | `i>start && nums[i]==nums[i-1]` | 40/90/47 |
| **Set 层内去重** | 不能排序 | `Set.contains(x) → continue` | 491 非递减子序列 |

> 💡 **判断标准**：题目是否要求"保持原数组相对顺序"？要求 → Set 去重；不要求 → 排序去重更高效。

## 7. 去重技术对比总结

### 7.1 三种去重速查

| 场景 | 代码 | 适用题 | 关键理解 |
|------|------|:---:|------|
| 组合/子集去重 | `i > start && nums[i]==nums[i-1]` | 40/90 | 同层重复 → 结果重复 |
| 排列去重 | `i > 0 && nums[i]==nums[i-1] && !used[i-1]` | 47 | 同层 + 路径区分 |
| 子序列去重 | 每层 `Set` 记录 | 491 | 不能排序的场景 |

### 7.2 面试高频追问

| 追问 | 标准回答 |
|------|------|
| 排列去重为什么还要 `!used[i-1]`？ | 区分"同层重复"（重复值已在同层展开过，跳过）和"同路径重复"（重复值分布在路径不同位置，如 [1,1,2] 合法） |
| 子集为什么进入就收集？ | 每个节点都代表一个前缀子集，节点总数 = 2ⁿ = 子集总数，天然一一对应 |
| 491 为什么不能用排序去重？ | 题目要求保持原数组相对顺序，排序会破坏顺序 → 改用层内 Set |
| 组合 vs 排列防重区别？ | 组合用 start 防"回头重复"，排列用 used 防"重复选择"，一维 vs 二维的防重 |

> 🎯 **核心要点**：排列用 `used[]` 且从 0 遍历（顺序相关），组合/子集用 `startIndex`（顺序无关）。去重必须排序（或 Set），且注意**同层去重 vs 同路径去重**的本质区别。子集与组合的唯一差异是**收集时机**——进入即收集还是满足条件才收集。
