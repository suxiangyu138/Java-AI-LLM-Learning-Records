## 1. 切割问题的本质

### 1.1 组合与切割的视角转换

```
组合视角：从 [1,2,3,4] 中选元素
  [1,2] [1,3] [1,4] [2,3] [2,4] [3,4]

切割视角：把字符串 "aab" 切成若干段，每段合法
  "a"|"a"|"b"
  "a"|"ab"
  "aa"|"b"
  "aab"

两者完全同构！start 既是"选元素的起点"，也是"切割线的位置"：
  组合：path.add(nums[i]) → 选一个元素
  切割：path.add(s.substring(start, i+1)) → 切下一段
```

### 1.2 切割模板

```java
void backtrack(String s, int start, List<String> path, List<List<String>> res) {
    if (start == s.length()) {          // ① 切完了整串
        res.add(new ArrayList<>(path));
        return;
    }
    for (int i = start; i < s.length(); i++) {
        String segment = s.substring(start, i + 1);   // ② 切割段 [start, i]
        if (!isValid(segment)) continue;              // ③ 合法性校验（剪枝）

        path.add(segment);
        backtrack(s, i + 1, path, res);               // ④ 从 i+1 继续切
        path.remove(path.size() - 1);
    }
}
```

## 2. 131. 分割回文串

### 2.1 完整实现

```java
/**
 * LeetCode 131. 分割回文串
 * 给你一个字符串 s，将 s 分割成一些子串，使每个子串都是回文串。
 * 返回所有可能的分割方案。
 *
 * 判断回文可用双指针（O(n)）或预处理 DP 表（O(n²) 建表 O(1) 查询）
 */
public List<List<String>> partition(String s) {
    List<List<String>> res = new ArrayList<>();
    // 预处理回文表：isPal[i][j] 表示 s[i..j] 是否回文
    boolean[][] isPal = precomputePalindrome(s);
    backtrack(s, 0, isPal, new ArrayList<>(), res);
    return res;
}

private void backtrack(String s, int start, boolean[][] isPal,
                       List<String> path, List<List<String>> res) {
    if (start == s.length()) {
        res.add(new ArrayList<>(path));
        return;
    }

    for (int i = start; i < s.length(); i++) {
        if (!isPal[start][i]) continue;      // 剪枝：非回文段跳过

        path.add(s.substring(start, i + 1));
        backtrack(s, i + 1, isPal, path, res);
        path.remove(path.size() - 1);
    }
}

// 预处理：dp[i][j] = (s[i]==s[j]) && (j-i<=1 || dp[i+1][j-1])
private boolean[][] precomputePalindrome(String s) {
    int n = s.length();
    boolean[][] dp = new boolean[n][n];
    for (int len = 1; len <= n; len++) {               // 区间长度
        for (int i = 0; i + len - 1 < n; i++) {
            int j = i + len - 1;
            if (s.charAt(i) == s.charAt(j) && (len <= 2 || dp[i + 1][j - 1])) {
                dp[i][j] = true;
            }
        }
    }
    return dp;
}
```

### 2.2 区间剪枝要点

```
分割回文串的核心剪枝：每个切割段必须合法（回文）
  → 把 O(n) 的回文判断升级为 O(1) 的表查询 → 整体效率大增

区间 DP 回文判断（面试加分项）：
  dp[i][j] = (s[i]==s[j]) && (j-i<=1 || dp[i+1][j-1])
  长度 1：单字符必回文
  长度 2：两字符相等
  长度 >2：首尾相等 + 内部回文
```

## 3. 93. 复原 IP 地址

### 3.1 完整实现（26届秋招真实手撕题）

```java
/**
 * LeetCode 93. 复原 IP 地址（26届秋招面经题）
 * 有效 IP 地址：由 4 段组成，每段 0-255，且不能有前导零。
 *
 * 约束三重：
 *   1. 恰好 4 段
 *   2. 每段数值 [0,255]
 *   3. 段内无前导零（"01" 非法，"0" 合法）
 */
public List<String> restoreIpAddresses(String s) {
    List<String> res = new ArrayList<>();
    if (s.length() < 4 || s.length() > 12) return res;  // 长度剪枝
    backtrack(s, 0, 0, new StringBuilder(), res);
    return res;
}

private void backtrack(String s, int start, int segments,
                       StringBuilder path, List<String> res) {
    // 剪枝 1：段数到 4 但还没用完字符 → 非法
    if (segments == 4) {
        if (start == s.length()) res.add(path.toString());
        return;
    }
    // 剪枝 2：剩余字符不足以填满剩余段数
    int remaining = s.length() - start;
    int need = 4 - segments;
    if (remaining < need || remaining > need * 3) return;

    for (int i = start; i < start + 3 && i < s.length(); i++) {
        String segment = s.substring(start, i + 1);

        // 剪枝 3：段合法性（无前导零 + 数值 ≤ 255）
        if (segment.length() > 1 && segment.charAt(0) == '0') break;
        int val = Integer.parseInt(segment);
        if (val > 255) break;                 // 单调剪枝：再长更大

        int lenBefore = path.length();
        if (segments > 0) path.append('.');   // 除第一段外加分隔点
        path.append(segment);

        backtrack(s, i + 1, segments + 1, path, res);

        path.setLength(lenBefore);            // 撤销：回退到加段前
    }
}
```

### 3.2 剪枝清单

| 剪枝 | 条件 | 作用 |
|------|------|------|
| 总长剪枝 | `s.length() < 4 || > 12` | 直接排除不可能输入 |
| 段数剪枝 | `segments == 4 && start != n` | 提前终止错误路径 |
| 剩余字符剪枝 | `remaining < need \|\| > need*3` | 每段 1-3 位，范围外不可能 |
| 前导零剪枝 | `"01"` 开头为 0 | 段非法 |
| 数值剪枝 | `> 255` 则 break | 单调：段更长只会更大 |

## 4. 51. N 皇后

### 4.1 问题与核心约束

```java
/**
 * LeetCode 51. N 皇后（回溯棋盘问题代表题）
 * n×n 棋盘放置 n 个皇后，任意两个皇后不能在同一行、同一列、同一对角线。
 *
 * 约束分析（用数组代替二维判断）：
 *   row: 每行放一个（回溯层数 = 行号，天然满足"每行一个"）
 *   col[i]: 第 i 列是否已被占用
 *   diag1[row+col]: 主对角线（/ 方向），row+col 为常数
 *   diag2[row-col+n-1]: 副对角线（\ 方向），row-col 为常数
 */
public List<List<String>> solveNQueens(int n) {
    List<List<String>> res = new ArrayList<>();
    boolean[] col = new boolean[n];
    boolean[] diag1 = new boolean[2 * n - 1];   // row + col 范围 [0, 2n-2]
    boolean[] diag2 = new boolean[2 * n - 1];   // row - col + n - 1 范围 [0, 2n-2]
    char[][] board = new char[n][n];
    for (char[] row : board) Arrays.fill(row, '.');
    backtrack(n, 0, col, diag1, diag2, board, res);
    return res;
}

private void backtrack(int n, int row,
                       boolean[] col, boolean[] diag1, boolean[] diag2,
                       char[][] board, List<List<String>> res) {
    if (row == n) {                              // 所有行都放好
        List<String> list = new ArrayList<>();
        for (char[] r : board) list.add(new String(r));
        res.add(list);
        return;
    }

    for (int c = 0; c < n; c++) {
        int d1 = row + c;                        // 主对角线编号
        int d2 = row - c + n - 1;                // 副对角线编号
        if (col[c] || diag1[d1] || diag2[d2]) continue;  // 冲突剪枝

        board[row][c] = 'Q';
        col[c] = diag1[d1] = diag2[d2] = true;
        backtrack(n, row + 1, col, diag1, diag2, board, res);
        board[row][c] = '.';                     // 撤销
        col[c] = diag1[d1] = diag2[d2] = false;
    }
}
```

### 4.2 对角线编号原理

```
n=4 棋盘（行 row=0..3, 列 col=0..3）：

主对角线 /：row+col 相同 → 编号 d1 = row+col
  0 1 2 3
  1 2 3 4
  2 3 4 5
  3 4 5 6

副对角线 \：row-col 相同 → 编号 d2 = row-col+n-1（偏移防负）
  3 2 1 0
  4 3 2 1
  5 4 3 2
  6 5 4 3

用三个 boolean 数组 O(1) 判冲突，取代 O(n) 扫描
```

## 5. 37. 解数独

### 5.1 完整实现

```java
/**
 * LeetCode 37. 解数独（棋盘回溯 + 约束传播）
 * 填写空白格（'.'），使每行/每列/每个 3×3 宫格包含 1-9 各一次。
 *
 * 模板差异：
 *   1. 按格子扫描而非按行回溯
 *   2. 找到一个解即可 → 递归返回 boolean 提前终止
 */
public void solveSudoku(char[][] board) {
    boolean[][] rows = new boolean[9][10];
    boolean[][] cols = new boolean[9][10];
    boolean[][] boxes = new boolean[9][10];

    // 初始化：记录已填数字
    for (int i = 0; i < 9; i++)
        for (int j = 0; j < 9; j++)
            if (board[i][j] != '.') {
                int d = board[i][j] - '0';
                rows[i][d] = cols[j][d] = boxes[boxIndex(i, j)][d] = true;
            }

    backtrack(board, 0, 0, rows, cols, boxes);
}

private boolean backtrack(char[][] board, int i, int j,
                          boolean[][] rows, boolean[][] cols, boolean[][] boxes) {
    if (i == 9) return true;                  // 扫完全部格子 → 有解
    if (j == 9) return backtrack(board, i + 1, 0, rows, cols, boxes);
    if (board[i][j] != '.')                   // 已填 → 跳下一个
        return backtrack(board, i, j + 1, rows, cols, boxes);

    for (int d = 1; d <= 9; d++) {
        int b = boxIndex(i, j);
        if (rows[i][d] || cols[j][d] || boxes[b][d]) continue;  // 冲突剪枝

        board[i][j] = (char) ('0' + d);
        rows[i][d] = cols[j][d] = boxes[b][d] = true;

        if (backtrack(board, i, j + 1, rows, cols, boxes)) return true;

        board[i][j] = '.';                    // 撤销
        rows[i][d] = cols[j][d] = boxes[b][d] = false;
    }
    return false;                             // 9 个数都试过 → 无解回溯
}

private int boxIndex(int i, int j) {
    return (i / 3) * 3 + j / 3;               // 3×3 宫格编号
}
```

## 6. 79. 单词搜索

### 6.1 完整实现

```java
/**
 * LeetCode 79. 单词搜索
 * 在 m×n 网格中找单词，四方向移动，同一格子不能重复使用。
 *
 * 模板差异：
 *   1. 选择列表 = 当前格子的四个方向
 *   2. 结束条件 = 匹配完单词全部字母
 *   3. visited 标记走过（或原地修改 board）
 */
public boolean exist(char[][] board, String word) {
    int m = board.length, n = board[0].length;
    boolean[][] visited = new boolean[m][n];

    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            if (backtrack(board, word, 0, i, j, visited))
                return true;                  // 找到一个即可
    return false;
}

private boolean backtrack(char[][] board, String word, int index,
                          int i, int j, boolean[][] visited) {
    // 剪枝 1：字符不匹配 → 立即返回
    if (board[i][j] != word.charAt(index)) return false;

    // 结束条件：匹配完最后一个字符
    if (index == word.length() - 1) return true;

    visited[i][j] = true;                     // 标记走过

    int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};
    for (int[] d : dirs) {
        int ni = i + d[0], nj = j + d[1];
        // 剪枝 2：越界或已访问 → 跳过
        if (ni < 0 || ni >= board.length || nj < 0 || nj >= board[0].length) continue;
        if (visited[ni][nj]) continue;

        if (backtrack(board, word, index + 1, ni, nj, visited)) return true;
    }

    visited[i][j] = false;                    // 撤销标记
    return false;
}
```

## 7. 切割 vs 棋盘：剪枝对比总结

### 7.1 五类回溯题完整对比

| 题型 | 选择列表 | 结束条件 | 主要剪枝 | 代表题 |
|------|------|------|------|:---:|
| 组合 | `[start, n)` | 长度/总和达标 | 范围、单调 | 77/39/40 |
| 排列 | 全数组跳过 used | 长度 = n | 同层去重 | 46/47 |
| 子集 | `[start, n)` | 每层收集 | 同层去重 | 78/90 |
| 切割 | 切点 `[start, n)` | start = n | 段合法性、剩余长度 | 131/93 |
| 棋盘 | 方向/位置集合 | 摆满/匹配完 | 冲突、越界、visited | 51/37/79 |

### 7.2 剪枝四步法

```
拿到回溯题 → 按顺序剪枝：
1. 全局剪枝：输入本身不可能有解？（93 长度 <4）
2. 剩余量剪枝：剩余空间填不满/放不下？（77 范围、93 剩余字符）
3. 合法性剪枝：当前选择是否合法？（131 回文、51 冲突、93 前导零）
4. 单调剪枝：排序后可否 break？（39/40 总和超限）
```

### 7.3 面试高频追问

| 追问 | 标准回答 |
|------|------|
| 切割问题怎么理解成组合？ | start 既是选元素起点也是切割线位置，切割段 = substring(start, i+1) |
| N 皇后为什么用三个数组判重？ | row+col 与 row-col 在对角线上是常数，O(1) 冲突检测 |
| 数独/单词搜索怎么提前终止？ | 递归返回 boolean，找到解逐层 return true |
| 单词搜索 visited 能优化吗？ | 可以原地把 board[i][j] 改成 '#' 或 '\0'，省 O(mn) 空间 |

> 🎯 **核心要点**：切割问题把"选元素"换成"切位置"（substring），棋盘问题把"线性选择"换成"多维约束"（行列对角线/方向），本质仍是"选择→递归→撤销"模板。**剪枝是棋盘题的灵魂**——冲突检测、剩余量判断、提前终止（boolean 返回），做好剪枝才能从"能解"到"高效解"。
