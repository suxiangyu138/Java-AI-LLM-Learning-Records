## 优先队列基础

### 1. 定义

优先队列是一种特殊队列，元素出队顺序按**优先级**而非入队顺序决定。优先级由比较规则定义（升序/降序/自定义规则）。

### 2. 核心特性

| 操作 | 时间复杂度 |
|------|-----------|
| 插入 | O(log n) |
| 取最值（堆顶） | O(1) |
| 删除最值 | O(log n) |

### 3. 底层实现对比

| 实现方式 | 插入 | 取最值 | 删除最值 |
|----------|------|--------|----------|
| **堆（完全二叉树）** | **O(log n)** | **O(1)** | **O(log n)** |
| 有序数组 | O(n) | O(1) | O(1) |
| 无序数组 | O(1) | O(n) | O(n) |

> **堆是最优实现**，时间复杂度稳定且均衡。

## 堆的核心概念

### 1. 定义

堆是**完全二叉树**，分为大顶堆与小顶堆：

```
      大顶堆                    小顶堆
        9                        1
       / \                      / \
      7   8                    3   2
     / \ / \                  / \ / \
    5  6 3  4                5  4 6  7
```

| 类型 | 规则 | 堆顶 |
|------|------|------|
| **大顶堆（Max Heap）** | 父节点 ≥ 子节点 | 最大值 |
| **小顶堆（Min Heap）** | 父节点 ≤ 子节点 | 最小值 |

### 2. 存储结构

堆使用**数组顺序存储**（利用完全二叉树特性）：

```
索引:  0    1    2    3    4    5    6
      [9]  [7]  [8]  [5]  [6]  [3]  [4]
```

| 关系 | 索引公式 |
|------|----------|
| 父节点 | `(i - 1) / 2` |
| 左子节点 | `2 * i + 1` |
| 右子节点 | `2 * i + 2` |

### 3. 核心操作

| 操作 | 说明 | 时间复杂度 |
|------|------|-----------|
| **上浮（siftUp）** | 插入元素后，从下往上调整 | O(log n) |
| **下沉（siftDown）** | 删除堆顶后，从上往下调整 | O(log n) |
| **建堆（heapify）** | 数组转堆，从最后一个非叶子节点开始 | O(n) |

## Java 实现（小顶堆）

```java
class MinHeap {
    private int[] heap;
    private int size;

    public MinHeap(int capacity) {
        heap = new int[capacity];
        size = 0;
    }

    // 插入元素
    public void offer(int val) {
        heap[size] = val;
        siftUp(size);
        size++;
    }

    // 删除堆顶
    public int poll() {
        int top = heap[0];
        heap[0] = heap[size - 1];
        size--;
        siftDown(0);
        return top;
    }

    // 上浮调整
    private void siftUp(int i) {
        while (i > 0) {
            int parent = (i - 1) / 2;
            if (heap[i] >= heap[parent]) break;
            swap(i, parent);
            i = parent;
        }
    }

    // 下沉调整
    private void siftDown(int i) {
        while (2 * i + 1 < size) {
            int left = 2 * i + 1;
            int right = 2 * i + 2;
            int min = left;
            if (right < size && heap[right] < heap[left]) {
                min = right;
            }
            if (heap[i] <= heap[min]) break;
            swap(i, min);
            i = min;
        }
    }

    private void swap(int i, int j) {
        int temp = heap[i];
        heap[i] = heap[j];
        heap[j] = temp;
    }
}
```

## Java 内置优先队列（PriorityQueue）

### 1. 基础特性

| 特性 | 说明 |
|------|------|
| 底层结构 | **小顶堆**（完全二叉树 + 数组） |
| 初始容量 | 11，自动扩容 |
| 线程安全 | ❌ 非线程安全，并发需使用 `PriorityBlockingQueue` |

### 2. 自定义优先级

```java
// 大顶堆
PriorityQueue<Integer> maxHeap = new PriorityQueue<>((a, b) -> b - a);

// 自定义对象优先级
class Task {
    int priority;
    String name;
}
PriorityQueue<Task> taskQueue = new PriorityQueue<>(
    (a, b) -> a.priority - b.priority
);
```

### 3. 常用方法

| 方法 | 说明 |
|------|------|
| `offer(E e)` | 插入元素 |
| `poll()` | 删除并返回堆顶 |
| `peek()` | 获取堆顶但不删除 |
| `size()` | 获取元素数量 |

## Java 后端实战场景

### 1. 任务调度

| 场景 | 实现方式 |
|------|----------|
| 优先级任务队列 | 高优先级任务优先执行 |
| 延迟队列 | 基于小顶堆实现定时任务 |

### 2. 数据处理

| 场景 | 方案 |
|------|------|
| **TopK 问题** | 小顶堆求前 K 大元素，复杂度 O(n log k) |
| **合并 K 个有序链表** | 小顶堆高效合并 |

### 3. 中间件应用

| 中间件 | 实现 |
|--------|------|
| Redis 有序集合（ZSet） | skiplist + 堆实现 |
| 消息队列优先级队列 | 堆结构保证顺序 |

### 4. 算法优化

| 算法 | 优化方式 |
|------|----------|
| 堆排序 | O(n log n)，原地排序 |
| Dijkstra 最短路径 | 小顶堆优化时间复杂度 |

## 总结

1. **堆**是优先队列的最优实现，核心为**上浮（siftUp）** 和**下沉（siftDown）** 调整
2. Java `PriorityQueue` 基于**小顶堆**，支持自定义优先级比较器
3. 后端应用覆盖**任务调度、数据处理、中间件、算法优化**四大场景
4. 掌握堆结构可高效解决 **TopK、最短路径**等高频面试问题
