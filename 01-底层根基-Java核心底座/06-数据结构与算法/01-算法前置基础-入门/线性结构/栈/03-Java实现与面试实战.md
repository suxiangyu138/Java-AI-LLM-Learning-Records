## 2. 特性匹配选型框架

### 2.1 "问题特性 → 工具特性"方法论

```
拿到题 → 提取"核心标签" → 匹配工具：

"最近配对/嵌套" → 栈（20 括号）
"同步最小/最大" → 辅助栈（155）
"下一个更大/更小" → 单调栈（739）
"窗口内最值" → 单调队列 Deque（239）
"先来先服务/层扩散" → 队列（BFS）
"TopK/优先级" → 堆（347）
"倒序还原" → 双栈（232）
```

### 2.2 选型对照表

| 问题特性 | 工具 | 排除理由 |
|------|------|------|
| 最近配对 | 栈 | 队列不能"撤销最近" |
| 下一个更大 | 单调栈 | 哈希表无法记录顺序 |
| 窗口最值 | 单调队列 | 栈无法移除过期元素 |
| 优先级顺序 | 堆 | 栈/队列无优先级 |
| 层扩散 | 队列 | 栈是深度优先 |

> 💡 面试加分表达："这题的核心标签是'每个元素找下一个更大'，匹配单调栈；哈希表虽然能 O(1) 查找，但无法维护顺序关系，所以排除。"

## 4. 高频追问与标准回答

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 为什么单调栈是 O(n)？ | 每个元素恰好入栈出栈各一次，总操作 2n；暴力每个元素都要向后扫描是 O(n²) |
| 2 | 单调栈为什么存下标？ | 需要计算距离（739 的天数差）和位置（84 的宽度），存值无法回溯位置 |
| 3 | 找更大为什么用递减栈？ | 栈内是"等待答案的候选"，栈顶最小 → 遇到比栈顶大的当前元素，栈顶答案确定弹出；栈保持递减 |
| 4 | 84 为什么要补 0？ | 头部 0：弹出后栈不空免判空；尾部 0：强制弹出所有残留元素（否则栈中柱子算不到面积） |
| 5 | 最小栈的辅助栈为什么用 <=？ | 相同最小值连续 push 时只存一次，pop 后会丢失最小值 |
| 6 | Stack 和 ArrayDeque 选哪个？ | ArrayDeque：无锁数组实现性能好；Stack 继承 Vector 全方法加锁，遗留 API |
| 7 | 栈实现队列为什么均摊 O(1)？ | 每个元素恒定 3 次操作（入 in、倒 out、出 out） |
| 8 | 单调栈和单调队列区别？ | 单调栈处理"下一个更大"（无过期概念）；单调队列处理"窗口最值"（有过期移除） |

## 5. 高频题深度复盘

### 5.1 84. 柱状图中最大的矩形（Hard 突破）

```java
public int largestRectangleArea(int[] heights) {
    int n = heights.length;
    int[] h = new int[n + 2];            // 首尾补 0
    System.arraycopy(heights, 0, h, 1, n);

    Deque<Integer> stack = new ArrayDeque<>();
    int maxArea = 0;

    for (int i = 0; i < h.length; i++) {
        while (!stack.isEmpty() && h[i] < h[stack.peek()]) {
            int height = h[stack.pop()];
            int width = i - stack.peek() - 1;    // 左右边界夹出的宽度
            maxArea = Math.max(maxArea, height * width);
        }
        stack.push(i);
    }
    return maxArea;
}
```

**复盘要点**：
- 三方会合：弹出元素（高）| 新栈顶（左边界）| 当前（右边界）
- 宽度公式：`i - stack.peek() - 1`（哨兵保证栈非空）
- 面试先讲思路（每个柱子作为高度的最大宽度），再写代码

### 5.2 155. 最小栈（设计题高频）

```java
class MinStack {
    Deque<Integer> data = new ArrayDeque<>();
    Deque<Integer> min = new ArrayDeque<>();

    public void push(int val) {
        data.push(val);
        min.push(min.isEmpty() ? val : Math.min(val, min.peek()));
    }
    public void pop() { data.pop(); min.pop(); }
    public int top() { return data.peek(); }
    public int getMin() { return min.peek(); }
}
```

**复盘要点**：
- 辅助栈同步（push 时算 min，pop 时同步弹）
- `<=` 防重复最小值丢失（面试必讲细节）
- 追问 O(1) 空间方案（差值法）是加分项

## 6. 调试技巧与自检清单

### 6.1 栈/单调栈自检三步法

```
第 1 步：API 检查
  □ 用 ArrayDeque 而不是 Stack？
  □ push/pop/peek 方向正确（push=addFirst）？

第 2 步：单调栈语义检查
  □ 栈存的是下标吗？（需要距离/宽度时必须）
  □ 单调方向对吗？（找更大 → 递减栈）
  □ 弹出时记录了答案/面积吗？
  □ 栈中剩余元素处理了吗？（739 保持 0 / 84 补哨兵）

第 3 步：边界用例
  □ 空栈操作（pop 前判空）
  □ 单调递增数组 / 单调递减数组
  □ 全部相同元素（单调栈全部弹出/全部保留）
  □ 最小栈重复值连续 push
```

### 6.2 高频 Bug 速查表

| Bug | 原因 | 修复 |
|------|------|------|
| 空栈 pop | 未判空 | `if (stack.isEmpty()) return ...` |
| 括号误判 | 最后没检查栈空 | `return stack.isEmpty()` |
| 最小栈丢值 | 辅助栈用 < 而非 <= | 改 <= |
| 逆波兰减错序 | a/b 顺序颠倒 | 先弹的是 b（后入栈） |
| 单调栈忘存下标 | 存了值 | 改存下标 |
| 84 残留未算 | 没补尾部哨兵 | 补 0 强制弹出 |
| 单调方向反 | 求更大用了递增栈 | 找更大用递减栈 |
