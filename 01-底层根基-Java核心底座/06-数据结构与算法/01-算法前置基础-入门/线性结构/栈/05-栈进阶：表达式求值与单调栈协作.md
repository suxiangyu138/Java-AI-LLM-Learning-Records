## 1. 表达式求值的完整体系

### 1.1 三种表达式

```
中缀：A + B × C（人类习惯，需优先级）
前缀：+ A × B C（波兰）
后缀：A B C × +（逆波兰，栈直接算）

⚠️ 转换关系：
  中缀 → 后缀：栈处理运算符
  后缀 → 计算：数字入栈，运算符弹两个

⚠️ 面试定位：
  后缀求值（150）→ 基础模板
  中缀求值（224/227）→ 进阶高频
```

### 1.2 栈在表达式中的角色

```
后缀：栈存数字（遇运算符弹两个）
中缀：栈存运算符（优先级控制）

⚠️ 核心规律：
  "后缀的栈管数字；中缀的栈管运算符"
```

### 1.3 识别信号

```
"表达式求值/计算器" → 栈
"逆波兰/后缀" → 150
"基本计算器" → 224（括号）/227（乘除）
"简化路径" → 栈模拟

⚠️ 面试必答：
"表达式求值 = 栈的经典应用——
 后缀管数字，中缀管运算符优先级。"
```

## 2. 逆波兰表达式详解

### 2.1 150. 逆波兰表达式求值

```java
/**
 * LeetCode 150. 逆波兰表达式（后缀表达式）
 * 数字入栈，运算符弹两个计算
 * ⚠️ 先弹的是 b（后入栈的）！
 */
public int evalRPN(String[] tokens) {
    Deque<Integer> stack = new ArrayDeque<>();

    for (String token : tokens) {
        switch (token) {
            case "+" -> {
                int b = stack.pop(), a = stack.pop();
                stack.push(a + b);
            }
            case "-" -> {
                int b = stack.pop(), a = stack.pop();
                stack.push(a - b);            // ⚠️ a-b 不是 b-a！
            }
            case "*" -> {
                int b = stack.pop(), a = stack.pop();
                stack.push(a * b);
            }
            case "/" -> {
                int b = stack.pop(), a = stack.pop();
                stack.push(a / b);            // ⚠️ 先弹的是 b
            }
            default -> stack.push(Integer.parseInt(token));
        }
    }
    return stack.peek();
}
// 推演 ["2","1","+","3","*"]：
//   2,1 入栈 → '+' 弹 1,2 → 3 入栈 → 3 入栈
//   '*' 弹 3,3 → 9 ✓（(2+1)×3 = 9）
// ⚠️ 面试必答：
//   "先弹的是 b（后入栈的），后弹的是 a——
//    表达式 a op b 中 a 先入栈。"
```

### 2.2 为什么后缀容易求值

```
后缀没有括号、没有优先级：
  操作顺序完全由位置决定
  遇数字 → 入栈
  遇运算符 → 弹两个算一个

⚠️ 对比中缀：
  中缀需要优先级判断（× 先于 +）
  后缀消除了这个需求

⚠️ 面试表达：
"后缀表达式天然适合栈——
 无优先级问题，遇运算符弹两个即可。"
```

## 3. 中缀表达式求值

### 3.1 227. 基本计算器 II（无括号）

```java
/**
 * LeetCode 227. 基本计算器 II（+ - * /，无括号）
 * 思路：遍历时处理乘除（优先级高的立即算），
 *      加减先入栈，最后统一求和
 */
public int calculate(String s) {
    Deque<Integer> stack = new ArrayDeque<>();
    int num = 0;
    char prevOp = '+';              // 前一个运算符

    for (int i = 0; i < s.length(); i++) {
        char c = s.charAt(i);

        if (Character.isDigit(c)) {
            num = num * 10 + (c - '0');     // 多位数拼接
        }

        // 遇到运算符或结尾 → 处理之前的数字
        if ((!Character.isDigit(c) && c != ' ')
            || i == s.length() - 1) {
            switch (prevOp) {
                case '+' -> stack.push(num);       // 加：入栈
                case '-' -> stack.push(-num);      // 减：负数入栈
                case '*' -> stack.push(stack.pop() * num);   // 乘：立即算
                case '/' -> stack.push(stack.pop() / num);   // 除：立即算
            }
            prevOp = c;
            num = 0;
        }
    }

    // 栈中全部相加（加减已在栈中）
    int result = 0;
    for (int x : stack) result += x;
    return result;
}
// 推演 "3+2*2"：
//   3: + 入栈 [3]；2: + 入栈 [3,2]
//   *: 弹 2×2=4 入栈 [3,4] → 和 7 ✓
// ⚠️ 核心思想：
//   "乘除立即算（优先级高），加减先入栈
//    最后统一求和——用'延迟处理'解决优先级"
```

### 3.2 224. 基本计算器 I（含括号）

```java
/**
 * LeetCode 224. 基本计算器 I（+ - 和括号）
 * 括号 → 遇到 '(' 保存现场，遇到 ')' 恢复
 */
public int calculate(String s) {
    Deque<Integer> stack = new ArrayDeque<>();
    int sign = 1;                   // 当前符号（+1/-1）
    int result = 0;
    int num = 0;

    for (char c : s.toCharArray()) {
        if (Character.isDigit(c)) {
            num = num * 10 + (c - '0');
        } else if (c == '+') {
            result += sign * num;   // 结算数字
            sign = 1;
            num = 0;
        } else if (c == '-') {
            result += sign * num;
            sign = -1;
            num = 0;
        } else if (c == '(') {
            stack.push(result);     // ⚠️ 保存现场
            stack.push(sign);
            result = 0;             // 括号内重新开始
            sign = 1;
        } else if (c == ')') {
            result += sign * num;   // 结算括号内
            num = 0;
            result *= stack.pop();  // 恢复符号
            result += stack.pop();  // 恢复外层结果
        }
    }
    result += sign * num;
    return result;
}
// 推演 "(1+(4+5+2)-3)+(6+8)" → 23 ✓
// ⚠️ 括号处理：
//   '('：保存 (结果, 符号) 到栈
//   ')'：恢复符号与结果
// ⚠️ 面试必答："括号 = 现场保存与恢复——
//   栈天然支持嵌套结构"
```

### 3.3 表达式求值的统一思路

```
① 无括号：优先级（乘除立即算 + 加减延迟）
② 有括号：现场保存/恢复（栈）
③ 后缀：无需优先级（遇运算符弹两个）

⚠️ 面试表达：
"表达式求值的统一思路：
 乘除立即结算（高优先级），
 加减延迟处理（入栈），
 括号现场保存恢复（嵌套）。"
```

## 4. 双栈协作与辅助栈

### 4.1 双栈倒腾（232 栈实现队列）

```java
/**
 * LeetCode 232. 用栈实现队列
 * in 栈入队，out 栈出队（倒腾逆转顺序）
 */
class MyQueue {
    Deque<Integer> in = new ArrayDeque<>();
    Deque<Integer> out = new ArrayDeque<>();

    public void push(int x) {
        in.push(x);
    }

    public int pop() {
        moveIfNeeded();
        return out.pop();
    }

    public int peek() {
        moveIfNeeded();
        return out.peek();
    }

    public boolean empty() {
        return in.isEmpty() && out.isEmpty();
    }

    private void moveIfNeeded() {
        if (out.isEmpty()) {            // ⚠️ out 空才倒腾
            while (!in.isEmpty()) {
                out.push(in.pop());
            }
        }
    }
}
// 均摊 O(1)：每个元素 3 次操作（入 in/倒 out/出 out）
// ⚠️ 面试必答："为什么均摊 O(1)？
//   每元素恒定 3 次操作（push/倒腾/pop）"
```

### 4.2 辅助栈同步（155 最小栈）

```java
/**
 * LeetCode 155. 最小栈
 * 辅助栈同步记录最小值（push 时维护）
 */
class MinStack {
    Deque<Integer> data = new ArrayDeque<>();
    Deque<Integer> min = new ArrayDeque<>();

    public void push(int val) {
        data.push(val);
        // ⚠️ 用 <=：相同最小值重复 push 不丢失
        min.push(min.isEmpty() ? val : Math.min(val, min.peek()));
    }

    public void pop() {
        data.pop();
        min.pop();                    // ⚠️ 同步弹
    }

    public int top() {
        return data.peek();
    }

    public int getMin() {
        return min.peek();
    }
}
// 推演：push 2,3,2,1 → data:[2,3,2,1] min:[2,2,2,1]
//   pop 两次 → min 仍 [2,2] → getMin=2 ✓（没丢！）
// ⚠️ 为什么用 <= 不用 <？
//   相同最小值重复 push 只存一次 → pop 后丢失
```

### 4.3 双栈的其他应用

```
① 浏览器历史（1472）：前进/后退双栈
② 简化路径（71）：栈存目录段
③ 基本计算器（224）：结果+符号双栈

⚠️ 识别：
  "需要逆序还原/现场保存" → 双栈
  "需要同步最值" → 辅助栈
```

## 5. 栈的工程应用

### 5.1 函数调用栈

```
递归 = 系统调用栈：
  调用 → 压栈（保存现场）
  返回 → 弹栈（恢复现场）

⚠️ 递归深度 = 栈深度：
  深链可能 StackOverflow
  → 显式栈迭代（堆内存）

⚠️ 面试必答：
"递归就是系统栈——理解调用栈
 就是理解递归的执行模型。"
```

### 5.2 编辑器撤销

```
撤销 = 栈：
  操作入栈（undo 栈）
  撤销 → 弹栈 → 重做栈入栈
  新操作 → 清空重做栈

⚠️ 工程类比：
  "撤销/重做 = 双栈协作的经典场景"
```

### 5.3 Java 栈的正确使用

```java
// ❌ Stack 类（继承 Vector，全方法加锁，遗留 API）
// ✅ ArrayDeque（无锁，性能好）
Deque<Integer> stack = new ArrayDeque<>();
stack.push(1);       // 压栈
stack.pop();         // 弹栈
stack.peek();        // 看栈顶

// ⚠️ offer/poll 不抛异常（add/remove 会抛）
// 面试表达："用 ArrayDeque 模拟栈——
//   Stack 继承 Vector 加锁性能差"
```

## 6. 进阶总结

### 6.1 进阶要点速查

```
① 表达式体系：后缀（管数字）/中缀（管运算符优先级）
② 优先级处理：乘除立即算 + 加减延迟（栈）
③ 括号处理：现场保存/恢复（栈天然嵌套）
④ 双栈：倒腾（队列）/辅助（最小栈）/浏览器
⑤ 工程：调用栈/撤销/ArrayDeque
```

### 6.2 面试话术模板

```
"表达式求值用栈：
 后缀 → 数字入栈，运算符弹两个；
 中缀 → 乘除立即算（高优先级），
        加减延迟入栈，括号现场保存。
 关键细节：先弹的是 b（后入栈）。
 复杂度 O(n)。"
```

### 6.3 易错点清单

| 错误 | 后果 | 修正 |
|------|------|------|
| 减/除 a/b 反 | 结果错 | 先弹 b 后弹 a |
| 辅助栈用 < | 最小值丢失 | 用 <= |
| 双栈忘 move | 出队顺序错 | moveIfNeeded |
| 括号忘恢复 | 结果错 | 弹栈恢复 |
| 多位数拼接漏 | 数字错 | num*10 + digit |

> 🎯 **核心要点**：栈进阶 = **表达式体系**（后缀/中缀/括号）+ **双栈协作**（倒腾/辅助）+ **工程应用**（调用栈/撤销）。"后缀管数字、中缀管优先级"是体系核心；"先弹 b 后弹 a"与"辅助栈 <= "是两个必答细节。
