## 1. 20. 有效的括号

### 1.1 完整实现（栈第一题）

```java
/**
 * LeetCode 20. 有效的括号（面试热身必考）
 * LIFO 匹配：左括号入栈，右括号与栈顶配对
 */
public boolean isValid(String s) {
    Deque<Character> stack = new ArrayDeque<>();
    Map<Character, Character> map = Map.of(
        ')', '(', ']', '[', '}', '{');

    for (char c : s.toCharArray()) {
        if (c == '(' || c == '[' || c == '{') {
            stack.push(c);                    // 左括号入栈
        } else {
            if (stack.isEmpty()) return false;    // ⚠️ 右括号无配对
            if (stack.pop() != map.get(c)) return false;  // 不匹配
        }
    }
    return stack.isEmpty();                   // ⚠️ 栈必须空！
}
// "([)]"：'(','['入栈，')'配'['? 不匹配 → false ✓
// "([{}])"：全部匹配 → 栈空 → true ✓
// ⚠️ 三个细节：
//   ① 右括号来时栈空 → false
//   ② 不匹配 → false
//   ③ 最后栈必须空（左括号多 → false）
```

## 2. 155. 最小栈

### 2.1 完整实现（辅助栈）

```java
/**
 * LeetCode 155. 最小栈（辅助栈同步）
 */
class MinStack {
    Deque<Integer> data = new ArrayDeque<>();
    Deque<Integer> min = new ArrayDeque<>();

    public void push(int val) {
        data.push(val);
        // ⚠️ 用 <=：相同最小值重复 push 不丢失
        min.push(min.isEmpty() ? val : Math.min(val, min.peek()));
    }

    public void pop() {
        data.pop();
        min.pop();                    // ⚠️ 同步弹
    }

    public int top() {
        return data.peek();
    }

    public int getMin() {
        return min.peek();            // 辅助栈顶 = 当前最小值
    }
}
// 推演：push 2, 3, 2, 1
//   data: [2,3,2,1]  min: [2,2,2,1]
//   pop 两次 → min 仍 [2,2] → getMin=2 ✓（没丢！）
// ⚠️ 面试必答："为什么用 <=？
//   相同最小值重复 push 只存一次，
//   pop 后最小值丢失。"
// ⚠️ 进阶：O(1) 空间差值法（存 val-min）
```

## 3. 232. 用栈实现队列

### 3.1 完整实现（双栈倒腾）

```java
/**
 * LeetCode 232. 用栈实现队列
 * in 栈入队，out 栈出队（倒腾逆转顺序）
 */
class MyQueue {
    Deque<Integer> in = new ArrayDeque<>();
    Deque<Integer> out = new ArrayDeque<>();

    public void push(int x) {
        in.push(x);                            // 直接入 in
    }

    public int pop() {
        moveIfNeeded();
        return out.pop();
    }

    public int peek() {
        moveIfNeeded();
        return out.peek();
    }

    public boolean empty() {
        return in.isEmpty() && out.isEmpty();
    }

    // ⚠️ 关键：out 空时把 in 全部倒过来
    private void moveIfNeeded() {
        if (out.isEmpty()) {
            while (!in.isEmpty()) {
                out.push(in.pop());            // 倒腾
            }
        }
    }
}
// 推演 push 1,2,3：
//   in=[1,2,3]；pop → out 空 → 倒腾 → out=[3,2,1]
//   out.pop() = 1 ✓ FIFO！
// ⚠️ 均摊 O(1)：每元素 3 次操作（入/倒/出）
```

## 4. 225. 用队列实现栈

### 4.1 完整实现（单队列轮转）

```java
/**
 * LeetCode 225. 用队列实现栈
 * 单队列 + 轮转：push 后把前面的移到后面
 */
class MyStack {
    private Queue<Integer> queue;

    public MyStack() {
        queue = new LinkedList<>();
    }

    public void push(int x) {
        queue.offer(x);
        // ⚠️ 轮转：把前面的 n-1 个移到后面
        int size = queue.size();
        for (int i = 0; i < size - 1; i++) {
            queue.offer(queue.poll());
        }
        // 新元素成为队首（栈顶）
    }

    public int pop() {
        return queue.poll();             // 队首 = 栈顶
    }

    public int top() {
        return queue.peek();
    }

    public boolean empty() {
        return queue.isEmpty();
    }
}
// 推演 push 1,2,3：
//   push 1 → [1]；push 2 → 轮转 → [2,1]
//   push 3 → 轮转 → [3,2,1]；pop → 3 ✓
// ⚠️ push O(n)，其余 O(1)
// ⚠️ 面试对比：232 双栈倒腾 vs 225 单队列轮转
```

## 5. 150. 逆波兰表达式求值

### 5.1 完整实现

```java
/**
 * LeetCode 150. 逆波兰表达式（后缀）
 * 数字入栈，运算符弹两个计算
 */
public int evalRPN(String[] tokens) {
    Deque<Integer> stack = new ArrayDeque<>();

    for (String token : tokens) {
        switch (token) {
            case "+" -> {
                int b = stack.pop(), a = stack.pop();
                stack.push(a + b);
            }
            case "-" -> {
                int b = stack.pop(), a = stack.pop();
                stack.push(a - b);            // ⚠️ a-b 不是 b-a！
            }
            case "*" -> {
                int b = stack.pop(), a = stack.pop();
                stack.push(a * b);
            }
            case "/" -> {
                int b = stack.pop(), a = stack.pop();
                stack.push(a / b);            // ⚠️ 先弹的是 b
            }
            default -> stack.push(Integer.parseInt(token));
        }
    }
    return stack.peek();
}
// 推演 ["2","1","+","3","*"]：
//   2,1 入栈 → '+' 弹 1,2 → 3 入栈 → 3 入栈
//   '*' 弹 3,3 → 9 ✓
// ⚠️ 面试必答："先弹的是 b（后入栈的）——
//   表达式 a op b 中 a 先入栈"
```

## 6. 227. 基本计算器 II

### 6.1 完整实现（无括号）

```java
/**
 * LeetCode 227. 基本计算器 II（+ - * /，无括号）
 * 乘除立即算（高优先级），加减先入栈
 */
public int calculate(String s) {
    Deque<Integer> stack = new ArrayDeque<>();
    int num = 0;
    char prevOp = '+';

    for (int i = 0; i < s.length(); i++) {
        char c = s.charAt(i);

        if (Character.isDigit(c)) {
            num = num * 10 + (c - '0');     // ⚠️ 多位数拼接
        }

        if ((!Character.isDigit(c) && c != ' ')
            || i == s.length() - 1) {
            switch (prevOp) {
                case '+' -> stack.push(num);
                case '-' -> stack.push(-num);
                case '*' -> stack.push(stack.pop() * num);   // ⚠️ 立即算
                case '/' -> stack.push(stack.pop() / num);
            }
            prevOp = c;
            num = 0;
        }
    }

    int result = 0;
    for (int x : stack) result += x;
    return result;
}
// 推演 "3+2*2"：
//   3: + 入栈 [3]；2: + 入栈 [3,2]
//   *: 弹 2×2=4 入栈 [3,4] → 和 7 ✓
// ⚠️ 核心思想：
//   "乘除立即算（优先级高），加减延迟入栈
//    最后统一求和——'延迟处理'解决优先级"
```

## 7. 224. 基本计算器 I

### 7.1 完整实现（含括号）

```java
/**
 * LeetCode 224. 基本计算器 I（+ - 和括号）
 * 括号 = 现场保存/恢复
 */
public int calculate(String s) {
    Deque<Integer> stack = new ArrayDeque<>();
    int sign = 1;
    int result = 0;
    int num = 0;

    for (char c : s.toCharArray()) {
        if (Character.isDigit(c)) {
            num = num * 10 + (c - '0');
        } else if (c == '+' || c == '-') {
            result += sign * num;       // 结算数字
            sign = c == '+' ? 1 : -1;
            num = 0;
        } else if (c == '(') {
            stack.push(result);         // ⚠️ 保存结果
            stack.push(sign);           // ⚠️ 保存符号
            result = 0;                 // 括号内重新开始
            sign = 1;
        } else if (c == ')') {
            result += sign * num;       // 结算括号内
            num = 0;
            result *= stack.pop();      // 恢复符号
            result += stack.pop();      // 恢复外层结果
        }
    }
    result += sign * num;
    return result;
}
// 推演 "(1+(4+5+2)-3)+(6+8)" → 23 ✓
// ⚠️ 面试必答：
//   "括号 = 现场保存与恢复——栈天然支持
//    嵌套结构（先入的后出）。"
```

## 8. 71. 简化路径

### 8.1 完整实现

```java
/**
 * LeetCode 71. 简化路径（Unix 风格）
 * "/a/./b/../../c/" → "/c"
 * 分段处理："." 忽略，".." 弹栈，其他入栈
 */
public String simplifyPath(String path) {
    Deque<String> stack = new ArrayDeque<>();

    for (String part : path.split("/")) {
        if (part.isEmpty() || part.equals(".")) {
            continue;                 // 空段和当前目录忽略
        }
        if (part.equals("..")) {
            if (!stack.isEmpty()) stack.pop();   // 返回上一级
        } else {
            stack.push(part);         // 目录入栈
        }
    }

    StringBuilder sb = new StringBuilder();
    for (String dir : stack) {
        sb.insert(0, "/" + dir);      // ⚠️ 栈底 → 栈顶 = 路径顺序
    }
    return sb.isEmpty() ? "/" : sb.toString();
}
// 推演 "/a/./b/../../c/"：
//   段：a 入栈；. 忽略；b 入栈；.. 弹 b；.. 弹 a；c 入栈
//   栈 [c] → "/c" ✓
// ⚠️ 三个细节：
//   ① split 的空段（连续 //）忽略
//   ② ".." 弹栈时栈空忽略（已在根）
//   ③ 拼接顺序（栈底先）
```

## 9. 32. 最长有效括号

### 9.1 完整实现（栈存下标）

```java
/**
 * LeetCode 32. 最长有效括号（Hard）
 * 栈存下标（不是字符！）：
 *   ① 栈底 = 最后一个未匹配的 ')'（哨兵）
 *   ② '(' 入栈
 *   ③ ')' 弹栈 → 栈空则当前 ')' 入栈（更新哨兵）
 *                 → 栈非空则长度 = i - stack.peek()
 */
public int longestValidParentheses(String s) {
    Deque<Integer> stack = new ArrayDeque<>();
    stack.push(-1);                  // ⚠️ 哨兵（虚拟的未匹配位置）
    int maxLen = 0;

    for (int i = 0; i < s.length(); i++) {
        if (s.charAt(i) == '(') {
            stack.push(i);           // '(' 入栈（下标）
        } else {
            stack.pop();             // 弹出匹配的 '('（或哨兵）
            if (stack.isEmpty()) {
                stack.push(i);       // ⚠️ 栈空 → 当前 ')' 成为新哨兵
            } else {
                maxLen = Math.max(maxLen, i - stack.peek());
            }
        }
    }
    return maxLen;
}
// 推演 "(()())"：
//   i=0 '(' 入栈 [-1,0]；i=1 '(' → [-1,0,1]
//   i=2 ')' 弹 1 → len=2-0=2；i=3 '(' → [-1,0,3]
//   i=4 ')' 弹 3 → len=4-0=4；i=5 ')' 弹 0 → len=5-(-1)=6 ✓
// ⚠️ 哨兵的作用：
//   栈空时无法计算长度 → 哨兵提供基准
// ⚠️ 面试必答："栈存下标（可算长度），
//   栈底哨兵记录'最后一个未匹配的右括号'"
```

## 10. 739. 每日温度（单调栈）

### 10.1 完整实现

```java
/**
 * LeetCode 739. 每日温度（单调栈第一题）
 * 单调递减栈（存下标）：当前比栈顶大 → 栈顶答案确定
 */
public int[] dailyTemperatures(int[] temperatures) {
    int n = temperatures.length;
    int[] answer = new int[n];
    Deque<Integer> stack = new ArrayDeque<>();

    for (int i = 0; i < n; i++) {
        // 当前温度比栈顶大 → 栈顶的"下一个更大"找到了
        while (!stack.isEmpty()
               && temperatures[i] > temperatures[stack.peek()]) {
            int idx = stack.pop();
            answer[idx] = i - idx;               // 距离 = 天数差
        }
        stack.push(i);                           // 当前下标入栈
    }
    return answer;
}
// 推演 [73,74,75,71,69,72,76,73] → [1,1,4,2,1,1,0,0] ✓
// ⚠️ 面试必答：
//   "单调栈存下标（需算距离）；
//    弹出时即答案（当前元素是它的下一个更大）；
//    每元素进出栈各一次 → O(n)。"
```
