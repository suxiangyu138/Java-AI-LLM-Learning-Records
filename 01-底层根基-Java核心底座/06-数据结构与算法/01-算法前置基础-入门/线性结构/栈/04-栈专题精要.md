## 1. 核心概念

### 1.1 栈的本质

> 栈（Stack）：只允许在栈顶（Top）操作的线性结构，**LIFO（后进先出）**。

```
操作：push（压栈）/ pop（弹栈）/ peek（看栈顶）/ isEmpty

类比：一叠盘子——最后放的先拿

push 1 → [1]
push 2 → [1, 2]
push 3 → [1, 2, 3]     ← 栈顶
pop 3 → [1, 2]

复杂度：所有操作 O(1)
```

### 1.2 识别信号

```
"最近配对/嵌套结构" → 栈（20 括号）
"后进先出/撤销" → 栈（编辑器撤销）
"表达式/优先级" → 栈（150 逆波兰）
"递归转迭代" → 显式栈

⚠️ 栈的核心场景：
  "最近相关" 问题（LIFO 天然匹配）
```

### 1.3 栈 vs 队列

| 维度 | 栈 | 队列 |
|------|:---:|:---:|
| 顺序 | LIFO | FIFO |
| 操作端 | 栈顶 | 队尾进队首出 |
| 典型 | 括号/DFS | BFS/调度 |

```
选型："最近相关" → 栈；"顺序相关" → 队列
```

## 2. 完整代码模板

### 2.1 20. 有效的括号（栈第一题）

```java
/**
 * LeetCode 20. 有效的括号（面试热身必考）
 */
public boolean isValid(String s) {
    Deque<Character> stack = new ArrayDeque<>();
    Map<Character, Character> map = Map.of(
        ')', '(', ']', '[', '}', '{');

    for (char c : s.toCharArray()) {
        if (c == '(' || c == '[' || c == '{') {
            stack.push(c);                    // 左括号入栈
        } else {
            if (stack.isEmpty()) return false;    // ⚠️ 右括号无配对
            if (stack.pop() != map.get(c)) return false;  // 不匹配
        }
    }
    return stack.isEmpty();                   // ⚠️ 栈必须空！
}
// "([)]"：'(','['入栈，')'配'['? 不匹配 → false ✓
// 关键细节：
//   ① 右括号来时栈空 → false（如 ")" 开头）
//   ② 最后栈空 → false（如 "((" 左括号多）
```

### 2.2 155. 最小栈（辅助栈）

```java
/**
 * LeetCode 155. 最小栈（辅助栈同步最小值）
 */
class MinStack {
    Deque<Integer> data = new ArrayDeque<>();
    Deque<Integer> min = new ArrayDeque<>();

    public void push(int val) {
        data.push(val);
        // ⚠️ 用 <=：相同最小值重复 push 不丢失
        min.push(min.isEmpty() ? val : Math.min(val, min.peek()));
    }

    public void pop() {
        data.pop();
        min.pop();                    // ⚠️ 同步弹
    }

    public int top() {
        return data.peek();
    }

    public int getMin() {
        return min.peek();            // 辅助栈顶 = 当前最小值
    }
}
// 推演：push 2, push 3, push 2, push 1
//   data: [2,3,2,1]  min: [2,2,2,1]
//   pop 两次 → min 仍 [2,2] → getMin=2 ✓（没丢！）
```

### 2.3 232. 用栈实现队列（双栈倒腾）

```java
/**
 * LeetCode 232. 用栈实现队列（双栈倒腾）
 */
class MyQueue {
    Deque<Integer> in = new ArrayDeque<>();    // 入队栈
    Deque<Integer> out = new ArrayDeque<>();   // 出队栈

    public void push(int x) {
        in.push(x);                            // 直接入 in
    }

    public int pop() {
        moveIfNeeded();
        return out.pop();
    }

    public int peek() {
        moveIfNeeded();
        return out.peek();
    }

    public boolean empty() {
        return in.isEmpty() && out.isEmpty();
    }

    // ⚠️ 关键：out 空时把 in 全部倒过来
    private void moveIfNeeded() {
        if (out.isEmpty()) {
            while (!in.isEmpty()) {
                out.push(in.pop());            // 倒腾（逆序变正序）
            }
        }
    }
}
// push 1,2,3 → in:[1,2,3]
// pop → out 空 → 倒腾 → out:[3,2,1] → pop=1 ✓ FIFO！
// 均摊 O(1)：每个元素 3 次操作（入 in/倒 out/出 out）
```

## 3. 栈的五大经典应用

### 3.1 应用一：括号匹配（20）

```
"最近配对" → LIFO 天然匹配
  左括号入栈，右括号与栈顶配对

变体：
  678 含 * 通配符（双栈/DP）
  32 最长有效括号（栈存下标）
```

### 3.2 应用二：表达式求值（150/224）

```java
/**
 * 150. 逆波兰表达式（后缀表达式）
 * 数字入栈，运算符弹两个计算
 * ⚠️ 先弹的是 b（后入栈的）！
 */
public int evalRPN(String[] tokens) {
    Deque<Integer> stack = new ArrayDeque<>();
    for (String token : tokens) {
        switch (token) {
            case "+" -> { int b = stack.pop(), a = stack.pop(); stack.push(a + b); }
            case "-" -> { int b = stack.pop(), a = stack.pop(); stack.push(a - b); }
            case "*" -> { int b = stack.pop(), a = stack.pop(); stack.push(a * b); }
            case "/" -> { int b = stack.pop(), a = stack.pop(); stack.push(a / b); }
            default -> stack.push(Integer.parseInt(token));
        }
    }
    return stack.peek();
}
// "3 4 -" → 3-4 = -1（先弹 b=4，后弹 a=3 → a-b）
// 变体：224 基本计算器（中缀转后缀/双栈）
```

### 3.3 应用三：辅助栈（155）

```
同步记录附加信息（最小/最大）
  push 时同步维护 → O(1) 查询

变体：
  895 最大频率栈（频率+栈）
  225 队列实现栈（单队列轮转）
```

### 3.4 应用四：双栈倒腾（232）

```
两个栈倒腾逆转顺序 → 模拟队列
  每个元素均摊 3 次操作 → 均摊 O(1)

  225 队列实现栈（单队列轮转）
```

### 3.5 应用五：显式栈（DFS/单调栈）

```
递归转迭代：Deque 模拟系统栈

单调栈：栈内保持单调 → "下一个更大" O(n)
  （见单调栈专题）

⚠️ 栈是 DFS 与单调栈的公共底座
```

## 4. Java 栈的正确使用

### 4.1 Stack vs ArrayDeque

```java
// ❌ 不推荐：Java 官方 Stack 类
//   继承 Vector → 全方法加锁 → 性能差（遗留 API）
Stack<Integer> stack = new Stack<>();

// ✅ 推荐：ArrayDeque 模拟栈（无锁，性能好）
Deque<Integer> stack = new ArrayDeque<>();
stack.push(1);            // 压栈（addFirst）
stack.pop();              // 弹栈（removeFirst）
stack.peek();             // 看栈顶（peekFirst）
```

### 4.2 offer/poll vs add/remove

```java
// ⚠️ 两套 API：
//   add/remove：失败抛异常
//   offer/poll/peek：失败返回 null/false（推荐）
Queue<Integer> q = new LinkedList<>();
q.offer(1);               // ✅ 不抛异常
q.add(1);                 // 容量满时抛 IllegalStateException

// 面试建议：统一用 offer/poll/peek
```

### 4.3 为什么不用 Stack 类（面试必答）

```
Stack 的问题：
  ① 继承 Vector（遗留类）→ 全方法 synchronized → 性能差
  ② 设计混乱（允许插入中间元素——Vector 能力泄露）
  ③ 官方已建议用 Deque 替代

⚠️ 面试表达：
"我用 ArrayDeque 模拟栈——Stack 继承 Vector
 全方法加锁性能差，且是遗留 API。
 ArrayDeque 无锁数组实现，性能更好。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 为什么用 ArrayDeque 不用 Stack？ | Stack 继承 Vector 加锁性能差 + 遗留 API |
| 2 | 括号题三个细节？ | 栈空/不匹配/最后非空 |
| 3 | 辅助栈为什么 <=？ | 相同最小值重复 push 不丢失 |
| 4 | 双栈队列为什么均摊 O(1)？ | 每元素 3 次操作（入/倒/出） |
| 5 | 逆波兰为什么先弹的是 b？ | 栈顶是后入栈（表达式中靠后） |
| 6 | 什么时候用栈？ | 最近配对/嵌套/表达式/撤销 |
| 7 | 栈 vs 队列？ | LIFO 最近相关 vs FIFO 顺序相关 |
| 8 | 递归转迭代？ | 显式栈模拟（堆内存防溢出） |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 用 Stack 类 | 性能差 | ArrayDeque |
| 忘判栈空 | 空指针 | pop 前 isEmpty |
| 辅助栈用 < | 最小值丢失 | <= |
| 逆波兰 a/b 反 | 结果错 | 先弹 b 后弹 a |
| 双栈忘 move | 顺序错 | moveIfNeeded |

> 🎯 **核心要点**：栈 = **LIFO + 五大应用**（括号/表达式/辅助栈/双栈/显式栈）。识别信号："最近配对、嵌套、表达式"。ArrayDeque 替代 Stack、括号三细节、辅助栈 <= 是三大必答细节。
