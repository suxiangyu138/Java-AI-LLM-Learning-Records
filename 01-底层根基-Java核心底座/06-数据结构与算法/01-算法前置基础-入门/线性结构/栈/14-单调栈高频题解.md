## 1. 739. 每日温度（母题）

### 1.1 完整实现（单调递减栈）

```java
/**
 * LeetCode 739. 每日温度（单调栈第一题）
 * 返回每个温度后几天出现更高的温度
 * 单调递减栈（存下标！）
 */
public int[] dailyTemperatures(int[] temperatures) {
    int n = temperatures.length;
    int[] answer = new int[n];
    Deque<Integer> stack = new ArrayDeque<>();   // 存下标！

    for (int i = 0; i < n; i++) {
        // 当前温度比栈顶大 → 栈顶的"下一个更大"找到了
        while (!stack.isEmpty()
               && temperatures[i] > temperatures[stack.peek()]) {
            int idx = stack.pop();               // 弹出栈顶
            answer[idx] = i - idx;               // 距离 = 天数差
        }
        stack.push(i);                           // 当前下标入栈
    }
    return answer;
}
// 推演 [73,74,75,71,69,72,76,73] → [1,1,4,2,1,1,0,0] ✓
// ⚠️ 面试必答：
//   "栈存下标（需要算距离）；
//    弹出时即答案（当前元素是它的下一个更大）；
//    每元素进出栈一次 → O(n)。"
```

## 2. 496. 下一个更大元素 I

### 2.1 完整实现（预处理 + 哈希）

```java
/**
 * LeetCode 496. 下一个更大元素 I
 * nums1 是 nums2 的子集 → 预处理 nums2 查表
 */
public int[] nextGreaterElement(int[] nums1, int[] nums2) {
    // ① 单调栈预处理 nums2：每个元素的下一个更大
    Map<Integer, Integer> nextGreater = new HashMap<>();
    Deque<Integer> stack = new ArrayDeque<>();

    for (int x : nums2) {
        while (!stack.isEmpty() && x > stack.peek()) {
            nextGreater.put(stack.pop(), x);   // 栈顶的下一个更大 = x
        }
        stack.push(x);
    }
    // 栈中剩余没有下一个更大（查不到返回 -1）

    // ② 遍历 nums1 查表
    int[] result = new int[nums1.length];
    for (int i = 0; i < nums1.length; i++) {
        result[i] = nextGreater.getOrDefault(nums1[i], -1);
    }
    return result;
}
// nums2=[1,3,4,2]：
//   1:next=3；3:next=4；4:无；2:无
// nums1=[4,1,2] → [-1,3,-1] ✓
// ⚠️ 面试必答：
//   "双数组套路：对大的数组预处理 → 哈希表，
//    遍历小的数组查表 → O(n) 而非 O(n²)。"
```

## 3. 503. 下一个更大元素 II

### 3.1 完整实现（循环数组）

```java
/**
 * LeetCode 503. 下一个更大元素 II
 * 循环数组 → 遍历两遍（2n 次），下标取模
 */
public int[] nextGreaterElements(int[] nums) {
    int n = nums.length;
    int[] result = new int[n];
    Arrays.fill(result, -1);                     // 默认无更大
    Deque<Integer> stack = new ArrayDeque<>();

    for (int i = 0; i < 2 * n; i++) {
        int idx = i % n;                         // ⚠️ 取模模拟循环
        while (!stack.isEmpty() && nums[idx] > nums[stack.peek()]) {
            result[stack.pop()] = nums[idx];     // 找到下一个更大
        }
        stack.push(idx);
    }
    return result;
}
// [1,2,1] → [2,-1,2]（最后一个 1 的下一个更大是开头的 2）✓
// ⚠️ 为什么两遍？
//   循环数组的答案可能在"数组开头"
//   → 第二遍让每个元素看到开头
// ⚠️ 面试必答："两遍遍历 + 取模 = 逻辑上
//   把数组复制一份接在后面"
```

## 4. 84. 柱状图中最大的矩形

### 4.1 完整实现（递增栈 + 哨兵）

```java
/**
 * LeetCode 84. 柱状图中最大的矩形（Hard 经典）
 * 每个柱子作为高度 → 左右第一个更矮的
 * 弹出时三方会合
 */
public int largestRectangleArea(int[] heights) {
    int n = heights.length;
    int[] h = new int[n + 2];            // ⚠️ 首尾补 0
    System.arraycopy(heights, 0, h, 1, n);

    Deque<Integer> stack = new ArrayDeque<>();
    int maxArea = 0;

    for (int i = 0; i < h.length; i++) {
        while (!stack.isEmpty() && h[i] < h[stack.peek()]) {
            int height = h[stack.pop()];       // 当前柱子高度
            int left = stack.peek();           // 左边界（新栈顶）
            int right = i;                     // 右边界（当前更矮）
            int width = right - left - 1;      // 宽度
            maxArea = Math.max(maxArea, height * width);
        }
        stack.push(i);
    }
    return maxArea;
}
// 推演 [2,1,5,6,2,3] → 10 ✓（5×2）
// ⚠️ 面试必答：
//   "三方会合：弹出元素（高）、新栈顶（左界）、
//    当前元素（右界）。首尾补 0：
//    头 0 免判空，尾 0 强制弹出残留。"
```

## 5. 85. 最大矩形

### 5.1 完整实现（84 的逐行转化）

/**
 * LeetCode 85. 最大矩形
 * 二维矩阵 → 逐行转化为柱状图 → 84 题
 */
public int maximalRectangle(char[][] matrix) {
    if (matrix.length == 0) return 0;
    int n = matrix[0].length;
    int[] heights = new int[n];          // 每列"连续 1 的高度"
    int maxArea = 0;

    for (char[] row : matrix) {
        // ① 更新高度：1 累加，0 清零
        for (int j = 0; j < n; j++) {
            heights[j] = row[j] == '1' ? heights[j] + 1 : 0;
        }
        // ② 套 84 模板求当前行最大矩形
        maxArea = Math.max(maxArea, largestRectangleArea(heights));
    }
    return maxArea;
}

## 6. 42. 接雨水

### 6.1 单调栈版（按层计算）

```java
/**
 * LeetCode 42. 接雨水（单调栈版）
 * 递减栈找凹槽（左右壁 + 底部）
 */
public int trap(int[] height) {
    Deque<Integer> stack = new ArrayDeque<>();
    int water = 0;

    for (int i = 0; i < height.length; i++) {
        // 递减栈：当前比栈顶高 → 形成凹槽右壁
        while (!stack.isEmpty() && height[i] > height[stack.peek()]) {
            int bottom = stack.pop();          // 凹槽底部
            if (stack.isEmpty()) break;        // ⚠️ 无左壁 → 装不了水

            int left = stack.peek();           // 左壁
            int h = Math.min(height[left], height[i]) - height[bottom];
            int w = i - left - 1;              // 宽度
            water += h * w;                    // 这个凹槽的水
        }
        stack.push(i);
    }
    return water;
}
// 推演 [0,1,0,2,1,0,1,3,2,1,2,1] → 6 ✓
// ⚠️ 三解法对比（面试全讲 = 加分）：
//   暴力 O(n²)/O(1)
//   DP O(n)/O(n)
//   单调栈 O(n)/O(n)（按层）
//   双指针 O(n)/O(1)（按列）★ 最优
```

## 7. 907. 子数组的最小值之和

### 7.1 完整实现（贡献法）

```java
/**
 * LeetCode 907. 子数组的最小值之和（Hard）
 * 贡献法：每个元素作为最小值的贡献
 *   = val × (i-left) × (right-i)
 * ⚠️ 左严格右宽松（去重）
 */
public int sumSubarrayMins(int[] arr) {
    int n = arr.length;
    int MOD = 1_000_000_007;

    int[] left = new int[n];      // 左边第一个更小（距离）
    int[] right = new int[n];     // 右边第一个更小（距离）
    Deque<Integer> stack = new ArrayDeque<>();

    // 左边界：严格小于（用 >= 弹栈）
    for (int i = 0; i < n; i++) {
        while (!stack.isEmpty() && arr[stack.peek()] >= arr[i]) {
            stack.pop();
        }
        left[i] = stack.isEmpty() ? i + 1 : i - stack.peek();
        stack.push(i);
    }

    stack.clear();
    // 右边界：小于等于（用 > 弹栈）
    for (int i = n - 1; i >= 0; i--) {
        while (!stack.isEmpty() && arr[stack.peek()] > arr[i]) {
            stack.pop();
        }
        right[i] = stack.isEmpty() ? n - i : stack.peek() - i;
        stack.push(i);
    }

    // 贡献求和
    long sum = 0;
    for (int i = 0; i < n; i++) {
        sum = (sum + (long) arr[i] * left[i] % MOD * right[i]) % MOD;
    }
    return (int) sum;
}
// 推演 [3,1,2,4] → 17 ✓
// ⚠️ 为什么左严格右宽松？
//   重复元素去重：两边都"小于" → 重复计数
//   一边严格一边宽松 → 每个子数组只被"最左的最小"计算
// ⚠️ 面试必答：
//   "贡献法：每个元素作为最小值覆盖的子数组
//    = 左边数量 × 右边数量；
//    去重规则：左严格 + 右宽松。"
```

## 8. 316. 去除重复字母

### 8.1 完整实现（单调栈 + 贪心）

```java
/**
 * LeetCode 316. 去除重复字母（字典序最小）
 * 单调栈 + 贪心：当前 < 栈顶 且 栈顶后面还会出现 → 弹出
 */
public String removeDuplicateLetters(String s) {
    int[] lastIndex = new int[26];
    for (int i = 0; i < s.length(); i++) {
        lastIndex[s.charAt(i) - 'a'] = i;    // 最后出现位置
    }

    Deque<Character> stack = new ArrayDeque<>();
    boolean[] inStack = new boolean[26];

    for (int i = 0; i < s.length(); i++) {
        char c = s.charAt(i);
        if (inStack[c - 'a']) continue;      // 已在栈中

        // ⚠️ 单调性维护：c < 栈顶 且 栈顶还会出现 → 弹
        while (!stack.isEmpty()
               && c < stack.peek()
               && lastIndex[stack.peek() - 'a'] > i) {
            inStack[stack.pop() - 'a'] = false;
        }
        stack.push(c);
        inStack[c - 'a'] = true;
    }

    StringBuilder sb = new StringBuilder();
    while (!stack.isEmpty()) sb.append(stack.pollLast());  // 栈底到栈顶
    return sb.toString();
}
// 推演 "bcabc" → "abc"；"cbacdcbc" → "acdb" ✓
// ⚠️ 面试必答：
//   "贪心：字典序最小 → 当前字符更小时
//    弹出更大的栈顶（如果它后面还会出现）。
//    单调栈维护'字典序递增'。"
```
