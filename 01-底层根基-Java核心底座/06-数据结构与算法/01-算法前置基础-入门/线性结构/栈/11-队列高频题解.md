## 1. 102. 二叉树的层序遍历

### 1.1 完整实现（BFS 模板题）

```java
/**
 * LeetCode 102. 二叉树的层序遍历
 * size 分层：每轮先固定本层节点数
 */
public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> result = new ArrayList<>();
    if (root == null) return result;

    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);

    while (!queue.isEmpty()) {
        int levelSize = queue.size();      // ⚠️ 固定本层！
        List<Integer> level = new ArrayList<>();

        for (int i = 0; i < levelSize; i++) {
            TreeNode node = queue.poll();
            level.add(node.val);
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        result.add(level);
    }
    return result;
}
// ⚠️ 为什么必须固定 size？
//   不固定 → 本层与下层节点混在一起
// ⚠️ 队列是 BFS 的唯一结构：
//   FIFO 保证先进入的节点先处理（层序）
// ⚠️ 变体：107 自底向上（头插）、103 锯齿（反转）
//   199 右视图（每层最后一个）、513 左下角
```

## 2. 933. 最近请求次数

### 2.1 完整实现（窗口过期出队）

```java
/**
 * LeetCode 933. 最近的请求次数
 * 队列维护时间窗口：过期请求出队
 */
class RecentCounter {
    private Queue<Integer> queue;

    public RecentCounter() {
        queue = new LinkedList<>();
    }

    public int ping(int t) {
        queue.offer(t);                  // 新请求入队
        // ⚠️ 移除窗口外（超过 3000ms）的请求
        while (queue.peek() < t - 3000) {
            queue.poll();                // 队首过期 → 出队
        }
        return queue.size();             // 窗口内请求数
    }
}
// 推演 ping(1), ping(2), ping(3001), ping(3002)：
//   [1]→[1,2]→[2,3001]（1 过期）→[3001,3002]（2 过期）
//   返回：1,2,2,2 ✓
// ⚠️ 每个请求入队出队各一次 → 均摊 O(1)
// ⚠️ 面试必答："队列 FIFO 天然匹配
//   '先来先过期'的窗口语义"
```

## 3. 225. 用队列实现栈

### 3.1 完整实现（单队列轮转）

```java
/**
 * LeetCode 225. 用队列实现栈
 * 单队列 + 轮转：push 后把前面的移到后面
 */
class MyStack {
    private Queue<Integer> queue;

    public MyStack() {
        queue = new LinkedList<>();
    }

    public void push(int x) {
        queue.offer(x);
        // ⚠️ 轮转：把前面的 n-1 个移到后面
        int size = queue.size();
        for (int i = 0; i < size - 1; i++) {
            queue.offer(queue.poll());
        }
        // 新元素成为队首（栈顶）
    }

    public int pop() {
        return queue.poll();             // 队首 = 栈顶
    }

    public int top() {
        return queue.peek();
    }

    public boolean empty() {
        return queue.isEmpty();
    }
}
// 推演 push 1,2,3：
//   push 1 → [1]；push 2 → 轮转 → [2,1]
//   push 3 → 轮转 → [3,2,1]；pop → 3 ✓
// ⚠️ push O(n)，其余 O(1)
// ⚠️ 面试对比：
//   232 栈实现队列：双栈倒腾（均摊 O(1)）
//   225 队列实现栈：单队列轮转（push O(n)）
```

## 4. 622. 设计循环队列

### 4.1 完整实现（数组 + 取模）

```java
/**
 * LeetCode 622. 设计循环队列
 * 数组 + 取模循环
 */
class MyCircularQueue {
    private int[] data;
    private int head = 0, tail = 0;
    private int size = 0;                // ⚠️ 区分空满

    public MyCircularQueue(int k) {
        data = new int[k];
    }

    public boolean enQueue(int value) {
        if (isFull()) return false;
        data[tail] = value;
        tail = (tail + 1) % data.length; // ⚠️ 取模循环！
        size++;
        return true;
    }

    public boolean deQueue() {
        if (isEmpty()) return false;
        head = (head + 1) % data.length; // ⚠️ 取模循环！
        size--;
        return true;
    }

    public int Front() {
        return isEmpty() ? -1 : data[head];
    }

    public int Rear() {
        return isEmpty() ? -1
            : data[(tail - 1 + data.length) % data.length];  // ⚠️ 防负
    }

    public boolean isEmpty() { return size == 0; }
    public boolean isFull() { return size == data.length; }
}
// 推演 cap=3：enQueue(1,2,3) → 满；deQueue → 空 1 位
//   enQueue(4)：tail=(3)%3=0 → [4,2,3] ✓ 循环！
// ⚠️ 三个细节：
//   ① 取模循环：(tail+1) % len
//   ② 队尾防负：(tail-1+len) % len
//   ③ size 区分空满（head==tail 可能空也可能满）
```

## 5. 641. 设计循环双端队列

### 5.1 完整实现

```java
/**
 * LeetCode 641. 设计循环双端队列
 * = 622 + 两端操作
 */
class MyCircularDeque {
    private int[] data;
    private int head = 0, tail = 0;
    private int size = 0;
    private int capacity;

    public MyCircularDeque(int k) {
        data = new int[k];
        capacity = k;
    }

    // 前插：head 前移（防负）+ 赋值
    public boolean insertFront(int value) {
        if (isFull()) return false;
        head = (head - 1 + capacity) % capacity;   // ⚠️ 前移防负
        data[head] = value;
        size++;
        return true;
    }

    // 后插：赋值 + tail 后移
    public boolean insertLast(int value) {
        if (isFull()) return false;
        data[tail] = value;
        tail = (tail + 1) % capacity;
        size++;
        return true;
    }

    // 前删：head 后移
    public boolean deleteFront() {
        if (isEmpty()) return false;
        head = (head + 1) % capacity;
        size--;
        return true;
    }

    // 后删：tail 前移（防负）
    public boolean deleteLast() {
        if (isEmpty()) return false;
        tail = (tail - 1 + capacity) % capacity;
        size--;
        return true;
    }

    public int getFront() { return isEmpty() ? -1 : data[head]; }

    public int getRear() {
        return isEmpty() ? -1
            : data[(tail - 1 + capacity) % capacity];
    }

    public boolean isEmpty() { return size == 0; }
    public boolean isFull() { return size == capacity; }
}
// ⚠️ 四方向取模记忆：
//   前插/后删：前移（-1+len）% len（防负）
//   后插/前删：后移（+1）% len
```

## 6. 346. 滑动窗口平均值

### 6.1 完整实现（队列维护窗口）

```java
/**
 * LeetCode 346. 滑动窗口平均值
 * 队列维护窗口内元素，大小固定
 */
class MovingAverage {
    private Queue<Integer> queue;
    private int capacity;
    private double sum = 0;              // ⚠️ 维护和（O(1)）

    public MovingAverage(int size) {
        queue = new LinkedList<>();
        capacity = size;
    }

    public double next(int val) {
        queue.offer(val);
        sum += val;                      // 加新元素

        if (queue.size() > capacity) {
            sum -= queue.poll();         // ⚠️ 移除过期（同步减和）
        }
        return sum / queue.size();
    }
}
// 推演 cap=3：next(1)=1, next(10)=5.5, next(3)=4.67, next(5)=6
// ⚠️ 面试必答：
//   "维护 sum 变量 → 平均值 O(1)；
//    过期元素同步从 sum 减去（增量维护）。"
```

## 7. 207. 课程表（Kahn 拓扑）

### 7.1 完整实现

```java
/**
 * LeetCode 207. 课程表（Kahn 拓扑 = BFS + 入度）
 */
public boolean canFinish(int numCourses, int[][] prerequisites) {
    // ① 建图 + 入度
    List<List<Integer>> graph = new ArrayList<>();
    int[] indegree = new int[numCourses];
    for (int i = 0; i < numCourses; i++) graph.add(new ArrayList<>());
    for (int[] pre : prerequisites) {
        graph.get(pre[1]).add(pre[0]);
        indegree[pre[0]]++;
    }

    // ② 入度 0 入队（无前置依赖）
    Queue<Integer> queue = new LinkedList<>();
    for (int i = 0; i < numCourses; i++) {
        if (indegree[i] == 0) queue.offer(i);
    }

    // ③ BFS 处理
    int processed = 0;
    while (!queue.isEmpty()) {
        int cur = queue.poll();
        processed++;
        for (int next : graph.get(cur)) {
            if (--indegree[next] == 0) {   // 前置完成
                queue.offer(next);
            }
        }
    }
    return processed == numCourses;      // ⚠️ 判环
}
// ⚠️ 为什么"处理数 < n"即有环？
//   环上节点入度永远 ≥ 1 → 无法入队
// ⚠️ 面试必答："Kahn = BFS + 入度：
//   入度 0 入队 → 出队减入度 → 减到 0 再入队。
//   队列是'可处理集合'的载体。"
```

## 8. 994. 腐烂的橘子（BFS）

### 8.1 完整实现（多源 BFS）

```java
/**
 * LeetCode 994. 腐烂的橘子（多源 BFS 经典）
 * 所有烂橘子同时入队 → 逐层扩散计时
 */
public int orangesRotting(int[][] grid) {
    int m = grid.length, n = grid[0].length;
    Queue<int[]> queue = new LinkedList<>();
    int fresh = 0;

    // ① 所有腐烂橘子入队 + 统计新鲜数
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (grid[i][j] == 2) queue.offer(new int[]{i, j});
            else if (grid[i][j] == 1) fresh++;
        }
    }

    // ② 多源 BFS 扩散
    int minutes = 0;
    int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};
    while (!queue.isEmpty() && fresh > 0) {      // ⚠️ fresh > 0 剪枝
        int size = queue.size();
        for (int i = 0; i < size; i++) {
            int[] cur = queue.poll();
            for (int[] d : dirs) {
                int nx = cur[0] + d[0], ny = cur[1] + d[1];
                if (nx < 0 || nx >= m || ny < 0 || ny >= n) continue;
                if (grid[nx][ny] != 1) continue;

                grid[nx][ny] = 2;                // 腐烂（原地标记）
                fresh--;
                queue.offer(new int[]{nx, ny});
            }
        }
        minutes++;                               // 1 分钟 = 1 层
    }
    return fresh == 0 ? minutes : -1;            // 有剩余 → -1
}
// ⚠️ 面试必答：
//   "多源 BFS：所有源同时入队 = 超级源点；
//    size 分层计时（每层 = 1 分钟）；
//    fresh 计数判断感染是否完全。"
```
