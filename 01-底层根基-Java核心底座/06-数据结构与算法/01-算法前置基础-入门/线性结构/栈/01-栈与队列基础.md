## 1. 栈：后进先出

### 1.1 定义与操作

```
栈（Stack）：只允许在栈顶（Top）操作的线性结构
  LIFO（Last In First Out）：后进先出

操作：push（压栈）/ pop（弹栈）/ peek（看栈顶）/ isEmpty

类比：一叠盘子——最后放的先拿
```

```
push 1 → [1]
push 2 → [1, 2]
push 3 → [1, 2, 3]     ← 栈顶
pop 3 → [1, 2]
peek 2 → [1, 2]
```

### 1.2 栈的应用场景

| 场景 | 为什么用栈 | 代表题 |
|------|------|:---:|
| 括号匹配 | 最近匹配原则（LIFO） | 20 |
| 表达式计算 | 运算符优先级天然栈结构 | 150 |
| 函数调用 | 递归栈 | 所有递归 |
| 撤销操作 | 最近操作先撤销 | 编辑器 |
| DFS | 深度优先遍历 | 见 DFS 体系 |
| 单调栈 | 找下一个更大/更小 | 739 |

## 2. 队列：先进先出

### 2.1 定义与操作

```
队列（Queue）：队尾入队、队首出队的线性结构
  FIFO（First In First Out）：先进先出

操作：offer（入队）/ poll（出队）/ peek（看队首）

类比：排队买票——先来的先服务
```

```
offer 1 → [1]
offer 2 → [1, 2]
offer 3 → [1, 2, 3]     ← 队尾
poll → 1, 队列 [2, 3]    ← 队首先出
```

### 2.2 队列的应用场景

| 场景 | 为什么用队列 | 代表题 |
|------|------|:---:|
| BFS | 层扩散（见 BFS 体系） | 102/994 |
| 任务调度 | FIFO 公平调度 | 操作系统 |
| 缓冲 | 生产-消费 | 消息队列 |
| 滑动窗口 | 过期元素移除 | 933/239 |

## 3. 双端队列 Deque

### 3.1 定义

```
双端队列（Deque）：两端都可以插入和删除
  = 栈 + 队列 的合体

常用组合：
  只在一端操作 → 栈
  一端进一端出 → 队列
  两端都操作 → 单调队列（滑动窗口最值）
```

### 3.2 双向操作

```
      ┌────────────────────┐
offerFirst → |  [2]  [1]  [3]  | → offerLast
pollFirst  ← |                | ← pollLast
             └────────────────┘
   队首（left）              队尾（right）

Java 实现：ArrayDeque（数组实现，性能最好）
```

## 4. Java API 正确使用

### 4.1 栈的三种实现（⚠️ 陷阱）

```java
// ❌ 不推荐：Java 官方 Stack 类（继承 Vector，全方法加锁，性能差）
Stack<Integer> stack = new Stack<>();
stack.push(1);
stack.pop();

// ✅ 推荐：ArrayDeque 模拟栈（性能好，无锁）
Deque<Integer> stack = new ArrayDeque<>();
stack.push(1);            // 压栈（addFirst）
stack.pop();              // 弹栈（removeFirst）
stack.peek();             // 看栈顶（peekFirst）

// 也可以用 LinkedList（但 ArrayDeque 更快）
```

### 4.2 队列的两种实现

```java
// ✅ 推荐：LinkedList 实现 Queue
Queue<Integer> queue = new LinkedList<>();
queue.offer(1);           // 入队（add 失败抛异常，offer 返回 false）
queue.poll();             // 出队（remove 失败抛异常，poll 返回 null）
queue.peek();             // 看队首（element 抛异常，peek 返回 null）

// ✅ 双端队列
Deque<Integer> deque = new ArrayDeque<>();
deque.offerFirst(1);      // 队首插入
deque.offerLast(2);       // 队尾插入
deque.pollFirst();        // 队首删除
deque.pollLast();         // 队尾删除
```

### 4.3 API 选择总结

| 需求 | 推荐写法 | 避免 |
|------|------|------|
| 栈 | `Deque<Integer> s = new ArrayDeque<>()` | `Stack`（性能差） |
| 队列 | `Queue<Integer> q = new LinkedList<>()` | `Vector` |
| 双端 | `Deque<Integer> d = new ArrayDeque<>()` | — |
| offer vs add | 用 offer/poll/peek（不抛异常） | add/remove（抛异常） |

> 💡 **面试细节**：用 `ArrayDeque` 模拟栈、`LinkedList` 实现队列，并解释为什么不用 `Stack`（继承 Vector 的同步开销 + 遗留 API）——这是 Java 基础知识的加分点。

## 5. 栈 vs 队列 vs 双端队列

| 维度 | 栈 | 队列 | 双端队列 |
|------|:---:|:---:|:---:|
| 顺序 | LIFO | FIFO | 两者皆可 |
| 插入 | 栈顶 | 队尾 | 两端 |
| 删除 | 栈顶 | 队首 | 两端 |
| 查询 | 栈顶 O(1) | 队首 O(1) | 两端 O(1) |
| Java 实现 | ArrayDeque | LinkedList | ArrayDeque |
| 典型应用 | 括号/表达式/DFS | BFS/调度 | 单调队列/窗口最值 |

### 选型判断

```
"后进先出" → 栈（括号匹配、表达式、DFS）
"先进先出" → 队列（BFS、公平调度）
"两端都要操作" → Deque（单调队列）
"需要最值且会过期" → 单调栈/单调队列（见 03/04 模块）
```

## 9. 常见错误清单

| # | 易错点 | 对策 |
|---|--------|------|
| 1 | 栈空时 peek/pop | 先判 isEmpty |
| 2 | 括号题匹配后忘弹 | 匹配即 pop |
| 3 | 队列判空用 size | size == 0 或 isEmpty |
| 4 | 循环队列判满混淆 | size 计数或预留一格 |
| 5 | 栈与队列容器混用 | push/pop vs offer/poll |

> 🎯 **核心要点**：栈/队列是两种最基础的线性结构——**LIFO 管"最近相关"**（括号/表达式/DFS），**FIFO 管"顺序相关"**（BFS/调度）。Java 实现记住"ArrayDeque 模拟栈、LinkedList 实现队列、offer/poll/peek 不抛异常"，这是面试手写的第一道防线。
