## 1. 四大核心技巧的完整体系

### 1.1 技巧总览

```
① Dummy 虚拟头：统一头节点操作
   适用：删除/合并/分隔（头可能变化）
② 快慢指针：判环/中点/倒数第 N
   适用：定位类问题
③ 三指针：反转链表
   适用：反转/交换/分组翻转
④ 递归：分解为"当前节点 + 剩余链"
   适用：反转/合并（空间换简洁）

⚠️ 实际题目往往是组合：
  19 删除倒数第 N → Dummy + 快慢
  148 排序链表 → 快慢（中点）+ 递归（归并）
  234 回文链表 → 快慢（中点）+ 三指针（反转）+ 双指针
```

### 1.2 技巧选型表

| 问题特征 | 技巧 | 代表题 |
|------|------|:---:|
| 头节点可能被删/改 | Dummy | 19/86/82 |
| 定位（中点/倒数/环） | 快慢 | 141/876/19 |
| 反转/交换 | 三指针 | 206/24/25 |
| 递归结构天然 | 递归 | 21/206 递归版 |
| 设计题（LRU） | 哈希+双向 | 146 |

```
⚠️ 面试表达：
"这题的核心技巧是【Dummy + 快慢】——
 删除倒数第 N 可能删头（Dummy），
 需要定位（快慢先走 N+1 步）。"
```

### 1.3 画图原则

```
⚠️ 链表题第一原则：画图！
  指针变化视觉化 → 不动笔等于没做

画图步骤：
  ① 画出初始链表与所有指针
  ② 每一步修改 → 重画指针指向
  ③ 标注"暂存"的节点（防断链）
  ④ 确认循环结束条件

⚠️ 面试表达：
"我习惯先画图推演指针变化——
 链表题不动笔等于没做。"
```

## 2. Dummy 虚拟头的深度剖析

### 2.1 为什么需要 Dummy

```
问题场景：删除头节点
  普通做法：特判 head == null 或 head 被删
  → 大量分支判断 → 代码丑、易错

Dummy 方案：
  dummy → [原链表]
  所有操作从 dummy.next 开始统一处理
  删除任何节点（含原头节点）都变成
  "删除某个节点的后继"
  → 代码统一、无特判

⚠️ 记忆口诀：
  "修改链表先建 dummy，操作从 dummy 开始，
   返回 dummy.next"
```

### 2.2 Dummy 使用模板

```java
/**
 * Dummy 通用模板
 */
public ListNode solve(ListNode head) {
    ListNode dummy = new ListNode(-1);   // 值随意
    dummy.next = head;
    ListNode prev = dummy;               // 操作指针从 dummy 开始

    // ... 各种操作（删除/插入/合并）

    return dummy.next;                   // 返回新头
}
// ⚠️ 三个固定动作：
//   ① 建 dummy（值随意）
//   ② 操作从 dummy 开始
//   ③ 返回 dummy.next
```

### 2.3 19. 删除倒数第 N（Dummy 经典）

```java
/**
 * LeetCode 19. 删除链表的倒数第 N 个结点
 * Dummy + 快慢指针
 * ⚠️ 必须用 dummy：可能删除头节点！
 */
public ListNode removeNthFromEnd(ListNode head, int n) {
    ListNode dummy = new ListNode(-1);
    dummy.next = head;

    ListNode fast = dummy, slow = dummy;

    // ① fast 先走 n+1 步（让 slow 停在待删前驱）
    for (int i = 0; i <= n; i++) {
        fast = fast.next;
    }

    // ② 同步走，fast 到 null 时 slow 在待删前驱
    while (fast != null) {
        fast = fast.next;
        slow = slow.next;
    }

    // ③ 删除
    slow.next = slow.next.next;

    return dummy.next;
}
// 推演 1→2→3→4→5, n=2：
//   fast 先走 3 步 → 指向 4；slow 指向 dummy
//   同步走：fast 到 null，slow 指向 3（待删 4 的前驱）
//   3.next = 5 → 删除 4 ✓
// ⚠️ 为什么 fast 先走 n+1 而非 n？
//   让 slow 停在"前驱"而非"待删节点"
//   （删除需要前驱！）
```

### 2.4 其他 Dummy 场景

```
86 分隔链表：两个 dummy（小链表/大链表）
82 删除重复 II：dummy + 跳过整个区间
21 合并有序链：dummy 占位结果头

⚠️ 识别信号：
  "头节点可能被修改/删除/不确定"
  → 先建 dummy
```

## 3. 快慢指针的数学原理

### 3.1 为什么走 2 步

```
判环场景（141）：
  slow 走 1 步，fast 走 2 步
  相对速度 = 2 - 1 = 1（每轮差距减 1）
  环长 L → 最多 L 轮追上 → 必然相遇

⚠️ 如果走 3 步？
  相对速度 = 2（每轮差距减 2）
  环长不是 2 的倍数时可能永远跳过
  例：环长 3，fast 每次跳 2 → 可能错过

⚠️ 面试必答：
"走 2 步保证相对速度 1——
 任何环长下必然相遇。"
```

### 3.2 142. 找环入口的数学推导

```
设：
  a = 链表头到环入口的距离
  b = 环入口到相遇点的距离
  c = 相遇点到环入口的剩余距离
  环长 L = b + c

slow 走 = a + b
fast 走 = a + b + kL（k 圈）
且 fast = 2 × slow

⇒ 2(a+b) = a+b+kL
⇒ a + b = kL
⇒ a = kL - b = (k-1)L + (L-b) = (k-1)L + c

结论：从 head 走 a 步 与 从相遇点走 a 步
     都会到达环入口！

阶段 2 实现：
  slow 重置 head，fast 留在相遇点
  同速走 1 步 → 再次相遇 = 环入口 ✓
```

### 3.3 快慢指针的五大应用

```
① 判环（141）：相遇即有环
② 找入口（142）：相遇后重置同速走
③ 找中点（876）：fast 到头 slow 在中点
④ 倒数第 N（19）：fast 先走 N+1
⑤ 回文（234）：中点 + 反转 + 比较

⚠️ 循环条件统一：
  while (fast != null && fast.next != null)
  （访问 fast.next.next 前必须判空）
```

## 4. 三指针与反转的艺术

### 4.1 206. 反转链表（三指针）

```java
/**
 * LeetCode 206. 反转链表（三指针）
 * prev/curr/next 三个指针协同
 */
public ListNode reverseList(ListNode head) {
    ListNode prev = null;          // 前驱（初始为空）
    ListNode curr = head;

    while (curr != null) {
        ListNode next = curr.next;   // ① 暂存后继（防断链！）
        curr.next = prev;            // ② 反转指针
        prev = curr;                 // ③ 前驱前进
        curr = next;                 // ④ 当前前进
    }
    return prev;                     // 新头 = 原尾
}
// 推演 1→2→3→null：
//   ① next=2, ② 1.next=null, ③ prev=1, ④ curr=2
//   ① next=3, ② 2.next=1, ③ prev=2, ④ curr=3
//   ① next=null, ② 3.next=2, ③ prev=3, ④ curr=null
//   返回 3 → 3→2→1 ✓
// ⚠️ 为什么必须暂存 next？
//   反转 curr.next 后，原来的后继就丢了！
```

### 4.2 头插法（区间反转的利器）

```
头插法原理：遍历区间内每个节点，依次插到 pre 后面
  pre → [1] → [2] → [3] → [4] → [5]
  处理 3：pre → [3] → [1] → [2] → [4] → [5]
  处理 4：pre → [4] → [3] → [1] → [2] → [5]
  处理完区间 → 自动反转 ✓

92 反转链表 II 的核心：
  ① 定位 pre（left 前驱）
  ② 头插区间内节点
  ③ 完成即反转

⚠️ 与三指针对比：
  三指针：全链反转（206）
  头插法：区间反转（92/25）
```

### 4.3 递归反转（空间换简洁）

```java
/**
 * 递归版反转（空间 O(n)）
 * 思路：递归到末尾拿到 newHead，回溯时反转指针
 */
public ListNode reverseListRecursive(ListNode head) {
    if (head == null || head.next == null) return head;

    ListNode newHead = reverseListRecursive(head.next);
    head.next.next = head;   // 让后继指向自己（反转）
    head.next = null;        // 断开原前向
    return newHead;
}
// 1→2→3：
//   reverse(3) → 返回 3
//   reverse(2) → newHead=3, 3.next=2, 2.next=null → 3→2
//   reverse(1) → newHead=3, 2.next=1, 1.next=null → 3→2→1 ✓

// ⚠️ 迭代 vs 递归：
//   迭代：空间 O(1)，面试主推
//   递归：空间 O(n)，追问时展示
//   "链表很长时递归可能栈溢出 → 主推迭代"
```

## 5. 链表题的边界处理

### 5.1 边界清单

```
① 空链表（head == null）
② 单节点（head.next == null）
③ 删除头节点（Dummy 统一）
④ 尾部操作（next == null）
⑤ 快慢循环条件（fast 和 fast.next 判空）

⚠️ 手写后自检：
  空链表 → 不报错
  单节点 → 正确返回
  头节点 → Dummy 处理
```

### 5.2 常见断链错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 插入顺序反 | 断链 | 先连新节点再接 prev |
| 反转忘暂存 next | 断链 | 先存再反转 |
| 拼接忘断环 | 死循环 | 尾部 next=null |
| 循环条件漏判 | 空指针 | fast.next 判空 |
| 返回错头 | 结果错 | 返回 dummy.next |

```
⚠️ 断环场景（86/143）：
  分隔/重排后，原链表的尾节点
  可能还指向前面节点 → 必须 next=null
```

### 5.3 迭代 vs 递归的选型

```
迭代：空间 O(1)，无栈溢出风险 → 主推
递归：空间 O(n)，代码简洁 → 追问展示

⚠️ 面试表达：
"迭代版 O(1) 空间更优；递归版简洁但
 O(n) 栈空间，链表很长时可能栈溢出，
 所以主推迭代。"
```
