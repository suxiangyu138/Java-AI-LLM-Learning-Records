## 1. 核心概念

### 1.1 什么是单调栈

> 单调栈：栈内元素保持单调（递增或递减）的栈。新元素入栈时，**弹出所有破坏单调性的元素**，再入栈。

```
单调递减栈（求下一个更大元素）：
  入栈 5 → [5]
  入栈 3 → [5, 3]        （3 < 5 不破坏单调）
  入栈 4 → 弹出 3 → [5, 4]  （4 > 3 破坏递减 → 弹 3）

为什么"弹出即答案"？
  4 是 3 的"下一个更大元素"（第一个比它大的）
  → 弹出时记录答案
```

### 1.2 识别信号

```
"下一个更大/更小元素" → 单调栈（739/496/503）
"左右边界（第一个更小/大）" → 单调栈（84/907）
"维护单调序列" → 单调栈（316 去重字母）

⚠️ 核心特征：
  每个元素找"第一个比它大/小"的邻居
  → 单调栈 O(n)（暴力 O(n²)）
```

### 1.3 为什么是 O(n)

```
每个元素：
  入栈恰好 1 次
  出栈最多 1 次（弹出后永不再入）
  → 总操作 2n → O(n)

对比暴力：每个元素向后扫描找更大 → O(n²)

⚠️ 面试必答：
"每个元素进出栈各一次，总操作 O(2n)=O(n)"
```

## 2. 完整代码模板

### 2.1 739. 每日温度（母题）

```java
/**
 * LeetCode 739. 每日温度（单调栈第一题）
 * 返回每个温度后几天出现更高的温度
 */
public int[] dailyTemperatures(int[] temperatures) {
    int n = temperatures.length;
    int[] answer = new int[n];
    Deque<Integer> stack = new ArrayDeque<>();   // 存下标！

    for (int i = 0; i < n; i++) {
        // ⚠️ 当前温度比栈顶大 → 栈顶的"下一个更大"找到了
        while (!stack.isEmpty()
               && temperatures[i] > temperatures[stack.peek()]) {
            int idx = stack.pop();
            answer[idx] = i - idx;               // 距离 = 天数差
        }
        stack.push(i);                           // 当前下标入栈
    }
    // 栈中剩余元素：后面没有更高的温度 → 保持 0
    return answer;
}
// 推演 [73,74,75,71,69,72,76,73] → [1,1,4,2,1,1,0,0]
// 复杂度 O(n)：每元素进出栈一次
```

### 2.2 通用模板（求下一个更大）

```java
/**
 * 单调栈通用模板
 * 关键四要素：
 *   ① 栈存下标（需要距离/位置）
 *   ② 单调方向：求更大 → 递减栈
 *   ③ 弹出时机：当前值 > 栈顶值
 *   ④ 栈底 → 栈顶 递减
 */
public int[] nextGreater(int[] nums) {
    int n = nums.length;
    int[] result = new int[n];
    Arrays.fill(result, -1);
    Deque<Integer> stack = new ArrayDeque<>();

    for (int i = 0; i < n; i++) {
        while (!stack.isEmpty() && nums[i] > nums[stack.peek()]) {
            int idx = stack.pop();
            result[idx] = nums[i];       // 当前值 = 栈顶的下一个更大
        }
        stack.push(i);
    }
    return result;
}

// 求下一个更小：改符号
//   while (!stack.isEmpty() && nums[i] < nums[stack.peek()])

// 四个方向对照：
//   下一个更大 → 递减栈（739/496）
//   下一个更小 → 递增栈
//   上一个更大/更小 → 弹出时记录左侧答案
//   记忆："找更大用递减栈（栈顶最小，被更大的弹出）"
```

### 2.3 503. 循环数组（两遍取模）

```java
/**
 * LeetCode 503. 下一个更大元素 II（循环数组）
 * 遍历两遍（2n 次），下标取模 i % n
 */
public int[] nextGreaterElements(int[] nums) {
    int n = nums.length;
    int[] result = new int[n];
    Arrays.fill(result, -1);
    Deque<Integer> stack = new ArrayDeque<>();

    for (int i = 0; i < 2 * n; i++) {
        int idx = i % n;                         // ⚠️ 取模模拟循环
        while (!stack.isEmpty() && nums[idx] > nums[stack.peek()]) {
            result[stack.pop()] = nums[idx];     // 找到下一个更大
        }
        stack.push(idx);
    }
    return result;
}
// [1,2,1] → [2,-1,2]（最后一个 1 的下一个更大是开头的 2）
// ⚠️ 为什么两遍？循环数组的答案可能在"数组开头"
```

## 3. 单调栈的三大应用

### 3.1 应用一：下一个更大/更小（739/496/503）

```

  距离（739）或值（496/503）
```

### 3.2 应用二：区间边界（84 最大矩形）

```java
/**
 * LeetCode 84. 柱状图中最大的矩形
 * 每个柱子作为高度 → 找左右第一个更矮的
 * 单调递增栈弹出时"三方会合"：
 *   弹出元素 = 当前柱子（高）
 *   新栈顶 = 左边界（左边第一个更矮）
 *   当前元素 = 右边界（右边第一个更矮）
 * 面积 = h × (右边界 - 左边界 - 1)
 */
public int largestRectangleArea(int[] heights) {
    int n = heights.length;
    int[] h = new int[n + 2];            // ⚠️ 首尾补 0
    System.arraycopy(heights, 0, h, 1, n);

    Deque<Integer> stack = new ArrayDeque<>();
    int maxArea = 0;
    for (int i = 0; i < h.length; i++) {
        while (!stack.isEmpty() && h[i] < h[stack.peek()]) {
            int height = h[stack.pop()];
            int width = i - stack.peek() - 1;    // 三方会合
            maxArea = Math.max(maxArea, height * width);
        }
        stack.push(i);
    }
    return maxArea;
}
// 哨兵作用：头部 0 免判空；尾部 0 强制弹出全部
```

### 3.3 应用三：字典序最小（316 去重字母）

```java
/**
 * LeetCode 316. 去除重复字母（字典序最小）
 * 单调栈 + 贪心：
 *   当前字符 < 栈顶 且 栈顶后面还会出现 → 弹出栈顶
 *   （保留更小字符在前 → 字典序更小）
 */
public String removeDuplicateLetters(String s) {
    int[] lastIndex = new int[26];
    for (int i = 0; i < s.length(); i++) {
        lastIndex[s.charAt(i) - 'a'] = i;    // 最后出现位置
    }

    Deque<Character> stack = new ArrayDeque<>();
    boolean[] inStack = new boolean[26];

    for (int i = 0; i < s.length(); i++) {
        char c = s.charAt(i);
        if (inStack[c - 'a']) continue;      // 已在栈中

        // ⚠️ 单调性维护：c < 栈顶 且 栈顶还会出现 → 弹
        while (!stack.isEmpty()
               && c < stack.peek()
               && lastIndex[stack.peek() - 'a'] > i) {
            inStack[stack.pop() - 'a'] = false;
        }
        stack.push(c);
        inStack[c - 'a'] = true;
    }

    StringBuilder sb = new StringBuilder();
    while (!stack.isEmpty()) sb.append(stack.pollLast());  // 栈底到栈顶
    return sb.toString();
}
// "bcabc" → "abc"；"cbacdcbc" → "acdb"
```

## 4. 单调栈 vs 单调队列

### 4.1 对比表

| 维度 | 单调栈 | 单调队列 |
|------|:---:|:---:|
| 结构 | 栈（一端） | 双端队列 |
| 问题 | 下一个更大/更小 | 窗口内最值 |
| 过期概念 | 无（只进不出头） | 有（窗口滑出） |
| 复杂度 | O(n) | O(n) |
| 代表题 | 739/84 | 239 |

```
选型：
  "每个元素找下一个更大" → 单调栈
  "滑动窗口内最值" → 单调队列
  ⚠️ 单调队列 = 单调栈 + 窗口过期
```

### 4.2 何时选单调栈

```
① 找"第一个比它大/小"的邻居
② 需要"左右边界"（84/907 贡献法）
③ 维护字典序/单调序列（316）

⚠️ 识别关键词："下一个更大/更小、左右边界"
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"这题用单调栈：
 维护一个单调递减栈，存下标。
 遍历时，当前元素比栈顶大 → 栈顶元素找到了
 它的'下一个更大' → 弹出并记录答案。
 每个元素恰好进出栈一次 → O(n)。
 暴力需要 O(n²)，单调栈是关键优化。
 关键：存下标不存值（需要距离）。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 为什么单调栈 O(n)？ | 每元素进出栈各一次（总 2n） |
| 2 | 为什么存下标？ | 需要距离/宽度（位置信息） |
| 3 | 找更大为什么递减栈？ | 栈顶最小，遇到更大弹出即答案 |
| 4 | 84 为什么补 0？ | 头 0 免判空；尾 0 强制弹出残留 |
| 5 | 循环数组？ | 两遍遍历 + 取模 |
| 6 | 与单调队列区别？ | 无过期 vs 窗口过期 |
| 7 | 三方会合？ | 弹出=当前、新栈顶=左界、当前元素=右界 |
| 8 | 栈中剩余？ | 无更大 → 默认值（0/-1） |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 存值不存下标 | 无法算距离 | 存下标 |
| 单调方向反 | 结果错 | 找更大用递减栈 |
| 弹出忘记录 | 答案缺失 | 弹出时记录 |
| 84 忘补哨兵 | 残留未算 | 首尾补 0 |
| 比较方向错 | 弹出时机错 | nums[i] > 栈顶 |

> 🎯 **核心要点**：单调栈 = **存下标、单调递减找更大、弹出即答案**三铁律。识别信号："下一个更大/更小、左右边界、字典序最小"。739 母题 + 84 三方会合 + 316 贪心是三大应用模板；"每元素进出一次 O(n)"是面试必答。
