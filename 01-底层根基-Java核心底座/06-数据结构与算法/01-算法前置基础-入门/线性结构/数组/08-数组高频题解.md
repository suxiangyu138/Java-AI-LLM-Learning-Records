## 1. 1. 两数之和

### 1.1 完整实现（哈希）

```java
/**
 * LeetCode 1. 两数之和（面试第一题）
 * 关键细节：先检查再插入（防自匹配）
 */
public int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> map = new HashMap<>();   // 值 → 下标

    for (int i = 0; i < nums.length; i++) {
        int complement = target - nums[i];          // 补数
        if (map.containsKey(complement)) {
            return new int[]{map.get(complement), i};
        }
        map.put(nums[i], i);                        // ⚠️ 先查后插！
    }
    return new int[0];
}
// 推演 nums=[3,3], target=6：
//   i=0：补数 3 不在 map（还没存自己）→ 存 {3:0}
//   i=1：补数 3 在 map → 返回 [0,1] ✓
// ⚠️ 先插后查会返回 [0,0]（自匹配）
// 复杂度 O(n) 时间 O(n) 空间
```

## 2. 27/283. 移除元素与移动零

### 2.1 27. 移除元素（快慢覆盖）

```java
/**
 * LeetCode 27. 移除元素
 * slow 慢写（下一个保留位置），fast 快读（扫描）
 */
public int removeElement(int[] nums, int val) {
    int slow = 0;
    for (int fast = 0; fast < nums.length; fast++) {
        if (nums[fast] != val) {
            nums[slow++] = nums[fast];   // 保留覆盖
        }
    }
    return slow;
}
// 推演 [3,2,2,3], val=3：
//   fast=1(2) → nums[0]=2, slow=1
//   fast=2(2) → nums[1]=2, slow=2 → 返回 2 ✓
// ⚠️ 面试追问："为什么 O(1) 空间？"
//   原地覆盖（不申请新数组）
```

### 2.2 283. 移动零（补零）

```java
/**
 * LeetCode 283. 移动零
 * = 27（移除 0）+ 末尾补零
 */
public void moveZeroes(int[] nums) {
    int slow = 0;
    for (int fast = 0; fast < nums.length; fast++) {
        if (nums[fast] != 0) {
            nums[slow++] = nums[fast];   // 非零前移
        }
    }
    while (slow < nums.length) {
        nums[slow++] = 0;                // ⚠️ 末尾补零
    }
}
// 推演 [0,1,0,3,12]：
//   非零前移 → [1,3,12,3,12]，slow=3
//   补零 → [1,3,12,0,0] ✓
// ⚠️ 三题对比（27/26/283）：
//   27 移除 val：保留 != val
//   26 去重：保留 != nums[slow-1]
//   283 移动零：保留 != 0 + 补零
```

## 3. 26. 删除有序数组中的重复项

### 3.1 完整实现

```java
/**
 * LeetCode 26. 删除有序数组中的重复项
 * 与 27 的差异：保留条件是"与前一个保留值不同"
 */
public int removeDuplicates(int[] nums) {
    if (nums.length == 0) return 0;
    int slow = 1;                      // ⚠️ 第一个元素必然保留

    for (int fast = 1; fast < nums.length; fast++) {
        if (nums[fast] != nums[slow - 1]) {   // 与上一个保留值比较
            nums[slow++] = nums[fast];
        }
    }
    return slow;
}
// 推演 [0,0,1,1,1,2,2,3,3,4] → 5 ✓
// ⚠️ 变体：80 去重 II（最多保留 k 个）
//   if (slow < k || nums[fast] != nums[slow-k])
//   记忆："留 k 个看 slow-k"（滑动窗口思想）
```

## 4. 189. 旋转数组

### 4.1 完整实现（三次反转）

```java
/**
 * LeetCode 189. 旋转数组（原地 O(1) 空间）
 */
public void rotate(int[] nums, int k) {
    int n = nums.length;
    k %= n;                                // ⚠️ k 可能 > n
    reverse(nums, 0, n - 1);               // ① 整体反转
    reverse(nums, 0, k - 1);               // ② 前 k 反转
    reverse(nums, k, n - 1);               // ③ 后 n-k 反转
}

private void reverse(int[] arr, int lo, int hi) {
    while (lo < hi) {
        int tmp = arr[lo]; arr[lo] = arr[hi]; arr[hi] = tmp;
        lo++; hi--;
    }
}
// 推演 [1,2,3,4,5,6,7], k=3：
//   整体 → [7,6,5,4,3,2,1]
//   前 3 → [5,6,7,4,3,2,1]
//   后 4 → [5,6,7,1,2,3,4] ✓
// ⚠️ 面试追问："为什么三次反转？"
//   数学：反转 = 逆序操作；两次逆序 = 旋转
//   （整体逆序后，分段逆序恢复段内顺序）
```

## 5. 75. 颜色分类

### 5.1 完整实现（三指针）

```java
/**
 * LeetCode 75. 颜色分类（荷兰国旗）
 * 循环不变量：[0,p0) 全 0，[p2,n) 全 2
 */
public void sortColors(int[] nums) {
    int p0 = 0, p2 = nums.length - 1, curr = 0;

    while (curr <= p2) {
        if (nums[curr] == 0) {
            swap(nums, curr, p0);    // 0 到左边
            p0++;
            curr++;                  // ⚠️ 前进（换来的必是 0/1）
        } else if (nums[curr] == 2) {
            swap(nums, curr, p2);    // 2 到右边
            p2--;                    // ⚠️ 不前进（可能还是 2）
        } else {
            curr++;                  // 1 跳过
        }
    }
}
// 推演 [2,0,2,1,1,0]：
//   curr=0(2) 换 p2 → [0,0,2,1,1,2], p2=4（curr 不动）
//   curr=0(0) 换 p0 → [0,0,2,1,1,2], p0=1, curr=1
//   ... → [0,0,1,1,2,2] ✓
// ⚠️ 面试必讲："2 交换后 curr 不前进——
//   换回来的可能是 2，要再检查一次"
```

## 6. 48. 旋转图像

### 6.1 完整实现（转置 + 翻转）

```java
/**
 * LeetCode 48. 旋转图像（顺时针 90°，原地）
 */
public void rotate(int[][] matrix) {
    int n = matrix.length;

    // ① 转置（沿主对角线）
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {    // ⚠️ j 从 i+1
            int tmp = matrix[i][j];
            matrix[i][j] = matrix[j][i];
            matrix[j][i] = tmp;
        }
    }

    // ② 水平翻转（每行左右交换）
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n / 2; j++) {
            int tmp = matrix[i][j];
            matrix[i][j] = matrix[i][n - 1 - j];
            matrix[i][n - 1 - j] = tmp;
        }
    }
}
// 推演 3×3：
//   原始:     转置后:     水平翻转后:
//   1 2 3     1 4 7       7 4 1
//   4 5 6  →  2 5 8   →   8 5 2
//   7 8 9     3 6 9       9 6 3
//                        = 顺时针 90° ✓
// ⚠️ 面试必答："90° = 转置 + 水平翻转（数学推导）"
```

## 7. 54. 螺旋矩阵

### 7.1 完整实现（四边界）

```java
/**
 * LeetCode 54. 螺旋矩阵
 */
public List<Integer> spiralOrder(int[][] matrix) {
    List<Integer> result = new ArrayList<>();
    int top = 0, bottom = matrix.length - 1;
    int left = 0, right = matrix[0].length - 1;

    while (top <= bottom && left <= right) {
        for (int j = left; j <= right; j++)      // 上边 →
            result.add(matrix[top][j]);
        top++;

        for (int i = top; i <= bottom; i++)      // 右边 ↓
            result.add(matrix[i][right]);
        right--;

        if (top > bottom || left > right) break; // ⚠️ 单行/列防重复！

        for (int j = right; j >= left; j--)      // 下边 ←
            result.add(matrix[bottom][j]);
        bottom--;

        for (int i = bottom; i >= top; i--)      // 左边 ↑
            result.add(matrix[i][left]);
        left++;
    }
    return result;
}
// 推演 3×3：1,2,3 → 6,9 → 8,7 → 4 → 5 ✓
// ⚠️ 为什么单行/列要 break？
//   走完上边和右边后，只剩一行 → 下边会重复添加
// ⚠️ 变体：59 螺旋矩阵 II（填充方向切换）
```

## 8. 238. 除自身以外数组的乘积

### 8.1 完整实现（前后缀积）

```java
/**
 * LeetCode 238. 除自身以外数组的乘积
 * 要求：不能用除法！O(n) 时间
 * 两次遍历：左边乘积 × 右边乘积
 */
public int[] productExceptSelf(int[] nums) {
    int n = nums.length;
    int[] answer = new int[n];

    // ① 左边乘积
    answer[0] = 1;
    for (int i = 1; i < n; i++) {
        answer[i] = answer[i - 1] * nums[i - 1];
    }

    // ② 右边乘积（从右往左）
    int rightProduct = 1;
    for (int i = n - 1; i >= 0; i--) {
        answer[i] *= rightProduct;
        rightProduct *= nums[i];
    }
    return answer;
}
// 推演 [1,2,3,4]：
//   ① answer=[1,1,2,6]
//   ② i=3: 6×1=6, rp=4；i=2: 2×4=8, rp=12
//     i=1: 1×12=12, rp=24；i=0: 1×24=24 → [24,12,8,6] ✓
// ⚠️ 面试追问："为什么不能用除法？"
//   ① 可能有 0（除零）
//   ② 题目考察"前后缀积"思想
```

## 9. 73. 矩阵置零

### 9.1 完整实现（首行首列标记）

```java
/**
 * LeetCode 73. 矩阵置零（O(1) 空间）
 */
public void setZeroes(int[][] matrix) {
    int m = matrix.length, n = matrix[0].length;
    boolean firstRowZero = false, firstColZero = false;

    // ① 记录首行首列本身
    for (int j = 0; j < n; j++) if (matrix[0][j] == 0) firstRowZero = true;
    for (int i = 0; i < m; i++) if (matrix[i][0] == 0) firstColZero = true;

    // ② 用首行首列标记
    for (int i = 1; i < m; i++)
        for (int j = 1; j < n; j++)
            if (matrix[i][j] == 0) {
                matrix[i][0] = 0;    // 标记第 i 行
                matrix[0][j] = 0;    // 标记第 j 列
            }

    // ③ 根据标记置零
    for (int i = 1; i < m; i++)
        for (int j = 1; j < n; j++)
            if (matrix[i][0] == 0 || matrix[0][j] == 0)
                matrix[i][j] = 0;

    // ④ 处理首行首列
    if (firstRowZero) Arrays.fill(matrix[0], 0);
    if (firstColZero) for (int i = 0; i < m; i++) matrix[i][0] = 0;
}
// ⚠️ 为什么不能边扫边改？
//   已置 0 的行影响后续判断（连锁反应）
//   → 先标记再统一置 0（标记法核心思想）
```

## 10. 88. 合并两个有序数组

### 10.1 完整实现（反向指针）

```java
/**
 * LeetCode 88. 合并两个有序数组
 * ⚠️ 从后往前填（避免覆盖 nums1 前部）
 */
public void merge(int[] nums1, int m, int[] nums2, int n) {
    int p1 = m - 1;              // nums1 有效区末尾
    int p2 = n - 1;              // nums2 末尾
    int p = m + n - 1;           // 填充位置

    while (p2 >= 0) {
        if (p1 >= 0 && nums1[p1] > nums2[p2]) {
            nums1[p--] = nums1[p1--];
        } else {
            nums1[p--] = nums2[p2--];
        }
    }
}
// 推演 nums1=[1,2,3,0,0,0], m=3, nums2=[2,5,6]：
//   p1=2(3) vs p2=2(6) → 6 → nums1[5]=6
//   p1=2(3) vs p2=1(5) → 5 → nums1[4]=5
//   p1=2(3) vs p2=0(2) → 3 → nums1[3]=3
//   p1=1(2) vs p2=0(2) → 2 → nums1[2]=2
//   p1=0(1) vs p2=0(2) → 2 → nums1[1]=2
//   p2 耗尽 → nums1[0]=1 → [1,2,2,3,5,6] ✓
// ⚠️ 面试必答："从后往前避免覆盖——合并有序经典技巧"
```

## 11. 15. 三数之和

### 11.1 完整实现（排序 + 固定 + 双指针）

```java
/**
 * LeetCode 15. 三数之和（Hot 100 高频）
 * 三步：排序 → 固定一个 → 双指针找两数
 * 去重三处（核心易错点）
 */
public List<List<Integer>> threeSum(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    Arrays.sort(nums);                       // ① 排序

    for (int i = 0; i < nums.length - 2; i++) {
        if (nums[i] > 0) break;              // 剪枝：正数后面更大
        if (i > 0 && nums[i] == nums[i - 1]) continue;   // ② 固定数去重

        int left = i + 1, right = nums.length - 1;
        int target = -nums[i];

        while (left < right) {
            int sum = nums[left] + nums[right];
            if (sum == target) {
                res.add(Arrays.asList(nums[i], nums[left], nums[right]));
                // ③ 左右去重
                while (left < right && nums[left] == nums[left + 1]) left++;
                while (left < right && nums[right] == nums[right - 1]) right--;
                left++;
                right--;
            } else if (sum < target) {
                left++;
            } else {
                right--;
            }
        }
    }
    return res;
}
// 推演 [-1,0,1,2,-1,-4] → 排序 [-4,-1,-1,0,1,2]
//   固定 -1：双指针找 1 → [-1,-1,2] 和 [-1,0,1]
//   固定 0：双指针找 0 → [0,0,0]？不，只有 [0,1,-1] 重复 → 去重
//   结果 [[-1,-1,2],[-1,0,1]] ✓
// ⚠️ 去重三处缺一不可！
// ⚠️ 复杂度 O(n²)：排序 O(n log n) + 固定 O(n) × 双指针 O(n)
```

## 12. 42. 接雨水

### 12.1 双指针版（O(1) 空间）

```java
/**
 * LeetCode 42. 接雨水（经典 Hard）
 * 接水量 = min(左最高, 右最高) - 当前高度
 *
 * 双指针：维护 leftMax/rightMax，矮边确定
 */
public int trap(int[] height) {
    int left = 0, right = height.length - 1;
    int leftMax = 0, rightMax = 0;
    int water = 0;

    while (left < right) {
        leftMax = Math.max(leftMax, height[left]);
        rightMax = Math.max(rightMax, height[right]);

        if (leftMax < rightMax) {
            // 左边能确定：右边最高 ≥ rightMax > leftMax
            water += leftMax - height[left];
            left++;
        } else {
            water += rightMax - height[right];
            right--;
        }
    }
    return water;
}
// 推演 [0,1,0,2,1,0,1,3,2,1,2,1] → 6 ✓
// ⚠️ 为什么矮边能确定？
//   位置 left 的接水量 = min(左最高, 右边某个值) - height[left]
//   右边最大值 ≥ rightMax > leftMax → 确定 = leftMax - height[left]
// ⚠️ 三解法对比：
//   暴力 O(n²)/O(1)；DP O(n)/O(n)；双指针 O(n)/O(1) ★
```
