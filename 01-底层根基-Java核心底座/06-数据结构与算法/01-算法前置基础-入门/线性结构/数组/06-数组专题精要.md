## 1. 核心概念

### 1.1 数组的本质

```
连续内存 + 同类型元素
  O(1) 随机访问（arr[i] 直接寻址）
  O(n) 插入/删除（需移动元素）
  容量固定（Java 数组不可变长）

缓存友好（连续）→ 实际性能优于链表
（ArrayList 几乎总比 LinkedList 快）

⚠️ 寻址公式：arr[i] = base + i × 元素大小
  → 这就是 O(1) 随机访问的原理
```

### 1.2 识别信号

```
"数组" 标签 → 覆盖 Hot 100 约 20%
"找两数/三数" → 哈希/双指针
"连续子数组" → 滑窗/前缀和
"原地修改" → 快慢/交换
"有序数组" → 双指针/二分

⚠️ 数组题第一反应清单：
  有序 → 双指针/二分
  连续子数组 → 滑窗/前缀和
  找配对 → 哈希
  原地 → 覆盖/交换/反转
```

### 1.3 数组 vs 链表

| 维度 | 数组 | 链表 |
|------|:---:|:---:|
| 随机访问 | O(1) | O(n) |
| 头部增删 | O(n) | O(1) |
| 缓存 | 友好 | 差 |
| 大小 | 固定 | 动态 |

```
⚠️ 面试表达：
"数组缓存友好（连续内存），
 频繁随机访问选数组；
 频繁头部增删选链表。"
```

## 2. 完整代码模板

### 2.1 27. 移除元素（快慢覆盖）

```java
/**
 * LeetCode 27. 移除元素（快慢指针模板）
 * slow 慢写（下一个保留位置），fast 快读（扫描）
 */
public int removeElement(int[] nums, int val) {
    int slow = 0;
    for (int fast = 0; fast < nums.length; fast++) {
        if (nums[fast] != val) {
            nums[slow++] = nums[fast];   // 保留覆盖
        }
    }
    return slow;                         // 新长度
}
// O(n) 时间 O(1) 空间
// 推演 [3,2,2,3], val=3：
//   fast=1(2) → nums[0]=2, slow=1
//   fast=2(2) → nums[1]=2, slow=2 → 返回 2 ✓

// 变体家族（同一模板不同保留条件）：
//   26 去重：nums[fast] != nums[slow-1]
//   80 去重 II：nums[fast] != nums[slow-k]（k=2）
//   283 移动零：!= 0 + 末尾补零
```

### 2.2 189. 旋转数组（三次反转）

```java
/**
 * LeetCode 189. 旋转数组（原地 O(1) 空间）
 * 三次反转技巧：
 *   ① 整体反转 → ② 前 k 反转 → ③ 后 n-k 反转
 */
public void rotate(int[] nums, int k) {
    int n = nums.length;
    k %= n;                                // ⚠️ k 可能 > n！
    reverse(nums, 0, n - 1);               // ① 整体
    reverse(nums, 0, k - 1);               // ② 前 k
    reverse(nums, k, n - 1);               // ③ 后 n-k
}

private void reverse(int[] arr, int lo, int hi) {
    while (lo < hi) {
        int tmp = arr[lo]; arr[lo] = arr[hi]; arr[hi] = tmp;
        lo++; hi--;
    }
}
// 推演 [1,2,3,4,5,6,7], k=3：
//   整体反转 → [7,6,5,4,3,2,1]
//   前 3 反转 → [5,6,7,4,3,2,1]
//   后 4 反转 → [5,6,7,1,2,3,4] ✓
// ⚠️ 记忆："整体反转 → 前 k → 后 n-k"
```

### 2.3 238. 除自身以外数组的乘积

```java
/**
 * LeetCode 238. 除自身以外数组的乘积（不用除法）
 * 两次遍历：左边乘积 × 右边乘积
 */
public int[] productExceptSelf(int[] nums) {
    int n = nums.length;
    int[] answer = new int[n];

    // ① 左边乘积：answer[i] = nums[0..i-1] 的乘积
    answer[0] = 1;                    // 最左边没有元素 → 1
    for (int i = 1; i < n; i++) {
        answer[i] = answer[i - 1] * nums[i - 1];
    }

    // ② 右边乘积：从右往左累乘
    int rightProduct = 1;
    for (int i = n - 1; i >= 0; i--) {
        answer[i] *= rightProduct;    // 左边积 × 右边积
        rightProduct *= nums[i];      // 更新右边积
    }
    return answer;
}
// O(n) 时间 O(1) 空间（不含结果数组）
// 推演 [1,2,3,4]：
//   ① answer=[1,1,2,6]
//   ② i=3: 6×1=6, rp=4；i=2: 2×4=8, rp=12
//     i=1: 1×12=12, rp=24；i=0: 1×24=24 → [24,12,8,6] ✓
```

## 3. 数组技巧体系

### 3.1 六大技巧总览

```
① 双指针：对撞（167/11）/ 快慢（27/283）
② 滑动窗口：连续子数组最优（3/76）
③ 前缀和：区间和 O(1)（560）
④ 原地算法：O(1) 空间修改（48/75/189）
⑤ 哈希辅助：空间换时间（1 两数之和）
⑥ 二分：有序数组 O(log n)（33/153）

⚠️ 第一反应映射：
  有序 → 双指针/二分
  连续子数组 → 滑窗/前缀和
  找两数/存在 → 哈希
  原地 → 快慢覆盖/交换
```

### 3.2 原地算法的常用手法

```
① 快慢覆盖（27/283）：fast 读 slow 写
② 交换（75 三指针）：荷兰国旗
③ 三次反转（189）：旋转数组
④ 转置+翻转（48）：旋转图像
⑤ 标记法（73）：首行首列标记

⚠️ 识别信号：
  "原地/O(1) 额外空间" 关键词
  → 覆盖/交换/反转/标记
```

### 3.3 75. 颜色分类（三指针）

```java
/**
 * LeetCode 75. 颜色分类（荷兰国旗）
 * p0 管 0 边界、p2 管 2 边界、curr 扫描
 */
public void sortColors(int[] nums) {
    int p0 = 0, p2 = nums.length - 1, curr = 0;

    while (curr <= p2) {
        if (nums[curr] == 0) {
            swap(nums, curr, p0);    // 0 交换到左边
            p0++;
            curr++;                  // ⚠️ curr 前进（换来的必是 0/1）
        } else if (nums[curr] == 2) {
            swap(nums, curr, p2);    // 2 交换到右边
            p2--;                    // ⚠️ curr 不前进（换来的可能还是 2）
        } else {
            curr++;                  // 1 直接跳过
        }
    }
}
// ⚠️ 面试必讲："2 交换后 curr 不前进——
//   换回来的可能是 0/1/2，要再检查一次"
```

## 4. 边界处理详解

### 4.1 三大边界坑

```
① 空数组：arr[0] 越界
   → if (arr.length == 0) 前置

② 单元素：循环边界
   → 特判 n == 1

③ k 取模：旋转 k > n
   → k %= n

⚠️ 手写后自检三个用例：
  空数组 / 单元素 / 全相同
```

### 4.2 二维数组的边界

```
m = matrix.length（行数）
n = matrix[0].length（列数）

⚠️ 空矩阵：m == 0 或 n == 0
  matrix[0] 可能越界！

遍历顺序：先行后列（row-major，缓存友好）
```

### 4.3 溢出与类型

```
前缀和/乘积可能溢出 → long
组合数 → 先除后乘

⚠️ 面试表达：
"中间结果可能超 int，我用 long
 或先取模，最后再转回 int。"
```

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 忘 k%n | 越界 | 取模 |
| slow 语义混淆 | 结果错 | 明确"写入位" |
| 三指针方向错 | 排序错 | curr 前进规则 |
| 前缀和溢出 | 结果错 | long |
| 忘空数组 | 越界 | 前置判断 |
