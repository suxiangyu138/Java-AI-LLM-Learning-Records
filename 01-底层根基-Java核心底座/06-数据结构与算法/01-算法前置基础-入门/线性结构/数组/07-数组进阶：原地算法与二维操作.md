## 1. 原地算法的完整体系

### 1.1 什么是原地算法

```
原地算法（In-place）：O(1) 额外空间修改数组
  不申请与 n 成比例的额外数组
  面试加分点：空间从 O(n) → O(1)

⚠️ 识别信号：
  "原地修改" / "O(1) 额外空间" / "不使用额外数组"
  → 原地算法
```

### 1.2 五种原地手法

| 手法 | 原理 | 代表题 |
|------|------|:---:|
| 快慢覆盖 | fast 读 slow 写 | 27/283 |
| 交换 | 三指针分区 | 75 |
| 三次反转 | 数学变换 | 189 |
| 转置+翻转 | 线性变换 | 48 |
| 标记法 | 首行首列做标记 | 73 |

```
⚠️ 面试表达：
"这题要求 O(1) 空间 → 原地算法。
 我用【快慢覆盖/交换/反转/标记】手法：
 【原理简述】。"
```

### 1.3 原地 vs 额外空间的选型

```
原地：O(1) 空间，代码稍复杂
额外数组：O(n) 空间，代码简单

⚠️ 题目要求 O(1) → 原地
   题目没要求 → 先写简单版（正确性优先）
   面试官要求优化 → 展示原地版（加分）

⚠️ 面试表达：
"我先写 O(n) 空间的直观版，
 再优化到 O(1) 原地版。
 原地的关键：【手法原理】。"
```

## 2. 五种原地手法详解

### 2.1 手法一：快慢覆盖

```java
/**
 * 快慢覆盖：fast 读（扫描），slow 写（保留位置）
 * 适用：原地去重/移除/移动
 */
public int removeElement(int[] nums, int val) {
    int slow = 0;
    for (int fast = 0; fast < nums.length; fast++) {
        if (nums[fast] != val) {
            nums[slow++] = nums[fast];   // 保留覆盖
        }
    }
    return slow;
}
// 变体家族（同一模板不同保留条件）：
//   26 去重：nums[fast] != nums[slow-1]
//   80 去重 II：nums[fast] != nums[slow-k]（k=2）
//   283 移动零：!= 0 + 末尾补零
// ⚠️ 记忆："快读慢写，保留条件不同"
```

### 2.2 手法二：交换（三指针）

```java
/**
 * 75. 颜色分类（荷兰国旗）
 * p0 管 0 边界、p2 管 2 边界、curr 扫描
 * 循环不变量：
 *   [0, p0) 全是 0，[p2, n) 全是 2
 */
public void sortColors(int[] nums) {
    int p0 = 0, p2 = nums.length - 1, curr = 0;

    while (curr <= p2) {
        if (nums[curr] == 0) {
            swap(nums, curr, p0);    // 0 到左边
            p0++;
            curr++;                  // ⚠️ 前进（换来的必是 0/1）
        } else if (nums[curr] == 2) {
            swap(nums, curr, p2);    // 2 到右边
            p2--;                    // ⚠️ 不前进（可能还是 2）
        } else {
            curr++;                  // 1 跳过
        }
    }
}
// ⚠️ 面试必讲："2 交换后 curr 不前进——
//   换回来的可能还是 2，要再检查一次"
// 应用：三路快排的数组版（见排序专题）
```

### 2.3 手法三：三次反转

```java
/**
 * 189. 旋转数组（原地 O(1) 空间）
 * 数学技巧：整体反转 → 前 k 反转 → 后 n-k 反转
 */
public void rotate(int[] nums, int k) {
    int n = nums.length;
    k %= n;                                // ⚠️ k 可能 > n
    reverse(nums, 0, n - 1);               // ① 整体
    reverse(nums, 0, k - 1);               // ② 前 k
    reverse(nums, k, n - 1);               // ③ 后 n-k
}

private void reverse(int[] arr, int lo, int hi) {
    while (lo < hi) {
        int tmp = arr[lo]; arr[lo] = arr[hi]; arr[hi] = tmp;
        lo++; hi--;
    }
}
// 推演 [1,2,3,4,5,6,7], k=3：
//   整体反转 → [7,6,5,4,3,2,1]
//   前 3 反转 → [5,6,7,4,3,2,1]
//   后 4 反转 → [5,6,7,1,2,3,4] ✓
// ⚠️ 记忆："整体反转 → 前 k → 后 n-k"
```

### 2.4 手法四：转置+翻转

```java
/**
 * 48. 旋转图像（顺时针 90°，原地）
 * 数学：90° = 转置 + 水平翻转
 */
public void rotate(int[][] matrix) {
    int n = matrix.length;

    // ① 转置（沿主对角线）
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {    // ⚠️ j 从 i+1
            int tmp = matrix[i][j];
            matrix[i][j] = matrix[j][i];
            matrix[j][i] = tmp;
        }
    }

    // ② 水平翻转（每行左右交换）
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n / 2; j++) {
            int tmp = matrix[i][j];
            matrix[i][j] = matrix[i][n - 1 - j];
            matrix[i][n - 1 - j] = tmp;
        }
    }
}
// ⚠️ 组合记忆：
//   顺时针 90° = 转置 + 水平翻转
//   逆时针 90° = 转置 + 垂直翻转
//   旋转 180° = 水平 + 垂直
```

### 2.5 手法五：标记法

```java
/**
 * 73. 矩阵置零（O(1) 空间）
 * 用首行首列做标记（不能边扫边改！）
 */
public void setZeroes(int[][] matrix) {
    int m = matrix.length, n = matrix[0].length;
    boolean firstRowZero = false, firstColZero = false;

    // ① 记录首行首列本身
    for (int j = 0; j < n; j++) if (matrix[0][j] == 0) firstRowZero = true;
    for (int i = 0; i < m; i++) if (matrix[i][0] == 0) firstColZero = true;

    // ② 用首行首列标记其他行列
    for (int i = 1; i < m; i++)
        for (int j = 1; j < n; j++)
            if (matrix[i][j] == 0) {
                matrix[i][0] = 0;    // 标记第 i 行
                matrix[0][j] = 0;    // 标记第 j 列
            }

    // ③ 根据标记置零
    for (int i = 1; i < m; i++)
        for (int j = 1; j < n; j++)
            if (matrix[i][0] == 0 || matrix[0][j] == 0)
                matrix[i][j] = 0;

    // ④ 处理首行首列本身
    if (firstRowZero) Arrays.fill(matrix[0], 0);
    if (firstColZero) for (int i = 0; i < m; i++) matrix[i][0] = 0;
}
// ⚠️ 为什么不能边扫边改？
//   已置 0 的行影响后续判断（连锁反应）
//   → 先标记再统一置 0
```

## 3. 二维数组的操作艺术

### 3.1 下标规律速查

```
转置：matrix[i][j] ↔ matrix[j][i]
水平翻转：matrix[i][j] ↔ matrix[i][n-1-j]
垂直翻转：matrix[i][j] ↔ matrix[m-1-i][j]

对角线：
  主对角线（↘）：i - j 为常数
  副对角线（↙）：i + j 为常数

⚠️ 行列习惯：
  m = matrix.length（行数）
  n = matrix[0].length（列数）
  matrix[i][j]：i 行 j 列
```

### 3.2 螺旋矩阵（四边界模拟）

```java
/**
 * 54. 螺旋矩阵
 * 四边界收缩：top/bottom/left/right
 */
public List<Integer> spiralOrder(int[][] matrix) {
    List<Integer> result = new ArrayList<>();
    int top = 0, bottom = matrix.length - 1;
    int left = 0, right = matrix[0].length - 1;

    while (top <= bottom && left <= right) {
        for (int j = left; j <= right; j++)      // 上边 →
            result.add(matrix[top][j]);
        top++;

        for (int i = top; i <= bottom; i++)      // 右边 ↓
            result.add(matrix[i][right]);
        right--;

        if (top > bottom || left > right) break; // ⚠️ 单行/列防重复！

        for (int j = right; j >= left; j--)      // 下边 ←
            result.add(matrix[bottom][j]);
        bottom--;

        for (int i = bottom; i >= top; i--)      // 左边 ↑
            result.add(matrix[i][left]);
        left++;
    }
    return result;
}
// ⚠️ 为什么单行/列要 break？
//   走完上边和右边后，只剩一行 → 下边会重复添加
```

### 3.3 矩阵搜索技巧

```
74 展平二分：idx → (idx/n, idx%n)
240 右上角走法：大左移小下移（O(m+n)）
498 对角线遍历：i±j 常数规律

⚠️ 识别：
  "行升序+列升序" → 右上角走法（二叉搜索树思想）
  "行首 > 前行尾" → 展平二分
```

### 4.2 88. 合并有序数组（反向指针）

```java
/**
 * LeetCode 88. 合并两个有序数组
 * ⚠️ 从后往前填（避免覆盖 nums1 前部）
 */
public void merge(int[] nums1, int m, int[] nums2, int n) {
    int p1 = m - 1;              // nums1 有效区末尾
    int p2 = n - 1;              // nums2 末尾
    int p = m + n - 1;           // 填充位置（从后往前）

    while (p2 >= 0) {            // nums2 还有元素
        if (p1 >= 0 && nums1[p1] > nums2[p2]) {
            nums1[p--] = nums1[p1--];
        } else {
            nums1[p--] = nums2[p2--];
        }
    }
}
// 为什么从后往前？
//   从前往后会覆盖 nums1 前部未合并的有效元素
//   后部是 0 填充区 → 安全
// ⚠️ 面试必答："反向填充避免覆盖——合并有序的经典技巧"
```

### 4.3 238. 除自身以外数组的乘积

```java
/**
 * LeetCode 238. 除自身以外数组的乘积（不用除法）
 * 两次遍历：左边乘积 × 右边乘积
 */
public int[] productExceptSelf(int[] nums) {
    int n = nums.length;
    int[] answer = new int[n];

    // ① 左边乘积
    answer[0] = 1;
    for (int i = 1; i < n; i++) {
        answer[i] = answer[i - 1] * nums[i - 1];
    }

    // ② 右边乘积（从右往左累乘）
    int rightProduct = 1;
    for (int i = n - 1; i >= 0; i--) {
        answer[i] *= rightProduct;
        rightProduct *= nums[i];
    }
    return answer;
}
// O(n) 时间 O(1) 空间（不含结果数组）
// ⚠️ 面试追问："为什么不能用除法？"
//   ① 可能有 0（除零）
//   ② 题目可能明确要求（考察前缀积思想）
```

## 5. 边界与溢出的艺术

### 5.1 三大边界坑

```
① 空数组：arr[0] 越界
   → if (arr.length == 0) 前置

② 单元素：循环边界
   → 特判 n == 1

③ k 取模：旋转 k > n
   → k %= n

⚠️ 手写后自检三个用例：
  空数组 / 单元素 / 全相同
```

### 5.2 溢出防护

```
① 前缀和/乘积：long 或先取模
② 组合数：先除后乘
③ 快选/二分：left + (right-left)/2

⚠️ 识别：
  "乘积/求和/坐标相乘" → 检查溢出
```

### 5.3 数组题自检清单

```
□ 空数组 / 空矩阵
□ 单元素 / 单行单列
□ 全相同元素
□ 负数 / 最大值
□ 取模（k %= n）
□ 溢出（long）
```

### 6.3 易错点清单

| 错误 | 后果 | 修正 |
|------|------|------|
