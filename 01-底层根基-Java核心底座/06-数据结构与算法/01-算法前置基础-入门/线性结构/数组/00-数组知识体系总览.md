## 3. 学习路线推荐

### 🟢 路线 A：零基础入门（1 周）
```
01 数组基础 → 1 两数之和 → 217 重复元素 → 242 异位词
→ 283 移动零 → 66 加一 → 88 合并有序数组
```
- **目标**：掌握数组遍历与哈希表基本用法
- **题量**：约 10 题

### 🟡 路线 B：面试冲刺（1-2 周）
```
01-02 快速过 → 03 哈希经典全部（6题）
→ 04 数组技巧全部（6题）→ 05 高频复盘
```
- **目标**：Hot 100 数组/哈希全覆盖，暴力→优化脱口而出
- **题量**：约 20-25 题

### 🔴 路线 C：全面掌握（2-3 周）
```
完整 01→05 + HashMap 源码深读（put/get/扩容/红黑树）
→ 380 LRU 设计题 + 146 LRU 缓存
→ 前缀和+哈希组合（560/974/523）
→ 原地算法专项（73 矩阵置零/189 旋转数组）
```
- **目标**：原理 + 代码 + 设计题全通关
- **题量**：约 30 题

## 4. 核心概念速查

| 概念 | 一句话解释 | 典型例题 |
|------|-----------|------|
| **哈希表元模式** | 用哈希查找替换内层循环 → O(n²)→O(n) | 1. 两数之和 |
| **补数查找** | 查 target - nums[i] 是否在哈希表中 | 1/167 |
| **先查后插** | 先查补数再插入自身，避免自匹配 | 1. 两数之和 |
| **排序键** | 异位词排序后相同 → 做键 | 49 |
| **计数键** | 26 字符计数数组做键（更高效） | 49 优化版 |
| **起点剪枝** | `!set.contains(num-1)` 才作为序列起点 | 128 |
| **前缀和+哈希** | `prefix[j] - prefix[i] = k` 用哈希记录 | 560 |
| **荷兰国旗** | 三指针原地分区（0/1/2） | 75 |
| **转置+翻转** | 旋转 90° = 转置 + 水平翻转 | 48 |
| **前后缀积** | 左边乘积 × 右边乘积（不用除法） | 238 |
| **尾删换顶** | 删除时末尾元素补位 → O(1) | 380 |
| **负载因子** | 元素数/容量，超 0.75 扩容 | HashMap 原理 |
| **红黑树化** | 链表长度 > 8 → 红黑树 | HashMap 原理 |
