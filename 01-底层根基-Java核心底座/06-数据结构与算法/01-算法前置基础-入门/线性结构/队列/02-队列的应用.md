## 1. BFS 层序引擎

**BFS = 队列 + 层序推进**——队列的 FIFO 天然保证「先访问的层先扩散」。

```java
// 102 二叉树的层序遍历：队列 + size 分层
public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) return res;
    Deque<TreeNode> q = new ArrayDeque<>();
    q.offer(root);
    while (!q.isEmpty()) {
        int size = q.size();                   // 本层节点数（关键！）
        List<Integer> level = new ArrayList<>();
        for (int i = 0; i < size; i++) {
            TreeNode node = q.poll();
            level.add(node.val);
            if (node.left != null) q.offer(node.left);
            if (node.right != null) q.offer(node.right);
        }
        res.add(level);
    }
    return res;
}
```

| BFS 应用 | 队列角色 | 典型题 |
|---------|---------|--------|
| 层序遍历 | 逐层推进 | 102/429 |
| 最短步数 | 分层计数 | 1091/127 |
| 多源扩散 | 多起点入队 | 994/542 |
| 拓扑排序 | 入度队列 | 207（图经典算法目录） |

> 💡 **size 分层的本质**：`size = q.size()` 在每轮开始时固定——**处理的是「同一层」的节点**，步数/层数计数就准确；完整 BFS 见[图的遍历](../../图结构/图的遍历/02-BFS广度优先搜索.md)。

## 2. 滑动窗口

**滑动窗口**：定长窗口在序列上滑动，窗口内统计/最值——队列是窗口的天然载体。

```java
// 643 子数组最大平均数（定长窗口基础版）
public double findMaxAverage(int[] nums, int k) {
    double sum = 0;
    for (int i = 0; i < k; i++) sum += nums[i];     // 初始窗口
    double max = sum;
    for (int i = k; i < nums.length; i++) {
        sum += nums[i] - nums[i - k];               // 滑入滑出
        max = Math.max(max, sum);
    }
    return max / k;
}
```

| 窗口类型 | 队列使用 | 典型题 |
|---------|---------|--------|
| 定长窗口 | 下标队列 | 643/239 |
| 不定长窗口 | 双指针（非队列） | 3/76 |
| 窗口最值 | **单调队列** | 239（下节） |

> 💡 滑动窗口的三种形态：定长（队列/滑入滑出）、不定长（双指针伸缩）、最值（单调队列）——「窗口 + 队列」是定长场景的标准组合。

## 3. 单调队列

**单调队列**：队列内值单调（如递减）——队头是窗口最值，O(n) 完成窗口最值问题（暴力 O(nk)）。

```java
// 239 滑动窗口最大值：单调递减队列
public int[] maxSlidingWindow(int[] nums, int k) {
    int n = nums.length;
    int[] res = new int[n - k + 1];
    Deque<Integer> deque = new ArrayDeque<>();       // 存下标（值单调递减）

    for (int i = 0; i < n; i++) {
        // ① 移除队尾「小于当前值」的（它们永不会是窗口最大）
        while (!deque.isEmpty() && nums[deque.peekLast()] <= nums[i]) {
            deque.pollLast();
        }
        deque.offerLast(i);                          // 当前下标入队

        // ② 移除窗口外的队头（过期下标）
        while (!deque.isEmpty() && deque.peekFirst() <= i - k) {
            deque.pollFirst();
        }

        // ③ 窗口满时，队头 = 最大值
        if (i >= k - 1) {
            res[i - k + 1] = nums[deque.peekFirst()];
        }
    }
    return res;
}
```

**单调队列三步**：

```text
① 入队前清理: 队尾小于当前值的弹出（保单调）
② 入队:       当前下标入队尾
③ 出队清理:   队头过期（< i-k+1）弹出
④ 取答案:     队头 = 窗口最值
```

| 对比 | 暴力 | 单调队列 |
|------|:---:|:---:|
| 复杂度 | O(nk) | **O(n)** |
| 空间 | O(1) | O(k) |
| 每个元素 | 重复比较 k 次 | 入队出队各一次 |
| 适用 | — | 窗口最值/最值滑动 |

> 🎯 **单调队列识别信号**：「滑动窗口 + 最大值/最小值」→ 239 题模板直接套；与单调栈（[栈体系](../栈/00-栈知识体系总览.md)）思想同源（维护单调性），一个管窗口、一个管邻近。

## 4. 阻塞队列与并发

**阻塞队列（BlockingQueue）**：线程安全的队列——满了阻塞生产者、空了阻塞消费者（生产者消费者模型）。

```java
// 生产者消费者（阻塞队列版）
BlockingQueue<Task> queue = new ArrayBlockingQueue<>(100);

// 生产者线程
class Producer implements Runnable {
    public void run() {
        while (true) {
            queue.put(new Task());           // 满则阻塞
        }
    }
}

// 消费者线程
class Consumer implements Runnable {
    public void run() {
        while (true) {
            Task task = queue.take();        // 空则阻塞
            task.execute();
        }
    }
}
```

| 阻塞队列 | 特性 | 场景 |
|---------|------|------|
| ArrayBlockingQueue | 有界数组 | 固定容量 |
| LinkedBlockingQueue | 可选有界链表 | 默认无界 |
| PriorityBlockingQueue | 优先级 | 任务调度 |
| SynchronousQueue | 直接交接 | 无缓冲 |

> 💡 **工程版图**：线程池的任务队列（ThreadPoolExecutor 用 BlockingQueue）、消息中间件的内存缓冲——「队列 = 解耦 + 缓冲」是并发设计的第一课。

### 5.1 队列应用速记卡

```text
层序/最短步数  → BFS（队列 + size 分层）
窗口定长统计  → 滑入滑出（O(1) 更新）
窗口最值      → 单调队列（O(n)）
并发解耦缓冲  → BlockingQueue
```

### 5.2 单调队列与单调栈对比

| 对比 | 单调队列 | 单调栈 |
|------|:---:|:---:|
| 结构 | 队列（双端） | 栈 |
| 维护对象 | 窗口最值 | 邻近更大/更小 |
| 典型题 | 239 窗口最大值 | 739 每日温度 |
| 过期处理 | 队头弹出 | 无（不滑动） |
| 单调方向 | 递减（最大）/递增（最小） | 递减/递增 |

> 🎯 **核心要点**：应用验收——BFS 层序（size 分层）与单调队列（239 三清理步骤）两模板默写；识别信号「层序/最短」→ BFS、「窗口最值」→ 单调队列、「并发解耦」→ 阻塞队列；单调队列与单调栈的「窗口 vs 邻近」区别是面试高频对比；完整 BFS 见[图的遍历](../../图结构/图的遍历/02-BFS广度优先搜索.md)。
