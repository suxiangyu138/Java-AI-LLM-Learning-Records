## 1. FIFO 原理

**队列（Queue）**：先进先出（First In First Out）——队尾入队、队头出队。

```text
入队:  1 → 2 → 3
       队尾 ← 3 2 1 → 队头

出队:  poll() → 1（先进先出！）

操作:  offer(x) 队尾入队
      poll()   队头出队
      peek()   查看队头
```

| 对比 | 队列 | 栈 |
|------|:---:|:---:|
| 顺序 | **FIFO** | LIFO |
| 操作端 | 头出尾进 | 同一端 |
| 应用 | BFS/缓冲/调度 | DFS/回溯/括号 |
| 类比 | 排队买票 | 叠盘子 |

> 🎯 **识别信号**：「排队/缓冲/按到达顺序处理/BFS 层序」→ 队列；「撤销/递归/括号匹配」→ 栈。

## 2. 数组实现：循环队列

**循环队列**：数组环形复用——tail 绕回头部，解决「出队后头部空间浪费」问题。

```java
// 622 设计循环队列（LeetCode 标准题）
class MyCircularQueue {
    private final int[] data;
    private int front, rear;          // 队头/队尾
    private int size;                 // 当前元素数（简化判空判满）

    public MyCircularQueue(int k) {
        data = new int[k];
        front = 0;
        rear = 0;
        size = 0;
    }

    public boolean enQueue(int value) {        // 入队（队尾）
        if (isFull()) return false;
        data[rear] = value;
        rear = (rear + 1) % data.length;       // 环形前进
        size++;
        return true;
    }

    public boolean deQueue() {                 // 出队（队头）
        if (isEmpty()) return false;
        front = (front + 1) % data.length;     // 环形前进
        size--;
        return true;
    }

    public int Front() { return isEmpty() ? -1 : data[front]; }
    public int Rear() { return isEmpty() ? -1 : data[(rear - 1 + data.length) % data.length]; }
    public boolean isEmpty() { return size == 0; }
    public boolean isFull() { return size == data.length; }
}
```

**两种判满策略**：

| 策略 | 判满条件 | 空间 |
|------|---------|:---:|
| size 计数（本实现） | `size == capacity` | 全用满 |
| 预留一格 | `(rear+1) % n == front` | 浪费 1 格 |

> 💡 **环形下标公式**：`(index + 1) % capacity`——循环队列的核心；面试手写推荐 size 计数版（更直观）。

## 3. 链表实现

链表队列：**头删尾插**（O(1)）——无限长、无环问题。

```java
// 链表队列（头删尾插）
class LinkedQueue {
    private Node head, tail;         // 队头/队尾指针

    static class Node {
        int val;
        Node next;
        Node(int val) { this.val = val; }
    }

    public void offer(int val) {             // 入队：尾插
        Node node = new Node(val);
        if (tail == null) {
            head = tail = node;              // 空队列
        } else {
            tail.next = node;
            tail = node;
        }
    }

    public int poll() {                      // 出队：头删
        if (head == null) return -1;
        int val = head.val;
        head = head.next;
        if (head == null) tail = null;       // 队列空
        return val;
    }

    public int peek() { return head == null ? -1 : head.val; }
    public boolean isEmpty() { return head == null; }
}
```

| 对比 | 循环数组 | 链表 |
|------|:---:|:---:|
| 空间 | 固定容量 | 动态 |
| 判满 | 需要 | 不需要 |
| 缓存友好 | ✅ 连续 | ❌ 跳跃 |
| 实现复杂度 | ★★ | ★★ |
| 适用 | 容量已知 | 动态场景 |

> ⚠️ 链表队列的关键：**tail 指向最后一个节点**（不是 null 前一个）——offer 直接 tail.next 接新节点；poll 后若空要清 tail。

## 4. Java 队列容器

### 4.1 Queue 接口与实现

```java
// Queue 接口（Java）
Queue<Integer> queue = new LinkedList<>();   // 链表实现
// 或推荐：
Deque<Integer> deque = new ArrayDeque<>();   // 数组实现（更快）

// 核心方法
queue.offer(1);          // 入队（推荐，失败返回 false）
queue.poll();            // 出队（空返回 null）
queue.peek();            // 查看队头（空返回 null）
queue.add(1);            // 入队（失败抛异常）
queue.remove();          // 出队（空抛异常）
queue.element();         // 查看（空抛异常）
```

### 4.2 ArrayDeque 双端操作

```java
// ArrayDeque：双端队列（头尾都可操作）
ArrayDeque<Integer> deque = new ArrayDeque<>();

deque.offerLast(1);      // 队尾入
deque.offerFirst(0);     // 队头入
deque.pollFirst();       // 队头出
deque.pollLast();        // 队尾出
deque.peekFirst();
deque.peekLast();

// 单调队列场景：常用 offerLast/pollFirst/peekLast
```

| 方法组 | 失败行为 | 用途 |
|--------|---------|------|
| offer/poll/peek | 返回 false/null | **推荐（判空友好）** |
| add/remove/element | 抛异常 | 断言不空时 |
| offerFirst/pollLast | 双端 | 单调队列/双端需求 |

> 💡 **ArrayDeque 为何推荐**：数组实现（缓存友好）+ 双端操作 + 无 LinkedList 的节点开销——LeetCode 上 `Deque<Integer> q = new ArrayDeque<>()` 是标准写法。

## 5. 复杂度与选型

| 操作 | 循环数组 | 链表 | ArrayDeque |
|------|:---:|:---:|:---:|
| offer | O(1) | O(1) | O(1) 摊还 |
| poll | O(1) | O(1) | O(1) |
| peek | O(1) | O(1) | O(1) |
| 扩容 | 需处理 | 不需要 | 自动 |
| 空间 | O(n) | O(n) + 指针 | O(n) |

**选型口诀**：

```text
LeetCode/单线程 → ArrayDeque（默认）
需要判空语义  → offer/poll/peek（返回 null）
并发场景     → BlockingQueue（02 模块）
容量固定     → 手写循环数组
```

**面试追问**：

| 追问 | 答题要点 |
|------|---------|
| 为什么队列用循环数组？ | 防假溢出（空间复用） |
| 判满有几种写法？ | size 计数 / 预留一格 |
| ArrayDeque 为什么快？ | 数组连续 + 环形 |
| LinkedList 队列的坑？ | 空队列 poll 后 tail 清空 |
| 队列能实现栈吗？ | 能——两队列互相倒 |
| 栈能实现队列吗？ | 能——两栈（入栈+出栈） |

> 🎯 **核心要点**：本节验收——循环队列（622 题）与链表队列模板默写；环形下标公式 `(i+1)%n`；ArrayDeque 双端 API 熟悉；offer/poll/peek（null 语义）vs add/remove（异常语义）的选择；工程默认 ArrayDeque、并发 BlockingQueue（02 模块展开）。
