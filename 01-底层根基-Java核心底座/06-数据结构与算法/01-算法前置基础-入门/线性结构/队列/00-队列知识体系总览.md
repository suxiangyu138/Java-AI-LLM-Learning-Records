## 6. 常见问题 FAQ

| 问题 | 一句话答案 |
|------|-----------|
| 队列和栈的区别？ | 队列 FIFO、栈 LIFO |
| 队列用什么实现？ | 数组（循环）或链表；Java 用 ArrayDeque |
| 循环队列为什么省空间？ | 数组环形复用（浪费 1 格判满） |
| BFS 为什么用队列？ | 层序推进（先入先出天然分层） |
| 滑动窗口最大值用什么？ | 单调队列（O(n)） |
| 单调队列维护什么？ | 窗口内单调递减（队头 = 最大值） |
| 生产环境用什么队列？ | ArrayDeque（单线程）；BlockingQueue（并发） |
| ArrayDeque 和 LinkedList？ | ArrayDeque 更快（数组实现） |
| 队列能栈实现吗？ | 能——双队列/单队列模拟 |
| 阻塞队列有哪些？ | ArrayBlockingQueue/LinkedBlockingQueue |

## 8. 队列 vs 栈 vs 双端队列

| 维度 | 队列 | 栈 | 双端队列 |
|------|:---:|:---:|:---:|
| 顺序 | FIFO | LIFO | 头尾皆可 |
| 操作端 | 头出尾进 | 同端 | 两端 |
| 核心方法 | offer/poll | push/pop | offerFirst/offerLast |
| BFS/层序 | ✅ | ❌ | ✅ |
| 回溯/括号 | ❌ | ✅ | ❌ |
| 单调最值 | ✅ 单调队列 | ✅ 单调栈 | ✅ |
| Java 实现 | ArrayDeque | ArrayDeque/Stack | ArrayDeque |
