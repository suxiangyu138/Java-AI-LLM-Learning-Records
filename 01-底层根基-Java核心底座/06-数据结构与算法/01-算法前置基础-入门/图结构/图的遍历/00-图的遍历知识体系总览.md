## 6. 常见问题 FAQ

| 问题 | 一句话答案 |
|------|-----------|
| DFS 和 BFS 怎么选？ | 最短步数 BFS；连通/路径/判环 DFS |
| visited 什么时候标记？ | 入队/进函数立刻标记（防重复） |
| BFS 为什么能求最短？ | 无权图首次到达即最短 |
| 网格题要建图吗？ | 不用——方向数组（隐藏图） |
| DFS 递归会爆栈吗？ | 深树会——改迭代栈 |
| 多源 BFS 是什么？ | 所有起点同时入队扩散 |
| 判环用什么？ | 有向三色、无向排除父节点 |
| 记忆化 DFS 是什么？ | 返回值 + 缓存（避免重复计算） |
| 沉岛法是什么？ | 网格原地改值当 visited |
| 遍历后学什么？ | 拓扑排序/最短路/生成树 |

## 8. DFS vs BFS 对比总表

| 维度 | DFS | BFS |
|------|:---:|:---:|

| 最短步数 | ❌ | ✅ |
| 判环 | ✅ 三色/父排除 | ✅ 拓扑计数 |
| 路径枚举 | ✅ 回溯 | ❌ |

## 11. 遍历复杂度分析

### 11.1 时间与空间

```text
DFS/BFS 时间: O(V + E)
  每顶点入队/入栈一次、每边访问一次
  邻接表存储下的标准结论

DFS 空间: O(V)（递归栈最深 = 树高/链长）
BFS 空间: O(V)（队列最宽 = 最大层宽）

网格图特例: V = m×n，E ≈ 4mn
  → 网格 DFS/BFS 复杂度 O(m×n)
```

### 11.2 递归 vs 迭代栈

| 对比 | 递归 DFS | 迭代栈 DFS |
|------|:---:|:---:|
| 代码量 | 少 | 中 |
| 栈溢出风险 | 深树会 | 无 |
| 回溯（路径） | 天然 | 需手动 |
| 面试默认 | ✅ | 追问时写 |
