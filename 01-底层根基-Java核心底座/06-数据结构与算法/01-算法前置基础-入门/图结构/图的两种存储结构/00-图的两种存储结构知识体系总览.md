## 6. 常见问题 FAQ

| 问题 | 一句话答案 |
|------|-----------|
| 邻接矩阵什么时候用？ | 稠密图、频繁判边（Floyd）、n ≤ 1000 |
| 邻接表什么时候用？ | 稀疏图（LeetCode 90% 场景） |
| 为什么无向图要双向插入？ | 无向边 (u,v) 双向可达 |
| 邻接矩阵会 MLE 吗？ | n=10⁵ 时矩阵 10¹⁰ 格直接内存爆炸 |
| 网格题要建图吗？ | 不用——方向数组推导邻居（隐藏图） |
| 字符串节点怎么建图？ | Map<String, List<String>> |
| 边集数组有什么用？ | Kruskal 按权重排序、度统计 |
| 邻接表用什么容器？ | List 数组 / ArrayList / LinkedList |
| 带权图怎么存？ | List<int[]> 或 Edge 类 |
| 为什么「三问定存储」？ | 稀疏稠密、判边频率、按权排序 |

## 11. 复杂度对比详解

### 11.1 空间复杂度推导

```text
邻接矩阵: n × n 个格子
  无向图: 可只用上三角（n(n-1)/2），但实现复杂
  有向图: 满 n²（不可省）

邻接表: Σ 每顶点邻居数 = 2m（无向）/ m（有向）
  加上 n 个头指针 → O(V + E)

边集数组: 恰好 E 条边 → O(E)
```

### 11.2 遍历复杂度对比

```text
遍历全图:
  邻接矩阵: 每行扫 n 个 → O(n²)
  邻接表:   每顶点扫其邻居 → O(V + E)

结论: 稀疏图中邻接表遍历快一个量级
      （这就是 BFS/DFS 默认邻接表的原因）
```
