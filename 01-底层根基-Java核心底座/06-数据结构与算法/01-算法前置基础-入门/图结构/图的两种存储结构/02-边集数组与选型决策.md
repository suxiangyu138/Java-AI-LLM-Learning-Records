## 1. 边集数组

```java
// 存所有边：int[] {from, to, weight}
int[][] edges = {{0,1,5}, {1,2,2}, {0,2,3}};

// 按权重排序（Kruskal 最小生成树专用）
Arrays.sort(edges, (a, b) -> a[2] - b[2]);
```

| 场景 | 用途 |
|------|------|
| 最小生成树 Kruskal | 按权排序 + 并查集选边 |
| 简单的度统计 | 遍历 edges 累加 |
| 题目直接给边数组 | 先转邻接表再解题 |

> ⚠️ 边集数组查邻接是 O(E) 全扫——若同时需要「按点遍历」和「按权排序」，先建邻接表做遍历、边数组做排序，两者并存。

**边集数组 + 并查集 = Kruskal**：

```java
// Kruskal 骨架（图经典算法目录详解）
int kruskal(int n, int[][] edges) {
    Arrays.sort(edges, (a, b) -> a[2] - b[2]);   // ① 按权排序
    DSU dsu = new DSU(n);
    int cost = 0, count = 0;
    for (int[] e : edges) {
        if (dsu.union(e[0], e[1])) {             // ② 不连通则选边
            cost += e[2];
            if (++count == n - 1) break;         // ③ n-1 条边完成
        }
    }
    return count == n - 1 ? cost : -1;           // 不连通返回 -1
}
```

## 2. 哈希建图（字符串节点）

题目给 `String[]` 节点（如 `["A", "B", "C"]`）时，数组下标失效——用 `Map<String, List<String>>`：

```java
// 字符串节点建图
Map<String, List<String>> graph = new HashMap<>();
for (String[] pair : pairs) {                    // pair = [from, to]
    graph.computeIfAbsent(pair[0], k -> new ArrayList<>()).add(pair[1]);
    graph.computeIfAbsent(pair[1], k -> new ArrayList<>()).add(pair[0]);  // 无向
}

// 遍历与 visited
Set<String> visited = new HashSet<>();
void dfs(Map<String, List<String>> graph, String node, Set<String> visited) {
    visited.add(node);
    for (String next : graph.getOrDefault(node, List.of())) {
        if (!visited.contains(next)) dfs(graph, next, visited);
    }
}
```

| 维度 | 数组邻接表 | 哈希邻接表 |
|------|:---:|:---:|
| 节点类型 | int（0..n-1） | 任意（String 等） |
| visited | boolean[] | Set\<String\> |
| 建图 | `List<Integer>[]` | `Map<String, List<String>>` |
| 典型题 | 图论标准题 | 单词接龙、并查集字符串 |

> 💡 字符串节点 + 入度统计：`Map<String, Integer> inDegree`——拓扑排序的字符串版（课程表类题偶尔出现）。

## 3. 隐藏图：网格与状态

**隐藏图（Implicit Graph）**：节点与边不显式存储，邻居由**规则推导**——网格题（四方向）、状态转移题（变换规则）都是隐藏图。

```java
// 网格题：方向数组 = 邻接表（200 岛屿数量）
int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};

void dfs(char[][] grid, int x, int y) {
    if (x < 0 || x >= m || y < 0 || y >= n || grid[x][y] != '1') return;
    grid[x][y] = '0';                            // 沉岛（原地 visited）
    for (int[] d : dirs) {
        dfs(grid, x + d[0], y + d[1]);           // 邻居 = 规则推导
    }
}
```

```java
// 状态转移题：变换规则 = 邻接表（127 单词接龙）
// 每个单词是节点，差一个字母的单词相连
for (int j = 0; j < chars.length; j++) {
    char orig = chars[j];
    for (char c = 'a'; c <= 'z'; c++) {
        chars[j] = c;
        String next = new String(chars);         // 「邻居」由规则生成
        if (wordSet.contains(next) && !visited.contains(next)) {
            visited.add(next);
            q.offer(next);
        }
    }
    chars[j] = orig;
}
```

| 隐藏图类型 | 节点 | 邻居推导 | 典型题 |
|-----------|------|---------|--------|
| 网格 | 坐标 (x,y) | 方向数组 | 200/994/1091 |
| 状态 | 状态表示 | 变换规则 | 127/752/433 |
| 位运算 | 数字 | 位操作 | 数独类 |

> 💡 隐藏图的价值：省去显式建图（空间 O(1)），且遍历逻辑与显式图完全一致——**「邻居由规则推导」的思想**让网格/状态题与图论题无缝衔接。

## 4. 存储选型决策树

```text
拿到图题
├── 节点是字符串？ → Map<String, List<String>> 哈希建图
├── 网格/状态推导邻居？ → 隐藏图（方向数组/规则）
├── n 很大（>10⁴）？ → 邻接表（无脑选）
├── 需要 graph[u][v] 快速判边？
│   ├── 是，且 n ≤ 1000 → 邻接矩阵（Floyd/稠密图）
│   └── 否 → 邻接表
├── 需要按边权排序（MST）？ → 额外准备边集数组
└── 默认 → 邻接表（List<Integer>[]）
```

**决策速查卡**：

```text
邻接表  ←  90% 场景（稀疏图默认）
矩阵    ←  判边频繁 + n 小
边集    ←  Kruskal 排序
哈希    ←  字符串节点
隐藏图  ←  网格/状态
```

## 5. 存储面试问答

| 追问 | 答题要点 |
|------|---------|
| 为什么默认邻接表？ | 稀疏图空间 O(V+E)，遍历邻居 O(deg) |
| 邻接矩阵什么时候不可替代？ | Floyd 三重循环判边、稠密图 |
| 无向图建图注意什么？ | 双向插入（防遍历不全） |
| 网格题为什么不用建图？ | 方向数组即邻接表（隐藏图） |
| 带权图怎么存？ | List<int[]> {to, weight} 或 Edge 类 |
| 边集数组和邻接表冲突吗？ | 不冲突——Kruskal 排序 + 遍历两用 |
| 字符串节点 visited 用什么？ | Set\<String\>（不能 boolean[]） |
| 邻接表用数组还是 List<List>？ | 数组式 List<Integer>[] 最快 |
| 邻接矩阵空间多大？ | n² 个格子（n=10⁵ 直接 MLE） |
| 隐藏图的空间优势？ | 免建图（空间 O(1) 额外） |

### 5.1 存储代码速查（面试默写）

```java
// ① 邻接表（默认）
List<Integer>[] graph = new List[n];
for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
for (int[] e : edges) {
    graph[e[0]].add(e[1]);
    graph[e[1]].add(e[0]);       // 无向
}

// ② 邻接矩阵（判边）
int[][] graph = new int[n][n];
for (int[] row : graph) Arrays.fill(row, Integer.MAX_VALUE);
for (int[] e : edges) graph[e[0]][e[1]] = e[2];

// ③ 边集数组（排序）
Arrays.sort(edges, (a, b) -> a[2] - b[2]);

// ④ 哈希建图（字符串）
Map<String, List<String>> g = new HashMap<>();
g.computeIfAbsent("A", k -> new ArrayList<>()).add("B");

// ⑤ 隐藏图（网格）
int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};
```
