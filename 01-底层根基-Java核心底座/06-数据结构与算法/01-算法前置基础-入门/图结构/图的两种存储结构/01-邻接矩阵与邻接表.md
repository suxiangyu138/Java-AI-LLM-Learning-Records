# 01 - 邻接矩阵与邻接表

> 图的两大主力存储：邻接矩阵查边 O(1) 但空间 O(n²)，邻接表空间 O(V+E) 是稀疏图默认解——本节给出两种存储的完整 Java 模板与复杂度对比。

## 1. 两种存储的核心差异

| 维度 | 邻接矩阵 | 邻接表 |
|------|---------|--------|
| 空间 | O(n²) | O(V + E) |
| 查「u-v 是否有边」 | **O(1)** | O(degree(v)) |
| 遍历某点邻居 | O(n) | **O(degree)** |
| 建图代码量 | 最少 | 中等 |
| 适合 | 稠密图、快速判边 | **稀疏图（默认）** |
| LeetCode 使用率 | ~5% | **~90%** |

```text
无向图示例:     邻接矩阵（n=4）:        邻接表:
  A ── B         A B C D
  │              A 0 1 1 0        A: [B, C]
  C ── D         B 1 0 0 0        B: [A]
                 C 1 0 0 1        C: [A, D]
                 D 0 0 1 0        D: [C]
```

> 🎯 **结论先行**：LeetCode 图题 90% 用**邻接表**；邻接矩阵只在「题面小 n（≤1000）且频繁判边」时用；边集数组只在最小生成树/按权排序场景用（02 模块）。

## 2. 邻接矩阵

```java
// 无向无权图
boolean[][] graph = new boolean[n][n];
for (int[] edge : edges) {
    graph[edge[0]][edge[1]] = true;
    graph[edge[1]][edge[0]] = true;    // 无向图对称
}

// 有向带权图
int[][] graph = new int[n][n];
for (int[] row : graph) Arrays.fill(row, Integer.MAX_VALUE);  // 无边 = 极大值
for (int[] edge : edges) {
    graph[edge[0]][edge[1]] = edge[2];
}

// 查边
boolean hasEdge = graph[u][v];
// 遍历 u 的邻居
for (int v = 0; v < n; v++) {
    if (graph[u][v] != Integer.MAX_VALUE) { ... }
}
```

**适用特征**：
- n ≤ 1000 且需要频繁 `graph[u][v]` 判边（如 Floyd 算法）；
- 题目已给 `int[][] graph`（LeetCode 部分题直接给矩阵形式）；
- 稠密图（m ≈ n²）——矩阵空间可接受且查边优势明显。

> ⚠️ 陷阱：n = 10⁵ 时邻接矩阵 10¹⁰ 个格子直接 MLE——看见大 n 立即放弃矩阵。

## 3. 邻接表（主力）

### 3.1 无权图模板

```java
// 建图：List<Integer>[] 数组式邻接表
List<Integer>[] graph = new List[n];
for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
for (int[] edge : edges) {
    graph[edge[0]].add(edge[1]);
    graph[edge[1]].add(edge[0]);       // 无向图双向插入
}

// 遍历邻居
for (int next : graph[u]) { ... }
```

### 3.2 三种建图变体

```java
// 变体 1：List<List<Integer>>（更泛型）
List<List<Integer>> graph = new ArrayList<>();
for (int i = 0; i < n; i++) graph.add(new ArrayList<>());

// 变体 2：int[] 数组（竞赛提速）
List<Integer>[] graph = new List[n];       // 同 3.1

// 变体 3：ArrayList 预分配容量（减少扩容）
for (int i = 0; i < n; i++) graph[i] = new ArrayList<>(8);
```

### 3.3 遍历的三种形态

```java
// 遍历全部节点（防不连通）
for (int i = 0; i < n; i++) {
    if (!visited[i]) dfs(graph, i, visited);
}

// 邻接表的「隐藏图」：由规则推导邻居（网格题、状态题）
// 例：迷宫四方向
int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};
for (int[] d : dirs) {
    int nx = x + d[0], ny = y + d[1];
    if (inBound(nx, ny) && grid[nx][ny] == '1') dfs(grid, nx, ny);
}
```

> 💡 **隐藏图**：邻接表不一定要显式建——「邻居由坐标/规则推导」的网格题、状态转移题，直接用方向数组当邻接表，省去建图步骤。

## 4. 带权图的存储

### 4.1 邻接表带权（两种写法）

```java
// 方式一：int[] {to, weight}
List<int[]>[] graph = new List[n];
for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
for (int[] edge : edges) {             // edge = [from, to, weight]
    graph[edge[0]].add(new int[]{edge[1], edge[2]});
}

// 方式二：内部类 Edge（可读性更好，Dijkstra 常用）
class Edge {
    int to, weight;
    Edge(int to, int weight) { this.to = to; this.weight = weight; }
}
List<Edge>[] graph = new List[n];

// 遍历带权邻居
for (int[] e : graph[u]) {
    int v = e[0], w = e[1];            // 邻居 + 权重
}
```

### 4.2 邻接矩阵带权

```java
int[][] graph = new int[n][n];
for (int[] row : graph) Arrays.fill(row, Integer.MAX_VALUE);  // INF = 无边
for (int[] edge : edges) {
    graph[edge[0]][edge[1]] = edge[2];
    graph[edge[1]][edge[0]] = edge[2];  // 无向带权
}
// 自环置 0（可选）
for (int i = 0; i < n; i++) graph[i][i] = 0;
```

| 带权存储 | 写法 | 适用 |
|---------|------|------|
| `List<int[]>` | `{to, weight}` | Dijkstra（堆优化） |
| `List<Edge>` | 内部类 | 可读性优先 |
| `int[][]` 矩阵 | INF 初始化 | Floyd |
| 边集数组 | `int[] {from,to,w}` | Kruskal |

> 💡 Dijkstra 的标准存储：**邻接表 + 小顶堆**（每步取最小距离节点）；Floyd 的标准存储：**邻接矩阵**（三重循环判边）——算法决定存储，反之亦然。

## 5. 复杂度与选型对比

### 5.1 复杂度总表

| 操作 | 邻接矩阵 | 邻接表 |
|------|:---:|:---:|
| 空间 | O(n²) | O(V+E) |
| 查边 (u,v) | O(1) | O(deg(v)) |
| 遍历 v 的邻居 | O(n) | O(deg(v)) |
| 遍历全图 | O(n²) | O(V+E) |
| 添加边 | O(1) | O(1)（平均） |
| 删除边 | O(1) | O(deg) |

### 5.2 算法-存储匹配表

| 算法 | 首选存储 | 原因 |
|------|---------|------|
| BFS/DFS | 邻接表 | 遍历邻居 O(deg) |
| Dijkstra（堆优化） | 邻接表 | 稀疏图 + 邻居遍历 |
| Floyd | 邻接矩阵 | 三重循环判边 |
| Kruskal | 边集数组 | 按权排序 |
| Prim | 邻接矩阵/表 | 稠密矩阵、稀疏堆 |
| 网格题 | 隐藏图 | 免建图 |

### 5.3 选型口诀

```text
三问定存储:
  ① 稀疏还是稠密？    → 稀疏邻接表、稠密矩阵
  ② 频繁判边？        → 是 → 矩阵（n ≤ 1000）
  ③ 按权排序？        → 是 → 边集数组
  ④ 网格/状态？       → 隐藏图（方向数组）
  ⑤ 节点是字符串？    → Map<String, List<String>>
```

> 🎯 **核心要点**：本节验收——三种邻接表（无权/带权/变体）与两种矩阵（无权/带权 INF）模板默写；「稀疏邻接表、稠密矩阵」口诀 + 三问定存储；隐藏图思想（网格/状态免建图）；算法-存储匹配表（Dijkstra→邻接表、Floyd→矩阵、Kruskal→边集）；边集数组与字符串节点见 02 模块。
