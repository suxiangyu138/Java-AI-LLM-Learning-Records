## 5. 术语表

| 术语 | 英文 | 定义 |
|------|------|------|
| 顶点 | Vertex | 图的基本单位（点） |
| 边 | Edge | 顶点间的关系（线） |
| 无向边 | Undirected Edge | 无方向的边 (u, v) |
| 有向边 | Directed Edge | 有方向的边 u→v（弧） |
| 自环 | Self-loop | 顶点到自身的边 |
| 多重边 | Multi-edge | 两点间多条边 |
| 简单图 | Simple Graph | 无自环无多重边 |
| 完全图 | Complete Graph | 任意两点间都有边 |
| 路径 | Path | 相邻顶点序列 |
| 简单路径 | Simple Path | 不重复经过顶点 |
| 回路/环 | Cycle | 起点 = 终点的路径 |
| 连通图 | Connected Graph | 任意两点可达（无向） |
| 连通分量 | Connected Component | 极大连通子图 |
| 强连通 | Strongly Connected | 双向可达（有向） |
| 生成树 | Spanning Tree | 连通图的极小连通子图 |

## 6. 常见问题 FAQ

| 问题 | 一句话答案 |
|------|-----------|
| 图与树的区别？ | 树是无环连通图；图允许环和多连通分量 |
| 有向图和无向图怎么选？ | 关系有方向（依赖/流程）用有向；无方向（朋友/道路）用无向 |
| 什么是度？ | 无向=相连边数；有向=入度+出度 |
| 握手定理是什么？ | Σ所有顶点度数 = 2 × 边数 |
| 什么是连通分量？ | 极大连通子图（DFS 遍历起点计数） |
| 什么是强连通分量？ | 有向图中两两互达的极大子图 |
| 什么是 DAG？ | 有向无环图（拓扑排序的前提） |
| 什么是二分图？ | 顶点可分两组、组内无边的图（可二染色） |
| 稀疏图/稠密图怎么判断？ | m ≈ n 稀疏、m ≈ n² 稠密（影响存储选型） |
| 什么是生成树？ | 连通图包含全部顶点、边数最少的连通子图 |
