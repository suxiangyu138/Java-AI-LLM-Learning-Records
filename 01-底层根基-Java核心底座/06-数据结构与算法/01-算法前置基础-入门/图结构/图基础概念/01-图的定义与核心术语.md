## 1. 图的定义与组成

**图（Graph）= 顶点集 V + 边集 E**，记作 G = (V, E)。

| 术语 | 英文 | 含义 | 例子 |
|------|------|------|------|
| 顶点 | Vertex | 图的基本单位 | 城市、用户、课程、网页 |
| 边 | Edge | 两顶点间的关系 | 航线、好友、选课依赖、链接 |
| 顶点数 | \|V\| | 常记作 n | — |
| 边数 | \|E\| | 常记作 m | — |

```text
图 G = (V, E)
V = {A, B, C, D}               4 个顶点
E = {(A,B), (B,C), (C,D)}      3 条边
  A ── B ── C ── D
```

**图的表示符号速查**：

| 符号 | 含义 |
|------|------|
| G = (V, E) | 图由顶点集与边集组成 |
| \|V\| = n | 顶点数 |
| \|E\| = m | 边数 |
| (u, v) | 无向边 |
| ⟨u, v⟩ 或 u→v | 有向边（弧） |
| deg(v) | 顶点 v 的度 |
| deg⁺(v) / deg⁻(v) | 出度 / 入度 |

> 💡 **与树的区别**：树是图的特例（无环连通图）；图允许环、允许不连通。树的所有算法（遍历）都能在图上做，但图多出来的环与多连通分量需要额外处理——这是图题的核心难点来源。

## 2. 图的分类

### 2.1 有向图 vs 无向图

| 维度 | 无向图 | 有向图 |
|------|--------|--------|
| 边 | (A,B) 无方向，A↔B 互通 | A→B 有方向，A 可达 B 但 B 不一定可达 A |
| 存储 | 邻接表双边各插一次 | 邻接表单边插入 |
| 典型场景 | 好友关系、道路、电路 | 依赖关系、任务调度、网页链接 |
| 遍历注意 | 简单 | **方向不可逆**，visited 按出边判断 |

```text
无向图:  A ── B          有向图:  A ──▶ B
         │               (B 不一定能回 A)
         C
```

### 2.2 稀疏图 vs 稠密图

| 类型 | 边数 m 与 n 的关系 | 典型 | 存储首选 |
|------|-------------------|------|---------|
| 稀疏图 | m ≈ n（每点几条边） | 社交网络、道路图 | 邻接表 |
| 稠密图 | m ≈ n²（全连接） | 完全图、关系矩阵 | 邻接矩阵 |

> ⚠️ 绝大多数 LeetCode 图题是**稀疏图**——默认用邻接表，除非题面明确「任意两点都相连」。
>
> 💡 **稠密判定直觉**：n = 100 的图，完全图有 4950 条边；如果 m 只有几百，就是稀疏图。

### 2.3 其他分类维度

| 分类维度 | 类型 | 说明 |
|---------|------|------|
| 自环/多重边 | 简单图 vs 一般图 | 简单图无自环无多重边（LeetCode 默认） |
| 权重 | 无权图 vs 带权图 | 带权图边有距离/代价 |
| 连通性 | 连通图 vs 非连通图 | 非连通图有多个连通分量 |
| 形态 | 树/森林 vs 一般图 | 树 = 无环连通图 |
| 环 | 无环图（DAG）vs 有环图 | DAG 才能拓扑排序 |

## 3. 度与邻接

**度（Degree）**：与顶点相连的边数。

| 图的类型 | 度 | 计算公式 |
|---------|-----|---------|
| 无向图 | 每条边贡献 2 个度 | **Σ度 = 2m（握手定理）** |
| 有向图 | 入度 in-degree + 出度 out-degree | Σ入度 = Σ出度 = m |

```java
// 入度/出度数组：拓扑排序的前置统计
int[] inDegree = new int[n];
int[] outDegree = new int[n];
for (int[] edge : edges) {          // edge = [from, to]
    inDegree[to]++;
    outDegree[from]++;
}
```

**握手定理（Handshaking Lemma）**：

```text
无向图: Σ deg(v) = 2m
推论 1: 所有顶点的度之和必为偶数
推论 2: 奇度顶点的个数必为偶数

应用: 「一笔画」判定（欧拉路径）的第一条件
      推理题（奇度顶点问题）
```

> 💡 握手定理的用处：奇度顶点个数必为偶数——判断「一笔画」（欧拉路径）的第一条件，也是面试推理题的常用引理。

**邻接（Adjacency）**：与某顶点直接相连的顶点集合——邻接表的核心概念（衔接[图的两种存储结构](../图的两种存储结构/)）。

## 4. 路径、环与连通性

### 4.1 路径与环

| 术语 | 定义 | 例子 |
|------|------|------|
| 路径 Path | 顶点序列，相邻顶点有边 | A→B→C |
| 简单路径 | 不重复经过顶点的路径 | A→B→C（不含环） |
| 环 Cycle | 起点=终点的路径 | A→B→C→A |
| 自环 | 顶点到自身的边 | A→A（题中少见） |

```text
路径: A → B → C → D
环:   A → B → C → A
       ↑___________|
```

### 4.2 连通性

| 术语 | 定义 | 判定方法 |
|------|------|---------|
| 连通图（无向） | 任意两顶点间存在路径 | 任选起点 DFS/BFS 遍历，visited 数 = n |
| 连通分量 | 极大连通子图 | DFS 遍历计数（每轮 dfs 启动 +1） |
| 强连通（有向） | A 可达 B 且 B 可达 A | Kosaraju/Tarjan（图经典算法目录） |
| 可达性 | 从 u 能否走到 v | 单源 BFS/DFS |

```java
// 连通分量计数：每进入一次 dfs 就是一个新连通块
int count = 0;
for (int i = 0; i < n; i++) {
    if (!visited[i]) {
        count++;          // 新连通分量
        dfs(graph, i, visited);
    }
}
```

> 💡 连通分量计数是「岛屿数量」类题（200 题）的通用模型——网格版用方向数组当邻接表。

### 4.3 树与森林

- **树**：连通且无环（n 个顶点 n-1 条边）；
- **森林**：多棵树的集合；
- **判定树的两个等价条件**：①连通 + 无环；②连通 + m = n - 1（无向）。

```text
树的判定（面试口述）:
  条件 1: 连通且无环
  条件 2: 连通且 m = n - 1
  二者等价——满足其一即是树
```

## 5. 带权图与特殊图

### 5.1 带权图

边携带权重（距离、代价、时间）：

```text
  A ──5── B
  │       │
  3       2
  │       │
  C ──1── D
```

- 邻接表存 `List<int[]>` 或 `List<Edge>`（to + weight）；
- 无权重 = 所有边权为 1 → BFS 即可求最短；有权 → Dijkstra（图经典算法目录）。

### 5.2 特殊图

| 特殊图 | 定义 | 经典应用 |
|--------|------|---------|
| 完全图 | 任意两点间都有边（m = n(n-1)/2） | 全连接问题 |
| 二分图 | 顶点可分两组，组内无边 | 匹配、着色、判断合法性 |
| DAG（有向无环图） | 无环的有向图 | 拓扑排序、动态规划 |
| 树/森林 | 无环连通图/无环图 | 见 4.3 |
| 正则图 | 所有顶点度数相同 | 理论图论 |
| 欧拉图 | 存在一笔画回路 | 欧拉路径（图经典算法目录） |

```java
// 二分图判定：染色法（DFS，785 题）
boolean dfsColor(int[][] graph, int u, int[] color) {
    for (int v : graph[u]) {
        if (color[v] == 0) {
            color[v] = -color[u];               // 邻居染相反色
            if (!dfsColor(graph, v, color)) return false;
        } else if (color[v] == color[u]) {
            return false;                       // 冲突 = 非二分图
        }
    }
    return true;
}
```

### 5.3 图的现实建模示例

| 场景 | 顶点 | 边 | 图类型 |
|------|------|-----|--------|
| 社交网络 | 用户 | 好友关系 | 无向稀疏 |
| 微博关注 | 用户 | 关注方向 | 有向稀疏 |
| 地图导航 | 路口 | 道路（距离） | 无向带权 |
| 课程表 | 课程 | 先修依赖 | 有向 DAG |
| 网页链接 | 网页 | 超链接 | 有向带权 |
| 电路板 | 元件 | 导线 | 无向（可带权） |
