## 1. 连通分量与可达性

### 1.1 连通分量计数（DFS 版）

```java
// 547 省份数量：邻接矩阵 + DFS 连通分量
public int findCircleNum(int[][] isConnected) {
    int n = isConnected.length;
    boolean[] visited = new boolean[n];
    int provinces = 0;
    for (int i = 0; i < n; i++) {
        if (!visited[i]) {
            provinces++;
            dfs(isConnected, i, visited);
        }
    }
    return provinces;
}

void dfs(int[][] g, int u, boolean[] visited) {
    visited[u] = true;
    for (int v = 0; v < g.length; v++) {
        if (g[u][v] == 1 && !visited[v]) {
            dfs(g, v, visited);
        }
    }
}
```

## 2. 环检测

### 2.1 有向图：三色标记（DFS）

| 颜色 | 含义 |
|------|------|
| 0（白） | 未访问 |
| 1（灰） | 在递归栈中 |
| 2（黑） | 已完成（出栈） |

```java
// 207 课程表：有向图判环 = 能否完成所有课程
public boolean canFinish(int numCourses, int[][] prerequisites) {
    List<Integer>[] graph = new List[numCourses];
    for (int i = 0; i < numCourses; i++) graph[i] = new ArrayList<>();
    for (int[] p : prerequisites) graph[p[1]].add(p[0]);

    int[] color = new int[numCourses];          // 0 未访问 1 栈中 2 完成
    for (int i = 0; i < numCourses; i++) {
        if (color[i] == 0 && hasCycle(graph, i, color)) return false;
    }
    return true;
}

boolean hasCycle(List<Integer>[] graph, int u, int[] color) {
    color[u] = 1;
    for (int v : graph[u]) {
        if (color[v] == 1) return true;         // 栈中相遇 = 环
        if (color[v] == 0 && hasCycle(graph, v, color)) return true;
    }
    color[u] = 2;
    return false;
}
```

### 2.2 无向图：父节点排除法

```java
// 684 冗余连接：无向图判环（并查集更优解见进阶）
boolean hasCycleUndirected(List<Integer>[] graph, int n) {
    boolean[] visited = new boolean[n];
    for (int i = 0; i < n; i++) {
        if (!visited[i] && dfsCycle(graph, i, -1, visited)) return true;
    }
    return false;
}

boolean dfsCycle(List<Integer>[] graph, int u, int parent, boolean[] visited) {
    visited[u] = true;
    for (int v : graph[u]) {
        if (v == parent) continue;              // 跳过父节点（无向边双向记录）
        if (visited[v]) return true;            // 遇到已访问非父节点 = 环
        if (dfsCycle(graph, v, u, visited)) return true;
    }
    return false;
}
```

> ⚠️ 无向图**不能**套用有向图的三色「遇到灰即环」——无向边天然来回；必须排除父节点，否则每棵树都被误判成环。

## 3. 拓扑排序入门

**拓扑排序**：给 DAG 的顶点排一个线性序，使每条边 u→v 都满足 u 在 v 前。只有 DAG 才有拓扑序（有环 = 无解）。

### 3.1 Kahn 算法（BFS + 入度，推荐入门）

```java
// 210 课程表 II：拓扑排序并检测环
public int[] findOrder(int numCourses, int[][] prerequisites) {
    List<Integer>[] graph = new List[numCourses];
    int[] inDegree = new int[numCourses];
    for (int i = 0; i < numCourses; i++) graph[i] = new ArrayList<>();
    for (int[] p : prerequisites) {
        graph[p[1]].add(p[0]);
        inDegree[p[0]]++;
    }

    Deque<Integer> q = new ArrayDeque<>();
    for (int i = 0; i < numCourses; i++) {
        if (inDegree[i] == 0) q.offer(i);       // 入度为 0 = 无前置依赖
    }

    int[] order = new int[numCourses];
    int idx = 0;
    while (!q.isEmpty()) {
        int u = q.poll();
        order[idx++] = u;
        for (int v : graph[u]) {
            if (--inDegree[v] == 0) q.offer(v); // 前置完成，解锁后继
        }
    }
    return idx == numCourses ? order : new int[0];  // 数量不够 = 有环
}
```

| 步骤 | 操作 |
|------|------|
| 1 | 统计入度数组 |
| 2 | 入度为 0 的节点入队 |
| 3 | 出队加入结果，其所有后继入度 -1，减到 0 再入队 |
| 4 | 结果数 < n → 存在环 |

> 💡 Kahn 算法同时解决两件事：**排序 + 判环**（结果数量不够就是有环）。课程表、任务调度、编译依赖全是它的舞台。完整拓扑专题见[图论基础/拓扑排序](../../03-高频专题模块/专题 11：图/图论基础/拓扑排序/00-拓扑排序专题精要.md)。

## 4. 二分图判定

**二分图**：顶点能分成两组，所有边都跨组（组内无边）——等价于「能否二染色成功」。

```java
// 785 判断二分图：DFS 染色法
public boolean isBipartite(int[][] graph) {
    int n = graph.length;
    int[] color = new int[n];                   // 0 未染色 1/-1 两种颜色
    for (int i = 0; i < n; i++) {
        if (color[i] == 0) {
            color[i] = 1;
            if (!dfsColor(graph, i, color)) return false;
        }
    }
    return true;
}

boolean dfsColor(int[][] graph, int u, int[] color) {
    for (int v : graph[u]) {
        if (color[v] == 0) {
            color[v] = -color[u];               // 邻居染相反色
            if (!dfsColor(graph, v, color)) return false;
        } else if (color[v] == color[u]) {
            return false;                       // 邻居同色 = 冲突
        }
    }
    return true;
}
```

**识别信号**：「分成两组互不冲突」「染色」「派对/球队分配」「奇环不存在」→ 二分图。
