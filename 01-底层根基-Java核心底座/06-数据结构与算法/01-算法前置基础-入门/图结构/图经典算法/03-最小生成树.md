## 1. 最小生成树概念

**最小生成树（Minimum Spanning Tree）**：连通图的一个子图——包含全部 n 个顶点、n-1 条边、总权重最小。

```text
原图（5 点 7 边）:         最小生成树（4 边）:
   A ──2── B                  A ──2── B
   |\      /|                 |       /
   4 3    5 6                 4      /
   |  \  /  |                 |     /
   C ──1── D                  C ──1── D
        \  |                      \  |
        7  8                       7  |?
   （还连 E）               E ──?  选 2 或 3 最小边
```

| 要点 | 说明 |
|------|------|
| 边数 | 恰好 n - 1 |
| 连通 | 包含所有顶点 |
| 最小 | 总权重最小 |
| 唯一性 | 边权全不同才唯一 |
| 应用 | 网络布线、电路设计、聚类 |

> 💡 生成树 = 「删边到 n-1 条且仍连通」；MST = 其中总权最小的——**「连通所有点 + 代价最小」**是识别信号。

## 2. Kruskal 算法

**核心**：**边贪心**——按权重升序选边，选不产生环的（并查集判断），直到 n-1 条。

```java
// 1584 连接所有点的最小费用：Kruskal 模板
public int minCostConnectPoints(int[][] points) {
    int n = points.length;
    // ① 生成所有边（完全图 → 边集数组）
    List<int[]> edges = new ArrayList<>();
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            int w = Math.abs(points[i][0] - points[j][0])
                  + Math.abs(points[i][1] - points[j][1]);
            edges.add(new int[]{i, j, w});
        }
    }
    // ② 按权重排序
    edges.sort((a, b) -> a[2] - b[2]);

    // ③ 并查集选边
    DSU dsu = new DSU(n);
    int cost = 0, count = 0;
    for (int[] e : edges) {
        if (dsu.union(e[0], e[1])) {             // 不连通才选
            cost += e[2];
            if (++count == n - 1) break;         // n-1 条完成
        }
    }
    return cost;
}
```

| 步骤 | 操作 | 复杂度 |
|------|------|:---:|
| ① 建边集 | 所有边 | O(E) |
| ② 排序 | 按权重 | O(E log E) |
| ③ 并查集选边 | union 判断环 | O(E α(V)) |
| 总计 | — | **O(E log E)** |

> 💡 Kruskal 依赖 01 模块的并查集（union 返回是否成功 = 是否成环）——**边贪心 + 并查集**是 Kruskal 的全部。

## 3. Prim 算法

**核心**：**点贪心**——从任意点出发，每次选「连接已选集合与未选集合的最小边」（割定理），加入新点。

```java
// Prim 模板（邻接表 + 小顶堆，类似 Dijkstra）
int prim(int n, List<int[]>[] graph) {
    boolean[] inMST = new boolean[n];            // 已选点集
    // 小顶堆 {weight, node}：连接已选与未选的最小边
    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
    pq.offer(new int[]{0, 0});                   // 从 0 出发（虚拟边）

    int cost = 0, count = 0;
    while (!pq.isEmpty() && count < n) {
        int[] cur = pq.poll();
        int w = cur[0], u = cur[1];
        if (inMST[u]) continue;                  // 已选点跳过
        inMST[u] = true;
        cost += w;
        count++;
        for (int[] e : graph[u]) {
            if (!inMST[e[0]]) {                  // 未选邻居
                pq.offer(new int[]{e[1], e[0]});
            }
        }
    }
    return count == n ? cost : -1;               // 不连通
}
```

**Prim vs Dijkstra 的相似与区别**：

| 对比 | Prim | Dijkstra |
|------|:---:|:---:|
| 目标 | 生成树总权 | 单源距离 |
| 松弛依据 | 边权 | dist[u] + 边权 |
| 已确定 | 已入 MST | 已确定最短 |
| 代码 | 几乎同构 | — |

> 💡 **Prim ≈ Dijkstra 去掉累加**：Prim 用「边权」直接入堆，Dijkstra 用「dist[u]+边权」——两算法代码几乎一样，理解其一即通其二。

## 4. 两算法对比

| 维度 | Kruskal | Prim |
|------|:---:|:---:|
| 贪心对象 | **边** | **点** |
| 核心结构 | 并查集 | 堆 + visited |
| 复杂度 | O(E log E) | O(E log V)（堆） |
| 稀疏图 | ✅ 更优 | 可 |
| 稠密图 | 可 | ✅ 更优 |
| 需要排序 | ✅ | ❌ |
| 实现难度 | ★★ | ★★★ |

```text
选型: 
  稀疏图（m ≈ n）→ Kruskal（边少，排序便宜）
  稠密图（m ≈ n²）→ Prim（点少，堆操作少）
  面试默认 → Kruskal（并查集更常考）
```

## 5. 理论：割定理与安全边

**割（Cut）**：把顶点分成两个非空集合 (S, V-S)。**割定理**：横跨割的最小边一定是某个 MST 的边（安全边）。

```text
割定理图示:
        S          V-S
      A ──1── D        ← 横跨割的最小边（1）
      B ──3── E          任何 MST 必含该边
      C ──2── F

证明思路（反证）:
  假设 MST 不含安全边 e
  则 MST 中跨割必有一条边 e'（否则不连通）
  e' 的权 ≥ e（e 是跨割最小）
  用 e 替换 e' → 总权不增 → 仍是 MST ✓
```

| 算法 | 对应的割 |
|------|---------|
| Kruskal | 边排序过程中隐式维护的割 |
| Prim | 已选集合 S 与未选集合的割 |

> 🎯 **面试加分**：Kruskal 与 Prim 的正确性都由**割定理**保证——「每次选跨割最小边不破坏最优性」；证明用反证（替换 e' 权不增）是标准答案。

**面试追问**：

| 追问 | 答题要点 |
|------|---------|
| MST 有多少条边？ | n - 1 |
| Kruskal 为什么并查集？ | 选边判断是否成环 |
| Prim 为什么堆？ | 取跨割最小边 O(log V) |
| 有相等权边会怎样？ | MST 可能不唯一 |
| 怎么判断图不连通？ | 边数 < n-1 / count < n |
| 负权边影响 MST 吗？ | 不影响（MST 与正负无关） |
| MST 与最短路关系？ | 无关——MST 全局最优、最短路单源最优 |

> 🎯 **核心要点**：MST 验收——Kruskal（边排序 + 并查集）与 Prim（堆 + visited）两模板默写；选型一句话「**稀疏 Kruskal、稠密 Prim**」；割定理的正确性论证（反证替换）；「n-1 条边」的完成条件；负权不影响 MST 的认知；与 01 模块并查集、02 模块 Dijkstra（Prim 同构）形成完整闭环。
