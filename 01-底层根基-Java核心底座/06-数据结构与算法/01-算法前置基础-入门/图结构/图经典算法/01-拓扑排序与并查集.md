## 1. 拓扑排序概念

**拓扑排序**：给 DAG 的顶点排一个线性序，使每条边 u→v 都满足 u 在 v 前。

```text
课程依赖:              拓扑序（一种）:
  A → C → E            A → B → C → D → E → F
  B → D → F
  C → D

只有 DAG 有拓扑序: 有环 = 无解（循环依赖）
```

| 要点 | 说明 |
|------|------|
| 前提 | **DAG（有向无环图）** |
| 唯一性 | 不唯一（多个入度 0 可任意选） |
| 应用 | 课程表、编译依赖、任务调度 |
| 判环 | 结果数量 < n = 有环 |

> 💡 拓扑排序同时解决两件事：**排序 + 判环**——结果数不足就是有环（207 课程表的判定标准）。

## 2. Kahn 算法（BFS + 入度）

**核心**：入度为 0 的节点无前置依赖 → 先出队；出队后其后继入度 -1，减到 0 再入队。

```java
// 210 课程表 II：拓扑排序并检测环
public int[] findOrder(int numCourses, int[][] prerequisites) {
    List<Integer>[] graph = new List[numCourses];
    int[] inDegree = new int[numCourses];
    for (int i = 0; i < numCourses; i++) graph[i] = new ArrayList<>();
    for (int[] p : prerequisites) {
        graph[p[1]].add(p[0]);
        inDegree[p[0]]++;                          // 统计入度
    }

    Deque<Integer> q = new ArrayDeque<>();
    for (int i = 0; i < numCourses; i++) {
        if (inDegree[i] == 0) q.offer(i);          // 入度 0 入队
    }

    int[] order = new int[numCourses];
    int idx = 0;
    while (!q.isEmpty()) {
        int u = q.poll();
        order[idx++] = u;
        for (int v : graph[u]) {
            if (--inDegree[v] == 0) q.offer(v);    // 后继解锁
        }
    }
    return idx == numCourses ? order : new int[0]; // 数量不够 = 有环
}
```

| 步骤 | 操作 |
|------|------|
| 1 | 统计入度数组 |
| 2 | 入度为 0 的节点入队 |
| 3 | 出队加入结果，后继入度 -1，减到 0 入队 |
| 4 | 结果数 < n → 存在环 |

> 💡 Kahn = **BFS + 入度**——把图的遍历体系（02 模块）与「依赖解锁」思想结合；判环是天然副产品（出队数 < n）。

## 3. DFS 拓扑排序

**核心**：DFS 的「完成序逆序」= 拓扑序——完成时间晚的（依赖多的）排前面。

```java
// DFS 拓扑排序（210 题另一解法）
class Solution {
    List<Integer> order = new ArrayList<>();
    int[] color;                                   // 0 未访问 1 栈中 2 完成

    public int[] findOrder(int n, int[][] prerequisites) {
        List<Integer>[] graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] p : prerequisites) graph[p[1]].add(p[0]);

        color = new int[n];
        for (int i = 0; i < n; i++) {
            if (color[i] == 0 && !dfs(graph, i)) return new int[0];  // 有环
        }
        Collections.reverse(order);                // 完成序逆序 = 拓扑序
        return order.stream().mapToInt(Integer::intValue).toArray();
    }

    boolean dfs(List<Integer>[] graph, int u) {
        color[u] = 1;                              // 进入栈
        for (int v : graph[u]) {
            if (color[v] == 1) return false;       // 栈中相遇 = 环
            if (color[v] == 0 && !dfs(graph, v)) return false;
        }
        color[u] = 2;                              // 完成
        order.add(u);                              // 记录完成序
        return true;
    }
}
```

| 对比 | Kahn（BFS） | DFS |
|------|:---:|:---:|
| 核心 | 入度队列 | 完成序逆序 |
| 判环 | 出队数 < n | 三色栈中相遇 |
| 直观性 | ✅ 更直观 | 需理解完成序 |
| 面试默认 | ✅ | 追问时写 |

> ⚠️ DFS 拓扑的「完成序逆序」是面试易混点——完成顺序是「依赖的依赖先完成」，逆序才是依赖在前。

## 4. 并查集原理

**并查集（Union-Find / DSU）**：动态维护「元素属于哪个集合」——合并（union）与查询（find）近乎 O(1)。

```text
初始:  0  1  2  3  4  5       每个元素自己一个集合
union(0,1):  0→1             合并 0 和 1
union(2,3):  2→3
find(0)=1  find(3)=3         查询根
union(1,3):  1→3             整组合并
最终:  {0,1,2,3}  {4}  {5}
```

| 操作 | 功能 | 复杂度 |
|------|------|:---:|
| find(x) | 找 x 的集合根 | O(α(n)) |
| union(x,y) | 合并 x、y 所在集合 | O(α(n)) |
| 判断连通 | find(x) == find(y) | O(α(n)) |

> 💡 α(n) 是反阿克曼函数——实际可以认为 **O(1)**；并查集是「动态连通性」问题的标准答案。

## 5. 并查集优化与模板

### 5.1 两个关键优化

| 优化 | 作用 | 原理 |
|------|------|------|
| 路径压缩 | 查询时扁平化 | find 时把路径上节点直接挂到根 |
| 按秩合并 | 小树挂大树 | 高度小的根挂到高度大的根 |

### 5.2 完整模板

```java
// 并查集完整模板（路径压缩 + 按秩合并）
class DSU {
    int[] parent;
    int[] rank;                    // 秩（近似高度）

    DSU(int n) {
        parent = new int[n];
        rank = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;
    }

    // 查询根（路径压缩）
    int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]);   // 递归压缩
        }
        return parent[x];
    }

    // 合并（按秩）
    boolean union(int x, int y) {
        int rx = find(x), ry = find(y);
        if (rx == ry) return false;        // 已连通
        if (rank[rx] < rank[ry]) {
            parent[rx] = ry;
        } else if (rank[rx] > rank[ry]) {
            parent[ry] = rx;
        } else {
            parent[ry] = rx;
            rank[rx]++;
        }
        return true;                       // 合并成功（可用于计数）
    }

    // 判断连通
    boolean connected(int x, int y) {
        return find(x) == find(y);
    }
}
```

> 🎯 **并查集三件套**：find（路径压缩）、union（按秩 + 返回是否成功）、connected——合并返回 boolean 让「成功合并次数」直接可得（Kruskal 计数、冗余连接判环）。

```java
// 684 冗余连接：并查集合并失败即答案
public int[] findRedundantConnection(int[][] edges) {
    DSU dsu = new DSU(edges.length + 1);
    for (int[] e : edges) {
        if (!dsu.union(e[0], e[1])) {
            return e;                    // 已连通 = 这条边是冗余
        }
    }
    return new int[0];
}
```

**面试追问**：

| 追问 | 答题要点 |
|------|---------|
| 拓扑排序为什么 DAG 才有效？ | 环 = 相互依赖，无法线性化 |
| Kahn 判环的原理？ | 入度 0 节点全部出队则无环 |
| 并查集为什么近 O(1)？ | 路径压缩 + 按秩合并 → α(n) |
| 路径压缩的原理？ | 查询时把路径挂到根（扁平化） |
| 按秩合并的作用？ | 控制树高（防退化链表） |
| 并查集能删边吗？ | 难——只支持合并；删边需离线逆序 |

> 🎯 **核心要点**：本节验收——Kahn 拓扑（入度队列 + 判环）默写；并查集三件套默写（find 路径压缩 + union 按秩 + connected）；理解「拓扑 = 依赖解锁」「并查集 = 动态连通」两个心智模型；684（合并失败即冗余）与 547（根计数）是并查集最经典的两个应用；Kruskal（03 模块）直接复用并查集。
