## 6. 常见问题 FAQ

| 问题 | 一句话答案 |
|------|-----------|
| 拓扑排序什么时候无解？ | 图中有环（出队数 < n） |
| Kahn 和 DFS 拓扑怎么选？ | Kahn 直观（BFS+入度）；DFS 用完成序逆序 |
| 并查集复杂度？ | 路径压缩 + 按秩合并 ≈ O(α(n)) 反阿克曼 |
| Dijkstra 能处理负权吗？ | 不能——贪心假设失效；负权用 Bellman-Ford |
| Bellman-Ford 怎么判负环？ | 第 n 轮还能松弛 = 有负环 |
| Floyd 适合什么？ | 稠密图全源最短路（n ≤ 500） |
| Kruskal 和 Prim 怎么选？ | 稀疏边集 Kruskal；稠密点贪心 Prim |
| 生成树一定唯一吗？ | 不——边权有相等时可能多个 |
| 最短路径能走过重复点吗？ | 正权最短路径必简单（无重复） |
| 算法依赖哪种存储？ | Dijkstra/Prim 邻接表；Floyd/Kruskal 矩阵/边集 |
