## 1. 最短路径问题定义

**最短路径**：从源点到目标点的最小代价路径（边权之和最小）。

```text
问题分类:
  单源最短路径: 一个源点到所有点（Dijkstra/Bellman-Ford）
  全源最短路径: 任意两点间（Floyd）
  无权图: BFS（图的遍历目录已解）

边权分类:
  正权: Dijkstra（贪心有效）
  含负权: Bellman-Ford（可判负环）
  负环: 不存在最短路径（可无限小）
```

| 维度 | 单源正权 | 单源负权 | 全源 |
|------|:---:|:---:|:---:|
| 算法 | Dijkstra | Bellman-Ford | Floyd |
| 复杂度 | O(E log V) | O(VE) | O(V³) |
| 负权 | ❌ | ✅ | ✅ |
| 判负环 | ❌ | ✅ | ❌ |

> ⚠️ 负环（negative cycle）：环上权重和为负——路径可无限绕圈变小，最短路径不存在；Bellman-Ford 的第 n 轮松弛就是为检测它。

## 2. Dijkstra 算法（堆优化）

**核心**：贪心 + 松弛——每次从未确定点中取距离最小的（小顶堆），松弛其邻居。

```java
// 743 网络延迟时间：Dijkstra 堆优化模板
public int networkDelayTime(int[][] times, int n, int k) {
    // ① 邻接表建图（带权）
    List<int[]>[] graph = new List[n + 1];
    for (int i = 1; i <= n; i++) graph[i] = new ArrayList<>();
    for (int[] t : times) {
        graph[t[0]].add(new int[]{t[1], t[2]});   // {to, weight}
    }

    // ② 距离数组 + 小顶堆（dist, node）
    int[] dist = new int[n + 1];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[k] = 0;
    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
    pq.offer(new int[]{0, k});                    // {dist, node}

    // ③ 贪心松弛
    while (!pq.isEmpty()) {
        int[] cur = pq.poll();
        int d = cur[0], u = cur[1];
        if (d > dist[u]) continue;                // 过期条目（关键优化）
        for (int[] e : graph[u]) {
            int v = e[0], w = e[1];
            if (dist[u] + w < dist[v]) {          // 松弛操作
                dist[v] = dist[u] + w;
                pq.offer(new int[]{dist[v], v});
            }
        }
    }

    // ④ 找最大距离（全部可达的最大延迟）
    int ans = 0;
    for (int i = 1; i <= n; i++) {
        if (dist[i] == Integer.MAX_VALUE) return -1;  // 有不可达点
        ans = Math.max(ans, dist[i]);
    }
    return ans;
}
```

**模板要点**：

| 要点 | 说明 |
|------|------|
| 邻接表 + 小顶堆 | 稀疏图最优组合 |
| `d > dist[u]` 跳过 | 过期条目剪枝（否则超时） |
| 松弛条件 | `dist[u] + w < dist[v]` |
| 负权失效 | 贪心假设「已确定的最短」不再成立 |

> 💡 **为什么 Dijkstra 不能处理负权**：贪心「取最小即确定」依赖正权——负权可能让已确定点被更短路径绕过；复杂度 O((V+E) log V) 是单源最优。

## 3. Bellman-Ford 算法

**核心**：对**所有边**松弛 n-1 轮——第 i 轮后 dist 是「最多 i 条边」的最短路径；第 n 轮还能松弛 = 负环。

```java
// Bellman-Ford 模板（含负环检测）
int[] bellmanFord(int n, int[][] edges, int source) {
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[source] = 0;

    // ① 松弛 n-1 轮（最长简单路径 n-1 条边）
    for (int i = 0; i < n - 1; i++) {
        boolean updated = false;
        for (int[] e : edges) {                    // 遍历所有边
            int u = e[0], v = e[1], w = e[2];
            if (dist[u] != Integer.MAX_VALUE && dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;             // 松弛
                updated = true;
            }
        }
        if (!updated) break;                       // 提前终止（无更新）
    }

    // ② 第 n 轮：还能松弛 = 负环
    for (int[] e : edges) {
        int u = e[0], v = e[1], w = e[2];
        if (dist[u] != Integer.MAX_VALUE && dist[u] + w < dist[v]) {
            return null;                           // 存在负环
        }
    }
    return dist;
}
```

| 特性 | 说明 |
|------|------|
| 复杂度 | O(VE)（比 Dijkstra 慢，但通用） |
| 负权 | ✅ 支持 |
| 负环检测 | ✅ 第 n 轮松弛判断 |
| 适用 | 含负权、无负环的图 |

> 💡 应用场景：**有边数限制的最短路**（787 题「K 站中转」）——Bellman-Ford 的「轮数 = 边数」特性天然匹配。

## 4. Floyd 算法

**核心**：三重循环 + 动态规划——`dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])`。

```java
// Floyd 全源最短路径模板（邻接矩阵）
int[][] floyd(int n, int[][] edges) {
    int INF = Integer.MAX_VALUE / 2;               // 防溢出
    int[][] dist = new int[n][n];
    for (int[] row : dist) Arrays.fill(row, INF);
    for (int i = 0; i < n; i++) dist[i][i] = 0;
    for (int[] e : edges) {
        dist[e[0]][e[1]] = Math.min(dist[e[0]][e[1]], e[2]);  // 防重边
    }

    // 三重循环：k 为中间点
    for (int k = 0; k < n; k++) {
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (dist[i][k] != INF && dist[k][j] != INF) {
                    dist[i][j] = Math.min(dist[i][j], dist[i][k] + dist[k][j]);
                }
            }
        }
    }
    return dist;
}
```

| 特性 | 说明 |
|------|------|
| 复杂度 | O(V³)（n ≤ 500 可用） |
| 负权 | ✅（无负环即可） |
| 全源 | 一次算完任意两点 |
| 实现 | 三重循环最简单 |

> ⚠️ Floyd 的 `k` 循环必须在最外层——k 是「中间点集合」的 DP 维度；`INF/2` 防止 `INF + w` 溢出（经典坑）。

## 5. 三算法对比与选型

| 维度 | Dijkstra | Bellman-Ford | Floyd |
|------|:---:|:---:|:---:|
| 源点 | 单源 | 单源 | **全源** |
| 复杂度 | O(E log V) | O(VE) | O(V³) |
| 负权 | ❌ | ✅ | ✅ |
| 负环 | ❌ | ✅ 检测 | ❌ |
| 存储 | 邻接表 | 边集 | 邻接矩阵 |
| 实现难度 | ★★★ | ★★ | ★ |
| 适用 | **面试核心** | 负权/K 站限制 | 小图全源 |

```text
选型决策:
  单源 + 正权 → Dijkstra（默认）
  单源 + 负权 → Bellman-Ford
  单源 + 边数限制 → Bellman-Ford（轮数 = 边数）
  全源 + n ≤ 500 → Floyd
  无权图 → BFS（遍历目录）
```

**面试追问**：

| 追问 | 答题要点 |
|------|---------|
| Dijkstra 为什么快？ | 贪心 + 堆取最小（每点一次确定） |
| 为什么不能负权？ | 已确定点可能被负权绕过 |
| 松弛是什么？ | 尝试用 dist[u]+w 更新 dist[v] |
| Bellman-Ford 为什么 n-1 轮？ | 简单路径最多 n-1 条边 |
| 怎么判负环？ | 第 n 轮还能松弛 |
| Floyd 为什么 k 在最外层？ | 中间点集合的 DP 维度 |
| 有重边怎么办？ | 取 min（矩阵）或全存（邻接表） |
| 无向图怎么建？ | 双向插入（与建图一致） |

> 🎯 **核心要点**：最短路径验收——Dijkstra 堆优化模板默写（邻接表 + 小顶堆 + 过期跳过）；Bellman-Ford 的「n-1 轮 + 第 n 轮判环」；Floyd 三重循环（k 外层 + INF/2）；选型一句话：「**正权单源 Dijkstra、负权 Bellman-Ford、全源小图 Floyd、无权 BFS**」；「松弛」是贯穿三者的统一思想。
