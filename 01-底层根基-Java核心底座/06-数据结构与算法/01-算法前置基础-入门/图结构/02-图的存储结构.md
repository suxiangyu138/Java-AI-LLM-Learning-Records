# 02 - 图的存储结构

> 存储决定一切：邻接矩阵查边 O(1) 但空间 O(n²)，邻接表空间 O(V+E) 是稀疏图默认解，边集数组供 Kruskal 等排序场景。本节给出三种存储的 Java 模板与选型决策树。

## 1. 三种存储结构对比

| 维度 | 邻接矩阵 | 邻接表 | 边集数组 |
|------|---------|--------|---------|
| 空间 | O(n²) | O(V + E) | O(E) |
| 查「u-v 是否有边」 | O(1) | O(degree(v)) | O(E)（需排序/哈希） |
| 遍历某点邻居 | O(n) | O(degree) | O(E) |
| 适合 | 稠密图、快速判边 | **稀疏图（默认）** | Kruskal 按权重排序 |
| 建图代码量 | 最少 | 中等 | 最少 |
| LeetCode 使用率 | ~5% | ~90% | ~5%（排序场景） |

> 🎯 **结论先行**：LeetCode 图题 90% 用**邻接表**；邻接矩阵只在「题面小 n（≤1000）且频繁判边」时用；边集数组只在最小生成树/按权排序场景用。

## 2. 邻接矩阵

```java
// 无向无权图
boolean[][] graph = new boolean[n][n];
for (int[] edge : edges) {
    graph[edge[0]][edge[1]] = true;
    graph[edge[1]][edge[0]] = true;    // 无向图对称
}

// 有向带权图
int[][] graph = new int[n][n];
for (int[] row : graph) Arrays.fill(row, Integer.MAX_VALUE);  // 无边 = 极大值
for (int[] edge : edges) {
    graph[edge[0]][edge[1]] = edge[2];
}

// 查边
boolean hasEdge = graph[u][v];
// 遍历 u 的邻居
for (int v = 0; v < n; v++) {
    if (graph[u][v] != Integer.MAX_VALUE) { ... }
}
```

**适用特征**：
- n ≤ 1000 且需要频繁 `graph[u][v]` 判边（如 Floyd 算法）；
- 题目已给 `int[][] graph`（LeetCode 部分题直接给矩阵形式）。

> ⚠️ 陷阱：n = 10⁵ 时邻接矩阵 10¹⁰ 个格子直接 MLE——看见大 n 立即放弃矩阵。

## 3. 邻接表（主力）

### 3.1 无权图模板

```java
// 建图：List<Integer>[] 数组式邻接表
List<Integer>[] graph = new List[n];
for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
for (int[] edge : edges) {
    graph[edge[0]].add(edge[1]);
    graph[edge[1]].add(edge[0]);       // 无向图双向插入
}

// 遍历邻居
for (int next : graph[u]) { ... }
```

### 3.2 带权图模板

```java
// 方式一：int[] {to, weight}
List<int[]>[] graph = new List[n];
for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
for (int[] edge : edges) {             // edge = [from, to, weight]
    graph[edge[0]].add(new int[]{edge[1], edge[2]});
}

// 方式二：内部类 Edge（可读性更好）
class Edge {
    int to, weight;
    Edge(int to, int weight) { this.to = to; this.weight = weight; }
}
List<Edge>[] graph = new List[n];
```

### 3.3 遍历的三种形态

```java
// 遍历全部节点（防不连通）
for (int i = 0; i < n; i++) {
    if (!visited[i]) dfs(graph, i, visited);
}

// 邻接表的「隐藏图」：由规则推导邻居（网格题、状态题）
// 例：迷宫四方向
int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};
for (int[] d : dirs) {
    int nx = x + d[0], ny = y + d[1];
    if (inBound(nx, ny) && grid[nx][ny] == '1') dfs(grid, nx, ny);
}
```

> 💡 **隐藏图**：邻接表不一定要显式建——「邻居由坐标/规则推导」的网格题、状态转移题，直接用方向数组当邻接表，省去建图步骤。

## 4. 边集数组

```java
// 存所有边：int[] {from, to, weight}
int[][] edges = {{0,1,5}, {1,2,2}, {0,2,3}};

// 按权重排序（Kruskal 最小生成树专用）
Arrays.sort(edges, (a, b) -> a[2] - b[2]);
```

| 场景 | 用途 |
|------|------|
| 最小生成树 Kruskal | 按权排序 + 并查集选边（阶段四） |
| 简单的度统计 | 遍历 edges 累加 |
| 题目直接给边数组 | 先转邻接表再解题 |

> ⚠️ 边集数组查邻接是 O(E) 全扫——若同时需要「按点遍历」和「按权排序」，先建邻接表做遍历、边数组做排序，两者并存。

## 5. 存储选型决策树

```text
拿到图题
├── n 很大（>10⁴）？ → 邻接表（无脑选）
├── 需要 graph[u][v] 快速判边？
│   ├── 是，且 n ≤ 1000 → 邻接矩阵（Floyd/稠密图）
│   └── 否 → 邻接表
├── 需要按边权排序（MST）？ → 额外准备边集数组
├── 网格/状态推导邻居？ → 方向数组当邻接表（隐藏图）
└── 节点是字符串？ → Map<String, List<String>> 邻接表
```

**字符串节点建图**：

```java
Map<String, List<String>> graph = new HashMap<>();
for (String[] pair : pairs) {
    graph.computeIfAbsent(pair[0], k -> new ArrayList<>()).add(pair[1]);
    graph.computeIfAbsent(pair[1], k -> new ArrayList<>()).add(pair[0]);
}
```

> 🎯 **核心要点**：存储选型的验收标准——写建图代码前先回答「稀疏还是稠密、判边多不多、要不要按权排序」，三问定存储；邻接表模板（List 数组 + 双向插入）要能闭眼写，因为它决定了后面所有图算法的编码体验。
