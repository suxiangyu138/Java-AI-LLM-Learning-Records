## 4. 核心概念速查

| 概念 | 一句话说明 | 所在模块 |
|------|-----------|---------|
| 顶点/边 | 图的组成：点（Vertex）与连接关系（Edge） | 01 |
| 有向图 vs 无向图 | 边是否有方向；有向图入度/出度分开统计 | 01 |
| 度 | 无向图=相邻边数；有向图=入度+出度 | 01 |
| 路径/环 | 点序列连通则成路径；起点终点相同则成环 | 01 |
| 邻接矩阵 | `boolean[n][n]`，查边 O(1)、遍历 O(n²) | 02 |
| 邻接表 | `List<Integer>[]`，查边 O(度)、遍历 O(V+E) | 02 |
| visited 数组 | 防重复访问，图遍历的**第一铁律** | 03/04 |
| DFS 递归模板 | `dfs(节点) { 标记; for(邻居) 未访问则 dfs }` | 03 |
| BFS 队列模板 | `queue.offer(起点); size 分层扩散` | 04 |
| 无权最短路径 | BFS 首次到达即最短（与 BFS 模块呼应） | 04 |
| 环检测 | DFS 三色标记 / 拓扑排序计数 | 05 |
| 二分图判定 | 相邻节点不同色，DFS/BFS 染色法 | 05 |

> 🎯 **核心要点**：图算法的入门心法就两句——**存储选邻接表（90% 场景）**、**遍历带 visited**。把 DFS/BFS 两个模板写到肌肉记忆，岛屿/迷宫/课程表/腐烂橘子等高频题全部是模板的直接套用；本体系完成后衔接[图论基础](../../03-高频专题模块/专题 11：图/图论基础/00-图专题精要.md)与[图论进阶](../../04-中高级算法专题/专题 5：图论进阶/图论进阶/00-最短路专题精要.md)。
