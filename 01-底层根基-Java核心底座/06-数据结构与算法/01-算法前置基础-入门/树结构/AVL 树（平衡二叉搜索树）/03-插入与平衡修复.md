# 03 - 插入与平衡修复

> 插入 = BST 插入 + 回溯修复：沿路径更新高度、检查平衡因子、按失衡类型旋转——**最多一次旋转**（单旋或双旋），插入即 O(log n)。

## 1. 插入的两步

```text
第一步：按 BST 规则插入（与 701 题完全相同）
第二步：从插入节点回溯到根，逐层：
   ① 更新节点高度
   ② 计算平衡因子
   ③ 失衡 → 按类型旋转（balance 分发）
```

**为什么插入最多一次旋转**：旋转后最小失衡子树的高度恢复为插入前 → 上层祖先的平衡因子自动归位 → 无需继续回溯。

| 步骤 | 操作 | 复杂度 |
|------|------|--------|
| BST 插入 | 递归找空位 | O(log n) |
| 回溯修复 | 沿路径更新高度 + 检查 | O(log n) |
| 旋转 | 最多 1 次（单旋或双旋） | O(1) |
| 总计 | — | **O(log n)** |

> 💡 与红黑树对比：红黑树插入也是最多 2 次旋转（变色多次）；AVL 插入最多 1 次旋转但**回溯要更新每个祖先的高度**（O(log n) 常数步）——两者插入复杂度同阶，常数略有差异。

## 2. 回溯修复流程

```java
// 递归回溯的本质：返回值 = 修复后的子树根
AVLNode insert(AVLNode node, int val) {
    if (node == null) return new AVLNode(val);   // ① 空位落点

    if (val < node.val) {
        node.left = insert(node.left, val);       // ② 递归插入左
    } else if (val > node.val) {
        node.right = insert(node.right, val);     // ② 递归插入右
    } else {
        return node;                              // 重复值：不插入
    }

    updateHeight(node);                           // ③ 更新高度（回溯时）
    return balance(node);                         // ④ 平衡检查 + 旋转
}
```

**递归回溯的顺序**（理解关键）：
1. 递归深入 → 插入新节点；
2. **回溯返回时**：先更新当前节点高度（依赖子树已更新）；
3. 再检查平衡因子 → 失衡则旋转 → 返回新根给父节点挂接。

> ⚠️ **返回挂接**：旋转会改变子树根——`node.left = insert(...)` 的挂接模式确保新根正确接回（与 BST 体系 02 模块的「递归返回挂接」同款）。

## 3. 插入完整实现

```java
// AVL 树插入 + 平衡修复（完整版）
class AVLTree {
    private AVLNode root;

    public void insert(int val) {
        root = insert(root, val);
    }

    private AVLNode insert(AVLNode node, int val) {
        if (node == null) return new AVLNode(val);
        if (val < node.val) node.left = insert(node.left, val);
        else if (val > node.val) node.right = insert(node.right, val);
        else return node;

        updateHeight(node);
        return balance(node);          // 核心：平衡检查 + 旋转
    }

    private AVLNode balance(AVLNode node) {
        int bf = balanceFactor(node);  // 左高 - 右高
        if (bf > 1) {
            if (balanceFactor(node.left) >= 0) {
                return rotateRight(node);        // LL
            } else {
                node.left = rotateLeft(node.left);
                return rotateRight(node);        // LR
            }
        } else if (bf < -1) {
            if (balanceFactor(node.right) <= 0) {
                return rotateLeft(node);         // RR
            } else {
                node.right = rotateRight(node.right);
                return rotateLeft(node);         // RL
            }
        }
        return node;
    }

    private int height(AVLNode n) { return n == null ? 0 : n.height; }
    private int balanceFactor(AVLNode n) { return height(n.left) - height(n.right); }
    private void updateHeight(AVLNode n) {
        n.height = Math.max(height(n.left), height(n.right)) + 1;
    }
    // rotateRight / rotateLeft 见 02 模块
}
```

## 4. 插入修复示例推演

**示例**：依次插入 10, 5, 2（触发 LL 型右旋）。

```text
插入 10:   10
插入 5:    10           插入 2:    10     ← BF=+2 失衡（LL 型）
          /                        /         最小失衡子树根 = 10
         5                       5
                                 /
                                2
右旋 10:       5
              / \
             2   10   ✓ 平衡（一次旋转完成）
```

**示例**：依次插入 10, 5, 8（触发 LR 型双旋）。

```text
插入 10, 5:      10
                /
               5
插入 8:         10      ← BF=+2，左孩子 5 的 BF=-1（右高）→ LR 型
              /
             5
              \
               8
① 左旋 5:     10        ② 右旋 10:      8
             /                        / \
            8                        5  10
           /
          5
```

> 💡 手算推演的价值：把「背类型」变成「画出来」——插入新节点 → 标 BF → 找失衡根 → 判断同向/异向 → 旋转。

## 5. 插入速查表

| 场景 | 判定 | 操作 |
|------|------|------|
| 插入后无失衡 | 所有祖先 BF ∈ {-1,0,1} | 只需更新高度 |
| LL 型 | 失衡根 BF=+2、左孩子 BF ≥ 0 | 右旋失衡根 |
| RR 型 | 失衡根 BF=-2、右孩子 BF ≤ 0 | 左旋失衡根 |
| LR 型 | 失衡根 BF=+2、左孩子 BF < 0 | 左旋孩子 → 右旋根 |
| RL 型 | 失衡根 BF=-2、右孩子 BF > 0 | 右旋孩子 → 左旋根 |
| 重复值 | val == node.val | 不插入（或计数） |

**面试追问**：

| 追问 | 答题要点 |
|------|---------|
| 插入为什么最多一次旋转？ | 旋转后子树高度复原 → 上层自动平衡 |
| 平衡因子怎么更新？ | 回溯时 max(左,右)+1 |
| 递归版 vs 迭代版？ | 递归天然回溯；迭代需 parent 栈 |
| 最小失衡子树在哪？ | 从插入点向上第一个 BF=±2 的祖先 |

> 🎯 **核心要点**：插入验收——完整 insert 方法默写（BST 插入 + 回溯更新高度 + balance 分发）；理解「递归返回挂接」与「旋转后高度复原 → 一次旋转完成」两个关键；能手算推演 LL/LR 两种典型场景；迭代版（parent 栈回溯）作为进阶实现。删除（回溯到根、可能多次旋转）见 04 模块。
