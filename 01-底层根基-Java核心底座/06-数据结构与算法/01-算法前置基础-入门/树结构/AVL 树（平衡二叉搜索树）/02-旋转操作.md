# 02 - 旋转操作

> AVL 修复的全部武器：左旋、右旋、左右双旋、右左双旋——四种旋转保持 BST 性质、恢复平衡。旋转是树的「局部整形手术」，必须闭眼可画。

## 1. 旋转的本质

**旋转（Rotation）**：局部调整三个节点（及子树）的父子关系——**保持中序序列不变**（BST 性质）的同时降低高度。

```text
右旋前:                  右旋后:
      A                    B
     / \                  / \
    B   T3               T1  A
   / \                      / \
  T1 T2                   T2  T3

中序: T1 B T2 A T3     =    T1 B T2 A T3  ✓ 不变
高度: 降低 1 层（B 上提）
```

| 要点 | 说明 |
|------|------|
| 中序不变 | 旋转不破坏 BST 有序性（核心性质） |
| 局部性 | 只影响 3 个节点 + 子树挂接 |
| 高度 | 单旋降低 1 层 |
| 方向 | 右旋 = 左孩子上提；左旋 = 右孩子上提 |

> 💡 旋转是**对称操作**：右旋与左旋完全镜像——记住一个，另一个翻过来即可。

## 2. 右旋与左旋

### 2.1 右旋（LL 型修复）

```java
// 右旋：B（A 的左孩子）上提为根，A 变为 B 的右孩子
AVLNode rotateRight(AVLNode A) {
    AVLNode B = A.left;            // B 上提
    A.left = B.right;              // B 的右子树过继给 A 的左
    B.right = A;                   // A 变为 B 的右孩子
    updateHeight(A);               // 先更新下层
    updateHeight(B);               // 再更新上层
    return B;                      // 返回新子树根
}
```

```text
        A                B
       / \              / \
      B  T3    →       T1  A
     / \                  / \
    T1 T2               T2  T3
```

### 2.2 左旋（RR 型修复）

```java
// 左旋：完全镜像（C 上提，A 变为 C 的左孩子）
AVLNode rotateLeft(AVLNode A) {
    AVLNode C = A.right;
    A.right = C.left;              // C 的左子树过继
    C.left = A;
    updateHeight(A);
    updateHeight(C);
    return C;
}
```

```text
    A                    C
   / \                  / \
  T1  C      →         A  T3
     / \              / \
    T2 T3            T1  T2
```

> ⚠️ **更新的顺序**：先更新下沉节点（A），再更新上提节点（B/C）——**底层先算、上层后算**（依赖关系）。

## 3. 双旋：LR 与 RL

**LR 型**（BF=+2，左孩子的右子树高）：折线 → **先左旋左孩子变直线 → 再右旋失衡节点**。

```java
// LR 型双旋：左旋 B → 右旋 A
AVLNode rotateLR(AVLNode A) {
    A.left = rotateLeft(A.left);   // ① 先左旋左孩子（B 变 LL 形态）
    return rotateRight(A);         // ② 再右旋失衡节点（LL 修复）
}
```

```text
LR 型:               ① 左旋 B:            ② 右旋 A:
      A                  A                   C
     /                 /                   / \
    B                C                    B   A
     \              / \                  / \ / \
      C            B  T3                T1 T2 T3 T4
     / \
    T1  T2
```

**RL 型**（BF=-2，右孩子的左子树高）：镜像 → **先右旋右孩子 → 再左旋失衡节点**。

```java
AVLNode rotateRL(AVLNode A) {
    A.right = rotateRight(A.right);  // ① 先右旋右孩子
    return rotateLeft(A);            // ② 再左旋失衡节点
}
```

> 💡 **双旋 = 两次单旋**：第一次把折线掰直（变成 LL/RR），第二次按单旋修复——**掌握单旋，双旋自动会**。

## 4. 四种旋转的判定表

| 失衡类型 | 失衡节点 A 的 BF | A 孩子的 BF | 旋转 | 旋转次数 |
|:---:|:---:|:---:|------|:---:|
| LL | +2 | 左孩子 ≥ 0 | 右旋 A | 1 |
| RR | -2 | 右孩子 ≤ 0 | 左旋 A | 1 |
| LR | +2 | 左孩子 < 0 | 左旋左孩子 + 右旋 A | 2 |
| RL | -2 | 右孩子 > 0 | 右旋右孩子 + 左旋 A | 2 |

**判定三步**：
1. 找最小失衡子树根 A（BF = ±2）；
2. 看 **A 的哪侧孩子高**（左/右）；
3. 看 **该孩子的哪侧子树高**（左/右）→ 同向单旋、异向双旋。

## 5. 旋转模板

```java
// 四种旋转的统一入口：根据失衡类型分发
AVLNode balance(AVLNode node) {
    int bf = balanceFactor(node);            // 左高 - 右高
    if (bf > 1) {                            // 左子树失衡
        if (balanceFactor(node.left) >= 0) {
            return rotateRight(node);        // LL
        } else {
            return rotateLR(node);           // LR
        }
    } else if (bf < -1) {                    // 右子树失衡
        if (balanceFactor(node.right) <= 0) {
            return rotateLeft(node);         // RR
        } else {
            return rotateRL(node);           // RL
        }
    }
    return node;                             // 平衡
}
```

> 🎯 **核心要点**：旋转验收——右旋/左旋单旋默写（含高度更新顺序）；LR/RL 双旋 = 两次单旋的组合；「同向单旋、异向双旋」口诀 + 三步判定法（找失衡根 → 看孩子侧 → 看孙侧）；旋转保持中序不变的性质是面试必答点。插入/删除如何调用 balance 见 03/04 模块。
