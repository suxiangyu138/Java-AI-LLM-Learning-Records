# 00 - AVL 树知识体系总览

## 4. 核心概念速查

| 概念 | 一句话说明 | 所在模块 |
|------|-----------|---------|
| 平衡因子 | 左高 - 右高（-1/0/1 为平衡） | 01 |
| 最小失衡子树 | 插入/删除后第一个失衡的祖先 | 01 |
| LL 型 | 失衡节点左孩子的左子树插入 | 02 |
| LR 型 | 左孩子的右子树插入（先左后右双旋） | 02 |
| RR 型 | 右孩子的右子树插入 | 02 |
| RL 型 | 右孩子的左子树插入（先右后左双旋） | 02 |
| 插入修复 | 沿路径回溯，一次旋转即可 | 03 |
| 删除修复 | 回溯到根，最多 O(log n) 次 | 04 |
| 树高 | ≤ 1.44·log₂(n+1)（最矮平衡树） | 01/05 |
| 与红黑树 | AVL 查询快、红黑写快 | 05 |

> 🎯 **核心要点**：AVL 的价值 = **最严格的平衡（高差 ≤ 1）→ 最矮的树 → 最快的查询**；代价是删除修复可能 O(log n) 次旋转（红黑树 ≤ 3 次）——「读多写少选 AVL、写多读少选红黑」；四种失衡类型（LL/RR/LR/RL）是全部修复逻辑的骨架，旋转模板是肌肉记忆。
