## 1. AVL 树的定义

**AVL 树**：满足**任意节点左右子树高度差 ≤ 1** 的二叉搜索树（1962 年 Adelson-Velsky & Landis 发明，第一个自平衡 BST）。

```text
平衡 ✓:                     失衡 ✗:
       10                       10
      /  \                     /  \
     5   15                   5   15
    / \                      /      \
   2   7                    2       20
                          /
                         1
  任意节点高差 ≤ 1       10 的左高 3 右高 2 ✓
                         15 的左高 0 右高 2 ✗ 失衡！
```

| 性质 | 值 |
|------|-----|
| 平衡条件 | 任意节点 \|左高 - 右高\| ≤ 1 |
| 树高上界 | ≤ 1.44·log₂(n+1)（**最矮的平衡 BST**） |
| 查找 | O(log n) 严格保证 |
| 与 BST 关系 | 完全兼容（平衡化不改变有序性） |

> 💡 与红黑树的本质区别：AVL 是**高度平衡**（高差 ≤ 1），红黑树是**黑色平衡**（最长 ≤ 2×最短）——AVL 更严格 → 树更矮 → 查询更快；代价是旋转更频繁（05 模块详述）。

## 2. 平衡因子

**平衡因子（Balance Factor）**：`BF = 左子树高度 - 右子树高度`。

```java
// 平衡因子 = 左高 - 右高
int balanceFactor(TreeNode node) {
    return height(node.left) - height(node.right);
}

// 节点同时维护 height 字段（插入/删除后更新）
class AVLNode {
    int val;
    AVLNode left, right;
    int height;              // 以该节点为根的子树高度
}

// 高度更新：max(左, 右) + 1
void updateHeight(AVLNode node) {
    node.height = Math.max(height(node.left), height(node.right)) + 1;
}
```

| BF 值 | 状态 |
|:---:|------|
| -1 / 0 / 1 | ✅ 平衡 |
| 2 或 -2 | ⚠️ **失衡**（需旋转修复） |
| > 2 或 < -2 | 不可能（每次插入后立即修复） |

> ⚠️ **失衡判定只看 -2/2**：AVL 的修复是「发现即修」——任何时刻 BF 只可能到达 ±2（不会更深），所以旋转修复永远只针对 ±2 的节点。

## 3. 四种失衡类型

失衡节点 BF = ±2 时，按「失衡方向 + 插入方向」分四种：

```text
LL 型（BF=+2，左孩子的左子树高）:       RR 型（BF=-2，右孩子的右子树高）:
        A(+2)                              A(-2)
       /                                 /    \
      B(+1)                             B      C(-1)
     /                                         \
    C                                          D

LR 型（BF=+2，左孩子的右子树高）:       RL 型（BF=-2，右孩子的左子树高）:
        A(+2)                              A(-2)
       /                                      \
      B(-1)                                   B(+1)
        \                                    /
         C                                  C
```

| 类型 | 判定（失衡节点 A） | 修复 |
|------|-------------------|------|
| LL | A.BF=+2 且 A.left.BF ≥ 0 | **右旋 A**（单旋） |
| RR | A.BF=-2 且 A.right.BF ≤ 0 | **左旋 A**（单旋） |
| LR | A.BF=+2 且 A.left.BF < 0 | **左旋 A.left → 右旋 A**（双旋） |
| RL | A.BF=-2 且 A.right.BF > 0 | **右旋 A.right → 左旋 A**（双旋） |

> 🎯 **记忆口诀**：「**同向单旋、异向双旋**」——LL/RR 是直线（同向）单旋转；LR/RL 是折线（异向）双旋转。

## 4. 最小失衡子树

**最小失衡子树**：插入/删除后，**从新节点向上回溯，第一个 BF = ±2 的祖先**——旋转只作用在这棵子树上，旋转后整棵树恢复平衡。

```text
插入后:
        A          ← 第一个失衡（最小失衡子树根）
       / \
      B   E
     / \
    C   D
   /
  X  ← 新插入

修复: 只对 A 子树旋转 → 整棵树平衡（其他子树未受影响）
```

**为什么只需处理最小失衡子树**：
- 旋转是**局部操作**（子树根变换），不影响其他部分；
- 修复后子树高度恢复原状 → 祖先的平衡因子随之恢复 → **无需继续向上回溯**（插入场景）。

> ⚠️ 插入修复「一次旋转即完成」的秘密就在这：旋转后子树高度 = 插入前高度 → 上层全部自动平衡；**删除修复则不同**（旋转后高度可能仍少 1，需继续回溯，04 模块）。

### 5.1 树高上界的证明（斐波那契递推）

**定理**：高度 h 的 AVL 树最少节点数满足 F(h) = F(h-1) + F(h-2) + 1（斐波那契式）。

```text
证明思路（面试口述版）:
① 高度 h 的最少节点 AVL：根 + 两棵子树
   为最小化节点，子树高度取 h-1 和 h-2（高差 ≤ 1 且尽量失衡）
② F(h) = F(h-1) + F(h-2) + 1
   F(0) = 1, F(1) = 2
③ 解出: F(h) ≈ φ^(h+2)/√5 - 1（φ 黄金比例）
④ 反推: h ≤ log_φ(n) ≈ 1.44·log₂(n+1)  ✓
```

> 🎯 这是平衡树面试的终极证明题——答出「斐波那契递推 + 黄金比例」即满分。

### 5.2 高度 vs 深度的快速验证

| 判断 | 方法 |
|------|------|
| 单节点树 | 高度 0（边）或 1（节点）——按题面约定 |
| 空树 | 高度 0 |
| 快速判平衡 | 递归计算左右高差，任意点 >1 即失衡 |

> 🎯 **核心要点**：本节验收——能计算任意节点的 BF 并判定失衡；能画出四种失衡类型的树形；理解「最小失衡子树」是修复的唯一作用点；记住「插入一次旋转、删除可能多次」的关键差异；AVL 树高 1.44·log₂(n+1) 的证明（高度 h 的 AVL 最少节点数 = 斐波那契式递推 F(h) = F(h-1) + F(h-2) + 1）是进阶面试题。
