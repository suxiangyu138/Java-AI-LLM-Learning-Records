## 4. 核心概念速查

| 概念 | 一句话说明 | 所在模块 |
|------|-----------|---------|
| 红黑树 | 带颜色标记的平衡 BST，最长路径 ≤ 2×最短 | 01 |
| 五大性质 | 根黑/叶黑/红子黑/黑高相等/节点红或黑 | 01 |
| 黑高 | 从节点到叶子的黑色节点数（不含自己） | 01 |
| 2-3-4 树 | 红黑树的前身（等价变形） | 02 |
| 红节点 | 2-3-4 树中「与父节点同键」的表示 | 02 |
| 旋转 | 左旋/右旋：改变局部结构保持 BST 性质 | 03 |
| 变色 | 红黑互换，配合旋转修复平衡 | 03 |
| 插入修复 | 叔叔红→变色；叔叔黑→旋转 | 03 |
| 双黑 | 删除修复的核心概念（缺失的黑色） | 04 |
| 树化阈值 | HashMap 链表 ≥ 8 且容量 ≥ 64 转红黑树 | 05 |
| 查找效率 | O(log n) 稳定（最坏有保证） | 06 |

> 🎯 **核心要点**：红黑树的价值 = **BST 的 O(h) 被 h ≤ 2·黑高 ≤ 2·log₂(n+1) 锁死**——任何操作最坏 O(log n)；学习路径建议「先 2-3-4 树后红黑树」（等价关系让插入/删除的修复逻辑从「背情形」变成「推逻辑」）；面试通常考性质与对比，不考完整手写。BST 基础见[二叉搜索树](../二叉搜索树 BST（二叉排序树）/00-二叉搜索树 BST 知识体系总览.md)。
