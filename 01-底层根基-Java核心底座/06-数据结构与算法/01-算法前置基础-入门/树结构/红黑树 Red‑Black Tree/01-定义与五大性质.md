## 1. 红黑树的定义

**红黑树（Red-Black Tree）**：每个节点带红/黑颜色的**平衡二叉搜索树**，满足五条性质。

```text
             13(黑)
            /      \
         8(红)     17(红)
        /    \     /    \
     1(黑) 11(黑) 15(黑) 25(黑)
      \           /      /
     6(红)     15(黑) 22(红)
```

> 💡 红黑树的三个身份：① 二叉搜索树（所有 BST 性质成立）；② 颜色标记的平衡树；③ 2-3-4 树的二叉树表示（02 模块）。

## 2. 五大性质详解

| # | 性质 | 含义 | 作用 |
|---|------|------|------|
| 1 | 每个节点是红色或黑色 | 颜色二值 | 基础 |
| 2 | 根是黑色 | 根固定黑 | 约束 |
| 3 | 所有叶子（NIL）是黑色 | 空节点视为黑叶子 | 黑高统一 |
| 4 | 红节点的两个子节点都是黑色 | **红色不相邻** | 限制连续红 |
| 5 | 从任一节点到其所有后代叶子的路径含**相同数量**的黑节点 | 黑高相等 | **平衡核心** |

**性质 4 + 5 的组合拳**：
- 性质 5 保证「每条路径黑节点数相同」；
- 性质 4 保证「红色不连续」→ 红节点最多占一半；
- 合起来：**最长路径（红黑交替）≤ 2 × 最短路径（全黑）**。

> ⚠️ 常见误解：红黑树**不是** AVL 式的高度平衡（高度差 ≤ 1），而是「黑色平衡」——因此它的旋转次数少于 AVL，适合**插入删除频繁**的场景（这是它胜过 AVL 的关键，06 模块详述）。

## 3. 黑高与树高上界

**黑高（black-height）bh(x)**：从节点 x 到其叶子路径上的黑色节点数（**不含 x 本身**）。

```java
// 黑高计算（概念示意）
int blackHeight(TreeNode node) {
    if (node == null) return 0;              // NIL 叶为黑
    return node.isBlack ? 1 + blackHeight(node.left)
                        : blackHeight(node.left);
}
```

**核心定理**：含 n 个内部节点的红黑树，高度 h ≤ 2·log₂(n+1)。

```text
证明思路（面试口述版）：
① 性质 5 → 所有路径黑高相等 = bh(root)
② 性质 4 → 红不连续 → 红节点数 ≤ 黑节点数
   → 总节点 n ≥ 2^bh(root) - 1（全黑路径的最短树）
③ 路径最长 = 黑红交替 = 2 × bh(root)
④ 联立：h ≤ 2·bh(root) ≤ 2·log₂(n+1)  ✓
```

> 🎯 **定理的意义**：BST 的 O(h) 在红黑树中变成 **O(log n) 最坏有保证**——无论插入顺序如何（有序插入也不退化），这正是工程界选它的根本原因。

## 4. 为什么是「最长 ≤ 2×最短」

```text
最短路径（全黑）:    13(黑) → 8(黑) → 1(黑) → NIL      黑高 = 3
最长路径（红黑交替）: 13(黑) → 17(红) → 15(黑) → ...    黑高 = 3，但红黑交替 → 长度可达 6

结论: 最长 = 2 × 黑高 = 2 × 最短（性质 4 限制红色不连续）
```

**直观理解**：黑色节点数固定（性质 5），红色不能相邻（性质 4）——红色最多「插空」在黑色之间，路径长度最多翻倍。

## 5. 性质速查表

| 说法 | 含义 | 关联 |
|------|------|------|
| "红色不相邻" | 性质 4：红节点孩子必黑 | 插入修复 |
| "黑高相等" | 性质 5：平衡的核心 | 删除修复 |
| "NIL 黑叶子" | 空指针视为黑节点 | 性质 3 |
| "最长 2×最短" | 树高 O(log n) 的直觉 | 面试必答 |
| "黑色平衡" | 非高度平衡（区别于 AVL） | 06 对比 |
| "红黑树是 2-3-4 树" | 等价变形（02 模块） | 理解钥匙 |

### 5.1 五性质的记忆与验证

**记忆口诀**：「**根黑、叶黑、红子黑、黑高同、非红即黑**」——五句顺口溜覆盖全部性质。

**性质验证示例**（对照第 1 节示例树）：

```text
13(黑) 根黑 ✓
1(黑) 11(黑) 15(黑) 25(黑) 叶子黑 ✓（NIL 也黑）
8(红) 的两个孩子 1(黑) 11(黑) 黑 ✓（红色不相邻）
任意节点到叶子的黑节点数相同 ✓（性质 5，构造时保证）
```

### 5.2 红黑树与 2-3-4 树的黑高呼应

| 红黑树 | 2-3-4 树 |
|--------|---------|
| 黑高 bh | 树高（叶子层数） |
| 红节点 | 多键节点内的附加键 |
| 最长路径 ≤ 2×最短 | 树高 ≤ 2×bh 的另一种表达 |

> 💡 验证技巧：把红黑树「合并红孩子」还原成 2-3-4 树，若所有叶子同深度则性质 5 成立——这是面试手写验证的快捷法（详见 02 模块）。

### 5.3 常见面试追问

| 追问 | 答题要点 |
|------|---------|
| 红黑树 vs AVL 谁更矮？ | AVL（高度平衡 ≤ 1）；红黑树允许 2× 差距 |
| 为什么红黑树允许「不完美平衡」？ | 换来更少旋转（写操作快）——工程权衡 |
| 黑高和树高什么关系？ | 树高 ≤ 2×黑高 ≤ 2·log₂(n+1) |
| 红黑树查任意值？ | O(log n)（BST 性质保证） |
| 性质 4 为什么叫「红色不相邻」？ | 红节点孩子必黑——防止路径过长 |

### 5.4 五性质记忆卡

```text
性质速查（面试 30 秒默写）:
  1. 红或黑            —— 每个节点两种颜色之一
  2. 根黑              —— 根节点固定黑色
  3. 叶黑（NIL）       —— 空指针视为黑叶子
  4. 红子黑            —— 红节点孩子必黑（红色不相邻）
  5. 黑高相等          —— 任意节点到叶子的黑节点数相同

推论: 最长路径 ≤ 2 × 最短路径 → 树高 O(log n)
```

> 🎯 **核心要点**：本节验收——五性质默写（根黑/叶黑/红子黑/黑高同/非红即黑）；「最长 ≤ 2×最短」的推导（性质 4+5 组合）；树高上界 2·log₂(n+1) 的证明思路；「黑色平衡 ≠ 高度平衡」是红黑树与 AVL 的本质区别（AVL 见姊妹篇）。五条性质如何驱动插入/删除修复，见 03/04 模块。
