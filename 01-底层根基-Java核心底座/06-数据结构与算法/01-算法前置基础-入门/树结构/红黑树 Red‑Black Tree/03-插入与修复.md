# 03 - 插入与修复

> 插入 = BST 插入 + 红节点 + 最多两次旋转：叔叔红变色上提、叔叔黑旋转收编——用 2-3-4 树视角把三种修复情形推导出来，而不是背下来。

## 1. 插入的两步

```text
第一步：按 BST 规则插入，新节点染红色
  （红色 = 「附加键」→ 不破坏黑高，最多破坏性质 4 红色不相邻）
第二步：自底向上修复性质 4（父红则修）
```

**为什么新节点是红色**：染黑会改变黑高（破坏性质 5，最难修）；染红只可能破坏性质 4（红色相邻），修复成本低。

**只可能破坏性质 4**——父节点为红时连续两个红。修复按**叔叔（父的兄弟）颜色**分两类：

```text
插入后违规点：新红节点 z，父 p 红（祖父 g 必黑）

情形 1: 叔叔 u 红 → 变色上提
情形 2: 叔叔 u 黑 + z 是之字形（p 是 g 的右子、z 是 p 的左子等）
情形 3: 叔叔 u 黑 + z 是直线形
```

## 2. 修复情形一：叔叔是红色

**等价视角**：父+叔+祖父构成一个 4-节点，插入溢出 → **分裂**：中键（祖父）上提，两翼变黑。

```java
// 情形 1：叔叔红 → 父、叔变黑，祖父变红，问题向上传递
// 等价：4-节点分裂，中键上移（2-3-4 树视角）
if (uncle != null && uncle.isRed) {
    parent.isRed = false;        // 父变黑
    uncle.isRed = false;         // 叔变黑
    grandparent.isRed = true;    // 祖父变红（继续检查祖父的父）
    z = grandparent;             // 问题上升到祖父
}
```

```text
        g(黑)                        g(红)          ← 上提变红
       /    \                       /    \
    p(红)  u(红)    ────▶        p(黑)  u(黑)      ← 两翼变黑
    /                             /
 z(红)                          z(红)
```

> ⚠️ 变色后祖父变红——如果祖父的父也是红，违规**向上传递**，循环检查直到根（根强制染黑收尾）。

## 3. 修复情形二/三：叔叔是黑色

**等价视角**：3-节点吸收新键 → 旋转把「附加键」整理成直线，再旋转+变色收编。

**情形 2 → 情形 3**（之字形先转直线）：

```java
// 情形 2：叔叔黑 + 之字形 → 对父旋转，变成直线形
if (z == parent.right && parent == grandparent.left) {
    rotateLeft(parent);          // 左旋父
    z = parent;                  // 更新 z 为原父
    parent = z.parent;           // 父 = 祖父
}
// 对称情形：z == parent.left && parent == grandparent.right → rotateRight(parent)
```

**情形 3**（直线形 → 旋转 + 变色）：

```java
// 情形 3：叔叔黑 + 直线形 → 旋转祖父 + 变色
rotateRight(grandparent);        // 右旋祖父（把父提上来）
parent.isRed = false;            // 父变黑
grandparent.isRed = true;        // 祖父变红
```

```text
情形 2（之字形）:           情形 3（直线）:
        g(黑)                     g(黑)               p(黑)
       /                        /                    /   \
    p(红)          ──▶        p(红)   ──▶           z  g(红)
       \                        /
      z(红)                   z(红)
  先左旋 p                 再右旋 g + 变色
```

## 4. 插入完整实现

```java
// 红黑树插入修复（JDK TreeMap 风格，完整版）
void fixAfterInsertion(Node z) {
    z.color = RED;
    while (z != null && z != root && z.parent.color == RED) {
        Node parent = z.parent;
        Node grandparent = parent.parent;
        if (parent == grandparent.left) {                 // 父在左
            Node uncle = grandparent.right;
            if (uncle != null && uncle.color == RED) {    // 情形 1：叔叔红
                parent.color = BLACK;
                uncle.color = BLACK;
                grandparent.color = RED;
                z = grandparent;
            } else {
                if (z == parent.right) {                  // 情形 2：之字形
                    rotateLeft(parent);
                    z = parent;
                    parent = z.parent;
                }
                rotateRight(grandparent);                 // 情形 3：直线
                parent.color = BLACK;                     // 变色收尾
                grandparent.color = RED;
            }
        } else {                                          // 父在右（对称）
            // ... 镜像逻辑 ...
        }
    }
    root.color = BLACK;                                   // 性质 2：根永远黑
}
```

**旋转实现**：

```java
void rotateLeft(Node x) {           // 左旋：x 的右子 y 提上来
    Node y = x.right;
    x.right = y.left;               // y 的左子树过继给 x
    if (y.left != null) y.left.parent = x;
    y.parent = x.parent;
    if (x.parent == null) root = y;
    else if (x == x.parent.left) x.parent.left = y;
    else x.parent.right = y;
    y.left = x;
    x.parent = y;
}
// rotateRight 完全对称
```

## 5. 插入修复速查表

| 情形 | 条件（父在左为例） | 操作 | 2-3-4 树视角 |
|------|-------------------|------|-------------|
| 1 | 叔叔红 | 父/叔变黑、祖父变红、上移 | 4-节点分裂 |
| 2 | 叔叔黑 + 之字形 | 先旋父成直线 | 调整形态 |
| 3 | 叔叔黑 + 直线 | 旋祖父 + 父黑祖父红 | 3-节点吸收 |

| 性质 | 插入是否破坏 | 修复手段 |
|------|:---:|---------|
| 性质 2 根黑 | 可能（上移变红） | 收尾强制染黑 |
| 性质 4 红不相邻 | **主要破坏** | 旋转 + 变色 |
| 性质 5 黑高 | 从不破坏（染红插入） | 无需处理 |

> 🎯 **核心要点**：插入验收——能画三种情形的旋转变色过程；理解「新节点染红 → 只可能破坏性质 4 → 按叔叔颜色修复」的推理链；叔叔红 = 变色上提、叔叔黑 = 旋转收编的两思想（2-3-4 树分裂/吸收）；最多 **2 次旋转**（情形 2→3 各一次）+ O(log n) 次变色。删除（更复杂）见 04 模块。
