## 4. 核心概念速查

| 概念 | 一句话说明 | 所在模块 |
|------|-----------|---------|
| 二叉树 | 每个节点最多两个子节点的树 | 01 |
| 满二叉树 | 每层都满（节点数 2^h - 1） | 01 |
| 完全二叉树 | 除最后一层外全满、末层靠左（堆的形态） | 01 |
| 平衡二叉树 | 任意节点左右子树高度差 ≤ 1 | 01/05 |
| 前/中/后序 | 根左右 / 左根右 / 左右根（递归三兄弟） | 02 |
| 层序 | 逐层从左到右（BFS，队列实现） | 02 |
| 递归模板 | `递归(子树) = 处理根 + 递归左 + 递归右` | 02 |
| 迭代模板 | 显式栈模拟递归（前序最简单） | 02 |
| 序列化 | 树 ↔ 字符串的双向转换（用 null 标记空位） | 03 |
| 路径总和 | 根到叶的和、任意起点终点路径（前缀和） | 04 |
| LCA | 最近公共祖先：递归「左右都有就是答案」 | 05 |
| 树形 DP | 返回值 = 子树信息（高度/直径等） | 05/专题 4 |

> 🎯 **核心要点**：二叉树的黄金公式——**遍历模板 × 业务逻辑 = 90% 二叉树题**；递归三问（终止条件、子问题、返回值）是树题解法的统一框架；「先写递归再背迭代」是遍历的学习顺序；本体系完成后衔接[二叉搜索树](../二叉搜索树 BST（二叉排序树）/)与[专题 4 进阶](../../../03-高频专题模块/专题 4：树（二叉树为主）/二叉树/00-二叉树专题精要.md)。
