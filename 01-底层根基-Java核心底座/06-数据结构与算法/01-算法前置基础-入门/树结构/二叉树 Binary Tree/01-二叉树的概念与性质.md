## 1. 二叉树的定义

**二叉树（Binary Tree）**：每个节点**最多**有两个子节点（左子/右子）的有序树。

```java
public class TreeNode {           // LeetCode 标准定义
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode() {}
    TreeNode(int val) { this.val = val; }
    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val; this.left = left; this.right = right;
    }
}
```

**关键术语**：

| 术语 | 含义 |
|------|------|
| 根节点 | 没有父节点的节点（唯一） |
| 叶节点 | 没有子节点的节点 |
| 父子/兄弟 | 直接相连 / 同父节点 |
| 祖先/子孙 | 路径上的节点关系 |
| 高度 | 从节点到最远叶子的边数（树高 = 根的高度） |
| 深度 | 从根到节点的边数 |
| 层 | 深度 + 1（根在第 1 层） |

> ⚠️ **高度 vs 深度的歧义**：有的教材把「只有一个节点的树高」记为 0，有的记为 1——LeetCode 通常按「节点数」计（空树高度 0，单节点高度 1）。做题时先看题面约定。

## 2. 五种特殊形态

| 形态 | 定义 | 节点数/高度 | 典型场景 |
|------|------|------------|---------|
| 斜树 | 所有节点只有一侧子节点 | n = h + 1 | 最坏情况（退化为链表） |
| 满二叉树 | 每层都满 | n = 2^(h+1) - 1 | 理论最优形态 |
| 完全二叉树 | 除末层外全满、末层靠左 | 2^h ≤ n ≤ 2^(h+1)-1 | **堆的形态**（[堆 Heap](../堆 Heap/)） |
| 平衡二叉树 | 任意节点左右子树高度差 ≤ 1 | 高 ~ log n | AVL、红黑树（性能保证） |
| 二叉搜索树 BST | 左 < 根 < 右 | 有序，平均 log n | 查找/有序结构 |

```text
满二叉树（h=2）:      完全二叉树（末层靠左）:
       1                    1
      / \                  / \
     2   3                2   3
    / \ / \              / \
   4  5 6  7            4   5

二叉搜索树:            斜树（最坏）:
       5                    1
      / \                    \
     3   8                    2
    / \                        \
   2   4                        3
```

## 3. 核心性质公式

| # | 性质 | 公式 | 用途 |
|---|------|------|------|
| 1 | 第 i 层最多节点数 | 2^(i-1) | 层容量估计 |
| 2 | 高度 h 的树最多节点数 | 2^h - 1（h 按层数计） | 满二叉树节点数 |
| 3 | 节点数 n 的最小高度 | ⌈log₂(n+1)⌉ | 复杂度下界 |
| 4 | 叶节点与度为 2 的节点 | 叶数 = 二度节点数 + 1 | 推理题 |
| 5 | 完全二叉树父子下标 | left=2i, right=2i+1, parent=i/2（1 基） | 堆/数组存储 |
| 6 | 边数 | 边 = n - 1 | 连通性 |

**性质 4 的推导**（面试口述题）：设 n₀=叶子数、n₁=单子节点数、n₂=双子节点数：
- 总节点：n₀ + n₁ + n₂ = n
- 总边数：n - 1 = n₁ + 2n₂
- 联立：**n₀ = n₂ + 1** ✓

> 💡 性质 4 的经典考题：「一棵二叉树有 8 个度为 2 的节点，问叶子数」→ 答案 9。

## 4. 存储方式

### 4.1 链式存储（LeetCode 默认）

```java
// 节点对象 + 左右指针（见第 1 节 TreeNode）
// 特点：直观、支持任意形态；空间 O(n) + 指针开销
```

### 4.2 顺序存储（数组）

```java
// 完全二叉树/堆专用：父子下标数学关系
// 下标 1 基：left = 2i, right = 2i+1, parent = i/2
//       1
//      / \        → 数组 [_, 1, 2, 3, 4, 5]
//     2   3        下标:   0  1  2  3  4  5
//    / \
//   4   5
int left = 2 * i, right = 2 * i + 1, parent = i / 2;
```

| 维度 | 链式 | 顺序（数组） |
|------|------|-------------|
| 空间 | O(n) + 指针 | O(n)，无指针开销 |
| 随机访问 | 需遍历 | 按下标 O(1) |
| 适用 | **任意二叉树（通用）** | 完全二叉树/堆/线段树 |

> ⚠️ 斜树用数组存储会浪费大量空位（每层 1 个节点却占 2^i 空间）——只有完全二叉树适合顺序存储。
