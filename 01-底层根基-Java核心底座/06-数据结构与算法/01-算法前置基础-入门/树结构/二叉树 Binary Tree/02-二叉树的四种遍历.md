## 1. 遍历的本质

**遍历 = 访问每个节点恰好一次**。区别只在「访问根的时机」：

```text
       1
      / \
     2   3
    / \
   4   5

前序（根左右）: 1 2 4 5 3
中序（左根右）: 4 2 5 1 3
后序（左右根）: 4 5 2 3 1
层序:          1 2 3 4 5
```

| 遍历 | 记忆口诀 | 特征 |
|------|---------|------|
| 前序 | 根最先 | 第一个元素 = 根 |
| 中序 | 根在中间 | **BST 中序 = 升序**（核心性质） |
| 后序 | 根最后 | 最后元素 = 根；「左右根」适合自底向上 |
| 层序 | 逐层 | BFS，队列 |

> 🎯 树题 90% 的解法 = **选对遍历 + 在访问点写业务逻辑**。

## 2. 递归遍历三兄弟（前中后序）

**递归三问**（所有树题的统一框架）：
1. **终止条件**：节点为 null 时返回什么？
2. **子问题**：左右子树分别做什么？
3. **返回值**：需要向父节点汇报什么？

```java
// 前序遍历：根左右
List<Integer> preorder(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    dfs(root, res);
    return res;
}

void dfs(TreeNode node, List<Integer> res) {
    if (node == null) return;        // ① 终止条件
    res.add(node.val);               // ② 访问根（前序：先根）
    dfs(node.left, res);             // ③ 递归左
    dfs(node.right, res);            // ④ 递归右
}
```

```java
// 中序遍历：左根右 —— 只需移动 res.add 的位置
void dfs(TreeNode node, List<Integer> res) {
    if (node == null) return;
    dfs(node.left, res);             // 先左
    res.add(node.val);               // 中序：根在中间
    dfs(node.right, res);            // 后右
}

// 后序遍历：左右根 —— 根最后
void dfs(TreeNode node, List<Integer> res) {
    if (node == null) return;
    dfs(node.left, res);
    dfs(node.right, res);
    res.add(node.val);               // 后序：根最后
}
```

> 💡 **三个遍历 = 同一模板，只有 res.add 的位置不同**——记住「前中后 = 根的位置」即可。

## 3. 迭代遍历（显式栈）

**为什么需要迭代**：递归深度 = 树高，斜树（n 层）会**栈溢出**；迭代用显式栈控制，无此风险。

```java
// 前序遍历迭代：栈压右再压左（后进先出 → 左先出）
List<Integer> preorder(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    Deque<TreeNode> stack = new ArrayDeque<>();
    if (root != null) stack.push(root);
    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();
        res.add(node.val);
        if (node.right != null) stack.push(node.right);   // 先右
        if (node.left != null) stack.push(node.left);     // 后左 → 先出
    }
    return res;
}
```

```java
// 中序遍历迭代：一路向左 + 弹栈 + 转右（核心模板）
List<Integer> inorder(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode cur = root;
    while (cur != null || !stack.isEmpty()) {
        while (cur != null) {          // 一路向左
            stack.push(cur);
            cur = cur.left;
        }
        cur = stack.pop();             // 弹栈 = 访问
        res.add(cur.val);
        cur = cur.right;               // 转右子树
    }
    return res;
}
```

```java
// 后序遍历迭代：前序变体（根右左 → 反转）
List<Integer> postorder(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    Deque<TreeNode> stack = new ArrayDeque<>();
    if (root != null) stack.push(root);
    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();
        res.add(node.val);             // 先收集：根右左
        if (node.left != null) stack.push(node.left);
        if (node.right != null) stack.push(node.right);
    }
    Collections.reverse(res);          // 反转 → 左右根
    return res;
}
```

## 4. 层序遍历（BFS）

```java
// 层序遍历：队列 + size 分层（与图 BFS 同模板）
List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) return res;
    Deque<TreeNode> queue = new ArrayDeque<>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        int size = queue.size();           // 本层节点数
        List<Integer> level = new ArrayList<>();
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            level.add(node.val);
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        res.add(level);
    }
    return res;
}
```

**层序的三大变形**：

| 变形 | 处理 | 典型题 |
|------|------|--------|
| 锯齿形 | 偶数层反转 | 103 二叉树的锯齿形层序遍历 |
| 右视图 | 每层最后一个 | 199 二叉树的右视图 |
| 最大宽度 | 记录每层下标 | 662 二叉树最大宽度 |

## 5. 遍历模板速查表

| 遍历 | 递归 | 迭代核心 | 应用场景 |
|------|------|---------|---------|
| 前序 | 根→左→右 | 栈压右压左 | 复制树、序列化、路径记录 |
| 中序 | 左→根→右 | 一路向左+弹栈 | **BST 有序输出**、求第 K 小 |
| 后序 | 左→右→根 | 前序变体+反转 | 自底向上（树形 DP）、删除树 |
| 层序 | 无（天然迭代） | 队列+size | 最短路径、按层统计、右视图 |

> 🎯 **核心要点**：遍历验收——递归三兄弟闭眼默写（只移 add 位置）；迭代至少前序+中序能写；层序用「队列 + size 分层」；记忆锚点：**前序定根、中序分左右、后序自底向上、层序求最短**；BST 中序升序是与[二叉搜索树](../二叉搜索树 BST（二叉排序树）/)体系的核心连接。
