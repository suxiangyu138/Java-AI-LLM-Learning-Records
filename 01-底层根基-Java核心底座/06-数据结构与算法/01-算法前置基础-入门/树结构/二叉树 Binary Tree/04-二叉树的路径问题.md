## 1. 路径问题的两大模式

| 模式 | 路径形态 | 处理方式 | 典型题 |
|------|---------|---------|--------|
| 自顶向下 | 根 → 叶子（单向） | 前序传「累计值」 | 112 路径总和 |
| 自底向上 | 任意两点（可拐弯） | 后序返回「子树信息」 | 543 直径、124 最大路径和 |

> 🎯 **识别信号**：「从根到叶子」「从根出发」→ 自顶向下；「任意节点到任意节点」「经过某节点」→ 自底向上（左右子树信息在根处合并）。

## 2. 最大深度与最小深度

```java
// 104 二叉树的最大深度：自底向上，返回「子树最大深度」
public int maxDepth(TreeNode root) {
    if (root == null) return 0;                        // ① 终止
    int left = maxDepth(root.left);                    // ② 左子树深度
    int right = maxDepth(root.right);                  //    右子树深度
    return Math.max(left, right) + 1;                  // ③ 汇合 + 本层
}

// 111 二叉树的最小深度：⚠️ 不是对称改 Math.min！
public int minDepth(TreeNode root) {
    if (root == null) return 0;
    if (root.left == null) return minDepth(root.right) + 1;   // 只有右子
    if (root.right == null) return minDepth(root.left) + 1;   // 只有左子
    return Math.min(minDepth(root.left), minDepth(root.right)) + 1;
}
```

> ⚠️ **最小深度的坑**：`Math.min` 直接套会算出「经过空节点」的错误深度——**必须处理单子树情况**（只有一个孩子的节点，深度沿唯一孩子继续），这是面试高频陷阱。

## 3. 直径与最长路径

```java
// 543 二叉树的直径：任意两节点最长路径（边数）
// 关键：经过某节点的最长路径 = 左深度 + 右深度；全局最大在遍历中更新
class Solution {
    int max = 0;

    public int diameterOfBinaryTree(TreeNode root) {
        depth(root);
        return max;
    }

    int depth(TreeNode node) {                     // 返回高度，顺便更新直径
        if (node == null) return 0;
        int left = depth(node.left);
        int right = depth(node.right);
        max = Math.max(max, left + right);         // 路径经过当前节点
        return Math.max(left, right) + 1;          // 向父汇报自己的高度
    }
}

// 124 二叉树中的最大路径和：升级版（节点值可负）
// 负数子树贡献取 0（不选）：Math.max(0, 子树和)
```

**树形 DP 三要素**（本节起定型）：
1. **返回值**：向父节点汇报什么（高度）；
2. **局部最优**：在节点处合并左右信息（left + right）；
3. **全局最优**：全局变量或引用记录（max）。

## 4. 路径总和系列

### 4.1 路径总和（根到叶，112）

```java
// 112 路径总和：自顶向下传「剩余值」
public boolean hasPathSum(TreeNode root, int targetSum) {
    if (root == null) return false;
    if (root.left == null && root.right == null) {   // 叶子
        return root.val == targetSum;                // 恰好等于剩余
    }
    return hasPathSum(root.left, targetSum - root.val)
        || hasPathSum(root.right, targetSum - root.val);
}
```

### 4.2 路径总和 II（收集全部路径，113）

```java
// 113 路径总和 II：回溯收集路径（DFS + 撤销）
List<List<Integer>> res = new ArrayList<>();
List<Integer> path = new ArrayList<>();

void dfs(TreeNode node, int target) {
    if (node == null) return;
    path.add(node.val);                            // 选择
    if (node.left == null && node.right == null && node.val == target) {
        res.add(new ArrayList<>(path));            // 叶子命中 → 拷贝保存
    }
    dfs(node.left, target - node.val);
    dfs(node.right, target - node.val);
    path.remove(path.size() - 1);                  // 撤销（回溯关键）
}
```

### 4.3 路径总和 III（任意起点，437）

```java
// 437 路径总和 III：前缀和 + 回溯（树上的「和为 K 子数组」）
// 每节点维护「根到当前的前缀和」，查 map 中有没有 前缀和 - target
Map<Long, Integer> prefix = new HashMap<>();
int count = 0;

void dfs(TreeNode node, long sum, int target) {
    if (node == null) return;
    sum += node.val;
    count += prefix.getOrDefault(sum - target, 0);  // 存在差 = 有路径
    prefix.merge(sum, 1, Integer::sum);             // 入栈
    dfs(node.left, sum, target);
    dfs(node.right, sum, target);
    prefix.merge(sum, -1, Integer::sum);            // 出栈撤销
}
// 调用前：prefix.put(0L, 1);
```

> 💡 437 与数组「和为 K 的子数组」同构（前缀和 + 哈希表），只是把数组换成了树的 DFS——跨题型迁移是进阶的标志。

## 5. 路径问题速查表

| 题号 | 题目 | 模式 | 一句话思路 |
|------|------|------|-----------|
| 104 | 最大深度 | 自底向上 | 返回 max(左,右)+1 |
| 111 | 最小深度 | 自底向上 | ⚠️ 单子树沿唯一孩子 |
| 543 | 直径 | 自底向上 | 全局 max(左高+右高) |
| 124 | 最大路径和 | 自底向上 | 负贡献取 0 |
| 112 | 路径总和 | 自顶向下 | 传剩余值，叶子判定 |
| 113 | 路径总和 II | 自顶向下+回溯 | 收集路径，入栈撤销 |
| 437 | 路径总和 III | 前缀和+回溯 | 树上「和为 K 子数组」 |
| 687 | 最长同值路径 | 自底向上 | 同值才累计高度 |

> 🎯 **核心要点**：路径问题验收——能区分「自顶向下传值 vs 自底向上汇报」；104/543/124 三连能默写（返回高度 + 全局更新）说明树形 DP 入门；112→113→437 的难度递进（判定→收集→任意起点）是树的经典进阶链；437 的前缀和+回溯与哈希体系的「和为 K 子数组」呼应。树形 DP 深入见[专题 4 进阶](../../../03-高频专题模块/专题 4：树（二叉树为主）/二叉树/01-二叉树进阶：回溯构造与树形DP.md)。
