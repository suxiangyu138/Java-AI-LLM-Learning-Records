## 1. 由遍历序列构造二叉树

### 1.1 前序 + 中序构造（105）

**原理**：前序第一个 = 根；中序中根的左侧 = 左子树、右侧 = 右子树；递归切分。

```java
// LeetCode 105 从前序与中序遍历序列构造二叉树
public TreeNode buildTree(int[] preorder, int[] inorder) {
    Map<Integer, Integer> idx = new HashMap<>();   // 中序值 → 下标
    for (int i = 0; i < inorder.length; i++) idx.put(inorder[i], i);
    return build(preorder, 0, preorder.length - 1,
                 inorder, 0, inorder.length - 1, idx);
}

TreeNode build(int[] pre, int pl, int pr, int[] in, int il, int ir,
               Map<Integer, Integer> idx) {
    if (pl > pr) return null;
    int rootVal = pre[pl];                         // 前序第一个 = 根
    TreeNode root = new TreeNode(rootVal);
    int rootIdx = idx.get(rootVal);                // 根在中序的位置
    int leftSize = rootIdx - il;                   // 左子树大小
    root.left = build(pre, pl + 1, pl + leftSize,
                      in, il, rootIdx - 1, idx);
    root.right = build(pre, pl + leftSize + 1, pr,
                       in, rootIdx + 1, ir, idx);
    return root;
}
```

### 1.2 中序 + 后序构造（106）

同思路：**后序最后一个 = 根**，其余逻辑相同。

> ⚠️ **只有前序+后序无法唯一构造**（左右子树分界不明）——必须要有中序（提供左右划分）；「前+中」与「后+中」是两对黄金组合。

## 2. 序列化与反序列化

**序列化**：树 → 字符串（可传输/存储）；**反序列化**：字符串 → 树。用 `null` 标记空位保证唯一还原。

```java
// LeetCode 297 二叉树的序列化与反序列化（前序 + null 标记）
public String serialize(TreeNode root) {
    StringBuilder sb = new StringBuilder();
    serialize(root, sb);
    return sb.toString();
}

void serialize(TreeNode node, StringBuilder sb) {
    if (node == null) { sb.append("null,"); return; }
    sb.append(node.val).append(',');
    serialize(node.left, sb);
    serialize(node.right, sb);
}

public TreeNode deserialize(String data) {
    Deque<String> queue = new ArrayDeque<>(Arrays.asList(data.split(",")));
    return deserialize(queue);
}

TreeNode deserialize(Deque<String> queue) {
    String val = queue.poll();
    if (val.equals("null")) return null;
    TreeNode node = new TreeNode(Integer.parseInt(val));
    node.left = deserialize(queue);
    node.right = deserialize(queue);
    return node;
}
```

| 序列化方案 | 特点 |
|-----------|------|
| 前序 + null | 实现最简（递归天然匹配） |
| 层序 + null | 直观（LeetCode 输出格式） |
| 括号表示 | 紧凑但解析复杂 |

> 💡 序列化的应用场景：树缓存、分布式传输、数据库存储、二叉树比较（同构判断的预处理）。

## 3. 镜像翻转与对称

```java
// 226 翻转二叉树：交换左右子树（递归三问）
public TreeNode invertTree(TreeNode root) {
    if (root == null) return null;            // ① 终止
    TreeNode left = invertTree(root.left);    // ② 子问题：翻转左
    TreeNode right = invertTree(root.right);  //    翻转右
    root.left = right;                        // ③ 组合：交换
    root.right = left;
    return root;
}

// 101 对称二叉树：双指针镜像比较
public boolean isSymmetric(TreeNode root) {
    return isMirror(root.left, root.right);
}

boolean isMirror(TreeNode a, TreeNode b) {
    if (a == null && b == null) return true;       // 都空 = 对称
    if (a == null || b == null) return false;      // 一空一不空
    return a.val == b.val                          // 值相等
        && isMirror(a.left, b.right)               // 镜像比较
        && isMirror(a.right, b.left);
}
```

> 💡 翻转与对称的区别：翻转是**修改**树结构；对称是**判断**树是否镜像——对称用双指针（左子 vs 右子交叉比较），是「子树比较」类题的模板。

## 4. 遍历应用清单

| 应用 | 使用的遍历 | 核心技巧 | 典型题 |
|------|-----------|---------|--------|
| 构造二叉树 | 前/后序定根 + 中序分界 | 哈希表缓存中序下标 | 105/106 |
| 序列化 | 前序 + null | 递归顺序一致 | 297 |
| 翻转/对称 | 后序（先子树后交换）/ 双指针 | 递归三问 | 226/101 |
| 复制树 | 前序 | 每节点 new 一个 | 面试基础题 |
| 合并二叉树 | 前序 | 同位置相加 | 617 |
| 展开为链表 | 后序/前序 | 右指针串接 | 114 |

> 🎯 **核心要点**：本节验收——105 构造（前+中）能默写（哈希表缓存下标 + 左子树大小切分）；297 序列化递归一对（serialize 与 deserialize 顺序严格对应）；101 对称的双指针交叉比较（a.left vs b.right）；「前+后无法唯一构造」的结论要能解释。进阶（回溯构造、树形 DP）见[专题 4：树进阶](../../../03-高频专题模块/专题 4：树（二叉树为主）/二叉树/01-二叉树进阶：回溯构造与树形DP.md)。
