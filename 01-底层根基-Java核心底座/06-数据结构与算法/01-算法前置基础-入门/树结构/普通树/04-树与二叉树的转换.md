## 1. 转换原理：孩子兄弟表示法

**核心**：任何普通树都能用「左孩子 + 右兄弟」两个指针表示 → 结构上等价于二叉树。

```text
普通树:                孩子兄弟表示（二叉树形态）:
        A                    A
      / | \                 /
     B  C  D               B ── C ── D
    / \                   /
   E   F                 E ── F

规则:  left  = 第一个孩子（长子）
      right = 下一个兄弟
```

| 二叉树指针 | 普通树语义 |
|-----------|-----------|
| left | 第一个孩子（长子） |
| right | 下一个兄弟 |

> ⚠️ **语义变化警告**：转换后二叉树的 `right` 不再是「右孩子」而是「兄弟」——中序遍历二叉树 = 先遍历孩子子树、再遍历兄弟链。

## 2. 普通树 → 二叉树

```java
// 普通树 → 二叉树（孩子兄弟转换，递归）
TreeNode convertToBinary(Node node) {
    if (node == null) return null;
    TreeNode root = new TreeNode(node.val);
    if (!node.children.isEmpty()) {
        // 长子 → left
        root.left = convertToBinary(node.children.get(0));
    }
    // 兄弟链：长子之后的孩子依次为 right 链
    TreeNode cur = root.left;
    for (int i = 1; i < node.children.size(); i++) {
        cur.right = convertToBinary(node.children.get(i));
        cur = cur.right;
    }
    return root;
}
```

```text
        A               A
      / | \            /
     B  C  D          B ── C ── D
    / \              /
   E   F            E ── F
```

**转换后的遍历对应**（关键洞察）：

| 二叉树遍历 | 对应普通树 |
|-----------|-----------|
| 先序遍历 | 普通树先序（根→孩子）✓ 一致 |
| 后序遍历 | 普通树后序（孩子→根）✓ 一致 |
| **中序遍历** | **孩子→兄弟链**（不是普通树的标准遍历！） |

> 💡 **先序/后序在转换中保持不变**——这是孩子兄弟转换最优雅的性质：二叉树先序 = 普通树先序、后序同理，所以二叉树遍历模板可直接复用。

## 3. 二叉树 → 普通树

```java
// 二叉树 → 普通树（逆转换）
Node convertToGeneral(TreeNode node) {
    if (node == null) return null;
    List<Node> children = new ArrayList<>();
    TreeNode cur = node.left;                // 左子树 = 孩子链起点
    while (cur != null) {
        children.add(convertToGeneral(cur)); // 每个兄弟节点 → 一个孩子
        cur = cur.right;
    }
    return new Node(node.val, children);
}
```

> 💡 逆转换规律：**左子树 = 孩子链表、右子树 = 兄弟**——把 left 链的每个节点转成孩子，right 指针断开。

## 4. 森林 → 二叉树

**森林 = 多棵普通树**。转换规则：**每棵树的根依次作为前一个根的右兄弟**。

```text
森林:                          二叉树:
  T1    T2    T3               R1 ── R2 ── R3
  │     │     │               （根链 = 右兄弟链）
  ...   ...   ...
```

```java
// 森林 → 二叉树：根链用 right 串联
TreeNode forestToBinary(List<Node> forest) {
    TreeNode dummy = new TreeNode(-1);
    TreeNode cur = dummy;
    for (Node tree : forest) {
        cur.right = convertToBinary(tree);   // 每棵树 → 右兄弟
        cur = cur.right;
    }
    return dummy.right;                      // 返回第一个根
}
```

**应用场景**：并查集的森林表示、目录多根挂载、合并多棵子树为统一结构。

## 5. 转换速查表

| 转换 | 方法 | 关键规则 |
|------|------|---------|
| 普通树 → 二叉树 | 孩子兄弟递归 | left=长子、right=兄弟 |
| 二叉树 → 普通树 | left 链逆转换 | 左子树拆孩子链 |
| 森林 → 二叉树 | 根链 right 串联 | 每棵树根变右兄弟 |
| 二叉树 → 森林 | right 链拆开 | 根链断开成多棵树 |

**转换的价值**（面试必答）：

| 价值 | 说明 |
|------|------|
| 复用算法 | 二叉树遍历/深度/LCA 全部可用 |
| 统一存储 | 二叉链表通用表示 |
| 空间优化 | 2 指针 vs 任意长度 List |
| 概念打通 | 「树是二叉树的推广」与「二叉树是树的特化」双向理解 |

### 4.1 转换完整示例（手算推演）

```text
普通树:
        A
      / | \
     B  C  D
    / \
   E   F

孩子兄弟转换（left=长子, right=兄弟）:
  A: left=B, right=null
  B: left=E, right=C（C 是 B 的兄弟）
  C: left=null, right=D
  D: left=null, right=null
  E: left=null, right=F
  F: left=null, right=null

二叉树形态:
        A
       /
      B ── C ── D
     /
    E ── F
```

**验证**：转换后的二叉树先序遍历 = A B E F C D = 普通树先序 ✓

> 🎯 **核心要点**：转换验收——能手画孩子兄弟转换图（left=长子、right=兄弟）；记住「先序/后序在转换中不变、中序语义改变」；逆转换（左子树拆孩子链）与森林转换（根链右串）能写；「孩子兄弟表示法让任意树复用二叉树算法」是面试概念题的完整答案。
