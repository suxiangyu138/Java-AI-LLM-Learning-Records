## 4. 核心概念速查

| 概念 | 一句话说明 | 所在模块 |
|------|-----------|---------|
| 普通树/多叉树 | 子节点数不限的树（≥0 个） | 01 |
| 度 | 节点的子节点数（二叉树 ≤ 2，多叉不限） | 01 |
| 孩子表示法 | `Node { val, List<Node> children }` | 01 |
| 孩子兄弟表示法 | 左孩子 + 右兄弟指针（转二叉树的钥匙） | 01/04 |
| N 叉前序 | 根 → 依次遍历每个孩子 | 02 |
| N 叉后序 | 依次遍历每个孩子 → 根 | 02 |
| N 叉层序 | 队列 + size 分层（与二叉树同模板） | 02 |
| 森林 | 多棵树的集合 | 04 |
| 树的二叉树化 | 孩子兄弟表示 → 左子树存孩子、右子树存兄弟 | 04 |
| 文件系统 | 目录树：根 / → 子目录 → 文件 | 05 |

> 🎯 **核心要点**：普通树与二叉树的唯一区别是**孩子数量**——遍历模板只需把 `left/right` 换成 `for (child : children)`；工程中大多数「树」都是多叉树（文件系统/DOM/组织架构）；「孩子兄弟表示法」是把多叉树转成二叉树、复用二叉树算法的关键桥梁。
