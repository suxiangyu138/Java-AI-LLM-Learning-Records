## 1. 最大深度与最小深度

```java
// 559 N 叉树的最大深度：for 循环取 max
public int maxDepth(Node root) {
    if (root == null) return 0;
    int depth = 0;
    for (Node child : root.children) {
        depth = Math.max(depth, maxDepth(child));
    }
    return depth + 1;
}
```

**最小深度**（N 叉版同样有单子树陷阱）：

```java
// 最小深度：⚠️ 直接 Math.min 会误判「空孩子路径」
public int minDepth(Node root) {
    if (root == null) return 0;
    if (root.children.isEmpty()) return 1;        // 叶子
    int min = Integer.MAX_VALUE;
    for (Node child : root.children) {
        min = Math.min(min, minDepth(child));     // 只有非空孩子参与
    }
    return min + 1;
}
```

> ⚠️ 与二叉树 111 题同款陷阱：**空孩子不算路径**——N 叉版只需跳过空孩子（children 为空时直接返回叶子深度 1）。

## 2. 直径与最长路径

**直径** = 任意两节点间最长路径的边数。N 叉版：**经过节点的最长路径 = 最大两个子树深度之和**。

```java
// N 叉树直径（思路同二叉树 543，孩子变成循环）
class Solution {
    int max = 0;

    public int diameter(Node root) {
        depth(root);
        return max;
    }

    int depth(Node node) {
        if (node == null) return 0;
        // 找最大和次大子树深度
        int first = 0, second = 0;               // 前两大深度
        for (Node child : node.children) {
            int d = depth(child);
            if (d > first) { second = first; first = d; }
            else if (d > second) { second = d; }
        }
        max = Math.max(max, first + second);     // 经过本节点的最长路径
        return first + 1;                        // 向父汇报最大深度
    }
}
```

> 💡 「前两大」技巧（top-2 循环维护）在 N 叉树的路径类问题中反复出现——二叉树只需比较两个分支，N 叉树要在一组孩子中找前两大。

## 3. 叶子与内部节点计数

```java
// 叶子数：children 为空即叶子
int countLeaves(Node root) {
    if (root == null) return 0;
    if (root.children.isEmpty()) return 1;       // 叶子
    int count = 0;
    for (Node child : root.children) {
        count += countLeaves(child);
    }
    return count;
}

// 节点总数：1 + Σ子树
int countNodes(Node root) {
    if (root == null) return 0;
    int count = 1;
    for (Node child : root.children) {
        count += countNodes(child);
    }
    return count;
}

// 高度（边数版）：深度 - 1
```

| 统计 | 终止条件 | 递推 |
|------|---------|------|
| 节点总数 | null → 0 | 1 + Σ子树 |
| 叶子数 | 空孩子 → 1 | Σ子树 |
| 内部节点 | — | 总数 - 叶子 |

## 4. 树形 DP 的 N 叉推广

**树形 DP 三要素**（二叉树体系 04 模块的思想，N 叉同样成立）：

| 要素 | 二叉树 | N 叉树 |
|------|--------|--------|
| 返回值 | 向父汇报子树信息 | 同（for 循环聚合） |
| 局部最优 | max(左, 右) 合并 | 前两大/循环 max |
| 全局最优 | 全局变量更新 | 同 |
