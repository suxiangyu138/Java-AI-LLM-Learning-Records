## 4. 核心概念速查

| 概念 | 一句话说明 | 所在模块 |
|------|-----------|---------|
| BST 性质 | 左子树所有 < 根 < 右子树所有 | 01 |
| 中序升序 | BST 中序遍历 = 升序序列（**最核心性质**） | 01/03 |
| 验证 BST | 区间传递（min, max）而非简单左右比较 | 01 |
| 搜索 | 比根小向左、大向右，O(h) | 02 |
| 插入 | 空位落点，递归返回挂接 | 02 |
| 删除 | 无子/单子/双子（右子树最小替代）三态 | 02 |
| 第 K 小 | 中序遍历计数（或 BST 结点数加速） | 03 |
| 后继 | 中序序列中下一个节点（右子树最左/祖先） | 03 |
| 有序数组 → BST | 取中点递归，构造平衡 BST | 04 |
| BST ↔ 双向链表 | 中序遍历 + 前后指针 | 04 |
| BST 的 LCA | 值比较分岔点（O(h)） | 05 |

> 🎯 **核心要点**：BST 的黄金公式——**「中序升序」贯穿一切有序操作**；验证用「区间传递」而非左右比较（98 题经典陷阱）；删除双子用「右子树最小」替代；BST 操作复杂度 O(h)——**不平衡退化为 O(n)** 是 AVL/红黑树存在的理由（衔接平衡树体系）。二叉树基础见[二叉树 Binary Tree](../二叉树 Binary Tree/)。
