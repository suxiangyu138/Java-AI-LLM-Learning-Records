## 1. 有序数组 → 平衡 BST（108 题）

**原理**：取中点做根，左半递归左子树、右半递归右子树——「二分 + 递归」天然构造平衡 BST。

```java
// 108 将有序数组转换为二叉搜索树
public TreeNode sortedArrayToBST(int[] nums) {
    return build(nums, 0, nums.length - 1);
}

TreeNode build(int[] nums, int left, int right) {
    if (left > right) return null;
    int mid = left + (right - left) / 2;     // 中点做根（左偏）
    TreeNode root = new TreeNode(nums[mid]);
    root.left = build(nums, left, mid - 1);  // 左半 → 左子树
    root.right = build(nums, mid + 1, right);// 右半 → 右子树
    return root;
}
```

**为什么平衡**：每次取中点，左右子数组长度差 ≤ 1 → 任意子树高度差 ≤ 1。

> 💡 变体：有序链表 → 平衡 BST（109 题）——链表无随机访问，用「快慢指针找中点」或「中序填充」两种解法。

## 2. BST → 双向链表（426 题）

**原理**：中序遍历顺序 = 链表顺序；用**前驱指针**串接，原地转换（不动结构，只改指针）。

```java
// 426 将二叉搜索树转化为排序的双向链表
// 中序遍历 + 双向指针串接
Node head = null, prev = null;

public Node treeToDoublyList(Node root) {
    if (root == null) return null;
    inorder(root);
    head.left = prev;        // 首尾相连（循环双向链表）
    prev.right = head;
    return head;
}

void inorder(Node node) {
    if (node == null) return;
    inorder(node.left);
    if (prev == null) {
        head = node;         // 最左节点 = 链表头
    } else {
        prev.right = node;   // 前驱 → 当前
        node.left = prev;    // 当前 ← 前驱
    }
    prev = node;             // 前驱后移
    inorder(node.right);
}
```

**转换口诀**：**中序遍历 + prev 指针** = BST 有序化转换的标准套路。

| 转换 | 中序的作用 | 题号 |
|------|-----------|------|
| BST → 双向链表 | 中序顺序 = 链表顺序 | 426 |
| BST → 递增序列 | 中序输出 | 897 |
| BST → 平衡 BST | 中序收集 + 108 重建 | 1382 |

## 3. 修剪 BST（669 题）

**原理**：节点小于 low → 左子树全不要（返回右子树）；大于 high → 右子树全不要（返回左子树）；在区间内 → 递归修剪两侧。

```java
// 669 修剪二叉搜索树
public TreeNode trimBST(TreeNode root, int low, int high) {
    if (root == null) return null;
    if (root.val < low) {
        return trimBST(root.right, low, high);   // 当前+左子树全舍，右子树可能合格
    }
    if (root.val > high) {
        return trimBST(root.left, low, high);    // 当前+右子树全舍，左子树可能合格
    }
    root.left = trimBST(root.left, low, high);   // 区间内：修剪两侧
    root.right = trimBST(root.right, low, high);
    return root;
}
```

> ⚠️ 修剪与删除的区别：删除是删**单个**节点（保留子树）；修剪是裁掉**整片**越界区域——利用 BST 性质整体剪枝，这是 O(n) 而非 O(n log n)。

## 4. 转换思想总结

| 转换类型 | 核心思想 | 复杂度 | 题号 |
|---------|---------|--------|------|
| 数组 → BST | 二分中点做根 | O(n) | 108 |
| 链表 → BST | 快慢指针/中序填充 | O(n) | 109 |
| BST → 双向链表 | 中序 + prev 指针 | O(n) | 426 |
| BST → 平衡树 | 中序 + 重建 | O(n) | 1382 |
| 修剪越界 | 有序剪枝 | O(n) | 669 |
| BST 验证 | 区间传递 | O(n) | 98 |

**三句话总结**：
1. **有序 → BST**：二分取中点（108）；
2. **BST → 有序结构**：中序遍历（426）；
3. **有序性剪枝**：越界整片舍（669/938）。

> 🎯 **核心要点**：构造与转换验收——108（有序数组二分）与 426（中序+prev）能默写；理解「有序 ↔ BST」的双向通道（数组的二分 ↔ BST 的中序）；669 的「整片剪枝」体现 BST 有序性的效率红利；这四种转换是面试「树上变形题」的基础拼图。
