## 1. 第 K 小元素（230 题）

**原理**：BST 中序 = 升序，第 K 个访问到的节点就是答案。

```java
// 230 二叉搜索树中第 K 小的元素（中序计数）
public int kthSmallest(TreeNode root, int k) {
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode cur = root;
    while (cur != null || !stack.isEmpty()) {
        while (cur != null) { stack.push(cur); cur = cur.left; }
        cur = stack.pop();
        if (--k == 0) return cur.val;      // 第 K 个访问 = 第 K 小
        cur = cur.right;
    }
    return -1;
}
```

**复杂度**：O(h + K)——走到最左 O(h)，再访问 K 个节点。

> 💡 第 K 大 = 第 (n-K+1) 小，或反向中序（右根左）计数——面试常考「反着来」。

## 2. 后继与前驱

**后继（successor）**：中序序列中比 x 大的**最小**节点（下一个）。

```java
// 求 node 的后继（node 有右子树的情况）
TreeNode successor(TreeNode node) {
    // ① 有右子树：右子树的最左节点
    if (node.right != null) {
        TreeNode cur = node.right;
        while (cur.left != null) cur = cur.left;
        return cur;
    }
    // ② 无右子树：向上找「第一个使其位于左子树的祖先」
    // 需要 parent 指针或自顶向下搜索
    return null;
}
```

**自顶向下搜索后继**（无 parent 指针）：

```java
// 求「值 > x 的最小节点」（面试高频变体）
TreeNode successor(TreeNode root, int x) {
    TreeNode res = null;
    while (root != null) {
        if (root.val > x) {
            res = root;            // 候选：当前节点比 x 大
            root = root.left;      // 尝试更小的
        } else {
            root = root.right;     // 当前 ≤ x，向右找
        }
    }
    return res;
}
```

| 概念 | 定义 | 查找方法 |
|------|------|---------|
| 后继 | 大于 x 的最小节点 | 右子树最左 / 祖先左拐点 |
| 前驱 | 小于 x 的最大节点 | 左子树最右 / 祖先右拐点 |

## 3. 范围统计与区间查询

```java
// 938 二叉搜索树的范围和：统计 [low, high] 内节点值之和
public int rangeSumBST(TreeNode root, int low, int high) {
    if (root == null) return 0;
    if (root.val < low) return rangeSumBST(root.right, low, high);   // 整棵左子树都小，剪枝
    if (root.val > high) return rangeSumBST(root.left, low, high);   // 整棵右子树都大，剪枝
    return root.val                                                // 在区间内：累加自身
         + rangeSumBST(root.left, low, high)
         + rangeSumBST(root.right, low, high);
}
```

**BST 区间查询的优势**：利用有序性**剪枝**——当前节点小于 low 时左子树全排除，大于 high 时右子树全排除。平均复杂度远低于全树遍历。

## 4. BST 结点数加速

**问题**：频繁第 K 小（数据流场景）时，中序遍历 O(h+K) 太慢。

**加速方案**：节点增加 `size` 字段（子树结点数），第 K 小可 O(h)：

```java
// 带 size 的 BST 节点
class TreeNodeS {
    int val, size;          // size = 左 + 右 + 1
    TreeNodeS left, right;
}

// 第 K 小：比较 K 与左子树大小
int kthSmallest(TreeNodeS root, int k) {
    int leftSize = root.left == null ? 0 : root.left.size;
    if (k == leftSize + 1) return root.val;       // 根就是第 K 小
    if (k <= leftSize) return kthSmallest(root.left, k);   // 在左子树
    return kthSmallest(root.right, k - leftSize - 1);      // 在右子树（减去左+根）
}
```

> 💡 带 size 的 BST = **顺序统计树（Order Statistic Tree）**——Java 的 TreeMap 不提供 rank 查询，需要自实现；这是「第 K 小」从 O(h+K) 到 O(h) 的关键。
