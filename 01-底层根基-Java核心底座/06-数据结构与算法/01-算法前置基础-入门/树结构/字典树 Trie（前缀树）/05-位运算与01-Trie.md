## 1. 01-Trie 的结构

**01-Trie**：每个节点只有 0/1 两个分支（二叉树），按**二进制位**从高位到低位插入。

```text
插入 5(101), 3(011), 6(110)（3 位）:

            root
           /    \
          0      1         ← 最高位
         / \    /
        0   1  1           ← 次高位
        |   |  |
        1   1  0           ← 最低位
      (3) (5) (6)

查询与 5(101) 异或最大:
  贪心: 每一位尽量走「相反位」
  5 的位: 1 → 走 0(有) → 0 → 走 1(有) → 1 → 走 0(有)
  找到 6(110): 101 ⊕ 110 = 011 = 3 ✓ 最大
```

| 维度 | 普通 Trie | 01-Trie |
|------|-----------|---------|
| 分叉依据 | 字符 | 二进制位 |
| 深度 | 单词长度 | **固定 31（int）** |
| 查询目标 | 前缀匹配 | 异或最值 |
| 贪心策略 | 无 | **每一位走相反位** |

> 💡 **贪心正确性**：异或值的大小由**最高位**决定——从高位贪心走相反位，保证每位都取到最优 → 全局最优（与二叉字典序同理）。

## 2. 最大异或对（421 题）

**问题**：数组 nums 中找两个数使异或值最大。

**朴素**：O(n²) 两两比较。**01-Trie**：O(n × 31) 插入 + 查询。

```java
// LeetCode 421 数组中两个数的最大异或值
class Solution {
    public int findMaximumXOR(int[] nums) {
        TrieNode root = new TrieNode();
        int max = 0;

        for (int num : nums) {
            // ① 先查询当前数与已有数的最大异或
            max = Math.max(max, query(root, num));
            // ② 再插入当前数
            insert(root, num);
        }
        return max;
    }

    // 查询与 num 异或最大的数（贪心走相反位）
    int query(TrieNode root, int num) {
        TrieNode node = root;
        int xor = 0;
        for (int i = 30; i >= 0; i--) {          // 31 位（int 无符号位）
            int bit = (num >> i) & 1;
            int want = bit ^ 1;                  // 想要的相反位
            if (node.children[want] != null) {   // 有相反位 → 走
                xor |= (1 << i);                 // 该位异或结果 = 1
                node = node.children[want];
            } else {                             // 无相反位 → 只能同向
                node = node.children[bit];
            }
        }
        return xor;
    }

    void insert(TrieNode root, int num) {
        TrieNode node = root;
        for (int i = 30; i >= 0; i--) {
            int bit = (num >> i) & 1;
            if (node.children[bit] == null) node.children[bit] = new TrieNode();
            node = node.children[bit];
        }
    }

    class TrieNode {
        TrieNode[] children = new TrieNode[2];   // 0 / 1
    }
}
```

**为什么先查询后插入**：与「已见过的数」比较——边插入边查询避免与自己异或（结果 0）。

## 3. 01-Trie 完整实现

```java
// 01-Trie 通用模板（最大异或查询）
class BinaryTrie {
    private final TrieNode root = new TrieNode();
    private static final int MAX_BIT = 30;       // 31 位 int（0..30）

    static class TrieNode {
        TrieNode[] children = new TrieNode[2];
    }

    public void insert(int num) {
        TrieNode node = root;
        for (int i = MAX_BIT; i >= 0; i--) {
            int bit = (num >> i) & 1;
            if (node.children[bit] == null) node.children[bit] = new TrieNode();
            node = node.children[bit];
        }
    }

    /** 与 num 异或的最大值 */
    public int maxXor(int num) {
        TrieNode node = root;
        int xor = 0;
        for (int i = MAX_BIT; i >= 0; i--) {
            int bit = (num >> i) & 1;
            int opposite = bit ^ 1;
            if (node.children[opposite] != null) {
                xor |= (1 << i);
                node = node.children[opposite];
            } else {
                node = node.children[bit];
            }
        }
        return xor;
    }

    /** 异或值不超过 limit 的最大值（1707 题的变体） */
    public int maxXorWithin(int num, int limit) {
        // 维护子树最小值 min[]，查询时若 opposite 子树 min > limit 则放弃
        // 详见 1707 题解
        return -1;
    }
}
```

> ⚠️ 位数选择：负数最高位是符号位（31）——题目通常限定非负（0..30 位足够）；若含负数需从 31 位开始并处理符号位。

## 4. 变体应用

| 题号 | 题目 | 01-Trie 变体 |

| 421 | 最大异或对 | 基础：贪心相反位 |
| 1707 | 与数组中元素的最大异或值 | 加 limit 约束（子树 min 剪枝） |
| 1938 | 查询最大基因差 | 树上 01-Trie 合并/回溯 |
| 1803 | 统计异或值在范围内的数对 | 01-Trie + 前缀计数 |
| 2429 | 最小异或 | 贪心构造（非 Trie） |

```java
// 1707 思路：子树存最小值 min，limit 约束时
//   if (opposite 子树 min <= limit) 走 opposite
//   else if (同向子树 min <= limit) 走同向
//   else 无解
// 本质：贪心 + 子树最值剪枝（Trie 节点额外存 min）
```

> 💡 01-Trie 的进阶都是「节点存附加信息」（min/count）+ 贪心——**结构与基础模板不变，变的只是节点字段**。

## 5. 位运算 Trie 速查表

| 操作 | 复杂度 | 实现 |
|------|--------|------|
| 插入 | O(31) | 逐位下钻 |
| 最大异或 | O(31) | 贪心相反位 |
| 最大异或（限 limit） | O(31) | 子树 min 剪枝 |
| 异或值计数 | O(31) | 节点存 count |
| 空间 | O(n × 31) | 每数 31 节点 |

**面试对比**（为什么 01-Trie 而非排序）：

```text
排序 + 贪心?: 异或的最优解不是相邻数（异或无单调性）
  → 排序无法贪心，必须逐位决策 → 01-Trie 天然逐位

HashSet?: 无法逐位查询相反位分支
  → 只有 Trie 结构支持「按位分叉 + 分支选择」
```

> 🎯 **核心要点**：01-Trie 验收——421 完整实现默写（插入 + 贪心查询）；理解「从高位贪心走相反位」的正确性（异或大小由高位决定）；「先查询后插入」避免自异或；进阶变体（1707 limit 剪枝、1803 计数）都是「节点加字段」；与位运算体系（[位运算](../../../02-基础算法思想-核心/位运算/)）交叉复习。
