## 4. 核心概念速查

| 概念 | 一句话说明 | 所在模块 |
|------|-----------|---------|
| Trie | 按字符分叉的前缀共享树 | 01 |
| 插入 | 逐字符建节点，末尾标记 isEnd | 01 |
| 查找 | 逐字符下钻，检查 isEnd | 01 |
| 前缀查询 | 下钻成功即存在前缀 | 01 |
| 空间 | O(字符总数 × 字母表) | 01 |
| 数组实现 | `Trie[26] children`（小写字母） | 01 |
| 哈希实现 | `Map<Character, Trie>`（通用字符集） | 01 |
| 压缩 Trie | 单子链合并（Radix Tree） | 02 |
| 01-Trie | 按二进制位分叉（异或最值） | 05 |
| 单词搜索 II | Trie + DFS 剪枝 | 04 |

> 🎯 **核心要点**：Trie 的本质 = **「前缀共享」的多叉树**——插入 O(长度)、前缀查询 O(长度)，与字符串长度无关的数据规模无关；三大应用：**前缀匹配（补全/替换）、DFS 剪枝（单词搜索 II）、位运算（01-Trie 异或最值）**；面试从 208 实现开始，进阶到 212/421 收尾。
