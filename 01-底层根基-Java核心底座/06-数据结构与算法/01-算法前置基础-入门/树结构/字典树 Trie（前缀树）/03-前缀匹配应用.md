## 1. 单词替换（648 题）

**问题**：字典 roots 中的词根替换句子中「以词根开头」的单词——"cat" 替换 "cattle"。

**思路**：Trie 存词根，遍历句子每个单词，**前缀命中即替换（最短前缀）**。

```java
// LeetCode 648 单词替换
class Solution {
    public String replaceWords(List<String> dictionary, String sentence) {
        Trie root = new Trie();
        for (String word : dictionary) root.insert(word);   // 词根入 Trie

        StringBuilder res = new StringBuilder();
        for (String word : sentence.split(" ")) {
            if (res.length() > 0) res.append(' ');
            String replaced = root.findRoot(word);          // 找最短词根
            res.append(replaced != null ? replaced : word);
        }
        return res.toString();
    }
}

class Trie {
    Trie[] children = new Trie[26];
    boolean isEnd;

    void insert(String word) { /* 标准插入 */ }

    // 核心：沿路径找「第一个 isEnd 节点」= 最短前缀
    String findRoot(String word) {
        Trie node = this;
        StringBuilder prefix = new StringBuilder();
        for (char c : word.toCharArray()) {
            int idx = c - 'a';
            if (node.children[idx] == null) return null;    // 无词根命中
            node = node.children[idx];
            prefix.append(c);
            if (node.isEnd) return prefix.toString();       // 最短词根
        }
        return null;                                        // 整词都在但非词根
    }
}
```

> 💡 **最短前缀 = 第一个 isEnd**：沿字符下钻时，遇到的第一个单词结尾节点就是最短词根——「贪心 + Trie」的经典组合。

## 2. 搜索推荐系统（1268 题）

**问题**：输入前缀，返回字典中前 3 个以该前缀开头的单词（字典序）。

**思路**：Trie + DFS——下钻到前缀末尾，**DFS 收集子树所有单词**（字典序天然有序）。

```java
// LeetCode 1268 搜索推荐系统（核心：DFS 收集子树单词）
class Solution {
    public List<List<String>> suggestedProducts(String[] products, String searchWord) {
        Trie root = new Trie();
        for (String p : products) root.insert(p);

        List<List<String>> res = new ArrayList<>();
        Trie node = root;
        StringBuilder prefix = new StringBuilder();
        for (char c : searchWord.toCharArray()) {
            prefix.append(c);
            if (node == null || node.children[c - 'a'] == null) {
                node = null;                                // 后续全部空
                res.add(new ArrayList<>());
                continue;
            }
            node = node.children[c - 'a'];
            List<String> suggestions = new ArrayList<>();
            collect(node, prefix.toString(), suggestions);  // DFS 收集子树
            res.add(suggestions);
        }
        return res;
    }

    // DFS 收集子树中所有单词（字典序 = Trie 从左到右）
    void collect(Trie node, String prefix, List<String> out) {
        if (out.size() >= 3) return;                        // 只要前 3
        if (node.isEnd) out.add(prefix);
        for (int i = 0; i < 26; i++) {
            if (node.children[i] != null) {
                collect(node.children[i], prefix + (char) ('a' + i), out);
            }
        }
    }
}
```

> 💡 Trie 的字典序性质：**DFS 从左到右 = 字典序输出**——排序/推荐类问题的天然特性（与中序遍历 BST 类似）。

## 3. Trie 的删除与计数扩展

```java
// 扩展一：删除单词（递归回溯删除节点）
boolean delete(Trie node, String word, int depth) {
    if (depth == word.length()) {
        if (!node.isEnd) return false;          // 单词不存在
        node.isEnd = false;
        return isEmpty(node);                   // 无孩子才可删
    }
    int idx = word.charAt(depth) - 'a';
    if (node.children[idx] == null) return false;
    boolean canDelete = delete(node.children[idx], word, depth + 1);
    if (canDelete) node.children[idx] = null;   // 剪掉空分支
    return isEmpty(node) && !node.isEnd;
}

// 扩展二：单词计数（每个节点存 count）
class TrieCount {
    TrieCount[] children = new TrieCount[26];
    int count;                  // 经过该节点的单词数（前缀统计）
}

// 扩展三：前缀计数 = 前缀末尾节点的 count
int countPrefix(String prefix) {
    TrieCount node = this;
    for (char c : prefix.toCharArray()) {
        if (node.children[c - 'a'] == null) return 0;
        node = node.children[c - 'a'];
    }
    return node.count;
}
```

| 扩展 | 用途 | 实现要点 |
|------|------|---------|
| 删除 | 动态字典 | 递归回溯 + 空分支剪除 |
| 计数 | 前缀统计 | 节点存 count（经过次数） |
| 排序输出 | 字典序 | DFS 从左到右 |
| 最长公共前缀 | 多词共享 | 公共路径长度 |
