## 1. Trie 的结构

**字典树（Trie / Prefix Tree）**：多叉树，**每条边对应一个字符**，从根到节点的路径 = 前缀，叶子标记单词结尾。

```text
插入 "cat", "car", "card", "dog":

        root
       /    \
      c      d
      |      |
      a      o
     / \     |
    t   r    g
        |
        d

单词: cat, car, card, dog
前缀: ca → cat/car/card 共享
```

| 术语 | 含义 |
|------|------|
| 根节点 | 空节点（不存字符） |
| 边 | 一个字符 |
| 路径 | 从根到节点的字符序列 = 前缀 |
| isEnd | 节点是否是一个单词的结尾 |
| 共享 | 公共前缀只存一次（空间/时间双省） |

> 💡 与哈希集合对比：HashSet 查单词 O(1) 但**无法查前缀**；Trie 查前缀 O(长度) 且天然有序——「前缀查询」是 Trie 不可替代的价值。

## 2. 核心操作：插入/查找/前缀

### 2.1 插入

```java
// 插入 "cat": 逐字符下钻，不存在则建节点，末尾标记
void insert(String word) {
    Trie node = root;
    for (char c : word.toCharArray()) {
        int idx = c - 'a';
        if (node.children[idx] == null) {
            node.children[idx] = new Trie();   // 建新节点
        }
        node = node.children[idx];
    }
    node.isEnd = true;                          // 单词结尾标记
}
```

### 2.2 查找（完整单词）

```java
boolean search(String word) {
    Trie node = searchPrefix(word);             // 先下钻
    return node != null && node.isEnd;          // 必须命中 isEnd！
}
```

### 2.3 前缀查询

```java
boolean startsWith(String prefix) {
    return searchPrefix(prefix) != null;        // 下钻成功即存在该前缀
}

// 公共下钻逻辑
Trie searchPrefix(String prefix) {
    Trie node = root;
    for (char c : prefix.toCharArray()) {
        int idx = c - 'a';
        if (node.children[idx] == null) return null;  // 断链 = 不存在
        node = node.children[idx];
    }
    return node;
}
```

> ⚠️ **search 与 startsWith 的区别**：search 要求下钻到底且 **isEnd=true**；startsWith 只要求**下钻成功**——「cat」是前缀但不是「car」的完整单词。

## 3. 数组实现（208 题）

```java
// LeetCode 208 实现 Trie（前缀树）—— 完整模板
class Trie {
    private Trie[] children;          // 26 个小写字母
    private boolean isEnd;

    public Trie() {
        children = new Trie[26];
        isEnd = false;
    }

    public void insert(String word) {
        Trie node = this;
        for (char c : word.toCharArray()) {
            int idx = c - 'a';
            if (node.children[idx] == null) {
                node.children[idx] = new Trie();
            }
            node = node.children[idx];
        }
        node.isEnd = true;
    }

    public boolean search(String word) {
        Trie node = searchPrefix(word);
        return node != null && node.isEnd;
    }

    public boolean startsWith(String prefix) {
        return searchPrefix(prefix) != null;
    }

    private Trie searchPrefix(String prefix) {
        Trie node = this;
        for (char c : prefix.toCharArray()) {
            int idx = c - 'a';
            if (node.children[idx] == null) return null;
            node = node.children[idx];
        }
        return node;
    }
}
```

> 🎯 **208 题验收**：10 分钟内默写完整类——这是 Trie 面试的起跑线。

## 4. 哈希实现（通用字符集）

```java
// 哈希实现：适用于任意字符集（大小写混合/数字/Unicode）
class TrieHash {
    private Map<Character, TrieHash> children = new HashMap<>();
    private boolean isEnd;

    public void insert(String word) {
        TrieHash node = this;
        for (char c : word.toCharArray()) {
            node.children.computeIfAbsent(c, k -> new TrieHash());
            node = node.children.get(c);
        }
        node.isEnd = true;
    }

    public boolean search(String word) {
        TrieHash node = searchPrefix(word);
        return node != null && node.isEnd;
    }

    public boolean startsWith(String prefix) {
        return searchPrefix(prefix) != null;
    }

    private TrieHash searchPrefix(String prefix) {
        TrieHash node = this;
        for (char c : prefix.toCharArray()) {
            if (!node.children.containsKey(c)) return null;
            node = node.children.get(c);
        }
        return node;
    }
}
```

## 5. 复杂度与选型

| 维度 | 数组实现 | 哈希实现 |
|------|:---:|:---:|
| 空间/节点 | 26 指针（固定） | 按需（省空位） |
| 查子节点 | O(1) 下标 | O(1) 平均 |
| 字符集 | 仅小写字母 | 任意字符 |
| 适用 | LeetCode 默认 | 通用场景/大字符集 |

**复杂度总结**：

```text
插入:   O(单词长度 L)
查找:   O(L)
前缀:   O(L)
空间:   O(字符总数 × 字母表大小)

与数据规模 n 无关——只与字符串长度相关！
```

> 💡 对比记忆：HashSet 查单词 O(1) 但空间 O(n)；Trie 查单词 O(L) 但支持前缀 + 共享空间——**「需要前缀操作」是选 Trie 的唯一理由**。

> 🎯 **核心要点**：实现验收——数组版完整类默写（208）；理解 search（isEnd）与 startsWith（下钻成功）的区别；「前缀共享」的空间与时间双收益；复杂度 O(L) 与数据规模无关的性质；工程场景字符集复杂时切哈希实现。
