## 4. 核心概念速查

| 概念 | 一句话说明 | 所在模块 |
|------|-----------|---------|
| 大顶堆/小顶堆 | 父 ≥ 子 / 父 ≤ 子的完全二叉树 | 01 |
| 完全二叉树 | 除最后一层外满节点、最后一层靠左 | 01 |
| 父子下标 | `left = 2i+1, right = 2i+2, parent = (i-1)/2` | 01 |
| siftUp | 新元素上浮：与父比较交换 | 02 |
| siftDown | 删除后下沉：与较大的子交换 | 02 |
| 建堆 | 从 `n/2-1` 向前逐个 siftDown，O(n) | 02/04 |
| PriorityQueue | Java 堆实现：默认小顶堆，`Comparator.reverseOrder()` 大顶堆 | 03 |
| 堆排序 | 建堆 + 反复取顶，O(n log n)，不稳定 | 04 |
| TopK 套路 | 求前 K 大用小顶堆（K 大小）、前 K 小用大顶堆 | 05 |
| 双堆 | 大顶堆+小顶堆对半分，维护中位数 O(1) 查询 | 06 |

> 🎯 **核心要点**：堆的三大黄金应用——**TopK/第 K 大**（小顶堆固定 K 个）、**中位数**（双堆对半分）、**贪心+堆**（每次取最值合并，如合并 K 个有序链表）；面试手写堆只需会 siftUp/siftDown 两个动作；工程上直接用 PriorityQueue，只有面试题才手写。树的其他体系见[二叉树 Binary Tree](../二叉树 Binary Tree/)。
