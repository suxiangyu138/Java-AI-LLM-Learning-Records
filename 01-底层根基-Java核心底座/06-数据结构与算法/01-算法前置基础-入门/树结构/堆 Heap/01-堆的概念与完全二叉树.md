# 01 - 堆的概念与完全二叉树

## 1. 堆的定义

**堆（Heap）**：满足两个条件的树形结构——
1. **完全二叉树**（结构条件）；
2. **堆序性质**（值条件）：任意节点的值与其子节点满足大小关系。

| 名称 | 堆序性质 | 根节点 | 典型用途 |
|------|---------|--------|---------|
| 大顶堆（Max-Heap） | 父节点 ≥ 子节点 | 最大值 | 前 K 小、中位数左半 |
| 小顶堆（Min-Heap） | 父节点 ≤ 子节点 | 最小值 | 前 K 大、中位数右半、Dijkstra |

```text
大顶堆示例：            小顶堆示例：
      10                       1
     /  \                     / \
    9    6                   2   3
   / \   / \                / \ / \
  7  8  4  5               4  5 6  7
```

> 💡 **堆 ≠ 二叉搜索树**：堆只约束「父子大小」，兄弟之间无序（上例 9 和 6 谁大谁小都合法）；BST 约束「左<根<右」。堆是「局部有序」，BST 是「全局有序」。

## 2. 完全二叉树

**完全二叉树**：除最后一层外每一层都是满的，最后一层的节点都**靠左连续**排列。

```text
  完全二叉树 ✓          非完全 ✗（缺 6 的左子，不连续）
     1                       1
    / \                     / \
   2   3                   2   3
  / \                     / \
 4   5                   4
```

**为什么堆用完全二叉树**：
- 节点可以**连续存入数组**，无空位浪费；
- 父子下标有纯数学关系（见第 4 节），不需要指针；
- 树高固定为 ⌊log₂n⌋，操作复杂度可证明为 O(log n)。

## 3. 大顶堆与小顶堆

### 3.1 性质对比

| 维度 | 大顶堆 | 小顶堆 |
|------|--------|--------|
| 根节点 | 全局最大 | 全局最小 |
| 任意节点 | ≥ 所有子孙 | ≤ 所有子孙 |
| 查找最值 | O(1)（直接取根） | O(1) |
| 删除最值 | O(log n) | O(log n) |
| Java 默认 | 需 `Comparator.reverseOrder()` | `PriorityQueue<>()` |

> ⚠️ **只保证「根是最值」**，不保证次最值在根的哪个孩子——所以「第二大」不能简单取根的左/右子比较，要 pop 根后再取新根。

### 3.2 小顶堆的 Java 三件套

```java
PriorityQueue<Integer> minHeap = new PriorityQueue<>();       // 默认小顶堆
minHeap.offer(5);         // 插入，O(log n)
int min = minHeap.peek(); // 查最小值，O(1)
int removed = minHeap.poll(); // 取出最小值，O(log n)
```

## 4. 父子下标关系

堆用数组存储（0 基索引），**下标即结构**：

```java
// 数组表示大顶堆 [10, 9, 6, 7, 8, 4, 5]
// 下标:      0   1  2  3  4  5  6
int parent(int i) { return (i - 1) / 2; }
int left(int i)   { return 2 * i + 1; }
int right(int i)  { return 2 * i + 2; }
```

```text
数组 [10, 9, 6, 7, 8, 4, 5]
       10(0)
      /     \
   9(1)     6(2)
  /   \    /   \
7(3) 8(4) 4(5) 5(6)

验证：left(1) = 2*1+1 = 3 → 7 ✓
      parent(5) = (5-1)/2 = 2 → 6 ✓
```

> 💡 二叉树遍历层序编号与堆数组下标完全对应——这就是「层序遍历 = 数组顺序」的原因。

## 5. 堆的应用场景

| 场景 | 为什么用堆 | 典型题 |
|------|-----------|--------|
| TopK / 第 K 大 | 维护 K 大小堆，O(n log K) | 215 数组第 K 大、347 前 K 高频 |
| 中位数 | 双堆对半分 | 295 数据流中位数 |
| 贪心取最值 | 每次 O(log n) 取全局最值 | 23 合并 K 个链表、378 有序矩阵第 K 小 |
| 任务调度 | 优先级队列 | 621 任务调度器、239 窗口最大值（单调队列替代） |
| Dijkstra | 小顶堆取最小距离 | 743 网络延迟 |
| 堆排序 | 原地排序 O(n log n) | 912 排序数组 |

**「取最值 + 频繁增删」是堆的识别信号**——看到「第 K」「TopK」「每次取最小/最大」直接用堆。

### 5.1 堆的数组表示与层序的对应

```text
大顶堆: [10, 9, 6, 7, 8, 4, 5]
层序:    10 → 9, 6 → 7, 8, 4, 5

规律: 数组下标 = 层序遍历编号（从 0 开始）
      完全二叉树层序 = 数组顺序（无空位）
      这与「二叉树体系」的层序遍历模板天然对应
```

**为什么数组存堆不浪费空间**：完全二叉树无空位——n 个节点的堆恰好占数组前 n 个位置；斜树/普通二叉树用数组会有空洞（最坏浪费一半以上）。

### 5.2 堆与二叉搜索树的本质区别

| 维度 | 堆 | BST |
|------|-----|-----|
| 有序性 | **局部**（父子有序） | **全局**（中序升序） |
| 兄弟关系 | 无序（可任意交换） | 左<根<右 |
| 查任意值 | O(n) | O(log n) |
| 查最值 | **O(1)** | O(log n)（最左/最右） |
| 应用 | TopK/优先级 | 有序集合 |

> ⚠️ 面试对比题「堆和 BST 都取最值怎么选」——**堆查最值 O(1) 但查任意 O(n)，BST 反之**；只要最值用堆、要全序用 BST（详见[计算机中的各种树](../计算机中的各种树/02-堆家族对比.md)）。

### 5.3 常见面试追问

| 追问 | 答题要点 |
|------|---------|
| 为什么堆用完全二叉树？ | 数组连续存储 + 下标算父子 + 树高 log n 保证 |
| 堆的兄弟能比较吗？ | 不能——堆只约束父子，兄弟无序 |
| 「第二大」怎么找？ | 不能取根的左右子比较——要 poll 根后看新根 |
| 堆和优先队列什么关系？ | 优先队列 = 抽象数据类型，堆 = 实现（二叉堆最常见） |
| 堆的插入/删除复杂度？ | 都 O(log n)，上浮/下沉各一次 |

> 🎯 **核心要点**：概念验收——闭眼能画出大/小顶堆示例、写出父子下标三公式、说出「堆只保证根是最值」的局限；识别「第 K/TopK/取最值」信号直接想到堆；面试追问「为什么堆用完全二叉树」的标准答案是：数组连续存储 + 下标算父子 + 树高 log n。
