## 1. 区间统计树对比

| 树 | 核心能力 | 复杂度 | 应用 |
|----|---------|:---:|------|
| 线段树 | 区间查询 + 区间更新（懒标记） | O(log n) | 区间和/最值/众数 |
| 树状数组 | 前缀和 + 单点更新 | O(log n) | 逆序对、动态前缀和 |
| 二叉索引树 | 树状数组别名 | — | — |
| 分块（sqrt 分解） | 区间操作 + 块缓存 | O(√n) | 简单区间题 |

```text
区间问题决策:
  区间查询 + 单点更新 → 树状数组（更轻）
  区间查询 + 区间更新 → 线段树（懒标记）
  查询要求多样（最值+和+历史） → 线段树（灵活合并）
  数据量小（n ≤ 10⁵ 简单题） → 分块/前缀和暴力
```

## 2. 线段树 vs 树状数组

| 维度 | 线段树 | 树状数组 |
|------|:---:|:---:|
| 空间 | O(4n) | O(n) |
| 实现难度 | ★★★★ | ★★ |
| 区间查询 | ✅ 任意区间统计 | 前缀差（减法可逆才可） |
| 区间更新 | ✅ 懒标记 | ❌（需差分技巧） |
| 最值/最大子段和 | ✅ | ❌（只能可逆运算） |
| 常数 | 较大 | **极小（位运算）** |
| 适用 | 复杂区间问题 | 简单前缀/逆序对 |

**选型口诀**：**「加法可逆用树状、复杂合并用线段」**——逆序对/动态前缀和（可逆）树状数组；区间最大子段和/区间众数（不可逆）线段树。

**经典题映射**：

| 题号 | 题目 | 首选 |
|------|------|:---:|
| 307 | 区域和检索（可修改） | 树状数组 ✅ |
| 315 | 计算右侧小于当前元素的个数（逆序对） | 树状数组 ✅ |
| 327 | 区间和的个数 | 树状数组/线段树 |
| 493 | 翻转对 | 树状数组 |
| 699 | 掉落的方块（区间最大值） | 线段树 |
| 1157 | 子数组中占绝大多数的元素 | 线段树 |

## 3. 空间索引树

| 树 | 维度 | 核心思想 | 应用 |
|----|:---:|---------|------|
| KD 树 | 2-K 维 | 交替按维度中位划分 | 最近邻、范围搜索 |
| R 树 | 2D+ | 最小边界矩形（MBR）分层 | 地理信息系统（GIS） |
| 四叉树 | 2D | 空间四等分递归 | 2D 碰撞检测、图像 |
| 八叉树 | 3D | 空间八等分递归 | 3D 游戏场景管理 |
| BSP 树 | 任意 | 平面二分空间 | 3D 渲染 |

```text
最近邻搜索决策:
  数据点少（≤ 10⁴）、维度低 → 暴力/KD 树
  维度高（> 20 维） → KD 树退化，用哈希/LSH（近似）
  地理坐标范围查询 → R 树（PostGIS/数据库空间索引）
  2D 碰撞/区域 → 四叉树
```

**KD 树的构建与查询**：

```text
构建: 按维度轮流取中位数划分（类似二叉搜索树的多维版）
      第 1 层按 x、第 2 层按 y、第 3 层按 x……

查询: 与 BST 搜索同框架 + 剪枝
      目标点与当前节点比较 → 进相应子树
      回溯时检查另一侧是否可能更近（圆与分割面相交）
```

> 💡 KD 树的面试题（LeetCode 973/658 等）通常不需要真实现 KD 树——多数用「排序/堆」即可；KD 树的价值在工程空间索引（点云、推荐系统）。

## 4. 选型速查

| 问题 | 首选 | 备选 |
|------|------|------|
| 区间和 + 单点更新 | 树状数组 | 线段树 |
| 区间更新 + 区间查询 | 线段树（懒标记） | 分块 |
| 区间最值/最大子段和 | 线段树 | — |
| 逆序对计数 | 树状数组 | 归并排序 |
| 2D 最近邻 | KD 树 | 暴力（小数据） |
| 地理范围查询 | R 树 | PostGIS |
| 2D 碰撞检测 | 四叉树 | 空间哈希 |

### 3.1 树状数组模板（对照记忆）

```java
// 树状数组三件套：lowbit / add / query（下标 1 基）
class FenwickTree {
    int[] tree;

    FenwickTree(int n) { tree = new int[n + 1]; }

    int lowbit(int x) { return x & (-x); }          // 最低位 1

    void add(int i, int delta) {                    // 单点更新
        while (i < tree.length) {
            tree[i] += delta;
            i += lowbit(i);
        }
    }

    int query(int i) {                              // 前缀和
        int sum = 0;
        while (i > 0) {
            sum += tree[i];
            i -= lowbit(i);
        }
        return sum;
    }
    // 区间和 [l, r] = query(r) - query(l-1)（可逆运算的体现）
}
```

### 3.2 面试问答

| 问题 | 答案 |
|------|------|
| 树状数组能求区间最大值吗？ | 不能（max 不可逆）；用线段树 |
| 线段树为什么 4n 空间？ | 保守上界（数组树化可能越界 2n） |
| 懒标记是什么？ | 区间更新的延迟下发（查询时才下推） |
| KD 树维度灾难？ | 维度 > 20 时退化近似线性扫描 |
| 空间索引数据库怎么用？ | PostGIS R 树、MySQL 空间索引 |

### 3.3 区间问题选型速记

```text
单点改 + 区间查（可逆） → 树状数组
区间改 + 区间查          → 线段树（懒标记）
静态前缀和              → 直接前缀和数组（O(1)）
二维区间                → 二维树状数组/线段树
```

> 🎯 **核心要点**：区间统计验收——「可逆运算树状数组、复杂合并线段树」口诀；线段树/树状数组的模板（建树/查询/更新）见[高级数据结构](../../../04-中高级算法专题/专题 4：高级数据结构/高级数据结构/线段树/)体系；空间索引树（KD/R/四叉）了解思想与场景即可，工程由数据库/游戏引擎内置。
