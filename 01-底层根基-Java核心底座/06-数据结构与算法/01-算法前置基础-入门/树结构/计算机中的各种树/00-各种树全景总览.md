## 2. 树的全景分类

| 家族 | 核心能力 | 代表树 | 复杂度红利 |
|------|---------|--------|-----------|
| 搜索树 | 有序查找/插入/删除 | BST、AVL、红黑树、B 树 | O(log n) |
| 优先级堆 | 取最值/TopK | 二叉堆、斐波那契堆 | O(1) 查最值 |
| 字符串树 | 前缀/子串匹配 | Trie、后缀树 | 匹配 O(长度) |
| 区间统计 | 区间查询/更新 | 线段树、树状数组 | O(log n) |
| 空间索引 | 多维最近邻 | KD 树、R 树 | 维数相关 |
| 编码树 | 变长编码 | 哈夫曼树 | 最优前缀码 |
| 结构树 | 表达组织关系 | 表达式树、语法树、DOM 树 | — |

> 🎯 **选型一句话**：查什么用什么树——**查有序性用搜索树、查最值用堆、查前缀用 Trie、查区间用线段树**。

## 4. 一句话速查表

| 树 | 一句话定位 | 典型场景 |
|----|-----------|---------|
| BST | 有序二叉搜索树 | 有序 Map（退化风险） |
| AVL | 高度平衡 BST | 只读索引 |
| 红黑树 | 工程平衡 BST | TreeMap、HashMap 树化 |
| B 树 | 磁盘多路平衡树 | 数据库索引 |
| B+ 树 | B 树变体（叶子链表） | InnoDB 主索引 |
| 二叉堆 | 完全二叉树数组堆 | TopK、中位数 |
| Trie | 前缀共享树 | 输入提示、敏感词 |
| 后缀树 | 所有后缀压缩树 | 最长重复子串 |
| 线段树 | 区间统计树 | 区间和/最值 |
| 树状数组 | 轻量前缀树 | 前缀和、逆序对 |
| 哈夫曼树 | 最优前缀编码 | 压缩算法 |
| 并查集 | 连通性森林 | 判环、连通块 |
| KD 树 | 多维空间划分 | 最近邻搜索 |
| 语法树 | 语言结构表示 | 编译器 |

> 🎯 **核心要点**：本目录是「树结构」体系的**导览中枢**——每种树的深度内容在各自体系目录，本目录负责「横向对比 + 场景选型」；学习顺序建议：二叉树 → BST → 平衡树（AVL/红黑）→ B 树，之后按需求取用堆/Trie/线段树。
