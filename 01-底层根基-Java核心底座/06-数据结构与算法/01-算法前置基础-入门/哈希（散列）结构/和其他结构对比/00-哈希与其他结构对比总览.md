## 4. 核心概念速查

| 概念 | 一句话说明 | 所在模块 |
|------|-----------|---------|
| 哈希表 | O(1) 平均、无序、无最坏保证 | 01 |
| 数组 | O(1) 随机访问、O(n) 插入 | 01 |
| 链表 | O(1) 插入（已知位置）、O(n) 查找 | 01 |
| 红黑树 | O(log n) 最坏保证、有序 | 01 |
| 跳表 | O(log n) 平均、有序、可区间 | 01 |
| 有序性 | 树/跳表支持有序遍历 | 01 |
| 最坏保证 | 红黑树唯一 O(log n) | 01 |
| 缓存友好 | 数组最优、链表最差 | 01 |
| 选型决策 | 速度哈希、有序树、区间跳表 | 02 |

## 6. 常见问题 FAQ

| 问题 | 一句话答案 |
|------|-----------|
| 哈希 vs 数组？ | 哈希按键 O(1)、数组按下标 O(1) |
| 哈希 vs 红黑树？ | 哈希平均快、红黑最坏保证 + 有序 |
| 什么时候必须有序结构？ | 排序遍历/区间查询/取极值 |
| 跳表比红黑树好在哪？ | 实现简单、区间查询友好 |
| 哈希的最坏退化？ | O(n)（恶意/失效哈希） |
| 选型第一句？ | 要速度哈希、要有序树、要保证红黑 |


## 15. 一句话总结

| 维度 | 哈希 | 红黑树 | 数组 | 链表 | 跳表 |
|------|:---:|:---:|:---:|:---:|:---:|
| 速度 | ★★★★★ | ★★★ | ★★★★ | ★★ | ★★★ |
| 有序 | ❌ | ✅ | 排序后 | ❌ | ✅ |
| 保证 | ❌ | ✅ | ✅ | ✅ | ⚠️ |
| 缓存 | ★★★ | ★★★ | ★★★★★ | ★ | ★★★ |
| 场景 | Map | TreeMap | 下标 | 插删 | ZSet |

> 🎯 **核心要点**：对比验收——**「要平均速度选哈希、要有序选树、要最坏保证选红黑、要区间选跳表」**四句选型；哈希的「O(1) 平均无保证」与红黑树的「O(log n) 最坏保证」是核心权衡；有序性（树/跳表）是哈希永远缺的能力；缓存友好性（数组 > 哈希 > 链表）在性能敏感场景决定胜负。
