## 6. 常见问题 FAQ

| 问题 | 一句话答案 |
|------|-----------|
| 冲突能避免吗？ | 不能——鸽笼原理必然 |
| 链地址 vs 开放定址？ | 链挂链表、定址找空位 |
| Java 用什么？ | 链地址（+树化） |
| Redis 用什么？ | 链地址（渐进式 rehash） |
| 开放定址的删除问题？ | 需墓碑标记 |
| 装填因子影响冲突吗？ | α 越大冲突越多 |
| 树化阈值为什么 8？ | 泊松概率千万分之六 |
| 冲突严重怎么救？ | 扩容 / 换哈希函数 / 树化 |

## 14. 冲突案例实战

```text
案例 1: HashMap 存 1000 个整数，容量 16
  → α = 62.5 严重超载 → 自动扩容至 2048
  → α = 0.49 → ASL ≈ 1.24 ✓

案例 2: 字符串键全以 "0" 开头（模式聚集）
  → 哈希分布偏斜 → 桶长不均
  → 对策: 检查哈希函数 / 换乘法散列

案例 3: 攻击者构造同哈希 URL 参数
  → 桶长 10 万 → 树化兜底 O(log n) ✓
  → 配合限流彻底解决
```
