## 6. 常见问题 FAQ

| 问题 | 一句话答案 |
|------|-----------|
| 哈希查找为什么 O(1)？ | 一次哈希定位 + 常数级冲突比较 |
| 最坏什么时候 O(n)？ | 全部键同桶（恶意哈希/糟糕函数） |
| 未命中比命中快吗？ | 通常——链短则先到 null |
| 扰动函数作用？ | 混合高低位防低效低位 |
| 为什么 (n-1)&hash 定位？ | n 为 2 的幂时位与 = 取模 |
| 树化后查找变慢吗？ | 链表 8 个时树更快（O(log n)） |
| 扩容后查找？ | 重新 hash 定位（摊还 O(1)） |
| 查找和插入复杂度一样？ | 基本一样（定位 + 链操作） |

## 8. 复杂度对比总表

| 查找方式 | 平均 | 最坏 | 前提 |
|---------|:---:|:---:|------|
| 哈希查找 | **O(1)** | O(n) | 均匀哈希 + 合理 α |
| 二分查找 | O(log n) | O(log n) | 有序数组 |
| 二叉搜索树 | O(log n) | O(n) | 平衡（AVL/红黑 O(log n)） |
| 顺序查找 | O(n) | O(n) | 无前提 |
| 红黑树 | O(log n) | **O(log n)** | 最坏保证 |

## 9. 查找常见场景分析

| 场景 | 查找特点 | 推荐 |
|------|---------|------|
| 频繁按键取值 | 读多 | 哈希表（O(1)） |
| 需要有序遍历 | 全序 | 红黑树（TreeMap） |
| 区间查询 | 范围 | 树/跳表 |
| 大量不存在的查询 | miss 多 | 哈希 + 布隆前置 |
| 数据流动态 | 增删查均衡 | 哈希（摊还 O(1)） |

## 12. 一句话速记卡

```text
三步链路: hash → 定位 → 链查
O(1) 前提: 均匀哈希 + 合理装填因子
最坏 O(n): 恶意/失效哈希（全同桶）
HashMap 细节: 扰动 + (n-1)&hash + 双条件
扩容影响: α 回落 + JDK8 位运算拆链
```

## 13. 查找实战演练

```text
场景 1: 查 userMap.get("zhangsan")
  ① hash("zhangsan") → 扰动 → 0x8f3c...
  ② 桶位 = (16-1) & 0x8f3c = 12
  ③ 桶 12 链表: "lisi" → "zhangsan" ✓（2 次比较）

场景 2: 查不存在键
  ① hash("wangwu") → 桶 3
  ③ 桶 3 为空 → 未命中（0 次比较，最快）

场景 3: 恶意 10000 个同哈希键
  ③ 全部在桶 7 → 链表 10000 → O(n) 退化 ✗
```
