## 6. 常见问题 FAQ

| 问题 | 一句话答案 |
|------|-----------|
| 哈希函数要满足什么性质？ | 确定性、均匀性、高效性、单向性 |
| 为什么取模用质数？ | 减少模式聚集（如 k 是 p 的倍数） |
| 为什么 String 用 31？ | 素数 + 乘法便宜（31 = 32-1 移位优化） |
| 一致性哈希解决什么？ | 分布式节点增减时的最小迁移 |
| 什么是雪崩效应？ | 输入一位变化，输出约一半位变化 |
| 哈希函数和加密哈希区别？ | 加密哈希（SHA）单向性更强、更慢 |
| HashDoS 怎么防御？ | 随机种子、红黑树化、布隆前置 |
| 布隆过滤器能删吗？ | 基本不能（可计数布隆） |
| 哈希函数能逆向吗？ | 工程哈希可暴力；加密哈希不可行 |
| hashCode 与 equals 关系？ | 相等则 hashCode 必等（反之不然） |

## 14. 工程实践检查清单

| 场景 | 检查项 |
|------|--------|
| 自定义对象入 Map | hashCode + equals 是否同时重写 |
| 大键值集合 | 是否考虑布隆过滤器预筛 |
| 分布式分配 | 是否用一致性哈希（而非 hash % n） |
| 用户输入哈希 | 是否有限流/长度限制（防 HashDoS） |
| 哈希函数选型 | 加密哈希是否误用于表哈希 |
| 扩容时机 | 装填因子是否超过 0.75 |

> 🎯 **核心要点**：哈希函数验收——「**确定性 + 均匀性**」是哈希表 O(1) 的根基；质数取模与乘法散列两种经典构造；Java hashCode 的 31 倍设计（素数 + 移位优化）；一致性哈希（环形 + 虚拟节点）是分布式标配；HashDoS 防御（随机种子/树化/布隆）是工程红线；冲突与防御细节见 02 模块与[哈希冲突](../哈希冲突/)。
