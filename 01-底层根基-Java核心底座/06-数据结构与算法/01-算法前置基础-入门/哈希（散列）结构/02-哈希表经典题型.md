## 1. 1. 两数之和：母题深度解析

### 1.1 完整实现（含关键细节）

```java
/**
 * LeetCode 1. 两数之和（面试第一题）
 * 给定数组和目标值，返回和为 target 的两个数的下标。
 *
 * 关键细节：先检查再插入！
 *   - 保证不匹配自身（nums=[3,3], target=6 时）
 *   - 数组未遍历完时，每个补数都能找到正确的配对
 */
public int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> map = new HashMap<>();   // 值 → 下标

    for (int i = 0; i < nums.length; i++) {
        int complement = target - nums[i];          // 补数
        if (map.containsKey(complement)) {
            return new int[]{map.get(complement), i};  // 找到配对
        }
        map.put(nums[i], i);                        // ⚠️ 先查后插！
    }
    return new int[0];
}
```

### 1.2 推演：nums = [2, 7, 11, 15], target = 9

```text
i=0: 补数 7 不在 map → 存 {2:0}
i=1: 补数 7 在 map（下标 0）→ 返回 [0, 1] ✓

// 关键场景 nums = [3, 3], target = 6：
i=0: 补数 3 不在 map（还没存自己）→ 存 {3:0}
i=1: 补数 3 在 map → 返回 [0, 1] ✓
// 如果先插后查：i=0 时补数 3 在 map（自己！）→ 错误返回 [0,0]
```

### 1.3 为什么先查后插？

```text
⚠️ 先查后插防止"自匹配"：
  nums=[3,3], target=6，正确返回 [0,1]
  若先插后查：i=0 时查补数 3，map 里已有自己 → 返回 [0,0] ❌

记忆：处理 nums[i] 时，map 中只应有"之前遍历过的元素"
```

## 2. 217. 存在重复元素

### 2.1 三种解法对比

```java
/**
 * LeetCode 217. 存在重复元素
 * 判断数组中是否有重复元素
 */

// 解法一：HashSet（推荐，O(n)）
public boolean containsDuplicate(int[] nums) {
    Set<Integer> set = new HashSet<>();
    for (int x : nums) {
        if (!set.add(x)) return true;   // add 返回 false = 已存在
    }
    return false;
}

// 解法二：排序（O(n log n)，O(1) 空间）
public boolean containsDuplicate_Sort(int[] nums) {
    Arrays.sort(nums);
    for (int i = 1; i < nums.length; i++) {
        if (nums[i] == nums[i - 1]) return true;
    }
    return false;
}

// 解法三：哈希计数（HashMap 统计频次）
```

| 解法 | 时间 | 空间 | 适用 |
|------|:---:|:---:|------|
| HashSet | O(n) | O(n) | 快速判断 |
| 排序 | O(n log n) | O(1) | 空间受限 |
| 暴力 | O(n²) | O(1) | 不推荐 |

## 3. 242/49. 字母异位词：排序键与计数键

### 3.1 242. 有效的字母异位词

```java
/**
 * LeetCode 242. 有效的字母异位词
 * s 和 t 是否由相同字符组成（字母异位词）
 * "anagram" vs "nagaram" → true
 *
 * 最佳：26 长度计数数组（比哈希表更高效）
 */
public boolean isAnagram(String s, String t) {
    if (s.length() != t.length()) return false;

    int[] count = new int[26];             // 小写字母计数
    for (int i = 0; i < s.length(); i++) {
        count[s.charAt(i) - 'a']++;        // s 加
        count[t.charAt(i) - 'a']--;        // t 减
    }
    for (int c : count) {
        if (c != 0) return false;          // 任何计数不为 0 → 不同
    }
    return true;
}
```

### 3.2 49. 字母异位词分组（两种键）

```java
/**
 * LeetCode 49. 字母异位词分组
 * 把字母异位词分到同一组
 * ["eat","tea","tan","ate","nat","bat"]
 * → [["eat","tea","ate"],["tan","nat"],["bat"]]
 *
 * 核心：找"规范键"——异位词共享的标识
 */

// 方法一：排序键（直观）
//   "eat" 排序 → "aet"；"tea" 排序 → "aet" → 同组
public List<List<String>> groupAnagrams(String[] strs) {
    Map<String, List<String>> map = new HashMap<>();
    for (String s : strs) {
        char[] chars = s.toCharArray();
        Arrays.sort(chars);                 // 排序做键
        String key = new String(chars);
        map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
    }
    return new ArrayList<>(map.values());
}

// 方法二：计数键（更高效，免排序）
//   "eat" → "#1#0#0#...#1#1..."（26 位计数串）
public List<List<String>> groupAnagrams_Count(String[] strs) {
    Map<String, List<String>> map = new HashMap<>();
    for (String s : strs) {
        int[] count = new int[26];
        for (char c : s.toCharArray()) count[c - 'a']++;
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < 26; i++) {
            sb.append('#').append(count[i]);   // "#1#1#1#0..."
        }
        String key = sb.toString();
        map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
    }
    return new ArrayList<>(map.values());
}
```

### 3.3 键的设计思路

```text
"异位词分组"的核心：构造规范键
  键要求：异位词共享同键，非异位词不同键
  方案：排序键（O(k log k)）/ 计数键（O(k)）
  —— 面试讲解两种方案并说明计数键更优，是加分点
```

## 4. 128. 最长连续序列

### 4.1 完整实现（起点剪枝）

```java
/**
 * LeetCode 128. 最长连续序列（O(n) 时间！）
 * 给定未排序数组，找最长连续序列的长度
 * [100,4,200,1,3,2] → 1,2,3,4 → 4
 *
 * 核心优化：起点剪枝
 *   只有"没有前驱"的数才作为序列起点开始统计
 *   if (!set.contains(num - 1)) → 才从头统计
 *   保证每个数只被统计一次 → O(n)
 */
public int longestConsecutive(int[] nums) {
    Set<Integer> set = new HashSet<>();
    for (int x : nums) set.add(x);

    int maxLen = 0;
    for (int x : set) {                       // ⚠️ 遍历 set 去重
        if (!set.contains(x - 1)) {           // 剪枝：不是起点就跳过
            int cur = x;
            int len = 1;
            while (set.contains(cur + 1)) {   // 向后扩展
                cur++;
                len++;
            }
            maxLen = Math.max(maxLen, len);
        }
    }
    return maxLen;
}
```

### 4.2 为什么起点剪枝是 O(n)？

```text
朴素做法：对每个数都 while 向后数 → O(n²)（如 [1,2,3,...,n]）
起点剪枝：
  只有 x-1 不在集合中才开始统计（序列的开头）
  每个数最多被统计一次 → 总 O(n)

关键理解：
  [1,2,3,4,5] 中，只有 1 是起点（0 不在集合）
  → 只从 1 数到 5，其他数直接跳过
```

## 5. 560. 和为 K 的子数组：前缀和+哈希

### 5.1 完整实现

```java
/**
 * LeetCode 560. 和为 K 的子数组
 * 统计和为 k 的连续子数组个数
 * nums=[1,1,1], k=2 → [1,1] 出现 2 次 → 2
 *
 * 前缀和思想：
 *   pre[j] - pre[i] = sum(i+1..j)
 *   找 pre[j] - k 是否出现过 → 哈希记录前缀和出现次数
 *
 * ⚠️ 为什么不用滑动窗口？
 *   数组含负数时窗口收缩不单调 → 滑动窗口失效！
 */
public int subarraySum(int[] nums, int k) {
    Map<Integer, Integer> prefixCount = new HashMap<>();
    prefixCount.put(0, 1);        // ⚠️ 前缀和为 0 出现 1 次（空前缀）

    int sum = 0, count = 0;
    for (int x : nums) {
        sum += x;                 // 当前前缀和
        // 找有多少个前缀和 = sum - k
        count += prefixCount.getOrDefault(sum - k, 0);
        prefixCount.put(sum, prefixCount.getOrDefault(sum, 0) + 1);
    }
    return count;
}
```

### 5.2 推演：nums = [1, 1, 1], k = 2

```text
初始化: {0:1}, sum=0, count=0
x=1: sum=1, 查 1-2=-1 → 0 个；存 {0:1, 1:1}
x=1: sum=2, 查 2-2=0 → 1 个（[1,1]）；存 {0:1, 1:1, 2:1}
x=1: sum=3, 查 3-2=1 → 1 个（[1,1]）；存 {0:1, 1:1, 2:1, 3:1}
count = 2 ✓
```

## 6. 哈希表题型家族图谱

### 6.1 五大题型总结

| 题型 | 哈希的角色 | 代表题 | 复杂度 |
|------|------|:---:|:---:|
| 查找补数 | 值→下标，O(1) 配对 | 1/167 | O(n) |
| 判重 | Set 去重 | 217/219 | O(n) |
| 分组/映射 | 规范键→列表 | 49/242 | O(nk) |
| 连续序列 | Set 成员查询 + 剪枝 | 128 | O(n) |
| 前缀和统计 | 前缀和→次数 | 560/974 | O(n) |

### 6.2 面试解题话术

```text
"这道题我的思路是：暴力是 O(n²) 的内层循环扫描。
 用哈希表替换内层循环——把已遍历的元素存进哈希表，
 需要查找时 O(1) 命中。
 需要注意的细节是【先查后插/起点剪枝/初始化 0:1】..."
```

> 🎯 **核心要点**：哈希表题型就是"元模式"的五种变体——**找补数、判重、分组、连续查询、前缀和统计**。两数之和的"先查后插"、128 的"起点剪枝"、560 的"初始化 0:1"是三个必须记住的关键细节。遇到 O(n²) 的暴力解法，第一反应就是"能否用哈希表换内层循环"。
