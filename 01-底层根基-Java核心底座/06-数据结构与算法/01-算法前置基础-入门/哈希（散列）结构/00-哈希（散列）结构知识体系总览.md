## 4. 核心概念速查

| 概念 | 一句话说明 | 所在模块 |
|------|-----------|---------|
| 哈希函数 | 任意输入 → 定长输出的映射函数 | 01/06 |
| 冲突解决 | 链地址法（Java 默认）/开放定址/再哈希 | 01 |
| 负载因子 | 元素数/桶数，HashMap 默认 0.75 触发扩容 | 01/04 |
| 扰动函数 | `(h = key.hashCode()) ^ (h >>> 16)` 高低位混合 | 04 |
| 树化 | 链表长度 ≥ 8 且容量 ≥ 64 转红黑树 | 04 |
| 键设计 | 自定义 key 必须同时重写 hashCode + equals | 04/07 |
| HashDoS | 恶意构造同哈希键使查询退化为 O(n) | 07 |
| 一致性哈希 | 分布式缓存节点增减最小化数据迁移 | 07 |
| 布隆过滤器 | 位数组 + 多次哈希，存在误判的集合 | 07 |
| 空间换时间 | 哈希的本质：O(n) 空间换 O(1) 查询 | 02 |

> 🎯 **核心要点**：哈希体系的验收标准——算法题中「**用哈希表换掉内层循环**」（O(n²)→O(n)）是最值钱的元模式（两数之和/和为 K 的子数组）；面试中 HashMap 源码（扰动函数、树化阈值、扩容）是 Java 必背；自定义 key 的 hashCode+equals 契约是工程红线。数组技巧部分见[数组知识体系总览](../线性结构/数组/00-数组知识体系总览.md)。
