## 1. 3. 无重复字符的最长子串

### 1.1 完整实现（滑动窗口）

```java
/**
 * LeetCode 3. 无重复字符的最长子串（Hot 100 最高频）
 * 滑窗：右扩左缩 + 频次数组
 */
public int lengthOfLongestSubstring(String s) {
    int[] count = new int[128];         // ASCII 频次
    int left = 0;
    int maxLen = 0;

    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        count[c]++;                     // ① 扩窗

        while (count[c] > 1) {          // ② 缩窗（有重复）
            count[s.charAt(left)]--;
            left++;
        }

        maxLen = Math.max(maxLen, right - left + 1);   // ③ while 外
    }
    return maxLen;
}
// 推演 "abcabcbb" → 3 ✓
// ⚠️ 面试必答：
//   "缩窗用 while（缩一次可能仍不合法）；
//    最长在 while 外更新（缩完才合法）。"
```

## 2. 5. 最长回文子串

### 2.1 完整实现（中心扩展）

```java
/**
 * LeetCode 5. 最长回文子串
 * 中心扩展：2n-1 个中心（奇偶）
 */
public String longestPalindrome(String s) {
    int start = 0, maxLen = 0;

    for (int i = 0; i < s.length(); i++) {
        int len1 = expand(s, i, i);         // 奇数中心
        int len2 = expand(s, i, i + 1);     // 偶数中心
        int len = Math.max(len1, len2);

        if (len > maxLen) {
            maxLen = len;
            start = i - (len - 1) / 2;      // 计算起点
        }
    }
    return s.substring(start, start + maxLen);
}

private int expand(String s, int left, int right) {
    while (left >= 0 && right < s.length()
           && s.charAt(left) == s.charAt(right)) {
        left--;
        right++;
    }
    return right - left - 1;      // 回文长度
}
// 推演 "babad" → "bab" 或 "aba" ✓
// ⚠️ 2n-1 个中心：n 个奇数 + n-1 个偶数
// ⚠️ 起点公式：i - (len-1)/2
// ⚠️ 追问"更快" → Manacher O(n)（加分）
```

## 3. 125. 验证回文串

### 3.1 完整实现（对撞 + 跳过）

```java
/**
 * LeetCode 125. 验证回文串
 * 忽略大小写和非字母数字字符
 */
public boolean isPalindrome(String s) {
    int left = 0, right = s.length() - 1;

    while (left < right) {
        // 跳过非字母数字
        while (left < right && !Character.isLetterOrDigit(s.charAt(left))) {
            left++;
        }
        while (left < right && !Character.isLetterOrDigit(s.charAt(right))) {
            right--;
        }
        // 比较（忽略大小写）
        if (Character.toLowerCase(s.charAt(left))
            != Character.toLowerCase(s.charAt(right))) {
            return false;
        }
        left++;
        right--;
    }
    return true;
}
// "A man, a plan, a canal: Panama" → true ✓
// ⚠️ 变体：680 验证回文串 II（可删一个 → 分叉检查）
```

## 4. 28. 找出字符串中第一个匹配项的下标

### 4.1 完整实现（KMP）

```java
/**
 * LeetCode 28. 找出字符串中第一个匹配项的下标（KMP）
 */
public int strStr(String haystack, String needle) {
    int n = haystack.length(), m = needle.length();
    if (m == 0) return 0;

    // ① next 构建
    int[] next = new int[m];
    int j = 0;
    for (int i = 1; i < m; i++) {
        while (j > 0 && needle.charAt(i) != needle.charAt(j)) {
            j = next[j - 1];             // ⚠️ while 回退！
        }
        if (needle.charAt(i) == needle.charAt(j)) j++;
        next[i] = j;
    }

    // ② 匹配（主串不回溯）
    j = 0;
    for (int i = 0; i < n; i++) {
        while (j > 0 && haystack.charAt(i) != needle.charAt(j)) {
            j = next[j - 1];
        }
        if (haystack.charAt(i) == needle.charAt(j)) j++;
        if (j == m) return i - m + 1;
    }
    return -1;
}
// 推演 haystack="sadbutsad", needle="sad" → 0 ✓
// ⚠️ 面试必答：
//   "KMP 主串不回溯（O(n+m)）；
//    失配用 while 回退（可能多次）。"
```

## 5. 344. 反转字符串

### 5.1 完整实现（对撞交换）

```java
/**
 * LeetCode 344. 反转字符串
 * 原地反转字符数组（O(1) 空间）
 */
public void reverseString(char[] s) {
    int left = 0, right = s.length - 1;
    while (left < right) {
        char temp = s[left];
        s[left] = s[right];
        s[right] = temp;
        left++;
        right--;
    }
}
// 变体：541 反转字符串 II（每 2k 反转前 k）
// ⚠️ 面试必答："对撞交换 O(1) 空间——
//   左右指针相向移动，交换到相遇。"
```

## 6. 151. 反转字符串中的单词

### 6.1 完整实现（split + 逆序）

```java
/**
 * LeetCode 151. 反转字符串中的单词
 * "the sky is blue" → "blue is sky the"
 * 单词间可能多个空格，去掉多余空格
 */
public String reverseWords(String s) {
    String[] words = s.trim().split("\\s+");   // ⚠️ 多个空格

    StringBuilder sb = new StringBuilder();
    for (int i = words.length - 1; i >= 0; i--) {
        sb.append(words[i]);
        if (i > 0) sb.append(' ');
    }
    return sb.toString();
}
// 推演 "  hello world  " → "world hello" ✓
// ⚠️ 三个细节：
//   ① trim 去首尾空格
//   ② split("\\s+") 处理多个空格（正则转义！）
//   ③ 逆序拼接
// ⚠️ 变体：557 反转单词 III（每个单词内部反转）
```

## 7. 14. 最长公共前缀

### 7.1 完整实现（纵向扫描）

```java
/**
 * LeetCode 14. 最长公共前缀
 * ["flower","flow","flight"] → "fl"
 * 纵向扫描：以第一个字符串为基准逐列比较
 */
public String longestCommonPrefix(String[] strs) {
    if (strs.length == 0) return "";

    String first = strs[0];
    for (int i = 0; i < first.length(); i++) {
        char c = first.charAt(i);
        for (int j = 1; j < strs.length; j++) {
            // ⚠️ 越界 或 字符不同 → 前缀结束
            if (i >= strs[j].length() || strs[j].charAt(i) != c) {
                return first.substring(0, i);
            }
        }
    }
    return first;                    // 第一个就是公共前缀
}
// ⚠️ 三种解法：纵向扫描（逐列）/横向（两两）/二分
// ⚠️ 面试必答："纵向扫描 O(S)（S = 总字符数），
//   第一个字符串为基准，逐列比较所有字符串。"
```

## 8. 242. 有效的字母异位词

### 8.1 完整实现（计数数组）

```java
/**
 * LeetCode 242. 有效的字母异位词
 * 计数数组双向加减 → 全部为 0 则异位词
 */
public boolean isAnagram(String s, String t) {
    if (s.length() != t.length()) return false;

    int[] count = new int[26];
    for (int i = 0; i < s.length(); i++) {
        count[s.charAt(i) - 'a']++;    // s 加
        count[t.charAt(i) - 'a']--;    // t 减
    }
    for (int c : count) {
        if (c != 0) return false;      // ⚠️ 任何计数不为 0 → 不同
    }
    return true;
}
// "anagram" vs "nagaram" → true ✓
// O(n) 时间 O(1) 空间（固定 26）
// ⚠️ 值域大（Unicode）→ 改 HashMap
```

## 9. 76. 最小覆盖子串

### 9.1 完整实现（滑窗 Hard）

```java
/**
 * LeetCode 76. 最小覆盖子串（字节/腾讯高频 Hard）
 * valid 记录"已满足的字符种类数"
 */
public String minWindow(String s, String t) {
    int[] need = new int[128];
    for (char c : t.toCharArray()) need[c]++;

    int required = 0;
    for (int x : need) if (x > 0) required++;   // t 的种类数

    int left = 0, valid = 0, minLen = Integer.MAX_VALUE, start = 0;

    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        if (need[c] > 0) {
            need[c]--;
            if (need[c] == 0) valid++;          // 该类满足
        }

        while (valid == required) {             // ⚠️ 合法就缩（最短型）
            if (right - left + 1 < minLen) {
                minLen = right - left + 1;
                start = left;
            }
            char out = s.charAt(left);
            if (need[out] > 0) {
                if (need[out] == 0) valid--;    // 满足被破坏
                need[out]++;
            }
            left++;
        }
    }
    return minLen == Integer.MAX_VALUE ? ""
        : s.substring(start, start + minLen);
}
// 推演 s="ADOBECODEBANC", t="ABC" → "BANC" ✓
// ⚠️ 面试必答：
//   "valid = 已满足的字符种类数（不是数量）——
//    O(1) 判断合法；最短型在 while 内更新。"
```

## 10. 1143. 最长公共子序列

### 10.1 完整实现（双序列 DP）

```java
/**
 * LeetCode 1143. 最长公共子序列
 * dp[i][j] = text1[0..i-1] 与 text2[0..j-1] 的 LCS
 */
public int longestCommonSubsequence(String text1, String text2) {
    int m = text1.length(), n = text2.length();
    int[][] dp = new int[m + 1][n + 1];

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                dp[i][j] = dp[i - 1][j - 1] + 1;    // 对角+1
            } else {
                dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }
    return dp[m][n];
}
// 推演 "abcde" vs "ace" → 3 ✓
// ⚠️ 追问：
//   "输出 LCS？→ 反向追溯 dp 表"
//   "空间优化？→ 交替行 O(min(m,n))"
```

## 11. 22. 生成括号

### 11.1 完整实现（回溯）

```java
/**
 * LeetCode 22. 生成括号
 * 约束：任意前缀中 '(' 数 ≥ ')' 数
 */
public List<String> generateParenthesis(int n) {
    List<String> res = new ArrayList<>();
    backtrack(n, 0, 0, new StringBuilder(), res);
    return res;
}

private void backtrack(int n, int open, int close,
                       StringBuilder path, List<String> res) {
    if (path.length() == 2 * n) {              // 长度达标
        res.add(path.toString());
        return;
    }

    if (open < n) {                            // 还能加左括号
        path.append('(');
        backtrack(n, open + 1, close, path, res);
        path.deleteCharAt(path.length() - 1);
    }
    if (close < open) {                        // ⚠️ 右括号 < 左括号才能加
        path.append(')');
        backtrack(n, open, close + 1, path, res);
        path.deleteCharAt(path.length() - 1);
    }
}
// n=2 → ["(())","()()"] ✓
// ⚠️ 剪枝写法：选择前判断（close < open）★ 推荐
//   或递归入口判断（close > open → return）
// ⚠️ 结果数 = 卡特兰数 C(2n,n)/(n+1)
```

## 12. 459. 重复的子字符串

### 12.1 完整实现（KMP next 应用）

```java
/**
 * LeetCode 459. 重复的子字符串
 * 判断 s 是否可以由子串重复构成
 * 最小周期 = n - next[n-1]
 */
public boolean repeatedSubstringPattern(String s) {
    int n = s.length();
    int[] next = buildNext(s);           // 复用 KMP next

    int period = n - next[n - 1];        // ⚠️ 最小周期长度
    return period < n && n % period == 0;
}

private int[] buildNext(String s) {
    int m = s.length();
    int[] next = new int[m];
    int j = 0;
    for (int i = 1; i < m; i++) {
        while (j > 0 && s.charAt(i) != s.charAt(j)) j = next[j - 1];
        if (s.charAt(i) == s.charAt(j)) j++;
        next[i] = j;
    }
    return next;
}
// "abab"：next[3]=2 → period = 4-2 = 2 → 4%2==0 → true ✓
// "aba"：next[2]=1 → period = 3-1 = 2 → 3%2≠0 → false ✓
// ⚠️ 面试必答：
//   "最小周期 = n - next[n-1]——
//    最长公共前后缀的重叠部分 = n - 周期。"
```
