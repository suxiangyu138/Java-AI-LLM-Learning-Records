## 1. 四大模式的识别体系

### 1.1 四大模式总览

```
① 滑动窗口：最长/最短子串（3/76/567）
② 双指针：反转/回文验证（344/125/151）
③ DP：双序列（1143/72/10）
④ 回溯：组合/分割（17/131/22）

⚠️ 70% 字符串题可归为四大模式
  → 先识别模式再套模板
```

### 1.2 模式识别信号

| 模式 | 识别信号 | 代表题 |
|------|------|:---:|
| 滑窗 | "最长/最短子串" | 3/76 |

```

"这题属于哪个模式？
 连续子串 → 滑窗；

```

  四大模式 = 保底（必须熟练）

## 2. KMP 的完整原理

### 2.1 核心思想

```
暴力匹配：主串指针反复回溯 → O(n×m)
KMP：预处理 next 数组 → 主串不回溯 → O(n+m)

关键：利用"已匹配部分"的最长公共前后缀
  跳过不可能的位置

⚠️ next 数组定义：
  next[i] = pattern[0..i-1] 的最长公共前后缀长度
  （写代码前先声明定义！）
```

### 2.2 完整实现（28. strStr）

```java
/**
 * LeetCode 28. 找出字符串中第一个匹配项的下标
 * KMP 两段：next 构建 + 匹配（都是 while 回退）
 */
public int strStr(String haystack, String needle) {
    int n = haystack.length(), m = needle.length();
    if (m == 0) return 0;
    if (n < m) return -1;

    // ═══════ ① next 数组构建 ═══════
    int[] next = new int[m];
    int j = 0;
    for (int i = 1; i < m; i++) {
        // ⚠️ 失配回退用 while（可能多次回退）！
        while (j > 0 && needle.charAt(i) != needle.charAt(j)) {
            j = next[j - 1];             // 回退到更短的前后缀
        }
        if (needle.charAt(i) == needle.charAt(j)) {
            j++;
        }
        next[i] = j;
    }

    // ═══════ ② 匹配（主串不回溯）═══════
    j = 0;
    for (int i = 0; i < n; i++) {
        while (j > 0 && haystack.charAt(i) != needle.charAt(j)) {
            j = next[j - 1];
        }
        if (haystack.charAt(i) == needle.charAt(j)) {
            j++;
        }
        if (j == m) {
            return i - m + 1;            // 匹配成功
        }
    }
    return -1;
}
// ⚠️ 面试必答：
//   "KMP 主串指针永不回溯——失配时模式串
//    跳到 next 位置。O(n+m)（主串 n 次 +
//    j 回退摊还 O(1)）。"
```

### 2.3 next 数组的应用

```
① 28 子串匹配（标准）
② 459 重复子字符串（最小周期 = n-next[n-1]）
③ 214 最短回文串（逆序拼接求 next）

⚠️ 面试定位：
  "思想要懂，手撕看公司"
  大厂可能要求手撕或讲清 next 数组
```

## 3. Manacher 的对称性

### 3.1 核心思想

```
中心扩展 O(n²)：每个中心独立扩展
Manacher O(n)：利用回文对称性复用结果

关键：
  center/right：当前最右回文的中心和右边界
  i 在 [center, right] 内 → 半径至少 =
    min(对称点 i' 的半径, right - i)
  → 已算过的部分不重复扩展

⚠️ 预处理：插入 # 统一奇偶
  "aba" → "#a#b#a#"
  "abba" → "#a#b#b#a#"（中心 #）
```

### 3.2 完整实现（5. 最长回文子串）

```java
/**
 * LeetCode 5. 最长回文子串（Manacher O(n)）
 */
public String longestPalindrome(String s) {
    // ① 预处理：插入分隔符
    StringBuilder sb = new StringBuilder("^");
    for (char c : s.toCharArray()) sb.append('#').append(c);
    sb.append("#$");
    char[] t = sb.toString().toCharArray();
    int n = t.length;

    int[] radius = new int[n];
    int center = 0, right = 0;       // 最右回文的中心和右边界
    int maxLen = 0, maxCenter = 0;

    for (int i = 1; i < n - 1; i++) {
        // ② 初始化半径：利用对称性
        if (i < right) {
            int mirror = 2 * center - i;        // i 的对称点
            radius[i] = Math.min(right - i, radius[mirror]);
        }

        // ③ 中心扩展（只扩展未覆盖部分）
        while (t[i + radius[i] + 1] == t[i - radius[i] - 1]) {
            radius[i]++;
        }

        // ④ 更新最右回文
        if (i + radius[i] > right) {
            center = i;
            right = i + radius[i];
        }

        // ⑤ 记录最大
        if (radius[i] > maxLen) {
            maxLen = radius[i];
            maxCenter = i;
        }
    }

    // 还原：半径-1 = 原串回文长度
    int start = (maxCenter - maxLen) / 2;
    return s.substring(start, start + maxLen);
}
// ⚠️ 面试定位：
//   中心扩展 O(n²) 是标准答案
//   Manacher 是加分项（深度展示）
```

## 4. 滚动哈希的应用

### 4.1 核心公式

```
多项式哈希：hash(s) = Σ s[i] × base^i
窗口滚动（O(1)）：
  window = (window - old×power) × base + new
  去旧首 → 升幂 → 加新尾

⚠️ 记忆："去旧首，升幂，加新尾"
  power = base^(m-1)（旧首字符的权重）
```

### 4.2 应用：最长重复子串（二分+哈希）

```
① 单调性：长度 len 有重复 → 更短也有
  → 可二分
② check(len)：O(n) 滚动哈希查重
  → O(n log n)

⚠️ 冲突处理（双保险）：
  哈希相等时实际比较子串
  概率 1/10⁹ + 验证兜底 → 100% 正确
```

### 4.3 三大专项的选型

```
KMP：单模式匹配（确定正确）
Manacher：最长回文（O(n) 最优）
滚动哈希：子串查重（Set 利器）

⚠️ 面试表达：
"匹配用 KMP（确定性）；查重用滚动哈希
 （O(1) 子串比较）；回文用 Manacher（O(n)）。"
```

## 5. 字符串的 Java 细节

### 5.1 不可变性与拼接

```
String 不可变 → 循环拼接 O(n²)
StringBuilder → O(n)（单线程）
StringBuffer → O(n)（线程安全，同步开销）

⚠️ 面试必答：
"循环拼接用 StringBuilder——String 不可变，
 每次 + 都创建新对象 O(n²)。"
```

### 5.2 equals vs ==

```
==：比较引用（地址）
equals：比较内容

⚠️ 字符串池：
  "abc" == "abc" → true（池中共享）
  new String("abc") == "abc" → false（不同对象）

⚠️ 面试必答：
"String 比较永远用 equals——
 == 比较引用，字符串池只是特例。"
```

### 5.3 常用 API 与陷阱

```
substring(1, 3)：左闭右开
split("\\s+")：正则需要转义
toCharArray()：修改不影响原串
charAt(i)：O(1) 直接访问

⚠️ 易错：
  split 的参数是正则（. 需转义）
  substring 越界（左闭右开）
  Unicode 字符可能占 2 个 char（了解）
```

## 6. 进阶总结

### 6.1 进阶要点速查

```
① 四大模式：滑窗/双指针/DP/回溯（70% 覆盖）
② KMP：next 数组 + 主串不回溯（O(n+m)）
③ Manacher：对称性复用（O(n)）
④ 滚动哈希：去旧首升幂加新尾（O(1) 滚动）
⑤ Java 细节：StringBuilder/equals/转义
```

### 6.2 面试话术模板

```
"字符串题先识别模式：
 连续子串 → 滑窗；
 双序列 → DP；
 所有方案 → 回溯。
 专项：匹配用 KMP（O(n+m)）、
 回文用中心扩展（追问 Manacher）、
 查重用滚动哈希。
 Java 细节：拼接 StringBuilder、比较 equals。"
```

### 6.3 易错点清单

| 错误 | 后果 | 修正 |
|------|------|------|
| 拼接用 + | O(n²) | StringBuilder |
| 比较用 == | 结果错 | equals |
| KMP 回退用 if | 死循环 | while |
| split 忘转义 | 分割错 | "\\s+" |
| substring 越界 | 异常 | 左闭右开 |

> 🎯 **核心要点**：字符串进阶 = **模式识别**（四大模式 70% 覆盖）+ **三大专项**（KMP/Manacher/滚动哈希）+ **Java 细节**（StringBuilder/equals）。"先识别模式再套模板"是方法论；KMP 的 while 回退与滚动公式是两大必背细节。
