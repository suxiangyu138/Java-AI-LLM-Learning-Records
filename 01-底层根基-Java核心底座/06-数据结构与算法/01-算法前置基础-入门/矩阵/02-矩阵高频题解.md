## 1. 48. 旋转图像

### 1.1 题目与思路

```
n×n 顺时针旋转 90°（原地）
两段式：转置（i<j 交换）→ 水平翻转每行
⚠️ 01 模块有"循环交换"与"两段式"双解，此处给最稳写法
```

### 1.2 完整代码（两段式）

```java
/**
 * LeetCode 48. 旋转图像
 * ⚠️ 旋转 90° = 转置 + 水平翻转（推导见 01 模块）
 */
public void rotate(int[][] matrix) {
    int n = matrix.length;
    // ① 转置（只交换上三角）
    for (int i = 0; i < n; i++)
        for (int j = i + 1; j < n; j++) {
            int t = matrix[i][j];
            matrix[i][j] = matrix[j][i];
            matrix[j][i] = t;
        }
    // ② 水平翻转（每行左右对折）
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n / 2; j++) {
            int t = matrix[i][j];
            matrix[i][j] = matrix[i][n - 1 - j];
            matrix[i][n - 1 - j] = t;
        }
}
// 推演 [[1,2,3],[4,5,6],[7,8,9]]：
//   转置 → [[1,4,7],[2,5,8],[3,6,9]]
//   水平 → [[7,4,1],[8,5,2],[9,6,3]] ✓
// ⚠️ 逆时针 90° = 转置 + 垂直翻转（对称记忆）
```

## 2. 54/59. 螺旋矩阵 I & II

### 2.1 题目与思路

```
54：按螺旋顺序读取矩阵
59：按螺旋顺序填充矩阵（逆操作）
共用"四边界收缩"模板：
  右 → 下 → 左 → 上，每走完一边收缩边界
⚠️ 54 的 break 防重复（单行/单列）
```

### 2.2 双题完整代码

```java
/** 54. 螺旋矩阵（读取） */
public List<Integer> spiralOrder(int[][] matrix) {
    List<Integer> res = new ArrayList<>();
    int top = 0, bottom = matrix.length - 1;
    int left = 0, right = matrix[0].length - 1;

    while (top <= bottom && left <= right) {
        for (int j = left; j <= right; j++) res.add(matrix[top][j]);
        top++;
        for (int i = top; i <= bottom; i++) res.add(matrix[i][right]);
        right--;
        if (top > bottom || left > right) break;   // ⚠️ 防单行/列重复
        for (int j = right; j >= left; j--) res.add(matrix[bottom][j]);
        bottom--;
        for (int i = bottom; i >= top; i--) res.add(matrix[i][left]);
        left++;
    }
    return res;
}
// 推演 [[1,2,3],[4,5,6],[7,8,9]]：
//   1,2,3 → 6,9 → 8,7 → 4 → 5 ✓

/** 59. 螺旋矩阵 II（填充，模板逆用） */
public int[][] generateMatrix(int n) {
    int[][] res = new int[n][n];
    int top = 0, bottom = n - 1, left = 0, right = n - 1;
    int val = 1;

    while (top <= bottom && left <= right) {
        for (int j = left; j <= right; j++) res[top][j] = val++;
        top++;
        for (int i = top; i <= bottom; i++) res[i][right] = val++;
        right--;
        if (top > bottom || left > right) break;
        for (int j = right; j >= left; j--) res[bottom][j] = val++;
        bottom--;
        for (int i = bottom; i >= top; i--) res[i][left] = val++;
        left++;
    }
    return res;
}
// ⚠️ 54/59 是同一模板的"读写两面"——面试说出
//   "读取是填充的逆操作"即可
```

## 3. 73. 矩阵置零

### 3.1 题目与思路

```
含 0 的行与列全部置 0（O(1) 空间）
首行首列借位标记（01 模块详解）+ 从下往上处理
```

### 3.2 完整代码

```java
/**
 * LeetCode 73. 矩阵置零（O(1) 空间）
 */
public void setZeroes(int[][] matrix) {
    int m = matrix.length, n = matrix[0].length;
    boolean firstRowZero = false, firstColZero = false;

    for (int j = 0; j < n; j++) if (matrix[0][j] == 0) firstRowZero = true;
    for (int i = 0; i < m; i++) if (matrix[i][0] == 0) firstColZero = true;

    // ⚠️ 标记：内部 0 记到首行首列
    for (int i = 1; i < m; i++)
        for (int j = 1; j < n; j++)
            if (matrix[i][j] == 0) {
                matrix[i][0] = 0;
                matrix[0][j] = 0;
            }

    // ⚠️ 从下往上/从右往左：保护首行首列的标记
    for (int i = m - 1; i >= 1; i--)
        for (int j = n - 1; j >= 1; j--)
            if (matrix[i][0] == 0 || matrix[0][j] == 0)
                matrix[i][j] = 0;

    if (firstRowZero) for (int j = 0; j < n; j++) matrix[0][j] = 0;
    if (firstColZero) for (int i = 0; i < m; i++) matrix[i][0] = 0;
}
// 推演 [[1,1,1],[1,0,1],[1,1,1]]：
//   标记：matrix[1][0]=0, matrix[0][1]=0
//   从下往上：行 1/2 与列 1/2 全置 0 → [[1,0,1],[0,0,0],[1,0,1]] ✓
// ⚠️ 面试表达："O(1) 空间的代价是'标记位被占用'——
//   首行首列原本的值用两个布尔保住，其余全部借位。"
```

## 4. 74. 搜索二维矩阵

### 4.1 题目与思路

```
每行整体大于前行 → 展平后是递增数组 → 一维二分
⚠️ 关键识别："完全有序"（row-major 展平递增）≠ "行列有序"
  74 满足前者 → 二分；240 只满足后者 → 右上角走
```

### 4.2 完整代码

```java
/**
 * LeetCode 74. 搜索二维矩阵（展平二分）
 * ⚠️ 一维下标 ↔ 二维坐标：mid / n 与 mid % n
 */
public boolean searchMatrix(int[][] matrix, int target) {
    int m = matrix.length, n = matrix[0].length;
    int lo = 0, hi = m * n - 1;

    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;
        int v = matrix[mid / n][mid % n];        // ⚠️ 下标转换
        if (v == target) return true;
        if (v < target) lo = mid + 1;
        else hi = mid - 1;
    }
    return false;
}
// 推演 [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target=3：
//   展平 [1,3,5,7,10,11,16,20,23,30,34,60] 二分 → 找到 3 ✓
// ⚠️ 复杂度：O(log(mn))，空间 O(1)
// ⚠️ 面试表达："74 的判定：matrix[i][n-1] < matrix[i+1][0]
//   （行尾 < 下行头）→ 展平严格递增 → 可二分。"
```

## 5. 240. 搜索二维矩阵 II

### 5.1 题目与思路

```
行列各自升序（无跨行保证）→ 右上角走法
右上角 = 本行最大、本列最小
  target 更小 → 排除整列；更大 → 排除整行
⚠️ 分治视角完整解见分治/07（四象限剪枝）
```

### 5.2 完整代码

```java
/**
 * LeetCode 240. 搜索二维矩阵 II
 * ⚠️ 右上角起点，每步排除一行或一列 → O(m+n)
 */
public boolean searchMatrixII(int[][] matrix, int target) {
    int i = 0, j = matrix[0].length - 1;
    while (i < matrix.length && j >= 0) {
        int v = matrix[i][j];
        if (v == target) return true;
        if (v > target) j--;          // ⚠️ 本行最大都大 → 排除整列
        else i++;                     // 本列最小都小 → 排除整行
    }
    return false;
}
// 推演 [[1,4,7,11],[2,5,8,12],[3,6,9,16]], target=5：
//   (0,3)=11 > 5 → 左移；(0,2)=7 → 左移；(0,1)=4 < 5 → 下移
//   (1,1)=5 ✓（3 步，O(m+n) 内）
// ⚠️ 面试表达："240 与 74 的区别是'有序强度'——
//   74 展平二分 O(log)，240 走法 O(m+n)。
//   240 的右上角是'两个方向有序'的汇合点。"
```

## 6. 36. 有效的数独

### 6.1 题目与思路

```
数独合法性：行/列/3×3 宫无重复数字
三组判重：row[i][d]、col[j][d]、box[i/3][j/3][d]
⚠️ 一次性遍历同时更新三组（O(1) 空间每组布尔）
```

### 6.2 完整代码

```java
/**
 * LeetCode 36. 有效的数独
 * ⚠️ 3×3 宫下标 = (i/3)*3 + j/3
 */
public boolean isValidSudoku(char[][] board) {
    boolean[][] row = new boolean[9][9];
    boolean[][] col = new boolean[9][9];
    boolean[][] box = new boolean[9][9];

    for (int i = 0; i < 9; i++) {
        for (int j = 0; j < 9; j++) {
            char c = board[i][j];
            if (c == '.') continue;
            int d = c - '1';                    // ⚠️ 0-8
            int b = (i / 3) * 3 + j / 3;        // ⚠️ 宫下标公式

            if (row[i][d] || col[j][d] || box[b][d]) return false;
            row[i][d] = col[j][d] = box[b][d] = true;
        }
    }
    return true;
}
// 推演 board[0][0]='5', board[0][4]='5'：
//   row[0][4] 第二次 → 冲突 → false ✓
// ⚠️ 位运算优化版：每组用 int 的 9 位作布尔（面试加分）
//   row[i] |= 1 << d; 检查 row[i] & (1 << d)
// ⚠️ 面试表达："数独判重 = 三组布尔/位掩码——
//   一次遍历同时维护行、列、宫三视图。"
```

## 7. 498. 对角线遍历

### 7.1 题目与思路

```
按对角线交替方向遍历矩阵（右上 → 左下 → 右上...）
方向标志 + 越界调整（01 模块模板），此题给完整推导
```

### 7.2 完整代码

```java
/**
 * LeetCode 498. 对角线遍历
 */
public int[] findDiagonalOrder(int[][] mat) {
    int m = mat.length, n = mat[0].length;
    int[] res = new int[m * n];
    int idx = 0, i = 0, j = 0;
    boolean up = true;

    while (idx < m * n) {
        res[idx++] = mat[i][j];

        if (up) {
            if (j == n - 1) { i++; up = false; }       // ⚠️ 右边界
            else if (i == 0) { j++; up = false; }      // 上边界
            else { i--; j++; }                         // 正常右上
        } else {
            if (i == m - 1) { j++; up = true; }        // ⚠️ 下边界
            else if (j == 0) { i++; up = true; }       // 左边界
            else { i++; j--; }                         // 正常左下
        }
    }
    return res;
}
// 推演 [[1,2,3],[4,5,6],[7,8,9]]：
//   右上：(0,0)=1 → (0,1)=2 → (1,0)=4
//   左下：... 最终 [1,2,4,7,5,3,6,8,9] ✓
// ⚠️ 边界优先级：右/下边界先于上/左（角点处理）
// ⚠️ 面试表达："对角线 = 方向标志 + 四边界调整；
//   角点（如右上角）两个条件都满足时
//   优先按'右边界'处理（先判断 j == n-1）。"
```

## 8. 矩阵题方法论总结

### 8.1 题型识别与选型

```
① 变换（旋转/镜像/转置）→ 坐标公式/两段式
② 遍历（螺旋/对角）→ 边界模板/方向标志
③ 标记（置零/状态）→ 首行首列借位/编码
④ 搜索（74/240）→ 有序强度决定（二分/走法）
⑤ 判重（数独）→ 三视图布尔/位掩码
⑥ 路径/岛屿 → DP/DFS（见对应专题）

⚠️ 识别信号：
  "旋转/翻转/转置" → 变换类
  "螺旋/对角线顺序" → 遍历类
  "行列有序搜索" → 搜索类
```

### 8.2 模板速查表

| 模板 | 核心 | 代表题 |
|------|------|--------|
| 两段式旋转 | 转置(i<j) + 水平翻转 | 48 |

| 首行首列标记 | 借位 + 倒序处理 | 73 |
| 展平二分 | mid/n, mid%n | 74 |
