## 1. 坐标变换的数学规律

### 1.1 四大基本变换

```
n×n 矩阵，坐标 (i, j)（i 行、j 列）：

① 转置：      (i, j) → (j, i)          （沿主对角线镜像）
② 水平翻转：  (i, j) → (i, n-1-j)       （左右镜像）
③ 垂直翻转：  (i, j) → (n-1-i, j)       （上下镜像）
④ 旋转 90°：  (i, j) → (j, n-1-i)       （顺时针）
```

```
⚠️ 组合技巧（旋转 = 两次镜像）：
  顺时针 90° = 转置 + 水平翻转
    (i,j) →转置→ (j,i) →水平→ (j, n-1-i) ✓
  逆时针 90° = 转置 + 垂直翻转
  旋转 180° = 水平 + 垂直（或两次 90°）

⚠️ 面试表达：
"旋转 90° 不用硬记坐标公式——记住
 '转置 + 水平翻转'的组合，推导一次即可。"
```

### 1.2 坐标公式速查表

| 变换 | 公式 | 组合方式 |
|------|------|---------|
| 顺时针 90° | (i,j)→(j, n-1-i) | 转置 + 水平翻转 |
| 逆时针 90° | (i,j)→(n-1-j, i) | 转置 + 垂直翻转 |
| 180° | (i,j)→(n-1-i, n-1-j) | 水平 + 垂直 |
| 转置 | (i,j)→(j,i) | 直接 |
| 水平镜像 | (i,j)→(i, n-1-j) | 直接 |

## 2. 原地操作的循环交换

### 2.1 旋转 90° 的原地实现

```
不借助新矩阵 → 4 元素循环交换：
  (i,j) → (j, n-1-i) → (n-1-i, n-1-j) → (n-1-j, i) → (i,j)

遍历范围：只处理"四分之一"区域（i < n/2，j 范围由 i 决定）
```

```java
/** LeetCode 48. 旋转图像（原地，4 元素循环交换） */
public void rotate(int[][] matrix) {
    int n = matrix.length;
    for (int i = 0; i < n / 2; i++) {              // ⚠️ 上半区
        for (int j = i; j < n - 1 - i; j++) {      // ⚠️ 当前层右半
            int tmp = matrix[i][j];
            matrix[i][j] = matrix[n - 1 - j][i];           // 左→上
            matrix[n - 1 - j][i] = matrix[n - 1 - i][n - 1 - j];  // 下→左
            matrix[n - 1 - i][n - 1 - j] = matrix[j][n - 1 - i];  // 右→下
            matrix[j][n - 1 - i] = tmp;                    // 上→右
        }
    }
}
// 推演 [[1,2],[3,4]]：
//   i=0, j=0：1→(0,1)、3→(0,0)、4→(1,0)、2→(1,1)
//   → [[3,1],[4,2]] ✓ 顺时针 90°
// ⚠️ 或更简单的两段式：先转置（i<j 交换），再水平翻转每行
//   （面试写两段式更不容易错！）
```

### 2.2 两段式实现（推荐写法）

```java
/** 旋转 90° = 转置 + 水平翻转（两段式，不易错） */
void rotateTwoStep(int[][] m) {
    int n = m.length;
    // ① 转置：只交换上三角（i < j）
    for (int i = 0; i < n; i++)
        for (int j = i + 1; j < n; j++) {
            int t = m[i][j]; m[i][j] = m[j][i]; m[j][i] = t;
        }
    // ② 水平翻转每行
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n / 2; j++) {
            int t = m[i][j]; m[i][j] = m[i][n - 1 - j]; m[i][n - 1 - j] = t;
        }
}
// ⚠️ 面试建议：两段式（转置+翻转）代码长但正确率 100%
//   循环交换式代码短但边界容易错——面试优先正确
```

## 3. 遍历模板：螺旋与对角线

### 3.1 螺旋遍历（54/59）

```
四边界收缩：top/bottom/left/right
  右 → 下 → 左 → 上，每走完一边收缩边界
⚠️ 终止条件：top > bottom || left > right
```

```java
/** LeetCode 54. 螺旋矩阵（四边界模板） */
public List<Integer> spiralOrder(int[][] matrix) {
    List<Integer> res = new ArrayList<>();
    int top = 0, bottom = matrix.length - 1;
    int left = 0, right = matrix[0].length - 1;

    while (top <= bottom && left <= right) {
        for (int j = left; j <= right; j++) res.add(matrix[top][j]);      // 右
        top++;
        for (int i = top; i <= bottom; i++) res.add(matrix[i][right]);    // 下
        right--;
        if (top > bottom || left > right) break;   // ⚠️ 单行/单列防重复
        for (int j = right; j >= left; j--) res.add(matrix[bottom][j]);   // 左
        bottom--;
        for (int i = bottom; i >= top; i--) res.add(matrix[i][left]);     // 上
        left++;
    }
    return res;
}
// ⚠️ break 防重复：单行矩阵（1×n）时"左/上"两段会重复遍历
// ⚠️ 记忆："右、下、左、上"四段 + 边界收缩 + 防重复 break
```

### 3.2 对角线遍历（498）

```
对角线规律：i+j 为常数（同一条对角线）
  i+j = 0..m+n-2 共 m+n-1 条对角线
  方向交替：奇偶条反向

⚠️ 遍历公式：
  每条对角线起点 = (min(i, m-1), i - min(i, m-1)) 之类
  ——直接用"行列越界调整"更简单
```

```java
/** LeetCode 498. 对角线遍历（方向交替） */
public int[] findDiagonalOrder(int[][] mat) {
    int m = mat.length, n = mat[0].length;
    int[] res = new int[m * n];
    int idx = 0, i = 0, j = 0;
    boolean up = true;                     // ⚠️ 方向标志

    while (idx < m * n) {
        res[idx++] = mat[i][j];
        if (up) {
            // 右上：i-1, j+1；越界则调整方向
            if (j == n - 1) { i++; up = false; }        // 右边界 → 向下
            else if (i == 0) { j++; up = false; }       // 上边界 → 向右
            else { i--; j++; }
        } else {
            // 左下：i+1, j-1；越界则调整方向
            if (i == m - 1) { j++; up = true; }         // 下边界 → 向右
            else if (j == 0) { i++; up = true; }        // 左边界 → 向下
            else { i++; j--; }
        }
    }
    return res;
}
// ⚠️ 边界调整优先级：先处理"角点"（右边界优先于上边界）
// ⚠️ 面试表达："对角线遍历用方向标志 + 越界调整——
//   每次越界改变方向并微调坐标（4 个边界情况）。"
```

## 4. 原地标记技巧

### 4.1 73. 矩阵置零的标记法

```
问题：含 0 的行/列全部置 0（原地，O(1) 空间）
技巧：用首行/首列当"标记位"
  ① 扫描：matrix[i][j]==0 → 标记 matrix[i][0] 与 matrix[0][j]
  ② 用标记置零（从下往上处理，保护标记位）
  ③ 特判首行/首列本身是否有 0（用额外标志）
```

```java
/** LeetCode 73. 矩阵置零（O(1) 空间标记法） */
public void setZeroes(int[][] matrix) {
    int m = matrix.length, n = matrix[0].length;
    boolean firstRowZero = false, firstColZero = false;

    // ① 记录首行/首列是否含 0
    for (int j = 0; j < n; j++) if (matrix[0][j] == 0) firstRowZero = true;
    for (int i = 0; i < m; i++) if (matrix[i][0] == 0) firstColZero = true;

    // ② 用首行首列做标记
    for (int i = 1; i < m; i++)
        for (int j = 1; j < n; j++)
            if (matrix[i][j] == 0) {
                matrix[i][0] = 0;
                matrix[0][j] = 0;
            }

    // ③ 根据标记置零（⚠️ 从下往上/从右往左，避免覆盖标记）
    for (int i = 1; i < m; i++)
        for (int j = 1; j < n; j++)
            if (matrix[i][0] == 0 || matrix[0][j] == 0) matrix[i][j] = 0;

    // ④ 处理首行首列
    if (firstRowZero) for (int j = 0; j < n; j++) matrix[0][j] = 0;
    if (firstColZero) for (int i = 0; i < m; i++) matrix[i][0] = 0;
}
// ⚠️ 要点：标记信息存"首行首列"（不额外占空间）
//   特判首行首列本身（标记位可能被覆盖）
// ⚠️ 面试表达："原地标记 = 借用已存在的结构存状态；
//   73 借首行首列，处理顺序保护标记不被覆盖。"
```

### 4.2 原地标记的通用思想

```
矩阵原地标记技巧族：
  ① 首行首列借位（73）
  ② 正负号标记（289 生命游戏：用 -1/2 编码状态）
  ③ 值编码（用"不可能值"表示两种状态）
  ④ 位标记（数字矩阵：value | 标志位）

⚠️ 面试表达：
"原地标记的本质是'状态编码'——用一个格子同时
 保存旧值和新状态（如 289 的 ±1 编码）。
 关键是编码不丢失信息且可解码。"
```

## 5. 矩阵搜索策略

### 5.1 三类矩阵搜索

| 矩阵类型 | 策略 | 复杂度 | 代表 |
|---------|------|:---:|------|
| 完全有序（展平递增） | 一维二分 | O(log n) | 74 |
| 行列各自有序 | 右上角走法 | O(m+n) | 240 |
| 无结构 | 遍历/哈希 | O(mn) | 36 数独 |

```
74 与 240 的区别：
  74：每行整体大于前行 → 展平是递增数组 → 二分
  240：只保证行内/列内有序（跨行不一定）→ 右上角走

⚠️ 面试表达：
"'完全有序'（74）可以展平二分；
 '行列有序'（240）用右上角走法（每步排除一行/列）——
 两者不通用，先判断矩阵的'有序强度'。"
```

### 5.2 右上角走法模板

```java
/** LeetCode 240 搜索（右上角起点，每步排除整行/整列） */
public boolean searchMatrix(int[][] matrix, int target) {
    int i = 0, j = matrix[0].length - 1;      // 右上角
    while (i < matrix.length && j >= 0) {
        if (matrix[i][j] == target) return true;
        if (matrix[i][j] > target) j--;       // 本行全大 → 排除整列
        else i++;                             // 本列全小 → 排除整行
    }
    return false;
}
// ⚠️ 正确性：右上角是"本行最大、本列最小"
//   target 更小 → 排除整列；更大 → 排除整行
// ⚠️ 完整解见分治/07（240 的分治视角）
```

## 6. 矩阵路径与岛屿

### 6.1 路径类问题（DP 记忆化）

```
网格路径家族：
  62 不同路径：dp[i][j] = dp[i-1][j] + dp[i][j-1]
  64 最小路径和：dp[i][j] = min(上, 左) + grid[i][j]
  63 障碍版：障碍处 dp = 0
  931 下降路径：dp[i][j] = min(上三) + grid[i][j]

⚠️ 通用模板：
  方向限制（只右/下）→ 二维 DP 或滚动数组
  记忆化版本同样成立（见记忆化专题 62）
```

### 6.2 岛屿问题（DFS/BFS 遍历）

```
岛屿家族（网格图 DFS）：
  200 岛屿数量：遍历 + 沉没（visited）
  695 最大岛屿：DFS 返回面积
  130 被围绕的区域：边界 DFS 标记
  岛屿周长：边界计数

⚠️ 统一模板：
  DFS(i,j)：越界返回 → 已访问返回 → 标记 → 四方向递归
  复杂度 O(mn)（每格访问一次）

⚠️ 面试表达：
"岛屿问题 = 网格图 DFS/BFS + 原地标记（沉没/visited）。
 与矩阵变换无关，但'网格'是共同载体。"
```
