## 1. 实验一 · 分治算法

### 1.1 归并排序

| 步骤 | 操作 |
|------|------|
| 分解 | 递归平分数组直到单个元素 |
| 合并 | 双指针比较左右有序子数组，取较小者 → 临时数组 |
| 复杂度 | 递推 T(n) = 2T(n/2) + O(n)，主定理 → O(n log n) |
| 空间 | O(n)（临时数组） |

### 1.2 快速排序

| 优化 | 方法 |
|------|------|
| 枢轴选择 | 首元素（简单）/ 随机选取（避免最坏）/ **三数取中**（更稳定） |
| 分区 | Hoare 分区 vs Lomuto 分区 |
| 尾递归优化 | 减少递归深度 |
| 小数组切换 | 长度 < 阈值 → 插入排序 |

| 情况 | 复杂度 |
|:----:|:------:|
| 平均 | O(n log n) |
| 最坏 | O(n²)（已序 + 首元素枢轴） |

### 1.3 性能对比实验

| 数据规模 | 数据分布 |
|:--------:|----------|
| 10³ / 10⁴ / 10⁵ / 10⁶ | 随机 / 正序 / 逆序 / 大量重复 |

> 统计比较次数和运行时间，分析数据分布对算法性能的影响。

### 1.4 最近点对（选做）

| 维度 | 方法 |
|:----:|------|
| 一维 | 排序后扫描相邻点 |
| 二维 | 分治，中间条带区域 d×2d 内暴力搜索 |

## 2. 实验二 · 动态规划

### 2.1 矩阵连乘

| 要素 | 公式 |
|------|------|
| 状态 | `m[i][j]` = A[i..j] 最小乘法次数 |
| 转移 | `m[i][j] = min(m[i][k] + m[k+1][j] + p[i-1]*p[k]*p[j])` |
| 填表 | `len` 从小到大（区间 DP 模板） |
| 回溯 | `s[i][j]` 记录最优分割点 |

### 2.2 最长公共子序列（LCS）

| 情况 | 转移 |
|------|------|
| `X[i-1] == Y[j-1]` | `dp[i][j] = dp[i-1][j-1] + 1` |
| `X[i-1] != Y[j-1]` | `dp[i][j] = max(dp[i-1][j], dp[i][j-1])` |

> 从 `dp[m][n]` 反向追踪输出 LCS 字符串。

### 2.3 0/1 背包

| 优化 | 做法 |
|------|------|
| 滚动数组 | `dp[j] = max(dp[j], dp[j-w[i]] + v[i])`，**j 从 W 倒序** |
| 回溯 | `path[i][j]` 记录是否选择物品 i |

### 2.4 编辑距离

| 操作 | 转移 |
|------|------|
| 字符相等 | `dp[i][j] = dp[i-1][j-1]` |
| 字符不等 | `1 + min(删除dp[i-1][j], 插入dp[i][j-1], 替换dp[i-1][j-1])` |

## 3. 实验三 · 贪心算法

### 3.1 活动安排

> 贪心策略：按**结束时间升序** → 优先选最早结束的相容活动。

### 3.2 哈夫曼编码

```text
构建：建小顶堆 → 取最小两个频率结点 → 合并为新结点（频率之和）→ 插入堆
编码：根到叶 → 左 0 右 1
WPL：所有叶子的 频率 × 路径长度 之和
```

### 3.3 最小生成树对比

| 算法 | 策略 | 复杂度 | 适用图 |
|------|------|:------:|:------:|
| **Prim** | 选点：每次选连接已访问集合的最小权边 | O(n²) | 稠密图 |
| **Kruskal** | 选边：边排序 + 并查集判环 | O(e log e) | 稀疏图 |

## 4. 实验四 · 回溯与分支限界

### 4.1 N 皇后

| 要素 | 说明 |
|------|------|
| 解空间 | 排列树（每行每列一个皇后） |
| 约束函数 | 不同列 + 不同对角线 `|row_i - row_j| ≠ |col_i - col_j|` |
| 回溯框架 | 逐行放置 → 检查约束 → 递归下一行 → 回溯 |

### 4.2 图着色

| 约束 | 相邻顶点颜色不能相同 |
|------|------|
| 优化 | 按**度降序**排列顶点（先着色度大的） |

### 4.3 0/1 背包的回溯解法

| 剪枝函数 | 公式 |
|----------|------|
| **约束函数** | 当前重量 ≤ 背包容量 |
| **限界函数** | 当前价值 + 剩余价值上界 ≤ 当前最优值 → 剪枝 |

> 物品按**单位价值降序**排列。

## 5. 实验五 · 图算法

### Dijkstra

| 优化 | 优先队列，每次取未访问中 dist 最小的点松弛邻居 |
|------|------|
| 复杂度 | O((V+E) log V) |
| 回溯 | 记录前驱结点 |

### Floyd

| 核心 | `for k, for i, for j: d[i][j] = min(d[i][j], d[i][k] + d[k][j])` |
|------|------|
| 复杂度 | O(V³) |
| 特点 | 所有点对最短路径，支持负权（不能有负环） |

### 对比实验

> 随机生成不同规模图，比较 **Dijkstra×V 次 vs Floyd** 运行时间。
