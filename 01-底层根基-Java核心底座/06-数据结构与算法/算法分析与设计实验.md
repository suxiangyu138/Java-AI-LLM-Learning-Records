## 核心知识点

### 实验一：分治算法
- 归并排序实现与优化
  - 递归划分：将数组平分为左右两半直到单个元素
  - 合并操作：双指针比较左右有序子数组，取较小者放入临时数组
  - 时间复杂度分析：递推式 T(n)=2T(n/2)+O(n)，主定理得 O(n log n)
  - 空间复杂度：O(n)（临时数组）
- 快速排序实现与优化
  - 枢轴(Pivot)选择策略：取首元素 (简单)、随机选取 (避免最坏)、三数取中 (更稳定)
  - 分区(Partition)操作：Hoare分区 vs Lomuto分区
  - 时间复杂度：平均 O(n log n)，最坏 O(n²)（数组已有序且取首元素为枢轴）
  - 尾递归优化 + 小数组切换插入排序
- 性能对比实验
  - 生成不同规模(10³/10⁴/10⁵/10⁶)和不同分布(随机/正序/逆序/大量重复)的数据
  - 统计算法的比较次数和实际运行时间
  - 分析数据分布对算法性能的影响
- 最近点对问题（选做）
  - 一维最近点对：排序后扫描相邻点
  - 二维最近点对：分治，中间条带区域 d×2d 内暴力搜索

### 实验二：动态规划
- 矩阵连乘问题
  - 状态定义：m[i][j] = 计算 A[i]×A[i+1]×...×A[j] 所需的最小乘法次数
  - 状态转移：m[i][j] = min_{k}(m[i][k] + m[k+1][j] + p[i-1]×p[k]×p[j])
  - 填表顺序：len 从小到大 (区间DP模板)
  - 记录最优分割点 s[i][j] 用于回溯输出括号方案
- 最长公共子序列(LCS)
  - 状态：dp[i][j] = X[0..i-1] 和 Y[0..j-1] 的 LCS 长度
  - 转移：X[i-1]==Y[j-1] → dp[i-1][j-1]+1；否则 max(dp[i-1][j], dp[i][j-1])
  - 回溯输出 LCS 字符串：从 dp[m][n] 反向追踪
- 0/1背包问题
  - 滚动数组优化：dp[j] = max(dp[j], dp[j-w[i]] + v[i])，j 从 W 倒序到 w[i]
  - 回溯输出选中物品：使用 path[i][j] 记录是否选择物品 i
- 编辑距离
  - 状态：dp[i][j] = word1[0..i-1] 转换为 word2[0..j-1] 的最少操作数
  - 转移：相等→dp[i-1][j-1]；不等→1+min(删除dp[i-1][j], 插入dp[i][j-1], 替换dp[i-1][j-1])

### 实验三：贪心算法
- 活动安排问题
  - 贪心策略：按结束时间升序排列 → 优先选择结束最早的相容活动
  - 正确性证明：选择最早结束的活动不会排除最优解
- 哈夫曼编码
  - 构建过程：建小顶堆 → 每次取两个最小频率的结点 → 合并为新结点（频率之和）→ 重新插入堆
  - 编码生成：从根到叶的路径，左0右1
  - 计算带权路径长度 WPL：所有叶子结点的频率×路径长度之和
- 最小生成树
  - Prim算法：从任意点开始 → 每次选择连接已访问集合和未访问集合的最小权边
  - Kruskal算法：边按权排序 → 并查集判是否成环 → 不成环则加入MST
  - 对比两种算法：Prim O(n²) 适合稠密图，Kruskal O(e log e) 适合稀疏图

### 实验四：回溯法与分支限界
- N皇后问题
  - 解空间：排列树 (每行每列放置一个皇后)
  - 约束函数：不能同列 → 不能同对角线 (|row_i-row_j|≠|col_i-col_j|)
  - 回溯框架：逐行放置 → 检查约束 → 可行则递归下一行 → 不可行则回溯
- 图的M着色问题
  - 约束函数：相邻顶点颜色不能相同
  - 回溯：对每个顶点尝试 M 种颜色
  - 优化：按度从大到小排序顶点（优先着色度大的顶点）
- 0/1背包问题的回溯解法
  - 约束函数：当前重量 + 剩余物品最小重量 ≤ 背包容量
  - 限界函数：当前价值 + 剩余物品价值上界 ≤ 当前最优值 (剪枝)
  - 物品按单位价值降序排列

### 实验五：图算法
- Dijkstra算法
  - 优先队列优化：dist[源点]=0，其余=∞，每次取出未访问中dist最小的点松弛其邻居
  - 时间复杂度：O((V+E) log V)
  - 记录前驱节点用于回溯最短路径
- Floyd算法
  - 三重循环：for k: for i: for j: d[i][j]=min(d[i][j], d[i][k]+d[k][j])
  - 时间复杂度 O(V³)，适用于任何图（可处理负权，不能处理负环）
  - 可同时求所有点对最短路径
- 算法对比：随机生成不同规模的图，比较Dijkstra×V次 vs Floyd的运行时间

### 实验六：算法性能综合测试
- 同一问题不同策略对比 (如背包问题)
  - 贪心法 (部分背包最优，0/1背包非最优)
  - 动态规划 (O(nW)，W大时不可用)
  - 回溯法 (可剪枝，最坏O(2ⁿ))
  - 分析解的质量 vs 运行时间的 trade-off
- 大规模数据下的稳定性测试
  - 测试各算法在极限数据下的表现 (是否超时/爆栈/溢出)
  - 分析实际运行时间与理论复杂度的关系曲线

## 重点难点
- **重点**：分治和DP的正确实现与优化、图算法的熟练编码
- **难点**：DP状态设计与转移方程的推导、回溯剪枝的有效性
