## 1. 7. 整数反转

### 1.1 题目与思路

```
32 位整数反转，溢出返回 0
数位反转 + 溢出提前检查（01 模块 3 节）
⚠️ 两个关键：负数处理、乘 10 前检查
```

### 1.2 完整代码

```java
/**
 * LeetCode 7. 整数反转（溢出检查）
 */
public int reverse(int x) {
    int result = 0;
    while (x != 0) {
        int digit = x % 10;                  // ⚠️ 负数取余也正确（-3%10=-3）
        // ⚠️ 溢出提前检查（乘 10 之前）
        if (result > Integer.MAX_VALUE / 10
                || (result == Integer.MAX_VALUE / 10 && digit > 7))
            return 0;
        if (result < Integer.MIN_VALUE / 10
                || (result == Integer.MIN_VALUE / 10 && digit < -8))
            return 0;
        result = result * 10 + digit;
        x /= 10;
    }
    return result;
}
// 推演 123：3 → 32 → 321 ✓
// 推演 -123：-3 → -32 → -321 ✓（负数取余天然正确）
// 推演 2147483647（MAX）：倒数第二位 result=214748364
//   digit=7 → result == MAX/10 && digit > 7 → 返回 0 ✓
// ⚠️ 面试必答："7 题 = 数位反转 + 提前检查——
//   乘 10 前与 MAX/10 比较；负数取余
//   Java 天然正确（-3%10=-3）。"
```

## 2. 50. Pow(x, n)

### 2.1 题目与思路

```
x^n（n 可达 ±2³¹）
快速幂：指数二进制分解，O(log n)
⚠️ 三个细节：n 负数、n 最小 -2³¹ 溢出、double 精度
```

### 2.2 完整代码

```java
/**
 * LeetCode 50. Pow(x, n)
 */
public double myPow(double x, int n) {
    long N = n;                              // ⚠️ 转 long 防 -2³¹ 溢出
    if (N < 0) {
        x = 1 / x;                           // ⚠️ 负数取倒数
        N = -N;
    }
    return fastPow(x, N);
}

private double fastPow(double x, long n) {
    double result = 1.0;
    while (n > 0) {
        if ((n & 1) == 1) result *= x;       // ⚠️ 奇数位累乘
        x *= x;                              // 平方
        n >>= 1;
    }
    return result;
}
// 推演 2^10：b=1010
//   b=10(偶)：x=4；b=5(奇)：res=4；x=16；b=2(偶)：x=256
//   b=1(奇)：res=4×256=1024 ✓
// ⚠️ 复杂度：O(log n)
// ⚠️ 面试必答："50 的坑是 -2³¹ 取负溢出——
//   n 先转 long 再取负。快速幂本体
//   '平方 + 按位累乘'三行。"
```

## 3. 9. 回文数

### 3.1 题目与思路

```
判断整数回文（不转字符串）
反转一半比较（O(log n) 时间 O(1) 空间）
⚠️ 负数和尾零特判
```

### 3.2 完整代码

```java
/**
 * LeetCode 9. 回文数（反转一半）
 */
public boolean isPalindrome(int x) {
    // ⚠️ 负数不是；尾零的非零数不是（120 反转 = 021）
    if (x < 0 || (x % 10 == 0 && x != 0)) return false;

    int reversed = 0;
    while (x > reversed) {                   // ⚠️ 反转一半即停
        reversed = reversed * 10 + x % 10;
        x /= 10;
    }
    return x == reversed || x == reversed / 10;   // 偶数/奇数位数
}
// 推演 1221：x=12, rev=12 → 停止 → 12==12 ✓
// 推演 121：x=1, rev=12 → 停止 → 1 == 12/10 = 1 ✓
// 推演 10：尾零且非 0 → false ✓（"10" 反转 "01" 不是回文）
// ⚠️ 面试必答："反转一半防溢出——
//   x ≤ rev 停止；奇数位用 rev/10 比较。
//   尾零特判是这题的隐藏边界。"
```

## 4. 168. Excel 表列名称

### 4.1 题目与思路

```
列号 → 列名（1 → A，28 → AB，701 → ZY）
26 进制 1-indexed（01 模块 2 节）
⚠️ 先 -1 再取余（对齐 0-indexed）
```

### 4.2 完整代码

```java
/**
 * LeetCode 168. Excel 表列名称（26 进制 1-indexed）
 */
public String convertToTitle(int columnNumber) {
    StringBuilder sb = new StringBuilder();
    while (columnNumber > 0) {
        columnNumber--;                      // ⚠️ 先 -1（1-indexed → 0-indexed）
        sb.append((char) ('A' + columnNumber % 26));   // 当前位
        columnNumber /= 26;
    }
    return sb.reverse().toString();
}
// 推演 1：0%26=0 → A ✓
// 推演 28：27%26=1 → B，27/26=1 → 0%26=0 → A → "AB" ✓
// 推演 702：701%26=25 → Z，701/26=26 → 25%26=25 → Z，26/26=1
//   → 0 → A → "AZZ"? 验证：702 = 26×27 → 27 = Z？不——
//   ⚠️ 702 = 26×26 + 26 → "ZZ"？验证：Z=26, ZZ = 26×26+26 = 702 ✓
//   推演正确：702→701%26=25(Z), 701/26=26→25%26=25(Z), 26/26=1→0(A)
//   → "ZZ"？——不对，702/26=27... 重新推演：
//   702：先-1=701；701%26=25→Z；701/26=26；-1=25；25%26=25→Z；
//   25/26=0 结束 → "ZZ" ✓
// ⚠️ 面试必答："Excel 列是 1-indexed——
//   不先 -1 会错在 26/52/702 等整除边界（Z 会变 AA）。"
```

## 5. 202. 快乐数

### 5.1 题目与思路

```
快乐数：各位平方和循环，最终到 1
不快乐 → 必入环（状态有限，01 模块 4 节）
判环：快慢指针（slow 一步、fast 两步）
```

### 5.2 完整代码

```java
/**
 * LeetCode 202. 快乐数（快慢指针判环）
 */
public boolean isHappy(int n) {
    int slow = n, fast = n;
    do {
        slow = squareSum(slow);
        fast = squareSum(squareSum(fast));   // ⚠️ fast 两步
    } while (slow != fast);                  // 相遇 = 入环

    return slow == 1;                        // 环中是否有 1
}

private int squareSum(int n) {
    int sum = 0;
    while (n > 0) {
        int d = n % 10;
        sum += d * d;
        n /= 10;
    }
    return sum;
}
// 推演 19：19→82→68→100→1→1（fast 到 1，slow 随后 → 环 {1}）
//   → slow == 1 ✓ 快乐
// 推演 4：4→16→37→58→89→145→42→20→4（环不含 1）
//   → 不快乐 ✓
// ⚠️ 复杂度：O(log n)（平方和位数收敛快）
// ⚠️ 面试必答："202 的洞察：平方和状态有限
//   （≤ 9²×位数）→ 不快乐必入环；
//   快慢指针 O(1) 空间判环。"
```

## 6. 231. 2 的幂

### 6.1 题目与思路

```
判断 n 是否是 2 的幂
n & (n-1) == 0：消除最低位 1 后为 0 ⟺ 只有一个 1
⚠️ 注意 n > 0（0 和负数不是）
```

### 6.2 完整代码

```java
/**
 * LeetCode 231. 2 的幂
 */
public boolean isPowerOfTwo(int n) {
    return n > 0 && (n & (n - 1)) == 0;      // ⚠️ 只有一个二进制 1
}
// 推演 8 (1000)：1000 & 0111 = 0 → true ✓
// 推演 12 (1100)：1100 & 1011 = 1000 ≠ 0 → false ✓
// 推演 0：n > 0 失败 → false ✓（0 不是 2 的幂）
// ⚠️ 变体：
//   342 4 的幂：2 的幂 && n % 3 == 1
//   326 3 的幂：循环除 3（见数论/02）
// ⚠️ 面试必答："2 的幂 ⟺ 二进制只有一个 1
//   ⟺ n&(n-1)==0。位运算一行结论。"
```

## 7. 268. 丢失的数字

### 7.1 题目与思路

```
[0, n] 中缺一个数（数组长度 n）
三解法：
  ① 求和相减：sum(0..n) - sum(nums)（⚠️ 溢出用 long）
  ② 异或：0..n 与 nums 全部异或 → 落单者
  ③ 哈希/排序（笨）
⚠️ 异或版 O(1) 空间且无溢出
```

### 7.2 完整代码

```java
/** 异或版（最优） */
public int missingNumber(int[] nums) {
    int x = 0;
    for (int i = 0; i <= nums.length; i++) x ^= i;      // 0..n
    for (int v : nums) x ^= v;                          // ⚠️ 成对抵消
    return x;                                           // 落单 = 缺失
}
// 推演 [3,0,1]（缺 2）：
//   0^1^2^3 ^ 3^0^1 = (0^0)^(1^1)^(3^3)^2 = 2 ✓

/** 求和版（防溢出用 long） */
public int missingNumberSum(int[] nums) {
    int n = nums.length;
    long total = (long) n * (n + 1) / 2;                // ⚠️ long 防溢出
    long sum = 0;
    for (int v : nums) sum += v;
    return (int) (total - sum);
}
// ⚠️ 面试必答："268 异或版最优——'成对抵消'
//   是异或的招牌用法；求和版注意 n(n+1)/2 溢出
//   转 long。"
```

## 8. 数学方法论总结

### 8.1 解题框架

```
① 识别：数位/进制/判环/位运算/公式
② 定模板：
   数位 → %10 + /10
   进制 → 除基取余（1-indexed 先 -1）
   判环 → 快慢指针
   位运算 → n&(n-1)/异或
③ 边界：负数/尾零/溢出/0
④ 验证：小样例 + 边界手推

⚠️ 识别信号：
  "反转/回文/数位" → 数位模板
  "Excel/进制" → 除基取余
  "幂/平方和循环" → 判环/快速幂
  "缺失/落单" → 异或
```

### 8.2 模板速查表

| 模板 | 核心 | 代表题 |
|------|------|--------|
| 数位反转 | %10 + /10 + 提前检查 | 7 |
| 快速幂 | 平方 + 按位累乘 | 50 |
| 回文 | 反转一半 | 9 |

### 8.3 自测清单

