## 1. 核心概念

### 1.1 数学题的分类

```
① 数位操作：反转整数、数字统计
② 快速幂/指数：Pow、次方取模
③ 数学推导：找规律、公式化
④ 进制转换：二进制/26 进制（Excel 列）
⑤ 计数问题：阶乘后的零、因子计数

共同点：先把问题数学化，再写代码
（与"模拟"的区别：模拟按规则走，数学找规律）
```

### 1.2 常用数学结论

```
① 快速幂：a^b 二进制分解 → O(log b)
② 阶乘后的零 = 因子 5 的个数（172）
③ 反转整数：r = r*10 + digit（⚠️ 溢出检查）
④ 进位加法：carry = sum / 10（2 两数相加）
⑤ 中位数原理：Σ|x-ai| 最小时 x 取中位数（462）
⑥ 等差数列和：n(n+1)/2（268 缺失数字）
⑦ 完全平方数有奇数个因子（319 灯泡）
⑧ 异或去重：x^x=0（136 只出现一次）
```

### 1.3 数学题 vs 模拟题

```
模拟：按规则逐步执行（题干即算法）
数学：找规律/公式（O(1) 或 O(log n)）

识别信号：
  "n 巨大" → 必然有数学规律（模拟会超时）
  "第 K 个 X" → 数位/进制规律
  "多少个零/多少个因子" → 计数公式

方法论：小规模枚举找规律 → 猜测 → 验证 → 证明
```

## 2. 完整代码模板

### 2.1 整数反转（含溢出防护）

```java
/**
 * LeetCode 7. 整数反转
 * 123 → 321；-123 → -321；溢出返回 0
 */
public int reverse(int x) {
    int result = 0;
    while (x != 0) {
        int digit = x % 10;               // 取最低位
        // ⚠️ 溢出检查：result*10 + digit 会溢出吗？
        if (result > Integer.MAX_VALUE / 10
            || result < Integer.MIN_VALUE / 10) {
            return 0;                     // 溢出 → 返回 0
        }
        result = result * 10 + digit;
        x /= 10;
    }
    return result;
}
// 推演 123：
//   digit=3 → result=3；digit=2 → result=32；digit=1 → result=321 ✓
// 溢出检查原理：
//   result > MAX/10 → result*10 必然溢出
//   （MAX = 2147483647，MAX/10 = 214748364）
```

### 2.2 快速幂（Pow）

```java
/**
 * LeetCode 50. Pow(x, n) —— 快速幂
 * 指数二进制分解 → O(log n)
 */
public double myPow(double x, int n) {
    long exp = n;                    // ⚠️ -2^31 取反会溢出 int → long
    if (exp < 0) {
        x = 1 / x;                   // 负次幂 = 倒数
        exp = -exp;
    }

    double result = 1;
    while (exp > 0) {
        if ((exp & 1) == 1) {        // 当前位为 1
            result *= x;             // 乘入结果
        }
        x *= x;                      // 平方递进
        exp >>= 1;                   // 下一位
    }
    return result;
}
// 推演 2^10：10 = 1010₂
//   位0(0)：x=4
//   位1(1)：result=4；x=16
//   位2(0)：x=256
//   位3(1)：result=4×256=1024 ✓

// ⚠️ 关键细节：n = -2^31 时 -n 溢出 int
//   → 先用 long 接收再取反
```

### 2.3 进制转换（Excel 列号）

```java
/**
 * LeetCode 168. Excel 表列名称
 * 1→A, 28→AB（26 进制，但 1-indexed！）
 */
public String convertToTitle(int columnNumber) {
    StringBuilder sb = new StringBuilder();

    while (columnNumber > 0) {
        columnNumber--;                        // ⚠️ 1-indexed 先减 1
        sb.append((char) ('A' + columnNumber % 26));
        columnNumber /= 26;
    }
    return sb.reverse().toString();
}
// 为什么先减 1？
//   26 → "Z"：不减 1 会算成 26%26=0 → 'A'（错误）
//   减 1 后：25%26=25 → 'Z' ✓
//   （Excel 列是 1-indexed 的 26 进制）

// 反向：171. Excel 表列序号
//   A→1, AB→28：sum = sum*26 + (c - 'A' + 1)
```

### 2.4 阶乘后的零（因子计数）

```java
/**
 * LeetCode 172. 阶乘后的零
 * 10 = 2×5；因子 2 永远够 → 零 = 因子 5 的个数
 */
public int trailingZeroes(int n) {
    int count = 0;
    while (n > 0) {
        n /= 5;                    // 5 的倍数、25 的倍数...
        count += n;
    }
    return count;
}
// n=25：25/5=5 + 5/5=1 → 6 ✓
// 25! 中因子 5：5,10,15,20 各 1 个 + 25 有 2 个 = 6
```

## 3. 数学推导方法

### 3.1 找规律的通用流程

```
① 小规模枚举：手算 n=1,2,3,4 的结果
② 观察序列：1,1,2,3,5... → 斐波那契？
             1,1,2,5,14 → 卡特兰数？
             1,0,1,0... → 奇偶规律？
③ 猜测公式/规律
④ 验证：n=5,6 是否符合
⑤ 证明（归纳/构造）：面试可简化

例（319 灯泡开关）：
  枚举 n=1..5：亮灯数 1,1,2,2,2...
  观察：第 k 盏灯亮 ⇔ 翻转奇数次 ⇔ k 有奇数个因子
  → 完全平方数（因子成对 + √k 自配对）
  → 答案 = ⌊√n⌋ ✓
```

### 3.2 进位与借位的通用模板

```java
/**
 * 字符串加法（415. 字符串相加）——进位模板
 * 适用于：二进制/十进制/大数加法
 */
public String addStrings(String num1, String num2) {
    StringBuilder sb = new StringBuilder();
    int i = num1.length() - 1, j = num2.length() - 1;
    int carry = 0;

    while (i >= 0 || j >= 0 || carry > 0) {   // ⚠️ 残留进位
        int sum = carry;
        if (i >= 0) sum += num1.charAt(i--) - '0';
        if (j >= 0) sum += num2.charAt(j--) - '0';

        sb.append(sum % 10);                   // 当前位
        carry = sum / 10;                      // 进位
    }
    return sb.reverse().toString();            // ⚠️ 反转
}
// 记忆："从后往前 + 进位贯穿 + 残留进位 + 反转"
```

### 3.3 中位数原理（462）

```java
/**
 * LeetCode 462. 最少移动次数使数组元素相等 II
 * Σ|x - ai| 在 x = 中位数时最小（绝对值不等式）
 *
 * 为什么不是平均数？
 *   平均数被极端值拉偏：[1,1,100] 中位 1 距离 99，
 *   平均 34 距离 132 → 中位数远优
 */
public int minMoves2(int[] nums) {
    Arrays.sort(nums);
    int median = nums[nums.length / 2];   // 中位数
    int moves = 0;
    for (int x : nums) {
        moves += Math.abs(x - median);
    }
    return moves;
}
// 证明思路：数轴上 n 个点到一个点距离和最小
//   每次移动 x 跨越一个点，两侧点数差决定方向
//   平衡点在"中间" → 中位数
```

## 4. 溢出防护详解

### 4.1 溢出场景清单

```
⚠️ 数学题的生命线：
  ① 反转整数：result > MAX/10 检查
  ② 负数取反：-(-2^31) 溢出 → long
  ③ 乘法中间值：long 或先除后乘
  ④ 累加/求和：n(n+1)/2 用 long
  ⑤ 快速幂取模：每步 % mod（防 long 也溢出时用 BigInteger）

记忆："看到乘法/取反/累加，先想溢出"
```

### 4.2 溢出检查的正确写法

```java
// 反转整数（逐位检查）
if (result > Integer.MAX_VALUE / 10
    || result < Integer.MIN_VALUE / 10) return 0;

// 两数相加（先判断再相加）
if (a > Integer.MAX_VALUE - b) return Integer.MAX_VALUE;

// 乘法（用 long 兜底）
long product = (long) a * b;
if (product > Integer.MAX_VALUE) ...

// 组合数（先除后乘）
result = result * (n - k + i) / i;   // 每步先乘后除仍可能溢出
// → 用 long 或 BigInteger（大组合数）
```

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 反转忘溢出检查 | 结果错误 | result 与 MAX/10 比较 |
| -2^31 取反 | int 溢出 | 先转 long |
| 1-indexed 忘减 1 | 26→A 错误 | columnNumber-- 先行 |
| 进位残留忘处理 | 少一位 | 循环条件含 carry > 0 |
| 结果忘反转 | 顺序颠倒 | StringBuilder reverse |
