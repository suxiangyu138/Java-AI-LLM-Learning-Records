## 1. 数位处理的三大模板

### 1.1 数位提取与反转

```java
/** 数位提取：逐位取余 + 整除 */
int extractDigits(int n) {
    int sum = 0;
    while (n > 0) {
        int digit = n % 10;         // ⚠️ 取最低位
        sum += digit;
        n /= 10;                    // 去掉最低位
    }
    return sum;
}

/** 数位反转（7. 整数反转的骨架） */
int reverseDigits(int n) {
    int result = 0;
    while (n != 0) {
        int digit = n % 10;
        // ⚠️ 溢出检查（见第 3 节）
        result = result * 10 + digit;
        n /= 10;
    }
    return result;
}
// ⚠️ 面试必答："数位处理 = %10 取位 + /10 移位——
//   提取/反转/求和三合一模板。"
```

### 1.2 回文数判断（9）

```java
/** 反转一半比较（O(log n) 时间 O(1) 空间） */
boolean isPalindrome(int x) {
    if (x < 0 || (x % 10 == 0 && x != 0)) return false;   // ⚠️ 负数和尾零特判

    int reversed = 0;
    while (x > reversed) {              // ⚠️ 反转一半即停
        reversed = reversed * 10 + x % 10;
        x /= 10;
    }
    return x == reversed || x == reversed / 10;   // 奇偶位数
}
// 推演 1221：x=122, rev=1 → x=12, rev=12 → 停止（x ≤ rev）
//   12 == 12 ✓；推演 121：x=1, rev=12 → 1 == 12/10=1 ✓
// ⚠️ 面试必答："回文判断反转一半——避免溢出
//   且 O(1) 空间；奇偶位数两个比较条件。"
```

### 1.3 数位处理的常见坑

```
① 负数：符号处理（反转通常不考虑符号位）
② 尾零：120 反转 = 21（前导零丢弃，天然）
③ 溢出：反转可能越界（7 题）
④ 0：特判（0 是回文）

⚠️ 面试表达：
"数位题三坑——负数、尾零、溢出；
 0 的回文特判（0 是回文数）。"
```

## 2. 进制转换体系

### 2.1 十进制 ↔ 任意进制

```java
/** 十进制 → 任意进制（2-36） */
String toBase(int n, int base) {
    if (n == 0) return "0";
    String digits = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ";
    StringBuilder sb = new StringBuilder();
    while (n > 0) {
        sb.append(digits.charAt(n % base));   // ⚠️ 取余得最低位
        n /= base;
    }
    return sb.reverse().toString();
}

/** 任意进制 → 十进制 */
int fromBase(String s, int base) {
    int result = 0;
    for (char c : s.toCharArray()) {
        int digit = Character.digit(c, base);
        result = result * base + digit;       // ⚠️ 累乘累加
    }
    return result;
}
// ⚠️ 面试必答："进制转换 = 除基取余（十进制→任意）
//   与乘基累加（任意→十进制），互为逆运算。"
```

### 2.2 Excel 列名（168：26 进制 1-indexed）

```
⚠️ 与普通 26 进制的区别：1-indexed（A=1 而非 0）
  → 每次先 -1 再取余！

转换：
  列号 → 列名：while (n > 0) { n--; 取 n % 26; n /= 26; }
  列名 → 列号：result = result * 26 + (c - 'A' + 1)

例：702 → Z；703 → AA（普通 26 进制会错）
⚠️ 面试必答：
"Excel 列是 1-indexed 26 进制——
 转换前先 -1（对齐 0-indexed），
 否则 26/52/702 边界全错。"
```

### 2.3 进制识别与选型

| 场景 | 进制 | 注意 |
|------|:---:|------|
| 二进制/位运算 | 2 | n&(n-1) 等技巧 |
| Excel 列 | 26（1-indexed） | 先 -1 |
| TinyURL | 62 | 字符集大 |
| 哈希编码 | 大进制 | 防碰撞 |

## 3. 溢出防护的艺术

### 3.1 溢出的三类场景

```
① 反转溢出：rev * 10 + digit 越界（7 题）
② 乘法溢出：a * b 超 int/long
③ 累加溢出：求和超范围

⚠️ 防护手段：
  ① 提前检查（乘 10 前比较）
  ② long 中转（宽类型计算）
  ③ 每步取模（模运算场景）
```

### 3.2 反转溢出的提前检查（7 题核心）

```java
/** 7. 整数反转（带溢出检查） */
int reverse(int x) {
    int result = 0;
    while (x != 0) {
        int digit = x % 10;
        // ⚠️ 溢出检查：result 将乘 10，与边界比较
        if (result > Integer.MAX_VALUE / 10
                || (result == Integer.MAX_VALUE / 10 && digit > 7)) {
            return 0;                          // 正溢出
        }
        if (result < Integer.MIN_VALUE / 10
                || (result == Integer.MIN_VALUE / 10 && digit < -8)) {
            return 0;                          // 负溢出
        }
        result = result * 10 + digit;
        x /= 10;
    }
    return result;
}
// ⚠️ 面试必答："反转溢出检查 = 乘 10 前与
//   MAX/10 比较——'先检查后运算'是溢出防护
//   的标准姿势。"
```

### 3.3 溢出防护决策表

| 场景 | 手段 | 例子 |
|------|------|------|
| 反转/数位 | 提前比较 MAX/10 | 7 |
| 乘法 | long 中转 | 50、372 |
| 面积/距离 | long | 223、874 |
| 模运算 | 每步 % MOD | 数论家族 |
| 求和 | long / BigInteger | 大数 |

```
⚠️ 面试表达：
"溢出防护三手段——提前检查（数位类）、
 long 中转（乘法类）、每步取模（模运算类）。"
```

## 4. 判环：数学中的快慢指针

### 4.1 快乐数（202）的判环思想

```
快乐数：各位平方和反复计算，最终到 1
⚠️ 不快乐 → 会进入循环（不是无限发散）！
  证明：数的平方和 ≤ 9²×位数，有限状态 → 必入环

⚠️ 用快慢指针判环（同 141 环形链表）：
  slow 算一步、fast 算两步 → 相遇即入环
  fast 到 1 → 快乐

⚠️ 面试必答：
"202 的数学洞察：平方和状态有限 → 不快乐必入环。
 判环用快慢指针（slow 一步、fast 两步）
 或哈希记录（Set 见重复即环）。"
```

### 4.2 完整实现

```java
/** 202. 快乐数（快慢指针判环） */
public boolean isHappy(int n) {
    int slow = n, fast = n;
    do {
        slow = squareSum(slow);              // 一步
        fast = squareSum(squareSum(fast));   // 两步
    } while (slow != fast);                  // 相遇 = 入环

    return slow == 1;                        // ⚠️ 环含 1 → 快乐
}

private int squareSum(int n) {
    int sum = 0;
    while (n > 0) {
        int d = n % 10;
        sum += d * d;
        n /= 10;
    }
    return sum;
}
// 推演 19：19→82→68→100→1（fast 先到 1 判断）
//   不快乐：4→16→37→58→89→145→42→20→4（入环）
// ⚠️ 面试表达："快乐数 = 判环题——
//   状态有限必入环；快慢指针或 Set 均可。"
```

## 5. 位运算的数学应用

### 5.1 位运算速查

| 技巧 | 表达式 | 用途 |
|------|--------|------|
| 2 的幂 | n & (n-1) == 0 | 231 |
| 4 的幂 | 2 的幂 && n % 3 == 1 | 342 |
| 最低位 1 | n & (-n) | lowbit |
| 异或自消 | a ^ a = 0 | 找落单 |
| 偶数 | n & 1 == 0 | 奇偶 |

```
⚠️ 面试必答：
"位运算数学三件套：2 的幂（n&(n-1)==0）、
 异或自消（成对抵消）、lowbit（n&-n）。
 231/136/191 都是它们的最小应用。"
```

### 5.2 二进制计数（191）

```java
/** 191. 位 1 的个数（n & (n-1) 消最低位 1） */
int hammingWeight(int n) {
    int count = 0;
    while (n != 0) {
        n &= n - 1;                 // ⚠️ 消掉最低位 1
        count++;
    }
    return count;
}
// 推演 11 (1011)：1011&1010=1010；1010&1001=1000；
//   1000&0111=0000 → 3 次 ✓
// ⚠️ 复杂度：O(位数中 1 的个数)（优于逐位检查 O(32)）
```

## 6. 数学推导方法论

### 6.1 数学题的思考流程

```
① 小规模枚举：手算 n=1,2,3...
② 找规律：序列/公式/周期
③ 数学论证：归纳/构造/反证
④ 实现验证：代码 + 边界

⚠️ 与"脑筋急转弯"的关系：
  数学 = 有据可推的规律
  脑筋急转弯 = 洞察后的一行结论

⚠️ 面试必答：
"数学题先小规模枚举找模式，再证明——
 证明是数学题与猜答案的分界线。"
```

### 6.2 常见数学结论速查

| 结论 | 应用 |
|------|------|
| 等差/等比求和公式 | 数列类 |
| 完全平方数因子奇数 | 灯泡开关 |
| 因子 5 计数 | 阶乘零 |
| 中位数绝对差最小 | 移动次数 |
| 奇偶性 | 博弈 |
