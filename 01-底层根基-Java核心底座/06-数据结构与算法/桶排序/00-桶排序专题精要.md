## 1. 核心概念

### 1.1 什么是桶排序

> 桶排序：把数据**均匀分到 k 个桶**，桶内各自排序，最后顺序拼接。数据均匀分布时接近 O(n)。

```
步骤：
  ① 确定桶范围（均匀划分值域）
  ② 数据分桶（映射到对应桶）
  ③ 桶内排序（任意排序算法）
  ④ 顺序拼接所有桶

复杂度：
  平均 O(n+k)：分桶 O(n) + 桶内排序 Σ O(bᵢ log bᵢ)
  最坏 O(n²)：全部数据进一个桶（分布不均）
  空间 O(n+k)
```

### 1.2 适用场景

```
✅ 均匀分布数据（浮点数 0-1、正态分布）
✅ 值域可划分成连续区间
❌ 极端分布（全部相同/极端集中 → 单桶退化）

对比：
  计数排序：值域小（每个值一个桶）
  桶排序：值域大但可划分区间（每个区间一个桶）
  基数排序：按位分桶（多次）

关系：计数排序是桶排序的特例（每值一桶）
```

### 1.3 识别信号

```
"均匀分布/浮点数排序" → 桶排序
"频次统计 + TopK" → 频次桶（变形）
"排序后最大间距" → 桶 + 鸽巢原理

⚠️ 面试定位：
  直接考桶排序较少
  频次桶（347/451）与鸽巢原理（164）更常考
```

## 2. 完整代码模板

### 2.1 桶排序模板（浮点数 0-1 均匀分布）

```java
/**
 * 桶排序标准实现（浮点数 [0,1) 均匀分布）
 */
public void bucketSort(double[] arr) {
    int n = arr.length;
    List<List<Double>> buckets = new ArrayList<>();
    for (int i = 0; i < n; i++) {
        buckets.add(new ArrayList<>());
    }

    // ① 分桶：值 × n → 桶下标
    for (double x : arr) {
        int idx = (int) (x * n);        // [0,1) × n → [0, n-1]
        buckets.get(idx).add(x);
    }

    // ② 桶内排序（均匀分布 → 桶内数据少）
    for (List<Double> bucket : buckets) {
        Collections.sort(bucket);       // 可换任意排序
    }

    // ③ 顺序拼接
    int index = 0;
    for (List<Double> bucket : buckets) {
        for (double x : bucket) {
            arr[index++] = x;
        }
    }
}
// 均匀分布时：每桶 n/k 个元素 → 桶内 O((n/k)log(n/k))
// 总 O(n + k×(n/k)log(n/k)) = O(n)（k≈n 时）

// 推演 [0.1, 0.7, 0.3, 0.9, 0.5]（n=5）
// 桶：[0.1] [0.3] [0.5] [] [0.7] [] [] [] [] [0.9]
// 桶内排序 + 拼接 → [0.1, 0.3, 0.5, 0.7, 0.9] ✓
```

### 2.2 任意值域的分桶

```java
/**
 * 任意值域 [min, max] 分 k 个桶
 */
public void bucketSortAny(double[] arr, double min, double max) {
    int n = arr.length;
    List<List<Double>> buckets = new ArrayList<>();
    for (int i = 0; i < n; i++) buckets.add(new ArrayList<>());

    // ⚠️ 映射：值 → 桶下标（归一化到 [0, 1)）
    double range = max - min;
    for (double x : arr) {
        int idx = (int) ((x - min) / range * n);
        if (idx >= n) idx = n - 1;      // ⚠️ 最大值边界
        buckets.get(idx).add(x);
    }
    // 桶内排序 + 拼接（同上）
}
// ⚠️ 边界处理：x == max 时 idx 可能 == n → 修正
```

### 2.3 164. 最大间距（桶 + 鸽巢原理）

```java
/**
 * LeetCode 164. 最大间距（桶思想 O(n)）
 * 排序后相邻元素的最大差值
 *
 * 鸽巢原理：最大间距 ≥ (max-min)/(n-1)
 *   → 桶大小 = 该值 → 桶内不可能有答案
 *   → 只需比较"相邻非空桶"的桶间差值！
 */
public int maximumGap(int[] nums) {
    if (nums.length < 2) return 0;

    int min = Integer.MAX_VALUE, max = Integer.MIN_VALUE;
    for (int x : nums) {
        min = Math.min(min, x);
        max = Math.max(max, x);
    }
    if (min == max) return 0;

    // ① 桶大小与桶数
    int n = nums.length;
    int bucketSize = Math.max(1, (max - min) / (n - 1));
    int bucketCount = (max - min) / bucketSize + 1;

    // ② 每桶只存最小/最大（鸽巢：桶内无答案）
    int[] bucketMin = new int[bucketCount];
    int[] bucketMax = new int[bucketCount];
    Arrays.fill(bucketMin, Integer.MAX_VALUE);
    Arrays.fill(bucketMax, Integer.MIN_VALUE);

    for (int x : nums) {
        int idx = (x - min) / bucketSize;
        bucketMin[idx] = Math.min(bucketMin[idx], x);
        bucketMax[idx] = Math.max(bucketMax[idx], x);
    }

    // ③ 相邻非空桶的差值 = 候选答案
    int maxGap = 0, prevMax = min;
    for (int i = 0; i < bucketCount; i++) {
        if (bucketMin[i] == Integer.MAX_VALUE) continue;  // 空桶跳过
        maxGap = Math.max(maxGap, bucketMin[i] - prevMax);
        prevMax = bucketMax[i];
    }
    return maxGap;
}
// O(n)：分桶 + 扫描（对比排序 O(n log n)）
// ⚠️ 鸽巢原理是本题核心洞察
```

## 3. 频次桶详解

### 3.1 347. 前 K 高频元素（频次桶）

```java
/**
 * LeetCode 347. 前 K 高频元素（频次桶 O(n)）
 * 下标 = 出现频次，桶内 = 该频次的元素
 */
public int[] topKFrequent(int[] nums, int k) {
    // ① 计数
    Map<Integer, Integer> freq = new HashMap<>();
    for (int x : nums) freq.merge(x, 1, Integer::sum);

    // ② ⚠️ 频次桶：下标 = 频次（最大频次 ≤ n）
    List<Integer>[] buckets = new List[nums.length + 1];
    for (var e : freq.entrySet()) {
        int f = e.getValue();
        if (buckets[f] == null) buckets[f] = new ArrayList<>();
        buckets[f].add(e.getKey());
    }

    // ③ 从高频往低频收集 k 个
    int[] result = new int[k];
    int idx = 0;
    for (int f = buckets.length - 1; f > 0 && idx < k; f--) {
        if (buckets[f] != null) {
            for (int x : buckets[f]) result[idx++] = x;
        }
    }
    return result;
}
// O(n)：计数 O(n) + 分桶 O(n) + 收集 O(k)
// 对比堆解法 O(n log k)：频次桶更快！
```

### 3.2 频次桶 vs 堆

| 维度 | 频次桶 | 堆 |
|------|:---:|:---:|
| 复杂度 | **O(n)** | O(n log k) |
| 空间 | O(n) | O(k) |
| 实现 | 稍复杂 | 简单 |
| 适用 | 频次范围可控 | 通用/流式 |

```
选型：静态数组 + 频次可控 → 频次桶更快
     数据流/在线 → 堆
```

### 3.3 451. 按频率排序字符（桶拼接）

```java
/**
 * LeetCode 451. 根据字符出现频率排序
 * 频次桶 → 从高频到低频拼接
 */
public String frequencySort(String s) {
    int[] freq = new int[128];               // ASCII
    for (char c : s.toCharArray()) freq[c]++;

    List<Character>[] buckets = new List[s.length() + 1];
    for (int i = 0; i < 128; i++) {
        if (freq[i] > 0) {
            if (buckets[freq[i]] == null) buckets[freq[i]] = new ArrayList<>();
            buckets[freq[i]].add((char) i);
        }
    }

    StringBuilder sb = new StringBuilder();
    for (int f = buckets.length - 1; f > 0; f--) {   // 高频优先
        if (buckets[f] != null) {
            for (char c : buckets[f]) {
                for (int i = 0; i < f; i++) sb.append(c);  // 重复 f 次
            }
        }
    }
    return sb.toString();
}
// "tree" → freq: t1 r1 e2 → 桶[2]=[e], 桶[1]=[t,r] → "eetr" ✓
```

## 4. 鸽巢原理的应用

### 4.1 鸽巢原理（抽屉原理）

```
把 n+1 个物品放入 n 个抽屉 → 至少一个抽屉有 2 个

应用（164 最大间距）：
  区间 [min, max] 分 n-1 个桶
  n 个数放入 n-1 个桶 → 至少一桶为空（鸽巢！）
  → 最大间距 ≥ 桶大小（跨桶）
  → 桶内不可能有答案 → 只比较相邻非空桶

⚠️ 面试表达：
"鸽巢原理保证至少一个空桶，
 所以最大间距必然跨桶，
 桶内无需比较（桶大小 < 答案下界）。"
```

### 4.2 鸽巢原理的其他应用

```
① 生日悖论（23 人 50% 重复生日）
② 数组中必有重复元素（n+1 个数放 n 个位置）
③ 哈希冲突必然存在（鸽笼）
④ 最大间距（164）

⚠️ 识别信号："n 个物品 n-1 个位置/桶"
```

### 4.3 桶思想的通用价值

```
① 分治式排序：分桶 → 桶内排序 → 拼接
② 频次统计：频次作桶下标（免排序）
③ 鸽巢证明：最大间距/重复检测
④ 滑动窗口 + 桶：220 存在重复 III（值域分桶）

⚠️ 面试加分：
"桶思想把'全局问题'变成'桶内局部问题'，
 配合鸽巢原理可以证明桶内无需处理。"
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"前 K 高频用频次桶：频次作为桶下标，
 元素放入对应桶——O(n) 分桶后从高频
 往低频收集即可，无需排序。
 相比堆解法 O(n log k)，频次桶 O(n) 更快。
 鸽巢原理变体（164）：至少一空桶 → 最大间距跨桶。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 桶排序什么时候优于快排？ | 均匀分布 + 要求 O(n)；分布未知可能退化单桶 |
| 2 | 频次桶 vs 堆？ | 静态频次桶 O(n)；流式/大数据堆 O(n log k) |
| 3 | 鸽巢原理应用？ | 至少一空桶 → 最大间距跨桶 → 桶内无需比较 |
| 4 | 桶内排序选什么？ | 任意排序；均匀分布桶内少 → 插入即可 |
| 5 | 最坏情况？ | 全部进一桶 → O(n²) |
| 6 | 桶 vs 计数 vs 基数？ | 区间桶 vs 每值桶 vs 按位桶 |
| 7 | 值域映射细节？ | 归一化 + 边界修正（idx >= n） |
| 8 | 桶大小怎么定？ | 数据分布决定；均匀分布 n 桶最优 |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 最大值映射出界 | 越界 | idx 修正 n-1 |
| 分布不均硬用 | 退化成 O(n²) | 先确认分布 |
| 频次桶忘初始化 | 空指针 | 用时 new |
| 鸽巢桶大小错 | 答案错误 | (max-min)/(n-1) |
| 空桶跳过遗漏 | 结果错 | continue 正确 |

> 🎯 **核心要点**：桶排序 = **分桶 + 桶内排序 + 拼接**。识别信号："均匀分布、前 K 高频、最大间距"。面试高频是**频次桶**变形（347/451）——频次作下标免排序；鸽巢原理（164）是进阶加分。
