## 1. 掩码基础操作速查

### 1.1 核心操作（必背）

```java
int mask = 0;

mask |= 1 << i;              // ① 置位（选第 i 个）
boolean has = (mask >> i & 1) == 1;   // ② 检查（第 i 个是否选）
mask &= ~(1 << i);           // ③ 清位（取消选）
int count = Integer.bitCount(mask);   // ④ 已选个数
int full = (1 << n) - 1;     // ⑤ 全集
int lowbit = mask & (-mask); // ⑥ 最低位 1
mask ^= 1 << i;              // ⑦ 翻转（奇偶状态切换）

// ⚠️ 面试必答：
//   "掩码六操作——置位/检查/清位/计数/
//    全集/翻转——是状态压缩的基础。"
```

### 1.2 掩码作数组下标

```
状态压缩的核心：掩码直接作下标
  int[] dp = new int[1 << n];       // 2^n 状态
  dp[mask] = 该状态的值

⚠️ 复杂度：状态数 2^n × 转移 O(n) = O(n·2^n)
  n ≤ 20 → 2^20 ≈ 10⁶ 可行
  n ≤ 25 → 3×10⁷ 边缘
  n ≥ 30 → 不可行（需 Meet-in-the-Middle）

⚠️ 面试必答：
"状态压缩 = 掩码作下标 + 2^n 数组——
 n ≤ 20 是安全边界；n ≥ 30 换折半枚举。"
```

## 2. 状态压缩 DP 框架

### 2.1 通用模板

```java
/** 状态压缩 DP 通用框架（TSP 类） */
int stateCompressionDP(int n, int[][] cost) {
    int[] dp = new int[1 << n];              // dp[mask] = 状态 mask 的最优值
    Arrays.fill(dp, Integer.MAX_VALUE / 2);
    dp[1 << 0] = 0;                          // 从 0 出发（仅 0 被访问）

    for (int mask = 0; mask < (1 << n); mask++) {
        if (dp[mask] == Integer.MAX_VALUE / 2) continue;
        // ⚠️ 枚举下一个要加入的节点
        for (int v = 0; v < n; v++) {
            if ((mask & (1 << v)) != 0) continue;   // 已访问
            int next = mask | (1 << v);
            dp[next] = Math.min(dp[next], dp[mask] + cost[最后节点][v]);
        }
    }
    return dp[(1 << n) - 1];                 // 全访问状态
}
// ⚠️ 面试必答："状压 DP = 掩码递推——
//   状态是'已选集合'（mask），转移是
//   '加入新元素'（置位）。O(n·2^n)。"
```

### 2.2 状压 DP 的识别信号

```
⚠️ 识别信号：
  ① "每个元素只能用一次" → 掩码状态
  ② n ≤ 20（2^n 可行）→ 状压候选
  ③ 顺序无关的集合状态 → 掩码
  ④ 位操作可表达转移 → 状压

典型：
  698 划分为 K 个子集（已分配）
  473 火柴拼正方形（已用集合）
  1349 考场座位（行状态）
  526 优美排列（已用数字）
  464 博弈（已选集合）
```

## 3. 子集枚举与位运算加速

### 3.1 枚举子集

```java
/** 枚举 mask 的所有子集（含空集） */
for (int sub = mask; sub > 0; sub = (sub - 1) & mask) {
    // 处理子集 sub
}
// ⚠️ 复杂度：3^n（所有子集的子集总数）
// 例：mask = 1011（3 个元素）
//   sub: 1011 → 1010 → 1001 → 1000 → 0011 → 0010 → 0001

/** 枚举超集（补集枚举） */
int complement = full ^ mask;                // 补集
// ⚠️ 应用：集合划分（698）、折半枚举
```

### 3.2 位运算加速技巧

```java
// ① 快速判断是否包含：mask & (1 << i)
// ② 快速求补集：full ^ mask
// ③ 最低位 1 提取：mask & (-mask)（lowbit）
// ④ 移除最低位 1：mask & (mask - 1)
// ⑤ 翻转某位：mask ^ (1 << i)
// ⚠️ 面试必答："位运算加速的核心是
//   '一条指令完成集合操作'——
//   与/或/异或即集合的交/并/对称差。"
```

## 4. 博弈与回溯的掩码

### 4.1 博弈掩码（464）

```java
/** 464. 我能赢吗（掩码博弈状态） */
int[] memo = new int[1 << maxN];             // 0 未算/1 胜/-1 败

int dfs(int mask, int remaining) {
    if (memo[mask] != 0) return memo[mask];  // ⚠️ 三态缓存
    for (int i = 1; i <= maxN; i++) {
        if ((mask & (1 << (i - 1))) != 0) continue;   // 已选
        if (i >= remaining
                || dfs(mask | (1 << (i - 1)), remaining - i) == -1) {
            return memo[mask] = 1;           // ⚠️ 存在必胜走法
        }
    }
    return memo[mask] = -1;
}
// ⚠️ 面试必答："博弈掩码 = 三态缓存（胜/败/未算）
//   + 胜负传递（我赢 = 有一步让对手必败）。"
```

### 4.2 回溯的掩码剪枝

```
回溯 + 掩码：
  状态 = 已选集合（mask）→ 去重剪枝
  ⚠️ 相同 mask 的搜索子树相同 → 缓存跳过

⚠️ 面试必答：
"回溯的掩码去重 = 相同'已选集合'
 只搜一次——698/473 的剪枝核心。"
```

## 5. 前缀奇偶状态：1915 技巧

### 5.1 1915 最美子字符串

```
统计"最多一个奇数频次字符"的子串数
奇偶状态压缩：
  每字符的频次奇偶 = 1 位（26 位掩码）
  前缀异或：mask[i] = 前 i 个字符的奇偶状态

子串 [l, r] 合法 ⟺ mask[r] 与 mask[l] 差 ≤ 1 位
  → 查"相同"或"差一位"的历史前缀

⚠️ 面试必答：
"1915 = 频次奇偶压缩——
 26 字符奇偶 = 26 位掩码；
 前缀异或差 ≤ 1 位即合法子串。"
```

### 5.2 完整实现

```java
/** 1915. 最美子字符串（前缀奇偶 + 掩码） */
public long wonderfulSubstrings(String word) {
    Map<Integer, Integer> count = new HashMap<>();
    count.put(0, 1);                         // 空前缀
    int mask = 0;
    long result = 0;

    for (char c : word.toCharArray()) {
        mask ^= 1 << (c - 'a');              // ⚠️ 翻转该字符奇偶
        // ① 全部偶数（相同掩码）
        result += count.getOrDefault(mask, 0);
        // ② 恰好一个奇数（差一位）
        for (int i = 0; i < 26; i++) {
            result += count.getOrDefault(mask ^ (1 << i), 0);
        }
        count.merge(mask, 1, Integer::sum);
    }
    return result;
}
// 推演 "aba"：
//   a：mask=1 → 相同 0 + 差一位 {0} → 1（"a"）
//   b：mask=3 → 差一位 {1,2} → 1（"ab"）
//   a：mask=2 → 相同 {2}? 历史 mask 2 无；差一位 {3,0} → 3 有 1（"aba"）
//   结果 4 ✓
// ⚠️ 复杂度：O(26n)
// ⚠️ 面试必答："1915 的前缀奇偶——
//   合法子串 ⟺ 前缀掩码相同或差一位。"
```

## 6. 掩码的复杂度分析

### 6.1 复杂度速查

| 操作 | 复杂度 | 场景 |
|------|:---:|------|
| 状态数 | 2^n | 全部状态 |
| 状态 + 转移 | O(n·2^n) | 状压 DP |
| 子集枚举 | 3^n | 子集划分 |
| 折半枚举 | 2^(n/2) | n ≥ 30 |

```
⚠️ 经验边界：
  n = 20 → 2^20 = 10⁶（安全）
  n = 25 → 3×10⁷（边缘，需优化）
  n = 30 → 1.07×10⁹（不可行 → 折半）

⚠️ 面试必答：
"掩码复杂度 = 2^n 状态数——
 转移乘 n（状压 DP）、子集枚举乘
 3^n。n ≤ 20 安全、n ≥ 30 折半。"
```

### 6.2 折半枚举（Meet in the Middle）

```
n = 30 的集合问题：
  拆两半（各 15）→ 各枚举 2^15
  组合两半结果（排序 + 双指针/哈希）

⚠️ 面试必答：
"折半枚举把 2^30 拆成 2×2^15——
 指数减半 + 组合合并，n=30 也可行。"
```

### 7.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 位号错（1<<i vs 1<<(i-1)） | 状态错 | 0/1 基统一 |
| 忘初始化 dp | 递推错 | 起点状态 |
