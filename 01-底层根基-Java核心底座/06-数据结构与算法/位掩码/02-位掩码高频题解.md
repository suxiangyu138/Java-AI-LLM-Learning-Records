## 1. 526. 优美的排列（状压 DP）

### 1.1 题目与思路

```
1..n 的排列中，第 i 位满足 i 整除或整除 i 的排列数
状压 DP：mask = 已放置的数字集合
  dp[mask] = 放置 mask 集合的方案数（按 bitCount 分层）
⚠️ 状态 = 集合（顺序无关）→ 掩码天然适配
```

### 1.2 完整代码

```java
/**
 * LeetCode 526. 优美的排列（状压 DP）
 */
public int countArrangement(int n) {
    int[] dp = new int[1 << n];              // dp[mask] = 方案数
    dp[0] = 1;

    for (int mask = 0; mask < (1 << n); mask++) {
        int pos = Integer.bitCount(mask) + 1;    // ⚠️ 当前放置位置（1 基）
        for (int i = 1; i <= n; i++) {
            if ((mask & (1 << (i - 1))) != 0) continue;   // 已用
            // ⚠️ 位置 pos 与数字 i 的优美条件
            if (pos % i == 0 || i % pos == 0) {
                dp[mask | (1 << (i - 1))] += dp[mask];
            }
        }
    }
    return dp[(1 << n) - 1];                 // 全放置
}
// 推演 n=2：
//   mask=0, pos=1：1 满足（1%1=0）→ dp[01]+=1；2 满足 → dp[10]+=1
//   mask=01, pos=2：2 满足（2%2=0）→ dp[11]+=1
//   mask=10, pos=2：1 满足（2%1=0）→ dp[11]+=1
//   结果 dp[11] = 2 ✓（[1,2] 和 [2,1]）
// ⚠️ 复杂度：O(n·2^n)
// ⚠️ 面试必答："526 = 掩码方案数 DP——
//   状态 = 已放集合、转移 = 放新数字、
//   bitCount 推位置。dp 存方案数。"
```

## 2. 473. 火柴拼正方形（掩码 + 回溯剪枝）

### 2.1 题目与思路

```
火柴能否拼成正方形（分成 4 组等和）
回溯 + 掩码去重：
  状态 = 已分配火柴的集合（mask）
  相同 mask 搜索子树相同 → 缓存跳过
⚠️ 剪枝三件套：排序降序、边长上限、掩码去重
```

### 2.2 完整代码

```java
/**
 * LeetCode 473. 火柴拼正方形（回溯 + 掩码剪枝）
 */
public boolean makesquare(int[] matchsticks) {
    int total = 0;
    for (int x : matchsticks) total += x;
    if (total % 4 != 0) return false;        // ⚠️ 总和必须被 4 整除
    int target = total / 4;
    Arrays.sort(matchsticks);                // ⚠️ 降序（大根先试，剪枝强）
    // 反转成降序
    for (int i = 0, j = matchsticks.length - 1; i < j; i++, j--) {
        int t = matchsticks[i]; matchsticks[i] = matchsticks[j]; matchsticks[j] = t;
    }
    if (matchsticks[0] > target) return false;

    int[] sides = new int[4];                // 四条边的当前长度
    return backtrack(matchsticks, 0, sides, target);
}

private boolean backtrack(int[] sticks, int idx, int[] sides, int target) {
    if (idx == sticks.length)
        return sides[0] == target && sides[1] == target
                && sides[2] == target;       // 三条对则第四条必对

    for (int i = 0; i < 4; i++) {
        if (sides[i] + sticks[idx] > target) continue;   // ⚠️ 超边剪枝
        // ⚠️ 对称剪枝：相同长度的边跳过
        if (i > 0 && sides[i] == sides[i - 1]) continue;
        sides[i] += sticks[idx];
        if (backtrack(sticks, idx + 1, sides, target)) return true;
        sides[i] -= sticks[idx];             // 回溯
    }
    return false;
}
// 推演 [1,1,2,2,2]：total=8, target=2
//   排序 [2,2,2,1,1] → 大根先放 → 快速找到方案 ✓
// ⚠️ 复杂度：剪枝后远小于 4^n
// ⚠️ 面试必答："473 = 回溯 + 三大剪枝——
//   降序（大根先试）、超边跳过、对称边去重；
//   掩码版（已用集合）是等价写法。"
```

## 3. 464. 我能赢吗（博弈掩码）

### 3.1 题目与思路

```
轮流选数（每个一次），累计 ≥ total 者胜
状态 = 已选集合（mask）→ 三态缓存
⚠️ 完整推导见记忆化/02 与位掩码/01 模块 4 节
```

### 3.2 完整代码

```java
/**
 * LeetCode 464. 我能赢吗（博弈掩码）
 */
public boolean canIWin(int maxChoosableInteger, int desiredTotal) {
    if (desiredTotal <= 0) return true;
    if (maxChoosableInteger * (maxChoosableInteger + 1) / 2 < desiredTotal)
        return false;                        // ⚠️ 总和不够 → 无人能赢

    int[] memo = new int[1 << maxChoosableInteger];   // 0/1/-1 三态
    return dfs(0, desiredTotal, maxChoosableInteger, memo) == 1;
}

private int dfs(int mask, int remaining, int maxN, int[] memo) {
    if (memo[mask] != 0) return memo[mask];
    for (int i = 1; i <= maxN; i++) {
        if ((mask & (1 << (i - 1))) != 0) continue;   // 已选
        if (i >= remaining                       // 选了直接赢
                || dfs(mask | (1 << (i - 1)), remaining - i, maxN, memo) == -1) {
            return memo[mask] = 1;               // ⚠️ 存在必胜走法
        }
    }
    return memo[mask] = -1;                      // 全部走法都输
}
// 推演 maxN=4, total=6（先手胜）：
//   dfs(0,6)：试选 4 → 剩 2；对手 dfs(4,2)：选 2 赢 → 对手胜
//   试选 3 → 剩 3；对手选 3 赢？——对手胜；试选 2 → 剩 4；
//   对手 dfs(2,4)：选 4 赢 → 对手胜... 最终找到必胜走法 ✓
// ⚠️ 复杂度：O(2^maxN × maxN)
// ⚠️ 面试必答："464 = 博弈三态缓存——
//   状态 = 已选集合掩码；
//   我赢 = 存在一步让对手必败。"
```

## 4. 1915. 最美子字符串（前缀奇偶）

### 4.1 题目与思路

```
最多一个奇数频次字符的子串数
前缀奇偶压缩：26 字符奇偶 = 26 位掩码
⚠️ 完整推导见位掩码/01 模块 5 节
```

### 4.2 完整代码

```java
/**
 * LeetCode 1915. 最美子字符串（前缀奇偶）
 */
public long wonderfulSubstrings(String word) {
    Map<Integer, Integer> count = new HashMap<>();
    count.put(0, 1);                         // ⚠️ 空前缀（全偶）
    int mask = 0;
    long result = 0;

    for (char c : word.toCharArray()) {
        mask ^= 1 << (c - 'a');              // 翻转字符奇偶
        result += count.getOrDefault(mask, 0);       // ① 全部偶数字符
        for (int i = 0; i < 26; i++) {               // ② 恰一个奇数
            result += count.getOrDefault(mask ^ (1 << i), 0);
        }
        count.merge(mask, 1, Integer::sum);
    }
    return result;
}
// 推演 "aba"：
//   前缀掩码：a → 1；ab → 3；aba → 2
//   a：相同 0 + 差一位 {0}→1 → +1（"a"）
//   b：差一位 {1,2}：1 有 1 次 → +1（"ab"）
//   a：相同 2 无；差一位 {3,0}：3 有 1 次 → +1（"aba"）
//   总 4 ✓
// ⚠️ 复杂度：O(26n)
// ⚠️ 面试必答："1915 = 前缀奇偶掩码——
//   子串合法 ⟺ 两端前缀掩码相同（全偶）
//   或差一位（一个奇数）。"
```

## 5. 78. 子集（掩码枚举回顾）

### 5.1 完整代码

```java
/**
 * LeetCode 78. 子集（掩码枚举）
 */
public List<List<Integer>> subsets(int[] nums) {
    int n = nums.length;
    List<List<Integer>> result = new ArrayList<>();
    for (int mask = 0; mask < (1 << n); mask++) {   // ⚠️ 2^n 个掩码
        List<Integer> sub = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            if ((mask & (1 << i)) != 0) sub.add(nums[i]);   // 第 i 位 = 1 → 选
        }
        result.add(sub);
    }
    return result;
}
// ⚠️ 面试必答："78 = 掩码枚举的最小样板——
//   mask 的每一位 = 一个元素的选/不选。"
```

## 6. 位掩码方法论总结

### 6.1 解题框架

```
① 识别：集合状态 / 每个元素一次 / n ≤ 20
② 设计状态：mask = 已选集合（或奇偶状态）
③ 选形态：
   计数/最值 → 状压 DP（dp[mask] 递推）
   可行性 → 回溯 + 掩码剪枝
   博弈 → 三态缓存
   奇偶 → 前缀异或
④ 复杂度：O(n·2^n) / O(3^n) / O(26n)

⚠️ 识别信号：
  "每个元素恰好一次/集合状态" → 掩码
  "轮流选择/必胜" → 博弈掩码
  "奇偶频次" → 前缀异或
```

### 6.2 模板速查表

| 题型 | 模板 | 代表题 |
|------|------|--------|
| 方案数 | dp[mask] += dp[前置] | 526 |
| 可行性 | 回溯 + 剪枝 | 473 |
| 博弈 | 三态缓存 | 464 |
| 前缀奇偶 | 异或 + 计数 | 1915 |
| 子集枚举 | 2^n 掩码 | 78 |

### 6.3 自测清单

```
□ 位号（0/1 基）统一？
□ dp 初始化（起点状态）？
□ 剪枝（降序/超界/对称）？
□ 博弈三态（0 未算）？
□ 前缀异或方向？
□ n ≤ 20 边界？
□ 回溯还原？
```
