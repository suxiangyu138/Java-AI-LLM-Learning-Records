## 1. 核心概念

### 1.1 什么是位掩码

> 位掩码（Bitmask）：用**一个整数的二进制位表示集合**。第 i 位 = 1 表示元素 i 在集合中。

```
例：mask = 1011₂ 表示集合 {0, 1, 3}

优势：
  集合操作 O(1)（位运算）
  状态只占 1 个 int（32 位 = 32 个元素的集合）
  数组下标 = 掩码值 → 状态压缩 DP

适用条件：n ≤ 20（2²⁰ ≈ 10⁶ 状态可行）
```

### 1.2 识别信号

```
"已选/已访问集合" + n ≤ 20 → 位掩码
"子集枚举/状态压缩/TSP" → 位掩码
"集合操作频繁" → 位运算 O(1)

⚠️ 状态数评估（面试第一句）：
  2ⁿ 状态 × 附加维度
  n=20 → 10⁶ ✓；n=25 → 3×10⁷ 勉强
  n=30 → 10⁹ 爆炸 → 换思路
```

### 1.3 位掩码 vs 布尔数组

```
掩码：1 个 int、位运算 O(1)、可做 DP 下标
布尔数组：可读但无法做 DP 下标

→ 状态压缩 DP 必须用掩码
  （dp[mask] 的数组下标就是掩码值）
```

## 2. 完整代码模板

### 2.1 位操作速查

```java
// ═══════════ 集合操作 ═══════════════════════════
mask | (1 << i)          // 加入元素 i
mask & ~(1 << i)         // 移除元素 i
(mask >> i & 1) == 1     // 是否包含 i
Integer.bitCount(mask)   // 集合大小
(1 << n) - 1             // 全集（n 个元素全选）

// ═══════════ 枚举子集 ═══════════════════════════
// mask 的所有非空子集
for (int sub = mask; sub > 0; sub = (sub - 1) & mask) {
    // sub 遍历 mask 的子集
}
// 例：mask=1100 → 1100, 1000, 0100
// 原理：每次减 1 后与 mask 相与（只保留 mask 内的位）
// ⚠️ 总枚举量 3ⁿ（每个元素三种状态）

// ═══════════ 判断全集/空集 ═══════════════════════
mask == (1 << n) - 1     // 是否全选
mask == 0                // 是否空集
```

### 2.2 78. 子集（位枚举版）

```java
/**
 * LeetCode 78. 子集（位运算版）
 * 2ⁿ 个子集 ↔ 掩码 0..2ⁿ-1
 */
public List<List<Integer>> subsets(int[] nums) {
    List<List<Integer>> result = new ArrayList<>();
    int n = nums.length;

    for (int mask = 0; mask < (1 << n); mask++) {
        List<Integer> subset = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            if ((mask & (1 << i)) != 0) {   // 第 i 位为 1
                subset.add(nums[i]);
            }
        }
        result.add(subset);
    }
    return result;
}
// O(n × 2ⁿ)：2ⁿ 个掩码 × 每个 O(n) 构造
// 对比回溯版：位枚举更"数学"，回溯更通用（可剪枝）
```

### 2.3 464. 我能赢吗（博弈 + 掩码）

```java
/**
 * LeetCode 464. 我能赢吗
 * 状态 = 已取数字集合（掩码）→ 记忆化博弈
 * 剩余和可由掩码推导 → 一维状态！
 */
public boolean canIWin(int maxChoosableInteger, int desiredTotal) {
    int sum = maxChoosableInteger * (maxChoosableInteger + 1) / 2;
    if (sum < desiredTotal) return false;    // 剪枝：全选都不够
    if (desiredTotal <= 0) return true;

    Boolean[] memo = new Boolean[1 << maxChoosableInteger];
    return dfs(0, desiredTotal, maxChoosableInteger, memo);
}

private boolean dfs(int mask, int remain, int max, Boolean[] memo) {
    if (memo[mask] != null) return memo[mask];

    for (int i = 0; i < max; i++) {
        int bit = 1 << i;
        if ((mask & bit) != 0) continue;     // 已取过

        int nextRemain = remain - (i + 1);
        boolean opponentLose = nextRemain <= 0
            || !dfs(mask | bit, nextRemain, max, memo);
        // ⚠️ 对手必败 → 我必胜

        if (opponentLose) {
            return memo[mask] = true;
        }
    }
    return memo[mask] = false;
}
// 状态数 2^max（max ≤ 20 → 10⁶ 可行）
// ⚠️ Boolean[] 可区分"未计算"与 false（boolean[] 不行）
```

## 3. 状态压缩 DP 详解

### 3.1 TSP 模板（旅行商）

```java
/**
 * 状态压缩 DP 标准模板（TSP）
 * dp[mask][i]：已访问集合 mask、当前在城市 i 的最短距离
 */
public int tsp(int[][] dist) {
    int n = dist.length;
    int[][] dp = new int[1 << n][n];       // 2ⁿ × n 状态
    for (int[] row : dp) Arrays.fill(row, Integer.MAX_VALUE / 2);
    dp[1][0] = 0;                          // 从城市 0 出发

    for (int mask = 1; mask < (1 << n); mask++) {
        for (int i = 0; i < n; i++) {
            if ((mask & (1 << i)) == 0) continue;    // i 不在集合
            for (int j = 0; j < n; j++) {
                if ((mask & (1 << j)) != 0) continue; // j 已访问

                int nextMask = mask | (1 << j);       // 加入 j
                dp[nextMask][j] = Math.min(
                    dp[nextMask][j],
                    dp[mask][i] + dist[i][j]);        // 松弛
            }
        }
    }
    return dp[(1 << n) - 1][0];            // 访问完所有城市回 0
}
// 复杂度 O(n² × 2ⁿ)
// 对比暴力 n!：状态压缩是集合问题的标准解法
```

### 3.2 状态压缩 DP 的通用模式

```
① 状态定义：dp[mask][附加维度]
   mask = 已选集合，附加 = 当前位置/最后元素
② 转移：尝试"加入一个新元素"
   nextMask = mask | (1 << j)
③ 初始化：起点状态（dp[1][0] 等）
④ 答案：全选状态（(1<<n)-1）

⚠️ 附加维度：
   只需要集合 → 一维 dp[mask]
   需要顺序 → 二维 dp[mask][last]
```

### 3.3 状态数评估（面试必答）

```
dp 大小 = 2ⁿ × 附加维度
  2²⁰ ≈ 10⁶ ✓（常见上限）
  2²⁵ ≈ 3×10⁷（勉强，内存 100MB+）
  2³⁰ ≈ 10⁹ ✗（爆炸）

⚠️ 面试表达：
  "状态数 2²⁰ ≈ 10⁶，dp 数组 10⁶ × 20，
   内存约 80MB 可行，复杂度 O(n²·2ⁿ)。"
```

## 4. 位掩码的操作技巧

### 4.1 枚举子集的复杂度

```
for (sub = mask; sub > 0; sub = (sub-1) & mask)
  单个 mask 的子集枚举：O(2^k)（k = mask 的位数）
  所有 mask 的全体子集：O(3ⁿ)
    （每个元素三种状态：在 mask 不在 sub / 在 sub / 都不在）

⚠️ 需要枚举全部子集的题目（1655 等）注意 3ⁿ 上限
```

### 4.2 掩码的常用变形

```
① 奇偶状态（1915 最美子串）：
   前缀奇偶掩码（26 位 = 26 个字母奇偶）
   窗口 [l,r] 有效 ⇔ 两前缀掩码相差 ≤ 1 位

② 行状态（1349 座位）：
   每行座位用掩码表示 → 行间 DP 转移

③ 子集划分（698）：
   掩码表示"已分配" → 记忆化

识别："状态是集合 + 需要枚举/转移" → 掩码
```

### 4.3 掩码与位运算的结合

```
mask & (mask - 1)   // 去掉最低位 1（枚举技巧）
mask & (-mask)      // 取最低位 1（分组）
Integer.numberOfTrailingZeros(mask)  // 最低位 1 的位置

⚠️ 面试小技巧：
  "取最低位 1 的位置"用 numberOfTrailingZeros
  比循环快且简洁
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"这是集合选择问题，n ≤ 20 → 状态压缩：
 用 int 掩码表示'已选集合'，dp[mask] 表示
 该状态的最优值。转移用位运算加元素
 （mask | (1<<i)）。
 状态数 2ⁿ = 10⁶ 可行，复杂度 O(n × 2ⁿ)。
 枚举子集用 (sub-1)&mask 技巧。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 什么时候想到位掩码？ | n ≤ 20 的集合问题 + "已选集合"状态 |
| 2 | 状态数怎么评估？ | 2ⁿ × 附加维度；2²⁰ ≈ 10⁶ 是常见上限 |
| 3 | 枚举子集复杂度？ | 单 mask 2^k；全体 3ⁿ |
| 4 | 为什么要附加维度？ | 需要"最后元素/位置"时（TSP 的 dp[mask][i]） |
| 5 | 与布尔数组区别？ | 掩码可做数组下标（状态压缩必需） |
| 6 | Boolean[] vs boolean[]？ | 记忆化需区分"未计算"与 false |
| 7 | 位运算加速？ | 加入/判断/枚举都 O(1) |
| 8 | n 大了怎么办？ | 状态爆炸 → 换贪心/数学/剪枝 |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 忘评估状态数 | 内存爆炸 | 先算 2ⁿ |
| 掩码越界 | 溢出 | 1L << n（大 n） |
| 枚举子集写错 | 漏子集 | (sub-1) & mask |
| 附加维度缺失 | 状态不完整 | TSP 加 [i] |
| boolean[] 记忆化 | 无法区分未算 | 用 Boolean[] |

> 🎯 **核心要点**：位掩码 = **整数表示集合 + 位运算操作 + 状态压缩 DP**。识别信号："n ≤ 20 的集合/选择问题、已选状态"。三大操作（加入/判断/枚举子集）+ 状态数评估（2ⁿ）是必备技能；TSP 模板是状态压缩 DP 的标准骨架。
