# 栈与队列

## 📌 课程定位
栈和队列是操作受限的线性表，却是计算机科学中应用最广的结构——函数调用、表达式求值、BFS/DFS、缓冲区、消息队列……面试必考。

## 🎯 核心章节

### 1. 栈（Stack）——LIFO 后进先出
- **ADT**：push（入栈）、pop（出栈）、top/peek（取栈顶）、isEmpty
- **顺序栈**：数组+栈顶指针实现，注意栈满判断
- **链栈**：单链表头插/头删实现，无栈满问题
- **共享栈**：两个栈共享一个数组空间，从两端向中间生长，高效利用空间

### 2. 栈的应用（⭐ 重点）
- **括号匹配**：遇到左括号入栈，右括号出栈匹配——编译原理词法分析基础
- **表达式求值**：
  - 中缀→后缀（逆波兰）：操作数直接输出，运算符比较栈顶优先级
  - 后缀表达式求值：操作数入栈，运算符弹出两个操作数计算后入栈
- **函数调用栈**：每次函数调用压入栈帧（返回地址、局部变量），返回时弹出
- **递归转非递归**：用栈手动模拟系统调用栈
- **撤销/回退操作**：编辑器Undo、浏览器后退

### 3. 队列（Queue）——FIFO 先进先出
- **ADT**：enqueue（入队）、dequeue（出队）、front（取队头）、isEmpty
- **顺序队列**：front/rear指针，假溢出问题
- **循环队列（⭐ 必会）**：
  - 用取模运算实现环形：`(rear+1) % maxSize`
  - 区分队空/队满：牺牲一个单元法 or 计数法
  - 队空：`front == rear`；队满：`(rear+1) % maxSize == front`
- **链队列**：带头结点的单链表+头尾指针

### 4. 双端队列（Deque）
- 两端都可以插入/删除的队列
- Java 的 ArrayDeque、Python 的 collections.deque
- 应用：滑动窗口最大值问题

### 5. 优先队列（Priority Queue）
- **用堆实现**（大根堆/小根堆），入队O(log n)，取优先级最高O(1)
- **应用**：Dijkstra最短路、任务调度、Top K问题、哈夫曼编码
