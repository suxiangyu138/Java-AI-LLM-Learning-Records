## 1. 栈（Stack）——LIFO 后进先出

### 1.1 栈的 ADT

| 操作 | 描述 |
|------|------|
| `push(x)` | 元素 x 入栈 |
| `pop()` | 弹出栈顶元素 |
| `top() / peek()` | 获取栈顶元素（不弹出） |
| `isEmpty()` | 判断栈是否为空 |
| `size()` | 返回栈中元素个数 |

### 1.2 顺序栈（数组实现）

```java
public class ArrayStack<E> {
    private static final int DEFAULT_CAPACITY = 10;
    private E[] data;
    private int top; // 栈顶指针，指向下一个可插入位置

    @SuppressWarnings("unchecked")
    public ArrayStack() {
        data = (E[]) new Object[DEFAULT_CAPACITY];
        top = 0;
    }

    public void push(E element) {
        if (top == data.length) {
            resize(data.length * 2);
        }
        data[top++] = element;
    }

    public E pop() {
        if (isEmpty()) throw new EmptyStackException();
        E element = data[--top];
        data[top] = null; // 避免内存泄漏
        return element;
    }

    public E peek() {
        if (isEmpty()) throw new EmptyStackException();
        return data[top - 1];
    }

    public boolean isEmpty() { return top == 0; }
}
```

### 1.3 链栈（链表实现）

```java
public class LinkedStack<E> {
    private ListNode<E> top; // 栈顶指针
    private int size;

    public void push(E element) {
        ListNode<E> newNode = new ListNode<>(element);
        newNode.next = top;
        top = newNode;
        size++;
    }

    public E pop() {
        if (isEmpty()) throw new EmptyStackException();
        E data = top.data;
        top = top.next;
        size--;
        return data;
    }

    public E peek() {
        if (isEmpty()) throw new EmptyStackException();
        return top.data;
    }

    public boolean isEmpty() { return top == null; }
}
```

| 实现方式 | 优点 | 缺点 |
|---------|------|------|
| 顺序栈 | 空间局部性好，缓存友好 | 需要扩容，有容量上限 |
| 链栈 | 动态容量，无栈满问题 | 额外指针开销 |

### 1.4 共享栈

两个栈共享一个数组空间，从两端向中间生长。

```java
public class SharedStack<E> {
    private E[] data;
    private int top1; // 左栈栈顶（从 0 向右）
    private int top2; // 右栈栈顶（从 n-1 向左）

    @SuppressWarnings("unchecked")
    public SharedStack(int capacity) {
        data = (E[]) new Object[capacity];
        top1 = -1;
        top2 = capacity;
    }

    public void push1(E element) {
        if (top1 + 1 == top2) throw new StackOverflowError("栈满");
        data[++top1] = element;
    }

    public void push2(E element) {
        if (top1 + 1 == top2) throw new StackOverflowError("栈满");
        data[--top2] = element;
    }
}
```

> 💡 **共享栈的优势**：高效利用空间，一个栈满时另一个栈可能还有空间。

## 2. 栈的应用（重点）

### 2.1 括号匹配

```java
public boolean isValid(String s) {
    Map<Character, Character> map = Map.of(')', '(', ']', '[', '}', '{');
    Deque<Character> stack = new ArrayDeque<>();
    for (char c : s.toCharArray()) {
        if (map.containsValue(c)) {
            stack.push(c); // 左括号入栈
        } else {
            if (stack.isEmpty() || stack.pop() != map.get(c)) {
                return false;
            }
        }
    }
    return stack.isEmpty();
}
```

> ⚠️ **边界检查**：遍历结束后检查栈是否为空，避免 `"(("` 这种情况误判。

### 2.2 表达式求值（逆波兰表达式）

**中缀 → 后缀（调度场算法）**：

| 步骤 | 说明 |
|------|------|
| 1 | 操作数直接输出 |
| 2 | 运算符与栈顶比较优先级，栈顶优先级≥当前则弹出，然后将当前运算符入栈 |
| 3 | 左括号直接入栈 |
| 4 | 右括号弹出直到左括号 |
| 5 | 遍历结束，弹出栈中所有运算符 |

**后缀表达式求值**：

```java
public int evalRPN(String[] tokens) {
    Deque<Integer> stack = new ArrayDeque<>();
    for (String token : tokens) {
        switch (token) {
            case "+" -> stack.push(stack.pop() + stack.pop());
            case "-" -> { int b = stack.pop(); int a = stack.pop(); stack.push(a - b); }
            case "*" -> stack.push(stack.pop() * stack.pop());
            case "/" -> { int b = stack.pop(); int a = stack.pop(); stack.push(a / b); }
            default -> stack.push(Integer.parseInt(token));
        }
    }
    return stack.pop();
}
```

### 2.3 函数调用栈

每次函数调用压入**栈帧**，包含：

- 返回地址
- 局部变量
- 参数
- 调用者栈帧的基址

函数返回时弹出栈帧，恢复调用者的执行环境。

> 💡 **递归转非递归**的本质就是用**手动栈**模拟系统调用栈。

### 2.4 单调栈

找出数组中每个元素右侧第一个比它大的元素（Next Greater Element）。

```java
public int[] nextGreaterElement(int[] nums) {
    int n = nums.length;
    int[] result = new int[n];
    Arrays.fill(result, -1);
    Deque<Integer> stack = new ArrayDeque<>(); // 存下标
    for (int i = 0; i < n; i++) {
        while (!stack.isEmpty() && nums[i] > nums[stack.peek()]) {
            int idx = stack.pop();
            result[idx] = nums[i];
        }
        stack.push(i);
    }
    return result;
}
```

> 🎯 **单调栈是面试高频技巧**，常用于解决接雨水、最大矩形、每日温度等问题。

## 3. 队列（Queue）——FIFO 先进先出

### 3.1 队列的 ADT

| 操作 | 描述 |
|------|------|
| `enqueue(x)` / `offer(x)` | 元素 x 入队 |
| `dequeue()` / `poll()` | 出队 |
| `front() / peek()` | 获取队头元素 |
| `isEmpty()` | 判断队列是否为空 |
| `size()` | 返回队列元素个数 |

> ⚠️ **假溢出**：`rear == maxSize` 时队尾已满，但队头前面还有空位，称为假溢出。解决方案——**循环队列**。

### 3.3 循环队列（⭐ 必会）

```java
public class CircularQueue<E> {
    private E[] data;
    private int front; // 队头指针
    private int rear;  // 队尾指针（指向下一个插入位置）
    private int size;  // 当前元素个数

    @SuppressWarnings("unchecked")
    public CircularQueue(int capacity) {
        data = (E[]) new Object[capacity];
        front = 0;
        rear = 0;
        size = 0;
    }

    public boolean offer(E element) {
        if (isFull()) return false;
        data[rear] = element;
        rear = (rear + 1) % data.length; // 取模实现环形
        size++;
        return true;
    }

    public E poll() {
        if (isEmpty()) return null;
        E element = data[front];
        data[front] = null;
        front = (front + 1) % data.length;
        size--;
        return element;
    }

    public E peek() { return isEmpty() ? null : data[front]; }

    public boolean isEmpty() { return size == 0; }

    public boolean isFull() { return size == data.length; }
}
```

**两种判空/判满方法**：

| 方法 | 队空条件 | 队满条件 | 特点 |
|------|---------|---------|------|
| 牺牲一个单元 | `front == rear` | `(rear+1) % maxSize == front` | 最多存 maxSize-1 个元素 |
| 计数法 | `size == 0` | `size == maxSize` | 需要维护 size 变量 |

### 3.4 链队列

```java
public class LinkedQueue<E> {
    private ListNode<E> front; // 队头
    private ListNode<E> rear;  // 队尾
    private int size;

    public void offer(E element) {
        ListNode<E> newNode = new ListNode<>(element);
        if (rear == null) {
            front = rear = newNode;
        } else {
            rear.next = newNode;
            rear = newNode;
        }
        size++;
    }

    public E poll() {
        if (front == null) return null;
        E data = front.data;
        front = front.next;
        if (front == null) rear = null; // 队列变空
        size--;
        return data;
    }

    public E peek() { return front == null ? null : front.data; }
}
```

## 4. 双端队列（Deque）

两端都可以插入和删除的队列。

```java
// Java Deque 接口的主要方法
Deque<E> deque = new ArrayDeque<>();
deque.addFirst(x);   // 队头插入
deque.addLast(x);    // 队尾插入
deque.removeFirst(); // 队头删除
deque.removeLast();  // 队尾删除
deque.getFirst();    // 获取队头
deque.getLast();     // 获取队尾
```

| 实现类 | 特点 |
|--------|------|
| `ArrayDeque` | 数组实现，无容量限制，性能优于 `LinkedList` |
| `LinkedList` | 链表实现，支持 null 元素 |

**应用：滑动窗口最大值**（#239）

```java
public int[] maxSlidingWindow(int[] nums, int k) {
    if (nums == null || k <= 0) return new int[0];
    int n = nums.length;
    int[] result = new int[n - k + 1];
    Deque<Integer> deque = new ArrayDeque<>(); // 存储下标，保证队头最大

    for (int i = 0; i < n; i++) {
        // 移除超出窗口范围的下标
        while (!deque.isEmpty() && deque.peekFirst() < i - k + 1) {
            deque.pollFirst();
        }
        // 移除队列中比当前元素小的（它们不可能成为最大值）
        while (!deque.isEmpty() && nums[deque.peekLast()] < nums[i]) {
            deque.pollLast();
        }
        deque.offerLast(i);
        // 窗口形成后记录结果
        if (i >= k - 1) {
            result[i - k + 1] = nums[deque.peekFirst()];
        }
    }
    return result;
}
```

## 5. 优先队列（Priority Queue）

### 5.1 堆实现

优先队列用**堆**实现——大根堆（最大优先）或小根堆（最小优先）。

| 操作 | 时间复杂度 |
|------|-----------|
| 入队（push） | O(log n) |
| 出队（pop） | O(log n) |
| 取优先级最高（top） | O(1) |
| 建堆 | O(n) |

```java
// Java 优先队列（默认小根堆）
PriorityQueue<Integer> minHeap = new PriorityQueue<>();
// 大根堆
PriorityQueue<Integer> maxHeap = new PriorityQueue<>((a, b) -> b - a);
```

### 5.2 应用场景

| 应用 | 说明 |
|------|------|
| Dijkstra 最短路 | 堆优化，每次取距离最短的未访问结点 |
| 任务调度 | 优先级高的任务先执行 |
| Top K 问题 | 维护大小为 K 的小根堆 |
| 哈夫曼编码 | 每次取两个最小权值合并 |
| 合并 K 个有序链表 | 每次取各链表头的最小值 |

> 💡 **Java `PriorityQueue` 默认是小根堆**，若要大根堆需传入 `Comparator.reverseOrder()`。

## 6. 栈与队列的对比

| 维度 | 栈（Stack） | 队列（Queue） |
|------|------------|-------------|
| **原则** | LIFO（后进先出） | FIFO（先进先出） |
| **核心操作** | push / pop | offer / poll |
| **物理实现** | 数组 / 链表 | 数组（循环）/ 链表 |
| **典型应用** | 函数调用、括号匹配、Undo | BFS、消息队列、缓冲区 |
| **变形** | 单调栈、共享栈 | 循环队列、双端队列、优先队列 |

## 8. 学习建议

1. **手写循环队列**的所有操作，注意取模的边界条件（`(rear+1) % maxSize`）
2. **表达式求值**是经典综合题，用代码完整实现一遍
3. **单调栈**是面试高频技巧，掌握 Next Greater Element 模板可解决 80% 单调栈问题
4. **优先队列**是 TopK、Dijkstra 的核心数据结构，理解堆的上滤和下滤过程

> 🎯 栈和队列虽然"操作受限"，但正是这种限制让它们成为解决特定问题的利器——限制带来了简洁与高效。
