## 1. 253. 会议室 II（事件扫描）

### 1.1 题目与思路

```
最少会议室 = 区间最大重叠数
事件扫描：进入 +1、离开 -1，扫描取峰值
⚠️ 同坐标先离开（首尾相接不重叠）
```

### 1.2 完整代码

```java
/**
 * LeetCode 253. 会议室 II（事件扫描）
 */
public int minMeetingRooms(int[][] intervals) {
    // 事件化：进入 +1 / 离开 -1
    int n = intervals.length;
    int[] starts = new int[n];
    int[] ends = new int[n];
    for (int i = 0; i < n; i++) {
        starts[i] = intervals[i][0];
        ends[i] = intervals[i][1];
    }
    Arrays.sort(starts);                       // ⚠️ 进入时间排序
    Arrays.sort(ends);                         // 离开时间排序

    int rooms = 0, maxRooms = 0;
    int i = 0, j = 0;
    while (i < n) {
        if (starts[i] < ends[j]) {             // ⚠️ 有会议开始早于最早结束
            rooms++;                           // 需要新会议室
            i++;
        } else {                               // 会议结束 → 释放
            rooms--;
            j++;
        }
        maxRooms = Math.max(maxRooms, rooms);
    }
    return maxRooms;
}
// 推演 [[0,30],[5,10],[15,20]]：
//   starts=[0,5,15], ends=[10,20,30]
//   i=0: 0<10 → rooms=1；i=1: 5<10 → rooms=2
//   i=2: 15<10? 否 → rooms=1, j=1；15<20 → rooms=2
//   峰值 2 ✓
// ⚠️ 复杂度：O(n log n)（排序），O(n) 空间
// ⚠️ 面试表达："253 = 双指针扫描（排序后的进入/离开
//   时间线）——'最早开始 vs 最早结束'决定
//   需要新房间还是释放房间。"
```

## 2. 218. 天际线问题

### 2.1 题目与思路

```
多个矩形（left, right, height）→ 轮廓拐点
事件 + TreeMap 高度多重集：
  进入 (left, +h)、离开 (right, -h)
  扫描时高度变化 → 记录拐点
⚠️ 同坐标先处理进入（否则离开瞬间高度先降）
```

### 2.2 完整代码

```java
/**
 * LeetCode 218. 天际线问题
 */
public List<List<Integer>> getSkyline(int[][] buildings) {
    // ① 事件：进入 +h / 离开 -h（用负数标记离开）
    List<int[]> events = new ArrayList<>();
    for (int[] b : buildings) {
        events.add(new int[]{b[0], b[2]});     // 进入
        events.add(new int[]{b[1], -b[2]});    // 离开（负数）
    }
    // ⚠️ 排序：位置升序；同位置先进入（高度为正的在前）
    events.sort((a, b) -> a[0] != b[0] ? a[0] - b[0]
            : b[1] - a[1]);                   // ⚠️ 高度降序（进入优先）

    TreeMap<Integer, Integer> heights = new TreeMap<>();   // 高度 → 计数
    List<List<Integer>> result = new ArrayList<>();
    int prevMax = 0;

    for (int[] e : events) {
        int h = e[1];
        if (h > 0) heights.merge(h, 1, Integer::sum);      // 进入
        else {
            int count = heights.get(-h);                    // 离开
            if (count == 1) heights.remove(-h);
            else heights.put(-h, count - 1);
        }
        int curMax = heights.isEmpty() ? 0 : heights.lastKey();
        if (curMax != prevMax) {                            // ⚠️ 高度变化 → 拐点
            result.add(List.of(e[0], curMax));
            prevMax = curMax;
        }
    }
    return result;
}
// 推演 [[2,9,10],[3,7,15],[5,12,12],[15,20,10],[19,24,8]]：
//   x=2: 高度 10 → 拐点 (2,10)
//   x=3: 进入 15 → 最高 15 → 拐点 (3,15)
//   x=7: 离开 15 → 最高 12 → 拐点 (7,12)
//   x=12: 离开 12 → 最高 10 → 拐点 (12,10)
//   ...最终轮廓 ✓
// ⚠️ 复杂度：O(n log n)（TreeMap 操作 O(log n)）
// ⚠️ 面试表达："天际线 = 事件 + TreeMap 高度计数——
//   高度变化即拐点。同坐标'进入优先'
//   保证离开瞬间不产生虚假拐点。"
```

## 3. 850. 矩形面积 II

### 3.1 题目与思路

```
多个矩形覆盖总面积（可重叠，n ≤ 200）
二维扫描线：x 分列（宽度已知）→ 每列 y 一维覆盖
⚠️ 01 模块 5 节完整推导
```

### 3.2 完整代码

```java
/**
 * LeetCode 850. 矩形面积 II（二维扫描线）
 */
public int rectangleArea(int[][] rects) {
    // ① x 边界去重排序
    Set<Integer> xs = new TreeSet<>();
    for (int[] r : rects) { xs.add(r[0]); xs.add(r[2]); }
    Integer[] xArr = xs.toArray(new Integer[0]);

    long total = 0;
    for (int i = 0; i < xArr.length - 1; i++) {
        int x1 = xArr[i], x2 = xArr[i + 1];
        long width = x2 - x1;

        // ② 覆盖该列的矩形（y 区间）
        List<int[]> yRanges = new ArrayList<>();
        for (int[] r : rects)
            if (r[0] <= x1 && x2 <= r[2])      // ⚠️ 矩形横跨该列
                yRanges.add(new int[]{r[1], r[3]});

        // ③ y 区间合并求覆盖长度（贪心合并）
        long yLen = unionLength(yRanges);
        total += width * yLen;
    }
    return (int) (total % 1_000_000_007);
}

/** 区间合并求总长度 */
private long unionLength(List<int[]> ranges) {
    ranges.sort((a, b) -> a[0] - b[0]);
    long len = 0;
    int curL = -1, curR = -1;
    for (int[] r : ranges) {
        if (r[0] > curR) {                     // 新段
            len += curR - curL;                // 结算旧段
            curL = r[0]; curR = r[1];
        } else {
            curR = Math.max(curR, r[1]);       // 扩展当前段
        }
    }
    len += curR - curL;                        // ⚠️ 最后一段
    return len;
}
// 推演 rects=[[0,0,2,2],[1,0,2,3],[1,0,3,1]]：
//   x 边界 [0,1,2,3]
//   [0,1]：矩形 1 → y [0,2] 长 2 → 面积 2
//   [1,2]：全部 → y 合并 [0,3] 长 3 → 面积 3
//   [2,3]：矩形 3 → y [0,1] 长 1 → 面积 1
//   总面积 6 ✓
// ⚠️ 复杂度：O(n² log n)（列数 × 每列合并排序）
// ⚠️ 面试表达："850 把二维问题拆成'列 × 列内一维'——
//   n=200 时 O(n² log n) 可行；坐标压缩
//   可降到 O(n²)。"
```

## 4. 391. 完美矩形

### 4.1 题目与思路

```
矩形能否无缝拼接成完整大矩形（无重叠无空隙）
四条件：面积守恒 + 角点奇偶（恰好 4 个奇次角 = 外四角）
⚠️ 01 模块 6 节推导；Set 的异或语义
```

### 4.2 完整代码

```java
/**
 * LeetCode 391. 完美矩形
 */
public boolean isRectangleCover(int[][] rectangles) {
    long areaSum = 0;
    int minX = Integer.MAX_VALUE, minY = Integer.MAX_VALUE;
    int maxX = Integer.MIN_VALUE, maxY = Integer.MIN_VALUE;
    Set<String> corners = new HashSet<>();

    for (int[] r : rectangles) {
        areaSum += (long) (r[2] - r[0]) * (r[3] - r[1]);
        minX = Math.min(minX, r[0]); maxX = Math.max(maxX, r[2]);
        minY = Math.min(minY, r[1]); maxY = Math.max(maxY, r[3]);

        String[] cs = {
                r[0] + "," + r[1], r[0] + "," + r[3],
                r[2] + "," + r[1], r[2] + "," + r[3]};
        for (String c : cs) {                 // ⚠️ 角点异或
            if (!corners.add(c)) corners.remove(c);   // 偶数次 → 抵消
        }
    }
    // ① 面积守恒
    if (areaSum != (long) (maxX - minX) * (maxY - minY)) return false;
    // ② 恰好 4 个奇次角
    if (corners.size() != 4) return false;
    // ③ 4 个角 = 外四角
    return corners.contains(minX + "," + minY)
            && corners.contains(minX + "," + maxY)
            && corners.contains(maxX + "," + minY)
            && corners.contains(maxX + "," + maxY);
}
// 推演 [[1,1,3,3],[3,1,4,2],[3,2,4,4],[1,3,2,4],[2,3,3,4]]：
//   面积守恒 ✓；角点：外角 4 个奇数、内部角全部偶数 → true ✓
// 推演 两个重叠矩形：内部角出现 2 次？——重叠会产生
//   "内部十字角"出现 2 次... 面积守恒先失败 → false ✓
// ⚠️ 复杂度：O(n)
// ⚠️ 面试表达："完美矩形 = 面积守恒 + 角点奇偶——
//   无重叠无空隙 ⟺ 内部角全偶数、外角恰好 4 个。"
```

## 5. 2406. 将区间分为最少组数

### 5.1 题目与思路

```
区间分组（组内区间不重叠）的最少组数
= 最大重叠数（与 253 同构！）
⚠️ 两种写法：事件扫描（同 253）或 堆贪心
```

### 5.2 完整代码（堆贪心版）

```java
/**
 * LeetCode 2406. 将区间分为最少组数
 * ⚠️ 与 253 本质相同：最少组 = 最大重叠数
 * 堆贪心版：按开始排序，堆存"各组最晚结束"
 */
public int minGroups(int[][] intervals) {
    Arrays.sort(intervals, (a, b) -> a[0] - b[0]);    // 开始时间排序

    // ⚠️ 小顶堆：各组的"结束时间"（堆顶 = 最早结束）
    PriorityQueue<Integer> heap = new PriorityQueue<>();
    for (int[] it : intervals) {
        if (!heap.isEmpty() && heap.peek() < it[0]) {
            heap.poll();                       // ⚠️ 有空闲组（最早结束 < 开始）
        }
        heap.offer(it[1]);                     // 占用一组（更新结束）
    }
    return heap.size();                        // 组数 = 堆大小
}
// 推演 [[5,10],[6,8],[1,5],[2,3],[1,10]]：
//   [1,5]：堆空 → 入 5 → {5}
//   [1,10]：5 < 1? 否 → 入 10 → {5,10}
//   [2,3]：5 < 2? 否 → 入 3 → {3,5,10}
//   [5,10]：3 < 5 → 弹 3，入 10 → {5,10,10}
//   [6,8]：5 < 6 → 弹 5，入 8 → {8,10,10} → 3 组 ✓
// ⚠️ 复杂度：O(n log n)
// ⚠️ 面试表达："2406 与 253 同一本质（最大重叠），
//   堆贪心视角：按开始时间分配'最早空闲的组'——
//   贪心正确性：最早结束的组如果不能接，其他组更不能。"
```

## 6. 1109. 航班预订统计（差分数组）

### 6.1 题目与思路

```
bookings[i] = [first, last, seats] → 每航班座位数
区间加法 → 差分数组（坐标紧凑 1..n）
⚠️ 扫描线的事件形态（01 模块 2 节统一视角）
```

### 6.2 完整代码

```java
/**
 * LeetCode 1109. 航班预订统计（差分数组）
 */
public int[] corpFlightBookings(int[][] bookings, int n) {
    int[] diff = new int[n + 2];               // ⚠️ +2 防 last+1 越界

    for (int[] b : bookings) {
        diff[b[0]] += b[2];                    // 区间起点 +seats
        diff[b[1] + 1] -= b[2];                // 区间终点后 -seats
    }
    int[] result = new int[n];
    int cur = 0;
    for (int i = 0; i < n; i++) {
        cur += diff[i + 1];                    // ⚠️ 前缀和还原
        result[i] = cur;
    }
    return result;
}
// 推演 bookings=[[1,2,10],[2,3,20],[2,5,25]], n=5：
//   diff：+10@1, -10@3；+20@2, -20@4；+25@2, -25@6
//   还原：航班1:10；航班2:10+20+25=55；航班3:20+25=45
//         航班4:25；航班5:25 ✓
// ⚠️ 复杂度：O(n + m)（差分最优——对比扫描线 O(n log n)）
// ⚠️ 面试表达："1109 坐标范围小（1..n）→ 差分数组
//   O(n+m) 优于扫描线 O(n log n)。
//   与 253 的区别正是'坐标范围'决定的选型。"
```

## 7. 扫描线方法论总结

### 7.1 解题框架

```
① 识别：区间重叠/覆盖/峰值/面积 → 扫描线候选
② 选型：
   坐标紧凑（≤10⁶）→ 差分数组 O(n+k)
   坐标任意 → 事件排序 O(n log n)
   二维 → 列 × 列内一维
   判定类 → 边界校验（角点法）
③ 事件排序：同坐标顺序由语义定
④ 状态维护：计数器 / TreeMap / 堆
⑤ 复杂度：O(n log n)（排序主导）

⚠️ 识别信号：
  "最大重叠/最少房间/最少组" → 253/2406
  "轮廓/覆盖面积" → 218/850
  "完美拼接" → 391
  "区间加减" → 1109（差分）
```

### 7.2 题型模板速查

| 题型 | 核心 | 代表题 |
|------|------|--------|
| 最大重叠 | 事件 ±1 峰值 | 253、2406 |
| 动态高度 | TreeMap 计数 | 218 |
| 二维面积 | 列宽 × y 覆盖 | 850 |
| 完美判定 | 角点奇偶 + 面积 | 391 |
| 区间加减 | 差分数组 | 1109 |
| 区间合并 | 排序贪心 | 56、850 内部 |

### 7.3 自测清单

```
□ 事件排序语义正确（先离开/先进入）？
□ TreeMap 计数归零才删键？
□ 二维列边界去重？
□ 角点法四条件全查？
□ 坐标范围选型（差分 vs 事件）？
□ 溢出（面积 long）？
□ 堆贪心的"最早结束"判断正确？
```
