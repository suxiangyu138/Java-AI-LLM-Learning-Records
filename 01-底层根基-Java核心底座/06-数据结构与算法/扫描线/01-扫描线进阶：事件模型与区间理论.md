## 1. 事件模型：扫描线的骨架

### 1.1 基本思想

```
扫描线 = 把"区间/矩形"问题转化为"事件序列"：
  区间 [l, r] → 两个事件：(l, +1) 进入、(r, -1) 离开
  按坐标排序事件 → 一次扫描维护当前状态

⚠️ 核心优势：
  区间重叠/覆盖/峰值问题 → O(n log n)（排序事件 + O(n) 扫描）
  对比暴力两两比较 O(n²)

⚠️ 面试必答：
"扫描线 = 事件化 + 排序 + 单次扫描。
 每个区间拆成进入/离开两个事件，
 扫描时维护计数器/高度/集合。"
```

### 1.2 事件模板

```java
/** 事件模板：区间 → 进入/离开事件 */
class Event {
    int pos;        // 坐标
    int delta;      // +1 进入 / -1 离开
    int value;      // 附加信息（高度/权重）
}

List<Event> toEvents(int[][] intervals) {
    List<Event> events = new ArrayList<>();
    for (int[] it : intervals) {
        events.add(new Event(it[0], +1, it[2]));   // 进入
        events.add(new Event(it[1], -1, it[2]));   // 离开
    }
    // ⚠️ 排序细节：同位置先离开还是先进入？
    //   会议场景（253）：先离开后进入（首尾相接不算重叠）
    //   覆盖场景：先进入后离开（连续覆盖）
    events.sort((a, b) -> a.pos != b.pos ? a.pos - b.pos
            : a.delta - b.delta);             // 按 (位置, delta) 排序
    return events;
}
// ⚠️ 排序规则是扫描线最容易出错的地方：
//   253 会议室：同刻先 -1（离开）→ 相衔接的会议不重叠
//   覆盖面积：同刻先 +1（进入）→ 无缝覆盖算连续
```

### 1.3 事件排序的细节

```
⚠️ 同位置多事件的顺序（关键决策点）：
  求"最大重叠数"：先减后加（峰值不虚高）
  求"覆盖总长"：先加后减（连续覆盖不中断）

⚠️ 面试表达：
"同坐标事件顺序由'语义'决定——
 253 会议室（首尾相接不算重叠）先离开；
 覆盖统计（无缝衔接算连续）先进入。
 先问语义再定排序。"
```

## 2. 扫描线 vs 差分数组：统一视角

### 2.1 两者的本质

```
差分数组：区间 [l, r] +v → diff[l] += v; diff[r+1] -= v
扫描线：区间 [l, r] → 事件 (l, +1) / (r, -1)

⚠️ 完全同构！
  差分数组 = 扫描线的事件数组（按位置隐式有序）
  扫描线 = 差分数组的"排序 + 显式扫描"

⚠️ 区别：
  差分：坐标连续（数组下标）→ 用数组
  扫描线：坐标任意/稀疏 → 排序后扫描

⚠️ 面试必答：
"差分数组与扫描线是同一思想——
 区间两端打标记。坐标紧凑用数组（O(n+k)），
 坐标任意用排序事件（O(n log n)）。"
```

### 2.2 选型决策

| 场景 | 差分数组 | 扫描线 |
|------|:---:|:---:|
| 坐标范围小（≤10⁶） | ✅ O(n+k) | 可用 |
| 坐标任意（1e9） | ❌ 数组爆炸 | ✅ 排序 |
| 需要坐标有序输出 | 需遍历 | ✅ 天然有序 |
| 区间附加信息（高度） | ❌ 只支持 ±v | ✅ 任意值 |

```
⚠️ 典型对应：
  1109 航班预订（坐标小）→ 差分数组
  253 会议室（坐标任意）→ 扫描线事件
  850 矩形面积 → 扫描线（二维）

⚠️ 面试表达：
"'坐标范围'决定选型——小范围差分 O(n+k) 更快，
 大范围扫描线 O(n log n) 可行。"
```

## 3. 区间覆盖的三种形态

### 3.1 形态一：最大重叠数（253）

```
问题：区间最大重叠数（同时进行的会议数）
扫描：每步 current += delta → 记录最大值
⚠️ 排序：同位置先离开（-1）——相衔接不算重叠

⚠️ 面试表达：
"最大重叠 = 扫描线计数器峰值。
 同刻先 -1 保证 [1,2] 与 [2,3] 不重叠。"
```

### 3.2 形态二：覆盖总长度

```
问题：区间并集总长度
扫描：当前覆盖数 > 0 时累加长度
  ⚠️ 覆盖数从 0 → 1 或 1 → 0 时结算区间长度

⚠️ 排序：同位置先 +1（无缝覆盖算连续）
  例：[1,3] 与 [3,5] → 总长 4（不是 4？是 [1,5] = 4 ✓）
```

### 3.3 形态三：区间合并

```
问题：合并所有重叠区间
排序后贪心：
  当前区间 [l, r]，下一区间 [l2, r2]
  l2 ≤ r → 合并（r = max(r, r2)）
  否则 → 输出当前，开始新的

⚠️ 复杂度：O(n log n)（排序主导）
⚠️ 面试表达：
"区间合并 = 排序 + 贪心扩展——
 重叠则右端取 max，不重叠则结算。
 是扫描线思想的'静态度'（无需事件计数）。"
```

## 4. 动态高度维护：TreeMap 技巧

### 4.1 218 天际线的核心

```
天际线问题：多个矩形（x1, x2, h），求轮廓拐点
事件：进入 (x1, +h) / 离开 (x2, -h)
扫描时维护"当前高度的多重集合"：
  ⚠️ 用 TreeMap（计数多重集）：高度 → 出现次数
  当前最高高度 = TreeMap 最后一个键（lastKey）

⚠️ 为什么需要 TreeMap：
  PriorityQueue 的删除 O(n)（懒删除也可但复杂）
  TreeMap 计数 → 增删 O(log n) → 总 O(n log n)

⚠️ 面试必答：
"动态高度用 TreeMap 计数（高度 → 次数）——
 最高高度 = lastKey()。进入 +1 计数、
 离开 -1 计数，计数归零才删键。"
```

### 4.2 TreeMap 多重集模板

```java
/** 高度多重集（TreeMap 计数） */
TreeMap<Integer, Integer> heights = new TreeMap<>();

void addHeight(int h) {
    heights.merge(h, 1, Integer::sum);
}

void removeHeight(int h) {
    int count = heights.get(h);
    if (count == 1) heights.remove(h);     // ⚠️ 归零才删键
    else heights.put(h, count - 1);
}

int currentMax() {
    return heights.isEmpty() ? 0 : heights.lastKey();   // ⚠️ 最高
}
// ⚠️ 变体：
//   需要最低 → firstKey()
//   需要总和 → 遍历求和（可另维护 sum 变量）
```

## 5. 二维扫描线：面积问题

### 5.1 850 矩形面积 II 的思路

```
多个矩形（可能重叠）的覆盖总面积
二维扫描线：O(n² log n) 或 O(n²)
  ① 收集所有 x 边界（排序去重）
  ② 相邻 x 区间 [x_i, x_i+1]：宽度固定
  ③ 对每个 x 区间：收集覆盖它的矩形 → 一维扫描线求 y 覆盖长度
  ④ 面积 = Σ 宽度 × y 覆盖长度

⚠️ 复杂度：O(n² log n)（n 个矩形，n 个 x 区间）
  对比"离散化 + 差分"的 O(n²)（坐标压缩）

⚠️ 面试必答：
"二维扫描线 = 一维扫描线 × 每列重算——
 x 方向分列（宽度已知），每列内做
 y 方向的一维覆盖统计。n 小（≤200）可行。"
```

### 5.2 二维扫描线骨架

```java
/** 850 矩形面积 II 骨架 */
long rectangleArea(int[][] rects) {
    // ① 收集 x 边界
    Set<Integer> xs = new TreeSet<>();
    for (int[] r : rects) { xs.add(r[0]); xs.add(r[2]); }
    List<Integer> xList = new ArrayList<>(xs);

    long total = 0;
    // ② 每对相邻 x：宽度 = x[i+1] - x[i]
    for (int i = 0; i < xList.size() - 1; i++) {
        int x1 = xList.get(i), x2 = xList.get(i + 1);
        long width = x2 - x1;

        // ③ 收集覆盖该 x 区间的矩形（x1 ≥ r[0] 且 x2 ≤ r[2]）
        List<int[]> active = new ArrayList<>();
        for (int[] r : rects)
            if (r[0] <= x1 && x2 <= r[2]) active.add(r);

        // ④ y 方向一维覆盖长度（扫描线/合并）
        long yLen = unionLength(active);
        total += width * yLen;
    }
    return total % 1_000_000_007;
}
// ⚠️ unionLength：对 y 区间做"区间合并"（第 3 节形态三）
// ⚠️ 面试表达："二维扫描线把面积问题拆成
//   '列宽度 × 列内 y 覆盖'——每列一次一维扫描。"
```

## 6. 完美矩形的角点法

### 6.1 391 完美矩形的判定

```
多个矩形能否无缝拼接成一个大矩形（无重叠无空隙）
四条件：
  ① 面积守恒：Σ 小矩形面积 == 大矩形面积
  ② 角点计数：只有 4 个"奇次角"（出现奇数的角）
  ③ 4 个奇次角 = 大矩形的四角
  ④ 无内部角点出现偶数次？——角点计数已覆盖

⚠️ 核心：角点出现次数
  拼接边界上的角出现 2 次（两个矩形共享）
  外角出现 1 次（4 个）
  内部交点出现 4 次
  → 恰好 4 个奇次角 = 完美拼接

⚠️ 面试必答：
"完美矩形 = 面积守恒 + 角点奇偶——
 完美拼接时内部角出现偶数次（2 或 4），
 只有外四角出现奇数次（1）。"
```

### 6.2 角点法实现要点

```java
/** 391 完美矩形判定骨架 */
boolean isRectangleCover(int[][] rectangles) {
    long areaSum = 0;
    int minX = Integer.MAX_VALUE, minY = Integer.MAX_VALUE;
    int maxX = Integer.MIN_VALUE, maxY = Integer.MIN_VALUE;
    Set<String> corners = new HashSet<>();

    for (int[] r : rectangles) {
        areaSum += (long) (r[2] - r[0]) * (r[3] - r[1]);
        minX = Math.min(minX, r[0]); maxX = Math.max(maxX, r[2]);
        minY = Math.min(minY, r[1]); maxY = Math.max(maxY, r[3]);

        // ⚠️ 角点奇偶：出现偶数次则抵消（remove）
        for (String c : cornersOf(r)) {
            if (!corners.add(c)) corners.remove(c);   // ⚠️ 第二次出现 → 移除
        }
    }
    // ① 面积守恒
    if (areaSum != (long) (maxX - minX) * (maxY - minY)) return false;
    // ② 恰好 4 个奇次角 = 大矩形四角
    if (corners.size() != 4) return false;
    return corners.containsAll(Set.of(
            minX + "," + minY, minX + "," + maxY,
            maxX + "," + minY, maxX + "," + maxY));
}
// ⚠️ Set 的 add/remove 技巧：出现奇数次保留、偶数次移除
// ⚠️ 面试表达："角点法用 Set 的异或语义——
//   每个角'进一次出一次'，最后只剩出现
//   奇数次的角，必须恰好是大矩形四角。"
```

## 7. 面试要点与追问

### 7.1 面试话术模板

```
"扫描线 = 事件化（区间拆进入/离开）→ 排序 →
 单次扫描维护状态。同坐标事件顺序由语义决定
 （253 先离开、覆盖先进入）。
 与差分数组同构（坐标小用数组，任意用排序）。
 动态高度用 TreeMap 计数；二维扫描线 = 列宽度
 × 列内一维覆盖。"
```

### 7.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 扫描线核心？ | 事件化 + 排序 + 单次扫描 |
| 2 | 同坐标顺序？ | 语义决定（253 先离开） |
| 3 | 与差分数组？ | 同构；坐标小数组、任意排序 |
| 4 | 动态高度？ | TreeMap 计数 + lastKey |
| 5 | 二维面积？ | 列宽度 × 列内一维覆盖 |
| 6 | 完美矩形？ | 面积守恒 + 角点奇偶（4 个奇次角） |
| 7 | 复杂度？ | O(n log n)（排序主导） |
| 8 | 什么时候不适用？ | 动态修改区间 → 线段树 |

### 7.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 事件顺序错 | 峰值/覆盖错 | 语义先定 |
| 高度删除忘计数 | 高度错误 | TreeMap 计数归零才删 |
