## 1. 树的基本概念

### 1.1 树的定义

树是 **n (n ≥ 0) 个结点的有限集**，递归定义：

- 空集（n = 0）是树
- 非空树：有且仅有一个**根结点**；其余结点分为 m 个**互不相交**的子树（递归定义）

> 💡 树的递归定义意味着树的大部分操作天然适合用**递归**实现。

### 1.2 基本术语

| 术语 | 定义 |
|------|------|
| **结点深度** | 从根结点向下到该结点的层数（根深度为 1 或 0） |
| **结点高度** | 从该结点向下到最远叶结点的层数 |
| **度（degree）** | 结点拥有的子树个数 |
| **叶子结点** | 度为 0 的结点 |
| **内部结点** | 度 > 0 的结点 |
| **路径长度** | 路径上经过的边的数量 |
| **森林** | m 棵互不相交的树的集合 |

### 1.3 树的性质

| 性质 | 说明 |
|------|------|
| n 个结点的树有 **n-1 条边** | 每个结点（除根外）有且仅有一个父结点 |
| 度为 m 的树第 i 层最多有 **m^(i-1)** 个结点 | i ≥ 1 |
| 高度为 h 的 m 叉树最多有 **(m^h - 1)/(m - 1)** 个结点 | |
| n 个结点的二叉树有 **n+1 个空指针域** | 总指针域 2n，非空 n-1，空 = 2n - (n-1) = n+1 |

## 2. 二叉树的存储与遍历

### 2.1 存储结构

**顺序存储**（完全二叉树适用）：

```java
// 父结点下标 i，左孩子 2i+1，右孩子 2i+2
int[] tree = new int[n];
int leftChild = 2 * i + 1;
int rightChild = 2 * i + 2;
int parent = (i - 1) / 2;
```

**链式存储**：

```java
public class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode(int val) { this.val = val; }
}
```

### 2.2 递归遍历（⭐ 三大遍历必须肌肉记忆）

```java
// 前序遍历：根 → 左 → 右
void preorder(TreeNode root) {
    if (root == null) return;
    System.out.print(root.val + " "); // 访问根
    preorder(root.left);              // 遍历左子树
    preorder(root.right);             // 遍历右子树
}

// 中序遍历：左 → 根 → 右
void inorder(TreeNode root) {
    if (root == null) return;
    inorder(root.left);
    System.out.print(root.val + " ");
    inorder(root.right);
}

// 后序遍历：左 → 右 → 根
void postorder(TreeNode root) {
    if (root == null) return;
    postorder(root.left);
    postorder(root.right);
    System.out.print(root.val + " ");
}
```

| 遍历方式 | 顺序 | 典型应用 |
|---------|------|---------|
| 前序遍历 | 根 → 左 → 右 | 序列化、复制树、表达式树前缀 |
| 中序遍历 | 左 → 根 → 右 | BST 排序输出（升序） |
| 后序遍历 | 左 → 右 → 根 | 删除树、计算目录大小、表达式树后缀 |

### 2.3 非递归遍历（用栈模拟）

```java
// 前序遍历非递归
void preorderIterative(TreeNode root) {
    if (root == null) return;
    Deque<TreeNode> stack = new ArrayDeque<>();
    stack.push(root);
    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();
        System.out.print(node.val + " ");
        // 先压右再压左——出栈时先访问左
        if (node.right != null) stack.push(node.right);
        if (node.left != null) stack.push(node.left);
    }
}

// 中序遍历非递归
void inorderIterative(TreeNode root) {
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode cur = root;
    while (cur != null || !stack.isEmpty()) {
        while (cur != null) {      // 沿左链全部入栈
            stack.push(cur);
            cur = cur.left;
        }
        cur = stack.pop();          // 弹出访问
        System.out.print(cur.val + " ");
        cur = cur.right;            // 转向右子树
    }
}

// 后序遍历非递归（双栈法）
void postorderIterative(TreeNode root) {
    if (root == null) return;
    Deque<TreeNode> stack = new ArrayDeque<>();
    Deque<TreeNode> output = new ArrayDeque<>();
    stack.push(root);
    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();
        output.push(node);
        if (node.left != null) stack.push(node.left);
        if (node.right != null) stack.push(node.right);
    }
    while (!output.isEmpty()) {
        System.out.print(output.pop().val + " ");
    }
}
```

### 2.4 层序遍历（BFS）

```java
void levelOrder(TreeNode root) {
    if (root == null) return;
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        int levelSize = queue.size();
        for (int i = 0; i < levelSize; i++) {
            TreeNode node = queue.poll();
            System.out.print(node.val + " ");
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        System.out.println(); // 换行分隔每层
    }
}
```

> 💡 **层序遍历 = 树的 BFS**，是 BFS 最经典的应用场景之一。

## 3. 二叉树构造

### 3.1 前序 + 中序 → 唯一二叉树

前序确定根，中序分左右。

```java
public TreeNode buildTree(int[] preorder, int[] inorder) {
    return build(preorder, 0, preorder.length - 1,
                 inorder, 0, inorder.length - 1);
}

private TreeNode build(int[] pre, int preL, int preR,
                       int[] in, int inL, int inR) {
    if (preL > preR) return null;
    TreeNode root = new TreeNode(pre[preL]); // 前序第一个为根
    // 在中序中找到根的位置
    int rootIdx = inL;
    while (in[rootIdx] != root.val) rootIdx++;
    int leftSize = rootIdx - inL; // 左子树大小
    root.left = build(pre, preL + 1, preL + leftSize,
                      in, inL, rootIdx - 1);
    root.right = build(pre, preL + leftSize + 1, preR,
                       in, rootIdx + 1, inR);
    return root;
}
```

### 3.2 后序 + 中序 → 唯一二叉树

后序最后一个为根，同理。

| 组合 | 能否唯一确定 |
|------|------------|
| 前序 + 中序 | 能 |
| 后序 + 中序 | 能 |
| 前序 + 后序 | **不能**（反例：单分支树） |

> ⚠️ 仅前序+后序无法区分左右子树的分界，因此不能唯一确定二叉树。

## 4. 二叉搜索树（BST，⭐ 重点）

### 4.1 性质

- 左子树所有结点值 < 根结点值 < 右子树所有结点值
- 中序遍历即为**升序序列**
- 对 BST 的操作时间复杂度 O(h)，其中 h 为树高

### 4.2 查找

```java
public TreeNode searchBST(TreeNode root, int target) {
    if (root == null || root.val == target) return root;
    if (target < root.val) return searchBST(root.left, target);
    else return searchBST(root.right, target);
}
```

### 4.3 插入

```java
public TreeNode insertIntoBST(TreeNode root, int val) {
    if (root == null) return new TreeNode(val);
    if (val < root.val) root.left = insertIntoBST(root.left, val);
    else root.right = insertIntoBST(root.right, val);
    return root;
}
```

### 4.4 删除（三种情况）

```java
public TreeNode deleteNode(TreeNode root, int key) {
    if (root == null) return null;
    if (key < root.val) {
        root.left = deleteNode(root.left, key);
    } else if (key > root.val) {
        root.right = deleteNode(root.right, key);
    } else {
        // 情况 1：叶结点
        if (root.left == null && root.right == null) return null;
        // 情况 2：单孩子
        if (root.left == null) return root.right;
        if (root.right == null) return root.left;
        // 情况 3：两个孩子——用直接后继（右子树最左）替换
        TreeNode successor = findMin(root.right);
        root.val = successor.val;
        root.right = deleteNode(root.right, successor.val);
    }
    return root;
}

private TreeNode findMin(TreeNode root) {
    while (root.left != null) root = root.left;
    return root;
}
```

| 删除情况 | 操作 | 复杂度 |
|---------|------|--------|
| 叶结点 | 直接删除 | O(1) |
| 单孩子 | 孩子替代 | O(1) |
| 两个孩子 | 找后继/前驱替换 | O(h) |

## 5. 平衡二叉树（AVL）

### 5.1 平衡因子

`平衡因子 BF = 左子树高度 - 右子树高度`，`|BF| ≤ 1`。

### 5.2 四种旋转（⭐ 必会手画）

| 失衡情况 | 描述 | 旋转方式 |
|---------|------|---------|
| **LL** | 左子树比右子树高 2，左孩子的左子树插入 | 右单旋 |
| **RR** | 右子树比左子树高 2，右孩子的右子树插入 | 左单旋 |
| **LR** | 左子树比右子树高 2，左孩子的右子树插入 | 先左旋再右旋 |
| **RL** | 右子树比左子树高 2，右孩子的左子树插入 | 先右旋再左旋 |

```java
// 右旋（LL 情况）
private TreeNode rotateRight(TreeNode y) {
    TreeNode x = y.left;
    TreeNode T2 = x.right;
    // 旋转
    x.right = y;
    y.left = T2;
    // 更新高度
    y.height = 1 + Math.max(height(y.left), height(y.right));
    x.height = 1 + Math.max(height(x.left), height(x.right));
    return x;
}

// 左旋（RR 情况）
private TreeNode rotateLeft(TreeNode x) {
    TreeNode y = x.right;
    TreeNode T2 = y.left;
    y.left = x;
    x.right = T2;
    x.height = 1 + Math.max(height(x.left), height(x.right));
    y.height = 1 + Math.max(height(y.left), height(y.right));
    return y;
}
```

### 5.3 性能对比

| 指标 | BST（非平衡） | AVL | 红黑树 |
|------|-------------|-----|--------|
| 查找 | O(h)，最坏 O(n) | O(log n) | O(log n) |
| 插入 | O(h) | O(log n) + 旋转 | O(log n) + 染色 |
| 删除 | O(h) | O(log n) + 旋转 | O(log n) + 染色 |
| 平衡程度 | 不保证 | 严格平衡 | 弱平衡（最长 ≤ 2×最短） |

> 🎯 **AVL 适合查找多、修改少的场景**（读密集）；红黑树适合**写密集**场景（如 Java HashMap、TreeMap）。

## 6. 红黑树

### 6.1 五大性质

| 序号 | 性质 |
|------|------|
| 1 | 每个结点是红色或黑色 |
| 2 | 根结点是黑色 |
| 3 | 叶结点（NIL）是黑色 |

## 7. 堆

### 7.1 堆的性质

- **完全二叉树**结构
- **堆序性**：大根堆中父 ≥ 子；小根堆中父 ≤ 子

### 7.2 数组存储

```java
int leftChild = 2 * i + 1;   // 左孩子
int rightChild = 2 * i + 2;  // 右孩子
int parent = (i - 1) / 2;    // 父结点
```

### 7.3 上滤（插入）

```java
public void offer(int val) {
    if (size == data.length) resize();
    data[size] = val;
    siftUp(size);
    size++;
}

private void siftUp(int i) {
    while (i > 0 && data[i] > data[(i - 1) / 2]) { // 大根堆
        swap(i, (i - 1) / 2);
        i = (i - 1) / 2;
    }
}
```

**时间复杂度**：O(log n)

### 7.4 下滤（删除堆顶）

```java
public int poll() {
    if (isEmpty()) throw new NoSuchElementException();
    int max = data[0];
    data[0] = data[--size];
    siftDown(0);
    return max;
}

private void siftDown(int i) {
    while (2 * i + 1 < size) { // 有左孩子
        int larger = 2 * i + 1; // 左孩子
        if (larger + 1 < size && data[larger + 1] > data[larger]) {
            larger = larger + 1; // 右孩子更大
        }
        if (data[i] >= data[larger]) break;
        swap(i, larger);
        i = larger;
    }
}
```

**时间复杂度**：O(log n)

### 7.5 建堆（自底向上）

```java
public void buildHeap(int[] arr) {
    data = arr;
    size = arr.length;
    // 从最后一个非叶结点开始下滤
    for (int i = size / 2 - 1; i >= 0; i--) {
        siftDown(i);
    }
}
```

**时间复杂度**：O(n)（均摊分析，不是 n log n）

### 7.6 堆排序

```java
public void heapSort(int[] arr) {
    // 1. 建堆
    int n = arr.length;
    for (int i = n / 2 - 1; i >= 0; i--) siftDown(arr, n, i);
    // 2. 依次取出堆顶
    for (int i = n - 1; i > 0; i--) {
        swap(arr, 0, i);
        siftDown(arr, i, 0);
    }
}
```

**时间复杂度**：O(n log n)，**空间复杂度**：O(1)

## 8. 哈夫曼树

### 8.1 基本概念

**WPL（带权路径长度）** = Σ(权值 × 路径长度)。哈夫曼树是 WPL 最小的二叉树（最优二叉树）。

### 8.2 构造算法（贪心）

```java
class HuffmanNode {
    int weight;
    HuffmanNode left, right;
    HuffmanNode(int weight) { this.weight = weight; }
}

public HuffmanNode buildHuffmanTree(int[] weights) {
    PriorityQueue<HuffmanNode> pq = new PriorityQueue<>(
        (a, b) -> a.weight - b.weight);
    for (int w : weights) pq.offer(new HuffmanNode(w));

    while (pq.size() > 1) {
        HuffmanNode left = pq.poll();
        HuffmanNode right = pq.poll();
        HuffmanNode parent = new HuffmanNode(left.weight + right.weight);
        parent.left = left;
        parent.right = right;
        pq.offer(parent);
    }
    return pq.poll();
}
```

### 8.3 哈夫曼编码

- 左分支标记 **0**，右分支标记 **1**
- 从根到叶的路径即该字符的编码
- 高频字符短编码，低频字符长编码
- 是**前缀码**（任何一个字符的编码不是其他编码的前缀）

## 10. 学习建议

1. 树的所有操作基本是**递归**，把递归三要素（终止条件、递归体、返回值）刻在脑子里
2. **AVL 四种旋转**画 10 遍，直到能盲写
3. 优先队列/堆是 TopK、Dijkstra、合并 K 个链表等高频题的核心数据结构
4. 二叉树遍历是基础中的基础——**前中后序递归 + 非递归 + 层序**必须能手写

> 🎯 树的本质是递归结构——掌握了递归就掌握了树，掌握了树就掌握了大部分高级数据结构的基础。
