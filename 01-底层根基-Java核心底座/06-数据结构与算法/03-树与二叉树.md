# 树与二叉树

## 📌 课程定位
树是计算机科学中最重要的非线性结构——文件系统、数据库索引、编译器AST、决策树、路由算法……面试必考递归思维的核心载体。

## 🎯 核心章节

### 1. 树的基本概念
- **树的定义**：递归定义——空集 or 根结点+若干不相交的子树
- **基本术语**：结点深度（从根向下）、高度（从叶向上）、度（孩子数）、路径长度
- **树的性质**：n个结点的树有n-1条边

### 2. 二叉树的存储与遍历（⭐ 三大遍历必须肌肉记忆）
- **存储结构**：顺序存储（完全二叉树适用）、链式存储（left + data + right）
- **递归遍历**：
  - 前序遍历：根→左→右（序列化、复制树）
  - 中序遍历：左→根→右（BST排序输出）
  - 后序遍历：左→右→根（删除树、计算目录大小）
- **非递归遍历**：用栈模拟递归——前序(先压右再压左)、中序(沿左链压栈)
- **层序遍历**：用队列，逐层访问——BFS的思想

### 3. 二叉树构造
- **前序+中序 → 唯一二叉树**：前序确定根，中序分左右
- **后序+中序 → 唯一二叉树**
- **仅前序+后序 → 不能唯一确定**（反例：单分支树）

### 4. 二叉搜索树（BST, ⭐ 重点）
- **性质**：左子树 < 根 < 右子树（中序遍历即得排序序列）
- **查找**：二分思想，O(h)，最好O(log n)，退化斜树O(n)
- **插入**：查找失败位置即插入位置
- **删除的三种情况**：
  1. 叶结点→直接删
  2. 单孩子→孩子替代
  3. 两个孩子→用直接后继（右子树最左）或直接前驱（左子树最右）替换

### 5. 平衡二叉树（AVL）
- **平衡因子** = 左子树高 - 右子树高，|BF| ≤ 1
- **四种旋转（⭐ 必会手画）**：
  - LL（右单旋）：左子树比右子树高2且左子树的左子树更高
  - RR（左单旋）：对称情况
  - LR（先左后右）：左子树的右子树插入导致
  - RL（先右后左）：右子树的左子树插入导致
- **红黑树（了解）**：弱平衡，插入删除比AVL快，HashMap底层

### 6. 堆
- **大根堆/小根堆**：完全二叉树+堆序性（父≥子 or 父≤子）
- **堆的数组存储**：i的左孩子2i+1，右孩子2i+2，父(i-1)/2
- **上滤（插入）**：新元素放末尾，沿路径向上比较交换，O(log n)
- **下滤（删除堆顶）**：末尾元素放堆顶，沿路径向下比较交换，O(log n)
- **建堆**：自底向上（从最后一个非叶结点开始下滤），O(n)
- **堆排序**：建堆→反复交换堆顶与最后一个元素+下滤，O(n log n)

### 7. 哈夫曼树
- **WPL（带权路径长度）**：∑(权值×路径长度)，最优二叉树使WPL最小
- **构造**：每次取两个最小权值合并，重复n-1次（贪心）
- **哈夫曼编码**：左分支0、右分支1，高频字符短编码，前缀码

## ✅ 学习建议
- 树的所有操作基本是递归，把递归三要素（终止条件、递归体、返回值）刻在脑子里
- AVL四种旋转画10遍，直到能盲写
- 优先队列/堆是TopK、Dijkstra、合并K个链表等高频题的核心数据结构
