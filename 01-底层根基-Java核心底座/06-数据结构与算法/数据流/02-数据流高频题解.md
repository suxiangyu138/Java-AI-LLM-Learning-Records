## 1. 703. 数据流中的第 K 大元素

### 1.1 题目与思路

```
流式数据，每次 add 后返回第 K 大
定长小顶堆：堆顶 = 第 K 大（堆内保留前 K 大）
⚠️ 超过 K 弹最小（堆顶）→ 堆内永远是前 K 大
```

### 1.2 完整代码

```java
/**
 * LeetCode 703. 数据流中的第 K 大元素
 */
class KthLargest {
    private final int k;
    private final PriorityQueue<Integer> heap = new PriorityQueue<>();  // 小顶堆

    public KthLargest(int k, int[] nums) {
        this.k = k;
        for (int x : nums) add(x);          // ⚠️ 复用 add 逻辑建堆
    }

    public int add(int val) {
        heap.offer(val);
        if (heap.size() > k) heap.poll();   // ⚠️ 超过 K 弹最小（堆顶）
        return heap.peek();                 // 堆顶 = 第 K 大
    }
}
// 推演 k=3, [4,5,8,2]：
//   add(4)：[4]；add(5)：[4,5]；add(8)：[4,5,8]
//   add(2)：[2,4,5,8] → 弹 2 → [4,5,8] → 返回 4 ✓
//   add(10)：[4,5,8,10] → 弹 4 → [5,8,10] → 返回 5 ✓
// ⚠️ 复杂度：O(log k)/次（堆大小恒 k）
// ⚠️ 面试必答："703 = 定长小顶堆——
//   堆内永远存'前 K 大'，堆顶即第 K 大；
//   超过容量弹最小。数据流 TopK 的标准答案。"
```

## 2. 295. 数据流的中位数

### 2.1 题目与思路

```
流式 addNum + findMedian
双堆：大顶堆（左半）+ 小顶堆（右半）
⚠️ 01 模块 2 节双堆原理完整推导
```

### 2.2 完整代码

```java
/**
 * LeetCode 295. 数据流的中位数（双堆）
 */
class MedianFinder {
    // ⚠️ 大顶堆（左半）：堆顶 = 左半最大
    private final PriorityQueue<Integer> left = new PriorityQueue<>((a, b) -> b - a);
    // ⚠️ 小顶堆（右半）：堆顶 = 右半最小
    private final PriorityQueue<Integer> right = new PriorityQueue<>();

    public void addNum(int num) {
        // ① 先入左半
        left.offer(num);
        // ② 平衡值序：左顶 ≤ 右顶
        if (!right.isEmpty() && left.peek() > right.peek()) {
            right.offer(left.poll());
        }
        // ③ 平衡大小：左 = 右 或 左 = 右+1
        if (left.size() > right.size() + 1) right.offer(left.poll());
        if (right.size() > left.size()) left.offer(right.poll());
    }

    public double findMedian() {
        if (left.size() == right.size())
            return (left.peek() + right.peek()) / 2.0;   // 偶数平均
        return left.peek();                              // 奇数左顶
    }
}
// 推演 addNum(1) addNum(2)：
//   1：左[1]；2：入左 [1,2] → 左顶 2 > 右空？no
//   大小：左 2 > 右 0+1 → 右[2] → 左[1] 右[2] → 中位 1.5 ✓
// 推演 addNum(3)：
//   3 入左 [1,3] → 左顶 3 > 右顶 2 → 右[2,3] → 左[1]
//   大小：左 1 < 右 2 → 左[1,3]? 不——poll 右顶 2 → 左[1,2]
//   最终左[1,2] 右[3] → 中位 2 ✓
// ⚠️ 复杂度：add O(log n)、find O(1)
// ⚠️ 面试必答："295 = 双堆三步——入左、
//   值序平衡（左顶≤右顶）、大小平衡（差≤1）。"
```

## 3. 480. 滑动窗口中位数（hard）

### 3.1 题目与思路

```
每个滑动窗口（大小 k）的中位数
双堆 + 延迟删除（窗口滑出元素）
⚠️ 01 模块 3/4 节原理；此题给完整实现
```

### 3.2 完整代码

```java
/**
 * LeetCode 480. 滑动窗口中位数（双堆 + 延迟删除）
 */
public double[] medianSlidingWindow(int[] nums, int k) {
    // ⚠️ 双堆：用 long 防溢出（中位数加法）
    PriorityQueue<Long> left = new PriorityQueue<>((a, b) -> Long.compare(b, a));
    PriorityQueue<Long> right = new PriorityQueue<>();
    Map<Long, Integer> pending = new HashMap<>();       // 延迟删除表
    int leftSize = 0, rightSize = 0;

    double[] result = new double[nums.length - k + 1];

    for (int i = 0; i < nums.length; i++) {
        // ① 滑入
        long x = nums[i];
        if (left.isEmpty() || x <= left.peek()) {
            left.offer(x); leftSize++;
        } else {
            right.offer(x); rightSize++;
        }

        // ② 滑出（延迟删除）
        if (i >= k) {
            long out = nums[i - k];
            pending.merge(out, 1, Integer::sum);        // 记账
            if (out <= left.peek()) leftSize--;
            else rightSize--;
        }

        // ③ 清理脏堆顶 + 平衡
        prune(left, pending);
        prune(right, pending);
        while (leftSize > rightSize + 1) {
            right.offer(left.poll());
            leftSize--; rightSize++;
            prune(left, pending);
        }
        while (leftSize < rightSize) {
            left.offer(right.poll());
            leftSize++; rightSize--;
            prune(right, pending);
        }

        // ④ 取中位数
        if (i >= k - 1) {
            result[i - k + 1] = (k % 2 == 1)
                    ? left.peek()
                    : (left.peek() + right.peek()) / 2.0;
        }
    }
    return result;
}

private void prune(PriorityQueue<Long> heap, Map<Long, Integer> pending) {
    while (!heap.isEmpty() && pending.getOrDefault(heap.peek(), 0) > 0) {
        long x = heap.poll();
        pending.merge(x, -1, Integer::sum);             // ⚠️ 清脏
    }
}
// 推演 nums=[1,3,-1,-3,5,3,6,7], k=3：
//   窗口 [1,3,-1]：排序 [-1,1,3] → 中位 1
//   窗口 [3,-1,-3]：排序 [-3,-1,3] → -1
//   窗口 [-1,-3,5]：→ -1；[-3,5,3] → 3
//   结果 [1,-1,-1,3,5,6] ✓
// ⚠️ 复杂度：O(n log k)
// ⚠️ 面试必答："480 = 295 双堆 + 延迟删除——
//   滑出元素记账不删堆，取顶时清脏；
//   逻辑大小（leftSize/rightSize）与堆实际大小分离。"
```

## 4. 346. 滑动窗口平均值

### 4.1 题目与思路

```
固定窗口大小的流式平均值
队列 + 累加和（O(1) 更新）
⚠️ 窗口不满时按实际元素数平均
```

### 4.2 完整代码

```java
/**
 * LeetCode 346. 滑动窗口平均值
 */
class MovingAverage {
    private final int size;
    private final Deque<Integer> queue = new ArrayDeque<>();
    private int sum = 0;                     // ⚠️ 窗口内和（O(1) 维护）

    public MovingAverage(int size) { this.size = size; }

    public double next(int val) {
        queue.offer(val);
        sum += val;
        if (queue.size() > size) {           // ⚠️ 超窗口 → 滑出
            sum -= queue.poll();
        }
        return (double) sum / queue.size();  // 按实际大小平均
    }
}
// 推演 size=3：next(1)→1；next(10)→5.5；next(3)→4.67；next(5)→6
//   （窗口 [10,3,5] → (10+3+5)/3 = 6）✓
// ⚠️ 复杂度：O(1)/次
// ⚠️ 面试必答："346 = 队列 + 滚动和——
//   窗口进出各 O(1)，平均值 O(1) 查询。
//   与 933（计数）同构，只是维护值变成和。"
```

## 5. 933. 最近的请求次数

### 5.1 题目与思路

```
每个 ping(t) 返回 [t-3000, t] 内的 ping 次数
队列（FIFO）：入队 + 淘汰超时
⚠️ 时间单调递增 → 队列天然有序 → 队首判断超时
```

### 5.2 完整代码

```java
/**
 * LeetCode 933. 最近的请求次数
 */
class RecentCounter {
    private final Deque<Integer> queue = new ArrayDeque<>();

    public int ping(int t) {
        queue.offer(t);                      // ① 新请求入队
        // ② 淘汰超时（t-3000 之前的）
        while (!queue.isEmpty() && queue.peek() < t - 3000) {
            queue.poll();                    // ⚠️ 队首最老 → 超时淘汰
        }
        return queue.size();                 // 剩余 = 窗口内请求数
    }
}
// 推演 ping(1)→1；ping(100)→2；ping(3001)→3
//   ping(3002)：淘汰 < 2 的（1 和 100）→ 2 ✓
// ⚠️ 复杂度：均摊 O(1)（每个请求进出一次）
// ⚠️ 面试必答："933 = 单调队列——
//   时间单调递增 → 队首必最老，
//   超时即弹出。均摊 O(1)。"
```

## 6. 数据流方法论总结

### 6.1 解题框架

```
① 在线判定：数据流 → 在线结构（不可重排）
② 需求分析：要什么？
   第 K → 定长堆
   中位数 → 双堆
   窗口均值/计数 → 队列
   窗口最值 → 单调队列
③ 删除问题：窗口滑出 → 延迟删除
④ 复杂度：每次 O(log n) 或均摊 O(1)

⚠️ 识别信号：
  "add + query 交替" → 数据流
  "窗口滑动" → 队列/双堆 + 删除
```

### 6.2 题型模板速查

| 题型 | 结构 | 代表题 |
|------|------|--------|
| 流式 TopK | 定长小顶堆 | 703 |
| 流式中位数 | 双堆 | 295 |
| 窗口中位数 | 双堆 + 延迟删除 | 480 |
| 窗口均值 | 队列 + 滚动和 | 346 |
| 窗口计数 | 单调队列淘汰 | 933 |
| 窗口最值 | 单调队列 | 239 |

### 6.3 自测清单

```
□ 在线/离线判定？
□ 双堆三步（入左/值序/大小）？
□ 延迟删除三件套（记账/清脏/逻辑大小）？
□ 窗口滑出及时 remove？
□ 中位数 long 防溢出？
□ 队列淘汰条件（超时/超尺寸）？
□ 复杂度表述（每次 vs 均摊）？
```
