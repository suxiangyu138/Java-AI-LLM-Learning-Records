## 1. 核心概念

### 1.1 什么是枚举

> 枚举：**穷举所有可能**，逐一验证。是算法的"保底方案"——任何问题都能枚举，只是复杂度可能不可接受。

```
枚举的价值：
  ① 面试先说暴力（展示思路正确）
  ② 小数据规模直接可行
  ③ 枚举+优化 = 很多高级算法的起点

三大枚举形态：
  组合枚举（选哪些）：回溯/位掩码
  排列枚举（什么顺序）：回溯/nextPermutation
  参数枚举（什么值）：循环遍历候选值
```

### 1.2 枚举的三个场景

```
① 暴力打底（面试第一步）
   任何题都能枚举 → 先说暴力证明理解
   → 再优化（哈希/双指针/DP）

② 小规模直接解
   n ≤ 20 → 2ⁿ 子集枚举可行
   n ≤ 10 → n! 排列枚举可行

③ 参数枚举（答案在值域中）
   枚举候选答案 → 验证
   → 可配合二分（单调时）

⚠️ 枚举的本质：把"找答案"变成"试答案"
```

### 1.3 枚举 vs 回溯 vs 模拟

```
枚举：穷举候选（思路层面）
回溯：枚举 + 剪枝 + 撤销（结构化实现）
模拟：按规则逐步执行（过程层面）

关系：回溯是"枚举所有方案"的代码实现
    模拟是"跟着题干走"（可能不需要枚举）
```

## 2. 完整代码模板

### 2.1 暴力枚举 → 优化演示（两数之和）

```java
// ═══════════ ① 暴力 O(n²) ═══════════════════════
public int[] twoSum_Brute(int[] nums, int target) {
    for (int i = 0; i < nums.length; i++) {
        for (int j = i + 1; j < nums.length; j++) {
            if (nums[i] + nums[j] == target) {
                return new int[]{i, j};   // 枚举所有数对
            }
        }
    }
    return new int[0];
}

// ═══════════ ② 哈希优化 O(n) ═════════════════════
// 内层循环在做"查找补数" → 哈希表 O(1) 替代
public int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> map = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        if (map.containsKey(target - nums[i])) {
            return new int[]{map.get(target - nums[i]), i};
        }
        map.put(nums[i], i);               // ⚠️ 先查后插
    }
    return new int[0];
}
// 面试表达："暴力 O(n²) 双重循环枚举，
// 内层是查找 → 哈希表降到 O(n)"
```

### 2.2 位掩码枚举子集

```java
/**
 * 78. 子集（位枚举版）
 * n 个元素 → 2ⁿ 个子集 → 掩码 0..2ⁿ-1
 */
public List<List<Integer>> subsets(int[] nums) {
    List<List<Integer>> result = new ArrayList<>();
    int n = nums.length;

    for (int mask = 0; mask < (1 << n); mask++) {
        List<Integer> subset = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            if ((mask & (1 << i)) != 0) {   // 第 i 位为 1 → 选
                subset.add(nums[i]);
            }
        }
        result.add(subset);
    }
    return result;
}
// O(n × 2ⁿ)：2ⁿ 个掩码 × 每个 O(n) 构造
// ⚠️ n ≤ 20 可行（2²⁰ ≈ 10⁶）
```

### 2.3 参数枚举模板（枚举候选答案）

```java
/**
 * 参数枚举：答案在值域中逐个尝试
 * 例：69. 平方根（暴力版）
 */
public int mySqrt_Brute(int x) {
    long ans = 0;
    for (long i = 1; i * i <= x; i++) {    // 枚举候选
        ans = i;
    }
    return (int) ans;
}
// O(√x) 太慢 → 二分优化 O(log x)

/**
 * 通用模式：
 * for (候选 : 值域) {
 *     if (验证(候选)) { 记录; }
 * }
 * ⚠️ 候选值单调 → 二分优化（答案二分）
 */
```

## 3. 枚举的复杂度评估

### 3.1 数据规模 → 算法选择

```
n ≤ 10 → n! 排列枚举可行（362 万）
n ≤ 20 → 2ⁿ 子集枚举可行（10⁶）
n ≤ 500 → O(n²) 可行（25 万）
n ≤ 10⁵ → O(n log n) 可行
n ≤ 10⁶ → O(n) 可行

⚠️ 面试第一步："n 最大多少？"
  决定枚举是否可行 / 需要什么优化
```

### 3.2 枚举量的估算

```
组合枚举：C(n,k)（选 k 个）
子集枚举：2ⁿ
排列枚举：n!
笛卡尔积：a×b×c（多维）

⚠️ 常见陷阱：
  三数之和暴力 C(n,3) = n(n-1)(n-2)/6 ≈ n³/6
  n=10⁵ → 1.6×10¹⁴ → 不可行！
  → 必须优化（排序+双指针 O(n²)）
```

### 3.3 什么时候暴力就是正解

```
① n 很小（≤ 20）：2ⁿ 可行
② 需要"所有方案"：枚举/回溯是唯一解
③ 其他算法都不适用时（兜底）

⚠️ 面试策略：
  先给暴力（O(n²)/O(2ⁿ)）证明理解
  再给优化方案（展示能力）
  面试官常问："你的解法从暴力怎么演进？"
```

## 4. 枚举优化三板斧

### 4.1 三板斧总览

```
① 剪枝：排除不可能的分支（回溯剪枝）
   例：组合总和排序后 sum > target → break

② 降维：哈希替代内层循环
   例：两数之和 O(n²) → O(n)

③ 单调性：排序后双指针/二分
   例：三数之和 O(n³) → O(n²)
       参数枚举 O(值域) → O(log 值域)

口诀："内层查什么，就用什么结构加速"
```

### 4.2 优化示例：三数之和

```java
/**
 * 15. 三数之和：O(n³) → O(n²)
 * ① 排序（双指针前提）
 * ② 固定一个数
 * ③ 双指针找两数和（单调性：有序数组）
 */
public List<List<Integer>> threeSum(int[] nums) {
    Arrays.sort(nums);                       // ① 排序
    List<List<Integer>> result = new ArrayList<>();

    for (int i = 0; i < nums.length - 2; i++) {
        if (i > 0 && nums[i] == nums[i - 1]) continue;  // 去重
        int lo = i + 1, hi = nums.length - 1;
        int target = -nums[i];

        while (lo < hi) {                    // ② 双指针（有序）
            int sum = nums[lo] + nums[hi];
            if (sum == target) {
                result.add(List.of(nums[i], nums[lo], nums[hi]));
                while (lo < hi && nums[lo] == nums[lo + 1]) lo++;
                while (lo < hi && nums[hi] == nums[hi - 1]) hi--;
                lo++; hi--;
            } else if (sum < target) lo++;
            else hi--;
        }
    }
    return result;
}
// 暴力 C(n,3) → 优化后 O(n²)
// ⚠️ 优化来源：排序让"两数查找"可用双指针（单调）
```

### 4.3 枚举优化的识别

```
双重循环 + 内层"查找" → 哈希/二分
双重循环 + 数组有序 → 双指针
枚举候选值 + 单调验证 → 答案二分
组合枚举 + 大量剪枝 → 回溯（剪枝）

⚠️ 面试表达：
"暴力是 O(n²) 双重循环枚举所有数对。
 内层循环在做'补数查找' → 用哈希表 O(1)
 替代 → 总 O(n)。这就是枚举 + 数据结构优化。"
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"暴力是 O(n²) 双重循环枚举所有数对。
 内层循环在做'补数查找' → 用哈希表 O(1)
 替代 → 总 O(n)。
 这就是枚举 + 数据结构优化——
 先枚举（保证正确），再优化（保证效率）。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 为什么要先讲暴力？ | 证明理解问题（思路正确）+ 展示优化意识 |
| 2 | 什么时候暴力就是正解？ | n ≤ 20（2ⁿ）；需要所有方案；无更优解 |
| 3 | 枚举优化的通用路径？ | 内层查找→哈希；有序→双指针；单调→二分 |
| 4 | 枚举 vs 回溯？ | 回溯 = 枚举 + 剪枝 + 撤销（结构化实现） |
| 5 | 怎么估算枚举量？ | C(n,k)/2ⁿ/n! + 数据规模判断 |
| 6 | 剪枝写在哪？ | 选择前（省递归调用）；排序后 break |
| 7 | 位掩码枚举限制？ | n ≤ 20（2ⁿ 状态可行） |
| 8 | 与数学题区别？ | 枚举试答案；数学找规律（O(1)） |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 没估规模就枚举 | 超时 | 先算 n 上限 |
| 内层重复计算 | 浪费 | 提取/缓存 |
| 枚举忘剪枝 | 白跑分支 | 选择前剪枝 |
| 位枚举越界 | 溢出 | 1L << n（大 n） |
| 枚举当唯一解 | 面试分低 | 主动优化 |

> 🎯 **核心要点**：枚举 = **穷举 + 优化**的组合拳。识别信号："暴力解法、所有可能、候选值"。面试先讲暴力展示思路，再用"内层查找→哈希、有序→双指针、单调→二分"三板斧优化——这是最标准的面试表达路径。
