## 1. 1. 两数之和（哈希枚举）

### 1.1 题目与思路

```
两数之和 = target（返回下标）
三层递进：
  暴力 O(n²)（两两枚举）
  哈希 O(n)（边遍历边查补数）⭐
⚠️ 哈希版 = "枚举 + 查历史"模板（01 模块 3 节）
```

### 1.2 完整代码

```java
/**
 * LeetCode 1. 两数之和
 */
public int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> seen = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        int need = target - nums[i];
        if (seen.containsKey(need)) {
            return new int[]{seen.get(need), i};   // ⚠️ 补数在历史中
        }
        seen.put(nums[i], i);                      // 先查后插
    }
    return new int[]{-1, -1};
}
// 推演 [2,7,11,15], target=9：
//   i=0：need=7 无 → {2:0}
//   i=1：need=7 有 → [0,1] ✓
// ⚠️ 复杂度：O(n)（两两枚举 O(n²) → 哈希查历史）
// ⚠️ 面试表达："两数之和是'枚举+哈希'的原型——
//   内层枚举被 O(1) 查表替代，复杂度降一维。
//   这题的变体（15/18/454）都是同一思想。"
```

## 2. 15. 三数之和（排序 + 双指针）

### 2.1 题目与思路

```
三数和为 0 的全部组合（不重复）
排序 + 固定一个 + 双指针扫剩余（O(n²)）
⚠️ 去重是关键（排序后跳过相同值）
```

### 2.2 完整代码

```java
/**
 * LeetCode 15. 三数之和
 */
public List<List<Integer>> threeSum(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    Arrays.sort(nums);                          // ⚠️ 排序：去重 + 双指针前提
    int n = nums.length;

    for (int i = 0; i < n - 2; i++) {
        if (nums[i] > 0) break;                 // ⚠️ 剪枝：首数 > 0 后续更大
        if (i > 0 && nums[i] == nums[i - 1]) continue;    // 外层去重

        int lo = i + 1, hi = n - 1;
        while (lo < hi) {
            int sum = nums[i] + nums[lo] + nums[hi];
            if (sum == 0) {
                res.add(List.of(nums[i], nums[lo], nums[hi]));
                while (lo < hi && nums[lo] == nums[lo + 1]) lo++;   // 去重
                while (lo < hi && nums[hi] == nums[hi - 1]) hi--;
                lo++; hi--;
            } else if (sum < 0) lo++;           // 太小 → 左移
            else hi--;                          // 太大 → 右移
        }
    }
    return res;
}
// 推演 [-1,0,1,2,-1,-4] → 排序 [-4,-1,-1,0,1,2]
//   i=1(-1)：lo=2(-1), hi=5(2) → -1+(-1)+2=0 ✓ → 记录 [-1,-1,2]
//            lo 去重后 3(0), hi=4(1) → -1+0+1=0 ✓ → [-1,0,1]
//   i=2(-1) 与 i=1 相同 → 跳过 ✓ → 结果 [[-1,-1,2],[-1,0,1]]
// ⚠️ 复杂度：O(n²)（排序 O(n log n) + 双指针 O(n²)）
// ⚠️ 面试表达："三数之和 = 排序 + 固定 + 双指针——
//   双指针把 O(n²) 的剩余枚举降为 O(n)，
//   去重三层（外层/内层左右）缺一不可。"
```

## 3. 18. 四数之和（剪枝双指针）

### 3.1 题目与思路

```
四数和 = target（全部组合）
固定两个 + 双指针（O(n³)）+ 两层剪枝
⚠️ 目标可为负 → 剪枝用 long 防溢出
```

### 3.2 完整代码

```java
/**
 * LeetCode 18. 四数之和
 */
public List<List<Integer>> fourSum(int[] nums, int target) {
    List<List<Integer>> res = new ArrayList<>();
    Arrays.sort(nums);
    int n = nums.length;

    for (int i = 0; i < n - 3; i++) {
        if (i > 0 && nums[i] == nums[i - 1]) continue;   // 外层去重
        // ⚠️ 剪枝 1：最小四数已超 → 全部超
        if ((long) nums[i] + nums[i+1] + nums[i+2] + nums[i+3] > target) break;
        // ⚠️ 剪枝 2：最大四数不够 → 跳过 i
        if ((long) nums[i] + nums[n-1] + nums[n-2] + nums[n-3] < target) continue;

        for (int j = i + 1; j < n - 2; j++) {
            if (j > i + 1 && nums[j] == nums[j - 1]) continue;   // 第二层去重
            // 同款两层剪枝（j 固定时）
            if ((long) nums[i] + nums[j] + nums[j+1] + nums[j+2] > target) break;
            if ((long) nums[i] + nums[j] + nums[n-1] + nums[n-2] < target) continue;

            int lo = j + 1, hi = n - 1;
            while (lo < hi) {
                long sum = (long) nums[i] + nums[j] + nums[lo] + nums[hi];
                if (sum == target) {
                    res.add(List.of(nums[i], nums[j], nums[lo], nums[hi]));
                    while (lo < hi && nums[lo] == nums[lo + 1]) lo++;
                    while (lo < hi && nums[hi] == nums[hi - 1]) hi--;
                    lo++; hi--;
                } else if (sum < target) lo++;
                else hi--;
            }
        }
    }
    return res;
}
// 推演 [1,0,-1,0,-2,2], target=0 → 排序 [-2,-1,0,0,1,2]
//   i=0(-2), j=1(-1)：lo=2(0), hi=5(2) → -2-1+0+2=-1<0 → lo...
//   逐步找到 [-2,-1,1,2], [-2,0,0,2], [-1,0,0,1] ✓
// ⚠️ 复杂度：O(n³)（两层固定 + 双指针）
// ⚠️ 面试表达："四数之和 = 三数之和 + 一层循环；
//   两层剪枝（最小超界/最大不够）在有序数组上
//   是正确的快速跳过——能砍掉大量无效枚举。"
```

## 4. 78/90. 子集 I & II（位掩码）

### 4.1 题目与思路

```
78：全部子集（位掩码枚举 2^n）
90：含重复值的子集（位掩码 + 去重）
⚠️ 90 的去重：排序 + 同值元素"选要连续选"
```

### 4.2 双题完整代码

```java
/** 78. 子集（位掩码） */
public List<List<Integer>> subsets(int[] nums) {
    int n = nums.length;
    List<List<Integer>> res = new ArrayList<>();
    for (int mask = 0; mask < (1 << n); mask++) {
        List<Integer> sub = new ArrayList<>();
        for (int i = 0; i < n; i++)
            if ((mask & (1 << i)) != 0) sub.add(nums[i]);   // ⚠️ 第 i 位
        res.add(sub);
    }
    return res;
}
// 推演 [1,2]：mask 00→[]、01→[1]、10→[2]、11→[1,2] ✓
// 复杂度：O(2^n × n)

/** 90. 子集 II（去重：排序 + 连续选取） */
public List<List<Integer>> subsetsWithDup(int[] nums) {
    Arrays.sort(nums);                          // ⚠️ 去重前提
    List<List<Integer>> res = new ArrayList<>();
    backtrack(nums, 0, new ArrayList<>(), res);
    return res;
}

private void backtrack(int[] nums, int start,
                       List<Integer> path, List<List<Integer>> res) {
    res.add(new ArrayList<>(path));             // ⚠️ 每个节点都是子集
    for (int i = start; i < nums.length; i++) {
        if (i > start && nums[i] == nums[i - 1]) continue;   // ⚠️ 同层去重
        path.add(nums[i]);
        backtrack(nums, i + 1, path, res);      // start = i+1（组合不回头）
        path.remove(path.size() - 1);
    }
}
// 推演 [1,2,2]：
//   [] → [1] → [1,2] → [1,2,2]；[2] → [2,2]（第二个 2 跳过同层）✓
// ⚠️ 面试表达："子集 II 的去重 = 排序 + 同层跳过
//   （i > start 而非 i > 0）——相同值在同一层的
//   展开等价，只保留第一个。"
```

## 5. 69. x 的平方根（参数枚举 → 二分）

### 5.1 题目与思路

```
√x 向下取整（不调库）
参数枚举：0..x 逐个试 → O(√x)（x 巨大时不可行）
二分答案：判定 mid² ≤ x 单调 → O(log x) ⭐
⚠️ 二分 = 参数枚举的单调加速（01 模块 4 节）
```

### 5.2 完整代码

```java
/**
 * LeetCode 69. x 的平方根（二分答案）
 * ⚠️ 找最大的 mid 使 mid² ≤ x
 */
public int mySqrt(int x) {
    int lo = 0, hi = x;
    while (lo < hi) {
        int mid = lo + (hi - lo + 1) / 2;       // ⚠️ 上取整（lo=mid 防死循环）
        if ((long) mid * mid <= x) {            // ⚠️ long 防溢出
            lo = mid;                           // 可行 → 尝试更大
        } else {
            hi = mid - 1;                       // 过大 → 收紧
        }
    }
    return lo;
}
// 推演 x=8：
//   mid=4：16>8 → hi=3；mid=2：4≤8 → lo=2；mid=3：9>8 → hi=2 → 返回 2 ✓
// ⚠️ 复杂度：O(log x)（对比枚举 O(√x)）
// ⚠️ 面试表达："平方根是'参数枚举'的二分答案样板——
//   答案值域 [0, x]、判定 mid² ≤ x 单调、
//   二分 O(log x)。上取整 + lo=mid 配套防死循环。"
```

## 6. 292. Nim 游戏（枚举找规律）

### 6.1 题目与思路

```
每次拿 1-3 块石头，拿到最后一块的人赢（先手）
找规律：小规模枚举 → 归纳
  1,2,3 块：先手必赢
  4 块：先手必输（无论拿 1-3，对手拿完）
  5,6,7：先手必赢（先拿到 4 的余量）
  8：必输...
→ 规律：n % 4 == 0 必输，否则必赢
⚠️ 找规律流程（01 模块方法论）：枚举小规模 → 归纳 → 证明
```

### 6.2 完整代码

```java
/**
 * LeetCode 292. Nim 游戏
 * ⚠️ 规律：4 的倍数必输（对手总能把局面保持为 4 的倍数）
 */
public boolean canWinNim(int n) {
    return n % 4 != 0;                  // ⚠️ 一行结论
}
// 证明（归纳）：
//   4k：先手拿 1-3 → 剩 4k-1..4k-3 → 后手补到 4(k-1)
//   → 后手永远把 4 的倍数留给先手 → 最后 4 块时先手拿不完
//   → 先手必输 ✓
// 非 4 倍数：先手先拿 n%4 块 → 把 4 的倍数交给后手 → 必赢 ✓
// ⚠️ 面试表达："Nim 用归纳证明：4 的倍数是'必败态'
//   （拿 1-3 后对手总能补回 4 的倍数）。
//   找规律题流程：小规模枚举 → 猜规律 → 归纳证明。"
// ⚠️ 变体：一次拿 1-m 块 → 必败态 = (m+1) 的倍数（同构）
```

## 7. 枚举方法论总结

### 7.1 解题框架

```
① 评估空间：枚举对象 × 判定代价 → 可行？
② 选优化：
   需要去重 → 排序 + 跳过相同
   需要加速 → 哈希查历史 / 双指针
   需要剪枝 → 有序边界快速跳过
   单调判定 → 二分替代枚举
③ 选形态：组合（start）/ 子集（位掩码）/ 参数（二分）
④ 验证：边界 + 小规模手推 + 复杂度论述

⚠️ 识别信号：
  "所有组合/子集/方案" → 枚举
  "第 K/最值" → 二分答案（参数枚举加速）
```

### 7.2 题型模板速查

| 题型 | 形态 | 优化 | 代表题 |
|------|------|------|--------|
| 两数配对 | 组合枚举 | 哈希 | 1、454 |
| 三数/四数 | 组合枚举 | 排序+双指针+剪枝 | 15、18 |
| 子集 | 位掩码/回溯 | 去重 | 78、90 |
| 参数答案 | 值域枚举 | 二分 | 69、875 |
| 找规律 | 小规模枚举 | 归纳 | 292 |

### 7.3 自测清单

```
□ 枚举空间评估（先算再写）？
□ 去重三层（外层/内层左右）？
□ 双指针前提（排序）？
□ 剪枝方向正确（break vs continue）？
□ 上取整 + lo=mid 防死循环？
□ long 防溢出（平方/四数和）？
□ 找规律有归纳证明？
```
