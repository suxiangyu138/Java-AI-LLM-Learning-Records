## 1. 167. 两数之和 II

### 1.1 完整实现（对撞）

```java
/**
 * LeetCode 167. 两数之和 II - 输入有序数组
 * 对撞指针：sum 与 target 比较决定移动方向
 */
public int[] twoSum(int[] numbers, int target) {
    int left = 0, right = numbers.length - 1;

    while (left < right) {
        int sum = numbers[left] + numbers[right];
        if (sum == target) {
            return new int[]{left + 1, right + 1};   // ⚠️ 1-indexed
        } else if (sum < target) {
            left++;          // 需要更大的和 → 左指针右移
        } else {
            right--;         // 需要更小的和 → 右指针左移
        }
    }
    return new int[0];
}
// 推演 [2,7,11,15], target=9：
//   sum=17>9 → right--（排除 15 的组合）
//   sum=13>9 → right--（排除 11 的组合）
//   sum=9 ✓ → [1,2]
// ⚠️ 面试必答："每步排除'以端点为界'的一批组合——
//   有序性保证移动方向与和的变化单调对应"
```

## 2. 15. 三数之和

### 2.1 完整实现（固定 + 对撞 + 去重三处）

```java
/**
 * LeetCode 15. 三数之和（Hot 100 高频）
 * 三步：排序 → 固定一个 → 双指针找两数
 * ⚠️ 去重三处（核心易错点）
 */
public List<List<Integer>> threeSum(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    Arrays.sort(nums);                       // ① 排序

    for (int i = 0; i < nums.length - 2; i++) {
        if (nums[i] > 0) break;              // 剪枝：正数后面更大
        if (i > 0 && nums[i] == nums[i - 1]) continue;   // ② 固定数去重

        int left = i + 1, right = nums.length - 1;
        int target = -nums[i];

        while (left < right) {
            int sum = nums[left] + nums[right];
            if (sum == target) {
                res.add(Arrays.asList(nums[i], nums[left], nums[right]));
                // ③ 左右去重
                while (left < right && nums[left] == nums[left + 1]) left++;
                while (left < right && nums[right] == nums[right - 1]) right--;
                left++;
                right--;
            } else if (sum < target) {
                left++;
            } else {
                right--;
            }
        }
    }
    return res;
}
// 推演 [-1,0,1,2,-1,-4] → 排序 [-4,-1,-1,0,1,2]
//   固定 -1：双指针找 1 → [-1,-1,2] 和 [-1,0,1]
//   固定 0：找 0 → 无新组合（去重）
//   结果 [[-1,-1,2],[-1,0,1]] ✓
// ⚠️ 去重三处缺一不可！
// ⚠️ 复杂度 O(n²)：排序 O(n log n) + 固定 O(n) × 双指针 O(n)
```

## 3. 11. 盛最多水的容器

### 3.1 完整实现（短板移动）

```java
/**
 * LeetCode 11. 盛最多水的容器
 * 容量 = min(左高, 右高) × 宽度
 * ⚠️ 为什么移动矮边？（短板效应论证）
 */
public int maxArea(int[] height) {
    int left = 0, right = height.length - 1;
    int maxWater = 0;

    while (left < right) {
        int width = right - left;
        int h = Math.min(height[left], height[right]);
        maxWater = Math.max(maxWater, width * h);

        // ⚠️ 移动矮的一边（核心规则）
        if (height[left] < height[right]) left++;
        else right--;
    }
    return maxWater;
}
// 推演 [1,8,6,2,5,4,8,3,7]：
//   最大 = 49（8 和 7 的容器）
//   ⚠️ 面试必答：
//   "移动高边 → 宽度变小，高度不变（还是矮边）
//    → 容量必变小；移动矮边才有希望 → 安全排除"
```

## 4. 125. 验证回文串

### 4.1 完整实现（对撞 + 跳过）

```java
/**
 * LeetCode 125. 验证回文串
 * 忽略大小写和非字母数字字符
 */
public boolean isPalindrome(String s) {
    int left = 0, right = s.length() - 1;

    while (left < right) {
        // ⚠️ 跳过非字母数字
        while (left < right && !Character.isLetterOrDigit(s.charAt(left))) {
            left++;
        }
        while (left < right && !Character.isLetterOrDigit(s.charAt(right))) {
            right--;
        }
        // 比较（忽略大小写）
        if (Character.toLowerCase(s.charAt(left))
            != Character.toLowerCase(s.charAt(right))) {
            return false;
        }
        left++;
        right--;
    }
    return true;
}
// "A man, a plan, a canal: Panama" → true ✓
// ⚠️ 变体：680 验证回文串 II（可删一个字符 → 分叉检查）
//   if (不匹配) return check(l+1,r) || check(l,r-1)
```

## 5. 42. 接雨水

### 5.1 双指针版（O(1) 空间）

```java
/**
 * LeetCode 42. 接雨水（经典 Hard）
 * 接水量 = min(左最高, 右最高) - 当前高度
 * 双指针：维护 leftMax/rightMax，矮边确定
 */
public int trap(int[] height) {
    int left = 0, right = height.length - 1;
    int leftMax = 0, rightMax = 0;
    int water = 0;

    while (left < right) {
        leftMax = Math.max(leftMax, height[left]);
        rightMax = Math.max(rightMax, height[right]);

        if (leftMax < rightMax) {
            // ⚠️ 左边能确定：右边最高 ≥ rightMax > leftMax
            water += leftMax - height[left];
            left++;
        } else {
            water += rightMax - height[right];
            right--;
        }
    }
    return water;
}
// 推演 [0,1,0,2,1,0,1,3,2,1,2,1] → 6 ✓
// ⚠️ 三解法对比：
//   暴力 O(n²)/O(1)；DP O(n)/O(n)；双指针 O(n)/O(1) ★
// ⚠️ 面试追问："为什么矮边能确定？"
//   min(左最高, 右边最高) 的"右边最高" ≥ rightMax > leftMax
//   → 取小必为 leftMax → 可确定
```

## 6. 27/283. 移除元素与移动零

### 6.1 27. 移除元素（快慢）

```java
/**
 * LeetCode 27. 移除元素
 * slow 慢写（下一个保留位置），fast 快读（扫描）
 */
public int removeElement(int[] nums, int val) {
    int slow = 0;
    for (int fast = 0; fast < nums.length; fast++) {
        if (nums[fast] != val) {
            nums[slow++] = nums[fast];   // 保留覆盖
        }
    }
    return slow;
}
// 推演 [3,2,2,3], val=3：
//   fast=1(2) → nums[0]=2, slow=1
//   fast=2(2) → nums[1]=2, slow=2 → 返回 2 ✓
```

### 6.2 283. 移动零（补零）

```java
/**
 * LeetCode 283. 移动零
 * = 27（移除 0）+ 末尾补零
 */
public void moveZeroes(int[] nums) {
    int slow = 0;
    for (int fast = 0; fast < nums.length; fast++) {
        if (nums[fast] != 0) {
            nums[slow++] = nums[fast];   // 非零前移
        }
    }
    while (slow < nums.length) {
        nums[slow++] = 0;                // ⚠️ 末尾补零
    }
}
// 推演 [0,1,0,3,12]：
//   非零前移 → [1,3,12,3,12]，slow=3
//   补零 → [1,3,12,0,0] ✓
// ⚠️ 三题对比（27/26/283）：
//   27 移除 val：保留 != val
//   26 去重：保留 != nums[slow-1]
//   283 移动零：保留 != 0 + 补零
```

## 7. 141. 环形链表

### 7.1 完整实现（Floyd 判圈）

```java
/**
 * LeetCode 141. 环形链表
 * 快慢相遇 → 有环
 * ⚠️ 相对速度 1 → 任何环长必然相遇
 */
public boolean hasCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {   // ⚠️ 判空防越界
        slow = slow.next;            // 1 步
        fast = fast.next.next;       // 2 步
        if (slow == fast) return true;   // 相遇 → 有环
    }
    return false;                    // fast 先到 null → 无环
}
// 面试追问：
//   "为什么走 2 步？" → 相对速度 1，环长 L 最多 L 轮追上
//   "142 找入口？" → 相遇后重置 slow，同速走再相遇 = 入口
```

## 8. 88. 合并两个有序数组

### 8.1 完整实现（反向指针）

```java
/**
 * LeetCode 88. 合并两个有序数组
 * ⚠️ 从后往前填（避免覆盖 nums1 前部）
 */
public void merge(int[] nums1, int m, int[] nums2, int n) {
    int p1 = m - 1;              // nums1 有效区末尾
    int p2 = n - 1;              // nums2 末尾
    int p = m + n - 1;           // 填充位置

    while (p2 >= 0) {
        if (p1 >= 0 && nums1[p1] > nums2[p2]) {
            nums1[p--] = nums1[p1--];
        } else {
            nums1[p--] = nums2[p2--];
        }
    }
}
// 推演 nums1=[1,2,3,0,0,0], m=3, nums2=[2,5,6]：
//   → [1,2,2,3,5,6] ✓
// ⚠️ 面试必答："从后往前避免覆盖——
//   后部是 0 填充区，安全；前部有效元素不会被覆盖"
```

## 9. 977. 有序数组的平方

### 9.1 完整实现（对撞取大）

```java
/**
 * LeetCode 977. 有序数组的平方
 * 最大的平方在两端（负数平方可能大）
 * → 从后往前填，取两端平方较大者
 */
public int[] sortedSquares(int[] nums) {
    int n = nums.length;
    int[] result = new int[n];
    int left = 0, right = n - 1;
    int p = n - 1;                        // 从后往前填

    while (left <= right) {
        int leftSquare = nums[left] * nums[left];
        int rightSquare = nums[right] * nums[right];
        if (leftSquare > rightSquare) {
            result[p--] = leftSquare;     // 左端平方更大
            left++;
        } else {
            result[p--] = rightSquare;    // 右端平方更大
            right--;
        }
    }
    return result;
}
// 推演 [-4,-1,0,3,10]：
//   → [0,1,9,16,100] ✓
// ⚠️ 为什么对撞？
//   有序 → 平方后"两端大中间小"
//   最大平方一定在两端 → 从两端取最大（归并思想）
```

## 10. 881. 救生艇

### 10.1 完整实现（最大配最小）

```java
/**
 * LeetCode 881. 救生艇
 * 每艘船最多载两人且重量 ≤ limit，求最少船数
 * 贪心 + 对撞：最重的尽量配最轻的
 */
public int numRescueBoats(int[] people, int limit) {
    Arrays.sort(people);
    int left = 0, right = people.length - 1;
    int boats = 0;

    while (left <= right) {
        if (people[left] + people[right] <= limit) {
            left++;               // 最轻的能陪最重的
        }
        right--;                  // 最重的一定上船
        boats++;
    }
    return boats;
}
// 推演 [3,2,2,1], limit=3 → 排序 [1,2,2,3]
//   1+3=4>3 → 3 单独（1船）；2+2=4>3 → 2 单独（1船）
//   1 单独（1船）→ 3 艘
// ⚠️ 贪心正确性：
//   最重的人 w：
//     能配最轻 → 两人一艘（最优）
//     配不了 → 没有任何人能配 → 单独（必然）
//   → 每步都是最优决策
```
