## 7. 双指针 vs 滑动窗口

| 维度 | 双指针 | 滑动窗口 |
|------|------|------|
| 本质 | 指针按规则移动 | 双指针维护连续区间 |
| 区间 | 不要求连续 | **必须是连续区间** |
| 移动 | 对撞/同向/速度差 | 右扩左缩 |
| 适用 | 有序找两数、原地修改、链表 | 连续子数组/子串最优 |
| 代表题 | 15/167/27/141 | 3/76/209 |
| 关系 | **滑动窗口是双指针的特例** | 同向双指针 + 区间维护 |

```
记忆：双指针是"技巧"，滑动窗口是"区间版双指针"
  对撞/快慢/滑窗三模式，滑窗放双指针体系下讲解
```

## 8. 双指针解题心法

```
① 识别模式（30 秒）
   有序找两数 → 对撞；原地修改 → 快慢；连续区间 → 滑窗

② 定义指针语义（一句话）
   left/right 分别代表什么？slow 是"下一个写入位置"？

③ 确定移动规则（核心）
   什么条件动 left？什么条件动 right？
   每轮必有一个指针移动（否则死循环）

④ 验证单调性（面试必讲）
   为什么被排除的组合不可能包含答案？
   （有序单调 / 短板效应 / 速度差必然相遇）

⑤ 边界处理
   空数组 / 单元素 / 全相同 / 相遇时刻
```
