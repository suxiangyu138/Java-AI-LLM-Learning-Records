## 2. 三大模板速查（默写版）

```java
// ═══════════ 模板一：对撞指针 ═══════════════════════
// 适用：167/15/11/125/42
int left = 0, right = arr.length - 1;
while (left < right) {
    // 处理 arr[left], arr[right]
    if (条件A) left++;        // 单调性决定移动方向
    else right--;
}

// ═══════════ 模板二：快慢指针（数组）══════════════
// 适用：27/26/80/283
int slow = 0;
for (int fast = 0; fast < arr.length; fast++) {
    if (保留条件(arr[fast])) {
        arr[slow++] = arr[fast];   // 快读慢写
    }
}
// slow = 新长度；283 需补零

// ═══════════ 模板三：快慢指针（链表）══════════════
// 适用：141/876/19
ListNode slow = head, fast = head;
while (fast != null && fast.next != null) {
    slow = slow.next;          // 1 步
    fast = fast.next.next;     // 2 步
}
```

## 3. 面试解题话术

```
📣 第 1 步：模式识别 (15秒)
"这题是【对撞指针】——数组有序，找两数之和，
 两端相向移动是自然选择。"

📣 第 2 步：说单调性（核心！）(60秒)
"为什么对撞是对的？
 当前 sum < target 时，移动 left 值变大；
 sum > target 时，移动 right 值变小。
 有序数组保证指针移动方向与和的变化单调对应，
 每步安全排除'以该端点为准'的一批组合。
 所以 O(n) 而不是 O(n²)。"

📣 第 3 步：写代码 (2分钟)
（按模板默写）

📣 第 4 步：验证 (30秒)
"用 [2,7,11,15], target=9 推演：
 sum=17>9 → right--，sum=13>9 → right--，sum=9 ✓ 返回 [1,2]"
```

## 4. 高频追问与标准回答

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 双指针为什么是 O(n)？ | 每个指针最多移动 n 次（单调不回头），总移动 2n 次；暴力枚举 (i,j) 对是 n² |
| 2 | 为什么双指针是正确的？ | 单调性论证：有序性保证指针移动方向与结果变化方向对应，被排除的组合不可能包含最优解 |
| 3 | 双指针有反例吗？ | 无序数组找两数（无法判断方向）；含负数子数组和（滑窗不单调，用前缀和）；需要范围查询等 |
| 4 | 对撞 vs 快慢怎么选？ | 对撞：两端信息/有序找两数/面积；快慢：原地修改/链表/保持顺序 |
| 5 | 三数之和为什么先排序？ | 排序让双指针可用（单调性）+ 相邻去重可行；代价 O(n log n) 不影响整体 O(n²) |
| 6 | 接雨水双指针为什么 O(1) 空间？ | 只维护 leftMax/rightMax 两个变量，矮边确定接水量后移动，无需预处理数组 |
| 7 | 合并数组为什么从后往前？ | 避免覆盖 nums1 前部未合并的有效元素；后部是 0 填充区，安全 |
| 8 | 快慢指针判环为什么走 2 步？ | 相对速度 1 保证任何环长必然相遇；走 3 步以上可能跳过 slow 永远追不上 |

## 5. 高频题深度复盘

### 5.1 42. 接雨水（Hard 最常考）

```java
public int trap(int[] height) {
    int left = 0, right = height.length - 1;
    int leftMax = 0, rightMax = 0;
    int water = 0;

    while (left < right) {
        leftMax = Math.max(leftMax, height[left]);
        rightMax = Math.max(rightMax, height[right]);

        if (leftMax < rightMax) {
            water += leftMax - height[left];   // 矮边确定
            left++;
        } else {
            water += rightMax - height[right];
            right--;
        }
    }
    return water;
}
```

**复盘要点**：
- 原理：接水量 = min(左最高, 右最高) - 当前高度
- 矮边确定：leftMax < rightMax 时左边接水量可确定
- 面试进阶：讲清 DP 版（O(n) 空间）→ 双指针版（O(1)）的演进

### 5.2 15. 三数之和（去重是灵魂）

```java
public List<List<Integer>> threeSum(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    Arrays.sort(nums);
    for (int i = 0; i < nums.length - 2; i++) {
        if (nums[i] > 0) break;
        if (i > 0 && nums[i] == nums[i - 1]) continue;   // 去重①
        int left = i + 1, right = nums.length - 1;
        while (left < right) {
            int sum = nums[i] + nums[left] + nums[right];
            if (sum == 0) {
                res.add(Arrays.asList(nums[i], nums[left], nums[right]));
                while (left < right && nums[left] == nums[left + 1]) left++;
                while (left < right && nums[right] == nums[right - 1]) right--;
                left++; right--;
            } else if (sum < 0) left++;
            else right--;
        }
    }
    return res;
}
```

**复盘要点**：
- 去重三处缺一不可（固定数/左指针/右指针）
- `nums[i] > 0` 剪枝（排序后正数不可能和为 0）
- 面试易错：找到解后忘记左右去重

## 6. 调试技巧与自检清单

### 6.1 双指针自检三步法

```
第 1 步：指针前进检查
  □ 每轮循环至少一个指针在移动？
  □ 循环条件 left < right 还是 left <= right 符合题目？

第 2 步：语义检查
  □ slow 的语义是"下一个写入位置"还是"边界"？
  □ left/right 排除的区间是否正确？

第 3 步：边界用例
  □ 空数组 / 单元素
  □ 全相同元素（去重题）
  □ 全 0 / 全正 / 含负数
  □ 指针相遇时（left == right）的处理
```

### 6.2 高频 Bug 速查表

| Bug | 原因 | 修复 |
|------|------|------|
| 死循环 | 忘记 left++/right-- | 每轮检查指针必动 |
| 结果重复 | 三数之和没去重 | 三处去重 |
| 越界 | fast.next 空指针 | 循环条件判空 |
| 覆盖问题 | 合并数组从前往后 | 改从后往前 |
| slow 语义错 | 把 slow 当"当前值" | 明确"下一个写入位" |
| 指针越过 | 对撞用 <= | 多数场景用 < |

### 6.3 面试手写 Checklist

```
□ 先说模式（对撞/快慢/滑窗）
□ 说清指针语义
□ 讲单调性论证（为什么正确）
□ 移动规则正确
□ 去重（三数之和）
□ 边界：空/单元素/全相同
□ 复杂度 O(n)/O(1)
□ 手动推演 1 个用例
```

> 🎯 **核心要点**：双指针面试 = **模板 + 单调性论证 + 细节**。三大模板默写、15 题去重三处、42 题矮边确定、88 题反向防覆盖——这些是最高频的考点细节。"为什么双指针是对的？"是面试必答题，务必用单调性论证回答。双指针是 O(n²)→O(n) 的第一优化手段，熟练掌握它在面试中就是效率优势。
