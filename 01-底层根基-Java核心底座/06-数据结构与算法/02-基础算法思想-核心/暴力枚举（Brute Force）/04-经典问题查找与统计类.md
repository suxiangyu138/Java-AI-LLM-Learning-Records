## 1. 两数之和：暴力到哈希的经典弧线

### 1.1 题目与暴力版

**题**：给定数组与 target，找两个数下标使和 == target（1 题）。

```java
// 暴力 O(n²)：枚举所有 (i, j) 对
public int[] twoSum(int[] nums, int target) {
    for (int i = 0; i < nums.length; i++) {
        for (int j = i + 1; j < nums.length; j++) {
            if (nums[i] + nums[j] == target) {
                return new int[]{i, j};
            }
        }
    }
    return new int[0];
}
```

**复杂度**：解空间 C(n,2) ≈ n²/2，单解验证 O(1) → **O(n²)**。

### 1.2 优化版：哈希查补数

**瓶颈分析**：内层循环在找 `target - nums[i]`——这是"查找"，可以哈希化。

```java
// 哈希 O(n)：值 → 下标，一边遍历一边查补数
public int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> map = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        int need = target - nums[i];
        if (map.containsKey(need)) {          // 补数已在前面出现过
            return new int[]{map.get(need), i};
        }
        map.put(nums[i], i);
    }
    return new int[0];
}
```

> 🎯 **这是全题库最经典的一条优化弧线**：O(n²) → O(n)。三句话面试版：**"暴力是双层循环枚举数对；瓶颈是内层查找补数；用哈希表把查找降到 O(1)，同时可以边遍历边维护"**。注意：本题**不能排序**（要返回原下标），这正是 03 文件"排序破坏下标"的实例。

### 1.3 三个变体的选型

| 变体 | 约束 | 解法 |
|------|------|------|
| 1 两数之和 | 返回下标 | 哈希 O(n)（不能排序） |
| 167 两数之和 II | 已排序 | 双指针 O(n) 或二分 O(n log n) |
| 653 两数之和 IV | 二叉搜索树 | 中序转有序数组 + 双指针 |

## 2. 三数之和：排序 + 双指针

### 2.1 题目与暴力版

**题**：找所有和为 0 的三元组，**不得重复**（15 题）。

```java
// 暴力 O(n³)：三重循环
public List<List<Integer>> threeSumBrute(int[] nums) {
    Set<List<Integer>> res = new HashSet<>();   // 用 Set 去重（暴力版）
    int n = nums.length;
    for (int i = 0; i < n; i++)
        for (int j = i + 1; j < n; j++)
            for (int k = j + 1; k < n; k++)
                if (nums[i] + nums[j] + nums[k] == 0)
                    res.add(Arrays.asList(nums[i], nums[j], nums[k]));
    return new ArrayList<>(res);
}
```

**问题**：O(n³) 超时，且用 Set 去重浪费空间——大量枚举是浪费的。

### 2.2 优化版：排序 + 固定 i + 双指针

```java
// O(n²)：排序后固定 i，内层双指针
public List<List<Integer>> threeSum(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    Arrays.sort(nums);                          // ① 排序：去重 + 双指针前提
    int n = nums.length;
    for (int i = 0; i < n - 2; i++) {
        if (nums[i] > 0) break;                          // ② 剪枝
        if (i > 0 && nums[i] == nums[i - 1]) continue;   // ③ 去重：同值 i 只做一次
        int l = i + 1, r = n - 1;
        while (l < r) {
            int sum = nums[i] + nums[l] + nums[r];
            if (sum == 0) {
                res.add(Arrays.asList(nums[i], nums[l], nums[r]));
                while (l < r && nums[l] == nums[l + 1]) l++;   // ④ 去重 l
                while (l < r && nums[r] == nums[r - 1]) r--;   // ⑤ 去重 r
                l++; r--;
            } else if (sum < 0) l++;
            else r--;
        }
    }
    return res;
}
```

**四个关键点**（面试逐条讲）：

```text
① 排序: 双指针需要单调性，相邻去重需要有序
② 剪枝: nums[i] > 0 时三数必为正 → 直接 break（比 continue 更快）
③ 去重 i: 相同 i 值只处理一次（同层去重）
④⑤ 去重 l/r: 找到一个解后跳过所有相同值，防止重复三元组
```

> 💡 **复杂度对比**：暴力 O(n³) + Set 去重；优化 O(n log n) 排序 + O(n²) 主体 = **O(n²)**，且空间 O(1)（不含输出）。"排序去重"四字是本类题的总纲。

## 3. 四数之和：嵌套 + 剪枝

**题**：找所有和为 target 的四元组（18 题）。与三数之和同构：固定 i、j 两层，内层双指针。

```java
// 18 四数之和：O(n³)
public List<List<Integer>> fourSum(int[] nums, long target) {
    List<List<Integer>> res = new ArrayList<>();
    Arrays.sort(nums);
    int n = nums.length;
    for (int i = 0; i < n - 3; i++) {
        if (i > 0 && nums[i] == nums[i - 1]) continue;     // 去重
        // 剪枝：最小四数和都超了 → 后面更大，break
        if ((long) nums[i] + nums[i+1] + nums[i+2] + nums[i+3] > target) break;
        for (int j = i + 1; j < n - 2; j++) {
            if (j > i + 1 && nums[j] == nums[j - 1]) continue;  // 去重
            int l = j + 1, r = n - 1;
            while (l < r) {
                long sum = (long) nums[i] + nums[j] + nums[l] + nums[r];
                if (sum == target) {
                    res.add(Arrays.asList(nums[i], nums[j], nums[l], nums[r]));
                    while (l < r && nums[l] == nums[l+1]) l++;
                    while (l < r && nums[r] == nums[r-1]) r--;
                    l++; r--;
                } else if (sum < target) l++;
                else r--;
            }
        }
    }
    return res;
}
```

> ⚠️ 两个易错点：**① 用 long 求和**——四个 int 相加可能溢出（-10⁹ 级别数据）；**② 每层都要去重**（i 层、j 层、l/r 层各一次），漏一层就出重复四元组。推广：k 数之和 = 固定 k−2 层 + 双指针，O(n^(k−1))。

## 4. 和为 K 的子数组：前缀和 + 哈希

### 4.1 题目与三层优化

**题**：求数组中和为 K 的**连续子数组**个数（560 题）。

```text
① 暴力三重循环:   O(n³)   枚举起点×终点×求和
② 前缀和优化:     O(n²)   枚举起点×终点，区间和 O(1)
③ 前缀和 + 哈希:  O(n)    只遍历一次，查"补"的个数
```

### 4.2 完整代码（③）

```java
// 560 和为 K 的子数组: O(n)
public int subarraySum(int[] nums, int k) {
    Map<Integer, Integer> cnt = new HashMap<>();   // 前缀和 → 出现次数
    cnt.put(0, 1);                                 // 空前缀和为 0
    int pre = 0, ans = 0;
    for (int x : nums) {
        pre += x;                                  // 当前前缀和
        ans += cnt.getOrDefault(pre - k, 0);       // 之前有多少个 (pre-k) → 就有多少子数组
        cnt.put(pre, cnt.getOrDefault(pre, 0) + 1);
    }
    return ans;
}
```

**为什么对**：子数组和 `sum(i..j) = pre[j+1] − pre[i]`，要求等于 k ⟺ `pre[i] = pre[j+1] − k`——遍历到 j 时，哈希表里 `pre − k` 的计数就是"以 j 结尾且和为 k 的子数组个数"。**注意必须边算边存**（先查后存），否则会误算子数组长度 0 的情况。

> 🎯 560 是"前缀和 + 哈希"的**最标准模板**，变体：523 和可被 K 整除（存余数）、1248 恰好 K 个奇数（奇偶计数）、974 和可被 K 整除的子数组（余数哈希）。

## 5. 回文枚举：中心扩展法

### 5.1 暴力版：枚举所有子串

**题**：找最长回文子串（5 题）。

```java
// 暴力 O(n³)：枚举起点×终点×验证回文
public String longestPalindromeBrute(String s) {
    int n = s.length(), best = 0, start = 0;
    for (int i = 0; i < n; i++)
        for (int j = i; j < n; j++)
            if (isPalindrome(s, i, j) && j - i + 1 > best) {
                best = j - i + 1; start = i;
            }
    return s.substring(start, start + best);
}
```

### 5.2 优化版：枚举中心 + 向两边扩展

**关键观察**：回文由**中心**唯一确定——n 个字符 + n−1 个间隙 = **2n−1 个中心**，每个中心向两边扩展验证。

```java
// 5 最长回文子串: O(n²)（中心扩展）
public String longestPalindrome(String s) {
    int n = s.length(), start = 0, maxLen = 1;
    for (int i = 0; i < n; i++) {
        int len1 = expand(s, i, i);       // 奇数中心（单字符）
        int len2 = expand(s, i, i + 1);   // 偶数中心（间隙）
        int len = Math.max(len1, len2);
        if (len > maxLen) { maxLen = len; start = i - (len - 1) / 2; }
    }
    return s.substring(start, start + maxLen);
}
private int expand(String s, int l, int r) {
    while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) { l--; r++; }
    return r - l - 1;                     // 回文长度
}
```

**复杂度**：O(n²)（2n−1 个中心 × 最多 n 次扩展）。647 回文子串（计数）同法，把"最长"改为"计数"即可。

> 💡 同题更优解：Manacher 算法 O(n)——但**面试先给中心扩展 O(n²) 再提 Manacher**，展示"暴力 → 优化 → 更优"的完整梯度。这也是枚举思想的胜利：**换一个更好的枚举对象（中心而非子串）**。

## 6. 子数组统计：枚举端点与计数技巧

### 6.1 枚举右端点的统一视角

大量子数组统计题可以统一为"**枚举右端点，维护左端点**"：

| 题目 | 枚举右端点时的维护 | 复杂度 |
|------|------------------|:---:|
| 560 和为 K | 哈希表存前缀和计数 | O(n) |
| 209 长度最小 | 滑动窗口收缩左端 | O(n) |
| 1248 恰好 K 个奇数 | 前缀奇偶计数 | O(n) |
| 795 区间子数组个数 | 单调窗口（最大值在界内） | O(n) |

### 6.2 模板：枚举右端 + 哈希计数

```text
for (r 从 0 到 n-1):
    更新右端状态（前缀和 / 窗口和 / 计数）
    在哈希/窗口里查满足条件的左端个数 → 累加答案
    把当前右端状态存入哈希/窗口
```

> 🎯 **洞察**：子数组统计类问题的本质都是"**和为 K / 边界 / 极值约束下的端点对计数**"——把"枚举起点"换成"枚举终点 + 查起点"，O(n²) 变 O(n)。这就是枚举对象的转换艺术（对应 02 文件"改变枚举对象"优化法）。
