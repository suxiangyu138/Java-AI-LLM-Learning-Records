## 1. 优化方法论

**「先暴力后优化」四步**：

```text
① 暴力验证: 先写枚举（保证思路正确）
② 分析瓶颈: 找出最重的循环（通常内层）
③ 定向优化: 内层用哈希/二分/剪枝替换
④ 验证等价: 优化后结果与暴力一致

例: 两数之和
  ① 暴力: O(n²) 双循环 ✓
  ② 瓶颈: 内层找 target-nums[i]（O(n)）
  ③ 优化: 哈希表查找 → O(1)
  ④ 验证: 结果一致 ✓
```

| 优化手段 | 替换的暴力 | 代价 |
|---------|:---:|:---:|
| 剪枝 | 无效枚举 | 无（纯加速） |
| 哈希 | 内层线性查找 | 空间 O(n) |
| 二分 | 内层线性查找 | 需有序 + O(log n) |
| 预处理 | 重复计算 | 空间 O(n) |
| 双指针 | 二维枚举 | 需单调性 |

> 🎯 **核心认知**：**高效算法 = 聪明的枚举**——所有算法都在「少枚举」（剪枝/贪心）或「快验证」（哈希/二分）——掌握枚举就掌握了优化入口。

## 2. 剪枝优化

**剪枝（Pruning）**：提前排除「不可能成为答案」的分支——枚举的纯加速手段（不影响正确性）。

```java
// 剪枝示例 1: 组合剩余不足（77 组合优化）
// 原: for (int i = start; i <= n; i++)
// 剪枝: 剩余可选数 < 还需要数 → 停止
for (int i = start; i <= n - (k - path.size()) + 1; i++) {
    path.add(i);
    combine(n, k, i + 1, path, res);
    path.remove(path.size() - 1);
}
// 效果: 避免无解分支（剪枝后同正确性、少递归）

// 剪枝示例 2: 枚举起点剪枝（三数之和）
// 排序后: nums[i] + nums[l] + nums[r]
// nums[i] > 0 时后面全正 → 直接 break（经典剪枝）
if (nums[i] > 0) break;
```

| 剪枝类型 | 判定 | 例 |
|---------|------|-----|
| 剩余不足 | 可选数 < 需求数 | 77 组合 |
| 有序剪枝 | 当前最小已超限 | 三数之和 |
| 对称剪枝 | 对称解等价 | 回文类 |
| 可行性剪枝 | 当前路径必失败 | 回溯类 |

> 💡 剪枝三问：**「这个分支还有可能吗？」**（可行性）**「还有必要吗？」**（最优性）**「和别的分支重复吗？」**（对称性）——三问都有则剪。

## 3. 哈希加速

**哈希加速**：把「内层查找」从 O(n) 降为 O(1)——空间换时间的最经典应用。

```java
// 两数之和: 暴力 O(n²) → 哈希 O(n)
public int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> map = new HashMap<>();    // 值 → 下标
    for (int i = 0; i < nums.length; i++) {
        int need = target - nums[i];
        if (map.containsKey(need)) {                 // O(1) 查补数
            return new int[]{map.get(need), i};
        }
        map.put(nums[i], i);                         // 边查边存
    }
    return new int[0];
}
```

| 题号 | 题目 | 暴力 | 哈希优化 |
|------|------|:---:|:---:|
| 1 | 两数之和 | O(n²) | **O(n)** |
| 3 | 无重复最长子串 | O(n²) | O(n) 滑动 |
| 128 | 最长连续序列 | O(n²) | **O(n)** |
| 49 | 异位词分组 | O(n²·L) | O(n·L) |
| 560 | 和为 K 子数组 | O(n²) | **O(n)** 前缀和 |
| 146 | LRU 缓存 | O(n) | **O(1)** 哈希+链表 |

```java
// 560 和为 K 的子数组（前缀和 + 哈希）: O(n²) → O(n)
public int subarraySum(int[] nums, int k) {
    Map<Integer, Integer> prefix = new HashMap<>();
    prefix.put(0, 1);                                // 空前缀
    int sum = 0, count = 0;
    for (int num : nums) {
        sum += num;
        count += prefix.getOrDefault(sum - k, 0);     // 找 前缀和-k
        prefix.merge(sum, 1, Integer::sum);
    }
    return count;
}
```

> 🎯 **识别信号**：「内层线性查找」→ 哈希替换——**凡是「枚举中找存在/找配对」都能哈希化**；前缀和 + 哈希是「子数组和」类题的标准优化（560 题）。

## 4. 二分加速

**二分加速**：枚举外层 + 内层二分（需有序）——O(n²) → O(n log n)。

```java
// 枚举 + 二分: 三数之和暴力 O(n³) → 排序 + 双指针 O(n²)
public List<List<Integer>> threeSum(int[] nums) {
    Arrays.sort(nums);                               // ① 排序（二分/双指针前提）
    List<List<Integer>> res = new ArrayList<>();
    for (int i = 0; i < nums.length - 2; i++) {
        if (i > 0 && nums[i] == nums[i - 1]) continue;  // 去重
        if (nums[i] > 0) break;                      // 剪枝（后面全正）
        int left = i + 1, right = nums.length - 1;   // ② 双指针
        while (left < right) {
            int sum = nums[i] + nums[left] + nums[right];
            if (sum == 0) {
                res.add(List.of(nums[i], nums[left], nums[right]));
                while (left < right && nums[left] == nums[left + 1]) left++;   // 去重
                while (left < right && nums[right] == nums[right - 1]) right--;// 去重
                left++; right--;
            } else if (sum < 0) {
                left++;                              // 和太小 → 右移
            } else {
                right--;                             // 和太大 → 左移
            }
        }
    }
    return res;
}
```

| 枚举变体 | 复杂度 | 前提 |
|---------|:---:|------|
| 暴力三循环 | O(n³) | 无 |
| 枚举 + 二分 | O(n² log n) | 有序 |
| **枚举 + 双指针** | **O(n²)** | 有序 + 单调 |
| 哈希优化 | O(n²) | 无（空间换） |

> 💡 双指针是「有序枚举」的终极形态：**单调性让指针只前进**（无需回头）——三数之和 O(n³) → O(n²) 的教科书级优化（双指针体系衔接）。

### 5.2 综合应用：枚举的完整思维

```java
// 5. 最长回文子串: 枚举中心 + 双向扩展（O(n²)）
public String longestPalindrome(String s) {
    int start = 0, maxLen = 0;
    for (int i = 0; i < s.length(); i++) {
        // 奇数长度中心
        int len1 = expand(s, i, i);
        // 偶数长度中心
        int len2 = expand(s, i, i + 1);
        int len = Math.max(len1, len2);
        if (len > maxLen) {
            maxLen = len;
            start = i - (len - 1) / 2;
        }
    }
    return s.substring(start, start + maxLen);
}

int expand(String s, int left, int right) {          // 双向扩展
    while (left >= 0 && right < s.length() && s.charAt(left) == s.charAt(right)) {
        left--; right++;
    }
    return right - left - 1;
}
// 暴力 O(n³) → 枚举中心 O(n²)：内层从「子串验证」换成「中心扩展」
```

> 💡 **枚举优化的心法**：找出「重复计算的子问题」——最长回文暴力枚举所有子串并验证（O(n³)），枚举中心让每次扩展是纯增量（O(n²)）；**优化 = 消除重复**。
