## 1. 子集问题：三种实现方式对比

**题**：给定无重复元素的数组，返回所有子集（78 题）。

### 1.1 方式一：位掩码（01 文件已讲，竞赛首选）

```java
// 位掩码: O(2ⁿ × n)，2ⁿ 个掩码 × n 位检查
public List<List<Integer>> subsets(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    int n = nums.length;
    for (int mask = 0; mask < (1 << n); mask++) {
        List<Integer> subset = new ArrayList<>();
        for (int i = 0; i < n; i++)
            if ((mask & (1 << i)) != 0) subset.add(nums[i]);
        res.add(subset);
    }
    return res;
}
```

### 1.2 方式二：迭代扩展（"选择 vs 不选择"逐元素累积）

```java
// 迭代扩展: 每来一个元素，把已有子集全部复制一份加上它
public List<List<Integer>> subsetsIter(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    res.add(new ArrayList<>());               // 空集
    for (int x : nums) {
        int size = res.size();
        for (int i = 0; i < size; i++) {      // 只复制本轮之前的子集
            List<Integer> copy = new ArrayList<>(res.get(i));
            copy.add(x);
            res.add(copy);
        }
    }
    return res;
}
// 过程: [] → [], [1] → [], [1], [2], [1,2] → ... 共 2ⁿ 个
```

### 1.3 方式三：递归选/不选（衔接回溯）

```java
// 递归: 每个元素"选"或"不选"两条分支
void dfs(int[] nums, int i, List<Integer> path, List<List<Integer>> res) {
    if (i == nums.length) { res.add(new ArrayList<>(path)); return; }  // 叶子收集
    dfs(nums, i + 1, path, res);              // ① 不选
    path.add(nums[i]);
    dfs(nums, i + 1, path, res);              // ② 选
    path.remove(path.size() - 1);             // 撤销
}
```

### 1.4 三种方式对比

| 方式 | 复杂度 | 特点 | 适用 |
|------|:---:|------|------|
| 位掩码 | O(2ⁿ·n) | 无递归、状态可传递（衔接状压 DP） | 竞赛、n ≤ 20 |
| 迭代扩展 | O(2ⁿ·n) | 直观、无递归、天然顺序 | 面试首选之一 |
| 递归选/不选 | O(2ⁿ·n) | 回溯模板、可加剪枝 | 衔接回溯、n 大时 |

> 💡 面试三种都说一遍是加分项："子集有**位掩码、迭代扩展、递归选/不选**三种写法，位掩码适合 n≤20 和状态压缩场景，递归版可以无缝升级成回溯加剪枝。"

## 2. 组合问题：startIndex 机制

**题**：从 1~n 中选 k 个数的所有组合（77 题）。

```java
// 77 组合: O(C(n,k))，"从 start 开始 + 不回头"保证无序性
public List<List<Integer>> combine(int n, int k) {
    List<List<Integer>> res = new ArrayList<>();
    dfs(n, k, 1, new ArrayList<>(), res);
    return res;
}
void dfs(int n, int k, int start, List<Integer> path, List<List<Integer>> res) {
    if (path.size() == k) { res.add(new ArrayList<>(path)); return; }  // 选够 k 个
    for (int i = start; i <= n; i++) {
        path.add(i);
        dfs(n, k, i + 1, path, res);          // 下一个从 i+1：不回头（关键！）
        path.remove(path.size() - 1);
    }
}
```

### 2.1 为什么用 startIndex 而不是 used 数组

```text
组合: [1,2] == [2,1]（无序）→ startIndex 保证只往前选 → 天然不重复
排列: [1,2] != [2,1]（有序）→ 需要 used 数组标记全部可选 → 见 06 文件

startIndex 传 i+1: 本层选了 i，下层只能选更大的 → 杜绝回头
used 数组: 每层都能选任意未用元素 → 产生全排列
```

### 2.2 剪枝：剩余不足提前停止

```java
// 剪枝: 当前已选 path.size()，还需 k - path.size() 个
// 当 i 到 n 剩余不足时直接停止循环（i 最大只能到 n - 还需数 + 1）
for (int i = start; i <= n - (k - path.size()) + 1; i++) {
    ...
}
```

> 🎯 **组合问题的三句箴言**：**① startIndex 保证无序不重复；② 剪枝条件 `i <= n - (k - path.size()) + 1`；③ 收集时深拷贝 `new ArrayList<>(path)`**。这三句背熟，组合类全通。

## 3. 组合总和系：可重复选与去重

### 3.1 39 组合总和（元素可重复选）

**题**：候选数组（无重复）可无限次选取，找和为 target 的所有组合。

```java
// 39: 递归传 i 而不是 i+1 → 允许重复选当前元素
void dfs(int[] c, int target, int start, List<Integer> path, List<List<Integer>> res) {
    if (target == 0) { res.add(new ArrayList<>(path)); return; }
    for (int i = start; i < c.length; i++) {
        if (c[i] > target) continue;          // 剪枝
        path.add(c[i]);
        dfs(c, target - c[i], i, path, res);  // ★ 传 i：下次还能选 c[i]（可重复）
        path.remove(path.size() - 1);
    }
}
```

### 3.2 40 组合总和 II（不可重复选 + 原数组有重复）

```java
// 40: 排序 + 同层去重 + 传 i+1
Arrays.sort(candidates);                       // ① 排序（去重前提）
void dfs(int[] c, int target, int start, List<Integer> path, List<List<Integer>> res) {
    if (target == 0) { res.add(new ArrayList<>(path)); return; }
    for (int i = start; i < c.length; i++) {
        if (c[i] > target) break;              // 剪枝（已排序，后面更大）
        if (i > start && c[i] == c[i - 1]) continue;   // ② 同层去重（核心）
        path.add(c[i]);
        dfs(c, target - c[i], i + 1, path, res);        // ③ 传 i+1：不重复选
        path.remove(path.size() - 1);
    }
}
```

### 3.3 三题对比（面试必背）

| 题目 | 元素可重复选？ | 数组有重复？ | 关键差异 |
|:---:|:---:|:---:|------|
| 39 | ✔（传 i） | ✘ | 递归传 i |
| 40 | ✘（传 i+1） | ✔（需去重） | 排序 + 同层去重 + 传 i+1 |
| 216 | ✘ | ✘ | 固定 k 个数 + 和 == n |

> ⚠️ **同层去重的精髓**：`i > start && nums[i] == nums[i-1]` 跳过的是**同一层**的重复选择（如 [1,1,2] 中第一个 1 和第二个 1 作为"本层第一位"是等价的）；**同一路径**上的重复元素（如 [1,1] 连续选两个 1）是合法的，不能跳。**先排序才能让重复元素相邻**。

## 4. 子集 II：排序 + 同层去重

**题**：数组含重复元素，返回所有**不重复**子集（90 题）。

```java
// 90 子集 II: 排序 + 同层去重（位掩码版）
public List<List<Integer>> subsetsWithDup(int[] nums) {
    Arrays.sort(nums);                        // ① 排序
    List<List<Integer>> res = new ArrayList<>();
    int n = nums.length;
    Set<String> seen = new HashSet<>();       // 方式A: Set 暴力去重
    for (int mask = 0; mask < (1 << n); mask++) {
        List<Integer> subset = new ArrayList<>();
        for (int i = 0; i < n; i++)
            if ((mask & (1 << i)) != 0) subset.add(nums[i]);
        String key = subset.toString();       // 序列化去重（简单但慢）
        if (seen.add(key)) res.add(subset);
    }
    return res;
}
```

```java
// 更优: 回溯版同层去重 O(2ⁿ)（无 Set 开销）
void dfs(int[] nums, int start, List<Integer> path, List<List<Integer>> res) {
    res.add(new ArrayList<>(path));           // 进入即收集（子集：每个结点都是答案）
    for (int i = start; i < nums.length; i++) {
        if (i > start && nums[i] == nums[i - 1]) continue;   // 同层去重
        path.add(nums[i]);
        dfs(nums, i + 1, path, res);
        path.remove(path.size() - 1);
    }
}
```

> 🎯 **子集 vs 组合的收集时机**：子集是"**进入即收集**"（每个结点都是合法子集），组合是"**叶子收集**"（凑够 k 个才收）。这个差异在回溯专题里是必考点，此处先把机制记住。

## 5. 多路选择：电话号码组合

**题**：数字串映射到字母，返回所有组合（17 题）。

```java
// 17: 每层可选分支数量不同（2/3/4 个字母），多路递归
String[] map = {"", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"};

void dfs(String digits, int idx, StringBuilder sb, List<String> res) {
    if (idx == digits.length()) { res.add(sb.toString()); return; }
    String letters = map[digits.charAt(idx) - '0'];
    for (char c : letters.toCharArray()) {    // 本层的选择列表（3~4 个）
        sb.append(c);
        dfs(digits, idx + 1, sb, res);
        sb.deleteCharAt(sb.length() - 1);
    }
}
// 复杂度: O(4ⁿ × n)（最坏全是 9）
```

> 💡 17 题是"**独立解空间**"的典型：每层选择不受前面选择影响（不像组合受 startIndex 约束）——用**固定字符串拼接 + 撤销**而非 startIndex。它展示了多路枚举的通用形态。

## 6. 剪枝与去重技巧汇总

### 6.1 去重三原则（背下来）

```text
① 必须先排序: 让重复元素相邻（去重的前提）
② 同层去重:  if (i > start && nums[i] == nums[i-1]) continue
   —— 组合/子集用 start 判断同层
③ 排列去重:  if (i > 0 && nums[i] == nums[i-1] && !used[i-1]) continue
   —— 排列用 used 判断同层（06 文件详解）
```

### 6.2 剪枝三类型

| 类型 | 条件 | 例题 |
|------|------|------|
| 长度剪枝 | 剩余元素不足凑够 k 个 | 77 |
| 数值剪枝 | 当前和已超 target / 排序后后面更大 | 39/40 |
| 有序早停 | 最小元素已不满足 → break | 15 |

### 6.3 易错点清单

| 易错点 | 错误写法 | 正确写法 |
|--------|---------|---------|
| 深拷贝 | `res.add(path)` | `res.add(new ArrayList<>(path))` |
| 可重复选 | `dfs(..., i + 1, ...)` | `dfs(..., i, ...)` |
| 去重判断 | `if (nums[i]==nums[i-1])`（同路径误杀） | `if (i > start && ...)`（同层才跳） |
| 剪枝早停 | `continue`（可能漏更优） | 排序后用 `break` |
| 组合用 used | `used[]` 导致排列语义 | 组合必须 startIndex |
