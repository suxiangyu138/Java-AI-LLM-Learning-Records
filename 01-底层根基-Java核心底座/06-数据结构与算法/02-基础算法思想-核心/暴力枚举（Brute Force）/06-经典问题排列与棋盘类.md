## 1. 全排列：used 数组机制

**题**：返回数组所有全排列（46 题）。

### 1.1 暴力版：递归选 + used 标记

```java
// 46 全排列: O(n! × n)，used 数组标记已选元素
public List<List<Integer>> permute(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    dfs(nums, new boolean[nums.length], new ArrayList<>(), res);
    return res;
}
void dfs(int[] nums, boolean[] used, List<Integer> path, List<List<Integer>> res) {
    if (path.size() == nums.length) {         // ① 选满 n 个 → 叶子
        res.add(new ArrayList<>(path));       // 深拷贝！
        return;
    }
    for (int i = 0; i < nums.length; i++) {   // ② 每层都从 0 开始（与组合的区别！）
        if (used[i]) continue;                // ③ 已选过 → 跳过
        used[i] = true;                       // ④ 标记
        path.add(nums[i]);
        dfs(nums, used, path, res);
        used[i] = false;                      // ⑤ 撤销（回溯）
        path.remove(path.size() - 1);
    }
}
```

### 1.2 排列 vs 组合的关键差异

| | 排列（46） | 组合（77） |
|--|-----------|-----------|
| 每层遍历起点 | **0**（所有元素都可选） | **start**（只能往后选） |
| 去重机制 | used 数组 | startIndex |
| 顺序敏感性 | [1,2] ≠ [2,1]（都要） | [1,2] == [2,1]（只要一个） |
| 解空间 | n! | C(n,k) |

> 🎯 **一句话区分**：**"顺序算不算数"决定一切**——顺序算数（排列）用 used 从 0 遍历；顺序不算（组合）用 start 不回头。面试被问"为什么排列要 used、组合要 start"，答出这句话就满分。

### 1.3 另一种实现：交换法

```java
// 交换法: 不用 used，就地交换（01 文件已见）
void permute(int[] nums, int start, List<List<Integer>> res) {
    if (start == nums.length) {
        List<Integer> list = new ArrayList<>();
        for (int x : nums) list.add(x);
        res.add(list);
        return;
    }
    for (int i = start; i < nums.length; i++) {
        swap(nums, start, i);                 // 把第 i 个换到 start 位
        permute(nums, start + 1, res);
        swap(nums, start, i);                 // 换回（回溯）
    }
}
```

used 版清晰、可推广到去重（47）；交换版省空间、适合无重复。**面试优先 used 版**（去重扩展方便）。

## 2. 全排列 II：同层去重

**题**：数组含重复元素，返回所有**不重复**全排列（47 题）。

```java
// 47 全排列 II: used + 同层去重
public List<List<Integer>> permuteUnique(int[] nums) {
    Arrays.sort(nums);                        // ① 排序（去重前提）
    List<List<Integer>> res = new ArrayList<>();
    dfs(nums, new boolean[nums.length], new ArrayList<>(), res);
    return res;
}
void dfs(int[] nums, boolean[] used, List<Integer> path, List<List<Integer>> res) {
    if (path.size() == nums.length) { res.add(new ArrayList<>(path)); return; }
    for (int i = 0; i < nums.length; i++) {
        // ② 同层去重（核心）: 前一个相同元素没被本层用 → 跳过
        if (i > 0 && nums[i] == nums[i - 1] && !used[i - 1]) continue;
        if (used[i]) continue;
        used[i] = true;
        path.add(nums[i]);
        dfs(nums, used, path, res);
        used[i] = false;
        path.remove(path.size() - 1);
    }
}
```

### 2.1 去重条件为什么是 `!used[i-1]`

```text
场景: nums = [1a, 1b, 2]，排列中 1a 与 1b 只该出现一次

!used[i-1]（推荐）: 前一个 1 还没用 → 当前 1 就是"同层重复" → 跳过
                → 保证重复元素按"第一个 1 先被使用"的顺序枚举
used[i-1]（也正确）: 前一个 1 已用 → 当前 1 是"同一路径" → 跳过
                → 效果相同（都只保留一种相对顺序），只是判断时机不同
```

两种写法都 AC，但 `!used[i-1]` 剪枝更彻底（重复元素只在一种排列里出现），是社区主流写法。**面试写出 `i > 0 && nums[i] == nums[i-1] && !used[i-1]` 并解释"保证重复元素的相对顺序唯一"即满分**。

### 2.2 去重对比（47 vs 40/90）

| 题目 | 去重判断 | 原理 |
|------|---------|------|
| 40 组合总和 II | `i > start && nums[i]==nums[i-1]` | start 界定"同层" |
| 90 子集 II | 同上 | 同上 |
| 47 全排列 II | `i > 0 && nums[i]==nums[i-1] && !used[i-1]` | used 界定"同层" |

## 3. 下一个排列：字典序枚举

**题**：原地求比当前排列大的**下一个**字典序排列（31 题）。

```java
// 31 下一个排列: 字典序枚举的核心算法（四步）
public void nextPermutation(int[] nums) {
    int n = nums.length;
    // ① 从右往左找第一个降序点 i（nums[i] < nums[i+1]）
    int i = n - 2;
    while (i >= 0 && nums[i] >= nums[i + 1]) i--;
    if (i >= 0) {
        // ② 从右往左找第一个比 nums[i] 大的 j
        int j = n - 1;
        while (nums[j] <= nums[i]) j--;
        // ③ 交换 i、j
        swap(nums, i, j);
    }
    // ④ 反转 [i+1, n)（原为降序，反转后是最小后缀）
    reverse(nums, i + 1, n - 1);
}
```

**为什么正确**：字典序的"下一个" = 把尽可能靠右的"小增"换到右边、后缀反转成最小——这是枚举排列的**迭代生成器**，配合排序可枚举全部排列且天然去重。

> 💡 **应用**：K 个不同字符的所有排列按字典序输出、第 k 个排列（60 题，数学法）。31 题是"排列枚举"的迭代视角，与 46 的递归视角互补——**两种视角都要会**。

## 4. N 皇后：从暴力到递进剪枝

**题**：n×n 棋盘放 n 个皇后，互不攻击（不同行/列/对角线），返回所有摆法（51 题）。

### 4.1 暴力版：枚举所有摆法

```text
暴力最朴素: 在 n² 个格子中选 n 个放皇后 → C(n², n) 种
  n=8: C(64, 8) ≈ 4.4×10⁹ → 完全不可行
```

### 4.2 递进剪枝（枚举优化的教科书案例）

```text
剪枝① 每行必须放一个 → 解空间从 C(n²,n) 降到 nⁿ 种"每行选一列"
剪枝② 每列不能重复   → usedCol 标记 → 降为 n! 种（每行选未用列）
剪枝③ 对角线不能冲突 → 主对角线 r-c 相同、副对角线 r+c 相同
          → 实际搜索中再砍 90%+，n=8 实际约 2000 个结点
```

```java
// 51 N 皇后: 行递进 + 列/对角线三数组剪枝
public List<List<String>> solveNQueens(int n) {
    List<List<String>> res = new ArrayList<>();
    char[][] board = new char[n][n];
    for (char[] row : board) Arrays.fill(row, '.');
    boolean[] col = new boolean[n], diag1 = new boolean[2 * n - 1], diag2 = new boolean[2 * n - 1];
    dfs(n, 0, col, diag1, diag2, board, res);
    return res;
}
void dfs(int n, int r, boolean[] col, boolean[] d1, boolean[] d2,
         char[][] board, List<List<String>> res) {
    if (r == n) {                             // 全部放完 → 收集
        List<String> rows = new ArrayList<>();
        for (char[] row : board) rows.add(new String(row));
        res.add(rows);
        return;
    }
    for (int c = 0; c < n; c++) {
        if (col[c] || d1[r - c + n - 1] || d2[r + c]) continue;  // 列 + 双对角线
        board[r][c] = 'Q';
        col[c] = true; d1[r - c + n - 1] = true; d2[r + c] = true;
        dfs(n, r + 1, col, d1, d2, board, res);
        board[r][c] = '.';
        col[c] = false; d1[r - c + n - 1] = false; d2[r + c] = false;
    }
}
```

### 4.3 剪枝收益量化

| 阶段 | 解空间 | n=8 实际规模 |
|------|:---:|:---:|
| 纯暴力（任选 n 格） | C(n², n) | 4.4×10⁹ |
| 剪枝①（每行一个） | nⁿ | 1.7×10⁷ |
| 剪枝②（列不重复） | n! | 40320 |
| 剪枝③（对角线） | 实际搜索结点 | ~2000 |

> 🎯 **N 皇后是"枚举优化 = 约束递进"的最强教学案例**：每加一个约束，解空间掉一个数量级——这就是剪枝的本质：**用约束信息跳过不可能的分支**。对角线判重的两个公式 `r-c`（主对角线）与 `r+c`（副对角线）是必背考点。

## 5. 解数独：暴力填数的剪枝

**题**：填充 9×9 数独（37 题）。

```java
// 37 解数独: 逐格尝试 1-9，行列宫三数组剪枝
public void solveSudoku(char[][] board) {
    boolean[][] row = new boolean[9][10], col = new boolean[9][10];
    boolean[][][] box = new boolean[3][3][10];
    for (int i = 0; i < 9; i++)
        for (int j = 0; j < 9; j++)
            if (board[i][j] != '.') {
                int d = board[i][j] - '0';
                row[i][d] = col[j][d] = box[i/3][j/3][d] = true;
            }
    dfs(board, 0, 0, row, col, box);
}
boolean dfs(char[][] b, int i, int j, boolean[][] row, boolean[][] col, boolean[][][] box) {
    if (i == 9) return true;                  // 全部填完
    if (j == 9) return dfs(b, i + 1, 0, row, col, box);   // 换行
    if (b[i][j] != '.') return dfs(b, i, j + 1, row, col, box);  // 已有数字
    for (int d = 1; d <= 9; d++) {
        if (row[i][d] || col[j][d] || box[i/3][j/3][d]) continue;  // 行列宫冲突
        b[i][j] = (char) ('0' + d);
        row[i][d] = col[j][d] = box[i/3][j/3][d] = true;
        if (dfs(b, i, j + 1, row, col, box)) return true;  // 找到即返回
        row[i][d] = col[j][d] = box[i/3][j/3][d] = false;
        b[i][j] = '.';
    }
    return false;                             // 9 个数字都试过 → 回溯
}
```

> 💡 数独与 N 皇后的共同结构：**逐行/逐格推进 + 多条件冲突数组 + 找到即返回**（bool 返回值版回溯）。棋盘类题的枚举框架就三件事：**推进顺序（行/格）、冲突检查（数组/位掩码）、撤销恢复**。

## 6. 网格与棋盘枚举技巧

| 技巧 | 说明 | 例题 |
|------|------|------|
| 方向数组 | `int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}}` 统一扩展 | 79 单词搜索 |
| 位掩码冲突 | 一行用一个 int 的位表示占用（加速） | 52 N 皇后 II |
| 边界守卫 | 越界即返回（先判边界再判内容） | 130 被围绕区域 |
| 坐标编码 | `(r, c) → r*cols + c` 转一维 | 695 岛屿面积 |
| 标记数组 | visited 或就地改值（沉岛法） | 200 岛屿数量 |

```java
// 79 单词搜索: 网格四方向递归枚举
boolean dfs(char[][] b, String w, int i, int r, int c, boolean[][] vis) {
    if (i == w.length()) return true;
    if (r < 0 || r >= b.length || c < 0 || c >= b[0].length) return false;  // 边界
    if (vis[r][c] || b[r][c] != w.charAt(i)) return false;                  // 访问过/字符不符
    vis[r][c] = true;
    boolean ok = dfs(b, w, i+1, r+1, c, vis) || dfs(b, w, i+1, r-1, c, vis)
              || dfs(b, w, i+1, r, c+1, vis) || dfs(b, w, i+1, r, c-1, vis);
    vis[r][c] = false;
    return ok;
}
```

| 题号 | 题目 | 枚举模型 | 关键点 | 复杂度 |

| 46 | 全排列 | 排列 used | 每层从 0 遍历 | O(n!·n) |

| 31 | 下一个排列 | 字典序 | 降序点 + 反转后缀 | O(n) |
| 60 | 排列序列 | 数学计数 | 阶乘分块 | O(n²) |
| 51 | N 皇后 | 棋盘 | 行列对角线三剪枝 | O(n!) |
| 52 | N 皇后 II | 棋盘计数 | 位运算加速 | O(n!) |
| 37 | 解数独 | 棋盘填数 | 行列宫剪枝 | O(9^空格) |
| 79 | 单词搜索 | 网格 | 方向数组 + visited | O(4^len) |
| 22 | 括号生成 | 组合约束 | 左右括号计数 | O(卡特兰数) |
| 491 | 非递减子序列 | 子集 + Set 去重 | 每层 Set（不能排序） | O(2ⁿ·n) |

> 🎯 **核心要点**：排列棋盘类 = 枚举思想的"高压区"。必背四件事：**① used 数组 + 每层从 0 遍历（排列 vs 组合的分水岭）；② 同层去重 `!used[i-1]`（47）；③ nextPermutation 四步（31）；④ 棋盘三剪枝结构（N 皇后：行递进 + 列/对角线数组）**。这类题暴力不可行（4.4×10⁹），但**每加一个约束剪枝就掉一个数量级**——枚举优化的精髓全在这里。
