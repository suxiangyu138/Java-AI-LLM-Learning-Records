## 1. 四模型模板速查（默写版）

### 1.1 顺序枚举

```java
// 一维 O(n)
for (int i = 0; i < n; i++) { check(nums[i]); }

// 二维 O(n²)（j = i+1 避免重复对）
for (int i = 0; i < n; i++)
    for (int j = i + 1; j < n; j++)
        if (nums[i] + nums[j] == target) { ... }
```

### 1.2 子集枚举（位掩码）

```java
// O(2ⁿ × n)，n ≤ 20
for (int mask = 0; mask < (1 << n); mask++) {
    List<Integer> subset = new ArrayList<>();
    for (int i = 0; i < n; i++)
        if ((mask & (1 << i)) != 0) subset.add(nums[i]);
    ...
}
```

### 1.3 排列枚举（used 版）

```java
// O(n! × n)，n ≤ 10
void dfs(int[] nums, boolean[] used, List<Integer> path, List<List<Integer>> res) {
    if (path.size() == nums.length) { res.add(new ArrayList<>(path)); return; }
    for (int i = 0; i < nums.length; i++) {
        if (used[i]) continue;
        used[i] = true; path.add(nums[i]);
        dfs(nums, used, path, res);
        used[i] = false; path.remove(path.size() - 1);
    }
}
```

### 1.4 组合枚举（start 版）

```java
// O(C(n,k) × k)，剪枝: i <= n - (k - path.size()) + 1
void dfs(int n, int k, int start, List<Integer> path, List<List<Integer>> res) {
    if (path.size() == k) { res.add(new ArrayList<>(path)); return; }
    for (int i = start; i <= n - (k - path.size()) + 1; i++) {
        path.add(i);
        dfs(n, k, i + 1, path, res);
        path.remove(path.size() - 1);
    }
}
```

> 🎯 **默写口诀**：**"子集掩码、排列 used、组合 start"**——三行口诀对应三个模板，30 秒内写出即可过手撕关。

## 2. 去重三原则与深拷贝

### 2.1 去重三原则

```text
① 必须先排序: 让重复元素相邻（90/40/47 的共同前提）
② 同层去重:   组合/子集 if (i > start && nums[i] == nums[i-1]) continue
              排列     if (i > 0 && nums[i] == nums[i-1] && !used[i-1]) continue
③ 深拷贝:     res.add(new ArrayList<>(path))——绝不能 add(path)
```

### 2.2 为什么必须深拷贝

```java
List<Integer> path = new ArrayList<>();
// ...
res.add(path);                    // ❌ 所有结果引用同一个 path
res.add(new ArrayList<>(path));   // ✔ 每份都是独立副本
```

Java 的 `add` 存的是**引用**——`path` 后续被修改（remove），已加入的结果也会变。这是**枚举/回溯类题的最高频 bug**，没有之一。

## 3. Java 实现易错点清单

| 易错点 | 错误写法 | 正确写法 | 后果 |
|--------|---------|---------|------|
| 结果集引用 | `res.add(path)` | `res.add(new ArrayList<>(path))` | 所有结果相同（严重） |
| 排列用 start | 组合模板套排列 | 排列每层从 0 + used | 漏解（严重） |
| 组合用 used | 排列模板套组合 | 组合 startIndex | 大量重复解（严重） |
| 可重复选 | `dfs(..., i+1, ...)` | `dfs(..., i, ...)` | 漏解（严重） |
| 去重误杀同路径 | `if (nums[i]==nums[i-1])` 无条件跳 | `if (i > start && ...)` 同层才跳 | 漏解（严重） |
| 位掩码 n 过大 | n=30 硬跑 2³⁰ | n≤20 用位掩码，否则剪枝 | 超时 |
| int 溢出 | `(1 << 31)` | `1L << n` 或 `(1 << n)` n≤30 谨慎 | 结果错误 |
| 提前 return | 找到就 return 忘记撤销 | 撤销后再 return | 状态残留 |
| 修改入参 | 直接用原数组排序保下标 | 拷贝数组/下标数组 | 数据被破坏 |

## 4. 笔试机考应用映射

### 4.1 枚举在笔试中的三种角色

| 角色 | 场景 | 说明 |
|------|------|------|
| 正解 | 解空间 ≤ 10⁶ | 直接暴力 AC（签到题/基础题） |
| 兜底 | 时间不够/思路不清 | 暴力保证部分分（竞赛策略） |
| 验证器 | 对拍 | 写完优化算法后，用暴力对拍验证正确性 |

### 4.2 高频笔试/机考题型分布

```text
查找统计类（30%+）:  两数/三数之和、子数组和、回文 → 04 文件
子集组合类（25%）:   子集、组合总和、去重变体 → 05 文件
排列棋盘类（20%）:   全排列、N 皇后、网格搜索 → 06 文件
```

## 5. 面试话术与追问三板斧

### 5.1 一分钟自我介绍版（背下来）

> "暴力枚举是算法解题的第一方法论，核心是**无遗漏遍历解空间**，复杂度等于**解空间大小乘单解验证成本**。我掌握四种模型：顺序、子集（位掩码）、排列（used）、组合（start），以及对应的优化手段——**少枚举**（剪枝、双指针、滑动窗口）和**快验证**（哈希、二分、前缀和）。拿到题目我会先写暴力验证思路，再分析瓶颈定向优化，比如两数之和从 O(n²) 用哈希优化到 O(n)。"

### 5.2 追问三板斧

| 追问 | 高分回答 |
|------|---------|
| "枚举的复杂度怎么分析？" | 公式：解空间 × 验证成本；例：两数之和 C(n,2) × O(1) = O(n²) |
| "什么时候该优化？" | 1 秒规则：解空间 × 验证成本 > 10⁷~10⁸ 就优化；n≤20 子集、n≤10 排列可直接暴力 |
| "枚举和回溯什么关系？" | 回溯 = 枚举 + 剪枝（DFS 骨架）；枚举是穷举框架，回溯加约束提前终止 |

### 5.3 加分延伸

> "另外我理解**所有高效算法本质上都是聪明的枚举**——动态规划是枚举 + 记忆化去重叠，双指针是枚举 + 单调性跳过，哈希是枚举 + O(1) 验证。**枚举能力决定优化空间**，所以我习惯先暴力、后优化、最后对拍验证。"

## 6. 软考考点精讲

软件设计师/系统架构师考试中枚举相关考点：

### 6.1 复杂度计算题

> 用三重循环求所有三元组和的复杂度是？
> A. O(n)  B. O(n²)  C. O(n³)  D. O(2ⁿ)

**答案 C**。技巧：循环嵌套层数 × 单层规模 = 复杂度（三层 n 循环 = O(n³)）。

### 6.2 解空间规模题

> n 个元素的子集个数为？全排列个数为？

**答案：2ⁿ 与 n!**。这是枚举的数学基础，必考必背。

### 6.3 算法思想对比题

> 回溯法与暴力枚举的关系是？
> A. 无关系  B. 回溯 = 枚举 + 剪枝  C. 枚举 = 回溯 + 剪枝  D. 完全等价

**答案 B**。答题技巧：见到"回溯"必联想到"枚举 + 剪枝/约束"。

### 6.4 位运算题

> 判断整数掩码 mask 的第 i 位是否为 1？

**答案**：`(mask >> i) & 1 == 1` 或 `(mask & (1 << i)) != 0`。软考常考 `1 << i` 与 `&` 的组合用法。

## 7. 手撕清单与验收

### 7.1 必默写清单（面试前过关）

```text
① 两数之和: 暴力 → 哈希（1）              ← 优化链展示
② 子集: 位掩码 + 迭代扩展 + 递归（78）      ← 三种写法
③ 组合: start + 剪枝（77）                ← 组合模板
④ 全排列: used（46） + 去重（47）          ← 排列模板
⑤ 组合总和: 传 i 可重复（39）+ 去重（40）   ← 变体迁移
⑥ 三数之和: 排序 + 双指针（15）            ← 少枚举范式
⑦ N 皇后: 三剪枝（51）                    ← 棋盘范式
```

### 7.2 验收清单

- [ ] 30 秒默写四模型模板（顺序/位掩码/used/start）
- [ ] 能背出去重三原则（排序/同层/深拷贝）并解释原因
- [ ] 能说出"1 秒规则"与三临界点（n=10/20/22）
- [ ] 能对任意枚举题估算复杂度并判断是否需优化
- [ ] 能讲"暴力 → 优化"的完整理由链（少枚举/快验证）
- [ ] 10 分钟内完成 1/78/77/46 四题的手写

> 🎯 **核心要点**：面试全流程 = **默写四模板 → 讲去重三原则 → 估算复杂度 → 展示优化链**。暴力枚举不是"笨办法"而是"方法论起点"——能写、能估、能优化、能讲，四件事全做到，这道基础题就是满分。**记住：所有高效算法都是聪明的枚举**，这句话能贯穿整个算法面试。
