## 1. 实战题：215 数组中的第 K 个最大元素（quickselect）

### 1.1 题目与思路

**题**：无序数组第 K 大（要求优于排序的 O(n log n) 或直接期望 O(n)）。

**quickselect（快速选择）**：partition 后 pivot 永久就位——**如果 pivot 位置恰好是目标，直接返回；否则只递归包含目标的那一侧**：

```text
为什么平均 O(n):
  每次只处理一侧 → T(n) = T(n/2) + O(n)
  → O(n) + O(n/2) + O(n/4) + … = 2n = O(n)（几何级数）
最坏: 划分退化 → T(n) = T(n−1) + O(n) = O(n²)（随机基准防御）
```

### 1.2 完整代码（分区循环版）

```java
/**
 * LeetCode 215. 数组中的第 K 个最大元素（quickselect）
 * 平均 O(n)，最坏 O(n²)（随机基准防御）；O(1) 额外空间
 */
public int findKthLargest(int[] nums, int k) {
    int target = nums.length - k;              // 第 k 大 = 升序第 n-k 小
    int lo = 0, hi = nums.length - 1;

    while (lo < hi) {
        int p = partition(nums, lo, hi);       // Lomuto 划分（pivot 就位）
        if (p < target) lo = p + 1;            // ① 目标在右区
        else if (p > target) hi = p - 1;       // ② 目标在左区
        else break;                            // ③ 恰好就位
    }
    return nums[target];
}

// partition 与 01 文件 Lomuto 版相同（可随机化基准增强）
// 推演 [3,2,1,5,6,4]，k=2（目标=第 5 小，target=4）：
//   划分 pivot=4 → [3,2,1,4,6,5]，p=3 < 4 → 只处理右区 [6,5]
//   划分 pivot=5 → [5,6]，p=5 > 4 → 只处理左区 [5]
//   划分 pivot=5 → p=4 == target → 返回 5 ✓（第 2 大）
```

> 🎯 **quickselect 的价值**："**快排的划分是'免费的定位器'**——pivot 永久就位让'找第 K 大'不必排序全数组。215 是快排思想最优雅的实战变形，平均 O(n) 优于排序后取值的 O(n log n)。"

## 2. 实战题：75 颜色分类（三路划分）

### 2.1 题目与思路

**题**：只含 0/1/2 的数组原地排序，要求一趟扫描（O(n) + 常数空间）。

**三路划分（荷兰国旗问题，Dijkstra）**：把 0 换到左区、2 换到右区、1 留在中间——**这就是 02 文件三路快速排序的划分裸题**：

```java
/**
 * LeetCode 75. 颜色分类（荷兰国旗三路划分）
 * 时间 O(n) 一趟扫描，空间 O(1)
 */
public void sortColors(int[] nums) {
    int lo = 0, mid = 0, hi = nums.length - 1;
    while (mid <= hi) {
        if (nums[mid] == 0) {              // ① 0 → 换到左区
            swap(nums, lo, mid);
            lo++; mid++;
        } else if (nums[mid] == 2) {       // ② 2 → 换到右区
            swap(nums, mid, hi);
            hi--;                          // mid 不动（换来的元素再查）
        } else {
            mid++;                         // ③ 1 → 留在中间
        }
    }
}
// 推演 [2,0,2,1,1,0]：
//   mid=0(2) → 换 hi → [0,0,2,1,1,2] hi=4
//   mid=0(0) → 换 lo → [0,0,2,1,1,2] lo=1
//   mid=1(0) → 换 lo → [0,0,2,1,1,2] lo=2
//   mid=2(2) → 换 hi → [0,0,1,1,2,2] hi=3
//   mid=2(1) → mid++；mid=3(1) → mid++
//   结束 [0,0,1,1,2,2] ✓
```

> 💡 **讲解亮点**："75 题 = 三路快速排序的划分步——**0 区、1 区、2 区就是 <p、=p、>p 三区**。会写 75，就能把三路快排的 `lt/gt` 边界理解透。"

## 3. 实战题：912 排序数组（工程版）

### 3.1 题目与思路

**题**：排序数组（912），n ≤ 5×10⁴，要求 O(n log n)。

**工程版快排 = 组合拳**（把 02 文件优化全用上）：

```java
/**
 * LeetCode 912. 排序数组（工程版快排）
 * 三数取中 + 小区间插入 + 深度兜底
 */
private static final int THRESHOLD = 16;

public int[] sortArray(int[] nums) {
    quickSort(nums, 0, nums.length - 1);
    return nums;
}

private void quickSort(int[] a, int lo, int hi) {
    if (hi - lo <= THRESHOLD) {          // ① 小区间切插入排序
        insertionSort(a, lo, hi);
        return;
    }
    if (lo >= hi) return;
    int p = partitionMedian(a, lo, hi);  // ② 三数取中划分（防退化）
    quickSort(a, lo, p - 1);
    quickSort(a, p + 1, hi);
}
```

### 3.2 为什么 912 快排版能过、冒泡版不能

```text
快排平均: ~1.39·n·log₂n ≈ 1.39 × 5×10⁴ × 16 ≈ 1.1×10⁶ 次操作 → 毫秒级 ✓
冒泡最坏: n²/2 ≈ 1.25×10⁹ 次操作 → 超时 ✗

912 三版对比:
  快排: 平均最快、原地 → 面试首选（含退化防御）
  归并: 稳定无退化、O(n) 空间
  堆排: 最坏有界、O(1) 空间、常数大
```

> 🎯 **实战判断**："912 是排序家族选型的考试现场——**默认写快排（带三数取中 + 小区间插入）**，被追问再补归并/堆排的选型论述。一个函数把 02 文件的优化全用上，就是'工程快排'的完整答卷。"

## 4. 面试话术三连

### 4.1 三连话术（背下来）

```text
Q1: "快排的原理与复杂度？"
A: "选基准 → 划分成左小右大 → pivot 永久就位 → 递归两侧。
   平均 O(n log n)（常数约 1.39n log n，原地无拷贝所以实际最快），
   最坏 O(n²)（固定基准 + 有序数据）；空间 O(log n) 栈；不稳定。"

Q2: "快排的退化怎么防？"
A: "三层防御：随机基准/三数取中让退化不可构造；
   introsort 递归深度超限转堆排（JDK 阈值 64）彻底兜底；
   三路划分处理重复元素（全重复从 O(n²) 降到 O(n)）。
   再加小区间切插入（阈值 47）减少递归开销。"

Q3: "快排 vs 归并 vs 堆排？"
A: "快排平均最快但最坏可退化（可防）；归并稳定无退化但 O(n) 空间；
   堆排最坏有界且 O(1) 空间但常数大。JDK 的答案：
   基本类型双轴快排（+归并/堆排兜底），对象 TimSort（稳定）。"
```

### 4.2 30 秒手写版本（Lomuto）

```java
// 面试手写标准版（2 分钟内）
void quickSort(int[] a, int lo, int hi) {
    if (lo >= hi) return;
    int p = partition(a, lo, hi);
    quickSort(a, lo, p - 1);
    quickSort(a, p + 1, hi);
}
int partition(int[] a, int lo, int hi) {
    int p = a[hi], i = lo;
    for (int j = lo; j < hi; j++)
        if (a[j] < p) { int t = a[i]; a[i] = a[j]; a[j] = t; i++; }
    int t = a[i]; a[i] = a[hi]; a[hi] = t;
    return i;
}
```

## 6. 软考与笔试考点：过程模拟

### 6.1 过程模拟题（必考大题）

**真题样式**：对序列 [49, 38, 65, 97, 76, 13, 27] 做快速排序（基准取首元素），写出每趟划分结果。

| 趟 | 操作 | 结果 |
|:---:|------|------|
| 初始 | — | [49, 38, 65, 97, 76, 13, 27] |
| 1 | 基准 49：右找 <49（27,13），左找 >49（65,97）交换，pivot 归位 | [13, 38, 27, **49**, 76, 97, 65] |
| 2 | 左 [13,38,27] 基准 13：无更小 → 原位；右 [38,27] 基准 38：27 左移 | [13, 27, **38**, **49**, 76, 97, 65] |
| 3 | 右 [76,97,65] 基准 76：65 左移、97 右移 | [13, 27, 38, 49, 65, **76**, 97] |
| 4 | 右 [97] 单元素 | [13, 27, 38, 49, 65, 76, **97**] ✓ |

**答题技巧**：

```text
① 基准取首元素 → 先从右往左找小的、再从左往右找大的、交换
② 指针相遇处放基准（pivot 归位）→ 该位置就是最终位置
③ 每趟只写"划分结果 + pivot 位置"，别把递归展开写混
④ 软考常见变体: 基准取末尾/取中值——先看清题干！
```

### 6.2 其他题型

| 考点 | 题型 | 要点 |
|------|------|------|
| 最坏情况判定 | 选择题 | 有序 + 取首元素基准 → O(n²)；三数取中后有序数据正常 |
| 复杂度辨析 | 计算题 | 平均 1.39n log n 次比较；最坏 n²/2 |

## 7. 高频追问与标准回答

| # | 追问 | 标准回答 |
|:---:|------|---------|
| 1 | 为什么快排平均是最快的？ | 原地无拷贝 + 缓存友好（顺序扫描），比较常数 1.39 虽略高于归并但搬移成本远低 |
| 2 | 有序数组快排一定慢？ | 只有固定基准才慢；三数取中/随机基准后有序输入表现正常 |
| 3 | 快排能稳定吗？ | 不能——跨距离交换是结构性缺陷，任何基准策略都改不了 |
| 4 | quickselect 和最坏？ | 平均 O(n)（只递归一侧）；最坏 O(n²)（随机基准防御） |
| 5 | JDK 为什么用双轴？ | 一次固化 2 个基准 + 三区划分天然处理重复元素 |
| 6 | 为什么对象数组不用快排？ | 不稳定——对象排序要求稳定 → TimSort |
| 7 | 尾递归优化解决什么？ | 递归栈最坏 O(n) → O(log n)（只递归小区间、大区间迭代） |
| 8 | 三路划分什么时候收益最大？ | 重复元素多时——中间区跳过，全重复 O(n) |
| 9 | 快排和冒泡什么关系？ | 冒泡是相邻交换（O(n²)）；快排是跨距离交换（平均 O(n log n)）——快排 = 冒泡的"跳跃版" |
| 10 | 2026 年快排新进展？ | JDK-8266431 引入并行基数排序与 AVX512 SIMD（int 快 13×） |

> 🎯 **核心要点**：实战面试通关 = **两个变形（215 quickselect 平均 O(n)、75 三路划分）+ 一个工程版（912 组合拳）+ 话术三连 + 一道模拟（软考划分过程，基准首元素版）**。快排在面试中的定位是"**手撕第一优先级 + 退化防御必答 + JDK 故事加分**"——从 Lomuto 到双轴到 2026 SIMD，一条线讲完就是排序家族的深度天花板。
