## 1. 知识体系导图

```text
冒泡排序（Bubble Sort）
│
├── 核心本质 ──────────────────────────────────────────────
│   ├── = 相邻元素两两比较，逆序则交换
│   ├── 每趟把当前最大者"冒泡"到末尾（未排序区收缩）
│   ├── 最多 n−1 趟，每趟比较 n−1、n−2… 1 次
│   └── 稳定（严格大于才交换）+ 原地（O(1) 空间）
│
├── 关键特性 ──────────────────────────────────────────────
│   ├── 时间复杂度：最好 O(n) / 平均 O(n²) / 最坏 O(n²)
│   ├── 空间复杂度：O(1)（原地交换）
│   ├── 稳定性：✔ 稳定（相邻交换不越位）
│   └── 适应性：✔ 有序数据 O(n)（提前终止优化后）
│
├── 两大优化 ──────────────────────────────────────────────
│   ├── 提前终止：某趟无交换 → 已有序 → 结束
│   ├── 记录最后交换位置：末尾有序区动态缩短
│   └── 效果：近乎有序数据从 O(n²) → 接近 O(n)
│
├── 三大变体 ──────────────────────────────────────────────
│   ├── 鸡尾酒排序（双向冒泡）：左右交替扫描，快 20-40%
│   ├── 梳排序：间隔递减（n/1.3），平均接近 O(n log n)
│   └── 奇偶排序：奇数/偶数位置交替比较，易并行
│
├── 工程定位 ──────────────────────────────────────────────
│   ├── 教学价值：第一个学会的排序、交换类排序入门
│   ├── 小数据（n < 100）或近乎有序数据仍可用
│   └── 大规模被插入/快排取代（常数与阶数都不占优）
│
└── 实战与面试 ────────────────────────────────────────────
    ├── 手写：基础版 + 提前终止版（1 分钟默写）
    ├── 考题：检测有序数组、移动零（冒泡思想）、912（会超时）
    ├── 对比：冒泡 vs 选择 vs 插入（三个 O(n²) 谁最好）
    └── 话术：稳定性 + 教学价值 + 提前终止 + 适用边界
```

## 4. 核心概念速查

| 概念 | 一句话解释 | 说明 |
|------|-----------|------|
| **冒泡排序** | 相邻比较、逆序交换，最大者每趟冒到末尾 | 最简单的交换类排序 |
| **相邻交换** | 只比较/交换相邻两元素 | 稳定性与教学性的来源 |
| **未排序区** | 每趟末尾固定一个最大者 | 扫描区间逐趟收缩 |
| **提前终止** | 某趟无交换 → 已有序 → 结束 | 让最好情况到 O(n) |
| **lastSwap** | 记录最后交换位置 | 末尾有序区动态缩短 |
| **鸡尾酒排序** | 左右交替扫描的双向冒泡 | 常数更小，快 20-40% |
| **梳排序** | 间隔从 n/1.3 递减的比较交换 | 平均接近 O(n log n) |
| **奇偶排序** | 奇/偶位置对交替比较 | 易于并行 |
| **稳定性** | 相等元素相对顺序不变 | 冒泡稳定（严格大于才交换） |
| **交换次数** | 最坏 n(n-1)/2 次 | 软考计算考点 |

## 5. 复杂度与特性速查表

| 维度 | 最好 | 平均 | 最坏 | 说明 |
|------|:---:|:---:|:---:|------|
| 时间复杂度 | O(n) | O(n²) | O(n²) | 最好 = 有序 + 提前终止 |
| 空间复杂度 | O(1) | O(1) | O(1) | 原地交换 |
| 比较次数 | n−1 | n²/2 | n²/2 | 每趟比较数递减 |
| 交换次数 | 0 | n²/2 | n²/2 | 与逆序对数量正比 |
| 稳定性 | ✔ 稳定 | — | — | 严格大于才交换 |
| 适应性 | ✔ 有序最快 | — | — | 提前终止优化后 |

**与其他 O(n²) 排序对比**：

| 算法 | 最好 | 最坏 | 稳定 | 适应 | 常数 | 独特价值 |
|------|:---:|:---:|:---:|:---:|:---:|------|
| 冒泡排序 | O(n) | O(n²) | ✔ | ✔ | 大（交换 3 赋值） | 教学直观 |
| 插入排序 | O(n) | O(n²) | ✔ | ✔ | 最小 | 小数组/近乎有序王者 |
| 选择排序 | O(n²) | O(n²) | ✘ | ✘ | 中 | 交换次数 O(n) 最少 |

> 🎯 **一句话选型**：三个 O(n²) 里**冒泡综合最弱**——常数最大（每次交换 3 次赋值）、适应性最差（数据有序时提前终止仍要扫描）、唯一价值是教学直观。**n < 64 选插入、写操作贵选选择、教学演示选冒泡**。

## 6. 常见误区速查

| 误区 | 正解 |
|------|------|
| "冒泡排序时间复杂度固定 O(n²)" | ❌ 加提前终止后最好 O(n)——有序数据一趟即停 |
| "冒泡排序不稳定" | ❌ 稳定！相邻交换不会让相等元素越过彼此 |
| "冒泡排序和选择排序一样" | ❌ 冒泡相邻交换（每趟可能多次交换）；选择找最小再交换（每趟 1 次） |
| "冒泡排序 n < 100 时能用" | ❌ 能用但不推荐——插入排序同场景常数更小 |
| "鸡尾酒排序改变复杂度" | ❌ 复杂度不变（仍 O(n²)），只是常数因子更小 |
| "梳排序是另一类排序" | ❌ 梳排序 = 冒泡思想 + 间隔递减（冒泡的规模化变体） |
| "冒泡排序适合大规模数据" | ❌ n > 1000 时 O(n²) 不可接受，快排/归并是正解 |
| "提前终止能检测任意有序" | ✔ 对——某趟无交换 ⇔ 数组已有序（软考判断题考点） |
