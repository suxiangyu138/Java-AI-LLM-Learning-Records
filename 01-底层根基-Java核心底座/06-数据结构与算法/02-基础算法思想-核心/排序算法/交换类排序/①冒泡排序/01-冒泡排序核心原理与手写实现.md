## 1. 冒泡模型：从水泡到算法

### 1.1 算法就像气泡上浮

水中气泡不断上浮变大，冒泡排序同理——**每次扫描让当前最大元素"浮"到末尾**：

```text
① 从左到右扫描未排序区
② 相邻两元素比较，逆序（前 > 后）则交换
③ 一趟结束 → 最大者"冒泡"到末尾（固定不动）
④ 未排序区缩短 1 位，重复直到只剩 1 个元素

每趟的效果:
  第 1 趟 → 最大元素到位
  第 2 趟 → 次大元素到位
  …
  第 n−1 趟 → 全部有序
```

### 1.2 算法要素

```text
未排序区: arr[0 .. n-1-i]（第 i 趟）
每趟: 相邻两两比较 n−1−i 次，逆序交换
总趟数: 最多 n−1 趟（提前终止可更少）
交换: 每交换 1 次 = 3 次赋值（temp 中转）——常数大的来源
```

> 🎯 **核心动作三连**：**相邻比较（arr[j] > arr[j+1]）→ 逆序交换（swap）→ 未排序区收缩**。与选择排序的"找最小再交换"不同，冒泡是"边扫边换"——**它每趟的交换次数 = 该趟消除的逆序对，这是它与选择排序最本质的区别**。

## 2. 基本实现：两个版本

### 2.1 基础版（教材版，最常手写）

```java
/**
 * 冒泡排序（基础版）
 * 时间 O(n²)，空间 O(1)，稳定
 */
public static void bubbleSort(int[] arr) {
    int n = arr.length;
    for (int i = 0; i < n - 1; i++) {        // ① 最多 n−1 趟
        for (int j = 0; j < n - 1 - i; j++) { // ② 未排序区收缩
            if (arr[j] > arr[j + 1]) {        // ③ 严格大于才交换 → 稳定
                int tmp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = tmp;
            }
        }
    }
}
```

### 2.2 提前终止版（优化一，面试推荐）

```java
/**
 * 冒泡排序（提前终止版）
 * 某趟无交换 → 数组已有序 → 提前结束（最好 O(n)）
 */
public static void bubbleSortOptimized(int[] arr) {
    int n = arr.length;
    for (int i = 0; i < n - 1; i++) {
        boolean swapped = false;             // ① 本趟交换标记
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                int tmp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = tmp;
                swapped = true;
            }
        }
        if (!swapped) return;                // ② 无交换 → 已有序
    }
}
```

> 💡 **面试表达**："基础版 O(n²) 固定；加 `swapped` 标记后，**有序数据一趟扫描（n−1 次比较）即结束 → 最好 O(n)**。这是冒泡唯一值得讲的优化，也是软考常考的点。"

## 3. 逐步推演：n=8 全流程

**数据**：[8, 3, 5, 1, 9, 2, 6, 4]（升序排序）

| 趟 | 扫描区间 | 主要交换 | 数组状态 | 到位 |
|:---:|:---:|------|------|:---:|
| 初始 | — | — | [8,3,5,1,9,2,6,4] | — |
| 1 | [0..6] | 8↔3, 8↔5, 8↔1, 9↔2, 9↔6, 9↔4 | [3,5,1,8,2,6,4,**9**] | 9 |
| 2 | [0..5] | 5↔1, 8↔2, 8↔6, 8↔4 | [3,1,5,2,6,4,**8,9**] | 8 |
| 3 | [0..4] | 3↔1, 5↔2, 6↔4 | [1,3,2,5,4,**6,8,9**] | 6 |
| 4 | [0..3] | 3↔2, 5↔4 | [1,2,3,4,**5,6,8,9**] | 5 |
| 5 | [0..2] | 无交换 → 提前终止 | [1,2,3,4,5,6,8,9] ✓ | — |

**单趟推演示例（第 1 趟）**：

```text
扫描 [0..6]，两两比较:
  8>3 交换 → [3,8,5,1,9,2,6,4]
  8>5 交换 → [3,5,8,1,9,2,6,4]
  8>1 交换 → [3,5,1,8,9,2,6,4]
  8<9 不换
  9>2 交换 → [3,5,1,8,2,9,6,4]
  9>6 交换 → [3,5,1,8,2,6,9,4]
  9>4 交换 → [3,5,1,8,2,6,4,9]
最大者 9 冒泡到末尾 ✓
```

> 🎯 **从推演看复杂度直觉**：第 5 趟无交换——**"无交换 ⇔ 已有序"是提前终止的理论基础**（一趟扫描若没有逆序对，全局就真没有逆序对）。冒泡的工作量 = 逆序对数量，数据越有序工作量越小，这就是它的适应性来源。

## 4. 复杂度推导：最好/平均/最坏

### 4.1 精确计数（第 i 趟）

```text
第 i 趟比较 n−1−i 次，交换次数 = 该趟扫描区间内的逆序对数量

总比较次数（不提前终止）:
  Σ(n−1−i) = (n−1) + (n−2) + … + 1 = n(n−1)/2 ≈ n²/2

最坏交换次数（完全逆序）:
  每趟交换次数 = 比较次数 → 总 n(n−1)/2 ≈ n²/2
  （每次交换 = 3 次赋值 → 最坏 ~1.5n² 次赋值，常数大的来源）
```

### 4.2 三情形汇总

| 情形 | 比较次数 | 交换次数 | 复杂度 |
|------|:---:|:---:|:---:|
| 最好（有序 + 提前终止） | n−1 | 0 | **O(n)** |
| 平均（随机） | n²/2 | n²/4 | **O(n²)** |
| 最坏（逆序） | n²/2 | n²/2 | **O(n²)** |

```text
面试推导句:
"冒泡第 i 趟比较 n−1−i 次，最坏共 n(n−1)/2 次比较和交换；
加提前终止后，有序输入一趟扫描即停 → O(n)。
交换 3 次赋值 → 同为 O(n²) 但常数最大。"
```

> 🎯 **面试必答句**："冒泡排序最好 O(n)（有序 + 提前终止）、平均与最坏 O(n²)、空间 O(1)、稳定。**它和选择排序同为 O(n²)，但交换次数最多（每趟多次交换）、常数最大，是三个 O(n²) 里工程价值最低的——教学意义远大于实用意义。**"

## 5. 稳定性证明

### 5.1 证明

```text
内层条件: arr[j] > arr[j+1]（严格大于才交换）

相等元素 a == b（a 在 b 前面）:
  比较时 arr[j] > arr[j+1] 不成立（相等）→ 不交换
  → a 永远保持在 b 前面 → 稳定 ✔

相邻交换不会让相等元素"越过"彼此:
  两个相等元素之间要越过对方，必须发生一次交换，
  而交换条件（严格大于）对它们恒不成立
```

### 5.2 如果不带等号会怎样

```java
// ❌ 错误：arr[j] >= arr[j+1] 会把相等元素换到前面 → 不稳定
if (arr[j] >= arr[j + 1]) { ... }
```

> ⚠️ **稳定性考点**：稳定排序口诀"冒插归基"——**冒泡稳定靠"严格大于才交换"**，与插入排序同款机制。面试被问"冒泡为什么不把相等元素换过去"——答"交换条件对相等元素恒不成立，相邻交换无法越过相等元素"。

## 6. 与选择/插入排序对比

| 维度 | 冒泡排序 | 选择排序 | 插入排序 |
|------|:---:|:---:|:---:|
| 最好复杂度 | O(n) | **O(n²)**（不适应性！） | O(n) |
| 平均/最坏 | O(n²) | O(n²) | O(n²) |
| 稳定性 | ✔ 稳定 | ✘ 不稳定 | ✔ 稳定 |
| 适应性 | ✔ 有序最快 | ✘ 与数据无关 | ✔ 有序最快 |
| 交换次数 | O(n²)（最多） | **O(n)**（最少） | O(n²)（移动） |
| 常数因子 | 最大（3 赋值/交换） | 中 | 最小 |
| 实际速度（n 小） | 最慢 | 居中 | **最快** |

**各自的独特价值**：

```text
冒泡排序: 唯一价值是教学直观（可加提前终止检测有序）
选择排序: 交换次数 O(n)——写操作贵的场景（大对象/闪存）
插入排序: 综合最优——稳定 + 适应 + 常数最小（小数组王者）

面试选型标准答案:
  "n 小或近乎有序 → 插入排序；
   写操作昂贵 → 选择排序；
   冒泡排序只用于教学——它把'交换'表演得最清楚。"
```

> 🎯 **核心要点**：冒泡排序通关四件事——**① 1 分钟默写基础版 + 提前终止版**；**② 复杂度从"每趟比较 n−1−i 次"推导**（Σ = n²/2，提前终止 → O(n)）；**③ 稳定性靠"严格大于才交换"保证**；**④ 定位清晰**（教学直观、常数最大、被插入/快排取代）。它是 O(n²) 家族里"**你写的第一个、工程最后一个**"的排序——这个定位讲清楚，比吹嘘它强。
