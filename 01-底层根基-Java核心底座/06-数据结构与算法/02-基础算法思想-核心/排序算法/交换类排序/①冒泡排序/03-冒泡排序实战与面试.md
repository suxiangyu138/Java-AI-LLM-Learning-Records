## 1. 实战题：检测数组是否已排序

### 1.1 题目与思路

**题**：O(n) 判断数组是否升序（不排序）。

**冒泡思想**：一趟冒泡如果"无交换" ⇔ 已有序——等价做法是**一趟扫描检查所有相邻对**：

```java
/** 检测数组是否升序（一趟扫描，O(n)）——冒泡提前终止思想的直接应用 */
public boolean isSorted(int[] arr) {
    for (int i = 0; i < arr.length - 1; i++) {
        if (arr[i] > arr[i + 1]) return false;   // 发现逆序对 → 未排序
    }
    return true;
}
```

> 🎯 **这题的深层价值**：它证明了提前终止优化的正确性基础——**"所有相邻对有序 ⇔ 全数组有序"**。讲这题时主动引出冒泡的 `swapped` 标记，就是"算法题 → 底层思想"的连线加分。

## 2. 实战题：283 移动零（冒泡思想版）

### 2.1 题目与思路

**题**：把数组中的 0 移到末尾，保持非零元素相对顺序（原地）。

**冒泡视角**：0 就是"要冒到末尾的气泡"——用双指针交换实现"0 冒泡"，且保持顺序：

```java
/**
 * LeetCode 283. 移动零（双指针交换版 = 冒泡思想的"0 冒泡"）
 * 保持非零元素相对顺序（稳定）→ 这正是冒泡的稳定性特性
 */
public void moveZeroes(int[] nums) {
    int slow = 0;                              // 下一个非零应放的位置
    for (int fast = 0; fast < nums.length; fast++) {
        if (nums[fast] != 0) {
            // 把非零元素"交换"到前面（0 自动被挤到后面）
            int tmp = nums[slow];
            nums[slow] = nums[fast];
            nums[fast] = tmp;
            slow++;
        }
    }
}
// 推演 [0,1,0,3,12]：
//   fast=0 跳过；fast=1: 交换(0,1) → [1,0,0,3,12]
//   fast=2 跳过；fast=3: 交换(1,3) → [1,3,0,0,12]
//   fast=4: 交换(2,4) → [1,3,12,0,0] ✓
```

> 💡 **讲解亮点**："移动零要求**保持非零元素相对顺序**——这就是稳定性的要求；交换法 = '把 0 冒泡到末尾'的冒泡思想。**这题是冒泡的'稳定交换'思想在双指针下的升华**。"

## 3. 实战题：912 排序数组（冒泡的边界）

### 3.1 题目与思路

**题**：排序数组（912），n ≤ 5×10⁴。

```text
冒泡排序在此题:
  O(n²) ≈ 1.25×10⁹ 次操作 → 必然超时 ❌
  即使加提前终止 + lastSwap + 鸡尾酒，最坏仍是 O(n²)

结论: 912 的冒泡版只存在于教学——
  正解是快排（期望 O(n log n)）/ 归并（稳定）/ 堆排（有界）
  → 这题本身就是"冒泡退出工程舞台"的现场证据
```

### 3.2 冒泡在题目中的真正位置

| 场景 | 冒泡可用？ | 说明 |
|------|:---:|------|
| n < 100 的手写排序 | ✔ 勉强 | 鸡尾酒版常数可接受 |
| 检测有序 | ✔ 推荐 | 一趟 O(n)，冒泡思想 |
| 保持顺序的交换题（283） | ✔ 思想复用 | 稳定交换 = 冒泡特性 |
| n ≥ 10⁴ 的排序题 | ✘ 超时 | 快排/归并/堆排 |
| 要求最坏有界 | ✘ | 冒泡最坏 O(n²) 无逃生口 |

> 🎯 **实战判断**："**冒泡排序在算法题里从不作正解，但它的两个思想——'无交换⇔有序'（检测）与'稳定交换'（283）——是题目的解法来源**。" 这个定位讲清楚，比硬套冒泡有深度得多。

## 4. 面试话术三连

### 4.1 三连话术（背下来）

```text
Q1: "冒泡排序的复杂度？"
A: "最好 O(n)——有序数据加提前终止一趟即停；
   平均和最坏 O(n²)——每趟比较 n−1−i 次，
   最坏共 n(n−1)/2 次比较和交换；空间 O(1)，稳定。"

Q2: "冒泡排序有什么用？"
A: "三个场景：教学演示（最直观的交换类排序）、
   小数据（n < 100，鸡尾酒版）、检测有序（一趟思想）。
   工程上 n 大用快排，n 小用插入——冒泡常数最大，
   是三个 O(n²) 里唯一'只教不产'的。"

Q3: "冒泡 vs 选择 vs 插入？"
A: "都是 O(n²)。插入综合最优（稳定 + 适应 + 常数最小）；
   选择唯一优势是交换次数 O(n)；
   冒泡唯一优势是教学直观——它把'相邻交换'表演得最清楚。"
```

### 4.2 30 秒手写版本

```java
// 面试手写（提前终止版，1 分钟内）
void bubbleSort(int[] a) {
    for (int i = 0; i < a.length - 1; i++) {
        boolean swapped = false;
        for (int j = 0; j < a.length - 1 - i; j++)
            if (a[j] > a[j + 1]) { int t = a[j]; a[j] = a[j + 1]; a[j + 1] = t; swapped = true; }
        if (!swapped) return;
    }
}
```

## 6. 软考与笔试考点：交换次数计算

### 6.1 过程模拟与计数题

**真题样式**：对序列 [5, 1, 4, 2, 8] 做冒泡排序，写出每趟结果，并计算总交换次数。

| 趟 | 比较与交换 | 结果 |
|:---:|------|------|
| 初始 | — | [5,1,4,2,8] |
| 1 | 5↔1, 5↔4, 5↔2（8 不动） | [1,4,2,5,8] |
| 2 | 4↔2（1 不动） | [1,2,4,5,8] |
| 3 | 无交换 → 提前终止 | [1,2,4,5,8] ✓ |

**总交换次数 = 逆序对数量**：

```text
[5,1,4,2,8] 的逆序对: (5,1)(5,4)(5,2)(4,2) = 4 个
验证: 第 1 趟 3 次 + 第 2 趟 1 次 = 4 次 ✓

⚠️ 考点: 冒泡总交换次数 = 逆序对数量（软考判断题常考）
  最坏（逆序）: n(n−1)/2 次
  最好（有序）: 0 次
```

### 6.2 其他题型

| 考点 | 题型 | 要点 |
|------|------|------|
| 稳定性判断 | 概念题 | 稳定口诀"冒插归基"含冒泡（严格大于才交换） |
| "无交换⇔有序" | 判断题 | 正确——相邻对有序 ⇔ 全局有序（传递性） |
| 复杂度辨析 | 选择题 | 提前终止后最好 O(n)，不是固定 O(n²) |
| 与选择对比 | 选择题 | 冒泡交换多（O(n²)）；选择交换少（O(n)） |
| 鸡尾酒排序 | 概念题 | 双向冒泡，常数小，复杂度不变 |

## 7. 高频追问与标准回答

| # | 追问 | 标准回答 |
|:---:|------|---------|
| 1 | 为什么冒泡比插入慢？ | 交换 3 次赋值 × 最坏 n²/2 次 ≈ 1.5n²；插入用移动（覆盖）约 n²/4 次赋值 |
| 2 | 冒泡能提前终止吗？ | 能——某趟无交换 ⇔ 已有序（相邻对有序 ⇔ 全局有序） |
| 3 | 冒泡为什么稳定？ | 严格大于才交换，相等元素永不越过彼此（相邻交换） |
| 4 | 什么时候用冒泡？ | 教学、n < 100、检测有序——工程排序用插入/快排 |
| 5 | 鸡尾酒排序复杂度变了？ | 没变——仍 O(n²)，只是常数因子更小（快 20-40%） |
| 6 | 怎么把冒泡变快？ | 梳排序（间隔递减，平均接近 O(n log n)）——冒泡的"希尔化" |
| 7 | 冒泡与选择交换次数？ | 冒泡最坏 n²/2；选择恒 n−1 次（每趟 1 次） |
| 8 | 移动零为什么用交换？ | 保持非零元素相对顺序 = 稳定性要求，交换 = "0 冒泡" |

> 🎯 **核心要点**：实战面试通关 = **两个思想（无交换⇔有序、稳定交换）+ 一道变形题（283 移动零）+ 一个定位（教学工具）+ 一次计数（交换次数 = 逆序对数量）**。冒泡在面试中的正确姿势是"**主动承认它工程价值低，但讲清楚它的两个思想遗产**"——诚实 + 深度，比硬吹高级。
