## 1. 知识体系导图

```text
希尔排序（Shell Sort / 缩小增量排序，1959，Donald Shell）
│
├── 核心本质 ──────────────────────────────────────────────
│   ├── = 多次不同步长的插入排序（gap 从大递减到 1）
│   ├── 分组插入：间隔 gap 的元素为一组，组内插入排序
│   ├── 大跨步就位：元素一步可跳跃 gap 个位置 → 消除远距离逆序
│   └── 最后一趟 gap=1 = 普通插入排序（此时数组已基本有序）
│
├── 关键特性 ──────────────────────────────────────────────
│   ├── 时间复杂度：最好 O(n log n) / 平均 依增量序列（≈O(n^1.3)）/ 最坏 O(n^3/2)~O(n²)
│   ├── 空间复杂度：O(1)（原地）
│   ├── 稳定性：✘ 不稳定（大跨步跳跃跳过相等元素）
│   └── 决定性因素：增量序列（gap sequence）的选择
│
├── 增量序列（六大经典 + 最新进展）──────────────────────────
│   ├── Shell 原始 n/2^k：最坏 Θ(n²)，全偶增量奇偶隔离 → 避免
│   ├── Knuth (3^k−1)/2：O(n^3/2)，教学首选
│   ├── Hibbard 2^k−1：O(n^3/2)，理论可证
│   ├── Sedgewick 双公式交错：最坏 O(n^4/3)，大数据通用库首选
│   ├── Ciura（2001）：实测最快（n ≤ 10⁴）
│   └── 2025-2026：TCS 论文（期望 O(n log²n)，有争议）；
│                   Tokuda 下界 Ω(n^1.2695)（2026 证明）；
│                   25 年来首个超越 Ciura 的进化搜索序列（2026）
│
├── 工程价值 ──────────────────────────────────────────────
│   ├── O(1) 空间 + 亚二次时间 → 嵌入式/内存受限场景
│   ├── n ≤ 10⁴ 中等规模：Ciura 序列实测效率高
│   └── 教学价值：增量序列如何影响复杂度的最佳案例
│
└── 实战与面试 ────────────────────────────────────────────
    ├── 手写：n/2 基础版（30 秒）+ Knuth 版（2 分钟）
    ├── 考点：过程模拟（软考/考研大题）、稳定性反例、复杂度与序列关系
    ├── 对比：直接插入 vs 希尔 vs 快排
    └── 谈资：2026 下界证明 / Ciura 序列 25 年首次被超越
```

## 4. 核心概念速查

| 概念 | 一句话解释 | 说明 |
|------|-----------|------|
| **希尔排序** | 按增量分组做插入排序，gap 从大缩到 1 | 插入排序的规模化改进（1959） |
| **缩小增量排序** | 希尔排序的别称 | 强调"增量不断缩小的插入排序" |
| **增量（gap）** | 组内元素的间隔距离 | 最后一趟必须为 1 才保证正确 |
| **增量序列** | gap 取值的序列 | 决定复杂度与性能的关键 |
| **分组插入** | 间隔 gap 的元素视为一组做插入排序 | 各组在同一趟交叉完成 |
| **大跨步就位** | 元素一步移动 gap 个位置 | 消除远距离逆序 → 突破 O(n²) |
| **基本有序** | 前几趟后数组接近有序 | gap=1 趟利用插入排序适应性收尾 |
| **奇偶隔离** | 全偶增量时奇偶位置元素永不比较 | Shell 原始序列退化的原因 |
| **互质** | 相邻增量没有公因数 | 好增量序列的黄金标准之一 |
| **稳定性** | 相等元素相对顺序不变 | 希尔不稳定（跨组跳跃） |

## 5. 复杂度与特性速查表

| 维度 | 最好 | 平均 | 最坏 | 说明 |
|------|:---:|:---:|:---:|------|
| 时间复杂度 | O(n log n) | 依序列（Sedgewick 实证 ≈ O(n^7/6)） | O(n^3/2)~O(n²) | 最坏取决于增量序列 |
| 空间复杂度 | O(1) | O(1) | O(1) | 原地排序 |
| 稳定性 | ✘ 不稳定 | — | — | 跨组跳跃打破相等序 |
| 适应性 | 部分 | — | — | 有序数据更快，但不如直接插入显著 |

**主要增量序列的复杂度对比**：

| 增量序列 | 最坏 | 平均（实证） | 定位 |
|------|:---:|:---:|------|
| Shell 原始（n/2^k） | Θ(n²) | — | 教学演示，工程避免 |
| Knuth / Hibbard | O(n^3/2) | ≈O(n^1.5) | 教学首选 |
| Sedgewick | O(n^4/3) | ≈O(n^7/6) | 大数据通用库 |
| Ciura | 未证明 | 实测最快 | n ≤ 10⁴ 首选 |
| Tokuda | ≥ Ω(n^1.2695)（2026 证明） | 接近 Ciura | 有下界保证 |

> 🎯 **一句话选型**：希尔排序是"**以 O(1) 空间换亚二次时间**"的经典——工程通用排序被 TimSort/双轴快排取代（无严格 O(n log n) 与稳定性），但在嵌入式、受限内存与中等规模数据场景仍有价值。**增量序列的选择是它与众不同的灵魂，其最优性至今是开放问题。**

## 6. 常见误区速查

| 误区 | 正解 |
|------|------|
| "希尔排序是另一种全新的排序" | ❌ 希尔 = 分组的直接插入排序（gap 递减的多次插入排序） |
| "希尔排序平均复杂度固定是 O(n^1.3)" | ❌ 依赖增量序列；O(n^1.3) 只是 Sedgewick 序列的经验值 |
| "gap = n/2 递减就够了" | ❌ 全偶增量 → 奇偶位置元素长期隔离 → 最坏退化 O(n²) |
| "希尔排序稳定" | ❌ 大跨步跳跃会跳过相等元素而不比较 → 不稳定（01 有反例） |
| "希尔排序最坏也接近 O(n log n)" | ❌ 最坏依序列为 O(n^3/2)~O(n²)（Shell 原始序列正是 Θ(n²)） |
| "JDK 不用它 = 它没有价值" | ❌ 嵌入式/受限内存（O(1) 空间）与中等规模数据仍有价值 |
| "增量序列研究早已尘埃落定" | ❌ 2025 TCS 期望复杂度论文、2026 Tokuda 下界证明、2026 超越 Ciura 的新序列 |
| "增量越大效率越高" | ❌ 增量下降过快/增量间可整除都会导致退化 |
