## 1. 知识体系导图

```text
堆排序（Heap Sort，1964 J. Williams）
│
├── 核心本质 ──────────────────────────────────────────────
│   ├── = 用"堆"做选择排序：堆顶即最值，O(log n) 取顶
│   ├── 数组即完全二叉树（2i+1, 2i+2, (i−1)/2 下标映射）
│   ├── 三步: 建堆 O(n) → 交换堆顶与末尾 → 堆化 O(log n)
│   └── 升序用大顶堆，降序用小顶堆（软考必考判定）
│
├── 关键特性 ──────────────────────────────────────────────
│   ├── 时间复杂度：最好 = 平均 = 最坏 O(n log n)（最坏有界！）
│   ├── 空间复杂度：O(1)（原地，无辅助数组）
│   ├── 稳定性：✘ 不稳定（堆化交换跨越元素）
│   └── 适应性：✘ 无（有序数据也一样 O(n log n)）
│
├── 家族定位 ──────────────────────────────────────────────
│   ├── 选择排序家族顶点: 线性找最小 → 树形找最小
│   ├── 1964 为弥补锦标赛排序（空间 O(n)）缺陷而生
│   └── TopK / 优先队列的地基（堆的工程形态）
│
├── 工程特性 ──────────────────────────────────────────────
│   ├── 优点: 最坏 O(n log n) 有界 + O(1) 空间 → 内存受限场景
│   ├── 缺点: 缓存不友好（跳跃访问）+ 常数大于快排
│   └── introsort 的兜底（递归深度超限转堆排）
│
├── 变体与工程 ────────────────────────────────────────────
│   ├── bottom-up heapsort（下沉比较减半）
│   ├── weak heap / smoothsort（Dijkstra，自适应变体）
│   └── 优先队列（PriorityQueue）→ TopK 的工程默认
│
└── 实战与面试 ────────────────────────────────────────────
    ├── 手写：建堆 + 排序循环（5 分钟）
    ├── 考题：215 TopK、347 前 K 高频、23 合并 K 链表
    ├── 软考：建堆过程模拟（筛选法）是必考大题
    └── 话术：最坏有界 + O(1) 空间 + 缓存劣势 + TopK 王者
```

## 4. 核心概念速查

| 概念 | 一句话解释 | 说明 |
|------|-----------|------|
| **堆** | 完全二叉树 + 堆性质（父 ≥ 子） | 数组逻辑映射，无指针 |
| **大顶堆** | 父 ≥ 子，堆顶最大 | 升序排序必须用 |
| **小顶堆** | 父 ≤ 子，堆顶最小 | 降序 / TopK 用 |
| **siftDown** | 节点与较大孩子交换下沉 | 堆化的核心操作 |
| **heapify** | 自底向上建堆 | 从最后非叶子 (n−2)/2 开始 |
| **建堆 O(n)** | 底层节点多但下沉少 | Σ h·n/2^h < 2n |
| **取顶** | 堆顶与末尾交换 + 堆化 | 每次 O(log n) |
| **完全二叉树** | 除底层外全满、底层左对齐 | 数组下标即树结构 |
| **优先队列** | 堆的抽象（PriorityQueue） | TopK 工程默认 |
| **introsort 兜底** | 快排深度超限转堆排 | 快排最坏防御 |

## 5. 复杂度与特性速查表

| 维度 | 最好 | 平均 | 最坏 | 说明 |
|------|:---:|:---:|:---:|------|
| 时间复杂度 | O(n log n) | O(n log n) | **O(n log n)** | 三情形相同（最坏有界！） |
| 空间复杂度 | O(1) | O(1) | O(1) | 原地（数组即树） |
| 稳定性 | ✘ 不稳定 | — | — | 堆化交换跨越元素 |
| 适应性 | ✘ 无 | — | — | 有序数据不减复杂度 |

**堆排 vs 快排 vs 归并**：

| 维度 | 堆排 | 快排 | 归并 |
|------|:---:|:---:|:---:|
| 最坏 | **O(n log n)** | O(n²)（可防） | **O(n log n)** |
| 平均 | O(n log n) 常数大 | O(n log n) 常数最小 | O(n log n) 常数中 |
| 空间 | **O(1)** | O(log n) 栈 | O(n) 辅助 |
| 稳定 | ✘ | ✘ | ✔ |
| 缓存 | 差（跳跃访问） | 好（原地顺序） | 中 |
| 适用 | 最坏有界 + 内存受限 | 通用数组（工程默认） | 稳定/链表/外部 |

> 🎯 **一句话选型**：**要最坏 O(n log n) 有界且内存受限（O(1)）→ 堆排；通用数组平均性能 → 快排；稳定/链表/外部 → 归并**。堆排的工程角色是"兜底者"——introsort 的深度超限转堆排，正是它最坏有界 + 原地特性的最好归宿。

## 6. 常见误区速查

| 误区 | 正解 |
|------|------|
| "建堆是 O(n log n)" | ❌ 自底向上筛选是 O(n)——底层节点多但下沉少，Σ h·n/2^h < 2n |
| "堆排序最好情况 O(n)" | ❌ 无适应性——有序输入也 O(n log n)（三情形相同） |
| "堆排序稳定" | ❌ 堆化交换跨越元素 → 不稳定（与快排/选择同源） |
| "升序排序用小顶堆" | ❌ 升序用**大顶堆**（每次取最大放末尾）；小顶堆用于降序/TopK |
| "堆排序空间 O(log n)" | ❌ O(1)——数组即树，无辅助结构（递归都不需要） |
| "堆排序缓存友好" | ❌ 堆化跳跃访问父子（下标 ×2），缓存命中率低于快排 |
| "堆排序适合小数组" | ❌ 常数开销大，小数据用插入/选择更简单 |
| "堆排序适合链式存储" | ❌ 完全二叉树依赖数组下标，链表上效率大降 |
| "堆排序只能排最值" | ❌ 完整排序 + TopK + 优先队列 + introsort 兜底，四重身份 |
| "堆排序和选择排序无关" | ❌ 堆排序 = 用堆优化"找最值"的选择排序（家族顶点） |
