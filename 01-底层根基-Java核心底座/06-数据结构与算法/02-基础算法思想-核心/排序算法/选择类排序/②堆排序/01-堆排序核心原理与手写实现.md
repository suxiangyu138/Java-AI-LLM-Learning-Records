## 1. 堆模型：数组即完全二叉树

### 1.1 完全二叉树的下标映射

```text
数组 [a₀, a₁, a₂, a₃, a₄, a₅, a₆] 逻辑上是一棵完全二叉树:

             a₀
          /      \
       a₁          a₂
      /  \        /  \
    a₃    a₄    a₅    a₆

下标映射（核心公式）:
  左孩子:   2i + 1
  右孩子:   2i + 2
  父节点:   (i − 1) / 2
  最后非叶子: (n − 2) / 2
```

### 1.2 堆性质与排序方向

```text
大顶堆: 每个父节点 ≥ 孩子 → 堆顶 = 全局最大
小顶堆: 每个父节点 ≤ 孩子 → 堆顶 = 全局最小

升序排序 → 大顶堆（每次把最大取到末尾，末尾从后往前有序）
降序排序 → 小顶堆（每次把最小取到末尾）
⚠️ 软考常考: "升序排序用大顶堆还是小顶堆？" → 大顶堆！
```

> 🎯 **核心动作三连**：**建堆（自底向上 siftDown）→ 交换（堆顶 ↔ 末尾）→ 堆化（根节点 siftDown）**。与选择排序对比——选择是"线性扫描找最值 O(n)"，堆是"堆顶即最值 O(1) 读取、O(log n) 维护"，**同样的'选最值'框架，复杂度从 O(n²) 降到 O(n log n)**。

## 2. 基本实现：siftDown + heapify + 排序循环（5 分钟默写）

### 2.1 完整代码（面试标准答案）

```java
/**
 * 堆排序（大顶堆，升序）
 * 时间 O(n log n)（三情形相同），空间 O(1)，不稳定
 */
public void heapSort(int[] arr) {
    int n = arr.length;

    // ① 建堆：自底向上 siftDown（从最后非叶子开始）
    for (int i = (n - 2) / 2; i >= 0; i--) {
        siftDown(arr, i, n);
    }

    // ② 排序：反复取堆顶到末尾
    for (int i = n - 1; i > 0; i--) {
        int tmp = arr[0]; arr[0] = arr[i]; arr[i] = tmp;  // 堆顶 ↔ 末尾
        siftDown(arr, 0, i);                              // 堆化 [0..i-1]
    }
}

/** 下沉：节点 i 与较大孩子交换，直到满足堆性质（heapSize 为有效堆大小） */
private void siftDown(int[] arr, int i, int heapSize) {
    while (true) {
        int left = 2 * i + 1, right = 2 * i + 2;
        int largest = i;                                 // ① 假设自己最大
        if (left < heapSize && arr[left] > arr[largest]) largest = left;
        if (right < heapSize && arr[right] > arr[largest]) largest = right;
        if (largest == i) break;                         // ② 已满足堆性质
        int tmp = arr[i]; arr[i] = arr[largest]; arr[largest] = tmp;  // ③ 与较大孩子交换
        i = largest;                                     // ④ 继续下沉
    }
}
```

### 2.2 三个关键实现细节

```text
① 建堆起点 (n−2)/2: 最后非叶子节点——
   叶子（> (n−2)/2）没有孩子，无需下沉
② siftDown 用循环而非递归: 避免递归栈，空间严格 O(1)
③ 排序循环 i 递减: heapSize 每轮减 1——
   已交换到末尾的元素永不参与堆化
```

> 💡 **记忆技巧**：堆排序 = "**建堆（后半段下沉）+ 取顶（头尾交换 + 根下沉）**"。siftDown 是唯一的核心函数，建堆和排序循环都调它——**会写 siftDown 就写完了堆排序的 70%**。

## 3. 建堆 O(n) 的数学证明

### 3.1 直觉：底层节点多但下沉少

```text
自底向上建堆: 每个非叶子节点最多下沉到叶子
  高度为 h 的节点: 最多下沉 h 次
  高度为 h 的节点数: ≈ n / 2^(h+1)（完全二叉树性质）

总下沉次数:
  S = Σ h · (n/2^(h+1))，h 从 1 到 log₂n
    = (n/2) · Σ h/2^h
    < (n/2) · 2            （Σ h/2^h = 2 的经典级数）
    = O(n) ✓

对比"自顶向下插入建堆"（O(n log n)）:
  自顶向下: 每个节点从根下沉到目标深度 → Σ n·log n
  自底向上: 节点从自身下沉 → 底层节点（占一半）几乎不下沉
  → 差一个数量级，这就是"筛选法"的威力
```

### 3.2 面试推导句

```text
"建堆 O(n) 的直觉：高度为 h 的节点有 n/2^(h+1) 个、最多下沉 h 次，
总下沉次数 Σ h·n/2^(h+1) < 2n → O(n)。
自顶向下插入建堆是 O(n log n)——差在'节点从根开始'与'从自身开始'。"
```

> 🎯 **面试必答**："建堆 O(n) 不是 O(n log n)——**底层一半节点几乎不下沉，下沉总次数 Σ h·n/2^(h+1) < 2n**。这个证明是堆排序面试的第一个必考细节，能推导的比背结论的高级。"

## 4. 逐步推演：n=8 全流程

**数据**：[8, 3, 5, 1, 9, 2, 6, 4]（升序排序，大顶堆）

**阶段一：建堆（从下标 3 开始自底向上）**

| 下标 | 操作 | 数组状态 |
|:---:|------|------|
| 初始 | — | [8,3,5,1,9,2,6,4] |
| 3 (值1) | 孩子 7(4) > 1 → 下沉 | [8,3,5,4,9,2,6,1] |
| 2 (值5) | 孩子 6(6) > 5 → 下沉 | [8,3,6,4,9,2,5,1] |
| 1 (值3) | 孩子 4(9) > 3 → 下沉到 4 | [8,9,6,4,3,2,5,1] |
| 0 (值8) | 孩子 1(9) > 8 → 下沉到 1 | [9,8,6,4,3,2,5,1] ✓ 大顶堆 |

**阶段二：排序（每轮交换堆顶与末尾 + 堆化）**

| 轮 | 操作 | 数组状态 |
|:---:|------|------|
| 1 | 9↔1，堆化 [0..6] | [8,4,6,1,3,2,5,**9**] |
| 2 | 8↔5，堆化 [0..5] | [6,4,5,1,3,2,**8,9**] |
| 3 | 6↔2，堆化 [0..4] | [5,4,3,1,2,**6,8,9**] |
| 4 | 5↔2，堆化 [0..3] | [4,2,3,1,**5,6,8,9**] |
| 5 | 4↔1，堆化 [0..2] | [3,2,1,**4,5,6,8,9**] |
| 6 | 3↔1，堆化 [0..1] | [2,1,**3,4,5,6,8,9**] |
| 7 | 2↔1 | [1,2,3,4,5,6,8,9] ✓ |

> 🎯 **从推演看结构**：每轮"堆顶 ↔ 末尾"后，末尾元素**永久就位**（它就是当前最大值）——与选择排序"每趟固定一个最值"完全同构，只是"找最值"从 O(n) 扫描变成 O(log n) 堆化。**堆排序就是选择排序的"树形加速版"，这张推演表就是证据**。

## 5. 复杂度推导：三情形相同的结构原因

### 5.1 精确分析

```text
建堆: O(n)（见第 3 节证明）
排序: n−1 轮 × 每轮 siftDown O(log n) = O(n log n)
总: O(n) + O(n log n) = O(n log n)

三情形相同的原因:
  建堆与排序循环的结构与数据无关——
  不管输入是否有序，堆的性质与交换路径完全相同
  → 最好 = 平均 = 最坏 = O(n log n)（唯一与数据无关的 O(n log n) 排序）
```

### 5.2 常数分析（为什么平均比快排慢）

```text
堆排: 每轮堆化 ~2·log₂n 次比较（每层 2 次：两孩子比 + 与父比）
      + 交换跨越下标 ×2 的父子（缓存不友好）
快排: 平均 ~1.39·n·log₂n 次比较 + 顺序扫描（缓存友好）

实际数据（2025-2026 基准）:
  堆排在 O(n log n) 家族中常数最大——
  但"最坏有界 + O(1) 空间"是快排/归并给不了的组合
  → 工程角色 = 兜底者（introsort 深度超限转堆排）
```

> 🎯 **面试必答句**："堆排序 O(n log n) 三情形相同——**结构决定复杂度，与数据无关**；空间 O(1)；不稳定。平均常数大于快排（每层 2 次比较 + 缓存跳跃），但'最坏有界 + 原地'的组合是它独有的——introsort 的兜底就选它。"

## 6. 稳定性分析：为什么不稳定（含反例）

### 6.1 反例演示（大顶堆）

**数据**：[5a, 8, 5b, 1]（5a 在 5b 前，相等，升序排序）

| 阶段 | 操作 | 数组状态 |
|:---:|------|------|
| 初始 | — | [5a, 8, 5b, 1] |
| 建堆 | 8 上浮到根 | [8, 5a, 5b, 1] |
| 第 1 轮 | 8↔1，堆化 | [5b, 5a, 1, **8**] |
| 第 2 轮 | 5b↔1，堆化 | [5a, 1, **5b, 8**] |
| 完成 | 5a↔1 | [1, 5a, 5b, 8] |

**结果**：虽然最终 5a 在 5b 前，但中间 5b 曾越过 5a（第 1 轮堆化后 5b 到了 5a 前面）——**对多组相等元素构造，相对顺序必然被打乱**。

```text
不稳定机制: siftDown 的交换沿"父 ↔ 较大孩子"路径跨越任意距离
  → 相等元素在堆化过程中被越过（与快排/选择的跨距离交换同源）
  → 任何基于交换的堆操作都无法稳定

⚠️ 面试表达: "堆排序不稳定——堆化交换跨越父子路径，
   相等元素的相对顺序无法保证。要稳定选归并。"
```

## 7. 手写易错点与调试技巧

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 建堆起点写 `n/2` | `(n−2)/2`（最后非叶子） | 少建一层 |
| 2 | 左右孩子下标越界 | `left < heapSize` 判断 | 数组越界 |
| 3 | 忘 `break` 提前退出 | `largest == i` 时退出 | 死循环/多余下沉 |
| 4 | 堆化范围含已排序区 | 传 `heapSize = i`（递减） | 已就位元素被扰动 |
| 5 | 升序用小顶堆 | 升序用**大顶堆** | 排成降序 |
| 6 | siftDown 用递归 | 用循环 | 递归栈（空间非 O(1)） |
| 7 | 比较用 `>=` | `>`（严格大于取较大孩子） | 无实质影响但语义错 |

**调试技巧**：

```text
① 小样本验证: n=8 随机数组，对照本文件推演表逐步核对
② 断言验证: 排序完成后 assert 升序
③ 堆性质验证: 打印建堆结果，检查每个父 ≥ 子（大顶堆）
④ 边界验证: 空数组、单元素、全相等元素（应原地不动或正确排序）
```

> 🎯 **核心要点**：堆排序通关四件事——**① 5 分钟默写 siftDown + 建堆 + 排序循环**（siftDown 是灵魂，建堆起点 (n−2)/2）；**② 建堆 O(n) 证明张嘴就来**（Σ h·n/2^(h+1) < 2n）；**③ 三特性脱口而出**（最坏有界、O(1) 空间、不稳定 + 缓存差）；**④ 选型定位清晰**（TopK 王者 + introsort 兜底 + 内存受限场景）。**它是唯一"最坏有界 + 原地"的排序，也是选择家族从 O(n²) 到 O(n log n) 的顶点**——这两点就是它 60 年不衰的全部理由。
