## 1. 实战题：215 数组中的第 K 个最大元素（堆版）

### 1.1 题目与思路

**题**：无序数组第 K 大（n ≤ 10⁵，K 任意）。

**堆版双解**：

```text
解法一（最小堆 TopK）: 维护大小 K 的最小堆 → O(n log K) + O(K) 空间
解法二（QuickSelect）: 平均 O(n)（215 最优解，见 ②快速排序 03 文件）

选型: 面试两版都给——
  K 小 / 空间受限 → 堆版；追求平均最优 → QuickSelect
```

### 1.2 堆版完整代码

```java
/**
 * LeetCode 215. 数组中的第 K 个最大元素（最小堆 TopK 版）
 * 时间 O(n log K)，空间 O(K)
 */
public int findKthLargest(int[] nums, int k) {
    PriorityQueue<Integer> heap = new PriorityQueue<>();   // 最小堆
    for (int x : nums) {
        if (heap.size() < k) {
            heap.offer(x);
        } else if (x > heap.peek()) {
            heap.poll();
            heap.offer(x);                  // 堆顶 = 当前第 K 大（门槛）
        }
    }
    return heap.peek();                     // 门槛即第 K 大
}
// 推演 [3,2,1,5,6,4]，k=2：
//   入 3,2 → 堆 [2,3]；1 < 2 跳过；5 > 2 → [3,5]
//   6 > 3 → [5,6]；4 < 5 跳过 → 返回 5 ✓（第 2 大）
```

> 🎯 **堆版的讲解亮点**："堆顶是'第 K 大的门槛'——**这个语义让最小堆 TopK 天然适合流式数据**（元素逐个到达也能维护）。讲 215 时点出'门槛'思维，比背代码有深度。"

## 2. 实战题：347 前 K 个高频元素

### 2.1 题目与思路

**题**：返回数组中出现频率前 K 高的元素。

**两步走**：哈希计数（O(n)）→ 最小堆 TopK（按频率比较，O(n log K)）：

```java
/**
 * LeetCode 347. 前 K 个高频元素
 * 时间 O(n log K)，空间 O(n)
 */
public int[] topKFrequent(int[] nums, int k) {
    // ① 哈希统计频率
    Map<Integer, Integer> freq = new HashMap<>();
    for (int x : nums) freq.merge(x, 1, Integer::sum);

    // ② 最小堆（按频率升序，堆顶 = 当前第 K 高频的门槛）
    PriorityQueue<Integer> heap = new PriorityQueue<>(
        (a, b) -> freq.get(a) - freq.get(b));
    for (int key : freq.keySet()) {
        heap.offer(key);
        if (heap.size() > k) heap.poll();   // 超容 → 弹最低频
    }

    int[] result = new int[k];
    for (int i = 0; i < k; i++) result[i] = heap.poll();
    return result;
}
// 推演 [1,1,1,2,2,3]，k=2：
//   freq: {1:3, 2:2, 3:1}
//   入 1,2 → 堆 [2,1]（按频率）；入 3 → 堆 [3,2,1] → 弹 3（频率 1）
//   返回 [1,2]（频率 3、2）✓
```

> 💡 **变体意识**："347 = **计数 + TopK 的组合题**——451 全量按频重排（频次桶）、347 取前 K（堆）。同一套计数，两个 TopK 容器（堆/频次桶）的选型对比是面试加分点。"

## 3. 实战题：23 合并 K 个升序链表（堆版）

### 3.1 题目与思路

**题**：K 个升序链表 → 一个升序链表（O(N log K)）。

**堆版 = K 路归并**（详见多路归并专题）：K 个头入最小堆 → 弹最小 → 同路补位：

```java
/**
 * LeetCode 23. 合并 K 个升序链表（最小堆 = K 路归并）
 * 时间 O(N log K)，空间 O(K)
 */
public ListNode mergeKLists(ListNode[] lists) {
    PriorityQueue<ListNode> heap = new PriorityQueue<>((a, b) -> a.val - b.val);
    for (ListNode h : lists)
        if (h != null) heap.offer(h);           // ① K 个头入堆

    ListNode dummy = new ListNode(0), tail = dummy;
    while (!heap.isEmpty()) {
        ListNode node = heap.poll();            // ② 弹全局最小
        tail.next = node;
        tail = node;
        if (node.next != null) heap.offer(node.next);   // ③ 同路补位
    }
    return dummy.next;
}
```

> 🎯 **23 题与堆的深度绑定**："**堆 = 多路归并的选最小引擎**——K 路归并每次选最小 O(log K)，堆是工程默认实现（败者树是常数优化）。23 题把'堆'与'归并'两个考点一次考完，是堆的三大实战舞台之首。"

## 4. 实战题：912 排序数组（堆排版）

### 4.1 完整实现（复用 01 文件模板）

```java
/**
 * LeetCode 912. 排序数组（堆排版）
 * 最坏 O(n log n) 有界 + O(1) 空间 —— 912 的标准正解之一
 */
public int[] sortArray(int[] nums) {
    int n = nums.length;
    for (int i = (n - 2) / 2; i >= 0; i--) siftDown(nums, i, n);   // 建堆
    for (int i = n - 1; i > 0; i--) {
        int t = nums[0]; nums[0] = nums[i]; nums[i] = t;            // 取顶
        siftDown(nums, 0, i);                                       // 堆化
    }
    return nums;
}
// siftDown 见 01 文件（循环版，比较左右孩子选较大者下沉）
```

### 4.2 912 三版选型论述

```text
快排: 平均最快（含退化防御）→ 面试首选
归并: 稳定无退化 → 稳定需求时
堆排: 最坏有界 + O(1) 空间 → 内存受限 / 最坏可预测
  （912 上堆排 O(n log n) 严格达标，但常数大于快排）

⚠️ 面试表达: "912 三个正解都能过——
   快排最快、归并稳定、堆排最坏有界且零额外空间。
   写堆排展示'最坏有界'意识，是选型论述的加分项。"
```

## 5. 面试话术三连

### 5.1 三连话术（背下来）

```text
Q1: "堆排序的原理与复杂度？"
A: "建堆 O(n) + n 次取顶 O(log n) → 总 O(n log n) 三情形相同。
   空间 O(1)（数组即完全二叉树）；不稳定。
   升序用大顶堆：每次堆顶与末尾交换，末尾永久就位。"

Q2: "建堆为什么是 O(n)？"
A: "自底向上筛选：高度 h 的节点 n/2^(h+1) 个、最多下沉 h 次，
   总下沉 Σ h·n/2^(h+1) < 2n → O(n)。
   自顶向下插入建堆才是 O(n log n)。"

Q3: "什么时候用堆排序？"
A: "三个场景：内存受限（O(1) 空间无递归栈）；
   最坏必须 O(n log n)（快排退化不可接受）；
   introsort 兜底（C++ std::sort / JDK 深度超限转堆排）。
   通用排序不用它——常数大 + 缓存不友好，快排/归并更好。"
```

### 5.2 30 秒手写版本（siftDown 核心）

```java
// 面试手写核心（2 分钟内：建堆 + 排序循环 + siftDown）
void heapSort(int[] a) {
    for (int i = (a.length - 2) / 2; i >= 0; i--) sink(a, i, a.length);
    for (int i = a.length - 1; i > 0; i--) {
        int t = a[0]; a[0] = a[i]; a[i] = t;
        sink(a, 0, i);
    }
}
void sink(int[] a, int i, int n) {
    while (2 * i + 1 < n) {
        int c = 2 * i + 1;
        if (c + 1 < n && a[c + 1] > a[c]) c++;
        if (a[i] >= a[c]) break;
        int t = a[i]; a[i] = a[c]; a[c] = t;
        i = c;
    }
}
```

## 6. 软考与笔试考点：建堆过程模拟

### 6.1 建堆过程模拟题（必考大题）

**真题样式（软考）**：对序列 [15, 9, 7, 8, 20, -1, 7, 4] 用筛选法建初始小根堆，写出结果。

| 下标 | 操作（小根堆：父 ≤ 子，较小者上浮） | 数组状态 |
|:---:|------|------|
| 初始 | — | [15, 9, 7, 8, 20, -1, 7, 4] |
| 3 (值8) | 孩子 7(4) < 8 → 8 下沉 | [15, 9, 7, 4, 20, -1, 7, 8] |
| 2 (值7) | 孩子 5(-1) < 7 → 7 下沉 | [15, 9, -1, 4, 20, 7, 7, 8] |
| 1 (值9) | 孩子 3(4) < 9 → 9 下沉到 3，再与孩子 7(8) 比 → 下沉到 7 | [15, 4, -1, 8, 20, 7, 7, 9] |
| 0 (值15) | 孩子 1(4), 2(-1) → -1 上浮，15 下沉到 2，再与孩子 5(7) 比 → 下沉到 5 | [-1, 4, 7, 8, 20, 15, 7, 9] ✓ |

**答案**：[-1, 4, 7, 8, 20, 15, 7, 9]（软考标准答案，已逐步骤验证）。

**答题技巧**：

```text
① 起点 = 最后一个非叶子 (n−2)/2 = 3，自底向上逐层筛选
② 小根堆: 与"较小的孩子"比较，父 > 子则下沉
③ 每步写"下沉后的完整数组"——中间状态是评分点
④ 陷阱: 大顶堆 vs 小顶堆的"上浮方向"别搞反（升序排序用大顶堆）
```

### 6.2 其他题型

| 考点 | 题型 | 要点 |
|------|------|------|
| 稳定性判断 | 概念题 | 口诀"冒插归基"不含堆——堆化交换不稳定 |
| 建堆复杂度 | 计算题 | O(n)（Σ h·n/2^h < 2n），不是 O(n log n) |
| 堆判定 | 判断题 | 给定数组判断是否大顶堆/小顶堆（逐父比子） |
| 插入/删除 | 大题 | 插入尾上浮 O(log n)；删根尾补 + 下沉 O(log n) |
| 与选择排序 | 辨析题 | 同为选最值家族：线性 O(n²) vs 树形 O(n log n) |
| TopK 选型 | 选择题 | 流式/空间受限 → 最小堆；内存内 → QuickSelect |

## 7. 高频追问与标准回答

| # | 追问 | 标准回答 |
|:---:|------|---------|
| 1 | 为什么堆排序最坏也是 O(n log n)？ | 建堆与取顶的结构与数据无关——复杂度与分布解耦 |
| 2 | 建堆为什么快？ | 底层节点（占一半）几乎不下沉，总下沉 < 2n |
| 3 | 升序为什么用大顶堆？ | 每次取最大放末尾，末尾从后往前有序 |
| 4 | 堆排序为什么缓存差？ | 下沉路径下标 ×2 跳跃，父子相距远 → 缓存未命中 |
| 5 | 堆排序 vs 快排？ | 快排平均更快（缓存好）；堆排最坏有界 + O(1) 空间 |
| 6 | TopK 为什么用最小堆？ | 堆顶 = 第 K 大门槛，空间 O(k) 支持流式大数据 |
| 7 | 堆和优先队列什么关系？ | PriorityQueue = 堆的工程形态（offer 上浮/poll 下沉） |
| 8 | introsort 里堆排的角色？ | 深度超限转堆排 → 最坏兜底（C++ std::sort / JDK 深度 64） |
| 9 | 堆排序适合小数组吗？ | 不适合——常数开销大，小数据用插入/选择 |
| 10 | 2025-2026 堆排表现？ | 跨语言基准中最一致的 O(n log n)（与数据分布无关） |

> 🎯 **核心要点**：实战面试通关 = **三题（215 门槛思维 + 347 计数组合 + 23 多路归并）+ 一模拟（软考建堆，起点 (n−2)/2 自底向上）+ 话术三连（复杂度/建堆证明/场景）**。堆排序在面试中的定位是"**手撕第二优先级 + 建堆证明必答 + TopK 方法论加分**"——把"堆 = 优先队列 = TopK 引擎 = 工业排序保险丝"讲成一条线，选择家族就圆满了。
