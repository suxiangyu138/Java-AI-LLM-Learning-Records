## 1. 220. 存在重复元素 III（值域分桶）

### 1.1 题目与思路

```
|nums[i]-nums[j]| ≤ t 且 |i-j| ≤ k
桶宽 t+1：同桶必满足、邻桶查边界（01 模块 5 节）
```

### 1.2 完整代码

```java
/**
 * LeetCode 220. 存在重复元素 III
 */
public boolean containsNearbyAlmostDuplicate(int[] nums, int k, int t) {
    Map<Long, Long> bucket = new HashMap<>();
    long w = (long) t + 1;

    for (int i = 0; i < nums.length; i++) {
        long id = bucketId(nums[i], w);
        if (bucket.containsKey(id)) return true;         // ⚠️ 同桶必满足
        if (bucket.containsKey(id - 1) && nums[i] - bucket.get(id - 1) <= t)
            return true;                                 // 邻桶下界检查
        if (bucket.containsKey(id + 1) && bucket.get(id + 1) - nums[i] <= t)
            return true;                                 // 邻桶上界检查

        bucket.put(id, (long) nums[i]);
        if (i >= k) bucket.remove(bucketId(nums[i - k], w));   // ⚠️ 滑窗
    }
    return false;
}

private long bucketId(long x, long w) {
    return x >= 0 ? x / w : (x + 1) / w - 1;             // 负数向下取整
}
// 推演 nums=[1,2,3,1], k=3, t=0：
//   w=1：1→桶1；2→桶2（邻桶检查 |2-1|>0 ✗）；3→桶3
//   i=3：1→桶1 已存在 → true ✓（下标差 3 ≤ 3）
// ⚠️ 复杂度：O(n)（每元素 O(1) 桶操作）
// ⚠️ 面试必答："220 = 桶宽 t+1 值域分桶——
//   同桶命中、邻桶边界检查、隔桶排除；
//   滑窗用桶移除维护 k 约束。"
```

## 2. 164. 最大间距（鸽巢原理）

### 2.1 题目与思路

```
排序后相邻元素最大差值（O(n)）
桶 + 鸽巢原理：
  下界 gap = ceil((max-min)/(n-1))
  桶宽 gap → 桶内差 < gap ≤ 答案 → 桶内不可能是答案
  → 只查相邻非空桶
⚠️ 01 模块 3 节定理推导；基数排序版见基数/02
```

### 2.2 完整代码

```java
/**
 * LeetCode 164. 最大间距（桶 + 鸽巢原理）
 */
public int maximumGap(int[] nums) {
    int n = nums.length;
    if (n < 2) return 0;

    int min = Integer.MAX_VALUE, max = Integer.MIN_VALUE;
    for (int x : nums) { min = Math.min(min, x); max = Math.max(max, x); }
    if (max == min) return 0;

    // ⚠️ 理论下界：n 个元素 n-1 个间隔的平均值
    int gap = (int) Math.ceil((double) (max - min) / (n - 1));
    int bucketCount = (max - min) / gap + 1;

    int[] bucketMin = new int[bucketCount];
    int[] bucketMax = new int[bucketCount];
    boolean[] used = new boolean[bucketCount];
    Arrays.fill(bucketMin, Integer.MAX_VALUE);

    for (int x : nums) {                     // 分桶（只记 min/max）
        int idx = (x - min) / gap;
        used[idx] = true;
        bucketMin[idx] = Math.min(bucketMin[idx], x);
        bucketMax[idx] = Math.max(bucketMax[idx], x);
    }

    int best = 0, prevMax = min;
    for (int i = 0; i < bucketCount; i++) {
        if (!used[i]) continue;
        best = Math.max(best, bucketMin[i] - prevMax);   // ⚠️ 桶间差
        prevMax = bucketMax[i];
    }
    return best;
}
// 推演 [3,6,9,1]：gap=ceil(8/3)=3 → 桶宽 3
//   桶 0：[1]；桶 1：[3]；桶 2：[6]；桶 3：[9]
//   桶间差：3-1=2? 3-1=2, 6-3=3, 9-6=3 → 最大 3 ✓
// ⚠️ 复杂度：O(n) 时间 + O(n) 空间
// ⚠️ 面试必答："164 = 鸽巢原理——
//   答案 ≥ gap（平均间隔），桶宽 gap →
//   桶内不可能是答案 → 只查桶间。"
```

## 3. 349. 两个数组的交集（桶计数）

### 3.1 题目与思路

```
两数组交集（去重）
桶计数：值域有限（10³ 内）→ 计数数组标记
⚠️ 或 Set 判重（值域大时）
```

### 3.2 完整代码

```java
/**
 * LeetCode 349. 两个数组的交集（桶计数）
 */
public int[] intersection(int[] nums1, int[] nums2) {
    boolean[] in1 = new boolean[1001];       // ⚠️ 值域 0..1000
    for (int x : nums1) in1[x] = true;

    Set<Integer> result = new HashSet<>();
    for (int x : nums2)
        if (in1[x]) result.add(x);           // ⚠️ 在 nums1 中 → 交集

    return result.stream().mapToInt(Integer::intValue).toArray();
}
// 推演 [1,2,2,1] ∩ [2,2] → {2} ✓
// ⚠️ 复杂度：O(n+m)，空间 O(值域)
// ⚠️ 变体：350 交集 II（保留重复次数 → 计数 min 次）
// ⚠️ 面试必答："349 = 布尔桶标记——
//   值域小（0..1000）用数组；值域大用 Set。"
```

## 4. 912. 排序数组（桶排序版）

### 4.1 题目与思路

```
数组排序（桶排序版）——展示完整实现
⚠️ 912 值域 [-50000, 50000] → 可分桶
```

### 4.2 完整代码

```java
/**
 * LeetCode 912. 排序数组（桶排序版）
 * ⚠️ 桶数 = √n 量级 + 桶内排序
 */
public int[] sortArray(int[] nums) {
    int n = nums.length;
    int min = Integer.MAX_VALUE, max = Integer.MIN_VALUE;
    for (int x : nums) { min = Math.min(min, x); max = Math.max(max, x); }

    // 桶数 ≈ n/10（或 √n）——桶内少量元素
    int bucketCount = Math.max(1, n / 10);
    double width = (double) (max - min + 1) / bucketCount;

    List<Integer>[] buckets = new List[bucketCount];
    for (int i = 0; i < bucketCount; i++) buckets[i] = new ArrayList<>();
    for (int x : nums) {
        int idx = Math.min((int) ((x - min) / width), bucketCount - 1);  // ⚠️ 边界
        buckets[idx].add(x);
    }

    int idx = 0;
    for (List<Integer> bucket : buckets) {
        Collections.sort(bucket);            // 桶内排序
        for (int x : bucket) nums[idx++] = x;   // 按桶序合并
    }
    return nums;
}
// ⚠️ 复杂度：均匀时 O(n)；退化 O(n log n)
// ⚠️ 面试必答："912 桶版 = 分桶 + 桶内排序——
//   均匀数据线性、极端数据退化；
//   与计数/基数版的选型对比见基数/02。"
```

## 5. 347/451. 频次桶回顾

### 5.1 频次桶模式

```
频次桶（347/451）vs 值域桶（220/164）：
  频次桶：下标 = 频次（1..n），桶内 = 元素
  值域桶：下标 = 值域区间，桶内 = 元素

⚠️ 共同点：桶 = "按维度索引"的结构
  频次维度（TopK）或值域维度（差值约束）

⚠️ 面试必答：
"桶的两种维度——频次桶（下标=频次，
 免排序取 TopK）与值域桶（下标=值域，
 差值/分布约束）。识别'维度'是关键。"
```

### 5.2 完整代码导航

```
347 前 K 高频（频次桶）：见计数/02 完整实现
```

## 6. 桶排序方法论总结

### 6.1 解题框架

```
① 识别：均匀分布排序 / 差值约束 / 频次统计
② 选桶维度：
   频次 → 频次桶（347）
   值域 → 值域桶（220/164）
   排序 → 分桶 + 桶内排序（912）
③ 设计：桶宽/桶数（t+1 / gap / n 量级）
④ 复杂度：均匀 O(n)、退化 O(n log n)

⚠️ 识别信号：
  "差值 ≤ t" → 桶宽 t+1
  "最大间距" → 鸽巢 + 桶间
  "按频率" → 频次桶
  "线性排序" → 分桶
```
