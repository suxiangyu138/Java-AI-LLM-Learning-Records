## 1. 桶排序的本质

### 1.1 核心思想

```
桶排序 = 分而治之的排序：
  ① 把数据按值域分到 k 个桶
  ② 桶内排序（任意排序）
  ③ 按桶顺序合并

⚠️ 关键：桶间天然有序 → 只需桶内排序

⚠️ 面试必答：
"桶排序 = 分桶 + 桶内排序——
 桶间有序免比较，总复杂度取决于
 桶内排序与分布均匀性。"
```

### 1.2 适用条件

```
① 数据均匀分布（随机数）
② 值域已知可分桶
⚠️ 非均匀 → 全进一桶 → 退化为桶内排序

⚠️ 面试必答：
"桶排序前提是'均匀分布'——
 分布不均匀时退化为 O(n log n)（全进一桶）。"
```

## 2. 桶的划分设计

### 2.1 桶的数量与宽度

```
桶数 k 与桶宽 w 的关系：
  w = (max - min) / k（等宽分桶）

⚠️ 设计权衡：
  k 大 → 桶内少 → 排序快，但桶多占空间
  k 小 → 桶内多 → 排序慢
  最优：k ≈ n（每桶平均 1 个元素）

⚠️ 面试必答：
"桶数取 ≈ n 最优——每桶期望 1 个元素，
 桶内排序退化为常数。k 太大空间浪费、
 k 太小桶内拥挤。"
```

### 2.2 分桶公式

```java
/** 等宽分桶：元素 x → 桶下标 */
int bucketIndex(int x, int min, double width, int k) {
    return (int) ((x - min) / width);        // ⚠️ 等宽映射
}
// 边界：x == max 时下标 = k → 特殊处理（归入最后一个桶）
// ⚠️ 面试表达："分桶公式 = (x-min)/width——
//   等宽映射保证桶间有序（桶 i 全部 ≤ 桶 i+1）。"
```

## 3. 期望复杂度的严格分析

### 3.1 均匀分布的期望

```
均匀分布 + k = n 个桶：
  每桶期望元素数 = n/k = 1

桶内排序（如插入排序）期望代价：
  桶 i 有 Xᵢ 个元素，E[Xᵢ] = 1
  E[桶内代价] = E[Xᵢ²]（插入排序 O(X²)）
  E[Xᵢ²] = Var(Xᵢ) + E[Xᵢ]² ≈ 1 + 1 = 2（泊松近似）

总期望 = Σ E[桶内] + 分桶 O(n) = O(n)

⚠️ 面试必答：
"均匀分布下每桶期望 1 个元素——
 桶内排序期望 O(1)，总 O(n)。
 关键论证：E[X²] 有界（二项/泊松近似）。"
```

### 3.2 最坏复杂度

```
最坏：所有元素进同一桶 → 桶内排序决定
  O(n log n)（桶内用快排/归并）

⚠️ 面试必答：
"桶排序最好 O(n)（均匀）、最坏 O(n log n)
 （全进一桶）——分布决定复杂度。"
```

## 4. 桶内排序的选型

### 4.1 选型表

| 桶内元素数 | 推荐排序 | 原因 |
|:---:|------|------|
| 少（≤ 16） | 插入排序 | 小数组最快 |
| 中等 | 快排 | 通用 |
| 未知 | 递归桶排序 | 自适应 |

```
⚠️ 面试必答：
"桶内排序选型看'期望元素数'——
 少用插入（常数小）、多则快排、
 或递归桶排序（自适应）。"
```

### 4.2 递归桶排序

```
桶内元素仍多 → 再分桶（递归）
  → 与基数排序的"多位"思想呼应

⚠️ 面试表达：
"递归桶排序 = 分桶的自适应深度——
 分布好的数据深度浅（快）、
 分布差的数据深度深（兜底）。"
```

## 5. 值域分桶：220 的技巧

### 5.1 220 存在重复 III

```
|nums[i] - nums[j]| ≤ t 且 |i - j| ≤ k（滑窗 + 值域约束）
值域分桶：桶宽 = t+1 → 同桶必满足差值约束！
  ⚠️ 同桶 → 差 ≤ t ✓
  ⚠️ 相邻桶 → 需检查边界（可能满足）
  ⚠️ 更远桶 → 不可能（差 > t）

⚠️ 面试必答：
"220 的桶宽取 t+1——同桶必满足、
 邻桶检查边界、隔桶直接排除。
 桶把 O(k) 的差值检查降为 O(1)。"
```

### 5.2 完整实现

```java
/** 220. 存在重复元素 III（值域分桶） */
public boolean containsNearbyAlmostDuplicate(int[] nums, int k, int t) {
    Map<Long, Long> bucket = new HashMap<>();     // 桶号 → 值
    long w = (long) t + 1;                        // ⚠️ 桶宽 = t+1

    for (int i = 0; i < nums.length; i++) {
        long id = getBucketId(nums[i], w);        // 桶号

        if (bucket.containsKey(id)) return true;  // ① 同桶必满足
        // ② 检查相邻桶（可能满足）
        if (bucket.containsKey(id - 1) && nums[i] - bucket.get(id - 1) <= t)
            return true;
        if (bucket.containsKey(id + 1) && bucket.get(id + 1) - nums[i] <= t)
            return true;

        bucket.put(id, (long) nums[i]);
        if (i >= k) bucket.remove(getBucketId(nums[i - k], w));  // 滑窗
    }
    return false;
}

/** ⚠️ 负数桶号处理 */
private long getBucketId(long x, long w) {
    return x >= 0 ? x / w : (x + 1) / w - 1;      // 负数向下取整
}
// 推演 nums=[1,5,9,1,5,9], k=2, t=3：
//   w=4：1→桶0；5→桶1（|5-1|=4 > 3 → 检查邻桶 0：5-1=4 > 3 ✗）
//   ...
// ⚠️ 面试必答："220 = 桶宽 t+1 的值域分桶——
//   同桶命中即答案；负数桶号
//   用 (x+1)/w - 1 向下取整对齐。"
```

## 6. 桶 vs 计数 vs 基数

### 6.1 三兄弟对比

| 维度 | 桶排序 | 计数排序 | 基数排序 |
|------|:---:|:---:|:---:|
| 分桶 | 值域分桶 | 值即下标 | 按位分桶 |
| 桶内 | 需排序 | 无（展开） | 稳定排序 |
| 复杂度 | O(n) 期望 | O(n+k) | O(d·(n+r)) |
| 前提 | 均匀分布 | 值域小 | 可分位 |

```
⚠️ 关系：
  计数 = 桶排序的"极致"（每桶一个值）
  基数 = 桶排序的"多位版"（按位分桶）

⚠️ 面试必答：
"线性排序三兄弟——桶按值域分、
 计数按值直接索引、基数按位分——
 本质都是'值域索引免比较'。"
```

### 6.2 选型决策

```
均匀分布 + 值域大 → 桶排序
值域小 → 计数排序
定长整数 → 基数排序
非均匀 → 快排

⚠️ 面试表达：
"'分布与值域'决定选型——
 均匀用桶、值域小用计数、可分位用基数。"
```

## 7. 面试要点与追问

### 7.1 面试话术模板

```
"桶排序 = 分桶 + 桶内排序 + 合并。
 桶数 ≈ n 最优（每桶期望 1 个）。
 均匀分布期望 O(n)（E[X²] 有界论证）、
 最坏 O(n log n)（全进一桶）。
 220 的桶宽 t+1 是值域分桶的经典应用
 （同桶必满足、邻桶查边界）。"
```

### 7.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 桶排序前提？ | 均匀分布 |

### 7.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 桶数太少 | 退化为桶内排序 | k ≈ n |
| 负数桶号错 | 桶错乱 | 向下取整公式 |
| 220 忘邻桶检查 | 漏解 | 三个检查 |
| 桶内排序用 O(n²) | 期望变差 | 插入（小桶） |
| 非均匀硬桶排 | 退化 | 先评估分布 |
