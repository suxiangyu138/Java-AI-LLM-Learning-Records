## 1. 快速排序：分治 + partition

### 1.1 完整实现（经典版）

```java
/**
 * 快速排序：分治 + 基准分区
 * 步骤：
 *   ① 选基准 pivot（通常取首元素）
 *   ② partition：小于基准的放左边，大于的放右边
 *   ③ 递归排序左右两半
 * 平均 O(n log n)，最坏 O(n²)，不稳定
 */
public void quickSort(int[] arr, int lo, int hi) {
    if (lo >= hi) return;                     // 基线：区间长度 ≤ 1

    int pivotIndex = partition(arr, lo, hi);  // 分区，返回基准位置
    quickSort(arr, lo, pivotIndex - 1);       // 递归左半
    quickSort(arr, pivotIndex + 1, hi);       // 递归右半
}

/**
 * 经典分区（Hoare 变体，教材常用）：
 * 以 arr[hi] 为基准，i 指向小于区末尾
 * 遍历 j 从 lo 到 hi-1：
 *   arr[j] < pivot → i++ 然后交换 arr[i] 与 arr[j]
 * 最后把基准放到 i+1 位置
 */
private int partition(int[] arr, int lo, int hi) {
    int pivot = arr[hi];
    int i = lo - 1;                           // 小于基准的边界
    for (int j = lo; j < hi; j++) {
        if (arr[j] < pivot) {
            i++;
            swap(arr, i, j);
        }
    }
    swap(arr, i + 1, hi);                     // 基准归位
    return i + 1;                             // 返回基准最终位置
}

private void swap(int[] arr, int i, int j) {
    int tmp = arr[i]; arr[i] = arr[j]; arr[j] = tmp;
}
```

### 1.2 快速选择（Quick Select）

```java
/**
 * 快速选择：只递归包含答案的一侧 → 平均 O(n)
 * 用于 TopK / 第 K 大问题
 */
public int quickSelect(int[] arr, int lo, int hi, int k) {
    int pivotIndex = partition(arr, lo, hi);
    if (pivotIndex == k) return arr[k];          // 命中
    else if (pivotIndex < k)
        return quickSelect(arr, pivotIndex + 1, hi, k);  // 只查右半
    else
        return quickSelect(arr, lo, pivotIndex - 1, k);  // 只查左半
}
// 复杂度：T(n) = T(n/2) + O(n) → 平均 O(n)
// 最坏 O(n²)：已有序数组 + 固定基准（必须随机化基准）
```

## 2. 快速排序的三大优化

### 2.1 优化一：三数取中（防退化）

```java
/**
 * 问题：有序数组 + 固定基准（首/尾）→ 每次只排除一个元素 → O(n²)
 * 解决：取 lo、mid、hi 三个位置的中位数做基准
 *   → 即使数组有序，基准也接近中值 → 划分均衡
 */
private int medianOfThree(int[] arr, int lo, int hi) {
    int mid = lo + (hi - lo) / 2;
    // 把三个位置的中位数交换到 hi（作为 pivot）
    if (arr[lo] > arr[mid]) swap(arr, lo, mid);
    if (arr[lo] > arr[hi]) swap(arr, lo, hi);
    if (arr[mid] > arr[hi]) swap(arr, mid, hi);
    return arr[hi];       // 现在 arr[hi] 是中位数
}
```

### 2.2 优化二：小区间插入排序

```java
/**
 * 问题：递归到小区间时，函数调用开销占比大
 * 解决：区间长度 < 阈值（如 10~20）时改用插入排序
 */
public void quickSortOptimized(int[] arr, int lo, int hi) {
    if (hi - lo + 1 < 16) {                   // 小区间
        insertionSort(arr, lo, hi);           // 插入排序（见 02 模块）
        return;
    }
    int pivotIndex = partition(arr, lo, hi);
    quickSortOptimized(arr, lo, pivotIndex - 1);
    quickSortOptimized(arr, pivotIndex + 1, hi);
}
```

### 2.3 优化三：三路快排（大量重复元素）

```java
/**
 * 问题：数组大量重复元素（如全 1）时，经典分区严重失衡
 * 解决：三路划分 —— 小于 / 等于 / 大于 基准三部分
 *   [ < pivot ] [ == pivot ] [ > pivot ]
 *   equals 区间不参与递归 → 重复元素多时效率极高
 */
public void quickSort3Way(int[] arr, int lo, int hi) {
    if (lo >= hi) return;
    int pivot = arr[lo];
    int lt = lo;        // < pivot 区间的右边界
    int gt = hi;        // > pivot 区间的左边界
    int i = lo + 1;

    while (i <= gt) {
        if (arr[i] < pivot) {
            swap(arr, i++, lt++);      // 小值放入左边
        } else if (arr[i] > pivot) {
            swap(arr, i, gt--);        // 大值放入右边（i 不动）
        } else {
            i++;                       // 等于 pivot → 留在中间
        }
    }
    quickSort3Way(arr, lo, lt - 1);    // 递归 < 部分
    quickSort3Way(arr, gt + 1, hi);    // 递归 > 部分
    // == 部分不递归！
}
```

### 2.4 优化总结

| 优化 | 解决的问题 | 效果 |
|------|------|------|
| 三数取中 | 有序数组退化 O(n²) | 划分均衡 |
| 小区间插入 | 递归调用开销 | 常数降低 |
| 三路快排 | 大量重复元素失衡 | 重复场景线性 |
| 随机基准 | 恶意输入攻击 | 平均保证 |

## 3. 归并排序：稳定之王

### 3.1 完整实现（递归版）

```java
/**
 * 归并排序：先拆后合
 * ① 对半拆分到单元素（天然有序）
 * ② 两两合并有序子数组
 * 稳定，最好=最坏=平均 O(n log n)，空间 O(n)
 */
public void mergeSort(int[] arr, int lo, int hi) {
    if (lo >= hi) return;
    int mid = lo + (hi - lo) / 2;
    mergeSort(arr, lo, mid);        // 拆左半
    mergeSort(arr, mid + 1, hi);    // 拆右半
    merge(arr, lo, mid, hi);        // 合并
}

private void merge(int[] arr, int lo, int mid, int hi) {
    // 复制到辅助数组
    int[] temp = new int[hi - lo + 1];
    int i = lo, j = mid + 1, k = 0;

    // 双指针合并：取较小者
    while (i <= mid && j <= hi) {
        // ⚠️ <= 保证稳定性：左半相等元素优先
        if (arr[i] <= arr[j]) temp[k++] = arr[i++];
        else temp[k++] = arr[j++];
    }
    while (i <= mid) temp[k++] = arr[i++];   // 左半剩余
    while (j <= hi)  temp[k++] = arr[j++];   // 右半剩余

    // 写回原数组
    System.arraycopy(temp, 0, arr, lo, temp.length);
}
```

### 3.2 稳定性为什么成立？

```
合并时相等元素：
  arr[i] == arr[j] → 取左半的 arr[i]（条件用 <=）
  → 左半元素永远先于右半相等元素 → 相对顺序保持 ✓

如果把条件写成 < → 相等时取右半 → 不稳定！

记忆：merge 的比较符号用 <= 才稳定
```

### 3.3 迭代版（自底向上）

```java
/**
 * 迭代版归并：O(n log n)，空间 O(n)，无递归栈
 * 从 len=1 开始，合并相邻的两段 len 长区间
 */
public void mergeSortIterative(int[] arr) {
    int n = arr.length;
    int[] temp = new int[n];

    for (int len = 1; len < n; len *= 2) {      // 合并段长 1,2,4,8...
        for (int lo = 0; lo < n - len; lo += 2 * len) {
            int mid = lo + len - 1;
            int hi = Math.min(lo + 2 * len - 1, n - 1);
            mergeTo(arr, temp, lo, mid, hi);    // 合并到辅助数组再写回
        }
    }
}
```

## 4. 堆排序：原地排序

### 4.1 完整实现

```java
/**
 * 堆排序：利用完全二叉树（数组表示）
 * ① 建最大堆：从 n/2-1 开始自底向上 heapify
 * ② 反复：堆顶（最大值）与末尾交换，堆大小减一，重新下沉
 * O(n log n)，空间 O(1)，不稳定
 */
public void heapSort(int[] arr) {
    int n = arr.length;

    // ① 建堆：从最后一个非叶子节点开始下沉
    for (int i = n / 2 - 1; i >= 0; i--) {
        siftDown(arr, i, n);
    }

    // ② 逐个取堆顶
    for (int i = n - 1; i > 0; i--) {
        swap(arr, 0, i);          // 堆顶（最大）放到末尾
        siftDown(arr, 0, i);      // 堆大小减为 i，重新下沉
    }
}

/**
 * 下沉：把 i 节点与其左右孩子比较，与较大者交换，直到满足堆性质
 * 子节点下标：左 2i+1，右 2i+2（数组表示完全二叉树）
 */
private void siftDown(int[] arr, int i, int size) {
    while (true) {
        int largest = i;
        int left = 2 * i + 1;
        int right = 2 * i + 2;
        if (left < size && arr[left] > arr[largest]) largest = left;
        if (right < size && arr[right] > arr[largest]) largest = right;
        if (largest == i) break;          // 已满足堆性质
        swap(arr, i, largest);
        i = largest;                      // 继续下沉
    }
}
```

### 4.2 建堆为什么是 O(n)？

```
直观理解：多数节点在底层附近
  → 底层节点只需少量比较即可到位
  深度 d 的节点下沉最多 d 次（其实只跟高度有关）

数学推导：总下沉次数 = Σ(h=1..log n) (n/2^h) × h ≈ 2n = O(n)

所以建堆 O(n)，排序阶段 n 次取顶 × O(log n) 下沉 = O(n log n)
```

### 4.3 与 PriorityQueue 的关系

```
Java 的 PriorityQueue 内部就是二叉堆：
  offer() → 堆尾上浮
  poll() → 堆顶出 + 堆尾补位下沉

堆排序 = 建堆 + 反复 poll
TopK 问题 = 大小为 k 的堆（小根堆存最大 k 个）
```

## 5. 三大高级排序对比

| 维度 | 快排 | 归并 | 堆排 |
|------|:---:|:---:|:---:|
| 平均 | O(n log n) | O(n log n) | O(n log n) |
| 最坏 | **O(n²)** | O(n log n) | O(n log n) |
| 空间 | O(log n) | **O(n)** | **O(1)** |
| 稳定 | ❌ | ✅ | ❌ |
| 常数 | **最小**（缓存友好） | 中（需拷贝） | 较大（跳跃访问） |
| 适用 | 通用首选 | 稳定/链表/逆序对 | 内存受限/TopK |
| 递归 | 有 | 有（可迭代） | 无（循环下沉） |

### 为什么快排实际最快？

```
1. 局部性好：partition 顺序访问数组 → CPU 缓存命中率高
2. 无辅助数组：不像归并需要拷贝，常数更小
3. 平均比较次数少：约 1.39n log n（略优于归并）
→ 所以 Java Arrays.sort(基本类型) 用双轴快排
```

## 6. 面试手撕要点

### 6.1 手撕 Checklist

```
□ 快排：递归终止条件 lo >= hi
□ 快排：partition 循环边界（j < hi）
□ 快排：基准归位后递归 [lo, pi-1] 和 [pi+1, hi]
□ 归并：mid 计算防溢出
□ 归并：合并用 <= 保证稳定
□ 归并：剩余元素全部拷入辅助数组
□ 堆排：建堆从 n/2-1 开始
□ 堆排：下沉循环的子节点越界检查
```

### 6.2 高频追问

| 追问 | 标准回答 |
|------|------|
| 快排最坏情况？怎么避免？ | 有序/逆序 + 固定基准 → O(n²)；三数取中/随机基准 |
| 快排 vs 归并 vs 堆排选哪个？ | 通用快排（常数小）；稳定用归并；内存受限用堆排 |
| 归并为什么适合链表？ | 只需 next 指针，不需要随机访问，稳定 O(n log n) |
| 堆排建堆复杂度？ | O(n)——底层节点下沉次数少，总和 ≈ 2n |

> 🎯 **核心要点**：三大高级排序是面试手撕的重中之重。**快排**记住 partition 模板 + 三大优化（三数取中/小区间插入/三路快排）；**归并**记住"拆-合"模板 + `<=` 保证稳定 + 链表适配；**堆排**记住建堆从 n/2-1 + 下沉循环。手撕顺序建议：快排 → 归并 → 堆排，每写完一个用 [1,3,2,5,4] 快速验证。
