## 4. 核心概念速查

| 概念 | 一句话解释 | 关联算法 |
|------|-----------|------|
| **稳定性** | 相等元素排序后相对顺序不变 | 归并/插入/冒泡稳定；快排/选择/堆不稳定 |
| **原地排序** | 常数级额外空间（O(1)） | 冒泡/选择/插入/快排/堆排 |
| **比较排序下界** | 任何比较排序最坏 ≥ Ω(n log n) | 快排/归并/堆排 |
| **partition** | 快排分区：小于/大于基准 | 快排、快速选择 |
| **heapify** | 堆调整：下沉/上浮 | 堆排、优先级队列 |
| **三数取中** | 左中右取中位数做基准 | 快排优化 |
| **三路快排** | 分成小于/等于/大于三段 | 大量重复元素优化 |
| **哨兵法** | 分区时不交换只覆盖 | 快排写法 |
| **归并逆序对** | 合并时统计右半小于左半的个数 | 归并应用 |
| **快速选择** | 只递归一侧的 partition | TopK 问题 |
| **外部排序** | 内存放不下时分批+归并 | 大数据排序 |

## 7. 八大排序一句话总结

| 算法 | 一句话记忆 | 面试定位 |
|------|------|------|
| **冒泡** | 相邻两两交换，大者上浮 | 教学入门，可加"无交换提前退出"优化 |
| **选择** | 每轮选最小放到前面，交换次数最少 | 交换代价高的场景 |
| **插入** | 像理扑克牌，插到已排序区间 | 近乎有序 O(n)，TimSort 部件 |
| **希尔** | 插入的跨越式升级，按增量分组 | 深度专题：[②希尔排序](../插入类排序/②希尔排序（缩小增量排序）/00-希尔排序知识体系总览.md) |
| **快排** | 基准分区 + 递归，工业级之王 | **手撕第一优先**（三数取中） |
| **归并** | 先拆后合，稳定无退化 | 稳定需求 / 链表排序 / 逆序对 |
| **堆排** | 建堆 + 反复取顶，原地 O(1) 空间 | 内存受限 / TopK 基础 |
| **计数** | 值域小 → 直接用值当下标 | 分数/年龄统计 O(n) |

## 8. 速记口诀

```
复杂度：
  冒选插 O(n²)，快归堆 O(n log n)
  快排最坏会退化，归并稳定不退化

稳定性：
  冒插归 + 三个线性 = 稳定
  选快希堆 = 不稳定

选型：
  默认快排，稳定归并，内存紧堆排
  小数组插入，值域小计数，链表归并
```
