## 1. 核心概念

### 1.1 归并排序三步

> 归并排序：**拆（对半分）→ 递归排 → 合（合并有序）**。最好/最坏/平均都是 O(n log n)，且**稳定**。

```
[38, 27, 43, 3, 9, 82, 10]
拆：分两半递归
合：两两合并有序子数组

拆分层数：log₂n 层
每层合并总代价：O(n)
总复杂度：O(n log n)（无退化！）

稳定性：合并时相等元素优先取左半（<=）
```

### 1.2 识别信号

```
"稳定排序" → 归并
"链表排序" → 归并（无随机访问）
"逆序对统计" → 归并（合并时计数）
"排序链表/外部排序" → 归并思想

⚠️ 面试手撕三件套之一（快排/归并/堆排）
  归并是"稳定无退化"的代表
```

### 1.3 归并 vs 快排 vs 堆排

| 维度 | 归并 | 快排 | 堆排 |
|------|:---:|:---:|:---:|
| 最坏 | O(n log n) | O(n²) | O(n log n) |
| 空间 | O(n) 辅助数组 | O(log n) 栈 | O(1) |
| 稳定 | ✅ | ❌ | ❌ |
| 链表 | ✅ 最优 | 不适用 | 不适用 |
| 实际速度 | 中（拷贝多） | 最快（缓存友好） | 中 |

```
选型：稳定/链表/逆序对 → 归并
     通用数组 → 快排；内存受限 → 堆排
```

## 2. 完整代码模板

### 2.1 数组归并（面试标准答案）

```java
/**
 * 归并排序模板（数组，稳定）
 */
public void mergeSort(int[] arr) {
    int[] temp = new int[arr.length];      // ① 全局辅助数组
    sort(arr, 0, arr.length - 1, temp);
}

private void sort(int[] arr, int lo, int hi, int[] temp) {
    if (lo >= hi) return;                  // ② 基线

    int mid = lo + (hi - lo) / 2;
    sort(arr, lo, mid, temp);              // ③ 拆左
    sort(arr, mid + 1, hi, temp);          // ④ 拆右
    merge(arr, lo, mid, hi, temp);         // ⑤ 合并
}

private void merge(int[] arr, int lo, int mid, int hi, int[] temp) {
    System.arraycopy(arr, lo, temp, lo, hi - lo + 1);  // 拷贝辅助

    int i = lo, j = mid + 1, k = lo;
    while (i <= mid && j <= hi) {
        // ⚠️ <= 保证稳定（左半相等元素优先）
        if (temp[i] <= temp[j]) arr[k++] = temp[i++];
        else arr[k++] = temp[j++];
    }
    while (i <= mid) arr[k++] = temp[i++];   // 剩余左半
    while (j <= hi)  arr[k++] = temp[j++];   // 剩余右半
}
// 优化：小规模（<16）改插入排序（减少递归开销）
// 迭代版：len=1 开始自底向上合并（无递归栈）
```

### 2.2 推演：[38, 27, 43, 3]

```
拆：[38,27] 和 [43,3]
  [38,27] → [38] [27] → 合并 → [27,38]
  [43,3] → [43] [3] → 合并 → [3,43]
合：[27,38] 与 [3,43]
  3<27 → [3]；27<43 → [3,27]；38<43 → [3,27,38]；43 → [3,27,38,43] ✓
```

### 2.3 链表归并（148. 排序链表）

```java
/**
 * LeetCode 148. 排序链表（链表归并）
 * 快慢指针找中点 → 断开 → 递归 → 合并
 * ⚠️ 链表归并无需辅助数组（O(1) 额外空间）
 */
public ListNode sortList(ListNode head) {
    if (head == null || head.next == null) return head;   // 基线

    // ① 快慢指针找中点
    ListNode slow = head, fast = head;
    while (fast.next != null && fast.next.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    ListNode second = slow.next;
    slow.next = null;                    // ⚠️ 断开！

    // ② 递归排序两半
    ListNode left = sortList(head);
    ListNode right = sortList(second);

    // ③ 合并（21 题复用）
    return mergeTwoLists(left, right);
}
// 为什么链表排序选归并？
//   无随机访问 → 快排 partition 低效
//   归并只需 next 指针 → 天然适配
```

## 3. 归并的三大优势

### 3.1 优势一：稳定

```
合并时相等元素取左半（<=）：
  [a, b] 与 [b, c]（两个 b）
  → 左半的 b 先入结果 → 顺序保持 ✓

⚠️ 如果用 <（相等取右半）→ 不稳定
  记忆："merge 用 <= 才稳定"

应用：二次排序（先学号后分数）
  Java 对象排序（TimSort）基于归并
```

### 3.2 优势二：无退化

```
拆分与数据无关（每次严格对半分）：
  递归树恒 log n 层 × 每层 O(n)
  → 最好 = 最坏 = 平均 O(n log n)

对比快排：基准选择影响划分 → 最坏 O(n²)

⚠️ 面试必答：
"归并没有最坏退化——拆分不依赖数据，
 递归树结构固定，恒 log n 层。"
```

### 3.3 优势三：适配链表

```
链表无随机访问：
  快排 partition 需要双向遍历 → 低效
  堆排依赖数组下标 → 不适用
  归并只需 next 指针 → 天然适配

⚠️ 链表归并额外空间 O(1)（无辅助数组）
  数组归并需要 O(n) 辅助数组
```

## 4. 逆序对统计详解

### 4.1 核心思想（剑指 51）

```java
/**
 * 逆序对：i < j 且 nums[i] > nums[j]
 * 归并天然适合：合并时右半先入结果
 *   → 它与左半剩余的所有元素都构成逆序对
 */
public int reversePairs(int[] nums) {
    int[] temp = new int[nums.length];
    return count(nums, 0, nums.length - 1, temp);
}

private int count(int[] arr, int lo, int hi, int[] temp) {
    if (lo >= hi) return 0;

    int mid = lo + (hi - lo) / 2;
    int result = count(arr, lo, mid, temp)      // 左半内部
               + count(arr, mid + 1, hi, temp); // 右半内部

    // 合并时统计跨两半的逆序对
    int i = lo, j = mid + 1, k = lo;
    while (i <= mid && j <= hi) {
        if (arr[i] <= arr[j]) {
            temp[k++] = arr[i++];
        } else {
            // ⚠️ 关键：arr[j] 与左半剩余 (mid-i+1) 个都构成逆序对
            result += mid - i + 1;
            temp[k++] = arr[j++];
        }
    }
    // 剩余拷贝（同标准归并）
    while (i <= mid) temp[k++] = arr[i++];
    while (j <= hi)  temp[k++] = arr[j++];
    System.arraycopy(temp, lo, arr, lo, hi - lo + 1);
    return result;
}
// 推演 [7,5,6,4]：
//   左半 [7,5]：合并时 5<7 → +1（5,7）
//   右半 [6,4]：合并时 4<6 → +1（4,6）
//   跨半：4<5 → +2（4,5 与 4,7）；6>5 → +1（6,7）
//   总 = 5 ✓（(7,5),(7,6),(7,4),(5,4),(6,4)）
```

### 4.2 为什么"右半先入 = 逆序对"？

```
合并时左半 [i..mid] 与右半 [j..hi] 都已有序：
  arr[j] < arr[i] → arr[j] 小于左半所有剩余元素
  → 构成 (mid-i+1) 个逆序对（arr[i..mid] 每个都 > arr[j]）

⚠️ 这是归并排序解决逆序对的灵魂
  面试必须能推导
```

### 4.3 逆序对变体

```
① 493 翻转对：条件变为 arr[i] > 2×arr[j]
   → 合并前先统计（双指针），再正常合并
② 315 右侧更小：返回每个位置的计数
   → 树状数组/归并两种解法
③ 315 变体：区间和的个数（327）

⚠️ 选型：
  逆序对统计 → 归并（直观）
  右侧更小 → 树状数组（每元素计数更方便）
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"归并排序拆成'拆-排-合'三步：对半拆分、
 递归排序、合并有序子数组。
 全局辅助数组避免反复分配。
 合并用 <= 保证稳定。
 O(n log n) 无退化（拆分与数据无关）。
 链表和逆序对场景是它的专属优势。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 为什么没有最坏退化？ | 拆分与数据无关 → 递归树恒 log n 层 |
| 2 | 稳定性怎么实现？ | merge 用 <=（相等取左半） |
| 3 | 为什么链表最优？ | 只需 next 指针；无随机访问需求 |
| 4 | 空间复杂度？ | 递归版 O(n) 辅助 + O(log n) 栈；迭代版 O(n) |
| 5 | 逆序对怎么统计？ | 右半先入 → 与左半剩余 (mid-i+1) 个构成 |
| 6 | 递归 vs 迭代？ | 迭代自底向上（无栈）；递归直观 |
| 7 | 小数组优化？ | 阈值内改插入排序（减少递归开销） |
| 8 | TimSort 关系？ | Java 对象排序 = 归并+插入混合（稳定） |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| merge 用 < | 不稳定 | 用 <= |
| 剩余元素漏拷 | 结果缺失 | 两个 while |
| 辅助数组反复分配 | 性能差 | 全局 temp |
| 逆序对忘计数 | 漏统计 | 右半入时 +mid-i+1 |
| 链表忘断开 | 合并错 | slow.next = null |

> 🎯 **核心要点**：归并 = **拆-排-合** + **稳定（<=）+ 无退化**。识别信号："稳定排序、链表排序、逆序对"。辅助数组复用、小规模插入优化、逆序对计数（mid-i+1）是三大进阶细节；"为什么链表选归并"是面试必答。
