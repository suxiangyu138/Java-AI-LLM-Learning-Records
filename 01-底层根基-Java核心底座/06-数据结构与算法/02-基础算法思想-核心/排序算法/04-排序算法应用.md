## 1. TopK 问题：堆 vs 快速选择

### 1.1 问题定义

```
经典问题：数据流/数组中找第 K 大（或最大的 K 个）
  LeetCode 215. 数组中的第 K 个最大元素

两种主流解法：
  ① 堆（小根堆）：O(n log k)
  ② 快速选择：平均 O(n)，最坏 O(n²)
```

### 1.2 解法一：堆（TopK 标准解法）

```java
/**
 * LeetCode 215. 数组中的第 K 个最大元素（堆解法）
 * 维护大小为 k 的小根堆：堆顶 = 第 k 大
 * 思路：
 *   ① 前 k 个元素建小根堆
 *   ② 后续元素 > 堆顶 → 替换堆顶（堆顶是当前最小的候选）
 *   ③ 结束时堆顶就是第 k 大
 * O(n log k)，空间 O(k)
 */
public int findKthLargest(int[] nums, int k) {
    PriorityQueue<Integer> minHeap = new PriorityQueue<>();  // 小根堆
    for (int x : nums) {
        minHeap.offer(x);
        if (minHeap.size() > k) {
            minHeap.poll();          // 超过 k 个 → 弹出最小的
        }
    }
    return minHeap.peek();           // 堆顶 = 第 k 大
}
```

### 1.3 解法二：快速选择（平均 O(n)）

```java
/**
 * 快速选择：基于快排 partition，只递归包含答案的一侧
 * 注意：必须随机选基准（或三数取中），否则有序数组退化 O(n²)
 */
public int findKthLargest_QuickSelect(int[] nums, int k) {
    int n = nums.length;
    return quickSelect(nums, 0, n - 1, n - k);   // 第 k 大 = 第 n-k 小
}

private int quickSelect(int[] arr, int lo, int hi, int k) {
    if (lo == hi) return arr[lo];
    // 随机化：交换随机位置到 hi 作为基准（防退化）
    int randomIdx = lo + new Random().nextInt(hi - lo + 1);
    swap(arr, randomIdx, hi);

    int pivot = arr[hi];
    int i = lo - 1;
    for (int j = lo; j < hi; j++) {
        if (arr[j] < pivot) swap(arr, ++i, j);
    }
    swap(arr, i + 1, hi);

    if (i + 1 == k) return arr[i + 1];
    else if (i + 1 < k) return quickSelect(arr, i + 2, hi, k);
    else return quickSelect(arr, lo, i, k);
}
```

### 1.4 两种解法对比

| 维度 | 堆 | 快速选择 |
|------|:---:|:---:|
| 时间复杂度 | O(n log k) | 平均 O(n)，最坏 O(n²) |
| 空间 | O(k) | O(log n) 递归栈 |
| 数据流场景 | ✅ 支持在线 | ❌ 需全量数组 |
| 稳定 | — | — |
| 大 K 场景 | k 大时堆空间大 | 无额外空间 |

```
选型：
  静态数组找第 K 大 → 快速选择（平均 O(n) 更快）
  数据流/动态新增 → 堆（在线处理）
  大量 TopK → 堆
```

## 2. 外部排序：大数据面试压轴题

### 2.1 问题场景

```
场景：1TB 日志文件，内存只有 2GB，怎么排序？

内存放不下 → 不能一次性读入 → 外部排序
```

### 2.2 外部排序三步法

```
步骤 1：分批排序（生成顺段 Run）
  每次读入内存能装下的数据（如 1GB）
  → 内存排序 → 写回磁盘为一个有序段（顺段）
  → 得到若干有序段

步骤 2：多路归并（K 路归并）
  每段各取一个元素放入堆（大小为 K）
  每次弹出最小值写入结果文件
  对应段的下一个元素补入堆
  → 类似 23. 合并 K 个有序链表！

步骤 3：重复归并
  顺段数量大 → 多轮归并（每轮 K 路合并）
  最终合成一个完整有序文件
```

```java
/**
 * K 路归并核心（Java 实现）：
 * 每个顺段是一个迭代器，堆里存 (值, 段号)
 * 复杂度：O(N log K)，堆调整每次 O(log K)
 */
public void kWayMerge(List<Iterator<Integer>> runs, String outputFile) {
    // 堆元素：(值, 来自哪个顺段)
    PriorityQueue<int[]> heap =
        new PriorityQueue<>((a, b) -> a[0] - b[0]);

    for (int i = 0; i < runs.size(); i++) {
        if (runs.get(i).hasNext()) {
            heap.offer(new int[]{runs.get(i).next(), i});
        }
    }

    while (!heap.isEmpty()) {
        int[] min = heap.poll();               // 取全局最小
        write(min[0]);                         // 写入结果
        int seg = min[1];
        if (runs.get(seg).hasNext()) {
            heap.offer(new int[]{runs.get(seg).next(), seg});  // 补充
        }
    }
}
```

### 2.3 进阶：败者树

```
K 路归并的优化：败者树（Loser Tree）
  堆的不足：每次调整需 log K 次比较
  败者树：维护"输家"的比较树，复用历史比较结果
  → 内部节点只比较一次，调整代价更小
  → 访存更少，工业级外部排序首选

面试话术：
"多路归并用败者树而不是堆做优化——比较次数更少、
 访存更少。堆需要 log K 次比较，败者树只需一次。
 工业级实现（如数据库排序）用败者树。"
```

## 3. 线性排序：计数 / 桶 / 基数

### 3.1 计数排序（值域小）

```java
/**
 * 计数排序：值域 k 较小（如 0-100 的分数）时
 * ① 统计每个值的个数
 * ② 前缀和 → 确定每个值的最终位置
 * ③ 倒序回填（保证稳定）
 * O(n+k)，空间 O(k)，稳定
 */
public void countingSort(int[] arr, int maxVal) {
    int[] count = new int[maxVal + 1];
    for (int x : arr) count[x]++;

    // 前缀和：count[i] = ≤ i 的元素个数
    for (int i = 1; i <= maxVal; i++) {
        count[i] += count[i - 1];
    }

    // 倒序回填到结果数组（倒序保证稳定）
    int[] result = new int[arr.length];
    for (int i = arr.length - 1; i >= 0; i--) {
        result[--count[arr[i]]] = arr[i];
    }
    System.arraycopy(result, 0, arr, 0, arr.length);
}
```

### 3.2 桶排序（均匀分布）

```java
/**
 * 桶排序：把数据分到 k 个桶，桶内排序，顺序拼接
 * 适用：数据均匀分布（如 0-1 的浮点数）
 * 平均 O(n+k)，最坏 O(n²)（全进一个桶）
 */
public void bucketSort(double[] arr) {
    int k = arr.length;
    List<List<Double>> buckets = new ArrayList<>();
    for (int i = 0; i < k; i++) buckets.add(new ArrayList<>());

    for (double x : arr) {
        int idx = (int) (x * k);          // 映射到桶
        buckets.get(idx).add(x);
    }

    int index = 0;
    for (List<Double> bucket : buckets) {
        Collections.sort(bucket);          // 桶内排序（可任选）
        for (double x : bucket) arr[index++] = x;
    }
}
```

### 3.3 基数排序（多关键字）

```java
/**
 * 基数排序：按位排序（个位 → 十位 → 百位...）
 * 每位用计数排序（稳定），低位优先（LSD）
 * O(kn)，k 为位数，空间 O(n+k)，稳定
 * 例：对三位整数，先按个位排，再十位，再百位
 */
public void radixSort(int[] arr) {
    // 找最大值确定位数
    int max = 0;
    for (int x : arr) max = Math.max(max, x);

    // 按位处理：exp = 1, 10, 100...
    for (int exp = 1; max / exp > 0; exp *= 10) {
        countingSortByDigit(arr, exp);
    }
}

private void countingSortByDigit(int[] arr, int exp) {
    int[] count = new int[10];             // 数字 0-9
    int[] result = new int[arr.length];
    for (int x : arr) count[(x / exp) % 10]++;
    for (int i = 1; i < 10; i++) count[i] += count[i - 1];
    for (int i = arr.length - 1; i >= 0; i--) {   // 倒序稳定
        int digit = (arr[i] / exp) % 10;
        result[--count[digit]] = arr[i];
    }
    System.arraycopy(result, 0, arr, 0, arr.length);
}
```

### 3.4 三种线性排序对比

| 算法 | 适用 | 复杂度 | 稳定性 | 局限 |
|------|------|:---:|:---:|------|
| 计数 | 值域小 | O(n+k) | ✅ | 值域大浪费空间 |
| 桶 | 均匀分布 | O(n+k) | ✅ | 分布不均退化 |
| 基数 | 定长数值 | O(kn) | ✅ | 需可拆位 |

## 4. 归并排序的应用：逆序对

```java
/**
 * LeetCode 493 / 剑指 Offer 51. 数组中的逆序对
 * 逆序对：i < j 且 nums[i] > nums[j]
 *
 * 归并排序天然适合：合并时右半元素先入结果
 * → 说明它比左半剩余的所有元素都小 → 累加逆序对
 */
public int reversePairs(int[] nums) {
    return mergeSortCount(nums, 0, nums.length - 1);
}

private int mergeSortCount(int[] arr, int lo, int hi) {
    if (lo >= hi) return 0;
    int mid = lo + (hi - lo) / 2;

    int count = mergeSortCount(arr, lo, mid)
              + mergeSortCount(arr, mid + 1, hi);

    // 合并时统计逆序对
    int[] temp = new int[hi - lo + 1];
    int i = lo, j = mid + 1, k = 0;
    while (i <= mid && j <= hi) {
        if (arr[i] <= arr[j]) {
            temp[k++] = arr[i++];
        } else {
            // 右半元素 arr[j] < arr[i]
            // → arr[j] 与左半剩余的 (mid-i+1) 个元素都构成逆序对
            count += mid - i + 1;
            temp[k++] = arr[j++];
        }
    }
    while (i <= mid) temp[k++] = arr[i++];
    while (j <= hi)  temp[k++] = arr[j++];
    System.arraycopy(temp, 0, arr, lo, temp.length);
    return count;
}
```

## 5. Java Arrays.sort() 源码原理

### 5.1 双轨设计（关键知识点）

```java
// 基本类型数组（int[] / long[] / double[]...）
Arrays.sort(int[])  → DualPivotQuickSort（双轴快排）
  - 两个基准 → 三段划分 → 缓存友好
  - 性能极致，但不稳定

// 对象数组（Integer[] / String[]...）
Arrays.sort(Object[]) → TimSort（归并 + 插入混合）
  - 稳定！（对象的稳定性有意义）
  - 小片段（<32）用插入排序
  - 检测有序段（run）直接复用 → 近乎有序时 O(n)

// 并行排序（大数据量）
Arrays.parallelSort() → ForkJoin 分治并行
  - 数据量大时多线程并行归并
```

### 5.2 TimSort 要点

```
TimSort = 归并排序 + 插入排序的混合：
  ① 扫描出天然有序段（run）
  ② 短 run 用插入排序补齐（最小 32）
  ③ 相邻 run 归并（栈式归并）
  ④ 近乎有序数据 → O(n)，最坏 O(n log n)
  ⑤ 稳定 → Java 对象排序首选
```

### 5.3 为什么基本类型用快排、对象用归并？

```
稳定性的意义：
  对象（如学生）排序后，稳定性影响实际结果 → 必须稳定 → TimSort
  基本类型（纯数值）无"顺序是否打乱"的问题 → 追求速度 → 双轴快排

内存考虑：
  TimSort 需要 O(n) 临时空间（对象引用）
  基本类型数据量大时，O(n) 空间代价高 → 快排原地

面试金句："Java 对基本类型用双轴快排（速度快、原地），
  对对象用 TimSort（稳定，对象的排序稳定性有意义）。"
```

## 6. 排序选型决策树

```
拿到排序场景 → 按顺序问自己：

① 数据量多大？
   内存装不下 → 外部排序（分批 + K 路归并）
   能装下 → 继续

② 是否要求稳定？
   是 → 归并（数组）/ TimSort（Java 对象）/ 插入（小数据）
   否 → 继续

③ 数据有什么特征？
   值域小（如 0-100 分数）→ 计数排序 O(n)
   均匀分布浮点数 → 桶排序 O(n)
   定长数值 → 基数排序 O(kn)
   近乎有序 → 插入排序 / TimSort O(n)

④ 默认选择？
   通用数组 → 快排（三数取中优化）
   链表 → 归并
   内存受限 → 堆排
   TopK → 堆 / 快速选择
```

### 面试场景速答表

| 场景 | 答案 |
|------|------|
| "10 万条近乎有序数据怎么排？" | 插入排序（O(n)）或 TimSort |
| "1 亿数据找 Top100？" | 小根堆 O(n log 100) |
| "1TB 文件怎么排？" | 外部排序：分批排序 + K 路归并（败者树） |
| "学生先按班再按分数排？" | 稳定排序两次（归并/TimSort） |
| "0-100 分的成绩排序？" | 计数排序 O(n) |
| "链表排序？" | 归并排序（无随机访问） |

> 🎯 **核心要点**：排序应用是面试拉开差距的地方。**TopK 双解法**（堆 O(n log k) / 快速选择 O(n)）、**外部排序三步法**（分批+多路归并+败者树优化）、**Arrays.sort 双轨原理**（双轴快排 vs TimSort）、**稳定排序二次排序**——这四个知识点的对答如流程度，直接决定你在排序专题上的面试等级。
