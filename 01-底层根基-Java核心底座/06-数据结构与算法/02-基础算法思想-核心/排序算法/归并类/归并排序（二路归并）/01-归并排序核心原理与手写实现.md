## 1. 分治模型：拆-排-合三步

### 1.1 算法就是"先拆后合"

归并排序（1945 年冯·诺依曼提出）的分治三步：

```text
拆（Divide）: 把数组从中间对半拆开，递归拆到单元素
排（Conquer）: 单元素天然有序（递归基）
合（Merge）: 两两合并有序子数组 → 更大的有序子数组

[38, 27, 43, 3, 9, 82, 10]
拆：对半分 → [38,27,43,3] | [9,82,10] → 递归到单元素
合：两两合并 → 层层归并 → 完整有序

拆分层数: log₂n 层
每层合并总代价: O(n)
总复杂度: O(n log n)（无退化！）
```

### 1.2 二路归并：核心原子操作

```text
输入: 两个已有序的序列 [lo..mid] 与 [mid+1..hi]
输出: 一个合并后的有序序列

双指针算法:
  ① i 指向左块头，j 指向右块头，k 指向结果位置
  ② 比较 a[i] 与 a[j]，取较小者写入结果，指针前进
  ③ 一方耗尽 → 剩余全部接尾

稳定性关键: 相等时取左块（a[i] <= a[j] 成立 → 取 i）
```

> 🎯 **核心动作三连**：**对半拆（mid = lo + (hi-lo)/2）→ 递归排（左右各自）→ 合并（双指针 + 辅助数组）**。与快排对比：快排是"先 partition 定位、再递归"，归并是"先递归、再 merge 合并"——**归并的拆分只按位置，不按数值，这正是它无退化的根源**。

## 2. 基本实现：递归版（2 分钟默写）

### 2.1 完整代码（面试标准答案）

```java
/**
 * 归并排序（递归版，稳定，无退化）
 * 时间 O(n log n)，空间 O(n) 辅助数组
 */
public void mergeSort(int[] arr) {
    int[] temp = new int[arr.length];      // ① 全局辅助数组（全程复用）
    sort(arr, 0, arr.length - 1, temp);
}

private void sort(int[] arr, int lo, int hi, int[] temp) {
    if (lo >= hi) return;                  // ② 基线：单元素天然有序

    int mid = lo + (hi - lo) / 2;          // ③ 对半拆（防溢出的写法）
    sort(arr, lo, mid, temp);              // ④ 递归排左半
    sort(arr, mid + 1, hi, temp);          // ⑤ 递归排右半
    merge(arr, lo, mid, hi, temp);         // ⑥ 合并两个有序块
}

private void merge(int[] arr, int lo, int mid, int hi, int[] temp) {
    System.arraycopy(arr, lo, temp, lo, hi - lo + 1);  // ① 拷贝到辅助数组

    int i = lo, j = mid + 1, k = lo;
    while (i <= mid && j <= hi) {
        // ⚠️ <= 保证稳定（相等时左半元素优先）
        if (temp[i] <= temp[j]) arr[k++] = temp[i++];
        else                    arr[k++] = temp[j++];
    }
    while (i <= mid) arr[k++] = temp[i++];   // ② 左半剩余
    while (j <= hi)  arr[k++] = temp[j++];   // ③ 右半剩余
}
```

### 2.2 三个关键实现细节

```text
① 全局辅助数组: 递归全程复用同一个 temp ——
   若每层新建辅助数组，空间会退化为 O(n log n)
② mid 防溢出: lo + (hi - lo) / 2 而非 (lo + hi) / 2 ——
   大数组时 (lo+hi) 可能溢出 int（面试细节加分项）
③ 稳定写法: temp[i] <= temp[j] 取左块 ——
   用 < 则相等元素取右块 → 不稳定（见第 5 节反例）
```

> 💡 **记忆技巧**：归并排序 = "**二分递归 + 三 while 合并**"。合并的"三 while"（主循环 + 左剩余 + 右剩余）与 21 题合并链表、88 题合并数组是同一个原子操作的三种形态——**会写 merge 就会写一半的归并题**。

## 3. 逐步推演：n=7 全流程

**数据**：[38, 27, 43, 3, 9, 82, 10]（升序排序）

| 阶段 | 操作 | 结果 |
|:---:|------|------|
| 拆分 | 对半递归到单元素 | [38] [27] [43] [3] [9] [82] [10] |
| 第 1 轮合并 | 两两合并 | [27,38] [3,43] [9,82] [10] |
| 第 2 轮合并 | 四四合并 | [3,27,38,43] [9,10,82] |
| 第 3 轮合并 | 全体合并 | [3,9,10,27,38,43,82] ✓ |

**单次合并推演（第 2 轮：[27,38] 与 [3,43]）**：

```text
i=0(27) vs j=0(3): 3 < 27 → 取 3 → [3]
i=0(27) vs j=1(43): 27 < 43 → 取 27 → [3,27]
i=1(38) vs j=1(43): 38 < 43 → 取 38 → [3,27,38]
右块剩余 43 → 接尾 → [3,27,38,43] ✓
```

> 🎯 **从推演看结构**：**每一层合并的总工作量都是 O(n)**（7 个元素在第 1 层合并 6 次比较、第 2 层 6 次、第 3 层 6 次……），而层数只有 log₂n——**"每层 O(n) × log n 层 = O(n log n)"是归并复杂度的全部直觉**，比背公式重要。

## 4. 复杂度推导：为什么恒为 O(n log n)

### 4.1 递推方程与主定理

```text
T(n) = 2T(n/2) + O(n)
  ├─ 2T(n/2): 左右两半各递归一次
  └─ O(n):    合并两个有序块（一次线性扫描）

主定理（情形二）:
  a = 2, b = 2, f(n) = O(n) = O(n^(log₂2 - ε)) 不满足情形一
  f(n) = Θ(n^(log₂2)) → 情形二 → T(n) = Θ(n log n) ✓

展开验证:
  T(n) = 2T(n/2) + n
       = 2(2T(n/4) + n/2) + n = 4T(n/4) + 2n
       = 2^k·T(n/2^k) + k·n
  k = log₂n → T(n) = n·T(1) + n·log₂n = Θ(n log n)
```

### 4.2 无退化的根源：拆分不依赖数据

```text
快排的划分取决于基准值与数据的相对关系 → 最坏 O(n²)
归并的划分只取决于位置（严格对半）→ 与数据分布完全无关

→ 递归树结构固定: 恒 log n 层，每层恒 O(n)
→ 最好 = 平均 = 最坏 = O(n log n)（三情形相同）

⚠️ 面试必答:
"归并排序没有最坏退化——因为它不挑基准，只按位置对半拆，
递归树形状与数据无关，永远 log n 层。"
```

### 4.3 空间复杂度辨析

```text
数组版: O(n) 辅助数组（合并的暂存区）+ O(log n) 递归栈
  → 常记为 O(n)（辅助数组主导）

链表版: 无辅助数组（合并只改指针）→ O(log n) 递归栈

⚠️ 常见误区:
"归并空间 O(1)"是错的（数组版必须 O(n) 辅助）；
"归并 O(n log n) 空间"也是错的（全程复用 → O(n)）
```

> 🎯 **面试必答句**："归并排序 O(n log n) 时间、O(n) 空间、稳定——三情形复杂度相同，因为拆分只按位置不按数值。它是'用 O(n) 空间换无退化和稳定'的典型代表；链表版空间降为 O(log n)。"

## 5. 稳定性证明：merge 用 <= 的奥秘

### 5.1 为什么 <= 保证稳定

```text
合并时相等元素（temp[i] == temp[j]）:
  <= 成立 → 取左块元素 → 左块的相等元素先入结果
  → 相等元素的相对顺序在合并中保持不变 → 稳定 ✔

反例（用 < 会怎样）:
  [b₁, c] 与 [b₂, d]（b₁ == b₂，b₁ 在左块）
  用 < : temp[i] < temp[j] 不成立（相等）→ 取右块 b₂
  → b₂ 先入结果 → b₁ 被挤到 b₂ 后面 → 不稳定 ✘

记忆: "merge 用 <= 才稳定，用 < 就翻车"
```

### 5.2 稳定性的工程价值

```text
多关键字排序: 先按次关键字稳定排 → 再按主关键字稳定排
  → 主关键字相同者保持次关键字的顺序
  → 数据库 ORDER BY a, b 就是两次稳定排序

Java 对象排序必须稳定（用户依赖相等元素的原顺序）
  → Arrays.sort(Object[]) 选 TimSort（归并家族）
  → Arrays.sort(int[]) 不要求稳定 → 双轴快排（更快）
```

> ⚠️ **稳定性考点**：稳定排序口诀"冒插归基"——**归并在家族中的稳定性靠"相等取左块"实现，代价是 O(n) 辅助空间**。"稳定 + 无退化"是归并 vs 快排/堆排的核心竞争力，面试对比题必答。

## 6. 链表归并：为什么归并是链表的天选

### 6.1 三大排序在链表上的表现

| 算法 | 链表适配 | 原因 |
|------|:---:|------|
| 归并 | ✔ 最优 | 只需 next 指针，合并 O(1) 额外空间 |
| 快排 | ✘ 低效 | partition 需要双向遍历/随机访问 |
| 堆排 | ✘ 不适用 | 依赖数组下标定位堆元素 |

### 6.2 链表归并核心代码（148）

```java
/**
 * LeetCode 148. 排序链表（链表归并）
 * 快慢指针找中点 → 断开 → 递归 → 合并（21 题复用）
 */
public ListNode sortList(ListNode head) {
    if (head == null || head.next == null) return head;   // 基线

    // ① 快慢指针找中点（slow 停在前半末尾）
    ListNode slow = head, fast = head;
    while (fast.next != null && fast.next.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    ListNode second = slow.next;
    slow.next = null;                    // ⚠️ 断开两半！

    // ② 递归排序两半
    ListNode left = sortList(head);
    ListNode right = sortList(second);

    // ③ 合并（21 题迭代版，O(1) 空间）
    return mergeTwoLists(left, right);
}
```

> 🎯 **链表归并的灵魂**：数组归并需要 O(n) 辅助数组（搬移元素）；**链表归并只改指针，合并本身零空间成本**——"无随机访问"不是缺陷而是契机，归并是唯一能 O(1) 额外空间完成链表排序的 O(n log n) 算法。这也是 148 题的必选解法。

## 7. 逆序对统计入门与手写易错点

### 7.1 逆序对：合并时顺手计数

```java
/**
 * 剑指 Offer 51. 数组中的逆序对（入门版）
 * ⚠️ 关键：右块元素被取走时，它与左块剩余全部构成逆序对
 */
int count = 0;

private void mergeCount(int[] nums, int lo, int mid, int hi, int[] tmp) {
    int i = lo, j = mid + 1, k = lo;
    while (i <= mid && j <= hi) {
        if (nums[i] <= nums[j]) {
            tmp[k++] = nums[i++];               // 左块归位：无逆序
        } else {
            count += mid - i + 1;               // ⭐ 批量计数
            tmp[k++] = nums[j++];
        }
    }
    // 剩余拷贝同标准归并
    while (i <= mid) tmp[k++] = nums[i++];
    while (j <= hi)  tmp[k++] = nums[j++];
    System.arraycopy(tmp, lo, nums, lo, hi - lo + 1);
}
// 推演 [7,5,6,4]：总逆序对 5 ✓（(7,5)(7,6)(7,4)(5,4)(6,4)）
```

**为什么"批量"正确**：左块已有序 → `nums[j]` 小于左块剩余 `[i..mid]` 全部 → 一次加完 `(mid-i+1)` 个。

### 7.2 手写易错点速查

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | merge 用 `<` | `temp[i] <= temp[j]` | 失去稳定性 |
| 2 | 剩余元素漏拷 | 两个 while 接尾 | 结果元素缺失 |
| 3 | 辅助数组每层新建 | 全程复用全局 temp | 空间退化为 O(n log n) |
| 4 | mid 用 `(lo+hi)/2` | `lo + (hi-lo)/2` | 大数组溢出 |
| 5 | 链表忘记断开 | `slow.next = null` | 合并出错/成环 |
| 6 | 逆序对忘计数 | 右块取走时 `+mid-i+1` | 漏统计 |

> 🎯 **核心要点**：归并排序通关四件事——**① 2 分钟默写递归版**（二分递归 + 三 while 合并 + <= 稳定）；**② 说清无退化**（拆分只按位置，递归树恒 log n 层）；**③ 会讲三个专属场景**（稳定排序、链表排序、逆序对统计）；**④ 逆序对批量计数张嘴就来**（右块取走 +mid-i+1）。**归并是"分治思想的教科书"，也是唯一一个"排序 + 统计一举两得"的算法**——这正是它从 1945 年活跃到今天的根本原因。
