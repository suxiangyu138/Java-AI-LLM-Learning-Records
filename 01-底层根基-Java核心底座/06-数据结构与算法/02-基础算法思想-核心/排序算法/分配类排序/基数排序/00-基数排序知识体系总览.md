## 1. 知识体系导图

```text
基数排序（Radix Sort，源自 1887 年穿孔卡片机，现代 LSD 版）
│
├── 核心本质 ──────────────────────────────────────────────
│   ├── = 按位多次稳定排序（个位 → 十位 → 百位…）
│   ├── 每位用稳定计数排序（桶数 = 基数）
│   ├── LSD：低位优先（数值主流）→ 稳定累积
│   └── MSD：高位优先（字符串字典序）→ 递归分桶
│
├── 关键特性 ──────────────────────────────────────────────
│   ├── 时间复杂度：O(d·(n+r))，定长键（32 位 r=256）→ O(4n) = 线性
│   ├── 空间复杂度：O(n+r)（结果数组 + 计数数组）
│   ├── 稳定性：✔ 稳定（倒序回填的计数排序）
│   └── 非比较排序：突破比较下界 Ω(n log n)
│
├── 正确性核心 ────────────────────────────────────────────
│   ├── 每轮必须稳定 → 高位相同时低位顺序不乱
│   ├── 轮 k 后序列按"后 k 位"有序（归纳定理）
│   └── 倒序回填 = 计数排序的稳定写法（关键实现细节）
│
├── 变体与工程 ────────────────────────────────────────────
│   ├── 基数选择：r=10 教学 / r=256 字节工程标准 / r=2^16 内存换轮数
│   ├── 负数：偏移法（简单有溢出风险）/ 符号位变换（无溢出）
│   ├── 浮点：IEEE 754 位变换（黑魔法，了解即可）
│   ├── 字符串：LSD 补位 / MSD 递归（天然适配字典序）
│   └── 字节基数排序：32 位整数 4 轮完成，缓存友好
│
├── 工程前沿（2025-2026）──────────────────────────────────
│   ├── Onesweep（NVIDIA，已入 CUB v1.10）：decoupled look-back 单趟前缀和
│   ├── AMD GPUOpen 2025：常量大小循环缓冲的内存优化版
│   ├── libcusort（2025，Blackwell 调优）：RTX 5090 int8 快 33.6%
│   └── GPU 基准（PLoS ONE 2026）：基数排序 ~50× 于 CPU 单核
│
└── 实战与面试 ────────────────────────────────────────────
    ├── 手写：十进制 LSD（2 分钟）+ 字节基数排序（进阶）
    ├── 考题：164 最大间距（桶/基数双解）、912 三版、451 频次桶、179 比较器
    ├── 对比：计数（单轮）/ 基数（多轮）/ 桶（分区）三兄弟
    └── 话术：稳定性必答 + 线性复杂度表达 + 何时赢快排
```

## 4. 核心概念速查

| 概念 | 一句话解释 | 说明 |
|------|-----------|------|
| **基数排序** | 按位多次稳定排序，d 轮线性时间 | 非比较排序，突破 Ω(n log n) 下界 |
| **基数（r）** | 每轮按几个可能取值分桶 | 十进制 10、字节 256、二进制 2 |
| **位（digit）** | 每轮处理的键的一部分 | 十进制位 / 8 位字节组 / 字符 |
| **轮（pass）** | 对某一位做一次稳定计数排序 | d = 总位数 = 最大值的位数 |
| **LSD** | 最低位优先（个位 → 高位） | 数值排序主流，只需稳定即可 |
| **MSD** | 最高位优先（高位 → 低位） | 字符串字典序，需递归分桶 |
| **稳定计数排序** | 倒序回填的计数排序 | 基数排序每轮的组件 |
| **倒序回填** | 从后往前放置元素 | 稳定性的实现细节（关键！） |
| **前缀和** | 计数数组累加成位置区间 | 定位每个元素的落位 |
| **补位** | 短字符串末尾补最小字符 | 变长字符串 LSD 的对齐方案 |
| **字节基数排序** | r=256，每次处理 8 位 | 工程标准：4 轮完成 32 位整数 |
| **比较下界** | Ω(n log n) 对所有比较排序 | 基数排序靠"非比较"绕开它 |
| **值域索引** | 用键值直接定位而非比较 | 计数/基数/桶的共同思想 |

## 5. 复杂度与特性速查表

| 维度 | 最好 | 平均 | 最坏 | 说明 |
|------|:---:|:---:|:---:|------|
| 时间复杂度 | O(d·(n+r)) | O(d·(n+r)) | O(d·(n+r)) | 与数据有序度无关（非比较） |
| 空间复杂度 | O(n+r) | O(n+r) | O(n+r) | 结果数组 O(n) + 计数 O(r) |
| 稳定性 | ✔ 稳定 | — | — | 倒序回填保证 |
| 适应性 | ✘ 无 | — | — | 有序/无序等速 |
| 定长键特例 | O(n) | O(n) | O(n) | 32 位整数 r=256 → d=4 恒定 |

**与线性排序"三兄弟"对比**：

| 算法 | 维度 | 复杂度 | 键要求 | 空间 | 适用 |
|------|:---:|:---:|------|:---:|------|
| 计数排序 | 值域 | O(n+k) | 值域小（整数） | O(k) | 成绩 0-100 等小值域 |
| 基数排序 | 位数 | O(d·(n+r)) | 可分位（定长键） | O(n+r) | 32 位整数、定长字符串 |
| 桶排序 | 分布 | O(n) 期望 | 均匀分布 | O(n) | 随机数等均匀数据 |

> 🎯 **一句话选型**：三兄弟共用"值域索引"思想——**计数是单轮索引（值域小），基数是分位多轮（值域大但可分位），桶是分布分区（数据均匀）**。需要稳定时计数/基数可保证，桶取决于桶内排序。定长整数 + 大 n + 稳定需求 → 基数排序是唯一线性选项。

## 6. 常见误区速查

| 误区 | 正解 |
|------|------|
| "基数排序是桶排序的别名" | ❌ 基数是"按位多轮 + 稳定累积"；桶是"单轮分区 + 桶内排序" |
| "基数排序必须用十进制" | ❌ 基数任意：r=256（字节）是工程主流，轮数更少 |
| "LSD 与 MSD 复杂度不同" | ❌ 同为 O(d·(n+r))；区别在实现（稳定累积 vs 递归分桶）与适用键型 |
| "基数排序总是快于快排" | ❌ 渐进是，实际看规模：n 大 + 定长键赢，n 小快排常数小 |
| "负数取绝对值排完就是答案" | ❌ 绝对值会乱序（-3 绝对值比 -1 大，但 -3 < -1）；需偏移或符号位变换 |
| "每轮用不稳定排序也行" | ❌ 稳定性是正确性核心——高位相同时低位顺序必须保留 |
| "计数排序正序回填也能保证稳定" | ❌ 正序回填会覆盖元素、破坏稳定性；必须倒序回填 |
| "基数排序只能排整数" | ❌ 字符串（按字符位）、浮点（IEEE 754 位变换）均可 |
| "面试不考手写基数排序" | ❌ 面试少要求手撕，但**软考/考研的过程模拟题是高频考点** |
| "基数排序没有研究价值" | ❌ 2025-2026 GPU 排序前沿正是基数排序（Onesweep 进 CUB、libcusort） |
