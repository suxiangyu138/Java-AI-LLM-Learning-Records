## 1. 问题定义与难度定位

### 1.1 问题定义

```text
给定 n 个城市及两两间距离 d(i,j)，求一条从城市 1 出发、
访问每个城市恰好一次、最终回到城市 1 的最短回路（Hamiltonian 回路）。
```

- **对称 TSP**：d(i,j) = d(j,i)（无向）
- **非对称 TSP**：d(i,j) ≠ d(j,i)（有向，如单行道）
- 本文件默认对称 TSP

### 1.2 难度定位

- 是 NP-hard 问题中的**招牌问题**（连同 0-1 背包、SAT）
- 解空间 = (n−1)! / 2（对称性减半）
- n = 20 时约 1.2×10¹⁷ 条回路——穷举完全不可能
- 分支限界配合紧下界，**n ≤ 20 可精确求解**；更大规模交给求解器/启发式

> 💡 经典对比案例（教材常引）：**求解 n=15 的 TSP，回溯法跑了 40 分钟无结果，分支限界 3 秒出解**。这不是回溯菜，而是回溯没有界函数——它必须走完所有可行排列才知道谁最优。

## 2. 排列树建模

### 2.1 树结构

每个结点对应"访问序列的前 k 个城市已确定"：

```text
               [起点 1]
        /       |       \
     [1,2]    [1,3]    [1,4]
     /   \     /   \    ...
 [1,2,3] [1,2,4] ...
```

- 第 k 层结点：已走城市序列 v₁→v₂→…→vₖ，对应已走路程 cost
- 叶子（k = n）：还需走 vₙ→v₁ 闭合，形成完整回路
- 结点数：n! 量级（排列树，比子集树大得多）

### 2.2 结点状态

| 字段 | 含义 |
|------|------|
| path | 已确定的部分序列（ArrayList<Integer>） |
| cost | 已走路程 Σ d(前驱, 后继) |
| lb | 下界（见第 3 节） |
| visited | 城市访问标记（可选，用 path.contains 代替） |

### 2.3 约束剪枝

- **不重复**：新城市必须在未访问集合中（visited 检查）
- **提前闭合**：已访问 n−1 个城市时只剩一个选择，直接算叶子
- **lb 剪枝**：lb ≥ best 则不入堆（限界剪枝，核心）

## 3. 下界函数：从 MST 到 1-树

### 3.1 为什么用 MST

**松弛**：删除"回路"约束（要求恰好一个环），只要求"访问全部城市且连通"，得到 **最小生成树（MST）**——多项式可解（Prim O(n²)）。

**合法性**：任何一条合法回路删去任意一条边后，剩余 n−1 条边恰好构成一棵生成树：

```text
回路总长 = 树边权和 + 被删边 ≥ MST 权值
→ MST 权值 ≤ 回路总长  →  MST 权值是回路长度的下界 ✔
```

### 3.2 结点处如何计算

对结点（已走 k 个城市，已花费 cost）：

```text
lb = cost + MST(剩余城市 ∪ {vₖ, v₁} 组成的子图)
```

其中"剩余城市 + 起点 + 终点"必须连通成树（回路的剩余部分本质是它们之间的连接），MST 给出最省连接。

### 3.3 1-树（1-tree）：更紧的下界

MST 允许起点/终点度数不足，不够"像回路"。**1-树** 固定城市 1：

```text
1-tree = 城市1连两条最短边 + (其余城市)的 MST
lb₁₋ₜᵣₑₑ = cost + 1-tree 权值(未访问城市)
```

为什么更紧：回路中城市 1 的度数**恰好为 2**（进来 + 出去），而 1-tree 强制城市 1 只连两条边（度数 2），比 MST（可能度数 1）更接近真实结构，因此下界 ≥ MST 下界。

| 下界 | 计算成本 | 紧度 | 说明 |
|------|:---:|:---:|------|
| 0 下界 | O(1) | 极松 | 退化 BFS |
| MST 下界 | O(n²) | 中 | 教科书标准 |
| 1-树下界 | O(n²) | 较紧 | 对称 TSP 标配 |
| HK 势值修正 | O(n³)+ | 很紧 | 理论里程碑，工业级 |

> 🎯 **面试表述**："TSP 的下界来自松弛——去掉'必须成环'约束得到 MST；更进一步，固定起点的 1-树强制起点度数为 2，更贴近回路结构，界更紧。" 这一句就展示了从 03 文件的松弛方法论到具体问题的完整迁移。

## 4. 减枝策略：对称性与先行剪枝

### 4.1 对称性减枝（常数因子 2）

对称 TSP 中回路 1→2→3→4→1 与 1→4→3→2→1 是同一条回路（反向走）。因此在第二层**固定"第二个城市取编号小于第三个城市"**，或更简单：**只搜索 path 中第二个城市 < 最后一个城市的序列**——直接砍掉一半搜索树。

实现：扩展第 2 层时只允许新城市编号 < 第 n 层候选；或者在第 3 层强制 path[1] < path[2]（即第二个城市小于第三个城市）。

### 4.2 先行剪枝（动态可行性）

当已访问 n−1 个城市时，最后一步无选择自由——直接计算完整回路并更新 best，**跳过该叶子的入堆出堆**：

```java
if (cur.path.size() == n - 1) {
    int last = 唯一未访问城市;
    int total = cur.cost + d(cur.path.get(n - 2), last) + d(last, 0);
    best = Math.min(best, total);   // 直接更新，不入堆
    continue;
}
```

### 4.3 强连通剪枝（非对称 TSP）

非对称 TSP 中，若剩余城市到起点没有可行边（d = ∞），该结点必死——扩展前检查剩余城市集合是否强连通。

## 5. 优先队列式 Java 实现

```java
import java.util.*;

public class TspBranchAndBound {

    static int n;
    static int[][] dist;          // dist[i][j]，对称，i,j ∈ [0, n)
    static int best = Integer.MAX_VALUE;

    static class Node implements Comparable<Node> {
        List<Integer> path;       // 已访问序列（path.get(0) = 0 起点）
        int cost;                 // 已走路程
        int lb;                   // 下界
        Node(List<Integer> path, int cost, int lb) {
            this.path = new ArrayList<>(path);
            this.cost = cost;
            this.lb = lb;
        }
        @Override
        public int compareTo(Node o) { return Integer.compare(this.lb, o.lb); }
    }

    /** 未访问城市的 MST 权值（Prim），加上回起点所需（见 lb 公式） */
    static int mstLowerBound(Node cur) {
        boolean[] visited = new boolean[n];
        for (int c : cur.path) visited[c] = true;
        // 将当前路径的终点、起点与未访问城市一起连成 MST
        int[] minEdge = new int[n];
        Arrays.fill(minEdge, Integer.MAX_VALUE);
        boolean[] inTree = new boolean[n];
        int root = cur.path.get(cur.path.size() - 1);  // 从终点开始
        minEdge[root] = 0;
        int total = 0;
        for (int i = 0; i < n; i++) {
            int u = -1;
            for (int j = 0; j < n; j++)
                if (!inTree[j] && (u == -1 || minEdge[j] < minEdge[u])) u = j;
            inTree[u] = true;
            total += minEdge[u];
            for (int j = 0; j < n; j++)
                if (!inTree[j] && dist[u][j] < minEdge[j]) minEdge[j] = dist[u][j];
        }
        return total;
    }

    static int solve(int[][] d) {
        dist = d;
        n = d.length;
        best = Integer.MAX_VALUE;

        PriorityQueue<Node> heap = new PriorityQueue<>();
        List<Integer> start = new ArrayList<>();
        start.add(0);
        Node root = new Node(start, 0, mstLowerBound(new Node(start, 0, 0)));
        heap.offer(root);

        while (!heap.isEmpty()) {
            Node cur = heap.poll();
            if (cur.lb >= best) break;          // 提前终止：堆顶都不比 best 好
            if (cur.path.size() == n) {         // 完整回路
                best = Math.min(best, cur.cost + dist[cur.path.get(n - 1)][0]);
                continue;
            }
            if (cur.path.size() == n - 1) {     // 先行剪枝：最后一步直接结算
                int last = -1;
                for (int c = 0; c < n; c++) if (!cur.path.contains(c)) { last = c; break; }
                int total = cur.cost + dist[cur.path.get(n - 1)][last] + dist[last][0];
                best = Math.min(best, total);
                continue;
            }
            for (int next = 0; next < n; next++) {
                if (cur.path.contains(next)) continue;          // 不重复
                if (cur.path.size() == 1 && next != 1) continue; // 对称性：第二个城市固定从 1 开始
                int newCost = cur.cost + dist[cur.path.get(cur.path.size() - 1)][next];
                Node child = new Node(cur.path, newCost, 0);
                child.path.add(next);
                child.lb = newCost + mstLowerBound(child);
                if (child.lb < best) heap.offer(child);
            }
        }
        return best;
    }

    public static void main(String[] args) {
        int[][] d = {
            {0, 10, 15, 20},
            {10, 0, 35, 25},
            {15, 35, 0, 30},
            {20, 25, 30, 0}
        };
        System.out.println(solve(d));   // 期望 80：0→1→3→2→0 = 10+25+30+15
    }
}
```

> ⚠️ 实现注意：
> 1. `mstLowerBound` 在结点扩展时被反复调用，每次 O(n²)——n ≤ 20 时可接受；n 更大时用**增量 MST**（只更新受影响边）或换 1-树
> 2. 对称性固定"第二个城市 = 1"（代码中 `next != 1` 剪枝）——把 n! 的树砍到 (n−1)!，再配合正向/反向合并其实减半，实际探索量约为 (n−1)!/2
> 3. 本例 `lb >= best` 的终止与入堆条件都用"严格"语义：lb == best 的子树最多打平，不需要

## 6. 手动走查：n=4 全流程

**数据**：距离矩阵（上例）：d(0,1)=10, d(0,2)=15, d(0,3)=20, d(1,2)=35, d(1,3)=25, d(2,3)=30。全图 MST = 10+15+20 = 45（三条最短边 0-1、0-2、0-3），lb = 已走路程 + 45。

| 步骤 | 操作 | 堆（lb, path） | best |
|:---:|------|----------------|:---:|
| 1 | 根 [0] 入堆：lb = 0 + 45 = 45 | {[0]:45} | ∞ |
| 2 | 扩展 [0]：生成 [0,1] lb=10+45=55、[0,2] lb=15+45=60、[0,3] lb=20+45=65 | {[0,1]:55, [0,2]:60, [0,3]:65} | ∞ |
| 3 | 扩展 [0,1]（lb 55 最小）：[0,1,2] lb=45+45=90、[0,1,3] lb=35+45=80 | {[0,2]:60, [0,3]:65, [0,1,3]:80, [0,1,2]:90} | ∞ |
| 4 | 扩展 [0,2]（60）：[0,2,1] lb=50+45=95、[0,2,3] lb=45+45=90 | {[0,3]:65, [0,1,3]:80, [0,2,3]:90, [0,1,2]:90, [0,2,1]:95} | ∞ |
| 5 | 扩展 [0,3]（65）：[0,3,1] lb=45+45=90、[0,3,2] lb=50+45=95 | {[0,1,3]:80, [0,2,3]:90, [0,1,2]:90, [0,3,1]:90, [0,2,1]:95, [0,3,2]:95} | ∞ |
| 6 | 扩展 [0,1,3]（80）：子结点 [0,1,3,2] 已满 4 城 → 叶子结算 best = 65 + d(2,0) = 65+15 = **80**（回路 0→1→3→2→0） | … | **80** |
| 7 | 依次扩展 size=3 结点（先行剪枝直接结算）：[0,2,3] → 45+25+10=80；[0,1,2] → 45+30+20=95；[0,3,1] → 45+35+15=95；[0,2,1] → 50+25+20=95。best 保持 80 | … | 80 |
| 8 | 堆顶 lb = 110 ≥ best = 80 → **提前终止**，输出 80 | — | **80** |

> 🎯 **要点**：整个搜索只扩展了 8 个结点（穷举需 6 条回路、搜索树含 33 个结点），且在找到最优解 80 后立即通过"堆顶 lb ≥ best"证明最优——这就是界函数 + 提前终止的合力。注意步骤 7 中 [0,2,3] 的结算值 80 与 best 打平，未更新——但它证明了"并列最优"的存在。

## 7. 与回溯法、动态规划求解对比

| 维度 | 回溯法 | 动态规划（Held-Karp） | 分支限界 |
|------|-------|---------------------|---------|
| 思路 | DFS 枚举全部排列 | 状态 (S, j)：子集 + 终点 | Best-First + 下界剪枝 |
| 时间复杂度 | O(n!) | O(n²·2ⁿ) | 最坏 O(n!)，实际远小于 |
| 空间复杂度 | O(n) | **O(n·2ⁿ)（巨大）** | O(活结点数) |
| n 上限 | ≤ 11 左右 | ≤ 20（内存极限） | ≤ 20~30（界够紧时） |
| 适用 | 教学 | n 固定且需严格上界 | 实际精确求解首选 |

> 💡 面试对比题标准答案：**"DP 的 Held-Karp 用子集状态压到 O(n²2ⁿ)，但空间 O(n2ⁿ) 在 n≥21 就爆内存；分支限界空间是动态的、由剪枝决定，配合紧下界能解到 n=20+。两者其实可以融合——先跑 DP 得到 best 作为分支限界的初始解。"**（融合思想是加分项）

## 8. 规模与实战建议

| n | 建议方法 | 说明 |
|:---:|---------|------|
| ≤ 10 | 回溯 / 暴力全排列 | 足够快 |
| ≤ 20 | 分支限界（MST/1-树下界） | 精确求解黄金区间 |
| ≤ 40 | 分支限界 + 紧界 + 增量优化 | 视数据分布，可能仍需时间限制 |
| > 40 | 启发式（2-opt、模拟退火、遗传）或求解器 | 精确解不可行，转近似 |

**实战三步走**：① 贪心（最近邻）构造初始 best → ② 分支限界精确求解 → ③ 超时则用 2-opt 局部搜索兜底。

> 🎯 **核心要点**：TSP 是分支限界"秀肌肉"的地方——**排列树（n!）比子集树（2ⁿ）大得多，界函数的价值也大得多**。掌握三个层次：MST 下界（删约束松弛）、1-树下界（加结构约束紧化）、对称性剪枝（常数因子减半）。n=15 回溯 40 分钟 vs 分支限界 3 秒的案例是面试讲故事的利器。
