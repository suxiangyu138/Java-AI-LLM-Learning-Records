## 1. 装载问题：最大堆教科书范本

### 1.1 问题定义

```text
n 个集装箱，重量 wᵢ，两艘船载重量 C₁、C₂。
求一种装载方案，使第一艘船装得尽可能多，其余装第二艘。
```

第一艘船装得最多 ⇔ 子集和问题（subset sum）变体——选一个子集使总重 ≤ C₁ 且最大。

### 1.2 建模与上界

- **解空间树**：子集树（每箱 装/不装）
- **上界函数**（超简单但有效）：

```text
ub = 当前已装总重 + 剩余集装箱总重
```

理由：剩余箱子重量都是非负收益，全部装上也最多增加这么多 → 合法上界。注意它比分数背包上界松，但装载问题没有"价值"维度、目标就是重量本身，这个界已经是"最紧"的简单界。

### 1.3 Java 实现骨架（最大堆）

```java
static class Node {
    int level;      // 已决策箱子数
    int weight;     // 已装总重
    int ub;         // 上界 = weight + 剩余总重
}

static int shipLoad(int[] w, int capacity) {
    int n = w.length;
    int total = Arrays.stream(w).sum();
    PriorityQueue<Node> heap = new PriorityQueue<>((a, b) -> b.ub - a.ub);
    int best = 0;
    heap.offer(new Node(0, 0, total));
    while (!heap.isEmpty()) {
        Node cur = heap.poll();
        if (cur.ub <= best) break;                    // 提前终止
        if (cur.level == n) {
            best = Math.max(best, cur.weight);        // 叶子：完整方案
            continue;
        }
        // 不装
        Node skip = new Node(cur.level + 1, cur.weight,
                cur.weight + (total - prefixSum[w, cur.level + 1]));
        if (skip.ub > best) heap.offer(skip);
        // 装（约束检查）
        if (cur.weight + w[cur.level] <= capacity) {
            Node take = new Node(cur.level + 1, cur.weight + w[cur.level],
                    cur.weight + w[cur.level] + (total - prefixSum[w, cur.level + 1]));
            if (take.ub > best) heap.offer(take);
        }
    }
    return best;
}
```

> 💡 两船问题的完整解：第一船装 best 后，剩余集装箱若总重 ≤ C₂ 则方案可行，否则无解（此时可尝试换目标或输出"第一船最多装多少"作为答案）。面试题通常只问第一船的装载量。

## 2. 作业分配问题：排列树 + 成本下界

### 2.1 问题定义

```text
n 个作业分给 n 个人（每项作业恰由一人完成、每人恰做一项），
第 i 人做第 j 项作业的成本 c[i][j]，求最小总成本。
```

这就是**指派问题（Assignment Problem）**。n ≤ 20 时可以用匈牙利算法 O(n³) 精确求解；而分支限界解法是软考/教材的常客，且是理解"排列树下界"的绝佳例子。

### 2.2 建模与下界

- **解空间树**：排列树（确定第 1 项作业给谁、第 2 项给谁……）
- **下界函数**（删约束松弛）：

```text
lb = 已分配成本 + Σ(剩余每项作业的"最小可能成本")
```

其中"最小可能成本" = 该项作业在**未被占用的人**中取成本最小者。注意每项作业独立取最小值可能让同一个人被取多次——这正是**松弛**（删除"每人只做一项"约束），故 lb 合法（≤ 真实最优）。

```java
static int lowerBound(int assignedCost, boolean[] usedPerson, int[][] cost) {
    int n = cost.length, lb = assignedCost;
    for (int job = 0; job < n; job++) {
        if (job < assignedCount) continue;    // 已分配的作业跳过（其成本已计入）
        int minC = Integer.MAX_VALUE;
        for (int person = 0; person < n; person++)
            if (!usedPerson[person]) minC = Math.min(minC, cost[person][job]);
        lb += minC;
    }
    return lb;
}
```

### 2.3 更紧的变体

- **行/列归约**：先对成本矩阵做行、列归约（每行减最小、每列减最小），归约和本身是一个全局下界，且归约后的矩阵对角线可作为初始 best
- 这与求解器中的 **LP 松弛 + 取整** 是同一思想的不同表现

## 3. 多机调度问题：makespan 下界

### 3.1 问题定义

```text
n 个作业（处理时间 pᵢ）分配给 m 台相同的机器，每台机器按顺序处理分到的作业，
求最小化最大完工时间 C_max（makespan）。
```

NP-hard（m ≥ 2 时）。教科书用它展示**多约束下界的组合**：

### 3.2 三层下界

```text
lb = max( ① 已分配机器上的最大负载,
          ② 剩余作业总时间 / m,        // 平均分摊的乐观下限
          ③ 剩余作业中单个最大时间 )    // 至少要做最久的那个
```

- ① 是确定值（不是松弛）
- ② 是"把剩余工作完美平摊到 m 台"的松弛 → 下界
- ③ 是"至少一台上要做最长的作业"的松弛 → 下界

三者取 max = 三个独立松弛的交集，**比任一单独下界都紧**——这是"组合下界"的通用手法：每个松弛给一个约束，取最紧的那个。

### 3.3 工程扩展

- 初始 best：用贪心（LPT：最长处理时间优先）构造可行调度
- 结合分支限界可精确解 n ≤ 30 左右；工业上大规模调度交给 CP-SAT/OR-Tools（09 文件）

## 4. 布线问题：队列式 BFS 变体

### 4.1 问题定义

```text
电路板上网格（m×n），起点 s 到终点 t，障碍物不能经过，
求最短路径（可上下左右走）。
```

### 4.2 为什么用队列式分支限界

网格图最短路径 = BFS 天然最优（无权图）。分支限界视角：

- **解空间**：网格上的路径树（每个格子向 4 邻域扩展）
- **活结点表**：队列（FIFO）
- **界函数**：**曼哈顿距离**——当前点到终点的直线距离（忽略障碍物）是剩余路程的下界 → 用 `已走步数 + 曼哈顿距离` 剪枝

```text
已走步数 + 曼哈顿距离 ≥ best  →  剪枝
```

> 💡 这就是 **A*** 的原型：`f(n) = g(n) + h(n)`，h = 曼哈顿距离（可采纳）。布线问题在实践中就是 A* 解决，而 A* = 优先队列式分支限界——**同一个算法在不同教材里的两个名字**。

### 4.3 与纯 BFS 的对比

| 维度 | 纯 BFS | 队列式 B&B（A* 变体） |
|------|:---:|:---:|
| 扩展顺序 | 严格按层 | 按 f = g+h 择优 |
| 剪枝 | 无（仅去重） | 曼哈顿下界剪枝 |
| 空间 | O(mn) | O(mn)（但实际更小） |
| 效率 | 中等 | 更快（下界引导） |

## 5. 最大团问题：子集树 + 乐观上界

### 5.1 问题定义

```text
无向图 G，团 = 两两都有边的顶点子集，求最大团（顶点数最多）。
```

NP-hard。它与独立集、顶点覆盖互相等价（补图关系）。

### 5.2 建模与上界

- **解空间树**：子集树（顶点 加入/不加入）
- **上界**：

```text
ub = 当前团大小 + (候选顶点中"与当前团全连通"的顶点数)
```

候选 = 尚未决策且与团内所有顶点都相邻的顶点。全部加入（乐观假设）得到的规模是上界。

### 5.3 剪枝细节

- 约束剪枝：新顶点必须与当前团内**每个**顶点相邻（否则不是团）
- 限界剪枝：`ub ≤ best` 剪掉
- 加速技巧：按度数降序处理顶点，大度数顶点先决策，让 best 更早变大

## 6. 单源最短路径：B&B 视角重读 Dijkstra

### 6.1 统一视角

```text
Dijkstra = 优先队列式分支限界，其中：
  lb(结点) = 已确认的最短路距离（从起点到该点）
  = g(v) + 0    （0 是"剩余路程"的平凡下界，非负边权保证）
  提前终止 = 终点出堆即最优（堆顶 lb 最小 ⇒ 所有其他点路径都不更短）
```

### 6.2 为什么 A* 通常更快

A* 把 0 换成**可采纳启发式 h(v)**（如到终点的欧氏距离），lb = g(v) + h(v) 更紧 → 更早剪枝、更少扩展。代价：h 必须满足一致性（单调性），否则界函数失效。

### 6.3 三个名字一个算法

| 算法 | 界函数 | 说明 |
|------|-------|------|
| Dijkstra | g(v) + 0 | 无启发，最通用 |
| A* | g(v) + h(v) | h 可采纳时最优 |
| 分支限界 | 自定义 lb/ub | 框架本身 |

> 🎯 **把这里彻底想通，图论搜索与组合优化就打通了**：最短路径是"最小化问题的分支限界特例"，而分支限界是最短路径思想的推广。面试被问"A* 和 Dijkstra 的区别"，答"A* 是带了可采纳启发式的 Dijkstra，等价于分支限界里更紧的下界"——直接封顶。

## 7. 问题-模型-界函数对照总表

| 问题 | 解空间树 | 界函数 | 界函数来源（松弛） | 活结点表 |
|------|:---:|------|------|:---:|
| 0-1 背包 | 子集树 | 分数背包上界 | 连续化松弛 | 最大堆 |
| 装载问题 | 子集树 | 已装 + 剩余总重 | 全装乐观假设 | 最大堆 |
| 最大团 | 子集树 | 团规模 + 连通候选数 | 全候选可加入乐观假设 | 最大堆 |
| TSP | 排列树 | MST / 1-树下界 | 删"成环"约束 | 最小堆 |
| 作业分配 | 排列树 | 已分配 + 剩余作业逐项最小成本 | 删"一人一项"约束 | 最小堆 |
| 多机调度 | 满 m 叉树 | max(当前负载, 剩余均值, 最大单作业) | 三个松弛取 max | 最小堆 |
| 布线 | 网格图 | 已走步数 + 曼哈顿距离 | 删障碍约束（A* 启发） | 队列/最小堆 |
| 单源最短路 | 图 | g(v) + h(v) | 非负边权 / 可采纳启发 | 最小堆 |

> 🎯 **核心要点**：所有界函数都可以用 03 文件的方法论复现——**找约束、删约束、取极值**。背包删"整数性"（连续化）、TSP 删"成环"（MST）、分配删"一人一项"（逐项最小）、布线删"障碍"（曼哈顿）。**会设计松弛，就会设计界函数**——这就是本文件五个问题的共同密码。
