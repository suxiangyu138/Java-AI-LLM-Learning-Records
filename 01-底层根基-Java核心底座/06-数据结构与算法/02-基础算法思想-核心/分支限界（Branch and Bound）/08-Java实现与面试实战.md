## 1. 通用骨架：所有 B&B 代码的母版

无论子集树还是排列树，代码结构完全一致（这也是 B&B 最优雅的地方）：

```java
// ① 结点定义
static class Node {
    int level;            // 已决策深度（或 path 长度）
    // 问题相关状态：curWeight / curValue / path / cost ...
    double bound;         // 界值：ub（最大化）或 lb（最小化）
}

// ② 界函数（问题相关，独立方法）
static double bound(Node node) { ... }

// ③ 主循环（通用骨架）
static double branchAndBound() {
    // 预处理：排序（背包按单位价值、TSP 按距离等）
    PriorityQueue<Node> heap = new PriorityQueue<>(
            (a, b) -> Double.compare(b.bound, a.bound));   // 最大化：最大堆
    double best = 0;                                       // 初始最优值
    heap.offer(根结点);
    while (!heap.isEmpty()) {
        Node cur = heap.poll();
        if (cur.bound <= best) break;                      // ④ 提前终止
        if (cur.level == MAX) { best = max(best, cur.value); continue; } // 叶子
        for (每个子结点 child) {
            if (!可行(child)) continue;                    // ⑤ 约束剪枝
            child.bound = bound(child);
            if (child.bound > best) heap.offer(child);     // ⑥ 限界剪枝
        }
    }
    return best;
}
```

**六个固定零件**：结点类、界函数、堆（大小方向）、提前终止、约束剪枝、限界剪枝。**面试默写时按这六块讲，逻辑不会乱**。

> 🎯 记忆口诀：**"一结点二界三堆，四停五约六限"**——六个零件顺序背诵，任何 B&B 题都能在 5 分钟内搭出框架。

## 2. 模板一：子集树 + 最大堆（最大化）

适用：0-1 背包、装载、最大团。核心差异只在**界函数**，骨架复用第 1 节：

```java
// 0-1 背包界函数：当前价值 + 剩余容量分数背包
static double upperBound(int level, int weight, int value,
                         int capacity, int[] w, int[] v) {
    double bound = value;
    int remain = capacity - weight;
    for (int i = level; i < w.length && remain > 0; i++) {
        if (w[i] <= remain) { bound += v[i]; remain -= w[i]; }
        else { bound += (double) v[i] / w[i] * remain; break; }
    }
    return bound;
}

// 装载问题界函数：当前重量 + 剩余总重（更简单）
static int upperBoundLoad(int level, int weight, int[] w, int suffixSum) {
    return weight + (suffixSum - prefixSum[level]);   // 预处理后缀和，O(1)
}
```

**子集树模板要点**：

```text
分支 = 2 个（选/不选）→ 循环写死两次调用，或 for (int take = 0; take <= 1; take++)
深度 = n → level == n 时是叶子
预处理 = 排序（背包）或后缀和（装载）
```

## 3. 模板二：排列树 + 最小堆（最小化）

适用：TSP、作业分配、调度。骨架同第 1 节，差异：

```java
// 结点携带 path（已访问序列）
static class Node {
    List<Integer> path;
    int cost;
    int lb;
}

// 最小堆（lb 小者优先）
PriorityQueue<Node> heap = new PriorityQueue<>((a, b) -> a.lb - b.lb);
double best = Double.MAX_VALUE;

// 扩展：遍历所有未访问的下一城市
for (int next = 0; next < n; next++) {
    if (path.contains(next)) continue;              // 不重复约束
    // 对称性剪枝（TSP 专属，可选）
    if (path.size() == 1 && next > 1) continue;
    Node child = new Node(path, cost + d(last, next), lb(child));
    if (child.lb < best) heap.offer(child);
}

// 叶子/先行剪枝
if (cur.path.size() == n - 1) {                     // 只差最后一步
    int total = cur.cost + d(last, unvisited) + d(unvisited, 0);
    best = Math.min(best, total);
    continue;
}
```

**排列树模板要点**：

```text
分支 = 所有未访问元素（循环 + contains 检查）
深度 = n → path.size() == n 是叶子（或 n−1 先行剪枝）
对称性剪枝 = TSP 第二层固定，砍掉一半
界函数 = cost + 松弛项（MST/1-tree/逐项最小）
```

## 4. PriorityQueue 使用避坑清单

| 坑 | 错误示范 | 正确做法 | 后果 |
|----|---------|---------|------|
| 比较器直接相减 | `(a,b) -> b.bound - a.bound` | `(a,b) -> Double.compare(b.bound, a.bound)` | double/int 溢出或精度丢失 → 堆顺序错乱 |
| 堆方向搞反 | 最小化问题用最大堆 | 最小化 → 最小堆；最大化 → 最大堆 | 扩展顺序错 → 慢/错 |
| 忘记最大堆 | 直接 `new PriorityQueue<>()` | 最大堆必须反转比较器 | Java PQ 默认最小堆 |
| 界值 float 比较 | `==` 判等 | 用 `<=` / `>=` 语义 | 边界误判 |
| 结点可变导致堆失效 | 入堆后修改结点字段 | 结点入堆后**只读**（或重新 offer） | 堆性质破坏，扩展乱序 |
| 记录方案时共享引用 | `Node.path` 直接赋值 | 拷贝 `new ArrayList<>(path)` | 所有结点共享同一 list，方案错乱 |

> ⚠️ 第 6 条是最高频 bug：**B&B 结点必须携带独立副本**（它不做"撤销"），这与回溯的"路径复用"完全相反——写代码时最容易惯性用错。

LeetCode 题目规模小、状态可压缩，官方题解几乎全部用 DP/回溯/图算法。B&B 的战场在**软考、考研、算法设计课、运筹场景**。但以下题目是**思想映射**（解法用到 B&B 的组件或可优化）：

| 题号 | 题目 | 与 B&B 的关系 |
|:---:|------|------|
| 743 | 网络延迟时间 | Dijkstra 模板 = B&B 特例（最小堆 + 0 下界） |
| 787 | K 站中转最便宜 | 类 B&B：按 cost 优先扩展 + 站数剪枝 |
| 126 | 单词接龙 II | 双向 BFS 剪枝 = 界思想 |
| 847 | 访问所有节点最短路径 | TSP 变体：mask + BFS/DP（n ≤ 12） |
| 698 | 划分为 k 个相等子集 | 子集树 + 强剪枝（可换 B&B 表述） |

## 6. 软考考点精讲

软件设计师（2023-2026）与系统架构师考试中 B&B 的三类题型：

### 6.1 概念对比题（选择题）

必考原型：
> 下列关于分支限界法与回溯法的说法中，**错误**的是？
> A. 回溯法深度优先搜索解空间树
> B. 分支限界法广度优先或最小耗费优先搜索
> C. 回溯法只求可行解，分支限界法求最优解
> D. 分支限界法的界函数可以任意设计

**答案 D**（界函数必须合法、单调、根含最优）。答题技巧：选项中凡出现"任意/随意/无需满足"修饰界函数，必错。

### 6.2 限界函数设计题（简答/填空）

> 0-1 背包问题的分支限界法中，上界函数如何构造？为什么是上界？

标准答案：物品按单位价值降序；上界 = 已选价值 + 剩余容量按单位价值顺序做**分数背包**的贪心最优值；因分数背包可行域包含 0-1 背包可行域，其最优值 ≥ 0-1 背包最优值，故为合法上界。

### 6.3 搜索过程题（大题）

给数据让画出搜索树、写出扩展顺序、标注剪枝结点、给出最优解。解题模板：

```text
① 先写界函数公式与初始 best
② 画树：每层标注（ub/lb, 路径）
③ 按堆优先级标扩展序号
④ 标出剪枝结点（约束剪枝 ⓧ / 限界剪枝 ✂）
⑤ 叶子或提前终止时给出最优值
```

> 🎯 得分要点：**过程题必须把"提前终止那一行"写出来**——在堆顶界不优于 best 处明确标注终止原因，这是阅卷采分点，也是与回溯答案区分的标志。

## 7. 面试话术与模拟追问

### 7.1 一分钟自我介绍版（背下来）

> "分支限界是求解组合优化问题的精确算法，核心是**解空间树 + 界函数**。分支指广度或最佳优先扩展子结点，限界指用上界/下界剪掉不可能产生更优解的子树。它和回溯的区别是：回溯 DFS 找所有解、只做约束剪枝；分支限界 Best-First 找最优解、额外做最优性剪枝，而且可以在未搜完时通过界值证明最优。我用它解过 0-1 背包和 TSP，0-1 背包的上界是分数背包松弛，TSP 的下界是 MST。"

### 7.2 追问三板斧

| 追问 | 高分回答 |
|------|---------|
| "为什么能保证最优？" | 界函数合法 + 单调 + 根覆盖最优，三前提保证只剪无望子树 |
| "最坏复杂度？" | 最坏 O(2ⁿ)/O(n!)，与穷举同阶；实际由界紧度决定 |
| "和 A* 什么关系？" | A* 是 B&B 特例：lb = g + h，h 可采纳即界合法；Dijkstra 是 h ≡ 0 的退化 |

### 7.3 一个加分的延伸

> "另外我了解工业级 MIP 求解器（Gurobi、OR-Tools）的核心就是 Branch and Cut——B&B 加割平面收紧 LP 松弛界，配合启发式初始解；2025 年的前沿方向是用图神经网络和强化学习学习分支策略，目标是在不牺牲最优性的前提下大幅剪枝。"
