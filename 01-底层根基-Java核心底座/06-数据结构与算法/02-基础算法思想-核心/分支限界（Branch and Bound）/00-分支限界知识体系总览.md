## 1. 知识体系导图

```text
分支限界（Branch and Bound）
│
├── 核心本质 ──────────────────────────────────────────────
│   ├── = BFS / 最佳优先（Best-First）+ 界函数剪枝
│   ├── 核心套路：分支（扩展子结点）→ 限界（估算剪枝）
│   ├── 适用判断："求最优解 + 解空间可枚举" → 精确算法
│   └── 解空间树模型：子集树 / 排列树 / 满 m 叉树
│
├── 三要素 ────────────────────────────────────────────────
│   ├── 活结点表（队列 / 优先队列 / 堆）
│   ├── 扩展结点选择策略（FIFO / LIFO / 最大效益优先）
│   └── 限界函数（上界 ub / 下界 lb + 单调性）
│
├── 两类经典实现 ──────────────────────────────────────────
│   ├── 🟡 队列式（FIFO）：BFS 变体，教学演示常用
│   │   └── 简单直观、无优先级、不提前终止
│   ├── 🔴 优先队列式（Best-First）：工程与竞赛首选
│   │   ├── 最大化 → 最大堆（ub 大者先扩展）
│   │   ├── 最小化 → 最小堆（lb 小者先扩展）
│   │   └── 队头不优于 best → 提前终止（正确性可证明）
│   └── 回溯式（LIFO/DFS 变体）：与回溯法衔接
│
├── 界函数设计（核心中的核心）──────────────────────────────
│   ├── 上界（最大化）：分数背包松弛 / 线性松弛 / 贪心估算
│   ├── 下界（最小化）：MST 松弛 / 1-树 / 路径松弛 / 贪心
│   ├── 三大原则：界类型匹配、单调性、根结点界含最优解
│   └── 松紧权衡：界越紧剪枝越多，但计算代价越高
│
├── 五大经典题型 ──────────────────────────────────────────
│   │
│   ├── 🟡 0-1 背包（子集树 + 分数背包上界）
│   │   └── 最经典入门题，几乎人人会考
│   ├── 🔴 旅行商 TSP（排列树 + MST/1-树下界）
│   │   └── 对比回溯法：40 分钟 vs 3 秒的经典案例
│   ├── 🟡 装载问题（子集树 + 上界 = 剩余总重）
│   │   └── 最大堆优先队列实现教科书范本
│   ├── 🟡 作业调度 / 分配问题（排列树 + 成本下界）
│   │   └── 任务分配、流水作业、时间表问题
│   └── 🟡 布线 / 最大团 / 单源最短路径（BFS 变体）
│
├── 与四大算法对比 ────────────────────────────────────────
│   ├── 回溯法：DFS 找所有解 ↔ 分支限界找最优解
│   ├── 贪心：局部最优近似 ↔ 分支限界全局最优
│   ├── 动态规划：子问题重叠 ↔ 分支限界无重叠依赖
│   └── A* / Dijkstra：B&B 的特例（一致/可采纳启发式）
│
└── 现代演进 ─────────────────────────────────────────────
    ├── Branch and Cut（B&B + 割平面）→ 工业级 MIP 求解器
    ├── OR-Tools CP-SAT / HiGHS / SCIP / Gurobi / CPLEX
    ├── ML / RL 增强分支策略（GNN、MDP 建模，2025 前沿）
    └── 混合求解：CP-SAT 作为 B&B 验证器（2025 实践）
```

## 4. 核心概念速查

| 概念 | 一句话解释 | 典型例题 |
|------|-----------|------|
| **分支（Branch）** | 扩展结点时一次性生成全部子结点，构成搜索树 | 所有 B&B 问题 |
| **限界（Bound）** | 用界函数估算子树最优值，无望子树直接剪掉 | 所有 B&B 问题 |
| **解空间树** | 所有可行解构成的空间树：子集树 / 排列树 / 满 m 叉树 | 背包=子集树，TSP=排列树 |
| **活结点** | 已生成但子结点尚未全部扩展的结点 | 队列/堆中的结点 |
| **扩展结点** | 正在生成子结点的活结点 | 每次循环队头 |
| **死结点** | 子结点已全部扩展或已被限界剪掉的结点 | 无需再处理的结点 |
| **限界函数（界函数）** | 估算结点子树最优值：ub（最大化）/ lb（最小化） | 分数背包上界、MST 下界 |
| **单调性** | ub(父) ≥ ub(子)、lb(父) ≤ lb(子)，保证不错剪 | 界函数合法性检查 |
| **队列式（FIFO）** | 活结点表用队列，BFS 式逐层扩展 | 教学示例、布线问题 |
| **优先队列式** | 活结点表用堆，最大/最小效益优先（Best-First） | 0-1 背包、TSP、装载 |
| **提前终止** | 堆顶界不优于当前最优解即可终止，安全且高效 | 优先队列式通用 |
| **松弛（Relaxation）** | 放宽约束得到的易解问题，其最优值构成合法界 | 分数背包、LP、MST |
| **Branch and Cut** | B&B + 割平面，工业级 MIP 求解器核心框架 | Gurobi / CPLEX / SCIP |

## 6. 复杂度速查表

| 问题 | 解空间树 | 结点数（最坏） | 队列式空间 | 优先队列式空间 | 界函数 |
|------|---------|:---:|:---:|:---:|------|
| 0-1 背包 | 子集树 | 2ⁿ⁺¹ − 1 | O(2ⁿ) | O(2ⁿ)（堆） | 分数背包上界 |
| 装载问题 | 子集树 | 2ⁿ⁺¹ − 1 | O(2ⁿ) | O(2ⁿ) | 剩余总重上界 |
| TSP | 排列树 | n!（约 n!/2 对称剪枝） | O(n!) | O(n!) | MST / 1-树下界 |
| 作业调度 | 排列树 | n! | O(n!) | O(n!) | 贪心下界 |
| 布线问题 | 网格图 | O(nm) | O(nm) | O(nm) | 曼哈顿距离 |
| 单源最短路（Dijkstra） | 图 | O(V) 结点 × 边扩展 | O(V+E) | O(V) 堆 | 已走路长 + 0 下界 |

> 🎯 **核心要点**：分支限界最坏情况仍是指数级（它毕竟是精确算法），但好的界函数能把搜索树剪到远小于穷举——这就是它存在的全部意义。**复杂度看最坏、效率看剪枝**，两者要分开讲。

## 7. 常见误区速查

| 误区 | 正解 |
|------|------|
| "分支限界 = 回溯 + 剪枝" | ❌ 搜索骨架不同：回溯是 DFS（空间 O(n)），分支限界是 BFS/Best-First（空间 O(2ⁿ)） |
| "界函数越紧一定越好" | ❌ 紧界剪枝多但计算贵，要算"剪枝收益 × 结点数 vs 计算成本"的性价比 |
| "分支限界和动态规划互相替代" | ❌ DP 依赖子问题重叠，B&B 不依赖——TSP 的 DP（Held-Karp）空间 O(n·2ⁿ) 爆内存时，B&B 仍是动态空间 |
| "贪心能求出最优就不用 B&B" | ❌ 贪心不保证最优（无贪心选择性质时）；B&B 保证最优，两者是"近似 vs 精确"生态关系 |
| "优先队列式空间小" | ❌ 栈式/DFS 空间 O(n) 最小；优先队列式时间快但空间最坏 O(2ⁿ) |
| "A* 和 Dijkstra 是不同算法" | ❌ 同一框架（B&B 特例）：A* = Dijkstra + 可采纳启发式 = 更紧的下界 |
| "界函数可以随意设计" | ❌ 必须合法（真上/下界）+ 单调 + 根结点界含最优解，否则会静默丢解 |
