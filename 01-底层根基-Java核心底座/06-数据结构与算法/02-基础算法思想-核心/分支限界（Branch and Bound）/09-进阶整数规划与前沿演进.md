## 1. 从组合问题到整数规划（MILP）

前八篇的问题（背包、TSP、调度、装载）都可以统一写成**混合整数线性规划（MILP）**：

```text
min / max  cᵀx
约束        Ax ≤ b
           xᵢ ∈ Z（整数变量），部分可为 0-1 布尔变量
```

例：0-1 背包的 MILP 形式：

```text
max   Σ vᵢ·xᵢ
s.t.  Σ wᵢ·xᵢ ≤ C
      xᵢ ∈ {0, 1}
```

**为什么统一写成 MILP 有意义**：工业界几乎所有的组合优化（生产排程、车辆路径、航班规划、投资组合、电网调度）都可以建模为 MILP，而 MILP 有一个**统一且强大的求解器生态**——它们的内核全部是分支限界。学完本系列前八篇，你就已经理解了求解器 80% 的原理。

## 2. LP 松弛：MILP 的界函数

### 2.1 定义

MILP 的界函数 = **LP 松弛**：把整数变量放宽为连续变量

```text
xᵢ ∈ {0,1}  →  0 ≤ xᵢ ≤ 1（连续）
```

LP 是多项式可解的（单纯形法 / 内点法），且 LP 可行域 ⊇ MILP 可行域，所以：

```text
最大化：LP 最优值 ≥ MILP 最优值  →  上界 ub ✔
最小化：LP 最优值 ≤ MILP 最优值  →  下界 lb ✔
```

这正是 03 文件"连续化松弛"思想的工业级版本——**分数背包上界就是 LP 松弛的一个具体实例**（分数背包恰好在多项式时间可解）。

### 2.2 B&B 在 MILP 上的完整流程

```text
① 根结点：解整棵 MILP 的 LP 松弛
② 若 LP 解恰好全整数 → 已是最优，结束
③ 否则取一个分数变量 xⱼ = 0.6，分支：
     左子：xⱼ ≤ 0（即 xⱼ = 0）
     右子：xⱼ ≥ 1（即 xⱼ = 1）
④ 各子结点解 LP 松弛，得各自界
⑤ 剪枝规则（三选一）：
     a. LP 无可行解 → 剪
     b. LP 最优值不优于 best → 剪
     c. LP 解全整数 → 更新 best（该结点不用再分）
⑥ 未剪的结点继续分支，直到证明最优
```

**教科书级区别**：MILP 的 B&B 分支依据是"分数变量的取值"（0.6 → 强制 ≤0 或 ≥1），而不是手写问题里的"选/不选"——但框架完全一致。

### 2.3 关键工程点

| 环节 | 技术 | 作用 |
|------|------|------|
| 初始 best | 启发式求可行整数解 | 剪枝提前生效 |
| 界 | LP 松弛（割平面收紧） | 更紧的界 = 更小搜索树 |
| 结点选择 | 最优界优先（Best-First）/ 深度优先混合 | 平衡速度与内存 |
| 变量选择 | 分数程度最大、伪代价、强分支 | 决定树形状 |
| 精度 | 双精度容忍 + 安全圆整 | 避免数值错误 |

## 3. Branch and Cut：B&B + 割平面

### 3.1 为什么需要割平面

LP 松弛的界往往不够紧（松弛解离整数解很远 → 树很大）。**割平面**：

```text
在 B&B 的结点上，若 LP 最优解 x* 不是整数：
  找一条不等式 αᵀx ≤ β，满足：
    ① 所有 MILP 可行解都满足（合法）
    ② x* 违反它（x* 被切掉）
  加入模型重新求解 LP → 界更紧
```

割平面在**不改变问题可行域**的前提下切掉松弛解的"角"，让 LP 界不断逼近 MILP 最优值——这就是"Branch **and Cut**"（分支 + 切）。

### 3.2 经典割平面族

| 割平面 | 适用场景 |
|--------|---------|
| Gomory 割（从单纯形表生成） | 通用，理论上可收敛 |
| 子环消除割（TSP） | 去掉 LP 松弛产生的"小回路" |
| 覆盖不等式（背包） | 0-1 问题 |
| knapsack cover cuts、clique cuts | 组合结构识别 |

> 💡 TSP 的工业级求解（Concorde 求解器）正是 **B&B + 子环消除割 + 1-树紧界**的组合，曾精确求解上万个城市的实例——纯手写 B&B 只能到 n ≈ 30，**差距就是割平面与高级界函数拉开的**。

### 3.3 完整求解器循环

```text
while (gap > 容忍度) {
    启发式: 尝试改进 best（可行解）
    结点:   选一个活结点
    LP:     解松弛 + 加割平面收紧（cut）
    if 界值 >= best → 剪枝
    else if 全整数 → 更新 best
    else → 选变量分支（branch）
}
```

`gap = (best_bound − best_incumbent) / best_incumbent` 是求解器的**进度条**——运行超时/内存受限时，输出"最优值在 [best, best_bound] 之间"，即**带证明的近似解**。这正是分支限界"提前终止"思想的工程化：**时间预算到了，用界值给出最优性证书区间**。

## 4. 工业级求解器全景

| 求解器 | 类型 | 核心 | 定位 |
|--------|------|------|------|
| Gurobi | 商业 | B&B + 割平面 + 启发式 | 性能标杆，学界业界标准 |
| CPLEX | 商业（IBM） | 同 Gurobi | 老牌巨头 |
| SCIP | 开源 | B&B + 割平面（框架化） | 学术研究主力，可定制 |
| HiGHS | 开源 | 单纯形 + B&B | 快速轻量，OR-Tools 默认 MIP 后端 |
| CBC | 开源 | B&B + 割平面 | 经典后端（OR-Tools 内置） |
| OR-Tools CP-SAT | 开源（Google） | SAT 推理 + 传播 + LNS | 逻辑约束多的组合问题，常快于传统 MIP |

> 🎯 一句话选型：**纯 MILP（变量主要是整数、约束线性）→ Gurobi/SCIP/HiGHS；含大量布尔变量与逻辑约束（if-then、排他、调度）→ CP-SAT；问题可建模为网络流 → 专用网络求解器更快**（OR-Tools 官方选型建议，见参考来源 1）。

## 5. OR-Tools 实战：MPSolver 与 CP-SAT

### 5.1 MPSolver（传统 B&B 包装）

```python
from ortools.linear_solver import pywraplp

solver = pywraplp.Solver.CreateSolver("CBC")   # 或 HiGHS
x = [solver.IntVar(0, 1, f"x{i}") for i in range(n)]
solver.Maximize(sum(v[i] * x[i] for i in range(n)))
solver.Add(sum(w[i] * x[i] for i in range(n)) <= C)
status = solver.Solve()          # 底层就是 B&B（+割平面）
print(solver.Objective().Value())
```

### 5.2 CP-SAT（2025 视角的推荐首选）

CP-SAT 不走传统 B&B 的 LP 松弛，而是用 **SAT 求解 + 约束传播 + 惰性线性松弛**——对布尔变量多的问题，它的剪枝更"狠"。

官方权威示例（CP-SAT Primer，参考来源 3）：**100 件物品的 NP-hard 背包问题（2¹⁰⁰ ≈ 10³⁰ 种可能），CP-SAT 用 0.01 秒求解并证明最优**——对比手写 B&B 的 n ≤ 50 适用边界，工业级工程的差距可见一斑。

```python
from ortools.sat.python import cp_model

model = cp_model.CpModel()
x = [model.NewBoolVar(f"x{i}") for i in range(n)]
model.Add(sum(w[i] * x[i] for i in range(n)) <= C)
model.Maximize(sum(v[i] * x[i] for i in range(n)))
solver = cp_model.CpSolver()
solver.Solve(model)
print(solver.ObjectiveValue())
```

> 💡 学习路径建议：手写 B&B（本系列）→ 理解原理 → OR-Tools 跑真实规模 → 读 CP-SAT Primer 源码级拆解。**原理（手写）与工具（求解器）双修，是运筹向面试的完整准备。**

## 6. 前沿一：机器学习增强分支策略（2025）

分支限界在 2025 年的最热方向：**用 ML/RL 学习"分支策略"和"结点选择"**，替代求解器里手调的专家启发式（参考来源 5/6/7）。

### 6.1 三个代表性工作

| 工作 | 方法 | 结果 |
|------|------|------|
| 学习高效 B&B（2025，Applied Soft Computing） | GNN + 模仿学习统一学习**变量选择 + 结点选择**，MILP 编码为二部图 | 在求解时间、搜索树大小、优化动态上超过开源标杆 SCIP 与近期 RL 方法 |
| BBMDP（NeurIPS 2025 Poster） | 把 B&B 的**变量选择**建模为马尔可夫决策过程（MDP），统一接入各种 RL 算法 | 在 4 个标准 MILP 基准上超过此前 SOTA RL 智能体 |
| ML for Exact Solvers 综述（2025） | 系统梳理 ML 嵌入 B&B 的四个环节：分支、割选择、结点排序、参数控制 | 强调"不牺牲全局最优性"的约束性增强 |

### 6.2 为什么值得关注

```text
传统 B&B:  分支策略 = 手调启发式（强分支/伪代价/最不可行）→ 经验主导
ML-B&B:    分支策略 = 神经网络（GNN 读 MILP 二部图）→ 数据主导
核心承诺:   保持"最优性保证"不变（界函数仍合法），只优化"树的形状"
```

> 💡 面试谈资：**"求解器的分支策略正在从专家规则走向学习模型——因为 B&B 的搜索树形状对求解速度影响巨大，而'哪个变量先分支'本质是一个可以学习的模式识别问题。2025 年的 GNN 方法与 RL 方法（BBMDP）已开始在标准基准上超越 SCIP 的手调启发式。"**

## 7. 前沿二：混合求解与领域特化

### 7.1 Hybrid B&B + CP-SAT（2025 实践）

Google OR-Tools 社区 2025 年的一个演示（参考来源 4）：**slack 驱动的 RF（Relative Feasibility）控制器**决定何时在 B&B 内部调用 CP-SAT：

```text
rf_score = slack（界 gap）× 时间因子
if rf_score 高:  用快速贪心补全当前结点
else:            用 CP-SAT 区间模型验证/收紧
```

CP-SAT 在这里**严格作为验证器**使用——B&B 负责主搜索结构，CP-SAT 负责难点结点的强推理。**"主求解器 + 强推理子求解器"的混合架构是 2025 年的明确趋势**。

### 7.2 领域特化 B&B

2025 年《European Journal of Operational Research》的领域成果（参考来源 8）：**带冲突约束的单源多目标最短路径**（NP-hard 扩展）的专用 B&B——松弛解、原始-对偶重优化、快速不可行检测三项技术把搜索树大幅压缩。**领域知识 → 更紧的界 → 更小的树**，再次印证本系列的核心方法论。

## 8. 从本系列回望：B&B 全景定位

```text
组合优化问题
 ├── 精确算法
 │    ├── 手写: 回溯 / DP / 分支限界（本系列 00-08）
 │    └── 求解器: B&B + 割平面 + 启发式（09）
 │         ├── Gurobi / CPLEX / SCIP / HiGHS / CBC
 │         └── CP-SAT（SAT 推理路线）
 ├── 近似算法: 贪心 / 2-opt / 模拟退火 / 遗传
 └── ML 增强: GNN 分支 / RL 分支（2025 前沿，保持最优性）
```

**整条链路都是同一棵"界函数之树"**：

| 层级 | 界函数 | 剪枝手段 |
|------|--------|---------|
| 手写 B&B | 分数背包 / MST / 曼哈顿 | 约束 + 限界 |
| 求解器 | LP 松弛 + 割平面 | 加界（cut） |
| CP-SAT | SAT 推理 + 传播 | 域传播 |
| ML-B&B | 学习到的分支/结点策略 | 更小的树 |

> 🎯 **核心要点**：整数规划求解器 = 本系列全部内容的工业级合体——LP 松弛是界函数、Branch and Cut 是界的强化、启发式是初始 best、gap 是工程化的提前终止。2025 前沿（GNN/RL 学习分支、B&B+CP-SAT 混合）都在**不改变最优性保证**的前提下优化搜索树。**"理解 B&B 就能读懂求解器，读懂求解器就能接住 2025 年的前沿"——这就是本系列的最高落点。**
