## 1. 六种位运算

### 1.1 运算速查

| 运算符 | 名称 | 规则 | 示例 |
|:---:|------|------|------|
| `&` | 与 | 两位都为 1 才为 1 | `5 & 3 = 1` (101 & 011 = 001) |
| `\|` | 或 | 任一位为 1 即为 1 | `5 \| 3 = 7` (101 \| 011 = 111) |
| `^` | 异或 | 相同为 0，不同为 1 | `5 ^ 3 = 6` (101 ^ 011 = 110) |
| `~` | 取反 | 0↔1 翻转 | `~5 = -6`（补码） |
| `<<` | 左移 | 整体左移，低位补 0 | `5 << 1 = 10`（乘 2） |
| `>>` | 右移 | 整体右移，高位补符号位 | `-5 >> 1 = -3` |
| `>>>` | 无符号右移 | 高位补 0 | `-5 >>> 1 = 2147483645` |

### 1.2 运算性质

```
与 &：取交集、清位（置 0）
或 |：取并集、置位（置 1）
异或 ^：翻转、去重、求差
左移 << n：×2ⁿ
右移 >> n：÷2ⁿ（向下取整，负数注意）

经典恒等式：
  x & 0 = 0        x | 0 = x        x ^ 0 = x
  x & 1 = x        x | 1 = 1        x ^ 1 = ~x（翻转）
  x & x = x        x | x = x        x ^ x = 0
```

## 2. 二进制与补码

### 2.1 负数怎么表示（补码）

```
int 是 32 位补码表示：

+5 = 0000...0101
-5 = 1111...1011（补码）

补码求法：取反 + 1
  5 的二进制：0000...0101
  取反：      1111...1010
  +1：        1111...1011 = -5 ✓

为什么用补码？
  减法变加法：a - b = a + (-b)（硬件统一加法器）
  0 唯一表示（-0 不存在）
```

### 2.2 为什么 `~5 = -6`？

```
~5 = ~(0000...0101) = 1111...1010
1111...1010 是补码，其真值 = -(取反) - 1 = -6

记忆：~x = -(x+1)（对任意整数成立）
```

### 2.3 溢出防护

```java
// ⚠️ 移位溢出陷阱
1 << 31              // 2147483648 溢出为负数（int 最大 2^31-1）
1L << 31             // ✅ 用 long 得到 2147483648
(1L << 32) - 1       // 低 32 位全 1 的掩码

// 面试中涉及 2^31 级别数值 → 用 long
```

## 3. 异或三大性质

### 3.1 三大性质（面试必背）

```
① 归零律：x ^ x = 0       （相同数异或消去）
② 恒等律：x ^ 0 = x       （0 异或保持不变）
③ 交换律+结合律：
   x ^ y = y ^ x
   (x ^ y) ^ z = x ^ (y ^ z)
```

### 3.2 应用：136. 只出现一次的数字

```java
/**
 * LeetCode 136. 只出现一次的数字
 * 所有数异或：
 *   成对的数 x^x=0 全部抵消
 *   只出现一次的数 x^0=x 保留
 */
public int singleNumber(int[] nums) {
    int result = 0;
    for (int x : nums) {
        result ^= x;        // 全体异或
    }
    return result;
}
// [4,1,2,1,2]：4^1^2^1^2 = 4^(1^1)^(2^2) = 4^0^0 = 4 ✓
```

### 3.3 异或的本质

```
异或 = "无进位加法"：
  5 ^ 3 = 101 ^ 011 = 110 = 6
  （1+1=0 不进位）

应用面：
  去重（x^x=0）→ 136/268
  交换变量（a^=b; b^=a; a^=b）
  翻转特定位（x ^ mask）
  加密（明文 ^ 密钥 = 密文）
```

## 4. 八大核心技巧

### 4.1 技巧一：n & (n-1) 去掉最低位的 1

```
n = 12 (1100)
n-1 = 11 (1011)
n & (n-1) = 1000 = 8    ← 最低位的 1 被去掉！

原理：n-1 会把最低位 1 变成 0，低位全变 1
     与运算后：最低位 1 位置变 0，低位本来为 0 不受影响

应用：
  ① 判断 2 的幂：n & (n-1) == 0（231 题）
  ② 统计 1 的个数：循环去掉直到 0（191 题）
```

### 4.2 技巧二：n & (-n) 取最低位的 1

```
n = 12 (1100)
-n = -12（补码 = 取反+1 = 0100）
n & (-n) = 0100 = 4    ← 只保留最低位的 1！

原理：-n 的补码中，最低位 1 的位置与 n 相同
     且该位以上全相反 → 与运算只留最低位 1

应用：
  260 题分组（按最低位 1 分组异或）
  树状数组的 lowbit
```

### 4.3 技巧三：检查/设置/翻转第 k 位

```java
// 检查第 k 位是否为 1
boolean isSet = (n & (1 << k)) != 0;

// 将第 k 位置为 1
n = n | (1 << k);

// 将第 k 位置为 0（先取反掩码）
n = n & ~(1 << k);

// 翻转第 k 位
n = n ^ (1 << k);
```

### 4.4 技巧四：乘除 2 与奇偶判断

```java
x * 2   →  x << 1
x / 2   →  x >> 1（整数除法）
x % 2   →  x & 1（奇偶判断，0 偶 1 奇）

// 例：二分查找的 mid 写法
int mid = left + ((right - left) >> 1);   // 防溢出 + 位运算
```

### 4.5 技巧五：异或交换变量（了解）

```java
// 不借助临时变量交换 a 和 b
a ^= b;    // a = a^b
b ^= a;    // b = b^(a^b) = a
a ^= b;    // a = (a^b)^a = b
// 面试了解即可（可读性差，实际代码不用）
```

### 4.6 技巧六：位掩码表示集合

```java
// 用 int 的 32 位表示集合状态（第 i 位 = 元素 i 是否在集合中）
int mask = 0;
mask |= (1 << i);            // 加入元素 i
boolean in = (mask & (1 << i)) != 0;   // 判断是否在集合
mask &= ~(1 << i);           // 移除元素 i
int count = Integer.bitCount(mask);    // 集合大小

// 应用：状态压缩 DP、子集枚举（78 题）、TSP
```

### 4.7 技巧七：异或前缀

```java
// 前缀异或：pre[i] = nums[0]^...^nums[i]
// 区间异或：[l, r] 的异或 = pre[r] ^ pre[l-1]（异或自反性）

// 应用：1310. 子数组异或查询
// 异或前缀和数组：pre[i] = pre[i-1] ^ nums[i]
```

## 5. 位运算优先级陷阱

### 5.1 优先级顺序（面试高频坑）

```
⚠️ 位运算优先级低于比较运算符！

  if (n & 1 == 1)      // ❌ 语法错误！== 先执行：(n & (1==1))
  if ((n & 1) == 1)    // ✅ 必须加括号！

优先级从高到低：
  括号 () → 移位 << >> >>> → 比较 == != → 位与 & → 位异或 ^ → 位或 |

记忆：& 比 == 低！判断位必须加括号！
```

### 5.2 常见坑速查

| 错误写法 | 正确写法 | 原因 |
|------|------|------|
| `n & 1 == 1` | `(n & 1) == 1` | == 优先级高于 & |
| `n ^ m == 0` | `(n ^ m) == 0` | 同上 |
| `1 << 31` | `1L << 31` | int 溢出 |
| `-5 >> 1` | `-5 >>> 1`（需无符号时） | >> 补符号位 |
| `x = x << 1 + 1` | `x = (x << 1) + 1` | + 高于 << |

> 🎯 **核心要点**：位运算的地基是**六种运算 + 异或三性质 + 八大技巧**。最常用的是 `x^x=0`（去重）、`n&(n-1)`（去最低位 1）、`n&(-n)`（取最低位 1）、`1<<k`（位操作）。**优先级陷阱**（`&` 低于 `==`）是面试手写时最容易翻车的地方——判断位时一律加括号。
