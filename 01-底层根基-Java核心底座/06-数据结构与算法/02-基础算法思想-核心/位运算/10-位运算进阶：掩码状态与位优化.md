## 1. 位运算技巧的完整体系

### 1.1 八大技巧速查

```
① n & (n-1)：去掉最低位 1（计数/2 的幂）
② n & (-n)：取最低位 1（分组/lowbit）
③ n & (1<<k)：检查第 k 位
④ n | (1<<k)：置第 k 位
⑤ n ^ (1<<k)：翻转第 k 位
⑥ (n & 1) == 1：奇偶判断（⚠️ 加括号！）
⑦ <<1 / >>1：乘 2 / 除 2
⑧ 1L << 31：溢出防护（int 用 long）

⚠️ 记忆："去位 n&(n-1)、取位 n&(-n)、
  检查置翻转都用 1<<k"
```

### 1.2 技巧的数学本质

```
n & (n-1)：n-1 把最低位 1 变 0、低位全变 1
  与运算后：最低位 1 位置变 0 ✓

n & (-n)：-n = ~n+1（补码）
  与运算只留最低位 1（其余位相反）✓

⚠️ 面试必答：
"n&(n-1) 去掉最低位 1（计数/2 的幂）；
 n&(-n) 取最低位 1（分组/lowbit）——
 都源于补码/二进制性质。"
```

### 1.3 技巧应用映射

| 技巧 | 应用 | 代表题 |
|------|------|:---:|
| x^x=0 | 去重 | 136/268 |
| n&(n-1) | 计数/2 幂 | 191/231 |
| n&(-n) | 分组 | 260 |
| 1<<k | 掩码操作 | 78/掩码 DP |
| >>1 | 二分 mid | 所有二分 |
| &1 | 奇偶 | 所有题 |

## 2. 位掩码状态设计

### 2.1 什么是位掩码状态

```
用整数的二进制位表示集合/状态：
  第 i 位 = 1 → 元素 i 在集合中
  mask = 1011₂ → 集合 {0, 1, 3}

优势：
  状态只占 1 个 int（32 位）
  集合操作 O(1)（位运算）
  数组下标 = 掩码值（状态压缩 DP）

⚠️ 适用：n ≤ 20（2²⁰ ≈ 10⁶ 状态可行）
```

### 2.2 状态设计三要素

```
① 状态含义：mask 的每一位代表什么？
   "已选/已访问/奇偶/行状态"
② 状态转移：加入/移除一个元素（位运算）
   mask | (1<<i)    加入
   mask & ~(1<<i)   移除
③ 状态评估：bitCount / 附加维度

⚠️ 面试第一句：
"状态数 2²⁰ ≈ 10⁶，dp 数组可行，
 复杂度 O(n×2ⁿ)。"
```

### 2.3 掩码操作的通用模板

```java
// ═══════════ 集合操作 ═══════════════════════════
mask | (1 << i)          // 加入元素 i
mask & ~(1 << i)         // 移除元素 i
(mask >> i & 1) == 1     // 是否包含 i
Integer.bitCount(mask)   // 集合大小
(1 << n) - 1             // 全集

// ═══════════ 枚举子集 ═══════════════════════════
// mask 的所有非空子集（每次去掉最低位 1）
for (int sub = mask; sub > 0; sub = (sub - 1) & mask) {
    // sub 遍历 mask 的子集
}
// 例：mask=1100 → 1100, 1000, 0100
// 原理：(sub-1) 减 1 后与 mask 相与（只保留 mask 内的位）
// ⚠️ 总枚举量 3ⁿ（每元素三种状态）
```

## 3. 状态压缩 DP

### 3.1 TSP 模板（标准骨架）

```java
/**
 * 状态压缩 DP 标准模板（TSP 旅行商）
 * dp[mask][i]：已访问集合 mask、当前在城市 i
 */
public int tsp(int[][] dist) {
    int n = dist.length;
    int[][] dp = new int[1 << n][n];       // 2ⁿ × n
    for (int[] row : dp) Arrays.fill(row, Integer.MAX_VALUE / 2);
    dp[1][0] = 0;                          // 从城市 0 出发

    for (int mask = 1; mask < (1 << n); mask++) {
        for (int i = 0; i < n; i++) {
            if ((mask & (1 << i)) == 0) continue;    // i 不在集合
            for (int j = 0; j < n; j++) {
                if ((mask & (1 << j)) != 0) continue; // j 已访问

                int nextMask = mask | (1 << j);       // 加入 j
                dp[nextMask][j] = Math.min(
                    dp[nextMask][j],
                    dp[mask][i] + dist[i][j]);        // 松弛
            }
        }
    }
    return dp[(1 << n) - 1][0];            // 访问完所有城市
}
// 复杂度 O(n² × 2ⁿ)（2ⁿ 状态 × n² 转移）
// ⚠️ 对比暴力 n!：状态压缩是集合问题的标准解法
```

### 3.2 状态压缩 DP 通用模式

```
① 状态定义：dp[mask][附加维度]
   mask = 已选集合，附加 = 当前位置/最后元素
② 转移：尝试"加入一个新元素"
   nextMask = mask | (1 << j)
③ 初始化：起点状态（dp[1][0] 等）
④ 答案：全选状态（(1<<n)-1）

⚠️ 附加维度的必要性：
  需要顺序 → 二维 dp[mask][last]
  只需集合 → 一维 dp[mask]
```

### 3.3 状态数评估（面试必答）

```
dp 大小 = 2ⁿ × 附加维度
  2²⁰ ≈ 10⁶ ✓（常见上限）
  2²⁵ ≈ 3×10⁷（勉强，内存 100MB+）
  2³⁰ ≈ 10⁹ ✗（爆炸）

⚠️ 面试表达：
"状态数 2²⁰ ≈ 10⁶，dp 数组 10⁶ × 20，
 内存约 80MB 可行，复杂度 O(n²·2ⁿ)。"
```

## 4. 位运算优化常见场景

### 4.1 快排/二分的 mid 优化

```java
// 二分查找的 mid（防溢出 + 位运算）
int mid = left + ((right - left) >> 1);
// ⚠️ >> 优先级低于 + → 必须加括号！

// 快排/快选中判断
if ((n & 1) == 1) { ... }   // ⚠️ & 低于 == → 必须加括号！
```

### 4.2 状态判断的位优化

```
① 奇数判断：(n & 1) == 1（vs n % 2）
② 2 的幂：n > 0 && (n & (n-1)) == 0
③ 两数异号：(a ^ b) < 0（符号位异或）
④ 绝对值：|a| = (a ^ (a>>31)) - (a>>31)（了解）
⑤ 交换：a ^= b; b ^= a; a ^= b（了解，可读性差）

⚠️ 面试表达：
"位运算 O(1) 且常数小——判断/集合操作
 用位运算替代算术/数组访问。"
```

### 4.3 计数优化

```
① 1 的个数：n&(n-1) 循环（次数 = 1 的个数）
② 位计数 DP：dp[i] = dp[i>>1] + (i&1)
   （338 比特位计数：O(n) 递推）
③ 最低位 1 位置：Integer.numberOfTrailingZeros

⚠️ 338 的递推：
  i 的 1 个数 = (i 去掉最低位) 的 1 个数 + 最低位
  → 重叠子问题 → DP
```

## 5. 位运算的边界与陷阱

### 5.1 优先级陷阱（面试最高频坑）

```
⚠️ 位运算优先级低于比较运算符！
  if (n & 1 == 1)      // ❌ 语法错误！== 先执行
  if ((n & 1) == 1)    // ✅ 必须加括号！

优先级从高到低：
  括号 → 移位 << >> → 比较 == → 位与 & → 异或 ^ → 或 |

⚠️ 记忆："& 比 == 低！判断位必须加括号！"
```

### 5.2 移位陷阱

```
① 负数 >> 补符号位（算术右移）
   位模式操作必须 >>>（无符号右移）
   ⚠️ 190 颠倒二进制位用 >> 会死循环！

② 1 << 31 溢出为负数（int）
   用 1L << 31（long）

③ ~x = -(x+1)（补码）

⚠️ 面试必答：
"负数右移用 >> 补符号位；需要位模式
 操作时用 >>>（无符号）。"
```

### 5.3 溢出与类型

```
① 大数异或/掩码：用 long
② 组合数/哈希：先取模
③ 负数取模：((x % mod) + mod) % mod

⚠️ 识别：
  "1<<31/坐标相乘/前缀和" → 检查溢出
```

## 6. 进阶总结

### 6.1 进阶要点速查

```
① 八大技巧：去位/取位/检查/置位/翻转/奇偶/移位/溢出
② 掩码状态：集合用整数表示（加入/移除/判断 O(1)）
③ 状态压缩 DP：TSP 模板 + 状态数评估（2ⁿ）
④ 位优化：mid>>1/奇偶&1/符号异或
⑤ 陷阱：& 低于 == / >> vs >>> / 1<<31 溢出
```

### 6.2 面试话术模板

```
"这是集合选择问题，n ≤ 20 → 状态压缩：
 用 int 掩码表示'已选集合'，dp[mask] 表示
 该状态的最优值。转移用位运算加元素
 （mask | (1<<i)）。
 状态数 2ⁿ = 10⁶ 可行，复杂度 O(n × 2ⁿ)。
 位运算细节：判断位必须加括号（& 低于 ==）。"
```

### 6.3 易错点清单

| 错误 | 后果 | 修正 |
|------|------|------|
| 优先级错 | 语法错误 | (n & 1) == 1 加括号 |
| 负数 >> | 死循环 | 用 >>> |
| 1<<31 | 溢出 | 用 long |
| 状态数爆炸 | 内存溢出 | 先评估 2ⁿ |
| 忘取模 | 溢出 | 每步取模 |

> 🎯 **核心要点**：位运算进阶 = **掩码状态设计**（集合→整数）+ **状态压缩 DP**（TSP 模板 + 状态数评估）+ **位优化**（mid>>1/奇偶&1）+ **陷阱防护**（优先级/移位/溢出）。"集合用掩码、状态数先评估"是状态设计核心；"& 低于 =="是手写必防。
