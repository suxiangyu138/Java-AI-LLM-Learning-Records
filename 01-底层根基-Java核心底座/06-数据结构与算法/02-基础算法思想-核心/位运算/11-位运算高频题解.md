## 1. 136. 只出现一次的数字

### 1.1 完整实现（全体异或）

```java
/**
 * LeetCode 136. 只出现一次的数字（位运算第一题）
 * 要求：线性时间 + O(1) 空间
 *
 * 全体异或：成对的抵消，落单的保留
 *   x^x=0（归零）+ x^0=x（恒等）+ 结合律
 */
public int singleNumber(int[] nums) {
    int result = 0;
    for (int x : nums) {
        result ^= x;        // 全体异或
    }
    return result;
}
// 推演 [4,1,2,1,2]：
//   4^1^2^1^2 = 4^(1^1)^(2^2) = 4^0^0 = 4 ✓
// ⚠️ 面试必答：
//   "异或三性质：x^x=0 归零、x^0=x 恒等、
//    结合律——成对抵消、落单保留。
//    O(1) 空间是位运算相比哈希的优势。"
```

## 2. 137. 只出现一次的数字 II

### 2.1 完整实现（按位统计 %3）

```java
/**
 * LeetCode 137. 只出现一次的数字 II
 * 每个数出现 3 次，只有 1 个数出现 1 次
 * ⚠️ 异或无法消去 3 次（x^x^x = x）→ 按位统计
 */
public int singleNumber(int[] nums) {
    int result = 0;
    for (int bit = 0; bit < 32; bit++) {      // 逐位处理
        int count = 0;
        for (int x : nums) {
            count += (x >> bit) & 1;          // 统计该位 1 的个数
        }
        if (count % 3 != 0) {                 // 余 1 → 答案是 1
            result |= (1 << bit);
        }
    }
    return result;
}
// 推演 [2,2,3,2]（10,10,11,10）：
//   位 0：1+1+1+1 = 4 % 3 = 1 → 答案位 0 = 1
//   位 1：1+1+0+1 = 3 % 3 = 0 → 答案位 1 = 0
//   → 答案 01 = 1？不对，3 的二进制是 11
//   重新数：3 = 11（位 0=1, 位 1=1）
//   位 0：2(0)+2(0)+3(1)+2(0) = 1 % 3 = 1 → 位 0 = 1
//   位 1：2(1)+2(1)+3(1)+2(1) = 4 % 3 = 1 → 位 1 = 1
//   → 答案 11 = 3 ✓
// ⚠️ 通用：出现 k 次 → 按位统计 % k
```

## 3. 260. 只出现一次的数字 III

### 3.1 完整实现（取位分组）

```java
/**
 * LeetCode 260. 只出现一次的数字 III
 * 两个落单 → 全体异或 = a^b → 取位分组
 */
public int[] singleNumber3(int[] nums) {
    // ① 全体异或 = a ^ b
    int xor = 0;
    for (int x : nums) xor ^= x;

    // ② 取最低位的 1（a 和 b 在该位必然不同）
    int diff = xor & (-xor);          // 例：xor=6(110) → diff=2(010)

    // ③ 按 diff 位分组异或
    int a = 0, b = 0;
    for (int x : nums) {
        if ((x & diff) == 0) a ^= x;   // diff 位为 0 的组
        else b ^= x;                   // diff 位为 1 的组
    }
    return new int[]{a, b};
}
// 推演 [1,2,1,3,2,5]：
//   xor = 3^5 = 6(110)；diff = 2(010)
//   按位 1 分组：位 1 为 0：1,1,5 → a=5
//               位 1 为 1：2,3,2 → b=3
//   → [5,3] ✓
// ⚠️ 面试必答：
//   "a 和 b 在 diff 位必然不同（否则 xor 该位为 0），
//    分组后同组异或抵消成对元素"
```

## 4. 268. 丢失的数字

### 4.1 完整实现（下标+值异或）

```java
/**
 * LeetCode 268. 丢失的数字
 * 下标和值全部异或 → 成对抵消 → 剩下丢失的
 */
public int missingNumber(int[] nums) {
    int result = nums.length;         // 先异或 n
    for (int i = 0; i < nums.length; i++) {
        result ^= i;                  // 异或下标
        result ^= nums[i];            // 异或值
    }
    return result;
}
// 推演 [3,0,1]：
//   3 ^ (0^3) ^ (1^0) ^ (2^1)
//   = 3^3^0^1^2^1^0 = 2 ✓
// 数学解法：Σ(0..n) - Σ(nums)（long 防溢出）
// ⚠️ 面试两种解法都能讲 = 加分
```

## 5. 191. 位 1 的个数

### 5.1 完整实现（三种解法）

```java
/**
 * LeetCode 191. 位 1 的个数（汉明重量）
 * 解法一：n&(n-1) 去位计数（最优）
 */
public int hammingWeight(int n) {
    int count = 0;
    while (n != 0) {
        n &= (n - 1);        // 去掉最低位的 1
        count++;             // 循环次数 = 1 的个数
    }
    return count;
}
// 推演 n=11(1011)：
//   1011 & 1010 = 1010 → 1010 & 1001 = 1000
//   → 1000 & 0111 = 0 → 3 次 → count=3 ✓

// 解法二：逐位检查（固定 32 次）
public int hammingWeight_BitByBit(int n) {
    int count = 0;
    for (int i = 0; i < 32; i++) {
        count += (n >> i) & 1;   // ⚠️ 用 >> 会补符号位？
        // 用 & 1 检查 → 安全（不依赖符号位）
    }
    return count;
}
// 解法三：Java API
// Integer.bitCount(n)（底层优化）
// ⚠️ 面试先手写 n&(n-1) 版，补充 bitCount
```

## 6. 231. 2 的幂

### 6.1 完整实现

```java
/**
 * LeetCode 231. 2 的幂
 * 2 的幂二进制只有一个 1
 */
public boolean isPowerOfTwo(int n) {
    return n > 0 && (n & (n - 1)) == 0;   // ⚠️ n > 0 必须！
}
// 8(1000) & 7(0111) = 0 ✓；10(1010) & 9(1001) = 8 ≠ 0 ✗
// ⚠️ 为什么必须 n > 0？
//   0 & (-1) = 0 → 不判 n>0 会误判 0 是 2 的幂！
// 变体：
//   326 3 的幂（循环除 3）
//   342 4 的幂（2 的幂 && n % 3 == 1）
```

## 7. 461. 汉明距离

### 7.1 完整实现（异或 + 计数）

```java
/**
 * LeetCode 461. 汉明距离
 * 两数二进制不同位的个数
 * 两步：异或（不同位=1）→ 数 1 的个数（191 复用）
 */
public int hammingDistance(int x, int y) {
    int xor = x ^ y;              // 不同位标记为 1
    int count = 0;
    while (xor != 0) {
        xor &= (xor - 1);         // 去掉最低位 1
        count++;
    }
    return count;
}
// 推演 x=1(001), y=4(100)：
//   xor = 101 → 2 个 1 → 距离 2 ✓
// 一行版：Integer.bitCount(x ^ y)
// 变体：477 汉明距离总和（按位统计 0×1）
```

## 8. 371. 两整数之和

### 8.1 完整实现（异或 + 进位）

```java
/**
 * LeetCode 371. 两整数之和（不用 + 和 -）
 * 位运算加法：
 *   和（无进位）= a ^ b
 *   进位 = (a & b) << 1
 *   重复直到进位为 0
 */
public int getSum(int a, int b) {
    while (b != 0) {
        int carry = (a & b) << 1; // 进位（两数都是 1 的位置）
        a = a ^ b;                // 无进位和
        b = carry;                // 进位参与下一轮
    }
    return a;
}
// 推演 5 + 3：
//   无进位和：101^011 = 110(6)；进位：(101&011)<<1 = 010(2)
//   6+2：110^010 = 100(4)；进位：(110&010)<<1 = 100(4)
//   4+4：100^100 = 000(0)；进位：(100&100)<<1 = 1000(8)
//   0+8：进位 0 → 结果 8 ✓（5+3=8 ✓）
// ⚠️ 减法 = getSum(a, ~b + 1)（补码）
// ⚠️ 面试追问："为什么循环能终止？"
//   进位每次左移 → 最终为 0
```

## 9. 190. 颠倒二进制位

### 9.1 完整实现（逐位累积）

```java
/**
 * LeetCode 190. 颠倒二进制位
 * 逐位提取 + 左移累积
 */
public int reverseBits(int n) {
    int result = 0;
    for (int i = 0; i < 32; i++) {
        result = (result << 1) | (n & 1);   // 累积最低位
        n >>>= 1;                           // ⚠️ 必须 >>>！
    }
    return result;
}
// 推演 43261596 → 964176192（题示例）✓
// ⚠️ 面试必答：
//   "为什么用 >>> 而不是 >>？
//    负数右移补符号位（1），>>> 补 0——
//    我们只关心位模式，必须 >>> 才能
//    拿到正确的'下一位'"
// ⚠️ 固定 32 次循环（int 固定 32 位）
```

## 10. 338. 比特位计数

### 10.1 完整实现（DP + 位运算）

```java
/**
 * LeetCode 338. 比特位计数
 * 返回 [0, n] 每个数的二进制中 1 的个数
 * 递推公式：dp[i] = dp[i >> 1] + (i & 1)
 *   i >> 1：去掉最低位
 *   i & 1：最低位是否是 1
 */
public int[] countBits(int n) {
    int[] dp = new int[n + 1];
    for (int i = 1; i <= n; i++) {
        dp[i] = dp[i >> 1] + (i & 1);    // 递推
    }
    return dp;
}
// 推演：
//   dp[0]=0
//   dp[1]=dp[0]+1=1    dp[2]=dp[1]+0=1
//   dp[3]=dp[1]+1=2    dp[4]=dp[2]+0=1
//   → [0,1,1,2,1] ✓
// ⚠️ 变体公式：dp[i] = dp[i & (i-1)] + 1（去掉最低位 1）
// ⚠️ 面试必答："重叠子问题 → DP：
//   i 的 1 个数 = (i 去掉最低位) 的 1 个数 + 最低位"
```
