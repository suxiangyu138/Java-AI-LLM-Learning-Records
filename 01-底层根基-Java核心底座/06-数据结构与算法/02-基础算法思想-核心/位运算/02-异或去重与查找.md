## 1. 136. 只出现一次的数字

### 1.1 完整实现

```java
/**
 * LeetCode 136. 只出现一次的数字（位运算第一题）
 * 非空数组，其他元素都出现两次，找只出现一次的元素
 * 要求：线性时间 + O(1) 空间
 *
 * 解法：全体异或
 *   成对的数：x ^ x = 0（归零律）
 *   只出现一次的数：x ^ 0 = x（恒等律）
 *   结合律保证顺序无关
 */
public int singleNumber(int[] nums) {
    int result = 0;
    for (int x : nums) {
        result ^= x;
    }
    return result;
}
// [4,1,2,1,2]：4^1^2^1^2 = 4^(1^1)^(2^2) = 4^0^0 = 4 ✓
```

### 1.2 为什么异或可行？

```
暴力：哈希表计数 O(n) 空间 → 不满足 O(1) 要求
排序：O(n log n) → 不满足线性要求

异或：
  ① 交换律：顺序无关
  ② 归零律：成对元素消去
  ③ 恒等律：落单元素保留
  → 一趟 O(n)，O(1) 空间，完美满足

面试必讲："异或的三条性质让成对的元素
 自动抵消，落单的元素保留下来。"
```

### 1.3 变体：540. 有序数组中的单一元素

```java
/**
 * LeetCode 540. 有序数组中的单一元素
 * 有序数组中每个元素出现两次，只有一个出现一次
 *
 * 解法一：异或 O(n)（通用，但没利用有序）
 * 解法二：二分 O(log n)（利用有序！）
 *   观察：单一元素出现前，成对元素下标是 (偶, 奇)
 *        单一元素出现后，变成 (奇, 偶)
 *   检查 nums[mid] 与 nums[mid^1] 是否相等
 */
public int singleNonDuplicate(int[] nums) {
    int left = 0, right = nums.length - 1;
    while (left < right) {
        int mid = left + (right - left) / 2;
        // mid^1：mid 是偶数 → mid+1；mid 是奇数 → mid-1
        if (nums[mid] == nums[mid ^ 1]) {
            left = mid + 1;        // 单一元素在右边
        } else {
            right = mid;           // 单一元素在左边
        }
    }
    return nums[left];
}
```

## 2. 268. 丢失的数字

### 2.1 三种解法

```java
/**
 * LeetCode 268. 丢失的数字
 * [0, n] 中缺少一个数，数组长度 n
 * nums=[3,0,1] → 缺 2
 *
 * 解法一：异或（O(n)/O(1)）
 *   把下标和值都异或：
 *   (0^1^2^...^n) ^ (nums[0]^...^nums[n-1])
 *   成对的抵消 → 剩下的就是丢失的数字
 */
public int missingNumber(int[] nums) {
    int result = nums.length;         // 先异或 n
    for (int i = 0; i < nums.length; i++) {
        result ^= i;                  // 异或下标
        result ^= nums[i];            // 异或值
    }
    return result;
}
// [3,0,1]：3 ^ (0^3) ^ (1^0) ^ (2^1) = 3^3^0^1^2^1^0 = 2 ✓

// 解法二：数学（等差数列求和）
public int missingNumber_Sum(int[] nums) {
    int n = nums.length;
    int expected = n * (n + 1) / 2;   // 0..n 的和
    int actual = 0;
    for (int x : nums) actual += x;
    return expected - actual;
}
// 注意：n 很大时用 long 防溢出

// 解法三：哈希集合（O(n)/O(n)，不推荐）
```

### 2.2 解法对比

| 解法 | 时间 | 空间 | 要点 |
|------|:---:|:---:|------|
| 异或 | O(n) | O(1) | 下标+值全部异或 |
| 数学 | O(n) | O(1) | 等差数列相减 |
| 哈希 | O(n) | O(n) | 不满足 O(1) |

> 💡 异或与数学都是 O(1) 空间；面试先说异或（体现位运算能力），再说数学解（体现数学直觉）。

## 3. 260. 只出现一次的数字 III

### 3.1 完整实现（分组异或）

```java
/**
 * LeetCode 260. 只出现一次的数字 III
 * 两个数只出现一次，其他都出现两次。找这两个数。
 *
 * 三步：
 *   ① 全体异或 → xor = a ^ b（其他成对的抵消）
 *   ② 找 xor 的任意一个 1 位（用 xor & (-xor) 取最低位 1）
 *      该位把数组分成两组：该位为 0 的一组，为 1 的一组
 *      a 和 b 必然在不同组（它们在 xor 的这个位不同）
 *   ③ 两组分别异或 → 各组得到 a 和 b
 */
public int[] singleNumber3(int[] nums) {
    // ① 全体异或 = a ^ b
    int xor = 0;
    for (int x : nums) xor ^= x;

    // ② 取最低位的 1（a 和 b 在该位必然不同）
    int diff = xor & (-xor);          // 例：xor=6(110) → diff=2(010)

    // ③ 按 diff 位分组异或
    int a = 0, b = 0;
    for (int x : nums) {
        if ((x & diff) == 0) {
            a ^= x;                   // diff 位为 0 的组
        } else {
            b ^= x;                   // diff 位为 1 的组
        }
    }
    return new int[]{a, b};
}
// nums=[1,2,1,3,2,5]：xor=3^5=6(110)
// diff=2(010)：按第 1 位分组
//   位0组：1,1,5 → a=5；位1组：2,3,2 → b=3 → [5,3] ✓
```

### 3.2 为什么分组可行？

```
xor = a ^ b，设 xor 的最低 1 位是第 k 位
  a 和 b 在第 k 位必然不同（否则 xor 该位为 0）

分组：第 k 位为 0 / 第 k 位为 1
  a 和 b 分到不同组 ✓
  其他成对元素：成对的 x 第 k 位相同 → 同组 → 组内异或抵消 ✓
  → 每组异或结果就是 a 和 b ✓
```

### 3.3 变体：137. 只出现一次的数字 II

```java
/**
 * LeetCode 137. 只出现一次的数字 II
 * 每个数出现 3 次，只有 1 个数出现 1 次
 *
 * 异或无法消去 3 次（x^x^x = x）→ 按位统计
 * 统计每一位上 1 的个数 % 3 → 余数就是答案该位
 */
public int singleNumber2(int[] nums) {
    int result = 0;
    for (int bit = 0; bit < 32; bit++) {      // 逐位处理
        int count = 0;
        for (int x : nums) {
            count += (x >> bit) & 1;          // 统计该位 1 的个数
        }
        if (count % 3 != 0) {                 // 余 1 → 答案是 1
            result |= (1 << bit);
        }
    }
    return result;
}
// 位运算版本（状态机）：once/twice 两个变量
// 通用：出现 k 次 → 按位统计 % k
```

## 4. 异或应用家族

### 4.1 异或专题题单

| 题号 | 题目 | 异或技巧 | 复杂度 |
|:---:|------|------|:---:|
| 136 | 只出现一次 I | 全体异或 | O(n)/O(1) |
| 137 | 只出现一次 II | 按位统计 %3 | O(32n)/O(1) |
| 260 | 只出现一次 III | 取位分组 | O(n)/O(1) |
| 268 | 丢失的数字 | 下标+值异或 | O(n)/O(1) |
| 540 | 有序单一元素 | 二分+mid^1 | O(log n)/O(1) |
| 1310 | 子数组异或查询 | 异或前缀 | O(n)/O(n) |
| 1720 | 解码异或数组 | 逆运算 | O(n)/O(1) |

### 4.2 异或题解题框架

```
拿到"出现次数/找缺失/找重复" → 问：

① 出现两次 → 全体异或（136）
② 出现三次 → 按位统计 %3（137）
③ 两个落单 → 取位分组异或（260）
④ 缺失数字 → 下标+值异或 / 数学（268）
⑤ 区间异或 → 异或前缀（1310）

面试话术：
"异或的三条性质（x^x=0、x^0=x、结合律）
 让成对元素自动抵消。这题全体异或后，
 剩下的就是落单的数——O(n) 时间 O(1) 空间。"
```

### 4.3 面试追问

| 追问 | 标准回答 |
|------|------|
| 为什么异或能去重？ | x^x=0 归零律，成对元素抵消；x^0=x 恒等律，落单元素保留 |
| 137 为什么异或不行？ | x^x^x = x 无法抵消 3 次；改用按位统计 %3 |
| 260 为什么需要分组？ | 全体异或得到 a^b，但无法区分两者；取 a^b 中一个 1 位分组，a、b 必然不同组 |
| 异或和加法的关系？ | 异或是"无进位加法"：5^3=6（101+011 无进位） |

> 🎯 **核心要点**：异或去重系列是位运算的招牌——**136 全体异或**、**137 按位统计**、**260 取位分组**、**268 下标+值异或**。每道题都要能讲清"为什么异或能消去成对元素"（x^x=0 + 结合律）。位运算 O(1) 空间是面试加分点，值得反复手写。
