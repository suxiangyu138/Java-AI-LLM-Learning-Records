## 3. 学习路线推荐

### 🟢 路线 A：零基础入门（3 天）
```
01 三要素 → 求和/遍历手写 → 边界与死循环练习
→ 04 链表反转 + 快速幂 → 06 简单题（206/70/141）
```
- **目标**：for/while 闭眼能写，能说清三要素与终止性

### 🟡 路线 B：面试冲刺（1 周）
```
01 快速过 → 02 fail-fast 陷阱 → 03 中序/层序迭代必背
```

- **目标**：递归版被追问"栈溢出怎么办"能 5 分钟转迭代

```
完整 01→05 + 每类 5 题 + 手写迭代器/IDDFS 拓展
→ 状态机法模拟复杂递归 → 42 接雨水迭代版 → 30 串联子串
```
- **目标**：任意递归都能转迭代；性能优化意识成为肌肉记忆
- **题量**：约 30 题

## 4. 核心概念速查

| 概念 | 一句话解释 | 典型例题 |
|------|-----------|------|
| **迭代三要素** | 初始化、循环条件、更新步进缺一不可 | 求和、遍历 |
| **循环不变量** | 每次迭代都保持成立的性质，用于证明正确性 | 二分查找 |
| **for-each** | 编译成 Iterator 的语法糖 | 任意集合遍历 |
| **fail-fast** | modCount 变化时抛 CME，防止脏读 | 遍历中删除 |
| **尾递归** | 递归调用在最后一步，可直接转循环 | 阶乘 |
| **显式栈** | 用堆内存栈模拟调用栈，消除栈溢出 | 树遍历 |
| **滚动数组** | 只保留前 k 个状态，空间 O(1) | 70 爬楼梯 |
| **牛顿迭代** | 切线逼近求根，收敛速度快 | 69 平方根 |
| **快速幂** | 按二进制位展开，O(log n) 次乘法 | 50 Pow(x,n) |
| **IDDFS** | 迭代加深：限制深度逐层 DFS | 深搜+最优深度 |

## 5. 迭代 vs 递归全景对比

| 维度 | 迭代 | 递归 |
|------|------|------|
| 状态存储 | 显式变量（原地更新） | 调用栈帧（每次调用新建） |
| 辅助空间 | O(1)（无显式栈时） | O(深度) |
| 栈溢出风险 | 无 | 深度 > 10⁴~10⁵ 可能溢出 |
| 代码表达 | 线性推进清晰 | 树/链表自相似结构清晰 |
| 性能 | 无调用开销 | 有压栈/弹栈开销 |
| 适用场景 | 数组、数值、状态机 | 树、分治、回溯、DFS |
| 转换关系 | **可互转**：尾递归直接转；一般递归显式栈 | 见模块 03 |

```
记忆：递归把状态藏进调用栈，迭代把状态摆在变量里。
  面试策略：先写递归（快、清晰），被追问再转迭代。
  中序迭代（左探-回溯-右转）是必背考点。
```

## 6. 复杂度速查表

| 问题 | 递归版 | 迭代版 | 迭代思路 |
|------|:---:|:---:|------|
| 阶乘 | O(n) 空间 | **O(1) 空间** | 尾递归直接转循环 |
| 斐波那契 | O(2ⁿ) 时间 | **O(n)/O(1)** | 滚动数组 |
| 反转链表 | O(n) 栈 | **O(n)/O(1)** | 三指针 |
| 中序遍历 | O(h) 栈 | **O(n)/O(h)** | 显式栈 |
| 层序遍历 | 需队列 | **O(n)/O(n)** | BFS 天然迭代 |
| 快速幂 | O(log n) 栈 | **O(log n)/O(1)** | 二进制展开 |
| 约瑟夫环 | 模拟 O(nk) | **O(n)/O(1)** | 数学递推 |
| 平方根 | — | **O(log n)** | 牛顿/二分迭代 |
| 区间和查询 | — | **O(1) 查询** | 前缀和 |
| 最长无重复子串 | — | **O(n)** | 滑动窗口迭代 |
