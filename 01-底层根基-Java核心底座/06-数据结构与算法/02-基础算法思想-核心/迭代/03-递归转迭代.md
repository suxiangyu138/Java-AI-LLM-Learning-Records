## 1. 为什么要转迭代

```
① 栈溢出：递归深度 = 调用栈深度
   深度 10⁴~10⁵ 可能 StackOverflowError（默认 -Xss 约 512KB~1MB）
   链表退化 / 网格 DFS / 超深树 → 高危

② 性能：每次调用有压栈/弹栈/现场保存开销
   迭代无调用开销，常数因子更小

③ 面试考点：高频追问"栈溢出怎么办？"
   → "转迭代（显式栈用堆内存，不受调用栈限制）"

⚠️ 工程真相：显式栈空间复杂度仍是 O(n)，
   但堆内存远大于调用栈，且没有崩溃风险
```

## 2. 方法一：尾递归直接变循环

> 尾递归（Tail Recursion）：**递归调用是函数最后一步**，结果直接返回，无后续操作。此时可直接改写为循环——参数更新 + 循环体替换递归调用。

```java
// 尾递归版：累乘结果通过 acc 参数"下传"
int factorial(int n, int acc) {
    if (n == 0) return acc;                 // 基线
    return factorial(n - 1, n * acc);       // 递归在最后一步（尾调用）
}

// 转循环：acc 变局部变量，递归调用变"更新参数 + 继续循环"
int factorialLoop(int n) {
    int acc = 1;
    while (n > 0) {
        acc *= n;       // ← 对应 factorial(n-1, n*acc)
        n--;            // ← 参数更新
    }
    return acc;
}
```

```
转换规则：
  递归参数 → 局部变量
  基线条件 → 循环退出条件
  递归调用 → 更新参数 + 循环体尾部
⚠️ Java 不会自动做尾调用优化（TCO），函数式语言会——所以必须手动转
```

## 3. 方法二：显式栈模拟

> 通用方法：用 `Deque`（堆内存）模拟系统调用栈。**压栈时机**和**弹栈处理**决定遍历顺序。

```
通用思路：
  ① 明确"递归在做什么"——每个调用帧保存什么状态
  ② 确定入栈顺序（栈后进先出 → 先压后处理的）
  ③ 弹栈时执行"递归返回后要做的事"

前序遍历推导（根左右）：
  递归：处理根 → 递归左 → 递归右
  迭代：弹栈处理根 → 先压右（后处理）→ 再压左（先处理）
```

```java
/**
 * 前序迭代：根 → 左 → 右
 */
public List<Integer> preorder(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    if (root == null) return result;
    Deque<TreeNode> stack = new ArrayDeque<>();
    stack.push(root);
    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();                 // 弹栈 = 处理
        result.add(node.val);
        if (node.right != null) stack.push(node.right);  // 先压右
        if (node.left != null) stack.push(node.left);    // 再压左
    }
    return result;
}
// 记忆："先压右后压左，弹出即处理"（栈后进先出）
```

## 4. 树遍历迭代四模板

> ⚠️ **中序迭代是面试最高频的递归转迭代考点**，必须闭眼能写。

### 4.1 中序遍历：左探-回溯-右转（必背）

```java
public List<Integer> inorder(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode cur = root;

    while (cur != null || !stack.isEmpty()) {
        while (cur != null) {            // ① 左探：一路向左压栈
            stack.push(cur);
            cur = cur.left;
        }
        cur = stack.pop();               // ② 回溯：弹出 = 处理
        result.add(cur.val);             //     中序位置（左根右）
        cur = cur.right;                 // ③ 右转：转向右子树
    }
    return result;
}
// 记忆："左探-回溯-右转"三步循环
// 递归版 3 行 → 迭代版 12 行，但无栈溢出风险
```

### 4.2 后序遍历：头插法（根右左逆序）

```java
public List<Integer> postorder(TreeNode root) {
    LinkedList<Integer> result = new LinkedList<>();
    Deque<TreeNode> stack = new ArrayDeque<>();
    if (root != null) stack.push(root);

    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();
        result.addFirst(node.val);       // 头插：把"根右左"变"左右根"
        if (node.left != null) stack.push(node.left);
        if (node.right != null) stack.push(node.right);
    }
    return result;
}
// 推演：压栈顺序 根→右→左，输出顺序 根右左，头插反转 → 左右根 ✓
```

### 4.3 层序遍历：BFS 队列（天然迭代）

```java
public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> result = new ArrayList<>();
    if (root == null) return result;
    Queue<TreeNode> queue = new ArrayDeque<>();
    queue.offer(root);

    while (!queue.isEmpty()) {
        int size = queue.size();         // ⚠️ 先快照当前层大小
        List<Integer> level = new ArrayList<>();
        for (int i = 0; i < size; i++) { // 只弹当前层
            TreeNode node = queue.poll();
            level.add(node.val);
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        result.add(level);
    }
    return result;
}
// 记忆："先取 size 快照，只处理一层"（否则层会混）
```

### 4.4 四模板速查

| 遍历 | 数据结构 | 口诀 | 时空 |
|------|:---:|------|:---:|
| 前序 | 栈 | 先压右后压左，弹出即处理 | O(n)/O(h) |
| 中序 | 栈 | 左探-回溯-右转 | O(n)/O(h) |
| 后序 | 栈 | 头插反转"根右左" | O(n)/O(h) |
| 层序 | 队列 | 先取 size 快照 | O(n)/O(n) |

## 5. 方法三：状态机模拟递归帧

> 最通用的方法（适合"递归调用出现在中间位置"的复杂递归）：**把每个调用帧拆成多个阶段，用状态标记模拟"递归返回后继续执行"**。

```
思路：
  ① 给递归体的每个"调用点之后"编号（阶段）
  ② 栈帧 = {节点, 阶段}，弹栈后按阶段分派处理
  ③ 阶段推进 = 模拟递归返回后的继续执行

适用：DFS 回溯、多分支递归、调用点在循环体中间的递归
```

```java
/**
 * 后序迭代（标记法：null 哨兵标记"该处理了"）
 * 模拟递归帧：左 → 右 → 处理
 */
public List<Integer> postorderMark(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode node = root, last = null;

    while (node != null || !stack.isEmpty()) {
        while (node != null) {           // 左探（模拟递归左子树）
            stack.push(node);
            node = node.left;
        }
        TreeNode peek = stack.peek();
        if (peek.right != null && peek.right != last) {
            node = peek.right;           // 右子树未处理 → 转右
        } else {                         // 左右都完成 → 处理
            result.add(peek.val);
            last = stack.pop();          // last 标记"刚处理完谁"
        }
    }
    return result;
}
// 状态机思路：每个节点经历 左→右→处理 三个阶段
// last 变量记录上一个处理的节点，避免重复进右子树
```

## 6. 常见转换对照表

| 递归形态 | 转换方法 | 代表题目 |
|---------|---------|---------|
| 尾递归 | 直接变循环（最简单） | 阶乘、累加、斐波那契 |
| 线性递归 | 显式栈 | 反转链表、链表求和 |
| 树遍历 | 显式栈 / 队列模板 | 94/144/145/102 |
| 树形递归 | 显式栈 + 状态标记 | 二叉树最大路径和 |
| 回溯（DFS） | 显式栈存路径 + 状态 | 全排列、组合、岛屿 |
| 记忆化递归 | 先转迭代 DP | 爬楼梯、打家劫舍 |

```java
// 反转链表：递归 → 迭代（三指针，O(1) 空间完胜）
public ListNode reverseList(ListNode head) {
    ListNode prev = null, cur = head;
    while (cur != null) {
        ListNode next = cur.next;   // ① 暂存后继
        cur.next = prev;            // ② 反转指针
        prev = cur;                 // ③ prev 前进
        cur = next;                 // ④ cur 前进
    }
    return prev;
}
// 递归版：reverseList(head.next) 后回溯改指针
// 迭代版：prev/cur/next 三指针，空间 O(1)
```

## 7. 什么时候保留递归

| 场景 | 选择 | 理由 |
|------|:---:|------|
| 树高度 O(log n)~O(h) 安全 | 递归 | 代码简洁，深度可控 |
| 链表 / 深度 = n | **迭代** | 深度 = n 必溢出 |
| 回溯/组合枚举 | 递归为主 | 状态管理天然匹配（也可栈模拟） |
| 明确面试追问 | 先递归后转 | 展示两种能力 |
| 大数据量生产代码 | **迭代** | 防 StackOverflowError |

```
面试表达模板：
"这题递归深度 O(h)，树高一般安全；但若退化成链 O(n) 会栈溢出。
 我可以转迭代：尾递归直接改循环，一般递归用显式栈，
 中序遍历是左探-回溯-右转，空间 O(h)，无栈溢出风险。"
```

> 🎯 **核心要点**：递归转迭代三方法——**尾递归直接变循环**（最简单）、**显式栈模拟**（通用）、**状态机分阶段模拟**（复杂递归）。必背四模板：前序（先压右后压左）、中序（**左探-回溯-右转**）、后序（头插反转）、层序（队列 + size 快照）。转换动机：栈溢出防护 + 性能 + 面试考点。
