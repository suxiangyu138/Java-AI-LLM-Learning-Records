## 1. 链表操作迭代

> 链表天然适合迭代：**单链表无法回溯，迭代靠"暂存后继"实现指针变换**。

### 1.1 反转链表（三指针模板，必背）

```java
public ListNode reverseList(ListNode head) {
    ListNode prev = null;              // 已反转部分的新头
    ListNode cur = head;
    while (cur != null) {
        ListNode next = cur.next;      // ① 暂存后继（否则断链）
        cur.next = prev;               // ② 当前节点指向前驱
        prev = cur;                    // ③ prev 前进
        cur = next;                    // ④ cur 前进
    }
    return prev;                       // 终止：cur == null，prev 即新头
}
// 与递归版对比：递归 O(n) 栈，迭代 O(1) 空间
// 记忆："暂存后继 → 反转 → 双指针前进"
```

### 1.2 链表迭代高频操作

| 操作 | 迭代思路 | 题目 |
|------|---------|:---:|
| 反转链表 | prev/cur/next 三指针 | 206 |
| 合并有序链表 | 哨兵头 + 双指针尾插 | 21 |
| 判环 | 快慢指针（Floyd） | 141 |
| 链表中点 | 快慢指针 | 876 |
| 删除倒数第 N | 快指针先走 N 步 | 19 |
| 两两交换 | 哨兵 + 成对反转 | 24 |

```java
// 合并有序链表（哨兵节点技巧：避免处理空头分支）
public ListNode mergeTwoLists(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(0);   // 哨兵：统一"空链表"边界
    ListNode tail = dummy;
    while (l1 != null && l2 != null) {
        if (l1.val <= l2.val) { tail.next = l1; l1 = l1.next; }
        else                  { tail.next = l2; l2 = l2.next; }
        tail = tail.next;
    }
    tail.next = (l1 != null) ? l1 : l2; // 接上剩余
    return dummy.next;
}
// 💡 哨兵节点 = 迭代的"初始化技巧"，消除头节点特判
```

## 2. 数值迭代

### 2.1 快速幂（二进制展开）

```java
/**
 * 50. Pow(x, n)：O(log n) 次乘法
 * 原理：n 的二进制位决定哪些 x^(2^k) 需要相乘
 */
public double myPow(double x, int n) {
    long N = n;                          // ⚠️ 防 -2³¹ 取负溢出
    if (N < 0) { x = 1.0 / x; N = -N; }

    double ans = 1.0;
    while (N > 0) {
        if ((N & 1) == 1) ans *= x;      // 当前位 = 1 → 乘上当前幂
        x *= x;                          // 幂次翻倍：x^(2^k)
        N >>= 1;                         // 移到下一位
    }
    return ans;
}
// 例：x¹³ = x⁸·x⁴·x¹（13 = 1101₂）
// 记忆："位为 1 就乘，底数自乘，右移"
```

### 2.2 牛顿迭代法求平方根

```java
/**
 * 69. x 的平方根（牛顿法）
 * 迭代公式：x₁ = (x₀ + n/x₀) / 2（切线逼近）
 * 收敛性：每次迭代误差平方级下降，通常几十次内收敛
 */
public int mySqrt(int x) {
    if (x == 0) return 0;
    double x0 = x;
    while (true) {
        double x1 = (x0 + x / x0) / 2;
        if (Math.abs(x1 - x0) < 1e-7) break;   // 收敛判定：变化足够小
        x0 = x1;
    }
    return (int) x0;
}
// ⚠️ 迭代法的共性：初始值 + 更新公式 + 收敛判定（三要素！）
```

| 数值方法 | 迭代公式 | 收敛速度 | 场景 |
|---------|---------|:---:|------|
| 牛顿法 | x ← x - f(x)/f'(x) | 平方收敛 | 求根/最优化 |
| 二分逼近 | 每次砍半区间 | 线性收敛 | 单调函数求值 |
| 梯度下降 | θ ← θ - η·∇f | 线性 | 机器学习 |
| 幂法 | 反复左乘矩阵 | 线性 | 求最大特征值 |

> 💡 所有数值迭代都是同一个骨架：**初始值 → 更新公式 → 收敛判定**——三要素的完美体现。

## 3. 动态规划迭代

> DP 有两种写法：记忆化递归（自顶向下）和**迭代填表（自底向上）**。迭代版无栈溢出、常数小，是生产首选。

### 3.1 滚动数组：空间 O(1)

```java
/**
 * 70. 爬楼梯 / 509. 斐波那契
 * 转移方程：f(i) = f(i-1) + f(i-2)
 * 滚动数组：只保留前两个状态 → 空间 O(1)
 */
public int climbStairs(int n) {
    if (n <= 2) return n;
    int a = 1, b = 2;                    // f(1), f(2) 初始状态
    for (int i = 3; i <= n; i++) {
        int c = a + b;                   // 迭代转移
        a = b;
        b = c;                           // 滚动：丢弃最旧状态
    }
    return b;
}
// 记忆："数组变三变量"——滚动数组 = 只留需要的窗口
```

### 3.2 记忆化递归 vs 迭代填表

| 维度 | 记忆化递归 | 迭代填表 |
|------|:---:|:---:|
| 方向 | 自顶向下 | 自底向上 |
| 栈溢出 | 深度 = 状态数，可能溢出 | 无 |
| 代码 | 递归 + 缓存 Map | 双重循环 |
| 只依赖部分状态 | 天然跳过无关状态 | 可能多算 |
| 生产选择 | 状态少/依赖稀疏 | **主流** |

```
通用转换：把递归调用 f(i) 换成循环填表
  f(0), f(1) → 初始行
  for i: for j: dp[i][j] = 转移(dp[i-1][j], ...)
```

## 4. 数组模拟迭代

### 4.1 螺旋矩阵（四边界收缩）

```java
/**
 * 59. 螺旋矩阵 II：上右下左四轮，每轮收缩一条边界
 */
public int[][] generateMatrix(int n) {
    int[][] matrix = new int[n][n];
    int top = 0, bottom = n - 1, left = 0, right = n - 1;
    int num = 1;
    while (num <= n * n) {
        for (int j = left; j <= right; j++) matrix[top][j] = num++;  // →
        top++;
        for (int i = top; i <= bottom; i++) matrix[i][right] = num++; // ↓
        right--;
        for (int j = right; j >= left; j--) matrix[bottom][j] = num++; // ←
        bottom--;
        for (int i = bottom; i >= top; i--) matrix[i][left] = num++;  // ↑
        left++;
    }
    return matrix;
}
// 记忆："四边界四方向，每轮收缩"——循环不变量：未填区域 = [top..bottom]×[left..right]
```

### 4.2 约瑟夫环（数学迭代）

```java
/**
 * 剑指 62 / 1823. 约瑟夫环
 * 逆推：f(1) = 0，f(i) = (f(i-1) + k) % i
 * 不用模拟删除，O(n) 直接推出最后幸存者
 */
public int lastRemaining(int n, int k) {
    int ans = 0;                         // f(1)：1 人时幸存者下标 0
    for (int i = 2; i <= n; i++) {
        ans = (ans + k) % i;             // 从 i-1 人反推 i 人
    }
    return ans;
}
// 对比：链表模拟删除 O(nk)，数学迭代 O(n)/O(1)
// 💡 关键：迭代的每一步状态 = "规模 i 时的幸存者下标"
```

## 5. 字符串与搜索迭代

### 5.1 KMP 前缀函数（迭代构建）

```java
/**
 * KMP 前缀函数 pi[i] = 子串 s[0..i] 的最长相等真前后缀长度
 * 迭代构建：j = pi[i-1]，失配就回退 pi[j-1]
 */
public int[] prefixFunction(String s) {
    int n = s.length();
    int[] pi = new int[n];
    for (int i = 1; i < n; i++) {
        int j = pi[i - 1];                       // 继承上一状态
        while (j > 0 && s.charAt(i) != s.charAt(j)) {
            j = pi[j - 1];                       // 失配回退（迭代！）
        }
        if (s.charAt(i) == s.charAt(j)) j++;
        pi[i] = j;
    }
    return pi;
}
// KMP 主匹配 O(n+m)：失配时模式串指针回退而非重头再来
```

### 5.2 双指针与滑动窗口（迭代的子集）

```
双指针/滑动窗口 = 迭代 + 指针状态：
  · 对撞指针：left++ / right--（有序数组找两数）→ 167/11/15
  · 快慢指针：fast/slow 不同速 → 27/141/876
  · 滑动窗口：right 扩 / left 缩，维护区间不变量 → 3/76/209

它们本质都是"单次循环 + 状态指针"，是迭代思想的直接应用
（详见同目录"双指针思想"与"滑动窗口思想"子体系）
```

### 5.3 迭代加深搜索 IDDFS

```
IDDFS（Iterative Deepening DFS）：
  用迭代控制递归深度：for (depth = 1; depth <= max; depth++) DFS(depth)
  每轮 DFS 只搜索到指定深度 → 结合 BFS 的最优性与 DFS 的空间
  应用：深度最优解问题（如十五数码）、无限深度搜索空间

价值：把"深度上限"变成迭代的循环条件——迭代思想的搜索应用
```

## 6. 真实世界中的迭代

| 场景 | 迭代形式 |
|------|---------|
| 事件循环 | while (true) { 取事件 → 处理 }（Netty/Node.js） |
| 消息循环 | while (!shutdown) { 接收消息 → 分发 } |
| 游戏主循环 | while (running) { input → update → render } |
| 状态机 | while 循环 + switch 状态迁移 |
| 数据管道 | 迭代器链式消费（Stream 惰性迭代） |
| 数值仿真 | 时间步进迭代（物理引擎） |

```java
// 事件循环骨架（Netty 风格）
while (!isShutdown) {
    Event event = eventQueue.take();   // 阻塞取事件
    handle(event);                     // 处理
    updateState();                     // 状态更新（三要素之步进）
}
// 几乎所有"常驻服务"都是一个大迭代
```

> 🎯 **核心要点**：迭代五大应用——**链表**（三指针/哨兵）、**数值**（快速幂/牛顿法，骨架 = 初始值+更新公式+收敛判定）、**DP**（滚动数组 O(1) 空间）、**模拟**（螺旋四边界/约瑟夫数学递推）、**搜索**（KMP 回退/KMP 前缀函数、双指针滑窗、IDDFS）。真实世界的事件循环、游戏主循环也是迭代。所有应用共享同一骨架：**初始化 → 循环条件 → 步进更新**。
