## 2. 必背代码模板

### 2.1 反转链表（迭代）

```java
public ListNode reverseList(ListNode head) {
    ListNode prev = null, cur = head;
    while (cur != null) {
        ListNode next = cur.next;   // ① 暂存后继
        cur.next = prev;            // ② 反转指针
        prev = cur;                 // ③ prev 前进
        cur = next;                 // ④ cur 前进
    }
    return prev;
}
// 时空：O(n)/O(1)；与递归版对比是必答点
```

### 2.2 中序遍历（迭代，最高频考点）

```java
public List<Integer> inorder(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode cur = root;
    while (cur != null || !stack.isEmpty()) {
        while (cur != null) {       // 左探
            stack.push(cur);
            cur = cur.left;
        }
        cur = stack.pop();          // 回溯
        result.add(cur.val);        // 处理
        cur = cur.right;            // 右转
    }
    return result;
}
// 时空：O(n)/O(h)；口诀：左探-回溯-右转
```

### 2.3 层序遍历（队列）

```java
public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> result = new ArrayList<>();
    if (root == null) return result;
    Queue<TreeNode> queue = new ArrayDeque<>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        int size = queue.size();    // ⚠️ 先快照，否则层会混
        List<Integer> level = new ArrayList<>();
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            level.add(node.val);
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        result.add(level);
    }
    return result;
}
```

### 2.4 快速幂（迭代）

```java
public double myPow(double x, int n) {
    long N = n;                     // ⚠️ 防 -2³¹ 取负溢出
    if (N < 0) { x = 1.0 / x; N = -N; }
    double ans = 1.0;
    while (N > 0) {
        if ((N & 1) == 1) ans *= x; // 位为 1 → 乘
        x *= x;                     // 底数自乘
        N >>= 1;                    // 右移
    }
    return ans;
}
// O(log n)：13 = 1101₂ → x¹³ = x⁸·x⁴·x¹
```

## 3. 面试话术模板

```
"这题我写迭代版：
 ① 三要素：初始化（prev=null, cur=head）、
   循环条件（cur != null）、更新步进（prev/cur 前进）；
 ② 循环不变量：'已处理区间 [0, prev] 已反转'，
   初始化成立、每轮保持、终止时 prev 即新头，所以正确；
 ③ 复杂度 O(n)/O(1)，无栈溢出风险。
 如果先写递归版：深度 O(n) 可能溢出，我可以转显式栈迭代。"
```

```
递归 → 迭代的回答框架：
  ① 递归深度多少？（树 O(h) 安全 / 链表 O(n) 危险）
  ② 递归形态？（尾递归 → 直接循环；一般 → 显式栈）
  ③ 显式栈怎么压？（先压后处理的；中序 = 左探-回溯-右转）
  ④ 空间对比？（递归 O(n) 调用栈 vs 迭代 O(h) 堆栈）
```

## 4. 高频追问 TOP 10

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 迭代三要素？ | 初始化、循环条件、更新步进（缺一不可） |
| 2 | 死循环怎么避免？ | 检查步进是否执行、条件是否恒真、收敛性 |
| 3 | 循环不变量是什么？ | 每轮保持的性质；初始化/保持/终止三性质证明正确性 |
| 4 | 递归转迭代怎么转？ | 尾递归直接循环；一般递归显式栈/状态机 |
| 5 | 中序迭代怎么做？ | 左探-回溯-右转（显式栈） |
| 6 | 遍历中删除元素？ | iterator.remove() / removeIf；直接 remove 抛 CME |
| 7 | for-each 是什么？ | 编译成 Iterator 的语法糖（数组用索引） |
| 8 | 迭代器 vs 索引？ | 迭代器解耦容器、链表 O(1) 顺序访问；索引适合随机访问 |
| 9 | 什么时候用递归不迭代？ | 树/回溯自相似结构；深度大/生产代码用迭代 |
| 10 | while 和 for 的区别？ | 本质等价；for 三要素集中不易漏，while 适合条件驱动 |

## 5. 常见错误与修正

| 错误 | 后果 | 修正 |
|------|------|------|
| 漏更新步进（i++ 缺失） | 死循环 | 三要素自查，for 优于 while |
| 条件恒真/方向错 | 死循环 / 空转 | 手推 1-2 轮验证 |
| off-by-one（i <= n） | 越界 / 漏最后一个 | 统一 [0, n) 半开区间 |
| 遍历中直接 list.remove | ConcurrentModificationException | iterator.remove() / removeIf |
| 链表反转忘暂存后继 | 断链丢节点 | 三指针顺序：暂存→反转→前进 |
| 中序迭代忘右转 | 死循环 / 漏右子树 | 三步口诀：左探-回溯-右转 |
| 层序不先取 size | 层与层混在一起 | `int size = queue.size()` |
| 递归硬扛大深度 | StackOverflowError | 转显式栈迭代 |
| 循环内 String 拼接 | O(n²) 时间 | StringBuilder |
| 快速幂 int 取负 | Integer.MIN_VALUE 溢出 | 转 long 再取负 |

> 🎯 **核心要点**：迭代面试 = **模板 + 话术 + 转换能力**。必背四模板：反转链表（三指针）、中序迭代（左探-回溯-右转）、层序（队列 + size 快照）、快速幂（二进制展开）。话术三件套：三要素 → 循环不变量 → 复杂度。被追问"栈溢出"时：分析深度 → 判断形态 → 显式栈转换。高频错误集中在：漏步进、off-by-one、遍历中删除、忘暂存后继。
