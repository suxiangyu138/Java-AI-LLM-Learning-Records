## 6. 常见问题 FAQ

| 问题 | 一句话答案 |
|------|-----------|
| DP 和递归区别？ | 递归无缓存（指数）、DP 记忆化（多项式） |
| DP 和贪心区别？ | 贪心局部最优（需证明）、DP 全局最优（枚举子问题） |
| DP 和枚举区别？ | 枚举全穷举、DP 记忆化剪枝 |
| 什么时候用 DP？ | 最优子结构 + 重叠子问题 |
| 状态怎么定义？ | 问「子问题的答案是什么」 |
| 转移怎么找？ | 问「最后一个选择是什么」 |
| 初始化怎么定？ | 边界状态（dp[0] 等） |
| 遍历顺序？ | 依赖方向（正序/逆序/先区间长） |
| 空间怎么优化？ | 滚动数组（只留依赖行） |
| DP 难在哪？ | 建模（状态+转移）而非实现 |

## 9. 五步法模板卡

```text
① 状态: dp[i] = 子问题的答案
② 转移: dp[i] = f(dp[i-1], ...)（问最后一个选择）
③ 初始化: dp[0] 等边界值
④ 遍历: 依赖方向（背包 0-1 逆序）
⑤ 优化: 滚动数组（只留依赖行）
```

| 认知 | 一句话 |
|------|--------|
| DP 本质 | 聪明的枚举（记忆化剪枝） |
