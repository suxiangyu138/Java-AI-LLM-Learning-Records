## 1. 树形 DP 的本质

**树形 DP**：`dp[node]` 表示以 node 为根的子树最优——树上后序遍历（子树先算，根汇总）。

```text
统一框架:
  遍历: DFS 后序（先子树后根）
  状态: dp[node] = 子树信息（可多值）
  转移: 汇总子节点 dp
  入口: 根节点（或每节点为根的枚举）

识别信号: 树/森林 + 最优选择/计数
对比线性 DP: 线性依赖前驱、树形依赖子树
```

| 维度 | 线性 DP | 树形 DP |
|------|:---:|:---:|
| 结构 | 序列 | **树** |
| 状态 | dp[i] | dp[node] |
| 遍历 | for | **DFS 后序** |
| 依赖 | 前驱 | 子节点 |
| 入口 | dp[0] | 根 |

> 🎯 **树形 DP 心法**：**「返回值 = 子树信息」**——每个节点向父节点汇报「子树的最优/两态/高度」，父节点汇总决策；树的直径、最大路径和、打家劫舍 III 全部是这一思想的变体。

## 2. 核心模板：后序 + 返回值

```java
// 树形 DP 万能骨架
// 返回值 = 子树信息（可返回数组表示多状态）
int[] dfs(TreeNode node) {
    if (node == null) return baseCase();       // ① 空子树基准

    int[] left = dfs(node.left);               // ② 后序: 先算左子树
    int[] right = dfs(node.right);             // ③ 再算右子树

    // ④ 汇总决策（核心逻辑）
    int[] cur = new int[STATE_COUNT];
    cur[0] = combine(left[0], right[0], node.val);
    return cur;                                // ⑤ 向父汇报
}

// 调用: dfs(root) → 取所需状态
```

**为什么必须后序**：

```text
依赖关系: 父节点需要子节点的 dp
  → 必须先算出子树 → 后序天然满足

反例（前序）: 算父节点时子节点还没算 → 依赖缺失 ✗
```

| 要素 | 说明 |
|------|------|
| 返回值 | 子树信息（单值或数组） |
| 基准 | null 节点的返回值 |
| 汇总 | max/求和/两态组合 |
| 入口 | 根（或每个节点） |

> ⚠️ **树形 DP 的常见错误**：前序/中序遍历（依赖未算）——**必须后序**；返回值语义不清（先想好「向父汇报什么」再写）。

## 3. 选择模型：打家劫舍 III

**选择模型**：每个节点「选/不选」两态——打家劫舍 III 是标杆。

```java
// 337 打家劫舍 III
// 返回 [偷该节点, 不偷该节点] 的最大金额
public int rob(TreeNode root) {
    int[] res = dfs(root);
    return Math.max(res[0], res[1]);
}

int[] dfs(TreeNode node) {
    if (node == null) return new int[]{0, 0};

    int[] left = dfs(node.left);
    int[] right = dfs(node.right);

    // 偷: 子节点不能偷
    int steal = node.val + left[1] + right[1];
    // 不偷: 子节点可偷可不偷（取大）
    int skip = Math.max(left[0], left[1])
             + Math.max(right[0], right[1]);
    return new int[]{steal, skip};
}
```

| 选择题 | 状态 | 决策 |
|--------|------|------|
| 337 打家劫舍 III | 偷/不偷 | 偷则子不偷 |
| 968 监控二叉树 | 三态 | 见第 5 节 |
| 310 最小高度树 | 高度 | 换根/双 BFS |
| 树的独立集 | 选/不选 | 同 337 |

> 💡 **两态返回值的通用性**：凡是「选/不选」的树上决策都能用 [选, 不选] 数组——**状态数组的每个下标 = 一个决策维度**；父子约束（偷则子不偷）体现在转移条件。

## 4. 路径模型：直径与最大路径和

**路径模型**：dp 返回「单向下行信息」，全局在节点处汇总。

### 4.1 树的直径（543）

```java
// 543 二叉树的直径
// 返回: 高度（单向下行最长）；全局: 左高 + 右高
int max = 0;
int depth(TreeNode node) {
    if (node == null) return 0;
    int left = depth(node.left);              // 后序
    int right = depth(node.right);
    max = Math.max(max, left + right);        // 经过本节点的最长路径
    return Math.max(left, right) + 1;         // 向父汇报高度
}
// 答案: max（任意节点左右高度和的最大值）
```

### 4.2 最大路径和（124）

```java
// 124 二叉树中的最大路径和
// 返回: 单向下行最大和（可为负 → 取 0 剪枝）
int best = Integer.MIN_VALUE;
int maxDown(TreeNode node) {
    if (node == null) return 0;
    int left = Math.max(0, maxDown(node.left));   // 负贡献取 0（不选）
    int right = Math.max(0, maxDown(node.right));
    best = Math.max(best, left + right + node.val); // 经过本节点的路径
    return Math.max(left, right) + node.val;        // 单向下行汇报
}
```

| 路径题 | 返回值 | 全局汇总 |
|--------|--------|---------|
| 543 直径 | 高度 | 左高+右高 |
| 124 最大路径和 | 单向下行和 | 左+右+val |
| 687 最长同值路径 | 同值高度 | 同值累计 |
| 250 统计同值子树 | 布尔 | 计数 |

> 🎯 **路径模型双通道**：**返回值 = 单通道（向父），全局变量 = 双通道（左+右+根）**——「单向下行信息」与「本节点汇合路径」是树形路径题的标准双轨。

## 5. 状态模型：监控二叉树

**状态模型**：超过两态的树上决策——监控二叉树三态。

```java
// 968 监控二叉树（三态）
// 返回: [该节点被覆盖, 该节点未覆盖但可被父覆盖, 该节点有相机]
// 简化实现: 0=未覆盖 1=已覆盖 2=有相机
int cameras = 0;
int dfs(TreeNode node) {
    if (node == null) return 1;                  // 空节点视为已覆盖
    int left = dfs(node.left);
    int right = dfs(node.right);

    if (left == 0 || right == 0) {               // ① 有子节点未覆盖 → 必须放相机
        cameras++;
        return 2;
    }
    if (left == 2 || right == 2) {               // ② 子节点有相机 → 本节点已覆盖
        return 1;
    }
    return 0;                                    // ③ 子节点都覆盖 → 本节点交给父
}
// 调用: dfs(root); 若根返回 0 则 cameras++（根未覆盖需相机）
```

| 状态题 | 状态数 | 转移关键 |
|--------|:---:|---------|
| 968 监控二叉树 | 3 | 子未覆盖→放相机 |
| 树着色 | k 色 | 颜色约束 |
| 最少相机/守卫 | 3 | 贪心/DP 两解 |

> 💡 三态设计的思路：**状态 = 节点与父/子的「责任关系」**——监控题的三种状态对应「谁来覆盖我」（自己/子/父）；状态数量由「责任关系」决定而非拍脑袋。

### 6.2 精讲：310 最小高度树（换根 DP）

```java
// 310: 找最小高度树的根（最多 2 个）
// 思路 A（换根 DP）: 两次 DFS——down[node]=子树高、up[node]=父侧高
//   换根转移: up[child] = max(down[other], up[node]) + 1（兄弟里最高 + 父侧）
//   每个节点的高度 = max(down[node], up[node])，取最小者
// 思路 B（双 BFS，本题最优）: 利用树直径性质 O(n)
//   ① 从任意节点 BFS 到最远节点 A
//   ② 从 A BFS 到最远节点 B，并记录 parent 回溯链
//   ③ A-B 路径的中点（1 或 2 个）即最小高度树的根
public List<Integer> findMinHeightTrees(int n, int[][] edges) {
    if (n == 1) return List.of(0);
    // ① 建邻接表 → BFS(0) 找最远 A
    // ② BFS(A) 记录 parent[] 与路径 → 找最远 B
    // ③ 从 B 沿 parent 回溯收集路径 → 取中点 1~2 个返回
}
```

> 💡 310 的两种思路：**换根 DP**（标准：down[node] 子树高 + up[node] 父侧高，两次 DFS）或**树直径双 BFS**（最短证明）——「树的结构性质（直径/中心）」是树形 DP 之外的第二武器。
