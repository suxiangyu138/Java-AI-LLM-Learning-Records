## 1. DP 的本质

**动态规划 = 分治 + 记忆化**：把大问题拆成重叠子问题，每个子问题只算一次。

```text
暴力递归（斐波那契）:    动态规划（记忆化）:
  fib(5)                    fib(5)
  ├─ fib(4)                 ├─ fib(4)  ← 算一次缓存
  │  ├─ fib(3)              └─ fib(3)  ← 算一次缓存
  │  │  └─ ... 重复计算!
  │  └─ fib(2)
  └─ fib(3) ← 重复!
  O(2ⁿ)                    O(n)

暴力 = 同一子问题反复算
DP  = 每子问题算一次（记忆化）
```

| 对比 | 递归暴力 | 动态规划 |
|------|:---:|:---:|
| 复杂度 | 指数 | **多项式** |
| 缓存 | ❌ | ✅ |
| 方向 | 自顶向下 | 自底向上（或递归+记忆） |
| 类比 | 重复劳动 | 归档复用 |

> 🎯 **DP 的本质一句话**：**「用空间换时间——把指数级重复计算压缩为多项式」**；所有 DP 题的共同目标都是消灭「同一子问题算多遍」。

## 2. 两大前提

**能不能用 DP？问两个问题**：

```text
① 最优子结构（Optimal Substructure）:
   全局最优能由子问题最优组合得出？
   例: 最大子数组和 → 每个位置的「以 i 结尾最大值」
       由「以 i-1 结尾最大值」+ 当前值 组合

② 重叠子问题（Overlapping Subproblems）:
   子问题是否反复出现？
   例: 斐波那契 fib(3) 出现多次
   反例: 二分查找（每次子问题不同）→ 分治非 DP
```

| 问题 | 最优子结构 | 重叠子问题 | 算法 |
|------|:---:|:---:|------|
| 斐波那契 | ✅ | ✅ | **DP** |
| 最短路径 | ✅ | ✅ | **DP/Dijkstra** |
| 二分查找 | ❌ | ❌ | 分治 |
| 快速排序 | ❌ | ❌ | 分治 |
| 贪心题 | ⚠️ 需证明 | ❌ | 贪心 |

> ⚠️ **区分 DP 与分治**：分治（快排/归并）子问题不重叠——各算各的；DP 子问题重叠——必须缓存；「重叠」是 DP 与分治的分水岭（衔接[分治思想（Divide and Conquer）](../分治思想（Divide and Conquer）/)）。

## 3. 五步法

**DP 万能五步**（面试必背框架）：

```text
① 定义状态:  dp[i] 表示什么？
   → 问「子问题的答案是什么」
   → 一维不够就二维（加维度 = 加决策变量）

② 找转移方程: dp[i] 与 dp[i-1]/dp[i-2]... 的关系？
   → 问「最后一个选择是什么」
   → 枚举最后一步的所有可能

③ 初始化:    边界状态 dp[0]/dp[1] 的值？
   → 最小子问题的答案（手动确定）

④ 定遍历顺序: 依赖方向？
   → 一维: 正序/逆序（依赖前或后）
   → 背包: 0-1 逆序、完全正序（防重复取）

⑤ 优化空间:  能滚动数组吗？
   → 只依赖前 k 个 → 数组压缩到 k
```

```java
// 五步法的代码骨架
int dpSolve(int[] nums) {
    int n = nums.length;
    // ① 状态定义: dp[i]
    int[] dp = new int[n];
    // ③ 初始化
    dp[0] = nums[0];
    // ④ 遍历顺序（正序）
    for (int i = 1; i < n; i++) {
        // ② 转移方程
        dp[i] = Math.max(dp[i - 1] + nums[i], nums[i]);
    }
    // 答案 = 状态聚合
    return Arrays.stream(dp).max().getAsInt();
}
```

> 🎯 **面试心法**：遇到 DP 题先大声说出五步（状态/转移/初始化/遍历/优化）——**框架本身就让面试官知道你会 DP**；转移找不出时回到「最后一个选择是什么」。

## 4. 完整示例：打家劫舍

**198 打家劫舍**：相邻不能偷，最大金额。

```java
// 五步法完整演示
public int rob(int[] nums) {
    int n = nums.length;
    if (n == 1) return nums[0];

    // ① 状态: dp[i] = 偷前 i 家的最大金额
    int[] dp = new int[n];
    // ③ 初始化: 前 1 家 / 前 2 家
    dp[0] = nums[0];
    dp[1] = Math.max(nums[0], nums[1]);

    // ④ 正序遍历
    for (int i = 2; i < n; i++) {
        // ② 转移: 最后一家「偷」或「不偷」
        //  偷: dp[i-2] + nums[i]（隔一家）
        //  不偷: dp[i-1]
        dp[i] = Math.max(dp[i - 1], dp[i - 2] + nums[i]);
    }
    return dp[n - 1];
}

// ⑤ 空间优化（滚动数组）: O(n) → O(1)
public int robOptimized(int[] nums) {
    int prev2 = 0, prev1 = 0;            // dp[i-2], dp[i-1]
    for (int num : nums) {
        int cur = Math.max(prev1, prev2 + num);
        prev2 = prev1;
        prev1 = cur;
    }
    return prev1;
}
```

```text
「最后一个选择」分析:
  第 i 家: 偷（→ dp[i-2]+nums[i]）或 不偷（→ dp[i-1]）
  → 取 max = 转移方程 ✓

初始化: dp[0]=nums[0]、dp[1]=max(nums[0],nums[1])
遍历: 正序（依赖 i-1/i-2，已算好）
```

> 💡 打家劫舍是「一维线性 DP」的模板——**状态只有一维、转移枚举最后一步、空间可滚到 O(1)**；198 → 213（环形）→ 337（树形）是经典进阶链。

## 5. 自顶向下 vs 自底向上

| 对比 | 自顶向下（记忆化递归） | 自底向上（递推） |
|------|:---:|:---:|
| 思路 | 递归 + 缓存 | 循环迭代 |
| 代码 | 直觉（递归） | 迭代 |
| 空间 | 递归栈 + 缓存 | 数组 |
| 超时风险 | 栈溢出（深递归） | 无 |
| 适用 | 转移难推导/依赖复杂 | 标准模型 |

```java
// 自顶向下（记忆化）: 329 最长递增路径 风格
// 返回值 = 从 (x,y) 出发的最长递增路径长度；memo 缓存已算结果
int dfs(int[][] matrix, int x, int y, int[][] memo) {
    if (memo[x][y] != 0) return memo[x][y];        // 记忆化: 已算过直接返回
    int best = 1;                                  // 至少包含自己
    int[][] dirs = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
    for (int[] d : dirs) {
        int nx = x + d[0], ny = y + d[1];
        if (在界内 && matrix[nx][ny] > matrix[x][y]) {   // 只走向更大值
            best = Math.max(best, 1 + dfs(matrix, nx, ny, memo));
        }
    }
    return memo[x][y] = best;                      // 缓存后返回
}
```

| 选择依据 | 说明 |
|---------|------|
| 依赖方向明确 → 自底向上 | 递推简单 |
| 依赖复杂/记忆化天然 → 自顶向下 | 递归 + memo |
| 大规模 → 自底向上 | 避免栈溢出 |

> 💡 两种写法**本质等价**（同一个 dp）——自顶向下适合「转移依赖难枚举」的场景（如矩阵路径、树形）；自底向上适合标准模型（背包/线性）；面试先写自底向上（稳），追问记忆化时补充。

## 6. 空间优化：滚动数组

**滚动数组（Rolling Array）**：dp 只依赖最近 k 行——数组压缩到 k，空间降维。

```java
// 爬楼梯（依赖前 2 个）: O(n) 空间 → O(1)
public int climbStairs(int n) {
    if (n <= 2) return n;
    int a = 1, b = 2;                  // dp[i-2], dp[i-1]
    for (int i = 3; i <= n; i++) {
        int c = a + b;                 // dp[i] = dp[i-1] + dp[i-2]
        a = b;
        b = c;
    }
    return b;
}

// 二维滚动（背包常见）: dp[i][j] 依赖 dp[i-1][...]
// → 只保留一行 dp[j]，逆序遍历防覆盖
```

| 优化类型 | 依赖 | 压缩 |
|---------|------|:---:|
| 一维滚动 | dp[i-1]、dp[i-2] | O(n) → O(1) |
| 二维滚动 | dp[i-1] 行 | O(n²) → O(n) |
| 完全背包滚动 | 可重复取 | 正序遍历 |
| 0-1 背包滚动 | 不可重复取 | **逆序遍历** |

> ⚠️ **背包滚动的顺序陷阱**：0-1 背包（每物一次）逆序、完全背包（可多次）正序——**遍历顺序决定「取一次还是取多次」**，这是背包 DP 最经典的坑（02 模块详解）。
