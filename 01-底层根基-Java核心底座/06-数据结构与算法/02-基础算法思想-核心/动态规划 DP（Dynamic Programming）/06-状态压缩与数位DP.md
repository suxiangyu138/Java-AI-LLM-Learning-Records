## 1. 状态压缩 DP 的本质

**状态压缩 DP**：用位掩码（int）表示「集合状态」——哪些元素已选/已访问。

```text
为什么需要压缩:
  集合状态无法用 int 下标表达（如「选 1,3,5」）
  位掩码: mask 的二进制位 = 元素选/不选
    mask = 0b101 = 选了 {0, 2}

状态: dp[mask] 或 dp[mask][last]
  一维: mask 表示已选集合
  二维: +last（最后一个是谁——TSP 需要）

前提: n ≤ 20（2²⁰ ≈ 100 万状态）

识别信号: 「子集选择/排列类」+ n 小 + 状态依赖已选集合
```

| 维度 | 说明 |
|------|------|
| 状态表示 | mask（int 位掩码） |
| 状态数 | 2ⁿ |
| 转移 | 枚举「下一步选谁」 |
| 上限 | n ≤ 20 |
| 与暴力区别 | 暴力枚举 2ⁿ 无缓存；压缩 DP 记忆化 |

> 🎯 **状态压缩的本质**：**「位掩码 = 集合的唯一编码」**——把一个集合（子问题）压缩成一个 int，让「集合状态」也能进 dp 数组；衔接[暴力枚举](../暴力枚举（Brute Force）/01-枚举的核心思想与模型.md)的位掩码子集枚举。

## 2. 状态压缩核心模板

### 2.1 TSP 模板（二维 dp[mask][last]）

```java
// 847 访问所有节点的最短路径（BFS 版）或 TSP 模板
// 状态: dp[mask][last] = 已访问 mask、当前在 last 的最短路径
int shortestPathLength(int n, int[][] graph) {
    int full = (1 << n) - 1;                    // 全访问
    int[][] dp = new int[1 << n][n];
    for (int[] row : dp) Arrays.fill(row, Integer.MAX_VALUE / 2);

    // 初始化: 从任意点出发
    Deque<int[]> q = new ArrayDeque<>();
    for (int i = 0; i < n; i++) {
        dp[1 << i][i] = 0;
        q.offer(new int[]{1 << i, i});
    }

    // BFS 版状态压缩（免 Dijkstra）
    while (!q.isEmpty()) {
        int[] cur = q.poll();
        int mask = cur[0], last = cur[1];
        if (mask == full) return dp[mask][last];
        for (int next : graph[last]) {
            int newMask = mask | (1 << next);
            if (dp[newMask][next] > dp[mask][last] + 1) {
                dp[newMask][next] = dp[mask][last] + 1;
                q.offer(new int[]{newMask, next});
            }
        }
    }
    return -1;
}
```

### 2.2 一维模板（dp[mask] 纯集合）

```java
// 一维: dp[mask] = 集合 mask 的最优
for (int mask = 0; mask < (1 << n); mask++) {
    // 枚举「从 mask 出发的下一步」
    for (int i = 0; i < n; i++) {
        if ((mask & (1 << i)) != 0) continue;   // i 已选
        int newMask = mask | (1 << i);
        dp[newMask] = min(dp[newMask], dp[mask] + cost(mask, i));
    }
}
```

**位运算三件套**：

```java
int full = (1 << n) - 1;          // 全集
boolean has = (mask & (1 << i)) != 0;   // i 是否在集合
int newMask = mask | (1 << i);    // 加入 i
// 遍历子集（进阶）: for (int sub = mask; sub > 0; sub = (sub-1) & mask)
```

> 💡 **遍历子集技巧**：`for (sub = mask; sub; sub = (sub-1) & mask)`——枚举 mask 的全部子集（O(3ⁿ) 总复杂度），是子集型状态压缩（如 698）的常用优化。

## 3. 状态压缩经典题

| 题号 | 题目 | 状态 | 转移 |
|------|------|------|------|
| 526 | 优美的排列 | mask 已用 | 排列计数 |
| 691 | 贴纸拼词 | mask 已覆盖 | 位或 |
| 698 | 划分为 k 个等和子集 | mask 已分配 | 子集和 |
| 847 | 访问所有节点 | mask+last | BFS 最短 |
| 1879 | 最小异或和 | mask 已匹配 | 位操作 |
| 1723 | 完成工作最短时间 | mask 已分配 | 回溯+DP |

```java
// 526 优美的排列（排列计数模板）
public int countArrangement(int n) {
    int[] dp = new int[1 << n];          // dp[mask] = mask 排列数
    dp[0] = 1;
    for (int mask = 0; mask < (1 << n); mask++) {
        int count = Integer.bitCount(mask);       // 已选个数（当前位次）
        for (int i = 0; i < n; i++) {
            if ((mask & (1 << i)) != 0) continue; // i 已用
            int pos = count + 1;                  // 新元素的位置（1 基）
            if (pos % (i + 1) == 0 || (i + 1) % pos == 0) {  // 条件
                dp[mask | (1 << i)] += dp[mask];
            }
        }
    }
    return dp[(1 << n) - 1];
}
```

> ⚠️ **状态压缩的适用判断**：n ≤ 20 且「子问题的关键在于已选集合」——**如果「选了哪些」决定未来决策，就值得压缩**；n > 22 时 2ⁿ 状态超时，考虑双向搜索/剪枝。

## 4. 数位 DP 的本质

**数位 DP**：统计 [0, N] 范围内满足条件的数字个数——按「数位」逐位遍历 + 记忆化。

```text
为什么需要数位 DP:
  暴力: 遍历 0..N（N 可达 10¹⁸）→ 超时
  数位: 状态 = (位置 pos, 是否紧贴上限 tight, 其他约束)
        → O(位数 × 状态) = O(18 × 10) 极快

识别信号: 「范围内数字 + 计数/某位限制」
典型题: 不含某数字/不含重复位/数字和/回文数
```

| 维度 | 说明 |
|------|------|
| 状态 | dp[pos][tight][约束] |
| 上限 | 位数（≤ 18） |
| 复杂度 | O(位数 × 10 × 状态) |
| 实现 | 记忆化递归（自顶向下） |
| 关键 | tight（是否贴上限） |

> 🎯 **数位 DP 的本质**：「**tight（贴上限）是唯一的特殊状态**」——不贴上限时结果只依赖 pos 和约束（可缓存），贴上限时逐位精确模拟——记忆化只缓存「不贴上限」的分支。

## 5. 数位 DP 核心模板

```java
// 数位 DP 万能模板（记忆化递归）
// 233 数字 1 的个数: 统计 [1,n] 中 1 出现的次数
public int countDigitOne(int n) {
    String s = String.valueOf(n);
    int len = s.length();
    // memo[pos][count][tight]: pos 已处理位数、count 已出现 1 的个数、是否贴上限
    // count 上限 = len（如 111...1），故第二维用 len+1 防越界
    Long[][][] memo = new Long[len][len + 1][2];
    return (int) dfs(s, 0, 0, 1, memo);
}

long dfs(String s, int pos, int count, int tight, Long[][][] memo) {
    if (pos == s.length()) return count;              // ① 结束: 返回统计值
    if (memo[pos][count][tight] != null) return memo[pos][count][tight]; // ② 记忆化

    int limit = tight == 1 ? s.charAt(pos) - '0' : 9;  // ③ 上限: 贴上限则取 s[pos]，否则 9
    long total = 0;
    for (int d = 0; d <= limit; d++) {
        int newTight = (tight == 1 && d == limit) ? 1 : 0;  // ④ 更新 tight
        total += dfs(s, pos + 1, count + (d == 1 ? 1 : 0), newTight, memo);
    }
    if (tight == 0) memo[pos][count][tight] = total;  // ⑤ 只缓存不贴上限的分支
    return total;
}
```

**模板五步**：

```text
① 结束条件: pos 到末尾 → 返回当前统计
② 记忆化: 缓存 (pos, 状态, tight=0)
③ 上限: tight 决定当前位最大可填
④ tight 传递: 只有「之前贴上限且填了上限」才继续贴
⑤ 缓存条件: 只缓存不贴上限（贴上限分支唯一不缓存）
```

> 💡 **模板变体**：约束状态（是否已出现某数字/数字和/是否前导零）都加在「记忆化键」里——**状态维度 = 题面约束**；「前导零」（leading zero）是含 0 数字题的常见额外状态。

### 6.2 精讲：2376 统计特殊整数

```java
// 2376: 统计 [1,n] 中「各位数字都不重复」的数字
// 状态: pos（位数）+ mask（已用数字集合）+ tight（贴上限）+ started（是否已开始非零位）
// 前置: digits = n 的十进制位数组; len = digits.length
// memo 维度: [len][1<<10][2][2]（10 位数字 0-9）
long dfs(int pos, int mask, int tight, int started,
         int[] digits, Long[][][][] memo) {
    if (pos == digits.length) return started ? 1 : 0;   // ① 结束: 全 0 不计数
    if (memo[pos][mask][tight][started] != null)        // ② 记忆化
        return memo[pos][mask][tight][started];

    int limit = tight == 1 ? digits[pos] : 9;           // ③ 上限
    long total = 0;
    for (int d = 0; d <= limit; d++) {
        int newTight = (tight == 1 && d == limit) ? 1 : 0;
        if (started == 0 && d == 0) {
            // ④ 前导零: 不占位、不改 mask、仍算未开始
            total += dfs(pos + 1, mask, newTight, 0, digits, memo);
        } else if ((mask & (1 << d)) == 0) {
            // ⑤ 新数字: 加入 mask、标记已开始
            total += dfs(pos + 1, mask | (1 << d), newTight, 1, digits, memo);
        }                                               // ⑥ 已用数字 → 剪枝（不合法）
    }
    if (tight == 0) memo[pos][mask][tight][started] = total;  // ⑦ 只缓存不贴上限
    return total;
}
```

> 💡 2376 把「状态压缩 + 数位 DP」合体——**mask（已用数字）既是数位 DP 的约束状态、又是状态压缩的集合编码**；「前导零」处理是含 0 数字题的必考细节。

### 6.3 面试追问

| 追问 | 答题要点 |
|------|---------|
| 状态压缩前提？ | n ≤ 20 + 集合状态 |

> 🎯 **核心要点**：两类高阶 DP 验收——状态压缩（mask 集合编码、dp[mask][last]、n≤20、子集遍历技巧、526/847 模板）；数位 DP（pos+tight+约束三状态、五步模板、只缓存不贴上限、前导零处理、233/2376 模板）；「mask = 集合编码」是两类的共同数学基础。
