## 1. 区间 DP 的本质

**区间 DP**：`dp[i][j]` 表示区间 [i,j] 上的最优解——大区间由小区间合并而来。

```text
统一框架:
  状态: dp[i][j] = 区间 [i,j] 的最优
  转移: dp[i][j] = f(dp[i][k], dp[k+1][j])（枚举分割点 k）
  遍历: 先长度（len）→ 再起点（i）→ 最后分割点（k）

识别信号: 「区间合并/切割/回文」+ 数组或字符串
对比线性 DP: 线性依赖前驱、区间依赖「内部子区间」
```

| 维度 | 线性 DP | 区间 DP |
|------|:---:|:---:|
| 状态 | dp[i] | **dp[i][j]** |
| 依赖 | 前驱 | 内部子区间 |
| 遍历 | 正序 | **先长度** |
| 复杂度 | O(n)/O(n²) | O(n³)（分割点） |
| 空间 | O(n) | O(n²) |

> 🎯 **区间 DP 与线性的本质区别**：线性问题「后缀接前缀」，区间问题「两块拼一块」——**转移永远在枚举「最后一块怎么拼」**。

## 2. 核心模板：先长度后起点

```java
// 区间 DP 万能模板
int[][] dp = new int[n][n];
for (int i = 0; i < n; i++) dp[i][i] = init(i);    // ③ 初始化: 单元素区间

for (int len = 2; len <= n; len++) {                // ① 区间长度（从小到大）
    for (int i = 0; i + len <= n; i++) {            // ② 起点
        int j = i + len - 1;                        // 终点
        dp[i][j] = INF;                             // ④ 初始为不可达
        for (int k = i; k < j; k++) {               // ⑤ 分割点
            dp[i][j] = Math.min(dp[i][j],
                dp[i][k] + dp[k + 1][j] + cost(i, k, j));
        }
    }
}
```

**为什么先长度**：

```text
依赖关系: dp[i][j] 依赖 dp[i][k] 和 dp[k+1][j]
  → 两个子区间的长度都 < len（i..k 和 k+1..j 更短）
  → 长度从小到大：短区间先算完 → 长区间可用

反例（先起点）: 
  算 dp[0][5] 时 dp[0][2]、dp[3][5] 还没算 → 依赖缺失 ✗
```

> ⚠️ **区间 DP 最容易错的遍历顺序**：必须先长度后起点——保证「依赖的子区间已算好」；写错顺序结果全错且难 debug。

## 3. 合并模型

**合并模型**：区间合并的代价最优化——石子合并、矩阵链乘。

```java
// 矩阵链乘（经典合并模型）
// dp[i][j] = 合并区间 [i,j] 的最小代价
// 转移: dp[i][j] = min(dp[i][k] + dp[k+1][j] + p[i]*p[k+1]*p[j+1])
for (int len = 2; len <= n; len++) {
    for (int i = 0; i + len <= n; i++) {
        int j = i + len - 1;
        dp[i][j] = Integer.MAX_VALUE;
        for (int k = i; k < j; k++) {
            dp[i][j] = Math.min(dp[i][j],
                dp[i][k] + dp[k + 1][j] + cost);
        }
    }
}
```

| 合并题 | 代价定义 | 关键 |
|--------|---------|------|
| 矩阵链乘 | p 乘积 | 经典模板 |
| 石子合并 | 区间和 | 前缀和优化 |
| 1039 多边形三角剖分 | 三角形权 | 分割点 |

> 💡 合并模型的代价 cost 常是「区间和」——用**前缀和 O(1) 预处理**避免每轮求和（石子合并的标准优化）。

## 4. 回文模型

**回文模型**：区间回文性质/回文子序列/回文分割。

```java
// 516 最长回文子序列
// dp[i][j] = 区间 [i,j] 的最长回文子序列长度
public int longestPalindromeSubseq(String s) {
    int n = s.length();
    int[][] dp = new int[n][n];
    for (int i = 0; i < n; i++) dp[i][i] = 1;      // 单字符回文
    for (int len = 2; len <= n; len++) {
        for (int i = 0; i + len <= n; i++) {
            int j = i + len - 1;
            if (s.charAt(i) == s.charAt(j)) {
                dp[i][j] = dp[i + 1][j - 1] + 2;   // 两端相等 → 扩展
            } else {
                dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1]);  // 舍弃一端
            }
        }
    }
    return dp[0][n - 1];
}
```

| 回文题 | 状态 | 转移核心 |
|--------|------|---------|
| 516 最长回文子序列 | dp[i][j] 长度 | 两端相等 +2 / 否则 max 去端 |
| 5 最长回文子串 | 布尔 isPal | 两端相等且内部回文 |
| 647 回文子串个数 | 布尔 + 计数 | 扩展计数 |
| 131 分割回文串 | 回溯 + 预判 | 预处理 isPal |
| 132 分割回文串 II | dp[i] 最少切割 | 线性 + 回文预判 |
| 730 不同回文子序列 | 双指针去重 | 两端处理 |

> 💡 **回文子串 vs 子序列**：子串必须连续（布尔 isPal + 扩展）、子序列可跳（长度 dp + 取舍）——**子串用「两端扩展判断」、子序列用「两端取舍」**。

## 5. 切分模型

**切分模型**：区间切分的最优——戳气球（最后戳 k）、切木棍。

```java
// 312 戳气球（区间 DP 标杆）
// 思路: 倒着想——dp[i][j] = (i,j) 开区间内先戳完的最大硬币
//       最后一个戳 k: 得 nums[i]*nums[k]*nums[j]（两侧只剩 i、j）
public int maxCoins(int[] nums) {
    int n = nums.length;
    int[] val = new int[n + 2];                   // 加虚拟边界 1
    val[0] = val[n + 1] = 1;
    for (int i = 0; i < n; i++) val[i + 1] = nums[i];

    int[][] dp = new int[n + 2][n + 2];
    for (int len = 2; len <= n + 1; len++) {      // 区间长度
        for (int i = 0; i + len <= n + 1; i++) {
            int j = i + len;
            for (int k = i + 1; k < j; k++) {     // 最后戳的气球
                dp[i][j] = Math.max(dp[i][j],
                    dp[i][k] + dp[k][j] + val[i] * val[k] * val[j]);
            }
        }
    }
    return dp[0][n + 1];
}
```

| 切分题 | 思考角度 | 关键 |
|--------|---------|------|
| 312 戳气球 | **最后一个戳的 k** | 虚拟边界 1 |
| 1547 切棍子 | 第一个切的 k | 排序切割点 |
| 1000 合并石头 | 合并组数 | 前缀和 |
| 87 扰乱字符串 | 分割比较 | 两个子串 |

> 🎯 **戳气球的思维转换**：正着戳难（邻居会变）、**倒着想「最后戳哪个」**——最后戳 k 时两侧固定为 i、j，子问题独立——「倒序决策」是区间切分的通用技巧。

### 6.2 精讲：132 分割回文串 II

```java
// 132: 最少切割次数（区间 + 线性混合）
// 预处理 isPal: 回文判断（区间 DP 布尔）
// 线性 dp: dp[i] = 前 i 个字符的最少切割
public int minCut(String s) {
    int n = s.length();
    // ① 预处理回文: isPal[i][j] = s[i..j] 是否回文
    boolean[][] isPal = new boolean[n][n];
    for (int len = 1; len <= n; len++) {
        for (int i = 0; i + len <= n; i++) {
            int j = i + len - 1;
            isPal[i][j] = s.charAt(i) == s.charAt(j)
                && (len <= 2 || isPal[i + 1][j - 1]);
        }
    }
    // ② 线性 DP: dp[i] = min(dp[j]) + 1（j..i 是回文）
    int[] dp = new int[n];
    for (int i = 0; i < n; i++) {
        if (isPal[0][i]) { dp[i] = 0; continue; }
        dp[i] = i;                                 // 最坏: 每字符切
        for (int j = 0; j < i; j++) {
            if (isPal[j + 1][i]) {
                dp[i] = Math.min(dp[i], dp[j] + 1);
            }
        }
    }
    return dp[n - 1];
}
```

> 💡 132 的启示：**区间 DP 常常是「预处理工具」**——先用区间 DP 算出 isPal（O(n²)），再跑线性 DP（O(n²)）；「回文判断」是很多字符串 DP 题的公共前置。
