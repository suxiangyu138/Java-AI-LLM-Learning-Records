## 1. 背包问题总览

**背包问题**：给定容量和物品（重量/价值），求容量内的最优选择。

```text
统一模型:
  物品: 重量 w[i]、价值 v[i]
  容量: C
  目标: 容量内价值最大（或方案数）

四种基本类型:
  0-1 背包:    每物一次
  完全背包:    每物无限次
  多重背包:    每物有限 k 次
  分组背包:    每组选一个
```

| 类型 | 物品次数 | 滚动遍历 | 典型题 |
|------|:---:|:---:|--------|
| 0-1 | 1 次 | **逆序** | 416 分割等和子集 |
| 完全 | 无限 | **正序** | 322 零钱兑换 |
| 多重 | k 次 | 二进制拆分 | 洛谷 P1776 宝物筛选 |
| 分组 | 组内 1 个 | 组外逆序 | 洛谷 P1757 通天之分组背包 |
| 计数 | 1 次/无限 | 逆/正 | 494/518 |

> 🎯 **背包的灵魂**：**「容量维度 j + 遍历顺序」**——0-1 逆序（防重复取）、完全正序（允许重复取）；理解这一点，背包变体全部迎刃而解。

## 2. 0-1 背包

### 2.1 二维 → 一维

```java
// 二维版（直观）: dp[i][j] = 前 i 个物品、容量 j 的最大价值
// 转移: 不选 dp[i-1][j] / 选 dp[i-1][j-w] + v
int[][] dp = new int[n + 1][C + 1];
for (int i = 1; i <= n; i++) {
    for (int j = 0; j <= C; j++) {
        dp[i][j] = dp[i - 1][j];                 // 不选
        if (j >= weights[i - 1]) {
            dp[i][j] = Math.max(dp[i][j], dp[i - 1][j - weights[i - 1]] + values[i - 1]);
        }
    }
}
// 答案: dp[n][C]

// 一维滚动版（面试标准）: dp[j] = 容量 j 的最大价值
int[] dp = new int[C + 1];
for (int i = 0; i < n; i++) {
    for (int j = C; j >= weights[i]; j--) {      // 逆序！
        dp[j] = Math.max(dp[j], dp[j - weights[i]] + values[i]);
    }
}
```

### 2.2 为什么逆序（核心考点）

```text
正序遍历的错误:
  dp[3] = max(dp[3], dp[3-w] + v)  用物品 i 更新
  dp[6] = max(dp[6], dp[6-w] + v)  ← dp[6-w] 已含物品 i！
  → 同一物品被取两次（变完全背包）✗

逆序遍历的正确:
  dp[6] 先更新（用 dp[4]，此时 dp[4] 不含物品 i）
  dp[3] 后更新（不会污染更大的容量）
  → 每物只取一次 ✓

口诀: 0-1 逆序 = 防重复取
```

> ⚠️ **面试必考**：为什么 0-1 背包一维要逆序？——**正序会让 dp[j-w] 已被当前物品更新过，等于重复取同一物品**；逆序保证 dp[j-w] 还是「上一行」的值。

## 3. 完全背包

### 3.1 正序实现

```java
// 完全背包: 每物无限次 → 正序遍历（与 0-1 唯一的区别！）
int[] dp = new int[C + 1];
for (int i = 0; i < n; i++) {
    for (int j = weights[i]; j <= C; j++) {      // 正序！
        dp[j] = Math.max(dp[j], dp[j - weights[i]] + values[i]);
    }
}

// 322 零钱兑换（完全背包最小个数）
public int coinChange(int[] coins, int amount) {
    int[] dp = new int[amount + 1];
    Arrays.fill(dp, amount + 1);                 // INF
    dp[0] = 0;
    for (int coin : coins) {
        for (int j = coin; j <= amount; j++) {   // 正序（可重复）
            dp[j] = Math.min(dp[j], dp[j - coin] + 1);
        }
    }
    return dp[amount] > amount ? -1 : dp[amount];
}
```

### 3.2 0-1 vs 完全对比

| 维度 | 0-1 背包 | 完全背包 |
|------|:---:|:---:|
| 物品次数 | 1 次 | 无限次 |
| 滚动遍历 | **逆序** | **正序** |
| 二维转移 | dp[i-1][j-w] | dp[i][j-w]（可复用本行） |
| 典型题 | 416/494 | 322/518/279 |

```text
二维视角（理解本质）:
  0-1:   dp[i][j] = max(dp[i-1][j], dp[i-1][j-w]+v)
         用「上一行」→ 逆序防覆盖
  完全:  dp[i][j] = max(dp[i-1][j], dp[i][j-w]+v)
         用「本行」→ 正序允许传递（无限次）
```

> 💡 一句记忆：**「0-1 看上一行（逆序）、完全看本行（正序）」**——遍历方向本质是「用哪一行的 dp[j-w]」的显式表达。

## 4. 多重背包与变体

### 4.1 多重背包（二进制拆分）

```java
// 多重背包: 每物 k[i] 次 → 二进制拆分转 0-1
// 思路: k 个物品拆成 1, 2, 4, ..., 2^m, 剩余 —— 对数个
//   k=13 → 1+2+4+6（4 个物品替代 13 个）
//   正确性: 任意 0..k 的数量都能由这些二进制位组合出来
// 效果: O(n·k·C) → O(n·log k·C)

// ① 拆分（把「k 次」变「log k 个 0-1 物品」）
List<Item> items = new ArrayList<>();
for (int i = 0; i < n; i++) {
    int k = count[i];
    for (int piece = 1; piece <= k; piece <<= 1) {   // 1, 2, 4, 8...
        items.add(new Item(weights[i] * piece, values[i] * piece));
        k -= piece;
    }
    if (k > 0) {                                     // 剩余不足 2^m 的部分
        items.add(new Item(weights[i] * k, values[i] * k));
    }
}
// ② 再按 0-1 背包跑（逆序遍历）
```

| 变体 | 处理 |
|------|------|
| 多重（k 次） | 二进制拆分 → 0-1 |
| 分组（组内选 1） | 组为外层，容量逆序 |
| 二维费用（重量+体积） | dp[j][k] 双容量 |
| 混合（0-1+完全） | 按类型选遍历方向 |
| 求方案数 | 计数转移（下节） |

> 💡 二进制拆分的正确性：任意 0..k 的数量都能由 1,2,4,...,2^m,剩余 组合——**把「k 次」压缩为「log k 个 0-1 物品」**，竞赛级优化。

## 5. 计数背包

**计数背包**：求「恰好装满/不超过容量」的方案数——转移从 max 变为累加。

```java
// 494 目标和（0-1 计数背包）
// 思路: sum(P) - sum(N) = target, sum(P)+sum(N)=total
//       → sum(P) = (total + target) / 2 → 0-1 背包凑该和
public int findTargetSumWays(int[] nums, int target) {
    int total = 0;
    for (int n : nums) total += n;
    if ((total + target) % 2 != 0 || Math.abs(target) > total) return 0;
    int sum = (total + target) / 2;

    int[] dp = new int[sum + 1];
    dp[0] = 1;                                 // 初始化: 空方案
    for (int num : nums) {
        for (int j = sum; j >= num; j--) {     // 0-1 逆序
            dp[j] += dp[j - num];              // 计数: 累加方案
        }
    }
    return dp[sum];
}

// 518 零钱兑换 II（完全计数）: 正序
// for (int j = coin; j <= amount; j++) dp[j] += dp[j - coin];
```

| 计数背包 | 初始化 | 遍历 | 典型题 |
|---------|:---:|:---:|--------|
| 0-1 计数 | dp[0]=1 | 逆序 | 494 目标和 |
| 完全计数 | dp[0]=1 | 正序 | 518 零钱 II |
| 恰好装满（最值） | dp[0]=0, 其余 INF | 按类型 | 322 |
| 恰好装满（可行性） | dp[0]=true, 其余 false | 按类型 | 416 |

> ⚠️ **计数与最值的初始化差异**：计数背包 dp[0]=1（空集一种方案）；最值背包 dp[0]=0、其余 -INF/INF（不可达标记）——**初始化语义决定「恰好 vs 不超过」**。

### 6.2 精讲：416 分割等和子集

```java
// 416: 能否分成两个和相等的子集 = 能否凑出 sum/2
public boolean canPartition(int[] nums) {
    int sum = 0;
    for (int n : nums) sum += n;
    if (sum % 2 != 0) return false;

    int target = sum / 2;
    boolean[] dp = new boolean[target + 1];    // dp[j] = 能否凑出 j
    dp[0] = true;                              // 空集能凑 0
    for (int num : nums) {
        for (int j = target; j >= num; j--) {  // 0-1 逆序
            dp[j] = dp[j] || dp[j - num];      // 选或不选
        }
    }
    return dp[target];
}
```
