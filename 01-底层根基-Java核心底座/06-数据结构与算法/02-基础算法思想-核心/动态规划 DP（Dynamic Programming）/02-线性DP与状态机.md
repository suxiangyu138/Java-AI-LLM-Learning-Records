## 1. 线性 DP 的本质

**线性 DP**：`dp[i]` 只依赖「前面的状态」（i-1/i-2/前缀）——一维状态、线性推进。

```text
统一框架:
  状态: dp[i] = 以 i 结尾（或前 i 个）的最优
  转移: dp[i] = f(dp[i-1], dp[i-2], ..., 元素)
  方向: 正序遍历（依赖已算好的前驱）

识别信号: 一维序列 + 求最优/计数/可行性
```

| 维度 | 说明 |
|------|------|
| 状态维度 | 1 维（dp[i]） |
| 依赖方向 | 前驱（i-1 等） |
| 遍历 | 正序 |
| 空间优化 | 滚动（依赖前 k 个 → k 变量） |
| 复杂度 | O(n) 或 O(n²)（枚举前驱） |

> 🎯 **线性 DP 的本质**：「以 i 结尾」的状态定义是万能钥匙——最大子数组和（以 i 结尾最大）、LIS（以 i 结尾最长）、打家劫舍（前 i 家）都能用它统一。

## 2. 入门三题

### 2.1 爬楼梯（70 题）

```java
// 状态: dp[i] = 到第 i 阶的方法数
// 转移: dp[i] = dp[i-1] + dp[i-2]（最后一步 1 或 2）
// 初始化: dp[1] = 1, dp[2] = 2
public int climbStairs(int n) {
    if (n <= 2) return n;
    int a = 1, b = 2;                    // 滚动（依赖前 2 个）
    for (int i = 3; i <= n; i++) {
        int c = a + b;
        a = b;
        b = c;
    }
    return b;
}
```

### 2.2 打家劫舍（198 题）

```java
// 状态: dp[i] = 偷前 i 家的最大金额
// 转移: dp[i] = max(dp[i-1], dp[i-2] + nums[i])
//        最后一家: 不偷 → dp[i-1]；偷 → dp[i-2]+nums[i]
// 初始化: dp[0]=nums[0], dp[1]=max(nums[0],nums[1])
public int rob(int[] nums) {
    int prev2 = 0, prev1 = 0;            // 滚动
    for (int num : nums) {
        int cur = Math.max(prev1, prev2 + num);
        prev2 = prev1;
        prev1 = cur;
    }
    return prev1;
}
```

### 2.3 最大子数组和（53 题）

```java
// 状态: dp[i] = 以 i 结尾的最大子数组和
// 转移: dp[i] = max(nums[i], dp[i-1] + nums[i])
//        要么从 i 重新开始，要么接上前面
// 答案: max(dp[i])（不一定 dp[n-1]！）
public int maxSubArray(int[] nums) {
    int cur = nums[0], best = nums[0];
    for (int i = 1; i < nums.length; i++) {
        cur = Math.max(nums[i], cur + nums[i]);   // 重新开始 or 延续
        best = Math.max(best, cur);
    }
    return best;
}
```

| 题目 | 状态 | 转移核心 | 细节 |
|------|------|---------|------|
| 70 爬楼梯 | dp[i] 方法数 | dp[i-1]+dp[i-2] | 斐波那契变体 |
| 198 打家劫舍 | dp[i] 最大金额 | max(偷/不偷) | 相邻限制 |
| 53 最大子数组和 | dp[i] 结尾最大 | max(a, dp+a) | **答案 = max 所有 dp** |
| 213 打家劫舍 II | 环形 | 拆两个线性 | 首尾不同取 |
| 152 乘积最大子数组 | 最大×最小 | 双状态（负负得正） | **需存最小** |

> ⚠️ 三个细节陷阱：①53 题答案要 `max(dp[i])` 而非 dp[n-1]（子数组可结束于任意位置）；②152 题负负得正需同时维护最大和最小；③213 环形打家劫舍拆成「不含首」和「不含尾」两个子问题。

## 3. 最长递增子序列 LIS

### 3.1 O(n²) 经典 DP

```java
// 300 最长递增子序列
// 状态: dp[i] = 以 nums[i] 结尾的 LIS 长度
// 转移: dp[i] = max(dp[j] + 1) 对 j < i 且 nums[j] < nums[i]
// 初始化: dp[i] = 1（自己）
public int lengthOfLIS(int[] nums) {
    int n = nums.length;
    int[] dp = new int[n];
    Arrays.fill(dp, 1);
    int ans = 1;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < i; j++) {        // 枚举前驱
            if (nums[j] < nums[i]) {
                dp[i] = Math.max(dp[i], dp[j] + 1);
            }
        }
        ans = Math.max(ans, dp[i]);
    }
    return ans;
}
```

### 3.2 O(n log n) 贪心 + 二分

```java
// 维护「每个长度的最小结尾」: tails[length] = 最小尾数
// tails 单调递增 → 二分找插入位置
public int lengthOfLIS(int[] nums) {
    int[] tails = new int[nums.length];
    int len = 0;
    for (int num : nums) {
        int lo = 0, hi = len;
        while (lo < hi) {                     // 二分第一个 ≥ num
            int mid = lo + (hi - lo) / 2;
            if (tails[mid] < num) lo = mid + 1;
            else hi = mid;
        }
        tails[lo] = num;                      // 替换或追加
        if (lo == len) len++;
    }
    return len;
}
```

| 对比 | O(n²) DP | O(n log n) 二分 |
|------|:---:|:---:|
| 复杂度 | O(n²) | O(n log n) |
| 思路 | 枚举前驱 | 贪心最小尾数 |
| 求具体序列 | ✅ | 需辅助数组 |
| 面试默认 | ✅ 先写 | 追问优化时写 |

> 💡 **LIS 的泛化**：最长递减（取负/反转）、最长递增子序列个数、俄罗斯套娃（排序 + LIS）——LIS 是「序列优化」类题的万能底座。

## 4. 状态机 DP：股票买卖系列

**状态机 DP**：dp[i][state]——状态含「当前持有/不持有」等决策维度，转移 = 状态切换。

### 4.1 核心模板（122 无限次交易）

```java
// 122 买卖股票的最佳时机 II（无限次）
// 状态: hold = 当前持有最大利润; empty = 当前空仓最大利润
// 转移:
//   hold  = max(hold, empty - price)   （买入 or 保持）
//   empty = max(empty, hold + price)   （卖出 or 保持）
public int maxProfit(int[] prices) {
    int hold = -prices[0];               // 第 1 天买入
    int empty = 0;
    for (int i = 1; i < prices.length; i++) {
        int prevHold = hold;
        hold = Math.max(hold, empty - prices[i]);     // 买入/保持
        empty = Math.max(empty, prevHold + prices[i]); // 卖出/保持
    }
    return empty;
}
```

### 4.2 状态机全家桶

| 题号 | 题目 | 状态维度 |
|------|------|---------|
| 121 | 一次交易 | 持有/不持有（记录最小价） |
| 122 | 无限次 | 持有/不持有 |
| 123 | 最多两次 | 持有 × 交易次数 |
| 188 | 最多 k 次 | 持有 × k |
| 309 | 含冷冻期 | 持有/空仓/冷冻 |
| 714 | 含手续费 | 持有/空仓（扣费） |

```java
// 188 最多 k 次（通用模板）: dp[k][state]
public int maxProfit(int k, int[] prices) {
    if (prices.length == 0) return 0;
    // 状态: buy[i] = 第 i 次买入后最大利润
    //       sell[i] = 第 i 次卖出后最大利润
    int[] buy = new int[k + 1];
    int[] sell = new int[k + 1];
    Arrays.fill(buy, -prices[0]);
    for (int price : prices) {
        for (int i = 1; i <= k; i++) {
            buy[i] = Math.max(buy[i], sell[i - 1] - price);   // 买入（用上次卖出的钱）
            sell[i] = Math.max(sell[i], buy[i] + price);      // 卖出
        }
    }
    return sell[k];
}
```

> 🎯 **状态机心法**：**状态 = 决策变量（持有/空仓）的笛卡尔积**——股票系列统一为「持有/空仓 × 交易次数」；冷冻期加一态、手续费在转移中扣减；识别信号：「可以多次买卖/带条件」→ 状态机。

## 5. 线性 DP 进阶技巧

### 5.1 经典变体

| 技巧 | 说明 | 典型题 |
|------|------|--------|
| 拆环 | 环形 → 两个线性 | 213 打家劫舍 II |
| 双状态 | 正负乘积 | 152 乘积最大 |
| 后缀依赖 | 从后向前 | 45 跳跃游戏 II |
| 滚动压缩 | 状态降维（buy/sell 数组） | 188 |
| 辅助数组 | 记录路径 | 673 最长递增子序列个数 |

### 5.2 经典题精讲：乘积最大子数组（152）

```java
// 负负得正 → 同时维护「最大」和「最小」
public int maxProduct(int[] nums) {
    int max = nums[0], min = nums[0], best = nums[0];
    for (int i = 1; i < nums.length; i++) {
        if (nums[i] < 0) {                 // 负数翻转最大最小
            int tmp = max;
            max = min;
            min = tmp;
        }
        max = Math.max(nums[i], max * nums[i]);
        min = Math.min(nums[i], min * nums[i]);
        best = Math.max(best, max);
    }
    return best;
}
```

> 💡 152 题的启发：**当「正负号」影响最优方向时，状态要存两个极值**——「负负得正」让最坏可能变最好，dp 必须同时跟踪最大与最小（线性 DP 的状态设计灵活性体现）。
