## 1. 知识体系导图

```text
分治（Divide and Conquer）
│
├── 核心本质 ──────────────────────────────────────────────
│   ├── = 拆分（Divide）→ 解决（Conquer）→ 合并（Combine）
│   ├── 判据：子问题相互独立 + 答案需要组合
│   ├── 基线：问题小到可直接解（单元素/空）
│   └── 数学基础：递归 + 主定理（T(n) = aT(n/b) + f(n)）
│
├── 三大应用支柱 ──────────────────────────────────────────
│   ├── 🟡 排序分治：归并排序（拆中点+合 merge）、快速排序（拆 pivot）
│   ├── 🟡 选择分治：快速选择（期望 O(n) 的 TopK 解法）
│   └── 🟡 二分分治：二分查找变体、二分答案（把最优化转判定）
│
├── 两类进阶形态 ──────────────────────────────────────────
│   ├── 跨边界分治：逆序对/翻转对（归并计数）
│   │   └── 一次比较批量结算 → O(n²) → O(n log n)
│   └── 构造分治：二叉树重建、表达式分治（递归下降）
│
├── 与兄弟算法关系 ────────────────────────────────────────
│   ├── 递归：分治的机制载体（递归 + 拆分 + 合并）
│   ├── 动态规划：子问题独立（分治）vs 重叠（DP）
│   ├── 暴力枚举：分治是"少枚举"的极致形态
│   └── 二分查找：分治思想的特化（单路 + 有序）
│
└── 快速选择子专题（3 篇）─────────────────────────────────
    ├── 00-快速选择专题精要（原理 + 模板 + 复杂度推导）
    ├── 01-快速选择进阶（中位数、复杂选择）
    └── 02-快速选择高频题解
```

## 4. 核心概念速查

| 概念 | 一句话解释 | 典型例题 |
|------|-----------|------|
| **分治** | 拆分-解决-合并，大问题拆成独立子问题 | 归并排序 |
| **子问题独立** | 子问题互不重叠（vs DP 的重叠） | 分治判据 |
| **基线条件** | 问题小到可直接解 | 单元素数组 |

| **逆序对** | 归并过程中跨边界计数 | 剑指 51 |

## 5. 复杂度速查表

| 算法 | 递推式 | 时间复杂度 | 空间 | 稳定性 |
|------|--------|:---:|:---:|:---:|
| 归并排序 | T(n)=2T(n/2)+O(n) | O(n log n) | O(n) | 稳定 |
| 快速排序（平均） | T(n)=T(k)+T(n-k)+O(n) | O(n log n) | O(log n) 栈 | 不稳定 |
| 快速排序（最坏） | T(n)=T(n-1)+O(n) | O(n²) | O(n) 栈 | 不稳定 |
| 快速选择（期望） | T(n)=T(n/2)+O(n) | O(n) | O(log n) | — |
| 二分查找 | T(n)=T(n/2)+O(1) | O(log n) | O(1) | — |
| 逆序对计数 | 同归并 | O(n log n) | O(n) | — |
| 二叉树重建 | 每层 O(n) × 层数 | O(n)~O(n²) | O(n) | — |
| 表达式分治 | 每层遍历 | O(n)~O(n²) | O(n) | — |

> 🎯 **主定理速记**：比较 `n^log_b(a)` 与 `f(n)`——**f 更小 → n^log_b(a)；同阶 → 乘 log n；f 更大 → f**。三个经典：归并（同阶→O(n log n)）、树遍历（n¹>c→O(n)）、二分（同阶→O(log n)）。

## 6. 常见误区速查

| 误区 | 正解 |
|------|------|
| "分治 = 递归" | ❌ 递归是机制，分治是思想（递归 + 拆分 + 合并）——所有分治都用递归，但递归不都是分治 |
| "分治和 DP 是一回事" | ❌ 分治子问题**独立**（无需记忆化）；DP 子问题**重叠**（必须记忆化） |
| "快排平均 O(n log n) 就够稳" | ❌ 已排序输入 + 固定 pivot → 最坏 O(n²)；工程上要随机化/三数取中 |
| "归并空间 O(log n)" | ❌ 归并需要 O(n) 临时数组（递归栈额外 O(log n)），合计 O(n) |
| "二分答案只能用于有序数组" | ❌ 二分答案用于**单调判定函数**（能吃多少香蕉）——有序数组只是特例 |
| "TopK 只能用堆" | ❌ 三条路线：快选 O(n) 期望（需要读全部）、堆 O(n log k)（适合流式）、桶（数据范围小） |
| "逆序对只能暴力 O(n²)" | ❌ 归并计数 O(n log n)——左半有序时一次比较批量结算 |
| "快速选择最坏是 O(n)" | ❌ 期望 O(n)，最坏 O(n²)（同快排）；加随机化避免 |

## 10. 一句话速记卡

```text
分治三步: 拆（Divide）→ 解（Conquer）→ 合（Combine）
判据:     子问题独立 + 答案组合 → 分治；重叠 → DP
主定理:   n^log_b(a) 与 f(n) 比大小，同阶乘 log n
排序双雄: 归并稳定 O(n log n) 空间 O(n)；快排原地但最坏 O(n²)
快速选择: 每次只进一侧 → 期望 O(n)（215）
二分答案: 最优化转判定，单调即可二分（875/410）
归并计数: 左半有序 → 一次比较批量结算（剑指 51）
TopK 三路: 快选 O(n) 期望 / 堆 O(n log k) 流式 / 桶 O(n) 范围小
```

> 🎯 **核心要点**：分治验收三件事——**① "拆-解-合"三步骤脱口而出**（判据：子问题独立 + 答案组合）；**② 主定理三情形会用**（归并 O(n log n)、树遍历 O(n)、二分 O(log n)）；**③ 三大应用支柱各有一题**（排序：912、选择：215、二分答案：875）。**分治与 DP 的分水岭是"子问题是否独立"**——这是面试对比题的必考点。快速选择子专题是 TopK 场景的深潜补充，与 03 题型全景互补。
