## 1. 核心概念

### 1.1 分治的三步

> 分治（Divide and Conquer）：**拆分 → 解决 → 合并**。把大问题拆成独立子问题，解决后合并答案。

```text
三步：
  ① Divide：拆分成更小的同类子问题
  ② Conquer：递归解决子问题（到最小规模直接解）
  ③ Combine：合并子问题的解

经典例子：
  归并排序：拆两半 → 各自排序 → 合并有序
  快速排序：分区 → 各自排序 → 无需合并（原地）
  二分查找：比较中间 → 只进一侧（无需合并）
  最大子序和：左半/右半/跨中点 取最大
```

### 1.2 识别信号

```text
"对半分 + 子问题独立" → 分治
"排序/最值/统计" 类问题 → 分治候选

⚠️ 三个条件（缺一不可）：
  ① 可拆分（对半/分组）
  ② 子问题独立（不重叠）
  ③ 可合并（合并代价可控）

不满足 ②（重叠）→ 动态规划（见第 4 节）
```

### 1.3 分治的隐藏难点

```text
⚠️ 跨边界问题（最常见的坑）：
  最优解可能"跨中点"（不完整落在某半）
  例：最大子序和跨中点 → 需要额外计算

处理：递归子问题 + 跨边界专门计算
  → 复杂度 = 递归层数 × 每层额外代价
```

### 2.2 53. 最大子序和（分治版）

```java
/**
 * LeetCode 53. 最大子序和（分治版 O(n log n)）
 * 答案在：左半 / 右半 / 跨中点 三选一
 */
public int maxSubArray(int[] nums) {
    return dc(nums, 0, nums.length - 1);
}

private int dc(int[] nums, int lo, int hi) {
    if (lo == hi) return nums[lo];       // 基线

    int mid = lo + (hi - lo) / 2;
    int leftMax = dc(nums, lo, mid);         // 左半
    int rightMax = dc(nums, mid + 1, hi);    // 右半

    // ⚠️ 跨中点的最大子序和（必须包含 mid 和 mid+1）
    int leftSum = Integer.MIN_VALUE, sum = 0;
    for (int i = mid; i >= lo; i--) {        // 向左扩展
        sum += nums[i];
        leftSum = Math.max(leftSum, sum);
    }
    int rightSum = Integer.MIN_VALUE;
    sum = 0;
    for (int i = mid + 1; i <= hi; i++) {    // 向右扩展
        sum += nums[i];
        rightSum = Math.max(rightSum, sum);
    }

    return Math.max(Math.max(leftMax, rightMax),
                    leftSum + rightSum);      // ③ 三选一
}
// 推演 [-2,1,-3,4]：
//   左半 [-2,1] → max(1)；右半 [-3,4] → max(4)
//   跨中点：左扩展 -2+1=-1... 右扩展 -3+4=1 → 跨 = -1+1=0
//   三选一 max(1, 4, 0) = 4 ✓
```

### 2.3 23. 合并 K 个有序链表（分治合并）

```java
/**
 * LeetCode 23. 合并 K 个升序链表（分治版）
 * 两两合并（mergeTwoLists 复用）→ 每轮数量减半
 */
public ListNode mergeKLists(ListNode[] lists) {
    if (lists == null || lists.length == 0) return null;
    return mergeRange(lists, 0, lists.length - 1);
}

private ListNode mergeRange(ListNode[] lists, int lo, int hi) {
    if (lo == hi) return lists[lo];          // 单个链表

    int mid = lo + (hi - lo) / 2;
    ListNode left = mergeRange(lists, lo, mid);      // 左半合并
    ListNode right = mergeRange(lists, mid + 1, hi); // 右半合并
    return mergeTwoLists(left, right);               // 合并（21 题）
}
// 复杂度 O(N log K)：每层合并总 O(N)，log K 层
// 对比堆解法 O(N log K)：分治空间 O(log K) 更省
```

## 3. 分治的复杂度分析

### 3.1 主定理（Master Theorem）

```text
T(n) = a·T(n/b) + f(n)
  a：子问题个数
  b：规模缩小倍数
  f(n)：拆分+合并代价

常见情形：
  归并：T(n) = 2T(n/2) + O(n) → O(n log n)
  二分：T(n) = T(n/2) + O(1) → O(log n)
  快排平均：T(n) = 2T(n/2) + O(n) → O(n log n)
  快选：T(n) = T(n/2) + O(n) → O(n)
  最大子序和：T(n) = 2T(n/2) + O(n) → O(n log n)

⚠️ 面试至少能推导归并：
  递归树 log n 层 × 每层合并 O(n)
```

### 3.2 递归树分析（归并）

```text
T(n) = 2T(n/2) + n
递归树：
  第 0 层：1 个问题，代价 n
  第 1 层：2 个问题，每代价 n/2 → 总 n
  第 2 层：4 个问题，每代价 n/4 → 总 n
  ...
  第 log n 层：n 个问题，每代价 1 → 总 n
  共 log n 层 × 每层 O(n) = O(n log n) ✓
```

### 3.3 跨边界问题对复杂度的影响

```text
最大子序和分治版：
  每层递归额外做跨中点扫描 O(n)（该层的区间长度）
  → 每层 O(n) × log n 层 = O(n log n)
  （对比 Kadane 的 O(n)：分治不是最优，但展示思想）

⚠️ 面试表达：
"分治版 O(n log n) 不是最优（Kadane O(n)），
 但展示分治思想——答案三选一（左/右/跨中点），
 跨中点需要额外扫描。"
```

## 4. 分治 vs 动态规划

### 4.1 对比表

| 维度 | 分治 | 动态规划 |
|------|:---:|:---:|
| 子问题关系 | **独立**（不重叠） | 重叠 |
| 重复计算 | 无 | 有（需缓存） |
| 代表 | 归并/快排 | 背包/序列 DP |
| 实现 | 递归 | 递归或迭代 |

```text
记忆：子问题独立 → 分治；子问题重叠 → DP
  归并排序的子问题互不相关 → 分治
  斐波那契的子问题大量重叠 → DP

⚠️ 常见混淆：分治 + 记忆化 = DP
  加了缓存的"分治"处理重叠子问题 → 就是 DP
  （记忆化是两者的桥梁）
```

### 4.2 分治 vs 递归 vs DFS

```text
递归：机制（函数调用自身）
分治：思想（拆-解-合，必须拆分+合并）
DFS：搜索策略（深度优先遍历）

关系：
  分治一定用递归实现
  DFS 可能不用分治（直接遍历）
  递归是三者共同的地基

⚠️ 面试表达：
"分治是'拆-解-合'思想，递归是实现机制。
 归并排序是分治典范——拆两半、递归排、
 合并有序。"
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```text
"最大子序和分治三选一：答案要么在左半、
 要么在右半、要么跨过中点。
 前两种递归解决，跨中点的从中间向两边
 扩展找最大。T(n)=2T(n/2)+O(n) → O(n log n)。
 跨中点扫描是分治的隐藏难点——最优解
 可能不完整落在某半。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 什么时候想到分治？ | 可对半拆分 + 子问题独立 + 合并简单 |
| 2 | 与 DP 的区别？ | 子问题独立 → 分治；重叠 → DP（加缓存） |
| 3 | 跨中点怎么处理？ | 递归子问题 + 跨边界专门计算 |
| 4 | 主定理？ | T(n) = aT(n/b) + f(n) 三情形 |
| 5 | 归并为什么 O(n log n)？ | log n 层 × 每层合并 O(n) |
| 6 | 分治 vs 递归？ | 分治是思想（拆解合），递归是机制 |
| 7 | 快选是分治吗？ | 是（但只递归一侧 → O(n)） |
| 8 | 什么时候分治不是最优？ | 有更优的专门算法（Kadane O(n)） |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 忘跨中点计算 | 漏最优解 | 专门扫描 |
| 子问题重叠还分治 | 指数爆炸 | 加缓存（变 DP） |
| 基线写错 | 无限递归 | lo == hi 返回 |
| 合并方向错 | 结果错 | 明确合并语义 |
| 边界计算错 | 越界 | mid 推导正确 |

> 🎯 **核心要点**：分治 = **拆-解-合**三步。识别信号："独立子问题、对半分"。跨边界计算（53）是常见隐藏难点；与 DP 的区分（子问题独立 vs 重叠）是面试必答；主定理的推导（归并 log n 层）是复杂度分析基本功。
