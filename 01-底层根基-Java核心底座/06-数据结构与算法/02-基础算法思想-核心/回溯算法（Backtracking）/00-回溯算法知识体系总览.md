## 1. 知识体系导图

```
回溯算法 (Backtracking)
│
├── 核心本质 ──────────────────────────────────────────────
│   ├── = DFS（深度优先搜索）+ 状态回退
│   ├── 核心套路：选择 → 递归 → 撤销选择
│   ├── 适用判断："找出所有可行方案" → 99% 是回溯
│   └── 决策树模型：宽度=选择列表，深度=递归层数
│
├── 回溯三要素 ────────────────────────────────────────────
│   ├── 路径 path（已做的选择）
│   ├── 选择列表（当前可选选项）
│   ├── 结束条件（何时收集结果）
│   └── 收集时务必拷贝 path（new ArrayList<>(path)）
│
├── 五大经典题型 ──────────────────────────────────────────
│   │
│   ├── 🟡 组合（30%+ 核心）
│   │   ├── 77. 组合（startIndex 控顺序）
│   │   ├── 39. 组合总和（可重复选 → 递归传 i）
│   │   ├── 40. 组合总和 II（排序 + 同层去重）
│   │   ├── 216. 组合总和 III
│   │   └── 17. 电话号码字母组合
│   │
│   ├── 🟡 排列（20%+ 去重是核心）
│   │   ├── 46. 全排列（used 数组标记）
│   │   └── 47. 全排列 II（同层去重 + used）
│   │
│   ├── 🟡 子集（15%+ 组合变种）
│   │   ├── 78. 子集（进入即收集）
│   │   ├── 90. 子集 II（排序 + 同层去重）
│   │   └── 491. 非递减子序列（Set 去重）
│   │
│   ├── 🟡 切割（10%+ 组合变形）
│   │   ├── 131. 分割回文串
│   │   └── 93. 复原 IP 地址（范围剪枝）
│   │
│   └── 🔴 棋盘/网格（15%+ 剪枝是关键）
│       ├── 51. N 皇后（行列对角线判重）
│       ├── 37. 解数独
│       └── 79. 单词搜索（回溯 + visited）
│
├── 去重技巧 ──────────────────────────────────────────────
│   ├── 必须先排序（同层去重的前提）
│   ├── 组合/子集去重：if (i > start && nums[i] == nums[i-1]) continue
│   ├── 排列去重：if (i > 0 && nums[i] == nums[i-1] && !used[i-1]) continue
│   └── 子序列去重：每层 Set 记录
│
├── 四大剪枝 ──────────────────────────────────────────────
│   ├── 边界剪枝（越界/负值/超限）
│   ├── 范围剪枝（剩余个数凑不齐）
│   ├── 单调剪枝（排序后 break 早停）
│   └── 对称性剪枝（等价状态只试一次）
│
└── Java 实战 ─────────────────────────────────────────────
    ├── 组合模板（startIndex 版）
    ├── 排列模板（used 版）
    ├── 子集模板（进入即收集版）
```

## 4. 核心概念速查

| 概念 | 一句话解释 | 典型例题 |
|------|-----------|------|
| **回溯** | DFS + 状态回退，穷举所有可行解 | 所有"列出方案"题 |
| **选择-递归-撤销** | path 加入 → 递归 → path 移除 | 回溯代码三步曲 |
| **决策树** | 宽度=选择列表，深度=递归层数，路径=一个解 | 全排列决策树 |
| **startIndex** | 组合中控制起始位置，防止回头重复 | 77. 组合 |
| **used 数组** | 排列中标记已选元素 | 46. 全排列 |
| **同层去重** | 排序后 `i>start && nums[i]==nums[i-1]` 跳过 | 40/90/47 |
| **path 拷贝** | `new ArrayList<>(path)` 再收集 | 所有回溯题收集处 |
| **剪枝** | 提前终止无效分支，减少搜索量 | 39/216/93 |
| **单调剪枝** | 排序后 `sum > target` 直接 break | 39. 组合总和 |
| **切割问题** | start 作为切割线，substring 为候选段 | 131/93 |
| **棋盘问题** | 行列/对角线判重，逐行放置 | 51. N 皇后 |

## 6. 复杂度速查表

| 问题 | 结果数量 | 时间复杂度 | 空间复杂度 | 关键技巧 |
|------|:---:|:---:|:---:|------|
| 组合 C(n,k) | C(n,k) | O(C(n,k)×k) | O(k) | startIndex |
| 子集 | 2ⁿ | O(2ⁿ) | O(n) | 进入即收集 |
| 全排列 | n! | O(n×n!) | O(n) | used 数组 |
| 组合总和 | 指数级 | O(指数) | O(target) | 排序+剪枝 |
| 切割回文串 | 2^(n-1) | O(n×2ⁿ) | O(n) | 区间切割 |
| N 皇后 | ≤ n! | O(n×n!) | O(n²) | 行列斜线判重 |
| 解数独 | 有限 | O(9^81) 剪枝后 | O(1) | 约束传播 |
| 单词搜索 | 1 | O(m×n×3^L) | O(L) | visited 回溯 |
