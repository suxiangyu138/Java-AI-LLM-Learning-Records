## 1. 组合问题的本质

### 1.1 什么是组合

```
组合：从 n 个元素中选出 k 个，不讲究顺序
  C(4,2) 从 [1,2,3,4] 选 2 个：
  [1,2] [1,3] [1,4] [2,3] [2,4] [3,4] —— 共 6 种
  [2,1] 和 [1,2] 是同一个组合！

关键：如何避免 [2,1] 这种重复？
  → startIndex：每次只从当前位置往后选，绝不回头
  → 保证组合内元素严格递增（下标递增）
```

### 1.2 组合 vs 排列

| 维度 | 组合 | 排列 |
|------|------|------|
| 顺序是否相关 | 否 | 是 |
| 防重手段 | startIndex（不回头） | used 数组（不重复选） |
| 每层选择起点 | `start` 起 | `0` 起（跳过 used） |
| 结果数量 | C(n,k) | P(n,k) |

## 2. 77. 组合：startIndex 入门

### 2.1 完整实现（含范围剪枝）

```java
/**
 * LeetCode 77. 组合
 * 给定 n 和 k，返回范围 [1, n] 中所有可能的 k 个数的组合。
 *
 * 模板要点：
 *   1. start 控制"不回头"——从 start 开始选，避免 [2,1] 与 [1,2] 重复
 *   2. 结束条件：path 长度 == k
 *   3. 范围剪枝：i 最多到 n-(k-path.size())+1，
 *      保证后面至少还有 k-path.size() 个数可填
 */
public List<List<Integer>> combine(int n, int k) {
    List<List<Integer>> res = new ArrayList<>();
    backtrack(n, k, 1, new ArrayList<>(), res);
    return res;
}

private void backtrack(int n, int k, int start,
                       List<Integer> path, List<List<Integer>> res) {
    if (path.size() == k) {                        // ① 收集
        res.add(new ArrayList<>(path));
        return;
    }

    // ② 范围剪枝：i ≤ n - (k - path.size()) + 1
    //    当前还差 k-path.size() 个数，i 最多只能到 n-差+1
    for (int i = start; i <= n - (k - path.size()) + 1; i++) {
        path.add(i);                               // ③ 做选择
        backtrack(n, k, i + 1, path, res);         // ④ 递归，不回头 → i+1
        path.remove(path.size() - 1);              // ⑤ 撤销
    }
}
```

### 2.2 范围剪枝推演：n=4, k=3

```
path 空时：差 3 个数 → i ≤ 4-3+1 = 2
  第一层只能选 1 或 2 —— 选 3 后面只剩 4，凑不齐 3 个！

path=[1] 时：差 2 个数 → i ≤ 4-2+1 = 3
  第二层可选 2、3（选 4 只剩 0 个数，凑不齐）

不剪枝：遍历所有 i 但白跑 → 递归到最后一层才发现凑不齐
剪枝后：直接从源头排除不可能的分支
```

## 3. 39. 组合总和：可重复选择

### 3.1 关键区别：递归传 i 而不是 i+1

```java
/**
 * LeetCode 39. 组合总和
 * 给你一个无重复元素的整数数组 candidates 和一个目标整数 target，
 * 找出所有和为目标值的组合。candidates 中的数字可以无限制重复选取。
 *
 * 与 77 的唯一区别：
 *   77 不能重复选同一元素 → 递归传 i+1
 *   39 可以重复选当前元素 → 递归传 i（起点不变，但本轮用过）
 */
public List<List<Integer>> combinationSum(int[] candidates, int target) {
    List<List<Integer>> res = new ArrayList<>();
    Arrays.sort(candidates);                     // 排序 → 支持单调剪枝
    backtrack(candidates, target, 0, new ArrayList<>(), res);
    return res;
}

private void backtrack(int[] nums, int remain, int start,
                       List<Integer> path, List<List<Integer>> res) {
    if (remain == 0) {                           // ① 恰好凑满
        res.add(new ArrayList<>(path));
        return;
    }

    for (int i = start; i < nums.length; i++) {
        // ② 单调剪枝：排序后，nums[i] 已经大于剩余值，
        //    后面的元素更大，不可能凑齐 → break（不是 continue！）
        if (nums[i] > remain) break;

        path.add(nums[i]);                       // ③ 选择
        backtrack(nums, remain - nums[i], i, path, res);  // ④ 传 i → 可重复选
        path.remove(path.size() - 1);            // ⑤ 撤销
    }
}
```

### 3.2 为什么传 i 不会产生重复组合？

```
candidates = [2, 3, 6, 7], target = 7

路径 [2,2,3] 的产生过程：
  选 2（start=0）→ 选 2（start=0）→ 选 3（start=1）✓

为什么不会产生 [3,2,2]？
  选 3 时 start=1，后续只能选 3/6/7，永远选不到 2
  → 组合内下标单调不减 → 不会重复

总结：可重复选 = 传 i；不可重复选 = 传 i+1
     这是 39 与 77 唯一的模板差异
```

## 4. 40. 组合总和 II：排序 + 去重

### 4.1 同层去重的原理

```java
/**
 * LeetCode 40. 组合总和 II
 * 与 39 的区别：candidates 含重复元素，且每个数字在每个组合中只能使用一次。
 *
 * 去重核心：同层去重
 *   if (i > start && nums[i] == nums[i-1]) continue;
 *
 * 为什么？nums 已排序，相同值相邻。
 *   同层（同一个 for 循环）中，nums[i] 与 nums[i-1] 相等时，
 *   选 nums[i] 产生的所有组合 与 选 nums[i-1] 产生的完全相同 → 跳过
 *   （注意：i > start 才跳过 —— 同一条路径内允许重复值，如 [1,1,2]）
 */
public List<List<Integer>> combinationSum2(int[] candidates, int target) {
    List<List<Integer>> res = new ArrayList<>();
    Arrays.sort(candidates);                        // ⚠️ 去重前提：必须排序
    backtrack(candidates, target, 0, new ArrayList<>(), res);
    return res;
}

private void backtrack(int[] nums, int remain, int start,
                       List<Integer> path, List<List<Integer>> res) {
    if (remain == 0) {
        res.add(new ArrayList<>(path));
        return;
    }

    for (int i = start; i < nums.length; i++) {
        if (nums[i] > remain) break;                // 单调剪枝

        // ⚠️ 同层去重：跳过本层用过的相同值
        if (i > start && nums[i] == nums[i - 1]) continue;

        path.add(nums[i]);
        backtrack(nums, remain - nums[i], i + 1, path, res);  // 不可重复选 → i+1
        path.remove(path.size() - 1);
    }
}
```

### 4.2 同层去重 vs 同路径去重

```
nums = [1, 1, 2], target = 3

❌ 不做去重：会输出两份 [1,2]（第一个 1 或第二个 1）
✅ 同层去重：i > start 时跳过重复 → 只输出一份 [1,2]

⚠️ 为什么不能无脑跳过所有相同值？
  同路径内 [1,1,...] 是合法的（两个位置用两个 1）
  所以条件必须是 i > start（同层）而不是 i > 0（同路径）
  例：nums=[1,1,2,3], target=6 → [1,1,2,2]... 同路径的 1 需要保留
```

## 5. 216. 组合总和 III：多重约束

### 5.1 完整实现

```java
/**
 * LeetCode 216. 组合总和 III
 * 找出所有相加之和为 n 的 k 个数的组合，且满足：
 *   - 只使用数字 1 到 9
 *   - 每个数字最多使用一次
 *
 * 约束三重：个数 = k、总和 = n、数字范围 [1,9] 不重复
 */
public List<List<Integer>> combinationSum3(int k, int n) {
    List<List<Integer>> res = new ArrayList<>();
    backtrack(k, n, 1, new ArrayList<>(), res);
    return res;
}

private void backtrack(int k, int remain, int start,
                       List<Integer> path, List<List<Integer>> res) {
    // 剪枝 1：剩余个数 > 可用的数（[start,9] 区间不够填）
    if (path.size() + (10 - start) < k) return;

    if (path.size() == k) {                    // 个数达标
        if (remain == 0)                       // 且总和达标
            res.add(new ArrayList<>(path));
        return;
    }

    for (int i = start; i <= 9; i++) {
        if (i > remain) break;                 // 剪枝 2：单调剪枝

        path.add(i);
        backtrack(k, remain - i, i + 1, path, res);
        path.remove(path.size() - 1);
    }
}
```

### 5.2 三类组合题对比速查

| 题目 | 可重复选 | 元素重复 | 额外约束 | 递归传参 | 去重 |
|:---:|:---:|:---:|------|:---:|------|
| 77. 组合 | ❌ | — | 个数 = k | `i+1` | — |
| 39. 组合总和 | ✅ | 无重复 | 总和 = target | `i` | — |
| 40. 组合总和 II | ❌ | 有重复 | 总和 = target | `i+1` | 排序+同层去重 |
| 216. 组合总和 III | ❌ | — | 个数=k + 总和=n | `i+1` | — |

## 6. 17. 电话号码的字母组合

### 6.1 完整实现

```java
/**
 * LeetCode 17. 电话号码的字母组合
 * 2-9 数字对应字母映射（电话键盘），给定 digits，返回所有可能的字母组合。
 *
 * 特殊点：这是"多串"组合——每层的选择列表来自不同的字符串
 * 所以用 index 标记当前处理哪个数字，而不是 startIndex
 */
public List<String> letterCombinations(String digits) {
    List<String> res = new ArrayList<>();
    if (digits.isEmpty()) return res;

    String[] map = {"", "", "abc", "def", "ghi", "jkl",
                    "mno", "pqrs", "tuv", "wxyz"};
    backtrack(digits, map, 0, new StringBuilder(), res);
    return res;
}

private void backtrack(String digits, String[] map, int index,
                       StringBuilder path, List<String> res) {
    if (index == digits.length()) {            // 处理完所有数字
        res.add(path.toString());              // StringBuilder 也要拷贝！
        return;
    }

    String letters = map[digits.charAt(index) - '0'];
    for (char c : letters.toCharArray()) {
        path.append(c);                        // 做选择
        backtrack(digits, map, index + 1, path, res);
        path.deleteCharAt(path.length() - 1);  // 撤销
    }
}
// 输入 "23" → ["ad","ae","af","bd","be","bf","cd","ce","cf"]
```

### 6.2 为什么用 index 而不用 start？

```
组合问题：选择列表来自同一个数组 → start 防回头
本题：每层选择列表来自不同字符串 → 用 index 定位当前字符串
两者本质都是"当前层从哪里开始选"，只是场景不同
```

## 7. 剪枝技巧总结

### 7.1 四大剪枝速查

| 剪枝类型 | 代码形态 | 适用场景 | 示例 |
|------|------|------|------|
| **边界剪枝** | `if (remain < 0) return` | 总和超限 | 39/40/216 |
| **范围剪枝** | `i <= n-(k-size)+1` | 剩余个数凑不齐 | 77/216 |
| **单调剪枝** | `if (nums[i] > remain) break` | 排序后提前终止 | 39/40 |
| **对称去重** | `if (i>start && nums[i]==nums[i-1]) continue` | 重复元素 | 40 |

### 7.2 剪枝写在"选择前"还是"选择后"？

```
✅ 推荐：写在 for 循环内、做选择之前
   for (int i = start; i < n; i++) {
       if (nums[i] > remain) break;   // 先判断再选
       path.add(nums[i]); ...
   }

❌ 不推荐：进入递归后再判断
   backtrack(...) {
       if (remain < 0) return;        // 递归入口判断
       ...
   }
   缺点：递归调用已经发生了，白白消耗栈帧；剪枝越早越好
```

### 7.3 面试加分：主动讲剪枝

```
"这道题我做了两个剪枝：
 1. 单调剪枝——排序后一旦 nums[i] > remain 就 break，
    因为后面的元素更大，不可能再凑齐（continue 会浪费剩余循环）；
 2. 范围剪枝——组合 77 中 i 上界 = n-(k-path.size())+1，
    保证当前分支至少还有足够的数可选。
 剪枝不改变最坏复杂度，但面试题的剪枝常常是关键扣分点。"
```

> 🎯 **核心要点**：组合问题是回溯最核心的题型。**startIndex 防回头、可重复选传 i 否则传 i+1、排序+同层去重、单调剪枝用 break**——这四件事是组合家族的全部差异。17 题用 index 处理多串场景。把 77/39/40/216 四题吃透，组合类题目全部通杀。
