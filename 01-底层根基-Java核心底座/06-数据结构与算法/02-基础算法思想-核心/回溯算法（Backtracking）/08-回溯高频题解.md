## 1. 46/47. 全排列 I & II

### 1.1 46. 全排列（排列模板）

```java
/**
 * LeetCode 46. 全排列
 * used 数组 + 从 0 遍历（顺序相关）
 */
public List<List<Integer>> permute(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    backtrack(nums, new boolean[nums.length],
              new ArrayList<>(), res);
    return res;
}

private void backtrack(int[] nums, boolean[] used,
                       List<Integer> path, List<List<Integer>> res) {
    if (path.size() == nums.length) {
        res.add(new ArrayList<>(path));
        return;
    }
    for (int i = 0; i < nums.length; i++) {      // ⚠️ 从 0 开始！
        if (used[i]) continue;
        used[i] = true;
        path.add(nums[i]);
        backtrack(nums, used, path, res);
        path.remove(path.size() - 1);
        used[i] = false;                         // ⚠️ 标记也要撤销
    }
}
// 推演 [1,2,3]：决策树 3! = 6 个叶子 ✓
// ⚠️ 与组合的区别：startIndex（不回头）vs used（回头但不重复）
```

### 1.2 47. 全排列 II（去重）

```java
/**
 * LeetCode 47. 全排列 II（26 届秋招手撕重点）
 * 排列去重：i>0 && nums[i]==nums[i-1] && !used[i-1]
 */
public List<List<Integer>> permuteUnique(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    Arrays.sort(nums);                          // ⚠️ 去重前提
    boolean[] used = new boolean[nums.length];
    backtrack(nums, used, new ArrayList<>(), res);
    return res;
}

private void backtrack(int[] nums, boolean[] used,
                       List<Integer> path, List<List<Integer>> res) {
    if (path.size() == nums.length) {
        res.add(new ArrayList<>(path));
        return;
    }
    for (int i = 0; i < nums.length; i++) {
        if (used[i]) continue;
        // ⚠️ 核心：前一个相同值未被使用 → 本层已展开过 → 跳过
        if (i > 0 && nums[i] == nums[i - 1] && !used[i - 1]) continue;

        used[i] = true;
        path.add(nums[i]);
        backtrack(nums, used, path, res);
        path.remove(path.size() - 1);
        used[i] = false;
    }
}
// 推演 [1,1,2]：去重后 3! / 2! = 3 个结果 ✓
// ⚠️ 面试必讲："!used[i-1] 区分同层（跳过）
//   与同路径（保留 [1,1,...]）"
```

## 2. 77. 组合

### 2.1 完整实现（含范围剪枝）

```java
/**
 * LeetCode 77. 组合
 * startIndex 防回头 + 范围剪枝
 */
public List<List<Integer>> combine(int n, int k) {
    List<List<Integer>> res = new ArrayList<>();
    backtrack(n, k, 1, new ArrayList<>(), res);
    return res;
}

private void backtrack(int n, int k, int start,
                       List<Integer> path, List<List<Integer>> res) {
    if (path.size() == k) {
        res.add(new ArrayList<>(path));
        return;
    }

    // ⚠️ 范围剪枝：i ≤ n-(k-size)+1（保证能凑满 k 个）
    for (int i = start; i <= n - (k - path.size()) + 1; i++) {
        path.add(i);
        backtrack(n, k, i + 1, path, res);
        path.remove(path.size() - 1);
    }
}
// 推演 n=4, k=3：
//   第一层 i ≤ 4-(3-0)+1 = 2（只能选 1 或 2）
//   选 3 后面只剩 4，凑不齐 3 个 → 源头排除！
// 结果：6 个组合 ✓
// ⚠️ 面试必讲："范围剪枝从源头排除不可能分支"
```

## 3. 39/40. 组合总和 I & II

### 3.1 39. 组合总和（可重复选）

```java
/**
 * LeetCode 39. 组合总和
 * 可重复选 → 递归传 i（而非 i+1）
 * 排序 + 单调剪枝（break）
 */
public List<List<Integer>> combinationSum(int[] candidates, int target) {
    List<List<Integer>> res = new ArrayList<>();
    Arrays.sort(candidates);                    // 单调剪枝前提

    backtrack(candidates, target, 0, new ArrayList<>(), res);
    return res;
}

private void backtrack(int[] nums, int remain, int start,
                       List<Integer> path, List<List<Integer>> res) {
    if (remain == 0) {
        res.add(new ArrayList<>(path));
        return;
    }

    for (int i = start; i < nums.length; i++) {
        if (nums[i] > remain) break;            // ⚠️ 单调剪枝（break！）

        path.add(nums[i]);
        backtrack(nums, remain - nums[i], i, path, res);  // ⚠️ 传 i
        path.remove(path.size() - 1);
    }
}
// 推演 [2,3,6,7], target=7：
//   选 2 → 选 2 → 选 3 → [2,2,3] ✓
//   选 7 → [7] ✓
// ⚠️ 为什么传 i 不产生重复？
//   组合内下标单调不减 → 不会回头选更小的
// ⚠️ 单调剪枝为什么 break？
//   排序后 nums[i] > remain → 后面更大必然也超 → 终止循环
```

### 3.2 40. 组合总和 II（不可重复 + 去重）

```java
/**
 * LeetCode 40. 组合总和 II
 * 含重复元素 + 每个数只能用一次
 * = 39 的模板 + i+1（不可重复）+ 同层去重
 */
public List<List<Integer>> combinationSum2(int[] candidates, int target) {
    List<List<Integer>> res = new ArrayList<>();
    Arrays.sort(candidates);
    backtrack(candidates, target, 0, new ArrayList<>(), res);
    return res;
}

private void backtrack(int[] nums, int remain, int start,
                       List<Integer> path, List<List<Integer>> res) {
    if (remain == 0) {
        res.add(new ArrayList<>(path));
        return;
    }

    for (int i = start; i < nums.length; i++) {
        if (nums[i] > remain) break;            // 单调剪枝

        // ⚠️ 同层去重（i>start 而非 i>0）
        if (i > start && nums[i] == nums[i - 1]) continue;

        path.add(nums[i]);
        backtrack(nums, remain - nums[i], i + 1, path, res);  // ⚠️ i+1
        path.remove(path.size() - 1);
    }
}
// 推演 [10,1,2,7,6,1,5], target=8：
//   排序 [1,1,2,5,6,7,10] → 去重后结果不重复 ✓
// ⚠️ 39 vs 40 的三处差异：
//   ① 递归传 i vs i+1
//   ② 无去重 vs 同层去重
//   ③ 其余完全相同（同模板）
```

## 4. 78/90. 子集 I & II

### 4.1 78. 子集（进入即收集）

```java
/**
 * LeetCode 78. 子集
 * ⚠️ 与组合的唯一区别：每个节点都是答案
 */
public List<List<Integer>> subsets(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    backtrack(nums, 0, new ArrayList<>(), res);
    return res;
}

private void backtrack(int[] nums, int start,
                       List<Integer> path, List<List<Integer>> res) {
    res.add(new ArrayList<>(path));             // ⚠️ 进入即收集！

    for (int i = start; i < nums.length; i++) {
        path.add(nums[i]);
        backtrack(nums, i + 1, path, res);
        path.remove(path.size() - 1);
    }
}
// 决策树节点数 = 2³ = 8 = 子集数 ✓
// 推演 [1,2,3]：
//   [] → [1],[2],[3] → [1,2],[1,3],[2,3] → [1,2,3] ✓
// ⚠️ 记忆："子集进入即收集，组合满足才收集"
```

## 5. 17. 电话号码的字母组合

### 5.1 完整实现

```java
/**
 * LeetCode 17. 电话号码的字母组合
 * ⚠️ 多串组合：每层选择列表来自不同字符串
 * → 用 index 定位当前数字（而非 startIndex）
 */
public List<String> letterCombinations(String digits) {
    List<String> res = new ArrayList<>();
    if (digits.isEmpty()) return res;

    String[] map = {"", "", "abc", "def", "ghi", "jkl",
                    "mno", "pqrs", "tuv", "wxyz"};
    backtrack(digits, map, 0, new StringBuilder(), res);
    return res;
}

private void backtrack(String digits, String[] map, int index,
                       StringBuilder path, List<String> res) {
    if (index == digits.length()) {
        res.add(path.toString());               // ⚠️ StringBuilder 拷贝
        return;
    }

    String letters = map[digits.charAt(index) - '0'];
    for (char c : letters.toCharArray()) {
        path.append(c);
        backtrack(digits, map, index + 1, path, res);
        path.deleteCharAt(path.length() - 1);   // ⚠️ 撤销
    }
}
// 输入 "23" → ["ad","ae","af","bd","be","bf","cd","ce","cf"]
// ⚠️ index vs startIndex：
//   组合：同一数组 → start 防回头
//   本题：不同字符串 → index 定位当前串
// ⚠️ StringBuilder 撤销：deleteCharAt（非 removeLast）
```

## 6. 131. 分割回文串

### 6.1 完整实现

```java
/**
 * LeetCode 131. 分割回文串
 * 切割 = 组合变形：start 是"切割线"位置
 */
public List<List<String>> partition(String s) {
    List<List<String>> res = new ArrayList<>();
    backtrack(s, 0, new ArrayList<>(), res);
    return res;
}

private void backtrack(String s, int start,
                       List<String> path, List<List<String>> res) {
    if (start == s.length()) {                  // ⚠️ 切完整个串
        res.add(new ArrayList<>(path));
        return;
    }

    for (int i = start; i < s.length(); i++) {
        String segment = s.substring(start, i + 1);
        if (!isPalindrome(segment)) continue;   // 剪枝：非回文段跳过

        path.add(segment);
        backtrack(s, i + 1, path, res);         // 从 i+1 继续切
        path.remove(path.size() - 1);
    }
}

private boolean isPalindrome(String s) {
    int lo = 0, hi = s.length() - 1;
    while (lo < hi) {
        if (s.charAt(lo++) != s.charAt(hi--)) return false;
    }
    return true;
}
// 推演 "aab"：a|a|b / a|ab ✗ / aa|b → [[a,a,b],[aa,b]] ✓
// ⚠️ 切割与组合的同构：
//   组合：path.add(nums[i]) → 选一个元素
//   切割：path.add(substring(start, i+1)) → 切下一段
//   优化：预处理回文表（isPal[i][j]）→ O(1) 判断
```

## 7. 93. 复原 IP 地址

### 7.1 完整实现（26 届秋招真题）

```java
/**
 * LeetCode 93. 复原 IP 地址（26 届秋招手撕）
 * 三重约束：4 段 / 每段 0-255 / 无前导零
 */
public List<String> restoreIpAddresses(String s) {
    List<String> res = new ArrayList<>();
    if (s.length() < 4 || s.length() > 12) return res;  // 总长剪枝

    backtrack(s, 0, 0, new StringBuilder(), res);
    return res;
}

private void backtrack(String s, int start, int segments,
                       StringBuilder path, List<String> res) {
    // 剪枝 1：段数到 4 但还没用完字符 → 非法
    if (segments == 4) {
        if (start == s.length()) res.add(path.toString());
        return;
    }
    // 剪枝 2：剩余字符填不满/超出剩余段数
    int remaining = s.length() - start;
    int need = 4 - segments;
    if (remaining < need || remaining > need * 3) return;

    for (int i = start; i < start + 3 && i < s.length(); i++) {
        String segment = s.substring(start, i + 1);

        // 剪枝 3：前导零（"01" 非法，"0" 合法）
        if (segment.length() > 1 && segment.charAt(0) == '0') break;
        // 剪枝 4：数值 > 255（单调 break）
        if (Integer.parseInt(segment) > 255) break;

        int lenBefore = path.length();
        if (segments > 0) path.append('.');    // 加分隔点
        path.append(segment);

        backtrack(s, i + 1, segments + 1, path, res);

        path.setLength(lenBefore);             // ⚠️ 撤销（回退长度）
    }
}
// 输入 "25525511135" → ["255.255.11.135","255.255.111.35"]
// ⚠️ 四重剪枝是本题灵魂（面试必讲）
```

## 8. 51. N 皇后

### 8.1 完整实现

```java
/**
 * LeetCode 51. N 皇后
 * 按行放置 + 三数组判冲突（行列对角线）
 */
public List<List<String>> solveNQueens(int n) {
    List<List<String>> res = new ArrayList<>();
    boolean[] col = new boolean[n];
    boolean[] diag1 = new boolean[2 * n - 1];   // row+col
    boolean[] diag2 = new boolean[2 * n - 1];   // row-col+n-1
    char[][] board = new char[n][n];
    for (char[] row : board) Arrays.fill(row, '.');

    backtrack(n, 0, col, diag1, diag2, board, res);
    return res;
}

private void backtrack(int n, int row,
                       boolean[] col, boolean[] diag1, boolean[] diag2,
                       char[][] board, List<List<String>> res) {
    if (row == n) {                             // 所有行放好
        List<String> list = new ArrayList<>();
        for (char[] r : board) list.add(new String(r));
        res.add(list);
        return;
    }

    for (int c = 0; c < n; c++) {
        int d1 = row + c;                       // 主对角线编号
        int d2 = row - c + n - 1;               // 副对角线编号
        if (col[c] || diag1[d1] || diag2[d2]) continue;  // 冲突剪枝

        board[row][c] = 'Q';
        col[c] = diag1[d1] = diag2[d2] = true;
        backtrack(n, row + 1, col, diag1, diag2, board, res);
        board[row][c] = '.';                    // 撤销
        col[c] = diag1[d1] = diag2[d2] = false;
    }
}
// ⚠️ 对角线编号原理：
//   主对角线 /：row+col 为常数
//   副对角线 \：row-col 为常数（+n-1 防负）
// → O(1) 判冲突（取代 O(n) 扫描）
// 复杂度：O(n! × n)（排列剪枝后）
```

## 9. 79. 单词搜索

### 9.1 完整实现（回溯 + visited）

```java
/**
 * LeetCode 79. 单词搜索
 * 网格路径搜索 → 回溯（必须恢复标记）
 */
public boolean exist(char[][] board, String word) {
    for (int i = 0; i < board.length; i++) {
        for (int j = 0; j < board[0].length; j++) {
            if (dfs(board, word, 0, i, j)) return true;   // 任一起点
        }
    }
    return false;
}

private boolean dfs(char[][] board, String word, int index,
                    int i, int j) {
    // ① 匹配完整个单词 → 找到
    if (index == word.length()) return true;

    // ② 越界 / 字符不匹配
    if (i < 0 || i >= board.length || j < 0 || j >= board[0].length) {
        return false;
    }
    if (board[i][j] != word.charAt(index)) return false;

    // ③ 标记（原地用 '\0' 代替 visited）
    char temp = board[i][j];
    board[i][j] = '\0';

    // ④ 四方向探索（短路或：找到即返回）
    boolean found = dfs(board, word, index + 1, i + 1, j)
                 || dfs(board, word, index + 1, i - 1, j)
                 || dfs(board, word, index + 1, i, j + 1)
                 || dfs(board, word, index + 1, i, j - 1);

    // ⑤ ⚠️ 撤销（回溯的灵魂！探索其他方向）
    board[i][j] = temp;

    return found;
}
// 复杂度 O(mn × 3^L)（L = 单词长度，剪枝后实际快）
// ⚠️ 沉岛 vs 回溯：
//   计数/连通 → 沉岛（不用恢复）
//   路径搜索 → 回溯（必须恢复）
//   "需要恢复吗？"是网格 DFS 的第一问
```

## 10. 22. 生成括号

### 10.1 完整实现

```java
/**
 * LeetCode 22. 生成括号
 * 约束：任意前缀中 '(' 数 ≥ ')' 数
 * 用左右计数控制（无需回溯路径检查）
 */
public List<String> generateParenthesis(int n) {
    List<String> res = new ArrayList<>();
    backtrack(n, 0, 0, new StringBuilder(), res);
    return res;
}

private void backtrack(int n, int open, int close,
                       StringBuilder path, List<String> res) {
    if (path.length() == 2 * n) {              // 长度达标
        res.add(path.toString());
        return;
    }

    if (open < n) {                            // 还能加左括号
        path.append('(');
        backtrack(n, open + 1, close, path, res);
        path.deleteCharAt(path.length() - 1);
    }
    if (close < open) {                        // ⚠️ 右括号 < 左括号才能加
        path.append(')');
        backtrack(n, open, close + 1, path, res);
        path.deleteCharAt(path.length() - 1);
    }
}
// n=2 → ["(())","()()"] ✓
// ⚠️ 剪枝的两种写法：
//   ① 递归入口判断（close > open → return）
//   ② 选择前判断（close < open 才加）★ 推荐（省递归）
// ⚠️ 结果数 = 卡特兰数 C(2n,n)/(n+1)
```

## 11. 216. 组合总和 III

### 11.1 完整实现（26 届秋招真题）

```java
/**
 * LeetCode 216. 组合总和 III（26 届秋招手撕）
 * 1-9 选 k 个数和为 n（每个数一次）
 * 三重约束：个数=k / 总和=n / 数字 1-9 不重复
 */
public List<List<Integer>> combinationSum3(int k, int n) {
    List<List<Integer>> res = new ArrayList<>();
    backtrack(k, n, 1, new ArrayList<>(), res);
    return res;
}

private void backtrack(int k, int remain, int start,
                       List<Integer> path, List<List<Integer>> res) {
    // 剪枝 1：剩余个数 > 可用数（[start,9] 不够填）
    if (path.size() + (10 - start) < k) return;

    if (path.size() == k) {                    // 个数达标
        if (remain == 0)                       // 且总和达标
            res.add(new ArrayList<>(path));
        return;
    }

    for (int i = start; i <= 9; i++) {
        if (i > remain) break;                 // 剪枝 2：单调剪枝

        path.add(i);
        backtrack(k, remain - i, i + 1, path, res);
        path.remove(path.size() - 1);
    }
}
// 推演 k=3, n=7 → [[1,2,4]] ✓
// ⚠️ 组合家族四题对比：
//   77：个数=k（范围剪枝）
//   39：可重复选（传 i）
//   40：去重（i>start）
//   216：个数+总和双约束
```

### 12.2 回溯识别三步

```
① 识别题型："所有方案" → 回溯
② 选模板：startIndex / used / 即收集 / 切割 / 棋盘
③ 加细节：去重（排序+同层）/ 剪枝（范围/单调）

⚠️ 面试手写顺序：
  说三要素（path/选择/结束）→ 套模板 → 加去重剪枝
```

### 12.3 面试话术模板

```
"这是【组合/排列/子集/切割/棋盘】回溯：
 三要素是【...】。
 模板用【startIndex/used】因为【顺序相关/无关】。
 去重：【排序 + 同层】/【!used】/【Set】。
 剪枝：【范围/单调/冲突】（写在选择前）。
 复杂度由输出规模决定：【2ⁿ/n!/C(n,k)】。"
```

> 🎯 **核心要点**：十二道母题覆盖回溯全题型——**排列**（46/47）、**组合**（77/39/40/216）、**子集**（78/90）、**多串**（17）、**切割**（131/93）、**棋盘**（51/79）、**计数约束**（22）。每类的"关键细节"（去重机制/剪枝位置/撤销方式）是面试得分点；"识别题型 → 选模板 → 加细节"是应对新题的标准路径。
