## 1. 为什么二叉树天生适合递归

二叉树的结构本身就是递归定义：

```text
一棵二叉树 = 根节点 + 左子树（二叉树）+ 右子树（二叉树）
空（null）是它的基线条件
```

```java
class TreeNode {
    int val;
    TreeNode left;    // 左子树：又是一棵二叉树
    TreeNode right;   // 右子树：又是一棵二叉树
}
```

**"结构自相似"是递归的天然信号**（呼应 08 精要 1.2）：对子树的问题 = 对整棵树的问题缩小规模——直接套递归三要素：

| 三要素 | 树的对应 |
|--------|---------|
| 基线条件 | `node == null`（空树） |
| 递推关系 | 问题分解为 left 子问题 + right 子问题 |
| 收敛性 | 子树规模严格小于当前树 |

> 🎯 **树递归的复杂度铁律**：**时间 O(n)**（每个节点恰好访问一次）、**空间 O(h)**（递归深度 = 树高）。这两个数面试必答，且要补充"最坏 h = n（退化为链）→ 栈溢出风险"。

## 2. 树递归三问框架

写任何树递归前，先自问三句（对应 03 文件的返回值语义设计）：

```text
① 终止条件是什么？        → 空节点？叶子节点？（两种常见基线）
② 本层返回什么？          → 子树高度？是否满足条件？拼接后的结构？
③ 本层要做什么？          → 返回值如何与左右子树的返回值组合？
```

### 2.1 基线条件的两种写法

```java
// 写法 A：空节点基线（最通用，能处理所有空指针）
int maxDepthA(TreeNode root) {
    if (root == null) return 0;                          // 空树高度 0
    return Math.max(maxDepthA(root.left), maxDepthA(root.right)) + 1;
}

// 写法 B：叶子基线（某些题更自然，如路径收集）
int countLeaves(TreeNode root) {
    if (root == null) return 0;
    if (root.left == null && root.right == null) return 1;  // 叶子
    return countLeaves(root.left) + countLeaves(root.right);
}
```

> ⚠️ **111 最小深度的经典坑**（02 文件已详解）：直接 `min(l, r) + 1` 会把"只有单子树"的节点错误地算作深度 1——必须区分"空子树不能算深度"。**基线条件不只是"空就返回"——要问"空在这里的语义是什么"**。

### 2.2 三问框架应用示例（100 相同的树）

```java
// 100 相同的树：三问
// ① 终止: 双空 → true；一空一非空 → false
// ② 返回: 两子树是否相同（boolean）
// ③ 本层: val 相等 && 左相同 && 右相同
public boolean isSameTree(TreeNode p, TreeNode q) {
    if (p == null && q == null) return true;      // 双空
    if (p == null || q == null) return false;     // 单空
    return p.val == q.val
        && isSameTree(p.left, q.left)
        && isSameTree(p.right, q.right);
}
```

## 3. 前中后序遍历三模板

三种遍历只移动"处理"的位置（08 精要 2.3 已给雏形，此处给完整版 + 迭代对照）：

```java
// 144 前序遍历: 根 → 左 → 右
public List<Integer> preorderTraversal(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    preorder(root, res);
    return res;
}
void preorder(TreeNode node, List<Integer> res) {
    if (node == null) return;
    res.add(node.val);                 // 处理：递阶段
    preorder(node.left, res);
    preorder(node.right, res);
}

// 94 中序遍历: 左 → 根 → 右
void inorder(TreeNode node, List<Integer> res) {
    if (node == null) return;
    inorder(node.left, res);
    res.add(node.val);                 // 处理：夹中间
    inorder(node.right, res);
}

// 145 后序遍历: 左 → 右 → 根
void postorder(TreeNode node, List<Integer> res) {
    if (node == null) return;
    postorder(node.left, res);
    postorder(node.right, res);
    res.add(node.val);                 // 处理：归阶段
}
```

**记忆口诀**："**前中后指根的位置**"——根处理在前 → 前序；在中 → 中序；在后 → 后序。复杂度均为 O(n) 时间 / O(h) 空间。

> 🎯 面试升级点：**"中序遍历的迭代版（左探-回溯-右转）"**是递归转迭代的必背考点（08 精要 4.2 已给）。前序迭代 = 栈直接压（右先左后）；后序迭代 = 前序变形反转或双栈。三种遍历都能用显式栈模拟——**"递归隐式用调用栈，迭代显式用 Deque"**这句是标准表达。

## 4. N 叉树遍历：模板的推广

**题**：N 叉树（每个节点有 children 列表）的前序/后序（589/590）。

```java
class Node {
    int val;
    List<Node> children;      // 多个孩子
}

// 589 N 叉树前序: 把"左、右两次调用"推广为"遍历 children"
void preorderN(Node node, List<Integer> res) {
    if (node == null) return;
    res.add(node.val);                       // 处理：递阶段
    for (Node child : node.children) {       // 与二叉树唯一的差别
        preorderN(child, res);
    }
}
```

**推广要点**：

```text
二叉树: 递归调用固定两次（left、right）
N 叉树: 递归调用在 for 循环里（children）
骨架完全一致 —— "递归模板与孩子数量无关"
```

> 💡 429 N 叉树层序同理（层序是 BFS，不用递归）；590 N 叉树后序把 add 移到循环后。**会写二叉树遍历 = 会写 N 叉树遍历**，差的只是一个 for。

## 5. 三种遍历的应用场景

### 5.1 场景总表（背）

| 遍历 | 输出特征 | 经典应用 | 代表题 |
|------|---------|---------|--------|
| 前序 | 根先出现 | 序列化、构建树、路径前缀 | 297 序列化、105 重建 |
| 中序 | **BST 升序** | 排序输出、BST 验证 | 98 验证 BST、230 第 k 小 |
| 后序 | 子树结果先就绪 | 高度/和/最大路径聚合 | 104、124、543 直径 |

```text
选序口诀（呼应 03 文件）:
  要子树答案 → 后序（聚合）
  传父层信息 → 前序（携带）
  有序输出   → 中序（BST）
```

### 5.2 后序聚合的典型：543 二叉树直径

```java
// 543 直径（经过根的最长路径）：后序聚合 + 全局变量
int maxD = 0;
public int diameterOfBinaryTree(TreeNode root) {
    height(root);
    return maxD;
}
int height(TreeNode node) {
    if (node == null) return 0;
    int l = height(node.left), r = height(node.right);   // 先问子树
    maxD = Math.max(maxD, l + r);                        // 归阶段：经过本节点的最长路径
    return Math.max(l, r) + 1;                           // 返回高度给父层
}
```

> 🎯 **"后序聚合 + 全局答案"是树递归最高频的组合模式**（124 最大路径和、687 最长同值路径同理，02 文件有题解）：**子树返回"单边最优"，全局变量记录"经过本节点的最优"**——一个函数干两件事（返回给父层 + 更新全局），这是树递归的进阶核心。

## 6. 树递归经典应用：对称、路径与祖先

### 6.1 101 对称二叉树

```java
// 101 对称: 双树递归（比较两棵镜像树）
public boolean isSymmetric(TreeNode root) {
    return isMirror(root.left, root.right);
}
boolean isMirror(TreeNode a, TreeNode b) {
    if (a == null && b == null) return true;
    if (a == null || b == null) return false;
    return a.val == b.val
        && isMirror(a.left, b.right)     // 镜像: a 的左 ↔ b 的右
        && isMirror(a.right, b.left);    //       a 的右 ↔ b 的左
}
```

> 💡 **双参数递归**是树递归的常见变体（对称、相同树、比较树）：**"同时递归两棵树"比"递归一棵树"只多一个参数**——模式上没有任何新东西。

### 6.2 236 最近公共祖先（LCA）

```java
// 236 LCA: 后序"找没找到"信号
public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    if (root == null || root == p || root == q) return root;  // 命中或为空
    TreeNode l = lowestCommonAncestor(root.left, p, q);
    TreeNode r = lowestCommonAncestor(root.right, p, q);
    if (l != null && r != null) return root;   // 左右各找到一个 → 本节点是 LCA
    return l != null ? l : r;                  // 单侧找到 → 向上传
}
```

**LCA 是后序 + 哨兵语义的集大成者**：返回值携带"这一侧有没有找到"的信息，左右都有 → 本节点是答案。**想通 LCA = 想通树递归的返回值设计**。

### 6.3 112 路径总和（前序携带）

```java
// 112 路径总和: 前序携带"剩余和"
public boolean hasPathSum(TreeNode root, int targetSum) {
    if (root == null) return false;
    if (root.left == null && root.right == null) return root.val == targetSum;  // 叶子判定
    return hasPathSum(root.left, targetSum - root.val)
        || hasPathSum(root.right, targetSum - root.val);
}
```

## 7. 递归遍历 vs 迭代遍历

| 维度 | 递归 | 迭代（显式栈） |
|------|------|---------------|
| 代码量 | 3 行模板 | 前序 ~8 行、中序 ~12 行 |
| 可读性 | 与问题结构一致 | 需手动管理状态 |
| 空间 | O(h) 调用栈 | O(h) 显式栈（堆内存） |
| 溢出风险 | 有（默认栈 512KB~1MB） | 低（堆内存大） |
| 适用 | 面试首选、题目直译 | 深度不可控的工程场景 |

**选型建议**：

```text
面试: 先写递归（清晰），被追问"栈溢出怎么办" → 现场转迭代
工程: 树深度可控（h ≤ 10⁴）用递归；不可控（深层 JSON、长链）用迭代
```

> 🎯 **核心要点**：二叉树 = 递归的练功房。四件事通关：**① 三问框架**（终止/返回/本层）；**② 三模板**（前中后序，只动处理位置，N 叉树只是加 for）；**③ 两大模式**（前序携带传参、后序聚合 + 全局答案）；**④ 双参数递归**（对称/LCA/相同树）。记住"**要子树答案 → 后序，传父层信息 → 前序，有序输出 → 中序**"，树递归题 80% 有了骨架。
