## 1. 21. 合并两个有序链表

### 1.1 题目与思路

```text
两个升序链表合并为升序。递归视角：
  当前节点 = 两个头中较小者，其余 = 递归合并剩下的两个子链表
  基线：任一为空 → 直接返回另一个

⚠️ 递归的"返回值语义"：返回"合并后的链表头"（想清楚这点，代码自然出来）
```

### 1.2 完整代码

```java
/**
 * LeetCode 21. 合并两个有序链表
 * 时间 O(m+n)，空间 O(m+n)（递归栈）
 */
public ListNode mergeTwoLists(ListNode l1, ListNode l2) {
    if (l1 == null) return l2;              // 基线：一方空 → 另一方整体
    if (l2 == null) return l1;

    if (l1.val <= l2.val) {
        l1.next = mergeTwoLists(l1.next, l2);   // 选 l1，合并其余
        return l1;
    } else {
        l2.next = mergeTwoLists(l1, l2.next);   // 选 l2，合并其余
        return l2;
    }
}
// 推演 l1=[1,3] l2=[2,4]：
//   1<2 → 1.next = merge([3],[2,4])
//          2<3 → 2.next = merge([3],[4]) → 3.next = merge([],[4]) = [4]
//   结果 1→2→3→4 ✓
```

> 🎯 **同类题**：23. 合并 K 个升序链表（两两合并或分治递归）。口诀："比大小选头，递归合余部"。

## 2. 24. 两两交换链表中的节点

### 2.1 题目与思路

```text
每两个节点交换顺序。递归视角：
  前两个节点交换后，第二个节点指向"剩余部分交换后的头"
  基线：空或单节点 → 直接返回

⚠️ 易错点：head.next.next 的赋值顺序（先接剩余，再断原链）
```

### 2.2 完整代码

```java
/**
 * LeetCode 24. 两两交换链表中的节点
 * 1→2→3→4 → 2→1→4→3
 */
public ListNode swapPairs(ListNode head) {
    if (head == null || head.next == null) return head;  // 基线：空/单节点

    ListNode second = head.next;              // ② 记住第二个节点
    head.next = swapPairs(second.next);       // ① 先递归处理后面的（2 的后继）
    second.next = head;                       // ③ 第二个指向第一个（完成交换）
    return second;                            // ④ 新头 = 第二个
}
// 推演 1→2→3→4：
//   swap(1,2)：second=2；1.next=swap(3,4)=4；2.next=1 → 2→1→4→3 ✓
// ⚠️ 顺序记忆：先接剩余（head.next），再反指（second.next=head）
```

## 3. 104/111. 最大深度与最小深度

### 3.1 104. 最大深度（后序聚合）

```java
/**
 * LeetCode 104. 二叉树的最大深度
 * 后序聚合：子问题结果向上合并
 */
public int maxDepth(TreeNode root) {
    if (root == null) return 0;                                  // 基线
    int left = maxDepth(root.left);                              // 左子树深度
    int right = maxDepth(root.right);                            // 右子树深度
    return Math.max(left, right) + 1;                            // 聚合：+1 自己
}
// 时间 O(n)，空间 O(h)
// ⚠️ 递归"后序"直觉：先问子问题，再算自己
```

### 3.2 111. 最小深度（经典坑）

```java
/**
 * LeetCode 111. 二叉树的最小深度
 * ⚠️ 不能直接 Math.min——[1,2] 的最小深度是 2 不是 1！
 *    单子树节点：空子树不能算深度（根到叶子必须走到叶子）
 */
public int minDepth(TreeNode root) {
    if (root == null) return 0;
    if (root.left == null) return minDepth(root.right) + 1;   // 只有右子树
    if (root.right == null) return minDepth(root.left) + 1;   // 只有左子树
    return Math.min(minDepth(root.left), minDepth(root.right)) + 1;
}
```

> 🎯 **聚合题口诀**："子树结果 + 自己 = 本层答案"（后序）。注意最小深度要区分单子树情况。

## 4. 226. 翻转二叉树

### 4.1 题目与思路

```text
翻转 = 交换每个节点的左右子树（自顶向下，先交换后递归）
基线：空节点
⚠️ 递归与交换的先后：可以先交换再递归（前序），也可以先递归再交换（后序）
   ——只要每个节点都交换过左右孩子即可
```

### 4.2 完整代码

```java
/**
 * LeetCode 226. 翻转二叉树
 * 前序版：先交换，再递归子树
 */
public TreeNode invertTree(TreeNode root) {
    if (root == null) return null;                 // 基线

    TreeNode tmp = root.left;                      // ① 交换左右
    root.left = root.right;
    root.right = tmp;

    invertTree(root.left);                         // ② 递归翻转左
    invertTree(root.right);                        // ③ 递归翻转右
    return root;
}
// 输入 [4,2,7,1,3,6,9] → 输出 [4,7,2,9,6,3,1]
// 面试背景：Homebrew 作者面试被要求手写此题（GitHub 梗）
```

## 5. 509. 斐波那契：三版演进

### 5.1 题目与思路

```text
F(n) = F(n-1) + F(n-2)，F(0)=0, F(1)=1
这题的面试价值：展示"递归 → 记忆化 → 迭代"的完整演进
（一个题考三个能力点）
```

### 5.2 三版代码对比

```java
/** 版一：朴素递归 ❌ O(2^n) —— 重叠子问题指数爆炸 */
public int fib1(int n) {
    if (n <= 1) return n;
    return fib1(n - 1) + fib1(n - 2);
}

/** 版二：记忆化递归 ✅ O(n) —— 缓存去重 */
public int fib2(int n) {
    int[] memo = new int[n + 1];
    Arrays.fill(memo, -1);
    return dfs(n, memo);
}
private int dfs(int n, int[] memo) {
    if (n <= 1) return n;
    if (memo[n] != -1) return memo[n];
    return memo[n] = dfs(n - 1, memo) + dfs(n - 2, memo);
}

/** 版三：迭代 ✅ O(n) O(1) —— 自底向上滚动 */
public int fib3(int n) {
    if (n <= 1) return n;
    int a = 0, b = 1;
    for (int i = 2; i <= n; i++) {
        int c = a + b;
        a = b;
        b = c;
    }
    return b;
}
```

| 版本 | 时间 | 空间 | 定位 |
|------|:---:|:---:|------|
| 朴素递归 | O(2^n) | O(n) | 演示爆炸 |
| 记忆化 | O(n) | O(n) | 自顶向下 DP |
| 迭代 | O(n) | O(1) | 最优解 |

> 🎯 **面试回答顺序**：先给朴素递归（展示递归理解）→ 主动指出指数复杂度 → 上记忆化 → 最后迭代 O(1) 空间。**主动演进**是加分项。

## 6. 70. 爬楼梯

### 6.1 题目与思路

```text
每次爬 1 或 2 阶，问 n 阶有多少种爬法。
递推：f(n) = f(n-1) + f(n-2)（先爬 1 阶或先爬 2 阶）
→ 本质就是斐波那契（f(1)=1, f(2)=2）
```

### 6.2 完整代码

```java
/**
 * LeetCode 70. 爬楼梯
 * 递归+记忆化（自顶向下）—— 面试先写这个，理解后转迭代
 */
public int climbStairs(int n) {
    int[] memo = new int[n + 1];
    return dfs(n, memo);
}
private int dfs(int n, int[] memo) {
    if (n <= 2) return n;                    // 基线：1 阶=1 种，2 阶=2 种
    if (memo[n] != 0) return memo[n];
    return memo[n] = dfs(n - 1, memo) + dfs(n - 2, memo);
}

// 迭代版（最优）：
public int climbStairsIter(int n) {
    if (n <= 2) return n;
    int a = 1, b = 2;
    for (int i = 3; i <= n; i++) {
        int c = a + b;
        a = b;
        b = c;
    }
    return b;
}
// 变体：一次可爬 1/2/3 阶 → f(n) = f(n-1)+f(n-2)+f(n-3)
//      相邻两步不能同数（如 746 最小花费）→ 加一维状态
```

## 7. 50. Pow(x, n)

### 7.1 题目与思路

```text
xⁿ = x^(n/2) × x^(n/2)（n 偶） 或 × x（n 奇）→ 二分递归
基线：n == 0 → 1
⚠️ 易错点：n 为负数、n = -2³¹ 溢出（先转 long）
```

### 7.2 完整代码

```java
/**
 * LeetCode 50. Pow(x, n)
 * 时间 O(log n)（每次规模减半）
 */
public double myPow(double x, int n) {
    long N = n;                              // ⚠️ 转 long 防 -2³¹ 溢出
    if (N < 0) return 1 / pow(x, -N);        // 负数 → 倒数
    return pow(x, N);
}
private double pow(double x, long n) {
    if (n == 0) return 1;                    // 基线：x⁰ = 1
    double half = pow(x, n / 2);             // 递归：只算一半
    if ((n & 1) == 1) return half * half * x;   // 奇数：补乘一个 x
    return half * half;                      // 偶数
}
// 推演 myPow(2, 10)：
//   pow(2,5) → pow(2,2) → pow(2,1) → pow(2,0)=1
//   2^1: half=1, 奇 → 1*1*2=2
//   2^2: half=2, 偶 → 4
//   2^5: half=4, 奇 → 16*2=32
//   2^10: half=32, 偶 → 1024 ✓
// ⚠️ 只递归一次 pow(x, n/2)，不要写 pow(x,n/2)*pow(x,n/2)（会变 O(n)）
```

## 8. 779. 第 K 个语法符号

### 8.1 题目与思路

```text
第 1 行：0
第 n 行由上一行扩展：0 → 01，1 → 10
即 row(n) = row(n-1) + invert(row(n-1))，问第 n 行第 k 位

递归定位：不看整行，直接算位置
  k 在左半 → 查 row(n-1) 第 k 位（值不变）
  k 在右半 → 查 row(n-1) 第 k-2^(n-2) 位（值取反）
基线：n==1 → 0
```

### 8.2 完整代码

```java
/**
 * LeetCode 779. 第 K 个语法符号
 * ⚠️ 核心技巧：不要构造整行（2^(n-1) 个字符装不下），递归定位
 */
public int kthGrammar(int n, int k) {
    if (n == 1) return 0;                          // 基线：第一行只有 0
    int half = 1 << (n - 2);                       // 左半长度 = 2^(n-2)
    if (k <= half) {
        return kthGrammar(n - 1, k);               // 左半：值不变
    } else {
        return kthGrammar(n - 1, k - half) ^ 1;    // 右半：取反
    }
}
// 推演 n=4, k=5：
//   row4 = row3 + invert(row3) = 01101001
//   half = 2² = 4 → k=5 在右半 → kthGrammar(3, 1) ^ 1
//     row3 = 0110 → 第 1 位 = 0 → 结果 0^1 = 1 ✓（row4 第 5 位 = 1）
// 时间 O(n)：每层 O(1)，共 n 层
```

> 🎯 **同类思想**：875/找第 K 位、按位定位类问题——"用递归剪掉一半搜索空间"，是"分治定位"的典型。

## 9. 687. 最长同值路径

### 9.1 题目与思路

```text
找最长路径，路径上的值全部相同（路径可弯曲经过根）。
后序聚合：每个节点返回"沿单侧延伸的最大长度"，
  同时用 left+right 尝试更新全局答案

⚠️ 返回值 ≠ 答案：返回值是"单边长度"，答案是"双边和"
  ——这是树形聚合题的通用难点
```

### 9.2 完整代码

```java
/**
 * LeetCode 687. 最长同值路径
 * 时间 O(n)，空间 O(h)
 */
int ans = 0;

public int longestUnivaluePath(TreeNode root) {
    ans = 0;
    dfs(root);
    return ans;
}

/** 返回：从 root 出发，沿单侧向下最长同值长度 */
private int dfs(TreeNode root) {
    if (root == null) return 0;

    int left = dfs(root.left);                  // 左子树单侧长度
    int right = dfs(root.right);                // 右子树单侧长度

    // ⚠️ 值不同 → 贡献归零（断链）
    int leftLen = (root.left != null && root.left.val == root.val) ? left + 1 : 0;
    int rightLen = (root.right != null && root.right.val == root.val) ? right + 1 : 0;

    ans = Math.max(ans, leftLen + rightLen);    // 通过当前节点的"双边"路径
    return Math.max(leftLen, rightLen);         // 返回给父节点的"单边"路径
}
// 例：[1,4,5,4,4,null,5]
//   node 4(左) 返回 1；node 4(右) 返回 1
//   父 4：leftLen=2, rightLen=0 → 路径 4-4-4 长度 2 ✓
// ⚠️ 结构：ans 全局 + 后序 + 返回值是"半边"
```

## 10. 124. 二叉树中的最大路径和

### 10.1 题目与思路

```text
任意节点到任意节点的最大路径和（可弯曲、可单边）。
与 687 同构：后序聚合 + 全局 ans
差别：687 判"值相等"，124 算"和最大"
⚠️ 负数分支贡献为负 → 截断为 0（不选）
```

### 10.2 完整代码

```java
/**
 * LeetCode 124. 二叉树中的最大路径和
 * 经典 hard，树形聚合模板题
 */
int maxSum = Integer.MIN_VALUE;

public int maxPathSum(TreeNode root) {
    maxSum = Integer.MIN_VALUE;
    dfs(root);
    return maxSum;
}

/** 返回：从 root 向下延伸的最大单边路径和（可为 0 截断） */
private int dfs(TreeNode root) {
    if (root == null) return 0;

    int left = Math.max(0, dfs(root.left));     // ⚠️ 负贡献截断为 0
    int right = Math.max(0, dfs(root.right));

    maxSum = Math.max(maxSum, left + right + root.val);   // 过当前节点的整条路径

    return Math.max(left, right) + root.val;    // 给父节点：只能选一边
}
// 例：[-10,9,20,null,null,15,7]
//   node 15+7=22；20 节点：left=15,right=7 → 整条 15+20+7=42 → ans=42 ✓
// 推演注意：负数节点单独也可能成为答案（如单节点 [-3] → -3）
```

> 🎯 **模板总结**：**"半边返回 + 双边更新 + 全局变量"**——所有树形聚合题（687/124/543 直径/236 最近公共祖先）同一个框架。

## 11. 894. 所有可能的满二叉树

### 11.1 题目与思路

```text
n 个节点构造所有满二叉树（每个节点 0 或 2 个子节点）。
分治：根节点 + 左子树 i 个节点 + 右子树 n-1-i 个节点（i 取奇数）
记忆化：n 相同 → 结果相同，缓存 List
基线：n==1 → 单节点树
⚠️ n 为偶数时不可能有满二叉树 → 直接返回空
```

### 11.2 完整代码

```java
/**
 * LeetCode 894. 所有可能的满二叉树
 * 分治 + 记忆化（n 从 1 到 19，直接枚举所有拆分）
 */
Map<Integer, List<TreeNode>> memo = new HashMap<>();

public List<TreeNode> allPossibleFBT(int n) {
    if ((n & 1) == 0) return new ArrayList<>();        // ⚠️ 偶数不可能
    if (memo.containsKey(n)) return memo.get(n);       // 记忆化
    if (n == 1) {
        List<TreeNode> single = new ArrayList<>();
        single.add(new TreeNode(0));
        memo.put(1, single);
        return single;                                 // 基线：单节点
    }

    List<TreeNode> res = new ArrayList<>();
    for (int i = 1; i < n; i += 2) {                   // 左子树节点数（奇数）
        int j = n - 1 - i;                             // 右子树节点数
        for (TreeNode left : allPossibleFBT(i)) {      // 笛卡尔积组合
            for (TreeNode right : allPossibleFBT(j)) {
                res.add(new TreeNode(0, left, right));
            }
        }
    }
    memo.put(n, res);
    return res;
}
// 推演 n=3：i=1（左 1 节点）, j=1（右 1 节点）→ 1 种：根+左右单节点
//   n=5：i=1,j=3 与 i=3,j=1 → 共 2 种组合结构
```

## 12. 递归解题方法论总结

### 12.1 四步框架（每道题套用）

```text
① 明确定义：函数参数与返回值语义（"返回什么给上一层"）
   ⚠️ 回答不出来 = 没想清楚，先写注释再写代码
② 找到基线：最小规模直接返回（空/0/1/单节点）
   ⚠️ 基线最先写，先判退出
③ 设计递推：把问题缩小为子问题调用自身
   ⚠️ 只信"子问题返回正确"，不要手推全栈
④ 验证收敛：规模必减 + 手推 2-3 层验证
```

### 12.2 题型模板速查

| 模板 | 特征 | 返回语义 | 代表题 |
|------|------|---------|--------|
| 线性递归 | 链表/单链 | 合并后的头 | 21、24、206 |
| 后序聚合 | 树 | 子树结果+自己 | 104、687、124 |
| 前序传参 | 树/路径 | 路径状态下传 | 路径和、序列化 |
| 二分递归 | 数字折半 | 半结果合并 | 50、二分查找 |
| 分治定位 | 行/序列定位 | 剪半搜索 | 779 |
| 分治构造 | 枚举结构 | 结构列表 | 894 |
| 记忆化 | 重叠子问题 | 状态结果缓存 | 509、70 |

### 12.3 复杂度速答

```text
时间：数调用树节点数（多路递归）或写递推方程（分治）
空间：最深调用链（不是总调用数）
表达："时间 O(n)，空间 O(h)，h 为递归深度"
```
