## 1. 贪心算法的本质

### 1.1 定义

> 贪心算法（Greedy）：每一步都做出**当下看来最优的选择**（局部最优），希望通过一系列局部最优选择得到全局最优解。

```
类比：登山捡石头
  贪心：每步捡最大的石头 → 可能错过远处更大的
  DP：考虑所有路径 → 找到最优组合

贪心赌的是：局部最优的组合 = 全局最优
```

### 1.2 贪心的特征

```
① 选择不可反悔：一步定型，不能回头改
   （所以叫"贪心"——只顾眼前）
② 无回溯/重算：不像 DP 需要比较所有子问题
③ 效率高：通常 O(n log n)（排序）或 O(n)

三个"如果"：
  如果能证明局部最优 → 全局最优 → 贪心
  如果局部最优可能危害全局 → DP/其他
  如果无法判断 → 先试贪心 + 反例验证
```

## 2. 两大核心性质

### 2.1 贪心选择性质（Greedy Choice Property）

> 全局最优解可以通过**一系列局部最优选择**达成——每一步的贪心选择都是全局最优解的一部分。

```
通俗理解：每一步"看起来最好"的选择，
不会堵死通向全局最优的路。

验证方法：假设某个最优解不以贪心选择开头，
尝试用贪心选择替换它（交换论证）→ 结果不更差
```

### 2.2 最优子结构（Optimal Substructure）

> 问题的最优解包含子问题的最优解。

```
贪心做完第一步后，剩余问题是同类子问题
且子问题的最优解 + 第一步选择 = 全局最优

例：分发饼干（455）
  把最小的饼干给最小胃口的孩子（贪心选择）
  → 剩余孩子和饼干是相同结构的子问题
  → 递归应用贪心 = 全局最优
```

### 2.3 两个性质的配合

```
贪心选择性质 → 保证"每步选择正确"
最优子结构 → 保证"选择后剩余问题可继续贪心"

两者缺一不可：
  只有最优子结构没有贪心选择 → DP 解决（需比较）
  只有贪心选择没有最优子结构 → 贪心可能中途失效
```

## 3. 证明方法：交换论证与归纳法

### 3.1 交换论证法（最常用）

```
证明思路：
  ① 假设存在一个最优解 O
  ② 用贪心选择 g 替换 O 中的某个选择 → 得到 O'
  ③ 证明 O' 不比 O 差（代价/数量/收益）
  ④ 由归纳可得：贪心解 = 最优解

以 435 无重叠区间为例：
  贪心策略：保留结束最早的区间
  假设最优解 O 的第一个区间不是结束最早的 g
  → 用 g 替换 O 的第一个区间
  → g 结束更早 → 与后续区间冲突更少
  → O' 不差于 O ✓ → 贪心最优
```

### 3.2 数学归纳法

```
证明思路：
  ① 基础：第一步贪心选择正确
  ② 归纳：假设前 k 步贪心正确
  ③ 递推：第 k+1 步贪心选择正确
  → 贪心解 = 最优解

例：455 分发饼干
  最小饼干 ≥ 最小胃口 → 给（贪心最优，不浪费）
  最小饼干 < 最小胃口 → 该饼干无法满足任何人（丢弃）
  → 每步正确，归纳成立
```

### 3.3 面试表达

```
"我证明贪心正确性用的是交换论证：
 假设最优解不以我的贪心选择开头，
 用贪心选择替换后结果不会更差，
 所以贪心选择可以出现在最优解中，
 反复替换得到贪心解 = 最优解。"
```

## 4. 贪心 vs 动态规划

### 4.1 核心区别

| 维度 | 贪心 | 动态规划 |
|------|:---:|:---:|
| 决策方式 | 每步选局部最优 | 比较所有子问题 |
| 回退能力 | **不可反悔** | 可回退（dp 表记录） |
| 子问题处理 | 只处理一条路径 | 所有子问题 |
| 复杂度 | 通常更低 | 需要状态枚举 |
| 正确性 | 需要证明 | 转移方程保证 |
| 关系 | **DP 的特例** | 更通用 |

### 4.2 关键认知

```
贪心 = DP 的特例：
  当"局部最优选择"恰好与"全局最优路径"一致时
  → 无需枚举所有子问题 → 贪心更高效

面试表达：
"这题满足贪心选择性质——每步的局部最优
 必然在全局最优解中，所以不需要 DP 枚举。"
```

## 5. 反例识别：什么时候不能用

### 5.1 经典反例一：0-1 背包

```
背包容量 10：
  物品 A：重量 6，价值 30（单位价值 5）
  物品 B：重量 5，价值 25（单位价值 5）
  物品 C：重量 5，价值 25（单位价值 5）

贪心按单位价值选：A(6,30) → 剩余 4 装不下 B/C → 总价值 30
最优解：B + C = 重量 10，价值 50！

为什么失败：选 A 虽然单位价值最高，
但占用了大量容量 → 阻碍了后续更好的组合
→ 不满足贪心选择性质（局部最优危害全局）
→ 必须用 DP
```

### 5.2 经典反例二：硬币找零

```
面额 1/3/4 元，找 6 元：
  贪心（优先大面额）：4 + 1 + 1 = 3 枚
  最优解：3 + 3 = 2 枚！

为什么失败：4 元硬币虽然单枚价值大，
但组合不灵活 → 贪婪选大面额并非最优
```

### 5.3 反例识别清单

| 场景 | 能否贪心 | 原因 |
|------|:---:|------|
| 0-1 背包 | ❌ | 选物品影响后续容量 |
| 部分背包（可切分） | ✅ | 单位价值贪心正确 |
| 普通硬币找零 | ✅ | 1/5/10 等标准面额 |
| 奇葩面额找零 | ❌ | 组合不灵活 |
| 无负权最短路 (Dijkstra) | ✅ | 贪心+堆 |
| 负权最短路 | ❌ | 需 Bellman-Ford |
| 区间调度 | ✅ | 结束时间排序 |

## 6. 四步解题法

```
① 问题分解：把原问题分解为若干阶段（每阶段做一次选择）
② 阶段切割：明确每一步的选择内容（选谁/怎么选）
③ 确定策略：定义"局部最优"的度量标准
   （结束最早？单位价值最高？需求最小？）
④ 验证正确：数学归纳法 / 交换论证法证明

⚠️ 90% 贪心题需要排序！
  找不到排序角度的贪心策略往往有问题
```

### 面试话术模板

```
"这题用贪心：我定义局部最优为【...】（度量标准）。
 每步选择【...】（贪心策略）。
 正确性证明：交换论证——假设最优解不以我的选择开头，
 替换后不更差，因此贪心解 = 最优解。
 复杂度：排序 O(n log n) + 线性扫描 O(n)。"
```

> 🎯 **核心要点**：贪心的本质是"局部最优 → 全局最优"的**赌注**——赌对了效率极高（O(n)），赌错了就是 0-1 背包的教训。两大性质（贪心选择 + 最优子结构）是判断标准，交换论证是证明工具，反例识别是保险丝。面试时**必须主动证明**"为什么贪心是对的"，这是贪心题与普通题最大的区分点。
