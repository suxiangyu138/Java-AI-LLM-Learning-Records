## 2. 面试解题话术：策略+证明

```
📣 第 1 步：识别 (15秒)
"这是区间选择问题，用贪心——
 需要选最多互不重叠的区间。"

📣 第 2 步：说策略 (30秒)
"贪心策略：按结束时间升序排序，
 优先保留结束最早的区间。
 因为结束早 → 留出的空间多 → 能容纳更多区间。"

📣 第 3 步：证明正确性（核心！）(60秒)
"我用交换论证证明：
 假设最优解的第一个区间不是结束最早的 G，
 用 G 替换它——G 结束不晚于原区间，
 与后续区间的冲突不会更多，
 所以替换后的解不更差。
 归纳推进，贪心解 = 最优解。"

📣 第 4 步：复杂度 (10秒)
"排序 O(n log n) + 扫描 O(n) = O(n log n)，空间 O(1)。"
```

> 🎯 **贪心面试与其他算法最大的不同**：写完代码不算完，**必须证明**。面试官说"为什么贪心是对的？"是 100% 会问的——交换论证和反例验证都要能脱口而出。

## 3. 高频追问与标准回答

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 怎么判断能用贪心？ | 检查贪心选择性质：局部最优选择是否在全局最优解中。用反例尝试：能找到反例就不能用，找不到再用交换论证证明 |
| 2 | 为什么按结束时间排序？ | 结束早留出更多空间；交换论证证明贪心解 = 最优解 |
| 3 | 贪心和 DP 的区别？ | 贪心每步选局部最优不可反悔；DP 枚举所有子问题可回退。贪心是 DP 的特例（当贪心选择性质成立时） |
| 4 | 给个贪心失效的例子？ | 0-1 背包：按单位价值贪心选最大的，可能占用容量堵死最优组合；奇葩硬币找零：1/3/4 找 6 元，贪心 4+1+1 不是最优 3+3 |
| 5 | 什么时候必须先排序？ | 90% 的贪心题需要排序——找"最小/最大"匹配、区间处理等。找不到排序角度的策略往往有问题 |
| 6 | 两趟遍历为什么取 max？ | 左到右满足一个方向的约束，右到左满足另一个方向；取 max 兼顾两方向，直接赋值会覆盖之前的合法结果 |
| 7 | 反悔贪心是什么？ | 贪心选择后如果发现更优选择，用堆记录历史选择并替换（如 630 课程表 III：超时后放弃最耗时的课程） |

## 4. 进阶：反悔贪心

### 4.1 630. 课程表 III（Hard 进阶）

```java
/**
 * LeetCode 630. 课程表 III（反悔贪心代表题）
 * 每门课有持续时间 duration 和截止时间 lastDay
 * 求最多能修完的课程数
 *
 * 贪心 + 反悔：
 *   ① 按截止时间排序（越早截止越先安排）
 *   ② 能按时修 → 加入（贪心选择）
 *   ③ 不能按时修 → 用堆找到"已修课程中最长的"
 *      如果放弃最长课程能让当前课程加入且总数不变
 *      → 反悔替换（总数不变但总时间更短 → 为未来留空间）
 *
 * 本质：贪心 + 堆保存历史选择，牺牲局部最优换全局最优
 */
public int scheduleCourse(int[][] courses) {
    // 按截止时间排序
    Arrays.sort(courses, (a, b) -> a[1] - b[1]);

    PriorityQueue<Integer> heap = new PriorityQueue<>(
        (a, b) -> b - a);               // 大根堆：存已修课程时长
    int time = 0;                       // 当前总时间

    for (int[] course : courses) {
        int duration = course[0], lastDay = course[1];
        time += duration;
        heap.offer(duration);           // 先加入（贪心）

        if (time > lastDay) {           // 超时 → 反悔
            time -= heap.poll();        // 放弃最长的课程
        }
    }
    return heap.size();                 // 堆中就是最终选的课程
}
```

### 4.2 反悔贪心的通用模式

```
模板四步：
  ① 排序（按截止/优先级）
  ② 贪心选择 + 入堆
  ③ 超限时弹出"代价最大"的（反悔）
  ④ 堆大小 = 最优选择数

特征：每步看似贪心，但允许"撤销历史选择"
   → 局部最优 + 全局可调整
   → 比纯贪心强，比 DP 简单
```

## 5. 高频题深度复盘

### 5.1 135. 分发糖果（Hard 常考）

```java
public int candy(int[] ratings) {
    int n = ratings.length;
    int[] candies = new int[n];
    Arrays.fill(candies, 1);

    for (int i = 1; i < n; i++) {                    // 左到右
        if (ratings[i] > ratings[i - 1]) {
            candies[i] = candies[i - 1] + 1;
        }
    }
    for (int i = n - 2; i >= 0; i--) {               // 右到左
        if (ratings[i] > ratings[i + 1]) {
            candies[i] = Math.max(candies[i], candies[i + 1] + 1);
        }
    }
    int sum = 0;
    for (int c : candies) sum += c;
    return sum;
}
```

**复盘要点**：
- 双向约束 → 两趟遍历（每趟只处理一个方向）
- 第二趟 `Math.max` 是关键（不覆盖第一趟结果）
- 面试常问："为什么不能一趟完成？"

### 5.2 452. 引爆气球（复盘）

```java
public int findMinArrowShots(int[][] points) {
    Arrays.sort(points, (a, b) -> Integer.compare(a[1], b[1]));
    int arrows = 1, lastEnd = points[0][1];
    for (int i = 1; i < points.length; i++) {
        if (points[i][0] > lastEnd) {    // 端点相撞算重叠
            arrows++;
            lastEnd = points[i][1];
        }
    }
    return arrows;
}
```

**复盘要点**：
- 与 435 对比讲解（同一模型一字之差）
- `Integer.compare` 防溢出（区间值可能极大）
- 贪心证明：一支箭尽可能多地覆盖 → 按结束排序最优

## 6. 调试技巧与自检清单

### 6.1 贪心自检三步法

```
第 1 步：策略检查
  □ 贪心策略是什么？（一句话说清）
  □ 需要排序吗？排序键选对了吗？
  □ 局部最优会危害全局吗？（尝试反例）

第 2 步：边界检查
  □ 空数组 / 单元素
  □ 全部重叠 / 全部不重叠
  □ 极端值（int 溢出用 Integer.compare）
  □ 第一个/最后一个元素的处理

第 3 步：证明检查（面试核心）
  □ 能用交换论证/归纳法证明吗？
  □ 找不到反例吗？
  □ 能讲清"为什么这一步选择是对的"？
```

### 6.2 高频 Bug 速查表

| Bug | 原因 | 修复 |
|------|------|------|
| 区间比较溢出 | `a[1] - b[1]` 极大值溢出 | `Integer.compare(a[1], b[1])` |
| 排序键选错 | 合并区间按结束排 | 看目标："选最多"按结束，"扫覆盖"按开始 |
| 端点处理错 | 435/452 混淆 | 相撞是否算重叠决定 `>=` 还是 `>` |
| 贪心失效无察觉 | 没验证反例 | 先试 0-1 背包式反例 |
| 堆方向搞反 | 反悔贪心堆用错 | 放弃最长 → 大根堆 |
| 两趟遍历覆盖 | 第二趟直接赋值 | 用 `Math.max` 兼顾 |

### 6.3 面试手写 Checklist

```
□ 先说贪心策略（一句话：选什么/怎么度量）
□ 说需要排序 + 排序键
□ 证明正确性（交换论证/归纳）
□ 主动提反例检查（0-1 背包为什么不行）
□ 边界：空/单/全重叠/全不重叠
□ 溢出防护
□ 复杂度 O(n log n) 或 O(n)
□ 手动跑 1 个用例
```

> 🎯 **核心要点**：贪心面试 = **策略 + 证明 + 反例意识**。区间调度（435/452）和分配问题（455/135）是最高频考点，反悔贪心（630）是进阶分水岭。记住三句话：**"90% 贪心题要排序"、"为什么贪心是对的必须能证明"、"0-1 背包是贪心最大的反例"**——讲清这三点，贪心题就是你的稳定得分项。
