## 1. 标记机制的完整体系

### 1.1 为什么需要标记

```
DFS 需要防重复访问：
  网格：相邻格子互相发现 → 来回递归
  图：环/共享节点 → 无限递归

⚠️ 标记的三要素：
  ① 标记时机（递归前！）
  ② 标记方式（数组/原地/颜色）
  ③ 是否恢复（沉岛 vs 回溯）
```

### 1.2 标记的时机（最大坑）

```
⚠️ 标记必须在递归前：
  标记太晚 → 相邻格子互相发现 → 来回递归 → 栈溢出

✅ 正确顺序：
  越界判断 → 条件判断 → 标记 → 递归四方向

⚠️ 面试必答：
"网格 DFS 标记必须在递归前——
 否则相邻格子会互相递归，直接栈溢出。"
```

### 1.3 三种标记方式

| 方式 | 实现 | 空间 | 适用 |
|------|------|:---:|------|
| visited 数组 | boolean[][] | O(mn) | 通用/不破坏输入 |
| 原地标记 | 沉岛/'0'/'\0' | O(1) | 可修改输入 |
| 颜色数组 | 0/1/2 | O(n) | 判环/染色 |

```
⚠️ 选型：
  可修改输入 → 原地标记（省空间）
  不可修改 → visited 数组
  需要判环 → 颜色数组（三态）
```

## 2. 沉岛 vs 回溯 vs 记忆化

### 2.1 三者的区别

```
沉岛（永久标记）：计数/连通
  例：200 岛屿数量（1→0，不用恢复）

回溯（标记+撤销）：路径搜索
  例：79 单词搜索（标记后恢复，探索其他方向）

记忆化（缓存结果）：重叠子问题
  例：329 递增路径（缓存最长路径）

⚠️ 识别："需要恢复吗？"
  计数/连通 → 不恢复（沉岛）
  路径搜索 → 恢复（回溯）
  重叠子问题 → 缓存（记忆化）
```

### 2.2 三种实现的模板

```java
// ═══════════ 沉岛（永久标记）══════════════════════
void sink(char[][] grid, int i, int j) {
    if (越界 || grid[i][j] != '1') return;
    grid[i][j] = '0';              // ⚠️ 永久标记（不用恢复）
    sink(grid, i+1, j); sink(grid, i-1, j);
    sink(grid, i, j+1); sink(grid, i, j-1);
}

// ═══════════ 回溯（标记+撤销）══════════════════════
boolean backtrack(char[][] board, ...) {
    if (越界 || board[i][j] != c) return false;
    char temp = board[i][j];
    board[i][j] = '\0';            // ⚠️ 标记
    boolean found = backtrack(四个方向);
    board[i][j] = temp;            // ⚠️ 撤销（灵魂！）
    return found;
}

// ═══════════ 记忆化（缓存结果）══════════════════════
int memoDFS(int[][] matrix, int i, int j, int[][] memo) {
    if (memo[i][j] != 0) return memo[i][j];   // ⚠️ 查缓存
    int best = 计算(递归调用);
    return memo[i][j] = best;                 // ⚠️ 存缓存
}
```

### 2.3 面试表达

```
"网格 DFS 三选一：
 计数/连通 → 沉岛（永久标记，O(1) 空间）；
 路径搜索 → 回溯（标记后恢复，探索其他方向）；
 重叠子问题 → 记忆化（缓存结果，O(状态数)）。
 '需要恢复吗？'是网格 DFS 的第一问。"
```

## 3. DFS 的状态设计

### 3.1 状态的完整描述

```
DFS 状态 = 递归参数：
  位置：(i, j)
  位置+属性：(i, j, 剩余步数)
  位置+状态：(i, j, 掩码)

⚠️ 状态不完整 = 结果错误
  例：576 出界路径（位置+剩余步数）
  例：403 青蛙过河（位置+跳跃距离）
```

### 3.2 状态维度的选择

| 问题 | 状态 | 维度 |
|------|------|:---:|
| 连通块 | (i, j) | 2D |
| 单词搜索 | (i, j, 索引) | 3D |
| 出界路径 | (i, j, 步数) | 3D |
| 青蛙过河 | (位置, 跳跃) | Map |
| 博弈 | 掩码 | 1D 掩码 |

```
⚠️ 判断标准：
  "状态能否唯一决定未来？"
  能 → 维度够；不能 → 缺维度
```

### 3.3 记忆化 + 状态设计的结合

```
329 递增路径（经典）：
  状态：(i, j)
  记忆化：memo[i][j] = 从 (i,j) 出发的最长路径
  ⚠️ 为什么不需要 visited？
    递增 → 无环 → 不可能走回已访问格子

⚠️ 面试必答：
"递增路径天然无环 → 不需要 visited，
 只需要记忆化（缓存结果）。
 有环场景（如单词搜索）→ 需要 visited+回溯。"
```

## 4. DFS 与图论算法的结合

### 4.1 DFS + 颜色法（判环）

```
颜色：0 未访问 / 1 访问中 / 2 已完成
  递归中遇到"访问中"(1) → 有环！

⚠️ 与简单 visited 的区别：
  visited 只区分"访问过/没访问过"
  颜色法区分"本路径上"与"其他路径"
  → 只有颜色法能判环

⚠️ 面试必答：
"判环必须颜色法——遇到'访问中'
 说明当前路径绕回自己（环）；
 简单 visited 无法区分路径归属。"
```

### 4.2 DFS + 染色（二分图）

```
相邻节点必须异色，冲突 → 非二分图
  颜色：1 / -1（两种）
  DFS 染色 + 冲突检测

⚠️ 图可能不连通 → 遍历所有未染色起点
```

### 4.3 DFS + Tarjan（连通性）

```
dfn/low + 栈 → 强连通分量（有向）
dfn/low + 父节点 → 桥/割点（无向）

⚠️ 竞赛级；面试掌握 1192（求桥）模板即可
```

## 5. DFS 的复杂度与优化

### 5.1 复杂度分析

```
树 DFS：O(n) 时间 O(h) 空间（h = 树高）
网格 DFS：O(mn) 时间 O(mn) 空间（最坏）
图 DFS：O(V+E) 时间 O(V) 空间
回溯 DFS：O(指数)（输出规模决定）

⚠️ 网格空间最坏 O(mn)：
  递归深度 = 最长路径（蛇形）
  → 可能栈溢出 → 显式栈迭代
```

### 5.2 优化方向

```
① 剪枝：提前终止不可能的分支
② 记忆化：缓存重叠子问题
③ 迭代：显式栈防栈溢出
④ 位压缩：状态用掩码

⚠️ 面试表达：
"DFS 递归深度可能 O(mn)，
 可以转显式栈迭代防栈溢出。"
```

### 5.3 栈溢出与应对

```
递归深度分析：
  树高 h → 深度 h（通常安全）
  链表长度 n → 深度 n（危险）
  网格最坏 m×n → 深度 m×n（危险）

应对方案：
  ① 显式栈迭代（堆内存）
  ② 尾递归优化（Java 不支持自动）

⚠️ 面试必答：
"递归深度 O(路径长度) 可能栈溢出，
 可以转显式栈迭代（Deque 模拟）。"
```

## 6. 进阶总结

### 6.1 进阶要点速查

```
① 标记机制：时机（递归前）/方式（数组/原地/颜色）/恢复
② 三选一：沉岛（计数）/回溯（路径）/记忆化（缓存）
③ 状态设计：完整描述 + 维度选择
④ 图论结合：颜色法（判环）/染色（二分）/Tarjan
⑤ 复杂度：O(V+E)/O(mn) + 栈溢出应对
```

### 6.2 面试话术模板

```
"这题用 DFS：
 ① 标记【沉岛/回溯/记忆化】（需要恢复吗？）；
 ② 状态【(i,j)+附加维度】（完整描述剩余问题）；
 ③ 复杂度【O(mn)/O(V+E)】；
 ④ 递归深度【O(路径)】→ 可转显式栈。
 追问判环：【颜色法 0/1/2】。"
```

### 6.3 易错点清单

| 错误 | 后果 | 修正 |
|------|------|------|
| 标记在递归后 | 栈溢出 | 标记前移 |
| 图忘 visited | 无限递归 | 加 visited |
| 路径搜索忘撤销 | 结果重复 | 成对恢复 |
| 状态缺维度 | 结果错 | 完整描述 |
| 深链硬递归 | 栈溢出 | 转迭代 |

> 🎯 **核心要点**：DFS 进阶 = **标记机制**（时机/方式/恢复）+ **三选一**（沉岛/回溯/记忆化）+ **状态设计**（完整性）+ **图论结合**（颜色法）。"需要恢复吗？"是第一问；"标记在递归前"是铁律；颜色法判环与记忆化免 visited 是两个必答点。
