## 1. 知识体系导图

```
DFS（深度优先搜索）
│
├── 核心原理 ──────────────────────────────────────────────
│   ├── 一条路走到底，走不通再回头（栈/递归实现）
│   ├── 前序：先处理再递归（自顶向下）
│   ├── 后序：先递归再处理（自底向上）
│   └── 回溯 = DFS + 状态撤销（见回溯体系）
│
├── 适用场景 ──────────────────────────────────────────────
│   ├── "所有路径/方案" → DFS（79/257/131）
│   ├── "连通块" → DFS（200 岛屿）
│   ├── 树的遍历/属性 → DFS（104/124）
│   └── 图判环/拓扑 → DFS 颜色法
│
├── 经典题型 ──────────────────────────────────────────────
│   │
│   ├── 🟢 树 DFS
│   │   ├── 104. 最大深度（后序）
│   │   ├── 257. 所有路径（前序）
│   │   └── 124. 最大路径和（后序有状态）
│   │
│   ├── 🟡 网格 DFS
│   │   ├── 200. 岛屿数量（沉岛）
│   │   ├── 695. 岛屿最大面积
│   │   ├── 79. 单词搜索（回溯+visited）
│   │   └── 130. 被围绕的区域
│   │
│   ├── 🟡 图 DFS
│   │   ├── 133. 克隆图（哈希映射）
│   │   ├── 785. 判断二分图（染色）
│   │   ├── 841. 钥匙和房间
│   │   └── 207. 课程表（颜色法判环）
│   │
│   └── 🟡 记忆化 DFS
│       ├── 329. 矩阵最长递增路径
│       ├── 62. 不同路径
│       └── 338. 比特位计数
│       （记忆化 = DFS + 缓存，见动态规划体系）
│
├── 与 BFS 的对比 ─────────────────────────────────────────
│   ├── DFS：栈/递归/路径/空间小
│   ├── BFS：队列/最短/层序/空间大
│   └── 选择标准（见 BFS 体系）
│
├── 关键技巧 ──────────────────────────────────────────────
│   ├── visited：防重复访问（网格/图）
│   ├── 沉岛：原地标记省空间
│   ├── 回溯撤销：路径收集成对 add/remove
│   └── 颜色法：0/1/2 三态判环
│
└── Java 实战 ─────────────────────────────────────────────
    ├── 递归模板（前序/后序）
    ├── 网格方向数组模板
    ├── 显式栈（防栈溢出）
    └── 面试话术：先讲递归边界再写
```

## 3. 学习路线推荐

### 🟢 路线 A：零基础入门（1 周）
```
01 核心原理 → 104 最大深度 → 226 翻转
→ 200 岛屿数量 → 257 所有路径
```
- **目标**：递归 DFS 模板闭眼能写
- **题量**：约 8-10 题

### 🟡 路线 B：面试冲刺（1-2 周）
```
01 速过 → 02 网格 DFS（5题）→ 03 图 DFS（3题）
→ 05 高频复盘
```
- **目标**：网格/图 DFS 全覆盖，连通块秒杀
- **题量**：约 15 题

### 🔴 路线 C：全面掌握（2 周）
```
完整 01→05 + 记忆化 DFS（329）
→ 显式栈迭代（防栈溢出）
→ 颜色法判环 + 拓扑 DFS 版
→ DFS 与回溯/DP 的交叉（见对应体系）
```
- **目标**：DFS 全部形态可手写，能讲清与回溯/DP 关系
- **题量**：约 20 题

## 4. 核心概念速查

| 概念 | 一句话解释 | 典型例题 |
|------|-----------|------|
| **深度优先** | 一条路走到底再回头 | 树遍历 |
| **前序** | 先处理再递归（自顶向下） | 257 路径 |
| **后序** | 先递归再处理（自底向上） | 104 深度 |
| **沉岛** | 原地标记 1→0 代替 visited | 200 |
| **visited** | 防重复访问（网格/图） | 79/133 |
| **回溯撤销** | 递归后恢复状态 | 79 单词搜索 |
| **颜色法** | 0/1/2 三态判环 | 207 课程表 |
| **记忆化** | DFS + 缓存（重叠子问题） | 329 |
| **显式栈** | 递归转迭代防栈溢出 | 树遍历迭代版 |
| **连通块** | DFS 一次遍历整块 | 200/695 |
