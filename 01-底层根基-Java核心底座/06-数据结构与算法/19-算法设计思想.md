## 2. 暴力枚举

### 2.1 核心定义

枚举（穷举）是最基础最直观的算法思想，将问题的所有可能解逐一列举，逐一验证是否符合约束条件。

### 2.2 核心逻辑

1. **确定解空间**：明确所有可能解的范围
2. **逐一枚举**：按一定顺序列举每一个可能解
3. **验证判断**：对每个枚举的解，验证是否符合约束

### 2.3 适用条件

| 条件 | 说明 |
|------|------|
| 解空间小 | 可能解的数量在可控范围内 |
| 约束条件简单 | 验证成本低 |

> 解空间过大时枚举算法效率极低，不适用。

## 3. 分治法

### 3.1 核心定义

分治（Divide and Conquer）将原问题分解为若干个规模相等、结构相同、**相互独立**的子问题，递归求解每个子问题，最后合并结果。

```
分解（Divide） → 求解（Conquer） → 合并（Combine）
```

### 3.2 与动态规划的区别

| 维度 | 分治 | 动态规划 |
|:-----|:----:|:--------:|
| 子问题关系 | **独立**，无重叠 | **重叠** |
| 求解方式 | 递归 | 填表 / 记忆化搜索 |
| 典型问题 | 归并排序、二分查找 | 背包问题、LCS |

### 3.3 经典算法

| 算法 | 递推式 | 复杂度 |
|------|--------|:------:|
| 归并排序 | T(n) = 2T(n/2) + O(n) | O(n log n) |
| 快速排序 | T(n) = 2T(n/2) + O(n) | O(n log n) 平均 |
| 二分查找 | T(n) = T(n/2) + O(1) | O(log n) |
| Karatsuba 大整数乘法 | T(n) = 3T(n/2) + O(n) | O(n^1.585) |
| Strassen 矩阵乘法 | T(n) = 7T(n/2) + O(n²) | O(n^2.807) |
| 最近点对 | — | O(n log n) |

### 3.4 归并排序 Java 实现

```java
/**
 * 归并排序（分治思想）
 * 分解 → 递归排序 → 合并
 * 时间复杂度：O(n log n)，空间复杂度：O(n)
 */
public class MergeSort {
    public void sort(int[] arr) {
        if (arr == null || arr.length <= 1) return;
        int[] temp = new int[arr.length];
        mergeSort(arr, 0, arr.length - 1, temp);
    }

    private void mergeSort(int[] arr, int left, int right, int[] temp) {
        if (left >= right) return;
        int mid = left + (right - left) / 2;
        mergeSort(arr, left, mid, temp);
        mergeSort(arr, mid + 1, right, temp);
        merge(arr, left, mid, right, temp);
    }

    private void merge(int[] arr, int left, int mid, int right, int[] temp) {
        int i = left, j = mid + 1, k = 0;
        while (i <= mid && j <= right) {
            temp[k++] = arr[i] <= arr[j] ? arr[i++] : arr[j++];
        }
        while (i <= mid) temp[k++] = arr[i++];
        while (j <= right) temp[k++] = arr[j++];
        System.arraycopy(temp, 0, arr, left, k);
    }
}
```

## 4. 动态规划

### 4.1 核心定义

动态规划（DP）将复杂问题分解为重叠的子问题，通过存储子问题的最优解（记忆化），避免重复计算。

### 4.2 DP 三要素

| 要素 | 说明 |
|------|------|
| **状态定义** | 明确 `dp[i]` 或 `dp[i][j]` 表示什么 |
| **状态转移方程** | 子问题间的关联关系（核心步骤） |
| **边界条件** | 基础子问题的解（Base Case） |

### 4.3 DP 解题五部曲

1. 定义状态 `dp[i]` 表示什么
2. 推导状态转移方程
3. 确定初始值（Base Case）
4. 确定遍历顺序
5. 举例推导验证

### 4.4 适用条件

| 条件 | 说明 |
|------|------|
| **重叠子问题** | 不同子问题包含相同的更小子问题 |
| **最优子结构** | 全局最优解包含子问题最优解 |
| **无后效性** | 某一步的决策不影响后续子问题的求解 |

### 4.5 经典 DP 问题

| 问题 | 状态定义 | 转移方程 |
|------|----------|----------|
| **斐波那契** | `dp[i]` = 第 i 个斐波那契数 | `dp[i] = dp[i-1] + dp[i-2]` |
| **最长递增子序列（LIS）** | `dp[i]` = 以 i 结尾的 LIS 长度 | `dp[i] = max(dp[j] + 1)`，`j < i 且 a[j] < a[i]` |
| **最长公共子序列（LCS）** | `dp[i][j]` = X[0..i-1] 和 Y[0..j-1] 的 LCS 长度 | 相等 `dp[i-1][j-1]+1`，否则 `max(dp[i-1][j], dp[i][j-1])` |
| **0/1 背包** | `dp[i][w]` = 前 i 件、容量 w 的最大价值 | `max(dp[i-1][w], dp[i-1][w-w_i] + v_i)` |
| **编辑距离** | `dp[i][j]` = word1[0..i] → word2[0..j] | 插入/删除/替换取最小 |

### 4.6 0/1 背包模板

```java
/**
 * 0/1 背包问题
 * 二维 → 滚动数组优化
 */
public int knapsack(int[] weight, int[] value, int capacity) {
    int n = weight.length;
    int[] dp = new int[capacity + 1];

    for (int i = 0; i < n; i++) {
        // 倒序遍历，保证每个物品只用一次
        for (int j = capacity; j >= weight[i]; j--) {
            dp[j] = Math.max(dp[j], dp[j - weight[i]] + value[i]);
        }
    }
    return dp[capacity];
}
```

### 4.7 DP vs 贪心 vs 分治

| 维度 | 分治 | 动态规划 | 贪心 |
|:-----|:----:|:--------:|:----:|
| 子问题关系 | 独立、不重叠 | 重叠 | 无子问题 |
| 记忆化 | 无 | 有 | 无 |
| 决策方式 | 分而治之 | 全局考虑 | 局部最优 |
| 适用条件 | 可拆分+合并简单 | 最优子结构+无后效性 | 贪心选择性质 |

## 5. 贪心算法

### 5.1 核心定义

贪心算法每一步决策都选择当前状态下的局部最优解，逐步累积得到全局最优解。

> 注意：并非所有场景都适用，需满足**贪心选择性质**（局部最优可推出全局最优）。

### 5.2 经典贪心算法

| 问题 | 贪心策略 | 时间复杂度 |
|:-----|----------|:----------:|
| 活动安排 | 按结束时间升序，优先选最早结束 | O(n log n) |
| 哈夫曼编码 | 每次取最小频率的两节点合并 | O(n log n) |
| Prim 算法 | 每次选连接已访问集合的最小权边 | O(n²) / O(E log V) |
| Kruskal 算法 | 边排序 + 并查集判环 | O(E log E) |
| Dijkstra 算法 | 每次选未访问中 dist 最小的点 | O(n²) / O(E log V) |
| 部分背包 | 按单位价值降序选取 | O(n log n) |

### 5.3 贪心反例

硬币面额 {1, 3, 4}，兑换 6 元：
- 贪心：4 + 1 + 1 = 3 枚
- 最优：3 + 3 = 2 枚
- 此时贪心失效，需用动态规划

## 6. 回溯法

### 6.1 核心定义

回溯法是一种 **"试错-回退-再试"** 的搜索算法，本质是深度优先搜索（DFS）的延伸，结合**剪枝**优化减少无效搜索。

### 6.2 核心构成

| 构成 | 说明 |
|:----|------|
| **路径** | 当前已经选择的候选元素（部分解） |
| **可选列表** | 当前状态下可以选择的候选元素 |
| **终止条件** | 判断当前路径是否已构成有效解 |
| **剪枝条件** | 提前排除不可能产生有效解的分支 |

### 6.3 通用模板

```java
/**
 * 回溯算法通用模板
 * 核心：选 → 探 → 撤 三步循环
 */
void backtrack(路径, 可选列表) {
    if (满足终止条件) {
        保存结果;
        return;
    }
    for (选择 : 可选列表) {
        if (剪枝条件) continue;       // 剪枝
        做选择（加入路径）;
        backtrack(路径, 新的可选列表); // 递归探索
        撤销选择（移除路径）;           // 回溯
    }
}
```

### 6.4 经典实例

**组合问题（LeetCode 77）**：

```java
class Combine {
    List<List<Integer>> result = new ArrayList<>();
    List<Integer> path = new ArrayList<>();

    public List<List<Integer>> combine(int n, int k) {
        backtrack(n, k, 1);
        return result;
    }

    private void backtrack(int n, int k, int start) {
        if (path.size() == k) {
            result.add(new ArrayList<>(path));          // 保存结果
            return;
        }
        // 剪枝：剩余元素不足时提前退出
        for (int i = start; i <= n - (k - path.size()) + 1; i++) {
            path.add(i);                                 // 选
            backtrack(n, k, i + 1);                      // 探
            path.remove(path.size() - 1);                // 撤
        }
    }
}
```

**全排列（LeetCode 46）**：

```java
class Permute {
    List<List<Integer>> result = new ArrayList<>();
    List<Integer> path = new ArrayList<>();
    boolean[] used;

    public List<List<Integer>> permute(int[] nums) {
        used = new boolean[nums.length];
        backtrack(nums);
        return result;
    }

    private void backtrack(int[] nums) {
        if (path.size() == nums.length) {
            result.add(new ArrayList<>(path));
            return;
        }
        for (int i = 0; i < nums.length; i++) {
            if (used[i]) continue;  // 剪枝：跳过已选元素
            used[i] = true;
            path.add(nums[i]);
            backtrack(nums);
            path.remove(path.size() - 1);
            used[i] = false;
        }
    }
}
```

### 6.5 适用场景

| 类别 | 典型问题 |
|:-----|----------|
| **组合/子集类** | 组合、子集、组合总和 |
| **排列类** | 全排列、电话号码字母组合 |
| **约束满足类** | N 皇后、数独求解、图着色 |
| **路径/分割类** | 迷宫寻路、分割回文串、复原 IP 地址 |

### 6.6 优缺点

| 优点 | 缺点 |
|:----|:-----|
| 思路简洁直观，"选-探-撤"三步适配各类问题 | 时间复杂度高，最坏 O(n!) 或 O(2ⁿ) |
| 灵活性强，可通过剪枝操作灵活优化 | 空间复杂度高，递归栈 + 存储路径 |
| 适用性广，覆盖组合、排列、分割、约束等场景 | 解空间极大时不可用 |

## 7. 分支限界法

### 7.1 核心思想

分支限界法是一种 **"广度优先搜索 + 剪枝"** 的算法，通过限界函数剪去不可能得到最优解的分支。

### 7.2 回溯 vs 分支限界

| 维度 | 回溯法 | 分支限界法 |
|:-----|:------:|:----------:|
| 搜索策略 | 深度优先 | 广度优先 / 最小成本优先 |
| 目标 | 找所有解 | 找最优解 |
| 队列 | — | FIFO 队列 / 优先队列 |
| 剪枝依据 | 约束函数 | 限界函数 |

### 7.3 0/1 背包的分支限界解法

```java
/**
 * 分支限界法解 0/1 背包
 * 使用优先队列按 bound 排序
 */
public class KnapsackBB {
    static class Node {
        int level, profit, weight;
        double bound;
        Node(int l, int p, int w) {
            level = l; profit = p; weight = w;
        }
    }

    public int knapsack(int[] w, int[] v, int cap) {
        int n = w.length;
        PriorityQueue<Node> pq = new PriorityQueue<>(
            (a, b) -> Double.compare(b.bound, a.bound)
        );

        Node root = new Node(-1, 0, 0);
        root.bound = bound(root, w, v, cap);
        pq.offer(root);
        int maxProfit = 0;

        while (!pq.isEmpty()) {
            Node curr = pq.poll();
            if (curr.bound <= maxProfit) continue;

            int level = curr.level + 1;
            // 选
            Node left = new Node(level, curr.profit + v[level], curr.weight + w[level]);
            if (left.weight <= cap) {
                maxProfit = Math.max(maxProfit, left.profit);
                left.bound = bound(left, w, v, cap);
                if (left.bound > maxProfit) pq.offer(left);
            }
            // 不选
            Node right = new Node(level, curr.profit, curr.weight);
            right.bound = bound(right, w, v, cap);
            if (right.bound > maxProfit) pq.offer(right);
        }
        return maxProfit;
    }

    private double bound(Node node, int[] w, int[] v, int cap) {
        int level = node.level + 1, profit = node.profit, weight = node.weight;
        while (level < w.length && weight + w[level] <= cap) {
            profit += v[level];
            weight += w[level];
            level++;
        }
        if (level < w.length) {
            profit += (cap - weight) * (double) v[level] / w[level];
        }
        return profit;
    }
}
```

## 8. DFS / BFS 核心总结与模板

### 8.1 核心本质

| 搜索 | 本质 | 数据结构 | 适用场景 |
|:-----|:-----|:--------:|----------|
| **DFS（深度优先）** | 一路到底，碰壁回溯 | 栈（递归/手动栈） | 枚举方案、连通块、回溯、树遍历 |
| **BFS（广度优先）** | 层层扩散，按层遍历 | 队列 | 无权图最短路径、最少步数、层序遍历 |

### 8.2 关键对比

| 特性 | DFS | BFS |
|:-----|:---:|:---:|
| 数据结构 | 栈（递归 / Stack） | 队列（Queue） |
| 搜索顺序 | 深度优先 | 层次优先 |
| 最短路径 | 不保证 | 一定保证（无权图） |
| 访问标记 | 递归进入标记，回溯可能撤销 | 入队立即标记 |
| 空间复杂度 | O(h) — 递归深度 | O(w) — 同层最大宽度 |
| 代表题型 | 岛屿、子集、排列、回溯 | 单词接龙、迷宫、层序遍历 |

### 8.3 DFS 递归模板

```java
void dfs(int x, int y) {
    // 1. 边界终止条件
    if (越界 / 不合法) return;
    // 2. 标记已访问
    visited[x][y] = true;
    // 3. 遍历所有方向/邻接节点
    for (方向) {
        int nx = x + dx[i];
        int ny = y + dy[i];
        if (合法且未访问) {
            dfs(nx, ny);
        }
    }
    // 4. 回溯（需要枚举所有方案时才撤销）
    visited[x][y] = false;
}
```

### 8.4 DFS 迭代模板（手动栈）

```java
Deque<Node> stack = new ArrayDeque<>();
stack.push(start);
visited[start] = true;

while (!stack.isEmpty()) {
    Node cur = stack.pop();
    // 处理当前节点
    for (Node neighbor : cur.neighbors) {
        if (!visited[neighbor]) {
            visited[neighbor] = true;
            stack.push(neighbor);
        }
    }
}
```

### 8.5 BFS 标准模板（最短路径专用）

```java
Queue<Node> queue = new LinkedList<>();
queue.offer(start);
visited[start] = true;
int step = 0;

while (!queue.isEmpty()) {
    int size = queue.size();
    for (int i = 0; i < size; i++) {    // 按层遍历
        Node cur = queue.poll();
        if (cur == target) return step;  // 到达终点，返回步数

        for (Node neighbor : cur.neighbors) {
            if (!visited[neighbor]) {
                visited[neighbor] = true;
                queue.offer(neighbor);
            }
        }
    }
    step++;  // 一层遍历完，步数 +1
}
```

### 8.6 刷题选择口诀

- 求**最短、最少步数、最小次数** → BFS
- 求**所有方案、组合、排列、连通块** → DFS
- 矩阵/网格类：两种都可，求最短用 BFS
- 数据量大、递归深度深 → 用迭代 DFS / BFS，避免栈溢出

### 8.7 DFS 应用场景

| 类别 | 典型问题 |
|:-----|----------|

| 图论 | 判断环、拓扑排序、寻找所有可达路径 |

### 8.8 BFS 应用场景

## 9. 剪枝算法

### 9.1 核心定义

剪枝是一种通用的**优化策略**，通过提前识别并删除"无效、冗余或不可能产生最优解"的分支，减少计算复杂度。

> 如同修剪果树，剪掉不结果的枝条，让养分集中供给有效枝条。剪枝算法则"剪掉"无效的计算路径，让计算资源集中在有价值的部分。

### 9.2 核心分类

#### 按剪枝策略分类

| 策略 | 核心逻辑 | 典型场景 |
|:-----|----------|----------|
| **可行性剪枝** | 违反约束则剪枝 | N 皇后冲突判断 |
| **最优性剪枝** | 无法超越已知最优解则剪枝 | TSP 分支限界 |
| **启发式剪枝** | 基于启发函数估值的剪枝 | Alpha-Beta 剪枝 |

#### 决策树中的剪枝

| 剪枝方法 | 剪枝方式 | 计算复杂度 | 说明 |
|:---------|:--------:|:----------:|------|
| **预剪枝（Pre-pruning）** | 自上而下 | 低 | 生成过程中提前终止分支生长 |
| **后剪枝（Post-pruning）** | 自下而上 | 高 | 生成完整树后删除贡献小的分支 |
| **CCP（代价复杂剪枝）** | 自底向上 | O(n²) | 权衡模型复杂度与预测误差 |

### 9.3 经典剪枝案例

**N 皇后问题中的可行性剪枝**：

```java
public int solveNQueens(int n) {
    int[] board = new int[n];  // board[row] = col
    return backtrack(0, n, board);
}

private int backtrack(int row, int n, int[] board) {
    if (row == n) return 1;
    int count = 0;
    for (int col = 0; col < n; col++) {
        if (!isSafe(row, col, board)) continue;  // 可行性剪枝
        board[row] = col;
        count += backtrack(row + 1, n, board);
        // 回溯（数组值会被覆盖，无需额外操作）
    }
    return count;
}

private boolean isSafe(int row, int col, int[] board) {
    for (int i = 0; i < row; i++) {
        if (board[i] == col ||
            Math.abs(board[i] - col) == Math.abs(i - row)) {
            return false;
        }
    }
    return true;
}
```

### 9.4 剪枝条件设计原则

| 剪枝类型 | 设计原则 |
|:---------|----------|
| 可行性剪枝 | 条件严格匹配问题约束，确保剪枝的分支一定无有效解 |
| 最优性剪枝 | 需实时更新最优解，确保判断准确 |
| 启发式剪枝 | 启发函数需合理，兼顾乐观估计和计算效率 |

## 10. 随机化算法

### 10.1 核心思想

引入随机因素，降低最坏情况复杂度或解决确定性问题。

```java
/**
 * 随机化快排（随机选 pivot，避免最坏 O(n²)）
 */
public class RandomizedQuickSort {
    public void sort(int[] arr) {
        quickSort(arr, 0, arr.length - 1);
    }

    private void quickSort(int[] arr, int left, int right) {
        if (left >= right) return;
        int pivotIndex = randomizedPartition(arr, left, right);
        quickSort(arr, left, pivotIndex - 1);
        quickSort(arr, pivotIndex + 1, right);
    }

    private int randomizedPartition(int[] arr, int left, int right) {
        int randIdx = left + (int)(Math.random() * (right - left + 1));
        swap(arr, randIdx, right);
        return partition(arr, left, right);
    }
    // ... partition 实现同标准快排
}
```

## 11. 字符串算法

### 11.1 KMP 算法

KMP 算法是高效的字符串匹配算法，核心是利用**部分匹配表（next 数组）**，匹配失败时主串指针不回溯，模式串智能回退。

| 特性 | 暴力匹配 | KMP |
|:-----|:--------:|:---:|
| 时间复杂度 | O(n × m) | **O(n + m)** |
| 主串指针 | 回溯 | **永不回溯** |
| 预处理 | 无 | next 数组 O(m) |

```java
/**
 * KMP 算法完整实现
 */
public class KMP {
    /**
     * 构建 next 数组（部分匹配表）
     * next[i] = 子串 s[0..i] 的最长相等前后缀长度
     */
    public int[] buildNext(String pattern) {
        int m = pattern.length();
        int[] next = new int[m];
        int j = 0;
        for (int i = 1; i < m; i++) {
            while (j > 0 && pattern.charAt(i) != pattern.charAt(j)) {
                j = next[j - 1];
            }
            if (pattern.charAt(i) == pattern.charAt(j)) {
                j++;
            }
            next[i] = j;
        }
        return next;
    }

    /**
     * KMP 匹配 — 返回首次匹配位置
     */
    public int kmpSearch(String text, String pattern) {
        int n = text.length(), m = pattern.length();
        if (m > n) return -1;
        int[] next = buildNext(pattern);
        int j = 0;
        for (int i = 0; i < n; i++) {
            while (j > 0 && text.charAt(i) != pattern.charAt(j)) {
                j = next[j - 1];
            }
            if (text.charAt(i) == pattern.charAt(j)) {
                j++;
            }
            if (j == m) {
                return i - m + 1;
            }
        }
        return -1;
    }

    /**
     * KMP 匹配 — 查找所有匹配位置
     */
    public List<Integer> kmpFindAll(String text, String pattern) {
        List<Integer> indices = new ArrayList<>();
        int n = text.length(), m = pattern.length();
        if (m > n) return indices;
        int[] next = buildNext(pattern);
        int j = 0;
        for (int i = 0; i < n; i++) {
            while (j > 0 && text.charAt(i) != pattern.charAt(j)) {
                j = next[j - 1];
            }
            if (text.charAt(i) == pattern.charAt(j)) {
                j++;
            }
            if (j == m) {
                indices.add(i - m + 1);
                j = next[j - 1];  // 查找重叠匹配
            }
        }
        return indices;
    }
}
```

### 11.2 字符串算法对比

| 算法 | 时间复杂度 | 空间复杂度 | 核心思想 | 适用场景 |
|:-----|:----------:|:----------:|----------|----------|
| **朴素匹配** | O(n×m) | O(1) | 逐字符比较 | 短串匹配 |
| **KMP** | O(n+m) | O(m) | 前缀函数，主串不回溯 | 长文本匹配 |
| **Boyer-Moore** | O(n/m)~O(n×m) | O(m+k) | 坏字符+好后缀规则 | 实际场景高效 |
| **Rabin-Karp** | O(n+m) 平均 | O(1) | 滚动哈希 | 多模式串匹配 |
| **Trie 字典树** | O(L) 查找 | O(字母表×L×N) | 多叉树逐字符 | 自动补全、拼写检查 |
| **AC 自动机** | O(n+z) | O(m) | Trie + 失败指针 | 多模式串匹配 |
| **Manacher** | O(n) | O(n) | 回文半径数组 | 最长回文子串 |
| **Z 函数** | O(n) | O(n) | LCP 数组 | 模式匹配、子串出现次数 |

### 12.1 双指针

分类：

**典型题**：两数之和（有序数组）、三数之和、判断链表环、反转链表。

### 12.2 滑动窗口

```java
/**
 * 滑动窗口通用模板
 */
int left = 0, right = 0;
while (right < n) {
    // 扩大窗口：加入 right 元素
    while (窗口需要收缩) {
        // 缩小窗口：移除 left 元素
        left++;
    }
    // 更新结果
    right++;
}
```

**典型题**：最长无重复子串、最小覆盖子串、滑动窗口最大值。

### 12.3 前缀和

**核心公式**：区间和 = 前缀和[右] - 前缀和[左-1]

| 类型 | 适用场景 |
|:-----|----------|
| 一维前缀和 | 数组区间和查询 |
| 二维前缀和 | 矩阵子矩阵和 |

**典型题**：子数组和为 k、二维矩阵子矩阵和、多次区间和查询。

### 12.4 位运算常用技巧

| 技巧 | 运算 | 说明 |
|:-----|:----:|------|
| 判断奇偶 | `n & 1` | 结果为 1 为奇数 |
| 消除最低位 1 | `n & (n - 1)` | 可用于统计二进制 1 的个数 |

### 12.5 二分答案

```
解题框架：
1. 确定答案取值范围 [left, right]
2. while (left < right)：
    mid = left + (right - left) / 2
    if (check(mid)) right = mid  // mid 可行，尝试更小
    else left = mid + 1           // mid 不可行，尝试更大
3. 返回 left
```

**关键**：答案需满足**单调性**，且验证函数需高效。

**典型题**：珂珂吃香蕉、分割数组的最大值、寻找峰值。

## 13. 三大核心算法思想对比

### 13.1 贪心 vs 动态规划 vs 分治

| 维度 | 贪心算法 | 动态规划 | 分治算法 |
|:-----|:--------:|:--------:|:--------:|
| **决策方式** | 局部最优 → 全局最优 | 全局考虑，存储子问题解 | 分解-求解-合并 |
| **记忆化** | 无 | 有 | 无 |
| **子问题关系** | 无重叠 | 重叠 | 独立无重叠 |
| **适用条件** | 贪心选择性质 | 最优子结构+无后效性 | 可拆分+合并简单 |
| **典型问题** | 活动选择、哈夫曼编码 | 背包问题、LCS | 归并排序、二分查找 |

### 13.2 回溯 vs 分支限界

| 维度 | 回溯法 | 分支限界法 |
|:-----|:------:|:----------:|
| 搜索策略 | 深度优先 | 广度优先 / 最小成本优先 |
| 目标 | 找所有可行解 | 找最优解 |
| 剪枝依据 | 约束函数 | 限界函数 |
| 使用队列 | 隐式（递归栈） | 显式（FIFO / 优先队列） |

## 14. 算法选择指南

### 14.1 按场景选择

| 场景 | 推荐算法思想 | 原因 |
|:-----|-------------|------|
| 追求效率、解空间小 | 枚举算法 | 最简单直接 |
| 局部最优可推全局最优 | 贪心算法 | 高效但不一定正确需证明 |
| 子问题重叠、需全局最优 | 动态规划 | 空间换时间，避免重复计算 |
| 子问题独立、可拆分合并 | 分治算法 | 分解-解决-合并典型模式 |
| 需所有可行解、可剪枝 | 回溯算法 | 试探+回退的通用解空间搜索 |
| 快速查找、去重 | 哈希算法 | O(1) 操作 |
| 求最短/最少步数 | BFS | 首次到达即最优解 |
| 求所有路径/连通性 | DFS | 深度探索优先 |

### 14.2 按时间复杂度选择

| 数据规模 | 可接受复杂度 | 推荐算法 |
|:---------|:------------:|----------|
| n ≤ 20 | O(2ⁿ), O(n!) | 回溯（暴力搜索） |
| n ≤ 100 | O(n⁴) | 动态规划（基本） |
| n ≤ 1000 | O(n²) | 贪心、动态规划（O(n²)） |
| n ≤ 10⁵ | O(n log n) | 分治、堆排序、Dijkstra |
| n ≤ 10⁷ | O(n) | 哈希、线性遍历 |
| n 极大 | O(log n), O(1) | 二分查找、哈希 |

### 14.3 实际建议

1. **排序算法**：小规模/有序数据优先选插入排序，通用高效选快速排序，稳定排序选归并排序
2. **查找算法**：无序用线性查找，有序用二分查找，高频读写用哈希查找，有序动态数据用树表查找
3. **算法思想**：分治（拆分子问题）、贪心（局部最优）、动态规划（重叠子问题+最优子结构）、回溯（试错+剪枝）是四大核心思路

---

> **核心总结**：算法设计思想的核心是"解决问题的思路"，不同思想适用于不同场景。实际应用中常将多种算法思想结合（如回溯+剪枝、动态规划+哈希），关键是根据问题的约束条件和数据规模选择最合适的算法思想，优化时间和空间复杂度。掌握回溯通用模板、DFS/BFS 模板、KMP next 数组构建等核心模板，能显著提升编码效率和解题能力。
