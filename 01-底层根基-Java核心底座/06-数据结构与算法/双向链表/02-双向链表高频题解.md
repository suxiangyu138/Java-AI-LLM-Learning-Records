## 1. 460. LFU 缓存（双哈希 + 双向链表）

### 1.1 题目与思路

```
LFU：淘汰"频次最低且最久未用"的元素
结构（01 模块 4 节）：双哈希嵌套
  key → 节点（定位）
  频次 → LRU 链（同频次内按 LRU）
  minFreq 维护（空链提升）
⚠️ 这是最复杂的缓存设计题（hard）
```

### 1.2 完整代码

```java
/**
 * LeetCode 460. LFU 缓存
 */
class LFUCache {
    private static class Node {
        int key, val, freq;
        Node prev, next;
        Node(int k, int v) { key = k; val = v; freq = 1; }
    }

    private static class FreqList {          // ⚠️ 每条频次的 LRU 链
        Node head = new Node(0, 0);
        Node tail = new Node(0, 0);

        FreqList() { head.next = tail; tail.prev = head; }

        void addToTail(Node node) {
            node.prev = tail.prev;
            node.next = tail;
            tail.prev.next = node;
            tail.prev = node;
        }

        void remove(Node node) {
            node.prev.next = node.next;
            node.next.prev = node.prev;
        }

        boolean isEmpty() { return head.next == tail; }
    }

    private final Map<Integer, Node> nodes = new HashMap<>();
    private final Map<Integer, FreqList> freqLists = new HashMap<>();
    private final int capacity;
    private int minFreq = 0;

    public LFUCache(int capacity) {
        this.capacity = capacity;
    }

    public int get(int key) {
        Node node = nodes.get(key);
        if (node == null) return -1;
        touch(node);                          // ⚠️ 访问提升频次
        return node.val;
    }

    public void put(int key, int value) {
        if (capacity == 0) return;
        Node node = nodes.get(key);
        if (node != null) {
            node.val = value;
            touch(node);
            return;
        }
        if (nodes.size() == capacity) evict();      // ⚠️ 超容量淘汰
        Node newNode = new Node(key, value);
        nodes.put(key, newNode);
        freqLists.computeIfAbsent(1, k -> new FreqList()).addToTail(newNode);
        minFreq = 1;                          // ⚠️ 新节点频次 1 → minFreq 重置
    }

    /** ⚠️ 访问：频次 +1，跨链移动 */
    private void touch(Node node) {
        FreqList oldList = freqLists.get(node.freq);
        oldList.remove(node);
        if (oldList.isEmpty() && node.freq == minFreq) minFreq++;  // ⚠️ 空链提升

        node.freq++;
        freqLists.computeIfAbsent(node.freq, k -> new FreqList())
                .addToTail(node);
    }

    /** 淘汰：minFreq 链的头（最久未用） */
    private void evict() {
        FreqList list = freqLists.get(minFreq);
        Node victim = list.head.next;         // ⚠️ 链头 = 最久未用
        list.remove(victim);
        nodes.remove(victim.key);
    }
}
// 推演 cap=2：put(1,1) put(2,2) get(1) put(3,3)
//   put(1)：freq1 链 [1]；put(2)：freq1 链 [1,2]
//   get(1)：1 → freq2 链 [1]；minFreq=1
//   put(3)：超容量 → 淘汰 minFreq=1 链头 2 ✓（频次最低）
// ⚠️ 复杂度：全部 O(1)
// ⚠️ 面试必答："460 = 双哈希嵌套 + minFreq——
//   '频次 → LRU 链'每条链内部还是 LRU 语义；
//   minFreq 只在'空链且最小'时提升。"
```

## 2. 641. 设计循环双端队列

### 2.1 题目与思路

```
前后都可插入删除的循环队列
双实现：循环数组（取模下标）或双向链表（哨兵）
⚠️ 01 模块 5 节循环数组要点；此处给完整实现
```

### 2.2 完整代码（双向链表版）

```java
/**
 * LeetCode 641. 设计循环双端队列（双向链表版）
 */
class MyCircularDeque {
    private static class Node {
        int val;
        Node prev, next;
        Node(int v) { val = v; }
    }

    private final Node head = new Node(0);   // ⚠️ 哨兵
    private final Node tail = new Node(0);
    private final int capacity;
    private int size = 0;

    public MyCircularDeque(int k) {
        capacity = k;
        head.next = tail;                    // ⚠️ 哨兵互指
        tail.prev = head;
    }

    public boolean insertFront(int value) {
        if (isFull()) return false;
        Node node = new Node(value);
        // ⚠️ 头插：head ↔ node ↔ 原第一个
        node.next = head.next;
        node.prev = head;
        head.next.prev = node;
        head.next = node;
        size++;
        return true;
    }

    public boolean insertLast(int value) {
        if (isFull()) return false;
        Node node = new Node(value);
        // 尾插：node ↔ tail
        node.prev = tail.prev;
        node.next = tail;
        tail.prev.next = node;
        tail.prev = node;
        size++;
        return true;
    }

    public boolean deleteFront() {
        if (isEmpty()) return false;
        head.next = head.next.next;          // 跳过第一个
        head.next.prev = head;
        size--;
        return true;
    }

    public boolean deleteLast() {
        if (isEmpty()) return false;
        tail.prev = tail.prev.prev;
        tail.prev.next = tail;
        size--;
        return true;
    }

    public int getFront() { return isEmpty() ? -1 : head.next.val; }
    public int getRear() { return isEmpty() ? -1 : tail.prev.val; }
    public boolean isEmpty() { return size == 0; }
    public boolean isFull() { return size == capacity; }
}
// ⚠️ 面试必答："641 链表版 = 哨兵 + 四操作——
//   头插尾插/头删尾删都是 O(1)；
//   size 判断空满（哨兵版不用 head==tail 二义）。"
```

## 3. 1472. 设计浏览器历史记录

### 3.1 题目与思路

```
浏览器前进/后退（访问新页清空前进历史）
双向链表模拟（或双栈）：
  当前页 = 指针位置；访问 = 截断 + 插入
⚠️ 关键：visit 清空"前进部分"（截断链表）
```

### 3.2 完整代码（双向链表版）

```java
/**
 * LeetCode 1472. 设计浏览器历史记录（双向链表）
 */
class BrowserHistory {
    private static class Node {
        String url;
        Node prev, next;
        Node(String u) { url = u; }
    }

    private Node cur;                        // ⚠️ 当前页指针

    public BrowserHistory(String homepage) {
        cur = new Node(homepage);
    }

    public void visit(String url) {
        Node node = new Node(url);
        cur.next = node;                     // ⚠️ 新页接在后面
        node.prev = cur;
        cur = node;                          // 前进
        // ⚠️ 新节点没有 next → 前进历史自动清空（截断）
    }

    public String back(int steps) {
        while (steps-- > 0 && cur.prev != null) cur = cur.prev;   // 回退
        return cur.url;
    }

    public String forward(int steps) {
        while (steps-- > 0 && cur.next != null) cur = cur.next;   // 前进
        return cur.url;
    }
}
// 推演 visit("a") visit("b") back(1) visit("c")：
//   cur: home → a → b → back → a → visit c → a → c
//   ⚠️ visit(c) 后 b 的前进路径被截断（c.next = null）
//   forward 不会回到 b ✓
// ⚠️ 面试必答："1472 = 双向链表指针模拟——
//   visit 截断前进（新节点无 next）；
//   back/forward 是双指针移动，O(步数)。"
```

## 4. 138. 复制带随机指针的链表

### 4.1 题目与思路

```
深拷贝链表（next + random 指针）
三解法：
  ① 哈希：旧节点 → 新节点（O(n) 空间）
  ② 原地：新旧交错插入 → 补 random → 拆开（O(1) 空间）⭐
⚠️ 原地法的三阶段是经典技巧
```

### 4.2 完整代码（原地法）

```java
/**
 * LeetCode 138. 复制带随机指针的链表（原地法 O(1) 空间）
 */
public Node copyRandomList(Node head) {
    if (head == null) return null;

    // ① 新旧交错：1 → 1' → 2 → 2' → ...
    Node cur = head;
    while (cur != null) {
        Node copy = new Node(cur.val);
        copy.next = cur.next;                // 新节点插在旧节点后
        cur.next = copy;
        cur = copy.next;
    }

    // ② 补 random：新节点的 random = 旧节点 random 的 next
    cur = head;
    while (cur != null) {
        if (cur.random != null) {
            cur.next.random = cur.random.next;   // ⚠️ 镜像映射
        }
        cur = cur.next.next;
    }

    // ③ 拆开：新旧链表分离
    Node dummy = new Node(0);
    Node tail = dummy;
    cur = head;
    while (cur != null) {
        Node copy = cur.next;                // 新节点
        tail.next = copy;
        tail = copy;
        cur.next = copy.next;                // 还原旧链
        cur = cur.next;
    }
    return dummy.next;
}
// 推演 1→2→3（random: 2→1, 3→3）：
//   交错后：1→1'→2→2'→3→3'
//   random 补：2'.random = 1'.next? 不——2.random=1 → 2'.random = 1' ✓
//   拆开：1→2→3 与 1'→2'→3' ✓
// ⚠️ 面试必答："138 原地法三阶段——
//   交错插入、random 镜像（旧.next.random = 旧.random.next）、
//   拆开还原。O(1) 空间优于哈希法。"
```

## 5. 146. LRU 缓存（回顾 + 变体）

### 5.1 完整回顾（哨兵 + 哈希）

```java
/**
 * LeetCode 146. LRU 缓存（完整实现）
 * ⚠️ 完整注释见设计/02；此处给出最短正确版
 */
class LRUCache {
    private static class Node {
        int key, val;
        Node prev, next;
        Node(int k, int v) { key = k; val = v; }
    }

    private final Map<Integer, Node> map = new HashMap<>();
    private final Node head = new Node(0, 0), tail = new Node(0, 0);
    private final int capacity;

    public LRUCache(int capacity) {
        this.capacity = capacity;
        head.next = tail; tail.prev = head;
    }

    public int get(int key) {
        Node node = map.get(key);
        if (node == null) return -1;
        moveToTail(node);                    // ⚠️ 访问刷新
        return node.val;
    }

    public void put(int key, int value) {
        Node node = map.get(key);
        if (node != null) {
            node.val = value;
            moveToTail(node);
            return;
        }
        node = new Node(key, value);
        map.put(key, node);
        addToTail(node);
        if (map.size() > capacity) {
            Node oldest = head.next;
            removeNode(oldest);
            map.remove(oldest.key);          // ⚠️ 同步删哈希
        }
    }

    private void addToTail(Node node) {
        node.prev = tail.prev; node.next = tail;
        tail.prev.next = node; tail.prev = node;
    }
    private void removeNode(Node node) {
        node.prev.next = node.next; node.next.prev = node.prev;
    }
    private void moveToTail(Node node) {
        removeNode(node); addToTail(node);
    }
}
// ⚠️ 面试必答："146 三件套——哨兵链表（O(1) 边界）、
//   访问刷新（get/put 都 moveToTail）、
//   节点存 key（淘汰同步删哈希）。"
```

## 6. 双向链表方法论总结

### 6.1 解题框架

```
① 识别：需要 O(1) 插入删除 + 顺序 → 双向链表
② 设计：
   哨兵（边界统一）
   节点字段（key/val/freq 按需）
   哈希搭配（定位）
③ 操作：插入/删除/移动模板
④ 边界：空/满/单节点

⚠️ 识别信号：
  "缓存设计" → LRU/LFU 三件套
  "前后操作" → 双端队列
  "前进后退" → 指针模拟
  "深拷贝" → 交错插入
```
