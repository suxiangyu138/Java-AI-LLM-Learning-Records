## 1. 核心概念

### 1.1 什么是树状数组

> 树状数组（Fenwick Tree / BIT）：用数组 + **lowbit** 技巧实现"单点更新 + 前缀查询"均 O(log n) 的结构，代码比线段树简洁得多。

```
核心：lowbit(x) = x & (-x)（x 二进制最低位的 1）

tree[i] 管辖区间：(i - lowbit(i), i]（左开右闭）
例：tree[8]（1000₂，lowbit=8）管理 [0,8]
    tree[6]（0110₂，lowbit=2）管理 [4,6]

        1  2  3  4  5  6  7  8（下标）
tree:  [1][1,2][3][1..4][5][5,6][7][1..8]

操作：
  update(i, v)：i 及所有"上级" += v（i += lowbit(i)）
  query(i)：前缀和（i -= lowbit(i) 累加）
```

### 1.2 能解决什么

```
① 单点更新 + 前缀和查询（307 区域和检索）
② 逆序对计数（315 右侧更小元素）★ 高频
③ 动态第 K 小（配合二分）
④ 频次统计（值域排名）

vs 线段树：
  树状数组：代码短、常数小，但只支持"前缀"查询
  线段树：任意区间查询，功能更强
  → 能用树状数组就用它（更简单）
```

### 1.3 与线段树的选型

```
单点更新 + 前缀查询 → 树状数组（三行代码）
任意区间 + 区间更新 → 线段树（懒标记）
不可逆操作（max）→ 线段树

⚠️ 区间 [l, r] 查询 = query(r) - query(l-1)（可逆时）
  → 树状数组也能查任意区间（减法即可）
```

## 2. 完整代码模板

### 2.1 标准实现（307. 区域和检索）

```java
/**
 * LeetCode 307. 区域和检索 - 数组可修改（树状数组版）
 */
class FenwickTree {
    private int[] tree;
    private int n;

    public FenwickTree(int[] nums) {
        n = nums.length;
        tree = new int[n + 1];             // ⚠️ 1-indexed
        for (int i = 0; i < n; i++) {
            update(i + 1, nums[i]);        // 逐个插入
        }
    }

    // 单点更新：位置 i（1-indexed）加 delta
    public void update(int i, int delta) {
        for (; i <= n; i += lowbit(i)) {   // ⚠️ 向上更新所有上级
            tree[i] += delta;
        }
    }

    // 前缀和：前 i 个元素的和
    public int query(int i) {
        int sum = 0;
        for (; i > 0; i -= lowbit(i)) {    // ⚠️ 向下累加覆盖区间
            sum += tree[i];
        }
        return sum;
    }

    // 区间和 [l, r]（1-indexed）
    public int rangeSum(int l, int r) {
        return query(r) - query(l - 1);
    }

    private int lowbit(int x) {
        return x & (-x);                   // 最低位 1
    }
}
// 构建 O(n log n)（或 O(n) 前缀和优化）
// 单点更新/前缀查询均 O(log n)
```

### 2.2 推演：update(3, +5) 的路径

```
n = 8，update(3, 5)：
  i=3：tree[3] += 5；i += lowbit(3)=1 → i=4
  i=4：tree[4] += 5；i += lowbit(4)=4 → i=8
  i=8：tree[8] += 5；i += lowbit(8)=8 → i=16 > 8 结束
  更新了 tree[3], tree[4], tree[8]

query(6) 的路径：
  i=6：sum += tree[6]；i -= lowbit(6)=2 → i=4
  i=4：sum += tree[4]；i -= lowbit(4)=4 → i=0 结束
  sum = tree[6] + tree[4]
  tree[6] 管理 [4,6]，tree[4] 管理 [0,4] → 覆盖 [0,6] ✓
```

### 2.3 更新与查询的方向记忆

```
update：i += lowbit(i)（向上找"管辖我的"上级）
query：i -= lowbit(i)（向下累加"我管辖的"区间）

记忆口诀："加往上走，减往下收"
  ⚠️ 写反 → 死循环或错误结果（面试手写高频错误）
```

## 3. lowbit 详解

### 3.1 lowbit 的数学本质

```
lowbit(x) = x & (-x)：取 x 二进制最低位的 1

例：6 = 0110₂
  -6（补码）= 1010₂
  6 & (-6) = 0010 = 2 ✓

补码原理：
  -x = ~x + 1
  ~x：6 的位全反 → 1001
  +1：1010
  与 x 的与运算：只有最低位 1 保留（其余相反）

记忆："lowbit = 最低位 1 的值（2 的幂）"
```

### 3.2 lowbit 的应用

```
① 树状数组：update/query 的步长
② 二进制枚举：n & (n-1) 的姐妹技巧
③ 位运算技巧：判断 2 的幂（n & (n-1) == 0）

⚠️ lowbit(0) = 0 → 死循环！
  → 树状数组下标从 1 开始（0 无意义）
```

### 3.3 为什么 tree[i] 管辖 (i-lowbit(i), i]？

```
i 的二进制表示中最低位 1 的位置决定管辖范围：
  i = 6 (0110)：lowbit = 2 → 管辖 [4, 6]（2 个元素）
  i = 8 (1000)：lowbit = 8 → 管辖 [0, 8]（8 个元素）

直觉：i 的二进制"能整除 2^k"的最大 k
  → 管辖 2^k 个元素

⚠️ 不必死记，理解"update 向上、query 向下"
  两个方向由 lowbit 步长驱动即可
```

## 4. 树状数组的经典应用

### 4.1 315. 右侧更小元素（逆序对）

```java
/**
 * LeetCode 315. 计算右侧小于当前元素的个数
 * 从右往左扫描 + 值域排名 + 树状数组计数
 */
public List<Integer> countSmaller(int[] nums) {
    // ① 离散化：值 → 排名（1-indexed）
    int[] sorted = nums.clone();
    Arrays.sort(sorted);
    Map<Integer, Integer> rank = new HashMap<>();
    for (int x : sorted) {
        rank.putIfAbsent(x, rank.size() + 1);
    }

    // ② 从右往左扫描
    FenwickTree bit = new FenwickTree(new int[rank.size() + 1]);
    List<Integer> result = new ArrayList<>();

    for (int i = nums.length - 1; i >= 0; i--) {
        int r = rank.get(nums[i]);
        // 已见过的元素中，排名 < r 的个数 = 右侧更小
        result.add(bit.query(r - 1));
        bit.update(r, 1);                // 当前值入树
    }
    Collections.reverse(result);         // 恢复顺序
    return result;
}
// 每个元素 update + query 各 O(log n) → O(n log n)
// ⚠️ 离散化：值域大 → 排名压缩（空间 O(n)）
```

### 4.2 逆序对计数的通用模式

```
"从右往左 + 树状数组"模式：
  ① 离散化值域（排名）
  ② 从右往左（或从左往右）扫描
  ③ query(排名-1) 统计已见更小/更大
  ④ update(排名, +1) 登记当前值

应用家族：
  315 右侧更小元素
  493 翻转对（查询条件变为 2×x）
  剑指 51 逆序对（统计全部）

⚠️ 为什么从右往左？
  右侧元素先入树 → 查询时树里只有右侧的
  → query(r-1) 自然得到"右侧更小"计数
```

### 4.3 动态第 K 小（树状数组 + 二分）

```java
/**
 * 动态有序统计：树状数组存频次 + 二分找第 K 小
 * findKth：二分排名，query(mid) ≥ k 的最小 mid
 */
public int findKth(FenwickTree bit, int n, int k) {
    int lo = 1, hi = n;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (bit.query(mid) >= k) {
            hi = mid;                    // 前缀和 ≥ k → 答案 ≤ mid
        } else {
            lo = mid + 1;
        }
    }
    return lo;
}
// 应用：动态插入 + 查第 K 小 → O(log² n)
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"右侧更小元素用树状数组：
 ① 值域先离散化成排名（1-indexed）；
 ② 从右往左扫描——update(排名,+1) 表示已见过，
    query(排名-1) 得到比它小的个数；
 ③ 每个元素 O(log n) → 总 O(n log n)。
 树状数组核心：lowbit 步长，update 向上、
 query 向下，代码只有三行。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | lowbit 怎么理解？ | x & (-x) 取最低位 1（补码原理） |
| 2 | update 向上、query 向下？ | 加往上传（上级都要加）、减往下收（累加管辖区间） |
| 3 | 为什么 1-indexed？ | lowbit(0)=0 会死循环 |
| 4 | 什么时候选树状数组？ | 单点更新+前缀查询；可逆操作（和/异或） |
| 5 | 离散化？ | 值域大 → 排名压缩（空间 O(n)） |
| 6 | 逆序对为什么从右往左？ | 右侧先入树 → query 自然得到右侧统计 |
| 7 | 与线段树选型？ | 前缀+可逆 → BIT 简单；区间+不可逆 → 线段树 |
| 8 | 动态第 K 小？ | BIT 存频次 + 二分查询（O(log² n)） |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 下标从 0 开始 | 死循环 | 1-indexed（i+1） |
| update/query 方向反 | 结果错 | 加向上、减向下 |
| 忘离散化 | 数组爆炸 | 排名映射 |
| 逆序对方向错 | 统计反 | 从右往左 |
| lowbit 写错 | 死循环 | x & (-x) |

> 🎯 **核心要点**：树状数组 = **lowbit + update 向上 + query 向下**三行核心。识别信号："单点更新+前缀查询、逆序对、右侧更小"。315 的"离散化 + 从右往左 + query(rank-1)"是模板级套路；与线段树的选型要能讲清。
