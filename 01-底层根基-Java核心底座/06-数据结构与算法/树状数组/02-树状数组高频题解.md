## 1. 307. 区域和检索（可修改）

### 1.1 题目与思路

```
单点修改 + 区间查询 → 树状数组标准题
⚠️ 对比 303（不可修改 → 前缀和即可）
  307 有 update → 前缀和 O(n) 修改不可行 → BIT O(log n)
```

### 1.2 完整代码

```java
/**
 * LeetCode 307. 区域和检索（树状数组）
 */
class NumArray {
    private final int[] tree;
    private final int[] nums;

    public NumArray(int[] nums) {
        this.nums = nums;
        tree = new int[nums.length + 1];
        for (int i = 0; i < nums.length; i++)
            update(i, nums[i]);               // ⚠️ 逐个建树
    }

    public void update(int index, int val) {
        int delta = val - nums[index];        // ⚠️ 差值更新
        nums[index] = val;
        for (int i = index + 1; i < tree.length; i += i & (-i))   // 1 基
            tree[i] += delta;
    }

    public int sumRange(int left, int right) {
        return prefix(right + 1) - prefix(left);   // ⚠️ 区间 = 前缀差
    }

    private int prefix(int i) {
        int sum = 0;
        while (i > 0) {
            sum += tree[i];
            i -= i & (-i);
        }
        return sum;
    }
}
// 推演 nums=[1,3,5]：树 [0,1,4,5,9]
//   sumRange(0,2) = prefix(3)-prefix(0) = 9-0 = 9 ✓
//   update(1,2)：delta=-1 → 更新 2,4 → 树 [0,1,3,5,8]
//   sumRange(0,2) = 8 ✓（1+2+5）
// ⚠️ 复杂度：update/sumRange 均 O(log n)
// ⚠️ 面试表达："307 是 BIT 的最小应用——
//   '单点改 + 区间查'直接套模板；
//   与 303 的对比体现'可修改'的价值。"
```

## 2. 剑指 51. 数组中的逆序对（BIT 版）

### 2.1 题目与思路

```
逆序对计数（i < j 且 a[i] > a[j]）
BIT 版：从右往左扫描，每个数查"已见过且更小"的个数
  ⚠️ 值域 BIT：update(rank, 1) 标记出现，query(rank-1) 查更小
⚠️ 需要离散化（值域大）
```

### 2.2 完整代码

```java
/**
 * 剑指 Offer 51. 数组中的逆序对（树状数组版）
 */
public int reversePairs(int[] nums) {
    // ① 离散化（01 模块 4 节）
    int[] sorted = nums.clone();
    Arrays.sort(sorted);
    int m = 1;
    for (int i = 1; i < sorted.length; i++)
        if (sorted[i] != sorted[m - 1]) sorted[m++] = sorted[i];

    // ② BIT 从右往左扫描
    int[] tree = new int[m + 1];
    long count = 0;
    for (int i = nums.length - 1; i >= 0; i--) {
        int rank = Arrays.binarySearch(sorted, 0, m, nums[i]) + 1;
        // 查"已见过的更小值" = 排名 < rank 的计数
        count += query(tree, rank - 1);
        update(tree, rank, 1);                // 当前值标记
    }
    return (int) count;
}
// 推演 [7,5,6,4]：
//   离散化 {4:1, 5:2, 6:3, 7:4}
//   从右往左：
//   4(rank1)：query(0)=0；标记 1 → BIT {1:1}
//   6(rank3)：query(2)=1（4 更小）→ count=1；标记 3
//   5(rank2)：query(1)=1（4）→ count=2；标记 2
//   7(rank4)：query(3)=3（4,5,6）→ count=5 ✓
// ⚠️ 复杂度：O(n log n)（离散化 O(n log n) + BIT O(n log n)）
// ⚠️ 面试表达："BIT 逆序对 = 从右往左扫描 +
//   值域计数——每个数查'已见且更小'（前缀和），
//   再把自己标记。对比归并版：无需递归，代码更短。"
```

## 3. 493. 翻转对（BIT + 二分）

### 3.1 题目与思路

```
i < j 且 a[i] > 2·a[j] 的个数
BIT 版：从右往左扫描，查"已见过且 < a[i]/2"的个数
  ⚠️ 2·a[j] < a[i] ⟺ rank(a[j]) < rank 阈值
  → 对 a[i]/2 在离散化数组中二分定位阈值排名
```

### 3.2 完整代码

```java
/**
 * LeetCode 493. 翻转对（BIT + 二分）
 */
public int reversePairs(int[] nums) {
    // ① 离散化（值 + 2×值 都需要定位）
    long[] sorted = new long[nums.length * 2];
    for (int i = 0; i < nums.length; i++) {
        sorted[i * 2] = nums[i];
        sorted[i * 2 + 1] = 2L * nums[i];    // ⚠️ long 防溢出
    }
    Arrays.sort(sorted);

    int[] tree = new int[nums.length * 2 + 1];
    long count = 0;
    for (int i = nums.length - 1; i >= 0; i--) {
        // ⚠️ 阈值：第一个 > 2·a[i] 的排名位置
        int threshold = lowerBound(sorted, 2L * nums[i]);
        count += query(tree, threshold);     // 已见且 < 2·a[i]

        int rank = lowerBound(sorted, nums[i]) + 1;
        update(tree, rank, 1);
    }
    return (int) count;
}
// 推演 [1,3,2,3,1]：
//   从右往左：1 → 阈值 2 以上 0 个；标记 1
//   3 → 阈值 6 以上 0 个... 3 → 2·1=2，已见 <2 的只有 1 → 1 个 ✓
//   总计 2 ✓（与归并版一致）
// ⚠️ 复杂度：O(n log n)（每次二分 O(log n) + BIT O(log n)）
// ⚠️ 面试表达："493 的 BIT 版 = 逆序对 + 阈值二分——
//   '2 倍'条件把'更小'变成'排名阈值以下'，
//   lowerBound 找阈值排名即可。"
```

## 4. 327. 区间和的个数（离散化 + BIT）

### 4.1 题目与思路

```
区间和在 [lower, upper] 的个数
前缀和变换：区间和 = pre[r] - pre[l] ∈ [L, U]
  ⟺ pre[l] ∈ [pre[r] - U, pre[r] - L]
→ 从左往右扫描 pre，BIT 维护"已见过的 pre[l]"
  查询值域区间 [pre[r]-U, pre[r]-L] 内的计数
⚠️ 需要离散化（pre 与 pre± 边界都要入表）
```

### 4.2 完整代码

```java
/**
 * LeetCode 327. 区间和的个数（离散化 + BIT）
 */
public int countRangeSum(int[] nums, int lower, int upper) {
    int n = nums.length;
    long[] pre = new long[n + 1];
    for (int i = 0; i < n; i++) pre[i + 1] = pre[i] + nums[i];

    // ① 离散化：pre 与所有查询边界
    List<Long> all = new ArrayList<>();
    for (long p : pre) all.add(p);
    for (long p : pre) {
        all.add(p - upper);                  // ⚠️ 区间下边界
        all.add(p - lower);                  // 上边界
    }
    long[] sorted = all.stream().mapToLong(Long::longValue).sorted().distinct().toArray();

    // ② 扫描前缀和：BIT 维护已见过的 pre[l]
    int[] tree = new int[sorted.length + 1];
    long count = 0;
    for (int i = 0; i < pre.length; i++) {
        // 查 [pre[i]-upper, pre[i]-lower] 内已见过的 pre[l]
        int loIdx = lowerBound(sorted, pre[i] - upper);      // ⚠️ ≥ 下界
        int hiIdx = lowerBound(sorted, pre[i] - lower + 1);  // < 上界+1
        count += query(tree, hiIdx) - query(tree, loIdx);

        // 标记当前 pre[i]（作为未来的 l）
        int rank = lowerBound(sorted, pre[i]) + 1;
        update(tree, rank, 1);
    }
    return (int) count;
}
// ⚠️ 关键：离散化必须包含"查询边界值"
//   （pre±L/U 才能二分定位）——这是 327 的难点
// ⚠️ 复杂度：O(n log n)
// ⚠️ 面试表达："327 = 前缀和 + 值域区间查询——
//   BIT 维护已见前缀和，查询值域区间计数。
//   与归并版（分治/04）同复杂度，BIT 版
//   是'在线扫描'视角。"
```

## 5. 1409. 查询带键的排列

### 5.1 题目与思路

```
初始排列 [1..n]，每次查询把元素移到开头，
输出每次移动前的位置
BIT 模拟：
  ⚠️ 把排列映射到"虚拟位置"：
  初始位置 = i + m（预留 m 个空位）
  移到开头 = 放到递减的空位
  BIT 维护"每个虚拟位置是否有元素"→ 位置 = 前缀和
```

### 5.2 完整代码

```java
/**
 * LeetCode 1409. 查询带键的排列（BIT 模拟）
 */
public int[] processQueries(int[] queries, int m) {
    int n = queries.length;
    int[] pos = new int[m + 1];              // 元素 → 虚拟位置
    int[] tree = new int[n + m + 1];         // BIT：位置 → 是否有元素

    // ① 初始：元素 i 放在 n + i（预留 n 个空位给移动）
    for (int i = 1; i <= m; i++) {
        pos[i] = n + i;
        update(tree, pos[i], 1);
    }

    int[] result = new int[n];
    for (int i = 0; i < n; i++) {
        int x = queries[i];
        // ② 当前位置 = 前缀计数 - 1（1 基）
        result[i] = query(tree, pos[x]) - 1;

        // ③ 移到开头：旧位置移除，新位置 = n - i（递减空位）
        update(tree, pos[x], -1);
        pos[x] = n - i;
        update(tree, pos[x], 1);
    }
    return result;
}
// 推演 queries=[3,1,2,1], m=5：
//   初始位置：1@6, 2@7, 3@8, 4@9, 5@10
//   查 3：位置 8 → 前缀 3 → 输出 2；移到 4
//   查 1：位置 6 → 前缀 2 → 输出 1；移到 3
//   查 2：位置 7 → 前缀 3 → 输出 2；移到 2
//   查 1：位置 3 → 前缀 1 → 输出 0 → [2,1,2,0] ✓
// ⚠️ 复杂度：O((n+m) log(n+m))
// ⚠️ 面试表达："1409 是 BIT 的'位置模拟'——
//   虚拟位置 + 前缀计数求当前下标；
//   移动 = 删旧位 + 放新位（递减空位）。"
```

## 6. 树状数组方法论总结

### 6.1 解题框架

```
① 识别：单点改/区间查/计数统计 → BIT 候选
② 建模：
   值域问题 → 值域 BIT（离散化）
   位置问题 → 位置 BIT（虚拟位置）
   区间问题 → 差分/双 BIT
③ 离散化：值域大先压缩（含查询边界！）
④ 扫描方向：逆序对从右往左、前缀和从左往右
⑤ 复杂度：O(n log n)

⚠️ 识别信号：
  "可修改 + 区间查询" → 307
  "计数配对（逆序对/翻转对）" → 剑指51/493/315/327
  "动态位置" → 1409
```

### 6.2 题型模板速查

| 题型 | BIT 角色 | 代表题 |
|------|---------|--------|
| 单点改区间查 | 标准 BIT | 307 |
| 逆序对 | 值域计数 + 前缀 | 剑指51 |
| 倍数条件 | 阈值二分 | 493 |
| 值域区间 | 双边界二分 | 327 |
| 动态位置 | 位置 BIT | 1409 |
| 最长序列 | BIT 优化 DP | 673 |

### 6.3 自测清单

```
□ 1 基下标（index+1）？
□ 离散化包含查询边界？
□ 扫描方向正确（逆序对从右往左）？
□ long 防溢出（2×/前缀和）？
□ update/query 路径正确？
□ 区间查询 l-1？
□ 复杂度 O(n log n) 表述？
```
