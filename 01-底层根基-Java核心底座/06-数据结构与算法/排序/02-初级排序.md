## 1. 冒泡排序

### 1.1 基本实现

```java
/**
 * 冒泡排序：相邻元素两两比较，大者上浮（向右移动）
 * 每轮确定一个最大值放到末尾
 * 稳定，O(n²)，空间 O(1)
 */
public void bubbleSort(int[] arr) {
    int n = arr.length;
    for (int i = 0; i < n - 1; i++) {           // 轮数
        for (int j = 0; j < n - 1 - i; j++) {   // 每轮范围缩小
            if (arr[j] > arr[j + 1]) {
                swap(arr, j, j + 1);
            }
        }
    }
}

private void swap(int[] arr, int i, int j) {
    int tmp = arr[i];
    arr[i] = arr[j];
    arr[j] = tmp;
}
```

### 1.2 优化版（提前终止）

```java
/**
 * 优化：某轮没有任何交换 → 已经有序 → 提前退出
 * 最好情况（已有序）：O(n)
 */
public void bubbleSortOptimized(int[] arr) {
    int n = arr.length;
    for (int i = 0; i < n - 1; i++) {
        boolean swapped = false;              // 本轮是否发生交换
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                swap(arr, j, j + 1);
                swapped = true;
            }
        }
        if (!swapped) break;                  // 无交换 → 有序 → 退出
    }
}
```

### 1.3 特征

```
✅ 稳定（相等不交换）
✅ 实现最简单，教学价值高
✅ 优化后对有序数组 O(n)
❌ 平均 O(n²)，常数较大
❌ 实际工程几乎不用
```

## 2. 选择排序

### 2.1 基本实现

```java
/**
 * 选择排序：每轮找最小值放到最前面
 * 交换次数少（每轮最多 1 次），但不稳定
 */
public void selectionSort(int[] arr) {
    int n = arr.length;
    for (int i = 0; i < n - 1; i++) {
        int minIndex = i;                     // 记录最小值的下标
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIndex]) {
                minIndex = j;
            }
        }
        if (minIndex != i) {
            swap(arr, i, minIndex);           // 每轮最多交换 1 次
        }
    }
}
```

### 2.2 为什么不稳定？

```
原数组：[(a,5), (b,3), (c,5)]

第一轮：找最小值 (b,3)，与 (a,5) 交换
  → [(b,3), (a,5), (c,5)]
第二轮：找最小值 → (a,5)（下标 1）
  与 (c,5) 交换 → [(b,3), (c,5), (a,5)]
  
结果：值相等的 a 和 c 相对顺序反转（a 本来在 c 前）→ 不稳定

原因：最小值与前面的元素做"远距离交换"，
     跳过中间元素时可能打乱相等元素的顺序
```

### 2.3 特征

```
✅ 交换次数最少（n-1 次），适合"交换代价高"的场景
✅ 思路最直观（不断选最小）
❌ 不稳定
❌ 无法提前终止（永远 O(n²)）
```

## 3. 插入排序

### 3.1 基本实现

```java
/**
 * 插入排序：像整理扑克牌，把当前元素插入到已排序区间的正确位置
 * 稳定，近乎有序时 O(n) —— 实际应用最多的初级排序
 */
public void insertionSort(int[] arr) {
    int n = arr.length;
    for (int i = 1; i < n; i++) {
        int key = arr[i];                     // 待插入的元素
        int j = i - 1;
        // 已排序区间从后往前找插入位置
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];              // 元素后移（覆盖式）
            j--;
        }
        arr[j + 1] = key;                     // 插入
    }
}
```

### 3.2 为什么"近乎有序"时最快？

```
已有序数组 [1,2,3,4,5]：
  每轮 while 条件 arr[j] > key 立即不成立 → 内层 O(1)
  总复杂度 O(n) ← 最好情况

逆序数组 [5,4,3,2,1]：
  每轮都要把前面所有元素后移 → 内层 O(n)
  总复杂度 O(n²) ← 最坏情况

随机数组：平均 O(n²)（但常数很小）

应用：TimSort 中，短片段（<64）用插入排序！
```

### 3.3 与冒泡/选择对比

| 维度 | 冒泡 | 选择 | 插入 |
|------|:---:|:---:|:---:|
| 稳定性 | ✅ | ❌ | ✅ |
| 最好情况 | O(n)（优化后） | O(n²) | **O(n)** |
| 平均 | O(n²) | O(n²) | O(n²) |
| 交换/移动 | 多 | 最少（n-1 次交换） | 移动多但可用覆盖 |
| 实际价值 | 教学 | 交换代价高场景 | **近乎有序/小数组** |

## 4. 希尔排序

### 4.1 基本实现

```java
/**
 * 希尔排序：插入排序的改进
 * 思想：按增量 gap 分组，组内插入排序，逐步缩小 gap 到 1
 *   gap=4: 对下标 0,4,8... 一组；1,5,9... 一组 ...
 *   gap=2: 对 0,2,4... 一组；1,3,5... 一组 ...
 *   gap=1: 就是普通插入排序
 * 效果：大跨步移动让元素快速接近正确位置，最后 gap=1 时近乎有序
 */
public void shellSort(int[] arr) {
    int n = arr.length;
    for (int gap = n / 2; gap > 0; gap /= 2) {   // 增量序列
        // 组内插入排序（间隔 gap 的元素视为一组）
        for (int i = gap; i < n; i++) {
            int key = arr[i];
            int j = i;
            while (j >= gap && arr[j - gap] > key) {
                arr[j] = arr[j - gap];
                j -= gap;
            }
            arr[j] = key;
        }
    }
}
```

### 4.2 特征

```
✅ 跨越式移动 → 大幅减少总移动次数
✅ 平均 O(n^1.3)（实证），中等规模表现不错
❌ 不稳定（分组打乱了相等元素的顺序）
❌ 增量序列选择影响性能，理论上限未完全证明
   最坏情况仍可达 O(n²)（如 gap 序列不当）

面试定位：了解原理即可，手撕优先级低于快排/归并/堆排
```

## 5. 四大初级排序对比

| 算法 | 平均 | 最好 | 最坏 | 空间 | 稳定 | 交换/移动 | 适用 |
|------|:---:|:---:|:---:|:---:|:---:|------|------|
| 冒泡 | O(n²) | O(n) | O(n²) | O(1) | ✅ | 多 | 教学 |
| 选择 | O(n²) | O(n²) | O(n²) | O(1) | ❌ | **最少** | 交换代价高 |
| 插入 | O(n²) | **O(n)** | O(n²) | O(1) | ✅ | 多但可覆盖 | 近乎有序/小数组 |
| 希尔 | O(n^1.3) | O(n log n)~ | O(n²) | O(1) | ❌ | 中 | 中等规模 |

### 面试选型一句话

```
"小规模数据（如 n<1000）或近乎有序的数据，插入排序最快；
 交换代价高选选择排序；教学演示用冒泡；
 希尔排序了解原理即可，实际工程中
 小数组由 TimSort/双轴快排内部的插入排序接管。"
```

## 6. 初级排序的面试价值

### 6.1 面试中的角色

```
1. 开场热身题："手写一个排序" → 插入排序（最稳）
2. 追问基础："哪些排序稳定？为什么？" → 理论
3. 场景题："10 万条近乎有序数据怎么排？" → 插入排序优化
4. 高级排序的组成部件：
   - TimSort 的片段内插入排序
   - 快排优化的小区间插入排序
```

### 6.2 高频追问

| 追问 | 标准回答 |
|------|------|
| 为什么插入排序近乎有序时 O(n)？ | 每轮 while 条件立即失败，内层 O(1) |
| 为什么选择排序不稳定？ | 远距离交换会跨越相等元素 |
| 冒泡优化怎么做？ | 记录每轮是否交换，无交换提前退出 |
| 插入排序实际用在哪？ | Java TimSort 小片段（<64）、快排小区间优化 |

> 🎯 **核心要点**：初级排序是理解高级排序的铺垫——**插入排序**（近乎有序 O(n)、稳定、常数小）是真正的实用者，冒泡/选择更多是教学意义，希尔是插入的跨越式升级。记住"冒插归稳定，选快希堆不稳定"，以及插入排序在 TimSort/快排优化中的角色，初级排序的面试分就到手了。
