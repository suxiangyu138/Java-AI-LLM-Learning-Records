## 1. 核心概念

### 1.1 复杂度速查表（必背）

| 算法 | 平均 | 最坏 | 空间 | 稳定 | 适用 |
|------|:---:|:---:|:---:|:---:|------|
| 冒泡 | O(n²) | O(n²) | O(1) | ✅ | 教学 |
| 选择 | O(n²) | O(n²) | O(1) | ❌ | 交换代价高 |
| 插入 | O(n²) | O(n²) | O(1) | ✅ | 近乎有序 |
| 希尔 | O(n^1.3) | O(n²) | O(1) | ❌ | 中等规模 |
| **快排** | O(n log n) | **O(n²)** | O(log n) | ❌ | 通用首选 |
| **归并** | O(n log n) | O(n log n) | O(n) | ✅ | 稳定/链表 |
| **堆排** | O(n log n) | O(n log n) | O(1) | ❌ | 内存受限 |
| 计数/基数/桶 | O(n+k) | — | O(k) | ✅ | 线性场景 |

```
⚠️ 记忆口诀：
  "冒插归稳定，选快希堆不稳定"
  "快排最快但退化，归并稳定无退化"
```

### 1.2 识别信号

```
"手写排序" → 快排/归并（912）
"第 K 大" → 快选/堆（215）
"稳定排序" → 归并（对象排序）
"链表排序" → 归并（148）
"线性排序" → 计数/基数/桶

⚠️ 面试必背：
  复杂度表 + 稳定性 + 选型口诀
```

### 1.3 选型口诀

```
默认快排（常数小、缓存友好）
稳定 → 归并 / 插入 / 冒泡
内存紧 → 堆排
近乎有序 → 插入（O(n)）
链表 → 归并（无随机访问）
值域小 → 计数；均匀分布 → 桶；定长数值 → 基数
```

## 2. 完整代码模板

### 2.1 快排（含三数取中优化）

```java
/**
 * 快速排序（面试标准答案：三数取中防退化）
 */
public void quickSort(int[] arr, int lo, int hi) {
    if (lo >= hi) return;

    // ⚠️ 三数取中（防有序数组退化 O(n²)）
    int mid = lo + (hi - lo) / 2;
    if (arr[lo] > arr[mid]) swap(arr, lo, mid);
    if (arr[lo] > arr[hi]) swap(arr, lo, hi);
    if (arr[mid] > arr[hi]) swap(arr, mid, hi);
    swap(arr, mid, hi);                  // 中位数做基准

    // partition：小于基准放左边
    int pivot = arr[hi], i = lo - 1;
    for (int j = lo; j < hi; j++) {
        if (arr[j] < pivot) swap(arr, ++i, j);
    }
    swap(arr, i + 1, hi);

    quickSort(arr, lo, i);               // 递归左
    quickSort(arr, i + 2, hi);           // 递归右（基准在 i+1）
}
// 平均 O(n log n)，最坏 O(n²)（三数取中后几乎不触发）
// 空间 O(log n)（递归栈）
// 推演 [3,7,8,5,2,1,9,5,4]：三数取中 + 分区 → 递归
```

### 2.2 归并（稳定关键 <=）

```java
/**
 * 归并排序（稳定，无退化）
 */
public void mergeSort(int[] arr) {
    int[] temp = new int[arr.length];      // ① 全局辅助数组
    sort(arr, 0, arr.length - 1, temp);
}

private void sort(int[] arr, int lo, int hi, int[] temp) {
    if (lo >= hi) return;
    int mid = lo + (hi - lo) / 2;
    sort(arr, lo, mid, temp);              // 拆左
    sort(arr, mid + 1, hi, temp);          // 拆右
    merge(arr, lo, mid, hi, temp);         // 合并
}

private void merge(int[] arr, int lo, int mid, int hi, int[] temp) {
    System.arraycopy(arr, lo, temp, lo, hi - lo + 1);
    int i = lo, j = mid + 1, k = lo;
    while (i <= mid && j <= hi) {
        // ⚠️ <= 保证稳定（左半相等元素优先）
        if (temp[i] <= temp[j]) arr[k++] = temp[i++];
        else arr[k++] = temp[j++];
    }
    while (i <= mid) arr[k++] = temp[i++];
    while (j <= hi)  arr[k++] = temp[j++];
}
// 最好=最坏=平均 O(n log n)（无退化）
// ⚠️ 稳定性 = merge 的 <= 符号
```

### 2.3 堆排（建堆 + 下沉）

```java
/**
 * 堆排序（原地 O(1) 空间）
 */
public void heapSort(int[] arr) {
    int n = arr.length;

    // ① 建堆：从最后一个非叶子开始下沉（O(n)）
    for (int i = n / 2 - 1; i >= 0; i--) {
        siftDown(arr, i, n);
    }

    // ② 取堆顶交换到末尾
    for (int i = n - 1; i > 0; i--) {
        swap(arr, 0, i);                 // 最大元素归位
        siftDown(arr, 0, i);             // 重建堆
    }
}

private void siftDown(int[] arr, int i, int size) {
    while (2 * i + 1 < size) {           // 有左孩子
        int child = 2 * i + 1;
        if (child + 1 < size && arr[child + 1] > arr[child]) {
            child++;                     // 选较大孩子
        }
        if (arr[i] >= arr[child]) break;
        swap(arr, i, child);
        i = child;
    }
}
// O(n log n) 时间 O(1) 空间，不稳定
// ⚠️ 建堆 O(n) 的推导：Σ(n/2^h × h) ≈ 2n
```

## 3. 排序的稳定性

### 3.1 什么是稳定性

```
稳定：相等元素排序后相对顺序不变

应用场景（二次排序）：
  先按学号排，再按分数排（稳定）
  → 分数相同保持学号顺序

⚠️ 不稳定排序的后果：
  二次排序时破坏第一次的顺序
```

### 3.2 稳定 vs 不稳定

```
稳定：冒泡、插入、归并、计数、基数、桶
不稳定：选择、快排、堆排、希尔

为什么不稳定？
  选择：远距离交换跨越相等元素
  快排：partition 交换
  堆排：堆顶与末尾交换

⚠️ 记忆："冒插归 + 三个线性 = 稳定"
```

### 3.3 稳定性在面试中的角色

```
"对象排序"（Java Arrays.sort 对象版）→ TimSort（稳定）
"基本类型" → 双轴快排（不稳定无所谓）

⚠️ 面试必答：
"为什么 Java 对象排序用稳定的 TimSort？
 对象排序后相对顺序有意义（二次排序），
 必须稳定；基本类型纯数值无所谓。"
```

## 4. 工程选型与 Java 实现

### 4.1 Java Arrays.sort 原理

```
基本类型（int[]/long[]/...）→ DualPivotQuickSort（双轴快排）
  - 两个基准 → 三段划分 → 缓存友好
  - 性能极致但不稳定

对象类型（Integer[]/String[]/...）→ TimSort（归并+插入混合）
  - 稳定！（对象的稳定性有意义）
  - 小片段（<32）用插入排序
  - 近乎有序时 O(n)

⚠️ 面试必答：
"基本类型用双轴快排（快、原地、稳定性无所谓）；
 对象用 TimSort（稳定——对象排序后顺序有意义）。"
```

### 4.2 TimSort 要点

```
TimSort = 归并 + 插入混合：
  ① 扫描天然有序段（run）
  ② 短 run 插入排序补齐（最小 32）
  ③ 相邻 run 归并（栈式）

特性：
  近乎有序 → O(n)
  最坏 O(n log n)
  稳定 → 对象排序首选
```

### 4.3 外部排序（大数据）

```
1TB 数据内存 2GB：
  ① 分批内存排序 → 有序段（run）写磁盘
  ② K 路归并（堆取最小）→ 合成有序

⚠️ 面试表达：
"外部排序 = 分批排序 + 多路归并。
 每批内存可容纳 → 排序写盘；
 K 路归并用堆（或败者树）取全局最小。"
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"手撕快排：三数取中选基准防退化，
 partition 把小于基准的放左边，
 递归两侧。平均 O(n log n)，
 最坏 O(n²)（三数取中后几乎不触发）。
 稳定性：不稳定。
 追问归并：稳定无退化，merge 用 <=。
 堆排：O(1) 空间，建堆 O(n)。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 快排最坏？怎么防？ | 有序+固定基准 O(n²)；三数取中/随机 |
| 2 | 为什么快排最快？ | 缓存友好 + 无辅助数组 + 常数小 |
| 3 | 归并为什么稳定？ | merge 用 <=（相等取左半） |
| 4 | 建堆为什么 O(n)？ | 底层节点下沉少，Σ ≈ 2n |
| 5 | 链表为什么归并？ | 无随机访问；归并只需 next |
| 6 | Arrays.sort 原理？ | 基本类型双轴快排；对象 TimSort |
| 7 | 排序稳定性？ | 冒插归+线性稳定；选快希堆不稳定 |
| 8 | 大数据排序？ | 外部排序（分批+多路归并） |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 快排边界写错 | 死循环 | 递归 [lo,i] 与 [i+2,hi] |
| 归并用 < | 不稳定 | 用 <= |
| 堆排建堆起点错 | 结果错 | n/2-1 |
| 归并忘拷贝剩余 | 结果缺失 | 两个 while |
| 选择排序换错 | 越界 | minIndex 记录 |

> 🎯 **核心要点**：复杂度表 + 手撕三件套 + 选型口诀。快排必带三数取中、归并必讲稳定性、堆排必讲建堆 O(n)——三个"必"是面试得分点。Arrays.sort 双轨原理与外部排序是进阶加分。
