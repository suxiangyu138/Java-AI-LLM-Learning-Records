## 1. 1192. 查找集群内的关键连接（无向图桥）

### 1.1 题目与思路

```
无向图的所有桥（删除后图分裂的边）
Tarjan 变体：low[v] > dfn[u] 判定桥
⚠️ 无向图特判：跳过父边（否则回边误判为桥）
```

### 1.2 完整代码

```java
/**
 * LeetCode 1192. 查找集群内的关键连接
 * ⚠️ 无向图桥：low[v] > dfn[u]（严格大于）
 */
class Solution {
    private int[] dfn, low;
    private int timer = 0;
    private List<List<Integer>> bridges = new ArrayList<>();

    public List<List<Integer>> criticalConnections(int n, List<List<Integer>> connections) {
        // 建无向图
        List<Integer>[] graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (var e : connections) {
            graph[e.get(0)].add(e.get(1));
            graph[e.get(1)].add(e.get(0));
        }

        dfn = new int[n];
        low = new int[n];
        dfs(0, -1, graph);                    // ⚠️ 题目保证连通，从 0 出发
        return bridges;
    }

    private void dfs(int u, int parent, List<Integer>[] graph) {
        dfn[u] = low[u] = ++timer;
        for (int v : graph[u]) {
            if (v == parent) continue;        // ⚠️ 跳过父边（无向图关键）
            if (dfn[v] == 0) {
                dfs(v, u, graph);
                low[u] = Math.min(low[u], low[v]);
                if (low[v] > dfn[u]) {        // ⚠️ 桥判定（严格大于）
                    bridges.add(List.of(u, v));
                }
            } else {
                low[u] = Math.min(low[u], dfn[v]);   // 回边（非父边）
            }
        }
    }
}
// 推演 图：0-1, 1-2, 2-0, 1-3（三角形 + 悬挂边）
//   1→3：low[3]=dfn[3] > dfn[1] → 桥 (1,3) ✓
//   0-1：low[1]=1（经 1→2→0 回边）≤ dfn[0] → 非桥 ✓
// ⚠️ 复杂度：O(V+E)（每条边恰好访问两次）
// ⚠️ 面试表达："无向图桥 = Tarjan 变体——
//   父边跳过是唯一区别；判定式 low[v] > dfn[u]
//   表示 v 的子树翻不出 u 之上的祖先。"
```

## 2. 2065. 最大化路径价值（SCC + DP）

### 2.1 题目与思路

```
有向图从 0 出发（可重复经过节点）在规定时间内
收集最大价值（节点价值重复访问只算一次）
⚠️ 环的存在：可重复经过 → 环内价值全部可收集
   → 缩点：SCC 价值 = 内部节点价值之和（全部可拿）
   → DAG 上"时间约束"DP
⚠️ 时间约束的处理：maxTime 限制路径长度
```

### 2.2 完整代码（缩点 + 时间 DP）

```java
/**
 * LeetCode 2065. 最大化路径价值
 * ⚠️ 思路：Tarjan 缩点（环内价值全拿）→ DAG 上时间 DP
 * 简化实现：由于可重复经过，SCC 内价值总和即收益
 */
public int maximalPathQuality(int[] values, int[][] edges, int maxTime) {
    int n = values.length;
    List<int[]>[] graph = new List[n];        // 邻接表（带时间）
    for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
    for (int[] e : edges) {
        graph[e[0]].add(new int[]{e[1], e[2]});
        graph[e[1]].add(new int[]{e[0], e[2]});
    }

    // ⚠️ 本图是无向图，无向图不存在"缩点省时间"的收益
    // （环内绕圈耗时间）→ 直接 DFS + 回溯（节点少时可行）
    return dfs(0, 0, maxTime, graph, values, new boolean[n]);
}

/** DFS + 回溯：经过节点时首次访问才计价值 */
private int dfs(int u, int time, int maxTime, List<int[]>[] graph,
                int[] values, boolean[] visited) {
    if (time > maxTime) return 0;             // 超时剪枝

    boolean first = !visited[u];
    int gain = first ? values[u] : 0;         // ⚠️ 重复访问不加价值
    visited[u] = true;

    int best = 0;
    if (u == 0) best = gain;                  // 回到 0 可结算（价值已含）
    for (int[] e : graph[u]) {
        best = Math.max(best, gain + dfs(e[0], time + e[1], maxTime, graph, values, visited));
    }
    visited[u] = false;                       // ⚠️ 回溯
    return best;
}
// 推演 values=[0,32,10,43], edges=[[0,1,10],[1,2,15],[0,3,10]], maxTime=49：
//   DFS 所有路径找最大价值组合（0→1→2 值 32+10=42 时间 25...
//   回到 0 需要更多时间... 探索后取最优）
// ⚠️ 面试表达："2065 的 SCC 视角：环可重复走 →
//   环内价值必可全拿；但本题无向 + 时间约束，
//   用 DFS 回溯直接解（n 小）。SCC 思想用于
//   '纯收益'场景（价值全拿），时间约束场景要 DFS。"
// ⚠️ 面试结论：讲清"何时缩点、何时 DFS"比背代码更重要
```

## 3. 最少加边使图强连通

### 3.1 题目与思路

```
有向图最少加几条边强连通（经典面试题）
三步骤：Tarjan → 缩点 → max(入 0, 出 0)
⚠️ 特判：单 SCC（已强连通）→ 0
```

### 3.2 完整代码

```java
/**
 * 最少加边使有向图强连通
 * ⚠️ 结论：max(入度为 0 的 SCC 数, 出度为 0 的 SCC 数)
 */
int minEdgesToStrongConnect(int n, List<Integer>[] graph) {
    // ① Tarjan 求 SCC（01 模块模板）
    List<List<Integer>> sccs = tarjan(graph);

    if (sccs.size() == 1) return 0;           // ⚠️ 已强连通特判

    // ② 缩点统计出入度
    int m = sccs.size();
    int[] compId = new int[n];
    for (int i = 0; i < m; i++)
        for (int v : sccs.get(i)) compId[v] = i;

    boolean[] hasIn = new boolean[m];
    boolean[] hasOut = new boolean[m];
    for (int u = 0; u < n; u++)
        for (int v : graph[u])
            if (compId[u] != compId[v]) {
                hasOut[compId[u]] = true;
                hasIn[compId[v]] = true;
            }

    int in0 = 0, out0 = 0;
    for (int i = 0; i < m; i++) {
        if (!hasIn[i]) in0++;
        if (!hasOut[i]) out0++;
    }
    return Math.max(in0, out0);
}
// 推演 图：1→2, 2→1, 2→3, 3→2（{1,2,3} 一个 SCC）→ 0 ✓
// 推演 图：1→2（两个 SCC：{1},{2}）
//   入 0：{1}；出 0：{2} → max(1,1) = 1 ✓（加 2→1 即可）
// ⚠️ 证明直觉：每个"入 0"需要一条进边、每个"出 0"
//   需要一条出边；一条边同时补一对 → max
// ⚠️ 面试必答："最少加边 = max(入 0, 出 0)——
//   这是缩点后 DAG 的结构性质，证明用配对思想。"
```

## 4. 可达性统计（缩点 + 拓扑 DP）

### 4.1 题目与思路

```
统计每个节点能到达的节点数（有向图，n 可达 10⁵）
暴力：每个节点 DFS → O(n²) 超时
缩点 + 拓扑 DP：
  ① 缩点 → DAG
  ② 拓扑逆序：SCC 可达数 = 自己 + 后继 SCC 可达数并集
⚠️ 集合用 BitSet（位运算合并，n ≤ 10⁵ 时 10⁵/64 个 long）
```

### 4.2 完整代码

```java
/** 可达性统计（缩点 + 拓扑逆序 + BitSet） */
long[] reachableCount(int n, List<Integer>[] graph) {
    // ① Tarjan 缩点 → DAG
    // ② 拓扑排序（Kahn）
    int[] indegree = new int[m];
    for (int u = 0; u < m; u++)
        for (int v : dag[u]) indegree[v]++;
    Deque<Integer> queue = new ArrayDeque<>();
    for (int i = 0; i < m; i++)
        if (indegree[i] == 0) queue.offer(i);
    List<Integer> topo = new ArrayList<>();
    while (!queue.isEmpty()) {
        int u = queue.poll();
        topo.add(u);
        for (int v : dag[u])
            if (--indegree[v] == 0) queue.offer(v);
    }

    // ③ 拓扑逆序 DP（BitSet 存可达集合）
    BitSet[] reach = new BitSet[m];
    for (int i = 0; i < m; i++) reach[i] = new BitSet();
    for (int i = topo.size() - 1; i >= 0; i--) {   // ⚠️ 逆拓扑序
        int u = topo.get(i);
        reach[u].set(u);                       // 自己可达
        for (int v : dag[u])
            reach[u].or(reach[v]);             // ⚠️ 并集合并（位运算）
    }
    // ④ 还原到原节点：SCC 内节点可达数相同 + SCC 大小
    long[] result = new long[n];
    for (int u = 0; u < n; u++)
        result[u] = reach[compId[u]].cardinality();   // 该 SCC 可达 SCC 数
    // ⚠️ 精确到节点数需再乘 SCC 大小（简化版给 SCC 级答案）
    return result;
}
// ⚠️ BitSet 的优势：并集 O(m/64)（位运算）而非 O(m)
// ⚠️ 面试表达："可达性 = 缩点 + 拓扑逆序 DP +
//   BitSet 并集——三步把 O(n²) 降到
//   O(n×m/64)（位并行）。"
```

## 5. 强连通方法论总结

### 5.1 解题框架

```
① 识别：有向图环/连通性/可达性 → SCC 候选
② 建模：Tarjan 求 SCC（dfn/low/栈）
③ 缩点：SCC → DAG 节点
④ 应用：
   最少加边 → max(入 0, 出 0)
   有向 DP → 拓扑序
   可达性 → 拓扑逆序 + BitSet
   无向图 → 桥/割点变体（判定式变化）

⚠️ 识别信号：
  "强连通/环/可达性/关键边" → 本家族
  "删边分裂" → 桥（无向）
  "环内收益" → 缩点
```

### 5.2 判定式速查

| 问题 | 判定式 | 图类型 |
|------|--------|:---:|
| SCC 根 | low[v] >= dfn[u] | 有向 |
| 桥 | low[v] > dfn[u] | 无向 |
| 割点（非根） | low[v] >= dfn[u] | 无向 |
| 割点（根） | 子节点 ≥ 2 | 无向 |

### 5.3 自测清单

```
□ 回边用 dfn[v]（非 low[v]）？
□ 无向图跳父边？
□ 缩点去重边（跨 SCC 才加）？
□ 最少加边特判（单 SCC → 0）？
□ 拓扑逆序 DP（依赖先算）？
□ 超时剪枝（时间约束）？
□ 复杂度 O(V+E) 表述？
```

> 🎯 **核心要点**：强连通题 = **Tarjan**（O(V+E)）+ **缩点 DAG 化** + **判定式选择**（SCC/桥/割点）。四题覆盖：无向桥（1192）、环内收益（2065）、结构性质（最少加边）、统计应用（可达性）——"有环就缩点"是图论难题的统一钥匙。
