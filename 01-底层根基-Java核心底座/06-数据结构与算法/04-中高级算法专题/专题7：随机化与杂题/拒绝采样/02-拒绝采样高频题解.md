## 1. 470. 用 Rand7 实现 Rand10

### 1.1 题目与思路

```
rand7() → rand10()（等概率 1-10）
拒绝采样：(rand7()-1)×7 + rand7() → 1..49 均匀
  接受 1..40（拒绝 41..49）→ %10 + 1
接受率 40/49 ≈ 81.6% → 期望重试 1.22 次
⚠️ 完整推导见概率与统计/02（含优化版），此处提炼 + 变体
```

### 1.2 完整代码与变体

```java
/** 基础版 */
public int rand10() {
    int x;
    do {
        x = (rand7() - 1) * 7 + rand7();   // ⚠️ 1..49 均匀（两位数编码）
    } while (x > 40);                      // 拒绝 41..49
    return x % 10 + 1;
}
// ⚠️ 面试表达："(rand7()-1)×7+rand7() 是'7 进制两位数'——
//   均匀覆盖 1..49。拒绝 41..49 后余下仍均匀（拒绝不破坏均匀性）。"

/** 变体：用更少的平均调用（优化思路，面试加分） */
public int rand10Optimized() {
    while (true) {
        int a = rand7(), b = rand7();
        int x = (a - 1) * 7 + b;           // 1..49
        if (x <= 40) return x % 10 + 1;    // 第一段接受

        // ⚠️ 剩余 9 个值（41..49）再利用：×7 扩大为 1..63
        int c = rand7();
        int y = (x - 40 - 1) * 7 + c;      // 1..63 均匀（9×7）
        if (y <= 60) return y % 10 + 1;    // 接受 60/63
        // 再剩余 3 个 → 继续循环
    }
}
// 期望调用：2×1.22 → 约 2.36 → 再降到 ~2.1 次
// ⚠️ 变体 Rand5→Rand7：拒绝 21..25（1..25 取 1..21）
//   变体 Rand10→Rand7：7 进制一位直接拒绝 8-10
```

> 🎯 **要点**：拒绝采样做"分布转换"的核心是——**构造均匀超集**（编码法）+ **拒绝越界值**（保持均匀）+ **接受率最大化**（利用剩余值）。

## 2. 478. 在圆内随机生成点

### 2.1 题目与思路

```
圆内均匀随机点
三种方案对比：
  拒绝采样：正方形包围 → π/4 接受率（直观）
  极坐标：r=√u 一次完成（公式易错）
  正态+归一：非均匀（错误方案）
⚠️ 极坐标的 √u 是高频考点（面积 ∝ r²）
```

### 2.2 完整代码（双方案）

```java
/** 方案一：拒绝采样（π/4 ≈ 78.5%） */
public double[] randPointReject(double radius, double x0, double y0, Random rand) {
    while (true) {
        double x = x0 + (rand.nextDouble() * 2 - 1) * radius;
        double y = y0 + (rand.nextDouble() * 2 - 1) * radius;
        double dx = x - x0, dy = y - y0;
        if (dx * dx + dy * dy <= radius * radius)   // ⚠️ 平方比较
            return new double[]{x, y};
    }
}
// 期望重试 = 1/(π/4) ≈ 1.27 次

/** 方案二：极坐标（一次完成，无重试） */
public double[] randPointPolar(double radius, double x0, double y0, Random rand) {
    double theta = rand.nextDouble() * 2 * Math.PI;          // 角度均匀
    double r = radius * Math.sqrt(rand.nextDouble());        // ⚠️ √u！
    return new double[]{x0 + r * Math.cos(theta),
                        x0 + r * Math.sin(theta)};
}
// ⚠️ 为什么 √u：半径 r 处累积概率 = r²/R²（面积占比）
//   反函数 r = R·√u；直接 r = R·u → 中心密度大（错误）
// ⚠️ 面试表达："478 双方案——拒绝采样直观但重试；
//   极坐标一次完成但 √u 记错就错。面试先讲 √u 的
//   面积论证（为什么不是 r = R·u），再写代码。"
```

## 3. 497. 随机点中的非重叠矩形

### 3.1 题目与思路

```
多个非重叠矩形，等概率返回"矩形内整数点"
三步：
  ① 面积加权：随机选矩形（概率 ∝ 面积）
  ② 矩形内随机点：宽高均匀（整数坐标）
  ③ 预计算前缀面积 + 二分（O(log n) 选矩形）
⚠️ 这是"加权随机 + 区域内采样"的组合
```

### 3.2 完整代码

```java
/**
 * LeetCode 497. 随机点中的非重叠矩形
 * ⚠️ 面积加权选矩形（前缀和 + 二分）+ 矩形内均匀点
 */
class Solution {
    private final int[][] rects;
    private final int[] prefixArea;            // 前缀面积
    private final Random rand = new Random();

    public Solution(int[][] rects) {
        this.rects = rects;
        prefixArea = new int[rects.length];
        int sum = 0;
        for (int i = 0; i < rects.length; i++) {
            int[] r = rects[i];
            // ⚠️ 整数点个数 = (x2-x1+1)×(y2-y1+1)
            sum += (r[2] - r[0] + 1) * (r[3] - r[1] + 1);
            prefixArea[i] = sum;
        }
    }

    public int[] pick() {
        // ① 按面积加权选矩形（前缀和 + 二分）
        int target = rand.nextInt(prefixArea[prefixArea.length - 1]) + 1;
        int lo = 0, hi = prefixArea.length - 1;
        while (lo < hi) {                       // 第一个 ≥ target
            int mid = lo + (hi - lo) / 2;
            if (prefixArea[mid] >= target) hi = mid;
            else lo = mid + 1;
        }
        int[] r = rects[lo];

        // ② 矩形内均匀整数点
        int x = r[0] + rand.nextInt(r[2] - r[0] + 1);
        int y = r[1] + rand.nextInt(r[3] - r[1] + 1);
        return new int[]{x, y};
    }
}
// 推演 rects=[[1,1,5,5]]：唯一矩形 → 直接均匀点 ✓
// 推演 rects=[[-2,-2,-1,-1],[1,0,3,0]]：
//   面积 4 与 3 → 前缀 [4, 7] → 4/7 概率选矩形 0 ✓
// ⚠️ 面试表达："497 = 加权选择（前缀和+二分，见 528）
//   + 区域均匀采样（矩形宽高均匀）。组合是采样题
//   的高频形态。"
```

## 4. 710. 黑名单中的随机数

### 4.1 题目与思路

```
[0, n) 中排除黑名单后等概率随机（黑名单可达 n/2）
方案对比：
  拒绝采样：随机到黑名单 → 重试（黑名单占比大时爆炸）
  映射法 ⭐：黑名单值映射到尾部白名单 → O(1) 一次
⚠️ 这是"拒绝 vs 映射"选型的教科书案例（01 模块第 5 节）
```

### 4.2 完整代码（映射法）

```java
/**
 * LeetCode 710. 黑名单中的随机数
 * ⚠️ 映射：黑名单中 < W 的值 → 尾部白名单值（一一对应）
 */
class Solution {
    private final int W;                        // 可用区大小 = n - m
    private final Map<Integer, Integer> mapping = new HashMap<>();
    private final Random rand = new Random();

    public Solution(int n, int[] blacklist) {
        int m = blacklist.length;
        W = n - m;

        Set<Integer> blackSet = new HashSet<>();
        for (int b : blacklist) if (b >= W) blackSet.add(b);   // ⚠️ 尾部黑名单直接跳过

        // 为"可用区内的黑名单值"找尾部白名单映射
        Set<Integer> whiteSet = new HashSet<>();
        for (int b : blacklist) if (b < W) whiteSet.add(b);
        int cursor = W;
        for (int b : blacklist) {
            if (b < W) {                       // ⚠️ 需要映射的黑名单值
                while (blackSet.contains(cursor)) cursor++;    // 跳过尾部黑名单
                mapping.put(b, cursor++);      // 映射到白名单
            }
        }
    }

    public int pick() {
        int x = rand.nextInt(W);               // [0, W) 均匀
        return mapping.getOrDefault(x, x);     // ⚠️ 黑名单值走映射，白名单原值
    }
}
// 推演 n=6, blacklist=[0,2,3]：
//   W=3；尾部黑名单（≥3）：{3}；可用区黑名单 {0,2}
//   映射：0→3？3 是黑名单 → 4；2→5 → mapping {0:4, 2:5}
//   pick：随机 [0,3) → 0→4，1→1，2→5 → 结果 {1,4,5} 等概率 ✓
// ⚠️ 面试表达："黑名单占比大时拒绝采样期望重试爆炸
//   （如黑掉 90% → 平均试 10 次）——映射法把
//   '拒绝'变成'置换'，O(1) 保证。"
```

## 5. 528. 按权重随机选择

### 5.1 题目与思路

```
按权重 w[i] 概率选择下标
前缀和 + 二分（数轴线段映射）——一次定位无重试
⚠️ 与"拒绝采样"的关系：同属"分布采样"家族，
   但前缀和是确定性映射（接受率 100%）
```

### 5.2 完整代码

```java
/**
 * LeetCode 528. 按权重随机选择
 */
class Solution {
    private final int[] prefix;
    private final Random rand = new Random();

    public Solution(int[] w) {
        prefix = new int[w.length];
        prefix[0] = w[0];
        for (int i = 1; i < w.length; i++) prefix[i] = prefix[i - 1] + w[i];
    }

    public int pickIndex() {
        int target = rand.nextInt(prefix[prefix.length - 1]) + 1;  // [1, total]
        int lo = 0, hi = prefix.length - 1;
        while (lo < hi) {                       // 第一个 ≥ target
            int mid = lo + (hi - lo) / 2;
            if (prefix[mid] >= target) hi = mid;
            else lo = mid + 1;
        }
        return lo;
    }
}
// 推演 w=[1,3]：prefix=[1,4]；target=1 → 0；2/3/4 → 1
//   → 25% 选 0、75% 选 1 ✓
// ⚠️ 对比拒绝采样：
//   528 用"映射"（前缀和数轴）→ 一次完成
//   若用拒绝采样（随机下标 + 权重校验）→ 平均重试多
// ⚠️ 面试表达："528 是'权重映射'的教科书——
//   权重画成数轴，随机点落在哪段选谁。
//   前缀和 + 二分 = O(log n) 一次定位。"
```

## 6. 采样方法选型实战

### 6.1 五题的方法全景

| 题目 | 方法 | 接受率/成本 | 为什么 |
|------|------|:---:|--------|
| 470 | 拒绝采样 | 81.6% | 超集构造简单 |
| 478 | 极坐标/拒绝 | 100%/78.5% | 圆有解析式 |
| 497 | 加权 + 均匀 | 100% | 矩形均匀直接给 |
| 710 | 映射 | 100% | 黑名单大 → 拒绝爆炸 |
| 528 | 前缀和映射 | 100% | 权重 → 数轴 |

```
⚠️ 选型决策：
  目标区域有解析参数化（圆/矩形）？→ 直接构造
  超集易构造 + 接受率高？→ 拒绝采样
  拒绝区域占比大？→ 映射
  离散权重？→ 前缀和 + 二分
```

### 6.2 组合题模式

```
采样题常是"选择 + 生成"的组合：
  加权选子区域（528 模式）→ 区域内均匀生成（478 模式）
  例：497 = 528 + 478（矩形版）
  例：地图随机点 = 面积加权选多边形 + 多边形内采样

⚠️ 面试表达：
"复杂采样 = 分解：先'选哪个区域'（权重/面积），
 再'区域内怎么采'（均匀/分布）。两阶段各自
 选最优方法，组合即可。"
```

## 7. 方法论总结

### 7.1 采样题四步框架

```
① 目标分布：均匀于什么区域/按什么权重？
② 方法选型：直接构造 / 拒绝采样 / 映射 / 前缀和
③ 数学验证：接受率（面积比）、均匀性（√u 论证）、等概率（映射双射）
④ 工程防护：重试上限、整数坐标边界、精度（平方比较）

⚠️ 识别信号：
  "随机生成 + 等概率/按权重" → 采样题
  "RandX 实现 RandY" → 拒绝采样
  "排除黑名单" → 映射
```

### 7.2 自测清单

```
□ 均匀性论证（√u 面积反函数 / 编码超集 / 映射双射）？
□ 接受率算过（期望重试可接受）？
□ 整数点坐标 +1（闭区间）？
□ 前缀和 target 从 1 开始？
□ 黑名单映射尾部游标跳过黑名单？
□ 高维/低接受率换方法了？
```
