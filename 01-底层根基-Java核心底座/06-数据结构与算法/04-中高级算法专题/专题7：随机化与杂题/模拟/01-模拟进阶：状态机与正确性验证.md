## 1. 状态机：模拟的骨架

### 1.1 什么是状态机

```
模拟题 = 状态机：状态 + 转移规则
  状态：当前位置/方向/剩余量/阶段
  转移：规则决定下一步

⚠️ 状态机设计三步：
  ① 列出所有状态（有限集合）
  ② 列出转移规则（状态 → 状态）
  ③ 边界处理（越界/终止条件）

⚠️ 面试表达：
"模拟题先画状态机——状态集合 + 转移规则。
 状态机画清楚，代码就是转移规则的翻译。"
```

### 1.2 状态机示例：螺旋矩阵

```
状态：方向（右/下/左/上）+ 边界（top/bottom/left/right）
转移：走完一边 → 收缩边界 + 换方向
终止：top > bottom || left > right

⚠️ 状态机视角的螺旋：
  4 个状态（方向）循环转移
  每次转移携带"边界收缩"副作用

⚠️ 代码即状态表：
  方向数组 dirs = {{0,1},{1,0},{0,-1},{-1,0}}（右下左上）
  方向索引 + 边界判断 = 完整状态机
```

### 1.3 状态机的两种实现

```java
/** 方式一：方向数组 + 索引（螺旋/机器人通用） */
int[][] dirs = {{0,1},{1,0},{0,-1},{-1,0}};   // 右下左上
int d = 0;                                    // 当前方向索引
// 转向：d = (d + 1) % 4
// 前进：i += dirs[d][0]; j += dirs[d][1]

/** 方式二：显式状态（布尔/枚举）——语义清晰 */
boolean movingRight = true;
// if (movingRight) {...} else {...}
```

| 方式 | 优点 | 适用 |
|------|------|------|
| 方向数组 | 简洁、可循环 | 方向轮转类（螺旋/机器人） |
| 显式状态 | 可读、可扩展 | 复杂状态（生命游戏） |

## 2. 方向控制模板

### 2.1 通用方向模板（874 机器人/螺旋）

```java
/** 方向控制核心模板：方向数组 + 边界/障碍处理 */
class DirectionRobot {
    private static final int[][] DIRS = {{0,1},{1,0},{0,-1},{-1,0}};
    // ⚠️ 顺序：右下左上（顺时针）；索引 (d+1)%4 右转

    private int d = 0;                          // 方向状态
    private int x = 0, y = 0;

    void turnRight() { d = (d + 1) % 4; }       // 右转（顺时钟）
    void turnLeft()  { d = (d + 3) % 4; }       // 左转（逆时钟）

    boolean moveForward(Set<String> obstacles) {
        int nx = x + DIRS[d][0];
        int ny = y + DIRS[d][1];
        if (obstacles.contains(nx + "," + ny)) return false;   // 障碍阻挡
        x = nx; y = ny;
        return true;
    }
}
// ⚠️ 变体：只右转（螺旋）、四个方向（网格遍历）
// ⚠️ 面试表达："方向控制 = 方向数组 + 取模转向。
//   右转 (d+1)%4、左转 (d+3)%4——一个数组
//   覆盖所有方向类模拟题。"
```

### 2.2 方向数组的方向语义

```
⚠️ 方向数组的顺序选择：
  顺时针：右 → 下 → 左 → 上（{(0,1),(1,0),(0,-1),(-1,0)}）
  用于：螺旋、机器人右转

⚠️ 网格四方向（DFS/BFS）：
  上下左右：{(1,0),(-1,0),(0,1),(0,-1)}
  与"方向轮转"的区别：DFS 方向数组无顺序要求

⚠️ 八方向（棋盘）：
  环绕一圈 8 个（骑士走法见概率与统计/00 688 题）
```

## 3. 进位模拟：大数运算家族

### 3.1 加法的进位模板

```java
/** 67/415. 二进制/字符串加法：统一进位模板 */
String addStrings(String a, String b) {
    StringBuilder sb = new StringBuilder();
    int i = a.length() - 1, j = b.length() - 1, carry = 0;

    while (i >= 0 || j >= 0 || carry > 0) {     // ⚠️ 三者都空才结束
        int sum = carry;
        if (i >= 0) sum += a.charAt(i--) - '0';
        if (j >= 0) sum += b.charAt(j--) - '0';
        sb.append(sum % 10);                    // ⚠️ 当前位
        carry = sum / 10;                       // 进位
    }
    return sb.reverse().toString();             // ⚠️ 逆序拼接再反转
}
// 推演 "11" + "123"：
//   1+3=4 进位 0；1+2=3；0+1=1 → 逆序 [4,3,1] → 反转 "134" ✓
// ⚠️ 变体：
//   二进制（67）：sum % 2、carry = sum / 2
//   大数乘法（43）：双层循环 + 结果数组
```

### 3.2 乘法的竖式模板

```java
/** 43. 字符串相乘：竖式（结果数组先乘后进位） */
String multiply(String num1, String num2) {
    int m = num1.length(), n = num2.length();
    int[] res = new int[m + n];                 // ⚠️ 结果长度 ≤ m+n

    for (int i = m - 1; i >= 0; i--) {
        for (int j = n - 1; j >= 0; j--) {
            int mul = (num1.charAt(i) - '0') * (num2.charAt(j) - '0');
            int p1 = i + j, p2 = i + j + 1;     // ⚠️ 高位 + 低位位置
            res[p2] += mul;                     // 先累加不进位
            res[p1] += res[p2] / 10;            // 进位到高位
            res[p2] %= 10;                      // 低位取余
        }
    }
    // 去前导零 + 拼接
    StringBuilder sb = new StringBuilder();
    for (int v : res) if (!(sb.length() == 0 && v == 0)) sb.append(v);
    return sb.length() == 0 ? "0" : sb.toString();
}
// 推演 "123" × "45"：
//   3×5=15 → res[3]=5, res[2]=1；2×5=10 → ...
//   最终 res = [0,5,5,3,5] → "5535" ✓
// ⚠️ 面试表达："大数乘法 = 竖式模拟——
//   先'乘累加'（不进位），再'统一进位'（自低向高）。"
```

### 3.3 进位模拟的边界

```
⚠️ 三个边界：
  ① 最高位进位（如 999+1 → 1000）：循环条件含 carry > 0
  ② 前导零（乘法结果 0 开头）：拼接时跳过
  ③ 负数/小数点：先处理符号/小数位再模拟

⚠️ 面试表达：
"进位模拟的三坑——最高位进位、前导零、
 符号处理。模板里 while 条件带 carry 是
 最高位进位的保障。"
```

## 4. 时间与日期的模拟

### 4.1 时间换算模板

```
时间模拟通用套路：
  ① 统一到最小单位（如秒/分钟）再计算
  ② 计算完再拆回（h = total / 60 等）
  ③ 24 小时制取模（(h + 24) % 24 防负数）

⚠️ 面试表达：
"时间类模拟先'降单位'——统一到分钟/秒
 再算，避免跨小时/天的进位错误。"
```

### 4.2 日期计算的要点

```
日期模拟（月/日/闰年）：
  ① 月份天数数组（二月特判闰年）
  ② 闰年：%4==0 且 (%100!=0 || %400==0)
  ③ 跨月/跨年的进位（模拟日历）

⚠️ 工程提示：
  Java 有 LocalDate（Date API）——模拟题
  通常要求手写（不用库），面试先问清
```

## 5. 模拟的边界与正确性验证

### 5.1 边界清单

| 边界 | 风险 |
|------|------|
| 空输入 | 越界 |
| 单元素 | 循环条件 |
| 极端值（最大/最小） | 溢出 |
| 最高位进位 | 长度 |
| 前导零 | 格式 |
| 方向越界 | 数组越界 |

### 5.2 正确性验证方法

```
① 小样例手推：3-5 个元素逐步推演
② 边界样例：空/单元素/最大最小
③ 状态机核对：每个转移规则都覆盖
④ 输出断言：中间状态打印/断点

⚠️ 面试表达：
"模拟题的正确性来自'规则翻译'的完整——
 每条规则都要有对应代码分支。
 手推小样例 + 边界样例是标准验证。"
```

### 5.3 模拟题的复杂度表达

```
模拟复杂度 = 步数 × 每步代价
  螺旋：O(mn)（每格一次）
  大数加法：O(max(m,n))
  大数乘法：O(mn)
  机器人：O(指令数 × 障碍判断)

⚠️ 面试表达：
"模拟题复杂度 = 模拟步数 × 单步代价——
 说清楚'模拟了 O(k) 步、每步 O(c)'即可。"
```

## 6. 模拟 vs 数学 vs 找规律

### 6.1 选型对比

| 维度 | 模拟 | 数学 | 找规律 |
|------|:---:|:---:|:---:|
| 思路 | 逐步执行规则 | 公式推导 | 小规模归纳 |
| 正确性 | 规则忠实 | 推导严谨 | 需证明 |
| 复杂度 | 步数相关 | 最优（O(1)） | 最优 |
| 适用 | 过程明确 | 有闭式解 | 有规律 |

```
⚠️ 选型判断：
  过程明确且短 → 模拟（直接）
  过程长但可归纳 → 数学（求和/周期）
  规模巨大 → 必须数学/规律（模拟超时）

⚠️ 面试表达：
"模拟是'忠实执行'——规则复杂但直接；
 数学是'发现本质'——过程有周期/公式时
 复杂度从 O(步数) 降到 O(1)。
 先评估：步数是否可控？可控模拟，否则找规律。"
```

### 6.2 模拟题的典型陷阱

```
① 规则读漏（边界条件没翻译）
② 方向/进位状态忘更新
③ 循环条件少一项（如 carry）
④ 贪图"一步到位"（先模拟再优化）

⚠️ 工程建议：模拟题"先正确后优化"——
  第一步忠实翻译规则，通过后再考虑数学
```

### 7.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 循环少 carry 条件 | 最高位丢失 | while 含 carry |
| 方向忘更新 | 死循环/错序 | 每步更新 d |
| 乘法忘前导零处理 | 格式错 | 拼接跳过 0 |
| 规则翻译不全 | 结果错 | 状态机核对 |
| 边界未测 | 越界 | 小样例+边界 |
