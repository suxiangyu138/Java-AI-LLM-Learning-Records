## 1. 319. 灯泡开关

### 1.1 题目与思路

```
n 个灯泡，第 i 轮翻转所有 i 的倍数，最终亮着的数量
洞察：灯泡 k 被翻转的次数 = k 的因子个数
  因子成对（a×b=k）→ 奇数次 = 完全平方数
  亮着的 = 完全平方数 → 答案 = ⌊√n⌋
⚠️ 数据规模可达 10⁹ → 必须数学（模拟 O(n√n) 不可行）
```

### 1.2 完整代码

```java
/**
 * LeetCode 319. 灯泡开关
 * ⚠️ 亮着 = 因子数为奇数的位置 = 完全平方数
 */
public int bulbSwitch(int n) {
    return (int) Math.sqrt(n);          // ⚠️ 一行结论：⌊√n⌋ 个完全平方
}
// 推演 n=3：亮 1（√1）、灭 2（因子 1,2）、灭 3（因子 1,3）→ 1 ✓
//   完全平方数 1,4,9,16... 在 1..n 中有 ⌊√n⌋ 个 ✓
// 证明：
//   灯泡 k 被翻转 k 的每个因子轮
//   因子成对 (a,b)：a×b=k，翻转两次抵消
//   只有 a=b（完全平方）时多翻一次 → 亮
// ⚠️ 面试表达："319 = 因子奇偶性——
//   因子成对抵消，完全平方数因子数为奇数。
//   从'翻转次数'到'因子个数'是这题的洞察跳板。"
```

## 2. 1025. 除数博弈

### 2.1 题目与思路

```
n 开始，轮流选 x（n%x==0 且 x<n）用 n-x 继续，无法操作者输
洞察（01 模块 2 节必败态分析）：
  n=1 输；n=2 赢；n=3 输；n=4 赢...
  奇数必输、偶数必赢
⚠️ 证明：奇数因子都是奇数 → 只能变偶数；
  偶数可选 1 变奇数 → 永远把奇数留给对手
```

### 2.2 完整代码

```java
/**
 * LeetCode 1025. 除数博弈
 */
public boolean divisorGame(int n) {
    return n % 2 == 0;                  // ⚠️ 偶数赢、奇数输
}
// 推演：
//   n=2：先手选 1 → n=1 → 对手无法操作 → 赢 ✓
//   n=3：先手只能选 1 → n=2 给对手 → 输 ✓
//   n=4：先手选 1 → n=3（必败态）给对手 → 赢 ✓
// 归纳证明：
//   奇数 n：因子全奇 → 只能变偶数（给对手必胜态）
//   偶数 n：选 1 → 变奇数（给对手必败态）
//   → 奇数必败、偶数必胜 ✓
// ⚠️ 面试表达："1025 的洞察是奇偶性——
//   偶数永远能选 1 把奇数给对手；
//   奇数只能把偶数给对手。必败态 = 奇数。"
```

## 3. 172. 阶乘后的零

### 3.1 题目与思路

```
n! 尾部零的个数
洞察：零 = 因子 10 = 因子 2×5
  2 的因子远多于 5 → 数 5 的因子即可
  count = n/5 + n/25 + n/125 + ...
⚠️ n 可达 10⁹ → 数学（模拟阶乘不可行）
```

### 3.2 完整代码

```java
/**
 * LeetCode 172. 阶乘后的零
 */
public int trailingZeroes(int n) {
    int count = 0;
    while (n > 0) {
        n /= 5;                         // ⚠️ 数 5、25、125... 的贡献
        count += n;
    }
    return count;
}
// 推演 n=25：
//   25/5=5（5,10,15,20,25 各 1 个 5）；5/5=1（25 多 1 个）
//   count = 5+1 = 6 ✓（25! 有 6 个尾零）
// 推演 n=5：5/5=1 → 1 ✓（5! = 120）
// ⚠️ 证明：每 5 个数有一个 5 的倍数（n/5）；
//   每 25 个数多一个 5（n/25）... 累加即总数
// ⚠️ 面试表达："尾部零 = 因子 2×5——
//   2 永远够用（每隔一个数就有），
//   只需数 5 的幂次贡献。"
```

## 4. 292. Nim 游戏

### 4.1 题目与思路

```
每次拿 1-3 块，拿完最后一块者赢（先手）
必败态 = 4 的倍数（对手总能补回 4）
⚠️ 证明见枚举/02（同一题双视角）
```

### 4.2 完整代码

```java
/**
 * LeetCode 292. Nim 游戏
 */
public boolean canWinNim(int n) {
    return n % 4 != 0;                  // ⚠️ 4 的倍数必败
}
// 推演：
//   n=4：先手拿 1-3 → 后手补到 0 → 后手赢 ✓ 必败
//   n=7：先手拿 3 → 剩 4 给后手 → 后手必败 → 先手赢 ✓
// 归纳证明：
//   4k：先手拿 x（1-3）→ 后手拿 4-x → 剩 4(k-1)
//   → 后手永远把 4 的倍数留给先手 → 最后 4 块先手拿不完
//   → 4 的倍数必败 ✓
// ⚠️ 变体：一次拿 1-m → 必败态 = (m+1) 的倍数（同构）
// ⚠️ 面试表达："Nim 是必败态分析的入门题——
//   '4 的倍数'规律的发现路径：枚举 1-10 →
//   4,8 必败 → 归纳证明。"
```

## 5. 389. 找不同

### 5.1 题目与思路

```
s 与 t（多一个字符，其余乱序）→ 找出多出的字符
异或：两个字符串全部字符异或 → 落单者
⚠️ 变体：哈希计数、排序对比（异或最优 O(1) 空间）
```

### 5.2 完整代码

```java
/**
 * LeetCode 389. 找不同（异或）
 */
public char findTheDifference(String s, String t) {
    char result = 0;
    for (char c : s.toCharArray()) result ^= c;    // ⚠️ 成对抵消
    for (char c : t.toCharArray()) result ^= c;    // 多出的字符剩下来
    return result;
}
// 推演 s="abcd", t="abcde"：
//   全部异或：a^b^c^d ^ a^b^c^d^e = (a^a)^...^(e) = e ✓
// ⚠️ 复杂度：O(n)，O(1) 空间
// ⚠️ 面试表达："异或三性质（自消/恒等/交换）——
//   两个字符串整体异或，成对抵消，
//   唯一落单的就是答案。'找落单'= 异或。"
```

## 6. 458. 可怜的小猪

### 6.1 题目与思路

```
buckets 桶水中一桶有毒，小猪喝后 minutesToDie 分钟死亡
minutesToTest 分钟内找出毒桶，最少需要几只猪
信息论（01 模块 5 节）：
  每只猪可实验轮数 = minutesToTest / minutesToDie
  状态数 = 轮数 + 1（含存活）→ 进制 = 轮数+1
  猪数 = ⌈log(进制)(buckets)⌉
⚠️ 注意：轮数为 0 时特判（1 只猪只能测 1 桶？）
```

### 6.2 完整代码

```java
/**
 * LeetCode 458. 可怜的小猪（信息论）
 */
public int poorPigs(int buckets, int minutesToDie, int minutesToTest) {
    int rounds = minutesToTest / minutesToDie;     // 每只猪的轮数
    if (rounds == 0) return buckets - 1;           // ⚠️ 无法测试 → 每桶一只
    int base = rounds + 1;                         // ⚠️ 进制（轮数+存活）

    int pigs = 0;
    int capacity = 1;                              // base^pigs
    while (capacity < buckets) {
        capacity *= base;                          // ⚠️ 容量指数增长
        pigs++;
    }
    return pigs;
}
// 推演 buckets=1000, die=15, test=60：
//   rounds = 4 → base = 5 → 5^5 = 3125 ≥ 1000 → pigs = 5 ✓
//   5 只猪 = 5 进制 5 位数 = 3125 种状态 ≥ 1000 桶 ✓
// ⚠️ 面试表达："458 是信息论题——每只猪提供
//   (轮数+1) 种状态（哪轮死/没死），
//   m 只猪 = (轮数+1)^m 种区分能力。
//   猪数 = 最小 m 使 base^m ≥ buckets。"
// ⚠️ 边界：rounds=0 时 base=1 → 每桶要一只猪（减去最后一桶）
```

## 7. 507. 完美数

### 7.1 题目与思路

```
完美数 = 所有真因子之和等于自身（如 28 = 1+2+4+7+14）
因子枚举：只到 √n（因子成对）
⚠️ 注意：不包括自身、包括 1
```

### 7.2 完整代码

```java
/**
 * LeetCode 507. 完美数
 * ⚠️ 因子成对枚举到 √n
 */
public boolean checkPerfectNumber(int num) {
    if (num <= 1) return false;                  // ⚠️ 1 不是完美数

    int sum = 1;                                 // 因子 1（始终是）
    for (int i = 2; i * i <= num; i++) {         // ⚠️ 只到 √n
        if (num % i == 0) {
            sum += i;
            if (i != num / i) sum += num / i;    // ⚠️ 成对因子（防平方重复）
        }
    }
    return sum == num;
}
// 推演 28：因子 1+2+4+7+14 = 28 ✓
//   枚举 i=2,4（√28≈5.3）；4 的配对 7 → 1+2+4+7+14=28 ✓
// 推演 6：1+2+3 = 6 ✓；推演 12：1+2+3+4+6=16 ≠ 12 ✗
// ⚠️ 复杂度：O(√n)
// ⚠️ 面试表达："507 = 因子成对枚举——
//   只到 √n，配对因子一次加俩；
//   平方数特判（i == num/i 不重复加）。"
```

## 8. 脑筋急转弯方法论总结

### 8.1 题型与洞察映射

| 洞察类型 | 识别信号 | 代表题 |
|---------|---------|--------|
| 因子奇偶 | 开关/操作次数 | 319 |
| 必败态 | 轮流博弈 | 292、1025 |
| 因子计数 | 尾零/因子和 | 172、507 |
| 异或 | 找落单/不同 | 389、136 |
| 信息论 | 最少实验 | 458 |
| 对称性 | 与 n 无关 | 1227 |

### 8.2 解题五步（每个题都过一遍）

```
① 规模评估：数据多大？模拟可行？
   10⁹ → 数学/规律
② 小规模枚举：手算 8-10 个值
③ 序列观察：差分/奇偶/取模找模式
④ 猜规律 + 反例检查（边界/奇偶/外推）
⑤ 证明（归纳/反证）+ 代码 O(1) 或 O(√n)

⚠️ 识别信号：
  "巨大数据 + 简单规则" → 规律
  "轮流操作/博弈" → 必败态
  "最少实验/最多区分" → 信息论
```

### 8.3 自测清单

```
□ 数据规模评估（模拟 vs 数学）？
□ 小规模枚举 ≥ 8 个值？
□ 规律有证明（归纳/反证）？
□ 边界特判（0/1/负/超界）？
□ 因子枚举到 √n + 配对？
□ 异或/位运算用对？
□ 进制公式正确（轮数+1）？
```
