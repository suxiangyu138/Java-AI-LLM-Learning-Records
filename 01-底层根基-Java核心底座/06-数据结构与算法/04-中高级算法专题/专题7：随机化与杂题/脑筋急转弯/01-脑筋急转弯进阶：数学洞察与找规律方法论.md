## 1. 找规律的五步方法论

### 1.1 五步流程

```
① 小规模枚举：手动算 n=1,2,3,4... 的结果
② 列表观察：结果序列找模式（周期/递推/条件）
③ 猜规律：给出公式或规则
④ 验证：更大规模检验（或程序验证）
⑤ 证明：数学归纳/反证（面试加分项）

⚠️ 面试表达：
"找规律 = 小规模枚举 → 序列观察 → 猜规律
 → 扩大验证 → 归纳证明。五步缺一不可——
 尤其'证明'，只猜不证在面试中会失分。"
```

### 1.2 序列观察的技巧

```
常见模式：
  周期：结果按周期重复（Nim 的 4 周期）
  递推：f(n) 依赖 f(n-1)/f(n-2)
  条件分支：奇偶/整除/大小
  常数：结果与 n 无关（1227 飞机座位 1/2）

⚠️ 观察技巧：
  多算几个（至少 8-10 个）
  看差分（一阶/二阶差）
  分奇偶看两列
  对 n 取模看

⚠️ 面试表达：
"序列观察的常用技巧：差分、奇偶分列、
 取模看周期——三个视角都试过再下结论。"
```

### 1.3 识别"脑筋急转弯"信号

```
⚠️ 题型信号：
  ① 数据规模巨大（10⁹+）→ 不可能是模拟 → 必有规律
  ② 描述反直觉（"意想不到"）→ 数学洞察
  ③ 一行结论可解（%4、完全平方、异或）
  ④ 博弈类（轮流操作）

⚠️ 反直觉信号：
  "与 n 无关/恒为某值" → 对称性/守恒
  "奇偶决定胜负" → 奇偶性分析
```

## 2. 博弈类：必败态分析

### 2.1 必胜态/必败态理论

```
博弈状态分类：
  必败态（P）：无论怎么走，对手都有必胜回应
  必胜态（N）：存在一步走到必败态

递推判定（小规模枚举的基础）：
  P 状态：所有后继都是 N
  N 状态：存在后继是 P

⚠️ 通用分析流程：
  ① 从终局反推（终局往往是 P/N 确定）
  ② 递推标记小规模状态
  ③ 观察必败态的规律（如 4 的倍数）

⚠️ 面试必答：
"'必败态'是博弈题的钥匙——从终局反推
 标记小规模，找必败态集合的规律。
 Nim 的 4 倍数、除法博弈的偶数都是
 这样发现的。"
```

### 2.2 例子：除法博弈（1025）

```
1025 除数博弈：
  n 为偶数 → 先手必赢（选 1，变奇数给对手）
  n 为奇数 → 先手必输（只能选奇数因子 → 变偶数）

分析：
  n=1：先手无法操作 → 输（P）
  n=2：选 1 → n=1 给对手 → 赢（N）
  n=3：只能选 1 → n=2 给对手 → 输（P）
  n=4：选 1 → n=3（P）→ 赢（N）
  → 规律：奇数 P、偶数 N ✓

⚠️ 面试表达：
"除法博弈的洞察：奇数只有奇数因子 → 
 只能变偶数；偶数可选 1 变奇数。
 奇偶性就是必胜态规律。"
```

### 2.3 博弈规律的验证

```
⚠️ 验证三步：
  ① 小规模标记（1-20 手推）
  ② 规律与标记一致
  ③ 证明（归纳：P 的后继全 N、N 存在 P 后继）

⚠️ 反例优先：找到规律后立刻找反例
  "4 的倍数必败" → 检查 8、12...
  反例推翻 → 修正规律
```

## 3. 数论洞察：因子与完全平方

### 3.1 因子配对

```
因子成对出现：n = a × b（a ≤ √n ≤ b）
完全平方数：有一对相等（√n 自己）

⚠️ 应用（319 灯泡开关）：
  灯泡开关次数 = 因子个数
  奇数次开关 = 因子数为奇数 = 完全平方数
  → 亮着的 = 完全平方数位置

⚠️ 面试必答：
"因子成对是数论基本洞察——只有完全平方数
 的因子个数是奇数。'开关奇偶'类问题
 都归约到因子奇偶。"
```

### 3.2 因子计数与阶乘尾部零

```
172 阶乘后的零：
  零来自因子 2×5
  2 的个数远多于 5 → 只需数 5 的因子
  count = n/5 + n/25 + n/125 + ...

⚠️ 面试表达：
"尾部零 = 因子 10 = 因子 2×5——
 数 5 的因子即可（2 永远够用）。
 n/5 + n/25 + ... 是数'5 的贡献'。"
```

### 3.3 数论工具速查

| 洞察 | 应用 |
|------|------|
| 因子成对 | 319 灯泡（完全平方） |
| 因子计数 | 507 完美数 |
| 尾零 = 因子 5 | 172 |
| 奇偶性 | 1025、292 |
| 质因数分解 | 质数判断类 |
| 异或性质 | 389 找不同 |

## 4. 异或的巧妙应用

### 4.1 异或三性质

```
a ^ a = 0        （自己异或自己 = 0）
a ^ 0 = a        （与 0 异或不变）
交换律/结合律    （顺序无关）

⚠️ 应用（389 找不同）：
  两个字符串异或全部字符 → 落单的字符

⚠️ 面试必答：
"异或三性质是'找落单'问题的标准武器——
 成对抵消、落单保留。136 只出现一次、
 389 找不同、461 汉明距离全用它。"
```

### 4.2 异或题型的识别

```
识别信号：
  "找只出现一次/不同的元素" → 异或
  "成对 + 一个落单" → 异或
  "位运算可简化" → 异或/位计数

⚠️ 与计数的关系：
  异或 = 计数 mod 2（出现偶数次抵消）
  位计数 = 计数 mod k（137 题，见计数专题）

⚠️ 面试表达：
"'成对抵消'与'mod 2'同义——异或是
 计数思想在位运算的投影。"
```

## 5. 信息论推理：最少实验设计

### 5.1 信息论的实验设计（458 小猪）

```
458 可怜的小猪：
  minutesToTest / minutesToDie 决定"每个小猪能试几轮"
  每轮实验有 k+1 种结果（k 轮 + 存活）
  → 1 只小猪提供 k+1 进制的一位数
  → 需要的小猪 = ⌈log(k+1)(buckets)⌉

⚠️ 面试必答：
"实验设计题用信息论：每只动物提供
 (轮数+1) 种状态（进制）→ 需要的动物数
 = ⌈logᵦ(buckets)⌉（b = 轮数+1）。
 这是'最少实验次数'的通解。"
```

### 5.2 信息论推理的通用模式

```
实验设计三步：
  ① 确定每个实验体的"状态数"（k 轮 → k+1 态）
  ② 总信息量 = 状态数^实验体数
  ③ 需要实验体 = ⌈log_状态数(候选数)⌉

⚠️ 面试表达：
"最少实验 = 信息量计算——每个实验体
 携带 k+1 进制一位信息，总容量
 = (k+1)^m ≥ 候选数 → m 的最小值。"
```

## 6. 规律的正确性证明

### 6.1 三种证明方法

| 方法 | 适用 | 例子 |
|------|------|------|
| 数学归纳 | 递推规律 | Nim 4 的倍数 |
| 反证 | 必败态 | 博弈类 |
| 构造性 | 存在性 | 欧拉回路、字典序 |

```
⚠️ 归纳证明模板：
  ① 基础：n=1（或最小规模）成立
  ② 归纳假设：n=k 成立
  ③ 归纳步骤：n=k+1 由假设推出
  ④ 结论

⚠️ 面试表达：
"给规律必须配证明——归纳是标准姿势：
 基础 + 假设 + 步骤。'猜规律 + 证规律'
 完整表达是面试加分点。"
```

### 6.2 反例意识

```
⚠️ 规律验证的第一件事：找反例
  反例优先策略：
  ① 边界值（1、2、最大值）
  ② 对称情况（奇偶两侧）
  ③ 规律外推一步（4 的倍数 → 5 验证）

⚠️ 面试表达：
"给规律前先自问：有没有反例？
 边界、奇偶、外推一步——三个反例区
 都检查过才放心。"
```

## 7. 面试要点与追问

### 7.1 面试话术模板

```
"这类题数据规模大/反直觉 → 找规律。
 五步法：小规模枚举 → 观察序列 →
 猜规律 → 验证 → 归纳证明。
 这题的规律是【...】，证明：【...】。
 复杂度 O(1)（公式直接算）。"
```

### 7.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 怎么发现规律？ | 小规模枚举 + 序列观察（差分/奇偶/取模） |
| 2 | 博弈题通用方法？ | 必败态分析（终局反推标记） |
| 3 | 怎么证明规律？ | 归纳/反证/构造性 |
| 4 | 因子奇偶什么时候用？ | 开关/操作次数类（319） |
| 5 | 尾零怎么数？ | 因子 5 计数（n/5+n/25+...） |
| 6 | 异或解决什么？ | 成对抵消找落单 |
| 7 | 最少实验？ | 信息论：⌈logᵦ(候选数)⌉ |
| 8 | 反直觉结论怎么信？ | 小规模验证 + 证明 |

### 7.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 只猜不证 | 面试失分 | 归纳证明 |
| 序列算太少 | 规律猜错 | ≥8 个 |
| 忘反例检查 | 规律错误 | 边界/奇偶 |
| 大数硬模拟 | 超时 | 找规律 |
| 博弈不反推 | 找不到必败态 | 终局起手 |
