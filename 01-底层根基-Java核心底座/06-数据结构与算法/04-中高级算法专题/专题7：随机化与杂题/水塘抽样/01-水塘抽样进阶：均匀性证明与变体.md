## 1. 水塘抽样的原理

### 1.1 问题定义

```
问题：流式数据（长度未知或巨大），等概率抽样
  k=1：等概率取 1 个
  k=m：等概率取 m 个

⚠️ 为什么不能"先数长度再随机"：
  ① 数据可能无限（流式）
  ② 两次遍历成本高（一次扫描内存 O(1) 是目标）

⚠️ 核心思想（k=1）：
  第 i 个元素以 1/i 概率替换当前候选
  → 最终每个元素等概率 1/n

⚠️ 面试必答：
"水塘抽样 = 一次扫描 + O(1) 内存——
 第 i 个元素以 1/i 概率进入样本，
 数学归纳保证最终均匀。"
```

### 1.2 直觉：为什么 1/i

```
第 i 个元素被"考虑"时，前面 i-1 个的选中概率都是 1/(i-1)
新元素以 1/i 替换 → 前面元素保留概率 = (i-1)/i
→ 前面元素最终概率 = 1/(i-1) × (i-1)/i × ... 逐级相乘 = 1/n

⚠️ 直觉表达：
"每个新元素'挤掉'旧候选的概率是 1/i——
 旧候选能活下来必须连续通过所有后续
 淘汰关，概率相乘后恰好 1/n。"
```

## 2. k=1 的均匀性证明

### 2.1 数学归纳法

```
定理：遍历完 n 个元素后，每个元素被选中的概率 = 1/n

归纳证明：
  基础：n=1 → 唯一元素概率 1 ✓
  假设：前 n-1 个元素各 1/(n-1)
  步骤：
    第 n 个元素以 1/n 概率替换 → P(第 n 个) = 1/n ✓
    前 n-1 个元素保留概率 = 1/(n-1) × (1 - 1/n)
      = 1/(n-1) × (n-1)/n = 1/n ✓
  → 所有元素 1/n ✓

⚠️ 面试必答：
"水塘均匀性 = 数学归纳——
 新元素 1/i 替换，旧元素保留概率
 逐级相乘，最终全部 1/n。"
```

### 2.2 完整实现（382 链表随机节点）

```java
/** LeetCode 382. 链表随机节点（k=1 水塘） */
class Solution {
    private final ListNode head;
    private final Random rand = new Random();

    public Solution(ListNode head) { this.head = head; }

    public int getRandom() {
        ListNode cur = head;
        int result = 0, i = 1;
        while (cur != null) {
            if (rand.nextInt(i) == 0) {        // ⚠️ 1/i 概率
                result = cur.val;
            }
            i++;
            cur = cur.next;
        }
        return result;
    }
}
// ⚠️ 复杂度：O(n) 时间、O(1) 空间
// ⚠️ 面试必答："382 是水塘最小样板——
//   rand.nextInt(i) == 0 即 1/i 概率选中。"
```

## 3. k=m 的扩展证明

### 3.1 算法流程

```
k=m 水塘：
  ① 前 m 个元素全部进入样本
  ② 第 i 个元素（i > m）以 m/i 概率替换样本中随机一个

⚠️ 证明（归纳）：
  第 i 个元素进入概率 = m/i
  样本中某元素在 i 步后保留概率：
    = m/i × (1 - 1/m) = (m-1)/i（被替换概率 1/m 的条件）
  最终概率 = m/n ✓（同样的级联相乘）

⚠️ 面试必答：
"k=m 水塘：前 m 个全进，之后 m/i 概率
 替换样本中随机一个——每个元素最终
 概率 m/n，证明同样是归纳级联。"
```

### 3.2 完整实现

```java
/** k=m 水塘抽样（流式取 m 个） */
int[] reservoirSample(int[] stream, int m) {
    int[] sample = new int[m];
    Random rand = new Random();

    for (int i = 0; i < stream.length; i++) {
        if (i < m) {
            sample[i] = stream[i];             // ① 前 m 个全进
        } else {
            int j = rand.nextInt(i + 1);       // ⚠️ [0, i] 随机
            if (j < m) {
                sample[j] = stream[i];         // ② m/i 概率替换
            }
        }
    }
    return sample;
}
// ⚠️ rand.nextInt(i+1) < m ⟺ m/(i+1) 概率
// ⚠️ 应用：流式抽样广告/日志、大数据抽样
```

## 4. 加权水塘抽样

### 4.1 加权思想

```
元素有权重 w[i]，抽样概率 ∝ 权重
方法（Algorithm A-Res）：
  每个元素生成 key = u^(1/w)（u 是 [0,1] 随机数）
  取 key 最大的 m 个

⚠️ 为什么 u^(1/w)：权重越大 → key 越接近 1 → 更容易进 Top-m

⚠️ 面试必答：
"加权水塘 = 随机 key 法——
 每个元素 key = u^(1/w)（u 均匀随机），
 取最大 m 个。权重大的元素 key 期望更大。"
```

### 4.2 398 随机数索引的加权视角

```java
/** LeetCode 398. 随机数索引（同值元素等概率） */
class Solution {
    private final int[] nums;
    private final Random rand = new Random();

    public Solution(int[] nums) { this.nums = nums; }

    public int pick(int target) {
        int count = 0, result = -1;
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] == target) {
                count++;
                if (rand.nextInt(count) == 0) result = i;   // ⚠️ 1/count 概率
            }
        }
        return result;
    }
}
// ⚠️ 本质：对 target 的索引流做 k=1 水塘
//   （不知道 target 出现几次 → 水塘天然适配）
// ⚠️ 面试必答："398 = 对'命中流'做水塘——
//   命中第 count 次时 1/count 概率选中。"
```

## 5. 水塘 vs 拒绝采样 vs 洗牌

### 5.1 三种随机方法的对比

| 方法 | 场景 | 复杂度 | 内存 |
|------|------|:---:|:---:|
| 水塘抽样 | 流式/长度未知 | O(n) | O(k) |
| 拒绝采样 | 分布转换 | 期望 O(1/p) | O(1) |
| Fisher-Yates | 静态数组洗牌 | O(n) | O(1) |

```
⚠️ 关系：
  水塘 = "流式洗牌"（洗牌是静态版）
  拒绝采样 = 采样"分布"而非"流"

⚠️ 面试必答：
"三者分工——流式抽样水塘（长度未知）、
 分布转换拒绝采样（Rand 转换）、
 静态重排洗牌（Fisher-Yates）。
 水塘与洗牌本质同一思想（逐步替换）。"
```

### 5.2 选型决策

```
数据形态？
  流式/长度未知 → 水塘
  静态数组可重排 → 洗牌
  需要分布转换 → 拒绝采样/前缀和

⚠️ 面试表达：
"先问数据形态：流式水塘、静态洗牌、
 分布拒绝——形态决定方法。"
```

## 6. 随机化算法的复杂度分析

### 6.1 期望 vs 最坏 vs 高概率

```
随机化算法的三种保证：
  期望复杂度：平均表现（快排 O(n log n)）
  最坏复杂度：理论上限（快排 O(n²)）
  高概率保证：失败概率 ≤ 1/n^c（随机哈希）

⚠️ 水塘的保证：
  期望 O(n)（一次扫描）——确定性的！
  ⚠️ 水塘的随机性只影响"选谁"不影响"耗时"
  （对比快选：随机性影响耗时）

⚠️ 面试必答：
"水塘的复杂度是确定的 O(n)——
 随机性只决定抽样结果；快选/快排的
 随机性影响运行时间（期望分析）。"
```

### 6.2 随机算法的分类

| 类型 | 结果 | 时间 |
|------|:---:|:---:|
| 拉斯维加斯 | 一定正确 | 随机（快选） |
| 蒙特卡洛 | 概率正确 | 确定（随机近似） |
| 水塘抽样 | 一定正确 | 确定 O(n) |

```
⚠️ 面试必答：
"随机算法三分类——拉斯维加斯（结果对、
 时间随机）、蒙特卡洛（时间定、结果概率对）、
 水塘（都确定，随机只在抽样）。"
```

## 7. 面试要点与追问

### 7.1 面试话术模板

```
"水塘抽样解决'长度未知的流式等概率抽样'：
 第 i 个元素 1/i 概率替换（k=1），
 数学归纳证明均匀（1/n）。
 k=m：前 m 全进 + m/i 替换。
 复杂度 O(n) 时间 O(1) 空间，随机性不影响耗时。
 与洗牌同源、与拒绝采样分工（流式 vs 分布）。"
```

### 7.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| rand.nextInt(n) 固定 | 不均匀 | 1/i 随 i 变 |
