## 1. 382. 链表随机节点

### 1.1 题目与思路

```
链表长度未知 → 等概率随机返回一个节点
水塘 k=1：第 i 个节点 1/i 概率替换
⚠️ 完整证明见 01 模块 2 节
```

### 1.2 完整代码

```java
/**
 * LeetCode 382. 链表随机节点（水塘 k=1）
 */
class Solution {
    private final ListNode head;
    private final Random rand = new Random();

    public Solution(ListNode head) { this.head = head; }

    public int getRandom() {
        ListNode cur = head;
        int result = 0, i = 1;
        while (cur != null) {
            if (rand.nextInt(i) == 0) {        // ⚠️ 1/i 概率选中
                result = cur.val;
            }
            i++;
            cur = cur.next;
        }
        return result;
    }
}
// 推演 [1,2,3]（模拟一次）：
//   i=1：rand(1)==0 必中 → result=1
//   i=2：1/2 概率 → result=2
//   i=3：1/3 概率 → result=3
//   最终概率：P(3)=1/3；P(2)=2/3×1/2=1/3；P(1)=2/3×1/2×1=1/3 ✓
// ⚠️ 复杂度：O(n) 时间、O(1) 空间
// ⚠️ 面试必答："382 = 水塘最小样板——
//   rand.nextInt(i)==0 即 1/i 概率；
//   推演三个元素验证均匀性。"
```

## 2. 398. 随机数索引

### 2.1 题目与思路

```
数组含重复值，pick(target) 等概率返回 target 的某个下标
方法：对"命中流"做水塘（不知道 target 出现几次）
⚠️ 对比简单法：先收集所有下标（O(n) 空间）——水塘 O(1)
```

### 2.2 完整代码

```java
/**
 * LeetCode 398. 随机数索引（命中流水塘）
 */
class Solution {
    private final int[] nums;
    private final Random rand = new Random();

    public Solution(int[] nums) { this.nums = nums; }

    public int pick(int target) {
        int count = 0, result = -1;
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] == target) {
                count++;                       // 命中次数
                if (rand.nextInt(count) == 0) {
                    result = i;                // ⚠️ 1/count 概率替换
                }
            }
        }
        return result;
    }
}
// 推演 nums=[1,2,3,3,3], pick(3)：
//   命中流 [2,3,4]（下标）
//   i=2：count=1 → 必中 → result=2
//   i=3：count=2 → 1/2 → result=3
//   i=4：count=3 → 1/3 → result=4
//   最终概率各 1/3 ✓
// ⚠️ 复杂度：O(n) 时间、O(1) 空间
// ⚠️ 面试必答："398 = 对'命中下标流'做 k=1 水塘——
//   命中的第 count 个以 1/count 概率选中，
//   无需知道 target 总出现次数。"
```

## 3. 命中流水塘模式

### 3.1 模式抽象

```
"命中流水塘" = 边过滤边抽样：
  for (元素 : 流) {
      if (满足条件) {           // 过滤出"命中流"
          count++;
          if (rand.nextInt(count) == 0) result = 当前;
      }
  }

⚠️ 应用场景：
  398 随机数索引（命中 = 值等于 target）
  随机抽样满足条件的元素（年龄/类型过滤）
  流式随机挑选某类事件

⚠️ 面试必答：
"'命中流水塘'是水塘的过滤形态——
 先条件过滤再对命中流抽样；
 无需知道命中总数。"
```

### 3.2 模式验证

```
⚠️ 正确性：命中流就是"长度未知的流"
  → 水塘定理直接适用（对命中元素编号即可）

⚠️ 面试表达：
"过滤不破坏均匀性——命中流本身
 是未知长度的流，水塘对其直接生效。"
```

## 4. 采样方法选型实战

### 4.1 五题方法全景

| 题目 | 方法 | 为什么 |
|------|------|--------|
| 382 链表随机 | 水塘 k=1 | 长度未知 |
| 398 随机索引 | 命中流水塘 | 同值个数未知 |
| 384 洗牌 | Fisher-Yates | 静态数组 |
| 470 Rand 转换 | 拒绝采样 | 分布转换 |
| 528 加权随机 | 前缀和+二分 | 权重已知 |

```
⚠️ 选型决策：
  数据流式/长度未知 → 水塘
  静态可重排 → 洗牌
  分布转换 → 拒绝采样
  权重已知 → 前缀和映射
```

### 4.2 采样题的共同骨架

```
所有采样题四步：
  ① 数据形态（流式/静态/分布）
  ② 均匀性要求（等概率/加权）
  ③ 方法选型（池塘/洗牌/拒绝/映射）
  ④ 数学验证（均匀性证明/接受率）

⚠️ 面试必答：
"采样题先答'形态 + 要求 + 方法 + 证明'
 四件套——方法选型正确 + 数学验证
 完整是采样题满分答案。"
```

## 5. 水塘方法论总结

### 5.1 解题框架

```
① 识别：流式/长度未知 + 等概率 → 水塘
② 定 k：抽 1 个 → k=1（1/i）；抽 m 个 → k=m（m/i）
③ 过滤：有条件的流 → 命中流水塘
④ 证明：数学归纳（1/n 或 m/n）
⑤ 复杂度：O(n) 时间、O(k) 空间

⚠️ 识别信号：
  "未知长度/流式 + 等概率" → 水塘
  "重复值的随机下标" → 命中流水塘
```

### 5.2 自测清单

```
□ 概率 1/i（随 i 变化）？
□ 替换逻辑正确（k=m 随机位置）？
□ 均匀性证明能讲？
□ 过滤流（398）？
□ O(1) 空间？
□ 与洗牌/拒绝采样区分？
```
