## 1. 核心概念

### 1.1 随机化的价值

> 随机化：用**随机选择**代替固定选择，把"最坏情况"变成"期望情况"。常见于**防退化**和**等概率采样**。

```
两大应用：
  ① 随机化算法（防退化）
     快排/快选：随机基准 → 期望 O(n log n)
     有序数组 + 固定基准 → 最坏 O(n²)

  ② 随机采样（等概率）
     洗牌：Fisher-Yates
     水塘抽样：流式等概率
     拒绝采样：生成目标分布

本质：把"对手构造的最坏输入"变成"期望均匀"
（随机化让坏情况概率趋近 0）
```

### 1.2 识别信号

```
"打乱数组/随机节点" → 采样类
"快排/快选超时" → 随机化基准
"流式等概率" → 水塘抽样
"用 X 实现 Y 随机" → 拒绝采样

⚠️ 面试定位：中低频，但快排随机化是必答
```

### 1.3 随机化 vs 确定性

```
确定性算法：结果确定，最坏可预测
随机化算法：期望好，最坏概率极低

⚠️ 面试表达：
"确定性算法最坏 X，我用随机化把期望降到 Y，
 最坏情况概率为 0（指数级小）。"
```

## 2. 完整代码模板

### 2.1 384. 打乱数组（Fisher-Yates 洗牌）

```java
/**
 * LeetCode 384. 打乱数组（Fisher-Yates 洗牌）
 * 每个排列等概率 1/n!
 */
class Solution {
    private int[] original;
    private int[] nums;
    private Random random = new Random();

    public Solution(int[] nums) {
        this.nums = nums;
        this.original = nums.clone();
    }

    public int[] reset() {
        nums = original.clone();
        return nums;
    }

    public int[] shuffle() {
        // ⚠️ 从后往前：i 与 [0, i] 随机位置交换
        for (int i = nums.length - 1; i > 0; i--) {
            int j = random.nextInt(i + 1);      // ⚠️ 包含 i
            int tmp = nums[i];
            nums[i] = nums[j];
            nums[j] = tmp;
        }
        return nums;
    }
}
// 推演 [1,2,3]：
//   i=2：与 [0,2] 随机交换（如换到 1 → [1,3,2]）
//   i=1：与 [0,1] 随机交换（如换到 0 → [3,1,2]）
//   i=0：结束
// 每个排列概率 = 1/3! ✓
```

### 2.2 215. 快选（随机基准防退化）

```java
/**
 * 快速选择：随机基准是防退化的关键
 * ⚠️ 有序数组 + 固定基准 → 每次只排除 1 个 → O(n²)
 */
public int quickSelect(int[] arr, int lo, int hi, int k) {
    if (lo == hi) return arr[lo];

    // ⚠️ 随机基准（防有序数组退化）
    int idx = lo + new Random().nextInt(hi - lo + 1);
    swap(arr, idx, hi);

    int pivot = arr[hi];
    int i = lo - 1;
    for (int j = lo; j < hi; j++) {
        if (arr[j] < pivot) swap(arr, ++i, j);
    }
    swap(arr, i + 1, hi);

    if (i + 1 == k) return arr[i + 1];
    else if (i + 1 < k) return quickSelect(arr, i + 2, hi, k);
    else return quickSelect(arr, lo, i, k);
}
// 期望 O(n)：随机基准 → 期望均匀划分
// ⚠️ 面试必答："为什么随机化？防有序输入退化"
```

### 2.3 382. 链表随机节点（水塘抽样）

```java
/**
 * LeetCode 382. 链表随机节点（水塘抽样）
 * 流式等概率：第 i 个元素以 1/i 概率替换候选
 */
public int getRandom() {
    ListNode cur = head;
    int result = 0, count = 0;

    while (cur != null) {
        count++;
        if (random.nextInt(count) == 0) {    // 1/count 概率
            result = cur.val;                // 替换候选
        }
        cur = cur.next;
    }
    return result;
}
// O(n) 时间 O(1) 空间（无法预知长度）
// 数学归纳保证每个节点概率 1/n
```

## 3. 随机化原理详解

### 3.1 为什么随机基准能防退化

```
快排最坏：固定基准（首/尾）+ 有序数组
  → 每次分区只排除一个元素 → O(n²)

随机基准：任何输入下基准位置均匀分布
  → 期望划分均衡 → 期望 O(n log n)
  → 最坏 O(n²) 概率 = (1/n)^n 趋近 0

⚠️ 等价方案：
  三数取中（确定性，防有序退化）
  随机化（概率性，防一切恶意输入）
  → 面试说随机化或三数取中均可
```

### 3.2 随机化的代价

```
代价一：结果不确定（同一输入可能不同输出）
  ⚠️ 快排结果确定（排序正确性不受影响）
  但快选的最坏时间不可预测

代价二：需要随机源（Random 对象）
  工程：ThreadLocalRandom（并发安全）

代价三：调试困难（难以复现）
  ⚠️ 工程上可固定种子复现

⚠️ 面试表达：
"随机化的代价是输出/时间不确定，
 但正确性不受影响；可固定种子复现。"
```

### 3.3 确定性替代方案

```
三数取中（防有序退化）：
  取 lo/mid/hi 中位数做基准
  → 有序数组也均衡（确定性的）

随机化 vs 三数取中：
  随机：防一切恶意输入（概率性）
  三数取中：防有序输入（确定性，但可被构造）

面试推荐：三数取中（简单确定）
  或"随机 + 三数取中"双保险
```

## 4. 等概率采样的正确性

### 4.1 Fisher-Yates 的归纳证明

```
归纳假设：前 k 步后，前 k 个位置的排列等概率

第 k 步：位置 k 与 [0, k] 随机交换
  → 每个元素到位置 k 的概率 = 1/(k+1)
  → 前 k 个位置的元素概率不变（条件概率）
  → 归纳成立

⚠️ 为什么从后往前？
  每次只处理"未洗"部分（保证均匀）
  从前往后处理会破坏概率均匀性
```

### 4.2 水塘抽样的归纳证明

```
归纳假设：前 i-1 个元素等概率 1/(i-1)

第 i 个元素：
  选中概率 1/i（替换候选）
  前 i-1 个元素保留概率 = 1/(i-1) × (1 - 1/i) = 1/i
  → 前 i 个元素等概率 1/i ✓

结论：第 n 个元素到达时，每个元素概率 1/n
⚠️ 不需要知道 n（流式场景的核心价值）
```

### 4.3 水塘 vs 洗牌对比

```
水塘抽样：流式（未知总量、一次扫描、O(1) 空间）
洗牌：全量数组（可打乱，O(n) 空间）

选型：
  数据流/链表 → 水塘
  全量数组可修改 → 洗牌
  ⚠️ 面试把两个都讲清 = 加分
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"洗牌用 Fisher-Yates：从后往前遍历，
 第 i 个位置与 [0,i] 中随机位置交换。
 数学归纳可证每个排列等概率 1/n!。
 复杂度 O(n)，原地 O(1) 空间。
 快选用随机基准防有序数组退化 O(n²)。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 快排为什么必须随机？ | 固定基准被有序输入攻击 → O(n²) |
| 2 | Fisher-Yates 为什么从后往前？ | 只处理未洗部分保证均匀 |
| 3 | 水塘抽样为什么 1/i？ | 归纳证明：保留概率相乘 = 1/n |
| 4 | 随机化代价？ | 时间不确定；正确性不受影响；固定种子复现 |
| 5 | 三数取中 vs 随机？ | 确定性防有序；随机防一切（概率性） |
| 6 | 水塘 vs 洗牌？ | 流式 O(1) 空间 vs 全量 O(n) |
| 7 | ThreadLocalRandom？ | 并发安全（工程推荐） |
| 8 | 等概率怎么验证？ | 数学归纳 / 大样本统计 |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| nextInt(i) 不含 i | 概率不均匀 | nextInt(i+1) |
| 从前往后洗牌 | 概率偏斜 | 从后往前 |
| 忘随机基准 | 有序输入超时 | 随机交换 |
| 水塘概率错 | 不等概率 | 1/count 替换 |
| 忘 clone 原数组 | reset 失效 | 保存原始副本 |

> 🎯 **核心要点**：随机化 = **防退化（随机基准）+ 等概率（洗牌/水塘/拒绝采样）**。识别信号："打乱、随机节点、防超时"。快选的随机基准、Fisher-Yates 的从后往前、水塘的归纳证明是三大必背细节。
