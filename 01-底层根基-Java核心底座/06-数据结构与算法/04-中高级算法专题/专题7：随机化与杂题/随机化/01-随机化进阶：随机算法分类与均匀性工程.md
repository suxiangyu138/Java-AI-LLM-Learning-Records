## 1. 随机算法三分类

### 1.1 分类总览

| 类型 | 结果 | 时间 | 代表 |
|------|:---:|:---:|------|
| 拉斯维加斯 | 一定正确 | 随机 | 快选、随机快排 |
| 蒙特卡洛 | 概率正确 | 确定 | 随机近似、Bloom 过滤 |
| 随机采样 | 随机结果 | 确定 | 水塘、洗牌 |

```
⚠️ 面试必答：
"随机算法三分类——拉斯维加斯（对错确定、
 时间随机）、蒙特卡洛（时间确定、结果概率对）、
 采样（结果就是随机的，无所谓对错）。"
```

### 1.2 各类的典型场景

```
拉斯维加斯：快选/快排（随机基准防退化）
蒙特卡洛：蒙特卡洛积分、随机近似
采样：洗牌/水塘/拒绝采样（结果本身要随机）

⚠️ 面试表达：
"'防退化'用拉斯维加斯（快排随机基准）、
 '求近似'用蒙特卡洛（统计估计）、
 '要随机结果'用采样。三者目标不同。"
```

## 2. 均匀随机数的工程实现

### 2.1 Java 随机数体系

| 类 | 特点 | 用途 |
|------|------|------|
| Random | 伪随机、快、可种子 | 通用（非安全） |
| ThreadLocalRandom | 线程局部、更快 | 并发随机 |
| SecureRandom | 密码学安全 | 安全场景 |
| SplittableRandom | 可分裂 | 并行 |

```
⚠️ 面试必答：
"Random 是伪随机（线性同余）——快但可预测；
 SecureRandom 是密码学安全（熵源）——
 安全场景（哈希种子/令牌）必须用它。"
```

### 2.2 均匀性验证

```
⚠️ 验证随机算法的均匀性：
  ① 大量采样统计频率（10⁶ 次 → 频率 ≈ 理论概率）
  ② 数学推导（归纳/对称性）
  ③ 边界检查（0 和 n-1 的概率）

⚠️ 面试表达：
"均匀性验证两条路——数学证明（归纳/对称）
 与统计验证（大样本频率）。面试给数学证明。"
```

### 2.3 常见均匀性陷阱

```
① rand.nextInt(n) vs rand.nextInt() % n（模偏差）
② 洗牌用 [0, n) 而非 [0, i]（不均匀）
③ 拒绝采样忘边界（接受率计算错）
④ 随机种子固定（结果可预测）

⚠️ 面试必答：
"均匀性陷阱——洗牌必须在 [0, i] 内取、
 拒绝采样算准接受率、安全场景随机种子
 不能固定。"
```

## 3. 随机种子与安全性

### 3.1 种子的作用

```
种子 → 伪随机序列（同种子同序列）
用途：可复现实验（测试）、HashDoS 防御（随机种子）

⚠️ 安全风险：
  固定种子 → 序列可预测 → 抽样可被操纵
  例：抽奖/AB 测试用固定种子 → 结果可预测

⚠️ 面试必答：
"随机种子决定序列——测试要可复现（固定），
 生产要不可预测（真随机/安全随机）。"
```

### 3.2 SecureRandom 的使用

```java
// 安全随机（密码/令牌/安全哈希种子）
SecureRandom secure = new SecureRandom();
byte[] token = new byte[32];
secure.nextBytes(token);                   // ⚠️ 熵源驱动

// 场景：
//   HashDoS 种子（JVM 启动随机化）
//   API 令牌/会话 ID
//   密码盐（详见密码学哈希专题）
// ⚠️ 面试必答："安全场景用 SecureRandom——
//   Random 可预测，令牌/盐/种子
//   被预测 = 安全被攻破。"
```

## 4. 随机化在算法设计中的角色

### 4.1 三大角色

```
① 防退化：随机基准（快排/快选）→ 期望最优
② 空间压缩：哈希随机化（布隆过滤器）→ 概率去重
③ 近似求解：蒙特卡洛 → 难问题的统计近似

⚠️ 面试必答：
"随机化三角色——防退化（快排）、
 压缩（布隆）、近似（蒙特卡洛）。
 用'概率换时间/空间'是随机化的本质。"
```

### 4.2 随机化的代价

```
代价一：概率性（极小概率出错）
代价二：不可复现（生产难调试）
代价三：安全审查（随机源质量）

⚠️ 面试表达：
"随机化是'用可接受的概率风险换确定性
 成本'——快排的 O(n²) 概率趋近 0、
 布隆的误判率可调。工程上要评估
 失败概率是否可接受。"
```

## 5. 去随机化与确定性

### 5.1 去随机化思想

```
去随机化：把随机算法改成确定性算法
  方法：
  ① 中位数法（快排三数取中 → 确定但弱）
  ② BFPRT（确定 O(n) 快选）
  ③ 双哈希（概率 → 高概率）

⚠️ 面试必答：
"去随机化的代表——BFPRT 用中位数的
 中位数替代随机基准，确定 O(n)；
 代价是常数变大。"
```

### 5.2 确定性与随机性的选择

| 场景 | 选型 |
|------|------|
| 面试手写 | 随机化（简单 + 期望最优） |
| 对抗性输入 | 确定性（BFPRT/树化） |
| 安全相关 | 确定性 + 安全随机 |
| 测试可复现 | 固定种子 |

```
⚠️ 面试表达：
"面试写随机化（代码简单）、生产防
 对抗输入用确定性结构（红黑树/
 BFPRT）——'随机化 vs 确定性'是
 复杂度与代码量的权衡。"
```

## 6. 随机化的复杂度分析

### 6.1 期望分析的写法

```
⚠️ 期望复杂度的论证模板：
  ① 定义随机变量（基准位置等）
  ② 写出递推（T(n) = T(随机) + O(n)）
  ③ 取期望（E[T(n)] = ... 几何级数）

例：快选的期望 O(n)：
  E[T(n)] = n + E[T(n/2)]（期望减半）
  = n + n/2 + n/4 + ... = 2n = O(n)

⚠️ 面试必答：
"期望复杂度论证三步——随机变量、
 递推方程、取期望求和。
 快选 O(n)：每次期望减半 → 几何级数。"
```

### 6.2 高概率保证

```
⚠️ 高概率（with high probability, whp）：
  失败概率 ≤ 1/n^c（c 是常数）

例：随机哈希表查找 whp O(1)
  证明：冲突概率指数下降（生日悖论 + 独立哈希）

⚠️ 面试必答：
"'高概率'是比'期望'更强的保证——
 期望 O(1) 允许偶尔退化，
 高概率 O(1) 把退化概率压到 1/n^c。"
```

```
"随机化 = 用概率换时间/空间。
 三分类：拉斯维加斯（结果对时间随机）、
 蒙特卡洛（时间定结果概率对）、采样（结果随机）。
 工程：Random（伪随机）vs SecureRandom（安全）。
 复杂度用期望分析（递推 + 取期望）。
 面试写随机化，生产防对抗用确定性。"
```
