## 1. 384. 打乱数组（Fisher-Yates）

### 1.1 题目与思路

```
洗牌（等概率排列）+ reset（恢复原样）
Fisher-Yates：从尾部向前，与 [0, i] 随机交换
⚠️ 均匀性证明（01 模块 2 节）
```

### 1.2 完整代码

```java
/**
 * LeetCode 384. 打乱数组
 */
class Solution {
    private final int[] original;
    private int[] nums;
    private final Random rand = new Random();

    public Solution(int[] nums) {
        this.nums = nums;
        this.original = nums.clone();          // ⚠️ 保存原始
    }

    public int[] reset() {
        nums = original.clone();               // 恢复
        return nums;
    }

    public int[] shuffle() {
        for (int i = nums.length - 1; i > 0; i--) {
            int j = rand.nextInt(i + 1);       // ⚠️ 必须在 [0, i]！
            int t = nums[i]; nums[i] = nums[j]; nums[j] = t;
        }
        return nums;
    }
}
// 均匀性证明：
//   第 i 步选中正确元素的概率 = 1/(i+1)
//   P(特定排列) = Π 1/(i+1) = 1/n! ✓ 所有排列等概率
// ⚠️ 常见错误：rand.nextInt(nums.length)（全范围）
//   → 某些排列概率不同（不均匀！）
// ⚠️ 面试必答："384 = Fisher-Yates——
//   [0, i] 内随机交换（不是 [0, n)）；
//   reset 用 clone 保存的原始数组。"
```

## 2. 519. 随机翻转矩阵

### 2.1 题目与思路

```
m×n 矩阵，每次随机选"未翻过"的位置翻成 1（不放回抽样）
尾部交换映射：随机 [0, remaining) + 映射被换走的位置
⚠️ 本质：不放回随机抽样（01 模块/拒绝采样/02 有基础版）
```

### 2.2 完整代码

```java
/**
 * LeetCode 519. 随机翻转矩阵
 * ⚠️ 尾部交换：抽走的位置用"剩余区尾部"补位
 */
class Solution {
    private final int rows, cols;
    private int remaining;
    private final Map<Integer, Integer> swapped = new HashMap<>();
    private final Random rand = new Random();

    public Solution(int m, int n) {
        rows = m; cols = n;
        remaining = m * n;
    }

    public int[] flip() {
        int r = rand.nextInt(remaining--);     // ⚠️ [0, remaining) 抽一个
        // ⚠️ 若 r 被换过（映射存在）→ 取映射值（即尾部原值）
        int x = swapped.getOrDefault(r, r);

        // 尾部交换：把剩余区最后一个（remaining）补到 r 的位置
        swapped.put(r, swapped.getOrDefault(remaining, remaining));

        return new int[]{x / cols, x % cols};  // 一维 → 二维
    }

    public void reset() {
        remaining = rows * cols;
        swapped.clear();
    }
}
// 推演 2×2（4 位置），flip 三次：
//   flip1：r=2 → 返回 (1,0)；swap {2:3}
//   flip2：r=1 → 返回 (0,1)；swap {2:3, 1:3}？——1 没被换过 → (0,1)；
//         尾部 3 补到 1 → swap {2:3, 1:3}？不——put(1, getOrDefault(3,3)=3)
//   flip3：r=0 → (0,0)；flip4：r=3 → 查映射 {3:3}? 3 被换过？——
//   ⚠️ 映射语义：swapped[r] = 被换到 r 位置的原值
//   3 从未被抽过 → getOrDefault(3,3) = 3 → (1,1) ✓ 恰好每个位置一次
// ⚠️ 面试必答："519 = 尾部交换不放回抽样——
//   抽 r 后用尾部补位，映射记录'补位关系'；
//   每个位置恰好返回一次（不放回均匀）。"
```

## 3. 215. 第 K 大（随机基准快选）

### 3.1 题目与思路

```
第 K 大（随机基准的拉斯维加斯算法）
随机化角色：防退化（有序输入 + 固定基准 → O(n²)）
⚠️ 期望 O(n) 的证明（随机化/01 模块 6 节）
```

### 3.2 完整代码

```java
/**
 * LeetCode 215. 第 K 大（随机基准快选）
 * ⚠️ 随机化：基准随机 → 期望每次砍半
 */
public int findKthLargest(int[] nums, int k) {
    int target = nums.length - k;
    int lo = 0, hi = nums.length - 1;
    Random rand = new Random();

    while (lo <= hi) {
        // ⚠️ 随机基准（防有序输入退化）
        int pIdx = lo + rand.nextInt(hi - lo + 1);
        swap(nums, pIdx, hi);
        int pivot = nums[hi];

        int i = lo;
        for (int j = lo; j < hi; j++) {
            if (nums[j] <= pivot) swap(nums, i++, j);
        }
        swap(nums, i, hi);                   // 基准归位

        if (i == target) return nums[i];
        if (i < target) lo = i + 1;
        else hi = i - 1;
    }
    return -1;
}
// ⚠️ 期望分析：
//   E[T(n)] = n + E[T(n/2)]（随机基准期望砍半）
//   = n + n/2 + n/4 + ... = 2n = O(n) ✓
// ⚠️ 面试必答："215 的随机化 = 随机基准——
//   有序输入不再退化（O(n²) 概率趋近 0），
//   期望 O(n) 用几何级数论证。"
```

## 4. 470. 用 Rand7 实现 Rand10

### 4.1 题目与思路

```
rand7 → rand10（拒绝采样，蒙特卡洛式）
(rand7-1)×7 + rand7 → 1..49 → 接受 1..40
⚠️ 拒绝保持均匀（拒绝不破坏分布）
```

### 4.2 完整代码

```java
/**
 * LeetCode 470. 用 Rand7 实现 Rand10
 */
public int rand10() {
    int x;
    do {
        x = (rand7() - 1) * 7 + rand7();     // ⚠️ 1..49 均匀
    } while (x > 40);                        // 拒绝 41..49
    return x % 10 + 1;
}
// 均匀性论证：
//   编码 (a-1)×7+b 是 7 进制两位数 → 1..49 均匀
//   拒绝 41..49 后剩余 1..40 仍均匀（拒绝不破坏均匀）
//   → %10 后 1..10 均匀 ✓
// 接受率 = 40/49 ≈ 81.6%，期望重试 1.22 次
// ⚠️ 面试必答："470 = 拒绝采样——
//   超集编码（7 进制）→ 拒绝越界 → 均匀保持；
//   接受率 40/49 是期望次数的依据。"
```

## 5. 382/398. 水塘抽样

### 5.1 双题要点

```
382 链表随机：1/i 概率替换（完整实现见水塘/02）
398 随机索引：命中流水塘（1/count 概率）

⚠️ 两题共用模式：
  边遍历边"1/i 概率替换当前候选"
  数学归纳保证均匀（1/n）

⚠️ 面试必答：
"382/398 = 水塘双题——
 382 对流本身抽样、398 对命中流抽样；
 核心都是 1/i 概率替换 + 归纳证明。"
```

### 5.2 快速对照

```java
/** 382 核心：rand.nextInt(i) == 0 替换 */
```

## 6. 随机化方法论总结

### 6.1 解题框架

```
① 识别角色：防退化/采样/近似
② 选方法：
   重排 → Fisher-Yates
   不放回 → 尾部交换映射
   分布转换 → 拒绝采样
   流式 → 水塘
③ 均匀性：数学证明（归纳/编码/对称）
④ 复杂度：期望分析（递推取期望）
⑤ 安全：SecureRandom（生产）

⚠️ 识别信号：
  "打乱/随机返回" → 洗牌/水塘
  "随机不重复" → 尾部交换
  "Rand 转换" → 拒绝采样
```

### 6.2 模板速查表

| 题型 | 方法 | 代表题 |
|------|------|--------|
| 洗牌 | Fisher-Yates [0,i] | 384 |
| 不放回 | 尾部交换映射 | 519 |
| 第 K | 随机基准快选 | 215 |
| 分布转换 | 拒绝采样 | 470 |
| 流式抽样 | 水塘 1/i | 382、398 |

### 6.3 自测清单

```
□ 均匀性证明（归纳/编码）？
□ 洗牌 [0,i] 而非 [0,n)？
□ 随机基准（防退化）？
□ 拒绝采样接受率？
□ 水塘 1/i 分母正确？
□ 安全场景 SecureRandom？
□ 期望复杂度论证？
```
