# 01-普通莫队与带修莫队

> 莫队的本质是"用排序把指针移动次数压下来"。它不要求数据结构支持区间合并，只要求能 O(1) 增加/删除一个元素并维护答案。这个极低的门槛，让莫队成为离线区间问题的通用暴力优化框架。

## 1. 问题模型

```text
给定长度为 n 的数组，q 次询问
每次询问区间 [l, r] 的某个统计量
例：
  区间不同数个数
  区间众数
  区间内出现次数为 k 的数有多少个
  区间异或和（这题前缀和即可，仅作示例）
```

要求：

```text
① 离线（可以读完所有询问再处理）
② 能 O(1) 往区间里加一个元素
③ 能 O(1) 从区间里删一个元素
④ 能 O(1) 得到当前区间的答案
```

三条都满足，就能套莫队。

---

## 2. 暴力指针移动

维护当前区间 $[L,R]$ 与对应的答案：

```text
初始：L=1, R=0，区间为空
处理询问 [l,r]：
  while L > l: add(--L)
  while R < r: add(++R)
  while L < l: remove(L++)
  while R > r: remove(R--)
  此时区间等于 [l,r]，记录答案
```

如果按输入顺序处理，指针可能来回横跳：

```text
询问序列：[1, n], [1, 1], [1, n], [1, 1], ...
每次移动 O(n)，总复杂度 O(nq)
```

## 3. 排序策略与复杂度

### 3.1 排序方式

把左端点按块分组，块内按右端点排序：

```text
块大小 B
排序键：(l / B, r)
```

### 3.2 复杂度证明

设询问数为 $q$，数组长度为 $n$。

**左指针移动**：

同一块内，$l$ 的差值不超过 $B$。相邻询问左指针移动 $O(B)$，共 $q$ 次：

$$O(qB)$$

跨块时，左指针移动最多 $n$，共 $n/B$ 次跨块：

$$O\left(\frac{n^2}{B}\right)$$

**右指针移动**：

每个块内，$r$ 单调递增，总移动不超过 $n$。共 $n/B$ 个块：

$$O\left(\frac{n^2}{B}\right)$$

**总复杂度**：

$$O\left(qB+\frac{n^2}{B}\right)$$

对 $B$ 求导取极值：

$$q-\frac{n^2}{B^2}=0\Longrightarrow B=\frac{n}{\sqrt{q}}$$

代入得：

$$O(n\sqrt{q})$$

当 $q\approx n$ 时：

$$O(n\sqrt{n})$$

### 3.3 块大小的选择

```text
q ≈ n：B = √n
q 远大于 n：B = n/√q（更小）
q 远小于 n：B 更大，但实际常直接取 √n

工程简化：B = max(1, (int) Math.sqrt(n))
```

## 4. 奇偶优化

普通排序在块切换时，右指针要从 $n$ 回到 1，产生额外移动。奇偶优化让相邻块的右端点方向相反：

```text
奇数块：r 升序
偶数块：r 降序
```

效果：

```text
块 1：r 从 1 到 n
块 2：r 从 n 到 1（接着上一块末尾，不用跳回）
块 3：r 从 1 到 n
...
```

这是常数优化，不改变渐进复杂度，但实际运行时间通常下降 30%-50%。

```java
Arrays.sort(queries, (a, b) -> {
    int blockA = a.l / blockSize;
    int blockB = b.l / blockSize;
    if (blockA != blockB) {
        return Integer.compare(blockA, blockB);
    }
    if ((blockA & 1) == 1) {
        return Integer.compare(b.r, a.r);
    }
    return Integer.compare(a.r, b.r);
});
```

## 5. 普通莫队模板

以"区间不同数个数"为例（洛谷 P1972 的离线弱化版）：

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.Arrays;
import java.util.StringTokenizer;

public class MoAlgorithm {

    private static class Query {
        int left;
        int right;
        int index;

        Query(int left, int right, int index) {
            this.left = left;
            this.right = right;
            this.index = index;
        }
    }

    private final int[] array;
    private final int[] count;
    private int distinct;
    private int currentLeft;
    private int currentRight;

    public MoAlgorithm(int[] array, int maxValue) {
        this.array = array;
        this.count = new int[maxValue + 1];
        this.currentLeft = 0;
        this.currentRight = -1;
        this.distinct = 0;
    }

    private void add(int position) {
        int value = array[position];
        if (count[value] == 0) {
            distinct++;
        }
        count[value]++;
    }

    private void remove(int position) {
        int value = array[position];
        count[value]--;
        if (count[value] == 0) {
            distinct--;
        }
    }

    public int[] solve(Query[] queries, int n) {
        int blockSize = Math.max(1, (int) Math.sqrt(n));
        Arrays.sort(queries, (a, b) -> {
            int blockA = a.left / blockSize;
            int blockB = b.left / blockSize;
            if (blockA != blockB) {
                return Integer.compare(blockA, blockB);
            }
            if ((blockA & 1) == 1) {
                return Integer.compare(b.right, a.right);
            }
            return Integer.compare(a.right, b.right);
        });

        int[] answer = new int[queries.length];
        for (Query query : queries) {
            while (currentLeft > query.left) {
                add(--currentLeft);
            }
            while (currentRight < query.right) {
                add(++currentRight);
            }
            while (currentLeft < query.left) {
                remove(currentLeft++);
            }
            while (currentRight > query.right) {
                remove(currentRight--);
            }
            answer[query.index] = distinct;
        }
        return answer;
    }

    public static void main(String[] args) throws IOException {
        BufferedReader reader = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(reader.readLine().trim());
        int[] array = new int[n];
        StringTokenizer tokenizer = new StringTokenizer(reader.readLine());
        int maxValue = 0;
        for (int i = 0; i < n; i++) {
            array[i] = Integer.parseInt(tokenizer.nextToken());
            maxValue = Math.max(maxValue, array[i]);
        }

        int q = Integer.parseInt(reader.readLine().trim());
        Query[] queries = new Query[q];
        for (int i = 0; i < q; i++) {
            tokenizer = new StringTokenizer(reader.readLine());
            int left = Integer.parseInt(tokenizer.nextToken()) - 1;
            int right = Integer.parseInt(tokenizer.nextToken()) - 1;
            queries[i] = new Query(left, right, i);
        }

        int[] answer = new MoAlgorithm(array, maxValue).solve(queries, n);
        StringBuilder output = new StringBuilder();
        for (int value : answer) {
            output.append(value).append('\n');
        }
        System.out.print(output);
    }
}
```

## 6. 带修莫队

### 6.1 问题扩展

如果区间查询之间还夹杂"单点修改"：

```text
Q l r：查询区间 [l, r]
R p v：把位置 p 的值改为 v
```

普通莫队无法处理，因为答案依赖"当前数组状态"。

### 6.2 增加时间维

把操作序列看成一个时间轴：

```text
每个询问记录：左端点 l、右端点 r、发生时间 t
t = 在这次询问之前有多少次修改
```

处理询问时，指针移动变成三维：

```text
① 调整时间：应用或撤销修改，直到当前时间等于 t
② 调整左右端点：与普通莫队相同
```

### 6.3 修改的二分性

单点修改可以"正向应用"和"反向撤销"：

```text
应用：把 p 位置改成新值 v
撤销：把 p 位置改回旧值 old
```

所以时间指针可以左右移动。

### 6.4 排序与块大小

```text
排序键：(l / B, r / B, t)
块大小 B = n^(2/3)
```

复杂度：

$$O\left(n^{5/3}\right)$$

推导思路：

```text
左右指针在二维块内移动：O(n · n^(2/3)) = O(n^(5/3))
时间指针在每个 (l块, r块) 内单调：O(n · (n/B)²) = O(n · n^(2/3)) = O(n^(5/3))
```

### 6.5 奇偶优化

同样适用：

```text
l 块为奇数 → r 降序
r 块为奇数 → t 降序
```

## 7. 带修莫队模板

```java
import java.util.Arrays;

public class MoWithModification {

    private static class Query {
        int left;
        int right;
        int time;
        int index;

        Query(int left, int right, int time, int index) {
            this.left = left;
            this.right = right;
            this.time = time;
            this.index = index;
        }
    }

    private static class Modification {
        int position;
        int oldValue;
        int newValue;

        Modification(int position, int oldValue, int newValue) {
            this.position = position;
            this.oldValue = oldValue;
            this.newValue = newValue;
        }
    }

    private final int[] array;
    private final int[] count;
    private int distinct;

    public MoWithModification(int[] array, int maxValue) {
        this.array = array.clone();
        this.count = new int[maxValue + 1];
    }

    private void add(int position) {
        int value = array[position];
        if (count[value] == 0) {
            distinct++;
        }
        count[value]++;
    }

    private void remove(int position) {
        int value = array[position];
        count[value]--;
        if (count[value] == 0) {
            distinct--;
        }
    }

    private void apply(Modification modification, int left, int right) {
        int position = modification.position;
        if (position >= left && position <= right) {
            int oldValue = array[position];
            if (count[oldValue] == 1) {
                distinct--;
            }
            count[oldValue]--;
            if (count[modification.newValue] == 0) {
                distinct++;
            }
            count[modification.newValue]++;
        }
        array[position] = modification.newValue;
    }

    private void rollback(Modification modification, int left, int right) {
        int position = modification.position;
        if (position >= left && position <= right) {
            int newValue = array[position];
            if (count[newValue] == 1) {
                distinct--;
            }
            count[newValue]--;
            if (count[modification.oldValue] == 0) {
                distinct++;
            }
            count[modification.oldValue]++;
        }
        array[position] = modification.oldValue;
    }

    public int[] solve(Query[] queries, Modification[] modifications, int n) {
        int blockSize = Math.max(1, (int) Math.pow(n, 2.0 / 3.0));
        Arrays.sort(queries, (a, b) -> {
            int blockLeftA = a.left / blockSize;
            int blockLeftB = b.left / blockSize;
            if (blockLeftA != blockLeftB) {
                return Integer.compare(blockLeftA, blockLeftB);
            }
            int blockRightA = a.right / blockSize;
            int blockRightB = b.right / blockSize;
            if (blockRightA != blockRightB) {
                return Integer.compare(blockRightA, blockRightB);
            }
            return Integer.compare(a.time, b.time);
        });

        int[] answer = new int[queries.length];
        int currentLeft = 0;
        int currentRight = -1;
        int currentTime = 0;

        for (Query query : queries) {
            while (currentTime < query.time) {
                apply(modifications[currentTime++], currentLeft, currentRight);
            }
            while (currentTime > query.time) {
                rollback(modifications[--currentTime], currentLeft, currentRight);
            }
            while (currentLeft > query.left) {
                add(--currentLeft);
            }
            while (currentRight < query.right) {
                add(++currentRight);
            }
            while (currentLeft < query.left) {
                remove(currentLeft++);
            }
            while (currentRight > query.right) {
                remove(currentRight--);
            }
            answer[query.index] = distinct;
        }
        return answer;
    }
}
```

> **警告**：带修莫队最容易错的两处。第一，修改位置可能不在当前区间 `[left, right]` 内，此时只能改数组、不能动计数；否则 `count` 与 `distinct` 会与区间脱节。第二，位置在区间内时，必须"先减旧值、再改数组、再加新值"，顺序写反会读到已被覆盖的值。这两处出错都不会立刻崩溃，只会让答案缓慢偏移，极难定位。

## 8. 复杂度对比

| 变体 | 排序键 | 块大小 | 复杂度 |
|------|--------|--------|--------|
| 普通莫队 | (l 块, r) | $\sqrt{n}$ | $O(n\sqrt{n})$ |
| 奇偶优化 | 同上，方向交替 | $\sqrt{n}$ | 同阶，常数更小 |
| 带修莫队 | (l 块, r 块, t) | $n^{2/3}$ | $O(n^{5/3})$ |
| 树上莫队 | 欧拉序区间 | $\sqrt{n}$ | $O(n\sqrt{n})$ |
| 回滚莫队 | (l 块, r) | $\sqrt{n}$ | $O(n\sqrt{n})$ |

## 9. 易错点

```text
① 指针移动顺序错误
   add 与 remove 的顺序不影响正确性（只要最终区间正确）
   但 currentRight 初始为 -1、currentLeft 为 0 必须一致

② 删除时先判断 count 再减
   顺序写反会导致漏减或多减

③ 数组值域没有离散化
   count 数组开不下 → 先离散化或改用 HashMap

④ 块大小用固定值
   n 与 q 差异大时性能退化 → 按 n/√q 计算

⑤ 带修莫队忘记撤销修改
   时间指针回退时必须恢复旧值

⑥ 奇偶优化方向写反
   不影响正确性，但削弱优化效果

⑦ 多组数据没有清空 count 与 distinct
```

## 10. 小结

| 问题 | 答案 |
|------|------|
| 莫队前提 | 离线、O(1) 增删、O(1) 取答案 |
| 排序 | 左端点分块，块内按右端点 |
| 块大小 | $\sqrt{n}$；带修 $n^{2/3}$ |
| 复杂度 | 普通 $O(n\sqrt{n})$，带修 $O(n^{5/3})$ |
| 奇偶优化 | 相邻块右端点方向相反 |
| 带修 | 增加时间维，应用/撤销修改 |
