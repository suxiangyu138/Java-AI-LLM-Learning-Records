# 莫队算法知识体系总览

> 莫队是"离线 + 分块 + 指针移动"的通用框架：把询问排序，让左右指针的总移动距离从 O(nq) 降到 O(n√q)。它不依赖特殊数据结构，只要能 O(1) 增删元素并维护答案，就能套用。树上路径、带修改、只增不删等场景各有对应变体。

## 4. 核心概念速查

| 概念 | 含义 |
|------|------|
| 离线 | 先读入所有询问，排序后统一处理 |
| 块大小 | 普通莫队 $\sqrt{n}$，带修 $n^{2/3}$ |
| 指针移动 | 通过增删元素维护当前区间答案 |
| 奇偶优化 | 左端点所在块为奇数时右端点降序，减少回扫 |
| 带修莫队 | 增加时间维，支持修改操作 |
| 欧拉序 | 树上莫队把路径转成区间 |
| 回滚莫队 | 只增不删或只删不加时的处理方式 |
| 复杂度 | 普通 $O(n\sqrt{n})$，带修 $O(n^{5/3})$ |
