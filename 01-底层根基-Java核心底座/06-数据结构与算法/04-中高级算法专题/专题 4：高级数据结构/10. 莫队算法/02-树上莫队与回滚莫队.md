# 02-树上莫队与回滚莫队

> 树上莫队用欧拉序把"树上路径"变成"序列区间"，再用出现次数的奇偶性判断节点是否在路径上。回滚莫队解决另一类问题：答案只支持增加、不支持删除时，用"块内暴力 + 块间回滚"绕开删除操作。

## 1. 树上莫队：欧拉序

### 1.1 欧拉序的定义

DFS 遍历树，每个节点在"进入"和"离开"时各记录一次：

```text
原树：
        1
      /   \
     2     3
    / \
   4   5

欧拉序（括号序列）：
  1, 2, 4, 4, 5, 5, 2, 3, 3, 1

in[u]：第一次出现的位置
out[u]：第二次出现的位置

in[1]=1, out[1]=10
in[2]=2, out[2]=7
in[4]=3, out[4]=4
in[5]=5, out[5]=6
in[3]=8, out[3]=9
```

欧拉序长度是 $2n$。

### 1.2 与 dfn 的区别

| 序列 | 长度 | 用途 |
|------|------|------|
| dfn（先序时间戳） | $n$ | 子树区间、树链剖分 |
| 欧拉序（括号序列） | $2n$ | 树上莫队、路径转区间 |

---

## 2. 路径转区间

设 $in[u] < in[v]$，分两种情况：

### 2.1 $u$ 是 $v$ 的祖先

```text
路径 u-v = 区间 [in[u], in[v]]
```

例子：路径 1-4，`in[1]=1, in[4]=3`，区间 `[1,3] = {1,2,4}`，正好是路径。

### 2.2 $u$ 不是 $v$ 的祖先

```text
路径 u-v = 区间 [out[u], in[v]] + lca(u,v)
```

例子：路径 4-3，`out[4]=4, in[3]=8`，区间 `[4,8] = {4,5,5,2,3}`。

统计出现奇数次的节点：

```text
4 出现 1 次（奇）→ 在路径上
5 出现 2 次（偶）→ 不在
2 出现 1 次（奇）→ 在
3 出现 1 次（奇）→ 在

结果：{4, 2, 3}
但真实路径 4-3 是 {4, 2, 1, 3}
→ 缺了 LCA(4,3)=1
→ 所以最后要手动加上 lca
```

## 3. 奇偶性与正确性

**命题**：欧拉序区间 $[out[u], in[v]]$ 中，节点 $x$ 出现奇数次当且仅当 $x$ 在路径 $u\to v$ 上（不含 LCA）。

**证明思路**：

```text
欧拉序中每个节点出现两次（进、出）

考虑节点 x 与路径的关系：
① x 在 u-v 路径上：
   x 的子树包含路径的一段
   进入 x 与离开 x 恰好一个在区间内
   → 出现 1 次（奇）

② x 不在路径上，且 x 的子树完全在路径一侧：
   两次出现都在区间内，或都在区间外
   → 出现 0 或 2 次（偶）

③ x 是 LCA：
   两次出现都在区间外（因为区间从 out[u] 开始）
   → 出现 0 次，需要手动补上
```

这个性质让莫队的 `add/remove` 变成同一个操作：**toggle**。

```text
toggle(x)：
  如果 x 已经出现奇数次 → 从答案中移除 x
  如果 x 出现偶数次 → 把 x 加入答案

add 与 remove 完全对称
```

## 4. 树上莫队模板

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

public class TreeMo {

    private static class Query {
        int left;
        int right;
        int extra;
        int index;

        Query(int left, int right, int extra, int index) {
            this.left = left;
            this.right = right;
            this.extra = extra;
            this.index = index;
        }
    }

    private final List<Integer>[] graph;
    private final int[] in;
    private final int[] out;
    private final int[] euler;
    private final int[] depth;
    private final int[] parent;
    private final int[] size;
    private final int[] heavy;
    private final int[] top;
    private int timer;

    @SuppressWarnings("unchecked")
    public TreeMo(int n) {
        graph = new List[n];
        for (int i = 0; i < n; i++) {
            graph[i] = new ArrayList<>();
        }
        in = new int[n];
        out = new int[n];
        euler = new int[2 * n];
        depth = new int[n];
        parent = new int[n];
        size = new int[n];
        heavy = new int[n];
        top = new int[n];
        Arrays.fill(heavy, -1);
    }

    public void addEdge(int u, int v) {
        graph[u].add(v);
        graph[v].add(u);
    }

    public void build(int root) {
        dfs1(root, -1);
        dfs2(root, root);
        timer = 0;
        dfsEuler(root, -1);
    }

    private void dfs1(int u, int p) {
        parent[u] = p;
        size[u] = 1;
        int maxSize = 0;
        for (int v : graph[u]) {
            if (v == p) {
                continue;
            }
            depth[v] = depth[u] + 1;
            dfs1(v, u);
            size[u] += size[v];
            if (size[v] > maxSize) {
                maxSize = size[v];
                heavy[u] = v;
            }
        }
    }

    private void dfs2(int u, int head) {
        top[u] = head;
        if (heavy[u] != -1) {
            dfs2(heavy[u], head);
        }
        for (int v : graph[u]) {
            if (v == parent[u] || v == heavy[u]) {
                continue;
            }
            dfs2(v, v);
        }
    }

    private void dfsEuler(int u, int p) {
        in[u] = timer;
        euler[timer++] = u;
        for (int v : graph[u]) {
            if (v != p) {
                dfsEuler(v, u);
            }
        }
        out[u] = timer;
        euler[timer++] = u;
    }

    public int lca(int u, int v) {
        while (top[u] != top[v]) {
            if (depth[top[u]] < depth[top[v]]) {
                int temp = u;
                u = v;
                v = temp;
            }
            u = parent[top[u]];
        }
        return depth[u] < depth[v] ? u : v;
    }

    public Query makeQuery(int u, int v, int index) {
        if (in[u] > in[v]) {
            int temp = u;
            u = v;
            v = temp;
        }
        int ancestor = lca(u, v);
        if (ancestor == u) {
            return new Query(in[u], in[v], -1, index);
        }
        return new Query(out[u], in[v], ancestor, index);
    }

    public int[] solve(Query[] queries, int[] color, int colorCount) {
        int n = color.length;
        int blockSize = Math.max(1, (int) Math.sqrt(2 * n));
        Arrays.sort(queries, (a, b) -> {
            int blockA = a.left / blockSize;
            int blockB = b.left / blockSize;
            if (blockA != blockB) {
                return Integer.compare(blockA, blockB);
            }
            if ((blockA & 1) == 1) {
                return Integer.compare(b.right, a.right);
            }
            return Integer.compare(a.right, b.right);
        });

        int[] count = new int[colorCount + 1];
        boolean[] active = new boolean[n];
        int[] answer = new int[queries.length];
        int currentLeft = 0;
        int currentRight = -1;
        int distinct = 0;

        for (Query query : queries) {
            while (currentLeft > query.left) {
                int node = euler[--currentLeft];
                distinct += toggle(node, active, count, color);
            }
            while (currentRight < query.right) {
                int node = euler[++currentRight];
                distinct += toggle(node, active, count, color);
            }
            while (currentLeft < query.left) {
                int node = euler[currentLeft++];
                distinct += toggle(node, active, count, color);
            }
            while (currentRight > query.right) {
                int node = euler[currentRight--];
                distinct += toggle(node, active, count, color);
            }

            int extraCount = 0;
            if (query.extra != -1 && !active[query.extra]) {
                int value = color[query.extra];
                if (count[value] == 0) {
                    extraCount = 1;
                }
            }

            answer[query.index] = distinct + extraCount;
        }
        return answer;
    }

    private int toggle(int node, boolean[] active, int[] count, int[] color) {
        int value = color[node];
        if (active[node]) {
            active[node] = false;
            count[value]--;
            return count[value] == 0 ? -1 : 0;
        }
        active[node] = true;
        if (count[value] == 0) {
            count[value]++;
            return 1;
        }
        count[value]++;
        return 0;
    }
}
```

> **提示**：`extra` 是 LCA。它不在区间里，需要单独判断：如果它的颜色在当前区间没有出现，答案加 1。这个判断必须用"颜色计数是否为零"，不能只看 `active`。

## 5. 回滚莫队：问题背景

有些统计量只支持"增加"，不支持"删除"：

```text
例：维护区间最大值
  加入一个数：max = max(max, x)
  删除一个数：无法从 max 恢复（不知道次大值）

例：维护区间内"出现次数最多的数的出现次数"（众数）
  加入容易，删除时无法快速恢复

例：维护区间内不同数的个数
  删除时如果计数归零可以减，这个可以删
  → 不在回滚莫队的必要场景
```

普通莫队的左右指针都会回退，需要删除。回滚莫队通过"块内暴力"绕开删除。

---

## 6. 回滚莫队的流程

### 6.1 排序

```text
按左端点所在块排序，块内按右端点升序
```

### 6.2 逐块处理

对每个左端点块 $[blockLeft, blockRight]$：

```text
① 初始化：
   L = blockRight + 1
   R = blockRight
   当前区间为空

② 处理块内的询问（按右端点升序）：
   ① 右指针只向右扩展：while R < query.right: add(++R)
   ② 记录快照（保存当前答案与相关状态）
   ③ 左指针在块内暴力移动：while L > query.left: add(--L)
   ④ 记录答案
   ⑤ 回滚到快照（撤销左指针的修改）
   ⑥ L 复位到 blockRight + 1
```

关键点：

```text
右指针在整块内只增不减 → 不需要删除
左指针只在块内移动，范围 ≤ B → 可以暴力
每次询问处理完，左指针的修改全部回滚
```

### 6.3 为什么不需要删除

```text
右指针：整块内单调递增，从不回退
左指针：每次询问从 blockRight+1 向左扩展，处理完回滚
→ 整个过程中只有 add 操作
```

### 6.4 快照与回滚

快照需要保存"会被左指针修改的状态"：

```text
答案值
计数数组中被修改的位置（或用操作栈记录）
```

两种实现：

| 方式 | 做法 | 适用 |
|------|------|------|
| 全量拷贝 | 保存整个 count 数组 | 值域小、块数少 |
| 操作栈 | 记录每次 add 的副作用，逆序撤销 | 值域大、状态复杂 |

## 7. 回滚莫队模板

以"区间最大值"为例（只增不删）：

```java
import java.util.Arrays;

public class RollbackMo {

    private static class Query {
        int left;
        int right;
        int index;

        Query(int left, int right, int index) {
            this.left = left;
            this.right = right;
            this.index = index;
        }
    }

    public int[] solve(int[] array, Query[] queries) {
        int n = array.length;
        int blockSize = Math.max(1, (int) Math.sqrt(n));

        Arrays.sort(queries, (a, b) -> {
            int blockA = a.left / blockSize;
            int blockB = b.left / blockSize;
            if (blockA != blockB) {
                return Integer.compare(blockA, blockB);
            }
            return Integer.compare(a.right, b.right);
        });

        int[] answer = new int[queries.length];
        int queryIndex = 0;

        for (int block = 0; block * blockSize < n; block++) {
            int blockLeft = block * blockSize;
            int blockRight = Math.min(n - 1, blockLeft + blockSize - 1);

            int right = blockRight;
            int currentMax = Integer.MIN_VALUE;

            while (queryIndex < queries.length
                    && queries[queryIndex].left / blockSize == block
                    && queries[queryIndex].right <= blockRight) {
                int result = Integer.MIN_VALUE;
                for (int i = queries[queryIndex].left; i <= queries[queryIndex].right; i++) {
                    result = Math.max(result, array[i]);
                }
                answer[queries[queryIndex].index] = result;
                queryIndex++;
            }

            while (queryIndex < queries.length
                    && queries[queryIndex].left / blockSize == block) {
                Query query = queries[queryIndex];

                while (right < query.right) {
                    currentMax = Math.max(currentMax, array[++right]);
                }

                int savedMax = currentMax;

                int left = blockRight + 1;
                while (left > query.left) {
                    currentMax = Math.max(currentMax, array[--left]);
                }

                answer[query.index] = currentMax;

                currentMax = savedMax;
                queryIndex++;
            }
        }
        return answer;
    }
}
```

这个模板的结构值得记住：

```text
外层：按左端点分块
内层第一段：右端点落在块内的询问，直接暴力
内层第二段：右端点超出块的询问，右指针单调扩展
每处理一个询问：保存快照 → 左指针暴力 → 取答案 → 恢复快照
```

## 8. 复杂度与适用边界

### 8.1 复杂度

```text
右指针：每块单调移动 O(n)，共 O(n√n)
左指针：每次询问最多移动 B，共 O(qB)
总复杂度：O(n√n + q√n)
```

### 8.2 适用场景

| 场景 | 是否适合 |
|------|---------|
| 只增不删的统计量 | 适合 |
| 只删不增的统计量 | 适合（反向做） |
| 增删都 O(1) | 普通莫队更简单 |
| 需要在线 | 不适合，莫队都是离线 |
| 修改操作 | 用带修莫队，不是回滚 |

### 8.3 常见题型

```text
区间最大值（只增）
区间众数（只增）
区间内"出现次数 ≥ k 的数"的数量（只增）
区间 mex（需要特殊设计）
```

## 9. 易错点

```text
① 欧拉序长度开成 n
   必须是 2n

② in/out 记录错误
   进入时记 in，离开时记 out，顺序不能反

③ 路径转区间时没有按 in 排序
   必须保证 in[u] < in[v]

④ 祖先判断用 depth 而不是 LCA
   必须用 lca(u,v) == u

⑤ extra 的 LCA 重复计数
   如果 LCA 已在区间中（active），不能再加

⑥ 回滚莫队忘记复位左指针
   下一个询问的左指针会从错误位置开始

⑦ 快照只保存了答案，没保存计数
   左指针的 add 修改了 count，回滚不彻底

⑧ 右指针在块切换时没有重置
   每个块都要从 blockRight 重新开始
```

> **警告**：回滚莫队的回滚必须"精确撤销左指针的每一次 add"。如果 `add` 修改了多个状态（计数、最大值、辅助数组），快照要覆盖全部。最稳妥的方式是用操作栈记录每次修改的旧值，逆序恢复。

---

## 10. 小结

| 问题 | 答案 |
|------|------|
| 树上莫队依赖什么 | 欧拉序（长度 2n） |
| 路径转区间 | 祖先：`[in[u], in[v]]`；否则 `[out[u], in[v]] + LCA` |
| 奇偶性 | 出现奇数次即在路径上 |
| toggle | add 与 remove 同一个操作 |
| 回滚莫队适用 | 只增不删的统计量 |
| 回滚流程 | 右指针单调 + 左指针块内暴力 + 快照回滚 |
| 复杂度 | 二者都是 O(n√n) |
