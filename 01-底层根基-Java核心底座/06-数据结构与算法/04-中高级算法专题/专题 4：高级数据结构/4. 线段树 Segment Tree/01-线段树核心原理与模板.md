## 1. 线段树模型：区间信息的二叉树

```text
线段树: 维护区间信息的二叉树——
  每个节点对应原数组的一个区间 [l, r]
  非叶节点 = 左右子区间的"合并"（和/最值/gcd）

例: 数组 [1, 3, 5, 7, 9, 11]（区间和线段树）
           [0..5]=36
         /          \
    [0..2]=9      [3..5]=27
    /     \       /     \
 [0..1]=4 [2]=5 [3..4]=16 [5]=11
 /    \
[0]=1 [1]=3

⚠️ 存储: 堆式（2p 左子、2p+1 右子）——
  数组大小 4n（防越界）

⚠️ 前提: 区间信息可"合并"（结合律）——
  和: sum(左) + sum(右)；最值: max(左, 右)；gcd: gcd(左, 右)
  "能合并就能建树"是线段树的万能公式
```

> 🎯 **核心认知**："**线段树 = '每节点一个区间、信息分治合并'——树高 O(log n)，任意区间查询拆成 O(log n) 个节点**。'能合并的信息'（和/最值/gcd）都能维护，这是它 vs BIT 的全能所在。"

## 2. build：自底向上建树

### 2.1 实现

```java
/**
 * build: 自底向上建树 O(n)
 * tree[p] 对应区间 [l, r]
 */
void build(int[] nums, int p, int l, int r) {
    if (l == r) {                               // ① 叶子: 存单元素
        tree[p] = nums[l];
        return;
    }
    int mid = (l + r) / 2;
    build(nums, p * 2, l, mid);                 // ② 左子树
    build(nums, p * 2 + 1, mid + 1, r);         // ③ 右子树
    tree[p] = tree[p * 2] + tree[p * 2 + 1];    // ④ pushup: 合并
}
// 推演 [1,3,5]（n=3，tree 开 4n=12）：
//   build(1,0,2) → 叶子 [0]=1、[1]=3、[2]=5
//   tree[3] = 1+3 = 4（[0..1]）；tree[1] = 4+5 = 9（[0..2]）✓
// ⚠️ 合并操作"+"可换成 max/gcd/乘——一个 build 通吃
```

> 💡 **pushup 的抽象**："**'tree[p] = merge(tree[2p], tree[2p+1])'——build 与 update 共用同一行合并逻辑（pushup）**。把 merge 抽象成函数，线段树就能维护任意可结合信息。"

## 3. query：区间查询（分治合并）

### 3.1 实现与推演

```java
/**
 * query: 查询 [ql, qr] 的区间信息
 * 分治: 区间完全覆盖 → 返回节点；部分覆盖 → 拆两半
 * 时间 O(log n)
 */
int query(int p, int l, int r, int ql, int qr) {
    if (ql <= l && r <= qr) return tree[p];     // ① ⚠️ 完全覆盖 → 直接返回
    int mid = (l + r) / 2;
    int sum = 0;
    if (ql <= mid) sum += query(p * 2, l, mid, ql, qr);         // ② 左半有交集
    if (qr > mid) sum += query(p * 2 + 1, mid + 1, r, ql, qr);  // ③ 右半有交集
    return sum;
}
// 推演 tree=[9,4,5]（[1,3,5]），query(1,0,2,1,2)（查 [1..2]=8）：
//   [0..2] 不完全覆盖 → mid=1 → 左 [0..1] 部分覆盖 → 继续
//   [0..1] mid=0 → 左 [0] 无交集跳过、右 [1] 完全覆盖 → 3
//   右 [2] 完全覆盖 → 5 → 总 = 3+5 = 8 ✓
// ⚠️ 三情形: 完全覆盖直接返 / 部分覆盖拆两半 / 无交集不递归
```

> 🎯 **query 的分治**："**'完全覆盖直接返回、部分覆盖拆两半'——任意区间拆成 O(log n) 个整段**。与归并排序的分治同构，只是'合并'发生在返回路径上。"

## 4. update：单点更新（递归定位）

### 4.1 实现与推演

```java
/**
 * update: 单点更新（a[pos] += delta）
 * 递归定位叶子 → 路径上 pushup
 * 时间 O(log n)
 */
void update(int p, int l, int r, int pos, int delta) {
    if (l == r) {                               // ① 到达叶子
        tree[p] += delta;                       // ② 更新
        return;
    }
    int mid = (l + r) / 2;
    if (pos <= mid) update(p * 2, l, mid, pos, delta);       // ③ 左子树定位
    else update(p * 2 + 1, mid + 1, r, pos, delta);          // ④ 右子树定位
    tree[p] = tree[p * 2] + tree[p * 2 + 1];    // ⑤ pushup: 路径上重新合并
}
// 推演 tree=[9,4,5]（[1,3,5]），update(2, 2)（a[2]=5 → 7）：
//   定位叶子 [2] → tree[4] = 7
//   返回: tree[2] = 1+7 = 8；tree[1] = 8+5... 
//   ⚠️ 注意: 上述是 n=3 的堆式编号，路径上每个祖先都要重新合并 ✓
```

> 💡 **update 的路径**："**'递归定位叶子 → 返回路径上 pushup'——O(log n) 个祖先重新合并**。单点更新是最简单形态；区间更新需要懒标记（02 文件）。"

## 5. 完整模板（307 区域检索）与推演

### 5.1 面试标准模板

```java
/**
 * 线段树完整模板（单点更新 + 区间查询）——307 区域检索
 * build O(n)、query/update O(log n)、空间 O(4n)
 */
class SegmentTree {
    private final int[] tree;
    private final int n;

    public SegmentTree(int[] nums) {
        n = nums.length;
        tree = new int[4 * n];                  // ① 4n 空间
        build(nums, 1, 0, n - 1);
    }

    private void build(int[] nums, int p, int l, int r) {
        if (l == r) { tree[p] = nums[l]; return; }
        int mid = (l + r) / 2;
        build(nums, p * 2, l, mid);
        build(nums, p * 2 + 1, mid + 1, r);
        tree[p] = tree[p * 2] + tree[p * 2 + 1];    // ② pushup
    }

    public void update(int index, int val) {    // ③ 单点更新（差值版）
        update(1, 0, n - 1, index, val);
    }

    private void update(int p, int l, int r, int pos, int val) {
        if (l == r) { tree[p] = val; return; }
        int mid = (l + r) / 2;
        if (pos <= mid) update(p * 2, l, mid, pos, val);
        else update(p * 2 + 1, mid + 1, r, pos, val);
        tree[p] = tree[p * 2] + tree[p * 2 + 1];
    }

    public int sumRange(int ql, int qr) {       // ④ 区间查询
        return query(1, 0, n - 1, ql, qr);
    }

    private int query(int p, int l, int r, int ql, int qr) {
        if (ql <= l && r <= qr) return tree[p];
        int mid = (l + r) / 2, sum = 0;
        if (ql <= mid) sum += query(p * 2, l, mid, ql, qr);
        if (qr > mid) sum += query(p * 2 + 1, mid + 1, r, ql, qr);
        return sum;
    }
}
// 推演 [1,3,5]：sumRange(0,2)=9 → update(1,2) → sumRange(0,2)=8 ✓
// 记忆: "build 合并、query 覆盖、update 定位 + 回并"
```

### 5.2 模板四函数

```text
build(建树): 叶子存值、祖先合并（pushup）
query(查询): 完全覆盖直接返、部分覆盖拆两半
update(更新): 定位叶子、路径回并
pushup(合并): build 与 update 共用的一行

⚠️ 记忆: "三个递归函数共享 mid 拆分与 pushup 合并"
```

> 🎯 **模板的复用**："**'build/query/update 三递归 + pushup 一行合并'——单点版模板就是线段树的骨架**。加懒标记（02 文件）只需增 pushdown 与区间版 update；换信息只需改 pushup。"

## 6. 识别信号与易错点

### 6.1 识别信号

```text
"区间查询 + 单点/区间更新（动态）" → 线段树
"区间最值 + 更新" → 线段树（BIT 不行！）
"区间 gcd/乘/复杂合并" → 线段树
"动态区间统计（10⁵ 量级）" → 线段树/BIT

⚠️ 选型: 前缀/计数 → BIT（短）；最值/复杂合并 → 线段树
```

### 6.2 易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 空间开 2n | 开 4n | 越界（随机 bug） |
| 2 | query 忘完全覆盖判断 | `ql<=l && r<=qr` 前置 | O(n) 退化 |
| 3 | 叶子条件写错 | `l == r` | 死循环 |
| 4 | mid 用 (l+r)/2 溢出 | `l + (r−l)/2` | 大区间溢出 |
| 5 | update 忘回并 | 路径上 pushup | 祖先信息过期 |
| 6 | 无交集还递归 | `ql<=mid` 判断 | 白递归 |
| 7 | 合并函数写死 + | 抽象 merge | 无法换信息 |

> 🎯 **核心要点**：线段树基础通关四件事——**① 区间树模型**（节点 = 区间 + 合并信息）；**② 三操作**（build/query/update）；**③ 完全覆盖语义**（query 的关键）；**④ 4n 空间**。**'能合并就能建树'——单点模板 5 分钟默写，就是线段树的入场券**。
