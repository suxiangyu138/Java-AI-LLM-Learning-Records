## 1. 307 区域和检索（单点版实战）

### 1.1 题目与思路

**题**：数组单点更新 + 区间求和（01 模板直接套）。

**与 BIT 版对比**（同一题双解）：

```java
/**
 * LeetCode 307. 区域和检索（线段树单点版）
 * 与 BIT 版对比: 代码更长但可扩展（最值/懒标记）
 */
class NumArray {
    private final SegmentTree tree;              // 01 文件模板

    public NumArray(int[] nums) {
        tree = new SegmentTree(nums);
    }
    public void update(int index, int val) {
        tree.update(index, val);
    }
    public int sumRange(int left, int right) {
        return tree.sumRange(left, right);
    }
}
// 推演 [1,3,5] → sumRange(0,2)=9 → update(1,2) → sumRange(0,2)=8 ✓
// ⚠️ 双解对比: BIT ~20 行 vs 线段树 ~60 行——
//   "这题 BIT 够用；线段树是为扩展性（最值/区间更新）准备的"
```

> 🎯 **307 的选型论述**："**同一题 BIT 与线段树双解——'BIT 短小够用、线段树为扩展性'的选型话术是加分项**。面试先给 BIT（快），追问'要区间最值/区间更新呢'再升级线段树。"

## 2. 区间最值：BIT 做不到的事

### 2.1 题目与思路

**题**：区间最大值查询 + 单点更新（BIT 的硬伤场景）。

**线段树改 pushup 即可**：

```java
/**
 * 区间最值线段树
 * ⚠️ 与区间和的唯一差异: pushup 从 + 变 max
 */
class MaxTree {
    private final int[] tree;
    private final int n;

    // build 同 01，只有 pushup 不同:
    private void pushup(int p) {
        tree[p] = Math.max(tree[p * 2], tree[p * 2 + 1]);   // ① max 合并
    }
    // query 同 01（max 聚合）:
    private int query(int p, int l, int r, int ql, int qr) {
        if (ql <= l && r <= qr) return tree[p];
        int mid = (l + r) / 2;
        int res = Integer.MIN_VALUE;             // ② ⚠️ 初始为"中性值"
        if (ql <= mid) res = Math.max(res, query(p * 2, l, mid, ql, qr));
        if (qr > mid) res = Math.max(res, query(p * 2 + 1, mid + 1, r, ql, qr));
        return res;
    }
}
// 推演 [3,1,5] → query(0,2) = 5 ✓
// ⚠️ "改 pushup 就换功能"——和 → max → gcd 全是一行之差
//   中性值: 和用 0、max 用 −∞、gcd 用 0——"查询初始值"是易错点
```

> 💡 **改一行换功能**："**'pushup 一行之差'——和/max/gcd 只是合并函数不同**。把 merge 抽象后，线段树维护什么信息由调用方决定——'能合并就能建树'的实证。"

## 3. 动态开点：大值域的按需建树

### 3.1 题目与思路

**题**：值域极大（1e9）的区间操作（普通线段树 4×1e9 数组爆内存）。

**动态开点**：按需建节点——只用 O(q log m) 空间：

```java
/**
 * 动态开点线段树
 * ⚠️ 不能堆式存储——每节点记录左右儿子编号
 * 空间 O(q·log m)（q = 操作次数）
 */
class DynamicSegTree {
    private static class Node {
        int sum, lazy;
        Node left, right;                        // ① 指针式儿子（动态分配）
    }

    private final Node root = new Node();        // ② 根先建
    private final int n;                         // 值域上限（如 1e9）

    private void update(Node node, int l, int r, int ql, int qr, int k) {
        if (ql <= l && r <= qr) {
            node.sum += k * (r - l + 1);         // ③ 完全覆盖批量更新
            node.lazy += k;
            return;
        }
        pushdown(node, l, r);                    // ④ 下放（可能新建孩子）
        int mid = (l + r) / 2;
        if (ql <= mid) {
            if (node.left == null) node.left = new Node();   // ⑤ ⚠️ 按需新建
            update(node.left, l, mid, ql, qr, k);
        }
        if (qr > mid) {
            if (node.right == null) node.right = new Node();
            update(node.right, mid + 1, r, ql, qr, k);
        }
        node.sum = (node.left == null ? 0 : node.left.sum)
                 + (node.right == null ? 0 : node.right.sum);  // ⑥ 空儿子按 0
    }
}
// 推演 值域 [0, 1e9]，只操作 3 个点 → 只建 3 条链（O(3·30) 节点）
// ⚠️ 空间: O(q·log m)——值域 1e9 → 树高 30 → 每操作 30 节点
```

> 🎯 **动态开点的定位**："**'按需建节点 + 指针儿子'——大值域（1e9）也能线段树**。空间 O(q log m) 让它处理普通线段树爆内存的场景，也是主席树（可持久化）的地基。"

## 4. 权值线段树：逆序对与第 K 大

### 4.1 题目与思路

**题**：值域频次统计 + 第 K 大（动态）。

**权值线段树**（值域开树 + 离散化）：

```java
/**
 * 权值线段树: 下标 = 值、信息 = 频次
 * 与 BIT 值域频次同思路，但支持"区间频次 + 二分第 K 大"更直接
 */
// ① 建树在"值域"上（离散化后 [1..m]）
// ② insert(x): 值 x 的频次 +1（单点更新）
// ③ 第 K 大: 二分定位——
//    queryKth(p, l, r, k):
//      左子树频次 ≥ k → 去左；否则去右（k − 左频次）
//    O(log n) 直接定位 ✓

// 逆序对（权值线段树版）:
//   与 BIT 版同思路（从后往前 query(rank−1)）
//   ⚠️ 动态开点版可免离散化（值域 1e9 直接开）

// ⚠️ 定位: "权值线段树 = 值域频次的线段树"——
//   BIT 版更短；线段树版支持区间频次查询
```

> 💡 **权值线段树的定位**："**'值域开树 + 频次信息'——第 K 大在树上二分 O(log n) 直接定位**。与 BIT 的差异：BIT 靠二分 + query、线段树天然支持树上定位——'要第 K 大'时权值线段树更自然。"

## 5. 扫描线与进阶应用

### 5.1 扫描线（面积并）

```java
/**
 * 扫描线: 矩形面积并（竞赛经典）
 * 思路: 按 y 坐标扫描——
 * ① 每条水平边: (x1, x2, +1/−1)（入边/出边）
 * ② 线段树维护 x 轴上的"覆盖长度"
 * ③ 面积 += 覆盖长度 × 相邻 y 差
 * ⚠️ 线段树管"x 区间覆盖长度"——区间更新 + 区间查询
 */
// 洛谷 P5490 模板题；面试提存在即可（竞赛向）

// 进阶家族:
//   线段树二分: 树上二分找位置（第 K 小）
//   线段树合并/分裂: 竞赛技巧
//   势能线段树: 区间开方/取模（值快速收敛）
//   李超线段树: 直线/线段最值
//   主席树: 可持久化（6. 可持久化子目录）
```

> 🎯 **扫描线的定位**："**扫描线 = '线段树管 x 轴覆盖长度 + y 轴扫描'——面积并的经典**。竞赛向进阶（P5490）；面试提'存在扫描线解法'即可，主战场是 307 与区间更新。"

## 6. 面试话术与追问

### 6.1 话术模板

```text
"这是【应用】题——线段树【机制】。
build 自底向上、query 完全覆盖直接返、
update 定位 + pushup；区间更新加懒标记（pushdown）。
复杂度: O(log n)/操作、O(4n) 空间。
选型: 【vs BIT/分块】……"

例: "区间最值 + 更新——线段树（BIT 做不了最值）。
     pushup 用 max 合并，查询初始值 −∞。
     O(log n)。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|---------|
| 1 | 线段树能维护什么？ | 一切可合并信息（和/最值/gcd/乘）——"能合并就能建树" |
| 2 | 为什么空间 4n？ | 堆式存储防越界（2n 在非 2 的幂时不够） |
| 3 | 懒标记是什么？ | 整段覆盖只打标记、访问孩子才 pushdown——"延迟更新按需下发" |
| 4 | 懒标记的前提？ | 修改可批量执行（区间加可、区间平方不可） |
| 5 | 与 BIT 选型？ | 前缀/计数 → BIT（短）；最值/复杂合并/懒标记 → 线段树 |
| 6 | 动态开点是什么？ | 大值域按需建节点——O(q log m) 空间、指针儿子 |
| 7 | query 为什么 O(log n)？ | 完全覆盖直接返——任意区间拆成 O(log n) 个整段 |
| 8 | 多懒标记顺序？ | 先乘后加——乘法作用于已有加法标记 |

> 🎯 **核心要点**：线段树实战通关——**307（单点双解）+ 区间最值（改 pushup）+ 动态开点（大值域）+ 权值线段树（第 K 大）+ 扫描线（面积）**。五应用覆盖"基础/扩展/值域/竞赛"——"能合并就能建树 + 懒标记按需下发"，就是线段树的完整答案。
