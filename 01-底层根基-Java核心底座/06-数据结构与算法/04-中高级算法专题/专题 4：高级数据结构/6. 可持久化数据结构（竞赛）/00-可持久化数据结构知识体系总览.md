## 1. 知识体系导图

```text
可持久化数据结构（Persistent DS）
│
├── 核心本质 ──────────────────────────────────────────────
│   ├── = 支持"回到历史版本"的数据结构
│   ├── 版本复用: 修改只复制路径上 O(log n) 节点
│   ├── 新版本与旧版本共享未修改部分
│   └── 代价: 空间 O(n log n)、时间 O(log n)
│
├── 主席树（可持久化权值线段树）─────────────────────────
│   ├── 全称: 可持久化权值线段树（黄嘉泰 = 主席树）
│   ├── 动态开点: 指针儿子 + root[] 记录各版本
│   ├── 建树: 每个前缀一棵权值线段树（继承前版）
│   └── 查询: 两版本作差 + 树上二分
│
├── 静态区间第 K 小（P3834 经典）───────────────────────
│   ├── 离散化: 大值域 → 排名
│   ├── 前缀建树: root[i] = 插 a[i] 的版本
│   ├── 作差: [l,r] 的权值树 = root[r] − root[l−1]
│   └── 树上二分: 左子树差值决定第 K 小方向
│
├── 扩展应用 ─────────────────────────────────────────────
│   ├── 标记永久化: 不能懒标记（会污染其他版本）
│   ├── 树上第 K 小: 树上差分（P2633）
│   ├── 动态第 K 小: 树套树（BIT + 主席树）
│   ├── 可持久化 Trie / 并查集
│   └── 二维数点 / 区间颜色（强制在线）
│
└── 实战与面试 ────────────────────────────────────────────
    ├── 手写: P3834 模板（离散化 + 动态开点 + 作差）
    ├── 复杂度: O(n log n) 空间、O(log n)/查询
    ├── 空间: 开 n << 5（千万别省）
    └── 定位: 竞赛高频（NOI 级）；面试提存在
```

## 4. 核心概念速查

| 概念 | 一句话解释 | 说明 |
|------|-----------|------|
| **可持久化** | 支持回到历史版本 | 版本复用节点 |
| **版本复用** | 修改只复制 O(log n) 节点 | 新旧共享未改部分 |
| **主席树** | 可持久化权值线段树 | 黄嘉泰（俗称主席） |
| **动态开点** | 指针儿子按需建 | 不可堆式存储 |
| **root[]** | 各版本的根数组 | 版本索引 |
| **权值线段树** | 值域频次树 | 第 K 小的基础 |
| **作差** | root[r] − root[l−1] | 区间权值树 |
| **树上二分** | 左子树差值定方向 | 第 K 小查询 |
| **标记永久化** | 不 pushdown 的懒标记 | 防止污染版本 |
| **树套树** | BIT/线段树套主席树 | 动态第 K 小 |

## 5. 复杂度速查表

| 操作 | 普通线段树 | 主席树 |
|------|:---:|:---:|
| 建树（n 次插入） | O(n) | **O(n log n)**（每插入建 log n 节点） |
| 查询 | O(log n) | O(log n) |
| 空间 | O(4n) | **O(n log n)**（约 n<<5） |
| 版本数 | 1 | n（root[] 记录） |

```text
⚠️ 空间估算（OI Wiki 警告）:
  节点总数 ≈ 2n−1 + n(⌈log₂n⌉+1)
  竞赛惯例: 开 n << 5（32 倍）——"千万别省空间"
```

> 🎯 **一句话定位**："**可持久化 = '版本复用的数据结构'——每次修改只复制 O(log n) 个路径节点，新旧版本共享其余**。主席树是它的代表：静态区间第 K 小（P3834）是竞赛必背模板。"

## 6. 常见误区速查

| 误区 | 正解 |
|------|------|
| "可持久化 = 拷贝全树" | ❌ 只复制修改路径 O(log n) 节点——共享未改部分 |
| "主席树用堆式存储" | ❌ 必须动态开点（指针儿子）——版本共享需要 |
| "懒标记能用在主席树上" | ❌ pushdown 会污染其他版本——用标记永久化 |
| "空间开 4n 够" | ❌ O(n log n)——竞赛开 n<<5，千万别省 |
| "第 K 小查询 O(log²n)" | ❌ O(log n)——两树同时递归（作差 + 树上二分） |
| "主席树能动态更新" | ❌ 单点更新波及后续所有版本 → 动态用树套树 |
| "可持久化只有线段树" | ❌ Trie/并查集/Treap 都有可持久化版本 |
| "版本 = 深拷贝" | ❌ 版本 = 新根 + 共享子树（逻辑快照） |
| "离散化可省" | ❌ 大值域（±10⁹）必须离散化到 [1,n] |
| "面试要手撕主席树" | ❌ 竞赛要求；面试讲原理即可 |
