## 1. 可持久化原理：版本复用

```text
问题: 支持"回到历史版本"的数据结构（版本查询）
朴素: 每次修改深拷贝整棵树 → O(n) 空间/次 ✗

版本复用: 修改只复制"访问路径上的 O(log n) 个节点"——
  ① 新版本 = 新根 + 新路径节点
  ② 未修改的子树直接共享（指针复用）
  ③ root[] 数组记录每个版本的根

例: 插入 3 到版本 0 →
  新路径: 根 → … → 叶子（log n 个新节点）
  其他子树: 全部指向版本 0 的旧节点 ✓

⚠️ 代价: 时间 O(log n)、空间 O(log n)/次——
  n 次操作 → 总空间 O(n log n)

类比: Git 的版本管理——只存差异，不拷贝全量
```

> 🎯 **核心认知**："**可持久化 = 'Git 式版本管理'——每次修改只记录差异（路径节点），版本间共享未改部分**。O(log n) 的复制成本换来无限版本回退，这是它的全部魔法。"

## 2. 主席树模型：可持久化权值线段树

### 2.1 定义与结构

```text
主席树 = 可持久化权值线段树（黄嘉泰提出，俗称"主席"）

权值线段树: 下标 = 值（离散化后）、信息 = 频次——
  每个节点维护值域区间 [l, r] 的数字出现次数

可持久化: 为每个前缀 [1..i] 建一棵权值线段树——
  root[i] = 插入 a[1..i] 后的版本
  root[i] 由 root[i−1] 插入 a[i] 得来（继承 + 新路径）

⚠️ 为什么前缀建树:
  [l, r] 的权值树 = root[r] − root[l−1]（作差）
  → 任意区间第 K 小可查

⚠️ 不能堆式存储:
  版本共享 → 节点由"新路径 + 旧共享"组成——
  必须动态开点 + 记录左右儿子编号
```

### 2.2 三要素

```text
① 动态开点: 指针/编号儿子（非 2p/2p+1）
② root[]: 每个版本的根
③ 作差: 查询用两个版本的差值

⚠️ 记忆: "动态开点 + 版本根 + 前缀作差"
```

> 🎯 **主席树的定位**："**'前缀的权值线段树版本'——root[i] 是前缀状态、作差得任意区间状态**。会线段树 + 会动态开点，主席树就是'版本复用'的一层包装。"

## 3. 动态开点与 clone

### 3.1 核心操作

```java
/**
 * 动态开点 + clone（复制路径节点）
 * 内存池 + 编号引用（竞赛标准）
 */
class PSTNode {
    int sum;                                     // ① 频次（权值树）
    int left, right;                             // ② 儿子编号（非堆式）
}

int[] sum, left, right;                          // ③ 内存池（数组版）
int nodeCount;                                   // ④ 已分配节点数

int cloneNode(int old) {                         // ⑤ ⚠️ clone: 复制旧节点
    nodeCount++;
    sum[nodeCount] = sum[old];
    left[nodeCount] = left[old];
    right[nodeCount] = right[old];
    return nodeCount;
}
// ⚠️ 空间: 总节点 ≈ 2n−1 + n(⌈log₂n⌉+1)——开 n<<5 安全
//   clone 是主席树的核心——"复制旧节点再改路径"
```

### 3.2 插入（建新版本）

```java
/**
 * 插入: 从旧版本复制路径 + 修改
 * 返回新版本根编号
 */
int update(int prev, int l, int r, int pos) {
    int cur = cloneNode(prev);                   // ① 复制当前节点
    sum[cur]++;                                  // ② 频次 +1

    if (l != r) {                                // ③ 非叶子 → 递归子路径
        int mid = (l + r) / 2;
        if (pos <= mid) {
            left[cur] = update(left[prev], l, mid, pos);   // ④ 左路径新节点
        } else {
            right[cur] = update(right[prev], mid + 1, r, pos);  // ⑤ 右路径
        }
    }
    return cur;                                  // ⑥ 新版本节点
}
// 推演 版本 0 → 插 3（log n 路径）：
//   每层 clone 一个节点 → 新路径 log n 节点
//   兄弟子树仍指向版本 0（共享）✓
// ⚠️ 未修改的孩子: 从 prev 继承编号（共享）——
//   "clone 自己 + 递归改一边"就是版本复用的实现
```

> 🎯 **clone 的灵魂**："**'clone 自己、递归改一边'——新版本 = 新路径 + 共享兄弟**。update 返回新根、root[i] 存之——版本管理就在这一个函数里。"

## 4. 前缀建树与作差

### 4.1 前缀建树

```java
// 为每个前缀建版本:
int[] root = new int[n + 1];
root[0] = 0;                                     // ① 空版本（0 号节点 = 空树）
for (int i = 1; i <= n; i++) {
    root[i] = update(root[i - 1], 1, m, rank[i]);  // ② 前缀 [1..i] 版本
}
// ⚠️ rank[i] = a[i] 离散化后的排名（1..m）
//   每个版本比上个多一个频次 → 前缀频次信息
```

### 4.2 作差（区间状态）

```text
核心等式: 区间 [l, r] 的权值树 = root[r] − root[l−1]

为什么: root[r] 含 [1..r] 频次、root[l−1] 含 [1..l−1]——
  逐节点相减 = (l..r) 的频次 ✓

实现: 查询时两棵树同时递归——
  左子树差值 = sum[left[r 版本]] − sum[left[l−1 版本]]
  差值决定第 K 小方向
```

> 🎯 **作差的直觉**："**'区间 = 两前缀之差'——前缀和的经典思想应用到版本树**。查询时两树同步走、只算差值——这是主席树查询的全部秘密。"

## 5. P3834 完整模板（静态区间第 K 小）

### 5.1 完整实现

```java
/**
 * P3834 静态区间第 K 小（主席树模板）
 * 预处理 O(n log n)，查询 O(log n)，空间 O(n log n)
 */
class PersistentSegTree {
    private final int[] sum, left, right;        // ① 内存池
    private int nodeCount = 0;

    public PersistentSegTree(int maxNodes) {
        sum = new int[maxNodes];
        left = new int[maxNodes];
        right = new int[maxNodes];
    }

    private int cloneNode(int old) { ... }        // ② clone（3.1 节）

    private int update(int prev, int l, int r, int pos) { ... }  // ③ 插入（3.2 节）

    /** 查询 [l, r] 区间第 k 小（两版本作差 + 树上二分） */
    public int query(int u, int v, int l, int r, int k) {
        // u = root[l−1]、v = root[r]
        if (l == r) return l;                    // ④ 叶子 = 答案（排名）

        int mid = (l + r) / 2;
        int leftCount = sum[left[v]] - sum[left[u]];   // ⑤ ⚠️ 左子树差值
        if (k <= leftCount) {
            return query(left[u], left[v], l, mid, k);      // ⑥ 第 K 小在左
        } else {
            return query(right[u], right[v], mid + 1, r, k - leftCount);  // ⑦ 右（偏移）
        }
    }
}

// 主流程:
//   ① 离散化: a → rank（sort + unique + lower_bound）
//   ② 前缀建树: root[i] = update(root[i−1], 1, m, rank[i])
//   ③ 查询: ans = query(root[l−1], root[r], 1, m, k)
//   ④ 还原: 输出 original[ans]（排名 → 原值）

// 推演 a=[1,5,2,6,3,7,4]，查 [2,5] 第 2 小：
//   作差后区间权值 = {5,2,6,3} → 第 2 小 = 3 ✓
// ⚠️ 模板五步: 离散化 → 前缀建树 → 作差 → 树上二分 → 还原
```

### 5.2 模板要点

```text
五步: ① 离散化 ② 前缀建树 ③ 两版本作差
      ④ 树上二分 ⑤ 排名还原原值

⚠️ 记忆: "会线段树 + 动态开点 + 前缀差 = 主席树"
```

> 🎯 **P3834 的模板地位**："**P3834 = 主席树的 'Hello World'——离散化/建树/作差/二分四件套全演示**。会它，树上第 K 小（P2633）只是加树上差分。"

## 6. 识别信号与易错点

### 6.1 识别信号

```text
"静态区间第 K 小/大（多次查询）" → 主席树
"区间权值统计（频次/颜色）" → 主席树
"版本回退/历史查询" → 可持久化
"强制在线 + 区间统计" → 主席树/树套树

⚠️ 面试定位: 竞赛高频（NOI 级）——
  面试讲"主席树能静态区间第 K 小 O(log n)"即可
```

### 6.2 易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 用堆式存储 | 动态开点（编号儿子） | 版本共享失效 |
| 2 | 忘 clone | update 先复制旧节点 | 污染旧版本 |
| 3 | 空间开 4n | n<<5（32 倍） | 越界（随机 bug） |
| 4 | 作差方向错 | sum[left[v]] − sum[left[u]] | 频次错 |
| 5 | 第 K 小偏移忘减 | `k − leftCount` | 定位错 |
| 6 | 忘离散化 | 大值域直接建 | 空间爆 |
| 7 | 还原忘 original | 排名 → 原值 | 输出错 |
| 8 | 懒标记 | 标记永久化（扩展） | 污染版本 |

> 🎯 **核心要点**：主席树通关四件事——**① 版本复用**（复制路径共享其余）；**② 三件套**（动态开点/clone/root[]）；**③ P3834 五步**（离散化/建树/作差/二分/还原）；**④ 空间纪律**（n<<5）。**主席树 = '线段树 + 版本复用'——'clone 自己、递归改一边'十字诀，就是它的全部实现**。
