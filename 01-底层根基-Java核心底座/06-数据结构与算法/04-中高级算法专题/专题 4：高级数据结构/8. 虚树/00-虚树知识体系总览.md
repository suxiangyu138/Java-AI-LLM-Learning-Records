# 虚树知识体系总览

> 虚树解决的是"多次询问、每次只涉及少量关键点"的树上问题。它把整棵树压缩成只包含关键点与它们两两 LCA 的小树，规模从 O(n) 降到 O(k)，让每次询问的树形 DP 变得可行。

## 4. 核心概念速查

| 概念 | 含义 |
|------|------|
| 关键点 | 每次询问给出的点集 |
| 虚树 | 只含关键点、关键点两两 LCA、根的压缩树 |
| 虚树规模 | O(k)，k 为关键点数 |
| 建树依据 | 按 dfn 排序后用单调栈维护右链 |
| 边权 | 原树上两点的距离（或路径最小边权等） |
| 总复杂度 | O(Σk log k + Σk log n) |
