# 01-虚树构造与 DP 模板

> 虚树的构造只有三步：关键点按 dfn 排序、补上相邻点的 LCA、用单调栈按右链建树。难点不在代码，而在理解"为什么补 LCA"和"栈里维护的是什么"。

## 1. 问题模型

```text
给定一棵 n 个节点的树，m 次询问
每次询问给出 k 个关键点
要求在这些关键点上做某种树形 DP

约束：
  n 可达 10^5-10^6
  m 可达 10^5
  但 Σk 有限（如 Σk ≤ 10^5 或 10^6）
```

朴素做法对每次询问遍历整棵树，复杂度 $O(nm)$，不可接受。

---

## 2. 为什么需要虚树

关键观察：

```text
一次询问只关心 k 个关键点
以及这些点之间的"祖先-后代"关系
其余大量节点对答案没有贡献
```

例子：

```text
原树（n=7）：
        1
      / | \
     2  3  4
    / \    |
   5   6   7

关键点：5, 6, 7

真正影响答案的节点：
  5, 6, 7
  它们的 LCA：2（5 和 6 的 LCA）、1（2 和 7 的 LCA）
  → 虚树节点：1, 2, 5, 6, 7（5 个）

被压缩掉的：3, 4（与关键点之间的路径无关）
```

规模对比：

| 做法 | 每次询问复杂度 | 总复杂度 |
|------|--------------|---------|
| 原树遍历 | O(n) | O(nm) |
| 虚树 | O(k log k + k log n) | O(Σk log k + Σk log n) |

当 $n=10^6$、$m=10^5$、$\sum k=10^5$ 时，虚树可行，原树遍历不可行。

---

## 3. 构造原理

### 3.1 需要哪些节点

虚树的节点集合：

$$\mathcal{V}_{virtual} = \{root\}\cup\{关键点\}\cup\{关键点两两的 LCA\}$$

更精确地说，只需要"按 dfn 排序后相邻两点的 LCA"：

```text
设关键点按 dfn 排序为 p1, p2, ..., pk
加入 lca(p1,p2), lca(p2,p3), ..., lca(p_{k-1},p_k)
即可覆盖所有需要的分叉点
```

为什么相邻就够：

```text
任意两点的 LCA，一定等于某对"dfn 相邻"的点的 LCA
（这是 dfn 序的经典性质）

所以补 k-1 个 LCA 就够了，不需要 O(k²) 对
```

### 3.2 为什么按 dfn 排序

dfn 是先序遍历的时间戳。按 dfn 排序后，关键点在"树的平面展开"上从左到右排列：

```text
虚树的构建过程 = 按从左到右的顺序，维护当前最右侧的链

栈里始终存的是：
  从虚树根到"当前处理节点"这条路径上的所有节点（右链）
```

---

## 4. 构造步骤

```text
第 1 步：关键点按 dfn 升序排序
第 2 步：对相邻两点求 LCA，把所有 LCA 加入节点集合
第 3 步：节点集合去重，再按 dfn 排序
第 4 步：单调栈建树
```

第 4 步的伪代码：

```text
stack = []
for v in nodes（按 dfn 排序）:
    if stack 为空:
        push(v)
        continue

    l = lca(v, stack.top())

    while stack.size >= 2 and depth[stack[-2]] >= depth[l]:
        addEdge(stack[-2], stack[-1])
        pop()

    if stack.top() != l:
        addEdge(l, stack.top())
        pop()
        push(l)

    push(v)

while stack.size >= 2:
    addEdge(stack[-2], stack[-1])
    pop()
```

三个动作的含义：

| 动作 | 含义 |
|------|------|
| `while depth[stack[-2]] >= depth[l]` | 栈顶的链已经处理完，弹出并连边 |
| `if stack.top() != l` | 当前 LCA 不在栈中，插入它作为新的分叉点 |
| `addEdge(l, stack.top())` | 把 LCA 与原栈顶连边 |

---

## 5. 正确性说明

### 5.1 栈维护的是右链

按 dfn 顺序处理节点时，当前节点 $v$ 要么是栈顶的后代，要么在栈顶的右侧子树。栈中保存的是"从虚树根到当前节点路径上的祖先链"。

### 5.2 为什么弹到 `depth[stack[-2]] >= depth[l]`

设栈中从底到顶为 $a_0,a_1,\ldots,a_t$。如果 $a_{t-1}$ 的深度不小于 $l$，说明 $a_t$ 及其子树已经完整处理（因为 $v$ 在 $l$ 的另一侧），可以把 $a_t$ 挂到 $a_{t-1}$ 上并弹出。

### 5.3 为什么需要补 LCA

如果不补 LCA，两个关键点可能不在同一条链上，虚树会缺少分叉点，树的连通性被破坏。补上 LCA 后，任意两个关键点的最近公共祖先都在虚树中，祖先关系得以保留。

## 6. 完整代码

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

public class VirtualTree {

    private final int n;
    private final List<Integer>[] graph;
    private final int[] parent;
    private final int[] depth;
    private final int[] size;
    private final int[] heavy;
    private final int[] top;
    private final int[] dfn;
    private int timer;

    @SuppressWarnings("unchecked")
    public VirtualTree(int n) {
        this.n = n;
        graph = new List[n];
        for (int i = 0; i < n; i++) {
            graph[i] = new ArrayList<>();
        }
        parent = new int[n];
        depth = new int[n];
        size = new int[n];
        heavy = new int[n];
        top = new int[n];
        dfn = new int[n];
        Arrays.fill(heavy, -1);
    }

    public void addEdge(int u, int v) {
        graph[u].add(v);
        graph[v].add(u);
    }

    public void build(int root) {
        dfs1(root, -1);
        dfs2(root, root);
    }

    private void dfs1(int u, int p) {
        parent[u] = p;
        size[u] = 1;
        int maxSize = 0;
        for (int v : graph[u]) {
            if (v == p) {
                continue;
            }
            depth[v] = depth[u] + 1;
            dfs1(v, u);
            size[u] += size[v];
            if (size[v] > maxSize) {
                maxSize = size[v];
                heavy[u] = v;
            }
        }
    }

    private void dfs2(int u, int head) {
        top[u] = head;
        dfn[u] = timer++;
        if (heavy[u] != -1) {
            dfs2(heavy[u], head);
        }
        for (int v : graph[u]) {
            if (v == parent[u] || v == heavy[u]) {
                continue;
            }
            dfs2(v, v);
        }
    }

    public int lca(int u, int v) {
        while (top[u] != top[v]) {
            if (depth[top[u]] < depth[top[v]]) {
                int temp = u;
                u = v;
                v = temp;
            }
            u = parent[top[u]];
        }
        return depth[u] < depth[v] ? u : v;
    }

    public int dfn(int u) {
        return dfn[u];
    }

    public int depth(int u) {
        return depth[u];
    }

    public int parent(int u) {
        return parent[u];
    }

    public VirtualResult buildVirtualTree(int root, int[] keys) {
        List<Integer> nodes = new ArrayList<>();
        nodes.add(root);
        for (int key : keys) {
            nodes.add(key);
        }

        nodes.sort((a, b) -> Integer.compare(dfn[a], dfn[b]));

        int m = nodes.size();
        for (int i = 1; i < m; i++) {
            nodes.add(lca(nodes.get(i - 1), nodes.get(i)));
        }

        nodes.sort((a, b) -> Integer.compare(dfn[a], dfn[b]));

        List<Integer> unique = new ArrayList<>();
        for (int node : nodes) {
            if (unique.isEmpty() || unique.get(unique.size() - 1) != node) {
                unique.add(node);
            }
        }

        List<List<Integer>> virtualGraph = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            virtualGraph.add(new ArrayList<>());
        }

        int[] stack = new int[unique.size() + 1];
        int stackTop = 0;

        for (int v : unique) {
            if (stackTop == 0) {
                stack[stackTop++] = v;
                continue;
            }

            int ancestor = lca(v, stack[stackTop - 1]);

            while (stackTop >= 2 && depth[stack[stackTop - 2]] >= depth[ancestor]) {
                virtualGraph.get(stack[stackTop - 2]).add(stack[stackTop - 1]);
                virtualGraph.get(stack[stackTop - 1]).add(stack[stackTop - 2]);
                stackTop--;
            }

            if (stack[stackTop - 1] != ancestor) {
                virtualGraph.get(ancestor).add(stack[stackTop - 1]);
                virtualGraph.get(stack[stackTop - 1]).add(ancestor);
                stackTop--;
                stack[stackTop++] = ancestor;
            }

            stack[stackTop++] = v;
        }

        while (stackTop >= 2) {
            virtualGraph.get(stack[stackTop - 2]).add(stack[stackTop - 1]);
            virtualGraph.get(stack[stackTop - 1]).add(stack[stackTop - 2]);
            stackTop--;
        }

        return new VirtualResult(root, virtualGraph, unique);
    }

    public static class VirtualResult {
        private final int root;
        private final List<List<Integer>> graph;
        private final List<Integer> nodes;

        public VirtualResult(int root, List<List<Integer>> graph, List<Integer> nodes) {
            this.root = root;
            this.graph = graph;
            this.nodes = nodes;
        }

        public int root() {
            return root;
        }

        public List<List<Integer>> graph() {
            return graph;
        }

        public List<Integer> nodes() {
            return nodes;
        }
    }
}
```

使用示例：

```java
VirtualTree tree = new VirtualTree(7);
tree.addEdge(0, 1);
tree.addEdge(0, 2);
tree.addEdge(0, 3);
tree.addEdge(1, 4);
tree.addEdge(1, 5);
tree.addEdge(3, 6);
tree.build(0);

VirtualTree.VirtualResult result = tree.buildVirtualTree(0, new int[]{4, 5, 6});
for (int node : result.nodes()) {
    System.out.println("virtual node: " + node);
}
```

## 7. 例题：消耗战

**题意**：

```text
给定一棵带边权的树，根为 1
每次询问给出 k 个关键点
要求切断若干条边，使得每个关键点都与根不连通
求最小切断代价
```

**思路**：

预处理每个节点到根的路径上的最小边权 `mn[u]`。

在虚树上做 DP：

```text
dp[u]：切断 u 子树内所有关键点与根连通的最小代价

如果 u 是关键点：
  必须切断 u 与根的联系
  dp[u] = mn[u]

如果 u 不是关键点：
  两种选择：
    ① 直接切断根到 u 的某条边：代价 mn[u]
    ② 分别切断每个孩子子树：代价 Σ dp[v]
  dp[u] = min(mn[u], Σ dp[v])
```

答案：`dp[root]`。

代码：

```java
public long solve(int root, int[] keys, int[] parent,
                  long[] minEdgeToRoot, List<List<Integer>> virtualGraph,
                  boolean[] isKey) {
    return dfsVirtual(root, parent, minEdgeToRoot, virtualGraph, isKey);
}

private long dfsVirtual(int u, int parent, long[] minEdgeToRoot,
                        List<List<Integer>> virtualGraph, boolean[] isKey) {
    if (isKey[u]) {
        return minEdgeToRoot[u];
    }

    long sum = 0;
    boolean hasChild = false;
    for (int v : virtualGraph.get(u)) {
        if (v == parent) {
            continue;
        }
        hasChild = true;
        sum += dfsVirtual(v, u, minEdgeToRoot, virtualGraph, isKey);
    }

    if (!hasChild) {
        return minEdgeToRoot[u];
    }
    return Math.min(minEdgeToRoot[u], sum);
}
```

注意：虚树中只有关键点与 LCA，"叶子"可能不是原树叶子，但一定是关键点，所以 `minEdgeToRoot` 的语义仍然成立。

## 8. 复杂度分析

```text
预处理：
  dfs1/dfs2：O(n)

单次询问：
  排序：O(k log k)
  求 LCA：O(k log n)（树链剖分）或 O(k)
  建树：O(k)
  DP：O(k)

单次总计：O(k log k + k log n)
所有询问：O(Σk log k + Σk log n)
```

空间：

```text
虚树图：如果每次询问都开 n 个 ArrayList，内存与初始化开销大
→ 优化：用 map 或只对涉及的节点建邻接表
→ 或用时间戳标记，避免每次清空
```

> **提示**：上面的模板为了清晰，每次询问都新建 `n` 个 `ArrayList`。$m$ 很大时会因初始化 O(n) 而退化。生产/竞赛实现应改为"只清理涉及的节点"或使用链式前向星 + 时间戳。

## 9. 易错点

```text
① 忘记把根加入节点集合
   → 虚树可能不连通，DP 从错误的根开始

② 只对原始关键点排序，没把 LCA 一起排序
   → 栈构造顺序错误，边连错

③ 补 LCA 时只补相邻原始关键点的 LCA
   → 实际上这样是对的；错的是补完不重新排序

④ 栈判断写成 depth[stack[-2]] > depth[l]
   → 少弹一层，出现重复边或环

⑤ 多组询问不清理虚树邻接表
   → 上一组数据残留，答案错误

⑥ 关键点去重遗漏
   → 重复关键点导致栈中重复节点，DP 重复计算

⑦ 边权映射错误
   → 虚树边权应为原树上两点的距离或路径最小值，不是父边权
```

## 10. 小结

| 问题 | 答案 |
|------|------|
| 虚树解决什么 | 多次询问、每次少量关键点的树上 DP |
| 节点集合 | 根 + 关键点 + 相邻点 LCA |
| 建树方式 | dfn 排序 + 单调栈维护右链 |
| 单次复杂度 | O(k log k + k log n) |
| 关键点 DP | 关键点强制切，非关键点取 min |
| 常见错误 | 忘加根、忘排序 LCA、栈条件、清理 |
