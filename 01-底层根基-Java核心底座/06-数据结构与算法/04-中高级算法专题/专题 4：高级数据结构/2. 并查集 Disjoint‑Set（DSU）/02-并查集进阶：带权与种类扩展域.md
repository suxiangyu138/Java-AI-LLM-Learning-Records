## 1. 进阶变体全景

| 变体 | 回答的问题 | 核心机制 |
|------|:---:|------|
| 基础 DSU | 是否同组 | parent 树 |
| 带权 DSU | 同组内的"关系"（距离/差值） | weight[] 到父权值 |
| 种类 DSU | 多种角色（敌人/朋友/物种） | 元素拆多域 |
| 可撤销 DSU | 回滚到历史状态 | 栈记录 + 时间倒序 |

```text
⚠️ 识别主线:
  "只要'是否同组' → 基础版
   需要'同组内的数值关系' → 带权
   多类互斥关系 → 扩展域
   需要回滚 → 可撤销"
```

> 🎯 **核心认知**："**进阶变体 = 基础版回答'是否同组'、带权回答'什么距离'、扩展域回答'什么角色'、可撤销回答'过去的状态'**——四种语义层层递进，识别'要回答什么'是选型第一步。"

## 2. 带权 DSU：weight 数组

### 2.1 模型

```text
带权 DSU: 基础版 + weight[x] = x 到父节点的"关系值"
  距离/差值: weight[x]（数值）
  奇偶性: weight[x] ∈ {0,1}（异或运算）
  模关系: weight[x] ∈ {0,1,2}（模加法群）

核心性质（可传递性）:
  x 到根的距离 = 路径上 weight 之和
  find 压缩时同步累加（weight[x] += weight[parent[x]]）
  x 与 y 的关系 = weight[x] 与 weight[y] 的差（相对根）

⚠️ 应用:
  战舰（距离差）、食物链（模 3）、区间奇偶性（异或）
```

> 🎯 **带权的本质**："**'weight[x] = x 到父的关系'——通过根做中转，任意两元素的关系 = 各自到根关系的组合**。'可传递的关系'（距离/差值/异或）是带权 DSU 的适用前提。"

## 3. 带权 DSU 的路径压缩与合并推导

### 3.1 路径压缩同步更新

```java
/**
 * 带权 DSU: find 压缩时同步更新 weight
 * ⚠️ 更新必须在"改变父指针"之前完成
 */
int[] parent;
int[] weight;                                     // ① 到父的权值

int find(int x) {
    if (parent[x] != x) {
        int root = find(parent[x]);               // ② 先找根（递归）
        weight[x] += weight[parent[x]];           // ③ ⚠️ 累加到根的权值
        parent[x] = root;                         // ④ 再挂根
    }
    return parent[x];
}
// 例: 链 x → a → root，weight[x]=1, weight[a]=2
//   压缩后: weight[x] = 1 + 2 = 3（x 到根的距离）✓
// ⚠️ 顺序: 必须先更新 weight 再改 parent——
//   否则 weight[parent[x]] 已被覆盖（旧父丢失）
```

### 3.2 合并时的权值推导

```java
/**
 * 带权 union(x, y, w): 已知 value[x] − value[y] = w
 * 推导: root_x 挂到 root_y 后，weight[root_x] 是多少？
 *   设 weight[x] = x 到 root_x 的距离、weight[y] = y 到 root_y 的距离
 *   value[x] = w + value[y]
 *   value[root_x] = value[x] − weight[x]
 *   value[root_y] = value[y] − weight[y]
 *   → weight[root_x] = value[root_x] − value[root_y]
 *                    = (w + value[y] − weight[x]) − (value[y] − weight[y])
 *                    = w − weight[x] + weight[y]
 */
void union(int x, int y, int w) {
    int rx = find(x), ry = find(y);
    if (rx == ry) {
        // ① 已同组 → 检查是否矛盾（冲突检测）
        if (weight[x] - weight[y] != w) 矛盾!
        return;
    }
    parent[rx] = ry;
    weight[rx] = w - weight[x] + weight[y];       // ② 新权值（推导结果）
}
// ⚠️ 推导是带权 DSU 的难点——"先画关系图、再列等式"
//   异或场景: weight 用 ^（奇偶性）、+ 换 ^
```

> 🎯 **带权推导的方法论**："**'画关系图 → 设 value 变量 → 列等式 → 解出新权值'——推导过程比背公式重要**。冲突检测（已同组时验证 w）是带权 DSU 的隐藏考点（990 等式方程正是它）。"

## 4. 种类 DSU（扩展域）

### 4.1 模型

```text
种类 DSU（扩展域）: 把每个元素拆成多个"逻辑角色"
  处理互斥/多类关系（敌人/朋友、三个物种、染色）

例（敌对关系）:
  每个元素拆两域: 自己域 + 敌人域
  A 与 B 敌对 → union(A, B的敌人域) 且 union(A的敌人域, B)
  效果: A 的朋友 ≠ B 的朋友（通过敌人域传递）

例（食物链，3 物种）:
  每动物拆 3 域: 同类域/猎物域/天敌域
  关系边: 吃/被吃/同类——域间 union 表达

⚠️ 与带权的选择:
  数值关系（距离/差值）→ 带权（一个数组）
  逻辑角色（敌人/物种）→ 扩展域（拆多份）
  两种都可解食物链——扩展域更直观、带权更省空间
```

### 4.2 代码骨架（敌人关系）

```java
/**
 * 种类 DSU（扩展域）: 元素 i 拆成 i 与 i+n 两个域
 * 0..n−1 = 自己域；n..2n−1 = 敌人域
 */
int find(int x) { ... }                           // 同基础版

void setEnemy(int a, int b) {                     // ① a 与 b 敌对
    union(a, b + n);                              // a 的朋友 = b 的敌人
    union(a + n, b);                              // a 的敌人 = b 的朋友
}

boolean isFriend(int a, int b) {
    return find(a) == find(b);                    // ② 同域 = 朋友
}
boolean isEnemy(int a, int b) {
    return find(a) == find(b + n);                // ③ 对方敌人域 = 敌对
}
// ⚠️ 冲突检测: isFriend(a,b) && isEnemy(a,b) 同时成立 → 矛盾
//   域数量: 2 域（敌人）、3 域（物种）、K 域（K 类关系）
```

> 🎯 **扩展域的直觉**："**'拆域 = 把'角色关系'变成'集合关系'——敌人域相并即敌对**。域数量由关系种类决定（2 敌对/3 物种/K 类），冲突检测是它的隐藏考点。"

## 5. 可撤销 DSU

### 5.1 原理

```text
可撤销 DSU: 支持 union 后回滚到之前状态
  适用: 线段树分治、按时间轴操作的图问题

两大铁律:
  ① ⚠️ 禁用路径压缩——压缩破坏树结构信息，无法恢复
  ② 必须按大小合并（size 可恢复；rank 也可但 size 更直观）

实现: 栈记录每次合并的"操作快照"——
  (子根, 父根, 原子树大小)
  撤销: 弹栈 → 子根父设回自身 → 恢复父根大小

⚠️ 只能"时间倒序"撤销（后进先出）——
  不能任意回滚（那是可持久化并查集的范畴）
```

### 5.2 代码骨架

```java
/**
 * 可撤销 DSU（栈记录 + 时间倒序撤销）
 */
class RollbackDSU {
    int[] parent, size;
    Deque<int[]> history = new ArrayDeque<>();    // ① 操作快照栈

    int find(int x) {                             // ② ⚠️ 无路径压缩！
        while (parent[x] != x) x = parent[x];
        return x;
    }

    void union(int x, int y) {
        int rx = find(x), ry = find(y);
        if (rx == ry) { history.push(null); return; }   // ③ 无效操作也占位
        if (size[rx] > size[ry]) { int t = rx; rx = ry; ry = t; }
        history.push(new int[]{rx, ry, size[ry]});      // ④ 快照
        parent[rx] = ry;
        size[ry] += size[rx];
    }

    void rollback(int tag) {                      // ⑤ 撤销到标记点
        while (history.size() > tag) {
            int[] op = history.pop();
            if (op == null) continue;
            parent[op[0]] = op[0];                // ⑥ 子根恢复自身
            size[op[1]] = op[2];                  // ⑦ 父根大小恢复
        }
    }
}
// ⚠️ 无路径压缩 → find O(log n)；撤销 O(1)/操作
//   应用: 线段树分治（DFS 进入合并、返回撤销）
```

> 🎯 **可撤销的定位**："**'栈记录 + 时间倒序 + 禁路径压缩'——三条铁律缺一不可**。它是线段树分治的地基（DFS 进合并、出撤销），竞赛向进阶内容。"

## 6. 变体识别与易错点

### 6.1 识别决策树

```text
"是否同组" → 基础 DSU
"同组内的距离/差值/奇偶" → 带权 DSU
"敌人/朋友/物种等逻辑角色" → 扩展域 DSU
"需要回滚/分治" → 可撤销 DSU
"持久化/任意版本查询" → 可持久化 DSU（竞赛）

⚠️ 食物链双解: 带权（模 3 群）与扩展域（3 域）——
  都常见，扩展域直观、带权省空间
```

### 6.2 易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 带权压缩先改父后更新 | 先累加再挂根 | 权值错 |
| 2 | 带权合并推导错 | 画图列等式 | 权值错 |
| 3 | 冲突检测漏 | 同组时验证 w | 矛盾漏报 |
| 4 | 扩展域域数不够 | K 类拆 K 域 | 关系错 |
| 5 | 可撤销用路径压缩 | 只按大小 | 无法撤销 |
| 6 | 撤销顺序错 | 时间倒序（后进先出） | 状态错乱 |
| 7 | 无效 union 忘占位 | history 压 null | 对齐错 |

> 🎯 **核心要点**：并查集进阶通关四件事——**① 变体识别**（数值→带权、角色→扩展域、回滚→可撤销）；**② 带权三要素**（weight 数组/压缩同步/合并推导）；**③ 扩展域拆域**（敌人 2 域/物种 3 域）；**④ 可撤销三铁律**（禁压缩/按大小/倒序撤销）。**进阶变体 = '基础版 + 更多语义'——'要回答什么'一句话，就是全部选型**。
