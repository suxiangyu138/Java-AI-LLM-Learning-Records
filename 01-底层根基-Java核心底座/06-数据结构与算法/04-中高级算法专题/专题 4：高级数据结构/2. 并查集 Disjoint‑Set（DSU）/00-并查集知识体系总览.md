## 1. 知识体系导图

```text
并查集（DSU / Union-Find）
│
├── 核心本质 ──────────────────────────────────────────────
│   ├── = 不相交集合的"合并 + 查询是否同组"
│   ├── 树结构: parent[] 数组，根 = 集合代表
│   ├── find(x): 找根（路径压缩优化）
│   └── union(x, y): 合并两集合（按秩/按大小合并）
│
├── 两大优化 ──────────────────────────────────────────────
│   ├── 路径压缩: find 时把路径节点直接挂根（扁平化）
│   ├── 按秩合并: 矮树挂高树（防退化链表）
│   └── 复杂度: 单独用 O(log n)；双用 O(α(n))（反阿克曼 ≤ 5）
│
├── 进阶变体 ──────────────────────────────────────────────
│   ├── 带权 DSU: weight[] 记节点到父的关系（距离/差值/异或）
│   ├── 种类 DSU（扩展域）: 元素拆多域（敌人/朋友/物种）
│   ├── 可撤销 DSU: 栈记录 + 时间倒序撤销（线段树分治）
│   └── 离线技巧: 倒序处理/染色跳点（O(nα(n))）
│
├── 经典应用 ──────────────────────────────────────────────
│   ├── 连通分量: 200 岛屿、547 省份（并查集版）
│   ├── 判环: 684 冗余连接（合并冲突即环）
│   ├── Kruskal: 最小生成树判环
│   ├── 等价关系: 990 等式方程、边界连通（130）
│   └── 动态连通性: 在线合并 + 查询
│
└── 实战与面试 ────────────────────────────────────────────
    ├── 手写: 模板 2 分钟（find 递归 + union 按秩）
    ├── 复杂度: O(α(n)) 反阿克曼证明
    ├── 变体识别: 关系可传递 → 带权；多类关系 → 扩展域
    └── 话术: "合并 + 查询 + 优化"三段式
```

## 4. 核心概念速查

| 概念 | 一句话解释 | 说明 |
|------|-----------|------|
| **并查集** | 集合合并 + 同组查询 | 树结构 + parent[] |
| **find** | 找集合代表（根） | 路径压缩优化 |
| **union** | 合并两集合 | 按秩/按大小合并 |
| **路径压缩** | find 时节点直接挂根 | 扁平化树 |
| **按秩合并** | 矮树挂高树 | 防退化 |
| **反阿克曼** | α(n) ≤ 5（实际常数） | 双优化后复杂度 |
| **带权 DSU** | weight[] 记节点到父关系 | 距离/差值/异或 |
| **扩展域** | 元素拆多域（敌人/朋友） | 多类关系 |
| **可撤销 DSU** | 栈记录 + 时间倒序撤销 | 线段树分治 |
| **Kruskal** | 最小生成树 + 判环 | 并查集经典应用 |

## 5. 复杂度速查表

| 实现 | find | union | 总操作（m 次） |
|------|:---:|:---:|:---:|
| 朴素 | O(n) 最坏 | O(n) | O(mn)（退化链表） |
| 只路径压缩 | O(log n) 摊还 | O(log n) | O(m log n) |
| 只按秩合并 | O(log n) | O(log n) | O(m log n) |
| **双优化** | **O(α(n))** | **O(α(n))** | **O(m·α(n))** |

```text
⚠️ 反阿克曼函数 α(n):
  实际任何 n ≤ 10^80 都满足 α(n) ≤ 5
  → 双优化后视为"近似 O(1)"
```

> 🎯 **一句话定位**："**并查集 = '集合的合并与查询'——两大优化（路径压缩/按秩合并）后 O(α(n)) 近似常数**。连通分量、判环、Kruskal、等价关系，一个模板通吃。"

## 6. 常见误区速查

| 误区 | 正解 |
|------|------|
| "并查集能维护路径信息" | ❌ 基础版只维护"是否同组"——路径信息要带权 DSU |
| "路径压缩后树会乱" | ❌ 只影响内部结构不影响集合语义（find 结果不变） |
| "按秩合并 = 按大小合并" | ❌ 秩是高度上界、大小是元素数——都防退化，语义略异 |
| "可撤销 DSU 可以用路径压缩" | ❌ 路径压缩破坏树结构 → 无法撤销；必须只按秩合并 |
| "并查集 O(1)" | ❌ O(α(n))——反阿克曼近似常数但严格不是 1 |
| "union 顺序无所谓" | ❌ 无按秩合并会退化链表（0→1→2→3…）→ O(n) |
| "find 递归一定行" | ❌ 深树递归栈溢出 → 迭代版（或 n 大时用循环） |
| "带权 = 扩展域" | ❌ 带权存"数值关系"（距离/差值）；扩展域拆"逻辑域"（敌人/朋友） |
| "并查集只用于图" | ❌ 等价关系/染色/动态连通性都是它的主场 |
| "合并冲突一定是环" | ❌ 只有在"已同组再合并"时才是环（684 判环） |
