## 1. 547 省份数量（连通分量）

### 1.1 题目与思路

**题**：邻接矩阵表示城市连通关系，求连通分量数（省份数）。

**并查集合并 + 计数**：

```java
/**
 * LeetCode 547. 省份数量（并查集版）
 * 时间 O(n²·α(n))，空间 O(n)
 */
public int findCircleNum(int[][] isConnected) {
    int n = isConnected.length;
    DSU dsu = new DSU(n);                          // ① 每城市一集合

    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {          // ② 只扫上三角
            if (isConnected[i][j] == 1) {
                dsu.union(i, j);                   // ③ 相连 → 合并
            }
        }
    }
    // ④ 计数: 根的数量 = 集合数
    int count = 0;
    for (int i = 0; i < n; i++)
        if (dsu.find(i) == i) count++;             // ⑤ 自己是根的集合
    return count;
}
// 推演 [[1,1,0],[1,1,0],[0,0,1]] → 2 ✓（{0,1} 与 {2}）
// ⚠️ 计数技巧: 根的数量 = 集合数（parent[i]==i 的个数）
//   三解对比: DFS/BFS（遍历标记）与并查集（动态合并）
```

> 🎯 **547 的必考点**："**'相连即合并、根数即答案'——并查集解连通分量的标准姿势**。与 DFS/BFS 的差异：并查集支持**动态加边**（在线连通性问题），面试三解对比是加分。"

## 2. 684 冗余连接（判环）

### 2.1 题目与思路

**题**：树 + 一条冗余边（n 个节点 n 条边），删除后仍是树，返回该边。

**合并冲突即环**：

```java
/**
 * LeetCode 684. 冗余连接
 * 并查集判环: 已同组再合并 → 该边构成环
 */
public int[] findRedundantConnection(int[][] edges) {
    int n = edges.length;
    DSU dsu = new DSU(n + 1);                      // ① 1-based

    for (int[] edge : edges) {
        int a = edge[0], b = edge[1];
        if (dsu.isSame(a, b)) {
            return edge;                           // ② ⚠️ 已同组 → 构成环！
        }
        dsu.union(a, b);                           // ③ 否则合并
    }
    return new int[0];
}
// 推演 [[1,2],[1,3],[2,3]] → [2,3] ✓
//   （[1,2] 合并、[1,3] 合并、[2,3] 已同组 → 环）
// ⚠️ 判环原理: 树的性质 = n 节点 n−1 边且无环——
//   n 条边必有一条"已连通再连"的 → 那条就是冗余
//   变体: 685 冗余连接 II（有向图——需多判断）
```

> 🎯 **684 的判环直觉**："**'已同组再 union = 环'——并查集判环的一行代码**。Kruskal 的判环核心正是它：MST 中每条边合并前先查'是否已连通'。"

## 3. 990 等式方程（带权冲突检测）

### 3.1 题目与思路

**题**：变量间的等式/不等式，判断是否全部可满足。

**并查集冲突检测**：等式先合并、不等式后验证：

```java
/**
 * LeetCode 990. 等式方程的可满足性
 * 两遍: 等式全合并 → 不等式逐个验证
 */
public boolean equationsPossible(String[] equations) {
    DSU dsu = new DSU(26);                         // ① 26 个字母变量

    // ② 第一遍: 所有 "==" 合并
    for (String eq : equations) {
        if (eq.charAt(1) == '=') {
            dsu.union(eq.charAt(0) - 'a', eq.charAt(3) - 'a');
        }
    }
    // ③ 第二遍: 所有 "!=" 验证
    for (String eq : equations) {
        if (eq.charAt(1) == '!') {
            if (dsu.isSame(eq.charAt(0) - 'a', eq.charAt(3) - 'a')) {
                return false;                      // ④ 相等却要求不等 → 矛盾
            }
        }
    }
    return true;
}
// 推演 ["a==b","b!=a"] → false ✓（a==b 与 b!=a 矛盾）
//   ["a==b","b==c","a!=c"] → false ✓
// ⚠️ 两遍法: 先合并全部相等关系、再验证不等——
//   "先建立等价类、再查冲突"是等价关系题的标准套路
```

> 💡 **990 的等价类思想**："**'等式建等价类、不等式验冲突'——990 是并查集'等价关系'语义的直接应用**。带权 DSU 的冲突检测（02 文件）是它的进阶形态。"

## 4. Kruskal 最小生成树

### 4.1 题目与思路

**题**：最小生成树（边权最小的连通子图）。

**Kruskal = 排序 + 并查集判环**：

```java
/**
 * Kruskal 最小生成树
 * ① 边按权值排序 ② 并查集判环 ③ 不环则选边
 * 时间 O(E log E)，空间 O(V)
 */
int kruskal(int n, int[][] edges) {                // edges: [u, v, w]
    Arrays.sort(edges, (a, b) -> a[2] - b[2]);     // ① 按权值升序
    DSU dsu = new DSU(n);

    int total = 0, count = 0;
    for (int[] edge : edges) {
        if (!dsu.isSame(edge[0], edge[1])) {       // ② 不成环才选
            dsu.union(edge[0], edge[1]);
            total += edge[2];                      // ③ 累计权值
            count++;
            if (count == n - 1) break;             // ④ n−1 条边即成树
        }
    }
    return count == n - 1 ? total : -1;            // ⑤ 连通才返回
}
// 推演 3 节点边 (0,1,1)(1,2,2)(0,2,3) → 3 ✓（选 1+2）
// ⚠️ 贪心正确性: 每次选"最小不成环边"→ 全局最小——
//   并查集在这里是"判环加速器"（O(α(n)) 判连通）
```

> 🎯 **Kruskal 的定位**："**Kruskal = '排序 + 并查集判环'——并查集是它的判环引擎**。面试考 Kruskal 时并查集模板是前提，'为什么贪心对'（切割性质）是追问点。"
