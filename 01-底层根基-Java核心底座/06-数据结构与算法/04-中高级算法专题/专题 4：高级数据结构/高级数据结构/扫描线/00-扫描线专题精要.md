## 1. 核心概念

### 1.1 什么是扫描线

> 扫描线（Sweep Line）：把区间/矩形的**起止点变成事件**，按坐标排序后**线性扫描**，事件处更新状态。

```
核心思想：
  ① 事件化：每个区间 [l, r] → 事件 (l, +1) 和 (r, -1)
  ② 排序：按坐标排序所有事件
  ③ 扫描：逐个处理事件，维护当前状态（重叠数/高度）

应用：最大重叠数、合并区间、天际线、矩形面积

⚠️ 与"排序 + 遍历"的区别：
  普通：直接遍历区间（逐个处理）
  扫描线：转化为事件点（统一在事件处处理）
  → 适用于"重叠/覆盖"类统计
```

### 1.2 识别信号

```
"最大重叠/同时进行" → 扫描线（253 会议室）
"天际线/轮廓" → 扫描线（218）
"区间覆盖统计" → 扫描线/差分
"矩形面积并集" → 二维扫描线

⚠️ 面试定位：
  一维扫描线（253）面试高频
  二维（850 矩形面积）竞赛级
```

### 1.3 扫描线的本质

```
"把区间问题变成事件序列问题"
  区间 → 两个事件（开始/结束）
  事件带类型（+1/-1/高度）
  扫描时维护"当前状态"

⚠️ 关键：事件排序的规则
  同坐标时先处理谁？
  → 决定"端点相撞是否算重叠"
```

## 2. 完整代码模板

### 2.1 253. 会议室 II（事件扫描线）

```java
/**
 * LeetCode 253. 会议室 II（一维扫描线经典）
 * 开始事件 +1，结束事件 -1 → 扫描维护当前占用
 */
public int minMeetingRooms(int[][] intervals) {
    int n = intervals.length;
    int[][] events = new int[2 * n][2];

    // ① 事件化：开始 +1，结束 -1
    for (int i = 0; i < n; i++) {
        events[2 * i] = new int[]{intervals[i][0], 1};
        events[2 * i + 1] = new int[]{intervals[i][1], -1};
    }

    // ② 排序（先按坐标，再按类型）
    Arrays.sort(events, (a, b) ->
        a[0] != b[0] ? a[0] - b[0] : a[1] - b[1]);
    // ⚠️ 同坐标：结束(-1) 先于 开始(+1)
    // （[l,r] 与 [r,x] 不重叠 → 先释放再占用）

    // ③ 扫描维护当前占用数
    int rooms = 0, maxRooms = 0;
    for (int[] e : events) {
        rooms += e[1];               // 占用 +1 或释放 -1
        maxRooms = Math.max(maxRooms, rooms);
    }
    return maxRooms;
}
// 推演 [[0,30],[5,10],[15,20]]：
// 事件：(0,+1),(5,+1),(10,-1),(15,+1),(20,-1),(30,-1)
// 扫描：1,2,1,2,1,0 → max=2 ✓
```

### 2.2 218. 天际线问题（高度扫描线）

```java
/**
 * LeetCode 218. 天际线问题（Hard）
 * 建筑 [left, right, height] → 输出天际线关键点
 */
public List<List<Integer>> getSkyline(int[][] buildings) {
    // ① 事件化：开始 -h（负标记），结束 +h
    List<int[]> events = new ArrayList<>();
    for (int[] b : buildings) {
        events.add(new int[]{b[0], -b[2]});    // 开始（负）
        events.add(new int[]{b[1], b[2]});     // 结束（正）
    }
    // ② 排序：坐标升序；同坐标开始(-)先（高度大的先）
    events.sort((a, b) -> a[0] != b[0] ? a[0] - b[0]
                          : a[1] - b[1]);

    // ③ TreeMap 维护"当前高度 → 数量"（多建筑同高）
    TreeMap<Integer, Integer> heights = new TreeMap<>();
    heights.put(0, 1);                         // 地面
    List<List<Integer>> result = new ArrayList<>();
    int prevMax = 0;

    for (int[] e : events) {
        int h = Math.abs(e[1]);
        if (e[1] < 0) {                        // 开始：加入高度
            heights.merge(h, 1, Integer::sum);
        } else {                               // 结束：移除高度
            heights.merge(h, -1, Integer::sum);
            if (heights.get(h) == 0) heights.remove(h);
        }

        int curMax = heights.lastKey();        // 当前最高
        if (curMax != prevMax) {               // ⚠️ 最高变化才输出
            result.add(List.of(e[0], curMax));
            prevMax = curMax;
        }
    }
    return result;
}
// O(n log n)：排序 + TreeMap 操作
// ⚠️ 两个细节：
//   ① 同高度多建筑 → TreeMap 计数（不能直接删）
//   ② 最高变化才输出（不是每事件都输出）
```

### 2.3 1109. 航班预订统计（差分数组）

```java
/**
 * LeetCode 1109. 航班预订统计（差分数组 = 扫描线简化）
 * bookings[i] = [first, last, seats] → 每航班累计预订数
 */
public int[] corpFlightBookings(int[][] bookings, int n) {
    int[] diff = new int[n + 2];               // ⚠️ 多一位

    for (int[] b : bookings) {
        diff[b[0]] += b[2];                    // 开始 +seats
        diff[b[1] + 1] -= b[2];                // 结束下一位 -seats
    }

    // 前缀和还原
    int[] result = new int[n];
    int cur = 0;
    for (int i = 0; i < n; i++) {
        cur += diff[i + 1];                    // ⚠️ 1-indexed
        result[i] = cur;
    }
    return result;
}
// O(n + k)：k 次 O(1) 更新 + 一次还原
```

## 3. 事件排序的细节

### 3.1 同坐标的处理规则

```
⚠️ 关键问题：坐标相同时先处理谁？
  [l, r] 与 [r, x]：
  若端点相撞算"不重叠" → 结束(-1) 先于 开始(+1)
  若相撞算"重叠" → 开始先于结束

253 会议室：会议 [l,r] 与 [r,x] 不重叠（同人可连开）
  → 结束先处理（先释放再占用）

⚠️ 面试必答：
"同坐标时先处理结束事件——保证
 相邻区间不重叠（先释放再占用）。"
```

### 3.2 天际线的排序细节

```
218 天际线：
  同坐标：开始事件（负高度）先于结束（正）
  → 高的先处理（保证同 x 取最高）

  例：x=5 同时有建筑开始和结束
  先处理开始 → 高度先升 → 输出正确

⚠️ 与 253 的差异：
  253：结束先（同坐标）
  218：开始先（同坐标）
  → 按题目语义决定（面试别搞混）
```

### 3.3 排序稳定性

```
事件排序注意：
  ① 坐标相同 → 按类型（+1/-1 或正负号）
  ② 类型相同 → 顺序无关（状态结果相同）
  ③ 用 Integer.compare 防溢出

⚠️ 常见错误：
  只按坐标排序 → 同坐标顺序随机 → 结果依赖输入顺序
```

## 4. 扫描线 vs 差分数组

### 4.1 对比表

| 维度 | 扫描线 | 差分数组 |
|------|:---:|:---:|
| 事件 | (坐标, 类型) | diff[l] += v |
| 适用 | 重叠状态/高度 | 区间统一增减 |
| 统计 | 扫描中取最值 | 前缀和还原 |
| 扩展 | 可携带高度等 | 只有 ±v |

```
关系：差分 = 扫描线的简化（事件只有 ±v）
  扫描线可携带更多信息（高度/类型）
  差分只记录"增减量"

选型：
  "区间增减 + 最终数组" → 差分（更简单）
  "重叠状态 + 实时最值" → 扫描线
```

### 4.2 扫描线的三维扩展

```
二维扫描线（850 矩形面积并集）：
  ① 按 x 坐标事件化（矩形左/右边）
  ② 每两个相邻 x 之间：y 区间合并（一维）
  ③ 面积 = 宽度 × 合并后的 y 覆盖长度

复杂度：O(n²)（每对 x 做一次 y 合并）
⚠️ 竞赛级；面试了解思路即可
```

### 4.3 扫描线的时间线应用

```
① 日程冲突检测（729）：TreeMap + floor/ceiling
② 时间区间最大重叠：事件 ±1（253）
③ 进程调度可视化：同 253
④ 飞行计划/订票统计：差分（1109）

⚠️ 面试表达：
"区间统计问题我转化为事件序列——
 开始 +1 结束 -1，排序后扫描维护状态，
 最大值就是答案。O(n log n)（排序主导）。"
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"会议室统计用扫描线：开始事件 +1、结束事件 -1，
 排序后线性扫描维护当前占用数，最大值就是
 最少会议室。
 关键细节：同坐标时结束先处理（保证相邻区间
 不重叠——先释放再占用）。
 O(n log n)。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 结束事件为什么先处理？ | [l,r] 与 [r,x] 不重叠 → 先释放再占用 |
| 2 | 什么时候用扫描线？ | 大量区间重叠/覆盖统计 |
| 3 | 与差分数组关系？ | 差分为扫描线简化（事件 ±v） |
| 4 | 天际线两个细节？ | 高度变化才输出 + TreeMap 计数（同高多建筑） |
| 5 | 复杂度？ | O(n log n)（排序主导） |
| 6 | 二维扫描线？ | 按 x 事件化 + 每对 x 做 y 合并（竞赛级） |
| 7 | 事件排序注意？ | 坐标 + 类型双关键字；Integer.compare 防溢出 |
| 8 | 与贪心区间区别？ | 贪心逐个选；扫描线事件化统一处理 |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 同坐标顺序错 | 重叠判定反 | 结束先（253）/开始先（218） |
| 忘 TreeMap 计数 | 同高建筑错删 | merge + 归零删 |
| 天际线每事件输出 | 多余关键点 | 高度变化才输出 |
| 差分忘 +1 位 | 越界 | diff[n+1] |
| 比较器溢出 | 排序错 | Integer.compare |

> 🎯 **核心要点**：扫描线 = **事件化 + 排序 + 状态维护**三步。识别信号："重叠数、天际线、覆盖统计"。253（±1 计数）与 218（高度 TreeMap）是两个模板；事件排序细节（结束先/开始先）是失分点；与差分数组的关系是必答对比。
