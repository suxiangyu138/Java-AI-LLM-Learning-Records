## 1. lowbit 的数学原理

### 1.1 lowbit 定义

```
lowbit(x) = x & (-x) = x 二进制中"最低位的 1"对应的值

例：lowbit(6) = 6 & (-6)
  6  = 0110
  -6 = 1010（补码 = 取反 + 1）
  &  = 0010 = 2 ✓（最低位 1 在第 2 位）

⚠️ 直觉：-x 的补码 = 取反 + 1
  → x 与 -x 只在"最低位 1"处都是 1
  → x & (-x) 恰好提取最低位 1

⚠️ 面试必答：
"lowbit(x) = x & (-x)——补码的性质保证
 它恰好是 x 最低位 1 的权值。
 这是树状数组索引跳转的基础。"
```

### 1.2 lowbit 的几何意义

```
树状数组的树结构：
  c[i] 管辖 [i - lowbit(i) + 1, i] 区间
  节点 i 的父亲 = i + lowbit(i)

例（8 个元素）：
  c[1] → [1,1]；c[2] → [1,2]；c[3] → [3,3]；c[4] → [1,4]
  c[5] → [5,5]；c[6] → [5,6]；c[7] → [7,7]；c[8] → [1,8]

⚠️ 规律：
  i 是 2 的幂 → 管辖 [1, i]（前缀全量）
  i 是奇数 → 管辖 [i, i]（单点）

⚠️ 面试表达：
"c[i] 管辖的长度 = lowbit(i)——
 树状数组用 lowbit 把前缀和拆成
 O(log n) 段，update 与 query 都是
 二进制路径上的 O(log n) 跳转。"
```

## 2. update 与 query 的二进制推导

### 2.1 update 的路径

```
update(i, delta)：更新 a[i]，所有管辖 i 的 c[j] 都要改
  路径：i → i + lowbit(i) → i + lowbit(...) → ... ≤ n

例：update(3, +5)（n=8）：
  3 → 4 → 8（3+1=4, 4+4=8）
  修改 c[3]、c[4]、c[8]（管辖 3 的节点）✓

⚠️ 为什么：c[j] 管辖 [j-lowbit(j)+1, j]
  j 管辖 i ⟺ i ∈ [j-lowbit(j)+1, j]
  等价于 j 的二进制是 i 的"前缀 + 进位" → i + lowbit(i) 链
```

### 2.2 query 的路径

```
query(i)：求前缀和 a[1..i]
  路径：i → i - lowbit(i) → ... → 0（累加 c[j]）

例：query(7)（n=8）：
  7 → 6 → 4 → 0：c[7] + c[6] + c[4]
  c[7]=[7,7], c[6]=[5,6], c[4]=[1,4] → 覆盖 [1,7] ✓

⚠️ 区间查询 [l, r] = query(r) - query(l-1)
```

### 2.3 完整模板（逐行注释）

```java
/** 树状数组（1-indexed，大小 n） */
class BIT {
    private final int[] tree;

    BIT(int n) { tree = new int[n + 1]; }

    /** 单点更新：a[i] += delta（路径 i → i+lowbit → ...） */
    void update(int i, int delta) {
        while (i < tree.length) {
            tree[i] += delta;
            i += i & (-i);               // ⚠️ i + lowbit(i)：找父亲
        }
    }

    /** 前缀查询：sum(a[1..i])（路径 i → i-lowbit → ...） */
    int query(int i) {
        int sum = 0;
        while (i > 0) {
            sum += tree[i];
            i -= i & (-i);               // ⚠️ i - lowbit(i)：找左兄弟
        }
        return sum;
    }

    /** 区间查询 [l, r] */
    int rangeQuery(int l, int r) {
        return query(r) - query(l - 1);
    }
}
// ⚠️ 复杂度：update/query 均 O(log n)
// ⚠️ 核心记忆："更新向上（+lowbit），查询向左（-lowbit）"
```

## 3. 树状数组的变体

### 3.1 变体矩阵

| 变体 | 功能 | 实现要点 |
|------|------|---------|
| 单点改 + 区间查 | 标准 BIT | 基础模板 |
| 区间改 + 单点查 | 差分 BIT | update(l,+v), update(r+1,-v) |
| 区间改 + 区间查 | 双 BIT | 两个 BIT 维护差分与 i×差分 |
| 二维 BIT | 矩阵区域和 | 双层循环 update/query |
| 求第 K 小 | 值域 BIT + 二分 | 前缀和二分定位 |

```
⚠️ 区间改 + 单点查（差分思路）：
  a[i] 的修改 → 差分数组 diff 的单点操作
  → BIT 维护 diff：区间 [l,r]+v = update(l,+v); update(r+1,-v)
  → 单点值 = query(i)（diff 前缀和）

⚠️ 区间改 + 区间查（双 BIT 推导）：
  Σa[i] = ΣΣdiff[j] = (r+1)·Σdiff - Σ(j·diff)
  → 两个 BIT：一个维护 diff、一个维护 i×diff

⚠️ 面试表达：
"树状数组四种组合由'维护对象'决定——
 单点场景维护原数组，区间场景维护差分数组。"
```

### 3.2 求第 K 小（值域 BIT + 二分）

```java
/** 值域 BIT 求第 K 小（离散化后） */
int kth(int k, BIT bit, int size) {
    int lo = 1, hi = size;
    while (lo < hi) {
        int mid = (lo + hi) / 2;
        if (bit.query(mid) >= k) hi = mid;    // ⚠️ 前缀计数二分
        else lo = mid + 1;
    }
    return lo;
}
// 应用：动态集合的第 K 小/中位数（在线插入）
// 复杂度：O(log²n)（二分 × BIT 查询）
```

## 4. 离散化：值域压缩

### 4.1 为什么需要

```
树状数组要求"下标 = 值"（1..n）：
  值域 10⁹ → 数组不可能开
  但不同值只有 10⁵ 个 → 压缩到 1..m

⚠️ 离散化三步：
  ① 收集所有出现的值
  ② 排序 + 去重
  ③ 值 → 排名（二分映射）
```

### 4.2 完整实现

```java
/** 离散化：值 → 排名（1 基） */
int[] discretize(int[] nums) {
    int[] sorted = nums.clone();
    Arrays.sort(sorted);

    // 去重
    int m = 1;
    for (int i = 1; i < sorted.length; i++)
        if (sorted[i] != sorted[m - 1]) sorted[m++] = sorted[i];

    // 每个原值 → 排名
    int[] rank = new int[nums.length];
    for (int i = 0; i < nums.length; i++)
        rank[i] = Arrays.binarySearch(sorted, 0, m, nums[i]) + 1;
    return rank;
}
// ⚠️ 应用：逆序对（BIT 计数）、315/493/327（值域压缩）
// ⚠️ 复杂度：O(n log n)（排序主导），之后 BIT 操作 O(log m)
// ⚠️ 面试必答：
//   "值域大 → 离散化压缩到不同值个数——
//    逆序对类问题的标准前处理。"
```

## 5. BIT vs 线段树 vs 归并

### 5.1 三方案对比

| 维度 | 树状数组 | 线段树 | 归并排序 |
|------|:---:|:---:|:---:|
| 单点改/区间查 | O(log n) | O(log n) | ❌ 不支持 |
| 区间改/区间查 | O(log n)（双 BIT） | O(log n)（懒标记） | ❌ |
| 代码量 | ★ 最简 | ★★★ 复杂 | ★★ |
| 空间 | O(n) | O(4n) | O(n) |
| 最值查询 | ❌ 只支持可逆运算 | ✅ | ❌ |
| 统计配对（逆序对） | ✅ | ✅ | ✅ |

```
⚠️ 选型：
  求和/计数类 → BIT（代码最短）
  最值/区间覆盖 → 线段树（功能全）
  纯离线统计 → 归并（无需额外结构）

⚠️ 面试必答：
"BIT 只支持'可逆运算'（求和/异或/计数）；
 最值不可逆 → 线段树。
 逆序对三解：归并 O(n log n)、
 BIT 离散化 O(n log n)、线段树同。"
```

### 5.2 逆序对三解对比（同一题）

| 解法 | 思想 | 复杂度 | 代码 |
|------|------|:---:|:---:|
| 归并 | 合并时计数 | O(n log n) | 中 |
| BIT | 值域计数 + 前缀和 | O(n log n) | 短 |
| 线段树 | 区间计数 | O(n log n) | 长 |

```
⚠️ 面试表达：
"逆序对是数据结构三解的经典题——
 归并（合并计数）、BIT（值域前缀和）、
 线段树（区间计数）。BIT 代码最短，
 归并无需离散化。"
```

## 6. BIT 的工程应用

### 6.1 真实场景

| 场景 | BIT 的角色 |
|------|-----------|
| 动态排名/分位数 | 值域 BIT 求第 K 小 |
| 在线频次统计 | 值 → BIT 计数 |
| 逆序对/相似度 | 离线统计 |
| 二维统计 | 二维 BIT（稀疏用 Map 行） |
| 前缀异或 | BIT 存异或（可逆运算） |

```
⚠️ 工程局限：
  BIT 是"离线友好"结构（值域需预知 → 离散化）
  在线动态值域 → 平衡树/跳表

⚠️ 面试表达：
"BIT 的工程定位：值域已知的计数/求和
 ——离散化后 O(log n) 一切操作。"
```

## 7. 面试要点与追问

### 7.1 面试话术模板

```
"树状数组 = lowbit 分治的前缀结构：
 c[i] 管辖 [i-lowbit(i)+1, i]，
 更新向上（i+lowbit）、查询向左（i-lowbit），
 均 O(log n)。只支持可逆运算（求和/计数）。
 值域大先离散化。对比：求和 BIT 最简、
 最值线段树、离线统计归并。"
```

### 7.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | lowbit 是什么？ | x & (-x)，最低位 1 的权值 |
| 2 | c[i] 管辖范围？ | [i-lowbit(i)+1, i] |
| 3 | update 路径？ | i → i+lowbit → ...（向上） |
| 4 | query 路径？ | i → i-lowbit → ...（向左） |
| 5 | 支持什么运算？ | 可逆（和/异或/计数），不支持最值 |
| 6 | 值域大怎么办？ | 离散化压缩 |
| 7 | 区间修改？ | 差分 BIT / 双 BIT |
| 8 | vs 线段树？ | 求和 BIT 简；最值线段树 |

### 7.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 0-indexed 使用 | 死循环 | 1 基 |
| 忘离散化 | 数组爆炸 | 排名压缩 |
| 区间查询忘 l-1 | 边界错 | query(r)-query(l-1) |
| 最值用 BIT | 结果错 | 线段树 |
| update 循环条件错 | 越界/漏改 | i < n+1 |
