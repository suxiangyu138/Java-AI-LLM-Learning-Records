## 1. 699. 掉落的方块（懒标记区间最值）

### 1.1 题目与思路

```
方块依次掉落（有宽度有高度），记录每次掉落后堆叠的最大高度
区间更新 + 区间最值查询：
  方块 [left, right] 落高 h → 该区间当前最大高度 + h
⚠️ 需要：区间查询最大值 + 区间赋值（当前最大 + h）→ 懒标记线段树
⚠️ 坐标离散化（方块位置可能稀疏）
```

### 1.2 完整代码（离散化 + 线段树）

```java
/**
 * LeetCode 699. 掉落的方块
 * ⚠️ 简化版：离散化 + 每块暴力更新（n ≤ 1000 可行）
 *   完整线段树版（懒标记）展示思路
 */
public List<Integer> fallingSquares(int[][] positions) {
    int n = positions.length;
    // ① 坐标离散化（方块左右端点）
    List<Integer> coords = new ArrayList<>();
    for (int[] p : positions) {
        coords.add(p[0]);
        coords.add(p[0] + p[1] - 1);         // ⚠️ 右端点（闭区间）
    }
    Collections.sort(coords);
    // 去重
    List<Integer> uniq = new ArrayList<>();
    for (int c : coords)
        if (uniq.isEmpty() || uniq.get(uniq.size() - 1) != c) uniq.add(c);
    int m = uniq.size();

    // ② 线段树（区间最值 + 懒标记）
    // 简化：m ≤ 2000 时直接暴力也可；此处用数组模拟
    int[] height = new int[m];

    List<Integer> result = new ArrayList<>();
    int maxAll = 0;
    for (int[] p : positions) {
        // ③ 定位离散化下标（二分）
        int l = Collections.binarySearch(uniq, p[0]);
        int r = Collections.binarySearch(uniq, p[0] + p[1] - 1);

        // ④ 查询区间当前最大高度
        int curMax = 0;
        for (int i = l; i <= r; i++) curMax = Math.max(curMax, height[i]);

        // ⑤ 区间更新：全部变为 curMax + h
        for (int i = l; i <= r; i++) height[i] = curMax + p[1];

        maxAll = Math.max(maxAll, curMax + p[1]);
        result.add(maxAll);
    }
    return result;
}
// 推演 [[1,2],[2,3],[6,1]]：
//   块 1：区间 [1,2] 高度 2 → 最大 2
//   块 2：区间 [2,3] 当前最大 2 → 高度 5 → 最大 5
//   块 3：[6,6] 高度 1 → 最大 5
//   结果 [2,5,5] ✓
// ⚠️ 面试必答："699 = 区间最值 + 区间更新——
//   离散化坐标后线段树/暴力均可（n 小暴力过）；
//   面试讲清'区间查询 + 区间赋值'的线段树语义。"
```

## 2. 307. 区域和检索（线段树版）

### 2.1 题目与思路

```
单点修改 + 区间查询（线段树标准应用）
⚠️ 对比：树状数组版见树状数组/02——同题双解
```

### 2.2 完整代码（线段树）

```java
/**
 * LeetCode 307. 区域和检索（线段树版）
 */
class NumArray {
    private final int[] tree;
    private final int n;

    public NumArray(int[] nums) {
        n = nums.length;
        tree = new int[4 * n];
        build(nums, 1, 0, n - 1);
    }

    private void build(int[] nums, int node, int l, int r) {
        if (l == r) { tree[node] = nums[l]; return; }
        int mid = (l + r) / 2;
        build(nums, node * 2, l, mid);
        build(nums, node * 2 + 1, mid + 1, r);
        tree[node] = tree[node * 2] + tree[node * 2 + 1];
    }

    public void update(int index, int val) {
        update(1, 0, n - 1, index, val);
    }

    private void update(int node, int l, int r, int idx, int val) {
        if (l == r) { tree[node] = val; return; }
        int mid = (l + r) / 2;
        if (idx <= mid) update(node * 2, l, mid, idx, val);
        else update(node * 2 + 1, mid + 1, r, idx, val);
        tree[node] = tree[node * 2] + tree[node * 2 + 1];   // ⚠️ 回溯合并
    }

    public int sumRange(int left, int right) {
        return query(1, 0, n - 1, left, right);
    }

    private int query(int node, int l, int r, int ql, int qr) {
        if (ql <= l && r <= qr) return tree[node];   // ⚠️ 完全覆盖
        int mid = (l + r) / 2;
        int sum = 0;
        if (ql <= mid) sum += query(node * 2, l, mid, ql, qr);
        if (qr > mid) sum += query(node * 2 + 1, mid + 1, r, ql, qr);
        return sum;
    }
}
// ⚠️ 复杂度：update/sumRange O(log n)
// ⚠️ 面试必答："307 线段树版 = 建/更/查三模板——
//   与树状数组版（树状数组/02）同复杂度，
//   线段树代码更长但可扩展区间更新。"
```

## 3. 315. 右侧更小元素（离散化 + 线段树）

### 3.1 题目与思路

```
每个元素右侧更小值的个数（三解：归并/树状数组/线段树）
线段树版：
  离散化值域 → 从右往左扫描
  查询"已见过且更小"的计数（区间 [1, rank-1] 求和）
  更新：rank 位置 +1（标记出现）
⚠️ 完整推导见分治/04（归并版）与树状数组/02（BIT 版）
```

### 3.2 完整代码

```java
/**
 * LeetCode 315. 右侧更小元素（离散化 + 线段树）
 */
public List<Integer> countSmaller(int[] nums) {
    int n = nums.length;
    // ① 离散化（值域压缩）
    int[] sorted = nums.clone();
    Arrays.sort(sorted);
    int m = 1;
    for (int i = 1; i < n; i++)
        if (sorted[i] != sorted[m - 1]) sorted[m++] = sorted[i];

    // ② 线段树（值域计数）
    SegmentTree st = new SegmentTree(m);

    Integer[] result = new Integer[n];
    for (int i = n - 1; i >= 0; i--) {           // ⚠️ 从右往左扫描
        int rank = Arrays.binarySearch(sorted, 0, m, nums[i]) + 1;
        result[i] = st.query(1, 0, m - 1, 0, rank - 1);  // 已见且更小
        st.update(1, 0, m - 1, rank - 1, 1);     // 标记当前（计数 +1）
    }
    return Arrays.asList(result);
}
// ⚠️ 线段树叶子存"该值出现的次数"，区间查询 = 前缀计数
// ⚠️ 复杂度：O(n log n)
// ⚠️ 面试必答："315 线段树版 = 值域计数——
//   从右往左扫描，查'更小'即区间 [1, rank-1] 的
//   计数和；与归并版/树状数组版三解同复杂度。"
```

## 4. 线段树应用方法论

### 4.1 解题框架

```
① 识别：区间查询/更新 → 线段树候选
② 选形态：
   区间更新 + 区间查 → 懒标记
   单点改 + 区间查 → 基础三模板
   值域计数 → 离散化 + 计数线段树
   大值域 → 动态开点
③ 节点设计：可合并信息（和/最值/4 元组）
④ 选型检查：有没有更简单的工具？

⚠️ 识别信号：
  "区间更新" → 线段树独门
  "区间最值 + 修改" → 线段树/懒标记
  "可修改区间查询" → 线段树/树状数组
```

### 4.2 模板速查表

| 题型 | 线段树形态 | 代表题 |
|------|-----------|--------|
| 区间更新+最值 | 懒标记 | 699 |
| 单点改+区间和 | 基础三模板 | 307 |
| 值域计数 | 离散化 | 315、327、493 |
| 大值域 | 动态开点 | 值域 1e9 类 |

### 4.3 自测清单

```
□ 4n 空间？
□ 查询完全覆盖判断？
□ 懒标记下推/回溯？
□ 离散化（含区间边界）？
□ 合并公式正确？
□ 与树状数组选型说明？
□ 复杂度 O(log n)？
```

> 🎯 **核心要点**：线段树题 = **形态识别**（懒标记/单点/计数/动态开点）+ **节点设计**（可合并信息）+ **选型论证**（vs 树状数组/平衡树）。三题覆盖主要形态：区间更新（699）、单点查询（307）、值域计数（315）——"先问有没有更简单工具"是选型第一步。
