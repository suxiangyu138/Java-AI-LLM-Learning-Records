## 1. 251. 展开二维向量

### 1.1 题目与思路

```
vec2d = [[1,2],[3],[4,5,6]] → next() 依次返回 1,2,3,4,5,6

设计选择：
  方案 A（推荐）：行迭代器 + 列下标 —— 惰性，空间 O(1)
  方案 B：构造时全量扁平化 —— 简单但空间 O(n)
⚠️ 面试先给 A，被问"如果行数很多呢" → 强化惰性论证
```

### 1.2 完整代码

```java
/**
 * LeetCode 251. 展开二维向量
 * 状态：当前行迭代器 + 预取的下一个值
 * ⚠️ 惰性：只推进到"下一个非空行"，空行直接跳过
 */
class Vector2D implements Iterator<Integer> {
    private final Iterator<List<Integer>> rowIter;   // 行迭代器
    private Iterator<Integer> colIter = null;        // 列迭代器（当前行）
    private Integer nextVal;                         // 预取缓存

    public Vector2D(List<List<Integer>> vec2d) {
        rowIter = vec2d.iterator();
    }

    @Override public Integer next() {
        if (!hasNext()) throw new NoSuchElementException();
        Integer v = nextVal;
        nextVal = null;                    // ⚠️ 取走缓存
        return v;
    }

    @Override public boolean hasNext() {
        if (nextVal != null) return true;  // 缓存有效
        // ⚠️ 惰性推进：跳过空行
        while (rowIter.hasNext()) {
            if (colIter == null || !colIter.hasNext())
                colIter = rowIter.next().iterator();
            if (colIter.hasNext()) {
                nextVal = colIter.next();  // 找到下一个元素
                return true;
            }
        }
        return false;
    }
}
// 推演 [[1,2],[3],[4,5,6]]：
//   hasNext → 行0 有元素 → 缓存 1
//   next → 1；hasNext → 缓存 2 → next → 2
//   行0 耗尽 → 行1 [3] → 3；行2 [4,5,6] → 4,5,6 ✓
// ⚠️ 注意：next() 和 hasNext() 都走"预取"这一条路径 → 状态一致
```

> 🎯 **变体**：若允许多线程轮询，hasNext 的"缓存判断"需加锁或 volatile——面试可提一句展示并发意识。

## 2. 281. 锯齿迭代器

### 2.1 题目与思路

```
两个 List 交替输出：v1=[1,2], v2=[3,4,5] → 1,3,2,4,5

状态：两个迭代器 + 轮转标志
⚠️ 经典坑：某迭代器先耗尽时，不能停在空迭代器上干等
   → 每次 next 后检查并切换
```

### 2.2 完整代码

```java
/**
 * LeetCode 281. 锯齿迭代器（经典两迭代器版）
 * ⚠️ 交替规则：轮流取，但"自己空了就轮到对方"（不空转）
 */
class ZigzagIterator implements Iterator<Integer> {
    private final Iterator<Integer> it1;
    private final Iterator<Integer> it2;
    private boolean pickFirst = true;          // 轮到谁（状态标志）

    public ZigzagIterator(List<Integer> v1, List<Integer> v2) {
        this.it1 = v1.iterator();
        this.it2 = v2.iterator();
    }

    @Override public boolean hasNext() {
        // ⚠️ 核心：优先检查"轮到的"，空了再检查另一个
        if (pickFirst) return it1.hasNext() || it2.hasNext();
        else           return it2.hasNext() || it1.hasNext();
    }

    @Override public Integer next() {
        if (!hasNext()) throw new NoSuchElementException();
        Iterator<Integer> chosen;
        if (pickFirst) {
            chosen = it1.hasNext() ? it1 : it2;   // ⚠️ 自己空 → 取对方
        } else {
            chosen = it2.hasNext() ? it2 : it1;
        }
        pickFirst = !pickFirst;                   // 切换轮转
        return chosen.next();
    }
}
// 推演 v1=[1,2], v2=[3,4,5]：
//   next(1→it1) → 1；next(2→it2) → 3；next(1→it1) → 2
//   next(2→it2) → 4；it2 先空吗？不——next(1→it1 空→it2) → 5 ✓
//   输出 1,3,2,4,5 ✓
```

> 🎯 **k 个迭代器版本**：把"两个 + 布尔"推广为"列表 + 轮转下标"，见 [01-迭代器进阶](01-迭代器进阶：惰性设计与多迭代器协同.md) 第 5 节。

## 3. 900. RLE 迭代器

### 3.1 题目与思路

```
编码数组 [count, value, count, value, ...]：如 [3,8,0,9,2,5] = [8,8,8,5,5]
next(n)：跳过 n 个元素，返回"最后跳过的值"；越界返回 -1

⚠️ 此题陷阱：next(n) 一次可能跨多个 count 段
   → 状态 = 当前段下标 + 段内剩余计数
```

### 3.2 完整代码

```java
/**
 * LeetCode 900. RLE 迭代器
 * 状态：(idx, remain) —— 当前 value 下标 + 该段剩余个数
 */
class RLEIterator {
    private final int[] encoding;
    private int idx;          // 当前段的 value 下标（encoding 中偶数位）
    private int remain;       // 当前段剩余数量

    public RLEIterator(int[] encoding) {
        this.encoding = encoding;
        this.idx = 0;
        this.remain = 0;      // 初始：未进入任何段
    }

    public int next(int n) {
        while (n > 0) {
            if (idx >= encoding.length) return -1;      // ⚠️ 耗尽
            if (remain == 0) {                          // 进入下一段
                remain = encoding[idx];
                idx += 2;                               // 指向 value 的位置？——
                // 修正：remain 是计数，当前 value 是 encoding[idx-1]
                if (remain == 0) { idx--; idx++; continue; }  // 0 计数段跳过
            }
            int take = Math.min(n, remain);             // 本段最多吃 take 个
            remain -= take;
            n -= take;
            if (n == 0) return encoding[idx - 1];       // ⚠️ 最后跳过的值
        }
        return -1;
    }
}
```

```java
// ⭐ 更清晰的标准写法（推荐）：
class RLEIterator2 {
    private final int[] e;
    private int i = 0;            // 指向 [count, value] 段的 count 位置

    public RLEIterator2(int[] encoding) { this.e = encoding; }

    public int next(int n) {
        while (i < e.length) {
            if (e[i] == 0) {            // 计数 0 的段直接跳过
                i += 2;
                continue;
            }
            if (n <= e[i]) {            // 本段足够
                e[i] -= n;              // ⚠️ 直接扣减（原地修改 count）
                return e[i + 1];
            }
            n -= e[i];                  // 本段不够 → 吃掉整段
            i += 2;
        }
        return -1;                      // 全部耗尽
    }
}
// 推演 [3,8,0,9,2,5]：
//   next(2)：段0 count=3 ≥ 2 → count=1，返回 8 ✓
//   next(1)：count=1 ≥ 1 → count=0，返回 8 ✓
//   next(2)：count=0 跳过；段2 count=2 ≥ 2 → 返回 5 ✓
//   next(1)：段4 count=2 → count=1 返回 5；next(1) → 返回 5；next(1) → -1 ✓
```

> 🎯 **要点**：RLE 迭代器 = 计数型游标。`原地扣减 count` 比维护额外 remain 字段更简洁；跳过 0 计数段是必写的防御。

## 4. 1305. 两棵二叉搜索树中的所有元素

### 4.1 题目与思路

```
两棵 BST → 返回所有元素升序列表
方案对比：
  方案 A（推荐）：两个中序迭代器 + 归并 —— 空间 O(h1+h2)
  方案 B：中序收集两个列表再归并 —— 空间 O(n)
⚠️ 此题价值：把 [173 BST 迭代器](00-迭代器专题精要.md) 与归并模板组合应用
```

### 4.2 完整代码

```java
/**
 * LeetCode 1305. 两棵二叉搜索树中的所有元素
 * BST 迭代器（173 模板）+ 两路归并（01 第 5 节模板）
 */
public List<Integer> getAllElements(TreeNode root1, TreeNode root2) {
    BSTIter it1 = new BSTIter(root1);
    BSTIter it2 = new BSTIter(root2);
    List<Integer> res = new ArrayList<>();

    Integer v1 = it1.hasNext() ? it1.next() : null;   // 各取首元素
    Integer v2 = it2.hasNext() ? it2.next() : null;

    while (v1 != null || v2 != null) {                // ⭐ 归并模板
        if (v2 == null || (v1 != null && v1 <= v2)) {
            res.add(v1);
            v1 = it1.hasNext() ? it1.next() : null;   // 取完补位
        } else {
            res.add(v2);
            v2 = it2.hasNext() ? it2.next() : null;
        }
    }
    return res;
}

/** BST 中序迭代器（173 模板：左探-回溯-右转） */
class BSTIter {
    private final Deque<TreeNode> stack = new ArrayDeque<>();

    BSTIter(TreeNode root) {
        pushLeft(root);                               // 初始左探
    }
    int next() {
        TreeNode node = stack.pop();
        pushLeft(node.right);                         // 右转左探
        return node.val;
    }
    boolean hasNext() { return !stack.isEmpty(); }
    private void pushLeft(TreeNode node) {
        while (node != null) { stack.push(node); node = node.left; }
    }
}
// 时间 O(n1+n2)，空间 O(h1+h2)（两个栈，不存全部元素）
// ⚠️ 归并三要点回顾：先取首、取小、取完补位
```

> 🎯 **迁移**：同样的"迭代器 + 归并"可直接套 88. 合并两个有序数组、21. 合并两个有序链表——**有序迭代器归并是万用模板**。

## 5. 实战一：手写惰性管道（map/filter 装饰器）

### 5.1 思路

```
装饰器模式：map 迭代器 = 包一层原迭代器，next 时变换
  惰性：变换推迟到 next() 时刻，不是构造时
  ⚠️ 这就是 Stream.map/filter 的底层骨架（简化版）

组合：filter(map(it)) → 变换后再过滤
```

### 5.2 完整代码

```java
/** ⭐ 手写惰性 map：包装任意迭代器 */
class MapIterator<A, B> implements Iterator<B> {
    private final Iterator<A> src;
    private final Function<A, B> fn;

    MapIterator(Iterator<A> src, Function<A, B> fn) {
        this.src = src;
        this.fn = fn;
    }
    @Override public boolean hasNext() { return src.hasNext(); }
    @Override public B next() { return fn.apply(src.next()); }   // ⚠️ 惰性变换
}

/** ⭐ 手写惰性 filter：跳过不满足条件的元素 */
class FilterIterator<T> implements Iterator<T> {
    private final Iterator<T> src;
    private final Predicate<T> pred;
    private T cached;                       // 预取：下一个合格元素
    private boolean hasCached;

    FilterIterator(Iterator<T> src, Predicate<T> pred) {
        this.src = src;
        this.pred = pred;
    }

    @Override public boolean hasNext() {
        advance();                          // 惰性：推进到下一个合格者
        return hasCached;
    }

    @Override public T next() {
        if (!hasNext()) throw new NoSuchElementException();
        T v = cached;
        hasCached = false;                  // 取走
        return v;
    }

    private void advance() {
        while (!hasCached && src.hasNext()) {
            T v = src.next();
            if (pred.test(v)) { cached = v; hasCached = true; }   // 合格 → 缓存
        }
    }
}

// 使用：惰性管道（全部按需计算）
List<Integer> data = List.of(1, 2, 3, 4, 5, 6);
Iterator<Integer> pipeline = new MapIterator<>(
        new FilterIterator<>(data.iterator(), x -> x % 2 == 0),   // 偶数
        x -> x * x);                                              // 平方
while (pipeline.hasNext())
    System.out.print(pipeline.next() + " ");   // 4 16 36（惰性逐个产出）
```

> 🎯 **价值**：这段代码 = Stream 管道的微缩实现。面试说"Stream 底层是惰性管道"时，能现场写出装饰器版 = 硬核加分。

## 6. 实战二：手写 fail-fast 迭代器

### 6.1 思路

```
实现 ArrayList 风格的迭代器：
  ① 构造时快照 modCount
  ② 每次操作前校验（不匹配 → ConcurrentModificationException）
  ③ remove() 用迭代器自己的语义（同步 modCount，不触发异常）
⚠️ 展示对 JDK 内部机制的还原能力
```

### 6.2 完整代码

```java
/** 手写 fail-fast 列表迭代器（ArrayList.Itr 的教学复刻） */
class FailFastList<T> implements Iterable<T> {
    private Object[] data;
    private int size;
    private int modCount;                    // ⚠️ 结构修改计数

    public void add(T v) {
        if (size == data.length) grow();
        data[size++] = v;
        modCount++;                          // 写操作 → 计数 +1
    }

    @Override public Iterator<T> iterator() {
        return new Itr();
    }

    private class Itr implements Iterator<T> {
        private int cursor;                  // 下一个下标
        private int lastRet = -1;            // 最后返回下标（remove 用）
        private final int expectedModCount = modCount;   // ⚠️ 快照

        @Override public boolean hasNext() {
            checkForComodification();
            return cursor != size;
        }

        @Override public T next() {
            checkForComodification();
            if (cursor >= size) throw new NoSuchElementException();
            @SuppressWarnings("unchecked")
            T v = (T) data[lastRet = cursor++];     // 记录 lastRet
            return v;
        }

        @Override public void remove() {
            if (lastRet < 0) throw new IllegalStateException();  // ⚠️ 契约
            checkForComodification();
            removeAt(lastRet);               // 业务删除
            cursor = lastRet;
            lastRet = -1;                    // ⚠️ 复位
            expectedModCount = modCount;     // ⚠️ 同步快照 → 迭代器删除不 CME
        }

        private void checkForComodification() {
            if (modCount != expectedModCount)
                throw new ConcurrentModificationException();
        }
    }
}
// 验证：
//   FailFastList<Integer> l = new FailFastList<>();
//   for (int x : l) { if (x == 1) l.add(9); }   // CME ✓（外部 add 改 modCount）
//   it.next(); it.remove(); it.remove();        // IllegalStateException ✓
```

> 🎯 **关键设计**：`expectedModCount` 是 final 快照 → 外部修改必触发 CME；迭代器自己 remove 后**重新赋值快照** → 合法删除不误报。这正是 JDK 的真实逻辑。

## 7. 实战三：Range 迭代器工具类

### 7.1 思路

```
工程工具类：Range(开始, 结束, 步长) 支持 for-each
  展示 Iterable 的正确实现姿势（iterator() 返回新迭代器）
⚠️ 常见错误：把类本身实现为 Iterator（自身有状态）
   → 正确：Iterable 接口 + 内部每次返回新迭代器
```

### 7.2 完整代码

```java
/** Range 工具：for (int x : new Range(1, 10, 2)) → 1,3,5,7,9 */
class Range implements Iterable<Integer> {
    private final int start, end, step;     // [start, end) 步长 step

    Range(int start, int end, int step) {
        this.start = start; this.end = end; this.step = step;
    }

    @Override public Iterator<Integer> iterator() {
        return new RangeIter();             // ⚠️ 每次调用返回"全新"迭代器
    }

    private class RangeIter implements Iterator<Integer> {
        private int cur = start;            // 迭代器独立状态（多线程各拿各的）

        @Override public boolean hasNext() { return cur < end; }

        @Override public Integer next() {
            if (cur >= end) throw new NoSuchElementException();
            int v = cur;
            cur += step;                    // 状态推进
            return v;
        }
    }
}

// 配套：无限流 + take（惰性截断工具）
static <T> List<T> take(Iterator<T> it, int n) {
    List<T> res = new ArrayList<>();
    for (int i = 0; i < n && it.hasNext(); i++) res.add(it.next());
    return res;                             // ⚠️ 提前终止：后续元素永不计算
}
// 用法：take(new FibonacciIterator(), 10) → 前 10 个斐波那契
```

> 🎯 **工程纪律**：`Iterable`（可多次遍历）与 `Iterator`（一次性游标）是两种角色——**集合实现 Iterable，遍历实现 Iterator**，职责分离是正确姿势。

## 8. 迭代器设计方法论

### 8.1 设计四步框架

```
① 明确"遍历到哪"：状态变量
   数组 → 下标；链表 → 节点；树 → 栈；嵌套 → 迭代器栈
② 明确"下一步怎么走"：推进规则
   next 后状态如何更新（+1 / 右转左探 / 弹栈压栈）
③ 统一入口：hasNext/next 共享状态
   ⚠️ 预取模式：hasNext 惰性推进 + 缓存；next 返回缓存并复位
   （或非预取：hasNext 只判断、next 才推进——需保证语义精确）
④ 边界验证：空、耗尽、连续调用、null 元素
   画调用序列：h n h n / n n n / h h h / h n n(抛异常)
```

### 8.2 题型模板速查

| 模板 | 状态 | 惰性空间 | 代表 |
|------|------|:---:|------|
| 预取缓存 | nextVal + 标志 | O(1) | 284 |
| 栈路径 | 左路径栈 | O(h) | 173 |
| 栈嵌套 | 子迭代器栈 | O(深度) | 341 |
| 行/列推进 | 行迭代器 + 列游标 | O(1) | 251 |
| 轮转交替 | 轮转标志 + 空检查 | O(1) | 281 |
| 计数游标 | 段下标 + 剩余计数 | O(1) | 900 |
| 两路归并 | 两当前值 + 补位 | O(h1+h2) | 1305 |
| 装饰器管道 | 包装迭代器 + 变换 | O(1) | 实战一 |

### 8.3 复杂度速答

```
时间：每次 next() 的代价（预取版 hasNext 可能摊销）
  树迭代器：均摊 O(1)（每个节点进出栈一次）
  嵌套列表：均摊 O(1)（每元素推进有限次）
空间：说"O(深度)/O(1)，不是 O(n)"（惰性的核心卖点）
表达："next/hasNext 均摊 O(1)，空间 O(h)，惰性展开"
```

---

> 🎯 **核心要点**：迭代器解题四步（状态→推进→共享→边界）+ 惰性空间论（O(深度) 而非 O(总量)）+ 三大实战（装饰器管道 = Stream 骨架、fail-fast 复刻 = JDK 机制、Range = Iterable 正确姿势）。四题 + 三实战覆盖迭代器全部题型。
