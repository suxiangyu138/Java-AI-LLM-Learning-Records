# Link-Cut Tree 知识体系总览

> Link-Cut Tree（LCT）是"动态树"的标准数据结构：支持断边、连边、换根、路径查询与修改，均摊复杂度 O(log n)。它用一组 splay 维护树上的"偏好路径"，通过 access 操作把任意根到节点的路径变成一条可操作的辅助树。

## 4. 核心概念速查

| 概念 | 含义 |
|------|------|
| 原树 | 实际维护的树（动态变化） |
| 辅助树 | 每条偏好路径对应一棵 splay |
| 偏好路径 | 从某节点到根的路径中被选中的一段 |
| access(x) | 把根到 $x$ 的路径变成偏好路径 |
| makeroot(x) | 把 $x$ 变为原树的根 |
| findroot(x) | 找 $x$ 所在原树的根 |
| split(x,y) | 把 $x\to y$ 路径放到一棵 splay 中 |
| link / cut | 连边 / 断边 |
| 均摊复杂度 | 所有操作 O(log n) |
