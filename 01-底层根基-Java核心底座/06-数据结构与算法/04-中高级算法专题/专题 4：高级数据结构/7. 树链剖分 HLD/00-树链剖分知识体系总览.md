# 树链剖分（HLD）知识体系总览

> 树链剖分把一棵树拆成若干条重链，让"树上路径"变成"序列上不超过 O(log n) 段连续区间"。有了这个转换，路径查询、路径修改、子树操作都能交给线段树或树状数组处理，是树上问题从 O(n) 降到 O(log² n) 的标准手段。

## 3. 学习路线推荐

### 3.1 面试与笔试路线

```text
01 原理与 LCA
  → 02 路径查询（掌握"链上区间"的拆分方式）
```

树链剖分在普通后端面试中极少直接考，但在算法岗、竞赛、部分大厂机试中出现。掌握 LCA 与路径查询模板即可。

### 3.2 竞赛路线

```text
01 → 02 → 线段树进阶 → 动态树（LCT）→ 树上莫队
```

树链剖分是"静态树路径问题"的通用解；动态树（LCT）是它的动态版本；树上莫队是它的离线替代方案之一。

## 4. 核心概念速查

| 概念 | 含义 |
|------|------|
| 重儿子 | 子树大小最大的儿子 |
| 轻儿子 | 除重儿子外的其他儿子 |
| 重链 | 从某节点出发，一路走重儿子形成的链 |
| 链头 | 重链上深度最小的节点（top） |
| dfn | 剖分后的时间戳，重链内连续 |
| 子树区间 | `[dfn[u], dfn[u]+size[u]-1]` |
| 路径拆分段数 | O(log n) |
| 单次路径操作 | O(log² n)（线段树） |
