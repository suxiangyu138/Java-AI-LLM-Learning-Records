# 02-路径查询与子树操作模板

> 树链剖分本身只负责"把路径拆成区间"，真正的查询与修改由线段树完成。这一篇给出点权路径操作、子树操作、边权转点权三套模板，以及它们最容易写错的边界。

## 1. 整体结构

```text
原始树
  │
  ├── dfs1：size / heavy / parent / depth
  ├── dfs2：top / dfn / rev
  │
  ▼
dfn 序列（每个位置存节点权值）
  │
  ├── 线段树：区间加、区间和、区间最值
  │
  ▼
路径操作 = 若干段 dfn 区间操作
子树操作 = 一段 dfn 区间操作
```

三个数组的分工：

| 数组 | 含义 |
|------|------|
| `dfn[u]` | 节点 $u$ 在序列中的下标 |
| `rev[i]` | 序列下标 $i$ 对应的节点 |
| `top[u]` | 节点 $u$ 所在重链的链头 |

---

## 2. 建树与映射

```java
long[] base = new long[n];
for (int u = 0; u < n; u++) {
    base[dfn[u]] = weight[u];
}
SegmentTree seg = new SegmentTree(base);
```

注意 `base` 用 `long`，避免路径和溢出。节点数 $10^5$、权值 $10^9$ 时，路径和可达 $10^{14}$，必须用 `long`。

## 3. 路径查询与修改

### 3.1 点权版本

查询 $u\to v$ 路径上的点权和：

```java
public long pathQuery(int u, int v) {
    long result = 0;
    while (top[u] != top[v]) {
        if (depth[top[u]] < depth[top[v]]) {
            int temp = u;
            u = v;
            v = temp;
        }
        result += seg.query(dfn[top[u]], dfn[u]);
        u = parent[top[u]];
    }
    if (depth[u] > depth[v]) {
        int temp = u;
        u = v;
        v = temp;
    }
    result += seg.query(dfn[u], dfn[v]);
    return result;
}
```

路径修改同理，把 `query` 换成 `update`：

```java
public void pathUpdate(int u, int v, long value) {
    while (top[u] != top[v]) {
        if (depth[top[u]] < depth[top[v]]) {
            int temp = u;
            u = v;
            v = temp;
        }
        seg.update(dfn[top[u]], dfn[u], value);
        u = parent[top[u]];
    }
    if (depth[u] > depth[v]) {
        int temp = u;
        u = v;
        v = temp;
    }
    seg.update(dfn[u], dfn[v], value);
}
```

### 3.2 拆解过程示例

```text
路径 8 → 6（以 00 篇的树为例）

8: top=1, dfn=3
6: top=6, dfn=6

第 1 轮：top[8]=1，top[6]=6，深度不同
  跳 top 更深的 6 → 取区间 [dfn[6], dfn[6]] = [6,6]
  u = parent[6] = 3

第 2 轮：top[8]=1，top[3]=3，深度不同
  跳 3 → 取区间 [dfn[3], dfn[3]] = [4,4]
  u = parent[3] = 1

第 3 轮：top[8]=1，top[1]=1，同链
  取 [min(dfn[1],dfn[8]), max(...)] = [0,3]

总区间：[6,6] ∪ [4,4] ∪ [0,3]
```

### 3.3 为什么最后一段要取 min/max

同一条重链上，dfn 随深度递增。$u$ 与 $v$ 谁深谁浅不一定，所以取 `dfn` 较小到较大：

```java
if (depth[u] > depth[v]) {
    swap(u, v);
}
result += seg.query(dfn[u], dfn[v]);
```

先按深度交换，比直接 `Math.min(dfn[u],dfn[v])` 更直观，也方便边权版本排除 LCA。

## 4. 子树查询与修改

子树在 dfn 上是一段连续区间：

```java
public long subtreeQuery(int u) {
    return seg.query(dfn[u], dfn[u] + size[u] - 1);
}

public void subtreeUpdate(int u, long value) {
    seg.update(dfn[u], dfn[u] + size[u] - 1, value);
}
```

这是树链剖分相对于倍增 LCA 的额外收益：倍增只能求 LCA，剖分还能顺手支持子树操作。

## 5. 边权转点权

树上的边权需要转成点权才能用同一套模板。标准做法：

```text
把边 (u, parent[u]) 的权值存到 u 上
→ 每个节点（除根）代表它到父亲的边
→ 根节点没有边，权值设为 0
```

路径查询时，LCA 对应的点权不属于路径上的边，必须排除：

```java
public long pathQueryEdge(int u, int v) {
    long result = 0;
    while (top[u] != top[v]) {
        if (depth[top[u]] < depth[top[v]]) {
            int temp = u;
            u = v;
            v = temp;
        }
        result += seg.query(dfn[top[u]], dfn[u]);
        u = parent[top[u]];
    }
    if (depth[u] > depth[v]) {
        int temp = u;
        u = v;
        v = temp;
    }
    if (dfn[u] + 1 <= dfn[v]) {
        result += seg.query(dfn[u] + 1, dfn[v]);
    }
    return result;
}
```

关键就是最后的 `dfn[u] + 1`：

```text
点权版本：查询 [dfn[u], dfn[v]]
边权版本：查询 [dfn[u]+1, dfn[v]]（排除 LCA）

当 u == v 时，dfn[u]+1 > dfn[v]，区间为空，直接跳过
```

边权转点权的赋值时机：

```java
private void dfs1(int u, int p) {
    parent[u] = p;
    size[u] = 1;
    for (int v : graph[u]) {
        if (v == p) {
            continue;
        }
        depth[v] = depth[u] + 1;
        edgeWeight[v] = weightOfEdge(u, v);
        dfs1(v, u);
        size[u] += size[v];
        if (size[v] > maxSize) {
            maxSize = size[v];
            heavy[u] = v;
        }
    }
}
```

## 6. 完整模板

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

public class HLDTree {

    private static class SegmentTree {
        private final long[] tree;
        private final long[] lazy;
        private final int n;

        SegmentTree(long[] arr) {
            n = arr.length;
            tree = new long[4 * n];
            lazy = new long[4 * n];
            build(1, 0, n - 1, arr);
        }

        private void build(int node, int left, int right, long[] arr) {
            if (left == right) {
                tree[node] = arr[left];
                return;
            }
            int mid = (left + right) >>> 1;
            build(node << 1, left, mid, arr);
            build(node << 1 | 1, mid + 1, right, arr);
            tree[node] = tree[node << 1] + tree[node << 1 | 1];
        }

        private void apply(int node, int left, int right, long value) {
            tree[node] += value * (right - left + 1);
            lazy[node] += value;
        }

        private void pushDown(int node, int left, int right) {
            if (lazy[node] == 0 || left == right) {
                return;
            }
            int mid = (left + right) >>> 1;
            apply(node << 1, left, mid, lazy[node]);
            apply(node << 1 | 1, mid + 1, right, lazy[node]);
            lazy[node] = 0;
        }

        public void update(int queryLeft, int queryRight, long value) {
            update(1, 0, n - 1, queryLeft, queryRight, value);
        }

        private void update(int node, int left, int right,
                            int queryLeft, int queryRight, long value) {
            if (queryLeft <= left && right <= queryRight) {
                apply(node, left, right, value);
                return;
            }
            pushDown(node, left, right);
            int mid = (left + right) >>> 1;
            if (queryLeft <= mid) {
                update(node << 1, left, mid, queryLeft, queryRight, value);
            }
            if (queryRight > mid) {
                update(node << 1 | 1, mid + 1, right, queryLeft, queryRight, value);
            }
            tree[node] = tree[node << 1] + tree[node << 1 | 1];
        }

        public long query(int queryLeft, int queryRight) {
            return query(1, 0, n - 1, queryLeft, queryRight);
        }

        private long query(int node, int left, int right,
                           int queryLeft, int queryRight) {
            if (queryLeft <= left && right <= queryRight) {
                return tree[node];
            }
            pushDown(node, left, right);
            int mid = (left + right) >>> 1;
            long result = 0;
            if (queryLeft <= mid) {
                result += query(node << 1, left, mid, queryLeft, queryRight);
            }
            if (queryRight > mid) {
                result += query(node << 1 | 1, mid + 1, right, queryLeft, queryRight);
            }
            return result;
        }
    }

    private final List<Integer>[] graph;
    private final int[] parent;
    private final int[] depth;
    private final int[] size;
    private final int[] heavy;
    private final int[] top;
    private final int[] dfn;
    private final int[] rev;
    private int timer;
    private SegmentTree seg;

    @SuppressWarnings("unchecked")
    public HLDTree(int n) {
        graph = new List[n];
        for (int i = 0; i < n; i++) {
            graph[i] = new ArrayList<>();
        }
        parent = new int[n];
        depth = new int[n];
        size = new int[n];
        heavy = new int[n];
        top = new int[n];
        dfn = new int[n];
        rev = new int[n];
        Arrays.fill(heavy, -1);
    }

    public void addEdge(int u, int v) {
        graph[u].add(v);
        graph[v].add(u);
    }

    public void build(int root, long[] weight) {
        dfs1(root, -1);
        dfs2(root, root);
        long[] base = new long[weight.length];
        for (int u = 0; u < weight.length; u++) {
            base[dfn[u]] = weight[u];
        }
        seg = new SegmentTree(base);
    }

    private void dfs1(int u, int p) {
        parent[u] = p;
        size[u] = 1;
        int maxSize = 0;
        for (int v : graph[u]) {
            if (v == p) {
                continue;
            }
            depth[v] = depth[u] + 1;
            dfs1(v, u);
            size[u] += size[v];
            if (size[v] > maxSize) {
                maxSize = size[v];
                heavy[u] = v;
            }
        }
    }

    private void dfs2(int u, int head) {
        top[u] = head;
        dfn[u] = timer;
        rev[timer++] = u;
        if (heavy[u] != -1) {
            dfs2(heavy[u], head);
        }
        for (int v : graph[u]) {
            if (v == parent[u] || v == heavy[u]) {
                continue;
            }
            dfs2(v, v);
        }
    }

    public void pathUpdate(int u, int v, long value) {
        while (top[u] != top[v]) {
            if (depth[top[u]] < depth[top[v]]) {
                int temp = u;
                u = v;
                v = temp;
            }
            seg.update(dfn[top[u]], dfn[u], value);
            u = parent[top[u]];
        }
        if (depth[u] > depth[v]) {
            int temp = u;
            u = v;
            v = temp;
        }
        seg.update(dfn[u], dfn[v], value);
    }

    public long pathQuery(int u, int v) {
        long result = 0;
        while (top[u] != top[v]) {
            if (depth[top[u]] < depth[top[v]]) {
                int temp = u;
                u = v;
                v = temp;
            }
            result += seg.query(dfn[top[u]], dfn[u]);
            u = parent[top[u]];
        }
        if (depth[u] > depth[v]) {
            int temp = u;
            u = v;
            v = temp;
        }
        result += seg.query(dfn[u], dfn[v]);
        return result;
    }

    public void subtreeUpdate(int u, long value) {
        seg.update(dfn[u], dfn[u] + size[u] - 1, value);
    }

    public long subtreeQuery(int u) {
        return seg.query(dfn[u], dfn[u] + size[u] - 1);
    }

    public int lca(int u, int v) {
        while (top[u] != top[v]) {
            if (depth[top[u]] < depth[top[v]]) {
                int temp = u;
                u = v;
                v = temp;
            }
            u = parent[top[u]];
        }
        return depth[u] < depth[v] ? u : v;
    }
}
```

## 7. 例题与识别信号

### 7.1 识别信号

```text
看到以下描述，优先考虑树链剖分：
  ① 树上路径的"和/最值/第 k 大"查询
  ② 树上路径的区间修改（加、赋值）
  ③ 子树查询 + 路径查询混合
  ④ 支持换根但只影响子树范围
  ⑤ 边权转点权后仍是区间操作
```

### 7.2 经典题型

| 题型 | 做法 |
|------|------|
| 路径和 + 路径加 | 线段树维护区间和与懒标记 |
| 路径最值 + 单点改 | 线段树维护区间最值 |
| 子树和 + 子树加 | dfn 区间直接操作 |
| 路径第 k 小 | 树链剖分 + 主席树（或整体二分） |
| 动态树（断边连边） | 改用 LCT |
| 路径颜色段数 | 线段树维护左右端点颜色 + 合并 |

### 7.3 换根问题

```text
只有换根，没有断边/连边：
  不需要 LCT
  维护当前根 root
  查询子树时分类讨论：
    ① u == root：整棵树
    ② root 不在 u 的子树内：仍是 [dfn[u], dfn[u]+size[u]-1]
    ③ root 在 u 的子树内：取 u 的"包含 root 的那个儿子"的补集
```

## 8. 易错点

```text
① 路径最后一段忘记按深度交换
   → 查询区间反向，结果错误或越界

② 边权版本忘记 +1 排除 LCA
   → 多算一条边

③ 线段树懒标记没有下推
   → 区间修改后查询结果错误

④ 用 int 存路径和
   → 溢出成负数

⑤ dfn 从 0 开始但线段树从 1 开始
   → 差一位，全错

⑥ 多组数据没有重置 timer 与线段树
   → 上一组数据污染

⑦ 递归建树深度过大
   → StackOverflowError
```

> **提示**：树链剖分的代码模板很长，考试时优先保证"dfs1/dfs2/路径循环"三处的下标与边界正确，线段树部分可以背模板。

---

## 9. 小结

| 问题 | 答案 |
|------|------|
| 路径查询 | 不断跳链，累加每段区间 |
| 子树查询 | `[dfn[u], dfn[u]+size[u]-1]` |
| 边权转点权 | 边权存到深度较大的端点 |
| 边权路径查询 | 最后一段从 `dfn[u]+1` 开始 |
| 复杂度 | 单次 O(log² n) |
| 换根 | 分类讨论，不必上 LCT |
| 常见错误 | 深度交换、LCA 排除、懒标记、溢出 |
