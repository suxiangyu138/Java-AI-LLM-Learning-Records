## 1. 知识体系导图

```text
树状数组（BIT / Fenwick Tree，Peter Fenwick 1994）
│
├── 核心本质 ──────────────────────────────────────────────
│   ├── = 动态前缀和: 单点更新 + 前缀查询 O(log n)
│   ├── lowbit(x) = x & (-x): 区间划分的钥匙
│   ├── 每个节点存"一段区间和"（lowbit 长度）
│   └── 相比线段树: 代码 1/3、常数小，但功能受限
│
├── 两大操作 ──────────────────────────────────────────────
│   ├── query(x): 前缀和（x -= lowbit 向下累加）
│   ├── update(x, delta): 单点更新（x += lowbit 向上传播）
│   └── 直觉: 二进制进位/退位划分区间
│
├── 区间扩展 ──────────────────────────────────────────────
│   ├── 差分 BIT: 区间更新 + 单点查询（update(l,+k)(r+1,−k)）
│   ├── 双 BIT: 区间更新 + 区间查询
│   ├── 二维 BIT: 矩阵前缀和（竞赛）
│   └── 逆序对: BIT + 离散化（高频！）
│
├── 经典应用 ──────────────────────────────────────────────
│   ├── 逆序对统计: LCR 170（离散化 + query(rank−1)）
│   ├── 动态前缀: 在线更新的前缀和查询
│   ├── 区间统计: 值域频次 + 前缀计数
│   └── 配合二分: 第 K 小（BIT 上的二分）
│
└── 实战与面试 ────────────────────────────────────────────
    ├── 手写: 模板 2 分钟（lowbit/query/update）
    ├── 复杂度: O(log n)/操作、O(n) 空间
    ├── 与线段树: BIT 短小、线段树全能
    └── 话术: "lowbit 划分 + 二进制直觉"双段式
```

## 4. 核心概念速查

| 概念 | 一句话解释 | 说明 |
|------|-----------|------|
| **树状数组** | 动态前缀和的数据结构 | 单点更新 + 前缀查询 |
| **lowbit** | x & (−x)：最低位 1 的权值 | 区间划分的钥匙 |
| **query(x)** | 求 [1, x] 前缀和 | x -= lowbit 累加 |
| **update(x, d)** | 单点加 d | x += lowbit 传播 |
| **差分** | 区间更新转两次单点 | BIT 区间扩展 |
| **离散化** | 大值域压缩为排名 | 逆序对的前提 |
| **逆序对** | i<j 且 a[i]>a[j] | BIT 高频应用 |
| **第 K 小** | BIT 上的二分查找 | 动态排名 |

## 5. 复杂度速查表

| 操作 | 朴素 | 树状数组 | 线段树 |
|------|:---:|:---:|:---:|
| 单点更新 | O(1) | **O(log n)** | O(log n) |
| 前缀查询 | O(n) | **O(log n)** | O(log n) |
| 区间查询 | O(n) | O(log n)×2 | O(log n) |
| 区间更新 | — | O(log n)×2（差分） | O(log n)（懒标记） |
| 代码量 | — | **~20 行** | ~80 行 |
| 空间 | — | O(n) | O(4n) |

> 🎯 **一句话定位**："**树状数组 = '动态前缀和的最短实现'——O(log n) 单点更新 + 前缀查询，代码只有线段树的 1/3**。它不能做的（区间最值/懒标记），线段树补上——两者是互补而非替代。"

## 6. 常见误区速查

| 误区 | 正解 |
|------|------|
| "BIT 能求区间最值" | ❌ 只能维护可逆运算（和/异或）——最值用线段树 |
| "BIT 下标从 0 开始" | ❌ 从 1 开始（0 会死循环——lowbit(0)=0） |
| "区间更新要新结构" | ❌ 差分数组 + BIT 即可（两次单点更新） |
| "离散化是可选优化" | ❌ 大值域（10¹⁴）必须离散化——否则数组爆内存 |
| "BIT 比线段树全能" | ❌ BIT 代码短但功能受限（无懒标记/最值） |
| "逆序对只能用归并" | ❌ BIT + 离散化是等价的 O(n log n) 解法 |
| "query 是区间查询" | ❌ 是前缀查询——区间 = 两个前缀之差 |
| "update 从上往下" | ❌ 从 x 向上（x += lowbit）传播到 n |
| "负数不能 BIT" | ❌ 偏移量转换为非负即可 |
| "BIT 只能一维" | ❌ 二维/多维 BIT 存在（矩阵前缀和） |
