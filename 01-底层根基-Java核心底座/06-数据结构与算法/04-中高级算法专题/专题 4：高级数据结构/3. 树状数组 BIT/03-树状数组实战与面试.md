## 1. LCR 170 交易逆序对（离散化 + BIT）

### 1.1 题目与思路

**题**：数组逆序对总数（i<j 且 a[i]>a[j]）。

**BIT 思路**：值域频次 + 前缀计数——从后往前，每个元素统计"已出现的小于它的个数"：

```java
/**
 * LCR 170. 交易逆序对的总数（BIT + 离散化）
 * 从后往前: query(rank−1) = 后面已出现的小于 a[i] 的个数
 * 时间 O(n log n)，空间 O(n)
 */
public int reversePairs(int[] record) {
    // ① 离散化: 值 → 排名（1..n）
    int[] sorted = record.clone();
    Arrays.sort(sorted);
    int[] rank = new int[record.length];
    for (int i = 0; i < record.length; i++)
        rank[i] = Arrays.binarySearch(sorted, record[i]) + 1;

    BIT bit = new BIT(record.length);            // ② 值域频次 BIT
    int count = 0;
    for (int i = record.length - 1; i >= 0; i--) {   // ③ ⚠️ 从后往前
        count += bit.query(rank[i] - 1);         // ④ 后面小于它的个数
        bit.update(rank[i], 1);                  // ⑤ 自己入 BIT
    }
    return count;
}
// 推演 [7,5,6,4]：离散化 [4,2,3,1]
//   从后往前:
//   i=3(1): query(0)=0；update(1)
//   i=2(3): query(2)=1（4<6 ✓）；update(3)
//   i=1(2): query(1)=1（4<5 ✓）；update(2)
//   i=0(4): query(3)=3（5,6,4 < 7 ✓）
//   总 = 0+1+1+3 = 5 ✓
// ⚠️ 核心: "值域频次 + 前缀计数"——
//   query(rank−1) = 值域中小于当前值的已出现个数
```

> 🎯 **LCR 170 的必考点**："**'离散化 + 从后往前 + query(rank−1)'——BIT 求逆序对的标准三件套**。与归并排序解法等价（都是 O(n log n)），面试两解都能给 = 展示数据结构功底。"

## 2. 307 区域和检索（BIT 版）

### 2.1 题目与思路

**题**：数组支持单点更新 + 区间求和（动态前缀和的经典场景）。

**BIT 模板直接套**：

```java
/**
 * LeetCode 307. 区域和检索 - 数组可修改（BIT 版）
 * 单点更新 + 区间查询——BIT 的主场
 */
class NumArray {
    private final BIT bit;
    private final int[] nums;

    public NumArray(int[] nums) {
        this.nums = nums.clone();
        bit = new BIT(nums.length);
        for (int i = 1; i <= nums.length; i++)
            bit.update(i, nums[i - 1]);          // ① 逐个建树（O(n log n)）
    }

    public void update(int index, int val) {     // ② 单点更新
        int delta = val - nums[index];           //    差值更新
        nums[index] = val;
        bit.update(index + 1, delta);
    }

    public int sumRange(int left, int right) {   // ③ 区间查询
        return bit.query(right + 1) - bit.query(left);   // 两前缀之差
    }
}
// 推演 [1,3,5] → sumRange(0,2)=9 → update(1,2) → sumRange(0,2)=8 ✓
// ⚠️ 与静态前缀和的差异: 静态建好 O(1) 查询；
//   BIT 支持更新后 O(log n) 查询——"动态"是它存在的意义
```

> 🎯 **307 的定位**："**307 = BIT 的面试入场题——'单点更新 + 区间查询'正是 BIT 的主场**。能讲'静态前缀和 vs BIT'的选型（要不要更新），这道题就答完整了。"

## 3. 动态第 K 小（BIT + 二分）

### 3.1 题目与思路

**题**：动态集合（插入/删除）中查询第 K 小元素。

**BIT 值域频次 + 二分**：

```java
/**
 * 动态第 K 小（BIT + 二分）
 * BIT 存值域频次 → query(x) = 值域 ≤ x 的个数
 * 二分找最小的 x 使 query(x) ≥ k
 * 时间 O(log²n)，空间 O(值域)
 */
class KthFinder {
    private final BIT bit;                       // ① 值域频次 BIT
    private final int maxValue;

    public KthFinder(int maxValue) {
        this.maxValue = maxValue;
        bit = new BIT(maxValue);
    }

    public void insert(int x) { bit.update(x, 1); }
    public void remove(int x) { bit.update(x, -1); }

    public int kth(int k) {                      // ② 二分第 K 小
        int lo = 1, hi = maxValue;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (bit.query(mid) >= k) {
                hi = mid;                        // ③ 前缀 ≥ k → 答案在左
            } else {
                lo = mid + 1;                    // ④ 不够 → 答案在右
            }
        }
        return lo;
    }
}
// 推演 insert(1,3,3,5) → kth(2) = 3 ✓（第二小 = 3）
// ⚠️ 二分单调性: query(x) 随 x 单调不减——
//   "最小的 x 使前缀 ≥ k"就是第 K 小（值域二分）
```

> 💡 **BIT × 二分的组合**："**'值域频次 BIT + 二分'——query 单调让第 K 小可二分**。动态集合的排名查询（值域已知时）是 BIT 的高阶应用，与二分答案（专题 10）同款思维。"

## 4. 离散化详解

### 4.1 为什么需要

```text
问题: 值域可能极大（10⁹、10¹⁴）——
  按值建 BIT 需要 10¹⁴ 数组 → 内存爆

离散化: 把"值"映射为"排名"（相对大小）——
  原值 1, 999, 100000, 15 → 排名 1, 3, 4, 2
  值域从 10¹⁴ 压到 n（数组长度）✓

⚠️ 前提: BIT 只关心"相对大小"（频次/计数）——
  离散化不改变相对顺序 → 结果不变
```

### 4.2 离散化实现

```java
// 离散化三件套: 排序 → 去重 → 二分映射
int[] discretize(int[] nums) {
    int[] sorted = nums.clone();
    Arrays.sort(sorted);                          // ① 排序
    // 去重（可选——BIT 值域可含重复）
    int[] unique = Arrays.stream(sorted).distinct().toArray();

    int[] rank = new int[nums.length];
    for (int i = 0; i < nums.length; i++)
        rank[i] = Arrays.binarySearch(unique, nums[i]) + 1;  // ② 二分映射（1-based）
    return rank;
}
// 推演 [1, 999, 100000, 15] → unique = [1,15,999,100000]
//   rank = [1, 3, 4, 2] ✓（相对大小保持）
// ⚠️ 相等元素: 映射相同排名（stable 处理保持稳定）
```

> 🎯 **离散化的价值**："**'排序 + 去重 + 二分映射'把大值域压到 n——BIT 只关心相对大小，离散化零副作用**。逆序对、区间统计、动态排名，全部需要它做前置。"

## 6. 面试话术与追问

### 6.1 话术模板

```text
"这是【应用】题——树状数组【机制】。
lowbit(x) = x & (−x) 划分区间；
update 上增、query 下减，均 O(log n)。
（写码）模板 + 【离散化/差分】扩展。
复杂度: O(n log n) 时间、O(n) 空间。"

例: "逆序对——值域频次 BIT。
    离散化后从后往前，query(rank−1) 统计小于当前值的。
    O(n log n)。与归并排序解法等价。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|---------|
| 1 | lowbit 是什么？ | x & (−x)——最低位 1 的权值，区间划分依据 |
| 2 | 为什么下标从 1 开始？ | lowbit(0)=0 → 死循环 |
| 3 | query/update 方向？ | query 下减（砍最低位 1）、update 上增（进位） |
| 4 | 区间更新怎么做？ | 差分数组——两次单点更新 |
| 5 | 与线段树选型？ | 前缀和/计数 → BIT（短小）；最值/懒标记 → 线段树 |
| 6 | 逆序对为什么离散化？ | 大值域数组爆内存——映射为排名 |
| 7 | BIT 复杂度？ | O(log n)/操作、O(n) 空间 |
| 8 | BIT 能求最值吗？ | 不能——只维护可逆运算（和/异或）；最值用线段树 |

> 🎯 **核心要点**：BIT 实战通关——**LCR 170（离散化 + 频次计数）+ 307（动态前缀）+ 第 K 小（BIT + 二分）**。三应用覆盖"逆序对/动态查询/排名"——"值域频次 + 前缀计数 + 离散化前置"，就是 BIT 面试的全部套路。
