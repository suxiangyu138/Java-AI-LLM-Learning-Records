## 1. BIT 能力矩阵：能做与不能做

| 能力 | BIT | 线段树 |
|------|:---:|:---:|
| 单点更新 + 前缀查询 | ✔ O(log n) | ✔ |
| 区间查询（前缀差） | ✔ | ✔ |
| 区间更新 + 单点查询 | ✔（差分） | ✔ |
| 区间更新 + 区间查询 | ✔（双 BIT） | ✔（懒标记） |
| 区间最值 | ✘（不可逆） | ✔ |
| 第 K 小 | ✔（+二分） | ✔ |
| 代码量 | ~20 行 | ~80 行 |

```text
⚠️ BIT 的边界: 只能维护"可逆运算"（和/异或）——
  最值（不可逆）必须线段树
  区间更新类可用差分"借道"实现
```

> 🎯 **能力边界**："**BIT 只能维护可逆运算（和/异或），但'差分'让区间更新借道实现**。'不能求最值'是它 vs 线段树的唯一硬伤——其余都能借差分补上。"

## 2. 差分 BIT：区间更新 + 单点查询

### 2.1 原理

```text
问题: 区间 [l, r] 加 k，查询单点值（高频）
差分思想: 维护差分数组 d——
  d[i] = a[i] − a[i−1]
  区间 [l,r] 加 k → d[l] += k、d[r+1] −= k（两次单点！）
  单点查询 a[x] = Σd[1..x]（差分前缀和）

BIT 落地: 对差分数组建 BIT——
  区间更新 = 两次 update（O(log n)）
  单点查询 = 一次 query（O(log n)）
```

### 2.2 完整实现

```java
/**
 * 差分 BIT: 区间更新 + 单点查询
 * 例: 307 区域和检索（配合） / 区间加类题
 */
class RangeBIT {
    private final BIT bit;                       // ① 对差分数组建 BIT

    public RangeBIT(int[] nums) {
        bit = new BIT(nums.length + 1);
        // ② 差分初始: d[i] = nums[i] − nums[i−1]
        for (int i = 1; i <= nums.length; i++)
            bit.update(i, nums[i - 1] - (i > 1 ? nums[i - 2] : 0));
    }

    public void rangeAdd(int l, int r, int k) {  // ③ ⚠️ 区间更新 = 两次单点
        bit.update(l, k);                        //    d[l] += k
        bit.update(r + 1, -k);                   //    d[r+1] −= k
    }

    public int pointQuery(int x) {               // ④ 单点查询 = 差分前缀和
        return bit.query(x);                     //    a[x] = Σd[1..x]
    }
}
// 推演 a=[1,2,3]：差分 d=[1,1,1]
//   rangeAdd(2,3,5): d[2]+=5、d[4]−=5 → d=[1,6,1,−5]
//   pointQuery(2) = 1+6 = 7 = a[2]（原 2 + 5）✓
// ⚠️ 本质: "区间更新问题 → 差分数组的单点更新问题"
```

> 🎯 **差分的转换**："**'区间更新 → 差分数组两次单点更新'——BIT 借差分实现了原本做不到的区间操作**。能讲出这个转换，BIT 的扩展能力就立住了。"

## 3. 双 BIT：区间更新 + 区间查询

### 3.1 原理

```text
问题: 区间 [l,r] 加 k + 区间 [l,r] 求和（都要 O(log n)）

数学推导: 用两个差分 BIT——
  维护 d[i]（差分）与 d[i]·(i−1)（加权差分）
  Σa[1..x] = x·Σd[1..x] − Σ(d[i]·(i−1))[1..x]

实现: 两个 BIT——
  bit1: d[i]（区间更新）
  bit2: d[i]·(i−1)（区间更新的加权版）
  区间和 [l,r] = (query1(r)·r − query2(r)) − (query1(l−1)·(l−1) − query2(l−1))

⚠️ 公式推导（面试可简讲）:
  Σa[i] = ΣΣd[j]（j ≤ i）= Σd[j]·(n−j+1)——
  拆成 n·Σd − Σd·(j−1) → 两个 BIT
```

### 3.2 完整实现

```java
/**
 * 双 BIT: 区间更新 + 区间查询（洛谷 P3372 的 BIT 版）
 */
class RangeRangeBIT {
    private final BIT bit1;                      // ① d[i]
    private final BIT bit2;                      // ② d[i]·(i−1)

    public RangeRangeBIT(int n) {
        bit1 = new BIT(n);
        bit2 = new BIT(n);
    }

    public void rangeAdd(int l, int r, int k) {  // ③ 两个 BIT 各两次更新
        bit1.update(l, k); bit1.update(r + 1, -k);
        bit2.update(l, k * (l - 1));
        bit2.update(r + 1, -k * r);
    }

    private int prefixSum(int x) {               // ④ Σa[1..x]
        return x * bit1.query(x) - bit2.query(x);
    }

    public int rangeSum(int l, int r) {          // ⑤ 区间和
        return prefixSum(r) - prefixSum(l - 1);
    }
}
// 推演 a=[1,2,3] → rangeAdd(2,3,5) → rangeSum(1,3) = 16 ✓（1+7+8）
// ⚠️ 公式: prefixSum(x) = x·query1(x) − query2(x)
//   推导: Σa[i] = Σ d[j]·(i−j+1)（差分展开）——拆两项
```

> 💡 **双 BIT 的定位**："**双 BIT 是'区间更新 + 区间查询'的最短实现（~40 行 vs 线段树 ~80 行）**——竞赛常用它替代懒标记线段树。公式 `x·Σd − Σd·(i−1)` 背住即可，推导面试讲思路。"

## 4. 二维 BIT：矩阵前缀和

### 4.1 实现与推演

```java
/**
 * 二维 BIT: 矩阵单点更新 + 子矩阵前缀和（竞赛）
 * 时间 O(log²n)，空间 O(n²)
 */
class BIT2D {
    private final int[][] tree;
    private final int m, n;

    public BIT2D(int m, int n) {
        this.m = m; this.n = n;
        tree = new int[m + 1][n + 1];
    }

    public void update(int x, int y, int delta) {   // ① 双层 lowbit
        for (int i = x; i <= m; i += lowbit(i))
            for (int j = y; j <= n; j += lowbit(j))
                tree[i][j] += delta;
    }

    public int query(int x, int y) {                // ② 前缀和（双层）
        int sum = 0;
        for (int i = x; i > 0; i -= lowbit(i))
            for (int j = y; j > 0; j -= lowbit(j))
                sum += tree[i][j];
        return sum;
    }

    private int lowbit(int x) { return x & (-x); }

    // ③ 子矩阵和 = 四角容斥
    public int rangeSum(int x1, int y1, int x2, int y2) {
        return query(x2, y2) - query(x1 - 1, y2)
             - query(x2, y1 - 1) + query(x1 - 1, y1 - 1);
    }
}
// 推演 3×3 全 1：rangeSum(2,2,3,3) = 4 ✓
// ⚠️ 二维 = 一维 × 2（内外两层 lowbit）——
//   复杂度 O(log²n)；子矩阵 = 四角容斥（与前缀和同款）
```

> 🎯 **二维的扩展逻辑**："**二维 BIT = '一维 × 2'——update/query 都是双层 lowbit**。子矩阵和沿用前缀和的四角容斥，会一维就会二维（竞赛向，面试提存在即可）。"

## 5. BIT vs 线段树：选型对比

| 维度 | 树状数组 | 线段树 |
|------|:---:|:---:|
| 代码量 | ~20 行 | ~80 行 |
| 常数 | 小 | 较大 |
| 单点 + 前缀 | ✔ 主场 | ✔ |
| 区间最值 | ✘ | ✔ |
| 懒标记 | ✘ | ✔ |
| 区间更新 | ✔（差分借道） | ✔（原生） |
| 可扩展性 | 有限 | 任意（合并函数） |

```text
⚠️ 选型一句话:
  "前缀和/逆序对/频次统计 → BIT（短小快）；
   区间最值/复杂合并 → 线段树（全能）
   ——BIT 是 80% 场景的最短解，线段树是兜底"

⚠️ 面试表达:
  "这题是动态前缀和 → 树状数组（~20 行、O(log n)）；
   如果需要区间最值或复杂懒标记 → 线段树。"
```

## 6. 识别信号与易错点

### 6.1 识别信号

```text
"区间更新 + 单点查询" → 差分 BIT
"区间更新 + 区间查询" → 双 BIT（或懒标记线段树）
"矩阵更新/查询" → 二维 BIT
"动态前缀 + 值域统计" → BIT（+离散化）

⚠️ 判断: "操作是什么 + 需求是什么"——
  单点↔前缀 → 基础 BIT；区间→单点 → 差分；
  区间→区间 → 双 BIT；需要最值 → 线段树
```

### 6.2 易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 差分忘更新 r+1 | `update(r+1, −k)` | 区间外被影响 |
| 2 | 双 BIT 加权公式错 | `d·(i−1)` 与 `d·r` | 区间和错 |
| 3 | 二维容斥符号错 | `+query(x1−1,y1−1)` | 子矩阵和错 |
| 4 | 差分初始忘 d[1]=a[1] | 逐项差分 | 首元素错 |
| 5 | 区间更新用单 BIT 直接做 | 必须差分 | 无法实现 |
| 6 | 需要最值硬用 BIT | 换线段树 | 结果错 |
| 7 | 二维越界 | 双层 `i<=m && j<=n` | 越界 |

> 🎯 **核心要点**：BIT 进阶通关四件事——**① 能力矩阵**（可逆运算 + 差分借道）；**② 差分转换**（区间更新 → 两次单点）；**③ 双 BIT 公式**（x·Σd − Σd·(i−1)）；**④ 选型判断**（短小 vs 全能）。**'差分借道 + 双层扩展'——BIT 从'点操作'进化到'面操作'的全部路径**。
