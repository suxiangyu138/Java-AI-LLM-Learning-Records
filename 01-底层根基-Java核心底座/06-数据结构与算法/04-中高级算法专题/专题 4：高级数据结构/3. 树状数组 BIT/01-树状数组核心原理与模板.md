## 1. 树状数组模型：lowbit 划分区间

```text
树状数组（Fenwick Tree）: 动态前缀和——
  支持单点更新 + 前缀查询，均 O(log n)

核心: lowbit(x) = x & (−x)（x 二进制最低位 1 的权值）
  tree[x] 存储区间 (x − lowbit(x), x] 的和（长度为 lowbit(x)）

例: n = 8
  tree[1] = a[1]（lowbit(1)=1）
  tree[2] = a[1]+a[2]（lowbit(2)=2）
  tree[4] = a[1..4]（lowbit(4)=4）
  tree[6] = a[5]+a[6]（lowbit(6)=2）
  tree[8] = a[1..8]（lowbit(8)=8）

⚠️ 下标从 1 开始（0 的 lowbit 是 0 → 死循环）
```

> 🎯 **核心认知**："**每个 tree[x] 管 '长为 lowbit(x) 的一段区间'——区间划分由二进制最低位 1 决定**。query 把多个 tree 节点拼成前缀和、update 把变化传播到所有覆盖节点，两者都是 O(log n)。"

## 2. lowbit 的二进制直觉

### 2.1 定义与例

```java
int lowbit(int x) { return x & (-x); }
// x & (−x): 取 x 二进制的最低 1 位
//   6 = 110 → −6 = 010 → 110 & 010 = 010 = 2 ✓
//   8 = 1000 → −8 = 1000 → 1000 & 1000 = 8 ✓

// 推演:
//   x = 1: lowbit = 1
//   x = 2: lowbit = 2
//   x = 3: lowbit = 1
//   x = 4: lowbit = 4
//   x = 6: lowbit = 2
```

### 2.2 为什么用它

```text
query(x) 中 x −= lowbit(x):
  6 → 4 → 0（110 → 100 → 000）
  每次"砍掉最低位 1"——区间逐步拆小
  tree[6] + tree[4] = (5,6] + (0,4] = [1..6] ✓

update(x) 中 x += lowbit(x):
  3 → 4 → 8（011 → 100 → 1000）
  每次"向最高位进位"——找到所有覆盖区间
  tree[3], tree[4], tree[8] 都要更新 ✓

⚠️ 直觉: "query 砍最低位 1（向下拆区间）、
   update 进最低位 1（向上找覆盖者）"
```

> 🎯 **lowbit 的灵魂**："**'query 砍最低位 1、update 进最低位 1'——二进制进位/退位就是 BIT 的全部直觉**。理解 6→4→0 与 3→4→8 两条路径，模板就是顺理成章。"

## 3. query：前缀查询（下减）

### 3.1 实现与推演

```java
/**
 * 前缀查询: 求 [1, x] 的和
 * x -= lowbit(x) 逐步累加
 * 时间 O(log n)
 */
int query(int x) {
    int sum = 0;
    for (; x > 0; x -= lowbit(x)) {
        sum += tree[x];                        // ① 累加当前区间
    }
    return sum;
}
// 推演 query(6)（tree: [1]=a1, [2]=a1+a2, [4]=a1..a4, [6]=a5+a6）：
//   x=6: sum += tree[6] = a5+a6
//   x=4: sum += tree[4] = a1..a4
//   x=0: 结束 → sum = a1..a6 ✓
// 区间查询 [l, r] = query(r) − query(l−1)
```

> 💡 **区间查询**："**'区间 [l,r] = query(r) − query(l−1)'——BIT 的区间查询是两个前缀之差**。记住这个，区间统计类问题（频次/和）都能套。"

## 4. update：单点更新（上增）

### 4.1 实现与推演

```java
/**
 * 单点更新: a[x] += delta
 * x += lowbit(x) 向上传播
 * 时间 O(log n)
 */
void update(int x, int delta) {
    for (; x <= n; x += lowbit(x)) {
        tree[x] += delta;                      // ① 更新所有覆盖区间
    }
}
// 推演 update(3, 5)（n=8）：
//   x=3: tree[3] += 5
//   x=4: tree[4] += 5（覆盖 [1..4]）
//   x=8: tree[8] += 5（覆盖 [1..8]）
//   x=16 > 8: 结束
// ⚠️ 覆盖性: x += lowbit 到达的每个节点都包含原位置——
//   3 在 tree[3]（区间 (2,3]）、tree[4]（[1..4]）、tree[8]（[1..8]）中 ✓
```

> 🎯 **update 的覆盖性**："**'x += lowbit 一路向上'——路径上的每个节点区间都包含 x**。3→4→8 的路径保证所有覆盖 a[3] 的区间都被更新，这是 BIT 正确性的根基。"

## 5. 完整模板与推演

### 5.1 面试标准模板

```java
/**
 * 树状数组完整模板——面试标准答案
 * 单点更新 + 前缀查询 O(log n)，空间 O(n)
 */
class BIT {
    private final int[] tree;
    private final int n;

    public BIT(int n) {
        this.n = n;
        tree = new int[n + 1];                 // ① 下标从 1 开始
    }

    private int lowbit(int x) { return x & (-x); }  // ② 核心

    public void update(int x, int delta) {     // ③ 单点更新
        for (; x <= n; x += lowbit(x)) tree[x] += delta;
    }

    public int query(int x) {                  // ④ 前缀查询
        int sum = 0;
        for (; x > 0; x -= lowbit(x)) sum += tree[x];
        return sum;
    }

    public int range(int l, int r) {           // ⑤ 区间查询
        return query(r) - query(l - 1);
    }
}
// 记忆: "lowbit 一记、update 上增、query 下减"
```

### 5.2 建树与操作推演

```java
// 建树（两种）:
//   ① 逐个 update: O(n log n)（简单）
//   ② 线性建树: tree[i] += a[i]; j = i + lowbit(i); tree[j] += tree[i]（O(n)）

// 完整推演: a = [1, 2, 3, 4, 5]，逐个 update
//   update(1,1): tree[1]=1, tree[2]=1, tree[4]=1, tree[8]=1
//   update(2,2): tree[2]=3, tree[4]=3, tree[8]=3
//   update(3,3): tree[3]=3, tree[4]=6, tree[8]=6
//   update(4,4): tree[4]=10, tree[8]=10
//   update(5,5): tree[5]=5, tree[6]=5, tree[8]=15
//   query(5) = tree[5] + tree[4] = 5 + 10 = 15 ✓（1+2+3+4+5）
```

> 🎯 **模板的验证**："**建树后 query(5) = tree[5] + tree[4] = 15——推演一遍模板就可信了**。面试手写后走这个 5 元素样例，正确性一目了然。"

## 6. 识别信号与易错点

### 6.1 识别信号

```text
"动态前缀和（在线更新 + 查询）" → BIT
"逆序对/区间计数统计" → BIT + 离散化
"频次数组 + 前缀计数" → BIT
"值域统计 + 第 K 小" → BIT + 二分

⚠️ 与静态前缀和区分:
  静态（建好不更新）→ 前缀和数组 O(1)
  动态（频繁更新）→ BIT O(log n)
```

### 6.2 易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 下标从 0 开始 | 从 1（lowbit(0)=0） | 死循环 |
| 2 | lowbit 写错 | `x & (-x)` | 区间划分错 |
| 3 | query 用 += lowbit | `x -= lowbit` | 死循环/错和 |
| 4 | update 用 -= lowbit | `x += lowbit` | 更新不传播 |
| 5 | 区间查询忘 l−1 | `query(r) − query(l−1)` | 边界错 |
| 6 | n 越界 | `x <= n` 判断 | 越界 |
| 7 | 大值域不离散化 | 离散化排名 | 内存爆 |

> 🎯 **核心要点**：BIT 基础通关四件事——**① lowbit 语义**（最低位 1 权值）；**② query/update 方向**（下减/上增）；**③ 区间查询公式**（两前缀之差）；**④ 模板 2 分钟默写**。**'lowbit 划区、加减进位'——树状数组的全部秘密就在这一行 lowbit 里**。
