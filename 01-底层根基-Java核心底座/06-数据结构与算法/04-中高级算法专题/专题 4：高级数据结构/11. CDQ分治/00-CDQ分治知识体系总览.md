# CDQ 分治知识体系总览

> CDQ 分治是"用分治消除一维限制"的离线算法：把三维偏序问题按第一维排序、分治第二维、树状数组维护第三维，复杂度 O(n log² n)。它也是"动态问题转离线"的通用手段，可以把带时间维的修改与查询统一成偏序计数。

## 4. 核心概念速查

| 概念 | 含义 |
|------|------|
| 偏序 | 多维"小于等于"关系的计数 |
| 三维偏序 | 统计 $a'\le a,b'\le b,c'\le c$ 的点数 |
| 分治维度 | 第一维排序，第二维分治，第三维树状数组 |
| 去重 | 相同三元组合并计数 |
| 归并 | 分治过程中按第二维归并 |
| 贡献统计 | 只统计"左半对右半"的贡献 |
| 复杂度 | $O(n\log^2 n)$ |
