## 1. 核心概念

### 1.1 什么是前缀和

> 前缀和：预处理数组 `pre[i] = nums[0] + nums[1] + ... + nums[i]`，使任意区间 `[l, r]` 的和能在 O(1) 时间求出。

```
nums  = [3, 1, 4, 1, 5]
pre   = [3, 4, 8, 9, 14]

区间 [1, 3] 的和 = pre[3] - pre[0] = 9 - 3 = 6 ✓（1+4+1）

通用公式：sum(l, r) = pre[r] - pre[l-1]（l>0 时）
         sum(0, r) = pre[r]

暴力 O(n) 查询 vs 前缀和 O(1) 查询（O(n) 预处理）
```

### 1.2 核心公式与变体

```
① 一维前缀和：pre[i] = pre[i-1] + nums[i]
② 二维前缀和：pre[i][j] = 左上角到 (i,j) 的矩形和
   子矩阵和 = pre[r2][c2] - pre[r1-1][c2]
            - pre[r2][c1-1] + pre[r1-1][c1-1]
   （容斥：加回重复减去的左上角）
③ 前缀异或：preXor[i] = preXor[i-1] ^ nums[i]
   区间异或 = preXor[r] ^ preXor[l-1]（异或自反性）
④ 前缀和+哈希：统计"和为 K 的子数组个数"（560）

⚠️ 约定：pre[0] = 0（长度 n+1，统一公式）
```

### 1.3 何时用前缀和

```
① 多次区间和查询（303 区域和检索）
② 子数组和统计（560 和为 K / 974 可被 K 整除）
③ 二维矩阵子矩阵和（304）
④ 差分数组（区间统一增减 → 前缀和还原）

⚠️ 含负数时滑动窗口失效 → 前缀和+哈希是正解
   （560 题的标准答案！）

选型："连续区间求和/计数 → 前缀和；滑窗需单调"
```

## 2. 完整代码模板

### 2.1 一维前缀和模板

```java
/**
 * LeetCode 303. 区域和检索（一维前缀和模板）
 */
class NumArray {
    private int[] pre;                     // 长度 n+1，pre[0]=0

    public NumArray(int[] nums) {
        int n = nums.length;
        pre = new int[n + 1];
        for (int i = 0; i < n; i++) {
            pre[i + 1] = pre[i] + nums[i]; // pre[i+1] = 前 i+1 个的和
        }
    }

    public int sumRange(int left, int right) {
        return pre[right + 1] - pre[left]; // 区间 [left, right]
    }
}
// 构建 O(n)，查询 O(1)
// ⚠️ 下标对应：pre[k] = nums[0..k-1] 的和
```

### 2.2 二维前缀和模板

```java
/**
 * LeetCode 304. 二维区域和检索
 * pre[i][j] = 从 (0,0) 到 (i,j) 的矩形和
 */
class NumMatrix {
    private int[][] pre;                   // (m+1)×(n+1)，边界 0

    public NumMatrix(int[][] matrix) {
        int m = matrix.length, n = matrix[0].length;
        pre = new int[m + 1][n + 1];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                pre[i + 1][j + 1] = matrix[i][j]
                    + pre[i][j + 1]        // 上方
                    + pre[i + 1][j]        // 左方
                    - pre[i][j];           // ⚠️ 减重叠（容斥）
            }
        }
    }

    public int sumRegion(int r1, int c1, int r2, int c2) {
        return pre[r2 + 1][c2 + 1]
             - pre[r1][c2 + 1]             // 减上方
             - pre[r2 + 1][c1]             // 减左方
             + pre[r1][c1];                // ⚠️ 加回重叠
    }
}
// 构建 O(mn)，查询 O(1)
```

### 2.3 差分数组模板（区间统一增减）

```java
/**
 * 差分数组：区间 [l, r] 统一 +v
 * diff[l] += v; diff[r+1] -= v;
 * 前缀和还原 → 每个位置的值
 *
 * LeetCode 370. 区间加法
 */
public int[] getModifiedArray(int length, int[][] updates) {
    int[] diff = new int[length + 1];      // ⚠️ 多一位防越界

    for (int[] u : updates) {
        int start = u[0], end = u[1], inc = u[2];
        diff[start] += inc;
        diff[end + 1] -= inc;              // 结束位置的下一位减
    }

    // 前缀和还原
    int[] result = new int[length];
    int cur = 0;
    for (int i = 0; i < length; i++) {
        cur += diff[i];                    // 累积
        result[i] = cur;
    }
    return result;
}
// 每次更新 O(1)，还原 O(n)（对比暴力 O(nk)）
```

## 3. 前缀和 + 哈希详解

### 3.1 560. 和为 K 的子数组

```java
/**
 * LeetCode 560. 和为 K 的子数组（前缀和+哈希经典）
 * 统计和为 k 的连续子数组个数
 *
 * 数学转化：
 *   sum(l, r) = k ⇔ pre[r] - pre[l-1] = k
 *   ⇔ pre[l-1] = pre[r] - k
 *   → 遍历 r 时，统计"前缀和 = pre[r]-k"的出现次数
 *
 * ⚠️ 为什么滑动窗口不行？
 *   数组含负数 → 扩窗可能减小和 → 条件不单调 → 滑窗失效
 */
public int subarraySum(int[] nums, int k) {
    Map<Integer, Integer> prefixCount = new HashMap<>();
    prefixCount.put(0, 1);           // ⚠️ 空前缀和为 0（出现 1 次）

    int sum = 0, count = 0;
    for (int x : nums) {
        sum += x;                            // 当前前缀和
        count += prefixCount.getOrDefault(sum - k, 0);
        prefixCount.put(sum, prefixCount.getOrDefault(sum, 0) + 1);
    }
    return count;
}
```

### 3.2 推演：nums = [1, 1, 1], k = 2

```
初始化: {0:1}, sum=0, count=0
x=1: sum=1, 查 1-2=-1 → 0 个；存 {0:1, 1:1}
x=1: sum=2, 查 2-2=0 → 1 个（[1,1]）；存 {0:1, 1:1, 2:1}
x=1: sum=3, 查 3-2=1 → 1 个（[1,1]）；存 {0:1, 1:1, 2:1, 3:1}
count = 2 ✓
```

### 3.3 为什么必须初始化 {0: 1}？

```
前缀和恰好等于 k 的子数组（从 0 开始）：
  例 nums=[1,1,1], k=1 → [0,0] 和 [2,2]
  第一个 [0,0]：sum=1, 查 sum-k=0 → 需要"空前缀 0"
  → 不初始化 {0:1} 会漏掉从开头开始的子数组！

记忆："{0:1} 表示空前缀，处理从头开始的子数组"
```

### 3.4 前缀和+哈希家族

| 题号 | 题目 | 变体 |
|:---:|------|------|
| 560 | 和为 K 的子数组 | 基础版（计数） |
| 974 | 可被 K 整除的子数组 | 前缀和 mod K（负 mod 处理） |
| 523 | 连续子数组和 | mod K + 首次出现下标 |
| 325 | 最长子数组和为 K | 前缀和首次出现下标 |
| 930 | 和相同的二元子数组 | atMost 容斥（滑动窗口版） |
| 525 | 连续数组 | 0/1 映射 + 前缀和 |

```
974 的关键细节（负数取模）：
  mod = ((sum % k) + k) % k   // ⚠️ Java 负数取模为负
  例：-3 % 5 = -3（Java）→ 调整为 2
```

## 4. 二维前缀和与差分

### 4.1 二维前缀和的容斥理解

```
构建 pre[i][j]：
  矩形和 = 当前格 + 上矩形 + 左矩形 - 左上重叠矩形

查询 [r1,c1] 到 [r2,c2]：
  大矩形 - 上矩形 - 左矩形 + 左上小矩形（加回减多的）

记忆："加加减减，左上补回"（容斥原理）
```

### 4.2 差分的高级应用

```
① 区间统一增减（370）
② 扫描线（253 会议室：事件 +1/-1）
③ 差分 + 前缀和 = 覆盖次数统计

⚠️ 差分 vs 前缀和关系：
  差分是前缀和的"逆运算"
  对差分做前缀和 → 还原原数组
  对原数组做前缀和 → 得到区间和
  "差分管区间修改，前缀和管区间查询"
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"子数组和 = K 的计数问题：
 滑动窗口在有负数时失效（条件不单调），
 我用前缀和 + 哈希：
  sum(l,r)=k ⇔ pre[r]-pre[l-1]=k
  ⇔ 找 pre[l-1] = pre[r]-k 的出现次数。
 遍历时维护前缀和计数 → O(n) 一次扫描。
 ⚠️ 初始化 {0:1} 处理从开头开始的子数组。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 前缀和 vs 滑动窗口？ | 滑窗需条件单调（不含负数）；前缀和+哈希通用（含负数） |
| 2 | 为什么 {0:1} 必须初始化？ | 处理"从开头开始的和为 K 的子数组"（空前缀和 0） |
| 3 | 二维前缀和怎么推？ | 容斥：大矩形 - 上 - 左 + 左上（加回减多的） |
| 4 | 差分数组什么时候用？ | 多次区间统一增减 → O(1)/次更新，前缀和还原 |
| 5 | 负数取模怎么处理？ | Java % 结果与被除数同号 → ((x % k) + k) % k |
| 6 | 前缀异或为什么可行？ | 异或自反性：x^y^y = x → 区间异或 = pre[r]^pre[l-1] |
| 7 | 何时前缀和不适用？ | 需要区间更新（用差分/线段树）；数组频繁变化 |
| 8 | 数据规模注意？ | 前缀和可能溢出 → 用 long；mod 场景先取模 |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 忘初始化 {0:1} | 漏掉从头开始的子数组 | 必须 put(0, 1) |
| 二维容斥符号错 | 查询结果错 | "加加减减，左上补回" |
| 负数取模为负 | 哈希键错乱 | ((x % k) + k) % k |
| 差分忘 end+1 | 影响范围外元素 | diff[end+1] -= inc |
| 前缀和溢出 | 结果错 | 用 long |

> 🎯 **核心要点**：前缀和 = **预处理换 O(1) 查询**。三大模板：一维/二维（容斥）、前缀和+哈希（560 含负数）、差分（区间修改）。识别信号："区间和、子数组和统计、区间统一增减"。560 的数学转化（pre[r]-k 计数）是面试最高频考点。
