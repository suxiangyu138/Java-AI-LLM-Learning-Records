## 1. 303. 区域和检索（一维模板）

### 1.1 题目与思路

```
多次查询区间 [l, r] 之和 → 前缀和预计算 O(n)，查询 O(1)
⚠️ 303 是前缀和的最小模板（01 模块 1 节）
```

### 1.2 完整代码

```java
/**
 * LeetCode 303. 区域和检索（一维前缀和模板）
 */
class NumArray {
    private final int[] pre;               // ⚠️ pre[i+1] = 前 i+1 个和

    public NumArray(int[] nums) {
        pre = new int[nums.length + 1];    // ⚠️ 多一位（pre[0]=0）
        for (int i = 0; i < nums.length; i++)
            pre[i + 1] = pre[i] + nums[i];
    }

    public int sumRange(int left, int right) {
        return pre[right + 1] - pre[left]; // ⚠️ 区间和 = 前缀和之差
    }
}
// 推演 nums=[-2,0,3,-5,2,-1]：
//   pre=[0,-2,-2,1,-4,-2,-3]
//   查询 [0,2]：pre[3]-pre[0] = 1-0 = 1 ✓（-2+0+3）
//   查询 [2,5]：pre[6]-pre[2] = -3-(-2) = -1 ✓（3-5+2-1）
// ⚠️ 复杂度：预计算 O(n)，查询 O(1)
// ⚠️ 面试表达："303 是前缀和的最小样板——
//   pre 多开一位（pre[0]=0）让区间公式
//   统一为 pre[r+1]-pre[l]，免边界特判。"
```

## 2. 560. 和为 K 的子数组

### 2.1 题目与思路

```
和为 K 的子数组个数（O(n)！）
前缀和 + 哈希：查 pre[r] - K 在历史中的次数
⚠️ 01 模块 2 节完整推导，此处给最完整实现
```

### 2.2 完整代码

```java
/**
 * LeetCode 560. 和为 K 的子数组
 */
public int subarraySum(int[] nums, int k) {
    Map<Integer, Integer> count = new HashMap<>();
    count.put(0, 1);                        // ⚠️ 前缀和 0 出现 1 次（空前缀）
    int pre = 0, result = 0;

    for (int x : nums) {
        pre += x;
        result += count.getOrDefault(pre - k, 0);   // ⚠️ 核心：查补前缀
        count.merge(pre, 1, Integer::sum);
    }
    return result;
}
// 推演 [1,2,3], k=3：
//   pre=1：查 -2 → 0；记 {0:1, 1:1}
//   pre=3：查 0 → 1（[1,2]）✓；记 {3:1}
//   pre=6：查 3 → 1（[3]）✓ → 结果 2 ✓
// ⚠️ 为什么先查后记：避免"同一元素自配"
//   （pre[r]-pre[l] 需要 l < r，先查保证历史）
// ⚠️ 面试表达："560 = 前缀和 + 哈希查历史——
//   sum[l..r]=K ⟺ pre[l]=pre[r]-K，
//   数历史中 pre[r]-K 出现几次即可。"
```

## 3. 974. 和可被 K 整除的子数组

### 3.1 题目与思路

```
和可被 K 整除的子数组个数
核心：pre[r] ≡ pre[l] (mod K) → 同余配对
⚠️ 负数取模转正（01 模块 3 节）
```

### 3.2 完整代码

```java
/**
 * LeetCode 974. 和可被 K 整除的子数组
 */
public int subarraysDivByK(int[] nums, int k) {
    Map<Integer, Integer> count = new HashMap<>();
    count.put(0, 1);                        // 前缀和 mod 0 出现 1 次
    int pre = 0, result = 0;

    for (int x : nums) {
        pre += x;
        int mod = ((pre % k) + k) % k;      // ⚠️ Java 负数取模转正
        result += count.getOrDefault(mod, 0);
        count.merge(mod, 1, Integer::sum);
    }
    return result;
}
// 推演 [4,5,0,-2,-3,1], k=5：
//   pre mods：4,4,4,2,4,0（用转正公式）
//   4 出现 4 次 → C(4,2) = 6；0 出现 2 次 → C(2,2) = 1
//   结果 6+1 = 7 ✓
// ⚠️ 同余组合：n 次出现 → C(n,2) = n(n-1)/2 对
// ⚠️ 面试表达："可整除 = 前缀和同余——
//   pre[r]-pre[l] ≡ 0 ⟺ 同余。配对计数
//   C(n,2) 由哈希次数累加自然完成。"
```

## 4. 523. 连续的子数组和

### 4.1 题目与思路

```
是否存在长度 ≥ 2 且和为 k 的倍数的子数组
与 974 区别：长度约束（≥ 2）→ 记录"首次出现下标"而非次数
⚠️ 返回布尔（存在性）
```

### 4.2 完整代码

```java
/**
 * LeetCode 523. 连续的子数组和
 * ⚠️ 长度 ≥ 2：记录首次出现下标，检查距离
 */
public boolean checkSubarraySum(int[] nums, int k) {
    Map<Integer, Integer> firstPos = new HashMap<>();
    firstPos.put(0, -1);                    // ⚠️ 空前缀下标 -1
    int pre = 0;

    for (int i = 0; i < nums.length; i++) {
        pre += nums[i];
        int mod = k == 0 ? pre : ((pre % k) + k) % k;   // ⚠️ k=0 特判

        if (firstPos.containsKey(mod)) {
            if (i - firstPos.get(mod) >= 2) return true;  // ⚠️ 长度 ≥ 2
        } else {
            firstPos.put(mod, i);           // ⚠️ 只记首次（保留最长距离）
        }
    }
    return false;
}
// 推演 [23,2,4,6,7], k=6：
//   pre mods：5,1,5,... → i=0 记 {5:0}；i=2 时 mod=5 → 2-0=2 ≥ 2 ✓
//   （[23,2,4] = 29? 23+2+4=29 不是 6 倍数——验证：pre[3]-pre[0]=29-23=6 ✓ 是）
// ⚠️ 为什么"只记首次"：距离 = i - first，首次下标使距离最大
// ⚠️ 面试表达："523 = 974 + 长度约束——
//   哈希改存'首次下标'，检查 i-first ≥ 2。
//   k=0 时退化为'存在相邻两数均为 0'。"
```

## 5. 325. 和等于 K 的最长子数组长度

### 5.1 题目与思路

```
和为 K 的最长子数组长度（返回长度，无则 0）
与 560 同模板，哈希存"首次出现下标"（最长距离）
⚠️ 细节：记录首次（距离最大），存在时不更新
```

### 5.2 完整代码

```java
/**
 * LeetCode 325. 和等于 K 的最长子数组长度
 */
public int maxSubArrayLen(int[] nums, int k) {
    Map<Integer, Integer> firstPos = new HashMap<>();
    firstPos.put(0, -1);                    // ⚠️ 空前缀（长度为 i+1）
    int pre = 0, best = 0;

    for (int i = 0; i < nums.length; i++) {
        pre += nums[i];
        // ⚠️ 查 pre - k 的首次出现 → 最长距离
        if (firstPos.containsKey(pre - k)) {
            best = Math.max(best, i - firstPos.get(pre - k));
        }
        firstPos.putIfAbsent(pre, i);       // ⚠️ 只记首次（最长距离）
    }
    return best;
}
// 推演 [1,-1,5,-2,3], k=3：
//   pre: 1,0,5,3,6
//   i=3 时 pre=3，查 0 → first=1 → 长度 3-1=2？[1,-1,5,-2]=3? 
//   ⚠️ [1,-1,5,-2,3]：pre[4]-pre[1] = 6-0 = 6? 不对——验证：
//   i=0:pre=1, 查-2无, 记{0:-1,1:0}
//   i=1:pre=0, 查-3无, 记{0:-1(已存),1:0}
//   i=2:pre=5, 查2无, 记{5:2}
//   i=3:pre=3, 查0 → best=3-(-1)=4（[1,-1,5,-2] = 3 ✓）
//   i=4:pre=6, 查3 → 4-3=1 → best 保持 4 ✓
// ⚠️ 面试表达："325 与 560 的区别只有一处——
//   哈希存'首次下标'取最长距离（560 存次数计数）。"
```

## 6. 1310. 子数组异或查询

### 6.1 题目与思路

```
多次查询区间异或 → 前缀异或（异或自逆：a^a=0）
⚠️ 与前缀和的唯一区别：用 ^ 而非 +
```

### 6.2 完整代码

```java
/**
 * LeetCode 1310. 子数组异或查询
 */
public int[] xorQueries(int[] arr, int[][] queries) {
    int n = arr.length;
    int[] pre = new int[n + 1];
    for (int i = 0; i < n; i++)
        pre[i + 1] = pre[i] ^ arr[i];       // ⚠️ 前缀异或

    int[] res = new int[queries.length];
    for (int i = 0; i < queries.length; i++) {
        int l = queries[i][0], r = queries[i][1];
        res[i] = pre[r + 1] ^ pre[l];       // ⚠️ 区间异或 = 前缀相消
    }
    return res;
}
// 推演 arr=[1,3,4,8], 查询 [[0,1],[1,2],[0,3],[3,3]]：
//   pre=[0,1,2,6,14]
//   [0,1]：pre[2]^pre[0] = 2^0 = 2（1^3）✓
//   [1,2]：pre[3]^pre[1] = 6^1 = 7（3^4）✓
//   [3,3]：pre[4]^pre[3] = 14^6 = 8 ✓
// ⚠️ 复杂度：O(n + q)
// ⚠️ 面试表达："异或自逆 → 前缀异或的'减法'
//   就是异或自身。1310 与 303 同构，
//   运算符从 + 换成 ^ 即可。"
```

## 7. 前缀和方法论总结

### 7.1 题型识别与选型

```
① 多次区间查询 → 前缀和（和/异或/计数）
② 和为 K / 可整除 → 前缀和 + 哈希
   ⚠️ 计数 → 存次数；最长 → 存首次下标
③ 区间修改 → 差分数组
④ 二维区域 → 二维容斥
⑤ 动态修改 + 查询 → 树状数组/线段树

⚠️ 识别信号：
  "区间和/区域和查询" → 前缀和
  "和为 K/倍数" → 前缀和 + 哈希
  "区间修改" → 差分
```

### 7.2 模板速查表

| 模板 | 核心 | 代表题 |
|------|------|--------|
| 一维前缀和 | pre[r+1] - pre[l] | 303 |
| 前缀和 + 哈希 | 查 pre-k 历史 | 560、325 |
| mod 同余 | (x%k+k)%k | 974、523 |
| 二维容斥 | 加两块减重叠 | 304 |
| 差分数组 | 两端打标记 | 370、1109 |
| 前缀异或 | ^ 自逆 | 1310 |

### 7.3 自测清单

```
□ pre[0]=0 初始化（哈希版 put(0,1)）？
```
