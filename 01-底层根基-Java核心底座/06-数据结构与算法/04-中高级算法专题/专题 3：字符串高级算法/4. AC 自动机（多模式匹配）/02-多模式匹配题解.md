## 1. HDU 2222 单词统计（经典母题）

### 1.1 题目与思路

**题**：K 个模式串在文本中出现次数的总和（每个模式串计一次）。

**AC 自动机完整流程**（Trie → fail → 匹配统计）：

```java
/**
 * HDU 2222 Keywords Search（AC 自动机母题）
 * 统计所有模式串在文本中出现的次数
 * 时间 O(n + m)，空间 O(Σ·m)
 */
int solve(String[] patterns, String text) {
    // ① 建 Trie（插入所有模式串）
    Node root = new Node();
    for (String p : patterns) insert(root, p);

    // ② 构建 fail（BFS）
    buildFail(root);

    // ③ 匹配 + fail 链统计
    Node cur = root;
    int count = 0;
    for (char c : text.toCharArray()) {
        int idx = c - 'a';
        while (cur != root && cur.children[idx] == null) cur = cur.fail;  // 失配跳
        if (cur.children[idx] != null) cur = cur.children[idx];

        for (Node p = cur; p != root; p = p.fail) {   // ④ fail 链统计
            if (p.count > 0) {
                count += p.count;
                p.count = 0;                       // ⑤ ⚠️ 置 0 防重复计数
            }
        }
    }
    return count;
}
// 推演 patterns = ["he","she","his","hers"], text = "ushers" → 3
//   "she"（1）+ 沿 fail 的 "he"（2）+ "hers"（3）✓
// ⚠️ 母题三件套: 建 Trie → buildFail → 匹配统计——
//   "置 0 防重复"是计数类 AC 题的标准细节
```

> 🎯 **HDU 2222 的模板地位**："**2222 = AC 自动机的 'Hello World'——Trie/fail/匹配三件套全演示**。会它，敏感词过滤、多模式统计全是换皮。"

## 2. 敏感词过滤（工程应用）

### 2.1 题目与思路

**题**：把文本中的敏感词替换为 `*`（多模式匹配的工程场景）。

**AC 自动机 + 命中替换**：

```java
/**
 * 敏感词过滤（AC 自动机工程应用）
 * 命中模式串 → 替换为等长 '*'
 */
String filterSensitive(String text, String[] banned) {
    // ① 建 Trie + fail（同 2222）
    // ② 匹配: 记录每个命中的 [起点, 终点] 区间
    List<int[]> matches = new ArrayList<>();
    Node cur = root;
    for (int i = 0; i < text.length(); i++) {
        int idx = text.charAt(i) - 'a';
        while (cur != root && cur.children[idx] == null) cur = cur.fail;
        if (cur.children[idx] != null) cur = cur.children[idx];

        // ③ fail 链上的每个模式串 = 一次命中
        for (Node p = cur; p != root; p = p.fail) {
            if (p.count > 0 && p.len > 0) {
                matches.add(new int[]{i - p.len + 1, i});   // 记录区间
            }
        }
    }
    // ④ 替换: 按区间把字符变为 '*'
    char[] result = text.toCharArray();
    for (int[] m : matches) {
        for (int k = m[0]; k <= m[1]; k++) result[k] = '*';
    }
    return new String(result);
}
// 推演 text="he is a her", banned=["he","her"] → "** is a ***" ✓
// ⚠️ 工程细节: 节点记 len（模式串长度）→ 命中时反推起点
//   重叠敏感词: 区间标记法天然处理（多次置 '*' 无副作用）
```

> 💡 **工程落地的要点**："**敏感词过滤 = AC 匹配 + 区间标记——节点存 len 反推起点、区间置 '\*' 处理重叠**。微信/论坛的敏感词系统就是 AC 自动机的工程形态。"

## 3. Trie 图匹配（O(1) 转移）

### 3.1 题目与思路

**题**：用 Trie 图（空儿子补 fail）实现 O(1) 转移的匹配。

**Trie 图构建 + 直接转移**：

```java
/**
 * Trie 图匹配（确定性自动机）
 * 空儿子直接指向 fail 的同字符儿子 → 匹配无 while
 */
void buildTrieGraph(Node root) {
    Queue<Node> queue = new LinkedList<>();
    for (int i = 0; i < 26; i++) {
        if (root.children[i] != null) {
            root.children[i].fail = root;
            queue.offer(root.children[i]);
        } else {
            root.children[i] = root;             // ① 根的"空儿子"指向根（自环）
        }
    }
    while (!queue.isEmpty()) {
        Node cur = queue.poll();
        for (int i = 0; i < 26; i++) {
            Node child = cur.children[i];
            if (child != null) {
                child.fail = cur.fail.children[i];   // ② 有儿子: fail = 父fail的儿子
                queue.offer(child);
            } else {
                cur.children[i] = cur.fail.children[i];  // ③ ⚠️ 空儿子补 fail 的儿子
            }
        }
    }
}

// 匹配: 无 while 失配循环——直接转移！
for (char c : text.toCharArray()) {
    cur = cur.children[c - 'a'];                 // ④ O(1) 转移
    // fail 链统计同前
}
// ⚠️ 效果: 匹配从"while 跳 fail"变"直接转移"——
//   Trie 图 = 确定性有限自动机（DFA），工程实现标准
```

> 🎯 **Trie 图的面试价值**："**'空儿子补 fail 儿子'让失配转移 O(1)——Trie 图是 AC 自动机的 DFA 形态**。面试讲'为什么补'（匹配免 while）+ 效果（O(1) 转移），就是 AC 自动机的工程深度。"

## 4. 多模式统计变体

### 4.1 变体清单

| 变体 | 需求 | 修改点 |
|:---:|:---:|:---:|
| 出现次数（2222） | 各模式计数 | count 数组（命中 +1） |
| 是否出现 | 布尔判定 | 找到即返回 |
| 最长命中 | 最长模式串 | 记录 len 取 max |
| 全部出现位置 | 位置列表 | 记录区间/下标 |
| 模式串去重 | 去重统计 | count 置 0 或 Set |

```text
⚠️ 变体规律: "匹配流程不变、统计方式变——
   计数/布尔/最长/位置，都是 fail 链统计的改法"
```

## 5. 家族总览与对比

## 6. 易错点与面试要点

### 6.1 易错点

| # | 易错点 | 正确写法 | 后果 |

| 1 | 2222 忘置 0 | 命中后 count=0 | 重复计数 |

| 3 | Trie 图根空儿子忘补 | 指向根（自环） | 匹配死循环 |
| 4 | fail 链统计漏 | 每命中节点沿链 | 后缀模式漏计 |
