## 1. 知识体系导图

```text
字符串高级算法
│
├── 匹配家族 ──────────────────────────────────────────────
│   ├── KMP: 单模式匹配 O(n)——next/border 数组（1. 子目录）
│   ├── 字符串哈希: 滚动哈希/Rabin-Karp（字符串高级/）
│   └── Z 函数: 扩展 KMP——后缀 LCP（字符串高级/）
│
├── 回文家族 ─────────────────────────────────────────────
│   ├── Manacher: O(n) 最长回文（2. 子目录）
│   ├── 插入 # 统一奇偶
│   └── 应用: 回文子串计数、最短回文串
│
├── 多模式家族 ───────────────────────────────────────────
│   ├── Trie: 前缀树（5. 子目录——208/211/212）
│   ├── AC 自动机: Trie + KMP fail（4. 子目录——敏感词）
│   └── 复杂度: 多模式 O(n+m) vs 逐个 KMP O(k·n)
│
├── 后缀家族（竞赛）──────────────────────────────────────
│   ├── 后缀数组 SA: 倍增 + 基数排序 O(n log n)（3. 子目录）
│   ├── height/LCP: RMQ 区间最小
│   └── 应用: 最长公共子串、不同子串计数
│
└── 面试定位 ─────────────────────────────────────────────
    ├── 高频: KMP（28/686）、Trie（208/212）、Manacher（5）
    ├── 中频: 滚动哈希、Z 函数
    └── 竞赛: SA/AC 自动机/SAM/PAM
```

## 5. 算法对比速查表

| 算法 | 功能 | 时间 | 空间 | 面试频率 |
|------|------|:---:|:---:|:---:|
| 字符串哈希 | 子串比较/匹配 | O(n) 预 + O(1) 查 | O(n) | ★★★★ |
| KMP | 单模式匹配 | O(n+m) | O(m) | ★★★★ |
| Trie | 前缀检索 | O(L) | O(Σ·L) | ★★★★ |
| Manacher | 最长回文 | O(n) | O(n) | ★★★ |
| Z 函数 | 后缀 LCP | O(n) | O(n) | ★★★ |
| AC 自动机 | 多模式匹配 | O(n+m) | O(Σ·m) | ★★ |
| 后缀数组 | 后缀排序/LCP | O(n log n) | O(n) | ★★ 竞赛 |

## 6. 常见误区速查

| 误区 | 正解 |
|------|------|
| "KMP 是背代码" | ❌ 核心是 border 语义——失配回退到最长公共前后缀 |
| "Manacher 只能求最长" | ❌ 回文半径数组可判任意子串回文、计数回文子串 |
| "AC 自动机 = 高级 KMP" | ❌ = Trie + KMP fail——多模式匹配（敏感词过滤） |
| "Trie 只是字典" | ❌ 前缀统计/异或最值/自动机基座（212 单词搜索） |
| "哈希可能冲突就不敢用" | ❌ 双哈希/大质数模——工程与面试都够用 |
| "后缀数组只能排序" | ❌ height/LCP 的 RMQ 是它真正价值（LCS/重复子串） |
| "所有匹配都用 KMP" | ❌ 单模式 KMP、多模式 AC、子串比较哈希——按场景选 |
| "SA 构造必须背" | ❌ 竞赛才手写倍增；面试讲清原理即可 |
| "回文问题只能 O(n²)" | ❌ Manacher O(n)——面试 5/647 的进阶答案 |
| "字符串哈希是偷懒" | ❌ O(1) 子串比较是工程标准做法（配合二分） |
