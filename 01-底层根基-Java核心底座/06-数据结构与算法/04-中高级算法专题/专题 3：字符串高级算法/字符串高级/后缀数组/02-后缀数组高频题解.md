## 1. 1044. 最长重复子串（后缀数组版）

### 1.1 题目与思路

```
最长重复子串（两处出现、可重叠）
后缀数组版：max(height) 直接出答案——但"输出子串"还要定位下标
⚠️ 复杂度：构建 O(n log n) + 扫 height O(n) = O(n log n)
   对比滚动哈希版：二分 + 每轮 O(n) = O(n log n)（常数不同）
```

### 1.2 完整代码

```java
/**
 * LeetCode 1044. 最长重复子串（后缀数组版）
 * ⚠️ max(height) 的排名即答案位置
 */
public String longestDupSubstring(String s) {
    int n = s.length();
    int[] sa = buildSuffixArray(s);          // 00 模块倍增模板
    int[] height = buildHeight(s, sa);       // 00 模块 h 不减模板

    int bestIdx = -1, bestLen = 0;
    for (int i = 1; i < n; i++) {
        if (height[i] > bestLen) {           // ⚠️ 找 max(height)
            bestLen = height[i];
            bestIdx = sa[i];                 // 起点 = 排名 i 的后缀起点
        }
    }
    return bestLen == 0 ? "" : s.substring(bestIdx, bestIdx + bestLen);
}
// 推演 s="banana"：
//   height = [0,1,3,0,0,2] → max = 3（"ana"）
//   返回 "ana" ✓
// ⚠️ 面试要点：这题"会讲"比"会写"更重要——
//   "max(height) 即最长重复子串长度，起点是
//   对应后缀的下标。" 手写用滚动哈希更实际。
```

## 2. 1062. 最长重复子串（同构速解）

### 2.1 与 1044 的差异

```
1044：任意重复（可重叠）→ max(height)
1062：要求"不重叠"（两处不能重叠）→ 需要附加检查

附加条件：两个后缀起点距离 > 子串长度（不重叠）
  sa[i] 与 sa[i-1] 的 LCP = height[i] 且 |sa[i] - sa[i-1]| > height[i]
  → 不重叠才计入
```

### 2.2 核心修改

```java
// 1044 的 height 扫描加一个条件：
int bestLen = 0;
for (int i = 1; i < n; i++) {
    // ⚠️ 附加条件：起点距离 > LCP 长度（两处不重叠）
    if (height[i] > bestLen && Math.abs(sa[i] - sa[i - 1]) > height[i]) {
        bestLen = height[i];
        bestIdx = sa[i];
    }
}
// ⚠️ 注意：不重叠检查只针对"相邻对"——更精确的解法
//   需要检查"窗口内所有对"，但相邻检查是常用近似
//   面试表达："1062 在 1044 基础上加不重叠约束，
//   重叠候选用起点距离过滤。"
```

## 3. 1698. 字符串的不同子字符串数量

### 3.1 题目与思路

```
统计不同子串数量（n ≤ 500，O(n²) 可过；后缀数组 O(n log n)）
公式：Σ(n - sa[i] - height[i])
  ⚠️ 每个后缀贡献"独有的前缀数"（全长 - 与前驱共享的 LCP）
  字典序枚举保证不重不漏
```

### 3.2 完整代码

```java
/**
 * LeetCode 1698. 字符串的不同子字符串数量
 * ⚠️ 一行公式 + 构造模板
 */
public int countDistinct(String s) {
    int n = s.length();
    int[] sa = buildSuffixArray(s);
    int[] height = buildHeight(s, sa);

    long total = 0;
    for (int i = 0; i < n; i++) {
        // ⚠️ 核心公式：该后缀全长 - 与前一名共享的 LCP
        total += (n - sa[i]) - height[i];
    }
    return (int) total;
}
// 推演 s="banana"（n=6）：
//   sa=[5,3,1,0,4,2]，height=[0,1,3,0,0,2]
//   贡献：1 + 2 + 2 + 6 + 2 + 2 = 15 ✓
// ⚠️ 直观理解：把后缀按字典序排好后，
//   每个新后缀只会"新增"独有前缀——其他前缀都已出现过
// ⚠️ 变体：要求不同子串按长度排序输出 → 后缀数组按
//   (长度, 排名) 枚举即可
```

## 4. 最长公共子串（拼接 + height）

### 4.1 题目与思路

```
两字符串 s1、s2 的最长公共子串
三步：拼接 s1 + '#' + s2 → 构建 sa/height → 归属不同的相邻对取 max
⚠️ 分隔符必须小于所有字符（隔离跨串 LCP）
```

### 4.2 完整代码

```java
/** 两字符串最长公共子串（返回子串本身） */
String longestCommonSubstring(String s1, String s2) {
    String s = s1 + "#" + s2;                  // ⚠️ 分隔符隔离
    int n1 = s1.length();
    int[] sa = buildSuffixArray(s);
    int[] height = buildHeight(s, sa);

    int bestLen = 0, bestIdx = 0;
    for (int i = 1; i < s.length(); i++) {
        // ⚠️ 归属判断：两个相邻后缀分属不同字符串
        boolean cross = (sa[i] < n1) != (sa[i - 1] < n1);
        if (cross && height[i] > bestLen) {
            bestLen = height[i];
            bestIdx = Math.min(sa[i], sa[i - 1]);
        }
    }
    return bestLen == 0 ? "" : s.substring(bestIdx, bestIdx + bestLen);
}
// 推演 s1="ABAB", s2="BABA"：
//   拼接 "ABAB#BABA"，height 中跨串相邻最大 = 3（"ABA"）✓
// ⚠️ k 个字符串版本：归属用位掩码（第 i 串 → 第 i 位）
//   连续段内掩码覆盖全部 → 该段最小 height 为候选
// ⚠️ 面试表达："公共子串 = 跨串相邻后缀的最大 LCP——
//   排序把公共前缀最长的后缀排在一起，跨串即公共。"
```

## 5. 子串出现次数（二分定位）

### 5.1 题目与思路

```
统计模式串 P 在 s 中出现的次数（可重叠）
后缀数组：以 P 为前缀的后缀在 sa 中连续
  二分两次：lower_bound(P) 与 upper_bound(P) → 区间长度
⚠️ 对比 KMP：KMP 单次匹配 O(n+m)；后缀数组支持
  多个 P 查询（每次 O(m log n)）——"一次构建多查询"
```

### 5.2 完整代码

```java
/** 子串 P 在 s 中的出现次数（后缀数组 + 二分） */
int countOccurrences(String s, String p) {
    int n = s.length(), m = p.length();
    int[] sa = buildSuffixArray(s);

    // ⚠️ 第一个"前缀 ≥ P"的排名
    int lo = lowerBound(s, sa, p);
    // ⚠️ 第一个"前缀 > P"的排名
    int hi = upperBound(s, sa, p);
    return hi - lo;
}

int lowerBound(String s, int[] sa, String p) {
    int lo = 0, hi = sa.length;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        // 比较后缀与 P（截取 m 字符）
        String suffix = s.substring(sa[mid], Math.min(sa[mid] + p.length(), s.length()));
        if (suffix.compareTo(p) >= 0) hi = mid;
        else lo = mid + 1;
    }
    return lo;
}
// upperBound 同构（> 而非 >=）
// 推演 s="banana", p="ana"：
//   以 "ana" 开头的后缀：sa 中下标 3（"ana"）与 1（"anana"）→ 区间 [1,3) → 2 次 ✓
// ⚠️ 复杂度：O(m log n)（每次比较 O(m)，二分 O(log n)）
// ⚠️ 面试价值：展示"后缀数组 = 子串字典序索引"——
//   任何子串问题都能转成 sa 区间问题
```

## 6. 最长回文子串（后缀数组版）

### 6.1 题目与思路

```
最长回文子串（LeetCode 5）
后缀数组版：s + '#' + reverse(s) 拼接
  奇数回文：中心 i → 比较 s[i..] 与 rev[n-1-i..] 的 LCP
  偶数回文：比较 s[i..] 与 rev[n-i..] 的 LCP
⚠️ 复杂度 O(n log n)；Manacher O(n) 更优——此题展示
   后缀数组的"通用性"（同一个结构解所有子串问题）
```

### 6.2 核心逻辑

```java
/** 后缀数组求最长回文子串（思路展示，实际推荐 Manacher） */
String longestPalindrome(String s) {
    int n = s.length();
    String rev = new StringBuilder(s).reverse().toString();
    String concat = s + "#" + rev;
    // 构建 sa/height + RMQ（任意两后缀 LCP O(1) 查询）

    int bestLen = 1, bestStart = 0;
    for (int i = 0; i < n; i++) {
        // 奇数回文：以 i 为中心
        int odd = lcp(rankOf(i), rankOf(2 * n - i));        // s[i..] vs rev[n-1-i..]
        if (2 * odd - 1 > bestLen) { ... }
        // 偶数回文：中心在 i 与 i+1 之间
        int even = lcp(rankOf(i), rankOf(2 * n - i + 1));   // s[i..] vs rev[n-i..]
        if (2 * even > bestLen) { ... }
    }
    return s.substring(bestStart, bestStart + bestLen);
}
// ⚠️ rankOf(k) = concat 中下标 k 的后缀排名（rank[sa[i]] = i）
//   两个后缀的 LCP = height 区间 RMQ（见 01 模块第 3 节）
// ⚠️ 面试表达："回文 = 正序后缀与逆序后缀的 LCP——
//   后缀数组一次构建，任意中心 O(1) 查询回文半径。
//   工程上 Manacher O(n) 才是答案，这里展示同构。"
```

## 7. 后缀数组 vs 滚动哈希：终极选型

### 7.1 对比总表

| 维度 | 滚动哈希 | 后缀数组 |
|------|:---:|:---:|
| 构建 | O(n) | O(n log n) |
| 子串比较 | O(1)（概率） | O(1)（RMQ，确定） |
| 最长重复子串 | 二分 + 哈希 O(n log n) | max(height) O(n) |
| 不同子串计数 | 枚举 O(n²) | 公式 O(n) |
| 多模式查询 | 哈希集合 | 二分定位 |
| 碰撞风险 | 有（双哈希缓解） | 无（确定） |
| 实现难度 | ★ 简单 | ★★★ 复杂 |

### 7.2 面试决策树

```
单题一次 → 滚动哈希（实现快，O(n log n) 足够）
多类查询 / 多次查询 → 后缀数组（一次构建全复用）
要求确定性（防碰撞） → 后缀数组 / 双哈希 + 验证
n 很大且只查一次 → 滚动哈希（构建快）
面试手写场景 → 滚动哈希（后缀数组讲思路即可）

⚠️ 面试表达：
"滚动哈希构建 O(n)、实现简单，是面试首选；
 后缀数组构建 O(n log n) 但一次构建后
 重复子串/公共子串/子串计数全部 O(n) 或 O(1) 查询——
 是'多查询场景'的最优解。"
```

## 8. 方法论总结

### 8.1 后缀数组应用四步

```
① 构建：倍增法 O(n log n)（sa + rank）
② 派生：height O(n)（h 不减引理）+ RMQ（可选）
③ 识别：题目要什么？
   最长重复 → max(height)
   不同子串 → Σ(n - sa[i] - height[i])
   公共子串 → 拼接 + 归属判断
   出现次数 → 二分定位区间
   回文 → 正逆拼接 + LCP
④ 输出：从 sa/height 还原具体子串（记录起点）

⚠️ 通用套路："任何子串问题 = sa 区间问题"
```

### 8.2 自测清单

```
□ 分隔符小于所有字符（多串拼接）？
□ height[0] = 0？
□ 归属判断用掩码/分段正确？
□ RMQ 取 min（不是 max）？
□ 输出子串时记录起点下标？
□ 面试先说"最优解后缀数组"再说"实现用哈希"？
```

### 8.3 复杂度速查

```
构建：O(n log n)（倍增）| O(n)（DC3/SA-IS，竞赛级）
height：O(n)
单次 LCP 查询：O(1)（ST 表预处理 O(n log n)）
子串出现次数：O(m log n)
不同子串数：O(n)（构建后）
最长重复子串：O(n)（构建后）
```

> 🎯 **核心要点**：后缀数组应用 = **max(height)**（最长重复）+ **Σ贡献公式**（不同子串）+ **拼接归属**（公共子串）+ **二分区间**（出现次数）+ **正逆拼接**（回文）。面试策略：会讲概念与公式，实现用滚动哈希——"最优解后缀数组、可写解滚动哈希"是标准话术。
