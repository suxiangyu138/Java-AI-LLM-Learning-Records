## 1. 核心概念

### 1.1 什么是后缀数组

> 后缀数组（Suffix Array）：字符串**所有后缀按字典序排序**后，记录每个后缀起始下标的数组。

```
s = "banana"
后缀：banana, anana, nana, ana, na, a

字典序排序：a, ana, anana, banana, na, nana
后缀数组 sa = [5, 3, 1, 0, 4, 2]
（对应起始下标 5,3,1,0,4,2）

配套概念：
  rank[i] = 后缀 i 的排名（sa 的逆）
  height[i] = sa[i] 与 sa[i-1] 的最长公共前缀（LCP）

应用公式：
  最长重复子串 = max(height)（相邻后缀的 LCP 最大）
  不同子串数 = Σ(n - sa[i] - height[i])
```

### 1.2 后缀数组能解决什么

```
① 最长重复子串：max(height) → O(n)
② 不同子串计数：Σ(n - sa[i] - height[i]) → O(n)
③ 子串出现次数：二分定位 sa 区间
④ 最长公共子串（两字符串）：拼接 + height

对比：
  滚动哈希 + 二分：O(n log n) 可解①（更简单）
  后缀数组：O(n log n) 一次构建解决所有
  → 后缀数组是"一劳永逸"但构建复杂
```

### 1.3 构建方法

```
朴素：所有后缀排序 → O(n² log n)（比较字符串 O(n)）

倍增法：O(n log n) ★ 主流
  第 k 轮：按前 2^k 个字符排序（利用上一轮排名）
  双关键字排序（第一关键字 + 第二关键字）

DC3/SA-IS：O(n)（竞赛级，超纲）

⚠️ 面试定位：后缀数组属于竞赛级算法
  面试几乎不要求手写 → 了解概念与应用即可
```

## 2. 代码模板

```java
/**
 * 后缀数组构建（倍增法）——了解思路即可
 * 第 k 轮：所有后缀按前 2^k 个字符排序
 * 双关键字：前半排名 + 后半排名
 */
public int[] buildSuffixArray(String s) {
    int n = s.length();
    int[] sa = new int[n];
    int[] rank = new int[n];
    int[] tmp = new int[n];

    // ① 初始化：按第一个字符排名
    for (int i = 0; i < n; i++) {
        sa[i] = i;
        rank[i] = s.charAt(i);
    }

    // ② 倍增：长度 1, 2, 4, 8...
    for (int k = 1; k < n; k *= 2) {
        // 双关键字排序：(rank[i], rank[i+k] 或 -1)
        int finalK = k;
        Integer[] boxed = new Integer[n];
        for (int i = 0; i < n; i++) boxed[i] = i;
        Arrays.sort(boxed, (a, b) -> {
            if (rank[a] != rank[b]) return rank[a] - rank[b];
            int ra = a + finalK < n ? rank[a + finalK] : -1;
            int rb = b + finalK < n ? rank[b + finalK] : -1;
            return ra - rb;
        });
        for (int i = 0; i < n; i++) sa[i] = boxed[i];

        // ③ 更新排名
        tmp[sa[0]] = 0;
        for (int i = 1; i < n; i++) {
            tmp[sa[i]] = tmp[sa[i - 1]]
                + (compare(s, sa[i - 1], sa[i], finalK) ? 1 : 0);
        }
        System.arraycopy(tmp, 0, rank, 0, n);
    }
    return sa;
}

/**
 * height 数组（LCP）：最长重复子串 = max(height)
 */
public int[] buildHeight(String s, int[] sa) {
    int n = s.length();
    int[] rank = new int[n];
    for (int i = 0; i < n; i++) rank[sa[i]] = i;

    int[] height = new int[n];       // height[i] = LCP(sa[i], sa[i-1])
    int h = 0;
    for (int i = 0; i < n; i++) {
        if (rank[i] > 0) {
            int j = sa[rank[i] - 1];
            while (i + h < n && j + h < n
                   && s.charAt(i + h) == s.charAt(j + h)) h++;
            height[rank[i]] = h;
            if (h > 0) h--;          // ⚠️ 经典优化：h 至少减 1
        }
    }
    return height;
}
```

## 4. 面试要点

```
① 后缀数组的复杂度？
   倍增法构建 O(n log n)（排序主导）
   height 构建 O(n)
   查询 O(log n)（二分定位）

② 与滚动哈希的选型？
   滚动哈希 + 二分：O(n log n)，实现简单 ★ 面试推荐
   后缀数组：一次构建多查询，实现复杂
   → 面试用哈希，后缀数组作为"更优方案"提及

③ 核心公式必背？
   最长重复子串 = max(height)
   不同子串数 = Σ(n - sa[i] - height[i])
   （height[i] = 与前一个后缀的 LCP）

④ 面试需要手写吗？
   基本不需要（竞赛级）
   能讲清概念 + 应用公式 = 足够

面试话术：
"这类题最优解是后缀数组——所有后缀排序后，
 相邻后缀的最长公共前缀（height）的最大值
 就是最长重复子串。构建 O(n log n)。
 面试实现我更倾向滚动哈希+二分（同样 O(n log n)
 但代码简单得多）。"
```

> 🎯 **核心要点**：后缀数组 = **sa（后缀排序）+ height（相邻 LCP）**两个概念 + 两个公式（最长重复=max(height)、不同子串=Σ(n-sa[i]-height[i])）。竞赛级算法，面试了解概念、会讲应用即可，实现用滚动哈希替代。
