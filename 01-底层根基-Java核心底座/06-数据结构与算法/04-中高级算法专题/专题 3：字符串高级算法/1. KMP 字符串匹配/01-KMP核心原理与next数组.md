## 1. KMP 模型：主串不回退

```text
问题: 在主串 s 中找模式串 p（O(n+m) 要求）
暴力: 失配后主串指针回退 → 最坏 O(nm)

KMP（Knuth-Morris-Pratt，1977）核心:
  失配时不回退主串指针（i 只前进）——
  利用"已匹配部分"的 border 信息，只回退模式串指针（j）

已匹配部分: s[i−j..i−1] == p[0..j−1]
失配时: 已匹配部分有"公共前后缀"——
  j 回退到最长公共前后缀长度 → 前缀已匹配，继续比

⚠️ 核心认知:
  "主串指针永不回退——'浪费的匹配'通过 border 复用"
```

> 🎯 **核心认知**："**KMP = '主串不回退、模式串按 border 回退'——已匹配部分的前后缀复用让每次失配都跳到'可能匹配'的位置**。O(n+m) 的来源：主串指针只前进、模式串指针回退总量 O(m)。"

## 2. border 概念：next 的本质

### 2.1 什么是 border

```text
border（公共前后缀）: 字符串的"真前缀 = 真后缀"的长度

例: p = "ababa"
  长度 3 的 border: "aba"（前缀 aba == 后缀 aba）✓
  长度 1 的 border: "a" ✓
  最长 border = 3

next[i] = p[0..i] 的最长 border 长度（前缀长度）
  next[i] 语义: "失配在 i+1 时，j 回退到 next[i]"

⚠️ 为什么 border 有用:
  匹配到 i 失配时，p[0..i−1] 已匹配——
  其最长 border（next[i−1]）就是"已经重新匹配好的前缀"
  → j 跳到 next[i−1] 继续比，不用从头来
```

### 2.2 失配跳转的直觉

```text
匹配: s = "ABABABC", p = "ABABC"
  匹配到 s[4]='A' vs p[4]='C' 失配
  已匹配 "ABAB"——最长 border "AB"（长度 2）
  → 主串不回头，j 跳到 2（"AB" 已匹配），继续比 s[4] vs p[2]='A' ✓

⚠️ 记忆: "失配 = 已匹配部分有 border——
  前缀已匹配，j 跳过去接着比"
```

## 3. next 数组构建（核心）

### 3.1 构建代码

```java
/**
 * next 数组构建: p 自我匹配
 * next[i] = p[0..i] 的最长 border 长度
 * 时间 O(m)
 */
int[] buildNext(String p) {
    int m = p.length();
    int[] next = new int[m];
    int j = 0;                                   // ① 当前最长 border

    for (int i = 1; i < m; i++) {
        // ② 失配回退: p[i] != p[j] → j 回退到 next[j−1]
        while (j > 0 && p.charAt(i) != p.charAt(j)) {
            j = next[j - 1];
        }
        if (p.charAt(i) == p.charAt(j)) {
            j++;                                 // ③ 匹配 → border +1
        }
        next[i] = j;                             // ④ 记录
    }
    return next;
}
// 推演 p = "ababa"：
//   i=1('b'): j=0 不匹配 → next[1]=0
//   i=2('a'): 匹配 j=0 → j=1 → next[2]=1
//   i=3('b'): 匹配 j=1 → j=2 → next[3]=2
//   i=4('a'): 匹配 j=2 → j=3 → next[4]=3
//   next = [0, 0, 1, 2, 3] ✓（"ababa" 最长 border = 3）
// ⚠️ 构建 = 模式串自我匹配——与匹配主流程同构（j 回退逻辑一致）
```

### 3.2 构建的自我匹配视角

```text
buildNext 本质: 用 KMP 自己匹配自己——
  主串 = p、模式串 = p（从 i=1 开始）
  失配时 j 回退到 next[j−1]（与匹配主流程相同）

⚠️ 记忆: "next 构建 = KMP 跑一遍自己——
   匹配主流程会了，构建自然就会"
```

> 🎯 **next 的灵魂**："**'构建 = 自我匹配'——buildNext 与匹配主流程共享完全相同的回退逻辑**。会匹配就会构建，会构建就会匹配：KMP 的两半是一回事。"

## 4. 匹配主流程

### 4.1 完整实现（28 题）

```java
/**
 * LeetCode 28. 找出字符串中第一个匹配项的下标（KMP）
 * 时间 O(n+m)，空间 O(m)
 */
public int strStr(String haystack, String needle) {
    int n = haystack.length(), m = needle.length();
    if (m == 0) return 0;
    int[] next = buildNext(needle);              // ① 先构建 next

    int j = 0;                                   // ② 模式串指针
    for (int i = 0; i < n; i++) {                // ③ 主串指针只前进！
        while (j > 0 && haystack.charAt(i) != needle.charAt(j)) {
            j = next[j - 1];                     // ④ 失配回退（主串不动）
        }
        if (haystack.charAt(i) == needle.charAt(j)) {
            j++;                                 // ⑤ 匹配 → 双进
        }
        if (j == m) return i - m + 1;            // ⑥ 完整匹配 → 返回起点
    }
    return -1;
}
// 推演 haystack="sadbutsad", needle="sad" → 0 ✓
//   haystack="leetcode", needle="leeto" → -1 ✓
// ⚠️ 主流程 = 构建 + 匹配两段——结构完全对称
```

### 4.2 主流程要点

```text
三步: ① 构建 next ② 主串循环（i 只进）③ 失配 j 回退

⚠️ 与暴力的差异:
  暴力: 失配 i 回退（重新从头匹配）
  KMP: 失配 j 回退（复用 border，i 不回）

记忆: "i 只前进、j 按 next 回退——这就是 KMP 的全部"
```

> 🎯 **KMP 的面试表达**："**'主串指针永不回退 + 模式串按 next 回退'——next[i] 是已匹配部分的最长公共前后缀，回退后前缀已匹配，继续比较即可**。能讲出 border 语义，KMP 就不是背代码。"

## 5. 逐步推演

**s = "ABABABCAB", p = "ABABC"**，next = [0,0,1,2,0]

| 步骤 | i | j | 比较 | 动作 |
|:---:|:---:|:---:|:---:|------|
| 1 | 0 | 0 | A==A ✓ | j=1 |
| 2 | 1 | 1 | B==B ✓ | j=2 |
| 3 | 2 | 2 | A==A ✓ | j=3 |
| 4 | 3 | 3 | B==B ✓ | j=4 |
| 5 | 4 | 4 | A vs C ✗ | j=next[3]=2（"AB" 已匹配） |
| 6 | 4 | 2 | A==A ✓ | j=3 |
| 7 | 5 | 3 | B==B ✓ | j=4 |
| 8 | 6 | 4 | C==C ✓ | j=5 == m → 返回 6−5+1=2 ✓ |

**结果**：匹配起点 2（s[2..6] = "ABABC"）✓

```text
观察: 第 5 步失配后 i 停在 4（不回退！）——
  j 从 4 回退到 2（"AB" 前缀已匹配）→ 第 6 步直接继续比
  省掉的比较 = border 复用的收益
```

## 6. 识别信号与易错点

### 6.1 识别信号

```text
"找子串/匹配 + O(n) 要求" → KMP
"重复子串/周期性" → KMP（686/459）
"字符串循环节" → KMP（len − next[len−1] 整除性）

⚠️ 面试定位: KMP 是字符串高频考点——
  28 题是手撕入场券；686 是变体
```

### 6.2 易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | next 构建忘回退 | `while (j > 0 && 不匹配)` | border 错 |
| 2 | 匹配循环忘回退 | 失配 `j = next[j−1]` | 退化为暴力 |
| 3 | next[j−1] 越界 | j > 0 前置 | 越界 |
| 4 | 空模式串 | m==0 返回 0 | 空指针 |
| 5 | 返回位置错 | `i − m + 1` | 起点偏移 |
| 6 | next 语义混淆 | next[i] = 最长 border 长度 | 回退错 |
| 7 | 循环节判断忘边界 | `n % (n−next[n−1]) == 0` | 误判周期 |

> 🎯 **核心要点**：KMP 通关四件事——**① border 语义**（最长公共前后缀）；**② 构建 = 自我匹配**；**③ 主流程**（i 只进、j 按 next 回退）；**④ 复杂度**（O(n+m)）。**KMP = '主串不回退'——'border 复用'四个字，就是它比暴力快的原因**。
