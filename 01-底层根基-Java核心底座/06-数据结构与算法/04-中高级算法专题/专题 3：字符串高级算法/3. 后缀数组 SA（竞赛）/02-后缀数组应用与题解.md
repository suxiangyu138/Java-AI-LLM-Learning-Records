## 1. 最长重复子串（max height）

### 1.1 题目与思路

**题**：字符串中出现至少两次的最长子串长度。

**原理**：相邻排名后缀最相似——最长重复子串出现在某对相邻后缀之间：

```java
/**
 * 最长重复子串 = max(height)
 * 原理: 出现两次的子串 = 某两个后缀的公共前缀
 *       最相似的（公共前缀最长）两个后缀排名相邻
 */
int longestRepeatedSubstring(String s) {
    int[] sa = buildSA(s);                       // ① 后缀排序
    int[] height = buildHeight(s, sa);           // ② 相邻 LCP

    int best = 0;
    for (int h : height) best = Math.max(best, h);   // ③ max height
    return best;
}
// 推演 "banana"：
//   height = [0, 1, 3, 0, 0, 2]（"ana" 与 "anana" LCP=3）
//   max = 3 → "ana" 出现两次 ✓
// ⚠️ 原理: 任何重复子串都是两个后缀的公共前缀——
//   "最相似"的后缀排名相邻（字典序性质）
```

> 🎯 **max height 的原理**："**'重复子串 = 两后缀的公共前缀' + '最相似的后缀排名相邻' → 最长重复 = max(height)**。字典序的连续性让'相邻即最相似'成立，这是后缀数组的经典性质。"

## 2. 两串最长公共子串（拼接 + 跨串）

### 2.1 题目与思路

**题**：两个字符串的最长公共子串。

**拼接 + 跨 # 相邻对**：

```java
/**
 * 两串 LCS（最长公共子串，SA 版）
 * s1 + '#' + s2 → 排序后找"跨 # 两侧"且 height 最大的相邻对
 */
int longestCommonSubstring(String s1, String s2) {
    String combined = s1 + "#" + s2;             // ① 拼接（# 分隔）
    int n1 = s1.length();

    int[] sa = buildSA(combined);
    int[] height = buildHeight(combined, sa);

    int best = 0;
    for (int i = 1; i < sa.length; i++) {
        // ② ⚠️ 跨 # 两侧: 一个来自 s1、一个来自 s2
        boolean left = sa[i - 1] < n1, right = sa[i] < n1;
        if (left != right) {                     // ③ 跨串相邻对
            best = Math.max(best, height[i]);
        }
    }
    return best;
}
// 推演 s1="abcdef", s2="bcde" → 4 ✓（"bcde"）
// ⚠️ # 的作用: 防止 LCP 跨越两串边界（# 与任何字符不同）
//   跨串条件: 相邻两个后缀一个来自 s1、一个来自 s2
```

> 🎯 **拼接技巧的通用性**："**'s1#s2 拼接 + 跨 # 相邻对'是后缀数组处理多串问题的标准套路**——# 分隔防跨串、跨串条件筛目标。两串 LCS 是后缀数组最经典的工程应用。"

## 3. 不同子串计数（height 差分）

### 3.1 题目与思路

**题**：字符串的不同子串个数。

**每个后缀贡献新子串 = 长度 − 与前驱的 LCP**：

```java
/**
 * 不同子串计数
 * 公式: Σ(sa[i] 的后缀长度 − height[i])
 *      = n(n+1)/2 − Σheight[i]
 */
long countDistinctSubstrings(String s) {
    int n = s.length();
    int[] sa = buildSA(s);
    int[] height = buildHeight(s, sa);

    long total = (long) n * (n + 1) / 2;         // ① 全部子串数
    for (int h : height) total -= h;             // ② 减去重复部分
    return total;
}
// 推演 "abab"：n(n+1)/2 = 10
//   height = [0, 2, 0, 1]（"ab" 与 "abab" LCP=2 等）
//   10 − (0+2+0+1) = 7 ✓（a,b,ab,ba,aba,bab,abab）
// ⚠️ 原理: 按排名顺序添加后缀——
//   新后缀的"新子串" = 自己的长度 − 与前面后缀重复的部分
//   重复部分 = 与排名前驱的 LCP（height）
```

> 🎯 **height 差分的原理**："**'新后缀贡献 = 长度 − height'——排名顺序添加后缀，重复的子串只与前驱共享**。n(n+1)/2 − Σheight 是后缀数组最优雅的公式之一。"

## 4. LCP 查询：RMQ 应用

### 4.1 任意两后缀 LCP

```java
/**
 * 任意两后缀 LCP（RMQ）
 * LCP(i, j) = min(height[rk[i]+1 .. rk[j]])（rk[i] < rk[j]）
 * 预处理 ST 表 → O(1) 查询
 */
int lcpQuery(int[] height, int[][] st, int i, int j) {
    int l = rk[i], r = rk[j];
    if (l > r) { int tmp = l; l = r; r = tmp; }
    // ⚠️ 区间 [l+1, r] 的最小 height
    int k = log2[r - l];
    return Math.min(st[l + 1][k], st[r - (1 << k) + 1][k]);
}
// 应用: 大量 LCP 查询（配合后缀数组的各类问题）
// ⚠️ ST 表: O(n log n) 预处理、O(1) 查询——
//   与 RMQ 通用模板相同（区间最值）
```

> 💡 **LCP 查询的复用**："**'LCP = 排名区间 height 最小值'把 LCP 变成标准 RMQ——ST 表 O(1) 查询**。后缀数组与 RMQ 的组合是竞赛常客（字符串 + 数据结构）。"

## 5. 后缀家族总览

| 应用 | 核心 | 复杂度 |
|:---:|:---:|:---:|
| 最长重复子串 | max(height) | O(n) |
| 两串 LCS | 拼接 + 跨串相邻 | O(n log n) |
| 不同子串计数 | n(n+1)/2 − Σheight | O(n) |
| 任意 LCP 查询 | 排名区间 RMQ | O(1) 查询 |
| 第 k 小子串 | 后缀序 + height 差分 | O(n) |
| 最长回文（SA 版） | 反转拼接 + LCP | O(n log n) |

```text
⚠️ 家族规律:
  "SA 负责排序、height 负责 LCP——
   一切应用 = 排序结果 + LCP 信息的组合"
```

## 6. 易错点与面试要点

### 6.1 易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 拼接忘 # | `s1 + '#' + s2` | LCP 跨串 |
| 2 | 跨串条件写反 | `left != right` 判跨串 | 漏/多计数 |
| 3 | 不同子串公式错 | `n(n+1)/2 − Σheight` | 计数错 |
| 4 | RMQ 区间开闭错 | `[l+1, r]` 不含 l | 边界错 |
| 5 | height 数组暴力求 | 相邻性质 O(n) | O(n²) |
| 6 | long 溢出 | 子串数用 long | int 溢出 |
| 7 | 排名互逆忘 | rk[sa[k]] = k | 查询错 |

### 6.2 面试要点

```text
① 定位: "后缀数组竞赛向——面试讲原理与应用即可"
② 复杂度: "倍增 + 基数 = O(n log n)"
③ 三公式: "max(height)/拼接跨串/不同子串"
④ 与哈希对比: "SA 是精确后缀工具；哈希更快但可能冲突"

⚠️ 高频追问: "后缀数组 vs 字符串哈希？"
  → "哈希 O(1) 子串比较但可能冲突（双哈希缓解）；
    SA 精确且能排序后缀（LCS/重复子串/不同子串），
    但构造 O(n log n) 更复杂——按需求选"
```

> 🎯 **核心要点**：后缀数组应用通关——**max height（重复子串）+ 拼接跨串（两串 LCS）+ height 差分（不同子串）+ RMQ（LCP 查询）**。四大应用共享"sa 排序 + height 信息"——"排序一次、LCP 万能"就是后缀家族的全部哲学。
