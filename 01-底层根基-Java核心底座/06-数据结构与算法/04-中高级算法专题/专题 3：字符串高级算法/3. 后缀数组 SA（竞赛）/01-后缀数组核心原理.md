## 1. 后缀数组模型：sa/rk/height

```text
后缀: s[i..n−1]（共 n 个后缀）
后缀数组 SA: 所有后缀按字典序排序后的下标顺序
  sa[k] = 排名第 k 的后缀的起始下标

排名数组 rk: 后缀的排名
  rk[i] = 起始下标 i 的后缀的排名
  sa 与 rk 互逆: rk[sa[k]] = k

height 数组: 相邻排名后缀的 LCP（最长公共前缀）
  height[k] = LCP(sa[k−1], sa[k])

⚠️ 三个数组的关系:
  sa: "谁排第几" → 字典序排序
  rk: "我排第几" → 排名查询
  height: "相邻有多像" → LCP 一切应用的基础

例: s = "banana"
  后缀: banana, anana, nana, ana, na, a
  排序: a(5), ana(3), anana(1), banana(0), na(4), nana(2)
  sa = [5, 3, 1, 0, 4, 2]
```

> 🎯 **核心认知**："**后缀数组 = '后缀的字典序排序'——sa/rk/height 三数组把'所有后缀的比较'变成'可查询的排名与 LCP'**。一切后缀问题（LCS/重复子串/不同子串）都建立在它之上。"

## 2. 倍增构造思想

### 2.1 倍增排序（O(n log n)）

```text
朴素: 比较 n 个后缀（O(n² log n)）——不可行
倍增: 按"长度 1, 2, 4, 8..."的双关键字排序——

第 k 轮: 比较每个后缀的前 2^k 个字符
  第一关键字: 前 2^(k−1) 个字符的排名（上轮结果）
  第二关键字: 后 2^(k−1) 个字符的排名（上轮结果）
  双关键字排序 → 前 2^k 个字符的排名

终止: 所有排名互不相同（或达到 n）→ 排序完成
轮数: O(log n) 轮

⚠️ 核心: "每轮翻倍比较范围——用上轮排名作本轮的比较键"
```

### 2.2 伪代码骨架

```java
// 倍增构造骨架
int[] buildSA(String s) {
    int n = s.length();
    int[] sa = new int[n], rk = new int[n];

    // ① 初始: 按单字符排序
    // ② 倍增: for (k = 1; k < n; k <<= 1)
    //    - 第一关键字 = rk[i]
    //    - 第二关键字 = rk[i + k]（越界视为最小）
    //    - 双关键字基数排序 → 新 rk
    // ③ 排名全异 → 终止

    return sa;
}
// ⚠️ 完整实现 ~40 行（竞赛向）——
//   面试只需讲清"倍增 + 双关键字"思想
```

> 🎯 **倍增的直觉**："**'每轮比较长度翻倍，上轮排名当下轮键'——2^k 字符的比较拆成两个 2^(k−1) 的排名比较**。O(log n) 轮 × O(n) 排序 = O(n log n)。"

## 3. 基数排序优化

### 3.1 为什么用基数排序

```text
双关键字排序的选择:
  比较排序: O(n log n)/轮 × log n 轮 = O(n log² n)
  基数排序: O(n)/轮 × log n 轮 = **O(n log n)**

基数排序优势: 键值域是"排名"（≤ n）——
  计数排序 O(n + 值域) = O(n) ✓

⚠️ 实现: 先按第二关键字排、再按第一关键字排（稳定）
  经典技巧: 第二关键字 = "后半段起点排序"的自然顺序
```

### 3.2 复杂度

```text
倍增轮数: O(log n)
每轮: 基数排序 O(n)（计数排序按排名值域）
总: O(n log n) 时间、O(n) 空间

⚠️ 竞赛替代: SA-IS / DC3 可到 O(n)——
  面试/竞赛初学用倍增即可

记忆: "倍增 O(log n) 轮 × 基数 O(n) = O(n log n)"
```

> 💡 **基数排序的定位**："**后缀数组的 O(n log n) 来自'倍增 × 基数'——比较排序会多一个 log**。基数排序按'排名'值域计数，是构造速度的关键。"

## 4. height/LCP 数组

### 4.1 定义与求法

```text
height[i] = LCP(sa[i−1], sa[i])——相邻排名后缀的公共前缀

性质: 任意两个后缀的 LCP = 排名区间内 height 的最小值（RMQ）
  LCP(sa[l], sa[r]) = min(height[l+1..r])

求法: O(n) 的"相邻性质"——
  height[rk[i]] ≥ height[rk[i−1]] − 1（相邻后缀的 LCP 递减缓慢）
  → 总扩展量 O(n)

⚠️ 核心: height 数组 O(n) 可求（利用相邻性质），
  一切 LCP 查询变成 RMQ（区间最小值）
```

### 4.2 height 的三种用途

```text
① LCP 查询: 任意两后缀的 LCP = 区间 min（RMQ 预处理）
② 最长重复子串: max(height)（相邻排名 = 最相似的两个后缀）
③ 不同子串计数: 总子串数 − Σheight[i]
   （每个后缀贡献的新子串 = 长度 − 与前驱的 LCP）

⚠️ 公式: 不同子串数 = n(n+1)/2 − Σheight[i]
```

> 🎯 **height 的价值**："**'任意后缀 LCP = 区间 RMQ、最长重复 = max(height)、不同子串 = n(n+1)/2 − Σheight'——height 是后缀数组从'排序'到'解题'的桥**。三公式是后缀数组应用的灵魂。"

## 5. 核心应用公式

| 应用 | 公式/方法 | 复杂度 |
|------|------|:---:|
| 最长公共子串（两串） | 拼接 + 跨串相邻 height 最大 | O(n log n) |
| 最长重复子串 | max(height) | O(n) |
| 不同子串计数 | n(n+1)/2 − Σheight | O(n) |
| 任意 LCP 查询 | 排名区间 RMQ | O(1) 查询 |
| 第 k 小子串 | 后缀按序 + height 差分 | O(n) |

```text
⚠️ 拼接技巧: 两串求 LCS 时——
  s1 + '#' + s2（# 分隔防跨串匹配）
  找"跨 # 两侧"且 height 最大的相邻对
```

## 6. 识别信号与易错点

### 6.1 识别信号

```text
"所有后缀/子串 + 字典序/排名" → 后缀数组
"最长公共子串/重复子串" → SA + height
"不同子串计数/第 k 小子串" → SA + height 公式
"LCP 大量查询" → SA + RMQ

⚠️ 面试定位: 竞赛向（NOI 级）——
  面试提到"后缀数组 O(n log n) 可求 LCS/重复子串"即可
  手写倍增是竞赛要求，面试讲原理
```

### 6.2 易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 拼接忘分隔符 | `s1 + '#' + s2` | 跨串匹配 |
| 2 | height 求法暴力 | 相邻性质 O(n) | O(n²) 退化 |
| 3 | LCP 区间开闭错 | `min(height[l+1..r])` | 边界错 |
| 4 | 不同子串公式错 | `n(n+1)/2 − Σheight` | 计数错 |
| 5 | 基数排序不稳定 | 先第二键再第一键 | 排序错 |
| 6 | 越界后缀处理 | 越界视为最小（0） | 排序错 |
| 7 | 复杂度讲成 O(n log²n) | 基数 = O(n log n) | 面试失分 |

> 🎯 **核心要点**：后缀数组通关四件事——**① sa/rk/height 三数组语义**；**② 倍增 + 基数 = O(n log n)**；**③ height 三公式**（LCP RMQ/重复子串/不同子串）；**④ 拼接技巧**（# 分隔）。**后缀数组 = '后缀排序 + LCP 查询'——'sa 排序、height 解题'八个字，就是后缀家族的全部应用**。
