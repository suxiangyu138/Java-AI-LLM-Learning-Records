## 1. 二分查找 = 单侧分治

### 1.1 位置关系

```
二分查找 = 分治的特例：
  拆分：对半（O(1)）
  解决：只递归包含答案的一侧（O(log n)）
  合并：无（O(1)）

⚠️ 与快选的对比：
  快选：partition 后单侧递归 → O(n)（因为 partition 是 O(n)）
  二分：mid 判断后单侧递归 → O(log n)（因为判断是 O(1)）

关系图：
  分治（拆-解-合）
    ├─ 归并型（两侧 + 合并）→ n log n
    └─ 单侧型（丢弃一半）→ 快选 O(n) / 二分 O(log n)
```

### 1.2 二分的前提（面试必答）

```
① 单调性：序列有序（或某种单调性质）
② 二段性：能 O(1) 判断"去左还是去右"

⚠️ 常见误区：
  "数组有序才能二分" 过于狭窄——正确说法是：
  "存在单调性质 + 可 O(1) 判定去留方向"即可二分
  例：峰值问题（无序！）但两侧趋势可判定
```

### 1.3 二分四要素

```
① 搜索空间 [lo, hi]：闭区间 / 左闭右开？选一种贯穿到底
② 判定函数 mid：如何判断去左/去右
③ 收缩方向：lo = mid+1 / hi = mid（取决于模板）
④ 终止与返回：lo > hi？返回 lo / hi / 哨兵

⚠️ 工程铁律：写二分必须先定模板，全程一致
  推荐：while (lo < hi) + 收缩留 mid（见下节）
```

## 2. 二分模板与边界变体

### 2.1 两大模板对比

```java
/** 模板一：while (lo <= hi)——标准查找（值可能不存在） */
int binarySearch(int[] nums, int target) {
    int lo = 0, hi = nums.length - 1;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;          // ⚠️ 防溢出写法
        if (nums[mid] == target) return mid;
        if (nums[mid] < target) lo = mid + 1;
        else                    hi = mid - 1;
    }
    return -1;                                 // 不存在
}

/** 模板二：while (lo < hi)——边界收缩（答案必然存在） */
int searchRange(int[] nums, int target) {
    // 找第一个 >= target 的位置（lower_bound）
    int lo = 0, hi = nums.length;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (nums[mid] >= target) hi = mid;     // ⚠️ 满足 → 保留 mid
        else                     lo = mid + 1;
    }
    return lo;                                 // 第一个满足位置（或 n）
}
// 模板二变体：
//   最后一个 <= target：mid 满足 → lo = mid（mid 不排除）
//     注意：mid = lo + (hi-lo+1)/2（⚠️ 上取整防死循环）
```

### 2.2 边界变体全家（34. 在排序数组中查找元素位置）

```java
/**
 * LeetCode 34. 查找 target 的起止位置
 * 两次二分：lower_bound（第一个 ≥）与 upper_bound（第一个 >）
 */
public int[] searchRange(int[] nums, int target) {
    int first = lowerBound(nums, target);
    if (first == nums.length || nums[first] != target) return new int[]{-1, -1};
    return new int[]{first, upperBound(nums, target) - 1};
}

private int lowerBound(int[] nums, int t) {   // 第一个 >= t
    int lo = 0, hi = nums.length;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (nums[mid] >= t) hi = mid;
        else lo = mid + 1;
    }
    return lo;
}

private int upperBound(int[] nums, int t) {   // 第一个 > t
    int lo = 0, hi = nums.length;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (nums[mid] > t) hi = mid;
        else lo = mid + 1;
    }
    return lo;
}
// ⚠️ 变体速查：
//   第一个 >= t   → lowerBound
//   第一个 > t    → upperBound
//   最后一个 <= t → upperBound - 1
//   最后一个 < t  → lowerBound - 1
```

## 3. 33. 旋转数组搜索

### 3.1 题目与思路

```
旋转数组 [4,5,6,7,0,1,2]：整体有序但发生了旋转（两段递增）
mid 将数组分成两段，必有一段有序：
  左段有序（nums[lo] <= nums[mid]）：
    target 在 [lo, mid] → 去左；否则去右
  右段有序（否则）：
    target 在 (mid, hi] → 去右；否则去左
⚠️ 核心：每次至少丢弃一半（利用"必有一半有序"）
```

### 3.2 完整代码

```java
/**
 * LeetCode 33. 搜索旋转排序数组
 */
public int search(int[] nums, int target) {
    int lo = 0, hi = nums.length - 1;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;
        if (nums[mid] == target) return mid;

        if (nums[lo] <= nums[mid]) {               // ⚠️ 左段有序
            if (nums[lo] <= target && target < nums[mid])
                hi = mid - 1;                      // target 在左段
            else
                lo = mid + 1;                      // 去右段
        } else {                                   // ⚠️ 右段有序
            if (nums[mid] < target && target <= nums[hi])
                lo = mid + 1;                      // target 在右段
            else
                hi = mid - 1;                      // 去左段
        }
    }
    return -1;
}
// 推演 [4,5,6,7,0,1,2], target=0：
//   mid=3(7)：左段有序 [4..7]，0 不在 → lo=4
//   mid=5(1)：右段有序？nums[4]=0 <= nums[5]=1 → 左段有序 [0,1]
//     0 <= 0 < 1 → hi=4 → mid=4(0) == target ✓
// ⚠️ 变体 81：含重复元素 → 无法判断哪段有序时 lo++（退化为 O(n)）
```

## 4. 153. 旋转数组最小值

### 4.1 题目与思路

```
旋转数组找最小值（唯一）
性质：最小值是"右段起点"——第一个小于 nums[hi] 的元素？不——
  最小值特征是：nums[i] < nums[0] 的"第一个位置"（若整体有序则是 nums[0]）

判定：
  nums[mid] < nums[hi] → mid 及右侧递增 → 最小值在左（含 mid）
  nums[mid] > nums[hi] → 左段大 → 最小值在右（不含 mid）
```

### 4.2 完整代码

```java
/**
 * LeetCode 153. 寻找旋转排序数组中的最小值
 */
public int findMin(int[] nums) {
    int lo = 0, hi = nums.length - 1;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (nums[mid] < nums[hi]) {
            hi = mid;                     // ⚠️ 右段递增 → 最小值在 [lo, mid]
        } else {
            lo = mid + 1;                 // mid 在左段 → 最小值在 (mid, hi]
        }
    }
    return nums[lo];
}
// 推演 [3,4,5,1,2]：
//   mid=2(5)：5 > 2 → lo=3
//   mid=3(1)：1 < 2 → hi=3 → 返回 1 ✓
// ⚠️ 判断基准选 nums[hi]（而非 nums[lo]）的原因：
//   无旋转时 nums[lo] 判定会直接排除最小值（nums[lo] < nums[hi] 也成立）
//   而 nums[hi] 判定能统一处理两种情形
// ⚠️ 变体 154：含重复 → 相等时 hi--（最坏 O(n)）
```

## 5. 162. 寻找峰值

### 5.1 题目与思路

```
任意峰值：nums[i] > 左右邻居（边界视为 -∞）
数组无序！为什么能二分？
  关键性质：nums[mid] < nums[mid+1] → 右侧必有峰值
            nums[mid] > nums[mid+1] → 左侧必有峰值（含 mid）
⚠️ 这是"二段性"而非"有序性"——二分判定的本质是方向性
```

### 5.2 完整代码

```java
/**
 * LeetCode 162. 寻找峰值
 * ⚠️ 无序也能二分：上升趋势的一侧必然存在峰值
 */
public int findPeakElement(int[] nums) {
    int lo = 0, hi = nums.length - 1;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (nums[mid] < nums[mid + 1]) {
            lo = mid + 1;          // 上升 → 峰值在右侧
        } else {
            hi = mid;              // 下降 → 峰值在左侧（含 mid）
        }
    }
    return lo;
}
// 推演 [1,2,1,3,5,6,4]：
//   mid=3(3)：3 < 5 上升 → lo=4
//   mid=5(6)：6 > 4 下降 → hi=5
//   mid=4(5)：5 < 6 上升 → lo=5 → 返回 5（值 6）✓
// 正确性：上升段终点必然有峰值（边界视为 -∞，一直上升则端点即峰）
// ⚠️ 变体：852 山脉数组峰值（更简单，单峰）
```

> 🎯 **峰值题的启示**：二分不要求数组有序，只要求**方向可判定**——"每走一步能确定答案在哪一侧"。这是从"二分查找"到"二分答案"的思想桥梁。

## 6. 二分答案：最优化 → 判定

### 6.1 核心框架

```
二分答案 = 对"答案值域"二分，而非对数组下标二分

适用特征（四条件）：
  ① 答案是一个数值（最小最大/第 K）
  ② 答案有单调性：答案越大（越小）可行性单调
  ③ 可行解可 O(n)/O(k) 验证
  ④ 值域连续（整数二分）或可枚举

模板：
  lo = 最小可能答案，hi = 最大可能答案
  while (lo < hi):
      mid = (lo + hi) / 2
      if 可行(mid):  hi = mid     // 找最小可行解
      else:          lo = mid + 1
  return lo
⚠️ 关键：check(mid) 是"判定"，单调性保证二分正确
```

### 6.2 二分答案 vs 二分查找

| 维度 | 二分查找 | 二分答案 |
|------|---------|---------|
| 二分对象 | 数组下标 | 答案值域 |
| 判定 | 比较 nums[mid] | check(mid) 可行性 |
| 前提 | 有序/二段性 | 答案单调 |
| 复杂度 | O(log n) | O(log 值域 × check) |
| 典型 | 34/33/162 | 410/875/378 |

```
⚠️ 识别信号：
  "最大值最小化 / 最小值最大化" → 二分答案
  "第 K 小（有序结构）" → 二分答案或堆
  "速度/能力/阈值的最优" → 二分答案
```

## 7. 378. 有序矩阵第 K 小

### 7.1 题目与思路

```
行、列分别升序的 n×n 矩阵，找第 K 小的元素
方案：
  ① 堆（多路归并）：O(k log n)（k 接近 n² 时退化）
  ② 二分答案 ⭐：值域二分 + 计数
     check(mid)：矩阵中 ≤ mid 的元素个数 ≥ k？
     ⚠️ 计数技巧：从左下角出发，利用行列有序 O(n)
```

### 7.2 完整代码

```java
/**
 * LeetCode 378. 有序矩阵中第 K 小的元素（二分答案）
 * 答案范围 [matrix[0][0], matrix[n-1][n-1]]
 */
public int kthSmallest(int[][] matrix, int k) {
    int n = matrix.length;
    int lo = matrix[0][0], hi = matrix[n - 1][n - 1];

    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (countLessOrEqual(matrix, mid) >= k) {
            hi = mid;                     // ⚠️ 满足 → 答案 ≤ mid
        } else {
            lo = mid + 1;
        }
    }
    return lo;
}

/** ⭐ 计数：矩阵中 ≤ target 的个数（左下角出发 O(n)） */
private int countLessOrEqual(int[][] matrix, int target) {
    int n = matrix.length;
    int i = n - 1, j = 0;                 // 从左下角开始
    int count = 0;
    while (i >= 0 && j < n) {
        if (matrix[i][j] <= target) {
            count += i + 1;               // ⚠️ 该列上方的 i+1 个都 ≤ target
            j++;                          // 右移
        } else {
            i--;                          // 上移（值变小）
        }
    }
    return count;
}
// 复杂度：O(n·log(max-min))——计数 O(n)，二分 log 值域
// ⚠️ 妙处：二分的是"值"不是"下标"，矩阵无需完全有序
//   （只有行列有序 → 左下角计数 O(n) 技巧）
```

## 8. 410. 分割数组的最大值

### 8.1 题目与思路

```
把数组分成 m 段，使"各段和的最大值"最小（最大值最小化）
二分答案：
  答案范围 [max(单元素), sum(全部)]
  check(mid)：能否分成 ≤ m 段，且每段和 ≤ mid？（贪心计数）
⚠️ 单调性：段上限 mid 越大 → 能分的段越少 → 可行性单调
```

### 8.2 完整代码

```java
/**
 * LeetCode 410. 分割数组的最大值（二分答案 + 贪心 check）
 */
public int splitArray(int[] nums, int m) {
    int lo = 0, hi = 0;
    for (int x : nums) {
        lo = Math.max(lo, x);             // ⚠️ 下界：至少是最大单元素
        hi += x;                          // 上界：不分段（一段总和）
    }

    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (canSplit(nums, m, mid)) {
            hi = mid;                     // 可行 → 尝试更小的段上限
        } else {
            lo = mid + 1;
        }
    }
    return lo;
}

/** 贪心：每段尽可能装（≤ limit），统计最少分段数 */
private boolean canSplit(int[] nums, int m, int limit) {
    int segments = 1, curSum = 0;
    for (int x : nums) {
        if (curSum + x > limit) {         // 装不下 → 开新段
            segments++;
            curSum = x;
            if (segments > m) return false;
        } else {
            curSum += x;
        }
    }
    return segments <= m;
}
// 推演 [7,2,5,10,8], m=2 → 答案 18（[7,2,5] [10,8]）
//   二分 lo=10 hi=32 → mid=21 可行 → 18 可行 → 17 不可行（10+8>17 需 3 段）
// 复杂度：O(n·log(总和))
// ⚠️ 同类：875 吃香蕉（速度二分）、1011 运输能力（同构题）
```

> 🎯 **二分答案四件套**：定值域（lo/hi）→ 写 check（贪心/计数）→ 验证单调 → 收缩方向（可行则收上界）。410/875/1011/1482 全是同一模板。

## 9. 面试要点与追问

### 9.1 面试话术模板

```
"二分=单侧分治：mid 判定后丢弃一半搜索空间。
 这题是二分答案——答案值域单调，check(mid) 可行则收上界。
 【check 实现】。复杂度 O(【log 值域 × check】)。
 写二分先定模板：while(lo<hi) + 收缩方向与 mid 取整一致。"
```

### 9.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 二分的前提？ | 二段性（方向可判定），不必须有序 |
| 2 | lo<hi 与 lo<=hi 区别？ | 边界收缩模板 vs 标准查找模板 |
| 3 | mid 溢出？ | lo + (hi-lo)/2；上取整时 +1 防死循环 |
| 4 | 旋转数组怎么二分？ | 必有一半有序，判断 target 在哪个区间 |
| 5 | 峰值为什么能二分？ | 无序也有二段性：上升侧必有峰 |
| 6 | 二分答案怎么识别？ | 最大值最小化/第 K 小/速度阈值 |
| 7 | check 怎么写？ | 贪心分段/计数，验证单调性 |
| 8 | 二分答案复杂度？ | O(log 值域 × check 代价) |

### 9.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| mid 下取整 + lo=mid | 死循环 | lo=mid 时必须上取整 |
| 旋转数组判断区间写反 | 答案错 | 先判哪段有序再定位 |
| 二分答案下界设 0 | 多算一层（无害但慢） | 设 max(元素) |
| check 里计数漏边界 | 判定错 | 段数 > m 提前返回 |
| 模板混用 | 边界错乱 | 一种模板贯穿到底 |

> 🎯 **核心要点**：二分 = 单侧分治，前提是"方向可判定"而非"有序"。三大应用：**边界查找**（lower/upper bound）、**结构二分**（旋转/峰值）、**二分答案**（值域二分 + 单调 check）。410/378/875 共用一个模板。
