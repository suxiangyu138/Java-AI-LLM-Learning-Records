## 1. 归并排序：递归版与迭代版

### 1.1 递归版（教科书标准）

```java
/**
 * 归并排序（递归版）
 * 拆两半 → 各自排序 → 合并有序
 * 时间 O(n log n)（每层合并 O(n)，log n 层）
 * 空间 O(n)（辅助数组）
 */
void mergeSort(int[] nums, int lo, int hi, int[] tmp) {
    if (lo >= hi) return;                     // 基线：0/1 个元素

    int mid = lo + (hi - lo) / 2;
    mergeSort(nums, lo, mid, tmp);            // ① 拆：左半
    mergeSort(nums, mid + 1, hi, tmp);        // ② 拆：右半

    // ③ 合并（核心）
    int i = lo, j = mid + 1, k = lo;
    while (i <= mid && j <= hi) {
        if (nums[i] <= nums[j]) tmp[k++] = nums[i++];   // ⚠️ <= 保证稳定
        else                    tmp[k++] = nums[j++];
    }
    while (i <= mid) tmp[k++] = nums[i++];    // 左半剩余
    while (j <= hi)  tmp[k++] = nums[j++];    // 右半剩余
    System.arraycopy(tmp, lo, nums, lo, hi - lo + 1);   // 写回
}
// ⚠️ 稳定性：nums[i] <= nums[j] 时取左 → 相同值左先 → 稳定 ✓
// ⚠️ 空间优化：全程复用同一个 tmp 数组（不要每层新建）
```

### 1.2 自底向上迭代版（省递归栈）

```java
/**
 * 归并排序（自底向上）
 * 从长度 1 的块开始，两两合并，块长翻倍
 * ⚠️ 无递归 → 无栈溢出风险，工程实用
 */
void mergeSortIterative(int[] nums) {
    int n = nums.length;
    int[] tmp = new int[n];
    for (int len = 1; len < n; len <<= 1) {          // 块长 1,2,4,8...
        for (int lo = 0; lo < n; lo += len * 2) {    // 每对块
            int mid = Math.min(lo + len - 1, n - 1);
            int hi = Math.min(lo + len * 2 - 1, n - 1);
            if (mid < hi) merge(nums, lo, mid, hi, tmp);  // 合并两个有序块
        }
    }
}
// 推演 [3,1,4,2]：
//   len=1：合并 (0,1)→[1,3]，(2,3)→[2,4] → [1,3,2,4]
//   len=2：合并 (0,3)→[1,2,3,4] ✓
// ⚠️ 边界：mid、hi 都要防越界（min 夹紧）
```

### 1.3 归并排序的三个工程细节

| 细节 | 作用 |
|------|------|
| 小规模转插入排序（< 16） | 减少递归开销（TimSort 同款思路） |
| 共享临时数组 | 空间 O(n) 而非 O(n log n) |
| 判断两半是否已有序 | 有序则跳过合并（对近似有序输入加速） |

## 2. 148. 排序链表

### 2.1 思路

```
链表排序（O(n log n)）只能归并（快排链表需要随机访问）
  ① 快慢指针找中点（拆半）
  ② 递归排序两半
  ③ 21 题合并两个有序链表
⚠️ 不能直接套数组归并：链表取中点需 O(n) 扫描
```

### 2.2 完整代码

```java
/**
 * LeetCode 148. 排序链表（归并 + 快慢指针）
 */
public ListNode sortList(ListNode head) {
    if (head == null || head.next == null) return head;   // 基线

    // ① 快慢指针找中点（slow 停在前半末尾）
    ListNode slow = head, fast = head.next;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    ListNode rightHead = slow.next;       // 后半头
    slow.next = null;                     // ⚠️ 断开两半！

    // ② 递归排序
    ListNode left = sortList(head);
    ListNode right = sortList(rightHead);

    // ③ 合并（21 题模板）
    return mergeTwoLists(left, right);
}

private ListNode mergeTwoLists(ListNode a, ListNode b) {
    ListNode dummy = new ListNode(0), tail = dummy;
    while (a != null && b != null) {
        if (a.val <= b.val) { tail.next = a; a = a.next; }
        else                { tail.next = b; b = b.next; }
        tail = tail.next;
    }
    tail.next = (a != null) ? a : b;
    return dummy.next;
}
// 复杂度：O(n log n)，空间 O(log n)（递归栈，无辅助数组——链表合并是原地改指针）
// ⚠️ 与数组归并对比：数组 O(n) 空间（辅助数组）；链表 O(log n)（无需辅助）
```

## 3. 逆序对计数：归并的统计天赋

### 3.1 核心思想

```
归并过程中，右半元素 j 被取走时：
  左半剩余元素 [i..mid] 都大于 nums[j]
  → 逆序对数量 += mid - i + 1（本次合并的贡献）

⚠️ 关键认知：排序与统计一举两得
  排序保证：比较时两半内部有序 → 可批量计数（而非逐个比）
  统计后：正常归并（顺序不变）→ 不影响排序结果
```

```java
/**
 * 剑指 Offer 51. 数组中的逆序对（归并计数模板）
 */
int count = 0;

public int reversePairs(int[] nums) {
    int[] tmp = new int[nums.length];
    mergeSort(nums, 0, nums.length - 1, tmp);
    return count;
}

private void mergeSort(int[] nums, int lo, int hi, int[] tmp) {
    if (lo >= hi) return;
    int mid = lo + (hi - lo) / 2;
    mergeSort(nums, lo, mid, tmp);
    mergeSort(nums, mid + 1, hi, tmp);
    merge(nums, lo, mid, hi, tmp);
}

private void merge(int[] nums, int lo, int mid, int hi, int[] tmp) {
    int i = lo, j = mid + 1, k = lo;
    while (i <= mid && j <= hi) {
        if (nums[i] <= nums[j]) {
            tmp[k++] = nums[i++];
        } else {
            // ⚠️ ⭐ 统计：左半剩余 [i..mid] 全部 > nums[j]
            count += mid - i + 1;
            tmp[k++] = nums[j++];
        }
    }
    while (i <= mid) tmp[k++] = nums[i++];
    while (j <= hi)  tmp[k++] = nums[j++];
    System.arraycopy(tmp, lo, nums, lo, hi - lo + 1);
}
// 推演 [7,5,6,4]：
//   合并 (7,5)：5 取走时 i=0 → count += 1 → 7>5
//   合并 (6,4)：count += 1
//   合并 (5,7,4,6)：4 取走时 i=0 → count += 2（5,7>4）
//                  6 取走时 i=1 → count += 1（7>6）
//   总 = 1+1+2+1 = 5 ✓（(7,5)(7,6)(7,4)(5,4)(6,4)）
```

### 3.2 归并计数的变体家族

| 题目 | 统计条件 | 修改点 |
|------|---------|--------|
| 51 逆序对 | nums[i] > nums[j] | 基础模板 |
| 493 翻转对 | nums[i] > 2·nums[j] | 合并前先扫一遍统计（乘 2 不破坏序） |
| 315 右侧更小 | nums[i] > nums[j] 记下标 | 统计时带原始下标 |

> 🎯 **模板价值**：凡是"统计跨左右两半的二元关系"（大小、倍数、距离）→ 归并计数模板。先统计后归并，两不误。

## 4. 快速排序：两种分区

### 4.1 Lomuto 分区（简单，面试首选）

```java
/**
 * 快速排序（Lomuto 分区：单指针遍历 + 交换）
 * 基准 = 末尾元素，i 指向"小于区"边界
 */
void quickSort(int[] nums, int lo, int hi) {
    if (lo >= hi) return;
    int p = partition(nums, lo, hi);
    quickSort(nums, lo, p - 1);      // 左侧（< 基准）
    quickSort(nums, p + 1, hi);      // 右侧（> 基准）
}

int partition(int[] nums, int lo, int hi) {
    int pivot = nums[hi];            // 取末尾为基准
    int i = lo;                      // < pivot 区的下一个位置
    for (int j = lo; j < hi; j++) {
        if (nums[j] < pivot) {       // 发现小于基准的
            swap(nums, i, j);        // 换入小于区
            i++;
        }
    }
    swap(nums, i, hi);               // 基准归位
    return i;                        // 基准最终位置
}
```

### 4.2 Hoare 分区（双指针相向）

```java
/**
 * Hoare 分区：双指针相向扫描，交换两侧逆序对
 * ⚠️ 优点：交换次数更少、常数更小（工程首选）
 * ⚠️ 注意：返回值不是基准位置，而是"分界点"
 */
int partitionHoare(int[] nums, int lo, int hi) {
    int pivot = nums[lo + (hi - lo) / 2];   // 取中点为基准
    int i = lo, j = hi;
    while (true) {
        while (nums[i] < pivot) i++;        // 左边找 ≥ pivot
        while (nums[j] > pivot) j--;        // 右边找 ≤ pivot
        if (i >= j) return j;               // ⚠️ 返回分界
        swap(nums, i, j);
        i++; j--;
    }
}
```

| 对比 | Lomuto | Hoare |
|------|:---:|:---:|
| 实现 | 简单（单指针） | 稍复杂（双指针） |
| 交换次数 | 多（约 3 倍） | 少 |
| 递归边界 | p-1 / p+1（基准归位） | lo..j / j+1..hi（分界） |
| 适用 | 教学/快选（返回基准位） | 工程性能 |

## 5. 快排的退化与随机化

### 5.1 退化分析

```
有序数组 + 取末尾基准：
  partition 每次只分出 1 个（其余全在一边）
  → 递归深度 n → O(n²)

⚠️ 与 BST 退化的同构性：
  快排的递归树 = 基准元素构成的 BST
  有序输入 → 基准形成链 → 树退化 → O(n²)
  （与 [01 分治核心框架] 中"随机数据平均 1.39·log n"同理）
```

### 5.2 三种抗退化手段

```java
// ① 随机基准（最常用）：概率上不可能总选到最坏位置
int idx = lo + new Random().nextInt(hi - lo + 1);
swap(nums, hi, idx);            // 换到末尾，走 Lomuto

// ② 三数取中：lo、mid、hi 的中位数做基准（对有序输入友好）
int mid = lo + (hi - lo) / 2;
if ((nums[lo] < nums[mid]) != (nums[lo] < nums[hi])) swap(nums, lo, hi);
else if ((nums[mid] < nums[lo]) != (nums[mid] < nums[hi])) swap(nums, mid, hi);

// ③ 单侧递归：先递归小半，大半迭代（防栈溢出，压到 O(log n)）
while (lo < hi) {
    int p = partition(nums, lo, hi);
    if (p - lo < hi - p) { quickSort(nums, lo, p - 1); lo = p + 1; }
    else                 { quickSort(nums, p + 1, hi); hi = p - 1; }
}
```

> 🎯 **面试必答**："随机化基准后，期望复杂度 O(n log n) 与输入分布无关——最坏 O(n²) 的概率趋近于 0（但理论最坏仍在）。"

## 6. 三路快排：处理重复元素

### 6.1 问题背景

```
大量重复元素（如全是 0/1）时：
  普通快排将重复元素全部堆到一侧 → 仍退化 O(n²)
  三路快排：分成 < pivot、== pivot、> pivot 三区
  → 等于区不动，只递归两侧 → 重复多时接近 O(n)
```

### 6.2 实现（荷兰国旗问题）

```java
/**
 * 三路快排（荷兰国旗分区）
 * [lo, lt) < pivot；[lt, gt] == pivot；(gt, hi] > pivot
 */
void quickSort3(int[] nums, int lo, int hi) {
    if (lo >= hi) return;
    int lt = lo, gt = hi, i = lo + 1;
    int pivot = nums[lo];                  // 基准

    while (i <= gt) {
        if (nums[i] < pivot) {             // 小于 → 换到左区
            swap(nums, i++, lt++);
        } else if (nums[i] > pivot) {      // 大于 → 换到右区
            swap(nums, i, gt--);           // ⚠️ i 不前进（换来的还没看）
        } else {
            i++;                           // 等于 → 留在中间
        }
    }
    quickSort3(nums, lo, lt - 1);          // 只递归小于区
    quickSort3(nums, gt + 1, hi);          // 只递归大于区
}
// 推演 [2,1,2,2,3,2]：
//   一趟后：<2 区 [1]，==2 区 [2,2,2,2]，>2 区 [3]
//   只递归 [1] 与 [3] → 剩余 O(n) ✓
// ⚠️ 应用：75. 颜色分类（荷兰国旗）、大量重复数据排序
```

## 7. 归并 vs 快排：全维度对比

| 维度 | 归并排序 | 快速排序 |
|------|:---:|:---:|
| 时间复杂度 | O(n log n) 稳定 | 期望 O(n log n)，最坏 O(n²) |
| 空间 | O(n)（辅助数组） | O(log n)（递归栈，原地） |
| 稳定性 | ✅ 稳定 | ❌ 不稳定 |
| 缓存友好 | 顺序访问（缓存好） | 随机跳转（缓存差） |
| 外部排序 | ✅（磁盘归并） | ❌ |
| 链表排序 | ✅ | ❌（需随机访问） |
| 工程应用 | TimSort 的合并部分、外部排序 | Java Arrays.sort(primitive) 用双轴快排 |

```
选型口诀：
  需要稳定 → 归并（对象排序默认稳定）
  内存敏感 → 快排（原地）
  链表/外部 → 归并
  原始类型 → 快排（无稳定需求，常数小）

⚠️ 工程事实（Java）：
  Arrays.sort(Object[]) → TimSort（归并+插入混合）
  Arrays.sort(int[])     → DualPivotQuickSort（双轴快排）
```

## 8. 面试要点与追问

### 8.1 面试话术模板

```
"排序用归并/快排：归并稳定 O(n log n) 但要 O(n) 辅助空间，
 适合链表和外部排序；快排原地期望 O(n log n)，
 随机化基准防退化，但不稳定。
 这题需要【稳定/原地/链表】→ 选【归并/快排】。"
```

### 8.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 归并为什么稳定？ | 相等时取左侧元素（<= 比较） |
| 2 | 快排退化？ | 有序输入 + 固定基准 → O(n²)；随机化/三数取中 |
| 3 | 归并空间？ | O(n) 辅助数组（递归栈仅 O(log n)） |
| 4 | 逆序对怎么统计？ | 归并时右元素取走 → 左剩余个数即逆序对 |
| 5 | Lomuto vs Hoare？ | 单指针简单 vs 双指针交换少 |
| 6 | 三路快排？ | 分三区（< == >），重复元素多时接近 O(n) |
| 7 | 链表排序？ | 归并（快慢指针拆半），数组归并 O(n) 空间、链表 O(log n) |
| 8 | Java 用哪个？ | 对象 TimSort（稳定）；原始类型双轴快排 |

### 8.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 归并每层新建辅助数组 | 空间 O(n log n) | 全程复用 |
| 快排固定末尾基准 + 有序输入 | O(n²) | 随机化 |
| 逆序对统计忘加 mid-i+1 | 漏计 | 右取走时批量加 |
| 链表排序忘断开两半 | 死循环/错序 | slow.next = null |
| 三路快排 i 不前进（大于区） | 漏元素 | 换入右区时 i 不动 |

---

> 🎯 **核心要点**：归并（稳定 + O(n) 空间）与快排（原地 + 期望 O(n log n)）是分治的双峰。逆序对计数是归并的"统计天赋"（排序+计数一举两得）；随机化与三路分区是快排的两道护身符。
