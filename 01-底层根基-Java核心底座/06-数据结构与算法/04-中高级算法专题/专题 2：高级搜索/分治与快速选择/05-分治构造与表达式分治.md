## 1. 构造类分治的识别

### 1.1 题型特征

```
⚠️ 识别信号：
  "返回所有可能的..."（枚举全部结构）→ 分治构造
  "根据规则重建..."（给定一个规则）→ 递归构造
  "加括号的所有结果"（表达式）→ 分治 + 记忆化

与普通分治的区别：
  普通分治：返回一个最优值/统计量（int/boolean）
  构造分治：返回一组结构（List<TreeNode> / List<String>）
```

### 1.2 构造类分治的统一模式

```
分治构造 = 选"分点" + 左右子问题 + 笛卡尔积组合

  以 i 为根/分点 → 左侧子问题产出的结构 × 右侧子问题产出的结构
  → 组合生成当前层的所有结构

⚠️ 三层结构：
  ① 遍历所有可能的分点（for 循环）
  ② 递归获取两侧结构列表
  ③ 两两组合（笛卡尔积）加入结果
```

### 1.3 为什么这类题常用"记忆化"

```
分治构造的子问题可能重叠：
  95：G(3) 的左子树结构与另一个 G(3) 的右子树结构相同
  241：同一个子表达式被多个括号方案重复计算

⚠️ 识别信号：
  "子结构被重复构造" → 用 Map 缓存（分治 → 自顶向下 DP）
```

## 2. 95. 不同的二叉搜索树 II

### 2.1 题目与思路

```
返回 1..n 能构成的所有 BST（96 题只问数量，95 题要全部结构）
分治构造：
  以 i 为根 → 左子树用 [1..i-1] 的所有结构，右子树用 [i+1..n] 的所有结构
  → 笛卡尔积组合（每个左 × 每个右）
⚠️ 与 96 的关系：96 的 G(n) = ΣG(i-1)·G(n-i)，95 就是把每个 G 展开成 List
```

### 2.2 完整代码

```java
/**
 * LeetCode 95. 不同的二叉搜索树 II
 * 分治构造：根 i + 左右结构列表 + 笛卡尔积
 * ⚠️ 记忆化：区间 [lo, hi] 的结果可缓存（子问题重叠）
 */
Map<String, List<TreeNode>> memo = new HashMap<>();

public List<TreeNode> generateTrees(int n) {
    return build(1, n);
}

private List<TreeNode> build(int lo, int hi) {
    List<TreeNode> res = new ArrayList<>();
    if (lo > hi) {                        // ⚠️ 空区间返回 [null]（组合时用到）
        res.add(null);
        return res;
    }
    String key = lo + "," + hi;
    if (memo.containsKey(key)) return memo.get(key);   // 记忆化

    for (int i = lo; i <= hi; i++) {      // ① 遍历分点（根）
        List<TreeNode> lefts = build(lo, i - 1);       // ② 左侧结构
        List<TreeNode> rights = build(i + 1, hi);      // ② 右侧结构
        for (TreeNode L : lefts) {                    // ③ 笛卡尔积
            for (TreeNode R : rights) {
                res.add(new TreeNode(i, L, R));       // 组合
            }
        }
    }
    memo.put(key, res);
    return res;
}
// n=3 的结果（5 种，与 96 的卡特兰数一致）：
//   [1,null,2,null,3]  [1,null,3,2]  [2,1,3]  [3,1,null,null,2]  [3,2,null,1]
// ⚠️ 关键细节：空区间返回 [null] 而非空列表——
//   否则"无左子树"的情况无法参与笛卡尔积
```

> 🎯 **易错点**：`build(lo, i-1)` 中 lo > hi 时返回 `[null]`（含空树），而不是空列表。这是构造类分治的通用细节。

## 3. 241. 为运算表达式设计优先级

### 3.1 题目与思路

```
"2-1-1" → 加括号的所有结果：[0, 2]（(2-1)-1=0，2-(1-1)=2）
分治构造：
  每个运算符都是"分点"：
    左子表达式的结果 × 右子表达式的结果 → 用该运算符组合
⚠️ 运算符分割 → 表达式天然可以分治（左半、右半独立计算）
⚠️ 记忆化：同一个子表达式被多个方案重复计算
```

### 3.2 完整代码

```java
/**
 * LeetCode 241. 为运算表达式设计优先级（分治 + 记忆化）
 */
Map<String, List<Integer>> memo = new HashMap<>();

public List<Integer> diffWaysToCompute(String expression) {
    if (memo.containsKey(expression)) return memo.get(expression);

    List<Integer> res = new ArrayList<>();
    boolean hasOp = false;

    for (int i = 0; i < expression.length(); i++) {
        char c = expression.charAt(i);
        if (!Character.isDigit(c)) {                  // ⚠️ 运算符 = 分点
            hasOp = true;
            List<Integer> left = diffWaysToCompute(expression.substring(0, i));
            List<Integer> right = diffWaysToCompute(expression.substring(i + 1));

            for (int a : left)                        // 笛卡尔积
                for (int b : right) {
                    res.add(c == '+' ? a + b
                          : c == '-' ? a - b : a * b);   // 组合
                }
        }
    }

    if (!hasOp) res.add(Integer.parseInt(expression));  // ⚠️ 纯数字：基线
    memo.put(expression, res);
    return res;
}
// 推演 "2-1-1"：
//   分点 '-'（下标1）：左 "2"=[2]，右 "1-1"=[0]
//     2-0=2 → 加入
//   分点 '-'（下标3）：左 "2-1"=[1]，右 "1"=[1]
//     1-1=0 → 加入
//   结果 [2, 0] ✓
// ⚠️ 注意：递归深度 = 运算符个数，substring 开销可用下标区间优化
```

> 🎯 **本质**：241 = 卡特兰数结构（加括号方案数 = 卡特兰数）——运算符个数为 n 时，括号方案是卡特兰数 C(n)。分治枚举的就是这棵括号树的全部形态。

## 4. 654. 最大二叉树

### 4.1 题目与思路

```
数组 → 最大二叉树：最大值是根，左右子数组递归构造
分治构造：
  ① 区间找最大值（分点 = 最大值位置）
  ② 左区间递归 = 左子树，右区间递归 = 右子树

⚠️ 复杂度：每次找最大 O(区间长) → 最坏 O(n²)（降序数组）
   → 可用单调栈优化 O(n)（进阶，面试加分）
```

### 4.2 完整代码

```java
/**
 * LeetCode 654. 最大二叉树
 */
public TreeNode constructMaximumBinaryTree(int[] nums) {
    return build(nums, 0, nums.length - 1);
}

private TreeNode build(int[] nums, int lo, int hi) {
    if (lo > hi) return null;                // 基线：空区间

    // ① 区间找最大值及其下标（分点）
    int maxIdx = lo;
    for (int i = lo + 1; i <= hi; i++)
        if (nums[i] > nums[maxIdx]) maxIdx = i;

    // ② 递归构造左右子树
    TreeNode root = new TreeNode(nums[maxIdx]);
    root.left = build(nums, lo, maxIdx - 1);
    root.right = build(nums, maxIdx + 1, hi);
    return root;
}
// 推演 [3,2,1,6,0,5]：最大值 6（下标3）为根
//   左 [3,2,1] → 3 为根 → 右子树 [2,1] → 2 → 右 [1]
//   右 [0,5] → 5 为根 → 左 [0]
// ⚠️ 复杂度：最坏 O(n²)（有序数组每层扫 O(n)）；单调栈 O(n) 是进阶解法
```

## 5. 构造家族：前/中/后序重建二叉树

### 5.1 三种组合一览

| 已知遍历 | 能否唯一重建 | 关键 | 代表题 |
|---------|:---:|------|--------|
| 前序 + 中序 | ✅ | 前序首位=根，中序划分 | 105 |
| 中序 + 后序 | ✅ | 后序末位=根，中序划分 | 106 |
| 前序 + 后序 | ⚠️ 不唯一（但可重建一种） | 前序首=根，后序末=根 | 889 |
| 前序/后序 + 空标记 | ✅（含 null 的序列化） | 空节点标记 | 297 |

```
⚠️ 为什么"前序+后序"不唯一？
  前序 根 左... 右...，后序 ...左 ...右 根
  若只有左子树，前序=根+左，后序=左+根 → 无法区分左右
  例：前序 [1,2]、后序 [2,1] → 2 是左孩子还是右孩子？两种都合法

⚠️ 统一模板（105/106）：
  ① 前序首位（或后序末位）定位根
  ② 哈希表 O(1) 在中序中找根
  ③ leftSize = 根下标 - inLo → 划分子树区间
```

### 5.2 106. 中序 + 后序构造（与 105 对称）

```java
/**
 * LeetCode 106. 从中序与后序遍历序列构造二叉树
 * ⚠️ 与 105 对称：后序末位是根，左子树大小同样用中序定位
 */
Map<Integer, Integer> idxMap = new HashMap<>();

public TreeNode buildTree(int[] inorder, int[] postorder) {
    for (int i = 0; i < inorder.length; i++) idxMap.put(inorder[i], i);
    return build(postorder, 0, postorder.length - 1,
                 inorder, 0, inorder.length - 1);
}

private TreeNode build(int[] post, int poLo, int poHi,
                       int[] in, int inLo, int inHi) {
    if (poLo > poHi) return null;

    int rootVal = post[poHi];                    // ⚠️ 后序末位 = 根
    TreeNode root = new TreeNode(rootVal);
    int rootIdx = idxMap.get(rootVal);           // 中序定位根

    int leftSize = rootIdx - inLo;               // 左子树大小

    root.left = build(post, poLo, poLo + leftSize - 1,        // 后序左段
                      in, inLo, rootIdx - 1);
    root.right = build(post, poLo + leftSize, poHi - 1,       // 后序右段
                       in, rootIdx + 1, inHi);
    return root;
}
// ⚠️ 口诀："先定根（前首/后末），中序分两半，leftSize 划区间"
```

## 6. 分治构造的通用模板

### 6.1 两类构造模板

```java
/** 模板 A：全枚举构造（返回结构列表，95/241） */
List<Node> buildAll(区间) {
    List<Node> res = new ArrayList<>();
    if (基线) return [基线结构];
    if (记忆化命中) return 缓存;
    for (分点 : 所有可能分点) {
        List<Node> lefts = buildAll(左区间);
        List<Node> rights = buildAll(右区间);
        for (L : lefts) for (R : rights) res.add(组合(L, R));  // 笛卡尔积
    }
    return res;
}

/** 模板 B：单结构构造（返回一个结构，654/105/108） */
Node buildOne(区间) {
    if (空区间) return null;
    定位根/分点;                       // 最大元素/前序首位/中位数
    Node root = new Node(...);
    root.left = buildOne(左区间);
    root.right = buildOne(右区间);
    return root;
}
```

### 6.2 模板选型表

| 特征 | 模板 A | 模板 B |
|------|:---:|:---:|
| 返回 | 全部结构列表 | 单一结构 |
| 分点 | 遍历所有（for） | 规则确定（一个） |
| 组合 | 笛卡尔积 | 拼接 |
| 记忆化 | 常用（子结构复用） | 不需要（无重叠） |
| 代表 | 95、241、894 | 654、105、108、109 |

## 7. 卡特兰数与分治构造

### 7.1 为什么构造数量是卡特兰数

```
n 个节点 BST 数量 = 卡特兰数 C(n) = C(2n,n)/(n+1)
n 个运算符的括号方案数 = 卡特兰数

递推：C(n) = Σ C(i-1)·C(n-i)   （i = 1..n）
  —— 与分治构造的递归完全同构：
  枚举分点 i → 左子问题规模 i-1 × 右子问题规模 n-i

⚠️ 面试表达：
"'所有可能的 X'的数量往往是卡特兰数——
 因为枚举分点 + 左右组合的结构就是卡特兰递推。
 96 题问数量（卡特兰 DP），95 题要结构（分治构造）。"
```

### 7.2 卡特兰数的识别信号

| 场景 | 卡特兰数？ |
|------|:---:|
| n 个节点二叉树数量 | ✅ C(n) |
| n 对括号合法序列 | ✅ C(n) |
| n 个元素出栈序列数 | ✅ C(n) |
| n+1 个叶子满二叉树 | ✅ C(n) |
| 凸 n+2 边形三角剖分 | ✅ C(n) |
| n×n 网格不越对角线路径 | ✅ C(n) |

## 8. 面试要点与追问

### 8.1 面试话术模板

```
"构造类分治：枚举每个可能的分点（根/运算符），
 递归构造左右子结构，再笛卡尔积组合。
 子结构会重复出现，所以加记忆化（退化为自顶向下 DP）。
 空区间要返回 [null]（空结构）参与组合。"
```

### 8.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 构造类怎么识别？ | 返回全部可能结构 / 按规则重建 |
| 2 | 为什么空区间返回 [null]？ | 空结构要参与笛卡尔积（无左子树也是一种方案） |
| 3 | 为什么加记忆化？ | 子问题重叠（同一区间/子表达式反复构造） |

### 8.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 空区间返回空列表 | 组合结果缺"无子树"方案 | 返回 [null] |
| 构造类不记忆化 | 指数爆炸 | Map 缓存区间/子串 |
| leftSize 计算错 | 子树划分错 | rootIdx - inLo |
| 241 忘解析纯数字 | 递归死循环 | 无运算符时 parseInt |
| 笛卡尔积只取一个左 | 漏结构 | 双层循环全组合 |
