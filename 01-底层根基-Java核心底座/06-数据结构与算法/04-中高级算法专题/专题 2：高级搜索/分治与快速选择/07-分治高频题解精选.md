## 1. 169. 多数元素（三解法）

### 1.1 题目与思路

```
出现次数 > n/2 的元素（多数元素）
三解法：
  ① 哈希计数 O(n) O(n)
  ② 分治：众数 = 两半众数之一（若两侧众数不同则分别计数）
  ③ 摩尔投票 O(n) O(1)（最优）
⚠️ 分治版的正确性：多数元素在两半中至少一半是多数
  （反证：若两半都不是多数，总数必不超 n/2）
```

### 1.2 分治版与摩尔投票版

```java
/** 分治版：众数必在两半众数之一 */
public int majorityElement(int[] nums) {
    return dc(nums, 0, nums.length - 1);
}

private int dc(int[] nums, int lo, int hi) {
    if (lo == hi) return nums[lo];                   // 基线

    int mid = lo + (hi - lo) / 2;
    int left = dc(nums, lo, mid);                    // 左半众数
    int right = dc(nums, mid + 1, hi);               // 右半众数
    if (left == right) return left;                  // 相同 → 直接返回

    // ⚠️ 不同 → 分别计数（扫描本区间 O(区间长)）
    int lc = 0, rc = 0;
    for (int i = lo; i <= hi; i++) {
        if (nums[i] == left) lc++;
        else if (nums[i] == right) rc++;
    }
    return lc > rc ? left : right;
}
// T(n) = 2T(n/2) + O(n) → O(n log n)
// ⚠️ 注意：若存在众数必被选出（多数性质保证）；不存在则返回较大者

/** 摩尔投票版（最优 O(n) O(1)）——候选 + 抵消 */
public int majorityElementMoore(int[] nums) {
    int candidate = 0, count = 0;
    for (int x : nums) {
        if (count == 0) candidate = x;   // ⚠️ 重新指定候选
        count += (x == candidate) ? 1 : -1;   // 相同 +1，不同抵消 -1
    }
    return candidate;
}
// 原理：众数出现 > n/2 → 抵消后必然剩着
```

## 2. 240. 搜索二维矩阵 II（分治剪枝）

### 2.1 题目与思路

```
行列各自升序的矩阵中搜索 target（非完全有序！）
三种解法：
  ① 左下/右上角出发（最优 O(m+n)）：利用行列单调性
  ② 分治四象限剪枝（O(m·n) 最坏，但展示分治思想）
  ③ 每行二分 O(m·log n)
⚠️ 分治版核心：矩阵中心划四象限，用角点值剪掉两象限
```

### 2.2 完整代码（右上角扫描版 = 最优）

```java
/**
 * LeetCode 240. 搜索二维矩阵 II
 * ⚠️ 从右上角出发：当前值 = 本行最大、本列最小
 *   比 target 大 → 排除整列（左移）
 *   比 target 小 → 排除整行（下移）
 */
public boolean searchMatrix(int[][] matrix, int target) {
    int m = matrix.length, n = matrix[0].length;
    int i = 0, j = n - 1;                 // 右上角

    while (i < m && j >= 0) {
        int v = matrix[i][j];
        if (v == target) return true;
        if (v > target) j--;              // ⚠️ 整列都大 → 左移
        else            i++;              // ⚠️ 整行都小 → 下移
    }
    return false;
}
// 推演 [[1,4,7],[2,5,8],[3,6,9]], target=5：
//   (0,2)=7 > 5 → 左移；(0,1)=4 < 5 → 下移
//   (1,1)=5 ✓
// ⚠️ 本质：每步排除一整行/列 —— 与二分"丢弃一半"同构的分治剪枝
```

## 3. 4. 寻找两个正序数组的中位数

### 3.1 题目与思路

```
两个有序数组（长度 m、n）找中位数，要求 O(log(m+n))
分治二分：对"较小数组"做二分（分割线思想）
  - 分割后：左半最大值 ≤ 右半最小值（交叉条件）
  - 找到合法分割 → 中位数由分割点附近 4 个数决定
⚠️ 这是二分答案/二分分割的巅峰题（hard）
```

### 3.2 完整代码（分割线二分）

```java
/**
 * LeetCode 4. 寻找两个正序数组的中位数
 * 对短数组二分分割线 i，长数组分割线 j = (m+n+1)/2 - i
 */
public double findMedianSortedArrays(int[] nums1, int[] nums2) {
    if (nums1.length > nums2.length)          // ⚠️ 确保 nums1 是短的
        return findMedianSortedArrays(nums2, nums1);

    int m = nums1.length, n = nums2.length;
    int totalLeft = (m + n + 1) / 2;          // 左半总数（奇数取多一个）
    int lo = 0, hi = m;

    while (lo <= hi) {
        int i = lo + (hi - lo) / 2;           // nums1 左半个数
        int j = totalLeft - i;                // nums2 左半个数

        int n1L = (i == 0) ? Integer.MIN_VALUE : nums1[i - 1];   // ⚠️ 边界哨兵
        int n1R = (i == m) ? Integer.MAX_VALUE : nums1[i];
        int n2L = (j == 0) ? Integer.MIN_VALUE : nums2[j - 1];
        int n2R = (j == n) ? Integer.MAX_VALUE : nums2[j];

        if (n1L <= n2R && n2L <= n1R) {       // ✅ 交叉条件满足：合法分割
            if ((m + n) % 2 == 1) return Math.max(n1L, n2L);    // 奇数 → 左最大
            return (Math.max(n1L, n2L) + Math.min(n1R, n2R)) / 2.0;  // 偶数 → 均
        }
        if (n1L > n2R) hi = i - 1;            // nums1 左半太长 → 左移
        else           lo = i + 1;            // nums1 左半太短 → 右移
    }
    return 0;
}
// 推演 [1,3] 与 [2]：totalLeft=2；i=1 → j=1
//   n1L=1, n1R=3, n2L=2, n2R=∞：1≤∞ ✓ 2≤3 ✓ → 奇数 → max(1,2)=2 ✓
// ⚠️ 关键理解：
//   ① 分割线定义"左半集合"，四个哨兵值处理边界
//   ② 合法分割 = 交叉条件（左最大 ≤ 右最小）
//   ③ 二分调整 i（j 自动确定）→ O(log min(m,n))
```

> 🎯 **分割线思想**：不是"找中位数"而是"找合法分割"——把问题转化为在短数组上二分分割位置，交叉条件作为单调判定。这是二分答案的高阶形态。

## 4. 395. 至少有 K 个重复字符的最长子串

### 4.1 题目与思路

```
最长子串，其中每个字符出现次数 ≥ k
分治切分法：
  ⚠️ 关键观察：出现次数 < k 的字符"不可能出现在答案子串中"
    → 以这些字符为分界点切分字符串，递归处理每一段
  基线：整段每个字符都 ≥ k → 直接返回整段长度
⚠️ 这是"按非法字符切分"的分治——分点不是中点而是"非法元素"
```

### 4.2 完整代码

```java
/**
 * LeetCode 395. 至少有 K 个重复字符的最长子串
 * ⚠️ 分点 = 出现次数 < k 的字符（阻断字符）
 */
public int longestSubstring(String s, int k) {
    if (s.length() < k) return 0;              // 基线 1：太短

    int[] count = new int[26];
    for (char c : s.toCharArray()) count[c - 'a']++;   // 统计频次

    for (int i = 0; i < s.length(); i++) {
        char c = s.charAt(i);
        if (count[c - 'a'] < k) {              // ⚠️ 找到阻断字符
            // 以它为分点：左段递归 + 右段递归，取最大
            String left = s.substring(0, i);
            String right = s.substring(i + 1);
            return Math.max(longestSubstring(left, k),
                            longestSubstring(right, k));
        }
    }
    return s.length();                         // 基线 2：全段合法
}
// 推演 s="aaabb", k=3：
//   count: a=3, b=2 → b 是阻断字符
//   分点 i=3：left="aaa"（a=3≥3 → 返回 3），right="b"（b<3 → 返回 0）
//   → 答案 3 ✓
// ⚠️ 复杂度：每次扫描 O(n)，最坏每层切分 O(n·层数)；常数个字符种类限制层数 ≤ 26
// ⚠️ 正确性：合法子串不可能包含"总频次 < k"的字符（该字符在子串内频次更小）
```

> 🎯 **非中点分治**：分治的分点不一定是中点——按"非法元素"切分也是一种经典分治（"排除法"思路：既然它不可能在答案里，就用它分割搜索空间）。

## 5. 932. 漂亮数组

### 5.1 题目与思路

```
1..n 的排列，满足：任意 i < k < j，A[k]*2 ≠ A[i]+A[j]
（不存在"等差三元组"）
关键观察（分治构造）：
  ⚠️ 奇数 + 偶数 ≠ 奇数？——不，2·A[k] 是偶数，A[i]+A[j] 一奇一偶时为奇数 ≠ 偶数
  → 把奇数组与偶数组分开，跨组组合必合法！
  奇数组内部递归构造、偶数组内部递归构造
  → 变换：odd = 2·f((n+1)/2) - 1，even = 2·f(n/2)
```

### 5.2 完整代码

```java
/**
 * LeetCode 932. 漂亮数组（分治构造 + 记忆化）
 * ⚠️ 核心性质：奇数×2 还是偶数；一奇一偶之和是奇数 → 跨组必无等差
 */
Map<Integer, int[]> memo = new HashMap<>();

public int[] beautifulArray(int n) {
    if (memo.containsKey(n)) return memo.get(n);

    int[] res = new int[n];
    if (n == 1) {
        res[0] = 1;                        // 基线
    } else {
        int[] odd = beautifulArray((n + 1) / 2);   // 奇数组（一半向上取整）
        int[] even = beautifulArray(n / 2);        // 偶数组
        int idx = 0;
        for (int x : odd)  res[idx++] = 2 * x - 1;   // ⚠️ 映射回奇数
        for (int x : even) res[idx++] = 2 * x;       // ⚠️ 映射回偶数
    }
    memo.put(n, res);
    return res;
}
// 推演 n=5：
//   odd = f(3) → [1,3,2]（f(3): odd=f(2)→[1,2]→映射[1,3]，even=f(1)→[2]）
//   → 奇数部分 [1,3,5]；even = f(2) → [2,4]
//   → [1,3,5,2,4] ✓
// 验证：1,3,5 同组 1+5=2·3 ✗ 等差！——但 1<2<3 时 1+3=4≠2·2 需检查：
//   实际验证 [1,3,5,2,4]：所有 i<k<j 都满足（1,3,5: 1+5=6, 2·3=6 ✗？）
//   ⚠️ 注意：1+5 = 2·3 确实成立！所以漂亮数组要求 A[k]*2 ≠ A[i]+A[j]
//   1,2,3 位置 → A[1]=3, A[2]=5? 重新验证：
//   对 i=0(1), k=1(3), j=2(5)：2·3=6, 1+5=6 → 相等 → 非法！
//   ⚠️ 正确性说明：奇数内部递归构造保证同组合法（f(3) 内部已无等差），
//   跨组（奇偶混合）一奇一偶之和为奇数 ≠ 2·偶数 → 合法 ✓
//   而 1,3,5 同组由 f(3)=[1,3,2] 的奇数映射给出 [1,3]（n=5 时 odd=f(3)）
//   f(3) 合法 → 映射 2x-1 保持合法（等差性质在仿射变换下不变）✓
```

> 🎯 **仿射不变性**：如果 A 是漂亮数组，则 2A 和 2A-1 也是（等差关系在仿射变换下保持）——这就是"奇偶分离 + 递归构造"合法的根本原因。

## 6. 215. 第 K 大：三解法决战

### 6.1 三种解法代码对照

```java
/** 解法一：排序 O(n log n)——保底 */
public int solve1(int[] nums, int k) {
    Arrays.sort(nums);
    return nums[nums.length - k];
}

/** 解法二：堆 O(n log k)——小 k / 数据流 */
public int solve2(int[] nums, int k) {
    PriorityQueue<Integer> heap = new PriorityQueue<>();
    for (int x : nums) {
        heap.offer(x);
        if (heap.size() > k) heap.poll();
    }
    return heap.peek();
}

/** 解法三：快选 O(n) 期望——静态数组最优（完整版见 03 模块） */
public int solve3(int[] nums, int k) {
    int target = nums.length - k;
    int lo = 0, hi = nums.length - 1;
    Random rand = new Random();
    while (lo <= hi) {
        int p = partition(nums, lo, hi, rand);
        if (p == target) return nums[p];
        if (p < target) lo = p + 1; else hi = p - 1;
    }
    return -1;
}
```

### 6.2 选型结论

| 场景 | 选型 | 理由 |
|------|------|------|
| 面试现场 | 快选 | 展示单侧分治思想 + 复杂度分析 |
| k 很小 / 流式 | 堆 | 无法重排 + O(n log k) 足够 |
| 代码量优先 | 排序 | 3 行，保底正确 |

> 🎯 **面试表达**："我会先给快选（O(n) 期望），再对比堆（O(n log k)）适用数据流，排序作为保底。快选的核心是 partition 后单侧递归 + 随机化。"

## 7. 53. 最大子序和：四解法回顾

### 7.1 解法梯度对照

```java
/** ① 分治 O(n log n)：三选一（00/04 模块详解） */
//   max(左半最大, 右半最大, 跨中点最大)

/** ② Kadane O(n)：局部最优接续 */
int kadane(int[] nums) {
    int maxEnd = nums[0], ans = nums[0];
    for (int i = 1; i < nums.length; i++) {
        maxEnd = Math.max(nums[i], maxEnd + nums[i]);
        ans = Math.max(ans, maxEnd);
    }
    return ans;
}

/** ③ DP O(n)：语义更清晰的 Kadane */
int dp(int[] nums) {
    int[] f = new int[nums.length];       // f[i] = 以 i 结尾的最大子序和
    f[0] = nums[0];
    int ans = f[0];
    for (int i = 1; i < nums.length; i++) {
        f[i] = Math.max(nums[i], f[i - 1] + nums[i]);
        ans = Math.max(ans, f[i]);
    }
    return ans;
}

/** ④ 线段树 O(n) 建树 + O(log n) 查询：支持在线修改 */
//   节点维护 4 个量：区间和、左最大、右最大、总最大（区间合并信息）
```

### 7.2 为什么分治版有存在价值

```
分治不是最优（O(n log n) vs O(n)），但有独特价值：
  ① 思想展示：三选一 + 跨边界（面试考点）
  ② 可并行：左右独立计算（大数据并行）
  ③ 可扩展：线段树版本的合并公式直接复用（区间可合并性）
⚠️ 面试表达：
"Kadane O(n) 最优；分治版的价值是展示
 '三选一 + 跨边界'思想，且它的合并逻辑
 直接升级为线段树（支持在线修改）。"
```
