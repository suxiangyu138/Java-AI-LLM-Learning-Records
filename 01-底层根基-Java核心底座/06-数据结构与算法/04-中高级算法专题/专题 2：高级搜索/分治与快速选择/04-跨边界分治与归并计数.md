## 1. 跨边界问题家族识别

### 1.1 什么是跨边界问题

```
最优解/统计结果可能"横跨分界点"——不完整落在某一半内：
  最大子序和：最优区间 [i,j] 可能跨过 mid
  区间和计数：前缀和差值的配对可能跨左右两半
  逆序对家族：一个元素在左半、另一个在右半

⚠️ 识别信号：
  "答案可能穿过中间" → 跨边界
  "统计元素对（二元关系）" → 归并计数
```

### 1.2 两类跨边界处理

| 类型 | 处理方式 | 代表 |
|------|---------|------|
| 扫描型 | 从 mid 向两侧扩展扫描取最优 | 53 |
| 计数型 | 合并前统计跨半对，再正常归并 | 327/315/493 |

```
⚠️ 核心心法：
  分治递归保证"半内"的情况被覆盖
  我们需要额外处理的只有"跨半"的情况
  → 拆成两个子问题 + 跨边界扫描/计数
```

### 1.3 复杂度的一般公式

```
跨边界扫描/计数代价 = O(该层区间长度)（排序后或扩展扫描）
每层 O(n) × log n 层 = O(n log n)
⚠️ 例外：如果扫描是 O(1)（如只取中点两侧各一个）→ O(n)
```

## 2. 53. 最大子序和：四解法对比

### 2.1 分治版（跨边界扫描型，00 已有模板，此处提炼）

```
答案三选一：
  左半最大 / 右半最大 / 跨中点最大
跨中点 = 从 mid 向左扩展的最大和 + 从 mid+1 向右扩展的最大和

⚠️ 正确性论证：
  任何子区间 [i,j]：
    j ≤ mid → 属于左半子问题
    i > mid → 属于右半子问题
    i ≤ mid < j → 跨中点，被扫描覆盖
  → 三个来源穷尽所有可能 ✓
```

### 2.2 四解法全景对比（同一题的梯度）

| 解法 | 复杂度 | 空间 | 思想 |
|------|:---:|:---:|------|
| 暴力枚举 | O(n²) | O(1) | 枚举所有子区间 |
| Kadane（贪心） | O(n) | O(1) | 局部和 < 0 则丢弃 |
| DP | O(n) | O(1) | dp[i] = max(nums[i], dp[i-1]+nums[i]) |
| 分治 | O(n log n) | O(log n) | 三选一 |
| 线段树 | O(n) 建树 O(log n) 查询 | O(n) | 区间可合并 → 可动态查询 |

```java
// Kadane（最优，O(n)）：
int maxSubArrayKadane(int[] nums) {
    int maxEnd = nums[0], ans = nums[0];
    for (int i = 1; i < nums.length; i++) {
        maxEnd = Math.max(nums[i], maxEnd + nums[i]);  // 要么接上，要么重新开始
        ans = Math.max(ans, maxEnd);
    }
    return ans;
}
// ⚠️ 面试表达："分治 O(n log n) 不是最优，Kadane O(n) 才是；
//   但分治展示'三选一 + 跨边界'思想，且线段树版本支持在线修改"
```

## 3. 327. 区间和个数：归并 + 前缀和

### 3.1 题目与思路

```
统计 [lower, upper] 范围内的区间和个数
区间和 [i,j] = prefix[j] - prefix[i-1]（前缀和变换）
→ 问题变为：统计前缀和数组中 j > i 且 lower ≤ prefix[j]-prefix[i] ≤ upper

分治视角：
  左半前缀和与右半前缀和的配对 = 跨边界统计
  两半各自有序后（归并排序）→ 双指针批量统计
⚠️ 这是归并计数的最难变体：条件从"大小"变为"差值区间"
```

### 3.2 完整代码

```java
/**
 * LeetCode 327. 区间和个数（归并 + 前缀和）
 * ⚠️ 前缀和可能超 int → 用 long
 */
long[] prefix;

public int countRangeSum(int[] nums, int lower, int upper) {
    int n = nums.length;
    prefix = new long[n + 1];
    for (int i = 0; i < n; i++)
        prefix[i + 1] = prefix[i] + nums[i];     // 前缀和
    long[] tmp = new long[n + 1];
    return mergeCount(prefix, 0, n, lower, upper, tmp);
}

private int mergeCount(long[] arr, int lo, int hi, int lower, int upper, long[] tmp) {
    if (lo >= hi) return 0;                      // 单元素：无配对
    int mid = lo + (hi - lo) / 2;
    int count = mergeCount(arr, lo, mid, lower, upper, tmp)
              + mergeCount(arr, mid + 1, hi, lower, upper, tmp);

    // ⭐ 跨边界统计：左半每个 i，找右半 j 使 lower ≤ arr[j]-arr[i] ≤ upper
    // 两半有序 → 双指针 [start, end) 就是满足差值的区间
    int start = mid + 1, end = mid + 1;
    for (int i = lo; i <= mid; i++) {
        while (start <= hi && arr[start] - arr[i] < lower) start++;  // 找下界
        while (end <= hi && arr[end] - arr[i] <= upper) end++;       // 找上界
        count += end - start;                    // [start, end) 内都满足
    }
    // 正常归并（保持两半有序，供上层统计）
    merge(arr, lo, mid, hi, tmp);
    return count;
}
// 复杂度 O(n log n)
// ⚠️ 双指针正确性：i 递增时 arr[j]-arr[i] 递减 →
//   start/end 只增不减（单调性），不会回退 → 总 O(n)
```

> 🎯 **要点**：区间和 → 前缀和差分；跨边界配对 → 双指针区间定位；排序保持单调性 → 双指针不回退。三个转化是这题的灵魂。

## 4. 315. 右侧更小元素个数

### 4.1 题目与思路

```
每个元素右侧比它小的元素个数
归并计数 + 下标映射：
  归并时记录"每个原元素被取走时右半已取走多少"
⚠️ 需要携带原始下标（答案要按原顺序输出）
```

### 4.2 完整代码

```java
/**
 * LeetCode 315. 计算右侧小于当前元素的个数
 * ⚠️ 带 index 的归并计数（值与其原始下标绑定）
 */
int[] ans;

public List<Integer> countSmaller(int[] nums) {
    int n = nums.length;
    ans = new int[n];
    int[] idx = new int[n];               // ⚠️ 下标数组（对下标排序）
    for (int i = 0; i < n; i++) idx[i] = i;
    int[] tmpIdx = new int[n];
    mergeSort(nums, idx, 0, n - 1, tmpIdx);

    List<Integer> res = new ArrayList<>();
    for (int x : ans) res.add(x);
    return res;
}

private void mergeSort(int[] nums, int[] idx, int lo, int hi, int[] tmpIdx) {
    if (lo >= hi) return;
    int mid = lo + (hi - lo) / 2;
    mergeSort(nums, idx, lo, mid, tmpIdx);
    mergeSort(nums, idx, mid + 1, hi, tmpIdx);

    int i = lo, j = mid + 1, k = lo;
    int rightTaken = 0;                   // ⚠️ 右半已取走个数
    while (i <= mid && j <= hi) {
        if (nums[idx[i]] <= nums[idx[j]]) {
            // 左半元素归位：右半已取走 rightTaken 个都更小
            ans[idx[i]] += rightTaken;
            tmpIdx[k++] = idx[i++];
        } else {
            rightTaken++;                 // 右半元素更小，记入已取
            tmpIdx[k++] = idx[j++];
        }
    }
    while (i <= mid) {                    // 左半剩余：右半全取完
        ans[idx[i]] += rightTaken;
        tmpIdx[k++] = idx[i++];
    }
    while (j <= hi) tmpIdx[k++] = idx[j++];
    System.arraycopy(tmpIdx, lo, idx, lo, hi - lo + 1);   // 写回下标数组
}
// 推演 [5,2,6,1]：
//   合并 (5,2)：2 取走 rightTaken=1；5 归位 → ans[5] += 1
//   合并 (6,1)：ans[6] += 1
//   合并 (2,5,1,6)：1 取走 rightTaken=1；2 归位 ans[2]+=1；
//                  5 归位 ans[5]+=2 → 总 ans = [2,1,1,0] ✓
```

## 5. 493. 翻转对

### 5.1 题目与思路

```
统计 i < j 且 nums[i] > 2·nums[j]
与逆序对的差别：条件 ×2 → 两半有序时不能用"取走时计数"（×2 后可能跨越多个）
  → 合并前先单独扫一遍统计，再正常归并
⚠️ 乘 2 可能溢出 int → 用 long
```

### 5.2 完整代码

```java
/**
 * LeetCode 493. 翻转对
 * ⚠️ 两步分离：先统计（双指针），后归并（排序）
 */
int count = 0;

public int reversePairs(int[] nums) {
    int[] tmp = new int[nums.length];
    mergeSort(nums, 0, nums.length - 1, tmp);
    return count;
}

private void mergeSort(int[] nums, int lo, int hi, int[] tmp) {
    if (lo >= hi) return;
    int mid = lo + (hi - lo) / 2;
    mergeSort(nums, lo, mid, tmp);
    mergeSort(nums, mid + 1, hi, tmp);

    // ⭐ 先统计：两半各自有序 → 双指针
    int j = mid + 1;
    for (int i = lo; i <= mid; i++) {
        while (j <= hi && (long) nums[i] > 2L * nums[j]) j++;  // ⚠️ long 防溢出
        count += j - (mid + 1);           // 右半前 j-(mid+1) 个都满足
    }

    // 后归并：正常合并两半（保持有序）
    int i = lo, k = lo;
    j = mid + 1;
    while (i <= mid && j <= hi)
        tmp[k++] = (nums[i] <= nums[j]) ? nums[i++] : nums[j++];
    while (i <= mid) tmp[k++] = nums[i++];
    while (j <= hi)  tmp[k++] = nums[j++];
    System.arraycopy(tmp, lo, nums, lo, hi - lo + 1);
}
// 推演 [1,3,2,3,1]：合并 (3,2,3,1) 时：
//   左半 [1,3]，右半 [1,2,3]
//   i=1(值1)：j 移动到 nums[j]>2 → j 指向 3 → count += 1（1>2·1 ✓ 等）
//   i=3：3 > 2·1 ✓、3 > 2·2 ✗ → j 到值3 → count += 2
//   总 count = 2 ✓（(3,1)(3,1)）
// ⚠️ 关键对比：51 逆序对"边归并边计数"；493 乘 2 后必须"先统计后归并"
```

## 6. 归并计数万能模板

### 6.1 统一模板

```java
/**
 * 归并计数万能模板（统计跨左右两半的二元关系）
 * 定制点只有两个：① 统计条件  ② 统计时机
 */
int count = 0;

void mergeCount(int[] nums, int lo, int hi, int[] tmp) {
    if (lo >= hi) return;
    int mid = lo + (hi - lo) / 2;
    mergeCount(nums, lo, mid, tmp);
    mergeCount(nums, mid + 1, hi, tmp);

    // ⭐ 统计时机 A：合并中计数（条件与排序序兼容时）
    //   int i = lo, j = mid + 1;
    //   while (i <= mid && j <= hi) {
    //       if (nums[i] <= nums[j]) tmp[k++] = nums[i++];
    //       else { count += mid - i + 1; tmp[k++] = nums[j++]; }
    //   }

    // ⭐ 统计时机 B：合并前双指针扫（条件与排序序不兼容时）
    //   int j = mid + 1;
    //   for (int i = lo; i <= mid; i++) {
    //       while (j <= hi && 满足条件(nums[i], nums[j])) j++;
    //       count += j - (mid + 1);
    //   }

    // 正常归并（保持有序，供上层统计）
    merge(nums, lo, mid, hi, tmp);
}
```

### 6.2 统计时机选择表

| 题目 | 条件 | 时机 | 为什么 |
|------|------|:---:|--------|
| 51 逆序对 | a > b | 合并中 | 单调性直接匹配 |
| 315 右侧更小 | a > b（带下标） | 合并中 | 同上 + 记录 rightTaken |
| 493 翻转对 | a > 2b | 合并前 | ×2 破坏与排序的同步性 |
| 327 区间和 | L ≤ a-b ≤ U | 合并前 | 差值区间需要双指针边界 |

> 🎯 **判断口诀**："条件能被排序序直接推进 → 合并中计数（O(n)）；条件需要跳跃比较 → 合并前双指针（O(n)）。两者都是每层 O(n)，总 O(n log n)。"

## 7. 树状数组与归并计数对比

### 7.1 另一种思路：树状数组（BIT）

```
逆序对也可以用树状数组：
  从右往左扫描，每个数查询"已见过的比它小的个数"
  → 在值域上做前缀和查询 + 单点更新

数值离散化 → 树状数组大小 = 不同值个数
复杂度 O(n log n)（常数比归并小，且只扫描一遍）
```

```java
// 树状数组版逆序对骨架：
int count = 0;
BIT bit = new BIT(离散化后的值域大小);
for (int i = n - 1; i >= 0; i--) {          // 从右往左
    int rank = 离散化(nums[i]);              // 值 → 排名（去重后）
    count += bit.query(rank - 1);           // 右侧已出现且更小的个数
    bit.update(rank, 1);                    // 当前数加入
}
```

### 7.2 对比

| 维度 | 归并计数 | 树状数组 |
|------|:---:|:---:|
| 核心 | 合并时/前批量统计 | 值域前缀和 + 离散化 |
| 顺序 | 按位置排序 | 从右往左扫描 |
| 空间 | O(n) 辅助 | O(值域) ≈ O(n) |
| 扩展 | 条件任意（双指针） | 适合"小于/大于"类 |
| 易错 | 双指针单调性 | 离散化 + 查询下标 |

```
⚠️ 面试表达：
"归并计数和树状数组都能 O(n log n) 统计逆序对类问题。
 归并是分治思维（跨边界统计），
 树状数组是'在线扫描 + 值域索引'。
 条件复杂（区间、倍数）时归并更灵活。"
```

### 8.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 统计完忘归并 | 上层统计错误 | 统计与排序两步都要 |
| 双指针回退清零 | O(n²) | start/end 只增不减 |
| int 溢出（×2/前缀和） | 答案错 | long |
| 315 忘带下标 | 输出顺序错 | 下标数组绑定 |
| 53 跨中点扫描左右方向反 | 漏最优 | mid 向左、mid+1 向右 |
