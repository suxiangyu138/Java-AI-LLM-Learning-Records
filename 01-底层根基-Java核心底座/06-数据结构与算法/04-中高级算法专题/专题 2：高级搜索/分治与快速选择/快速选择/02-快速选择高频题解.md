## 1. 215. 数组中的第 K 个最大元素

### 1.1 题目与思路

```
第 K 大（快选完整版 + 堆版对比）
⚠️ 完整理论见分治/03 与 01 模块，此处给最完整的可手撕实现
```

### 1.2 完整代码（快选 + 三路优化）

```java
/**
 * LeetCode 215. 数组中的第 K 个最大元素
 * ⚠️ 三路分区版：重复元素优化（01 模块 2 节）
 */
public int findKthLargest(int[] nums, int k) {
    int target = nums.length - k;                // 第 K 大 = 第 n-K 小
    int lo = 0, hi = nums.length - 1;
    Random rand = new Random();

    while (lo <= hi) {
        int pIdx = lo + rand.nextInt(hi - lo + 1);
        int pivot = nums[pIdx];
        swap(nums, pIdx, hi);

        // 三路分区：< pivot | == pivot | > pivot
        int lt = lo, gt = hi, i = lo;
        while (i <= gt) {
            if (nums[i] < pivot) swap(nums, i++, lt++);
            else if (nums[i] > pivot) swap(nums, i, gt--);
            else i++;
        }
        if (target < lt) hi = lt - 1;
        else if (target > gt) lo = gt + 1;
        else return pivot;                       // ⚠️ target 在等于区
    }
    return -1;
}
// 推演 [3,2,1,5,6,4], k=2 → target=4
//   pivot=6：三路 → <区 [3,2,1,5,4]，==区 [6] → target=4 > gt → lo=gt+1
//   继续 → 最终 5 ✓
// ⚠️ 复杂度：期望 O(n)（重复元素多时三路显著加速）
// ⚠️ 面试表达："215 我写三路快选——普通 Lomuto 在
//   重复数据下退化；三路把等于区一次排除，
//   期望 O(n) 且对抗重复输入稳健。"
```

## 2. 973. 最接近原点的 K 个点

### 2.1 题目与思路

```
距离平方作键 → 快选第 K 小（距离）
⚠️ 比较函数抽象（01 模块 3 节）：快选模板的键可替换
```

### 2.2 完整代码

```java
/**
 * LeetCode 973. 最接近原点的 K 个点
 * ⚠️ 键 = 距离平方（不开方，无精度损失）
 */
public int[][] kClosest(int[][] points, int k) {
    quickSelect(points, 0, points.length - 1, k);
    return Arrays.copyOf(points, k);             // ⚠️ 前 K 个已就位（无序）
}

private void quickSelect(int[][] p, int lo, int hi, int k) {
    if (lo >= hi) return;
    int pivot = dist(p[hi]);
    int i = lo;
    for (int j = lo; j < hi; j++) {
        if (dist(p[j]) <= pivot) swap(p, i++, j);
    }
    swap(p, i, hi);
    if (i == k) return;
    if (i < k) quickSelect(p, i + 1, hi, k);
    else quickSelect(p, lo, i - 1, k);
}

private int dist(int[] p) { return p[0] * p[0] + p[1] * p[1]; }
// 推演 points=[[1,3],[-2,2],[2,-2]], k=1：
//   距离 10, 8, 8 → 第 1 小 = 8 → [-2,2] 或 [2,-2] ✓
// ⚠️ 面试表达："973 把'点'换成'距离键'——
//   快选模板的核心是分区比较函数；
//   键替换后 215/973/347/692 全部同构。"
```

## 3. 347. 前 K 个高频元素（快选版）

### 3.1 题目与思路

```
哈希统计频率 → 频率数组快选（第 n-K 小? 不——直接选"频率第 K 大"）
⚠️ 三解法对比（本模块快选版；频次桶版见计数/02；堆版见分治/03）
```

### 3.2 完整代码（快选版）

```java
/**
 * LeetCode 347. 前 K 个高频元素（快选版）
 * ⚠️ 思路：哈希统计 → 频率数组 → 快选频率第 K 大 → 收集
 */
public int[] topKFrequent(int[] nums, int k) {
    Map<Integer, Integer> freq = new HashMap<>();
    for (int x : nums) freq.merge(x, 1, Integer::sum);

    // 转成频率数组（值 + 频率）
    int[][] pairs = new int[freq.size()][2];
    int idx = 0;
    for (var e : freq.entrySet())
        pairs[idx++] = new int[]{e.getKey(), e.getValue()};

    // 快选：按频率（下标 1）排前 K
    quickSelectFreq(pairs, 0, pairs.length - 1, k);

    int[] res = new int[k];
    for (int i = 0; i < k; i++) res[i] = pairs[i][0];
    return res;
}

private void quickSelectFreq(int[][] p, int lo, int hi, int k) {
    if (lo >= hi) return;
    int pivot = p[hi][1];                       // ⚠️ 键 = 频率
    int i = lo;
    for (int j = lo; j < hi; j++) {
        if (p[j][1] >= pivot) swap(p, i++, j);  // ⚠️ 降序分区（前 K 大）
    }
    swap(p, i, hi);
    if (i == k) return;
    if (i < k) quickSelectFreq(p, i + 1, hi, k);
    else quickSelectFreq(p, lo, i - 1, k);
}
// 推演 [1,1,1,2,2,3], k=2：freq {1:3, 2:2, 3:1}
//   频率 [3,2,1] 快选前 2 → [3,2] → 元素 [1,2] ✓
// ⚠️ 复杂度：哈希 O(n) + 快选 O(n) 期望 = O(n) 期望
// ⚠️ 三解法选型：数据量大且重复少 → 快选；
//   频率范围小 → 频次桶（O(n) 确定）；在线 → 堆
```

## 4. 324. 摆动排序 II（快选中位数）

### 4.1 题目与思路

```
重排数组使 nums[0] < nums[1] > nums[2] < nums[3]...（摆动）
三步：
  ① 快选求中位数（第 n/2 小）
  ② 三路分区：< 中位数 | == | >（荷兰国旗）
  ③ 交叉放置：大数放奇数位、小数放偶数位（防止相邻相等）
⚠️ 中位数性质：摆动排序的"分界线"——小于的在偶数位、
   大于的在奇数位，中间数隔离
```

### 4.2 完整代码（交叉放置版）

```java
/**
 * LeetCode 324. 摆动排序 II
 * ⚠️ 关键：中位数三分区 + 交叉放置（大小交替）
 */
public void wiggleSort(int[] nums) {
    int n = nums.length;
    int median = findKthLargest(nums, (n + 1) / 2);   // 中位数（215 快选）

    // ① 三路分区（< med | == med | > med）
    int lt = 0, gt = n - 1, i = 0;
    while (i <= gt) {
        if (nums[i] < median) swap(nums, i++, lt++);
        else if (nums[i] > median) swap(nums, i, gt--);
        else i++;
    }

    // ② 交叉放置：映射 index → 虚拟重排位置
    //    ⚠️ 大数去奇数位、小数去偶数位（倒序交叉防相邻相等）
    int[] result = new int[n];
    int small = (n - 1) / 2, large = n - 1;
    for (int j = 0; j < n; j++) {
        if (j % 2 == 0) result[j] = nums[small--];   // 偶数位 ← 小数（倒序）
        else result[j] = nums[large--];              // 奇数位 ← 大数（倒序）
    }
    System.arraycopy(result, 0, nums, 0, n);
}
// 推演 [1,5,1,1,6,4]：中位数 4
//   分区 [1,1,1 | 4 | 5,6] → 交叉 [1,6,1,5,1,4] ✓
//   1<6>1<5>1<4 ✓ 摆动成立
// ⚠️ 为什么倒序交叉：正序会让相等的中间数相邻
//   （如 [1,1,1,2,2] 中位数 1 → 正序会 1,1 相邻 ✗）
// ⚠️ 面试表达："324 是三路分区 + 交叉放置——
//   中位数做'隔板'，小数偶数位、大数奇数位。
//   倒序放置防重复值相邻是细节关键。"
```

## 5. 295. 数据流的中位数（双堆）

### 5.1 题目与思路

```
不断 addNum + findMedian（在线）
双堆：大顶堆（左半最大）+ 小顶堆（右半最小）
  平衡规则：左堆大小 = 右堆 或 右堆+1
  中位数 = 左堆顶（奇数）或 (左顶+右顶)/2（偶数）
⚠️ 对比快选：快选一次 O(n)；流式必须堆 O(log n)/元素
```

### 5.2 完整代码

```java
/**
 * LeetCode 295. 数据流的中位数（双堆）
 */
class MedianFinder {
    // ⚠️ 大顶堆（左半）：堆顶是左半最大
    private final PriorityQueue<Integer> left = new PriorityQueue<>((a, b) -> b - a);
    // ⚠️ 小顶堆（右半）：堆顶是右半最小
    private final PriorityQueue<Integer> right = new PriorityQueue<>();

    public void addNum(int num) {
        // ① 先入左半
        left.offer(num);
        // ② 平衡：左顶 ≤ 右顶（左半所有元素 ≤ 右半所有元素）
        if (!right.isEmpty() && left.peek() > right.peek()) {
            right.offer(left.poll());
        }
        // ③ 大小平衡：|左| - |右| ≤ 1（左 = 右 或 左 = 右+1）
        if (left.size() > right.size() + 1) right.offer(left.poll());
        if (right.size() > left.size()) left.offer(right.poll());
    }

    public double findMedian() {
        if (left.size() == right.size())
            return (left.peek() + right.peek()) / 2.0;   // 偶数：平均
        return left.peek();                               // 奇数：左顶
    }
}
// 推演 addNum(1), 2, 3：
//   1：左[1]；2：左[1,2]→平衡右[2]→左[1]右[2]；3：左[1,3]→左[1,3]右[2]
//   → 大小失衡？左=2 右=1 → 左[1]右[2,3] → 再平衡左[1,2]右[3]？
//   最终左[1,2]右[3] → 中位数 2 ✓
// ⚠️ 面试表达："双堆保证左半全部 ≤ 右半全部，
//   堆顶即'分界线两侧'——O(log n) 插入、O(1) 中位数。
//   快选做不到在线，这就是流式选堆的原因。"
```

## 6. 462. 最少移动次数使数组元素相等 II

### 6.1 题目与思路

```
每次 ±1 使全部相等的最少次数 → 目标 = 中位数（非均值！）
  总次数 = Σ|xi - median|
⚠️ 数学性质（01 模块 1 节）：绝对差和中位数最小
```

### 6.2 完整代码

```java
/**
 * LeetCode 462. 最少移动次数使数组元素相等 II
 * ⚠️ 中位数（快选可 O(n)，排序 O(n log n) 也行）
 */
public int minMoves2(int[] nums) {
    Arrays.sort(nums);                          // 或快选取中位数 O(n)
    int median = nums[nums.length / 2];         // ⚠️ 中位数（排序后）

    int moves = 0;
    for (int x : nums) moves += Math.abs(x - median);   // 绝对差和
    return moves;
}
// 推演 [1,2,3]：中位数 2 → |1-2|+|2-2|+|3-2| = 2 ✓
//   验证：1→2（+1），3→2（-1）共 2 次 ✓
// 推演 [1,10,10]：中位数 10 → 9+0+0 = 9
//   ⚠️ 均值 7 会算 12——中位数 9 才是最小 ✓
// ⚠️ 面试表达："462 的目标是中位数不是均值——
//   Σ|xi-m| 中位数最小（均值最小化平方和）。
//   看到'绝对差和'立刻想到中位数。"
```

## 7. 快速选择方法论总结

### 7.1 解题框架

```
① 识别：第 K / 中位数 / TopK → 快选候选
② 转键：距离/频率/值 → 统一比较函数
③ 选型：
   静态 + 数组可改 + 只要值 → 快选
   在线/保序/不可改 → 堆
   需要全序 → 排序
④ 优化：随机化（防退化）+ 三路（防重复）
⑤ 边界：k 与 n 的转换、空输入

⚠️ 识别信号：
  "第 K 大/小、中位数、前 K" → 本家族
  "数据流/在线" → 排除快选
```

### 7.2 题型模板速查

| 题型 | 键 | 方法 | 代表题 |
|------|:---:|------|--------|
| 第 K 大 | 值 | 三路快选 | 215 |
| 第 K 近 | 距离² | 快选 | 973 |
| 前 K 频 | 频率 | 快选/桶 | 347 |
| 摆动 | 中位数 | 快选+交叉 | 324 |
| 流式中位 | - | 双堆 | 295 |
| 绝对差最小 | 中位数 | 快选/排序 | 462 |

### 7.3 自测清单

```
□ 第 K 大转第 K 小（n-k）？
```
