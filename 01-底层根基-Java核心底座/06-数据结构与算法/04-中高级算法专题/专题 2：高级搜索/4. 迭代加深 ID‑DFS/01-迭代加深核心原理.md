## 1. 迭代加深模型：阈值递增的 DFS

```text
问题: DFS 找最优解（深度未知）——
  普通 DFS: 可能一条路走到很深（空间 O(d) 但时间差）
  BFS: 深度已知但空间 O(b^d)（内存爆炸）

迭代加深（ID-DFS）:
  for (depth = 1; depth <= maxDepth; depth++)
      DFS(限制深度 = depth)
  → 深度阈值递增，每轮重搜

类比: 逐渐加深的水井——
  先看 1 米深、再 2 米、3 米……直到找到目标

⚠️ 核心: 深度阈值递增——每轮 DFS 只搜到当前深度
  找到目标时的阈值 = 答案深度（保证最优）
```

> 🎯 **核心认知**："**ID-DFS = '阈值递增的 DFS'——用'每轮重搜'换'O(d) 空间'**。它是 BFS 的'空间换时间'镜像：BFS 空间爆炸、ID-DFS 时间略增但空间极小。"

## 2. 为什么可行：重搜代价分析

### 2.1 重搜不亏

```text
直觉: 每轮重搜前面所有深度——不是浪费吗？
数学: 分支因子 b 时——
  第 d 层节点数 b^d 占总数约 (b−1)/b（b ≥ 2 时）
  浅层重搜的代价 ≈ 最后一层的代价（同阶）

例: b = 2, d = 10:
  节点总数: 2 + 4 + ... + 1024 ≈ 2046
  最后一层: 1024 ≈ 总数的一半
  重搜代价: 每轮重搜浅层 ≈ 2 × 最后一层（可接受）

⚠️ 结论: "b ≥ 2 时，重搜浅层的代价与最后一层同阶——
  总时间 O(b^d)（与单次深搜同阶），空间只有 O(d)"
```

### 2.2 时间空间对照

| 算法 | 时间 | 空间 |
|------|:---:|:---:|
| BFS | O(b^d) | **O(b^d)**（爆炸） |
| DFS | O(b^d) | O(d) |
| ID-DFS | **O(b^d)（常数略大）** | **O(d)** |

```text
⚠️ 面试表达:
  "ID-DFS 时间与 DFS/BFS 同阶 O(b^d)，
   但空间只有 O(d)——'用常数倍重搜换指数级空间'"
```

> 🎯 **重搜不亏的论证**："**'浅层重搜代价 ≈ 最后一层代价'（几何级数性质）——重搜的常数倍可接受，换来的 O(d) 空间是 BFS 给不了的**。这个论证是 ID-DFS 面试的必答点。"

## 3. ID-DFS 模板

### 3.1 核心模板

```java
/**
 * 迭代加深（ID-DFS）模板
 * 深度阈值递增 + DFS 深度限制
 */
boolean idDfs(状态, int maxDepth) {
    for (int depth = 1; depth <= maxDepth; depth++) {   // ① 阈值递增
        if (dfs(状态, 0, depth)) return true;           // ② 每轮重搜
    }
    return false;
}

boolean dfs(状态, int curDepth, int limit) {
    if (到达目标) return true;                    // ③ 找到目标
    if (curDepth == limit) return false;          // ④ ⚠️ 到达深度阈值 → 停止
    for (后继状态) {
        if (dfs(后继, curDepth + 1, limit)) return true;   // ⑤ 递归
    }
    return false;
}
// 记忆: "阈值递增 + 深度截断——curDepth == limit 即停"
```

### 3.2 模板要点

```text
三要素: ① 阈值递增循环 ② DFS 深度截断 ③ 找到即返回

⚠️ 与普通 DFS 的差异:
  普通 DFS: 无深度限制（可能无限深）
  ID-DFS: curDepth == limit 截断（控制深度）

记忆: "普通 DFS + 深度闸门（limit）"
```

> 🎯 **模板的灵魂**："**ID-DFS = '普通 DFS + 深度闸门'——limit 递增、到点即停**。会 DFS 就能 30 秒改出 ID-DFS，'深度截断'是它与普通 DFS 的唯一区别。"

## 4. IDA*：迭代加深 + A*

### 4.1 原理

```text
IDA* (Iterative Deepening A*):
  迭代加深的阈值 = f 值（g + h）而非深度

  每轮: DFS 限制 f ≤ 阈值（超过即剪）
  阈值递增: 从 start 的 h 开始，逐轮增加
  下一轮阈值 = 本轮超过的最小 f

优势: A* 的优先队列空间 O(b^d) →
      IDA* 只保留 DFS 栈 O(d) ✓

适用: 内存受限 + 最优搜索（8 数码、15 数码）
```

### 4.2 模板骨架

```java
/**
 * IDA* 模板（8/15 数码适用）
 * 阈值递增 f = g + h；DFS 剪 f > 阈值
 */
int idaStar(状态 start, 状态 target) {
    int threshold = heuristic(start, target);     // ① 初始阈值 = h(start)
    while (true) {
        int nextThreshold = dfs(start, 0, threshold, target);  // ② 每轮 DFS
        if (nextThreshold == 找到) return 答案;   // ③ 找到最优解
        if (nextThreshold == 无解) return -1;
        threshold = nextThreshold;                // ④ 阈值 = 本轮最小超限 f
    }
}

int dfs(状态 s, int g, int threshold, 目标) {
    int f = g + heuristic(s, 目标);
    if (f > threshold) return f;                  // ⑤ 超阈值 → 返回超限值
    if (到达目标) return 找到;
    int minOver = ∞;
    for (后继) {
        int result = dfs(后继, g + 1, threshold, 目标);
        if (result == 找到) return 找到;
        minOver = min(minOver, result);           // ⑥ 记录最小超限 f
    }
    return minOver;                               // ⑦ 下一轮阈值
}
// ⚠️ 核心: 阈值递增 + f 超限剪枝 + 返回"最小超限值"作下轮阈值
```

> 🎯 **IDA* 的定位**："**IDA* = '迭代加深的 A*'——阈值从 h(start) 递增、DFS 剪 f 超阈值**。它把 A* 的优先队列空间换成 DFS 栈（O(d)），是内存受限时的最优搜索标准（15 数码经典）。"

## 5. 完备性与最优性

### 5.1 性质分析

```text
ID-DFS: 完备 ✔（阈值递增到答案深度一定找到）
       最优 ✔（首个找到的深度 = 最小深度）
IDA*:   完备 ✔（阈值递增到最优解的 f）
       最优 ✔（h admissible 时）

⚠️ 与 A* 的对比:
  A*: 完备最优 + 优先队列（空间大）
  IDA*: 完备最优 + DFS 栈（空间小、时间略增）

选型: 内存够 → A*；内存受限 → IDA*
```

### 5.2 面试表达

```text
"ID-DFS/IDA* 都是完备且最优的——
  阈值递增保证不会漏解、首个解即最优。
  与 BFS/A* 的区别只在空间：
  BFS 存整层、A* 存优先队列、
  ID-DFS/IDA* 只存 DFS 栈 O(d)。"
```

## 6. 识别信号与易错点

### 6.1 识别信号

```text
"答案深度已知较小 + 状态空间大" → 迭代加深
"深搜可行但可能太深 + 要最优" → ID-DFS
"内存受限 + 最优搜索" → IDA*
"8/15 数码、埃及分数、骑士巡逻" → 迭代加深家族

⚠️ 判断: "BFS 内存爆 + DFS 可能无限深 → 迭代加深"
```

### 6.2 易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 忘深度截断 | `curDepth == limit` 返回 | 无限递归 |
| 2 | 阈值不递增 | 每轮 depth++ | 永不深入 |
| 3 | IDA* 阈值用深度 | 用 f = g + h | 退化为 ID-DFS |
| 4 | 忘记录最小超限 | 返回 minOver | 下轮阈值错 |
| 5 | 目标判定位置错 | 扩展前判（避免多扩一层） | 深度多 1 |
| 6 | maxDepth 太小 | 覆盖答案深度 | 漏解 |
| 7 | 空间优化忘讲 | O(d) 对比 BFS | 面试失分 |

> 🎯 **核心要点**：迭代加深通关四件事——**① 重搜不亏论证**（浅层代价同阶）；**② 模板**（阈值递增 + 深度截断）；**③ IDA* = ID + A\***（f 阈值 + 超限剪枝）；**④ 完备最优**（阈值递增保证）。**ID-DFS = '时间换空间的最优搜索'——'阈值递增、到点即停'八个字，就是它的全部魔法**。
