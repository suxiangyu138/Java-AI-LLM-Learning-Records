## 1. 329 矩阵最长递增路径（记忆化 + 免 visited）

### 1.1 完整实现

```java
/**
 * LeetCode 329. 矩阵中的最长递增路径
 * memo[i][j] = 从 (i,j) 出发的最长递增路径
 * ⚠️ 严格递增 → 天然无环 → 不需要 visited！
 */
public int longestIncreasingPath(int[][] matrix) {
    int m = matrix.length, n = matrix[0].length;
    int[][] memo = new int[m][n];                // 0 = 未计算（路径 ≥ 1）

    int best = 0;
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            best = Math.max(best, dfs(matrix, i, j, memo));
    return best;
}

private int dfs(int[][] matrix, int i, int j, int[][] memo) {
    if (memo[i][j] != 0) return memo[i][j];      // ① 查缓存

    int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};
    int best = 1;                                // ② 自己至少 1
    for (int[] d : dirs) {
        int ni = i + d[0], nj = j + d[1];
        if (ni < 0 || ni >= matrix.length || nj < 0 || nj >= matrix[0].length) continue;
        if (matrix[ni][nj] <= matrix[i][j]) continue;   // ③ 非递增跳过
        best = Math.max(best, 1 + dfs(matrix, ni, nj, memo));
    }
    return memo[i][j] = best;                    // ④ 存缓存
}
// 推演 [[9,9,4],[6,6,8],[2,1,1]] → 4 ✓（1→2→6→9）
// ⚠️ 面试必讲: 为什么不需要 visited？
//   路径严格递增 → 不可能走回已访问格子 → 天然无环
//   （有环才需要 visited；递增单调性 = 无环保证）
```

> 🎯 **329 的必考点**："**'严格递增 → 天然无环 → 免 visited'是记忆化与 visited 关系的最佳案例**——单调性让'回访不可能'，visited 就是多余的。能讲清'为什么不需要'，记忆化就通了。"

## 2. 403 青蛙过河（隐藏状态设计）

### 2.1 题目与思路

**题**：青蛙按石头跳，第一次跳 1 格，之后每次跳 k−1/k/k+1，能否到终点。

**隐藏状态**：仅位置不足以描述——上一步的跳跃距离影响下一步：

```java
/**
 * LeetCode 403. 青蛙过河
 * 状态: (位置, 上一步跳跃) —— 隐藏状态！
 * memo: Map<位置, Set<跳跃>> 或二维数组
 */
public boolean canCross(int[] stones) {
    Map<Integer, Set<Integer>> memo = new HashMap<>();   // ① 位置 → 可达跳跃集合
    for (int s : stones) memo.put(s, new HashSet<>());
    memo.get(0).add(1);                          // ② 第一步跳 1

    for (int pos : stones) {
        for (int jump : memo.get(pos)) {         // ③ 遍历该位置的所有跳跃
            int next = pos + jump;
            if (next == stones[stones.length - 1]) return true;  // ④ 到终点
            if (memo.containsKey(next)) {        // ⑤ 下一跳可选 k−1/k/k+1
                if (jump - 1 > 0) memo.get(next).add(jump - 1);
                memo.get(next).add(jump);
                memo.get(next).add(jump + 1);
            }
        }
    }
    return false;
}
// 推演 [0,1,3,5,6,8,12,17] → true ✓（1→2→2→3→4→5）
//   [0,1,2,3,4,8,9,11] → false ✓
// ⚠️ 隐藏状态: "上一步跳跃距离"不在题目显式状态里——
//   不加入它，不同跳跃历史到达同一位置会互相污染
```

> 🎯 **403 的状态设计**："**'位置 + 上一步跳跃'是经典隐藏状态——只记位置会丢失'下一步能跳多少'的信息**。状态设计'能不能回答下一步'是记忆化正确性的判据。"

## 3. 691 贴纸拼词（mask + 记忆化）

### 3.1 题目与思路

**题**：用贴纸（可重复用）拼出目标串，每张贴纸剪下字符，求最少贴纸数。

**mask 记目标串剩余字符**：

```java
/**
 * LeetCode 691. 贴纸拼词
 * mask = 目标串还需哪些字符（状压）
 * dp[mask] = 拼出剩余目标的最少贴纸数
 * 时间 O(2^len × stickers)，空间 O(2^len)
 */
public int minStickers(String[] stickers, String target) {
    int n = target.length();
    int[] dp = new int[1 << n];                  // ① mask → 最少贴纸
    Arrays.fill(dp, Integer.MAX_VALUE);
    dp[0] = 0;                                   // ② 空目标 = 0 张贴纸

    for (int mask = 0; mask < (1 << n); mask++) {
        if (dp[mask] == Integer.MAX_VALUE) continue;
        for (String sticker : stickers) {
            int next = mask;
            int[] count = new int[26];
            for (char c : sticker.toCharArray()) count[c - 'a']++;
            for (int i = 0; i < n; i++) {        // ③ 用贴纸消目标字符
                if (((mask >> i) & 1) == 1) continue;   // 已消跳过
                char c = target.charAt(i);
                if (count[c - 'a'] > 0) {
                    count[c - 'a']--;
                    next |= (1 << i);            // ④ 标记已消
                }
            }
            dp[next] = Math.min(dp[next], dp[mask] + 1);
        }
    }
    return dp[(1 << n) - 1] == Integer.MAX_VALUE ? -1 : dp[(1 << n) - 1];
}
// 推演 stickers=["with","example","science"], target="thehat" → 3 ✓
// ⚠️ 记忆化 + 状压: mask 记"剩余字符集合"——搜索去重 + 集合状态
//   与高级 DP 的状压同源（这里是"搜索视角"的迭代填表）
```

> 💡 **记忆化 × 状压的组合**："**691 = 搜索去重（mask 状态）+ 集合操作（位运算）**——'目标剩余集合'是搜索状态、mask 是它的编码。高级搜索与高级 DP 在此交汇：同一状态空间，搜索视角去重、DP 视角填表。"

## 4. 464 我能赢吗（博弈三态，回顾）

### 4.1 完整实现（博弈记忆化代表）

```java
/**
 * LeetCode 464. 我能赢吗
 * 博弈记忆化: mask + Boolean 三态 + 胜负传递
 */
public boolean canIWin(int maxChoosableInteger, int desiredTotal) {
    int sum = (1 + maxChoosableInteger) * maxChoosableInteger / 2;
    if (sum < desiredTotal) return false;        // ① 总和不够必输
    return dfs(0, desiredTotal, maxChoosableInteger,
               new Boolean[1 << maxChoosableInteger]);
}

private boolean dfs(int mask, int remain, int max, Boolean[] memo) {
    if (memo[mask] != null) return memo[mask];   // ② 三态缓存（null 未算）
    for (int i = 1; i <= max; i++) {
        if (((mask >> (i - 1)) & 1) == 1) continue;
        if (i >= remain) return memo[mask] = true;    // ③ 直接赢
        if (!dfs(mask | (1 << (i - 1)), remain - i, max, memo))
            return memo[mask] = true;                // ④ 对手必输 → 我赢
    }
    return memo[mask] = false;                       // ⑤ 全输 → 我输
}
// 推演 max=10, total=11 → true ✓
// ⚠️ 三态缓存的意义: false 也是有效结果——
//   boolean[] 无法区分"未算"与"算过=false" → 必须 Boolean[]
```

> 🎯 **464 与 691 的对照**："**464（博弈：胜负传递 + 三态）与 691（拼词：最少贴纸 + 填表）是记忆化的两种形态——'DFS 胜负'与'迭代最值'**。同一 mask 状态空间，问题语义决定实现形态。"

## 5. 记忆化搜索家族总览

| 题 | 状态 | 缓存 | 记忆化类型 |
|:---:|:---:|:---:|:---:|
| 329 递增路径 | (i,j) | int[][] | 最值型（免 visited） |
| 403 青蛙过河 | (pos, jump) | Map<pos, Set> | 可达性（隐藏状态） |
| 691 贴纸拼词 | mask | int[] | 最值型（状压） |
| 464 我能赢吗 | mask | Boolean[] | 博弈型（三态） |
| 62 不同路径 | (i,j) | int[][] | 计数型 |

```text
⚠️ 家族规律:
  "最值/计数 → int 缓存；可达性 → 集合/布尔；
   博弈 → 三态；集合状态 → mask"
```

## 6. 易错点与面试要点

### 6.1 易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 329 忘免 visited 论证 | 讲清单调性无环 | 面试失分 |
| 2 | 403 状态漏跳跃 | (pos, jump) 双状态 | 结果错误 |
| 3 | 403 跳 0 步 | `jump−1 > 0` 才加 | 原地循环 |
| 4 | 691 贴纸字符重复用 | count 数组消耗 | 多消字符 |
| 5 | 464 用 boolean[] | Boolean[] 三态 | false 误判 |
| 6 | 691 mask 位操作错 | `mask>>i & 1`、`next |= 1<<i` | 集合错 |
| 7 | 缓存初值 = 答案可能值 | -1/null 标记 | 误判已算 |

### 6.2 面试要点

```text
① 状态设计先讲: "状态 = (位置, 上一步跳跃)——隐藏状态要补"
② 缓存结构选型: "数组/Map/三态由状态与结果类型决定"
③ 免 visited 论证: "单调性 → 无环 → 不需要"
④ 复杂度: "状态数 × 转移数"

⚠️ 高频追问: "记忆化与 visited 的区别？"
  → "visited 防回访（防环）、memo 防重算（去重）——
    记忆化 = visited + 结果缓存；单调场景免 visited"
```

> 🎯 **核心要点**：记忆化题解通关——**329（免 visited 论证）+ 403（隐藏状态）+ 691（状压记忆化）+ 464（博弈三态）**。四题覆盖最值/可达/状压/博弈四种形态——"状态设计完整性 + 缓存选型 + 三态标记"，记忆化搜索就全通了。
