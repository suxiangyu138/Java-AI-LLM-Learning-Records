## 1. 双向 BFS 模型：两端夹击

```text
问题: 从起点 S 到终点 T 的最短步数（单位代价）
单向 BFS: 从 S 出发，逐层扩散直到碰到 T
  → 扩散深度 = 答案 d，探索 O(b^d) 个状态

双向 BFS: S 与 T 同时扩散——
  ① 从 S 向前搜（正向队列）
  ② 从 T 向后搜（反向队列——状态可逆！）
  ③ 两个前沿"相遇" → 最短路径找到

类比: 单向挖隧道 vs 两头同时挖——
  单向挖 d 米，双向各挖 d/2 米 → 工程量减半

⚠️ 关键前提: 状态转移可逆——
  反向搜索要知道"谁可以到达当前状态"
  例: 单词接龙（变换可逆）、开锁（拨动可逆）
```

> 🎯 **核心认知**："**双向 BFS = '两头挖隧道'——两个前沿各扩 d/2 层就相遇，探索量从 b^d 降到 b^(d/2)**。'状态可逆'是它的前提：反向搜索需要知道'前驱'。"

## 2. 为什么快：复杂度分析

### 2.1 数学推导

```text
假设: 分支因子 b、最短路径深度 d
单向 BFS 探索: 1 + b + b² + ... + b^d ≈ b^d
双向 BFS 探索: 2 × (1 + b + ... + b^(d/2)) ≈ 2·b^(d/2)

比值: b^d / (2·b^(d/2)) = b^(d/2) / 2

例: b=10, d=10:
  单向: 10¹⁰ = 100 亿
  双向: 2×10⁵ = 20 万 → 快约 5000 倍！

⚠️ 面试表达:
  "双向 BFS 把探索深度从 d 减半到 d/2——
   复杂度从 O(b^d) 降到 O(b^(d/2))，
   分支因子越大、深度越深，收益越明显"
```

### 2.2 空间同样减半

```text
单向 BFS 空间: O(b^d)（最坏存整层）
双向 BFS 空间: O(b^(d/2))（两个前沿各半）

⚠️ 双向 BFS 双赢: 时间减半 + 空间减半——
  "用'多一个队列'换'两个都减半'"
```

> 🎯 **复杂度要点**："**'深度减半'是双向 BFS 的全部秘密——b^(d/2) 而非 b^d**。面试给公式 + 数字例（b=10、d=10 → 快 5000 倍），比背结论有说服力。"

## 3. 双向 BFS 模板

### 3.1 标准实现（752 开锁）

```java
/**
 * 双向 BFS 模板（752 打开转盘锁）
 * 两个集合（前向/后向）+ 交替扩展较小者
 */
int openLock(String[] deadends, String target) {
    Set<String> dead = new HashSet<>(Arrays.asList(deadends));
    if (dead.contains("0000")) return -1;
    if (target.equals("0000")) return 0;

    Set<String> forward = new HashSet<>();       // ① 前向前沿
    Set<String> backward = new HashSet<>();      // ② 后向前沿
    forward.add("0000");
    backward.add(target);
    Set<String> visited = new HashSet<>();       // ③ 全局去重

    int steps = 0;
    while (!forward.isEmpty() && !backward.isEmpty()) {
        // ④ ⚠️ 扩展较小者（优化: 减少探索量）
        if (forward.size() > backward.size()) {
            Set<String> tmp = forward; forward = backward; backward = tmp;
        }

        Set<String> next = new HashSet<>();
        for (String cur : forward) {
            if (backward.contains(cur)) return steps;   // ⑤ 相遇！
            if (visited.contains(cur)) continue;
            visited.add(cur);
            for (String neighbor : getNeighbors(cur)) { // ⑥ 生成邻居
                if (!dead.contains(neighbor) && !visited.contains(neighbor))
                    next.add(neighbor);
            }
        }
        forward = next;
        steps++;
    }
    return -1;
}
// ⚠️ 模板五步: 双集合 → 扩展小者 → 相遇判定 → 邻居生成 → 步数递增
//   "扩展较小者"是双向 BFS 的经典优化（平衡探索量）
```

### 3.2 模板要点

```text
五步: ① 双前沿集合 ② 交替扩展 ③ 相遇判定
      ④ 邻居生成 ⑤ 步数计数

⚠️ 与单向 BFS 的差异:
  单向: 一个队列 + 层数
  双向: 两个集合 + 交替扩展 + 相遇判定
  去重: visited 全局（防两前沿内部重复）
```

> 🎯 **模板的灵魂**："**'扩展较小者'让两个前沿均衡前进——总探索量最小**。相遇判定在'扩展当前层'时检查（backward.contains(cur)），步数 = 相遇时的层数。"

## 4. 相遇判定与实现细节

### 4.1 为什么"扩展较小者"正确

```text
两个前沿总有一大一小——
扩展小者: 让小前沿追上大前沿 → 总探索量最小化
不扩展大者: 避免单侧膨胀（退化为单向 BFS）

⚠️ 直觉: "让两队人相对而行——
   总是让'人少的一队'走，两队很快相遇"

实现: 每次循环前交换（forward/backward 互换引用）
```

### 4.2 相遇 = 最短

```text
为什么相遇即最短:
  双向 BFS 按层同步推进——
  前向第 k 层、后向第 (d−k) 层相遇时，
  路径长度 = k + (d−k) = d
  任何更短路径都会让两前沿更早相遇 → 相遇即最短 ✓

⚠️ 步数计算: 前向步数 + 后向步数 = 总步数
  实现中: 每轮 steps++，相遇时返回 steps（已计入双方）
```

## 5. 适用条件：状态可逆

### 5.1 可逆 vs 不可逆

```text
可逆（能用双向）:
  单词接龙（a→b 变换可逆）
  开锁（拨动可逆）
  滑动谜题（滑动可逆）
  迷宫（移动可逆）

不可逆（不能用）:
  带方向性的状态转移（单向图）
  状态压缩（信息丢失）

⚠️ 判断: "反向搜索能生成'前驱'吗？"
  能 → 双向；不能 → 单向
```

### 5.2 什么时候收益最大

```text
① 分支因子大（b 大）: 减半效果指数级放大
② 深度深（d 大）: 深度减半收益明显
③ 起点终点都明确: 双向的前提

⚠️ 反例: 起点终点近（d 小）→ 双向收益有限
  面试表达: "深度大 + 分支大 → 双向收益最大"
```

## 6. 识别信号与易错点

### 6.1 识别信号

```text
"最短步数 + 状态可逆" → 双向 BFS（127/752/773）
"迷宫/密码/单词变换最短" → 双向 BFS
"状态空间大 + 两端明确" → 双向 BFS

⚠️ 面试定位: 双向 BFS 是 BFS 进阶高频——
  127 单词接龙是 Google/Amazon 高频题
```

### 6.2 易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 忘"扩展较小者" | size 比较交换 | 单侧膨胀 |
| 2 | 忘 visited | 全局去重 | 死循环/重复 |
| 3 | 相遇判定位置错 | 扩展当前层时检查 | 漏最短 |
| 4 | 状态不可逆硬用 | 先判可逆 | 反向搜不了 |
| 5 | 起点=终点忘判 | 先判 target == start | 返回 -1 错 |
| 6 | 邻居生成越界 | 边界检查 | 越界/死循环 |
| 7 | 步数计数错 | 每轮 +1（双方各半） | 步数翻倍/减半 |

> 🎯 **核心要点**：双向 BFS 通关四件事——**① 复杂度论证**（b^(d/2) vs b^d，数字例）；**② 五步模板**（双集合/扩展小者/相遇/邻居/步数）；**③ 可逆性判断**；**④ 相遇即最短**。**双向 BFS = '两头挖隧道'——'状态可逆 + 扩展小者'八个字，就是搜索减半的全部秘密**。
