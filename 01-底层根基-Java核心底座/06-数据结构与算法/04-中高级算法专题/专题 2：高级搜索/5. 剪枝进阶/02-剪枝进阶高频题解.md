## 1. 数独：约束传播剪枝

### 1.1 题目与思路

**题**：填满 9×9 数独（行/列/宫不重复）。

**约束传播**：每格维护"候选数字集"，冲突即剪 + **先填约束最多的格**：

```java
/**
 * 数独（约束传播剪枝）
 * ① 行/列/宫三组布尔（O(1) 冲突检查 = 可行性剪枝）
 * ② 先填候选最少的格（排序剪枝——约束最多先试）
 */
boolean solveSudoku(char[][] board) {
    boolean[][] rows = new boolean[9][10];       // ① 占用表（可行性剪枝）
    boolean[][] cols = new boolean[9][10];
    boolean[][] boxes = new boolean[9][10];
    // 初始化占用表...

    return backtrack(board, rows, cols, boxes);
}

private boolean backtrack(char[][] board, boolean[][] rows,
                          boolean[][] cols, boolean[][] boxes) {
    int[] cell = findMostConstrained(board);     // ② 找候选最少的空格
    if (cell == null) return true;               //    全部填完

    int i = cell[0], j = cell[1];
    for (int num = 1; num <= 9; num++) {
        int box = (i / 3) * 3 + j / 3;
        if (rows[i][num] || cols[j][num] || boxes[box][num]) continue;  // ③ 可行性剪枝
        board[i][j] = (char) ('0' + num);        // ④ 填
        rows[i][num] = cols[j][num] = boxes[box][num] = true;
        if (backtrack(board, rows, cols, boxes)) return true;
        board[i][j] = '.';                       // ⑤ 回溯
        rows[i][num] = cols[j][num] = boxes[box][num] = false;
    }
    return false;
}

private int[] findMostConstrained(char[][] board) {
    int bestI = -1, bestJ = -1, minOptions = 10;
    for (int i = 0; i < 9; i++)
        for (int j = 0; j < 9; j++) {
            if (board[i][j] != '.') continue;
            int options = countOptions(board, i, j);   // ⑥ 候选数
            if (options < minOptions) {               // ⑦ 选最少的
                minOptions = options;
                bestI = i; bestJ = j;
            }
        }
    return bestI == -1 ? null : new int[]{bestI, bestJ};
}
// ⚠️ 两大剪枝: 冲突检查（可行性）+ 先填最少候选（排序）——
//   数独从"能解"到"秒解"的关键就是这两者
```

> 🎯 **数独的剪枝价值**："**'三组布尔（可行性）+ 先填最少候选（排序）'是数独的两大剪枝——纯回溯 9^81 不可行、加剪枝后毫秒级**。约束传播 = 让'最受限'的决策最先做。"

## 2. N 皇后：对称与对角剪枝

### 2.1 题目与思路

**题**：n 皇后互不攻击（回溯专题 04 已讲基础版）。

**剪枝优化**：三数组（列/对角线）+ 对称剪枝：

```java
/**
 * N 皇后剪枝版（回溯专题基础 + 剪枝深潜）
 */
int solveNQueensCount(int n) {
    boolean[] cols = new boolean[n];
    boolean[] diag1 = new boolean[2 * n - 1];    // 正对角线（row−col 恒定）
    boolean[] diag2 = new boolean[2 * n - 1];    // 反对角线（row+col 恒定）
    return dfs(n, 0, cols, diag1, diag2);
}

private int dfs(int n, int row,
                boolean[] cols, boolean[] diag1, boolean[] diag2) {
    if (row == n) return 1;                      // ① 放满 = 一个解
    int count = 0;
    for (int col = 0; col < n; col++) {
        int d1 = row - col + n - 1;
        int d2 = row + col;
        // ② 可行性剪枝: 三方向冲突检查（O(1)）
        if (cols[col] || diag1[d1] || diag2[d2]) continue;
        cols[col] = diag1[d1] = diag2[d2] = true;
        count += dfs(n, row + 1, cols, diag1, diag2);
        cols[col] = diag1[d1] = diag2[d2] = false;
    }
    return count;
}
// 推演 n=4 → 2 ✓；n=8 → 92 ✓
// ⚠️ 剪枝效果: 行递归 + 三数组把 C(64,8)≈4.4×10⁹ 缩到约 2000 节点——
//   "可行性剪枝前置"让无效分支根本不生成
// 对称剪枝: 第一行只需试 0..n/2（对称性）——省一半（高级优化）
```

> 🎯 **N 皇后的剪枝数字**："**'行递归 + 列/对角线三数组'把 4.4×10⁹ 缩到约 2000 节点（6 个数量级）**——这是可行性剪枝前置的极致演示。对称剪枝（第一行只试一半）是进阶谈资。"

## 3. 组合优化：可行性 + 最优性双剪

### 3.1 题目与思路（分支限界）

```java
/**
 * 组合优化（分支限界思想）
 * 例: 0/1 背包求最大价值（n 大时的搜索解法）
 * 双剪: 可行性（重量超）+ 最优性（上界不够）
 */
int best = 0;                                    // ① 全局最优

void knapsackBranch(int[] w, int[] v, int capacity,
                    int index, int currentWeight, int currentValue) {
    // ② 可行性剪枝: 重量超容量 → 必然不合法
    if (currentWeight > capacity) return;
    // ③ 最优性剪枝: 当前值 + 剩余全选 ≤ 已知最优 → 剪
    if (currentValue + remainingUpperBound(index, v) <= best) return;

    if (index == w.length) {                     // ④ 到末尾 → 更新最优
        best = Math.max(best, currentValue);
        return;
    }
    knapsackBranch(w, v, capacity, index + 1, currentWeight, currentValue);         // 不选
    knapsackBranch(w, v, capacity, index + 1,
                   currentWeight + w[index], currentValue + v[index]);              // 选
}

// 剩余上界: 剩余物品价值之和（简单上界——可换"价值密度"更强上界）
int remainingUpperBound(int index, int[] v) {
    int sum = 0;
    for (int i = index; i < v.length; i++) sum += v[i];
    return sum;
}
// ⚠️ 双剪配合: 可行性砍"不合法"、最优性砍"不优"——
//   排序剪枝（按价值密度降序）能让最优性剪枝更早生效
```

> 💡 **分支限界 = 搜索 + 双剪**："**分支限界 = 深度优先搜索 + 可行性剪枝 + 最优性剪枝（上界）**——背包/旅行商/调度问题的搜索解法。'上界估计'的质量决定剪枝效率。"

## 5. 家族总览与调试

| 场景 | 剪枝类型 | 核心判据 |
|:---:|:---:|:---:|
| 数独 | 可行性 + 排序 | 冲突表 + 最少候选 |
| N 皇后 | 可行性 + 对称 | 三数组 + 行递归 |
| 埃及分数 | 可行性 | 项数下界 |
| 背包 | 可行性 + 最优性 | 重量 + 上界 |
| 15 数码 | 防回退 + IDA* | 反向移动 + f 阈值 |
| 组合 | 搜索位置 | startIndex（对称性） |
| 记忆化 | 重复剪枝 | 同状态去重 |

```text
⚠️ 规律: "搜索题的剪枝组合 =
   可行性（必然无解）+ 最优性（必然不优）
   + 排序（先试对的）+ 去重（同态免算）"
```

## 6. 易错点与面试要点

### 6.1 易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | "可能无解"当剪枝 | 必须"必然" | 丢解 |
| 2 | 剪枝后不对拍 | 小数据验证 | bug 难查 |
| 3 | 上界估计高估 | 上界 ≤ 真实可达 | 误剪最优 |
| 4 | N 皇后忘撤销三数组 | 成对撤销 | 状态污染 |
| 5 | 数独忘找最少候选 | 固定顺序扫 | 剪枝减半 |
| 6 | 最优性剪枝忘初始化 best | best = ∞/0 合理初值 | 剪枝失效 |
| 7 | 剪枝位置太靠后 | 递归开头前置 | 树不瘦 |

### 6.2 面试要点

```text
① 分类开场: "可行性/最优性/排序/重复四类"
② 正确性论证: "被剪分支必然无解/必然不优"
③ 量化效果: "N=8 皇后 4.4×10⁹ → 2000 节点"
④ 对拍验证: "剪枝前后结果一致"

⚠️ 高频追问: "剪枝和记忆化的关系？"
  → "记忆化是重复剪枝（同状态去重）——
    剪枝家族中'去重'这一类的特例"
```

> 🎯 **核心要点**：剪枝题解通关——**数独（约束传播 + 最少候选）、N 皇后（三数组 + 对称）、背包（可行性 + 最优性双剪）**。三场景覆盖剪枝全部类型——"可行性管有没有、最优性管好不好、排序管先试谁、去重管免重算"，组合使用就是搜索工程。
