## 1. 知识体系导图

```text
高级搜索（状态空间搜索的进阶）
│
├── 搜索本质 ──────────────────────────────────────────────
│   ├── 状态 → 图节点、状态转移 → 边
│   ├── 搜索 = 遍历状态空间（DFS/BFS 基础）
│   └── 进阶 = 让遍历"更少、更快、更聪明"
│
├── 记忆化搜索（去重）───────────────────────────────────
│   ├── DFS + memo = 重叠子问题去重（1. 子目录）
│   ├── 缓存结构: 数组 / HashMap / 三态 Boolean
│   ├── 博弈记忆化: 胜负传递（三态缓存）
│   └── 与剪枝关系: 记忆化 = "重复剪枝"
│
├── 双向 BFS（规模减半）─────────────────────────────────
│   ├── 起点终点同时搜 → 相遇即最优
│   ├── 复杂度: O(b^(d/2)) vs 单向 O(b^d)
│   ├── 适用: 状态可逆（单词接龙、开锁）
│   └── 面试: 127/752 是高频（2. 子目录）
│
├── A* 启发式搜索（导向）────────────────────────────────
│   ├── f = g + h: 已走 + 预估
│   ├── admissible（不低估）→ 最优
│   ├── 与 Dijkstra/BFS 的关系（h=0 退化）
│   └── 适用: 8 数码、迷宫最短路（3. 子目录）
│
├── 迭代加深 ID-DFS（深度控制）─────────────────────────
│   ├── 深度阈值递增重搜 → 空间 O(d)
│   ├── IDA* = ID + A*（内存受限最优搜索）
│   ├── 完备 + 最优（阈值递增到答案深度）
│   └── 适用: 答案深度已知小、状态空间大（4. 子目录）
│
└── 剪枝工程（效率）────────────────────────────────────
    ├── 可行性剪枝: 必然无解的分支提前砍
    ├── 最优性剪枝: 已不优的分支提前砍
    ├── 排序/搜索位置/重复/层数剪枝
    └── 本质: "提前知道走不通"（5. 子目录）
```

## 5. 算法特性对比表

| 算法 | 完备性 | 最优性 | 时间 | 空间 |
|------|:---:|:---:|:---:|:---:|
| DFS | 有限图 ✔ | ✘ | O(b^d) | O(d) |
| BFS | ✔ | 单位代价 ✔ | O(b^d) | O(b^d) |
| 双向 BFS | ✔ | 单位代价 ✔ | O(b^(d/2)) | O(b^(d/2)) |
| A* | 一致启发 ✔ | ✔ | 最优 | 指数级 |
| ID-DFS | ✔ | ✔ | O(b^d)（重搜） | **O(d)** |
| IDA* | ✔ | ✔ | 最优 | O(d) |

## 6. 常见误区速查

| 误区 | 正解 |
|------|------|
| "记忆化 = 剪枝" | ❌ 记忆化是"重复剪枝"（同状态去重）——只是剪枝的一种 |
| "双向 BFS 一定更快" | ❌ 复杂度 O(b^(d/2)) 是理论——状态不可逆时用不了 |
| "A* 一定最优" | ❌ 只有 h 满足 admissible（不低估）才最优 |
| "迭代加深 = 更慢" | ❌ 空间 O(d) 是核心优势；浅层重搜代价可接受（b 大时） |
| "剪枝会丢解" | ❌ 正确剪枝只砍"必然无解/必然不优"的分支 |
| "ID-DFS 与 DFS 不同" | ❌ 就是 DFS + 深度限制（阈值递增） |
| "A* 与 Dijkstra 无关" | ❌ h=0 时 A* 退化为 Dijkstra |
| "剪枝是玄学" | ❌ 分类清晰: 可行性/最优性/重复/排序/搜索位置 |
| "高级搜索面试不考" | ❌ 双向 BFS（127/752）是高频面试题 |
| "所有搜索都要记忆化" | ❌ 无重叠子问题 → 记忆化无意义 |
