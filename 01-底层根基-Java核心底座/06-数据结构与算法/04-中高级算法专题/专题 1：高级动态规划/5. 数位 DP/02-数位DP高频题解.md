## 1. 233 数字 1 的个数（数位 DP 经典）

### 1.1 数位 DP 实现

```java
/**
 * LeetCode 233. 数字 1 的个数
 * 统计 [0, n] 中数字 1 出现的总次数
 * 状态: pos + tight + count（已出现 1 的个数）
 */
public int countDigitOne(int n) {
    String s = String.valueOf(n);
    int[][][] memo = new int[s.length()][2][s.length() + 1];
    for (int[][] m : memo) for (int[] row : m) Arrays.fill(row, -1);
    return dfs(s, 0, 1, 0, memo);
}

private int dfs(String s, int pos, int tight, int count, int[][][] memo) {
    if (pos == s.length()) return count;         // ① 基线: 返回累计的 1 数
    if (tight == 0 && memo[pos][tight][count] != -1)
        return memo[pos][tight][count];          // ② 缓存（自由态）

    int limit = tight == 1 ? s.charAt(pos) - '0' : 9;
    int total = 0;
    for (int d = 0; d <= limit; d++) {
        int nextCount = count + (d == 1 ? 1 : 0);    // ③ 累计 1 的个数
        int nextTight = (tight == 1 && d == limit) ? 1 : 0;
        total += dfs(s, pos + 1, nextTight, nextCount, memo);
    }
    if (tight == 0) memo[pos][tight][count] = total; // ④ 存缓存
    return total;
}
// 推演 n=13 → 6 ✓（1,10,11,12,13 中共 6 个 1）
// ⚠️ 与 01 模板差异: 基线返回 count（累计值）而非 1——
//   "计数型"数位 DP 把统计值作为状态的一部分传递
```

> 🎯 **233 的两种解法**："**233 有数位 DP 与数学公式（逐位贡献法）双解——数位 DP 模板化、数学解 O(d)**。面试先写数位 DP（通用），追问再讲数学法（n=13 时十位贡献 4 个 1 等）。"

## 2. 902 最大为 N 的数字组合

### 2.1 题目与思路

**题**：用 digits 中的数字（可重复）组成 ≤ N 的正整数个数。

**数位 DP + 可选集**：

```java
/**
 * LeetCode 902. 最大为 N 的数字组合
 * 状态: pos + tight + lead（前导零——位数少于 N 也合法）
 */
public int atMostNGivenDigitSet(String[] digits, int n) {
    String s = String.valueOf(n);
    Set<Integer> allowed = new HashSet<>();
    for (String d : digits) allowed.add(d.charAt(0) - '0');

    int[][][] memo = new int[s.length()][2][2];
    for (int[][] m : memo) for (int[] row : m) Arrays.fill(row, -1);
    return dfs(s, 0, 1, 1, allowed, memo) - 1;   // ① −1: 排除全前导零（数字 0）
}

private int dfs(String s, int pos, int tight, int lead,
                Set<Integer> allowed, int[][][] memo) {
    if (pos == s.length()) return 1;             // ② 填完（含全 0 情况）
    if (tight == 0 && memo[pos][tight][lead] != -1)
        return memo[pos][tight][lead];

    int limit = tight == 1 ? s.charAt(pos) - '0' : 9;
    int count = 0;
    for (int d = 0; d <= limit; d++) {
        if (lead == 1 && d == 0) {               // ③ 前导零: 跳过（不用 allowed）
            count += dfs(s, pos + 1, 0, 1, allowed, memo);  // 位数少一位也合法
        } else if (allowed.contains(d)) {        // ④ 非前导: 必须用 allowed
            int nextTight = (tight == 1 && d == limit) ? 1 : 0;
            count += dfs(s, pos + 1, nextTight, 0, allowed, memo);
        }
    }
    if (tight == 0) memo[pos][tight][lead] = count;
    return count;
}
// 推演 digits=["1","3","5","7"], n=100 → 20 ✓（1,3,5,7,11..77 共 4+16）
// ⚠️ lead 的实战价值: 位数少于 N 的数（如 N=100 时 1 位数/2 位数）
//   由"前导零跳过"分支自然覆盖——这是 lead 存在的意义
```

> 💡 **lead 的分支**："**902 中'前导零跳过'分支让'位数不足'的数自动计数——不用单独处理 1 位数/2 位数**。lead 状态解决'长度可变'问题，是数位 DP 处理'位数自由'的关键。"

## 3. 统计不含重复数字的整数（lead 实战）

### 3.1 题目与思路

**题**：[0, N] 中各位数字互不相同的数字个数（如 123 合法、121 不合法）。

**状态 + 已用数字掩码**：

```java
/**
 * 统计不含重复数字的整数
 * 状态: pos + tight + lead + mask（已用数字集合）
 */
int countNoRepeat(int n) {
    String s = String.valueOf(n);
    // memo[pos][tight][lead][mask]——mask 1024 种（10 个数字）
    int[][][][] memo = new int[s.length()][2][2][1 << 10];
    ...
    return dfs(s, 0, 1, 1, 0, memo);
}

private int dfs(String s, int pos, int tight, int lead, int mask, int[][][][] memo) {
    if (pos == s.length()) return 1;
    if (tight == 0 && memo[pos][tight][lead][mask] != -1)
        return memo[pos][tight][lead][mask];

    int limit = tight == 1 ? s.charAt(pos) - '0' : 9;
    int count = 0;
    for (int d = 0; d <= limit; d++) {
        if (lead == 1 && d == 0) {               // ① 前导零: 不进 mask
            count += dfs(s, pos + 1, 0, 1, mask, memo);
        } else if (((mask >> d) & 1) == 0) {     // ② 数字未用过
            count += dfs(s, pos + 1,
                (tight == 1 && d == limit) ? 1 : 0, 0,
                mask | (1 << d), memo);          // ③ 加入 mask
        }
    }
    if (tight == 0) memo[pos][tight][lead][mask] = count;
    return count;
}
// 推演 N=20 → 19 ✓（0-20 中 11 重复 → 19 个不重复）
// ⚠️ mask 状态 = 状压思想进入数位 DP——
//   "已用数字集合"用位掩码表达（与状压 DP 同款位运算）
```

> 🎯 **数位 × 状压的组合**："**'不含重复数字' = 数位 DP + mask 状态——'已用数字集合'用位掩码**。高级 DP 的组合题常是'数位框架 + 状压状态'，识别'每位的选择约束'就能套。"

## 4. 数位 DP 家族总览

| 题 | 自定义状态 | 特殊处理 |
|:---:|:---:|:---:|
| 不含某数字 | 无 | banned 跳过 |
| 233 数字 1 | count（累计） | 基线返回累计 |
| 902 数字组合 | 可选集 | lead 跳过分支 |
| 不含重复数字 | mask（已用集合） | 位掩码去重 |
| 数位和限制 | 和 | 基线判和 |

```text
⚠️ 家族规律:
  "条件逐位判定 → 自定义状态加到记忆化键；
   位数自由 → lead 处理；集合约束 → mask"
```

## 5. 数学解法对比（233）

### 5.1 逐位贡献法（O(d)）

```java
// 数学法: 统计每一位上 1 出现的次数（高位 × 位权 + 低位部分）
// 例: n=213 的十位——
//   高位 2、低位 3: 十位 1 出现 (2) × 10 + (3+1) = 24 次
//   公式: high × digit + (cur == 1 ? low + 1 : cur > 1 ? digit : 0)

// ⚠️ 对比:
//   数位 DP: 通用（改条件即可）、模板化
//   数学法: O(d) 更快、但每题公式不同
//   面试建议: 数位 DP 为主，数学法作为追问展示
```

## 6. 易错点与面试要点

### 6.1 易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 233 基线返回 1 | 返回累计 count | 统计全错 |
| 2 | 902 忘 −1 | 排除全前导零（数字 0） | 多算 1 |
| 3 | 902 前导零分支忘 lead 传递 | lead 保持 1 | 位数不足漏计 |
| 4 | mask 忘检查 | `(mask>>d)&1 == 0` 才选 | 重复数字混入 |
| 5 | 缓存含 tight=true | 只记自由态 | 逻辑错/浪费 |
| 6 | memo 维度漏自定义状态 | 每维一个状态 | 状态污染 |
| 7 | 大 N 用 int | N 可达 10⁹（int 够）；更大用 long | 溢出 |

### 6.2 面试要点

```text
① 模板四要素开场: "逐位填 + tight 管上限 + 缓存自由态"
② 自定义状态讲清: "count 累计 / mask 集合——为什么需要它"
③ 区间前缀差: "solve(R) − solve(L−1)"
④ 复杂度: O(d² × k)——状态数极小

⚠️ 高频追问: "为什么 tight=true 不缓存？"
  → "贴上限的路径只有一条（前缀固定）——
    缓存它没有复用价值；自由态被大量前缀共享"
```

> 🎯 **核心要点**：数位 DP 题解通关——**233（计数型）、902（可选集 + lead）、不含重复（mask 状态）**。三题覆盖数位 DP 的三种自定义状态——"自定义状态加到记忆化键、lead 管位数自由、mask 管集合约束"，模板一套，条件一改，全部数位题通吃。
