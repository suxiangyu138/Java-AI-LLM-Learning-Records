## 1. 数位 DP 模型：逐位决策 + 记忆化

```text
数位 DP: 统计 [0, N] 中满足数位条件的数字个数
  例: 不含 4 的数、数字 1 的个数、不含重复数字

为什么不能枚举: N 可达 10⁹+ → 枚举超时
为什么能 DP: 逐位决策（高位 → 低位），
  相同"剩余位数 + 约束状态"的子问题大量重复 → 记忆化

模型: 把数字看作一串数位，从高位到低位逐位选择
  状态: pos（当前位）+ tight（是否贴上限）+ lead（前导零）+ 自定义状态
  转移: 枚举当前位 0-9（受 tight 限制）

⚠️ 与普通 DP 的差异: 它本质是"DFS + 记忆化"——
  用记忆化搜索实现（数位 DP 的标准形态）
```

> 🎯 **核心认知**："**数位 DP = '逐位填数字的 DFS + 记忆化'——把'统计大区间'变成'数位上的状态转移'**。它不需要数学公式，状态数又极小（O(d²)），是高级 DP 里性价比最高的模板。"

## 2. 三状态：pos/tight/lead

### 2.1 状态语义

```text
pos: 当前处理到第几位（从高位往低位）
tight: 前缀是否与 N 完全一致——
  tight=true → 当前位 ≤ N 的对应位（贴上限）
  tight=false → 当前位可任意 0-9（已脱离上限）
lead: 是否有前导零（数字是否已开始）——
  用于处理"0"的位数（如数字 0 算不算）

⚠️ tight 是数位 DP 的灵魂:
  tight=true 的分支一旦选择"小于上限位"→ 变 false 且不再变回
  例: N=123，前缀"12"后 tight=false → 下一位 0-9 任意

为什么需要 lead:
  "数字 005"与"5"是同一个数——
  前导零影响"位数相关"的条件（如"偶数位数"）
```

### 2.2 状态压缩

```text
完整状态: (pos, tight, lead, ...) 四维
优化: tight/lead 是布尔——维度小；
  自定义状态（已用数字集合/1 的个数）视题目加

⚠️ 记忆化键: 通常只缓存 (pos, tight=false, lead=false, 自定义状态)
  ——tight=true 的路径唯一（贴上限只有一条），缓存无意义
  → memo 只记 tight=false 的分支（节省空间）
```

> 🎯 **tight 的理解**："**tight = '还在贴着上限走吗'——贴上限时当前位受限，一旦选小就自由了**。'贴上限的路径只有一条'是它不进缓存的原因，也是数位 DP 空间小的关键。"

## 3. 记忆化模板（核心）

### 3.1 通用模板（统计不含某数字）

```java
/**
 * 数位 DP 通用模板——统计 [0, N] 不含 digit 的数字个数
 * 状态: pos（位）/ tight（贴上限）/ lead（前导零）
 */
int countWithoutDigit(int n, int banned) {
    String s = String.valueOf(n);
    int[][][] memo = new int[s.length()][2][2];
    for (int[][] m : memo) for (int[] row : m) Arrays.fill(row, -1);
    return dfs(s, 0, 1, 1, banned, memo);
}

private int dfs(String s, int pos, int tight, int lead,
                int banned, int[][][] memo) {
    if (pos == s.length()) return 1;             // ① 数位填完 → 1 种
    if (tight == 0 && memo[pos][tight][lead] != -1)
        return memo[pos][tight][lead];           // ② 查缓存（仅 tight=false）

    int limit = tight == 1 ? s.charAt(pos) - '0' : 9;   // ③ 上限
    int count = 0;
    for (int d = 0; d <= limit; d++) {
        if (d == banned) continue;               // ④ 禁止数字跳过
        int nextTight = (tight == 1 && d == limit) ? 1 : 0;  // ⑤ 贴上限传递
        int nextLead = (lead == 1 && d == 0) ? 1 : 0;        // ⑥ 前导零传递
        count += dfs(s, pos + 1, nextTight, nextLead, banned, memo);
    }
    if (tight == 0) memo[pos][tight][lead] = count;  // ⑦ 存缓存
    return count;
}
// 推演 N=100 不含 4 → 90 ✓（0-99 中 19 个含 4，100 不含）
// ⚠️ 模板四要素: ① 基线 ② 查缓存 ③ 上限 ④ 存缓存
```

### 3.2 模板口诀

```text
"逐位填、上限看 tight、缓存只记自由态"
  ① 基线: 填完返回 1（一种数）
  ② 上限: tight ? N[pos] : 9
  ③ 转移: 枚举 d，更新 tight/lead
  ④ 缓存: 只记 tight=false（自由态可复用）

⚠️ 记忆: "pos 推进、tight 收窄、lead 消退、
   缓存专记自由态"
```

> 🎯 **模板的灵魂**："**'tight=false 才缓存'是数位 DP 的空间魔法——自由态被大量复用（每个前缀都通向它）、贴上限态只有一条路径（缓存无意义）**。状态数从 10^d 降到 O(d²)，这就是数位 DP 快的原因。"

## 4. 区间统计：solve(R) − solve(L−1)

### 4.1 区间转换

```java
// 统计 [L, R] 满足条件的个数:
int countInRange(int L, int R, ...) {
    return solve(R, ...) - solve(L - 1, ...);
}
// ⚠️ 数位 DP 的标配: 先写 solve(N)（[0,N] 统计），
//   区间 = 两个前缀之差

// 例: 统计 [100, 999] 不含 4 的数字
//   = countWithoutDigit(999) − countWithoutDigit(99)
// 推演: [0,999] 共 9×9×9=729 不含 4；[0,99] 共 81 → 648 ✓
```

> 💡 **前缀差的通用性**："**'solve(R) − solve(L−1)'是数位 DP 的区间标配——所有'区间统计'都拆成两个前缀统计**。面试先写 solve(N)，区间自然导出。"

## 5. 为什么状态数这么少

### 5.1 状态计数

```text
朴素枚举: 10^d 个数字（d = 位数，N=10⁹ → 10¹⁰ 不可行）
数位 DP: 状态 = pos × tight × lead × 自定义
  = d × 2 × 2 × k（k 为自定义状态数）
  N=10⁹（d=10）→ 10 × 2 × 2 × k ≈ 40k 状态
  每个状态转移 ≤ 10 次 → 总 O(d²·k·10) ≈ 40 万操作

⚠️ 对比: 10¹⁰ → 40 万——快约 25 万倍！
```

### 5.2 复杂度表达

```text
时间: O(d² × k × 10)——d = 位数、k = 自定义状态
空间: O(d × k)（memo 数组）

⚠️ 面试表达:
  "数位 DP 状态数 = 位数 × 布尔状态 × 自定义状态 ≈ O(d²)——
   比枚举 10^d 个数字快指数级"
```

## 6. 识别信号与易错点

### 6.1 识别信号

```text
"[0,N] / [L,R] + 数位条件" → 数位 DP
"不含某数字 / 1 的个数 / 不含重复数字" → 数位 DP
"N 很大（10⁹+）+ 逐位条件" → 数位 DP

⚠️ 区分: "数位条件" vs "数值条件"——
  数位: 逐位判定（含 4、位数和）
  数值: 整体判定（质数、平方数）→ 不是数位 DP

⚠️ 面试定位: 数位 DP 面试出现率中等——
  模板固定（记忆化搜索），会模板就能套
```

### 6.2 易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 忘 lead 状态 | 前导零影响位数条件 | 0 的统计错 |
| 2 | tight 传递错 | `d == limit 且原 tight` 才保持 | 上限失效 |
| 3 | 缓存含 tight=true | 只记 tight=false | 空间浪费/逻辑错 |
| 4 | 忘减 L−1 | solve(R) − solve(L−1) | 区间漏 L |
| 5 | 基线返回 0 | 填完返回 1 | 计数全 0 |
| 6 | memo 忘重置 | 每次 solve 新建 | 用例污染 |
| 7 | 上限取错 | `tight ? s[pos] : 9` | 越界/漏数 |

> 🎯 **核心要点**：数位 DP 通关四件事——**① 三状态语义**（pos/tight/lead）；**② 模板四要素**（基线/查缓存/上限/存缓存）；**③ 只缓存自由态**（空间魔法）；**④ 前缀差**（solve(R)−solve(L−1)）。**数位 DP 是'把统计变状态转移'的魔法——'逐位填、tight 管上限、缓存专记自由态'三句口诀，就是全部模板**。
