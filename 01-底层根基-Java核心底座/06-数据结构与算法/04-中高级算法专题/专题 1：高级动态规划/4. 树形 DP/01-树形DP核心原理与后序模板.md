## 1. 树形 DP 模型：后序自底向上

```text
树形 DP: 在树上做 DP——节点的答案依赖其子节点

核心: 后序遍历（自底向上）
  ① 递归处理所有子节点（子问题先算）
  ② 用子节点结果更新父节点状态
  ③ 根节点的结果 = 全局答案

状态设计:
  无约束: dp[node] = 子树最优值（104 树高）
  父子约束: 返回元组（偷/不偷、选/不选）——337 打家劫舍
  全局聚合: 直径/最大路径（子节点信息 + 全局变量）

⚠️ 与 DFS 的区别: 树形 DP = 后序 DFS + 结果缓存/整合——
  普通 DFS 只遍历；树形 DP 用子结果算父结果
```

> 🎯 **核心认知**："**树形 DP 的灵魂 = '后序整合'——子节点先算完，父节点拿结果做决策**。'依赖子树信息'是它区别于其他 DP 的最大特征（与 DFS 专题的后序信息流同源）。"

## 2. 后序遍历模板

### 2.1 基础模板（104 树高）

```java
/**
 * LeetCode 104. 二叉树最大深度——树形 DP 最小形态
 * 后序: 子节点高度先算，父节点 = max + 1
 */
public int maxDepth(TreeNode root) {
    if (root == null) return 0;                  // ① 基线（空节点深度 0）
    int left = maxDepth(root.left);              // ② 左子树深度（先算）
    int right = maxDepth(root.right);            // ③ 右子树深度（先算）
    return Math.max(left, right) + 1;            // ④ 整合: max + 自己
}
// 推演 [3,9,20,null,null,15,7] → 3 ✓
// ⚠️ 这是树形 DP 的最小原型: "基线 → 递归子 → 整合"
```

### 2.2 模板三要素

```text
① 基线: 空节点返回 0/边界值
② 递归: 左右子树各自求解（子问题）
③ 整合: 子结果组合成父结果

⚠️ 记忆: "基线 → 子先算 → 父整合——
   与 DFS 的后序（先子后父）完全同构"
```

> 🎯 **模板的扩展**："**104 是最小原型——'基线/递归/整合'三要素在 337/543/124 中全部复用**。树形 DP 的题都是'整合方式'不同：加 1（深度）、取 max（直径）、二元组（打家劫舍）。"

## 3. 二元组状态：打家劫舍 III

### 3.1 题目与思路

**题**：二叉树打家劫舍——父子不能同时偷，求最大偷窃值。

**为什么必须二元组**：父节点决策依赖"子节点偷没偷"——只返回单值无法判断：

```java
/**
 * LeetCode 337. 打家劫舍 III
 * 返回 (rob, notRob): 该子树根偷/不偷的最大值
 * 转移: rob = val + 子 notRob；notRob = 子 max 之和
 */
public int rob(TreeNode root) {
    int[] result = dfs(root);
    return Math.max(result[0], result[1]);       // ① 根偷/不偷取最大
}

private int[] dfs(TreeNode node) {
    if (node == null) return new int[]{0, 0};    // ② 空节点都是 0
    int[] left = dfs(node.left);                 // ③ 左子树二元组
    int[] right = dfs(node.right);               // ④ 右子树二元组

    // ⑤ 偷当前: 子节点都不能偷
    int rob = node.val + left[1] + right[1];
    // ⑥ 不偷当前: 子节点各自取最优
    int notRob = Math.max(left[0], left[1]) + Math.max(right[0], right[1]);
    return new int[]{rob, notRob};
}
// 推演 [3,2,3,null,3,null,1] → 7 ✓（3+3+1）
// ⚠️ 为什么不能只返回单值: 父节点要知道"子节点偷了没"——
//   单值丢失该信息 → 二元组是父子约束题的标配
```

> 🎯 **337 的必考点**："**'偷/不偷'二元组——偷当前则子不能偷、不偷则子取最优**。'父决策依赖子状态'→ 返回元组，这是树形 DP 与线性 DP 的最大差异。337 是 2025 面试树形 DP 必考题。"

## 4. 全局变量更新：直径与最大路径

### 4.1 543 二叉树的直径

```java
/**
 * LeetCode 543. 二叉树的直径
 * 直径 = 某节点的左高 + 右高（全局最大）
 * 后序算高度 + 全局变量更新
 */
int diameter = 0;

public int diameterOfBinaryTree(TreeNode root) {
    height(root);
    return diameter;
}

private int height(TreeNode node) {
    if (node == null) return 0;
    int left = height(node.left);                // ① 左高
    int right = height(node.right);              // ② 右高
    diameter = Math.max(diameter, left + right); // ③ ⚠️ 全局更新（经过本节点的直径）
    return Math.max(left, right) + 1;            // ④ 返回高度（不是直径！）
}
// 推演 [1,2,3,4,5] → 3 ✓（4→2→1→3 或 5→2→1→3）
// ⚠️ 关键: 函数返回"高度"、全局变量记"直径"——
//   直径可能不经过根节点 → 每节点都检查
```

### 4.2 124 二叉树最大路径和

```java
/**
 * LeetCode 124. 二叉树中的最大路径和
 * 路径和 = 节点 + 左增益 + 右增益（可只走一边）
 */
int best = Integer.MIN_VALUE;

public int maxPathSum(TreeNode root) {
    gain(root);
    return best;
}

private int gain(TreeNode node) {
    if (node == null) return 0;
    int left = Math.max(0, gain(node.left));     // ① 左增益（负则舍弃）
    int right = Math.max(0, gain(node.right));   // ② 右增益（负则舍弃）
    best = Math.max(best, node.val + left + right);  // ③ 全局: 经过本节点的路径
    return node.val + Math.max(left, right);     // ④ 返回单边最大增益
}
// 推演 [-10,9,20,null,null,15,7] → 42 ✓（15+20+7）
// ⚠️ 与 543 同构: "返回单边值、全局记双边值"——
//   负增益用 max(0, ...) 舍弃是 124 的关键细节
```

> 💡 **全局变量的模式**："**543/124 共享'返回单边、全局记双边'模式——函数返回'向上的贡献'、全局变量记'经过本节点的最优'**。'返回什么 vs 记录什么'是两个不同量，这是树形 DP 的最高频混淆点。"

## 5. 树形背包简介

### 5.1 概念与代码骨架

```java
// 树形背包: 树上选节点（含容量限制）
// 例: 每个节点选/不选 + 容量 k（如"选 k 个节点最大价值"）
// 状态: dp[node][j] = 子树 node 中选 j 个的最优值
// 转移: 树上分组背包——每个孩子是一组，组内选 0..size 个

void treeKnapsack(TreeNode node, int capacity) {
    // dp[node][0..capacity]: 子树选 j 个
    for (TreeNode child : children(node)) {
        treeKnapsack(child, capacity);           // ① 子先算
        for (int j = capacity; j >= 0; j--)      // ② 逆序（0/1 组内）
            for (int k = 0; k <= size(child); k++)
                dp[node][j] = max(dp[node][j], dp[node][j-k] + dp[child][k]);
    }
}
// ⚠️ 面试定位: 树形背包是"分组背包 × 树"——概念理解即可
//   蓝桥/ACM 常见，大厂面试较少直接考
```

## 6. 识别信号与易错点

### 6.1 识别信号

```text
"树/二叉树 + 最优值 + 父子约束" → 树形 DP
"打家劫舍/选节点 + 不能相邻" → 二元组状态
"直径/最长路径" → 全局变量更新
"树上选 k 个 + 容量" → 树形背包

⚠️ 2025 趋势: 树形 DP（337）与区间 DP（312）是压轴题——
  "区分候选人的关键考点"
```

### 6.2 易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 只返回单值（337） | 二元组（偷/不偷） | 父无法决策 |
| 2 | 543 函数返回直径 | 返回高度（全局记直径） | 直径算错 |
| 3 | 124 负增益不舍弃 | `max(0, gain)` | 负路径拉低 |
| 4 | 基线忘空节点 | `null → 0` | 空指针 |
| 5 | 全局变量忘重置 | 每用例重置 | 用例间污染 |
| 6 | 树形背包顺序错 | 组内逆序 | 重复选 |
| 7 | 状态定义不清 | 先讲 dp[node] 含义 | 转移错 |

> 🎯 **核心要点**：树形 DP 通关四件事——**① 后序模板**（基线 → 子先算 → 父整合）；**② 二元组状态**（337 偷/不偷）；**③ 返回 vs 记录分离**（543/124 单边返回、全局记双边）；**④ 识别信号**（父子约束/直径/树上背包）。**树形 DP 是压轴题（337 必考）——'后序整合 + 元组状态'八个字，就是树的 DP 全部秘密**。
