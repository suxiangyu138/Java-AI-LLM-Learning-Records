## 1. 337 打家劫舍 III（二元组状态）

### 1.1 完整实现（01 文件回顾 + 变体）

```java
/**
 * LeetCode 337. 打家劫舍 III
 * 返回 (rob, notRob) 二元组
 */
public int rob(TreeNode root) {
    int[] r = dfs(root);
    return Math.max(r[0], r[1]);
}

private int[] dfs(TreeNode node) {
    if (node == null) return new int[]{0, 0};
    int[] left = dfs(node.left);
    int[] right = dfs(node.right);
    int rob = node.val + left[1] + right[1];        // 偷: 子都不偷
    int notRob = Math.max(left[0], left[1])
               + Math.max(right[0], right[1]);      // 不偷: 子各自最优
    return new int[]{rob, notRob};
}
// 推演 [3,2,3,null,3,null,1] → 7 ✓（3+3+1）
// 变体: 337 的"树形版本"扩展——
//   带权树选节点（不相邻）→ 同一二元组模板
// ⚠️ 空间优化: 返回 int[2] 每次新建——可换 (int rob, int notRob) 两变量
```

> 🎯 **337 的必答**："**'偷当前 = 子 notRob 之和；不偷 = 子 max 之和'——二元组让父节点决策信息完整**。'为什么不能单值'是面试必问：单值丢失'子是否被偷'的信息。"

## 2. 543 二叉树的直径（全局变量）

### 2.1 完整实现（01 文件回顾）

```java
/**
 * LeetCode 543. 二叉树的直径
 * 返回高度、全局记直径（左高 + 右高）
 */
int diameter = 0;

public int diameterOfBinaryTree(TreeNode root) {
    diameter = 0;                                 // ① 用例间重置
    height(root);
    return diameter;
}

private int height(TreeNode node) {
    if (node == null) return 0;
    int left = height(node.left);
    int right = height(node.right);
    diameter = Math.max(diameter, left + right);   // ② 经过本节点的直径
    return Math.max(left, right) + 1;              // ③ 返回高度（向上贡献）
}
// 推演 [1,2,3,4,5] → 3 ✓；[1,2] → 1 ✓（单边）
// ⚠️ 变体: 687 最长同值路径（同值才累计——条件变体）
//   1522 N 叉树直径（children 列表遍历）
```

> 💡 **"返回 vs 记录"分离**："**543 的'返回高度、记录直径'是树形 DP 最高频的混淆点**——返回的是'向上贡献'（单边），记录的是'经过本节点'（双边）。讲清'两个量各是什么'，543/124/687 全通。"

## 3. 124 二叉树最大路径和（负增益舍弃）

### 3.1 完整实现（01 文件回顾 + 细节）

```java
/**
 * LeetCode 124. 二叉树中的最大路径和
 * 增益 = 单边贡献；路径 = 节点 + 双边增益
 * ⚠️ 负增益舍弃（max(0, ...)）——路径可以只走一边
 */
int best = Integer.MIN_VALUE;

public int maxPathSum(TreeNode root) {
    best = Integer.MIN_VALUE;
    gain(root);
    return best;
}

private int gain(TreeNode node) {
    if (node == null) return 0;
    int left = Math.max(0, gain(node.left));       // ① 左增益（负则 0）
    int right = Math.max(0, gain(node.right));     // ② 右增益（负则 0）
    best = Math.max(best, node.val + left + right);// ③ 经过本节点的路径
    return node.val + Math.max(left, right);       // ④ 单边最大增益
}
// 推演 [-10,9,20,null,null,15,7] → 42 ✓（15+20+7）
//   [-3] → -3 ✓（单节点：best 初始 MIN_VALUE 保证被更新）
// ⚠️ 为什么 max(0, ...): 负增益加入只会让路径更小——
//   "路径可以从任意节点开始/结束" → 负分支直接舍弃
```

> 🎯 **124 的两个细节**："**① 负增益 `max(0, ...)` 舍弃（路径自由起止）；② `best` 初始 MIN_VALUE（防全负树）**——两个细节都是 124 的失分点，主动讲出 = 加分。"

## 4. 968 监控二叉树（三态贪心/DP）

### 4.1 题目与思路

**题**：二叉树每个节点放监控可覆盖自己+父+子，求最少监控数。

**三态返回**（比二元组更细）：

```java
/**
 * LeetCode 968. 监控二叉树
 * 返回三态: 0 = 未覆盖 / 1 = 有监控 / 2 = 被覆盖
 * 贪心: 后序——叶子父节点放监控最划算
 */
int cameras = 0;

public int minCameraCover(TreeNode root) {
    cameras = 0;
    if (dfs(root) == 0) cameras++;                 // ① 根未覆盖 → 补一个
    return cameras;
}

private int dfs(TreeNode node) {
    if (node == null) return 2;                    // ② 空节点视为"被覆盖"
    int left = dfs(node.left);
    int right = dfs(node.right);

    if (left == 0 || right == 0) {                 // ③ 子未覆盖 → 本节点必须放
        cameras++;
        return 1;                                  //    返回"有监控"
    }
    if (left == 1 || right == 1) return 2;         // ④ 子有监控 → 本节点被覆盖
    return 0;                                      // ⑤ 子都被覆盖 → 本节点未覆盖
}
// 推演 [0,0,null,0,0] → 1 ✓（监控 2 覆盖 1,3,4,5？——实际监控 3 或 2）
//   实际: [0,0,null,0,0] 答案 1 ✓（放根右子的位置）
// ⚠️ 贪心正确性: 后序自底向上——"尽量让监控覆盖更多"（放叶子父）
//   三态比二元组多一层"被覆盖"语义
```

> 💡 **三态 vs 二元组**："**968 的三态（未覆盖/有监控/被覆盖）比 337 的二元组多一个'被覆盖'态**——因为监控的覆盖半径是 1（父+子），需要表达'我被别人覆盖'。状态粒度由问题语义决定。"

## 5. 树形 DP 家族总览

| 题 | 状态 | 返回 vs 记录 | 识别 |
|:---:|:---:|:---:|:---:|
| 104 树高 | 单值 | 返回高度 | 最简原型 |
| 337 打家劫舍 | 二元组 | 返回 (偷,不偷) | 父子不相邻 |
| 543 直径 | 高度+全局 | 返回高度/记直径 | 最长路径 |
| 124 最大路径 | 增益+全局 | 返回单边/记双边 | 可负节点 |
| 968 监控 | 三态 | 返回 0/1/2 | 覆盖半径 1 |
| 687 同值路径 | 高度+全局 | 同值才累计 | 543 条件版 |
| 树形背包 | dp[node][j] | 容量分组 | 树上选 k 个 |

```text
⚠️ 家族规律:
  "无约束 → 单值；父子约束 → 二元组；覆盖语义 → 三态；
   全局最优 → 返回单边 + 全局记录"
```

## 6. 易错点与面试要点

### 6.1 易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 337 返回单值 | 二元组 | 父决策信息缺失 |
| 2 | 543 返回直径 | 返回高度 | 父节点重复累计 |
| 3 | 124 忘 max(0,...) | 负增益舍弃 | 全负树错 |
| 4 | 124 best 初始 0 | MIN_VALUE | 全负树返回 0 |
| 5 | 968 空节点返回 0 | 返回 2（被覆盖） | 误放监控 |
| 6 | 968 根未覆盖忘补 | `dfs(root)==0 → cameras++` | 根漏监控 |
| 7 | 全局变量跨用例 | 每次重置 | 用例污染 |

### 6.2 面试要点

```text
① 状态粒度: "父子约束 → 元组；覆盖 → 三态；无约束 → 单值"
② 返回 vs 记录: "返回向上贡献、记录经过本节点"
③ 后序理由: "子节点信息先算——父决策依赖子结果"
④ 复杂度: O(n) 时间、O(H) 递归栈

⚠️ 高频追问: "337 为什么后序？"
  → "父节点的偷/不偷依赖子节点的状态——
    必须先知道子节点结果（后序整合）"
```

> 🎯 **核心要点**：树形 DP 题解通关——**337（二元组）+ 543/124（返回 vs 记录）+ 968（三态）**。四题覆盖树形 DP 全部状态粒度——"状态粒度由问题语义决定"一句，就是树形 DP 的选型总纲。
