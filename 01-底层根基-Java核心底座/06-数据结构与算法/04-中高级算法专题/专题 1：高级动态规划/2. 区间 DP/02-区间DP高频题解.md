## 1. 312 戳气球（区间 DP 代表作）

### 1.1 题目与思路

**题**：戳破所有气球得 coins[i]×coins[左]×coins[右]，求最大得分。

**"最后一步"逆向**：假设最后戳破的是 k——此时 (i,k) 与 (k,j) 已全被戳掉，**k 的左右邻居是 i 与 j**（补 1 边界）：

```java
/**
 * LeetCode 312. 戳气球
 * dp[i][j] = 戳破 (i,j) 开区间内所有气球的最大得分
 * 转移: 最后戳 k → dp[i][k] + dp[k][j] + nums[i]*nums[k]*nums[j]
 * ⚠️ 开区间: i、j 是"虚拟边界"（不戳），k 是最后戳的
 */
public int maxCoins(int[] nums) {
    int n = nums.length;
    int[] a = new int[n + 2];                   // ① 补虚拟边界 1
    a[0] = a[n + 1] = 1;
    System.arraycopy(nums, 0, a, 1, n);

    int[][] dp = new int[n + 2][n + 2];
    for (int len = 2; len <= n + 1; len++) {    // ② 长度循环（开区间）
        for (int i = 0; i + len <= n + 1; i++) {
            int j = i + len;
            for (int k = i + 1; k < j; k++) {   // ③ k 在开区间内
                dp[i][j] = Math.max(dp[i][j],
                    dp[i][k] + dp[k][j] + a[i] * a[k] * a[j]);
            }
        }
    }
    return dp[0][n + 1];
}
// 推演 [3,1,5,8] → 167 ✓（经典答案）
// ⚠️ 为什么"最后戳 k"正确: k 被戳时左右邻居是 i、j
//   （中间的已全戳掉）→ 子问题 (i,k) 与 (k,j) 完全独立！
```

> 🎯 **312 的必考点**："**'开区间 + 最后戳 k'——k 被戳时邻居是固定的 i、j，这是子问题独立的全部秘密**。补 1 边界让公式统一（乘 1 无影响）。能讲清'为什么逆向'，312 就从 hard 变 medium。"

## 2. 1039 多边形三角剖分

### 2.1 题目与思路

**题**：凸多边形三角剖分，最小化所有三角形顶点值乘积之和。

**与 312 同构**：区间 [i,j] 选顶点 k 组成三角形 (i,k,j)：

```java
/**
 * LeetCode 1039. 多边形三角剖分的最低得分
 * dp[i][j] = 顶点 [i,j] 子多边形的最小得分
 * 转移: 选 k 与 i、j 成三角形 → dp[i][k] + dp[k][j] + v[i]*v[k]*v[j]
 * ⚠️ 与 312 完全同构——"开区间 + 最后分割点 k"！
 */
public int minScoreTriangulation(int[] values) {
    int n = values.length;
    int[][] dp = new int[n][n];
    for (int len = 2; len < n; len++) {         // ① 长度（至少 3 个顶点）
        for (int i = 0; i + len < n; i++) {
            int j = i + len;
            dp[i][j] = Integer.MAX_VALUE;
            for (int k = i + 1; k < j; k++) {
                dp[i][j] = Math.min(dp[i][j],
                    dp[i][k] + dp[k][j] + values[i] * values[k] * values[j]);
            }
        }
    }
    return dp[0][n - 1];
}
// 推演 [1,2,3] → 6 ✓（唯一三角形 1×2×3）
//   [3,7,4,5] → 144 ✓（两种剖分取最小）
// ⚠️ 识别: "凸多边形 + 剖分/三角" → 与 312 同模板
```

> 💡 **同构识别**："**1039 = 312 的几何版——'开区间 + 选 k 组成三角形'与'开区间 + 最后戳 k'完全同构**。会 312 就能 10 分钟写 1039，这是区间 DP 模板复用能力的直接体现。"

## 3. 647 回文子串与 516 回文子序列

### 3.1 647 回文子串（计数，中心扩展/DP）

```java
/**
 * LeetCode 647. 回文子串的个数
 * dp[i][j] = s[i..j] 是否回文
 * 转移: 两端相同 && (长度 ≤ 2 || 内层回文)
 */
public int countSubstrings(String s) {
    int n = s.length();
    boolean[][] dp = new boolean[n][n];
    int count = 0;
    for (int i = n - 1; i >= 0; i--) {           // ① i 递减（依赖 i+1）
        for (int j = i; j < n; j++) {
            if (s.charAt(i) == s.charAt(j)
                && (j - i <= 2 || dp[i + 1][j - 1])) {   // ② 收缩判定
                dp[i][j] = true;
                count++;
            }
        }
    }
    return count;
}
// 推演 "abc" → 3（a,b,c）✓；"aaa" → 6 ✓
// ⚠️ j−i ≤ 2 覆盖: 单字符/双字符（无需内层）
//   中心扩展版 O(n²)/O(1) 更省空间（专题 1 讲过）
```

## 4. 石子合并环形版

### 4.1 环形处理

```java
/**
 * 石子合并（环形版）
 * 破环为链: 数组复制一份（长度 2n）
 * 答案 = min(dp[i][i+n−1])  i ∈ [0, n)
 */
int stoneMergeCircle(int[] stones) {
    int n = stones.length;
    int[] a = new int[2 * n];                    // ① 破环为链
    for (int i = 0; i < 2 * n; i++) a[i] = stones[i % n];

    // 前缀和 + dp（同线性版，长度 n 的窗口）
    int[][] dp = new int[2 * n][2 * n];
    int best = Integer.MAX_VALUE;
    for (int i = 0; i < n; i++) {                // ② 每个起点取最小
        best = Math.min(best, /* dp[i][i+n-1] */);
    }
    return best;
}
// ⚠️ 环形通用技巧: "破环为链（复制 2 倍）+ 滑动窗口取 min"
//   适用: 环形石子、环形戳气球、环形打家劫舍
```

## 5. 区间 DP 变体总览

| 题 | 类型 | 转移形态 | 与母题关系 |
|:---:|------|:---:|------|
| 312 戳气球 | 分割型 | dp[i][k] + dp[k][j] + 乘积 | 母题 |
| 1039 三角剖分 | 分割型 | 同 312（几何版） | 同构 |
| 石子合并 | 分割型 | dp[i][k] + dp[k+1][j] + 区间和 | 母题 |
| 矩阵链乘法 | 分割型 | dp[i][k] + dp[k+1][j] + 维度积 | 石子同构 |
| 647 回文子串 | 收缩型 | 两端相同 + 内层 | 收缩母题 |
| 516 回文子序列 | 收缩型 | 相同 +2 / 去一端 | 收缩母题 |

## 6. 易错点与面试要点

### 6.1 易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 312 忘补边界 1 | a[0]=a[n+1]=1 | 边界乘法错 |
| 2 | 312 开区间理解错 | dp(i,j) 不含 i,j | 边界被戳 |
| 3 | 1039 长度从 1 起 | len ≥ 2（至少 3 顶点） | 越界 |
| 4 | 647 忘 `j−i ≤ 2` | 双/单字符特判 | 内层越界 |
| 5 | 环忘复制数组 | 2n 长度 | 环形漏最优 |
| 6 | 分割点 k 取到端点 | k ∈ (i, j) 开区间 | 非法三角形 |
| 7 | 遍历顺序错 | 长度在外 | 用到未算区间 |

### 6.2 面试要点

```text
① "最后一步"开场: "假设最后戳破的是 k……"
② 子问题独立论证: "k 左右的气球已全戳掉 → (i,k) 与 (k,j) 独立"
③ 复杂度: O(n³) 时间、O(n²) 空间
④ 变体识别: 三角剖分 = 312 同构；插入成回文 = n − LPS

⚠️ 高频追问: "312 为什么是 O(n³)？"
  → "三层循环: 长度 n × 起点 n × 分割点 n"
```

> 🎯 **核心要点**：区间 DP 题解通关——**312（最后戳 k + 补边界）+ 1039（同构）+ 647/516（收缩型）+ 石子环形（破环为链）**。四题覆盖两种转移形态与环形处理——"最后一步 + 开区间"八个字，就是区间 DP 的全部钥匙。
