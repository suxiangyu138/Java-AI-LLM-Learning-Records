## 1. 区间 DP 模型：状态与转移

```text
区间 DP: 处理区间 [i, j] 上的子问题
  状态: dp[i][j] = 区间 [i,j] 的最优值
  转移: 枚举分割点 k，拆成 [i,k] 与 [k+1,j] 分别求解后合并

   dp[i][j] = optimal(dp[i][k] + cost + dp[k+1][j])  （k ∈ [i, j))

适用: 区间分割/合并/爆破/回文
  例: 石子合并、矩阵链乘法、312 戳气球、1039 三角剖分

⚠️ 遍历顺序: 按区间长度从小到大（先小区间后大区间）——
  dp[i][j] 依赖更短的区间，必须先算短的
```

> 🎯 **核心认知**："**区间 DP 的灵魂 = '区间拆两半'——dp[i][j] 由 dp[i][k] 与 dp[k+1][j] 拼出**。'长度从小到大'的遍历顺序是它区别于线性 DP 的最大特征。"

## 2. 长度枚举模板（核心）

### 2.1 通用模板

```java
/**
 * 区间 DP 通用模板
 * 三层循环: 长度 → 起点 → 分割点
 */
int intervalDP(int[] nums) {
    int n = nums.length;
    int[][] dp = new int[n][n];

    // ① 长度从 2 开始（长度 1 的区间是 base case）
    for (int len = 2; len <= n; len++) {
        for (int i = 0; i <= n - len; i++) {       // ② 起点
            int j = i + len - 1;                   // ③ 终点
            dp[i][j] = Integer.MAX_VALUE;
            for (int k = i; k < j; k++) {          // ④ 分割点
                dp[i][j] = Math.min(dp[i][j],
                    dp[i][k] + cost(i, k, j) + dp[k + 1][j]);
            }
        }
    }
    return dp[0][n - 1];
}
// ⚠️ 长度 1 的 dp[i][i] 需要初始化（base case）
//   cost(i,k,j) 是合并 [i,k] 与 [k+1,j] 的额外代价
```

### 2.2 模板三要素

```text
① 长度循环: len 从小到大（依赖更短区间）
② 起终枚举: i 从 0、j = i+len−1
③ 分割点 k: 枚举所有切法，取最优

⚠️ 记忆: "三层循环 = 长度 × 起点 × 切点——
   顺序不能乱（长度在最外层！）"
```

> 🎯 **模板的灵魂**："**'长度在外、起点在中、切点在内'——这个顺序保证'算 dp[i][j] 时它的子区间全已算好'**。顺序错 = 用到未计算的子区间 = 结果错。"

## 3. "最后一步"逆向思维

### 3.1 为什么从"最后一步"想

```text
正向想: "第一步合并哪两堆？" → 选择太多、子问题纠缠
逆向想: "最后一步合并的区间是 [i,j]？" → 分割点 k 自然浮现

例（312 戳气球）:
  正向: 先戳哪个？→ 戳掉后区间分裂，依赖混乱
  逆向: 最后戳破的气球是 k？
    → 戳 k 时 [i,k) 与 (k,j] 已全被戳掉
    → 子问题: 区间 [i,k) 与 (k,j] 互不干扰！✓

⚠️ 判断口诀:
  "区间题'最后一步'想——最后操作的对象是谁？
   它的左右两侧自然分成独立子问题"
```

> 💡 **逆向思维的通用性**："**'最后一步'是区间 DP 的破题点——戳气球的最后一只、合并的最后一刀、切割的最后一块**。找到'最后操作对象'，分割点 k 与独立子问题就都出来了。"

## 4. 石子合并（基础母题）

### 4.1 题目与思路

**题**：N 堆石子围成环，每次合并相邻两堆，代价 = 两堆之和，求最小总代价。

**线性版**（先掌握）：

```java
/**
 * 石子合并（线性版）
 * dp[i][j] = 合并 [i,j] 的最小代价
 * 转移: dp[i][j] = min(dp[i][k] + dp[k+1][j]) + sum[i][j]
 */
int stoneMerge(int[] stones) {
    int n = stones.length;
    int[] prefix = new int[n + 1];               // ① 前缀和（快速求区间和）
    for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + stones[i];

    int[][] dp = new int[n][n];
    for (int len = 2; len <= n; len++) {
        for (int i = 0; i <= n - len; i++) {
            int j = i + len - 1;
            dp[i][j] = Integer.MAX_VALUE;
            for (int k = i; k < j; k++) {
                dp[i][j] = Math.min(dp[i][j],
                    dp[i][k] + dp[k + 1][j] + (prefix[j + 1] - prefix[i]));
            }
        }
    }
    return dp[0][n - 1];
}
// 推演 [1,2,3]：合并 (1,2)=3 → 3+3=6；或 (2,3)=5 → 5+1=6 → 6 ✓
// ⚠️ 环形版: 数组复制一份（长度 2n），取 min(dp[i][i+n−1])
```

> 🎯 **石子合并的模板地位**："**石子合并 = 区间 DP 的'Hello World'——cost 就是区间和（前缀和 O(1) 取）**。会它就会矩阵链乘法（cost = 维度乘积）与一切'合并代价'型区间 DP。"

## 5. 回文类区间 DP

### 5.1 516 最长回文子序列

```java
/**
 * LeetCode 516. 最长回文子序列
 * dp[i][j] = s[i..j] 的最长回文子序列
 * 转移: 两端相同 +2 / 不同取 max(去左, 去右)
 */
public int longestPalindromeSubseq(String s) {
    int n = s.length();
    int[][] dp = new int[n][n];
    for (int i = n - 1; i >= 0; i--) {           // ① 从右往左（依赖 i+1）
        dp[i][i] = 1;                            // ② 单字符回文
        for (int j = i + 1; j < n; j++) {
            if (s.charAt(i) == s.charAt(j)) {
                dp[i][j] = dp[i + 1][j - 1] + 2; // ③ 两端相同 → 内层 + 2
            } else {
                dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1]);  // ④ 去一端
            }
        }
    }
    return dp[0][n - 1];
}
// 推演 "bbbab" → 4 ✓（"bbbb"）
// ⚠️ 遍历方向: i 从右往左（dp[i][j] 依赖 dp[i+1][*]）
//   —— 区间 DP 的"长度从小到大"在这里表现为"i 递减、j 递增"
```

> 💡 **回文区间 DP 的两种形态**："**516 的'两端收缩'（相同 +2）与戳气球的'中间分割'（k 切两半）是区间 DP 的两大转移形态**——'收缩型'适合回文、'分割型'适合合并。"

## 6. 识别信号与易错点

### 6.1 识别信号

```text
"区间/子串 + 合并/分割/爆破/切割" → 区间 DP
"回文子序列/子串 + 最优" → 回文区间 DP
"矩阵链/石子/多边形" → 经典区间 DP

⚠️ 与线性 DP 区分:
  线性: 前缀/后缀递推（一维）
  区间: 任意 [i,j] 子区间（二维 + 分割点）

⚠️ 面试定位: 戳气球（312）是 Google/Amazon 高频 hard——
  "hard 变 medium"的区间 DP 经典
```

### 6.2 易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 长度循环在外层 | len 最外层 | 用到未算的子区间 |
| 2 | 忘初始化长度 1 | dp[i][i] = base | 转移引用空值 |
| 3 | 分割点 k 边界 | k ∈ [i, j) | 漏切法/越界 |
| 4 | cost 忘加 | 合并代价（区间和等） | 结果偏小 |
| 5 | 回文遍历方向错 | i 递减 j 递增 | 依赖未算 |
| 6 | 环忘复制数组 | 长度 2n 取 min | 环形漏最优 |
| 7 | 状态定义不清 | 先讲 dp[i][j] 含义 | 转移错 |

> 🎯 **核心要点**：区间 DP 通关四件事——**① 长度枚举模板**（长度×起点×切点三层）；**② "最后一步"逆向思维**（戳气球/合并最后一刀）；**③ 两种转移形态**（分割型/收缩型）；**④ 石子合并母题**（前缀和 cost）。**区间 DP 是面试压轴题（312 高频）——'最后一步想、长度从小排'十个字，就是全部钥匙**。
