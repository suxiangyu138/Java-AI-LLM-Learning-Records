## 1. 多维 DP 模型：状态维度与转移

```text
多维 DP = 状态含 2 个以上维度:
  dp[i][j]: 二维（网格/双序列）
  dp[i][j][k]: 三维（+ 剩余容量/步数/数量）

三大模型:
  ① 网格类: dp[i][j] = 到 (i,j) 的最优值（62/64）
  ② 双序列类: dp[i][j] = 前 i/j 个的最优（72 LCS）
  ③ 背包类: dp[i][j] = 前 i 个物品容量 j（0/1、完全）

转移范式:
  网格: 从上/左来（dp[i][j] = f(dp[i-1][j], dp[i][j-1]))
  双序列: 匹配/跳过（dp[i][j] = f(dp[i-1][j-1], dp[i-1][j], dp[i][j-1]))
  背包: 选/不选（dp[j] = max(dp[j], dp[j-w] + v))

⚠️ 面试重点: 状态定义 + 转移方程的"为什么对"
```

> 🎯 **核心认知**："**多维 DP 的维度 = 问题的'自由度'——网格两坐标、双序列两指针、背包加容量**。识别'几个自由变量'就是确定维度数。"

## 2. 网格类：二维状态 (i,j)

### 2.1 64 最小路径和（模板）

```java
/**
 * LeetCode 64. 最小路径和
 * dp[i][j] = 到 (i,j) 的最小和 = min(上, 左) + grid[i][j]
 * 时间 O(mn)，空间 O(mn)（可滚动 O(n)）
 */
public int minPathSum(int[][] grid) {
    int m = grid.length, n = grid[0].length;
    int[][] dp = new int[m][n];
    dp[0][0] = grid[0][0];
    for (int i = 1; i < m; i++) dp[i][0] = dp[i-1][0] + grid[i][0];   // 首列
    for (int j = 1; j < n; j++) dp[0][j] = dp[0][j-1] + grid[0][j];   // 首行
    for (int i = 1; i < m; i++)
        for (int j = 1; j < n; j++)
            dp[i][j] = Math.min(dp[i-1][j], dp[i][j-1]) + grid[i][j];
    return dp[m-1][n-1];
}
// 推演 [[1,3,1],[1,5,1],[4,2,1]] → 7 ✓（1→3→1→1→1）
// ⚠️ 首行首列初始化（只能直走）是网格 DP 的边界要点
```

> 💡 **网格模板**："**dp[i][j] = min(上, 左) + 当前值——首行首列单独初始化**。62 路径数（加法）、64 最小和（min）是同一模板的两种聚合。"

## 3. 双序列类：LCS 与编辑距离

### 3.1 1143 最长公共子序列（LCS 模板）

```java
/**
 * LeetCode 1143. 最长公共子序列
 * dp[i][j] = text1[0..i) 与 text2[0..j) 的 LCS
 * 转移: 相同 +1 / 不同取 max(删一, 删二)
 */
public int longestCommonSubsequence(String text1, String text2) {
    int m = text1.length(), n = text2.length();
    int[][] dp = new int[m + 1][n + 1];          // ① +1 哨兵（空串）
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                dp[i][j] = dp[i - 1][j - 1] + 1;   // ② 相同 → 对角线 +1
            } else {
                dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);  // ③ 不同 → 取 max
            }
        }
    }
    return dp[m][n];
}
// 推演 "abcde" vs "ace" → 3 ✓（"ace"）
// ⚠️ 双序列模板: dp[i][j] = 前 i/j 个；三种转移（匹配/删一/删二）
//   72 编辑距离 = 同模板 + 增删改三种代价
```

### 3.2 双序列 vs 网格

| 维度 | 网格（64） | 双序列（1143） |
|------|:---:|:---:|
| 状态 | 坐标 (i,j) | 前缀长度 (i,j) |
| 边界 | 首行首列 | 第 0 行/列（空串） |
| 转移 | 上/左 | 对角线/上/左 |
| 模板 | min(上,左)+当前 | 匹配 +1 / 不匹配 max |

## 4. 背包家族：0/1 与完全

### 4.1 0/1 背包（每物一次）

```java
/**
 * 0/1 背包: 每物品最多选一次
 * dp[j] = 容量 j 的最大价值
 * ⚠️ 逆序更新（防止重复选同一物品）
 */
int knapsack01(int[] w, int[] v, int capacity) {
    int[] dp = new int[capacity + 1];
    for (int i = 0; i < w.length; i++) {
        for (int j = capacity; j >= w[i]; j--) {    // ⚠️ 逆序！
            dp[j] = Math.max(dp[j], dp[j - w[i]] + v[i]);
        }
    }
    return dp[capacity];
}
// ⚠️ 逆序原因: 正序时 dp[j-w[i]] 可能已被本物品更新过
//   → 同一物品被选多次（那是完全背包！）
```

### 4.2 完全背包（无限次）与分组

```java
// 完全背包: 正序更新（允许重复选）
for (int j = w[i]; j <= capacity; j++)
    dp[j] = Math.max(dp[j], dp[j - w[i]] + v[i]);

// 分组背包: 每组最多选一个（组内 0/1）
for (每个组)
    for (int j = capacity; j >= 0; j--)          // 逆序（组内 0/1）
        for (物品 in 组)
            if (j >= w) dp[j] = max(dp[j], dp[j-w] + v);

// ⚠️ 顺序口诀: "0/1 逆序、完全正序、分组组内逆序"
```

> 🎯 **背包三问**："**0/1 逆序（防重复）、完全正序（允重复）、分组外层组**——三个顺序决定三种语义。'选不选/选几次/选几个'是背包家族的第一识别。"

## 5. 滚动数组：二维压一维

### 5.1 原理与实现

```java
// 二维 DP → 一维滚动（只保留上一行）
// 64 最小路径和的滚动版:
int[] dp = new int[n];
Arrays.fill(dp, Integer.MAX_VALUE);
dp[0] = 0;
for (int i = 0; i < m; i++) {
    for (int j = 0; j < n; j++) {
        if (j > 0) dp[j] = Math.min(dp[j], dp[j - 1]);   // min(上, 左)
        dp[j] += grid[i][j];
    }
}
// ⚠️ 空间 O(mn) → O(n)；背包已是一维滚动形态

// 何时不能滚动: 转移依赖"对角线"且需回溯路径（LCS 可滚动但要省路径则不能）
```

### 5.2 滚动数组的覆盖顺序（灵魂）

```text
依赖"上方 + 左方" → 正序滚动（从左到右）
依赖"左上（对角线）" → 需保存 prev 变量（LCS）
0/1 背包依赖"左侧旧值" → 逆序滚动（从右到左）

⚠️ 一句话: "先看依赖方向，再定滚动顺序——
   覆盖顺序错了 = 用了新值当旧值"
```

## 6. 识别信号与易错点

### 6.1 识别信号

```text
"网格/矩阵 + 最优/路径数" → 网格类（62/64）
"两个序列/字符串 + 匹配/编辑" → 双序列类（1143/72）
"容量 + 价值 + 选物品" → 背包类
"三个自由变量（如 i,j,k 步数）" → 三维 DP

⚠️ 三维例: 576 出界路径（(i,j,剩余步数)）、688 骑士概率
```

### 6.2 易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 网格忘初始化首行首列 | 边界单独初始化 | 边界值错 |
| 2 | 双序列忘 +1 哨兵 | dp[m+1][n+1]（空串行） | 越界/漏空串 |
| 3 | 0/1 背包正序 | 逆序更新 | 物品重复选 |
| 4 | 完全背包逆序 | 正序更新 | 物品只能选一次 |
| 5 | 滚动顺序错 | 按依赖方向定 | 新值污染旧值 |
| 6 | 状态维度过度 | 能回答的最小状态 | 空间浪费/超时 |
| 7 | 转移"为什么对"讲不清 | 解释状态定义 | 面试失分 |

> 🎯 **核心要点**：多维 DP 通关四件事——**① 三大模型识别**（网格/双序列/背包）；**② 滚动数组顺序**（依赖方向决定）；**③ 背包三顺序口诀**（0/1 逆、完全正、分组组内逆）；**④ 状态定义能解释**。**多维 DP 是高级 DP 的地基——会了它，区间/树形只是'维度换成区间/节点'**。
