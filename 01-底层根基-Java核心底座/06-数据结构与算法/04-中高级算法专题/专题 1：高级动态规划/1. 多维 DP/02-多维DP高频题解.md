## 1. 62 不同路径与 63 不同路径 II（网格）

### 1.1 62 不同路径

```java
/**
 * LeetCode 62. 不同路径
 * dp[i][j] = 到 (i,j) 的路径数 = 上 + 左
 * 时间 O(mn)，空间 O(n)（滚动）
 */
public int uniquePaths(int m, int n) {
    int[] dp = new int[n];
    Arrays.fill(dp, 1);                          // ① 首行全 1（只能横走）
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            dp[j] += dp[j - 1];                  // ② dp[j] = 上 + 左（滚动）
        }
    }
    return dp[n - 1];
}
// 推演 3×3 → 6 ✓；3×7 → 28 ✓
// ⚠️ 组合数解: C(m+n−2, m−1)——数学版 O(min(m,n))
```

### 1.2 63 不同路径 II（含障碍）

```java
/**
 * LeetCode 63. 不同路径 II
 * 障碍格 dp = 0；首行首列遇障碍后全 0
 */
public int uniquePathsWithObstacles(int[][] grid) {
    int m = grid.length, n = grid[0].length;
    int[] dp = new int[n];
    dp[0] = grid[0][0] == 0 ? 1 : 0;             // ① 起点可能被堵
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (grid[i][j] == 1) { dp[j] = 0; continue; }   // ② 障碍清零
            if (j > 0) dp[j] += dp[j - 1];       // ③ 上 + 左
        }
    }
    return dp[n - 1];
}
// 推演 [[0,0,0],[0,1,0],[0,0,0]] → 2 ✓
// ⚠️ 边界: 起点/终点被堵返回 0；首行首列遇障碍后全 0
```

## 2. 64 最小路径和（滚动数组版）

### 2.1 滚动实现

```java
/**
 * LeetCode 64. 最小路径和（滚动数组版）
 * 空间 O(mn) → O(n)
 */
public int minPathSum(int[][] grid) {
    int m = grid.length, n = grid[0].length;
    int[] dp = new int[n];
    Arrays.fill(dp, Integer.MAX_VALUE);
    dp[0] = 0;
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (j > 0) dp[j] = Math.min(dp[j], dp[j - 1]);  // min(上, 左)
            dp[j] += grid[i][j];
        }
    }
    return dp[n - 1];
}
// 推演 [[1,3,1],[1,5,1],[4,2,1]] → 7 ✓
// ⚠️ 正序滚动（依赖左方）——与背包逆序对比记忆
```

## 3. 72 编辑距离（双序列经典）

### 3.1 完整实现

```java
/**
 * LeetCode 72. 编辑距离
 * dp[i][j] = word1[0..i) → word2[0..j) 的最少操作
 * 转移: 相同继承 / 不同 min(增, 删, 改) + 1
 */
public int minDistance(String word1, String word2) {
    int m = word1.length(), n = word2.length();
    int[][] dp = new int[m + 1][n + 1];
    for (int i = 0; i <= m; i++) dp[i][0] = i;   // ① 删光 word1
    for (int j = 0; j <= n; j++) dp[0][j] = j;   // ② 插入 word2

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                dp[i][j] = dp[i - 1][j - 1];     // ③ 相同 → 继承
            } else {
                dp[i][j] = Math.min(dp[i - 1][j],        // 删除
                           Math.min(dp[i][j - 1],        // 插入
                                    dp[i - 1][j - 1])) + 1;  // 替换
            }
        }
    }
    return dp[m][n];
}
// 推演 "horse" → "ros" → 3 ✓（horse→rorse→rose→ros）
// ⚠️ 三种操作对应三个方向: 删=上、插=左、改=左上
```

> 🎯 **72 的必考点**："**编辑距离 = LCS 模板 + 三种代价——相同继承、不同 min(删/插/改)+1**。'三个方向对应三种操作'是面试必讲细节。"

## 4. 1143 最长公共子序列（LCS）

### 4.1 完整实现（01 文件回顾 + 变体）

```java
/**
 * LeetCode 1143. 最长公共子序列
 */
public int longestCommonSubsequence(String text1, String text2) {
    int m = text1.length(), n = text2.length();
    int[][] dp = new int[m + 1][n + 1];
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (text1.charAt(i - 1) == text2.charAt(j - 1))
                dp[i][j] = dp[i - 1][j - 1] + 1;
            else
                dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
        }
    }
    return dp[m][n];
}
// 变体: 1035 不相交的线（LCS 换皮）、583 删除两字符串（m+n−2·LCS）
// ⚠️ 最长回文子序列 = s 与 s 反转的 LCS（516）
```

## 5. 背包家族：416/322/518

### 5.1 416 分割等和子集（0/1 背包判定）

```java
/**
 * LeetCode 416. 分割等和子集
 * 0/1 背包: 能否凑出 sum/2
 * ⚠️ 逆序滚动（0/1 语义）
 */
public boolean canPartition(int[] nums) {
    int sum = 0;
    for (int x : nums) sum += x;
    if (sum % 2 != 0) return false;              // ① 奇数不可能
    int target = sum / 2;
    boolean[] dp = new boolean[target + 1];
    dp[0] = true;
    for (int x : nums) {
        for (int j = target; j >= x; j--) {      // ② 逆序（0/1）
            dp[j] = dp[j] || dp[j - x];
        }
    }
    return dp[target];
}
// 推演 [1,5,11,5] → 11 ✓（[1,5,5] 与 [11]）
```

### 5.2 322 零钱兑换（完全背包）与 518 组合数

```java
/**
 * LeetCode 322. 零钱兑换（完全背包最小值）
 * 正序滚动（硬币无限次）
 */
public int coinChange(int[] coins, int amount) {
    int[] dp = new int[amount + 1];
    Arrays.fill(dp, amount + 1);
    dp[0] = 0;
    for (int coin : coins) {
        for (int j = coin; j <= amount; j++) {   // ① 正序（完全背包）
            dp[j] = Math.min(dp[j], dp[j - coin] + 1);
        }
    }
    return dp[amount] > amount ? -1 : dp[amount];
}
// 推演 [1,2,5], amount=11 → 3 ✓（5+5+1）

// 518 零钱兑换 II（组合数）: dp[j] += dp[j−coin]（正序）
// ⚠️ 三题区分: 416 判定（boolean）、322 最少（min）、518 计数（求和）
```

> 🎯 **背包三题**："**416 判定、322 最少、518 计数——同一模板三种聚合（boolean/min/sum）**。'0/1 逆序、完全正序'的滚动顺序是全部背包题的共同纪律。"

## 6. 易错点与面试要点

### 6.1 易错点

| # | 题 | 易错点 | 正确写法 |
|:---:|:---:|------|------|
| 1 | 63 | 首行首列障碍后不清零 | 遇障碍后续全 0 |
| 2 | 63 | 起点被堵 | `dp[0] = grid[0][0]==0 ? 1 : 0` |
| 3 | 72 | 初始化漏空串行 | dp[i][0]=i、dp[0][j]=j |
| 4 | 72 | 替换方向错 | dp[i-1][j-1] 是"改" |
| 5 | 416 | 忘奇数和判断 | sum%2 != 0 → false |
| 6 | 322 | 正序逆序混 | 完全正序/0/1 逆序 |
| 7 | 518 | 组合/排列混 | 外层物品（组合）；外层容量是排列 |

### 6.2 面试要点

```text
① 状态定义先讲清: "dp[i][j] 表示……"——再写转移
② 滚动数组主动提: "空间可以 O(mn) 压到 O(n)"
③ 双序列三方向: 匹配/删/插/改的方向语义
④ 背包三聚合: 判定/最值/计数对应 boolean/min/sum

⚠️ 高频追问: "为什么 0/1 逆序？"
  → "正序时 dp[j−w] 可能已被本物品更新——会重复选；
    逆序保证用的是'上一轮'的旧值"
```

> 🎯 **核心要点**：多维 DP 题解通关——**网格三题（62/63/64）+ 双序列两题（72/1143）+ 背包三题（416/322/518）**。八题覆盖三大模型全部形态——"状态定义 + 滚动顺序 + 聚合方式"三要素齐备，多维 DP 就是送分题。
