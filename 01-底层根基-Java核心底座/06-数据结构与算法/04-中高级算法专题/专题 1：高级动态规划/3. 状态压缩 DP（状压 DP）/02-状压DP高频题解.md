## 1. 847 访问所有节点的最短路径（TSP 变体）

### 1.1 题目与思路

**题**：无向图访问所有节点至少一次的最短路径（可重复访问节点）。

**与 TSP 的差异**：可重复访问 → 先 Floyd 求全源最短，再套 TSP：

```java
/**
 * LeetCode 847. 访问所有节点的最短路径
 * ① Floyd 预处理全源最短（可重复访问 → 任意两点间走最短路）
 * ② TSP 模板: dp[mask][i]
 */
public int shortestPathLength(int[][] graph) {
    int n = graph.length;
    // ① Floyd: dist[i][j] = 全源最短
    int[][] dist = new int[n][n];
    for (int[] row : dist) Arrays.fill(row, 1000);
    for (int i = 0; i < n; i++) {
        dist[i][i] = 0;
        for (int j : graph[i]) dist[i][j] = 1;
    }
    for (int k = 0; k < n; k++)
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                dist[i][j] = Math.min(dist[i][j], dist[i][k] + dist[k][j]);

    // ② TSP 模板（dp[mask][i]）
    int full = (1 << n) - 1;
    int[][] dp = new int[1 << n][n];
    for (int[] row : dp) Arrays.fill(row, 1000);
    for (int i = 0; i < n; i++) dp[1 << i][i] = 0;   // 起点任意（可从任一点开始）

    for (int mask = 1; mask <= full; mask++) {
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                int nextMask = mask | (1 << j);
                dp[nextMask][j] = Math.min(dp[nextMask][j],
                    dp[mask][i] + dist[i][j]);
            }
        }
    }
    int best = Integer.MAX_VALUE;
    for (int i = 0; i < n; i++) best = Math.min(best, dp[full][i]);
    return best;
}
// 推演 [[1,2,3],[0],[0],[0]] → 4 ✓（0→1→0→2→0→3）
// ⚠️ 与 TSP 差异: ① 全源最短预处理（可重复访问）② 起点任意
```

> 🎯 **847 的变体识别**："**'可重复访问' → Floyd 全源最短 + TSP**——把'重复访问'翻译成'两点间走最短路'，问题就归约成 TSP。'归约思想'是状压变体题的核心能力。"

## 2. 526 优美的排列（mask 计数）

### 2.1 题目与思路

**题**：1..n 的排列，满足位置 i 被 i 整除或整除 i，求个数。

**mask 记"已放置的数字集合"**：

```java
/**
 * LeetCode 526. 优美的排列
 * dp[mask] = 放置 mask 集合的优美排列数
 * 时间 O(n·2ⁿ)，空间 O(2ⁿ)
 */
public int countArrangement(int n) {
    int[] dp = new int[1 << n];
    dp[0] = 1;
    for (int mask = 0; mask < (1 << n); mask++) {
        int pos = Integer.bitCount(mask) + 1;    // ① 下一个放置位置（已放 + 1）
        for (int i = 1; i <= n; i++) {
            if (((mask >> (i - 1)) & 1) == 1) continue;   // ② 已放置
            if (i % pos != 0 && pos % i != 0) continue;   // ③ 优美条件
            dp[mask | (1 << (i - 1))] += dp[mask];        // ④ 累加
        }
    }
    return dp[(1 << n) - 1];
}
// 推演 n=2: 排列 [1,2]（1|1、2|2）与 [2,1]（2%1=0、1%2≠0 但 2%1）→ 2 ✓
// ⚠️ mask 一维即可: "位置"由 bitCount 推出（不需第二维）——
//   状态 = 已放集合，位置是确定函数
```

> 💡 **mask 一维 vs 二维**："**526 的'位置'可由 mask 推出（bitCount）→ 一维够用**；847 的'当前位置'不由 mask 决定 → 需要第二维。'位置能否由 mask 推导'是维度选择的判据。"

## 3. 464 我能赢吗（博弈状压）

### 3.1 完整实现（01 文件回顾 + 深潜）

```java
/**
 * LeetCode 464. 我能赢吗
 * dp[mask] = 该状态先手能否赢（Boolean 三态）
 * ⚠️ 博弈状压三要素: mask 状态 + 三态缓存 + 必败转移
 */
public boolean canIWin(int maxChoosableInteger, int desiredTotal) {
    int sum = (1 + maxChoosableInteger) * maxChoosableInteger / 2;
    if (sum < desiredTotal) return false;        // ① 总和不够必输
    if (desiredTotal <= 0) return true;          // ② 目标已达成
    return dfs(0, desiredTotal, maxChoosableInteger,
               new Boolean[1 << maxChoosableInteger]);
}

private boolean dfs(int mask, int remain, int max, Boolean[] memo) {
    if (memo[mask] != null) return memo[mask];
    for (int i = 1; i <= max; i++) {
        if (((mask >> (i - 1)) & 1) == 1) continue;
        if (i >= remain) return memo[mask] = true;   // ③ 选 i 直接赢
        if (!dfs(mask | (1 << (i - 1)), remain - i, max, memo))
            return memo[mask] = true;               // ④ 对手必输 → 我赢
    }
    return memo[mask] = false;                      // ⑤ 所有选择对手都赢 → 我输
}
// 推演 max=10, total=11 → true ✓（先手选 1 后对手必输）
// ⚠️ 博弈核心: "存在一步让对手必输 → 本状态赢；
//   所有步对手都赢 → 本状态输"——记忆化缓存胜负
```

> 🎯 **博弈状压的必考点**："**'存在一步对手必输 = 赢'的转移 + Boolean 三态缓存**——博弈 DP 与普通 DP 的差异就在'胜负传递'语义。464 是博弈状压的面试代表。"

## 4. 943 最短超级串（TSP 变体）

### 4.1 题目与思路

**题**：用所有字符串拼接成最短的含全部子串的串（顺序可任意）。

**TSP 归约**：`dist[i][j] = 拼接 i→j 的额外长度`（重叠部分不计）：

```java
/**
 * LeetCode 943. 最短超级串
 * ① 预处理 dist[i][j] = j 拼到 i 后的额外长度（重叠部分）
 * ② TSP 模板: dp[mask][i] = 以 i 结尾的最小额外长度
 */
public String shortestSuperstring(String[] words) {
    int n = words.length;
    // ① dist[i][j]: words[j] 接到 words[i] 后的新增长度
    int[][] dist = new int[n][n];
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++) {
            if (i == j) continue;
            dist[i][j] = words[j].length();
            for (int k = 0; k < words[i].length(); k++) {

                    dist[i][j] = words[j].length() - (words[i].length() - k);
```

> 💡 **TSP 归约的通用性**："**943 = TSP 换皮——'顺序任意的最短拼接' = '访问所有节点的最短路径'**。识别'顺序自由 + 最优'结构，先归约再套模板，是状压进阶的核心能力。"

## 5. 状压 DP 家族总览

| 题 | 状态 | 类型 | 与 TSP 关系 |
|:---:|:---:|:---:|:---:|
| TSP | dp[mask][i] | 最短路 | 母题 |
| 847 访问所有 | dp[mask][i] + Floyd | 最短路 | 可重复版 |
| 943 超级串 | dp[mask][i] + dist | 最短路 | 拼接版 |
| 526 优美排列 | dp[mask] | 计数 | mask 一维 |
| 464 我能赢吗 | dp[mask] 三态 | 博弈 | 胜负传递 |
| 691 贴纸拼词 | dp[mask] | 最值 | 集合目标版 |

```text
⚠️ 家族规律:
  "最短路 → dp[mask][i]（+i 维）
   计数/博弈 → dp[mask]（一维）
   变体 = 预处理 dist + TSP 模板"
```

## 6. 易错点与面试要点

### 6.1 易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 847 忘 Floyd | 可重复访问需全源最短 | 路径漏走最短路 |
| 2 | 847 起点固定 0 | 起点任意（dp[1<<i][i]=0） | 漏最优起点 |
| 3 | 526 位置计算错 | `bitCount(mask) + 1` | 位置错 |
| 4 | 464 忘总和剪枝 | `sum < target` false | 白算 |
| 5 | 464 用 boolean 缓存 | Boolean[] 三态（null 未算） | 无法区分未算/输 |
| 6 | 943 重叠计算错 | 最长重叠（从短到长试） | dist 错 |
| 7 | 规模不检查 | N > 20 硬状压 | 内存爆 |

### 6.2 面试要点

```text
① 规模先确认: "N=15 → 2¹⁵×15 ≈ 50 万状态，可行"
② 维度选择: "位置可由 mask 推出 → 一维；否则 +i 维"
③ 变体归约: "可重复 → Floyd；拼接 → dist 预处理"
④ 复杂度: O(n²·2ⁿ) vs 暴力 O(n!)——量化优势

⚠️ 高频追问: "TSP 复杂度？"
  → "O(n²·2ⁿ)——每 mask 每 i 转移 n 次；
     n=15 比 O(n!) 快约 10¹⁰ 倍"
```

> 🎯 **核心要点**：状压题解通关——**847（Floyd+TSP）、526（mask 计数）、464（博弈三态）、943（dist 预处理）**。四题覆盖最短路/计数/博弈三类——"规模确认 + 维度选择 + 变体归约"三连，状压 DP 就是可复用的模板库。
