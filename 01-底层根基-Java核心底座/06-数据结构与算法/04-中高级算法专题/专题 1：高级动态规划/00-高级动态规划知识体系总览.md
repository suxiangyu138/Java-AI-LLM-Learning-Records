## 1. 知识体系导图

```text
高级动态规划（压轴题级别）
│
├── 多维 DP ──────────────────────────────────────────────
│   ├── 二维/三维状态: 62 路径、72 编辑距离、1143 LCS
│   ├── 背包家族: 0/1、完全、多重、分组
│   ├── 滚动数组: 二维压一维（顺序是灵魂）
│   └── 识别: "两个序列/网格 + 最优值"
│
├── 区间 DP ──────────────────────────────────────────────
│   ├── 状态 dp[i][j] = 区间 [i,j] 的最优值
│   ├── 模板: 长度枚举 + 分割点 k（石子合并/矩阵链）
│   ├── "最后一步"逆向思维（312 戳气球）
│   └── 识别: "区间分割/合并/爆破/回文"
│
├── 状态压缩 DP ──────────────────────────────────────────
│   ├── 位掩码 = 集合（N ≤ 20 前提！）
│   ├── TSP: dp[mask][i]（O(n²·2ⁿ) vs 暴力 O(n!)）
│   ├── 位运算三件套 + 子集枚举 O(3ⁿ)
│   └── 识别: "子集/指派/遍历全部 + N 小"
│
├── 树形 DP ──────────────────────────────────────────────
│   ├── 后序自底向上（子节点先算）
│   ├── 二元组状态: 打家劫舍 III（偷/不偷）
│   ├── 直径/最大路径（全局变量更新）
│   └── 识别: "树结构 + 父子约束"
│
├── 数位 DP ──────────────────────────────────────────────
│   ├── 状态: pos/tight/lead（记忆化搜索）
│   ├── solve(R) − solve(L−1) 区间统计
│   ├── 状态数 O(d²) 极小
│   └── 识别: "[0,N] 数位条件统计"
│
└── 斜率优化/四边形不等式（竞赛向）───────────────────────
    ├── 斜率优化: 决策点凸包 + 单调队列
    ├── 四边形不等式: 决策单调性剪枝
    └── 定位: 蓝桥/ACM 向，面试提及即可
```

## 5. 模式识别决策树

```text
① 树结构 + 父子约束 → 树形 DP（子目录 4）
② 区间分割/合并/爆破 → 区间 DP（子目录 2）
③ 子集/指派 + N ≤ 20 → 状压 DP（子目录 3）
④ [0,N] 数位条件统计 → 数位 DP（子目录 5）
⑤ 两个序列/网格 + 最优 → 多维 DP（子目录 1）
⑥ 转移含 max/min 可凸优化 → 斜率优化（子目录 6）

⚠️ 高频识别信号:
  "计数多少种 / 最大最小值 / 最优分割 / 是否可达"
```

> 🎯 **一句话定位**："**高级 DP = 基础 DP 的'模式化升级'——每个模式一套状态定义 + 转移范式**。面试中区间 DP（戳气球）与树形 DP（打家劫舍 III）是区分候选人的压轴题（2025 趋势确认）。"

## 6. 常见误区速查

| 误区 | 正解 |
|------|------|
| "高级 DP 是背模板" | ❌ 核心是"状态定义为什么对"——面试要解释转移方程 |
| "状压 DP 不限规模" | ❌ N ≤ 20 前提（2²⁰×20 ≈ 2000 万状态可行） |
| "区间 DP 从第一步想" | ❌ 用"最后一步"逆向思维（312 最后戳破的气球） |
| "树形 DP 返回单值就够" | ❌ 父子约束需返回元组（偷/不偷） |
| "数位 DP 直接枚举" | ❌ 记忆化 pos/tight/lead——状态数 O(d²) |
| "滚动数组顺序随便" | ❌ 0/1 背包逆序、完全背包正序（覆盖顺序是灵魂） |
| "状态维度越多越好" | ❌ 能回答问题的**最小状态**即可（过度设计常见） |
| "高级 DP 面试不考" | ❌ 区间/树形是压轴题（2025 趋势） |
