## 1. 332. 重新安排行程（Hierholzer + 字典序）

### 1.1 题目与思路

```
给定机票（出发 → 到达），从 JFK 出发，用完全部机票
（每个"边"恰好一次）→ 欧拉路径（有向图）
要求：字典序最小的行程
Hierholzer + 邻接表排序（字典序 → 先走小目的地）
⚠️ 欧拉路径存在性由题意保证（给定用例必有解）
```

### 1.2 完整代码

```java
/**
 * LeetCode 332. 重新安排行程
 * ⚠️ 有向图欧拉路径：Hierholzer + 邻接表逆序字典序
 */
public List<String> findItinerary(List<List<String>> tickets) {
    // ① 建图：邻接表 + 排序（保证字典序）
    Map<String, List<String>> graph = new HashMap<>();
    for (var t : tickets)
        graph.computeIfAbsent(t.get(0), k -> new ArrayList<>()).add(t.get(1));
    for (var list : graph.values())
        Collections.sort(list);              // ⚠️ 升序 → 优先走字典序小的

    // ② Hierholzer（迭代版，防递归栈溢出）
    List<String> result = new ArrayList<>();
    Deque<String> stack = new ArrayDeque<>();
    stack.push("JFK");                       // ⚠️ 起点确定

    while (!stack.isEmpty()) {
        String node = stack.peek();
        List<String> neighbors = graph.get(node);
        if (neighbors != null && !neighbors.isEmpty()) {
            stack.push(neighbors.remove(0));     // ⚠️ 走边即删（贪心 + 字典序）
        } else {
            result.add(stack.pop());             // 死路 → 记录
        }
    }
    Collections.reverse(result);             // ⚠️ 反转得正确顺序
    return result;
}
// 推演 [["JFK","SFO"],["JFK","ATL"],["SFO","ATL"],["ATL","JFK"],["ATL","SFO"]]：
//   图：JFK→[ATL,SFO]，ATL→[JFK,SFO]，SFO→[ATL]
//   走：JFK→ATL→JFK→SFO→ATL→SFO
//   → ["JFK","ATL","JFK","SFO","ATL","SFO"] ✓
// ⚠️ 为什么"死路入栈"而非直接输出：
//   先到的是子环，后到的是主路径；反转后才正确
// ⚠️ 面试表达："332 = Hierholzer + 字典序——
//   邻接表排序保证贪心走的是最小字典序；
//   删边走 + 死路入栈 + 反转是标准三件套。"
```

## 2. 753. 破解保险箱（de Bruijn 序列）

### 2.1 题目与思路

```
密码 = 连续的 k 位数字（0..9），
求最短序列包含所有 n^k 种密码
建模：de Bruijn 序列 = 欧拉回路
  节点 = k-1 位数字
  边 = k 位数字（节点 + 新数字 → 新节点）
  每条边对应一个密码 → 欧拉回路覆盖全部
⚠️ 全偶度 → 回路存在 → Hierholzer 构造
```

### 2.2 完整代码

```java
/**
 * LeetCode 753. 破解保险箱（de Bruijn 序列 = 欧拉回路）
 */
public String crackSafe(int n, int k) {
    if (n == 1) {                             // ⚠️ 特判：1 位密码直接全列
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < k; i++) sb.append(i);
        return sb.toString();
    }

    // 节点 = n-1 位数字（状态）
    StringBuilder result = new StringBuilder();
    Set<String> visited = new HashSet<>();
    String start = "0".repeat(n - 1);

    // ⚠️ 迭代式 DFS：从每个节点出发尝试所有数字
    Deque<String> stack = new ArrayDeque<>();
    stack.push(start);
    while (!stack.isEmpty()) {
        String node = stack.peek();
        boolean extended = false;
        for (int d = 0; d < k; d++) {
            String edge = node + d;           // 边 = 节点 + 新数字
            if (visited.add(edge)) {          // ⚠️ 未访问的边
                stack.push(edge.substring(1));// 新节点 = 去掉首位
                extended = true;
                break;                        // ⚠️ 一条条走（Hierholzer 贪心）
            }
        }
        if (!extended) {
            result.append(node.charAt(node.length() - 1));  // 死路 → 记录末位
            stack.pop();
        }
    }
    // 拼接：前缀 + 记录序列
    return start + result.reverse().substring(1);
}
// 推演 n=2, k=2：
//   节点 "0","1"；边 00,01,10,11（4 个密码）
//   欧拉回路访问全部 4 条边 → 序列 "00110"（含 00,01,11,10）✓
// ⚠️ 面试表达："753 的关键是建模——密码是'边'、
//   n-1 位前缀是'节点'；全偶度保证欧拉回路，
//   Hierholzer 构造出覆盖所有密码的最短序列。"
// ⚠️ 长度 = k^n + n - 1（边数 + 起始前缀长度）
```

## 3. 2097. 合法重新排列数对

### 3.1 题目与思路

```
pairs = [a,b] 表示"路径 a→b"，重排使前后相接
（前一组的 b == 下一组的 a）——用完全部边的欧拉路径！
⚠️ 与 332 的区别：
  332 给起点（JFK）；2097 起点不定 → 找起点
  起点 = 出度 - 入度 = 1 的节点（无则任意）
```

### 3.2 完整代码

```java
/**
 * LeetCode 2097. 合法重新排列数对
 * ⚠️ 不定起点的欧拉路径：先找起点（出多入少者）
 */
public int[][] validArrangement(int[][] pairs) {
    // ① 建图 + 出入度统计
    Map<Integer, List<Integer>> graph = new HashMap<>();
    Map<Integer, Integer> in = new HashMap<>(), out = new HashMap<>();
    for (int[] p : pairs) {
        graph.computeIfAbsent(p[0], k -> new ArrayList<>()).add(p[1]);
        out.merge(p[0], 1, Integer::sum);
        in.merge(p[1], 1, Integer::sum);
    }

    // ② 找起点：出 - 入 = 1 的节点；没有则任意节点
    int start = pairs[0][0];
    for (int node : graph.keySet()) {
        if (out.getOrDefault(node, 0) - in.getOrDefault(node, 0) == 1) {
            start = node;                    // ⚠️ 唯一起点
            break;
        }
    }

    // ③ Hierholzer（迭代 + 逆序输出）
    List<int[]> result = new ArrayList<>();
    Deque<Integer> stack = new ArrayDeque<>();
    stack.push(start);
    while (!stack.isEmpty()) {
        int node = stack.peek();
        List<Integer> nexts = graph.get(node);
        if (nexts != null && !nexts.isEmpty()) {
            stack.push(nexts.remove(nexts.size() - 1));   // ⚠️ 删边走
        } else {
            result.add(new int[]{stack.pop(), stack.isEmpty()
                    ? start : stack.peek()});   // ⚠️ 记录 [当前, 下一个]
            // 简化写法：记录边 [next, node] 在反转时处理
        }
    }
    // 反转并整理为边对
    Collections.reverse(result);
    return result.toArray(new int[0][]);
}
// 推演 pairs=[[5,1],[4,5],[11,9],[9,4]]：
//   出度-入度：5:+1-1=0, 4:+1-1=0, 11:+1=1, 9:+1-1=0
//   起点 = 11 → 11→9→4→5→1 ✓
// ⚠️ 面试表达："2097 = 不定起点欧拉路径——
//   起点 = 出度比入度多 1 的节点（欧拉定理）；
//   找到起点后就是标准 Hierholzer。"
```

## 4. 一笔画判定实战

### 4.1 无向图一笔画判定

```java
/** 一笔画判定（无向图）：奇度节点 0 或 2 个 + 连通 */
boolean canDrawInOneStroke(int n, List<int[]> edges) {
    // ① 度数统计
    int[] degree = new int[n];
    for (int[] e : edges) { degree[e[0]]++; degree[e[1]]++; }

    // ② 数奇度节点
    int odd = 0;
    for (int d : degree) if (d % 2 == 1) odd++;
    if (odd != 0 && odd != 2) return false;     // ⚠️ 核心判定

    // ③ 连通性（忽略孤立点）——并查集/DFS
    return isConnected(n, edges);
}
// ⚠️ 应用：
//   汉字/图形一笔画判断
//   街道清扫路线设计
//   电路板布线可行性

// ⚠️ 面试表达："一笔画 = 奇度节点数判定——
//   0 个（回路）或 2 个（从奇度起笔）。
//   再加连通性检查就是完整判定。"
```

### 4.2 奇度节点起笔的直观

```
奇度节点 = 进出不配对：
  起点：多一条出边（出度 = 入度 + 1）
  终点：多一条入边（入度 = 出度 + 1）
  偶数度节点：进出配对，可进可出

⚠️ 面试表达：
"为什么从奇度起笔？奇度节点'进出不平衡'，
 必须是路径的端点——起点或终点。"
```

## 5. 欧拉路径方法论总结

### 5.1 解题框架

```
① 识别：是不是欧拉题？
   "每条边恰好一次 / 用完全部边 / 一笔画" → 欧拉
   ⚠️ 与哈密顿区分（每个点恰好一次 → 不是欧拉）
② 建模：边 = 什么？节点 = 什么？
   （332：机票是边；753：密码是边）
③ 判定：度数条件（全偶/两奇）+ 连通性
④ 构造：Hierholzer（贪心删边 + 死路入栈 + 反转）
⑤ 变体：字典序（排序邻接表）、不定起点（找出入度差 1）

⚠️ 识别信号：
  "用完全部边/机票/边对重排" → 欧拉路径
  "一笔画/最短序列覆盖全部" → 欧拉回路
```

### 5.2 模板速查表

| 场景 | 模板 | 代表题 |
|------|------|--------|
| 有向 + 定起点 + 字典序 | Hierholzer + 排序 | 332 |
| 有向 + 不定起点 | 找出入度差 1 起点 | 2097 |
| 全覆盖序列 | de Bruijn 建模 | 753 |
| 无向一笔画 | 奇度判定 | 判定题 |
| 回路构造 | 任意起点 + Hierholzer | 753 变体 |

### 5.3 自测清单

```
□ 判定条件正确（0/2 个奇度 + 连通）？
□ 有向图用出入度差？
□ 贪心走边时删除边？
□ 死路入栈 + 最后反转？
□ 字典序邻接表排序？
□ 不定起点找法正确？
□ 特判（n=1 等）？
```

---

> 🎯 **核心要点**：欧拉题 = **建模**（边/节点映射）+ **判定**（度数条件）+ **Hierholzer**（删边贪心 + 回溯入栈 + 反转）。三题覆盖全部形态：定起点字典序（332）、全覆盖构造（753）、不定起点（2097）——识别"用完全部边"信号是解题第一步。
