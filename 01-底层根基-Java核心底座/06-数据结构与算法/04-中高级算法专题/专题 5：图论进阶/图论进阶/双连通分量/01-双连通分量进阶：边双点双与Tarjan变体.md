## 1. 边双连通 vs 点双连通

### 1.1 定义

```
边双连通：删掉任意一条边仍连通（无桥）
点双连通：删掉任意一个点仍连通（无割点）

⚠️ 区别：
  边双 → 桥（割边）是分界
  点双 → 割点是分界

⚠️ 关系：
  点双连通 ⟹ 边双连通（删点比删边破坏力大）
  但边双连通不一定是点双连通（如"8"字形两环共点）

⚠️ 面试必答：
"边双防'断边'、点双防'断点'——
 点双更强（删点能断开的一定能删边断开）。
 '8'字形两个环共一个点是经典反例。"
```

### 1.2 判定定理

| 概念 | 判定 | 算法 |
|------|------|------|
| 桥 | low[v] > dfn[u] | Tarjan 变体 |
| 割点 | low[v] >= dfn[u]（根：≥2 子） | Tarjan 变体 |
| 边双连通分量 | 无桥（缩桥后） | Tarjan + 栈 |
| 点双连通分量 | 割点分离 | Tarjan + 栈（特殊弹出） |

```
⚠️ 面试必答：
"四判定一条线：桥 >、割点 ≥（根特判）、
 边双缩桥、点双按割点切分——
 都是 dfn/low 思想。"
```

## 2. 桥与割点的判定推导

### 2.1 桥的判定（无向图）

```
边 (u, v)（v 是 DFS 树中 u 的子节点）是桥 ⟺ low[v] > dfn[u]
  含义：v 的子树没有"回边"翻到 u 或更早
  → 删掉 (u,v) 后 v 子树孤立

⚠️ 严格大于 vs 大于等于：
  桥：low[v] > dfn[u]（v 翻不到 u）
  割点：low[v] >= dfn[u]（v 翻不到 u 之前）

⚠️ 面试必答：
"桥的判定 low[v] > dfn[u]——v 的子树
 若能用回边到达 u 或更早，则 (u,v) 不是桥。
 完整实现见强连通/02 的 1192。"
```

### 2.2 割点的判定（含根特判）

```
非根节点 u 是割点 ⟺ 存在子节点 v 使 low[v] >= dfn[u]
  含义：v 的子树翻不到 u 之上 → 删 u 后 v 子树断开

根节点特判：根是割点 ⟺ 有 ≥ 2 个 DFS 子节点
  原因：根没有祖先，删除后每个子树独立

⚠️ 面试必答：
"割点两情形——非根看 low[v] >= dfn[u]、
 根看子节点数 ≥ 2。根特判是高频遗漏。"
```

### 2.3 判定代码

```java
/** 割点模板（Tarjan 变体） */
int[] dfn, low;
boolean[] isCut;
int timer = 0;

void tarjan(int u, int parent, List<Integer>[] graph) {
    dfn[u] = low[u] = ++timer;
    int children = 0;
    for (int v : graph[u]) {
        if (v == parent) continue;
        if (dfn[v] == 0) {
            children++;
            tarjan(v, u, graph);
            low[u] = Math.min(low[u], low[v]);
            // ⚠️ 割点判定（非根）
            if (parent != -1 && low[v] >= dfn[u]) isCut[u] = true;
        } else {
            low[u] = Math.min(low[u], dfn[v]);
        }
    }
    // ⚠️ 根特判
    if (parent == -1 && children >= 2) isCut[u] = true;
}
// ⚠️ 面试表达："割点模板与桥模板同构——
//   只差判定式（≥ vs >）与根特判。"
```

## 3. 边双连通分量：Tarjan 变体

### 3.1 求边双的两种方法

```
方法一：桥标记法
  ① Tarjan 找所有桥
  ② DFS 不跨桥 → 每个连通块 = 边双

方法二：Tarjan + 栈（与 SCC 类似）
  无向图 DFS + 栈，low[v] > dfn[u] 时弹出
```

### 3.2 边双缩点（桥 → 树）

```
边双缩点：每个边双压缩为节点
  → 原图变成一棵树（桥是树的边）

⚠️ 性质：
  树的边 = 原图的桥
  树上任意两节点路径上的边 = 必须经过的桥
  → 桥的"关键性"一目了然

⚠️ 面试必答：
"边双缩点得到'桥树'——原图的桥就是
 树的边。树的路径 = 必经之桥，
 这是 1192 等题的结构化视角。"
```

### 3.3 边双的应用

```
① 最少加边使无桥（全部边双连通）：
   缩点成树 → 加边数 = ceil(叶子数/2)
   （树的叶子两两配对成环）
② 关键路径分析（必经边）
③ 网络可靠性（无单点故障边）

⚠️ 面试必答：
"树加最少边成环 = ceil(叶子/2)——
 叶子配对连边消除所有桥。
 这是边双缩点的经典结论。"
```

## 4. 点双连通分量：割点分离

### 4.1 点双的特性

```
点双连通分量（块）：
  ① 内部无割点（删任意点仍连通）
  ② 两个点双至多共享一个割点
  ③ 割点属于多个点双；非割点属于一个

⚠️ 与边双的区别：
  边双：边不重叠，节点唯一归属
  点双：点可重叠（割点），块之间有公共点

⚠️ 面试必答：
"点双的独特性质：割点'属于多个块'——
 块之间通过割点连接，形成'块割树'。"
```

### 4.2 求点双的 Tarjan（特殊弹出）

```java
/** 点双（块）：栈存边而非节点 */
void tarjanBlock(int u, int parent, List<Integer>[] graph) {
    dfn[u] = low[u] = ++timer;
    int children = 0;
    for (int v : graph[u]) {
        if (v == parent) continue;
        if (dfn[v] == 0) {
            edgeStack.push(new int[]{u, v});   // ⚠️ 边入栈
            children++;
            tarjanBlock(v, u, graph);
            low[u] = Math.min(low[u], low[v]);
            if (low[v] >= dfn[u]) {            // ⚠️ 割点边界 → 弹出块
                List<int[]> block = new ArrayList<>();
                while (true) {
                    int[] e = edgeStack.pop();
                    block.add(e);
                    if (e[0] == u && e[1] == v) break;
                }
                // block = 一个点双（可能只有一条边）
            }
        } else if (dfn[v] < dfn[u]) {          // ⚠️ 回边（避免重复入栈）
            edgeStack.push(new int[]{u, v});
            low[u] = Math.min(low[u], dfn[v]);
        }
    }
}
// ⚠️ 关键区别：栈存"边"（节点可能属于多个块）
// ⚠️ 面试表达："点双的 Tarjan 栈存边——
//   割点边界 low[v] >= dfn[u] 时弹出
//   该边所在块（割点会出现在多个块）。"
```

## 5. 双连通 vs 强连通

### 5.1 三兄弟对比

| 维度 | 强连通 SCC | 边双 | 点双 |
|------|:---:|:---:|:---:|
| 图类型 | 有向 | 无向 | 无向 |
| 对象 | 顶点集 | 顶点集 | 顶点集（边集） |
| 分界 | 无 | 桥 | 割点 |
| 判定 | low[v] >= dfn[u] | low[v] > dfn[u] | low[v] >= dfn[u] |
| 重叠 | 不重叠 | 不重叠 | 割点重叠 |
| 缩点结果 | DAG | 树 | 块割树 |

```
⚠️ 面试必答：
"三兄弟对比——SCC 有向、边双防断边、
 点双防断点。判定式只有'等于号'差异：
 SCC 与点双 ≥、桥 >（根特判是点双/割点独有）。"
```

### 5.2 记忆口诀

```
有向 SCC：low[v] >= dfn[u]（u 是根，弹出栈）
无向桥：  low[v] >  dfn[u]（严格大于）
无向割点：low[v] >= dfn[u]（根看子树数）
无向点双：low[v] >= dfn[u]（栈存边）

⚠️ 面试表达：
"'等于号'的差异来自'分界对象'——
 SCC/割点/点双允许'回到自己'（≥），
 桥不允许（>，否则不桥）。"
```

## 6. 双连通的应用

### 6.1 应用场景

| 场景 | 双连通工具 |
|------|-----------|
| 网络关键边（1192） | 桥 |
| 网络关键节点 | 割点 |
| 最少加边去单点故障 | 边双缩点 + ceil(叶/2) |
| 图同构判定 | 块割树结构 |
| 可靠传输 | 双连通保证冗余路径 |

```
⚠️ 冗余路径视角：
  边双连通 ⟺ 任意两点有两条边不相交路径
  点双连通 ⟺ 任意两点有两条点不相交路径

⚠️ 面试必答：
"双连通的本质 = 冗余——
 边双 = 两条'边不相交'路径，
 点双 = 两条'点不相交'路径（Menger 定理）。"
```

### 6.2 与并查集的关系

```
冗余连接（685）的另一种解法：并查集
  判断加边是否成环（并查集连通性）
  ⚠️ 并查集解决"无向图加边成环"问题
  双连通解决"删边/删点断开"问题
  → 两者互补（环检测 vs 关键性）

⚠️ 面试表达：
"'加边成环'用并查集、'删边断开'用桥——
 两个视角覆盖'冗余'问题的两面。"
```

## 7. 面试要点与追问

### 7.1 面试话术模板

```
"双连通 = dfn/low 思想的四种应用：
 SCC（有向 ≥）、桥（无向 >）、割点（无向 ≥ + 根特判）、
 点双（栈存边）。
 边双缩点 → 树（桥为边）；点双 → 块割树（割点重叠）。
 应用：关键边/点、最少加边去单点故障。"
```

### 7.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 边双 vs 点双？ | 防断边 vs 防断点 |
| 2 | 桥判定？ | low[v] > dfn[u] |
| 3 | 割点判定？ | low[v] >= dfn[u] + 根特判 |
| 4 | 点双栈存什么？ | 边（割点属多块） |
| 5 | 边双缩点结果？ | 树（桥 = 树边） |
| 6 | 最少加边去桥？ | ceil(叶子/2) |
| 7 | vs 强连通？ | 有向 vs 无向，判定差等号 |
| 8 | 冗余路径？ | Menger：边双/点双 = 两条不相交路径 |

### 7.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 割点忘根特判 | 根误判 | children ≥ 2 |
| 桥用 >= | 桥多算 | 严格 > |
| 点双栈存节点 | 块错乱 | 存边 |
| 无向图忘跳父边 | 回边误判 | parent 跳过 |
| 混淆 SCC/桥判定 | 结果错 | 图类型 + 等号 |

---

> 🎯 **核心要点**：双连通体系 = **四判定**（SCC ≥/桥 >/割点 ≥ + 根/点双存边）+ **缩点结果**（树 vs 块割树）+ **冗余本质**（Menger 定理）。"同一 dfn/low，四种判定"是双连通题的骨架。
