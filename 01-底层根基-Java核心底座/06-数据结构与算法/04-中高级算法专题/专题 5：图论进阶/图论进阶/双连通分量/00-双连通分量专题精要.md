## 1. 核心概念

### 1.1 割点、桥与双连通

```
无向图三种概念：
  桥（割边）：删除后图不连通
  割点（关节点）：删除后图不连通
  双连通分量：不含割点的极大子图

例：A—B—C
  桥：A-B 和 B-C 都是桥
  割点：B（删 B 后 A 与 C 断开）

应用：
  网络关键连接（删掉就断网）
  冗余设计（避免单点故障）
```

### 1.2 识别信号

```
"关键连接/关键边" → 桥（1192）
"删除后不连通" → 桥/割点
"网络中的单点故障" → 割点

⚠️ 面试定位：竞赛/进阶
  1192 是唯一进入 Hot 100 的 Tarjan 应用
  掌握模板 + 判定公式即可
```

### 1.3 判定条件（核心公式）

```
基于 dfn（时间戳）和 low（可达最早时间戳）：

桥（边 u-v）：low[v] > dfn[u]
  → v 的子树到不了 u 或更早 → 这条边是唯一通道

割点（节点 u）：
  ① u 是根：有 ≥ 2 个孩子 → 割点
  ② u 非根：存在孩子 v 使 low[v] ≥ dfn[u]
  → v 的子树到不了 u 的上面 → u 是关键节点

⚠️ 割点用 ≥（子树可达 u 也算割），桥用 >（严格）
  记忆："桥更严格——要完全够不到"
```

## 2. 完整代码模板

### 2.1 1192. 网络中的关键连接（求桥）

```java
/**
 * LeetCode 1192. 网络中的关键连接（Tarjan 无向图版）
 */
public List<List<Integer>> criticalConnections(int n,
        List<List<Integer>> connections) {
    // ① 建图（无向：双向加边）
    List<List<Integer>> graph = new ArrayList<>();
    for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
    for (List<Integer> c : connections) {
        graph.get(c.get(0)).add(c.get(1));
        graph.get(c.get(1)).add(c.get(0));
    }

    int[] dfn = new int[n];
    int[] low = new int[n];
    List<List<Integer>> bridges = new ArrayList<>();
    dfs(0, -1, graph, dfn, low, bridges, new int[1]);
    return bridges;
}

private void dfs(int u, int parent, List<List<Integer>> graph,
                 int[] dfn, int[] low,
                 List<List<Integer>> bridges, int[] timer) {
    dfn[u] = low[u] = ++timer[0];

    for (int v : graph.get(u)) {
        if (v == parent) continue;        // ⚠️ 无向图：跳过父边

        if (dfn[v] == 0) {                // 未访问
            dfs(v, u, graph, dfn, low, bridges, timer);
            low[u] = Math.min(low[u], low[v]);

            // ⚠️ 桥的判定：v 到不了 u 或更早
            if (low[v] > dfn[u]) {
                bridges.add(List.of(u, v));   // u-v 是桥
            }
        } else {
            low[u] = Math.min(low[u], dfn[v]);   // 回边更新
        }
    }
}
// 复杂度 O(V+E)
// ⚠️ 与有向图 Tarjan 的差异：
//   ① 跳过父节点（防重复走同一条无向边）
//   ② 回边处理无需 inStack 判断（无向天然）
```

### 2.2 割点模板

```java
/**
 * 割点模板（low[v] >= dfn[u] 判定）
 */
public List<Integer> findArticulationPoints(int n, int[][] edges) {
    // 建图（无向）同前
    int[] dfn = new int[n];
    int[] low = new int[n];
    boolean[] isCut = new boolean[n];
    int[] timer = new int[1];

    for (int i = 0; i < n; i++) {
        if (dfn[i] == 0) {
            dfsCut(i, -1, graph, dfn, low, isCut, timer);
        }
    }

    List<Integer> result = new ArrayList<>();
    for (int i = 0; i < n; i++) {
        if (isCut[i]) result.add(i);
    }
    return result;
}

private void dfsCut(int u, int parent, List<List<Integer>> graph,
                    int[] dfn, int[] low, boolean[] isCut, int[] timer) {
    dfn[u] = low[u] = ++timer[0];
    int children = 0;                    // ⚠️ 根的孩子数

    for (int v : graph.get(u)) {
        if (v == parent) continue;

        if (dfn[v] == 0) {
            children++;
            dfsCut(v, u, graph, dfn, low, isCut, timer);
            low[u] = Math.min(low[u], low[v]);

            // ⚠️ 割点判定（两种情形）
            if (parent == -1 && children >= 2) {
                isCut[u] = true;         // ① 根：≥2 孩子
            } else if (parent != -1 && low[v] >= dfn[u]) {
                isCut[u] = true;         // ② 非根：low[v] ≥ dfn[u]
            }
        } else {
            low[u] = Math.min(low[u], dfn[v]);
        }
    }
}
```

### 2.3 桥 vs 割点判定对比

```
            桥（边）          割点（节点）
判定条件    low[v] > dfn[u]   low[v] >= dfn[u]
根特判      无                根有 ≥2 孩子
语义        v 够不到 u 之上   v 够不到 u 之上（含 u）

为什么割点用 >=？
  v 的子树能到 u 本身 → 删 u 后 v 仍与 u 之上断开？
  能到 u 但 u 被删 → 断了！→ 所以 low[v] == dfn[u] 也算割点
  桥：low[v] == dfn[u] → v 能到 u → 边 u-v 不是唯一通道

⚠️ 记忆："桥严格（>），割点宽松（>=）"
```

## 3. 桥与割点的判定推导

### 3.1 桥的推导

```
边 u-v（v 是 u 的孩子）：
  low[v] = v 子树能到达的最早时间戳
  low[v] > dfn[u] → v 子树到不了 u 或更早
  → 从 v 子树出发的唯一出路是边 u-v
  → 删掉 u-v → v 子树与图断开 → 桥 ✓

low[v] <= dfn[u] → v 子树有回边到 u 或更早
  → 删 u-v 后 v 子树仍连通 → 不是桥
```

### 3.2 割点的推导

```
节点 u 非根，孩子 v：
  low[v] >= dfn[u] → v 子树到不了 u 的父节点方向
  → 删 u 后 v 子树与图断开 → u 是割点 ✓

根的特例：
  根没有"父方向"可依赖
  → 根的孩子 ≥ 2 → 删根断开各孩子 → 割点
  （根 1 个孩子 → 删根不断开）

⚠️ 面试表达：
"桥看边两端'够不够得到'；割点看
 孩子子树'够不够到父方向'。
 根因为无父方向，用孩子数判断。"
```

### 3.3 无向图 Tarjan 的特殊性

```
与有向图 Tarjan 的三个差异：
  ① parent 参数：跳过父节点（防走回头路）
  ② 无 inStack 判断：无向图回边必然"可达"
  ③ 每条边恰处理一次（双向建图但跳过父边）

⚠️ 重边问题（进阶）：
  跳过父节点会漏重边（A-B 两条边）
  解决：用"边编号"代替"父节点"判断
  （面试了解即可）
```

## 4. 双连通 vs 强连通

### 4.1 对比表

| 维度 | 强连通（有向） | 桥/割点（无向） |
|------|:---:|:---:|
| 图 | 有向 | 无向 |
| 判定 | dfn==low 弹栈 | low[v]>dfn[u]（桥） |
| 目标 | 互相可达分组 | 关键边/点 |
| 应用 | 缩点 DAG | 网络关键连接 |
| 高频题 | 少 | 1192（Hot 100） |

```
⚠️ 易混点：
  两者都叫"连通"，但方向性完全不同
  （有向 vs 无向、分组 vs 关键元素）
```

### 4.2 并查集 vs Tarjan 的选型

```
静态"判断是否成环" → 并查集更简单（684）
找"关键边/桥" → 必须 Tarjan（1192）

⚠️ 识别：
  "删除后不连通/关键连接" → Tarjan（桥）
  "加边判环/动态连通" → 并查集
```

### 4.3 双连通分量（BCC）

```
双连通分量：无向图中不含割点的极大子图
  点双连通：任意两点有两条"点不交"路径
  边双连通：任意两点有两条"边不交"路径

应用：冗余网络设计（单点故障仍连通）

⚠️ 面试定位：了解概念即可
  实现（Tarjan 变体）竞赛级
```

### 6.1 面试话术模板

```
"网络关键连接 = 找桥。Tarjan 无向图版：
 dfn 时间戳 + low 子树可达最早时间。
 边 u-v 是桥 ⇔ low[v] > dfn[u]
 （v 的子树到不了 u 或更早，说明这条边是唯一通道）。
 O(V+E)。关键细节：无向图要跳过父节点。"
```

| # | 追问 | 标准回答 |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 忘跳过父节点 | 死循环 | parent 判断 |
| 桥用 >= | 误判 | 严格 > |
| 割点用 > | 漏割点 | >= |
| 根孩子数忘统计 | 根割点漏 | children 计数 |
| 有向图模板套无向 | 错误 | 无向变体 |

> 🎯 **核心要点**：桥/割点 = **Tarjan 无向图变体**（跳过父节点 + low 判定）。识别信号："关键连接、删除后不连通、割点桥"。判定公式（桥 >、割点 ≥、根 ≥2 孩子）与 1192 模板是核心考点；与并查集/强连通的选型是面试对比点。
