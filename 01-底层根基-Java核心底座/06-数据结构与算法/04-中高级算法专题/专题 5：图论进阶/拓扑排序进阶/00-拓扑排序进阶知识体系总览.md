## 1. 知识体系导图

```text
拓扑排序进阶（图论视角）
│
├── 双模板深潜 ───────────────────────────────────────────
│   ├── Kahn（BFS）: 判环直观、可分层、可字典序
│   ├── DFS 三色: 环定位精准、代码简洁
│   ├── 选型: 工程/竞赛首选 Kahn；定位环用 DFS
│   └── 环定位: DFS 遇"访问中"记录路径
│
├── 字典序控制 ───────────────────────────────────────────
│   ├── 字典序最小: 队列换小根堆（B3644 家谱树）
│   ├── 字典序最大: ⚠️ 反图 + 大根堆 + 反转（常见陷阱）
│   └── 复杂度: O(V log V + E)
│
├── 分层拓扑（并行调度）────────────────────────────────
│   ├── 每层整体弹出（size 快照）
│   ├── 层数 = DAG 最长路径 + 1（并行下界）
│   └── 应用: Bazel 构建、并行课程（1136）
│
├── 拓扑 + DP ───────────────────────────────────────────
│   ├── 核心: 按拓扑序前向松弛（O(V+E)）
│   ├── DAG 最长路径 / 关键路径（CPM）
│   ├── 计数: P4017 食物链（dp[v] += dp[u]）
│   └── 经典: 1857 最大颜色值、2050 并行课程 III
│
├── 综合应用 ─────────────────────────────────────────────
│   ├── 2392 矩阵构造（行列双拓扑）
│   ├── 310 最小高度树（剥叶拓扑）
│   ├── 依赖解析: 循环依赖报错定位（环定位）
│   └── 构建系统: Bazel/Gradle 并行调度
│
└── 实战与面试 ───────────────────────────────────────────
    ├── 手写: Kahn/DFS 双版（5 分钟）
    ├── 进阶: 字典序/分层/DP 三变体
    ├── 复杂度: O(V+E)；堆版 O(V log V)
    └── 话术: "双模板 + 变体识别 + DP 扩展"三段式
```

## 4. 核心概念速查

| 概念 | 一句话解释 | 说明 |
|------|-----------|------|
| **Kahn** | 入度消解（BFS 版） | 判环直观、可扩展 |
| **DFS 三色** | 访问中 = 环（后序反转） | 环定位精准 |
| **字典序最小** | 队列换小根堆 | B3644 模板 |
| **反图陷阱** | 字典序最大 ≠ 大根堆直接套 | 反图 + 堆 + 反转 |
| **分层拓扑** | 每层整体弹出 | 层数 = 最长路径 + 1 |
| **前向松弛** | 按拓扑序做 DP 转移 | 拓扑 + DP 核心 |
| **关键路径** | DAG 最长路径（CPM） | 项目最短工期 |
| **环定位** | 三色记录环路径 | 循环依赖报错 |
| **剥叶拓扑** | 入度 1 层层删 | 310 最小高度树 |

## 5. 进阶能力矩阵

| 能力 | 方法 | 复杂度 | 代表 |
|------|:---:|:---:|:---:|
| 判环 | Kahn 计数 / DFS 三色 | O(V+E) | 207 |
| 环定位 | DFS 三色记录路径 | O(V+E) | 依赖报错 |
| 字典序最小 | Kahn + 小根堆 | O(V log V+E) | B3644 |
| 分层 | 每层 size 弹出 | O(V+E) | 1136/Bazel |
| 最长路径 | 拓扑序 + 前向松弛 | O(V+E) | 2050/CPM |
| 计数 | dp[v] += dp[u] | O(V+E) | P4017 |
| 矩阵构造 | 行列双拓扑 | O(V+E) | 2392 |

> 🎯 **一句话定位**："**拓扑排序进阶 = '模板 + 三变体 + DP 扩展'——Kahn/DFS 双实现打底，字典序/分层/最长路径各配一个数据结构**。'按拓扑序做 DP'让它从'排序'升级为'DAG 上的通用求解器'。"

## 6. 常见误区速查

| 误区 | 正解 |
|------|------|
| "字典序最大 = 大根堆直接套" | ❌ 需反图 + 最大堆 + 反转结果（直接套会错） |
| "层数 = 轮数" | ❌ 层数 = DAG 最长路径 + 1（并行下界） |
| "拓扑 + DP 用递归合并" | ❌ 先拓扑序再前向松弛——递归会变"偏心率" |
| "DFS 不能判环" | ❌ 三色（访问中 = 环）——且能精确定位环路径 |
| "Kahn 不能分层" | ❌ size 快照即分层（同 BFS 层序遍历） |
| "拓扑序唯一" | ❌ 不唯一；字典序版是其中特定一个 |
| "最长路径用 Dijkstra" | ❌ DAG 用拓扑序 + DP O(V+E)；Dijkstra 不支持负权且有环前提 |
| "环检测只看计数" | ❌ 计数判有无、三色能定位（工程报错需要位置） |
| "拓扑只能排 DAG" | ❌ 有环时也能用——判环/定位环是它的副产品 |
| "工程只用 Kahn" | ❌ 定位循环依赖（报错）用 DFS 三色更直接 |
