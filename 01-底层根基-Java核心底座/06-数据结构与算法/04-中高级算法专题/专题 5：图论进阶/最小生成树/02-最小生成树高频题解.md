## 1. 1584. 连接所有点的最小费用

### 1.1 题目与思路

```
点的曼哈顿距离建边 → Kruskal 最小生成树
⚠️ 完全图 E = n(n-1)/2 → 建边后排序
```

### 1.2 完整代码

```java
/**
 * LeetCode 1584. 连接所有点的最小费用（Kruskal）
 */
public int minCostConnectPoints(int[][] points) {
    int n = points.length;
    // ① 建边（曼哈顿距离）
    List<int[]> edges = new ArrayList<>();
    for (int i = 0; i < n; i++)
        for (int j = i + 1; j < n; j++)
            edges.add(new int[]{i, j,
                    Math.abs(points[i][0] - points[j][0])
                            + Math.abs(points[i][1] - points[j][1])});

    // ② Kruskal
    Collections.sort(edges, (a, b) -> a[2] - b[2]);
    int[] parent = new int[n];
    for (int i = 0; i < n; i++) parent[i] = i;

    int total = 0, count = 0;
    for (int[] e : edges) {
        int ru = find(parent, e[0]), rv = find(parent, e[1]);
        if (ru != rv) {                      // ⚠️ 不成环
            parent[ru] = rv;
            total += e[2];
            if (++count == n - 1) break;     // n-1 条完成
        }
    }
    return total;
}

private int find(int[] parent, int x) {
    while (parent[x] != x) {
        parent[x] = parent[parent[x]];       // 路径压缩
        x = parent[x];
    }
    return x;
}
// 推演 points=[[0,0],[2,2],[3,10],[5,2],[7,0]]：
//   最近连接：2+7+5+2... MST 总费用 20 ✓
// ⚠️ 复杂度：O(E log E)，E = n²/2
// ⚠️ 面试必答："1584 = 建边 + Kruskal——
//   完全图边数 O(n²)，排序主导；
//   '任意两点可连'的 MST 标准形态。"
```

## 2. 1168. 水资源分配（虚拟节点）

### 2.1 题目与思路

```
每城可打井（固定费）或引水（管道费）→ 全部有水最小费用
虚拟水源节点 0：打井 = 连 0 的边
⚠️ 01 模块 5 节虚拟节点推导
```

### 2.2 完整代码

```java
/**
 * LeetCode 1168. 水资源分配（虚拟节点 + Kruskal）
 */
public int minCostToSupplyWater(int n, int[] wells, int[][] pipes) {
    // ① 建边：虚拟水源 0 + 井边 + 管道边
    List<int[]> edges = new ArrayList<>();
    for (int i = 1; i <= n; i++)
        edges.add(new int[]{0, i, wells[i - 1]});    // ⚠️ 打井 = 水源边
    for (int[] p : pipes) edges.add(p);              // 引水管道

    // ② Kruskal（n+1 个节点）
    Collections.sort(edges, (a, b) -> a[2] - b[2]);
    int[] parent = new int[n + 1];
    for (int i = 0; i <= n; i++) parent[i] = i;

    int total = 0, count = 0;
    for (int[] e : edges) {
        int ru = find(parent, e[0]), rv = find(parent, e[1]);
        if (ru != rv) {
            parent[ru] = rv;
            total += e[2];
            if (++count == n) break;         // ⚠️ n+1 节点 → n 条边
        }
    }
    return total;
}
// 推演 n=2, wells=[1,1], pipes=[[1,2,1]]：
//   边：0-1(1)、0-2(1)、1-2(1)
//   MST：0-1(1) + 0-2(1) = 2（两城都打井）
//   或 0-1(1) + 1-2(1) = 2（1 打井 2 引水）→ 最小 2 ✓
// ⚠️ 面试必答："1168 = 虚拟水源节点——
//   打井变成'连水源的边'，MST 自动决策
//   每城是打井还是引水；边数 = n（n+1 节点）。"
```

## 3. 1135. 最低成本连通所有城市

### 3.1 题目与思路

```
标准 MST（Kruskal），不可达返回 -1
⚠️ 与 1584 的区别：边已给出（不是完全图）
```

### 3.2 完整代码

```java
/**
 * LeetCode 1135. 最低成本连通所有城市（Kruskal）
 */
public int minimumCost(int n, int[][] connections) {
    Arrays.sort(connections, (a, b) -> a[2] - b[2]);
    int[] parent = new int[n + 1];
    for (int i = 1; i <= n; i++) parent[i] = i;

    int total = 0, count = 0;
    for (int[] c : connections) {
        int ru = find(parent, c[0]), rv = find(parent, c[1]);
        if (ru != rv) {
            parent[ru] = rv;
            total += c[2];
            if (++count == n - 1) return total;   // ⚠️ 提前完成
        }
    }
    return -1;                               // ⚠️ 连不通
}
// 推演 n=3, [[1,2,5],[1,3,6],[2,3,1]]：
//   (2,3,1) → (1,2,5) → 总 6，2 条边完成 → 6 ✓
// ⚠️ 面试必答："1135 = Kruskal 最小样板——
//   n-1 条边提前返回；连不通返回 -1
//   （count 不足 n-1）。"
```

## 4. 684. 冗余连接（并查集判环）

### 4.1 题目与思路

```
无向图 n 条边（n 个节点，树 + 一条冗余边）→ 删冗余边
并查集：加边时 find 相同 → 成环 → 该边冗余
⚠️ 返回"最后出现的冗余边"→ 顺序遍历记录
```

### 4.2 完整代码

```java
/**
 * LeetCode 684. 冗余连接（并查集判环）
 */
public int[] findRedundantConnection(int[][] edges) {
    int n = edges.length;
    int[] parent = new int[n + 1];
    for (int i = 1; i <= n; i++) parent[i] = i;

    for (int[] e : edges) {
        int ru = find(parent, e[0]), rv = find(parent, e[1]);
        if (ru == rv) return e;              // ⚠️ 成环 → 冗余边
        parent[ru] = rv;
    }
    return new int[0];
}
// 推演 [[1,2],[1,3],[2,3]]：
//   1-2、1-3 连接；2-3：find(2)==find(3) → 冗余 [2,3] ✓
// ⚠️ 复杂度：O(n α(n))（近似线性）
// ⚠️ 面试必答："684 = 并查集判环——
//   加边时两端已连通即冗余；
//   有向版本（685）加出入度分析（双连通/02）。"
```

## 5. 最小生成树方法论总结

### 5.1 解题框架

```
① 识别：最小连通 → MST
② 建边：
   点集 → 计算边（曼哈顿）
   选项 → 虚拟节点转边
   已给边 → 直接用
③ 选算法：Kruskal（边集）/ Prim（邻接）
④ 判环：并查集
⑤ 边界：连不通返回 -1、边数 n-1

⚠️ 识别信号：
  "连接所有点/城市最小费用" → MST
  "打井/引水选项" → 虚拟节点
  "删冗余边成树" → 并查集判环
```

### 5.2 模板速查表

| 题型 | 形态 | 代表题 |
|------|------|--------|
| 点集 MST | 建边 + Kruskal | 1584 |
| 选项转边 | 虚拟节点 | 1168 |
| 标准 MST | Kruskal 样板 | 1135 |
| 判环删边 | 并查集 | 684 |
| 关键边 | 删边重跑 | 1489 |

### 5.3 自测清单

```
□ 并查集路径压缩？
□ 判环（find 相同跳过）？
□ 提前结束（n-1 条）？
□ 虚拟节点边数（n+1 → n 条）？
□ 连不通返回 -1？
□ 排序（O(E log E)）？
□ 选型（Kruskal/Prim）？
```

---

> 🎯 **核心要点**：MST 题 = **建边**（点集/虚拟节点/已给）+ **Kruskal 判环** + **边界**（连不通/边数）。四题覆盖全部形态：点集（1584）、虚拟节点（1168）、标准（1135）、判环（684）——"最小连通"识别后，并查集 + 排序是万能骨架。
