## 1. 差分约束系统

### 1.1 问题定义与核心洞察

```text
差分约束系统：一组形如 x_j - x_i ≤ c_k 的不等式
目标：找一组可行解（x 的取值），或判断无解

核心洞察（面试必答）：
  x_j - x_i ≤ c  ⟺  x_j ≤ x_i + c
  对比最短路三角不等式：dist[v] ≤ dist[u] + w(u,v)
  → 完全相同！所以：
      不等式 x_j ≤ x_i + c  ⟶  建边 i → j，权值 c
      跑最短路 → dist[i] 就是一组可行解 x_i

例子：
  x1 - x2 ≤ 5  → 边 2 → 1 权 5
  x3 - x1 ≤ 2  → 边 1 → 3 权 2
  解出 dist = 对任意可行解整体 +C 仍可行（自由常数）
```

### 1.2 超级源点与可行性判断

```text
为什么需要超级源点？
  普通最短路从单一起点出发，不可达点无解；
  差分约束要求"所有变量"都满足 → 所有点都要有值

做法：
  新增 0 号虚拟节点，向每个点连权 0 的边
  dist[0] = 0 → 从 0 出发跑最短路，所有点都被初始化
  ⚠️ 这等价于隐含不等式 x_i ≤ x_0 + 0 = 0 → 给出一个上界

无解判定 = 负环：
  环上不等式相加：0 ≤ 环权 < 0 → 矛盾
  例：x1 ≤ x2 + 2，x2 ≤ x1 - 3
      → 0 ≤ (x2-x1) + (x1-x2) = -1 → 矛盾（负环）

⚠️ 判负环必须先保证全图可达（超级源点）：
  不可达的子图里若有负环 → 单起点 SPFA 永远发现不了它
```

### 1.3 求最大值 / 最小值

```text
统一为 ≤ 形式（x_j ≤ x_i + c）→ 最短路 → dist = 最大值（上界）
统一为 ≥ 形式（x_j ≥ x_i + c）→ 最长路 → dist = 最大值（下界）

为什么最短路给出"最大值"？
  dist[v] = min(dist[u] + w) 是所有路径约束的交集
  → 满足所有"x_j ≤ x_i + c"的同时尽可能大
  不可达（INF）→ 无上界，任意大（差分约束的自由度）

最长路实现两种：
  ① 取负建图跑最短路（把 ≥ 变 -c 的 ≤）——通用
  ② 直接写 SPFA 松弛条件反向——直观但易错，推荐 ①
```

### 1.4 不等式变形技巧（面试高频）

| 原条件 | 变形 | 建边 |
|------|------|------|
| x_j - x_i ≤ c | 直接用 | i → j 权 c |
| x_j - x_i ≥ c | x_i ≤ x_j - c | j → i 权 -c |
| x_j - x_i = c | 双向 ≤ | i → j 权 c 且 j → i 权 -c |
| x_j - x_i < c（整数） | x_j - x_i ≤ c-1 | i → j 权 c-1 |
| x_j > x_i（整数） | x_j - x_i ≥ 1 | i → j 权 -1（最长路） |
| x_i ≤ C | x_i - x_0 ≤ C | 0 → i 权 C |

```text
前缀和建模（区间约束问题的关键）：
  设 S[i] = 前 i 个位置的和
  · 单点取值区间：0 ≤ S[i] - S[i-1] ≤ 1（位置 i 为 0 或 1）
  · 区间和约束：S[r] - S[l-1] ≥ t → 区间 [l, r] 和至少 t
  → 所有"区间和满足条件"类题目（如 POJ 1201 Intervals）
    都能翻译成差分约束
```

### 1.5 完整模板

```java
/**
 * 差分约束模板：求 x_n - x_1 的最大值（不存在输出 -1，无约束输出 -2）
 * 核心：SPFA 求最短路 + 入队计数判负环 + 超级源点
 */
public long differenceConstraints(int n, List<int[]> ineqs) {
    // ineqs: [i, j, c] 表示 x_j - x_i ≤ c（节点编号从 1 开始）
    List<List<int[]>> graph = new ArrayList<>();
    for (int i = 0; i <= n; i++) graph.add(new ArrayList<>());
    for (int[] e : ineqs) {
        int i = e[0], j = e[1], c = e[2];
        graph.get(i).add(new int[]{j, c});   // i → j 权 c
    }
    // 超级源点 0 → 所有点，权 0
    for (int i = 1; i <= n; i++) graph.get(0).add(new int[]{i, 0});

    long[] dist = new long[n + 1];
    Arrays.fill(dist, Long.MAX_VALUE);
    dist[0] = 0;

    // SPFA：队列 + 入队计数（cnt[v] ≥ n+1 → 负环 → 无解）
    Deque<Integer> q = new ArrayDeque<>();
    boolean[] inQ = new boolean[n + 1];
    int[] cnt = new int[n + 1];
    q.offer(0); inQ[0] = true;

    while (!q.isEmpty()) {
        int u = q.poll(); inQ[u] = false;
        for (int[] e : graph.get(u)) {
            int v = e[0], w = e[1];
            if (dist[u] != Long.MAX_VALUE && dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                if (!inQ[v]) {
                    q.offer(v); inQ[v] = true;
                    if (++cnt[v] > n) return -1;   // 入队超 n+1 次 → 负环
                }
            }
        }
    }
    if (dist[n] == Long.MAX_VALUE) return -2;      // x_n 无上界
    return dist[n];
}
// 复杂度：最坏 O(VE)（SPFA 上界），平均接近 O(E)
// ⚠️ 为什么不用 Dijkstra：边权有负（c 可为负），且需负环判定
```

## 2. 同余最短路

### 2.1 思想：把无限凑数问题压成有限图

```text
问题原型（跳楼机 P3403）：
  有 x、y、z 三种楼层步长，从第 1 层开始，能到达 ≤ H 的多少层？
  等价：a·x + b·y + c·z 能表示 [1, H] 内多少个数（a,b,c ≥ 0）

为什么不能直接 DP/背包？
  H 可到 2^63 - 1 → 状态爆炸

核心洞察：
  固定模数 x（取三种面值最小者），任何能凑出的数 k 满足：
    k ≡ r (mod x)，且 k ≥ dist[r]
  其中 dist[r] = "模 x 余 r 的可凑数的最小值"
  → 只要知道最小可凑数，该余数类内每 +x 都是可凑数！

证明（模数最小者 x 的妙处）：
  dist[r] 意义下，从 dist[r] 出发不断 +x（步长 x 存在！）
  → dist[r], dist[r]+x, dist[r]+2x, ... 全部可凑
  → 余数类 r 的计数 = (H - dist[r]) / x + 1
  → 答案 = Σ 所有余数类的计数，余类互不相交 → 不重不漏
```

### 2.2 建图与求解

```text
建图（x 个点 = 模 x 的剩余系 0..x-1）：
  对每个其他面值 y：
    对每个余数 i：连边 i → (i + y) % x，权值 y
  （x 本身不用连边：它只负责"步进"，不改变余数）

含义：从余数 i 花代价 y 走到余数 (i+y)%x
  → dist[r] 恰好 = "模 x 余 r 的最小可凑数"

求解：Dijkstra（所有边权为正）
  源点：dist[1 % x] = 1（从第 1 层出发；整体平移 0 基则 dist[0]=0）
```

```java
/**
 * 同余最短路模板：洛谷 P3403 跳楼机
 * x, y, z：三种楼层步长；H：最高层（1 基）
 * 返回能到达的层数（不含第 1 层时视题目而定，本模板含第 1 层）
 */
public long jumpMachine(long H, long x, long y, long z) {
    // 取最小面值做模数 → 状态数最少
    long mod = Math.min(x, Math.min(y, z));
    if (mod == 1) return H;                    // 步长 1 → 每层都可达

    // 模 mod 的剩余系建图：每个点 i 连两个转移（另两种步长）
    List<List<long[]>> graph = new ArrayList<>();
    for (int i = 0; i < mod; i++) graph.add(new ArrayList<>());
    long[] steps = {x, y, z};
    for (long s : steps) {
        if (s == mod) continue;                // 模数自身不用连边
        for (int i = 0; i < mod; i++) {
            graph.get(i).add(new long[]{(i + s) % mod, s});
        }
    }

    // Dijkstra：dist[r] = 模 mod 余 r 的最小可凑数
    long[] dist = new long[(int) mod];
    Arrays.fill(dist, Long.MAX_VALUE);
    dist[1 % (int) mod] = 1;                   // 从第 1 层出发

    PriorityQueue<long[]> pq = new PriorityQueue<>((a, b) ->
        Long.compare(a[0], b[0]));
    pq.offer(new long[]{1, 1 % (int) mod});
    while (!pq.isEmpty()) {
        long[] cur = pq.poll();
        long d = cur[0];
        int u = (int) cur[1];
        if (d > dist[u]) continue;
        for (long[] e : graph.get(u)) {
            int v = (int) e[0];
            if (d + e[1] < dist[v]) {
                dist[v] = d + e[1];
                pq.offer(new long[]{dist[v], v});
            }
        }
    }

    // 统计：每个余数类从 dist[r] 起每 +mod 都是可凑数
    long ans = 0;
    for (long r : dist) {
        if (r <= H) ans += (H - r) / mod + 1;
    }
    return ans;
}
// 复杂度：O(mod · log mod)，mod = min(x,y,z) ≤ 10⁵ → 可行
// 注意：x,y,z,H 用 long（H 可达 2^63-1）
```

### 2.3 变体与推广

```text
变体一（P2371 墨墨的等式）：
  求 [L, R] 区间内能凑出的数 → 分别算 ≤R 和 ≤L-1 后相减

变体二（P2662 牛场围栏）：
  求最大凑不出的数 → 所有余数类都可达后，答案有上界
  → 取所有 dist[r] 的最大值，再 -mod 即为最大凑不出数

变体三：最少用几张面值凑出模 K 余 p 的数
  → 边权改 1，跑最短路（或 0-1 BFS），dist[p] 即答案

识别信号：
  "凑数 / 面值 / 楼层 / 步长 + 巨大上界 H"
  当背包 DP 的容量维度撑不住（H > 10⁷）→ 转同余最短路
```

## 3. Johnson 全源最短路

### 3.1 动机：三种全源方案的对比

| 方案 | 复杂度 | 适用 |
|------|:---:|------|
| Floyd | O(V³) | 稠密图，V ≤ 500 |
| n 次 Bellman-Ford | O(V²E) | 不实用 |
| n 次 Dijkstra | O(VE log V) | ⚠️ 但要求无负权边 |
| **Johnson** | O(VE log V) | 稀疏图 + 负权边 |

```text
问题：稀疏图 + 存在负权边 + 要求全源
  朴素思路：n 次 Bellman-Ford → O(V²E) 太慢
  Floyd → O(V³) 稠密图浪费
  → 能不能把负权边"洗"成正权，再跑 n 次 Dijkstra？

错误做法：所有边同时 +C
  → 不同路径边数不同 → 加边数×C → 路径间的相对大小被破坏
  例：s→t 直连 -5 与 s→a→t 两条 +1：
      都 +10 后直连 5、绕行 21 → 最短路从绕行变成直连 → 错

正确做法：每条边的修正量不能是常数，要依赖端点（势能）
```

### 3.2 重赋权（Reweighting）：势能思想

```text
给每个点一个"势能" h[v]（类似重力势能/电势），
定义新边权：w'(u,v) = w(u,v) + h[u] - h[v]

性质一：最短路不变
  任意路径 p: v₁→v₂→…→vₖ 的新长度：
    Σ w'(vᵢ,vᵢ₊₁) = Σ w(vᵢ,vᵢ₊₁) + h[v₁] - h[vₖ]
  → 每条 s→t 路径都加上同一个常数 h[s]-h[t]
  → 路径间相对大小不变 → 最短路不变（所有 s→t 路径同加减）

性质二：势能怎么选才让新边权非负？
  需要 w(u,v) + h[u] - h[v] ≥ 0 ⟺ h[v] ≤ h[u] + w(u,v)
  → 这正是最短路的三角不等式！
  → 取 h[v] = 某个点到 v 的最短路距离即可

怎么得到 h[v]？
  加虚拟源点 s 连所有点权 0 → Bellman-Ford 求最短路
  一次 BF 搞定所有 h[v]，顺带判负环（负环时全源无定义）
```

### 3.3 完整流程与模板

```text
Johnson 五步：
  ① 加虚拟源点 s：向所有点连权 0 的边
  ② Bellman-Ford(s) → h[v] = s 到 v 最短路；发现负环 → 终止
  ③ 重赋权：w'(u,v) = w(u,v) + h[u] - h[v] ≥ 0
  ④ 删 s，对每个点跑一次堆优化 Dijkstra → dist'[u][v]
  ⑤ 还原：dist(u,v) = dist'(u,v) + h[v] - h[u]
```

```java
/**
 * Johnson 全源最短路模板（洛谷 P5905）
 * n 点 m 边，含负权边（保证无负环），返回所有点对最短路
 * edges: [u, v, w]（1 基，返回 0 基 dist[u][v]）
 */
public long[][] johnson(int n, int[][] edges) {
    // ① 建图 + 虚拟源点 0（连所有点权 0）
    List<List<long[]>> graph = new ArrayList<>();
    for (int i = 0; i <= n; i++) graph.add(new ArrayList<>());
    for (int[] e : edges) graph.get(e[0]).add(new long[]{e[1], e[2]});
    for (int i = 1; i <= n; i++) graph.get(0).add(new long[]{i, 0});

    // ② Bellman-Ford 求 h[]（虚拟源点 0 出发），同时判负环
    long[] h = new long[n + 1];
    Arrays.fill(h, Long.MAX_VALUE);
    h[0] = 0;
    boolean hasNegCycle = false;
    for (int round = 0; round <= n; round++) {   // 第 n+1 轮再松弛 = 负环
        boolean updated = false;
        for (int u = 0; u <= n; u++) {
            if (h[u] == Long.MAX_VALUE) continue;
            for (long[] e : graph.get(u)) {
                if (h[u] + e[1] < h[e[0]]) {
                    h[e[0]] = h[u] + e[1];
                    updated = true;
                }
            }
        }
        if (round == n && updated) hasNegCycle = true;
    }
    if (hasNegCycle) return null;                // 负环 → 全源最短路无定义

    // ③ 重赋权：w'(u,v) = w + h[u] - h[v] ≥ 0
    List<List<long[]>> g2 = new ArrayList<>();
    for (int i = 0; i <= n; i++) g2.add(new ArrayList<>());
    for (int[] e : edges) {
        long w2 = e[2] + h[e[0]] - h[e[1]];
        g2.get(e[0]).add(new long[]{e[1], w2});
    }

    // ④⑤ 每个点为起点跑 Dijkstra，再还原
    long[][] res = new long[n][n];
    for (int s = 1; s <= n; s++) {
        long[] d = dijkstra(g2, n, s);
        for (int t = 1; t <= n; t++) {
            if (d[t] == Long.MAX_VALUE) res[s-1][t-1] = Long.MAX_VALUE;
            else res[s-1][t-1] = d[t] + h[t] - h[s];   // 还原
        }
    }
    return res;
}

/** 普通堆优化 Dijkstra（正权图） */
private long[] dijkstra(List<List<long[]>> graph, int n, int s) {
    long[] dist = new long[n + 1];
    Arrays.fill(dist, Long.MAX_VALUE);
    dist[s] = 0;
    PriorityQueue<long[]> pq = new PriorityQueue<>((a, b) ->
        Long.compare(a[0], b[0]));
    pq.offer(new long[]{0, s});
    while (!pq.isEmpty()) {
        long[] cur = pq.poll();
        long d = cur[0];
        int u = (int) cur[1];
        if (d > dist[u]) continue;
        for (long[] e : graph.get(u)) {
            if (d + e[1] < dist[(int) e[0]]) {
                dist[(int) e[0]] = d + e[1];
                pq.offer(new long[]{dist[(int) e[0]], e[0]});
            }
        }
    }
    return dist;
}
// 复杂度：O(VE log V)（BF O(VE) + n 次 Dijkstra），稀疏图优于 Floyd O(V³)
```

### 3.4 与费用流 Primal-Dual 的联系（扩展）

```text

  每次增广后残量图可能含负权反向边
  → 用上一次最短路距离做势能，把残量图边权修正为非负
  → 之后每次增广只需 Dijkstra（原先是 Bellman-Ford/SPFA）
```

## 4. 负环检测深潜

### 4.1 三种判负环方案

| 方案 | 复杂度 | 适用 |
|------|:---:|------|
| Bellman-Ford 第 n 轮再松弛 | O(VE) | 模板题、Johnson 内嵌 |
| SPFA 记录「最短路边数」cnt[v] | 平均快，最坏 O(VE) | 面试首选 |
| SPFA 记录「入队次数」 | 同上 | 同上 |
| SPFA + 栈（DFS 式） | 找负环极快 | 只想快速判定存在性 |

```text
核心原理：
  最短路边数 ≤ V-1（无负环时，简单路径）
  → 若某点最短路边数 ≥ V → 出现重复点 → 存在负环
  SPFA 每松弛一次 v 就 cnt[v] = cnt[u] + 1
  cnt[v] ≥ n → 负环
```

### 4.2 常见坑：不可达负环

```text
单起点 SPFA 只能发现"起点可达"的负环。
差分约束/判负环模板题里：
  必须先把所有点入队（或借超级源点 0 连全图）
  否则负环藏在不可达子图 → 判无解失败 → 结果错误

典型：P4878 Layout 需要两次 SPFA
  ① 带超级源点 → 判负环（无解输出 -1）
  ② 从 1 号点出发 → 求最短路（不可达输出 -2）
```

### 4.3 SPFA vs Bellman-Ford vs Dijkstra（负权全貌）

| 算法 | 负权边 | 判负环 | 复杂度 | 何时用 |
|------|:---:|:---:|:---:|------|
| Dijkstra | ✗ | ✗ | O((V+E)logV) | 正权，默认首选 |
| Bellman-Ford | ✓ | ✓（第 n 轮） | O(VE) | 模板/限步数变体 |
| SPFA | ✓ | ✓（cnt 计数） | 期望 O(E)，最坏 O(VE) | 差分约束、负环判定 |
| Johnson 内嵌 BF | ✓ | ✓ | 预处理一次 | 全源 |

```text
⚠️ SPFA 的最坏复杂度 O(VE) 可被构造卡死（如稠密网格）
  面试话术：'SPFA 平均很快，但最坏 O(VE)，正权图一律用 Dijkstra'
```

## 5. Floyd 变体：最小环与传递闭包

### 5.1 无向图最小环

```text
问题：图中最短的环（≥ 3 个节点），如 LeetCode 2608 图中的最短环

Floyd 找最小环（经典技巧）：
  在枚举中转点 k 时，环 = k 的前驱路径 + 一条边 (i,k) + 边 (k,j)
  在"第 k 轮"更新前，dist 里只含节点 < k 的路径
  → 用 dist[i][j]（i,j < k）+ w(i,k) + w(k,j) 拼出一个环
  → 依次取最小即全局最小环

BFS 替代方案（LC 2608 官方思路）：
  枚举每条边 (u,v) 删掉，从 u 到 v 跑 BFS 最短距离 +1 = 经过该边的环
  复杂度 O(E·(V+E))，稠密图用 Floyd 法更稳
```

```java
/**
 * Floyd 变体：无向图最小环
 * g 为邻接矩阵（无边的位置 INF，自环 0），返回最小环长度（无环返回 INF）
 */
public int minCycle(int n, int[][] g) {
    int INF = Integer.MAX_VALUE / 3;   // 防溢出
    int[][] dist = new int[n][n];
    for (int i = 0; i < n; i++)
        System.arraycopy(g[i], 0, dist[i], 0, n);

    int ans = INF;
    // ⚠️ 顺序：先"找环"，再"更新 dist"，k 循环不变式才成立
    for (int k = 0; k < n; k++) {
        for (int i = 0; i < k; i++) {
            for (int j = 0; j < k; j++) {
                if (i == j) continue;
                // 环 = 最短路径(i→j 只经 <k) + 两条边 k
                ans = Math.min(ans, dist[i][j] + g[i][k] + g[k][j]);
            }
        }
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                dist[i][j] = Math.min(dist[i][j], dist[i][k] + dist[k][j]);
            }
        }
    }
    return ans;
}
// 为什么先找环再更新：dist[i][j] 此时仍只经 < k 的点，
// 与 k 的临边拼出的环恰好是"k 为最大编号"的代表环 → 不重不漏
```

### 5.2 传递闭包（Warshall）

```text
问题：有向图可达性（路径是否存在），如"谁是所有人的祖先"
解法：Floyd 魔改，布尔运算替代加法：
  reach[i][j] = reach[i][j] || (reach[i][k] && reach[k][j])
复杂度 O(V³)，只能小图（V ≤ 10³ 勉强）

优化：
  bitset 压缩一行 → O(V³ / 64)，V = 2000 可行
  Java：BitSet[] rows，转移 rows[i].or(rows[k])（当 reach[i][k]）
```

```java
/**
 * 传递闭包：bitset 优化（O(V³/64)）
 */
public boolean[][] transitiveClosure(int n, boolean[][] adj) {
    BitSet[] reach = new BitSet[n];
    for (int i = 0; i < n; i++) {
        reach[i] = new BitSet(n);
        for (int j = 0; j < n; j++)
            if (adj[i][j]) reach[i].set(j);
    }
    for (int k = 0; k < n; k++) {
        for (int i = 0; i < n; i++) {
            if (reach[i].get(k)) {
                reach[i].or(reach[k]);   // i 能到 k → i 能到 k 能到的一切
            }
        }
    }
    boolean[][] res = new boolean[n][n];
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            res[i][j] = reach[i].get(j);
    return res;
}
```

## 6. 本章小结

```text
差分约束：
  不等式 x_j ≤ x_i + c = 三角不等式 → 建边跑最短路
  超级源点保证连通，负环 = 无解，求最值看 ≤/≥ 方向
  识别信号："至少/至多/不早于" + 变量差值

同余最短路：
  取最小面值作模数 → 剩余系做节点 → Dijkstra → 按余类统计
  识别信号："凑数 + 巨大上界"（背包容量维度撑不住时）

Johnson：
  虚拟源点 + BF 求势能 h → 重赋权 w' = w + h[u] - h[v]
  → n 次 Dijkstra → 还原
  识别信号："负权 + 稀疏 + 全源"

负环检测：
  BF 第 n 轮 / SPFA cnt 计数 / 栈式 SPFA
  ⚠️ 不可达负环要借超级源点

建模方法论：
  看到"最值/可行性 + 约束" → 问：能翻译成路径吗？
  翻译成功 → 选对算法（正权 Dijkstra / 负权 SPFA / 全源 Johnson）
```

> 🎯 **核心要点**：本章是「最短路思想的输出端」——不满足于把最短路当算法，而是当**建模语言**：不等式、凑数、可达性、最小环都能译成最短路问题。差分约束（不等式→边）与同余最短路（余数→节点）是面试最高频的两种建模；Johnson 的势能重赋权则是理解「为什么不能统一加常数」的进阶分水岭。
