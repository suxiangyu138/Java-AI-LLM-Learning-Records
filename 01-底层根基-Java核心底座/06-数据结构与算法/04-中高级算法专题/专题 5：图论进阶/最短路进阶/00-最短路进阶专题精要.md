## 1. 进阶主题地图

### 1.1 进阶与基础的边界

```text
最短路基础（见「最短路」专题）：
  无权图 → BFS          正权 → Dijkstra
  负权 → Bellman-Ford   全源 → Floyd

最短路进阶（本专题）：
  ┌─ 状态维度扩展 ── 分层图最短路（拆点/扩展状态）
  │                 0-1 BFS（双端队列替代堆）
  │                 次短路 / K 短路（并行状态）
  │                 状态压缩最短路（bitmask 入状态）
  ├─ 建模转化 ────── 差分约束系统（不等式 → 最短路）
  │                 同余最短路（剩余系 → 最短路）
  │                 最短路树 / 最短路 DAG（路径还原与计数）
  ├─ 算法演进 ────── Johnson 全源（重赋权 + n 次 Dijkstra）
  │                 SPFA 深潜与负环检测
  │                 Floyd 变体：最小环 / 传递闭包
  └─ 图论衔接 ────── 最短路 → 网络流（费用流最短增广路）
```

### 1.2 进阶的本质：给「状态」扩维度

```text
基础最短路的状态 = 节点 u
进阶最短路的状态 = (节点 u, 附加信息)

附加信息可以是：
  · 已用免费次数  → 分层图（k+1 层）
  · 已访问点集     → 状态压缩（2^n 维）
  · 最短路/次短路  → 双状态并行松弛
  · 边权只取 0/1   → 0-1 BFS（状态无维度，但换更快的队列）
  · 不等式变量     → 差分约束（问题本身就是一张图）
  · 模 K 的余数    → 同余最短路（K 个状态点）

一句话：状态空间越大，能表达的问题越多，代价是点×维度。
```

### 1.3 思维模型：图论建模四步法

```text
① 识别问题是否可建模为最短路：
   求最小代价/最大收益/可行性 → 检查是否满足"三角不等式结构"
② 决定状态维度：
   免费次数？步数上限？访问集合？→ 决定要不要拆点/压维
③ 决定边权语义：
   代价？概率？最大值？步数？0/1 布尔？→ 决定松弛公式与算法
④ 决定算法：
   边权 ≥ 0 → Dijkstra 家族；存在负权 → SPFA/BF；0/1 → 双端队列
```

## 2. 五大进阶武器速查

### 2.1 分层图最短路（免费 k 次问题）

```text
问题：最多 k 条边免费（或扣步数上限），求最小代价
状态：dist[i][j] = 到节点 i 且已用 j 次免费的最小代价
转移：dist[v][j] = min(dist[v][j], dist[u][j] + w)      ← 不用免费
      dist[v][j+1] = min(dist[v][j+1], dist[u][j])        ← 用一次免费
答案：min(dist[t][0..k])（可能用不完 k 次）

两种实现：
  ① 显式建 k+1 层图：层间连 0 权单向边 → 空间 O(nk + mk)，易爆内存
  ② 扩展状态（推荐）：dist 开二维 + 松弛时两路转移 → 空间 O(nk + m)
复杂度：O(mk log(nk))
```

### 2.2 0-1 BFS（边权只有 0/1）

```text
适用：边权 ∈ {0, 1} 的最短路（网格/开关类问题高频）
思想：双端队列 deque
      · 走 0 权边 → 从队头插入（不增加层数）
      · 走 1 权边 → 从队尾插入（层数 +1）
      · 出队即确定（同 BFS 的层序性质）
复杂度：O(V+E)，比 Dijkstra 少一个 log
与 Dijkstra 的关系：0-1 BFS 是 Dijkstra 的特化（桶队列替代堆）
```

### 2.3 次短路（双状态并行）

```text
问题：严格次短路径（长度 > 最短路的最小值）
状态：dist1[i] = 最短路，dist2[i] = 严格次短路
松弛：候选 = dist1[u] + w 或 dist2[u] + w
      · 候选 < dist1[v] → dist2[v] = dist1[v]; dist1[v] = 候选
      · dist1[v] < 候选 < dist2[v] → dist2[v] = 候选
      ⚠️ 等号情况不更新（保证"严格"）
技巧：次短路可以绕路，绕路点在一条最短路边上再走
```

### 2.4 差分约束系统（不等式 → 最短路）

```text
形式：一组不等式  x_j - x_i ≤ c_k
建模：x_j ≤ x_i + c_k  ⟺ 三角不等式 dist[v] ≤ dist[u] + w
      → 连边 i → j，权值 c
求解：加超级源点 0（连所有点权 0）→ 跑 SPFA
判解：出现负环 → 无解（不等式矛盾）
求最大/最小：统一 ≤ 跑最短路得最大值；统一 ≥ 跑最长路得最小值
变形：A = B → A ≤ B 且 B ≤ A（双向 0 权边）
      A < B → A + 1 ≤ B（整数变量）
⚠️ 必须用 SPFA/Bellman-Ford（有负权边），Dijkstra 不可用
```

### 2.5 同余最短路（背包 → 最短路）

```text
问题：给定面值 a₁…aₙ，问能凑出多少个 ≤ H 的数
      或最小凑不出/最大凑不出的数（如「跳楼机」「牛场围栏」）
建模：取最小面值 x 作模数，建 x 个点（模 x 的剩余系 0..x-1）
      · 对每个其他面值 y：连边 i → (i+y) % x，权值 y
      · dist[i] = 能到达的、模 x 余 i 的最小数值
      · 跑 Dijkstra（边权为正）
统计：ans = Σ (H - dist[i]) / x + 1（dist[i] ≤ H 的项）
      每个数 k 的余类唯一 → 不重不漏
```

### 2.6 Johnson 全源最短路（负权 + 全源）

```text
适用：稀疏图 + 含负权边 + 求所有点对最短路
      Floyd O(V³) 太慢时；负权使 n 次 Dijkstra 不可行时
五步：
  ① 加虚拟源点 s → 连所有点权 0 的边
  ② Bellman-Ford 求 s 到每个点最短路 h[v]（顺带判负环）
  ③ 重赋权：w'(u,v) = w(u,v) + h[u] - h[v] ≥ 0  ← 三角不等式保证
  ④ 删虚拟源点，对每个点跑一次堆优化 Dijkstra
  ⑤ 还原：dist(u,v) = dist'(u,v) - h[u] + h[v]
复杂度：O(VE log V)（二叉堆），稀疏图优于 Floyd
```

## 3. 进阶技术选型

### 3.1 问题特征 → 技术对照表

| 问题特征 | 技术 | 复杂度 | 识别信号 |
|------|------|:---:|------|
| 最多 k 次免费/忽略 | 分层图 | O(mk log(nk)) | "最多 k 次"、"可跳过 k 条" |
| 边权 0/1 | 0-1 BFS | O(V+E) | 开关、黑白格、移除障碍 |
| 求第二短路径 | 次短路双状态 | O((V+E) log V) | "第二小代价"、"次短" |
| 一组不等式求可行解/最值 | 差分约束 | O(VE) 最坏 | "至少/至多差多少"、"约束" |
| 面值凑数计数/最小不可凑 | 同余最短路 | O(x·log x) | 面值、楼层、凑数、模余 |
| 负权稀疏图全源 | Johnson | O(VE log V) | 全源 + 负权 + 稀疏 |
| 全源稠密小图 | Floyd | O(V³) | V ≤ 500 |
| 判负环 | SPFA 计数 / BF 第 n 轮 | O(VE) | "矛盾"、"无限减小" |

### 3.2 一句话记忆

```text
分层图 = 免费次数入状态；0-1 BFS = 边权只有 0/1 的 BFS
次短路 = 两个 dist 并行松弛；差分约束 = 不等式建边
同余最短路 = 余数当节点；Johnson = 重赋权把负权洗成正权
```

## 5. 面试要点与追问

### 5.1 面试话术模板

```text
"这个问题本质是带状态的最短路：把免费次数/步数/集合编入状态，
 用 Dijkstra 在扩展状态图上松弛。
 分层图有两种写法：显式建 k+1 层图（直观但费内存），
 或 dist 开二维直接两路转移（省内存，推荐）。
 若边权只有 0/1，可以把堆换成双端队列降到 O(V+E)。
 若是不等式约束问题，转差分约束建图，用 SPFA 判负环。"
```

### 5.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 分层图什么时候用显式建图？ | k 小（≤ 20）、需要路径还原时；k 大用扩展状态省内存 |
| 2 | 分层图答案为什么取 min(dist[t][0..k])？ | 不一定用完 k 次免费就最优，每层终点都要比 |
| 3 | 0-1 BFS 为什么比 Dijkstra 快？ | 边权只有两档 → 桶/双端队列 O(1) 取最小，省 log |
| 4 | 0-1 BFS 队头插入为什么正确？ | 0 权边不增加距离，插队头保持距离不减的队列序 |
| 5 | 差分约束为什么必须 SPFA？ | 图里有负权边（不等式可正可负），且要靠负环判无解 |
| 6 | 差分约束怎么判无解？ | 负环 = 环上不等式相加自相矛盾（0 ≤ 负数） |
| 7 | Johnson 为什么不会改坏最短路？ | 每条路径都加同样的 h[s]-h[t]，路径间相对大小不变 |
| 8 | 同余最短路为什么取最小面值做模？ | 点数 = 模数，取最小面值 → 状态最少、建图最省 |

### 5.3 应用场景提示（简历/项目向）

```text
· 地图导航：分层图 = 多次免单/优先通道 的最优路线（如打车优惠券）
· 游戏寻路：0-1 BFS = 可走/需破墙两种地形的最短路径
· 排课/排产：差分约束 = 任务前后置时间窗约束的可行性判断
· 货币找零/凑数：同余最短路 = 最小不可凑金额、凑数计数
```

## 6. 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 分层图建 k+1 层显式图 | k 大时 MLE | 用扩展状态（dist 二维） |
| 分层图忘了比终点所有层 | 答案偏大 | ans = min(dist[t][0..k]) |
| 0-1 BFS 用堆替代双端队列 | 多一个 log 被卡 | 0 权队头插入 |
| 次短路更新顺序反了 | 次短路数据污染 | 先降级再更新（先 dist2 = dist1） |
| 差分约束用 Dijkstra | 负权边直接错 | 一律 SPFA/Bellman-Ford |
| 差分约束忘加超级源点 | 不可达点无解 | 0 号点连所有点权 0 |
| 差分约束判负环漏不可达点 | 有负环却判无解 | 全部点先入队或借超级源点 |
| 同余最短路模数不取最小面值 | 状态点数过多 | 取最小面值作模数 |
| Johnson 还原忘减 h | 答案全错 | dist(u,v) = dist'(u,v) + h[v] - h[u] |
| 严格次短路用 ≤ 更新 | 非严格（等于也算） | 等号不更新 |

> 🎯 **核心要点**：最短路进阶 = **状态扩维（分层图/0-1BFS/次短路/状态压缩）+ 建模转化（差分约束/同余最短路）+ 算法演进（Johnson）**。面试判断顺序：先看"状态能不能加维度"，再看"问题能不能翻译成不等式/余数"。一切以「识别信号 → 选技术 → 背模板」三步走。
