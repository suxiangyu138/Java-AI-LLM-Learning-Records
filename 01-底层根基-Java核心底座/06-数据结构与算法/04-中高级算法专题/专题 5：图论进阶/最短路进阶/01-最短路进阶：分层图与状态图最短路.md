## 1. 分层图最短路

### 1.1 问题模型

```text
典型题面：n 点 m 边的图，最多可以 k 条边免费（或不计权），
         求 s → t 的最小代价。

实例：坐飞机，最多 k 张 0 元机票；打车，最多 k 张立减券。

关键观察：
  一条边被"免费"时，它的权值视为 0。
  问题不再是普通最短路，因为"用不用免费券"改变了边权。
```

### 1.2 方法一：显式建 k+1 层图（拆点扩边）

```text
把每个节点复制 k+1 份，构成 k+1 层平行图：

  第 0 层  第 1 层  第 2 层  ...  第 k 层
  u₀ ────── u₁ ────── u₂          (垂直线 = 免费通道)
   │  \      │  \      │
   v₀ ────── v₁ ────── v₂

规则：
  ① 每层内部：照抄原图所有边（权值不变，双向边同样复制）
  ② 层间：i 层 → i+1 层，边权 0（走一次 = 用掉 1 次免费）
     ⚠️ 是单向的！免费次数只会增加不会减少
  ③ 跑一次 Dijkstra：起点 = s 在第 0 层的副本，终点 = t 在任意层

空间代价：点 O(nk)，边 O(mk)
  → k 大时容易 MLE（k=1000、n=10⁵ 直接爆）
```

### 1.3 方法二：扩展状态 Dijkstra（推荐，省内存）

```text
不显式建图，而是把"层"编进状态：
  dist[i][j] = 到节点 i、已用 j 次免费的最小代价
  (i, j) 就是一张"虚拟节点"——k+1 层图上的点

松弛时两路转移（模拟两条层间/层内边）：
  dist[v][j]     ← dist[u][j] + w     不用免费（层内边）
  dist[v][j+1]   ← dist[u][j]         用免费（层间 0 权边）

复杂度：O(mk log(nk))，空间 O(nk + m)  ← 省掉 m·k 的显式边
```

```java
/**
 * 分层图最短路模板（扩展状态法）——面试标准答案
 * 问题：最多 k 条边免费，求 s → t 最小代价
 * graph: 邻接表 List<List<int[]>>，int[] = {to, weight}
 * 返回：最小代价（不可达返回 -1）
 */
public int layeredGraphDijkstra(List<List<int[]>> graph, int n,
                                int s, int t, int k) {
    // dist[i][j]：到 i、用了 j 次免费的最小代价
    long[][] dist = new long[n][k + 1];
    for (long[] row : dist) Arrays.fill(row, Long.MAX_VALUE);
    dist[s][0] = 0;

    // 堆元素：(代价, 节点, 已用免费次数)
    PriorityQueue<long[]> pq = new PriorityQueue<>((a, b) ->
        Long.compare(a[0], b[0]));
    pq.offer(new long[]{0, s, 0});

    while (!pq.isEmpty()) {
        long[] cur = pq.poll();
        long d = cur[0];
        int u = (int) cur[1], used = (int) cur[2];

        // 过期跳过（该状态已有更短路径）
        if (d > dist[u][used]) continue;

        for (int[] edge : graph.get(u)) {
            int v = edge[0], w = edge[1];

            // ① 不用免费：层内转移（同 used）
            if (d + w < dist[v][used]) {
                dist[v][used] = d + w;
                pq.offer(new long[]{dist[v][used], v, used});
            }
            // ② 用免费：层间转移（used + 1），边权视为 0
            if (used < k && d < dist[v][used + 1]) {
                dist[v][used + 1] = d;
                pq.offer(new long[]{d, v, used + 1});
            }
        }
    }

    // ⚠️ 答案 = 终点所有层取最小（可能用不完 k 次免费）
    long ans = Long.MAX_VALUE;
    for (int j = 0; j <= k; j++) ans = Math.min(ans, dist[t][j]);
    return ans == Long.MAX_VALUE ? -1 : (int) ans;
}
// 复杂度：O(mk log(nk))，空间 O(nk + m)
```

### 1.4 DP 视角：为什么这样松弛是对的

```text
把 dist[i][j] 看作 DP 状态，转移本质是：

  dist[v][j] = min(
      min_{u→v} ( dist[u][j] + w ),    ← 本条边不免费
      min_{u→v} ( dist[u][j-1] )        ← 本条边免费
  )

这正是一个"带维度 j 的最短路 DP"。
由于图有环、边权非负 → 不能直接拓扑序递推，
而 Dijkstra 的贪心松弛恰好能完成这个 DP：
堆保证"每次取到的是当前最小状态"，
松弛就是状态转移，等价于在这张 (n × (k+1)) 的展开图上跑普通 Dijkstra。

一句话：分层图 = 把 DP 的维度展开成图的维度，再用 Dijkstra 求解。
```

### 1.5 显式建图 vs 扩展状态对比

| 维度 | 显式建 k+1 层图 | 扩展状态（dist 二维） |
|------|------|------|
| 直观性 | ★★★★★ 一眼看懂 | ★★★ 需要理解状态语义 |
| 空间 | O(nk + mk) | O(nk + m)（省一层边） |
| k 大时 | 极易 MLE | 安全 |
| 路径还原 | 直接（记录前驱状态） | 同样可记录 (prev, used) |
| 边界处理 | 终点任意层都算 | min(dist[t][0..k]) |
| 适用 | k ≤ 20 的小题 | 面试首选，k 可到 10⁴ |

### 1.6 分层图变体

```text
① 限步数版（等价于 787 K 站中转）：
   状态 dist[i][j] = 经过 j 条边到达 i
   转移只走层间"步数 +1"，层内无横边
   → 本质是 k+1 轮 Bellman-Ford（快照法），见「最短路」专题

② 两种优惠可叠加：
   dist 加维度即可：dist[i][j] = 用 j 次优惠A、l 次优惠B
   → 状态空间变 (kA+1)×(kB+1)，仍是 Dijkstra

③ 层转移带代价：
   免费券不是 0 而是半价 → 层间边权 w/2，照搬
```

## 2. 0-1 BFS：双端队列版最短路

### 2.1 核心思想

```text
适用场景：边权只有 0 和 1 的最短路。
  · 典型：网格中「空地为 0、墙拆除代价为 1」
  · 面试识别信号："移除障碍物的最小数目"、"开关的最少次数"

为什么普通 BFS 不行？
  BFS 按"层数"扩散，默认每条边走 1 步；
  0 权边不增加距离 → 它的邻居应该和自己在同一"距离层"，
  普通队列先进先出会打乱距离单调性 → 结果可能不是最短。

解法：双端队列 deque
  · 走 0 权边 → 把邻居插到队头（距离不变，保持队首距离最小）
  · 走 1 权边 → 把邻居插到队尾（距离 +1）
  · 每次从队头出队，出队即确定（与 BFS 相同的不变量）

为什么正确？
  队列中元素的"距离"始终非递减（0 权头插、1 权尾插）
  → 队头永远是未处理的最小距离 → 第一次出队即最短路
  → 与 Dijkstra 同构，只是把堆换成了双端队列（两档距离的桶）
```

### 2.2 模板

```java
/**
 * 0-1 BFS 模板
 * 场景：网格图，grid[i][j] == 1 表示障碍（走它代价 1），0 表示空地
 * 从 (0,0) 到 (m-1,n-1)，求最小移除障碍数
 */
public int zeroOneBFS(int[][] grid) {
    int m = grid.length, n = grid[0].length;
    int[][] dist = new int[m][n];
    for (int[] row : dist) Arrays.fill(row, Integer.MAX_VALUE);
    dist[0][0] = 0;

    Deque<int[]> dq = new ArrayDeque<>();   // 双端队列
    dq.offerFirst(new int[]{0, 0});
    int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};

    while (!dq.isEmpty()) {
        int[] cur = dq.pollFirst();
        int x = cur[0], y = cur[1];
        for (int[] d : dirs) {
            int nx = x + d[0], ny = y + d[1];
            if (nx < 0 || nx >= m || ny < 0 || ny >= n) continue;

            int w = grid[nx][ny];           // 边权：0 或 1
            int nd = dist[x][y] + w;
            if (nd < dist[nx][ny]) {
                dist[nx][ny] = nd;
                if (w == 0) dq.offerFirst(new int[]{nx, ny}); // 0 权 → 队头
                else        dq.offerLast(new int[]{nx, ny});  // 1 权 → 队尾
            }
        }
    }
    return dist[m - 1][n - 1];
}
// 复杂度：O(V+E)——每个点入队出队各一次，无 log
```

### 2.3 三种「队列」家族的对比

| 算法 | 数据结构 | 复杂度 | 适用边权 |
|------|------|:---:|------|
| BFS | 普通队列 | O(V+E) | 全部相等（视为 1） |
| **0-1 BFS** | 双端队列 | O(V+E) | 0 或 1 |
| Dijkstra（堆） | 优先队列 | O((V+E) log V) | ≥ 0 任意 |
| Dial 算法 | 桶数组 | O(V+E+C) | 非负小整数 |

```text
本质联系：
  0-1 BFS = 边权只有 2 档的 Dial 算法（两桶 = 双端队列）
  Dial 算法 = 边权整数且上限 C 时，用 C 个桶替代堆
  → 理解 0-1 BFS 是理解「桶替代堆」思想的最小例子
```

### 2.4 推演：开关灯问题

```text
洛谷 P4667 [BalticOI 2011] Switch the Lamp On：
  网格由 '/' 与 '\' 两种斜向导线组成，
  旋转一个开关代价 1，求从左上到右下最少旋转次数。

建模：
  网格每个「交叉点」是节点（(R+1) × (C+1) 个）
  对角连通性有 4 种斜向边：
    · 已有导线方向匹配 → 边权 0（直接走）
    · 不匹配 → 边权 1（旋转一次）
  边权只有 0/1 → 0-1 BFS 秒杀

推演片段（2×2 网格，默认左上 → 右下）：
  起点 (0,0)：两条对角边
    匹配导线 → 距离 0，队头插入
    不匹配   → 距离 1，队尾插入
  队头永远是"没花代价能到的点" → 0 代价点先扩散完
  再扩散 1 代价点 → 保证每次出队的距离最小
```

## 3. 次短路与 K 短路

### 3.1 严格次短路：双状态并行

```text
思想：最短路"顺路"得到的次短路可能只是绕了远路，
     但严格次短路允许重复点（通常不限制），只需比最短路长一点。

维护两个数组：
  dist1[v] = v 的最短路
  dist2[v] = v 的严格次短路（> dist1[v] 中的最小值）

松弛逻辑（核心！）：
  候选 c = dist1[u] + w（或 dist2[u] + w）
  · c < dist1[v]  → dist2[v] = dist1[v]（最短路降级为次短）
                    dist1[v] = c（更新最短路）→ 入堆
  · dist1[v] < c < dist2[v] → dist2[v] = c → 入堆
  · c == dist1[v] → 跳过（严格性：等长不算次短）
  · c == dist2[v] → 跳过（无意义）
  ⚠️ 每次更新的状态都要入堆：次短路也可能继续更新别人
```

```java
/**
 * 严格次短路模板（Dijkstra 双状态）
 * 返回 dist1[t]、dist2[t]（t 的严格次短路；不存在返回 -1）
 */
public int[] secondShortest(List<List<int[]>> graph, int n, int s, int t) {
    int[] d1 = new int[n], d2 = new int[n];
    Arrays.fill(d1, Integer.MAX_VALUE);
    Arrays.fill(d2, Integer.MAX_VALUE);
    d1[s] = 0;

    // 堆：(距离, 节点) —— 双状态共用，按距离最小出堆
    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
    pq.offer(new int[]{0, s});

    while (!pq.isEmpty()) {
        int[] cur = pq.poll();
        int d = cur[0], u = cur[1];
        if (d > d2[u]) continue;              // 比次短路还大 → 过期

        for (int[] edge : graph.get(u)) {
            int v = edge[0], w = edge[1];
            int cand = d + w;

            if (cand < d1[v]) {               // 超越最短路 → 降级
                d2[v] = d1[v];
                d1[v] = cand;
                pq.offer(new int[]{cand, v});
            } else if (cand > d1[v] && cand < d2[v]) {
                d2[v] = cand;                 // 严格大于最短路才更新
                pq.offer(new int[]{cand, v});
            }
            // cand == d1[v]：不更新（保证"严格"）
        }
    }
    return new int[]{d1[t], d2[t] == Integer.MAX_VALUE ? -1 : d2[t]};
}
// 复杂度：O((V+E) log V)，与普通 Dijkstra 同阶
// 推导：每个节点的最短/次短各入堆一次 → 常数 2 倍
```

### 3.2 推演：Roadblocks

```text
洛谷 P2865 [USACO06NOV] Roadblocks：求 1 → 4 的严格次短路
图（无平行边）：1→2 (1)，2→4 (2)，1→3 (4)，3→4 (2)

最短路：1-2-4 = 3
次短路候选：
  1-3-4        = 6  ✓（不同路径，比 3 大）
  1-2-1-2-4    = 5  ✓（允许重复节点的绕行，更短！）
  1-2-4-2-4    = 7  ✗
→ 严格次短路 = 5（重复走 1↔2 一条最短路边，绕行两个单位）

关键结论：
  ① 次短路允许重复节点 → "在最短路上多绕一圈"可能是次短
  ② 双状态 Dijkstra 的松弛 `d2[v] ← d1[u] + w` 会自动发现绕行：
     1→2（d1=1）后，2 无次短；但堆里已有 (1, 2)，
     再经 2→1→2→4 的候选 = 1+1+1+2 = 5 < d2[4] 初始 ∞ → 更新
  ③ 因此次短路无需特判"是否绕行"，双状态并行天然覆盖
```

### 3.3 K 短路（面试扩展）

```text
K 短路 = 第 k 短的 s→t 路径（k 通常很小，如 k=2,3）

解法一：A* 估价 + 优先队列（经典）
  f(v) = g(v) + h(v)，g = 已走代价，h = v→t 的最短路（反图跑一次 Dijkstra）
  优先弹出 f 最小的点，t 第 k 次出队即第 k 短路
  ⚠️ h 必须 ≤ 真实剩余代价（可采纳性）→ 反图最短路天然满足

解法二：可持久化左偏树（竞赛级，面试不考）
  O(m log n + k log k) 严格高效，但实现复杂

面试定位：次短路必须手写；K 短路知道 A* 思路即可
```

## 4. 状态压缩最短路

### 4.1 思路

```text
把「已访问集合」编入状态：
  dist[mask][v] = 已访问集合为 mask 且当前在 v 的最小代价
  mask 是 bitmask（2^n 个状态）

适用：n 很小（≤ 15~20）的"访问指定点集"类问题
  例：864 获得所有钥匙、847 访问所有节点的最短路径

本质：这是「状态空间 = 点 × 2^n」的分层图，
     转移 = 走到新点 v' 并或上 v' 的 bit
     因为边权通常相等 → 用 BFS 即可（等价于 0-1 BFS 的推广）
```

### 4.2 模板（BFS + bitmask）

```java
/**
 * 状态压缩 BFS：n 个节点，从 0 出发，访问所有节点回到任意处的最少步数
 * dist[mask][v] 用 visited 数组（BFS 层数即距离，无需存代价）
 */
public int shortestPathAllNodes(int[][] graph) {  // LeetCode 847
    int n = graph.length;
    // 起点可以是任意点：全部入队（多源）
    Deque<int[]> q = new ArrayDeque<>();
    boolean[][] vis = new boolean[1 << n][n];
    for (int i = 0; i < n; i++) {
        q.offer(new int[]{1 << i, i, 0});   // {mask, 当前点, 步数}
        vis[1 << i][i] = true;
    }

    while (!q.isEmpty()) {
        int[] cur = q.poll();
        int mask = cur[0], u = cur[1], step = cur[2];
        if (mask == (1 << n) - 1) return step;   // 全访问完

        for (int v : graph[u]) {
            int nm = mask | (1 << v);
            if (!vis[nm][v]) {
                vis[nm][v] = true;
                q.offer(new int[]{nm, v, step + 1});
            }
        }
    }
    return -1;
}
// 复杂度：O(2^n · n · degree)，n ≤ 15 时约 50 万状态，可行
```

### 4.3 与分层图的统一视角

```text
分层图：状态 = (节点, 免费次数 j)         —— 维度是"资源计数"
状态压缩：状态 = (节点, 访问集合 mask)    —— 维度是"集合"
时间依赖：状态 = (节点, 时刻 t)           —— 维度是"时间"

→ 三者是同一个套路：状态 = 节点 × 附加维度
→ 附加维度决定空间：k / 2^n / T
→ 识别问题就是识别"什么信息在路径选择中会变化且不可忽略"
```

## 5. 时间依赖图与动态图

### 5.1 时间依赖图（边权随时间变化）

```text
问题：公交班次/地铁时刻表，边权 = 发车间隔 → 等待时间随到达时刻变化
  w(u→v, t) = f(到达 u 的时刻)

解法：状态加时间维
  dist[t][v]：时刻 t 在 v 的最小代价
  ⚠️ 关键：同一时刻状态只取最小值 → 出队即确定（Dijkstra 思想仍成立）
  优化：把时刻离散化为班次 → 只保留有效时刻

面试定位：知道存在即可，多数考察停留在"提示你加时间维"
```

### 5.2 动态图（边权修改）

```text
在线增删边/改权 → 最短路要动态维护：
  · 只加边：增量 Dijkstra（新边只影响局部）
  · 改边权：分段重算（竞赛级，通常不考）
面试题常伪装成：询问多次、每次修改一条边
  → 提示：离线处理（分块/整体二分），或逐次重跑 Dijkstra（n 小）

实际工程（导航系统）：路况变化 = 时间依赖图 + 增量更新
```

## 6. 本章小结

```text
分层图（免费 k 次）：
  状态 dist[i][j] 两路转移 → O(mk log(nk))
  显式建图直观但费内存，扩展状态是面试标准答案
  答案取 min(dist[t][0..k])

0-1 BFS：
  边权 {0,1} → 双端队列替代堆 → O(V+E)
  0 权队头、1 权队尾，出队即确定

次短路：
  d1/d2 双状态并行松弛，先降级再更新
  严格性 → 等号不更新；绕行路径天然被考虑

状态压缩：
  mask 入状态 → BFS 按层扩散
  n ≤ 15~20 才可行

统一视角：最短路进阶 = 节点 × 附加维度
```

> 🎯 **核心要点**：本章全部技术本质是「**给状态加维度**」。分层图加资源计数、状态压缩加集合、时间依赖加时刻；0-1 BFS 则是「边权只有两档时用双端队列替代堆」的效率优化。面试拿到新题先问自己：路径最优解依赖哪些附加信息？把它编进状态，Dijkstra 家族就能接住。
