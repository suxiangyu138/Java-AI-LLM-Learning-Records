## 1. P4568 [JLOI2011] 飞行路线（分层图模板）

### 1.1 题目与思路

```text
n 点 m 边无向图，可最多 k 条边免费，求 s → t 最小花费
分层图模板题：状态 = (节点, 已用免费次数)
两种写法：显式 k+1 层图（易 MLE） / 扩展状态 dist 二维（推荐）
```

### 1.2 完整代码

```java
/**
 * 洛谷 P4568 [JLOI2011] 飞行路线（分层图：扩展状态 Dijkstra）
 * n ≤ 1e4, m ≤ 5e4, k ≤ 10，节点 0 基
 */
public int flightRoute(int n, int m, int k,
                       List<int[]>[] graph, int s, int t) {
    long[][] dist = new long[n][k + 1];
    for (long[] row : dist) Arrays.fill(row, Long.MAX_VALUE);
    dist[s][0] = 0;

    PriorityQueue<long[]> pq = new PriorityQueue<>((a, b) ->
        Long.compare(a[0], b[0]));                 // (代价, 节点, 已用免费次数)
    pq.offer(new long[]{0, s, 0});

    while (!pq.isEmpty()) {
        long[] cur = pq.poll();
        long d = cur[0];
        int u = (int) cur[1], used = (int) cur[2];
        if (d > dist[u][used]) continue;           // 过期跳过

        for (int[] e : graph[u]) {
            int v = e[0], w = e[1];
            if (d + w < dist[v][used]) {           // 不用免费
                dist[v][used] = d + w;
                pq.offer(new long[]{dist[v][used], v, used});
            }
            if (used < k && d < dist[v][used + 1]) { // 用一次免费（权 0）
                dist[v][used + 1] = d;
                pq.offer(new long[]{d, v, used + 1});
            }
        }
    }

    long ans = Long.MAX_VALUE;                     // ⚠️ 终点所有层取最小
    for (int j = 0; j <= k; j++) ans = Math.min(ans, dist[t][j]);
    return (int) ans;
}
// 复杂度：O(mk log(nk))，空间 O(nk + m)
// 推演：k=1 时相当于"删一条边后最短路"——
//   第 0 层算普通最短路，第 1 层 = 用过免费的最短路
// 面试必答："分层图本质是把 DP 维度展开成图维度；
//   免费次数 j 是状态的一部分，转移两路：用 / 不用。"
```

### 1.3 变体：P2939 [USACO09FEB] 修路

```text
与飞行路线同构：把 k 条路的"花费改为 0"
区别：双向边（建图时两侧都加）；k 可能更大 → 必须用扩展状态
识别信号："最多改造 k 条 / 免费 k 条 / 忽略 k 条" → 分层图
```

## 2. 2290. 到达角落需要移除障碍物的最小数目（0-1 BFS）

### 2.1 题目与思路

```text
m × n 网格，0 = 空地，1 = 障碍（移除代价 1）
从 (0,0) 到 (m-1,n-1)，求最少移除障碍数
边权 = 目标格的值（0 或 1）→ 0-1 BFS：双端队列替代堆
```

### 2.2 完整代码

```java
/**
 * LeetCode 2290. 到达角落需要移除障碍物的最小数目（0-1 BFS）
 * 等价于 Dijkstra，但边权只有 0/1 → 双端队列 O(V+E)
 */
public int minimumObstacles(int[][] grid) {
    int m = grid.length, n = grid[0].length;
    int[][] dist = new int[m][n];
    for (int[] row : dist) Arrays.fill(row, Integer.MAX_VALUE);
    dist[0][0] = 0;

    Deque<int[]> dq = new ArrayDeque<>();
    dq.offerFirst(new int[]{0, 0});                // 0 权 → 队头
    int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};

    while (!dq.isEmpty()) {
        int[] cur = dq.pollFirst();
        int x = cur[0], y = cur[1];
        for (int[] d : dirs) {
            int nx = x + d[0], ny = y + d[1];
            if (nx < 0 || nx >= m || ny < 0 || ny >= n) continue;
            int nd = dist[x][y] + grid[nx][ny];    // 边权 = 目标格 0/1
            if (nd < dist[nx][ny]) {
                dist[nx][ny] = nd;
                if (grid[nx][ny] == 0) dq.offerFirst(new int[]{nx, ny});
                else                   dq.offerLast(new int[]{nx, ny});
            }
        }
    }
    return dist[m - 1][n - 1];
}
// 复杂度：O(mn)，比堆优化快一个 log
// 面试必答："0-1 BFS = 边权两档的 Dial 算法；
//   0 权队头插入保持距离不减，出队即确定。"
```

### 2.3 同型题

```text
· P4667 [BalticOI 2011] Switch the Lamp On：斜向开关旋转，0-1 BFS 经典
· 网格"最少移除 / 最少破墙"类 → 识别信号统一是 0/1 代价
· 多源 0-1 BFS 变体：多个起点同时入队，同样按 0/1 权头尾插入
```

## 3. P2865 [USACO06NOV] Roadblocks（严格次短路）

### 3.1 题目与思路

```text
求 1 → N 的严格次短路（比最短路长，且是第二小）
双状态 Dijkstra：d1 = 最短路，d2 = 严格次短路
核心：候选 > d1[v] 才可能更新 d2（保证"严格"）
```

### 3.2 完整代码

```java
/**
 * 洛谷 P2865 [USACO06NOV] Roadblocks（严格次短路，双状态）
 * n ≤ 5000，m ≤ 1e5，双向边
 */
public int roadblocks(int n, List<int[]>[] graph, int s, int t) {
    int[] d1 = new int[n + 1], d2 = new int[n + 1];
    Arrays.fill(d1, Integer.MAX_VALUE);
    Arrays.fill(d2, Integer.MAX_VALUE);
    d1[s] = 0;

    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
    pq.offer(new int[]{0, s});

    while (!pq.isEmpty()) {
        int[] cur = pq.poll();
        int d = cur[0], u = cur[1];
        if (d > d2[u]) continue;                   // ⚠️ 比次短还大 → 过期

        for (int[] e : graph[u]) {
            int v = e[0], w = e[1];
            int cand = d + w;
            if (cand < d1[v]) {                    // 超越最短路 → 降级
                d2[v] = d1[v];
                d1[v] = cand;
                pq.offer(new int[]{cand, v});
            } else if (cand > d1[v] && cand < d2[v]) {
                d2[v] = cand;                      // 严格性：等号不更新
                pq.offer(new int[]{cand, v});
            }
        }
    }
    return d2[t];
}
// 复杂度：O((V+E) log V)，双状态只带来常数 2
// 推演：1→2(1) 2→4(2) 1→3(4) 3→4(2)
//   d1[4]=3；d2[4] 最终 = 5（1→2→1→2→4 绕行）✓
// 面试必答："次短路允许重复节点 → 绕行路径天然被双状态发现；
//   更新顺序是先降级最短路再尝试更新次短路。"
```

## 4. P5960 【模板】差分约束（超级源点 + 判负环）

### 4.1 题目与思路

```text
n 个变量 m 个不等式 x_j - x_i ≤ c，求任意一组可行解（无解输出 NO）
建模：x_j ≤ x_i + c → 边 i → j 权 c → 最短路
超级源点 0 连所有点权 0 → 保证全图可达 → 负环 = 无解
⚠️ 必须 SPFA（有负权边 + 判负环），Dijkstra 不可用
```

### 4.2 完整代码

```java
/**
 * 洛谷 P5960 【模板】差分约束
 * 输入：n, m；m 行 u v c 表示 x_v - x_u ≤ c
 * 输出：任意可行解 x[1..n]，无解输出 "NO"
 */
public void diffConstraint(int n, int m, int[][] ineq) {
    List<List<int[]>> graph = new ArrayList<>();
    for (int i = 0; i <= n; i++) graph.add(new ArrayList<>());
    for (int[] e : ineq) graph.get(e[0]).add(new int[]{e[1], e[2]});
    for (int i = 1; i <= n; i++) graph.get(0).add(new int[]{i, 0}); // 超级源点

    int[] dist = new int[n + 1];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[0] = 0;

    Deque<Integer> q = new ArrayDeque<>();
    boolean[] inQ = new boolean[n + 1];
    int[] cnt = new int[n + 1];
    q.offer(0);
    inQ[0] = true;

    while (!q.isEmpty()) {
        int u = q.poll();
        inQ[u] = false;
        for (int[] e : graph.get(u)) {
            int v = e[0], w = e[1];
            if (dist[u] != Integer.MAX_VALUE && dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                if (!inQ[v]) {
                    q.offer(v);
                    inQ[v] = true;
                    if (++cnt[v] > n) {            // 入队 > n 次 → 负环
                        System.out.println("NO");
                        return;
                    }
                }
            }
        }
    }
    for (int i = 1; i <= n; i++) System.out.println(dist[i]); // 一组可行解
}
// 复杂度：期望 O(E)，最坏 O(VE)（SPFA 上界）
// 面试必答："差分约束 = 三角不等式的逆向翻译；
//   负环对应环上不等式自相矛盾，因此无解。
//   超级源点保证所有变量被约束，否则不可达子图的负环会漏判。"
```

### 4.3 变体：P1993 小 K 的农场（混合约束）

```text
三种约束（都是 1 基）：
  a b c：x_a - x_b ≥ c   → x_b ≤ x_a - c → 边 a → b 权 -c（最长路视角）
  a b c：x_a - x_b ≤ c   → 边 b → a 权 c
  a b c（c=0 时）：x_a = x_b → 双向 0 权边
判可行性：负环 → 矛盾 → "No"
⚠️ 统一转化技巧：≥ 形式取反变成 ≤（边权变负），仍跑最短路判负环
```

## 5. P3403 跳楼机（同余最短路）

### 5.1 题目与思路

```text
给定步长 x, y, z，从第 1 层出发，问能到达 ≤ H 的多少层
H 可达 2^63-1 → 背包维度爆炸 → 同余最短路
取最小步长为模数 mod，剩余系 0..mod-1 做节点
dist[r] = 模 mod 余 r 的最小可到达层数 → 每 +mod 都可达 → 按余类计数
```

### 5.2 完整代码

```java
/**
 * 洛谷 P3403 跳楼机（同余最短路，Dijkstra）
 * 模数取最小步长 → 状态数最少；x,y,z ≤ 1e5，H ≤ 2^63-1 用 long
 */
public long jumpMachine(long H, long x, long y, long z) {
    long mod = Math.min(x, Math.min(y, z));
    if (mod == 1) return H;                        // 步长 1 → 每层都可达

    List<long[]>[] graph = new List[(int) mod];
    for (int i = 0; i < mod; i++) graph[i] = new ArrayList<>();
    long[] steps = {x, y, z};
    for (long s : steps) {
        if (s == mod) continue;
        for (int i = 0; i < mod; i++)
            graph[i].add(new long[]{(i + s) % mod, s});
    }

    long[] dist = new long[(int) mod];
    Arrays.fill(dist, Long.MAX_VALUE);
    dist[1 % (int) mod] = 1;

    PriorityQueue<long[]> pq = new PriorityQueue<>((a, b) ->
        Long.compare(a[0], b[0]));
    pq.offer(new long[]{1, 1 % (int) mod});
    while (!pq.isEmpty()) {
        long[] cur = pq.poll();
        long d = cur[0];
        int u = (int) cur[1];
        if (d > dist[u]) continue;
        for (long[] e : graph[u]) {
            if (d + e[1] < dist[(int) e[0]]) {
                dist[(int) e[0]] = d + e[1];
                pq.offer(new long[]{dist[(int) e[0]], e[0]});
            }
        }
    }

    long ans = 0;
    for (long r : dist)
        if (r <= H) ans += (H - r) / mod + 1;      // 余类内每 +mod 都可达
    return ans;
}
// 复杂度：O(mod log mod)，mod ≤ 1e5 → 可行
// 面试必答："同余最短路 = 用模数把无限计数问题压成 mod 个节点；
//   一个余数类的最小可达数决定该类所有可达数（步进 = 模数）。"
```

### 5.3 变体：P2371 墨墨的等式（区间统计）

```text
问 [L, R] 内能凑出的数 → ans = count(≤ R) - count(≤ L-1)
    count(H) 用同余最短路模板（上题）求出
识别信号："凑出 / 拼出 + 上界 10^18 级别" → 同余最短路
```

## 7. 2608. 图中的最短环（BFS 删边法）

### 7.1 题目与思路

```text
n 节点无向图（简单图），求最短环的边数（环长 ≥ 3，无环返回 -1）
删边法：枚举每条边 (u,v)，删掉后从 u 到 v 的 BFS 最短距离 +1
       = 经过该边的最小环长 → 全局取最小
⚠️ 必须用"边编号"而非"节点对"删除，防止平行边互相干扰
```

### 7.2 完整代码

```java
/**
 * LeetCode 2608. 图中的最短环（BFS 删边法）
 * n ≤ 1000，m ≤ 1000
 */
public int findShortestCycle(int n, int[][] edges) {
    // 邻接表存 (邻居, 边编号)——删边按编号删
    List<int[]>[] graph = new List[n];
    for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
    for (int i = 0; i < edges.length; i++) {
        int u = edges[i][0], v = edges[i][1];
        graph[u].add(new int[]{v, i});
        graph[v].add(new int[]{u, i});
    }

    int ans = Integer.MAX_VALUE;
    for (int i = 0; i < edges.length; i++) {
        int u = edges[i][0], v = edges[i][1];
        // 删掉边 i 后，u → v 的 BFS 距离 +1 = 经过该边的最小环
        int d = bfs(n, graph, u, v, i);
        if (d != -1) ans = Math.min(ans, d + 1);
    }
    return ans == Integer.MAX_VALUE ? -1 : ans;
}

/** 从 start 到 end 的最短路（禁止经过编号 bannedIdx 的边） */
private int bfs(int n, List<int[]>[] graph, int start, int end, int bannedIdx) {
    int[] dist = new int[n];
    Arrays.fill(dist, -1);
    dist[start] = 0;
    Deque<Integer> q = new ArrayDeque<>();
    q.offer(start);
    while (!q.isEmpty()) {
        int u = q.poll();
        if (u == end) return dist[u];
        for (int[] nb : graph[u]) {
            if (nb[1] == bannedIdx) continue;   // ⚠️ 按边编号跳过，避免平行边误删
            if (dist[nb[0]] == -1) {
                dist[nb[0]] = dist[u] + 1;
                q.offer(nb[0]);
            }
        }
    }
    return -1;
}
// 复杂度：O(m × (V+E))；m ≤ 1000 时可行
// 面试必答："删边 BFS = 枚举环上的'必经边'；
//   也可以枚举边后用 Floyd 的 k 序技巧 O(V³) 找最小环（稠密图）。"
```

## 8. 864. 获得所有钥匙的最短路径（状态压缩 BFS）

### 8.1 题目与思路

```text
网格含钥匙 a-f 与门 A-F（匹配钥匙才能过），起点 @
求拿到所有钥匙的最短步数
状态 = (x, y, 钥匙集合 mask) → BFS（每步代价 1）
mask ≤ 2^6 = 64 种 → 状态总数 m·n·64 可控
```

### 8.2 完整代码

```java
/**
 * LeetCode 864. 获得所有钥匙的最短路径（状态压缩 BFS）
 * 钥匙 ≤ 6 把 → mask 6 bit
 */
public int shortestPathAllKeys(String[] grid) {
    int m = grid.length, n = grid[0].length();
    int sx = 0, sy = 0, allKeys = 0;
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++) {
            char c = grid[i].charAt(j);
            if (c == '@') { sx = i; sy = j; }
            else if (c >= 'a' && c <= 'f') allKeys |= 1 << (c - 'a');
        }

    // visited[x][y][mask]
    boolean[][][] vis = new boolean[m][n][1 << 6];
    Deque<int[]> q = new ArrayDeque<>();
    q.offer(new int[]{sx, sy, 0, 0});          // x, y, mask, step
    vis[sx][sy][0] = true;
    int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};

    while (!q.isEmpty()) {
        int[] cur = q.poll();
        int x = cur[0], y = cur[1], mask = cur[2], step = cur[3];
        if (mask == allKeys) return step;

        for (int[] d : dirs) {
            int nx = x + d[0], ny = y + d[1];
            if (nx < 0 || nx >= m || ny < 0 || ny >= n) continue;
            char c = grid[nx].charAt(ny);
            if (c == '#') continue;                    // 墙
            if (c >= 'A' && c <= 'F') {                // 门：需对应钥匙
                if ((mask & (1 << (c - 'A'))) == 0) continue;
            }
            int nmask = mask;
            if (c >= 'a' && c <= 'f') nmask |= 1 << (c - 'a'); // 捡钥匙

            if (!vis[nx][ny][nmask]) {
                vis[nx][ny][nmask] = true;
                q.offer(new int[]{nx, ny, nmask, step + 1});
            }
        }
    }
    return -1;
}
// 复杂度：O(m · n · 2^k)；k ≤ 6 → 可行
// 面试必答："钥匙集合是路径选择中的关键信息 →
//   必须进状态；2^6 状态 × 网格 = 典型状态压缩 BFS。"
```

## 9. 最短路进阶方法论总结

### 9.1 识别信号 → 技术 → 模板（速查）

| 题面信号 | 技术 | 模板位置 |
|------|------|------|
| "最多 k 条免费 / 改造 / 忽略" | 分层图 | 01 模块 1.3 |
| 代价只有 0/1（破墙、开关） | 0-1 BFS | 01 模块 2.2 |
| "次短 / 第二小代价" | 双状态 Dijkstra | 01 模块 3.1 |
| "至少 / 至多 / 不早于" + 差值 | 差分约束 | 02 模块 1.5 |
| "凑数 / 面值 / 楼层 + 巨大上界" | 同余最短路 | 02 模块 2.2 |
| 负权 + 全源 + 稀疏 | Johnson | 02 模块 3.3 |
| "最短环 / 是否有环长 ≤ x" | BFS 删边 / Floyd | 03 模块 7 |
| "钥匙 / 访问集合 + n ≤ 15" | 状态压缩 BFS | 01 模块 4.2 |

### 9.2 做题顺序（面试口述流程）

```text
① 先找"路径最优依赖哪些附加信息"→ 决定状态维度
② 再判边权性质 → 决定算法（正权 Dijkstra / 0/1 双端队列 / 负权 SPFA）
③ 最后套模板 → 注意三坑：过期跳过、终点多状态取 min、不可达判定
```

### 9.3 一句话考点清单

```text
分层图：dist[i][j] 两路转移，答案 min(dist[t][0..k]) —— 必背
0-1 BFS：0 权队头、1 权队尾，O(V+E) —— 必背
次短路：先降级再更新，等号不更新（严格） —— 高频
差分约束：≤ 建边、超级源点、负环无解 —— 高频
同余最短路：最小面值做模，余类统计 —— 进阶
Johnson：势能重赋权，路径等价加常数 —— 进阶
```

> 🎯 **核心要点**：八道母题 = 五大进阶技术的标准载体。面试做到「识别信号 → 报技术 → 背模板 → 点三坑」就能过关；刷题建议按「分层图 → 0-1 BFS → 次短路 → 差分约束」四连刷建立手感，再挑战同余最短路与 Johnson。
