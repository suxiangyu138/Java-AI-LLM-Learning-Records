## 1. 核心概念

### 1.1 什么是强连通分量

> 强连通分量（SCC）：有向图中**任意两点互相可达**的最大节点组。每个节点恰好属于一个 SCC。

```
例：A→B→C→A（互相可达 → 一个 SCC）
    D→E（E 到不了 D → 不是 SCC）

有向图 vs 无向图：
  无向图：连通分量（DFS 一遍即可）
  有向图：强连通分量（方向性 → 需要 Tarjan/Kosaraju）

价值：**缩点**——把每个 SCC 压成一个点
  → 原图变成 DAG（无环）→ 可拓扑/DP
```

### 1.2 识别信号

```
"互相可达/强连通" → SCC
"缩点后 DAG" → SCC 思想
"最少加边使强连通" → 缩点后统计出入度
"有向图环相关" → SCC 候选

⚠️ 面试定位：竞赛/进阶级
  笔试可能出现；面试手撕少
  掌握模板 + 缩点思想即可
```

### 1.3 两大算法

| 算法 | 思路 | 实现 |
|------|------|:---:|
| **Tarjan** | dfn/low + 栈，一次 DFS | 推荐（代码短） |
| Kosaraju | 两遍 DFS（正图+反图） | 直观但需反图 |

```
选型：Tarjan（一次 DFS，面试展示）
  或 Kosaraju（思路直观：正图排序 → 反图 DFS）
  讲清任一即可
```

## 2. Tarjan 完整模板

### 2.1 标准实现

```java
/**
 * Tarjan 求强连通分量
 * 核心变量：
 *   dfn[u]：u 的访问序号（时间戳）
 *   low[u]：u 的子树中能到达的最小 dfn
 *   栈：保存当前 SCC 的候选节点
 */
public List<List<Integer>> tarjanSCC(List<List<Integer>> graph) {
    int n = graph.size();
    int[] dfn = new int[n];
    int[] low = new int[n];
    boolean[] inStack = new boolean[n];
    Deque<Integer> stack = new ArrayDeque<>();
    List<List<Integer>> sccs = new ArrayList<>();
    int[] timer = new int[1];        // 时间戳计数器

    // ⚠️ 图可能不连通 → 遍历所有起点
    for (int i = 0; i < n; i++) {
        if (dfn[i] == 0) {
            dfs(i, graph, dfn, low, inStack, stack, sccs, timer);
        }
    }
    return sccs;
}

private void dfs(int u, List<List<Integer>> graph,
                 int[] dfn, int[] low, boolean[] inStack,
                 Deque<Integer> stack, List<List<Integer>> sccs,
                 int[] timer) {
    dfn[u] = low[u] = ++timer[0];    // ① 初始化时间戳
    stack.push(u);
    inStack[u] = true;

    for (int v : graph.get(u)) {
        if (dfn[v] == 0) {           // ② 未访问 → 递归
            dfs(v, graph, dfn, low, inStack, stack, sccs, timer);
            low[u] = Math.min(low[u], low[v]);   // 用子树更新
        } else if (inStack[v]) {     // ③ 在栈中 → 回边
            low[u] = Math.min(low[u], dfn[v]);
        }
    }

    // ④ ⚠️ dfn == low → u 是 SCC 根 → 弹栈
    if (dfn[u] == low[u]) {
        List<Integer> scc = new ArrayList<>();
        while (true) {
            int node = stack.pop();
            inStack[node] = false;
            scc.add(node);
            if (node == u) break;    // 弹到 u 为止
        }
        sccs.add(scc);
    }
}
// 复杂度 O(V+E)：每条边恰访问一次
```

### 2.2 dfn 与 low 的理解

```
dfn[u]：u 是什么时候被访问的（时间戳）
low[u]：u 通过子树/回边能"够到"的最早时间戳

dfn[u] == low[u] 的含义：
  u 的子树无法到达 u 之前访问的节点
  → u 是这个 SCC 中"最早"的节点（根）
  → 栈中 u 之上的节点都属于这个 SCC

⚠️ 面试表达：
"dfn 是访问时间戳，low 是通过回边
 能回到的最早时间戳。dfn==low 说明
 该节点是分量根——弹栈得到一个 SCC。"
```

### 2.3 推演：A→B→C→A，D→E

```
节点 A,B,C,D,E，边 A→B, B→C, C→A, D→E

DFS(A)（从 A 开始）：
  dfn[A]=1, low[A]=1
  → B：dfn[B]=2 → C：dfn[C]=3
    C→A：A 在栈中（inStack）→ low[C]=min(3,1)=1
    返回：low[B]=min(2,1)=1；low[A]=min(1,1)=1
  dfn[A]==low[A]==1 → 弹栈 C,B,A → SCC1 = {A,B,C} ✓

DFS(D)（下一个未访问）：
  dfn[D]=4 → E：dfn[E]=5
  E 无出边 → dfn[E]==low[E]==5 → SCC2 = {E}
  D 无其他 → dfn[D]==low[D]==4 → SCC3 = {D}
结果：[{A,B,C}, {E}, {D}] ✓
```

## 3. 缩点思想详解

### 3.1 缩点 = SCC → DAG

```
缩点：把每个 SCC 压成一个节点
  原图 → DAG（无环！）

为什么必然无环？
  若缩点后有环 → 环上的点互相可达
  → 应属同一 SCC → 矛盾

价值：
  ① 拓扑排序（DAG 可拓扑）
  ② DP（DAG 上最长路/计数）
  ③ 统计出入度为 0 的 SCC（最少加边）
```

### 3.2 应用：最少加边使强连通

```
问题：有向图最少加几条边使整个图强连通？

解法（缩点后）：
  SCC 缩点 → DAG
  入度为 0 的 SCC 数 = a
  出度为 0 的 SCC 数 = b
  答案 = max(a, b)（单 SCC 特判 0）

直觉：入度 0 需要"被连入"，出度 0 需要"连出去"
  → 两两配对（加边连接）

⚠️ 面试表达：
"缩点后统计入度/出度为 0 的 SCC 数，
 答案取两者较大值——每个入度 0 的
 需要一条入边，出度 0 的需要一条出边，
 配对连接。"
```

### 3.3 缩点 + DP

```
DAG 上 DP（缩点后）：
  ① 拓扑排序（Kahn）
  ② 按拓扑序递推：
     dp[v] = max(dp[v], dp[u] + 价值[v])

应用：可达性统计、最长路径、方案计数

⚠️ 面试加分：
"缩点把复杂有向图变成 DAG，
 之后所有 DAG 算法（拓扑/DP）都可用了。"
```

## 4. 强连通 vs 其他图论概念

### 4.1 概念对比

| 概念 | 图类型 | 定义 | 算法 |
|------|:---:|------|:---:|
| 连通分量 | 无向 | 互相可达（无向） | DFS |
| 强连通分量 | 有向 | 互相可达（有向） | Tarjan |
| 双连通分量 | 无向 | 无割点 | Tarjan 变体 |
| 环 | 两者 | 回到自身的路径 | 拓扑/颜色法 |

```
⚠️ 易混点：
  无向图 → 连通分量（简单）
  有向图 → 强连通分量（复杂）
  无向图割点 → 双连通（见双连通专题）
```

### 4.2 Tarjan vs Kosaraju

| 维度 | Tarjan | Kosaraju |
|------|:---:|:---:|
| DFS 次数 | 1 次 | 2 次（正+反图） |
| 空间 | 栈 | 反图 |
| 代码 | 稍短 | 直观 |
| 理解 | dfn/low | 排序+反转 |

```
Kosaraju 思路（了解）：
  ① 正图 DFS → 记录完成顺序
  ② 反图按完成顺序逆序 DFS → 每次得一个 SCC
  ⚠️ 需要建反图（空间翻倍）
```

### 4.3 与拓扑判环的关系

```
判环的两种路径：
  拓扑（Kahn/颜色法）：只判"有无环"
  强连通（Tarjan）：找出"所有环的结构"

选型：
  只判有无环 → 拓扑（更简单）
  需要环的组成/缩点 → Tarjan
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"强连通分量用 Tarjan：dfn 记录时间戳，
 low 记录子树可达的最早时间，dfn==low
 说明是分量根，弹栈得到 SCC。
 缩点后图变 DAG，可以做拓扑和 DP。
 O(V+E)。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | dfn 和 low 区别？ | dfn 访问时间戳；low 可达最早时间戳 |
| 2 | 为什么缩点是 DAG？ | 缩点有环 → 应同 SCC（矛盾） |
| 3 | 最少加边怎么算？ | max(入度 0 数, 出度 0 数) |
| 4 | 与拓扑判环区别？ | 拓扑判有无；SCC 找结构 |
| 5 | 与连通分量区别？ | 无向 vs 有向 |
| 6 | 栈的作用？ | 保存当前 SCC 候选（弹到根） |
| 7 | 回边处理？ | inStack 判断（区分已完成） |
| 8 | Kosaraju 思路？ | 正图排序 + 反图 DFS（两遍） |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 忘遍历所有起点 | 漏 SCC | for 循环未访问 |
| 回边忘 inStack 判断 | low 错误 | 只有栈中才更新 |
| 弹栈边界错 | SCC 错 | 弹到 u 为止 |
| 缩点建图漏边 | DAG 不完整 | 跨 SCC 边重连 |
| 时间戳忘递增 | dfn 全 0 | ++timer[0] |

> 🎯 **核心要点**：Tarjan = **dfn/low + 栈 + dfn==low 弹栈**。识别信号："互相可达、强连通、最少加边"。缩点思想（SCC→DAG→拓扑/DP）比算法本身更常考；无向图的桥（low[v]>dfn[u]）是高频变体（见双连通专题）。
