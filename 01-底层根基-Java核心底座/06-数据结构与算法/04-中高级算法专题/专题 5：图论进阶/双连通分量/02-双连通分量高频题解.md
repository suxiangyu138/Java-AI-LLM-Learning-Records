## 1. 1192. 网络中的关键连接（桥）

### 1.1 题目与思路

```
无向图所有桥（关键连接 = 删除后分裂的边）
Tarjan 桥判定：low[v] > dfn[u]
⚠️ 完整推导见强连通/02 与 01 模块 2 节，此处给最终实现
```

### 1.2 完整代码

```java
/**
 * LeetCode 1192. 网络中的关键连接
 */
class Solution {
    private int[] dfn, low;
    private int timer = 0;
    private List<List<Integer>> bridges = new ArrayList<>();

    public List<List<Integer>> criticalConnections(int n, List<List<Integer>> connections) {
        List<Integer>[] graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (var e : connections) {
            graph[e.get(0)].add(e.get(1));
            graph[e.get(1)].add(e.get(0));
        }

        dfn = new int[n];
        low = new int[n];
        dfs(0, -1, graph);
        return bridges;
    }

    private void dfs(int u, int parent, List<Integer>[] graph) {
        dfn[u] = low[u] = ++timer;
        for (int v : graph[u]) {
            if (v == parent) continue;          // ⚠️ 无向图跳过父边
            if (dfn[v] == 0) {
                dfs(v, u, graph);
                low[u] = Math.min(low[u], low[v]);
                if (low[v] > dfn[u]) {          // ⚠️ 桥判定（严格 >）
                    bridges.add(List.of(u, v));
                }
            } else {
                low[u] = Math.min(low[u], dfn[v]);   // 回边
            }
        }
    }
}
// 推演 图：0-1, 1-2, 2-0, 1-3, 3-4
//   0-1-2 构成环 → low 回退 → 0-1、1-2 非桥
//   1-3-4：low[3]=dfn[3] > dfn[1] → 桥 (1,3)
//   3-4：low[4]=dfn[4] > dfn[3] → 桥 (3,4)
//   结果 [(1,3),(3,4)] ✓
// ⚠️ 复杂度：O(V+E)
// ⚠️ 面试必答："1192 = 桥的模板题——
//   无向图跳过父边 + low[v] > dfn[u] 判定。"
```

## 2. 割点求解（完整实现）

### 2.1 题目与思路

```
求无向图所有割点（删除后图分裂的节点）
判定：非根 low[v] >= dfn[u]；根 children >= 2
⚠️ 面试经典手撕题（01 模块 2 节）
```

### 2.2 完整代码

```java
/**
 * 求无向图所有割点
 */
class CutVertexFinder {
    private int[] dfn, low;
    private boolean[] isCut;
    private int timer = 0;

    List<Integer> findCutVertices(int n, List<List<Integer>> edges) {
        List<Integer>[] graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (var e : edges) {
            graph[e.get(0)].add(e.get(1));
            graph[e.get(1)].add(e.get(0));
        }

        dfn = new int[n];
        low = new int[n];
        isCut = new boolean[n];
        for (int i = 0; i < n; i++)            // ⚠️ 图可能不连通
            if (dfn[i] == 0) dfs(i, -1, graph);

        List<Integer> result = new ArrayList<>();
        for (int i = 0; i < n; i++) if (isCut[i]) result.add(i);
        return result;
    }

    private void dfs(int u, int parent, List<Integer>[] graph) {
        dfn[u] = low[u] = ++timer;
        int children = 0;
        for (int v : graph[u]) {
            if (v == parent) continue;
            if (dfn[v] == 0) {
                children++;
                dfs(v, u, graph);
                low[u] = Math.min(low[u], low[v]);
                // ⚠️ 非根割点判定
                if (parent != -1 && low[v] >= dfn[u]) isCut[u] = true;
            } else {
                low[u] = Math.min(low[u], dfn[v]);
            }
        }
        // ⚠️ 根特判：≥ 2 个子节点
        if (parent == -1 && children >= 2) isCut[u] = true;
    }
}
// 推演 图：0-1-2-0（三角）+ 0-3
//   0 是根：children = 2（1 和 3）→ 割点 ✓
//   1、2：low 能回退到 0（环）→ 非割点
//   3：low[3]=dfn[3] >= dfn[0] → 0 是割点（已判）；3 本身非根无子 → 非
//   结果 [0] ✓（删 0 后 {1,2} 与 {3} 分离）
// ⚠️ 面试必答："割点与桥只有两处差异——
//   判定 ≥ vs >、根特判（children ≥ 2）。"
```

## 3. 1568. 使陆地分离的最少天数

### 3.1 题目与思路

```
网格岛屿，每天可把一块陆地变水，最少几天使岛屿分离
洞察（分类讨论）：
  ① 已分离（≥2 个岛或 0 个）→ 0 天
  ② 存在"桥格/割点格"（去掉后分离）→ 1 天
  ③ 否则 → 2 天（角落格去掉必分离）
⚠️ 答案只有 0/1/2！关键在于判断"是否存在割点格"
```

### 3.2 完整代码

```java
/**
 * LeetCode 1568. 使陆地分离的最少天数
 * ⚠️ 洞察：答案 ∈ {0, 1, 2}
 *   0：已分离；1：有割点（桥格）；2：否则
 */
public int minDays(int[][] grid) {
    int m = grid.length, n = grid[0].length;

    // ① 统计岛屿数
    int islands = countIslands(grid);
    if (islands != 1) return 0;                // ⚠️ 已分离/无岛

    // ② 尝试去掉每个陆地 → 是否分离
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (grid[i][j] == 1) {
                grid[i][j] = 0;                // 模拟去掉
                if (countIslands(grid) != 1) {
                    grid[i][j] = 1;            // 还原
                    return 1;                  // ⚠️ 存在"桥格" → 1 天
                }
                grid[i][j] = 1;
            }
        }
    }
    return 2;                                  // ⚠️ 没有桥格 → 2 天
}

private int countIslands(int[][] grid) {
    int m = grid.length, n = grid[0].length;
    boolean[][] visited = new boolean[m][n];
    int count = 0;
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            if (grid[i][j] == 1 && !visited[i][j]) {
                count++;
                dfs(grid, i, j, visited);
            }
    return count;
}
// ⚠️ 为什么 2 天一定够：
//   任意"角落"陆地（角或边）去掉后
//   剩余仍连通？——取一个边界格子：
//   去掉它 + 再去掉相邻格子 → 必分离
//   （最坏情况：单个陆地 → 0/2 天）
// ⚠️ 复杂度：O(m²n²)（每格试一次 × 全图统计）——m,n ≤ 30 可行
// ⚠️ 面试必答："1568 = 分类讨论——
//   答案只有 0/1/2：已分离 0、
//   有'桥格'（模拟去掉即分离）1、
//   否则 2（角落两刀必分离）。"
```

## 4. 685. 冗余连接 II

### 4.1 题目与思路

```
有向图加一条边成环，删除一条边使其成为有根树
两种错误类型：
  ① 有节点入度 2（两个父节点）→ 删其中一条
  ② 有环（无入度 2）→ 删环上的边
⚠️ 并查集检测（不是 Tarjan——本题是"删边成树"）
```

### 4.2 完整代码

```java
/**
 * LeetCode 685. 冗余连接 II（并查集）
 */
public int[] findRedundantDirectedConnection(int[][] edges) {
    int n = edges.length;
    int[] parent = new int[n + 1];             // 节点 → 父节点
    int[] uf = new int[n + 1];
    for (int i = 1; i <= n; i++) uf[i] = i;

    int[] candidateA = null, candidateB = null;

    // ① 找入度 2 的节点（两个候选边）
    for (int[] e : edges) {
        if (parent[e[1]] != 0) {               // ⚠️ 已有父节点 → 入度 2
            candidateA = new int[]{parent[e[1]], e[1]};  // 先来的边
            candidateB = e;                    // 后到的边
        } else {
            parent[e[1]] = e[0];
        }
    }

    // ② 并查集检测环（跳过候选 B）
    for (int[] e : edges) {
        if (candidateB != null && e == candidateB) continue;   // ⚠️ 暂不连 B
        int ra = find(uf, e[0]), rb = find(uf, e[1]);
        if (ra == rb) {                        // 成环
            // 有入度 2 → 环在 A 侧 → 删 A；否则删当前边
            return candidateB == null ? e : candidateA;
        }
        uf[ra] = rb;
    }
    return candidateB;                         // 无环 → 删后到边
}

private int find(int[] uf, int x) {
    while (uf[x] != x) {
        uf[x] = uf[uf[x]];                     // 路径压缩
        x = uf[x];
    }
    return x;
}
// 推演 edges=[[1,2],[1,3],[2,3]]：
//   ② 检测：1-2、1-3 连接；2-3：find(2)==find(3) → 环
//   无入度 2 → 删 [2,3] ✓
// 推演 edges=[[1,2],[2,3],[3,4],[4,1],[1,5]]：
//   ⚠️ 入度 2：节点 1（2→1 和 4→1）→ A=[2,1], B=[4,1]
//   跳过 B 检测环：2-3,3-4,4-1... 成环 → 删 A=[2,1] ✓
// ⚠️ 面试必答："685 是'删边成树'→ 并查集；
//   两个候选：入度 2 的先来边 A、后到边 B——
//   跳过 B 检测环，成环删 A，否则删 B。"
```

## 5. 双连通方法论总结

### 5.1 解题框架

```
① 识别：关键边/关键点/删边分离 → 双连通
② 定工具：
   桥 → low[v] > dfn[u]（1192）
   割点 → low[v] >= dfn[u] + 根特判
   删边成树 → 并查集（685）
   网格分离 → 分类讨论（1568）
③ 边界：不连通图、根特判、父边跳过
④ 复杂度：O(V+E)（Tarjan）或 O(n²)（枚举模拟）

⚠️ 识别信号：
  "关键连接/关键节点" → 桥/割点
  "删除使分离" → 桥/割点/枚举
  "冗余边成树" → 并查集
```

### 5.2 模板速查表

| 题型 | 工具 | 代表题 |
|------|------|--------|
| 关键边 | Tarjan 桥（>） | 1192 |
| 关键点 | Tarjan 割点（≥+根） | 割点题 |
| 最少天数 | 分类讨论（0/1/2） | 1568 |
| 冗余边 | 并查集 | 685 |
| 边双缩点 | 桥标记 + DFS | 加边去桥 |

### 5.3 自测清单

```
□ 无向图跳过父边？
□ 桥用 >（严格）？
□ 割点根特判（children ≥ 2）？
□ 图不连通（外层循环）？
□ 并查集路径压缩？
□ 枚举模拟还原现场？
□ 复杂度表述？
```

> 🎯 **核心要点**：双连通题 = **工具识别**（桥/割点/并查集/分类讨论）+ **判定式**（>/≥/根特判）+ **边界**（不连通/父边）。四题覆盖全部形态：桥（1192）、割点（手撕）、分类（1568）、并查集（685）——"先问删什么，再选工具"。
