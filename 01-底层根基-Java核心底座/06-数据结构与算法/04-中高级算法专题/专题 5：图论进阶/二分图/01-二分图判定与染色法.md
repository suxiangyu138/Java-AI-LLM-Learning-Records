## 1. 二分图定义与判定定理

```text
二分图: 顶点集可分 U、V 两组——
  每条边都连接 U 与 V 之间（组内无边）

典型二分图: 树、偶环、棋盘网格、二分网络

判定定理: 图是二分图 ⇔ 无奇环 ⇔ 可二染色
  奇环: 奇数长度的环（三角形、五边形…）
  偶环: 可以染色（红蓝交替一圈正好两种色）

⚠️ 为什么奇环不行:
  环上交替染色——奇数个点绕一圈
  最后一个点与起点同色（相邻却同色）→ 冲突

⚠️ 判定方法: 染色法——
  两色交替染、发现冲突 → 有奇环 → 非二分图
```

> 🎯 **核心认知**："**'无奇环 ⇔ 可二染色'是二分图的判定定理——染色法就是它的构造性验证**。理解'奇环为何冲突'（绕一圈颜色错位），判定逻辑就通了。"

## 2. 染色法模型：两色交替

### 2.1 规则

```text
规则: 相邻节点颜色必须不同（两色 0/1 或 1/2）

流程:
  ① 从未染色节点开始（非连通图: 每个分量都要）
  ② 起点染 1
  ③ 邻居染 2 → 邻居的邻居染 1 → 交替
  ④ 冲突: 某节点已染色但与当前要求不同 → 非二分图

⚠️ 冲突的判定:
  遍历邻居时——若已染色且 == 当前色 → 冲突（奇环！）
  若未染色 → 染相反色继续

记忆: "邻点异色、同色即冲突"
```

### 2.2 为什么遍历所有节点

```text
非连通图: 一个分量的染色不影响其他分量——
  必须从每个未染色的节点启动（外层循环）
  漏一个分量 = 漏判一个奇环

⚠️ 面试必答:
  "非连通图每个连通分量独立染色——
   外层循环遍历所有节点，未染色则启动新一轮 BFS/DFS"
```

> 🎯 **染色法的本质**："**'相邻异色、同色冲突'——两色交替给每个连通分量"盖章"**。非连通 = 多轮盖章，漏一轮就漏判。"

## 3. BFS 染色模板

### 3.1 完整实现

```java
/**
 * 二分图判定（BFS 染色法）
 * 时间 O(V+E)，空间 O(V)
 */
public boolean isBipartite(int[][] graph) {        // 邻接表
    int n = graph.length;
    int[] color = new int[n];                      // ① 0 未染 / 1 / 2

    for (int start = 0; start < n; start++) {      // ② ⚠️ 遍历所有（非连通）
        if (color[start] != 0) continue;
        color[start] = 1;                          // ③ 起点染 1

        Queue<Integer> queue = new LinkedList<>();
        queue.offer(start);
        while (!queue.isEmpty()) {
            int cur = queue.poll();
            for (int next : graph[cur]) {
                if (color[next] == 0) {            // ④ 未染 → 染相反色
                    color[next] = 3 - color[cur];  //    1 ↔ 2
                    queue.offer(next);
                } else if (color[next] == color[cur]) {
                    return false;                  // ⑤ ⚠️ 同色 → 冲突（奇环）
                }
            }
        }
    }
    return true;
}
// 推演 graph=[[1,3],[0,2],[1,3],[0,2]]（偶环 4 点）：
//   0 染 1 → 1,3 染 2 → 2 染 1 → 无冲突 → true ✓
// 推演 [[1,2,3],[0,2],[0,1,3],[0,2]]（含三角形）：
//   1 染 2 后，0 的邻居 2 染 1、3 染 2……
//   到节点 2: 邻居 1 已染 2 == 当前 2？→ 冲突 → false ✓
// ⚠️ 3−color 技巧: 1↔2 互相切换（color = 3 − color）
```

> 🎯 **BFS 模板要点**："**'外层遍历所有节点 + 内层 BFS 染色 + 同色判冲突'——三件套完整覆盖非连通图**。`3 − color` 一行完成两色切换，是模板的简洁点。"

## 4. DFS 染色与推演

### 4.1 DFS 版（递归）

```java
/**
 * 二分图判定（DFS 染色法）——递归版
 */
public boolean isBipartiteDFS(int[][] graph) {
    int n = graph.length;
    int[] color = new int[n];

    for (int i = 0; i < n; i++) {                  // ① 外层: 非连通处理
        if (color[i] == 0 && !dfs(graph, i, 1, color)) {
            return false;
        }
    }
    return true;
}

private boolean dfs(int[][] graph, int node, int c, int[] color) {
    color[node] = c;                               // ② 染色
    for (int next : graph[node]) {
        if (color[next] == c) return false;        // ③ 冲突（同色）
        if (color[next] == 0 && !dfs(graph, next, 3 - c, color)) {
            return false;                          // ④ 未染 → 反色递归
        }
    }
    return true;
}
// 推演 星形图 [[1,2],[0],[0]] → true ✓（两色交替）
//   [[1],[0,2],[1,3],[2]] 奇数环（3 点）→ 冲突 false ✓
// ⚠️ BFS vs DFS: 结果等价——DFS 代码更短、BFS 免栈溢出
//   面试: BFS 更稳（大图无递归风险）；DFS 展示递归理解
```

> 💡 **BFS vs DFS**："**染色法 BFS/DFS 等价——BFS 免递归栈溢出（工程稳）、DFS 代码更短**。面试先给 BFS 保底、追问再给 DFS 版，双解展示。"

## 5. 非连通图与冲突检测

### 5.1 经典应用：P1330 封锁阳光大学

```java
/**
 * Luogu P1330 封锁阳光大学（染色法应用）
 * 每条边两端至少一个被封锁（河蟹）——最小点覆盖的染色版
 * 思路: 染色后取"每分量较小色数"之和
 */
// ① 染色判定（同模板）——非二分图 → 无解（Impossible）
// ② 每个连通分量: 颜色 1 的节点数 vs 颜色 2 的节点数
//   取较小者（选较少的色组封锁）
// ③ 总和 = 最少河蟹数

// 推演 链 0-1-2: 染 [1,2,1] → 选色 2 的节点（1 个）→ 1 ✓
// ⚠️ 应用识别: "每条边至少一端被选" = 点覆盖——
//   染色分量内取较小色组 = 贪心最小覆盖（二分图性质）
```

### 5.2 P1525 关押罪犯（二分 + 染色）

```java
/**
 * Luogu P1525 关押罪犯
 * 二分答案 + 染色判定: 最小化最大怨气值
 */
// ① 二分 mid（最大怨气值）
// ② 建图: 怨气 > mid 的罪犯对连边（必须分开关）
// ③ 染色判定: 图是二分图 → mid 可行（能分两监狱）
// ④ 二分找最小可行 mid

```

> 🎯 **染色法的应用模式**："**'分组冲突'问题 = 染色判定；'最小化最大冲突' = 二分 + 染色**——P1330 与 P1525 是两大经典。识别'冲突配对'信号就能建模成染色题。"

## 6. 识别信号与易错点

### 6.1 识别信号

```text
"分组/染色/冲突 + 相邻不兼容" → 染色判定
"奇环/可二染色" → 染色法
"最小化最大冲突" → 二分 + 染色
"棋盘/网格/行列配对" → 二分图建模（棋盘天然二分）

⚠️ 面试定位: 染色法是二分图入门——
  785 判断二分图是 LeetCode 高频题
```

### 6.2 易错点

| # | 易错点 | 正确写法 | 后果 |
|:---:|------|------|------|
| 1 | 忘外层遍历 | 每个未染节点启动 | 非连通漏判 |
| 2 | 冲突判定条件反 | `== color[cur]` 才冲突 | 误判/漏判 |
| 3 | 染色用 1/2 但切换错 | `3 − color` | 同色相邻 |
| 4 | 已染节点跳过 | 已染且异色 → 继续 | 漏冲突检测 |
| 5 | 空图/单点 | 直接 true | 特判漏 |
| 6 | DFS 深图栈溢出 | 用 BFS | 栈溢出 |
| 7 | 二分+染色边界 | 二分答案正确性 | mid 判定错 |

> 🎯 **核心要点**：染色法通关四件事——**① 判定定理**（无奇环 ⇔ 可二染色）；**② 模板三件套**（外层遍历/交替染色/同色冲突）；**③ BFS/DFS 双解**；**④ 应用模式**（分组冲突/二分+染色）。**'邻点异色、同色即冲突'——染色法就是二分图判定的十行模板**。
