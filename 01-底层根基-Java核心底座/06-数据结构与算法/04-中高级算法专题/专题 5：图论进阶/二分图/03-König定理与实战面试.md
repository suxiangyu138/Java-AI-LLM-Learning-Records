## 1. König 定理：最小点覆盖 = 最大匹配

### 1.1 定理内容

```text
König 定理（1931）: 二分图中——
  最小点覆盖数 = 最大匹配数

最小点覆盖: 选最少的点，使每条边至少一个端点被选
  （监控问题: 路口装摄像头覆盖所有路段）

为什么成立（直觉）:
  ① 最大匹配的每条边需要至少一个点覆盖 → 覆盖 ≥ 匹配
  ② 二分图性质保证能构造出"恰好覆盖匹配边"的点集 → 覆盖 ≤ 匹配
  → 相等 ✓

⚠️ 适用范围: 只对二分图成立——
  一般图的最小点覆盖是 NP 难问题！

⚠️ 构造方法（最大匹配 M 基础上）:
  ① 从左侧未匹配点出发，沿"非匹配边 → 匹配边"交替 DFS
  ② 标记可达点
  ③ 最小覆盖 = 左侧未标记 ∪ 右侧已标记（大小 = |M|）
```

> 🎯 **König 定理的价值**："**'最小点覆盖 = 最大匹配'把 NP 难的覆盖问题变成匹配问题——二分图专属的 min-max 定理**。监控/覆盖/封锁类问题，建模二分图后直接套匈牙利。"

## 2. 三大衍生结论

### 2.1 定理三连

```text
① 最小点覆盖 = 最大匹配（König 定理）
② 最大独立集 = 总点数 − 最小点覆盖 = 总点数 − 最大匹配
   独立集: 互不相邻的最大点集
   证明: I 是独立集 ⟺ V−I 是点覆盖（补集关系）
③ DAG 最小路径覆盖 = 顶点数 − 最大匹配
   拆点: 每个点拆成"出点/入点"建二分图
   路径覆盖: 最少的路径覆盖所有点

⚠️ 应用识别:
  "选最少的点覆盖所有边" → ① 最小点覆盖
  "选最多的点互不连接" → ② 最大独立集
  "最少路径覆盖所有点" → ③ 路径覆盖
```

### 2.2 记忆口诀

```text
"覆盖 = 匹配、独立 = 总 − 匹配、路径 = 顶点 − 匹配"
  ——三个公式只差一个"减"字，全部源自 König

⚠️ 面试必答:
  "König 定理三推论——最小点覆盖 = 最大匹配、
   最大独立集 = 总点 − 最大匹配、
   DAG 路径覆盖 = 顶点 − 最大匹配，
   全部 O(VE)（匈牙利算匹配后 O(1) 套公式）"
```

> 🎯 **定理三连的复用**："**'覆盖/独立/路径'三个看似不同的问题，全部归约到'最大匹配'一个算法**。识别问题类型 → 套公式——这就是二分图建模的最高效路径。"

## 3. POJ 3041 小行星（行列建模经典）

### 3.1 题目与思路

**题**：网格有 K 个小行星，一次可清除一行或一列，求最少次数。

**行列建模**：行 = 左点、列 = 右点、小行星 = 边——**最少清除 = 最小点覆盖**：

```java
/**
 * POJ 3041 Asteroids（行列建模 + König）
 * 行 → 左点、列 → 右点、小行星 (r,c) → 边 r-c
 * 最少清除次数 = 最小点覆盖 = 最大匹配
 */
public int minimumShots(int[][] asteroids, int rows, int cols) {
    Hungarian hungarian = new Hungarian(rows, cols);
    for (int[] a : asteroids) {
        hungarian.addEdge(a[0], a[1]);           // ① 小行星 = 行-列边
    }
    return hungarian.maxMatching();              // ② König: 覆盖 = 匹配
}
// 推演 小行星 (0,0),(0,1),(1,1)：
//   行 0-列 0、行 0-列 1、行 1-列 1 → 最大匹配 2
//   清除 2 次（行 0 + 列 1）✓
// ⚠️ 建模要点: "清除一行/列" = 选一个点覆盖该行/列的所有小行星
//   = 最小点覆盖 = 最大匹配（König）
```

> 🎯 **行列建模的通用性**："**'行-列配对'建模——小行星/棋子/格子覆盖问题全部适用**。识别'一次操作清除一行/一列'信号 → 行列二分图 + König。"

 *   黑格 = 左点、白格 = 右点、相邻格 = 边

// 例: 2×3 棋盘（6 格）→ 最大匹配 3 → 3 块骨牌 ✓
// ⚠️ 识别: "棋盘/网格 + 相邻配对" → 黑白染色建二分图
//   障碍格跳过（挖掉）

 * 例: 每条街道（边）至少一端装监控（点）
 * 例: P1330 封锁阳光大学（河蟹封锁边）
 */
// ① 染色判定: 非二分图 → 无解（P1330 输出 Impossible）
// ② 每个分量取较小色组 → 最少封锁

## 5. KM 最大权匹配（竞赛）

### 5.1 概念

```text
KM 算法（Kuhn-Munkres）: 二分图最大权匹配——
  边有权值，求总权值最大的匹配（可完美匹配场景）

核心: 顶标 + 相等子图——
  ① 给每个节点可行顶标 l(i)（满足 w(u,v) ≤ l(u)+l(v)）
  ② 相等子图: 只保留 w(u,v) == l(u)+l(v) 的边
  ③ 在相等子图上找完美匹配——找到即最大权完美匹配
  ④ 未找到 → 调整顶标（左点减 d、右点加 d）→ 引入新相等边

复杂度: O(n³)（稠密图）；稀疏图可用网络流

⚠️ 面试定位: 竞赛内容——
  "最大权匹配用 KM（O(n³) 顶标法）"提及即可
  手撕优先级低于匈牙利
```

> 🎯 **KM 的定位**："**'顶标 + 相等子图'——最大权匹配的竞赛标配（O(n³)）**。面试提'KM 解决最大权匹配'即可；主战场仍是匈牙利 + König 三连。"
