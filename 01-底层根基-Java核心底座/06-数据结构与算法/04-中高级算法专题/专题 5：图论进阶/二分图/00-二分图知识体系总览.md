## 1. 知识体系导图

```text
二分图（Bipartite Graph）
│
├── 核心本质 ──────────────────────────────────────────────
│   ├── = 顶点可分 U/V 两组，边只跨组（组内无边）
│   ├── 判定定理: 无奇环 ⇔ 可二染色 ⇔ 二分图
│   ├── 典型: 树、偶环、棋盘网格
│   └── 建模: "冲突/配对"问题 → 二分图
│
├── 判定：染色法 ─────────────────────────────────────────
│   ├── 两色交替染色（BFS/DFS）
│   ├── 冲突（邻点同色）→ 有奇环 → 非二分图
│   ├── 非连通图: 每个连通分量独立判定
│   └── 应用: 关押罪犯（二分+染色）、分组冲突
│
├── 最大匹配：匈牙利算法 ─────────────────────────────────
│   ├── 匹配: 无公共端点的边集
│   ├── 增广路: 首尾未匹配的交错路 → 翻转 +1
│   ├── 匈牙利: 每个左点找增广路 O(VE)
│   └── HK 优化: O(√V·E)（竞赛）
│
├── König 定理与衍生 ────────────────────────────────────
│   ├── 最小点覆盖 = 最大匹配（König 定理）
│   ├── 最大独立集 = 总点数 − 最大匹配
│   ├── DAG 最小路径覆盖 = 顶点数 − 最大匹配
│   └── 最大权匹配: KM 算法（顶标 + 相等子图）
│
├── 经典应用 ─────────────────────────────────────────────
│   ├── 行列建模: POJ 3041 小行星（行/列为点）
│   ├── 二分答案 + 染色: P1525 关押罪犯
│   ├── 棋盘覆盖: 骨牌/格子染色成二分图
│   └── 监控覆盖: 最小点覆盖（König）
│
└── 实战与面试 ───────────────────────────────────────────
    ├── 手写: 染色法（2 分钟）+ 匈牙利（5 分钟）
    ├── 复杂度: 染色 O(V+E)、匈牙利 O(VE)
    ├── 定理: König 三连（覆盖/独立集/路径覆盖）
    └── 话术: "建模 → 选算法 → 套定理"三段式
```

## 4. 核心概念速查

| 概念 | 一句话解释 | 说明 |
|------|-----------|------|
| **二分图** | 顶点分 U/V、边只跨组 | 组内无边 |
| **奇环** | 奇数长度的环 | 有奇环 ⇔ 非二分图 |
| **染色法** | 两色交替，冲突即非二分 | 判定标准（BFS/DFS） |
| **匹配** | 无公共端点的边集 | 最大匹配 = 边数最多 |
| **增广路** | 首尾未匹配的交错路 | 翻转后匹配 +1 |
| **匈牙利算法** | 每个左点找增广路 | O(VE) |
| **König 定理** | 最小点覆盖 = 最大匹配 | 二分图 min-max |
| **最大独立集** | 互不相邻的最大点集 | = 总点 − 最大匹配 |
| **路径覆盖** | DAG 最小路径覆盖 | = 顶点 − 最大匹配 |
| **KM 算法** | 最大权匹配 | 顶标 + 相等子图 O(n³) |

## 5. 定理速查表

| 定理 | 公式 | 应用 |
|------|:---:|:---:|
| 判定定理 | 无奇环 ⇔ 可二染色 | 染色法判定 |
| **König 定理** | **最小点覆盖 = 最大匹配** | 监控/覆盖问题 |
| 独立集 | 最大独立集 = 总点数 − 最大匹配 | 互不攻击布局 |
| 路径覆盖 | 最小路径覆盖 = 顶点数 − 最大匹配 | DAG 调度 |
| 网络流 | 最大匹配 = 最大流（容量 1） | 二分图网络流 |

> 🎯 **一句话定位**："**二分图 = '冲突与配对问题的统一框架'——染色判定、匈牙利匹配、König 定理三件套**。'建模成二分图'是 90% 题目的第一步，'套定理'是最后一步。"

## 6. 常见误区速查

| 误区 | 正解 |
|------|------|
| "染色法只判连通图" | ❌ 非连通图每个分量独立判定——遍历所有未染色点 |
| "有环就不是二分图" | ❌ 偶环是二分图（如矩形网格）——只有**奇环**不是 |
| "最大匹配 = 完美匹配" | ❌ 完美匹配要求全覆盖；最大匹配是边数最多 |
| "König 定理适用于所有图" | ❌ 只适用于二分图（一般图是 NP 难） |
| "最小点覆盖 = 最小顶点数" | ❌ = 最大匹配数（König）——不是随便选点 |
| "匈牙利 O(V²E)" | ❌ 邻接表 O(VE)——每个左点 DFS 一遍 |
| "二分图一定能二染色" | ❌ 是"二染色成功 ⇔ 二分图"——有奇环就失败 |
| "建模只能是 U/V 两组" | ❌ 行列建模/棋盘染色/拆点都是常见建模 |
| "最大独立集单独算" | ❌ = 总点 − 最大匹配（König 推论） |
| "KM 适合稀疏图" | ❌ KM O(n³) 适合稠密；稀疏用网络流/匈牙利 |
