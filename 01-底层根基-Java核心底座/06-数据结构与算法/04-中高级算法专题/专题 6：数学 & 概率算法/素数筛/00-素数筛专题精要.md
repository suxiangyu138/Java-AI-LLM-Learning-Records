## 1. 核心概念

### 1.1 素数三问

```text
① 判定：n 是不是素数？（单个数）
   试除法 O(√n)：只需试除到 √n
   大数（10^18）→ Miller-Rabin（随机算法专题）

② 筛选：n 以内的所有素数？（批量）
   埃氏筛 O(n log log n)
   欧拉筛（线性筛）O(n)

③ 分解：n = p₁^a₁·p₂^a₂·...？（质因数分解）
   试除分解 O(√n)
   大数分解 → Pollard-Rho（进阶）

重要结论：
  任何 n 最多有一个大于 √n 的质因子
  → 试除只需到 √n，剩余部分要么 1 要么是质数
```

### 1.2 素数分布（直觉与定理）

```text
素数定理：n 以内的素数个数 ≈ n / ln(n)
  π(10⁶) ≈ 78,498（实际 78,498，定理误差很小）
  → 素数密度 ≈ 1/ln(n)，n 大时越来越稀疏

相邻素数间隙：平均 ln(n)，最大间隙远大于平均
  （面试考点：如 LC 2523 范围内最接近的两个质数）

欧几里得证明：素数有无穷多个
  （假设有限，乘积+1 必产生新质因子 → 矛盾）
```

## 2. 三大筛法模板

### 2.1 试除法（单个数判定）

```java
/**
 * 单个数素性判定：试除到 √n
 */
public boolean isPrime(long n) {
    if (n < 2) return false;
    // ⚠️ 枚举 i*i ≤ n，用 i ≤ n/i 防 i*i 溢出
    for (long i = 2; i <= n / i; i++) {
        if (n % i == 0) return false;
    }
    return true;
}
// 复杂度 O(√n)；6k±1 优化：只试 2,3 与 6k±1 形式
```

### 2.2 埃氏筛（埃拉托斯特尼）

```java
/**
 * 埃氏筛：n 以内的素数表
 * 原理：从 2 开始，把每个素数的倍数标记为合数
 * ⚠️ 只需从 i*i 开始筛（i·k, k<i 已被更小素数筛过）
 */
public boolean[] sieveEratosthenes(int n) {
    boolean[] isComposite = new boolean[n + 1];
    for (int i = 2; i <= n / i; i++) {        // 到 √n 即可
        if (!isComposite[i]) {                // i 是素数
            for (int j = i * i; j <= n; j += i) {
                isComposite[j] = true;        // 标记合数
            }
        }
    }
    return isComposite;   // !isComposite[i] = i 是素数
}
// 复杂度 O(n log log n)，空间 O(n)
// 常数优化：j += i 用位运算，偶数单独处理可再减半
```

### 2.3 欧拉筛（线性筛，面试必背）

```java
/**
 * 欧拉筛：每个合数只被它的「最小质因子」筛掉一次 → O(n)
 * 这是与埃氏筛的本质区别（埃氏筛一个合数可能被标记多次）
 */
public int[] sieveEuler(int n) {
    boolean[] isComposite = new boolean[n + 1];
    int[] primes = new int[n + 1];            // 素数表
    int cnt = 0;
    for (int i = 2; i <= n; i++) {
        if (!isComposite[i]) primes[cnt++] = i;
        for (int j = 0; j < cnt && i * primes[j] <= n; j++) {
            isComposite[i * primes[j]] = true;
            if (i % primes[j] == 0) break;    // ⚠️ 核心！保证最小质因子
        }
    }
    return Arrays.copyOf(primes, cnt);
}
// 复杂度 O(n)——每个合数恰好被筛一次
// ⚠️ break 条件：i 是 primes[j] 的倍数时停下，
//   否则 primes[j+1] 会被更大质因子筛 → 重复标记
```

### 2.4 欧拉筛为什么是 O(n)（面试必答）

```text
关键：内层循环保证「每个合数恰好被最小质因子标记一次」

设合数 x = p · q（p = 最小质因子）：
  当外层 i = q（≥ p）时，内层扫到 primes[j] = p：
    x = q·p 被标记 ✓
  若 x 还尝试用更大质因子 q' 标记（i = p 时扫到 q'）：
    i % primes[j] = p % 2? ...
  反证：i = p 时若 primes[j] > p 且 i % primes[j] ≠ 0 继续筛，
  则 x = i·primes[j] 的最小质因子其实是 min(i 的最小质因子, primes[j]) ≤ p
  → 会被「更小质因子」在更早时刻标记 → 这里再标记就是重复
  → break 在 i % primes[j] == 0 正是「最小质因子 <= primes[j] 已处理完」

一句话：break 时机 = 最小质因子边界，保证无重复标记
```

## 3. 筛法选型

### 3.1 对比表

| 方案 | 复杂度 | 空间 | 适用 |
|------|:---:|:---:|------|
| 试除法 | O(√n) | O(1) | 单个数判定 |
| 埃氏筛 | O(n log log n) | O(n) | n ≤ 10⁷ 批量素数 |
| 欧拉筛 | O(n) | O(n) | 需要素数表/积性函数 |
| 区间筛 | O((R-L+1) log log R) | O(√R + 区间长) | 大区间小范围 [L, R] |
| Miller-Rabin | O(k log³ n) | O(1) | 大数素性判定 |
| Pollard-Rho | O(n^1/4) 期望 | O(1) | 大数分解 |

### 3.2 选择口诀

```text
单数 → 试除；小范围批量 → 埃氏；要积性函数/大素数表 → 欧拉
区间大而窄 → 区间筛；10^18 级判定 → Miller-Rabin
10^18 级分解 → Pollard-Rho；比赛默认 1e7 内 → 欧拉筛打表
```

## 4. 素数与现实世界

### 4.1 2024 新纪录：第 52 个梅森素数（最新资讯）

```text
2024-10-21 GIMPS 宣布发现已知最大素数：
  2^136279841 - 1（记作 M136279841），约 4102 万位十进制数字
  · 第 52 个梅森素数，由 Luke Durant（前 NVIDIA 员工）发现
  · 首次主要依靠 GPU 计算（数千块 GPU 的"云超级计算机"，
    分布在 17 个国家 24 个数据中心）
  · 通过卢卡斯-莱默测试（Lucas-Lehmer）验证
  · 上一个纪录：M82589933（2486 万位，2018-12）

梅森素数形式：Mₚ = 2^p - 1（p 为质数，但 p 质数 ≠ Mₚ 质数）
欧拉定理：偶完全数与梅森素数一一对应
  → 目前已知最大的偶完全数 = 2^136279840 · M136279841

面试彩蛋：提到 M52 + GPU + GIMPS 说明关注前沿
```

### 4.2 素数在工程中的应用

```text
① 哈希表容量：取素数减少冲突（经典：容量 = 2^p 附近素数）
② 密码学：RSA 依赖大质数；Diffie-Hellman 依赖素数阶循环群
③ 随机化：哈希取模（质数模让冲突均匀）
④ 竞赛：素数表是数论题的预处理基石（质因数分解、积性函数）
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"批量筛素数用欧拉筛：每个合数被最小质因子筛一次，
 关键在 i % primes[j] == 0 时 break，
 保证复杂度严格 O(n)。
 单个数判定试除到 √n；
 大数判定用 Miller-Rabin（随机算法）。
 筛法还能顺带求欧拉函数、莫比乌斯函数（积性函数预处理）。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 埃氏筛为什么从 i² 开始？ | i·k (k<i) 已被 k 的倍数筛过，重复标记浪费 |
| 2 | 欧拉筛为什么线性？ | break 保证最小质因子唯一标记 → 无重复 |
| 3 | 试除到哪？ | √n；因为合数必有一因子 ≤ √n |
| 4 | 埃氏 vs 欧拉选哪个？ | 面试背欧拉（O(n) + 可扩展积性函数）；埃氏代码更短 |
| 5 | 区间 [L,R] 大区间怎么筛？ | 只筛 √R 内素数，再用它们标记区间内合数 |
| 6 | n ≤ 10^18 怎么判素数？ | Miller-Rabin（随机 + 快速幂）；确定性版本用已知基 |
| 7 | 筛法能顺便求什么？ | φ（欧拉函数）、μ（莫比乌斯）、约数个数/和（积性函数） |
| 8 | 素数有什么现实用途？ | 哈希、RSA、DH 密钥交换、随机数生成 |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 埃氏筛从 i 开始筛 | 大量重复标记，TLE | j = i*i 开始 |
| 欧拉筛漏 break | 重复标记 → 退化 O(n log log n) | i % primes[j] == 0 break |
| i*i ≤ n 溢出 int | 死循环/越界 | i ≤ n/i |
| 试除忘处理 n 为 1 | 1 被当素数 | n < 2 return false |
| 区间筛不筛 √R | 大质数漏判 | 先筛 [2, √R] 素数表 |
| 分解剩余 > 1 的因子 | 漏掉大质因子 | 试除完后剩 n>1 → 本身是质因子 |

> 🎯 **核心要点**：素数筛三件套 = **试除（单个）+ 埃氏/欧拉（批量）+ 区间筛（大区间）**。面试唯一必背是欧拉筛及其 break 证明；大数场景（Miller-Rabin/Pollard-Rho）在「随机算法」专题展开。前沿话题：2024 年 M52 梅森素数 = 4102 万位，GPU 发现——面试彩蛋。
