## 1. 欧拉筛的深入原理

### 1.1 为什么埃氏筛不是线性的

```text
埃氏筛流程：每个素数 p 标记 p², p²+p, ...
合数 30 = 2·3·5 会被标记几次？
  素数 2 标记（30 是 2 的倍数）
  素数 3 标记（30 是 3 的倍数）
  素数 5 标记（30 是 5 的倍数）
→ 标记次数 = 不同质因子个数 → 合计 O(n log log n)

欧拉筛目标：每个合数只被「最小质因子」标记一次
  30 只被 (2, 15) 标记：外循环 i=15 时 primes[j]=2 → 30
  → 标记总次数 = 合数个数 = O(n)
```

### 1.2 break 条件的严格论证

```text
内层循环：
  for j = 0..cnt-1，标记 i·primes[j]，当 i % primes[j] == 0 时 break

要证：合数 x 恰被标记一次，且时机为「i = x / p_min」

设 x 的最小质因子 = p（p = primes[j₀]），x = p·q，q ≥ p：
  ① 存在性：外层 i = q 时，j < j₀ 的 primes[j] 不整除 q
     （若 primes[j] | q 则 primes[j] < p 是 x 的更小质因子，矛盾）
     → 内层顺利扫到 j₀，标记 x = q·p ✓
  ② 唯一性：若外层 i 使 x = i·primes[j']，且 primes[j'] > p，
     则 i = x/primes[j'] < x/p = q，i 含质因子 p
     → 当内层扫到 primes[j] = p（p ≤ primes[j']）时，
       i % p == 0 → break → 永远不会扫到 primes[j'] 
     → 不可能用非最小质因子标记 x ✓

结论：break 恰好切断「非最小质因子」的标记路径 → 线性
```

### 1.3 欧拉筛与埃氏筛性能实测（直觉）

```text
n = 10⁷：
  埃氏筛 ≈ 0.3s（常数小，双循环简单）
  欧拉筛 ≈ 0.4s（多一次数组写入）
  → 复杂度差距（log log n ≈ 3）被常数抵消
  → 竞赛中 n ≤ 10⁷ 两者皆可，欧拉筛的不可替代性在「积性函数」

⚠️ 面试回答不要只说"欧拉筛更快"——
  正确说法："欧拉筛严格 O(n) 且能顺带求积性函数，
  但纯筛素数时两者常数接近，选欧拉筛是写题习惯与扩展性。"
```

## 2. 线性筛扩展：积性函数预处理

### 2.1 积性函数概念

```text
积性函数 f：f(ab) = f(a)·f(b)（gcd(a,b) = 1 时）
完全积性：任意 a, b 都成立

常见积性函数：
  φ(n) 欧拉函数        —— 与 n 互质数个数
  μ(n) 莫比乌斯函数     —— 平方因子处理
  d(n) 约数个数         —— σ₀
  σ(n) 约数和           —— σ₁
  e(n), I(n), id(n)     —— 单位/常/幂函数

线性筛能求积性函数的原因：
  每个合数被「最小质因子 × 系数」唯一标记一次
  → 标记时根据 f(最小质因子) 与 f(系数) 的互质关系递推 f(合数)
```

### 2.2 线性筛求欧拉函数 φ

```java
/**
 * 线性筛同时求素数表 + 欧拉函数 φ[1..n]
 * φ 的递推（p = primes[j] 为最小质因子）：
 *   i % p == 0 → i 含因子 p：φ(i·p) = φ(i) · p
 *   i % p != 0 → 互质：φ(i·p) = φ(i) · (p-1)
 */
public long[] linearSievePhi(int n) {
    boolean[] isComposite = new boolean[n + 1];
    int[] primes = new int[n + 1];
    long[] phi = new long[n + 1];
    phi[1] = 1;
    int cnt = 0;
    for (int i = 2; i <= n; i++) {
        if (!isComposite[i]) {
            primes[cnt++] = i;
            phi[i] = i - 1;               // 素数 φ = p-1
        }
        for (int j = 0; j < cnt && (long) i * primes[j] <= n; j++) {
            int p = primes[j];
            isComposite[i * p] = true;
            if (i % p == 0) {
                phi[i * p] = phi[i] * p;       // i 已含 p → φ 乘 p
                break;                         // ⚠️ 仍要 break
            } else {
                phi[i * p] = phi[i] * (p - 1); // 互质 → φ 乘 p-1
            }
        }
    }
    return phi;
}
// 为什么 φ(i·p) = φ(i)·p（i 含 p）？
//   φ 公式：φ = n·Π(1-1/pᵢ)。i·p 相比 i 只多了 p 的幂次，
//   因子公式中 p 项的 (1-1/p) 不变 → φ 按 p 倍增长
```

### 2.3 线性筛求莫比乌斯函数 μ 与约数个数 d

```java
/**
 * 线性筛求 μ（莫比乌斯）+ d（约数个数）
 * μ 定义：含平方因子 → 0；k 个不同质因子 → (-1)^k
 * d 定义：n = Π pᵢ^aᵢ → d(n) = Π (aᵢ+1)
 */
public void linearSieveMuD(int n) {
    boolean[] isComposite = new boolean[n + 1];
    int[] primes = new int[n + 1];
    int[] mu = new int[n + 1];
    int[] d = new int[n + 1];
    int[] minExp = new int[n + 1];        // 最小质因子的指数
    mu[1] = 1; d[1] = 1;
    int cnt = 0;

    for (int i = 2; i <= n; i++) {
        if (!isComposite[i]) {
            primes[cnt++] = i;
            mu[i] = -1;                   // 一个质因子 → (-1)^1
            d[i] = 2;                     // 1 和自身
            minExp[i] = 1;
        }
        for (int j = 0; j < cnt && (long) i * primes[j] <= n; j++) {
            int p = primes[j];
            int x = i * p;
            isComposite[x] = true;
            if (i % p == 0) {
                // i 含因子 p：x 的最小质因子指数 = minExp[i] + 1
                mu[x] = 0;                            // 含平方因子
                d[x] = d[i] / (minExp[i] + 1) * (minExp[i] + 2);
                minExp[x] = minExp[i] + 1;
                break;
            } else {
                mu[x] = -mu[i];                       // 新质因子 → 翻号
                d[x] = d[i] * 2;                      // 互质 → 约数相乘
                minExp[x] = 1;
            }
        }
    }
}
// 应用：莫比乌斯反演（竞赛级）、约数相关计数题
```

### 2.4 积性函数预处理速查表

| 函数 | i % p == 0 时 | i % p != 0 时 |
|------|------|------|
| φ | φ(i)·p | φ(i)·(p-1) |
| μ | 0 | -μ(i) |
| d（约数个数） | d(i)/(e+1)·(e+2) | d(i)·2 |
| σ（约数和） | σ(i)·(1+p^e+1) / (1+...+p^e) | σ(i)·(1+p) |
| gcd 相关 | 特判 | 相乘 |

## 3. 区间筛：大区间小范围

### 3.1 问题与思路

```text
问题：求 [L, R] 内素数个数（R - L ≤ 10⁶，但 R 可达 10^12）
直接开 R 数组 → 空间爆炸

关键：合数 n ∈ [L, R] 必有质因子 p ≤ √n ≤ √R
步骤：
  ① 筛出 [2, √R] 的素数表（欧拉筛，√R ≤ 10⁶）
  ② 用每个素数 p 标记 [L, R] 内 p 的倍数（从 max(p², ⌈L/p⌉·p) 开始）
  ③ 区间内未被标记的 = 素数
复杂度：O(√R + (R-L+1)·log log R)，空间 O(√R + 区间长)
```

### 3.2 完整模板

```java
/**
 * 区间筛：求 [L, R] 内素数个数（L, R ≤ 10^12，R-L ≤ 10^6）
 */
public int intervalSieve(long L, long R) {
    if (L < 2) L = 2;                     // 1 不算素数
    int len = (int) (R - L + 1);
    boolean[] comp = new boolean[len];    // comp[i] = L+i 是否合数

    int limit = (int) Math.sqrt(R);
    int[] primes = sieveEuler(limit);     // ① 小素数表（欧拉筛）

    for (int p : primes) {                // ② 标记区间内合数
        // 从 max(p², 第一个 ≥ L 的倍数) 开始
        long start = Math.max((long) p * p, (L + p - 1) / p * p);
        for (long x = start; x <= R; x += p) {
            comp[(int) (x - L)] = true;
        }
    }
    // ③ 统计
    int cnt = 0;
    for (int i = 0; i < len; i++) if (!comp[i]) cnt++;
    return cnt;
}
// ⚠️ (L + p - 1) / p * p：向上取整到 p 的倍数（防 start < L）
// 复杂度 O(√R log log √R + (R-L) log log R)
```

## 4. 质因数分解体系

### 4.1 试除分解（小规模，面试必写）

```java
/**
 * 质因数分解：n = p₁^a₁ · p₂^a₂ · ...
 * 返回因子列表（每项 = 质因子）
 */
public List<Long> factorize(long n) {
    List<Long> factors = new ArrayList<>();
    for (long i = 2; i <= n / i; i++) {   // ⚠️ 到 √n（n 动态缩小）
        while (n % i == 0) {              // 除尽 → i 必为质数
            factors.add(i);
            n /= i;
        }
    }
    if (n > 1) factors.add(n);            // ⚠️ 剩余大质因子
    return factors;
}
// 为什么不用判素？while 除尽保证 i 是质数：
//   若 i 是合数，其质因子已在前面的循环除尽 n，n % i ≠ 0
// 复杂度 O(√n)，n ≤ 10^12 时 10⁶ 次循环可过
```

### 4.2 Pollard-Rho（大数分解，期望 O(n^1/4)）

```text
问题：n 是 10^18 级合数，试除 O(√n) 不可行

思路（随机 + 生日悖论）：
  ① Miller-Rabin 判定 n 是否素数（是 → 结束）
  ② 随机函数 f(x) = (x² + c) mod n 产生伪随机序列
     （伪随机数 a 与随机数 b 有概率满足 gcd(|a-b|, n) > 1）
  ③ 对序列相邻差取 gcd，找到一个非平凡因子 d
  ④ 递归分解 d 与 n/d，直到全部为素数

生日悖论视角：
  随机取 ~√n 个数，两个数差与 n 有公因子的概率可观
  Pollard-Rho 把复杂度压到 O(n^1/4)（约 10⁴⁵ → 10^11 次操作）

实现要点：
  Floyd 判环（龟兔赛跑）检测序列循环
  倍增 gcd（积累若干步取一次 gcd 摊薄开销）

面试定位：说得出思想即可；现场手写是 ACM 级要求
```

### 4.3 分解方法选型

| 规模 | 方法 | 复杂度 |
|------|------|:---:|
| n ≤ 10^12 | 试除分解 | O(√n) |
| n ≤ 10^7 批量分解 | 线性筛最小质因子表（spf） | O(n) 预处理 + O(log n)/数 |
| n ≤ 10^18 | Miller-Rabin + Pollard-Rho | O(n^1/4) 期望 |
| 预处理 spf | 每个数 O(log n) 分解 | 最快批处理 |

```java
/**
 * spf（最小质因子表）：线性筛扩展，O(1) 取任意数的最小质因子
 */
public int[] spfSieve(int n) {
    int[] spf = new int[n + 1];
    List<Integer> primes = new ArrayList<>();
    for (int i = 2; i <= n; i++) {
        if (spf[i] == 0) { spf[i] = i; primes.add(i); }
        for (int p : primes) {
            if (p > spf[i] || (long) i * p > n) break;
            spf[i * p] = p;               // 最小质因子 = p
        }
    }
    return spf;   // spf[x]：x 的最小质因子；spf[x] == x → 素数
}
// 分解任意 x：不断除以 spf[x] → 每次 O(1)，总 O(log x)
// 用途：大量数快速分解、求约数个数、阶乘质因子统计
```

## 5. 筛法与分解的实战组合

### 5.1 阶乘的质因子统计（n! 中质因子 p 的个数）

```text
公式：vₚ(n!) = ⌊n/p⌋ + ⌊n/p²⌋ + ⌊n/p³⌋ + ...
  例：v₂(10!) = 5 + 2 + 1 = 8（10! 含 8 个因子 2）

应用：
  ① 求 n! 结尾 0 的个数 → min(v₂, v₅) = v₅
  ② n! 能否被 k 整除判定
  ③ exLucas 的预处理部分

实现：欧拉筛出 ≤ n 的素数 → 对每个素数套公式 → O(n/log n · log n) ≈ O(n)
```

### 5.2 约数个数与约数和（筛法版）

```java
/**
 * 批量求 1..n 的约数个数 d[i]（枚举倍数法，类埃氏）
 * 复杂度 O(n log n)，n ≤ 10⁶ 可用；要 O(n) 用积性函数线性筛
 */
public int[] divisorCount(int n) {
    int[] d = new int[n + 1];
    for (int i = 1; i <= n; i++)
        for (int j = i; j <= n; j += i)
            d[j]++;                        // i 是 j 的约数
    return d;
}
// 面试问题："1..n 约数个数之和？" → Σ⌊n/i⌋（整除分块优化）
```

### 5.3 实战例题思路

```text
① 判断 a^b 是否为完全平方数：
   a 的每个质因子指数 × b 后全为偶数 → 只需查 a 分解后指数奇偶
   → 试除分解 + 判指数

② 求 1..n 与 n 互质的数之和（φ 应用）：
   和为 n·φ(n)/2（与 n 互质的数成对出现）

③ [L, R] 区间筛 + 相邻素数最大/最小间隙：
   P1835 素数密度 + LC 2523 → 区间筛打底，扫相邻差
```

## 6. 本章小结

```text
欧拉筛：
  每个合数被最小质因子唯一标记 → O(n)
  break 条件 = 最小质因子边界（背证明）

积性函数：
  φ/μ/d/σ 都可在线性筛内递推
  i%p==0 与互质两种情况的递推公式要记

区间筛：
  先筛 √R 小素数表 → 标记 [L, R] → 统计
  大区间窄范围的唯一方案

质因数分解：
  试除（面试必写）/ spf 表（批量）/ Pollard-Rho（大数）
  试除的 while 除尽保证"无需判素"

组合应用：
  阶乘质因子 vₚ(n!)、约数计数、平方数判定
```

> 🎯 **核心要点**：欧拉筛的 break 证明是面试唯一硬核考点；积性函数递推（φ/μ/d）是竞赛高频；区间筛和 Pollard-Rho 是"大数场景"的两把钥匙。记忆链：**线性筛（最小质因子唯一标记）→ 积性函数（同一次遍历递推）→ 区间筛（√R 素数表标记）→ spf 表（O(log) 分解任意数）**。
