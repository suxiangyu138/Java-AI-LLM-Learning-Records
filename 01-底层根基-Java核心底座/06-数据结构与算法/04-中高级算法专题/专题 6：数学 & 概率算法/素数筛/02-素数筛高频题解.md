## 1. P3383 【模板】线性筛素数

### 1.1 题目与思路

```text
n ≤ 10^8，输出 n 以内所有素数
欧拉筛模板：每个合数被最小质因子标记一次 → O(n)
⚠️ n = 10^8 时内存 ≈ 2 个 boolean/int 数组 → 100~400MB
   实际题面 n ≤ 10^8 需内存优化（BitSet 或只存奇数）
```

### 1.2 完整代码

```java
/**
 * 洛谷 P3383 【模板】线性筛素数（欧拉筛）
 * 返回 primes 素数表
 */
public int[] sieveEuler(int n) {
    boolean[] isComposite = new boolean[n + 1];
    int[] primes = new int[n + 1];
    int cnt = 0;
    for (int i = 2; i <= n; i++) {
        if (!isComposite[i]) primes[cnt++] = i;
        for (int j = 0; j < cnt && (long) i * primes[j] <= n; j++) {
            isComposite[i * primes[j]] = true;
            if (i % primes[j] == 0) break;     // ⚠️ 最小质因子保证
        }
    }
    return Arrays.copyOf(primes, cnt);
}
// 复杂度 O(n)；⚠️ i * primes[j] 用 long 防溢出
// 面试必答："欧拉筛每个合数只被最小质因子标记一次：
//   i % primes[j] == 0 时 break 是线性的关键。"
```

## 2. P1835 素数密度（区间筛）

### 2.1 题目与思路

```text
求 [L, R] 内素数个数：R - L ≤ 10⁶，但 R ≤ 2^31
直接开 R 数组空间不够 → 区间筛
① 筛 [2, √R] 素数表（√R ≤ 46340）
② 用每个素数标记 [L, R] 内倍数
③ 统计未标记
```

### 2.2 完整代码

```java
/**
 * 洛谷 P1835 素数密度（区间筛）
 */
public int intervalSieve(long L, long R) {
    if (L < 2) L = 2;
    int len = (int) (R - L + 1);
    boolean[] comp = new boolean[len];

    int limit = (int) Math.sqrt(R);
    int[] primes = sieveEuler(limit);          // ① 小素数表

    for (int p : primes) {                     // ② 标记区间合数
        long start = Math.max((long) p * p, (L + p - 1) / p * p);
        for (long x = start; x <= R; x += p) {
            comp[(int) (x - L)] = true;
        }
    }
    int cnt = 0;                               // ③ 统计
    for (boolean b : comp) if (!b) cnt++;
    return cnt;
}
// ⚠️ start 从 max(p², 向上取整到 p 的倍数) 开始：防止重复标记与越界
// 复杂度 O(√R + (R-L) log log R)，空间 O(√R + R-L)
// 推演 L=2, R=10：√10=3 → 素数 [2,3]
//   2 标记 4,6,8,10；3 标记 9 → 未标记 2,3,5,7 → 4 个 ✓
```

## 3. 204. 计数质数（埃氏/欧拉筛）

### 3.1 题目与思路

```text
统计 < n 的素数个数（n ≤ 5×10⁶）
埃氏筛即可（常数小）；面试建议写欧拉筛展示深度
⚠️ 边界：n 以内不含 n；n ≤ 2 → 0
```

### 3.2 完整代码

```java
/**
 * LeetCode 204. 计数质数（埃氏筛版，代码最短）
 */
public int countPrimes(int n) {
    if (n <= 2) return 0;
    boolean[] isComposite = new boolean[n];
    int cnt = 0;
    for (int i = 2; i < n; i++) {
        if (!isComposite[i]) {
            cnt++;
            if ((long) i * i < n) {
                for (long j = (long) i * i; j < n; j += i) {
                    isComposite[(int) j] = true;
                }
            }
        }
    }
    return cnt;
}
// 复杂度 O(n log log n)
// 欧拉筛版本见 02 模块 1（把 n 换成 n-1 边界即可）
// 面试必答："埃氏筛从 i² 开始标记；
//   也可以现场写欧拉筛：每个合数被最小质因子筛一次，O(n)。"
```

## 4. 2523. 范围内最接近的两个质数

### 4.1 题目与思路

```text
在 [left, right] 内找差值最小的相邻质数对（不存在返回 [-1,-1]）
① 埃氏筛标记 [left, right]（区间筛思路，right ≤ 10⁶ 可直接开数组）
② 收集区间素数 → 扫相邻差取最小
⚠️ 题目保证区间内素数成对才输出；left ≤ 10⁶ 直接筛
```

### 4.2 完整代码

```java
/**
 * LeetCode 2523. 范围内最接近的两个质数
 */
public int[] closestPrimes(int left, int right) {
    boolean[] comp = new boolean[right + 1];
    // 埃氏筛到 right
    for (int i = 2; i * i <= right; i++) {
        if (!comp[i]) {
            for (int j = i * i; j <= right; j += i) comp[j] = true;
        }
    }
    List<Integer> primes = new ArrayList<>();
    for (int i = Math.max(2, left); i <= right; i++) {
        if (!comp[i]) primes.add(i);
    }
    if (primes.size() < 2) return new int[]{-1, -1};

    int best = Integer.MAX_VALUE;
    int[] ans = new int[2];
    for (int i = 1; i < primes.size(); i++) {
        int gap = primes.get(i) - primes.get(i - 1);
        if (gap < best) {                     // ⚠️ 题目要求最小差（若有相同取先出现的）
            best = gap;
            ans[0] = primes.get(i - 1);
            ans[1] = primes.get(i);
        }
    }
    return ans;
}
// 复杂度 O(right log log right)
// 面试必答："先筛后扫；最小差对 = 相邻素数差最小
//   （素数分布无规律 → 只能筛全区间后暴力扫相邻对）。"
```

## 5. P1075 质因数分解

### 5.1 题目与思路

```text
n = p·q（p ≤ q，均为质数），求 q
试除找最小质因子 p → q = n / p
⚠️ 无需筛素数表：从 2 试除，第一个整除 n 的必是质数
```

### 5.2 完整代码

```java
/**
 * 洛谷 P1075 质因数分解：n 为两质数之积，求较大者
 */
public long largestPrimeFactor(long n) {
    for (long i = 2; i <= n / i; i++) {
        if (n % i == 0) return n / i;     // 第一个整除者 = 小质因子
    }
    return n;                             // n 本身是质数（不会走到）
}
// 复杂度 O(√n)
// 面试必答："从 2 起试除，第一个整除 n 的必是最小质因子
//   （若 i 是合数，它的质因子早已除尽 n，n % i ≠ 0）；
//   于是较大质因子 = n / p。"
```

## 6. 素数筛方法论总结

### 6.1 题型识别 → 方案

| 题面信号 | 方案 | 模板位置 |
|------|------|------|
| 统计 [2, n] 素数个数 | 埃氏/欧拉筛 | 02 模块 1/3 |
| 区间 [L, R] 素数（R 巨大） | 区间筛 | 02 模块 2 |
| 单个数判定（≤ 10^12） | 试除 √n | 00 模块 2.1 |
| 单个数判定（10^18） | Miller-Rabin | 「随机算法」专题 |
| 质因数分解（≤ 10^12） | 试除分解 | 01 模块 4.1 |
| 批量分解（≤ 10^7） | spf 最小质因子表 | 01 模块 4.3 |
| 素数对差值类 | 筛 + 相邻扫描 | 02 模块 4 |
| 需要 φ/μ/d 函数表 | 线性筛积性函数 | 01 模块 2 |

### 6.2 三查口诀（写筛法时自查）

```text
一查边界：i*i ≤ n 防溢出（用 i ≤ n/i）
二查起始：埃氏从 i²、区间筛从 max(p², ⌈L/p⌉·p)
三查欧拉：break 是否在 i % primes[j] == 0
```

### 6.3 一句话考点清单

```text
试除法：i ≤ n/i，while 除尽免判素 —— 必背
埃氏筛：j = i*i 起步 —— 必背
欧拉筛：最小质因子唯一标记 + break —— 必背
区间筛：√R 素数表 + 标记 [L, R] —— 高频
spf 表：O(log n) 分解任意数 —— 进阶
梅森素数 M52：2^136279841-1，2024，GPU —— 彩蛋
```
