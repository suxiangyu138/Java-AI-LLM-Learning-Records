## 1. 核心概念

### 1.1 概率题的本质

> 概率题 = **数学推导** + **DP/模拟实现**。核心是"把随机过程的期望/概率算出来"。

```
三种题型：
  ① 期望计算：E[X] = Σ x×P(x)
  ② 概率 DP：状态转移带概率
  ③ 采样模拟：拒绝采样/水塘（见对应专题）

核心工具：
  期望线性性：E[X+Y] = E[X] + E[Y]（无需独立！）
  对称性：等价位置概率相同
  全概率公式：P(A) = Σ P(A|Bᵢ)×P(Bᵢ)
```

### 1.2 识别信号

```
"期望、概率、随机、平均需要多少步"
→ 概率题

⚠️ 概率题的两个方向：
  数学推导（规律清晰）→ 公式 O(1)
  状态转移（过程复杂）→ 概率 DP
```

### 1.3 面试定位

```
频率：中低频（大厂偶尔考）
价值：区分度题（会者不多）
准备：三大工具 + 3-5 道经典题足够
```

## 2. 完整代码模板

### 2.1 概率 DP 模板（记忆化）

```java
/**
 * 808. 分汤（概率 DP 经典）
 * A/B 两种汤各 100ml 一份，四种操作等概率
 * 求 A 先空的概率 + 0.5×同时空
 */
public double soupServings(int n) {
    // ⚠️ 剪枝：n 很大时概率趋近 1（A 先空几乎必然）
    if (n > 5000) return 1.0;

    int m = (n + 24) / 25;              // 按 25ml 一份
    double[][] memo = new double[m + 1][m + 1];
    return dfs(m, m, memo);
}

private double dfs(int a, int b, double[][] memo) {
    if (a <= 0 && b <= 0) return 0.5;   // 同时空：各半概率
    if (a <= 0) return 1.0;             // A 先空：概率 1
    if (b <= 0) return 0.0;             // B 先空：概率 0

    if (memo[a][b] > 0) return memo[a][b];

    // 四种操作等概率（各 1/4）→ 期望 = 加权平均
    memo[a][b] = 0.25 * (dfs(a - 4, b, memo)      // 操作 1
                       + dfs(a - 3, b - 1, memo)  // 操作 2
                       + dfs(a - 2, b - 2, memo)  // 操作 3
                       + dfs(a - 1, b - 3, memo));// 操作 4
    return memo[a][b];
}
// ⚠️ 剪枝依据：n 增大 → A 先空概率单调趋近 1
//   n > 5000 时误差 < 10⁻⁵ → 直接返回 1.0
```

### 2.2 概率 DP 的通用模式

```java
/**
 * 概率 DP 模板（记忆化）：
 * 状态 = 剩余局面（数量/位置/步数）
 * 转移 = Σ P(选择) × dp(下一状态)
 * 目标 = 初始状态的期望/概率
 */
double dfs(状态参数, double[][] memo) {
    if (边界条件) return 边界概率;      // ① 边界语义
    if (memo[...] > 0) return memo[...]; // ② 查缓存

    double result = 0;
    for (每种选择) {
        result += 概率 × dfs(下一状态);  // ③ 加权平均
    }
    return memo[...] = result;           // ④ 存缓存
}
// ⚠️ 与普通 DP 的区别：转移乘概率（加权）
```

### 2.3 688. 骑士在棋盘上的概率

```java
/**
 * LeetCode 688. 骑士在棋盘上的概率
 * k 步后骑士仍在棋盘上的概率
 * 8 方向走法 × 概率 DP
 */
public double knightProbability(int n, int k, int row, int column) {
    double[][] dp = new double[n][n];   // 当前步的概率分布
    dp[row][column] = 1.0;

    int[][] dirs = {{1,2},{1,-2},{-1,2},{-1,-2},
                    {2,1},{2,-1},{-2,1},{-2,-1}};   // 8 方向

    for (int step = 0; step < k; step++) {
        double[][] next = new double[n][n];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (dp[i][j] == 0) continue;
                for (int[] d : dirs) {
                    int ni = i + d[0], nj = j + d[1];
                    if (ni >= 0 && ni < n && nj >= 0 && nj < n) {
                        // ⚠️ 每步概率除以 8（等概率走法）
                        next[ni][nj] += dp[i][j] / 8.0;
                    }
                }
            }
        }
        dp = next;                       // 迭代一步
    }

    double result = 0;
    for (double[] rowArr : dp) {
        for (double p : rowArr) result += p;   // 仍在棋盘的概率和
    }
    return result;
}
// O(k×n²×8)：每步全棋盘扩散
```

## 3. 期望线性性详解

### 3.1 核心定理

```
E[X+Y] = E[X] + E[Y]（对任意随机变量成立！）
  → 不需要独立性！

威力：把复杂期望拆成简单指示变量之和
  指示变量：I = 1 如果事件发生，否则 0
  E[I] = P(事件发生)

例：n 个独立事件，每个概率 p，期望成功数
  朴素：E = Σ k×C(n,k)×p^k×(1-p)^(n-k)（复杂！）
  线性性：E = n×p（每个指示变量期望相加）
```

### 3.2 应用示例

```
例：洗牌后，期望有多少张牌在"原位"（不动点）？
  第 i 张牌在原位的概率 = 1/n
  E[不动点数] = Σ E[Iᵢ] = n × 1/n = 1

例：掷 n 次骰子，期望出现 6 的次数
  E = n × 1/6

⚠️ 面试表达：
"期望用线性性拆解：把总期望拆成
 每个指示变量的期望之和——
 第 i 个事件贡献 E[Iᵢ] = P(发生)，
 无需考虑事件之间的依赖，直接相加。"
```

### 3.3 对称性简化

```
等价位置/角色 → 概率相同
  例（1227 飞机座位）：
    第 n 个乘客坐自己座位的概率？
    对称论证：第 n 乘客要么坐自己的位（概率对称）
    → 与第 1 乘客地位等价 → 1/2（n>1）

⚠️ 对称性使用条件：
  角色完全等价（无信息差异）
  使用前验证（不是所有题都有对称性）
```

## 4. 概率 DP 的模式

### 4.1 概率 DP vs 普通 DP

| 维度 | 概率 DP | 普通 DP |
|------|:---:|:---:|
| 转移 | 加权平均（乘概率） | 取 max/min/求和 |
| 目标 | 期望/概率 | 最优值/计数 |
| 边界 | 概率语义（0/1/0.5） | 数值语义 |
| 实现 | 记忆化更自然 | 表格/滚动 |

```
⚠️ 概率 DP 的边界语义：
  "谁先耗尽"→ 1.0/0.0/0.5
  "仍在/已出"→ 1.0/0.0
  边界必须对应题目的事件定义
```

### 4.2 概率 DP 的迭代 vs 记忆化

```
记忆化（自顶向下）：
  状态稀疏时高效（808 分汤）
  边界语义直观

迭代（自底向上）：
  状态稠密时高效（688 骑士）
  步数推进自然（k 步扩散）

选型：按状态空间密度选择
  ⚠️ 面试两个都能讲 = 加分
```

### 4.3 常见概率结论

```
① 几何分布：成功概率 p → 期望次数 1/p
   （拒绝采样期望重试次数）
② 二项分布：n 次独立、概率 p → 期望 np
③ 期望线性：与独立性无关（核心工具）
④ 生日悖论：23 人 50% 概率有相同生日
⑤ 蒙提霍尔：换门 2/3（经典反直觉）

⚠️ 面试表达：
"几何分布期望 1/p——每次独立尝试
 成功概率 p，期望次数是 1/p。"
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"期望用线性性拆解：把总期望拆成
 每个指示变量的期望之和——
 第 i 个事件贡献 E[Iᵢ] = P(发生)，
 无需考虑事件之间的依赖，直接相加。
 这题状态是【剩余量】，概率 DP 转移
 用加权平均（各选择概率 × 子状态期望）。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 期望线性性条件？ | 任意随机变量成立（无需独立）——核心威力 |
| 2 | 概率 DP vs 普通 DP？ | 转移乘概率（加权）；边界是概率语义 |
| 3 | 什么时候记忆化/迭代？ | 状态稀疏记忆化；步数推进迭代 |
| 4 | 大 n 剪枝依据？ | 概率单调趋近 1（808：n>5000 返回 1.0） |
| 5 | 对称性怎么用？ | 等价角色概率相同（1227：1/2） |
| 6 | 几何分布？ | 成功概率 p → 期望 1/p |
| 7 | 加权随机（528）？ | 前缀和 + 二分定位权重区间 |
| 8 | 浮点精度？ | double 累积误差可控；比较用容差 |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 期望直接相乘 | 忽略相关性 | 用线性性拆解 |
| 边界语义错 | 结果错 | 明确"谁先耗尽" |
| 忘除以选择数 | 概率和 > 1 | 等概率 ÷n |
| 剪枝过激 | 精度不足 | 验证阈值 |
| 对称性滥用 | 结果错 | 验证角色等价 |

> 🎯 **核心要点**：概率题三件套 = **期望线性性**（拆分）、**概率 DP**（记忆化+加权转移）、**对称性**（简化）。识别信号："期望、概率、随机"。先想数学规律（线性/对称），再落 DP 模板；边界概率语义（0/1/0.5）是最大易错点。
