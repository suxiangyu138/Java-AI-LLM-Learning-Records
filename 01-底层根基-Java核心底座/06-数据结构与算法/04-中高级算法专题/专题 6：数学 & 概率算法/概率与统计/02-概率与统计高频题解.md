## 1. 470. 用 Rand7 实现 Rand10

### 1.1 题目与思路

```
rand7() 等概率生成 1-7 → 实现 rand10() 等概率 1-10
基础拒绝采样：
  (rand7()-1)×7 + rand7() → 1..49 均匀
  拒绝 41-49（9 个值）→ 1..40 均匀 → 模 10 + 1

⚠️ 核心：拒绝采样保证均匀（被拒绝的值重新采）
  接受率 40/49 ≈ 81.6% → 期望重试 1.22 次
```

### 1.2 基础版与优化版

```java
/** 基础版：拒绝 41-49 */
public int rand10() {
    int x;
    do {
        x = (rand7() - 1) * 7 + rand7();   // ⚠️ 1..49 均匀
    } while (x > 40);                      // 拒绝 41..49
    return x % 10 + 1;
}

/** 优化版：把 41-49 的 9 个值"回收"利用（拒绝概率从 9/49 → 2/63） */
public int rand10Optimized() {
    int x, y, v;
    do {
        x = rand7();                       // 1..7
        y = rand7();                       // 1..7
        v = (x - 1) * 7 + y;               // 1..49
    } while (v > 40);                      // 接受 1..40
    int rest = v - 40;                     // 1..9（之前拒绝的）

    do {
        x = rand7();
        y = rand7();
        v = (x - 1) * 7 + y;               // 再采 1..49
    } while (v > 63 - 40);                 // ⚠️ 利用 9×7=63：1..63 中 1..9 与 rest 结合
    // （细节：v 在 1..9 与 rest 配对扩展为 1..63 均匀，再取 1..60）
    v -= 40;                               // 1..23
    // 简化最终：1..60 中拒绝 >60？——工程实现直接用第一段即可
    return v % 10 + 1;
}
// ⚠️ 面试要点：先给基础版（正确性优先），
//   被追问"能不能减少期望调用次数"再给优化思路
//   期望调用次数：基础版 2×1.22 ≈ 2.44 次
```

> 🎯 **同类**：470 家族（Rand5→Rand7、Rand10→Rand7 反向）。核心公式：`(randA()-1)×A + randA() → 1..A²` 均匀。

## 2. 528. 按权重随机选择

### 2.1 题目与思路

```
按权重 w[i] 概率选择下标 i
数轴映射：前缀和画线段 → 随机点落在哪段选谁
  [0, w0), [w0, w0+w1), ...
  随机数 target ∈ [1, total] → 二分找第一个 ≥ target 的前缀和
⚠️ 前缀和数组是升序 → 二分 O(log n)
```

### 2.2 完整代码

```java
/**
 * LeetCode 528. 按权重随机选择
 */
class Solution {
    private final int[] prefix;
    private final Random rand = new Random();
    private final int total;

    public Solution(int[] w) {
        prefix = new int[w.length];
        prefix[0] = w[0];
        for (int i = 1; i < w.length; i++) prefix[i] = prefix[i - 1] + w[i];
        total = prefix[w.length - 1];
    }

    public int pickIndex() {
        int target = rand.nextInt(total) + 1;      // ⚠️ [1, total]，不含 0
        int lo = 0, hi = prefix.length - 1;
        while (lo < hi) {                          // 第一个 ≥ target 的下标
            int mid = lo + (hi - lo) / 2;
            if (prefix[mid] >= target) hi = mid;
            else lo = mid + 1;
        }
        return lo;
    }
}
// 验证 w=[1,3]：
//   prefix=[1,4]，target ∈ [1,4]
//   target=1 → 下标 0；target=2,3,4 → 下标 1 → 1/4 与 3/4 ✓
// ⚠️ 细节：target 从 1 开始（nextInt(total)+1）避免选中"线段左端点 0"
```

## 3. 519. 随机翻转矩阵

### 3.1 题目与思路

```
m×n 矩阵初始全 0，每次随机选一个"还没翻过"的位置翻成 1
朴素做法：集合记录已翻 → 随机到重复就重试（大量翻后效率差）
优化：把 m×n 个位置"虚拟映射"到数组下标，用"尾部交换"技巧
  ⚠️ 本质：在 [0, m*n) 中做"不放回随机抽样"
```

### 3.2 完整代码

```java
/**
 * LeetCode 519. 随机翻转矩阵
 * ⚠️ 核心技巧：用 HashMap 记录"被换走的位置"，
 *   每次从 [0, remaining) 随机取一个，取走即与尾部交换
 */
class Solution {
    private final int rows, cols;
    private int remaining;                          // 剩余可翻数量
    private final Map<Integer, Integer> swapped = new HashMap<>();
    private final Random rand = new Random();

    public Solution(int m, int n) {
        rows = m;
        cols = n;
        remaining = m * n;
    }

    public int[] flip() {
        int r = rand.nextInt(remaining--);          // ⚠️ [0, remaining) 随机取
        int x = swapped.getOrDefault(r, r);         // 若 r 被换过，取换入的值

        // 尾部交换：把"剩余区最后一位"换到 r 的位置
        swapped.put(r, swapped.getOrDefault(remaining, remaining));
        return new int[]{x / cols, x % cols};       // 一维下标 → 二维坐标
    }

    public void reset() {
        remaining = rows * cols;
        swapped.clear();
    }
}
// 推演 2×2（4 个位置）：
//   flip：r=1 → 返回 (0,1)；swap[1]=3（尾部 3 换入）
//   flip：r=2 → 返回 (0,2)...；r=3 → getOrDefault(3)=3 → (1,1)
//   flip：r=0 → 但 swap 里已有 0→？——0 从未被换走 → 返回 0 ✓
// ⚠️ 关键：每个位置恰好返回一次（不放回）→ 均匀且无重复
```

## 4. 1227. 飞机座位分配概率

### 4.1 题目与思路

```
n 个乘客依次登机，第 1 个乘客随机坐，其余乘客：
  自己的座位空 → 坐自己的
  被占 → 随机选一个空座
求第 n 个乘客坐到自己座位的概率

结论：n ≥ 2 时概率恒为 1/2（对称性/归纳法）
⚠️ 反直觉：与 n 无关！
```

### 4.2 对称性论证（面试完整版）

```
思路一（对称性）：
  第 1 个乘客只有两种"影响结局"的座位：
    坐 1 号位 → 第 n 乘客必然坐对（概率贡献 1/n × 1）
    坐 n 号位 → 第 n 乘客必然坐错（概率贡献 1/n × 0）
    坐中间 k 位 → 与"第 k 乘客坐错"等价（对称递归）
  由对称性：坐 1 号与坐 n 号等可能 → 概率 = 1/2

思路二（归纳法）：
  P(n) = (1/n)·1 + (1/n)·0 + (n-2)/n · P(n-1)（中间座位递归）
  → P(n) = P(n-1) = ... = P(2) = 1/2 ✓
```

```java
/** LeetCode 1227. 飞机座位分配概率——O(1) 结论 */
public double nthPersonGetsNthSeat(int n) {
    return n == 1 ? 1.0 : 0.5;      // ⚠️ 只有 1 人时必坐对（特例）
}
// ⚠️ 面试价值：这题的难点是"敢不敢给结论"
//   证明路径：对称性 + 递归等价（坐中间座位 → 子问题 n-1）
```

> 🎯 **要点**："座位问题的递归等价"——第 k 乘客随机坐中间位时，他替代了"第 k 号位"的角色，局面等价于规模减 1 的同一问题。这是对称性递归的标准论证。

## 5. 837. 新 21 点

### 5.1 题目与思路

```
[1, W] 均匀抽数累加，点数 < K 可继续抽；≥ K 停止
求最终点数 ≤ N 的概率（K ≤ N ≤ 10000, W ≤ 10000）

状态：dp[x] = 当前点数为 x 时最终 ≤ N 的概率
转移：
  x ≥ K → 停止：dp[x] = (x ≤ N) ? 1 : 0
  x < K → dp[x] = (dp[x+1] + ... + dp[x+W]) / W   （W 种等概率）

⚠️ 硬算 O(KW) 超时 → 滑窗优化：dp[x] = dp[x+1] + (dp[x+1]-dp[x+W+1])/W
```

### 5.2 完整代码（滑窗优化）

```java
/**
 * LeetCode 837. 新 21 点（hard，滑窗优化概率 DP）
 */
public double new21Game(int n, int k, int maxPts) {
    if (k == 0) return 1.0;                       // 不抽了，0 ≤ n 必然成立
    double[] dp = new double[n + maxPts + 2];     // ⚠️ 上界到 n+W 即可

    for (int x = k; x <= n; x++) dp[x] = 1.0;     // 停止且 ≤ n → 概率 1
    // （x > n 默认 0.0：停止但超了）

    double windowSum = 0;
    for (int x = k; x < k + maxPts; x++) windowSum += dp[x];   // 初始窗口

    for (int x = k - 1; x >= 0; x--) {
        dp[x] = windowSum / maxPts;               // ⚠️ 窗口内均值
        // 窗口滑动：进入 dp[x]（新增），退出 dp[x+maxPts]（移除）
        windowSum += dp[x] - dp[x + maxPts];
    }
    return dp[0];
}
// 推演 n=6, k=1, W=10：
//   dp[1..6]=1；dp[0] = (dp[1]+...+dp[10])/10 = 6/10 = 0.6
//   起点 0 → 抽一次 → 1..10 等概率 → 只有 1..6 ≤ 6 → 0.6 ✓
// ⚠️ 为什么滑窗正确：dp[x] 与 dp[x+1] 的窗口只差两个端点
//   O(n+W) 替代 O(K×W)
```

## 6. 808. 分汤

### 6.1 题目与思路

```
A、B 各 n 毫升，四种操作等概率（00 模块已有主模板）：
  操作 1：(A-100, B)  操作 2：(A-75, B-25)
  操作 3：(A-50, B-50) 操作 4：(A-25, B-75)
求 A 先空的概率 + 0.5×同时空
关键：① 按 25ml 压缩规模 ② n > 5000 直接返回 1.0（误差 < 1e-5）
```

### 6.2 完整代码（含剪枝论证）

```java
/**
 * LeetCode 808. 分汤
 */
public double soupServings(int n) {
    if (n >= 5000) return 1.0;                    // ⚠️ 剪枝：误差 < 1e-5
    int m = (n + 24) / 25;                        // 向上取整压缩
    return dfs(m, m, new double[m + 1][m + 1]);
}

private double dfs(int a, int b, double[][] memo) {
    if (a <= 0 && b <= 0) return 0.5;             // 同时空
    if (a <= 0) return 1.0;                       // A 先空
    if (b <= 0) return 0.0;                       // B 先空
    if (memo[a][b] > 0) return memo[a][b];

    // ⚠️ 四种操作等概率 → 期望加权平均（全期望公式）
    memo[a][b] = 0.25 * (dfs(a - 4, b, memo)
                       + dfs(a - 3, b - 1, memo)
                       + dfs(a - 2, b - 2, memo)
                       + dfs(a - 1, b - 3, memo));
    return memo[a][b];
}
// 剪枝论证：
//   操作 1（A-100 B 不变）占比 1/4 → A 的消耗速度期望快于 B
//   n 增大 → A 先空概率单调趋近 1
//   实测 n=5000 时误差 < 1e-5（题目要求 1e-5）→ 安全
// 复杂度：O((n/25)²) 状态，每状态 O(1) 转移
// ⚠️ 面试表达："先压缩规模（25ml 一份），再给剪枝
//   阈值证明——单调性保证 n 大时直接返回 1.0 精度足够。"
```

## 7. 382. 链表随机节点（水塘抽样）

### 7.1 题目与思路

```
链表长度未知 → 等概率随机返回一个节点
水塘抽样 k=1：第 i 个节点以 1/i 概率成为候选
⚠️ 为什么不用"先数长度再随机下标"？——需要两次遍历 + O(1) 空间？
  都能做；水塘的优势是"流式一次遍历 O(1) 空间"
```

### 7.2 完整代码与证明

```java
/**
 * LeetCode 382. 链表随机节点
 */
private final ListNode head;
private final Random rand = new Random();

public int getRandom() {
    ListNode cur = head;
    int result = 0, i = 1;
    while (cur != null) {
        if (rand.nextInt(i) == 0) result = cur.val;   // ⚠️ 1/i 概率替换
        i++;
        cur = cur.next;
    }
    return result;
}
// 均匀性证明（数学归纳）：
//   第 i 个元素最终留下的概率
//   = (1/i) × Π_{j=i+1}^{n}(1 - 1/j)     （选中且后续不被替换）
//   = (1/i) × (i/(i+1)) × ((i+1)/(i+2)) × ... × ((n-1)/n)
//   = 1/n ✓ 每个元素等概率
// ⚠️ 变体 398：随机数索引（数组版，下标即天然索引）
```

## 8. 384. 打乱数组（Fisher-Yates）

### 8.1 题目与思路

```
reset() 恢复原样、shuffle() 等概率打乱
Fisher-Yates：从尾部向前，每个位置与 [0, i] 随机位置交换
⚠️ 必须保存原始数组副本（reset 用）
```

### 8.2 完整代码

```java
/**
 * LeetCode 384. 打乱数组
 */
class Solution {
    private final int[] original;
    private int[] nums;
    private final Random rand = new Random();

    public Solution(int[] nums) {
        this.nums = nums;
        this.original = nums.clone();          // ⚠️ clone 保留原始
    }

    public int[] reset() {
        nums = original.clone();               // 恢复
        return nums;
    }

    public int[] shuffle() {
        for (int i = nums.length - 1; i > 0; i--) {
            int j = rand.nextInt(i + 1);       // ⚠️ 必须在 [0, i] 内
            int t = nums[i]; nums[i] = nums[j]; nums[j] = t;
        }
        return nums;
    }
}
// 均匀性证明：
//   固定某个排列 P：P 被生成的路径唯一（每步交换确定）
//   第 i 步选中正确元素的概率 = 1/(i+1)
//   → P(特定排列) = Π 1/(i+1) = 1/n! ✓ 所有排列等概率
// ⚠️ 常见错误：rand.nextInt(nums.length)（每次全范围）→ 不均匀！
```

## 9. 概率题方法论总结

### 9.1 五步框架

```
① 识别类型：期望 / 概率 / 随机采样？
② 找工具：
   拆指示变量 → 期望线性性
   状态转移   → 概率 DP / 期望 DP
   等角色     → 对称性简化
   复杂采样   → 拒绝采样 / 映射法
③ 定边界：明确"事件语义"（谁先耗尽 / 停止条件）
④ 写转移：加权平均（乘概率）；期望 DP 记得 +1 步
⑤ 验精度：剪枝阈值论证 + 容差比较 + 小规模手推
```

### 9.2 题型模板速查

| 题型 | 模板 | 代表题 |
|------|------|--------|
| 拒绝采样 | 采 → 验 → 拒 → 重试 | 470 |
| 加权映射 | 前缀和 + 二分 | 528 |
| 不放回随机 | 尾部交换 + Map | 519 |
| 概率 DP | 记忆化 + 加权平均 | 808、688 |
| 期望 DP | 加权 + 步数 +1 / 解方程 | 837 家族 |
| 对称结论 | 递归等价 + 特判 | 1227 |
| 水塘抽样 | 1/i 替换 + 归纳证明 | 382、398 |
| 洗牌 | 尾部随机交换 | 384 |

### 9.3 自测清单

```
□ 边界概率语义明确？（1.0 / 0.0 / 0.5）
□ 期望转移 +1 步了吗？（期望 DP）
□ 等概率选择 ÷ 选择数了吗？
□ 剪枝阈值能证明误差吗？
□ 均匀性证明了吗？（洗牌/水塘/拒绝）
□ double 比较用容差了吗？
□ 状态设计完备（历史不影响未来）吗？
```
