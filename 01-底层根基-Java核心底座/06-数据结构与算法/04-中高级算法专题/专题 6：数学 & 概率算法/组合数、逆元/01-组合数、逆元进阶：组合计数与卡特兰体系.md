## 1. Lucas 定理深潜：证明与 Kummer 定理

### 1.1 为什么 Lucas 能「拆位」：二项式展开证明

精要篇只给了公式，这里补上完整证明——它是面试「为什么 Lucas 成立」的标准答案，也是理解 Kummer 定理的跳板。

设 p 为质数，先把 n 写成 p 进制：`n = n₀ + n₁·p + n₂·p² + ... + nₛ·pˢ`（nᵢ ∈ [0, p-1]）。

**第一步：范德蒙德的「新生之梦」。** 在模 p 意义下考察 `(1+x)^p`：

`(1+x)^p = Σ C(p,k)·xᵏ`，而对 `0 < k < p` 有 `p | C(p,k)`（组合数分子含因子 p，分母不含），于是中间项全部消失：

`(1+x)^p ≡ 1 + x^p (mod p)`

重复应用：`(1+x)^(p^i) ≡ 1 + x^(p^i) (mod p)`。

**第二步：按 p 进制分解二项式。**

`(1+x)^n = Πᵢ ((1+x)^(p^i))^nᵢ ≡ Πᵢ (1 + x^(p^i))^nᵢ (mod p)`

**第三步：比较 x^m 的系数。** 把 m 也写成 p 进制 `m = m₀ + m₁·p + ...`，右侧展开后 x^m 的系数正好是 Πᵢ C(nᵢ, mᵢ)（每一位独立选择）；左侧 x^m 的系数是 C(n, m)。两边相等即得：

`C(n, m) ≡ Πᵢ C(nᵢ, mᵢ) (mod p)` —— 这正是 Lucas 定理的「按位相乘」形态，与递归式 `C(n,m) ≡ C(n mod p, m mod p) · C(n/p, m/p) (mod p)` 等价。

> 💡 证明的直觉：模 p 下「高进制位」与「低进制位」互不干扰，组合数被拆成各位独立贡献——这就是为什么 Lucas 只要求 p 是质数，而对 n, m 的大小毫无限制。

### 1.2 Kummer 定理：从 Lucas 到「进位计数」

Kummer 定理（1852）给出更强的结论，是 Lucas 的精确化：

`v_p(C(n, m))` = 用 p 进制计算 `m + (n-m)` 时的**进位次数**。

其中 `v_p(x)` 表示 x 的质因子分解中 p 的指数。面试两条推论最常考：

- **组合数奇偶性（p = 2）**：`C(n, m)` 为奇数 ⟺ `m + (n-m)` 二进制相加无进位 ⟺ `m` 的每个二进制位都被 `n` 包含，即 `(n & m) == m`（m 是 n 的位子集）。
- **整除性判断**：`p | C(n, m)` ⟺ p 进制下 `m + (n-m)` 至少进一次位。

验证：`C(5,2) = 10` 为偶数。n=5（`101`₂），m=2（`010`₂）：`m & ~n = 010 & 010 = 010 ≠ 0`，不是位子集 → 偶数 ✓。

> 🎯 Kummer 速记：**Lucas 说「每位独立」；Kummer 说「进位破坏独立」**——进位一次，p 的指数就加一。

### 1.3 Lucas 实现清单：边界与坑

| # | 坑点 | 后果 | 修正 |
|:---:|------|------|------|
| 1 | 阶乘表开到 n | 空间爆炸（n 可达 10¹⁸） | 表只开到 p-1 |
| 2 | 忘判 `m%p > n%p` | 查表越界 / 答案错误 | 该位组合数直接取 0 |
| 3 | 逆元用 exgcd 替代费马 | 可行但 p 质数没必要 | 费马 `a^(p-2)` 即可 |
| 4 | 用 long 存储 p 进制位 | 丢失（n < 10¹⁸ 时 p 进制位 < p ≤ 10⁵ 不会丢，但 n%p 需先取模） | `n % p`、`n / p` 全程 long |
| 5 | 多组询问重复建表 | T×O(p) 超时 | 建表一次复用 |

递归版模板（p 为质数，阶乘表 `fac[]` 预处理到 p-1）：

```java
/**
 * Lucas 定理（递归版）
 * fac[]/invfac[]：模 p 的阶乘与逆元阶乘表，预处理到 p-1
 * 适用：n, m ≤ 10^18，p ≤ 10^5 且为质数
 */
public long lucas(long n, long m, long p) {
    if (m == 0) return 1;
    // 递归：低位组合 × 高位组合；C(n%p, m%p) 内部自带 m>n 判 0
    return C((int)(n % p), (int)(m % p), p)
         * lucas(n / p, m / p, p) % p;
}

/** 小范围组合数（0 ≤ m ≤ n ≤ p-1，表已建好） */
private long C(int n, int m, long p) {
    if (m < 0 || m > n) return 0;
    return fac[n] * invfac[m] % p * invfac[n - m] % p;
}
// 复杂度：O(p) 建表 + O(log_p n) 递归；⚠️ 递归深度 log_p n ≤ 60，安全
```

> ⚠️ 面试追问「Lucas 里 C(n%p, m%p) 的 n%p 会不会比 m%p 小？」——会！此时该位贡献 0，不是「交换 m、n」！例如 `C(8,6) mod 5`：`8%5=3, 6%5=1`，低位 `C(3,1)=3`，高位 `lucas(1,1)=1` → 答案 3。而 `C(8,1) mod 5`：低位 `C(3,1)=3`，高位 `lucas(1,0)=1` → 3 ✓（C(8,1)=8 ≡ 3 mod 5）。关键在递归出口 `m==0` 时返回 1——低位一旦出现 `m%p > n%p`，该位为 0，整个乘积为 0。

### 1.4 特例：p = 2 时的位运算形态

p = 2 时 Lucas 退化为纯位运算判断：

`C(n, m) ≡ 1 (mod 2) ⟺ (n & m) == m`

这是「组合数奇偶性」题的通用解法，O(1) 免建表；推广到任意质数 p，则等价于 Kummer 进位次数为 0。

## 2. exLucas：合数模数的完整体系

### 2.1 为什么 Lucas 在合数模下失效

Lucas 的证明依赖「p 为质数」两条命脉：① `(1+x)^p ≡ 1 + x^p` 的中间项消失（要求 p 整除 C(p,k)）；② 阶乘求逆依赖费马小定理（要求模为质数）。模数是合数 P 时二者同时崩塌——费马求逆直接算出一个不存在的「逆元」。

exLucas 的思路不是修补 Lucas，而是**绕道**：把合数拆成互质块，各块用「提因子 + 循环节 + 欧拉/exgcd 求逆」硬算，最后 CRT 拼回。整体架构：

```text
目标：C(n,m) mod P（P 任意合数）
  │ ① 质因数分解
  ▼
P = p₁^k₁ · p₂^k₂ · ... · pₜ^kₜ
  │ ② 对每个 pᵢ^kᵢ 独立求 C(n,m) mod pᵢ^kᵢ   ← 难点：分母与 pᵢ 不互质
  ▼
x ≡ r₁ (mod p₁^k₁), x ≡ r₂ (mod p₂^k₂), ...
  │ ③ CRT 合并（模数两两互质）
  ▼
最终答案 x mod P
```

（注：exLucas 与 Lucas 名字相似但无直接关系，是「质因数分解 + CRT」的独立体系。）

### 2.2 核心难点：C(n,m) mod p^k 怎么算

`m!`、`(n-m)!` 里都含有因子 p，与 `p^k` 不互质 → **不能直接求逆元**。解法是「把 p 因子整体提出来」：

**① 提因子。** 设 `n! = p^a · A`，其中 A 与 p 互质；同理 `m! = p^b · B`、`(n-m)! = p^c · C`。则：

`C(n,m) = p^(a-b-c) · A / (B·C) (mod p^k)`

此时分母 `B·C` 与 `p^k` 互质，逆元存在——用**欧拉定理**（`x^φ ≡ 1`，φ(p^k) = p^k·(p-1)/p）或 **exgcd** 求逆，不能再用费马小定理。

**② 指数 a-b-c 用 Legendre 公式。** `v_p(n!) = ⌊n/p⌋ + ⌊n/p²⌋ + ⌊n/p³⌋ + ...`（勒让德定理）。若 `a-b-c ≥ k`，说明 p^k 整除组合数，结果直接为 0。

**③ 关键函数 F(n) = n! 去掉全部 p 因子后 mod p^k。** 直接乘 O(n) 会超时，利用周期性：`[1, p^k]` 中与 p 互质的数组成一个循环节（模 p^k 下乘法有周期），于是：

`F(n) = F(⌊n/p⌋) · (循环节乘积)^(⌊n/p^k⌋) · (⌊n/p^k⌋·p^k 之后余下的互质段乘积) mod p^k`

中间项用快速幂，递归深度 O(log_p n)。这是整个 exLucas 唯一的「难写」函数，其余全是套模板。

### 2.3 完整可运行模板（Java）

```java
/**
 * exLucas 完整模板：C(n,m) mod P（P 为任意正整数，n,m ≤ 10^18）
 * 复杂度：O(Σ pᵢ^kᵢ · log n)；适用 P ≤ 10^6 量级（分解 + 循环节都可行）
 * 三步：分解 P → 对每个 p^k 独立求 → CRT 合并
 */
public class ExLucas {

    // ========== ① 质因数分解：返回 {p, k, p^k} 列表 ==========
    private static List<long[]> factorize(long P) {
        List<long[]> list = new ArrayList<>();
        for (long p = 2; p * p <= P; p++) {
            if (P % p != 0) continue;
            long pk = 1; int k = 0;
            while (P % p == 0) { P /= p; pk *= p; k++; }
            list.add(new long[]{p, k, pk});
        }
        if (P > 1) list.add(new long[]{P, 1, P});
        return list;
    }

    // ========== ② C(n,m) mod p^k（核心难点） ==========
    private static long combPrimePow(long n, long m, long p, int k, long pk) {
        // ① Legendre 提因子：p 的总指数 e = v_p(n!) - v_p(m!) - v_p((n-m)!)
        long e = 0;
        for (long x = n; x > 0; x /= p) e += x / p;
        for (long x = m; x > 0; x /= p) e -= x / p;
        for (long x = n - m; x > 0; x /= p) e -= x / p;
        if (e >= k) return 0;                        // p^k | C(n,m) → 直接 0
        // ② 各阶乘去掉 p 因子后互质，可用欧拉定理求逆
        long phi = pk / p * (p - 1);                 // φ(p^k) = p^k·(1-1/p)
        long fn = facNoP(n, p, pk);
        long fm = facNoP(m, p, pk);
        long fnm = facNoP(n - m, p, pk);
        long inv = qpow(fm * fnm % pk, phi - 1, pk); // 欧拉定理：x^φ≡1 → 逆元 x^(φ-1)
        return qpow(p, e, pk) * fn % pk * inv % pk;
    }

    /** n! 去掉全部 p 因子后 mod p^k（循环节 + 快速幂 + 递归） */
    private static long facNoP(long n, long p, long pk) {
        if (n == 0) return 1;
        // 循环节：1..pk 中与 p 互质的数乘积（预处理一次，本题内联计算）
        long cycle = 1;
        for (long i = 1; i <= pk; i++)
            if (i % p != 0) cycle = cycle * (i % pk) % pk;
        long res = qpow(cycle, n / pk, pk);          // 完整循环节段
        for (long i = pk * (n / pk) + 1; i <= n; i++)// 末尾不完整段
            if (i % p != 0) res = res * (i % pk) % pk;
        return res * facNoP(n / p, p, pk) % pk;      // 递归：整除 p 的部分
    }

    // ========== ③ CRT 合并（模数两两互质） ==========
    private static long crt(long[] r, long[] mod, long P) {
        long x = 0;
        for (int i = 0; i < r.length; i++) {
            long Mi = P / mod[i];                    // 其余模数乘积
            long inv = qpow(Mi, phi(mod[i]) - 1, mod[i]); // Mi 逆元（欧拉）
            x = (x + r[i] * Mi % P * inv) % P;
        }
        return x;
    }

    private static long phi(long x) { // 单点欧拉函数（因子已分解时可直接带参）
        long res = x;
        for (long i = 2; i * i <= x; i++) {
            if (x % i == 0) {
                res = res / i * (i - 1);
                while (x % i == 0) x /= i;
            }
        }
        if (x > 1) res = res / x * (x - 1);
        return res;
    }

    private static long qpow(long a, long b, long mod) {
        long res = 1 % mod;
        a %= mod;
        while (b > 0) {
            if ((b & 1) == 1) res = res * a % mod;
            a = a * a % mod;
            b >>= 1;
        }
        return res;
    }

    // ========== 入口 ==========
    public static long exLucas(long n, long m, long P) {
        List<long[]> facs = factorize(P);
        long[] r = new long[facs.size()];
        long[] mod = new long[facs.size()];
        for (int i = 0; i < facs.size(); i++) {
            long[] f = facs.get(i);
            mod[i] = f[2];                                   // p^k
            r[i] = combPrimePow(n, m, f[0], (int) f[1], f[2]);
        }
        return crt(r, mod, P);
    }
}
// 面试定位：exLucas 是「困难模板」，面试只需讲清三步流程 + 提因子思想；
// 洛谷 P4720 为模板题，笔试手写前可先分解 P 确认规模（P ≤ 10^6 才适合）
```

### 2.4 实战推演：C(n, k) mod 10（Lucas + CRT 组合）

求组合数对 10 取模（2025.08 力扣题解中出现的实战形态）——10 是合数，`φ(10)=4` 但 2、5 不互质因子太多，直接用阶乘逆元不可行。拆解：

`10 = 2 × 5` → 分别求 `C(n,k) mod 2` 与 `C(n,k) mod 5`，再 CRT 合并。

- mod 2：p=2 质数 → 直接 Lucas（或 Kummer 奇偶判定）；
- mod 5：p=5 质数 → Lucas；
- 合并：`x ≡ r₂ (mod 2)`、`x ≡ r₅ (mod 5)` → 唯一解 mod 10，可用「查表」：x 由 (r₂, r₅) 两维唯一决定（0..9 每个数模 2、模 5 的组合两两不同），10 以内暴力枚举即可。

> 💡 一般化结论：**合数模 = 质数幂分解 + Lucas/exLucas 分治 + CRT 合并**，这三件套组合能覆盖一切「组合数取模」问题。若 P 含质数幂因子（如 12 = 4×3），则 4 这一路必须走 exLucas 的「提因子」路线，普通 Lucas 只负责质数路。

## 3. 卡特兰数体系：反射原理与 Ballot 定理

### 3.1 本质与六场景等价表

卡特兰数的**本质**：两种对立的操作排成序列，任意前缀里「A 类操作数 ≥ B 类操作数」。凡是满足这个约束的计数，答案都是卡特兰数：

| 场景 | A 操作（+1） | B 操作（-1） | 约束 |
|------|------|------|------|
| 括号匹配 | 左括号 | 右括号 | 任意前缀左 ≥ 右 |
| 出栈序列 | 入栈 | 出栈 | 任意前缀入 ≥ 出（栈不空） |
| Dyck 路径 | 向上 | 向右 | 不越过 y = x |
| 二叉搜索树 | 左子树 | 右子树 | 根切开后的结构递归 |
| 三角剖分 | 边 | 对角线 | 凸 n+2 边形 |
| 购票找零 | 收 100 | 找 50 | 任意前缀收 ≥ 找 |

识别信号一句话：**「从左到右扫描，某类操作数量任何时候不少于另一类」→ 卡特兰数**。

### 3.2 反射原理：一条双射吃遍全部证明

以 Dyck 路径（从 (0,0) 到 (n,n)，不越过 y=x）为例，反射原理三步：

**① 总数**：无约束路径 `C(2n, n)`（2n 步选 n 步向上）。

**② 数非法**：非法路径 = 至少一次碰到 `y = x+1`。取**第一次**碰到 y=x+1 的位置，把之后的路段沿直线 `y = x+1` 做轴对称翻转——终点 (n, n) 被翻到 (n-1, n+1)。这个变换是一一对应（可逆），于是：

非法路径数 = 从 (0,0) 到 (n-1, n+1) 的任意路径数 = `C(2n, n-1)`

**③ 相减**：`Catₙ = C(2n, n) - C(2n, n-1) = C(2n, n)/(n+1)`

验证 n=3：`C(6,3) - C(6,2) = 20 - 15 = 5` ✓（3 对括号的 5 种合法串）。

> 🎯 反射原理核心：**非法方案在第一次越线处「翻折」后半段，与一条无约束路径双射**——把「带约束计数」变成「无约束计数」，再相减。出栈、括号、找零全部可以这样证明，一法通六法。

### 3.3 Ballot 定理与广义卡特兰

反射原理的自然推广——**投票问题**：候选人 A 得 a 票、B 得 b 票（a > b），计票全程 A 都严格领先的概率是多少？

答案是 `(a - b) / (a + b)`（Ballot 定理，1887）。直觉验证 a=3, b=2：概率 1/5。可以用路径语言证明：路径从 (1,0) 出发到 (a, b)，「A 恒领先」⟺ 不碰 y=x ⟺ 不碰 y=x+1（从 (1,0) 起恒有 A ≥ B+1... 用反射同样可得）：

`P(A 恒领先) = (C(a+b-1, b) - C(a+b-1, a)) / C(a+b, b) = (a-b)/(a+b)`

配套格点结论（不碰 y=x 的路径数）：`C(a+b-1, b) - C(a+b-1, a)`。双线约束（y=x+k₁ 与 y=x+k₂ 之间）时需**反射 + 容斥**反复翻折（「反射容斥」），是卡特兰的进阶形态。

### 3.4 卡特兰数的计算与取模

| 公式 | 形态 | 适用 |
|------|------|------|
| 通项式 | `Catₙ = C(2n,n)/(n+1)` | 模数不含 n+1 的因子时最简洁 |
| 差分式 | `Catₙ = C(2n,n) - C(2n,n+1)` | **免除法**，p 任意都能算 |
| 线性递推 | `Catₙ = (4n-2)/(n+1) · Catₙ₋₁` | 单点递推 O(n)，省阶乘表 |
| 卷积递推 | `Catₙ = Σ Catₖ·Catₙ₋₁₋ₖ` | 结构拆分（最后出栈元素 / 根的位置） |

取模实战注意：

- 差分式 `C(2n,n) - C(2n,n+1)` 完全避开除法——当模数恰好整除 n+1（如模 5 求 Cat₄，n+1=5）时，`(n+1)⁻¹` 不存在，此时**必须**用差分式；
- 线性递推做模数时同样受此约束，遇到 `p | (n+1)` 改用差分式；
- 无模数场景：n ≤ 19 时 Catₙ 可入 int，n ≤ 33 可入 long，更大用 BigInteger。

### 3.5 卡特兰 vs 一般 DP 计数的识别

| 信号 | 卡特兰 | 普通 DP |
|------|------|------|
| 约束形态 | 「任意前缀 A ≥ B」 | 位置/状态相关 |
| 状态数 | 一维（n 或 2n） | 通常二维+ |
| 关键操作 | 找到「第一次越界」/「最后一次操作对象」拆分 | 转移方程 |
| 典型题 | 括号、出栈、BST、三角剖分 | 路径数（无越界约束）、背包 |

判别技巧：写出前缀约束后，尝试「以最后一次/第一个关键事件切开序列」——能切成左右两个独立子问题（卷积），就是卡特兰；切不开就是 DP。

## 4. 组合计数方法论：球盒模型与错排

### 4.1 球盒模型四象限（stars and bars）

把「n 个球放进 k 个盒子」按「球/盒是否可区分」分成四象限——组合计数的通用底座：

| 球 | 盒 | 允许空盒 | 方案数 | 识别信号 |
|:---:|:---:|:---:|------|------|
| 有区别 | 有区别 | 是 | `kⁿ` | 每球独立选盒子（乘法原理） |
| 有区别 | 有区别 | 否 | `Σ (-1)ʲ C(k,j)(k-j)ⁿ = k!·S(n,k)` | 容斥减掉空盒（第二类斯特林数） |
| 无区别 | 有区别 | 是 | `C(n+k-1, k-1)` | 隔板法：n 球 + k-1 板排列 |
| 无区别 | 有区别 | 否 | `C(n-1, k-1)` | 先各放 1 个再隔板 |

隔板法（stars and bars）推导：n 个相同球排成一列，插 k-1 块隔板分成 k 段 → 从 n+k-1 个位置选 k-1 个放板 → `C(n+k-1, k-1)`。不允许空盒则先给每盒预放 1 个，剩 n-k 个球再隔板 → `C(n-1, k-1)`。

经典转化：**方程 `x₁ + x₂ + ... + xₖ = n` 的非负整数解 = `C(n+k-1, k-1)`；正整数解 = `C(n-1, k-1)`**。这是隔板法最常考的形态。

### 4.2 错排：递推与容斥两条路

错排 `Dₙ`：1..n 的排列中没有一个元素待在原位。

- **递推式**：`Dₙ = (n-1)(Dₙ₋₁ + Dₙ₋₂)`，边界 `D₁ = 0, D₂ = 1`。
  推导（核心分类）：考虑元素 1 的位置——若 1 与某元素 k（k≠1）互换，剩下 n-2 个错排，共 `(n-1)·Dₙ₋₂`；若 1 占据 k 的位置但 k 不在 1 的位置，把「k 视作新的 1」，剩 n-1 个错排，共 `(n-1)·Dₙ₋₁`。
- **容斥式**：`Dₙ = n! · Σᵢ₌₀ⁿ (-1)ⁱ/i!`（先全排列，减去至少一个在位的，容斥交替加减）。
- **极限**：`Dₙ / n! → 1/e ≈ 0.3679`（当 n 大时，随机排列是全错排的概率约 36.8%）——面试常考的「估算」题。

取模实现：`Dₙ = (n-1)·((Dₙ₋₁ + Dₙ₋₂) % p) % p`，O(n) 递推；n 巨大时用矩阵快速幂（转移 `[[n-1, n-1],[1,0]]` 因系数含 n 需分段处理，笔试少见）。

### 4.3 容斥原理在计数中的三个应用

- **多重集组合**（CF 451E Devu and Flowers）：n 种花各有限量 cᵢ，选 m 朵。无限制隔板法 `C(m+n-1, n-1)`，减去「第 i 种超量」（每种至少 cᵢ+1），加回「两种同时超量」……标准容斥 `Σ (-1)^|S| · C(m - Σcᵢ - |S| + n - 1, n-1)`，每项用 Lucas 求模。识别信号：**「有限量 + 选若干」→ 隔板 + 容斥**。
- **禁止相邻**：n 个男、n 个女排一列，先排男（n!），再用容斥算女插入时不能相邻的排法。
- **并集大小**：`|A∪B∪C| = Σ|A| - Σ|A∩B| + |A∩B∩C|`——「至少一个事件发生」类的计数与概率问题统一入口。

### 4.4 组合恒等式的证明技巧

面试被问「证明 C(n,k)·k = n·C(n-1,k-1)」时，两种范式任选：

- **组合证明（首选，口述快）**：等式两边数同一个对象。左边：从 n 人选 k 人并指定其中 1 人为组长；右边：先选组长（n 种）再从剩余 n-1 人选 k-1 人。两边都是「k 人小组 + 组长」→ 相等。
- **代数证明**：按定义展开阶乘约分。

高频恒等式速查（含证明思路）：

| 恒等式 | 一句话证明 |
|------|------|
| `C(n,k) = C(n, n-k)` | 选 k 个 = 留下 n-k 个 |
| `C(n,k) = n/k · C(n-1,k-1)` | 吸收恒等式，展开即得 |
| `Σ C(n,k) = 2ⁿ` | 全体子集数 |
| `C(n,k) = C(n-1,k) + C(n-1,k-1)` | 杨辉：第 k 个元素取或不取 |
| `Σ C(a,j)C(b,k-j) = C(a+b,k)` | 范德蒙德：分两堆选人 |

## 5. 逆元的工程深入：批量求逆与边界

### 5.1 批量求逆：前缀积 + 一次快速幂（P5431 模板）

逐个求逆元是 O(n log p)，n 到 10⁶ 量级就超时。批量技巧把总代价压到 **O(n + log p)**：

```java
/**
 * 批量求逆：对 a[1..n]，O(n + log p) 求出全部 a[i]⁻¹（只需一次快速幂）
 * 原理：s[i] = Π a[1..i]；inv(s[n]) 求一次；
 *       inv(a[i]) = inv(s[i]) · s[i-1]；inv(s[i-1]) = inv(s[i]) · a[i]
 */
public static long[] invBatch(long[] a, long p) {
    int n = a.length;
    long[] s = new long[n + 1];
    long[] invS = new long[n + 1];
    s[0] = 1;
    for (int i = 1; i <= n; i++) s[i] = s[i - 1] * a[i] % p;
    invS[n] = qpow(s[n], p - 2, p);          // ⚠️ 全流程唯一一次快速幂
    long[] inv = new long[n + 1];
    for (int i = n; i >= 1; i--) {
        inv[i] = invS[i] * s[i - 1] % p;     // a[i]⁻¹ = (Πa[1..i])⁻¹ · Πa[1..i-1]
        invS[i - 1] = invS[i] * a[i] % p;    // 倒推前缀积的逆
    }
    return inv;
}
// 边界：a[i] 全部与 p 互质（p 为质数且 a[i] % p != 0）；s[n] 为 0 时不可逆
```

P5431 的求和 `Σ kⁱ·aᵢ⁻¹` 还能用霍纳式变形把 k 的幂也省掉——逆序累乘，每步乘以 k：

```java
// 求 Σ_{i=1..n} k^i · a[i]⁻¹ mod p（a 从 1 开始计数）
long ans = 0;
for (int i = n; i >= 1; i--) {
    ans = (ans + inv[i]) * k % p;            // 逆序：越早加入的项乘的 k 越多
}
// 展开验证：i=n 项得 k¹，i=1 项得 kⁿ → 与 Σ k^i·a[i]⁻¹ 完全一致
```

### 5.2 三种批量实现对比

| 方法 | 思路 | 快速幂次数 | 空间 | 适用 |
|------|------|:---:|:---:|------|
| 前缀积倒推 | 对 s[n] 求一次逆再倒推 | 1 | 2 个数组 | 通用首选 |
| 通分合并 | `Σ 1/aᵢ = (Σ Π_{j≠i} aⱼ) / Π aⱼ`，分子用前缀×后缀积 | 1 | 3 个数组 | 只需总和时 |
| 边读边通分 | 读入时同步维护 `(Σ kⁱ·其他) / Π aᵢ` | 1 | 常数 | 卡内存 + 只要总和 |

三者都只做一次快速幂；区别在中间产物是「逐项逆元」还是「总和分子」。

### 5.3 线性递推求逆的边界（精要篇补充）

精要篇给了 `inv[i] = (p - p/i)·inv[p % i] % p`，这里补全三个**致命前提**：

- **必须 n < p**：若 `p | i`（即 i ≥ p 且 i 是 p 的倍数），`p % i = 0`，`inv[0]` 未定义，递推崩坏。质数 p 下只有 i = p 时发生 → n ≥ p 就错；
- **p 必须为质数**：非质数模数下 `inv[p % i]` 未必存在（p%i 可能不与 p 互质）；
- 记忆点：**线性递推 = 「小范围 + 质数模」专用**，范围超过模数立刻换前缀积批量法。

### 5.4 模数非质数时的应对策略

| 场景 | 工具 | 说明 |
|------|------|------|
| gcd(a, p) = 1，p 任意 | exgcd 求逆 | 唯一可靠通用法（见「欧几里得 exgcd」专题 01） |
| gcd(a, p) = 1，p = qᵏ | 欧拉定理 `a^(φ(p)-1)` | 快速幂替代 exgcd，代码更短 |
| gcd(a, p) ≠ 1 | **无逆元** | 逆元不存在！改用整数递推/DP，或按 p 的质因子分治处理 |
| p = 1e9+7 型质数 | 费马 `a^(p-2)` | 默认首选 |

### 5.5 大组合数的精确值（无模数场景）

| 规模 | 方案 |
|------|------|
| n ≤ 60 | `C(60,30) ≈ 1.18×10¹⁷ < long`，逐项 `res = res·(n-i+1)/i`（先乘后除，每步整除） |
| n ≤ 100+ | 超 long → `BigInteger`（慢，笔试禁用） |
| 只需数量级 | 双精度对数：`log C(n,m) = Σ log i - ...`，`exp` 还原（概率工程题常用） |
| 大质数因子 | 分解 n! 的质因数，指数相减后乘回（素因子法） |

> ⚠️ 逐项乘除的写法顺序不能反：`res = res * (n-i+1) / i` 中**乘法会先溢出**（中间值可达 res 的 (n-i+1) 倍）。LC 62 的答案是 `≤ 2×10⁹`（数据保证），long 中间量安全；若 n 大到答案逼近 10¹⁸ 仍可用 long 精确算（`C(60,30) < 9.2×10¹⁸`），再大必须换方案。
