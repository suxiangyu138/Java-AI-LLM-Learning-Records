## 1. 62. 不同路径（组合数 / DP）

### 1.1 题目与思路

```text
m×n 网格，从左上到右下，只能向右/向下，求路径数（m, n ≤ 100，答案 ≤ 2×10⁹）
法一（组合数）：总共走 m+n-2 步，选 m-1 步向下 → C(m+n-2, m-1)
   ⚠️ 必须用 long 逐项乘除，且取 min(m-1, n-1) 减少循环
法二（DP）：dp[i][j] = dp[i-1][j] + dp[i][j-1]，一维滚动数组
面试首选：组合数公式一句话能讲清，DP 适合口述「无溢出顾虑」
```

### 1.2 完整代码

```java
/**
 * LeetCode 62. 不同路径
 * 解法一：组合数公式 C(m+n-2, m-1)，逐项乘除防溢出
 */
public int uniquePaths(int m, int n) {
    // 总步数 m+n-2，取 min(m-1, n-1) 为 k，减少循环次数
    int N = m + n - 2;
    int k = Math.min(m - 1, n - 1);
    long res = 1;
    for (int i = 1; i <= k; i++) {
        res = res * (N - i + 1) / i;     // ⚠️ 每步先乘后除，保证整除（long 承接中间量）
    }
    return (int) res;
}
// 复杂度 O(min(m,n))；面试必答："边乘边除、每步整除、取较小 k 防溢出；
//   答案 ≤ 2×10⁹ 时 long 中间量安全，但 m,n 再大（如 100×100 满值）组合数会溢出 long，换 DP"

/**
 * 解法二：DP（一维滚动），任意规模无溢出
 */
public int uniquePathsDp(int m, int n) {
    int[] dp = new int[n];
    java.util.Arrays.fill(dp, 1);        // 第一行全 1
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            dp[j] += dp[j - 1];          // dp[j](上) + dp[j-1](左)
        }
    }
    return dp[n - 1];
}
// 复杂度 O(m×n) 时间 O(n) 空间；推演 m=3,n=3：dp 变化 [1,1,1]→[1,2,3]→[1,3,6] → 6 ✓
```

## 2. 118/119. 杨辉三角 I/II（递推与单行生成）

### 2.1 题目与思路

```text
118：生成前 numRows 行（numRows ≤ 30）
119：只返回第 rowIndex 行（rowIndex ≤ 33），要求 O(rowIndex) 空间
119 两个套路：① 滚动数组倒序更新；② 组合数逐项递推 row[i] = row[i-1]·(n-i+1)/i
⚠️ 组合数递推的乘法用 long：row[i-1] ≤ 1.1×10⁹，乘 (n-i+1) 后超 int
```

### 2.2 完整代码

```java
/**
 * LeetCode 119. 杨辉三角 II（单行生成，O(rowIndex) 空间）
 */
public List<Integer> getRow(int rowIndex) {
    Integer[] row = new Integer[rowIndex + 1];
    Arrays.fill(row, 0);                       // ⚠️ 预填 0，否则 row[i] 首次访问为 null
    row[0] = 1;
    // 从第 1 行迭代到第 rowIndex 行；j 倒序：row[j] 与 row[j-1] 都还是上一行的值
    for (int i = 1; i <= rowIndex; i++) {
        for (int j = i; j >= 1; j--) {
            row[j] = row[j - 1] + row[j];      // 上一行 j-1 + 上一行 j
        }
    }
    return Arrays.asList(row);
}
```

```java
/**
 * 组合数公式版：C(n,k) = C(n,k-1)·(n-k+1)/k，逐项乘除（k ≤ n/2 时对称省一半）
 */
public List<Integer> getRowComb(int rowIndex) {
    List<Integer> res = new ArrayList<>();
    res.add(1);
    long c = 1;                            // C(n,0) = 1
    for (int k = 1; k <= rowIndex; k++) {
        c = c * (rowIndex - k + 1) / k;    // ⚠️ long 承接，先乘后除每步整除
        res.add((int) c);
    }
    return res;
}
// 推演 n=4：1 → 4 → 6 → 4 → 1 ✓；面试必答："119 的核心是倒序滚动防覆盖，
//   或者组合数逐项乘除；两种都要会，组合数版还能顺带复习 C(n,k) 递推公式。"
```

## 3. 63. 不同路径 II（障碍 DP）

### 3.1 题目与思路

```text
62 加障碍：网格中 1 表示障碍，路径不能经过
组合数公式失效（障碍破坏「等权组合」）→ 必须 DP
转移：dp[j] += dp[j-1]（上 + 左），障碍点置 0；
      首行首列初始化遇到障碍后全为 0（⚠️ 常见错：只把障碍点置 0 不处理后续）
```

### 3.2 完整代码

```java
/**
 * LeetCode 63. 不同路径 II（一维滚动 DP + 障碍处理）
 */
public int uniquePathsWithObstacles(int[][] grid) {
    int m = grid.length, n = grid[0].length;
    if (grid[0][0] == 1) return 0;             // 起点就是障碍
    long[] dp = new long[n];
    dp[0] = 1;
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (grid[i][j] == 1) {
                dp[j] = 0;                     // 障碍：路径数清零
            } else if (j > 0) {
                dp[j] += dp[j - 1];            // 上 + 左（dp[j] 保留上一行的值）
            }
        }
    }
    return (int) dp[n - 1];
}
// 复杂度 O(m×n) 时间 O(n) 空间
// 面试必答："62 的障碍版必须 DP，组合数公式不能处理不规则的障碍布局；
//   滚动数组里 dp[j] 天然存上一行的值，障碍清零 + 左值累加即可。"
```

## 4. 96. 不同的二叉搜索树（卡特兰数）

### 4.1 题目与思路

```text
n 个节点（1..n）能构造多少种 BST？（n ≤ 19，答案 Cat(19) = 1767263190 入 int）
法一（卡特兰）：Cat(n) = C(2n,n)/(n+1)——识别信号「根切开后左右子树递归」
法二（DP）：dp[i] = Σ dp[k]·dp[i-1-k]（选 k 为根，左 k-1 个右 i-k 个）
面试场景：能立刻说出「这是卡特兰数」是加分项，DP 递推是保底
```

### 4.2 完整代码

```java
/**
 * LeetCode 96. 不同的二叉搜索树（DP 递推，等价于卡特兰）
 */
public int numTrees(int n) {
    long[] dp = new long[n + 1];
    dp[0] = 1;                                  // 空树
    for (int i = 1; i <= n; i++) {
        for (int k = 0; k < i; k++) {
            dp[i] += dp[k] * dp[i - 1 - k];     // 左 k 个 + 右 i-1-k 个
        }
    }
    return (int) dp[n];
}
// 复杂度 O(n²)；面试必答："选任意节点为根，左右子树规模决定子问题，
//   递推形态 dp[i]=Σdp[k]·dp[i-1-k] 就是卡特兰数的卷积递推；
//   节点只论个数不论值（BST 性质保证结构唯一对应），所以答案与数值无关。"

/**
 * 卡特兰公式版：Cat(n) = C(2n, n)/(n+1)，先算组合数再除
 */
public int numTreesCatalan(int n) {
    long c = 1;                                 // C(2n, 0)
    for (int i = 1; i <= n; i++) {
        c = c * (n + i) / i;                    // C(2n, n) 逐项乘除
    }
    return (int) (c / (n + 1));                 // 卡特兰通项式
}
// 推演 n=3：C(6,3)=20 → 20/4 = 5 ✓（3 节点的 BST 确实 5 种）
// ⚠️ 若模数恰好整除 n+1，通项式会失效 → 改用差分式 C(2n,n)-C(2n,n+1)（见 01 篇 3.4）
```

## 5. P2822 组合数问题（杨辉 + 二维前缀和）

### 5.1 题目与思路

```text
给定 k 与 t 组询问 (n, m)，问 0 ≤ i ≤ n, 0 ≤ j ≤ min(i, m) 中 k | C(i,j) 的个数
n, m ≤ 2000，k ≤ 21（2017 NOIP 提高组 D1T2），t ≤ 10⁴
套路固定：① 杨辉三角 mod k 预处理（判定整除）；② 二维前缀和 O(1) 回答
⚠️ 边界：j 的上界是 min(i, m)，前缀和只统计合法 j；C(i,j) 中 j > i 时按 0 处理
```

### 5.2 完整代码

```java
/**
 * 洛谷 P2822 组合数问题（杨辉 + 二维前缀和）
 * C[i][j] = C[i][j] mod k 是否为 0；pre[i][j] 为左上矩形内满足条件的个数
 */
public void solve(int k, int[][] queries) {
    int MAX = 2000;
    int[][] C = new int[MAX + 1][MAX + 1];
    int[][] pre = new int[MAX + 1][MAX + 1];
    C[0][0] = 1 % k;
    for (int i = 1; i <= MAX; i++) {
        C[i][0] = C[i][i] = 1 % k;
        for (int j = 1; j < i; j++) {
            C[i][j] = (C[i - 1][j] + C[i - 1][j - 1]) % k;   // 只存 mod k 值即可判整除
        }
    }
    for (int i = 1; i <= MAX; i++) {
        for (int j = 1; j <= i; j++) {                       // j > i 的组合数恒 0，无需统计
            pre[i][j] = pre[i - 1][j] + pre[i][j - 1] - pre[i - 1][j - 1]
                        + (C[i][j] == 0 ? 1 : 0);
        }
    }
    // 查询：Σ_{i≤n, j≤min(i,m)} → 直接查 pre[n][min(n,m)]（j 上限取 min(i,m) 由 pre 结构保证）
    for (int[] q : queries) {
        int n = q[0], m = q[1];
        // 对每个 i ≤ n，j 有效上界 min(i, m) —— 逐行累加最稳妥
        int ans = 0;
        for (int i = 1; i <= n; i++) {
            ans += pre[i][Math.min(i, m)];                   // pre[i][j] 行内前缀
        }
        System.out.println(ans);
    }
}
// 复杂度：预处理 O(2000²) + 每组 O(n)；面试必答："k 整除判定 = C mod k 为 0，
//   杨辉三角边模边存 + 前缀和压掉重复查询；j 的三角区域（j ≤ i）要小心边界。"
```

## 6. P3807 【模板】Lucas 定理

### 6.1 题目与思路

```text
t 组询问 C(n,m) mod p（n, m ≤ 10¹⁸，p ≤ 10⁵ 为质数）
Lucas：C(n,m) ≡ C(n%p, m%p)·C(n/p, m/p) (mod p)
阶乘表只开 p 大小（p ≤ 10⁵），递归深度 log_p n ≤ 60
⚠️ C(n%p, m%p) 内部判 m > n 返回 0
```

### 6.2 完整代码

```java
/**
 * 洛谷 P3807 【模板】Lucas 定理（建表 + 递归 + 快速幂逆元）
 */
public class P3807 {
    private static long[] fac, invfac;
    private static long p;

    public static long C(int n, int m) {
        if (m < 0 || m > n) return 0;
        return fac[n] * invfac[m] % p * invfac[n - m] % p;
    }

    public static long lucas(long n, long m) {
        if (m == 0) return 1;
        return C((int) (n % p), (int) (m % p)) * lucas(n / p, m / p) % p;
    }

    public static void main(String[] args) throws Exception {
        java.io.BufferedReader br = new java.io.BufferedReader(new java.io.InputStreamReader(System.in));
        int t = Integer.parseInt(br.readLine());
        while (t-- > 0) {
            String[] s = br.readLine().split(" ");
            long n = Long.parseLong(s[0]);
            long m = Long.parseLong(s[1]);
            p = Long.parseLong(s[2]);
            fac = new long[(int) p];                         // ⚠️ 表只开到 p
            invfac = new long[(int) p];
            fac[0] = 1;
            for (int i = 1; i < p; i++) fac[i] = fac[i - 1] * i % p;
            invfac[(int) p - 1] = qpow(fac[(int) p - 1], p - 2);   // 一次快速幂 + 倒推
            for (int i = (int) p - 1; i >= 1; i--) invfac[i - 1] = invfac[i] * i % p;
            System.out.println(lucas(n, m));
        }
    }

    private static long qpow(long a, long b) {
        long res = 1 % p;
        a %= p;
        while (b > 0) {
            if ((b & 1) == 1) res = res * a % p;
            a = a * a % p;
            b >>= 1;
        }
        return res;
    }
}
// 复杂度 O(p + log_p n) 每组；面试必答："n, m 巨大而 p 小 → 阶乘表只够开到 p-1，
//   所以必须 Lucas 拆位；低位 C(n%p,m%p) 若 m%p > n%p 返回 0，别把 m、n 换掉。"
```

## 7. P1044 栈（卡特兰数模板）

### 7.1 题目与思路

```text
n 个元素（1..n）按序入栈，问合法出栈序列数（n ≤ 18）
答案 = Cat(n)：入栈/出栈 → 左右括号，任意前缀入栈数 ≥ 出栈数
n ≤ 18 → Cat(18) = 477638700 入 int，直接整数递推/公式，不需要模数
```

### 7.2 完整代码

```java
/**
 * 洛谷 P1044 栈（卡特兰数，n ≤ 18 无需取模）
 */
public long stackCount(int n) {
    long[] cat = new long[n + 1];
    cat[0] = 1;
    for (int i = 1; i <= n; i++) {
        cat[i] = cat[i - 1] * 2 * (2 * i - 1) / (i + 1);     // 线性递推 (4n-2)/(n+1)
    }
    return cat[n];
}
// 推演 n=3：cat[1]=1·2·1/2=1，cat[2]=1·2·3/3=2，cat[3]=2·2·5/4=5 ✓
// 面试必答："出栈序列 = 括号序列双射：把入栈当左括号、出栈当右括号，
//   任意前缀左 ≥ 右 ⟺ 栈不空 ⟺ 合法；这就是卡特兰数的识别信号。"
```

## 8. P5431 乘法逆元 2（批量逆元）

### 8.1 题目与思路

```text
n 个正整数 a[1..n] 与 k，求 Σ k^i·a[i]⁻¹ mod p（n ≤ 5×10⁶，p 为质数，时限紧）
逐个快速幂 O(n log p) 必超时 → 前缀积 + 一次快速幂 O(n + log p)
最终求和用霍纳逆序折叠 k 的幂，避免单独维护 k^i
⚠️ 必须快读；s[n] ≡ 0 时无解（说明某个 a[i] ≡ 0 mod p）
```

### 8.2 完整代码

```java
/**
 * 洛谷 P5431 乘法逆元 2（前缀积批量逆元 + 霍纳求和）
 * 思路：s[i]=Πa[1..i]；对 s[n] 做一次费马求逆；
 *       a[i]⁻¹ = s[i-1]·invS[i]；invS[i-1] = invS[i]·a[i] 倒推
 */
public long solve(long[] a, long k, long p) {
    int n = a.length - 1;                      // a[1..n]
    long[] s = new long[n + 1], invS = new long[n + 1];
    s[0] = 1;
    for (int i = 1; i <= n; i++) s[i] = s[i - 1] * (a[i] % p) % p;
    invS[n] = qpow(s[n], p - 2, p);            // ⚠️ 全程唯一一次快速幂
    long ans = 0;
    for (int i = n; i >= 1; i--) {
        long invA = invS[i] * s[i - 1] % p;    // a[i]⁻¹
        invS[i - 1] = invS[i] * (a[i] % p) % p;
        ans = (ans + invA) * k % p;            // 霍纳：逆序累乘 k，i 项自然获得 k^i 权重
    }
    return ans;
}

private long qpow(long a, long b, long p) {
    long res = 1 % p;
    a %= p;
    while (b > 0) {
        if ((b & 1) == 1) res = res * a % p;
        a = a * a % p;
        b >>= 1;
    }
    return res;
}
// 复杂度 O(n + log p)；面试必答："批量逆元把 n 次快速幂压成 1 次：
//   前缀积求整、倒推还原单点逆元；霍纳折叠让 k 的幂随循环自然累乘。
//   这是组合数/概率期望题求逆元时的性能底线。"
```


| 模数非质数求单点逆元 | exgcd / 欧拉定理 | 「exgcd」专题 01 |

### 10.2 四步解题法（面试口述）

```text
① 规模：n, m 多大？（决定杨辉 / 阶乘逆元 / Lucas / exLucas）
② 模数：质数？合数？（决定费马 / 欧拉 / exgcd / 提因子）
③ 计数结构：前缀约束？（卡特兰）隔板？（球盒）超量？（容斥）
④ 套模板 + 检查四个坑：m > n 判 0 / 表开到 p-1 / 每步整除 / 批量只做一次快速幂
```
