## 1. 核心概念

### 1.1 组合数定义与性质

```text
C(n, m) = n! / (m! × (n-m)!)     ← 从 n 个取 m 个的方案数
性质（面试速查）：
  C(n, 0) = C(n, n) = 1
  C(n, m) = C(n, n-m)                   对称性
  C(n, m) = C(n-1, m) + C(n-1, m-1)     杨辉递推（加法原理）
  C(n, m) = n/m × C(n-1, m-1)           递推约分
  Σ C(n, k) = 2^n                       二项式定理（全体子集）
  范德蒙德恒等式：Σ C(a,k)C(b,n-k) = C(a+b,n)

二项式定理：(x+y)^n = Σ C(n,k)·x^k·y^(n-k)
```

### 1.2 为什么要逆元（取模除法的困境）

```text
C(n,m) 的数值巨大（C(100,50) ≈ 10^29）→ 必须取模
但 (a/b) mod p ≠ (a mod p)/(b mod p)！
  → 除法在模意义下没有定义 → 转化为乘法：
      a/b ≡ a × b⁻¹ (mod p)，b⁻¹ 是 b 的乘法逆元
  → 组合数取模 = 阶乘取模 × 逆元取模

逆元定义：a × a⁻¹ ≡ 1 (mod p)
存在条件：gcd(a, p) = 1（互质）
```

### 1.3 组合数求法选型（核心决策表）

```text
n, m 小（≤ 10³）→ 杨辉三角递推 O(n²) 预处理 O(1) 查询
n, m 中等（≤ 10⁶）+ p 质数 → 阶乘 + 逆元 O(n) 预处理 O(1) 查询
n, m 巨大（10^18）+ p 小质数 → Lucas 定理 O(p + log n)
p 为任意合数 → exLucas / Lucas + CRT
```

## 2. 组合数四种求法

### 2.1 杨辉三角（递推，无模数限制）

```java
/**
 * 杨辉三角预处理：C(n,m) = C(n-1,m) + C(n-1,m-1)
 * 适用 n ≤ 10³；⚠️ 对模数 p 无要求（纯加法）
 */
public long[][] pascal(int n, long p) {
    long[][] C = new long[n + 1][n + 1];
    for (int i = 0; i <= n; i++) {
        C[i][0] = C[i][i] = 1;
        for (int j = 1; j < i; j++) {
            C[i][j] = (C[i-1][j] + C[i-1][j-1]) % p;
        }
    }
    return C;
}
// 空间可滚到一维：C[j] = (C[j] + C[j-1]) % p（⚠️ 倒序）
```

### 2.2 阶乘 + 逆元（默认首选，p 为质数）

```java
/**
 * 组合数预处理：fac / invfac → C(n,m) O(1) 查询
 * 适用 n ≤ 10⁶，p 为质数（1e9+7）
 */
public class Comb {
    private final long[] fac, invfac;
    private final long p;

    public Comb(int n, long p) {
        this.p = p;
        fac = new long[n + 1];
        invfac = new long[n + 1];
        fac[0] = 1;
        for (int i = 1; i <= n; i++) fac[i] = fac[i - 1] * i % p;
        invfac[n] = quickPow(fac[n], p - 2, p);   // ⚠️ 只算一次快速幂
        for (int i = n; i >= 1; i--) {
            invfac[i - 1] = invfac[i] * i % p;    // 倒推
        }
    }

    public long C(int n, int m) {
        if (m < 0 || m > n) return 0;
        return fac[n] * invfac[m] % p * invfac[n - m] % p;
    }
}
// 复杂度 O(n + log p) 预处理，O(1) 查询
```

### 2.3 Lucas 定理（n, m 巨大，p 小质数）

```java
/**
 * Lucas：C(n,m) ≡ C(n%p, m%p) × C(n/p, m/p) (mod p)
 * 适用 n, m ≤ 10^18，p ≤ 10^5 质数
 */
public long lucas(long n, long m, long p, Comb comb) {
    if (m == 0) return 1;
    // 递归：C(n%p, m%p) × lucas(n/p, m/p)
    return comb.C((int)(n % p), (int)(m % p))
         * lucas(n / p, m / p, p, comb) % p;
}
// 复杂度 O(p + log_p n)
// ⚠️ comb.C 内部查表也要用模 p 的阶乘表（预处理到 p-1）
// 特例 p=2：C(n,m) ≡ 1 (mod 2) ⟺ m 的二进制位都是 n 的 1 位子集
```

### 2.4 扩展 Lucas（p 为合数，简述）

```text
p 任意合数时：
  ① 分解 p = Π pᵢ^cᵢ
  ② 对每个 pᵢ^cᵢ 分别求 C(n,m) mod pᵢ^cᵢ
     （阶乘分段：pᵢ 的幂提出来单独计数 + 剩余部分按循环节快速幂）
  ③ CRT 合并（中国剩余定理，exgcd 实现）
复杂度 O(max pᵢ^cᵢ)；面试说出思路即可，不要求手写
```

## 3. 逆元体系

### 3.1 三种求法对比

| 方法 | 条件 | 复杂度 | 场景 |
|------|------|:---:|------|
| 费马小定理 a^(p-2) | p 质数 | O(log p) | 单点求逆 |
| exgcd | gcd(a,p)=1 | O(log p) | 模数非质数 |
| 线性递推 | p 质数 | O(n) | 批量 1..n |
| 阶乘逆元倒推 | p 质数 | O(n) | 组合数 |

```java
/**
 * 线性递推求逆元：inv[i] = (p - p/i) · inv[p % i] % p
 * 推导：p = k·i + r → k·i ≡ -r → i⁻¹ ≡ -k·r⁻¹
 */
public long[] invAll(int n, long p) {
    long[] inv = new long[n + 1];
    inv[1] = 1;
    for (int i = 2; i <= n; i++) {
        inv[i] = (p - p / i) % p * inv[(int) (p % i)] % p;
    }
    return inv;
}
```

### 3.2 分数取模（工程高频）

```text
(a / b) mod p = a × b⁻¹ mod p
  例：(1/2) mod 1e9+7 = 1 × 2^(1e9+5) mod 1e9+7 = 5e8+4
  → 组合数、概率期望题的标准操作

⚠️ 分子分母都先取模；b 与 p 必须互质
  1e9+7 为质数 → 任何 1 ≤ b < p 安全
```

## 4. 卡特兰数速查

```text
定义：Catₙ = C(2n, n) / (n+1) = C(2n, n) - C(2n, n+1)
前几项：1, 1, 2, 5, 14, 42, 132, 429（Cat₀=1 起）
递推：Catₙ = Σ_{k=0}^{n-1} Catₖ·Catₙ₋₁₋ₖ（卷积形式）

应用场景（识别信号！）：
  · 出栈序列数（n 个元素进栈，合法出栈顺序）
  · 括号匹配数（n 对括号的合法序列）
  · 凸多边形三角划分
  · n 个节点的二叉搜索树形态数
  · 不越过对角线的路径（y ≤ x 约束）
  · 二叉树形态数（含满二叉树变体）

卡特兰取模：Catₙ = C(2n,n)·(n+1)⁻¹ → 逆元
  或递推 Catₙ = Catₙ₋₁ · 2(2n-1)/(n+1)
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"组合数取模先看数据范围：
 n ≤ 10³ 用杨辉三角；n ≤ 10⁶ + 质数模用阶乘逆元；
 n 巨大 + 小质数模用 Lucas。
 逆元是取模除法的桥梁：费马（质数模）、exgcd（任意模）。
 卡特兰数识别信号是'任何时候前缀都不越界'的计数问题。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 为什么需要逆元？ | 模意义下除法无定义，(a/b)%p ≠ (a%p)/(b%p) |
| 2 | 逆元存在条件？ | gcd(a, p) = 1；p 质数时非 0 元素都有 |
| 3 | 三种逆元怎么选？ | 单点费马/任意模 exgcd/批量线性递推 |
| 4 | 阶乘逆元为什么倒推？ | invfac[i-1] = invfac[i]·i，只需 1 次快速幂 |
| 5 | Lucas 适用条件？ | n, m 巨大 + p 小质数（阶乘表只能开到 p） |
| 6 | 卡特兰识别信号？ | "任何时刻 A ≥ B"（出栈/括号/路径/树） |
| 7 | C(n,m) = 0 的情况？ | m < 0 或 m > n；Lucas 中 m%p > n%p 时 C=0 |
| 8 | 组合数性质常考？ | 对称性、杨辉递推、ΣC(n,k)=2ⁿ、范德蒙德 |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 直接用除法取模 | 结果错（除不散） | 转逆元 |
| Lucas 阶乘表开到 n | 超空间 | 阶乘表只开到 p-1 |
| 一维杨辉正序滚 | 同一行内被重复使用 | 倒序更新 |
| 忘判 m > n | 数组越界/错误 | 先判 0 |
| invfac 全用快速幂算 | O(n log p) 超时 | 只算一次倒推 |
| 卡特兰用除法公式 | mod 下除不了 | C(2n,n)·(n+1)⁻¹ 或递推 |
| p 为合数用费马 | 逆元不存在/错误 | exgcd / exLucas |

> 🎯 **核心要点**：组合数 = **看数据范围选方法**（杨辉/阶乘逆元/Lucas/exLucas），逆元 = **看模数性质选工具**（费马/exgcd/递推），卡特兰 = **记识别信号**（前缀不越界）。三张决策表背熟，组合计数模块无死角。
