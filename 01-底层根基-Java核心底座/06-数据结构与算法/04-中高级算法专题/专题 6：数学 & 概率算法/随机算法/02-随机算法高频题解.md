## 1. 384. 打乱数组（Fisher-Yates）

### 1.1 题目与思路

```text
支持 reset()（恢复原数组）与 shuffle()（等概率返回排列）
Fisher-Yates 从后往前，i 与 [0, i] 随机交换
⚠️ 复制原数组存 reset；每个元素到任意位置概率 1/n
```

### 1.2 完整代码

```java
/**
 * LeetCode 384. 打乱数组
 */
class Solution {
    private final int[] original;
    private final Random rnd = new Random();

    public Solution(int[] nums) {
        original = nums.clone();
    }

    public int[] reset() {
        return original.clone();          // ⚠️ 返回副本，防外部修改
    }

    public int[] shuffle() {
        int[] arr = original.clone();
        for (int i = arr.length - 1; i > 0; i--) {
            int j = rnd.nextInt(i + 1);   // ⚠️ 0 ≤ j ≤ i（均匀关键）
            int t = arr[i]; arr[i] = arr[j]; arr[j] = t;
        }
        return arr;
    }
}
// 复杂度 O(n)；面试必答："从后往前，每个位置与随机前缀位置交换；
//   j 必须取 [0, i] 闭区间，否则最后一位概率不均。"
```

## 2. 382. 链表随机节点（蓄水池 k=1）

### 2.1 题目与思路

```text
单链表（未知长度），等概率返回一个节点值
蓄水池 k=1：第 i 个节点以 1/i 概率成为答案
⚠️ 只能遍历一次（链表不能随机访问）
```

### 2.2 完整代码

```java
/**
 * LeetCode 382. 链表随机节点（蓄水池 k=1）
 */
class Solution {
    private final ListNode head;
    private final Random rnd = new Random();

    public Solution(ListNode head) { this.head = head; }

    public int getRandom() {
        ListNode cur = head;
        int ans = cur.val, i = 1;
        while (cur != null) {
            if (rnd.nextInt(i) == 0) ans = cur.val;  // ⚠️ 1/i 概率选中
            i++;
            cur = cur.next;
        }
        return ans;
    }
}
// 证明：第 k 个节点最终被选中 = 1/k × Π_{i>k} (i-1)/i = 1/n
// 面试必答："未知长度 + 只能遍历一次 → 蓄水池；
//   k=1 时每步以 1/i 概率替换答案，最终每个节点 1/n。"
```

## 3. 398. 随机数索引（蓄水池变体）

### 3.1 题目与思路

```text
数组中可能有重复值，等概率返回 target 的一个下标
朴素：遍历收集所有下标 → O(n) 空间
蓄水池版：遍历时对每个 = target 的位置以 1/cnt 概率选中
→ O(1) 空间
```

### 3.2 完整代码

```java
/**
 * LeetCode 398. 随机数索引（蓄水池，O(1) 空间）
 */
class Solution {
    private final int[] nums;
    private final Random rnd = new Random();

    public Solution(int[] nums) { this.nums = nums; }

    public int pick(int target) {
        int ans = -1, cnt = 0;
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] == target) {
                cnt++;
                if (rnd.nextInt(cnt) == 0) ans = i;  // 1/cnt 概率选中
            }
        }
        return ans;
    }
}
// 推演 nums=[1,2,3,3,3], target=3：
//   下标 2,3,4 依次以 1/1, 1/2, 1/3 概率成为答案 → 各 1/3 ✓
// 面试必答："与 382 同源——只对命中元素计数，
//   第 cnt 个命中者以 1/cnt 概率替换答案。"
```

## 4. 470. 用 Rand7 实现 Rand10（拒绝采样）

### 4.1 题目与思路

```text
用均匀 Rand7 实现均匀 Rand10
① 两次 Rand7 → (a-1)*7 + (b-1) ∈ [0, 48]（均匀 49 个值）
② 拒绝 ≥ 40 的结果（10 的倍数边界）：取 1..40 → %10 + 1
⚠️ 拒绝的概率 = 9/49，期望重试次数 = 49/40 ≈ 1.2 → 期望 O(1)
```

### 4.2 完整代码

```java
/**
 * LeetCode 470. 用 Rand7 实现 Rand10（拒绝采样）
 */
public int rand10() {
    while (true) {
        int v = (rand7() - 1) * 7 + (rand7() - 1);   // 均匀 [0, 48]
        if (v < 40) return v % 10 + 1;               // 拒绝 [40, 48]
    }
}
// 均匀性证明：49 个值均匀 → 每个 v < 40 等概率 1/49
//   → 每个 1..10 出现 4 次 → 均匀 ✓
// 期望调用次数：2 × 49/40 ≈ 2.45 次 Rand7
// 面试必答："拒绝采样：构造均匀超集 → 取模映射 → 拒绝尾部
//   保证均匀；拒绝概率固定 → 期望采样次数常数。"
```

## 5. 528. 按权重随机选择（前缀和 + 二分）

### 5.1 题目与思路

```text
按权重 w 随机返回下标：P(i) = w[i] / Σw
前缀和数组 pre[i] = Σw[0..i-1] → 随机 x ∈ [1, Σw]
二分找第一个 pre[i] ≥ x → 返回 i
⚠️ 预处理 O(n)，查询 O(log n)
```

### 5.2 完整代码

```java
/**
 * LeetCode 528. 按权重随机选择（前缀和 + 二分）
 */
class Solution {
    private final int[] pre;                 // pre[i] = Σw[0..i-1]
    private final int total;
    private final Random rnd = new Random();

    public Solution(int[] w) {
        pre = new int[w.length];
        pre[0] = w[0];
        for (int i = 1; i < w.length; i++) pre[i] = pre[i - 1] + w[i];
        total = pre[w.length - 1];
    }

    public int pickIndex() {
        int x = rnd.nextInt(total) + 1;      // ⚠️ [1, total] 闭区间
        // 二分：第一个 pre[i] ≥ x（左边界）
        int l = 0, r = pre.length - 1;
        while (l < r) {
            int mid = (l + r) >> 1;
            if (pre[mid] >= x) r = mid;
            else l = mid + 1;
        }
        return l;
    }
}
// 推演 w=[1,3]：pre=[1,4]，total=4
//   x=1 → pre[0]=1 ≥ 1 → 0；x=2,3,4 → 1
//   → P(0)=1/4, P(1)=3/4 ✓
// 面试必答："权重随机 = 把概率摊到数轴上，
//   前缀和二分定位；进阶 O(1) 查询用别名采样（见 01 模块 5.4）。"
```

## 6. 710. 黑名单中的随机数（映射法）

### 6.1 题目与思路

```text
在 [0, n) 中等概率返回一个不在黑名单的数字
n 大（10^9）、黑名单 m 小 → 不能开数组
映射法：把 [0, n-m) 作为"白名单区"，黑名单映射到尾部
① 合法区 [0, bound)，bound = n - m
② 黑名单中 < bound 的数字 → 映射到尾部未被占用的数
③ 随机 [0, bound) → 若命中黑名单 → 取映射；否则直接用
⚠️ 黑名单中的 ≥ bound 数字天然不在合法区，无需处理
```

### 6.2 完整代码

```java
/**
 * LeetCode 710. 黑名单中的随机数（映射法）
 */
class Solution {
    private final int bound;
    private final Map<Integer, Integer> map = new HashMap<>();
    private final Random rnd = new Random();

    public Solution(int n, int[] blacklist) {
        bound = n - blacklist.length;
        Set<Integer> black = new HashSet<>();
        for (int b : blacklist) if (b >= bound) black.add(b);

        // 尾部可用的候选（从 bound 往后找不在黑名单的数）
        int tail = bound;
        for (int b : blacklist) {
            if (b < bound) {                 // ⚠️ 只映射合法区内的黑名单
                while (black.contains(tail)) tail++;   // 找尾部空白位
                map.put(b, tail++);
            }
        }
    }

    public int pick() {
        int x = rnd.nextInt(bound);
        return map.getOrDefault(x, x);       // 命中黑名单 → 走映射
    }
}
// 复杂度 O(m) 预处理 + O(1) 查询
// 面试必答："黑名单映射 = 压缩合法空间：
//   黑名单内 < bound 的映射到尾部空白，随机只落在 [0, bound)。"
```

### 7.2 五步解题法（面试口述）

```text
① 识别场景：打乱/抽样/权重/映射/拒绝
② 选武器：洗牌→FY；流→蓄水池；权重→前缀和；黑名单→映射
③ 写随机核心：j = nextInt(i+1)、1/cnt、v % 10 等
④ 均匀性自查：每个候选是否等概率（条件概率连乘）
⑤ 边界：闭区间、拒绝尾部、映射冲突
```

### 7.3 一句话考点清单

```text
Fisher-Yates：j = nextInt(i+1)，概率 1/n —— 必背
蓄水池：第 i 个 1/i 概率（k=1）/ k/i（k 元）—— 必背
拒绝采样：均匀超集 + 拒绝尾部，期望常数 —— 必背
权重随机：前缀和二分 O(log n) —— 必背
映射法：黑名单 → 尾部空白，随机只在合法区 —— 进阶
均匀性三证：条件概率 / 归纳 / 排列计数 —— 加分
```

> 🎯 **核心要点**：七道母题 = 随机算法四大范式（洗牌/抽样/拒绝/映射）。面试高频顺序：384 → 382/398 → 470 → 528；每道题都能延伸「概率相等证明」。写完自查三点：**闭区间 i+1、1/cnt 计数、拒绝边界**——随机算法题的坑全在这。
