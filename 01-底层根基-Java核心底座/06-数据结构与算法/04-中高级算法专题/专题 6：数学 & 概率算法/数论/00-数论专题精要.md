## 1. 核心概念

### 1.1 数论是什么

> 数论：研究整数性质的数学分支。算法面试中常用部分：**素数、最大公约数（gcd）、同余取模、质因数分解**。

```
核心概念速查：
  素数：>1 且只有 1 和自身两个因子
  合数：>1 且非素数
  互质：gcd(a,b) = 1
  整除：a | b ⇔ b % a == 0
  同余：a ≡ b (mod m) ⇔ (a-b) % m == 0
  质因数分解：n = p1^a1 × p2^a2 × ...
```

### 1.2 三大模块

```
① 素数判定/筛选
  单个数判定：试除到 √n → O(√n)
  批量筛选：埃氏筛 O(n log log n)、线性筛 O(n)

② 最大公约数
  欧几里得（辗转相除）：gcd(a,b) = gcd(b, a%b)
  扩展欧几里得：解 ax+by=gcd(a,b)（竞赛级）

③ 快速幂/取模
  二分指数：a^b 用二进制分解指数 → O(log b)
  取模规则：(a×b) % m = (a%m × b%m) % m
```

### 1.3 常用结论（面试速查）

```
① 任何数最多有一个大于 √n 的质因子
   （分解时只需试除到 √n）
② 质数个数（n 以内）≈ n / ln(n)（素数定理）
③ 完全平方数有奇数个因子（319 灯泡开关）
④ 水壶问题（365）：能倒出的量 = gcd 的倍数
⑤ n 以内质数：埃氏筛打表
⑥ 大数幂取模：快速幂（指数二进制分解）
```

## 2. 完整代码模板

### 2.1 素数判定（单个数）

```java
/**
 * 素数判定：试除到 √n
 * O(√n) 时间 O(1) 空间
 */
public boolean isPrime(int n) {
    if (n < 2) return false;
    // ⚠️ 只需到 √n（i*i <= n，防 i*i 溢出用 long）
    for (int i = 2; (long) i * i <= n; i++) {
        if (n % i == 0) return false;   // 找到因子 → 合数
    }
    return true;
}
// 为什么到 √n 就够？
//   n = a×b 且 a ≤ b → a ≤ √n
//   找到小因子 a 即证明合数 → 无需超过 √n
```

### 2.2 埃氏筛（批量素数）

```java
/**
 * 埃氏筛：O(n log log n) 求 [0, n) 内所有素数
 * 思想：从 2 开始，把每个素数的倍数标记为合数
 */
public int countPrimes(int n) {
    if (n <= 2) return 0;
    boolean[] isComposite = new boolean[n];   // 默认 false（素数）
    int count = 0;

    for (int i = 2; i < n; i++) {
        if (!isComposite[i]) {                // i 是素数
            count++;
            // ⚠️ 从 i*i 开始筛（i 的更小倍数已被更小素数筛过）
            if ((long) i * i < n) {
                for (long j = (long) i * i; j < n; j += i) {
                    isComposite[(int) j] = true;
                }
            }
        }
    }
    return count;
}
// 从 i² 开始的原因：
//   i 的倍数 k×i（k < i）已被素数 k 筛过
//   例：6 = 2×3 在 i=2 时筛过；i=3 从 9 开始
//   → 避免重复标记

/**
 * 线性筛（O(n)，面试了解）：
 * 每个合数只被最小质因子筛一次
 * 埃氏筛对面试已足够，线性筛是进阶展示
 */
```

### 2.3 gcd（欧几里得）

```java
/**
 * 最大公约数：辗转相除 O(log min(a,b))
 */
public int gcd(int a, int b) {
    return b == 0 ? a : gcd(b, a % b);
}

// 最小公倍数：lcm(a,b) = a / gcd(a,b) * b
//   ⚠️ 先除后乘防溢出
public long lcm(long a, long b) {
    return a / gcd(a, b) * b;
}
// 推演 gcd(48, 36)：
//   gcd(36, 12) → gcd(12, 0) → 12 ✓
// 48 = 2⁴×3，36 = 2²×3² → 公约部分 2²×3 = 12 ✓
```

### 2.4 快速幂

```java
/**
 * 快速幂：a^b % mod，指数二进制分解 → O(log b)
 */
public long quickPow(long a, long b, long mod) {
    long result = 1;
    a %= mod;                             // ⚠️ 先取模

    while (b > 0) {
        if ((b & 1) == 1) {               // 当前二进制位为 1
            result = result * a % mod;    // 乘入结果
        }
        a = a * a % mod;                  // 平方递进
        b >>= 1;                          // 下一位
    }
    return result;
}
// 推演 2^10：10 = 1010₂
//   位 0（0）：a=2²=4
//   位 1（1）：result=4；a=4²=16
//   位 2（0）：a=16²=256
//   位 3（1）：result=4×256=1024 ✓
// 2^10 = 2^8 × 2^2 = 256 × 4 = 1024 ✓
```

## 3. 三大模板详解

### 3.1 质因数分解

```java
/**
 * 质因数分解：试除到 √n
 * 每个数最多一个 > √n 的质因子（结论①）
 */
public List<Integer> primeFactors(int n) {
    List<Integer> factors = new ArrayList<>();

    // ① 试除 2（唯一偶素数）
    while (n % 2 == 0) {
        factors.add(2);
        n /= 2;
    }

    // ② 试除奇数
    for (int i = 3; (long) i * i <= n; i += 2) {
        while (n % i == 0) {
            factors.add(i);
            n /= i;
        }
    }

    // ③ ⚠️ 剩余 n > 1 → 是最大质因子
    if (n > 1) factors.add(n);
    return factors;
}
// 推演 n = 84：84 = 2²×3×7
//   试 2：84/2=42, 42/2=21 → [2,2]
//   试 3：21/3=7 → [2,2,3]
//   i=5 时 25>7 停止；剩余 7 > 1 → [2,2,3,7] ✓
```

### 3.2 取模运算的注意事项

```
⚠️ Java 负数取模：
  -3 % 5 = -3（结果与被除数同号）！
  需要正模：((x % mod) + mod) % mod

⚠️ 溢出防护：
  乘法用 long：a * b % mod（先乘可能溢出 int）
  大数场景：BigInteger 或快速幂

⚠️ 模运算的交换性：
  (a + b) % m = (a%m + b%m) % m
  (a × b) % m = (a%m × b%m) % m
  → 可以分步取模（防溢出）
```

### 3.3 水壶问题（gcd 应用）

```java
/**
 * LeetCode 365. 水壶问题
 * 两个容量 x、y 的水壶，能否量出 z 升？
 *
 * 数学结论（贝祖定理）：
 *   z 能倒出 ⇔ z 是 gcd(x,y) 的倍数 且 z ≤ x+y
 *   贝祖：ax + by = z 有整数解 ⇔ gcd(x,y) | z
 *   实际操作等价于"倒来倒去 = ax + by"
 */
public boolean canMeasureWater(int x, int y, int z) {
    if (x + y < z) return false;
    if (x == 0 || y == 0) return z == 0 || z == x + y;
    return z % gcd(x, y) == 0;
}
```

### 4.2 172 阶乘后的零（因子计数）

```java
/**
 * LeetCode 172. 阶乘后的零
 * 10 = 2×5，因子 2 永远够 → 零的个数 = 因子 5 的个数
 * n! 中因子 5 的个数 = Σ n/5^k
 */
public int trailingZeroes(int n) {
    int count = 0;
    while (n > 0) {
        n /= 5;              // 5 的倍数贡献 1 个，25 的倍数再贡献...
        count += n;
    }
    return count;
}
// n=25：25/5=5 + 5/5=1 → 6 ✓
// （25! 中：5,10,15,20 各 1 个 + 25 贡献 2 个 = 6）
```

### 4.3 最大公约数在算法中的角色

```
① 分数化简：分子分母同除 gcd
② 斜率防浮点：dx/gcd, dy/gcd（149 直线上最多点）
③ 水壶/测量问题：贝祖定理
④ 字符串 gcd（1071）：两字符串长度的 gcd 相关
⑤ 扩展欧几里得：逆元计算（组合数学取模）

⚠️ 斜率分数的关键细节（149 题）：
  符号统一（dx 恒正）+ 垂直/水平特判
  例：1/2 和 2/4 → gcd 约分后都是 "1,2"
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"素数筛选用埃氏筛：从 2 开始，
 把每个素数的倍数标记为合数，
 从 i² 开始避免重复标记。
 O(n log log n) 时间 O(n) 空间。
 gcd 用欧几里得辗转相除，O(log n)。
 大数幂取模用快速幂——指数二进制分解，
 每步平方递进，O(log b)。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 为什么试除到 √n？ | n=a×b 且 a≤b → a≤√n；找到小因子即合数 |
| 2 | 埃氏筛为什么从 i² 开始？ | i 的更小倍数被更小素数筛过（避免重复） |
| 3 | gcd 复杂度？ | 欧几里得 O(log min(a,b))（每次至少减半） |
| 4 | 快速幂原理？ | 指数二进制分解：a^13 = a^8×a^4×a^1，每步平方 |
| 5 | 负数取模？ | Java % 与被除数同号 → ((x%m)+m)%m |
| 6 | 大数幂溢出？ | long 中间值 + 分步取模 |
| 7 | gcd 的应用？ | 约分/斜率分数/水壶/贝祖定理 |
| 8 | 阶乘后零的规律？ | 10=2×5，因子 5 计数 Σ n/5^k |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 试除到 n 不 √n | 超时 | (long)i*i <= n |
| 埃氏筛从 i 开始 | 重复标记 | 从 i² 开始 |
| 负数取模直接 % | 键错乱 | 加 mod 调整 |
| 乘法溢出 | 结果错 | long 或先取模 |
| gcd 递归方向反 | 死循环 | gcd(b, a%b) |

> 🎯 **核心要点**：数论三件套 = **埃氏筛**（批量素数，i² 起点）、**gcd**（辗转相除，O(log n)）、**快速幂**（二进制分解，O(log b)）。识别信号："素数、质因数、整除、公约数、大数幂"。取模防溢出与负数处理是两个必答细节。
