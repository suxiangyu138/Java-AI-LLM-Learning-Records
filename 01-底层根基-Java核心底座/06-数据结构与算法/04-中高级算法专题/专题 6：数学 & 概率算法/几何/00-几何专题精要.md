## 1. 核心概念

### 1.1 几何问题的本质

> 几何题 = **向量运算** + 数学性质。算法面试中的几何题通常不涉及高深几何，而是用**叉积/点积**解决共线、方向、距离问题。

```
核心工具：
  叉积（cross product）：判定三点方向/共线
  点积（dot product）：判定垂直/角度
  距离公式：欧氏/曼哈顿
  斜率：⚠️ 浮点问题 → 用分数（gcd 约分）代替

⚠️ 几何题最大的坑：浮点数精度
  斜率 1/3 和 2/6 用 double 比较可能不等
  → 用最简分数 (dx/gcd, dy/gcd) 或交叉相乘
```

### 1.2 叉积的应用

```
向量 ab = (x1, y1)，ac = (x2, y2)
cross = x1*y2 - y1*x2

cross > 0：ac 在 ab 逆时针方向
cross < 0：ac 在 ab 顺时针方向
cross = 0：三点共线（或两向量平行）

应用：
  ① 三点共线判定（149 直线上最多点）
  ② 点在直线哪一侧（凸包判断）
  ③ 凸包算法（587）的旋转方向判断
```

### 1.3 几何题分类

```
① 点/线关系：共线、同侧、距离（149）
② 凸包：围住所有点的最小多边形（587）
③ 几何构造：圆内随机点（478 拒绝采样）
④ 矩形/面积：重叠判断（836）、面积计算（223）

高频度：算法面试中几何题较少，了解核心工具即可
  面试定位：中等优先级（出现即拉开差距）
```

## 2. 完整代码模板

### 2.1 叉积模板

```java
/**
 * 叉积：判定三点方向关系
 * 返回 >0 逆时针 / <0 顺时针 / =0 共线
 * ⚠️ 用 long 防坐标相乘溢出
 */
public long cross(int[] p1, int[] p2, int[] p3) {
    long x1 = p2[0] - p1[0], y1 = p2[1] - p1[1];
    long x2 = p3[0] - p1[0], y2 = p3[1] - p1[1];
    return x1 * y2 - y1 * x2;
}

// 三点共线判定
public boolean isCollinear(int[] p1, int[] p2, int[] p3) {
    return cross(p1, p2, p3) == 0;
}
// 推演：(0,0), (1,1), (2,2)
//   x1=1,y1=1；x2=2,y2=2 → 1×2 - 1×2 = 0 → 共线 ✓
```

### 2.2 斜率防浮点（149 直线上最多点）

```java
/**
 * LeetCode 149. 直线上最多的点（几何题最高频）
 * 用"最简分数"表示斜率，避免 double 精度问题
 *
 * 思路：固定一个点，统计到其他点的斜率计数
 *   O(n²) 枚举固定点 × 斜率哈希
 */
public int maxPoints(int[][] points) {
    int n = points.length;
    if (n <= 2) return n;
    int maxCount = 0;

    for (int i = 0; i < n; i++) {
        Map<String, Integer> slopeCount = new HashMap<>();
        int same = 1;                    // 与固定点重合的点
        int curMax = 0;

        for (int j = i + 1; j < n; j++) {
            int dx = points[j][0] - points[i][0];
            int dy = points[j][1] - points[i][1];

            if (dx == 0 && dy == 0) {    // 重合点
                same++;
                continue;
            }

            String key = slopeKey(dx, dy);
            int count = slopeCount.merge(key, 1, Integer::sum);
            curMax = Math.max(curMax, count);
        }
        maxCount = Math.max(maxCount, curMax + same);
    }
    return maxCount;
}

// 斜率标准化：最简分数 + 符号统一
private String slopeKey(int dx, int dy) {
    int g = gcd(Math.abs(dx), Math.abs(dy));
    dx /= g;
    dy /= g;
    // ⚠️ 统一符号：dx 恒正（(1,2) 与 (-1,-2) 同斜率）
    if (dx < 0) { dx = -dx; dy = -dy; }
    if (dx == 0) return "0,1";           // 垂直线（dy 归一）
    if (dy == 0) return "1,0";           // 水平线
    return dx + "," + dy;
}

private int gcd(int a, int b) {
    return b == 0 ? a : gcd(b, a % b);
}
// 推演：点 (0,0), (1,2), (2,4)
//   (1,2) 斜率：dx=1, dy=2 → "1,2"
//   (2,4) 斜率：dx=2, dy=4 → gcd=2 → "1,2" ✓ 同斜率！
```

### 2.3 矩形重叠与面积

```java
/**
 * LeetCode 836. 矩形重叠
 * 判断两个矩形是否重叠（投影区间法）
 * 不重叠条件：一个在另一个的左边/右边/上边/下边
 */
public boolean isRectangleOverlap(int[] rec1, int[] rec2) {
    // rec = [x1, y1, x2, y2]
    // 不重叠 ⇔ 左右不重叠 或 上下不重叠
    return !(rec1[2] <= rec2[0]      // rec1 完全在 rec2 左边
          || rec2[2] <= rec1[0]      // rec1 完全在 rec2 右边
          || rec1[3] <= rec2[1]      // rec1 完全在 rec2 下边
          || rec2[3] <= rec1[1]);    // rec1 完全在 rec2 上边
}

/**
 * LeetCode 223. 矩形面积
 * 总面积 = 面积1 + 面积2 - 重叠面积
 */
public int computeArea(int ax1, int ay1, int ax2, int ay2,
                       int bx1, int by1, int bx2, int by2) {
    int area1 = (ax2 - ax1) * (ay2 - ay1);
    int area2 = (bx2 - bx1) * (by2 - by1);

    // 重叠矩形（交集）
    int overlapW = Math.min(ax2, bx2) - Math.max(ax1, bx1);
    int overlapH = Math.min(ay2, by2) - Math.max(ay1, by1);
    int overlap = (overlapW > 0 && overlapH > 0)
                ? overlapW * overlapH : 0;

    return area1 + area2 - overlap;    // 容斥
}
```

## 3. 浮点精度问题详解

### 3.1 为什么不能用 double 斜率

```
例：斜率 1/3（点 (0,0),(1,3)）与 2/6（点 (0,0),(2,6)）
  double 表示 1.0/3.0 可能为 0.3333333333333333
  2.0/6.0 同样 → 相等（运气好）
  但某些情况下：0.1+0.2 = 0.30000000000000004 ≠ 0.3
  → 哈希键比较不可靠！

正确方案：
  ① 最简分数对（gcd 约分）→ 整数键
  ② 交叉相乘比较（a/b == c/d ⇔ a×d == b×c）
  ③ 距离平方代替距离（免开方）
```

### 3.2 浮点问题清单

```
⚠️ 三种精度陷阱：
  ① 斜率/角度：分数对代替 double
  ② 距离比较：平方代替开方（欧氏距离）
  ③ 坐标相乘：int 溢出 → long

距离平方技巧（973 最接近原点）：
  dist² = x² + y²（免 Math.sqrt，比较大小不变）
  → 排序/堆直接用平方（更快更精确）
```

### 3.3 距离公式

```
欧氏距离：√((x1-x2)² + (y1-y2)²)
  比较用平方（免开方）

曼哈顿距离：|x1-x2| + |y1-y2|
  应用：1584 连接所有点最小费用

切比雪夫距离：max(|x1-x2|, |y1-y2|)
  应用：棋盘移动

⚠️ 面试先确认"哪种距离"（题目可能混用）
```

## 4. 几何题的常见模型

### 4.1 凸包（587 安装栅栏）

```
凸包：围住所有点的最小凸多边形

Andrew 单调链（推荐实现）：
  ① 按 (x, y) 排序
  ② 构建下凸包（叉积 ≤ 0 弹栈）
  ③ 构建上凸包（叉积 ≥ 0 弹栈）
  ④ 合并（去重端点）

复杂度 O(n log n)（排序主导）
面试定位：了解思路即可（很少要求手撕完整实现）

⚠️ 面试可讲核心："用叉积判断旋转方向，
  保持凸包上点按逆时针排列"
```

### 4.2 圆内随机点（478）

```
拒绝采样：正方形内随机 → 圆内接受
  接受概率 π/4 ≈ 78.5% → 期望 1.27 次

更优：极坐标（无拒绝）
  r = R × √rand（⚠️ 开方保证均匀）
  θ = 2π × rand
  为什么 √？面积均匀 → r² 均匀 → r = √(rand)

面试加分："拒绝采样简单；极坐标 O(1) 无拒绝更优"
```

### 4.3 几何与算法的结合

```
① 几何 + 排序：按角度/距离排序（凸包）
② 几何 + 哈希：斜率计数（149）
③ 几何 + 二分：点是否在多边形内（射线法）
④ 几何 + DP：最短路径（几何约束）

识别信号："坐标、点、线、面积、距离"
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"直线上最多点：固定一个点，计算其他点
 到它的斜率。斜率用最简分数 (dx/gcd, dy/gcd)
 表示避免浮点误差（1/3 和 2/6 是同一斜率），
 符号统一 dx 恒正。哈希表计数 → O(n²)。
 关键细节：重合点单独计数（same）。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 为什么用叉积不用斜率？ | 叉积整数精确无浮点误差；斜率除法有精度问题 |
| 2 | 浮点误差怎么彻底避免？ | 分数对（gcd 约分）+ 距离平方 + 交叉相乘 |
| 3 | 斜率为什么 dx 恒正？ | (1,2) 与 (-1,-2) 同斜率；统一符号才能哈希匹配 |
| 4 | 凸包实现思路？ | Andrew：排序 + 上下凸包 + 叉积判旋转方向 |
| 5 | 圆内随机为什么 √？ | 面积均匀 → r² 均匀 → r = √rand（不 √ 会聚中心） |
| 6 | 矩形重叠的判定？ | 不重叠四条件（左/右/上/下）取反 |
| 7 | 距离用平方？ | 比较大小不变 + 免开方精度损失 |
| 8 | 坐标溢出？ | 叉积/距离平方用 long |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| double 斜率做键 | 哈希匹配失败 | 分数对整数键 |
| 忘符号统一 | 斜率误判 | dx 恒正 |
| 叉积 int 溢出 | 结果错 | long |
| 重叠忘取反 | 判定相反 | 不重叠取反 |
| 随机点不 √ | 点聚中心 | r = R√rand |

> 🎯 **核心要点**：几何题 = **叉积判方向 + 分数防浮点 + 距离平方**三大工具。识别信号："共线、凸包、重叠、距离"。149（斜率分数）是最高频题，"防浮点"的表达是面试关键加分点。
