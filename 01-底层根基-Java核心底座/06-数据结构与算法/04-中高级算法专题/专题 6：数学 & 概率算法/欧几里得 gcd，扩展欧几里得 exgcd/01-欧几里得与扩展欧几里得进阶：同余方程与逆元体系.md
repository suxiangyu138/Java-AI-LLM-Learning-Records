## 1. gcd 算法体系与复杂度分析

### 1.1 三种 gcd 算法对比

| 算法 | 原理 | 复杂度 | 特点 |
|------|------|:---:|------|
| 辗转相除法（欧几里得） | gcd(a,b) = gcd(b, a%b) | O(log min(a,b)) | 默认首选 |
| 更相减损术 | gcd(a,b) = gcd(a-b, b) | O(max(a,b)) 最坏 | 减法简单但慢 |
| Stein 算法（移位） | 同时除 2 提因子 + 减 | O(log) 无除法 | 大整数场景 |

```text
更相减损为什么慢？
  gcd(10⁹, 1)：每次减 1 → 10⁹ 步
  辗转相除：一次取模 10⁹ % 1 = 0 → 1 步

Stein 思路（二进制）：
  ① a, b 都为偶 → gcd = 2·gcd(a/2, b/2)
  ② 一偶一奇 → 偶数除 2
  ③ 都奇 → gcd(a,b) = gcd((a-b)/2, b)（差是偶数）
  避免除法 → 大整数（BigInteger）友好
```

### 1.2 辗转相除的复杂度证明（面试加分）

```text
关键引理：a ≥ b 时 a % b < a/2

证明：a % b = a - ⌊a/b⌋·b
  若 b ≤ a/2 → a%b < b ≤ a/2 ✓
  若 b > a/2 → ⌊a/b⌋ = 1 → a%b = a - b < a/2 ✓

推论：每执行两次取模，较大的数至少减半
  → 取模次数 O(log min(a,b))
  → 总复杂度 O(log min(a,b))
```

### 1.3 gcd 的扩展结论（面试速查）

```text
① gcd(a, b) = gcd(a, b - a) = gcd(a, b + a·k)
② gcd(a, b, c) = gcd(gcd(a, b), c)（可结合）
③ lcm(a, b) × gcd(a, b) = a × b（最小公倍数公式）
   ⚠️ 先除后乘防溢出：lcm = a / gcd(a,b) * b
④ gcd(a, b) = 1 表示互质（逆元存在的前提）
⑤ 任意数的约数 ≤ 2√n 个（枚举优化依据）
⑥ n 个数的 gcd：任何加入顺序结果相同
```

## 2. exgcd 的完整推导

### 2.1 递归推导（从底向上）

```text
边界：b = 0 时
  gcd(a, 0) = a → 特解 (x, y) = (1, 0)，因为 a·1 + 0·0 = a

回溯：已知 b·x' + (a%b)·y' = d，求 a·x + b·y = d 的 (x, y)
  由 a%b = a - ⌊a/b⌋·b 代入：
    b·x' + (a - ⌊a/b⌋·b)·y' = d
    a·y' + b·(x' - ⌊a/b⌋·y') = d
  对照 a·x + b·y = d：
    x = y'
    y = x' - ⌊a/b⌋·y'

记忆：新x = 旧y；新y = 旧x - (a/b)·旧y
```

### 2.2 通解与最小正整数解

```text
设 d = gcd(a, b)，特解 (x₀, y₀)，通解：
  x = x₀ + (b/d)·t
  y = y₀ - (a/d)·t        （t ∈ ℤ）

为什么周期是 b/d 而不是 b？
  a·(x₀ + (b/d)·t) + b·(y₀ - (a/d)·t)
  = ax₀ + by₀ + (ab/d - ab/d)·t = d ✓

最小正整数解（x 方向）：
  step = b/d
  x_min = (x₀ % step + step) % step
  ⚠️ 先 mod 再 +step 再 mod：Java 负数 % 结果为负
```

```java
/**
 * 求 ax + by = c 的最小正整数解 x 及解的个数（洛谷 P5656 核心）
 */
public long[] solveMin(long a, long b, long c) {
    long[] xy = new long[2];
    long d = exgcd(a, b, xy);
    if (c % d != 0) return null;             // 无解

    xy[0] *= c / d;
    xy[1] *= c / d;
    long step = b / d;                       // ⚠️ 周期 = b/d
    long xMin = (xy[0] % step + step) % step;   // 最小正整数解
    long yMax = (c - a * xMin) / b;          // 对应 y
    return new long[]{xMin, yMax};
}
// 注意：a,b,c 可到 10^18 → a·xMin 可能溢出 long → 用 BigInteger 或
// 变换公式 yMax = (y0 - (a/d)·t) 避免直接乘
```

### 2.3 exgcd 的迭代实现（防爆栈）

```java
/**
 * exgcd 迭代版（辗转相除 + 矩阵跟踪）
 * 用递推关系维护 (x, y) 的变换
 */
public long[] exgcdIter(long a, long b) {
    long x = 1, y = 0;       // 当前表示：a·x + b·y = a
    long u = 0, v = 1;       // 当前表示：a·u + b·v = b
    while (b != 0) {
        long q = a / b;
        // (a, b) ← (b, a - q·b)，同时更新系数
        long ta = a; a = b; b = ta - q * b;
        long tx = x; x = u; u = tx - q * u;
        long ty = y; y = v; v = ty - q * v;
    }
    return new long[]{x, y};   // a·x + b·y = gcd
}
// 面试优先写递归版（好背）；生产环境在意栈深时用迭代版
```

## 3. 线性同余方程全解

### 3.1 解的结构分析

```text
方程：ax ≡ b (mod m)
等价：ax + my = b

解的三种情况：
  ① gcd(a, m) ∤ b → 无解
  ② gcd(a, m) | b → 恰好 gcd(a, m) 个模 m 不同的解

为什么有 d = gcd(a,m) 个解？
  ax 模 m 的取值只能落在 {d 的倍数} 上（d | a, d | m）
  → ax ≡ b 有解当且仅当 d | b
  此时原方程除以 d：a'x ≡ b' (mod m')，gcd(a', m') = 1
  → 模 m' 意义下唯一解 x₀（一个特解）
  → 模 m 意义下：x = x₀ + m'·t，t = 0..d-1 → d 个解
```

### 3.2 完整求解流程

```java
/**
 * 解 ax ≡ b (mod m)：返回所有模 m 意义下的解（升序）
 */
public List<Long> solveCongruence(long a, long b, long m) {
    List<Long> res = new ArrayList<>();
    long[] xy = new long[2];
    long d = exgcd(a, m, xy);              // ax + my = d 的特解
    if (b % d != 0) return res;            // ① 无解

    // ② 特解放大 + 归一化到模 m' 意义下
    long m1 = m / d;
    long x0 = (xy[0] * (b / d) % m1 + m1) % m1;
    // ③ 生成 d 个解：x0, x0 + m1, ..., x0 + (d-1)·m1
    for (long t = 0; t < d; t++) res.add(x0 + t * m1);
    return res;
}
// 推演：3x ≡ 6 (mod 9)：d = gcd(3,9) = 3 | 6 → 3 个解
//   m' = 3，x0 = 2（3·2=6 ≡ 6）→ 解：2, 5, 8 ✓
```

### 3.3 同余方程组：CRT 前置

```text
x ≡ a₁ (mod m₁)
x ≡ a₂ (mod m₂)        （m₁, m₂ 互质）

解法（中国剩余定理核心）：
  M = m₁·m₂
  x = a₁·M₂·inv(M₂) + a₂·M₁·inv(M₁) (mod M)
  其中 M₁ = M/m₁，inv(M₁) = M₁⁻¹ mod m₁（用 exgcd！）

→ exgcd 是 CRT 的底层工具（互质逆元只能 exgcd）
→ 完整 CRT 见「初等数论」专题/竞赛扩展
```

## 4. 乘法逆元四法

### 4.1 四种求法全景对比

| 方法 | 条件 | 复杂度 | 适用 |
|------|------|:---:|------|
| 费马小定理 a^(p-2) | p 质数，gcd(a,p)=1 | O(log p) | 单点求逆（默认） |
| exgcd | gcd(a,p)=1（不限质数） | O(log p) | 模数非质数 |
| 线性递推 inv[i] | p 质数，批量 1..n | O(n) | 批量预处理 |
| 阶乘逆元 | p 质数，组合数场景 | O(n) | C(n,m) O(1) 查询 |

### 4.2 批量线性递推求逆元（O(n)）

```java
/**
 * 预处理 1..n 的逆元（模 p 为质数）
 * 公式：inv[i] = (p - p/i) · inv[p % i] % p
 */
public long[] invAll(int n, long p) {
    long[] inv = new long[n + 1];
    inv[1] = 1;
    for (int i = 2; i <= n; i++) {
        inv[i] = (p - p / i) % p * inv[(int) (p % i)] % p;
    }
    return inv;
}
// 推导：p = k·i + r（k = p/i, r = p%i < i）
//   k·i + r ≡ 0 (mod p) → k·i ≡ -r → i⁻¹ ≡ -k·r⁻¹
//   → inv[i] = (p - k) · inv[r] % p  ← 递推（r < i 已算过）
```

### 4.3 阶乘逆元（组合数基石）

```java
/**
 * 阶乘 + 阶乘逆元：C(n,m) = fac[n]·invfac[m]·invfac[n-m] 的基础
 */
public long[] facInv(int n, long p) {
    long[] fac = new long[n + 1];
    long[] invfac = new long[n + 1];
    fac[0] = 1;
    for (int i = 1; i <= n; i++) fac[i] = fac[i - 1] * i % p;
    invfac[n] = quickPow(fac[n], p - 2, p);   // 只做一次快速幂！
    for (int i = n; i >= 1; i--) {
        invfac[i - 1] = invfac[i] * i % p;    // 倒推：invfac[i-1] = invfac[i]·i
    }
    return invfac;
}
// 核心：1 次快速幂 + n 次乘法 → O(n + log p)
```

### 4.4 逆元的工程陷阱

```text
① 逆元存在的充要条件：gcd(a, p) = 1
   p 是 1e9+7 这类质数 → 任何 1 ≤ a < p 都有逆元
   p 是合数 → 与 p 不互质的数没有逆元（如 6 模 10 无逆元）
② 负数归一化：exgcd 结果可能为负 → (x % p + p) % p
③ 模数 = 1：逆元定义退化（任何数 ≡ 0），直接特判
④ 大数相乘溢出：1e9+7 级安全；1e18 级需要快速乘
```

## 5. 不定方程与工程应用

### 5.1 二元一次不定方程 ax + by = c 全解

```text
流程（P5656 标准五步）：
  ① exgcd 求特解 (x₀, y₀) 满足 ax₀ + by₀ = gcd
  ② 判 c % gcd ≠ 0 → 无解
  ③ 放大 k = c/gcd → 一组特解
  ④ 通解：x = x₀·k + (b/gcd)·t，y = y₀·k - (a/gcd)·t
  ⑤ 按需取最小正整数解 / 统计正解个数

正解个数统计（a, b, c > 0 时）：
  x_min 对应 y_max；x_max 对应 y_min
  t 的取值范围：x_min ≤ x ≤ x_max ⟺ t ∈ [0, (x_max - x_min)/step_x]
  正解组数 = ⌊(x_max - x_min) / step_x⌋ + 1（若 x_min ≤ x_max）
```

### 5.2 工程应用一：RSA 私钥求解

```text
RSA 密钥生成：
  选两个大质数 p, q → n = pq，φ(n) = (p-1)(q-1)
  选公钥指数 e（与 φ(n) 互质）
  私钥 d 满足：e·d ≡ 1 (mod φ(n))

→ d = e⁻¹ mod φ(n)，恰好是 exgcd 求逆元！
  （模数 φ(n) 非质数 → 费马小定理不可用 → 必须 exgcd）
  d 的工程形态：java.math.BigInteger.modInverse() 底层就是扩展欧几里得
```

### 5.3 工程应用二：错位补偿与线性校准

```text
场景：传感器/时钟误差校准
  两个设备读数差随时间线性漂移：差值 = a·t + b
  找到整数时刻 t 使差值归零 → 解 a·t ≡ -b (mod period)
  → 线性同余方程，exgcd 一步解出（周期解可能不存在）

场景：循环队列/哈希槽位分配
  两个步长 a, b 在模 m 下何时相遇 → 同余方程
```

### 5.4 竞赛扩展：多项式与矩阵上的欧几里得

```text
exgcd 的本质：任何「欧几里得整环」（Euclidean domain）上都能做
  · 整数环 ℤ：本章内容
  · 多项式环 F[x]：多项式 gcd 与逆元（纠错码 RS 码的基石）
  · 高斯整数：复数域扩展

面试定位：说出「exgcd 是环论上的通用工具」是加分项，
  但不要求现场推导多项式版本
```

## 6. 本章小结

```text
gcd 体系：
  辗转相除 O(log)，更相减损慢，Stein 大数友好
  lcm = a/gcd·b（先除后乘防溢出）

exgcd：
  边界 (1,0)，回溯 新x=旧y，新y=旧x-(a/b)·旧y
  通解 x = x₀ + (b/d)t，周期 = b/d

同余方程 ax ≡ b (mod m)：
  gcd ∤ b 无解；有解则 d 个模 m 解，周期 m/d

逆元四法：
  费马（质数单点）/ exgcd（非质数）/ 线性递推（批量）/
  阶乘逆元（组合数）——按场景选

工程出口：
  RSA 私钥 d = e⁻¹ mod φ(n) ← exgcd
  组合数取模 ← 阶乘逆元
  CRT 合并 ← exgcd 逆元
```

> 🎯 **核心要点**：exgcd 一个算法撬动四个场景（不定方程/同余方程/逆元/CRT）。面试记忆链：**贝祖判有解 → 回溯求特解 → 周期 b/d 求通解 → 逆元四法按场景选**。手推 `6x+15y=9` 与 `3x≡6 (mod 9)` 两个例题，足以应对 90% 的面试追问。
