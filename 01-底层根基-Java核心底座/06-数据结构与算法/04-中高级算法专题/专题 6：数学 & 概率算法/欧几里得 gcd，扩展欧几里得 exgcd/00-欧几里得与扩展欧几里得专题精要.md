## 1. 核心概念

### 1.1 欧几里得算法（辗转相除法）

```text
gcd(a, b) = gcd(b, a % b)
  原理：a 和 b 的公约数集合 = b 和 a%b 的公约数集合（证略，1.2 给）
  终止：b = 0 时 gcd = a

复杂度：O(log min(a,b))（每两步至少减半）
  例：gcd(48, 18)：
  48 % 18 = 12 → gcd(18, 12)
  18 % 12 = 6  → gcd(12, 6)
  12 % 6  = 0  → gcd = 6 ✓
```

### 1.2 贝祖定理（裴蜀定理）——exgcd 的数学依据

```text
对任意整数 a, b，存在整数 x, y 使得：
  ax + by = gcd(a, b)

推论：
  方程 ax + by = c 有整数解 ⟺ gcd(a, b) | c
  （c 是 gcd 的倍数才有解，如 6x+8y=3 无解）

重要：
  a₁x₁ + a₂x₂ + ... + aₖxₖ = gcd(a₁,...,aₖ)·n 恒有解
  有解 ≠ 唯一解：解有无穷多组（通解见 1.3）
```

### 1.3 扩展欧几里得（exgcd）

```text
欧几里得只求 gcd；exgcd 额外求出贝祖等式的一组特解 (x₀, y₀)：
  ax₀ + by₀ = gcd(a, b)

通解（所有解）：d = gcd(a, b)
  x = x₀ + (b/d) · t
  y = y₀ - (a/d) · t        （t 任意整数）

最小正整数解：x = (x₀ mod (b/d) + (b/d)) mod (b/d)

应用三大件（面试必考）：
  ① 求乘法逆元：gcd(a,p)=1 时 ax ≡ 1 (mod p) 的解
  ② 解线性同余方程 ax ≡ b (mod m)
  ③ 解二元一次不定方程 ax + by = c
```

## 2. gcd 与 exgcd 完整模板

### 2.1 gcd（迭代版，避免递归爆栈）

```java
/**
 * gcd 模板：欧几里得算法（迭代版）
 */
public long gcd(long a, long b) {
    while (b != 0) {
        long t = a % b;
        a = b;
        b = t;
    }
    return a;
}
// 复杂度 O(log min(a,b))
// ⚠️ 负数处理：Java 的 % 结果可能为负 → 用 Math.abs 或先归一化
```

### 2.2 exgcd（递归版，面试标准答案）

```java
/**
 * exgcd 模板：求 ax + by = gcd(a, b) 的一组特解
 * 返回 gcd，x/y 传出特解（引用语义用数组模拟）
 */
public long exgcd(long a, long b, long[] xy) {
    if (b == 0) {
        xy[0] = 1;              // a×1 + 0×0 = a = gcd(a, 0)
        xy[1] = 0;
        return a;
    }
    long d = exgcd(b, a % b, xy);
    // 回溯：设 b·x' + (a%b)·y' = d
    // a%b = a - (a/b)·b 代入 → a·y' + b·(x' - (a/b)·y') = d
    long x = xy[1];
    long y = xy[0] - (a / b) * xy[1];
    xy[0] = x;
    xy[1] = y;
    return d;
}
// 记忆口诀：新x = 旧y，新y = 旧x - (a/b)·旧y
```

### 2.3 exgcd 求解 ax + by = c 的完整流程

```java
/**
 * 解不定方程 ax + by = c：返回一组特解；无解返回 null
 */
public long[] solveDiophantine(long a, long b, long c) {
    long[] xy = new long[2];
    long d = exgcd(a, b, xy);            // 先求 ax + by = gcd 的特解
    if (c % d != 0) return null;         // 贝祖定理：无解判定
    long k = c / d;
    xy[0] *= k;                          // 放大到目标 c
    xy[1] *= k;
    return xy;
}
// 通解：x = xy[0] + (b/d)·t，y = xy[1] - (a/d)·t
// 最小正整数解：见 01 模块 2.2
```

### 2.4 推演：6x + 15y = 9

```text
exgcd(6, 15)：
  exgcd(15, 6)：15 = 2·6 + 3 → exgcd(6, 3)：6 = 2·3 + 0
  → exgcd(3, 0) 返回 (x=1, y=0), d=3
  回溯到 (6, 3)：a=6, b=3, a/b=2
    x = 0, y = 1 - 2·0 = 1 → (6,3): x=0, y=1
  回溯到 (15, 6)：a=15, b=6, a/b=2
    x = 1, y = 0 - 2·1 = -2 → (15,6): x=1, y=-2
  回溯到 (6, 15)：a=6, b=15, a/b=0
    x = -2, y = 1 - 0·(-2) = 1 → 特解：x=-2, y=1
  验证：6×(-2) + 15×1 = 3 = gcd ✓

放大到 9：k = 9/3 = 3 → x = -6, y = 3
  验证：6×(-6) + 15×3 = -36 + 45 = 9 ✓
  通解：x = -6 + 5t, y = 3 - 2t
```

## 3. exgcd 三大应用

### 3.1 应用一：乘法逆元（模数非质数时唯一选择）

```java
/**
 * 求 a 模 p 的乘法逆元（gcd(a,p)=1 才有；否则不存在）
 * 等价于解 ax + py = 1 → x 即逆元
 */
public long invMod(long a, long p) {
    long[] xy = new long[2];
    long d = exgcd(a, p, xy);
    if (d != 1) return -1;               // 不互质 → 无逆元
    // ⚠️ 负数归一化：结果可能为负
    return (xy[0] % p + p) % p;
}
// 与费马小定理对比：模数质数 → a^(p-2)（快速幂）；
// 模数非质数 → 必须 exgcd —— 这是 exgcd 不可替代的场景
```

### 3.2 应用二：线性同余方程 ax ≡ b (mod m)

```text
ax ≡ b (mod m) ⟺ ax + my = b 有整数解
  解的情况：
  ① gcd(a, m) ∤ b → 无解
  ② gcd(a, m) | b → 有 gcd(a, m) 个模 m 意义下不同的解

求解步骤：
  ① exgcd 求 ax + my = gcd 的特解 (x₀, y₀)
  ② 放大 k = b/gcd → x₁ = x₀·k
  ③ 通解：x = x₁ + (m/gcd)·t（模 m/gcd 意义下唯一）
  ④ 最小正整数解：x mod (m/gcd) 归一化
```

### 3.3 应用三：分数取模 a/b mod p

```text
(a / b) mod p = a × b⁻¹ mod p
  b⁻¹ = exgcd 逆元（模非质数）或费马小定理（模质数）

工程应用：组合数 C(n,m) = n!/(m!(n-m)!) 的取模计算
  → 阶乘 + 逆元预处理（见「组合数、逆元」专题）
```

## 5. 面试要点与追问

### 5.1 面试话术模板

```
"exgcd 是欧几里得的扩展：回溯时用
 新x = 旧y，新y = 旧x - (a/b)·旧y
 还原出 ax + by = gcd(a,b) 的特解。
 贝祖定理保证有解；通解加 (b/d, -a/d) 的整数倍。
 三大应用：解不定方程、解同余方程、求乘法逆元——
 模数非质数时逆元只能用 exgcd。"
```

### 5.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | gcd 为什么 O(log)？ | 每两步 a, b 至少减半（a ≥ b 时 a%b < a/2） |
| 2 | 贝祖定理内容？ | ax+by=gcd(a,b) 有解；ax+by=c 有解 ⟺ gcd|c |
| 3 | exgcd 递归怎么回溯？ | 新x=旧y，新y=旧x-(a/b)·旧y（a%b 展开代入） |
| 4 | 通解长什么样？ | x=x₀+(b/d)t，y=y₀-(a/d)t |
| 5 | 逆元存在的条件？ | gcd(a,p)=1（互质），模质数时可用费马 |
| 6 | 同余方程几个解？ | gcd(a,m) 个模 m 不同解；归一化后 (m/d) 周期 |
| 7 | 负数取模怎么办？ | (x % p + p) % p 归一化 |
| 8 | 与欧拉定理关系？ | 两者都能求逆元：exgcd 不要求质数，欧拉/费马要求互质+质数 |

### 5.3 与其他专题衔接

```text
exgcd → 组合数：组合数除法取模的逆元（「组合数、逆元」专题）
exgcd → 密码学：RSA 私钥 d 的计算 e·d ≡ 1 (mod φ(n)) 就是 exgcd
exgcd → CRT：中国剩余定理求逆元合并（「初等数论」/竞赛扩展）
exgcd → 矩阵/多项式：欧几里得整环上的推广（竞赛级）
```

## 6. 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 回溯公式写反 | 解全错 | 新x=旧y，新y=旧x-(a/b)·旧y |
| 忘判断 c % gcd ≠ 0 | 输出错误解 | 先贝祖判定再放大 |
| 逆元结果负数 | 取模结果错 | (x % p + p) % p |
| 通解忘记除以 d | 周期错 | x 周期 = b/d 而非 b |
| 递归爆栈（a,b 大） | StackOverflow | 迭代版 gcd，exgcd 用 long |
| 求逆元忘查互质 | 错用不存在的逆元 | d != 1 → 无逆元返回 |
| 最小正整数解直接 mod | 可能仍为负/0 | 先 mod 周期再加周期再 mod |

> 🎯 **核心要点**：exgcd = **贝祖定理（有解判定）+ 回溯还原（特解）+ 通解公式（周期）**三件套。面试只要答出「回溯公式 + 三大应用 + 逆元互质条件」就过关；`6x+15y=9` 这类手算推演是必会题。
