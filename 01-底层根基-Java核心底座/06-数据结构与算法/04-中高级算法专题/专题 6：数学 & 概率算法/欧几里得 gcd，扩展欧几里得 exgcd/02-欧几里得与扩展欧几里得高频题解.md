## 1. P4549 裴蜀定理（多变量贝祖）

### 1.1 题目与思路

```text
给 n 个数 a₁..aₙ（可为负），求 x₁a₁ + ... + xₙaₙ 的最小正值
贝祖定理推广：能取到的最小正值 = gcd(a₁, ..., aₙ)
→ 答案 = 所有数取绝对值后的最大公约数
⚠️ 负数 → 取绝对值再 gcd（gcd 只定义在正整数）
```

### 1.2 完整代码

```java
/**
 * 洛谷 P4549 裴蜀定理：最小正系数组合 = 全体 gcd
 */
public long bezoutMin(int[] nums) {
    long g = 0;
    for (int a : nums) {
        g = gcd(g, Math.abs(a));     // ⚠️ 负数取绝对值
    }
    return g;
}

private long gcd(long a, long b) {
    while (b != 0) {
        long t = a % b;
        a = b;
        b = t;
    }
    return a;
}
// 推演 [-6, 15, 10]：gcd(gcd(6,15)=3, 10) = 1 → 答案为 1
// 面试必答："k 个变量的贝祖定理：
//   组合能取到的正最小值恰好是全体数的最大公约数；
//   负数先取绝对值。"
```

## 2. P5656 【模板】二元一次不定方程

### 2.1 题目与思路

```text
解 ax + by = c（a,b,c ≤ 10^9，多组询问）
要求：无解输出 -1；有解输出 最小正整数 x、对应最大 y、正解组数、
      x 最小值时的 y、y 最小值时的 x
⚠️ 乘除注意 long 溢出（a·xMin 可能 10^18+）
```

### 2.2 完整代码

```java
/**
 * 洛谷 P5656 【模板】二元一次不定方程
 * exgcd 特解 → 通解 → 统计正解
 */
public String diophantine(long a, long b, long c) {
    long[] xy = new long[2];
    long d = exgcd(a, b, xy);
    if (c % d != 0) return "-1";                 // ① 无解判定

    long stepX = b / d, stepY = a / d;           // 通解周期
    // 最小正整数 x（归一化）
    long x0 = ((xy[0] * (c / d)) % stepX + stepX) % stepX;
    long y0 = (c - a * x0) / b;                  // 对应 y（由方程反解）

    if (y0 > 0) {
        // 正解组数：x 从 x0 开始每次 +stepX，y 相应每次 -stepY
        long cnt = y0 / stepY + 1;               // y > 0 的组数
        long yMin = y0 % stepY;                  // y 最小值（正）
        return String.format("x_min=%d y_max=%d cnt=%d x_of_y_min=%d y_min=%d",
                x0, y0, cnt, (c - yMin * b) / a, yMin);
    }
    // 无正整数解：y 恒 ≤ 0 → 输出 x 最小 + y 最大（可能 ≤ 0）
    return String.format("x=%d y=%d", x0, y0);
}

private long exgcd(long a, long b, long[] xy) {
    if (b == 0) { xy[0] = 1; xy[1] = 0; return a; }
    long d = exgcd(b, a % b, xy);
    long x = xy[1], y = xy[0] - (a / b) * xy[1];
    xy[0] = x; xy[1] = y;
    return d;
}
// ⚠️ (c - a*x0)/b 可能仍溢出：严格做法用 BigInteger 或
//   用通解公式 y0 = y0' - stepY·t 避免中间大数
// 推演 2x + 3y = 7：exgcd 特解 (-1,1)，d=1，stepX=3, stepY=2
//   x0 = (-1·7 mod 3 + 3) mod 3 = 2 → y0 = (7-4)/3 = 1
//   正解：x=2,y=1 ✓（唯一正解）
```

## 3. POJ 1061 青蛙的约会（同余方程）

### 3.1 题目与思路

```text
两只青蛙跳数轴（环形，总长 L）：
  蛙A 起点 x，速度 m；蛙B 起点 y，速度 n
  跳 t 步后相遇：x + m·t ≡ y + n·t (mod L)
  → (m - n)·t ≡ y - x (mod L)
  → 线性同余方程！exgcd 求解，输出最小正整数 t
⚠️ m - n 可为负 → 系数归一化；无解输出 "Impossible"
```

### 3.2 完整代码

```java
/**
 * POJ 1061 青蛙的约会：解 (m-n)·t ≡ y-x (mod L)
 */
public String frogMeeting(long x, long y, long m, long n, long L) {
    long a = m - n, b = y - x;
    // 同余方程系数可为负：先对 L 归一化
    a = ((a % L) + L) % L;
    b = ((b % L) + L) % L;

    long[] xy = new long[2];
    long d = exgcd(a, L, xy);              // a·t + L·k = gcd(a, L)
    if (b % d != 0) return "Impossible";   // 贝祖：无解

    // 特解放大 + 最小正整数解（周期 = L/d）
    long step = L / d;
    long t = ((xy[0] * (b / d)) % step + step) % step;
    return String.valueOf(t);
}

private long exgcd(long a, long b, long[] xy) {
    if (b == 0) { xy[0] = 1; xy[1] = 0; return a; }
    long d = exgcd(b, a % b, xy);
    long x = xy[1], y = xy[0] - (a / b) * xy[1];
    xy[0] = x; xy[1] = y;
    return d;
}
// 面试必答："追及问题转同余方程三步：
//   列式 x+mt ≡ y+nt (mod L) → 移项成 at ≡ b (mod L)
//   → exgcd 解 + 周期 L/d 归一化。"
```

## 4. 365. 水壶问题（gcd 应用）

### 4.1 题目与思路

```text
两个水壶容量 x, y，只能倒空/倒满/互倒，能否量出 z 升？
数学本质：能量出的量 = x, y 的任意整数线性组合
  → z 可量出 ⟺ gcd(x, y) | z 且 z ≤ x + y
⚠️ 组合系数可为负（倒掉/倒出 = 减法操作）
```

### 4.2 完整代码

```java
/**
 * LeetCode 365. 水壶问题（贝祖定理判定）
 */
public boolean canMeasureWater(int x, int y, int z) {
    if (z == 0) return true;
    if (x + y < z) return false;           // 总容量不够
    return z % gcd(x, y) == 0;             // 贝祖：gcd 的倍数
}

private int gcd(int a, int b) {
    while (b != 0) {
        int t = a % b;
        a = b;
        b = t;
    }
    return a;
}
// 推演 x=3, y=5, z=4：gcd=1 | 4 且 4 ≤ 8 → true
//   操作：装满5 → 倒3（剩2）→ 倒空3 → 倒2入3 → 装满5 → 倒1入3（3满）→ 剩4 ✓
// 面试必答："水壶问题 = 贝祖定理：操作序列等价于
//   ax + by（正=加水，负=倒水），能到 z 当且仅当 gcd | z。"
```

## 5. P1082 同余方程（exgcd 求逆元）

### 5.1 题目与思路

```text
求 ax ≡ 1 (mod b) 的最小正整数解（gcd(a,b)=1 保证）
= 求 a 模 b 的逆元 → exgcd（b 不保证质数 → 不能费马）
⚠️ b 非质数是本题关键设计
```

### 5.2 完整代码

```java
/**
 * 洛谷 P1082 同余方程：ax ≡ 1 (mod b)，求最小正整数 x
 */
public long minInverse(long a, long b) {
    long[] xy = new long[2];
    long d = exgcd(a, b, xy);              // a·x + b·y = 1
    // gcd 必为 1（题目保证有解）→ x 即逆元，归一化
    long step = b / d;
    return (xy[0] % step + step) % step;   // 最小正整数解
}

private long exgcd(long a, long b, long[] xy) {
    if (b == 0) { xy[0] = 1; xy[1] = 0; return a; }
    long d = exgcd(b, a % b, xy);
    long x = xy[1], y = xy[0] - (a / b) * xy[1];
    xy[0] = x; xy[1] = y;
    return d;
}
// 推演 3x ≡ 1 (mod 10)：exgcd(3,10) → x=-3（3·(-3)+10·1=1）
//   归一化：(-3 % 10 + 10) % 10 = 7 → 3·7=21 ≡ 1 (mod 10) ✓
// 面试必答："模数非质数 → 逆元必须 exgcd；
//   解出来 x 可能为负 → 对周期 b/d 归一化取最小正整数。"
```

## 6. 1979. 找出数组的最大公约数（gcd 模板）

### 6.1 题目与思路

```text
数组 nums，求 [最大值, 最小值] 的 gcd
纯模板题：先线性扫最大最小，再 gcd
```

### 6.2 完整代码

```java
/**
 * LeetCode 1979. 找出数组的最大公约数
 */
public int findGCD(int[] nums) {
    int max = nums[0], min = nums[0];
    for (int v : nums) {
        max = Math.max(max, v);
        min = Math.min(min, v);
    }
    return gcd(max, min);
}

private int gcd(int a, int b) {
    while (b != 0) {
        int t = a % b;
        a = b;
        b = t;
    }
    return a;
}
// 复杂度 O(n + log(max))，热身题
```

## 7. exgcd 方法论总结

### 7.1 题型识别 → 方案

| 题面信号 | 方案 | 模板位置 |
|------|------|------|
| "组合系数能取到的最小正值" | 全体 gcd（贝祖） | 02 模块 1 |
| ax + by = c，求整数解/正解 | exgcd 五步 | 01 模块 5.1 |
| ax ≡ b (mod m)，求最小解 | exgcd + 周期归一化 | 01 模块 3.2 |
| 追及/循环相遇 | 列式转同余方程 | 02 模块 3 |
| 求 a 模 p 逆元（p 非质数） | exgcd | 02 模块 5 |
| 水壶/容器倒水 | gcd 倍数判定 | 02 模块 4 |
| 分数取模、组合数 | 逆元（四法选一） | 「组合数、逆元」专题 |

### 7.2 五步解题法（面试口述）

```text
① 识别：不定方程 / 同余方程 / 逆元 / 判定
② 列式：ax + by = c 或 ax ≡ b (mod m)
③ exgcd 求特解（边界 1,0 + 回溯公式）
④ 贝祖判定 c % gcd，无解直接出
⑤ 周期 b/d 归一化，输出最小正整数解 / 统计正解
```

### 7.3 一句话考点清单

```text
贝祖定理：ax+by=c 有解 ⟺ gcd|c —— 必背
exgcd 回溯：新x=旧y，新y=旧x-(a/b)·旧y —— 必背
通解周期：x 周期 b/d，y 周期 a/d —— 必背
逆元条件：gcd(a,p)=1，非质数模只能 exgcd —— 必背
负数归一化：(x % p + p) % p —— 高频坑
```

> 🎯 **核心要点**：六道母题覆盖 exgcd 全部输出形态（判定/特解/最小正解/解组数/逆元）。面试最常考的是「P1082 求逆元」和「P5656 不定方程」两类；水壶题是 gcd 的趣味应用。写代码时三查：**c%d、周期 b/d、负数归一化**。
