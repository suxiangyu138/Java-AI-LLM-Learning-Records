## 1. 矩阵快速幂：线性递推的加速器

### 1.1 从斐波那契说起

```text
朴素 DP：F(n) = F(n-1) + F(n-2) → O(n)
n = 10^18 时不可能逐项算。

观察：F(n) 由前两项决定 → 状态向量 (F(n), F(n-1)) 的转移是线性的：

  | F(n)   |   | 1 1 | | F(n-1) |
  | F(n-1) | = | 1 0 | | F(n-2) |

令 M = [[1,1],[1,0]]，则：
  | F(n)   |        | F(1) |
  | F(n-1) | = M^(n-1) | F(0) |

→ 问题变成矩阵幂：M^(n-1) 用快速幂 O(log n) 算出
→ 斐波那契：O(n) → O(log n) 的跃迁
```

### 1.2 构造转移矩阵的万能三步法

```text
① 写递推式（高阶 → 一阶）
   例：F(n) = 2F(n-1) + 3F(n-2) + 4
   引入辅助状态（常数项拆成 C(n) = 4，C(n+1) = C(n) 恒成立）

② 列状态向量（把递推用到的历史状态全放进去）
   (F(n), F(n-1), 1)ᵀ

③ 凑转移矩阵：让 状态(n) = M × 状态(n-1)
   | F(n)   |   | 2 3 4 | | F(n-1) |
   | F(n-1) | = | 1 0 0 | | F(n-2) |
   | 1      |   | 0 0 1 | | 1      |
   最后一列塞常数系数，最后一行保持常数 1

注意：系数取模 p（系数角色），指数取模 φ(p)（指数角色）——角色不同！
```

### 1.3 常见递推的转移矩阵速查

| 递推式 | 状态向量 | 转移矩阵 |
|------|------|------|
| F(n)=F(n-1)+F(n-2) | (F(n),F(n-1)) | [[1,1],[1,0]] |
| F(n)=F(n-1)+F(n-2)+F(n-3) | 3 维 | 第一行 [1,1,1]，对角 1 |
| F(n)=2F(n-1)+3F(n-2) | 2 维 | [[2,3],[1,0]] |
| F(n)=F(n-1)+F(n-2)+C（常数） | (F(n),F(n-1),1) | 3 维，见 1.2 |
| 混合乘积型 f(n)=f(n-1)·f(n-2) | 指数向量 | 指数做斐波那契递推（见 4 节） |

### 1.4 完整模板（含取模细节）

```java
/**
 * 矩阵快速幂完整模板（模 p，p 通常 = 1e9+7）
 * 支持 n 维方阵，O(k³ log b)
 */
public class MatPow {
    private static final long MOD = 1_000_000_007L;

    public static long[][] matPow(long[][] a, long b) {
        int k = a.length;
        long[][] res = unit(k);                    // ⚠️ 单位矩阵
        while (b > 0) {
            if ((b & 1) == 1) res = mul(res, a);
            a = mul(a, a);
            b >>= 1;
        }
        return res;
    }

    private static long[][] unit(int k) {
        long[][] u = new long[k][k];
        for (int i = 0; i < k; i++) u[i][i] = 1;   // 对角 1
        return u;
    }

    /** 矩阵乘法：三重循环 + 每步取模防溢出 */
    private static long[][] mul(long[][] A, long[][] B) {
        int k = A.length;
        long[][] C = new long[k][k];
        for (int i = 0; i < k; i++)
            for (int j = 0; j < k; j++)
                for (int t = 0; t < k; t++)
                    C[i][j] = (C[i][j] + A[i][t] * B[t][j]) % MOD;
        return C;
    }

    /** 例：斐波那契 F(n)（F(0)=0, F(1)=1） */
    public static long fib(long n) {
        if (n < 2) return n;
        long[][] m = matPow(new long[][]{{1,1},{1,0}}, n - 1);
        return m[0][0];                            // = M^(n-1) 的左上角
    }
}
// 复杂度：O(k³ log n)；2×2 矩阵时 O(8 log n) ≈ O(log n)
```

### 1.5 推演：F(10) 的矩阵路径

```text
F(0)=0, F(1)=1
M = [[1,1],[1,0]]

M^9 快速幂过程（只看左上角 F 值）：
  M^1 = [[1,1],[1,0]]    → F(2)=1
  M^2 = [[2,1],[1,1]]    → F(3)=2
  M^4 = [[5,3],[3,2]]    → F(5)=5
  M^8 = [[34,21],[21,13]] → F(9)=34
  M^9 = M^8 × M = [[55,34],[34,21]] → F(10)=55 ✓
```

### 1.6 加速技巧

```text
① 稀疏矩阵：首行有值其余为 0 的递推矩阵，
   乘法可手写专用循环（把 k³ 降到 k²）
② 多组询问：预计算 M 的 2⁰,2¹,...,2⁶⁰ 次幂（倍增表），
   每组询问 O(k³ log n) → O(k³ log n) 不变但常数大幅降低
③ 取模开销：中间乘法用 long 溢出前就模（1e9+7 平方后 ≈ 1e18 不溢）
```

## 2. 欧拉定理与降幂体系

### 2.1 三个定理的递进关系

```text
欧拉定理（欧拉 1763）：
  gcd(a, m) = 1 ⟹ a^φ(m) ≡ 1 (mod m)
  推论：a^b ≡ a^(b mod φ(m)) (mod m)     ← 指数可模 φ(m)

费马小定理（欧拉定理特例，m 为质数）：
  φ(m) = m-1 ⟹ a^(m-1) ≡ 1 (mod m)
  ⟹ 逆元 a⁻¹ ≡ a^(m-2) (mod m)           ← 快速幂求逆元

扩展欧拉定理（取消互质限制，任意 a, m）：
  b < φ(m)  → a^b 直接算
  b ≥ φ(m)  → a^b ≡ a^(b mod φ(m) + φ(m)) (mod m)

为什么扩展欧拉需要 +φ(m)？
  条件 gcd(a,m)=1 时指数模 φ(m) 是"周期"；
  不互质时 a^φ(m) ≢ 1，周期前可能存在"前导不循环段"（preperiod）
  b ≥ φ(m) 才进入循环段 → 必须保证指数落在循环段里 → +φ(m) 兜底
  例：2^10 mod 4，φ(4)=2，10 mod 2 = 0 → 2⁰=1 ≠ 0（正确 0）
  加 φ(m)：10 ≥ 2 → 2^(10 mod 2 + 2) = 2^2 = 0 ✓
```

### 2.2 欧拉函数完整求法

```java
/**
 * 欧拉函数 φ(n)：试除分解质因数
 * 原理：φ(n) = n × Π(1 - 1/pᵢ)（pᵢ 为不同质因子）
 */
public long eulerPhi(long n) {
    long res = n;
    for (long i = 2; i * i <= n; i++) {
        if (n % i == 0) {
            res = res / i * (i - 1);     // ⚠️ 先除后乘防溢出
            while (n % i == 0) n /= i;   // ⚠️ 除尽，避免重复计同一因子
        }
    }
    if (n > 1) res = res / n * (n - 1);  // 剩余大质因子
    return res;
}
// 复杂度 O(√n)；批量求 1~n 的 φ 用线性筛（见「素数筛」专题）
```

### 2.3 费马小定理的两个方向

```text
方向一（降幂）：a^b mod p ≡ a^(b mod (p-1))，p 为质数
  应用：HDU 4549 —— 指数是斐波那契，先模 p-1 再快速幂

方向二（逆元）：a⁻¹ ≡ a^(p-2) mod p
  应用：组合数除法取模、分数取模（见「组合数、逆元」专题）

⚠️ 前提：p 为质数且 gcd(a, p) = 1
  非质数模数求逆元 → exgcd（见「欧几里得 exgcd」专题）
```

## 3. 超级指数问题实战

### 3.1 字符串指数：LC 372 超级次方

```text
问题：a^b mod 1337，其中 b 以数组/字符串给出（长度可达 10^5）
思路：b 无法转成 long → 边读边对 φ(1337) 取模 + 判断是否 ≥ φ

推演 1337 的 φ：
  1337 = 7 × 191 → φ(1337) = 1337 × 6/7 × 190/191 = 6 × 190 = 1140
```

```java
/**
 * LeetCode 372. 超级次方：a^b mod 1337（b 为数组，超大）
 */
private static final int MOD = 1337;

public int superPow(int a, int[] b) {
    if (MOD == 1) return 0;
    int phi = 1140;                        // φ(1337) = 1140
    int exp = 0;
    boolean big = false;
    for (int d : b) {
        if (exp * 10 + d >= phi) big = true;   // 记录 b 是否 ≥ φ
        exp = (exp * 10 + d) % phi;
    }
    if (big) exp += phi;                   // 扩展欧拉：+φ 兜底
    return (int) quickPow(a % MOD, exp, MOD);
}
// 复杂度：O(len(b) + log φ)；记忆点：指数边读边模 + 溢出标记
```

### 3.2 幂塔：P4139 上帝与集合的正确用法

```text
问题：2^(2^(2^...)) mod p（无限 2 的幂塔，p ≤ 10^7，多组询问）

核心递归：
  f(p) = 2^(塔) mod p
  = 2^( (塔的下一层) mod φ(p) + φ(p) ) mod p      ← 扩展欧拉
  塔的下一层也是无限幂塔 → 递归 f(φ(p))

终止条件：模数一路 φ 下去会变成 1 → 返回 0（2^0 的思想：任何数 mod 1 = 0）

  2^(2^...)
    ↓ 递归
  φ(p) → φ(φ(p)) → ... → 1

复杂度：φ 下降极快（每次至少减半，偶数时减半以上）
  → 递归层数 O(log p)，每组询问 O(log² p)
  ⚠️ 必须预处理 1~10^7 的 φ（线性筛），否则每组重算爆 TLE
```

```java
/**
 * P4139 核心递归：powTower(p) = 无限幂塔 2^(2^...) mod p
 * phi[]：线性筛预处理的欧拉函数
 */
public long powTower(int p) {
    if (p == 1) return 0;                  // 模 1 恒 0 → 递归出口
    // 指数 = 下层塔 mod φ(p) + φ(p)（下层塔 ≥ φ(p) 恒成立，b ≥ 2）
    long exp = powTower(phi[p]) + phi[p];
    return quickPow(2, exp, p);
}
// 层数 O(log p)；记忆点：无限幂塔问题 = 沿 φ 链递归，出口是模数 1
```

### 3.3 大指数取模的通用策略表

| 指数形态 | 策略 | 复杂度 |
|------|------|:---:|
| long 范围 | 直接快速幂 | O(log b) |
| 字符串/数组（10^5 位） | 边读边模 φ(m)，标记是否 ≥ φ | O(len) |
| 幂塔/嵌套幂 | 沿 φ 链递归 | O(log p) 层 |
| 分数/负指数（模质数） | 转逆元（费马小定理） | O(log p) |

## 4. 复杂场景组合：矩阵 + 降幂

### 4.1 乘积型递推：HDU 4549 M斐波那契数列

```text
问题：f(0)=a, f(1)=b, f(n) = f(n-1) × f(n-2)（n 巨大，mod 1e9+7）

关键观察：乘法递推 → 取对数变成加法递推
  f(n) = a^F(n-1)? 不对——展开看：
  f(2) = b·a
  f(3) = f(2)·f(1) = (b·a)·b = a·b²
  f(4) = f(3)·f(2) = (a·b²)·(b·a) = a²·b³
  f(n) = a^fib(n-1) × b^fib(n)      ← 指数恰好是斐波那契数！

求解：
  ① 矩阵快速幂求 fib(n), fib(n-1)（指数巨大 → 必须降幂）
  ② 指数对 φ(1e9+7) = 1e9+6 取模（⚠️ 不是 1e9+7！）
  ③ a^指数 mod p：快速幂
  ④ 特判 a 是 p 的倍数 → 答案 0
```

```java
/**
 * HDU 4549：f(n) = a^fib(n-1) × b^fib(n) mod (1e9+7)
 * ⚠️ 指数必须模 1e9+6（费马小定理），系数模 1e9+7
 */
public long mFib(long a, long b, long n) {
    final long P = 1_000_000_007L, PHI = P - 1;   // φ(P) = P-1
    if (n == 0) return a % P;
    if (n == 1) return b % P;

    // ① 指数：fib(n), fib(n-1) mod PHI（矩阵快速幂，模 PHI！）
    long[][] m = matPowMod(new long[][]{{1,1},{1,0}}, n - 1, PHI);
    long fibN = m[0][0], fibN1 = m[0][1];         // fib(n), fib(n-1)

    // ② 快速幂算两项（系数角色 → 模 P）
    long pa = quickPow(a, fibN1, P);              // a^fib(n-1)
    long pb = quickPow(b, fibN, P);               // b^fib(n)
    return pa * pb % P;
}
// 核心考点：同一问题里"指数角色"与"系数角色"用不同模数！
// 指数模 PHI（=P-1），系数模 P —— 混用必错
```

### 4.2 带常数的递推：CF 1182E 思路

```text
问题：f(n) = f(n-1)·f(n-2)·f(n-3)·c^(2n-6)，n 巨大

思路：
  ① 取对数 → 指数做线性递推（三阶斐波那契 + 多项式项）
  ② 矩阵快速幂（5×5 或拆解）求出各项指数
  ③ c 的指数项用等差/矩阵处理，最后逆元归一化
  ④ 全部指数对 φ(p) 取模，系数对 p 取模

面试定位：说出「乘积型递推 → 指数化 → 矩阵快速幂 → 双模数」四步即可
```

## 5. 面试深水区

### 5.1 快速幂的数学证明（面试加分）

```text
二进制分解正确性证明：
  b = Σ bᵢ·2ⁱ（bᵢ ∈ {0,1}，i = 0..⌊log₂b⌋）
  a^b = a^(Σ bᵢ·2ⁱ) = Π (a^(2ⁱ))^bᵢ      ← 指数相加变乘法
  循环不变式：迭代到第 i 位时 res = Π_{j<i} a^(2^j·bⱼ)（模 p）
  → 终止时 res = a^b mod p ✓
```

### 5.2 溢出与性能细节

```text
① long × long：1e9+7 平方 ≈ 1e18 < 9.2e18（long 上限）→ 安全
   若模数 1e18 级：乘法要用「快速乘」（__int128 / 加法二分）
② 快速乘模板（模数超大时）：
   a × b mod p = (a × (b/2) × 2 + (b%2 ? a : 0)) mod p，O(log b)
③ 幂指数负数（LC 50）：x^(-n) = 1 / x^n → 用 double 或转分数处理
   整数幂场景（组合数）无此问题（指数恒非负）
```

### 5.3 与其它专题的衔接

```text
快速幂 ← 逆元：费马小定理 a^(p-2)（「组合数、逆元」专题）
快速幂 ← exgcd：模数非质数时逆元换 exgcd（「欧几里得 exgcd」专题）
快速幂 → 素数判定：Miller-Rabin 的 a^(d·2^s) 核心计算（「随机算法」专题）
快速幂 → 密码学：RSA 加密 a^e mod n 就是快速幂（工程应用）
```

## 6. 本章小结

```text
矩阵快速幂：
  三步构造转移矩阵（写递推 → 列状态向量 → 凑矩阵）
  单位矩阵初始化，O(k³ log n)
  识别信号："线性递推 + n 巨大（10^18）"

欧拉降幂体系：
  欧拉定理（互质）→ 费马小定理（质数模）→ 扩展欧拉（任意）
  b ≥ φ(m) 时 exp = b mod φ(m) + φ(m)
  识别信号："指数超大（字符串/幂塔）"

双模数陷阱（必考）：
  系数 → 模 p；指数 → 模 φ(p)
  质数模 → 指数模 p-1

递归幂塔：
  沿 φ 链递归到模数 1，预处理 φ 数组
```

> 🎯 **核心要点**：本章两大进阶 = **矩阵快速幂**（把递推从 O(n) 拉到 O(log n)）与**欧拉降幂**（把指数从任意大到可算）。最难的组合题（乘积型递推）就是「指数化 + 矩阵快速幂 + 双模数」三步。面试记忆锚点：**指数模 φ(p)、系数模 p、单位矩阵、+φ(m) 兜底**——四个易错点背下来就赢了一半。
