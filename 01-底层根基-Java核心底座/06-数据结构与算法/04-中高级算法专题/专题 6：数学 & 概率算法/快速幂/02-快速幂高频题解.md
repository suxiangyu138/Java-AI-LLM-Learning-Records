## 1. 50. Pow(x, n)（负指数）

### 1.1 题目与思路

```text
计算 x^n（n 可为负，|n| ≤ 2^31，double 精度）
快速幂 + 负指数转正：x^(-n) = 1 / x^n
⚠️ n = Integer.MIN_VALUE 时 -n 溢出 → 用 long
```

### 1.2 完整代码

```java
/**
 * LeetCode 50. Pow(x, n)（快速幂 + 负指数）
 */
public double myPow(double x, int n) {
    long exp = n;                        // ⚠️ 防 -(-2^31) 溢出
    if (exp < 0) {
        x = 1.0 / x;
        exp = -exp;
    }
    double res = 1.0;
    while (exp > 0) {
        if ((exp & 1) == 1) res *= x;
        x *= x;
        exp >>= 1;
    }
    return res;
}
// 复杂度 O(log |n|)
// 面试必答："n 为负先取倒数，再对 |n| 快速幂；
//   注意 int 最小值取负溢出 → 用 long 接住。"
```

## 2. 372. 超级次方（字符串指数 + 欧拉降幂）

### 2.1 题目与思路

```text
a^b mod 1337，b 以数组给出（长度 ≤ 10^5）→ 无法转成整数
欧拉降幂：指数边读边模 φ(1337)=1140，判断是否 ≥ φ 后 +φ 兜底
```

### 2.2 完整代码

```java
/**
 * LeetCode 372. 超级次方（欧拉降幂）
 */
private static final int MOD = 1337;

public int superPow(int a, int[] b) {
    int phi = 1140;                      // φ(1337) = 7×191 → 6×190
    int exp = 0;
    boolean big = false;
    for (int d : b) {
        if (exp * 10L + d >= phi) big = true;
        exp = (int)((exp * 10L + d) % phi);
    }
    if (big) exp += phi;                 // 扩展欧拉定理：b ≥ φ → +φ
    return (int) quickPow(a % MOD, exp, MOD);
}

private long quickPow(long a, long b, long p) {
    long res = 1 % p;
    a %= p;
    while (b > 0) {
        if ((b & 1) == 1) res = res * a % p;
        a = a * a % p;
        b >>= 1;
    }
    return res;
}
// 复杂度 O(len(b) + log φ)
// 推演 b=[2,3]（23），23 ≥ 1140？否 → exp = 23 → 2^23 mod 1337 = ?
// 面试必答："指数大得读不进来 → 边读边模 φ(m)；
//   模数 1337 不是质数 → 必须用 φ 而不是 p-1；
//   big 标记保证 b ≥ φ 时 +φ（扩展欧拉兜底）。"
```

## 3. P1226 【模板】快速幂

### 3.1 题目与思路

```text
输入 a, b, p，输出 a^b mod p（b ≤ 2^31）
纯模板题：迭代快速幂，注意底数取模与 p=1 边界
```

### 3.2 完整代码

```java
/**
 * 洛谷 P1226 【模板】快速幂（迭代版）
 */
public void quickPowTemplate(long a, long b, long p) {
    long res = 1 % p;                    // ⚠️ p=1 时直接得 0
    a %= p;
    long base = a, exp = b;
    while (exp > 0) {
        if ((exp & 1) == 1) res = res * base % p;
        base = base * base % p;
        exp >>= 1;
    }
    System.out.println(a + "^" + b + " mod " + p + " = " + res);
}
// 复杂度 O(log b)
// 变式：递归版（面试常问）见 00 模块 2.3
```

## 4. P3390 【模板】矩阵快速幂

### 4.1 题目与思路

```text
n 阶矩阵 A 的 k 次幂 mod p（n ≤ 100, k ≤ 10^12）
矩阵乘法 O(n³) + 快速幂 O(log k) → O(n³ log k)
⚠️ n=100 时 n³=10⁶，log k≈40 → 4×10⁷ 次取模运算，勉强可过
   n 更大必须用稀疏优化（首行递推矩阵）
```

### 4.2 完整代码

```java
/**
 * 洛谷 P3390 【模板】矩阵快速幂
 * 输入：n, k；n×n 矩阵 A；输出 A^k mod 1e9+7
 */
public long[][] matrixPow(long[][] a, long k, long p) {
    int n = a.length;
    long[][] res = new long[n][n];
    for (int i = 0; i < n; i++) res[i][i] = 1;   // ⚠️ 单位矩阵

    while (k > 0) {
        if ((k & 1) == 1) res = mul(res, a, p);
        a = mul(a, a, p);
        k >>= 1;
    }
    return res;
}

private long[][] mul(long[][] A, long[][] B, long p) {
    int n = A.length;
    long[][] C = new long[n][n];
    for (int i = 0; i < n; i++) {
        for (int t = 0; t < n; t++) {          // ⚠️ 交换循环序加速缓存
            if (A[i][t] == 0) continue;        // 稀疏剪枝
            for (int j = 0; j < n; j++) {
                C[i][j] = (C[i][j] + A[i][t] * B[t][j]) % p;
            }
        }
    }
    return C;
}
// 复杂度 O(n³ log k)；乘法交换循环顺序（i-t-j）+ 零值跳过可提速数倍
```

## 5. P4139 上帝与集合的正确用法（幂塔递归）

### 5.1 题目与思路

```text
2^(2^(2^...)) mod p（无限 2 的幂塔），p ≤ 10^7，T ≤ 1000 组询问
扩展欧拉递归：f(p) = 2^(f(φ(p)) + φ(p)) mod p
沿 φ 链递归到 1，φ 下降极快 → 层数 O(log p)
⚠️ 多组询问必须预处理 1~10^7 的 φ（线性筛）
```

### 5.2 完整代码

```java
/**
 * 洛谷 P4139（幂塔 + 欧拉降幂递归）
 * phi[] 由线性筛预处理（见「素数筛」专题 01）
 */
public long powTower(int p) {
    if (p == 1) return 0;                    // 模 1 恒 0 → 出口
    // 下层塔值 f(φ(p)) ≥ φ(p) 恒成立（塔 ≥ 2^0+...）→ 直接用扩展欧拉
    long exp = powTower(phi[p]) + phi[p];
    return quickPow(2, exp, p);
}

private long quickPow(long a, long b, long p) {
    long res = 1 % p;
    a %= p;
    while (b > 0) {
        if ((b & 1) == 1) res = res * a % p;
        a = a * a % p;
        b >>= 1;
    }
    return res;
}
// 复杂度 O(T · log p · log p)（每层一次快速幂，层数 log p）
// 推演 p=3：φ(3)=2 → f(3)=2^(f(2)+2) mod 3
//   f(2)：φ(2)=1 → f(2)=2^(f(1)+1) mod 2；f(1)=0 → f(2)=2^1 mod 2 = 0
//   f(3) = 2^(0+2) = 4 mod 3 = 1 ✓（2^∞ 塔 mod 3 确实 = 1）
// 面试必答："幂塔 = 沿 φ 链递归降幂，模数 1 是出口；
//   φ 链每次至少减半 → 层数对数级。"
```

## 6. HDU 4549 M斐波那契数列（矩阵 + 降幂组合）

### 6.1 题目与思路

```text
f(0)=a, f(1)=b, f(n)=f(n-1)·f(n-2)，求 f(n) mod 1e9+7（n 巨大）
乘积型递推 → 展开发现 f(n) = a^fib(n-1) × b^fib(n)
指数（斐波那契）巨大 → ①矩阵快速幂求指数（模 φ(p)=1e9+6）
②快速幂算 a^指数、b^指数（系数角色模 p=1e9+7）
⚠️ 双模数：指数模 1e9+6，系数模 1e9+7
```

### 6.2 完整代码

```java
/**
 * HDU 4549：f(n) = a^fib(n-1) × b^fib(n) mod 1e9+7
 */
private static final long P = 1_000_000_007L;
private static final long PHI = P - 1;         // φ(P) = P-1（费马小定理）

public long mFib(long a, long b, long n) {
    if (n == 0) return a % P;
    if (n == 1) return b % P;

    // ① 指数（fib(n), fib(n-1)）：矩阵快速幂，⚠️ 模 PHI
    long[][] m = matPow(new long[][]{{1,1},{1,0}}, n - 1, PHI);
    long fibN = m[0][0], fibN1 = m[0][1];

    // ② 系数（a^..., b^...）：快速幂，⚠️ 模 P
    long pa = quickPow(a, fibN1, P);
    long pb = quickPow(b, fibN, P);
    return pa * pb % P;
}

private long[][] matPow(long[][] a, long b, long mod) {
    long[][] res = {{1,0},{0,1}};
    while (b > 0) {
        if ((b & 1) == 1) res = mul(res, a, mod);
        a = mul(a, a, mod);
        b >>= 1;
    }
    return res;
}

private long[][] mul(long[][] A, long[][] B, long mod) {
    long[][] C = new long[2][2];
    for (int i = 0; i < 2; i++)
        for (int j = 0; j < 2; j++)
            for (int t = 0; t < 2; t++)
                C[i][j] = (C[i][j] + A[i][t] * B[t][j]) % mod;
    return C;
}

private long quickPow(long a, long b, long mod) {
    long res = 1 % mod;
    a %= mod;
    while (b > 0) {
        if ((b & 1) == 1) res = res * a % mod;
        a = a * a % mod;
        b >>= 1;
    }
    return res;
}
// 面试必答："乘积型递推取对数 → 指数做斐波那契；
//   指数与系数必须用不同模数——指数模 φ(p)，系数模 p；
//   这就是本题最大的坑。"
```

### 6.3 同类题：CF 1182E 思路提纲

f(n) = f(n-1)·f(n-2)·f(n-3)·c^(2n-6)

### 7.2 四步解题法（面试口述）

```text
① 指数什么形态？（long / 字符串 / 幂塔 / 负数）
② 模数什么性质？（质数 → φ=p-1；合数 → 算 φ）
③ 指数角色 vs 系数角色？（决定模 φ(p) 还是模 p）
④ 套模板 + 检查四个坑（底数取模 / 单位矩阵 / +φ 兜底 / 溢出）
```

### 7.3 一句话考点清单

```text
快速幂：判位、自乘、边乘边模 —— 必背
矩阵快速幂：单位矩阵初始化，转移矩阵三步构造 —— 必背
欧拉降幂：b ≥ φ(m) 时 exp = b mod φ(m) + φ(m) —— 必背
双模数：指数模 φ(p)，系数模 p —— 高频坑
幂塔：φ 链递归到 1 —— 进阶
```
