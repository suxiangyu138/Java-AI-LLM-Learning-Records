## 1. 核心概念

### 1.1 快速幂解决什么

```text
朴素计算 a^b：b 次乘法 → O(b)，b = 10^18 直接爆炸
快速幂：把指数按二进制分解 → O(log b) ≈ 60 次乘法

原理（5^19 例子）：
  19 = 10011₂ = 16 + 2 + 1
  5^19 = 5^16 × 5^2 × 5^1
  → 只需把 5 不断自乘（5, 5², 5⁴, 5⁸, 5¹⁶），按位取用

取模性质（边乘边模防溢出）：
  (a × b) % m = ((a % m) × (b % m)) % m
```

### 1.2 三大应用场景（面试定位）

```text
① 大数幂取模：a^b mod p          —— 最基础，必背
② 矩阵快速幂：线性递推加速        —— 斐波那契 O(log n)、DP 转移
③ 欧拉降幂：指数超大（字符串输入）—— 超级次方、幂塔
```

### 1.3 前置知识：欧拉函数与欧拉定理

```text
欧拉函数 φ(m) = 1~m 中与 m 互质的个数
  例：φ(10) = 4（1,3,7,9）

欧拉定理：gcd(a, m) = 1 ⟹ a^φ(m) ≡ 1 (mod m)
费马小定理（m 为质数时 φ(m) = m-1）：
  a^(m-1) ≡ 1 (mod m) ⟹ 逆元 a⁻¹ ≡ a^(m-2) (mod m)

用途：指数 b 可以模 φ(m) 后计算（a^b ≡ a^(b mod φ(m))）
```

## 2. 快速幂完整模板

### 2.1 迭代版（面试标准答案）

```java
/**
 * 快速幂模板：a^b mod p（迭代版，面试必背）
 * 复杂度 O(log b)，b ≤ 10^18 用 long
 */
public long quickPow(long a, long b, long p) {
    long res = 1 % p;          // ⚠️ 模数为 1 时直接返回 0
    a %= p;                    // ⚠️ 先对底数取模，防溢出
    while (b > 0) {
        if ((b & 1) == 1) res = res * a % p;   // 当前位为 1 → 乘入
        a = a * a % p;         // 底数平方（对应二进制位左移）
        b >>= 1;               // 指数右移
    }
    return res;
}
// 模板三要点：
//   ① 位运算判位 (b & 1)
//   ② 底数自乘 a * a
//   ③ 边乘边模（防 long 溢出）
```

### 2.2 推演：2^10 mod 1000

```text
10 = 1010₂（位：8, 2）
res=1, a=2
b=10 (1010): 位0=0 → 不乘；a=4, b=5
b=5  (0101): 位0=1 → res=4；a=16, b=2
b=2  (0010): 位0=0 → 不乘；a=256, b=1
b=1  (0001): 位0=1 → res=4×256=1024 mod 1000 = 24
结果：2^10 = 1024 mod 1000 = 24 ✓
```

### 2.3 递归版（理解用）

```java
/**
 * 快速幂递归版：a^b = (a^(b/2))² × (b 为奇数 ? a : 1)
 */
public long quickPowRec(long a, long b, long p) {
    if (b == 0) return 1 % p;
    long half = quickPowRec(a, b / 2, p);
    long res = half * half % p;
    if ((b & 1) == 1) res = res * a % p;   // 奇数补一个 a
    return res;
}
// 面试可能让你写递归版：同上，注意补乘奇数次底数
```

## 3. 三种形态的选型

### 3.1 场景对比表

| 场景 | 工具 | 复杂度 | 识别信号 |
|------|------|:---:|------|
| 普通大数幂取模 | 快速幂 | O(log b) | a^b mod p |
| 线性递推加速 | 矩阵快速幂 | O(k³ log n) | f(n) = f(n-1)+f(n-2)，n 巨大 |
| 指数超级大（字符串） | 欧拉降幂 | O(log b) | 指数 10^10⁵、幂塔 |
| 指数 < φ(m) 且互质 | 直接算 | O(log b) | b 正常范围 |

### 3.2 矩阵快速幂核心模板

```java
/**
 * 矩阵快速幂：斐波那契 F(n) 用 2×2 转移矩阵加速
 * F(n) = F(n-1) + F(n-2) → 转移矩阵 [[1,1],[1,0]]
 * 复杂度 O(2³ log n) = O(log n)，n = 10^18 也没问题
 */
public long fibMat(long n, long p) {          // F(0)=0, F(1)=1
    if (n < 2) return n;
    long[][] base = {{1, 1}, {1, 0}};
    long[][] m = matPow(base, n - 1, p);       // M^(n-1)
    return m[0][0] % p;                        // F(n) = (M^(n-1))[0][0]
}

private long[][] matPow(long[][] a, long b, long p) {
    int k = a.length;
    long[][] res = new long[k][k];
    for (int i = 0; i < k; i++) res[i][i] = 1; // ⚠️ 单位矩阵（不是全 0/全 1）
    while (b > 0) {
        if ((b & 1) == 1) res = matMul(res, a, p);
        a = matMul(a, a, p);
        b >>= 1;
    }
    return res;
}

private long[][] matMul(long[][] A, long[][] B, long p) {
    int k = A.length;
    long[][] C = new long[k][k];
    for (int i = 0; i < k; i++)
        for (int j = 0; j < k; j++)
            for (int t = 0; t < k; t++)
                C[i][j] = (C[i][j] + A[i][t] * B[t][j]) % p;
    return C;
}
// 构造转移矩阵三步：写出递推 → 列向量 (F(n),F(n-1)) → 凑矩阵
```

### 3.3 欧拉降幂模板

```java
/**
 * 扩展欧拉定理：a^b mod m
 *   b < φ(m) → 直接快速幂
 *   b ≥ φ(m) → a^(b mod φ(m) + φ(m)) mod m
 * 处理 b 以字符串输入（LC 372 超级次方）
 */
public long eulerPow(long a, String b, long m) {
    if (m == 1) return 0;
    long phi = eulerPhi(m);                 // 求 φ(m)
    long exp = 0; boolean big = false;
    for (char c : b.toCharArray()) {        // 边读边模，同时判断是否 ≥ φ(m)
        exp = (exp * 10 + (c - '0')) % phi;
        if (exp * 10 + (c - '0') >= phi) big = true;
    }
    if (big) exp += phi;                    // 超界 → 加一个 φ(m)
    return quickPow(a, exp, m);
}

/** 欧拉函数：试除分解质因数 */
private long eulerPhi(long m) {
    long res = m;
    for (long i = 2; i * i <= m; i++) {
        if (m % i == 0) {
            res = res / i * (i - 1);        // ⚠️ 先除后乘防溢出
            while (m % i == 0) m /= i;      // ⚠️ 除尽，防漏质因子
        }
    }
    if (m > 1) res = res / m * (m - 1);
    return res;
}
```

## 4. 欧拉降幂速查

```text
适用条件对照：
  gcd(a,m)=1 且 b 任意      → a^b ≡ a^(b mod φ(m))        （欧拉定理）
  m 为质数                 → a^b ≡ a^(b mod (m-1))        （费马小定理）
  b ≥ φ(m) 任意 a          → a^b ≡ a^(b mod φ(m) + φ(m))  （扩展欧拉定理）

⚠️ 扩展欧拉定理为什么要 +φ(m)？
  例：2^10 mod 4，φ(4)=2，10 mod 2 = 0 → 2⁰=1 ≠ 正确值 0
  因为 2^0 ≡ 1 但 2^2 ≡ 0 mod 4，指数归零时幂不再以 1 为周期
  → b ≥ φ(m) 时必须加 φ(m) 兜底

⚠️ 模数区别：
  作为"系数"的数 → 对 p 取模
  作为"指数"的数 → 对 φ(p) 取模
  （HDU 4549 M斐波那契经典坑：指数递推模 1e9+6 而非 1e9+7）
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"快速幂把指数二进制分解：
 ① 底数 a 不断自乘（a, a², a⁴...）；
 ② 指数右移，当前位为 1 就把对应底数乘入答案；
 ③ 全程取模防溢出。
 复杂度 O(log b)。升级场景：
 矩阵快速幂处理线性递推（斐波那契 O(log n)）；
 指数超大时用欧拉降幂把指数模 φ(m)。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 为什么能二进制分解？ | 指数加法变乘法：a^(x+y) = a^x·a^y，二进制的位权相加 |
| 2 | 为什么 mod 可以边乘边模？ | 取模对乘法分配：(a×b)%m = (a%m × b%m)%m |
| 3 | 递归版怎么写？ | a^b = (a^(b/2))²，奇数补乘 a；边界 b=0 |
| 4 | 负指数怎么办？ | x⁻ⁿ = (x⁻¹)ⁿ，LC 50 用 1/x 后取正指数（整数场景） |
| 5 | 模数为 1 会怎样？ | 结果恒 0，res 初始化为 1 % p 直接兜住 |
| 6 | 矩阵快速幂的初值？ | 单位矩阵（对角 1），不是全 0 也不是全 1 |
| 7 | 什么时候用欧拉降幂？ | 指数大到不能直接读入（10^18+ 或字符串/幂塔） |
| 8 | 指数取模模什么？ | 模 φ(p)；p 为质数时模 p-1（费马小定理） |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 底数不先取模 | long 溢出 | a %= p 开头做 |
| 忘乘当前位底数 | 答案偏小 | if ((b&1)==1) res = res*a%p |
| 矩阵初值全 0/全 1 | 结果全错 | 单位矩阵 |
| 指数取模模错对象 | 结果错误难排查 | 指数模 φ(p)，系数模 p |
| 欧拉降幂不加 φ(m) | b mod φ = 0 时错 | b ≥ φ(m) 时 exp += φ(m) |
| 欧拉函数漏质因子 | φ 偏大 | while 除尽同一因子 |
| 欧拉函数先乘后除 | 溢出 | res = res / i * (i-1) |

> 🎯 **核心要点**：快速幂 = **位运算 + 二分指数**，三形态（普通/矩阵/欧拉降幂）是面试三大考点。判断信号："求幂 + 取模 + 指数大" → 快速幂；"递推 + n 巨大" → 矩阵快速幂；"指数以字符串/幂塔给出" → 欧拉降幂。模板三要点（取模、判位、自乘）必须闭眼能写。
