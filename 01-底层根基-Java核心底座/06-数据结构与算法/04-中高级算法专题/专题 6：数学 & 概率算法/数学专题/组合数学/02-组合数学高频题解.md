## 1. 62. 不同路径（公式 vs DP）

### 1.1 题目与思路

```
m×n 网格（只右/下）路径数
双解：组合公式 C(m+n-2, m-1) 与 DP
⚠️ 公式 O(min(m,n))；DP O(mn)
```

### 1.2 双解法完整代码

```java
/** 解法一：组合公式（无障碍时最优） */
public int uniquePathsFormula(int m, int n) {
    // ⚠️ 共走 m+n-2 步，选 m-1 步向下（或 n-1 步向右）
    long result = 1;
    int k = Math.min(m, n) - 1;              // 取小者防溢出
    int total = m + n - 2;
    for (int i = 1; i <= k; i++) {
        result = result * (total - k + i) / i;   // ⚠️ 边乘边除防溢出
    }
    return (int) result;
}
// 推演 m=3, n=7 → C(8,2) = 28 ✓
// ⚠️ 计算技巧：result = result * (total-k+i) / i
//   保证每步整除（组合数性质）

/** 解法二：DP（可扩展障碍） */
public int uniquePaths(int m, int n) {
    int[] dp = new int[n];
    Arrays.fill(dp, 1);                      // 第 0 行全 1
    for (int i = 1; i < m; i++)
        for (int j = 1; j < n; j++)
            dp[j] += dp[j - 1];              // 滚动数组
    return dp[n - 1];
}
// ⚠️ 面试必答："62 双解——公式 O(min) 快、
//   DP 可扩展（63 障碍版）；面试两个都能讲。"
```

## 2. 63. 不同路径 II（障碍 DP）

### 2.1 题目与思路

```
有障碍物的路径数（障碍处不可走）
DP：障碍处 dp=0、第一行/列遇障截断
⚠️ 公式失效（约束）→ DP 兜底
```

### 2.2 完整代码

```java
/**
 * LeetCode 63. 不同路径 II（障碍 DP）
 */
public int uniquePathsWithObstacles(int[][] obstacleGrid) {
    int m = obstacleGrid.length, n = obstacleGrid[0].length;
    int[] dp = new int[n];

    // ① 第一行：遇障碍后全 0
    for (int j = 0; j < n; j++) {
        if (obstacleGrid[0][j] == 1) break;  // ⚠️ 障碍截断
        dp[j] = 1;
    }

    for (int i = 1; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (obstacleGrid[i][j] == 1) {
                dp[j] = 0;                   // ⚠️ 障碍清零
            } else if (j > 0) {
                dp[j] += dp[j - 1];          // 上 + 左
            }
            // j == 0：dp[0] = 上方值（第一列只从上）
        }
    }
    return dp[n - 1];
}
// 推演 [[0,0,0],[0,1,0],[0,0,0]]：
//   第一行 [1,1,1]；第二行：障碍处 0 → [1,0,1]
//   第三行：[1,1,2] → 2 ✓
// ⚠️ 面试必答："63 = 62 + 障碍清零——
//   障碍 dp=0、首行遇障截断；
//   '约束出现公式失效转 DP'的经典。"
```

## 3. 96. 不同的二叉搜索树（卡特兰数）

### 3.1 题目与思路

```
1..n 能构成多少种 BST
卡特兰数：G(n) = Σ G(i-1)·G(n-i)
⚠️ 完整推导见分治/05（构造版 95 是枚举结构）
```

### 3.2 完整代码

```java
/**
 * LeetCode 96. 不同的二叉搜索树（卡特兰 DP）
 */
public int numTrees(int n) {
    int[] G = new int[n + 1];
    G[0] = 1;                                // 空树 1 种
    G[1] = 1;

    for (int len = 2; len <= n; len++) {     // ⚠️ 按长度递推
        for (int i = 1; i <= len; i++) {
            G[len] += G[i - 1] * G[len - i]; // 左 i-1 个 × 右 len-i 个
        }
    }
    return G[n];
}
// 推演 G(3) = G(0)G(2) + G(1)G(1) + G(2)G(0) = 2+1+2 = 5 ✓
// ⚠️ 面试必答："96 = 卡特兰递推——
//   以 i 为根 → 左 i-1 × 右 n-i；
//   结构递归是卡特兰的识别信号。"
```

## 4. 22. 括号生成（卡特兰 + 回溯）

### 4.1 题目与思路

```
n 对括号的所有合法序列（数量 = 卡特兰数）
回溯：左括号数 < n 可加左；右括号数 < 左括号数可加右
⚠️ 生成结构 → 回溯枚举（95 同族：枚举而非计数）
```

### 4.2 完整代码

```java
/**
 * LeetCode 22. 括号生成（回溯）
 */
public List<String> generateParenthesis(int n) {
    List<String> result = new ArrayList<>();
    backtrack(n, 0, 0, new StringBuilder(), result);
    return result;
}

private void backtrack(int n, int left, int right,
                       StringBuilder sb, List<String> result) {
    if (sb.length() == 2 * n) {              // 填满
        result.add(sb.toString());
        return;
    }
    if (left < n) {                          // ⚠️ 左括号还有余量
        sb.append('(');
        backtrack(n, left + 1, right, sb, result);
        sb.deleteCharAt(sb.length() - 1);    // 回溯
    }
    if (right < left) {                      // ⚠️ 右括号不能超过左
        sb.append(')');
        backtrack(n, left, right + 1, sb, result);
        sb.deleteCharAt(sb.length() - 1);
    }
}
// 推演 n=2：(())、()() → 2 种 = C(2) ✓
// ⚠️ 复杂度：O(卡特兰数 × n)（生成所有合法结构）
// ⚠️ 面试必答："22 = 回溯 + 两个约束——
//   左随时可加（left < n）、右受限于左（right < left）；
//   数量 = 卡特兰数是计数视角。"
```

## 5. 377. 组合总和 IV（排列计数 DP）

### 5.1 题目与思路

```
目标和的组合数（顺序不同算不同 → 排列计数）
dp[sum] = Σ dp[sum - num]（每个数都试）
⚠️ 与 39（回溯组合）的区别：377 是排列计数（顺序有关）
```

### 5.2 完整代码

```java
/**
 * LeetCode 377. 组合总和 IV（排列计数 DP）
 */
public int combinationSum4(int[] nums, int target) {
    int[] dp = new int[target + 1];
    dp[0] = 1;                               // 和为 0 一种（空组合）

    for (int sum = 1; sum <= target; sum++) {
        for (int num : nums) {               // ⚠️ 每个数都可以是"最后一位"
            if (sum >= num) {
                dp[sum] += dp[sum - num];    // 排列计数：顺序敏感
            }
        }
    }
    return dp[target];
}
// 推演 nums=[1,2,3], target=4：
//   dp[1]=1；dp[2]=dp[1]+dp[0]=2（1+1, 2）
//   dp[3]=dp[2]+dp[1]+dp[0]=4；dp[4]=dp[3]+dp[2]+dp[1]=7 ✓
// ⚠️ 对比 39 组合总和（回溯去重）：顺序无关
// ⚠️ 面试必答："377 = 排列计数 DP——
//   外层循环目标和、内层遍历候选（每个可当末位）；
//   与组合（39）的区别是'顺序敏感'。"
```

## 6. 组合数学方法论总结

### 6.1 解题框架

```
① 识别：计数问题 → 组合数学
② 判断顺序：顺序有关（排列）vs 无关（组合）
③ 判断约束：无约束 → 公式；有约束 → DP/回溯
④ 识别结构：结构递归 → 卡特兰
⑤ 取模：大数用阶乘逆元

⚠️ 识别信号：
  "多少种/方案数" → 计数
  "二叉树/括号/出栈" → 卡特兰
  "障碍/限制" → DP
  "顺序不同算不同" → 排列
```

### 6.2 模板速查表

| 题型 | 计数方式 | 代表题 |
|------|---------|--------|
| 路径计数 | 公式 C 或 DP | 62、63 |
| 结构计数 | 卡特兰 | 96 |
| 结构生成 | 回溯 | 22、95 |
| 排列计数 | 顺序敏感 DP | 377 |
| 组合计数 | 回溯去重 | 39 |

### 6.3 自测清单

```
□ 顺序判断（排列/组合）？
□ 公式 vs DP（有无约束）？
□ 组合数边乘边除防溢出？
□ 卡特兰识别（结构递归）？
□ 障碍清零/截断？
□ 回溯剪枝条件？
□ 取模（大数）？
```
