## 1. 核心概念

### 1.1 基础公式

```
排列（考虑顺序）：P(n,k) = n! / (n-k)!
组合（不考虑顺序）：C(n,k) = n! / (k! × (n-k)!)

常用恒等式：
  C(n,k) = C(n, n-k)                    （对称性）
  C(n,k) = C(n-1,k) + C(n-1,k-1)        （帕斯卡递推）
  C(n,0) + C(n,1) + ... + C(n,n) = 2ⁿ   （子集总数）

⚠️ 区分：
  排列 = 组合 × 内部排列（P = C × k!）
  "顺序有关" → 排列；"顺序无关" → 组合
```

### 1.2 卡特兰数（高频考点）

```
卡特兰数：C(n) = C(2n,n) / (n+1)

前几项：1, 1, 2, 5, 14, 42, 132...

应用场景（都是"配对/入栈出栈"结构）：
  ① n 对括号的合法排列数（22 生成括号）
  ② n 个节点能组成的不同 BST 数（96）
  ③ n 个元素入栈出栈的序列数
  ④ 凸多边形三角剖分数
  ⑤ 网格对角路径（不越过对角线的路径）

识别信号：结果是 1, 2, 5, 14, 42... → 卡特兰
```

### 1.3 组合计数的两类问题

```
纯计数：公式直接算（C(n,k)）
  例：62 不同路径 = C(m+n-2, m-1)

约束计数：DP 转移累加
  例：有障碍路径（DP 障碍清零）
  例：有去重要求（DP 状态去重）

选型："无约束 → 公式；有约束/动态 → DP"
```

## 2. 完整代码模板

### 2.1 组合数计算（防溢出）

```java
/**
 * 计算 C(n,k)——乘法除法交替 + 对称取小 + long
 */
public long combination(int n, int k) {
    if (k > n - k) k = n - k;          // ⚠️ 对称性：取较小 k
    long result = 1;

    for (int i = 1; i <= k; i++) {
        result = result * (n - k + i) / i;   // 每步先乘后除
        // C(n,k) = n(n-1)...(n-k+1) / k!
        // 第 i 步：result = C(n-k+i, i)
    }
    return result;
}
// C(10,3) = 10×9×8 / 3×2×1 = 120
// 推演：i=1: 10/1=10；i=2: 10×9/2=45；i=3: 45×8/3=120 ✓

/**
 * 帕斯卡三角 DP（n 较大、需要全部组合数）
 * dp[i][j] = dp[i-1][j-1] + dp[i-1][j]
 */
public long[][] pascal(int n) {
    long[][] dp = new long[n + 1][n + 1];
    for (int i = 0; i <= n; i++) {
        dp[i][0] = 1;                  // C(i,0) = 1
        for (int j = 1; j <= i; j++) {
            dp[i][j] = dp[i - 1][j - 1] + dp[i - 1][j];
        }
    }
    return dp;                         // dp[n][k] = C(n,k)
}
// O(n²) 预计算，O(1) 查询任意 C(n,k)
```

### 2.2 62. 不同路径（组合公式）

```java
/**
 * LeetCode 62. 不同路径
 * m×n 网格，只能右/下，路径数 = C(m+n-2, m-1)
 * （总共走 m+n-2 步，选 m-1 步向下）
 */
public int uniquePaths(int m, int n) {
    // 组合数可能很大 → long
    long result = 1;
    int total = m + n - 2;
    int k = Math.min(m - 1, n - 1);    // 对称取小

    for (int i = 1; i <= k; i++) {
        result = result * (total - k + i) / i;
    }
    return (int) result;
}
// m=3, n=7：total=8, k=2 → C(8,2) = 28 ✓

// DP 版（通用，可加障碍）：
// dp[i][j] = dp[i-1][j] + dp[i][j-1]（障碍处为 0）
```

### 2.3 96. 不同的 BST（卡特兰 DP）

```java
/**
 * LeetCode 96. 不同的二叉搜索树
 * n 个节点能组成的 BST 数量 = 卡特兰数
 *
 * DP 推导：dp[i] = Σ dp[j] × dp[i-1-j]
 *   根固定后：左子树 j 个节点，右子树 i-1-j 个
 *   （左右独立 → 乘法原理）
 */
public int numTrees(int n) {
    long[] dp = new long[n + 1];
    dp[0] = 1;                          // 空树
    dp[1] = 1;

    for (int i = 2; i <= n; i++) {
        for (int j = 0; j < i; j++) {
            dp[i] += dp[j] * dp[i - 1 - j];
        }
    }
    return (int) dp[n];
}
// dp[2] = dp[0]×dp[1] + dp[1]×dp[0] = 2 ✓
// dp[3] = dp[0]×dp[2] + dp[1]×dp[1] + dp[2]×dp[0] = 5 ✓
// 序列 1, 2, 5, 14... = 卡特兰数 ✓
```

## 3. 卡特兰数详解

### 3.1 递推公式

```
卡特兰数的三种形式：
  ① 组合式：C(n) = C(2n, n) / (n+1)
  ② 递推式：C(n+1) = C(n) × 2(2n+1) / (n+2)
  ③ DP 式：dp[i] = Σ dp[j] × dp[i-1-j]

面试最稳：DP 式（直观，不容易算错）
  组合式：需要先算 C(2n,n)（可能溢出）
  递推式：需要证明

代码（递推式，O(n)）：
public long catalan(int n) {
    long c = 1;                        // C(0) = 1
    for (int i = 0; i < n; i++) {
        c = c * 2 * (2L * i + 1) / (i + 2);
    }
    return c;
}
```

### 3.2 为什么这些场景都是卡特兰？

```
共同结构：第一元素/操作后，问题分裂成
  "左边子问题 × 右边子问题"（分治式计数）

例（BST）：
  选根 k → 左子树 k-1 个节点 + 右子树 n-k 个节点
  dp[n] = Σ dp[k-1] × dp[n-k] ← 正是卡特兰递推！

例（括号）：
  第一对括号把剩余分成"内部"和"外部"两部分
  同样得到分治式递推

识别口诀："分治式计数 dp[i]=Σ dp[j]×dp[i-1-j] → 卡特兰"
```

### 3.3 验证技巧

```
面试时如何快速确认是卡特兰？
  手算前几项：n=1→1, n=2→2, n=3→5
  与卡特兰序列 1,1,2,5,14,42 对照
  匹配 → 用 DP 式计算（稳）
  → 面试表达："我验证了前几项是 1,2,5，
    符合卡特兰数，用递推计算。"
```

## 4. 组合计数 vs DP 计数

### 4.1 选型对比

| 维度 | 组合公式 | DP 计数 |
|------|:---:|:---:|
| 适用 | 无约束纯计数 | 有约束/动态 |
| 实现 | 一行公式 | 转移方程 |
| 复杂度 | O(k) | O(状态数) |
| 例 | 62 无障碍路径 | 63 有障碍路径 |
| 去重 | ❌ 公式无法 | ✅ 状态设计 |

```
⚠️ 组合公式的局限：
  有障碍/有上限/有去重 → 公式失效
  → DP 是万能方案（公式是特例）
```

### 4.2 组合计数在算法题中的角色

```
① 路径计数：网格路径 = C(m+n-2, m-1)
② 子集计数：2ⁿ 个子集（含空集）
③ 方案数：卡特兰（BST/括号）
④ 概率题：C(n,k)/2ⁿ（抛硬币概率）
⑤ 数位计数：排列组合逐位统计

识别信号："多少种方案、多少种排列/组合"
⚠️ 结果巨大 → 取模（组合数取模用逆元，竞赛级）
```

### 4.3 组合数取模（进阶）

```
n ≤ 10³：帕斯卡三角 DP（O(n²)）
n ≤ 10⁷ + 质数模：阶乘 + 费马小定理逆元
  C(n,k) = n! × inv(k!) × inv((n-k)!) % mod
  inv(x) = x^(mod-2) % mod（快速幂）

面试定位：竞赛级；笔试大数组合会用到
  理解即可，手写看情况
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"这是计数问题：从 m+n-2 步中选 m-1 步向下，
 即 C(m+n-2, m-1)。
 对称性取较小 k，乘法除法交替防溢出 → O(k)。
 如果有障碍（约束），公式失效，
 改用 DP：dp[i][j] = dp[i-1][j] + dp[i][j-1]。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | C(n,k) 怎么防溢出？ | 对称取小 k + 先除后乘 + long；巨大用 BigInteger |
| 2 | 怎么识别卡特兰？ | 分治式递推 dp[i]=Σdp[j]×dp[i-1-j] + 序列 1,2,5,14 |
| 3 | 组合 vs 排列？ | 顺序相关 → 排列；无关 → 组合 |
| 4 | 何时用公式 vs DP？ | 无约束公式；有障碍/去重/动态 → DP |
| 5 | 结果巨大怎么办？ | 取模：小 n 帕斯卡；大 n 逆元（费马小定理） |
| 6 | 组合计数复杂度？ | 公式 O(k)；帕斯卡 O(n²)；逆元 O(n log n) |
| 7 | 为什么 62 是组合数？ | 路径 = 选 m-1 个"下"的位置（其余是"右"） |
| 8 | 计数 vs 列举？ | "多少种" → 计数（公式/DP）；"所有方案" → 回溯 |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 先乘后除溢出 | 结果错 | 每步除法或 long |
| 忘对称取小 | 循环太长 | k = min(k, n-k) |
| 排列组合混淆 | 结果错 | 判断顺序相关性 |
| 有约束用公式 | 结果错 | 换 DP |
| 卡特兰验证遗漏 | 误用公式 | 手算前几项对照 |

> 🎯 **核心要点**：组合数学 = **C(n,k) 公式（防溢出三招）+ 卡特兰识别（分治递推 + 序列验证）**。识别信号："多少种方案、计数"。选型口诀："无约束公式、有约束 DP、所有方案回溯"。
