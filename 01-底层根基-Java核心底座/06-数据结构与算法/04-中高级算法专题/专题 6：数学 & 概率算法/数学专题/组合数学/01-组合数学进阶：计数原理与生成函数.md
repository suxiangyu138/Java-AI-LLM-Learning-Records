## 1. 计数原理三件套

### 1.1 三大原理

```
① 加法原理：互斥事件计数相加
   A ∪ B（不相交）→ |A| + |B|

② 乘法原理：独立步骤计数相乘
   A × B → |A| × |B|

③ 容斥原理：重叠事件去重
   |A ∪ B| = |A| + |B| - |A ∩ B|
   |A ∪ B ∪ C| = 三单和 - 三双和 + 三交集

⚠️ 面试必答：
"'加法不相交、乘法独立、容斥去重叠'——
 计数题先判断事件关系再选原理。"
```

### 1.2 容斥的实战应用

```
例：1..100 中 3 或 5 的倍数个数
  |3 倍数| + |5 倍数| - |15 倍数|
  = 33 + 20 - 6 = 47 ✓

⚠️ 面试必答：
"容斥 = 加单集合 - 加双集合 + 加三集合...
 交替符号。'或'字题是容斥的识别信号。"
```

## 2. 排列与组合的完整公式

### 2.1 核心公式

```
排列（顺序有关）：P(n,k) = n! / (n-k)!
组合（顺序无关）：C(n,k) = n! / (k!(n-k)!)

⚠️ 关系：
  P(n,k) = C(n,k) × k!（排列 = 组合 × 内部排序）

⚠️ 常见变形：
  C(n,k) = C(n,n-k)（对称性）
  C(n,k) = C(n-1,k) + C(n-1,k-1)（递推，帕斯卡）

⚠️ 面试必答：
"'顺序有关排列、无关组合'——
 识别'顺序'是排列组合题的第一步；
 递推式 C(n,k) = C(n-1,k) + C(n-1,k-1) 是 DP 基础。"
```

### 2.2 组合题的识别信号

| 信号 | 结论 |
|------|------|
| "选择/分组/子集"（顺序无关） | 组合 C |
| "排列/安排/顺序" | 排列 P |
| "至少/至多/或" | 容斥/补集 |
| "恰好/至少一次" | 补集（总 - 反面） |
| "相邻/不相邻" | 捆绑法/插空法 |

```
⚠️ 面试必答：
"'至少'优先想补集（总数 - 不满足）、
 '相邻'用捆绑法（整体排列）、
 '不相邻'用插空法（空隙插入）。"
```

## 3. 卡特兰数：结构计数的通用答案

### 3.1 定义与识别

```
卡特兰数：C(n) = C(2n,n) / (n+1) = Σ C(i-1)C(n-i)

识别信号（结构递归）：
  ① n 个节点二叉树数量
  ② n 对括号合法序列
  ③ n 个元素出栈序列
  ④ 凸多边形三角剖分
  ⑤ 不越对角线路径

⚠️ 面试必答：
"卡特兰数的识别：'结构 = 左结构 × 右结构'
 的递归计数（枚举分点）——括号/二叉树/
 出栈全是一族。"
```

### 3.2 卡特兰的递推实现

```java
/** 卡特兰数（递推，O(n²)）或公式 O(n) */
long catalan(int n) {
    long[] c = new long[n + 1];
    c[0] = 1;
    for (int i = 1; i <= n; i++)
        for (int j = 0; j < i; j++)
            c[i] += c[j] * c[i - 1 - j];     // ⚠️ 枚举分点
    return c[n];
}
// 例：c(3) = c0c2 + c1c1 + c2c0 = 2+1+2 = 5 ✓
// ⚠️ 公式版：C(2n,n)/(n+1)（组合数 + 逆元）
// ⚠️ 面试必答："卡特兰递推 = 枚举分点——
//   左子问题 × 右子问题累加；
//   与 96 BST、22 括号的递归完全同构。"
```

## 4. 生成函数思想

### 4.1 生成函数是什么

```
生成函数：把计数序列变成多项式
  A(x) = Σ aₙxⁿ（aₙ = 第 n 项计数）

⚠️ 威力：多项式乘法 = 计数的卷积
  两个序列的卷积 = 组合计数的自然表达

⚠️ 面试定位：
  生成函数是组合计数的"高级工具"
  （背包计数、整数划分、组合恒等式）
  面试了解思想即可（不要求手算）

⚠️ 面试必答：
"生成函数把'计数'变成'多项式运算'——
 卷积即组合；是组合计数的统一语言。"
```

### 4.2 与背包计数的关系

```
完全背包计数 = 生成函数系数的 DP 求法：
  每件物品 = 一个因子 (1 + x + x² + ...)
  方案数 = 展开后的系数

⚠️ 面试必答：
"背包计数 = 生成函数的离散求值——
 DP 是生成函数系数的迭代算法。"
```

## 5. 组合数取模

### 5.1 三种求法

| 方法 | 复杂度 | 适用 |
|------|:---:|------|
| 递推 C(n,k) | O(n²) | n ≤ 5000 |
| 阶乘 + 逆元 | O(n) 预处理 | n ≤ 10⁶、模素数 |
| Lucas 定理 | O(log n) | n 巨大 |

```
⚠️ 面试必答：
"组合数取模三法——小 n 递推、
 大 n 阶乘逆元（费马小定理）、
 超大 n Lucas。模素数 + 逆元是主流。"
```

### 5.2 阶乘逆元模板（见数论/01 完整实现）

```java
// C(n,k) = fact[n] × invFact[k] × invFact[n-k]
// invFact 用费马小定理：invFact[n] = fastPow(fact[n], MOD-2)
// ⚠️ 面试必答："组合数取模 = 阶乘预处理 +
//   逆元除法（素数模）。"
```

## 6. 组合计数 vs DP

### 6.1 两种计数的关系

```
组合公式：闭式解（O(1)/O(n)）
DP 计数：递推解（状态转移累加）

⚠️ 什么时候用 DP：
  ① 有约束（障碍/上限）→ 公式失效
  ② 状态依赖复杂 → 递推自然
  ③ 需要中间状态 → DP 记录

⚠️ 面试必答：
"'无障碍'用公式（C 组合）、
 '有约束'用 DP（障碍清零）——
 62 与 63 正是这对对比。"
```

### 6.2 组合公式 vs DP 对照

| 问题 | 公式版 | DP 版 |
|------|--------|-------|
| 62 不同路径 | C(m+n-2, m-1) | dp[i][j] 递推 |
| 63 有障碍 | 公式失效 | 障碍清零 |
| 96 BST 数 | 卡特兰公式 | G(n) 递推 |
| 377 组合 IV | 复杂 | dp 排列计数 |

```
⚠️ 面试必答：
"'先试公式、约束多转 DP'——
 组合公式是 O(1) 捷径，DP 是通用兜底。"
```

## 7. 面试要点与追问

### 7.1 面试话术模板

```
"组合计数三问：顺序？约束？取模？
 顺序无关组合、有关排列；
 约束多转 DP、无障碍用公式；
 大数取模用阶乘逆元。
 卡特兰数识别：结构递归（左×右）。"
```

### 7.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 组合 vs 排列？ | 顺序无关 vs 有关 |
| 2 | 三大原理？ | 加法/乘法/容斥 |
| 3 | 卡特兰识别？ | 结构递归计数 |
| 4 | 至少怎么算？ | 补集（总-反面） |
| 5 | 组合数取模？ | 阶乘逆元/Lucas |
| 6 | 公式 vs DP？ | 无约束公式、有约束 DP |
| 7 | 相邻/不相邻？ | 捆绑/插空 |
| 8 | 生成函数？ | 计数 = 多项式系数 |

### 7.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 排列组合混淆 | 结果错 | 顺序判断 |
| 容斥符号错 | 多算/漏算 | 交替符号 |
| 取模除法直接除 | 错 | 逆元 |
| 忘障碍处理 | 多算 | DP 清零 |
| 卡特兰公式用错 | 错 | C(2n,n)/(n+1) |
