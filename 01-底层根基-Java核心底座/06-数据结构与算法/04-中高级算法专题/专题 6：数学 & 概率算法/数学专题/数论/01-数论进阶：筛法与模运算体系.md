## 1. 素数筛：埃氏筛与线性筛

### 1.1 埃氏筛（Sieve of Eratosthenes）

```
原理：从 2 开始，把每个素数的倍数全部标记合数
  2 标记 4,6,8...；3 标记 9,12,15...；5 标记 25,30...

优化：
  ① 只需筛到 √n（大于 √n 的合数已被更小因子标记）
  ② 从 p² 开始标记（小于 p² 的 p 的倍数已有更小素因子）

复杂度：O(n log log n)（近似线性）
```

```java
/** 埃氏筛（204 计数质数的核心） */
int countPrimes(int n) {
    if (n < 2) return 0;
    boolean[] isComposite = new boolean[n];
    int count = 0;
    for (int i = 2; i < n; i++) {
        if (!isComposite[i]) {
            count++;
            // ⚠️ 从 i*i 开始标记（i*i 之前已被更小素因子标记）
            if ((long) i * i < n) {
                for (long j = (long) i * i; j < n; j += i)
                    isComposite[(int) j] = true;
            }
        }
    }
    return count;
}
// ⚠️ 面试必答："埃氏筛从 p² 开始标记——
//   p 的小倍数已被更小的素因子覆盖，
//   这是常数优化的关键。"
```

### 1.2 线性筛（欧拉筛）

```
埃氏筛的缺陷：合数被重复标记（12 = 2×6 = 3×4）
线性筛：每个合数只被"最小素因子"标记一次 → O(n)

核心：内层循环用 prime[j] 筛 i×prime[j]，
  当 i % prime[j] == 0 时 break（保证最小素因子唯一）
```

```java
/** 线性筛：每个合数只标记一次，O(n) */
int[] linearSieve(int n) {
    boolean[] isComposite = new boolean[n + 1];
    int[] primes = new int[n + 1];
    int count = 0;

    for (int i = 2; i <= n; i++) {
        if (!isComposite[i]) primes[count++] = i;   // i 是素数
        for (int j = 0; j < count && (long) i * primes[j] <= n; j++) {
            isComposite[i * primes[j]] = true;      // 用素数筛 i 的倍数
            if (i % primes[j] == 0) break;          // ⚠️ 保证最小素因子
        }
    }
    return Arrays.copyOf(primes, count);
}
// ⚠️ break 条件：i % primes[j] == 0 时
//   i×primes[j] 的最小素因子是 primes[j]
//   （更小的素因子已在之前处理）→ 提前终止防重复标记
// ⚠️ 面试表达："线性筛 vs 埃氏筛：埃氏 O(n log log n)
//   足够；线性筛 O(n) 且能顺便求最小素因子/欧拉函数。"
```

## 2. gcd 与贝祖定理

### 2.1 欧几里得算法与贝祖

```
gcd(a, b) = gcd(b, a % b)（欧几里得，辗转相除）

贝祖定理（Bézout）：gcd(a,b) = d ⟺ ∃x,y 使 ax + by = d
  ⚠️ 应用：水壶问题（365）——两个壶能量出的
   水量 = gcd 的倍数

⚠️ 面试必答：
"贝祖定理：ax+by 能取到的所有值 = gcd(a,b) 的倍数。
 365 水壶：能否量出 target ⟺ target % gcd(x,y) == 0
 且 target ≤ 两壶总容量。"
```

### 2.2 扩展欧几里得（exgcd）

```java
/** 扩展欧几里得：求 ax + by = gcd(a,b) 的一组解 */
long[] exgcd(long a, long b) {
    if (b == 0) return new long[]{1, 0};          // a×1 + 0×0 = a
    long[] r = exgcd(b, a % b);
    return new long[]{r[1], r[0] - (a / b) * r[1]};
}
// ⚠️ 应用：乘法逆元（解同余方程 ax ≡ 1 mod m）
// 面试定位：知道存在性（贝祖）+ 能写模板即可
```

### 2.3 gcd 的高频应用

| 应用 | 原理 |
|------|------|
| 分数化简 | 分子分母 ÷ gcd |
| 最简斜率 | dx/dy ÷ gcd（149 题键） |
| 水壶量水 | 贝祖定理 |
| 周期性 | gcd(周期1, 周期2) |
| 字符串 gcd | 长度 gcd（1071） |

## 3. 快速幂与欧拉降幂

### 3.1 快速幂（二分幂）

```java
/** 快速幂：a^b mod m，O(log b) */
long fastPow(long a, long b, long mod) {
    long result = 1 % mod;
    a %= mod;
    while (b > 0) {
        if ((b & 1) == 1) result = result * a % mod;   // ⚠️ 奇数位累乘
        a = a * a % mod;                                // 平方
        b >>= 1;                                        // 指数减半
    }
    return result;
}
// 推演 3^5：b=101
//   b=5(奇)：res=3；a=9；b=2
//   b=2(偶)：res=3；a=81；b=1
//   b=1(奇)：res=3×81=243 ✓
// ⚠️ 面试必答："快速幂 = 指数二进制分解——
//   每步平方 + 按位累乘，O(log b)。"
```

### 3.2 欧拉降幂

```
欧拉定理：a^φ(m) ≡ 1 (mod m)（gcd(a,m)=1）
降幂公式：a^b mod m = a^(b mod φ(m) + φ(m)) mod m（b ≥ φ(m)）

⚠️ 应用（372 超级次方）：指数是数组（巨大）
   → 欧拉降幂把指数压到 φ(m) 内

⚠️ 面试必答：
"大指数取模 → 欧拉降幂：指数对 φ(m) 取模。
 372 的指数是数组（10^100 级别）——
 降幂后快速幂解决。"
```

### 3.3 欧拉函数（φ）

```
φ(n) = 1..n 中与 n 互质的个数
  φ(p) = p-1（素数）
  φ(p^k) = p^k - p^(k-1)
  积性：gcd(a,b)=1 → φ(ab) = φ(a)φ(b)

⚠️ 面试表达：
"欧拉函数是模运算体系的基石——
 φ(p)=p-1 给出费马小定理（下节）。"
```

## 4. 模运算体系

### 4.1 模运算的性质

```
(a + b) % m = (a%m + b%m) % m
(a × b) % m = (a%m × b%m) % m
⚠️ 除法不直接成立 → 需要乘法逆元

⚠️ Java 负数取模：(-5) % 3 = -2
  转正：(x % m + m) % m

⚠️ 面试必答：
"模运算加减乘都保序，除法定理需要逆元；
 Java 负数取模要先转正（+m 再 %m）。"
```

### 4.2 乘法逆元与费马小定理

```
乘法逆元：a × a⁻¹ ≡ 1 (mod m)

费马小定理（m 是素数）：a^(m-1) ≡ 1 (mod m)
  → a⁻¹ ≡ a^(m-2) (mod m)（快速幂求逆元）

⚠️ 应用：
  组合数取模的除法
  分数取模（竞赛高频）
  同余方程的求解

⚠️ 面试必答：
"素数模数下逆元 = 快速幂 a^(m-2)（费马小定理）；
 非素数模 → 扩展欧几里得。"
```

## 5. 组合数取模

### 5.1 三种求法

| 方法 | 复杂度 | 适用 |
|------|:---:|------|
| 递推 C(n,k) = C(n-1,k) + C(n-1,k-1) | O(n²) | n ≤ 5000 |
| 阶乘 + 逆元 | O(n) 预处理 | n ≤ 10⁶，模素数 |
| Lucas 定理 | O(log n) | n 巨大，模素数 |

```java
/** 阶乘 + 逆元求组合数（模素数） */
long[] fact, invFact;                        // 阶乘与阶乘逆元
long MOD = 1_000_000_007L;

void preprocess(int n) {
    fact = new long[n + 1];
    invFact = new long[n + 1];
    fact[0] = 1;
    for (int i = 1; i <= n; i++) fact[i] = fact[i - 1] * i % MOD;
    invFact[n] = fastPow(fact[n], MOD - 2, MOD);   // ⚠️ 费马小定理
    for (int i = n - 1; i >= 0; i--)
        invFact[i] = invFact[i + 1] * (i + 1) % MOD;
}

long C(int n, int k) {
    if (k < 0 || k > n) return 0;
    return fact[n] * invFact[k] % MOD * invFact[n - k] % MOD;
}
// ⚠️ 面试必答："组合数取模 = 阶乘预处理 +
//   逆元除法——费马小定理（a^(m-2)）求逆元，
//   O(1) 查询。"
```

### 5.2 常见取模陷阱

```
① 中间乘法溢出 → 每步 % MOD
② 减法负数 → (x - y + MOD) % MOD
③ 除法 → 逆元（不是直接除）
④ 比较大小取模后失真 → 需取模前比较

⚠️ 面试表达：
"取模四陷阱：乘法溢出、减法负数、
 除法逆元、比较失真——每步取模是铁律。"
```

## 7. 面试要点与追问

### 7.1 面试话术模板

```
"数论题先定工具：素数 → 埃氏筛 O(n log log n)；
 gcd → 欧几里得 + 贝祖（ax+by = gcd 的倍数）；
 幂 → 快速幂 O(log b)（指数大 → 欧拉降幂）；
 取模 → 每步取模 + 除法用逆元（费马小定理）。"
```

### 7.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 埃氏筛复杂度？ | O(n log log n) |
| 2 | 线性筛 break？ | 保证最小素因子唯一标记 |
| 3 | 贝祖定理？ | ax+by = gcd 的倍数 |
| 4 | 快速幂？ | 指数二进制分解 O(log b) |
| 5 | 欧拉降幂？ | 指数对 φ(m) 取模 |
| 6 | 逆元？ | 费马小定理 a^(m-2)（素数模） |
| 7 | 组合数取模？ | 阶乘 + 逆元 |
| 8 | 取模陷阱？ | 负数转正/除法逆元 |

### 7.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 筛到 n 而非 √n | 常数浪费 | 从 p² 开始 |
| 幂运算 int 溢出 | 结果错 | long + 每步取模 |
| 负数取模 | 键错 | (x%m+m)%m |
| 除法直接取模 | 结果错 | 逆元 |
| 组合数递推 n 大 | OOM | 阶乘 + 逆元 |
