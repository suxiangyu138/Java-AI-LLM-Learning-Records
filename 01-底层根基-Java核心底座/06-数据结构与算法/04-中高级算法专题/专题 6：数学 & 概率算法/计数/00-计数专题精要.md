## 1. 核心概念

### 1.1 计数的三种形式

```
① 计数数组（int[26]/int[n]）：值域小且已知
   → 字符频次、数值频次
   → 下标 = 值，元素 = 频次

② 哈希计数（HashMap）：值域大/未知
   → 通用计数
   → getOrDefault + 1

③ 计数排序：值域小 → 频次 → 前缀和 → 排序
   → O(n+k) 线性排序（见排序体系）

选型：值域小 → 数组；值域大/动态 → HashMap
```

### 1.2 计数的核心价值

```
把"查找/比较"变成"下标访问" → O(1)

① 判断/统计频次：异位词、重复元素
② TopK 频次：计数 + 堆/桶
③ 频次比较：两个数组的异同
④ 计数的计数：频次作为键（桶思想）
⑤ 字符统计：26 字母计数

⚠️ 数组 vs HashMap 选型：
  值域小且连续（26 字母/0-100）→ 数组 O(1) 访问
  值域大/未知/稀疏 → HashMap
```

### 1.3 识别信号

```
"出现次数、频次、异位词、前 K 高频、频率"
→ 计数

⚠️ 计数的计数（二阶计数）：
  频次本身作为下标（桶排序思想）
  例：347 用频次做桶 → O(n) 免排序
```

## 2. 完整代码模板

### 2.1 计数数组（字符频次）

```java
/**
 * LeetCode 242. 有效的字母异位词
 * 计数数组：s 加、t 减 → 全部为 0 则异位词
 */
public boolean isAnagram(String s, String t) {
    if (s.length() != t.length()) return false;

    int[] count = new int[26];
    for (int i = 0; i < s.length(); i++) {
        count[s.charAt(i) - 'a']++;    // s 加
        count[t.charAt(i) - 'a']--;    // t 减
    }
    for (int c : count) {
        if (c != 0) return false;      // 任何计数不为 0 → 不同
    }
    return true;
}
// 一次遍历双向计数 → O(n) / O(1)
// ⚠️ 为什么双向？不用两个数组再比较（省一次遍历）
```

### 2.2 哈希计数（通用）

```java
/**
 * 哈希计数模板（值域大/未知）
 */
Map<Integer, Integer> count = new HashMap<>();
for (int x : nums) {
    // ⚠️ getOrDefault 必须 +1（否则覆盖而非累加）
    count.put(x, count.getOrDefault(x, 0) + 1);
}

// 更简洁的写法：merge
count.merge(x, 1, Integer::sum);

// ⚠️ 遍历时修改：
//   for-each 中不能直接 put/remove（ConcurrentModification）
//   → 用 entrySet 或先收集再修改
```

### 2.3 字符计数键（异位词分组）

```java
/**
 * LeetCode 49. 字母异位词分组
 * 计数数组转字符串做键："#1#1#1#0..."（26 位）
 */
public List<List<String>> groupAnagrams(String[] strs) {
    Map<String, List<String>> map = new HashMap<>();

    for (String s : strs) {
        int[] count = new int[26];
        for (char c : s.toCharArray()) {
            count[c - 'a']++;          // 计数
        }
        // 计数 → 规范键（异位词共享同键）
        StringBuilder key = new StringBuilder();
        for (int x : count) {
            key.append('#').append(x);
        }
        map.computeIfAbsent(key.toString(),
            k -> new ArrayList<>()).add(s);
    }
    return new ArrayList<>(map.values());
}
// "eat" → "#1#0#0...#1#1"；"tea" 同键 → 同组 ✓
// O(nk)（n 个词 × 每个 k 长度）
```

## 3. 频次桶详解

### 3.1 347. 前 K 高频元素（频次桶）

```java
/**
 * LeetCode 347. 前 K 高频元素
 * 桶排序思想：下标 = 频次，桶内 = 该频次的元素
 *   → O(n) 免排序（频次范围 ≤ n）
 */
public int[] topKFrequent(int[] nums, int k) {
    // ① 计数
    Map<Integer, Integer> freq = new HashMap<>();
    for (int x : nums) freq.merge(x, 1, Integer::sum);

    // ② ⚠️ 频次桶：下标 = 频次（最大频次 ≤ n）
    List<Integer>[] buckets = new List[nums.length + 1];
    for (var e : freq.entrySet()) {
        int f = e.getValue();
        if (buckets[f] == null) buckets[f] = new ArrayList<>();
        buckets[f].add(e.getKey());
    }

    // ③ 从高频往低频收集 k 个
    int[] result = new int[k];
    int idx = 0;
    for (int f = buckets.length - 1; f > 0 && idx < k; f--) {
        if (buckets[f] != null) {
            for (int x : buckets[f]) result[idx++] = x;
        }
    }
    return result;
}
// O(n)：计数 O(n) + 分桶 O(n) + 收集 O(k)
// 对比堆解法 O(n log k)：频次桶更快！
```

### 3.2 频次桶 vs 堆

| 维度 | 频次桶 | 堆 |
|------|:---:|:---:|
| 复杂度 | **O(n)** | O(n log k) |
| 空间 | O(n) | O(k) |
| 实现 | 稍复杂 | 简单 |
| 适用 | 频次范围可控 | 通用 |
| 数据流 | ❌ | ✅ |

```
选型：静态数组 + 频次可控 → 频次桶更快
     数据流/在线 → 堆
```

### 3.3 451. 按频率排序字符（桶拼接）

```java
/**
 * LeetCode 451. 根据字符出现频率排序
 * 频次桶 → 从高频到低频拼接字符
 */
public String frequencySort(String s) {
    int[] freq = new int[128];               // ASCII
    for (char c : s.toCharArray()) freq[c]++;

    // 桶：下标 = 频次
    List<Character>[] buckets = new List[s.length() + 1];
    for (int i = 0; i < 128; i++) {
        if (freq[i] > 0) {
            if (buckets[freq[i]] == null) buckets[freq[i]] = new ArrayList<>();
            buckets[freq[i]].add((char) i);
        }
    }

    StringBuilder sb = new StringBuilder();
    for (int f = buckets.length - 1; f > 0; f--) {   // 高频优先
        if (buckets[f] != null) {
            for (char c : buckets[f]) {
                for (int i = 0; i < f; i++) sb.append(c);  // 重复 f 次
            }
        }
    }
    return sb.toString();
}
// "tree" → freq: t1 r1 e2 → 桶[2]=[e], 桶[1]=[t,r] → "eetr" ✓
```

## 4. 计数的进阶应用

### 4.1 计数 + 滑动窗口

```
字符频次数组维护窗口状态（滑窗模板的"维护结构"）：
  3. 无重复最长子串：count[c] > 1 → 缩窗
  567. 字符串排列：need 与 window 频次比较
  76. 最小覆盖子串：need[] 负数表示多余

⚠️ 计数数组做窗口状态 → O(1) 更新
  （比 HashMap 快，值域小时首选）
```

### 4.2 计数 + 前缀和

```
统计"和为 K / 可被 K 整除"的子数组个数：
  前缀和 + 计数（HashMap 存前缀和出现次数）

变体：
  560 和为 K：count[pre - k]
  974 可被 K 整除：count[pre mod K]（⚠️ 负数取模）

⚠️ 为什么用计数？前缀和可能重复出现
  → 计数而非只存是否存在
```

### 4.3 计数的计数（频次的频次）

```
应用：最少操作使数组元素相等（453）
  保留频次最大的值不动，其余 +1 到位

⚠️ 概念：
  一阶计数：值 → 频次
  二阶计数：频次 → 值列表（桶）
  三阶：频次 → 频次（更少见）

面试表达："我用二阶计数（频次作桶下标），
 免去排序 → O(n)"
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"字符频次用 26 长度计数数组——下标是字符、
 元素是频次。比较两个字符串是否异位词
 就是计数数组相减全为 0，O(n) 一次遍历。
 前 K 高频用频次桶：频次作为桶下标，
 O(n) 分桶后从高频往低频收集，免排序。
 值域大时改用 HashMap 计数。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 数组 vs HashMap 计数？ | 值域小且连续 → 数组 O(1)；大/未知 → HashMap |
| 2 | getOrDefault 易错？ | 忘 +1 会覆盖而非累加；merge 更简洁 |
| 3 | 频次桶为什么免排序？ | 桶下标 = 频次 → 天然有序（O(n) 收集） |
| 4 | 频次桶 vs 堆？ | 静态频次桶 O(n)；流式/大数据堆 O(n log k) |
| 5 | 字符计数键？ | 计数数组转字符串（"#1#0..."）→ 异位词同键 |
| 6 | 计数在滑窗中？ | 频次数组做窗口状态 → O(1) 更新 |
| 7 | 计数的计数？ | 频次作桶下标（二阶计数） |
| 8 | 计数排序关系？ | 计数排序 = 计数 + 前缀和 + 回填（线性排序） |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| getOrDefault 忘 +1 | 计数变覆盖 | +1 或 merge |
| 桶数组越界 | 频次 = n 时 | 长度 n+1 |
| 遍历时修改 map | 并发异常 | entrySet/收集 |
| 字符转下标忘 -'a' | 越界 | c - 'a' |
| 收集顺序错 | TopK 反了 | 从高频往低频 |

> 🎯 **核心要点**：计数 = **数组（小值域）/HashMap（大值域）**两种形式 + **频次桶**（二阶计数免排序）。识别信号："频次、出现次数、异位词、前 K 高频"。getOrDefault+1 与频次桶是两大细节考点。
