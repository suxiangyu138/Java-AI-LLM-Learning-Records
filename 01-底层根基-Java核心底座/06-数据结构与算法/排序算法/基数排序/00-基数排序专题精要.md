## 1. 核心概念

### 1.1 什么是基数排序

> 基数排序：对数值**按位多次排序**（个位 → 十位 → 百位...），每位用**稳定的**计数排序。复杂度 O(kn)（k = 最大位数）。

```
例：[170, 45, 75, 90, 802, 24, 2, 66]

按个位排：170, 90, 802, 2, 24, 45, 75, 66
按十位排：802, 2, 24, 45, 66, 170, 75, 90
按百位排：2, 24, 45, 66, 75, 90, 170, 802 ✓

为什么按位排有效？
  低位先排好 → 高位相同时低位顺序保持
  （稳定性是关键！）
```

### 1.2 LSD 与 MSD

```
LSD（低位优先）：从个位到高位 ★ 常用
  → 每次稳定排序，高位相同时低位有序

MSD（高位优先）：从高位到低位
  → 需递归处理每组，实现复杂

面试掌握 LSD 即可
```

### 1.3 识别信号

```
"定长数值（ID/时间戳/固定位数）" → 基数排序
"要求 O(n) 排序 + 数值可拆位" → 基数排序

⚠️ 面试定位：
  了解原理 + 能手写按位计数排序
  高频度低于快排/归并（面试很少要求手撕）
  但"三种线性排序对比"是高频追问
```

## 2. 完整代码模板

### 2.1 LSD 完整实现（十进制）

```java
/**
 * 基数排序（LSD，十进制）——面试标准答案
 */
public void radixSort(int[] arr) {
    if (arr.length == 0) return;

    // ① 找最大值确定位数
    int max = 0;
    for (int x : arr) max = Math.max(max, x);

    // ② 按位排序：exp = 1, 10, 100...
    for (int exp = 1; max / exp > 0; exp *= 10) {
        countingSortByDigit(arr, exp);
    }
}

// 按某一位稳定排序（计数排序核心）
private void countingSortByDigit(int[] arr, int exp) {
    int n = arr.length;
    int[] count = new int[10];         // 十进制 0-9
    int[] result = new int[n];

    // ① 该位的数字计数
    for (int x : arr) {
        count[(x / exp) % 10]++;
    }

    // ② 前缀和（确定位置）
    for (int i = 1; i < 10; i++) {
        count[i] += count[i - 1];
    }

    // ③ ⚠️ 倒序回填（稳定性关键！）
    for (int i = n - 1; i >= 0; i--) {
        int digit = (arr[i] / exp) % 10;
        result[--count[digit]] = arr[i];
    }
    System.arraycopy(result, 0, arr, 0, n);
}
// 复杂度：O(k×n)（k = 最大位数）+ O(10) 空间
```

### 2.2 推演：[170, 45, 75, 90, 802, 24, 2, 66]

```
按个位（exp=1）：
  数字：0,5,5,0,2,4,2,6
  排序后：170, 90, 802, 2, 24, 45, 75, 66
  （个位 0:170,90；2:802,2；4:24；5:45,75；6:66）

按十位（exp=10）：
  数字：7,9,0,0,2,4,7,6
  排序后：802, 2, 24, 45, 66, 170, 75, 90
  （十位 0:802,2；2:24；4:45；6:66；7:170,75；9:90）
  ⚠️ 170 和 75 十位都是 7 → 保持个位顺序（稳定！）

按百位（exp=100）：
  数字：8,0,0,0,0,1,0,0
  排序后：2, 24, 45, 66, 75, 90, 170, 802 ✓
  （百位 0 的保持十位顺序 → 完全有序！）
```

/**
 * 负数处理：分离正负
 * ① 负数取绝对值 → 基数排序 → 逆序拼接
 * ② 正数基数排序 → 拼接
 */
public void radixSortWithNegatives(int[] arr) {
    List<Integer> neg = new ArrayList<>();
    List<Integer> pos = new ArrayList<>();
    for (int x : arr) {
        if (x < 0) neg.add(-x);        // ⚠️ 取绝对值
        else pos.add(x);
    }
    // 分别基数排序
    // 负数组逆序（绝对值大的更小）→ 拼接
}

## 3. 稳定性的关键作用

### 3.1 为什么必须稳定？

```
高位排序后，低位顺序必须保持：
  例：170 和 75（十位都是 7）
  若个位顺序被破坏 → 170 可能在 75 后
  → 百位排序时顺序错误

稳定性保证：
  高位相同时 → 按低位的顺序（已排好）
  → 每轮排序后整体"按已处理位有序"

⚠️ 面试必答：
"基数排序每轮必须稳定——高位排序后
 要保持低位的已有顺序，不稳定会导致
 结果错误。倒序回填正是为了实现稳定。"
```

### 3.2 稳定性验证

```
关键轮次：多位相同的元素
  170 与 75（十位同 7）：
  个位 170(0) < 75(5) → 排序后 170 在前
  十位排序保持该顺序 → 最终 170 在 75 前 ✓

⚠️ 用不稳定排序（正序回填）会怎样？
  个位顺序反转 → 十位相同时顺序错 → 最终错
```

### 3.3 与计数排序的依赖

```
基数排序 = 多次计数排序（按位）
  计数排序提供"稳定的按位排序"
  倒序回填 → 稳定性 → 基数正确性

⚠️ 关系记忆：
  "基数排序的组件是稳定计数排序"
  （计数排序的稳定性是基数的前提）
```

## 4. 基数排序 vs 其他线性排序

### 4.1 对比表

| 排序 | 维度 | 复杂度 | 适用 |
|------|:---:|:---:|------|
| 计数 | 值域 | O(n+k) | 值域小 |
| 桶 | 区间 | O(n+k) | 均匀分布 |
| 基数 | 位数 | O(kn) | 定长数值 |

```
关系：基数排序 = 按位重复计数排序
  每位的桶数 = 基数（十进制 10、二进制 2）
  稳定 → 高位处理不破坏低位
```

### 4.2 选型判断

```
计数 vs 基数：
  值域小（0-100）→ 计数（一轮 O(n+k)）
  值域大但位数少（32 位整数）→ 基数（k=10 轮）

基数 vs 快排：
  定长数值 + 要求 O(n) → 基数
  通用场景 → 快排（常数小）

⚠️ 复杂度的 k：
  k = 最大位数 = log₁₀(max)
  定长数据（32 位整数）→ k 恒定 → 视为 O(n)
```

### 4.3 基数排序的优缺点

```
优点：
  线性复杂度（k 恒定时）
  稳定（可做二次排序）
  无比较 → 突破下界

缺点：
  需要可拆位（数值/字符串）
  每轮额外空间 O(n)
  负数/浮点处理麻烦
  ⚠️ 字符串也可基数排序（按字符位）
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"定长数值可用基数排序：按位多次稳定排序，
 每位用计数排序（桶数 = 基数 10）。
 关键：必须稳定——高位排序后要保持低位顺序。
 O(k×n) 时间，k 为位数（定长时视为 O(n)）。
 空间 O(n)（每轮结果数组）。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 为什么必须稳定？ | 高位排序保持低位顺序（否则结果错误） |
| 2 | 复杂度？ | O(k×n)（k = 位数）；定长视为 O(n) |
| 3 | 与计数排序关系？ | 基数 = 按位重复稳定计数排序 |
| 4 | 负数处理？ | 分离正负 → 负的逆序拼接 |
| 5 | 什么时候优于快排？ | 定长数值 + 要求 O(n) |
| 6 | 稳定性怎么实现？ | 倒序回填（计数排序的稳定写法） |
| 7 | 字符串可以吗？ | 可以（按字符位，需等长处理） |
| 8 | 空间？ | O(n+k)（结果数组 + 计数） |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 忘稳定性 | 结果错误 | 倒序回填 |
| exp 循环边界 | 漏最高位 | max/exp > 0 |
| 位数取数错 | 排序错 | (x/exp)%10 |
| 负数直接排 | 结果错 | 分离处理 |
| 拷贝漏 | 原数组未变 | System.arraycopy |

> 🎯 **核心要点**：基数排序 = **按位稳定计数排序 × 位数轮**。识别信号："定长数值、O(n) 需求"。稳定性是正确性关键（高位不破坏低位）；与计数/桶的对比是面试追问点；"k 恒定时视为 O(n)"是复杂度表达要点。
