## 1. 排序的本质与分类

### 1.1 排序的定义

> 排序：将一组记录按关键字大小有序排列。**记录的完整性**——排序不只是排数字，而是排携带数据的记录（稳定排序的意义就在于此）。

### 1.2 两大分类体系

```
按是否基于比较：
  比较排序：冒泡/选择/插入/希尔/快排/归并/堆排
    → 下界 Ω(n log n)，通用性强
  非比较排序：计数/基数/桶
    → 可达到 O(n)，但受值域/分布限制

按时间复杂度：
  O(n²) 初级：冒泡/选择/插入/希尔
  O(n log n) 高级：快排/归并/堆排
  O(n) 线性：计数/基数/桶
```

### 1.3 为什么学排序？

```
排序是算法面试的基础设施：
  1. 二分查找的前提（有序数组）
  2. TopK、中位数等问题的基础
  3. 分治思想（快排/归并）的最佳教学载体
  4. 稳定性的概念延伸到工程二次排序
  5. 面试考察：手撕代码 + 复杂度 + 场景选型
```

## 2. 稳定性：最重要的概念

### 2.1 定义

> **稳定排序**：排序后，相等关键字元素的**相对顺序**保持不变。

```
不稳定示例（选择排序）：
  原数组：[(a,3), (b,3), (c,1)]
  按值排序后：(c,1), (a,3), (b,3)
  a 和 b 值相等（都是 3），原顺序 a 在 b 前
  选择排序可能变成 b 在 a 前 → 不稳定

稳定排序（归并）：
  (c,1), (a,3), (b,3)  ← a 仍然在 b 前面 ✓
```

### 2.2 为什么稳定性重要？（二次排序）

```
应用场景：先按学号排序，再按分数排序
  需求：分数相同的，学号小者在前（保持学号的有序性）

正确做法：先按学号排一次（稳定），再按分数排（稳定）
  → 分数相同的学生自动保持学号顺序

如果用不稳定排序按分数排 → 学号顺序被打乱 → 需求无法满足

结论：多关键字排序必须用稳定排序！
```

### 2.3 各排序稳定性速记

| 稳定 | 不稳定 |
|------|------|
| 冒泡（相等不交换） | 选择（远距离交换） |
| 插入（相等不越过） | 希尔（分组打乱） |
| 归并（左半优先） | 快排（partition 交换） |
| 计数/基数/桶 | 堆排（堆顶交换） |

> 🎯 **记忆技巧**："冒插归"（冒泡、插入、归并）+ 三个线性排序稳定；"选快希堆"不稳定。

## 3. 原地 vs 非原地

### 3.1 定义

```
原地排序（In-place）：额外空间 O(1)（常数级）
  冒泡/选择/插入/希尔/快排（递归栈不算）/堆排

非原地排序：需要 O(n) 或更多辅助空间
  归并（辅助数组 O(n)）
  计数/基数/桶（计数数组/桶数组）
```

### 3.2 空间复杂度细节

| 算法 | 额外空间 | 说明 |
|------|:---:|------|
| 快排 | O(log n) | 递归栈深度（平均），最坏 O(n) |
| 归并 | O(n) | 合并时的辅助数组 |
| 堆排 | O(1) | 原地交换，无递归 |
| 计数 | O(k) | k = 值域大小 |
| 基数 | O(n+k) | 桶数组 |

> 💡 快排通常被归为原地排序（交换在数组内），但严格说递归栈占用 O(log n) 空间。面试讲"原地"时可以说"忽略递归栈，快排是原地交换"。

## 4. 比较排序下界 Ω(n log n)

### 4.1 决策树论证

```
任何基于比较的排序都可以抽象为决策树：
  每个节点 = 一次比较（a[i] < a[j]?）
  左子树 = 比较结果为真，右子树 = 为假
  叶子节点 = 一种最终排列

n 个元素有 n! 种排列 → 决策树至少有 n! 个叶子
二叉树高度 h 最多有 2^h 个叶子 → 2^h ≥ n! → h ≥ log₂(n!)

由斯特林公式：log₂(n!) ≈ n log₂ n - 1.44n
→ 任何比较排序最坏情况至少需要 Ω(n log n) 次比较 ✓
```

### 4.2 三类高级排序的比较次数

| 算法 | 比较次数 | 达到下界？ |
|------|:---:|:---:|
| 归并 | 最优 n log n - n + 1 | ✅ 渐近达到 |
| 堆排 | 约 2n log n | ✅ 渐近达到 |
| 快排 | 平均 1.39n log n | ✅ 平均达到 |

### 4.3 为什么非比较排序能突破下界？

```
计数排序等不用比较，而是利用值的直接映射：
  值 v → 计数数组下标 v → 直接确定位置
  → 绕过决策树模型 → 可以 O(n)

代价：需要知道值域范围，值域大时不可行
```

## 5. 复杂度分析方法

### 5.1 分析框架：三层复杂度

```
最好情况（Best）：输入已有序/近乎有序
最坏情况（Worst）：输入逆序/最不利分布
平均情况（Average）：随机输入的平均期望

例：快速排序
  最好/平均 O(n log n)：基准划分均衡
  最坏 O(n²)：已有序 + 固定基准 → 每次只排除一个元素
```

### 5.2 归并为什么无退化？

```
归并的拆分与数据无关：
  无论输入如何，递归树结构固定（每次对半分）
  树高 log₂n 层，每层合并总代价 O(n)
  → 最好 = 最坏 = 平均 = O(n log n)

快排的拆分依赖基准值：
  基准是数据的一部分 → 数据分布影响划分均衡度
  → 最好/平均 O(n log n)，最坏 O(n²)
```

### 5.3 面试复杂度讲解话术

```
"排序复杂度要看三个维度：
 时间上，归并最稳定（永远 O(n log n)），快排平均最快
 （常数小、缓存友好），堆排最坏有保障；
 空间上，堆排 O(1) 最优，归并需要 O(n) 辅助数组；
 稳定性上，归并稳定，快排和堆排不稳定。
 所以：通用排序默认快排，稳定需求用归并，
 内存受限用堆排，链表排序用归并（无随机访问）。"
```

## 6. 排序术语速查表

| 术语 | 含义 | 示例 |
|------|------|------|
| **逆序对** | i<j 且 a[i]>a[j] 的对数 | [3,1,2] 有 2 个逆序对 |
| **有序度** | 正序对数量 | 完全有序 = n(n-1)/2 |
| **基准 pivot** | 快排分区依据 | 首/尾/随机/三数取中 |
| **分区 partition** | 按基准划分数组 | 快排核心操作 |
| **下沉 sift-down** | 堆中节点与子节点比较下移 | 堆排建堆 |
| **希尔增量** | 分组间隔序列 | gap = n/2 递减 |
| **桶** | 分区间容器 | 桶排序/基数排序 |
| **哨兵** | 分区时不交换直接覆盖 | 快排优化写法 |
| **双轴快排** | 两个基准的 partition | Java Arrays.sort 基本类型 |
| **TimSort** | 归并+插入混合 | Java Arrays.sort 对象类型 |
| **顺段 run** | 外部排序中的有序段 | 外部排序 |

> 🎯 **核心要点**：排序理论三大基石——**稳定性**（二次排序场景）、**原地性**（空间复杂度）、**比较下界**（Ω(n log n)，非比较排序的突破）。先背熟"冒插归稳定、选快希堆不稳定"和复杂度表，再学具体算法，事半功倍。
