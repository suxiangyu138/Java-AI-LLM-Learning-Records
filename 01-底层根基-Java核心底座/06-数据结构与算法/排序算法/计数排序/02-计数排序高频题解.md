## 1. 75. 颜色分类（计数版 + 荷兰国旗双解）

### 1.1 题目与思路

```
原地排序 0/1/2（颜色分类），不允许计数？——不，题目要求"一趟 + 常数空间"
⚠️ 计数排序版：两趟（统计 + 重写）——不符合"一趟"但符合"常数空间"
  荷兰国旗版：三指针一趟 —— 题目标准答案
⚠️ 两版都要会：计数版展示"值域小直接用计数"的直觉
```

### 1.2 双解法完整代码

```java
/** 解法一：计数排序版（O(n)，两趟）——值域只有 3，最直接 */
public void sortColorsCount(int[] nums) {
    int[] count = new int[3];
    for (int x : nums) count[x]++;               // ① 频次
    int idx = 0;
    for (int v = 0; v < 3; v++)                  // ② 展开
        while (count[v]-- > 0) nums[idx++] = v;
}
// 推演 [2,0,2,1,1,0]：count=[2,2,2] → [0,0,1,1,2,2] ✓
// ⚠️ 复杂度 O(n)，但"两趟 + 额外 O(3) 空间"——不合题意要求

/** 解法二：荷兰国旗（三指针一趟 + 原地）——标准答案 */
public void sortColors(int[] nums) {
    int lo = 0, hi = nums.length - 1, i = 0;
    while (i <= hi) {
        if (nums[i] == 0) {
            swap(nums, lo++, i++);               // 0 换到左区
        } else if (nums[i] == 2) {
            swap(nums, i, hi--);                 // ⚠️ 2 换到右区（i 不动！）
        } else {
            i++;                                 // 1 留在中间
        }
    }
}
// 推演 [2,0,2,1,1,0]：
//   i=0(2) → 换 hi=5 → [0,0,2,1,1,2]
//   i=0(0) → 换 lo=0, i=1 → [0,0,2,1,1,2]
//   i=1(0) → 换 lo=1, i=2 → [0,0,2,1,1,2]
//   i=2(2) → 换 hi=4 → [0,0,1,1,2,2] ✓
// ⚠️ 三指针细节：换入 2 时 i 不前进（换来的可能是 0/2 需再处理）
//   换入 0 时 i 前进（换来的 1 或原 0 已就位？——lo 只指向 0/1 区）
// ⚠️ 面试表达："75 题计数版 O(n) 两趟最直观；
//   荷兰国旗三指针一趟原地是标准解——i 遇到 2
//   换后不前进是防漏的关键。"
```

## 2. 1122. 数组的相对排序

### 2.1 题目与思路

```
arr2 定义顺序：arr2 中出现的元素按 arr2 顺序排前面
其余元素升序排后面
计数排序版：
  ① 统计 arr1 频次
  ② 按 arr2 顺序输出（每元素输出 count 次）
  ③ 剩余元素按值升序输出
⚠️ 题设：0 ≤ arr1[i] ≤ 1000（值域已知 → 计数数组）
```

### 2.2 完整代码

```java
/**
 * LeetCode 1122. 数组的相对排序
 * ⚠️ 值域 0-1000 已知 → 计数数组直接可用
 */
public int[] relativeSortArray(int[] arr1, int[] arr2) {
    int[] count = new int[1001];                 // ⚠️ 值域上限 1000
    for (int x : arr1) count[x]++;

    int idx = 0;
    // ① 按 arr2 顺序输出
    for (int v : arr2) {
        while (count[v]-- > 0) arr1[idx++] = v;
    }
    // ② 剩余按升序输出
    for (int v = 0; v <= 1000; v++) {
        while (count[v]-- > 0) arr1[idx++] = v;
    }
    return arr1;
}
// 推演 arr1=[2,3,1,3,2,4,6,7,9,2,19], arr2=[2,1,4,3,9,6]：
//   count[2]=3, count[1]=1, count[4]=1, count[3]=2, count[9]=1, count[6]=1
//   按 arr2：2,2,2,1,4,3,3,9,6
//   剩余：7,19 → [2,2,2,1,4,3,3,9,6,7,19] ✓
// ⚠️ 复杂度：O(n + 1001)（值域固定 → 线性）
// ⚠️ 值域更大时：哈希计数 + 排序剩余部分（O(n log n)）
```

## 3. 1051. 高度检查器

### 3.1 题目与思路

```
多少位置的高度与"排序后"不同（最小交换次数的变体？不——就是比较次数）
计数排序版：计数排序得到有序序列 → 逐位比较
⚠️ 两种思路：
  ① 克隆 + Arrays.sort + 逐位比较（O(n log n)）
  ② 计数排序 + 逐位比较（O(n + k)，值域 1-100）⭐
```

### 3.2 完整代码

```java
/**
 * LeetCode 1051. 高度检查器
 * ⚠️ 计数排序：值域 1-100 已知 → O(n + 100)
 */
public int heightChecker(int[] heights) {
    int[] count = new int[101];                  // ⚠️ 高度范围 1-100
    for (int h : heights) count[h]++;

    int diff = 0, idx = 0;
    for (int h = 1; h <= 100; h++) {             // 升序展开
        while (count[h]-- > 0) {
            if (heights[idx] != h) diff++;       // ⚠️ 与原始位置比较
            idx++;
        }
    }
    return diff;
}
// 推演 [1,1,4,2,1,3]：排序后 [1,1,1,2,3,4]
//   原始 [1,1,4,2,1,3]：位置 2,4,5 不同 → 3 ✓
// ⚠️ 复杂度：O(n + 100)，空间 O(100)
// ⚠️ 面试表达："1051 是计数排序的'半应用'——
//   不需要完整排序结果，只需知道'每个位置应该是什么'，
//   计数展开天然给出。"
```

## 4. 912. 排序数组（计数版 + 值域分析）

### 4.1 题目与思路

```
数组排序——计数版展示"值域分析"决策
⚠️ 912 值域 [-50000, 50000] → 跨度 100001 ≈ 数据量（n ≤ 5×10⁴）
  k ≈ 2n → 计数排序可用且有竞争力
```

### 4.2 完整代码 + 值域分析

```java
/**
 * LeetCode 912. 排序数组（计数版）
 */
public int[] sortArray(int[] nums) {
    // ⚠️ 值域分析：跨度 100001，n ≤ 50000 → k ≈ 2n → 计数可用
    int min = Integer.MAX_VALUE, max = Integer.MIN_VALUE;
    for (int x : nums) { min = Math.min(min, x); max = Math.max(max, x); }

    int[] count = new int[max - min + 1];       // ⚠️ 偏移计数
    for (int x : nums) count[x - min]++;

    int idx = 0;
    for (int i = 0; i < count.length; i++)
        while (count[i]-- > 0) nums[idx++] = i + min;
    return nums;
}
// 复杂度：O(n + k) = O(n + 100001)，空间 O(100001) ≈ 0.4MB
// ⚠️ 面试论述：
//   "912 值域跨度 10⁵ 与 n（5×10⁴）同量级 → 计数排序 O(n+k)
//    可行；若值域 10⁹ → 计数空间 4GB 不可行 → 基数/快排。
//    这题展示'值域分析驱动选型'的思维。"
// ⚠️ 注意：内存 O(k) 也计入空间复杂度——这是计数排序的代价
```

## 5. 136/137. 只出现一次的数字（位计数）

### 5.1 题目与思路

```
136：一个数出现 1 次，其余 2 次 → 异或全部（a^a=0）⭐
137：一个数出现 1 次，其余 3 次 → 位计数（每位统计 %3）
⚠️ 137 的"计数"是"位级计数"：每位 1 的个数 mod 3 = 目标数该位
   → 这是计数思想的位运算形态
```

### 5.2 完整代码

```java
/** 136. 只出现一次的数字（异或，O(n) O(1)） */
public int singleNumber(int[] nums) {
    int x = 0;
    for (int v : nums) x ^= v;                  // ⚠️ 成对抵消
    return x;
}
// 原理：a ^ a = 0，a ^ 0 = a → 成对元素全消，剩单数

/** 137. 只出现一次的数字 II（位计数 %3） */
public int singleNumberII(int[] nums) {
    int ans = 0;
    for (int bit = 0; bit < 32; bit++) {
        int sum = 0;
        for (int v : nums)
            sum += (v >> bit) & 1;              // ⚠️ 第 bit 位计数
        if (sum % 3 != 0)                       // ⚠️ 3 次抵消
            ans |= 1 << bit;                    // 目标数该位为 1
    }
    return ans;
}
// 推演 [2,2,3,2]：位 0：2(0)+2(0)+3(1)+2(0) = 1 → %3=1 → ans 位0=1
//   位 1：0+0+1+0 = 1 → ans 位1=1 → ans=3 ✓
// ⚠️ 复杂度：O(32n) ≈ O(n)，O(1) 空间
// ⚠️ 变体 260：两个单数 → 异或分组（按某位区分）
```

## 6. 实战：离散化 + 计数排序组合

### 6.1 场景

```
大值域 + 需要频次/排序 → 离散化压缩后计数
组合套路：
  ① 离散化：值 → 排名（01 模块第 4 节）
  ② 对排名计数排序/频次桶
  ③ 结果映射回原值

⚠️ 典型场景：
  树状数组值域索引（逆序对 BIT 版，见分治/04）
  频次统计 + 值域 10⁹（如用户 ID）
  稀疏矩阵的列索引压缩
```

### 6.2 完整示例（离散化 + 频次桶）

```java
/** 大值域元素的 TopK 频次（离散化 + 频次桶组合） */
List<Integer> topKFrequentLargeDomain(long[] values, int k) {
    // ① 离散化（01 模块模板）
    Map<Long, Integer> rank = discretize(values);

    // ② 排名频次统计
    int[] freq = new int[rank.size()];
    for (long v : values) freq[rank.get(v)]++;

    // ③ 频次桶（下标 = 频次）——与 347 同构但基于排名
    @SuppressWarnings("unchecked")
    List<Long>[] buckets = new List[values.length + 1];
    for (var e : rank.entrySet()) {
        int f = freq[e.getValue()];
        if (buckets[f] == null) buckets[f] = new ArrayList<>();
        buckets[f].add(e.getKey());
    }

    // ④ 取前 K
    List<Long> res = new ArrayList<>();
    for (int f = values.length; f >= 1 && res.size() < k; f--)
        if (buckets[f] != null) res.addAll(buckets[f]);
    return res;
}
// ⚠️ 价值：值域 10⁹ 也能用"计数思想"——
//   离散化把索引空间压缩到不同值个数 m
// ⚠️ 复杂度：O(n log n)（离散化排序）+ O(n + m)（计数）
```

## 7. 计数排序应用方法论

### 7.1 应用识别信号

```
① 值域已知且小（题目给出范围/字符集固定）→ 直接计数
② 需要"按顺序输出频次"（1122/451）→ 计数展开
③ 需要"每个位置应该是什么"（1051）→ 计数展开比较
④ 值域大但稀疏 → 离散化 + 计数
⑤ 位级统计（137）→ 位计数（计数思想的位形态）

⚠️ 三步判断：
  值域多大？→ 数组/哈希/离散化
  要排序还是统计？→ 展开/桶化
  要稳定吗？→ 倒序放置
```

### 7.2 题型模板速查

| 题型 | 计数形态 | 代表题 |
|------|---------|--------|
| 小值域排序 | 频次 + 展开 | 75、912 |
| 相对顺序输出 | 计数 + 指定顺序 | 1122 |
| 位置对比 | 计数展开 + 比较 | 1051 |
| 位级计数 | 逐位 % 次数 | 137 |
| 大值域 TopK | 离散化 + 频次桶 | 347 变体 |

### 7.3 自测清单

```
□ 值域分析（k 与 n 关系）做对了吗？
□ 负数偏移（x - min）？
□ 稳定需要时倒序放置？
□ 展开时还原偏移（i + min）？
□ 荷兰国旗换 2 时 i 不前进？
□ 位计数只算 32 位（含符号位）？
□ 离散化去重正确（rank 唯一）？
```
