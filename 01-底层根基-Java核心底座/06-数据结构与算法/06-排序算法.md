## 2. 冒泡排序

相邻比较交换，每轮最大/最小元素"浮"到末端。

```java
public void bubbleSort(int[] arr) {
    int n = arr.length;
    for (int i = 0; i < n - 1; i++) {
        boolean swapped = false; // 优化：flag 检测是否交换
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
                swapped = true;
            }
        }
        if (!swapped) break; // 未交换说明已有序，提前终止
    }
}
```

| 指标 | 值 |
|------|---|
| 最好时间复杂度 | O(n)（已排序，flag 提前终止） |
| 平均/最坏 | O(n²) |
| 空间复杂度 | O(1) |
| 稳定性 | 稳定（相邻比较，相等不交换） |

> 💡 **冒泡优化的关键**：添加 `swapped` 标志，一轮遍历未交换则说明已有序。

## 3. 选择排序

每轮选最小元素放到前面。交换次数少（O(n)），但比较次数始终为 O(n²)。

```java
public void selectionSort(int[] arr) {
    int n = arr.length;
    for (int i = 0; i < n - 1; i++) {
        int minIdx = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIdx]) minIdx = j;
        }
        if (minIdx != i) {
            int temp = arr[i];
            arr[i] = arr[minIdx];
            arr[minIdx] = temp;
        }
    }
}
```

| 指标 | 值 |
|------|---|
| 时间复杂度 | O(n²)（全部情况） |
| 空间复杂度 | O(1) |
| 稳定性 | 不稳定（交换破坏相对顺序） |
| 特点 | 交换次数少（最多 n-1 次），写操作少 |

## 4. 插入排序

类似理牌：将当前元素插入前面已排序序列的合适位置。

```java
public void insertionSort(int[] arr) {
    int n = arr.length;
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;
        // 从后向前扫描，找到插入位置
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j]; // 后移
            j--;
        }
        arr[j + 1] = key;
    }
}
```

| 指标 | 值 |
|------|---|
| 最好时间复杂度 | O(n)（已排序，只需一次比较） |
| 最坏/平均 | O(n²) |
| 空间复杂度 | O(1) |
| 稳定性 | 稳定 |

> 💡 **插入排序在小数据量和近乎有序时性能极好**（常数因子小）。Java `Arrays.sort()` 在数组长度小于 47 时使用插入排序。

## 5. 希尔排序

插入排序的改进——按增量 gap 分组，组内插入排序，逐渐减小 gap。

```java
public void shellSort(int[] arr) {
    int n = arr.length;
    // Shell 原始增量序列：n/2, n/4, ..., 1
    for (int gap = n / 2; gap > 0; gap /= 2) {
        // 对每个组进行插入排序
        for (int i = gap; i < n; i++) {
            int temp = arr[i];
            int j = i;
            while (j >= gap && arr[j - gap] > temp) {
                arr[j] = arr[j - gap];
                j -= gap;
            }
            arr[j] = temp;
        }
    }
}
```

| 增量序列 | 时间复杂度 | 说明 |
|---------|-----------|------|
| Shell（n/2, n/4, ...） | O(n²) | 原始序列，最坏情况 O(n²) |
| Hibbard（2^k - 1） | O(n^1.5) | 互质，性能更好 |
| Sedgewick | O(n^1.3) | 实际性能最好的序列之一 |

| 指标 | 值 |
|------|---|
| 空间复杂度 | O(1) |
| 稳定性 | 不稳定（分组打破相对顺序） |
| 核心思想 | 让元素先基本有序，最后 gap=1 做一次完整插入排序 |

> ⚠️ 希尔排序的**稳定性**：不稳定。因为分组排序可能把相同元素分到不同组交换。

## 6. 归并排序（⭐ 分治思想代表）

### 6.1 递归实现

```java
public void mergeSort(int[] arr, int left, int right) {
    if (left >= right) return;
    int mid = left + (right - left) / 2;
    mergeSort(arr, left, mid);       // 递归排序左半
    mergeSort(arr, mid + 1, right);  // 递归排序右半
    merge(arr, left, mid, right);    // 合并两个有序数组
}

private void merge(int[] arr, int left, int mid, int right) {
    int[] temp = new int[right - left + 1];
    int i = left, j = mid + 1, k = 0;
    // 双指针合并
    while (i <= mid && j <= right) {
        temp[k++] = arr[i] <= arr[j] ? arr[i++] : arr[j++];
    }
    while (i <= mid) temp[k++] = arr[i++];
    while (j <= right) temp[k++] = arr[j++];
    // 复制回原数组
    System.arraycopy(temp, 0, arr, left, temp.length);
}
```

### 6.2 归并排序的应用：逆序对计数

```java
private int mergeAndCount(int[] arr, int left, int mid, int right) {
    int[] temp = new int[right - left + 1];
    int i = left, j = mid + 1, k = 0;
    int count = 0;
    while (i <= mid && j <= right) {
        if (arr[i] <= arr[j]) {
            temp[k++] = arr[i++];
        } else {
            temp[k++] = arr[j++];
            count += mid - i + 1; // 关键：左半剩余元素都比 arr[j] 大
        }
    }
    while (i <= mid) temp[k++] = arr[i++];
    while (j <= right) temp[k++] = arr[j++];
    System.arraycopy(temp, 0, arr, left, temp.length);
    return count;
}
```

| 指标 | 值 |
|------|---|
| 时间复杂度 | O(n log n)（全部情况） |
| 空间复杂度 | O(n)（需要辅助数组） |
| 稳定性 | 稳定（合并时 ≤ 保证稳定性） |
| 适用场景 | 外部排序（大文件排序） |

> 🎯 **归并排序的特点**：任何时候都是 O(n log n)，稳定，但需要 O(n) 额外空间。适合需要稳定排序或外部排序的场景。

## 7. 快速排序（⭐ 面试最高频排序）

### 7.1 核心：分区操作（Partition）

```java
public void quickSort(int[] arr, int left, int right) {
    if (left >= right) return;
    int pivotIdx = partition(arr, left, right);
    quickSort(arr, left, pivotIdx - 1);
    quickSort(arr, pivotIdx + 1, right);
}
```

### 7.2 Lomuto 分区（选最右为 pivot）

```java
private int partitionLomuto(int[] arr, int left, int right) {
    int pivot = arr[right];
    int i = left; // i 指向小于 pivot 区域的右边界
    for (int j = left; j < right; j++) {
        if (arr[j] < pivot) {
            swap(arr, i, j);
            i++;
        }
    }
    swap(arr, i, right);
    return i;
}
```

### 7.3 Hoare 分区（两端指针向中间扫描）

```java
private int partitionHoare(int[] arr, int left, int right) {
    int pivot = arr[left + (right - left) / 2];
    int i = left - 1, j = right + 1;
    while (true) {
        do { i++; } while (arr[i] < pivot);
        do { j--; } while (arr[j] > pivot);
        if (i >= j) return j;
        swap(arr, i, j);
    }
}
```

### 7.4 优化策略

| 优化 | 效果 |
|------|------|
| **三数取中法选 pivot** | `arr[left], arr[mid], arr[right]` 取中位数，防退化 O(n²) |
| **小数组切换插入排序** | 长度 < 阈值（如 10）时用插入排序，减少递归开销 |
| **三路快排** | 分成 `< pivot = pivot > pivot` 三段，大量重复元素时效率高 |

```java
// 三路快排（处理大量重复元素）
private void quickSort3Way(int[] arr, int left, int right) {
    if (left >= right) return;
    int lt = left, gt = right;
    int pivot = arr[left];
    int i = left + 1;
    while (i <= gt) {
        if (arr[i] < pivot) swap(arr, lt++, i++);
        else if (arr[i] > pivot) swap(arr, i, gt--);
        else i++;
    }
    quickSort3Way(arr, left, lt - 1);
    quickSort3Way(arr, gt + 1, right);
}
```

| 指标 | 值 |
|------|---|
| 平均时间复杂度 | O(n log n) |
| 最坏时间复杂度 | O(n²)（已排序且选最左/最右为 pivot） |
| 空间复杂度 | O(log n)（递归栈） |
| 稳定性 | 不稳定 |

> 💡 **快速排序实际最快**——常数因子小，空间局部性好。Java `Arrays.sort()` 对基本类型使用快排（Dual-Pivot QuickSort）。

## 8. 堆排序

```java
public void heapSort(int[] arr) {
    int n = arr.length;
    // 1. 建堆（自底向上下滤）
    for (int i = n / 2 - 1; i >= 0; i--) {
        siftDown(arr, n, i);
    }
    // 2. 依次取出堆顶
    for (int i = n - 1; i > 0; i--) {
        swap(arr, 0, i); // 堆顶（最大）与末尾交换
        siftDown(arr, i, 0); // 对新的堆顶下滤
    }
}

private void siftDown(int[] arr, int n, int i) {
    while (2 * i + 1 < n) {
        int larger = 2 * i + 1;
        if (larger + 1 < n && arr[larger + 1] > arr[larger]) {
            larger = larger + 1;
        }
        if (arr[i] >= arr[larger]) break;
        swap(arr, i, larger);
        i = larger;
    }
}
```

| 指标 | 值 |
|------|---|
| 时间复杂度 | O(n log n)（全部情况） |
| 空间复杂度 | O(1)（原地排序） |
| 稳定性 | 不稳定 |
| 特点 | 唯一 O(n log n) 且 O(1) 空间的排序 |

> ⚠️ 堆排序不稳定，且常数因子比快排大，实际性能通常不如快排。

## 9. 非比较排序

### 9.1 计数排序

统计每个值出现的次数 → 前缀和 → 放置，适合值域小的整数。

```java
public void countingSort(int[] arr) {
    if (arr.length == 0) return;
    int max = Arrays.stream(arr).max().getAsInt();
    int min = Arrays.stream(arr).min().getAsInt();
    int range = max - min + 1;
    int[] count = new int[range];
    int[] output = new int[arr.length];
    // 1. 统计频次
    for (int num : arr) count[num - min]++;
    // 2. 前缀和（稳定排序关键）
    for (int i = 1; i < range; i++) count[i] += count[i - 1];
    // 3. 反向填充（保持稳定）
    for (int i = arr.length - 1; i >= 0; i--) {
        output[count[arr[i] - min] - 1] = arr[i];
        count[arr[i] - min]--;
    }
    System.arraycopy(output, 0, arr, 0, arr.length);
}
```

| 指标 | 值 |
|------|---|
| 时间复杂度 | O(n + k)，k 为值域范围 |
| 空间复杂度 | O(k) |
| 稳定性 | 稳定 |
| 适用场景 | 值域小且为整数的数据（如考试成绩 0-100） |

### 9.2 桶排序

数据分到多个桶 → 桶内排序 → 合并。

```java
public void bucketSort(float[] arr) {
    int n = arr.length;
    List<Float>[] buckets = new ArrayList[n];
    for (int i = 0; i < n; i++) buckets[i] = new ArrayList<>();
    // 1. 分桶
    for (float num : arr) {
        int bucketIdx = (int) (num * n);
        buckets[bucketIdx].add(num);
    }
    // 2. 桶内排序
    for (List<Float> bucket : buckets) Collections.sort(bucket);
    // 3. 合并
    int idx = 0;
    for (List<Float> bucket : buckets) {
        for (float num : bucket) arr[idx++] = num;
    }
}
```

### 9.3 基数排序

从低位到高位逐位排序（多用稳定排序如计数排序）。

```java
public void radixSort(int[] arr) {
    int max = Arrays.stream(arr).max().getAsInt();
    for (int exp = 1; max / exp > 0; exp *= 10) {
        countingSortByDigit(arr, exp);
    }
}

private void countingSortByDigit(int[] arr, int exp) {
    int n = arr.length;
    int[] output = new int[n];
    int[] count = new int[10];
    for (int num : arr) count[(num / exp) % 10]++;
    for (int i = 1; i < 10; i++) count[i] += count[i - 1];
    for (int i = n - 1; i >= 0; i--) {
        int digit = (arr[i] / exp) % 10;
        output[count[digit] - 1] = arr[i];
        count[digit]--;
    }
    System.arraycopy(output, 0, arr, 0, n);
}
```

| 算法 | 时间复杂度 | 空间 | 适用场景 |
|------|-----------|------|---------|
| 计数排序 | O(n + k) | O(k) | 小值域整数 |
| 桶排序 | O(n + k) | O(n + k) | 均匀分布的数据 |
| 基数排序 | O(d(n + r)) | O(r) | 整数或定长字符串 |

> 💡 非比较排序能突破 O(n log n) 的下界，因为利用了数据本身的特性（值域、位数等）。

## 11. 排序选择指南

| 场景 | 推荐算法 | 理由 |
|------|---------|------|
| 数据量小（< 50） | 插入排序 | 常数因子小，代码简单 |
| 需要稳定排序 | 归并排序 | 唯一 O(n log n) 稳定的比较排序 |
| 综合性能优先 | 快速排序 | 实际最快，空间局部性好 |
| 内存严格受限 | 堆排序 | O(1) 额外空间 |
| 外部排序（大文件） | 归并排序 | 分治 + 多路归并 |
| 值域小的整数 | 计数/桶/基数排序 | 线性时间 |

> 🎯 **面试重点**：快排和归并能手写，理解稳定性的含义（"排序后相等元素相对位置不变"），以及每种算法的适用场景。

## 12. 学习建议

1. **快排和归并能手写**，默写出来——这是面试的"入门题"
2. 理解**稳定性**的含义：排序后相等元素的相对位置不变——多关键字排序（如先按成绩排序，相同成绩按学号）需要稳定排序
3. 用 Java 手写所有排序，对比运行时间验证理论复杂度
4. 非比较排序理解其适用场景即可，不必深入复杂实现

> 🎯 排序是算法的基本功——掌握了排序，就掌握了分治、递归、堆、双指针等核心思想的实践应用。
