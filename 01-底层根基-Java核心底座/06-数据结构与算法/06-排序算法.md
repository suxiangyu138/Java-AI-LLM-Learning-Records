# 排序算法

## 📌 课程定位
排序是算法设计的"入门训练场"——几乎所有基础算法思想（分治、贪心、堆、二分）都能在排序中找到。面试必问。

## 🎯 核心章节

### 1. 排序算法总览（⭐ 必记这张表）

| 算法 | 最好 | 平均 | 最坏 | 空间 | 稳定性 |
|------|------|------|------|------|--------|
| 冒泡排序 | O(n) | O(n²) | O(n²) | O(1) | 稳定 |
| 选择排序 | O(n²) | O(n²) | O(n²) | O(1) | 不稳定 |
| 插入排序 | O(n) | O(n²) | O(n²) | O(1) | 稳定 |
| 希尔排序 | O(n) | O(n^1.3) | O(n²) | O(1) | 不稳定 |
| 归并排序 | O(n log n) | O(n log n) | O(n log n) | O(n) | 稳定 |
| 快速排序 | O(n log n) | O(n log n) | O(n²) | O(log n) | 不稳定 |
| 堆排序 | O(n log n) | O(n log n) | O(n log n) | O(1) | 不稳定 |
| 计数排序 | O(n+k) | O(n+k) | O(n+k) | O(k) | 稳定 |
| 桶排序 | O(n) | O(n+k) | O(n²) | O(n+k) | 稳定 |
| 基数排序 | O(d(n+r)) | O(d(n+r)) | O(d(n+r)) | O(r) | 稳定 |

### 2. 基础排序（O(n²) 三重奏）
- **冒泡排序**：相邻比较交换，每轮最大/最小"浮"到末端
  - 优化：加入flag检测本轮是否交换，未交换则提前终止
- **选择排序**：每轮选最小放到前面——交换次数少(O(n))，但比较永远是O(n²)
- **插入排序**：类似理牌，将当前元素插入前面已排序的合适位置
  - 近乎有序时接近O(n)，小数据量时实际性能好（常数因子小）

### 3. 希尔排序
- 对插入排序的改进——按增量gap分组，每组内插入排序，逐渐减小gap
- **增量序列**：Shell原始(n/2, n/4, ...)、Hibbard(2^k-1)、Sedgewick
- gap=1时就是标准插入排序，前面的轮次让元素基本有序

### 4. 归并排序（⭐ 分治思想代表）
- 分治三步：递归二分数组 → 递归排序左右 → 合并两个有序数组
- 合并过程用双指针法（常考手写）
- **逆序对计数**是归并的经典扩展应用
- 外部排序（大文件排序）中也用归并思想

### 5. 快速排序（⭐ 面试最高频排序）
- **核心：分区操作(Partition)**——选 pivot，小的放左，大的放右
- **两种实现**：Lomuto（选最右为pivot）和 Hoare（两端指针向中间扫描）
- **优化**：
  - 三数取中法选pivot，防退化O(n²)
  - 小数组切换为插入排序
  - 三路快排：分成 < = > 三段，大量重复元素时效率高
- **非递归实现**：用栈模拟递归

### 6. 堆排序
- 建堆O(n) + n-1次下滤O(n log n) = O(n log n)
- 不稳定——交换时破坏同值相对位置
- 唯一O(n log n)且空间O(1)的排序

### 7. 非比较排序（了解即可）
- **计数排序**：统计每个值出现的次数→前缀和→放置，适合值域小的整数
- **桶排序**：数据分到多个桶→桶内排序→合并
- **基数排序**：从低位到高位逐位排序（多用稳定排序如计数排序）

### 8. 排序选择指南
- 数据量小 → 插入排序（简单高效）
- 追求稳定 → 归并排序
- 追求综合性能 → 快速排序（实际最快）
- 内存严格受限 → 堆排序
- 外部排序 → 归并
- 值域小 → 计数/桶/基数

## ✅ 学习建议
- **快排和归并能手写**，默写出来——这是面试"入门题"
- 理解稳定性含义：排序后相等元素的相对位置不变——哪些场景需要稳定性（多关键字排序）
- 用Python/Java手写所有排序，对比运行时间验证理论复杂度
