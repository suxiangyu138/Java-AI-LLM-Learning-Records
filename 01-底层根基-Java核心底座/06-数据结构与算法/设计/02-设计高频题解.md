## 1. 146. LRU 缓存（哈希 + 双向链表）

### 1.1 题目与思路

```
get/put 均 O(1) + 容量淘汰最久未使用
复合结构：HashMap(key → Node) + 双向链表（LRU 顺序）
⚠️ 三原则（01 模块）：双向链表、同步更新、哨兵节点
```

### 1.2 完整代码

```java
/**
 * LeetCode 146. LRU 缓存
 */
class LRUCache {
    // ⚠️ 双向链表节点（存 key 是为了删除时能删哈希）
    static class Node {
        int key, val;
        Node prev, next;
        Node(int k, int v) { key = k; val = v; }
    }

    private final Map<Integer, Node> map = new HashMap<>();
    private final int capacity;
    private final Node head = new Node(0, 0);   // ⚠️ 哨兵（最久未用侧）
    private final Node tail = new Node(0, 0);   // 哨兵（最近使用侧）

    public LRUCache(int capacity) {
        this.capacity = capacity;
        head.next = tail;
        tail.prev = head;
    }

    public int get(int key) {
        Node node = map.get(key);
        if (node == null) return -1;
        moveToTail(node);                       // ⚠️ 访问即刷新！
        return node.val;
    }

    public void put(int key, int value) {
        if (map.containsKey(key)) {
            Node node = map.get(key);
            node.val = value;
            moveToTail(node);                   // 更新也刷新
            return;
        }
        Node node = new Node(key, value);
        map.put(key, node);
        addToTail(node);
        if (map.size() > capacity) {            // ⚠️ 超容量淘汰
            Node oldest = head.next;
            removeNode(oldest);
            map.remove(oldest.key);             // ⚠️ 哈希同步删除
        }
    }

    // ⚠️ 三个基础操作（双向链表 O(1)）：
    private void removeNode(Node node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }
    private void addToTail(Node node) {
        node.prev = tail.prev;
        node.next = tail;
        tail.prev.next = node;
        tail.prev = node;
    }
    private void moveToTail(Node node) {
        removeNode(node);
        addToTail(node);
    }
}
// 推演 cap=2：put(1,1) put(2,2) get(1) put(3,3)
//   put(1)：链表 [1]；put(2)：[1,2]
//   get(1)：1 移到尾 → [2,1]
//   put(3)：超容量 → 淘汰头 2 → [1,3] ✓
// ⚠️ 面试必答："146 = 哈希定位 + 双向链表保序——
//   get/put 都刷新（移到尾部），超容量淘汰头部。
//   节点存 key 是为了淘汰时同步删哈希。"
```

## 2. 155. 最小栈（辅助栈）

### 2.1 题目与思路

```
push/pop/top/getMin 均 O(1)
辅助栈：同步记录"当前最小值"
⚠️ 两种实现：同步压栈（min 栈同大小）或差值法（进阶）
```

### 2.2 完整代码（双栈 + 差值法）

```java
/** 方式一：同步辅助栈（直观） */
class MinStack {
    private final Deque<Integer> stack = new ArrayDeque<>();
    private final Deque<Integer> minStack = new ArrayDeque<>();

    public void push(int val) {
        stack.push(val);
        // ⚠️ 辅助栈压"当前最小值"
        int min = minStack.isEmpty() ? val : Math.min(minStack.peek(), val);
        minStack.push(min);
    }
    public void pop() {
        stack.pop();
        minStack.pop();                        // ⚠️ 同步弹出
    }
    public int top() { return stack.peek(); }
    public int getMin() { return minStack.peek(); }
}
// 推演 push(3) push(5) push(2)：min 栈 [3,3,2] → getMin=2 ✓
//   pop() → min 栈弹 2 → getMin=3 ✓

/** 方式二：差值法（O(1) 空间，面试加分） */
class MinStack2 {
    private final Deque<Long> stack = new ArrayDeque<>();  // ⚠️ 差值可能溢出 int
    private long min;

    public void push(int val) {
        if (stack.isEmpty()) {
            stack.push(0L);
            min = val;
        } else {
            stack.push((long) val - min);      // ⚠️ 存差值
            if (val < min) min = val;
        }
    }
    public void pop() {
        long diff = stack.pop();
        if (diff < 0) min = min - diff;        // ⚠️ 弹出的是最小值 → 还原
    }
    public int top() {
        long diff = stack.peek();
        return diff >= 0 ? (int) (min + diff) : (int) min;
    }
    public int getMin() { return (int) min; }
}
// ⚠️ 面试表达："最小栈 = 辅助栈同步记录最小值
//   （O(n) 空间）；差值法 O(1) 空间但细节多
//   （负数差值表示'该元素是新最小值'）。"
```

## 3. 380. O(1) 时间插入、删除和获取随机元素

### 3.1 题目与思路

```
insert/remove/getRandom 均 O(1)（元素不重复）
哈希 + 数组：
  哈希：值 → 下标（O(1) 定位）
  数组：存值（O(1) 随机）
⚠️ 删除技巧：尾部交换（数组中间删除是 O(n)）
```

### 3.2 完整代码

```java
/**
 * LeetCode 380. O(1) 随机获取
 */
class RandomizedSet {
    private final List<Integer> values = new ArrayList<>();
    private final Map<Integer, Integer> pos = new HashMap<>();  // 值 → 下标
    private final Random rand = new Random();

    public boolean insert(int val) {
        if (pos.containsKey(val)) return false;
        pos.put(val, values.size());
        values.add(val);                        // ⚠️ 尾插 O(1)
        return true;
    }

    public boolean remove(int val) {
        if (!pos.containsKey(val)) return false;
        int idx = pos.get(val);
        int last = values.get(values.size() - 1);

        // ⚠️ 尾部交换三连：覆盖 → 更新映射 → 删尾
        values.set(idx, last);                  // ① 末尾值覆盖被删位
        pos.put(last, idx);                     // ② 更新末尾值的下标
        values.remove(values.size() - 1);       // ③ 删除尾部
        pos.remove(val);                        // ④ 删映射
        return true;
    }

    public int getRandom() {
        return values.get(rand.nextInt(values.size()));
    }
}
// 推演 insert(1) insert(2) insert(3) → values=[1,2,3], pos={1:0,2:1,3:2}
//   remove(1)：idx=0, last=3 → values=[3,2], pos={3:0,2:1} ✓
//   getRandom → 随机下标访问 ✓
// ⚠️ 面试必答："380 = 哈希定位 + 数组随机——
//   '尾部交换删除'把 O(n) 删除变 O(1)：
//   被删元素与末尾交换，删尾 + 更新映射。"
```

## 4. 208. 实现 Trie（前缀树）

### 4.1 题目与思路

```
insert/search/startsWith 前缀查询
Trie：26 叉树（children 数组 + isEnd 标记）
⚠️ 两种实现：数组版（26 固定）与 Map 版（任意字符）
```

### 4.2 完整代码

```java
/**
 * LeetCode 208. 实现 Trie
 */
class Trie {
    private static class Node {
        Node[] children = new Node[26];        // ⚠️ 26 叉（a-z）
        boolean isEnd;                          // 单词结束标记
    }

    private final Node root = new Node();

    public void insert(String word) {
        Node cur = root;
        for (char c : word.toCharArray()) {
            int idx = c - 'a';
            if (cur.children[idx] == null) cur.children[idx] = new Node();
            cur = cur.children[idx];
        }
        cur.isEnd = true;                       // ⚠️ 标记单词结束
    }

    public boolean search(String word) {
        Node node = find(word);
        return node != null && node.isEnd;      // ⚠️ 必须完整单词
    }

    public boolean startsWith(String prefix) {
        return find(prefix) != null;            // ⚠️ 前缀存在即可
    }

    private Node find(String s) {
        Node cur = root;
        for (char c : s.toCharArray()) {
            cur = cur.children[c - 'a'];
            if (cur == null) return null;
        }
        return cur;
    }
}
// 推演 insert("apple") search("app") → false（无 isEnd）
//   startsWith("app") → true ✓
// ⚠️ 复杂度：O(L)（L = 单词长度）
// ⚠️ 变体：
//   211 添加与搜索单词（. 通配 → 递归回溯）
//   212 单词搜索 II（Trie + 网格 DFS）
//   648 单词替换（前缀匹配）
// ⚠️ 面试表达："Trie = 26 叉树 + isEnd 标记——
//   search 查完整词（isEnd 必须）、
//   startsWith 查前缀（走到即可）。"
```

## 5. 225. 用队列实现栈

### 5.1 题目与思路

```
队列实现栈：push O(n)、pop/top O(1)（单队列轮转）
⚠️ push 时把前面的元素轮转到新元素后面
   → 队首 = 栈顶
```

### 5.2 完整代码

```java
/**
 * LeetCode 225. 用队列实现栈（单队列轮转）
 */
class MyStack {
    private final Deque<Integer> queue = new ArrayDeque<>();   // 队首 = 栈顶

    public void push(int x) {
        queue.offer(x);                         // ① 入队尾
        // ⚠️ 轮转：把前面的 n-1 个移到新元素后面
        for (int i = 0; i < queue.size() - 1; i++) {
            queue.offer(queue.poll());          // 队首移到队尾
        }
    }

    public int pop() { return queue.poll(); }   // ⚠️ 队首 = 栈顶
    public int top() { return queue.peek(); }
    public boolean empty() { return queue.isEmpty(); }
}
// 推演 push(1) push(2) push(3)：
//   push(1)：[1]
//   push(2)：[1,2] → 轮转 → [2,1]（队首 2 = 栈顶）
//   push(3)：[2,1,3] → 轮转两次 → [3,2,1] ✓
//   pop → 3（队首）✓
// ⚠️ 复杂度：push O(n)（轮转 n-1 次）、pop O(1)
// ⚠️ 面试表达："队列实现栈 = push 时轮转——
//   新元素入队尾后，把前面的全部移到它后面，
//   队首永远是'最后入'的元素（栈顶语义）。"
```

## 6. 232. 用栈实现队列

### 6.1 题目与思路

```
栈实现队列：双栈倒腾
  in 栈：push 用（队尾方向）
  out 栈：pop 用（队首方向，倒序）
⚠️ out 空时把 in 全部倒入（一次倒腾，均摊 O(1)）
```

### 6.2 完整代码

```java
/**
 * LeetCode 232. 用栈实现队列（双栈倒腾）
 */
class MyQueue {
    private final Deque<Integer> in = new ArrayDeque<>();
    private final Deque<Integer> out = new ArrayDeque<>();

    public void push(int x) {
        in.push(x);                             // ⚠️ 只入 in 栈
    }

    private void transfer() {                   // ⚠️ 倒腾：in → out（逆序）
        if (out.isEmpty()) {
            while (!in.isEmpty()) out.push(in.pop());
        }
    }

    public int pop() {
        transfer();
        return out.pop();                       // out 栈顶 = 队首
    }

    public int peek() {
        transfer();
        return out.peek();
    }

    public boolean empty() {
        return in.isEmpty() && out.isEmpty();
    }
}
// 推演 push(1) push(2) push(3)：
//   in=[1,2,3]；pop → 倒腾 out=[3,2,1] → 弹 1 ✓
//   push(4)：in=[4]；pop → out 非空直接弹 2 ✓（in 不动）
// ⚠️ 复杂度：push O(1)、pop 均摊 O(1)（每元素倒腾一次）
// ⚠️ 面试表达："双栈倒腾 = 一次逆序完成队列语义——
//   倒腾只发生在 out 空时，每元素恰好
//   倒一次 → 均摊 O(1)。"
```

## 7. 设计题方法论总结

### 7.1 解题框架（五步）

```
① 需求拆解：列出每个操作与复杂度要求
② 结构选型：哈希 + 什么？（链表/数组/栈/树）
③ 状态定义：节点字段/下标映射/辅助结构
④ 同步更新：多结构联动的原子性
⑤ 边界验证：空/满/重复/不存在

⚠️ 识别信号：
  "O(1) + 特性（LRU/随机/最小）" → 复合结构
  "实现 XX 类（栈/队列/Trie）" → 基础结构互转
```

### 7.2 模板速查表

| 题目 | 结构 | 关键技巧 |
|------|------|---------|
| 146 LRU | 哈希 + 双向链表 | 哨兵 + 访问刷新 + 尾部交换淘汰 |
| 155 最小栈 | 栈 + 辅助栈 | 同步最小值 / 差值法 |
| 380 随机 | 哈希 + 数组 | 尾部交换删除 |
| 208 Trie | 26 叉树 | isEnd 标记 |
| 225 队列→栈 | 单队列 | push 轮转 |
| 232 栈→队列 | 双栈 | out 空时倒腾 |

### 7.3 自测清单

```
□ 每个操作复杂度 O(1) 论证？
□ 多结构同步更新（一个方法内）？
□ 哨兵/边界处理？
□ 副作用（get 刷新 LRU、删除更新映射）？
□ 空/满/重复操作验证？
□ 双向链表（删除需前驱）？
□ 均摊 vs 最坏说明？
```
