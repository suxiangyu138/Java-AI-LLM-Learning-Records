## 1. 核心概念

### 1.1 设计题的考察本质

> 设计题：为特定操作集设计数据结构，**每个操作达到指定复杂度**（通常 O(1)）。考察对基础结构的理解与组合能力。

```
设计题三步：
  ① 列出操作与复杂度要求
  ② 识别需要的底层结构
  ③ 处理结构间的联动

经典三题：
  LRU 缓存（146）：哈希 + 双向链表
  最小栈（155）：主栈 + 辅助栈
  O(1) 随机获取（380）：哈希 + 数组
```

### 1.2 结构选型速查

| 需求 | 结构 | 原理 |
|------|------|------|
| O(1) 查找 | 哈希表 | key → 位置 |
| O(1) 删除任意 | 双向链表 | prev 直接定位 |
| O(1) 取最值 | 堆 | 堆顶 |
| O(1) 随机访问 | 数组 | 下标 |
| 有序 + log | 红黑树 | TreeMap |
| 最近使用顺序 | 链表 | 头部/尾部 |

```
⚠️ 设计题的通用公式：
  "哈希管定位 + 结构管操作"
  哈希解决"找到它"（O(1)）
  结构解决"操作它"（O(1)）
```

### 1.3 识别信号

```
"设计一个支持 O(1) 的..." → 设计题
"get/put 都 O(1)" → LRU 类
"随机获取 O(1)" → 数组 + 哈希
"最小/最大 O(1)" → 辅助栈/双堆

⚠️ 面试定位：大厂高频（尤其 LRU）
  手写流畅度 = 加分关键
```

## 2. 完整代码模板

### 2.1 380. O(1) 插入删除随机（尾删换顶）

```java
/**
 * LeetCode 380. O(1) 时间插入、删除和获取随机元素
 * 哈希定位 + 数组随机访问 + 尾删换顶
 */
class RandomizedSet {
    Map<Integer, Integer> indexMap = new HashMap<>();   // 值 → 数组下标
    List<Integer> values = new ArrayList<>();           // 值列表
    Random random = new Random();

    public boolean insert(int val) {
        if (indexMap.containsKey(val)) return false;
        indexMap.put(val, values.size());   // 记录下标
        values.add(val);
        return true;
    }

    public boolean remove(int val) {
        if (!indexMap.containsKey(val)) return false;

        int idx = indexMap.get(val);              // 待删下标
        int last = values.get(values.size() - 1); // 末尾元素

        values.set(idx, last);                    // ① 末尾补位
        indexMap.put(last, idx);                  // ② 更新补位者下标
        values.remove(values.size() - 1);         // ③ 删末尾 O(1)
        indexMap.remove(val);                     // ④ 删映射
        return true;
    }

    public int getRandom() {
        return values.get(random.nextInt(values.size()));
    }
}
// 为什么"尾删换顶"？
//   数组删中间 O(n)（移动）；换末尾再删 O(1)
// ⚠️ 代价：被换元素的下标要同步更新（哈希）
```

### 2.2 155. 最小栈（辅助栈）

```java
/**
 * LeetCode 155. 最小栈（辅助栈同步）
 */
class MinStack {
    Deque<Integer> data = new ArrayDeque<>();
    Deque<Integer> min = new ArrayDeque<>();

    public void push(int val) {
        data.push(val);
        // ⚠️ 用 <=：相同最小值重复 push 不丢失
        min.push(min.isEmpty() ? val : Math.min(val, min.peek()));
    }

    public void pop() {
        data.pop();
        min.pop();                    // ⚠️ 同步弹
    }

    public int top() {
        return data.peek();
    }

    public int getMin() {
        return min.peek();            // 辅助栈顶 = 当前最小值
    }
}
// 推演：push 2, push 3, push 2, push 1
//   data: [2,3,2,1]  min: [2,2,2,1]
//   pop → min 仍 [2,2,2] → getMin=2 ✓（没丢！）

// O(1) 空间版（差值法）：
//   存 val - min，min 单独维护 → 面试加分
```

### 2.3 232. 用栈实现队列（双栈倒腾）

```java
/**
 * LeetCode 232. 用栈实现队列
 * in 栈入队，out 栈出队（倒腾逆转顺序）
 */
class MyQueue {
    Deque<Integer> in = new ArrayDeque<>();
    Deque<Integer> out = new ArrayDeque<>();

    public void push(int x) {
        in.push(x);                              // 直接入 in
    }

    public int pop() {
        moveIfNeeded();
        return out.pop();
    }

    public int peek() {
        moveIfNeeded();
        return out.peek();
    }

    public boolean empty() {
        return in.isEmpty() && out.isEmpty();
    }

    // ⚠️ 关键：out 空时把 in 全部倒过来
    private void moveIfNeeded() {
        if (out.isEmpty()) {
            while (!in.isEmpty()) {
                out.push(in.pop());              // 倒腾（逆序变正序）
            }
        }
    }
}
// 均摊 O(1)：每个元素 3 次操作（入 in/倒 out/出 out）
```

## 3. 设计题的三大套路

### 3.1 套路一：尾删换顶（O(1) 删除）

```
问题：数组删除中间 O(n)
方案：末尾元素补到待删位置 → 删除末尾 O(1)
代价：更新被换元素在哈希中的下标

识别："随机获取 + 删除 O(1)" → 380
```

### 3.2 套路二：辅助结构同步（O(1) 最值）

```
问题：获取最值需要遍历
方案：辅助栈/堆同步记录（push 时维护）
代价：空间翻倍

识别："最小/最大栈" → 155
⚠️ 细节：辅助栈用 <= 保重复值不丢
```

### 3.3 套路三：哈希 + 顺序结构（O(1) 全操作）

```
问题：既要 O(1) 定位又要 O(1) 排序/顺序
方案：哈希（定位）+ 双向链表（顺序）→ LRU
     哈希（定位）+ 数组（随机）→ 380
     双堆（有序统计）→ 295

识别："get/put 都 O(1)" → LRU
⚠️ 设计题的核心 = 组合两个结构满足两个需求
```

## 4. 设计题的方法论

### 4.1 五步设计法

```
① 列需求：每个操作 + 目标复杂度
② 选结构：为每个需求找 O(1) 结构
③ 组联动：结构间如何同步（哈希↔结构）
④ 写边界：空结构/重复/容量
⑤ 复杂度证明：每个操作 O(1) 论证

⚠️ 面试表达：
"需求拆解：get 要 O(1) → 哈希；
 顺序维护 → 双向链表；
 两者通过 Node 关联。"
```

### 4.2 边界条件清单

```
① 空结构操作（get 不存在 → -1）
② 重复插入（insert 已存在 → false）
③ 容量上限（LRU 超容量淘汰）
④ 单元素（删除唯一元素）
⑤ 相同值（辅助栈 <=）

⚠️ 面试写完后主动检查这些边界 = 加分
```

### 4.3 复杂度分析框架

```
每个操作单独论证：
  LRU get：哈希 O(1) + moveToHead O(1) → O(1)
  LRU put：哈希 O(1) + 头插/尾删 O(1) → O(1)
  ⚠️ 均摊 vs 严格：232 是均摊 O(1)
  → 面试讲清"为什么每个操作 O(1)"
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"设计思路：哈希表存'值 → 数组下标' O(1) 定位，
 数组支持 O(1) 随机访问。
 删除的难点是数组中间删除 O(n)——我用
 尾删换顶：末尾元素补到待删位置，更新它的
 下标，再删末尾。所有操作 O(1)。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | O(1) 删除的通用套路？ | 数组+哈希：尾删换顶；链表+哈希：双向直接摘除 |
| 2 | 为什么节点存 key？ | 删尾后同步删哈希（map.remove(removed.key)） |
| 3 | 单链表行不行（LRU）？ | 不行——删除任意节点 O(n) 找前驱 |
| 4 | 为什么不用 LinkedHashMap？ | 可以，但手写展示底层实现能力 |
| 5 | 辅助栈为什么 <=？ | 相同最小值重复 push 只存一次会丢失 |
| 6 | 线程安全？ | 不加锁不安全；加锁/ConcurrentHashMap |
| 7 | 均摊 vs 严格 O(1)？ | 232 双栈是均摊；LRU 是严格（每次 O(1)） |
| 8 | 变体 LFU？ | 双哈希（key→节点 + 频次→链表），更复杂 |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 尾删忘更新哈希 | 补位者定位错 | indexMap.put(last, idx) |
| 辅助栈用 < | 重复最小值丢失 | 用 <= |
| 双栈忘 move | 出队顺序错 | moveIfNeeded 先行 |
| 忘容量检查 | 内存无限增长 | size > cap → 淘汰 |
| 手写顺序乱 | 遗漏四件套 | 先写结构再写操作 |

> 🎯 **核心要点**：设计题 = **结构选型 + 联动维护**。三大必背：LRU（哈希+双向链表）、最小栈（辅助栈 <=）、O(1) 随机（尾删换顶）。"哈希定位 + 结构操作"是设计题总公式，边界与复杂度分析要主动讲。
