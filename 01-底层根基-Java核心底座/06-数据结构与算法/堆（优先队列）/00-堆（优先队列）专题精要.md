## 1. 核心概念

### 1.1 什么是堆

> 堆（Heap / PriorityQueue）：**完全二叉树**（数组存储），每个节点 ≥（最大堆）或 ≤（最小堆）其子节点。堆顶恒为最大/最小值。

```
      8（最大堆）
     / \
    5   6
   / \
  4   3

数组表示：[8, 5, 6, 4, 3]
  左孩子 = 2i+1，右孩子 = 2i+2，父 = (i-1)/2

操作复杂度：
  取最值 peek：O(1)
  插入 offer：O(log n)（上浮）
  删除 poll：O(log n)（下沉）
  建堆：O(n)（从 n/2-1 起下沉）
```

### 1.2 堆的三大应用

```
① TopK 问题：大小为 k 的堆（堆顶 = 第 k 大/小）
② 贪心/调度：每次取当前最优（Dijkstra/合并K链/哈夫曼）
③ 数据流：在线维护中位数（双堆）

⚠️ Java 注意：
  PriorityQueue 默认小根堆（升序）
  大根堆：new PriorityQueue<>((a,b) -> b - a)
  自定义对象：Comparator 定义优先级
```

### 1.3 堆 vs 其他结构

| 结构 | 取最值 | 插入 | 有序遍历 | 适用 |
|------|:---:|:---:|:---:|------|
| 堆 | O(1) | O(log n) | ❌ 无序 | 只关心最值 |
| 排序数组 | O(1) 固定端 | O(n) | ✅ | 静态 |
| TreeMap | O(log n) | O(log n) | ✅ | 需有序+范围 |
| 链表 | O(n) | O(1) 头部 | ✅ | 顺序操作 |

```
选型："只要最值 → 堆；要范围查询 → TreeMap"
```

## 2. 完整代码模板

### 2.1 TopK 模板（求第 K 大 / 前 K 大）

```java
/**
 * LeetCode 215. 数组中的第 K 个最大元素（堆版）
 * 小根堆维护"最大的 k 个"：堆顶 = 第 k 大
 */
public int findKthLargest(int[] nums, int k) {
    PriorityQueue<Integer> minHeap = new PriorityQueue<>();

    for (int x : nums) {
        minHeap.offer(x);
        if (minHeap.size() > k) {
            minHeap.poll();          // 弹出最小的 → 留最大的 k 个
        }
    }
    return minHeap.peek();           // 堆顶 = 第 k 大
}
// 复杂度 O(n log k)：插入 O(log k) × n 次
// 空间 O(k)

/**
 * 求最小的 k 个 → 大根堆（堆顶是最大候选，超 k 弹出）
 * PriorityQueue<Integer> maxHeap = new PriorityQueue<>((a,b) -> b-a);
 * 记忆："求大的留小堆，求小的留大堆"（堆顶是被淘汰候选）
 */
```

### 2.2 双堆模板（数据流中位数 295）

```java
/**
 * LeetCode 295. 数据流中位数（双堆经典）
 * 大根堆存左半（较小的一半），小根堆存右半（较大的一半）
 * 保持左堆大小 ≥ 右堆（差 ≤ 1）
 */
class MedianFinder {
    PriorityQueue<Integer> left  = new PriorityQueue<>((a,b) -> b-a);  // 大根堆
    PriorityQueue<Integer> right = new PriorityQueue<>();              // 小根堆

    public void addNum(int num) {
        left.offer(num);                 // ① 先入左
        right.offer(left.poll());        // ② 左最大给右（平衡）
        if (left.size() < right.size()) {
            left.offer(right.poll());    // ③ 保持左 ≥ 右
        }
    }

    public double findMedian() {
        if (left.size() > right.size()) {
            return left.peek();          // 奇数：左堆顶
        }
        return (left.peek() + right.peek()) / 2.0;   // 偶数：平均
    }
}
// 插入 O(log n)，查询中位数 O(1)
// ⚠️ 平衡三步的顺序：入左 → 左顶给右 → 右多还左
```

### 2.3 合并 K 个有序链表（堆应用）

```java
/**
 * LeetCode 23. 合并 K 个升序链表
 * 所有头节点入堆（按值排序）→ 每次取最小接入结果
 */
public ListNode mergeKLists(ListNode[] lists) {
    PriorityQueue<ListNode> pq = new PriorityQueue<>((a, b) -> a.val - b.val);
    for (ListNode node : lists) {
        if (node != null) pq.offer(node);      // 所有头入堆
    }

    ListNode dummy = new ListNode(-1);
    ListNode tail = dummy;
    while (!pq.isEmpty()) {
        ListNode min = pq.poll();              // 取最小
        tail.next = min;
        tail = tail.next;
        if (min.next != null) pq.offer(min.next);  // 后继补入
    }
    return dummy.next;
}
// O(N log K)：N 总节点，K 链表数
```

## 3. 堆的原理与实现

### 3.1 上浮与下沉（手写堆的基础）

```java
/**
 * 手写最大堆核心操作（了解原理，面试备用）
 */
class MaxHeap {
    private int[] heap;
    private int size;

    // 上浮：新元素与父比较，大则交换（插入用）
    private void siftUp(int i) {
        while (i > 0) {
            int parent = (i - 1) / 2;
            if (heap[i] <= heap[parent]) break;
            swap(i, parent);
            i = parent;
        }
    }

    // 下沉：与较大孩子比较，小则交换（删除/建堆用）
    private void siftDown(int i) {
        while (2 * i + 1 < size) {
            int child = 2 * i + 1;
            if (child + 1 < size && heap[child + 1] > heap[child]) {
                child++;                       // 选较大孩子
            }
            if (heap[i] >= heap[child]) break;
            swap(i, child);
            i = child;
        }
    }

    // 插入：尾部放入 → 上浮
    public void offer(int val) {
        heap[size++] = val;
        siftUp(size - 1);
    }

    // 取最大：堆顶与尾部交换 → 下沉
    public int poll() {
        int top = heap[0];
        heap[0] = heap[--size];
        siftDown(0);
        return top;
    }
}
```

### 3.2 为什么建堆是 O(n)？

```
直觉：多数节点在底层附近 → 下沉次数少
严格推导：
  深度 d 的节点最多下沉 h-d 次
  总下沉次数 = Σ(d=0..h) (n/2^(d+1)) × (h-d)
            ≈ n（等比数列求和）
  → 建堆 O(n) 而非 O(n log n)！

对比：n 次插入（每次上浮 O(log n)）= O(n log n)
  → 建堆用下沉更优（面试必答）

记忆："下沉建堆 O(n)，插入上浮 O(n log n)"
```

### 3.3 堆排序（三行核心）

```java
/**
 * 堆排序：建堆 → 反复取顶交换 → 下沉
 */
public void heapSort(int[] arr) {
    int n = arr.length;
    for (int i = n / 2 - 1; i >= 0; i--) {   // ① 建堆（下沉）
        siftDown(arr, i, n);
    }
    for (int i = n - 1; i > 0; i--) {        // ② 取顶
        swap(arr, 0, i);                     //    最大放末尾
        siftDown(arr, 0, i);                 //    重建堆
    }
}
// O(n log n) 时间，O(1) 空间，不稳定
// 完整实现见排序体系-03
```

## 4. TopK 与双堆详解

### 4.1 TopK 两种解法对比

| 维度 | 堆 | 快速选择 |
|------|:---:|:---:|
| 平均复杂度 | O(n log k) | **O(n)** |
| 最坏 | O(n log k) 稳定 | O(n²)（随机化缓解） |
| 空间 | O(k) | O(log n) 递归 |
| 数据流 | ✅ 在线 | ❌ 需全量 |
| 修改数组 | 不修改 | 原地交换 |
| 选型 | **流式/不修改** | 静态数组更快 |

```
面试话术：
"TopK 我有两种方案——堆 O(n log k) 支持
 数据流在线处理；快速选择平均 O(n) 更快
 但需要全量数组。这题是【静态/流式】，
 我选【...】。"
```

### 4.2 双堆的平衡推导

```
双堆不变量：
  left（大根）存较小一半，right（小根）存较大一半
  left.size() ∈ {right.size(), right.size()+1}

插入 num 后恢复不变量（三步）：
  ① num 入 left（假设先入左）
  ② left 最大给 right（保持有序分界）
  ③ right 比 left 多 → 还一个给 left

为什么这样三步？
  ① 保证"左小右大"的分界正确
  ② 防止 num 乱序（先入左排序，再转移）
  ③ 恢复大小平衡

中位数：
  奇数（left 多 1）→ left.peek()
  偶数（相等）→ (left+right)/2
```

### 4.3 双堆的其他应用

```
① 480 滑动窗口中位数：双堆 + 延迟删除
   （窗口滑出元素：标记删除 + 弹出时验证）
② 数据流最大/最小 K 个：定长堆
③ 中位数的变体：随时删除（295 扩展）

⚠️ 延迟删除技巧（480）：
  堆无法 O(1) 删任意元素
  → Map 记录待删次数，弹出时惰性验证
  → 均摊 O(log n)
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"TopK 用大小为 k 的小根堆：
 遍历数组时插入堆，超过 k 弹出最小——
 堆里永远保留最大的 k 个，堆顶就是第 k 大。
 O(n log k) 时间 O(k) 空间。
 优势：数据流场景也能在线处理，
 这是堆相比快速选择的独特价值。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 为什么建堆 O(n)？ | 下沉建堆：底层节点下沉少，Σ 等比求和 ≈ n；插入上浮才 O(n log n) |
| 2 | 求第 K 大为什么用小根堆？ | 小根堆堆顶是 k 个候选中的最小 = 第 k 大；"求大留小堆" |
| 3 | 双堆怎么保持平衡？ | 三步：入左 → 左顶给右 → 右多还左；差 ≤ 1 |
| 4 | PriorityQueue 特性？ | 默认小根堆；迭代无序；不支持 O(1) 删任意元素（延迟删除） |
| 5 | 堆 vs TreeMap？ | 堆只给最值 O(1)；TreeMap 有序+范围 O(log n) |
| 6 | 堆排序复杂度/稳定性？ | O(n log n)/O(1) 空间/不稳定（堆顶与末尾远距离交换） |
| 7 | 大数据 TopK？ | 堆 O(n log k) 内存 O(k)（k 远小于 n）；配合外部排序 |
| 8 | 如何自定义优先级？ | Comparator：`(a,b) -> b-a` 大根堆；对象按字段比较 |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 比较器写反 | 大小根堆颠倒 | 记住 `b-a` 是大根堆 |
| 堆方向选错 | 第 K 大用小根 | 求大留小堆 |
| 双堆顺序错 | 分界混乱 | 三步固定顺序 |
| 忘记初始化比较器 | 编译/逻辑错误 | new PriorityQueue<>(comparator) |
| 迭代堆当有序 | 结果乱序 | 堆只保证堆顶最值（poll 才有序） |

> 🎯 **核心要点**：堆 = **O(1) 取最值 + O(log n) 增删**。三大模板：TopK（定长堆）、双堆（中位数三步平衡）、合并 K 链（头入堆）。识别信号："最大/最小 K 个、每次取最优、数据流"。建堆 O(n) 的推导是原理分。
