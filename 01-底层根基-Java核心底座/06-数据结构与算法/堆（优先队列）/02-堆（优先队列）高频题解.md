## 1. 215. 数组中的第 K 个最大元素（母题）

### 1.1 完整实现（定长小根堆）

```java
/**
 * LeetCode 215. 数组中的第 K 个最大元素（堆版）
 * 小根堆维护"最大的 k 个"：堆顶 = 第 k 大
 */
public int findKthLargest(int[] nums, int k) {
    PriorityQueue<Integer> minHeap = new PriorityQueue<>();

    for (int x : nums) {
        minHeap.offer(x);
        if (minHeap.size() > k) {
            minHeap.poll();          // 弹出最小的 → 留最大的 k 个
        }
    }
    return minHeap.peek();           // 堆顶 = 第 k 大
}
// 推演 [3,2,1,5,6,4], k=2：
//   最终堆内 [5,6] → peek = 5 ✓
// ⚠️ 面试必答：
//   "小根堆堆顶是 k 个候选里最小的，即第 k 大；
//    求大的留小堆——堆顶是被淘汰的'门槛'。"
```

### 1.2 快速选择（O(n) 平均）

```java
/**
 * 快选：partition 后只递归一侧，平均 O(n)
 * ⚠️ 目标索引是 n-k（第 k 大 = 升序第 n-k 位）
 */
public int findKthLargest_QS(int[] nums, int k) {
    return quickSelect(nums, 0, nums.length - 1, nums.length - k);
}
// 与堆解法对比见 01-进阶 §2.3
// ⚠️ 面试话术："静态数组 → 快选更快；
//   数据流 → 堆在线处理。两种都要会写。"
```

## 2. 703. 数据流中的第 K 大元素

### 2.1 完整实现（215 的在线变体）

```java
/**
 * LeetCode 703. 数据流中的第 K 大元素
 * 定长堆：add 与初始化共用一条逻辑
 */
class KthLargest {
    private final PriorityQueue<Integer> pq;
    private final int k;

    public KthLargest(int k, int[] nums) {
        this.k = k;
        pq = new PriorityQueue<>();
        for (int x : nums) add(x);      // ⚠️ 初始化复用 add，少写一遍
    }

    public int add(int val) {
        pq.offer(val);
        if (pq.size() > k) pq.poll();   // 超出定长 → 弹最小
        return pq.peek();
    }
}
// 推演 k=3，初始 [4,5,8,2]：
//   add(3)→4  add(5)→5  add(10)→8  add(9)→8  add(4)→8 ✓
// ⚠️ 面试必答：
//   "堆里永远保留见过的最大的 k 个；
//    每次 add O(log k)，堆顶即第 k 大。"
```

## 3. 1046. 最后一块石头的重量

### 3.1 完整实现（大根堆模拟）

```java
/**
 * LeetCode 1046. 最后一块石头的重量
 * 每次取最重的两块碰撞 → 大根堆 poll 两次
 */
public int lastStoneWeight(int[] stones) {
    PriorityQueue<Integer> maxHeap = new PriorityQueue<>((a, b) -> b - a);
    for (int s : stones) maxHeap.offer(s);

    while (maxHeap.size() > 1) {
        int y = maxHeap.poll();        // 最重
        int x = maxHeap.poll();        // 次重
        if (y > x) maxHeap.offer(y - x);  // 不等 → 剩余入堆
    }
    return maxHeap.isEmpty() ? 0 : maxHeap.peek();
}
// 推演 [2,7,4,1,8,1]：
//   8-7=1 → [4,2,1,1,1] → 4-2=2 → [2,1,1,1]
//   → 2-1=1 → [1,1,1] → 1-1=0（相等不剩）→ 剩 [1] → 1 ✓
// ⚠️ 面试必答：
//   "操作描述里带'每次取最大/最重' → 大根堆；
//    每次取两个 + 差量回填 = 模拟题标准节奏。"
```

## 4. 347. 前 K 个高频元素

### 4.1 完整实现（HashMap + 小根堆）

```java
/**
 * LeetCode 347. 前 K 个高频元素
 * ① HashMap 统计频率 ② 小根堆按频率维护 top-k
 */
public int[] topKFrequent(int[] nums, int k) {
    Map<Integer, Integer> freq = new HashMap<>();
    for (int x : nums) freq.merge(x, 1, Integer::sum);

    // ⚠️ 比较器按"频率"升序，不是按元素值！
    PriorityQueue<Integer> pq = new PriorityQueue<>(
        (a, b) -> freq.get(a) - freq.get(b));
    for (int key : freq.keySet()) {
        pq.offer(key);
        if (pq.size() > k) pq.poll();   // 频率最低的弹出
    }

    int[] res = new int[k];
    for (int i = 0; i < k; i++) res[i] = pq.poll();
    return res;
}
// 推演 [1,1,1,2,2,3], k=2 → 频率 {1:3, 2:2, 3:1}
//   弹出 3 → 堆内留下 1、2 → 答案 [2,1] ✓（题目不要求顺序）
// O(n log k)，空间 O(n)
// ⚠️ 面试必答：
//   "高频 = 先统计再 TopK；比较器写频率差，
//    写成元素值差就变成'元素大小 TopK'了。"
```

### 4.2 桶排序（O(n) 方案）

```java
// 频率最大 ≤ n → 桶数组下标 = 频率，从高到低收集
// List<Integer>[] buckets = new List[n + 1];
// 倒序遍历 buckets，凑满 k 个即停
// ⚠️ 面试必答："数据范围明确、空间允许时，
//   桶排序 O(n) 优于堆 O(n log k)，是加分项。"
```

## 5. 692. 前 K 个高频单词

### 5.1 完整实现（347 + 字典序比较器）

```java
/**
 * LeetCode 692. 前 K 个高频单词
 * 频率升序小根堆；同频 → 字典序"大"的先弹（留下小的）
 */
public List<String> topKFrequent(String[] words, int k) {
    Map<String, Integer> freq = new HashMap<>();
    for (String w : words) freq.merge(w, 1, Integer::sum);

    PriorityQueue<String> pq = new PriorityQueue<>(
        (a, b) -> freq.get(a).equals(freq.get(b))
                  ? b.compareTo(a)                 // 同频：字典序大的在前
                  : freq.get(a) - freq.get(b));    // 异频：频率升序
    for (String w : freq.keySet()) {
        pq.offer(w);
        if (pq.size() > k) pq.poll();
    }

    LinkedList<String> res = new LinkedList<>();
    while (!pq.isEmpty()) res.addFirst(pq.poll()); // ⚠️ 堆是升序 → 头插反转
    return res;
}
// 推演 ["i","love","leetcode","i","love","coding"], k=2
//   → ["i","love"] ✓（i 与 love 同频 2，字典序 i < love）
// ⚠️ 面试必答：
//   "小根堆弹小的 → 字典序大的先被弹出；
//    堆内留下的都是字典序小的，结果需反转。
//    两条规则合并写进一个 Comparator。"
```

## 6. 23. 合并 K 个升序链表

### 6.1 完整实现（K 路归并）

```java
/**
 * LeetCode 23. 合并 K 个升序链表
 * 所有头节点入堆（按值）→ 每次取最小接入，后继补入
 */
public ListNode mergeKLists(ListNode[] lists) {
    PriorityQueue<ListNode> pq = new PriorityQueue<>((a, b) -> a.val - b.val);
    for (ListNode node : lists) {
        if (node != null) pq.offer(node);   // ① 所有头入堆
    }

    ListNode dummy = new ListNode(-1);
    ListNode tail = dummy;
    while (!pq.isEmpty()) {
        ListNode min = pq.poll();           // ② 取最小
        tail.next = min;
        tail = tail.next;
        if (min.next != null) pq.offer(min.next);  // ③ 后继补入
    }
    return dummy.next;
}
// 推演 k=3（各 2 节点）→ 全程 log 3 级：
//   每取一个节点，堆内始终只有 ≤ k 个头
// O(N log K)：N 总节点数，K 链表数；空间 O(K)
// ⚠️ 面试必答：
//   "堆内永远只有 K 个候选头 → O(N log K)；
//    对比两两合并 O(N log K) 常数更大、逐链
//    扫描 O(NK)，堆是 K 路归并的标准答案。"
```

## 7. 253. 会议室 II

### 7.1 完整实现（贪心 + 最小堆）

```java
/**
 * LeetCode 253. 会议室 II
 * 按开始时间排序；小根堆存"结束时间"，
 * 堆顶（最早结束）≤ 当前开始 → 复用房间
 */
public int minMeetingRooms(int[][] intervals) {
    Arrays.sort(intervals, (a, b) -> a[0] - b[0]);   // ① 按开始排序
    PriorityQueue<Integer> endTimes = new PriorityQueue<>();

    for (int[] iv : intervals) {
        if (!endTimes.isEmpty() && endTimes.peek() <= iv[0]) {
            endTimes.poll();        // ② 最早结束的会议已开完 → 复用
        }
        endTimes.offer(iv[1]);      // ③ 当前会议占用一个房间
    }
    return endTimes.size();         // 堆大小 = 需要的房间数
}
// 推演 [[0,30],[5,10],[15,20]]：
//   [0,30] → 堆 [30]
//   [5,10] → 30>5 不复用 → [10,30]
//   [15,20] → 10≤15 复用 → [20,30] → 答案 2 ✓
// ⚠️ 面试必答：
//   "贪心：先开始的先安排；最早结束的优先复用。
//    堆里存'正在进行'的会议 → 大小即峰值并发。"
```

## 8. 621. 任务调度器

### 8.1 完整实现（计数 + 公式，O(n)）

```java
/**
 * LeetCode 621. 任务调度器
 * 桶思想：最高频任务 maxFreq 决定最少时间
 * 最少 = (maxFreq-1)*(n+1) + 最高频任务种类数
 */
public int leastInterval(char[] tasks, int n) {
    int[] cnt = new int[26];
    for (char c : tasks) cnt[c - 'A']++;

    int maxFreq = 0, maxCount = 0;      // 最高频次数、有几类并列最高
    for (int c : cnt) {
        if (c > maxFreq) { maxFreq = c; maxCount = 1; }
        else if (c == maxFreq) maxCount++;
    }
    // ⚠️ 与任务总数取 max：冷却没填满 → 任务数更少则被任务总数撑大
    return Math.max(tasks.length, (maxFreq - 1) * (n + 1) + maxCount);
}
// 推演 ["A","A","A","B","B","B"], n=2：
//   maxFreq=3, maxCount=2 → (3-1)*3+2 = 8 ✓
//   A B _ A B _ A B（8 个时间片）
// ⚠️ 面试必答：
//   "A 类任务隔 n 个时间片 → 最后一个 A 后无需
//    冷却，所以 (maxFreq-1) 个完整周期 + 尾段。
//    若空隙可被其他任务填满，用任务总数兜底。"
```

## 9. 295. 数据流的中位数

### 9.1 完整实现（双堆三步平衡）

```java
/**
 * LeetCode 295. 数据流的中位数（双堆经典）
 * 大根堆存左半（较小的一半），小根堆存右半
 * 保持 left.size() ∈ {right.size(), right.size()+1}
 */
class MedianFinder {
    PriorityQueue<Integer> left  = new PriorityQueue<>((a, b) -> b - a);
    PriorityQueue<Integer> right = new PriorityQueue<>();

    public void addNum(int num) {
        left.offer(num);                  // ① 先入左
        right.offer(left.poll());         // ② 左最大给右（保持分界）
        if (left.size() < right.size()) {
            left.offer(right.poll());     // ③ 恢复"左 ≥ 右"
        }
    }

    public double findMedian() {
        if (left.size() > right.size()) return left.peek();
        return (left.peek() + right.peek()) / 2.0;
    }
}
// 推演 add 1,2,3：
//   add(1) → left=[1], right=[]                 → 中位 1
//   add(2) → 入左 [1,2] → 给右 2 → 平衡
//          → left=[1], right=[2]                → 中位 1.5
//   add(3) → 入左 [1,3] → 给右 3 → 左小还 2
//          → left=[1,2], right=[3]              → 中位 2 ✓
// ⚠️ 面试必答：
//   "三步固定顺序（入左→给右→还左）保证分界正确；
//    查询 O(1)、插入 O(log n)。追问：删除任意元素
//    需配合延迟删除（见 480）。"
```

## 10. 480. 滑动窗口中位数

### 10.1 完整实现（双堆 + 延迟删除）

```java
/**
 * LeetCode 480. 滑动窗口中位数（Hard 综合）
 * 295 双堆 + 窗口滑出元素 → 延迟删除
 */
class Solution {
    PriorityQueue<Integer> left  = new PriorityQueue<>((a, b) -> b - a);
    PriorityQueue<Integer> right = new PriorityQueue<>();
    Map<Integer, Integer> lazy = new HashMap<>();    // 待删计数
    int k;

    public double[] medianSlidingWindow(int[] nums, int k) {
        this.k = k;
        for (int i = 0; i < k; i++) addNum(nums[i]);
        int n = nums.length;
        double[] ans = new double[n - k + 1];
        ans[0] = getMedian();

        for (int i = k; i < n; i++) {
            lazy.merge(nums[i - k], 1, Integer::sum); // ① 滑出：标记删除
            addNum(nums[i]);                          // ② 滑入
            balance();                                // ③ 恢复平衡
            ans[i - k + 1] = getMedian();
        }
        return ans;
    }

    void addNum(int num) {        // 按大小直接入堆（省一次转移）
        if (left.isEmpty() || num <= left.peek()) left.offer(num);
        else right.offer(num);
    }

    void clean(PriorityQueue<Integer> h) {   // 惰性清理：弹出被标记的
        while (!h.isEmpty() && lazy.getOrDefault(h.peek(), 0) > 0) {
            lazy.merge(h.poll(), -1, Integer::sum);
        }
    }

    void balance() {
        clean(left); clean(right);
        if (left.size() > right.size() + 1) right.offer(left.poll());
        if (right.size() > left.size()) left.offer(right.poll());
        clean(left); clean(right);
    }

    double getMedian() {
        clean(left); clean(right);
        return left.size() == right.size()
               ? ((double) left.peek() + right.peek()) / 2 : left.peek();
    }
}
// 推演 nums=[1,3,-1,-3,5,3,6,7], k=3：
//   [1,3,-1]→1  [3,-1,-3]→-1  [-1,-3,5]→-1
//   [-3,5,3]→3  [5,3,6]→5      [3,6,7]→6
//   答案 [1,-1,-1,3,5,6] ✓
// ⚠️ 面试必答：
//   "堆无法 O(1) 删任意元素 → Map 记待删次数，
//    弹出时惰性验证；每元素假删+真删各一次，
//    均摊 O(log n)。三步：标记 → 入堆 → 平衡。"
```
