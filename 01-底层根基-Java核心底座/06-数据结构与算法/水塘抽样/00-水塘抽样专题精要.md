## 1. 核心概念

### 1.1 问题背景

> 水塘抽样（Reservoir Sampling）：从**长度未知的数据流**中**等概率**随机抽取样本，**O(1) 空间**（无法存储全部数据）。

```
场景：
  超大文件随机取一行（不知行数）
  数据流随机采样（无法回头）
  链表随机节点（只知道头）

为什么不能先数总量再随机？
  流式场景：无法二次读取（一次遍历）
  → 需要"边走边决定"且保证等概率
```

### 1.2 识别信号

```
"流式/未知长度 + 随机采样" → 水塘抽样
"链表随机节点/文件随机行" → 水塘抽样
"O(1) 空间 + 等概率" → 水塘抽样

⚠️ 与洗牌的区别：
  洗牌：全量数组（可打乱，O(n) 空间）
  水塘：流式数据（一次扫描，O(1) 空间）
```

### 1.3 核心直觉

```
遍历到第 i 个元素时：以 1/i 概率替换候选

第 1 个：1/1 选中
第 2 个：1/2 替换（第 1 个剩 1/2）
第 3 个：1/3 替换（前两个各剩 1/2 × 2/3 = 1/3）
...
第 n 个：1/n 替换 → 每个元素最终概率 = 1/n ✓

⚠️ 关键是"不确定 n"也能保证等概率
  （不需要先知道总量！）
```

## 2. 完整代码模板

### 2.1 382. 链表随机节点（标准水塘）

```java
/**
 * LeetCode 382. 链表随机节点（水塘抽样 k=1）
 */
class Solution {
    private ListNode head;
    private Random random = new Random();

    public Solution(ListNode head) {
        this.head = head;
    }

    public int getRandom() {
        ListNode cur = head;
        int result = 0, count = 0;

        while (cur != null) {
            count++;
            // ⚠️ 以 1/count 概率替换候选
            if (random.nextInt(count) == 0) {
                result = cur.val;
            }
            cur = cur.next;
        }
        return result;
    }
}
// O(n) 时间 O(1) 空间
// ⚠️ nextInt(count) == 0 的概率 = 1/count
```

### 2.2 398. 随机数索引（加权版本）

```java
/**
 * LeetCode 398. 随机数索引
 * target 出现多次，等概率返回任一下标
 */
public int pick(int[] nums, int target) {
    int result = -1, count = 0;

    for (int i = 0; i < nums.length; i++) {
        if (nums[i] == target) {
            count++;                        // target 第 count 次出现
            if (random.nextInt(count) == 0) {
                result = i;                 // 1/count 概率替换
            }
        }
    }
    return result;
}
// 例：target 出现 3 次 → 每个下标概率 1/3 ✓
// ⚠️ 只对 target 计数（其他值跳过）
// 推演 [1,2,1,1], target=1（下标 0,2,3）：
//   i=0：count=1 → nextInt(1)==0 → result=0
//   i=2：count=2 → 1/2 概率替换为 2
//   i=3：count=3 → 1/3 概率替换为 3
//   最终：下标 3 概率 1/3；下标 2 概率 2/3×1/2=1/3；
//         下标 0 概率 2/3×1/2=1/3 ✓ 等概率！
```

### 2.3 通用模板（k 个样本）

```java
/**
 * 水塘抽样通用模板（取 k 个样本）
 */
public int[] reservoirSample(Stream<Integer> stream, int k) {
    int[] reservoir = new int[k];
    int count = 0;
    Iterator<Integer> it = stream.iterator();

    while (it.hasNext()) {
        int x = it.next();
        if (count < k) {
            reservoir[count] = x;            // 前 k 个直接取
        } else {
            // ⚠️ k/(count+1) 概率替换池中随机一个
            int j = random.nextInt(count + 1);
            if (j < k) {
                reservoir[j] = x;
            }
        }
        count++;
    }
    return reservoir;
}
// 每个元素最终在池中的概率 = k/n
// ⚠️ j < k 的检查：k/(count+1) 概率进入池
```

## 3. 等概率的数学证明

### 3.1 k=1 的归纳证明

```
归纳假设：处理完前 i-1 个元素后，每个元素概率 1/(i-1)

第 i 个元素：
  被选中概率 = 1/i（替换候选）
  前 i-1 个元素保留概率 = 1/(i-1) × (1 - 1/i)
                        = 1/(i-1) × (i-1)/i
                        = 1/i ✓

→ 处理完 n 个元素：每个概率 1/n ✓

⚠️ 关键：概率"相乘相消"
  1/(i-1) × (i-1)/i = 1/i（每步保持等概率）
```

### 3.2 k 个样本的证明

```
归纳假设：前 i-1 个元素，每个在池中概率 k/(i-1)

第 i 个元素（i > k）：
  入池概率 = k/i（替换池中随机一个）
  池中元素保留概率 = k/(i-1) × (1 - k/i × 1/k)
                    = k/(i-1) × (i-1)/i
                    = k/i ✓

→ 处理完 n 个元素：每个概率 k/n ✓
（入池概率 k/i × 之后不被替换的概率）
```

### 3.3 证明的直觉理解

```
"每一步保持'等概率不变量'"
  第 i 步结束时：前 i 个元素等概率
  第 i+1 步：新元素 1/(i+1)，旧的乘以 (i)/(i+1)
  → 全部变为 1/(i+1) ✓

⚠️ 面试表达：
"用数学归纳证明：假设前 i-1 个等概率，
 第 i 个以 1/i 替换后，前 i 个仍等概率
 （旧的保留概率相乘恰好抵消）。"
```

## 4. 水塘抽样的扩展

### 4.1 加权水塘（带权重采样）

```
每个元素有权重 wᵢ：
  ① 扩展水塘：第 i 个以 wᵢ/(Σw) 概率替换
  ② 简单方案：按权重复制（空间爆炸）
  ③ A-Res 算法：生成 key = rand^(1/w) 取最大

⚠️ 面试定位：
  加权版本竞赛级；标准水塘（等权）面试足够
  提一句"加权需要 A-Res"即可
```

### 4.2 与拒绝采样的区别

```
水塘：等概率选"位置"（未知 n）
拒绝：生成目标分布（已知范围）

选型：
  流式未知总量 → 水塘
  已知范围生成分布 → 拒绝采样
  两者都属随机化专题

⚠️ 面试对比表达：
"水塘解决'流式等概率'；拒绝采样解决
 '从已知范围生成目标分布'——
 前者重试，后者重试。"
```

### 4.3 工程应用

```
① 大数据采样：超大文件随机行
② AB 测试：流式等概率分组
③ 数据库抽样：未知行数随机记录
④ 日志采样：保留代表性样本

⚠️ 工程注意：
  Random 线程安全（并发用 ThreadLocalRandom）
  种子固定可复现（测试用）
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"未知总量无法先计数再随机，用蓄水池抽样：
 遍历时第 i 个元素以 1/i 概率替换当前候选。
 归纳证明每个元素最终被选概率都是 1/n：
 旧的保留概率 (i-1)/i 与新的选中概率 1/i
 相乘相消，保持等概率不变量。
 O(n) 时间 O(1) 空间，适合流式场景。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 为什么 1/i 概率能等概率？ | 归纳证明：相乘相消保持不变量 |
| 2 | 什么时候用蓄水池？ | 流式/未知总量/一次遍历/无法回头 |
| 3 | 与洗牌区别？ | 水塘流式 O(1) 空间；洗牌全量 O(n) |
| 4 | k 个样本怎么做？ | 前 k 直接取，之后 k/i 概率替换 |
| 5 | 加权版本？ | A-Res（key = rand^(1/w)）竞赛级 |
| 6 | 与拒绝采样区别？ | 位置等概率 vs 分布生成 |
| 7 | 能先数总量吗？ | 能 → 直接随机下标更简单 |
| 8 | 复杂度？ | O(n) 时间 O(1) 空间 |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| nextInt(count) 用 count-1 | 概率偏差 | nextInt(count) |
| 能计数还用蓄水池 | 过度设计 | 直接随机下标 |
| 忘处理空流 | 返回默认 | 判空 |
| 概率替换写反 | 不等概率 | 1/count 替换 |
| 加权当等权 | 概率错误 | A-Res 或说明限制 |

> 🎯 **核心要点**：水塘抽样 = **第 i 个以 1/i 替换** + 归纳证明等概率。识别信号："未知总量、流式、随机抽样、O(1) 空间"。k 样本版本（k/i 替换池中随机）是进阶必知；与洗牌/拒绝采样的区别是面试对比点。
