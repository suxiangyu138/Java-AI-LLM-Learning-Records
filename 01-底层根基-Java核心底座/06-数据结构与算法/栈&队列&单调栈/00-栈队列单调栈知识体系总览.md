## 4. 核心概念速查

| 概念 | 一句话解释 | 典型例题 |
|------|-----------|------|
| **LIFO** | 后进先出（栈） | 20 括号匹配 |
| **FIFO** | 先进先出（队列） | 933 请求计数 |
| **辅助栈** | 同步记录最小值/最大值 | 155 最小栈 |
| **单调栈** | 栈内单调递增/递减 | 739 每日温度 |
| **存下标** | 单调栈存索引而非值 | 739/84/42 |
| **下一个更大元素** | 右侧第一个比它大的 | 496/503 |
| **弹出时机** | 遇到更大/更小时弹出计算 | 单调栈模板 |
| **补哨兵** | 首尾补 0 统一边界 | 84 最大矩形 |
| **循环数组** | 下标取模遍历两遍 | 503 |
| **栈模拟队列** | 双栈倒腾（in/out） | 232 |
| **双端队列** | 两端操作，单调队列基础 | 239 |

## 7. 记忆口诀

```
栈管最近，队列管顺序，Deque 管两端
下一个更大 → 单调递减栈
下一个更小 → 单调递增栈
存下标不存值，弹出即答案
首尾补 0 免判空，残留强制弹
辅助栈同步，<= 保重复
问题特性 → 工具特性（选型王道）
```
