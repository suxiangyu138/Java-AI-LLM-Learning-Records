## 1. 单调栈的本质

### 1.1 定义

> 单调栈：栈内元素保持单调（递增或递减）的栈。新元素入栈时，**弹出所有破坏单调性的元素**，再入栈。

```
单调递减栈（求下一个更大元素）：
  入栈 5 → [5]
  入栈 3 → [5, 3]        （3 < 5 不破坏单调）
  入栈 4 → 弹出 3 → [5, 4]  （4 > 3 破坏递减 → 弹 3）
```

### 1.2 解决的问题

```
"下一个更大/更小元素"问题的暴力解法：
  每个元素向右扫描找第一个比它大的 → O(n²)

单调栈解法：每个元素恰好入栈出栈一次 → O(n)

适用特征：找"右侧/左侧第一个比当前大（或小）的元素"

单调栈方向对照：
  下一个更大元素 → 单调递减栈（维护"还没找到答案"的候选）
  下一个更小元素 → 单调递增栈
```

### 1.3 为什么是 O(n)？

```
每个元素：
  入栈恰好 1 次
  出栈最多 1 次（弹出后永不再入）
  → 总操作 2n → O(n)

对比暴力：每个元素都要扫描后面的所有元素 → O(n²)

面试必答："每个元素进出栈各一次，所以总操作 O(2n)=O(n)"
```

## 2. 739. 每日温度：母题

### 2.1 完整实现（单调递减栈）

```java
/**
 * LeetCode 739. 每日温度（单调栈第一题）
 * 返回每个温度后几天出现更高的温度
 * [73,74,75,71,69,72,76,73] → [1,1,4,2,1,1,0,0]
 *
 * 单调递减栈（存下标！）：
 *   当前温度 > 栈顶温度 → 栈顶找到了"下一个更大" → 弹栈计算距离
 *   当前温度 ≤ 栈顶温度 → 入栈（继续等待）
 */
public int[] dailyTemperatures(int[] temperatures) {
    int n = temperatures.length;
    int[] answer = new int[n];
    Deque<Integer> stack = new ArrayDeque<>();   // 存下标

    for (int i = 0; i < n; i++) {
        // 当前温度比栈顶大 → 栈顶的下一个更大元素找到了
        while (!stack.isEmpty()
               && temperatures[i] > temperatures[stack.peek()]) {
            int idx = stack.pop();               // 弹出栈顶
            answer[idx] = i - idx;               // 距离 = 天数差
        }
        stack.push(i);                           // 当前下标入栈
    }
    // 栈中剩余的元素：后面没有更高的温度 → 保持 0
    return answer;
}
```

### 2.2 推演：temperatures = [73,74,75,71,69,72,76,73]

```
i=0(73): 栈空 → 入栈 [0]
i=1(74): 74>73 → 弹0, ans[0]=1-0=1；入栈 [1]
i=2(75): 75>74 → 弹1, ans[1]=1；入栈 [2]
i=3(71): 71<75 → 入栈 [2,3]
i=4(69): 69<71 → 入栈 [2,3,4]
i=5(72): 72>69 → 弹4, ans[4]=1；72>71 → 弹3, ans[3]=2；入栈 [2,5]
i=6(76): 76>72 → 弹5, ans[5]=1；76>75 → 弹2, ans[2]=4；入栈 [6]
i=7(73): 73<76 → 入栈 [6,7]
栈中剩 [6,7] → ans[6]=0, ans[7]=0
结果 [1,1,4,2,1,1,0,0] ✓
```

### 2.3 关键理解

```
为什么"当前比栈顶大"时弹出？
  当前元素是栈顶的"下一个更大元素"（第一个比它大的）
  → 栈顶答案确定，弹出（出栈后永不再处理）

为什么存下标不存值？
  需要计算距离（天数差）→ 必须知道位置
```

## 3. 496. 下一个更大元素 I

### 3.1 完整实现（单调栈 + 哈希表）

```java
/**
 * LeetCode 496. 下一个更大元素 I
 * nums1 是 nums2 的子集，返回 nums1 中每个元素在
 * nums2 中的下一个更大元素
 *
 * 思路：
 *   ① 对 nums2 用单调栈预处理：每个元素的下一个更大 → 哈希表
 *   ② 遍历 nums1 查表
 * 复杂度：O(n2 + n1) = O(n)
 */
public int[] nextGreaterElement(int[] nums1, int[] nums2) {
    // ① 单调栈预处理 nums2
    Map<Integer, Integer> nextGreater = new HashMap<>();
    Deque<Integer> stack = new ArrayDeque<>();

    for (int x : nums2) {
        while (!stack.isEmpty() && x > stack.peek()) {
            nextGreater.put(stack.pop(), x);   // 栈顶的下一个更大 = x
        }
        stack.push(x);
    }
    // 栈中剩余元素没有下一个更大（不用处理，查不到返回 -1）

    // ② 查表
    int[] result = new int[nums1.length];
    for (int i = 0; i < nums1.length; i++) {
        result[i] = nextGreater.getOrDefault(nums1[i], -1);
    }
    return result;
}
// nums2=[1,3,4,2]：
//   1: next=3；3: next=4；4: 无；2: 无
// nums1=[4,1,2] → [-1,3,-1] ✓
```

### 3.2 模式总结

```
"两个数组"的变体套路：
  对大的数组（nums2）预处理 → 哈希表
  遍历小的数组（nums1）查表
  → O(n) 而非 O(n²)
```

## 4. 503. 下一个更大元素 II

### 4.1 完整实现（循环数组）

```java
/**
 * LeetCode 503. 下一个更大元素 II
 * 循环数组（尾部接头部）中每个元素的下一个更大元素
 * [1,2,1] → [2,-1,2]（最后一个 1 的下一个更大是第一个 2）
 *
 * 技巧：遍历两遍（2n 次），下标取模 i % n
 *   → 等效于"数组后面再接一份自己"
 *   → 每个元素都能看到"后面的所有元素 + 前面的一部分"
 */
public int[] nextGreaterElements(int[] nums) {
    int n = nums.length;
    int[] result = new int[n];
    Arrays.fill(result, -1);                     // 默认无更大
    Deque<Integer> stack = new ArrayDeque<>();

    for (int i = 0; i < 2 * n; i++) {
        int idx = i % n;                         // ⚠️ 取模模拟循环
        while (!stack.isEmpty() && nums[idx] > nums[stack.peek()]) {
            result[stack.pop()] = nums[idx];     // 找到下一个更大
        }
        stack.push(idx);
    }
    return result;
}
// [1,2,1]：
//   第 1 遍：i=0:1入栈；i=1:2>1 → 弹0,res[0]=2；i=2:1<2入栈
//   第 2 遍：i=3(idx=0):1>1?否入栈；i=4(idx=1):2>1 → 弹2,res[2]=2
//   i=5(idx=2):1<2入栈 → 结束
//   结果 [2,-1,2] ✓
```

### 4.2 为什么遍历两遍？

```
循环数组的"下一个更大"可能出现在"数组开头"：
  最后一个 1 的下一个更大是开头的 2
  → 单遍遍历看不到开头 → 需要第二遍

两遍遍历 + 取模 = 逻辑上把数组复制一份接在后面
  [1,2,1,1,2,1] 中每个元素都能找到答案 ✓
```

## 5. 单调栈模板总结

### 5.1 通用模板（求下一个更大）

```java
/**
 * 单调栈通用模板（求每个元素的下一个更大元素）
 * 关键四要素：
 *   ① 栈存下标（需要距离/位置）
 *   ② 单调方向：求更大 → 递减栈
 *   ③ 弹出时机：当前值 > 栈顶值
 *   ④ 栈底 → 栈顶 递减
 */
public int[] nextGreater(int[] nums) {
    int n = nums.length;
    int[] result = new int[n];
    Arrays.fill(result, -1);
    Deque<Integer> stack = new ArrayDeque<>();

    for (int i = 0; i < n; i++) {
        // 弹出时机：当前值比栈顶大（破坏递减）
        while (!stack.isEmpty() && nums[i] > nums[stack.peek()]) {
            int idx = stack.pop();
            result[idx] = nums[i];       // 当前值 = 栈顶的下一个更大
        }
        stack.push(i);                   // 当前下标入栈
    }
    return result;
}

// 求下一个更小：改符号即可
//   while (!stack.isEmpty() && nums[i] < nums[stack.peek()])
```

### 5.2 四个方向对照

| 问题 | 栈方向 | 弹出条件 | 代表题 |
|------|:---:|------|:---:|
| 下一个更大 | 递减 | `nums[i] > 栈顶` | 739/496 |
| 下一个更小 | 递增 | `nums[i] < 栈顶` | 901/2104 |
| 上一个更大 | 递减 | 同左（弹出时记录左侧答案） | 84 |
| 上一个更小 | 递增 | 同左 | 907 |

```
记忆：找"更大"用递减栈（栈顶最小，被更大的弹出）
     找"更小"用递增栈（栈顶最大，被更小的弹出）
```

### 5.3 面试话术

```
"这题用单调栈：
 维护一个单调递减栈，存下标。
 遍历时，当前元素比栈顶大 → 栈顶元素找到了
 它的'下一个更大' → 弹出并记录答案。
 每个元素恰好进出栈一次 → O(n)。
 暴力需要 O(n²)，单调栈是关键优化。"
```

> 🎯 **核心要点**：单调栈是"下一个更大/更小元素"的唯一 O(n) 解法——**存下标、单调递减找更大、弹出即答案**是三大铁律。739 母题推演一遍，496（哈希表配合）、503（两遍取模）是变体模板。面试必答"为什么 O(n)"（每个元素进出一次），模板 + 论证齐备就是满分。
