## 1. 20. 有效的括号

### 1.1 完整实现（面试热身第一题）

```java
/**
 * LeetCode 20. 有效的括号
 * "()[]{}" → true；"([)]" → false
 *
 * LIFO 匹配：左括号入栈，右括号与栈顶配对
 *   匹配 → 弹栈
 *   不匹配/栈空 → false
 * 最后栈必须为空
 */
public boolean isValid(String s) {
    Deque<Character> stack = new ArrayDeque<>();
    // 右括号 → 对应左括号的映射
    Map<Character, Character> map = Map.of(
        ')', '(', ']', '[', '}', '{');

    for (char c : s.toCharArray()) {
        if (c == '(' || c == '[' || c == '{') {
            stack.push(c);                    // 左括号入栈
        } else {
            if (stack.isEmpty()) return false;    // 右括号无配对
            if (stack.pop() != map.get(c)) return false;  // 不匹配
        }
    }
    return stack.isEmpty();                   // ⚠️ 栈必须空！
}
// "([)]"：'(','['入栈，')'配'['? 不匹配 → false ✓
```

### 1.2 关键细节

```
① 栈空判断：右括号来时栈空 → false（如 ")" 开头）
② 最后栈空：左括号多 → false（如 "(("）
③ 用 map 或 if-else 均可（面试写 if-else 更快）

变体：
  678. 有效的括号字符串（含 * 通配符 → DP/双栈）
  32. 最长有效括号（栈存下标 → 见 04 或动态规划体系）
```

## 2. 155. 最小栈

### 2.1 完整实现（辅助栈）

```java
/**
 * LeetCode 155. 最小栈
 * push/pop/top/getMin 全部 O(1)
 *
 * 辅助栈方案：
 *   dataStack：正常数据
 *   minStack：同步记录当前最小值
 *   push：min(x, minStack.peek()) 入辅助栈
 *   pop：两个栈同步弹
 *
 * ⚠️ 辅助栈用 <= 而不是 <：
 *   相同最小值连续 push 两次时，
 *   只存一次会导致 pop 后最小值丢失
 */
class MinStack {
    Deque<Integer> data = new ArrayDeque<>();
    Deque<Integer> min = new ArrayDeque<>();

    public void push(int val) {
        data.push(val);
        // 辅助栈存当前最小值（<= 保证重复值不丢失）
        min.push(min.isEmpty() ? val : Math.min(val, min.peek()));
    }

    public void pop() {
        data.pop();
        min.pop();                    // 同步弹
    }

    public int top() {
        return data.peek();
    }

    public int getMin() {
        return min.peek();            // 栈顶即当前最小值
    }
}
// 推演：push 2, push 3, push 2, push 1
// data: [2,3,2,1]  min: [2,2,2,1]
// pop → data:[2,3,2] min:[2,2,2] → getMin=2 ✓（没丢！）
```

### 2.2 为什么用 <= 不用 <？

```
push 2, push 2, push 2 后 pop 两次：
  < 版本：min = [2]（只存一次）→ 两次 pop 后 min 空！
  <= 版本：min = [2,2,2] → 三次 pop 后 min 空
  → <= 保证每个重复最小值都有对应记录
```

### 2.3 变体

```
辅助栈：O(n) 空间
差值法：存 val - min，O(1) 空间（面试加分）
  栈里存差值，min 单独维护
  push: diff = val - min；diff < 0 → min = val
  pop: 栈顶 < 0 → min 恢复 = min - 栈顶
```

## 3. 232. 用栈实现队列

### 3.1 完整实现（双栈倒腾）

```java
/**
 * LeetCode 232. 用栈实现队列
 * 双栈倒腾：
 *   in 栈：入队时 push
 *   out 栈：出队时把 in 全部倒过来 pop
 *
 * 均摊 O(1)：每个元素最多倒腾两次（进 in、倒 out）
 */
class MyQueue {
    Deque<Integer> in = new ArrayDeque<>();    // 入队栈
    Deque<Integer> out = new ArrayDeque<>();   // 出队栈

    public void push(int x) {
        in.push(x);                            // 直接入 in
    }

    public int pop() {
        moveIfNeeded();                        // 确保 out 有数据
        return out.pop();
    }

    public int peek() {
        moveIfNeeded();
        return out.peek();
    }

    public boolean empty() {
        return in.isEmpty() && out.isEmpty();
    }

    // 关键：out 空时把 in 全部倒过来
    private void moveIfNeeded() {
        if (out.isEmpty()) {
            while (!in.isEmpty()) {
                out.push(in.pop());            // 倒腾（逆序变正序）
            }
        }
    }
}
// push 1,2,3 → in:[1,2,3]
// pop → out 空 → 倒腾 in→out：[3,2,1] → out.pop()=1 ✓ FIFO！
```

### 3.2 均摊 O(1) 证明

```
每个元素经历的操作：
  ① push 进 in：1 次
  ② 倒腾到 out：1 次
  ③ 从 out 弹出：1 次
  → 每个元素恒定 3 次操作 → 均摊 O(1) ✓

变体：225. 用队列实现栈
  单队列 + 每次 push 后把前面的重新入队
```

## 4. 150. 逆波兰表达式求值

### 4.1 完整实现

```java
/**
 * LeetCode 150. 逆波兰表达式（后缀表达式）
 * ["2","1","+","3","*"] → (2+1)×3 = 9
 *
 * 后缀表达式天然栈结构：
 *   数字 → 入栈
 *   运算符 → 弹两个数计算，结果入栈
 *   结束时栈顶 = 答案
 */
public int evalRPN(String[] tokens) {
    Deque<Integer> stack = new ArrayDeque<>();

    for (String token : tokens) {
        switch (token) {
            case "+" -> {
                int b = stack.pop(), a = stack.pop();
                stack.push(a + b);
            }
            case "-" -> {
                int b = stack.pop(), a = stack.pop();
                stack.push(a - b);            // ⚠️ a-b 不是 b-a！
            }
            case "*" -> {
                int b = stack.pop(), a = stack.pop();
                stack.push(a * b);
            }
            case "/" -> {
                int b = stack.pop(), a = stack.pop();
                stack.push(a / b);            // ⚠️ 先弹的是 b
            }
            default -> stack.push(Integer.parseInt(token));
        }
    }
    return stack.peek();
}
```

### 4.2 为什么"先弹出的是 b"？

```
表达式 "3 4 -"：3 - 4 = -1
  先弹 b=4（后入栈的），后弹 a=3（先入栈的）
  → 计算 a - b = 3 - 4 = -1 ✓
  （栈顶是最近的数 → 顺序反了 → 必须注意谁在前）

变体：224. 基本计算器（中缀转后缀或用栈直接算）
     227. 基本计算器 II
```

## 5. 71. 简化路径

### 5.1 完整实现

```java
/**
 * LeetCode 71. 简化路径（Unix 风格）
 * "/a/./b/../../c/" → "/c"
 *
 * 用 "/" 分割后处理各段：
 *   "."  → 忽略（当前目录）
 *   ".." → 弹栈（上一级）
 *   其他 → 入栈（目录名）
 */
public String simplifyPath(String path) {
    Deque<String> stack = new ArrayDeque<>();

    for (String part : path.split("/")) {
        if (part.isEmpty() || part.equals(".")) {
            continue;                 // 空段和当前目录忽略
        }
        if (part.equals("..")) {
            if (!stack.isEmpty()) stack.pop();   // 返回上一级
        } else {
            stack.push(part);         // 目录入栈
        }
    }

    // 拼接结果（栈底 → 栈顶 = 路径顺序）
    StringBuilder sb = new StringBuilder();
    for (String dir : stack) {        // ⚠️ 迭代 Deque 从栈底到栈顶
        sb.insert(0, "/" + dir);      // 或倒序拼接
    }
    return sb.isEmpty() ? "/" : sb.toString();
}
```

### 5.2 关键点

```
① split("/")：空段（连续 //）要忽略
② ".." 弹栈：栈空时忽略（路径已经在根）
③ 拼接顺序：先入栈的在前面（注意迭代方向）
```

## 6. 栈应用总结

### 6.1 栈题解耦框架

```
拿到"栈相关"题 → 问：
  ① 有"最近配对"吗？→ LIFO 匹配（20）
  ② 需要"同步辅助信息"？→ 辅助栈（155）
  ③ 需要"逆序还原"？→ 双栈倒腾（232）
  ④ 有"优先级/嵌套"？→ 表达式栈（150）
  ⑤ 有"路径/层级"？→ 栈模拟（71）
```

### 6.2 高频追问

| 追问 | 标准回答 |
|------|------|
| 为什么用 ArrayDeque 不用 Stack？ | Stack 继承 Vector 全方法加锁性能差，ArrayDeque 无锁数组实现更快 |
| 辅助栈为什么用 <=？ | 相同最小值重复 push 时只存一次，pop 后会丢失最小值 |
| 双栈队列为什么均摊 O(1)？ | 每个元素恒定 3 次操作（push/倒腾/pop） |
| 逆波兰为什么先弹的是 b？ | 栈顶是后入栈的数，表达式顺序 a op b 中 a 先入栈 |

> 🎯 **核心要点**：栈的五大经典应用——**括号匹配**（LIFO 最近配对）、**最小栈**（辅助栈同步最小值，<= 防丢失）、**栈实现队列**（双栈倒腾均摊 O(1)）、**逆波兰**（弹两个算一个，注意 a/b 顺序）、**简化路径**（分段处理）。每个都有 1-2 个面试官爱挖的细节，背熟即可稳拿分。
