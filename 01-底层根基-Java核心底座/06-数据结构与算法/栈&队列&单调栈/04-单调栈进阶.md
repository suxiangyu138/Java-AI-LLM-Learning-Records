## 1. 单调栈的进阶视角：区间边界

### 1.1 新视角：找到"左右边界"

```
基础视角：找下一个更大/更小元素（739）
进阶视角：找每个元素作为"边界"的左右范围（84/907）

以 84 题为例：
  每个柱子 h[i] 作为矩形高度时
  左边界 = 左边第一个比 h[i] 矮的柱子
  右边界 = 右边第一个比 h[i] 矮的柱子
  → 最大宽度 = 右边界 - 左边界 - 1

单调栈可以 O(n) 求出每个元素的"左右第一个更小/更大"！
```

### 1.2 一次遍历得到两侧边界

```
单调递增栈弹出时：
  弹出元素 = 当前柱子（右边界确定了）
  弹出后的新栈顶 = 左边界（左边第一个更矮的）
  当前柱子 = 右边界（右边第一个更矮的）

弹出时机 = 三方会合：
  栈顶（当前处理）| 弹出后栈顶（左侧边界）| 当前元素（右侧边界）
```

## 2. 84. 柱状图中最大的矩形

### 2.1 完整实现（单调递增栈 + 哨兵）

```java
/**
 * LeetCode 84. 柱状图中最大的矩形（Hard 经典）
 * heights = [2,1,5,6,2,3] → 最大矩形面积 10（5×2）
 *
 * 思路：每个柱子作为矩形高度，找左右第一个更矮的
 *   左边界 = 左边第一个更矮（栈中下一个）
 *   右边界 = 当前遇到的更矮柱子
 *   面积 = h × (右边界 - 左边界 - 1)
 *
 * ⚠️ 哨兵优化：数组首尾各补一个 0
 *   头部 0：避免栈空判断
 *   尾部 0：强制弹出所有元素（否则栈中残留无法计算）
 */
public int largestRectangleArea(int[] heights) {
    int n = heights.length;
    // 复制 + 首尾补 0
    int[] h = new int[n + 2];
    System.arraycopy(heights, 0, h, 1, n);

    Deque<Integer> stack = new ArrayDeque<>();
    int maxArea = 0;

    for (int i = 0; i < h.length; i++) {
        // 递增栈：遇到更矮的 → 弹出计算面积
        while (!stack.isEmpty() && h[i] < h[stack.peek()]) {
            int height = h[stack.pop()];       // 当前柱子高度
            int left = stack.peek();           // 左边界（新栈顶）
            int right = i;                     // 右边界（当前更矮）
            int width = right - left - 1;      // 宽度
            maxArea = Math.max(maxArea, height * width);
        }
        stack.push(i);
    }
    return maxArea;
}
// [2,1,5,6,2,3] → 哨兵版 [0,2,1,5,6,2,3,0]
// 面积计算：h=2: left=0(0), right=2(1) → 2×1=2
//          h=5: left=2(1), right=5(2) → 5×3=15... 取最大 10 ✓
```

### 2.2 为什么补哨兵？

```
尾部 0 的作用：
  栈中残留的柱子没有"更矮的"来触发弹出
  补 0 → 强制弹出所有元素 → 全部计算面积

头部 0 的作用：
  弹出后栈永不空 → 免去栈空判断
  （左边界恒存在）

记忆："首尾补 0，栈不空，不残留"
```

### 2.3 推演核心逻辑

```
[0,2,1,5,6,2,3,0]（哨兵版）
i=1(2): 入栈 [0,1]
i=2(1): 1<2 → 弹1(h=2), left=0(0), right=2 → 面积 2×1=2；入栈 [0,2]
i=3(5): 入栈 [0,2,3]
i=4(6): 入栈 [0,2,3,4]
i=5(2): 2<6 → 弹4(h=6), left=3, right=5 → 6×1=6
         2<5 → 弹3(h=5), left=2, right=5 → 5×2=10 ✓
         入栈 [0,2,5]
i=6(3): 3>2 → 入栈 [0,2,5,6]
i=7(0): 0<3 → 弹6(h=3), left=5, right=7 → 3×1=3
         0<2 → 弹5(h=2), left=2, right=7 → 2×4=8
         0<1 → 弹2(h=1), left=0, right=7 → 1×6=6
最大 = 10 ✓
```

## 3. 42. 接雨水：单调栈解法

### 3.1 完整实现（递减栈找凹槽）

```java
/**
 * LeetCode 42. 接雨水（单调栈版）
 * 单调递减栈：找"凹槽"（左右壁 + 底部）
 *
 * 弹出时形成凹槽：
 *   栈顶 = 凹槽底部（弹出）
 *   新栈顶 = 左壁（如果存在）
 *   当前 = 右壁
 *   水量 = (min(左壁,右壁) - 底部) × (右-左-1)
 *
 * 与双指针版区别：
 *   双指针：按"列"计算每格水量
 *   单调栈：按"层"计算每个凹槽水量
 */
public int trap(int[] height) {
    Deque<Integer> stack = new ArrayDeque<>();
    int water = 0;

    for (int i = 0; i < height.length; i++) {
        // 递减栈：当前比栈顶高 → 形成凹槽右壁
        while (!stack.isEmpty() && height[i] > height[stack.peek()]) {
            int bottom = stack.pop();          // 凹槽底部
            if (stack.isEmpty()) break;        // 无左壁 → 装不了水

            int left = stack.peek();           // 左壁
            int h = Math.min(height[left], height[i]) - height[bottom];
            int w = i - left - 1;              // 宽度
            water += h * w;                    // 这个凹槽的水
        }
        stack.push(i);
    }
    return water;
}
// [0,1,0,2,1,0,1,3,2,1,2,1] → 6 ✓
```

### 3.2 三种解法对比（接雨水）

| 解法 | 时间 | 空间 | 思路 |
|------|:---:|:---:|------|
| 暴力 | O(n²) | O(1) | 每格扫左右最高 |
| 双指针 | O(n) | O(1) | 按列计算，矮边确定 |
| **单调栈** | O(n) | O(n) | 按层计算凹槽 |

```
面试完整展示：
"接雨水有三种解法，我讲最优的双指针 O(n)/O(1)；
 单调栈版是按层计算凹槽——递减栈弹栈时
 栈顶是底部、新栈顶是左壁、当前是右壁。"
```

## 4. 907. 子数组的最小值之和

### 4.1 完整实现（贡献法 + 单调栈）

```java
/**
 * LeetCode 907. 子数组的最小值之和（Hard 进阶）
 * 所有子数组的最小值之和
 * [3,1,2,4] → 3+1+2+4 + 1+2+1 + 1+1 + 1 = 17
 *
 * 贡献法：
 *   每个元素作为"最小值"贡献给多少个子数组？
 *   左边界：左边第一个更小的位置（严格小于）
 *   右边界：右边第一个更小的位置（小于等于）
 *   → 贡献 = val × (i - left) × (right - i)
 *
 * ⚠️ 边界去重：左严格小于 + 右小于等于
 *   （避免重复计算相等元素）
 */
public int sumSubarrayMins(int[] arr) {
    int n = arr.length;
    int MOD = 1_000_000_007;

    int[] left = new int[n];      // 左边第一个更小（距离）
    int[] right = new int[n];     // 右边第一个更小（距离）
    Deque<Integer> stack = new ArrayDeque<>();

    // 左边界：严格小于（用 >= 弹栈）
    for (int i = 0; i < n; i++) {
        while (!stack.isEmpty() && arr[stack.peek()] >= arr[i]) {
            stack.pop();
        }
        left[i] = stack.isEmpty() ? i + 1 : i - stack.peek();
        stack.push(i);
    }

    stack.clear();
    // 右边界：小于等于（用 > 弹栈）
    for (int i = n - 1; i >= 0; i--) {
        while (!stack.isEmpty() && arr[stack.peek()] > arr[i]) {
            stack.pop();
        }
        right[i] = stack.isEmpty() ? n - i : stack.peek() - i;
        stack.push(i);
    }

    // 贡献求和
    long sum = 0;
    for (int i = 0; i < n; i++) {
        sum = (sum + (long) arr[i] * left[i] % MOD * right[i]) % MOD;
    }
    return (int) sum;
}
```

### 4.2 边界处理的意义

```
为什么左严格小、右小于等于？
  [2,2] 的重复元素去重：
  如果两边都"小于"→ 每个 2 都认为自己是 4 个子数组的最小
  → 重复计数！
  一边严格、一边宽松 → 每个子数组只被"最左的最小值"计算
  → 不重不漏 ✓
```

## 5. 单调栈应用总结

### 5.1 单调栈题型图谱

| 题号 | 题目 | 单调栈用途 | 难度 |
|:---:|------|------|:---:|
| 739 | 每日温度 | 下一个更大（距离） | 🟡 |
| 496 | 下一个更大 I | 预处理+查表 | 🟢 |
| 503 | 下一个更大 II | 循环数组 | 🟡 |
| 84 | 最大矩形 | 左右更小边界 | 🔴 |
| 42 | 接雨水 | 凹槽左右壁 | 🔴 |
| 907 | 子数组最小值 | 贡献法左右边界 | 🔴 |
| 901 | 股票价格跨度 | 上一个更大 | 🟡 |
| 316 | 去除重复字母 | 字典序最小 | 🟡 |

### 5.2 三种应用模式

```
模式一：下一个更大/更小（739/496/503）
  弹出时记录答案 → 单向信息

模式二：区间边界（84/907）
  弹出时三方会合（底部/左边界/右边界）
  → 双向信息

模式三：贪心维护（316 去重字母）
  弹出保证字典序最小（类似单调栈思路）
```

### 5.3 面试话术

```
"这题的核心是把问题转化为'找左右边界'：
 每个柱子作为高度时，左边界是左边第一个更矮的，
 右边界是右边第一个更矮的。
 单调递增栈弹出时正好三方会合——
 弹出的元素是当前柱子，新栈顶是左边界，
 当前元素是右边界。
 首尾补 0 简化边界处理。
 每个元素进出一次 → O(n)。"
```

> 🎯 **核心要点**：单调栈进阶的两个 Hard 经典——**84 最大矩形**（递增栈 + 首尾补 0 + 三方会合）、**42 接雨水**（递减栈找凹槽按层计算）。907 的贡献法展示了单调栈的第三层应用（左右边界 + 数学计数）。记忆"弹出即计算，三方会合定边界，首尾补 0 简化"三句话，Hard 单调栈题有章可循。
