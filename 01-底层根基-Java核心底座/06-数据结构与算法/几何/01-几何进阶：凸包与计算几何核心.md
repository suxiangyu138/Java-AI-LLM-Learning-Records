## 1. 向量基础：叉积与点积

### 1.1 两个核心运算

```
点积（内积）：a·b = ax·bx + ay·by = |a||b|cosθ
  用途：判断角度（>0 锐角 / <0 钝角 / =0 垂直）
  投影计算

叉积（外积）：a×b = ax·by - ay·bx（标量，z 方向大小）
  用途：
    > 0：b 在 a 的逆时针方向
    < 0：b 在 a 的顺时针方向
    = 0：共线
  三角形面积 = |a×b| / 2

⚠️ 叉积是计算几何的"瑞士军刀"：
  转向判断、点在直线哪侧、凸包、线段相交全用它
```

```java
/** 叉积：向量 a→b 与 a→c 的转向（cross(b-a, c-a)） */
long cross(long ax, long ay, long bx, long by) {
    return ax * by - ay * bx;
}
// > 0：c 在 a→b 的逆时针；< 0：顺时针；= 0：共线
// ⚠️ 注意用 long（坐标差可达 2×10⁴，相乘 4×10⁸ 安全）
//   坐标更大时用 long 乘法防溢出
```

### 1.2 点与直线/线段的关系

```
点在直线 AB 的哪一侧：
  cross(B-A, P-A) > 0 → 左侧；< 0 → 右侧；= 0 → 直线上

点到直线距离：
  |cross(B-A, P-A)| / |AB|

⚠️ 面试表达：
"叉积回答三个问题——转向（左右）、共线（=0）、
 面积（绝对值/2）。计算几何 90% 的题围绕叉积展开。"
```

## 2. 凸包：Andrew 单调链

### 2.1 凸包定义与算法选型

```
凸包：包含所有点的最小凸多边形（橡皮筋效果）

算法：
  Graham 扫描：极角排序 + 栈（O(n log n)）
  Andrew 单调链：按 x 排序 + 上下链（O(n log n)）⭐ 推荐
    ⚠️ 优点：不用极角（避免浮点/atan2），只用整数叉积
```

### 2.2 完整实现（Andrew 单调链）

```java
/**
 * LeetCode 587. 安装栅栏（凸包）
 * Andrew 单调链：排序 → 下链 → 上链
 * ⚠️ 全程整数叉积（无浮点误差）
 */
public int[][] outerTrees(int[][] trees) {
    // ① 按 (x, y) 字典序排序
    Arrays.sort(trees, (a, b) -> a[0] != b[0] ? a[0] - b[0] : a[1] - b[1]);
    int n = trees.length;

    // ② 单调栈维护凸包（下链 + 上链）
    int[] stack = new int[2 * n];
    int top = 0;

    for (int[] p : trees) {                      // 下链（从左到右）
        while (top >= 2 && cross(stack, trees, top, p) < 0) top--;   // ⚠️ 逆时针不满足则弹出
        stack[top++] = idx(p, trees);
    }
    // 上链（从右到左）——复用同一栈
    int lowerSize = top;
    for (int i = n - 2; i >= 0; i--) {           // ⚠️ 跳过已处理的最后一个点
        while (top > lowerSize && cross(stack, trees, top, p) < 0) top--;
        stack[top++] = i;
    }
    // 去重（首尾重复）
    ...
}
// ⚠️ 叉积判转向（伪代码核心）：
//   cross = (x2-x1)(y3-y1) - (y2-y1)(x3-x1)
//   cross < 0 → 右转 → 凹点弹出
//   cross >= 0 → 保留（含共线，LeetCode 587 要求包含边界点）
// 复杂度：O(n log n)（排序主导），栈操作 O(n)
```

### 2.3 凸包的应用

```
① 最大距离点对（旋转卡壳，见第 6 节）
② 点集的最小包围
③ 碰撞检测（凸多边形相交）
④ 线性回归的边界（感知机几何意义）

⚠️ 面试表达：
"凸包是计算几何的'预处理'——把点集压缩成
 边界点集。Andrew 单调链用字典序排序 + 叉积
 判断转向，全程整数运算无精度问题。"
```

## 3. 线段相交：跨立实验

### 3.1 判断方法

```
两线段 AB 与 CD 相交 ⟺
  ① 快速排斥：A/B 的包围盒与 C/D 的包围盒相交
  ② 跨立实验：A、B 在 CD 两侧（或线上）且 C、D 在 AB 两侧

⚠️ 快速排斥的意义：
  先排除"显然不相交"（包围盒无重叠）→ 减少叉积计算

⚠️ 跨立的边界：
  叉积 = 0（共线/端点重合）→ 需要特判"点在线段上"
```

```java
/** 跨立实验（核心判断） */
boolean intersect(int ax, int ay, int bx, int by,
                  int cx, int cy, int dx, int dy) {
    // ① 快速排斥（包围盒不相交 → 直接 false）
    if (Math.max(ax, bx) < Math.min(cx, dx) ||
        Math.max(cx, dx) < Math.min(ax, bx) ||
        Math.max(ay, by) < Math.min(cy, dy) ||
        Math.max(cy, dy) < Math.min(ay, by)) return false;

    // ② 跨立：C、D 分居 AB 两侧
    long c1 = cross(bx - ax, by - ay, cx - ax, cy - ay);
    long c2 = cross(bx - ax, by - ay, dx - ax, dy - ay);
    long c3 = cross(dx - cx, dy - cy, ax - cx, ay - cy);
    long c4 = cross(dx - cx, dy - cy, bx - cx, by - cy);
    return c1 * c2 <= 0 && c3 * c4 <= 0;    // ⚠️ ≤ 0 含共线（端点在线上也算）
}
// 应用：图形裁剪、地图道路相交检测、游戏碰撞
```

## 4. 最近点对：分治 O(n log n)

### 4.1 算法流程

```
最近点对（经典分治）：
  ① 按 x 排序 → 中线分成左右
  ② 递归求左右最近距离 d
  ③ 跨中线：只查"距中线 < d"的带状区（最多 6 个点需比较）
     ⚠️ 理论保证：带内每点只需与后续 6 个点比较（鸽巢原理）

复杂度论证：
  T(n) = 2T(n/2) + O(n)（排序后每层合并 O(n)）
  → O(n log n)
```

### 4.2 实现要点

```java
/** 最近点对（分治，返回最小距离） */
double closestPair(int[][] points) {
    Arrays.sort(points, (a, b) -> a[0] - b[0]);    // ① 按 x 排序
    return dc(points, 0, points.length - 1);
}

double dc(int[][] p, int lo, int hi) {
    if (hi - lo <= 2) return bruteForce(p, lo, hi);  // ⚠️ 小规模暴力

    int mid = (lo + hi) / 2;
    double d = Math.min(dc(p, lo, mid), dc(p, mid + 1, hi));  // ② 递归

    // ③ 跨中线：收集 |x - midX| < d 的点，按 y 排序，比较相邻
    List<int[]> strip = new ArrayList<>();
    for (int i = lo; i <= hi; i++)
        if (Math.abs(p[i][0] - p[mid][0]) < d) strip.add(p[i]);
    strip.sort((a, b) -> a[1] - b[1]);
    for (int i = 0; i < strip.size(); i++)
        for (int j = i + 1; j < strip.size() && strip.get(j)[1] - strip.get(i)[1] < d; j++)
            d = Math.min(d, dist(strip.get(i), strip.get(j)));   // ⚠️ 每点最多 6 次
    return d;
}
// ⚠️ 6 点上限的直觉：边长为 d 的正方形最多放 6 个
//   互相距离 ≥ d 的点（鸽巢原理/抽屉）
// ⚠️ 面试表达："跨中线区域按 y 排序后，
//   每点只需比较后续 6 个——这是 O(n) 合并且
//   总 O(n log n) 的数学保证。"
```

## 5. 多边形面积：鞋带公式

### 5.1 公式

```
顶点按顺序 (x0,y0), (x1,y1), ..., (xn-1,yn-1)：
  2S = |Σ (xi·yi+1 - xi+1·yi)|     （下标循环）

本质：叉积之和（每边与原点构成的有向三角形）
  绝对值 → 面积；符号 → 方向（正=逆时针）

⚠️ 应用：
  任意多边形面积（凸/凹均可！）
  判断顶点顺序方向（正负号）
  网格多边形面积（Pick 定理配合）
```

```java
/** 鞋带公式（多边形面积 ×2） */
long shoelace(long[] x, long[] y) {
    int n = x.length;
    long sum = 0;
    for (int i = 0; i < n; i++) {
        int j = (i + 1) % n;
        sum += x[i] * y[j] - x[j] * y[i];      // ⚠️ 循环下标
    }
    return Math.abs(sum);                       // 2×面积
}
// 例：正方形 (0,0)(1,0)(1,1)(0,1)：
//   sum = 0·0-1·0 + 1·1-1·0 + 1·1-0·1 + 0·0-0·1 = 2 → 面积 1 ✓
```

### 5.2 应用场景

| 场景 | 做法 |
|------|------|
| 多边形面积 | 鞋带公式 O(n) |
| 顶点顺序方向 | 符号判断（正=逆时针） |
| 点在多边形内 | 射线法 / 叉积（凸多边形） |
| 凸多边形判定 | 所有连续边同方向 |

## 6. 旋转卡壳与进阶几何

### 6.1 旋转卡壳（Rotating Calipers）

```
问题：凸多边形直径（最远点对）——暴力 O(n²)
旋转卡壳：O(n) 扫描（双指针随边旋转）
  核心性质：对每条边，最远点随边旋转单调移动

⚠️ 应用：
  凸多边形直径、最远点对、最小包围矩形、
  两凸多边形最近距离

⚠️ 面试定位：知道"凸包 + 旋转卡壳 = 直径 O(n log n)"
  即可；手写旋转卡壳属于竞赛级
```

### 6.2 常见几何模型汇总

| 模型 | 核心工具 | 复杂度 |
|------|---------|:---:|
| 点在直线哪侧 | 叉积 | O(1) |
| 线段相交 | 快速排斥 + 跨立 | O(1) |
| 凸包 | Andrew 单调链 | O(n log n) |
| 最近点对 | 分治 + 带状区 | O(n log n) |
| 多边形面积 | 鞋带公式 | O(n) |
| 点在凸多边形内 | 叉积/二分 | O(log n) |
| 直径 | 凸包 + 旋转卡壳 | O(n log n) |

## 7. 几何的浮点与整数策略

### 7.1 精度问题的三类场景

```
① 斜率作哈希键：1/3 与 2/6 的 double 可能不同
   → 最简分数（gcd 约分）整数键（149 题解法）
② 比较相等：0.1+0.2 ≠ 0.3
   → 交叉相乘 / 容差比较
③ 平方根：√(x²+y²) 比较
   → 用平方比较（省 sqrt + 无精度损失）

⚠️ 铁律：能整数就不浮点；能平方就不开方；能交叉乘就不除法
```

### 7.2 整数的正确姿势

```java
// 斜率比较：用最简分数（整数对）
//   判断 a/b == c/d → a·d == b·c（交叉相乘，无浮点）
// 距离比较：dist² 比较（不开方）
// 面积比较：2S 整数比较（不用除以 2）

// ⚠️ 溢出：坐标 10⁴ → 叉积 10⁸，平方 10¹⁶
//   用 long（Java int 不够）
```

### 8.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| double 斜率作键 | 精度错 | 最简分数 |
