## 1. 149. 直线上最多的点数

### 1.1 题目与思路

```
最多多少个点在同一直线上（hard）
固定点 + 斜率计数：
  对每个点 i，计算到其他点的斜率 → 相同斜率计数值最大
⚠️ 斜率精度问题：double 斜率不可靠（1/3 vs 2/6）
   → 最简分数对（dx/g, dy/g）作键（整数，无精度问题）
⚠️ 特判：垂直（dx=0）、重复点
```

### 1.2 完整代码

```java
/**
 * LeetCode 149. 直线上最多的点数
 * ⚠️ 斜率用"最简分数对"作键（dx/g, dy/g）——整数零误差
 */
public int maxPoints(int[][] points) {
    int n = points.length;
    if (n <= 2) return n;

    int best = 0;
    for (int i = 0; i < n; i++) {
        Map<Long, Integer> count = new HashMap<>();
        int same = 1, vertical = 0;                 // 重复点 + 垂直线

        for (int j = i + 1; j < n; j++) {
            int dx = points[j][0] - points[i][0];
            int dy = points[j][1] - points[i][1];
            if (dx == 0 && dy == 0) { same++; continue; }   // ⚠️ 重复点

            if (dx == 0) { vertical++; continue; }          // 垂直线单独记

            int g = gcd(Math.abs(dx), Math.abs(dy));        // ⚠️ 约分
            dx /= g; dy /= g;
            if (dx < 0) { dx = -dx; dy = -dy; }             // ⚠️ 归一化方向

            long key = (long) dx << 32 | dy;                // 分数对编码
            count.merge(key, 1, Integer::sum);
        }
        int maxSlope = vertical;
        for (int v : count.values()) maxSlope = Math.max(maxSlope, v);
        best = Math.max(best, maxSlope + same);             // ⚠️ +重复点
    }
    return best;
}
// 推演 [[1,1],[2,2],[3,3]]：i=0：dx=1,dy=1 → key(1,1) 计数 2
//   → maxSlope=2, same=1 → 2+1=3 ✓
// ⚠️ 复杂度：O(n²)（固定点 × 扫描其余）
// ⚠️ 面试表达："斜率不能存 double（1/3 与 2/6 浮点可能不同），
//   存最简分数对 (dx/g, dy/g)——gcd 约分后唯一。"
```

## 2. 587. 安装栅栏（凸包完整实现）

### 2.1 题目与思路

```
凸包（全部边界点，含共线点）——Andrew 单调链完整版
⚠️ LeetCode 587 特殊：要求返回"所有边界点"（含边上的点）
   → 弹出条件用 cross < 0（保留共线 cross = 0）
```

### 2.2 完整代码

```java
/**
 * LeetCode 587. 安装栅栏（Andrew 单调链完整实现）
 */
public int[][] outerTrees(int[][] trees) {
    int n = trees.length;
    if (n <= 1) return trees;

    Arrays.sort(trees, (a, b) -> a[0] != b[0] ? a[0] - b[0] : a[1] - b[1]);

    List<int[]> hull = new ArrayList<>();

    // 下链：从左到右
    for (int[] p : trees) {
        while (hull.size() >= 2 &&
               cross(hull.get(hull.size() - 2), hull.get(hull.size() - 1), p) < 0) {
            hull.remove(hull.size() - 1);        // ⚠️ 右转 → 弹出（凹点）
        }
        hull.add(p);
    }
    // 上链：从右到左
    int lowerSize = hull.size();
    for (int i = n - 2; i >= 0; i--) {
        int[] p = trees[i];
        while (hull.size() > lowerSize &&
               cross(hull.get(hull.size() - 2), hull.get(hull.size() - 1), p) < 0) {
            hull.remove(hull.size() - 1);
        }
        hull.add(p);
    }
    hull.remove(hull.size() - 1);                // ⚠️ 首尾重复，去重

    return hull.toArray(new int[0][]);
}

/** 叉积：向量 oa 与 ob 的转向 */
private int cross(int[] o, int[] a, int[] b) {
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0]);
}
// 推演 [[1,1],[2,2],[2,0],[2,4],[3,3],[4,2]]：
//   排序后下链：1,1 → 2,0 → 2,2 → 2,4 → 3,3 → 4,2 维护逆时针
//   最终凸包：[[1,1],[2,0],[4,2],[3,3],[2,4]]（含共线点）✓
// ⚠️ 要点：cross < 0 弹出（保留共线 → 587 要求含边界点）
//   标准凸包（不含边）用 cross <= 0
```

## 3. 478. 在圆内随机生成点

### 3.1 题目与思路

```
在半径 r 的圆内均匀随机生成点
两种方法：
  ① 拒绝采样：正方形采样 → 圆内接受（简单，接受率 π/4 ≈ 78.5%）
  ② 极坐标法 ⚠️ 有坑：r 必须用 √u 均匀采样（否则中心密集）
```

### 3.2 完整代码（极坐标正确版 + 拒绝采样版）

```java
/**
 * LeetCode 478. 在圆内随机生成点
 * ⚠️ 极坐标陷阱：半径必须用 sqrt(random) 才能均匀！
 *   （否则面积分布不均匀——半径小处概率密度高）
 */
class Solution {
    private final double r, x0, y0;
    private final Random rand = new Random();

    /** 方法一：极坐标（正确均匀） */
    public double[] randPoint() {
        double angle = rand.nextDouble() * 2 * Math.PI;      // 角度均匀
        double radius = r * Math.sqrt(rand.nextDouble());    // ⚠️ 半径 √u！
        return new double[]{
                x0 + radius * Math.cos(angle),
                y0 + radius * Math.sin(angle)};
    }

    /** 方法二：拒绝采样 */
    public double[] randPointReject() {
        while (true) {
            double x = x0 + (rand.nextDouble() * 2 - 1) * r; // 正方形内
            double y = y0 + (rand.nextDouble() * 2 - 1) * r;
            if (Math.pow(x - x0, 2) + Math.pow(y - y0, 2) <= r * r)
                return new double[]{x, y};                    // 圆内接受
        }
    }
}
// ⚠️ 为什么半径要 √u：
//   面积 ∝ r² → 半径 r 处累积概率 = r²/R² → 反函数 r = R·√u
//   直接 u·R → 内圈密度大（圆环面积小但样本一样多）
// ⚠️ 拒绝采样接受率 = π/4 ≈ 78.5%，期望重试 1.27 次
```

> 🎯 **要点**：圆内均匀采样的两大陷阱——极坐标要 √u、拒绝采样要检查边界。面试常见追问："为什么直接乘 random 不均匀？"（答：面积与半径平方成正比）。

## 4. 836. 矩形重叠

### 4.1 题目与思路

```
两个矩形（左下角 + 右上角）是否重叠（边界相接不算重叠）
投影法：x 轴与 y 轴投影都相交 ⟺ 矩形重叠
  ⚠️ 边界不算重叠 → 严格小于（开区间）
```

### 4.2 完整代码

```java
/**
 * LeetCode 836. 矩形重叠
 * ⚠️ 投影相交：rec1.x1 < rec2.x2 && rec2.x1 < rec1.x2（严格）
 */
public boolean isRectangleOverlap(int[] rec1, int[] rec2) {
    // x 投影：[x1, x2) 与 [x3, x4) 相交
    boolean xOverlap = rec1[0] < rec2[2] && rec2[0] < rec1[2];
    // y 投影同理
    boolean yOverlap = rec1[1] < rec2[3] && rec2[1] < rec1[3];
    return xOverlap && yOverlap;
}
// 推演 rec1=[0,0,2,2], rec2=[1,1,3,3]：
//   x：0 < 3 ✓ && 1 < 2 ✓ → 相交；y 同理 → true ✓
// 推演 rec1=[0,0,1,1], rec2=[1,0,2,1]：
//   x：0 < 2 ✓ 但 1 < 1 ✗ → false（边界相接不算）✓
// ⚠️ 记忆：两个区间 [a,b) [c,d) 相交 ⟺ a < d && c < b（严格）
```

## 5. 223. 矩形面积

### 5.1 题目与思路

```
两矩形覆盖的总面积 = 面积和 - 重叠面积
重叠面积 = 投影交集长度 × 投影交集宽度（无重叠则 0）
⚠️ 面积可能溢出 int → long
```

### 5.2 完整代码

```java
/**
 * LeetCode 223. 矩形面积
 */
public int computeArea(int ax1, int ay1, int ax2, int ay2,
                       int bx1, int by1, int bx2, int by2) {
    long area1 = (long) (ax2 - ax1) * (ay2 - ay1);      // ⚠️ long 防溢出
    long area2 = (long) (bx2 - bx1) * (by2 - by1);

    // 重叠区域的宽高（投影交集长度）
    long overlapW = Math.max(0, Math.min(ax2, bx2) - Math.max(ax1, bx1));
    long overlapH = Math.max(0, Math.min(ay2, by2) - Math.max(ay1, by1));

    return (int) (area1 + area2 - overlapW * overlapH);   // 容斥
}
// 推演 rec1=[-3,0,3,4], rec2=[0,-1,9,2]：
//   area1 = 6×4 = 24；area2 = 9×3 = 27
//   重叠宽 = min(3,9) - max(-3,0) = 3 - 0 = 3
//   重叠高 = min(4,2) - max(0,-1) = 2 - 0 = 2 → 重叠 6
//   总面积 = 24+27-6 = 45 ✓
// ⚠️ 公式记忆："交集区间长度 = min(右) - max(左)，负则取 0"
```

## 6. 593. 有效的正方形

### 6.1 题目与思路

```
四个点能否构成正方形
距离验证法：
  四点的 6 条距离（两两）排序后：
  4 条边相等 + 2 条对角线相等，且 边² × 2 = 对角线²
⚠️ 用平方距离（整数运算），且要排除"四点重合/退化"
```

### 6.2 完整代码

```java
/**
 * LeetCode 593. 有效的正方形
 * ⚠️ 六距离排序：4 边相等 + 2 对角线相等 + 勾股关系
 */
public boolean validSquare(int[] p1, int[] p2, int[] p3, int[] p4) {
    long[] d = new long[6];
    d[0] = dist(p1, p2); d[1] = dist(p1, p3); d[2] = dist(p1, p4);
    d[3] = dist(p2, p3); d[4] = dist(p2, p4); d[5] = dist(p3, p4);
    Arrays.sort(d);

    // ① 非退化：最短边 > 0
    if (d[0] == 0) return false;
    // ② 4 边相等 + 2 对角线相等
    if (d[0] != d[1] || d[1] != d[2] || d[2] != d[3]) return false;
    if (d[4] != d[5]) return false;
    // ③ 勾股：边² × 2 = 对角线²
    return d[0] * 2 == d[4];
}

private long dist(int[] a, int[] b) {
    long dx = a[0] - b[0], dy = a[1] - b[1];
    return dx * dx + dy * dy;                  // ⚠️ 平方距离（无浮点）
}
// 推演 (0,0)(1,1)(1,0)(0,1)：
//   距离平方：1,1,1,1（边）, 2,2（对角线）→ 1×4 边 + 2×2 对角线
//   1×2 = 2 ✓ → 正方形 ✓
// ⚠️ 为什么"4+2+勾股"充分：6 距离确定唯一图形
//   （SSS 全等意义下的四边形），条件满足必为正方形
```

## 7. 447. 回旋镖的数量

### 7.1 题目与思路

```
(i,j,k) 三元组，|ij| = |ik|（回旋镖）的数量
固定点 i：到 i 距离相同的点对 (j,k) 数量 = C(cnt, 2)
  每个距离出现 cnt 次 → 贡献 cnt·(cnt-1)
⚠️ 平方距离作键（整数，无浮点）
```

### 7.2 完整代码

```java
/**
 * LeetCode 447. 回旋镖的数量
 * ⚠️ 固定中心点 + 距离计数（平方距离整数键）
 */
public int numberOfBoomerangs(int[][] points) {
    int n = points.length;
    int total = 0;

    for (int i = 0; i < n; i++) {
        Map<Long, Integer> distCount = new HashMap<>();
        for (int j = 0; j < n; j++) {
            if (i == j) continue;
            long d = dist2(points[i], points[j]);
            distCount.merge(d, 1, Integer::sum);
        }
        for (int cnt : distCount.values()) {
            total += cnt * (cnt - 1);        // ⚠️ C(cnt,2)×2 = 有序对
        }
    }
    return total;
}
// 推演 points=[[0,0],[1,0],[2,0]]：
//   i=0：距离 1 出现 1 次，4 出现 1 次 → 0 贡献
//   i=1：距离 1 出现 2 次 → 2×1 = 2 ✓（(0,1,2) 与 (2,1,0)）
//   i=2：同 i=0 → 0 → 总 2 ✓
// ⚠️ 复杂度：O(n²)（固定点 × 全扫描）
// ⚠️ 变体：149 直线点数的"距离版"——同为"固定点 + 计数"模式
```

## 8. 几何题方法论总结

### 8.1 解题框架

```
① 抽象：把几何条件翻译成代数（叉积/距离/投影）
② 选工具：
   点线关系 → 叉积
   距离/圆 → 平方距离（整数）
   矩形 → 投影交集
   直线共点 → 最简分数斜率
   凸包 → Andrew 单调链
③ 精度：能整数不浮点（gcd/平方/交叉相乘）
④ 边界：退化（共线/重合/边界相接）、溢出（long）

⚠️ 识别信号：
  "直线/圆/矩形/点集" → 几何题
  "最多点/最小/最大面积" → 计算几何经典
```

### 8.2 题型模板速查

| 题型 | 核心 | 代表题 |
|------|------|--------|
| 共线计数 | 最简分数斜率键 | 149 |
| 凸包 | Andrew 单调链 | 587 |
| 圆内采样 | 极坐标 √u / 拒绝采样 | 478 |
| 矩形关系 | 投影交集 | 836、223 |
| 图形判定 | 距离排序 + 勾股 | 593 |
| 距离计数 | 平方距离 + 组合 | 447 |

### 8.3 自测清单

```
□ 用 long 防溢出（叉积/面积/平方）？
□ 斜率用最简分数（非 double）？
□ 退化特判（共线/重合/边界相接）？
□ 圆内采样 √u（防中心密集）？
□ 凸包共线处理符合题意（含边界 or 不含）？
□ 距离用平方（省 sqrt）？
```
