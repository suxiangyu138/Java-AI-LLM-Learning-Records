## 1. 基础遍历（1 个）

### 🏷️ 图
| 维度 | 内容 |
|------|------|
| **定位** | 存储与遍历基础（邻接表/邻接矩阵） |
| **模板题** | 133 克隆图、841 钥匙和房间、997 找到小镇法官 |
| **核心技巧** | 邻接表（稀疏图）、visited 数组、遍历所有连通分量、入度/出度 |
| **关联体系** | [DFS](../DFS/00-DFS知识体系总览.md) / [BFS](../BFS/00-BFS知识体系总览.md) |

```
建图模板（有向图）：
List<List<Integer>> graph = new ArrayList<>();
for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
graph.get(u).add(v);                    // 边 u → v
// 无向图加：graph.get(v).add(u);
// 带权图：List<int[]> 存 [to, weight]
```

## 2. 最短路径（1 个）

### 🏷️ 最短路
| 维度 | 内容 |
|------|------|
| **定位** | 带权图最短路径，Dijkstra 面试必考 |
| **模板题** | 743 网络延迟时间、1631 最小体力消耗、778 水位上升 |
| **核心技巧** | Dijkstra（堆优化）、无权图用 BFS、负权用 Bellman-Ford/SPFA |

```
Dijkstra 模板（堆优化）：
PriorityQueue<int[]> pq = new PriorityQueue<>((a,b) -> a[1]-b[1]);
pq.offer(new int[]{start, 0});
int[] dist = new int[n];
Arrays.fill(dist, Integer.MAX_VALUE);
dist[start] = 0;
while (!pq.isEmpty()) {
    int[] cur = pq.poll();
    int u = cur[0], d = cur[1];
    if (d > dist[u]) continue;                    // 跳过过期记录
    for (int[] e : graph.get(u)) {
        int v = e[0], w = e[1];
        if (dist[u] + w < dist[v]) {
            dist[v] = dist[u] + w;
            pq.offer(new int[]{v, dist[v]});
        }
    }
}
复杂度：O((V+E) log V)     ⚠️ 不能处理负权边！
```

## 3. 生成树与排序（2 个）

### 🏷️ 最小生成树（MST）
| 维度 | 内容 |
|------|------|
| **定位** | 连接所有节点的最小权重边集 |
| **模板题** | 1584 连接所有点的最小费用、1168 水资源分配 |
| **核心技巧** | Kruskal（排序+并查集）、Prim（堆+visited） |

```
Kruskal 模板（推荐，直观）：
① 所有边按权重排序
② 依次取边：两端不连通 → 加入（并查集合并）
③ 已连 n-1 条边 → 完成
复杂度：O(E log E)（排序为主）
```

## 4. 连通性（3 个）

### 🏷️ 强连通分量（SCC）
| 维度 | 内容 |
|------|------|
| **定位** | 有向图"互相可达"的最大节点组 |
| **模板题** | 求解 SCC 后缩点（问题简化） |
| **核心技巧** | Tarjan（low/dfn + 栈）或 Kosaraju（两遍 DFS） |

```
Tarjan 核心：
dfn[u] = 访问序号，low[u] = 子树中能到达的最小 dfn
当 dfn[u] == low[u] → u 是 SCC 根，弹栈出分量
应用：缩点后图变 DAG → 可做拓扑/DP
```

### 🏷️ 双连通分量（BCC）
| 维度 | 内容 |
|------|------|
| **定位** | 无向图割点/桥/双连通分量 |
| **模板题** | 1192 网络关键连接（找桥）、割点问题 |
| **核心技巧** | Tarjan 变体：桥判断 `low[v] > dfn[u]`、割点判断 `low[v] >= dfn[u]` |

### 🏷️ 并查集（Disjoint Set）
| 维度 | 内容 |
|------|------|
| **定位** | 动态连通性，合并/查询 O(α(n)) |
| **模板题** | 200 岛屿数量（并查集版）、547 省份数量、305 岛屿数量 II |
| **核心技巧** | 路径压缩 + 按秩合并、连接分量数统计 |

```
并查集模板：
int[] parent;
int find(int x) {
    if (parent[x] != x) parent[x] = find(parent[x]);   // 路径压缩
    return parent[x];
}
void union(int a, int b) {
    int ra = find(a), rb = find(b);
    if (ra != rb) parent[ra] = rb;                     // 可加按秩
}
应用：连通分量数、动态加边连通、Kruskal 判环
```

## 5. 其他（2 个）

### 🏷️ 扫描线
| 维度 | 内容 |
|------|------|
| **定位** | 区间事件排序处理，区间统计利器 |
| **模板题** | 218 天际线问题、253 会议室 II（差分版） |
| **核心技巧** | 事件排序（起点/终点 + 类型）、差分数组、TreeMap 维护高度 |

```
扫描线模板（会议室 II 差分版）：
Map<Integer, Integer> diff = new TreeMap<>();
for (int[] m : meetings) {
    diff.merge(m[0], 1, Integer::sum);       // 开始 +1
    diff.merge(m[1], -1, Integer::sum);      // 结束 -1
}
int rooms = 0, cur = 0;
for (int d : diff.values()) {
    cur += d;
    rooms = Math.max(rooms, cur);            // 最大重叠
}
```

## 6. 学习优先级建议

### 🟢 第一梯队（面试核心，2-3 周）
```
图（遍历）→ 并查集 → 拓扑排序 → 最短路（Dijkstra）
```

### 🟡 第二梯队（进阶加分，1-2 周）
```
最小生成树（Kruskal）→ 扫描线 → 强连通分量（了解）
```

### 🔴 第三梯队（竞赛级）
```
双连通分量 → 欧拉回路
（了解概念与判定条件即可）
```

### 图论算法选型总览

| 问题 | 算法 | 复杂度 |
|------|------|:---:|
| 无权图最短 | BFS | O(V+E) |
| 带权正边最短 | Dijkstra（堆） | O((V+E) log V) |
| 负权最短 | Bellman-Ford / SPFA | O(VE) / 期望 O(E) |
| 全源最短 | Floyd | O(V³) |
| 最小生成树 | Kruskal / Prim | O(E log E) |
| 判环/拓扑 | Kahn / 颜色法 | O(V+E) |
| 强连通分量 | Tarjan / Kosaraju | O(V+E) |
| 动态连通 | 并查集 | O(α(n)) |

> 🎯 **核心要点**：图论标签中面试主力是**图遍历、并查集、拓扑排序、Dijkstra** 四件套——模板固定（建图/visited/入度/堆），背熟即可。Kruskal/Tarjan/扫描线是进阶加分。图论题通用套路：**先判断图类型（有向/无向/带权）→ 选算法 → 套模板**，复杂度表要能背出来。
