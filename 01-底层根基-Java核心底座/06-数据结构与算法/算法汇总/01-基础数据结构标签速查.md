### 🏷️ 字典树（Trie）
| 维度 | 内容 |
|------|------|
| **定位** | 前缀共享树，字符串检索 O(长度) |
| **模板题** | 208 实现 Trie、211 添加搜索、212 单词搜索 II |
| **核心技巧** | 节点含 children[26] + isEnd；前缀匹配剪枝（212） |

```
Trie 节点模板：
class TrieNode {
    TrieNode[] children = new TrieNode[26];
    boolean isEnd;
}
核心优势：前缀共享 → 空间优化 + 前缀查询 O(L)
```

### 🏷️ 树状数组（BIT）
| 维度 | 内容 |
|------|------|
| **定位** | 前缀和/单点更新的 O(log n) 利器 |
| **模板题** | 307 区域和检索（BIT 版）、315 右侧更小元素 |
| **核心技巧** | `lowbit(x) = x & (-x)`、update 向上、query 向下 |

```
BIT 核心三行：
int lowbit(int x) { return x & (-x); }
void update(int i, int v) { for (; i <= n; i += lowbit(i)) tree[i] += v; }
int query(int i) { int s = 0; for (; i > 0; i -= lowbit(i)) s += tree[i]; return s; }
```

## 3. 堆与有序集合（3 个）

### 🏷️ 堆（优先队列）
| 维度 | 内容 |
|------|------|
| **定位** | 完全二叉树（数组），取最值 O(1)/O(log n) |
| **模板题** | 215 第 K 大、347 前 K 高频、23 合并 K 链 |
| **核心技巧** | 大小为 k 的堆（TopK）、堆排序（建堆 n/2-1 起下沉） |
| **关联体系** | [排序](../排序/00-排序知识体系总览.md)（堆排章节） |

```
TopK 选型：
  求最大 K 个 → 小根堆（堆顶是最小候选）
  求最小 K 个 → 大根堆
  数据流 → 堆（在线处理）；静态数组 → 快速选择更快
```

### 🏷️ 单调队列
| 维度 | 内容 |
|------|------|
| **定位** | 双端队列维护窗口单调性，窗口最值 O(n) |
| **模板题** | 239 滑动窗口最大值、1696 跳跃游戏 VI |
| **核心技巧** | 入队淘汰（晚到且大淘汰早到且小）、过期弹出、队头取值 |
| **关联体系** | [滑动窗口](../双指针/滑动窗口/00-滑动窗口知识体系总览.md) |

### 🏷️ 有序集合
| 维度 | 内容 |
|------|------|
| **定位** | 平衡树（Java TreeMap/TreeSet），有序+范围查询 |
| **模板题** | 220 存在重复 III、729 日程表 |
| **核心技巧** | 有序性（firstKey/floorKey/ceilingKey）、范围查询 |
| **注意** | Java 无内置多集（可 TreeMap 计数或用 sorted list） |

## 4. 学习优先级建议

### 🟢 第一梯队（面试必考，3-4 周）
```
数组 → 字符串 → 哈希表 → 链表 → 栈 → 队列
→ 二叉树 → 二叉搜索树 → 单调栈 → 堆
```

### 🟡 第二梯队（高频加分，2-3 周）
```
双向链表（LRU）→ 字典树 → 单调队列 → 有序集合
→ 树状数组
```

### 🔴 第三梯队（竞赛/储备，了解原理）
```
线段树 → 后缀数组等（配合 Hard 题使用）
```

> 🎯 **核心要点**：18 个基础结构标签中，**数组/字符串/哈希表/链表/栈/队列/二叉树/单调栈/堆** 9 个是面试主力（占 Hot 100 大部分），务必按第一梯队优先攻克。每个标签的"模板题"是学习入口——先做模板题吃透结构特性，再刷变体题。
