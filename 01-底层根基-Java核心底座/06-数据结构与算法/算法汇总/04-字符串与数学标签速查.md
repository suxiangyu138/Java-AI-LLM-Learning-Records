## 1. 字符串专项（3 个）

### 🏷️ 字符串匹配
| 维度 | 内容 |
|------|------|
| **定位** | 模式串匹配，KMP/BM/朴素三解法 |
| **模板题** | 28 strStr、686 重复字符串匹配、214 最短回文串 |
| **核心技巧** | KMP（next 数组 + 主串不回溯）、BM（坏字符+好后缀） |
| **关联体系** | [字符串](../字符串/00-字符串知识体系总览.md) |

```
KMP 核心两段：
// next 构建
int[] next = new int[m];
for (int i = 1, j = 0; i < m; i++) {
    while (j > 0 && p[i] != p[j]) j = next[j-1];   // ⚠️ while 回退
    if (p[i] == p[j]) j++;
    next[i] = j;
}
// 匹配（主串不回溯）
for (int i = 0, j = 0; i < n; i++) {
    while (j > 0 && t[i] != p[j]) j = next[j-1];
    if (t[i] == p[j]) j++;
    if (j == m) return i - m + 1;
}
```

### 🏷️ 后缀数组
| 维度 | 内容 |
|------|------|
| **定位** | 所有后缀的排序数组，字符串处理利器 |
| **模板题** | 最长重复子串（后缀数组版）、不同子串计数 |
| **核心技巧** | 倍增法构建 O(n log n)、height 数组（LCP）、RMQ 配合 |
| **难度** | 🔴 竞赛级，面试了解概念即可 |

```
后缀数组概念：
sa[i] = 第 i 小的后缀的起始下标
height[i] = sa[i] 与 sa[i-1] 的最长公共前缀
应用：最长重复子串 = max(height)、不同子串数 = Σ(n - sa[i] - height[i])
```

| **模板题** | 204 计数质数、365 水壶问题（gcd） |
| **核心技巧** | 埃氏筛 O(n log log n)、欧几里得 gcd、快速幂取模 |

```
数论三件套：
// 埃氏筛
boolean[] prime = new boolean[n+1];
for (int i = 2; i * i <= n; i++)
    if (!prime[i])
        for (int j = i*i; j <= n; j += i) prime[j] = true;
// gcd
int gcd(int a, int b) { return b == 0 ? a : gcd(b, a % b); }
// 快速幂
long pow(long a, long b, long mod) {
    long r = 1;
    while (b > 0) { if ((b & 1) == 1) r = r * a % mod; a = a * a % mod; b >>= 1; }
    return r;
}
```
