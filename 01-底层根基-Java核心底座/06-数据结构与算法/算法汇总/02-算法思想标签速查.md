## 1. 搜索类（4 个）

|------|------|

| **核心技巧** | 标记在递归前、沉岛/visited、前序传参后序聚合、颜色法判环 |
| **关联体系** | [DFS](../DFS/00-DFS知识体系总览.md) |

### 🏷️ 广度优先搜索（BFS）

|------|------|

| **模板题** | 102 层序、994 腐烂橘子、127 单词接龙 |
| **核心技巧** | 入队即标记、size 分层、多源 BFS、双向 BFS、Kahn 拓扑 |

### 🏷️ 回溯

## 2. 策略类（5 个）

### 🏷️ 动态规划
| 维度 | 内容 |
|------|------|
| **定位** | 状态转移，重叠子问题+最优子结构 |
| **模板题** | 70 爬楼梯、198 打家劫舍、1143 LCS |
| **核心技巧** | 五步法（状态/定义/转移/边界/顺序）、滚动数组、背包模板 |
| **关联体系** | [动态规划](../动态规划/00-动态规划知识体系总览.md) |

### 🏷️ 贪心
| 维度 | 内容 |
|------|------|
| **定位** | 局部最优→全局最优，不可反悔 |
| **模板题** | 455 分发饼干、435 无重叠区间、763 划分字母 |
| **核心技巧** | 贪心选择性质+最优子结构、交换论证、90% 需排序 |
| **关联体系** | [贪心算法](../贪心算法/00-贪心算法知识体系总览.md) |

### 🏷️ 模拟

| **核心技巧** | 状态数组（复制原状态防干扰）、边界模拟、细心 |

### 🏷️ 随机化

| **核心技巧** | 随机基准防快排退化、水塘抽样（流式等概率） |

## 3. 分治与递归（3 个）

### 🏷️ 分治
| 维度 | 内容 |
|------|------|
| **定位** | 拆分-解决-合并，子问题独立 |
| **模板题** | 53 最大子序和（分治版）、23 合并 K 链（分治版） |
| **核心技巧** | 与 DP 区别（子问题不重叠）、归并排序是分治典范 |
| **关联体系** | [排序](../排序/00-排序知识体系总览.md) |

### 🏷️ 递归
| 维度 | 内容 |
|------|------|
| **定位** | 自我调用，树/链表/DFS 的载体 |
| **模板题** | 206 反转链表（递归版）、104 最大深度 |
| **核心技巧** | 基线条件（base case）+ 递推关系、注意栈溢出 |
| **注意** | 递归是"机制"，回溯/DFS/分治是"思想" |

### 🏷️ 迭代器
| 维度 | 内容 |
|------|------|
| **定位** | 惰性遍历/按需生成（设计模式） |
| **模板题** | 284 顶端迭代器、341 扁平化嵌套列表迭代器 |
| **核心技巧** | 栈保存状态（341 用栈存 ListIterator）、hasNext/next 契约 |

## 5. 学习优先级建议

### 🟢 第一梯队（面试核心，4-6 周）
```
动态规划 → 回溯 → 贪心 → BFS → DFS → 二分查找
（前六个是 Hot 100 的绝对主力）
```

### 🟡 第二梯队（重要补充，2 周）
```
记忆化（DP 的递归形态）→ 分治 → 递归 → 快速选择
```

### 🔴 第三梯队（了解/储备）
```
枚举 → 模拟 → 随机化 → 迭代器
（简单标签，理解思想即可）
```

### 思想间的关系

```
递归（机制）→ DFS（搜索）→ 回溯（+撤销）/ 记忆化（+缓存）
记忆化（缓存）→ 动态规划（自底向上）
分治（拆分）→ 归并排序 / 快速选择
二分查找（二段性）→ 答案二分（+check 函数）
```

> 🎯 **核心要点**：算法思想类标签是面试的灵魂——**DP/回溯/贪心/BFS/DFS/二分** 六大思想覆盖 Hot 100 的 60%+。理解它们的**相互关系**（记忆化是 DP 的递归形态、回溯=DFS+撤销、分治是归并的底座）比孤立记忆每个标签重要得多。每个思想配一个"母题"反复练（如 DP 练爬楼梯、回溯练全排列），形成条件反射。
