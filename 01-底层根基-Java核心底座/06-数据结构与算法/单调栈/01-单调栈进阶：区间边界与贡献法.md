## 1. 单调栈的三层应用

### 1.1 三层体系

```
第一层：下一个更大/更小（739/496/503）
  弹出时记录答案（单向信息）

第二层：区间边界（84/907）
  弹出时三方会合（底部/左边界/右边界）

第三层：贡献法（907/2104）
  左右边界 + 数学计数（每个元素贡献多少子数组）

⚠️ 面试定位：
  第一层 = 必须掌握
  第二层 = 进阶必备
  第三层 = 拉开差距
```

### 1.2 三层的关系

```
第一层是"单侧信息"（下一个更大）
第二层是"双侧信息"（左右边界）
第三层是"双侧信息 × 计数"（贡献法）

⚠️ 识别：
  "下一个更大/更小" → 第一层
  "最大矩形/接雨水" → 第二层
  "子数组的和/计数" → 第三层
```

### 1.3 单调栈的核心不变式

```
⚠️ 所有应用的统一原理：
  "弹出时机 = 信息确定时机"

第一层：弹出时确定"下一个更大"
第二层：弹出时确定"左右边界"
第三层：弹出时确定"贡献范围"

⚠️ 面试必答：
"单调栈弹出时，该元素的所有信息
 已确定——这是 O(n) 的本质。"
```

## 2. 区间边界详解

### 2.1 什么是区间边界

```
每个元素作为"关键点"时的左右范围：
  例：84 每个柱子作为矩形高度
    左边界 = 左边第一个更矮的
    右边界 = 右边第一个更矮的
    宽度 = 右边界 - 左边界 - 1

⚠️ 单调栈可以 O(n) 求所有元素的左右边界
  （暴力每元素 O(n) 扫描 → O(n²)）
```

### 2.2 三方会合机制

```
单调递增栈弹出时：
  弹出元素 = 当前柱子（高度确定）
  新栈顶 = 左边界（左边第一个更矮的）
  当前元素 = 右边界（右边第一个更矮的）

⚠️ 弹出时机 = 三方会合：
  当前元素让栈顶"找到右边界"
  新栈顶是"左边界"
  → 一次弹出确定三个信息！
```

### 2.3 84. 柱状图中最大的矩形

```java
/**
 * LeetCode 84. 柱状图中最大的矩形（Hard 经典）
 * 每个柱子作为高度 → 找左右第一个更矮的
 * 面积 = h × (右边界 - 左边界 - 1)
 */
public int largestRectangleArea(int[] heights) {
    int n = heights.length;
    int[] h = new int[n + 2];            // ⚠️ 首尾补 0
    System.arraycopy(heights, 0, h, 1, n);

    Deque<Integer> stack = new ArrayDeque<>();
    int maxArea = 0;

    for (int i = 0; i < h.length; i++) {
        // 递增栈：遇到更矮的 → 弹出计算面积
        while (!stack.isEmpty() && h[i] < h[stack.peek()]) {
            int height = h[stack.pop()];       // 当前柱子高度
            int left = stack.peek();           // 左边界（新栈顶）
            int right = i;                     // 右边界（当前更矮）
            int width = right - left - 1;      // 宽度
            maxArea = Math.max(maxArea, height * width);
        }
        stack.push(i);
    }
    return maxArea;
}
// 推演 [2,1,5,6,2,3] → 哨兵版 [0,2,1,5,6,2,3,0]
//   面积计算：2×1=2；5×3=15；6×1=6；2×4=8；3×1=3
//   答案 10 ✓（5 和 6 组成 5×2=10）
// ⚠️ 哨兵作用：
//   头部 0：免栈空判断（左边界恒存在）
//   尾部 0：强制弹出残留（全部计算面积）
// ⚠️ 面试必答："首尾补 0——头 0 免判空，
//   尾 0 强制弹出所有残留。"
```

## 3. 贡献法详解

### 3.1 贡献法的思想

```
问题：所有子数组的某个统计量之和
  例：907 所有子数组最小值之和

暴力：枚举所有子数组 O(n²) → 超时
贡献法：每个元素"贡献"给多少个子数组？
  → 左右边界（该元素作为最小值的范围）
  → 贡献 = val × 左边数量 × 右边数量
  → O(n)

⚠️ 核心转化：
  "所有子数组的统计" → "每个元素的贡献"
```

### 3.2 907. 子数组的最小值之和

```java
/**
 * LeetCode 907. 子数组的最小值之和（Hard）
 * 每个元素作为最小值贡献：
 *   左边界：左边第一个更小（严格小于）
 *   右边界：右边第一个更小（小于等于）
 *   贡献 = val × (i-left) × (right-i)
 *
 * ⚠️ 边界去重：左严格 + 右宽松
 *   （避免相等元素重复计算）
 */
public int sumSubarrayMins(int[] arr) {
    int n = arr.length;
    int MOD = 1_000_000_007;

    int[] left = new int[n];      // 左边第一个更小的距离
    int[] right = new int[n];     // 右边第一个更小的距离
    Deque<Integer> stack = new ArrayDeque<>();

    // 左边界：严格小于（用 >= 弹栈）
    for (int i = 0; i < n; i++) {
        while (!stack.isEmpty() && arr[stack.peek()] >= arr[i]) {
            stack.pop();
        }
        left[i] = stack.isEmpty() ? i + 1 : i - stack.peek();
        stack.push(i);
    }

    stack.clear();
    // 右边界：小于等于（用 > 弹栈）
    for (int i = n - 1; i >= 0; i--) {
        while (!stack.isEmpty() && arr[stack.peek()] > arr[i]) {
            stack.pop();
        }
        right[i] = stack.isEmpty() ? n - i : stack.peek() - i;
        stack.push(i);
    }

    // 贡献求和
    long sum = 0;
    for (int i = 0; i < n; i++) {
        sum = (sum + (long) arr[i] * left[i] % MOD * right[i]) % MOD;
    }
    return (int) sum;
}
// 推演 [3,1,2,4] → 17 ✓
// ⚠️ 为什么左严格右宽松？
//   [2,2] 的重复去重：两边都"小于" →
//   每个 2 都认为自己是 4 个子数组的最小 → 重复计数
//   一边严格一边宽松 → 每个子数组只被"最左的最小"计算
// ⚠️ 面试必答："去重规则：左严格 + 右宽松——
//   保证每个子数组只被计算一次。"
```

### 3.3 贡献法家族

| 题号 | 题目 | 贡献对象 |
|:---:|------|------|
| 907 | 子数组最小值之和 | 每个元素作为最小值 |
| 2104 | 子数组范围和 | max 贡献 - min 贡献 |
| 828 | 统计子串中的唯一字符 | 每个字符的独享区间 |
| 1856 | 子数组最小乘积 | 最小值 × 区间和 |

```
⚠️ 通用框架：
  ① 左右边界（单调栈）
  ② 贡献 = 值 × 左范围 × 右范围
  ③ 求和取模
```

## 4. 84 最大矩形的完整剖析

### 4.1 完整推演

```
heights = [2,1,5,6,2,3]
哨兵版 = [0,2,1,5,6,2,3,0]

i=1(2)：入栈 [0,1]
i=2(1)：1 < 2 → 弹出 1
   高度=2，left=0（0），right=2 → 2×1=2
   入栈 [0,2]
i=3(5)：入栈 [0,2,3]
i=4(6)：入栈 [0,2,3,4]
i=5(2)：2 < 6 → 弹出 4
   高度=6，left=3，right=5 → 6×1=6
   2 < 5 → 弹出 3
   高度=5，left=2，right=5 → 5×2=10 ✓
   入栈 [0,2,5]
i=6(3)：3 > 2 → 入栈 [0,2,5,6]
i=7(0)：0 弹出全部
   高度=3，left=5，right=7 → 3×1=3
   高度=2，left=2，right=7 → 2×4=8
   高度=1，left=0，right=7 → 1×6=6
最大 = 10 ✓
```

### 4.2 面试表达

```
"每个柱子作为矩形高度时：
 左边界 = 左边第一个更矮的（栈中下一个）
 右边界 = 当前遇到的更矮柱子
 弹出时三方会合：弹出元素（高）、
 新栈顶（左界）、当前元素（右界）。
 首尾补 0 简化边界。
 每元素进出栈一次 → O(n)。"
```

### 4.3 变体：85 最大矩形（矩阵版）

```
二维矩阵 → 逐行转化为柱状图：
  每行统计"连续 1 的高度" → 84 题求解
  例：[[1,0,1,0,0],[1,0,1,1,1],[1,1,1,1,1]]
  第 2 行高度 [2,0,2,1,1] → 84 求 2
  第 3 行高度 [3,1,3,2,2] → 84 求 4
  最大 = 6 ✓

⚠️ 面试必答：
"85 = 84 的逐行转化——
 每行算高度数组，套 84 模板。"
```

## 5. 42 接雨水的单调栈解法

### 5.1 完整实现

```java
/**
 * LeetCode 42. 接雨水（单调栈版）
 * 递减栈找"凹槽"（左右壁 + 底部）
 *
 * 弹出时形成凹槽：
 *   栈顶 = 凹槽底部（弹出）
 *   新栈顶 = 左壁（如果存在）
 *   当前 = 右壁
 *   水量 = (min(左壁,右壁) - 底部) × (右-左-1)
 */
public int trap(int[] height) {
    Deque<Integer> stack = new ArrayDeque<>();
    int water = 0;

    for (int i = 0; i < height.length; i++) {
        // 递减栈：当前比栈顶高 → 形成凹槽右壁
        while (!stack.isEmpty() && height[i] > height[stack.peek()]) {
            int bottom = stack.pop();          // 凹槽底部
            if (stack.isEmpty()) break;        // 无左壁 → 装不了水

            int left = stack.peek();           // 左壁
            int h = Math.min(height[left], height[i]) - height[bottom];
            int w = i - left - 1;              // 宽度
            water += h * w;                    // 这个凹槽的水
        }
        stack.push(i);
    }
    return water;
}
// 推演 [0,1,0,2,1,0,1,3,2,1,2,1] → 6 ✓
// ⚠️ 与双指针版对比：
//   双指针：按"列"计算每格水量（O(1) 空间）
//   单调栈：按"层"计算凹槽水量（O(n) 空间）
// ⚠️ 面试三种解法都能讲 = 加分
```

## 6. 进阶总结

### 6.1 进阶要点速查

```
① 三层应用：下一个更大 / 区间边界 / 贡献法
② 三方会合：弹出元素（高）+ 新栈顶（左界）+ 当前（右界）
③ 哨兵：头 0 免判空、尾 0 强制弹出
④ 贡献法：左右边界 + 左严格右宽松去重
⑤ 85 = 84 逐行转化；42 凹槽按层计算
```

### 6.2 面试话术模板

```
"单调栈进阶应用：
 ① 区间边界：弹出时三方会合
   （弹出=当前、新栈顶=左界、当前元素=右界）；
 ② 84 用递增栈 + 首尾补 0；
 ③ 贡献法（907）：左右边界 + 左严格右宽松
   去重 → 贡献 = val × 左 × 右；
 ④ 每元素进出栈一次 → O(n)。"
```

### 6.3 易错点清单

| 错误 | 后果 | 修正 |
|------|------|------|
| 84 忘补哨兵 | 残留未算 | 首尾补 0 |
| 907 去重不对称 | 重复计数 | 左严格右宽松 |
| 宽度公式错 | 面积错 | right-left-1 |
| 42 忘判左壁 | 空栈 pop | 先判 isEmpty |
| 单调方向反 | 边界反 | 递增找更矮 |

> 🎯 **核心要点**：单调栈进阶 = **三层应用**（下一个更大/区间边界/贡献法）+ **三方会合**（弹出即确定）+ **哨兵技巧**（首尾补 0）。"弹出时机 = 信息确定时机"是统一原理；907 的"左严格右宽松"去重是贡献法灵魂。
