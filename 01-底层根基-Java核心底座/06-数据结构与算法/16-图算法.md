## 一、图的表示与遍历

### 1.1 图的定义回顾

图 G = (V, E)。按边方向分为有向图/无向图，按边权重分为无权图/有权图。核心概念：度（入度/出度）、路径、环、连通分量、强连通分量。

### 1.2 邻接矩阵（稠密图）

二维数组表示顶点连接关系，O(1) 查询两点是否相邻，空间 O(V²)，仅适合 V <= 1000 的稠密图。

```java
public class DenseGraph {
    private int[][] adj;
    public DenseGraph(int n) { adj = new int[n][n]; }
    public void addEdge(int u, int v) { adj[u][v] = 1; adj[v][u] = 1; } // 有向图只保留第一行
    public List<Integer> adj(int u) {
        List<Integer> res = new ArrayList<>();
        for (int v = 0; v < adj.length; v++) if (adj[u][v] == 1) res.add(v);
        return res;
    }
}
```

### 1.3 邻接表（稀疏图，后端主流）

HashMap 存储每个顶点的邻接列表，空间 O(V+E)，适合大规模稀疏图，是后端 90% 以上场景的首选。

```java
public class SparseGraph {
    Map<Integer, List<Edge>> adj = new HashMap<>();
    static class Edge { int to, w; Edge(int to, int w) { this.to = to; this.w = w; } }
    public SparseGraph(int n) { for (int i = 0; i < n; i++) adj.put(i, new ArrayList<>()); }
    public void addEdge(int u, int v, int w, boolean directed) {
        adj.get(u).add(new Edge(v, w));
        if (!directed) adj.get(v).add(new Edge(u, w));
    }
    public List<Edge> get(int u) { return adj.getOrDefault(u, new ArrayList<>()); }
}
```

### 1.4 DFS（非递归实现，避免栈溢出）

DFS 尽可能深地访问邻接顶点，回溯后继续。Java 递归超 1000 层会 StackOverflowError，后端优先用非递归。

```java
public static List<Integer> dfs(SparseGraph g, int start) {
    List<Integer> order = new ArrayList<>();
    Set<Integer> visited = new HashSet<>();
    Stack<Integer> stack = new Stack<>();
    stack.push(start); visited.add(start); order.add(start);
    while (!stack.isEmpty()) {
        int cur = stack.peek();
        boolean found = false;
        for (SparseGraph.Edge e : g.get(cur)) {
            if (!visited.contains(e.to)) {
                stack.push(e.to); visited.add(e.to); order.add(e.to); found = true; break;
            }
        }
        if (!found) stack.pop();
    }
    return order;
}
```

**场景**：环检测、拓扑排序、权限链路校验。

### 1.5 BFS（无权图最短路径）

逐层扩展，通过队列实现，可求解无权图中起点到所有顶点的最短路径（最少边数）。

```java
public static Map<Integer, Integer> bfs(SparseGraph g, int start) {
    Map<Integer, Integer> dist = new HashMap<>();
    Set<Integer> visited = new HashSet<>();
    Queue<Integer> q = new LinkedList<>();
    q.offer(start); visited.add(start); dist.put(start, 0);
    while (!q.isEmpty()) {
        int cur = q.poll();
        for (SparseGraph.Edge e : g.get(cur)) {
            if (!visited.contains(e.to)) {
                visited.add(e.to); q.offer(e.to); dist.put(e.to, dist.get(cur) + 1);
            }
        }
    }
    return dist;
}
```

**场景**：社交好友推荐（最短链路）、分布式节点最短通信路径。

### 1.6 工程化改造要点

| 方向 | 措施 | 方向 | 措施 |
|------|------|------|------|
| **顶点类型** | int -> String/Long 适配业务主键 | **剪枝** | 找到目标后提前退出 |
| **集合选型** | 频繁增删用 LinkedList；最短路径用 PriorityQueue | **并行** | ThreadPoolExecutor 多线程处理 |
| **空值防护** | 顶点不存在、权重非法等异常处理 | **缓存** | 高频查询结果缓存到 Redis |
| **延迟初始化** | 仅为有边顶点创建邻接列表 | **接口化** | 抽象 Graph 接口，支持多实现 |

## 二、最短路径算法

### 2.1 Dijkstra（贪心，无负权边）

每次选当前最近的未访问顶点更新邻接距离。优先队列优化后 O((V+E)log V)。不支持负权边。

```java
public static Map<Integer, Integer> dijkstra(SparseGraph g, int start) {
    Map<Integer, Integer> dist = new HashMap<>();
    for (int v : g.adj.keySet()) dist.put(v, Integer.MAX_VALUE);
    dist.put(start, 0);
    PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(a -> a[0]));
    pq.offer(new int[]{0, start});
    Set<Integer> visited = new HashSet<>();
    while (!pq.isEmpty()) {
        int[] cur = pq.poll();
        int d = cur[0], u = cur[1];
        if (visited.contains(u)) continue;
        visited.add(u);
        for (SparseGraph.Edge e : g.get(u)) {
            if (d != Integer.MAX_VALUE && d + e.w < dist.get(e.to)) {
                dist.put(e.to, d + e.w); pq.offer(new int[]{dist.get(e.to), e.to});
            }
        }
    }
    return dist;
}
```

**场景**：微服务调用最短耗时路径、物流路由规划、资源调度。

### 2.2 Bellman-Ford（处理负权边，检测负权环）

对所有边松弛 V-1 次，第 V 次仍能更新则存在负权环。O(VE)。

```java
public static int[] bellmanFord(SparseGraph g, int start, int V) {
    int[] dist = new int[V];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[start] = 0;
    for (int i = 0; i < V - 1; i++) {
        boolean updated = false;
        for (int u : g.adj.keySet())
            for (SparseGraph.Edge e : g.get(u))
                if (dist[u] != Integer.MAX_VALUE && dist[u] + e.w < dist[e.to])
                    { dist[e.to] = dist[u] + e.w; updated = true; }
        if (!updated) break;
    }
    for (int u : g.adj.keySet())
        for (SparseGraph.Edge e : g.get(u))
            if (dist[u] != Integer.MAX_VALUE && dist[u] + e.w < dist[e.to])
                { System.err.println("存在负权环"); return null; }
    return dist;
}
```

**场景**：金融收益计算、债务关系图等存在负权边的特殊场景。

### 2.3 Floyd-Warshall（所有结点对，DP 思想，O(V³)）

递推 `d[i][j] = min(d[i][j], d[i][k] + d[k][j])`，支持负权边（无负权环），适合 V <= 500 的稠密图。

```java
public class FloydWarshall {
    private int[][] d;
    private int[][] prev;
    private final int n;
    private boolean hasNegativeCycle;

    public FloydWarshall(int n) {
        this.n = n;
        d = new int[n][n]; prev = new int[n][n];
        for (int i = 0; i < n; i++) {
            Arrays.fill(d[i], Integer.MAX_VALUE / 2); d[i][i] = 0; Arrays.fill(prev[i], -1);
        }
    }

    public void addEdge(int from, int to, int w) {
        if (w < d[from][to]) { d[from][to] = w; prev[from][to] = from; }
    }

    public void compute() {
        for (int k = 0; k < n; k++)
            for (int i = 0; i < n; i++)
                for (int j = 0; j < n; j++)
                    if (d[i][k] + d[k][j] < d[i][j]) { d[i][j] = d[i][k] + d[k][j]; prev[i][j] = prev[k][j]; }
        for (int i = 0; i < n; i++) if (d[i][i] < 0) hasNegativeCycle = true;
    }

    public List<Integer> getPath(int from, int to) {
        if (hasNegativeCycle) throw new IllegalStateException("存在负权环");
        if (d[from][to] == Integer.MAX_VALUE / 2) return null;
        List<Integer> path = new ArrayList<>();
        for (int cur = to; cur != -1; cur = prev[from][cur]) path.add(cur);
        Collections.reverse(path); return path;
    }

    public boolean hasNegativeCycle() { return hasNegativeCycle; }
}
```

### 2.4 Johnson（大规模稀疏图，重赋权 + Dijkstra）

添加虚拟起点用 Bellman-Ford 计算 h(v)，重赋权后将负权边转换为非负权，再对每个结点调用 Dijkstra。O(V²log V + VE)，适合 V >= 1000 的稀疏图。

```java
public class Johnson {
    private final Map<Integer, List<Edge>> adj = new HashMap<>();
    private final int n;
    private boolean hasNegativeCycle;
    static class Edge { int to, w; Edge(int t, int w) { this.to = t; this.w = w; } }

    public Johnson(int n) { this.n = n; for (int i = 0; i < n; i++) adj.put(i, new ArrayList<>()); }
    public void addEdge(int from, int to, int w) { adj.get(from).add(new Edge(to, w)); }

    private int[] bellmanFord() {
        int[] h = new int[n];
        for (int i = 0; i < n - 1; i++) {
            boolean updated = false;
            for (int u = 0; u < n; u++) for (Edge e : adj.get(u))
                if (h[u] + e.w < h[e.to]) { h[e.to] = h[u] + e.w; updated = true; }
            if (!updated) break;
        }
        for (int u = 0; u < n; u++) for (Edge e : adj.get(u))
            if (h[u] != Integer.MAX_VALUE / 2 && h[u] + e.w < h[e.to])
                { hasNegativeCycle = true; return null; }
        return h;
    }

    private int[] dijkstra(int s, int[] h) {
        int[] d = new int[n];
        Arrays.fill(d, Integer.MAX_VALUE / 2); d[s] = 0;
        PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(a -> a[0]));
        pq.offer(new int[]{0, s});
        while (!pq.isEmpty()) {
            int[] cur = pq.poll();
            if (cur[0] > d[cur[1]]) continue;
            for (Edge e : adj.get(cur[1])) {
                int nd = cur[0] + e.w + h[cur[1]] - h[e.to];
                if (nd < d[e.to]) { d[e.to] = nd; pq.offer(new int[]{nd, e.to}); }
            }
        }
        int[] res = new int[n];
        for (int i = 0; i < n; i++)
            res[i] = d[i] == Integer.MAX_VALUE / 2 ? Integer.MAX_VALUE / 2 : d[i] + h[i] - h[s];
        return res;
    }

    public Map<Integer, Map<Integer, Integer>> compute() {
        int[] h = bellmanFord();
        if (hasNegativeCycle) throw new IllegalStateException("存在负权环");
        Map<Integer, Map<Integer, Integer>> res = new HashMap<>();
        for (int s = 0; s < n; s++) {
            int[] d = dijkstra(s, h);
            Map<Integer, Integer> map = new HashMap<>();
            for (int i = 0; i < n; i++) map.put(i, d[i] == Integer.MAX_VALUE / 2 ? -1 : d[i]);
            res.put(s, map);
        }
        return res;
    }
}
```

### 2.5 算法选型对比

| 算法 | 时间复杂度 | 支持负权 | 适用规模 | 实现复杂度 | 典型场景 |
|------|-----------|---------|---------|-----------|---------|
| **Dijkstra** | O((V+E)log V) | 否 | V <= 10000 | 低 | 路由规划、资源调度 |
| **Bellman-Ford** | O(VE) | 是（检测负权环） | V <= 1000 | 中 | 金融收益、债务图 |
| **Floyd-Warshall** | O(V³) | 是（无负权环） | V <= 500 | 低 | 小规模稠密图 APSP |
| **Johnson** | O(V²log V+VE) | 是（无负权环） | V >= 1000 | 高 | 大规模稀疏图 APSP |

## 三、最大流

### 3.1 流网络定义与后端映射

流网络 G = (V, E)，每条边有非负容量 c(u,v)，存在源点 s 和汇点 t。最大流是满足容量限制和流量守恒下的最大可行流量。

| 后端场景 | 映射 |
|---------|------|
| API 网关流量调度 | 网关 -> 中间节点 -> 后端集群 |
| 带宽分配 | 带宽入口 -> 分配节点 -> 各服务 |
| 任务调度流控 | 任务队列 -> 工作节点 -> 结果汇总 |
| 数据库连接池分配 | 连接池 -> 各业务模块 |

### 3.2 Ford-Fulkerson（DFS 找增广路径，V <= 100）

反复寻找 s 到 t 的增广路径并增加流量，直到不存在增广路径。时间复杂度 O(E x maxFlow)，仅适合小规模。

```java
public class FordFulkerson {
    static class Edge { int to, cap; Edge rev;
        Edge(int t, int c) { to = t; cap = c; } }
    List<List<Edge>> g; int s, t; boolean[] vis;

    public FordFulkerson(int n, int s, int t) {
        g = new ArrayList<>(n); for (int i = 0; i < n; i++) g.add(new ArrayList<>());
        this.s = s; this.t = t; vis = new boolean[n];
    }

    public void addEdge(int u, int v, int c) {
        Edge f = new Edge(v, c), r = new Edge(u, 0); f.rev = r; r.rev = f;
        g.get(u).add(f); g.get(v).add(r);
    }

    int dfs(int u, int f) {
        if (u == t) return f; vis[u] = true;
        for (Edge e : g.get(u))
            if (!vis[e.to] && e.cap > 0) {
                int m = dfs(e.to, Math.min(f, e.cap));
                if (m > 0) { e.cap -= m; e.rev.cap += m; return m; }
            }
        return 0;
    }

    public int maxFlow() {
        int total = 0, f;
        while (true) { Arrays.fill(vis, false); if ((f = dfs(s, Integer.MAX_VALUE)) == 0) break; total += f; }
        return total;
    }
}
```

### 3.3 Edmonds-Karp（BFS 优化，V = 100 ~ 1000）

用 BFS 替代 DFS 找最短增广路径，避免路径过长。时间复杂度 O(VE²)。

```java
public class EdmondsKarp {
    static class Edge { int to, cap; Edge rev;
        Edge(int t, int c) { to = t; cap = c; } }
    List<List<Edge>> g; int s, t; Edge[] prev; int[] vis; int ts;

    public EdmondsKarp(int n, int s, int t) {
        g = new ArrayList<>(n); for (int i = 0; i < n; i++) g.add(new ArrayList<>());
        this.s = s; this.t = t; prev = new Edge[n]; vis = new int[n];
    }

    public void addEdge(int u, int v, int c) {
        Edge f = new Edge(v, c), r = new Edge(u, 0); f.rev = r; r.rev = f;
        g.get(u).add(f); g.get(v).add(r);
    }

    boolean bfs() {
        ts++; Queue<Integer> q = new LinkedList<>(); q.offer(s); vis[s] = ts;
        while (!q.isEmpty()) {
            int u = q.poll();
            for (Edge e : g.get(u))
                if (e.cap > 0 && vis[e.to] != ts) { vis[e.to] = ts; prev[e.to] = e; q.offer(e.to); if (e.to == t) return true; }
        }
        return false;
    }

    public int maxFlow() {
        int total = 0;
        while (bfs()) {
            int aug = Integer.MAX_VALUE;
            for (int v = t; v != s; v = prev[v].rev.to) aug = Math.min(aug, prev[v].cap);
            for (int v = t; v != s; v = prev[v].rev.to) { prev[v].cap -= aug; prev[v].rev.cap += aug; }
            total += aug;
        }
        return total;
    }
}
```

### 3.4 Dinic（分层图 + 阻塞流，工业首选，V >= 1000）

分层图减少无效遍历，当前弧优化跳过已无容量的边。O(EV²)，稀疏图接近 O(E sqrt(V))，工业级首选。

```java
public class Dinic {
    static class Edge { int to, cap; Edge rev;
        Edge(int t, int c) { to = t; cap = c; } }
    List<List<Edge>> g; int s, t; int[] level, ptr;

    public Dinic(int n, int s, int t) {
        g = new ArrayList<>(n); for (int i = 0; i < n; i++) g.add(new ArrayList<>());
        this.s = s; this.t = t; level = new int[n]; ptr = new int[n];
    }

    public void addEdge(int u, int v, int c) {
        Edge f = new Edge(v, c), r = new Edge(u, 0); f.rev = r; r.rev = f;
        g.get(u).add(f); g.get(v).add(r);
    }

    boolean bfsLevel() {
        Arrays.fill(level, -1); level[s] = 0;
        Queue<Integer> q = new LinkedList<>(); q.offer(s);
        while (!q.isEmpty()) {
            int u = q.poll();
            for (Edge e : g.get(u)) if (e.cap > 0 && level[e.to] == -1) { level[e.to] = level[u] + 1; q.offer(e.to); }
        }
        return level[t] != -1;
    }

    int dfsFlow(int u, int f) {
        if (u == t) return f;
        for (int i = ptr[u]; i < g.get(u).size(); i++) {
            Edge e = g.get(u).get(i);
            if (e.cap > 0 && level[e.to] == level[u] + 1) {
                int m = dfsFlow(e.to, Math.min(f, e.cap));
                if (m > 0) { e.cap -= m; e.rev.cap += m; return m; }
            }
            ptr[u]++; // 当前弧优化
        }
        return 0;
    }

    public int maxFlow() {
        int total = 0, f;
        while (bfsLevel()) { Arrays.fill(ptr, 0); while ((f = dfsFlow(s, Integer.MAX_VALUE)) != 0) total += f; }
        return total;
    }
}
```

### 3.5 算法选型对比

| 算法 | 时间复杂度 | 适用规模 | 实现复杂度 | 后端推荐度 |
|------|-----------|---------|-----------|-----------|
| **Ford-Fulkerson** | O(E x maxFlow) | V <= 100 | 低 | ⭐⭐ |
| **Edmonds-Karp** | O(VE²) | V = 100 ~ 1000 | 中 | ⭐⭐⭐⭐ |
| **Dinic** | O(EV²) | V >= 1000 | 高 | ⭐⭐⭐⭐⭐ |

### 3.6 工程优化与常见坑点

| 类别 | 内容 |
|------|------|
| **存储** | 邻接表 `ArrayList<ArrayList<Edge>>` 避免 V² 内存；超大规模按顶点分片 |
| **当前弧优化** | Dinic 中 `ptr[]` 记录已遍历无容量边，直接跳过 |
| **缓存** | 静态流网络预计算结果缓存到 Redis |
| **算法适配** | 根据规模：V <= 100 用 Ford-Fulkerson，V <= 1000 用 Edmonds-Karp，V > 1000 用 Dinic |
| **栈溢出** | 递归 DFS 大规模图易 StackOverflowError，改用迭代或用 Edmonds-Karp / Dinic |
| **反向边** | 正向边减 f 时反向边必须加 f，通过 Edge.rev 确保同步 |
| **二维数组 OOM** | 邻接矩阵 O(V²) 在 V > 10000 时 OOM，优先邻接表 |
| **连通性** | 提前判断源点能否到达汇点，否者直接返回 0 |

## 四、连通分量与并查集

### 4.1 Union-Find（路径压缩 + 按秩合并）

求解连通分量的高效算法，路径压缩 + 按秩合并后 find/union 接近 O(1)。

```java
public class UnionFind {
    int[] parent, rank;
    public UnionFind(int n) {
        parent = new int[n]; rank = new int[n];
        for (int i = 0; i < n; i++) { parent[i] = i; rank[i] = 1; }
    }
    public int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]); // 路径压缩
        return parent[x];
    }
    public void union(int x, int y) {
        int rx = find(x), ry = find(y);
        if (rx == ry) return;
        if (rank[rx] < rank[ry]) parent[rx] = ry;
        else if (rank[rx] > rank[ry]) parent[ry] = rx;
        else { parent[ry] = rx; rank[rx]++; }
    }
    public boolean isConnected(int x, int y) { return find(x) == find(y); }
    public int count() {
        Set<Integer> roots = new HashSet<>();
        for (int i = 0; i < parent.length; i++) roots.add(find(i));
        return roots.size();
    }
}
```

### 4.2 Kruskal 算法（并查集应用）

所有边按权重排序，依次取最小边，若两端不在同一连通分量则加入并合并。检测环的核心依赖 Union-Find。

```java
public class KruskalMST {
    static class Edge implements Comparable<Edge> { int u, v, w;
        Edge(int u, int v, int w) { this.u = u; this.v = v; this.w = w; }
        public int compareTo(Edge o) { return Integer.compare(this.w, o.w); } }
    public static List<Edge> kruskal(List<Edge> edges, int n) {
        List<Edge> mst = new ArrayList<>();
        UnionFind uf = new UnionFind(n);
        Collections.sort(edges);
        for (Edge e : edges) {
            if (uf.find(e.u) != uf.find(e.v)) { uf.union(e.u, e.v); mst.add(e); if (mst.size() == n - 1) break; }
        }
        return mst;
    }
}
```

**场景**：朋友圈统计、分布式节点连通性检测、权限组管理、网络布线最低成本规划。

## 五、总结与选型

### 5.1 图算法选型全景

| 问题类型 | 推荐算法 | 适用场景 | 关键约束 |
|---------|---------|---------|---------|
| **图的遍历** | DFS / BFS | 路径查询、层次遍历 | DFS 非递归避免栈溢出 |
| **单源最短路径（无负权）** | Dijkstra（优先队列） | 路由规划、资源调度 | 边权重非负 |
| **单源最短路径（有负权）** | Bellman-Ford | 金融收益计算 | 需检测负权环 |
| **APSP（小规模稠密）** | Floyd-Warshall | V <= 500 | 实现简单，支持负权 |
| **APSP（大规模稀疏）** | Johnson | V >= 1000 | 重赋权 + Dijkstra |
| **最大流（小规模）** | Ford-Fulkerson | V <= 100 | DFS 找增广路径 |
| **最大流（中规模）** | Edmonds-Karp | V = 100 ~ 1000 | BFS 最短增广路径 |
| **最大流（大规模）** | Dinic | V >= 1000 | 分层图 + 阻塞流 |
| **连通分量** | Union-Find | 连通性判断 | 路径压缩 + 按秩合并 |
| **最小生成树** | Kruskal | 网络布线最低成本 | 需配合 Union-Find |

### 5.2 后端实践核心原则

1. **邻接表为主**：后端 90% 以上场景为稀疏图，空间更优、扩展灵活
2. **非递归优先**：递归改为迭代，避免生产环境栈溢出
3. **工程化改造**：异常处理、参数校验、动态适配、缓存优化
4. **算法切换**：根据数据规模动态选择，平衡性能与实现成本
5. **边界关注**：负权环检测、溢出处理（Integer.MAX_VALUE / 2 防溢出）、线程安全

> **🎯 从后端视角看，《算法导论》中的图算法是路由规划、流量调度、连通性判断、资源分配等日常需求的底层方法论。核心在于理解每种算法的时间复杂度特征和适用约束，根据业务数据规模合理选型，通过工程化改造让经典算法落地到生产环境。随着业务发展（千万级顶点、百亿级边），可结合图数据库（Neo4j）和分布式计算框架（Spark GraphX）扩展处理能力，但贪心、松弛、分层、阻塞流等核心思想始终是后端工程师的底层能力基石。**
