## 1. 192. 统计词频

### 1.1 题目与思路

```
words.txt 所有单词按频次降序输出（词 频次）
管道：tr 拆分 → sort → uniq -c → sort -rn
⚠️ tr -s 压缩连续空格
```

### 1.2 完整解法

```bash
# LeetCode 192. 统计词频
# ① tr -s ' ' '\n'：空格 → 换行（每个词一行，压缩连续空格）
# ② sort：排序（uniq 的前提）
# ③ uniq -c：统计频次（格式：次数 词）
# ④ sort -rn：按次数降序（-r 反序、-n 数值）
# ⑤ awk 交换列（次数在前 → 词在前）
cat words.txt \
  | tr -s ' ' '\n' \
  | sort \
  | uniq -c \
  | sort -rn \
  | awk '{print $2, $1}'

# 更简洁的等价写法：
# tr -s ' ' '\n' < words.txt | sort | uniq -c | sort -rn | awk '{print $2" "$1}'
```
```
推演 words.txt = "the day is sunny the the":
  拆词：the / day / is / sunny / the / the
  sort：day / is / sunny / the / the / the
  uniq -c：1 day / 1 is / 1 sunny / 3 the
  sort -rn：3 the / 1 sunny / 1 is / 1 day
  输出：the 3 / day 1 / is 1 / sunny 1（同频任意序）✓
```

> 🎯 **要点**：四段管道——`tr` 拆词、`sort` 排序、`uniq -c` 计数、`sort -rn` 降序。**uniq 必须配 sort**（只处理相邻重复）是本题第一考点。

## 2. 193. 有效电话号码

### 2.1 题目与思路

```
验证电话号码格式（两种合法格式）
grep -E 扩展正则匹配
⚠️ 格式：(xxx) xxx-xxxx 或 xxx-xxx-xxxx（x 是数字）
```

### 2.2 完整解法

```bash
# LeetCode 193. 有效电话号码
# ⚠️ 两种合法格式：
#   格式 1：(xxx) xxx-xxxx
#   格式 2：xxx-xxx-xxxx
# 正则：^ 开头、$ 结尾（整行匹配）、[0-9]{3} 三位数字
grep -E '^(\([0-9]{3}\) |[0-9]{3}-)[0-9]{3}-[0-9]{4}$' file.txt
```
```
推演：
  "987-123-4567"      → 格式 2 ✓
  "(123) 456-7890"    → 格式 1 ✓
  "(123) 456-7890"（行尾空格）→ ✗（$ 锚定）
  "123-456-789"       → ✗（只有 9 位）
  "123-456-78901"     → ✗（11 位）
```

> 🎯 **要点**：`^...$` 整行锚定 + `\(` 转义括号 + `[0-9]{3}` 定长数字。**grep -E** 用扩展正则（否则 `{3}` 需转义 `\{3\}`）。行首行尾的空格都会导致匹配失败（严格锚定）。

## 3. 194. 转置文件

### 3.1 题目与思路

```
矩阵文件转置（行列互换）
awk 二维数组：a[行,列] 存储 → 按列输出
⚠️ 列数取最大值（各行可能不等长）
```

### 3.2 完整解法

```bash
# LeetCode 194. 转置文件
awk '{
    # ① 每行按列存入二维数组
    for (i = 1; i <= NF; i++) {
        a[NR, i] = $i        # a[行号, 列号] = 值
    }
    # ② 记录最大列数
    if (NF > maxCols) maxCols = NF
}
END {
    # ③ 按列输出（列变行）
    for (j = 1; j <= maxCols; j++) {
        line = ""
        for (i = 1; i <= NR; i++) {
            if (line != "") line = line " "
            line = line a[i, j]
        }
        print line
    }
}' file.txt
```
```
推演：
  name age        → 转置 →
  alice 21          name alice
  ryan 30           age 21 30
  （2×2 → 2×2）
  更复杂 3×2 → 2×3 ✓
```

> 🎯 **要点**：awk `a[NR,i]` 二维数组存储 + END 块按列拼接输出。**NF 动态列数**（取 max）与**空格拼接**（行间不尾随空格）是两个细节。awk 数组是稀疏关联数组，天然支持二维。

## 4. 195. 第十行

### 4.1 题目与思路

```
打印第 10 行（文件可能不足 10 行 → 无输出）
sed -n '10p' 最简
⚠️ 多种写法都要会（面试常问替代方案）
```

### 4.2 完整解法

```bash
# LeetCode 195. 第十行

# 写法一：sed（最简）
sed -n '10p' file.txt

# 写法二：awk
awk 'NR == 10' file.txt

# 写法三：head + tail
head -10 file.txt | tail -1

# 写法四：while 循环
n=0
while read line && [ $n -le 10 ]; do
    n=$((n + 1))
    if [ $n -eq 10 ]; then
        echo "$line"
        break
    fi
done < file.txt
```
```
边界：
  10 行文件 → 打印第 10 行 ✓
  5 行文件 → 无输出（sed 不匹配即静默）✓
  空文件 → 无输出 ✓
```

> 🎯 **要点**：`sed -n '10p'`（-n 静默 + p 打印指定行）是最简答案；awk `NR==10` 语义最清晰。**不足 10 行无输出**是隐藏边界——所有写法行为一致。

## 5. Shell 方法论总结

### 5.1 解题框架

```
① 输出形状：行/列/排序？
② 工具选型：
   找行 → grep（正则）
   改流/定位 → sed
   拆列/统计 → awk
   字符转换 → tr
   排序去重 → sort/uniq
③ 管道串联（流式处理）
④ 边界验证（空/不足/尾随空格）

⚠️ 识别信号：
  "词频/计数" → sort + uniq -c
  "格式验证" → grep -E 正则
  "转置/列变换" → awk 数组
  "第 N 行" → sed -n
```

### 5.2 四题工具对照

| 题目 | 工具链 | 核心考点 |
|------|--------|---------|
| 192 词频 | tr+sort+uniq+awk | uniq 先 sort |
| 193 电话 | grep -E | ^$ 锚定 + 转义 |
| 194 转置 | awk 二维数组 | NR/NF + 拼接 |
| 195 第十行 | sed -n '10p' | 静默模式 |

### 5.3 自测清单

```
□ 管道顺序正确？
□ uniq 前有 sort？
□ 正则整行锚定（^$）？
□ awk 分隔符/列号？
□ sed -n 静默？
□ 边界（空/不足行）？
□ 输出格式（无尾随空格）？
```
