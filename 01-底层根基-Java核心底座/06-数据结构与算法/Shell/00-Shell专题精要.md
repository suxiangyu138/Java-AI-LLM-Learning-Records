## 1. 核心概念

### 1.1 Shell 题考什么

```
Shell 标签题 = LeetCode 上的 Shell 脚本题
  核心：文本流处理（管道思想）

三大工具：
  grep：文本搜索（正则）
  sed：流编辑（替换/删除）
  awk：文本分析（字段处理/统计）★ 最常用

设计哲学：单一功能 + 管道组合
  cat file | grep xxx | awk '{print $1}'
```

### 1.2 识别信号

```
"Shell 脚本/命令行" → Shell 标签
"词频统计/转置/第 N 行" → Shell 模板题
"文件处理" 且要求命令行 → Shell

⚠️ 面试定位：
  运维/DevOps/大数据岗必考
  纯算法岗很少考
  4 道 LeetCode Shell 题（192-195）覆盖全部考点
```

### 1.3 核心能力：管道

```
管道（|）：前一个命令的输出 → 后一个命令的输入

思想：把复杂任务分解成小步骤
  每个命令做一件事 → 组合解决

例（词频统计）：
  cat → tr（分词）→ sort（排序）→ uniq（计数）→ sort（排序）

⚠️ 与算法题的类比：
  管道 = 函数组合（f(g(h(x)))）
  每个命令 = 一个纯函数（输入流 → 输出流）
```

## 2. 完整代码模板

### 2.1 192. 统计词频

```bash
# 单词按行输出 → 排序 → 计数 → 按次数排序
cat words.txt \
  | tr -s ' ' '\n' \        # 空格转换行（-s 压缩重复）
  | sort \                  # 排序（相同单词相邻）
  | uniq -c \               # 计数（-c 加次数前缀）
  | sort -rn \              # 按次数降序（-r 反转 -n 数值）
  | awk '{print $2, $1}'    # 交换列：单词 次数

# 推演 "the day is sunny the the":
# tr → the\nday\nis\nsunny\nthe\nthe
# sort → day\nis\nsunny\nthe\nthe\nthe
# uniq -c → 1 day / 1 is / 1 sunny / 3 the
# sort -rn → 3 the / 1 sunny / 1 is / 1 day
# awk → "the 3" "sunny 1" "is 1" "day 1" ✓
```

### 2.2 193. 有效电话号码（grep 正则）

```bash
# 两种格式：(xxx) xxx-xxxx 或 xxx-xxx-xxxx
grep -E '^(\([0-9]{3}\) |[0-9]{3}-)[0-9]{3}-[0-9]{4}$' file.txt

# 正则拆解：
# ^               开头
# (\([0-9]{3}\) |   "(xxx) " 格式
# [0-9]{3}-)       "xxx-" 格式（二选一）
# [0-9]{3}-        "xxx-"
# [0-9]{4}$        "xxxx" 结尾

# ⚠️ grep -E = 扩展正则（egrep）
# 基础正则需转义 () 和 {} → 面试用 -E 更清晰
```

### 2.3 194. 转置文件（awk 二维数组）

```bash
# 行列互换（awk 二维数组）
awk '{ for (i = 1; i <= NF; i++) {
         a[NR, i] = $i          # 存第 NR 行第 i 列
       }
       if (NF > max) max = NF }  # 记录最大列数
     END {
       for (j = 1; j <= max; j++) {
         for (i = 1; i <= NR; i++) {
           printf "%s%s", a[i, j], (i == NR ? "\n" : " ")
         }
       }
     }' file.txt

# 输入：name age
#      alice 21
# 输出：name alice
#      age 21
# ⚠️ NR = 行号，NF = 当前行字段数，$i = 第 i 列
```

### 2.4 195. 第十行（三种解法）

```bash
# 方法一：sed 打印第 10 行（最简洁）
sed -n '10p' file.txt
# -n 不自动打印；10p 打印第 10 行

# 方法二：awk
awk 'NR == 10' file.txt

# 方法三：head + tail
head -n 10 file.txt | tail -n 1
# ⚠️ 文件不足 10 行时：
#   sed/awk 输出空；head|tail 也可能空（tail 无行）
#   ⚠️ 注意：若文件 < 10 行，应输出空（不是报错）
```

## 3. 三剑客详解

### 3.1 grep（行匹配）

```bash
# 基本用法
grep 'pattern' file           # 包含 pattern 的行
grep -v 'pattern' file        # 不包含（反向）
grep -i 'pattern' file        # 忽略大小写
grep -c 'pattern' file        # 计数
grep -E '正则' file           # 扩展正则

# ⚠️ 常见正则：
#   ^abc 开头 / abc$ 结尾 / a.b 任意字符
#   [0-9] 数字类 / (a|b) 或
```

### 3.2 sed（流编辑）

```bash
sed -n '10p' file             # 打印第 10 行
sed -n '5,10p' file           # 打印 5-10 行
sed 's/old/new/g' file        # 全局替换
sed '/pattern/d' file         # 删除匹配行
sed -i 's/old/new/' file      # ⚠️ -i 原地修改（小心！）

# ⚠️ 面试高频：sed -n 'Np' 取第 N 行
#   s/old/new/g：g 全局（不写只替换每行第一个）
```

### 3.3 awk（字段分析）★ 最常用

```bash
awk '{print $1}' file          # 第一列
awk '{print $NF}' file         # 最后一列（NF=列数）
awk -F',' '{print $2}' file    # 指定分隔符（逗号）
awk 'NR == 10' file            # 第 10 行
awk '{sum += $1} END {print sum}'   # 求和（END 最后执行）

# 内置变量：
#   $0 整行 / $1..$N 各列 / NR 行号 / NF 列数 / FS 分隔符

# ⚠️ 面试核心：$N 取列 + NR/NF 控制行与列
```

## 4. 管道思想与正则

### 4.1 管道 = 数据流处理

```
与算法类比：
  管道 = 函数组合
  sort = 排序算法
  uniq -c = 计数（哈希）
  awk = 映射/归约

⚠️ 面试表达：
"管道把任务分解：分词 → 排序 → 计数 →
 排序 → 格式化。每个命令一个职责，
 组合解决复杂问题——类似函数的组合。"
```

### 4.2 常用正则速查

| 符号 | 含义 | 示例 |
|:---:|------|------|
| `^` | 开头 | `^The` |
| `$` | 结尾 | `end$` |
| `.` | 任意字符 | `a.c` |
| `[0-9]` | 数字类 | `[0-9]{3}` |
| `[a-z]` | 小写类 | `[a-z]+` |
| `*` | 0 次以上 | `a*` |
| `+` | 1 次以上 | `a+` |
| `{n}` | 恰好 n 次 | `[0-9]{3}` |
| `(a\|b)` | 或 | `(cat\|dog)` |
| `\s` | 空白 | `\s+` |

```
⚠️ grep 正则注意：
  基础正则：+ ? | 需要转义
  grep -E：直接使用（推荐）
```

### 4.3 常见命令组合

```bash
# 排序统计
sort | uniq -c | sort -rn

# 字段提取 + 求和
awk '{sum += $N} END {print sum}'

# 行选择 + 替换
sed -n 'Np' | sed 's/x/y/g'

# 去重
sort -u file

# ⚠️ 面试准备：掌握 sort/uniq/tr/awk/sed/grep 六个命令
#   足够覆盖 LeetCode Shell 全部题目
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"统计词频用管道分解：tr 把空格转成换行
 得到每行一个单词，sort 排序后 uniq -c
 计数，sort -rn 按次数降序，最后 awk
 调整输出格式。每步一个小工具，组合解决。
 类似算法的函数组合思想。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 管道思想？ | 每命令一个职责 → 流式组合（函数组合类比） |
| 2 | awk 核心？ | $N 取列 + NR/NF 控制 + END 汇总 |
| 3 | grep -E？ | 扩展正则（无需转义 + ? |） |
| 4 | 第 N 行几种写法？ | sed -n 'Np' / awk 'NR==N' / head|tail |
| 5 | uniq 为什么先 sort？ | uniq 只去重相邻行（需排序） |
| 6 | 转置文件思路？ | awk 二维数组 a[NR,i] 存储 + 交换循环 |
| 7 | -i 原地修改注意？ | 会覆盖原文件（先备份） |
| 8 | 与算法题类比？ | 管道=函数组合；uniq=计数；awk=映射 |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| uniq 前忘 sort | 计数错误 | 先 sort |
| grep 忘 -E | 正则失效 | 加 -E |
| awk $0/$1 混淆 | 取错列 | $0 整行 $1 首列 |
| tr 忘 -s | 多空格干扰 | tr -s |
| sort 忘 -n | 字典序而非数值 | sort -n |

> 🎯 **核心要点**：Shell = **管道组合 + 三剑客（grep/sed/awk）**。识别信号："Shell 脚本、词频统计、转置文件"。四道 LeetCode Shell 题（192-195）覆盖全部考点；awk 的 NR/NF/$N 与"先 sort 再 uniq"是两个核心细节。
