## 1. 核心概念

### 1.1 矩阵问题分类

```
① 原地变换：旋转/翻转（48 旋转图像）
② 边界模拟：螺旋遍历（54 螺旋矩阵）
③ 区域修改：置零（73 矩阵置零）
④ 网格搜索：DFS/BFS（见 BFS/DFS 体系）
⑤ 路径/DP：网格 DP（62 不同路径）

三大核心技巧：
  转置+翻转（旋转）
  四边界模拟（螺旋）
  首行首列标记（置零）
```

### 1.2 下标规律（必背）

```
转置：matrix[i][j] ↔ matrix[j][i]
水平翻转：matrix[i][j] ↔ matrix[i][n-1-j]
垂直翻转：matrix[i][j] ↔ matrix[m-1-i][j]

顺时针 90° = 转置 + 水平翻转
逆时针 90° = 转置 + 垂直翻转
旋转 180° = 水平翻转 + 垂直翻转

⚠️ 转置时 j 从 i+1 开始（对角线不动）
⚠️ 行数 m = matrix.length，列数 n = matrix[0].length
```

### 1.3 遍历顺序

```
行优先：for i → for j（缓存友好）★ 默认
列优先：for j → for i（按列处理时）
螺旋：四边界收缩（top/bottom/left/right）
对角线：i+j 或 i-j 的常数规律

⚠️ 矩阵题的边界：
  空矩阵（m=0 或 n=0）
  单行/单列（螺旋要 break）
  方阵 vs 矩形（旋转只对方阵）
```

## 2. 完整代码模板

### 2.1 48. 旋转图像（转置 + 翻转）

```java
/**
 * LeetCode 48. 旋转图像（顺时针 90°，原地）
 */
public void rotate(int[][] matrix) {
    int n = matrix.length;

    // ① 转置（沿主对角线）
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {    // ⚠️ j 从 i+1
            int tmp = matrix[i][j];
            matrix[i][j] = matrix[j][i];
            matrix[j][i] = tmp;
        }
    }

    // ② 水平翻转（每行左右交换）
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n / 2; j++) {
            int tmp = matrix[i][j];
            matrix[i][j] = matrix[i][n - 1 - j];
            matrix[i][n - 1 - j] = tmp;
        }
    }
}
// O(n²) 时间 O(1) 空间

// 推演 3×3：
// 原始:     转置后:     水平翻转后:
// 1 2 3     1 4 7       7 4 1
// 4 5 6  →  2 5 8   →   8 5 2
// 7 8 9     3 6 9       9 6 3
//                       = 顺时针 90° ✓
```

### 2.2 54. 螺旋矩阵（四边界模拟）

```java
/**
 * LeetCode 54. 螺旋矩阵（四边界收缩）
 */
public List<Integer> spiralOrder(int[][] matrix) {
    List<Integer> result = new ArrayList<>();
    int top = 0, bottom = matrix.length - 1;
    int left = 0, right = matrix[0].length - 1;

    while (top <= bottom && left <= right) {
        for (int j = left; j <= right; j++)      // 上边 →
            result.add(matrix[top][j]);
        top++;

        for (int i = top; i <= bottom; i++)      // 右边 ↓
            result.add(matrix[i][right]);
        right--;

        if (top > bottom || left > right) break; // ⚠️ 单行/列防重复！

        for (int j = right; j >= left; j--)      // 下边 ←
            result.add(matrix[bottom][j]);
        bottom--;

        for (int i = bottom; i >= top; i--)      // 左边 ↑
            result.add(matrix[i][left]);
        left++;
    }
    return result;
}
// ⚠️ 走完上边和右边后检查边界交叉
// （单行 [[1,2,3]]：不 break 会重复添加）
```

### 2.3 73. 矩阵置零（首行首列标记）

```java
/**
 * LeetCode 73. 矩阵置零（O(1) 空间）
 * 用首行首列作为标记位
 */
public void setZeroes(int[][] matrix) {
    int m = matrix.length, n = matrix[0].length;
    boolean firstRowZero = false, firstColZero = false;

    // ① 记录首行首列本身是否需要置零
    for (int j = 0; j < n; j++) if (matrix[0][j] == 0) firstRowZero = true;
    for (int i = 0; i < m; i++) if (matrix[i][0] == 0) firstColZero = true;

    // ② 用首行首列做标记（其他行列）
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            if (matrix[i][j] == 0) {
                matrix[i][0] = 0;    // 标记第 i 行
                matrix[0][j] = 0;    // 标记第 j 列
            }
        }
    }

    // ③ 根据标记置零（⚠️ 不能边扫边改：连锁反应！）
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            if (matrix[i][0] == 0 || matrix[0][j] == 0) {
                matrix[i][j] = 0;
            }
        }
    }

    // ④ 处理首行首列本身
    if (firstRowZero) Arrays.fill(matrix[0], 0);
    if (firstColZero) for (int i = 0; i < m; i++) matrix[i][0] = 0;
}
```

## 3. 下标变换规律详解

### 3.1 旋转的组合推导

```
为什么"转置 + 水平翻转"= 顺时针 90°？

以 (i, j) 为例：
  转置后 → (j, i)
  水平翻转后 → (j, n-1-i)

顺时针 90° 的目标：原 (i,j) 应到 (j, n-1-i)
  ✓ 与组合结果一致

记忆："先转置，再翻边"
  顺时针 → 水平翻转；逆时针 → 垂直翻转
  旋转 180° → 翻转两次
```

### 3.2 240. 搜索二维矩阵 II（右上角走法）

```java
/**
 * LeetCode 240. 搜索二维矩阵 II
 * 行升序 + 列升序 → 右上角出发走"二叉搜索树"
 */
public boolean searchMatrix(int[][] matrix, int target) {
    int i = 0, j = matrix[0].length - 1;   // 右上角

    while (i < matrix.length && j >= 0) {
        if (matrix[i][j] == target) return true;
        else if (matrix[i][j] > target) j--;   // ⚠️ 大了 → 左移
        else i++;                               // 小了 → 下移
    }
    return false;
}
// O(m+n)：每次排除一行或一列
// 为什么右上角？该位置"行最小、列最大"→ 双向可决策
```

### 3.3 对角线遍历（498）

```
对角线规律：
  主对角线方向（↘）：i - j 为常数
  副对角线方向（↙）：i + j 为常数

例（对角线遍历 498）：
  偶数对角线向下，奇数对角线向上
  方向切换 + 边界回折

⚠️ 面试频率低，掌握"i±j 常数"规律即可
```

## 4. 矩阵的搜索技巧

### 4.1 展平二分（74. 搜索二维矩阵）

```java
/**
 * LeetCode 74. 搜索二维矩阵
 * 行首 > 前一行尾 → 可展平为一维有序数组
 */
public boolean searchMatrix(int[][] matrix, int target) {
    int m = matrix.length, n = matrix[0].length;
    int lo = 0, hi = m * n - 1;

    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;
        int val = matrix[mid / n][mid % n];    // ⚠️ 一维 → 二维
        if (val == target) return true;
        else if (val < target) lo = mid + 1;
        else hi = mid - 1;
    }
    return false;
}
// 展平技巧：idx → (idx/n, idx%n)
```

### 4.2 网格遍历（DFS/BFS 的矩阵形式）

```
网格 = 矩阵 + 方向数组：
  int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};   // 四方向
  // 8 方向加对角

⚠️ 网格题细节：
  标记在递归前（防来回递归）
  沉岛/visited/回溯三选一（见 DFS 体系）
  边界判断先行（nx < 0 || nx >= m ...）
```

### 4.3 矩阵题的错误模式

```
① 边扫边改（73 置零）→ 连锁反应
   → 先标记再统一修改
② 螺旋忘 break（54）→ 重复添加
   → 边界交叉检查
③ 行/列混淆 → matrix[i][j] 先行后列
④ 空矩阵未处理 → matrix[0] 越界
   → m == 0 或 n == 0 前置判断
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"旋转 90° 我拆成两步：先转置（对角线交换），
 再水平翻转（每行反转）。O(n²) 原地完成，
 不用额外矩阵。
 关键细节：转置时 j 从 i+1 开始（对角线不动）；
 螺旋矩阵单行/列时记得 break 防重复。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 旋转为什么转置+翻转？ | 数学推导：90° 旋转 = 转置 + 水平翻转的组合 |
| 2 | 螺旋为什么单行 break？ | 走完上/右边后只剩一行 → 下/左边会重复 |
| 3 | 置零为什么不能边扫边改？ | 已置 0 的行影响后续判断（连锁反应）→ 先标记 |
| 4 | 展平怎么映射？ | idx → (idx/n, idx%n) |
| 5 | 右上角走法原理？ | 该位置行最小列最大 → 大左移小下移（二叉搜索） |
| 6 | 行/列习惯？ | m 行 n 列；matrix[i][j] 先行后列 |
| 7 | 原地 vs 额外空间？ | 要求 O(1) → 转置翻转/标记法；否则简单 |
| 8 | 空矩阵处理？ | m==0 或 n==0 前置判断 |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 转置 j 从 0 | 换两次还原 | j = i+1 |
| 螺旋忘 break | 重复添加 | 边界交叉检查 |
| 置零边扫边改 | 连锁反应 | 先标记后修改 |
| 展平映射错 | 越界/错位 | mid/n、mid%n |
| 空矩阵访问 | 越界 | 前置判断 |

> 🎯 **核心要点**：矩阵三套路 = **转置+翻转**（旋转）、**四边界**（螺旋 + break）、**首行首列标记**（置零）。识别信号："旋转、螺旋、置零、搜索"。下标规律（i↔j、n-1-j）必须背熟，搜索技巧（展平二分/右上角走法）是加分项。
