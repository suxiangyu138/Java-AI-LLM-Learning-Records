## 1. 核心概念

### 1.1 贪心的本质

> 贪心：每步做**局部最优**选择，希望累积成全局最优。**不可反悔**——选完无法回退（vs DP 可回退）。

```
两大性质（判定标准）：
  ① 贪心选择性质：局部最优选择在全局最优解中
  ② 最优子结构：全局最优含子问题最优

⚠️ 反例识别（面试必答）：
  0-1 背包：按单位价值贪心会堵死最优组合
  奇葩硬币找零：1/3/4 找 6 元 → 贪心 4+1+1
    ≠ 最优 3+3
  → 局部最优危害全局 → 用 DP
```

### 1.2 识别信号

```
"求最大/最小/最少" + 决策可分步 → 贪心候选
"区间选择/调度" → 贪心（435/452）
"资源分配" → 贪心（455/135）

⚠️ 90% 贪心题需要排序！
  找不到排序角度的策略往往有问题

⚠️ 面试必答：
"贪心不可反悔——每步选择定型。
 0-1 背包是经典反例（局部最优危害全局）。"
```

### 1.3 题型全景

```
① 分配类：455 饼干（最小满足最小）、135 糖果（两趟）
② 区间类：435 无重叠、452 气球、56 合并（★ 核心）
③ 序列类：122 股票（累加上涨段）、763 划分字母
④ 数学类：462 中位数、991 逆向思维
⑤ 反悔贪心：630 课程表 III（堆+反悔）

⚠️ 区间调度是教科书级考点
```

## 2. 完整代码模板

### 2.1 435. 无重叠区间（区间调度母题）

```java
/**
 * LeetCode 435. 无重叠区间
 * 移除最少使剩余不重叠 = 保留最多不重叠
 * 贪心：按结束时间排序，优先保留结束最早的
 */
public int eraseOverlapIntervals(int[][] intervals) {
    // ⚠️ 按结束时间升序排序（让出空间）
    Arrays.sort(intervals, (a, b) -> a[1] - b[1]);

    int count = 0;
    int lastEnd = Integer.MIN_VALUE;

    for (int[] interval : intervals) {
        if (interval[0] >= lastEnd) {
            lastEnd = interval[1];     // 不重叠 → 保留
        } else {
            count++;                   // 重叠 → 丢弃
        }
    }
    return count;
}
// 推演 [[1,2],[2,3],[3,4],[1,3]]：
//   按结束排序：[[1,2],[2,3],[1,3],[3,4]]
//   [1,2]保留 → [2,3]保留 → [1,3]重叠丢弃 → [3,4]保留
//   返回 1 ✓
// 452 引爆气球 = 同一模型，唯一区别：端点相撞算重叠（>）
```

### 2.2 455. 分发饼干（最小满足最小）

```java
/**
 * LeetCode 455. 分发饼干（贪心入门第一题）
 * 最小饼干满足最小胃口（不浪费大饼干）
 */
public int findContentChildren(int[] g, int[] s) {
    Arrays.sort(g);                    // 胃口排序
    Arrays.sort(s);                    // 饼干排序

    int child = 0, cookie = 0;
    while (child < g.length && cookie < s.length) {
        if (s[cookie] >= g[child]) {
            child++;                   // 满足一个孩子
        }
        cookie++;                      // 饼干消耗或丢弃
    }
    return child;
}
// 证明（归纳）：
//   最小饼干 ≥ 最小胃口 → 给它（最优，大饼干留给大胃口）
//   最小饼干 < 最小胃口 → 这块饼干满足不了任何人（丢弃）
// 复杂度 O(n log n)（排序主导）
```

### 2.3 135. 分发糖果（两趟遍历）

```java
/**
 * LeetCode 135. 分发糖果（Hard 经典）
 * 相邻孩子中评分高的必须获得更多糖果
 * 双向约束 → 两趟遍历
 */
public int candy(int[] ratings) {
    int n = ratings.length;
    int[] candies = new int[n];
    Arrays.fill(candies, 1);        // 每人至少 1 颗

    // ① 左到右：处理"右边评分高"
    for (int i = 1; i < n; i++) {
        if (ratings[i] > ratings[i - 1]) {
            candies[i] = candies[i - 1] + 1;
        }
    }

    // ② 右到左：处理"左边评分高"（⚠️ 取 max 兼顾）
    for (int i = n - 2; i >= 0; i--) {
        if (ratings[i] > ratings[i + 1]) {
            candies[i] = Math.max(candies[i], candies[i + 1] + 1);
        }
    }

    int sum = 0;
    for (int c : candies) sum += c;
    return sum;
}
// ⚠️ 第二趟为什么取 max？
//   直接赋值会覆盖第一趟的结果（违反右高约束）
// 面试常问："为什么不能一趟完成？"
//   → 双向依赖，一趟只能满足一个方向
```

## 3. 正确性证明方法

### 3.1 交换论证法（最常用）

```
证明思路：
  ① 假设存在一个最优解 O
  ② 用贪心选择 g 替换 O 中的某个选择 → 得到 O'
  ③ 证明 O' 不比 O 差（代价/数量/收益）
  ④ 由归纳可得：贪心解 = 最优解

以 435 无重叠区间为例：
  贪心策略：保留结束最早的区间
  假设最优解 O 的第一个区间不是结束最早的 g
  → 用 g 替换 O 的第一个区间
  → g 结束更早 → 与后续区间冲突更少
  → O' 不差于 O ✓ → 贪心最优
```

### 3.2 数学归纳法

```
证明思路：
  ① 基础：第一步贪心选择正确
  ② 归纳：假设前 k 步贪心正确
  ③ 递推：第 k+1 步贪心选择正确
  → 贪心解 = 最优解

例：455 分发饼干
  最小饼干 ≥ 最小胃口 → 给（贪心最优，不浪费）
  最小饼干 < 最小胃口 → 该饼干无法满足任何人（丢弃）
  → 每步正确，归纳成立
```

### 3.3 面试表达

```
"我证明贪心正确性用的是交换论证：
 假设最优解不以我的贪心选择开头，
 用贪心选择替换后结果不会更差，
 所以贪心选择可以出现在最优解中，
 反复替换得到贪心解 = 最优解。"
```

## 4. 反例识别

### 4.1 经典反例一：0-1 背包

```
背包容量 10：
  物品 A：重量 6，价值 30
  物品 B：重量 5，价值 25
  物品 C：重量 5，价值 25

贪心按单位价值选：A(6,30) → 剩余 4 装不下 → 总价值 30
最优解：B + C = 重量 10，价值 50！

为什么失败：选 A 虽然单位价值最高，
但占用了大量容量 → 阻碍后续更好的组合
→ 不满足贪心选择性质 → 必须用 DP
```

### 4.2 经典反例二：硬币找零

```
面额 1/3/4 元，找 6 元：
  贪心（优先大面额）：4 + 1 + 1 = 3 枚
  最优解：3 + 3 = 2 枚！

为什么失败：4 元硬币虽然单枚价值大，
但组合不灵活 → 贪婪选大面额并非最优

⚠️ 标准面额（1/5/10）贪心正确（硬币系统性质）
```

### 4.3 反例识别清单

| 场景 | 能否贪心 | 原因 |
|------|:---:|------|
| 0-1 背包 | ❌ | 选物品影响后续容量 |
| 部分背包（可切分） | ✅ | 单位价值贪心正确 |
| 普通硬币找零 | ✅ | 1/5/10 标准面额 |
| 奇葩面额找零 | ❌ | 组合不灵活 |
| 无负权最短路 (Dijkstra) | ✅ | 贪心+堆 |
| 负权最短路 | ❌ | 需 Bellman-Ford |
| 区间调度 | ✅ | 结束时间排序 |

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"这题用贪心：我定义局部最优为【...】（度量标准）。
 每步选择【...】（贪心策略）。
 正确性证明：交换论证——假设最优解不以我的选择
 开头，替换后不更差，因此贪心解 = 最优解。
 复杂度：排序 O(n log n) + 线性扫描 O(n)。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 怎么判断能用贪心？ | 找反例失败 + 交换论证证明 |
| 2 | 为什么按结束排序？ | 结束早留出空间多（让出资源） |
| 3 | 贪心 vs DP？ | 贪心不可反悔；DP 比较所有子问题 |
| 4 | 给个反例？ | 0-1 背包/奇葩硬币找零 |
| 5 | 为什么先排序？ | 90% 贪心需要排序（匹配/区间） |
| 6 | 两趟为什么取 max？ | 兼顾双向约束（不覆盖第一趟） |
| 7 | 反悔贪心？ | 堆保存历史选择，超限放弃最差（630） |
| 8 | 什么时候 DP 兜底？ | 无法证明贪心正确时 |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 贪心失效无察觉 | 答案错 | 先试反例 |
| 排序键选错 | 结果错 | 按目标选排序键 |
| 两趟直接赋值 | 覆盖第一趟 | 取 max |
| 端点处理错 | 重叠判定反 | >= vs > |
| 忘证明 | 面试减分 | 交换论证 |

> 🎯 **核心要点**：贪心 = **策略 + 证明 + 反例意识**。区间调度（435/452）与分配（455/135）是最高频；"90% 要排序"、"交换论证"、"0-1 背包反例"三句话是面试必答。反悔贪心（630）是进阶分水岭。
