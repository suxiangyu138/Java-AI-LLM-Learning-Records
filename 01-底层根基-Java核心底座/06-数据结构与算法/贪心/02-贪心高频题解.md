## 1. 455. 分发饼干

### 1.1 完整实现（最小满足最小）

```java
/**
 * LeetCode 455. 分发饼干（贪心入门第一题）
 * 最小饼干满足最小胃口（不浪费大饼干）
 */
public int findContentChildren(int[] g, int[] s) {
    Arrays.sort(g);                    // 胃口排序
    Arrays.sort(s);                    // 饼干排序

    int child = 0, cookie = 0;
    while (child < g.length && cookie < s.length) {
        if (s[cookie] >= g[child]) {
            child++;                   // 满足一个孩子
        }
        cookie++;                      // 饼干消耗或丢弃
    }
    return child;
}
// 推演 g=[1,2,3], s=[1,1] → 1 ✓
// 证明（归纳）：
//   最小饼干 ≥ 最小胃口 → 给它（最优，大饼干留给大胃口）
//   最小饼干 < 最小胃口 → 这块饼干满足不了任何人（丢弃）
// ⚠️ 面试必答："为什么最小满足最小？
//   交换论证：任何最优解可用'最小满足最小'
//   替换而不更差"
```

## 2. 135. 分发糖果

### 2.1 完整实现（两趟遍历）

```java
/**
 * LeetCode 135. 分发糖果（Hard 经典）
 * 相邻孩子中评分高的必须获得更多糖果
 * 双向约束 → 两趟遍历
 */
public int candy(int[] ratings) {
    int n = ratings.length;
    int[] candies = new int[n];
    Arrays.fill(candies, 1);        // 每人至少 1 颗

    // ① 左到右：处理"右边评分高"
    for (int i = 1; i < n; i++) {
        if (ratings[i] > ratings[i - 1]) {
            candies[i] = candies[i - 1] + 1;
        }
    }

    // ② 右到左：处理"左边评分高"（⚠️ 取 max 兼顾）
    for (int i = n - 2; i >= 0; i--) {
        if (ratings[i] > ratings[i + 1]) {
            candies[i] = Math.max(candies[i], candies[i + 1] + 1);
        }
    }

    int sum = 0;
    for (int c : candies) sum += c;
    return sum;
}
// 推演 [1,3,2,2,1]：
//   ① → [1,2,1,1,1]
//   ② → 位置 3: max(1,2)=2 → [1,2,1,2,1] → 和 7 ✓
// ⚠️ 面试必答：
//   "为什么第二趟取 max？直接赋值会覆盖
//    第一趟结果（违反右高约束）"
//   "为什么不能一趟完成？双向依赖"
```

## 3. 435. 无重叠区间

### 3.1 完整实现（区间调度母题）

```java
/**
 * LeetCode 435. 无重叠区间
 * 移除最少使剩余不重叠 = 保留最多不重叠
 * 贪心：按结束时间排序，优先保留结束最早的
 */
public int eraseOverlapIntervals(int[][] intervals) {
    // ⚠️ 按结束时间升序排序（让出空间）
    Arrays.sort(intervals, (a, b) -> a[1] - b[1]);

    int count = 0;
    int lastEnd = Integer.MIN_VALUE;

    for (int[] interval : intervals) {
        if (interval[0] >= lastEnd) {
            lastEnd = interval[1];     // 不重叠 → 保留
        } else {
            count++;                   // 重叠 → 丢弃
        }
    }
    return count;
}
// 推演 [[1,2],[2,3],[3,4],[1,3]]：
//   按结束排序：[[1,2],[2,3],[1,3],[3,4]]
//   [1,2]保留 → [2,3]保留 → [1,3]重叠丢弃 → [3,4]保留
//   返回 1 ✓
// ⚠️ 交换论证（面试必讲）：
//   "结束最早 → 留出空间多 → 替换最优解
//    第一个区间不更差 → 贪心最优"
```

## 4. 452. 用最少数量的箭引爆气球

### 4.1 完整实现（435 孪生题）

```java
/**
 * LeetCode 452. 用最少数量的箭引爆气球
 * 一支箭 = 一组重叠气球（按结束排序）
 * ⚠️ 与 435 唯一区别：端点相撞算重叠
 */
public int findMinArrowShots(int[][] points) {
    // ⚠️ Integer.compare 防 int 溢出（区间可极大）
    Arrays.sort(points, (a, b) -> Integer.compare(a[1], b[1]));

    int arrows = 1;                        // 至少一支箭
    int lastEnd = points[0][1];

    for (int i = 1; i < points.length; i++) {
        // ⚠️ 端点相撞算重叠 → 用 > 而不是 >=
        if (points[i][0] > lastEnd) {
            arrows++;                      // 需要新箭
            lastEnd = points[i][1];
        }
    }
    return arrows;
}
// 推演 [[10,16],[2,8],[1,6],[7,12]] → 2 ✓
// ⚠️ 面试必答：
//   "435 vs 452 是同一模型，一字之差——
//    435 用 >=（相撞不重叠），452 用 >（相撞重叠）"
```

## 5. 56. 合并区间

### 5.1 完整实现（按开始排序）

```java
/**
 * LeetCode 56. 合并区间
 * 按开始排序 → 覆盖式扫描
 */
public int[][] merge(int[][] intervals) {
    Arrays.sort(intervals, (a, b) -> a[0] - b[0]);   // ⚠️ 按开始排序

    List<int[]> result = new ArrayList<>();
    int[] current = intervals[0];        // 当前合并区间

    for (int i = 1; i < intervals.length; i++) {
        if (intervals[i][0] <= current[1]) {
            // 重叠 → 扩展右边界（取较大结束）
            current[1] = Math.max(current[1], intervals[i][1]);
        } else {
            result.add(current);         // 不重叠 → 输出
            current = intervals[i];      // 开始新区间
        }
    }
    result.add(current);                 // ⚠️ 最后一个
    return result.toArray(new int[0][]);
}
// 推演 [[1,3],[2,6],[8,10],[15,18]] → [[1,6],[8,10],[15,18]] ✓
// ⚠️ 为什么按开始排序？
//   从早到晚扫描才能顺序合并（按结束会漏合并）
// ⚠️ 对比：435 按结束（选最多）；56 按开始（覆盖合并）
```

## 6. 763. 划分字母区间

### 6.1 完整实现（last 扩展边界）

```java
/**
 * LeetCode 763. 划分字母区间
 * 每个字母只出现在一个片段中
 * 预处理最后出现位置 + 贪心扩展右边界
 */
public List<Integer> partitionLabels(String s) {
    // ① 记录每个字符的最后位置
    int[] last = new int[26];
    for (int i = 0; i < s.length(); i++) {
        last[s.charAt(i) - 'a'] = i;
    }

    List<Integer> result = new ArrayList<>();
    int start = 0, end = 0;

    // ② 扫描并扩展边界
    for (int i = 0; i < s.length(); i++) {
        end = Math.max(end, last[s.charAt(i) - 'a']);  // 扩展右界

        if (i == end) {                    // ③ 到达片段边界
            result.add(end - start + 1);   // 分割
            start = i + 1;
        }
    }
    return result;
}
// 推演 "ababcbacadefegdehijhklij" → [9,7,8] ✓
// ⚠️ 贪心核心：
//   "当前片段的右边界 = 片段内所有字符
//    最后出现位置的最大值——扩展直到
//    所有字符的最后位置都在片段内"
```

## 7. 122. 买卖股票的最佳时机 II

### 7.1 完整实现（累加上涨段）

```java
/**
 * LeetCode 122. 买卖股票的最佳时机 II
 * 可以多次买卖（同时持有一股）→ 累加所有上涨段
 */
public int maxProfit(int[] prices) {
    int profit = 0;
    for (int i = 1; i < prices.length; i++) {
        if (prices[i] > prices[i - 1]) {
            profit += prices[i] - prices[i - 1];   // 只累加上涨段
        }
    }
    return profit;
}
// 推演 [7,1,5,3,6,4]：
//   累加 (5-1)+(6-3) = 4+3 = 7 ✓
// 证明：总利润 = 所有上涨段之和
//   一次完整交易（谷底买入、峰顶卖出）的利润
//   = 谷底到峰顶的累积上涨差之和
// ⚠️ 面试必答："为什么每天都判断？
//   涨就赚（当日卖出次日买回），跌不交易——
//   总利润 = Σ 正差值"
```

## 8. 860. 柠檬水找零

### 8.1 完整实现（优先大面额）

```java
/**
 * LeetCode 860. 柠檬水找零
 * 柠檬水 5 美元，顾客用 5/10/20 支付
 * 找零时优先用大面额（5 元最灵活）
 */
public boolean lemonadeChange(int[] bills) {
    int five = 0, ten = 0;

    for (int bill : bills) {
        if (bill == 5) {
            five++;                    // 收 5 元
        } else if (bill == 10) {
            if (five == 0) return false;   // 需要 5 元找零
            five--;
            ten++;
        } else {                       // 20 元
            if (ten > 0 && five > 0) {
                ten--;                 // ⚠️ 优先 10+5 组合
                five--;
            } else if (five >= 3) {
                five -= 3;             // 或 3 张 5 元
            } else {
                return false;
            }
        }
    }
    return true;
}
// 推演 [5,5,5,10,20] → true ✓
// ⚠️ 面试必答："为什么优先用 10 元？
//   5 元最灵活（5/10/20 都需要），10 元只能
//   用于 20 找零 → 优先消耗不灵活的"
```

## 9. 630. 课程表 III（反悔贪心）

### 9.1 完整实现

```java
/**
 * LeetCode 630. 课程表 III（Hard 进阶）
 * 贪心 + 反悔：超限时放弃已修中最长的
 */
public int scheduleCourse(int[][] courses) {
    // ① 按截止时间排序（越早截止越先安排）
    Arrays.sort(courses, (a, b) -> a[1] - b[1]);

    // ② 大根堆：存已修课程的时长（放弃时长最大的）
    PriorityQueue<Integer> heap = new PriorityQueue<>(
        (a, b) -> b - a);
    int time = 0;

    for (int[] course : courses) {
        int duration = course[0], lastDay = course[1];
        time += duration;
        heap.offer(duration);           // 先加入（贪心）

        if (time > lastDay) {           // ③ 超时 → 反悔
            time -= heap.poll();        // 放弃最长的课程
        }
    }
    return heap.size();                 // ④ 堆中 = 最终选的课程
}
// 推演 [[100,200],[200,1300],[1000,1250],[2000,3200]] → 3 ✓
// ⚠️ 面试必答：
//   "超限时放弃最长的——总数不变但总时间
//    更短，为未来留空间。堆保存历史选择
//    实现反悔（牺牲局部最优换全局最优）。"
```

## 10. 462. 最少移动次数使数组元素相等 II

### 10.1 完整实现（中位数原理）

```java
/**
 * LeetCode 462. 最少移动次数使数组元素相等 II
 * 每次移动把任意元素 +1 或 -1
 * 数学结论：目标值 = 中位数时总距离最小
 */
public int minMoves2(int[] nums) {
    Arrays.sort(nums);
    int median = nums[nums.length / 2];   // 中位数

    int moves = 0;
    for (int x : nums) {
        moves += Math.abs(x - median);    // 每个元素移动到中位数
    }
    return moves;
}
// 推演 [1,2,3] → 中位 2 → |1-2|+|2-2|+|3-2| = 2 ✓
// 为什么是中位数不是平均数？
//   平均数被极端值拉偏：[1,1,100] 中位 1 距离 99，
//   平均 34 距离 132 → 中位数远优
// ⚠️ 证明：绝对值不等式 Σ|x-ai| 在 x = 中位数最小
```
