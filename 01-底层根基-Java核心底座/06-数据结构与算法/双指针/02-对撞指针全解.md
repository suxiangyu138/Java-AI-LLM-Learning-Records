## 1. 对撞指针模板

```java
/**
 * 对撞指针通用模板
 * 适用：有序数组找两数、回文验证、面积问题
 * 关键：每轮 left 或 right 必移动一个（保证前进）
 *       移动方向由"排除不可能解"决定
 */
int left = 0, right = arr.length - 1;
while (left < right) {
    int sum = arr[left] + arr[right];   // 或计算面积/比较字符
    if (需要更大) {
        left++;                          // 左指针向右（值增大）
    } else if (需要更小) {
        right--;                         // 右指针向左（值减小）
    } else {
        // 找到答案
        break;
    }
}
```

## 2. 167. 两数之和 II

### 2.1 完整实现

```java
/**
 * LeetCode 167. 两数之和 II - 输入有序数组
 * 有序数组找和为 target 的两个数（1-indexed）
 *
 * 单调性论证（面试必讲）：
 *   sum < target → 移动 left（值变大，sum 增大）
 *   sum > target → 移动 right（值变小，sum 减小）
 *   每步排除"以该端点为准"的一批组合 → O(n)
 */
public int[] twoSum(int[] numbers, int target) {
    int left = 0, right = numbers.length - 1;

    while (left < right) {
        int sum = numbers[left] + numbers[right];
        if (sum == target) {
            return new int[]{left + 1, right + 1};   // 1-indexed
        } else if (sum < target) {
            left++;          // 需要更大的和
        } else {
            right--;         // 需要更小的和
        }
    }
    return new int[0];
}
```

### 2.2 推演：numbers = [2, 7, 11, 15], target = 9

```
left=0(2), right=3(15): sum=17 > 9 → right--  （排除 15 组合）
left=0(2), right=2(11): sum=13 > 9 → right--  （排除 11 组合）
left=0(2), right=1(7):  sum=9 == 9 → 返回 [1,2] ✓
共 3 轮 → O(n)
```

## 3. 11. 盛最多水的容器

### 3.1 完整实现

```java
/**
 * LeetCode 11. 盛最多水的容器
 * 找两条线，使容器盛水最多
 * 容量 = min(height[left], height[right]) × (right - left)
 *
 * 为什么移动矮边？（短板效应论证）
 *   容量由矮边决定：
 *     移动高边 → 宽度变小，高度不变 → 容量必变小 ❌
 *     移动矮边 → 宽度变小，但高度可能变大 → 有希望 ✅
 *   → 只有移动矮边才可能找到更优解 → 安全排除
 */
public int maxArea(int[] height) {
    int left = 0, right = height.length - 1;
    int maxWater = 0;

    while (left < right) {
        int width = right - left;
        int h = Math.min(height[left], height[right]);
        maxWater = Math.max(maxWater, width * h);

        // 移动矮的一边（关键是这条规则）
        if (height[left] < height[right]) {
            left++;
        } else {
            right--;
        }
    }
    return maxWater;
}
```

### 3.2 正确性论证（面试加分）

```
反证法：假设最优解是 (i*, j*)
  当 left 指向 i* 时，right 一定会在某个时刻指向 j*？
  —— 因为在到达 j* 前，所有被跳过的右边界 height[right] ≤ height[i*]
    （否则 left 不会移动：只有 height[left] < height[right] 才移动 left）
  —— 跳过这些右边界时，容量 ≤ height[i*] × (right - i*) 
       ≤ height[i*] × (j* - i*) = 最优解
  —— 所以被排除的组合不会比最优解更好 ✓
  （详细证明可简化表达为"短板效应 + 排除法"）
```

## 4. 15. 三数之和：固定+对撞

### 4.1 完整实现（含去重）

```java
/**
 * LeetCode 15. 三数之和（Hot 100 高频）
 * 找出数组中所有和为 0 的三元组（不重复！）
 *
 * 三步：
 *   ① 排序（去重与双指针的前提）
 *   ② 固定一个数 nums[i]
 *   ③ 在 [i+1, n) 上对撞找两数之和 = -nums[i]
 *
 * 去重三处（核心易错点）：
 *   ① 固定的数去重：nums[i] == nums[i-1] → 跳过
 *   ② 左指针去重：找到解后跳过相同值
 *   ③ 右指针去重：找到解后跳过相同值
 */
public List<List<Integer>> threeSum(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    Arrays.sort(nums);                       // ① 排序

    for (int i = 0; i < nums.length - 2; i++) {
        if (nums[i] > 0) break;              // 剪枝：正数后面更大
        if (i > 0 && nums[i] == nums[i - 1]) continue;   // ② 固定数去重

        int left = i + 1, right = nums.length - 1;
        int target = -nums[i];               // 找两数和 = -nums[i]

        while (left < right) {
            int sum = nums[left] + nums[right];
            if (sum == target) {
                res.add(Arrays.asList(nums[i], nums[left], nums[right]));
                // ③ 左右去重
                while (left < right && nums[left] == nums[left + 1]) left++;
                while (left < right && nums[right] == nums[right - 1]) right--;
                left++;
                right--;
            } else if (sum < target) {
                left++;
            } else {
                right--;
            }
        }
    }
    return res;
}
```

### 4.2 去重的关键理解

```
输入 [-1, 0, 1, 1, 2, -1, -4] 排序后 [-4, -1, -1, 0, 1, 1, 2]

固定的数：i=1 时 nums[1]=-1，i=2 时 nums[2]=-1
  → i=2 与 i=1 固定相同的数 → 产生相同结果 → 跳过 i=2 ✓
  （i > 0 且 nums[i] == nums[i-1] → continue）

左右指针：找到 [-1, 0, 1] 后，如果 left 指向的 1 和下一个 1 相同
  → 不跳过会再找到一份 [-1, 0, 1] → 必须去重
```

### 4.3 复杂度与变体

```
排序 O(n log n) + 固定 O(n) × 对撞 O(n) = O(n²)
空间 O(1)（忽略排序与结果存储）

变体：
  16. 最接近的三数之和 → 记录最小差值
  18. 四数之和 → 固定两个 + 对撞（O(n³)）
  259. 三数之和小于 K → 计数而非枚举
```

## 5. 125. 验证回文串

### 5.1 完整实现

```java
/**
 * LeetCode 125. 验证回文串
 * 忽略大小写和非字母数字字符，判断回文
 *
 * 对撞 + 跳过非法字符
 */
public boolean isPalindrome(String s) {
    int left = 0, right = s.length() - 1;

    while (left < right) {
        // 跳过非字母数字
        while (left < right && !Character.isLetterOrDigit(s.charAt(left))) {
            left++;
        }
        while (left < right && !Character.isLetterOrDigit(s.charAt(right))) {
            right--;
        }
        // 比较（忽略大小写）
        if (Character.toLowerCase(s.charAt(left))
            != Character.toLowerCase(s.charAt(right))) {
            return false;
        }
        left++;
        right--;
    }
    return true;
}
```

### 面试话术模板

```
"这题我用对撞指针：left 指向最左，right 指向最右，
 每轮比较两者之和（/面积/字符）。
 根据【单调性】，sum < target 时移动 left、sum > target
 时移动 right——因为有序数组保证指针移动方向与结果变化
 方向单调对应，被排除的组合不可能包含答案。
 时间 O(n)，空间 O(1)。"
```

> 🎯 **核心要点**：对撞指针是面试最常写的双指针——**有序找两数**（167）、**短板移动**（11）、**固定+对撞**（15）、**回文验证**（125）四大模板。每个模板都有"为什么要这样移动"的论证：167 靠有序单调性，11 靠短板效应，15 靠去重三处。能把"排除不可能解"的论证讲清楚，就是面试的区分度所在。
