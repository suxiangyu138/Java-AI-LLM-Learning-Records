## 1. 快慢指针的两种形态

### 1.1 数组形态：读写分工

```java
// slow 慢写（下一个保留元素的位置）
// fast 快读（扫描全部元素）
int slow = 0;
for (int fast = 0; fast < arr.length; fast++) {
    if (需要保留(arr[fast])) {
        arr[slow++] = arr[fast];   // 覆盖写入
    }
}
// 最终 arr[0..slow-1] 是保留结果，slow = 新长度
```

### 1.2 链表形态：速度分工

```java
// slow 走 1 步，fast 走 2 步
ListNode slow = head, fast = head;
while (fast != null && fast.next != null) {
    slow = slow.next;
    fast = fast.next.next;
}
// 应用：判环（相遇）、找中点（fast 到头时 slow 在中点）
```

### 1.3 快慢 vs 对撞

| 维度 | 快慢（同向） | 对撞（相向） |
|------|:---:|:---:|
| 方向 | 同向前进 | 两端向中间 |
| 核心 | 读写分工/速度差 | 单调排除 |
| 适用 | 原地修改、链表 | 有序找两数、回文 |
| 空间 | O(1) | O(1) |

## 2. 27. 移除元素：原地覆盖

### 2.1 完整实现

```java
/**
 * LeetCode 27. 移除元素
 * 原地移除所有值等于 val 的元素，返回新长度
 * [3,2,2,3], val=3 → 长度 2，数组前两位为 [2,2]
 *
 * 快慢指针：
 *   fast 扫描，slow 记录下一个保留位置
 *   arr[fast] != val → 保留，写入 arr[slow]
 */
public int removeElement(int[] nums, int val) {
    int slow = 0;
    for (int fast = 0; fast < nums.length; fast++) {
        if (nums[fast] != val) {
            nums[slow++] = nums[fast];   // 覆盖
        }
    }
    return slow;   // 新长度
}
```

### 2.2 推演：nums = [3, 2, 2, 3], val = 3

```
slow=0, fast=0: nums[0]=3 == val → 跳过
fast=1: nums[1]=2 ≠ 3 → nums[0]=2, slow=1 → [2,2,2,3]
fast=2: nums[2]=2 ≠ 3 → nums[1]=2, slow=2 → [2,2,2,3]
fast=3: nums[3]=3 == val → 跳过
返回 slow=2 ✓（前 2 位 [2,2]）
```

## 3. 26. 删除有序数组重复项

### 3.1 完整实现

```java
/**
 * LeetCode 26. 删除有序数组中的重复项
 * 原地去重，返回新长度
 * [0,0,1,1,1,2,2,3,3,4] → 5（[0,1,2,3,4]）
 *
 * 与 27 的差异：
 *   27 判断"是否等于 val"（固定值）
 *   26 判断"是否与上一个保留值不同"（动态值）
 */
public int removeDuplicates(int[] nums) {
    if (nums.length == 0) return 0;
    int slow = 1;                      // 第一个元素必然保留
    for (int fast = 1; fast < nums.length; fast++) {
        if (nums[fast] != nums[slow - 1]) {   // 与上一个保留值比较
            nums[slow++] = nums[fast];
        }
    }
    return slow;
}
```

### 3.2 变体：80. 删除重复 II（保留两个）

```java
/**
 * LeetCode 80. 删除有序数组重复 II
 * 每个元素最多出现两次
 * 通用解法：最多保留 k 个
 *   判断 nums[fast] != nums[slow - k] → 保留
 */
public int removeDuplicates2(int[] nums) {
    int k = 2;                        // 最多保留 2 个
    int slow = 0;
    for (int fast = 0; fast < nums.length; fast++) {
        // 前 k 个直接保留；之后与 slow-k 比较（滑动窗口思想）
        if (slow < k || nums[fast] != nums[slow - k]) {
            nums[slow++] = nums[fast];
        }
    }
    return slow;
}
// 26 题 = k=1 的特例！记忆：留 k 个看 slow-k
```

## 4. 283. 移动零

### 4.1 两种实现对比

```java
/**
 * LeetCode 283. 移动零
 * 把 0 移到末尾，非零保持相对顺序，原地
 * [0,1,0,3,12] → [1,3,12,0,0]
 */

// 写法一：先移非零，再补零
public void moveZeroes(int[] nums) {
    int slow = 0;
    for (int fast = 0; fast < nums.length; fast++) {
        if (nums[fast] != 0) {
            nums[slow++] = nums[fast];   // 非零前移
        }
    }
    while (slow < nums.length) {
        nums[slow++] = 0;                // 末尾补零
    }
}

// 写法二：交换法（保持"原地置换"语义）
public void moveZeroes_Swap(int[] nums) {
    int slow = 0;
    for (int fast = 0; fast < nums.length; fast++) {
        if (nums[fast] != 0) {
            int tmp = nums[slow];        // 与 slow 位置交换
            nums[slow] = nums[fast];
            nums[fast] = tmp;
            slow++;
        }
    }
}
```

### 4.2 三题对比：27 / 26 / 283

| 题 | 保留条件 | slow 起点 | 结尾处理 |
|:---:|------|:---:|------|
| 27 移除元素 | `!= val` | 0 | 无 |
| 26 去重 | `!= nums[slow-1]` | 1 | 无 |
| 283 移动零 | `!= 0` | 0 | **补零** |

> 💡 **记忆**：三个题都是"快读慢写"，区别只在**保留条件**。283 比 27 多一步补零（非零前移后尾部是旧值残留）。

## 5. 链表快慢指针应用

### 5.1 141. 环形链表（Floyd 判圈）

```java
/**
 * LeetCode 141. 环形链表
 * 快慢指针相遇 → 有环
 * 相对速度 1 → 任何环长必然相遇
 */
public boolean hasCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;           // 1 步
        fast = fast.next.next;      // 2 步
        if (slow == fast) return true;   // 相遇 → 有环
    }
    return false;                   // fast 先到 null → 无环
}
```

### 5.2 876. 链表的中间结点

```java
/**
 * LeetCode 876. 链表的中间结点
 * fast 到头时 slow 恰好在中间
 */
public ListNode middleNode(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    return slow;
}
// 应用：回文链表（234）、重排链表（143）、排序链表（148）的前置步骤
```

### 5.3 19. 删除链表倒数第 N 个结点

```java
/**
 * LeetCode 19. 删除链表的倒数第 N 个结点
 * fast 先走 N+1 步 → slow 停在待删节点前驱
 * 必须用 dummy（可能删除头节点）
 */
public ListNode removeNthFromEnd(ListNode head, int n) {
    ListNode dummy = new ListNode(-1);
    dummy.next = head;
    ListNode fast = dummy, slow = dummy;

    for (int i = 0; i <= n; i++) fast = fast.next;   // 先走 n+1

    while (fast != null) {           // 同步走
        fast = fast.next;
        slow = slow.next;
    }
    slow.next = slow.next.next;      // 删除
    return dummy.next;
}
```

### 面试话术模板

```
"这题用快慢指针（同向双指针）：
 fast 负责扫描，slow 负责记录保留位置。
 保留条件是【...】，满足就写入 arr[slow++]。
 每个元素只处理一次：O(n)，原地 O(1) 空间。"
```

> 🎯 **核心要点**：快慢指针的数组形态是**读写分工**（fast 扫描、slow 记录），链表形态是**速度分工**（1 步 vs 2 步）。27/26/283 三题同一模板、不同保留条件；141/876/19 三题同一速度差模型。记忆"慢写快读"和"1 步 2 步"，快慢指针全题型通杀。
