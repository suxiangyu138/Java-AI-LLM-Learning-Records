## 1. 核心概念

### 1.1 三大模式

```
① 对撞指针（相向）：有序找两数/回文/面积
   167 两数之和 II、11 盛水、15 三数之和

② 快慢指针（同向）：原地修改/链表
   27 移除元素、283 移动零、141 判环

③ 滑动窗口（同向+区间）：连续子数组
   3 无重复子串、76 最小覆盖
   （滑动窗口 = 双指针特例，见其专题）

本质：信息复用 + 安全排除
  每轮移动排除一批不可能的解
  每个指针最多移动 n 次 → O(n)
```

### 1.2 识别信号

```
"有序数组找两数" → 对撞（167）
"原地修改/去重" → 快慢（27/283）
"最大面积" → 对撞短板（11）
"连续子串最优" → 滑窗（3/76）
"链表判环/中点" → 快慢（141/876）

⚠️ 判定口诀：
  "有序找两数 → 对撞
   原地修改/链表 → 快慢
   连续子串 → 滑窗"
```

### 1.3 为什么是 O(n)

```
暴力：枚举所有 (i,j) 对 → O(n²)
双指针：两指针单调移动 → 总移动 2n 次 → O(n)

⚠️ 面试必答：
"每个指针最多移动 n 次（单调不回头），
 总移动 2n → O(n)。
 暴力枚举 (i,j) 对是 n² 次。"
```

## 2. 完整代码模板

### 2.1 167. 两数之和 II（对撞模板）

```java
/**
 * LeetCode 167. 两数之和 II - 输入有序数组
 * 对撞指针：sum 与 target 比较决定移动方向
 */
public int[] twoSum(int[] numbers, int target) {
    int left = 0, right = numbers.length - 1;

    while (left < right) {
        int sum = numbers[left] + numbers[right];
        if (sum == target) {
            return new int[]{left + 1, right + 1};   // 1-indexed
        } else if (sum < target) {
            left++;          // 需要更大的和 → 左指针右移
        } else {
            right--;         // 需要更小的和 → 右指针左移
        }
    }
    return new int[0];
}
// 推演 [2,7,11,15], target=9：
//   sum=17>9 → right--；sum=13>9 → right--
//   sum=9 ✓ → [1,2]
// O(n) 时间 O(1) 空间
```

### 2.2 11. 盛最多水的容器（短板移动）

```java
/**
 * LeetCode 11. 盛最多水的容器
 * 容量 = min(左高, 右高) × 宽度
 * ⚠️ 为什么移动矮边？（短板效应论证）
 *   移动高边 → 宽度变小，高度不变（还是矮边）→ 容量必变小
 *   移动矮边 → 宽度变小，但高度可能变大 → 有希望
 *   → 只有移动矮边才可能找到更优解
 */
public int maxArea(int[] height) {
    int left = 0, right = height.length - 1;
    int maxWater = 0;

    while (left < right) {
        int width = right - left;
        int h = Math.min(height[left], height[right]);
        maxWater = Math.max(maxWater, width * h);

        // 移动矮的一边（核心规则）
        if (height[left] < height[right]) left++;
        else right--;
    }
    return maxWater;
}
// O(n) 时间 O(1) 空间
// ⚠️ 面试必答："短板效应——容量由矮边决定，
//   移动高边容量必变小，移动矮边才有希望"
```

### 2.3 27. 移除元素（快慢模板）

```java
/**
 * LeetCode 27. 移除元素（快慢指针）
 * slow 慢写（下一个保留位置），fast 快读（扫描）
 */
public int removeElement(int[] nums, int val) {
    int slow = 0;
    for (int fast = 0; fast < nums.length; fast++) {
        if (nums[fast] != val) {
            nums[slow++] = nums[fast];   // 保留覆盖
        }
    }
    return slow;
}
// 变体家族：
//   26 去重：nums[fast] != nums[slow-1]
//   80 去重 II：nums[fast] != nums[slow-k]（k=2）
//   283 移动零：!= 0 + 末尾补零
// ⚠️ 记忆："快读慢写，保留条件不同"
```

## 3. 单调性论证

### 3.1 面试必答："为什么双指针是对的？"

```
以 167 两数之和为例：

当前和 sum = nums[left] + nums[right]
① sum < target → 需要更大的和
   只有移动 left（向右，值变大）才能增大和
   → 排除所有以 nums[left] 为左端点的组合 ✓

② sum > target → 需要更小的和
   只有移动 right（向左，值变小）才能减小和
   → 排除所有以 nums[right] 为右端点的组合 ✓

数学依据：有序性 → 指针移动方向与和的变化单调对应
这就是"单调性"——双指针正确性的根源
```

### 3.2 盛水容器的正确性

```
反证法：
  假设最优解是 (i*, j*)
  当 left 指向 i* 时，right 会在某个时刻指向 j*？
  —— 在到达 j* 前，所有被跳过的右边界
     height[right] ≤ height[i*]（否则 left 不会移动）
  —— 跳过这些右边界时，容量 ≤ height[i*] × (right - i*)
       ≤ 最优解
  → 被排除的组合不会比最优解更好 ✓

⚠️ 面试表达：
"短板效应 + 排除法：移动矮边时，
 被排除的组合容量不可能超过当前最优。"
```

### 3.3 单调性失效的场景

```
⚠️ 双指针不是万能的：
  无序数组找两数之和 → 无法判断移动方向
  含负数的子数组和 → 滑窗不单调（用前缀和）

判断标准：指针移动时能否"安全排除"一批解？
  能 → 双指针；不能 → 换思路
```

## 4. 三大模式详解

### 4.1 模式一：对撞（两端相向）

```
适用：有序找两数、回文、面积
模板：
  int left = 0, right = n - 1;
  while (left < right) {
      处理 arr[left], arr[right];
      根据条件移动 left++ 或 right--;
  }

变体：
  15 三数之和（固定+对撞+去重三处）
  42 接雨水（矮边确定水量）
  977 有序平方（两端取大）
  881 救生艇（最大配最小）

⚠️ 关键：每轮必有一个指针移动（防死循环）
```

### 4.2 模式二：快慢（同向前进）

```
适用：原地修改、链表问题
数组形态（读写分工）：
  slow 慢写（下一个保留位置）
  fast 快读（扫描全部）
链表形态（速度分工）：
  slow 1 步、fast 2 步（判环/中点/倒数第 N）

变体：
  141 判环（相遇）
  876 中点（fast 到头 slow 在中点）
  19 倒数第 N（fast 先走 N+1）
  234 回文（中点+反转+比较）

⚠️ 记忆："慢写快读"与"1 步 2 步"
```

### 4.3 模式三：滑窗（同向+区间）

```
适用：连续子数组/子串最优
模板：
  left 右扩探索，right 左缩修正
  条件单调 + 增量维护

⚠️ 详见滑动窗口专题（四大子模型）
  "连续看单调，单调看维护"
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"这题用对撞指针：left 指向最左，right 指向最右，
 每轮比较两者之和。
 根据单调性：sum < target 时移动 left、
 sum > target 时移动 right——
 有序数组保证指针移动方向与结果变化方向
 单调对应，被排除的组合不可能包含答案。
 时间 O(n)，空间 O(1)。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 为什么 O(n)？ | 每指针最多移动 n 次（单调不回头） |
| 2 | 为什么正确？ | 单调性论证：被排除的组合不可能含答案 |
| 3 | 对撞 vs 快慢？ | 两端相向 vs 同向前进（原地/链表） |
| 4 | 反例？ | 无序数组（无法判断方向）；含负数滑窗 |
| 5 | 三数之和为什么排序？ | 双指针前提（单调性）+ 相邻去重 |
| 6 | 盛水为什么移矮边？ | 短板效应：移高边容量必变小 |
| 7 | 接雨水 O(1) 空间？ | 维护 leftMax/rightMax 矮边确定 |
| 8 | 快慢为什么 2 步？ | 相对速度 1 判环必相遇 |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 循环条件 <= | 重复处理 | 用 < |
| 忘指针移动 | 死循环 | 每轮必动 |
| 三数忘去重 | 重复结果 | 三处去重 |
| 快慢判空漏 | 空指针 | fast.next 判空 |
| 移动方向反 | 结果错 | 单调性确认 |

> 🎯 **核心要点**：双指针 = **模式识别 + 单调性论证**。对撞（有序/面积）、快慢（原地/链表）两模板默写；15 题去重三处与 42 题矮边确定是进阶必考。面试必答"为什么 O(n)"与"为什么正确"（单调性）。
