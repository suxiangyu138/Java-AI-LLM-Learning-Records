## 2. 四大模板速查（默写版）

```java
// ═══════════ 模板一：定长窗口 ═══════════════════════
// 适用：643/438/567
for (int i = 0; i < k; i++) add(nums[i]);      // 先建首窗
check();                                        // ⚠️ 别忘首窗
for (int i = k; i < n; i++) {
    add(nums[i]);                               // 加新尾
    remove(nums[i - k]);                        // 去旧头
    check();
}

// ═══════════ 模板二：不定长求最长 ═══════════════════
// 适用：3/1004/424
int left = 0;
for (int right = 0; right < n; right++) {
    add(nums[right]);                           // 扩窗
    while (窗口不合法) { remove(nums[left]); left++; }   // 缩到合法
    answer = Math.max(answer, right - left + 1);          // while 外！
}

// ═══════════ 模板三：不定长求最短 ═══════════════════
// 适用：76/209
int left = 0;
for (int right = 0; right < n; right++) {
    add(nums[right]);
    while (窗口合法) {
        answer = Math.min(answer, right - left + 1);      // while 内！
        remove(nums[left]); left++;                        // 继续缩
    }
}

// ═══════════ 模板四：单调队列（窗口最值）══════════════
// 适用：239
Deque<Integer> deque = new ArrayDeque<>();      // 存下标
for (int i = 0; i < n; i++) {
    while (!deque.isEmpty() && nums[deque.peekLast()] < nums[i])
        deque.pollLast();                       // 淘汰弱元素
    deque.offerLast(i);
    if (deque.peekFirst() <= i - k) deque.pollFirst();    // 过期弹出
    if (i >= k - 1) result[i - k + 1] = nums[deque.peekFirst()];
}
```

## 3. 面试解题话术

```
📣 第 1 步：识别子模型 (15秒)
"这是连续子串问题 + 单调条件 → 滑动窗口。
 具体是【不定长求最长】——合法时取最大。"

📣 第 2 步：讲窗口维护 (60秒)
"我维护窗口 [left, right]：
 右指针扩展（加入字符，更新频次），
 左指针收缩（窗口不合法时，用 while 一直缩到合法）。
 窗口状态是增量维护的——扩窗加一、缩窗减一，不重复计算。"

📣 第 3 步：讲复杂度 (15秒)
"每个元素最多进窗口一次、出窗口一次 → O(n)。
 暴力枚举所有子串是 O(n²)，滑动窗口是唯一最优解。"

📣 第 4 步：讲细节 (30秒)
"注意三点：
 ① 缩窗用 while 不用 if（缩一次可能仍不合法）；
 ② 求最长在 while 外更新，求最短在 while 内更新；
 ③ 恰好型用容斥：exactlyK = atMost(K) - atMost(K-1)。"
```

## 4. 高频追问与标准回答

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 为什么滑动窗口是 O(n)？ | 两个指针都单调递增、永不回退，每个元素最多进出一次，总操作 O(2n)=O(n)；暴力枚举所有 (l,r) 对是 O(n²) |
| 2 | 缩窗为什么用 while 不用 if？ | 缩一次可能仍不合法（如多个重复字符），while 保证缩到合法为止 |
| 3 | 什么时候用滑动窗口？ | 连续子数组/子串 + 条件单调（扩窗更难满足）；含负数时不适用，用前缀和 |
| 4 | 求最长和求最短模板区别？ | 求最长：不合法才缩，while 外更新；求最短：合法就缩，while 内更新 |
| 5 | 恰好 K 怎么处理？ | 恰好不单调 → 容斥：exactlyK = atMost(K) - atMost(K-1)，两个 atMost 各用一次滑窗 |
| 6 | 76 题 valid 变量是什么？ | 已满足的字符种类数，valid == required 时窗口合法；用种类数而非数量，O(1) 判断 |
| 7 | 424 题 maxFreq 为什么不回退？ | 窗口最长时 maxFreq 必然最大，历史最大值是下界；不回退省去重算，不影响正确性 |
| 8 | 窗口最大值为什么用单调队列？ | 堆 O(n log k) 可解，但单调队列 O(n)——每个元素入队出队一次，"晚到且更大"淘汰"早到且更小" |
| 9 | 定长窗口常见错误？ | 忘记处理第一个窗口；去旧头写成 nums[k-i]（应为 nums[i-k]） |
| 10 | 前缀和 vs 滑动窗口怎么选？ | 条件单调 → 滑窗 O(n)/O(1)；含负数/统计个数 → 前缀和+哈希 O(n)/O(n) |

## 5. 高频题深度复盘

### 5.1 76. 最小覆盖子串（Hard 最高频）

```java
public String minWindow(String s, String t) {
    int[] need = new int[128];
    for (char c : t.toCharArray()) need[c]++;

    int required = 0;
    for (int x : need) if (x > 0) required++;   // t 的种类数

    int left = 0, valid = 0, minLen = Integer.MAX_VALUE, start = 0;

    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        if (need[c] > 0) {
            need[c]--;
            if (need[c] == 0) valid++;          // 该类满足
        }
        while (valid == required) {             // 合法 → 缩
            if (right - left + 1 < minLen) {
                minLen = right - left + 1;
                start = left;
            }
            char out = s.charAt(left);
            if (need[out] > 0) {
                if (need[out] == 0) valid--;    // 满足被破坏
                need[out]++;
            }
            left++;
        }
    }
    return minLen == Integer.MAX_VALUE ? "" : s.substring(start, start + minLen);
}
```

**复盘要点**：
- need 数组同时做"需求"和"窗口偏差"（负数 = 窗口有多余）
- valid 追踪种类而非数量（为什么：见 03 模块）
- 最短型：合法即记录（while 内更新）

### 5.2 239. 滑动窗口最大值（复盘）

```java
public int[] maxSlidingWindow(int[] nums, int k) {
    Deque<Integer> deque = new ArrayDeque<>();   // 存下标
    int[] result = new int[nums.length - k + 1];
    for (int i = 0; i < nums.length; i++) {
        while (!deque.isEmpty() && nums[deque.peekLast()] < nums[i])
            deque.pollLast();                    // 淘汰不可能当最大值的
        deque.offerLast(i);
        if (deque.peekFirst() <= i - k) deque.pollFirst();
        if (i >= k - 1) result[i - k + 1] = nums[deque.peekFirst()];
    }
    return result;
}
```

**复盘要点**：
- 存下标不存值（需要判断过期）
- 淘汰条件：`<`（相等的保留，因为可能成为新窗口最大值）
- 单调递减队列：队头永远是当前窗口最大值

## 6. 调试技巧与自检清单

### 6.1 滑窗自检三步法

```
第 1 步：窗口状态检查
  □ 扩窗时状态正确更新了吗？（频次+1 / 和增加）
  □ 缩窗时状态正确回退了吗？（频次-1 / 和减少）
  □ HashMap 计数归零时 remove 键了吗？（种类数判断）

第 2 步：模板正确性
  □ 缩窗用 while 了吗？
  □ 更新位置正确吗？（最长 while 外 / 最短 while 内）
  □ 定长窗口处理第一个窗口了吗？

第 3 步：边界用例
  □ 空字符串 / 空数组
  □ k = 0 / k = n（整个数组）
  □ 全部相同字符 / 全部不同
  □ 恰好型：k=1 和 k=n 的极端
```

### 6.2 高频 Bug 速查表

| Bug | 原因 | 修复 |
|------|------|------|
| 结果偏大 | 缩窗用了 if | 改 while |
| 答案漏更新 | 更新位置放错 | 最长外/最短内 |
| 种类数判断错 | 计数归零没 remove 键 | `if (count==0) map.remove(key)` |
| 首窗漏判 | 定长模板 | 先建窗再滑动 |
| 下标写错 | `nums[k-i]` | 应为 `nums[i-k]` |
| 单调队列过期判断错 | 存值不存下标 | 存下标才能判断 |

### 6.3 面试手写 Checklist

```

□ 复杂度 O(n)
```
