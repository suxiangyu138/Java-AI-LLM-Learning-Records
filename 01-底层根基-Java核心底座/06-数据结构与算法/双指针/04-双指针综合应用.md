## 1. 88. 合并两个有序数组：反向指针

### 1.1 完整实现（从后往前）

```java
/**
 * LeetCode 88. 合并两个有序数组
 * nums1 长度 m+n（后 n 位是 0），把 nums2 合并进 nums1
 * 要求：原地，O(m+n)
 *
 * 反向指针：从后往前填（避免覆盖 nums1 前部未合并的元素）
 *   p1 指向 nums1 有效区末尾，p2 指向 nums2 末尾，p 指向填充位置
 */
public void merge(int[] nums1, int m, int[] nums2, int n) {
    int p1 = m - 1;              // nums1 有效区末尾
    int p2 = n - 1;              // nums2 末尾
    int p = m + n - 1;           // 填充位置（从后往前）

    while (p2 >= 0) {            // nums2 还有元素
        if (p1 >= 0 && nums1[p1] > nums2[p2]) {
            nums1[p--] = nums1[p1--];    // 取 nums1 较大的
        } else {
            nums1[p--] = nums2[p2--];    // 取 nums2 较大的
        }
    }
}
```

### 1.2 为什么必须从后往前？

```
从前往后会覆盖 nums1 前部的有效元素！
  nums1 = [1,2,3,0,0,0], nums2 = [2,5,6]
  从前往后：先把 nums1[0]=1 和 nums2[0]=2 比较
    → 把 1 写回 nums1[0]（没问题，但 nums1[2]=3 迟早会被覆盖）
    → 当把 2 写到 nums1[1] 时，nums1[1]=2 已被覆盖！❌

从后往前：填充位置在末尾（0 区域），不会碰到未处理的有效元素
  → 安全原地合并 ✓
```

## 2. 42. 接雨水：双指针版

### 2.1 完整实现（O(1) 空间）

```java
/**
 * LeetCode 42. 接雨水（经典 Hard）
 * 每个位置能接的水 = min(左边最高, 右边最高) - height[i]
 *
 * 双指针版本：O(n) 时间，O(1) 空间
 *   维护 leftMax（左指针左侧最高）和 rightMax（右指针右侧最高）
 *   哪边最大高度更小 → 那边可以确定接水量
 */
public int trap(int[] height) {
    int left = 0, right = height.length - 1;
    int leftMax = 0, rightMax = 0;
    int water = 0;

    while (left < right) {
        // 更新两侧最高
        leftMax = Math.max(leftMax, height[left]);
        rightMax = Math.max(rightMax, height[right]);

        if (leftMax < rightMax) {
            // 左边能确定：接水 = leftMax - height[left]
            water += leftMax - height[left];
            left++;
        } else {
            // 右边能确定：接水 = rightMax - height[right]
            water += rightMax - height[right];
            right--;
        }
    }
    return water;
}
```

### 2.2 为什么矮边能确定接水量？

```
当前 leftMax < rightMax：
  位置 left 的接水量 = min(leftMax, 右边某个值) - height[left]
  右边最大值 ≥ rightMax > leftMax（rightMax 是右指针右侧的最大值）
  → 右边的"最高"必然 ≥ leftMax
  → 位置 left 的接水量 = leftMax - height[left] 可以确定！✓

同理 rightMax < leftMax 时右边可以确定。
每次只移动"最高值较小"的一侧 → 两侧交替收敛
```

### 2.3 接雨水三解法对比

| 解法 | 时间 | 空间 | 思路 |
|------|:---:|:---:|------|
| 暴力 | O(n²) | O(1) | 每格扫描左右最高 |
| 动态规划 | O(n) | O(n) | 预处理左右最高数组 |
| **双指针** | O(n) | **O(1)** | 维护两侧最大，矮边确定 |

## 3. 977. 有序数组的平方

### 3.1 完整实现（对撞取大）

```java
/**
 * LeetCode 977. 有序数组的平方
 * 非递减数组，返回每个数平方后的有序数组
 * [-4,-1,0,3,10] → [0,1,9,16,100]
 *
 * 对撞指针：最大的平方在两端（负数平方可能很大）
 *   从后往前填结果，取两端平方较大者
 */
public int[] sortedSquares(int[] nums) {
    int n = nums.length;
    int[] result = new int[n];
    int left = 0, right = n - 1;
    int p = n - 1;                        // 从后往前填

    while (left <= right) {
        int leftSquare = nums[left] * nums[left];
        int rightSquare = nums[right] * nums[right];
        if (leftSquare > rightSquare) {
            result[p--] = leftSquare;     // 左端平方更大
            left++;
        } else {
            result[p--] = rightSquare;    // 右端平方更大
            right--;
        }
    }
    return result;
}
```

### 3.2 为什么对撞？

```
数组有序 → 平方后"两端大中间小"（负数平方大）
  最大平方一定在两端之一 → 从两端取最大
  取完一个端点 → 该端点向中间收缩 → 继续取最大

本质：两段有序序列（负数的平方递减 + 正数的平方递增）
     的归并 → 双指针归并思想
```

## 4. 881. 救生艇：最大配最小

### 4.1 完整实现

```java
/**
 * LeetCode 881. 救生艇
 * 每艘船最多载两人且重量 ≤ limit，求最少船数
 *
 * 贪心 + 对撞：最重的尽量配最轻的
 *   最重的人：
 *     能配最轻 → 一起走（双指针都动）
 *     配不了 → 单独走（只动右指针）
 */
public int numRescueBoats(int[] people, int limit) {
    Arrays.sort(people);
    int left = 0, right = people.length - 1;
    int boats = 0;

    while (left <= right) {
        if (people[left] + people[right] <= limit) {
            left++;               // 最轻的能陪最重的
        }
        right--;                  // 最重的一定上船
        boats++;
    }
    return boats;
}
// [3,2,2,1], limit=3 → 排序 [1,2,2,3]
// 1+3=4>3 → 3 单独（1船），2+2=4>3 → 2 单独（1船）
// 1 单独（1船）→ 3 艘
```

### 4.2 贪心正确性

```
最重的人 w：
  如果能与最轻的人 l 共乘 → 最优（两人一艘）
  如果不能 → 没有任何人能与 w 共乘 → 单独（必然）
  → 每一步都是最优决策（贪心选择性质）
```

## 5. 202. 快乐数：数字判环

### 5.1 完整实现（快慢指针）

```java
/**
 * LeetCode 202. 快乐数
 * 循环计算各位平方和，若最终为 1 → 快乐数
 * 19 → 82 → 68 → 100 → 1 ✓
 *
 * 关键洞察：不是快乐数的会进入循环（永远不会到 1）
 *   → 转化为"链表判环"问题！
 *   → 快慢指针：slow 算一步，fast 算两步
 *      相遇 → 有环 → 不是快乐数
 *      到 1 → 快乐数
 */
public boolean isHappy(int n) {
    int slow = n, fast = getNext(n);

    while (fast != 1 && slow != fast) {   // 到 1 或相遇就停
        slow = getNext(slow);             // 慢：一步
        fast = getNext(getNext(fast));    // 快：两步
    }
    return fast == 1;
}

private int getNext(int n) {
    int sum = 0;
    while (n > 0) {
        int d = n % 10;
        sum += d * d;
        n /= 10;
    }
    return sum;
}
```

### 5.2 为什么能转成判环？

```
数字变换 getNext 是确定性的函数（同样的输入同样输出）
  → 从 n 出发的变换序列像链表的 next 指针
  → 若永远到不了 1，必然进入循环（有限状态！）
  → 判断"是否进入循环" = 链表判环

同类题：287. 寻找重复数（数组下标跳跃形成环）
```

## 6. 双指针综合解题框架

### 6.1 五步综合框架

```
① 识别：是哪种双指针？（对撞/快慢/滑窗）
② 定义指针语义：left/right 各代表什么
③ 确定移动规则：什么时候动哪个指针
④ 验证单调性：为什么被排除的组合不可能有答案
⑤ 边界：空数组/单元素/越界
```

### 6.2 双指针全家桶速查

| 模式 | 变体 | 代表题 | 关键 |
|------|------|:---:|------|
| 对撞 | 和/差比较 | 167/15/16 | 有序单调 |
| 对撞 | 短板移动 | 11/42 | 移动矮边 |
| 对撞 | 两端取大 | 977 | 负数的平方 |
| 对撞 | 最大配最小 | 881 | 贪心配对 |
| 快慢 | 读写分工 | 27/26/283 | 覆盖写入 |
| 快慢 | 速度差 | 141/876/19 | 1 步 2 步 |

### 6.3 面试话术

```
"这题我识别为【对撞/快慢】双指针。
 left/right 的语义是【...】。
 移动规则：当【条件】时移动【指针】，因为【单调性论证】。
 被排除的组合不可能包含最优解。
 时间 O(n)，空间 O(1)。"
```

> 🎯 **核心要点**：双指针综合应用展示了技巧的**迁移能力**——88 的反向防覆盖、42 的矮边确定、977 的两端归并、881 的贪心配对、202 的判环转换。遇到新题先识别"属于哪个变体"，再套移动规则。双指针 + 滑动窗口是数组题的效率双雄，练熟后 O(n) 解法信手拈来。
