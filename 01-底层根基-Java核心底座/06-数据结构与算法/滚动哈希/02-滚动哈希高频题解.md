## 1. 187. 重复的 DNA 序列

### 1.1 题目与思路

```
长度 10 的 DNA 片段（A/C/G/T）出现至少两次 → 返回全部
滑动窗口哈希：窗口 10 字符滚动 → 用 Set 判重
⚠️ DNA 只有 4 字符 → 可以"编码"为 2 位二进制（4 进制数）
   甚至不用模数：10×2=20 位 < int 32 位 → 零碰撞！
```

### 1.2 完整代码（4 进制编码版）

```java
/**
 * LeetCode 187. 重复的 DNA 序列
 * ⚠️ 妙解：A/C/G/T → 0/1/2/3（2 位），长度 10 → 20 位 int，无碰撞！
 */
public List<String> findRepeatedDnaSequences(String s) {
    List<String> res = new ArrayList<>();
    if (s.length() <= 10) return res;

    Map<Character, Integer> map = Map.of('A', 0, 'C', 1, 'G', 2, 'T', 3);
    Set<Integer> seen = new HashSet<>();
    Set<Integer> added = new HashSet<>();        // ⚠️ 防重复加入答案

    int hash = 0;
    int mask = (1 << 20) - 1;                    // 低 20 位掩码
    for (int i = 0; i < s.length(); i++) {
        // 滚动：左移 2 位加入新字符（编码 2 位）
        hash = ((hash << 2) | map.get(s.charAt(i))) & mask;   // ⚠️ 只留低 20 位
        if (i >= 9) {                            // 满 10 个字符
            if (!seen.add(hash)) {               // 出现过 → 重复
                if (added.add(hash)) {
                    res.add(s.substring(i - 9, i + 1));
                }
            }
        }
    }
    return res;
}
// 推演 s="AAAAACCCCCAAAAACCCCCCAAAAAGGGTTT"：
//   窗口 [0,10) 哈希 = 0000000000（全 A）
//   之后 [1,11) 哈希 = ... 用 Set 判重 → 输出重复片段
// ⚠️ 为什么零碰撞：4^10 = 2^20 种片段，int 20 位恰好一一映射！
//   哈希值即片段本身 → 完美哈希
```

> 🎯 **要点**：字符集小（4/26）时"编码式滚动哈希"是首选——用进制数直接表示，无需模数，零碰撞。窗口长度 × 编码位数 ≤ 32/64 位即可。

## 2. 718. 最长重复子数组

### 2.1 题目与思路

```
两个数组的最长公共子数组（连续）
方案：
  ① DP：dp[i][j] = 以 i,j 结尾的公共后缀长 → O(n²) 时间/空间
  ② 二分 + 双哈希：长度二分 + 每轮哈希判重 → O(n² log n)？不——
    每轮 O(n)，二分 log n 轮 → O(n log n) 期望 ⭐
⚠️ 二分答案的可行性：最长长度具有单调性（长为 k 可行 → k-1 可行）
```

### 2.2 完整代码（二分 + 双哈希）

```java
/**
 * LeetCode 718. 最长重复子数组（二分 + 双哈希）
 */
public int findLength(int[] nums1, int[] nums2) {
    int lo = 0, hi = Math.min(nums1.length, nums2.length);
    while (lo < hi) {
        int mid = lo + (hi - lo + 1) / 2;        // ⚠️ 上取整（lo=mid 时防死循环）
        if (hasCommon(nums1, nums2, mid)) lo = mid;      // 可行 → 试更长
        else hi = mid - 1;
    }
    return lo;
}

/** 检查是否存在长度为 len 的公共子数组（双哈希集合） */
private boolean hasCommon(int[] a, int[] b, int len) {
    long B1 = 131, M1 = 1_000_000_007L;
    long B2 = 137, M2 = 1_000_000_009L;
    // ① 计算 a 的所有 len 长子数组哈希（滚动）
    long h1 = 0, h2 = 0, pow1 = 1, pow2 = 1;
    for (int i = 0; i < len - 1; i++) {
        pow1 = pow1 * B1 % M1;
        pow2 = pow2 * B2 % M2;
    }
    Set<Long> seen = new HashSet<>();
    for (int i = 0; i < a.length; i++) {
        if (i < len) {
            h1 = (h1 * B1 + a[i]) % M1;
            h2 = (h2 * B2 + a[i]) % M2;
        } else {
            // ⚠️ 窗口滑动（减左乘 B 加右）
            h1 = ((h1 - a[i - len] * pow1 % M1 + M1) % M1 * B1 + a[i]) % M1;
            h2 = ((h2 - a[i - len] * pow2 % M2 + M2) % M2 * B2 + a[i]) % M2;
        }
        if (i >= len - 1) seen.add(h1 << 32 | h2);   // ⚠️ 双哈希合并成 key
    }
    // ② 同样的滚动计算 b，查集合
    h1 = 0; h2 = 0;
    for (int i = 0; i < b.length; i++) {
        if (i < len) {
            h1 = (h1 * B1 + b[i]) % M1;
            h2 = (h2 * B2 + b[i]) % M2;
        } else {
            h1 = ((h1 - b[i - len] * pow1 % M1 + M1) % M1 * B1 + b[i]) % M1;
            h2 = ((h2 - b[i - len] * pow2 % M2 + M2) % M2 * B2 + b[i]) % M2;
        }
        if (i >= len - 1 && seen.contains(h1 << 32 | h2)) return true;
    }
    return false;
}
// 复杂度：O(n log n) 期望（每轮 O(n)，二分 O(log n) 轮）
// ⚠️ 二分 + 哈希 = "二分答案"（见分治/06）与滚动哈希的经典结合
```

## 3. 1044. 最长重复子串

### 3.1 题目与思路

```
字符串中最长重复子串（两处出现且不重叠）
与 718 完全同构：长度二分 + 哈希判重
⚠️ 00 模块有主模板；此处补充双哈希完整版与验证细节
```

### 3.2 完整代码（双哈希 + 下标验证）

```java
/**
 * LeetCode 1044. 最长重复子串（二分 + 双哈希）
 * ⚠️ 输出子串本身 → 判重时记录下标
 */
String longestDupSubstring(String s) {
    int n = s.length();
    int lo = 1, hi = n - 1;
    String result = "";
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;
        String found = check(s, mid);            // 返回长度为 mid 的重复子串
        if (found != null) {
            result = found;                      // ⚠️ 可行 → 记录并试更长
            lo = mid + 1;
        } else {
            hi = mid - 1;
        }
    }
    return result;
}

/** 检查长度为 len 的重复子串（双哈希 + 下标） */
String check(String s, int len) {
    long B1 = 131, M1 = 1_000_000_007L;
    long B2 = 137, M2 = 1_000_000_009L;
    Map<Long, Integer> firstPos = new HashMap<>();   // ⚠️ 哈希 → 首次出现位置
    long h1 = 0, h2 = 0, pow1 = 1, pow2 = 1;
    for (int i = 0; i < len - 1; i++) {
        pow1 = pow1 * B1 % M1;
        pow2 = pow2 * B2 % M2;
    }
    for (int i = 0; i < s.length(); i++) {
        if (i < len) {
            h1 = (h1 * B1 + s.charAt(i)) % M1;
            h2 = (h2 * B2 + s.charAt(i)) % M2;
        } else {
            h1 = ((h1 - s.charAt(i - len) * pow1 % M1 + M1) % M1 * B1 + s.charAt(i)) % M1;
            h2 = ((h2 - s.charAt(i - len) * pow2 % M2 + M2) % M2 * B2 + s.charAt(i)) % M2;
        }
        if (i < len - 1) continue;
        long key = h1 << 32 | h2;
        if (firstPos.containsKey(key)) {
            int p = firstPos.get(key);
            // ⚠️ 碰撞终极验证：直接比较子串（防双哈希失效）
            if (s.substring(p, p + len).equals(s.substring(i - len + 1, i + 1)))
                return s.substring(p, p + len);
        } else {
            firstPos.put(key, i - len + 1);
        }
    }
    return null;
}
// 复杂度：O(n log n) 期望
// ⚠️ 三层防线：long 单哈希（先天低碰撞）→ 双哈希 key → equals 验证
//   equals 验证只在"哈希撞车"时触发 → 平均 O(1) 额外代价
```

## 4. 686. 重复叠加字符串匹配

### 4.1 题目与思路

```
a 重复叠加几次后包含 b？（返回最小次数，无解 -1）
暴力边界分析：
  最少次数 = ceil(b.length / a.length)
  最多 = 最少 + 2（超过则不可能——b 不可能横跨超过 2 个额外 a）
⚠️ 用滚动哈希/Rabin-Karp 在"叠加串"中找 b（KMP 也可）
```

### 4.2 完整代码

```java
/**
 * LeetCode 686. 重复叠加字符串匹配
 * ⚠️ 关键推导：构造次数上界 = ceil(len_b/len_a) + 2
 *   再多则 a 已重复超过 b 的长度 + 首尾 → 不可能再包含
 */
public int repeatedStringMatch(String a, String b) {
    int min = (b.length() + a.length() - 1) / a.length();   // 下界
    StringBuilder sb = new StringBuilder();
    for (int i = 0; i < min; i++) sb.append(a);
    // 尝试 min 与 min+1、min+2 三种长度
    for (int extra = 0; extra <= 2; extra++) {
        String s = sb.toString();
        if (rabinKarp(s, b) != -1) return min + extra;
        sb.append(a);
    }
    return -1;
}
// rabinKarp 见 [01-滚动哈希进阶](01-滚动哈希进阶：Rabin-Karp与双哈希.md)
// 推演 a="ab", b="babab"：
//   min = ceil(5/2) = 3 → "ababab" 包含 "babab"？含 → 返回 3 ✓
// 推演 a="aa", b="a"：min=1 → "aa" 含 → 返回 1 ✓
// ⚠️ 为什么 +2 够：b 若被包含，其起点必在"前 2 个 a"的范围内
//   （b 长度 ≤ 2×len_a + 余量时，起点超过 2 个 a 则尾部必然超出）
```

## 5. 214. 最短回文串

### 5.1 题目与思路

```
在 s 前面加字符，使结果是最短回文串
核心：找 s 的"最长回文前缀"——剩下的后缀反转拼到前面即可
  s = "aacecaaa" → 最长回文前缀 "aacecaa" → 补 "a" → "aaacecaaa"
用滚动哈希判断前缀是否回文：
  前缀 s[0..k] 回文 ⟺ 正序哈希 == 逆序哈希
  正序：pre[i] 累加；逆序：从右往左同样累加
⚠️ O(n) 找到最长回文前缀（KMP 也可：s + # + reverse(s) 的 next）
```

### 5.2 完整代码（滚动哈希）

```java
/**
 * LeetCode 214. 最短回文串（滚动哈希判断回文前缀）
 */
public String shortestPalindrome(String s) {
    int n = s.length();
    long B = 131, M = 1_000_000_007L;

    long forward = 0, backward = 0, pow = 1;
    int bestLen = 0;                          // 最长回文前缀长度
    for (int i = 0; i < n; i++) {
        int c = s.charAt(i) - 'a' + 1;        // ⚠️ 1-26，避免前缀 0 歧义
        forward = (forward * B + c) % M;      // 正序哈希
        backward = (c * pow + backward) % M;  // 逆序哈希（新字符放最高位）
        if (forward == backward) bestLen = i + 1;   // ⚠️ 前缀是回文
        pow = pow * B % M;
    }
    // 剩余后缀反转拼到前面
    String suffix = s.substring(bestLen);
    return new StringBuilder(suffix).reverse().append(s).toString();
}
// 推演 s="aacecaaa"：
//   i=6：前缀 "aacecaa" 正序哈希 == 逆序哈希 → bestLen=7
//   后缀 "a" → 反转 "a" + 原串 → "aaacecaaa" ✓
// ⚠️ 逆序哈希公式：backward = c·B^i + ... + c₀（c 是新最高位）
//   推导：backward_new = c·pow + backward_old（把旧哈希整体左移一位）
// ⚠️ 碰撞风险：这是"判断相等"场景 → 双哈希更稳（此处单哈希演示，
//   工程上建议双哈希或与 KMP 交叉验证）
```

## 6. 459. 重复的子字符串

### 6.1 题目与思路

```
s 是否由某个子串重复组成（"abab" ← "ab"×2）
经典结论：s 由子串重复组成 ⟺ s 是 (s+s) 去掉首尾后的子串
  证明：s = t×k → (s+s)[1..2n-2] 包含 s（在中间位置）
  反之：若 s 在 (s+s) 内部出现 → 周期 = 首次出现位置 → 周期整除长度
⚠️ 用滚动哈希在 (s+s)[1:-1] 中找 s（或 String.contains，面试用哈希展示）
```

### 6.2 完整代码

```java
/**
 * LeetCode 459. 重复的子字符串
 * ⚠️ 结论：s 重复组成 ⟺ (s+s) 去掉首尾后包含 s
 */
public boolean repeatedSubstringPattern(String s) {
    int n = s.length();
    String doubled = (s + s).substring(1, 2 * n - 1);   // 去首尾
    // 用 Rabin-Karp 判断 doubled 是否包含 s（这里用简单方式，面试可换哈希）
    return doubled.contains(s);
}
// 推演 s="abab"：doubled="bababa" 包含 "abab" ✓
// 推演 s="abc"：doubled="bcab" 不包含 "abc" ✓
// ⚠️ 哈希版实现：把 contains 换成 [01-滚动哈希](01-滚动哈希进阶：Rabin-Karp与双哈希.md)
//   的 rabinKarp(doubled, s) != -1
// ⚠️ 周期证明：s 在 (s+s) 内部出现 → 位置 p（1 ≤ p ≤ n-1）
//   则 s[i] = s[(i+p) mod n] → p 是周期 → p | n → 重复子串 = s[0..p)
```

## 7. 1392. 最长快乐前缀

### 7.1 题目与思路

```
既是 s 前缀又是 s 后缀（且非 s 本身）的最长子串
"ababab" → 最长快乐前缀 "abab"（长度 4）
滚动哈希：扫描所有位置，比较"前缀哈希"与"对应后缀哈希"取最大
⚠️ 与 KMP next 数组等价（next[n-1] 就是最长真前后缀）
```

### 7.2 完整代码（滚动哈希）

```java
/**
 * LeetCode 1392. 最长快乐前缀（滚动哈希）
 * ⚠️ 核心：位置 i 处，前缀 [0,i] 与后缀 [n-1-i, n-1] 哈希相等 → 快乐前缀
 */
public String longestPrefix(String s) {
    int n = s.length();
    long B = 131, M = 1_000_000_007L;
    long[] pow = new long[n + 1];
    pow[0] = 1;
    for (int i = 1; i <= n; i++) pow[i] = pow[i - 1] * B % M;

    long[] pre = new long[n + 1];              // 正序前缀哈希
    for (int i = 0; i < n; i++)
        pre[i + 1] = (pre[i] * B + (s.charAt(i) - 'a' + 1)) % M;

    // 检查长度 len 的前缀是否也是后缀：pre[len] == hash(后缀)
    int best = 0;
    for (int len = 1; len < n; len++) {
        long suffixHash = (pre[n] - pre[n - len] * pow[len] % M + M) % M;  // 后缀哈希
        if (pre[len] == suffixHash) best = len;   // ⚠️ 相等 → 快乐前缀
    }
    return s.substring(0, best);
}
// 推演 s="level"：
//   len=2：前缀 "le" vs 后缀 "el" ✗
//   len=1：前缀 "l" vs 后缀 "l" ✓ → best=1 → "l"
// 推演 s="ababab"：
//   len=2 "ab" ✓；len=4 "abab" ✓ → 返回 "abab" ✓
// ⚠️ 后缀哈希公式：sub = pre[n] - pre[n-len]·B^len（与前缀差分同理）
```

## 8. 滚动哈希方法论总结

### 8.1 题型模板速查

| 题型 | 核心手法 | 代表题 |
|------|---------|--------|
| 定长窗口查重 | 滚动哈希 + Set | 187 |
| 最长重复（二分） | 长度二分 + 哈希判重 | 718、1044 |
| 模式匹配 | Rabin-Karp | 686、459 |
| 回文判断 | 正逆序哈希比较 | 214 |
| 前后缀相等 | 前缀哈希 vs 后缀哈希 | 1392 |
| 编码式哈希 | 进制数直接表示（零碰撞） | 187 变体 |

### 8.2 解题四步框架

```
① 定哈希：字符集小 → 编码式（零碰撞）；
   字符集大 → 多项式哈希（B=131, M=1e9+7）
② 预计算：pre[] 前缀哈希 + pow[] 幂次
③ 滚动/查询：窗口滑动 O(1) 或子串差分 O(1)
④ 防碰撞：比较场景加验证（equals 回退）/ 双哈希
```

### 8.3 自测清单

```
□ 减法取模 +M 防负？
□ 字符映射从 1 开始（防前缀 0 歧义）？
□ 二分答案用上取整（lo=mid 时）？
□ 双哈希 key 合并无碰撞（h1<<32|h2）？
□ 判重时记录下标（输出子串场景）？
□ 窗口滑动公式推导正确（减左·B^(len-1)）？
```

> 🎯 **核心要点**：滚动哈希题 = **哈希构造**（编码式/多项式）+ **滑动/差分**（O(1)）+ **二分答案**（最长重复家族）。187 的编码式零碰撞、718/1044 的二分+双哈希、214 的正逆序比较、1392 的前后缀差分——四类手法覆盖全部题型。
