## 1. 核心概念

### 1.1 什么是滚动哈希

> 滚动哈希（Rabin-Karp）：用多项式把字符串映射为整数，窗口滑动时 **O(1) 增量更新**哈希值。

```
多项式哈希：
  hash("abc") = a×base² + b×base + c   （base=131 等质数）

窗口滚动（"abc" → "bcd"）：
  hash("bcd") = (hash("abc") - a×base²) × base + d
              = 去掉旧首字符 → 整体升幂 → 加新尾字符
  → O(1)！

本质：把"子串相等比较"（O(m)）变成"整数比较"（O(1)）
代价：可能哈希冲突（不同字符串同哈希）→ 概率极低
```

### 1.2 参数选择

```
base 选择：131 / 31（质数，与 mod 互质减少冲突）
mod 选择：
  10⁹+7（确定性，手动取模）★ 面试推荐
  2⁶⁴ 自然溢出（long 自动溢出，快但非确定）

⚠️ Java 取模负数：
  (x % mod + mod) % mod（% 结果与被除数同号）

⚠️ 溢出防护：
  中间乘法用 long（base² 可能超 int）
```

### 1.3 应用场景

```
① 子串匹配（Rabin-Karp 替代 KMP）
② 最长重复子串（二分长度 + 哈希查重）★ 核心应用
③ 回文前缀/后缀比较（214 最短回文串）
④ 字符串相等批量判断

与 KMP 对比：
  KMP：O(n+m) 确定、O(m) 空间
  滚动哈希：O(n+m) 期望、O(1) 空间、可查重
  查重场景（Set 去重）→ 哈希独有优势
```

## 2. 完整代码模板

### 2.1 Rabin-Karp 匹配模板

```java
/**
 * 滚动哈希匹配模板
 */
public int rabinKarp(String text, String pattern) {
    int n = text.length(), m = pattern.length();
    if (m > n) return -1;

    long base = 131, mod = 1_000_000_007;

    // ① 预计算 base^(m-1)（最高位权重）
    long power = 1;
    for (int i = 0; i < m - 1; i++) {
        power = power * base % mod;
    }

    // ② 计算 pattern 哈希 + 首个窗口哈希
    long patternHash = hash(pattern, base, mod);
    long windowHash = 0;
    for (int i = 0; i < m; i++) {
        windowHash = (windowHash * base + text.charAt(i)) % mod;
    }

    // ③ 滚动比较
    if (windowHash == patternHash) return 0;
    for (int i = m; i < n; i++) {
        // 滚动公式：去旧首 → 升幂 → 加新尾
        windowHash = ((windowHash
                       - text.charAt(i - m) * power % mod
                       + mod) % mod            // ⚠️ 防负数
                      * base + text.charAt(i)) % mod;
        if (windowHash == patternHash) return i - m + 1;
    }
    return -1;
}

private long hash(String s, long base, long mod) {
    long h = 0;
    for (char c : s.toCharArray()) {
        h = (h * base + c) % mod;
    }
    return h;
}
```

### 2.2 滚动公式推导

```
窗口 [i-m, i-1] → [i-m+1, i]：

旧窗口 = s[i-m]×base^(m-1) + s[i-m+1]×base^(m-2) + ... + s[i-1]

① 去掉旧首：旧窗口 - s[i-m]×power（power = base^(m-1)）
② 升幂：× base（整体左移一位）
③ 加新尾：+ s[i]

记忆口诀："去旧首，升幂，加新尾"
  公式：window = (window - old×power) × base + new

推演验证（"abc" → "bcd"）：
  hash("abc") - a×base² = b×base + c
  ×base → b×base² + c×base
  + d → b×base² + c×base + d = hash("bcd") ✓
```

### 2.3 固定长度子串哈希查重

```java
/**
 * 187. 重复的 DNA 序列（定长窗口哈希查重）
 * 所有长度为 10 的子串，返回出现 ≥ 2 次的
 */
public List<String> findRepeatedDnaSequences(String s) {
    if (s.length() <= 10) return new ArrayList<>();

    Set<String> seen = new HashSet<>();
    Set<String> repeated = new LinkedHashSet<>();

    for (int i = 0; i <= s.length() - 10; i++) {
        String sub = s.substring(i, i + 10);
        if (!seen.add(sub)) {              // ⚠️ add 返回 false = 已见过
            repeated.add(sub);
        }
    }
    return new ArrayList<>(repeated);
}
// 本题用 HashSet 存子串即可（长度固定 10）
// 若长度大（10⁵）→ 必须滚动哈希（substring 是 O(m)）
```

## 3. 哈希冲突与处理

### 3.1 冲突的本质

```
两个不同字符串可能映射到同一哈希值：
  多项式哈希是"模 mod"的 → 有限值域（mod 种）
  字符串无限多 → 鸽笼原理 → 必然有冲突

冲突概率 ≈ 1/mod ≈ 10⁻⁹（mod = 10⁹+7）
  → 工程上可接受（十万亿次比较才可能错一次）

⚠️ 确定性要求：不能接受任何错误时
  → 用 KMP（确定正确）
```

### 3.2 三种冲突处理方案

```
① 双哈希：两个 base 或两个 mod 同时算
   冲突概率 = (1/mod)² → 平方级降低
   ⚠️ 内存翻倍

② 冲突验证：哈希相等后逐字符比较
   Rabin-Karp 匹配的标准做法
   （哈希只是"快速筛选"）

③ 自然溢出：long 溢出代替取模
   快但结果不确定（不同 JVM 一致）

面试话术：
"哈希冲突概率约 1/10⁹ 极低；严格场景
 哈希相等后逐字符验证（双保险）。"
```

### 3.3 选择取模 vs 自然溢出

```
取模（10⁹+7）：
  ✅ 确定结果、可调试
  ✅ 与语言无关
  ⚠️ 稍慢（% 运算）

自然溢出（long）：
  ✅ 快（硬件溢出）
  ⚠️ 结果依赖类型宽度（64 位固定）
  ⚠️ 无法控制（冲突概率固定 2⁻⁶⁴）

面试推荐取模（确定性 + 讲解清晰）
```

## 4. 最长重复子串（二分+哈希）

### 4.1 1044. 最长重复子串

```java
/**
 * LeetCode 1044. 最长重复子串（Hard）
 * 思路：二分答案长度 + 滚动哈希查重
 *
 * 单调性：长度 len 有重复 → 更短也必有重复
 *   → 二分 len，check(len) 检查是否存在重复
 */
public String longestDupSubstring(String s) {
    int n = s.length();
    int lo = 1, hi = n - 1;
    String result = "";

    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;
        String found = findDuplicate(s, mid);
        if (found != null) {
            result = found;              // mid 可行 → 尝试更长
            lo = mid + 1;
        } else {
            hi = mid - 1;
        }
    }
    return result;
}

// check：是否存在长度为 len 的重复子串（返回一个）
private String findDuplicate(String s, int len) {
    int n = s.length();
    long base = 131, mod = 1_000_000_007;

    // 预计算 power = base^(len-1)
    long power = 1;
    for (int i = 0; i < len - 1; i++) power = power * base % mod;

    // 第一个窗口
    long hash = 0;
    for (int i = 0; i < len; i++) {
        hash = (hash * base + s.charAt(i)) % mod;
    }
    Map<Long, Integer> seen = new HashMap<>();   // ⚠️ 存起始下标（防误判）
    seen.put(hash, 0);

    // 滚动 + 查重
    for (int i = len; i < n; i++) {
        hash = ((hash - s.charAt(i - len) * power % mod + mod) % mod
                * base + s.charAt(i)) % mod;

        if (seen.containsKey(hash)) {
            // ⚠️ 冲突验证：实际比较两个子串
            int start = seen.get(hash);
            if (s.substring(start, start + len)
                .equals(s.substring(i - len + 1, i + 1))) {
                return s.substring(i - len + 1, i + 1);
            }
        } else {
            seen.put(hash, i - len + 1);
        }
    }
    return null;
}
// 复杂度：O(n log n)（二分 log n × 每轮 O(n)）
```

### 4.2 为什么需要存下标并验证？

```
哈希冲突（极低概率）会导致：
  不同子串同哈希 → 误判重复
  → 存起始下标，哈希命中时实际比较（双保险）

⚠️ 工程严谨性展示：
  "我用双保险：哈希快速筛选 + 实际比较确认，
   冲突概率 1/10⁹ 且验证兜底 → 正确性 100%"
```

### 4.3 二分 + 哈希的通用模式

```
① 识别单调性：长度/数量越大越难（或越易）
② 二分答案值域
③ check(mid)：滚动哈希 O(n) 验证
④ 记录最优可行答案

应用家族：
  1044 最长重复子串
  718 最长重复子数组（双哈希更稳）
  1062 最长重复子串
  ⚠️ 注意：字符串含任意字符（base 需大于字符集）
```

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 忘预计算 power | 滚动公式错 | base^(m-1) 先行 |
| 负数取模 | 哈希错乱 | + mod 调整 |
| 忘冲突验证 | 极低概率误判 | 存下标实际比较 |
| 二分边界错 | 漏最优解 | lo<=hi 记录可行 |
| power 溢出 | 结果错 | long + 每步取模 |

> 🎯 **核心要点**：滚动哈希 = **多项式哈希 + 窗口 O(1) 滚动**。识别信号："子串查重、最长重复子串、前后缀比较"。滚动公式"去旧首升幂加新尾"是唯一需要背的；二分+哈希（1044）是最高频应用。
