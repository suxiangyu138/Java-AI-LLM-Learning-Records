## 1. 437. 路径总和 III

### 1.1 完整实现（前缀和 + 哈希 + 回溯）

```java
/**
 * LeetCode 437. 路径总和 III
 * 路径不必从根开始、不必到叶子结束（自上而下连续即可）
 * 前缀和思想：连续段和 = cur(当前前缀) - pre(祖先前缀)
 * → HashMap 记录各前缀出现次数，查 cur - target
 */
public int pathSum(TreeNode root, int targetSum) {
    Map<Long, Integer> prefix = new HashMap<>();
    prefix.put(0L, 1);                    // ⚠️ 空路径前缀：允许从根开始
    return dfs(root, 0, targetSum, prefix);
}

private int dfs(TreeNode node, long cur, int target,
                Map<Long, Integer> prefix) {
    if (node == null) return 0;
    cur += node.val;                                    // ① 当前前缀和
    int cnt = prefix.getOrDefault(cur - target, 0);     // ② 查起点（先查后记！）
    prefix.merge(cur, 1, Integer::sum);                 // ③ 记录本前缀
    cnt += dfs(node.left, cur, target, prefix);         // ④ 递归
    cnt += dfs(node.right, cur, target, prefix);
    prefix.merge(cur, -1, Integer::sum);                // ⑤ ⚠️ 离开撤销
    return cnt;
}
// 推演 [10,5,-3,3,2,null,11,3,-2,null,1], target=8 → 3
//   5→3 ✓  5→2→1 ✓  -3→11 ✓
// ⚠️ 面试必答：
//   "与数组'和为 K 的子数组'同构，只是把线性回溯
//    换成 DFS 路径回溯；先查后记防把当前节点当起点，
//    long 防溢出；撤销计数防兄弟分支污染。O(n)。"
```

## 2. 199. 二叉树的右视图

### 2.1 完整实现（BFS 每层最后一个）

```java
/**
 * LeetCode 199. 二叉树的右视图
 * 层序遍历：每层最后一个节点即右视图成员
 */
public List<Integer> rightSideView(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    if (root == null) return res;

    Queue<TreeNode> q = new LinkedList<>();
    q.offer(root);
    while (!q.isEmpty()) {
        int size = q.size();
        for (int i = 0; i < size; i++) {
            TreeNode node = q.poll();
            if (i == size - 1) res.add(node.val);   // ⚠️ 每层最后一个
            if (node.left != null) q.offer(node.left);
            if (node.right != null) q.offer(node.right);
        }
    }
    return res;
}
// 推演 [1,2,3,null,5,null,4] → [1,3,4] ✓
// ⚠️ 面试必答：
//   "BFS 模板只改一行——i == size-1 才记录；
//    变体：左视图 i==0，层平均值、锯齿都是同一模板。"
```

### 2.2 DFS 版（先右后左 + 深度判首次）

```java
public void dfs(TreeNode node, int depth, List<Integer> res) {
    if (node == null) return;
    if (depth == res.size()) res.add(node.val);  // 首次到达该深度 → 最右
    dfs(node.right, depth + 1, res);             // ⚠️ 先右后左
    dfs(node.left, depth + 1, res);
}
// ⚠️ 面试必答："DFS 先右后左 → 每层第一个到达的
//   就是右视图；空间 O(h) 优于 BFS 的 O(n)。"
```

## 3. 114. 二叉树展开为链表

### 3.1 完整实现（右左中 + 前驱指针）

```java
/**
 * LeetCode 114. 二叉树展开为链表（右指针串联，左置空）
 * 右左中遍历 = 后序变体：先展开右、再展开左
 * pre 指向"已展开链表"的头，当前节点右指针接上
 */
class Solution {
    private TreeNode pre = null;

    public void flatten(TreeNode root) {
        if (root == null) return;
        flatten(root.right);       // ① 先展开右子树
        flatten(root.left);        // ② 再展开左子树
        root.right = pre;          // ③ 当前右指针 → 已展开部分
        root.left = null;          //    左指针置空
        pre = root;                // ④ 当前成为链表新头
    }
}
// 推演 [1,2,5,3,4,null,6] → 1→2→3→4→5→6 ✓
// ⚠️ 面试必答：
//   "为什么右左中？先右后左 → 递归返回时
//    pre 恰好是'比当前小的下一个'；
//    左置空满足链表定义。O(n)/O(h)。"
```

### 3.2 原地迭代（O(1) 空间备选）

```java
// 每个节点：左子树存在 → 找左子树最右节点，
//   把右子树接到它后面，左子树移到右指针位置
// ⚠️ 面试必答："O(1) 空间原地改造（找最右节点），
//   递归版更易写——先写递归，追问空间再上原地。"
```

## 4. 337. 打家劫舍 III

### 4.1 完整实现（树形 DP 状态机）

```java
/**
 * LeetCode 337. 打家劫舍 III
 * 不能偷父子相邻 → 每个节点返回 {不选, 选} 两种最优
 * 转移：不选 → 子自由；选 → 子必须不选
 */
public int rob(TreeNode root) {
    int[] res = dfs(root);
    return Math.max(res[0], res[1]);
}

private int[] dfs(TreeNode node) {
    if (node == null) return new int[2];
    int[] l = dfs(node.left), r = dfs(node.right);

    int notRob = Math.max(l[0], l[1]) + Math.max(r[0], r[1]);
    int rob    = node.val + l[0] + r[0];
    return new int[]{notRob, rob};
}
// 推演 [3,2,3,null,3,null,1]：
//   节点2：不选=3（偷左孙3），选=2        → [3,2]
//   节点3(右)：不选=1（偷右孙1），选=3    → [1,3]
//   根3：不选=3+3=6，选=3+0+0=3 → 答案 7 ✓
//   实际最优：根3 + 左孙3 + 右孙1 = 7 ✓
// ⚠️ 面试必答：
//   "树形DP = 后序 + 状态数组；无重叠子问题
//    （每个节点只访问一次）→ 不需要 memo；
//    与数组版 198 的区别是树形依赖而非线性依赖。"
```

## 5. 968. 监控二叉树

### 5.1 完整实现（三状态贪心）

```java
/**
 * LeetCode 968. 监控二叉树
 * 自底向上贪心：叶子交给父覆盖最省（一台相机覆盖 3 层）
 * 状态：0 未覆盖 / 1 有相机 / 2 已被覆盖
 */
class Solution {
    int cameras = 0;

    public int minCameraCover(TreeNode root) {
        if (dfs(root) == 0) cameras++;   // ⚠️ 根残留未覆盖 → 兜底补一台
        return cameras;
    }

    private int dfs(TreeNode node) {
        if (node == null) return 2;              // 空节点视为已覆盖
        int l = dfs(node.left), r = dfs(node.right);

        if (l == 0 || r == 0) { cameras++; return 1; }  // 子未覆盖 → 装相机
        if (l == 1 || r == 1) return 2;                  // 子有相机 → 被覆盖
        return 0;                                        // 子均覆盖 → 交给父
    }
}
// 推演 [0,0,null,0,0] → 叶子均返回 0 → 父装 1 台 → 根被覆盖 → 答案 1 ✓
// 推演 [0,0,null,0,null,0,null,null,0]（单链）→ 2 ✓
// ⚠️ 面试必答：
//   "三条转移对应三种孩子状态；空节点必须返回 2
//    （否则叶子会被误判未覆盖）；根是唯一没有
//    父节点的位置 → 最后单独兜底。O(n)。"
```

## 6. 662. 二叉树最大宽度

### 6.1 完整实现（完全二叉树编号 + 层内极差）

```java
/**
 * LeetCode 662. 二叉树最大宽度
 * 完全二叉树编号：根=1，左=2i，右=2i+1
 * 每层宽度 = 最右编号 - 最左编号 + 1
 */
public int widthOfBinaryTree(TreeNode root) {
    Deque<TreeNode> q = new ArrayDeque<>();
    Deque<Integer> ids = new ArrayDeque<>();
    q.offer(root); ids.offer(1);                // 根编号 1

    int max = 0;
    while (!q.isEmpty()) {
        int size = q.size();
        int left = ids.peek(), right = left;    // 本层最左编号
        for (int i = 0; i < size; i++) {
            TreeNode node = q.poll();
            int id = ids.poll();
            right = id;                         // 不断更新最右编号
            if (node.left != null)  { q.offer(node.left);  ids.offer(id * 2); }
            if (node.right != null) { q.offer(node.right); ids.offer(id * 2 + 1); }
        }
        max = Math.max(max, right - left + 1);
    }
    return max;
}
// 推演 [1,3,2,5,3,null,9]：
//   第 3 层编号 4,5,7 → 宽度 7-4+1 = 4 ✓（null 也算宽度！）
// ⚠️ 面试必答：
//   "编号法把'空位占宽'转为数值差——null 不计入
//    队列但编号保留；树深超 31 层编号溢出 → 用
//    long 或每层减去本层 left 归一化。O(n)。"
```

## 7. 222. 完全二叉树的节点个数

### 7.1 完整实现（满树公式 + 一侧递归）

```java
/**
 * LeetCode 222. 完全二叉树的节点个数
 * 完全二叉树：左右高度相等 → 左子树必满，直接 2^h-1
 * 不相等 → 右子树必满，递归左子树
 * ⚠️ 每层只递归一侧 → O(log²n) 而非 O(n)
 */
public int countNodes(TreeNode root) {
    if (root == null) return 0;
    int lh = height(root.left), rh = height(root.right);
    if (lh == rh) {
        return (1 << lh) + countNodes(root.right);   // 左满：公式 + 递归右
    }
    return (1 << rh) + countNodes(root.left);        // 右满：公式 + 递归左
}

private int height(TreeNode node) {   // 完全二叉树高度 = 一路向左
    int h = 0;
    while (node != null) { h++; node = node.left; }
    return h;
}
// 推演 [1,2,3,4,5,6] → 6：
//   根 lh=2, rh=2 → 4 + countNodes(3 子树)；
//   3 子树 lh=1, rh=0 → 1 + countNodes(6)；
//   6 子树 lh=0, rh=0 → 1 + 0 → 共 4+1+1 = 6 ✓
// ⚠️ 面试必答：
//   "关键洞察：完全二叉树左右高度必然'一满一
//    递归'——利用 2^h-1 公式 O(1) 结算满的一侧，
//    每次下降一层 → O(log²n)。暴力 BFS 是 O(n)。"
```
