## 1. 核心概念

### 1.1 博弈问题的模型

> 博弈题：**双人轮流操作**，双方都采取最优策略，问先手胜负/最大收益。模型为零和博弈（一方赢即另一方输）。

```
常见模型：
  ① 取石子类：Nim 游戏（异或和判胜负）
  ② 区间博弈：双方从两端取数（博弈 DP）
  ③ 状态博弈：状态转移有必胜/必败之分

三个基本概念：
  必胜态（N 态）：存在一步走到必败态
  必败态（P 态）：所有步都走到必胜态
  终局：无法操作 → 必败（轮到的人输）

博弈 = 从终局倒推（递归/DP）
```

### 1.2 三种博弈形态

| 形态 | 特征 | 解法 | 代表题 |
|------|------|------|:---:|
| **数学博弈** | 有公式规律 | 数学推导 O(1) | 292/1025 |
| **区间博弈** | 两端取数 | 区间 DP | 486/877 |
| **状态博弈** | 状态可枚举 | 记忆化+位掩码 | 464/913 |

```
识别信号：
  "轮流取石子/选数" → 先小规模找规律
  规律清晰 → 数学；状态多 → DP/记忆化
```

### 1.3 Nim 游戏与异或和

```
经典 Nim：n 堆石子，每轮取一堆的任意数量（可全取）
先手必胜 ⇔ 所有堆数量异或和 ≠ 0

证明（关键洞察）：
  异或和 = 0（平衡态）→ 无论怎么取，异或和变非 0
    （取某堆 x 为 x'，异或和必变 → 破坏平衡）
  异或和 ≠ 0 → 存在取法使异或和变 0
    （设 xor = s，找某堆 x 使 x' = x ^ s < x，
      取该堆为 x' → 新异或和 = 0）
  → 保持平衡者必胜（对手破坏平衡，我恢复平衡）

记忆：xor == 0 → 先手必败；xor != 0 → 先手必胜
```

## 2. 完整代码模板

### 2.1 区间博弈 DP 模板（486 预测赢家）

```java
/**
 * 区间博弈通用模板
 * dp[i][j] = 先手玩家在区间 [i,j] 的净胜分
 *
 * 转移（零和博弈）：
 *   dp[i][j] = max(nums[i] - dp[i+1][j],   // 取左端
 *                  nums[j] - dp[i][j-1])    // 取右端
 *   （我取 x 后，对手在剩余区间是先手，
 *     其净胜分从我的收益中扣除）
 */
public boolean predictWinner(int[] nums) {
    int n = nums.length;
    int[][] dp = new int[n][n];

    for (int i = 0; i < n; i++) {
        dp[i][i] = nums[i];               // 单元素：先手直接拿
    }

    for (int len = 2; len <= n; len++) {  // 区间长度递增
        for (int i = 0; i + len - 1 < n; i++) {
            int j = i + len - 1;
            dp[i][j] = Math.max(
                nums[i] - dp[i + 1][j],
                nums[j] - dp[i][j - 1]);
        }
    }
    return dp[0][n - 1] >= 0;             // 先手净胜分 ≥ 0 获胜
}
// 推演 [1, 5, 2]：
// dp[1][2] = max(5-2, 2-5) = 3（先手在 [5,2] 净胜 3）
// dp[0][2] = max(1-3, 2-4) = -2 → 先手输 ✓
```

### 2.2 状态博弈模板（记忆化 + 位掩码）

```java
/**
 * 状态博弈通用模板（464 我能赢吗）
 * 状态 = 局面（位掩码/位置组合）
 */
public boolean stateGame(状态参数) {
    Boolean[] memo = new Boolean[1 << n];   // ⚠️ Boolean 可判"未计算"
    return dfs(初始状态, memo);
}

private boolean dfs(int mask, Boolean[] memo) {
    if (memo[mask] != null) return memo[mask];

    for (每个可行操作) {
        int nextMask = mask | (1 << i);
        // ⚠️ 对手视角取反：对手必败 → 我必胜
        if (操作后直接赢 || !dfs(nextMask, memo)) {
            return memo[mask] = true;       // 存在一步必胜
        }
    }
    return memo[mask] = false;              // 所有步都输 → 必败
}
// 状态数检查（面试第一句）：
// "状态 2^n ≈ 10⁶，记忆化可行，复杂度 O(2^n × n)"
```

## 3. 必胜态判定原理

### 3.1 递归定义与倒推

```
必败态（P）：轮到的人必输（所有走法都到 N 态）
必胜态（N）：轮到的人必胜（存在一步到 P 态）

倒推示例（取 1-3 个，取完者胜）：
  n=0：终局 → P（无法操作）
  n=1,2,3：可取完 → 到 n=0(P) → N
  n=4：只能到 1,2,3（都 N）→ P
  n=5,6,7：可取到 4(P) → N
  n=8：只能到 5,6,7（都 N）→ P
  → 规律：4 的倍数必败 ✓

本质：博弈 DP 与普通 DP 的唯一区别是
  "转移时切换玩家视角"（对手的必胜 = 我的必败）
```

### 3.2 净胜分 vs 必胜性的选择

```
两种状态表示：
  ① 净胜分（数值）：dp = 我拿的 - 对手拿的
     适用：求"最大收益/能否获胜"（486）
  ② 必胜性（布尔）：dp = 当前玩家是否必胜
     适用：状态多、只问胜负（464）

选择：需要"最大得分"→ 净胜分；只问胜负 → 布尔
（877 用净胜分可同时得到最优策略）
```

### 3.3 平局的处理（进阶）

```
状态博弈可能有平局（913 猫和老鼠）：
  ① 从"确定结局"状态逆推（BFS 染色）
  ② 无法确定的状态 = 平局
  ⚠️ 有环时普通记忆化无法收敛
  → 需要逆推传播（见 01-博弈进阶）

识别信号："返回 0 平局 / 1 赢 / 2 输" → 逆推
```

## 4. 博弈与 DP 的关系

### 4.1 博弈 DP 的特殊性

```
普通 DP：dp[状态] = 最优值（单方视角）
博弈 DP：dp[状态] = 当前玩家视角的胜负/净胜分

差异一：视角切换
  普通：dp[i] = max(选择)
  博弈：dp[i] = max(选择 - 对手dp[后续])

差异二：目标
  普通：最大化自己的收益
  博弈：最大化"自己的收益 - 对手收益"（零和）

记忆："博弈 DP 的减法 = 零和博弈的体现"
```

### 4.2 博弈 vs 贪心

```
贪心：每步选"当下最优"——博弈中对手会反击
  → 贪心在博弈中几乎总是错误！

例（486）：先手贪心取两端较大者
  [1, 5, 2]：贪心取 2 → 对手拿 5 → 先手 3 输
  最优：取 1 → 对手被迫拿 5 或 2 → 先手 5+2-1... 
  实际最优是先手取 1（净胜 -2，仍然输，但比贪心好）

⚠️ 博弈必须"考虑对手的最优应对"（minimax 思想）
```

### 4.3 与 minimax 的关系

```
博弈 DP = minimax 思想的表格化：
  我走：max（选对自己最有利的）
  对手走：min（对手会选对我最不利的）
  → 交替 max/min（与"净胜分减法"等价）

面试话术：
"这是零和博弈，用 minimax 思想：
 我的收益最大化等价于对手收益最小化，
 所以转移用'取数 - 对手净胜分'，
 交替考虑双方的最优策略。"
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"博弈题从终局倒推：
 必败态是'怎么走都到必胜态'，
 必胜态是'存在一步到必败态'。
 这题状态是【区间/掩码/(i,M)】，
 转移用零和视角——我取 x 后对手在
 剩余局面的净胜分要从我的收益扣除。
 复杂度【O(n²)/O(2^n)】，
 状态数【10⁶】记忆化可行。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 为什么 xor=0 必败？ | Nim 平衡态：任何操作破坏平衡，对手总能恢复平衡（取 x' = x ^ s） |
| 2 | 博弈和普通 DP 区别？ | 博弈切换玩家视角（对手净胜分扣除）；普通 DP 只求单方最优 |
| 3 | 贪心为什么不行？ | 对手会反击——每步局部最优会被对手利用（minimax 思想） |
| 4 | 状态怎么压缩？ | 剩余和可由掩码推导 → 一维状态；多参数用 (i, M) 等 |
| 5 | 平局怎么处理？ | 有环 → 无法直接记忆化 → 从确定结局逆推 BFS |
| 6 | 净胜分 vs 布尔？ | 求最大得分 → 净胜分；只问胜负 → 布尔（省空间） |
| 7 | 什么时候找数学规律？ | 单堆/简单约束 → 小规模手算找规律 + 归纳证明 |
| 8 | SG 定理是什么？ | 子游戏独立时 SG=mex(可达SG)，总局面=异或（竞赛级） |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 忘记视角切换 | dp 变成"单方贪心" | 转移用减法/取反 |
| 状态漏参数 | 答案错误（M 会变） | 状态包含所有决定性参数 |
| 记忆化用 boolean[] | 无法区分未计算 | 用 Boolean[]/int[](-1) |
| 有环用普通递归 | 栈溢出/不收敛 | 逆推传播（913） |
| 贪心代替博弈 | 被对手反制 | 始终考虑对手最优 |

> 🎯 **核心要点**：博弈 = **终局倒推 + 零和视角转移**。三大形态（数学/区间 DP/状态博弈）按"状态可否枚举"选型；Nim 异或和（xor=0 必败）是数学代表，486 净胜分是 DP 代表。识别信号："轮流取数、先手必胜、最优策略"。
