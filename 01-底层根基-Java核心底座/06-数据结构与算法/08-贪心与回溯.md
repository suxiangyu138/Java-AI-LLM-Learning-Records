# 贪心算法与回溯算法

## 📌 课程定位
贪心和回溯是两种截然不同的解题策略——贪心追求"局部最优导致全局最优"的高效，回溯追求"穷举所有可能"的完备。两者在面试中都是常客。

## 🎯 核心章节

### 第一部分：贪心算法

### 1. 贪心核心思想
- **每一步做当前看起来最优的选择**，期望最终全局最优
- **贪心选择性**：局部最优能推出全局最优（用数学归纳法或交换论证证明）
- **与DP的区别**：DP会考虑所有子问题，贪心只做一个选择

### 2. 经典贪心问题
- **活动安排/区间调度**：按结束时间排序，每次选最早结束的——最优子结构的经典证明
- **哈夫曼编码**：每次取两棵权值最小的树合并——用最小堆实现
- **找零钱问题**：硬币面额满足贪心选择性时可以用贪心（如人民币1-5-10-20-50-100）
- **Dijkstra最短路**：每次选当前距离最短的未访问结点——贪心的图论应用
- **最小生成树（Prim/Kruskal）**：每次都选最小能连接的边

### 3. 贪心 vs DP 辨识
- 0-1背包 vs 部分背包：前者每种物品有1个（DP），后者可切割（贪心拿单价最高的）
- 关键判断：子问题之间是否有依赖/冲突？有→DP，无→可考虑贪心

### 第二部分：回溯算法

### 4. 回溯核心思想
- **DFS + 状态重置** = 回溯——穷举（或剪枝后穷举）所有解
- **解空间树**：每个决策是一个分支——回溯就是在这棵树上做DFS
- **核心三步模板**：
  1. 做选择
  2. 递归进入下一层
  3. 撤销选择

### 5. 经典回溯问题（⭐ 必刷）
- **子集问题（#78）**：每个元素选/不选——O(2ⁿ)
- **组合问题（#77）**：从n选k——按start索引避免重复
- **排列问题（#46）**：n个数的全排列——用visited数组标记
- **N皇后（#51）**：行列+对角线冲突检测 + 回溯
- **数独求解器（#37）**：空格逐个尝试1-9
- **括号生成（#22）**：左括号数≥右括号数的剪枝条件

### 6. 剪枝优化（⭐ 关键）
- **可行性剪枝**：当前路径不可能产生合法解，直接返回
- **最优性剪枝**：当前路径已经比已知最优解差，放弃搜索
- **排序预处理**：如组合问题先排序，遇到相同的跳过避免重复解
- **记忆化**：中间状态保存下来，遇到重复直接查表（记忆化搜索 = DP的自顶向下版本）

### 7. 分支限界法（了解）
- 回溯是DFS搜索解空间，分支限界是BFS搜索
- 用优先队列管理活结点，按优先级扩展
- 常用于求最优解（如旅行商问题、任务分配）

## ✅ 学习建议
- 回溯题重点在剪枝——不加剪枝大部分会超时
- 排列/组合/子集 三个回溯模板必须默写，这是所有回溯题的母题
- 贪心最难的部分是证明正确性，面试时至少要能说清"为什么局部最优能导致全局最优"
