## 一、高级设计和分析技术

> 高级设计和分析技术是构建高效算法的三大核心方法论——动态规划以空间换时间解决最优子结构问题，贪心算法以局部最优实现高效决策，摊还分析则从操作序列角度评估整体性能。

### 1.1 动态规划

#### 核心思想

动态规划（Dynamic Programming）的核心是"将复杂问题分解为重叠子问题，通过存储子问题的最优解避免重复计算"，其前提条件是具备**最优子结构**与**子问题重叠**性质。

| 对比项 | 动态规划 | 递归（无记忆化） | 暴力破解 |
|-------|---------|----------------|---------|
| 核心方法 | 自底向上，缓存子问题结果 | 自顶向下，递归调用 | 枚举所有可能 |
| 时间复杂度 | 多项式级 | 指数级 | 指数级 |
| 空间复杂度 | 较高（需缓存） | 较低 | 最低 |
| 后端适用性 | 高并发稳定 | 栈溢出风险 | 不可用于海量数据 |

#### Java 实现：最优令牌分配（限流场景）

```java
public class DynamicTokenAllocation {
    public int maxThroughput(int[] requestNums, int maxToken) {
        int n = requestNums.length;
        int[][] dp = new int[n][maxToken + 1];
        for (int j = 0; j <= maxToken; j++) dp[0][j] = Math.min(j, requestNums[0]);
        for (int i = 1; i < n; i++)
            for (int j = 0; j <= maxToken; j++)
                for (int k = 0; k <= maxToken; k++)
                    dp[i][j] = Math.max(dp[i][j], dp[i - 1][k] + Math.min(j, requestNums[i]));
        int max = 0;
        for (int j = 0; j <= maxToken; j++) max = Math.max(max, dp[n - 1][j]);
        return max;
    }
}
```

#### 后端应用场景

| 场景 | 问题建模 | 动态规划思想 |
|------|---------|------------|
| 缓存淘汰策略 | 有限空间内缓存访问频率最高的数据 | 最优二叉搜索树 / 最长公共子序列 |
| 订单拆分与合并 | 大额订单拆分为符合物流限制的小订单 | 矩阵链乘法 |
| SQL 查询优化 | 多表 JOIN 的连接顺序选择 | 最优子问题组合 |

> ⚠️ 注意事项：避免过度缓存导致内存溢出，可用滚动数组优化空间；子问题无重叠则不适合 DP。

### 1.2 贪心算法

#### 核心思想

贪心算法（Greedy Algorithm）每一步都做出当前最优选择，期望最终达到全局最优，前提是满足**贪心选择性质**与**最优子结构**。

| 对比项 | 贪心算法 | 动态规划 |
|-------|---------|---------|
| 决策方式 | 局部最优，即时决策 | 全局最优，回溯选择 |
| 缓存需求 | 无需缓存 | 需缓存子问题结果 |
| 时间复杂度 | 更低（通常 O(n log n)） | 较高（通常 O(n²)） |
| 适用场景 | 高并发快速决策 | 复杂优化问题 |

#### Java 实现：最短任务优先调度

```java
public class ShortestTaskFirstComparator implements Comparator<Runnable> {
    @Override
    public int compare(Runnable o1, Runnable o2) {
        if (o1 instanceof Task && o2 instanceof Task)
            return Integer.compare(((Task) o1).getExecuteTime(), ((Task) o2).getExecuteTime());
        return 0;
    }
}
// 应用于线程池
ExecutorService executor = new ThreadPoolExecutor(5, 10, 60L, TimeUnit.SECONDS,
        new PriorityBlockingQueue<>(10, new ShortestTaskFirstComparator()));
```

#### 后端应用场景

| 场景 | 策略 | 说明 |
|------|------|------|
| 负载均衡 | 最小连接数优先 | 每次选择当前连接数最少的服务器 |
| 数据压缩 | 哈夫曼编码 | 高频字符分配短编码 |
| 任务调度 | 最短任务优先（SJF） | 执行时间短的任务优先调度 |

> ⚠️ 局限性：需验证局部最优能推导全局最优；设置兜底策略避免长任务饥饿。

### 1.3 摊还分析

#### 核心思想

摊还分析（Amortized Analysis）关注**操作序列的整体平均性能**，而非单次操作的最坏时间复杂度，适合评估高并发场景下的长期性能。

| 分析方法 | 核心思想 | 后端适用性 |
|---------|---------|-----------|
| **聚集分析** | 先算总账再平均 | 最适合后端场景，无需复杂数学推导 |
| **记账方法** | 提前预支费用 | 适合多种操作类型组合 |
| **势能方法** | 状态映射计算变化 | 适合复杂数据结构分析 |

#### 经典分析：ArrayList 扩容

```text
初始容量 1，每次扩容为 2 倍
插入 n 个元素：
- 扩容次数：log₂(n) 次
- 总操作数：n（插入）+ (2 + 4 + ... + n)（扩容复制）= 3n - 2
- 摊还复杂度：(3n - 2) / n ≈ 3 → O(1)
```

#### 后端应用场景

| 场景 | 分析对象 | 结论 |
|------|---------|------|
| ArrayList 扩容 | 频繁插入 | 单次扩容 O(n)，摊还 O(1) |
| HashMap 扩容 | 负载因子 0.75 触发 | 单次 rehash O(n)，摊还 O(1) |
| 数据库连接池 | 连接创建与复用 | 单次创建成本高，复用后摊还极低 |
| StringBuilder | 字符数组扩容 | 与 ArrayList 类似，摊还 O(1) |

## 二、概率分析和随机算法

> 概率分析利用输入分布计算平均运行时间；随机算法通过引入随机选择使性能不依赖输入分布，是后端系统稳定性保障的核心工具。

### 2.1 随机算法的两大类型

| 类型 | 特点 | 正确性 | 运行时间 | 后端应用 |
|------|------|--------|---------|---------|
| **Las Vegas（拉斯维加斯）** | 一定给出正确解 | 100% 正确 | 随机 | 随机快排、随机选择、哈希冲突解决 |
| **Monte Carlo（蒙特卡洛）** | 运行时间固定 | 概率正确，错误率可控 | 固定 | 布隆过滤器、采样统计、近似计算 |

### 2.2 随机快速排序

随机选择基准值，避免最坏情况（已排序 / 逆序输入），期望时间复杂度 O(n log n)。

```java
public class RandomQuickSort {
    public void sort(int[] arr) { quickSort(arr, 0, arr.length - 1); }
    private void quickSort(int[] arr, int left, int right) {
        if (left >= right) return;
        int pivot = randomPartition(arr, left, right);
        quickSort(arr, left, pivot - 1);
        quickSort(arr, pivot + 1, right);
    }
    private int randomPartition(int[] arr, int left, int right) {
        int randIdx = left + (int) (Math.random() * (right - left + 1));
        swap(arr, randIdx, right);
        int pivot = arr[right], i = left - 1;
        for (int j = left; j < right; j++)
            if (arr[j] <= pivot) swap(arr, ++i, j);
        swap(arr, i + 1, right);
        return i + 1;
    }
    private void swap(int[] arr, int i, int j) {
        int temp = arr[i]; arr[i] = arr[j]; arr[j] = temp;
    }
}
```

### 2.3 随机选择（TopK 问题）

随机基准找第 k 小元素，期望时间复杂度 O(n)。复用与随机快排相同的`randomPartition`逻辑。

```java
public class RandomizedSelection {
    public int findKthSmallest(int[] arr, int k) {
        return quickSelect(arr, 0, arr.length - 1, k - 1);
    }
    private int quickSelect(int[] arr, int left, int right, int k) {
        if (left == right) return arr[left];
        int pivot = randomPartition(arr, left, right);
        if (k == pivot) return arr[k];
        else if (k < pivot) return quickSelect(arr, left, pivot - 1, k);
        else return quickSelect(arr, pivot + 1, right, k);
    }
}
```

### 2.4 随机哈希（HashMap 底层）

随机种子 + 扰动函数减少哈希冲突，保证期望 O(1) 查找。

```java
public class RandomizedHashMap {
    static class Node { int key, val; Node next; Node(int k, int v) { key = k; val = v; } }
    private Node[] table = new Node[16];
    private final int seed = (int) (Math.random() * Integer.MAX_VALUE);

    public void put(int key, int val) {
        int idx = hash(key) & (table.length - 1);
        Node newNode = new Node(key, val);
        if (table[idx] == null) { table[idx] = newNode; }
        else { Node curr = table[idx]; while (curr.next != null) curr = curr.next; curr.next = newNode; }
    }
    private int hash(int key) { key ^= seed; key ^= (key >>> 16); return key; }
}
```

### 2.5 后端应用场景

| 领域 | 具体应用 | 随机化策略 |
|------|---------|-----------|
| **负载均衡** | Nginx 随机路由、RPC 随机调用 | 加权随机选择，保证节点负载均匀 |
| **安全防攻击** | 随机令牌防重放、随机盐值加密 | 引入不可预测性，防止彩虹表攻击 |
| **大数据采样** | 海量数据随机抽样、布隆过滤器 | 随机哈希 + 概率数据结构，空间高效 |
| **分布式分片** | 一致性哈希虚拟节点 | 虚拟节点随机分布，避免数据倾斜 |

## 三、分支策略

> 分支策略是分治法中"分解"步骤的核心规则，决定如何将原问题拆分为子问题，直接影响分治算法的效率、稳定性与落地场景。

### 3.1 三大核心类型

| 类型 | 策略 | 递归深度 | 后端应用 |
|------|------|---------|---------|
| **二分分支** | 拆分为 2 个规模相等 / 相近的子问题 | log n | 归并排序、二分查找 |
| **多分分支（k 分）** | 拆分为 k 个子问题（k > 2） | logₖ n | 多路归并排序、分布式多节点分片 |
| **不平衡分支** | 根据数据特征动态拆分 | 最坏 O(n) | 快速排序（基准值选择）、动态分片 |

### 3.2 递归式求解（主定理）

```
T(n) = aT(n/b) + f(n)
```

| 参数 | 含义 |
|------|------|
| a | 子问题数 |
| b | 规模缩减因子 |
| f(n) | 合并代价 |

**主定理三种情况**：

```
1. 若 f(n) = O(n^(log_b a - ε))，则 T(n) = Θ(n^(log_b a))
2. 若 f(n) = Θ(n^(log_b a))，则 T(n) = Θ(n^(log_b a) · log n)
3. 若 f(n) = Ω(n^(log_b a + ε))，则 T(n) = Θ(f(n))
```

### 3.3 排序算法中的分支策略

#### 归并排序（二分分支）

```java
public void mergeSort(int[] arr, int left, int right, int[] temp) {
    if (left >= right) return;
    int mid = left + (right - left) / 2;
    mergeSort(arr, left, mid, temp);
    mergeSort(arr, mid + 1, right, temp);
    merge(arr, left, mid, right, temp);
}
```

| 维度 | 归并排序 | 快速排序 | 多路归并排序 |
|------|---------|---------|------------|
| 分支类型 | 二分平衡分支 | 动态不平衡分支 | 多分分支 |
| 复杂度 | O(n log n) | 平均 O(n log n)，最坏 O(n²) | O(n logₖ n) |
| 稳定性 | 稳定 | 不稳定 | 稳定 |
| 后端应用 | JDK `Arrays.sort` 对象排序 | JDK `Arrays.sort` 基础类型 | 大数据外部排序 |

### 3.4 分布式系统中的分支策略

| 场景 | 分支策略 | 说明 |
|------|---------|------|
| **分库分表** | k 路平衡分支 | 按哈希 / 范围拆分为 k 个分片，一致性哈希避免数据倾斜 |

### 3.5 ForkJoin 框架（Java 并行计算）

```java
public class ForkJoinSort extends RecursiveAction {
    private static final int THRESHOLD = 100;
    private int[] arr;
    private int left, right;

    public ForkJoinSort(int[] arr, int left, int right) {
        this.arr = arr; this.left = left; this.right = right;
    }

    @Override
    protected void compute() {
        if (right - left <= THRESHOLD) { Arrays.sort(arr, left, right + 1); return; }
        int mid = left + (right - left) / 2;
        invokeAll(new ForkJoinSort(arr, left, mid), new ForkJoinSort(arr, mid + 1, right));
    }
}
```

### 3.6 选型原则与常见误区

#### 选型原则

| 原则 | 说明 |
|------|------|
| **平衡优先** | 优先选择二分平衡分支，保证 O(n log n) 复杂度 |
| **场景适配** | 排序/查找用二分分支；分布式用多分分支（k = 4~8）；动态负载用不平衡分支 |
| **开销控制** | 分支数不宜过多（k > 8 管理开销剧增）；递归深度控制避免栈溢出 |
| **稳定性保障** | 归并排序稳定；快排不稳定（分支拆分导致元素相对位置变化） |

#### 常见误区

> ⚠️

| 误区 | 后果 |
|------|------|
| **过度分支** | 子问题管理开销大于计算收益 |
| **分支倾斜** | 数据分布不均导致退化为 O(n²) |
| **忽视合并代价** | 分支拆分简单但合并代价过高 |
| **递归深度失控** | 大数据场景下栈溢出 |

## 四、线性规划

> 线性规划是在一组线性约束条件下求解线性目标函数最大值或最小值的问题，核心三要素为**决策变量**、**目标函数**、**约束条件**。

### 4.1 标准型

《算法导论》定义的线性规划标准型：

| 要素 | 要求 | 后端适配 |
|------|------|---------|
| **目标函数** | 统一为最大化（max） | 最小化问题转化为 max(-Z) |
| **约束条件** | 等式约束，常数非负 | 引入松弛变量 / 剩余变量 |
| **决策变量** | 所有变量非负 | 实际场景中变量通常天然非负 |

### 4.2 核心求解算法

| 算法 | 时间复杂度 | 适用规模 | 推荐度 |
|------|-----------|---------|-------|
| **单纯形算法** | 指数级（最坏）但实际高效 | 变量 ≤ 1000 | 90% 场景首选 |
| **椭球算法** | 多项式时间 | 理论验证 | 不用于生产 |
| **内点算法** | 多项式时间 | 变量 ≥ 1000 | 大规模场景推荐 |

### 4.3 Google OR-Tools 示例

```java
import com.google.ortools.linearsolver.*;

public class LinearProgrammingDemo {
    static { System.loadLibrary("jniortools"); }

    public static void main(String[] args) {
        MPSolver solver = new MPSolver("FlowControl",
                MPSolver.OptimizationProblemType.GLOP_LINEAR_PROGRAMMING);
        MPVariable x1 = solver.makeNumVar(0.0, Double.POSITIVE_INFINITY, "query");
        MPVariable x2 = solver.makeNumVar(2000.0, Double.POSITIVE_INFINITY, "submit");
        MPVariable x3 = solver.makeNumVar(0.0, Double.POSITIVE_INFINITY, "stats");

        MPObjective obj = solver.objective();
        obj.setCoefficient(x1, 1); obj.setCoefficient(x2, 1);
        obj.setCoefficient(x3, 1); obj.setMaximization();

        MPConstraint c = solver.makeConstraint(0.0, 10000.0, "cap");
        c.setCoefficient(x1, 1); c.setCoefficient(x2, 1); c.setCoefficient(x3, 1);

        ResultStatus r = solver.solve();
        if (r == ResultStatus.OPTIMAL) {
            System.out.println("查询:" + x1.solutionValue() + " 提交:" + x2.solutionValue()
                    + " 统计:" + x3.solutionValue() + " 合计:" + obj.value());
        } else if (r == ResultStatus.INFEASIBLE) System.err.println("无可行解");
        else if (r == ResultStatus.UNBOUNDED) System.err.println("无界解");
    }
}
```

| 场景 | 建模 | 目标 |
|------|------|------|

## 五、数论算法

> 数论算法是现代加密（RSA）、分布式 ID 生成、数据校验等后端核心场景的底层支撑，其效率与正确性直接影响系统的性能与安全性。

### 5.1 欧几里得算法（GCD）

求解两个整数的最大公约数，时间复杂度 O(lg min(a, b))。

```java
public class NumberTheoreticUtils {
    public static long gcd(long a, long b) {
        a = Math.abs(a); b = Math.abs(b);
        while (b != 0) { long t = b; b = a % b; a = t; }
        return a;
    }
    public static java.math.BigInteger gcd(java.math.BigInteger a, java.math.BigInteger b) {
        return a.abs().gcd(b.abs());
    }
    // 扩展欧几里得：ax + by = gcd(a, b) → [gcd, x, y]
    public static java.math.BigInteger[] extendedGcd(java.math.BigInteger a, java.math.BigInteger b) {
        if (b.equals(java.math.BigInteger.ZERO))
            return new java.math.BigInteger[]{a, java.math.BigInteger.ONE, java.math.BigInteger.ZERO};
        java.math.BigInteger[] r = extendedGcd(b, a.mod(b));
        return new java.math.BigInteger[]{r[0], r[2], r[1].subtract(a.divide(b).multiply(r[2]))};
    }
}
```

**应用场景**：RSA 密钥生成（e 与 φ(n) 互质判定）、分布式数据分片因子判定、哈希冲突优化。扩展欧几里得用于求解模逆元（RSA 解密密钥 d：`d ≡ e⁻¹ mod φ(n)`）。

### 5.2 Miller-Rabin 素数判定

基于费马小定理的随机化素数测试，时间复杂度 O(k · lg³ n)。

| 方法 | 时间复杂度 | 适用场景 |
|------|-----------|---------|
| 朴素试除法 | O(√n) | 小整数素数判定 |
| Miller-Rabin | O(k · lg³ n) | 大素数快速判定（k 轮测试） |

```java
import java.math.BigInteger;
import java.util.Random;

public class PrimeUtils {
    private static final Random RANDOM = new Random();

    public static boolean isPrime(BigInteger n, int k) {
        if (n.compareTo(BigInteger.TWO) < 0) return false;
        if (n.equals(BigInteger.TWO)) return true;
        if (n.mod(BigInteger.TWO).equals(BigInteger.ZERO)) return false;

        // n-1 = d * 2^s
        BigInteger d = n.subtract(BigInteger.ONE);
        int s = 0;
        while (d.mod(BigInteger.TWO).equals(BigInteger.ZERO)) { d = d.divide(BigInteger.TWO); s++; }

        for (int i = 0; i < k; i++) {
            BigInteger a = new BigInteger(n.bitLength() - 1, RANDOM).add(BigInteger.ONE);
            BigInteger x = a.modPow(d, n);
            if (x.equals(BigInteger.ONE) || x.equals(n.subtract(BigInteger.ONE))) continue;
            boolean pass = false;
            for (int r = 1; r < s; r++) {
                x = x.modPow(BigInteger.TWO, n);
                if (x.equals(n.subtract(BigInteger.ONE))) { pass = true; break; }
            }
            if (!pass) return false;
        }
        return true;
    }

    public static BigInteger generatePrime(int bitLength) {
        BigInteger p;
        do { p = new BigInteger(bitLength, RANDOM);
             if (p.mod(BigInteger.TWO).equals(BigInteger.ZERO)) p = p.add(BigInteger.ONE);
        } while (!isPrime(p, 10));
        return p;
    }
}
```

> 💡 后端中可直接使用 `BigInteger.isProbablePrime(int certainty)`，其底层基于 Miller-Rabin 实现。`certainty` 取 10 可兼顾效率与安全性。

### 5.3 模幂运算（反复平方算法）

计算 `a^b mod m`，时间复杂度 O(lg b)，远优于朴素乘法的 O(b)。

```java
// 大整数模幂（BigInteger 自带 modPow 方法，底层为反复平方算法）
// BigInteger.valueOf(a).modPow(BigInteger.valueOf(b), BigInteger.valueOf(m))

// 小整数模幂（迭代版，long 范围，效率更高）
public static long modPow(long a, long b, long m) {
    long result = 1;
    a = a % m;
    while (b > 0) {
        if ((b & 1) == 1) result = (result * a) % m;
        a = (a * a) % m;
        b = b >> 1;
    }
    return result;
}
```

### 6.1 矩阵乘法

#### 朴素算法 vs Strassen 算法

| 算法 | 时间复杂度 | 适用规模 | 特点 |
|------|-----------|---------|------|
| **朴素算法** | O(mnp) | 小规模矩阵 | 三重循环，实现简单 |
| **Strassen 算法** | O(n^log₂7) ≈ O(n^2.807) | 大规模方阵 | 分治法，7 次乘法替代 8 次 |

#### 朴素矩阵乘法 Java 实现

```java
public static double[][] denseMultiply(double[][] A, double[][] B) {
    int m = A.length, n = A[0].length, p = B[0].length;
    if (n != B.length) throw new IllegalArgumentException("维度不匹配");
    double[][] C = new double[m][p];
    for (int i = 0; i < m; i++)
        for (int j = 0; j < p; j++)
            for (int k = 0; k < n; k++)
                C[i][j] += A[i][k] * B[k][j];
    return C;
}
```

#### 稀疏矩阵乘法（三元组存储）

后端场景中用户-物品评分矩阵等多为稀疏矩阵（非零元素 < 10%），采用三元组存储节省内存。

```java
public class SparseMatrixUtils {
    public static class Triple { int row, col; double value;
        Triple(int r, int c, double v) { row = r; col = c; value = v; } }
    public static java.util.List<Triple> multiply(java.util.List<Triple> A, java.util.List<Triple> B,
                                                    int m, int n, int p) {
        java.util.List<Triple> result = new java.util.ArrayList<>();
        double[] temp = new double[p];
        int aIdx = 0;
        for (int i = 0; i < m; i++) {
            java.util.Arrays.fill(temp, 0.0);
            while (aIdx < A.size() && A.get(aIdx).row == i) {
                Triple aT = A.get(aIdx);
                for (Triple bT : B)
                    if (bT.row == aT.col) temp[bT.col] += aT.value * bT.value;
                aIdx++;
            }
            for (int j = 0; j < p; j++)
                if (Math.abs(temp[j]) > 1e-6) result.add(new Triple(i, j, temp[j]));
        }
        return result;
    }
}
```

### 6.2 高斯消元法（部分主元）

求解线性方程组 Ax = b，时间复杂度 O(n³)。

```java
public class GaussianElimination {
    private static final double EPS = 1e-6;

    public static double[] solve(double[][] A, double[] b) {
        int n = A.length;
        double[][] aug = new double[n][n + 1];        // 增广矩阵
        for (int i = 0; i < n; i++) {
            System.arraycopy(A[i], 0, aug[i], 0, n);
            aug[i][n] = b[i];
        }
        for (int k = 0; k < n; k++) {                 // 前向消元（部分主元）
            int pr = k;
            for (int i = k + 1; i < n; i++)
                if (Math.abs(aug[i][k]) > Math.abs(aug[pr][k])) pr = i;
            double[] t = aug[k]; aug[k] = aug[pr]; aug[pr] = t;
            if (Math.abs(aug[k][k]) < EPS) return null;
            for (int i = k + 1; i < n; i++) {
                double f = aug[i][k] / aug[k][k];
                for (int j = k; j <= n; j++) aug[i][j] -= f * aug[k][j];
            }
        }
        double[] x = new double[n];                   // 回代求解
        for (int i = n - 1; i >= 0; i--) {
            double sum = 0.0;
            for (int j = i + 1; j < n; j++) sum += aug[i][j] * x[j];
            x[i] = (aug[i][n] - sum) / aug[i][i];
        }
        return x;
    }
}
```

### 6.3 LU 分解

将方阵 A 分解为下三角矩阵 L 和上三角矩阵 U，适合多次求解同一系数矩阵的场景。

```java
public class LUDecomposition {
    private static final double EPS = 1e-6;

    public static double[][][] decompose(double[][] A) {
        int n = A.length;
        double[][] L = new double[n][n];
        double[][] U = new double[n][n];
        for (int i = 0; i < n; i++) L[i][i] = 1.0;
        for (int k = 0; k < n; k++) {
            for (int j = k; j < n; j++) {
                double sum = 0.0;
                for (int p = 0; p < k; p++) sum += L[k][p] * U[p][j];
                U[k][j] = A[k][j] - sum;
            }
            if (Math.abs(U[k][k]) < EPS) return null;
            for (int i = k + 1; i < n; i++) {
                double sum = 0.0;
                for (int p = 0; p < k; p++) sum += L[i][p] * U[p][k];
                L[i][k] = (A[i][k] - sum) / U[k][k];
            }
        }
        return new double[][][]{L, U};
    }

    public static double[] solve(double[][] L, double[][] U, double[] b) {
        int n = L.length;
        double[] y = new double[n];       // Ly = b（前向替代）
        for (int i = 0; i < n; i++) {
            double sum = 0.0;
            for (int j = 0; j < i; j++) sum += L[i][j] * y[j];
            y[i] = b[i] - sum;
        }
        double[] x = new double[n];       // Ux = y（回代求解）
        for (int i = n - 1; i >= 0; i--) {
            double sum = 0.0;
            for (int j = i + 1; j < n; j++) sum += U[i][j] * x[j];
            x[i] = (y[i] - sum) / U[i][i];
        }
        return x;
    }
}
```
