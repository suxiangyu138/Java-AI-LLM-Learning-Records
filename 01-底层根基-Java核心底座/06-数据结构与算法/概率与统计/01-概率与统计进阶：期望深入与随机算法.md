## 1. 期望线性性深入

### 1.1 核心定理回顾与威力

```
E[X+Y] = E[X] + E[Y]        （无需独立性！）
E[cX] = c·E[X]
E[X] = Σ E[Iᵢ]（指示变量分解）

威力场景：
  复杂事件的期望 → 拆成简单事件的指示变量
  例：n 个盒子每个放一个球，期望非空盒子数
    E[Iᵢ] = P(盒子 i 非空) = 1 - (1-1/n)^n
    E = n·(1-(1-1/n)^n) → 约 0.632n（n 大时）
  ⚠️ 直接算"非空数"的分布极难，指示变量一行搞定
```

### 1.2 经典应用：随机排列与逆序数

```
n 个元素随机排列，期望逆序对数：
  任意一对 (i,j)，i 在 j 前的概率 = 1/2（对称性）
  E = C(n,2) × 1/2 = n(n-1)/4

⚠️ 三步法（面试必答框架）：
  ① 定义指示变量 Iₖ（k = 事件对）
  ② E[Iₖ] = P(事件 k 发生)
  ③ E = Σ E[Iₖ]（线性性直接相加）
```

### 1.3 线性性的"反直觉"应用

```
例：期望掷几次骰子能集齐 6 个面（优惠券收集者问题）
  集齐时间 = 第一阶段（收集第 1 个新面）期望 + 第 2 个新面 + ...
  第 k 个新面的等待：当前已有 k-1 个面 → 新面概率 (6-k+1)/6
  期望 = Σ 6/(6-k+1) = 6·(1 + 1/2 + ... + 1/6) ≈ 14.7 次

⚠️ 关键：把"集齐"拆成"每次收集新面"的独立阶段
  虽然阶段间不独立（剩余面数变化），但期望线性性仍适用！
```

## 2. 条件期望与全概率公式

### 2.1 全概率公式（贝叶斯基础）

```
P(A) = Σᵢ P(A|Bᵢ)·P(Bᵢ)     （Bᵢ 是完备事件组）
E[X] = Σᵢ E[X|Bᵢ]·P(Bᵢ)     （全期望公式）

⚠️ 概率 DP 的数学本质：
  dp(状态) = Σ P(选择ᵢ) × dp(下一状态ᵢ)
  这就是全期望公式的递归形式！
```

### 2.2 全期望公式与概率 DP

```
全期望公式：E[X] = E[E[X|Y]]（先条件再求期望）
  例：几何分布期望
    E[T] = p·1 + (1-p)·(1 + E[T])    （第一次成功 or 失败重来）
    解方程：E[T] = 1/p ✓

⚠️ 解方程法（概率 DP 的另一种形态）：
  当状态转移"回到自己"时（自环）：
  dp = p·(dp + 1) + (1-p)·0 → 解出 dp
  例：837 新 21 点、掷硬币游戏、随机游走
```

### 2.3 蒙提霍尔问题的完整分析（面试经典）

```
三扇门，主持人打开一扇羊门后换门？
  全概率分析：
  不换门 P(赢) = 1/3（初始选对）
  换门 P(赢) = P(初始选错) = 2/3（选错则另一扇必是车）
  条件概率视角：P(车在门2 | 主持人开3) = 2/3

⚠️ 反直觉根源：主持人的行为携带信息
  （他"故意"不开车所在的门 → 剩余门概率集中）
  面试表达："换门胜率 2/3，因为初始选错的概率 2/3 被
  主持人的信息转移到另一扇门。"
```

## 3. 常见分布速查

### 3.1 离散分布

| 分布 | 场景 | P(X=k) / 性质 | 期望 | 方差 |
|------|------|--------------|:---:|:---:|
| 伯努利 | 单次成功/失败 | p（k=1） | p | p(1-p) |
| 二项 B(n,p) | n 次独立尝试 | C(n,k)p^k(1-p)^(n-k) | np | np(1-p) |
| 几何 G(p) | 首次成功等待次数 | (1-p)^(k-1)·p | 1/p | (1-p)/p² |
| 泊松 P(λ) | 稀有事件计数 | λ^k·e^(-λ)/k! | λ | λ |

### 3.2 连续分布（了解）

| 分布 | 场景 | 期望 | 用途 |
|------|------|:---:|------|
| 均匀 U(a,b) | 等可能取值 | (a+b)/2 | 随机数基础 |
| 指数 Exp(λ) | 无记忆等待 | 1/λ | 泊松过程的间隔 |
| 正态 N(μ,σ²) | 中心极限 | μ | 统计推断基础 |

### 3.3 两个重要结论

```
① 泊松逼近二项：n 大 p 小 → B(n,p) ≈ P(np)
   应用：海量请求中的异常数估计
② 期望的线性性对"相依"也成立：
   E[X+Y] 不需要 X、Y 独立 ← 与方差（需要独立）不同
   ⚠️ 面试易混：Var(X+Y) 需要独立或给协方差
```

## 4. 期望 DP 与概率 DP

### 4.1 两种 DP 的区别

| 维度 | 概率 DP | 期望 DP |
|------|:---:|:---:|
| 状态值 | 概率（0-1） | 期望步数/期望值 |
| 转移 | Σ p × dp(下一状态) | Σ p × (dp(下一状态) + 1) |
| 边界 | 终局概率 0/1/0.5 | 终局期望 0 |
| 典型 | 808 分汤、688 骑士 | 爬楼梯期望步数、掷骰子到终点 |

```java
/** 期望 DP 模板：dp = 从状态走到终局的期望步数 */
double dfs(int state, double[] memo) {
    if (终局) return 0.0;                          // 终局期望 0
    if (memo[state] > 0) return memo[state];

    double e = 0;
    for (每种转移 (下一状态, 概率 p)) {
        e += p * (dfs(下一状态) + 1);   // ⚠️ 走一步 + 1 步期望
    }
    return memo[state] = e;
}
// 例：掷骰子直到出现 6（每次 1/6）：
//   dfs(未出) = (1/6)·1 + (5/6)·(dfs(未出)+1) → 解方程 6 步 ✓
```

### 4.2 状态设计的三个维度

```
① 剩余量：808 分汤（A/B 剩余份数）
② 位置/距离：688 骑士（坐标）、爬楼梯（台阶数）
③ 进度/计数：集齐收集（已收集种类数）
④ 组合状态：可含"谁先谁后"（边界语义的关键）

⚠️ 设计要点：
  状态必须"完备"（能推导所有转移）
  状态必须"能合并"（不同历史同状态 → 相同未来）
  记忆化维度 = 状态维度（2D/3D 数组或 Map）
```

### 4.3 稀疏 vs 稠密状态的实现选择

| 场景 | 推荐 | 理由 |
|------|:---:|------|
| 状态稠密（全网格） | 迭代 DP | 数组 + 循环，无栈 |
| 状态稀疏（大量不可达） | 记忆化 | 只算可达状态 |
| 带自环（回退转移） | 记忆化 + 解方程 | 迭代顺序难确定 |
| 步数推进（k 步扩散） | 迭代 + 滚动数组 | 688 骑士模式 |

## 5. 随机算法家族

### 5.1 Fisher-Yates 洗牌（384）

```java
/**
 * LeetCode 384. 打乱数组（Fisher-Yates）
 * ⚠️ 每个位置从"剩余部分"随机取一个交换 → 均匀
 */
private final int[] original;
private final int[] nums;
private final Random rand = new Random();

public void shuffle() {
    for (int i = nums.length - 1; i > 0; i--) {
        int j = rand.nextInt(i + 1);      // ⚠️ [0, i] 等概率
        swap(nums, i, j);
    }
}
// 均匀性证明：第 i 位取到任意元素的概率 = 1/(i+1) × 剩余条件 = 1/n
// ⚠️ 对比：Collections.shuffle 内部就是 Fisher-Yates
```

### 5.2 水塘抽样（382/398）

```
问题：流式数据（长度未知/巨大），等概率抽样 k 个
核心：第 i 个元素以 k/i 概率替换样本

k=1 证明：第 i 个元素最终留下的概率
  = (1/i) × Π_{j=i+1}^{n} (1 - 1/j) = 1/n ✓ 每个元素等概率
```

```java
/**
 * LeetCode 382. 链表随机节点（水塘抽样 k=1）
 */
public int getRandom() {
    ListNode cur = head;
    int result = 0, i = 1;
    while (cur != null) {
        if (rand.nextInt(i) == 0) result = cur.val;   // ⚠️ 以 1/i 概率选中
        i++;
        cur = cur.next;
    }
    return result;
}
// 空间 O(1)，一次遍历
// ⚠️ 面试表达："水塘抽样保证每个元素 1/n 等概率，
//   数学归纳：前 i 个元素各 1/i，第 i 个元素 1/i 替换。"
```

### 5.3 随机算法的复杂度分析

```
随机化算法的三种保证：
  期望复杂度：随机输入/随机选择下的平均（快排 O(n log n)）
  高概率保证：失败概率 ≤ 1/nᶜ（随机哈希）
  拉斯维加斯：结果必然正确，时间随机（快选）
  蒙特卡洛：时间确定，结果有概率错误（随机近似）

⚠️ 面试表达：
"快选是拉斯维加斯算法——答案一定对，
 只是运行时间随机；期望 O(n)。"
```

## 6. 拒绝采样与加权随机

### 6.1 拒绝采样框架

```
目标：从复杂分布采样
方法：从简单分布采样 → 不满足条件则拒绝重来
期望重试次数 = 1/接受率（几何分布）

⚠️ 模板：
  ① 简单分布采样候选 x
  ② 校验 x 是否落在目标范围内
  ③ 是 → 返回；否 → 重试（循环）

优化方向：提高接受率（470 的 [1,49] 利用 vs 浪费 41-49）
```

### 6.2 加权随机（528：前缀和 + 二分）

```java
/**
 * LeetCode 528. 按权重随机选择
 * ⚠️ 把权重画成数轴线段 → 随机点落在哪段就选谁
 */
int[] prefix;
Random rand = new Random();

public int pickIndex() {
    int total = prefix[prefix.length - 1];
    int target = rand.nextInt(total) + 1;        // [1, total] 随机点
    int lo = 0, hi = prefix.length - 1;
    while (lo < hi) {                            // ⚠️ 二分找第一个 ≥ target
        int mid = lo + (hi - lo) / 2;
        if (prefix[mid] >= target) hi = mid;
        else lo = mid + 1;
    }
    return lo;
}
// 例：权重 [1,3] → 线段 [0,1),[1,4) → 3/4 概率选下标 1 ✓
// ⚠️ 正确性：落在 [prefix[i-1], prefix[i]) 的概率 = w[i]/total
```

### 6.3 拒绝采样 vs 映射法的选择

| 方法 | 适用 | 优点 | 缺点 |
|------|------|------|------|
| 拒绝采样 | 值域大/关系不规则（Rand7→Rand10） | 思路简单 | 可能重试多次 |
| 前缀和映射 | 权重已知的离散选择（528） | 一次定位 O(log n) | 需权重可累计 |
| 线性映射 | 均匀范围转换（Rand5→Rand7 精确版） | 一次完成 | 有限制条件 |

## 7. 浮点精度与误差控制

### 7.1 精度问题的来源

```
① 概率相乘累积误差：k 步扩散后极小概率被抹平
② 无限级数截断：剪枝阈值的选择（808 n>5000 → 1.0）
③ 比较判断：double 相等比较不可靠

⚠️ 面试表达：
"概率题返回 double，答案允许 1e-5 误差——
 用 double 累积即可；比较时用容差
 |a-b| < 1e-9，不用 ==。"
```

### 7.2 误差控制三原则

| 原则 | 做法 |
|------|------|
| 剪枝前验证 | 阈值必须能证明误差 < 题目要求（808：< 1e-5） |
| 计算顺序 | 先乘概率再累加（避免先加后乘的溢出/误差放大） |
| 边界特判 | 概率趋近 0/1 的极端直接短路（n 超阈值返回固定值） |

```java
// 精度对比：正确 vs 错误写法
double bad = 0;
for (int i = 0; i < n; i++) bad += p[i];       // ❌ 先累加可能溢出

double good = 1.0;
for (int i = 0; i < n; i++) good *= p[i];      // ✅ 概率相乘保持量级
```

## 8. 面试要点与追问

### 8.1 面试话术模板

```
"概率题先想工具：能拆指示变量 → 期望线性性；
 过程有状态 → 概率 DP（加权平均转移）；
 有对称性 → 直接简化。
 这题用【工具】：【方案】。
 边界语义：A 先空 → 1.0，同时空 → 0.5。
 复杂度 O(【状态数 × 转移数】)。"
```

### 8.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 期望线性性要不要独立？ | 不需要——这是它最强的点 |
| 2 | 全期望公式与概率 DP 关系？ | DP 转移就是全期望公式的递归形式 |
| 3 | 期望 DP 和概率 DP？ | 期望转移 +1 步；概率直接乘 |
| 4 | 水塘抽样证明？ | 数学归纳：第 i 个元素 1/i，最终 1/n |
| 5 | Fisher-Yates 为什么均匀？ | 每个位置从剩余中随机取 |
| 6 | 拒绝采样期望次数？ | 1/接受率（几何分布） |
| 7 | 蒙提霍尔换门？ | 初始选错 2/3，主持人信息转移概率 |

### 8.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 期望当独立才能加 | 思路卡死 | 线性性直接拆 |
| 期望 DP 忘 +1 | 期望步数少算 | 每步转移 +1 |
| 洗牌取 [0, i] 写成 [0, n) | 不均匀 | 剩余部分随机 |
| 水塘用 1/i 写成 1/n | 抽样不均 | 按到达序 1/i |
| double 用 == 比较 | 判断错 | 容差比较 |
