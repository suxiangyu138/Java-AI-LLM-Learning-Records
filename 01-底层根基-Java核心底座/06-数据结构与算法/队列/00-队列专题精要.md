## 1. 核心概念

### 1.1 队列的本质

> 队列（Queue）：队尾入队、队首出队的线性结构，**FIFO（先进先出）**。

```
操作：offer（入队）/ poll（出队）/ peek（看队首）

类比：排队买票——先来的先服务

offer 1 → [1]
offer 2 → [1, 2]
offer 3 → [1, 2, 3]     ← 队尾
poll → 1, 队列 [2, 3]    ← 队首先出

复杂度：所有操作 O(1)
```

### 1.2 识别信号

```
"先进先出/顺序处理" → 队列
"BFS/层序扩散" → 队列（102/994）
"窗口过期移除" → 队列（933）
"公平调度" → 队列（操作系统）

⚠️ 队列的核心场景：
  "顺序相关" 问题（FIFO 天然匹配）
```

### 1.3 队列 vs 栈

| 维度 | 队列 | 栈 |
|------|:---:|:---:|
| 顺序 | FIFO | LIFO |
| 操作端 | 队尾进队首出 | 栈顶 |
| 典型 | BFS/调度 | 括号/DFS |

```
选型："顺序相关" → 队列；"最近相关" → 栈
```

## 2. 完整代码模板

### 2.1 933. 最近请求次数（队列滑动）

```java
/**
 * LeetCode 933. 最近的请求次数
 * 队列维护时间窗口：过期请求出队
 */
class RecentCounter {
    private Queue<Integer> queue;

    public RecentCounter() {
        queue = new LinkedList<>();
    }

    public int ping(int t) {
        queue.offer(t);                  // 新请求入队
        // ⚠️ 移除窗口外（超过 3000ms）的请求
        while (queue.peek() < t - 3000) {
            queue.poll();                // 队首过期 → 出队
        }
        return queue.size();             // 窗口内请求数
    }
}
// 每个请求入队出队各一次 → 均摊 O(1)
// 推演：ping(1), ping(2), ping(3001), ping(3002)
//   [1]→[1,2]→[2,3001]（1 过期）→[3001,3002]（2 过期）
//   返回：1,2,2,2 ✓
```

### 2.2 225. 用队列实现栈（单队列轮转）

```java
/**
 * LeetCode 225. 用队列实现栈
 * 单队列 + 轮转：push 后把前面的重新入队
 */
class MyStack {
    private Queue<Integer> queue;

    public MyStack() {
        queue = new LinkedList<>();
    }

    public void push(int x) {
        queue.offer(x);
        // ⚠️ 轮转：把前面的 n-1 个移到后面
        int size = queue.size();
        for (int i = 0; i < size - 1; i++) {
            queue.offer(queue.poll());
        }
        // 新元素成为队首（栈顶）
    }

    public int pop() {
        return queue.poll();             // 队首 = 栈顶
    }

    public int top() {
        return queue.peek();
    }

    public boolean empty() {
        return queue.isEmpty();
    }
}
// push 1,2,3：
//   push 1 → [1]
//   push 2 → [1,2] 轮转 → [2,1]
//   push 3 → [2,1,3] 轮转 → [3,2,1]
//   pop → 3 ✓（栈顶！）
// push O(n)，其余 O(1)
```

### 2.3 622. 设计循环队列（数组实现）

```java
/**
 * LeetCode 622. 设计循环队列（数组 + 取模）
 */
class MyCircularQueue {
    private int[] data;
    private int head = 0, tail = 0;      // 队首/队尾下标
    private int size = 0;                // 当前元素数

    public MyCircularQueue(int k) {
        data = new int[k];
    }

    public boolean enQueue(int value) {
        if (isFull()) return false;
        data[tail] = value;
        tail = (tail + 1) % data.length; // ⚠️ 取模循环
        size++;
        return true;
    }

    public boolean deQueue() {
        if (isEmpty()) return false;
        head = (head + 1) % data.length; // ⚠️ 取模循环
        size--;
        return true;
    }

    public int Front() {
        return isEmpty() ? -1 : data[head];
    }

    public int Rear() {
        return isEmpty() ? -1 : data[(tail - 1 + data.length) % data.length];
    }

    public boolean isEmpty() { return size == 0; }
    public boolean isFull() { return size == data.length; }
}
// ⚠️ 循环队列两个细节：
//   ① 取模循环（tail+1 % len）
//   ② 队尾取值 (tail-1+len) % len（防负）
```

## 3. 队列的经典应用

### 3.1 应用一：BFS（102 层序）

```
BFS = 队列驱动的逐层扩散
  size 固定本层 → 层数与步数

⚠️ 队列是 BFS 的唯一正确结构：
  FIFO 保证"先到先处理"（层序）

变体：199 右视图、103 锯齿形、107 自底向上
（详见 BFS 专题）
```

### 3.2 应用二：滑动窗口（933/346）

```
队列维护窗口：
  新元素入队（右扩）
  过期元素出队（左缩）
  队内 = 当前窗口

变体：
  346 滑动窗口平均值
  滑动窗口最大值 → 单调队列（Deque）
```

### 3.3 应用三：调度与缓冲

```
① 任务调度：FIFO 公平（操作系统）
② 生产-消费：消息队列（阻塞队列）
③ 打印队列：先提交先打印
④ 拓扑排序：Kahn 用队列（入度 0）

⚠️ 工程类比：
  Java BlockingQueue（线程安全队列）
  Kafka/RabbitMQ（分布式消息队列）
  → 队列思想贯穿系统设计
```

### 3.4 应用四：轮转（225）

```
单队列轮转模拟栈：
  push 后把前面元素移到后面
  → 队首 = 栈顶

⚠️ 展示"结构转换"能力：
  栈 ↔ 队列 互转（232 双栈、225 轮转）
```

## 4. 队列 vs 栈 vs 双端队列

### 4.1 对比表

| 结构 | 顺序 | 操作端 | 典型 |
|------|:---:|:---:|------|
| 队列 | FIFO | 尾进头出 | BFS/调度 |
| 栈 | LIFO | 栈顶 | 括号/DFS |
| 双端队列 | 两者 | 两端 | 单调队列 |

### 4.2 Java 实现

```java
// ✅ 队列：LinkedList（推荐）
Queue<Integer> queue = new LinkedList<>();
queue.offer(1);              // 入队
queue.poll();                // 出队
queue.peek();                // 看队首

// ✅ 双端队列：ArrayDeque（推荐）
Deque<Integer> deque = new ArrayDeque<>();
deque.offerFirst(1);         // 队首插入
deque.offerLast(2);          // 队尾插入
deque.pollFirst();           // 队首删除
deque.pollLast();            // 队尾删除

// ⚠️ offer/poll/peek 不抛异常（add/remove 会抛）
```

### 4.3 队列的复杂度与空间

```
全部操作 O(1)（链表/循环数组）
空间 O(n)（存储全部元素）

⚠️ 与栈的对比：
  队列空间 = 最大层宽（BFS）
  栈空间 = 最大深度（DFS）
  → 按图结构选择遍历方式
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"最近请求用队列维护时间窗口：
 新请求入队，队首过期就出队，
 队内就是窗口内的请求。
 每个请求入队出队各一次 → 均摊 O(1)。
 队列 FIFO 天然匹配'先来先服务'语义。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 队列 vs 栈？ | FIFO 顺序相关 vs LIFO 最近相关 |
| 2 | 为什么队列适合 BFS？ | FIFO 保证先到先处理（层序扩散） |
| 3 | 循环队列细节？ | 取模循环 + (tail-1+len)%len 防负 |
| 4 | 轮转模拟栈原理？ | push 后前面元素移到后面 |
| 5 | offer vs add？ | offer 不抛异常（推荐） |
| 6 | 队列实现？ | LinkedList（链表）；ArrayDeque（数组） |
| 7 | 阻塞队列？ | BlockingQueue（线程安全的生产-消费） |
| 8 | 单调队列？ | Deque 维护窗口最值（见单调队列专题） |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 用 add/remove | 抛异常 | offer/poll/peek |
| 循环队列忘取模 | 越界 | (tail+1) % len |
| 队尾取值忘防负 | 负数下标 | (tail-1+len) % len |
| 轮转次数错 | 顺序错 | size-1 次 |
| 忘判空 | 空指针 | isEmpty 先行 |

> 🎯 **核心要点**：队列 = **FIFO + 四大应用**（BFS/滑窗/调度/轮转）。识别信号："先进先出、顺序处理、窗口过期"。LinkedList 实现、offer/poll API、循环队列取模是三大细节；"队列是 BFS 的唯一正确结构"是面试必答。
