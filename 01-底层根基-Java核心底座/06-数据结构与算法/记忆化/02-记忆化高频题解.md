## 1. 62. 不同路径（记忆化入门）

### 1.1 题目与思路

```
m×n 网格从左上到右下（只向右/下）的路径数
记忆化：dfs(i,j) = dfs(i-1,j) + dfs(i,j-1)
⚠️ 与表格 DP 双写对比（01 模块 3 节）
```

### 1.2 完整代码（双版本）

```java
/** 记忆化版（自顶向下） */
public int uniquePaths(int m, int n) {
    int[][] memo = new int[m][n];
    return dfs(m - 1, n - 1, memo);       // 从终点反推
}

private int dfs(int i, int j, int[][] memo) {
    if (i == 0 || j == 0) return 1;       // ⚠️ 边界：只有一条直线路径
    if (memo[i][j] > 0) return memo[i][j];
    return memo[i][j] = dfs(i - 1, j, memo) + dfs(i, j - 1, memo);
}
// ⚠️ 哨兵：路径数 ≥ 1，用 0 判重安全（本场景 0 不可能是答案）
// 但更通用做法是 -1 哨兵（01 模块强调的陷阱）

/** 表格版（自底向上，面试更常写） */
public int uniquePathsDP(int m, int n) {
    int[] dp = new int[n];                // ⚠️ 滚动数组省空间
    Arrays.fill(dp, 1);                   // 第 0 行全 1
    for (int i = 1; i < m; i++)
        for (int j = 1; j < n; j++)
            dp[j] += dp[j - 1];           // dp[j] = 上一行 + 左边
    return dp[n - 1];
}
// 推演 m=3, n=2：
//   初始 [1,1]；i=1：dp[1]=1+1=2 → [1,2]
//   i=2：dp[1]=2+1=3 → [1,3] → 3 ✓
// ⚠️ 面试表达："62 是记忆化/表格 DP 的最小样板——
//   状态 (i,j)、转移两方向、边界直线为 1。"
```

## 2. 329. 矩阵中的最长递增路径

### 2.1 题目与思路

```
矩阵中最长严格递增路径长度
记忆化：dfs(i,j) = 1 + max(dfs(四方向中值更大的邻居))
⚠️ 两个关键：
  ① 严格递增 → 沿递增方向无环 → 记忆化安全
  ② 每个格子的最长路径只算一次（有重叠子问题）
```

### 2.2 完整代码

```java
/**
 * LeetCode 329. 矩阵中的最长递增路径
 * ⚠️ 递增保证无环——这是可以记忆化的前提
 */
public int longestIncreasingPath(int[][] matrix) {
    int m = matrix.length, n = matrix[0].length;
    int[][] memo = new int[m][n];              // -1 未算（0 可能是答案? 长度≥1）
    for (int[] row : memo) Arrays.fill(row, -1);

    int best = 0;
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            best = Math.max(best, dfs(matrix, i, j, memo));
    return best;
}

private int dfs(int[][] g, int i, int j, int[][] memo) {
    if (memo[i][j] != -1) return memo[i][j];   // ⚠️ -1 哨兵

    int best = 1;                              // 自己一个格子
    int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};
    for (int[] d : dirs) {
        int ni = i + d[0], nj = j + d[1];
        if (ni >= 0 && ni < g.length && nj >= 0 && nj < g[0].length
                && g[ni][nj] > g[i][j]) {      // ⚠️ 只走更大的
            best = Math.max(best, 1 + dfs(g, ni, nj, memo));
        }
    }
    return memo[i][j] = best;
}
// 推演 [[9,9,4],[6,6,8],[2,1,1]]：
//   从 (2,1)=1 出发：1→2→6→9 长度 4 ✓
// ⚠️ 复杂度：O(m·n)（每格一次 DFS，缓存复用）
// ⚠️ 面试表达："329 的递增值保证无环——
//   若允许相等值会成环（需 visited），
//   严格递增是'天然拓扑序'。"
```

## 3. 403. 青蛙过河（hard）

### 3.1 题目与思路

```
石子位置数组，青蛙从 0 出发，下一步跳 k-1/k/k+1（k = 上一步）
⚠️ 状态 = (位置, 上一步长度)——只记位置不够！
  例：到达同一位置的两种"上一步" → 下一步能力不同
```

### 3.2 完整代码

```java
/**
 * LeetCode 403. 青蛙过河
 * 状态：(stoneIndex, lastJump) → 是否可达终点
 */
public boolean canCross(int[] stones) {
    if (stones[1] != 1) return false;          // ⚠️ 第一步只能是 1
    int n = stones.length;
    Map<Integer, Integer> pos = new HashMap<>();
    for (int i = 0; i < n; i++) pos.put(stones[i], i);

    // 缓存：index → 该位置可用的"上一步长度集合"
    Map<Integer, Set<Integer>> memo = new HashMap<>();
    return dfs(stones, 0, 0, pos, memo);
}

private boolean dfs(int[] stones, int idx, int lastJump,
                    Map<Integer, Integer> pos, Map<Integer, Set<Integer>> memo) {
    if (idx == stones.length - 1) return true;     // 到达终点

    if (memo.containsKey(idx)
            && memo.get(idx).contains(lastJump)) return false;  // ⚠️ 失败缓存

    for (int jump = lastJump - 1; jump <= lastJump + 1; jump++) {
        if (jump <= 0) continue;                   // 必须前进
        int next = stones[idx] + jump;
        if (pos.containsKey(next)) {               // 下一石子存在
            if (dfs(stones, pos.get(next), jump, pos, memo))
                return true;
        }
    }
    memo.computeIfAbsent(idx, k -> new HashSet<>()).add(lastJump);
    return false;
}
// 推演 [0,1,3,5,6,8,12,17]：
//   0→1(k=1)→3(k=2)→5(k=2)→8(k=3)→12(k=4)→17(k=5) ✓
// ⚠️ 缓存语义：记录"失败的 (位置, 上一步)"组合——
//   同组合重复到达直接返回 false（防指数爆炸）
// ⚠️ 面试表达："403 的状态必须带 lastJump——
//   到达同一位置的路径不同 → 未来能力不同。
//   失败缓存是搜索题的记忆化形态。"
```

## 4. 576. 出界的路径数

### 4.1 题目与思路

```
球从 (startRow, startCol) 移动 maxMove 步，求所有"出界"路径数
状态：(i, j, moves) → 剩余步数的出界路径数
⚠️ 三维状态 + 模运算（结果可能巨大）
```

### 4.2 完整代码

```java
/**
 * LeetCode 576. 出界的路径数
 * dfs(i, j, moves) = 剩余 moves 步内出界的路径数
 */
public int findPaths(int m, int n, int maxMove,
                     int startRow, int startColumn) {
    long[][][] memo = new long[m][n][maxMove + 1];
    for (long[][] a : memo)
        for (long[] b : a) Arrays.fill(b, -1);
    return (int) dfs(m, n, startRow, startColumn, maxMove, memo);
}

private long dfs(int m, int n, int i, int j, int moves, long[][][] memo) {
    if (i < 0 || i >= m || j < 0 || j >= n) return 1;   // ⚠️ 出界 = 1 条路径
    if (moves == 0) return 0;                           // 没步数了
    if (memo[i][j][moves] != -1) return memo[i][j][moves];

    long total = 0;
    int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};
    for (int[] d : dirs)
        total += dfs(m, n, i + d[0], j + d[1], moves - 1, memo);
    return memo[i][j][moves] = total % 1_000_000_007;   // ⚠️ 模运算
}
// 推演 m=1, n=3, moves=3, 起点 (0,1)：
//   第一步左右即出界（2 条）+ 向内走再出界... → 答案 12 ✓
// ⚠️ 复杂度：O(m·n·maxMove)（三维状态数）
// ⚠️ 面试表达："576 是三维记忆化样板——
//   步数维度是'剩余资源'型状态；
//   出界即基线（返回 1）、步数耗尽即 0。"
```

## 5. 140. 单词拆分 II（hard）

### 5.1 题目与思路

```
s 能否拆成字典单词（返回全部拆法）
状态：index（后缀起点）→ 该后缀的所有拆法列表
⚠️ 记忆化的 List 缓存（构造类记忆化）：
  同后缀只计算一次，返回 List<String>
```

### 5.2 完整代码

```java
/**
 * LeetCode 140. 单词拆分 II
 * 状态：index → 从 index 开始的全部拆法
 */
Map<Integer, List<String>> memo = new HashMap<>();

public List<String> wordBreak(String s, List<String> wordDict) {
    Set<String> dict = new HashSet<>(wordDict);
    return dfs(s, 0, dict);
}

private List<String> dfs(String s, int index, Set<String> dict) {
    if (memo.containsKey(index)) return memo.get(index);   // ⚠️ List 缓存
    if (index == s.length()) {
        List<String> base = new ArrayList<>();
        base.add("");                          // ⚠️ 空串表示"拆完了"
        memo.put(index, base);
        return base;
    }

    List<String> result = new ArrayList<>();
    for (int end = index + 1; end <= s.length(); end++) {
        String word = s.substring(index, end);
        if (dict.contains(word)) {             // 匹配一个单词
            for (String suffix : dfs(s, end, dict)) {
                result.add(suffix.isEmpty()
                        ? word
                        : word + " " + suffix);   // 拼接拆法
            }
        }
    }
    memo.put(index, result);
    return result;
}
// 推演 s="catsanddog", dict=[cat,cats,and,sand,dog]：
//   dfs(0)：cat + dfs(3) 与 cats + dfs(4)
//   dfs(3)="sanddog" → sand+dog
//   结果 ["cat sand dog", "cats and dog"] ✓
// ⚠️ 关键细节：空串 "" 作为"拆完"的表示（否则无法拼接）
// ⚠️ 复杂度：O(n·字典匹配 + 结果数)——记忆化保证每个 index 算一次
```

## 6. 464. 我能赢吗（位掩码状态）

### 6.1 题目与思路

```
两人轮流从 1..maxChoosableInteger 选数（每个只能用一次），
先使累计和 ≥ desiredTotal 者胜
状态：(mask, total) → 当前玩家能否必胜
⚠️ mask = 已选数字集合（位掩码状态，01 模块第 4 节）
⚠️ 三态缓存：0 未算 / 1 必胜 / -1 必败
```

### 6.2 完整代码

```java
/**
 * LeetCode 464. 我能赢吗
 * 状态：mask（已选集合）→ 当前玩家是否必胜
 */
int[] memo;                                    // 0 未算，1 必胜，-1 必败
int maxN;

public boolean canIWin(int maxChoosableInteger, int desiredTotal) {
    // ⚠️ 可行性剪枝：所有数之和都不够 → 无人能赢
    if (desiredTotal <= 0) return true;
    if (maxChoosableInteger * (maxChoosableInteger + 1) / 2 < desiredTotal)
        return false;

    maxN = maxChoosableInteger;
    memo = new int[1 << maxN];                 // ⚠️ 掩码数组（2^m）
    return dfs(0, desiredTotal) == 1;
}

private int dfs(int mask, int remaining) {
    if (memo[mask] != 0) return memo[mask];    // 三态缓存

    for (int i = 1; i <= maxN; i++) {
        if ((mask & (1 << (i - 1))) == 0) {    // ⚠️ 未选
            if (i >= remaining                  // 选了直接赢
                    || dfs(mask | (1 << (i - 1)), remaining - i) == -1) {
                // 对手必败 → 我必胜
                return memo[mask] = 1;
            }
        }
    }
    return memo[mask] = -1;                    // 所有选择都让对手赢
}
// 推演 maxN=4, total=6：
//   必胜路径：选 4 → 剩 2；对手选 1/2/3...
//   若对手选 3 → 我选 2 赢；若对手选 2 → 我选 1... 
//   分析可得先手必胜 ✓
// ⚠️ 面试表达："博弈记忆化=三态缓存（必胜/必败/未算）
//   + 胜负传递：我赢 = 存在一步让对手必败。
//   mask 直接作数组下标，2^maxN 空间。"
```

## 7. 记忆化方法论总结

### 7.1 四步框架

```
① 状态设计：影响未来的最小参数集（含隐藏维度如 lastJump）
② 转移：dfs(状态) = f(子状态)（列出所有选择）
③ 缓存：选型（数组/Map/掩码）+ 哨兵（-1/visited/三态）
④ 边界：基线返回语义（出界 1 / 耗尽 0 / 拆完 ""）

⚠️ 识别信号：
  "重叠子问题 + 递归自然" → 记忆化
  "每个状态只算一次" → 记忆化的本质
```

### 6.2 题型模板速查

| 题型 | 状态 | 缓存 | 代表题 |
|------|------|------|--------|
| 路径计数 | (i, j) | int[][] | 62、576 |
| 最长路径 | (i, j) | int[][] -1 | 329 |
| 可达性 | (pos, param) | Map+Set | 403 |
| 构造枚举 | (index) | Map<k,List> | 140 |
| 博弈 | (mask, total) | int[1<<m] | 464 |

### 6.3 自测清单

```
□ 状态完备（隐藏维度如 lastJump）？
□ 无环前提（严格递增/递减/拓扑）？
□ 哨兵安全（-1/visited，0 可能是答案）？
□ 博弈用三态缓存？
□ 构造题空串/空列表边界正确？
□ 模运算在累加后立即取模？
□ 掩码位运算正确（1 << (i-1)）？
```
