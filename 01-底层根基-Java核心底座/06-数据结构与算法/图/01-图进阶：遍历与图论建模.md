## 1. 图的存储结构选型

### 1.1 三种存储

| 结构 | 空间 | 查询 | 适用 |
|------|:---:|:---:|------|
| 邻接矩阵 | O(V²) | O(1) | 稠密图 |
| 邻接表 | O(V+E) | O(度) | 稀疏图（默认） |
| 边集数组 | O(E) | 遍历 | 最小生成树 |

```
⚠️ 面试必答：
"邻接表是默认选择（稀疏图 O(V+E)）；
 邻接矩阵用于'稠密 + 需要 O(1) 查边'；
 边集用于 Kruskal（排序边）。"
```

### 1.2 Java 邻接表模板

```java
/** 邻接表（通用模板） */
List<Integer>[] graph = new List[n];          // 无权图
for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
for (int[] e : edges) {
    graph[e[0]].add(e[1]);
    // 无向图加：graph[e[1]].add(e[0]);
}

/** 带权图 */
List<int[]>[] weighted = new List[n];         // int[]{v, w}
for (int i = 0; i < n; i++) weighted[i] = new ArrayList<>();
weighted[u].add(new int[]{v, w});
// ⚠️ 面试必答："邻接表 = List[] 数组——
//   无权存 int、带权存 int[]{v,w}。"
```

## 2. DFS/BFS 遍历框架

### 2.1 DFS 模板

```java
/** DFS 遍历（防环 visited） */
boolean[] visited;

void dfs(int u, List<Integer>[] graph) {
    visited[u] = true;
    for (int v : graph[u]) {
        if (!visited[v]) dfs(v, graph);       // ⚠️ 未访问才深入
    }
}
// ⚠️ 应用：可达性（841 钥匙和房间）、连通块计数
// ⚠️ 树 vs 图：树无需 visited（无环）；图必须
```

### 2.2 BFS 模板

```java
/** BFS 遍历（分层 = 最短步数） */
void bfs(int start, List<Integer>[] graph) {
    boolean[] visited = new boolean[graph.length];
    Deque<Integer> queue = new ArrayDeque<>();
    queue.offer(start);
    visited[start] = true;
    int steps = 0;

    while (!queue.isEmpty()) {
        int size = queue.size();              // ⚠️ 当前层
        for (int i = 0; i < size; i++) {
            int u = queue.poll();
            for (int v : graph[u])
                if (!visited[v]) {
                    visited[v] = true;        // ⚠️ 入队即标记（防重复）
                    queue.offer(v);
                }
        }
        steps++;
    }
}
// ⚠️ BFS 分层 = 无权图最短路径（层数即距离）
// ⚠️ 面试必答："BFS 分层遍历 = 无权最短路径——
//   层数即距离；入队即标记防重复入队。"
```

### 2.3 DFS vs BFS 选型

| 场景 | 选型 |
|------|:---:|
| 可达性/连通性 | DFS |
| 最短步数 | BFS |
| 所有路径/方案 | DFS（回溯） |
| 分层/最短 | BFS |
| 拓扑/环 | 两者（Kahn/三色） |

```
⚠️ 面试表达：
"'求最短'BFS、'求所有'DFS——
 深度搜方案、广度搜步数。"
```

## 3. 图论建模：问题 → 图

### 3.1 建模四步

```
① 节点是什么？   （人/状态/位置）
② 边是什么？     （关系/转移/依赖）
③ 权是什么？     （代价/概率/距离）

"图论题先'建模'——节点/边/权/目标
```

## 4. 染色法与二分图

### 4.1 二分图判定

```
二分图：顶点可分成两集合，边只在集合间
判定：染色法（0/1 双色，DFS/BFS 传播）
  ⚠️ 相邻节点同色 → 不是二分图

⚠️ 面试必答：
"二分图 = 双色染色成功（相邻不同色）；
 有奇环 → 染色冲突 → 非二分图。"
```

### 4.2 完整实现（785）

```java
/** 785. 判断二分图（染色法） */
public boolean isBipartite(int[][] graph) {
    int n = graph.length;
    int[] color = new int[n];                 // 0 未染 / 1 / -1

    for (int i = 0; i < n; i++) {             // ⚠️ 图可能不连通
        if (color[i] != 0) continue;
        color[i] = 1;
        Deque<Integer> queue = new ArrayDeque<>();
        queue.offer(i);
        while (!queue.isEmpty()) {
            int u = queue.poll();
            for (int v : graph[u]) {
                if (color[v] == 0) {          // 未染 → 染相反色
                    color[v] = -color[u];
                    queue.offer(v);
                } else if (color[v] == color[u]) {
                    return false;             // ⚠️ 相邻同色 → 非二分
                }
            }
        }
    }
    return true;
}
// 推演 [[1,3],[0,2],[1,3],[0,2]]（四环）→ 可二分 ✓
// 推演 [[1,2,3],[0,2],[0,1,3],[0,2]]（三角形）→ 冲突 ✗
// ⚠️ 面试必答："785 = 染色法——未染染反色、
//   已染查冲突；不连通图外层循环。"
```

## 5. 连通性的四层体系

### 5.1 四层连通

| 层次 | 概念 | 工具 |
|------|------|------|
| 1 | 弱连通（无视方向） | 并查集/BFS |
| 2 | 有向可达 | DFS/BFS |
| 3 | 强连通（有向环） | Tarjan（强连通/01） |
| 4 | 双连通（无向防删） | Tarjan（双连通/01） |

```
⚠️ 面试必答：
"连通性四层——弱连通、可达、强连通、
 双连通——复杂度与工具逐层升级：
 并查集 → DFS → Tarjan。"
```

### 5.2 并查集速览

```java
/** 并查集（连通性基础工具） */
int[] parent;

int find(int x) {
    while (parent[x] != x) {
        parent[x] = parent[parent[x]];        // 路径压缩
        x = parent[x];
    }
    return x;
}
void union(int a, int b) {
    int ra = find(a), rb = find(b);
    if (ra != rb) parent[ra] = rb;            // 合并
}
// ⚠️ 应用：冗余连接（684）、连通分量、Kruskal
```

## 6. 图论问题分类地图

### 6.1 分类总览

```
图论问题体系：
  ① 遍历与连通（DFS/BFS/并查集）→ 本专题
  ② 拓扑排序 → 拓扑专题
  ③ 最短路 → 最短路专题
  ④ 最小生成树 → MST 专题
  ⑤ 强连通/双连通 → 连通分量专题
  ⑥ 匹配与流（进阶，竞赛级）

⚠️ 面试必答：
"图论六分支——遍历/拓扑/最短路/MST/
 连通分量/匹配流。面试核心是前五，
 每个分支有专门专题承接。"
```

### 6.2 学习路径

```
入门：DFS/BFS + 建模（本专题）
进阶：拓扑 + 最短路 + MST
高阶：Tarjan 家族（SCC/桥/割点）
竞赛：网络流、匹配

⚠️ 面试表达：
"'先建模后选算法'是图论题的统一姿势——
 遍历打底、拓扑/最短路/MST 是三大核心算法。"
```

|------|------|------|
