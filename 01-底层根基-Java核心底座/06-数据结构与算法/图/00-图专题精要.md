## 1. 核心概念

### 1.1 图的术语

```
图（Graph）= 节点（Vertex）+ 边（Edge）

分类（面试第一步判断）：
  有向 / 无向
  有权 / 无权
  连通 / 非连通（多个连通分量）
  有环 / 无环（树 = 无环连通图）
  稠密 / 稀疏（边数接近 n² / 接近 n）

度：
  无向图：节点的邻居数
  有向图：入度（指向它）+ 出度（它指向）
  特殊应用：入度+出度（997 小镇法官：
    入度 n-1 且出度 0 → 法官）
```

### 1.2 图的存储

| 存储 | 空间 | 判断边 | 遍历邻居 | 适用 |
|------|:---:|:---:|:---:|------|
| 邻接表 | O(V+E) | O(度) | 快 | **稀疏图（推荐）** |
| 邻接矩阵 | O(V²) | O(1) | 慢（扫全行） | 稠密图 |
| 边集 | O(E) | O(E) | 慢 | Kruskal |

```
选型：
  默认邻接表（List<List<Integer>> 或 List<List<int[]>> 带权）
  稠密图 + 频繁判边 → 邻接矩阵
  Kruskal → 边集数组（要排序）
```

### 1.3 图 vs 树

```
树 = 图的特例（无环 + 连通）
  → 树的算法（DFS/BFS）都适用于图

图与树的遍历差异：
  树：天然无环 → 无需 visited
  图：可能有环/共享节点 → 必须 visited！
  ⚠️ 图遍历忘 visited = 无限递归/重复处理
```

## 2. 完整代码模板

### 2.1 建图模板（邻接表）

```java
// ═══════════ 无权图（无向）════════════════════════
// 输入：n 节点，edges = [[u,v],...]（0-indexed）
List<List<Integer>> graph = new ArrayList<>();
for (int i = 0; i < n; i++) {
    graph.add(new ArrayList<>());
}
for (int[] e : edges) {
    graph.get(e[0]).add(e[1]);      // u → v
    graph.get(e[1]).add(e[0]);      // ⚠️ 无向加两条！（易漏）
}

// ═══════════ 带权图 ════════════════════════════════
// 边 [u, v, w] → int[] = {to, weight}
List<List<int[]>> graph = new ArrayList<>();
for (int[] e : edges) {
    graph.get(e[0]).add(new int[]{e[1], e[2]});
    graph.get(e[1]).add(new int[]{e[0], e[2]});   // 无向
}

// ═══════════ 字符节点（269 火星词典）══════════════
// Map<Character, List<Character>> 或 字符-'a' 映射下标
```

### 2.2 DFS 遍历模板

```java
/**
 * 图 DFS（必须 visited！）
 */
public void graphDFS(List<List<Integer>> graph, int n) {
    boolean[] visited = new boolean[n];

    // ⚠️ 遍历所有起点（图可能不连通！）
    for (int i = 0; i < n; i++) {
        if (!visited[i]) {
            dfs(graph, i, visited);
        }
    }
}

private void dfs(List<List<Integer>> graph, int node, boolean[] visited) {
    visited[node] = true;                    // 标记

    for (int next : graph.get(node)) {
        if (!visited[next]) {
            dfs(graph, next, visited);
        }
    }
}
// 复杂度 O(V+E)：每个节点访问一次，每条边看一次
```

### 2.3 BFS 遍历模板

```java
/**
 * 图 BFS（入队即标记！）
 */
public void graphBFS(List<List<Integer>> graph, int start) {
    Queue<Integer> queue = new LinkedList<>();
    boolean[] visited = new boolean[graph.size()];

    queue.offer(start);
    visited[start] = true;          // ⚠️ 入队即标记（防重复入队）

    while (!queue.isEmpty()) {
        int cur = queue.poll();
        for (int next : graph.get(cur)) {
            if (!visited[next]) {
                visited[next] = true;
                queue.offer(next);
            }
        }
    }
}
// 无权图最短路径：分层记录距离（size 分层）
```

## 3. 图的建模思维

### 3.1 三类建模（面试核心能力）

```
① 常规建模：实体 = 节点，关系 = 边
   例：133 克隆图（节点+邻居）、997 法官（入出度）

② 矩阵当图：格子 = 节点，四方向 = 边
   例：200 岛屿（'1' 连通）、994 腐烂（感染扩散）
   → 网格 DFS/BFS 模板（见 BFS/DFS 体系）

③ 数据当节点：操作 = 边（状态图）
   例：127 单词接龙（单词=节点，改一字母=边）
       1345 跳跃游戏 IV（位置=节点，跳转=边）
   → 状态 BFS（见 BFS 体系-03）

面试第一句："把问题建模成图——
 节点是【...】，边是【...】，这是【有向无权】图。"
```

### 3.2 建模示例：127 单词接龙

```
问题：beginWord → endWord，每次改一个字母
建模：
  节点 = 单词（字典中的词）
  边 = 两个词相差一个字母（可一步转换）
  目标 = beginWord 到 endWord 的最短路径（BFS）

⚠️ 为什么建"隐式图"而不是显式建边？
  n 个词两两比较建边 O(n²×L) 太慢
  每个词生成 26L 个候选 → HashSet 查存在 → O(n×26L)
  → "边按需生成"（隐式图）是状态 BFS 的标准做法
```

### 3.3 图论问题选型总览

| 问题 | 算法 | 复杂度 |
|------|------|:---:|
| 无权图最短 | BFS | O(V+E) |
| 带权正边最短 | Dijkstra（堆） | O((V+E) log V) |
| 负权最短 | Bellman-Ford / SPFA | O(VE) |
| 全源最短 | Floyd | O(V³) |
| 最小生成树 | Kruskal / Prim | O(E log E) |
| 判环/拓扑 | Kahn / 颜色法 | O(V+E) |
| 连通分量 | DFS / BFS / 并查集 | O(V+E) |
| 强连通 | Tarjan / Kosaraju | O(V+E) |
| 二分图 | 染色 | O(V+E) |

## 4. 图的基本算法框架

### 4.1 可达性（841 钥匙和房间）

```java
// DFS/BFS 从起点出发，visited 计数
// 全部可达 ⇔ visited 全 true
public boolean canVisitAllRooms(List<List<Integer>> rooms) {
    boolean[] visited = new boolean[rooms.size()];
    dfs(rooms, 0, visited);
    for (boolean v : visited) {
        if (!v) return false;        // 有房间不可达
    }
    return true;
}
```

### 4.2 连通分量计数（547 省份数量）

```java
// DFS 版：每个未访问节点开始一次 DFS = 一个分量
public int findCircleNum(int[][] isConnected) {
    int n = isConnected.length;
    boolean[] visited = new boolean[n];
    int count = 0;

    for (int i = 0; i < n; i++) {
        if (!visited[i]) {
            count++;                 // 新分量
            dfs(isConnected, i, visited);
        }
    }
    return count;
}
// 并查集版：union 成功 count--（见并查集专题）
// ⚠️ 面试两种解法都能讲 = 加分
```

### 4.3 判环与拓扑（207 课程表）

```java
// Kahn（BFS）：入度 0 入队 → 减入度 → 计数
// 处理数 < n → 有环
// DFS 颜色法：0 未访问 / 1 访问中 / 2 已完成
//   递归遇到"访问中" → 有环
// 完整实现见拓扑排序专题
```

### 4.4 染色判二分（785）

```java
// 相邻节点必须异色，冲突 → 非二分图
// 遍历所有分量（图可能不连通）
public boolean isBipartite(int[][] graph) {
    int n = graph.length;
    int[] color = new int[n];        // 0 未染 / 1 / -1

    for (int i = 0; i < n; i++) {
        if (color[i] == 0 && !dfs(graph, i, 1, color)) {
            return false;
        }
    }
    return true;
}
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"先把问题建模成图：节点是【...】，
 边是【...】，这是【有向/无向、有权/无权】图。
 需要【遍历/最短路径/判环/连通性】，
 我选【DFS/BFS/Dijkstra/拓扑】。
 建图用邻接表 O(V+E)，
 遍历每个节点恰好一次 → O(V+E)。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | 有向 vs 无向注意什么？ | 无向加两条边（漏加 = 图不完整）；有向注意方向语义 |
| 2 | 图为什么必须 visited？ | 图有环/共享节点；树天然无环才不需要 |
| 3 | 图不连通怎么办？ | 遍历所有未访问节点做起点（for 循环） |
| 4 | 邻接表 vs 矩阵？ | 稀疏用表（省空间遍历快）；稠密+判边用矩阵 |
| 5 | 带权图怎么存？ | List<int[]>（to, weight）或 int[n][n] 矩阵 |
| 6 | 建模怎么想到的？ | 实体→节点、关系→边；矩阵→格子；数据→状态 |
| 7 | 复杂度怎么算？ | O(V+E)：每节点一次 + 每条边一次（邻接表） |
| 8 | 什么时候并查集？ | 动态加边/连通分量 → 并查集优于 DFS |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 无向只加一条边 | 图不完整 | addEdge 双向 |
| 忘 visited | 无限递归/重复 | 遍历前标记 |
| 只从一个点遍历 | 漏连通分量 | for 循环所有起点 |
| 邻接表忘初始化 | 空指针 | 先 new 每行 |
| 判环用简单 visited | 误判 | 颜色法三态 |

> 🎯 **核心要点**：图 = **存储（邻接表）+ 遍历（DFS/BFS + visited）+ 建模**三件套。识别信号："节点关系、依赖、连通、路径"。面试先讲建模（节点=什么、边=什么）再选算法；"遍历所有连通分量"和"visited 必须"是两个必答细节。
