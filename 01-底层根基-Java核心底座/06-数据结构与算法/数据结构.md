## 1. 绪论

### 1.1 数据结构三要素

| 要素 | 说明 |
|------|------|
| **逻辑结构** | 数据元素间的逻辑关系（线性/非线性） |
| **存储结构** | 数据在计算机中的存储方式（顺序/链式） |
| **运算** | 对数据的操作（增删改查、排序等） |

### 1.2 复杂度分析

| 记号 | 含义 | 常见排序 |
|------|------|----------|
| O(1) | 常数 | — |
| O(log n) | 对数 | 折半查找 |
| O(n) | 线性 | 顺序查找 |
| O(n log n) | 线性对数 | 快排、归并 |
| O(n²) | 平方 | 冒泡、插入 |
| O(2ⁿ) | 指数 | 递归斐波那契 |

## 2. 线性表

### 2.1 顺序表 vs 链表

| 维度 | 顺序表（数组） | 单链表 |
|------|:------------:|:------:|
| 存储 | 连续内存 | 结点 (data + next) |
| 随机访问 | ✅ O(1) | ❌ O(n) |
| 插入/删除 | O(n) | O(1)（已知位置） |
| 空间 | 固定/扩容成本 | 额外指针开销 |

### 2.2 链表类型

| 类型 | 结构 | 特点 |
|------|------|------|
| 单链表 | `data + next` | 单向遍历 |
| 双向链表 | `prev + data + next` | 双向遍历，删除更高效 |
| 循环链表 | 尾结点→头结点 | 适合循环队列 |

### 2.3 基本操作

```text
头插法：新结点 → 原头结点 → head 指向新结点
尾插法：遍历到尾结点 → 尾结点.next → 新结点
删除：  前驱.next → 被删结点.next
```

## 3. 栈和队列

### 3.1 对比

| 维度 | 栈（Stack） | 队列（Queue） |
|------|------------|--------------|
| 规则 | LIFO（后进先出） | FIFO（先进先出） |
| 实现 | 顺序栈 / 链栈 | 循环队列 / 链队列 |
| 核心操作 | `push` / `pop` / `peek` | `enqueue` / `dequeue` |
| 应用 | 括号匹配、表达式求值、递归、DFS | BFS、缓冲区、打印队列 |

### 3.2 循环队列判定

| 条件 | 队空 | 队满 |
|------|:---:|:---:|
| 少用一个元素空间 | `front == rear` | `(rear+1) % maxSize == front` |

## 5. 树和二叉树

### 5.1 二叉树性质

| 编号 | 性质 |
|:----:|------|
| 1 | 第 k 层最多 2^(k-1) 个结点 |
| 2 | 深度 k 最多 2^k - 1 个结点 |
| 3 | `n0 = n2 + 1`（叶子数 = 度为 2 的结点数 + 1） |

### 5.2 四种遍历

| 遍历 | 顺序 | 递归模式 |
|------|------|----------|
| **前序** | 根 → 左 → 右 | `visit(root); pre(left); pre(right);` |
| **中序** | 左 → 根 → 右 | `in(left); visit(root); in(right);` |
| **后序** | 左 → 右 → 根 | `post(left); post(right); visit(root);` |
| **层序** | 逐层从左到右 | 队列实现 |

### 5.3 特殊二叉树

| 类型 | 特点 | 应用 |
|------|------|------|
| **哈夫曼树** | WPL 最小，带权路径长度最短 | 哈夫曼编码（数据压缩） |
| **线索二叉树** | 利用空指针存储前驱/后继 | 加速遍历 |
| 完全二叉树 | 适合顺序存储 | 堆排序 |

## 6. 图

### 6.1 存储方式

| 方式 | 空间 | 适用场景 |
|------|:----:|----------|
| 邻接矩阵 | O(n²) | 稠密图 |
| 邻接表 | O(n+e) | 稀疏图 |

### 6.2 遍历

| 方式 | 数据结构 | 特点 |
|------|----------|------|
| **DFS**（深度优先） | 栈 / 递归 | 走到底再回溯 |
| **BFS**（广度优先） | 队列 | 逐层扩展 |

### 6.3 核心算法速查

| 算法 | 用途 | 核心思想 | 复杂度 |
|------|------|----------|:------:|
| **Prim** | 最小生成树 | 选点（贪心） | O(n²) |
| **Kruskal** | 最小生成树 | 选边 + 并查集 | O(e log e) |
| **Dijkstra** | 单源最短路径（非负权） | 贪心 + 松弛 | O(n²) |
| **Floyd** | 多源最短路径 | 动态规划 | O(n³) |
| **拓扑排序** | AOV 网 | 入度为 0 的点入队 | O(n+e) |
| **关键路径** | AOE 网 | ve(i)/vl(i) 最早/最晚时间 | O(n+e) |

## 7. 查找

### 7.1 查找算法对比

| 算法 | 适用 | 平均复杂度 | 最坏 |
|------|------|:--------:|:---:|
| 顺序查找 | 任意 | O(n) | O(n) |
| 折半查找 | 有序顺序表 | O(log n) | O(log n) |
| BST | 动态查找 | O(log n) | O(n)（退化为链） |
| AVL | 动态查找 | O(log n) | O(log n) ✅ |

### 7.2 BST 删除三种情况

| 情况 | 操作 |
|------|------|
| 叶子结点 | 直接删除 |
| 单子结点 | 子树替代 |
| 双子结点 | 右子树最小结点（或左子树最大）替代 |

### 7.3 AVL 四种旋转

| 类型 | 场景 | 操作 |
|:----:|------|------|
| LL | 左子树的左子树插入 | **右单旋** |
| RR | 右子树的右子树插入 | **左单旋** |
| LR | 左子树的右子树插入 | 先左旋后右旋 |
| RL | 右子树的左子树插入 | 先右旋后左旋 |

### 7.4 B 树 vs B+ 树

| 维度 | B 树 | B+ 树 |
|------|------|------|
| 数据存储 | 所有结点存数据 | 仅叶子存数据 |
| 叶子链接 | 无 | ✅ 链表链接 |
| 范围查询 | 需回溯 | ✅ 效率高 |
| 应用 | — | **数据库索引（MySQL InnoDB）** |

### 7.5 散列表（Hash）

| 冲突处理方法 | 说明 |
|-------------|------|
| **开放定址法** | 线性探测 / 平方探测 / 双散列 |
| **链地址法** | 同义词链在同一链表 |
| 装填因子 α | α 越大，冲突越严重 |

## 8. 排序

### 8.1 排序算法全表

| 算法 | 平均时间 | 最坏时间 | 空间 | 稳定性 |
|------|:------:|:------:|:----:|:------:|
| 直接插入 | O(n²) | O(n²) | O(1) | ✅ |
| 希尔排序 | O(n^1.3) | O(n²) | O(1) | ❌ |
| 冒泡排序 | O(n²) | O(n²) | O(1) | ✅ |
| **快速排序** | O(n log n) | O(n²) | O(log n) | ❌ |
| 简单选择 | O(n²) | O(n²) | O(1) | ❌ |
| **堆排序** | O(n log n) | O(n log n) | O(1) | ❌ |
| **归并排序** | O(n log n) | O(n log n) | O(n) | ✅ |
| 基数排序 | O(d(n+r)) | O(d(n+r)) | O(r) | ✅ |

### 8.2 稳定性速记

| 稳定性 | 算法 |
|--------|------|
| ✅ 稳定 | 插入、冒泡、归并、基数 |
| ❌ 不稳定 | 希尔、快排、选择、堆 |

### 8.3 快排优化

| 优化 | 方法 |
|------|------|
| 枢轴选择 | 三数取中法（避免最坏 O(n²)） |
| 小规模切换 | 子数组长度 < 阈值 → 改用插入排序 |

## 9. 学习方法与参考

### 学习建议

| 步骤 | 做法 |
|------|------|
| 1 | 纸上画图理解指针/引用操作（链表、树、图） |
| 2 | 每个数据结构动手实现一遍（C/C++ 或 Java） |
| 3 | LeetCode 刷对应 Tag 题目（树/链表/栈/队列） |
| 4 | 总结每种数据结构的 ADT 定义 |

### 重点与难点

| 重点 | 难点 |
|------|------|
| 链表操作 | KMP 算法 |
| 二叉树遍历 | AVL 平衡旋转 |
| 图遍历 + 最短路径 | 图最短路径算法 |
| 查找与排序算法 | 快排优化 |
