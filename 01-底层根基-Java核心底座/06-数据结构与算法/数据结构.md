# 数据结构

## 课程概述
- **课程性质**：专业核心必修课
- **适用专业**：计算机类各专业
- **开课学期**：大二学年
- **考核方式**：考试（闭卷）+ 实验 + 平时成绩

## 课程目标
1. 掌握常用数据结构的基本概念、存储方式和实现方法
2. 理解各种数据结构的适用场景和性能特点
3. 能够分析和比较不同算法的时间与空间复杂度
4. 具备根据实际问题选择合适数据结构的能力

## 核心知识点

### 第一章：绪论
- 数据结构三要素：逻辑结构、存储结构、运算
- 时间复杂度分析：大O记号，常见复杂度排序 O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ)
- 空间复杂度分析

### 第二章：线性表
- 顺序表（数组实现）：随机存取O(1)、插入/删除O(n)
- 单链表：结点结构(data + next)、头插法/尾插法
- 双向链表、循环链表
- 顺序表与链表的比较与选择

### 第三章：栈和队列
- 栈：LIFO，顺序栈与链栈
  - 应用：括号匹配、表达式求值、递归实现、DFS
- 队列：FIFO，循环队列（front/rear指针、队空队满判定）
  - 应用：BFS、缓冲区、打印队列
- 双端队列

### 第四章：串
- 串的存储表示（定长顺序存储、堆分配存储）
- KMP算法：next数组、避免回溯、O(n+m)时间复杂度
- 模式匹配的应用

### 第五章：树和二叉树
- 树的基本术语（结点、度、深度/高度、路径）
- 二叉树的性质：第k层最多2^(k-1)个结点、深度为k最多2^k-1个结点
- 二叉树的存储：顺序存储（完全二叉树适用）、链式存储
- 二叉树的遍历：前序/中序/后序/层序遍历（递归+非递归实现）
- 线索二叉树
- 哈夫曼树（最优二叉树）与哈夫曼编码：WPL最小
- 树、森林与二叉树的转换

### 第六章：图
- 图的基本概念：有向图/无向图、邻接/关联、度/出度/入度
- 图的存储：邻接矩阵O(n²)、邻接表O(n+e)
- 图的遍历：DFS（栈/递归）、BFS（队列）
- 最小生成树：Prim算法（选点）、Kruskal算法（选边+并查集）
- 最短路径：Dijkstra算法（单源、非负权）、Floyd算法（多源）
- 拓扑排序：AOV网的应用
- 关键路径：AOE网、最早/最晚开始时间

### 第七章：查找
- 顺序查找O(n)、折半查找O(log n)（仅有序顺序表）
- 二叉排序树(BST)：插入、查找、删除（三种情况）
- 平衡二叉树(AVL)：平衡因子、四种旋转（LL、RR、LR、RL）
- B树与B+树（外存查找、数据库索引）
- 散列表(Hash)：散列函数设计、冲突处理（开放定址法、链地址法）、装填因子

### 第八章：排序
- 插入排序：直接插入O(n²)、希尔排序O(n^1.3)
- 交换排序：冒泡排序O(n²)、快速排序O(n log n)（枢轴选择优化）
- 选择排序：简单选择O(n²)、堆排序O(n log n)（建堆O(n)+排序O(n log n)）
- 归并排序：二路归并O(n log n)、稳定排序
- 基数排序：多关键字排序、稳定
- 各排序算法的稳定性、时间复杂度、空间复杂度比较

## 重点难点
- **重点**：链表操作、二叉树遍历、图的遍历与最短路径、查找与排序算法
- **难点**：KMP算法、AVL树的平衡旋转、图的最短路径算法、快排优化

## 学习方法与建议
1. 纸上画图辅助理解指针/引用操作
2. 每个数据结构都自己动手实现一遍（C/C++或Java）
3. 在LeetCode上刷对应Tag的题目（树、链表、栈、队列等）
4. 总结每种数据结构的ADT（抽象数据类型）定义
