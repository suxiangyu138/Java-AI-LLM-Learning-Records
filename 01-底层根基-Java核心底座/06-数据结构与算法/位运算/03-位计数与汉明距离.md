## 1. 191. 位 1 的个数：三种解法

### 1.1 解法一：n & (n-1)（最优）

```java
/**
 * LeetCode 191. 位 1 的个数（汉明重量）
 * n & (n-1) 每次去掉最低位的 1
 * 循环次数 = 1 的个数（而非 32 位全扫）
 */
public int hammingWeight(int n) {
    int count = 0;
    while (n != 0) {
        n &= (n - 1);        // 去掉最低位的 1
        count++;
    }
    return count;
}
// n=11(1011)：1011&1010=1010 → 1010&1001=1000 → 1000&0111=0
// 3 次循环 → count=3 ✓
```

### 1.2 解法二：逐位检查

```java
/**
 * 逐位检查：固定 32 次循环
 * 用 1 左移逐个检查每一位
 */
public int hammingWeight_BitByBit(int n) {
    int count = 0;
    for (int i = 0; i < 32; i++) {
        if ((n & (1 << i)) != 0) count++;
    }
    return count;
}

// 或：每次右移检查最低位
public int hammingWeight_Shift(int n) {
    int count = 0;
    for (int i = 0; i < 32; i++) {
        count += (n >> i) & 1;     // 检查第 i 位
    }
    return count;
}
// ⚠️ 右移用 >> 会补符号位 → 用 >>> 或逐位 & 1 更安全
```

### 1.3 三种解法对比

| 解法 | 循环次数 | 说明 |
|------|:---:|------|
| n&(n-1) | 1 的个数 | **最优**，面试首选 |
| 逐位检查 | 32 | 直观但固定 |
| Java API | 1 | `Integer.bitCount(n)`（底层实现优化） |

> 💡 面试先手写 n&(n-1) 版本，最后补充"Java 也有 Integer.bitCount()"，展示对库的了解。

## 2. 338. 比特位计数：DP 优化

### 2.1 完整实现（DP + 位运算）

```java
/**
 * LeetCode 338. 比特位计数
 * 返回 [0, n] 每个数的二进制中 1 的个数
 *
 * 三种思路：
 *   ① 逐个调用 bitCount：O(n log n)
 *   ② 递推公式（DP）：O(n) ← 最优
 *
 * 递推公式：dp[i] = dp[i >> 1] + (i & 1)
 *   i >> 1：去掉最低位
 *   i & 1：最低位是否是 1
 *   例：dp[5] = dp[2] + 1 = 1 + 1 = 2（101 有两个 1）✓
 */
public int[] countBits(int n) {
    int[] dp = new int[n + 1];
    for (int i = 1; i <= n; i++) {
        dp[i] = dp[i >> 1] + (i & 1);    // 递推
    }
    return dp;
}
// dp[0]=0
// dp[1]=dp[0]+1=1    dp[2]=dp[1]+0=1
// dp[3]=dp[1]+1=2    dp[4]=dp[2]+0=1
// → [0,1,1,2,1] ✓
```

### 2.2 变体公式

```java
// 公式二：i & (i-1) 去掉最低位 1
//   dp[i] = dp[i & (i-1)] + 1
int[] dp2 = new int[n + 1];
for (int i = 1; i <= n; i++) {
    dp2[i] = dp2[i & (i - 1)] + 1;     // 去掉一个 1 后 +1
}

// 公式三：最高位
//   dp[i] = dp[i - 最高位2的幂] + 1
```

### 2.3 为什么是 DP？

```
递推关系：dp[i] 可以从更小的子问题推导
  i 的 1 个数 = (i 去掉最低位后) 的 1 个数 + 最低位
  → 重叠子问题 → 动态规划（配合位运算优化）
```

## 3. 461. 汉明距离

### 3.1 完整实现

```java
/**
 * LeetCode 461. 汉明距离
 * 两个整数的二进制不同位的个数
 * x=1(001), y=4(100) → 2 位不同 → 2
 *
 * 两步：
 *   ① 异或：不同的位 = 1（xor = x ^ y）
 *   ② 数 1 的个数（191 题复用）
 */
public int hammingDistance(int x, int y) {
    int xor = x ^ y;              // 不同位标记为 1
    int count = 0;
    while (xor != 0) {
        xor &= (xor - 1);         // 去掉最低位 1
        count++;
    }
    return count;
}

// 一行版：Integer.bitCount(x ^ y)
```

### 3.2 汉明距离家族

| 题号 | 题目 | 变体 |
|:---:|------|------|
| 461 | 汉明距离 | 两数异或计数 |
| 477 | 汉明距离总和 | 按位统计：每位的贡献 = count0 × count1 |
| 191 | 位 1 个数 | 单数重量 |

```java
// 477 按位统计技巧（O(32n)）：
//   对每一位：0 的个数 × 1 的个数 = 该位的距离贡献
public int totalHammingDistance(int[] nums) {
    int total = 0;
    for (int bit = 0; bit < 32; bit++) {
        int ones = 0;
        for (int x : nums) {
            ones += (x >> bit) & 1;        // 该位 1 的个数
        }
        total += ones * (nums.length - ones);   // 0 数 × 1 数
    }
    return total;
}
```

## 4. 190. 颠倒二进制位

### 4.1 完整实现

```java
/**
 * LeetCode 190. 颠倒二进制位
 * 32 位无符号整数，逐位颠倒
 * 43261596 (00000010100101000001111010011100)
 * → 964176192 (00111001011110000010100101000000)
 *
 * 逐位提取 + 左移累积：
 *   ① 取 n 的最低位：n & 1
 *   ② 累积到 result：result = (result << 1) | bit
 *   ③ n 右移一位（>>> 无符号）
 */
public int reverseBits(int n) {
    int result = 0;
    for (int i = 0; i < 32; i++) {
        result = (result << 1) | (n & 1);   // 累积最低位
        n >>>= 1;                           // ⚠️ 无符号右移
    }
    return result;
}
```

### 4.2 关键点

```
① 必须用 >>>（无符号右移）：n 是负数时 >> 会补 1 导致死循环
② 固定 32 次循环（int 固定 32 位）
③ result 左移累积（低位变高位）

面试追问："为什么用 >>> 而不是 >>？"
  答：负数右移补符号位（1），>>> 补 0；
  我们只关心位模式，必须 >>> 保证每次拿到正确的"下一位"
```

## 5. 231. 2 的幂判断

### 5.1 完整实现

```java
/**
 * LeetCode 231. 2 的幂
 * 判断 n 是否是 2 的幂
 *
 * 核心：2 的幂二进制只有一个 1
 *   n & (n-1) == 0 且 n > 0
 *   例：8(1000) & 7(0111) = 0 ✓
 *       10(1010) & 9(1001) = 1000 ≠ 0 ✗
 */
public boolean isPowerOfTwo(int n) {
    return n > 0 && (n & (n - 1)) == 0;
}
// ⚠️ 必须 n > 0：0 & (-1) = 0 会误判！

// 变体：326. 3 的幂（无位运算，用循环除 3）
//     342. 4 的幂（2 的幂 + n % 3 == 1）
```

### 5.2 位运算判断家族

| 判断 | 技巧 |
|------|------|
| 2 的幂 | `n > 0 && (n & (n-1)) == 0` |
| 4 的幂 | 2 的幂 && `n % 3 == 1` |
| 奇偶 | `(n & 1) == 1` |
| 正负 | `(n >>> 31) == 0`（符号位） |
| 两数异号 | `(a ^ b) < 0`（符号位异或） |

## 6. 位计数应用总结

### 6.1 位计数技巧全家桶

| 技巧 | 代码 | 用途 |
|------|------|------|
| 去最低位 1 | `n & (n-1)` | 计数 191、2 的幂 231 |
| 取最低位 1 | `n & (-n)` | 分组 260、lowbit |
| 检查第 k 位 | `(n >> k) & 1` | 逐位统计 137/477 |
| 置位 | `n \| (1<<k)` | 掩码 |
| 清位 | `n & ~(1<<k)` | 掩码 |
| 翻转 | `n ^ (1<<k)` | 掩码 |
| 异或计数 | `Integer.bitCount` | 汉明距离 461 |

### 6.2 面试话术

```
"统计 1 的个数我用 n & (n-1)：
 每次操作去掉最低位的 1，循环次数恰好等于
 1 的个数（而不是固定 32 次）。
 例：n=1011 → 1010 → 1000 → 0，三次。
 时间复杂度 O(k)（k = 1 的个数），空间 O(1)。"
```

> 🎯 **核心要点**：位计数系列围绕两个核心技巧——**n&(n-1) 去位计数**（191/231/461）和**逐位统计**（137/477）。338 展示了**位运算 + DP 递推**的组合（dp[i] = dp[i>>1] + (i&1)）。190 提醒**无符号右移 >>>** 的重要性。所有位计数题都能转化为"异或 + 计数"两步走。
