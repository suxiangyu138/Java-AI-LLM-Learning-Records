## 1. 位掩码基础

### 1.1 什么是位掩码

```
位掩码（Bitmask）：用一个整数的二进制位表示集合状态
  第 i 位 = 1 → 元素 i 在集合中
  第 i 位 = 0 → 元素 i 不在集合中

例：mask = 1011（二进制）表示集合 {0, 1, 3}
  第 0 位=1 → 含 0；第 1 位=1 → 含 1
  第 2 位=0 → 不含 2；第 3 位=1 → 含 3

优势：
  集合操作用位运算 O(1)
  集合本身只占 1 个 int（32 位可表示 32 个元素的集合）
```

### 1.2 掩码操作速查

```java
int mask = 0;

mask |= (1 << i);            // 加入元素 i
mask &= ~(1 << i);           // 移除元素 i
boolean in = (mask >> i & 1) == 1;   // 判断是否包含 i
int size = Integer.bitCount(mask);   // 集合大小

// 枚举子集（常用技巧）
for (int sub = mask; sub > 0; sub = (sub - 1) & mask) {
    // 遍历 mask 的所有非空子集
}
// 例：mask=1100 → 子集：1100, 1000, 0100（依次去掉最低位1）
```

## 2. 78. 子集：二进制枚举

### 2.1 完整实现（位运算版）

```java
/**
 * LeetCode 78. 子集（位运算版）
 * n 个元素 → 2ⁿ 个子集 → 用 [0, 2ⁿ) 的二进制表示
 *   掩码第 i 位 = 1 → nums[i] 加入当前子集
 *
 * 例：nums=[1,2,3]
 *   mask=0 (000) → []
 *   mask=1 (001) → [1]
 *   mask=5 (101) → [1,3]
 *   mask=7 (111) → [1,2,3]
 */
public List<List<Integer>> subsets(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    int n = nums.length;

    for (int mask = 0; mask < (1 << n); mask++) {   // 枚举 2ⁿ 个掩码
        List<Integer> subset = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            if ((mask & (1 << i)) != 0) {           // 第 i 位为 1
                subset.add(nums[i]);                // 加入元素 i
            }
        }
        res.add(subset);
    }
    return res;
}
// 复杂度：O(n × 2ⁿ)（2ⁿ 个子集 × 每个 O(n) 构造）
```

### 2.2 位枚举 vs 回溯

| 维度 | 位枚举 | 回溯 |
|------|:---:|:---:|
| 思路 | 掩码映射 | 选/不选递归 |
| 代码 | 简洁（双循环） | 递归 + 撤销 |
| 可扩展性 | 弱（仅枚举） | 强（可剪枝/去重） |
| 适用 | 子集/状态压缩 | 组合/排列/去重 |

> 💡 78 题两种解法都要求掌握——位枚举展示"集合与整数一一对应"的思维，回溯展示通用框架（见回溯体系）。

## 3. 371. 两整数之和：位运算加法

### 3.1 完整实现

```java
/**
 * LeetCode 371. 两整数之和
 * 不使用 + 和 - 运算符，计算两整数之和
 *
 * 位运算加法：
 *   和（无进位）= a ^ b
 *   进位 = (a & b) << 1
 *   重复直到进位为 0
 *
 * 例：a=2(010), b=3(011)
 *   和 = 010^011 = 001；进位 = (010&011)<<1 = 100
 *   和 = 001^100 = 101；进位 = (001&100)<<1 = 000 → 结束
 *   结果 101 = 5 ✓
 */
public int getSum(int a, int b) {
    while (b != 0) {              // 进位为 0 时结束
        int carry = (a & b) << 1; // 进位（两数都是 1 的位置）
        a = a ^ b;                // 无进位和
        b = carry;                // 进位参与下一轮
    }
    return a;
}
```

### 3.2 为什么可行？

```
加法 = 无进位和 + 进位（递归相加）
  5 + 3：
  无进位和：101^011 = 110 (6)
  进位：    (101&011)<<1 = 010 (2)
  6 + 2：
  无进位和：110^010 = 100 (4)
  进位：    (110&010)<<1 = 100 (4)
  4 + 4：
  无进位和：100^100 = 000 (0)
  进位：    (100&100)<<1 = 1000 (8)
  0 + 8：进位 0 → 结果 8 ✓（101+011 = 1000 = 8 ✓）

原理：二进制加法每一位：1+1=0 进位 1（与运算定位进位）
```

## 4. 29. 两数相除：倍增减法

### 4.1 完整实现（位运算 + 二分思想）

```java
/**
 * LeetCode 29. 两数相除
 * 不用乘除取模，实现整数除法（向零截断）
 *
 * 倍增减法（指数加速）：
 *   用减法模拟，但每次减 divisor 的 2 的幂次倍
 *   dividend = divisor × (2^k 组合) + 余数
 *
 * ⚠️ 细节：
 *   ① 符号处理（同号正、异号负）
 *   ② int 溢出（-2147483648 / -1）
 *   ③ 用 long 计算避免溢出
 */
public int divide(int dividend, int divisor) {
    // ① 溢出特判：-2^31 / -1 = 2^31 超出 int
    if (dividend == Integer.MIN_VALUE && divisor == -1) {
        return Integer.MAX_VALUE;
    }

    // ② 符号判断
    boolean negative = (dividend < 0) ^ (divisor < 0);
    long a = Math.abs((long) dividend);    // long 防溢出
    long b = Math.abs((long) divisor);

    long quotient = 0;
    // ③ 倍增减法
    while (a >= b) {
        long temp = b;
        long multiple = 1;
        while (a >= (temp << 1)) {         // 倍增到最大
            temp <<= 1;
            multiple <<= 1;
        }
        a -= temp;                         // 减去最大倍数
        quotient += multiple;
    }

    return negative ? (int) -quotient : (int) quotient;
}
// 例：10 / 3 → a=10, b=3
//   temp=3→6→12（超）→ temp=6, multiple=2 → a=4, quotient=2
//   temp=3→6（超）→ temp=3, multiple=1 → a=1, quotient=3
// 结果 3 ✓（10 = 3×3 + 1）
```

### 4.2 复杂度分析

```
每次倍增最多 log(divisor) 次
外层循环最多 log(dividend) 轮
总复杂度：O(log² n)
（可进一步优化为每位处理 O(log n)）
```

## 5. 201. 数字范围按位与

### 5.1 完整实现

```java
/**
 * LeetCode 201. 数字范围按位与
 * [left, right] 所有数按位与的结果
 * [5, 7]：101 & 110 & 111 = 100 = 4
 *
 * 核心观察：按位与的结果 = 所有数的公共前缀
 *   （某一位只要有一个数是 0，结果该位就是 0）
 *   [5(101), 6(110), 7(111)]：
 *     第 0 位：1,0,1 → 0（有 0）
 *     第 1 位：0,1,1 → 0（有 0）
 *     第 2 位：1,1,1 → 1（全是 1）→ 结果 100 = 4 ✓
 *
 * 方法：同时右移 left/right 直到相等 → 公共前缀
 *       再左移回去
 */
public int rangeBitwiseAnd(int left, int right) {
    int shift = 0;
    while (left < right) {
        left >>= 1;              // 右移
        right >>= 1;
        shift++;                 // 记录右移次数
    }
    return left << shift;        // 公共前缀左移还原
}
// [5,7]：5(101) < 7(111) → 5>>1=2, 7>>1=3, shift=1
//         2 < 3 → 2>>1=1, 3>>1=1, shift=2
//         相等 → 1 << 2 = 4 ✓
```

### 5.2 直觉理解

```
范围 [left, right] 的公共前缀：
  left 和 right 的最高不同位之后全部为 0
  例：[5, 7] 最高不同位在第 1 位（5 是 10，7 是 11）
  → 第 0、1 位都是 0 → 结果只有第 2 位 → 4

数学：结果 = 去掉 left/right 的公共前缀后的低位清零
```

## 6. 位掩码应用：状态压缩 DP

### 6.1 状态压缩 DP 入门

```java
/**
 * 状态压缩 DP：用位掩码表示"已选集合"
 * 经典：旅行商问题（TSP）
 *   dp[mask][i]：已访问集合为 mask，当前在城市 i 的最短距离
 *
 * 掩码操作：
 *   mask | (1 << j)     → 把城市 j 加入集合
 *   (mask & (1 << i))   → 判断城市 i 是否已访问
 *   (1 << n) - 1        → 全部访问的完整集合
 */
public int tsp(int[][] dist) {
    int n = dist.length;
    int[][] dp = new int[1 << n][n];       // 2ⁿ 个状态
    for (int[] row : dp) Arrays.fill(row, Integer.MAX_VALUE / 2);
    dp[1][0] = 0;                          // 从城市 0 出发

    for (int mask = 1; mask < (1 << n); mask++) {
        for (int i = 0; i < n; i++) {
            if ((mask & (1 << i)) == 0) continue;     // i 不在集合
            for (int j = 0; j < n; j++) {
                if ((mask & (1 << j)) != 0) continue; // j 已访问
                dp[mask | (1 << j)][j] = Math.min(
                    dp[mask | (1 << j)][j],
                    dp[mask][i] + dist[i][j]);
            }
        }
    }
    return dp[(1 << n) - 1][0];            // 回到起点
}
// 复杂度：O(n² × 2ⁿ)（2ⁿ 状态 × n² 转移）
```

### 6.3 面试话术

```
"这题用状态压缩：用 int 的二进制位表示集合状态，
 第 i 位 = 1 表示元素 i 已处理。
 状态 dp[mask] 表示【...】，转移用位运算：
 加入元素 j：mask | (1 << j)。
 状态数 2ⁿ，转移 O(1) → 总 O(n × 2ⁿ)。
 n 较小（≤ 20）时状态压缩是标准解法。"
```

> 🎯 **核心要点**：位掩码把"集合"压缩成"整数"——**枚举子集**（78 位运算版）、**状态压缩 DP**（TSP/掩码题）、**位运算四则**（371 加法/29 除法）是三大进阶方向。记住"掩码三件套"（`|(1<<i)` 加入、`&(1<<i)` 判断、`(sub-1)&mask` 枚举子集），n ≤ 20 的集合问题优先想到状态压缩。
