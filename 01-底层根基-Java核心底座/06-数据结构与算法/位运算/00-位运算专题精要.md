## 1. 核心概念

### 1.1 六种运算与异或三性质

```
& 与｜| 或｜^ 异或｜~ 取反｜<< 左移｜>> 右移｜>>> 无符号右移

异或三性质（面试必背）：
  ① 归零律：x ^ x = 0（成对抵消）
  ② 恒等律：x ^ 0 = x（落单保留）
  ③ 交换律结合律（顺序无关）
  → 全体异或 = 只出现一次的数

⚠️ 优先级陷阱：& 低于 ==
  (n & 1) == 1 必须加括号！
```

### 1.2 识别信号

```
"只出现一次/找缺失" → 异或（136/268）
"位 1 的个数" → n&(n-1)（191）
"2 的幂" → n&(n-1)==0（231）
"汉明距离" → 异或+计数（461）
"集合状态" → 位掩码（78/DP）

⚠️ 位运算的价值：
  O(1) 空间（不申请额外数组）
  O(n) 时间（一趟扫描）
```

### 1.3 为什么 O(1) 空间是加分点

```
例：136 只出现一次
  暴力：哈希表计数 O(n) 空间
  位运算：全体异或 O(1) 空间 ✓

⚠️ 面试表达：
"哈希表能解但 O(n) 空间；
 位运算 O(1) 空间更优——面试加分点。"
```

## 2. 完整代码模板

### 2.1 136. 只出现一次（全体异或）

```java
/**
 * LeetCode 136. 只出现一次的数字（位运算第一题）
 * 要求：线性时间 + O(1) 空间
 *
 * 全体异或：成对的抵消，落单的保留
 *   x^x=0（归零）+ x^0=x（恒等）+ 结合律
 */
public int singleNumber(int[] nums) {
    int result = 0;
    for (int x : nums) {
        result ^= x;        // 全体异或
    }
    return result;
}
// 推演 [4,1,2,1,2]：
//   4^1^2^1^2 = 4^(1^1)^(2^2) = 4^0^0 = 4 ✓
// 面试必讲："异或的三条性质让成对的元素
//   自动抵消，落单的元素保留下来。"
```

### 2.2 191. 位 1 的个数（n&(n-1)）

```java
/**
 * LeetCode 191. 位 1 的个数
 * n & (n-1)：每次去掉最低位的 1
 * 循环次数 = 1 的个数（而非 32 位全扫）
 */
public int hammingWeight(int n) {
    int count = 0;
    while (n != 0) {
        n &= (n - 1);        // 去掉最低位的 1
        count++;
    }
    return count;
}
// 推演 n=11(1011)：
//   1011 & 1010 = 1010 → 1010 & 1001 = 1000
//   → 1000 & 0111 = 0 → 3 次 → count=3 ✓
// 原理：n-1 把最低位 1 变 0，低位全变 1
//      与运算后：最低位 1 位置变 0
// ⚠️ 面试追问："为什么循环次数恰好是 1 的个数？"
```

### 2.3 268. 丢失的数字（下标+值异或）

```java
/**
 * LeetCode 268. 丢失的数字
 * 下标和值全部异或 → 成对抵消 → 剩下丢失的
 */
public int missingNumber(int[] nums) {
    int result = nums.length;         // 先异或 n
    for (int i = 0; i < nums.length; i++) {
        result ^= i;                  // 异或下标
        result ^= nums[i];            // 异或值
    }
    return result;
}
// 推演 [3,0,1]：
//   3 ^ (0^3) ^ (1^0) ^ (2^1)
//   = 3^3^0^1^2^1^0 = 2 ✓
// 数学解法：Σ(0..n) - Σ(nums)（long 防溢出）
```

## 3. 异或三性质详解

### 3.1 三条性质的理解

```
① 归零律：x ^ x = 0
   "相同数异或消去"——去重的核心

② 恒等律：x ^ 0 = x
   "0 异或保持"——落单元素保留

③ 交换律+结合律：
   x ^ y = y ^ x
   (x ^ y) ^ z = x ^ (y ^ z)
   "顺序无关"——全体异或可行

⚠️ 面试必答：
"异或去重的三条性质：
 x^x=0 归零、x^0=x 恒等、结合律——
 成对元素自动抵消，落单元素保留。"
```

### 3.2 异或的本质

```
异或 = "无进位加法"：
  5 ^ 3 = 101 ^ 011 = 110 = 6
  （1+1=0 不进位）

应用面：
  去重（x^x=0）→ 136/268
  交换变量（a^=b; b^=a; a^=b）
  翻转特定位（x ^ mask）
  加密（明文 ^ 密钥 = 密文）
```

### 3.3 260. 只出现一次 III（取位分组）

```java
/**
 * LeetCode 260. 只出现一次的数字 III
 * 两个落单 → 全体异或 = a^b → 取位分组
 */
public int[] singleNumber3(int[] nums) {
    // ① 全体异或 = a ^ b
    int xor = 0;
    for (int x : nums) xor ^= x;

    // ② 取最低位的 1（a 和 b 在该位必然不同）
    int diff = xor & (-xor);          // 例：xor=6(110) → diff=2(010)

    // ③ 按 diff 位分组异或
    int a = 0, b = 0;
    for (int x : nums) {
        if ((x & diff) == 0) a ^= x;   // diff 位为 0 的组
        else b ^= x;                   // diff 位为 1 的组
    }
    return new int[]{a, b};
}
// ⚠️ 为什么分组可行？
//   a 和 b 在 diff 位必然不同（否则 xor 该位为 0）
//   成对元素同组 → 组内异或抵消 → 各得一个
```

## 4. 八大核心技巧

### 4.1 技巧速查

```
① n & (n-1)：去掉最低位 1 → 计数/2 的幂
② n & (-n)：取最低位 1 → 分组/lowbit
③ n & (1<<k)：检查第 k 位
④ n | (1<<k)：置第 k 位
⑤ n ^ (1<<k)：翻转第 k 位
⑥ (n & 1) == 1：奇偶判断（⚠️ 加括号！）
⑦ <<1 / >>1：乘 2 / 除 2
⑧ 1L << 31：溢出防护（int 用 long）
```

### 4.2 n&(n-1) 的两个应用

```
① 位计数（191）：循环去掉直到 0
   循环次数 = 1 的个数

② 2 的幂判断（231）：
   n > 0 && (n & (n-1)) == 0
   ⚠️ 必须 n > 0（0 & -1 = 0 会误判！）

⚠️ 面试必答：
"n&(n-1) 去掉最低位的 1——
 计数时循环几次就有几个 1；
 结果为 0 且 n>0 时是 2 的幂。"
```

### 4.3 溢出与优先级陷阱

```
⚠️ 优先级：& 低于 == 低于 移位
  if ((n & 1) == 1) 必须加括号！

⚠️ 移位陷阱：
  负数用 >> 补符号位 → 位模式操作用 >>>
  1<<31 溢出 → 用 1L<<31
  ~x = -(x+1)（补码）

⚠️ 面试手写最容易翻车点：
  "判断位必须加括号——& 的优先级低于 =="
```
