## 2. 核心技巧速查（默写版）

```java
// ═══════════ 位运算六则 ═══════════════════════════
int a = 5, b = 3;
a & b;        // 与：都为 1 才 1（清位）
a | b;        // 或：任一 1 就 1（置位）
a ^ b;        // 异或：不同为 1（翻转/去重）
~a;           // 取反：~x = -(x+1)
a << 2;       // 左移：×4
a >> 1;       // 右移：÷2（负数补 1）
a >>> 1;      // 无符号右移：高位补 0

// ═══════════ 八大技巧 ═══════════════════════════
n & (n - 1)            // 去掉最低位 1（计数/2 的幂）
n & (-n)               // 取最低位 1（分组/lowbit）
n & (1 << k)           // 检查第 k 位
n | (1 << k)           // 置第 k 位为 1
n & ~(1 << k)          // 置第 k 位为 0
n ^ (1 << k)           // 翻转第 k 位
(n & 1) == 1           // 奇偶判断（⚠️ 加括号！）
x ^ x == 0             // 异或去重

// ═══════════ 位掩码三件套 ═══════════════════════
mask | (1 << i)        // 加入元素 i
(mask >> i & 1) == 1   // 判断包含 i
(sub - 1) & mask       // 枚举 mask 子集
```

## 3. 面试解题话术

```
📣 第 1 步：识别位运算场景 (15秒)
"看到'找只出现一次/找缺失/统计 1 的个数'，
 我想到用位运算——O(1) 空间是最大优势。"

📣 第 2 步：说核心技巧 (30秒)
"核心是异或的三条性质：
 x^x=0 归零、x^0=x 恒等、结合律。
 所有成对的元素异或后抵消，
 落单的元素保留下来。"

📣 第 3 步：写代码 + 复杂度 (2分钟)
（按模板默写）

📣 第 4 步：验证 (30秒)
"用 [4,1,2,1,2] 验证：
 4^1^2^1^2 = 4^(1^1)^(2^2) = 4^0^0 = 4 ✓
 时间 O(n)，空间 O(1)。"
```

## 5. 高频题深度复盘

### 5.1 137. 只出现一次的数字 II（位运算综合）

```java
public int singleNumber(int[] nums) {
    int result = 0;
    for (int bit = 0; bit < 32; bit++) {
        int count = 0;
        for (int x : nums) {
            count += (x >> bit) & 1;      // 统计该位 1 的个数
        }
        if (count % 3 != 0) {
            result |= (1 << bit);         // 余 1 → 答案该位为 1
        }
    }
    return result;
}
// 位运算状态机版（进阶）：
//   once 记录出现 1 次的位，twice 记录出现 2 次的位
//   once = (once ^ x) & ~twice
//   twice = (twice ^ x) & ~once
//   最后返回 once
```

**复盘要点**：
- 通用思想：出现 k 次 → 按位统计 %k
- 状态机版 O(n)/O(1) 且只遍历一次（面试加分项）

### 5.2 371. 两整数之和（位运算加法）

```java
public int getSum(int a, int b) {
    while (b != 0) {
        int carry = (a & b) << 1;    // 进位：同为 1 的位置
        a = a ^ b;                   // 无进位和
        b = carry;                   // 进位继续加
    }
    return a;
}
```

**复盘要点**：
- 加法 = 无进位和 + 进位（递归相加直到无进位）
- 面试追问"为什么循环能终止？"→ 进位每次左移，最终为 0
- 减法 = `getSum(a, ~b + 1)`（补码减）

## 6. 调试技巧与自检清单

### 6.1 位运算自检三步法

```
第 1 步：括号检查
  □ 所有位运算判断都加括号了吗？
    （(n & 1) == 1 而非 n & 1 == 1）

第 2 步：移位检查
  □ 负数右移该用 >>> 吗？（位模式操作必须 >>>）
  □ 1<<31 溢出用 long 了吗？

第 3 步：边界用例
  □ 0 / 1 / -1 / Integer.MIN_VALUE / MAX_VALUE
  □ 全相同元素 / 单个元素
  □ 负数参与位运算的结果验证
```

### 6.2 高频 Bug 速查表

| Bug | 原因 | 修复 |
|------|------|------|
| 语法错误 | `n & 1 == 1` 优先级 | 加括号 `(n & 1) == 1` |
| 死循环 | 负数用 >> 右移 | 用 >>> |
| 溢出 | 1<<31 / 中间结果 | 用 long |
| 2 的幂误判 | 没判 n > 0 | `n > 0 && (n&(n-1))==0` |
| 190 结果错 | 用了 >> | 必须 >>> |
| 掩码越界 | i >= 32 | 检查元素范围 |
