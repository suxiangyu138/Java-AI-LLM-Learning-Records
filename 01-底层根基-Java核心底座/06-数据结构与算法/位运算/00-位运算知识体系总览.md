## 4. 核心概念速查

| 概念 | 一句话解释 | 典型例题 |
|------|-----------|------|
| **x^x = 0** | 相同数异或为 0（消去） | 136 只出现一次 |
| **x^0 = x** | 0 异或保持 | 268 丢失数字 |
| **交换律结合律** | 异或顺序无关 | 136 全体异或 |
| **n & (n-1)** | 去掉最低位的 1 | 191 位计数 |
| **n & (-n)** | 取最低位的 1 | 260 分组 |
| **1<<k 检查** | n & (1<<k) 判第 k 位 | 78 子集 |
| **乘除 2** | <<1 乘 2，>>1 除 2 | 29/371 |
| **无符号右移** | >>> 高位补 0 | 191 计数 |
| **位掩码** | 用整数表示集合状态 | 78/1915 |
| **公共前缀** | 区间按位与 = 公共前缀 | 201 |
| **汉明距离** | 两数异或后 1 的个数 | 461 |

## 6. 复杂度速查表

| 问题 | 时间复杂度 | 空间 | 核心技巧 |
|------|:---:|:---:|------|
| 只出现一次 (136) | O(n) | **O(1)** | 全体异或 |
| 只出现一次 III (260) | O(n) | **O(1)** | n&(-n) 分组 |
| 丢失的数字 (268) | O(n) | **O(1)** | 异或下标 |
| 位 1 个数 (191) | O(k) | O(1) | n&(n-1) |
| 比特位计数 (338) | O(n) | O(n) | DP+位运算 |
| 汉明距离 (461) | O(1) | O(1) | 异或+计数 |
| 2 的幂 (231) | O(1) | O(1) | n&(n-1)==0 |
| 颠倒二进制 (190) | O(1) | O(1) | 逐位提取 |
| 两整数之和 (371) | O(1) | O(1) | 异或+进位 |
| 只出现一次 II (137) | O(n) | O(1) | 按位计数 mod 3 |
| 范围按位与 (201) | O(1) | O(1) | 公共前缀 |
| 子集枚举 (78 位版) | O(n×2ⁿ) | O(1) | 掩码遍历 |
