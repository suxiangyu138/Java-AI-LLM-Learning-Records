# 数据结构实验

## 课程概述
- **课程性质**：专业核心必修课（配套实验课）
- **适用专业**：计算机类各专业
- **开课学期**：与数据结构理论课同步
- **考核方式**：实验报告 + 上机考核 + 平时操作

## 核心知识点

### 实验一：线性表
- 顺序表（数组实现）
  - 基本操作实现：初始化、按位置插入（后移元素）、按位置删除（前移元素）、按值查找
  - 时间复杂度：插入/删除 O(n)，按位置访问 O(1)
  - 扩容策略：容量满时扩展为原来的2倍
- 单链表
  - 结点结构：struct Node { int data; Node* next; }
  - 头插法建表：新结点始终插入头结点之后 → 逆序
  - 尾插法建表：维护尾指针 → 顺序
  - 插入操作：找到前驱结点 → 新结点next=前驱next → 前驱next=新结点（顺序不能反！）
  - 删除操作：找到前驱 → 前驱next=被删结点next → 释放被删结点
  - 链表逆转：三指针法（prev/curr/next）迭代翻转
- 综合练习
  - 两个有序链表合并为一个有序链表（双指针归并）
  - 求链表的中间结点（快慢指针法）
  - 判断链表是否有环（快慢指针，相遇即有环）

### 实验二：栈和队列
- 顺序栈
  - 结构：数组 + 栈顶指针 top（初始值-1表示空栈）
  - Push：top++, data[top] = x
  - Pop：x = data[top], top--
  - 判空：top == -1；判满：top == MAXSIZE-1
- 链栈
  - 结构：链表，栈顶在链表头部（便于插入和删除）
  - Push：头插法
  - Pop：删除头结点
- 栈的应用
  - 括号匹配：遇左括号入栈 → 遇右括号与栈顶匹配 → 最终栈空则匹配
  - 表达式求值
    - 中缀→后缀（调度场算法）：
      - 操作数直接输出
      - 运算符与栈顶比较优先级：高于则入栈，不高于则弹栈直到高于
      - 左括号直接入栈，右括号弹栈直到遇到左括号
    - 后缀表达式求值：遇操作数入栈→遇运算符弹出两个操作数计算→结果入栈
- 循环队列
  - 结构：数组 + front(队头) + rear(队尾下一个)
  - 入队：rear = (rear+1) % MAXSIZE, data[rear] = x
  - 出队：x = data[front], front = (front+1) % MAXSIZE
  - 队空：front == rear
  - 队满：(rear+1) % MAXSIZE == front（牺牲一个存储单元）
  - 或通过计数器count区分队空队满
- 队列的应用
  - 模拟银行排队系统：客户到达→入队→柜台空闲→出队服务→记录等待时间
  - BFS实现（见图相关实验）

### 实验三：二叉树
- 二叉树的存储
  - 二叉链表：struct Node { int data; Node *lchild, *rchild; }
  - 创建：给定先序序列（或先序+中序），递归创建
- 二叉树遍历
  - 前序遍历（根左右）递归：visit(root); preOrder(left); preOrder(right)
  - 中序遍历（左根右）递归：inOrder(left); visit(root); inOrder(right)
  - 后序遍历（左右根）递归：postOrder(left); postOrder(right); visit(root)
  - 层序遍历：队列辅助，根入队→出队时将其左右孩子入队→重复
  - 非递归实现（用栈模拟）：
    - 前序非递归：根入栈→弹出访问→右左孩子入栈
    - 中序非递归：沿左链一路到底入栈→弹栈访问→转向右子树
    - 后序非递归：双栈法或标记法
- 二叉树属性计算
  - 求结点总数：nodeCount = 1 + count(left) + count(right)
  - 求叶子结点数：左右子树都空→return 1
  - 求树的高度：height = 1 + max(height(left), height(right))
  - 判断是否为完全二叉树：层序遍历，出现空结点后不应再有非空结点
- 哈夫曼树
  - 构建：选森林中两个最小权值结点→合并为新结点（权值为和）→放回森林→重复
  - 哈夫曼编码：从根到叶路径编码，左0右1，不等长编码，无前缀歧义
  - 计算WPL（带权路径长度）

### 实验四：图
- 图的存储
  - 邻接矩阵：int G[n][n]，有边G[i][j]=权值(无边=∞)，空间O(n²)
  - 邻接表：vector<int> adj[n]（或链表），空间O(n+e)
- 图的遍历
  - DFS（深度优先）：递归访问→标记visited→对每个未访问邻接点递归DFS
  - BFS（广度优先）：入队起点→循环出队→将未访问邻接点入队并标记
- 最小生成树
  - Prim算法：任选起点→每次选与生成树距离最近的顶点加入→更新距离数组→重复n-1次
  - Kruskal算法：边按权排序→遍历每条边→并查集判断是否成环→不成环则加入MST
- 最短路径
  - Dijkstra：dist[s]=0, 其余∞→每次选未访问中dist最小者→松弛其邻接边→重复
  - Floyd：for(k) for(i) for(j) d[i][j]=min(d[i][j], d[i][k]+d[k][j])
- 拓扑排序
  - 计算所有顶点入度→入度为0者入队→出队时将其邻接点入度-1→入度为0者再入队→...

### 实验五：查找
- 顺序查找：逐一比较，O(n)，哨兵技术（a[0]=key，从后往前找可免去越界判断）
- 折半查找（二分查找）：left=0, right=n-1, mid=(left+right)/2→比较→缩小范围，O(log n)，仅有序顺序表
- 二叉排序树(BST)
  - 插入：从根开始，小于往左，大于往右，直到空位
  - 查找：同插入过程，遇空则不存在
  - 删除三种情况：叶子直接删、单孩子替代、双孩子用右子树最小结点替换（或左子树最大）
- 散列表(Hash Table)
  - 散列函数：除留余数法 hash(key)=key % p（p取小于表长的素数）
  - 冲突处理：
    - 开放定址法(线性探测)：冲突时找下一个空位(hash+i)%m
    - 链地址法：每个槽一个链表，冲突结点挂在链表后
  - 装填因子α = 填入记录数/表长，控制<0.75
- 查找性能对比：统计不同查找方法的比较次数和查找时间

### 实验六：排序
- 必须实现的排序算法
  - 直接插入排序：无序区第一个插入到有序区正确位置，稳定
  - 希尔排序：按增量分组→组内插入排序→增量递减（如n/2, n/4, ..., 1），不稳定
  - 冒泡排序：相邻比较交换，每轮最大"浮"到最后，稳定
  - 快速排序：选枢轴→分区(左边≤枢轴≤右边)→递归排序左右
  - 简单选择排序：每轮选最小元素与当前位置交换，不稳定
  - 堆排序：建大顶堆→堆顶与末尾交换→调整堆→重复，不稳定
  - 归并排序：递归二分→合并两个有序子序列，稳定
- 性能对比实验
  - 生成不同规模数据(1000/10000/100000)，不同分布(随机/正序/逆序)
  - 统计每种排序的运行时间和比较次数
  - 对比分析：何时快排反而慢(已有序且取首元素为枢轴)、归并为何稳定但需要额外空间
