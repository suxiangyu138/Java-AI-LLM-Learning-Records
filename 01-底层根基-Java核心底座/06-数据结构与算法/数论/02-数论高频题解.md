## 1. 204. 计数质数

### 1.1 题目与思路

```
小于 n 的质数个数（n 可达 5×10⁶）
埃氏筛：标记合数 + 计数
⚠️ 逐个判断素数 O(n√n) 超时 → 筛法 O(n log log n)
```

### 1.2 完整代码

```java
/**
 * LeetCode 204. 计数质数（埃氏筛）
 */
public int countPrimes(int n) {
    if (n <= 2) return 0;
    boolean[] isComposite = new boolean[n];
    int count = 0;

    for (int i = 2; i < n; i++) {
        if (!isComposite[i]) {
            count++;
            if ((long) i * i < n) {              // ⚠️ 从 i² 开始
                for (long j = (long) i * i; j < n; j += i)
                    isComposite[(int) j] = true; // 标记倍数
            }
        }
    }
    return count;
}
// 推演 n=10：质数 2,3,5,7 → 4 ✓
//   i=2 标记 4,6,8；i=3 标记 9（6 已标）；i=5：25 ≥ 10 跳过
// ⚠️ 复杂度：O(n log log n)
// ⚠️ 面试必答："204 = 埃氏筛——从 p² 开始标记
//   倍数（p 的小倍数已有更小素因子）。
//   线性筛 O(n) 也可，埃氏足够。"
```

## 2. 365. 水壶问题

### 2.1 题目与思路

```
两个容量 x、y 的壶，能否量出 target
贝祖定理：能量出的水量 = gcd(x,y) 的倍数
  且 target ≤ x + y（总容量）
⚠️ 数学：ax + by = target 有整数解 ⟺ gcd | target
```

### 2.2 完整代码

```java
/**
 * LeetCode 365. 水壶问题（贝祖定理）
 */
public boolean canMeasureWater(int x, int y, int target) {
    if (target == 0) return true;
    if (target > x + y) return false;          // ⚠️ 不能超过总容量
    return target % gcd(x, y) == 0;            // ⚠️ 贝祖定理
}

private int gcd(int a, int b) {
    while (b != 0) {
        int t = a % b;
        a = b;
        b = t;
    }
    return a;
}
// 推演 x=3, y=5, target=4：gcd=1 → 4%1==0 ✓
//   操作：5 满 → 倒 3 → 剩 2 → 倒空 3 → 2 倒入 → 5 满倒 3 → 剩 4 ✓
// 推演 x=2, y=6, target=5：gcd=2 → 5%2≠0 ✗ ✓
// ⚠️ 面试必答："365 = 贝祖定理——两壶能量出的
//   水量恰是 gcd 的倍数（ax+by 的值域），
//   加上'不超过总容量'约束即答案。"
```

## 3. 372. 超级次方

### 3.1 题目与思路

```
a^b mod 1337，b 是数组（巨大，如 [2,3] = 23）
欧拉降幂：指数对 φ(1337) 取模
  ⚠️ 1337 = 7 × 191（两个素数）→ φ = 6 × 190 = 1140
  b mod 1140 → 快速幂
⚠️ 或直接"逐位降幂"：a^b = (a^(b/10))^10 × a^(b%10)
```

### 3.2 完整代码（逐位降幂版，无需欧拉函数）

```java
/**
 * LeetCode 372. 超级次方
 * ⚠️ 逐位降幂：a^b = (a^(b/10))^10 · a^(b%10)
 *   递归处理数组指数
 */
public int superPow(int a, int[] b) {
    return pow(a, b, b.length - 1);
}

/** 计算 a^(b[0..idx]) mod 1337 */
private int pow(int a, int[] b, int idx) {
    if (idx < 0) return 1;
    int MOD = 1337;
    a %= MOD;

    // ⚠️ 核心公式：a^(b[0..idx]) = (a^(b[0..idx-1]))^10 · a^(b[idx])
    int prev = pow(a, b, idx - 1);             // 前半部分的幂
    int part1 = fastPow(prev, 10, MOD);        // 前半 ^10
    int part2 = fastPow(a, b[idx], MOD);       // 当前位
    return (int) ((long) part1 * part2 % MOD); // ⚠️ long 防溢出
}

private int fastPow(int a, int exp, int mod) {
    long base = a % mod, result = 1;
    while (exp > 0) {
        if ((exp & 1) == 1) result = result * base % mod;
        base = base * base % mod;
        exp >>= 1;
    }
    return (int) result;
}
// 推演 a=2, b=[1,0]（指数 10）：
//   pow(idx=1) = pow(idx=0)^10 × 2^0
//   pow(idx=0) = pow(idx=-1)^10 × 2^1 = 2
//   → 2^10 × 1 = 1024 mod 1337 = 1024 ✓
// ⚠️ 复杂度：O(位数 × log a)（每层快速幂）
// ⚠️ 面试必答："372 用逐位降幂：指数数组
//   按位拆解——a^(10k+d) = (a^k)^10 · a^d，
//   递归 + 快速幂。欧拉降幂是另一条路。"
```

## 4. 233. 数字 1 的个数

### 4.1 题目与思路

```
1..n 中数字 1 出现的总次数（n 可达 10⁹）
数位统计：按位计算"当前位是 1 的次数"
  第 i 位（权值 10^i）：
    当前位 < 1 → 高位 × 权值
    当前位 = 1 → 高位 × 权值 + 低位 + 1
    当前位 > 1 → (高位 + 1) × 权值
⚠️ 不能枚举（10⁹）→ 数位公式 O(位数)
```

### 4.2 完整代码

```java
/**
 * LeetCode 233. 数字 1 的个数（数位统计）
 */
public int countDigitOne(int n) {
    long count = 0;
    for (long pow = 1; pow <= n; pow *= 10) {   // ⚠️ 逐位（个/十/百...）
        long high = n / (pow * 10);             // 高位
        long cur = (n / pow) % 10;              // 当前位
        long low = n % pow;                     // 低位

        if (cur < 1) {
            count += high * pow;                // 只有高位贡献
        } else if (cur == 1) {
            count += high * pow + low + 1;      // ⚠️ 高位 + 低位 + 1（0..low）
        } else {
            count += (high + 1) * pow;          // 高位+1 全贡献
        }
    }
    return (int) count;
}
// 推演 n=13：
//   个位（pow=1）：high=1, cur=3, low=0 → (1+1)×1 = 2（1,11）
//   十位（pow=10）：high=0, cur=1, low=3 → 0×10+3+1 = 4（10,11,12,13）
//   总 6 ✓（1,10,11,12,13 中 1 出现 6 次）
// ⚠️ 复杂度：O(位数) ≈ O(log n)
// ⚠️ 面试必答："233 = 按位统计——当前位 <1/=1/>1
//   三种情况的贡献公式。三行公式记牢，
//   数位题（1/2/9 的出现次数）都同构。"
```

## 5. 263. 丑数

### 5.1 题目与思路

```
质因子只含 2/3/5 的正整数
循环除 2/3/5，最后剩 1 则是丑数
⚠️ 注意：1 是丑数、0 和负数不是
```

### 5.2 完整代码

```java
/**
 * LeetCode 263. 丑数
 */
public boolean isUgly(int n) {
    if (n <= 0) return false;                  // ⚠️ 0/负数不是

    for (int p : new int[]{2, 3, 5}) {
        while (n % p == 0) n /= p;             // ⚠️ 除掉所有该质因子
    }
    return n == 1;                             // 只剩 1 → 纯 2/3/5 因子
}
// 推演 6：6÷2=3，3÷3=1 → true ✓
// 推演 14：14÷2=7，7 除不尽 3/5 → 7≠1 → false ✓
// ⚠️ 复杂度：O(log n)（每除一次至少减半）
// ⚠️ 变体：264 丑数 II（生成第 n 个丑数 → 三指针 DP）
// ⚠️ 面试必答："丑数判定 = 循环除 2/3/5——
//   余下的 1 说明质因子全是 2/3/5。
//   变体 264 用三指针 DP（2/3/5 各一个指针）。"
```

## 6. 326. 3 的幂

### 6.1 题目与思路

```
判断 n 是否是 3 的幂
三种解法：
  ① 循环除 3（O(log n)）
  ② 上限法：3^19 = 3^⌊log₃(2³¹)⌋ 是 int 内最大 3 幂 → n 整除它
  ③ 数学：3^19 % n == 0
⚠️ 注意负数与 0
```

### 6.2 完整代码

```java
/** 循环除 3 版 */
public boolean isPowerOfThree(int n) {
    if (n <= 0) return false;
    while (n % 3 == 0) n /= 3;                 // ⚠️ 除尽 3
    return n == 1;
}

/** 上限法（O(1)）——3^19 = 1162261467 是 int 内最大 3 的幂 */
public boolean isPowerOfThreeFast(int n) {
    return n > 0 && 1162261467 % n == 0;       // ⚠️ 最大 3 幂整除 n
}
// 推演 n=27：27÷3=9÷3=3÷3=1 → true ✓
// 推演 n=45：45÷3=15，15%3=0 → 15÷3=5，5%3≠0 → 5≠1 → false ✓
// ⚠️ 变体：231 2 的幂（n&(n-1)==0）、342 4 的幂（2 的幂 + %3==1）
// ⚠️ 面试必答："3 的幂循环除法最直观；
//   上限法 O(1)——int 内最大 3 的幂
//   3^19 能被所有 3 的幂整除。"
```

## 7. 1071. 字符串的最大公因子

### 7.1 题目与思路

```
两个字符串的最大公因子（能整除两者的最长字符串）
定理：存在公因子 ⟺ str1+str2 == str2+str1
  且公因子长度 = gcd(len1, len2)
⚠️ 交叉拼接相等是"可约"的充要条件
```

### 7.2 完整代码

```java
/**
 * LeetCode 1071. 字符串的最大公因子
 */
public String gcdOfStrings(String str1, String str2) {
    // ① 交叉拼接不等 → 无公因子
    if (!(str1 + str2).equals(str2 + str1)) return "";   // ⚠️ 充要条件

    // ② 公因子长度 = 长度 gcd
    int g = gcd(str1.length(), str2.length());
    return str1.substring(0, g);
}

private int gcd(int a, int b) {
    while (b != 0) {
        int t = a % b;
        a = b;
        b = t;
    }
    return a;
}
// 推演 str1="ABCABC", str2="ABC"：
//   拼接相等 ✓；gcd(6,3)=3 → "ABC" ✓
// 推演 str1="ABAB", str2="AB"：
//   gcd(4,2)=2 → "AB" ✓
// 推演 str1="LEET", str2="CODE"：
//   "LEETCODE" ≠ "CODELEET" → "" ✓
// ⚠️ 面试必答："1071 的充要条件：str1+str2 == str2+str1
//   才存在公因子；长度 gcd 即答案长度。"
```

## 8. 数论方法论总结

### 8.1 解题框架

```
① 识别：素数/gcd/幂/数位/因子 → 数论
② 定工具：
   素数 → 埃氏筛
   可除性 → gcd（贝祖）
   大指数 → 快速幂/降幂
   出现次数 → 数位统计
   质因子 → 循环除/分解
③ 取模：每步取模 + 负数转正
④ 复杂度：O(log n)/O(n log log n)

⚠️ 识别信号：
  "质数/质因子" → 筛法/分解
  "量水/整除" → gcd
  "超大指数" → 快速幂/降幂
  "1..n 中数字出现次数" → 数位统计
```
