| 概念 | 定义 | Java 实现 | 后端适配 |
|------|------|----------|---------|

| **稀疏矩阵** | 非零元素占比 < 10% | 三元组（Triple）或 CRS | 只存储非零元素，节省内存 |

### 2.2 矩阵乘法

#### 2.2.1 算法原理

矩阵乘法是最基础、最常用的矩阵运算。《算法导论》中定义：若 A 是 m × n 矩阵，B 是 n × p 矩阵，则乘积 C = AB 是 m × p 矩阵。

| 算法 | 时间复杂度 | 适用规模 | 特点 |
|------|-----------|---------|------|
| **朴素算法** | O(mnp) | 小规模矩阵 | 三重循环，实现简单 |
| **Strassen 算法** | O(n^log₂7) ≈ O(n^2.807) | 大规模方阵 | 分治法，7 次乘法替代 8 次 |

> **注意**：Strassen 算法存在精度损失（浮点数运算累积误差），且在小规模矩阵上效率不如朴素算法，需根据矩阵规模选择合适的实现方案。

#### 2.2.2 Java 实现

```java
import java.util.ArrayList;
import java.util.List;

/**
 * 矩阵运算工具类
 * 基于《算法导论》矩阵乘法、Strassen算法实现，支持稠密/稀疏矩阵
 */
public class MatrixUtils {

    // =================== 稠密矩阵乘法（朴素算法）===================
    /**
     * 稠密矩阵乘法（朴素实现，适用于小规模矩阵）
     */
    public static double[][] denseMatrixMultiply(double[][] A, double[][] B) {
        int m = A.length;
        int n = A[0].length;
        int p = B[0].length;

        if (n != B.length) {
            throw new IllegalArgumentException(
                    "矩阵维度不匹配：A的列数(" + n + ") != B的行数(" + B.length + ")");
        }

        double[][] C = new double[m][p];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < p; j++) {
                for (int k = 0; k < n; k++) {
                    C[i][j] += A[i][k] * B[k][j];
                }
            }
        }
        return C;
    }

    // =================== 稠密矩阵乘法（Strassen算法）===================
    /**
     * Strassen算法矩阵乘法（分治法，适用于大规模方阵）
     */
    public static double[][] strassenMatrixMultiply(double[][] A, double[][] B) {
        int n = A.length;

        if (n == 1) {
            double[][] result = new double[1][1];
            result[0][0] = A[0][0] * B[0][0];
            return result;
        }

        int half = n / 2;
        double[][] A11 = new double[half][half];
        double[][] A12 = new double[half][half];
        double[][] A21 = new double[half][half];
        double[][] A22 = new double[half][half];
        double[][] B11 = new double[half][half];
        double[][] B12 = new double[half][half];
        double[][] B21 = new double[half][half];
        double[][] B22 = new double[half][half];

        for (int i = 0; i < half; i++) {
            System.arraycopy(A[i], 0, A11[i], 0, half);
            System.arraycopy(A[i], half, A12[i], 0, half);
            System.arraycopy(A[half + i], 0, A21[i], 0, half);
            System.arraycopy(A[half + i], half, A22[i], 0, half);

            System.arraycopy(B[i], 0, B11[i], 0, half);
            System.arraycopy(B[i], half, B12[i], 0, half);
            System.arraycopy(B[half + i], 0, B21[i], 0, half);
            System.arraycopy(B[half + i], half, B22[i], 0, half);
        }

        double[][] M1 = strassenMatrixMultiply(addMatrix(A11, A22), addMatrix(B11, B22));
        double[][] M2 = strassenMatrixMultiply(addMatrix(A21, A22), B11);
        double[][] M3 = strassenMatrixMultiply(A11, subtractMatrix(B12, B22));
        double[][] M4 = strassenMatrixMultiply(A22, subtractMatrix(B21, B11));
        double[][] M5 = strassenMatrixMultiply(addMatrix(A11, A12), B22);
        double[][] M6 = strassenMatrixMultiply(subtractMatrix(A21, A11), addMatrix(B11, B12));
        double[][] M7 = strassenMatrixMultiply(subtractMatrix(A12, A22), addMatrix(B21, B22));

        double[][] C11 = addMatrix(subtractMatrix(addMatrix(M1, M4), M5), M7);
        double[][] C12 = addMatrix(M3, M5);
        double[][] C21 = addMatrix(M2, M4);
        double[][] C22 = addMatrix(subtractMatrix(addMatrix(M1, M3), M2), M6);

        double[][] C = new double[n][n];
        for (int i = 0; i < half; i++) {
            System.arraycopy(C11[i], 0, C[i], 0, half);
            System.arraycopy(C12[i], 0, C[i], half, half);
            System.arraycopy(C21[i], 0, C[half + i], 0, half);
            System.arraycopy(C22[i], 0, C[half + i], half, half);
        }
        return C;
    }

    // =================== 稀疏矩阵乘法（三元组存储）===================
    /**
     * 稀疏矩阵乘法（三元组存储，只存储非零元素）
     */
    public static List<Triple> sparseMatrixMultiply(List<Triple> A, List<Triple> B,
                                                     int m, int n, int p) {
        List<Triple> result = new ArrayList<>();
        double[] temp = new double[p];

        int aIndex = 0;
        for (int i = 0; i < m; i++) {
            java.util.Arrays.fill(temp, 0.0);

            while (aIndex < A.size() && A.get(aIndex).row == i) {
                Triple aTriple = A.get(aIndex);
                int k = aTriple.col;
                double aVal = aTriple.value;

                for (Triple bTriple : B) {
                    if (bTriple.row != k) continue;
                    temp[bTriple.col] += aVal * bTriple.value;
                }
                aIndex++;
            }

            for (int j = 0; j < p; j++) {
                if (Math.abs(temp[j]) > 1e-6) {
                    result.add(new Triple(i, j, temp[j]));
                }
            }
        }
        return result;
    }

    private static double[][] addMatrix(double[][] A, double[][] B) {
        int n = A.length;
        double[][] result = new double[n][n];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                result[i][j] = A[i][j] + B[i][j];
            }
        }
        return result;
    }

    private static double[][] subtractMatrix(double[][] A, double[][] B) {
        int n = A.length;
        double[][] result = new double[n][n];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                result[i][j] = A[i][j] - B[i][j];
            }
        }
        return result;
    }

    public static class Triple {
        public int row;
        public int col;
        public double value;

        public Triple(int row, int col, double value) {
            this.row = row;
            this.col = col;
            this.value = value;
        }
    }
}
```

### 2.3 高斯消元法

#### 2.3.1 算法原理

《算法导论》中，高斯消元法是求解线性方程组 Ax = b 的核心算法，其核心思想是"通过初等行变换，将增广矩阵 [A|b] 转化为上三角矩阵，再通过回代求解方程组的解"。

```
阶段一：前向消元 → 将增广矩阵转化为上三角矩阵
阶段二：回代求解 → 从最后一行开始，逐步向上求解每个变量的值
```

| 项目 | 值 |
|------|-----|
| **时间复杂度** | O(n³) |
| **适用规模** | n < 1000 |
| **优化** | 部分主元消元法（避免除数为零或数值溢出） |

#### 2.3.2 Java 实现

```java
import java.util.Arrays;

/**
 * 高斯消元法工具类（求解线性方程组 Ax = b）
 * 基于《算法导论》部分主元消元法实现，避免数值异常
 */
public class GaussianEliminationUtils {

    private static final double EPS = 1e-6;

    /**
     * 高斯消元法求解线性方程组 Ax = b（部分主元消元）
     * @return 方程组的解向量 x；若无解或无穷多解，返回 null
     */
    public static double[] solveLinearSystem(double[][] A, double[] b) {
        int n = A.length;
        if (A[0].length != n || b.length != n) {
            throw new IllegalArgumentException("矩阵维度不匹配");
        }

        // 构建增广矩阵
        double[][] augMatrix = new double[n][n + 1];
        for (int i = 0; i < n; i++) {
            System.arraycopy(A[i], 0, augMatrix[i], 0, n);
            augMatrix[i][n] = b[i];
        }

        // 前向消元：部分主元消元法
        for (int k = 0; k < n; k++) {
            // 选择主元（当前列绝对值最大的元素所在行）
            int pivotRow = k;
            for (int i = k + 1; i < n; i++) {
                if (Math.abs(augMatrix[i][k]) > Math.abs(augMatrix[pivotRow][k])) {
                    pivotRow = i;
                }
            }

            // 交换主元行与当前行
            if (pivotRow != k) {
                double[] temp = augMatrix[k];
                augMatrix[k] = augMatrix[pivotRow];
                augMatrix[pivotRow] = temp;
            }

            // 若主元为 0，说明无解或无穷多解
            if (Math.abs(augMatrix[k][k]) < EPS) {
                return null;
            }

            // 消去当前列 k 下方的所有元素
            for (int i = k + 1; i < n; i++) {
                double factor = augMatrix[i][k] / augMatrix[k][k];
                for (int j = k; j <= n; j++) {
                    augMatrix[i][j] -= factor * augMatrix[k][j];
                }
            }
        }

        // 回代求解
        double[] x = new double[n];
        for (int i = n - 1; i >= 0; i--) {
            double sum = 0.0;
            for (int j = i + 1; j < n; j++) {
                sum += augMatrix[i][j] * x[j];
            }
            x[i] = (augMatrix[i][n] - sum) / augMatrix[i][i];
        }
        return x;
    }

    /**
     * 验证解的正确性
     */
    public static boolean verifySolution(double[][] A, double[] x, double[] b) {
        int n = A.length;
        for (int i = 0; i < n; i++) {
            double sum = 0.0;
            for (int j = 0; j < n; j++) {
                sum += A[i][j] * x[j];
            }
            if (Math.abs(sum - b[i]) > EPS) {
                return false;
            }
        }
        return true;
    }
}
```

### 2.4 矩阵分解

#### 2.4.1 算法原理

矩阵分解是将一个矩阵拆分为两个或多个简单矩阵的乘积，核心价值是"将复杂矩阵运算转化为简单矩阵的运算"。

| 分解方法 | 公式 | 时间复杂度 | 特点 | 适用场景 |
|---------|------|-----------|------|---------|
| **LU 分解** | A = LU | O(n³) | L 为下三角（主对角线为 1），U 为上三角 | 多次求解同一系数矩阵的线性方程组 |
| **QR 分解** | A = QR | O(n³) | Q 为正交矩阵（Q^T Q = I），R 为上三角 | 特征降维、最小二乘求解 |

#### 2.4.2 Java 实现（LU 分解）

```java
import java.util.Arrays;

/**
 * 矩阵分解工具类（LU分解）
 * 基于《算法导论》LU分解原理实现
 */
public class MatrixDecompositionUtils {

    private static final double EPS = 1e-6;

    /**
     * LU分解：将 n×n 方阵 A 拆分为下三角矩阵 L 和上三角矩阵 U（A = LU）
     * @return 长度为2的数组 [L, U]；若无法分解返回 null
     */
    public static double[][][] luDecomposition(double[][] A) {
        int n = A.length;
        if (A[0].length != n) {
            throw new IllegalArgumentException("LU分解仅支持方阵");
        }

        double[][] L = new double[n][n];
        double[][] U = new double[n][n];
        for (int i = 0; i < n; i++) {
            L[i][i] = 1.0;
        }

        for (int k = 0; k < n; k++) {
            // 计算 U 的第 k 行
            for (int j = k; j < n; j++) {
                double sum = 0.0;
                for (int p = 0; p < k; p++) {
                    sum += L[k][p] * U[p][j];
                }
                U[k][j] = A[k][j] - sum;
            }

            if (Math.abs(U[k][k]) < EPS) return null;

            // 计算 L 的第 k 列
            for (int i = k + 1; i < n; i++) {
                double sum = 0.0;
                for (int p = 0; p < k; p++) {
                    sum += L[i][p] * U[p][k];
                }
                L[i][k] = (A[i][k] - sum) / U[k][k];
            }
        }

        return new double[][][]{L, U};
    }

    /**
     * 基于LU分解求解线性方程组 Ax = b（适用于多次求解同一 A 的场景）
     */
    public static double[] solveWithLU(double[][] L, double[][] U, double[] b) {
        int n = L.length;

        // 求解 Ly = b（前向替代）
        double[] y = new double[n];
        for (int i = 0; i < n; i++) {
            double sum = 0.0;
            for (int j = 0; j < i; j++) {
                sum += L[i][j] * y[j];
            }
            y[i] = b[i] - sum;
        }

        // 求解 Ux = y（回代求解）
        double[] x = new double[n];
        for (int i = n - 1; i >= 0; i--) {
            double sum = 0.0;
            for (int j = i + 1; j < n; j++) {
                sum += U[i][j] * x[j];
            }
            x[i] = (y[i] - sum) / U[i][i];
        }
        return x;
    }
}
```

## 三、工程实践与避坑指南

### 3.1 存储优化

| 优化点 | 说明 |
|-------|------|
| **稀疏矩阵优先** | 采用压缩存储格式（三元组、CRS），避免二维数组导致的内存浪费 |
| **数据类型精简** | 普通场景用 double，计数场景用 int，高精度场景用 BigDecimal |
| **避免频繁创建** | 使用对象池复用矩阵对象，减少 GC 压力 |

### 3.2 效率优化

| 场景 | 推荐策略 |
|------|---------|
| **小规模矩阵（n < 100）** | 朴素算法 |
| **大规模矩阵（n ≥ 1000）** | Strassen 算法、分块算法 |
| **多次求解同一系数矩阵** | LU 分解 |
| **数值不稳定场景** | QR 分解 |
| **高并发场景** | 并行流、线程池、分布式计算框架 |

> **复用第三方库**：Java 后端开发中，无需重复实现复杂矩阵运算（如 QR 分解、大规模矩阵求逆），可复用 Apache Commons Math、MTJ（Matrix Toolkit Java）等成熟库。

### 3.3 稳定性优化

| 问题 | 方案 |
|------|------|
| **除数为零** | 部分主元消元法 |
