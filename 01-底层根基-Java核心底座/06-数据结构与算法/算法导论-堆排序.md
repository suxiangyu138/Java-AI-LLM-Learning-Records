## 一、堆的核心概念

### 1. 堆的结构

| 类型 | 定义 |
|------|------|
| **完全二叉树** | 除最后一层外，所有层节点填满，最后一层靠左排列 |
| **大顶堆** | 父节点 ≥ 子节点，堆顶为最大值 |
| **小顶堆** | 父节点 ≤ 子节点，堆顶为最小值 |

### 2. 堆的存储（数组）

| 节点 | 下标计算 |
|------|----------|
| 当前节点 i | — |
| 左子节点 | 2i + 1 |
| 右子节点 | 2i + 2 |
| 父节点 | (i - 1) / 2 |

### 3. 核心操作

| 操作 | 说明 | 时间复杂度 |
|------|------|------------|
| **堆化（heapify）** | 维护堆性质 | O(log n) |
| **建堆（build-heap）** | 将数组转为堆 | O(n) |
| **堆排序** | 循环取堆顶 + 堆化 | O(n log n) |

## 二、堆排序完整实现

```java
/**
 * 堆排序（大顶堆实现）
 * 时间复杂度：O(nlogn)
 * 空间复杂度：O(1) 原地排序
 * 稳定性：不稳定
 */
public class HeapSort {

    /**
     * 堆排序主方法
     */
    public void sort(int[] arr) {
        if (arr == null || arr.length <= 1) {
            return;
        }
        int n = arr.length;
        // 1. 建堆：从最后一个非叶子节点向上堆化
        for (int i = n / 2 - 1; i >= 0; i--) {
            heapify(arr, n, i);
        }
        // 2. 排序：交换堆顶与末尾，堆化剩余元素
        for (int i = n - 1; i > 0; i--) {
            // 交换堆顶（最大值）与当前末尾
            swap(arr, 0, i);
            // 堆化剩余i个元素
            heapify(arr, i, 0);
        }
    }

    /**
     * 堆化：维护大顶堆性质
     * @param arr 数组
     * @param len 堆有效长度
     * @param i 当前节点下标
     */
    private void heapify(int[] arr, int len, int i) {
        int largest = i;          // 最大值下标
        int left = 2 * i + 1;     // 左子节点
        int right = 2 * i + 2;    // 右子节点

        // 左子节点更大
        if (left < len && arr[left] > arr[largest]) {
            largest = left;
        }
        // 右子节点更大
        if (right < len && arr[right] > arr[largest]) {
            largest = right;
        }
        // 最大值不是当前节点，交换并递归堆化
        if (largest != i) {
            swap(arr, i, largest);
            heapify(arr, len, largest);
        }
    }

    /**
     * 交换数组元素
     */
    private void swap(int[] arr, int i, int j) {
        int temp = arr[i];
        arr[i] = arr[j];
        arr[j] = temp;
    }
}
```

## 三、堆排序核心步骤

> 堆排序的核心流程可以概括为以下四步：

1. **建堆**：将数组转为大顶堆，O(n)
2. **交换**：交换堆顶与末尾元素，最大值就位
3. **堆化**：堆化剩余 n - 1 个元素，O(log n)
4. **重复**：重复步骤 2-3，直到数组有序

## 四、Java后端核心应用场景

### 1. 优先队列（PriorityQueue）

- JDK `PriorityQueue` 基于小顶堆实现
- 应用：任务优先级调度、延迟队列、超时处理

```java
// 小顶堆：默认自然排序
PriorityQueue<Integer> minHeap = new PriorityQueue<>();
// 大顶堆：自定义比较器
PriorityQueue<Integer> maxHeap = new PriorityQueue<>((a, b) -> b - a);
```

### 2. TopK问题（高频面试）

| 维度 | 说明 |
|------|------|
| **场景** | 求前 K 大/小元素、热点排行、热门搜索 |
| **复杂度** | O(n log k)，远优于全排序 O(n log n) |

```java
/**
 * TopK问题：求数组中第K大元素
 */
public int findKthLargest(int[] nums, int k) {
    // 小顶堆，保留K个最大元素
    PriorityQueue<Integer> heap = new PriorityQueue<>();
    for (int num : nums) {
        heap.add(num);
        if (heap.size() > k) {
            heap.poll();
        }
    }
    return heap.peek();
}
```

### 3. 海量数据排序

| 场景 | 说明 |

| **内存受限场景** | 堆排序原地排序，无需额外空间 |
| **外部排序优化** | 多路归并 + 堆排序 |

### 4. 流式数据处理

| 场景 | 说明 |

## 五、堆排序性能分析

### 时间复杂度

|------|--------|
| 建堆 | O(n) |
| 堆化 | O(log n) |
| 总复杂度 | **O(n log n)**，稳定不退化 |

### 空间复杂度

| 维度 | 值 |
|------|----|
| 空间复杂度 | **O(1)**，原地排序，仅用常数额外空间 |

### 稳定性

| 维度 | 值 |
|------|----|
| 稳定性 | **不稳定**：交换可能改变相同元素相对位置 |

## 六、堆排序与其他排序对比

### 快排 vs 堆排

| 维度 | 快排 | 堆排 |
|------|------|------|
| 时间复杂度 | 平均 O(n log n)，最坏 O(n²) | 稳定 O(n log n) |
| 常数因子 | 小 | 大 |
| 实际速度 | **更快** | 较慢 |
| 适合场景 | 通用排序 | 内存受限场景 |

### 归并 vs 堆排

| 维度 | 归并 | 堆排 |
|------|------|------|
| 时间复杂度 | 稳定 O(n log n) | 稳定 O(n log n) |
| 空间复杂度 | **O(n)** | **O(1)** |
| 稳定性 | **稳定** | 不稳定 |
| 适合场景 | 外部排序、对象排序 | 内存紧张场景 |

### 后端选型建议

| 场景 | 推荐算法 |
|------|----------|
| 追求速度 | 快排（JDK `Arrays.sort` 基础类型） |
| 内存受限 | **堆排** |
| 要求稳定 | 归并（JDK `Arrays.sort` 对象类型） |
| TopK 问题 | **堆排最优** |

## 七、堆排序优化

### 1. 小顶堆优化 TopK

| 场景 | 堆类型 | 复杂度 |
|------|--------|--------|
| 求前 K 大 | 小顶堆 | O(n log k) |
| 求前 K 小 | 大顶堆 | O(n log k) |

### 2. 堆化迭代实现

避免递归栈溢出，适合大数据量：

```java
private void heapifyIterative(int[] arr, int len, int i) {
    while (true) {
        int largest = i;
        int left = 2 * i + 1;
        int right = 2 * i + 2;
        if (left < len && arr[left] > arr[largest]) largest = left;
        if (right < len && arr[right] > arr[largest]) largest = right;
        if (largest == i) break;
        swap(arr, i, largest);
        i = largest;
    }
}
```

### 3. 并行堆排序

- 多线程建堆 + 排序，提升大数据处理速度
- 应用：ForkJoin 框架、分布式计算

## 八、总结

> 1. 堆排序基于二叉堆，时间复杂度稳定 O(n log n)，空间 O(1)
> 2. 核心操作：建堆 O(n)、堆化 O(log n)、排序 O(n log n)
> 3. Java 后端核心应用：`PriorityQueue`、TopK 问题、海量数据排序、流式处理
> 4. 性能优于选择排序，适合内存受限场景
> 5. 面试高频：堆排序实现、TopK 问题、优先队列原理
> 6. 与快排/归并互补，是后端必备排序算法
