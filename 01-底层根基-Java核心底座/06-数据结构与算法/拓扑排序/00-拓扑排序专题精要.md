## 1. 核心概念

### 1.1 什么是拓扑排序

> 拓扑排序：**有向无环图（DAG）**的线性排列，满足每条边 u→v，u 都排在 v 前面。

```
课程依赖：
  A → B（先修 A 再修 B）
  A → C，B → D，C → D

拓扑序：A, B, C, D（或 A, C, B, D）

关键性质：
  ① 仅 DAG 有拓扑序（有环 → 无解）
  ② 拓扑序不唯一（入度 0 的节点可任意顺序）
  ③ 有向图有拓扑序 ⇔ 无环

⚠️ 常见误区：
  拓扑排序不是排序算法（不比较大小）
  是"依赖关系"的线性化
```

### 1.2 两种算法

| 算法 | 思路 | 实现 | 特点 |
|------|------|:---:|------|
| **Kahn（BFS）** | 入度 0 入队 → 减入度 | 队列 | **最易手写，推荐** |
| DFS 颜色法 | 0/1/2 三态判环 | 递归 | 展示 DFS 深度 |

```
选型：
  默认 Kahn（模板固定，好讲）
  被追问"DFS 怎么做" → 颜色法
  两者都要能讲（面试常问第二解法）
```

### 1.3 应用场景

```
① 依赖排序：课程表/编译顺序/任务调度
② 判环：有向图是否有环（拓扑序长度 < n）
③ 分层拓扑：并行课程（1136 最短学期数）
④ 字典序拓扑：优先队列替代普通队列
⑤ 剥叶子：310 最小高度树（入度 1 层层剥）

⚠️ 判定有环：拓扑序长度 < 节点数
```

## 2. Kahn 完整模板

### 2.1 标准实现（207/210 课程表）

```java
/**
 * Kahn 拓扑排序模板（BFS 版）——面试标准答案
 * 返回拓扑序；长度 < n 说明有环
 */
public int[] kahn(int n, int[][] edges) {
    // ① 建图 + 统计入度
    List<List<Integer>> graph = new ArrayList<>();
    int[] indegree = new int[n];
    for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
    for (int[] e : edges) {
        graph.get(e[0]).add(e[1]);    // e[0] → e[1]
        indegree[e[1]]++;             // ⚠️ 入度 +1
    }

    // ② 入度为 0 的节点入队（无前置依赖）
    Queue<Integer> queue = new LinkedList<>();
    for (int i = 0; i < n; i++) {
        if (indegree[i] == 0) queue.offer(i);
    }

    // ③ BFS 处理
    int[] order = new int[n];
    int index = 0;
    while (!queue.isEmpty()) {
        int cur = queue.poll();
        order[index++] = cur;         // 加入拓扑序

        for (int next : graph.get(cur)) {
            if (--indegree[next] == 0) {   // ⚠️ 前置完成
                queue.offer(next);         // 可以处理了
            }
        }
    }

    return index == n ? order : new int[0];   // 有环 → 空
}
// 复杂度 O(V+E)：每个节点入队一次，每条边处理一次
```

### 2.2 推演：edges = [[0,1],[0,2],[1,3],[2,3]]

```
建图：0→1, 0→2, 1→3, 2→3
入度：0:0, 1:1, 2:1, 3:2

① 入度 0 入队：[0]
② 弹 0 → 拓扑序 [0]；后继 1、2 入度减 1 → 都变 0 → 入队 [1,2]
③ 弹 1 → [0,1]；后继 3 入度 2→1（未到 0）
④ 弹 2 → [0,1,2]；后继 3 入度 1→0 → 入队 [3]
⑤ 弹 3 → [0,1,2,3]

拓扑序 [0,1,2,3] ✓（length=4=n → 无环）
```

### 2.3 为什么"入度减到 0 才入队"？

```
入度 = 还没完成的前置课程数
  前置完成一个 → 入度减 1
  减到 0 → 所有前置完成 → 可以修这门课

⚠️ 有环时：环上节点入度永远 ≥ 1
  → 永远无法入队 → 处理数 < n → 判环
  （这就是 Kahn 判环的原理）
```

## 3. DFS 颜色法判环

### 3.1 完整实现（207 第二解法）

```java
/**
 * DFS 颜色法：0 未访问 / 1 访问中 / 2 已完成
 * 递归中遇到"访问中" → 有环（当前路径回到自己）
 */
public boolean canFinish(int numCourses, int[][] prerequisites) {
    List<List<Integer>> graph = new ArrayList<>();
    for (int i = 0; i < numCourses; i++) graph.add(new ArrayList<>());
    for (int[] pre : prerequisites) {
        graph.get(pre[1]).add(pre[0]);    // pre[1] → pre[0]
    }

    int[] color = new int[numCourses];
    for (int i = 0; i < numCourses; i++) {
        if (color[i] == 0 && hasCycle(graph, i, color)) {
            return false;                 // 有环
        }
    }
    return true;
}

private boolean hasCycle(List<List<Integer>> graph, int node, int[] color) {
    color[node] = 1;                      // 访问中（在递归栈上）

    for (int next : graph.get(node)) {
        if (color[next] == 1) return true;     // ⚠️ 遇到访问中 → 环！
        if (color[next] == 0 && hasCycle(graph, next, color)) {
            return true;
        }
    }

    color[node] = 2;                      // 已完成（出递归栈）
    return false;
}
```

### 3.2 颜色法 vs 简单 visited

```
简单 visited 为什么不能判环？
  visited 只区分"访问过/没访问过"
  无法区分"本路径上"（访问中）与"其他路径"（已完成）

颜色法三态：
  0 未访问 → 进入递归
  1 访问中 → 当前递归栈上 → 有环！（回到自己）
  2 已完成 → 其他路径已处理 → 跳过

类比：1 = 递归调用栈中的节点
  遇到它说明"存在一条路径绕回自己" = 环
```

### 3.3 Kahn vs 颜色法对比

| 维度 | Kahn（BFS） | 颜色法（DFS） |
|------|:---:|:---:|
| 思路 | 入度 0 队列 | 递归栈判环 |
| 手写难度 | 固定模板 | 颜色数组三态 |
| 空间 | O(V) | O(V) 递归栈 |
| 面试推荐 | **首选** | 追问时展示 |
| 副产品 | 拓扑序 | 只能判环 |

```
面试完整表达：
"课程表两种解法——Kahn（BFS）统计入度判环，
 以及 DFS 颜色法：0 未访问、1 访问中、2 已完成，
 遇到访问中说明有环。我写 Kahn 版更易手写，
 两种复杂度都是 O(V+E)。"
```

### 4.2 分层拓扑（1136 并行课程）

```java
// 每层 = 一个学期（同 Kahn，按层计数）
public int minimumSemesters(int n, int[][] relations) {
    // 建图 + 入度（同上）
    Queue<Integer> queue = new LinkedList<>();
    for (int i = 1; i <= n; i++)
        if (indegree[i] == 0) queue.offer(i);

    int semesters = 0, processed = 0;
    while (!queue.isEmpty()) {
        int size = queue.size();         // ⚠️ 分层！
        for (int i = 0; i < size; i++) {
            int cur = queue.poll();
            processed++;
            for (int next : graph.get(cur)) {
                if (--indegree[next] == 0) queue.offer(next);
            }
        }
        semesters++;                     // 每层 = 1 学期
    }
    return processed == n ? semesters : -1;   // 有环 → -1
}
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"依赖关系用拓扑排序（Kahn 算法）：
 ① 统计每个节点的入度；
 ② 入度为 0（无前置）的节点入队；
 ③ 出队加入拓扑序，后继入度减 1，
    减到 0 再入队；
 ④ 处理数 == 节点数 → 无环；否则有环。
 复杂度 O(V+E)。BFS 版最易手写。
 追问 DFS 版：颜色法 0/1/2 三态判环。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | Kahn 为什么能判环？ | 环上节点入度永远 ≥ 1 → 无法入队 → 处理数 < n |
| 2 | 有向 vs 无向判环区别？ | 有向用拓扑/颜色法；无向 DFS 跳过父节点或并查集 |
| 3 | 字典序拓扑怎么改？ | 队列换 PriorityQueue（小根堆） |
| 4 | 分层拓扑怎么计层？ | 每轮固定 size 处理（同 BFS 分层） |
| 5 | 边方向怎么定？ | 依赖方向：先修 → 后续；语义统一（反了结果错） |
| 6 | 拓扑序唯一吗？ | 不唯一；唯一 ⇔ 任意时刻入度 0 节点最多 1 个 |
| 7 | 为什么不连通也行？ | 拓扑不要求图连通（入度 0 的多个分量各自入队） |
| 8 | 能处理带权依赖吗？ | 拓扑只管顺序；权重用 DP（2050 并行课程 III） |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 边方向反了 | 拓扑序颠倒 | 先修 → 后续统一 |
| 忘统计入度 | 全部入队/都不入队 | 建图时同步 indegree |
| 判环条件写错 | 有环误判无环 | index == n 才无环 |
| 颜色法忘置 2 | 误判环 | 递归返回后 color=2 |
| 分层忘 size | 层数错误 | int size = q.size() |

> 🎯 **核心要点**：Kahn = **入度统计 + 入度 0 入队 + 减入度**三步模板。识别信号："先修/依赖/顺序/判环"。310 剥叶子、分层拓扑、字典序拓扑是三大变形。Kahn 与颜色法双解法都要能讲。
