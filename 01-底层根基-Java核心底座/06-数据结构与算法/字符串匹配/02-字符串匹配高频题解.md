## 1. 28. 找出字符串中第一个匹配项的下标（KMP）

### 1.1 题目与思路

```
KMP 标准应用（完整推导见字符串匹配/01）
next 回退 + 文本指针不回退
```

### 1.2 完整代码

```java
/**
 * LeetCode 28. 找出字符串中第一个匹配项的下标（KMP）
 */
public int strStr(String haystack, String needle) {
    int n = haystack.length(), m = needle.length();
    if (m == 0) return 0;

    int[] next = buildNext(needle);
    int j = 0;
    for (int i = 0; i < n; i++) {
        while (j > 0 && haystack.charAt(i) != needle.charAt(j))
            j = next[j - 1];                 // ⚠️ 失败回退（i 不动）
        if (haystack.charAt(i) == needle.charAt(j)) j++;
        if (j == m) return i - m + 1;        // 匹配完成
    }
    return -1;
}

private int[] buildNext(String p) {
    int m = p.length();
    int[] next = new int[m];
    int j = 0;
    for (int i = 1; i < m; i++) {
        while (j > 0 && p.charAt(i) != p.charAt(j)) j = next[j - 1];
        if (p.charAt(i) == p.charAt(j)) j++;
        next[i] = j;
    }
    return next;
}
// 推演 haystack="aabaabaafa", needle="aabaaf"：
//   匹配到 "aabaab" 第 6 位失败：next[5]=2 → j=2
//   继续匹配 "aaf"？——第 6 位 a 与模式第 2 位 b 比较...
//   实际：aabaab 匹配后 a vs f 失败 → j=next[5]=2（模式 "aa"）
//   文本继续 → 命中 "aabaaf" ✓
// ⚠️ 复杂度：O(n+m)
// ⚠️ 面试必答："28 = KMP 完整实现——
//   next 构建（模式匹配自己）+ 匹配（回退不回头）。"
```

## 2. 459. 重复的子字符串

### 2.1 题目与思路

```
s 是否由重复子串组成
next 周期公式：period = n - next[n-1]
⚠️ 完整推导见字符串匹配/01 模块 5 节
```

### 2.2 完整代码

```java
/**
 * LeetCode 459. 重复的子字符串（next 周期）
 */
public boolean repeatedSubstringPattern(String s) {
    int n = s.length();
    int[] next = buildNext(s);
    int period = n - next[n - 1];            // ⚠️ 最小周期
    return period != n && n % period == 0;
}
// 推演 "abab"：next[3]=2 → period=2 → 4%2==0 → true ✓
// 推演 "abcabcabc"：next[8]=6 → period=3 → true ✓
// 推演 "aba"：next[2]=1 → period=2 → 3%2≠0 → false ✓
// ⚠️ 面试必答："459 = next 周期公式——
//   n - next[n-1] 是最小周期，整除即重复。
//   对比滚动哈希解（滚动哈希/02）：next 版更简洁。"
```

## 3. 796. 旋转字符串

### 3.1 题目与思路

```
s 旋转若干位后能否等于 goal
经典技巧：s+s 包含 goal 且长度相等
⚠️ 前提：长度必须相等（否则 s+s 可能包含子串）
```

### 3.2 完整代码

```java
/**
 * LeetCode 796. 旋转字符串
 * ⚠️ s 的任意旋转都是 s+s 的子串（从旋转点切开拼接）
 */
public boolean rotateString(String s, String goal) {
    return s.length() == goal.length()
            && (s + s).contains(goal);       // ⚠️ 长度约束防误判
}
// 推演 s="abcde", goal="cdeab"：
//   s+s = "abcdeabcde" 包含 "cdeab" ✓
// 推演 s="abcde", goal="abcdeab"：长度不等 → false ✓
// ⚠️ 复杂度：O(n)（contains 用 KMP/朴素）
// ⚠️ 面试必答："796 = s+s 拼接技巧——
//   旋转 = 从某点切开重接，必是 s+s 子串；
//   长度相等是隐藏前提。"
```

## 4. 1392. 最长快乐前缀

### 4.1 题目与思路

```
既是前缀又是后缀（非自身）的最长子串
next[n-1] 直接就是答案长度！
⚠️ next[n-1] = 整个串的最长相等前后缀
```

### 4.2 完整代码

```java
/**
 * LeetCode 1392. 最长快乐前缀（next 直接取）
 */
public String longestPrefix(String s) {
    int[] next = buildNext(s);
    int len = next[s.length() - 1];          // ⚠️ 全串最长前后缀
    return s.substring(0, len);
}
// 推演 "level"：next[4]=1（"l"）→ 返回 "l" ✓
// 推演 "ababab"：next[5]=4（"abab"）→ 返回 "abab" ✓
// ⚠️ 复杂度：O(n)
// ⚠️ 面试必答："1392 = next 数组白送——
//   next[n-1] 就是最长相等前后缀；
//   对比滚动哈希解（滚动哈希/02）：next 版一行。"
```

## 5. 214. 最短回文串

### 5.1 题目与思路

```
前面加字符使成回文（最短）
找最长回文前缀 → 剩余反转拼前面
KMP 版：s + '#' + reverse(s) 的 next 末位 = 最长回文前缀长度
⚠️ '#' 分隔防跨串匹配
```

### 5.2 完整代码

```java
/**
 * LeetCode 214. 最短回文串（KMP 版）
 */
public String shortestPalindrome(String s) {
    int n = s.length();
    String rev = new StringBuilder(s).reverse().toString();
    String concat = s + "#" + rev;           // ⚠️ 分隔符防跨串

    int[] next = buildNext(concat);
    int palLen = next[concat.length() - 1];  // ⚠️ 最长回文前缀长度

    String suffix = s.substring(palLen);     // 剩余部分
    return new StringBuilder(suffix).reverse().append(s).toString();
}
// 推演 s="aacecaaa"：
//   concat = "aacecaaa#aascecaa"（reverse 版）
//   next 末位 = 7（"aacecaa" 是回文前缀）
//   剩余 "a" → 反转 "a" + 原串 → "aaacecaaa" ✓
// ⚠️ 为什么 next 末位 = 回文前缀：
//   回文 ⟺ 前缀 == 反转后缀 → 拼接后前后缀相等
// ⚠️ 面试必答："214 = 拼接 + next——
//   回文前缀 ⟺ 原串前缀 == 反转串后缀
//   （'#' 保证不跨串），next 末位即长度。"
```

## 6. 686. 重复叠加字符串匹配

### 6.1 题目与思路

```
a 重复几次后包含 b（最小次数）
次数范围：ceil(len_b/len_a) 到 +2
⚠️ KMP/contains 在叠加串中找 b
```

### 6.2 完整代码

```java
/**
 * LeetCode 686. 重复叠加字符串匹配
 */
public int repeatedStringMatch(String a, String b) {
    int min = (b.length() + a.length() - 1) / a.length();   // ⚠️ 下界
    StringBuilder sb = new StringBuilder();
    for (int i = 0; i < min; i++) sb.append(a);

    for (int extra = 0; extra <= 2; extra++) {   // ⚠️ 最多再补 2 个
        if (sb.toString().contains(b)) return min + extra;
        sb.append(a);
    }
    return -1;
}
// 推演 a="abcd", b="cdabcdab"：
//   min = ceil(8/4) = 2 → "abcdabcd" 包含 ✓ → 2
// 推演 a="aa", b="a"：min=1 → "aa" 含 → 1 ✓
// ⚠️ 为什么 +2 够：b 起点必在前 2 个 a 内
//   （否则 b 尾部超出必要范围）
// ⚠️ 面试必答："686 = 次数上下界——
//   ceil(len_b/len_a) 起，最多 +2；
//   contains 内部可用 KMP 优化。"
```

## 7. 字符串匹配方法论总结

### 7.1 解题框架

```
① 识别：单模式匹配/周期/前后缀 → 匹配算法
② 选工具：
   单模式 → KMP/Z（确定）或 Rabin-Karp（简单）
   周期 → next[n-1] 公式
   旋转/拼接 → s+s 技巧
   回文前缀 → 拼接 + next
③ 实现：next 构建（自匹配递推）
④ 复杂度：O(n+m)

⚠️ 识别信号：
  "找子串/匹配" → KMP/Rabin-Karp
  "重复子串/周期" → next 公式
  "旋转/拼接" → s+s
  "快乐前缀/回文前缀" → next 直接取
```
