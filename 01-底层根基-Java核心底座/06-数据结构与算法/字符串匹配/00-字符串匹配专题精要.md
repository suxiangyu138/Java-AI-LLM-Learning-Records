## 1. 核心概念

### 1.1 问题定义与算法家族

> 字符串匹配：在主串 text（长度 n）中查找模式串 pattern（长度 m）第一次出现的位置。

```
算法家族对比：
  朴素匹配：主串每个位置尝试 → O(n×m)
  KMP：预处理 next，主串不回溯 → O(n+m) ★ 面试重点
  BM：从后往前 + 坏字符/好后缀 → 平均最快（工程常用）
  Rabin-Karp：滚动哈希 → O(n+m) 期望

KMP 的核心价值：
  匹配失败时主串指针**永不回溯**
  → 文本流场景（无法回退读取）特别适用
```

### 1.2 KMP 的核心思想

```
匹配到一半失败时，利用"已匹配部分"的最长公共前后缀
跳过不可能的位置：

text    : A B C A B D
pattern : A B C A B C
                  ↑ 失配

已匹配 "ABCAB" 的最长公共前后缀 = "AB"（长度 2）
→ 模式串直接跳到 j=2 继续比（前缀 AB 对齐后缀 AB）
→ 主串指针 i 不动！

next 数组定义：
  next[i] = pattern[0..i-1] 的最长公共前后缀长度
  （两种定义：含/不含自身，写代码前先声明）
```

### 1.3 为什么主串不回溯是优势

```
暴力匹配：
  主串指针 i 反复回溯 → 已比较字符重复比较
  最坏 O(n×m)：text="AAA...A", pattern="AA...B"
  每次匹配到最后一个字符才失败 → 回溯重来

KMP：
  主串指针 i 单调前进（n 次）
  模式串指针 j 回退（摊还 O(1)）
  → O(n+m)

文本流场景：
  主串是流式输入（无法回退）→ 只有 KMP 可行
```

## 2. KMP 完整模板

### 2.1 完整实现（28. 找出字符串中第一个匹配项的下标）

```java
/**
 * KMP 完整模板——两段结构（next 构建 + 匹配）
 * 都是"while 回退 + 相等推进"的模式
 */
public int strStr(String haystack, String needle) {
    int n = haystack.length(), m = needle.length();
    if (m == 0) return 0;
    if (n < m) return -1;

    // ═══════ ① next 数组构建 ═══════
    // next[i] = pattern[0..i] 的最长公共前后缀长度（含自身版）
    int[] next = new int[m];
    int j = 0;                            // 当前最长前后缀长度

    for (int i = 1; i < m; i++) {
        // ⚠️ 失配回退用 while（可能多次回退）不是 if！
        while (j > 0 && needle.charAt(i) != needle.charAt(j)) {
            j = next[j - 1];              // 回退到更短的前后缀
        }
        if (needle.charAt(i) == needle.charAt(j)) {
            j++;                          // 匹配 → 长度+1
        }
        next[i] = j;
    }

    // ═══════ ② 匹配（主串不回溯）═══════
    j = 0;
    for (int i = 0; i < n; i++) {
        while (j > 0 && haystack.charAt(i) != needle.charAt(j)) {
            j = next[j - 1];              // 模式串回退
        }
        if (haystack.charAt(i) == needle.charAt(j)) {
            j++;
        }
        if (j == m) {
            return i - m + 1;             // 匹配成功，返回起点
        }
    }
    return -1;
}
```

### 2.2 next 构建推演：pattern = "ABABCABAB"

```
next 数组：[0, 0, 1, 2, 0, 1, 2, 3, 4]

i=1(B)：j=0，B≠A → next[1]=0
i=2(A)：j=0，A==A → j=1 → next[2]=1
i=3(B)：j=1，B==B → j=2 → next[3]=2
i=4(C)：j=2，C≠A → 回退 j=next[1]=0；C≠A → next[4]=0
i=5(A)：j=0，A==A → j=1 → next[5]=1
i=6(B)：j=1，B==B → j=2 → next[6]=2
i=7(A)：j=2，A==A → j=3 → next[7]=3
i=8(B)：j=3，B==B → j=4 → next[8]=4

验证：pattern[0..7]="ABABCABA" 的最长公共前后缀 = "ABAB"（长度 4）✓
```

### 2.3 匹配过程推演

```
haystack = "ABABDABAC", needle = "ABABAC"
next = [0, 0, 1, 2, 3, 0]（needle: A B A B A C）

i=0..4：A B A B A 全部匹配 → j=5
i=5(D)：D ≠ C → 回退 j = next[4] = 3
  D vs pattern[3]=B → 不等 → 回退 j = next[2] = 1
  D vs pattern[1]=B → 不等 → 回退 j = next[0] = 0
  D vs pattern[0]=A → 不等，j=0
i=6(A)：A == A → j=1
i=7(B)：B == B → j=2
i=8(A)：A == A → j=3
...
主串指针 i 从 0 走到 8 只扫描一遍 → O(n) ✓
```

## 3. 匹配算法家族对比

### 3.1 算法对比表

| 算法 | 时间 | 空间 | 特点 |
|------|:---:|:---:|------|
| 朴素 | O(n×m) | O(1) | 简单，最坏差 |
| **KMP** | **O(n+m)** | O(m) | 主串不回溯，确定 |
| BM | 平均 O(n/m) | O(m) | 从后往前，工程最快 |
| Rabin-Karp | O(n+m) 期望 | O(1) | 哈希，可查重 |

```
工程选型：
  Java String.indexOf：朴素 + 优化（实际已很快）
  GNU grep：BM 变体
  竞赛/面试：KMP（思想标准）

⚠️ 面试答："KMP 是思想标准（不回溯）；
  BM 工程平均最快；Rabin-Karp 适合多模式"
```

### 3.2 朴素 vs KMP 复杂度对比

```
朴素最坏：text="AAAAA...AB", pattern="AAAA...B"
  每次从 i 开始匹配到末尾失败 → O(n×m)

KMP：同样的输入
  next 数组让 j 回退到前缀位置
  → 主串只扫一遍 → O(n+m)

⚠️ 面试必答："为什么 KMP 是 O(n+m)？
  主串指针 i 不回溯（n 次），
  j 的回退次数 ≤ 前进次数（摊还 O(1)）"
```

## 4. KMP 的应用扩展

### 4.1 459. 重复的子字符串（next 应用）

```java
/**
 * LeetCode 459. 重复的子字符串
 * 判断 s 是否可以由子串重复构成
 *
 * 技巧：最小周期 = n - next[n-1]
 *   s 由周期重复构成 ⇔ n % 周期 == 0
 */
public boolean repeatedSubstringPattern(String s) {
    int n = s.length();
    int[] next = buildNext(s);           // 复用 KMP next

    int period = n - next[n - 1];        // 最小周期长度
    return period < n && n % period == 0;
}
// "abab"：next[3]=2 → period = 4-2 = 2 → 4%2==0 → true ✓
// "aba"：next[2]=1 → period = 3-1 = 2 → 3%2≠0 → false ✓
// 原理：最长公共前后缀重叠部分 = n - 周期
```

### 4.2 214. 最短回文串（KMP/哈希）

```java
/**
 * LeetCode 214. 最短回文串
 * 在开头加字符使 s 成为回文，求最短结果
 *
 * 核心：找 s 的"最长回文前缀"
 *   KMP：s + "#" + 反转(s) → next 数组末位
 *     = 最长回文前缀长度
 *   然后补上剩余部分的逆序
 */
public String shortestPalindrome(String s) {
    String rev = new StringBuilder(s).reverse().toString();
    String combined = s + "#" + rev;     // # 防跨越匹配

    int[] next = buildNext(combined);
    int longestPalinPrefix = next[combined.length() - 1];

    return rev.substring(0, s.length() - longestPalinPrefix) + s;
}
// 例："aacecaaa" → 最长回文前缀 "aacecaa"(7)
//   补 rev 剩余 "aa" 的 "aa" → "aa" + s ✓
```

### 4.3 next 数组的通用价值

```
next（前缀函数）是独立工具：
  ① 字符串匹配（28）
  ② 重复周期检测（459）
  ③ 回文前缀（214）
  ④ 快乐前缀（1392）
  ⑤ 模式串前缀统计

面试定位："next 数组 = 前缀函数，
 是 KMP 之外独立可用的工具"
```

## 6. 面试要点与追问

### 6.1 面试话术模板

```
"KMP 预处理模式串的 next 数组（最长公共前后缀），
 匹配失败时主串指针不回溯，模式串跳到
 后缀匹配位置。
 时间复杂度 O(n+m)：主串扫一遍 + 预处理 O(m)。
 next 构建的核心是失配时 while 回退——
 回退后可能再次失配，所以要 while 不是 if。"
```

### 6.2 高频追问 TOP 8

| # | 追问 | 标准回答 |
|:---:|------|------|
| 1 | KMP 为什么 O(n+m)？ | 主串指针不回溯（n 次）；j 回退摊还 O(1) |
| 2 | next 构建难点？ | 失配回退必须 while（可能多次回退） |
| 3 | 为什么主串不回溯？ | 已匹配部分的最长前后缀已提供信息，无需重比 |
| 4 | KMP vs BM？ | KMP 思想标准；BM 工程平均最快（从后往前） |
| 5 | 与滚动哈希选型？ | 单模式 KMP 确定；多模式/查重用哈希 |
| 6 | next 数组还有啥用？ | 重复周期（459）、回文前缀（214） |
| 7 | 最小周期怎么求？ | n - next[n-1]（最长前后缀重叠 = n - 周期） |
| 8 | 工程用 KMP 吗？ | 库实现多用朴素优化/BM；KMP 价值在思想与竞赛 |

### 6.3 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 回退用 if | 死循环/漏匹配 | 用 while |
| 忘处理 m=0 | 越界 | 提前返回 0 |
| next 定义混淆 | 下标错 | 先声明含/不含自身 |
| 拼接忘 # | 跨越匹配误判 | s + "#" + rev |
| 459 忘 period<n | "a" 误判 true | 周期必须 < n |

> 🎯 **核心要点**：KMP = **next 构建 + 匹配**两段循环（都含 while 回退）。识别信号："查找子串位置、重复子字符串、最短回文串"。459 最小周期（n-next[n-1]）与 214 回文拼接是两个高频变体。面试先说"主串不回溯"思想，再手写模板。
