# 1. 哈希表篇

哈希表（HashMap/HashSet）的核心价值在于 **O(1) 的查找/插入/删除**，主要应用场景：

| 场景 | 经典题型 | 思路 |
|------|---------|------|
| 两数之和类 | LC 1, LC 454 | 遍历时查 target - nums[i] 是否存在 |
| 分组统计类 | LC 49, LC 242 | 排序/计数生成唯一 key |
| 连续序列类 | LC 128 | HashSet + 只从连续段的起点数 |
| 前缀和类 | LC 560, LC 525 | sum[i] - sum[j] = k 转 Map 查 |
| 频率统计类 | LC 347, LC 692 | HashMap 统计 + 堆排序 |
| 设计缓存类 | LC 146 | HashMap + 双向链表 |
| 原地哈希类 | LC 41, LC 442 | 数组本身当作哈希表 |

## 1.1 LC 1 两数之和 ★★★

> 一句话核心思路：遍历数组，用 HashMap 记录 `nums[i] -> index`，每步检查 `target - nums[i]` 是否已在 map 中。

### 题目描述

给定一个整数数组 `nums` 和一个整数目标值 `target`，请在该数组中找出 **和为目标值** 的那 **两个** 整数，并返回它们的数组下标。假设每种输入只会对应一个答案，且不能使用同一个元素两次。

### 完整 Java 代码

```java
import java.util.HashMap;
import java.util.Map;

public class LC01TwoSum {
    public int[] twoSum(int[] nums, int target) {
        // key: 元素值, value: 元素下标
        Map<Integer, Integer> map = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            int complement = target - nums[i];
            if (map.containsKey(complement)) {
                // 找到答案立即返回
                return new int[]{map.get(complement), i};
            }
            // 当前元素放入 map，供后续元素查
            map.put(nums[i], i);
        }
        // 题目保证有解，不会走到这里
        return new int[]{-1, -1};
    }
}
```

### 复杂度分析

| 维度 | 值 |
|------|----|
| 时间复杂度 | O(n)，一次遍历 |
| 空间复杂度 | O(n)，哈希表最多存 n 个元素 |

### 面试官追问

**Q：如果数组有序，能否不用额外空间？**  
A：可以。用 **双指针**（左右相向）能在 O(1) 空间 + O(n) 时间解决。但前提是有序，且要返回的是值而非下标。

**Q：如果找三个数之和等于 target 呢？**  
A：转化为两数之和。固定一个数，然后在剩余数组中找 `target - nums[i]` 的两数之和。

> 💡 **易错点**：
> - 必须先查 map 再 put，否则会重复使用当前元素（如 `target=6, nums=[3,3]`）
> - 返回下标顺序可交换，但必须是一先一后
> - 题目保证唯一解，但代码仍要处理无解情况

## 1.2 LC 49 字母异位词分组 ★★☆

> 一句话核心思路：字母异位词排序后相同，用 `排序后的字符串` 作为 key 分组；也可用 `字符计数` 作 key。

### 题目描述

给你一个字符串数组，请你将 **字母异位词** 组合在一起。字母异位词指字母相同但排列不同的字符串。

### 完整 Java 代码

```java
import java.util.*;

public class LC49GroupAnagrams {
    public List<List<String>> groupAnagrams(String[] strs) {
        // 解法一：排序作 key（最简洁，推荐）
        Map<String, List<String>> map = new HashMap<>();
        for (String s : strs) {
            char[] chars = s.toCharArray();
            Arrays.sort(chars);
            String key = new String(chars);          // 排序后作为 key
            map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
        }
        return new ArrayList<>(map.values());
    }
}
```

```java
// 解法二：计数作 key（字符串长度较大时更快）
public class LC49GroupAnagramsCount {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> map = new HashMap<>();
        for (String s : strs) {
            int[] count = new int[26];
            for (char c : s.toCharArray()) {
                count[c - 'a']++;
            }
            // 将计数数组编码为字符串 key: "1#2#0#0#..."
            StringBuilder sb = new StringBuilder();
            for (int c : count) {
                sb.append(c).append('#');
            }
            String key = sb.toString();
            map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
        }
        return new ArrayList<>(map.values());
    }
}
```

### 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 |
|-----|-----------|-----------|
| 排序作 key | O(nk log k) — n 个字符串，平均长度 k | O(nk) |
| 计数作 key | O(nk) — 无需排序 | O(nk) |

> 💡 **易错点**：
> - 排序法 key 用 `new String(chars)` 而非 `chars.toString()`
> - 计数法注意编码必须保证唯一性，分隔符 `#` 不可省略（避免 `[1, 12]` 与 `[11, 2]` 混淆）
> - `computeIfAbsent` 可简化代码，但面试时也可手写 if-else

## 1.3 LC 128 最长连续序列 ★★☆

> 一句话核心思路：全部元素入 HashSet，遍历时 **只从序列的起点开始数**（即 `num - 1` 不在 set 中时才计数），保证 O(n)。

### 题目描述

给定一个未排序的整数数组 `nums`，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。要求时间复杂度 **O(n)**。

### 完整 Java 代码

```java
import java.util.HashSet;
import java.util.Set;

public class LC128LongestConsecutiveSequence {
    public int longestConsecutive(int[] nums) {
        if (nums == null || nums.length == 0) return 0;

        // 1. 全部入 set
        Set<Integer> set = new HashSet<>();
        for (int num : nums) {
            set.add(num);
        }

        int longest = 0;
        for (int num : set) {          // 遍历 set 而非数组，去重
            // 2. 只从连续段的起点开始数
            if (!set.contains(num - 1)) {
                int cur = num;
                int len = 1;
                while (set.contains(cur + 1)) {
                    cur++;
                    len++;
                }
                longest = Math.max(longest, len);
            }
        }
        return longest;
    }
}
```

### 复杂度分析

| 维度 | 值 |
|------|----|
| 时间复杂度 | O(n) — 每个元素最多被访问两次（一次入 set，一次在 while 中作为连续段成员） |
| 空间复杂度 | O(n) — HashSet |

### 面试官追问

**Q：为什么遍历 set 而非 nums？**  
A：去重。重复元素不影响最长连续序列，遍历 set 可避免重复计算。

**Q：为什么只从 `num - 1` 不在 set 中的元素开始？**  
A：保证每个连续段只被统计一次。如果从中间元素开始，while 会重复计数，退化为 O(n^2)。这是该解法的灵魂所在。

> 💡 **易错点**：
> - 一定要先判断 `!set.contains(num - 1)` 再开始 while 循环，否则是 O(n^2)
> - 遍历 set 而非数组，避免重复元素干扰
> - 空数组返回 0，需做空值检查

## 1.4 LC 560 和为 K 的子数组 ★★★

> 一句话核心思路：**前缀和 + HashMap**，`preSum[i] - preSum[j] = k` 转化为在 map 中查找 `preSum - k` 的出现次数。

### 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，请你统计并返回 **和为 k 的子数组个数**。子数组是数组中元素的 **连续** 非空序列。

### 完整 Java 代码

```java
import java.util.HashMap;
import java.util.Map;

public class LC560SubarraySumEqualsK {
    public int subarraySum(int[] nums, int k) {
        // key: 前缀和, value: 出现次数
        Map<Integer, Integer> preSumMap = new HashMap<>();
        preSumMap.put(0, 1);    // 前缀和为 0 出现 1 次（空数组）

        int preSum = 0;
        int count = 0;
        for (int num : nums) {
            preSum += num;                      // 当前前缀和
            // preSum - preSum[j] = k  =>  preSum[j] = preSum - k
            if (preSumMap.containsKey(preSum - k)) {
                count += preSumMap.get(preSum - k);
            }
            // 将当前前缀和放入 map
            preSumMap.put(preSum,
                    preSumMap.getOrDefault(preSum, 0) + 1);
        }
        return count;
    }
}
```

### 复杂度分析

| 维度 | 值 |
|------|----|
| 时间复杂度 | O(n) — 一次遍历 |
| 空间复杂度 | O(n) — 前缀和 map 最多 n + 1 个 key |

### 面试官追问

**Q：为什么 map 要初始化 `(0, 1)`？**  
A：当某个子数组从下标 0 开始、前缀和正好等于 k 时，`preSum - k = 0`，需要从 map 中得到 1，代表空数组的基准前缀和。

**Q：如果数组中有负数，解法是否依然成立？**  
A：完全成立。前缀和可能递减，但 HashMap 只管记录每个前缀和出现过的次数，正负数不影响。

**Q：能否用滑动窗口？**  
A：不能。滑动窗口适用于 **单调性**（数组全正或全负），有负数时窗口不具有单调性，必须用前缀和。

> 💡 **易错点**：
> - 一定要先查 map 再 put 当前前缀和，否则可能把当前前缀和也算进去造成误差
> - 初始化 `(0, 1)` 容易忘记，这是 bug 高发点
> - 返回的是 **个数** 而非下标，注意审题

## 1.5 LC 347 前 K 个高频元素 ★★☆

> 一句话核心思路：HashMap 统计频率，**小顶堆**（PriorityQueue）维护 Top-K，O(n log k)。

### 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，请你返回其中出现频率前 `k` 高的元素。可以按 **任意顺序** 返回答案。

### 完整 Java 代码

```java
import java.util.*;

public class LC347TopKFrequentElements {
    public int[] topKFrequent(int[] nums, int k) {
        // 1. 统计频率
        Map<Integer, Integer> freqMap = new HashMap<>();
        for (int num : nums) {
            freqMap.put(num, freqMap.getOrDefault(num, 0) + 1);
        }

        // 2. 小顶堆，按频率排序（频率低的在堆顶）
        PriorityQueue<Integer> minHeap = new PriorityQueue<>(
                (a, b) -> freqMap.get(a) - freqMap.get(b)
        );
        for (int num : freqMap.keySet()) {
            minHeap.offer(num);
            if (minHeap.size() > k) {
                minHeap.poll();     // 移除频率最低的
            }
        }

        // 3. 堆中剩余的就是 Top-K
        int[] result = new int[k];
        for (int i = 0; i < k; i++) {
            result[i] = minHeap.poll();
        }
        return result;
    }
}
```

```java
// 进阶解法：基于快速排序的 quick select，平均 O(n)
public class LC347QuickSelect {
    public int[] topKFrequent(int[] nums, int k) {
        Map<Integer, Integer> freq = new HashMap<>();
        for (int n : nums) freq.put(n, freq.getOrDefault(n, 0) + 1);

        int[] unique = freq.keySet().stream().mapToInt(Integer::intValue).toArray();
        int n = unique.length;

        // 快速选择：找第 n-k 小的元素（即第 k 大的频率）
        quickSelect(unique, freq, 0, n - 1, n - k);
        return Arrays.copyOfRange(unique, n - k, n);
    }

    private void quickSelect(int[] arr, Map<Integer, Integer> freq,
                             int left, int right, int kSmallest) {
        if (left >= right) return;
        int pivot = partition(arr, freq, left, right);
        if (kSmallest == pivot) return;
        else if (kSmallest < pivot) quickSelect(arr, freq, left, pivot - 1, kSmallest);
        else quickSelect(arr, freq, pivot + 1, right, kSmallest);
    }

    private int partition(int[] arr, Map<Integer, Integer> freq, int left, int right) {
        int pivotFreq = freq.get(arr[right]);
        int i = left;
        for (int j = left; j < right; j++) {
            if (freq.get(arr[j]) <= pivotFreq) {
                swap(arr, i, j);
                i++;
            }
        }
        swap(arr, i, right);
        return i;
    }

    private void swap(int[] arr, int i, int j) {
        int tmp = arr[i]; arr[i] = arr[j]; arr[j] = tmp;
    }
}
```

### 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 |
|-----|-----------|-----------|
| 小顶堆 | O(n log k) | O(n) |
| Quick Select | O(n) 平均 / O(n^2) 最坏 | O(n) |

> 💡 **易错点**：
> - 小顶堆的比较器是 `(a, b) -> freqMap.get(a) - freqMap.get(b)`，频率低的在堆顶
> - 堆中只保留 k 个元素，超过就 poll
> - Quick Select 复杂度是平均 O(n)，但最坏 O(n^2)，面试时先说堆解更稳妥

## 1.6 LC 146 LRU 缓存 ★★★

> 一句话核心思路：**HashMap + 双向链表**，HashMap 提供 O(1) 查找，双向链表维护访问顺序（最近使用放头部）。LinkedHashMap 是现成实现，但面试建议手写确保通过。

### 题目描述

设计一个 LRU（最近最少使用）缓存机制。实现 `LRUCache` 类：
- `get(key)` — 获取 key 的值，不存在返回 -1
- `put(key, value)` — 插入或更新，如果容量满则删除最久未使用的元素
要求 **get 和 put 的时间复杂度均为 O(1)**。

### 完整 Java 代码

```java
import java.util.HashMap;
import java.util.Map;

public class LRUCache {
    // 双向链表节点
    private static class Node {
        int key, value;
        Node prev, next;
        Node(int key, int value) {
            this.key = key;
            this.value = value;
        }
    }

    private final int capacity;
    private final Map<Integer, Node> map;
    private final Node head;      // 虚拟头节点（右侧是最近使用的）
    private final Node tail;      // 虚拟尾节点（左侧是最久未使用的）

    public LRUCache(int capacity) {
        this.capacity = capacity;
        this.map = new HashMap<>();
        this.head = new Node(-1, -1);
        this.tail = new Node(-1, -1);
        head.next = tail;
        tail.prev = head;
    }

    public int get(int key) {
        Node node = map.get(key);
        if (node == null) return -1;
        // 移到头部（表示最近使用过）
        moveToHead(node);
        return node.value;
    }

    public void put(int key, int value) {
        Node node = map.get(key);
        if (node != null) {
            // key 已存在：更新值，移到头部
            node.value = value;
            moveToHead(node);
        } else {
            // key 不存在：创建新节点
            Node newNode = new Node(key, value);
            map.put(key, newNode);
            addToHead(newNode);
            // 超出容量，删除尾部节点（最久未使用）
            if (map.size() > capacity) {
                Node removed = removeTail();
                map.remove(removed.key);
            }
        }
    }

    // ---- 双向链表操作（封装为 private 方法） ----

    private void addToHead(Node node) {
        node.next = head.next;
        node.prev = head;
        head.next.prev = node;
        head.next = node;
    }

    private void removeNode(Node node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }

    private void moveToHead(Node node) {
        removeNode(node);
        addToHead(node);
    }

    private Node removeTail() {
        Node node = tail.prev;
        removeNode(node);
        return node;
    }
}
```

```java
// ---------- 基于 LinkedHashMap 的精简实现 ----------
import java.util.LinkedHashMap;
import java.util.Map;

public class LRUCacheLinkedHashMap extends LinkedHashMap<Integer, Integer> {
    private final int capacity;

    public LRUCacheLinkedHashMap(int capacity) {
        // accessOrder = true 表示按访问顺序排序
        super(capacity, 0.75f, true);
        this.capacity = capacity;
    }

    public int get(int key) {
        return super.getOrDefault(key, -1);
    }

    public void put(int key, int value) {
        super.put(key, value);
    }

    @Override
    protected boolean removeEldestEntry(Map.Entry<Integer, Integer> eldest) {
        return size() > capacity;
    }
}
```

### 复杂度分析

| 维度 | 值 |
|------|----|
| 时间复杂度 | O(1) — get 和 put 均 O(1) |
| 空间复杂度 | O(capacity) — 缓存容量 |

### 面试官追问

**Q：为什么用双向链表而非单向？**  
A：删除节点时需要知道它的前驱节点。单向链表删除需要 O(n) 遍历找前驱，双向链表 O(1)。

**Q：虚拟头尾节点的作用？**  
A：消除边界条件的 if-else 判断。头尾指针永远指向虚拟节点，不用处理 null 情况。

**Q：LinkedHashMap 的实现原理？**  
A：继承自 HashMap，内部维护一个双向链表，`accessOrder=true` 时每次 get/put 访问的节点被移到链表尾部（或头部，取决于实现定义）。

> ⚠️ **易错点**：
> - 更新已存在 key 时，也要 `moveToHead`
> - 删除尾部节点后，要从 map 中 remove，只删链表节点会内存泄漏
> - 双向链表的指针操作顺序不能乱，建议用独立方法封装

## 1.7 LC 41 缺失的第一个正数 ★★☆

> 一句话核心思路：**原地哈希** —— 将数组本身当作哈希表，把 `x` 放到下标 `x-1` 位置，再遍历找第一个 `nums[i] != i+1` 的下标。

### 题目描述

给你一个未排序的整数数组 `nums`，请你找出其中没有出现的 **最小的正整数**。要求时间复杂度 O(n) 且 **空间复杂度 O(1)**。

### 完整 Java 代码

```java
public class LC41FirstMissingPositive {
    public int firstMissingPositive(int[] nums) {
        int n = nums.length;

        // 1. 原地交换：将 x 放到下标 x-1 处
        for (int i = 0; i < n; i++) {
            // 只处理 1 ~ n 范围内的数，且目标位置不是正确值时才交换
            while (nums[i] >= 1 && nums[i] <= n && nums[nums[i] - 1] != nums[i]) {
                swap(nums, i, nums[i] - 1);
            }
        }

        // 2. 遍历找第一个缺失的正数
        for (int i = 0; i < n; i++) {
            if (nums[i] != i + 1) {
                return i + 1;
            }
        }

        // 3. 如果 1~n 都在，返回 n+1
        return n + 1;
    }

    private void swap(int[] nums, int i, int j) {
        int tmp = nums[i];
        nums[i] = nums[j];
        nums[j] = tmp;
    }
}
```

### 复杂度分析

| 维度 | 值 |
|------|----|
| 时间复杂度 | O(n) — 每个元素最多被交换两次 |
| 空间复杂度 | O(1) — 原地交换 |

### 面试官追问

**Q：为什么用 `while` 而非 `if`？**  
A：交换后当前位置来了一个新数，这个新数也可能需要归位，所以要持续 while 直到当前下标归位或无需处理。

**Q：为什么只处理 `1 ~ n` 范围的数？**  
A：最小正整数的答案范围是 `[1, n+1]`，超出范围的数不可能是答案，且也没有对应的下标放置。

> ⚠️ **易错点**：
> - while 条件中 `nums[nums[i] - 1] != nums[i]` 用来判断目标位置是否已放对，避免死循环（如 `[1, 1]`）
> - 边界情况：空数组返回 1，`[1]` 返回 2
> - 交换时数组下标边界检查：`nums[i] - 1` 必须在 `[0, n-1]` 范围内

# 2. 双指针篇

双指针的核心思想是 **利用两个指针协同遍历，减少循环层数**。常见模式：

| 模式 | 说明 | 经典题 |
|------|------|-------|

## 2.1 LC 283 移动零 ★★★

> 一句话核心思路：**快慢指针（同向）**，慢指针指向待填位置，快指针找非零元素，将非零元素依次填入，最后末尾补零。

### 题目描述

给定一个数组 `nums`，编写一个函数将所有 `0` 移动到数组的末尾，同时保持非零元素的相对顺序。要求 **原地操作**。

### 完整 Java 代码

```java
public class LC283MoveZeroes {
    public void moveZeroes(int[] nums) {
        // 快慢指针模板
        int slow = 0;     // 指向下一个非零元素应该放的位置
        for (int fast = 0; fast < nums.length; fast++) {
            if (nums[fast] != 0) {
                // 将非零元素交换到 slow 位置
                swap(nums, slow, fast);
                slow++;
            }
        }
        // 此时 [0, slow) 是非零元素，且保持原顺序
        // [slow, end) 自然全是零
    }

    private void swap(int[] nums, int i, int j) {
        int tmp = nums[i];
        nums[i] = nums[j];
        nums[j] = tmp;
    }
}
```

```java
// 优化版：减少不必要的交换
public class LC283MoveZeroesOptimized {
    public void moveZeroes(int[] nums) {
        int slow = 0;
        for (int fast = 0; fast < nums.length; fast++) {
            if (nums[fast] != 0) {
                if (fast != slow) {   // 仅在需要时交换
                    nums[slow] = nums[fast];
                    nums[fast] = 0;
                }
                slow++;
            }
        }
    }
}
```

### 复杂度分析

| 维度 | 值 |
|------|----|
| 时间复杂度 | O(n) — 一次遍历 |
| 空间复杂度 | O(1) — 原地操作 |

> 💡 **易错点**：
> - 慢指针始终指向第一个零的位置（或数组尾部），理解 `slow` 的语义是关键
> - 交换时非零元素的相对顺序保持 —— 由于 fast 始终在 slow 前面或相等，交换可保证顺序不变
> - 如果要求末尾补的是其他值（如 `#`），只需改判断条件

## 2.2 LC 11 盛最多水的容器 ★★☆

> 一句话核心思路：**左右相向指针**，面积 = `min(height[l], height[r]) * (r - l)`，**谁短移动谁**，因为移动短板面积可能变大，移动长板面积一定不会变大。

### 题目描述

给定一个长度为 `n` 的整数数组 `height`。找出其中的两条线，使得它们与 x 轴共同构成的容器可以容纳最多的水。返回最大水量。

### 完整 Java 代码

```java
public class LC11ContainerWithMostWater {
    public int maxArea(int[] height) {
        int left = 0, right = height.length - 1;
        int max = 0;

        while (left < right) {
            // 当前面积 = 短板高度 * 宽度
            int area = Math.min(height[left], height[right]) * (right - left);
            max = Math.max(max, area);

            // 移动较短的那一端（核心逻辑）
            if (height[left] < height[right]) {
                left++;
            } else {
                right--;
            }
        }
        return max;
    }
}
```

### 复杂度分析

| 维度 | 值 |
|------|----|
| 时间复杂度 | O(n) — 左右指针各遍历一次 |
| 空间复杂度 | O(1) |

### 面试官追问

**Q：为什么移动短板而非长板？**  
A：面积取决于短板高度和宽度。如果移动长板，下个面积的新短板 ≤ 原短板，宽度也减小，面积必然 ≤ 当前面积。移动短板虽然宽度减小，但高度可能变大，面积有可能增大。

**Q：如果 height[left] == height[right]，移动哪边？**  
A：都可以。两边都移动本质上等价，因为移动任一边，宽度都减 1，而新高度 ≤ 原高度。

> 💡 **易错点**：
> - 不要忘记 `Math.min(height[l], height[r])` —— 面积由 **短板** 决定
> - 指针移动条件写清楚，避免死循环

## 2.3 LC 15 三数之和 ★★★

> 一句话核心思路：排序 + **固定一个数** + **双指针**（左右相向）找两数之和 = `-nums[i]`，注意 **去重** 细节。

### 题目描述

给你一个整数数组 `nums`，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j != k` 且 `nums[i] + nums[j] + nums[k] = 0`。返回所有和为 0 且不重复的三元组。

### 完整 Java 代码

```java
import java.util.*;

public class LC15ThreeSum {
    public List<List<Integer>> threeSum(int[] nums) {
        List<List<Integer>> result = new ArrayList<>();
        if (nums == null || nums.length < 3) return result;

        Arrays.sort(nums);   // 排序是双指针的前提

        for (int i = 0; i < nums.length - 2; i++) {
            // 去重：跳过重复的固定元素
            if (i > 0 && nums[i] == nums[i - 1]) continue;

            // 剪枝：最小和 > 0 则后续不可能有解
            if (nums[i] + nums[i + 1] + nums[i + 2] > 0) break;
            // 剪枝：最大和 < 0 则跳过当前固定值
            if (nums[i] + nums[nums.length - 2] + nums[nums.length - 1] < 0) continue;

            int left = i + 1, right = nums.length - 1;
            int target = -nums[i];

            while (left < right) {
                int sum = nums[left] + nums[right];
                if (sum == target) {
                    result.add(Arrays.asList(nums[i], nums[left], nums[right]));

                    // 去重：跳过重复的 left 和 right
                    while (left < right && nums[left] == nums[left + 1]) left++;
                    while (left < right && nums[right] == nums[right - 1]) right--;

                    left++;
                    right--;
                } else if (sum < target) {
                    left++;
                } else {
                    right--;
                }
            }
        }
        return result;
    }
}
```

### 复杂度分析

| 维度 | 值 |
|------|----|
| 时间复杂度 | O(n^2) — 排序 O(n log n) + 双指针 O(n^2) |
| 空间复杂度 | O(1)（不计输出空间） |

### 面试官追问

**Q：去重为什么用 `nums[i] == nums[i - 1]` 而非 `nums[i] == nums[i + 1]`？**  
A：用 `i + 1` 会错误地跳过合法解（如 `[-1, -1, 2]` 是合法三元组，但 i=0 时 `nums[0] == nums[1]` 会跳过 -1）。`i - 1` 确保了只跳过之前已处理过的相同值。

**Q：能否用 HashSet 替代双指针？**  
A：可以，但去重更麻烦，且空间复杂度 O(n)。双指针是本题最优解。

> ⚠️ **易错点**：
> - 必须先排序
> - 三处去重：固定元素去重、left 去重、right 去重。漏一个就会出重复解
> - left 和 right 的去重要在找到一个解之后进行，而非 while 循环一开始
> - 注意整型溢出（虽然本题数值不大）

## 2.4 LC 42 接雨水 ★★☆

> 一句话核心思路：**双指针**解法——维护左右两侧的最高挡板，**谁低移动谁**，当前位置能接的雨水 = `min(leftMax, rightMax) - height[i]`。

### 题目描述

给定 `n` 个非负整数表示每个宽度为 1 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

### 完整 Java 代码

```java
// 解法一：双指针（最优，O(n) 时间 + O(1) 空间）
public class LC42TrappingRainWaterTwoPointer {
    public int trap(int[] height) {
        if (height == null || height.length < 3) return 0;

        int left = 0, right = height.length - 1;
        int leftMax = 0, rightMax = 0;
        int water = 0;

        while (left < right) {
            // 更新左右两侧最大高度
            leftMax = Math.max(leftMax, height[left]);
            rightMax = Math.max(rightMax, height[right]);

            if (height[left] < height[right]) {
                // 左边是短板，计算 left 位置的积水量
                water += leftMax - height[left];
                left++;
            } else {
                // 右边是短板，计算 right 位置的积水量
                water += rightMax - height[right];
                right--;
            }
        }
        return water;
    }
}
```

```java
// 解法二：单调栈（思路参考，详见 03 文件）
import java.util.ArrayDeque;
import java.util.Deque;

public class LC42TrappingRainWaterStack {
    public int trap(int[] height) {
        Deque<Integer> stack = new ArrayDeque<>();  // 存下标，栈底到栈顶递减
        int water = 0;
        for (int i = 0; i < height.length; i++) {
            // 当前高度 > 栈顶高度，说明形成凹槽
            while (!stack.isEmpty() && height[i] > height[stack.peek()]) {
                int bottom = stack.pop();          // 凹槽底部
                if (stack.isEmpty()) break;        // 左侧无挡板
                int left = stack.peek();
                int w = i - left - 1;              // 宽度
                int h = Math.min(height[left], height[i]) - height[bottom]; // 高度
                water += w * h;
            }
            stack.push(i);
        }
        return water;
    }
}
```

### 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 |
|-----|-----------|-----------|
| 双指针 | O(n) | O(1) |
| 单调栈 | O(n) | O(n) |

### 面试官追问

**Q：双指针解法中，为什么 `height[left] < height[right]` 时左侧一定可以接到水？**  
A：此时 `leftMax < rightMax`，left 位置的雨水量由 leftMax 决定（因为 right 方向有更高的挡板）。`leftMax - height[left]` 即当前列能接的雨水。

**Q：单调栈解法的思路？**  
A：维护一个递减栈。当遇到比栈顶高的柱子时，弹出栈顶作为凹槽底部，当前栈顶（弹出后的新栈顶）作为左挡板，当前柱子作为右挡板，计算这一层的积水。

> ⚠️ **易错点**：
> - 双指针：一定要先更新 leftMax/rightMax，再计算水量
> - 单调栈：栈中存的是 **下标**，通过下标取高度、算宽度
> - 柱状图至少需要 3 根柱子才可能接水，做边界检查

## 2.5 LC 26/80 删除有序数组重复项 ★★☆

> 一句话核心思路：**快慢指针通用模板** —— slow 指向下一个可填位置，fast 遍历数组，满足条件时填入 slow 位置。

### 题目描述

**LC 26**：删除有序数组中的重复项，每个元素只保留一次，返回新长度。  
**LC 80**：删除有序数组中的重复项 II，每个元素最多保留两次，返回新长度。

### 完整 Java 代码

```java
public class LC26RemoveDuplicates {
    // LC 26: 每个元素最多出现一次
    public int removeDuplicates(int[] nums) {
        if (nums.length == 0) return 0;
        int slow = 1;  // 下一个可填位置
        for (int fast = 1; fast < nums.length; fast++) {
            if (nums[fast] != nums[slow - 1]) {
                nums[slow++] = nums[fast];
            }
        }
        return slow;
    }
}
```

```java
public class LC80RemoveDuplicatesII {
    // LC 80: 每个元素最多出现两次
    public int removeDuplicates(int[] nums) {
        if (nums.length <= 2) return nums.length;
        int slow = 2;  // 前两个元素一定保留
        for (int fast = 2; fast < nums.length; fast++) {
            // 与 slow-2 位置比较，保证最多两个相同
            if (nums[fast] != nums[slow - 2]) {
                nums[slow++] = nums[fast];
            }
        }
        return slow;
    }
}
```

### 复杂度分析

| 维度 | 值 |
|------|----|
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |

### 面试官追问

**Q：为什么 LC 80 中比较的是 `nums[fast] != nums[slow - 2]`？**  
A：`slow - 2` 是已保留部分的倒数第二个位置。如果当前元素与它相同，说明保留部分中已有两个该值，当前元素必须跳过。

**Q：如果要求每个元素最多保留 k 次，通用模板怎么写？**  
A：`slow = k`，比较 `nums[fast] != nums[slow - k]`。这是一个高度通用的模板。

> 💡 **易错点**：
> - 理解 `slow` 的语义：指向下一个可填位置，同时也是新数组的长度
> - LC 26 中从 slow=1, fast=1 开始（默认第一个元素保留）
> - `nums[slow - 1]` 是已保留的最后一个元素

## 2.6 LC 75 颜色分类（荷兰国旗） ★★☆

> 一句话核心思路：**三指针（荷兰国旗问题）**—— `left` 指向 0 的右边界，`right` 指向 2 的左边界，`current` 遍历数组，遇 0 与 left 交换，遇 2 与 right 交换。

### 题目描述

给定一个包含红色、白色和蓝色（分别用 0、1、2 表示）的数组，对它们进行排序，使得相同颜色的元素相邻。要求 **原地排序，O(n) 时间，常数空间**。

### 完整 Java 代码

```java
public class LC75SortColors {
    public void sortColors(int[] nums) {
        int left = 0;           // 0 的右边界（下一个 0 放的位置）
        int right = nums.length - 1;  // 2 的左边界（下一个 2 放的位置）
        int cur = 0;            // 当前遍历指针

        while (cur <= right) {
            if (nums[cur] == 0) {
                // 遇到 0，交换到左侧
                swap(nums, left, cur);
                left++;
                cur++;          // 换过来的 left 位置肯定是 0 或 1，可以前进
            } else if (nums[cur] == 2) {
                // 遇到 2，交换到右侧
                swap(nums, right, cur);
                right--;        // right 减一，但 cur 不前进（因为换过来的是未处理的数）
            } else {
                // 遇到 1，直接跳过
                cur++;
            }
        }
    }

    private void swap(int[] nums, int i, int j) {
        int tmp = nums[i];
        nums[i] = nums[j];
        nums[j] = tmp;
    }
}
```

### 复杂度分析

| 维度 | 值 |
|------|----|
| 时间复杂度 | O(n) — 一次遍历 |
| 空间复杂度 | O(1) — 原地排序 |

### 面试官追问

**Q：为什么遇到 2 时 cur 不前进？**  
A：从 right 交换过来的数可能是 0、1 或 2，需要在当前位置重新判断，所以 cur 不能前进。

**Q：为什么遇到 0 时 cur 可以前进？**  
A：left 位置的数在之前已经被处理过，一定是 0 或 1（不可能是 2，因为 2 已经被交换到右侧了），所以换过来的数不需要重新判断。

> ⚠️ **易错点**：
> - while 条件是 `cur <= right` 而非 `cur < nums.length`，因为 `right` 在缩减
> - 遇到 2 时 `cur` 不前进是最容易写错的地方
> - 先处理 0 和 2，1 自然归位

## 2.7 LC 88 合并两个有序数组 ★☆☆

> 一句话核心思路：**从后往前 merge**—— 从两个数组的末尾开始比较，将较大的数放在 `nums1` 的末尾，避免覆盖未处理的元素。

### 题目描述

给你两个按 **非递减顺序** 排列的整数数组 `nums1` 和 `nums2`，以及 `m` 和 `n` 分别表示两个数组中有效元素的个数。将 `nums2` 合并到 `nums1` 中（`nums1` 的长度为 `m + n`，后 n 个位置为 0）。

### 完整 Java 代码

```java
public class LC88MergeSortedArray {
    public void merge(int[] nums1, int m, int[] nums2, int n) {
        int p1 = m - 1;      // nums1 有效元素的末尾
        int p2 = n - 1;      // nums2 的末尾
        int p = m + n - 1;   // 合并后的末尾

        // 从后往前遍历
        while (p2 >= 0) {    // 只需处理 nums2 的元素，nums1 的元素已就位
            if (p1 >= 0 && nums1[p1] > nums2[p2]) {
                nums1[p--] = nums1[p1--];
            } else {
                nums1[p--] = nums2[p2--];
            }
        }
    }
}
```

### 复杂度分析

| 维度 | 值 |
|------|----|
| 时间复杂度 | O(m + n) |
| 空间复杂度 | O(1) — 原地修改 |

### 面试官追问

**Q：为什么从后往前而不是从前往后？**  
A：从前往后 merge 时，nums1 中的小元素会被覆盖，需要额外空间保存。从后往前则不会覆盖未处理的元素。

**Q：while 条件为什么是 `p2 >= 0` 而非 `p1 >= 0 || p2 >= 0`？**  
A：当 p2 < 0 时，nums2 的所有元素已处理完毕，nums1 剩余元素自然有序，无需继续。

> 💡 **易错点**：
> - 从后往前遍历是核心技巧，要记住
> - while 条件可以是 `p2 >= 0`（p1 上的元素已在正确位置）
> - 不需要 `if (p1 >= 0)` 的 else 分支，因为 `p2 >= 0` 保证每次循环至少处理一个 p2 的元素

## 2.8 LC 160 相交链表 ★★☆

> 一句话核心思路：**双指针消除长度差** —— pA 走完 A 后走 B，pB 走完 B 后走 A，相遇点即为交点（或在 null 处相遇）。

### 题目描述

给你两个单链表的头节点 `headA` 和 `headB`，请你找出并返回两个单链表相交的起始节点。如果两个链表没有交点，返回 `null`。

### 完整 Java 代码

```java
public class LC160IntersectionOfTwoLinkedLists {
    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        if (headA == null || headB == null) return null;

        ListNode pA = headA;
        ListNode pB = headB;

        // pA 和 pB 各走 headA + headB 的路程
        // 如果有交点，会在交点相遇；如果无交点，会在 null 相遇
        while (pA != pB) {
            pA = (pA == null) ? headB : pA.next;
            pB = (pB == null) ? headA : pB.next;
        }
        return pA;  // 可能为 null（无交点）
    }
}

class ListNode {
    int val;
    ListNode next;
    ListNode(int x) {
        val = x;
        next = null;
    }
}
```

### 复杂度分析

| 维度 | 值 |
|------|----|
| 时间复杂度 | O(m + n) — 最多遍历两个链表长度之和 |
| 空间复杂度 | O(1) |

### 面试官追问

**Q：为什么这样走一定能相遇？**  
A：pA 和 pB 都走了 m + n 步（m, n 为两链表长度）。从速度上看，如果两链表相交，在进入交点之后 pA 和 pB 路程相同，一定会相遇。如果没有交点，它们会在 `null` 处相遇。

**Q：如果链表有环呢？**  
A：需要更复杂的判断，见 LC 141/142（环形链表），用快慢指针而非本方法。

> 💡 **易错点**：
> - pA 走完后指向 `headB` 而不是 `headB.next`（走完整的 A 链表 + B 链表）
> - 注意 null 情况的处理，防止 NullPointerException
> - 不要陷入死循环：如果没有交点，最终 pA 和 pB 会同时为 null

# 3. 滑动窗口篇（Bonus）

滑动窗口是 **双指针的特殊形式**，两个指针同向移动，维护一个窗口。核心模板：

```java
// 滑动窗口通用模板
int left = 0;
for (int right = 0; right < n; right++) {
    // 扩大窗口：加入 nums[right]
    while (窗口需要收缩) {
        // 缩小窗口：移除 nums[left]
        left++;
    }
```

## 3.1 LC 3 无重复字符的最长子串 ★★★

> 一句话核心思路：**滑动窗口 + HashSet/HashMap**，right 扩展窗口，遇到重复字符时 left 收缩到不重复位置，记录最大窗口长度。

### 完整 Java 代码

```java
import java.util.HashSet;
import java.util.Set;

public class LC03LongestSubstringWithoutRepeatingCharacters {
    public int lengthOfLongestSubstring(String s) {
        Set<Character> set = new HashSet<>();
        int left = 0, maxLen = 0;

        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);
            // 如果重复，收缩左边界直到不重复
            while (set.contains(c)) {
                set.remove(s.charAt(left));
                left++;
            }
            set.add(c);
            maxLen = Math.max(maxLen, right - left + 1);
        }
        return maxLen;
    }
}
```

### 复杂度分析

| 维度 | 值 |
|------|----|
| 时间复杂度 | O(n) — 每个字符最多进出窗口一次 |
| 空间复杂度 | O(\|Σ\|) — 字符集大小（ASCII 128 / Unicode） |

> 💡 **易错点**：
> - while 循环移除左侧字符直至当前字符不重复
> - 用 HashMap 记录字符最后出现位置可优化 left 跳跃式收缩
> - 空字符串返回 0

## 3.2 LC 438 找到所有字母异位词 ★★☆

> 一句话核心思路：**固定长度滑动窗口 + 字符计数**，维护窗口内字符计数与 p 的计数匹配。

### 完整 Java 代码

```java
import java.util.ArrayList;
import java.util.List;

public class LC438FindAllAnagrams {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> result = new ArrayList<>();
        if (s.length() < p.length()) return result;

        int[] pCount = new int[26];
        int[] window = new int[26];

        for (char c : p.toCharArray()) pCount[c - 'a']++;

        for (int i = 0; i < s.length(); i++) {
            window[s.charAt(i) - 'a']++;               // 加入窗口
            if (i >= p.length()) {
                window[s.charAt(i - p.length()) - 'a']--;  // 移出窗口
            }
            // 判断窗口是否匹配
            if (matches(pCount, window)) {
                result.add(i - p.length() + 1);
            }
        }
        return result;
    }

    private boolean matches(int[] a, int[] b) {
        for (int i = 0; i < 26; i++) {
            if (a[i] != b[i]) return false;
        }
        return true;
    }
}
```

### 复杂度分析

| 维度 | 值 |
|------|----|
| 时间复杂度 | O(n) — 一次遍历，每次 26 次比较 |
| 空间复杂度 | O(1) — 固定大小的计数数组 |

> 💡 **易错点**：
> - 固定窗口大小 = p.length()
> - 先加再减，注意窗口未满时不移出
> - 匹配判断可以用 diff 变量优化到 O(1)

## 3.3 LC 76 最小覆盖子串 ★★☆

> 一句话核心思路：**滑动窗口模板题**—— 先扩展 right 直到窗口覆盖 t 中所有字符，再收缩 left 寻找最小长度。

### 完整 Java 代码

```java
import java.util.HashMap;
import java.util.Map;

public class LC76MinimumWindowSubstring {
    public String minWindow(String s, String t) {
        if (s.length() < t.length()) return "";

        Map<Character, Integer> need = new HashMap<>();
        Map<Character, Integer> window = new HashMap<>();
        for (char c : t.toCharArray()) {
            need.put(c, need.getOrDefault(c, 0) + 1);
        }

        int left = 0, right = 0;
        int valid = 0;          // 已满足 need 条件的字符个数
        int start = 0, minLen = Integer.MAX_VALUE;

        while (right < s.length()) {
            char c = s.charAt(right);
            right++;
            // 扩大窗口
            if (need.containsKey(c)) {
                window.put(c, window.getOrDefault(c, 0) + 1);
                if (window.get(c).equals(need.get(c))) {
                    valid++;
                }
            }

            // 窗口满足条件，尝试收缩
            while (valid == need.size()) {
                // 更新最小子串
                if (right - left < minLen) {
                    start = left;
                    minLen = right - left;
                }
                char d = s.charAt(left);
                left++;
                // 缩小窗口
                if (need.containsKey(d)) {
                    if (window.get(d).equals(need.get(d))) {
                        valid--;
                    }
                    window.put(d, window.get(d) - 1);
                }
            }
        }
        return minLen == Integer.MAX_VALUE ? "" : s.substring(start, start + minLen);
    }
}
```

### 复杂度分析

| 维度 | 值 |
|------|----|
| 时间复杂度 | O(n) — s 和 t 各遍历一次 |
| 空间复杂度 | O(\|Σ\|) — 字符集大小 |

### 面试官追问

**Q：为什么用 `valid` 变量而非每次都比较两个 map？**  
A：valid 记录已达到 need 次数的字符种数，当 `valid == need.size()` 时表示窗口覆盖了所有字符。避免每次 O(|Σ|) 的比较。

> ⚠️ **易错点**：
> - `Integer.equals()` 而非 `==`（Integer 缓存范围 -128~127 之外对象地址不同）
> - 更新最小子串的时机在收缩窗口的 while 循环内
> - 返回空串而非 null
