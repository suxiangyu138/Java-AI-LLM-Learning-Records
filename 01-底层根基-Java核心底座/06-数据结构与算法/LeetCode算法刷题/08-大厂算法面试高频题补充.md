### 2.1 LC 25 K 个一组翻转链表 ★★★

> 字节跳动最爱链表题，没有之一。面试中要求 20 分钟内写出 bug-free 代码。

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode reverseKGroup(ListNode head, int k) {
        // 1. 创建 dummy 节点
        ListNode dummy = new ListNode(0);
        dummy.next = head;
        ListNode prev = dummy;
        ListNode end = dummy;

        while (end.next != null) {
            // 2. 找到需要翻转的 k 个节点的尾部
            for (int i = 0; i < k && end != null; i++) {
                end = end.next;
            }
            if (end == null) break;

            // 3. 记录翻转区间的起点和下一段的起点
            ListNode start = prev.next;
            ListNode next = end.next;

            // 4. 断开待翻转部分与后续的连接
            end.next = null;

            // 5. 翻转 [start, end] 区间
            prev.next = reverse(start);

            // 6. 翻转后 start 变成了尾部，将其与下一段连接
            start.next = next;

            // 7. 移动 prev 和 end 到下一段
            prev = start;
            end = prev;
        }
        return dummy.next;
    }

    private ListNode reverse(ListNode head) {
        ListNode prev = null;
        ListNode curr = head;
        while (curr != null) {
            ListNode next = curr.next;
            curr.next = prev;
            prev = curr;
            curr = next;
        }
        return prev;
    }
}
```

| 维度 | 数据 |
|------|------|
| 时间复杂度 | O(n)，每个节点被常数次操作 |
| 空间复杂度 | O(1)，原地翻转 |
| 公司标签 | 字节跳动、腾讯、阿里 |
| 面试官追问 | 如果 k=1 或 k=链表长度怎么处理？能否递归实现？递归的空间复杂度是多少？ |

### 2.2 LC 42 接雨水 ★★★

> 字节必考经典题，双指针解法需要理解透彻。

```java
class Solution {
    public int trap(int[] height) {
        if (height == null || height.length < 3) return 0;

        int left = 0, right = height.length - 1;
        int leftMax = 0, rightMax = 0;
        int ans = 0;

        while (left < right) {
            // 哪边柱子低，哪边先移动——因为接水量由较低一侧决定
            if (height[left] < height[right]) {
                if (height[left] >= leftMax) {
                    leftMax = height[left];
                } else {
                    ans += leftMax - height[left];
                }
                left++;
            } else {
                if (height[right] >= rightMax) {
                    rightMax = height[right];
                } else {
                    ans += rightMax - height[right];
                }
                right--;
            }
        }
        return ans;
    }
}
```

| 维度 | 数据 |
|------|------|
| 时间复杂度 | O(n)，单次遍历 |
| 空间复杂度 | O(1)，常数空间 |
| 公司标签 | 字节跳动、阿里、腾讯、美团 |
| 面试官追问 | 如果输入是环形数组怎么解？如果接的是二维雨水（LC 407）呢？ |

> 💡 **接雨水三种解法**：动态规划 O(n) 空间 → 单调栈 O(n) 空间 → 双指针 O(1) 空间。面试中从暴力 → DP → 双指针逐步优化是加分项。

### 2.3 LC 121/122/123 买卖股票系列 ★★☆

**LC 121 买卖股票的最佳时机（一次交易）**

```java
class Solution {
    public int maxProfit(int[] prices) {
        int minPrice = Integer.MAX_VALUE;
        int maxProfit = 0;
        for (int price : prices) {
            if (price < minPrice) {
                minPrice = price;
            } else if (price - minPrice > maxProfit) {
                maxProfit = price - minPrice;
            }
        }
        return maxProfit;
    }
}
```

**LC 123 买卖股票的最佳时机 III（最多两笔交易）**

```java
class Solution {
    public int maxProfit(int[] prices) {
        int buy1 = -prices[0], sell1 = 0;
        int buy2 = -prices[0], sell2 = 0;
        for (int i = 1; i < prices.length; i++) {
            buy1 = Math.max(buy1, -prices[i]);
            sell1 = Math.max(sell1, buy1 + prices[i]);
            buy2 = Math.max(buy2, sell1 - prices[i]);
            sell2 = Math.max(sell2, buy2 + prices[i]);
        }
        return sell2;

}
```

### 2.4 LC 239 滑动窗口最大值 ★★★

> 字节高频题，单调队列 Deque 的经典应用。

```java
class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        if (nums == null || nums.length == 0) return new int[0];
        int n = nums.length;
        int[] result = new int[n - k + 1];
        // Deque 存储的是下标，保证队列中的下标对应的值是单调递减的
        Deque<Integer> deque = new ArrayDeque<>();

        for (int i = 0; i < n; i++) {
            // 1. 移除超出窗口范围的元素（从队首）
            while (!deque.isEmpty() && deque.peekFirst() < i - k + 1) {
                deque.pollFirst();
            }
            // 2. 移除队列中所有小于当前元素的值（从队尾）
            while (!deque.isEmpty() && nums[deque.peekLast()] < nums[i]) {
                deque.pollLast();
            }
            // 3. 将当前元素下标加入队列
            deque.offerLast(i);
            // 4. 窗口形成后，队首元素即为当前窗口最大值
            if (i >= k - 1) {
                result[i - k + 1] = nums[deque.peekFirst()];
            }
        }
        return result;
    }
}
```

| 维度 | 数据 |
|------|------|
| 时间复杂度 | O(n)，每个元素最多入队和出队一次 |
| 空间复杂度 | O(k)，Deque 最多存 k 个元素 |
| 公司标签 | 字节跳动、阿里、腾讯 |
| 面试官追问 | 如何求滑动窗口的中位数？（LC 480，用两个优先队列或有序集合） |

### 2.5 LC 33 搜索旋转排序数组 ★★★

> 二分查找的经典变体，字节常将其作为"基础二分"的 follow-up。

```java
class Solution {
    public int search(int[] nums, int target) {
        int left = 0, right = nums.length - 1;

        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] == target) return mid;

            // 左半部分有序
            if (nums[left] <= nums[mid]) {
                if (nums[left] <= target && target < nums[mid]) {
                    right = mid - 1;
                } else {
                    left = mid + 1;
                }
            }
            // 右半部分有序
            else {
                if (nums[mid] < target && target <= nums[right]) {
                    left = mid + 1;
                } else {
                    right = mid - 1;
                }
            }
        }
        return -1;
    }
}
```

| 维度 | 数据 |
|------|------|
| 时间复杂度 | O(log n) |
| 空间复杂度 | O(1) |
| 公司标签 | 字节跳动、阿里、美团 |
| 面试官追问 | 如果数组中有重复元素怎么办？（LC 81，在最坏情况下会退化到 O(n)） |

### 2.6 LC 4 寻找两个正序数组的中位数 ★★★

> Hard 级二分查找，字节面试中拉开差距的题目。

```java
class Solution {
    public double findMedianSortedArrays(int[] nums1, int[] nums2) {
        // 保证 nums1 是较短的数组，减少二分次数
        if (nums1.length > nums2.length) {
            return findMedianSortedArrays(nums2, nums1);
        }

        int m = nums1.length, n = nums2.length;
        int left = 0, right = m;
        int totalLeft = (m + n + 1) / 2;

        while (left <= right) {
            // i: nums1 分割线右侧第一个元素下标
            // j: nums2 分割线右侧第一个元素下标
            int i = left + (right - left) / 2;
            int j = totalLeft - i;

            int nums1LeftMax = (i == 0) ? Integer.MIN_VALUE : nums1[i - 1];
            int nums1RightMin = (i == m) ? Integer.MAX_VALUE : nums1[i];
            int nums2LeftMax = (j == 0) ? Integer.MIN_VALUE : nums2[j - 1];
            int nums2RightMin = (j == n) ? Integer.MAX_VALUE : nums2[j];

            if (nums1LeftMax <= nums2RightMin && nums2LeftMax <= nums1RightMin) {
                // 找到正确分割
                if ((m + n) % 2 == 0) {
                    return (Math.max(nums1LeftMax, nums2LeftMax)
                            + Math.min(nums1RightMin, nums2RightMin)) / 2.0;
                } else {
                    return Math.max(nums1LeftMax, nums2LeftMax);
                }
            } else if (nums1LeftMax > nums2RightMin) {
                right = i - 1; // nums1 分割线左移
            } else {
                left = i + 1; // nums1 分割线右移
            }
        }
        return 0.0;
    }
}
```

| 维度 | 数据 |
|------|------|
| 时间复杂度 | O(log(min(m, n))) |
| 空间复杂度 | O(1) |
| 公司标签 | 字节跳动、腾讯、百度 |
| 面试官追问 | 如果要求第 K 小数怎么改？延伸：两个有序数组找第 K 小的数。 |

### 2.7 LC 146 LRU 缓存（再次强调） ★★★

> Hot100 中已详细讲解，此处仅作速查——字节面试手写 LRU 概率极高，要求 15 分钟内 bug-free。

```java
class LRUCache {
    // 双向链表节点
    static class Node {
        int key, value;
        Node prev, next;
        Node() {}
        Node(int key, int value) {
            this.key = key;
            this.value = value;
        }
    }

    private final int capacity;
    // 哨兵头尾节点，避免边界判断
    private final Node head = new Node();
    private final Node tail = new Node();
    private final Map<Integer, Node> map = new HashMap<>();

    public LRUCache(int capacity) {
        this.capacity = capacity;
        head.next = tail;
        tail.prev = head;
    }

    public int get(int key) {
        Node node = map.get(key);
        if (node == null) return -1;
        // 移动到链表头部（最近使用）
        moveToHead(node);
        return node.value;
    }

    public void put(int key, int value) {
        Node node = map.get(key);
        if (node != null) {
            node.value = value;
            moveToHead(node);
        } else {
            if (map.size() == capacity) {
                // 移除最久未使用的节点（尾节点前一个）
                Node removed = removeTail();
                map.remove(removed.key);
            }
            Node newNode = new Node(key, value);
            map.put(key, newNode);
            addToHead(newNode);
        }
    }

    private void moveToHead(Node node) {
        removeNode(node);
        addToHead(node);
    }

    private void addToHead(Node node) {
        node.prev = head;
        node.next = head.next;
        head.next.prev = node;
        head.next = node;
    }

    private void removeNode(Node node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }

    private Node removeTail() {
        Node node = tail.prev;
        removeNode(node);
        return node;
    }
}
```

> ⚠️ **注意**：面试中不要直接使用 `LinkedHashMap` 的现成实现，面试官想考察的是你能否手写双向链表 + HashMap 的结合。

### 2.8 LC 103 二叉树的锯齿形层序遍历 ★★☆

```java
class Solution {
    public List<List<Integer>> zigzagLevelOrder(TreeNode root) {
        List<List<Integer>> result = new ArrayList<>();
        if (root == null) return result;

        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        boolean leftToRight = true;

        while (!queue.isEmpty()) {
            int size = queue.size();
            Deque<Integer> level = new LinkedList<>();

            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();

                if (leftToRight) {
                    level.offerLast(node.val);
                } else {
                    level.offerFirst(node.val);
                }

                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }

            result.add(new ArrayList<>(level));
            leftToRight = !leftToRight;
        }
        return result;
    }
}
```

| 维度 | 数据 |
|------|------|
| 时间复杂度 | O(n) |
| 空间复杂度 | O(n) |
| 公司标签 | 字节跳动、腾讯 |

### 3.1 LC 460 LFU 缓存 ★★★

> 比 LRU 更难——不仅淘汰最久未使用，还要淘汰访问频率最低的。

```java
class LFUCache {
    // Node: key-value + 访问频率
    static class Node {
        int key, value, freq;
        Node prev, next;
        Node(int key, int value) {
            this.key = key;
            this.value = value;
            this.freq = 1;
        }
    }

    // FreqNode: 同一频率的节点构成的双向链表
    static class FreqList {
        Node head, tail;

        FreqList() {
            head = new Node(-1, -1);
            tail = new Node(-1, -1);
            head.next = tail;
            tail.prev = head;
        }

        void addToHead(Node node) {
            node.prev = head;
            node.next = head.next;
            head.next.prev = node;
            head.next = node;
        }

        void remove(Node node) {
            node.prev.next = node.next;
            node.next.prev = node.prev;
        }

        boolean isEmpty() {
            return head.next == tail;
        }

        Node removeLast() {
            if (isEmpty()) return null;
            Node node = tail.prev;
            remove(node);
            return node;
        }
    }

    private final int capacity;
    private int minFreq = 0;
    private final Map<Integer, Node> cache = new HashMap<>();
    private final Map<Integer, FreqList> freqMap = new HashMap<>();

    public LFUCache(int capacity) {
        this.capacity = capacity;
    }

    public int get(int key) {
        if (!cache.containsKey(key)) return -1;
        Node node = cache.get(key);
        updateFreq(node);
        return node.value;
    }

    public void put(int key, int value) {
        if (capacity == 0) return;

        if (cache.containsKey(key)) {
            Node node = cache.get(key);
            node.value = value;
            updateFreq(node);
        } else {
            if (cache.size() == capacity) {
                // 移除使用频率最低的链表中最久未使用的节点
                FreqList minList = freqMap.get(minFreq);
                Node removed = minList.removeLast();
                cache.remove(removed.key);
            }

            Node newNode = new Node(key, value);
            cache.put(key, newNode);
            minFreq = 1;
            freqMap.computeIfAbsent(1, k -> new FreqList()).addToHead(newNode);
        }
    }

    private void updateFreq(Node node) {
        // 从原频率列表移除
        FreqList oldList = freqMap.get(node.freq);
        oldList.remove(node);

        // 如果移除后当前最小频率链表为空，增加最小频率
        if (node.freq == minFreq && oldList.isEmpty()) {
            minFreq++;
        }

        // 更新频率并加入新链表
        node.freq++;
        freqMap.computeIfAbsent(node.freq, k -> new FreqList()).addToHead(node);
    }
}
```

| 维度 | 数据 |
|------|------|
| get 时间复杂度 | O(1) |
| put 时间复杂度 | O(1) |
| 空间复杂度 | O(capacity) |
| 公司标签 | 阿里（蚂蚁金服）、字节跳动 |

> 🎯 **核心要点**：LFU 的核心思想是"频率 + 时间"二维淘汰。面试时先讲清楚思路——每个频率维护一个双向链表，节点按访问时间排序，缓存满时淘汰最低频率链表尾部节点。

### 3.2 LC 120 三角形最小路径和 ★★☆

```java
class Solution {
    public int minimumTotal(List<List<Integer>> triangle) {
        int n = triangle.size();
        // 使用一维 DP，从底部向上递推
        int[] dp = new int[n];
        // 初始化为最后一层
        for (int i = 0; i < n; i++) {
            dp[i] = triangle.get(n - 1).get(i);
        }
        // 从倒数第二层向上
        for (int i = n - 2; i >= 0; i--) {
            for (int j = 0; j <= i; j++) {
                dp[j] = triangle.get(i).get(j) + Math.min(dp[j], dp[j + 1]);
            }
        }
        return dp[0];
    }
}
```

### 3.3 LC 279 完全平方数 ★★☆

```java
class Solution {
    public int numSquares(int n) {
        int[] dp = new int[n + 1];
        Arrays.fill(dp, Integer.MAX_VALUE);
        dp[0] = 0;

        for (int i = 1; i <= n; i++) {
            // 尝试减去每一个完全平方数
            for (int j = 1; j * j <= i; j++) {
                dp[i] = Math.min(dp[i], dp[i - j * j] + 1);
            }
        }
        return dp[n];
    }
}
```

### 3.4 LC 31 下一个排列 ★★★

> 经典技巧题——"下一个排列"是很多排列组合题的基石。

```java
class Solution {
    public void nextPermutation(int[] nums) {
        int i = nums.length - 2;
        // 1. 从右向左找到第一个降序的位置（即 nums[i] < nums[i+1]）
        while (i >= 0 && nums[i] >= nums[i + 1]) {
            i--;
        }

        if (i >= 0) {
            // 2. 从右向左找到第一个大于 nums[i] 的数
            int j = nums.length - 1;
            while (j >= 0 && nums[j] <= nums[i]) {
                j--;
            }
            // 3. 交换
            swap(nums, i, j);
        }

        // 4. 反转 i+1 到末尾的部分（降序变升序）
        reverse(nums, i + 1, nums.length - 1);
    }

    private void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }

    private void reverse(int[] nums, int start, int end) {
        while (start < end) {
            swap(nums, start++, end--);
        }
    }
}
```

### 3.5 LC 56 合并区间 ★★☆

```java
class Solution {
    public int[][] merge(int[][] intervals) {
        if (intervals == null || intervals.length == 0) return new int[0][];

        // 按区间起点排序
        Arrays.sort(intervals, (a, b) -> a[0] - b[0]);

        List<int[]> merged = new ArrayList<>();
        int[] current = intervals[0];

        for (int i = 1; i < intervals.length; i++) {
            if (intervals[i][0] <= current[1]) {
                // 有重叠，合并
                current[1] = Math.max(current[1], intervals[i][1]);
            } else {
                // 无重叠，加入结果并移动当前指针
                merged.add(current);
                current = intervals[i];
            }
        }
        merged.add(current);

        return merged.toArray(new int[merged.size()][]);
    }
}
```

### 3.6 补充：多线程交替打印

```java
    private final int times;

    public PrintABC(int times) {
        this.times = times;

        synchronized (this) {

        }
    }
```

### 4.1 LC 84 柱状图中最大的矩形 ★★★

> 单调栈经典题——腾讯面经中频繁出现。

```java
class Solution {
    public int largestRectangleArea(int[] heights) {
        int n = heights.length;
        // 维护单调递增栈（存下标）
        Deque<Integer> stack = new ArrayDeque<>();
        int maxArea = 0;

        for (int i = 0; i <= n; i++) {
            // 在原数组末尾添加一个高度 0，确保最后能清空栈
            int h = (i == n) ? 0 : heights[i];

            while (!stack.isEmpty() && h < heights[stack.peek()]) {
                int height = heights[stack.pop()];
                // 左边界：栈为空说明左侧没有更矮的柱子
                int left = stack.isEmpty() ? -1 : stack.peek();
                int width = i - left - 1;
                maxArea = Math.max(maxArea, height * width);
            }
            stack.push(i);
        }
        return maxArea;
    }
}
```

### 4.3 LC 124 二叉树最大路径和 ★★★

> Hard 题中的"温柔刀"——思路简单但边界多，腾讯面试高频。

```java
class Solution {
    private int maxSum = Integer.MIN_VALUE;

    public int maxPathSum(TreeNode root) {
        maxGain(root);
        return maxSum;
    }

    // 返回以当前节点为起点的最大单向路径和（向上贡献的值）
    private int maxGain(TreeNode node) {
        if (node == null) return 0;

        // 递归计算左右子树的最大贡献值，负值直接丢弃（取 0）
        int leftGain = Math.max(0, maxGain(node.left));
        int rightGain = Math.max(0, maxGain(node.right));

        // 以当前节点为"拐点"的路径和
        int currentPathSum = node.val + leftGain + rightGain;
        maxSum = Math.max(maxSum, currentPathSum);

        // 返回当前节点能贡献给父节点的最大值
        return node.val + Math.max(leftGain, rightGain);
    }
}
```

### 4.4 LC 148 排序链表 ★★☆

> 归并排序在链表上的经典应用——腾讯常考。

```java
class Solution {
    public ListNode sortList(ListNode head) {
        if (head == null || head.next == null) return head;

        // 1. 快慢指针找中点
        ListNode mid = findMiddle(head);
        ListNode rightHead = mid.next;
        mid.next = null; // 断开链表

        // 2. 递归排序左右两半
        ListNode left = sortList(head);
        ListNode right = sortList(rightHead);

        // 3. 合并两个有序链表
        return merge(left, right);
    }

    private ListNode findMiddle(ListNode head) {
        ListNode slow = head, fast = head.next;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }
        return slow;
    }

    private ListNode merge(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode(0);
        ListNode curr = dummy;
        while (l1 != null && l2 != null) {
            if (l1.val < l2.val) {
                curr.next = l1;
                l1 = l1.next;
            } else {
                curr.next = l2;
                l2 = l2.next;
            }
            curr = curr.next;
        }
        curr.next = (l1 != null) ? l1 : l2;
        return dummy.next;
    }
}
```

```java
import java.util.ArrayList;
import java.util.List;
import java.util.Random;

class RedPacket {
    /**
     * 抢红包算法 - 二倍均值法
     * @param totalAmount 总金额（单位：分）
     * @param totalCount  总份数
     * @return 每个红包的金额列表
     */
    public static List<Integer> divide(int totalAmount, int totalCount) {
        List<Integer> result = new ArrayList<>();
        Random random = new Random();

        int remainingAmount = totalAmount;
        int remainingCount = totalCount;

        for (int i = 0; i < totalCount - 1; i++) {
            // 当前红包金额 = [1, 剩余金额/剩余份数 × 2) 内的随机数
            int max = remainingAmount / remainingCount * 2;
            int amount = random.nextInt(max) + 1; // 至少 1 分
            result.add(amount);
            remainingAmount -= amount;
            remainingCount--;
        }
        // 最后一个人拿剩余全部
        result.add(remainingAmount);

        return result;
    }
}
```

### 5.2 补充：拓扑排序应用（排课表/依赖解析）

> 课程依赖、构建顺序、任务调度等场景的本质都是拓扑排序。

```java
/**
 * LC 207 课程表 - 判断是否能完成所有课程（是否存在环）
 * 拓扑排序：Kahn 算法（BFS）
 */
class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        // 1. 构建邻接表和入度表
        List<Integer>[] graph = new ArrayList[numCourses];
        int[] inDegree = new int[numCourses];

        for (int i = 0; i < numCourses; i++) {
            graph[i] = new ArrayList<>();
        }

        for (int[] edge : prerequisites) {
            int from = edge[1], to = edge[0];
            graph[from].add(to);
            inDegree[to]++;
        }

        // 2. 将入度为 0 的节点入队
        Queue<Integer> queue = new LinkedList<>();
        for (int i = 0; i < numCourses; i++) {
            if (inDegree[i] == 0) {
                queue.offer(i);
            }
        }

        // 3. BFS 拓扑排序
        int count = 0;
        while (!queue.isEmpty()) {
            int node = queue.poll();
            count++;

            for (int neighbor : graph[node]) {
                inDegree[neighbor]--;
                if (inDegree[neighbor] == 0) {
                    queue.offer(neighbor);
                }
            }
        }

        return count == numCourses;
    }
}
```

### 5.3 补充：字符串匹配 KMP

> KMP 是面试中最高频的字符串匹配算法，美团、百度爱考。

```java
class KMP {
    /**
     * KMP 主算法：返回 pattern 在 text 中首次出现的位置，未找到返回 -1
     */
    public int kmp(String text, String pattern) {
        if (pattern.isEmpty()) return 0;
        int n = text.length(), m = pattern.length();

        // 1. 计算 next 数组
        int[] next = buildNext(pattern);

        // 2. 匹配过程
        int j = 0; // pattern 指针
        for (int i = 0; i < n; i++) {
            while (j > 0 && text.charAt(i) != pattern.charAt(j)) {
                j = next[j - 1]; // 失配时回退
            }
            if (text.charAt(i) == pattern.charAt(j)) {
                j++;
            }
            if (j == m) {
                return i - m + 1; // 找到匹配
            }
        }
        return -1;
    }

    /**
     * 构建 next 数组（前缀函数）
     * next[i] = pattern[0..i] 中最长相等前后缀的长度
     */
    private int[] buildNext(String pattern) {
        int m = pattern.length();
        int[] next = new int[m];
        int j = 0; // 最长前后缀长度

        for (int i = 1; i < m; i++) {
            while (j > 0 && pattern.charAt(i) != pattern.charAt(j)) {
                j = next[j - 1];
            }
            if (pattern.charAt(i) == pattern.charAt(j)) {
                j++;
            }
            next[i] = j;
        }
        return next;
    }
}
```

```java
class Solution {

    public int[] shuffle() {

        return array;

        int temp = arr[i];
        arr[i] = arr[j];
        arr[j] = temp;
    }
}
```

```java
class Codec {

    public String serialize(MultiTreeNode root) {
        if (root == null) return "";
        StringBuilder sb = new StringBuilder();
        serializeHelper(root, sb);
        return sb.toString();
    }

    private void serializeHelper(MultiTreeNode node, StringBuilder sb) {
        sb.append(node.val).append(",");
        sb.append(node.children.size()).append(",");
        for (MultiTreeNode child : node.children) {
            serializeHelper(child, sb);
        }

    public MultiTreeNode deserialize(String data) {
        if (data == null || data.isEmpty()) return null;
        Queue<Integer> queue = new LinkedList<>();
        for (String s : data.split(",")) {
            if (!s.isEmpty()) {
                queue.offer(Integer.parseInt(s));
            }
        }
        return deserializeHelper(queue);

        if (queue.isEmpty()) return null;
        int val = queue.poll();
        int childCount = queue.poll();
        MultiTreeNode node = new MultiTreeNode(val);
        for (int i = 0; i < childCount; i++) {
            node.children.add(deserializeHelper(queue));
        }
        return node;
    }
}
```

### 6.1 补充：大数据 TopK 问题（海量数据处理）

> TopK 是海量数据面试题中最经典的问题。数据量太大无法一次加载到内存时，使用堆或分布式方案。

**方法一：小顶堆（适合小 K，内存放得下）**

```java
/**
 * 从数组中找出最大的 K 个数

class TopKByHeap {
    public List<Integer> findTopK(int[] nums, int k) {
        if (k <= 0 || nums == null || nums.length == 0) return new ArrayList<>();

        // 小顶堆，堆顶是最小值
        PriorityQueue<Integer> minHeap = new PriorityQueue<>(k);

        for (int num : nums) {
            if (minHeap.size() < k) {
                minHeap.offer(num);
            } else if (num > minHeap.peek()) {
                minHeap.poll();
                minHeap.offer(num);
            }
        }

        return new ArrayList<>(minHeap);
    }
}
```

**方法二：快速选择（适合内存放得下，要求 O(n) 平均时间）**

```java
class TopKByQuickSelect {
    public int findKthLargest(int[] nums, int k) {
        return quickSelect(nums, 0, nums.length - 1, nums.length - k);
    }

    private int quickSelect(int[] nums, int left, int right, int targetIdx) {
        int pivot = partition(nums, left, right);
        if (pivot == targetIdx) {
            return nums[pivot];
        }
        return (pivot < targetIdx)
                ? quickSelect(nums, pivot + 1, right, targetIdx)
                : quickSelect(nums, left, pivot - 1, targetIdx);
    }

    private int partition(int[] nums, int left, int right) {
        int pivot = nums[right]; // 选最右侧为枢轴
        int i = left;
        for (int j = left; j < right; j++) {
            if (nums[j] <= pivot) {
                swap(nums, i++, j);
            }
        }
        swap(nums, i, right);
        return i;
    }

    private void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }
}
```

```
2. 对每个小文件使用小顶堆求 TopK
3. 将 1000 个 TopK 结果合并，再次用小顶堆求全局 TopK
```

### 6.2 补充：布隆过滤器原理与实现

> 布隆过滤器用于判断"一个元素是否不在集合中"，常用于缓存穿透防护、爬虫 URL 去重。

```java
import java.util.BitSet;

class BloomFilter {
    private final BitSet bits;
    private final int size;
    private final int[] hashSeeds;

    public BloomFilter(int size, int[] hashSeeds) {
        this.size = size;
        this.bits = new BitSet(size);
        this.hashSeeds = hashSeeds;
    }

    public void add(String value) {
        for (int seed : hashSeeds) {
            int hash = hash(value, seed);
            bits.set(Math.abs(hash % size), true);
        }
    }

    public boolean mightContain(String value) {
        for (int seed : hashSeeds) {
            int hash = hash(value, seed);
            if (!bits.get(Math.abs(hash % size))) {
                return false; // 一定不存在
            }
        }
        return true; // 可能存在（有误判率）
    }

    private int hash(String value, int seed) {
        int h = 0;
        for (char c : value.toCharArray()) {
            h = seed * h + c;
        }
        return h;
    }
}
```

| 维度 | 数据 |
|------|------|
| 空间效率 | 远低于 HashSet，适合海量数据 |
| 误判率 | 可通过位数组大小和哈希函数个数控制（约 1%~5%） |
| 确定不存在 | 可以（"不在"一定不在，"在"不一定在） |
| 公司标签 | 京东、百度、字节跳动（Redis 缓存穿透场景） |

### 6.3 LC 547 省份数量 ★★☆

> 并查集经典入门题。

```java
class Solution {
    public int findCircleNum(int[][] isConnected) {
        int n = isConnected.length;
        UnionFind uf = new UnionFind(n);

        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (isConnected[i][j] == 1) {
                    uf.union(i, j);
                }
            }
        }

        return uf.getCount();
    }

    static class UnionFind {
        private int[] parent;
        private int[] rank;
        private int count;

        public UnionFind(int n) {
            parent = new int[n];
            rank = new int[n];
            count = n;
            for (int i = 0; i < n; i++) {
                parent[i] = i;
                rank[i] = 1;
            }
        }

        public int find(int x) {
            if (parent[x] != x) {
                parent[x] = find(parent[x]); // 路径压缩
            }
            return parent[x];
        }

        public void union(int x, int y) {
            int rootX = find(x);
            int rootY = find(y);
            if (rootX == rootY) return;

            // 按秩合并
            if (rank[rootX] < rank[rootY]) {
                parent[rootX] = rootY;
            } else if (rank[rootX] > rank[rootY]) {
                parent[rootY] = rootX;
            } else {
                parent[rootY] = rootX;
                rank[rootX]++;
            }
            count--;
        }

        public int getCount() {
            return count;
        }
    }
}
```

| 维度 | 数据 |
|------|------|

| 空间复杂度 | O(n) |
| 公司标签 | 百度、京东 |

### 6.4 补充：限流算法实现（令牌桶/漏桶/滑动窗口）

**令牌桶算法**

```java
import java.util.concurrent.TimeUnit;
import java.util.concurrent.atomic.AtomicLong;

class TokenBucket {
    private final long capacity;          // 桶容量
    private final long refillRate;        // 每秒令牌数
    private final AtomicLong tokens;      // 当前令牌数
    private volatile long lastRefillTime; // 上次补充时间

    public TokenBucket(long capacity, long refillRate) {
        this.capacity = capacity;
        this.refillRate = refillRate;
        this.tokens = new AtomicLong(capacity);
        this.lastRefillTime = System.currentTimeMillis();
    }

    public boolean tryAcquire() {
        refill();
        while (true) {
            long currentTokens = tokens.get();
            if (currentTokens <= 0) return false;
            if (tokens.compareAndSet(currentTokens, currentTokens - 1)) {
                return true;
            }
        }
    }

    private void refill() {
        long now = System.currentTimeMillis();
        long elapsed = now - lastRefillTime;
        if (elapsed < 1000) return; // 不到 1 秒不补充

        synchronized (this) {
            // Double-check
            if (now - lastRefillTime >= 1000) {
                long newTokens = (elapsed / 1000) * refillRate;
                tokens.set(Math.min(capacity, tokens.get() + newTokens));
                lastRefillTime = now;
            }
        }
    }
}
```

**滑动窗口计数器**

```java
class SlidingWindowCounter {
    private final int windowSize;    // 窗口大小（毫秒）
    private final int maxRequests;   // 窗口内最大请求数
    private final AtomicLong[] counters;
    private final int slotCount;     // 槽位数量

    public SlidingWindowCounter(int windowSize, int maxRequests, int slotCount) {
        this.windowSize = windowSize;
        this.maxRequests = maxRequests;
        this.slotCount = slotCount;
        this.counters = new AtomicLong[slotCount];
        for (int i = 0; i < slotCount; i++) {
            counters[i] = new AtomicLong(0);
        }
    }

    public boolean tryAcquire() {
        long now = System.currentTimeMillis();
        int currentSlot = (int)((now / (windowSize / slotCount)) % slotCount);
        long total = 0;

        for (int i = 0; i < slotCount; i++) {
            total += counters[i].get();
        }
        if (total >= maxRequests) return false;

        counters[currentSlot].incrementAndGet();
        return true;
    }
}
```

### 6.5 补充：一致性哈希算法

> 一致性哈希解决的是分布式缓存中的"节点增减对缓存命中率的影响"问题。

```java
import java.security.MessageDigest;
import java.security.NoSuchAlgorithmException;
import java.util.*;

class ConsistentHash<T> {
    private final int virtualNodes;  // 每个物理节点对应虚拟节点数
    private final TreeMap<Long, T> ring = new TreeMap<>(); // 哈希环

    public ConsistentHash(int virtualNodes, Collection<T> nodes) {
        this.virtualNodes = virtualNodes;
        for (T node : nodes) {
            addNode(node);
        }
    }

    public void addNode(T node) {
        for (int i = 0; i < virtualNodes; i++) {
            long hash = hash(node.toString() + "-" + i);
            ring.put(hash, node);
        }
    }

    public void removeNode(T node) {
        for (int i = 0; i < virtualNodes; i++) {
            long hash = hash(node.toString() + "-" + i);
            ring.remove(hash);
        }
    }

    public T getNode(String key) {
        if (ring.isEmpty()) return null;
        long hash = hash(key);
        // 找到第一个大于等于 hash 的节点
        Map.Entry<Long, T> entry = ring.ceilingEntry(hash);
        if (entry == null) {
            // 如果没有，则回到环的第一个节点
            entry = ring.firstEntry();
        }
        return entry.getValue();
    }

    private long hash(String key) {
        try {
            MessageDigest md = MessageDigest.getInstance("MD5");
            byte[] digest = md.digest(key.getBytes());
            return ((long)(digest[3] & 0xFF) << 24)
                 | ((long)(digest[2] & 0xFF) << 16)
                 | ((long)(digest[1] & 0xFF) << 8)
                 | (digest[0] & 0xFF);
        } catch (NoSuchAlgorithmException e) {
            throw new RuntimeException(e);
        }
    }
}
```

| 维度 | 数据 |
|------|------|
| 核心优势 | 节点增减时只影响邻近节点，缓存命中率高 |
| 虚拟节点 | 解决数据倾斜问题 |
| 公司标签 | 京东、字节跳动、美团 |
| 面试官追问 | Redis Cluster 的哈希槽和一致性哈希的区别？ |

```java
class UrlShortener {
    private static final String BASE62 = "0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ";
    private static final int BASE = 62;
    private final Map<String, String> shortToLong = new HashMap<>();
    private final Map<String, String> longToShort = new HashMap<>();
    private int counter = 1; // 可以用分布式 ID 生成器替代

    /**
     * 生成短链接：自增 ID → Base62 编码
     */
    public String shorten(String longUrl) {
        if (longToShort.containsKey(longUrl)) {
            return longToShort.get(longUrl);
        }

        String shortUrl = toBase62(counter);
        shortToLong.put(shortUrl, longUrl);
        longToShort.put(longUrl, shortUrl);
        counter++;

        return shortUrl;
    }

    public String getOriginal(String shortUrl) {
        return shortToLong.get(shortUrl);
    }

    private String toBase62(int num) {
        StringBuilder sb = new StringBuilder();
        while (num > 0) {
            sb.append(BASE62.charAt(num % BASE));
            num /= BASE;
        }
        return sb.reverse().toString();
    }
}
```

| 性能优化 | 预生成一批短链，写入缓存 |

```java
class RedPacketSegment {
    public static List<Integer> divide(int totalAmount, int totalCount) {
        // 在 [1, totalAmount) 范围内随机切 totalCount-1 刀
        Set<Integer> points = new TreeSet<>();
        Random random = new Random();

        // 生成切割点
        while (points.size() < totalCount - 1) {
            points.add(random.nextInt(totalAmount - 1) + 1);
        }

        // 计算每段金额
        List<Integer> result = new ArrayList<>();
        int prev = 0;
        for (int point : points) {
            result.add(point - prev);
            prev = point;
        }
        result.add(totalAmount - prev);

        return result;
    }
}
```

### 7.5 设计一个延迟队列

**方案一：JDK DelayQueue**

```java
import java.util.concurrent.Delayed;
import java.util.concurrent.DelayQueue;
import java.util.concurrent.TimeUnit;

class DelayedTask implements Delayed {
    private final String taskId;
    private final long executeTime; // 执行时间（毫秒时间戳）

    public DelayedTask(String taskId, long delayMs) {
        this.taskId = taskId;
        this.executeTime = System.currentTimeMillis() + delayMs;
    }

    @Override
    public long getDelay(TimeUnit unit) {
        return unit.convert(executeTime - System.currentTimeMillis(), TimeUnit.MILLISECONDS);
    }

    @Override
    public int compareTo(Delayed o) {
        return Long.compare(this.executeTime, ((DelayedTask)o).executeTime);
    }

    public String getTaskId() { return taskId; }
}

class DelayQueueExample {
    private final DelayQueue<DelayedTask> queue = new DelayQueue<>();

    public void produce(String taskId, long delayMs) {
        queue.put(new DelayedTask(taskId, delayMs));
    }

    public void consume() throws InterruptedException {
        // 阻塞直到有任务到期
        DelayedTask task = queue.take();
        System.out.println("Executing: " + task.getTaskId());
    }
}
```

```java
class BitMap {
    private final long[] words;
    private final int capacity;

    public BitMap(int capacity) {
        this.capacity = capacity;
        // 每个 long 64 位
        this.words = new long[(capacity + 63) / 64];
    }

    public void set(int bit) {
        if (bit < 0 || bit >= capacity) throw new IndexOutOfBoundsException();
        words[bit / 64] |= (1L << (bit % 64));
    }

    public boolean get(int bit) {
        if (bit < 0 || bit >= capacity) throw new IndexOutOfBoundsException();
        return (words[bit / 64] & (1L << (bit % 64))) != 0;
    }

    public void clear(int bit) {
        if (bit < 0 || bit >= capacity) throw new IndexOutOfBoundsException();
        words[bit / 64] &= ~(1L << (bit % 64));
    }
}
```
