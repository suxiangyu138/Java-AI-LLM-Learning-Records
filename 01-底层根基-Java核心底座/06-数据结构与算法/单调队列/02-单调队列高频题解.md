## 1. 239. 滑动窗口最大值（母题详解）

### 1.1 完整实现

```java
/**
 * LeetCode 239. 滑动窗口最大值（Hot 100）
 * 单调递减队列（存下标）三件套：
 *   ① 入队：弹出所有比当前小的（永久淘汰）
 *   ② 过期：队头滑出窗口 → 弹出
 *   ③ 取值：队头 = 当前窗口最大值
 */
public int[] maxSlidingWindow(int[] nums, int k) {
    int n = nums.length;
    int[] result = new int[n - k + 1];
    Deque<Integer> deque = new ArrayDeque<>();

    for (int i = 0; i < n; i++) {
        // ① 入队：弹出所有比当前小的
        //    （晚到且大淘汰早到且小）
        while (!deque.isEmpty() && nums[deque.peekLast()] < nums[i]) {
            deque.pollLast();
        }
        deque.offerLast(i);

        // ② 过期：滑出窗口的旧下标
        if (deque.peekFirst() <= i - k) {
            deque.pollFirst();
        }

        // ③ 取值：窗口形成后取队头
        if (i >= k - 1) {
            result[i - k + 1] = nums[deque.peekFirst()];
        }
    }
    return result;
}
// O(n)：每个元素进出队各一次
```

### 1.2 完整推演：[1, 3, -1, -3, 5, 3, 6, 7], k = 3

```
i=0: 入队 1 → deque=[0(1)]
i=1: 3 > 1 弹出 0 → deque=[1(3)]
i=2: -1 < 3 → deque=[1(3), 2(-1)]；i≥2 → 结果[0]=3
i=3: -3 < -1 → deque=[1(3),2(-1),3(-3)]；结果[1]=3
i=4: 5 弹出 3,2,1 → deque=[4(5)]；结果[2]=5
i=5: 3 < 5 → deque=[4(5),5(3)]；结果[3]=5
i=6: 6 弹出 5,4 → deque=[6(6)]；结果[4]=6
i=7: 7 弹出 6 → deque=[7(7)]；结果[5]=7
结果 [3,3,5,5,6,7] ✓
```

### 1.3 三个关键细节

```
① 为什么"比当前小的都弹出"？
   元素 x 比新元素 y 小且 x 在 y 左边（更早过期）：
     y 比 x 大 → x 在窗口内时 y 也在 → 最大轮不到 x
     y 比 x 晚过期 → y 存活时间覆盖 x
   → x 永久淘汰 ✓

② 为什么存下标不存值？
   需要判断过期（队头 ≤ i-k → 滑出）

③ 为什么相等不弹出？
   相等时保留旧的（更早过期）
   ⚠️ 弹出相等的也没错（结果相同）
   但保留更安全（避免极端情况）
```

## 2. 1696. 跳跃游戏 VI（DP 优化）

### 2.1 完整实现

```java
/**
 * LeetCode 1696. 跳跃游戏 VI
 * dp[i] = nums[i] + max(dp[i-k..i-1])
 * 单调队列维护 dp 窗口最大值 → O(n)
 */
public int maxResult(int[] nums, int k) {
    int n = nums.length;
    int[] dp = new int[n];
    dp[0] = nums[0];

    Deque<Integer> deque = new ArrayDeque<>();
    deque.offerLast(0);                          // dp[0] 入队

    for (int i = 1; i < n; i++) {
        // ① 过期：窗口 [i-k, i-1]（不含 i）
        while (!deque.isEmpty() && deque.peekFirst() < i - k) {
            deque.pollFirst();
        }

        // ② 转移：队头 = 窗口内 dp 最大
        dp[i] = nums[i] + dp[deque.peekFirst()];

        // ③ 维护单调（按 dp 值比较！）
        while (!deque.isEmpty() && dp[deque.peekLast()] <= dp[i]) {
            deque.pollLast();
        }
        deque.offerLast(i);
    }
    return dp[n - 1];
}
```

### 2.2 与 239 的三个差异

| 差异 | 239 | 1696 |
|------|:---:|:---:|
| 窗口含不含当前 | [i-k+1, i] 含 i | [i-k, i-1] 不含 i |
| 过期条件 | peekFirst <= i-k | peekFirst < i-k |
| 单调性比较 | nums 值 | dp 值 |

```
⚠️ 面试易错点：
  过期条件差一个等号！
  窗口 [i-k, i-1] → peekFirst < i-k
  （i-k 本身可以跳（含），所以严格小于才过期）
```

### 2.3 推演验证

```
nums = [1, -1, -2, 4, -7, 3], k = 2
dp[0] = 1，deque = [0(1)]

i=1：队头 0（≥ 1-2）→ dp[1] = -1 + dp[0] = 0
  维护：dp[0]=1 > 0 → deque = [0(1), 1(0)]
i=2：队头 0（≥ 0）→ dp[2] = -2 + dp[0] = -1
  deque = [0(1), 1(0), 2(-1)]
i=3：队头 0 < 1 → 过期弹出 → 队头 1
  dp[3] = 4 + dp[1] = 4
  维护：dp[1]=0 ≤ 4 弹出；dp[2]=-1 ≤ 4 弹出 → deque = [3(4)]
i=4：dp[4] = -7 + dp[3] = -3 → deque = [3(4), 4(-3)]
i=5：队头 3（≥ 3）→ dp[5] = 3 + dp[3] = 7
答案 7 ✓
```

## 3. 1425. 带限制的子序列和

### 3.1 完整实现

```java
/**
 * LeetCode 1425. 带限制的子序列和（Hard）
 * 选子序列：相邻选中元素下标差 ≤ k，可跳过
 * dp[i] = nums[i] + max(0, max(dp[i-k..i-1]))
 */
public int constrainedSubsetSum(int[] nums, int k) {
    int n = nums.length;
    int[] dp = new int[n];
    dp[0] = nums[0];

    Deque<Integer> deque = new ArrayDeque<>();
    deque.offerLast(0);
    int maxSum = dp[0];

    for (int i = 1; i < n; i++) {
        while (!deque.isEmpty() && deque.peekFirst() < i - k) {
            deque.pollFirst();
        }

        int best = deque.isEmpty() ? 0 : dp[deque.peekFirst()];
        dp[i] = nums[i] + Math.max(0, best);     // ⚠️ max(0, ...)
        maxSum = Math.max(maxSum, dp[i]);

        while (!deque.isEmpty() && dp[deque.peekLast()] <= dp[i]) {
            deque.pollLast();
        }
        deque.offerLast(i);
    }
    return maxSum;                               // ⚠️ 全局最大
}
```

### 3.2 与 1696 的核心区别

```
① 转移：+ max(0, best)（负数前缀不选）
   1696 必须跳 → 没有 max(0, ...)
② 返回值：全局最大 vs dp[n-1]
   1425 可跳过 → 最优可能不在末尾

⚠️ 面试必答：
"1425 可跳过元素，所以转移用 max(0, best)
 且答案取全局最大；1696 必须跳，
 答案在 dp[n-1]。"
```

### 3.3 推演验证

```
nums = [10, -2, -10, -5, 20], k = 2
dp[0] = 10，deque = [0(10)]，maxSum = 10

i=1：dp[1] = -2 + max(0, 10) = 8 → maxSum=10
i=2：队头 0（≥0）→ dp[2] = -10 + max(0, 10) = 0
i=3：队头 0 < 1 → 弹出 → 队头 1
  dp[3] = -5 + max(0, 8) = 3
i=4：队头 1 < 2 → 弹出 → 队头 2
  dp[4] = 20 + max(0, dp[2]=0) = 20
  ⚠️ 等等，dp[3]=3 也在窗口（4-2=2 ≤ 3 ≤ 3）？
  重新检查：deque 中谁最大？
  → 正确的窗口是 [2,3]，dp[2]=0, dp[3]=3 → best=3
  dp[4] = 20 + 3 = 23 → maxSum = 23 ✓
```

## 4. 862. 和至少为 K 的最短子数组

### 4.1 完整实现

```java
/**
 * LeetCode 862. 和至少为 K 的最短子数组（Hard）
 * 含负数 → 滑动窗口失效 → 前缀和 + 单调队列
 *
 * 前缀和 pre[]，找 j > i 使 pre[j] - pre[i] ≥ k
 * 单调递增队列维护 pre[i]（最小前缀和优先）
 */
public int shortestSubarray(int[] nums, int k) {
    int n = nums.length;
    long[] pre = new long[n + 1];
    for (int i = 0; i < n; i++) {
        pre[i + 1] = pre[i] + nums[i];
    }

    Deque<Integer> deque = new ArrayDeque<>();
    int minLen = Integer.MAX_VALUE;

    for (int i = 0; i <= n; i++) {
        // ① 队首满足条件 → 更新答案并弹出
        while (!deque.isEmpty() && pre[i] - pre[deque.peekFirst()] >= k) {
            minLen = Math.min(minLen, i - deque.pollFirst());
        }
        // ② 维护单调递增：弹出 ≥ pre[i] 的
        //    （更大且更晚 → 两个维度都输）
        while (!deque.isEmpty() && pre[deque.peekLast()] >= pre[i]) {
            deque.pollLast();
        }
        deque.offerLast(i);
    }
    return minLen == Integer.MAX_VALUE ? -1 : minLen;
}
// ⚠️ 为什么单调递增？
//   需要 pre[i] 尽量小（更容易 ≥ k）
//   且下标尽量小（距离更短）
//   淘汰"更大且更晚"的前缀和（两个维度都输）
```

### 4.2 推演：nums = [2, -1, 2], k = 3

```
pre = [0, 2, 1, 3]
i=0：队列空 → 入队 [0(0)]
i=1：pre[1]-pre[0] = 2 < 3 → 不入答案
  维护：pre[0]=0 < pre[1]=2 → 保留 → [0, 1]
i=2：pre[2]-pre[0] = 1 < 3 → 不入
  维护：pre[0]=0 < 1？0 < 1 ✓ 但 pre[1]=2 ≥ 1 → 弹出 1
  再检查 pre[0]=0 ≥ 1？否 → 保留 → [0, 2(1)]
  ⚠️ 注意：弹出 1 是因为 pre[1]=2 ≥ pre[2]=1
    （更大且更晚 → 不可能最优）
i=3：pre[3]-pre[0] = 3 ≥ 3 → 答案 3-0=3 → 弹出 0
  pre[3]-pre[2] = 2 < 3 → 不入
  答案 minLen = 3 ✓（[2,-1,2] 整个数组）
```

### 4.3 为什么滑动窗口失效

```
含负数 → 扩窗和可能变小 → 条件不单调
  无法判断"缩窗还是扩窗"

前缀和 + 单调队列：
  数学转化 pre[j] - pre[i] ≥ k → 找最小 j-i
  单调队列维护"候选 i"（前缀和递增 + 下标递增）

⚠️ 面试必答：
"含负数时窗口和不单调，滑动窗口失效；
 前缀和 + 单调队列是标准解法。"
```

## 5. 1499. 满足不等式的最大值

### 5.1 完整实现

```java
/**
 * LeetCode 1499. 满足不等式的最大值（Hard）
 * 求 max(xj - xi + yi + yj) 其中 xj - xi ≤ k
 *
 * 拆分变量：
 *   (yi - xi) + (xj + yj)
 *   ⚠️ 左端点贡献 (y-x) 与右端点贡献 (x+y) 分离
 *   单调队列维护窗口内 (y-x) 的最大值
 */
public int findMaxValueOfEquation(int[][] points, int k) {
    Deque<int[]> deque = new ArrayDeque<>();   // [x, y-x]
    int maxVal = Integer.MIN_VALUE;

    for (int[] p : points) {
        int x = p[0], y = p[1];

        // ① 过期：xj - xi > k → 弹出
        while (!deque.isEmpty() && x - deque.peekFirst()[0] > k) {
            deque.pollFirst();
        }
        // ② 更新答案：队首 (y-x) 最大
        if (!deque.isEmpty()) {
            maxVal = Math.max(maxVal, x + y + deque.peekFirst()[1]);
        }
        // ③ 维护单调：弹出 (y-x) 更小的
        while (!deque.isEmpty() && deque.peekLast()[1] <= y - x) {
            deque.pollLast();
        }
        deque.offerLast(new int[]{x, y - x});
    }
    return maxVal;
}
// 推演 points = [[0,0],[3,0],[9,2]], k = 3：
//   [0,0]：入队 [(0, 0)]
//   [3,0]：3-0 ≤ 3 ✓ → 答案 = 3+0+0 = 3
//     维护：0 ≤ 0-3=-3？否 → 入队 [(0,0), (3,-3)]
//   [9,2]：9-0 > 3 弹出 0；9-3 > 3 弹出 3 → 空
//     答案不变 → 3
// 注意：题目保证 x 递增（按 x 排序的输入）
```

### 5.2 变量拆分的技巧

```
原始表达式：xj - xi + yi + yj
按端点拆分：
  左端点（先到的）：yi - xi（随 x 变化）
  右端点（当前的）：xj + yj（固定部分）

→ 问题变成：窗口内找最大的 (y-x)
  （xj - xi ≤ k 是窗口约束）

⚠️ 面试表达：
"把 xi + yi 拆成 (yi - xi) + (xj + yj)——
 左端点的贡献 (y-x) 用单调队列维护，
 右端点贡献 (x+y) 是常数。"
```

### 5.3 拆分技巧的应用

```
"最大值 + 不等式约束" 类问题：
  ① 把表达式按"两个端点的贡献"拆分
  ② 一个端点的贡献入单调队列
  ③ 另一个端点作为常数计算

⚠️ 识别信号：
  "xi + yi + xj + yj" 形式的表达式
  + 下标/坐标距离约束
```

## 6. 题解方法论总结

### 6.1 五题模式总结

| 题号 | 题目 | 维护内容 | 单调方向 | 复杂度 |
|:---:|------|------|:---:|:---:|
| 239 | 窗口最大值 | nums 值 | 递减 | O(n) |
| 1696 | 跳跃游戏 VI | dp 值 | 递减 | O(n) |
| 1425 | 子序列和 | dp 值 + max(0) | 递减 | O(n) |
| 862 | 最短 ≥ K | 前缀和 | **递增** | O(n) |
| 1499 | 不等式最大值 | 拆分项 y-x | 递减 | O(n) |

### 6.2 单调队列解题五步

```
① 识别窗口/区间约束（下标差 ≤ k 等）
② 确定维护内容（值/dp/前缀和/拆分项）
③ 确定单调方向（递减取最大；递增取最小）
④ 三件套：入队淘汰 → 过期弹出 → 取头
⑤ 验证过期边界（< vs ≤，窗口含不含当前）

⚠️ 两个维度都输才淘汰：
  值更差 + 更早过期（或更晚）
  例：239 淘汰"小且早"；862 淘汰"大且晚"
```

### 6.3 面试话术

```
"窗口最值问题用单调队列三件套：
 入队淘汰（晚到且大淘汰早到且小）、
 过期弹出（队头滑出窗口）、取队头。
 每个元素进出队各一次 → O(n)。
 DP 优化版：维护 dp 值窗口；
 含负数版：前缀和 + 单调递增队列。
 复杂度从 O(nk) 或 O(n log k) 降到 O(n)。"
```

> 🎯 **核心要点**：五道母题覆盖单调队列全部形态——**窗口最值**（239）、**DP 优化**（1696/1425）、**前缀和**（862 含负数）、**变量拆分**（1499）。"晚到且优淘汰早到且劣"是统一原理；过期边界与单调方向是两个易错点。
