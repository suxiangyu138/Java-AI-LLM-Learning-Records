## 1. 单调队列优化 DP 的原理

### 1.1 问题模式

```
DP 转移需要"窗口内最值"：
  dp[i] = f(max/min(dp[i-k..i-1])) + cost[i]

暴力：每步扫描窗口 → O(nk)
单调队列：O(1) 取窗口最值 → O(n)

⚠️ 识别信号：
  "转移需要最近 k 个状态的最大/最小"
  → 单调队列优化
```

### 1.2 为什么单调队列能优化

```
普通滑动窗口维护的是"数组值"的窗口
DP 优化维护的是"dp 值"的窗口

核心相同：
  单调性维护（晚到且优淘汰早到且劣）
  过期弹出（窗口滑出）

差异：比较的是 dp[i] 而非 nums[i]

⚠️ 面试表达：
"状态转移需要窗口内最大值时，
 用单调队列把 O(nk) 降到 O(n)。"
```

### 1.3 优化前后的复杂度对比

| 解法 | 时间 | 空间 | 适用 |
|------|:---:|:---:|------|
| 暴力扫描 | O(nk) | O(n) | k 小 |
| 堆 | O(n log k) | O(k) | 通用 |
| **单调队列** | **O(n)** | O(k) | **最优** |

```
⚠️ 选型：
  单调队列 O(n) 最优（每元素进出一次）
  堆 O(n log k) 通用但慢
  → DP 窗口最值首选单调队列
```

## 2. 1696. 跳跃游戏 VI：DP 优化全解

### 2.1 问题与暴力解法

```java
/**
 * LeetCode 1696. 跳跃游戏 VI
 * 从 0 跳到 n-1，每次最多跳 k 步
 * 求路径得分最大值（分数可负）
 *
 * 暴力 DP：dp[i] = nums[i] + max(dp[i-k..i-1])
 *   → O(nk) 超时（n, k 可达 10⁵）
 */
public int maxResult_Brute(int[] nums, int k) {
    int n = nums.length;
    int[] dp = new int[n];
    dp[0] = nums[0];

    for (int i = 1; i < n; i++) {
        int max = Integer.MIN_VALUE;
        for (int j = Math.max(0, i - k); j < i; j++) {
            max = Math.max(max, dp[j]);      // ⚠️ 扫描窗口 O(k)
        }
        dp[i] = nums[i] + max;
    }
    return dp[n - 1];
}
// O(nk) 太慢 → 单调队列优化
```

### 2.2 单调队列优化版

```java
/**
 * 单调队列优化：窗口 [i-k, i-1] 内 dp 最大值
 * 单调递减队列（存下标，比较 dp 值）
 */
public int maxResult(int[] nums, int k) {
    int n = nums.length;
    int[] dp = new int[n];
    dp[0] = nums[0];

    Deque<Integer> deque = new ArrayDeque<>();   // 存下标
    deque.offerLast(0);                          // dp[0] 入队

    for (int i = 1; i < n; i++) {
        // ① 过期：滑出窗口 [i-k, i-1]
        while (!deque.isEmpty() && deque.peekFirst() < i - k) {
            deque.pollFirst();
        }

        // ② 转移：队头 = 窗口内 dp 最大
        dp[i] = nums[i] + dp[deque.peekFirst()];

        // ③ 维护单调：弹出 dp 更小的队尾
        while (!deque.isEmpty() && dp[deque.peekLast()] <= dp[i]) {
            deque.pollLast();
        }
        deque.offerLast(i);
    }
    return dp[n - 1];
}
// O(n)：每元素进出队各一次
```

### 2.3 推演：nums = [1, -1, -2, 4, -7, 3], k = 2

```
dp[0] = 1，deque = [0(1)]
i=1：过期检查（0 ≥ 1-2 ✓）→ dp[1] = -1 + dp[0] = 0
  维护：dp[0]=1 > dp[1]=0 → 保留 → deque = [0(1), 1(0)]
i=2：过期检查（0 ≥ 0 ✓）→ dp[2] = -2 + dp[0] = -1
  维护：dp[0]=1 > -1；dp[1]=0 > -1 → deque = [0,1,2]
i=3：过期检查（0 < 1 ✗ 弹出 0）→ 队头 1
  dp[3] = 4 + dp[1] = 4
  维护：dp[1]=0, dp[2]=-1 ≤ 4 → 弹出；dp[3]=4 → deque = [3(4)]
i=4：dp[4] = -7 + dp[3] = -3；deque = [3(4), 4(-3)]
i=5：过期检查（3 ≥ 3 ✓）→ dp[5] = 3 + dp[3] = 7
答案 7 ✓
```

### 2.4 与 239 的对比

| 维度 | 239 窗口最大值 | 1696 DP 优化 |
|------|:---:|:---:|
| 窗口内容 | nums 值 | dp 值 |
| 单调性比较 | nums[i] | dp[i] |
| 转移用途 | 直接输出 | 计算 dp[i] |
| 过期条件 | 队头 ≤ i-k | 队头 < i-k |

```
⚠️ 差异要点：
  1696 的窗口是 [i-k, i-1]（不含 i）
  → 过期条件：peekFirst < i-k
  （239 是 [i-k+1, i] 含 i → ≤ i-k）
  先插入 0 再转移，dp[i] 入队在第 ③ 步
```

## 3. 1425. 带限制的子序列和

### 3.1 问题与实现

```java
/**
 * LeetCode 1425. 带限制的子序列和（Hard）
 * 选子序列：相邻选中元素下标差 ≤ k
 * 求最大和（可跳过元素）
 *
 * DP：dp[i] = 以 i 结尾的最大子序列和
 *   dp[i] = nums[i] + max(0, max(dp[i-k..i-1]))
 *   ⚠️ 可选可不选前面的（max(0, ...)）
 */
public int constrainedSubsetSum(int[] nums, int k) {
    int n = nums.length;
    int[] dp = new int[n];
    dp[0] = nums[0];

    Deque<Integer> deque = new ArrayDeque<>();
    deque.offerLast(0);
    int maxSum = dp[0];

    for (int i = 1; i < n; i++) {
        // ① 过期：窗口 [i-k, i-1]
        while (!deque.isEmpty() && deque.peekFirst() < i - k) {
            deque.pollFirst();
        }

        // ② 转移：max(0, 窗口内 dp 最大值)
        int best = deque.isEmpty() ? 0 : dp[deque.peekFirst()];
        dp[i] = nums[i] + Math.max(0, best);
        maxSum = Math.max(maxSum, dp[i]);

        // ③ 维护单调（⚠️ 只保留正 dp：负的入队无意义？不，
        //    需要保留——负数也可能成为窗口最大值）
        while (!deque.isEmpty() && dp[deque.peekLast()] <= dp[i]) {
            deque.pollLast();
        }
        deque.offerLast(i);
    }
    return maxSum;
}
// 推演 nums=[10,-2,-10,-5,20], k=2：
//   dp[0]=10；i=1: 10+(-2)=8；i=2: 10+(-10)=0
//   i=3: max(dp[1],dp[2])=8 → -5+8=3
//   i=4: max(dp[2],dp[3])=3 → 20+3=23 → 答案 23 ✓
```

### 3.2 与 1696 的区别

```
1696：必须跳（dp[i] = nums[i] + max(dp[i-k..i-1])）
1425：可选可不选（+ max(0, ...)）

⚠️ 关键差异：
  max(0, best) —— 负数前缀不选
  返回值不同：1696 返回 dp[n-1]；1425 返回全局最大
```

### 3.3 单调队列 DP 优化家族

| 题号 | 题目 | 转移模式 |
|:---:|------|------|
| 1696 | 跳跃游戏 VI | dp[i] = nums[i] + max(dp[i-k..i-1]) |
| 1425 | 带限制的子序列和 | dp[i] = nums[i] + max(0, max(dp[i-k..i-1])) |
| 239 | 窗口最大值 | 非 DP（直接输出窗口最值） |
| 862 | 和至少为 K 最短 | 单调队列 + 前缀和 |
| 1499 | 满足不等式最大值 | 拆分变量 + 单调队列 |

## 4. 滑动窗口的变体问题

### 4.1 862. 和至少为 K 的最短子数组

```java
/**
 * LeetCode 862. 和至少为 K 的最短子数组（Hard）
 * 含负数 → 前缀和 + 单调队列
 *
 * 思路：
 *   前缀和 pre[]，找 j > i 使 pre[j] - pre[i] ≥ k
 *   单调递增队列维护 pre[i]（淘汰"更大且更晚"的）
 *   → 队首是"最小前缀和" → 距离最长可能最短
 */
public int shortestSubarray(int[] nums, int k) {
    int n = nums.length;
    long[] pre = new long[n + 1];
    for (int i = 0; i < n; i++) {
        pre[i + 1] = pre[i] + nums[i];
    }

    Deque<Integer> deque = new ArrayDeque<>();
    int minLen = Integer.MAX_VALUE;

    for (int i = 0; i <= n; i++) {
        // ① 队首满足条件 → 更新答案并弹出（越早的越好）
        while (!deque.isEmpty() && pre[i] - pre[deque.peekFirst()] >= k) {
            minLen = Math.min(minLen, i - deque.pollFirst());
        }
        // ② 维护单调递增：弹出 ≥ pre[i] 的（更大且更晚 → 不可能最优）
        while (!deque.isEmpty() && pre[deque.peekLast()] >= pre[i]) {
            deque.pollLast();
        }
        deque.offerLast(i);
    }
    return minLen == Integer.MAX_VALUE ? -1 : minLen;
}
// 为什么"更大且更晚"被淘汰？
//   更大 → 更难满足 ≥ k；更晚 → 距离更短
//   → 两个维度都输 → 永久淘汰
// ⚠️ 含负数 → 前缀和不单调 → 单调队列是唯一 O(n) 解
```

### 4.2 1499. 满足不等式的最大值

```java
/**
 * LeetCode 1499. 满足不等式的最大值（Hard）
 * 求 max(xj - xi + yi + yj) 其中 xj - xi ≤ k
 *
 * 拆分变量：
 *   = (yi - xi) + (xj + yj)
 *   单调队列维护 (yi - xi) 的最大值（窗口内）
 */
public int findMaxValueOfEquation(int[][] points, int k) {
    Deque<int[]> deque = new ArrayDeque<>();   // [x, y-x]
    int maxVal = Integer.MIN_VALUE;

    for (int[] p : points) {
        int x = p[0], y = p[1];

        // ① 过期：xj - xi > k → 弹出
        while (!deque.isEmpty() && x - deque.peekFirst()[0] > k) {
            deque.pollFirst();
        }
        // ② 更新答案：队首 (y-x) 最大
        if (!deque.isEmpty()) {
            maxVal = Math.max(maxVal, x + y + deque.peekFirst()[1]);
        }
        // ③ 维护单调：弹出 (y-x) 更小的（更大且更晚 → 淘汰）
        while (!deque.isEmpty() && deque.peekLast()[1] <= y - x) {
            deque.pollLast();
        }
        deque.offerLast(new int[]{x, y - x});
    }
    return maxVal;
}
// ⚠️ 核心技巧：把 xi + yi 拆成两部分
//   yi - xi（左端点贡献）与 xj + yj（右端点贡献）
//   → 单调队列维护左端点的 (y-x) 最大值
```

### 4.3 变体问题识别清单

```
"窗口内最值" → 239 模板
"DP 转移需要窗口最值" → 1696/1425
"前缀和 + 最短 ≥ k" → 862（单调递增队列）
"可拆分的表达式最值" → 1499（拆分变量）

⚠️ 识别三步：
  ① 是否窗口/区间约束？
  ② 维护的是什么？（值/dp/前缀和/拆分项）
  ③ 单调方向？（递增/递减）
```

## 5. 单调队列 vs 单调栈 vs 双堆

### 5.1 三结构对比

| 维度 | 单调队列 | 单调栈 | 双堆 |
|------|:---:|:---:|:---:|
| 结构 | Deque（两端） | Stack（一端） | 两个堆 |
| 问题 | 窗口最值 | 下一个更大 | 中位数/TopK |
| 过期 | ✅ 窗口滑出 | ❌ 无 | 延迟删除 |
| 复杂度 | O(n) | O(n) | O(n log k) |
| 代表 | 239/1696 | 739/84 | 295/480 |

```
选型：
  "窗口 + 最值" → 单调队列（O(n) 最优）
  "下一个更大" → 单调栈
  "中位数/删除" → 双堆
```

### 5.2 与双堆的对比（480 滑动窗口中位数）

```
窗口内中位数：
  双堆：O(n log k)（堆操作 + 延迟删除）
  单调队列：不适用（中位数非最值）

⚠️ 选型判断：
  窗口最值（最大/最小）→ 单调队列
  窗口有序统计（中位数）→ 双堆
  "最值 vs 有序统计"是分水岭
```

### 5.3 什么时候单调队列不是最优

```
① 需要"删除指定元素" → 延迟删除麻烦 → 双堆
② 需要"第 K 大"（非最值）→ 有序结构
③ 窗口大小动态变化大 → 注意过期条件

⚠️ 面试表达：
"窗口最值问题单调队列 O(n) 最优；
 窗口有序统计（中位数）用双堆。"
```

## 6. 进阶总结

### 6.1 单调队列五连

| 题号 | 题目 | 维护内容 | 关键点 |
|:---:|------|------|------|
| 239 | 窗口最大值 | nums 值 | 三件套模板 |
| 1696 | 跳跃游戏 VI | dp 值 | DP 优化 |
| 1425 | 子序列和 | dp 值 + max(0) | 可选可不选 |
| 862 | 最短 ≥ K | 前缀和（递增） | 含负数 |
| 1499 | 不等式最大值 | 拆分项 y-x | 变量拆分 |

### 6.2 单调队列解题四步

```
① 识别窗口/区间约束
② 确定维护内容（值/dp/前缀和/拆分项）
③ 确定单调方向（递减取最大；递增取最小）
④ 三件套：入队淘汰 → 过期弹出 → 取头

⚠️ 过期条件的边界（含不含当前元素）：
  窗口 [i-k+1, i] → peekFirst <= i-k
  窗口 [i-k, i-1] → peekFirst < i-k
```

### 6.3 面试话术

```
"DP 转移需要窗口内最大值，
 我用单调队列优化：单调递减队列存下标，
 队头即窗口最大 dp。
 每个元素进出队各一次 → O(n)（暴力 O(nk)）。
 维护规则：晚到且优淘汰早到且劣——
 值更大且更晚过期，必然更优。"
```

> 🎯 **核心要点**：单调队列进阶 = **DP 窗口优化**（1696/1425）+ **变体识别**（862 前缀和/1499 拆分）。"晚到且优淘汰早到且劣"是统一原理；过期边界（< vs ≤）与维护内容（值/dp/前缀和）是两大易错点。
