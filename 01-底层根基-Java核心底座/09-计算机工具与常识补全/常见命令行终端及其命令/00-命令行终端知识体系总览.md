## 4. 核心概念速查

| 概念 | 一句话解释 |
|------|-----------|
| **终端模拟器** | 显示命令行的「壳」程序（Kitty/Windows Terminal/iTerm2） |
| **Shell** | 解析执行命令的解释器（bash/zsh/fish/PowerShell） |
| **Terminal vs Shell** | 终端是「屏幕」，Shell 是「大脑」——两者协作 |
| **启动流程** | 登录 Shell → .bash_profile → .bashrc（配置加载顺序） |
| **alias** | 命令别名（`gs` = `git status`）——效率第一步 |
| **fzf** | 通用模糊查找器——文件/历史/进程全可搜 |
| **tmux** | 终端复用器——一个终端多窗口/会话持久化 |
| **Ctrl+R** | 历史命令反向搜索（配合 fzf 更强） |
| **增强工具链** | eza/fd/rg/bat 替代 ls/find/grep/cat（2026 主流） |
| **starship** | 跨 Shell 提示符（显示 git 分支/状态） |
| **cron / 计划任务** | 定时执行脚本（Linux cron / Windows 计划任务） |
| **shebang** | `#!/bin/bash` 脚本解释器声明 |
