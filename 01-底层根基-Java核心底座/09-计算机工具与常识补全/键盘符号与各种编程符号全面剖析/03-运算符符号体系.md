## 1. 运算符分类总览

> **背景**：运算符是符号的「动作语义」——编译器按符号执行对应操作。
> **目的**：系统掌握六类运算符 + 优先级，写对表达式、读对代码。
> **适用范围**：Java 全部；C/JS 等 C 系语言大部分通用。
> **不适用场景**：重载后的运算符（语义由类决定，如 String 的 `+`）。

| 类别 | 符号 | 作用 |
|------|------|------|
| **算术** | `+ - * / %` | 数学运算 |
| **赋值** | `= += -= *= /= %=` | 变量赋值 |
| **比较** | `== != > < >= <=` | 值比较 |
| **逻辑** | `&& \|\| !` | 布尔逻辑 |
| **位运算** | `& \| ^ ~ << >> >>>` | 二进制位操作 |
| **其他** | `?: instanceof 类型转换` | 三元/类型判断/转换 |

## 2. 算术运算符

### 2.1 基本算术

```java
int a = 10, b = 3;
a + b    // 13  加法
a - b    // 7   减法
a * b    // 30  乘法
a / b    // 3   ⚠️ 整数除法（结果截断！10/3=3 而非 3.33）
a % b    // 1   取余（模运算）

// 整数除法陷阱
double d = 10 / 3;        // ⚠️ 结果是 3.0 不是 3.33！（先整数除再转）
double d2 = 10.0 / 3;     // ✅ 3.33（浮点参与）
double d3 = (double) 10 / 3;  // ✅ 3.33
```

### 2.2 自增自减（++/--）

```java
int i = 5;
i++      // 后置：先取值再自增（表达式值为 5，i 变 6）
++i      // 前置：先自增再取值（i 变 7，表达式值为 7）

// 经典陷阱（面试必考）
int x = 5;
int y = x++ + ++x;    // x++ 值为 5（x 变 6）→ ++x 值为 7（x 变 7）→ y = 12
// 建议：表达式里不要混用 ++——可读性灾难
```

### 2.3 字符串拼接 `+`

```java
// + 的双重身份（重载）
int a = 1 + 2;              // 加法（数值）
String s = "a" + "b";       // 拼接（字符串）
String s2 = "值=" + 42;     // 拼接（数值转字符串）

// 拼接顺序陷阱
System.out.println(1 + 2 + "=");     // "3="（先加后拼）
System.out.println("=" + 1 + 2);     // "=12"（从左到右拼接！）
```

## 3. 赋值运算符

```java
// 基础赋值
int x = 10;        // = 赋值

// 复合赋值（= 与算术组合）
x += 5;    // x = x + 5
x -= 2;    // x = x - 2
x *= 3;    // x = x * 3
x /= 4;    // x = x / 4
x %= 2;    // x = x % 2

// 复合赋值的隐式转换（陷阱）
short s = 10;
s += 5;         // ✅ 复合赋值自动转换
// s = s + 5;   // ❌ 编译错误（int 不能赋给 short）
// 复合赋值隐含了类型转换：s = (short)(s + 5)
```

## 4. 比较运算符

### 4.1 基本比较

```java
int a = 5, b = 10;
a == b    // false  相等
a != b    // true   不等
a > b     // false  大于
a < b     // true   小于
a >= b    // false  大于等于
a <= b    // true   小于等于
```

### 4.2 `==` vs `equals`（Java 第一符号坑）

> ⚠️ **Java 面试必考**：`==` 比较「引用是否相同」；`equals` 比较「内容是否相同」：

```java
// 基本类型：== 比较值 ✅
int a = 1, b = 1;
a == b    // true（值相等）

// 引用类型：== 比较引用（地址）！
String s1 = new String("abc");
String s2 = new String("abc");
s1 == s2          // ❌ false（两个不同对象）
s1.equals(s2)     // ✅ true（内容相同）

// 字符串常量池（陷阱升级版）
String s3 = "abc";          // 常量池
String s4 = "abc";          // 常量池（同一对象）
s3 == s4          // ✅ true（常量池复用）——看起来像「== 能用」！
// ⚠️ 但 new String("abc") 与常量不相等——永远用 equals 比较内容

// 结论：字符串比较一律 equals（== 用于基本类型与 null 判断）
```

### 4.3 null 比较

```java
String s = null;
s == null         // ✅ true（null 判断用 ==）
// s.equals(null) // ❌ NPE！（null 上调用方法）
// 安全写法：Objects.equals(s, other)（两参都判空）
```

## 5. 逻辑运算符与短路

### 5.1 三种逻辑运算

```java
boolean a = true, b = false;

!a          // false   逻辑非（取反）
a && b      // false   逻辑与（且）
a || b      // true    逻辑或（或）
```

### 5.2 短路求值（&& 和 || 的核心特性）

> 🎯 **短路**：`&&` 左边为 false 时右边不执行；`||` 左边为 true 时右边不执行：

```java
// 短路的实战价值（防 NPE）
String s = null;
if (s != null && s.length() > 0) {   // ✅ 安全：s != null 为 false → 右边不执行
    ...
}
// 如果不用短路：if (s.length() > 0 && s != null) → NPE！（先执行了 length）

// 短路的副作用（面试题）
boolean flag = false;
int count = 0;
flag && (count++ > 0);    // count 不变！（右边没执行）
flag || (count++ > 0);    // count 变 1！（右边执行了）
```

### 5.3 逻辑 vs 位运算（& 和 && 的区别）

```text
& 与 && 的区别（面试高频）
├── & ：按位与（整数）/逻辑与（不短路——两边都执行！）
├── &&：短路与（左边 false 右边不执行）
├── | ：按位或（整数）/逻辑或（不短路）
├── ||：短路或
└── 使用：布尔逻辑用 && / ||（短路安全）；位操作才用 & / |
```

## 6. 位运算符

### 6.1 六种位运算

```java
// 按位操作（二进制视角）
int a = 0b1100;    // 12（二进制 1100）
int b = 0b1010;    // 10（二进制 1010）

a & b     // 0b1000 = 8    按位与（都为 1 才 1）
a | b     // 0b1110 = 14   按位或（有 1 即 1）
a ^ b     // 0b0110 = 6    按位异或（不同为 1）
~a        // 取反（所有位翻转）

// 移位
a << 2    // 左移 2 位（×4）= 48
a >> 2    // 右移 2 位（÷4，保留符号）= 3
a >>> 2   // 无符号右移（高位补 0）
```

### 6.2 位运算实战场景

```text
位运算的经典用途
├── ① 权限标志（位掩码）：READ=1, WRITE=2, EXEC=4
│   int perms = READ | WRITE;          // 组合
│   (perms & WRITE) != 0               // 判断是否有 WRITE
├── ② 快速乘除 2 的幂：x << 3 = x*8 / x >> 1 = x/2
├── ③ 异或交换（面试题）：a ^= b; b ^= a; a ^= b;
├── ④ 判断奇偶：(x & 1) == 1 奇数
└── ⑤ 颜色 RGB 提取：(color >> 16) & 0xFF 红色分量
```

## 7. 其他运算符：三元/instanceof/类型转换

### 7.1 三元运算符（唯一三元）

```java
// 语法：条件 ? 值1 : 值2
int max = (a > b) ? a : b;      // 取较大值
String msg = (age >= 18) ? "成年" : "未成年";

// 嵌套三元（可读性警告）
int grade = (score >= 90) ? 'A'
          : (score >= 80) ? 'B'
          : (score >= 70) ? 'C' : 'D';
// ⚠️ 超过两层嵌套建议改用 if-else（可读性）
```

### 7.2 instanceof（类型判断）

```java
Object obj = "hello";
if (obj instanceof String) {           // 类型判断
    String s = (String) obj;           // 类型转换
}

// Java 16+ 模式匹配（新写法）
if (obj instanceof String s) {         // 判断 + 直接绑定变量
    System.out.println(s.length());    // 无需手动转换
}

// 类型转换
int x = (int) 3.9;         // 强制转换（截断 = 3）
double d = 10;             // 隐式转换（int → double）
String num = String.valueOf(42);   // 数值转字符串
```

## 8. 运算符优先级表

```text
优先级（高 → 低，面试与读码必背）
─────────────────────────────────────
() [] .         括号/索引/成员（最高）
++ -- ! ~       一元/自增/取反
* / %           乘除取余
+ -             加减
<< >> >>>       移位
< > <= >= instanceof   比较
== !=           相等
&               按位与
^               按位异或
|               按位或
&&              逻辑与
||              逻辑或
?:              三元
= += -= ...     赋值（最低）
─────────────────────────────────────

记忆口诀：括号一元 → 乘除 → 加减 → 移位 → 比较 → 相等
         → 位与 → 异或 → 位或 → 逻辑与 → 逻辑或 → 三元 → 赋值

⚠️ 实战建议：复杂表达式加括号（可读性 > 记优先级）
```

## 9. 运算符易错陷阱

| # | 陷阱 | 表现 | 解法 |
|---|------|------|------|
| 1 | **`=` vs `==`** | `if (x = 5)` 赋值而非比较 | 条件里用 ==；常量放左边 `5 == x` |
| 2 | **整数除法** | 10/3=3（截断） | 浮点参与：10.0/3 |
| 3 | **`==` 比较字符串** | 内容相同但 false | 用 equals |
| 4 | **短路与位运算混** | `&` 不短路导致 NPE | 布尔用 `&&`/`\|\|` |
| 5 | **自增混在表达式** | 结果难预测 | 单独一行写 ++ |
| 6 | **复合赋值隐式转换** | short += int 行为诡异 | 了解 `s = (short)(s+5)` 语义 |
| 7 | **字符串拼接顺序** | "=" + 1 + 2 = "=12" | 注意从左到右 |
| 8 | **移位负数** | `>>` 保留符号位 | 无符号右移用 `>>>` |
| 9 | **位运算优先级** | `a & b == 0` 歧义 | 加括号 `(a & b) == 0` |
| 10 | **三元嵌套** | 可读性灾难 | 超两层用 if-else |

## 10. 核心要点

> 🎯 **核心要点**：
> 1. 六类运算符：算术/赋值/比较/逻辑/位/其他——每类的符号与语义要成体系
> 2. **Java 第一符号坑**：`==` 比较引用、`equals` 比较内容——字符串永远 equals（常量池会让 `==` 偶尔「碰巧对」）
> 3. 短路求值（&&/||）是防 NPE 利器——「null 检查放左边」
> 4. `+` 双重身份（加法/拼接）——拼接顺序从左到右
> 5. 优先级口诀 + 实战加括号——可读性 > 记优先级
> 6. 位运算实战：权限掩码/奇偶判断/颜色提取——面试高频场景
