## 4. 核心概念速查

| 概念 | 一句话解释 |
|------|-----------|
| **符号三重身份** | 英文名（沟通）+ 中文名（交流）+ 编程语义（代码） |
| **括号四家族** | () 圆括号（分组）/[] 方括号（数组索引）/{} 花括号（代码块）/\<\> 尖括号（泛型） |
| **引号三兄弟** | " 双引号（字符串）/ ' 单引号（字符）/ ` 反引号（模板/命令） |
| **运算符六类** | 算术/赋值/比较/逻辑/位/三元——Java 每类有专属符号 |
| **转义字符** | `\` 开头的特殊序列（\n 换行/\t 制表/\\ 反斜杠） |
| **Unicode 转义** | `\uXXXX` 表示任意 Unicode 字符 |
| **Shebang** | `#!` 脚本解释器声明（Linux 首行） |
| **短路求值** | `&&`/`\|\|` 短路——Java 与 C 的区别点 |
| **`==` vs `equals`** | 引用比较 vs 内容比较——Java 最高频符号坑 |
| **三元运算符** | `条件 ? 值1 : 值2`——Java 唯一三元运算符 |
