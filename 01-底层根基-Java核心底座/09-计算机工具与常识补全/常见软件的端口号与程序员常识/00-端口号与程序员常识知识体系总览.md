## 4. 核心概念速查

| 概念 | 一句话解释 |
|------|-----------|
| **端口号** | 传输层服务访问点（0-65535）——服务的「门牌号」 |
| **公认端口** | 0-1023：标准协议（HTTP 80/HTTPS 443）——需 root 绑定 |
| **注册端口** | 1024-49151：主流应用（MySQL 3306/Redis 6379） |
| **动态端口** | 49152-65535：客户端临时端口 |
| **TCP vs UDP 端口** | 独立空间——同一端口可同时用于 TCP 与 UDP（DNS 53） |
| **127.0.0.1** | 本机回环地址（localhost）——本机服务测试 |
| **0.0.0.0** | 所有接口——对外提供服务时绑定 |
| **端口占用** | 端口被进程绑定——第二个进程绑定失败 |
| **监听（LISTEN）** | 服务在端口等待连接的状态 |
| **高危端口** | 445/3389/6379/2375 等——公网暴露 = 高危 |
| **端口冲突** | 两个服务争同一端口——最常见的启动失败原因 |
