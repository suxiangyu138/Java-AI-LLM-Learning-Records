## 1. 基础编辑五件套

> **背景**：Ctrl+C/V/X/Z/S 是全应用通用的「肌肉记忆基础」——任何软件都认。
> **目的**：先形成五件套的条件反射，再扩展进阶技巧。
> **适用范围**：所有应用（Windows 系统级行为）。
> **不适用场景**：终端（Ctrl+C 是中断信号！见 05 篇）。

| 快捷键 | 功能 | 别名/说明 |
|:---:|------|---------|
| `Ctrl+C` | 复制 | Ctrl+Insert 等价 |
| `Ctrl+V` | 粘贴 | Shift+Insert 等价 |
| `Ctrl+X` | 剪切 | |
| `Ctrl+Z` | 撤销 | 全应用通用 |
| `Ctrl+Y` | 重做 | 部分应用用 Ctrl+Shift+Z |
| `Ctrl+A` | 全选 | 当前窗口全部 |
| `Ctrl+S` | **保存** | 打工人「保命键」——养成随手按 |

> 🎯 **习惯培养**：**Ctrl+S 是最高频的「保命键」**——每完成一个逻辑块就按一次，养成条件反射（配合 IDE 自动保存双保险）。

## 2. 剪贴板进阶

### 2.1 粘贴变体

```text
粘贴三兄弟
├── Ctrl+V         普通粘贴（带格式）
├── Ctrl+Shift+V   粘贴无格式文本（去掉格式——文档排版神器！）
└── Win+V          剪贴板历史（2026 效率利器，见 02 篇）

使用场景
├── 从网页复制到 Word/邮件 → Ctrl+Shift+V（保持目标格式）
├── 从代码复制到文档 → Ctrl+Shift+V（不带高亮/行号）
└── 多次复制后找旧的 → Win+V 历史选择
```

### 2.2 剪贴板历史（Win+V）

```text
Win+V 剪贴板历史（Windows 10+）
├── ① 记录最近多条复制内容（文本/图片）
├── ② 按 Win+V 弹出历史面板 → 选择粘贴
├── ③ 可固定常用条目（置顶）
├── ④ 支持跨设备同步（微软账号）
└── ⑤ 开发场景：复用命令/报错信息/临时片段

开启方式：设置 → 系统 → 剪贴板 → 剪贴板历史（开）
```

## 3. 文本选择技巧

### 3.1 基础选择

| 快捷键 | 功能 |
|:---:|------|
| `Shift+←/→` | 逐字符选择 |
| `Shift+↑/↓` | 逐行选择 |
| `Ctrl+Shift+←/→` | **按词选择**（效率核心！） |
| `Shift+Home/End` | 选择到行首/行尾 |
| `Ctrl+Shift+Home/End` | 选择到文档开头/结尾 |
| `Ctrl+A` | 全选 |

### 3.2 选择效率对比

```text
选择一段文本的效率对比
├── 鼠标拖选：精确但慢（手离开键盘）
├── 基础选择：Shift+方向（逐字符慢）
├── 词级选择：Ctrl+Shift+方向（按词快）
└── 目标：Ctrl+Shift+→ 词级选择成为肌肉记忆

典型操作（改一个变量名）：
① Ctrl+Shift+→ 选中单词
② 直接输入新名字（覆盖选中）
③ 或 Ctrl+C 复制 → 别处 Ctrl+V
```

## 4. 光标移动进阶

### 4.1 词级与行级移动

| 快捷键 | 功能 | 效率 |
|:---:|------|:---:|
| `Ctrl+←/→` | 按词移动光标 | ⭐⭐⭐ |
| `Home/End` | 行首/行尾 | ⭐⭐⭐ |
| `Ctrl+Home/End` | 文档开头/结尾 | ⭐⭐⭐ |
| `PageUp/PageDown` | 翻页 | ⭐⭐ |
| `Ctrl+G` | **跳转到指定行**（编辑器） | ⭐⭐⭐⭐ |

### 4.2 跳转（Ctrl+G）

```text
Ctrl+G 跳转行的场景（程序员高频）
├── ① IDE 报错跳转：错误信息给行号 → Ctrl+G 输入
├── ② 日志定位：日志输出行号 → 跳转查看
├── ③ 大文件导航：直接跳到目标区域
├── ④ IDEA：Ctrl+G 输入行:列（更精确）
└── ⑤ VS Code：Ctrl+G 同功能
```

> 🎯 **光标移动的进阶认知**：**鼠标点击 vs 快捷键移动——差距在「手离开键盘」**——词级移动（Ctrl+方向）是文本操作的第一效率升级点。

## 5. 查找替换

### 5.1 基础查找

| 快捷键 | 功能 |
|:---:|------|
| `Ctrl+F` | 查找（当前文档） |
| `Ctrl+H` | 替换 |
| `F3` | 查找下一个 |
| `Shift+F3` | 查找上一个 |
| `Ctrl+Shift+F` | 全局搜索（IDE，见 04 篇） |

### 5.2 查找的进阶用法

```text
查找技巧（2026 编辑器通用）
├── ① 选中文本直接 F3：无需先 Ctrl+F（选中即查找）
├── ② 正则查找：VS Code/IDEA 支持正则模式（Alt+R 切换）
├── ③ 大小写/全词匹配：Alt+C / Alt+W 切换
├── ④ 替换时用 $1 引用捕获组（正则替换）
└── ⑤ 批量替换确认：逐个确认（Alt+Enter 全部替换）
```

## 6. 多光标编辑（2026 效率核心）

### 6.1 多光标是什么

> 🎯 **多光标编辑**：同时编辑多个位置——批量修改同一模式文本的最快方式（2026 主流编辑器标配）。

### 6.2 常用操作（VS Code/IDEA）

```text
多光标操作
├── ① Alt+Click：在多个位置添加光标（任意位置）
├── ② Ctrl+D：选中下一个相同词（逐个添加）
├── ③ Ctrl+Shift+L：选中所有匹配项（一次性全选）
├── ④ Alt+Shift+↑/↓：向上/下复制当前行
└── ⑤ Ctrl+Alt+↑/↓：向上下添加光标（列编辑）

实战场景（批量修改）
├── 批量加前缀：选中所有行 → 光标在行首 → 输入
├── 批量改变量名：Ctrl+Shift+L 全选匹配 → 输入新名
├── 批量加引号：Alt+Click 多个词 → 输入 "
└── 批量加逗号/分号：列编辑模式添加
```

### 6.3 多光标 vs 查找替换

```text
选型的判断
├── 相同文本多次 → 查找替换（Ctrl+H）更快
├── 不同位置加相同内容 → 多光标（Alt+Click）
├── 批量改同名单词 → Ctrl+Shift+L（多光标式全选）
└── 组合：先 Ctrl+F 找到模式 → 再多光标处理
```

### 7.2 撤销的高级用法

```text

├── ① 普通撤销：Ctrl+Z 逐步回退（通用）
```

## 8. 保命键习惯

### 8.1 五个保命习惯

```text
保命键习惯（形成条件反射）
├── ① Ctrl+S：每完成一个逻辑块保存
├── ② Ctrl+Z：误操作立即撤销（不要慌）
├── ③ Ctrl+Shift+Z：撤销过头了重做
├── ④ Win+L：离开工位锁屏（数据安全）
├── ⑤ Ctrl+Shift+Esc：卡死秒开任务管理器
└── 金句：快捷键的终极价值不是快，是「条件反射」——
    遇到情况手指自动按下，不假思索
```

### 8.2 常见误区

```text
快捷键使用误区
├── ⚠️ 终端里 Ctrl+C 是中断不是复制！（用 Ctrl+Shift+C）
├── ⚠️ Ctrl+S 在部分网页是「保存页面」（浏览器可改）
├── ⚠️ 中文输入法占用快捷键：Ctrl+Space 等被输入法拦截
├── ⚠️ 不同应用同一快捷键含义不同（Ctrl+D 收藏 vs 多光标）
└── 解法：先确认当前应用语境，再按快捷键
```

## 9. 核心要点

> 🎯 **核心要点**：
> 1. 五件套（C/V/X/Z/S）是肌肉记忆基础——**Ctrl+S 保命键条件反射**
> 2. 剪贴板进阶：Ctrl+Shift+V 无格式粘贴 + Win+V 剪贴板历史（2026 效率利器）
> 3. 选择效率：词级选择（Ctrl+Shift+方向）> 字符选择 > 鼠标拖选
> 4. 多光标编辑（Alt+Click/Ctrl+D/Ctrl+Shift+L）是批量修改的最快方式
> 5. 跳转（Ctrl+G）与查找（F3 选中即查）——文本导航双剑
> 6. 语境陷阱：终端 Ctrl+C 是中断、中文输入法抢占快捷键——先看语境再按键
