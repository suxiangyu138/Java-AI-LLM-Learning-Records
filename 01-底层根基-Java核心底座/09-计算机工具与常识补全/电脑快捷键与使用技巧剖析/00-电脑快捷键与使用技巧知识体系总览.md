## 4. 核心概念速查

| 概念 | 一句话解释 |
|------|-----------|
| **Ctrl 系** | 编辑操作（复制/粘贴/撤销/查找）——全应用通用 |
| **Win 系** | 系统操作（运行/搜索/截图/虚拟桌面）——Windows 专属 |
| **Alt 系** | 窗口操作（切换/关闭/系统菜单） |
| **F 系** | 功能键（F2 重命名/F5 刷新/F12 跳转定义） |
| **Alt+Tab** | 窗口切换（按住 Alt 连按 Tab 预览） |
| **Win+V** | 剪贴板历史（多条复制记录复用） |
| **Win+Shift+S** | 区域截图（文档/提 Bug 高频） |
| **虚拟桌面** | Win+Ctrl+D 新建——任务/环境隔离 |
| **多光标编辑** | Alt+Click / Ctrl+D——批量修改利器 |
| **Ctrl+R** | 终端历史反向搜索 |
| **AutoHotkey** | 自定义快捷键/宏的自动化工具 |
| **盲操作** | 键盘熟练后的目标状态（减少 30%+ 鼠标移动） |

## 5. 一图看懂：程序员一天的高效操作

```text
程序员高效工作流（快捷键版）
├── 08:30  Win+E 打开项目目录 → Win+R 启动 IDE
├── 09:00  IDE：Ctrl+P 快速开文件 → F12 跳定义 → Ctrl+- 返回
├── 09:30  Ctrl+Shift+F 全局搜索 → F2 重命名 → Ctrl+D 多光标修改
├── 10:00  终端：Ctrl+R 搜历史 → Tab 补全 → Ctrl+L 清屏
├── 11:00  浏览器：Ctrl+L 地址栏 → Ctrl+Shift+T 恢复标签
├── 14:00  Alt+Tab 切换 → Win+V 复用报错信息 → Win+Shift+S 截图
├── 15:00  多任务：Win+Ctrl+D 新建虚拟桌面（隔离任务）
├── 16:00  Ctrl+Shift+Esc 查资源占用 → Win+L 锁定离开
└── 金句：每个快捷键省 2 秒——一天 200 次 = 省 400 秒 ≈ 7 分钟
```
