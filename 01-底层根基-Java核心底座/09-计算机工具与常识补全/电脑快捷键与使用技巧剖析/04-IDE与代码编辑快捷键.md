## 1. IDE 快捷键体系设计

> **背景**：现代 IDE（IDEA/VS Code）的快捷键按「操作类型」组织——导航、编辑、重构、搜索、运行。
> **目的**：建立「操作 → 快捷键」的映射体系，实现键盘驱动开发。
> **适用范围**：IDEA（Java 主）与 VS Code（全栈）双生态。
> **不适用场景**：纯文本编辑（系统快捷键足够，见 01 篇）。

```text
IDE 快捷键五大域
├── ① 导航：F12（定义）/ Ctrl+P（文件）/ Ctrl+G（行）
├── ② 编辑：Ctrl+D（复制行）/ Alt+方向（移动行）
├── ③ 重构：F2（重命名）/ Ctrl+.（快速修复）
├── ④ 搜索：Ctrl+Shift+F（全局）/ Ctrl+Shift+O（符号）
└── ⑤ 运行：Shift+F10（运行）/ Shift+F9（调试）
→ 金句：IDE 快捷键 = 鼠标的替代品——熟练后 90% 操作不碰鼠标
```

## 2. 代码导航（核心）

### 2.1 导航快捷键（IDEA 与 VS Code 通用）

| 快捷键 | 功能 | 场景 |
|:---:|------|------|
| `F12` | 跳转到定义 | 看方法实现 |
| `Alt+F12` | 快速预览定义（Peek） | 不离开当前位置 |
| `Shift+F12` | 查找引用 | 谁调用了它 |
| `Ctrl+-` / `Ctrl+Shift+-` | 后退/前进 | 导航历史返回 |
| `Ctrl+P` | **快速打开文件** | 按文件名秒开 |
| `Ctrl+Shift+O`（IDEA） | 搜索符号/方法 | 按方法名跳转 |
| `Ctrl+G` | 跳转行 | 报错定位 |
| `Alt+←/→` | 上一个/下一个位置（IDEA） | 编辑位置跳转 |

### 2.2 导航工作流（改 Bug 场景）

```text
改 Bug 的键盘工作流
├── ① Ctrl+Shift+F 全局搜索错误关键字
├── ② 点击结果（或 Enter）进入文件
├── ③ F12 跳转到相关方法定义
├── ④ Shift+F12 查看谁调用了它（影响面）
├── ⑤ F2 安全重命名（如需改名）
├── ⑥ Ctrl+- 返回调用点验证
└── ⑦ Shift+F10 运行测试验证
→ 全程键盘（0 次鼠标）——导航快捷键是 IDE 效率第一杠杆
```

## 3. 编辑与重构

### 3.1 编辑快捷键（IDEA）

| 快捷键 | 功能 |
|:---:|------|
| `Ctrl+D` | 复制当前行到下一行 |
| `Ctrl+Y` | 删除当前行 |
| `Alt+↑/↓` | 移动当前行上下 |
| `Shift+Alt+↑/↓` | 复制当前行上下 |
| `Ctrl+/` | 单行注释切换 |
| `Ctrl+Shift+/` | 块注释切换 |
| `Ctrl+Alt+L` | 格式化代码 |
| `Ctrl+Shift+U` | 大小写切换 |
| `Ctrl+Shift+J` | 合并行 |
| `Tab/Shift+Tab` | 缩进/反缩进 |
| `Ctrl+Alt+I` | 自动缩进 |

### 3.2 重构快捷键

| 快捷键 | 功能 | 场景 |
|:---:|------|------|
| `F2` | **重命名**（安全重构） | 变量/方法/类改名 |
| `Ctrl+.`（IDEA） | 快速修复/代码动作 | 自动修复建议 |
| `Ctrl+Alt+M` | 提取方法 | 长方法拆分 |
| `Ctrl+Alt+V` | 提取变量 | 魔法值提取 |
| `Ctrl+Alt+C` | 提取常量 | |
| `Ctrl+Alt+P` | 提取参数 | |
| `Alt+Enter` | **显示意图操作**（IDEA 万能键） | 修复/优化/生成 |

> 🎯 **IDEA 的 Alt+Enter（万能意图键）**：光标处按 Alt+Enter → 弹出所有可用操作（修复错误/优化/生成代码）——**遇到任何问题先按 Alt+Enter**，它是 IDEA 的「快捷键之首」。

## 4. 搜索体系

### 4.1 四级搜索

| 快捷键 | 范围 | 功能 |
|:---:|------|------|
| `Ctrl+F` | 当前文件 | 查找 |
| `Ctrl+Shift+F` | **全局** | 整个项目搜索 |
| `Ctrl+R` | 当前文件 | 替换 |
| `Ctrl+Shift+R` | 全局 | 全局替换 |
| `Ctrl+Shift+O` | 符号 | 按方法/类名跳转（IDEA） |
| `Ctrl+P` | 文件 | 按文件名打开 |

### 4.2 搜索的进阶用法

```text
全局搜索技巧（Ctrl+Shift+F）
├── ① 正则模式：复杂模式搜索（Alt+R 切换）
├── ② 范围限定：目录/文件类型（搜索前选择）
├── ③ 排除：!排除模式（搜索框输入 !test）
├── ④ 结果导航：结果面板 F4 跳转到文件
├── ⑤ 复制搜索结果：右键导出
└── ⑥ 搜索历史：最近搜索快速复用

VS Code 专属
├── Ctrl+P 输入 > ：命令面板（执行命令）
├── Ctrl+P 输入 @ ：跳转到符号（当前文件）
├── Ctrl+P 输入 # ：全局符号搜索
└── Ctrl+P 输入 :行号 ：跳转行（组合）
```

## 5. 多光标与批量编辑

### 5.1 多光标快捷键（VS Code 与 IDEA 对照）

| 操作 | VS Code | IDEA |
|------|:---:|:---:|
| 添加光标 | `Alt+Click` | `Alt+Click` |
| 选中下一个相同词 | `Ctrl+D` | `Alt+J` |
| 全选所有匹配 | `Ctrl+Shift+L` | `Ctrl+Alt+Shift+J` |
| 向上/下复制行 | `Shift+Alt+↑/↓` | `Ctrl+D`（复制行） |
| 列编辑 | `Shift+Alt+拖拽` | `Alt+Shift+拖拽` |

### 5.2 批量编辑实战

```text
场景 1：批量加前缀（多行行首加 // 注释）
├── Alt+Shift+拖拽 选中多行行首列
├── 输入 //（所有行同时生效）

场景 2：批量改同名单词
├── Ctrl+D 逐个选中（可控）或 Ctrl+Shift+L 全选（全量）
├── 直接输入新名（所有光标处替换）

场景 3：批量加引号
├── Alt+Click 逐个点击目标词
├── 输入 "（每个词被包裹）

场景 4：批量改格式（加逗号/分号）
├── 列编辑模式选中列位置
├── 输入符号（整列生效）
```

## 6. IDEA vs VS Code 对照

### 6.1 核心快捷键对照表

| 功能 | IntelliJ IDEA | VS Code |
|------|:---:|:---:|
| 快速打开文件 | `Ctrl+Shift+N` | `Ctrl+P` |
| 全局搜索 | `Ctrl+Shift+F` | `Ctrl+Shift+F` |
| 跳转定义 | `Ctrl+Alt+B`（实现）/`Ctrl+B` | `F12` |
| 查找引用 | `Alt+F7` | `Shift+F12` |
| 重命名 | `Shift+F6` | `F2` |
| 快速修复 | `Alt+Enter` | `Ctrl+.` |
| 运行 | `Shift+F10` | `F5` |
| 调试 | `Shift+F9` | `F5`（调试配置） |
| 格式化 | `Ctrl+Alt+L` | `Shift+Alt+F` |
| 复制行 | `Ctrl+D` | `Shift+Alt+↓` |
| 删除行 | `Ctrl+Y` | `Ctrl+Shift+K` |
| 终端开关 | `Alt+F12` | `Ctrl+` `` ` `` |
| 命令面板 | `Ctrl+Shift+A` | `Ctrl+Shift+P` |

### 6.2 双 IDE 工作流（2026 常见）

```text
双 IDE 的使用策略
├── Java 主开发 → IDEA（重构/调试生态最强）
├── 前端/脚本/全栈 → VS Code（轻量 + 生态丰富）
├── 同一台机器共存：快捷键冲突需适应（IDEA 键位 vs VS Code 键位）
├── VS Code 可切换键位方案：File → Preferences → Keymap
│   （选择 IntelliJ 风格——跨 IDE 无缝）
└── 金句：掌握「操作」而非「键位」——换 IDE 时查对照表即可
```

## 7. 快捷键学习路线

### 7.1 分级学习（按使用频率）

```text
IDE 快捷键分级学习
├── L1 必备（第 1 周，10 个）：
│   Ctrl+P 文件 / F12 定义 / Ctrl+Shift+F 全局搜 /
│   F2 重命名 / Ctrl+D 复制行 / Alt+Enter 修复 /
│   Ctrl+/ 注释 / Ctrl+Alt+L 格式化 / Shift+F10 运行 / Ctrl+Z
├── L2 提效（第 2 周，10 个）：
│   Shift+F12 引用 / Ctrl+- 返回 / Alt+↑↓ 移动行 /
│   Ctrl+Shift+O 符号 / Ctrl+G 跳行 / Ctrl+R 替换 /
│   Ctrl+. 快速修复 / 多光标 / Ctrl+W 扩展选择 / Ctrl+Shift+V 历史
└── L3 精通（持续，按需）：
    重构全家（提取方法/变量）/ 书签 / 断点调试 /
    自定义快捷键（Keymap 设置）

学习方法
├── ① 每周只加 3-5 个新快捷键（不贪多）
├── ② 刻意不用鼠标：卡住时查快捷键而非点鼠标
├── ③ IDE 内查看：Ctrl+Shift+A（IDEA）/ Ctrl+K Ctrl+S（VS Code）
└── ④ 冲突处理：Keymap 设置修改/搜索（见 07 篇）
```

### 7.2 效率自测

```text
IDE 快捷键自测（1 分钟内）
├── [ ] 按文件名打开文件（Ctrl+P/Ctrl+Shift+N）
├── [ ] 跳转到方法定义并返回（F12 + Ctrl+-）
├── [ ] 全局搜索并跳转（Ctrl+Shift+F → Enter）
├── [ ] 重命名变量（F2/Shift+F6）
├── [ ] 格式化代码（Ctrl+Alt+L）
├── [ ] 运行测试（Shift+F10/F5）
└── 6 项全过 = 键盘驱动开发入门
```

## 8. 核心要点

> 🎯 **核心要点**：
> 1. IDE 快捷键五大域：导航/编辑/重构/搜索/运行——**导航是效率第一杠杆**
> 2. 改 Bug 键盘工作流：全局搜 → 跳定义 → 查引用 → 重命名 → 返回 → 运行（全程零鼠标）
> 3. IDEA 的 Alt+Enter 是万能意图键——**遇到任何问题先按它**
> 4. 多光标批量编辑：Alt+Click/Ctrl+D/Ctrl+Shift+L——批量修改最快方式
> 5. 双 IDE 对照表 + VS Code 可切换 IntelliJ 键位——**掌握操作而非键位**
> 6. 学习路线：L1 十必备 → L2 十提效 → L3 按需；每周只加 3-5 个
