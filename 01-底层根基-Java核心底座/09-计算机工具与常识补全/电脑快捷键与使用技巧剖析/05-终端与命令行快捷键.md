## 1. 终端快捷键的独特性

> **背景**：终端（Shell）有自己的快捷键体系——源自 Unix 的 readline 库——与普通应用完全不同。
> **目的**：理解「终端语境」，避免 Ctrl+C 复制等经典错误。
> **适用范围**：Linux/macOS 终端（bash/zsh）；Windows 终端（PowerShell 兼容大部分）。
> **不适用场景**：普通 GUI 应用（用 01 篇的通用快捷键）。

```text
终端的「语境差异」——三个最坑的
├── ⚠️ Ctrl+C：中断当前命令（不是复制！）→ 复制用 Ctrl+Shift+C
├── ⚠️ Ctrl+V：字面粘贴/插入模式（不是粘贴！）→ 粘贴用 Ctrl+Shift+V
├── ⚠️ Ctrl+W：删除前一个词（不是关闭窗口！）
└── 金句：进终端先切换「终端语境」——通用快捷键在这里语义全变
```

## 2. 行编辑快捷键（Bash 风格）

### 2.1 光标移动

| 快捷键 | 功能 |
|:---:|------|
| `Ctrl+A` | 光标到行首 |
| `Ctrl+E` | 光标到行尾 |
| `Alt+B` | 后退一个词 |
| `Alt+F` | 前进一个词 |
| `Ctrl+←/→` | 按词移动（部分终端） |
| `Home/End` | 行首/行尾（兼容） |

### 2.2 编辑操作

| 快捷键 | 功能 |
|:---:|------|
| `Ctrl+W` | **删除前一个词** |
| `Alt+D` | 删除后一个词 |
| `Ctrl+U` | **删除到行首**（清空当前输入） |
| `Ctrl+K` | 删除到行尾 |
| `Ctrl+Y` | 粘贴刚删除的内容（yank） |
| `Ctrl+L` | **清屏**（保留当前输入） |
| `Ctrl+T` | 交换光标前后字符 |
| `Ctrl+_` | 撤销（readline） |

```bash
# 实用场景
# 命令输入一半想重来：Ctrl+U（清空）或 Ctrl+C（放弃整行）
# 命令太长改开头：Ctrl+A（行首）→ 修改 → Ctrl+E（行尾）
# 输错一个词：Ctrl+W 删词重输
```

## 3. 历史命令操作

### 3.1 历史基础

| 操作 | 功能 |
|:---:|------|
| `↑` / `↓` | 上一条/下一条历史 |
| `Ctrl+P` | 上一条历史（等价 ↑） |
| `Ctrl+N` | 下一条历史（等价 ↓） |
| `Ctrl+R` | **反向搜索历史** |
| `history` | 列出历史 |
| `!!` | 执行上一条命令 |
| `!$` | 上一条命令的最后一个参数 |

### 3.2 Ctrl+R 反向搜索（核心）

```text
Ctrl+R 反向搜索流程
├── ① 按 Ctrl+R → 提示符变为 (reverse-i-search)
├── ② 输入关键字 → 匹配最近的历史命令
├── ③ 再按 Ctrl+R → 继续回溯更早的匹配
├── ④ Enter 执行 / ← 编辑 / Ctrl+C 取消
└── 进阶：fzf 接管（见「常见命令行终端」系列 03 篇）
    → Ctrl+R 变成模糊搜索界面（更强）

实用技巧
├── 搜索关键字要独特（少字符高命中）
├── 搜到后想编辑：按 ← 或 Ctrl+E 进入编辑
└── 历史记忆：命令越复杂越值得搜（部署/构建命令）
```

### 3.3 历史的高级用法

```bash
!!                  # 执行上一条（sudo !! 提权重跑）
!123                # 执行历史第 123 条
!grep               # 执行最近以 grep 开头的命令
!$                  # 上一条命令最后一个参数
^old^new            # 替换上一条命令的文本并执行
# 例：docker run xxx → ^run^start（改为 start）

# 历史搜索的扩展（zsh）
# Ctrl+S 正向搜索（需配置） / history 管道 grep
history | grep docker    # 列出所有 docker 相关历史
```

## 4. 补全体系

### 4.1 基础补全

| 操作 | 功能 |
|:---:|------|
| `Tab` | **命令/路径补全**（终端第一效率键） |
| `Tab Tab` | 列出所有匹配（不唯一时） |
| `Alt+?` | 列出补全候选 |
| `Alt+*` | 展开所有匹配 |

### 4.2 补全的进阶（zsh/fish）

```text
补全能力对比
├── bash：基础补全（命令/路径）
├── zsh：增强补全（选项/参数/上下文感知）
│   └── git checkout <Tab> → 分支列表补全！
├── fish：自动补全（输入即提示，方向键接受）
└── 2026 建议：开发机 zsh/fish（补全效率差异明显）

Tab 补全场景
├── 路径补全：cd /usr/loc<Tab> → /usr/local/
├── 命令补全：git che<Tab> → git checkout
├── 参数补全（zsh）：ssh <Tab> → known_hosts 主机列表
└── 模糊补全（zsh）：cd pro<Tab> 匹配 project（fzf 增强）
```

## 5. 进程控制

### 5.1 前后台控制

| 快捷键 | 功能 |
|:---:|------|
| `Ctrl+C` | 中断当前前台进程 |
| `Ctrl+Z` | **挂起当前进程**（暂停） |
| `Ctrl+D` | 发送 EOF（退出 Shell/结束输入） |
| `fg` | 恢复挂起进程到前台 |
| `bg` | 恢复挂起进程到后台 |

```bash
# 场景：正在跑的服务想切走
# ① Ctrl+Z 挂起（进程暂停）
# ② bg 放到后台继续跑
# ③ fg 拉回前台
# 或更专业：Ctrl+Z → 用 tmux 管理（见终端系列）
```

### 5.2 进程控制注意

```text
⚠️ Ctrl+C vs Ctrl+Z 的区别
├── Ctrl+C：终止进程（SIGINT——进程可捕获）
├── Ctrl+Z：挂起进程（SIGTSTP——可恢复）
├── 场景：误启动长命令 → Ctrl+C 终止
├── 场景：临时切走 → Ctrl+Z + bg（继续跑）
└── 真正需要后台长期跑：nohup / tmux（会话级）
```

## 6. Windows 终端对照

### 6.1 Windows Terminal / PowerShell 快捷键

| 功能 | Linux（bash） | Windows Terminal |
|------|:---:|:---:|
| 复制 | Ctrl+Shift+C | Ctrl+Shift+C |
| 粘贴 | Ctrl+Shift+V | Ctrl+Shift+V |
| 中断 | Ctrl+C | Ctrl+C |
| 清屏 | Ctrl+L | Ctrl+L |
| 历史搜索 | Ctrl+R | Ctrl+R |
| 补全 | Tab | Tab |
| 新标签 | - | Ctrl+Shift+T |
| 新窗口 | - | Ctrl+Shift+N |
| 拆分窗格 | - | Alt+Shift+D（垂直）/Alt+Shift+-（水平） |
| 切换标签 | - | Ctrl+Tab |

### 6.2 PowerShell 的特色

```text
PowerShell 快捷键（与 bash 差异）
├── ① 粘贴：Ctrl+V（PowerShell 支持直接粘贴！）
├── ② 复制：Ctrl+C 选中后复制（上下文菜单）
├── ③ 删除词：Ctrl+Backspace / Ctrl+Delete
├── ④ 历史：↑↓ 与 Ctrl+R 同样支持
├── ⑤ 自动补全：Tab（模块/命令参数感知）
├── ⑥ 预测提示（PSReadLine）：灰色显示历史建议 → → 接受
└── 2026 建议：Windows 上用 Windows Terminal（多标签/分屏/主题）
```

## 7. 终端效率工作流

### 7.1 终端 + 快捷键组合

```text
高效终端会话（快捷键组合）
├── ① Ctrl+R 搜历史：部署命令/构建命令秒复用
├── ② Tab 补全：路径/命令不敲全
├── ③ Ctrl+U/Ctrl+K：输错快速清改
├── ④ Ctrl+L：输出刷屏快速清屏
├── ⑤ Ctrl+Z + bg：长任务切后台
├── ⑥ ↑ 快速重跑：重复命令两键
└── ⑦ 多标签（Windows Terminal）：Ctrl+Shift+T 新标签隔离任务
```

### 7.2 常见坑与排查

```text
终端快捷键常见坑
├── ⚠️ Ctrl+C 想复制 → 中断了命令（用 Ctrl+Shift+C）
├── ⚠️ Ctrl+V 想粘贴 → 出现 ^V（用 Ctrl+Shift+V）
├── ⚠️ 中文输入法抢占：Ctrl+Space 被输入法占用
│   → 终端内切英文（输入法设置）
├── ⚠️ Ctrl+R 在部分终端冲突（IDEA 终端需配置）
├── ⚠️ 粘贴多行命令：逐行执行风险（确认后再粘）
└── 排查：echo $SHELL 看 Shell 类型 → 对照对应快捷键
```

## 8. 核心要点

> 🎯 **核心要点**：
> 1. **终端语境**：Ctrl+C 中断/Ctrl+Shift+C 复制/Ctrl+Shift+V 粘贴——三个最坑的差异
> 2. 行编辑三件套：Ctrl+W（删词）/Ctrl+U（清行）/Ctrl+L（清屏）——输错快速改
> 3. Ctrl+R 反向搜索是历史操作核心——配合 fzf 变模糊搜索
> 4. Tab 补全是终端第一效率键——zsh/fish 的增强补全（git 分支列表）更值
> 5. Ctrl+Z 挂起 + bg/fg 前后台切换——长任务管理基础（长期用 tmux）
> 6. Windows Terminal：Ctrl+Shift+T 新标签 / Alt+Shift+D 分屏——多任务终端
