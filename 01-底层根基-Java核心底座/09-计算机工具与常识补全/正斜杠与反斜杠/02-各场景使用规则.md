## 1. 五场景规则全景

| # | 场景 | 用哪个 | 规则一句话 |
|---|------|:---:|-----------|
| 1 | **文件路径（跨平台代码）** | `/` | Windows 也认 `/`，Unix 只认 `/` |
| 2 | **URL / URI / HTTP** | `/` | 网络标准，`\` 非法 |
| 3 | **命令行参数** | `-`/`--` 为主 | 旧 Windows 用 `/`，新工具统一 `-` |
| 4 | **代码字符串** | `\\`（双写） | `\` 是转义符，不能单独写 |
| 5 | **正则表达式** | `\\` 或原始字符串 | 双重转义，最容易踩坑 |

> 🎯 **记忆口诀**：**网络和跨平台代码用 `/`；转义和 Windows 本地显示才用 `\`，且代码中不能单独书写反斜杠**。

## 2. 场景一：文件路径

### 2.1 规则

| 环境 | 分隔符 | 示例 |
|------|:---:|------|
| Linux/macOS | `/`（唯一） | `/home/user/project/src/Main.java` |
| Windows 原生 | `\` | `C:\Users\user\Desktop\a.txt` |
| **跨平台代码** | **`/`** | `"D:/data/orders.csv"`（Java/Node 都认） |

### 2.2 关键认知

```text
路径分隔符规则
├── Unix 系：/ 是唯一合法分隔符（\ 只是普通字符）
├── Windows：\ 是原生，但现代 Win32 API 兼容 /
├── 跨平台代码：写 /（Windows 能跑，Unix 也能跑）
└── 展示给用户：Windows 用户习惯 \（用系统 API 获取真实路径）

最佳实践（代码中）：
  Java:      File file = new File("D:/data/orders.csv");   // ✅
  Java:      File file = new File("D:\\data\\orders.csv"); // ⚠️ 能跑但难看
  Node.js:   fs.readFileSync("C:/Users/xxx/a.txt");        // ✅
  Python:    open("D:/data/a.csv")                          // ✅
```

> ⚠️ **规则**：**程序内部读写一律用 `/`；只有向 Windows 用户展示本地路径时才用 `\`**（由系统 API 生成，不是手写）。

## 3. 场景二：URL / URI

### 3.1 规则：只能 `/`

> 🎯 **URL 中反斜杠非法**——RFC 3986 规定 URL 路径分隔符只能是 `/`：

```text
✅ 正确：https://api.example.com/v1/users/42/orders
❌ 错误：https://api.example.com\v1\users\42\orders

浏览器行为：把 \ 自动修正为 /（Firefox 会提示）
服务器行为：\ 导致 404 或路由解析异常
```

### 3.2 各子场景

| 子场景 | 规则 | 示例 |
|--------|------|------|
| **HTTP URL** | 只能 `/` | `https://host/api/v1` |
| **相对路径引用** | `/` 开头 = 根路径 | `src="/assets/app.js"` |
| **Java 类路径资源** | `/`（类路径分隔） | `classpath:/config/app.yml` |
| **Spring 路由映射** | `/` | `@GetMapping("/api/users")` |
| **Nginx 代理** | `/` | `location /api/ { proxy_pass ...; }` |
| **Maven 仓库坐标** | `/` | `groupId/artifactId/version` |
| **Docker 镜像标签** | `/` | `registry.example.com/app:v1` |

### 3.3 URL 编码中的斜杠

```text
URL 中的特殊字符需要百分号编码
├── / 在路径中：正常使用
├── %2F：编码后的 /（用在参数值里！）
│   https://api.example.com/search?path=a%2Fb   ← 参数值中的 /
├── %5C：编码后的 \（罕见但存在）
└── 为什么参数值里的 / 要编码？
    → 否则服务器分不清「路径分隔」还是「参数内容」
```

> ⚠️ **跨平台开发者的经典错误**：把 Windows 路径直接拼进 URL——`api.example.com/files/C:\data\a.txt` 必然失败。**拼 URL 前先把 `\` 转成 `/`**（或直接全用 `/` 构建）。

## 4. 场景三：命令行

### 4.1 参数风格对比

| 平台/工具 | 参数前缀 | 示例 |
|-----------|:---:|------|
| Linux/macOS 工具 | `-`/`--` | `ls -l`、`git --version` |
| Windows cmd（旧） | `/` | `dir /w`、`format /s` |
| PowerShell（新） | `-` | `Get-Process -Name java` |
| Java CLI | `-`/`--` | `java -jar app.jar --port=8080` |
| 现代跨平台 CLI | `-`/`--` | `npm --version`、`uv sync --frozen` |

### 4.2 路径与参数的混淆陷阱

```text
cmd 中的混淆场景（历史遗留）
├── dir /w        → 参数（宽格式列表）
├── cd /          → 特殊含义（切到根目录）——不是路径！
├── 解决现代混乱：cmd 中路径尽量用 \（避免被当参数）
└── PowerShell 已无此问题（参数用 -，路径随便写）

Git Bash / WSL 中：
├── 路径统一 /（Unix 语义）
├── C:/Users/xxx 也能访问（Windows 盘符挂载）
└── 传 Windows 路径给命令时注意转义
```

> 💡 **实用技巧**：在 Git Bash / WSL（Unix 语义环境）下操作 Windows 路径时，**统一用 `/`**（`/c/Users/xxx` 或 `C:/Users/xxx`）——避免 `\` 在 Shell 中被当作转义符吞掉。

## 5. 场景四：代码字符串

### 5.1 转义的本质

> 🎯 **在大多数编程语言的字符串中，`\` 是转义字符**——它不表示「反斜杠本身」，而是与后面字符组合成特殊含义：

```text
常见转义序列
├── \n 换行 / \t 制表 / \r 回车
├── \u4E2D Unicode 字符（Java/JS）
├── \\ 表示「一个真正的反斜杠」
└── \" 表示「一个双引号」

结论：字符串里想写一个 \，必须写 \\（双写）
```

### 5.2 各语言对比

| 语言 | Windows 路径写法 | 说明 |
|------|----------------|------|
| **Java** | `"D:\\data\\a.txt"` | 必须双写 |
| **Python** | `r"D:\data\a.txt"` | 原始字符串免转义（首选！） |
| **JS/TS** | `"D:\\data\\a.txt"` | 必须双写 |
| **C#** | `@"D:\data\a.txt"` | 逐字字符串 @ 免转义 |
| **Shell** | `'/c/Users/xxx'` 单引号 | 单引号内不转义 |

```java
// Java 对比
String p1 = "D:/data/a.txt";      // ✅ 推荐：无需转义
String p2 = "D:\\data\\a.txt";    // ⚠️ 正确但繁琐（每个 \ 都要双写）
String p3 = "D:\data\a.txt";      // ❌ 编译错误或错误字符（\d 不是转义序列！）

// Java 反斜杠路径转正斜杠
String normalized = rawPath.replace("\\", "/");      // 或
String normalized2 = rawPath.replaceAll("\\\\", "/"); // 正则版（注意 4 个反斜杠！）
```

> ⚠️ **为什么 `"D:\data"` 会出错**：`\d` 在 Java 字符串中不是合法转义序列 → 编译错误；在 Python 中 `\d` 是普通字符（保留原样但 IDE 警告）——**两种语言两种命运，统一写 `/` 就没这些事**。

## 6. 场景五：正则表达式

### 6.1 双重转义的原理

> ⚠️ **正则表达式是双重转义的重灾区**：正则本身用 `\` 转义，正则又要写在字符串里，字符串再用 `\` 转义——**一层正则转义 + 一层字符串转义 = 双重转义**：

```text
正则中的反斜杠层级（以「匹配一个反斜杠字符」为例）
├── 正则层：\\（正则中匹配字面 \）
├── 字符串层：再转义一次 → \\\\
└── 最终代码：Java 中写 "\\\\"（8 个字符？不，4 个反斜杠=2 个转义对）

各语言对比：
  Java:      "\\\\"  → 正则 \\ → 匹配 \
  Python:    r"\\"   → 正则 \\ → 匹配 \（原始字符串救星！）
  JS:        "\\\\"  → 正则 \\ → 匹配 \
  JS(2026):  /\\/    → 正则字面量免字符串转义
```

### 6.2 常见正则转义场景

```java
// 匹配 Windows 路径中的反斜杠（Java）
String path = "C:\\Users\\xxx";
path.split("\\\\");                    // 按 \ 分割（Java 写 4 个）
path.matches(".*\\\\.*");              // 是否含 \

// 匹配文件分隔符的跨平台正则（用字符类避开转义）
String regex = "[\\\\/]";              // 匹配 \ 或 /（字符类中 \ 只需双写）

// Python 原始字符串（优雅方案）
import re
re.split(r"\\", path)                  // r"\\" 正则匹配 \（无需双重转义）
re.split(r"[\\/]", path)               // 匹配 \ 或 /
```

> 🎯 **正则转义口诀**：**匹配 `\` 字符 → Java/JS 字符串写 4 个反斜杠（`"\\\\"`）、Python 用原始字符串写 2 个（`r"\\"`）**——能用字符类 `[\\/]` 避开就别单独匹配。

## 7. 特殊场景：UNC 与 Windows 系统

### 7.1 UNC 路径（必须反斜杠）

```text
UNC 路径（Windows 网络共享）——反斜杠不可替代的场景
├── \\server\share\folder\file
├── 开头双反斜杠是硬性要求（\\ 不能写成 //）
├── Java 访问 UNC：File 与 NIO 均支持
├── 代码中：new File("\\\\server\\share\\file")  ← 4 个开头反斜杠！
└── 跨平台注意：Unix 没有 UNC 概念（用挂载）
```

### 7.2 Windows 系统特殊路径

| 路径 | 写法 | 说明 |
|------|------|------|
| **UNC 共享** | `\\server\share` | 网络共享 |
| **UNC 设备** | `\\?\C:\path` | 长路径/设备名（Win32 扩展） |
| **注册表** | `HKEY_LOCAL_MACHINE\...` | 反斜杠层级 |
| **WSL 路径** | `/mnt/c/Users/xxx` | Unix 风格访问 Windows |
| **Git Bash** | `/c/Users/xxx` | 盘符挂载为目录 |

### 7.3 Windows 环境变量中的路径

```bat
@echo off
:: Windows 批处理中路径变量（反斜杠 + 双引号）
set APP_DIR=C:\apps\myapp
set LOG_DIR=%APP_DIR%\logs

:: 拼接路径（避免尾部斜杠问题）
set TARGET=%APP_DIR%\app.jar

:: PATH 环境变量：多个路径用分号 ; 分隔（注意不是冒号！）
set PATH=C:\Windows\System32;C:\apps\tools;%PATH%
```

> 💡 **路径列表分隔符的跨平台差异**：Java 的 `File.pathSeparator`——Windows 用 `;`、Unix 用 `:`——多路径拼接（classpath/PATH）时跨平台必须用常量而非硬编码。

## 8. 核心要点

> 🎯 **核心要点**：
> 1. 五场景规则：路径（代码 `/`）/URL（只能 `/`）/命令行（`-` 为主）/字符串（`\\` 双写）/正则（双重转义）
> 2. 程序内部读写一律 `/`；只有向 Windows 用户展示本地路径才用 `\`（由系统 API 生成）
> 3. URL 拼路径前先把 `\` 转 `/`（`%2F` 处理参数中的斜杠）
> 4. 正则匹配 `\`：Java/JS 写 `"\\\\"`，Python 用 `r"\\"`，字符类 `[\\/]` 是优雅解法
> 5. UNC（`\\server\share`）与 Windows 环境变量路径是反斜杠的「合法主场」，跨平台代码需特殊处理
