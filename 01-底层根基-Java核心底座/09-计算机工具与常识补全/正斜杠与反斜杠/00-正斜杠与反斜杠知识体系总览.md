# 00 - 正斜杠与反斜杠 知识体系总览

## 4. 核心概念速查

| 概念 | 一句话解释 |
|------|-----------|
| **正斜杠 `/`** | Slash：路径分隔、URL、路由——全平台通用，跨平台代码首选 |
| **反斜杠 `\`** | Backslash：Windows 原生路径分隔符 + 编程语言转义字符 |
| **转义字符** | `\n`/`\t`/`\\`——反斜杠在代码字符串中的特殊含义 |
| **路径分隔符** | 文件系统目录层级分隔（Windows `\` / Unix `/`） |
| **路径列表分隔符** | 多个路径之间的分隔（Windows `;` / Unix `:`） |
| **URI/URL 分隔** | 网络地址一律 `/`，反斜杠非法 |
| **命令参数标志** | `-`/`--`（Unix）/`/`（旧 Windows）——历史纠葛的根源 |
| **正则转义** | 正则中 `\` 是转义符——双重转义是最大踩坑点 |
| **原始字符串** | `r"..."`（Python）——免转义的路径写法 |
| **File.separator** | Java 跨平台路径分隔符常量 |

## 5. 一图看懂：五场景规则

| 场景 | 用哪个 | 原因 |
|------|:---:|------|
| **文件路径（跨平台代码）** | `/` | Windows 也认 `/`，Unix 只认 `/` |
| **URL / URI / HTTP** | `/` | 网络标准，`\` 非法 |
| **Windows 本地路径展示** | `\` | 系统原生格式（用户习惯） |
| **命令行参数** | `-`/`--`（新）/`/`（旧 Windows） | 历史遗留 |
| **代码字符串转义** | `\\`（双写） | `\` 是转义字符，不能单独写 |
| **正则表达式** | `\\\\` 或原始字符串 | 双重转义 |

> 💡 **终极口诀**：**网络和跨平台代码用 `/`；转义和 Windows 本地显示才用 `\`，且代码中不能单独书写反斜杠**（要么 `\\`，要么原始字符串）。
