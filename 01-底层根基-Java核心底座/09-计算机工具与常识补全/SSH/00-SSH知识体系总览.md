## 4. 核心概念速查

| 概念 | 一句话解释 |
|------|-----------|
| **密钥对** | 私钥（本机）+ 公钥（服务器）——非对称加密认证 |
| **Ed25519** | 2026 推荐密钥类型（安全+快速+短） |
| **ssh-agent** | 内存中的密钥代理——免重复输入密码 |
| **Agent Forwarding** | 把本机 agent 转发给跳板机（⚠️ 有风险） |
| **authorized_keys** | 服务器上允许的公钥列表（可加高级选项） |
| **known_hosts** | 记录访问过的主机指纹（防中间人攻击） |
| **ssh_config** | 客户端配置（别名/跳板/选项）——复杂命令变简单 |
| **ProxyJump** | 跳板机连接（-J，OpenSSH 7.3+） |
| **ControlMaster** | 连接复用（多条 SSH 共享一条 TCP） |
| **fail2ban** | 失败次数超限自动封禁 IP（防暴力破解） |
| **sshd_config** | 服务端配置（认证方式/端口/权限） |
| **StrictHostKeyChecking** | 主机密钥严格校验（防中间人） |

## 5. 一图看懂：SSH 认证流程

```text
SSH 密钥认证流程
┌────────┐  ①请求连接  ┌────────┐
│ 客户端  │ ─────────→ │ 服务器  │
│ 私钥    │            │ 公钥    │
└────────┘            └────────┘
②服务器发挑战（随机数）
③客户端用私钥签名
④服务器用公钥验签 → 通过 → 建立会话

关键认知：
├── 私钥永远不出本机（泄露 = 身份被盗）
├── 公钥可以随意分发（服务器/托管平台）
├── 密码登录 vs 密钥登录：密钥更安全（不可爆破）
└── 2026 基线：服务器只允许密钥登录（禁用密码）
```
