## 3. 2026 市场格局

### 3.1 份额与定位

| 厂商 | 份额（2025） | 定位 | 一句话 |
|------|:---:|------|--------|
| **阿里云** | **36%**（↑） | 全能型生态帝国 | 均衡无短板、生态最丰富 |
| **华为云** | 16%（↓） | 政企信创首选 | 能不能交付而非模型好不好 |
| **腾讯云** | 9%（↓） | 社交生态与性价比 | 微信生态/音视频不可替代 |

### 3.2 2026 关键变化

```text
2026 云市场三大变化
├── ① 价格战结束 → 集体涨价（2026.3 起）
│   ├── AI 算力与存储涨幅 30-50%
│   ├── 腾讯云部分核心产品涨幅达 400%
│   └── 背景：Token 调用量日破 140 万亿（较 2024 增千倍）
├── ② AI 平台成为竞争主战场
│   ├── 阿里云目标：拿下 2026 中国 AI 云 80% 新增份额
│   ├── 腾讯云 VITA 3.0（多模态）定价约主流竞品 50%
│   └── 华为云盘古 2.0 聚焦工业垂直领域
└── ③ 国产芯片加速落地
    ├── 阿里倚天 710 / 华为鲲鹏·昇腾
    └── 国产芯片大规模训练可节省约 30% 算力开支
```

## 5. 核心概念速查

| 概念 | 一句话解释 |
|------|-----------|
| **ECS** | 阿里云弹性云服务器（Elastic Compute Service） |
| **CVM** | 腾讯云云服务器（Cloud Virtual Machine） |
| **ECS（华为）** | 华为云弹性云服务器 |
| **倚天 710** | 阿里自研 ARM 服务器芯片（降本） |
| **鲲鹏/昇腾** | 华为自研 CPU / AI 芯片（信创双引擎） |
| **飞天/神龙** | 阿里云操作系统 / 虚拟化架构 |
| **百炼** | 阿里云大模型平台（模型超市 + MaaS） |
| **ModelArts** | 华为云 AI 开发平台（昇腾路线独占） |
| **TI 平台** | 腾讯云智能体开发平台 |
| **混元** | 腾讯自研大模型 |
| **盘古 2.0** | 华为自研大模型（工业垂直） |
| **Qwen3.5** | 阿里通义千问系列（开源生态最丰富） |
| **VITA 3.0** | 腾讯多模态大模型（原生图文声统一） |
| **轻量服务器** | 腾讯 Lighthouse——个人项目性价比之王 |
| **TDSQL** | 腾讯云分布式数据库（TPC-C 认证） |
| **PolarDB** | 阿里云自研云数据库（TPC-C/TPC-H 认证） |
