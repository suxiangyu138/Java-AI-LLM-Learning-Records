## 1. 腾讯云定位与优势

> **背景**：腾讯云诞生于腾讯社交/游戏/音视频的业务土壤——从「腾讯的云」到「产业的云」。
> **目的**：理解腾讯云的生态优势与性价比定位。
> **适用范围**：游戏/直播/社交/小程序/内容治理。
> **不适用场景**：政企信创（华为云）、通用互联网大厂（阿里云）。

```text
腾讯云的核心优势（2026）
├── ① 微信生态打通（小程序/公众号/企业微信）
│   ├── 数据链路最短、延迟最低
│   └── C 端应用与微信集成不可替代
├── ② 音视频（TRTC）：领域不可替代
│   ├── 低延迟（毫秒级）
│   └── SDK 易用性一骑绝尘
├── ③ 游戏云：份额超 40%（行业第一）
│   ├── 游戏盾（DDoS 防护）
│   └── 低延迟节点
├── ④ 轻量服务器：个人项目性价比之王
├── ⑤ 大模型价格优势：VITA 3.0 约竞品 50%
└── ⑥ 稳定性：曾发生对象存储单园区故障（⚠️ 单 AZ 风险）

份额变化（2025）
├── 份额从 10% 微降至 9%
├── 2026.3 涨价潮中部分核心产品涨幅达 400%
└── 金句：腾讯云 = 「社交/游戏/音视频场景的最优解」
```

## 2. 轻量服务器 Lighthouse

### 2.1 产品定位

> **背景**：Lighthouse（轻量应用服务器）是腾讯云面向个人开发者/小项目的简化产品。
> **目的**：开箱即用的低成本服务器（套餐化）。
> **适用范围**：个人项目/博客/小应用/学习环境。
> **不适用场景**：生产级高可用架构（用 CVM + 负载均衡）。

```text
Lighthouse 特点
├── ① 套餐化：固定配置 + 固定价格（简单）
├── ② 开箱即用：预装镜像（WordPress/宝塔/Java 环境）
├── ③ 低成本：入门套餐约 50-100 元/月
├── ④ 集成：域名/SSL/防火墙（控制台一体化）
└── ⑤ 定位：个人项目「性价比之王」

vs CVM（标准云服务器）
├── Lighthouse：简单套餐（适合入门/个人）
├── CVM：灵活配置（适合生产/复杂架构）
├── 选型：个人学习 → Lighthouse；生产 → CVM
└── 金句：Lighthouse 是「云服务器的轻量版」——够用且便宜
```

## 3. 云服务器 CVM

### 3.1 CVM 家族

```text
CVM（Cloud Virtual Machine）实例族
├── 标准型 S 系列：均衡（Web/应用）
├── 计算型 C 系列：CPU 密集
├── 内存型 M 系列：内存密集
├── 高 IO 型：数据库/缓存
├── GPU 型：AI 训练/渲染
└── 竞价实例：低成本实验

计费模式（2026）
├── 包年包月（生产）
├── 按量计费（弹性）
├── 竞价实例（实验——可回收）
└── 预留实例（长期折扣）
```

### 3.2 Java 后端常用配置

```text
Java 项目选型建议（腾讯云）
├── 个人项目：Lighthouse 2C4G（便宜够用）
├── 中小服务：CVM 4C8G（标准型）
├── 生产集群：CVM 8C16G × N + CLB（负载均衡）
├── 数据库：TDSQL 或云数据库 MySQL
├── 缓存：云 Redis
└── 部署：容器（TKE 腾讯云 K8s）或裸机

开发者体验
├── 文档/SDK：中文完善（Java 示例齐全）
├── 控制台：简洁友好（新手友好）
├── 免费试用：新用户套餐（服务器/数据库/AI）
└── 金句：腾讯云对「独立开发者最友好」——门槛低 + 免费多
```

## 5. 数据库 TDSQL

### 5.1 产品定位

```text
TDSQL（腾讯云分布式数据库）
├── ① 类型：分布式关系型数据库
├── ② 认证：通过 TPC-C/TPC-H 严苛测试
├── ③ 兼容：MySQL 协议（迁移成本低）
├── ④ 场景：金融/电商核心系统（高并发）
├── ⑤ 特性：分布式事务/弹性扩展/高可用
└── ⑥ 对比：阿里 PolarDB（云原生）/华为 GaussDB（信创）

选型（Java 后端）
├── 常规业务 → 云数据库 MySQL（托管）
├── 高并发核心 → TDSQL（分布式）
├── 弹性伸缩 → 云原生数据库
└── 金句：TDSQL = 腾讯的「分布式数据库名片」——TPC-C 认证背书
```

## 9. 核心要点

> 🎯 **核心要点**：
> 1. 腾讯云 = 社交生态与性价比（份额 9%）——微信生态/音视频/游戏三张王牌
