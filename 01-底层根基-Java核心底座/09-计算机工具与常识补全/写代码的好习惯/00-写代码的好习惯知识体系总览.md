## 4. 核心概念速查

| 概念 | 一句话解释 |
|------|-----------|
| **DRY** | Don't Repeat Yourself 不重复自己（三处重复才抽象） |
| **KISS** | Keep It Simple 保持简单（简单的实现优于聪明的实现） |
| **YAGNI** | You Ain't Gonna Need It 不需要就别做（预测性抽象是债务） |
| **SOLID** | 单一职责/开闭/里氏/接口隔离/依赖反转 |
| **童子军规则** | 离开代码时让它比你发现时更干净 |
| **F.I.R.S.T** | 测试五原则：快速/独立/可重复/自我验证/及时 |
| **红绿重构** | TDD 循环：先写失败测试→最小实现→重构 |
| **预备性重构** | Kent Beck：先让改变变容易，再做容易的改变 |
| **空白画布陷阱** | 别让 AI 从零写项目——先建好结构与参照实现 |
| **外科手术式修改** | Karpathy 原则：不顺手重构，只改该改的 |
