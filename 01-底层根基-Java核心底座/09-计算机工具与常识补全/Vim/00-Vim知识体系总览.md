## 4. 核心概念速查

| 概念 | 一句话解释 |
|------|-----------|
| **模式编辑** | 普通/插入/可视/命令四种模式——不同模式按键含义不同 |
| **组合语法** | `[次数][操作][范围]`——`d2w` = 删除 2 个词 |
| **文本对象** | `aw`/`i(`/`i"` 等——按「词/括号/引号」为单位操作 |
| **点命令 `.`** | 重复上一次修改（Vim 最高效的按键） |
| **寄存器** | `"a` 等命名寄存器——剪贴板的「多档位」版本 |
| **宏 `q`** | 录制/回放操作序列——批量处理利器 |
| **跳跃列表** | `Ctrl+o`/`Ctrl+i`——在编辑历史位置间跳转 |
| **撤销分支** | Vim 支持「分叉撤销」——`:earlier`/`:later` |
| **vimrc** | 配置文件——把 Vim 变成「你的」编辑器 |
| **LSP** | 语言服务器协议——Neovim 获得 IDE 级补全/诊断 |
| **Treesitter** | 语法树解析——精确高亮/折叠（Neovim 0.10+） |
| **lazy.nvim** | 2026 主流插件管理器（Lua） |

## 5. 一图看懂：Vim 组合语法

```text
Vim 核心语法 = [次数] + [操作] + [范围]

   次数        操作          范围
    2          d            w
  （两次）   （删除）      （单词）

常用组合（肌肉记忆目标）：
├── dw   删除一个词          ├── ci"  改引号内内容
├── d2w  删除两个词          ├── di(  删括号内内容
├── dd   删除整行            ├── yiw  复制一个词
├── d$   删到行尾            ├── caw  改整个词（含空格）
├── dG   删到文件末尾        └── vi}  选中花括号块内
→ 掌握 20 个组合 = 覆盖 80% 日常编辑
```

---

> 🎯 **学习心法**：Vim 不是「背命令」而是「学语法」——理解了 `操作+范围` 的组合规则，几百个命令变成几十个词根的自由组合。每天练 15 分钟，两周形成肌肉记忆。
