## 4. 核心概念速查

| 概念 | 一句话解释 |
|------|-----------|
| **主人翁心态** | 不「等任务」而「找问题」——把自己当老板，项目成功我来兜底 |
| **算账思维** | 把技术指标翻译成业务价值（响应 2s→0.5s = 减少 30% 用户流失） |
| **A/B/C 类工作** | C 被动执行 / B 高质量完成 / A 创造杠杆价值（Kent Beck 分类） |
| **估算锥** | 项目越早期估算误差越大——报估算附波动范围 |
| **强烈观点弱立场** | 有鲜明的观点，却不固执己见——达成共识才是目的 |
| **九段工程师** | 从 1 段基础执行到 9 段战略布局的成长框架 |
| **修路而非赶路** | 解决根本问题（修路）优于重复处理个案（赶路） |
| **复利职业观** | 把职业当作复利而非彩票——没有捷径，但有复利 |
| **认知护城河** | 技术深度 × 业务理解 × AI 协同能力的乘积效应 |
| **影响力本质** | 你能帮助多少人解决问题——价值先行，影响力是副产品 |
| **触觉层次** | 2026 穿搭趋势：面料质感优先，同色系叠穿靠质感分层 |
| **静谧机能** | 低调功能设计（无 logo/防水/耐磨）——户外商务装 |
| **去班味** | 户外装成新商务装：舒适自由松弛 = 自信感（雷军/马云同款逻辑） |
| **版型大于品牌** | 合身是第一位的——穿得贵不如穿得对 |
| **数字断舍离** | 注意力是最贵资产：无手机时段 + 信息摄入配额 |
| **生活秩序感** | 作息/运动/财务/空间的秩序 = 内在掌控感的外化 |
