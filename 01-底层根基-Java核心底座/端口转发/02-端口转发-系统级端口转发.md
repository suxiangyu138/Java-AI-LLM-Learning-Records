## 1. iptables NAT 转发

```bash
# ===== 同机器端口转发（80 → 8080）=====
# 开启内核转发
echo 1 | sudo tee /proc/sys/net/ipv4/ip_forward

# DNAT：改目标地址
sudo iptables -t nat -A PREROUTING -p tcp --dport 80 -j REDIRECT --to-port 8080

# 持久化
# CentOS: sudo service iptables save
# Ubuntu: sudo apt install iptables-persistent && sudo netfilter-persistent save

# ===== 跨机器转发 =====
# 访问本机 80 → 转发到 192.168.1.50:8080
sudo iptables -t nat -A PREROUTING -p tcp --dport 80 -j DNAT --to-destination 192.168.1.50:8080
sudo iptables -t nat -A POSTROUTING -j MASQUERADE

# ===== 查看/删除 =====
sudo iptables -t nat -L -n -v               # 查看 NAT 规则
sudo iptables -t nat -D PREROUTING 1         # 删除第 1 条
```

```text
iptables NAT 链说明：
  PREROUTING  → 数据包到达时改目标地址（DNAT）
  POSTROUTING → 数据包离开时改源地址（SNAT/MASQUERADE）
  OUTPUT      → 本机发出的包改目标地址
```

## 2. firewalld forward-port

```bash
# CentOS 7+ 推荐方案（比 iptables 更简洁）

# 同机转发：80 → 8080
sudo firewall-cmd --permanent --add-forward-port=port=80:proto=tcp:toport=8080

# 跨机转发：80 → 192.168.1.50:8080
sudo firewall-cmd --permanent \
  --add-forward-port=port=80:proto=tcp:toport=8080:toaddr=192.168.1.50

# 开启 IP 伪装（跨机转发必须）
sudo firewall-cmd --permanent --add-masquerade

# 临时转发（测试用，重启消失）
sudo firewall-cmd --add-forward-port=port=80:proto=tcp:toport=8080

# 查看转发规则
sudo firewall-cmd --list-forward-ports

# 删除
sudo firewall-cmd --permanent --remove-forward-port=port=80:proto=tcp:toport=8080

sudo firewall-cmd --reload
```

## 3. socat 万能中继

```bash
# socat = "netcat on steroids"
sudo apt install socat    # 或 sudo dnf install socat

# ===== 基本转发 =====
socat TCP-LISTEN:8080,fork,reuseaddr TCP:internal-service:8080
# 监听本地 8080 → 转发到 internal-service:8080

# ===== 带日志的转发 =====
socat -v TCP-LISTEN:8080,fork TCP:backend:8080 2>&1 | tee proxy.log

# ===== UDP 转发 =====
socat UDP-LISTEN:53,fork,reuseaddr UDP:8.8.8.8:53

# ===== TLS 加密中继 =====
socat TCP-LISTEN:443,fork,reuseaddr OPENSSL:backend:443

# ===== systemd 后台运行 =====
# /etc/systemd/system/socat-proxy.service
[Unit]
Description=Socat Proxy 8080→backend:8080
[Service]
ExecStart=/usr/bin/socat TCP-LISTEN:8080,fork,reuseaddr TCP:backend:8080
Restart=always
[Install]
WantedBy=multi-user.target
```

```text
socat vs iptables 选择：
  socat    → 应用层中继，可做 TLS/日志/内容修改
  iptables → 内核层转发，性能极高，但功能单一
  Nginx    → 生产级，需额外部署
```

## 4. Nginx Stream 四层代理

```nginx
# /etc/nginx/nginx.conf 或 /etc/nginx/stream.conf
# stream 模块 = 四层 TCP/UDP 代理（非 HTTP）

stream {
    # MySQL 端口转发
    upstream mysql_backend {
        server prod-db.internal:3306;
    }
    server {
        listen 3306;
        proxy_pass mysql_backend;
        proxy_connect_timeout 5s;
    }

    # Redis 端口转发
    upstream redis_backend {
        server prod-redis.internal:6379;
    }
    server {
        listen 6379;
        proxy_pass redis_backend;
    }

    # SSH 跳板
    server {
        listen 2222;
        proxy_pass 192.168.1.100:22;
    }
}
```

```bash
# 验证 stream 模块是否编译
nginx -V 2>&1 | grep -o with-stream

# 检查配置 + 重载
sudo nginx -t && sudo systemctl reload nginx
```

| 方案 | 适用 | 优势 | 劣势 |
|------|------|------|------|
| **iptables** | 简单转发 | 极高性能 | 难维护 |
| **firewalld** | CentOS 环境 | 命令简洁 | 仅 CentOS |
| **socat** | 临时中继、调试 | 灵活万能 | 性能中等 |
| **Nginx stream** | 生产持久转发 | 稳定、可监控 | 需 Nginx |

---

> 🎯 **选择建议**：同机器低端口转发用 **firewalld forward-port**；临时调试用 **socat**；生产多端口代理用 **Nginx stream**。
