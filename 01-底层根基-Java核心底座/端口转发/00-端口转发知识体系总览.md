## 4. 核心场景速查

| 场景 | 方案 | 命令一句话 |
|------|:--:|------|
| 远程数据库连本地 | SSH 本地转发 | `ssh -L 3306:db:3306 bastion` |
| IDE 远程调试 | SSH 远程转发 | `ssh -R 5005:localhost:5005 dev` |
| 科学上网/全局代理 | SSH 动态转发 | `ssh -D 1080 proxy` |
| 低端口转发 | firewalld | `firewall-cmd --add-forward-port=port=80:toport=8080` |
| Docker 服务暴露 | docker -p | `docker run -p 8080:8080` |
| K8s 调试 Pod | kubectl | `kubectl port-forward pod/xxx 8080:8080` |
| 内网服务暴露公网 | frp/ngrok | 见 03 详解 |
