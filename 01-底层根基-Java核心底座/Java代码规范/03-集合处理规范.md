## 1. 集合初始化规范

### 1.1 容量预估公式

```java
// HashMap 容量预估公式：expectedSize / 0.75 + 1
int expectedSize = 100;
Map<String, User> map = new HashMap<>((int) (expectedSize / 0.75f) + 1);

// ArrayList 容量预估
List<User> list = new ArrayList<>(100);

// HashSet 容量预估
Set<User> set = new HashSet<>((int) (expectedSize / 0.75f) + 1);
```

### 1.2 为什么要预估容量

```java
// ❌ 不预估容量：多次扩容导致性能损耗
Map<String, User> map = new HashMap<>();  // 默认 16
for (int i = 0; i < 100; i++) {
    map.put("key" + i, new User());  // 扩容 3 次（16→32→64→128）
}

// ✅ 预估容量：一次到位
Map<String, User> map = new HashMap<>(134);  // 100 / 0.75 + 1
for (int i = 0; i < 100; i++) {
    map.put("key" + i, new User());  // 不扩容
}
```

> 💡 **Guava 工具类**：`Maps.newHashMapWithExpectedSize(100)` 自动计算容量。

## 2. 集合判空防御

### 2.1 标准判空写法

```java
// ❌ 冗余写法
if (list != null && list.size() > 0) { }
if (map != null && !map.isEmpty()) { }

// ✅ 使用工具类
import org.apache.commons.collections4.CollectionUtils;
import org.apache.commons.collections4.MapUtils;

if (CollectionUtils.isNotEmpty(list)) { }
if (MapUtils.isNotEmpty(map)) { }

// Spring 也提供
import org.springframework.util.CollectionUtils;
```

### 2.2 返回值判空

```java
// ❌ 返回 null
public List<User> getUsers() {
    if (noData) {
        return null;  // ❌ 调用方必须判空
    }
    return users;
}

// ✅ 返回空集合
public List<User> getUsers() {
    if (noData) {
        return Collections.emptyList();  // ✅ 调用方不用判空
    }
    return users;
}
```

## 3. Map 遍历的正确姿势

### 3.1 四种遍历方式对比

```java
Map<String, User> map = new HashMap<>();

// ✅ 推荐：entrySet 遍历（一次查找）
for (Map.Entry<String, User> entry : map.entrySet()) {
    String key = entry.getKey();
    User value = entry.getValue();
}

// ❌ 避免：keySet + get（两次查找）
for (String key : map.keySet()) {
    User value = map.get(key);  // ❌ 第二次查找
}

// ✅ Java 8+：forEach + Lambda
map.forEach((key, value) -> {
    System.out.println(key + ": " + value);
});

// ✅ 需要删除元素：迭代器
Iterator<Map.Entry<String, User>> it = map.entrySet().iterator();
while (it.hasNext()) {
    Map.Entry<String, User> entry = it.next();
    if (needDelete(entry.getValue())) {
        it.remove();  // ✅ 安全删除
    }
}
```

### 3.2 性能对比

| 方式 | 查找次数 | 推荐度 |
|------|---------|--------|
| entrySet | 1 次 | ⭐⭐⭐⭐⭐ |
| keySet + get | 2 次 | ⭐⭐ |
| forEach | 1 次 | ⭐⭐⭐⭐ |
| 迭代器 | 1 次 | ⭐⭐⭐⭐（可删除） |

## 4. List 遍历与修改

### 4.1 遍历中删除元素

```java
List<String> list = new ArrayList<>(List.of("a", "b", "c", "d"));

// ❌ 错误：抛 ConcurrentModificationException
for (String s : list) {
    if ("b".equals(s)) {
        list.remove(s);  // ❌ fail-fast
    }
}

// ✅ 方法 1：迭代器 remove()
Iterator<String> it = list.iterator();
while (it.hasNext()) {
    String s = it.next();
    if ("b".equals(s)) {
        it.remove();  // ✅ 安全
    }
}

// ✅ 方法 2：倒序遍历
for (int i = list.size() - 1; i >= 0; i--) {
    if ("b".equals(list.get(i))) {
        list.remove(i);
    }
}

// ✅ 方法 3：Java 8+ removeIf
list.removeIf("b"::equals);
```

### 4.2 fail-fast 原理

```java
// ArrayList 内部维护 modCount（修改次数）
// 迭代器创建时记录 expectedModCount
// 每次 next() 检查：if (modCount != expectedModCount) throw ConcurrentModificationException
```

## 5. Arrays.asList 使用陷阱

### 5.1 三大陷阱

```java
// 陷阱 1：返回的是 Arrays$ArrayList，不是 java.util.ArrayList
List<String> list = Arrays.asList("a", "b", "c");
System.out.println(list.getClass());  // class java.util.Arrays$ArrayList

// 陷阱 2：固定大小，不能 add/remove
list.add("d");       // ❌ UnsupportedOperationException
list.remove(0);      // ❌ UnsupportedOperationException

// 陷阱 3：修改会写回原数组
String[] arr = {"a", "b", "c"};
List<String> list2 = Arrays.asList(arr);
list2.set(0, "x");
System.out.println(arr[0]);  // "x"（原数组被修改）
```

### 5.2 正确转可修改 List

```java
// ✅ 方法 1：new ArrayList 包装
List<String> list = new ArrayList<>(Arrays.asList("a", "b", "c"));
list.add("d");  // ✅ 正常

// ✅ 方法 2：Java 8+ Stream
List<String> list2 = Stream.of("a", "b", "c").collect(Collectors.toList());

// ✅ 方法 3：Java 9+ List.of（不可变）
List<String> list3 = List.of("a", "b", "c");  // 不可变
```

## 6. subList 使用陷阱

### 6.1 subList 是视图不是独立 List

```java
List<String> list = new ArrayList<>(List.of("a", "b", "c", "d", "e"));
List<String> subList = list.subList(1, 3);  // [b, c]

// 修改 subList 会影响原 List
subList.set(0, "x");
System.out.println(list);  // [a, x, c, d, e]

// 修改原 List 会导致 subList 抛异常
list.add("f");
System.out.println(subList);  // ❌ ConcurrentModificationException
```

### 6.2 正确使用场景

```java
// ✅ 局部操作
List<String> list = new ArrayList<>(List.of("a", "b", "c", "d", "e"));
list.subList(1, 3).clear();  // 删除 [b, c]
System.out.println(list);    // [a, d, e]

// ✅ 转独立 List
List<String> subList = new ArrayList<>(list.subList(1, 3));
```

## 7. 集合转数组的正确写法

### 7.1 标准写法

```java
List<String> list = List.of("a", "b", "c");

// ❌ 错误：返回 Object[]
Object[] arr1 = list.toArray();

// ✅ 正确：指定类型
String[] arr2 = list.toArray(new String[0]);

// ✅ Java 11+：IntFunction
String[] arr3 = list.toArray(String[]::new);
```

### 7.2 数组长度传 0 还是 size()

```java
// ✅ 推荐：传 0（JVM 优化更好）
String[] arr = list.toArray(new String[0]);

// ⚠️ 可以但不推荐：传 size()
String[] arr2 = list.toArray(new String[list.size()]);
```

> 💡 **性能差异**：传 0 时 JVM 会分配一次数组；传 size() 时如果集合大小变化会分配两次。现代 JVM 对 `new String[0]` 有优化。

## 8. 不可变集合

### 8.1 三种创建方式

```java
// 方式 1：Collections.unmodifiable*
List<String> list = Collections.unmodifiableList(new ArrayList<>(Arrays.asList("a", "b")));

// 方式 2：Java 9+ List.of（推荐）
List<String> list2 = List.of("a", "b");
Set<String> set = Set.of("a", "b");
Map<String, Integer> map = Map.of("a", 1, "b", 2);

// 方式 3：Guava ImmutableList
List<String> list3 = ImmutableList.of("a", "b");
```

### 8.2 防御性拷贝

```java
// ❌ 返回可变集合，外部可修改
public List<User> getUsers() {
    return users;  // ❌ 外部可以 add/remove
}

// ✅ 返回不可变集合
public List<User> getUsers() {
    return Collections.unmodifiableList(users);
}

// ✅ 返回防御性拷贝
public List<User> getUsers() {
    return new ArrayList<>(users);
}
```

## 9. 常见反模式

| 反模式 | 问题 | 正确做法 |
|--------|------|---------|
| 循环里 contains | O(n²) 复杂度 | 用 Set.contains O(1) |
| 频繁 add/remove 中间位置 | ArrayList 性能差 | 用 LinkedList |
| 大集合无分页查询 | OOM 风险 | 流式处理/分页 |
| 集合作返回值被外部修改 | 数据不一致 | 返回不可变/拷贝 |
| keySet + get 遍历 Map | 双重查找 | 用 entrySet |
| for-each 中删除元素 | ConcurrentModificationException | 迭代器 remove() |
| Arrays.asList 当可变 List | UnsupportedOperationException | new ArrayList 包装 |
| subList 当独立 List | 影响原 List | new ArrayList 拷贝 |

## 10. 动手练习

### 练习 1：修复集合陷阱

```java
List<String> list = Arrays.asList("a", "b", "c");
list.add("d");  // 问题 1

List<String> subList = list.subList(0, 2);
subList.add("x");  // 问题 2

for (String s : list) {
    if ("b".equals(s)) {
        list.remove(s);  // 问题 3
    }
}
```

<details>
<summary>参考答案</summary>

```java
// 修复 1：转可修改 List
List<String> list = new ArrayList<>(Arrays.asList("a", "b", "c"));
list.add("d");

// 修复 2：转独立 List
List<String> subList = new ArrayList<>(list.subList(0, 2));
subList.add("x");

// 修复 3：用 removeIf
list.removeIf("b"::equals);
```
