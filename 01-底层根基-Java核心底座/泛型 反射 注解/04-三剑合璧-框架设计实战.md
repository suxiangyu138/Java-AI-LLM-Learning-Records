## 1. Spring IoC容器核心原理

Spring IoC（Inversion of Control，控制反转）的核心机制可以用一句话概括：**注解做标记，反射做扫描，泛型做约束**。三者缺一不可。

### 1.1 核心流程

```
@Component 注解标记类
       ↓
反射扫描 classpath 下所有 .class 文件
       ↓
Class.forName() 加载目标类
       ↓
反射调用 Constructor.newInstance() 创建实例
       ↓
@Autowired 注解标记依赖字段
       ↓
反射调用 Field.set() 注入依赖
       ↓
放入 Map<String, Object> 容器完成管理
```

### 1.2 关键源码分析 (Spring内部)

```java
// Spring 扫描的核心入口：ClassPathBeanDefinitionScanner
// 1. 扫描 classpath → 找出所有带有 @Component 的类
// 2. 解析 @Component.value() 取得 beanName
// 3. 构建 BeanDefinition 注册到 BeanFactory

// 创建实例的核心：AbstractAutowireCapableBeanFactory
// doCreateBean() → createBeanInstance() → populateBean()
// createBeanInstance(): 反射 Constructor 创建对象
// populateBean(): 遍历 Field → 找 @Autowired → getBean() 获取依赖 → Field.set() 注入

// 大致伪码如下 (Spring 5.x 真实逻辑简化)
void populateBean(String beanName, RootBeanDefinition mbd, Object instance) {
    for (Field field : instance.getClass().getDeclaredFields()) {
        Autowired ann = field.getAnnotation(Autowired.class);
        if (ann != null) {
            Object dependency = getBean(field.getType()); // 递归获取依赖
            field.setAccessible(true);
            field.set(instance, dependency);              // 反射注入
        }
    }
}
```

### 1.3 为什么需要泛型？

Spring 5 开始，`BeanFactory` 接口引入了泛型约束：

```java
public interface BeanFactory {
    // 非泛型版本 — 需要强转
    Object getBean(String name);

    // 泛型版本 — 类型安全，免强转 (Spring 3.0+)
    <T> T getBean(Class<T> requiredType);
}
```

泛型让用户从显式强转中解放出来：

```java
// 无泛型 — 以前必须这样
UserService service = (UserService) context.getBean("userService");

// 有泛型 — 现在这样
UserService service = context.getBean(UserService.class);
// 编译器自动推断 T = UserService，返回类型就是 UserService
```

> 🎯 **核心要点**：IoC本质是「注解规定规则 → 反射扫描执行 → 泛型约束类型」的流水线。注解是配置元数据，反射是运行时执行引擎，泛型是编译期类型护航。

## 2. MyBatis Mapper接口代理原理

最令初学者困惑的问题：**为什么Mapper是个接口，连实现类都没有，却能直接执行SQL？**

### 2.1 核心流程

```
@Select("SELECT * FROM user WHERE id = #{id}")
User findById(Long id);
       ↓
MyBatis 启动时扫描 Mapper 接口
       ↓
JDK 动态代理创建接口的代理对象
       ↓
调用 findById() → 进入 InvocationHandler.invoke()
       ↓
解析 @Select 注解获取 SQL 语句
       ↓
反射获取方法参数值
       ↓
泛型获取方法返回类型 (User / List<User>)
       ↓
JDBC 执行 SQL → ResultSet → 反射创建返回对象 → 字段映射
```

### 2.2 简化的 Mini-MyBatis 实现

```java
// ==================== 注解定义 ====================
@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.METHOD)
public @interface Select {
    String value();
}

// ==================== Mapper 接口 ====================
public interface UserMapper {
    @Select("SELECT * FROM user WHERE id = #{id}")
    User findById(Long id);

    @Select("SELECT * FROM user")
    List<User> findAll();
}

// ==================== 代理核心 ====================
public class MapperProxyFactory {
    @SuppressWarnings("unchecked")
    public static <T> T getMapper(Class<T> mapperInterface) {
        // 验证是否是接口
        if (!mapperInterface.isInterface()) {
            throw new IllegalArgumentException("Mapper must be an interface");
        }

        InvocationHandler handler = (proxy, method, args) -> {
            // 1. 获取 @Select 注解中的 SQL
            Select select = method.getAnnotation(Select.class);
            if (select == null) {
                throw new UnsupportedOperationException("No @Select annotation");
            }
            String sql = select.value();

            // 2. 泛型获取返回类型 (关键!)
            Type returnType = method.getGenericReturnType();

            // 3. 模拟 JDBC 执行 (此处省略 Connection/Statement/ResultSet)
            System.out.println("[代理] 执行SQL: " + sql);
            System.out.println("[代理] 参数: " + args[0]);

            // 4. 根据返回类型决定返回值
            if (returnType instanceof Class) {
                // 简单类型 → 反射创建实例
                return createEntity((Class<?>) returnType, args);
            } else if (returnType instanceof ParameterizedType) {
                // List<T> 类型 → 获取实际类型参数
                Type actualType = ((ParameterizedType) returnType)
                        .getActualTypeArguments()[0];
                return createList((Class<?>) actualType, args);
            }
            return null;
        };

        return (T) Proxy.newProxyInstance(
                mapperInterface.getClassLoader(),
                new Class[]{mapperInterface},
                handler
        );
    }

    private static Object createEntity(Class<?> clazz, Object[] args) {
        try {
            // 反射创建实例 (实际应映射 ResultSet)
            return clazz.getDeclaredConstructor().newInstance();
        } catch (Exception e) {
            throw new RuntimeException(e);
        }
    }

    private static List<Object> createList(Class<?> elementType, Object[] args) {
        // 泛型集合返回
        return new ArrayList<>();
    }

    public static void main(String[] args) {
        UserMapper mapper = MapperProxyFactory.getMapper(UserMapper.class);

        // 调用方法 → 自动被代理拦截 → 执行SQL
        User user = mapper.findById(1L);

        // 泛型集合也能正确处理
        List<User> users = mapper.findAll();
    }
}
```

> 💡 **关键洞察**：Mapper接口之所以不需要实现类，是因为JDK动态代理在运行时动态生成了一个实现了该接口的代理对象。所有方法调用都被`InvocationHandler.invoke()`拦截，转而执行SQL。

### 2.3 泛型在 MyBatis 中的关键作用

```java
public interface BaseMapper<T, ID> {
    // MyBatis-Plus 的核心设计
    T selectById(ID id);
    List<T> selectList(Wrapper<T> wrapper);
    int insert(T entity);
}

// 使用时泛型自动绑定：
// BaseMapper<User, Long> → T=User, ID=Long
// MyBatis 通过反射获取 T 的实际类型 → 自动推断表名、主键类型
```

> 🎯 **核心要点**：MyBatis Mapper代理 = **JDK动态代理** + **@Select等注解解析** + **泛型返回类型推导**。三者结合实现了「接口即DAO」的优雅设计。

## 3. JUnit @Test执行原理

JUnit 是如何知道哪些方法需要运行测试的？答案仍然是注解+反射。

### 3.1 核心流程

```
编译器看到 @Test 注解 → 保留到 RUNTIME
       ↓
JUnit 运行时拿到测试 Class
       ↓
遍历所有 Method → 过滤出有 @Test 的方法
       ↓
创建测试类实例 (反射 Constructor.newInstance())
       ↓
Method.invoke() 执行测试方法
       ↓
没抛异常 → 通过
抛异常 → 失败
```

### 3.2 简化的 JUnit 引擎

```java
@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.METHOD)
public @interface Test {
    // 期望的异常类型，默认无
    Class<? extends Throwable> expected() default None.class;

    static class None extends Throwable {
        private None() {} // 哨兵类，表示没有期望异常
    }
}

// @BeforeEach / @AfterEach 注解
@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.METHOD)
public @interface BeforeEach {}

@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.METHOD)
public @interface AfterEach {}

// Mini JUnit 测试引擎
public class MiniJUnit {
    public static void run(Class<?> testClass) {
        try {
            // 1. 反射获取所有方法
            Method[] methods = testClass.getDeclaredMethods();

            List<Method> beforeEachMethods = new ArrayList<>();
            List<Method> afterEachMethods = new ArrayList<>();
            List<Method> testMethods = new ArrayList<>();

            // 2. 按注解分类
            for (Method method : methods) {
                if (method.isAnnotationPresent(BeforeEach.class)) {
                    beforeEachMethods.add(method);
                }
                if (method.isAnnotationPresent(AfterEach.class)) {
                    afterEachMethods.add(method);
                }
                if (method.isAnnotationPresent(Test.class)) {
                    // 检查 expected 异常
                    Test testAnn = method.getAnnotation(Test.class);
                    testMethods.add(method);
                }
            }

            // 3. 执行测试
            for (Method testMethod : testMethods) {
                // 每次测试创建新实例 (隔离性)
                Object instance = testClass.getDeclaredConstructor().newInstance();

                try {
                    // BeforeEach
                    for (Method before : beforeEachMethods) {
                        before.invoke(instance);
                    }

                    // 执行测试
                    testMethod.invoke(instance);

                    // AfterEach
                    for (Method after : afterEachMethods) {
                        after.invoke(instance);
                    }

                    System.out.println("[PASS] " + testMethod.getName());

                } catch (InvocationTargetException e) {
                    // 测试方法抛出的异常被 InvocationTargetException 包装
                    Throwable actualException = e.getCause();

                    // 检查是否匹配 expected
                    Test testAnn = testMethod.getAnnotation(Test.class);
                    Class<?> expected = testAnn.expected();
                    if (expected != Test.None.class
                            && expected.isInstance(actualException)) {
                        System.out.println("[PASS] " + testMethod.getName()
                                + " (expected " + expected.getSimpleName() + ")");
                    } else {
                        System.out.println("[FAIL] " + testMethod.getName()
                                + " → " + actualException.getMessage());
                    }
                }
            }

        } catch (Exception e) {
            e.printStackTrace();
        }
    }

    // ==================== 使用示例 ====================
    static class UserServiceTest {
        @BeforeEach
        void setup() {
            System.out.println("  初始化测试环境...");
        }

        @Test
        void testFindUser() {
            System.out.println("  执行: 查询用户测试");
            assert "张三".equals("张三");
        }

        @Test(expected = IllegalArgumentException.class)
        void testInvalidInput() {
            System.out.println("  执行: 非法参数测试");
            throw new IllegalArgumentException("参数不能为空");
        }

        @AfterEach
        void teardown() {
            System.out.println("  清理测试资源...");
        }
    }

    public static void main(String[] args) {
        MiniJUnit.run(UserServiceTest.class);
    }
}
```

> ⚠️ **注意**：真正的 JUnit 5 (Jupiter) 使用了 `TestEngine` SPI 架构，配合 `MethodHandle` 而非 `Method.invoke()` 以获得更好的性能，但核心原理完全一致。

> 🎯 **核心要点**：JUnit测试框架本质 = **`@Test`注解做标记** + **反射扫描和调用** + **异常机制判断结果**。每个框架的「魔法」拆开看，都是这三板斧。

## 4. 手写框架实战

### 4.1 实战1：迷你依赖注入容器 (Mini-DI Container)

完整的可运行依赖注入容器，支持 `@Component`、`@Autowired`、包扫描和泛型 BeanFactory。

```java
import java.io.File;
import java.lang.annotation.ElementType;
import java.lang.annotation.Retention;
import java.lang.annotation.RetentionPolicy;
import java.lang.annotation.Target;
import java.lang.reflect.Constructor;
import java.lang.reflect.Field;
import java.net.URL;
import java.util.*;
import java.util.concurrent.ConcurrentHashMap;

// ==================== 1. 注解定义 ====================
@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.TYPE)
@interface Component {
    String value() default "";
}

@Retention(RetentionPolicy.RUNTIME)
@Target({ElementType.FIELD, ElementType.CONSTRUCTOR})
@interface Autowired {
}

// ==================== 2. 泛型 BeanFactory ====================
interface BeanFactory {
    // 按名称获取 (泛型安全)
    <T> T getBean(String name, Class<T> requiredType);

    // 按类型获取
    <T> T getBean(Class<T> requiredType);

    // 注册
    void registerBean(String name, Object bean);
}

// ==================== 3. ClassPath 扫描器 ====================
class ClassPathScanner {
    public static List<Class<?>> scan(String basePackage) {
        List<Class<?>> classes = new ArrayList<>();
        String path = basePackage.replace('.', '/');

        try {
            Enumeration<URL> resources = Thread.currentThread()
                    .getContextClassLoader().getResources(path);

            while (resources.hasMoreElements()) {
                URL resource = resources.nextElement();
                if (resource.getProtocol().equals("file")) {
                    scanDirectory(new File(resource.getFile()), basePackage, classes);
                }
            }
        } catch (Exception e) {
            throw new RuntimeException("Scan failed", e);
        }
        return classes;
    }

    private static void scanDirectory(File dir, String packageName, List<Class<?>> classes) {
        File[] files = dir.listFiles();
        if (files == null) return;

        for (File file : files) {
            if (file.isDirectory()) {
                scanDirectory(file, packageName + "." + file.getName(), classes);
            } else if (file.getName().endsWith(".class")) {
                String className = packageName + "."
                        + file.getName().replace(".class", "");
                try {
                    // 关键：Class.forName 加载类
                    classes.add(Class.forName(className));
                } catch (ClassNotFoundException e) {
                    // skip
                }
            }
        }
    }
}

// ==================== 4. Mini ApplicationContext ====================
class MiniApplicationContext implements BeanFactory {
    // 容器本体 —— Bean 存储
    private final Map<String, Object> singletonObjects = new ConcurrentHashMap<>();
    // Bean 定义信息
    private final Map<String, Class<?>> beanDefinitions = new HashMap<>();

    public MiniApplicationContext(String basePackage) {
        // 步骤1：扫描包下所有类
        List<Class<?>> classes = ClassPathScanner.scan(basePackage);

        // 步骤2：筛选带 @Component 的类，注册 BeanDefinition
        for (Class<?> clazz : classes) {
            Component component = clazz.getAnnotation(Component.class);
            if (component != null) {
                String beanName = component.value();
                if (beanName.isEmpty()) {
                    // 默认首字母小写
                    beanName = decapitalize(clazz.getSimpleName());
                }
                beanDefinitions.put(beanName, clazz);
            }
        }

        // 步骤3：创建 Bean 实例 (解决循环依赖暂不支持)
        for (String beanName : beanDefinitions.keySet()) {
            createBean(beanName);
        }
    }

    private Object createBean(String beanName) {
        if (singletonObjects.containsKey(beanName)) {
            return singletonObjects.get(beanName);
        }

        Class<?> clazz = beanDefinitions.get(beanName);
        if (clazz == null) {
            throw new RuntimeException("No bean definition for: " + beanName);
        }

        try {
            // 步骤3.1：反射创建实例 (默认无参构造)
            Constructor<?> constructor = clazz.getDeclaredConstructor();
            constructor.setAccessible(true);
            Object instance = constructor.newInstance();

            // 先放入容器，解决循环引用 (此处简化)
            singletonObjects.put(beanName, instance);

            // 步骤3.2：反射注入 @Autowired 依赖
            for (Field field : clazz.getDeclaredFields()) {
                Autowired autowired = field.getAnnotation(Autowired.class);
                if (autowired != null) {
                    // 按类型查找依赖 Bean
                    String depName = findBeanNameByType(field.getType());
                    if (depName == null) {
                        throw new RuntimeException("Cannot find dependency: "
                                + field.getType().getName());
                    }
                    Object dependency = createBean(depName);
                    field.setAccessible(true);
                    field.set(instance, dependency); // 反射注入
                }
            }

            return instance;

        } catch (Exception e) {
            throw new RuntimeException("Failed to create bean: " + beanName, e);
        }
    }

    private String findBeanNameByType(Class<?> type) {
        for (Map.Entry<String, Class<?>> entry : beanDefinitions.entrySet()) {
            if (type.isAssignableFrom(entry.getValue())) {
                return entry.getKey();
            }
        }
        return null;
    }

    // ==================== 泛型 BeanFactory 实现 ====================
    @Override
    @SuppressWarnings("unchecked")
    public <T> T getBean(String name, Class<T> requiredType) {
        Object bean = singletonObjects.get(name);
        if (bean == null) {
            throw new RuntimeException("No bean: " + name);
        }
        // 泛型确保类型安全
        if (!requiredType.isInstance(bean)) {
            throw new RuntimeException("Type mismatch: " + name);
        }
        return (T) bean;
    }

    @Override
    @SuppressWarnings("unchecked")
    public <T> T getBean(Class<T> requiredType) {
        for (Object bean : singletonObjects.values()) {
            if (requiredType.isInstance(bean)) {
                return (T) bean;
            }
        }
        throw new RuntimeException("No bean of type: " + requiredType);
    }

    @Override
    public void registerBean(String name, Object bean) {
        singletonObjects.put(name, bean);
    }

    private static String decapitalize(String str) {
        if (str == null || str.isEmpty()) return str;
        return Character.toLowerCase(str.charAt(0)) + str.substring(1);
    }
}

// ==================== 5. 使用示例 ====================
@Component
class UserRepository {
    public String findById(Long id) {
        return "User{id=" + id + ", name='张三'}";
    }
}

@Component
class UserService {
    @Autowired
    private UserRepository userRepository;

    public String getUser(Long id) {
        return userRepository.findById(id);
    }
}

@Component("app")
class Application {
    @Autowired
    private UserService userService;

    public void run() {
        System.out.println(userService.getUser(1L));
    }
}

// 运行入口
public class MiniDIDemo {
    public static void main(String[] args) {
        // 扫描当前包，自动创建 Bean 并注入依赖
        MiniApplicationContext context = new MiniApplicationContext("");

        // 泛型 getBean —— 无需强转！
        Application app = context.getBean(Application.class);
        app.run(); // 输出：User{id=1, name='张三'}

        // 按名称 + 泛型安全获取
        UserService service = context.getBean("userService", UserService.class);
        System.out.println(service.getUser(2L));
    }
}
```

> 💡 **核心设计思路**：
> 1. `@Component` 标记哪些类需要被管理
> 2. `ClassPathScanner` 利用反射和 `Class.forName()` 扫描并加载类
> 3. 反射 `Constructor.newInstance()` 创建对象
> 4. `@Autowired` + 反射 `Field.set()` 完成依赖注入
> 5. 泛型 `BeanFactory<T>` 确保类型安全的获取

### 4.2 实战2：通用 DAO — BaseRepository\<T, ID\>

利用泛型+反射+注解实现通用 CRUD 基类。

```java
import java.lang.annotation.ElementType;
import java.lang.annotation.Retention;
import java.lang.annotation.RetentionPolicy;
import java.lang.annotation.Target;
import java.lang.reflect.Field;
import java.lang.reflect.ParameterizedType;
import java.lang.reflect.Type;
import java.util.*;
import java.util.stream.Collectors;

// ==================== 注解 ====================
@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.TYPE)
@interface Table {
    String value(); // 表名
}

@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.FIELD)
@interface Column {
    String value();  // 列名
    boolean id() default false; // 是否主键
}

// ==================== 用户实体 ====================
@Table("t_user")
class User {
    @Column(value = "id", id = true)
    private Long id;

    @Column("user_name")
    private String userName;

    @Column("email")
    private String email;

    // getter/setter (省略以保持简洁)
    public Long getId() { return id; }
    public void setId(Long id) { this.id = id; }
    public String getUserName() { return userName; }
    public void setUserName(String userName) { this.userName = userName; }
    public String getEmail() { return email; }
    public void setEmail(String email) { this.email = email; }

    @Override
    public String toString() {
        return "User{id=" + id + ", userName='" + userName + "', email='" + email + "'}";
    }
}

// ==================== 通用 DAO 基类 ====================
abstract class BaseRepository<T, ID> {
    private Class<T> entityClass;
    private String tableName;
    private Map<String, Field> columnFieldMap = new LinkedHashMap<>();
    private Field idField;

    @SuppressWarnings("unchecked")
    public BaseRepository() {
        // 核心：通过泛型获取 T 的实际类型
        // 获取当前类的父类的泛型信息
        Type genericSuperclass = getClass().getGenericSuperclass();

        // BaseRepository<User, Long> 的 ParameterizedType
        // getActualTypeArguments()[0] = User.class
        // getActualTypeArguments()[1] = Long.class
        if (genericSuperclass instanceof ParameterizedType) {
            ParameterizedType pt = (ParameterizedType) genericSuperclass;
            Type[] actualTypes = pt.getActualTypeArguments();
            this.entityClass = (Class<T>) actualTypes[0]; // T = User
        }

        // 解析注解：表名
        Table table = entityClass.getAnnotation(Table.class);
        if (table != null) {
            this.tableName = table.value();
        } else {
            this.tableName = entityClass.getSimpleName().toLowerCase();
        }

        // 解析注解：字段映射
        for (Field field : entityClass.getDeclaredFields()) {
            Column column = field.getAnnotation(Column.class);
            if (column != null) {
                field.setAccessible(true);
                columnFieldMap.put(column.value(), field);
                if (column.id()) {
                    this.idField = field;
                }
            }
        }
    }

    // ==================== 泛型 CRUD 方法 ====================

    // 根据主键查询 —— 泛型 ID 类型
    public T findById(ID id) {
        String sql = "SELECT * FROM " + tableName + " WHERE "
                + getIdColumnName() + " = ?";
        System.out.println("[SQL] " + sql + " [params] " + id);

        // 实际应使用 JDBC 执行查询并映射 ResultSet
        // 此处模拟返回空实体
        return createEmptyEntity();
    }

    // 查询所有 —— 泛型 List<T>
    public List<T> findAll() {
        String sql = "SELECT * FROM " + tableName;
        System.out.println("[SQL] " + sql);
        return new ArrayList<>();
    }

    // 插入 —— 反射获取字段值
    public int insert(T entity) {
        StringBuilder columns = new StringBuilder();
        StringBuilder values = new StringBuilder();
        List<Object> params = new ArrayList<>();

        for (Map.Entry<String, Field> entry : columnFieldMap.entrySet()) {
            try {
                Object value = entry.getValue().get(entity); // 反射获取字段值
                if (value != null) {
                    if (columns.length() > 0) columns.append(", ");
                    columns.append(entry.getKey());
                    if (values.length() > 0) values.append(", ");
                    values.append("?");
                    params.add(value);
                }
            } catch (IllegalAccessException e) {
                throw new RuntimeException(e);
            }
        }

        String sql = "INSERT INTO " + tableName
                + " (" + columns + ") VALUES (" + values + ")";
        System.out.println("[SQL] " + sql + " [params] " + params);
        return 1;
    }

    // 更新 —— 基于主键
    public int update(T entity) {
        StringBuilder setClause = new StringBuilder();
        List<Object> params = new ArrayList<>();
        Object idValue = null;

        for (Map.Entry<String, Field> entry : columnFieldMap.entrySet()) {
            try {
                Object value = entry.getValue().get(entity);
                if (entry.getValue() == idField) {
                    idValue = value; // 主键作为 WHERE 条件
                } else if (value != null) {
                    if (setClause.length() > 0) setClause.append(", ");
                    setClause.append(entry.getKey()).append(" = ?");
                    params.add(value);
                }
            } catch (IllegalAccessException e) {
                throw new RuntimeException(e);
            }
        }

        params.add(idValue); // WHERE 条件的参数
        String sql = "UPDATE " + tableName + " SET " + setClause
                + " WHERE " + getIdColumnName() + " = ?";
        System.out.println("[SQL] " + sql + " [params] " + params);
        return 1;
    }

    // 删除
    public int deleteById(ID id) {
        String sql = "DELETE FROM " + tableName + " WHERE "
                + getIdColumnName() + " = ?";
        System.out.println("[SQL] " + sql + " [params] " + id);
        return 1;
    }

    // ==================== 辅助方法 ====================

    private String getIdColumnName() {
        for (Map.Entry<String, Field> entry : columnFieldMap.entrySet()) {
            if (entry.getValue() == idField) {
                return entry.getKey();
            }
        }
        return "id";
    }

    private T createEmptyEntity() {
        try {
            return entityClass.getDeclaredConstructor().newInstance();
        } catch (Exception e) {
            throw new RuntimeException(e);
        }
    }

    // 获取实体类 (供子类使用)
    protected Class<T> getEntityClass() {
        return entityClass;
    }
}

// ==================== 具体 DAO ====================
class UserRepository extends BaseRepository<User, Long> {
    // 继承后自动获得泛型绑定：T=User, ID=Long
    // 自动获取表名 t_user
    // 自动映射字段

    // 可以添加自定义查询
    public User findByUserName(String userName) {
        System.out.println("[SQL] SELECT * FROM t_user WHERE user_name = ? [params] " + userName);
        return createEmptyEntity();
    }
}

// ==================== 使用示例 ====================
public class GenericDAODemo {
    public static void main(String[] args) {
        UserRepository userRepo = new UserRepository();

        // 泛型安全的 CRUD
        User user = new User();
        user.setId(1L);
        user.setUserName("李四");
        user.setEmail("lisi@example.com");

        userRepo.insert(user);
        userRepo.findById(1L);
        userRepo.update(user);
        userRepo.deleteById(1L);
        userRepo.findByUserName("李四");

        // 输出示例:
        // [SQL] INSERT INTO t_user (id, user_name, email) VALUES (?, ?, ?) [params] [1, 李四, lisi@example.com]
        // [SQL] SELECT * FROM t_user WHERE id = ? [params] 1
        // [SQL] UPDATE t_user SET user_name = ?, email = ? WHERE id = ? [params] [李四, lisi@example.com, 1]
        // [SQL] DELETE FROM t_user WHERE id = ? [params] 1

    }

```

> 🎯 **核心要点**：
> 1. **泛型** `BaseRepository<T, ID>` 约束实体类型和主键类型，让 CRUD 方法类型安全
> 2. **反射** `getGenericSuperclass()` + `getActualTypeArguments()` 获取子类绑定的实际泛型类型
> 3. **注解** `@Table` / `@Column` 提供元数据，反射解析实现 Entity ↔ SQL 自动映射
> 4. 这就是 Spring Data JPA / MyBatis-Plus 的底层简化原理

### 4.3 实战3：声明式事务 @Transactional 模拟

利用动态代理实现声明式事务管理。

```java
import java.lang.annotation.ElementType;
import java.lang.annotation.Retention;
import java.lang.annotation.RetentionPolicy;
import java.lang.annotation.Target;
import java.lang.reflect.InvocationHandler;
import java.lang.reflect.Method;
import java.lang.reflect.Proxy;

// ==================== @Transactional 注解 ====================
@Retention(RetentionPolicy.RUNTIME)
@Target({ElementType.TYPE, ElementType.METHOD})
@interface Transactional {
    // 遇到什么异常回滚，默认 RuntimeException
    Class<? extends Throwable> rollbackOn() default RuntimeException.class;
}

// ==================== 事务管理器 (模拟) ====================
class TransactionManager {
    private static final ThreadLocal<Boolean> TX_STATUS = ThreadLocal.withInitial(() -> false);

    public static void beginTransaction() {
        TX_STATUS.set(true);
        System.out.println("[事务] 开启事务...");
    }

    public static void commit() {
        TX_STATUS.set(false);
        System.out.println("[事务] 提交事务 ✓");
    }

    public static void rollback() {
        TX_STATUS.set(false);
        System.out.println("[事务] 回滚事务 ✗");
    }

    public static boolean isActive() {
        return TX_STATUS.get();
    }
}

// ==================== 用户服务接口 ====================
interface UserService {
    void createUser(String name);
    void deleteUser(Long id);
}

// ==================== 具体实现 ====================
class UserServiceImpl implements UserService {
    @Override
    @Transactional(rollbackOn = RuntimeException.class)
    public void createUser(String name) {
        System.out.println("[业务] 插入用户: " + name);
        System.out.println("[业务] 发送欢迎邮件...");
        // 模拟异常触发回滚
        // throw new RuntimeException("DB连接失败");
    }

    @Override
    public void deleteUser(Long id) {
        System.out.println("[业务] 删除用户: " + id);
    }
}

// ==================== 事务代理工厂 ====================
class TransactionProxyFactory {
    @SuppressWarnings("unchecked")
    public static <T> T createProxy(T target) {
        return (T) Proxy.newProxyInstance(
                target.getClass().getClassLoader(),
                target.getClass().getInterfaces(),
                new TransactionInvocationHandler(target)
        );
    }

    private static class TransactionInvocationHandler implements InvocationHandler {
        private final Object target;

        TransactionInvocationHandler(Object target) {
            this.target = target;
        }

        @Override
        public Object invoke(Object proxy, Method method, Object[] args) throws Throwable {
            // 1. 获取目标方法上的 @Transactional 注解
            Method targetMethod = target.getClass().getMethod(
                    method.getName(), method.getParameterTypes());
            Transactional tx = targetMethod.getAnnotation(Transactional.class);

            // 2. 如果方法或类上没有 @Transactional，直接执行
            if (tx == null) {
                return method.invoke(target, args);
            }

            // 3. 开启事务
            TransactionManager.beginTransaction();

            try {
                // 4. 执行目标方法
                Object result = method.invoke(target, args);

                // 5. 正常 → 提交
                TransactionManager.commit();
                return result;

            } catch (Throwable e) {
                // 6. 获取真实异常 (InvocationTargetException 包装)
                Throwable actualEx = e instanceof java.lang.reflect.InvocationTargetException
                        ? e.getCause() : e;

                // 7. 判断是否需要回滚
                if (tx.rollbackOn().isInstance(actualEx)) {
                    TransactionManager.rollback();
                } else {
                    TransactionManager.commit(); // 非指定异常也提交
                }

                throw actualEx;
            }
        }
    }
}

// ==================== 使用示例 ====================
public class TransactionalDemo {
    public static void main(String[] args) {
        UserService userService = new UserServiceImpl();

        // 创建事务代理
        UserService proxy = TransactionProxyFactory.createProxy(userService);

        // 调用带事务的方法
        proxy.createUser("王五");

        System.out.println("----------------------------");

        // 调用不带事务的方法
        proxy.deleteUser(1L);
    }
}
```

> ⚠️ **局限性说明**：真实 Spring `@Transactional` 远比这复杂：
> - 支持传播行为 (`Propagation.REQUIRED`, `REQUIRES_NEW` 等)
> - 支持隔离级别 (`Isolation.READ_COMMITTED` 等)
> - 使用 AOP (CGLIB/JDK代理) 而非手动创建代理
> - 通过 `TransactionInterceptor` 在方法调用链中拦截

> 🎯 **核心要点**：声明式事务的本质 = **动态代理** + **`@Transactional`注解解析** + **反射调用原始方法** + **try-catch控制提交/回滚**。

### 4.4 实战4：JSON 序列化器 (Object → JSON)

利用反射实现通用 JSON 序列化，支持泛型集合。

```java
import java.lang.reflect.Array;
import java.lang.reflect.Field;
import java.lang.reflect.ParameterizedType;
import java.lang.reflect.Type;
import java.util.*;

public class MiniJsonSerializer {

    // ==================== 序列化核心 ====================
    public static String toJson(Object obj) {
        if (obj == null) return "null";
        if (isPrimitiveOrWrapper(obj)) return toPrimitiveJson(obj);
        if (obj instanceof String) return "\"" + escapeJson((String) obj) + "\"";
        if (obj instanceof Enum) return "\"" + obj.toString() + "\"";
        if (obj instanceof Date) return "\"" + obj.toString() + "\"";
        if (obj instanceof Collection) return toJsonArray((Collection<?>) obj);
        if (obj instanceof Map) return toJsonMap((Map<?, ?>) obj);
        if (obj.getClass().isArray()) return toJsonArrayFromArray(obj);
        return toJsonObject(obj);
    }

    // ==================== 对象转 JSON ====================
    private static String toJsonObject(Object obj) {
        StringBuilder sb = new StringBuilder("{");
        Field[] fields = obj.getClass().getDeclaredFields();

        boolean first = true;
        for (Field field : fields) {
            field.setAccessible(true);
            try {
                Object value = field.get(obj);
                if (value != null) {
                    if (!first) sb.append(", ");
                    sb.append("\"").append(field.getName()).append("\":");
                    sb.append(toJson(value));
                    first = false;
                }
            } catch (IllegalAccessException e) {
                // skip inaccessible fields
            }
        }
        sb.append("}");
        return sb.toString();
    }

    // ==================== 集合转 JSON ====================
    private static String toJsonArray(Collection<?> collection) {
        StringBuilder sb = new StringBuilder("[");
        boolean first = true;
        for (Object item : collection) {
            if (!first) sb.append(", ");
            sb.append(toJson(item));
            first = false;
        }
        sb.append("]");
        return sb.toString();
    }

    private static String toJsonArrayFromArray(Object array) {
        StringBuilder sb = new StringBuilder("[");
        int length = Array.getLength(array);
        for (int i = 0; i < length; i++) {
            if (i > 0) sb.append(", ");
            sb.append(toJson(Array.get(array, i)));
        }
        sb.append("]");
        return sb.toString();
    }

    // ==================== Map 转 JSON ====================
    private static String toJsonMap(Map<?, ?> map) {
        StringBuilder sb = new StringBuilder("{");
        boolean first = true;
        for (Map.Entry<?, ?> entry : map.entrySet()) {
            if (!first) sb.append(", ");
            sb.append("\"").append(entry.getKey()).append("\":");
            sb.append(toJson(entry.getValue()));
            first = false;
        }
        sb.append("}");
        return sb.toString();
    }

    // ==================== 基本类型 ====================
    private static String toPrimitiveJson(Object obj) {
        if (obj instanceof Boolean || obj instanceof Number) {
            return obj.toString();
        }
        return "\"" + obj.toString() + "\"";
    }

    private static boolean isPrimitiveOrWrapper(Object obj) {
        return obj instanceof Boolean || obj instanceof Number
                || obj instanceof Character;
    }

    private static String escapeJson(String s) {
        return s.replace("\\", "\\\\")
                .replace("\"", "\\\"")
                .replace("\n", "\\n")
                .replace("\r", "\\r")
                .replace("\t", "\\t");
    }

    // ==================== 泛型反序列化 (简化) ====================
    @SuppressWarnings("unchecked")
    public static <T> T fromJson(String json, Class<T> clazz) {
        // 仅演示反序列化单对象
        if (clazz == String.class) {
            return (T) json.replace("\"", "");
        }
        if (clazz == Integer.class || clazz == int.class) {
            return (T) Integer.valueOf(json.trim());
        }
        if (clazz == Long.class || clazz == long.class) {
            return (T) Long.valueOf(json.trim());
        }
        if (clazz == Double.class || clazz == double.class) {
            return (T) Double.valueOf(json.trim());
        }
        if (clazz == Boolean.class || clazz == boolean.class) {
            return (T) Boolean.valueOf(json.trim());
        }

        // 复杂对象反序列化 (极简版)
        try {
            T instance = clazz.getDeclaredConstructor().newInstance();
            // 简化处理：跳过实际 JSON 解析
            return instance;
        } catch (Exception e) {
            throw new RuntimeException("Cannot deserialize to " + clazz, e);
        }
    }

    // 带泛型的反序列化签名 (供扩展)
    public static <T> List<T> fromJsonList(String json, Class<T> elementType) {
        // 实际应解析 JSON 数组，逐个反序列化
        return new ArrayList<>();
    }

    // ==================== 数据模型 ====================
    static class User {
        private Long id;
        private String name;
        private Integer age;
        private String[] tags;
        private List<String> hobbies;

        public User() {} // 无参构造

        public User(Long id, String name, Integer age, String[] tags, List<String> hobbies) {
            this.id = id;
            this.name = name;
            this.age = age;
            this.tags = tags;
            this.hobbies = hobbies;
        }

        // getter (供序列化反射获取字段值)
        public Long getId() { return id; }
        public String getName() { return name; }
        public Integer getAge() { return age; }
        public String[] getTags() { return tags; }
        public List<String> getHobbies() { return hobbies; }
    }

    // ==================== 使用示例 ====================
    public static void main(String[] args) {
        // 基本对象序列化
        User user = new User(1L, "赵六", 25,
                new String[]{"java", "python"},
                Arrays.asList("读书", "跑步"));

        String json = MiniJsonSerializer.toJson(user);
        System.out.println("序列化结果:");
        System.out.println(json);
        // 输出: {"id":1,"name":"赵六","age":25,"tags":["java","python"],"hobbies":["读书","跑步"]}

        // 泛型 List 序列化
        List<User> users = Arrays.asList(user, user);
        String listJson = MiniJsonSerializer.toJson(users);
        System.out.println("\nList 序列化:");
        System.out.println(listJson);
        // 输出: [{"id":1,...}, {"id":1,...}]

        // Map 序列化
        Map<String, Object> map = new HashMap<>();
        map.put("code", 200);
        map.put("data", user);
        String mapJson = MiniJsonSerializer.toJson(map);
        System.out.println("\nMap 序列化:");
        System.out.println(mapJson);
        // 输出: {"code":200,"data":{"id":1,...}}

        // 反序列化 (基本类型)
        Integer num = MiniJsonSerializer.fromJson("42", Integer.class);
        System.out.println("\n反序列化: " + num);
    }
}
```

> 💡 **值得注意**：
> - 反射 `Field.get()` 可以获取任意访问权限的字段值（配合 `setAccessible(true)`）
> - 数组用 `Array.get()` 统一处理，避免了具体类型判断
> - 泛型集合的序列化完全不需要泛型信息，因为运行时实际对象的类型是确定的
> - 反序列化才真正需要泛型信息（因为要决定创建什么类型的对象）

> 🎯 **核心要点**：JSON序列化器的本质 = **反射遍历字段** + **递归序列化** + **泛型支持集合类型**。Jackson / Gson 的核心原理就是在此基础上增加类型适配器和性能优化。

## 5. 框架设计中的设计模式

「三剑合璧」是框架的工具箱，而设计模式是框架的蓝图。前者解决"怎么做"，后者解决"怎么组织"。

### 5.1 工厂模式 — BeanFactory

| 角色 | 对应实现 | 作用 |
|------|---------|------|
| 产品接口 | `BeanFactory` | 定义获取Bean的契约 |
| 具体工厂 | `DefaultListableBeanFactory` / `MiniApplicationContext` | 负责创建和管理Bean |
| 产品 | 所有 `@Component` 类 | 工厂生产的具体对象 |

```java
// 工厂模式核心：将「创建对象」和「使用对象」分离
// 调用方不需要知道对象的构造细节
UserService service = context.getBean(UserService.class);
// 背后可能涉及：构造器注入、属性设置、BeanPostProcessor处理...
```

### 5.2 代理模式 — AOP

| 角色 | 对应实现 | 作用 |
|------|---------|------|
| 主题接口 | `UserService` | 业务接口 |
| 真实主题 | `UserServiceImpl` | 核心业务逻辑 |
| 代理 | `TransactionProxyFactory` 创建的代理 | 织入横切关注点（事务/日志/安全） |

Spring AOP 使用两种代理策略：

```java
// JDK 动态代理 (有接口时)
// → 通过 Proxy.newProxyInstance 生成接口代理

// CGLIB (无接口时)
// → 通过字节码增强生成子类代理
// → 本质是 ASM 操作字节码
```

### 5.3 模板方法模式 — JdbcTemplate

```java
// JdbcTemplate 定义了 SQL 执行骨架
// 具体的结果映射交给回调

public <T> List<T> query(String sql, RowMapper<T> mapper) {
    Connection conn = getConnection();    // 固定步骤
    PreparedStatement ps = conn.prepareStatement(sql);  // 固定步骤
    ResultSet rs = ps.executeQuery();     // 固定步骤
    List<T> results = new ArrayList<>();
    while (rs.next()) {
        results.add(mapper.mapRow(rs));   // 可变步骤 → 回调
    }
    close(rs, ps, conn);                  // 固定步骤
    return results;
}

// 使用时只需提供 RowMapper 的匿名实现
// 这就是模板方法模式
```

### 5.4 策略模式 — 缓存策略

```java
// 定义策略接口
interface CacheStrategy {
    <T> T get(String key, Class<T> type);
    void put(String key, Object value);
}

// 具体策略
class RedisCacheStrategy implements CacheStrategy { /* ... */ }
class LocalCacheStrategy implements CacheStrategy { /* ... */ }

// 运行时切换
CacheStrategy strategy = useRedis ? new RedisCacheStrategy()
                                   : new LocalCacheStrategy();
```

### 5.5 观察者模式 — 事件监听

### 设计模式 vs 三剑合璧的关系

| 设计模式 | 使用的核心技术 | 典型框架应用 |
|---------|--------------|------------|
| 工厂模式 | 反射 `Constructor.newInstance()` | Spring BeanFactory |
| 代理模式 | `Proxy.newProxyInstance()` / CGLIB | Spring AOP / MyBatis Mapper |
| 模板方法 | 泛型 `<T>` + 回调接口 | JdbcTemplate / RestTemplate |
| 策略模式 | 泛型接口 + 反射加载实现类 | 缓存/认证策略切换 |
| 单例模式 | ConcurrentHashMap 存储 | Spring Bean 默认 scope |
| 观察者模式 | 反射调用 @EventListener 方法 | Spring Event |

> 🎯 **核心要点**：设计模式是框架的"架构蓝图"，泛型/反射/注解是"施工工具"。理解三者的协同，才能真正读懂框架源码。框架的本质 = **设计模式(骨架) + 泛型(类型约束) + 反射(运行时动态) + 注解(配置元数据)**。
