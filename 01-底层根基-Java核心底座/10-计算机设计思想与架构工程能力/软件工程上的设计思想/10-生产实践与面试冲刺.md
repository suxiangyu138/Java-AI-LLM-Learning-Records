# 10-生产实践与面试冲刺

> 定位：28 条思想的收束篇——工程落地清单、故障排查表、28 条速记表、12 道面试题与答题模板。

## 生产落地清单（12 项）

1. **类级设计**：SOLID 五条过一遍新类（变更理由唯一、扩展点按需、契约可替换、接口按需、依赖抽象）——不是每条必查，是变更时过一遍。
2. **模块边界**：新模块自问三问——内聚（服务同一目的？）、耦合（只依赖接口？）、正交（变化维度分离？）。
3. **复杂度门禁**：新增依赖（中间件/框架）前过 KISS 四问（团队熟悉度/部署复杂度/运维负担/心智成本）；新功能过 YAGNI（现在需要吗）。
4. **DRY 审查**：复制粘贴代码登记（三处重复必抽公共），合并前验证"修改动机相同"。
5. **健壮性**：所有外部输入有校验（接口层格式 + 业务层语义）；错误立即失败不吞；写操作幂等化（Token/业务 Key/版本号三选一）。
6. **状态机**：流程类业务（订单/审批/支付）状态与事件枚举化、迁移表集中定义、CAS 更新、非法迁移抛错。
7. **容错**：外部调用配重试（幂等 + 指数退避）与熔断；核心链路降级方案 + 兜底数据；开关配置化。
8. **配置治理**：规则参数进配置中心；逻辑不搬进配置；功能开关按环境隔离。
9. **权限**：账号按职责分权（应用账号最小面）；接口只返回必要字段；权限审计季度执行。
10. **可观测**：每个外部调用/状态迁移/异常分支有埋点；告警有指标依据；日志脱敏检查。
11. **缓存**：热点数据缓存 + 失效策略 + 四大问题防护（击穿锁/穿透布隆/雪崩抖动/一致性消息）；命中率监控。
12. **备份冗余**：3-2-1 备份 + 季度恢复演练；无单点部署；RPO/RTO 量化记录。

## 故障排查表

| 症状 | 第一怀疑 | 对应思想 |
|---|---|---|
| 改了 A 服务，B/C/D 全炸 | 耦合过高/边界错误 | 高内聚低耦合、迪米特 |
| 新增需求改 500 行老代码 | OCP 违规（扩展点缺失） | 开闭原则 |
| 订单状态出现"已发货又待支付" | 状态机缺失（散落 setStatus） | 状态机思想 |
| 重复提交产生两条订单 | 幂等缺失 | 幂等设计 |
| MQ 重复消费导致重复扣款 | 消费端未幂等化 | 幂等设计 |
| 下游故障把主链路拖垮 | 无熔断无降级 | 容错设计 |
| 线上问题无法定位 | 无链路追踪/日志不全 | 可观测性 |
| 改个规则要发版等审批 | 规则硬编码 | 配置驱动 |
| 热点 key 过期 DB 被打爆 | 缓存击穿未防护 | 缓存思想 |
| 账号泄漏后全库可删 | 权限过大 | 最小权限 |
| 数据误删无法恢复 | 备份缺失/未验证 | 备份冗余 |
| 并发扣库存超卖 | 乐观/悲观选型错误 | 悲观乐观 |

## 28 条思想速记表（面试背诵版）

**对象层**：SRP"一个类一个变更理由"；OCP"扩展开放修改关闭"；LSP"子类契约可替换"；ISP"接口按需切小"；DIP"依赖抽象不依赖细节"；迪米特"只交直接朋友"；高内聚低耦合"相关内聚无关解耦"；正交"改 A 不动 B"；KISS"简单优先"；YAGNI"现在不做"；DRY"逻辑才抽"；SoC"按问题切分"。

**韧性层**：防御式"不信输入"；Fail-Fast"错要早爆"；容错"局部坏整体好"；幂等"重复执行结果一致"；状态机"流转显式契约"；最小权限"权限最小面"；可观测"故障可定位"；缓存"空间换时间"；备份冗余"数据可恢复"。

**演进层**：配置驱动"规则可热改"；分层"改动局部化"；约定大于配置"默认就正确"；向后兼容"升级不伤客"。

**规模层**：分治"大拆小"；推拉"按需流动"；悲观乐观"按冲突率选锁"。

## 面试 12 题（含答题范式）

1. **SOLID 是什么？最常违反哪条？** → 五原则定义；工程中最常见是 SRP（上帝 Service）与 OCP（改老 if-else）；答题：定义 + 反例 + 修复路径。
2. **SRP 与 ISP 的区别？** → SRP 管类的职责（变更理由），ISP 管接口的切面（客户端依赖）；一个类可多接口，一个接口不可多职责。
3. **KISS/YAGNI/DRY 的边界？** → KISS 管怎么做、YAGNI 管做不做、DRY 管抄不抄；DRY 只抽"修改动机相同"的重复。
4. **高内聚低耦合怎么实现？** → 充血模型封装业务、防腐层/事件解耦、接口契约；度量：依赖数、变更耦合、LCOM。
5. **防御式编程 vs 疯狂 try-catch？** → 防御是提前拦截非法输入（校验分支），吞异常是隐藏错误；分层校验（接口格式 + 业务语义）。
6. **幂等怎么设计？** → 三方案（Token 防重复提交、业务 Key 防重复执行、版本号防并发覆盖）；2026 升级：操作版本号绑定业务状态。
7. **状态机为什么比 if-else 好？** → 合法迁移显式契约、非法迁移代码级拦截、可测试（每路径一用例）、CAS 并发安全、事件审计。
8. **熔断、限流、降级、重试的区别？** → 限流保护自己、熔断保护下游、降级保核心、重试治瞬时；顺序：重试→熔断→降级→兜底。
9. **缓存四大问题与解决？** → 击穿（锁/逻辑过期）、穿透（布隆/空值）、雪崩（抖动/多级）、一致性（Cache Aside + 消息失效）。
10. **悲观锁 vs 乐观锁怎么选？** → 冲突率 × 代价模型；高冲突复杂逻辑悲观，低冲突简短操作乐观（version/CAS）；分布式场景 Redisson vs 条件更新。
11. **接口升级怎么不破坏老客户端？** → 新增不删减 + 版本化 + 弃用周期 + 契约测试；破坏性变更提前公告 + 双版本并行。
12. **系统怎么从单体演进到分布式？** → 路线图：垂直优化（缓存/索引）→ 分治（分片/拆服务）→ 异步化（推拉结合）；YAGNI：到点才拆。

## 加分深度题

**Q：幂等与状态机回滚的冲突怎么解？** 操作版本号机制——(order_id, expected_version) 组合约束，回滚后 version 不回落，旧重试被拒（2026 华为云实证：冲突率千分级 → 十万分级）。

**Q：Kafka 是推还是拉？为什么？** 拉为主——消费者主动 pull，broker 不推；收益：消费者自主控制消费节奏（背压天然）、批量拉取高效；代价：实时性依赖轮询频率（可调）。对比 RabbitMQ 的推模型。

**Q：设计思想与设计模式的区别？** 思想是"为什么"（判断标准：SRP、OCP 是评价框架），模式是"怎么做"（模板：策略、观察者是方案）；原则指导模式选择，模式是原则的落地；"思想 × 场景 → 模式"是完整决策链。

**Q：AI 辅助开发时代设计思想的价值？** LLM 生成代码容易"表面正确、结构混乱"（贫血模型、上帝组件、过度抽象）——设计思想是 AI 产出的审查清单（KISS 删多余抽象、SRP 拆上帝类、SoC 防混责）；2026 共识：AI 时代工程师的核心能力从"写代码"转向"立结构与审结构"。

## 高频题的完整答题模板

**模板一：SOLID 类（1 分半版）**——先给定位（Robert Martin 提出的 OO 五原则，2026 仍是模块性/可测试性标准透镜）→ 逐条一句话（SRP 一个变更理由/OCP 扩展开放/ LSP 契约可替换/ISP 接口按需/DIP 依赖抽象）→ 工程反例（上帝 Service）→ 2026 修正（工具箱非清单、DIP 不是每个类都套接口、ArchUnit 自动化）。结构覆盖"是什么-怎么用-别滥用"三层。

**模板二：幂等类（2 分钟版）**——本质（重复执行无副作用）→ 四场景（重复提交/MQ 重放/接口重试/回滚重试）→ 三方案（Token/业务 Key/版本号）→ 边界陷阱（状态机回滚击穿——操作版本号组合约束）→ 与分布式事务协同（Saga/TCC 的幂等兜底）。这条链是 05 篇的全文骨架，背熟即可。

**模板三：状态机类（2 分钟版）**——核心（合法迁移显式契约）→ 三要素（状态/事件/迁移函数）→ 实现（迁移表/CAS/不可变状态）→ 结合（幂等内置 + 事件发布 + 事件溯源）→ 反例（散落 setStatus）。可附最小代码骨架（迁移表 + on 方法），展示"能写出来"而非"只背概念"。

**模板四：系统设计类（3 分钟版）**——"设计一个 XX 系统"用思想组合答：先高内聚低耦合（模块边界）→ 再状态机 + 幂等（核心流程正确性）→ 容错（重试熔断降级）→ 缓存（热点性能）→ 分治 + 乐观（规模与并发）→ 可观测（监控告警）。思想即是系统设计的检查清单，模板顺序即设计顺序。

## 面试速记（最后 30 秒版）

1. SOLID + KISS/YAGNI/DRY + 高内聚低耦合 + 关注点分离 = 对象与模块层。
2. 幂等、容错、状态机、配置驱动、分层、最小权限、可观测、向后兼容 = 系统层。
3. 答题结构万能公式：定义 → 工程体现 → 反例 → 选型边界 → 2026 修正。
4. 设计思想是"为什么"、设计模式是"怎么做"、架构风格是"在哪做"——三层分清，面试不慌。

> 🎯 **核心要点**：28 条思想的生产价值 = 评审清单（新代码过思想关）+ 排查地图（症状 → 思想定位）；面试价值 = 万能答题结构（定义→体现→反例→边界）+ 2026 修正点（幂等版本号、状态机 CAS、AI 审查清单）。能对任意问题输出"思想定位"，就是本体系毕业。
