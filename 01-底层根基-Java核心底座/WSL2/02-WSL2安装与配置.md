## 1. 安装 WSL2

### 1.1 前置条件

| 条件 | 要求 | 检查方式 |
|------|------|---------|
| **Windows 版本** | Win10 2004+ (Build 19041+) 或 Win11 | `winver` |
| **虚拟化** | BIOS 中开启 Intel VT-x / AMD-V | 任务管理器 → 性能 → 虚拟化: 已启用 |
| **Hyper-V** | Win10/11 Pro/Enterprise 内置；Home 版需手动启用 | `systeminfo \| findstr "Hyper-V"` |

### 1.2 一键安装（推荐）

```powershell
# 以管理员身份运行 PowerShell 或 Windows Terminal

# 一条命令：安装 WSL2 + 默认 Ubuntu 发行版
wsl --install

# 安装过程自动完成：
# 1. 启用"虚拟机平台"可选功能
# 2. 启用"Windows Subsystem for Linux"可选功能
# 3. 下载并安装最新的 Linux 内核更新包
# 4. 将 WSL2 设为默认版本
# 5. 下载并安装 Ubuntu（默认发行版）

# 重启后 Ubuntu 自动启动，设置 Linux 用户名和密码
```

### 1.3 指定发行版安装

```powershell
# 查看所有可安装的发行版
wsl --list --online
# 或 wsl -l -o

# 输出示例：
# NAME               FRIENDLY NAME
# Ubuntu             Ubuntu
# Ubuntu-24.04       Ubuntu 24.04 LTS
# Debian             Debian GNU/Linux
# Kali-linux         Kali Linux Rolling
# openSUSE-Tumbleweed  openSUSE Tumbleweed
# OracleLinux_9_0    Oracle Linux 9.0
# SUSE-Linux-Enterprise-Server-15-SP6  SUSE Linux Enterprise Server 15 SP6
# ...

# 安装指定发行版
wsl --install -d Ubuntu-24.04
wsl --install -d Debian
wsl --install -d Kali-linux
```

### 1.4 手动安装（旧版 Windows）

```powershell
# 如果 wsl --install 不可用（Win10 19041 之前）

# 步骤 1：启用 WSL 功能
dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart

# 步骤 2：启用虚拟机平台
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart

# 步骤 3：下载并安装 WSL2 Linux 内核更新包
# https://wslstorestorage.blob.core.windows.net/wslblob/wsl_update_x64.msi

# 步骤 4：设置 WSL2 为默认版本
wsl --set-default-version 2

# 步骤 5：从 Microsoft Store 安装 Linux 发行版
```

### 1.5 升级 WSL 内核

```powershell
# WSL 内核独立于发行版更新
wsl --update

# 查看当前 WSL 版本
wsl --version
# WSL 版本：2.4.x
# 内核版本：6.6.x
# WSLg 版本：1.0.x
# Windows 版本：10.0.26200.x

# 启用内核自动更新
wsl --update --pre-release    # 下载预发布版
```

## 2. 发行版选择与管理

### 2.1 发行版推荐

| 发行版 | 推荐场景 | 包管理器 | 特点 |
|------|---------|---------|------|
| **Ubuntu 24.04 LTS** | Java 开发（最推荐） | apt | 社区最大、教程最多、LTS 5 年支持 |
| **Debian** | 追求稳定、服务器一致 | apt | 比 Ubuntu 更轻量、更保守 |
| **Kali Linux** | 安全测试、渗透学习 | apt | 预装大量安全工具 |
| **Oracle Linux** | Oracle 生态开发 | dnf/yum | 与 RHEL 完全兼容 |
| **Alpine** | 极简、Docker 一致性 | apk | musl libc（与标准 glibc 不兼容） |
| **Arch (非官方)** | 滚动更新、最新工具 | pacman | ⚠️ WSL2 中无官方支持 |

> 💡 **Java 开发者首选 Ubuntu 24.04 LTS**：SDKMAN、Maven、Gradle、Docker 的最佳兼容性。

### 2.2 多发行版管理

```powershell
# === 查看已安装的发行版 ===
wsl --list --verbose
wsl -l -v
#   NAME            STATE           VERSION
# * Ubuntu-24.04    Running         2
#   Debian          Stopped         2
#   Kali-linux      Stopped         2
# * 表示默认发行版（wsl 命令默认进入）

# === 设置默认发行版 ===
wsl --set-default Ubuntu-24.04
wsl -s Ubuntu-24.04

# === 进入指定发行版 ===
wsl -d Debian
wsl --distribution Kali-linux

# === 以特定用户进入 ===
wsl -u root -d Ubuntu-24.04

# === 运行指定命令 ===
wsl ls -la /home
wsl -d Debian cat /etc/os-release

# === 终止发行版 ===
wsl --terminate Ubuntu-24.04
wsl -t Debian

# === 关机（终止所有发行版 + 释放内存） ===
wsl --shutdown

# === 注销/删除发行版 ===
wsl --unregister Kali-linux
# ⚠️ 删除后所有数据丢失！先 wsl --export 备份
```

### 2.3 首次进入后的初始化

```bash
# 进入 WSL2 Ubuntu 24.04 后，首先更新系统
sudo apt update && sudo apt upgrade -y

# 安装基础工具
sudo apt install -y build-essential curl wget git vim \
    software-properties-common apt-transport-https \
    ca-certificates gnupg lsb-release

# 安装 zsh + oh-my-zsh（提升终端体验）
sudo apt install -y zsh
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
chsh -s $(which zsh)

# 设置中文环境（可选）
sudo apt install -y language-pack-zh-hans
sudo update-locale LANG=zh_CN.UTF-8 LC_ALL=zh_CN.UTF-8
```

## 3. 全局配置：.wslconfig

### 3.1 配置位置与生效方式

```text
文件路径：%USERPROFILE%\.wslconfig  （如 C:\Users\用户名\.wslconfig）

生效方式：修改后执行 wsl --shutdown，然后重新启动 WSL2

影响范围：所有 WSL2 发行版
```

### 3.2 完整配置模板

```ini
# C:\Users\<用户名>\.wslconfig

[wsl2]
# ==========================================
# 内存限制（默认 = Windows 物理内存的 50% 或 8GB 取较小值）
# Java 开发者建议：物理 32GB → 12GB, 物理 16GB → 8GB
# ==========================================
memory=12GB

# ==========================================
# CPU 核心数限制（默认 = 所有核心）
# docker + 多个 Java 服务建议 4-8 核
# ==========================================
processors=8

# ==========================================
# Swap 交换空间（0 = 禁用）
# 内存不够用时使用，建议 ≥ 内存限制
# ==========================================
swap=12GB

# ==========================================
# Swap 文件位置（默认 = %USERPROFILE%\AppData\Local\Temp\swap.vhdx）
# ==========================================
# swapFile=C:\\swap.vhdx

# ==========================================
# localhost 端口转发（默认 true）
# WSL2 中监听的端口 → 映射到 Windows localhost
# ==========================================
localhostForwarding=true

# ==========================================
# 网络模式（Windows 11 22H2+ 支持）
# NAT      → 传统模式，独立子网（默认）
# Mirrored → 镜像 Windows 网络栈（共享 IP！）
# ==========================================
networkingMode=NAT

# ==========================================
# 防火墙集成（Mirrored 模式下有效）
# ==========================================
firewall=true

# ==========================================
# DNS 隧道（解决 VPN/代理下 DNS 问题）
# ==========================================
dnsTunneling=true

# ==========================================
# GUI 应用支持（WSLg → Linux GUI 直接显示在 Windows）
# ==========================================
guiApplications=true

# ==========================================
# 页面报告（Windows 可回收空闲内存）
# ==========================================
pageReporting=true

# ==========================================
# 内核命令行参数
# ==========================================
# kernelCommandLine=vsyscall=emulate

# ==========================================
# 自动代理（同步 Windows 代理设置到 WSL2）
# ==========================================
autoProxy=true
```

### 3.3 常见场景配置

```ini
# 场景一：大内存开发机（32-64GB）
[wsl2]
memory=16GB
processors=12
swap=16GB

# 场景二：轻薄本（8-16GB）
[wsl2]
memory=4GB
processors=4
swap=4GB

# 场景三：Docker 重度使用
[wsl2]
memory=16GB
processors=8
swap=8GB
networkingMode=Mirrored    # Docker 网络更简单
dnsTunneling=true
```

## 4. 发行版配置：wsl.conf

### 4.1 配置位置

```bash
# 每个发行版内部
/etc/wsl.conf

# 修改后重启发行版生效：
# PowerShell: wsl --terminate <发行版名>
# 然后重新: wsl -d <发行版名>
```

### 4.2 完整配置模板

```ini
# /etc/wsl.conf

# ==========================================
# [automount] 自动挂载 Windows 文件系统
# ==========================================
[automount]
# 是否启用自动挂载
enabled=true

# 挂载点（默认 /mnt/）
mountFsTab=true

# 挂载根目录（/mnt/c, /mnt/d ...）
root=/mnt/

# 挂载选项：
# uid/gid → 文件所有者
# fmask/dmask → 文件/目录权限掩码
# metadata → 支持 Linux 权限（可能影响性能）
options="metadata,uid=1000,gid=1000,umask=22,fmask=11"

# ==========================================
# [network] 网络配置
# ==========================================
[network]
# 自动生成 /etc/hosts（包含 Windows 主机名）
generateHosts=true

# 自动生成 /etc/resolv.conf（DNS 解析）
generateResolvConf=true

# 主机名（默认 = Windows 主机名）
hostname=wsl-ubuntu

# ==========================================
# [interop] Windows/Linux 互操作
# ==========================================
[interop]
# 允许从 WSL2 调用 Windows 程序（如 code, explorer.exe）
enabled=true

# 追加 Windows PATH 到 WSL2 PATH
appendWindowsPath=true

# ==========================================
# [user] 默认用户
# ==========================================
[user]
# wsl -d Ubuntu 进入时的默认用户
default=your_username

# ==========================================
# [boot] 启动命令（WSL2 启动时自动执行）
# ==========================================
[boot]
# systemd 支持（需要 WSL 0.67.6+）
systemd=true

# 启动时执行的命令
# command=service docker start
# command=mount -t drvfs G: /mnt/g
```

### 4.3 开发者推荐配置

```ini
# Java 开发者最常用的 wsl.conf

[automount]
enabled=true
root=/mnt/
options="metadata,uid=1000,gid=1000,dmask=022,fmask=133"

[network]
generateHosts=true
generateResolvConf=true
hostname=wsl-dev

[interop]
enabled=true
appendWindowsPath=true

[boot]
systemd=true
# Docker 自启动
command=service docker start
```

## 5. 发行版迁移与备份

### 5.1 导出/导入

```powershell
# === 导出（备份）===
# 将发行版导出为 tar 文件
wsl --export Ubuntu-24.04 D:\backup\ubuntu-backup.tar

# === 导入（恢复或迁移到其他盘）===
# 导入到指定目录（如从 C 盘迁到 D 盘）
wsl --import Ubuntu-24.04 D:\wsl\ubuntu D:\backup\ubuntu-backup.tar --version 2

# === 导入时指定默认用户 ===
# 先导入，然后修改 /etc/wsl.conf 或注册表
# 注册表位置：HKCU\Software\Microsoft\Windows\CurrentVersion\Lxss\
#   找到对应的发行版，修改 DefaultUid 为正确的 UID（1000）

# 或者更简单：直接 wsl -u yourname 进入，然后：
sudo sh -c 'echo "[user]\ndefault=yourname" >> /etc/wsl.conf'
```

### 5.2 克隆发行版

```powershell
# 1. 导出原发行版
wsl --export Ubuntu-24.04 ubuntu-original.tar

# 2. 导入为新发行版（不同名称 + 不同目录）
wsl --import Ubuntu-Clone D:\wsl\ubuntu-clone ubuntu-original.tar
# 注意：导入的发行版默认以 root 登录

# 3. 设置默认用户
wsl -d Ubuntu-Clone -u root
# 执行: echo -e "[user]\ndefault=yourusername" >> /etc/wsl.conf
# 然后: exit
wsl --terminate Ubuntu-Clone
# 重新进入即生效
```

### 5.3 默认安装位置修改

```powershell
# 默认发行版装在 C 盘（占用大），可以手动指定安装到其他盘

# 方式一：安装后迁移（推荐）
wsl --shutdown
wsl --export Ubuntu-24.04 D:\wsl-backup.tar
wsl --unregister Ubuntu-24.04
wsl --import Ubuntu-24.04 D:\wsl\Ubuntu-24.04 D:\wsl-backup.tar --version 2
del D:\wsl-backup.tar

# 方式二：修改注册表（安装前指定）
# HKCU\Software\Microsoft\Windows\CurrentVersion\Lxss\
# 新建 DWORD: UseDefaultInstallPath = 0
# 新建 String: PackageInstallPath = D:\wsl
```
