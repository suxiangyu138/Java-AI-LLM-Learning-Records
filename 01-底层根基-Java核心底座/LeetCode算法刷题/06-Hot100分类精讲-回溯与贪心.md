## 1. 回溯算法核心模板

### 回溯三要素

| 要素 | 说明 | 代码对应 |
|------|------|----------|
| **路径** | 已经做出的选择 | `List<Integer> path` / `StringBuilder sb` |
| **选择列表** | 当前可以做的选择 | `for` 循环遍历候选集，通过 `used[]` 或 `start` 剪枝 |
| **结束条件** | 到达决策树底部 | `if (路径长度 == 目标)` 加入结果集并 return |

### Java 标准模板

```java
void backtrack(/* 原始数据, 路径, 选择列表控制参数 */) {
    // 1. 结束条件：到达决策树底部
    if (满足条件) {
        result.add(new ArrayList<>(path)); // 深拷贝！
        return;
    }
    // 2. 遍历选择列表
    for (int i = start; i < nums.length; i++) {
        // 2.1 剪枝（去重 / 非法选择）
        if (used[i]) continue;
        // 2.2 做选择
        path.add(nums[i]);
        used[i] = true;
        // 2.3 进入下一层决策树
        backtrack(nums, i + 1, path, used, result);
        // 2.4 撤销选择（回溯）
        path.remove(path.size() - 1);
        used[i] = false;
    }
}
```

> 💡 核心口诀：**路径已定做选择，递归深入撤回之。剪枝在前效率高，深拷贝时别忘掉。**

## 2. 回溯篇 — 排列问题

### 2.1 LC 46 全排列 ★★★

> 给定不含重复数字的数组 `nums`，返回其所有可能的全排列。

#### 核心思路

标准回溯 + `visited[]` 数组标记已使用的元素。排列讲究**顺序**，所以每层递归都要从 `i = 0` 开始遍历，跳过已选元素。

#### 完整 Java 代码

```java
class Solution {
    public List<List<Integer>> permute(int[] nums) {
        List<List<Integer>> res = new ArrayList<>();
        boolean[] used = new boolean[nums.length];
        backtrack(nums, new ArrayList<>(), used, res);
        return res;
    }

    private void backtrack(int[] nums, List<Integer> path, boolean[] used, List<List<Integer>> res) {
        if (path.size() == nums.length) {
            res.add(new ArrayList<>(path)); // 深拷贝
            return;
        }
        for (int i = 0; i < nums.length; i++) {
            if (used[i]) continue;
            // 做选择
            path.add(nums[i]);
            used[i] = true;
            backtrack(nums, path, used, res);
            // 撤销选择
            path.remove(path.size() - 1);
            used[i] = false;
        }
    }
}
```

#### 复杂度分析

| 维度 | 值 |
|------|-----|
| 时间复杂度 | O(N * N!) — N! 个排列，每个拷贝 O(N) |
| 空间复杂度 | O(N) — 递归栈深度 + visited 数组 |

#### 追问

> **Q**：为什么 `res.add(path)` 不行，必须 `new ArrayList<>(path)`？  
> **A**：`path` 是引用类型，后续回溯会修改其内容。不加拷贝的话，`res` 中所有元素最终都指向同一个空列表。

#### 易错点

- 忘记深拷贝 → 结果集全为空
- `used[i] = true/false` 的对称性要保证
- 递归参数传递 `new ArrayList<>(path)` 而非 `path` 本身（除非在叶子节点拷贝）

### 2.2 LC 47 全排列 II ★★☆

> 给定可包含重复数字的序列 `nums`，返回所有不重复的全排列。

#### 核心思路

与 LC 46 相比多了**同层去重**：排序后，同一层中相同数字只选第一个，后续相同的跳过。

**关键剪枝条件：**
```java
if (i > 0 && nums[i] == nums[i - 1] && !used[i - 1]) continue;
```

#### 完整 Java 代码

```java
class Solution {
    public List<List<Integer>> permuteUnique(int[] nums) {
        Arrays.sort(nums); // 先排序，让相同元素相邻
        List<List<Integer>> res = new ArrayList<>();
        boolean[] used = new boolean[nums.length];
        backtrack(nums, new ArrayList<>(), used, res);
        return res;
    }

    private void backtrack(int[] nums, List<Integer> path, boolean[] used, List<List<Integer>> res) {
        if (path.size() == nums.length) {
            res.add(new ArrayList<>(path));
            return;
        }
        for (int i = 0; i < nums.length; i++) {
            if (used[i]) continue;
            // 同层剪枝：前一个相同元素没被用过，说明是同一层，跳过
            if (i > 0 && nums[i] == nums[i - 1] && !used[i - 1]) continue;
            path.add(nums[i]);
            used[i] = true;
            backtrack(nums, path, used, res);
            path.remove(path.size() - 1);
            used[i] = false;
        }
    }
}
```

> ⚠️ 为什么是 `!used[i-1]` 而不是 `used[i-1]`？  
> `used[i-1] == true` 说明前一个元素在本路径已被使用（不同层），此时允许相同元素进入下一层。`!used[i-1]` 意味着前一个元素刚回溯回来未使用（同层），此时必须剪枝。

#### 复杂度分析

| 维度 | 值 |
|------|-----|
| 时间复杂度 | O(N * N!) — 理论最坏，剪枝显著优化 |
| 空间复杂度 | O(N) |

#### 易错点

- 忘记排序 → 剪枝条件失效
- 剪枝条件写反 → `used[i-1]` 会导致漏解
- 同层去重与不同层恢复的逻辑混淆

## 3. 回溯篇 — 子集问题

### 3.1 LC 78 子集 ★★★

> 给定不含重复元素的整数数组 `nums`，返回所有可能的子集。

#### 核心思路

**解法一：回溯** — 每个元素选或不选，`start` 控制遍历起点（组合而非排列）。

**解法二：迭代** — 遍历数组，每遇到一个新元素就追加到已有子集后。

#### 完整 Java 代码

```java
class Solution {
    // 解法一：回溯法
    public List<List<Integer>> subsets(int[] nums) {
        List<List<Integer>> res = new ArrayList<>();
        backtrack(nums, 0, new ArrayList<>(), res);
        return res;
    }

    private void backtrack(int[] nums, int start, List<Integer> path, List<List<Integer>> res) {
        res.add(new ArrayList<>(path)); // 每个节点都加入结果（包括空集）
        for (int i = start; i < nums.length; i++) {
            path.add(nums[i]);
            backtrack(nums, i + 1, path, res); // i+1 保证不重复使用
            path.remove(path.size() - 1);
        }
    }
}
```

```java
// 解法二：迭代法（增量构造）
public List<List<Integer>> subsets(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    res.add(new ArrayList<>()); // 空集
    for (int num : nums) {
        int size = res.size();
        for (int j = 0; j < size; j++) {
            List<Integer> subset = new ArrayList<>(res.get(j));
            subset.add(num);
            res.add(subset);
        }
    }
    return res;
}
```

#### 复杂度分析

| 维度 | 回溯 | 迭代 |
|------|------|------|
| 时间复杂度 | O(2^N) | O(2^N) |
| 空间复杂度 | O(N) 递归栈 | O(1) 暂存 |

> 💡 **妙用**：回溯法中 `res.add(new ArrayList<>(path))` 放在递归入口而非出口，天然包含了空集和所有中间状态。

#### 易错点

- 回溯时 `start` 传 `i+1` 而非 `start+1`，否则会漏解
- 迭代法中要在遍历前固定 `size`，否则死循环

### 3.2 LC 90 子集 II ★★☆

> 给定可能包含重复元素的整数数组 `nums`，返回所有不重复的子集。

#### 核心思路

排序 + 同层去重，与 LC 47 去重逻辑完全一致。

#### 完整 Java 代码

```java
class Solution {
    public List<List<Integer>> subsetsWithDup(int[] nums) {
        Arrays.sort(nums);
        List<List<Integer>> res = new ArrayList<>();
        backtrack(nums, 0, new ArrayList<>(), res);
        return res;
    }

    private void backtrack(int[] nums, int start, List<Integer> path, List<List<Integer>> res) {
        res.add(new ArrayList<>(path));
        for (int i = start; i < nums.length; i++) {
            // 同层去重
            if (i > start && nums[i] == nums[i - 1]) continue;
            path.add(nums[i]);
            backtrack(nums, i + 1, path, res);
            path.remove(path.size() - 1);
        }
    }
}
```

> 💡 子集去重写法 `i > start` 比排列的 `!used[i-1]` 更简洁 —— 因为子集用 `start` 控制遍历起点，天然已保证了方向。

#### 复杂度分析

| 维度 | 值 |
|------|-----|
| 时间复杂度 | O(2^N) |
| 空间复杂度 | O(N) |

#### 追问

> **Q**：LC 78 与 LC 90 的唯一区别是什么？  
> **A**：LC 90 多了排序 + `i > start && nums[i] == nums[i-1]` 剪枝。

## 4. 回溯篇 — 组合问题

### 4.1 LC 39 组合总和 ★★★

> 给定无重复元素的数组 `candidates` 和目标值 `target`，找出所有和为 `target` 的组合。同一数字可无限重复选取。

#### 核心思路

回溯 + `start` 参数：由于可以重复选同一个元素，下一层递归 `start` 还是 `i`（而非 `i+1`）。提前对 `candidates` 排序可做剪枝优化。

#### 完整 Java 代码

```java
class Solution {
    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        List<List<Integer>> res = new ArrayList<>();
        Arrays.sort(candidates); // 排序便于剪枝
        backtrack(candidates, target, 0, new ArrayList<>(), res);
        return res;
    }

    private void backtrack(int[] candidates, int remain, int start,
                           List<Integer> path, List<List<Integer>> res) {
        if (remain == 0) {
            res.add(new ArrayList<>(path));
            return;
        }
        for (int i = start; i < candidates.length; i++) {
            if (candidates[i] > remain) break; // 剪枝：后面更大，直接结束
            path.add(candidates[i]);
            backtrack(candidates, remain - candidates[i], i, path, res); // i 不是 i+1
            path.remove(path.size() - 1);
        }
    }
}
```

#### 复杂度分析

| 维度 | 值 |
|------|-----|
| 时间复杂度 | O(N^(T/M)) — M 为最小值，T 为 target |
| 空间复杂度 | O(T/M) — 递归栈深度 |

#### 易错点

- 下一层 `start` 传 `i` 而非 `i+1`（可重复选）
- 不排序时剪枝方式不同（需要 `if (candidates[i] > remain) continue` 而非 `break`）

---

### 4.2 LC 40 组合总和 II ★★☆

> 给定可能包含重复元素的数组 `candidates` 和目标值 `target`，找出所有和为 `target` 的组合。**每个数字在每个组合中只能使用一次**。

#### 核心思路

LC 39 的三处改动：
1. 排序（必须）
2. 同层去重 `i > start && nums[i] == nums[i-1]`
3. 下一层 `start` 传 `i+1`

#### 完整 Java 代码

```java
class Solution {
    public List<List<Integer>> combinationSum2(int[] candidates, int target) {
        Arrays.sort(candidates);
        List<List<Integer>> res = new ArrayList<>();
        backtrack(candidates, target, 0, new ArrayList<>(), res);
        return res;
    }

    private void backtrack(int[] candidates, int remain, int start,
                           List<Integer> path, List<List<Integer>> res) {
        if (remain == 0) {
            res.add(new ArrayList<>(path));
            return;
        }
        for (int i = start; i < candidates.length; i++) {
            if (candidates[i] > remain) break;
            // 同层去重
            if (i > start && candidates[i] == candidates[i - 1]) continue;
            path.add(candidates[i]);
            backtrack(candidates, remain - candidates[i], i + 1, path, res);
            path.remove(path.size() - 1);
        }
    }
}
```

> 🎯 **核心对比：LC 39 vs LC 40**

| 特性 | LC 39 | LC 40 |
|------|-------|-------|
| 元素是否可重复选 | 是 | 否 |
| 下一层 start | `i` | `i+1` |
| 输入含重复 | 题目保证不重复 | 可能含重复 |
| 去重 | 不需要 | `i > start && nums[i] == nums[i-1]` |

## 5. 回溯篇 — 其他经典回溯

### 5.1 LC 17 电话号码的字母组合 ★★☆

> 给定一个仅包含数字 2-9 的字符串，返回所有它能表示的字母组合。

#### 核心思路

建立数字到字母的映射表，回溯逐个数字选择对应字母拼接字符串。

#### 完整 Java 代码

```java
class Solution {
    private static final String[] MAPPING = {
        "", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"
    };

    public List<String> letterCombinations(String digits) {
        List<String> res = new ArrayList<>();
        if (digits == null || digits.isEmpty()) return res;
        backtrack(digits, 0, new StringBuilder(), res);
        return res;
    }

    private void backtrack(String digits, int index, StringBuilder sb, List<String> res) {
        if (index == digits.length()) {
            res.add(sb.toString());
            return;
        }
        String letters = MAPPING[digits.charAt(index) - '0'];
        for (char c : letters.toCharArray()) {
            sb.append(c);
            backtrack(digits, index + 1, sb, res);
            sb.deleteCharAt(sb.length() - 1);
        }
    }
}
```

#### 复杂度分析

| 维度 | 值 |
|------|-----|
| 时间复杂度 | O(4^N) — 最坏每个数字对应 4 个字母 |
| 空间复杂度 | O(N) — 递归栈 + StringBuilder |

#### 易错点

- 空字符串输入返回 `[]` 而非 `[""]`
- `digits.charAt(index) - '0'` 转成数字下标
- `StringBuilder` 需要 `deleteCharAt` 回溯

### 5.2 LC 22 括号生成 ★★★

> 数字 `n` 代表生成括号的对数，设计函数生成所有可能的且**有效**的括号组合。

#### 核心思路

回溯 + 剪枝：维护 `open` 和 `close` 两个计数器。
- 当 `open < n` 时，可以加左括号
- 当 `close < open` 时，可以加右括号

#### 完整 Java 代码

```java
class Solution {
    public List<String> generateParenthesis(int n) {
        List<String> res = new ArrayList<>();
        backtrack(n, 0, 0, new StringBuilder(), res);
        return res;
    }

    private void backtrack(int n, int open, int close, StringBuilder sb, List<String> res) {
        if (sb.length() == 2 * n) {
            res.add(sb.toString());
            return;
        }
        if (open < n) {
            sb.append('(');
            backtrack(n, open + 1, close, sb, res);
            sb.deleteCharAt(sb.length() - 1);
        }
        if (close < open) {
            sb.append(')');
            backtrack(n, open, close + 1, sb, res);
            sb.deleteCharAt(sb.length() - 1);
        }
    }
}
```

#### 复杂度分析

| 维度 | 值 |
|------|-----|
| 时间复杂度 | O(4^N / sqrt(N)) — 第 N 个卡特兰数 |
| 空间复杂度 | O(N) — 递归栈 |

#### 易错点

- 右括号剪枝条件是 `close < open`，不是 `close < n`
- 忘记回溯 `sb` 的状态（注意用 `StringBuilder` 要手动删除）

### 5.3 LC 131 分割回文串 ★★☆

> 给定字符串 `s`，将 `s` 分割成若干子串，使每个子串都是回文串。返回所有可能的分割方案。

#### 核心思路

回溯 + 回文判断：在每一步尝试从 `start` 到 `end` 切分，如果是回文则递归处理剩余部分。

#### 完整 Java 代码

```java
class Solution {
    public List<List<String>> partition(String s) {
        List<List<String>> res = new ArrayList<>();
        backtrack(s, 0, new ArrayList<>(), res);
        return res;
    }

    private void backtrack(String s, int start, List<String> path, List<List<String>> res) {
        if (start == s.length()) {
            res.add(new ArrayList<>(path));
            return;
        }
        for (int end = start; end < s.length(); end++) {
            if (isPalindrome(s, start, end)) {
                path.add(s.substring(start, end + 1));
                backtrack(s, end + 1, path, res);
                path.remove(path.size() - 1);
            }
        }
    }

    private boolean isPalindrome(String s, int l, int r) {
        while (l < r) {
            if (s.charAt(l) != s.charAt(r)) return false;
            l++;
            r--;
        }
        return true;
    }
}
```

#### 复杂度分析

| 维度 | 值 |
|------|-----|
| 时间复杂度 | O(N * 2^N) |
| 空间复杂度 | O(N) |

#### 追问

> **Q**：如何优化回文判断？  
> **A**：预处理 DP 表 `dp[i][j]` 表示 `s[i..j]` 是否为回文，将判断降为 O(1)。递推：`dp[i][j] = (s[i]==s[j]) && (j-i<=2 || dp[i+1][j-1])`。

#### 易错点

- `substring` 的 end 参数是开区间，需要 `end + 1`
- 递归到 `start == s.length()` 收集结果

### 5.4 LC 79 单词搜索 ★★☆

> 给定二维网格 `board` 和单词 `word`，判断单词是否存在于网格中。同一单元格不能重复使用。

#### 核心思路

二维网格回溯（DFS）：从每个格子出发，向四个方向搜索匹配单词。用"临时标记"代替 visited 数组（将当前字符替换为 `'#'`）。

#### 完整 Java 代码

```java
class Solution {
    public boolean exist(char[][] board, String word) {
        int m = board.length, n = board[0].length;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (backtrack(board, word, i, j, 0)) return true;
            }
        }
        return false;
    }

    private boolean backtrack(char[][] board, String word, int i, int j, int index) {
        if (index == word.length()) return true;
        int m = board.length, n = board[0].length;
        if (i < 0 || i >= m || j < 0 || j >= n) return false;
        if (board[i][j] != word.charAt(index)) return false;

        char tmp = board[i][j];
        board[i][j] = '#'; // 标记已访问
        boolean found = backtrack(board, word, i + 1, j, index + 1)
                     || backtrack(board, word, i - 1, j, index + 1)
                     || backtrack(board, word, i, j + 1, index + 1)
                     || backtrack(board, word, i, j - 1, index + 1);
        board[i][j] = tmp; // 回溯恢复
        return found;
    }
}
```

#### 复杂度分析

| 维度 | 值 |
|------|-----|
| 时间复杂度 | O(M * N * 3^L) — L 为单词长度，首字母 4 方向，后续 3 方向 |
| 空间复杂度 | O(L) — 递归栈深度 |

#### 易错点

- 边界检查在字符匹配之前
- 恢复原字符是回溯关键
- 四个方向用 `||` 只要找到一个就返回

## 6. DFS 深度优先搜索

### 6.1 LC 200 岛屿数量 ★★☆

> 给定 `'1'`（陆地）和 `'0'`（水）组成的二维网格，计算岛屿数量。四周是海。

#### 核心思路

**沉岛法**：遍历网格，遇到 `'1'` 则岛屿数 +1，然后通过 DFS 将其相连的所有 `'1'` 标记为 `'0'`。

#### 完整 Java 代码

```java
class Solution {
    public int numIslands(char[][] grid) {
        int count = 0;
        for (int i = 0; i < grid.length; i++) {
            for (int j = 0; j < grid[0].length; j++) {
                if (grid[i][j] == '1') {
                    count++;
                    dfs(grid, i, j);
                }
            }
        }
        return count;
    }

    private void dfs(char[][] grid, int i, int j) {
        if (i < 0 || i >= grid.length || j < 0 || j >= grid[0].length) return;
        if (grid[i][j] == '0') return;
        grid[i][j] = '0'; // 沉岛
        dfs(grid, i + 1, j);
        dfs(grid, i - 1, j);
        dfs(grid, i, j + 1);
        dfs(grid, i, j - 1);
    }
}
```

#### 复杂度分析

| 维度 | 值 |
|------|-----|
| 时间复杂度 | O(M * N) — 每个格子访问一次 |
| 空间复杂度 | O(M * N) — 最坏全为陆地，递归栈深度 |

#### 追问

> **Q**：能否用 BFS 或并查集解决？  
> **A**：可以。BFS 用队列模拟，并查集将所有相邻 `'1'` union 起来。DFS 是最简洁的写法。

#### 易错点

- 边界检查先于 `grid[i][j] == '0'`
- 字符是 `'1'` 和 `'0'` 而非数字
- 沉岛后不用恢复（不同于 LC 79）

### 6.2 LC 51 N 皇后 ★★☆

> 将 `n` 个皇后放在 `n x n` 棋盘上，使任意两个皇后不在同一行、同一列、同一对角线上。返回所有合法摆放方案。

#### 核心思路

逐行放置皇后，用三个集合记录被占用的列、主对角线、副对角线。主对角线特点：行 - 列 = 常数；副对角线特点：行 + 列 = 常数。

#### 完整 Java 代码

```java
class Solution {
    public List<List<String>> solveNQueens(int n) {
        List<List<String>> res = new ArrayList<>();
        boolean[] col = new boolean[n];
        boolean[] diag1 = new boolean[2 * n - 1]; // 主对角线: row - col + (n-1)
        boolean[] diag2 = new boolean[2 * n - 1]; // 副对角线: row + col
        char[][] board = new char[n][n];
        for (char[] row : board) Arrays.fill(row, '.');
        backtrack(n, 0, col, diag1, diag2, board, res);
        return res;
    }

    private void backtrack(int n, int row, boolean[] col, boolean[] d1, boolean[] d2,
                           char[][] board, List<List<String>> res) {
        if (row == n) {
            List<String> solution = new ArrayList<>();
            for (char[] r : board) solution.add(new String(r));
            res.add(solution);
            return;
        }
        for (int c = 0; c < n; c++) {
            int idx1 = row - c + n - 1;
            int idx2 = row + c;
            if (col[c] || d1[idx1] || d2[idx2]) continue;
            // 放皇后
            board[row][c] = 'Q';
            col[c] = d1[idx1] = d2[idx2] = true;
            backtrack(n, row + 1, col, d1, d2, board, res);
            // 撤销
            board[row][c] = '.';
            col[c] = d1[idx1] = d2[idx2] = false;
        }
    }
}
```

#### 复杂度分析

| 维度 | 值 |
|------|-----|
| 时间复杂度 | O(N!) — 实际远小于 N!，因为剪枝 |
| 空间复杂度 | O(N) — 三个标记数组 + 棋盘 |

#### 易错点

- 主对角线索引计算 `row - col + (n-1)` 防止负数
- 副对角线直接用 `row + col` 即可
- 恢复棋盘状态时要对称

## 7. 贪心篇

### 7.1 LC 55 跳跃游戏 ★★★

> 给定非负整数数组 `nums`，每个元素代表在该位置可以跳跃的最大长度。判断是否能到达最后一个下标。

#### 核心思路

贪心维护**最远可达位置** `maxReach`，遍历每个位置，如果 `i > maxReach` 说明无法到达，直接返回 false；否则更新 `maxReach = max(maxReach, i + nums[i])`。

#### 完整 Java 代码

```java
class Solution {
    public boolean canJump(int[] nums) {
        int maxReach = 0;
        for (int i = 0; i < nums.length; i++) {
            if (i > maxReach) return false;
            maxReach = Math.max(maxReach, i + nums[i]);
            if (maxReach >= nums.length - 1) return true; // 提前结束
        }
        return true;
    }
}
```

#### 复杂度分析

| 维度 | 值 |
|------|-----|
| 时间复杂度 | O(N) |
| 空间复杂度 | O(1) |

#### 追问

> **Q**：为什么是对的？有没有反例？  
> **A**：贪心选择性质 —— 只要最远可达位置能覆盖到终点，就一定存在路径。反例不存在，因为 `maxReach` 是所有可能路径中能到的最远位置，只要 `maxReach` 到不了，任何路径都到不了。

#### 易错点

- 条件 `i > maxReach` 而非 `>=`
- 提前 break 不影响正确性，但可优化

### 7.2 LC 45 跳跃游戏 II ★★☆

> 与 LC 55 类似，但求**最少跳跃次数**。假设总能到达最后一个位置。

#### 核心思路

贪心：维护当前步数能到达的边界 `end` 和下一步能到达的最远位置 `farthest`。遍历数组，当 `i == end` 时，步数 +1，更新 `end = farthest`。

#### 完整 Java 代码

```java
class Solution {
    public int jump(int[] nums) {
        int jumps = 0, end = 0, farthest = 0;
        // 注意 i < nums.length - 1：最后一个位置不用跳
        for (int i = 0; i < nums.length - 1; i++) {
            farthest = Math.max(farthest, i + nums[i]);
            if (i == end) {
                jumps++;
                end = farthest;
            }
        }
        return jumps;
    }
}
```

#### 复杂度分析

| 维度 | 值 |
|------|-----|
| 时间复杂度 | O(N) |
| 空间复杂度 | O(1) |

#### 易错点

- 循环结束条件 `i < nums.length - 1`，跳到最后一个位置就够了
- `end` 更新在 `farthest` 计算之后

### 7.3 LC 121 买卖股票的最佳时机 ★★★

> 给定 `prices` 数组，`prices[i]` 是第 `i` 天的股票价格。只能买卖一次，求最大利润。

#### 核心思路

贪心：遍历中维护**历史最低价** `minPrice`，同时计算当天卖出能赚多少，更新最大利润。

#### 完整 Java 代码

```java
class Solution {
    public int maxProfit(int[] prices) {
        int minPrice = Integer.MAX_VALUE;
        int maxProfit = 0;
        for (int price : prices) {
            if (price < minPrice) {
                minPrice = price; // 更新最低价
            } else if (price - minPrice > maxProfit) {
                maxProfit = price - minPrice; // 更新最大利润
            }
        }
        return maxProfit;
    }
}
```

#### 复杂度分析

| 维度 | 值 |
|------|-----|
| 时间复杂度 | O(N) |
| 空间复杂度 | O(1) |

#### 追问

> **Q**：如果允许多次买卖（LC 122）呢？  
> **A**：所有上涨日都买卖 —— `for (int i = 1; i < prices.length; i++) if (prices[i] > prices[i-1]) profit += prices[i] - prices[i-1]`。

#### 易错点

- 最低价的更新要在计算利润之前（若当天是最低价，利润为 0 不用更新）
- 初始化 `minPrice = Integer.MAX_VALUE`

### 7.4 LC 763 划分字母区间 ★★☆

> 给定字符串 `s`，划分尽可能多的片段，使每个字母只出现在一个片段中。返回每个片段的长度。

#### 核心思路

两遍遍历：
1. 第一遍：用 HashMap 记录每个字符最后出现的位置
2. 第二遍：贪心地维护当前片段的结束位置 `end`，遍历时 `end = max(end, lastIndex[s[i]])`，当 `i == end` 时切分

#### 完整 Java 代码

```java
class Solution {
    public List<Integer> partitionLabels(String s) {
        int[] last = new int[26];
        for (int i = 0; i < s.length(); i++) {
            last[s.charAt(i) - 'a'] = i; // 最后出现位置
        }
        List<Integer> res = new ArrayList<>();
        int start = 0, end = 0;
        for (int i = 0; i < s.length(); i++) {
            end = Math.max(end, last[s.charAt(i) - 'a']);
            if (i == end) {
                res.add(end - start + 1);
                start = end + 1;
            }
        }
        return res;
    }
}
```

#### 复杂度分析

| 维度 | 值 |
|------|-----|
| 时间复杂度 | O(N) |
| 空间复杂度 | O(1) — 固定 26 个字母 |

#### 易错点

- 用数组代替 HashMap 更高效（仅 26 字母）
- 切分后 `start = end + 1`，而非 `start = i + 1`

### 7.5 LC 406 根据身高重建队列 ★★☆

> 每个人用 `(h, k)` 表示，`h` 是身高，`k` 是排在前面且身高 ≥ 该人的人数。根据被打乱顺序的队列重建正确的顺序。

#### 核心思路

排序 + 贪心插入：
1. 先按身高降序排序，身高相同的按 `k` 升序
2. 然后依次将每个人插入到 `k` 位置

> 💡 为什么这样是对？高个子先排，矮个子插入时不影响高个子的 `k`，因为矮个子不会让高个子的计数变化。

#### 完整 Java 代码

```java
class Solution {
    public int[][] reconstructQueue(int[][] people) {
        // 按身高降序，k 升序
        Arrays.sort(people, (a, b) -> a[0] != b[0] ? b[0] - a[0] : a[1] - b[1]);
        List<int[]> res = new LinkedList<>();
        for (int[] p : people) {
            res.add(p[1], p); // 插入到 k 位置
        }
        return res.toArray(new int[res.size()][]);
    }
}
```

#### 复杂度分析

| 维度 | 值 |
|------|-----|
| 时间复杂度 | O(N^2) — LinkedList 插入 O(N)，总 O(N^2) |
| 空间复杂度 | O(N) |

#### 追问

> **Q**：能否优化到 O(N log N)？  
> **A**：可用树状数组（Fenwick Tree）+ 二分查找做到 O(N log N)，面试一般不要求。

#### 易错点

- 排序比较器写法：降序用 `b[0] - a[0]`，升序用 `a[1] - b[1]`
- `List<int[]>` 的 `add(index, element)` 方法

## 8. 回溯 vs DP vs 贪心 对比总结

### 选择方式对比表

| 维度 | 回溯 (Backtracking) | 动态规划 (DP) | 贪心 (Greedy) |
|------|--------------------|---------------|---------------|
| **核心思想** | 试错 + 撤销 | 状态转移 + 记忆化 | 局部最优 → 全局最优 |
| **选择依据** | 遍历所有可能 | 最优子结构 | 贪心策略 |
| **正确性** | 绝对正确（穷举） | 正确（数学归纳） | 需证明贪心性质 |
| **效率** | 指数级 (2^N / N!) | 多项式 (N^2 / N) | 线性 (N) |
| **适用场景** | 所有解 / 排列组合子集 | 最优值 / 计数 | 最优值（特定结构） |
| **代码复杂度** | 模板化，较简单 | 递推/递归 + 状态定义 | 最简洁 |

### 题型识别口诀

```
求所有解 → 回溯（全排列、子集、组合、N 皇后）
求最优值 → 看性质（无后效性 → DP；贪心性质 → 贪心）
求是否可达 → 尝试贪心（跳跃游戏、买卖股票）
元素顺序重要 → 排列（used[] 从 0 开始）
元素顺序不重要 → 组合/子集（start 参数）
可重复选同一数 → start 传 i
不可重复选 → start 传 i+1
含重复元素 → 先排序，再加同层剪枝
```

### 复杂度对比

| 问题类型 | 回溯 | DP | 贪心 |
|---------|------|-----|------|
| 子集 (LC 78) | O(2^N) | — | — |
| 全排列 (LC 46) | O(N * N!) | — | — |
| 组合总和 (LC 39) | O(N^(T/M)) | — | — |
| 跳跃游戏 (LC 55) | — | O(N) | O(N) |
| 股票买卖 (LC 121) | — | O(N) | O(N) |

> 🎯 **面试建议**：
> 1. 回溯题先写模板框架（路径/选择/结束），再填细节
> 2. 去重问题先排序，加 `i > start && nums[i] == nums[i-1]` 剪枝
> 3. 贪心题先想反例，找不出反例就尝试证明
> 4. 遇到最优值问题，先尝试贪心，不行再想 DP
