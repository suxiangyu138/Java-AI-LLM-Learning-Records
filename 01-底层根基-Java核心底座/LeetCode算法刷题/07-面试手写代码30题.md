## 1. 面试手写题的特点与注意事项

### 与 IDE 写代码的区别

| 维度 | IDE 编码 | 白板手写 |
|------|---------|---------|
| 环境 | 自动补全、语法高亮、实时编译 | 纯记忆 + 手写 |
| 调试 | 断点调试、Print 大法 | 只能在脑中模拟 |
| 心态 | 改到对为止 | 一次过，压力大 |
| 重点 | 功能完整、工程化 | 思路清晰、关键逻辑正确 |

### 常见考核点

- **边界条件处理**：空输入、单元素、负值、越界
- **语法规范**：`==` vs `equals()`、数组声明写法、泛型
- **复杂度分析**：随手写时间/空间复杂度
- **测试意识**：写完主动说出测试用例
- **沟通能力**：边写边讲思路，不要沉默

### 手写代码注意事项

> 💡 **边写边讲思路**：面试官想看的不是你默写代码，而是你的思考过程

1. **审题确认** — 先和面试官确认输入输出约束（"数组有序吗？""元素范围？"）
2. **讲明算法** — 写之前先说思路：用什么数据结构、时间/空间复杂度
3. **注意缩进** — 白板也要保持缩进风格，大括号对齐
4. **变量命名** — `i`, `j`, `p`, `q`, `cur`, `prev` 等简短但不混淆
5. **写注释** — 关键步骤加注释展示工程习惯
6. **边界检查** — 写完立刻检查空指针、越界
7. **测试验证** — 自己举 2-3 个测试用例走一遍

> 🎯 **5 分钟法则**：如果 5 分钟还没想出思路，立即和面试官沟通，让他给提示

## 2. 排序类

### 2.1 快排 QuickSort ★★★

> **一句话**：选 pivot，partition 分左右，递归排序

```java
void quickSort(int[] arr, int left, int right) {
    if (left >= right) return;
    int pivot = partition(arr, left, right);
    quickSort(arr, left, pivot - 1);
    quickSort(arr, pivot + 1, right);
}

int partition(int[] arr, int left, int right) {
    int pivot = arr[right]; // 选最后一个为 pivot
    int i = left; // i 指向小于 pivot 的边界
    for (int j = left; j < right; j++) {
        if (arr[j] < pivot) {
            swap(arr, i, j);
            i++;
        }
    }
    swap(arr, i, right);
    return i;
}

void swap(int[] arr, int i, int j) {
    int tmp = arr[i];
    arr[i] = arr[j];
    arr[j] = tmp;
}
```

> ⚠️ **常见手写错误**：忘记 `if (left >= right)` 终止条件；partition 中 `i` 的初始值写错

- **时间复杂度**：平均 O(N log N)，最坏 O(N^2)
- **空间复杂度**：O(log N) 递归栈

### 2.2 归并排序 MergeSort ★★☆

> **一句话**：分治，先分后合，合并两个有序数组

```java
void mergeSort(int[] arr, int left, int right) {
    if (left >= right) return;
    int mid = left + (right - left) / 2;
    mergeSort(arr, left, mid);
    mergeSort(arr, mid + 1, right);
    merge(arr, left, mid, right);
}

void merge(int[] arr, int left, int mid, int right) {
    int[] tmp = new int[right - left + 1];
    int i = left, j = mid + 1, k = 0;
    while (i <= mid && j <= right) {
        if (arr[i] <= arr[j]) tmp[k++] = arr[i++];
        else tmp[k++] = arr[j++];
    }
    while (i <= mid) tmp[k++] = arr[i++];
    while (j <= right) tmp[k++] = arr[j++];
    System.arraycopy(tmp, 0, arr, left, tmp.length);
}
```

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(N) — 临时数组

### 2.3 堆排 HeapSort ★☆☆

> **一句话**：建最大堆，堆顶与末尾交换，调整堆

```java
void heapSort(int[] arr) {
    int n = arr.length;
    // 建堆
    for (int i = n / 2 - 1; i >= 0; i--) {
        heapify(arr, n, i);
    }
    // 排序
    for (int i = n - 1; i > 0; i--) {
        swap(arr, 0, i);
        heapify(arr, i, 0);
    }
}

void heapify(int[] arr, int n, int i) {
    int largest = i;
    int left = 2 * i + 1;
    int right = 2 * i + 2;
    if (left < n && arr[left] > arr[largest]) largest = left;
    if (right < n && arr[right] > arr[largest]) largest = right;
    if (largest != i) {
        swap(arr, i, largest);
        heapify(arr, n, largest);
    }
}
```

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(1) — 原地排序

### 2.4 LC 215 数组中的第 K 个最大元素 ★★★

> **一句话**：快排 partition，根据 pivot 位置缩小搜索范围

```java
int findKthLargest(int[] nums, int k) {
    int left = 0, right = nums.length - 1;
    int target = nums.length - k; // 第 k 大 = 第 N-k 小
    while (left <= right) {
        int pivot = partition(nums, left, right);
        if (pivot == target) return nums[pivot];
        else if (pivot < target) left = pivot + 1;
        else right = pivot - 1;
    }
    return -1;
}
// partition 同快排
```

> 💡 面试必考题！利用快排的 `partition` 实现 O(N) 的查找。注意是第 K 大，转为下标 `N - k`。

- **时间复杂度**：平均 O(N)，最坏 O(N^2)
- **空间复杂度**：O(1)

> ⚠️ **常见手写错误**：`target = nums.length - k` 写错；`while` 条件用 `left < right` 漏解

## 3. 链表类

### 3.1 LC 206 反转链表 ★★★

> **一句话**：三指针 prev/cur/next 迭代反转

```java
ListNode reverseList(ListNode head) {
    ListNode prev = null, cur = head;
    while (cur != null) {
        ListNode next = cur.next; // 保存下一个
        cur.next = prev;          // 反转
        prev = cur;               // 前进
        cur = next;
    }
    return prev; // 新头
}
```

> 💡 递归版本也要会：`ListNode newHead = reverseList(head.next); head.next.next = head; head.next = null; return newHead;`

- **时间复杂度**：O(N)
- **空间复杂度**：O(1) 迭代 / O(N) 递归

### 3.2 LC 92 反转链表 II ★★☆

> **一句话**：定位到 left 前一个节点，头插法反转区间

```java
ListNode reverseBetween(ListNode head, int left, int right) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;
    ListNode prev = dummy;
    // 1. 走到 left 前一个节点
    for (int i = 1; i < left; i++) prev = prev.next;
    // 2. 头插法反转
    ListNode cur = prev.next;
    for (int i = 0; i < right - left; i++) {
        ListNode next = cur.next;
        cur.next = next.next;
        next.next = prev.next;
        prev.next = next;
    }
    return dummy.next;
}
```

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

### 3.3 LC 21 合并两个有序链表 ★★★

> **一句话**：双指针比较，dummy 节点串联

```java
ListNode mergeTwoLists(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(0), cur = dummy;
    while (l1 != null && l2 != null) {
        if (l1.val <= l2.val) {
            cur.next = l1;
            l1 = l1.next;
        } else {
            cur.next = l2;
            l2 = l2.next;
        }
        cur = cur.next;
    }
    cur.next = (l1 != null) ? l1 : l2;
    return dummy.next;
}
```

- **时间复杂度**：O(N + M)
- **空间复杂度**：O(1)

### 3.4 LC 141 环形链表 ★★★

> **一句话**：快慢指针，相遇则有环

```java
boolean hasCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) return true;
    }
    return false;
}
```

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

### 3.5 LC 142 环形链表 II ★★☆

> **一句话**：相遇后，从头同步走，相遇处即环入口

```java
ListNode detectCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) { // 相遇
            ListNode p = head;
            while (p != slow) {
                p = p.next;
                slow = slow.next;
            }
            return p;
        }
    }
    return null;
}
```

> 💡 **数学原理**：`head → 入口 = 相遇点 → 入口` 的距离相等

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

### 3.6 LC 160 相交链表 ★★☆

> **一句话**：双指针分别遍历两链表，走完的跳到对方头，相遇即交点

```java
ListNode getIntersectionNode(ListNode headA, ListNode headB) {
    ListNode p = headA, q = headB;
    while (p != q) {
        p = (p == null) ? headB : p.next;
        q = (q == null) ? headA : q.next;
    }
    return p;
}
```

- **时间复杂度**：O(N + M)
- **空间复杂度**：O(1)

## 4. 树类

### 4.1 前序 / 中序 / 后序 遍历 ★★★

> **一句话**：递归三行，迭代用栈

```java
// ===== 递归 =====
void preorder(TreeNode root, List<Integer> res) {
    if (root == null) return;
    res.add(root.val);          // 根
    preorder(root.left, res);   // 左
    preorder(root.right, res);  // 右
}

void inorder(TreeNode root, List<Integer> res) {
    if (root == null) return;
    inorder(root.left, res);
    res.add(root.val);
    inorder(root.right, res);
}

void postorder(TreeNode root, List<Integer> res) {
    if (root == null) return;
    postorder(root.left, res);
    postorder(root.right, res);
    res.add(root.val);
}

// ===== 迭代：前序 =====
void preorderIterative(TreeNode root, List<Integer> res) {
    if (root == null) return;
    Stack<TreeNode> stack = new Stack<>();
    stack.push(root);
    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();
        res.add(node.val);
        if (node.right != null) stack.push(node.right); // 先右后左
        if (node.left != null) stack.push(node.left);
    }
}

// ===== 迭代：中序 =====
void inorderIterative(TreeNode root, List<Integer> res) {
    Stack<TreeNode> stack = new Stack<>();
    TreeNode cur = root;
    while (cur != null || !stack.isEmpty()) {
        while (cur != null) {
            stack.push(cur);
            cur = cur.left;
        }
        cur = stack.pop();
        res.add(cur.val);
        cur = cur.right;
    }
}
```

> 💡 **后序迭代**：前序改为 `根→右→左` 再反转结果，简便写法

### 4.2 层序遍历 ★★★

> **一句话**：BFS 队列，每层记录大小

```java
List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) return res;
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        int size = queue.size();
        List<Integer> level = new ArrayList<>();
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            level.add(node.val);
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        res.add(level);
    }
    return res;
}
```

### 4.4 LC 236 最近公共祖先 ★★★

> **一句话**：递归查找，左右都找到则当前节点为 LCA

```java
TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    if (root == null || root == p || root == q) return root;
    TreeNode left = lowestCommonAncestor(root.left, p, q);
    TreeNode right = lowestCommonAncestor(root.right, p, q);

}
```

### 4.5 LC 98 验证二叉搜索树 ★★☆

> **一句话**：中序遍历递增；或递归传递 min/max 范围

```java
// 解法一：递归范围法（推荐手写）
boolean isValidBST(TreeNode root) {
    return validate(root, Long.MIN_VALUE, Long.MAX_VALUE);
}

boolean validate(TreeNode root, long min, long max) {
    if (root == null) return true;
    if (root.val <= min || root.val >= max) return false;
    return validate(root.left, min, root.val)
        && validate(root.right, root.val, max);
}

// 解法二：中序遍历法
TreeNode prev = null;
boolean isValidBST2(TreeNode root) {
    if (root == null) return true;
    if (!isValidBST2(root.left)) return false;
    if (prev != null && root.val <= prev.val) return false;
    prev = root;
    return isValidBST2(root.right);
}
```

> ⚠️ **常见错误**：只检查左 < 根 < 右，忽略了全局范围；用 `Integer.MIN_VALUE` 遇到边界值会挂

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 5. 字符串与数组

### 5.1 LC 3 无重复字符的最长子串 ★★★

> **一句话**：滑动窗口，HashMap 记录字符最后出现位置

```java
int lengthOfLongestSubstring(String s) {
    Map<Character, Integer> map = new HashMap<>();
    int max = 0, left = 0;
    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        if (map.containsKey(c)) {
            left = Math.max(left, map.get(c) + 1); // 左指针右移
        }
        map.put(c, right);
        max = Math.max(max, right - left + 1);
    }
    return max;
}
```

> ⚠️ **常见错误**：`left` 直接赋为 `map.get(c) + 1` 而不是取 max，可能导致 left 回退

- **时间复杂度**：O(N)
- **空间复杂度**：O(字符集大小)

### 5.2 LC 15 三数之和 ★★★

> **一句话**：排序 + 双指针，固定一个数，剩下两个用双指针

```java
List<List<Integer>> threeSum(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    Arrays.sort(nums);
    for (int i = 0; i < nums.length - 2; i++) {
        if (i > 0 && nums[i] == nums[i - 1]) continue; // 去重
        int left = i + 1, right = nums.length - 1;
        while (left < right) {
            int sum = nums[i] + nums[left] + nums[right];
            if (sum == 0) {
                res.add(Arrays.asList(nums[i], nums[left], nums[right]));
                while (left < right && nums[left] == nums[left + 1]) left++; // 去重
                while (left < right && nums[right] == nums[right - 1]) right--;
                left++;
                right--;
            } else if (sum < 0) left++;
            else right--;
        }
    }
    return res;
}
```

> ⚠️ **常见错误**：忘记排序；去重时数组越界；`left < right` 条件在去重 while 中遗漏

- **时间复杂度**：O(N^2)
- **空间复杂度**：O(1)

### 5.3 LC 1 两数之和 ★★★

> **一句话**：HashMap 存储 <值, 下标> 边遍历边查找

```java
int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> map = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        int complement = target - nums[i];
        if (map.containsKey(complement)) {
            return new int[]{map.get(complement), i};
        }
        map.put(nums[i], i);
    }
    return new int[]{-1, -1};
}
```

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

### 5.4 LC 53 最大子数组和 ★★★

> **一句话**：Kadane 算法，维护当前和与最大和

```java
int maxSubArray(int[] nums) {
    int curSum = 0, maxSum = Integer.MIN_VALUE;
    for (int num : nums) {
        curSum = Math.max(curSum + num, num); // 要么续上，要么重开
        maxSum = Math.max(maxSum, curSum);
    }
    return maxSum;
}
```

> 💡 核心思想：`curSum` 如果为负就丢弃，从当前元素重新开始

- **时间复杂度**：O(N)

### 5.5 LC 5 最长回文子串 ★★☆

> **一句话**：中心扩展法，分奇偶两种中心

```java
String longestPalindrome(String s) {
    if (s == null || s.length() < 2) return s;
    int start = 0, maxLen = 1;
    for (int i = 0; i < s.length(); i++) {
        int len1 = expand(s, i, i);     // 奇数
        int len2 = expand(s, i, i + 1); // 偶数
        int len = Math.max(len1, len2);
        if (len > maxLen) {
            maxLen = len;
            start = i - (len - 1) / 2;
        }
    }
    return s.substring(start, start + maxLen);
}

int expand(String s, int l, int r) {
    while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) {
        l--;
        r++;
    }
    return r - l - 1;
}
```

- **时间复杂度**：O(N^2)
- **空间复杂度**：O(1)

## 6. DP 与回溯

### 6.1 LC 70 爬楼梯 ★★★

> **一句话**：斐波那契，滚动数组 O(1) 空间

```java
int climbStairs(int n) {
    if (n <= 2) return n;
    int a = 1, b = 2; // a=f(1), b=f(2)
    for (int i = 3; i <= n; i++) {
        int c = a + b;
        a = b;
        b = c;
    }
    return b;
}
```

- **时间复杂度**：O(N)

### 6.2 LC 198 打家劫舍 ★★★

> **一句话**：dp[i] = max(dp[i-1], dp[i-2] + nums[i])

```java
int rob(int[] nums) {
    if (nums.length == 1) return nums[0];
    int prev2 = nums[0]; // dp[i-2]
    int prev1 = Math.max(nums[0], nums[1]); // dp[i-1]
    for (int i = 2; i < nums.length; i++) {
        int cur = Math.max(prev1, prev2 + nums[i]);
        prev2 = prev1;
        prev1 = cur;
    }
    return prev1;
}
```

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

### 6.3 LC 46 全排列 ★★★

> **一句话**：回溯模板，visited 数组标记已选元素

```java
List<List<Integer>> permute(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    boolean[] used = new boolean[nums.length];
    backtrack(nums, new ArrayList<>(), used, res);
    return res;
}

void backtrack(int[] nums, List<Integer> path, boolean[] used, List<List<Integer>> res) {
    if (path.size() == nums.length) {
        res.add(new ArrayList<>(path));
        return;
    }
    for (int i = 0; i < nums.length; i++) {
        if (used[i]) continue;
        path.add(nums[i]);
        used[i] = true;
        backtrack(nums, path, used, res);
        path.remove(path.size() - 1);
        used[i] = false;
    }
}
```

- **时间复杂度**：O(N * N!)
- **空间复杂度**：O(N)

### 6.4 LC 22 括号生成 ★★☆

> **一句话**：回溯 + 剪枝，open < n 加左，close < open 加右

```java
List<String> generateParenthesis(int n) {
    List<String> res = new ArrayList<>();
    backtrack(n, 0, 0, new StringBuilder(), res);
    return res;
}

void backtrack(int n, int open, int close, StringBuilder sb, List<String> res) {
    if (sb.length() == 2 * n) {
        res.add(sb.toString());
        return;
    }
    if (open < n) {
        sb.append('(');
        backtrack(n, open + 1, close, sb, res);
        sb.deleteCharAt(sb.length() - 1);
    }
    if (close < open) {
        sb.append(')');
        backtrack(n, open, close + 1, sb, res);
        sb.deleteCharAt(sb.length() - 1);
    }
}
```

- **时间复杂度**：O(4^N / sqrt(N))
- **空间复杂度**：O(N)

### 6.5 LC 322 零钱兑换 ★★☆

> **一句话**：DP 递推，dp[i] = min(dp[i - coin] + 1)

```java
int coinChange(int[] coins, int amount) {
    int[] dp = new int[amount + 1];
    Arrays.fill(dp, amount + 1); // 初始化为"不可能"
    dp[0] = 0;
    for (int i = 1; i <= amount; i++) {
        for (int coin : coins) {
            if (i >= coin) {
                dp[i] = Math.min(dp[i], dp[i - coin] + 1);
            }
        }
    }
    return dp[amount] > amount ? -1 : dp[amount];
}
```

> ⚠️ **常见错误**：用 `Integer.MAX_VALUE` 初始化，`dp[i - coin] + 1` 会溢出

- **时间复杂度**：O(N * amount)
- **空间复杂度**：O(amount)

## 7. 设计题

### 7.1 LC 146 LRU 缓存 ★★★

> **一句话**：HashMap + 双向链表，get/put 都是 O(1)

```java
class LRUCache {
    class Node {
        int key, val;
        Node prev, next;
        Node(int k, int v) { key = k; val = v; }
    }

    private final int capacity;
    private final Map<Integer, Node> map = new HashMap<>();
    private final Node head = new Node(0, 0); // 虚拟头
    private final Node tail = new Node(0, 0); // 虚拟尾

    public LRUCache(int capacity) {
        this.capacity = capacity;
        head.next = tail;
        tail.prev = head;
    }

    public int get(int key) {
        Node node = map.get(key);
        if (node == null) return -1;
        moveToHead(node);
        return node.val;
    }

    public void put(int key, int value) {
        Node node = map.get(key);
        if (node != null) {
            node.val = value;
            moveToHead(node);
        } else {
            if (map.size() == capacity) {
                Node removed = removeTail();
                map.remove(removed.key);
            }
            Node newNode = new Node(key, value);
            map.put(key, newNode);
            addToHead(newNode);
        }
    }

    private void addToHead(Node node) {
        node.prev = head;
        node.next = head.next;
        head.next.prev = node;
        head.next = node;
    }

    private void moveToHead(Node node) {
        removeNode(node);
        addToHead(node);
    }

    private void removeNode(Node node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }

    private Node removeTail() {
        Node node = tail.prev;
        removeNode(node);
        return node;
    }
}
```

> 💡 面试高频！手写时注意：`get` 和 `put` 都要把访问节点移到头部；`put` 已存在的节点只更新值不创建新节点

- **时间复杂度**：get/sput 均为 O(1)
- **空间复杂度**：O(capacity)

### 7.2 LC 155 最小栈 ★★☆

> **一句话**：辅助栈存当前最小值，同步操作

```java
class MinStack {
    private Stack<Integer> stack;
    private Stack<Integer> minStack;

    public MinStack() {
        stack = new Stack<>();
        minStack = new Stack<>();
        minStack.push(Integer.MAX_VALUE);
    }

    public void push(int val) {
        stack.push(val);
        minStack.push(Math.min(minStack.peek(), val));
    }

    public void pop() {
        stack.pop();
        minStack.pop();
    }

    public int top() {
        return stack.peek();
    }

    public int getMin() {
        return minStack.peek();
    }
}
```

> 💡 优化版本：只用一个栈 + 一个变量存储最小值，入栈时压入旧最小值

- **时间复杂度**：所有操作 O(1)
- **空间复杂度**：O(N)

### 7.3 LC 232 用栈实现队列 ★★☆

> **一句话**：两个栈（输入栈 + 输出栈），输出栈为空时把输入栈全部倒入

```java
class MyQueue {
    private Stack<Integer> in;
    private Stack<Integer> out;

    public MyQueue() {
        in = new Stack<>();
        out = new Stack<>();
    }

    public void push(int x) {
        in.push(x);
    }

    public int pop() {
        if (out.isEmpty()) transfer();
        return out.pop();
    }

    public int peek() {
        if (out.isEmpty()) transfer();
        return out.peek();
    }

    public boolean empty() {
        return in.isEmpty() && out.isEmpty();
    }

    private void transfer() {
        while (!in.isEmpty()) {
            out.push(in.pop());
        }
    }
}
```

- **时间复杂度**：均摊 O(1)
- **空间复杂度**：O(N)

### 8.1 LC 200 岛屿数量 ★★☆

> **一句话**：DFS 沉岛法，遍历到 '1' 就沉掉相连的所有 '1'

```java
int numIslands(char[][] grid) {
    int count = 0;
    for (int i = 0; i < grid.length; i++) {
        for (int j = 0; j < grid[0].length; j++) {
            if (grid[i][j] == '1') {
                count++;
                dfs(grid, i, j);
            }
        }
    }
    return count;
}

void dfs(char[][] grid, int i, int j) {
    if (i < 0 || i >= grid.length || j < 0 || j >= grid[0].length) return;
    if (grid[i][j] == '0') return;
    grid[i][j] = '0'; // 沉岛
    dfs(grid, i + 1, j);
    dfs(grid, i - 1, j);
    dfs(grid, i, j + 1);
    dfs(grid, i, j - 1);
}
```

- **时间复杂度**：O(M * N)
- **空间复杂度**：O(M * N)

### 8.2 生产者-消费者模式 ★★☆

> **一句话**：wait/notify 或 BlockingQueue 实现

```java
// ===== 解法一：BlockingQueue（推荐手写，简洁） =====
class ProducerConsumer {
    private static final BlockingQueue<Integer> queue = new LinkedBlockingQueue<>(10);

    static class Producer implements Runnable {
        public void run() {
            for (int i = 0; ; i++) {
                try {
                    queue.put(i);
                    System.out.println("Produced: " + i);
                    Thread.sleep(100);
                } catch (InterruptedException e) { Thread.currentThread().interrupt(); }
            }
        }
    }

    static class Consumer implements Runnable {
        public void run() {
            while (true) {
                try {
                    int val = queue.take();
                    System.out.println("Consumed: " + val);
                    Thread.sleep(200);
                } catch (InterruptedException e) { Thread.currentThread().interrupt(); }
            }
        }
    }

    public static void main(String[] args) {
        new Thread(new Producer()).start();
        new Thread(new Consumer()).start();
    }
}

// ===== 解法二：wait/notify（考察底层原理） =====
class MyBlockingQueue<T> {
    private final Queue<T> queue = new LinkedList<>();
    private final int capacity;

    public MyBlockingQueue(int capacity) { this.capacity = capacity; }

    public synchronized void put(T item) throws InterruptedException {
        while (queue.size() == capacity) wait();
        queue.offer(item);
        notifyAll();
    }

    public synchronized T take() throws InterruptedException {
        while (queue.isEmpty()) wait();
        T item = queue.poll();
        notifyAll();
        return item;
    }
}
```

> 💡 面试中先说 `BlockingQueue` 的解法，再主动问"需要我写 wait/notify 版本吗"
