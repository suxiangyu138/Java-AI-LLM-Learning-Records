# 00 - 代码与编程语言的国际性知识体系总览

> 🎯 本系列共 **7 篇**，从编码演进到 Unicode 深入、从中文标准到语言支持、从工程实践到安全陷阱，覆盖代码国际化的全链路

## 4. 核心概念速查

| 概念 | 一句话解释 |
|------|-----------|
| **ASCII** | 7 位 128 字符——英文字符集始祖（1963） |
| **Unicode** | 全球字符统一编码——每个字符一个唯一码点 |
| **码点（Code Point）** | 字符的唯一编号（"A"=U+0041 / "中"=U+4E2D） |
| **UTF-8** | 变长编码（1-4 字节）——**互联网事实标准** |
| **UTF-16** | 定长 2 字节 + 代理对——Java char 的基础 |
| **BMP** | 基本多文种平面（前 65536 个码点） |
| **代理对** | 用两个 16 位单元表示 BMP 外字符（Emoji） |
| **GB2312/GBK/GB18030** | 中文编码三代标准（6763/21886/全 Unicode） |
| **Locale** | 语言+地区组合（zh_CN/en_US）——国际化的核心 |
| **i18n** | Internationalization（18 个字母）——国际化 |
| **utf8mb4** | MySQL 的完整 UTF-8（真正的 4 字节支持） |
| **宽字节注入** | 多字节编码下转义被绕过的安全漏洞 |

## 5. 一图看懂：字符编码演进

```text
字符编码演进（关键里程碑）
┌─────────────────────────────────────────────┐
│ 1963  ASCII（7 位 128 字符）                 │
│   └── 局限：只有英文                        │
│ 1980s 各国扩展编码（互不兼容！）              │
│   ├── 中国 GB2312 / 俄罗斯 KOI-8 / 日本 JIS  │
│   └── 问题：跨平台乱码                      │
│ 1991  Unicode 诞生（全球统一码点）           │
│   └── "A"=U+0041 / "中"=U+4E2D              │
│ 1993  UTF-8 标准（变长 1-4 字节）            │
│   └── 兼容 ASCII → 互联网事实标准            │
│ 2000  GB18030（中国强制标准，全 Unicode）     │
│ 2026  现状：UTF-8 一统天下（Web >98%）       │
└─────────────────────────────────────────────┘
```
