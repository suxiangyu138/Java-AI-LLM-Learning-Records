## 1. 三种脚本对比

| 维度 | Bash (.sh) | PowerShell (.ps1) | Batch (.bat) |
|------|:--------:|:---------------:|:----------:|
| 平台 | Linux/macOS | Win/Linux/macOS | Windows |
| 变量 | `$var` | `$var` | `%var%` |
| 赋值 | `var="val"` | `$var = "val"` | `set var=val` |
| 条件 | `if [ ... ]; then` | `if (...) { }` | `if ... ( )` |
| 循环 | `for i in ...; do` | `foreach ($i in ...)` | `for %%i in (...) do` |
| 函数 | `func() { }` | `function Func { }` | `call :label` |
| 参数 | `$1 $2 $@` | `$args[0]` | `%1 %2 %*` |
| 输出 | `echo` | `Write-Output` | `echo` |
| 管道 | 文本流 | 对象流 | 文本流 |
| 错误处理 | `set -e` / `trap` | `try/catch` | `if %errorlevel%` |

## 2. Bash Shell 脚本

### 2.1 项目启动脚本

```bash
#!/bin/bash
set -euo pipefail

PROJECT_DIR="/opt/myapp"
cd "$PROJECT_DIR"

echo "=== 启动开发环境 ==="

# 启动 MySQL（Docker）
docker start mysql-dev 2>/dev/null || \
  docker run -d --name mysql-dev -p 3306:3306 -e MYSQL_ROOT_PASSWORD=root mysql:8.0

# 启动 Redis
docker start redis-dev 2>/dev/null || \
  docker run -d --name redis-dev -p 6379:6379 redis:7-alpine

# 等待服务就绪
echo "等待 MySQL 就绪..." && sleep 5

# 启动 Spring Boot
mvn spring-boot:run -Dspring-boot.run.profiles=dev
```

### 2.2 日志清理脚本

```bash
#!/bin/bash
# cleanup.sh
LOG_DIR="${1:-/var/log/myapp}"
RETENTION_DAYS="${2:-7}"

echo "清理 $LOG_DIR 中 $RETENTION_DAYS 天前的日志"
find "$LOG_DIR" -name "*.log" -mtime "+$RETENTION_DAYS" -delete
echo "完成"
```

## 3. PowerShell 脚本

### 3.1 Windows 环境检查

```powershell
# check-env.ps1
Write-Host "=== 开发环境检查 ===" -ForegroundColor Green

$tools = @{
    "Java"    = "java -version 2>&1 | Select-Object -First 1"
    "Maven"   = "mvn -version 2>&1 | Select-Object -First 1"
    "Git"     = "git --version"
    "Docker"  = "docker --version"
    "Node"    = "node --version"
}

foreach ($tool in $tools.Keys) {
    try {
        $result = Invoke-Expression $tools[$tool] 2>$null
        Write-Host "✅ $tool : $result" -ForegroundColor Green
    } catch {
        Write-Host "❌ $tool : 未安装" -ForegroundColor Red
    }
}

Write-Host "`n端口占用检查:" -ForegroundColor Yellow
netstat -ano | Select-String "8080|3306|6379"
```

## 4. Batch 批处理

### 4.1 Windows Maven 构建

```batch
@echo off
chcp 65001 >nul
setlocal

echo ============================================
echo    Maven 构建 + 部署脚本
echo ============================================

set TARGET=%1
if "%TARGET%"=="" set TARGET=package

echo 执行: mvn clean %TARGET%
call mvn clean %TARGET% -DskipTests

if %errorlevel% neq 0 (
    echo ❌ 构建失败！
    pause
    exit /b 1
)

echo ✅ 构建成功！
dir target\*.jar /b

endlocal
pause
```

## 5. 跨平台定时任务

| 系统 | 工具 | 编辑命令 | 格式 |
|------|------|---------|------|
| Linux/macOS | crontab | `crontab -e` | `分 时 日 月 周` |
| Windows 传统 | schtasks | `schtasks /create` | 命令行参数 |
| Windows 现代 | Task Scheduler GUI | `taskschd.msc` | GUI |
| CI/CD | GitHub Actions / Jenkins | YAML / Groovy | 事件触发 |

```bash
# crontab 示例
0 2 * * * /opt/scripts/backup.sh           # 每天 2AM
*/10 * * * * /opt/scripts/health-check.sh   # 每 10 分钟
```

## 6. 开发常用模板

### 6.1 一键 Git 提交（.sh）

```bash
#!/bin/bash
MSG="${1:?请传入 commit message}"
git add -A && git commit -m "$MSG" && git push
echo "✅ 已提交并推送"
```

### 6.2 端口转发（.sh）

```bash
#!/bin/bash
# port-forward.sh — 从堡垒机转发数据库端口到本地
ssh -L ${1:-3306}:prod-db.internal:3306 bastion-host
```

### 6.3 批量重启微服务（.ps1）

```powershell
param([string[]]$Services = @("user-service","order-service"))
foreach ($svc in $Services) {
    Write-Host "重启 $svc ..." -NoNewline
    kubectl rollout restart deployment/$svc | Out-Null
    Write-Host " ✅"
}
```

> 🎯 **Bash 主攻 Linux**，**PowerShell 主攻 Windows/云**，**Batch 兼容旧系统**。`set -euo pipefail` 是 Bash 脚本的安全底线，`$errorlevel` 是 Batch 的判断依据，`try/catch` 是 PowerShell 的异常处理。
