## 1. 文件与目录操作

| 操作 | Linux/macOS | Windows cmd | PowerShell |
|------|-----------|-------------|------------|
| 列出文件 | `ls -la` | `dir` | `Get-ChildItem` / `ls` |
| 切换目录 | `cd /path` | `cd C:\path` | `cd C:\path` |
| 当前路径 | `pwd` | `cd` | `Get-Location` / `pwd` |
| 创建目录 | `mkdir -p a/b` | `md a\b` | `New-Item -Type Dir a\b` |
| 创建文件 | `touch file` | `type nul > file` | `New-Item file` |
| 复制 | `cp -r src dst` | `xcopy /E src dst` | `Copy-Item -Recurse src dst` |
| 移动/重命名 | `mv old new` | `move old new` | `Move-Item old new` |
| 删除文件 | `rm file` | `del file` | `Remove-Item file` |
| 删除目录 | `rm -rf dir` | `rmdir /S dir` | `Remove-Item -Recurse dir` |
| 查看文件 | `cat file` | `type file` | `Get-Content file` / `cat` |
| 分页查看 | `less file` | `more file` | `more file` |
| 搜索文件 | `find . -name "*.java"` | `dir /S *.java` | `gci -Recurse *.java` |
| 软链接 | `ln -s target link` | `mklink link target` | `New-Item -Type SymbolicLink` |
| 权限 | `chmod 755 file` | `icacls file` | `Set-Acl` |
| 磁盘使用 | `df -h` | `wmic logicaldisk` | `Get-PSDrive` |
| 目录大小 | `du -sh dir` | `dir /S dir` | `gci -Recurse dir \| Measure Length -Sum` |

## 2. 文本处理

| 操作 | Linux/macOS | Windows cmd | PowerShell |
|------|-----------|-------------|------------|
| 搜索文本 | `grep "error" file` | `find "error" file` | `Select-String "error" file` |
| 递归搜索 | `grep -r "error" ./` | `findstr /S "error" *.log` | `sls "error" (gci -r)` |
| 文本替换 | `sed 's/old/new/g' file` | ❌ 无原生 | `(gc file) -replace 'old','new'` |
| 行数统计 | `wc -l file` | `find /c /v "" file` | `(gc file).Count` |
| 排序 | `sort file` | `sort file` | `Sort-Object` |
| 去重 | `sort \| uniq` | ❌ | `Get-Unique` |
| 取头部 | `head -20 file` | ❌ | `gc file -Head 20` |
| 取尾部 | `tail -20 file` | ❌ | `gc file -Tail 20` |
| 实时跟踪 | `tail -f app.log` | ❌ | `gc app.log -Wait` |

## 3. 系统管理

| 操作 | Linux/macOS | Windows cmd | PowerShell |
|------|-----------|-------------|------------|
| 进程列表 | `ps aux` | `tasklist` | `Get-Process` |
| 查进程 | `ps aux \| grep java` | `tasklist \| findstr java` | `Get-Process java` |
| 终止进程 | `kill -9 PID` | `taskkill /F /PID 1234` | `Stop-Process -Id 1234` |
| 端口占用 | `lsof -i :8080` | `netstat -ano \| findstr 8080` | `Get-NetTCPConnection -LocalPort 8080` |
| 环境变量 | `echo $PATH` | `echo %PATH%` | `$env:PATH` |
| 设置变量 | `export KEY=val` | `set KEY=val` | `$env:KEY = "val"` |
| 别名 | `alias ll='ls -la'` | `doskey ll=dir` | `Set-Alias ll Get-ChildItem` |
| 进程监控 | `top` / `htop` | `taskmgr` (GUI) | `Get-Counter` |
| 服务管理 | `systemctl status nginx` | `sc query nginx` | `Get-Service nginx` |
| 定时任务 | `crontab -e` | `schtasks` | `Register-ScheduledTask` |

## 4. 网络操作

| 操作 | Linux/macOS | Windows cmd | PowerShell |
|------|-----------|-------------|------------|
| Ping | `ping -c 4 host` | `ping -n 4 host` | `Test-Connection -Count 4 host` |
| DNS | `dig host` / `nslookup` | `nslookup host` | `Resolve-DnsName host` |
| 路由追踪 | `traceroute host` | `tracert host` | `Test-NetConnection -TraceRoute` |
| 下载 | `curl -O url` | `curl -O url` | `Invoke-WebRequest -Uri url -OutFile f` |
| API | `curl -X POST url -d '{}'` | 同左 | `Invoke-RestMethod -Uri url -Body '{}'` |
| 端口检测 | `nc -zv host 80` | `telnet host 80` | `Test-NetConnection host -Port 80` |

## 5. 包管理对照

| 操作 | Linux (apt) | Linux (dnf) | macOS (brew) | Windows (winget) |
|------|:---------:|:---------:|:----------:|:--------------:|
| 更新索引 | `apt update` | `dnf check-update` | `brew update` | — |
| 安装 | `apt install pkg` | `dnf install pkg` | `brew install pkg` | `winget install pkg` |
| 搜索 | `apt search kw` | `dnf search kw` | `brew search kw` | `winget search kw` |
| 卸载 | `apt remove pkg` | `dnf remove pkg` | `brew uninstall pkg` | `winget uninstall pkg` |
| 升级 | `apt upgrade` | `dnf upgrade` | `brew upgrade` | `winget upgrade` |
| 已安装 | `apt list --installed` | `rpm -qa` | `brew list` | `winget list` |

---

> 🎯 **速记**：`ls=dir=gci`，`cat=type=gc`，`grep=findstr=sls`。Linux 命令在 PowerShell 中大部分可作为 alias 使用；cmd 中不通用，需查表。
