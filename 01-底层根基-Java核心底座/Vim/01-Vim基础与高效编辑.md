## 1. Vim 的定位与适用边界

> **背景**：Vim 1988 年诞生（Vi 1976），至今仍是服务器环境的事实标准编辑器；Neovim 是其现代分支。
> **目的**：模式编辑 + 组合语法 → 双手不离键盘的文本操作效率。
> **适用范围**：服务器远程编辑（无 GUI 环境）、快速文本修改、配置文件编辑、代码编辑（配合插件）。
> **不适用场景**：图形化重度重构（IDE 更直观）、大团队协作的默认编辑器（学习曲线）、不打算长期投入的场景（先用 nano）。

```text
什么时候用 Vim
├── ✅ 服务器上改配置（vim /etc/nginx/nginx.conf）
├── ✅ 远程 SSH 会话中编辑（无需下载/上传）
├── ✅ 快速修改（替换/批量操作比 IDE 快）
├── ✅ git commit 信息编辑（默认进入 vim）
├── ⚠️ 学习期效率低于 IDE（前两周会「变慢」）
└── ✅ 学成后：文本操作效率全面反超
```

## 2. 四种模式详解

### 2.1 模式全景

| 模式 | 进入方式 | 作用 | 按键语义 |
|------|---------|------|---------|
| **普通模式** | `Esc` | 默认模式：移动/操作 | 字母 = 命令 |
| **插入模式** | `i`/`a`/`o` 等 | 输入文本 | 字母 = 字符 |
| **可视模式** | `v`/`V`/`Ctrl+v` | 选择文本 | 移动 = 扩选 |
| **命令行模式** | `:`/`/`/`?` | 执行命令/搜索 | 输入命令 |

```text
模式切换（必须肌肉记忆）
┌──────────┐    i/a/o    ┌──────────┐
│ 普通模式  │ ─────────→ │ 插入模式  │
│ (Esc 回)  │ ←───────── │          │
└──────────┘    Esc      └──────────┘
    │  v/V/Ctrl+v               │
    ▼                          ▼
┌──────────┐    :           ┌──────────┐
│ 可视模式  │   ┌─────────→ │ 命令行模式 │
└──────────┘   │   Enter   └──────────┘
               └───────────┘
```

### 2.2 插入模式的进入方式（高频区分）

```bash
i     # 光标前插入（insert）
a     # 光标后插入（append）
I     # 行首插入
A     # 行尾插入（最常用！）
o     # 下方新行插入（open）
O     # 上方新行插入
s     # 删除光标字符并插入
S     # 删除整行并插入
cc    # 修改整行（等价 S）
```

> ⚠️ **新手最大困扰**：忘记按 Esc 导致命令变成输入文本——**遇到「命令没反应」先按 Esc 回普通模式**。

## 3. 光标移动全集

### 3.1 基础移动（hjkl）

```text
    k（上）
h（左）  l（右）
    j（下）

为什么不顺手？
├── ① 手不离键盘中央（h j k l 在食指/中指/无名指/小指下方）
├── ② 无需移动手腕（方向键要伸手）
└── ③ 可组合次数：5j = 向下 5 行
```

### 3.2 词级移动（效率核心）

| 按键 | 动作 | 说明 |
|:---:|------|------|
| `w` | 下一个词开头 | word（含标点分隔） |
| `W` | 下一个词开头 | WORD（空格分隔） |
| `b` | 上一个词开头 | back |
| `e` | 词尾 | end |
| `ge` | 上一个词尾 | |

```text
w vs W 的区别（中文/代码场景重要）
├── w：按「标点/字母数字」分词
│   例如 hello.world → hello / . / world（3 个词）
├── W：按「空白」分词
│   例如 hello.world → hello.world（1 个词）
└── 代码场景 w 更常用（按标识符跳转）
```

### 3.3 行/段落/屏幕级移动

| 按键 | 动作 |
|:---:|------|
| `0` | 行首（第一个字符） |
| `^` | 行首（第一个非空白字符） |
| `$` | 行尾 |
| `gg` | 文件开头 |
| `G` | 文件末尾 |
| `5G` | 第 5 行 |
| `Ctrl+d` | 向下翻半页 |
| `Ctrl+u` | 向上翻半页 |
| `Ctrl+f` | 向下翻整页 |
| `Ctrl+b` | 向上翻整页 |
| `{` / `}` | 上一段/下一段（空行分隔） |
| `(` / `)` | 上一句/下一句（句号分隔） |
| `%` | 匹配括号跳转（( [ { 之间） |

### 3.4 搜索移动与跳跃列表

```bash
# 搜索移动（比逐词移动快得多）
/pattern    # 向下搜索
?pattern    # 向上搜索
n           # 下一个匹配
N           # 上一个匹配

# 跳跃列表（编辑历史的「后退键」）
Ctrl+o      # 跳到上一个位置（jump older）
Ctrl+i      # 跳到下一个位置（jump newer）
# 妙用：在大文件里搜索跳转后，Ctrl+o 快速回到原位置

# 标记（书签）
mx          # 标记当前位置为 x
'x          # 跳到标记 x（反引号 `x 精确到列）
''          # 跳回上一次位置
```

> 🎯 **移动效率分层**：字符移动（hjkl）→ 词移动（w/b/e）→ 搜索移动（/pattern）→ 跳跃列表（Ctrl+o）——**层级越高越省按键，养成用搜索+跳跃的习惯**。

## 4. 编辑操作

### 4.1 删除（d = delete）

| 命令 | 动作 |
|:---:|------|
| `x` | 删除光标字符（dl） |
| `dw` | 删除一个词 |
| `d2w` | 删除两个词 |
| `dd` | 删除整行 |
| `d$` | 删到行尾（D） |
| `d0` | 删到行首 |
| `dG` | 删到文件末尾 |
| `d}` | 删到段末 |

### 4.2 修改（c = change，删除并进入插入）

| 命令 | 动作 |
|:---:|------|
| `cw` | 修改一个词 |
| `ciw` | 修改整个词（含边界处理） |
| `cc` | 修改整行 |
| `c$` | 修改到行尾（C） |
| `ct.` | 修改到下一个 `.` 前（t = till） |
| `cf"` | 修改到下一个 `"` 处（含引号） |

### 4.3 其他操作

```bash
y（yank）复制    p（paste）粘贴    u（undo）撤销
yy    复制整行      P    光标前粘贴    Ctrl+r  重做
yw    复制词       "0p  粘贴最近复制   U      撤销整行修改
y$    复制到行尾   "+p  粘贴系统剪贴板
```

### 4.4 点命令 `.`（最高效的按键）

> 🎯 **点命令**：重复上一次修改——把「一个修改单元」变成一键：

```text
场景：把文档中 5 个 "TODO" 改成 "DONE"
├── 笨方法：每处都按完整命令（重复 5 次）
├── 聪明方法：
│   ① 第一次修改：ciw → DONE → Esc（一个修改单元）
│   ② 之后每处：按 . （自动重复「修改词为 DONE」）
└── 点命令的威力：一次教学，N 次复读
```

## 5. 复制、粘贴与寄存器

### 5.1 寄存器（剪贴板的「多档位」）

> **背景**：Vim 的复制粘贴比系统剪贴板强大——它有 26 个命名寄存器 + 多个特殊寄存器。

| 寄存器 | 内容 | 说明 |
|:---:|------|------|
| `"0` | 最近复制 | 复制的内容（不被删除覆盖） |
| `"a`-`"z` | 命名寄存器 | 手动指定存储 |
| `"*` / `"+` | 系统剪贴板 | 与系统共享（需 GUI/剪贴板支持） |
| `"` | 未命名寄存器 | 最近删除/复制（默认） |

```bash
# 命名寄存器使用
"ayy        # 复制当前行到寄存器 a
"ap         # 粘贴寄存器 a 的内容
"a5yy       # 复制 5 行到 a

# 系统剪贴板（2026 现代 Vim 默认支持）
"+yy        # 复制到系统剪贴板（可粘贴到浏览器）
"+p         # 粘贴系统剪贴板内容

# 查看寄存器
:reg        # 列出所有寄存器内容
```

> ⚠️ **经典困惑**：删除后粘贴的不是想复制的内容——因为删除和复制共用未命名寄存器。解法：**复制用 `"0` 或命名寄存器**。

### 5.2 剪贴板支持检查

```vim
" 检查 Vim 是否支持系统剪贴板（输出 +clipboard 才支持）
vim --version | grep clipboard

" 不支持时（Linux 需装 xclip 等）
" Debian/Ubuntu: sudo apt install vim-gtk3
```

## 6. 撤销与重做

### 6.1 基本撤销

```bash
u           # 撤销一步
Ctrl+r      # 重做
U           # 撤销整行所有修改
```

### 6.2 撤销分支（Vim 独有）

> 🎯 **Vim 的撤销是「树状分叉」**——撤销后做新修改，不会丢失被撤销的历史：

```vim
" 场景：改 A → 改 B → 撤销（回到 A）→ 改 C
" 此时 B 还在撤销树里，可以找回！
:earlier 5m      " 回到 5 分钟前
:later 2m        " 前进 2 分钟
:undolist        " 查看撤销分支列表

" 也可以按修改次数
:earlier 10      " 回退 10 次修改
```

> 💡 **相比其他编辑器**：大多数编辑器的撤销是「线性」（撤销后新操作丢失历史）；Vim 的树状撤销让误操作可恢复——**大胆实验，随时回头**。

## 7. 组合语法：效率的核心

### 7.1 语法规则

```text
Vim 组合语法 = [次数] + [操作] + [范围]

操作（动词）：d 删除 / c 修改 / y 复制 / v 选择 / > 缩进
范围（名词）：w 词 / 行 / $ 行尾 / 文本对象（见 02 篇）

示例：
d2w    = 删除 2 个词
c$     = 修改到行尾
y3j    = 复制当前行 + 下面 3 行
>2}    = 缩进到段末（2 段）
```

### 7.2 组合 vs 逐键（效率对比）

```text
任务：删除一个词
├── 逐键：x x x x ...（按词长）
├── 组合：dw（2 键，与词长无关）
└── 任务：删除 3 个词
    ├── 逐键：重复 3 次 dw = 6 键
    └── 组合：d3w（3 键）

→ 组合语法的本质：把「多次重复」压成「一次表达」
→ 目标：见到文本形态，立即反应出对应组合（肌肉记忆）
```

## 10. 核心要点

> 🎯 **核心要点**：
> 1. 四种模式（普通/插入/可视/命令行）是 Vim 的根基——**命令没反应先按 Esc**
> 2. 移动分层：字符 → 词 → 搜索 → 跳跃列表——层级越高效率越高
> 3. 组合语法 `[次数][操作][范围]` 是效率核心（d2w 一个表达顶多次按键）
> 4. 点命令 `.` 重复上次修改；寄存器 `"0`/`"a` 解决「复制丢失」困惑
> 5. Vim 树状撤销（`:earlier`/`:later`）——大胆实验随时回头
> 6. 练习计划：vimtutor 入门 + 两周坚持过「变慢期」即反超
