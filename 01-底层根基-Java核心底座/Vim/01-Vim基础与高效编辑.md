## 1. 三种模式

```text
Vim 的核心哲学：不同的模式做不同的事

  Normal（普通模式）← 默认，导航、删除、复制
      → i I a A o O → Insert
      → : → Command-line
      → v V Ctrl+v → Visual

  Insert（插入模式）← 输入文字
      → Esc → 回 Normal

  Command-line（命令模式）← 保存、退出、搜索
```

### 1.1 插入模式入口

| 按键 | 行为 | 记忆 |
|:--:|------|------|
| `i` | 光标前插入 | **i**nsert |
| `I` | 行首插入 | 大 I → 行首 |
| `a` | 光标后插入 | **a**ppend |
| `A` | 行尾插入 | 大 A → 行尾 |
| `o` | 下一行插入 | **o**pen below |
| `O` | 上一行插入 | **O**pen above |

## 2. 光标移动

### 2.1 基础四方向（替代方向键）

```
        k（上）
h（左）        l（右）
        j（下）

为什么 hjkl？→ 手不离主键盘区，效率极高
```

### 2.2 单词与行内移动

| 按键 | 移动 | 口诀 |
|:--:|------|------|
| `w` | 下一个单词开头 | **w**ord |
| `b` | 上一个单词开头 | **b**ack |
| `e` | 单词结尾 | **e**nd |
| `0` | 硬行首 | |
| `^` | 第一个非空字符 | |
| `$` | 行尾 | 正则即视感 |
| `f{char}` | 跳到下一个{char} | **f**ind |
| `;` / `,` | 重复 f/t 搜索 | 正向/反向 |

### 2.3 页面与文件级

| 按键 | 移动 |
|:--:|------|
| `gg` | 文件头 |
| `G` | 文件尾 |
| `{N}gg` | 跳到第 N 行 |
| `Ctrl+d/u` | 下半/上半页 |
| `Ctrl+f/b` | 下/上一整页 |
| `zz` | 当前行居中 |
| `%` | 跳到匹配括号 |

## 3. 编辑操作

### 3.1 删除（d = delete）

| 按键 | 操作 |
|:--:|------|
| `x` | 删光标字符 |
| `dd` | 删整行 |
| `dw` | 删到单词尾 |
| `d$` / `D` | 删到行尾 |
| `d0` | 删到行首 |
| `dG` | 删到文件尾 |
| `{N}dd` | 删 N 行 |

### 3.2 修改（c = change = 删+入插入）

| 按键 | 操作 | 场景 |
|:--:|------|------|
| `cw` | 改一个单词 | 改变量名 |
| `ciw` | 改光标所在单词 | ⭐ 不依赖位置 |
| `ci"` | 改双引号内文本 | 改字符串内容 |
| `ci(` / `ci[` | 改括号内文本 | 改参数 |
| `cc` | 改整行 | 重写一行 |
| `C` | 改到行尾 | |

## 5. 生存速查卡

```text
打开：   vim file.txt
退出：   :q(退出) :q!(不保存强退) :wq(保存退出) ZZ(同:wq)
编辑：   i(插入) Esc(回Normal)
删除：   x(删字) dd(删行) u(撤销)
保存：   :w
搜索：   /word(向前) ?word(向后) n(下一) N(上一)
跳转：   $行尾 0行首 gg文件头 G文件尾
```

> 🎯 前 20 分钟掌握 `i Esc :wq dd u yy p / n gg G 0 $` 就能在服务器上生存。**不用鼠标，一周形成肌肉记忆**。
