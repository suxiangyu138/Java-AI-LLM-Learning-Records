## 1. 文本对象：以结构为单位操作

### 1.1 什么是文本对象

> **背景**：基础编辑按「字符/词/行」操作；文本对象让操作以「结构」为单位——括号内、引号内、标签内、句子、段落。
> **目的**：无论结构多长，一条命令精准命中——**光标在结构内任何位置都能操作**。
> **适用范围**：代码编辑（括号/引号/标签）、文档编辑（词/句/段）。
> **不适用场景**：无明确边界的文本（需手动可视选择）。

```text
文本对象语法 = 操作 + [i/a] + 对象
├── i（inside）：结构内部（不含边界）
├── a（around）：结构含边界（含括号/引号）
└── 对象：w 词 / s 句 / p 段 / ( ) 括号 / [ ] 中括号 / { } 花括号 / " ' ` 引号 / t 标签
```

### 1.2 文本对象全集

| 命令 | 含义 | 示例（光标在 "Hello" 内） |
|:---:|------|------|
| `ciw` | 修改整个词 | `ciw` → 输入替换词 |
| `ci(` / `ci)` | 修改括号内 | `ci(` → 改括号内全部 |
| `di(` | 删除括号内 | 保留括号删除内容 |
| `ca(` | 删除含括号 | 括号连同内容一起删 |
| `ci"` | 修改引号内 | 保留引号改内容 |
| `da"` | 删除含引号 | 引号连同内容删除 |
| `cit` | 修改标签内 | `<div>内容</div>` 只改内容 |
| `dat` | 删除含标签 | 整个标签删除 |
| `ci[` / `ci{` | 修改中括号/花括号内 | 代码块操作 |
| `vis` | 选择整个句子 | |
| `vip` | 选择整个段落 | |

```java
// 实战示例：Java 代码
// 光标在方法参数里任意位置
ci(     // 清空参数列表（保留括号）→ 重新输入参数
ci{     // 清空方法体（保留花括号）→ 重写方法体
da{     // 删除整个代码块（含花括号）
cit     // HTML/模板中修改标签内容

// 嵌套结构的处理：从内到外
// ci( 改最内层括号 → ci( 再按一次改外层（向内逐层）
```

> 🎯 **文本对象的价值**：**光标在结构内任何位置，命令结果一致**——不用精确移动光标到边界，这是 vs 可视选择的本质优势。

## 2. 可视模式进阶

### 2.1 三种可视模式

| 模式 | 进入 | 选择方式 |
|:---:|:---:|---------|
| **字符可视** | `v` | 逐字符选择 |
| **行可视** | `V` | 整行选择 |
| **块可视** | `Ctrl+v` | 矩形块选择（列编辑！） |

### 2.2 块可视（列编辑，最实用）

```text
块可视的场景：
├── 批量加注释（多行行首加 //）
├── 批量修改列（多行同一列的内容）
├── 复制矩形区域
└── 批量删除列

操作流程（批量加注释）：
① Ctrl+v 进入块可视
② 移动选中多行的行首列
③ I → 输入 // → Esc（所有选中行生效！）
```

```text
另一个高频场景（批量改前缀）：
① Ctrl+v 选中多行开头字符
② c → 输入新内容 → Esc（批量替换前缀）
```

### 2.3 可视模式的选择技巧

```text
可视 + 文本对象 = 精准选择
├── vi(   选择括号内（v 进入可视 + i( 文本对象）
├── vi"   选择引号内
├── vip   选择段落
├── 选中后：d 删除 / y 复制 / c 修改 / > 缩进
└── 选中后：o 切换光标到选择另一端（微调选择）
```

## 3. 寄存器进阶

### 3.1 特殊寄存器

| 寄存器 | 内容 | 高频场景 |
|:---:|------|---------|
| `"0` | 最近复制 | 删除后想粘贴之前复制的内容 |
| `"a`-`"z` | 命名寄存器 | 多段内容暂存交换 |
| `"+` / `"*` | 系统剪贴板 | 与外部应用交换 |
| `"%` | 当前文件名 | 命令中引用当前文件 |
| `"#` | 上一个文件名 | 两文件切换 |
| `".` | 最近插入的文本 | 粘贴上次输入 |

### 3.2 寄存器实战（交换两段内容）

```text
任务：交换两段文本（A 和 B）
① 光标到 A：da" （删除 A 到默认寄存器）
② 光标到 B：va"p （选择 B 并粘贴 A 覆盖）
③ 光标回 A 位置：p（粘贴 B）
→ 或者用命名寄存器更清晰：
   ① "ayy 复制 A 到寄存器 a
   ② "byy 复制 B 到寄存器 b
   ③ "ap 粘贴 A / "bp 粘贴 B
```

### 3.3 追加到寄存器

```text
批量收集散落的文本
├── ① "Ay 开头（大写 A = 追加到寄存器 a）
├── ② 逐处复制内容
└── ③ "ap 一次性粘贴全部收集内容
→ 用途：收集日志关键行、汇总散落配置
```

## 4. 宏录制：批量操作的录制机

### 4.1 什么是宏

> **背景**：重复的「多步操作」每次手打太慢——宏把操作序列录制成一键回放。
> **目的**：批量处理相同模式的文本（每行做同样的事）。
> **适用范围**：日志清洗、CSV 处理、代码批量改造。
> **不适用场景**：每行结构不同的文本（先统一结构再录宏）。

### 4.2 录制与回放

```bash
# 录制宏到寄存器 a
qa          # 开始录制（q + 寄存器名）
...操作...   # 执行要重复的操作
q           # 结束录制

# 回放
@a          # 播放一次
5@a         # 播放 5 次
@@          # 重复上次宏
```

### 4.3 宏实战：批量格式化

```text
任务：把 100 行 "name:xxx" 改成 "name: xxx"（加空格）

① 第一行手动处理：
   f:（跳到冒号）→ i（插入）→ 空格 → Esc
② 录制宏：
   qa f: i <Space> Esc q（录制到 a）
③ 批量回放：
   100@a（或者录制时用 j 下移一行，@@ 连续播放）

进阶技巧：
├── 宏内结尾用 j 下移一行 → @@ 可连续处理每行
├── 宏出错：u 撤销 + 修正后重新录制
└── 递归宏：@a 里包含 @a 实现循环（高级）
```

### 4.4 宏 vs 点命令（选择）

| 维度 | 点命令 `.` | 宏 `q` |
|------|:---:|:---:|
| 复杂度 | 单次修改 | 多步操作序列 |
| 录制 | 自动（上次修改） | 手动（qa...q） |
| 适用 | 简单重复 | 复杂批量流程 |

## 5. 搜索与替换

### 5.1 替换命令全解

```bash
# 基本替换（当前行第一个匹配）
:s/old/new

# 当前行全部匹配
:s/old/new/g

# 全文件替换（最常用！）
:%s/old/new/g

# 全文件 + 确认（安全替换——推荐！）
:%s/old/new/gc
# c 确认：y 替换 / n 跳过 / a 全部 / q 退出

# 范围替换
:5,10s/old/new/g        # 5-10 行
:.,$s/old/new/g         # 当前行到末尾
:'<,'>s/old/new/g       # 可视选择范围（自动出现）

# 忽略大小写
:%s/old/new/gi          # i = 忽略大小写
```

### 5.2 替换的高级模式

```bash
# 捕获组（替换中的 \1 引用）
:%s/\(orderId\)=\(\w\+\)/id:\2/g
# 把 orderId=xxx 改成 id:xxx

# 更清晰的写法（使用 \v 正则模式）
:%s/\v(orderId)=(\w+)/id:\2/g

# 特殊字符处理
:%s/\./\//g              # 点换成斜杠（转义）
:%s/[0-9]\+/N/g          # 数字批量替换为 N

# 多文件替换（配合 args）
:args **/*.java          # 加载文件列表
:argdo %s/old/new/ge | update   # 全部替换并保存
```

### 5.3 搜索技巧

```bash
# 高亮与取消
:set hlsearch            # 搜索高亮
:nohlsearch              # 取消临时高亮（或 nnoremap <Esc>）
:set incsearch           # 增量搜索（边输入边定位）

# 搜索特殊字符
/\v(pattern)             # 用 \v 让正则更像常规正则
/\cxxx                  # 本次搜索忽略大小写
/\Cxxx                  # 本次搜索区分大小写

# 全局命令（对匹配行执行操作）
:g/^#/d                  # 删除所有注释行
:g/ERROR/normal dd       # 删除所有含 ERROR 的行
:v/pattern/d             # 保留匹配行（反选删除）
```

> 🎯 **搜索替换安全习惯**：**批量替换先加 `c` 确认**（`:%s/old/new/gc`）——一次误替换全文件比多按几次 y 更危险。

## 6. 多文件与缓冲区

### 6.1 缓冲区（buffer）管理

```bash
:ls           # 列出缓冲区（打开的文件）
:bn           # 下一个缓冲区
:bp           # 上一个缓冲区
:b 3          # 跳到第 3 个缓冲区
:bd           # 关闭缓冲区（不退出 Vim）
:bd!          # 强制关闭（丢弃修改）
```

### 6.2 分屏（window）管理

```bash
:sp file      # 水平分屏
:vsp file     # 垂直分屏
Ctrl+w w      # 切换分屏
Ctrl+w h/j/k/l  # 按方向切换分屏
Ctrl+w =      # 均分屏宽
Ctrl+w _      # 最大化当前屏
:q            # 关闭当前分屏
```

### 6.3 标签页（tab）

```bash
:tabnew file  # 新标签页
gt            # 下一个标签
gT            # 上一个标签
:tabclose     # 关闭标签
```

> 🎯 **多文件工作流**：**缓冲区（隐藏文件）+ 分屏（对照编辑）+ 标签页（任务隔离）**——日常用 `:b` 切换 + `Ctrl+w` 分屏即可，标签页用于任务切换。

## 7. vimrc 配置艺术

### 7.1 配置文件的定位

> **背景**：vimrc 是 Vim 的配置文件（`~/.vimrc`；Neovim 用 `~/.config/nvim/init.vim` 或 `init.lua`）——把默认 Vim 调成「你的」编辑器。
> **目的**：一行配置 = 永久生效的行为改变。
> **适用范围**：个人开发环境；团队共享配置（`/etc/vimrc` 或仓库 dotfiles）。
> **不适用场景**：服务器临时编辑（不必改配置）。

### 7.2 核心配置模板（2026 推荐起点）

```vim
" ═══════════ 基础设置 ═══════════
set number              " 行号
set relativenumber      " 相对行号（配合组合命令高效跳转）
set expandtab           " Tab 转空格
set tabstop=4           " Tab 宽度 4
set shiftwidth=4        " 缩进宽度 4
set autoindent          " 自动缩进
set smartindent         " 智能缩进（代码）
set hlsearch            " 搜索高亮
set incsearch           " 增量搜索
set ignorecase          " 搜索忽略大小写
set smartcase           " 有大写时区分大小写
set scrolloff=5         " 滚动时保留 5 行（光标不贴边）
set mouse=a             " 鼠标支持（可选）
set clipboard=unnamedplus " 系统剪贴板（Linux）
syntax on               " 语法高亮
colorscheme desert      " 配色（可换）

" ═══════════ 快捷键映射 ═══════════
" 退出插入模式的更快方式
inoremap jk <Esc>

" 分屏切换（简化）
nnoremap <C-h> <C-w>h
nnoremap <C-j> <C-w>j
nnoremap <C-k> <C-w>k
nnoremap <C-l> <C-w>l

" 取消搜索高亮（Esc 连按）
nnoremap <Esc><Esc> :nohlsearch<CR>

" ═══════════ 文件类型相关 ═══════════
filetype plugin indent on
" Java 文件用 4 空格
autocmd FileType java setlocal tabstop=4 shiftwidth=4
" YAML 用 2 空格
autocmd FileType yaml setlocal tabstop=2 shiftwidth=2
```

### 7.3 配置的原则与避坑

```text
vimrc 配置原则
├── ① 增量配置：遇到痛点再查配置（不一次抄全）
├── ② 每条配置加注释（知道为什么）
├── ③ 版本管理：dotfiles 仓库管理（换机秒恢复）
├── ④ 少而精：配置是习惯的固化，不是功能的堆砌

常见坑
├── ⚠️ 改 vimrc 后不生效：需 :source $MYVIMRC 或重启
├── ⚠️ 语法错误导致启动异常：vim -u NONE 无配置启动排查
├── ⚠️ 团队差异：tab 宽度等团队统一（用 .editorconfig）
```

```bash
# 排查与验证
vim -u NONE file     # 无配置启动（排查配置问题）
:scriptnames         # 查看加载的配置/插件文件
:set tabstop?        # 查看当前值
:verbose set tabstop # 查看谁设置的
```

## 8. 核心要点

> 🎯 **核心要点**：
> 1. 文本对象 `ciw`/`di(`/`cit` 以结构为单位——光标在结构内任何位置命令结果一致（最高效的操作方式）
> 2. 块可视 `Ctrl+v` 实现列编辑（批量加注释/改前缀）
> 3. 宏 `qa...q` 录制多步操作 + `100@a` 批量回放——批量文本处理利器
> 4. 替换安全习惯：`:%s/old/new/gc` 确认替换；`\1` 捕获组实现结构化改写；`:g/pattern/d` 全局删除
> 5. vimrc 增量配置 + 注释 + dotfiles 版本管理；`vim -u NONE` 排查配置问题
