## 1. 定长窗口模板

```java
/**
 * 定长窗口通用模板（窗口大小固定 k）
 *
 * 三步：
 *   ① 构建第一个窗口 [0, k-1]
 *   ② 滑动：加新尾 nums[i]，去旧头 nums[i-k]
 *   ③ 每步判断窗口是否满足条件
 *
 * 复杂度 O(n)：每个元素恰好"进一次窗口、出一次窗口"
 */
public void fixedWindow(int[] nums, int k) {
    // ① 第一个窗口
    for (int i = 0; i < k; i++) {
        add(nums[i]);                     // 构建初始窗口状态
    }
    check();                              // 检查第一个窗口

    // ② 滑动
    for (int i = k; i < nums.length; i++) {
        add(nums[i]);                     // 加新尾
        remove(nums[i - k]);              // 去旧头（⚠️ i-k 不是 k-i）
        check();                          // 检查当前窗口
    }
}
```

> ⚠️ **关键坑**：忘记处理第一个窗口！很多人在循环里直接滑动，漏掉初始窗口的判断。

## 2. 643. 最大平均子数组

### 2.1 完整实现

```java
/**
 * LeetCode 643. 子数组最大平均数 I
 * 找长度为 k 的连续子数组最大平均值
 *
 * 定长窗口：维护窗口和，滑动时增量更新
 * 平均值最大 ⇔ 和最大（k 固定）
 */
public double findMaxAverage(int[] nums, int k) {
    // ① 第一个窗口的和
    int sum = 0;
    for (int i = 0; i < k; i++) {
        sum += nums[i];
    }
    int maxSum = sum;

    // ② 滑动：加新尾，去旧头
    for (int i = k; i < nums.length; i++) {
        sum += nums[i];              // 加新尾
        sum -= nums[i - k];          // 去旧头
        maxSum = Math.max(maxSum, sum);
    }
    return (double) maxSum / k;
}
```

### 2.2 推演：nums = [1, 12, -5, -6, 50, 3], k = 4

```
① 首窗 [0..3]：1+12-5-6 = 2，maxSum=2
② i=4：sum = 2 + 50 - 1 = 51（窗口 [1..4]），maxSum=51
③ i=5：sum = 51 + 3 - 12 = 42（窗口 [2..5]），maxSum=51
答案 = 51/4 = 12.75 ✓
增量：每步 O(1)，总 O(n)（暴力 O(nk)=O(n²)）
```

## 3. 438. 找到字符串中所有字母异位词

### 3.1 完整实现（频次数组）

```java
/**
 * LeetCode 438. 找到字符串中所有字母异位词
 * 在 s 中找 p 的所有异位词子串的起始下标
 * s="cbaebabacd", p="abc" → [0, 6]
 *
 * 思路：
 *   ① p 的字符频次（固定 26 数组）
 *   ② 定长窗口（长度 = p.length）统计窗口频次
 *   ③ 窗口频次 == p 频次 → 找到异位词
 */
public List<Integer> findAnagrams(String s, String p) {
    List<Integer> res = new ArrayList<>();
    if (s.length() < p.length()) return res;

    int[] pCount = new int[26];
    int[] windowCount = new int[26];

    // ① 统计 p 的频次
    for (char c : p.toCharArray()) pCount[c - 'a']++;

    // ② 滑动窗口
    for (int i = 0; i < s.length(); i++) {
        windowCount[s.charAt(i) - 'a']++;          // 加新尾

        if (i >= p.length()) {                     // 窗口超过长度
            windowCount[s.charAt(i - p.length()) - 'a']--;   // 去旧头
        }

        // ③ 窗口长度达标后比较频次
        if (i >= p.length() - 1
            && Arrays.equals(pCount, windowCount)) {
            res.add(i - p.length() + 1);           // 窗口起始下标
        }
    }
    return res;
}
```

### 3.3 推演：s = "cbaebabacd", p = "abc"

```
p 频次：a=1, b=1, c=1
i=0: 窗口 [c]：c=1
i=1: 窗口 [cb]：b=1, c=1
i=2: 窗口 [cba]：a=1, b=1, c=1 == p ✓ → 起始 0
i=3: 加 e 去 c → [bae] ✗
...
i=6: 窗口 [bac]：a=1, b=1, c=1 ✓ → 起始 6
答案 [0, 6] ✓
```

## 4. 567. 字符串的排列

### 4.1 完整实现（438 的变体）

```java
/**
 * LeetCode 567. 字符串的排列
 * s2 是否包含 s1 的某个排列
 * s1="ab", s2="eidbaooo" → true（"ba" 是 "ab" 的排列）
 *
 * 与 438 的关系：
 *   438 找所有异位词位置（返回下标列表）
 *   567 找是否存在任意一个（返回 boolean）
 *   —— 代码几乎相同！
 */
public boolean checkInclusion(String s1, String s2) {
    if (s1.length() > s2.length()) return false;

    int[] need = new int[26];
    int[] window = new int[26];

    for (char c : s1.toCharArray()) need[c - 'a']++;

    for (int i = 0; i < s2.length(); i++) {
        window[s2.charAt(i) - 'a']++;

        if (i >= s1.length()) {
            window[s2.charAt(i - s1.length()) - 'a']--;
        }

        // 定长窗口（长度 = s1）且频次匹配
        if (i >= s1.length() - 1 && Arrays.equals(need, window)) {
            return true;
        }
    }
    return false;
}
```

### 4.2 异位词三兄弟对比

| 题号 | 题目 | 返回值 | 差异 |
|:---:|------|------|------|
| 242 | 有效的异位词 | boolean | 两个字符串整体比较（非窗口） |
| 438 | 异位词分组位置 | List\<Integer\> | s 中所有窗口位置 |
| 567 | 字符串的排列 | boolean | 是否存在任一窗口 |

> 💡 **记忆**：438 与 567 代码骨架相同——**定长窗口 + 频次数组 + Arrays.equals**。242 是它们的静态版。

### 面试话术模板

```
"这题是定长窗口（长度固定为 k）。
 我先构建第一个窗口，然后每次滑动只做两件事：
 sum += nums[i] 加新尾，sum -= nums[i-k] 去旧头。
 每个元素恰好进出一次 → O(n)。
 注意不要漏掉第一个窗口的判断。"
```

> 🎯 **核心要点**：定长窗口是滑窗最简单稳定的模型——**先建首窗、增量滑动（加新尾去旧头）、每步检查**。643/438/567 三题同一模板，区别只在检查方式（和/频次/存在性）。记忆"i-k 去旧头"（不是 k-i）和"不要漏掉第一个窗口"两个坑，定长窗口题全部拿下。
