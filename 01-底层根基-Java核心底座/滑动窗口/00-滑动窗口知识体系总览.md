## 4. 核心概念速查

| 概念 | 一句话解释 | 典型例题 |
|------|-----------|------|
| **右扩左缩** | 右指针扩展探索，左指针收缩修正 | 所有滑窗题 |
| **条件单调性** | 扩窗更难满足条件、缩窗更易满足 | 滑窗成立前提 |
| **信息复用** | 增量计算窗口状态，不重复计算 | 643 定长 |
| **定长窗口** | 窗口长度固定 K，先建首窗再滑动 | 438/567 |
| **求最长** | while 缩到合法后，**while 外**更新答案 | 3/1004 |
| **求最短** | while 缩到非法前，**while 内**更新答案 | 76/209 |
| **恰好型** | exactlyK = atMost(K) - atMost(K-1) | 992/930 |
| **valid 变量** | 记录已满足的字符种类数（76 题） | 76 |
| **maxFreq 不回退** | 最长重复字符题的最大频次只增不减 | 424 |
| **单调队列** | 双端队列维护窗口最值 | 239 |
| **失效场景** | 含负数 → 不单调 → 前缀和+哈希 | 560 |

## 7. 口决速记

```
右扩左缩，先进后出          ← 滑窗骨架
连续看单调，单调看维护        ← 判定标准
最长在外更新，最短在内更新    ← 更新位置
缩窗必须用 while             ← 铁律
恰好等于至多减至多           ← 容斥公式
i-k 去旧头，勿漏第一窗口      ← 定长坑位
晚到且更大，淘汰早到且更小    ← 单调队列
```

## 8. 滑窗 vs 前缀和 vs 单调队列

| 技术 | 适用 | 复杂度 | 代表题 |
|------|------|:---:|:---:|
| 滑动窗口 | 连续区间 + 单调条件 | O(n)/O(1) | 3/76/209 |
| 前缀和+哈希 | 区间和统计（含负数） | O(n)/O(n) | 560/974 |
| 单调队列 | 窗口最值/DP 优化 | O(n)/O(k) | 239/1696 |
| 双堆 | 窗口中位数 | O(n log k) | 480 |

```
选型："连续看单调"→滑窗；"区间和统计"→前缀和；
     "窗口最值"→单调队列；"窗口有序统计"→双堆
```
