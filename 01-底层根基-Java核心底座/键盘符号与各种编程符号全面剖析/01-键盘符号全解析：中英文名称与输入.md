## 1. 为什么符号名称重要

> **背景**：代码交流（口头/文字）、英文报错、英文文档搜索——都需要准确的符号英文名。
> **目的**：建立符号名称的「肌肉记忆」——看到符号能说名、听到名能打符。
> **适用范围**：任何编程场景的沟通与排错。
> **不适用场景**：只读不写不交流的场景（几乎不存在）。

```text
符号名称的三大场景
├── ① 沟通：和同事说代码（"把 slash 改成 backslash"）
├── ② 排错：英文报错里找符号（"unexpected character: '^' at caret"）
├── ③ 搜索：用英文名搜文档（"Java backtick" / "regex caret"）
└── 金句：符号名称是程序员的「第二语言词汇表」——报错读不懂往往不是英语问题，是符号名问题
```

## 2. 符号名称对照表（32 个）

| 符号 | 英文名 | 中文名 | 编程场景 |

| `%` | **Percent** | 百分号 | 取余（`10 % 3`）/格式化（`%d`） |
| `^` | **Caret**（Circumflex） | 折音号/脱字符 | 异或（`a ^ b`）/正则行首 |
| `&` | **Ampersand** | 和号 | 逻辑与（`&&`）/按位与（`&`） |

## 3. 符号的编程俗称

> 🎯 **程序员之间的「行话」**——沟通时常用简称，掌握后交流更顺畅：

| 符号 | 编程俗称 | 场景 |
|:---:|---------|------|
| `!` | **bang** | "加个 bang 就是取反" |
| `#` | **hash** / **octothorpe** | "hash 开头是注释" |
| `*` | **star** | "star 表示全部" |
| `.` | **dot** | "dot 后面是方法" |
| `/` | **slash** | "URL 用 slash" |
| `\` | **backslash** | "路径用 backslash" |
| `\|` | **pipe** | "管道 pipe 接 grep" |
| `` ` `` | **backtick** | "反引号模板" |
| `~` | **tilde** | "tilde 是主目录" |
| `@` | **at** | "at 注解" |
| `%` | **mod**（取余时） | "mod 取余" |
| `^` | **caret** | "caret 是正则行首" |
| `&` | **amp**（`&&` 时） | "amp amp 短路与" |
| `<>` | **angle brackets** | "泛型用尖括号" |

> 💡 **报错里的符号名**：英文报错常直接使用符号名——`unexpected token: '}'`（花括号）、`illegal start of expression`（表达式非法开始，常见于括号/分号错误）。**认识符号名 = 读懂一半报错**。

## 4. 键盘输入方法

### 4.1 US 键盘符号位置（Shift 组合）

```text
US 键盘符号输入（无需 Shift 的直接符号）
` - = [ ] \ ; ' , . /

Shift 组合（主行数字）
1! 2@ 3# 4$ 5% 6^ 7& 8* 9( 0) -_ =+
其他 Shift 组合
[{  ]}  \|  ;:  '"  ,<  .>  /?

记忆技巧：
├── 数字行：Shift + 数字 = 符号（!@#$%^&*() 顺序）
├── 右侧：{ [ \ 是左手 Shift；} ] | 是右手 Shift
└── 中文键盘：布局与 US 相同（输入法切换）
```

### 4.2 常用符号输入速查

```bash
# 开发中最高频的符号输入
{}       # Shift + [ 和 Shift + ]
()       # Shift + 9 和 Shift + 0
[]       # 直接按（US 键盘）
<>       # Shift + , 和 Shift + .
|        # Shift + \
~        # Shift + `
_        # Shift + -
!@#$%^&*  # Shift + 数字 1-8
```

## 5. 中文输入法下的符号输入

> ⚠️ **中文输入法陷阱**：输入法会「智能替换」符号——**中文引号/括号/分号进入代码 = 编译错误**：

```text
中文输入法的高频事故
├── ⚠️ 中文引号："abc"（弯引号）→ Java 字符串语法错误！
├── ⚠️ 中文括号：（ ）→ 方法调用错误
├── ⚠️ 中文分号；→ 语句结束错误
├── ⚠️ 中文逗号，→ 参数分隔错误
├── ⚠️ 全角符号：１２３（全角数字）→ 类型不匹配

防护习惯
├── ① 写代码时切英文输入法（Ctrl+Space/Shift 切换）
├── ② IDE 报错「illegal character」→ 先查中文符号
├── ③ 编辑器设置：输入法状态提示（VS Code 右下角）
└── ④ 输入法「中文标点」选项关闭（写代码时）

符号输入方法（中文输入法内）
├── 输入 "v1" + 数字：特殊符号面板（搜狗/微软拼音）
├── 常用符号快捷键：Shift 直接输出英文符号（保持英文标点设置）
└── 特殊符号：～！@#￥%……&*（中文输入法全角版本）
```

> 🎯 **金句**：**「写代码用英文符号、写中文用中文符号」**——IDE 报 `illegal character` 时，第一反应检查输入法。

## 6. 特殊符号组合（Shebang/箭头等）

### 6.1 组合符号（多个符号的组合含义）

| 组合 | 名称 | 含义/用途 |
|:---:|------|---------|
| `#!` | **Shebang**（Sha-bang） | 脚本解释器声明（`#!/bin/bash` 第一行） |
| `->` | **Arrow** | 箭头（C 指针/Lambda 旧语法） |
| `=>` | **Fat Arrow** | 胖箭头（Lambda：Java `(x) -> x*2`） |
| `::` | **Method Reference** | 方法引用（Java `System.out::println`） |
| `...` | **Ellipsis**（Varargs） | 可变参数（`String... args`） |
| `===` | **Strict Equality** | 严格相等（JS） |
| `!==` | **Strict Inequality** | 严格不等（JS） |
| `<>` | **Diamond** | 菱形泛型（Java `List<>`） |
| `?:` | **Elvis**（?:） | 空值合并（Kotlin/Groovy） |
| `::` | **Scope** | 作用域符（C++ `Class::method`） |

### 6.2 符号组合的命名（沟通用）

```text
说代码时的组合叫法
├── && → "amp amp" / "and and"（短路与）
├── || → "pipe pipe"（短路或）
├── == → "equal equal"（相等比较）
├── != → "bang equal"（不等）
├── <= → "less equal"（小于等于）
├── -> → "arrow"（箭头/Lambda）
├── :: → "double colon"（方法引用）
└── ... → "dot dot dot" / "ellipsis"（可变参数）
```

## 7. 核心要点

> 🎯 **核心要点**：
> 1. 32 个键盘符号的「英文名 + 中文名 + 编程俗称」三重身份——**报错读不懂往往是符号名问题**
> 2. 编程俗称是行话：bang/hash/star/dot/slash/pipe/backtick——沟通必备
> 3. 中文输入法陷阱：中文引号/括号/分号进代码 = 编译错误——「写代码用英文符号」
> 4. 组合符号：Shebang（#!）/Fat Arrow（=>）/Diamond（<>）/Ellipsis（...）各有专属名称
> 5. 说代码的规范叫法：`&&` 说 "amp amp"、`->` 说 "arrow"——团队沟通零歧义
