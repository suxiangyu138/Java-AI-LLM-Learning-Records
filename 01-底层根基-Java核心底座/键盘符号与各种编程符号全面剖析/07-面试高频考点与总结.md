## 1. 面试高频题与答题框架

### 1.1 运算符类

**Q1：`==` 和 `equals` 的区别？**

```text
① ==：比较「引用是否相同」（基本类型比较值）
② equals：比较「内容是否相同」（Object 方法，类可重写）
③ 字符串陷阱：常量池让 "abc"=="abc" 碰巧 true
   → new String("abc")=="abc" 是 false！
④ 结论：字符串/对象内容比较一律 equals；== 用于基本类型与 null
⑤ 加分：Objects.equals(s1, s2) 防 NPE
```

**Q2：`&&` 和 `&` 的区别？**

```text
① &&：短路与——左边 false 右边不执行
② &：按位与（整数）；逻辑与（不短路——两边都执行）
③ 短路实战价值：if (s != null && s.length() > 0) 防 NPE
④ 面试延伸：|| 与 | 同理
⑤ 陷阱：& 不短路 → 左边 false 右边仍执行（副作用/异常）
```

**Q3：10 / 3 的结果是多少？**

```text
① 整数除法：10/3 = 3（截断，不是 3.33！）
② double d = 10/3 → 3.0（先整数除再转）
③ 正确：10.0/3 或 (double)10/3 → 3.33
④ 延伸：10 % 3 = 1（取余）
⑤ 陷阱：金额计算勿用浮点除法（精度问题）
```

**Q4：运算符优先级？**

```text
① 口诀：括号一元 → 乘除 → 加减 → 移位 → 比较 → 相等
   → 位与 → 异或 → 位或 → 逻辑与 → 逻辑或 → 三元 → 赋值
② 位运算优先级低于 ==：a & b == 0 是 a & (b==0)！
③ 实战建议：复杂表达式加括号（可读性 > 记优先级）
④ 面试点：x++ + ++x 类表达式（建议别写）
```

**Q5：自增 `i++` 和 `++i` 的区别？**

```text
① i++ 后置：先取值再自增（表达式值是旧值）
② ++i 前置：先自增再取值（表达式值是新值）
③ 面试题：int y = x++ + ++x（分步计算）
④ 建议：不要在表达式里混用 ++（可读性灾难）
⑤ 独立行使用无区别：i++; 与 ++i; 等价
```

### 1.2 字符串与转义类

**Q6：字符串里的 `\n` 和 `\\n` 区别？**

```text
① \n：换行符（一个字符）
② \\n：字面两个字符（\ 和 n）——想输出 "\n" 字样时用
③ Java 中 \ 不能单独出现（\d 编译错误）
④ 转义完整：\\ 表示一个反斜杠
⑤ 应用：Windows 路径 "C:\\data"（双写）
```

**Q7：正则里匹配反斜杠为什么要写 4 个？**

```text
① 双重转义：正则层转义 + 字符串层转义
② 正则匹配 \：正则写 \\ → Java 字符串再转义 → "\\\\"
③ Python 对比：r"\\"（原始字符串只需一层）
④ 优雅解法：字符类 [\\/]（同时匹配 \ 和 /）
⑤ 金句：一层正则转义 + 一层字符串转义 = 双重转义
```

**Q8：Java 注释里的 `\u000a` 有什么问题？**

```text
① \u 转义在 Java 的任何地方都生效（包括注释！）
② 注释里的 \u000a 被解析为换行 → 改变代码结构
③ 面试题：// \u000a System.out.println("执行了")——真的执行！
④ 预防：注释里不写 \u 序列
⑤ 其他语言无此问题（\u 只在字符串内）
```

### 1.3 符号语义类

**Q9：Java 中 `@`、`::`、`->`、`<>` 各代表什么？**

```text
① @：注解（@Override/@Autowired）——声明式编程
② ::：方法引用（System.out::println）——Lambda 简写
③ ->：Lambda 箭头（(x) -> x*2）——匿名函数
④ <>：菱形运算符（new ArrayList<>()）——泛型类型推断
⑤ 加分：Java 8+ 特性集中考察（Lambda/方法引用/流）
```

**Q10：`'a'` 和 `"a"` 的区别？**

```text
① 'a'：char（基本类型，2 字节）
② "a"：String（对象，有方法/长度）
③ 错误：'ab'（单引号多字符）→ 编译错误
④ char 运算：'a' + 1 = 'b'（ASCII 码运算）
⑤ 转换：String.valueOf('a') / "a".charAt(0)
```

**Q11：中文标点为什么会编译错误？**

```text
① 中文符号（（）“”；，）不是 Java 语法符号
② 报错：illegal character 或 unexpected token
③ 根因：输入法未切换（写代码用英文符号）
④ 全角字符（１２３）→ 类型不匹配
⑤ 排查：grep 中文标点；IDE 显示不可见字符
```

**Q12：`+` 在 Java 中有几种含义？**

```text
① 加法：1 + 2 = 3（数值）
② 字符串拼接："a" + "b" = "ab"（String 重载）
③ 拼接顺序：从左到右——"=" + 1 + 2 = "=12"（不是 "=3"！）
④ 一元正号：+5（少见）
⑤ 陷阱：1 + 2 + "=" = "3="（先加后拼）
```

### 1.4 综合类

**Q13：怎么快速定位编译错误？**

```text
① 只看第一个错误（后续是连锁反应）
② 报错字符反推：';' expected → 缺分号；'}' expected → 缺大括号
③ 检查最近修改的几行（80% 错误在那）
④ 中文符号检查（输入法事故高发）
⑤ IDE 辅助：Alt+Enter 快速修复/括号匹配高亮
```

**Q14：写代码时怎么避免符号类错误？**

```text
① 写代码切英文输入法（中文标点元凶）
② IDE 开启自动配对与错误提示
③ 复杂表达式加括号（防优先级错误）
④ 字符串比较用 equals（== 陷阱）
⑤ 从网页复制代码后检查不可见字符（NBSP）
⑥ 团队规范：Checkstyle/.editorconfig 强制符号规范
```

## 2. 代码题实战

**题 1：输出什么？**

```java
public static void main(String[] args) {
    int x = 5;
    int y = x++ + ++x;
    System.out.println(y);   // ?
    System.out.println(x);   // ?
}
// 答案：y = 12（5 + 7），x = 7
// 解析：x++ 值为 5（x→6）→ ++x 值为 7（x→7）→ 5+7=12
```

**题 2：输出什么？**

```java
String s = "abc";
String t = new String("abc");
System.out.println(s == t);        // ?  false（不同对象）
System.out.println(s.equals(t));   // ?  true（内容相同）
System.out.println(s == "abc");    // ?  true（常量池）
```

**题 3：下面哪行会编译错误？**

```java
char c1 = 'a';        // ✅
String s1 = "a";      // ✅
// char c2 = "a";     // ❌ String 不能赋给 char
// char c3 = 'ab';    // ❌ 单引号只能一个字符
String s2 = 'a' + ""; // ✅ 'a' 转字符串拼接
```

**题 4：输出什么？**

```java
int a = 10;
int b = 3;
System.out.println(a / b);       // 3（整数除法）
System.out.println(a % b);       // 1
System.out.println(1 + 2 + "="); // 3=
System.out.println("=" + 1 + 2); // =12
```

**题 5：找出错误**

```java
// 错误代码（含 3 处符号错误）
public class Test {
    public static void main(String[] args) {
        String s = "hello"      // ① 缺分号
        if (s = "hello") {      // ② = 应为 ==（且字符串用 equals）
            System.out.println（"ok"）;   // ③ 中文括号！
        }
    }
}
// 修复：加 ; 、== 改 equals、中文括号改英文
```

## 3. 终极速查表

| 符号 | 英文名 | Java 语义 | 易错点 |
|:---:|--------|---------|--------|
| `=` | Equal | 赋值 | 与 `==` 混用 |
| `==` | Equal Equal | 引用比较 | 字符串用 equals |
| `!=` | Bang Equal | 不等 | 与 `!` 混 |
| `&&` | Amp Amp | 短路与 | 与 `&` 混 |
| `\|\|` | Pipe Pipe | 短路或 | 与 `\|` 混 |
| `!` | Bang | 逻辑非 | 位置（!x） |
| `+` | Plus | 加法/拼接 | 拼接顺序 |
| `/` | Slash | 除法/注释 | 与 `\` 混 |
| `\` | Backslash | 转义 | 必须双写 `\\` |
| `%` | Percent | 取余 | 负数取余 |
| `? :` | Question Colon | 三元 | 嵌套可读性 |
| `()` | Parens | 调用/分组 | 与 `[]` 混 |
| `[]` | Brackets | 数组索引 | List 用 get() |
| `{}` | Braces | 代码块 | 缺 } 连锁报错 |
| `<>` | Angle | 泛型 | 与比较混 |
| `@` | At | 注解 | 拼写 |
| `::` | Double Colon | 方法引用 | Lambda 简写 |
| `->` | Arrow | Lambda | 捕获变量 |

| `'` `"` | Quotes | char/String | 'ab' 错误 |

## 4. 五大常见误区

| # | 误区 | 真相 |
|---|------|------|
| 1 | 「`==` 能比较字符串内容」 | 常量池碰巧 true——内容比较永远 equals |
| 2 | 「`&&` 和 `&` 差不多」 | && 短路（防 NPE）；& 不短路（副作用） |
| 3 | 「10/3 = 3.33」 | 整数除法截断 = 3；浮点参与才对 |
| 4 | 「反斜杠直接写就行」 | Java 中 `\` 不能单独出现（`\\` 双写） |
| 5 | 「报错看最后一个」 | 看第一个错误——后续是连锁反应 |
