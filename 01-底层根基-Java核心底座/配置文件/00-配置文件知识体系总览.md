# 00 - 配置文件知识体系总览

> 🎯 本系列共 **8 篇**，从格式语法到 Spring Boot 体系、从加载优先级到多环境管理、从 Nacos 配置中心到安全加密，覆盖配置文件全生命周期

## 4. 核心概念速查

| 概念 | 一句话解释 |
|------|-----------|
| **外部化配置** | 配置从代码中剥离，运行时可覆盖（环境变量/命令行/外部文件） |
| **配置优先级** | 后加载覆盖先加载：命令行 > JVM 参数 > 环境变量 > 配置中心 > 外部文件 > 包内 |
| **Profile** | 环境切换开关（dev/test/prod），`application-{profile}.yml` 分环境配置 |
| **@Value** | 注入单个配置值（`${key:默认值}`）——零散注入 |
| **@ConfigurationProperties** | 类型安全绑定配置对象（推荐）——支持嵌套/校验/松散绑定 |
| **配置中心** | 集中管理配置的服务（Nacos/Apollo）——动态刷新、环境隔离、审计 |
| **Namespace** | Nacos 命名空间：dev/test/prod 物理隔离 |
| **@RefreshScope** | 配置变更后无需重启生效的 Bean 作用域 |
| **ConfigMap/Secret** | K8s 配置注入（明文配置 / 敏感信息） |
| **宽松绑定** | `server.port` ↔ `SERVER_PORT`（环境变量自动映射） |

## 5. 配置优先级总表（核心速查）

```
高 ┌─────────────────────────────────────────────┐
   │ ① 命令行参数      --key=value               │
   │ ② JVM 系统属性    -Dkey=value               │
   │ ③ SPRING_APPLICATION_JSON 环境变量          │
   │ ④ JNDI 属性（传统外置部署）                  │
   │ ⑤ 操作系统环境变量（SERVER_PORT 宽松绑定）   │
   │ ⑥ Nacos 配置中心（远程）                    │
   │ ⑦ 外部 config/ 目录（jar 包外）             │
   │ ⑧ 外部当前目录（jar 包外）                  │
   │ ⑨ classpath:/config/（包内）               │
   │ ⑩ classpath:/application.yml（包内）        │
   │ ⑪ application-{profile}.yml（profile 覆盖） │
   │ ⑫ @PropertySource 自定义配置               │
   │ ⑬ bootstrap.yml（引导配置，最低）           │
   │ ⑭ @Value("${key:默认值}") 代码兜底          │
低 └─────────────────────────────────────────────┘
核心规则：优先级高者生效；Nacos 与本地是合并关系（同名 key 才覆盖）
```
