## 4. 核心概念速查

| 概念 | 一句话解释 | 详细位置 |
|------|-----------|---------|
| **VPN** | 在公共网络上建立加密的私有通信隧道 | [01-核心概念](./01-VPN核心概念与原理.md#1-vpn是什么) |
| **隧道 (Tunneling)** | 将原始数据包封装在另一个协议中传输 | [01-隧道技术](./01-VPN核心概念与原理.md#2-隧道技术) |
| **WireGuard** | 极简、高性能的现代VPN协议，仅4000行代码 | [02-WireGuard](./02-VPN协议详解.md#1-wireguard) |
| **OpenVPN** | 最成熟、兼容性最广的开源VPN方案 | [02-OpenVPN](./02-VPN协议详解.md#2-openvpn) |
| **IPsec** | 企业级VPN标准，操作系统原生支持 | [02-IPsec](./02-VPN协议详解.md#3-ipsecikev2) |
| **AES-256-GCM** | WireGuard 默认加密算法，同时提供加密和认证 | [01-加密体系](./01-VPN核心概念与原理.md#3-加密体系) |
| **Split Tunneling** | 只将指定流量路由到VPN，其余走本地网络 | [05-Split Tunneling](./05-VPN安全与排错.md#3-split-tunneling) |
| **Kill Switch** | VPN断开时自动切断网络，防止真实IP泄露 | [05-Kill Switch](./05-VPN安全与排错.md#2-kill-switch) |
| **DNS 泄露** | VPN连接后DNS查询仍走本地DNS服务器 | [05-DNS泄露](./05-VPN安全与排错.md#1-dns泄露) |
| **MTU** | 最大传输单元，VPN封装会减小有效MTU | [05-MTU问题](./05-VPN安全与排错.md#4-mtu-与性能问题) |
