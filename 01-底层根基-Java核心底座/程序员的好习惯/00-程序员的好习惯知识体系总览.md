## 4. 核心概念速查

| 概念 | 一句话解释 |
|------|-----------|
| **自动化铁律** | 重复两次以上的操作就自动化（终端别名/脚本） |
| **双终端原则** | 工作终端 + 探索终端，空间上切割专注与实验 |
| **两分钟原则** | 2 分钟内能处理完的小事立即处理，大事独立安排 |
| **15 分钟法则** | 不想干的活先承诺做 15 分钟；钻兔子洞先定 15 分钟倒计时 |
| **时间盒** | 为任务设明确起止时间，盒结束时评估状态决定续/停/调 |
| **深度工作** | 不被打断的专注时段——被打断后平均 15-20 分钟才能重新进入状态 |
| **断路器模式** | 晚 10 点后/周末自动"断开"工作，防过度消耗 |
| **技术翻译** | 把技术语言翻译成商业语言：「工期 + 影响」公式 |
| **拒绝公式** | 先说结论 + 诚实原因 + 替代方案 + 约定时间 |
| **单人晨会** | 每天开工 5 分钟写三行：昨天干完/今天盯死/潜在隐患 |

> 💡 **一句话总结**：程序员的好习惯 = **效率（把活干快）× 价值（把活干对）× 协作（让人信任）× 沉淀（让经验积累）× 边界（让状态可持续）**。2026 年的核心方法论：效率提升的本质不是塞进更多工作量，而是**消除工作流程中一切不必要的内部摩擦力**。
