## 1. 栈与单调栈

```java
// 单调栈：每日温度（找下一个更高温度要等几天）
public int[] dailyTemperatures(int[] temperatures) {
    int n = temperatures.length;
    int[] answer = new int[n];
    Deque<Integer> stack = new ArrayDeque<>();  // 存下标，栈内温度递减

    for (int i = 0; i < n; i++) {
        // 当前温度 > 栈顶温度 → 出栈（找到了栈顶的"下一个更高温度"）
        while (!stack.isEmpty() && temperatures[i] > temperatures[stack.peek()]) {
            int prevIndex = stack.pop();
            answer[prevIndex] = i - prevIndex;
        }
        stack.push(i);
    }
    return answer;  // 还在栈里的 = 没有更高温度 → answer 默认 0
}
```

```java
// 栈：有效括号判断
public boolean isValid(String s) {
    Deque<Character> stack = new ArrayDeque<>();
    Map<Character, Character> pairs = Map.of(')', '(', ']', '[', '}', '{');

    for (char c : s.toCharArray()) {
        if (pairs.containsKey(c)) {  // 右括号
            if (stack.isEmpty() || stack.pop() != pairs.get(c)) return false;
        } else {                     // 左括号
            stack.push(c);
        }
    }
    return stack.isEmpty();
}
```

## 2. 队列与优先队列

```java
// 优先队列：Top K 高频元素
public int[] topKFrequent(int[] nums, int k) {
    // 1. 统计频率
    Map<Integer, Integer> freq = new HashMap<>();
    for (int n : nums) freq.merge(n, 1, Integer::sum);

    // 2. 小顶堆（保留频率最高的 k 个）
    PriorityQueue<Integer> heap = new PriorityQueue<>(
        Comparator.comparingInt(freq::get)  // 按频率排序
    );

    for (int n : freq.keySet()) {
        heap.offer(n);
        if (heap.size() > k) heap.poll();  // 超过 k 就踢掉最小的
    }

    return heap.stream().mapToInt(Integer::intValue).toArray();
}
```

```java
// 双端队列：滑动窗口最大值
public int[] maxSlidingWindow(int[] nums, int k) {
    int n = nums.length;
    int[] result = new int[n - k + 1];
    Deque<Integer> deque = new ArrayDeque<>();  // 存下标，队列内值递减

    for (int i = 0; i < n; i++) {
        // 1. 移除窗口外的元素
        if (!deque.isEmpty() && deque.peekFirst() <= i - k) deque.pollFirst();
        // 2. 维护单调递减：移除所有比当前值小的
        while (!deque.isEmpty() && nums[deque.peekLast()] < nums[i]) deque.pollLast();
        deque.offerLast(i);
        // 3. 记录窗口最大值
        if (i >= k - 1) result[i - k + 1] = nums[deque.peekFirst()];
    }
    return result;
}
```

## 3. 哈希表技巧

```java
// HashMap 做计数（最常见的用法）
Map<Character, Integer> count = new HashMap<>();
for (char c : s.toCharArray()) {
    count.merge(c, 1, Integer::sum);  // Java 8+ 最简洁的计数方式
}

// 字母异位词分组
public List<List<String>> groupAnagrams(String[] strs) {
    Map<String, List<String>> map = new HashMap<>();
    for (String s : strs) {
        char[] chars = s.toCharArray();
        Arrays.sort(chars);
        String key = new String(chars);
        map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
    }
    return new ArrayList<>(map.values());
}
```

## 核心要点回顾

- 单调栈 = O(n) 找"下一个更大/更小元素"（每日温度/接雨水）
- 优先队列 = O(n log k) 解决 Top K（默认小顶堆）
- 双端队列 = O(n) 滑动窗口最大值
- HashMap 计数 = `merge(key, 1, Integer::sum)` 最简洁
- `ArrayDeque` 替代 `Stack` 和 `LinkedList`（更快）
