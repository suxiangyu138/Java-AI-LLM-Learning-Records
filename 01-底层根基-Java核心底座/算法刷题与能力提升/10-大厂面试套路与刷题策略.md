## 1. 大厂面试评分标准

```text
面试官评分表（隐性标准）：

1. 问题澄清（10%）
   → 问清楚输入/输出/约束/边界 case

2. 思路表达（25%）
   → 能不能讲清楚"为什么用这个算法"
   → 时间复杂度和空间复杂度分析

3. 代码实现（35%）
   → 代码风格、变量命名、边界处理
   → Bug-free?（有 bug 不等于挂，但多了肯定挂）

4. 测试与优化（20%）
   → 主动举例跑一遍代码
   → 主动提出优化方案

5. 沟通与合作（10%）
   → 卡住了会求助、接受提示、调整思路
```

```text
大厂难度对标：
  Google/Facebook: Medium-Hard 为主，重视沟通 + 优化
  Amazon/Microsoft: Easy-Medium 为主，重视代码质量 + Bug-free
  字节/阿里/腾讯: Medium 为主，重视基础 + 八股文 + 项目
  美团/快手/拼多多: Medium + 场景题，重视速度
```

## 2. 高效刷题策略

```text
三遍刷题法（每道题刷三遍，不是三道不同的题）：

第一遍（理解）：
  → 5 分钟想不出 → 看题解
  → 理解思路 → 不看答案自己写出来
  → 记录这道题的"核心 trick"

第二遍（隔天，巩固）：
  → 不看答案再写一遍
  → 这次 5 分钟内写出来 → 过了
  → 写不出来 → 标记"薄弱"，回头重点练

第三遍（一周后，复习）：
  → 快速回忆核心思路
  → 手写关键代码段
  → 用不同的测试用例跑一遍
```

```text
刷题优先级（时间有限时的顺序）：
  优先级 1: 数组/字符串/链表（出现频率最高）
  优先级 2: 树/哈希表/栈/队列
  优先级 3: DP/回溯/贪心
  优先级 4: 图/并查集/线段树（低频）

不要按题号刷！按**题型分类**刷！
  同一题型集中刷 5-10 题 → 形成肌肉记忆
```

## 3. 面试中的沟通技巧

```text
拿到题目的标准开场白（30 秒）：

"我先确认一下理解：
  - 输入是 XXX，输出是 YYY
  - 数据范围大约 ZZZ
  - 有没有重复元素？有没有负数？需不需要考虑空输入？

确认之后我想到一个初步方案：
  - 可以用 [算法] 解决，时间复杂度 O(X)，空间 O(Y)
  - 或者用 [算法2]，时间换空间
  - 我倾向于用第一个方案，您觉得这个方向可以吗？→ 得到反馈再开始写"

卡住时的标准话术：
  "我现在思路卡在 XXX，我尝试过 AAA 但发现 BBB 行不通。
   您方便给我一点提示吗？"
  （卡住 2-3 分钟就求提示 → 比硬撑 10 分钟最后放弃好得多）

写完代码后的标准收尾（30 秒）：
  "代码写完了，我举个例子跑一遍验证：
   输入 XXX → 第一步 ... → 最终结果 YYY ✓
   边界 case: 空输入 → 返回[] ✓
   复杂度: 时间 O(X), 空间 O(Y)
   如果要做优化，我想到 ..."
```

## 核心要点回顾

- 评分 = 沟通(10%) + 思路(25%) + 代码(35%) + 测试(20%) + 合作(10%)
- 三遍刷题法：理解 → 巩固(隔天) → 复习(一周)
- 按题型刷，不要按题号刷
- 卡住 2-3 分钟就求助（好过死撑 10 分钟）
- 写完代码必须主动跑测试用例
