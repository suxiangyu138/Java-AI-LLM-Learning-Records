## 1. 必写排序算法

```java
// 快速排序（必写！）
public void quickSort(int[] arr, int left, int right) {
    if (left >= right) return;
    int pivot = partition(arr, left, right);
    quickSort(arr, left, pivot - 1);
    quickSort(arr, pivot + 1, right);
}

private int partition(int[] arr, int left, int right) {
    int pivot = arr[right];              // 选最右为基准
    int i = left;                        // i 指向"小于区域"的末尾
    for (int j = left; j < right; j++) {
        if (arr[j] < pivot) {
            swap(arr, i, j);
            i++;
        }
    }
    swap(arr, i, right);                 // 基准放到正确位置
    return i;
}

// 归并排序（必写！）
public void mergeSort(int[] arr, int left, int right) {
    if (left >= right) return;
    int mid = left + (right - left) / 2;
    mergeSort(arr, left, mid);
    mergeSort(arr, mid + 1, right);
    merge(arr, left, mid, right);
}

private void merge(int[] arr, int left, int mid, int right) {
    int[] temp = new int[right - left + 1];
    int i = left, j = mid + 1, k = 0;
    while (i <= mid && j <= right) {
        temp[k++] = arr[i] <= arr[j] ? arr[i++] : arr[j++];
    }
    while (i <= mid) temp[k++] = arr[i++];
    while (j <= right) temp[k++] = arr[j++];
    System.arraycopy(temp, 0, arr, left, temp.length);
}
```

### 排序算法对比

| 算法 | 平均 | 最坏 | 空间 | 稳定 | 手写频率 |

## 2. 搜索算法

```java
// 二分查找找左边界（第一个 >= target 的位置）
public int lowerBound(int[] nums, int target) {
    int left = 0, right = nums.length;  // 右开区间
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] >= target) right = mid;
        else left = mid + 1;
    }
    return left;  // 左边界 = 第一个 >= target 的位置
}

// DFS 模板
public void dfs(参数) {
    if (终止条件) { 记录结果; return; }
    for (选择 in 可选择列表) {
        做选择;
        dfs(新参数);
        撤销选择;  // ← 回溯的精髓
    }
}
```

## 3. 排序思维解难题

```java
// 合并区间（先排序 → 再遍历）
public int[][] merge(int[][] intervals) {
    Arrays.sort(intervals, (a, b) -> a[0] - b[0]);  // 按起点排序
    List<int[]> merged = new ArrayList<>();

    for (int[] interval : intervals) {
        if (merged.isEmpty() || merged.get(merged.size()-1)[1] < interval[0]) {
            merged.add(interval);
        } else {
            merged.get(merged.size()-1)[1] =
                Math.max(merged.get(merged.size()-1)[1], interval[1]);
        }
    }
    return merged.toArray(new int[merged.size()][]);
}
```

## 核心要点回顾

- 快排 partition 模板：选 pivot → while 循环 → swap(i, right)
- 归并 merge 模板：temp 数组 → 双指针 → arraycopy
- 二分精髓：while(left < right) → mid 判断 → 收缩区间
- DFS 回溯 = 做选择 → 递归 → 撤销选择
- 排序思维 = 先排序让数据有序 → 再用简单逻辑处理
