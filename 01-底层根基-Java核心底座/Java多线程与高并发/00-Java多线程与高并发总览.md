## 4. 核心概念速查 {#4}

| 概念 | 一句话解释 | 模块 |
|------|-----------|:---:|
| **QPS** | 每秒查询数，衡量系统吞吐量的核心指标 | 01 |
| **TPS** | 每秒事务数，QPS 的业务等价物 | 01 |
| **令牌桶** | 固定速率生成令牌，请求需获取令牌才能通过 | 01 |
| **熔断** | 故障率超过阈值时自动切断请求，防止级联故障 | 01 |
| **削峰填谷** | 用 MQ 将瞬时高峰请求拉平为流式消费 | 01/04 |
| **无锁编程** | 用 CAS + 自旋替代互斥锁，适合低竞争场景 | 02 |
| **伪共享** | 多 CPU 缓存行竞争导致性能下降，@Contended 解决 | 02 |
| **虚拟线程** | JDK 21+ 轻量线程，百万级并发，IO 密集场景替代线程池 | 03 |
| **Pinning** | 虚拟线程被卡在载体线程上，synchronized + IO 是主因 | 03 |
| **Structured Concurrency** | 父子任务生命周期绑定，线程不泄漏 | 03 |
| **Scoped Values** | 不可变跨线程上下文，ThreadLocal 的虚拟线程友好替代 | 03 |
| **Lua 原子脚本** | Redis 端原子操作，秒杀防超卖核心 | 04 |
| **全链路压测** | 模拟真实流量，从网关到数据库端到端测试 | 04 |
| **影子表** | 压测数据写入专用表/库，与生产数据物理隔离 | 04 |
| **JFR** | Java Flight Recorder，低开销 JVM 事件记录器 | 05 |
| **Arthas** | 阿里开源 Java 在线诊断工具，不重启排查问题 | 05 |

## 5. 学习路线推荐 {#5}

### 🟢 初级路线：建立并发认知（2 周）

```
高并发核心指标 → 限流算法 → 线程池调优 → 虚拟线程入门
```

> 目标：理解高并发系统的基本概念，掌握线程池参数调优，能用虚拟线程写简单并发程序。

### 🟡 中级路线：实战能力建设（4 周）

```
秒杀系统设计 → 缓存策略 → 锁优化 → 结构化并发 → 熔断降级
```

> 目标：能独立设计秒杀等典型高并发场景的完整方案，理解各方案的适用边界。

### 🔴 高级路线：系统架构与排障（4 周）

```
全链路压测 → 线上问题排查 → 性能调优体系 → 架构演进 (Reactive → Virtual Threads)
```

> 目标：能主导高并发系统的架构设计、压测验证和线上应急，具备全链路排查能力。
