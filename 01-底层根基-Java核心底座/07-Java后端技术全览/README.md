## 一、阶段总览

### 1.1 阶段目标

将前六个阶段积累的 Java 知识、框架技能、数据库能力和工程实践，转化为：

| 目标领域 | 具体产出 | 衡量标准 |
|---------|---------|---------|
| **项目作品** | 2-3 个可展示的完整项目 | 代码可运行、有 README、已部署上线 |
| **面试能力** | 系统化的面试知识体系 | 能流畅回答 80% 的中高级面试问题 |
| **算法基础** | LeetCode 熟练度 | Hot 100 刷完 2 遍，周赛 3 题 |
| **简历竞争力** | 技术博客 + GitHub 主页 | 有项目链接，有技术文章，有活跃记录 |

### 1.2 阶段特点

- **并行执行**：本阶段与 Stage 5（SSM框架）和 Stage 6（分布式与微服务）**同步进行**。你不需要学完所有理论再动手，而是：
  - 学一个技术 → 立刻在项目中使用 → 验证理解 → 面试中能讲清楚
- **实战驱动**：每个项目的产出物比课程笔记更有价值
- **迭代循环**：简历 → 投递 → 面试 → 复盘 → 补漏 → 再投递

### 1.3 学习策略

```
传统学习路径：
  学习知识 → 全部学完 → 开始做项目 → 准备面试
                               ↓
                        知识已经遗忘大半

推荐并行路径：
  Stage 5 框架学习 ──→ 开始项目1（单体） ──→ 面试知识体系
       ↓                        ↓                    ↓
  Stage 6 分布式学习 ──→ 开始项目2（微服务） ──→ 刷算法题
                                ↓                    ↓
                          项目3（AI+）────→ 简历优化 → 投递面试
```

## 三、学习方法论

### 3.1 项目驱动学习

```
项目驱动学习循环：
┌─────────────────────────────────────────────────┐
│  1. 遇到需求 → 2. 搜索技术方案                    │
│       ↓                      ↓                   │
│  4. 代码实现 ← 3. 学习所需技术（仅够用即可）        │
│       ↓                                           │
│  5. 遇到 BUG/优化 → 返回 2（深入理解）              │
│       ↓                                           │
│  6. 总结记录 → 形成面试素材                          │
└─────────────────────────────────────────────────┘
```

**不要**：先学完 Spring Security 一整本书再开始做登录。
**要**：先搭项目框架，需要登录了，查 Spring Security 集成 JWT 的最佳实践，实现后再深入理解原理。

### 3.2 面试驱动学习

识别面试高频知识点，分配学习权重：

| 优先级 | 知识点 | 投入比例 |
|--------|--------|---------|
| P0（必问） | JVM、并发、集合、Spring、MySQL | 40% |
| P1（高频） | Redis、MQ、分布式、系统设计 | 30% |
| P2（加分） | AI 集成、云原生、性能优化 | 20% |
| P3（基础） | 网络、操作系统、设计模式 | 10% |

### 3.3 费曼学习法在面试准备中的应用

```
学习步骤：
1. 选择知识点（如：ConcurrentHashMap 原理）
2. 学习并理解（读源码 + 看文章）
3. 用大白话讲给自己听（录音或写下来）
4. 发现讲不清的地方 → 标注 → 重新学习
5. 直到能流畅讲给「不懂技术的人」听懂
```

## 六、常见问题与误区

### 6.1 常见误区

| 误区 | 真相 |
|------|------|
| "我要把所有知识学完再开始做项目" | 知识学不完，项目才是检验标准 |
| "项目要做得完美才敢放简历" | 60 分项目 + 已部署 > 90 分项目 + 本地 |
| "面试前突击刷题就行" | 面试知识需要时间沉淀，建议持续积累 |
| "系统设计是高级工程师才需要准备的" | 所有大厂面试都会考察系统设计思维 |
| "AI 跟 Java 没关系" | AI 集成已变成 Java 开发的差异化竞争力 |

### 6.2 常见问题

**Q: 我没做过真实项目，面试怎么讲？**
A: 自己做过的项目就是真实项目。关键是能讲清楚：
- 项目解决了什么问题
- 你做了什么、为什么这样做
- 遇到了什么困难、如何解决的
- 项目的亮点和技术挑战

**Q: 学历不好/非科班，有希望进大厂吗？**
A: 有。大厂更看重基础能力和学习潜力。通过项目展示你的能力，通过博客展示你的持续学习。很多非科班开发者通过优秀的项目和深入的技术博客拿到了大厂 offer。

**Q: 该选哪个方向做项目？**
A: 推荐先做博客/内容管理系统（简单），再做商城（有微服务复杂度），最后做 AI 应用（差异化）。三个方向展示了不同的能力，面试时可以按目标公司调整重点。

**Q: 如何平衡刷题和项目？**
A: 每天早上 1 道 LeetCode（保持手感），白天做项目，晚上总结面试知识。周末集中攻克章节难点。

## 十、心态调整

### 10.1 求职时期的心理建设

- **被拒是常态**：大厂简历通过率可能只有 5-10%，被拒绝不代表你不行
- **面试是双向的**：你也在评估公司是否适合你
- **持续迭代**：每次面试后总结经验，下次会更好
- **不要比较**：每个人的节奏不同，关注自己的进步

### 10.2 最后的话

> "找工作不是终点，而是职业发展的起点。Stage 7 教会你的不只是如何拿到 offer，更是如何成为一个持续成长的软件工程师。"
