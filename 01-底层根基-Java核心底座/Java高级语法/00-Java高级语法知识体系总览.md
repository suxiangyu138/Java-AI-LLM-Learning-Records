## 2. 版本速查

| 版本 | 核心特性 |
|------|------|
| Java 8 | Lambda, Stream, Optional, 方法引用 |
| Java 9 | 模块系统, 集合工厂方法 |
| Java 11 | var, HTTP Client |
| Java 14 | Record (预览), Switch 表达式 |
| Java 16 | Record 正式, instanceof 模式匹配 |
| Java 17 | **LTS**, 密封类, 文本块 |
| Java 19 | 虚拟线程 (预览) |
| Java 21 | **LTS**, 虚拟线程正式, Record Pattern, 字符串模板 |
