## 1. 文本块 Text Blocks

```java
// Java 8: SQL/JSON/HTML 是噩梦
String json = "{\n" +
    "  \"name\": \"Alice\",\n" +
    "  \"age\": 25,\n" +
    "  \"address\": {\n" +
    "    \"city\": \"Beijing\"\n" +
    "  }\n" +
    "}";

// Java 15+: 文本块（""" ... """）
String json = """
    {
      "name": "Alice",
      "age": 25,
      "address": {
        "city": "Beijing"
      }
    }
    """;

// 自动去除缩进（以闭合 """ 的位置为基准）
// 末尾 \ 取消换行
String sql = """
    SELECT id, name, email \
    FROM users \
    WHERE status = 'ACTIVE' \
    ORDER BY created_at DESC
    """;

// 结果: "SELECT id, name, email FROM users WHERE status = 'ACTIVE' ORDER BY created_at DESC"

// \s (space marker) 保留行尾空格
String line = """
    line1\s
    line2\s
    """;
```

## 2. 字符串模板 (Java 21)

```java
// Java 8: String.format 或 拼接
String msg = String.format("Hello %s, you have %d new messages", name, count);
String url = "https://api.example.com/users/" + userId + "/orders";

// Java 21: 字符串模板 STR
String msg = STR."Hello \{name}, you have \{count} new messages";
String url = STR."https://api.example.com/users/\{userId}/orders";

// 表达式中可以放任意 Java 代码
String report = STR."""
    Report for \{user.name()}
    ---------------------------
    Total Orders: \{orders.size()}
    Total Amount: $\{"%.2f".formatted(orders.stream().mapToDouble(Order::amount).sum())}
    Date: \{LocalDate.now()}
    """;

// 多行模板 + 文本块
String html = STR."""
    <html>
      <body>
        <h1>Welcome, \{user.name()}</h1>
        <p>You have \{user.unreadCount()} messages</p>
      </body>
    </html>
    """;
```

### 模板处理器

```java
// STR: 默认处理器（直接拼接字符串）
String s = STR."Hello \{name}";

// FMT: 格式化处理器（支持格式说明符）
String formatted = FMT."Price: $%.2f\{price}";  // Price: $99.99

// RAW: 返回原始模板（不处理）
StringTemplate st = RAW."Hello \{name}";
// st.fragments() = ["Hello ", ""]
// st.values() = [name]

// 自定义处理器（SQL 参数化、防注入）
String safeSQL = SQL."""
    SELECT * FROM users WHERE name = \{userName}
    """;
// 自动对 userName 做 SQL 转义，防止注入！
```

## 3. AI 开发实战

```java
// 1. Prompt 模板（AI 开发最高频场景）
public String buildPrompt(String task, String context, String format) {
    return STR."""
        You are an AI assistant specializing in Java development.

        Task: \{task}

        Context:
        \{context}

        Please respond in the following format:
        \{format}

        Important: Always provide complete, production-ready code.
        """;
}

// 2. JSON 响应（直接构造 JSON 字符串）
public String buildResponse(List<Product> products) {
    var items = products.stream()
        .map(p -> STR."""
            {"name": "\{p.name()}", "price": \{p.price()}}""")
        .collect(joining(",\n  "));

    return STR."""
        {
          "total": \{products.size()},
          "products": [
            \{items}
          ]
        }
        """;
}
```

## 核心要点回顾

- 文本块 `"""..."""`= 多行字符串，自动处理缩进
- `\` 取消换行，`\s` 保留空格
- 字符串模板 `STR."...\{expr}"` = 优雅的字符串插值
- `FMT` 支持格式说明符，`RAW` 返回未处理模板
- Prompt 模板 + JSON 响应 → 文本块 + 字符串模板 = 完美组合
