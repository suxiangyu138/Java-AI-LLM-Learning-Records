## 1. 纯文本类

| 后缀 | 全称 | 编码 | 打开方式 | 说明 |
|:----:|------|------|---------|------|
| **.txt** | Text File | UTF-8/GBK/ANSI | 任意文本编辑器 | 纯文本，无格式 |
| **.log** | Log File | UTF-8/ASCII | 文本编辑器 | 程序运行日志 |
| **.md** | Markdown | UTF-8 | VS Code/Typora/Obsidian | 轻量标记语言，转 HTML/PDF |
| **.csv** | Comma-Separated Values | UTF-8 | Excel/文本编辑器 | 表格数据，逗号分隔 |
| **.tsv** | Tab-Separated Values | UTF-8 | Excel/文本编辑器 | 表格数据，Tab 分隔 |
| **.sql** | SQL Script | UTF-8 | DataGrip/Navicat | SQL 脚本（建表/查询） |
| **.sh** | Shell Script | UTF-8 | bash/zsh | Linux/macOS 脚本 |
| **.bat** | Batch File | ASCII/GBK | cmd.exe | Windows 批处理 |
| **.ps1** | PowerShell Script | UTF-8 | PowerShell | Windows 自动化脚本 |

### 关键区分：换行符与编码

```text
换行符差异：
  Windows：  \r\n (CRLF)
  Linux/macOS： \n (LF)
  Old Mac：   \r (CR)

  → Git 中设置 core.autocrlf 自动转换
  → IDE 右下角可查看/切换换行符

编码差异：
  UTF-8   → 国际通用，Web 标准
  UTF-8 BOM → Windows 记事本默认（带 BOM 头，程序可能报错！）
  GBK     → 中文 Windows 默认（中文占用 2 字节）
  ANSI    → Windows 系统默认编码（中文系统 = GBK）
  ASCII   → 纯英文，128 字符

常见坑：
  ⚠️ Windows 记事本保存的 UTF-8 带 BOM → Java/Node.js 读取多出 3 字节
  ⚠️ Linux 上编辑的 .sh → 上传到 Windows → 换行符变 CRLF → 执行报错
```

## 2. 标记语言类

| 后缀 | 语言 | 用途 | 转目标 |
|:----:|------|------|:----:|
| **.md** | Markdown | 文档、README、Wiki | HTML, PDF |
| **.html / .htm** | HyperText Markup Language | 网页结构 | 浏览器直接渲染 |
| **.xml** | eXtensible Markup Language | 配置、数据交换 | 被程序解析 |
| **.xhtml** | XML + HTML | 严格版 HTML | 浏览器 |
| **.tex** | LaTeX | 学术论文排版 | PDF, DVI |
| **.rst** | reStructuredText | Python 文档 | HTML, PDF |
| **.adoc** | AsciiDoc | 技术文档 | HTML, PDF, DocBook |

```xml
<!-- xml 的关键特点：标签可自定义，严格闭合 -->
<?xml version="1.0" encoding="UTF-8"?>
<users>
    <user id="1">
        <name>Alice</name>
        <email>alice@example.com</email>
    </user>
</users>

<!-- 对比 html：标签是预定义的 -->
<!DOCTYPE html>
<html>
<head><title>Page</title></head>
<body><h1>Hello</h1></body>
</html>
```

## 3. 数据交换类

| 后缀 | 格式 | 可读性 | 用途 | 对比 |
|:----:|------|:----:|------|------|
| **.json** | JavaScript Object Notation | ✅ 好 | Web API、配置文件 | 最通用，体积小 |
| **.yaml / .yml** | YAML Ain't Markup Language | ✅ 极好 | 配置文件（K8s/Docker Compose） | 比 JSON 更可读 |
| **.xml** | XML | ⚠️ 冗长 | 旧系统、SOAP、Maven POM | 标签冗余，渐被替代 |
| **.csv** | CSV | ✅ 好 | 数据导出/导入/Excel | 表格数据最简单格式 |
| **.toml** | Tom's Obvious Minimal Language | ✅ 极好 | Rust/Cargo, Python 项目 | 简洁，适合配置 |
| **.proto** | Protocol Buffers | ❌ 不可读 | gRPC 接口定义 | 需编译为代码 |

```yaml
# YAML 示例（K8s Deployment）
apiVersion: apps/v1
kind: Deployment
metadata:
  name: user-service
spec:
  replicas: 3
  template:
    spec:
      containers:
      - name: app
        image: user-service:1.0
```

```toml
# TOML 示例（Cargo.toml）
[package]
name = "my-app"
version = "0.1.0"

[dependencies]
serde = "1.0"
tokio = { version = "1", features = ["full"] }
```

## 4. 电子文档类

| 后缀 | 类型 | 打开方式 | 特点 |
|:----:|------|---------|------|
| **.pdf** | Portable Document Format | Adobe Reader/浏览器 | 跨平台、不可编辑 |
| **.docx** | Word 文档 | Microsoft Word/WPS | Office Open XML |
| **.xlsx** | Excel 表格 | Microsoft Excel/WPS | 电子表格 |
| **.pptx** | PowerPoint 演示 | Microsoft PPT/WPS | 演示文稿 |
| **.odt** | Open Document Text | LibreOffice | 开源文档格式 |
| **.epub** | Electronic Publication | 电子书阅读器 | 可重排电子书 |
| **.mobi** | Mobipocket | Kindle | Kindle 电子书 |

```text
.docx / .xlsx / .pptx 的真实结构：
  → 本质是 ZIP 压缩包！
  → 改后缀为 .zip → 解压 → 看到 XML 文件
  → word/document.xml → 文档内容
  → xl/worksheets/sheet1.xml → 表格内容

  这就是 Java 中可以用 POI 库操作 Office 文件的原因
```

## 5. 打开与转换工具速查

| 需求 | 工具/命令 |
|------|---------|
| Markdown → HTML | `pandoc input.md -o output.html` |
| Markdown → PDF | `pandoc input.md --pdf-engine=xelatex -o output.pdf` |
| JSON 格式化 | `cat file.json \| python -m json.tool` 或 jq |
| XML 格式化 | `xmllint --format file.xml` |
| CSV 查看 | `column -s, -t file.csv` (Linux) |
| 文件编码转换 | `iconv -f GBK -t UTF-8 file.txt` |
| 换行符转换 | `dos2unix file.txt` / `unix2dos file.txt` |
| 大文件查看 | `less file.log` (Linux) / Large Text File Viewer (Win) |

> 🎯 **核心要点**：文本文件核心区分点 —— **编码（UTF-8/GBK）+ 换行符（LF/CRLF）+ 格式（纯文本/标记/结构化）**。跨平台开发时这三个最容易出问题。
