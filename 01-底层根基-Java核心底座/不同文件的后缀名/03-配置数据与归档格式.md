## 1. 配置文件格式

### 1.1 格式对比

| 后缀 | 格式 | 支持层级 | 注释 | Java 生态使用 |
|:----:|------|:------:|:--:|------|
| **.yml / .yaml** | YAML | ✅ 多级 | ✅ `#` | Spring Boot, Docker Compose, K8s |
| **.properties** | key=value | ❌ 扁平 | ✅ `#` | Spring Boot, Java 传统配置 |
| **.toml** | TOML | ✅ 多级 | ✅ `#` | Rust, Python 项目 |
| **.ini** | INI | ✅ Section | ✅ `;` 或 `#` | Windows, PHP |
| **.env** | key=value | ❌ 扁平 | ✅ `#` | Docker, Node.js, 环境变量 |
| **.xml** | XML | ✅ 多级 | ✅ `<!-- -->` | Maven pom.xml, Spring 旧配置 |
| **.json** | JSON | ✅ 多级 | ❌ 不支持！ | 现代配置趋势 |
| **.conf** | 多种 | 视情况 | 视情况 | Nginx, Apache, Logstash |

### 1.2 实战对比

```yaml
# application.yml（Spring Boot）—— 层级清晰
server:
  port: 8080
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/mydb
    username: root
  redis:
    host: localhost
    port: 6379
```

```properties
# application.properties —— 扁平、冗长
server.port=8080
spring.datasource.url=jdbc:mysql://localhost:3306/mydb
spring.datasource.username=root
spring.redis.host=localhost
spring.redis.port=6379
```

```ini
# config.ini —— 传统 Section 风格
[database]
host=localhost
port=3306
name=mydb

[redis]
host=localhost
port=6379
```

### 1.3 Spring Boot 配置加载优先级

```text
Spring Boot 配置优先级（从高到低）：

 1. 命令行参数：          --server.port=9090
 2. 环境变量：            SERVER_PORT=9090
 3. application-{profile}.yml / .properties   ← 环境特定
 4. application.yml / .properties             ← 默认配置
 5. @PropertySource 导入的配置

yml vs properties 选择：
  ✅ yml  → 层级数据、复杂配置、K8s/Docker
  ✅ properties → 简单应用、团队习惯
  ➡ 两者可共存，properties 优先级更高
```

## 2. 数据库与数据文件

### 2.1 数据库文件

| 后缀 | 说明 | 关联 |
|:----:|------|------|
| **.sql** | SQL 脚本（DDL/DML/DQL） | MySQL/PostgreSQL 等通用 |
| **.db** | 通用数据库文件 | SQLite 最常用 |
| **.sqlite / .sqlite3** | SQLite 数据库文件 | 嵌入式数据库 |
| **.mdb / .accdb** | Microsoft Access 数据库 | MS Office |
| **.frm / .ibd** | MySQL 表结构/数据文件 | MySQL 数据目录 |
| **.dmp** | 数据库转储文件 | Oracle/MySQL dump |
| **.bak** | 数据库备份文件 | SQL Server/通用 |
| **.mdf / .ldf** | SQL Server 数据/日志 | SQL Server |

### 2.2 数据交换文件

| 后缀 | 说明 | 打开方式 |
|:----:|------|---------|
| **.csv** | 逗号分隔值 | Excel, Pandas, 文本编辑器 |
| **.tsv** | Tab 分隔值 | Excel, Pandas |
| **.json** | JSON 数据 | 文本编辑器, jq |
| **.jsonl** | JSON Lines（每行一个 JSON） | 适合流式处理 |
| **.xml** | XML 数据 | 浏览器, 文本编辑器 |
| **.parquet** | 列式存储（Hadoop 生态） | PyArrow, Spark |
| **.orc** | 列式存储（Hive 优化） | Spark, Hive |
| **.avro** | 行式存储（序列化） | Kafka, Hadoop |
| **.pkl / .pickle** | Python 序列化 | Python pickle 模块 |

### 2.3 JSON vs JSONL

```text
JSON（标准格式）：
  [ {"id":1, "name":"Alice"}, {"id":2, "name":"Bob"} ]
  → 必须读完整文件才能解析
  → 适合 API 响应

JSONL（每行一个 JSON）：
  {"id":1, "name":"Alice"}
  {"id":2, "name":"Bob"}
  → 可以逐行流式处理
  → 适合日志、大数据场景
  → 追加数据不需重写整个文件
```

## 3. 压缩与归档格式

### 3.1 格式对比

| 后缀 | 类型 | 压缩率 | 速度 | 跨平台 | Java 支持 |
|:----:|:--:|:----:|:--:|:----:|:-------:|
| **.zip** | 归档+压缩 | 中 | 快 | ✅ | java.util.zip |
| **.tar** | 纯归档 | 无 | 快 | ✅ | Apache Commons Compress |
| **.tar.gz / .tgz** | 归档+压缩 | 高 | 中 | ✅ | Gzip + Tar |
| **.tar.bz2 / .tbz2** | 归档+压缩 | 更高 | 慢 | ✅ | Bzip2 + Tar |
| **.tar.xz** | 归档+压缩 | 最高 | 最慢 | ✅ | XZ + Tar |
| **.7z** | 压缩 | 极高 | 慢 | 需工具 | SevenZip 库 |
| **.rar** | 压缩 | 高 | 中 | 需 WinRAR | junrar 库 |
| **.gz / .gzip** | 纯压缩 | 中 | 中 | ✅ | java.util.zip.GZIP |
| **.bz2** | 纯压缩 | 高 | 慢 | ✅ | Apache Bzip2 |
| **.xz** | 纯压缩 | 极高 | 慢 | ✅ | XZ for Java |
| **.jar / .war** | ZIP 变体 | 中 | 快 | ✅ | jar 命令 |

### 3.2 tar 组合拳

```bash
# .tar 只是把文件"拼"在一起，不压缩
tar -cvf archive.tar ./mydir       # 创建
tar -xvf archive.tar               # 解包

# .tar.gz = tar + gzip 压缩（Linux 最常见）
tar -czvf archive.tar.gz ./mydir   # 创建
tar -xzvf archive.tar.gz           # 解压

# .tar.xz = tar + xz 压缩（最小体积）
tar -cJvf archive.tar.xz ./mydir   # 创建
tar -xJvf archive.tar.xz           # 解压

# 速记：c=create, x=extract, z=gzip, J=xz, v=verbose, f=file
```

### 3.3 Java 中处理压缩文件

```java
// 解压 ZIP
try (ZipInputStream zis = new ZipInputStream(new FileInputStream("file.zip"))) {
    ZipEntry entry;
    while ((entry = zis.getNextEntry()) != null) {
        if (!entry.isDirectory()) {
            // 处理 entry.getName()
            byte[] content = zis.readAllBytes();
        }
        zis.closeEntry();
    }
}

// GZIP 解压
try (GZIPInputStream gzis = new GZIPInputStream(new FileInputStream("file.gz"))) {
    String content = new String(gzis.readAllBytes(), StandardCharsets.UTF_8);
}
```

## 4. 序列化与缓存文件

| 后缀 | 说明 |
|:----:|------|
| **.ser** | Java 序列化对象 |
| **.proto** | Protobuf 接口定义（编译为代码） |
| **.pb** | Protobuf 二进制数据 |
| **.thrift** | Apache Thrift 接口定义 |
| **.avsc** | Avro Schema 定义 |
| **.msgpack** | MessagePack 二进制数据 |
| **.pkl** | Python Pickle 序列化 |
| **.cache** | 通用缓存文件 |
| **.tmp / .temp** | 临时文件 |

> ⚠️ **Java 序列化(.ser)已过时！** 推荐用 JSON/Protobuf/MessagePack 替代。Java 原生序列化有安全漏洞 + 跨版本不兼容。
