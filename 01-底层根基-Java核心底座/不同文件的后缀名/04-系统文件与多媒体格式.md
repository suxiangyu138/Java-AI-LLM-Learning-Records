## 1. 可执行文件与系统库

### 1.1 跨平台对比

| 平台 | 可执行文件 | 动态库 | 静态库 | 目标文件 |
|------|:-------:|:-----:|:-----:|:------:|
| **Windows** | `.exe` | `.dll` | `.lib` | `.obj` |
| **Linux** | 无后缀(ELF) | `.so` | `.a` | `.o` |
| **macOS** | 无后缀(Mach-O) / `.app` | `.dylib` | `.a` | `.o` |
| **Android** | `.apk` / `.aab` | `.so` | `.a` | - |
| **iOS** | `.ipa` | `.dylib` / `.framework` | `.a` | - |

```text
Linux 可执行文件为什么没有后缀？
  → Linux 通过文件权限判断是否可执行（x 位），不依赖后缀名
  → file 命令查看文件类型：
    $ file /usr/bin/java
    /usr/bin/java: ELF 64-bit LSB executable, x86-64

Windows 可执行文件：
  .exe  → 直接执行
  .msi  → Windows Installer 安装包
  .com  → 旧式 DOS 可执行文件
  .bat  → 批处理脚本
  .cmd  → NT 批处理
  .ps1  → PowerShell 脚本
  .vbs  → VBScript 脚本
```

### 1.2 系统相关文件

| 后缀 | 说明 | 平台 |
|:----:|------|:--:|
| `.sys` | Windows 系统驱动 | Windows |
| `.ko` | Linux 内核模块 | Linux |
| `.reg` | 注册表文件 | Windows |
| `.plist` | 属性列表（XML） | macOS/iOS |
| `.service` | systemd 服务单元 | Linux |
| `.cpl` | 控制面板扩展 | Windows |
| `.crash` / `.dmp` | 崩溃转储文件 | 通用 |

| 后缀 | 说明 | 平台 |
|:----:|------|:--:|

```bash
sudo rpm -ivh package.rpm    # 安装 .rpm
sudo snap install package    # 安装 snap

# 查看 .apk 内容（本质是 ZIP）
unzip -l app.apk
```

## 3. 图片格式

### 3.1 像素图 vs 矢量图

| 后缀 | 类型 | 压缩 | 透明 | 动图 | 典型用途 |
|:----:|:---:|:--:|:--:|:--:|------|
| **.jpg / .jpeg** | 像素 | 有损 | ❌ | ❌ | 照片、Web 图片 |
| **.png** | 像素 | 无损 | ✅ | ❌ (APNG 可) | UI 截图、图标 |
| **.gif** | 像素 | 无损 | ✅ | ✅ | 简单动图、表情 |
| **.webp** | 像素 | 有损+无损 | ✅ | ✅ | 现代 Web 图片 ★ |
| **.avif** | 像素 | 有损+无损 | ✅ | ✅ | 新一代 Web 图片 |
| **.bmp** | 像素 | 无 | ❌ | ❌ | Windows 位图 |
| **.svg** | 矢量 | 可压缩 | ✅ | ✅ | 图标、Logo ★ |
| **.eps** | 矢量 | - | ✅ | ❌ | 印刷、排版 |
| **.ico** | 像素 | - | ✅ | ❌ | 网站 favicon |
| **.tiff / .tif** | 像素 | 无损/有损 | ✅ | ❌ | 扫描、印刷 |
| **.raw** | 像素 | 无 | ❌ | ❌ | 相机原始数据 |

```text
JPEG vs PNG vs WebP 选择：
  JPEG  → 照片（渐变色多，200KB→50KB 肉眼不可见差异）
  PNG   → 截图/UI（大面积纯色 + 需透明）
  WebP  → 现代 Web（JPEG 质量 + PNG 透明 + 体积更小）
  SVG   → 图标/Logo（任意放大不失真）

Java 处理图片：
  ImageIO.read() → JPEG/PNG/BMP/GIF
  TwelveMonkeys 库 → WebP/TIFF 等更多格式
```

### 3.2 矢量图详解

```xml
<!-- SVG 本质是 XML 文本！ -->
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 100 100">
  <circle cx="50" cy="50" r="40" fill="red" />
  <rect x="20" y="20" width="60" height="60" fill="blue" opacity="0.5" />
</svg>

<!-- 优势：任意缩放不失真；CSS/JS 可直接操控；文件体积极小 -->
```

## 4. 音频与视频格式

### 4.1 音频

| 后缀 | 压缩 | 质量 | 典型用途 |
|:----:|:---:|:--:|------|
| **.mp3** | 有损 | 中高 | 流媒体、音乐 |
| **.aac** | 有损 | 高 | YouTube, iPhone |
| **.ogg** | 有损 | 高 | 开源替代 MP3 |
| **.flac** | 无损 | 极高 | 音乐发烧友、归档 |
| **.wav** | 无 | 极高 | 录音、音频编辑 |
| **.m4a** | AAC/ALAC | 高 | Apple Music |
| **.opus** | 有损 | 高 | VoIP、游戏语音 |

### 4.2 视频

| 后缀 | 容器 | 视频编码 | 音频编码 | 典型用途 |
|:----:|:--:|:-------:|:-------:|------|
| **.mp4** | MP4 | H.264/H.265 | AAC | 通用 Web 视频 ★ |
| **.mkv** | Matroska | 任意 | 任意 | 高清电影、字幕 |
| **.webm** | WebM | VP8/VP9/AV1 | Vorbis/Opus | Web 视频 |
| **.avi** | AVI | 任意 | 任意 | 旧格式（已过时） |
| **.mov** | QuickTime | H.264/ProRes | AAC | Apple 生态 |
| **.flv** | Flash Video | H.264 | AAC/MP3 | 直播流（渐被淘汰） |

```text
容器 vs 编码：
  容器 = 盒子（.mp4, .mkv） → 装视频轨+音频轨+字幕轨
  编码 = 压缩算法（H.264, H.265, VP9）→ 决定了质量和大小
  → .mp4 文件里的视频可能用 H.264 也可能是 H.265

H.264 vs H.265/HEVC vs AV1：
  H.264  → 2003，兼容性最好
  H.265  → 2013，比 H.264 体积减少 50%
  AV1    → 2018，开源，比 H.265 再减 30%
```

## 5. 字体与证书文件

| 后缀 | 说明 |
|:----:|------|
| **.ttf** | TrueType 字体（通用） |
| **.otf** | OpenType 字体 |
| **.woff** | Web Open Font Format |
| **.woff2** | WOFF 2.0（压缩率更高） |
| **.pem** | PEM 编码证书/密钥 |
| **.crt / .cer** | 证书文件 |
| **.key** | 私钥文件 |
| **.p12 / .pfx** | PKCS#12 证书+密钥打包 |
| **.csr** | 证书签名请求 |
| **.jks / .keystore** | Java Keystore（密钥库） |
| **.pem** | Privacy Enhanced Mail（Base64 编码证书） |

```bash
# 证书格式转换
# PEM → DER
openssl x509 -in cert.pem -outform der -out cert.der

# PKCS12 → JKS
keytool -importkeystore \
  -srckeystore cert.p12 -srcstoretype PKCS12 \
  -destkeystore cert.jks -deststoretype JKS

# 查看证书内容
openssl x509 -in cert.pem -text -noout
```
