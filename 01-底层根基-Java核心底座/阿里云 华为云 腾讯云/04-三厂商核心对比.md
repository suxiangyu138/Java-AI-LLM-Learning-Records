## 1. 云服务器对比

### 1.1 基础对比

| 维度 | 阿里云 ECS | 华为云 ECS | 腾讯云 CVM |
|------|:---:|:---:|:---:|
| 实例族 | 最丰富（g/c/r/d/h/gn） | 丰富（鲲鹏/x86/昇腾） | 丰富（s/c/m/gpu） |
| 自研芯片 | 倚天 710（ARM） | **鲲鹏（ARM）+ 昇腾（AI）** | 无（依赖 Intel/AMD） |
| 轻量产品 | 轻量应用服务器 | 无突出 | **Lighthouse（性价比之王）** |
| 抢占式实例 | ✅ | ✅ | ✅ |
| 计费模式 | 包年/按量/抢占/节省计划 | 包年/按量/竞价/专属 | 包年/按量/竞价/预留 |
| 稳定性（2025） | 无跨 AZ 严重事故 | 无跨 AZ 严重事故 | 曾发生存储单园区故障 |

### 1.2 选型要点

```text
云服务器选型要点
├── ① 个人项目：腾讯 Lighthouse（最便宜）
├── ② 中小服务：阿里 ECS / 腾讯 CVM（生态好）
├── ③ 信创要求：华为鲲鹏实例（唯一）
├── ④ AI 训练：阿里 GPU 现货 / 华为昇腾
├── ⑤ 成本敏感：抢占式实例（实验）+ 包年（生产）
└── ⑥ 2026 价格：CPU 稳定微降、GPU 高位（芯片紧张）
```

## 3. 自研技术栈对比

| 维度 | 阿里云 | 华为云 | 腾讯云 |
|------|:---:|:---:|:---:|
| 云操作系统 | 飞天 | 自研 | 自研 |
| CPU 芯片 | **倚天 710（ARM）** | **鲲鹏（ARM）** | 无 |
| AI 芯片 | 无（用 NVIDIA） | **昇腾（910B 可替代 A100）** | 无 |
| 虚拟化 | 神龙 | 自研 | 自研 |
| 数据库自研 | **PolarDB** | **GaussDB** | **TDSQL** |
| 大模型自研 | **通义千问（开源）** | **盘古（工业）** | **混元（多模态）** |
| 信创能力 | 部分 | **全栈最强** | 弱 |

```text
自研技术栈的意义
├── ① 阿里：倚天降本（RDS 等托管深度集成）+ 开源 Qwen 生态
├── ② 华为：全栈信创（芯片→平台→应用）——政企壁垒
├── ③ 腾讯：无芯片（依赖第三方）——但软件生态强
└── 选型影响：
    ├── 信创合规 → 华为（唯一全栈）
    ├── 成本优化 → 阿里倚天实例
    └── 快速开发 → 腾讯（不关心底层）
```

## 4. 数据库与中间件对比

| 维度 | 阿里云 | 华为云 | 腾讯云 |
|------|:---:|:---:|:---:|
| 云原生数据库 | **PolarDB** | Taurus | TDSQL-C |
| 分布式数据库 | PolarDB-X | **GaussDB** | **TDSQL** |
| 托管 MySQL | RDS | RDS | 云数据库 MySQL |
| Redis | **Tair** | GeminiDB | 云 Redis |
| 消息队列 | RocketMQ/Kafka 托管 | DMS | CMQ/CKafka |
| 认证背书 | TPC-C/TPC-H | TPC-C | **TPC-C/TPC-H** |

```text
数据库选型（Java 后端）
├── 常规业务 → 三家 RDS MySQL（差异不大）
├── 高并发核心 → PolarDB（阿里）/TDSQL（腾讯）/GaussDB（华为）
├── 信创替代 Oracle → GaussDB（华为唯一）
├── 缓存 → Tair/GeminiDB/云 Redis（均兼容 Redis）
└── 金句：常规选托管、核心选自研、信创选华为
```

## 5. 大模型平台对比

| 维度 | 阿里百炼 | 华为 ModelArts | 腾讯 TI |
|------|:---:|:---:|:---:|
| 定位 | 模型超市 + MaaS | 训练/部署平台 | 智能体平台 |
| 大模型 | Qwen3.5 系列（开源） | 盘古 2.0（工业） | 混元 + VITA 3.0 |
| 多模态 | Qwen-Omni（视频 50 分钟） | 工业视觉强 | **VITA 3.0（原生多模态）** |
| 价格 | 梯度（Turbo 到 Max） | 订阅制 | **VITA 约竞品 50%** |
| 私有化 | 支持 | **最强（数据不出域）** | 支持 |
| 生态 | **最丰富（开源 Qwen）** | MindSpore（昇腾） | 微信生态 |
| 上手难度 | 低 | 高（专业团队） | 中 |
| 适用 | 通用 AI 应用 | 政企私有化/工业 | C 端智能体 |

```text
大模型平台选型（2026）
├── 通用 AI 应用/快速接入 → 阿里百炼
├── 政企私有化（数据不出域）→ 华为 ModelArts
├── C 端智能体（微信生态）→ 腾讯 TI
├── 工业垂直（图纸/设备）→ 盘古
├── 多模态性价比 → VITA 3.0
└── 金句：AI 平台选型 = 场景（通用/政企/C 端）× 价格（VITA 优势）
```

## 7. 选型决策矩阵

```text
选型决策树
开始
 ├─ 有信创/合规要求？（政务/金融/国企）
 │   └─ 是 → 华为云（鲲鹏 + GaussDB + ModelArts）
 │
 ├─ 依赖微信生态？（小程序/C 端）
 │   └─ 是 → 腾讯云（微信 + TI 智能体）
 │
 ├─ 音视频/游戏业务？
 │   └─ 是 → 腾讯云（TRTC + 游戏盾）
 │
 ├─ 工业 AI（图纸/设备）？
 │   └─ 是 → 华为云（盘古 + 昇腾）
 │
 ├─ AI 应用（通用/RAG/Agent）？
 │   └─ 是 → 阿里云（百炼 + 开源 Qwen）
 │
 ├─ 个人项目/低成本起步？
 │   └─ 是 → 腾讯云（Lighthouse）
 │
 └─ 默认（通用 Java 后端/电商/互联网）
     └─ 阿里云（均衡无短板）
```

## 8. 2026 价格环境

### 8.1 价格变化（重要背景）

```text
2026 价格环境剧变
├── ① 2025.4：阿里率先价格战（最高降幅 60%）
├── ② 2026.3：集体涨价（10 天内相继调价）
│   ├── AI 算力/存储涨幅 30-50%
│   ├── 腾讯云部分核心产品涨幅达 400%
│   └── 背景：Token 日调用量 140 万亿（千倍增长）
├── ③ Token 单价变化：
│   ├── 过去两年：50-100 元 → 几元/百万（降幅 99%）
│   └── 但规模增长远超降价速度
└── ④ 结论：告别「低价圈地」——进入商业化定价阶段
```

### 8.2 成本策略（2026）

```text
2026 成本优化策略
├── ① 长期合约锁定：涨价潮下包年/承诺消费更值
├── ② 模型分级：轻量任务用 Turbo/VITA（成本差数倍）
├── ③ 缓存命中：合理缓存可省 60%+（Token 成本大头）
├── ④ 计费理解：输入/输出比例 1:2 或更高
├── ⑤ 警惕隐性成本：跨地域带宽（CEN）/向量库读写
└── ⑥ 金句：2026 选型 = 场景 × 价格 × 全链路成本（不再单比单价）
```

## 9. 核心要点

> 🎯 **核心要点**：
> 1. 三家定位：阿里（全能均衡 36%）/华为（政企信创 16%）/腾讯（社交生态 9%）
> 2. 自研对比：阿里倚天 + 开源 Qwen / 华为鲲鹏昇腾全栈信创 / 腾讯软件生态（无芯片）
> 3. 数据库：常规选托管、核心选自研（PolarDB/TDSQL/GaussDB）、信创选华为
> 4. AI 平台：百炼（通用）/ModelArts（政企私有化）/TI（C 端智能体）——VITA 价格优势
> 5. 选型决策树：信创 → 华为；微信 → 腾讯；默认 → 阿里
> 6. **2026 价格剧变**：价格战结束集体涨价——长期合约 + 模型分级 + 缓存命中是成本关键
