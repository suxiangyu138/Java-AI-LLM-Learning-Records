## 1. 场景决策树

```text
你的项目是什么类型？

├── 电商/金融/中大型企业 → 阿里云
├── Java 微服务 → 阿里云（Spring Cloud Alibaba 原生）
├── 初创公司/个人 → 腾讯云（Lighthouse + 免费试用）
├── 游戏/直播/音视频 → 腾讯云（TRTC + 40% 份额）
├── 政务/国企/信创 → 华为云（资质最全）
├── AI 算力训练 → 华为云（昇腾 + ModelArts）
├── AI 应用开发 → 阿里云百炼（模型最广）
├── 小程序/微信生态 → 腾讯云（原生）
├── 出海业务 → 阿里云（海外节点最多）
├── 预算敏感 → 华为云（价格最低）
└── 混合云/私有云 → 华为云（Stack 最成熟）

没有绝对最好，只有场景最优
```

## 2. 成本计算模型

| 厂商 | 年付 | 3 年预留 | 说明 |
|------|:---:|:---:|------|

| 腾讯云 | 2,106 元 | ~4,200 元 | 轻量更便宜 |

### 2.2 总拥有成本（TCO）估算

```text
中小型 Java 业务月成本（阿里云参考）：

├── ECS 2核4G × 2（高可用）    → ~¥500
├── RDS MySQL 2核4G           → ~¥400
├── Redis 1G                  → ~¥100
├── OSS（存储+流量）            → ~¥50
├── 域名 + HTTPS              → ~¥10
├── 云监控/日志                → ~¥50
└── 合计                      → ~¥1,100/月

省钱点：
├── 轻量服务器替代 ECS（个人场景省 50%）
├── 数据库自建（测试环境省 RDS 费用）
├── 预留实例（长期稳定业务省 30-50%）
└── 按量 → 包年（长期省 40%+）
```

## 3. 省钱六大策略

| 策略 | 做法 | 节省 |
|------|------|:---:|
| **① 预留实例** | 长期稳定业务买预留/包年 | 30-50% |
| **② 轻量服务器** | 个人/小业务用轻量 | 50%+ |
| **③ 免费试用** | 腾讯蜂驰 4核8G 7 天 + 阿里 ¥300 额度 | 全免 |
| **④ 弹性伸缩** | 高峰期扩容/低谷缩容 | 按需 |
| **⑤ 冷热分离** | 冷数据 OSS 低频存储 | 60%+ |
| **⑥ 多模型路由** | AI 场景简单任务用便宜模型 | 70%+ |

**续费注意：**
- 阿里云经济型 e 续费同价（99 元/年）
- 腾讯云续费折扣明确
- 华为云需关注活动（价格波动）

## 4. 避坑清单

| 坑 | 后果 | 对策 |
|----|------|------|
| **域名未备案** | 国内服务器无法访问（10-20 天） | 提前备案 |
| **安全组漏端口** | 服务不可访问 | 开通时确认 |
| **试用超额扣费** | 阿里试用超额度自动扣费 | 设置额度告警 |
| **数据库公网暴露** | 被扫库攻击 | RDS 仅内网 |
| **无备份** | 数据丢失无法恢复 | 开启自动备份 |
| **单机部署** | 宕机即业务中断 | 至少双机 + 负载均衡 |
| **带宽买小** | 流量高峰卡顿 | 按峰值预估 + 弹性带宽 |
| **忽略监控** | 故障发现滞后 | 云监控 + 告警规则 |

> 🎯 **核心要点**：最终决策三句话 — **① 看业务生态选厂商（Java 微服务→阿里、游戏音视频→腾讯、政企信创→华为）② 看预算省钱（免费试用先 POC → 轻量起步 → 预留实例）③ 看场景组合（AI 应用百炼 + 算力 ModelArts + 分发 TI 可以混用）**。没有任何一家全场景最优 — 组合使用三家云是大型团队的常见方案。
