## 2. 轻量服务器 Lighthouse

**性价比制高点 — 腾讯云的招牌产品：**

```text
Lighthouse 轻量应用服务器：
├── 将服务器 + 负载均衡 + CDN 流量包打包
├── 开箱即用（预装镜像：WordPress/宝塔/Java 环境）
├── 面向个人开发者/初创
└── 超低预算首选

价格参考：
├── 入门 S5：199 元/年
├── 2核8G/5M（S5.LARGE8）：约 2,106 元/年
└── 上海节点实测比阿里云便宜约 12%

AMD EPYC 实例（标准型 S5/S6）：
└── 同价位性能突出
```

## 3. 音视频与游戏生态

```text
腾讯云的两张王牌：

① TRTC（实时音视频）
   ├── 微信/QQ 生态原生集成
   ├── WebRTC 场景响应最快
   ├── 音视频 SDK 易用性一骑绝尘
   └── 直播/会议/在线教育首选

② 游戏云（份额 >40%）
   ├── GME 游戏多媒体引擎
   ├── 游戏服务器/对战/匹配
   ├── 国内游戏云第一
   └── 小程序开发（微信生态）

社交生态连接：
├── 小程序云开发（微信原生）
├── 企业微信生态
└── 用户增长/分发能力
```

## 4. 混元大模型与 TI 平台

| 产品 | 定位 | 详情 |
|------|------|------|
| **混元大模型** | 自研基座 | 微信生态深度打通 |
| **TI-ONE** | 训练/精调工程平台 | 企业 MLOps（数据处理/训练/部署/监控/评测/协作） |
| **TI 智能体平台（ADP）** | 智能体开发 | 知识问答/RAG/工作流/多智能体/企业权限/工作空间 |
| 自主可控 | 海光 CPU | **95% 自主可控率**、OCR 场景信创适配强 |

**TI 平台特色：**
```text
├── 生态型智能体平台路线
├── 与腾讯生态（微信/企业微信）强相关
├── TI-ONE：企业 MLOps 全流程
├── ADP：智能体开发 + 分发
└── 适合"智能体 + 分发"团队
```

## 6. 适用场景

```text
✅ 初创公司/个人开发者 → 最友好 + Lighthouse 超低价
✅ Web 应用/轻量服务 → 轻量服务器开箱即用
✅ 游戏/直播/音视频 → 份额 40% + TRTC 王牌
✅ 小程序开发 → 微信生态原生
✅ 预算敏感 → 上海节点便宜约 12%
✅ 智能体 + 微信分发 → TI 平台生态
❌ 大型企业级 PaaS → 丰富度稍逊阿里云
❌ 政企市场 → 渗透不及华为云
```

---

> 🎯 **核心要点**：腾讯云 = **社交生态 + 性价比**。三张牌：① Lighthouse 轻量服务器（性价比制高点、199 元/年起）② TRTC/游戏云（音视频不可替代、份额 40%）③ 微信生态（小程序/企业微信原生）。对开发者和初创最友好、免费试用最慷慨。短板：企业级 PaaS 丰富度、政企渗透不及前两家。
