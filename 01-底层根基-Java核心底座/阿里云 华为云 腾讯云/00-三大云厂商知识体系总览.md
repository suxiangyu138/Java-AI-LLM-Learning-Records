## 5. 核心概念速查

| 概念 | 一句话 |
|------|--------|
| ECS / CVM / ECS | 三家云服务器产品（阿里 ECS/腾讯 CVM/华为 ECS） |
| 飞天 | 阿里云自研操作系统 |
| 倚天 / 鲲鹏 | 阿里/华为自研 ARM 芯片（成本降 20%） |
| 昇腾 | 华为自研 AI 芯片（NPU） |
| 轻量服务器 | 腾讯 Lighthouse（性价比制高点） |
| 百炼 / ModelArts / TI | 三家大模型平台 |
| 通义 / 盘古 / 混元 | 三家自研大模型 |
| 信创 | 信息技术应用创新（国产化替代） |

---

> 🎯 **核心要点**：三大云选型口诀 — **① 电商/金融/中大型 → 阿里云（生态最全）② 初创/游戏/音视频 → 腾讯云（性价比+社交生态）③ 政务/国企/信创/AI 算力 → 华为云（自主可控）**。Java 后端微服务选阿里云（中间件兼容最佳）、WebRTC 音视频选腾讯云、大数据/AI 处理华为云接口更友好。
