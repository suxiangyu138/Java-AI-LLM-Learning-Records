## 1. 三平台定位与选择

| 平台 | 定位 | 最适合 |
|------|------|--------|
| **阿里云百炼** | 模型超市 + 云底座 | AI 应用开发（RAG/Agent/API 调用） |
| **华为云 ModelArts** | 政企全栈交付 | 模型训练/微调、信创 AI |
| **腾讯云 TI** | 生态型智能体平台 | 智能体开发 + 微信分发 |

```text
选择逻辑：
├── 做 AI 应用（RAG/Agent）→ 百炼（模型覆盖最广 + OpenAI 兼容）
├── 训练/微调大模型 → ModelArts（分布式训练）或 TI-ONE（MLOps）
├── 国产化/信创要求 → ModelArts（昇腾全栈）
├── 智能体 + 微信生态 → TI（ADP 平台）
└── 企业多模型统一调用 → 百炼（100+ 模型一个 Key）
```

## 2. 阿里云百炼实战

### 2.1 快速接入（OpenAI 兼容）

```python
from openai import OpenAI

client = OpenAI(
    api_key=os.getenv("DASHSCOPE_API_KEY"),   # 百炼控制台
    base_url="https://dashscope.aliyuncs.com/compatible-mode/v1"
)

# 调用通义千问
response = client.chat.completions.create(
    model="qwen3.5-plus",                     # 或 qwen3.5-flash（更便宜）
    messages=[{"role": "user", "content": "解释什么是 RAG"}]
)
print(response.choices[0].message.content)

# 调用第三方模型（DeepSeek/Kimi/GLM 等 100+）
response = client.chat.completions.create(
    model="deepseek-v3",                      # 百炼托管第三方模型
    messages=[{"role": "user", "content": "你好"}]
)
```

### 2.2 百炼应用搭建（可视化）

```text
百炼控制台 → 应用广场：
① 创建应用 → 选择模型（通义/第三方）
② 配置知识库（上传文档 → 自动向量化）
③ 配置插件（Web 搜索/函数调用）
④ 发布为 API 或 Web 应用

适合：零代码搭建 RAG 问答/客服/Agent
```

## 3. 华为云 ModelArts 实战

### 3.1 定位

```text
ModelArts = 数据 + 模型 + 应用开发全覆盖：

├── 数据处理：标注/清洗/增强
├── 模型开发：训练/微调（昇腾 NPU）
├── 模型部署：推理服务/私有化
├── Agent 工具链：工作流/知识库/提示词工程
└── 特色：分布式训练 + 昇腾全栈 + 信创
```

### 3.2 训练/微调流程

```bash
# ① 准备数据（ModelArts 数据集服务）
# ② 选择训练环境（昇腾 NPU 资源池）
# ③ 模型微调（盘古系列或开源模型）
# ④ 模型部署（在线推理 / 批量推理）
# ⑤ 私有化部署（政企数据不出门）
```

```python
# ModelArts SDK 示例（训练作业提交）
from modelarts.session import Session
from modelarts.estimator import Estimator

session = Session()
estimator = Estimator(
    session=session,
    framework_type="PyTorch",
    train_instance_type="modelarts.p3.8xlarge",
    train_script_path="/code/train.py",
    modelarts_pool_name="ascend-pool"     # 昇腾资源池
)
estimator.fit(inputs="/data/dataset")
```

## 4. 腾讯云 TI 实战

### 4.1 TI-ONE（训练平台）

```text
TI-ONE = 企业 MLOps 平台：
├── 数据处理/训练/部署/监控/评测
```
