## 1. Elements 面板的定位

> **背景**：Elements 面板同时展示 DOM 树与 CSS 样式——前端「改样式」的主战场。
> **目的**：实时修改样式预览（不改源码），定位样式问题。
> **适用范围**：前端开发/调试；页面样式排查。
> **不适用场景**：逻辑调试（用 Sources）；接口排查（用 Network）。

```text
Elements 面板能做什么
├── ① 查看/编辑 DOM 结构
├── ② 实时修改 CSS（立即生效预览）
├── ③ 调整样式数值（微调神器）
├── ④ 搜索 DOM 节点
├── ⑤ 元素截图
├── ⑥ DOM 断点（定位 JS 修改 DOM 的代码）
└── ⑦ 事件监听查看（谁绑定了事件）
```

## 2. DOM 导航与操作

### 2.1 DOM 树导航

| 快捷键 | 功能 |
|:---:|------|
| `↑` / `↓` | 兄弟节点间移动 |
| `←` / `→` | 折叠/展开节点（Alt+→ 展开全部子节点） |
| `Enter` | 编辑当前节点属性 |
| `Delete` / `Backspace` | 删除选中节点 |
| `Ctrl+F` | 搜索 DOM（标签/id/class/选择器） |
| `Ctrl+Z` | 撤销编辑 |
| `Ctrl+C` | 复制节点（HTML） |
| `Ctrl+Shift+C` | 重新进入检查模式 |

### 2.2 DOM 搜索技巧

```text
Ctrl+F 搜索 DOM（Elements 面板内）
├── ① 支持标签名：div
├── ② 支持 id：#header
├── ③ 支持 class：.btn-primary
├── ④ 支持完整选择器：#app .list li:first-child
├── ⑤ 支持 XPath（高级）：//div[@class='card']
└── 搜索后：Enter 跳到下一个匹配 / Shift+Enter 上一个

实用场景
├── 页面元素太多找不到 → Ctrl+F 搜索 class
├── 动态渲染元素 → 搜索后观察（断点定位渲染代码）
└── 组件定位 → 搜索组件根节点 class
```

## 3. 样式数值微调

### 3.1 数值步进（核心技巧）

> 🎯 **Elements 样式数值微调是「盲调样式」的核心**——选中数值后方向键微调：

| 快捷键 | 步进 | 场景 |
|:---:|:---:|------|
| `↑` / `↓` | 1（像素） | 常规微调 |
| `Shift+↑/↓` | 10 | 快速调整 |
| `Alt+↑/↓` | 0.1 | 精细调整（opacity/transform） |
| `Ctrl+↑/↓` | 100 | 大幅调整（字体大小等） |
| `Enter` | 提交数值 | |
| `Tab` / `Shift+Tab` | 下一个/上一个属性值 | 连续调整 |

```text
实战：调整元素间距
├── ① Ctrl+Shift+C 选中元素
├── ② 找到 margin/padding 的数值
├── ③ ↑↓ 调整（1px 步进）
├── ④ Shift+↑↓ 快速（10px）
├── ⑤ Tab 跳到下一个属性
└── ⑥ 调整满意 → 复制到源码（Ctrl+C）
→ 金句：样式微调全程键盘——数值即调即看
```

### 3.2 颜色调整

```text
颜色微调（2026 DevTools）
├── ① 点击颜色块 → 打开取色器
├── ② 取色器内 ↑↓ 调整明度（Shift 大步进）
├── ③ 支持吸管取色（页面任意位置）
├── ④ 复制格式切换（hex/rgb/hsl）
└── ⑤ 对比度检查（无障碍）
```

## 4. CSS 编辑与补全

### 4.1 样式编辑

| 操作 | 快捷键 | 说明 |
|------|:---:|------|
| 添加样式 | 双击属性区空行 | 输入属性名 |
| 自动补全 | `Ctrl+Space` | CSS 属性/值补全 |
| 快速生成 | 输入 `w100` 等缩写 | Emmet 风格（部分版本） |
| 编辑值 | 双击数值 | 进入编辑 |
| 禁用样式 | 勾选复选框 | 临时禁用查看 |
| 复制规则 | 右键 → Copy rule | 复制到源码 |
| 查看计算样式 | Computed 标签 | 最终生效值 |

### 4.2 样式调试技巧

```text
样式问题定位技巧
├── ① 看「被划掉」的样式：高优先级/来源覆盖
├── ② 样式来源：文件:行号（点击跳转 Sources）
├── ③ 继承样式：Inherited from 展开
├── ④ 查看伪类：:hover/:active（强制状态）
├── ⑤ 计算样式（Computed）：最终值总览
├── ⑥ 布局面板：盒子模型可视化（间隙问题）
└── ⑦ 本地修改：右键 → Overrides 保存（线上调试）

强制状态（伪类调试）
├── 右键元素 → Force state → :hover/:active/:focus
└── 排查 hover 样式不生效的利器
```

## 5. DOM 搜索

（见第 2 节 DOM 搜索技巧——Ctrl+F 是 Elements 面板的高频入口）

```text
补充：DOM 断点（Elements 面板的隐藏能力）
├── 右键元素 → Break on → Subtree modifications
│   （子节点变化时暂停——定位动态渲染代码）
├── Break on → Attribute modifications
│   （属性变化时暂停——定位 class 被改）
├── Break on → Node removal
│   （节点被删除时暂停——定位元素消失）
└── 场景：页面元素「莫名消失/变化」→ DOM 断点抓现行
```

元素截图（只截某个元素而非全屏）

## 7. 样式调试实战流程

### 7.1 完整流程（键盘流）

```text
样式 Bug 排查键盘流
┌──────────────────────────────────────────┐
│ ① F12 → Ctrl+Shift+C 点击问题元素        │
│ ② 看 Elements 选中（DOM 结构确认）        │
│ ③ 看 Styles：哪条样式「不对」             │
│    ├── 被覆盖？→ 看高优先级来源            │
│    ├── 没生效？→ 选择器匹配问题            │
│    └── 值不对？→ 数值微调验证              │
│ ④ ↑↓ 微调数值 → 实时预览确认期望值        │
│ ⑤ 复制修正后的样式 → 改源码               │
│ ⑥ Ctrl+R 刷新验证（改源码后）             │
└──────────────────────────────────────────┘
```

### 7.2 常见问题

```text
Elements 调试常见问题
├── ⚠️ 改的样式刷新后消失：DevTools 修改是临时的！
│   → 改完复制到源码（Ctrl+C → 编辑器粘贴）
├── ⚠️ 样式被 !important 覆盖：检查高优先级来源
├── ⚠️ 选择器不生效：检查 class 拼写/层级
├── ⚠️ 伪类样式调不出来：Force state 强制
└── ⚠️ 动态元素找不到：先操作触发再搜索
```

## 8. 核心要点

> 🎯 **核心要点**：
> 1. DOM 导航：↑↓ 移动 / ←→ 折叠 / Enter 编辑 / Delete 删除——树操作全键盘
> 2. **样式数值微调**：↑↓（1px）/Shift+↑↓（10px）/Alt+↑↓（0.1）——盲调样式核心
> 3. Ctrl+F 搜索 DOM（标签/#id/.class/选择器/XPath）——元素定位
> 4. DOM 断点（Break on）定位「谁改了 DOM」——元素消失/变化排查利器
> 5. 元素截图（命令菜单 Capture node screenshot）——提 Bug/文档配图
> 6. 强制状态（Force state）调试伪类——hover 样式排查
> 7. 金句：DevTools 改样式是临时的——**改完复制到源码**（最高频遗忘点）
