## 3. 2026 内核格局

| 引擎 | 浏览器 | JS 引擎 | 架构状态（2026） |
|------|--------|---------|------------------|
| Blink | Chrome/Edge/Opera/Brave/Android WebView | V8 | RenderingNG 完成（LayoutNG/PaintNG）、Site Isolation、Mojo 服务化 |
| Gecko | Firefox | SpiderMonkey | Stylo（Rust CSS）+ WebRender（GPU 绘制）、e10s + Fission |
| WebKit | Safari/iOS 全部浏览器 | JavaScriptCore | WebKit2 多进程、Metal 现代化、能效优先 |
| Servo/Ladybird | 新兴独立引擎 | 各自配套 | Servo 重新活跃、Ladybird 接近 alpha |

三个 2026 关键动态：**欧盟 DMA 打破 iOS WebKit 垄断**（Chrome iOS Blink 版已向欧盟用户推出，Firefox iOS Gecko 版 2025 试点、2026 扩大 rollout，欧盟外不变）；**三大引擎均完成现代化改造**；**单一化风险加剧**——Blink 的 CVE 同时影响 Chrome/Edge/Brave/Arc 与整个 Electron 生态，W3C/WHATWG 标准实际受 Blink 左右。

## 4. 与同级 Web 体系的边界

- **Web 高阶知识**：HTTP 协议、缓存、TLS、跨域、Web 安全——本体系聚焦"内核如何实现这些协议"
- **Web 服务器/Nginx**：服务端如何发资源——本体系是接收端视角
- **SpringBoot Web/Servlet**：Java Web 后端——浏览器内核是客户端尽头，两者在 HTTP 两端相遇
- **Web开发生态深度剖析**：框架与工程化——内核是框架的运行底座

一句话分工：**协议层看 Web 高阶知识，传输层看 Nginx，本体系看"HTML 变成像素"的全链路**。

## 6. 核心概念速查

| 概念 | 一句话 |
|------|--------|
| 渲染引擎 | 把 HTML/CSS 变成屏幕像素的引擎（解析→布局→绘制→合成） |
| JS 引擎 | 执行 JavaScript 的独立引擎（V8/JSC/SpiderMonkey） |
| RenderingNG | Chromium 渲染架构现代化：LayoutNG/PaintNG，解耦布局绘制 |
| Site Isolation | 每站点独立渲染进程的隔离机制，安全与内存的代价 |
| Mojo | Chromium 的进程间通信与面向服务架构 |
| 属性树 | Transform/Clip/Effect/Scroll 四棵树，O(1) 更新合成器属性 |
| 合成器动画 | 只有 transform/opacity 可离主线程运行的动画 |
| 三棵树 | Main/Pending/Active：提交-光栅化-激活的多缓冲模型 |
| 不可变片段树 | LayoutNG 布局输出，不可变支持增量布局 |
| 瓦片 | 视口划分的 256/512 像素光栅单元，只光栅化可见区 |
| V8 四层编译 | Ignition→Sparkplug→Maglev→TurboFan 渐进优化 |
| 隐藏类 + IC | V8 的动态类型优化：单态/多态/超态 |
| Orinoco | V8 分代 GC：新生代 Scavenge + 老年代并发标记清除 |
| Fission | Firefox 对标 Site Isolation 的站点隔离 |
| Stylo/WebRender | Gecko 的 Rust CSS 引擎与 GPU 绘制引擎 |
| DMA | 欧盟数字市场法，2024 起允许 iOS 非 WebKit 引擎 |
| 帧预算 | 60Hz 下每帧 16.7ms，JS 只有约 10ms 预算 |
| 布局抖动 | 读写交替强制同步布局，循环里性能灾难 |
| 预扫描器 | 主解析器阻塞时继续扫 markup 提前下载资源 |
| Layerize | 把 Paint Chunks 合并为合成层：内存 vs 变更成本权衡 |

## 7. 八大常见误区

1. **"内核 = Chrome"**——Blink 同时驱动 Edge/Brave/Arc/Electron，只测 Chrome 等于只测一个引擎
2. **"iOS 上 Chrome 是 Blink"**——欧盟外所有 iOS 浏览器都是 WebKit 壳，欧盟内 2026 起才有 Blink 版
3. **"transform/opacity 动画不卡"**——只有合成器驱动的才不卡；`will-change` 滥用会层爆炸
4. **"GPU 进程就是渲染进程"**——Viz 进程聚合所有渲染器的帧，GPU 驱动崩溃不拖垮浏览器
5. **"V8 只有一个编译器"**——现代 V8 是四层渐进编译，热函数才到 TurboFan
6. **"缓存不命中就出网"**——还有内存缓存、磁盘缓存、Service Worker 多层判断
7. **"HTTP/2 解决了队头阻塞"**——TCP 层丢包仍阻塞所有流，HTTP/3/QUIC 才真解决
8. **"will-change 提前声明一定快"**——每个提升层消耗 GPU 内存（4K 层约 33MB），要动画后移除
