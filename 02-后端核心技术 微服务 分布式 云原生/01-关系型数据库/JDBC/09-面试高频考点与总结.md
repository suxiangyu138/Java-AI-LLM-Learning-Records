## 1. 必背考点：十二问

### 1.1 JDBC 是什么？为什么 Java 不直接连数据库？

**答题链**：**标准 API（java.sql）+ 厂商驱动** → Java 代码面向接口，换库只换驱动 + URL → 五个核心接口（Driver/DriverManager/Connection/Statement/ResultSet）→ "接口在 JDK、实现在驱动"。

### 1.2 JDBC 4 还需要 Class.forName 吗？

**答题链**：**不需要（JDBC 4.0/ServiceLoader 自动注册）** → 驱动 jar 的 META-INF/services 声明 → DriverManager 初始化扫描 → **老教程的 Class.forName 是历史**（旧驱动例外）。

### 1.3 PreparedStatement 为什么防 SQL 注入？

**答题链**：**参数化（? 占位符）→ 参数作为"值"传给数据库 → SQL 结构执行前已固定** → 对比拼接（`'x' OR '1'='1'` 恒真）→ 附加收益：预编译性能（执行计划复用）+ 类型安全。

### 1.4 Statement 和 PreparedStatement 的区别？

**答题链**：静态拼接 vs 参数化 → 注入风险 vs 防注入 → 无预编译 vs 预编译（性能）→ 选型：**99% 用 PreparedStatement**（Statement 只用于无参 DDL/动态表名）→ CallableStatement 存储过程。

### 1.5 ResultSet 怎么用？

**答题链**：**游标模型（next 先下移再取列）** → getXxx 类型映射（**基本类型 NULL → 默认值，wasNull 判断**）→ 列名优先/索引从 1 → MetaData（手写 ORM）→ 时间用 getObject（JDBC 4.2）→ 大结果集流式（setFetchSize）。

### 1.6 JDBC 事务怎么开启？

**答题链**：**setAutoCommit(false) → SQL → commit/rollback → finally 复位（true）** → 一连接一事务（跨方法必须共享连接）→ savepoint 部分回滚 → **Spring 事务 = 连接绑定 + 提交回滚托管**。

### 1.7 连接池为什么快？HikariCP 核心参数？

**答题链**：**创建连接贵（握手+认证+会话）→ 预先建池复用** → getConnection 借/close 还 → HikariCP（Spring Boot 默认，字节码代理快）→ 核心参数：max-pool-size（核数×2+磁盘起步）/connection-timeout/max-lifetime（小于 DB wait_timeout）。

### 1.8 批处理怎么优化？

**答题链**：**addBatch + executeBatch（省网络往返/解析/提交）** → setAutoCommit(false) 前提 → 分批（500-1000）→ **MySQL rewriteBatchedStatements=true（多值 INSERT）** → 事务策略（整批原子/每批容错）→ 循环单条是反模式（10 倍差距）。

### 1.9 MyBatis 底层怎么执行 SQL？

**答题链**：**DataSource 借连接 → PreparedStatement 预编译 → 参数绑定（ParameterHandler）→ 执行 → ResultSet 映射（ResultSetHandler）** → 与 JDBC 七步一一对应 → `#{}` 预编译 / `${}` 拼接（风险）→ BatchExecutor = JDBC 批处理。

### 1.10 分页怎么实现？

**答题链**：**SQL 改写（LIMIT + COUNT）** → page 从 1 开始 → offset=(page-1)×size → 深分页（大偏移扫描）→ 游标/Keyset → **方言差异（MySQL LIMIT/Oracle ROWNUM）→ 分页插件要 DbType**。

### 1.11 连接泄漏怎么排查？

**答题链**：**借了没还（close 未执行）→ 活跃数持续上升 → 超时** → TWR 根治 → HikariCP leakDetectionThreshold（打堆栈）→ 活跃连接监控 → 常见漏点（异常路径/字段持有）。

### 1.12 时区和乱码怎么配？

**答题链**：**URL 必配 serverTimezone=Asia/Shanghai（新驱动强制）+ characterEncoding=utf8mb4（含 emoji）** → 三层一致（库/连接/应用）→ 存储 UTC、展示本地 → 时间差 8 小时排查三步。

## 2. 高频陷阱题 12 连问

1. **对错**：JDBC 4 需要 Class.forName 加载驱动。（❌ 自动注册）
2. **结果**：`"x' OR '1'='1"` 拼进 SQL 会怎样？（全表返回——注入）
3. **对错**：Statement 性能比 PreparedStatement 好。（❌ 无预编译，更差）
4. **结果**：ResultSet 初始位置？（第一行之前——next 先下移）
5. **对错**：getInt 对 NULL 返回 null。（❌ 返回 0——wasNull 判断）
6. **结果**：getXxx(0)？（❌ 索引从 1 开始）
7. **对错**：连接池的 close 会断开数据库连接。（❌ 归还池中）
8. **结果**：批处理不关自动提交会怎样？（每批自动提交——批次意义减半）
9. **对错**：rewriteBatchedStatements 对所有 SQL 生效。（❌ 仅 INSERT）
10. **结果**：MySQL 时间差 8 小时的第一排查？（serverTimezone/时区一致性）
11. **对错**：MyBatis 的 `${}` 和 `#{}` 都预编译。（❌ `${}` 是拼接——注入风险）
12. **结果**：不指定 serverTimezone 的新 MySQL 驱动？（报错/时区警告）

## 4. 场景题：手写简易连接池

**题目**：手写一个简易连接池（体现对连接池原理的理解）。

**答题框架**（按评分点展开）：

```java
// 简易连接池（核心思路）：
public class SimplePool {
    private final LinkedList<Connection> pool = new LinkedList<>();
    private final int maxSize;

    public SimplePool(String url, String user, String pwd, int maxSize) {
        this.maxSize = maxSize;
        for (int i = 0; i < maxSize; i++) {
            pool.add(createConnection(url, user, pwd));   // 预创建
        }
    }

    public Connection getConnection() throws SQLException {
        synchronized (pool) {
            if (pool.isEmpty()) {
                throw new SQLException("连接池耗尽，请等待");   // 简化：抛异常
                // 真实实现：等待（wait）+ 超时
            }
            return pool.removeFirst();        // 借出（真实：包装代理记录借用）
        }
    }

    public void returnConnection(Connection conn) {
        synchronized (pool) {
            pool.addLast(conn);               // 归还（真实：复位 autoCommit + 校验）
        }
    }
}

// 答题要点（能指出与真实连接池的差距 = 真懂）：
① 预创建（初始化建池）
② 借出/归还（removeFirst/addLast）
③ 等待机制（空池等待而非抛异常——真实实现 wait/超时）
④ 连接校验（归还时校验有效性——真实实现 isClosed/心跳）
⑤ 代理包装（leakDetection——真实实现包装 Connection 记录借用）
⑥ 参数（maxSize/超时——真实实现完整参数体系）
⑦ 线程安全（synchronized/并发集合——真实实现更细粒度锁）
```

## 5. 记忆口诀

```text
JDBC 五接口：Driver、DriverManager、Connection、Statement、ResultSet。
驱动自动载（JDBC 4）：Class.forName 成历史。
三兄弟选型：PreparedStatement 首选（预编译防注入）、Statement 仅 DDL、Callable 存过程。
ResultSet 是游标：next 先下移、NULL 用 wasNull、索引从 1 开始。
事务五步：关自动提交、执行、提交、回滚、finally 复位。
一连接一事务：跨方法共享连接——Spring 的底层。
连接池三价值：复用、限流、管理——借是 getConnection、还是 close。
批处理四件套：预编译、关提交、executeBatch、分批；MySQL 加 rewrite。
MyBatis 底层：预编译 + ResultSet 映射——框架是 JDBC 的自动挡。
URL 两必配：serverTimezone（时区）、characterEncoding=utf8mb4（编码）。
```
