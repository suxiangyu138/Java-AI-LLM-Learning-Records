## 3. 学习路线推荐

**路线 A：快速上手（1 天，推荐给所有后端）**
01 → 02 → 04 → 09。掌握嵌入式数据库的定位、数据类型特性、WAL 事务与 Java 集成——足以支撑本地缓存/原型/工具类项目。

**路线 B：SQLite 深入（3 天）**
路线 A + 03 + 05 + 06。补上查询优化（EXPLAIN）、JSONB、FTS5——能写出高性能的本地检索方案。

**路线 C：AI 时代进阶（面向 AI 工程师）**
路线 B + 07 + 08。向量搜索（sqlite-vec）、混合检索（FTS5+RRF）、Agent 记忆与 MCP 集成、分布式方案（Turso/Litestream）——2025-2026 年 SQLite 的主战场。

## 4. 核心概念速查

| 概念 | 一句话定义 | 关键事实（2025-2026） |
|------|-----------|---------------------|
| 嵌入式数据库 | 无服务器的库内数据库 | 全球部署量最大（数十亿） |
| 存储类 | 动态类型（NULL/INT/REAL/TEXT/BLOB） | 与静态类型数据库的本质差异 |
| B-tree | 表与索引的存储结构 | 页大小可调（4KB 默认） |
| WAL | 写前日志（替代回滚日志） | 读不阻塞写、写不阻塞读 |
| 单写者 | 同一时刻仅一个写事务 | BEGIN CONCURRENT 未入主线（Turso fork 提供） |
| 事务隔离 | 可串行化（单写者天然） | 读事务快照隔离 |
| JSONB | 二进制 JSON 格式（3.45+） | 快 3×、小 5-10%；仅 SQLite 内部格式 |
| FTS5 | 全文检索虚拟表 | BM25 排序、trigram、中文需分词 |
| sqlite-vec | 向量搜索扩展 | vec0 虚拟表、4 种距离、KNN |
| 混合检索 | FTS5 + 向量 + RRF 融合 | 2025-2026 RAG 标配 |
| WASM | 浏览器内运行 SQLite | 3.51 起支持 64 位；OPFS 持久化 |
| 最新版本 | 3.53.3（2026-06） | ALTER 支持约束增删、json_array_insert |

> 🎯 **核心要点**：SQLite 的定位是"文件即数据库"——零配置、单文件、可嵌入任意进程。它的独特之处（动态类型、单写者、页缓存）源于此定位；它的现代价值（JSONB、FTS5、向量搜索、WASM）让它成为 2025-2026 年 AI Agent 的默认本地存储。理解"嵌入式"这个前提，就理解了它的一切设计选择。
