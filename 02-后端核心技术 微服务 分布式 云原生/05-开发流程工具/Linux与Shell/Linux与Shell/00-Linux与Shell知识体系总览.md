## 3. 精通级学习路线

### 🟢 L1：能在 Linux 上部署 Java 应用（半天）

```
01-操作系统基础 → 02-常用命令 → 05-服务管理 → 12-服务器运维基础
产出：能在 Linux 上部署 SpringBoot jar 包、查看日志、启停服务
```

### 🔵 L2：运维与排错（1天）

```
03-系统管理 → 04-网络与安全 → 11-命令行速查 → 14-性能监控与JVM排查
产出：能独立排查 CPU 飙升、内存溢出、磁盘满、网络不通等问题
```

### 🟣 L3：权限深度与安全加固（半天）

```
13-权限与用户管理深度 + 04-网络与安全（安全部分）
产出：能设计生产环境的权限模型，配置最小权限原则
```

### 🟡 L4：Shell 脚本自动化（1天）

```
06→07→08→09→10（Shell 全系列）
产出：能编写自动化运维脚本、日志分析脚本、批量操作脚本
```
