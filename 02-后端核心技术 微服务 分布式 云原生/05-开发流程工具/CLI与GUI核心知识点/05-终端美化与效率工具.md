# 05 - 终端美化与效率工具

> 🎯 好的终端配置 = 工作效率翻倍 — Zsh/Oh My Zsh 美化、tmux 多窗格、fzf 模糊搜索、alias 快捷键

---

## 1. Shell 选型与美化

```bash
# 查看当前 Shell
echo $SHELL

# Zsh 安装 + 设为默认
sudo apt install zsh -y        # Ubuntu
chsh -s $(which zsh)

# ⭐ Oh My Zsh（Zsh 配置框架）
sh -c "$(curl -fsSL https://raw.github.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"

# 主题推荐
ZSH_THEME="agnoster"     # 显示 git 分支信息
ZSH_THEME="powerlevel10k"  # ⭐ 最流行，自定义强
```

### 推荐插件

```bash
# ~/.zshrc
plugins=(
  git              # git 别名 + 状态提示
  z                # 智能跳转目录（z + 目录名片段）
  zsh-autosuggestions    # 灰色提示（按 → 补全）
  zsh-syntax-highlighting # 命令语法高亮
  docker           # docker 命令补全
)
```

## 2. tmux — 终端复用

```bash
# 安装
sudo apt install tmux -y

# 基本操作
tmux new -s dev            # 新建名为 dev 的会话
tmux attach -t dev         # 重新接入
tmux ls                    # 列出所有会话

# 窗格操作（Ctrl+B 后）：
# %  水平分屏
# "  垂直分屏
# 方向键  切换窗格
# x  关闭窗格

# 好处：SSH 断开后会话保持、一个窗口管理多个终端
```

## 3. fzf — 模糊搜索

```bash
# Ctrl+R 历史命令模糊搜索（需配合 fzf 插件）
# Ctrl+T 当前目录文件模糊搜索
# ** 路径补全：vim **<TAB>  → 模糊匹配文件

# 管道中使用
ps -ef | fzf                    # 交互式过滤进程
git log --oneline | fzf         # 交互式选 commit
```

## 4. alias 提效

```bash
# ~/.zshrc 或 ~/.bashrc
alias ll='ls -lah'
alias gs='git status'
alias gp='git pull --rebase'
alias gc='git commit -m'
alias dps='docker ps --format "table {{.Names}}\t{{.Status}}"'
alias k='kubectl'
alias idea='open -a IntelliJ\ IDEA .'

# Java 相关
alias jps='jps -l -v'
alias mci='mvn clean install -DskipTests'
alias tailapp='tail -f logs/app.log'
```

## 5. 其他效率工具

| 工具 | 用途 | 安装 |
|------|------|------|
| **zoxide** | 智能跳转目录 | `curl -sS https://webinstall.dev/zoxide \| bash` |
| **bat** | 带语法高亮的 cat | `sudo apt install bat` |
| **ripgrep (rg)** | 超快 grep | `sudo apt install ripgrep` |
| **fd** | 超快 find | `sudo apt install fd-find` |
| **tldr** | 命令示例速查 | `npm install -g tldr` |
| **httpie** | 比 curl 好用的 HTTP 客户端 | `sudo apt install httpie` |

```bash
# 示例
tldr tar                   # 只看 tar 的常用示例
rg "TODO" src/             # 比 grep -rn 快 10 倍
fd "*.java" src/           # 比 find 快且默认忽略 .git
http :8080/api/users/1     # 比 curl 简洁
```

> 🎯 **最小配置即高收益**：Oh My Zsh + 3 插件（git/z/autosuggestions）+ tmux + 10 个 alias。20 分钟配置，每天省 100 次键盘敲击。
