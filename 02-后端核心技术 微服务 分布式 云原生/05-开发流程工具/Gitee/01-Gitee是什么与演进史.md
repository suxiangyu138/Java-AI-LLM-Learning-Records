## 1. Gitee 是什么：三个身份

Gitee（码云）由开源中国（OSChina）于 2013 年推出，现在同时具备三个身份：

- **代码托管平台**：Git 仓库托管、Pull Request 协作、Issue 管理——与 GitHub/GitLab 同构，Git 工作流完全通用
- **研发效能平台**：Gitee Go 流水线、GiteeScan 扫描、GiteeTest 测试、Pages 发布——从"存代码"走向"研发全流程"
- **合规基础设施**：企业版私有化部署 + 信创适配，面向政企客户——这是 GitHub/GitLab 在中国都无法替代的价值

三个身份是递进关系：托管是入口，效能是延伸，合规是壁垒。理解这个递进，才能理解 Gitee 为什么在国内市场占据独特位置——**GitHub 解决"全球协作"，Gitee 解决"国内落地"**。三者的产品形态对应也清晰：托管身份对应免费版（个人与开源）、效能身份对应企业版 SaaS（团队研发管理）、合规身份对应私有化部署（政企涉密）。你的使用场景落在哪层，就该用哪个版本——免费版"够用"不代表"该用"。

## 2. 演进史：从托管到 AI 基础设施

| 阶段 | 时间 | 关键动作 |
|------|------|----------|
| 起步 | 2013 | Gitee 上线，依托开源中国社区生态 |
| 企业化 | 2017+ | 企业版推出，确立私有化 + 国产化路线 |
| 效能化 | 2019-2023 | Gitee Go、GiteeScan、Pages、镜像仓库等能力补齐 |
| 智能化 | 2025 | "模力方舟"战略启动，AI 融入开发流程 |
| **升级** | **2026.01** | **从"代码托管平台"升级为"AI 驱动的工程效率基础设施"** |

2026 年 1 月的战略升级是质的转折：官方表述从"托管代码"变为"提升工程效率"——AI 代码生成、测试路径推荐、漏洞检测基于 MaaS（Model-as-a-Service）平台构建，且结合上下文语义理解与静态分析，不是简单补全工具。这条演进线对选型的启示：**选择 Gitee 不只是选"放代码的地方"，而是选一条国产化研发效能路线**。

对照同期行业动作：GitHub 押注 Copilot 与 Actions 生态、GitLab 押注 AI Duo 与一体化平台——三家 2026 年的共同方向都是"托管 + AI 研发效能"，差异在落地路径：GitHub 靠全球生态规模、GitLab 靠自托管一体化、Gitee 靠国内合规 + 本土化模型。带着这个行业背景看 Gitee，就不会把它当成"功能少一点的 GitHub"，而是一条目标明确的国产路线。

## 3. 解决什么问题

- **国内网络**：GitHub 在国内访问不稳定、clone/push 慢、依赖下载超时——Gitee 国内节点稳定流畅，原生支持国内镜像源（pub.flutter-io.cn、npmmirror 等），依赖安装速度提升数倍
- **合规要求**：源代码管理需满足监管要求——安全审计、细粒度权限、敏感操作留痕、源代码不出境
- **信创替代**：党政、金融、国企场景要求国产化工具链——Gitee 私有化部署已落地河南农担、国家信创适配项目等
- **中文生态**：中文文档/社区/Issue 交流、符合中国开发者习惯的 AI 建议（基于海量开源项目数据训练）
- **高校与培训**：国内大量高校使用 Gitee 做教学平台（课程仓库、学生作业提交、Git 实验），企业内训也常以 Gitee 为工具底座——这意味着"会 Git + 会用 Gitee"是校招简历的基本盘，而"懂 Gitee 企业版/Go 流水线"是明显的加分差异

## 4. 与 GitHub/GitLab 的本质差异

| 维度 | Gitee | GitHub | GitLab |
|------|-------|--------|--------|
| 归属 | 开源中国（中国） | Microsoft（美国） | GitLab Inc.（美国） |
| 网络 | 国内节点快 | 国内不稳定 | 国内一般 |
| 开源生态 | 国内为主 | 全球最大 | 中 |
| 企业方案 | 私有化 + 信创 | GitHub Enterprise | 自托管 CE/EE |
| 合规 | 源代码不出境 | 数据在境外 | 自托管可控 |
| CI/CD | Gitee Go（国产） | Actions | 内置最成熟 |
| AI | 模力方舟（本土化） | Copilot | Duo |

本质差异不在功能而在**属地与合规**：同样的事（托管/PR/CI），Gitee 的价值是"数据在中国、合规有保障、网络顺畅"。技术上三者底层都是 Git，工作流可无缝迁移。

## 5. 1350 万开发者意味着什么

截至 2026 年，Gitee 累计服务 1350 万+ 开发者。这个数字的意义：

- **生态规模**：国内最大代码托管平台之一，高校教学、企业内训、开源项目都有覆盖
- **AI 训练基础**：海量开源项目数据是模力方舟训练专用模型的语料基础——"懂中国开发者习惯"的 AI 靠的就是这批数据
- **招聘信号**：国内简历的"代码主页"常放 Gitee，面试官会看你的提交历史与项目质量

对个人开发者：Gitee 是简历的第二门面 + 国内开源参与入口 + 私有仓库的免费选择。

## 6. 五个边界

- **不做 Git 本身**：Git 协议与命令是 Git 知识体系的内容，Gitee 只是托管实现
- **不替代 GitHub 全球生态**：国际开源协作、世界级社区仍在 GitHub，Gitee 用镜像同步衔接
- **不做代码编辑器**：IDE 集成是 Git 体系/IDE 体系的内容
- **AI 不是 Copilot 复制品**：模力方舟是 MaaS 上的整体开发智能栈，不是单一补全工具
- **免费版 ≠ 全部能力**：镜像高级选项、Go 完整时长、Pages 免实名等需企业版
