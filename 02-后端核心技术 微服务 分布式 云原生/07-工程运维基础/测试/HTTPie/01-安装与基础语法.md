## 1. 安装

```bash
# pip（Python 方式，推荐开发环境）
pip install httpie
# 或升级
pip install --upgrade httpie

# Homebrew（macOS）
brew install httpie

# apt（Debian/Ubuntu）
apt install httpie

# 验证
http --version    # httpie 3.2.3
```

> 💡 命令名是 `http`（别名 `httpie`）；3.0+ 提供 `httpie` 管理命令（插件管理：`httpie plugins`）。

## 2. 命令语法结构

```text
http [flags] [METHOD] URL [items]
  │      │        │      │
 选项   方法     地址   请求项（key=value 等）
```

| 部分 | 说明 | 示例 |
|------|------|------|
| flags | 全局选项（`--json`/`--pretty`/`-a` 等） | `http --json POST ...` |
| METHOD | HTTP 方法（GET/POST/PUT/DELETE...） | `http POST ...` |
| URL | 请求地址 | `http GET api.example.com/users` |
| items | 请求项（头/参数/JSON 字段） | `name=张三 X-Trace:abc` |

> 🎯 **核心设计**：请求的所有组成（方法、头、参数、Body）都在**一条命令里声明**——没有 curl 的 `-H`/`-d`/`-X` 选项堆叠。

## 3. 方法：GET / POST 与简写

| 写法 | 说明 |
|------|------|
| `http GET url` | 显式方法 |
| `http POST url` | POST（有 items 时 GET 可省略方法名） |
| `http url` | 省略方法 = GET（默认） |
| `http url key=value` | **带 items 时省略方法 = POST**（自动推断） |

```bash
http example.com                      # GET
http example.com name=张三            # POST（有 items 自动推断）
http GET example.com name=张三        # 显式 GET + 参数
```

> ⚠️ **自动推断规则**：省略方法时，**有 items → POST，无 items → GET**——这是 HTTPie 与 curl 最大的心智差异。

## 4. URL 与便捷粘贴

```bash
# 基础
http api.example.com/users            # 无协议默认 http://
http https://api.example.com/users    # 显式 https

# URL 粘贴（3.x 特性）：协议名后可直接空格
https ://pie.dev/echo                 # 等价于 https://pie.dev/echo

# 路径拼接（使用变量）
BASE=https://api.example.com
http $BASE/users/1                    # 拼接 URL
```

| URL 场景 | 写法 |
|----------|------|
| 默认协议 | `http host/path`（自动补 http://） |
| HTTPS | `https://host/path` 或 `https ://host/path` |
| 查询参数 | `http url page==2 size==20`（用 `==` 运算符） |
| 变量拼接 | shell 变量 `${VAR}` 直接拼接 |

> 💡 URL 粘贴特性让"从浏览器/文档复制 URL 直接调试"零修改——协议后空格也不影响。

## 5. 常用全局选项

| 选项 | 说明 |
|------|------|
| `-j` / `--json` | JSON 模式（默认自动检测） |
| `-f` / `--form` | 表单模式（x-www-form-urlencoded） |
| `-m` / `--multipart` | multipart 模式（文件上传） |
| `-p` / `--print` | 输出控制（`-p H` 仅头、`-p B` 仅体） |
| `-v` / `--verbose` | 显示完整请求+响应（调试神器） |
| `-a` / `--auth` | 认证 `user:pass` |
| `-A` / `--auth-type` | 认证类型 `basic`/`digest`/`bearer` |
| `-S` / `--session` | 会话（见 [04](04-会话与脚本化.md)） |
| `-o` / `--output` | 输出到文件（下载） |
| `--offline` | 离线构建（不发送） |
| `--verify` | TLS 校验（`no` 跳过） |

## 6. 第一个请求实战

```bash
# 1. 简单 GET
http https://api.github.com/users/octocat

# 2. POST JSON（自动序列化）
http POST https://api.example.com/users \
  name=张三 \
  email=zhangsan@example.com

# 3. 带请求头 + 查询参数
http GET https://api.example.com/orders \
  page==2 size==20 \
  X-Auth-Token:abc123

# 4. 调试完整请求响应
http -v POST https://api.example.com/login \
  username=admin password=secret
```

```text
示例输出（自动格式化 + 语法高亮）：
HTTP/1.1 200 OK
Content-Type: application/json
...

{
    "id": 1,
    "name": "张三"
}
```

> 🎯 三步上手：`http url`（GET）→ `http POST url key=value`（JSON 自动）→ `http -v ...`（看全貌）。与 curl 对照见 [05](05-与curl对比与生产实践.md)。

## 7. 核心要点

> 🎯 **核心要点**：
> - 语法骨架：`http [flags] [METHOD] URL [items]`——一切声明在一条命令；
> - 方法推断：有 items 省略方法 = POST，无 = GET；
> - items 语法：`key=value`（JSON 字段）、`key:value`（头）、`key==value`（查询参数）；
> - 自动 JSON：发送自动序列化、响应自动格式化高亮；
> - `-v` 是调试第一选项（完整请求+响应）；
> - 3.x 特性：URL 粘贴（`https ://`）、Bearer 认证、`http --manual` 手册。
