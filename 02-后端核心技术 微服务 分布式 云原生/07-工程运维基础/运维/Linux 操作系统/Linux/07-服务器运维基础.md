## 1. 服务器硬件基础

### 1.1 核心组件与选型关注点

| 组件 | 说明 | 后端开发关注点 |
|------|------|----------------|
| CPU | 主频 + 核心数决定计算能力 | 高并发服务选多核（8C+）；批处理/计算密集型选高主频 |
| 内存 | 程序运行时驻留空间 | JVM 堆 + 系统缓存 + 外部组件（DB/Redis）之和，留 20% 余量 |
| 磁盘 | 数据持久化存储 | 系统盘 SSD + 数据盘 SSD/NVMe；数据库建议 NVMe SSD |
| 网络 | 带宽 + 延迟 | 带宽决定吞吐上限；内网万兆，公网按需 |

### 1.2 典型配置参考

| 场景 | CPU | 内存 | 磁盘 |
|------|:---:|:---:|------|
| 单体 Spring Boot + MySQL | 4C | 8G | 100G SSD |
| 微服务（2-3服务）+ Redis + MQ | 8C | 16G | 200G SSD |
| 生产读写分离 + ES 集群 | 16C+ | 32G+ | 500G+ NVMe |
| 开发/测试环境 | 2C | 4G | 50G |

### 1.3 硬件监控指标

| 指标 | 命令 | 告警阈值 |
|------|------|----------|
| CPU 使用率 | `top`, `mpstat` | > 80% 持续 5 分钟 |
| 内存使用率 | `free -h` | > 85% |
| 磁盘使用率 | `df -h` | > 85% 且持续增长 |
| 磁盘 IO | `iostat -x 1` | `%util` > 90% |
| 网络流量 | `iftop`, `nload` | 接近带宽上限 |

## 2. Linux 发行版选型

### 2.1 主流发行版对比（2026-08 现状）

| 发行版 | 包管理器 | 默认文件系统 | 适用场景 |
|--------|----------|:---:|----------|
| **Rocky Linux 10.2**（2026-05） | `dnf` | XFS | ⭐ 生产环境首选（RHEL 1:1 兼容，内核 6.12/systemd 257） |
| **AlmaLinux 10.2**（2026-05） | `dnf` | XFS | RHEL ABI 兼容替代，ELevate 原地升级工具 |
| **RHEL 10.2**（2026-05） | `dnf` | XFS | 企业合规场景（FIPS 140-3/Common Criteria），需订阅 |
| **Ubuntu Server 26.04 LTS**（2026-04） | `apt` | ext4 | 云原生/AI 工作负载，Docker/K8s 首选 |
| **Debian 13** | `apt` | ext4 | 追求极致稳定，资源占用低 |
| **CentOS Stream 10** | `dnf` | XFS | 滚动更新，预览 RHEL 新特性（**CentOS Linux 7/8 已 EOL**） |

### 2.2 选型建议（2026）

```
生产环境（企业）：Rocky Linux 10 / AlmaLinux 10 → 与 RHEL 10 兼容，免费、10 年支持
生产环境（互联网/云/AI）：Ubuntu 26.04 LTS → 云镜像最全、AI 工具链（CUDA/PyTorch）官方支持
极致稳定：Debian 13 → 包版本保守但极其稳定
⚠️ 注意：CentOS Linux 7（2024-06 EOL）/ 8（2021-12 EOL）已停止安全更新
  存量 CentOS 机器必须迁移：Rocky/Alma 可用 ELevate 原地升级，或新建实例重新部署
```

## 3. 系统安装与初始化

### 3.1 分区建议

| 分区 | 大小建议 | 说明 |
|------|----------|------|
| `/boot` | 1G | 内核文件，足够 |
| `/` | 50G-100G | 系统根分区 |
| `swap` | 内存 ≤ 16G：= 内存；内存 > 16G：4-8G | ⚠️ Java 服务不建议使用 swap |
| `/data` | 剩余全部 | 应用数据、日志、数据库 |

### 3.2 安装后初始化 Checklist

```bash
# ═══ Rocky / Alma Linux（RHEL 系）═══
# 1. 更新系统
dnf update -y

# 2. 安装基础工具
dnf install -y vim net-tools wget curl telnet nc htop bind-utils

# 3. 配置时区
timedatectl set-timezone Asia/Shanghai
timedatectl set-ntp true

# 4. 设置主机名
hostnamectl set-hostname prod-app-01

# 5. 关闭 SELinux（生产建议保持 Enforcing）
# setenforce 0  # 仅调试时

# ═══ Ubuntu ═══
# 1. 更新系统
apt update && apt upgrade -y

# 2. 安装基础工具
apt install -y vim net-tools wget curl telnet netcat-openbsd htop dnsutils

# 3-5. 同上
```

### 3.3 安全初始化

```bash
# 1. 创建普通用户并赋予 sudo
useradd -m -s /bin/bash admin
passwd admin
usermod -aG wheel admin          # CentOS (wheel 组)
usermod -aG sudo admin           # Ubuntu (sudo 组)

# 2. SSH 安全配置
vi /etc/ssh/sshd_config
# PermitRootLogin no
# PasswordAuthentication no     # 先配好密钥再改
systemctl reload sshd

# 3. 防火墙最小化
firewall-cmd --permanent --add-service=ssh
firewall-cmd --reload            # CentOS

ufw allow ssh
ufw enable                       # Ubuntu

# 4. 安装 fail2ban
dnf install -y fail2ban          # 或 apt install -y fail2ban
systemctl enable --now fail2ban
```

## 5. Rocky/Alma vs Ubuntu 运维对比

### 5.1 包管理

| 操作 | Rocky / Alma（RHEL 系） | Ubuntu |
|------|---------------|--------|
| 更新仓库 | `dnf update` | `apt update` |
| 升级软件 | `dnf upgrade` | `apt upgrade` |
| 安装软件 | `dnf install -y <pkg>` | `apt install -y <pkg>` |
| 搜索软件 | `dnf search <keyword>` | `apt search <keyword>` |
| 移除软件 | `dnf remove <pkg>` | `apt remove <pkg>` |
| 软件源目录 | `/etc/yum.repos.d/` | `/etc/apt/sources.list(.d/)` |

### 5.2 系统管理

| 功能 | Rocky / Alma | Ubuntu |
|------|---------------|--------|
| 防火墙 | `firewalld` (firewall-cmd) | `ufw` |
| 安全模块 | SELinux | AppArmor |
| root SSH | 默认允许 | ⚠️ 默认禁止 |
| 网络配置 | `/etc/sysconfig/network-scripts/ifcfg-*` | `/etc/netplan/*.yaml` |
| 服务管理 | `systemctl`（相同） | `systemctl`（相同） |

### 5.3 Java 环境安装

```bash
# Rocky / Alma（dnf，RHEL 系）
dnf install -y java-17-openjdk-devel

# Ubuntu
apt install -y openjdk-17-jdk

# 验证
java -version && javac -version
```

## 6. Unix 与 Linux

### 6.1 关系与历史

| 概念 | 说明 |
|------|------|
| **Unix** | 1970 年代贝尔实验室开发的多用户、多任务操作系统 |
| **Linux** | 类 Unix 系统，Linus Torvalds 1991 年创建，代码完全重写 |
| **POSIX** | 可移植操作系统接口标准，Linux/macOS/Unix 遵循 |
| **macOS** | 认证 Unix（Darwin 内核 + FreeBSD 用户态） |

### 6.2 对 Java 后端的意义

| 场景 | 说明 |
|------|------|
| macOS 开发 | 终端命令与 Linux 几乎一致，shell 脚本可复用 |
| 跨平台部署 | POSIX 标准命令（`ps`、`grep`、`awk`、`sed`）可平滑迁移 |
| 面试考核 | Unix/Linux 区别、POSIX 标准是后端面试常考概念 |
| JVM 跨平台 | Write Once, Run Anywhere — 但 shell 脚本可能需适配 |

## 7. Java 后端运维速查

### 7.1 系统信息速查

```bash
uname -a                    # 内核版本
cat /etc/os-release         # 发行版信息
hostnamectl                 # 主机名 + 系统信息
free -h                     # 内存使用
df -h                       # 磁盘使用
uptime                      # 运行时间 + 负载
lscpu                       # CPU 信息
```

### 7.2 Java 进程相关

```bash
ps -ef | grep java                         # 查找 Java 进程
jps -l -v                                  # JDK 进程列表
jstack <pid> > thread.dump                 # 线程堆栈
jstat -gc <pid> 1000 10                    # GC 统计（每秒 × 10次）
jmap -histo:live <pid> | head -20          # 堆对象 Top20
tail -f nohup.out                          # 实时日志
```

### 7.3 网络快速排查

```bash
ss -tlnp                                   # 监听端口
curl -v http://localhost:8080/health        # 健康检查
ping -c 4 <host>                            # 连通性
nc -zv <host> <port>                        # 端口测试
traceroute <host>                           # 路由追踪
```

### 7.4 常用运维脚本片段

```bash
# 一键查看 Java 进程关键信息
function java-info() {
    PID=$(pgrep -f "java" | head -1)
    echo "PID: $PID"
    echo "--- 启动命令 ---"
    cat /proc/$PID/cmdline | tr '\0' ' '
    echo ""
    echo "--- 内存 ---"
    cat /proc/$PID/status | grep -E "VmRSS|VmSize|Threads"
    echo "--- 文件句柄 ---"
    ls /proc/$PID/fd/ | wc -l
    echo "--- 端口 ---"
    ss -tlnp | grep $PID
}
```
