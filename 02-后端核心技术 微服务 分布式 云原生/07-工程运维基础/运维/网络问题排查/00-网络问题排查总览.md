## 4. 排查总原则

```text
① 分层定位：先确认哪一层（应用/传输/网络/DNS）出问题
② 由外到内：客户端 → 网络路径 → 服务端 → 应用
③ 工具最小集：ping（通不通）→ telnet/ss（端口通不通）→ curl（HTTP 通不通）
④ 看两端：客户端视角 + 服务端视角（ss -tnp 看连接状态）
⑤ 抓包定论：tcpdump 是"最终裁判"（不靠猜）
⑥ 记录现场：时间/现象/变更（回滚对比）
```

> ⚠️ 最常见的错误：**跳过分层直接改配置**——"连不上"先分清是 DNS 解析失败、网络不通、端口不通、还是应用没起。

## 5. 核心概念速查

| 概念 | 一句话 |
|------|--------|
| 三次握手 | SYN → SYN-ACK → ACK 建立连接 |
| 四次挥手 | FIN → ACK → FIN → ACK 关闭连接 |
| TIME_WAIT | 主动关闭方等待 2MSL（确认对方收到 FIN） |
| RST | 连接重置（端口没监听/协议错误/防火墙） |
| SYN 队列 | 半连接队列（握手未完成） |
| Accept 队列 | 全连接队列（等待 accept） |
| 连接超时 vs 读超时 | connectTimeout（建立连接）/ readTimeout（等待响应） |
| DNS 缓存 | 本地 hosts → resolver → 各级缓存 |
| TTL | DNS 记录缓存时间 / 网络包生存时间 |
| backlog | 内核 listen 队列长度（与 accept 队列相关） |
| 连接池 | 复用 TCP 连接（避免频繁握手） |
