## 2. 创建 SSH 会话

```text
连接入口：主页 → 新建连接 → SSH 连接（Linux）
```

| 配置项 | 说明 |
|--------|------|
| 名称 | 会话名（如 `生产-订单服务`） |
| 主机 | IP 或域名 |
| 端口 | 默认 22 |
| 用户名 | root 或普通用户 |
| 认证 | 密码 / 密钥 |
| 备注 | 用途标记（生产/测试环境隔离） |

```text
连接后界面（三栏式）：
  左侧：文件管理器（SFTP）
  中间：终端窗口
  右侧：实时监控面板
```

> 💡 **命名规范**：`环境-角色`（`生产-网关`、`测试-数据库`）——服务器多了以后，命名即索引。

## 3. 认证方式：密码与密钥

### 3.1 密码认证

```text
创建会话 → 认证方式选"密码" → 输入密码
建议：开启"记住密码"仅限个人电脑；生产服务器用密钥更安全
```

### 3.2 密钥认证（推荐）

```bash
# 服务器上生成密钥对
ssh-keygen -t ed25519 -C "your_email@example.com"   # 推荐 ed25519
# 公钥写入 authorized_keys
cat ~/.ssh/id_ed25519.pub >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys
```

```text
FinalShell 配置：
  会话 → 认证方式选"公钥" → 指定私钥文件路径
  支持 RSA / ED25519
  传输加密：AES-256
```

| 认证方式 | 安全 | 适用 |
|----------|------|------|
| 密码 | 中（可暴力破解） | 临时/个人服务器 |
| 密钥 | 高（无密码可登录） | **生产推荐** |
| 密钥+口令 | 最高 | 高安全场景 |

> 💡 生产纪律：**禁用 root 密码登录 + 密钥认证 + 仅允许特定 IP**（`sshd_config` 配置）——结合 Ubuntu/Linux 体系的安全章节。

## 4. 多服务器管理

| 能力 | 说明 |
|------|------|
| 多标签 | 一个窗口管理多台服务器（标签切换） |
| 分屏 | 同时查看多台（对比日志/配置） |
| 会话分组 | 按环境/项目分组管理 |
| 批量执行 | 同时对多台执行同一命令（见 [03](03-高级功能与生产实践.md)） |
| 命令历史 | 每台服务器的历史命令保存（永久） |

```text
典型场景：
  三台服务器分屏：应用日志 / 数据库 / 网关
  批量执行：所有节点同步 `systemctl restart app`
```

> 🎯 多标签 + 分屏是 FinalShell 的效率基础：**"一屏看多机"**让对比排查（配置差异/日志对比）不再来回切换。

## 5. 连接稳定性：编码与保活

### 5.1 中文乱码

```text
现象：服务器输出中文乱码
解决：会话设置 → 编码改为 GBK（部分系统默认 GBK）或 UTF-8
确认：服务器 `locale` 命令查看默认编码
```

### 5.2 连接保活（Keep-Alive）

```text
现象：长时间无操作后连接断开（防火墙/网络空闲超时）
解决：会话设置 → 开启"发送心跳包"，间隔 30-60 秒
```

> ⚠️ **保活是运维基本功**：长任务（日志跟踪/构建）中途断连 = 任务中断——开启心跳包 + 长任务用 `nohup`/`tmux` 双保险。

## 6. 常见连接问题

| 问题 | 原因 | 解决 |
|------|------|------|
| Connection refused | 端口不对/sshd 未启动 | 检查 22 端口与 sshd 状态 |
| 连接超时 | 防火墙/安全组 | 放行 22 端口（云安全组） |
| 认证失败 | 密码错/密钥不匹配 | 确认密码；密钥重新部署 |
| 中文乱码 | 编码不一致 | 会话编码改 GBK/UTF-8 |
| 频繁断连 | 无心跳包 | 开启 Keep-Alive（30-60s） |
| 密钥权限错 | authorized_keys 权限 | `chmod 600` + 属主正确 |

## 7. 核心要点

> 🎯 **核心要点**：
> - 三栏界面：左侧文件、中间终端、右侧监控——一个窗口闭环；
> - 命名规范 `环境-角色` 是服务器多了以后的第一生产力；
> - 生产用密钥认证（ED25519）+ 禁用密码 root 登录；
> - 编码 GBK/UTF-8 与心跳包（30-60s）是连接稳定性的两个开关；
> - 多标签分屏 + 批量命令 = 多机管理效率基础。
