## 1. 端口转发（隧道）

```text
SSH 端口转发：通过 SSH 加密隧道访问内网/受限服务
```

| 隧道类型 | 方向 | 场景 |
|----------|------|------|
| 本地转发 | 本地端口 → 服务器 → 目标 | 本地访问服务器内网服务（数据库/管理台） |
| 远程转发 | 服务器端口 → 本地 → 目标 | 内网穿透（服务器访问本地服务） |
| 动态转发 | SOCKS 代理 | 全局代理访问受限网络 |

```text
配置方式（可视化）：
  右键服务器 → "端口转发" → 添加规则
  本地端口：3307 → 目标地址：127.0.0.1:3306（服务器内网 MySQL）
  保存后本地 3307 即连接服务器内网数据库
```

| 典型场景 | 配置 |
|----------|------|
| 本地连服务器内网 MySQL | 本地 3307 → 127.0.0.1:3306 |
| 本地访问服务器内网管理台 | 本地 8080 → 127.0.0.1:8080 |
| 数据库备份到本地 | 本地转发 + 备份工具 |

> 🎯 **端口转发的价值**：**不暴露生产数据库/管理台到公网**——用 SSH 隧道按需访问，安全且灵活（比安全组开端口更安全）。

## 2. 跳板机与代理链

```text
场景：生产环境只能通过堡垒机/跳板机访问
FinalShell 支持代理链（多层跳转）：
  本地 → 跳板机 A → 跳板机 B → 目标服务器
```

| 能力 | 说明 |
|------|------|
| 代理链 | 多层堡垒机逐级跳转 |
| 会话代理 | 目标服务器会话指定"通过代理连接" |
| 可视化配置 | 代理链图形化（不用手写 ProxyCommand） |

```text
配置方式：
  ① 先创建跳板机会话
  ② 目标服务器会话 → 高级设置 → 代理 → 选择跳板机
  ③ 连接时自动经跳板机跳转
```

> 💡 多层跳板的替代：本地 SSH config `ProxyJump` 也能实现——FinalShell 的价值是**可视化**（不用记配置语法）。

## 3. 批量执行与命令面板

### 3.1 批量执行

```text
场景：多台服务器执行同一命令（升级依赖/同步配置/批量重启）
```

| 能力 | 说明 |
|------|------|
| 命令同步 | 选多台服务器 → 输入命令 → 同时执行 |
| 结果对比 | 各台输出对比查看 |
| 免费版限制 | 同时同步的服务器数有限（专业版无限制） |

```text
典型场景：
  所有节点：systemctl restart nginx
  所有节点：更新 hosts / 部署新版本
  集群节点：查看版本（输出对比）
```

### 3.2 命令面板

```text
命令面板 = 常用命令的快捷按钮（支持变量替换）
```

| 命令 | 变量示例 |
|------|---------|
| 查磁盘 | `df -h` |
| 查内存 | `free -m` |
| 看日志 | `tail -f /app/logs/{服务名}.log` |
| 重启服务 | `systemctl restart {服务名}` |
| Java 线程 | `jstack {PID}` |

> 🎯 **命令面板的价值**：高频运维命令"一键执行"——服务器多了以后不用每次手敲，且**变量替换**（服务名/PID）让同一命令适配多服务器。

## 5. 免费版 vs 专业版

| 能力 | 免费版 | 专业版 |
|------|:---:|:---:|
| SSH 连接数 | 无限制 | 无限制 |
| 广告 | ✅ 有 | ❌ 去除 |
| 标签页数 | 有限制 | 无限制 |
| 命令同步服务器数 | 有限制 | 无限制 |
| 配置云同步 | ❌ | ✅ |
| 海外加速/高级脚本 | 付费增值 | 付费增值 |

> 💡 个人使用免费版足够（广告可接受）；频繁多机操作/多设备同步 → 专业版（去广告+无限制+云同步）。

## 6. 与 Xshell 对比选型

| 维度 | FinalShell | Xshell + Xftp |
|------|-----------|---------------|
| 一体化 | ✅ 终端+文件+监控 | 双工具 |
| 实时监控 | ✅ 独家内置 | ❌ |
| 中文 | ✅ 原生 | ✅ |
| 免费 | 免费版（广告） | 个人免费/商业收费 |
| 平台 | Win/Mac/Linux | Win 为主 |
| 稳定性口碑 | 良好（偶有更新问题） | 老牌稳定 |
| 适用 | **新手/全功能需求/中文环境** | 已习惯双工具的老用户 |

| 选择场景 | 推荐 |
|----------|------|
| 新手/要一体化 | FinalShell |
| 想看服务器状态 | FinalShell（监控内置） |
| 老 Xshell 用户/企业采购 | Xshell（生态成熟） |
| 双工具已成习惯 | Xshell + Xftp 保留 |

> 🎯 **结论**：不是"谁取代谁"，是"哪个流程更适合你"——FinalShell 赢在**一体化与监控**，Xshell 赢在**老牌稳定与生态**。

## 7. 生产避坑清单

| # | 坑 | 规避 |
|---|----|------|
| 1 | 从非官方渠道下载 | 官网下载（hostbuf.com） |
| 2 | 密码登录生产 root | 密钥认证 + 禁密码 root |
| 3 | 大文件拖拽传输 | >500MB 用 rsync |
| 4 | 端口转发忘关 | 用完删除规则（隧道即暴露面） |
| 5 | 批量命令误执行 | 批量前先在一台验证 |
| 6 | kill 进程未确认 | 先看命令行/父进程再 kill |
| 7 | 忽略心跳包 | 长任务前确认 Keep-Alive |
| 8 | 会话命名混乱 | `环境-角色` 命名规范 |
| 9 | 广告版生产长期挂 | 专业版或接受广告（工具不影响功能） |
| 10 | 安全组全开 | 只开必要端口，管理走隧道 |

## 8. 核心要点

> 🎯 **核心要点**：
> - 端口转发三类型：本地（访问内网）、远程（穿透）、动态（SOCKS）——**不暴露公网端口的管理姿势**；
> - 跳板机可视化：代理链多层跳转不用记 ProxyCommand；
> - 批量执行 + 命令面板（变量替换）= 多机运维效率杠杆；
> - 选型：一体化+监控选 FinalShell，老牌生态选 Xshell；
> - 避坑 Top3：非官方下载、密码 root、大文件拖拽；
> - 定位：FinalShell 是"日常运维的瑞士军刀"，深度排障联动网络问题排查/日志监控指标体系。
