## 2. 创建会话

```text
新建会话流程：
  文件 → 新建 → 协议（SSH 默认 22）
  → 主机（IP/域名）→ 端口 → 用户名
  → 认证方式（密码/公钥）→ 连接
```

| 配置项 | 说明 |
|--------|------|
| 名称 | 会话名（`环境-角色` 命名规范） |
| 协议 | SSH/Telnet/串口/RDP/本地 Shell |
| 主机 | IP 或域名 |
| 认证 | 密码/公钥（见第 4 节） |
| 跳板 | 通过代理会话连接（见 [03](03-高级功能与生产实践.md)） |

> 💡 会话是 Xshell 的灵魂：**一次配置，双击即连**——服务器多了以后，"会话管理器"就是你的服务器索引。

## 3. 会话管理（核心能力）

| 能力 | 说明 |
|------|------|
| 会话保存 | 连接信息持久化（IP/端口/用户/认证） |
| 文件夹分组 | 按环境/项目分组（生产/测试/开发） |
| 凭据保存 | 用户名+密码+私钥口令永久保存（免密连接） |
| 会话导出/导入 | 多机同步配置（配合主密码） |
| 双击即连 | 无需重复输入任何信息 |

```text
文件夹分组示例：
  会话管理器
  ├─ 生产环境（网关/订单/支付）
  ├─ 测试环境（test-db/test-app）
  └─ 开发（dev-server）
```

> 🎯 **会话管理的价值**：**把"连服务器"从每次输入 IP+密码变成双击**——配合分组，几十台服务器的管理成本趋近于零。

## 4. 认证方式

| 认证 | 说明 | 推荐度 |
|------|------|:---:|
| 密码 | 简单，可暴力破解 | ⚠️ 临时 |
| 公钥（RSA/DSA/ECDSA/ED25519） | 安全，免密 | ✅ 生产推荐 |
| PKCS#11 | 硬件令牌（U 盾） | 高安全 |
| GSSAPI | Kerberos 集成（企业域） | 企业 |
| SSH CA | 证书签名认证 | 大规模管理 |

```bash
# 服务器生成密钥（ED25519 推荐）
ssh-keygen -t ed25519
cat ~/.ssh/id_ed25519.pub >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys
```

```text
Xshell 配置公钥：
  工具 → 用户密钥管理者 → 导入/生成密钥
  会话 → 认证 → 公钥 → 选择密钥
```

> 💡 Xshell 支持**密钥导入与生成**（工具→用户密钥管理者），生成的密钥对可直接部署到服务器——密钥管理是它的传统强项。

## 5. 主密码保护

```text
主密码（Master Password）：
  用主密码加密所有会话文件与登录凭据
  启动 Xshell 时输入主密码才能解锁会话

价值：
  凭据保存 + 主密码 = 笔记本丢了也不泄露服务器密码
```

| 场景 | 建议 |
|------|------|
| 个人电脑 | 可开（防他人使用） |
| 共享电脑 | **必开** |
| 高安全环境 | 必开 + 定期改主密码 |

> ⚠️ **主密码丢失 = 会话无法解锁**（不可找回）——设置后务必记住；与密码管理器配合使用。

## 6. 多标签与批量命令

### 6.1 多标签

| 能力 | 说明 |
|------|------|
| 多标签 | 一个窗口管理多台服务器 |
| 分屏 | 同时查看多台（对比日志） |
| 会话切换 | 标签间秒切 |

### 6.2 发送到所有会话（批量命令）

```text
场景：多台服务器执行同一命令
操作：视图 → 撰写窗格（Compose Bar）→ 勾选目标会话 → 输入命令 → 发送

或：工具 → "发送到所有会话"
```

```text
典型场景：
  所有节点 systemctl restart app
  所有节点更新 hosts
  集群检查版本（输出对比）
```

> 💡 **批量命令纪律**：先在一台验证命令正确，再批量发送；**只读命令（查看）批量安全，写操作（重启/删除）谨慎**。

## 7. 常见连接问题

| 问题 | 原因 | 解决 |
|------|------|------|
| Connection refused | sshd 未启动/端口错 | 检查 22 端口 |
| 认证失败 | 密码错/密钥不匹配 | 确认凭据；重新部署公钥 |
| 连接超时 | 防火墙/安全组 | 放行 22 端口 |
| 中文乱码 | 编码不一致 | 会话编码改 UTF-8/GBK |
| 频繁断连 | 无保活 | 会话属性开启 Keep-Alive |
| 主密码忘 | 无法解锁 | 无解（只能重建会话）——务必记住 |

## 8. 核心要点

> 🎯 **核心要点**：
> - 会话管理是 Xshell 的灵魂：分组 + 凭据保存 + 双击即连；
> - 认证全家桶：密码/公钥（ED25519 推荐）/PKCS#11/GSSAPI/SSH CA；
> - **主密码**保护会话文件与凭据（共享电脑必开）；
> - 批量命令：先单台验证再批量，写操作谨慎；
> - 命名规范 `环境-角色` + 文件夹分组 = 服务器索引；
> - Windows 平台首选，个人/学校免费。
