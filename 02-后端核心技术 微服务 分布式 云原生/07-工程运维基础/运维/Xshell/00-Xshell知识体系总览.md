## 4. 定位：与 FinalShell 对比

| 维度 | Xshell + Xftp | FinalShell |
|------|---------------|-----------|
| 形态 | 双工具组合（终端+文件） | 单工具四合一（含监控） |
| 平台 | **Windows 为主** | Win/Mac/Linux |
| 实时监控 | ❌ | ✅ 内置 |
| 会话管理 | ✅ 老牌成熟（主密码加密） | ✅ |
| 脚本自动化 | ✅ 脚本录制/触发器 | ⚠️ 基础 |
| 跳板机 | ✅ Jump Host 代理 | ✅ 代理链 |
| 免费 | 个人/学校免费 | 免费版（广告） |
| 稳定性 | 老牌稳定 | 良好 |
| 适合 | **Windows 老用户/企业采购** | 全平台/一体化需求 |

> 🎯 **选型结论**：Windows 平台、习惯双工具、要脚本自动化 → Xshell + Xftp；要一体化+监控+跨平台 → FinalShell（详见 FinalShell 体系对比章节）。

## 6. 核心功能速查

| 功能 | 一句话 |
|------|--------|
| SSH 终端 | SSH1/2、Telnet、串口、RDP 多协议 |
| 会话管理 | 保存连接、文件夹分组、凭据保存（主密码加密） |
| 多标签 | 并行管理多会话、分屏 |
| 批量命令 | "发送到所有会话" |
| 密钥认证 | RSA/DSA/ECDSA/ED25519/PKCS#11/GSSAPI |
| 跳板机 | Jump Host 代理（多层跳转） |
| 端口转发 | 本地/远程/动态隧道 + X11 |
| 脚本自动化 | 脚本录制回放、快捷命令、触发器 |
| Xftp | SFTP/FTP/FXP、断点续传、文件夹同步 |
| 本地集成 | 本地 Shell/WSL/PowerShell 标签 |
