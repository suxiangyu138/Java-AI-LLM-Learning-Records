## 1. Xftp 定位

```text
Xftp 8 = 专业的 SFTP/FTP 文件传输客户端
  SFTP（SSH 加密传输，推荐）
  FTP/FTPS
  与 Xshell 同厂配套（NetSarang）
```

| 能力 | 说明 |
|------|------|
| 拖放传输 | 本地 ↔ 服务器拖拽 |
| 断点续传 | 中断后继续 |
| 传输队列 | 批量任务管理/调度 |
| 文件夹同步 | 双向/单向同步 |
| 同步浏览 | 本地与远程目录联动定位 |
| 远程编辑 | 直接编辑服务器文件 |
| FXP | 服务器间直传（不经本地） |
| 传输加密 | 全程加密（SFTP） |

## 2. 与 Xshell 的协同

```text
一键协同（核心体验）：
  Xshell 工具栏 → "新建文件传输"按钮
  → Xftp 自动启动并连接到当前会话的服务器
  → 无需重新输入 IP/密码
```

| 场景 | 操作 |
|------|------|
| 终端看到日志 → 想看文件 | 工具栏一键打开 Xftp |
| 要传文件 → 又要在终端操作 | Xftp 传输 + Xshell 命令并行 |
| 多服务器 | 每个 Xshell 会话对应独立 Xftp 窗口 |

> 🎯 **协同价值**：**"Xshell 管命令行，Xftp 管传文件"**——一个按钮从终端切到文件管理器，无需重新认证。

## 3. 基础文件传输

| 操作 | 说明 |
|------|------|
| 上传 | 本地文件拖到右侧远程目录 |
| 下载 | 远程文件拖到左侧本地 |
| 传输队列 | 批量传输任务统一管理 |
| 覆盖策略 | 覆盖/跳过/重命名选择 |
| 权限设置 | 传输后批量 chmod |

```text
界面：
  左侧：本地目录树
  右侧：远程目录树
  底部：传输队列（进度/速度/状态）
```

> 💡 拖拽即传 + 队列管理——**多文件批量传输的体验是 Xftp 对比 scp 命令的核心优势**（可视化进度/暂停/续传）。

## 4. 断点续传与传输队列

| 能力 | 说明 |
|------|------|
| 断点续传 | 中断后从断点继续（大文件必备） |
| 传输调度 | 指定时间传输（低峰期） |
| 传输队列 | 暂停/恢复/重试单个或全部 |
| 限速 | 限制带宽（不影响业务） |

```text
大文件纪律（同 FinalShell）：
  > 500MB 大文件：Xftp 断点续传可用，但 rsync 更可靠（增量+脚本化）
  数据库备份：服务器内操作（mysqldump），再选择性下载
```

> ⚠️ 大文件传输的三个选择：小文件 → 拖拽；大文件一次性 → Xftp 断点续传；**超大/增量 → rsync**（可靠性优先）。

## 5. FXP：服务器间直传

```text
FXP = 两台服务器之间直接传输（不经本地中转）
  场景：服务器 A 的大文件复制到服务器 B
  优势：不占用本地带宽、不经过本地磁盘
```

```text
操作：
  ① 打开两个 Xftp 窗口（服务器 A / 服务器 B）
  ② 一个窗口的远程目录拖到另一个窗口的远程目录
  ③ 走 FXP 直传（需双方服务器支持）
```

| 对比 | 普通方式 | FXP |
|------|---------|-----|
| 路径 | A → 本地 → B | A → B（直连） |
| 带宽 | 占用本地上下行 | 服务器间带宽 |
| 适用 | 小文件 | **服务器间大文件**（备份/迁移） |

> 💡 FXP 的典型场景：**服务器迁移/备份复制**——大文件不经本地，省时省带宽。

## 6. 文件夹同步与同步浏览

### 6.1 文件夹同步

```text
场景：本地开发目录 ↔ 服务器部署目录保持同步
操作：工具 → 同步文件夹 → 选择方向（上传/下载/双向）
```

| 同步模式 | 说明 |
|----------|------|
| 上传（本地→远程） | 部署场景（代码/静态资源） |
| 下载（远程→本地） | 备份场景 |
| 双向 | 开发与服务器互同步（注意冲突） |

### 6.2 同步浏览

```text
同步浏览（Synchronized Browsing）：
  本地切换目录 → 远程自动切换到对应目录
  方便对比/定位（如对比本地与服务器的配置目录）
```

> 🎯 **文件夹同步的价值**：部署不再是"每次拖一堆文件"——**一键同步整个目录**（前端 dist、配置文件目录）。

## 7. Java 部署场景文件操作

```text
Java 后端日常（Xshell + Xftp 组合）：
  ① 部署 JAR：Xftp 拖拽上传 → Xshell 重启服务
  ② 改配置：Xftp 远程编辑（或下载改后传回）
  ③ 看日志：Xshell tail -f（或 Xftp 双击日志文件）
  ④ 证书/密钥：上传 → chmod 600（Xftp 权限设置）
  ⑤ 同步：本地配置目录 → 服务器（文件夹同步）
```

| 场景 | 工具分工 |
|------|---------|
| 上传 JAR + 重启 | Xftp 上传 → Xshell 重启 |
| 改 application.yml | Xftp 远程编辑 |
| 看日志 | Xshell tail -f |
| 传证书 | Xftp + 权限设置 |
| 前端部署 | 文件夹同步 |

> 💡 **组合拳**：Xftp 负责"文件在哪"，Xshell 负责"命令做什么"——部署全程两个窗口协同，不切工具。

## 8. 核心要点

> 🎯 **核心要点**：
> - 定位：SFTP/FTP 专业传输客户端，**"Xshell 管命令，Xftp 管文件"**；
> - 一键协同：Xshell 工具栏"新建文件传输"→ Xftp 自动连当前会话（零重新认证）；
> - 四大利器：断点续传、FXP 服务器间直传、文件夹同步、同步浏览；
> - 大文件纪律：拖拽（小）→ 断点续传（大）→ rsync（超大/增量）；
> - Java 部署组合拳：Xftp 传文件 + Xshell 执行命令；
> - 同步场景：前端 dist、配置目录一键同步。
