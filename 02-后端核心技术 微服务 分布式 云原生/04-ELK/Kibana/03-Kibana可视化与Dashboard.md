## 1. 可视化体系总览

### 1.1 Kibana 可视化工具演进

| 工具 | 时代 | 定位 | 现状 |
|------|------|------|------|
| 老式可视化（TSVB/Vega 等） | 7.x 前 | 各类型独立编辑器 | 逐步淘汰 |
| **Lens** | 7.x-9.x | 拖拽式统一编辑器 | **主力推荐** |
| ES|QL 可视化 | 9.1+ | 管道查询直接出图 | 9.x 新方向 |
| Canvas | 7.x-9.x | 像素级自定义 | 维护模式 |
| 嵌入报表 | 9.x | 报告导出 | 订阅功能 |

> 🎯 9.x 选型：**新可视化一律用 Lens 或 ES|QL**，老式编辑器仅用于迁移存量面板。

### 1.2 可视化数据流

```text
数据视图/ES|QL → 聚合查询（ES 执行） → 图表渲染（前端） → Dashboard 组装
```

## 2. Lens：拖拽式可视化编辑器

### 2.1 Lens 界面结构

```text
┌────────────────────────────────────────────┐
│ 数据源选择（数据视图 / ES|QL）              │
├────────────────────────────────────────────┤
│ 左侧：字段列表（拖拽到配置区）              │
│ 右侧配置区：                               │
│   · Metric 指标（数值聚合）                 │
│   · X 轴（分组字段/日期直方图）             │
│   · Breakdown（分组细化）                   │
│   · 过滤器（面板级过滤）                    │
└────────────────────────────────────────────┘
```

### 2.2 核心配置项

| 配置项 | 说明 | 示例 |
|------|------|------|
| 指标 | 聚合方式 + 字段 | 计数、平均值、百分位、Top 值 |
| X 轴 | 分组维度 | 时间直方图（自动间隔）、服务名 |
| Breakdown | 细分系列 | 按 level 拆分柱状图 |
| 过滤器 | 面板内过滤 | 只统计 ERROR 日志 |
| 参考线 | 阈值标记 | 响应时间 500ms 红线 |
| 颜色 | 调色板 | 状态色板（9.x 默认） |

### 2.3 常用聚合类型

| 聚合 | 适用 |
|------|------|
| Count | 命中数（日志量曲线） |
| Average / Sum / Min / Max | 数值指标 |
| Percentile（P95/P99） | 延迟分析 |
| Unique Count | 去重统计（活跃用户/IP） |
| Top Values | 高频值（报错 Top 接口） |
| Date Histogram | 时间分布（默认 X 轴） |

> 💡 9.x 提示：Top values 默认分类数在 9.x 提升到 9 个；Gauge 默认配色改为状态色板。

## 3. 图表类型与选型

### 3.1 图表选型表（面试/实战速查）

| 场景 | 推荐图表 | 说明 |
|------|------|------|
| 日志量随时间 | 柱状图/面积图 | X 轴时间直方图 |
| 错误码占比 | 饼图/环形图 | Top Values + 百分比 |
| 响应延迟趋势 | 折线图（P50/P95/P99 多线） | 多指标对比 |
| 服务对比 | 分组柱状图 | Breakdown by service |
| 单值指标 | Metric（大数字） | 今日错误总数 |
| 状态分布 | 饼图/环形图 | level 分布 |
| 地理分布 | 地图（region_map） | IP 归属（需 geoip） |
| 阈值监控 | Gauge（仪表盘） | 带警戒阈值 |

### 3.2 时间序列对比（折线 vs 柱状 vs 面积）

| 类型 | 特点 | 适用 |
|------|------|------|
| 折线图 | 连续趋势、多系列对比 | 延迟/吞吐趋势 |
| 柱状图 | 离散对比、峰值明显 | 按小时/天统计 |
| 面积图 | 强调总量与占比 | 堆叠看各服务占比 |

## 4. ES|QL 可视化

### 4.1 创建 ES|QL 可视化（9.1+ GA）

```sql
-- 例：按服务统计 1 小时内的错误数 Top 10
FROM logs-*
| WHERE level == "ERROR" AND @timestamp > now() - 1h
| STATS error_count = COUNT(*) BY service.name
| SORT error_count DESC
| LIMIT 10
```

### 4.2 ES|QL 可视化的工程要点（2026 现状）

| 要点 | 说明 |
|------|------|
| 版本 | 9.1 起 GA；9.2 图表配置持久化 GA |
| 全局过滤器 | 图层可设置「Use global filters」忽略 Dashboard 全局过滤 |
| 自动 LIMIT | 9.x 已不再自动追加 `LIMIT 10` |
| 多字段分组 | 9.4 起柱状/折线/面积支持多字段 Breakdown |
| 下钻 | 支持 Dashboard 与 URL 两种 drilldown |
| 对比 KQL 面板 | ES|QL 面板适用于「管道分析」类，KQL 面板适合「过滤 + 简单聚合」 |

> 🎯 选型建议：**统计报表类优先 ES|QL**（写一次查询既出数又出图），**交互探索类用 Lens**（拖拽改维度更快）。

## 5. Dashboard：面板组装与布局

### 5.1 创建 Dashboard 流程

```text
① 新建 Dashboard → Add panel
② 选择：新 Lens / 新 ES|QL / 已保存的可视化或搜索
③ 拖拽调整位置与大小
④ 设置面板标题、颜色、描述
⑤ 保存（Saved Object：dashboard-xxx）
```

### 5.2 面板布局技巧

| 技巧 | 说明 |
|------|------|
| 网格对齐 | 拖动时自动对齐网格，保持视觉整齐 |
| 面板分组 | 同主题面板相邻（错误概览 / 延迟分析 / 容量） |
| 颜色一致 | 同类指标统一颜色（错误红、吞吐蓝） |
| 时间同步 | 所有面板共享 Dashboard 时间范围 |
| 刷新策略 | 看板级 Auto refresh（1m 常见） |

### 5.3 典型日志看板结构（生产模板）

```text
┌─────────────────────────────────────────────┐
│ 顶部 Metric 行：今日错误总数 / 平均延迟 / 吞吐 │
├──────────┬──────────┬───────────────────────┤
│ 错误趋势 │ 错误 Top │ 延迟 P50/P95/P99       │
│ （面积图）│ 接口（表）│ （多线折线）           │
├──────────┴──────────┼───────────────────────┤
│ 按服务堆叠柱状图     │ 错误分布环形图          │
└─────────────────────┴───────────────────────┘
```

## 6. 交互：过滤器联动与下钻

### 6.1 Dashboard 全局过滤器

| 方式 | 说明 |
|------|------|
| 顶部过滤器栏 | 添加 KQL 过滤器，作用于所有面板 |
| 面板内过滤 | 只影响单个面板 |
| 点击联动 | 点击柱状图某柱子 → 创建临时过滤（9.x 行为） |

### 6.2 下钻（Drilldown）

| 类型 | 说明 |
|------|------|
| Dashboard 下钻 | 点击面板跳转到另一个 Dashboard（携带过滤上下文） |
| URL 下钻 | 跳转到外部 URL（携带参数） |
| 典型场景 | 总览看板 → 点击服务 → 跳转该服务明细看板 |

## 7. Canvas 与报表导出

### 7.1 Canvas（维护模式）

| 维度 | 说明 |
|------|------|
| 定位 | 像素级自由布局（适合对外大屏） |

## 8. 可视化性能与最佳实践

### 8.1 面板性能清单

| 问题 | 优化 |
|------|------|
| 面板加载慢 | 缩小时间范围、减少字段、用 ES|QL 预聚合 |
| 数据量过大 | `LIMIT` 控制、加 Breakdown 减少聚合桶 |
| 请求过多 | 减少面板数量、合并相关面板 |
| 高基数分组 | 分组字段选低基数（service 而非 request_id） |
| 时间粒度 | 长时间范围用粗粒度直方图（1h 而非 1m） |

### 8.2 可视化最佳实践

```text
① 一个面板回答一个问题（错误率、延迟、容量）
② 指标口径统一（P95 在哪都指同一个定义）
③ 时间粒度与时间范围匹配（1 天看小时、30 天看天）
④ 关键阈值加参考线（SLO 红线）
⑤ 面板命名规范（「服务名-指标-时间粒度」）
```

> 🎯 **核心要点**：Kibana 可视化三板斧——**Lens（拖拽探索，交互快）、ES|QL（管道分析，9.x 主力）、Dashboard（组装与联动）**。生产日志看板的标配结构 = Metric 概览行 + 错误/延迟/容量三区。记住三个 9.x 事实：ES|QL 可视化 9.1 GA（官方确认）、9.4 时间序列默认折线图 + Top value 默认 9 个系列（官方确认）、Canvas 进入维护模式。选图口诀：趋势用折线/面积、分布用柱状/饼图、单值用 Metric、阈值用 Gauge。
