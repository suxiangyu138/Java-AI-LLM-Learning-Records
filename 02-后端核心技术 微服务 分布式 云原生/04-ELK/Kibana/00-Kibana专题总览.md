## 2. 核心概念速查

| 概念 | 一句话 |
|------|------|
| Kibana | ES 的可视化与操作门户（Node.js 进程，端口 5601） |
| 版本对齐 | 与 ES 必须同主版本（9.x ↔ 9.x） |
| Data View | 数据视图：指向索引模式（如 `logs-*`） |
| KQL | 快速过滤语言（Discover 默认） |
| ES|QL | 管道式分析语言（9.x 主力，可视化 9.1 GA） |
| Lens | 拖拽式可视化编辑器（新可视化首选） |
| Dashboard | 多面板看板 + 全局过滤器联动 |
| Alerting | 规则 + 连接器 + 分组去重的告警体系 |
| Spaces | 团队级资源隔离 |
| ILM | 索引生命周期管理（热温冷删） |
| `.kibana_*` | Kibana 自身元数据索引（备份对象） |

## 4. 面试要点

| 问题 | 标准回答要点 |
|------|------|
| Kibana 与 ES 的关系？ | 门户 vs 引擎；版本严格对齐；数据请求全部代理给 ES |
| KQL vs ES|QL？ | KQL 快速过滤；ES|QL 管道分析，9.x 主力 |
| 日志看板怎么做？ | Metric 概览 + 错误/延迟/容量三区 + 分组收敛 |
| 告警怎么做？ | 规则（条件+频率）+ 连接器 + 分组去重 + 恢复必报 |
| 索引磁盘爆了？ | ILM：热温冷删 + rollover 滚动 |
| Kibana 慢？ | 90% 是 ES 慢：先查查询耗时，再调资源 |

> 🎯 **核心要点**：Kibana 七篇覆盖「部署 → 检索 → 可视化 → 告警 → 安全 → 运维」全链路。学习主线：**01 部署跑通 → 02 会查 → 03 会展示 → 04/05 会管 → 06 会排错**。面试记住一句话定位 + 三个 9.x 事实（ES|QL 可视化 GA、告警执行下沉 ES、Canvas 维护模式），其余按需翻篇。
