## 1. 高频面试题

### Q1（⭐⭐⭐⭐⭐）: Node.js 的事件循环是怎样的？

> 六个阶段循环：timers → pending callbacks → idle/prepare → poll → check → close callbacks
> 关键：微任务（Promise.then）在每个阶段之间执行，优先级高于宏任务
> `process.nextTick` 比 Promise 更优先

### Q2: CommonJS 和 ES Modules 的区别？

| 维度 | CommonJS | ES Modules |
|------|:---:|:---:|
| 加载 | 同步 | 异步 |
| 导出 | `module.exports` | `export` |
| 导入 | `require()` | `import` |
| this | 指向 module | undefined |
| 使用 | `"type": "commonjs"` | `"type": "module"` |
| 动态导入 | `require()` 随处可用 | `await import()` |

### Q3: Express 中间件原理？

> 中间件 = 函数链，每个函数 `(req, res, next)` → 调用 `next()` 传递给下一个 → 或者直接 `res.send()` 终止
> 顺序很重要：先注册的先执行

### Q4: async/await 的错误怎么处理？

> 1. `try-catch` 包裹 `await`
> 2. Promise 链末尾 `.catch()`
> 3. Express 全局错误中间件 `(err, req, res, next)`
> 4. `process.on('unhandledRejection')` 兜底

### Q5: 怎么做 MCP Server？

> 1. `@modelcontextprotocol/sdk` + Zod Schema
> 2. `server.tool(name, description, schema, handler)`
> 3. `StdioServerTransport` 本地 / `StreamableHTTPServerTransport` 远程
> 4. Claude Code 配置 `.mcp.json` 加载
