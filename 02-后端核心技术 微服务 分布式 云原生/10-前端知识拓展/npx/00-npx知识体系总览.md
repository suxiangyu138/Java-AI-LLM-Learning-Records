# 00 - npx 知识体系总览

> 🎯 npx 是 npm 的"执行搭档" — npm 负责"装"包，npx 负责"跑"包里的命令。无需全局安装即可执行任意 npm 包中的 CLI 工具，是前端工程化、脚手架初始化的第一入口。Java 后端理解 npx = 理解 `mvn exec:java` + `mvn archetype:generate` 的 Node.js 版本

## 4. 核心概念速查

| 概念 | 一句话 | Java 对标 |
|------|--------|----------|
| **npx** | 无需全局安装，直接执行 npm 包中的命令 | `mvn exec:java` |
| **npm exec** | npm 7+ 内置的官方命令，npx 是其兼容入口 | — |
| **npm x** | `npm exec` 的简写 | — |
| **临时安装** | 未安装的包会被临时下载到 `_npx` 缓存并执行 | Maven 自动下载依赖 |
| **本地优先** | 项目 `node_modules/.bin` 有的就用本地的 | 依赖当前 classpath |
| **脚手架** | `npx create-vite@latest` 一键生成项目 | `mvn archetype:generate` |
| **供应链风险** | npx 会下载并执行远程代码，需锁定版本 | 依赖漏洞需审计 |

---

> 🎯 **核心要点**：npx 让"零安装使用工具"成为可能 — 工具即服务，用完即走。但"远程拉取并执行"意味着每个 npx 命令都是一次供应链信任决策，安全章节必须看。
