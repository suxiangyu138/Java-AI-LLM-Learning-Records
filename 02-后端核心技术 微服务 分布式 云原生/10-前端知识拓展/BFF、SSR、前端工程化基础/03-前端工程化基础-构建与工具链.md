## 2. 包管理器对比

| 工具 | 速度 | 磁盘 | 锁文件 | 特点 |
|------|:---:|:---:|------|------|
| **npm** | ⭐⭐ | 中（扁平化） | `package-lock.json` | Node.js 默认 |
| **yarn** | ⭐⭐ | 中 | `yarn.lock` | Facebook 出品 |
| **pnpm** | ⭐⭐⭐ | 低（硬链接共享） | `pnpm-lock.yaml` | 最快、最省磁盘 |

```bash
# 常见命令
npm install          # 安装依赖
npm ci               # CI 环境严格安装
npm run dev          # 启动开发服务器
npm run build        # 生产构建
npx prettier --write .  # 格式化代码
```

## 3. 构建工具对比

| 工具 | 定位 | 速度 | 特点 |
|------|------|:---:|------|
| **Vite** | 现代构建工具 | ⭐⭐⭐ 极快 | ⭐ 前端开发主流（Vue/React 官方推荐） |
| **Webpack** | 老牌构建工具 | ⭐⭐ | 生态最丰富、但配置复杂 |
| **Turbopack** | Rust 构建工具 | ⭐⭐⭐ 极快 | Next.js 新绑定 |
| **esbuild** | Go 构建工具 | ⭐⭐⭐ 极快 | Vite 底层依赖 |
| **Rollup** | 库打包 | ⭐⭐ | 适合打包 npm 库 |

```javascript
// Vite 配置示例 — 类似 Maven pom.xml 的简洁配置
import { defineConfig } from 'vite';
import vue from '@vitejs/plugin-vue';

export default defineConfig({
  plugins: [vue()],
  server: {
    port: 3000,
    proxy: {                                 // ⭐ 开发环境代理
      '/api': {
        target: 'http://localhost:8080',     // → 转发到 Java 后端
        changeOrigin: true,
        rewrite: (path) => path.replace(/^\/api/, '')
      }
    }
  },
  build: {
    outDir: 'dist',                          // 构建产物目录（类似 Maven target/）
    assetsDir: 'assets',
    sourcemap: false
  }
});
```

### 构建产物

```text
npm run build 后：
  dist/
  ├── index.html               ← 入口 HTML
  ├── assets/
  │   ├── index-abc123.js      ← 带 Hash 的 JS（缓存友好）
  │   ├── index-abc123.css     ← 带 Hash 的 CSS
  │   └── logo-def456.svg      ← 静态资源
  └── favicon.ico

→ 整个 dist/ 部署到 Nginx 即可！
```

## 4. Java 项目中的前端集成

### 开发环境

```yaml
# Vite 开发代理 — 前端 localhost:3000 调后端 localhost:8080
# 开发时不用跨域！
```

```text
开发时：
  浏览器 → http://localhost:3000（Vite Dev Server）
    ├── /src/xxx.vue          → Vite 热更新
    └── /api/**               → Proxy → http://localhost:8080（Java）

生产构建：
  npm run build → dist/
  部署到 Nginx 或 Spring Boot static/ 目录
```

### 部署方式对比

| 方式 | 说明 | 适用 |
|------|------|------|
| **Nginx 分离部署** | dist/ → Nginx 静态目录 | ⭐ 生产推荐 |
| **Spring Boot 内嵌** | dist/ → src/main/resources/static/ | 小型项目 |
| **Docker 多阶段构建** | 先 npm build → 再 cp 到 Nginx | ⭐ 云原生 |
| **CDN 部署** | dist/ → OSS + CDN | 大流量 |

```dockerfile
# ⭐ Docker 多阶段：前端构建 + Nginx 部署
FROM node:20-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf
```

> 🎯 **后端记住**：Vite 开发用 Proxy 代理（告别跨域烦恼）、`npm run build` = `mvn package`、`dist/` = `target/`、`vite.config.ts` 是前端的 `pom.xml`。前端工程化和 Java 工程化是同一套思想的不同实现。
