## 1. CSS 文艺复兴概述


## 2. 容器查询 Container Queries

### 2.1 核心概念

```
容器查询 = "组件时代的媒体查询"：
  媒体查询基于视口（viewport）
  容器查询基于"自身父容器"的尺寸

⚠️ 面试必答：
"媒体查询回答'视口多宽'、
 容器查询回答'我的容器多宽'——
 组件复用（侧边栏/弹窗/卡片）必须用容器查询。"
```

### 2.2 基本用法

```css
/* ① 定义容器 */
.card-wrapper {
    container-type: inline-size;     /* 查询内联尺寸（水平） */
    container-name: card;            /* 命名（可选，多容器区分） */
}

/* ② 容器查询 */
@container card (min-width: 400px) {
    .card {
        display: grid;
        grid-template-columns: 1fr 2fr;
    }
}

/* ③ 容器查询单位（流式排版） */
.hero-title {
    font-size: clamp(1.5rem, 5cqi, 3rem);   /* cqi = 容器内联尺寸 5% */
}
```

### 2.3 样式查询（Style Queries）

```css
/* 查询自定义属性（主题切换免类名） */
@container style(--tone: warning) {
    .badge { background: hsl(35 80% 90%); }
}

/* 父组件设置变量 → 子组件自动响应 */
.parent { --tone: warning; }
```

| 类型 | 语法 | 支持 |
|------|------|:---:|
| 尺寸查询 | `@container (min-width: 400px)` | ✅ 广泛 |
| 样式查询 | `@container style(--x: y)` | ✅ 2026-04 起 |
| 滚动状态 | `@container scroll-state(stuck: top)` | 草案中 |

## 3. View Transitions 视图过渡

### 3.1 同文档过渡

```javascript
// JS API：状态切换时调用
document.startViewTransition(() => {
    updateDOM();      // ⚠️ 回调内同步更新 DOM
});
```

```css
/* 定制过渡动画 */
::view-transition-old(root) { animation: fade-out 200ms; }
::view-transition-new(root) { animation: fade-in 200ms; }

/* 共享元素（hero 缩放效果） */
.thumbnail { view-transition-name: product-image; }
```

### 3.2 跨文档过渡（MPA 的革命）

```css
/* ⚠️ 多页应用零框架获得平滑过渡（2024+） */
@view-transition {
    navigation: auto;
}

/* 前后页面相同 view-transition-name → 自动共享元素动画 */
/* 限制：同源 + 用户发起的导航（点击/表单提交） */
```

| 场景 | 用法 |
|------|------|
| SPA 状态切换 | `document.startViewTransition()` |
| MPA 页面跳转 | `@view-transition { navigation: auto; }` |
| 共享元素 | 相同 `view-transition-name` |
| 减少动画 | `prefers-reduced-motion` 自动禁用 |

> 🎯 **要点**：View Transitions 让"多页应用拥有原生 App 过渡"——Next.js/Nuxt/Astro 已内置支持。过渡在主线程外运行，不影响 Core Web Vitals。

## 4. CSS 嵌套与 :has()

### 4.1 CSS 嵌套（免 SCSS）

```css
/* 原生嵌套（2023+ 广泛支持） */
.card {
    padding: 16px;
    border-radius: 12px;

    /* 嵌套选择器 */
    &:hover {            /* = .card:hover */
        box-shadow: 0 8px 24px rgba(0,0,0,0.1);
    }
    .title {             /* = .card .title */
        font-weight: 600;
    }
    @media (max-width: 600px) {   /* 嵌套媒体查询 */
        padding: 8px;
    }
}
```

### 4.2 :has() 父选择器

```css
/* ⚠️ :has() = 按子元素/状态选父（2023 Baseline） */

/* 含徽章的卡片加边框 */
.card:has(.badge) { border-color: gold; }

/* 表单校验态（杀手级应用） */
form:has(input:invalid) .submit { opacity: 0.5; pointer-events: none; }

/* 有图标的输入框 */
.input-group:has(.icon) { padding-left: 32px; }

/* 选择器数量：相邻兄弟 */
h2:has(+ p) { margin-bottom: 0; }
```

> 🎯 **要点**：`:has()` 终结了"CSS 无法选父元素"的历史——表单校验态、组件状态样式（`figure:has(img)`）都是经典应用。配合 `:is()/:where()` 构成现代选择器三件套。

## 5. 锚点定位与 Popover

### 5.1 Popover API（原生弹出层）

```html
<!-- 2024+ 原生弹出层（免 JS/弹层库） -->
<button popovertarget="myPopover">打开菜单</button>

<div id="myPopover" popover>
    弹出内容
</div>
```

```css
/* 弹出层样式 */
#myPopover {
    margin: auto;
    border: none;
    border-radius: 8px;
    box-shadow: 0 8px 32px rgba(0,0,0,0.15);
    padding: 16px;
}
```

### 5.2 锚点定位（Anchor Positioning）

```css
/* 免 JS 的定位：工具提示/下拉定位（部分支持，2026 进行中） */
.tooltip {
    position: absolute;
    position-anchor: --trigger;       /* 锚定目标 */
    top: anchor(bottom);              /* 相对锚点定位 */
    left: anchor(center);
}

/* ⚠️ 渐进增强：不支持时优雅降级 */
```
