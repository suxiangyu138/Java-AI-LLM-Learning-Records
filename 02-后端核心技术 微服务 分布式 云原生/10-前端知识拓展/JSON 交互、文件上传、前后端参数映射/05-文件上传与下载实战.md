## 1. 基础文件上传

```java
@RestController
public class FileController {

    @PostMapping("/upload")
    public Result<String> upload(@RequestParam("file") MultipartFile file) throws IOException {
        // 获取原始文件名
        String originalName = file.getOriginalFilename();
        // 生成唯一文件名（防重名）
        String filename = UUID.randomUUID() + getExtension(originalName);
        // 保存
        Path dest = Path.of("/data/uploads", filename);
        Files.createDirectories(dest.getParent());
        file.transferTo(dest);

        return Result.ok("/files/" + filename);
    }

    // 多文件上传
    @PostMapping("/upload/batch")
    public Result<List<String>> upload(@RequestParam("files") MultipartFile[] files) {
        List<String> urls = Arrays.stream(files)
            .map(this::saveFile)
            .toList();
        return Result.ok(urls);
    }

    private String getExtension(String filename) {
        int i = filename.lastIndexOf('.');
        return i > 0 ? filename.substring(i) : "";
    }
}
```

## 2. 安全校验

```java
@Component
public class FileValidator {

    // ⚠️ 白名单 — 只允许这些类型！
    private static final Set<String> ALLOWED_EXTENSIONS = Set.of(
        "jpg", "jpeg", "png", "gif", "webp",     // 图片
        "pdf", "doc", "docx", "xls", "xlsx",     // 文档
        "zip"                                       // 压缩包
    );

    // 禁止的可执行类型
    private static final Set<String> BLOCKED_EXTENSIONS = Set.of(
        "jsp", "php", "exe", "sh", "bat", "py"
    );

    public void validate(MultipartFile file) {
        String ext = getExtension(Objects.requireNonNull(file.getOriginalFilename()))
            .toLowerCase().replace(".", "");

        // 1. 类型校验（白名单优先）
        if (!ALLOWED_EXTENSIONS.contains(ext)) {
            throw new BizException("不支持的文件类型: " + ext);
        }

        // 2. 大小校验（即使 yml 配置了，也加代码兜底）
        if (file.getSize() > 10 * 1024 * 1024) {
            throw new BizException("文件大小超过 10MB");
        }

        // 3. Magic Number 校验（防改后缀） ⭐
        try (InputStream in = file.getInputStream()) {
            byte[] magic = new byte[4];
            in.read(magic);
            // PNG: 89 50 4E 47,  JPEG: FF D8 FF E0
            if (!isValidImage(magic)) {
                throw new BizException("文件内容与扩展名不匹配");
            }
        } catch (IOException e) {
            throw new BizException("文件读取失败");
        }
    }
}
```

> ⚠️ **安全三件套**：白名单校验类型 + 大小限制 + Magic Number 防改后缀。这三个缺一个 = 安全隐患。

## 3. 大文件分片上传与秒传

```text
分片上传流程：
1. 前端将大文件切为 5MB 分片
2. 每片上传 → 后端存为临时文件
3. 全部上传完 → 合并分片 → 生成最终文件

秒传：
  上传前先计算文件 MD5 → 发给后端检查
  → 已存在 → 直接返回 URL（跳过上传）
```

```java
// 1. 检查是否已上传（秒传）
@GetMapping("/upload/check")
public Result<UploadCheckVO> check(@RequestParam String md5) {
    // 查询数据库是否已有相同 MD5 的文件
    FileInfo exist = fileService.findByMd5(md5);
    if (exist != null) {
        return Result.ok(UploadCheckVO.exists(exist.getUrl()));
    }
    // 返回已上传的分片序号
    List<Integer> uploaded = fileService.getUploadedChunks(md5);
    return Result.ok(UploadCheckVO.partial(uploaded));
}

// 2. 上传分片
@PostMapping("/upload/chunk")
public Result<?> uploadChunk(
    @RequestParam String md5,
    @RequestParam int index,
    @RequestParam("file") MultipartFile chunk) throws IOException {
    Path chunkPath = Path.of("/data/uploads/chunks", md5, String.valueOf(index));
    Files.createDirectories(chunkPath.getParent());
    chunk.transferTo(chunkPath);
    return Result.ok();
}

// 3. 合并分片
@PostMapping("/upload/merge")
public Result<String> merge(@RequestParam String md5,
                            @RequestParam String filename) throws IOException {
    Path dir = Path.of("/data/uploads/chunks", md5);
    Path dest = Path.of("/data/uploads", UUID.randomUUID() + getExtension(filename));

    try (OutputStream out = Files.newOutputStream(dest)) {
        Files.list(dir)
            .sorted(Comparator.comparingInt(p -> Integer.parseInt(p.getFileName().toString())))
            .forEach(chunk -> {
                try { Files.copy(chunk, out); Files.delete(chunk); }
                catch (IOException e) { throw new UncheckedIOException(e); }
            });
    }
    Files.delete(dir);  // 删除分片目录

    fileService.save(md5, filename, dest.toString());  // 记录 MD5
    return Result.ok("/files/" + dest.getFileName());
}
```

## 4. 文件下载

```java
@GetMapping("/download/{filename}")
public ResponseEntity<Resource> download(@PathVariable String filename) throws IOException {
    Path filePath = Path.of("/data/uploads", filename);
    Resource resource = new InputStreamResource(Files.newInputStream(filePath));

    return ResponseEntity.ok()
        .contentType(MediaType.APPLICATION_OCTET_STREAM)
        .header(HttpHeaders.CONTENT_DISPOSITION,
            "attachment; filename=\"" + URLEncoder.encode(filename, "UTF-8") + "\"")
        .contentLength(Files.size(filePath))
        .body(resource);
}
```

## 5. OSS 云存储集成

```java
// 阿里云 OSS / MinIO 统一接口
public interface FileStorage {
    String upload(String key, InputStream stream, String contentType);
    InputStream download(String key);
    void delete(String key);
    String getUrl(String key);
    boolean exists(String key);
}

// OSS 实现
@Service
public class OssFileStorage implements FileStorage {
    private final OSS ossClient;
    private final String bucket;

    @Override
    public String upload(String key, InputStream stream, String contentType) {
        ObjectMetadata meta = new ObjectMetadata();
        meta.setContentType(contentType);
        ossClient.putObject(bucket, key, stream, meta);
        return getUrl(key);
    }

    @Override
    public String getUrl(String key) {
        return String.format("https://%s.%s/%s", bucket, endpoint, key);
    }
}

// MinIO 实现（本地 S3 兼容 — 开发环境推荐）
@Service
```

| 方案 | 适用 | 特点 |
|------|------|------|
| **MinIO** | 开发/测试/自建 | S3 兼容、Docker 一键部署 |
| **阿里云 OSS** | 国内生产 | 稳定、CDN 加速、图片处理 |
| **本地磁盘** | 仅开发 | 简单但不可横向扩展 |

> 🎯 **文件上传铁律**：白名单类型 + Magic Number 防改后缀 + 大小限制 + UUID 防重名 + 路径不暴露原始文件名。大文件用分片+秒传，生产存 OSS/MinIO 而非本地磁盘。
