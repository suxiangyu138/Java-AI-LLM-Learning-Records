## 1. 参数来源三剑客

| 注解 | 来源 | 示例 |
|------|------|------|
| `@RequestParam` | URL 查询参数 / 表单 | `?name=张三&age=25` |
| `@PathVariable` | URL 路径 | `/users/{id}` |
| `@RequestBody` | HTTP Body（JSON） | `POST { "name": "张三" }` |

```java
@RestController
public class UserController {

    // ═══ @PathVariable — 路径参数 ═══
    @GetMapping("/users/{id}")
    public User getById(@PathVariable Long id) { ... }

    // ═══ @RequestParam — 查询参数 ═══
    @GetMapping("/users")
    public List<User> list(
        @RequestParam(defaultValue = "1") int page,
        @RequestParam(defaultValue = "20") int size,
        @RequestParam(required = false) String keyword) { ... }

    // ═══ @RequestBody — JSON Body ═══
    @PostMapping("/users")
    public Result<User> create(@RequestBody @Valid UserCreateDTO dto) { ... }

    // ═══ 混合使用 ═══
    @PutMapping("/users/{id}")
    public Result<User> update(
        @PathVariable Long id,
        @RequestBody @Valid UserUpdateDTO dto) { ... }

    // ═══ @RequestHeader — 请求头 ═══
    @GetMapping("/me")
    public User me(@RequestHeader("Authorization") String token) { ... }
}
```

| 场景 | 用哪个 |
|------|--------|
| 资源 ID | `@PathVariable` /users/{id} |
| 筛选/分页/搜索 | `@RequestParam` ?page=1&size=20 |
| 创建/修改（复杂结构） | `@RequestBody` + DTO |
| Token/Header 信息 | `@RequestHeader` |

## 2. 日期参数接收

```java
@RestController
public class OrderController {

    // ═══ 日期参数 ═══
    @GetMapping("/orders")
    public List<Order> list(
        @RequestParam @DateTimeFormat(pattern = "yyyy-MM-dd") LocalDate start,
        @RequestParam @DateTimeFormat(pattern = "yyyy-MM-dd HH:mm:ss") LocalDateTime end) {
        // GET /orders?start=2024-01-01&end=2024-01-15 10:00:00
    }

    // ═══ 枚举参数 ═══
    @GetMapping("/orders/filter")
    public List<Order> filter(@RequestParam OrderStatus status) {
        // GET /orders/filter?status=PAID
        // Spring 自动将 "PAID" → OrderStatus.PAID
    }
}
```

```java
// URL 参数中的数组接收
@GetMapping("/users")
public List<User> getByIds(@RequestParam List<Long> ids) {
    // GET /users?ids=1,2,3,4  → ids = [1,2,3,4]
}

// 或 POST JSON
@PostMapping("/users/batch")
public List<User> getByIds(@RequestBody List<Long> ids) {
    // POST [1,2,3,4]
}
```

## 3. 参数校验 @Valid

### 3.1 常用校验注解

| 注解 | 说明 | 示例 |
|------|------|------|
| `@NotNull` | 不能为 null | `@NotNull Long id` |
| `@NotBlank` | 不能为空字符串（trim后） | `@NotBlank String name` |
| `@NotEmpty` | 不能为 null 且长度>0 | `@NotEmpty List<Long> ids` |
| `@Size(min,max)` | 长度范围 | `@Size(min=2,max=30) String name` |
| `@Min/@Max` | 数值范围 | `@Min(18) int age` |
| `@Email` | 邮箱格式 | `@Email String email` |
| `@Pattern` | 正则匹配 | `@Pattern(regexp="^1[3-9]\\d{9}$")` |
| `@Valid` | 级联校验 | `@Valid Address address` |

```java
@Data
public class UserCreateDTO {
    @NotBlank(message = "姓名不能为空")
    @Size(min = 2, max = 30, message = "姓名长度 2-30")
    private String name;

    @NotNull(message = "年龄不能为空")
    @Min(value = 0, message = "年龄不能为负")
    @Max(value = 150, message = "年龄不合法")
    private Integer age;

    @Email(message = "邮箱格式错误")
    private String email;

    @Pattern(regexp = "^1[3-9]\\d{9}$", message = "手机号格式错误")
    private String phone;

    @Valid   // ⭐ 级联校验嵌套对象
    private Address address;
}
```

## 4. 分组校验与自定义校验

### 4.1 分组校验（创建 vs 更新）

```java
// 分组接口
public interface CreateGroup {}
public interface UpdateGroup {}

@Data
public class UserDTO {
    @NotNull(groups = UpdateGroup.class)      // 更新时 ID 必填
    private Long id;

    @NotBlank(groups = {CreateGroup.class, UpdateGroup.class})
    private String name;
}

@PostMapping("/users")
public Result<User> create(@RequestBody @Validated(CreateGroup.class) UserDTO dto) { }

@PutMapping("/users/{id}")
public Result<User> update(@RequestBody @Validated(UpdateGroup.class) UserDTO dto) { }
```

### 4.2 自定义校验注解

```java
@Target({ElementType.FIELD})
@Retention(RetentionPolicy.RUNTIME)
@Constraint(validatedBy = PhoneValidator.class)
public @interface Phone {
    String message() default "手机号格式错误";
    Class<?>[] groups() default {};
}

public class PhoneValidator implements ConstraintValidator<Phone, String> {
    private static final Pattern PATTERN = Pattern.compile("^1[3-9]\\d{9}$");

    @Override
    public boolean isValid(String value, ConstraintValidatorContext context) {
        return value == null || PATTERN.matcher(value).matches();
    }
}

// 使用
@Phone
private String phone;
```

> 🎯 **参数铁律**：URL 主键用 `@PathVariable`、筛选用 `@RequestParam`、复杂对象用 `@RequestBody` + DTO、必须校验用 `@Valid`、日期用 `@DateTimeFormat`、枚举直接写（Spring 自动转换）。
