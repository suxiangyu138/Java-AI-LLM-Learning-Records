## 1. 测试体系全景图

```
软件测试知识体系
│
├── 📐 测试理论基础
│   ├── 测试分类（按阶段/按方法/按目的）
│   ├── 测试原则（7大原则）
│   └── 测试心理学（开发者vs测试者思维差异）
│       → 01-软件测试核心.md
│
├── 🎯 用例设计方法
│   ├── 等价类划分 + 边界值分析
│   ├── 判定表 + 因果图 + 正交实验
│   ├── 场景法 + 状态转换测试
│   └── 错误推测 + 探索性测试
│       → 02-测试用例设计方法详解.md
│
├── 🔍 测试策略与覆盖
│   ├── 黑盒测试（功能/输入输出）
│   ├── 白盒测试（语句/分支/路径/条件覆盖）
│   ├── 灰盒测试（两者结合）
│   └── 测试充分性度量（覆盖率 vs 变异测试）
│       → 03-黑盒测试与白盒测试.md
│
├── 📋 测试管理
│   ├── 测试计划与测试策略
│   ├── 缺陷生命周期（提交→确认→修复→验证→关闭）
│   ├── 测试报告与度量
│   └── 测试团队与角色分工
│       → 04-测试管理与缺陷生命周期.md
│
├── ✅ 验收测试
│   ├── UAT用户验收测试
│   ├── Alpha测试 vs Beta测试
│   ├── 契约测试（Consumer-Driven Contract）
│   └── 验收标准（Acceptance Criteria）
│       → 05-验收测试与UAT.md
│
├── 🤖 测试自动化策略
│   ├── 什么该自动化，什么不该
│   ├── 自动化测试金字塔深度解读
│   ├── 自动化ROI评估
│   └── CI/CD中的测试分层策略
│       → 06-测试自动化策略.md
│
└── ⚡ 非功能性测试
    ├── 性能测试（负载/压力/稳定性/容量）
    ├── 安全测试（渗透测试/漏洞扫描）
    ├── 兼容性测试（浏览器/设备/OS）
    └── 可用性测试（用户体验/可访问性）
        → 07-非功能性测试.md
```

## 2. 与测试工具目录的关系

| 维度 | `软件测试/`（本目录） | `测试工具/`（兄弟目录） |
|------|---------------------|----------------------|
| **定位** | 测试**理论与方法论** | 测试**工具实操** |
| **内容** | 怎么设计测试、怎么管理测试 | JUnit怎么用、JMeter怎么配置 |
| **目标** | 培养测试思维 | 掌握测试技能 |
| **关系** | 理论指导实践 | 实践落地理论 |

> 💡 **学习建议**：先看本目录建立测试思维 → 再看测试工具目录上手实操 → 回到本目录深化理论基础。

## 4. 分层学习路线

### 🟢 开发者必学（1天）

```
上午：01-测试核心（理论基础） → 02-用例设计方法
下午：03-黑盒白盒（覆盖准则） → 06-自动化策略
```

### 🔵 测试工程师进阶（3天）

```
以上 + 04-测试管理 + 05-验收测试 + 07-非功能性测试
```
