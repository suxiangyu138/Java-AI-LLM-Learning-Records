## 1. 日志排查

| 命令 | 说明 | 示例 |
|------|------|------|
| `tail -f file.log` | 实时跟踪日志尾部 | `tail -f /var/log/app/spring.log` |
| `tail -n 200 file.log` | 查看最后 N 行 | `tail -n 500 catalina.out` |
| `grep ERROR file.log` | 过滤关键字行 | `grep "OutOfMemoryError" heap.log` |
| `grep -A5 -B5 err file.log` | 匹配行上下 N 行上下文 | `grep -B2 -A2 "500" access.log` |
| `grep -c ERROR file.log` | 统计匹配行数 | `grep -c "NullPointerException" app.log` |
| `less +F file.log` | 分页查看并支持 tail 模式 | `less +F /var/log/syslog` |
| `journalctl -u nginx` | systemd 服务日志 | `journalctl -u app.service --since "1h ago"` |
| `journalctl -f` | 实时查看系统日志 | `journalctl -xe -f` |

## 2. 端口与进程管理

| 命令 | 说明 | 示例 |
|------|------|------|
| `lsof -i :port` | 查看端口占用进程 | `lsof -i :8080` |
| `ss -tlnp` | 列出所有 TCP 监听端口 | `ss -tlnp \| grep :3306` |
| `ss -ant` | 列出所有 TCP 连接及状态 | `ss -ant \| awk '{print $1}' \| sort \| uniq -c` |
| `ps -ef \| grep java` | 查找 Java 进程 | `ps -ef \| grep '[j]ava'` |
| `pgrep -f "spring"` | 按模式查找进程 PID | `pgrep -fl java` |
| `jps -l -v` | JDK 进程列表 + JVM 参数 | `jps -l -v` |
| `kill -15 PID` | 优雅终止 (SIGTERM) | `kill -15 12345` |
| `kill -9 PID` | 强制终止 (SIGKILL) | `kill -9 12345` |
| `top -p PID` | 监控指定进程资源 | `top -p $(pgrep -f spring)` |
| `top -H -p PID` | 查看进程内线程 | `top -H -p $(pgrep -f java)` |
| `fuser -k 8080/tcp` | 杀死占用端口的进程 | `fuser -v 8080/tcp` |

## 3. 文件操作

| 命令 | 说明 | 示例 |
|------|------|------|
| `find . -name "*.log"` | 按名称查找文件 | `find /app -name "*.jar" -mtime -3` |
| `find . -type f -size +100M` | 查找大文件 | `find /opt -type f -size +500M` |
| `du -sh *` | 查看当前目录各项大小 | `du -sh --exclude=logs *` |
| `du -sh * \| sort -rh \| head` | 按大小排序 Top N | `du -sh /opt/* \| sort -rh \| head -10` |
| `tar -czf archive.tar.gz dir` | 打包压缩 | `tar -czf app-backup.tar.gz /app/` |
| `tar -xzf archive.tar.gz` | 解压 | `tar -xzf app-backup.tar.gz -C /opt/` |
| `rsync -avzP src/ dst/` | 增量同步（带进度） | `rsync -avzP --delete ./target/ deploy@server:/opt/` |
| `scp file user@host:/path` | 远程拷贝 | `scp app.jar root@10.0.0.5:/opt/app/` |
| `ln -s /path/to/target link` | 创建软链接 | `ln -snf /opt/myapp/versions/v1.1 /opt/myapp/current` |
| `stat file` | 查看文件详细信息（inode） | `stat app.jar` |

## 4. 系统监控

| 命令 | 说明 | 示例 |
|------|------|------|
| `top` / `htop` | 进程实时监控 | `top -o %MEM` |
| `free -h` | 内存使用情况 | `free -h` |
| `uptime` | 系统负载（1/5/15 分钟） | `uptime` |
| `vmstat 1 5` | CPU/内存/IO 统计 | `vmstat 2 10` |
| `mpstat -P ALL 1` | 各 CPU 核心利用率 | `mpstat -P ALL 1 5` |
| `dmesg \| tail -20` | 内核日志（OOM 等） | `dmesg \| grep -i oom` |
| `dmesg -T \| tail -20` | 带时间戳的内核日志 | `dmesg -T \| grep -i error` |
| `cat /proc/meminfo` | 详细内存信息 | `cat /proc/meminfo \| grep -E "MemTotal\|MemAvailable"` |
| `cat /proc/cpuinfo` | CPU 详细信息 | `cat /proc/cpuinfo \| grep "model name" \| uniq` |

## 5. 网络诊断

| 命令 | 说明 | 示例 |
|------|------|------|
| `curl -v http://host:port` | 调试 HTTP 请求 | `curl -s -o /dev/null -w "%{http_code}" http://localhost:8080/actuator/health` |
| `curl -I https://api.example.com` | 仅查看响应头 | `curl -I https://api.example.com` |
| `ping -c 4 host` | 连通性测试 | `ping -c 4 baidu.com` |
| `traceroute host` | 路由追踪 | `traceroute 10.0.0.1` |
| `nslookup domain` | DNS 解析 | `nslookup api.example.com` |
| `dig domain` | DNS 详细解析 | `dig +short api.example.com` |
| `telnet host port` | 测试 TCP 端口连通性 | `telnet db.internal 3306` |
| `nc -zv host port` | 端口扫描 | `nc -zv 10.0.0.2 22` |
| `tcpdump -i eth0 port 8080` | 抓包 | `tcpdump -i eth0 port 8080 -w capture.pcap` |
| `ss -s` | Socket 统计总览 | `ss -s` |

## 6. 磁盘管理

| 命令 | 说明 | 示例 |
|------|------|------|
| `df -h` | 磁盘分区使用量 | `df -h \| grep -v tmpfs` |
| `df -i` | inode 使用量 | `df -i` |
| `du -sh /path` | 目录总大小 | `du -sh /var/log` |
| `lsblk` | 块设备列表（树状） | `lsblk` |
| `blkid` | 块设备 UUID | `blkid /dev/sdb1` |
| `iostat -x 1` | 磁盘 IO 实时统计 | `iostat -x 1 5` |
| `iotop -o` | 进程级 IO 监控 | `sudo iotop -o` |
| `lsof \| grep deleted` | 排查已删除未释放文件 | `lsof \| grep deleted \| awk '{print $2}' \| sort -u` |
| `mount \| column -t` | 查看挂载信息 | `findmnt` |

## 7. 用户与权限

| 命令 | 说明 | 示例 |
|------|------|------|
| `who` / `w` | 当前登录用户 | `w` |
| `last -10` | 最近登录记录 | `last -10` |
| `id user` | 查看用户 UID/GID/组 | `id appuser` |
| `groups user` | 查看用户所属组 | `groups appuser` |
| `chmod 755 file` | 修改文件权限 | `chmod +x deploy.sh` |
| `chown user:group file` | 修改文件所有者 | `chown -R appuser:appuser /opt/app` |
| `getfacl file` | 查看 ACL 权限 | `getfacl /opt/myapp/config/` |
| `sudo -u user command` | 以指定用户身份执行 | `sudo -u appuser touch /opt/myapp/logs/test.log` |
| `visudo` | 安全编辑 sudoers | `visudo -f /etc/sudoers.d/myapp` |
| `getent passwd user` | 查询系统用户（NSS 统一入口） | `getent passwd appuser` |
| `usermod -aG group user` | 追加用户到组 | `usermod -aG docker appuser` |
| `setfacl -m u:user:rwx dir` | 设置 ACL 权限 | `setfacl -m u:nginx:r-- /etc/app.conf` |

## 8. 服务管理

| 命令 | 说明 | 示例 |
|------|------|------|
| `systemctl status svc` | 查看服务状态 | `systemctl status nginx` |
| `systemctl start/stop/restart svc` | 启停服务 | `systemctl restart order-app` |
| `systemctl enable --now svc` | 开机自启 + 立即启动 | `systemctl enable --now docker` |
| `systemctl daemon-reload` | 重载 Unit 文件（修改后必执行） | `systemctl daemon-reload` |
| `systemctl list-units --failed` | 列出失败服务 | `systemctl list-units --failed --type=service` |
| `journalctl -u svc -n 100` | 服务最近日志 | `journalctl -u app -n 200 --since "30 min ago"` |
| `journalctl -u svc -f` | 服务日志实时跟踪 | `journalctl -u app -f` |
| `journalctl --disk-usage` | 日志占用磁盘（可配限额） | `journalctl --vacuum-size=500M` |
| `crontab -l / -e` | 查看/编辑定时任务 | `crontab -l` |
| `sysctl -a` | 查看内核参数 | `sysctl net.ipv4.ip_local_port_range` |
| `sysctl -w key=value` | 临时修改内核参数 | `sysctl -w vm.max_map_count=262144` |
| `timedatectl set-timezone Asia/Shanghai` | 设置时区 | `timedatectl set-timezone Asia/Shanghai` |

## 9. Java 后端速查

| 场景 | 命令组合 | 说明 |
|------|---------|------|
| 后台启动 jar | `nohup java -Xms512m -Xmx1g -jar app.jar > app.log 2>&1 &` | 脱离终端运行（详见 03） |
| 优雅停止 | `kill -15 $(pgrep -f app.jar)` | SIGTERM 让 Spring 走停机钩子 |
| 查看 JVM 进程 | `jps -lv \| grep -E "order\|payment"` | 进程 + 启动参数（详见 09） |
| 线程栈快照 | `jstack -l PID > /tmp/thread.dump` | 死锁/阻塞定位（详见 09） |
| GC 观察 | `jstat -gcutil PID 2000` | 2 秒一次 GC 统计（详见 09） |
| 堆转储 | `jmap -dump:live,format=b,file=h.hprof PID` | 会 STW，线上慎用（详见 09） |
| 接口响应码 | `curl -s -o /dev/null -w "%{http_code}" :8080/actuator/health` | 健康检查 |
| 端口占用 | `ss -tlnp \| grep :8080` | 找监听进程 |
| 日志实时过滤 | `tail -f app.log \| grep --line-buffered ERROR` | 只留 ERROR 流 |
| 上下文排错 | `grep -A10 -B5 "Exception" app.log` | 异常前后 10/5 行 |
