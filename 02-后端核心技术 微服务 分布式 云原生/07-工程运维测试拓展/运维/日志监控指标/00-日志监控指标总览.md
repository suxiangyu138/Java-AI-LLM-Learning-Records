## 5. 版本窗口说明

| 项 | 现状（2026-08） | 说明 |
|----|----------------|------|
| SLF4J | 2.x（2.0.12+） | 事实标准门面；provider 机制 |
| Logback | 1.4.x / 1.5.x | Spring Boot 默认实现 |
| Log4j2 | 2.20.0+（安全要求） | 异步性能王者；Log4Shell 历史需版本管控 |
| Prometheus | 3.x | Remote Write 2.0、原生直方图（细节见同级体系） |
| Loki | v3.2 | 标签索引式日志（成本低于 ES 约 70%） |
| OpenTelemetry | 行业标准 | OTLP（gRPC 4317/HTTP 4318）；Alloy 统一采集器（取代 Promtail） |
| Grafana | 2026 版含 AI 异常检测 | LGTM 一体化（Loki/Grafana/Tempo/Mimir） |

> ⚠️ **时效性**：本文按 2026-08 检索的官方信息编写；版本与配置细节以官方文档为准。

## 6. 核心概念速查

| 概念 | 一句话 |
|------|--------|
| SLF4J | 日志门面（API），与实现解耦 |
| Logback | SLF4J 原生实现，Spring Boot 默认 |
| MDC | 线程上下文（traceId/userId 注入日志） |
| 滚动策略 | 按时间/大小切分日志文件（防单文件无限增长） |
| 异步日志 | AsyncAppender（Logback）/ Async Loggers（Log4j2） |
| EFK | Elasticsearch + Fluentd/Fluent Bit + Kibana（全文检索） |
| Loki | 标签索引式日志（轻量，与 Grafana 一体） |
| Micrometer | JVM 指标门面（Actuator 默认） |
| JVM 指标 | JVM 内存/GC/线程/类加载的监控指标族 |
| SLO | 服务级别目标（如 99.9% 可用性） |
| 错误预算 | 100% - SLO = 可容忍的错误量 |
| OpenTelemetry | 三支柱统一标准（埋点/导出分离） |
| 三支柱 | Metrics（指标）/ Logs（日志）/ Traces（链路） |
