## 4. 定位：与 Xshell 等工具对比

| 维度 | FinalShell | Xshell + Xftp | Putty + WinSCP |
|------|-----------|---------------|----------------|
| 一体化 | ✅ 终端+文件+监控一体 | 两个工具切换 | 两个工具切换 |
| 文件管理 | 内置 SFTP（拖拽/断点续传） | Xftp 独立 | WinSCP 独立 |
| 实时监控 | **独家内置**（无需服务器装脚本） | ❌ | ❌ |
| 端口转发 | ✅ 本地/远程/动态隧道 | ✅ | ⚠️ |
| 中文支持 | ✅ 原生中文 | ✅ | ⚠️ |
| 价格 | 免费版够用（专业版去广告） | 个人免费/商业收费 | 免费 |
| 平台 | Win/Mac/Linux | Win 为主 | 全平台 |

> 🎯 **选型结论**：日常运维 + 文件管理 + 想看服务器状态 → **FinalShell 一个工具闭环**；已有 Xshell 生态且习惯双工具 → 可保留；**FinalShell 对新手最友好**（可视化 + 中文 + 监控内置）。

## 6. 核心功能速查

| 功能 | 一句话 |
|------|--------|
| SSH 终端 | 多标签/分屏、智能补全、历史命令、中文不乱码 |
| SFTP 文件管理 | 终端与文件树同步、双向拖拽、断点续传、打包上传 |
| 实时监控 | CPU/内存/网络/IO 图表、进程一键 kill（无需服务器装脚本） |
| 端口转发 | 本地/远程/动态隧道（内网穿透） |
| 跳板机 | 代理链/多层堡垒机跳转登录 |
| 批量执行 | 同时对多台服务器执行同一命令 |
| 命令面板 | 常用命令分组 + 变量替换 |
| 内置编辑器 | 语法高亮、代码折叠 |
| rz/sz | zmodem 传输 + Python 脚本执行 |
