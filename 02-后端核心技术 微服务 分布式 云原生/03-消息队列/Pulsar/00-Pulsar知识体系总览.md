## 4. 核心概念速查

| 概念 | 一句话定义 | 关键事实（2025-2026） |
|------|-----------|---------------------|
| 消息+流平台 | 队列语义 + 流式语义一体 | 订阅模式决定语义 |
| 三层分离 | Broker/BookKeeper/元数据 | 计算与存储独立扩展 |
| BookKeeper | 持久化存储层（ledger） | E:Qw:Qa（默认 5:3:2） |
| 无状态 Broker | 路由/复制（不存数据） | 故障切换即时 |
| 订阅模式 | 消息分发语义 | Exclusive/Shared/Failover/Key_Shared |
| 多租户 | tenant→namespace→topic | 隔离（认证/配额/策略） |
| 跨地域复制 | 原生复制（namespace 属性） | 异步默认（AP） |
| 分层存储 | 冷数据卸载对象存储 | S3/GCS/Azure Blob |
| Functions | 轻量无服务器计算 | 消息处理内建 |
| 百万 topic | 主题规模优势 | 对比 Kafka 的核心差异 |
| 版本 | v4.2.x（2026-03 稳定） | v3.x LTS / v4.0 LTS |
| 元数据存储 | ZooKeeper 默认 / Oxia（4.x） | etcd 已移除 |

> 🎯 **核心要点**：Pulsar 的独特性 = **存储与计算分离**（BookKeeper 独立扩展）+ **原生多租户**（tenant/namespace 隔离）+ **原生跨地域复制**——这是它对比 Kafka 的三大差异化能力。定位是"云原生消息与流平台"：一个系统同时服务队列（点对点）、流（发布订阅）、事件（多租户/多地域）。2025-2026 主线：v4.x 简化（移除 V1 API/etcd）、Oxia 元数据、百万 topic 的 AI 工作负载场景。
