## 1. 模块总览

```text
spring-shell-core          ← 命令模型/注册/运行器（4.0 起不含 Boot 与 JLine 依赖）
spring-shell-starter       ← 集成装配（Boot 4 自动配置）
spring-boot-starter-shell  ← 一站式 Starter（日常唯一需要的依赖）
spring-shell-test          ← 命令测试工具（@ShellTest/ShellAssertions）
```

> 🎯 **要点**：4.0 把 `spring-shell-standard`、`spring-shell-commands`、`spring-shell-table` 全部并入 core——**日常项目只需一个 `spring-boot-starter-shell`**；想理解"哪些能力开箱即用"看 core 即可。

### 1.1 依赖传导链速览

```text
spring-boot-starter-shell
  ├── spring-shell-core          ← 命令模型/CommandCatalog/Runner（核心）
  │     └── spring-messaging? 否 → JLine（仅交互模式运行时，由 shell-starter 配）
  ├── spring-shell-starter       ← Boot 自动配置（默认装配 Interactive/NonInteractive Runner）
  └── spring-boot-starter（传递）
spring-shell-test（测试）
  └── spring-boot-starter-test（传递）
```

> 💡 4.0 架构关键：**core 不再依赖 Spring Boot 与 JLine**——core 可在纯 Spring 环境使用；JLine 相关（终端/补全）由装配层按需引入。依赖缺失的第一直觉：交互模式异常 = 查 JLine 是否被正确装配（starter 已带，手工引 core 时需自查）。

### 1.2 模块一句话全景

| 模块 | 一句话 |
|------|--------|
| spring-shell-core | 命令模型、CommandRegistration、CommandCatalog、三种 Runner |
| spring-shell-starter | 装配层：把 core 接进 Boot 4 自动配置（含 JLine） |
| spring-boot-starter-shell | 一站式入口（生产依赖） |
| spring-shell-test | 测试：@ShellTest、ShellAssertions、输入模拟 |
| （已并入）standard / commands / table | 4.0 前独立模块，现合入 core |

> 🎯 心智模型：**core 是"引擎"，starter 是"点火器"，test 是"试车台"**——生产只碰 starter 与 test 两个坐标。

## 2. 核心模块

| Artifact | 职责 | 关键类（包） |
|---------|------|-------------|
| `spring-shell-core` | 命令定义/注册/解析/执行/运行模式 | `@Command`、`@Option`、`CommandRegistration`（org.springframework.shell.command）、`CommandCatalog`、`InteractiveShellRunner`、`NonInteractiveShellRunner`、`ScriptShellRunner` |
| `spring-shell-starter` | Boot 自动配置 | 自动装配 Runner、终端、补全（org.springframework.shell.boot） |
| `spring-shell-test` | 测试支持 | `@ShellTest`、`ShellAssertions`、`ShellTestApplication` |

> ⚠️ **4.0 包名迁移**：命令 API 从 `org.springframework.shell.standard`（3.x）迁到 `org.springframework.shell.command`（4.0）；`@ShellComponent`/`@ShellMethod`/`@ShellOption` 已移除，替换为 `@Command`/`@Option`——旧 import 全部编译失败，按新包重写。

### 2.1 core 内部结构（4.0）

```text
org.springframework.shell
├── command        # 命令模型：@Command/@Option/CommandRegistration/CommandCatalog
├── completion     # 补全：CompletionProposal、CompletionContext
├── converter      # 参数转换：Converter、TypeConverter
├── runner         # 运行模式：Interactive/NonInteractive/Script ShellRunner
├── context        # 命令上下文与生命周期
├── exitcode       # 退出码：ExitCodeExceptionProvider 等
├── jline          # JLine 集成（终端/补全处理器）
└── terminal       # 终端抽象（NativeTerminal 等）
```

## 3. 4.0 模块合并对照

| 3.x 模块 | 4.0 去向 | 影响 |
|----------|---------|------|
| spring-shell-standard | 并入 core | 依赖简化 |
| spring-shell-standard-commands | 并入 core | help/quit/clear 等内置命令仍可用 |
| spring-shell-table | 并入 core | 表格输出能力保留 |
| spring-shell-shell-component | 移除（注解已删） | @ShellComponent → @Command（类级） |
| spring-shell-starter | 保留（改装配） | 自动配置增强 |

> 💡 迁移对照：3.x 的 `@ShellComponent + @ShellMethod` → 4.0 的 `@Component（或任意 Bean）+ @Command`；`@ShellOption` → `@Option`；`@ShellCommandGroup` → `@ShellCommandGroup`（保留）。

## 4. 依赖什么场景引入什么

| 场景 | 需要的依赖 |
|------|-----------|
| 交互式 CLI / REPL 工具 | `spring-boot-starter-shell` |
| 命令单元测试 | + `spring-shell-test`（test scope） |
| 纯 Spring（非 Boot）使用 core | spring-shell-core + 自行装配 Runner |
| GraalVM Native Image | starter（4.0.2+ 原生命令注册开箱即用） |
| 需要更多内置命令 | 已在 core（help/quit/clear/history/script/stacktrace） |

```xml
<!-- 标准生产依赖：一个 starter 搞定 -->
<dependency>
    <groupId>org.springframework.shell</groupId>
    <artifactId>spring-boot-starter-shell</artifactId>
</dependency>
<dependency>
    <groupId>org.springframework.shell</groupId>
    <artifactId>spring-shell-test</artifactId>
    <scope>test</scope>
</dependency>
```

### 4.1 版本线对照与冲突

| Boot 版本 | Shell 版本线 | 说明 |
|-----------|-------------|------|
| Boot 4.0.x | 4.0.x（当前 4.0.3） | 当前主线（SF 7.0.8） |
| Boot 3.x | 3.4.x（当前 3.4.3） | 维护线；迁移 4.0 前先升到最新 3.4.x |

| 报错现象 | 根因 | 处理 |
|---------|------|------|
| `@ShellMethod` 不存在 | 3.x 注解，4.0 已移除 | 改用 `@Command`/`@Option` |
| `ClassNotFoundException: org.springframework.shell.standard.*` | 4.0 包迁移 | 换 `org.springframework.shell.command.*` |
| JDK 25 下 tab 补全失效 | JLine 版本过旧 | 升级 4.0.3（JLine 3.30.13） |
| 自定义 Converter 不生效 | 3.x 的 Converter 注册方式不兼容 | 4.0.3 已修复 @Command + Converter 组合 |

> 🎯 经验法则：**4.0 语法差异是迁移期最大坑**——先看官方迁移指南（3.4.x → 4.0），新旧注解不要混用。

## 5. Starter 对照

| Starter | 包含 | 适用 |
|---------|------|------|
| `spring-boot-starter-shell` | core + starter 装配（含 JLine、内置命令） | **唯一需要的生产依赖** |
| （无其他官方 starter） | — | 特殊需求直接依赖 core 子能力 |

### 5.1 Boot 自动配置要点（Boot 4）

- 自动注册 `@Command` 注解 Bean（无需 `@EnableCommand`/`@CommandScan`）；
- 默认装配 Interactive + NonInteractive + Script 三种 Runner；
- `spring.shell.interactive.enabled=false` 可禁用交互模式（纯脚本/CI 场景）；
- 4.0.2 起非交互模式退出码真实反映命令结果（CI 可用）。

> 🎯 一句话选型：**生产 = spring-boot-starter-shell；测试 = 加 shell-test；版本永远跟 Boot 4 BOM**——4.0 之后依赖面比 3.x 更简单。
