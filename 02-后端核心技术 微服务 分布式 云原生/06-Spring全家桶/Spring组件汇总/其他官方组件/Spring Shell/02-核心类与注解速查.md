## 1. 命令定义

| 类/注解 | 职责 | 说明 |
|---------|------|------|
| `@Command` | 命令注解（方法级 / 类级） | `command`（命令名，可含分组 `group cmd`）、`description`、`group` |
| `@ShellCommandGroup` | 类级分组 | help 中分组展示 |
| `@Option` | 命令参数 | `longNames`/`shortNames`、`required`、`defaultValue`、`arity`（多值） |
| `CommandRegistration.Builder` | DSL 式命令定义 | 复杂命令：别名、补全、退出码、参数模型 |
| `CommandCatalog` | 命令注册表 | 查命令、执行命令（`catalog.invoke(...)`） |
| `CommandContext` | 命令执行上下文 | 当前命令、参数、环境 |

```java
// 注解式（简单命令首选）
@Component
class OrderCommand {
    @Command(command = "order query", description = "query order by id")
    String query(@Option(required = true) long id,
                 @Option(defaultValue = "10") int timeout) {
        return orderService.findById(id).toString();
    }
}

// DSL 式（复杂命令：别名 + 补全 + 退出码）
@Component
class OrderCommandRegistrar implements CommandRegistrationSupplier {
    @Override
    public List<CommandRegistration> get() {
        return List.of(CommandRegistration.builder()
                .command("order", "export")
                .withAlias().command("order", "dump").and()
                .withOption().longNames("file").required().and()
                .withTarget().function(ctx -> export(ctx.getOptionValue("file"))).and()
                .build());
    }
}
```

> 🎯 **要点**：4.0 命令方法返回值 = 输出文本；返回 null 无输出；抛异常 → 显示错误 + 非零退出码（非交互模式）。类级 `@Command` = 类内方法都是该命令的子命令（4.0.2 起分组更完善）。

## 2. 参数与转换

| 能力 | API | 说明 |
|------|-----|------|
| 具名参数 | `@Option(longNames = "file")` | `--file x` 或 `-f x` |
| 位置参数 | `@Option` + position（或 DSL positional） | 按序传入 |
| 必填/默认 | `required = true` / `defaultValue = "..."` | 缺省校验由框架完成 |
| 多值 | `arity = 3` 或集合类型 | 4.0.2 起 arity 完整支持 |
| 类型转换 | 内置 Converter / 自定义 `Converter<T>` | 字符串 → 任意类型 |
| 布尔标志 | `@Option(arity = 0)` | 无值开关（4.0.2 修复子命令布尔标志） |
| 补全 | `@Completion` / CompletionProposal | 参数值候选提示 |

```java
// 自定义类型转换（4.0.3 修复了 @Command + Converter 组合）
@Component
class LocalDateConverter implements Converter<LocalDate> {
    @Override
    public LocalDate convert(String source) {
        return LocalDate.parse(source);
    }
}
// 用法：@Option LocalDate date → 输入 2026-08-07 自动解析
```

> 💡 补全体验是 CLI 的"门面"：枚举/文件路径/数据库候选值都值得配 Completion——`@Completion` 注解或 CommandRegistration 的 completion 段。

## 3. 运行模式与退出码

| 类 | 模式 | 用法 |
|----|------|------|
| `InteractiveShellRunner` | 交互 REPL | 默认启动模式；JLine 补全/历史 |
| `NonInteractiveShellRunner` | 单命令 | `java -jar app.jar -c "order query --id 1"`（脚本/CI） |
| `ScriptShellRunner` | 脚本文件 | `--script commands.shell` 批量执行 |
| `ExitCodeExceptionProvider` | 异常 → 退出码 | 实现 `exitCode()` 控制非交互退出码 |
| `CommandRegistration` exitCode | 命令级退出码 | DSL 中指定成功/失败退出码 |

```java
// 自定义退出码：命令失败时返回特定码（CI 判定）
class NotFoundException extends RuntimeException implements ExitCodeExceptionProvider {
    @Override
    public int exitCode() {
        return 42;
    }
}
```

> ⚠️ 4.0.2 修复：非交互模式退出码此前**恒为 0**（CI 永远"成功"）——升级后命令失败会真实反映退出码，**CI 脚本需回归验证**。

## 4. 测试 API

| API | 用途 |
|-----|------|
| `@ShellTest` | 命令测试注解（自动装配 Shell 上下文，禁用交互） |
| `ShellAssertions` | 断言命令输出/退出码 |
| `ShellTestApplication` | 测试用应用入口 |
| 输入模拟 | 4.0.2 起支持测试"需要输入的命令"（应答式交互） |

```java
@ShellTest
class OrderCommandTest {
    @Autowired ShellTestClient client;

    @Test
    void queriesOrder() {
        ShellTestClient.ShellResult result =
                client.shellCommand("order query --id 1").run();
        assertThat(result.output()).contains("order#1");
        assertThat(result.exitCode()).isEqualTo(0);
    }
}
```

> 🎯 测试要点：**测试里禁交互模式**（@ShellTest 自动处理）；断言先看退出码再看输出文本——两者共同保证 CI 语义正确。

## 5. 4.0 变化对照

| 维度 | 3.x | 4.0 |
|------|-----|-----|
| 注解 | @ShellComponent / @ShellMethod / @ShellOption | @Command / @Option（旧注解移除） |
| 开关 | @EnableCommand / @CommandScan | Boot 自动注册（无需开关） |
| DSL | 旧 CommandRegistration | 新 Builder（withAlias/withOption/withTarget 链式） |
| 模块 | standard / commands / table 独立 | 全部并入 core |
| 包 | org.springframework.shell.standard | org.springframework.shell.command |
| 空安全 | — | JSpecify 标注 |
| 退出码 | 非交互恒为 0 | 真实反映（4.0.2 修复） |
| 原生命令 | 需手动注册 | 自动注册（4.0.2+） |

> ⚠️ 迁移顺序（官方要求）：先升到最新 3.4.x → 按迁移指南改注解（@ShellMethod→@Command、@ShellOption→@Option）→ 换包 import → 验证补全/转换/退出码。
