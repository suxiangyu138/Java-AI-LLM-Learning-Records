## 1. spring.shell.* 属性表

| 属性 | 默认值 | 说明 |
|------|--------|------|
| `spring.shell.interactive.enabled` | `true` | 交互模式开关（纯脚本/CI 置 false） |
| `spring.shell.noninteractive.enabled` | `true` | 单命令模式开关（`-c` 参数） |
| `spring.shell.script.enabled` | `true` | 脚本模式开关（`--script` 参数） |
| `spring.shell.script.location` | — | 默认脚本文件路径 |
| `spring.shell.script.execution.shutdown-on-eof` | `false` | 脚本读到 EOF 是否关闭应用 |
| `spring.shell.history.enabled` | `true` | 历史记录开关 |
| `spring.shell.history.file` | `~/.spring-shell.history` | 历史文件路径 |
| `spring.shell.command.help.enabled` | `true` | 内置 help 命令 |
| `spring.shell.command.quit.enabled` | `true` | 内置 quit 命令 |
| `spring.shell.command.clear.enabled` | `true` | 内置 clear 命令 |
| `spring.shell.command.history.enabled` | `true` | 内置 history 命令 |
| `spring.shell.command.script.enabled` | `true` | 内置 script 命令 |
| `spring.shell.command.stacktrace.enabled` | `true` | 内置 stacktrace（错误堆栈）命令 |
| `spring.shell.command.unknown-command.enabled` | `true` | 未知命令提示行为 |
| `spring.shell.command.quit.*` / `exit.*` | — | quit/exit 别名行为 |

```yaml
spring:
  shell:
    interactive:
      enabled: true
    history:
      enabled: true
      file: /var/app/.shell-history
    command:
      stacktrace:
        enabled: false     # 生产：关掉堆栈暴露
```

> 🎯 **高频三配**：`interactive.enabled`（服务化场景关闭交互）、`history.file`（容器持久化历史）、`command.stacktrace.enabled`（生产安全）。

## 2. 运行模式配置

| 场景 | 配置 | 说明 |
|------|------|------|
| 纯 CI / 服务化（无 TTY） | `spring.shell.interactive.enabled: false` | 避免终端初始化报错 |
| 交互 + 脚本混合 | 全默认 | `-c` 与交互并存 |
| 容器内只跑脚本 | `interactive.enabled: false` + `script.location` | 启动即执行脚本文件 |
| 调试命令输出 | `spring.shell.command.stacktrace.enabled: true` | 本地开、生产关 |

> ⚠️ 容器/无 TTY 环境启动交互模式可能抛终端错误——CI 与 Kubernetes Job 场景务必确认 interactive.enabled 关闭。

## 3. 脚本与历史配置

| 需求 | 配置/用法 |
|------|----------|
| 启动即执行固定脚本 | `spring.shell.script.location: classpath:init.shell` |
| 批量命令文件 | 运行时 `--script ops.shell` |
| 脚本结束后退出 | `spring.shell.script.execution.shutdown-on-eof: true` |
| 历史持久化（容器） | `spring.shell.history.file: /data/.shell-history`（挂载卷） |
| 禁用历史 | `spring.shell.history.enabled: false`（敏感命令审计场景） |

> 💡 脚本文件一行一条命令，支持空行与注释（`//` 行首）——运维批处理（批量查询/批量触发）用它最顺。

## 4. 内置命令配置

| 命令 | 配置开关 | 用途 |
|------|---------|------|
| help | `spring.shell.command.help.enabled` | 命令/分组帮助（4.0.2 起按字母排序） |
| quit / exit | `spring.shell.command.quit.enabled` | 退出交互模式 |
| clear | `spring.shell.command.clear.enabled` | 清屏 |
| history | `spring.shell.command.history.enabled` | 历史查看 |
| script | `spring.shell.command.script.enabled` | 交互内执行脚本文件 |
| stacktrace | `spring.shell.command.stacktrace.enabled` | 最近错误堆栈 |

> 🎯 安全考量：**生产暴露 stacktrace 会泄露内部类名/依赖信息**——运维终端建议关闭；如需排障日志在服务端留痕即可。

## 5. 测试环境配置

| 配置 | 说明 |
|------|------|
| `@ShellTest` 自动禁用交互 | 测试上下文默认 noninteractive |
| `spring.shell.noninteractive.enabled: true`（默认） | 测试依赖单命令模式 |
| 测试属性覆盖 | `@ShellTest(properties = "spring.shell.history.enabled=false")` |

> ⚠️ 测试注意：@ShellTest 上下文会加载完整 Spring 容器——**命令依赖的 Bean 必须可解析**；只测命令逻辑可把依赖 Mock 进容器。

> 🎯 配置心智模型：**yaml 管"模式开关与内置命令"，命令本身的参数/行为走注解与 DSL**——先定"交互还是服务化"，再定"脚本与历史策略"，最后处理安全（stacktrace）。
