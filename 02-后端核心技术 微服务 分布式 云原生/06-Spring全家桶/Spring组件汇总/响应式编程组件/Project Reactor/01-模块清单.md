## 1. 模块总览

```text
reactor-core         ← Mono/Flux/操作符/调度器（一切响应式的地基）
reactor-netty        ← Netty 传输层（WebFlux/RSocket 默认底层）
reactor-test         ← StepVerifier 测试工具
reactor-kafka        ← Kafka 响应式客户端
reactor-pool         ← 响应式对象池（连接池抽象）
reactor-adapter      ← 与其他响应式流实现互操作
reactor-extra        ← 额外操作符（可空但好用）
```

> 🎯 **要点**：日常项目只需要 **reactor-core**（WebFlux/R2DBC 会自动传递）；**reactor-test 是测试标配**；其他按"接什么系统"补。

### 1.1 依赖传导链速览

```text
spring-boot-starter-webflux
  ├── spring-webflux            ← 响应式 Web 框架
  ├── reactor-core              ← Mono/Flux（传递）
  └── reactor-netty             ← Netty 传输（传递）
spring-boot-starter-data-r2dbc
  ├── spring-data-r2dbc
  └── r2dbc-spi + 驱动（传递）
spring-boot-starter-webflux-test（测试）
  └── reactor-test / spring-test
```

> 💡 依赖缺失的第一直觉：**`Mono`/`Flux` 无法 import = 缺 reactor-core（starter 已带）；WebFlux 起不来 = 缺 reactor-netty；想用 StepVerifier = 加 reactor-test**。

### 1.2 模块一句话全景

| 模块 | 一句话 |
|------|--------|
| reactor-core | Mono/Flux、100+ 操作符、Schedulers、Context、Hooks |
| reactor-netty | 基于 Netty 的响应式 HTTP/TCP/UDP 传输 |
| reactor-test | StepVerifier（含虚拟时间）、TestPublisher |
| reactor-kafka | Kafka 消费/生产的响应式客户端 |
| reactor-pool | 通用响应式对象池（R2DBC/Netty 连接池都用它） |
| reactor-adapter | 与 RxJava/RxJava3 等互操作桥 |
| reactor-extra | Math/Retry 等扩展操作符 |

> 🎯 心智模型：**core 是"发动机"，netty 是"车轮"，test 是"试车台"**——WebFlux 项目三者齐备，纯数据处理只带 core。

## 2. 核心模块

| Artifact | 职责 | 关键类（包） |
|---------|------|-------------|
| `reactor-core` | 响应式流核心 | `Mono`、`Flux`（reactor.core.publisher）、`Schedulers`、`Context`（reactor.util.context）、`Hooks` |
| `reactor-test` | 测试支持 | `StepVerifier`、`TestPublisher`、`StepVerifier.Step` |
| `reactor-netty` | 传输层 | `HttpServer`、`HttpClient`（reactor.netty.http）、`TcpServer` |

> ⚠️ 响应式流规范（reactive-streams 1.0）是独立 jar，reactor-core 依赖它——接口类 `Publisher`/`Subscriber` 来自 `org.reactivestreams`，不要与 Reactor 自身类混淆。

### 2.1 core 内部结构

```text
reactor.core
├── publisher      # Mono/Flux + 操作符实现（100+ 个 FluxXxx/MonoXxx 类）
├── scheduler      # Schedulers、Scheduler 接口与实现
├── Disposable     # 订阅句柄（dispose 取消）
├── Scannable      # 流组装信息查询（调试/监控）
├── Fuseable       # 融合优化（队列融合接口）
└── exception      # 异常体系（Exceptions.throwIfFatal 等）
reactor.util
├── context        # Context / ContextView
└── retry          # Retry 规范（retryWhen 用）
```

> 💡 调试技巧：操作符太多时 `Flux` 的每个操作符都是独立内部类——堆栈里看到 `FluxMap`/`FluxFlatMap` 就能定位链上的环节。

## 3. 周边模块地图

| 类别 | 模块 | 典型使用 |
|------|------|---------|
| 传输 | reactor-netty | WebFlux/RSocket 默认 HTTP 传输；HttpClient 编程式调用 |
| 消息 | reactor-kafka | KafkaReceiver/KafkaSender 响应式消费/生产 |
| 池化 | reactor-pool | R2DBC 连接池、Netty 连接池（通用池抽象） |
| 互操作 | reactor-adapter | 与 RxJava 2/3、Future 等互操作 |
| 扩展 | reactor-extra | `FluxMath`（sum/average）、增强 retry |
| 测试 | reactor-test | StepVerifier.withVirtualTime、TestPublisher |

> 💡 选型逻辑：**先定"要响应式处理什么系统"**——Web 用 WebFlux（自带）、Kafka 用 reactor-kafka、数据库用 R2DBC（自带 pool）。

## 4. 依赖什么场景引入什么

| 场景 | 需要的依赖 |
|------|-----------|
| 响应式 Web（WebFlux） | `spring-boot-starter-webflux`（reactor-core + netty 已带） |
| 响应式数据库 | + `spring-boot-starter-data-r2dbc` + 数据库驱动（r2dbc-postgresql 等） |
| 响应式测试 | + `reactor-test`（test scope） |
| 纯流处理（非 Web） | `io.projectreactor:reactor-core` |
| Kafka 响应式消费 | + `reactor-kafka` |
| 自定义 HTTP 客户端（编程式） | reactor-netty 的 HttpClient（starter 已带） |
| 与其他响应式库互操作 | + `reactor-adapter` |

```xml
<!-- 测试标配 -->
<dependency>
    <groupId>io.projectreactor</groupId>
    <artifactId>reactor-test</artifactId>
    <scope>test</scope>
</dependency>
```

### 4.1 版本线对照与冲突

| Boot 版本 | Reactor 版本线 | 说明 |
|-----------|---------------|------|
| Boot 4.0.x | 3.8.x（2025.0.x Release Train，当前 3.8.6） | 当前主线 |
| Boot 3.x | 3.6.x / 3.7.x | 存量维护线 |

| 报错现象 | 根因 | 处理 |
|---------|------|------|
| `NoSuchMethodError`（Flux/Mono 方法） | Reactor 版本与 Boot 不配套 | Boot BOM 锁定（3.8.x ↔ Boot 4） |
| `ClassNotFoundException: org.reactivestreams.*` | 缺 reactive-streams | reactor-core 会传递，手工引时补 |
| StepVerifier 找不到 | 缺 reactor-test | 加 test scope 依赖 |
| 与 RxJava 类冲突 | adapter 版本不匹配 | 统一走 BOM |

> 🎯 经验法则：**Reactor 依赖全部交给 Boot BOM**（Release Train 对齐）；手工升 reactor-core 版本是 NoSuchMethodError 的头号来源。

## 5. Starter 对照

| Starter | 包含 | 适用 |
|---------|------|------|
| `spring-boot-starter-webflux` | spring-webflux + reactor-core + reactor-netty | 响应式 Web 标准入口 |
| `spring-boot-starter-data-r2dbc` | spring-data-r2dbc + r2dbc-spi（+pool） | 响应式数据访问 |
| （无独立 reactor starter） | — | 纯 Reactor 用 Maven 直接引 |

> 🎯 一句话选型：**Web 用 starter-webflux、数据用 starter-data-r2dbc、测试加 reactor-test**——版本永远跟 Boot BOM；纯流处理项目只需 reactor-core 一个坐标。
