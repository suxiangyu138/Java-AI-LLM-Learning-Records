## 1. 模块组成

| 模块 | 类型 | 职责 | 引入方 |
|------|------|------|--------|
| **spring-cloud-starter-openfeign** | starter | OpenFeign 全部能力（自动装配） | 需要 Feign 的服务 |
| **spring-cloud-openfeign-core** | 核心库 | @FeignClient 处理、FeignClientFactoryBean、自动装配 | 传递依赖 |
| **spring-cloud-starter-loadbalancer** | 配套 | **默认 Client（FeignBlockingLoadBalancerClient）依赖它，需显式加** | 单独引入（官方文档明确） |
| spring-cloud-openfeign 的第三方底座 | 外部库 | Netflix Feign（io.github.openfeign:feign-core 等） | 传递依赖 |
| spring-cloud-starter-circuitbreaker-* | 配套 | 熔断（fallback 支持） | 需要熔断时加 |
| 注册中心 starter | 配套 | 服务发现（nacos/eureka/consul） | 按选型 |
| spring-cloud-starter-netflix-hystrix | 废弃 | 老熔断方案 | 迁移期 |

> 💡 接入口诀：**`spring-cloud-starter-openfeign` + `spring-cloud-starter-loadbalancer` 必加**——loadbalancer 不是"可选优化"，是默认 Client 的运行前提（官方文档："must be added explicitly"）。

## 2. 依赖坐标与边界

### 2.1 官方坐标（Maven Central，5.0.2）

```xml
<dependency>
    <groupId>org.springframework.cloud</groupId>
    <artifactId>spring-cloud-starter-openfeign</artifactId>
</dependency>

<!-- ★ 默认 Client 依赖，官方要求显式加 -->
<dependency>
    <groupId>org.springframework.cloud</groupId>
    <artifactId>spring-cloud-starter-loadbalancer</artifactId>
</dependency>

<!-- 熔断（fallback 需要） -->
<dependency>
    <groupId>org.springframework.cloud</groupId>
    <artifactId>spring-cloud-starter-circuitbreaker-resilience4j</artifactId>
</dependency>

<!-- 版本管理：Spring Cloud BOM（不写 version） -->
<dependencyManagement>
    <dependency>
        <groupId>org.springframework.cloud</groupId>
        <artifactId>spring-cloud-dependencies</artifactId>
        <version>2025.1.2</version>
        <type>pom</type><scope>import</scope>
    </dependency>
</dependencyManagement>
```

### 2.2 依赖边界

| 边界 | 说明 |
|------|------|
| **版本 ↔ Cloud release train** | 5.0.x↔2025.1.x（Boot 4）；4.3.x↔2025.0.x（Boot 3.5） |
| loadbalancer 显式引入 | 默认 Client（FeignBlockingLoadBalancerClient）的前提 |
| 熔断可选 | 不加 CB starter 时 fallback 不生效（但 @FeignClient 正常） |
| Apache HC5 可选 | 默认用 Feign 内置 Client；加 hc5 依赖自动切换 |
| **无响应式** | Feign 无 WebFlux 支持（官方建议响应式场景用 @HttpExchange） |
| 无版本冲突 | 与 OpenFeign 3.x 第三方底座（io.github.openfeign）由 BOM 锁定 |

> ⚠️ **最常见的坑**：只加 starter-openfeign 不加 loadbalancer——启动能过，**运行时服务名解析失败**（UnknownHostException 或找不到 LoadBalancerClient），因为默认 Client 需要 LB（[08 篇](08-生产实践与选型避坑.md) 坑位表）。

## 3. 版本兼容矩阵（2026-08）

### 3.1 OpenFeign ↔ Spring Cloud ↔ Boot（权威组合）

| Spring Cloud | OpenFeign | Boot | JDK | 备注 |
|--------------|-----------|------|-----|------|
| **2025.1.x（Oakwood）** | **5.0.x（5.0.2）** | **4.0.x/4.1.x** | 17+ | **当前主线**；Jackson 3 兼容；定位=兼容适配器 |
| 2025.0.x（Northfields） | 4.3.x（4.3.3） | 3.5.x | 17 | OSS 已于 2026-06-30 EOL |
| 2024.0.x（Moorgate） | 4.2.x（4.2.3） | 3.4.x | 17 | EOL |
| 2023.0.x（Leyton） | 4.1.x（4.1.5） | 3.2.x/3.3.x | 17 | EOL |
| 2022.0.x（Kilburn） | 4.0.x | 3.0.x/3.1.x | 8/11/17 | 老存量；**feature-complete 宣布点** |
| 2021.0.x（Jubilee） | 3.1.x | 2.6.x/2.7.x | 8/11 | 老存量 |
| 2020.0.x（Ilford） | 2.2.x | 2.4.x/2.5.x | 8 | 老存量 |

> ⚠️ **版本事实**：OpenFeign 与 Config/Gateway 一样正常进位（无跳版）；**4.0.x 起 Apache HttpClient 4 不再支持**（只用 HC5）——老项目升级注意 httpClient 依赖更换。

### 3.2 快速对齐口诀

| 场景 | 推荐组合 |
|------|---------|
| 存量 Boot 4 项目 | OpenFeign 5.0.x（稳定，BOM 锁定） |
| 存量 Boot 3.5 | OpenFeign 4.3.x（**OSS EOL，建议升级**） |
| 新项目（Boot 4） | **评估 @HttpExchange**（官方新方向，[07 篇](07-迁移到Spring HTTP Service Clients.md)） |
| Boot 2.7 老项目 | OpenFeign 3.1.x（先升 Boot 全家桶） |

## 4. feature-complete 状态解读

### 4.1 官方原话（5.0.2 文档）

> "As announced in Spring Cloud 2022.0.0 release blog entry, we're now treating the Spring Cloud OpenFeign project as **feature-complete**. We are only going to be adding **bugfixes** and possibly merging some small community feature PRs. **We suggest migrating over to Spring HTTP Service Clients instead.**"

### 4.2 三条结论

| 结论 | 说明 |
|------|------|
| ① 功能冻结 ≠ 废弃 | bugfix 持续、生态稳定——**存量项目继续用完全安全** |
| ② 新特性别等 | 新需求（响应式等）不会在 Feign 里出现 |
| ③ 新项目看官方 | 官方明确导向 @HttpExchange（Spring Interface Clients） |

> 🎯 面试必答：**"feature-complete 意味着什么？"**——**"功能冻结、bugfix 维护"**：OpenFeign 不再加新特性（5.0 只有 Jackson 3 兼容），官方建议新代码迁移到 Spring HTTP Service Clients（@HttpExchange）；**但存量 Feign 代码不用慌**——它会长期维护（bugfix 模式），迁移是"新项目方向"而非"立即行动"。

## 5. 模块选型建议

| 场景 | 推荐 | 理由 |
|------|------|------|
| 存量 Feign 项目 | OpenFeign 5.0.x | 稳定、feature-complete 长期维护 |
| 新项目（Boot 4） | **@HttpExchange（HTTP Service Clients）** | 官方新方向、少一层代理、原生镜像友好（[07 篇](07-迁移到Spring HTTP Service Clients.md)） |
| 响应式链路 | @HttpExchange（WebClient 版） | Feign 无响应式支持 |
| 需要熔断降级 | Feign + resilience4j starter | fallback/fallbackFactory（[04 篇](04-熔断降级集成.md)） |
| 需要连接池/HTTP2 | Feign + Apache HC5 | hc5 依赖自动切换 |
