## 1. 接入清单与配置基线

### 1.1 接入清单

| 调用类型 | 用什么 | 说明 |
|---------|--------|------|
| 服务间调用（存量） | Feign | 稳定、feature-complete |
| 服务间调用（新项目） | @HttpExchange | 官方新方向（[07 篇](07-迁移到Spring HTTP Service Clients.md)） |
| 响应式链路 | @HttpExchange（WebClient 版） | Feign 不支持 |
| 外部 API（第三方） | RestClient | 无需服务发现 |
| 需要熔断降级 | Feign + CB / @HttpExchange + CB | 声明式降级 |

### 1.2 生产配置基线（Feign）

```yaml
spring:
  cloud:
    openfeign:
      circuitbreaker:
        enabled: true              # 熔断（fallback 生效）
      client:
        config:
          default:
            connectTimeout: 3000
            readTimeout: 5000
            loggerLevel: basic
      compression:
        request:
          enabled: true
          min-request-size: 2048
        response:
          enabled: true
logging:
  level:
    com.example.api.client: INFO   # 生产不开 DEBUG（防敏感数据）
```

## 2. 坑位表：10 大高频坑

| # | 坑 | 现象 | 解决 |
|---|-----|------|------|
| 1 | **缺 loadbalancer 依赖** | UnknownHostException: 服务名 | 显式加 starter-loadbalancer（[02 篇](02-快速开始与@FeignClient速查.md)） |
| 2 | **超时键写成短横线** | 超时配置不生效（走默认） | 用 camelCase：connectTimeout/readTimeout（[03 篇](03-超时重试与HTTP客户端.md)） |
| 3 | **fallback 不是 Bean** | 启动报错/fallback 不生效 | fallback 类加 @Component |
| 4 | **没开 circuitbreaker** | fallback 永远不触发 | feign.circuitbreaker.enabled=true |
| 5 | **熔断器实例名对不上** | 熔断"不生效"（走默认配置） | 先查实际命名（health 端点）再配 resilience4j（[04 篇](04-熔断降级集成.md)） |
| 6 | **业务 404 触发熔断** | 正常业务 404 把熔断器打爆 | ErrorDecoder 把 4xx 转业务异常 + 配 ignore-exceptions（[05 篇](05-拦截器日志压缩速查.md)） |
| 7 | **日志开了不输出** | loggerLevel 配了但没日志 | 还要 logging.level.<接口>=DEBUG（两者缺一不可） |
| 8 | **写接口开重试** | 重复提交 | 重试默认关；开只限读场景（[03 篇](03-超时重试与HTTP客户端.md)） |
| 9 | **自定义 Client 非单例** | 连接池耗尽/端口耗尽 | Client Bean 必须 Singleton（[03 篇](03-超时重试与HTTP客户端.md)） |
| 10 | **FULL 日志上生产** | 请求体/响应体（含密码）进日志 | 生产用 basic，FULL 仅调试 |

> 💡 排障口诀：**"依赖全不全（LB）→ 开关开没开（熔断）→ 键名对不对（camelCase）→ 命名配没配（熔断器名）"**——四步定位覆盖 80% 问题。

## 3. 调优：超时/熔断/重试组合

### 3.1 三层联动关系

```text
超时（readTimeout）→ 抛超时异常 → 计入熔断失败率 → 熔断 OPEN → fallback
  ├── readTimeout 太小：正常慢调用被误杀（P99 × 2 校准）
  ├── readTimeout 太大：慢调用长时间占连接（连接池压力）
  └── 熔断阈值（failure-rate-threshold）决定"多少超时算故障"

重试与熔断：重试在熔断内层（OPEN 时重试不执行）
  └── 瞬时故障（网络抖动）：重试救场；持续故障：熔断兜底
```

### 3.2 调优基线

| 参数 | 基线 | 说明 |
|------|------|------|
| readTimeout | 下游 P99 × 2 | 留余量不误杀 |
| connectTimeout | 1-3s | 连接快慢与网络质量 |
| failure-rate-threshold | 50 | 业务敏感可 30 |
| sliding-window-size | 50-100 | 样本足够 |
| wait-duration-in-open-state | 30s | 恢复节奏 |
| 重试 | 默认关 | 只读场景按需开 |

### 3.3 压测验证

```text
压测三问：
  ① 慢下游：readTimeout 超时 → 熔断统计 → OPEN → fallback 是否按预期？
  ② 挂下游：全部失败 → 熔断快速失败（不等待）？
  ③ 恢复：下游恢复 → 半开试探 → 回 CLOSED？
```

## 4. 监控与可观测

| 手段 | 配置 | 内容 |
|------|------|------|
| Micrometer 指标 | micrometer.enabled（默认 true） | 调用次数/耗时/失败率 |
| 链路追踪 | Micrometer Tracing | Feign 调用在 Zipkin/OTel 可见 |
| fallback 埋点 | fallbackFactory 打日志 | 降级次数/原因（可告警） |
| 熔断状态 | /actuator/health + resilience4j 指标 | 熔断器状态 |
| 日志 | loggerLevel=basic | 请求 URL/状态/耗时 |

> 🎯 告警基线：**降级次数突增（fallback 日志计数）→ 立即告警**——fallback 是"故障开始"的信号，比 5xx 告警早。

## 5. 客户端选型：Feign vs RestClient vs @HttpExchange

| 维度 | Feign | RestClient（RestTemplate 继任） | @HttpExchange |
|------|-------|-------------------------------|---------------|
| 类型 | 声明式 | 编程式 | 声明式 |
| 服务发现/LB | ✅ | @LoadBalanced | ✅（5.0 自动） |
| 熔断降级 | ✅ fallback | 手动 | ✅（5.0） |
| 响应式 | ❌ | ❌ | ✅ |
| 依赖 | starter-openfeign | 无（Framework 内置） | 无（Framework 7 内置） |
| 官方状态 | 兼容适配器 | 通用工具 | **新方向** |
| 适用 | 存量项目 | 外部 API/零星调用 | 新项目 |

> 🎯 选型一句话：**"服务间调用：新项目 @HttpExchange、存量 Feign；外部 API：RestClient；响应式：@HttpExchange（WebClient 版）"**——三种客户端各就各位，别混用。

## 6. 升级路径：4.3.x → 5.0.x

### 6.1 升级必要性

| 现状 | 判断 |
|------|------|
| 2025.0.x（Boot 3.5）+ Feign 4.3.x | **建议升级**：Northfields OSS 已结束 |
| 2024.0.x（Boot 3.4）+ Feign 4.2.x | **建议升级**：Moorgate EOL |
| 2023.0.x（Boot 3.2/3.3）+ Feign 4.1.x | 计划升级 |
| Boot 2.7 + Feign 3.1.x | 先升 Boot 全家桶 |

### 6.2 升级 Checklist

```text
□ 1. 整批升级：Boot 3.5→4.x + Cloud 2025.0→2025.1
□ 2. 版本：Feign 5.0.x（BOM 锁定，无单独坐标变更）
□ 3. 代码兼容：5.0 只有 Jackson 3 兼容（业务代码基本零改动）
□ 4. 依赖核对：HC4 → HC5（如用 Apache HttpClient）
□ 5. 回归：接口调用、熔断 fallback、超时、拦截器、日志
□ 6. 新项目评估：@HttpExchange 方向（[07 篇](07-迁移到Spring HTTP Service Clients.md)）
```

> 🎯 升级心法：**Feign 5.0 是"最小升级"（只有 Jackson 3 兼容）**——存量项目升级压力趋近于零；真正的决策是"要不要借机迁 @HttpExchange"（按 [07 篇](07-迁移到Spring HTTP Service Clients.md) 决策树评估）。
