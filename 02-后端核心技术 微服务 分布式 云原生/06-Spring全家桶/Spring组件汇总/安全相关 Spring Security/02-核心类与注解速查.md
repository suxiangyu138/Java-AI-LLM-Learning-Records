## 1. 配置体系

| 类/接口 | 用途 | 7.x 要点 |
|---------|------|---------|
| `SecurityFilterChain` | 安全过滤器链 Bean（配置入口） | 唯一合法配置形态 |
| `HttpSecurity` | 链式 DSL（Lambda 语法） | `and()` 已删除 |
| `@EnableWebSecurity` | 激活 Web 安全 | 常规必加 |
| `Customizer<HttpSecurity>` | **模块化配置 Bean（7.0 新）** | 只改局部、不动全局默认 |
| `WebSecurityCustomizer` | 忽略静态资源 | 替代旧 `WebSecurityConfigurerAdapter` 忽略写法 |
| `@EnableMethodSecurity` | 方法级安全开关 | 替代已删除的 `@EnableGlobalMethodSecurity` |

```java
@Bean
SecurityFilterChain chain(HttpSecurity http) throws Exception {
    http
        .authorizeHttpRequests(auth -> auth
            .requestMatchers("/public/**").permitAll()
            .anyRequest().authenticated())
        .formLogin(Customizer.withDefaults());
    return http.build();
}

// 7.0 模块化：局部定制（Boot 默认配置保留）
@Bean
Customizer<HttpSecurity> publicPaths() {
    return http -> http.authorizeHttpRequests(auth -> auth
            .requestMatchers("/actuator/health").permitAll());
}
```

## 2. 认证体系

| 类/接口 | 职责 | 说明 |
|---------|------|------|
| `AuthenticationManager` | 认证入口（调度 Provider） | `authenticationManager(authenticationConfiguration)` 获取 |
| `AuthenticationProvider` | 单种认证策略 | Dao/RememberMe/JWT/OTP... 各一个 |
| `DaoAuthenticationProvider` | 用户名密码认证 | 内部走 UserDetailsService + PasswordEncoder |
| `UserDetailsService` | 查询用户（自定义认证源的主入口） | `loadUserByUsername` |
| `UserDetails` / `User` | 用户模型（含权限） | 自定义实现可扩展字段 |
| `Authentication` | 认证结果对象 | `SecurityContextHolder.getContext().getAuthentication()` |
| `SecurityContextHolder` | 当前线程身份容器 | 异步场景需传播（DelegatingSecurityContext...） |
| `UsernamePasswordAuthenticationFilter` | 表单登录过滤器 | 处理 `/login` POST |
| `FactorGrantedAuthority`（7.0 新） | MFA 因素记录 | 记录"哪个因素、何时验证" |
| `MultiFactorAuthenticationManager.Builder` | MFA 构建器（7.0 新） | `.withFactor(new TimeBasedOneTimePasswordFactor(...))` |

```java
// 自定义认证源（最常见扩展）
@Service
public class UserService implements UserDetailsService {
    @Override
    public UserDetails loadUserByUsername(String username) {
        // 查 DB → 返回 User.withUsername(...).password(密文).roles(...).build()
    }
}
```

## 3. 授权体系

| 类/接口 | 职责 | 说明 |
|---------|------|------|
| `AuthorizationManager<T>` | 统一授权抽象 | 7.0 唯一入口 `authorize()`（`check()` 已删） |
| `AuthorizationDecision` | 授权决策结果 | 携带是否允许 |
| `RequestAuthorizationContext` | 请求级授权上下文 | 自定义授权器参数 |
| `authorizeHttpRequests` | 请求级授权 DSL | 替代 `authorizeRequests()` |
| `requestMatchers(...)` | 请求匹配（PathPattern） | 替代 `antMatchers`；`**` 仅限开头/结尾 |
| `AllRequiredFactorsAuthorizationManager`（7.0 新） | 要求全部 MFA 因素 | 站点级/端点级强制 |
| `AllAuthoritiesAuthorizationManager`（7.0 新） | 要求全部权限 | `hasAllRoles`/`hasAllAuthorities` |
| `spring-security-access` 模块 | 遗留授权 API | 仅存量代码 |

```java
// 自定义授权器（复杂规则推荐写法）
@Component
public class CustomAuthManager implements AuthorizationManager<RequestAuthorizationContext> {
    @Override
    public AuthorizationDecision authorize(Supplier<Authentication> auth, RequestAuthorizationContext ctx) {
        return new AuthorizationDecision(/* 规则 */);
    }
}
```

## 4. 密码与加密

| 类 | 算法 | 适用 |
|----|------|------|
| `Argon2PasswordEncoder` | Argon2id | **7.x 推荐默认**（`defaultsForSpring7()`） |
| `BCryptPasswordEncoder` | BCrypt | 存量主流（strength 10-14） |
| `SCryptPasswordEncoder` | scrypt | 内存密集抗 GPU |
| `Pbkdf2PasswordEncoder` | PBKDF2 | 标准迭代 |
| `DelegatingPasswordEncoder` | `{id}` 前缀路由 | **渐进迁移必用** |
| `PasswordEncoderFactories.createDelegatingPasswordEncoder()` | 工厂 | 直接拿 Delegating 实例 |

```java
// 存储格式：{id}前缀
"{bcrypt}$2a$12$..."    "{argon2}$argon2id$..."    "{noop}123456(仅演示)"
```

## 5. OAuth2 三件套

| 角色 | 关键类 | 配置入口 |
|------|--------|---------|
| 客户端（登录） | `OAuth2LoginAuthenticationFilter`、`OAuth2UserService` | `oauth2Login(...)` |
| 客户端（调用 API） | `OAuth2AuthorizedClient`、`OAuth2AuthorizedClientManager` | `OAuth2AuthorizedClientExchangeFilterFunction` |
| 资源服务器 | `JwtDecoder`（Nimbus）、`BearerTokenAuthenticationConverter` | `oauth2ResourceServer(rs -> rs.jwt(...))` |
| 授权服务器 | `OAuth2AuthorizationServerConfigurer`、`RegisteredClientRepository`、`OAuth2AuthorizationService` | `with(configurer, ...)` + `@Order(1)` 链 |

```yaml
# 快速对照
spring.security.oauth2.client.registration.*      # 客户端注册
spring.security.oauth2.client.provider.*          # 授权服务器信息
spring.security.oauth2.resourceserver.jwt.issuer-uri  # 资源服务器 JWT 签发方
spring.security.oauth2.resourceserver.opaque-token.* # 不透明令牌 introspection
```

## 6. 注解速查

| 注解 | 用途 | 位置 |
|------|------|------|
| `@EnableWebSecurity` | 激活 Web 安全 | 配置类 |
| `@EnableMethodSecurity` | 激活方法级安全 | 配置类 |
| `@EnableMultiFactorAuthentication`（7.0 新） | 激活 MFA | 配置类 |
| `@PreAuthorize` / `@PostAuthorize` | 方法执行前/后授权 | 方法 |
| `@PreFilter` / `@PostFilter` | 入参/返回集合过滤 | 方法 |
| `@Secured` / `@RolesAllowed` | 角色授权（旧式） | 方法 |
| `@AuthenticationPrincipal` | 注入当前认证主体 | 控制器参数 |
| `@WithMockUser` / `@WithJwt` / `@WithOAuth2User` | 测试模拟用户 | 测试方法 |

## 7. 7.x 删除/改名对照

| 旧（6.x） | 新（7.x） |
|---------|----------|
| `http.and()` | Lambda DSL（唯一） |
| `authorizeRequests()` | `authorizeHttpRequests()` |
| `antMatchers("/x/**")` | `requestMatchers("/x/**")`（PathPattern 规则） |
| `@EnableGlobalMethodSecurity` | `@EnableMethodSecurity` |
| `WebSecurityConfigurerAdapter` | `SecurityFilterChain` Bean |
| `MvcRequestMatcher`/`AntPathRequestMatcher` | `PathPatternRequestMatcher` |
| `AuthorizationManager#check` | `#authorize` |
| `@EnableAuthorizationServer` | `OAuth2AuthorizationServerConfigurer` |
| `ClientDetailsService` | `RegisteredClientRepository` |
| OAuth2 password grant | 授权码 + PKCE（或 client_credentials） |
| Jackson 2 序列化 | Jackson 3（`tools.jackson`） |

> 🎯 **速查结论**：写 7.x 配置 = Lambda DSL + requestMatchers + SecurityFilterChain Bean + @EnableMethodSecurity——五个形状记牢，其余按需查表。
