## 1. 集成地图

```text
┌─────────────────────────────────────────────────────┐
│ 请求 → Servlet 容器                                  │
│   ├── Filter 链（含 Spring Security 过滤器链，order -100）│
│   ├── DispatcherServlet（SpringMVC）                 │
│   │   ├── 拦截器（HandlerInterceptor）               │
│   │   ├── 控制器 → Service → DAO                     │
│   └── 响应                                          │
└─────────────────────────────────────────────────────┘
联动组件：
  Redis      → 会话共享 / Token 黑名单 / ShedLock 锁
  MVC        → @AuthenticationPrincipal 注入、SecurityContext 传递
  Gateway    → 网关统一认证（SecurityWebFilterChain）
  Task       → @Async 上下文传播（DelegatingSecurityContext...）
```

## 2. 与 Spring Boot / MVC 的集成

| 集成点 | 方式 | 说明 |
|--------|------|------|
| 控制器取当前用户 | `@AuthenticationPrincipal` 参数 | 首选（不污染业务层） |
| 控制器拿认证对象 | `Authentication` 参数 | 需要权限列表时 |
| MVC 拦截器与安全链 | 顺序：安全过滤器 → MVC 拦截器 | 拦截器里可读 SecurityContext |
| 异常联动 | `AccessDeniedException` → @RestControllerAdvice | 403 错误体统一（MVC 05 篇） |
| 静态资源放行 | `WebSecurityCustomizer` 或 requestMatchers permitAll | `/static/**`、`/favicon.ico` |
| 403/401 JSON 化 | `authenticationEntryPoint` / `accessDeniedHandler` | 无状态 API 标配 |

```java
// 无状态 API 的 401/403 JSON 化
http.exceptionHandling(ex -> ex
        .authenticationEntryPoint((req, res, e) -> {          // 未认证 → 401 JSON
            res.setStatus(401);
            res.getWriter().write("{\"code\":401,\"message\":\"unauthenticated\"}");
        })
        .accessDeniedHandler((req, res, e) -> {               // 无权限 → 403 JSON
            res.setStatus(403);
            res.getWriter().write("{\"code\":403,\"message\":\"forbidden\"}");
        }));
```

> 💡 **集成顺序红线**：安全过滤器链在 DispatcherServlet **之前**——Security 放行后才进入 MVC 拦截器与控制器。**在 MVC 拦截器里做鉴权是绕过了安全链**（除非是补充性检查）。

## 3. 与 Redis / 分布式体系的集成

| 场景 | 方案 | 联动文档 |
|------|------|---------|
| Session 共享（多实例） | Spring Session + Redis（spring-session-data-redis） | Spring Data Redis 体系 |
| JWT 黑名单（登出即时性） | Redis 存 jti + 过期时间 | [Spring Data Redis](../../Spring Data Redis/00-Spring Data Redis知识体系总览.md) |
| 登录限流 | Redis 计数 + Lua | Spring Data Redis 04 篇 |
| MFA TOTP secret 存储 | Redis/DB 加密存储 | 本体系 02 篇 |
| OAuth2 令牌存储 | Jdbc（标准）/ Redis 自定义 | 本体系 09 篇 |

```yaml
# 多实例 Session 共享
spring:
  session:
    store-type: redis
```

> ⚠️ **注意**：Boot 4 + Jackson 3 下 Session/Remember-Me 令牌序列化格式变化——升级后**存量会话会失效**（用户需重新登录），属预期行为。

## 4. 与网关 / 微服务的集成

| 架构 | 做法 | 说明 |
|------|------|------|
| 网关统一认证 | Spring Cloud Gateway + `SecurityWebFilterChain`（WebFlux 安全） | 验签 + 白名单 + 透传 |
| 服务信任网关 | 内部服务关闭安全或信任重写头 | 内网信任模型 |
| 服务各自校验 | 每服务 `oauth2ResourceServer` | 纵深防御（金融级） |
| 身份透传 | 网关重写 `X-User-Id`/`X-Roles` 头 | **必须由网关覆盖，禁止信任客户端直传** |

```java
// 网关（WebFlux 安全链）
@Bean
SecurityWebFilterChain gatewayChain(ServerHttpSecurity http) throws Exception {
    return http
            .csrf(csrf -> csrf.disable())
            .authorizeExchange(ex -> ex
                    .pathMatchers("/auth/**", "/public/**").permitAll()
                    .anyExchange().authenticated())
            .oauth2ResourceServer(rs -> rs.jwt(Customizer.withDefaults()))
            .build();
}
```

## 5. 高频问题速查

| 现象 | 根因 | 处理 |
|------|------|------|
| 升级 Boot 4 后接口全 403 | CSRF 默认覆盖 API | 无状态 API 显式 `csrf.disable()`（有 Cookie 会话则用 `csrf.spa()`） |
| 401 变跳登录页 | 无状态 API 未配 EntryPoint | `authenticationEntryPoint` 返回 401 JSON |
| 配置不生效 | 多个 SecurityFilterChain Bean 或 @Order 冲突 | 检查链匹配（securityMatcher）与 Order |
| @PreAuthorize 不生效 | 未开 @EnableMethodSecurity | 开启注解 |
| 异步线程身份为 null | ThreadLocal 不传播 | `DelegatingSecurityContextAsyncTaskExecutor` |
| 密码校验失败 | 编码器不匹配（{id} 前缀） | 确认存储格式与 PasswordEncoder 一致 |
| JWT 在 jwt.io 能解、接口 401 | 签名/公钥不匹配 | 检查 jwk-set-uri 与算法 |
| 有效令牌 401（升级后） | typ 头默认校验 | 签发方输出标准 typ 或评估兼容 |
| 老授权服务器握手失败 | PKCE 默认强制 | 升级对方或显式配置兼容 |
| 登录表单 403 | CSRF 令牌缺失 | 表单带 csrf 隐藏域/前端头 |

## 6. 排障三把钥匙

```text
钥匙一：分清 401 与 403
  401 = 认证失败（没令牌/坏令牌）→ 查认证链（EntryPoint/Provider）
  403 = 授权失败（有身份无权限）→ 查授权规则（requestMatchers/方法注解）

钥匙二：先看链再看配置
  请求是否进入安全链？（断点 SecurityFilterChain）
  哪条链匹配？（多链时 securityMatcher 是否命中）
  哪环拒绝？（CSRF → 认证 → 授权 逐环排查）

钥匙三：日志与测试兜底
  开启 DEBUG 日志（logging.level.org.springframework.security=DEBUG）
  SecurityMockMvc 写授权规则测试（升级迁移必备）
```

> 🎯 **速查结论**：集成地图一句话——**安全链在最外层**（容器 Filter），MVC/业务在里层；联动 Redis 管"会话/黑名单/限流"，联动网关管"统一认证 + 身份透传"。排障先分 401/403，再看链、再查配置，最后用测试锁定。
