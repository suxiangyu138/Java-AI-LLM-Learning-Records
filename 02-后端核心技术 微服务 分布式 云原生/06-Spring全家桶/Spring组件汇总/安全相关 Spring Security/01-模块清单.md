## 1. 模块总览

```text
spring-security-core          ← 认证/授权核心抽象（必选，被一切模块依赖）
├── config                    ← 配置 DSL（HttpSecurity 等）
├── web                       ← 过滤器链/Servlet 集成（Servlet 应用必选）
├── oauth2-core / client / jose / resource-server / authorization-server
├── ldap / cas / saml / acl / crypto / data / messaging
└── 7.0 新增：spring-security-access（遗留授权 API 可选模块）
```

> 🎯 **要点**：绝大多数应用不需要手动引模块——**用 Spring Boot Starter 一站式引入**（第 6 节）。手动引依赖的场景：纯 Spring（无 Boot）、特殊模块组合。

## 2. 核心与配置模块

| Artifact | 职责 | 关键类 |
|---------|------|--------|
| `spring-security-core` | 认证/授权核心抽象（必选） | `Authentication`、`AuthenticationManager`、`AuthorizationManager`、`PasswordEncoder`、`UserDetailsService`、`SecurityContextHolder` |
| `spring-security-config` | 配置 DSL 与注解支持 | `HttpSecurity`、`@EnableWebSecurity`、`@EnableMethodSecurity` |
| `spring-security-crypto` | 密码编码与加解密 | `BCryptPasswordEncoder`、`Argon2PasswordEncoder`（7.x） |
| `spring-security-access`（7.0 新） | 遗留授权 API（可选） | `AccessDecisionManager`、`AccessDecisionVoter` |

> ⚠️ **7.0 注意**：`AccessDecisionManager`/`@EnableGlobalMethodSecurity` 等遗留 API 迁入 `spring-security-access`——**只有存量代码需要**；新代码用 AuthorizationManager。

## 3. Web 模块

| Artifact | 职责 | 关键类/过滤器 |
|---------|------|-------------|
| `spring-security-web` | Servlet 过滤器链与集成 | `SecurityFilterChain`、`FilterChainProxy`、`SecurityContextHolderFilter`、`CsrfFilter`、`AuthorizationFilter` |
| `spring-security-web`（复用） | 表单/Basic/会话 | `UsernamePasswordAuthenticationFilter`、`ExceptionTranslationFilter` |
| `spring-security-oauth2-core` | OAuth2 通用模型 | `OAuth2AuthorizedClient`、`OAuth2AccessToken` |
| `spring-security-oauth2-client` | OAuth2 客户端 | `OAuth2LoginAuthenticationFilter`、`OAuth2AuthorizedClientManager` |
| `spring-security-oauth2-jose` | JOSE/JWT 实现 | `NimbusJwtEncoder`、`JwtDecoder` |
| `spring-security-oauth2-resource-server` | 资源服务器 | `BearerTokenAuthenticationFilter`、`BearerTokenAuthenticationConverter` |
| `spring-security-oauth2-authorization-server` | 授权服务器（**7.0 并入核心**） | `OAuth2AuthorizationServerConfigurer`、`RegisteredClientRepository` |

## 4. OAuth2 / OIDC 模块

| 场景 | 需要模块 | 启用配置 |
|------|---------|---------|
| 第三方登录（GitHub/企业） | `oauth2-client` | `oauth2Login(...)` |
| 保护 API（校验 JWT） | `oauth2-resource-server` + `oauth2-jose` | `oauth2ResourceServer(rs -> rs.jwt(...))` |
| 自建发令牌服务 | `oauth2-authorization-server`（并入核心后随 `spring-boot-starter-security`） | `OAuth2AuthorizationServerConfigurer` |
| 服务间调用（WebClient/RestTemplate） | `oauth2-client` | `OAuth2AuthorizedClientExchangeFilterFunction` |

**7.0 变化：**

- `spring-authorization-server` 独立项目并入 Spring Security，坐标不变、版本跟随（`7.0.0`）；
- PKCE 默认强制（`requireProofKey=true`）；
- Password grant（密码模式）移除——OAuth 2.1 语义；
- JWT `typ` 头默认校验。

## 5. 数据与集成模块

| Artifact | 职责 | 典型用途 |
|---------|------|---------|
| `spring-security-ldap` | LDAP 认证 | 企业目录登录 |
| `spring-security-saml2-service-provider` | SAML2 SP | 对接老式 IdP |
| `spring-security-cas` | CAS 单点登录 | 老架构 |
| `spring-security-acl` | 领域对象 ACL | 细粒度对象权限 |
| `spring-security-messaging` | WebSocket 安全 | STOMP 鉴权 |
| `spring-security-data` | Spring Data 集成 | 审计字段（@CreatedBy） |
| `spring-security-test` | 测试支持 | `@WithMockUser`、`SecurityMockMvc` |

> 💡 **集成经验**：LDAP/SAML/CAS 都是"替换 AuthenticationProvider 或加一个过滤器"——理解 [02-核心类速查](02-核心类与注解速查.md) 的 Provider 抽象后，接任何认证源都是加配置。

## 6. Spring Boot Starter 对照

| Starter | 包含 | 适用 |
|---------|------|------|
| `spring-boot-starter-security` | core + config + web + oauth2-client + **authorization-server（7.0 起）** | 常规 Web 应用（含自建授权服务器） |
| `spring-boot-starter-oauth2-client` | oauth2-client 全套 | 只需客户端登录 |
| `spring-boot-starter-oauth2-resource-server` | resource-server + jose | 只需保护 API |
| `spring-boot-starter-webflux` + security | 响应式安全（WebFlux） | 响应式应用 |

> ⚠️ **依赖选择**：`spring-boot-starter-security` 已含授权服务器能力（7.0 起）——**不要再引独立的 `spring-authorization-server` 旧坐标**（会版本冲突或双份）。
