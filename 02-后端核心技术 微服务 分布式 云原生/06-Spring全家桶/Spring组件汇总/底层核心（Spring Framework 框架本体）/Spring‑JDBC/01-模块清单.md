## 1. Artifact 坐标与版本线

| 项 | 值 |
|----|----|
| GroupId | `org.springframework` |
| ArtifactId | `spring-jdbc` |
| 最新版本 | 7.0.x（2026-08 时点，随 Framework 7.0 主线） |
| 维护线 | 7.0.x / 7.1.x（最新）、6.2.x（Boot 3.x） |
| Java 基线 | 17+；Jakarta EE 11 基线（7.0） |
| 常用配套 | spring-tx（事务）、HikariCP/Druid（连接池）、spring-boot-starter-jdbc（Boot） |

> 💡 Boot 4 中 `spring-boot-starter-jdbc` 自动装配 `DataSource`、`JdbcTemplate`、`JdbcClient`、`DataSourceTransactionManager`——业务代码无需任何配置即可注入。

## 2. 包结构地图

```text
org.springframework.jdbc
├── core                   ★ 模板层
│   ├── JdbcTemplate / NamedParameterJdbcTemplate / JdbcClient（★ 7.0 主推）
│   ├── JdbcOperations / NamedParameterJdbcOperations（接口，模板的抽象）
│   ├── RowMapper / ResultSetExtractor / RowCallbackHandler / PreparedStatementSetter
│   ├── StatementCreatorUtils / ArgumentPreparedStatementSetter
│   └── ColumnMapRowMapper / SingleColumnRowMapper
├── core.support
│   ├── JdbcDaoSupport（★ 7.0 废弃 #35145）/ SqlUpdate / StoredProcedure（旧对象映射）
│   └── KeyHolder / GeneratedKeyHolder（自增主键回填）
├── datasource             ★ 数据源
│   ├── DriverManagerDataSource / SingleConnectionDataSource / SimpleDriverDataSource
│   ├── DataSourceUtils（连接获取/释放/事务绑定）★
│   ├── TransactionAwareDataSourceProxy / LazyConnectionDataSourceProxy
│   ├── init：DatabasePopulator / ResourceDatabasePopulator / DataSourceInitializer
│   └── embedded：EmbeddedDatabaseBuilder（H2/H2 内存库测试）
├── object                # 旧式对象映射（SqlQuery 等，已边缘）
├── support               # SQLErrorCodeSQLExceptionTranslator 等异常翻译 ★
└── config?（无独立 config 包；XML 命名空间在 spring-tx/context）
```

**高频面试点名类**：`JdbcTemplate`、`JdbcClient`、`RowMapper`、`DataSourceUtils`（连接与事务绑定）、`SQLErrorCodeSQLExceptionTranslator`。

## 3. 7.0 废弃与移除清单

| 项 | 状态 | 替代 |
|----|------|------|
| `NamedParameterJdbcTemplate` | 废弃（待移除） | `JdbcClient`（命名参数内建）或 `JdbcTemplate` |
| `JdbcDaoSupport` 等 `DaoSupport` 类 | 废弃（#35145） | 组合注入 `JdbcTemplate`/`JdbcClient` |
| `queryForObject(sql, Array)` Kotlin 扩展 | 替换（#35846） | vararg 版本（`sql, vararg args`） |
| `org.springframework.orm.hibernate5` | 迁移（spring-orm） | `org.springframework.orm.jpa.hibernate`（JPA 3.2/Hibernate 7） |
| `DataSourceUtils` 等核心 API | 稳定 | - |

> ⚠️ **升级提示**：① 新代码不写 NamedParameterJdbcTemplate；② 存量迁移示例：`namedTpl.queryForObject(sql, params, Type)` → `jdbcClient.sql(sql).params(map).query(Type).single()`；③ Kotlin 调用处改 vararg。

## 4. 依赖边界

| 依赖 | 方向 | 说明 |
|------|------|------|
| `spring-core` / `spring-beans` | 依赖 | 工具、资源（SQL 脚本）、Bean 属性填充 |
| `spring-tx` | 依赖 | `DataSourceTransactionManager` 定义在 spring-tx，jdbc 提供实现 |
| JDBC 驱动（mysql-connector-j 等） | 运行时 | 编译期不需要 |
| 连接池（HikariCP/Druid） | 运行时 | 提供 `javax.sql.DataSource` 实现 |
| 反向依赖 | - | spring-orm（JPA）、spring-boot-starter-jdbc 依赖它 |

> 🎯 **核心要点**：spring-jdbc **不内置连接池**——`DriverManagerDataSource` 只是教学实现，生产必须配 HikariCP/Druid；连接池通过 `javax.sql.DataSource` SPI 接入，Spring 对此零侵入。

## 5. 版本兼容速查

| Spring Framework | Spring Boot | 备注 |
|------------------|-------------|------|
| 7.0.x（2025-11 起） | Boot 4.0.x | 当前主线；JdbcClient 语句级配置；NamedParameterJdbcTemplate 废弃 |
| 7.1.x（2026-05 起） | Boot 4.1.x | 最新维护线 |
| 6.2.x | Boot 3.4/3.5 | 存量主流；JdbcClient 可用（6.1+）但无语句级配置 |

> 💡 JdbcClient 的演进速记：6.1 诞生（fluent API）→ 7.0 增强（fetchSize/maxRows/queryTimeout 语句级配置 + 命名参数收编）——面试答"JdbcClient 什么时候出的、7.0 加了什么"按此。
