## 1. ResolvableType：运行时泛型解析

**痛点**：Java 泛型在运行时被擦除——`List<String>` 反射只能拿到 `List`。

```java
// 直接擦除：拿不到泛型参数
Field field = Foo.class.getDeclaredField("list");
System.out.println(field.getGenericType());   // java.util.List<java.lang.String>（源码可用）
// 但运行时 new ArrayList<String>() 传参后，对象层面已不可知

// ResolvableType：从字段/方法/类声明还原泛型
ResolvableType rt = ResolvableType.forField(Foo.class.getDeclaredField("list"));
rt.getGeneric(0).getType();                    // class java.lang.String

// 类层次泛型：class MyRepo implements Repository<Order>
ResolvableType.forClass(MyRepo.class).as(Repository.class).getGeneric(0).resolve();  // Order
```

| 场景 | 用法 |
|------|------|
| 字段泛型 | `ResolvableType.forField(field)` |
| 方法返回/参数 | `forMethodParameter(method, 0)` |
| 类层次 | `forClass(impl).as(iface).getGeneric(0)` |
| 集合/Map 嵌套 | `getGeneric(0)`、`getGeneric(1)`、`as(Collection.class)` |

> 🎯 **核心要点**：Spring 能"泛型注入"（`Repository<Order>` 按类型参数匹配候选）靠的正是 ResolvableType——它是 `@Autowired` 泛型匹配（见 [Spring-Beans-06](../Spring‑Beans/06-依赖注入与自动装配速查.md)）的底层引擎。

## 2. TypeDescriptor 与类型元数据

| 类型 | 职责 |
|------|------|
| `TypeDescriptor` | 类型描述（class + 泛型 + 注解），转换与校验用 |
| `GenericTypeResolver` | `resolveReturnType(method, clazz)` 等泛型解析工具 |
| `MethodParameter` | 方法参数描述（含注解），注入点解析基础 |
| `ParameterNameDiscoverer` | 方法参数名发现（字节码参数名，`-parameters` 编译选项） |

```java
TypeDescriptor source = TypeDescriptor.valueOf(String.class);
TypeDescriptor target = TypeDescriptor.valueOf(Integer.class);
boolean supported = conversionService.canConvert(source, target);
```

> 💡 `MethodParameter` + `ParameterNameDiscoverer` 是构造器注入"按参数名回退匹配"（见 Beans-06 裁决链）的基础设施。

## 3. 类型转换三时代：PropertyEditor → ConversionService

| 时代 | 机制 | 现状 |
|------|------|------|
| 1.0 | `PropertyEditor`（java.beans，JDK 1.0 设计） | 仍兼容（XML/占位符兜底），新代码不写 |
| 3.0+ | `ConversionService` + `Converter`（类型安全、泛型友好） | ✅ 标准（Spring MVC/占位符/绑定默认走它） |
| 3.2+ | `Formatter`（转换 + 解析 + 显示三合一，i18n 友好） | MVC 展示层首选（spring-context 提供） |

```text
转换请求（如 @Value("${pool.size}") 注入 int）：
  String → Integer：ConversionService 找 Converter<String,Integer>（内建）
  失败 → PropertyEditor 兜底 → 异常
```

| API | 语义 |
|-----|------|
| `ConversionService` | 门面：`convert(source, targetType)` / `canConvert` |
| `Converter<S,T>` | 简单转换：`convert(S) → T` |
| `ConverterFactory<S,R>` | 一族目标类型（如 String → Number 家族） |
| `GenericConverter` | 复杂转换（带类型上下文，如集合/Map） |
| `ConditionalConverter` | 条件激活：`matches(sourceType, targetType)` |
| `DefaultConversionService` | 内建 60+ 转换器（Number/日期/集合/枚举/字符串） |

> ⚠️ 边界：`Formatter` 在 **spring-context**（`format` 包）；`Converter` 族与 `ConversionService` 在 **spring-core**——归属不同模块，面试归类别混。

## 4. Converter 一族

```java
// 简单转换器：注册进容器后，@Value/绑定/MVC 自动使用
@Component
public class MoneyConverter implements Converter<String, Money> {
    @Override
    public Money convert(String source) {
        return Money.parse(source);        // "12.50" → Money(12.50)
    }
}

// 一族转换：String → 任意 Number 子类
public class StringToNumberConverterFactory
        implements ConverterFactory<String, Number> {
    @Override
    public <T extends Number> Converter<String, T> getConverter(Class<T> targetType) {
        return source -> (T) NumberUtils.parseNumber(source, targetType);
    }
}

// 带源类型判断的条件转换器
@Component
public class ConditionMoneyConverter implements Converter<String, Money>, ConditionalConverter {
    @Override
    public boolean matches(TypeDescriptor sourceType, TypeDescriptor targetType) {
        return Money.class.isAssignableFrom(targetType.getType());
    }
    // ...
}
```

> 💡 注册方式：① `@Component` + Boot 自动注册到 Web 层 ConversionService；② 纯 Spring：实现 `WebMvcConfigurer.addFormatters`（web）或 `ConversionServiceFactoryBean`/`DefaultFormattingConversionService` 装配。

## 5. 转换链与自定义转换器

```text
自定义转换器生效链路（@Value / 绑定 / MVC 参数）：
  1. 容器创建 ConversionService（Boot：webConversionService，含全部 Converter Bean）
  2. 转换请求到达 → 类型匹配查找（含 GenericConverter 条件）
  3. 命中 Converter → 转换；未命中 → 抛 ConversionFailedException
```

| 场景 | 做法 |
|------|------|
| @Value 注入自定义类型 | Converter<String, T> 注册进容器（Boot 自动收集） |
| MVC 请求参数绑定 | `Converter<String,T>`（web 层 `addFormatters`）或 `Formatter<T>` |
| 属性文件 → 对象 | Boot `@ConfigurationProperties`（内建宽松绑定转换） |
| 集合嵌套转换 | `GenericConverter`（`String[] → List<Money>`） |

> ⚠️ **排查提示**：`ConversionFailedException` = 目标类型无法从源转换——先确认 Converter 是否注册、类型是否匹配；`canConvert` 返回 false 时检查 `ConditionalConverter.matches` 条件。
