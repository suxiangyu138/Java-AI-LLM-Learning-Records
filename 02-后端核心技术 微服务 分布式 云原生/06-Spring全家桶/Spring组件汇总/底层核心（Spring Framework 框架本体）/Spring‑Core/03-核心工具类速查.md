## 1. 工具类总表

| 工具类 | 定位 | 替代品参考 |
|--------|------|-----------|
| `Assert` | 契约断言（缺省即抛 IllegalArgumentException） | - |
| `StringUtils` | 字符串判空/裁剪/驼峰 | Apache Commons Lang `StringUtils` |
| `ObjectUtils` | null 安全比较/toString/判空 | JDK `Objects` |
| `CollectionUtils` | 集合判空/合并/查找 | - |
| `ReflectionUtils` | 反射操作封装 | - |
| `ClassUtils` | 类加载/判断/短名 | - |
| `MethodInvoker` | 方法调用封装（含参数类型匹配） | - |
| `StopWatch` | 秒表计时 | - |
| `NamedThreadLocal` | 命名 ThreadLocal（易排查） | - |
| `ConcurrentReferenceHashMap` | 弱/软引用并发 Map | Caffeine 等 |
| `NumberUtils` / `SystemPropertyUtils` / `PropertiesLoaderUtils` | 数值/系统属性/属性加载 | - |

> 💡 使用原则：Spring 工具是"零依赖内建"，但**不代表最优**——判空优先 JDK `Objects`、并发 Map 优先 Caffeine；Spring 工具胜在"容器内天然一致"（如 `ReflectionUtils` 兼容 record/泛型）。

## 2. Assert：断言

| 方法 | 失败异常 |
|------|---------|
| `Assert.notNull(obj, msg)` | IllegalArgumentException |
| `Assert.hasText(str, msg)`（非 null 且含非空白） | IllegalArgumentException |
| `Assert.isTrue(cond, msg)` | IllegalArgumentException |
| `Assert.state(cond, msg)` | IllegalStateException |
| `Assert.isInstanceOf(Class, obj)` / `Assert.isAssignable(...)` | IllegalArgumentException |
| `Assert.notEmpty(Collection/Map/array, msg)` | IllegalArgumentException |

```java
public void create(Order order) {
    Assert.notNull(order, "order must not be null");
    Assert.hasText(order.getOrderNo(), "orderNo must have text");
    Assert.isTrue(order.getAmount().signum() > 0, "amount must be positive");
    // ...业务
}
```

> 💡 与 JDK `Objects.requireNonNull` 差异：Assert 提供消息 + 类型化异常；服务层参数校验**首选 Jakarta Validation（@Valid）+ 全局异常**，Assert 用于"程序内契约"（内部错误，非用户输入错误）。

## 3. StringUtils 与 ObjectUtils

```java
// StringUtils 高频
StringUtils.hasText(name);                 // 非 null 非空白（比 !"".equals 严谨）
StringUtils.capitalize("order");           // "Order"
StringUtils.uncapitalize("Order");         // "order"
StringUtils.arrayToDelimitedString(arr, ",");  // a,b,c
StringUtils.replace(uri, "{id}", "123");   // 模板替换
StringUtils.split("a,b,c", ",");           // 不保留空串（注意与 split(",") 差异）

// ObjectUtils 高频
ObjectUtils.nullSafeEquals(a, b);          // 全 null 视为相等
ObjectUtils.nullSafeToString(obj);         // 不会 NPE
ObjectUtils.isEmpty(str / arr / map);      // null 或空
ObjectUtils.containsConstant(enumClass, name);  // 枚举常量模糊匹配
```

> ⚠️ 命名陷阱：Spring `StringUtils.split` 与 JDK `String.split` 行为不同（Spring 版不保留尾部空元素）；判空用 `hasText`/`hasLength`（含空白判定差异），别用 `!str.isEmpty()` 直接判断。

## 4. 反射三件套：ReflectionUtils / ClassUtils / MethodInvoker

```java
// ReflectionUtils：异常被包装为 UndeclaredThrowableException，可用 handleReflectionException 规整
Method m = ReflectionUtils.findMethod(OrderService.class, "create", Long.class);
ReflectionUtils.invokeMethod(m, service, 1L);

// 遍历类的全部方法（含父类）
ReflectionUtils.doWithMethods(OrderService.class,
        method -> System.out.println(method.getName()),
        method -> method.isAnnotationPresent(MyAnnotation.class));

// 字段操作
ReflectionUtils.makeAccessible(field);         // private 也可见
ReflectionUtils.setField(field, target, value);

// 构造器推断（Spring 内部大量使用）
Constructor<?> ctor = ReflectionUtils.accessibleConstructor(OrderService.class, Long.class);

// ClassUtils
ClassUtils.forName("com.example.OrderService", cl);
ClassUtils.isPresent("jakarta.persistence.Entity", cl);    // 依赖探测（自动配置用）
ClassUtils.getShortName(OrderService.class);               // "OrderService"
ClassUtils.getDefaultClassLoader();                        // 上下文类加载器
```

> 🎯 **核心要点**：反射工具的意义不是"省几行代码"，而是**统一异常处理**（InvocationTargetException/IllegalAccessException → `UndeclaredThrowableException`）与 **Spring 内部一致语义**（泛型、record、Kotlin 数据类都考虑在内）——写框架级代码时用它，业务代码少用。

## 5. StopWatch 与其他

```java
// StopWatch：多段计时
StopWatch sw = new StopWatch("pipeline");
sw.start("step1");  // ... 
sw.stop();
sw.start("step2");  // ...
sw.stop();
System.out.println(sw.prettyPrint());   // 每段耗时 + 占比表
```

| 工具 | 说明 |
|------|------|
| `StopWatch` | 多段秒表；生产环境慎用（`sw.isRunning()` 防忘停） |
| `NamedThreadLocal` | 命名 ThreadLocal，日志可读性翻倍 |
| `ConcurrentReferenceHashMap` | 弱引用缓存 Map（元数据缓存场景） |
| `SystemPropertyUtils` | 系统属性解析（含默认值/占位符） |
| `PropertiesLoaderUtils` | 加载 .properties（含 classpath 多源） |
| `FileCopyUtils` / `StreamUtils` | 流/文件复制（`copyToString` 等） |
| `AopUtils`/`ClassUtils.getUserClass` | 代理类还原原始类（**排查代理类型必备**） |

> ⚠️ **排查技巧**：`AopUtils.isAopProxy(obj)` / `ClassUtils.getUserClass(obj.getClass())`——判断对象是否被代理、拿到被代理的真实类，是"为什么注解不生效"排查的第一步。
