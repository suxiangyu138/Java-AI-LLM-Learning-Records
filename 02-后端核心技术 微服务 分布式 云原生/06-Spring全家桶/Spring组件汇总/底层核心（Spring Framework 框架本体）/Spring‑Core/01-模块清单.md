## 1. Artifact 坐标与版本线

| 项 | 值 |
|----|----|
| GroupId | `org.springframework` |
| ArtifactId | `spring-core` |
| 最新版本 | 7.0.x（2026-08 时点，随 Framework 7.0 主线） |
| 维护线 | 7.0.x / 7.1.x（最新）、6.2.x（Boot 3.x） |
| Java 基线 | 17+（官方推荐 JDK 25 LTS；7.0 起 Java 24+ 自动用 Class-File API 扫描） |
| 可选伴侣 | Kotlin 2.2（core 提供 Kotlin 扩展）、GraalVM 25（AOT 运行时提示） |

> 💡 项目几乎从不显式声明 spring-core——`spring-beans` 传递依赖它；但**移除过时依赖排查**时要知道它是"万物之根"。

## 3. spring-jcl 移除与日志体系（7.0）

| 版本线 | 日志机制 |
|--------|---------|
| ≤ 6.2 | spring-jcl 模块：`SpringJclLog` 自动桥接（Log4j2/Logback/JDK 内置，无依赖） |
| 7.0+ | **spring-jcl 移除**，直接依赖 Apache Commons Logging 1.3.0（`org.apache.commons.logging`） |

```xml
<!-- 7.0 传递依赖即满足 -->
<dependency>
    <groupId>org.springframework</groupId>
    <artifactId>spring-core</artifactId>
    <version>7.0.6</version>
</dependency>
<!-- 无需再显式声明 org.springframework:spring-jcl -->
```

> ⚠️ **升级注意**：① 移除项目中显式声明的 `spring-jcl` 坐标；② 项目依赖 commons-logging 冲突时需检查传递版本（Commons Logging 1.3.0+）；③ 自定义日志桥接（如 SLF4J 的 `slf4j-jcl`）不受影响——应用层日志仍是 SLF4J/Logback 正常运作。

## 4. 依赖边界

```text
spring-core（零核心依赖）
  ├── 编译必需：无（纯 JDK）
  ├── 可选：kotlin-stdlib（Kotlin 扩展）、commons-logging 1.3（日志）
  └── 被依赖：spring-beans / spring-context / spring-aop / spring-web / Boot 全家
```

| 关系 | 说明 |
|------|------|
| core → 其他模块 | **零依赖**（地基特性） |
| beans → core | 注解（@Component 定义在 core）、工具、ConversionService |
| context → core | Environment 接口、SpEL、Resource 抽象、retry |
| aop/tx/web → core | 通用能力全部下沉 |

> 🎯 **核心要点**：`@Component`/`@Service` 定义在 **core 的 `org.springframework.stereotype`**；`Environment`/`PropertyResolver` 在 **core 的 `org.springframework.core.env`**——"注解与接口在 core、容器在 beans、企业容器在 context"是模块地图的三根支柱。

## 5. 版本兼容速查

| Spring Framework | Spring Boot | 备注 |
|------------------|-------------|------|
| 7.0.x（2025-11 起） | Boot 4.0.x | 当前主线；core.retry / JSpecify / glob AOT 提示 |
| 7.1.x（2026-05 起） | Boot 4.1.x | 最新维护线 |
| 6.2.x | Boot 3.4/3.5 | 存量主流；spring-jcl 仍存在、Spring Retry 独立项目 |

> 💡 **升级提示（6.x → 7.x）**：① 移除 spring-jcl 显式依赖；② `ListenableFuture` 相关代码改 `CompletableFuture`；③ 若用独立 spring-retry 项目：API 已在 7.0 内建（`core.retry`），移除外部依赖并迁移注解（`maxAttempts` → `maxRetries`）；④ AOT 资源提示改 glob 写法（[00-总览](00-Spring Core组件总览.md) 第 2 节）。
