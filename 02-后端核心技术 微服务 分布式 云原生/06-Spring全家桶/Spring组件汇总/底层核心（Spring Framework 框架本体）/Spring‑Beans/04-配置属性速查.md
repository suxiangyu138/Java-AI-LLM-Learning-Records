## 1. 配置入口总览

```text
Bean 定义来源（殊途同归 → BeanDefinition）
├── XML：<beans>/<bean>/<context:component-scan>      → XmlBeanDefinitionReader
├── 注解：@Component 扫描 / @Bean                      → ConfigurationClassPostProcessor
├── 程序化：BeanRegistrar（7.0 推荐） / Registry API    → 直接注册
└── Groovy：BeanBuilder（7.x 已边缘化，不展开）
```

> 💡 现代项目 99% 用"注解 + Java Config"，XML 仅存量系统；但 Spring Boot 自动配置的"条件装配"逻辑本质仍是 `@Conditional` + 配置属性联动，故属性速查必须会。

## 2. XML 命名空间速查

```xml
<?xml version="1.0" encoding="UTF-8"?>
<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xmlns:context="http://www.springframework.org/schema/context"
       xsi:schemaLocation="
           http://www.springframework.org/schema/beans
           https://www.springframework.org/schema/beans/spring-beans.xsd
           http://www.springframework.org/schema/context
           https://www.springframework.org/schema/context/spring-context.xsd">

    <context:component-scan base-package="com.example"/>   <!-- 注解扫描入口 -->

    <bean id="orderService" class="com.example.OrderService"
          scope="singleton" lazy-init="false" primary="true"
          init-method="init" destroy-method="close" depends-on="dataSource">
        <property name="repo" ref="orderRepo"/>
        <property name="pageSize" value="20"/>
    </bean>

    <!-- 构造器注入 + 集合 -->
    <bean id="orderRepo" class="com.example.OrderRepo">
        <constructor-arg index="0" value="mysql"/>
        <property name="handlers">
            <list><ref bean="h1"/><ref bean="h2"/></list>
        </property>
    </bean>
</beans>
```

| 属性/元素 | 含义 |
|-----------|------|
| `id` / `name` | Bean 名 / 别名（逗号分隔） |
| `class` | 全限定类名 |
| `scope` | 作用域（singleton/prototype/custom） |
| `lazy-init` | 是否懒加载（对 singleton 生效） |
| `primary` | 首选候选 |
| `init-method` / `destroy-method` | 初始化/销毁回调 |
| `depends-on` | 显式依赖（逗号分隔多个） |
| `autowire` | byName/byType/constructor（现代不推荐，用注解） |
| `<property name="x" ref="beanId"/>` | setter 注入 |
| `<constructor-arg index/name value/ref/>` | 构造器注入 |
| `<context:property-placeholder location="classpath:db.properties"/>` | 属性占位符解析器 |

## 3. Java Config 速查

```java
@Configuration                              // Full 模式配置类
@PropertySource("classpath:app.properties") // 加载属性文件
@ComponentScan(basePackages = "com.example",
               excludeFilters = @ComponentScan.Filter(type = FilterType.REGEX, pattern = ".*Mock"))
public class AppConfig {

    @Bean(name = {"pool", "connectionPool"}, destroyMethod = "close")
    @Lazy(value = false)
    @Primary
    public ConnectionPool pool(@Value("${pool.size:8}") int size) {
        return new ConnectionPool(size);
    }
}
```

| 注解属性 | 说明 |
|---------|------|
| `@Bean.name` / `value` | 名称（默认方法名；可多别名） |
| `@Bean.autowireCandidate` | 是否参与自动装配（false = 只能显式引用） |
| `@Bean.initMethod` / `destroyMethod` | 字符串方式指定（`destroyMethod = ""` 可关掉默认推断） |
| `@Configuration.proxyBeanMethods` | true（默认）@Bean 互调走代理保单例；false 提速（Lite 语义） |
| `@ComponentScan.lazyInit` | 扫描出的 Bean 统一懒加载 |
| `@ComponentScan.FilterType` | ANNOTATION / ASSIGNABLE_TYPE / REGEX / ASPECTJ / CUSTOM |

> ⚠️ **destroyMethod 默认推断陷阱**：`@Bean` 默认会查找 public `close()`/`shutdown()` 等约定方法作为销毁回调——若你的类恰好有同名方法但语义不是释放资源，需显式 `destroyMethod = ""` 关闭。

## 4. Spring Boot 属性速查

| 属性 | 默认 | 说明 |
|------|------|------|
| `spring.main.lazy-initialization` | false | 全局懒加载（开发期提速利器） |
| `spring.main.allow-bean-definition-overriding` | false | 同名 BeanDefinition 覆盖开关 |
| `spring.main.allow-circular-references` | false（7.0/Boot 4） | 循环依赖开关（Boot 2.6 起默认禁止，见 06 篇） |
| `spring.beaninfo.ignore` | true | 忽略 `BeanInfo` 类（JDK BeanInfo 元数据） |
| `spring.aop.proxy-target-class` | true（Boot 4） | CGLIB vs JDK 代理全局开关 |
| `spring.config.import` | - | 引入额外配置文件（`optional:` 前缀可容错） |
| `spring.profiles.active` | - | 激活 profile |
| `spring.messages.*` | - | MessageSource（context 层，Bean 相关少用） |

```yaml
spring:
  main:
    lazy-initialization: true        # 开发期全局懒加载
    allow-circular-references: false # 保持关闭，改代码而不是开开关
  beaninfo:
    ignore: true
  profiles:
    active: dev
```

> 💡 **与 beans 直接相关的其实很少**——Boot 属性主要在 autoconfigure 层；beans 层的"配置"更多由 `@Value` + `@ConfigurationProperties`（见 Spring Boot 系列）消费。

## 5. BeanRegistrar 注册规格速查（7.0）

`BeanRegistry.registerBean` 的规格 lambda 完整选项：

| 选项 | 默认 | 语义 |
|------|------|------|
| `prototype()` | false（单例） | 原型作用域 |
| `lazyInit()` | false | 懒加载 |
| `primary()` | false | 首选候选（= @Primary） |
| `fallback()` | false | 兜底候选（= @Fallback，7.0） |
| `backgroundInit()` | false | 后台异步初始化（不阻塞启动） |
| `autowirable(boolean)` | true | 是否自动装配候选 |
| `infrastructure()` | false | 标记为基础设施 Bean（框架级） |
| `order(Integer)` | null | 排序 |
| `description(String)` | null | 描述 |
| `supplier(Function<BeanRegistry, Object>)` | - | 实例化供应商（AOT 友好，可用 `ctx.bean(Clazz)` 取依赖） |

```java
registry.registerBean("ds", DataSource.class, spec -> spec
    .prototype()
    .backgroundInit()
    .supplier(ctx -> new HikariDataSource(ctx.bean(DataSourceConfig.class).url()));
```

## 6. 属性文件与占位符

```properties
# db.properties
pool.size=8
pool.timeout=3s
```

| 机制 | 写法 | 说明 |
|------|------|------|
| 占位符 | `${pool.size:8}` | `:` 后为默认值；解析器 `PropertySourcesPlaceholderConfigurer` 是 `BeanFactoryPostProcessor` |
| SpEL | `#{systemProperties['user.dir']}` | `@Value` 中 `#{}` 为表达式 |
| 组合 | `${pool.size:#{...}}` | 可嵌套（少用） |
| 宽松绑定 | `spring.datasource-url` vs `spring.datasource.url` | Boot 属性可大小写/连字符互换（autoconfigure 层） |

> 🎯 **核心要点**：占位符 `${}` 解析发生在容器启动早期（BeanFactoryPostProcessor 阶段）——因此属性缺失会在启动即失败，不会等到 getBean。
