## 1. 模块总览

```text
spring-aop        ← Spring AOP 本体（代理工厂/切点/通知/织入，被一切代理依赖）
spring-aspects    ← @AspectJ 注解支持（@Aspect/@Around 等）
aspectjweaver     ← AspectJ 织入器（第三方，spring-aspects 的运行时依赖）
spring-context     ← 含 AOP 基础设施（AopConfig、@EnableAspectJAutoProxy）
```

> 🎯 **要点**：Spring AOP 是**运行时代理织入**（动态代理），不是 AspectJ 的编译期/类加载期织入——`spring-aspects` 只是借用了 AspectJ 的注解语法，织入仍是代理。

## 2. 核心模块

| Artifact | 职责 | 关键类 |
|---------|------|--------|
| `spring-aop` | AOP 核心抽象与代理工厂 | `ProxyFactory`、`Advisor`、`Pointcut`、`Advice`、`AspectJExpressionPointcut` |
| `spring-context`（内含） | AOP 基础设施自动装配 | `@EnableAspectJAutoProxy`、`AnnotationAwareAspectJAutoProxyCreator` |
| `spring-beans`（内含） | Bean 后置处理器链路 | `AbstractAutoProxyCreator`（代理创建入口） |

> ⚠️ **注意**：几乎所有 Spring 项目都间接依赖 spring-aop（事务/缓存/异步都基于它）——**无需单独引入**，除非用纯 Spring 手动装配。

## 3. AspectJ 相关模块

| Artifact | 职责 | 引入时机 |
|---------|------|---------|
| `spring-aspects` | @AspectJ 注解模型支持（@Aspect、五类通知注解、@Pointcut） | 使用注解式 AOP 时（starter 已带） |
| `aspectjweaver` | AspectJ 织入器（表达式解析、LTW 能力） | 注解式 AOP 的运行时依赖；**需要 load-time weaving 时显式引入** |
| `aspectjrt` | AspectJ 运行时库 | 仅在真正使用 AspectJ 语言/编译时 |

```xml
<!-- 显式引入（纯 Spring 项目） -->
<dependency>
    <groupId>org.springframework</groupId>
    <artifactId>spring-aop</artifactId>
</dependency>
<dependency>
    <groupId>org.springframework</groupId>
    <artifactId>spring-aspects</artifactId>
</dependency>
```

> 💡 **AspectJ 三种织入方式对比**：

| 织入方式 | 时机 | Spring AOP 用的是？ |
|---------|:---:|:---:|
| 编译期织入（AJC） | 编译时 | ❌ |
| 类加载期织入（LTW） | JVM 加载类时 | 可选（需显式开启） |
| **运行时代理织入** | 运行时创建代理 | ✅ **默认方式** |

## 4. 依赖什么场景引入什么

| 场景 | 需要的依赖 |
|------|-----------|
| Spring Boot 注解式 AOP（@Aspect） | `spring-boot-starter-aop`（一行搞定） |
| 纯 Spring + 注解式 AOP | spring-aop + spring-aspects |
| 纯 Spring + XML 式 AOP | spring-aop（`<aop:config>` 命名空间） |
| 编程式 AOP（ProxyFactory） | spring-aop |
| load-time weaving | + aspectjweaver + 启动参数 `-javaagent` |
| 只依赖事务/缓存（不写切面） | 无需单独引入（starter 传递依赖） |

## 5. Starter 对照

| Starter | 包含 | 适用 |
|---------|------|------|
| `spring-boot-starter-aop` | spring-aop + spring-aspects + aspectjweaver | **注解式 AOP 标准入口** |
| `spring-boot-starter-web`（传递） | spring-aop（事务等基础设施） | 不写切面时无需加 AOP starter |
| `spring-boot-starter`（传递） | 同上 | 同上 |

> ⚠️ **经验**：Boot 项目里"@Aspect 不生效"十有八九是**忘了加 `spring-boot-starter-aop`**（stater-web 只带基础 spring-aop，不带 aspects 注解模型）。
