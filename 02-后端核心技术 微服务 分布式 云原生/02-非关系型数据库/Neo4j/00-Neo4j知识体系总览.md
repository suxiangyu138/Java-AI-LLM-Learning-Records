## 3. 学习路线推荐

**路线 A：图数据库入门（1 天，推荐给后端）**
01 → 02 → 07。掌握属性图模型、Cypher 基本查询与 Java 集成——足以支撑"关系密集"场景的建模。

**路线 B：Neo4j 深入（3 天）**
路线 A + 03 + 04 + 05。补上索引调优、事务集群、图算法——能独立设计图数据架构与复杂查询。

**路线 C：GraphRAG 前沿（面向 AI 工程师）**
路线 B + 06 + 08。向量搜索（SEARCH 语法）、GraphRAG 实现、GenAI Plugin 与 Aura Agent——2025-2026 年图数据库的主战场。

## 4. 核心概念速查

| 概念 | 一句话定义 | 关键事实（2025-2026） |
|------|-----------|---------------------|
| 属性图 | 节点+关系+属性的数据模型 | 关系的"一等公民" |
| Cypher | 声明式图查询语言 | Cypher 25 对齐 GQL 标准 |
| 节点/关系/属性 | 图的基本要素 | 关系有方向与类型 |
| Label | 节点的类型标签 | 索引/约束的载体 |
| MATCH | 模式匹配查询 | 图查询的核心 |
| 原生图存储 | 免索引邻接（index-free adjacency） | 关系遍历 O(1) 级 |
| Bolt 协议 | 二进制驱动协议 | 高性能访问 |
| 因果一致性 | 集群读一致性模型 | 写后读保证 |
| Vector 类型 | 原生向量存储（2025.10+） | VECTOR\<FLOAT32\>(1024) |
| SEARCH 语句 | 原生向量搜索语法（Cypher 25） | 索引内过滤（2026.02 GA） |
| GraphRAG | 图增强的 RAG 检索 | GenAI Plugin + Aura Agent |
| GDS | 图数据科学库 | 路径/中心性/社区算法 |
| GRAPH TYPE | 数据模型蓝图（2026 GA） | 声明统一 Schema |

> 🎯 **核心要点**：Neo4j = 原生图数据库——"关系的存储与遍历"是它的第一性原理（免索引邻接让多跳查询无需全局扫描）。它的价值场景是"关系密集"的数据（社交、风控、供应链、知识图谱）；2025-2026 年的主线是**向量搜索与 GraphRAG**（原生 Vector 类型 + SEARCH 语法 + GenAI 生态），让图数据库成为 AI 应用的知识层。
