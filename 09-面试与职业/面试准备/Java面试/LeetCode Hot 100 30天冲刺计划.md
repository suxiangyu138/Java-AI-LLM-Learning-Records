# LeetCode Hot 100 30 天冲刺计划

> **前置阅读：** `01-JavaSE/leetcode_hot100_study_guide.md`（题型精讲 + 代码模板）
> **本计划定位：** 不重复讲题解法，而是给你一个每天能执行的时间表 + 每阶段的验证标准。

---

## 一、核心原则

### 1.1 三个不要

| 不要 | 原因 |
|------|------|
| **不要死磕一道题超过 30 分钟** | 超出 30 分钟说明思路不对，直接看题解，理解后手写一遍 |
| **不要只看不写** | 眼睛会了 ≠ 手会了。每道题必须关掉题解自己写出来 |
| **不要追求一次记住** | 算法靠反复。同一道题会在周期内出现 2-3 次 |

### 1.2 刷题五步法

```
1. 读题 2 分钟 → 用自己的话复述题意
2. 思考 5 分钟 → 想暴力解 → 想优化点 → 想边界条件
3. 看题解 10 分钟 → 理解核心思路（不是背代码）
4. 手写 10 分钟 → 关掉题解，自己写 + 跑通所有测试用例
5. 复盘 3 分钟 → 这道题的"一句话核心思路"是什么？容易错在哪？
```

### 1.3 题目分级

| 级别 | 标记 | 要求 |
|------|------|------|
| **必秒** | ★★★ | 看到题 5 分钟内写出最优解，面试高频第一梯队 |
| **必会** | ★★☆ | 看到题能说出思路，10 分钟内写出代码 |
| **选做** | ★☆☆ | 理解思路即可，时间不够可跳过 |

## 三、题型代码模板速查

### 滑动窗口模板

```java
int left = 0, right = 0;
while (right < s.length()) {
    char c = s.charAt(right);
    right++;  // 扩大窗口
    // ... 更新窗口内数据
    
    while (窗口需要收缩) {
        char d = s.charAt(left);
        left++;  // 缩小窗口
        // ... 更新窗口内数据
    }
}
```

### 回溯模板

```java
void backtrack(路径, 选择列表) {
    if (满足结束条件) { result.add(路径); return; }
    for (选择 in 选择列表) {
        做选择;
        backtrack(路径, 选择列表);
        撤销选择;
    }
}
```

### 二叉树 DFS

```java
void dfs(TreeNode root) {
    if (root == null) return;
    // 前序位置
    dfs(root.left);
    // 中序位置
    dfs(root.right);
    // 后序位置
}
```

### 0-1 背包模板

```java
for (int i = 0; i < n; i++) {
    for (int j = capacity; j >= weight[i]; j--) {
        dp[j] = Math.max(dp[j], dp[j - weight[i]] + value[i]);
    }
}
// 注意：0-1 背包倒序遍历（每个物品只用一次）
// 完全背包正序遍历（每个物品无限用）
```

- **一道题刷 3 遍**：第一遍理解思路 → 第二遍独立写 → 第三遍面试前速过
- **10 道 ★★★ 题 > 100 道 ★☆☆ 题**：面试 80% 的原题来自那 25 道高频题
- **边写边讲**：面试不是笔试，你要能把思路说清楚，模拟时一定要出声
