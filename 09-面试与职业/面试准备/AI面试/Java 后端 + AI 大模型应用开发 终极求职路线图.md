Java 后端 + AI 大模型应用开发 终极求职路线图
第一阶段：Java 核心地基（2 个月）
1. Java 基础（必须精通）
    - 基础语法、集合框架（List/Map/Set 源码）
    - 泛型、反射、注解、动态代理
    - 异常处理、IO/NIO、序列化
    - 多线程 & 并发：Thread、线程池、锁、AQS、ThreadLocal、volatile
    - JVM：内存模型、GC、类加载、JVM 参数调优
    学会标准：手写线程池、讲清 HashMap 源码、面试不卡壳
2. 数据库 & 缓存（重中之重）
    - MySQL：索引、事务、锁、MVCC、执行计划、分库分表
    - MyBatis-Plus：CRUD、分页、联表、插件
    - Redis：数据结构、缓存穿透/击穿/雪崩、分布式锁、限流
3. 开发工具
    - Maven/Gradle
    - Git：分支、合并、回滚、冲突解决
    - Linux：常用命令、日志、部署、权限
    - Docker：打包、运行、镜像、容器
 
第二阶段：Java 后端工程体系（1.5 个月）
1. 主流框架
    - Spring Core：IOC、AOP、事务
    - SpringBoot：自动配置、启动原理、配置文件
    - SpringCloud 微服务（面试必问）
    - Nacos/Eureka：注册中心
    - Gateway：网关
    - OpenFeign：服务调用
    - Sentinel：限流降级
    - Seata：分布式事务
2. 中间件（必学）
    - RabbitMQ/RocketMQ：消息队列、异步、解耦、重试
    - Elasticsearch：全文检索（AI 项目也用）
    - XXL-Job：定时任务
3. 工程规范
    - 统一返回、全局异常、日志
    - 接口文档：Swagger/Knife4j
    - 压力测试：JMeter
    - 设计模式：单例、策略、模板、工厂、装饰器
    学会标准：能独立搭建微服务项目
 
第三阶段：AI 大模型应用核心（1.5 个月）
1. 大模型基础
    - LLM 基本概念：Transformer、Embedding、Context Window
    - 主流模型：GPT、Qwen、Llama、DeepSeek、ChatGLM
    - 提示词工程（Prompt）：结构化输出、思维链、Few-shot
    - Function Call（函数调用）
2. RAG 检索增强生成（企业落地 90%）
    - 文档处理：读取 PDF/Word/Markdown
    - 文本分块（Chunk）
    - 向量数据库：Milvus / Chroma / FAISS
    - 检索策略：相似度检索、多路召回、重排
    - RAG 优化：幻觉解决、上下文管理
3. Java 对接大模型（核心竞争力）
    - Spring AI / LangChain4j
    - 调用通义千问、文心一言、DeepSeek API
    - 流式返回（SSE）
    - 构建 AI 聊天机器人、知识库问答、AI 总结助手
4. AI 工程能力
    - 模型本地部署（Ollama）
    - 模型量化（INT4/INT8）
    - 向量库与 MySQL 结合
    - 接口限流、缓存、安全
 
第四阶段：Python 辅助工具链（0.5 个月）
- Python 基础
- Requests 爬虫：爬取公开数据做知识库
- Pandas 数据清洗
- 简单大模型脚本：生成语料、处理文档
    目标：辅助 Java AI 项目，不是转行
 
第五阶段：算法（贯穿全程，每天 1 小时）
必刷题型
- 数组、双指针、滑动窗口
- 链表、栈、队列
- 二叉树、DFS/BFS
- 动态规划基础
- 哈希、排序、二分
- 贪心、回溯
    学会标准：LeetCode 中等题 80% 能做，面试手撕不慌
 
第六阶段：项目实战（必须做 2～3 个）
项目 1：传统后端（必做）
- 后台管理系统 + 用户 + 权限 + 订单
    项目 2：AI 知识库系统（核心加分）
- SpringBoot + 大模型 API + 向量库 + RAG
- 文档上传 → 向量化 → 智能问答
    项目 3：AI 对话助手（面试展示）
- 流式对话、历史记忆、函数调用工具
 
第七阶段：面试必备（最后 1 个月）
- Java 高频面试题
- 数据库面试题
- 微服务面试题
- AI 大模型面试题（RAG、Prompt、Embedding）
- 项目讲解逻辑
- 手撕算法 & 手写代码
 
总时长
每天 4 小时，约 6～7 个月全部学完
学完后：任何 Java 后端 + AI 岗位，你不会有不知道的技术
