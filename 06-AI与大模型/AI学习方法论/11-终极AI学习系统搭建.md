# 终极 AI 学习系统搭建 —— VSCode + AI 全流程配置

## 目标

构建一个"无缝嵌入编码流程"的 AI 辅助系统，让 AI 在你需要的时候自然出现，不需要的时候安静退场。

## VSCode 配置

### 必装插件

```bash
# 1. GitHub Copilot —— 代码补全
code --install-extension GitHub.copilot

# 2. GitHub Copilot Chat —— AI 对话
code --install-extension GitHub.copilot-chat

# 3. Cursor（推荐替代 VSCode 直接使用 Cursor IDE）
# 下载地址：https://cursor.sh
# Cursor 已内置 AI 功能，无需额外插件
```

### 快捷键绑定

```
# Cursor 核心快捷键
Ctrl+K          唤起 AI 编辑（选中代码 → 输入需求 → AI 生成）
Ctrl+L          唤起 AI 对话（侧边栏聊天）
Ctrl+I          唤起 Composer（多文件编辑）
Ctrl+Shift+I    唤起 AI 解释代码
Ctrl+K Ctrl+S   查看所有快捷键

# 建议自定义
Alt+Shift+R     → 重构选中代码
Alt+Shift+E     → 解释选中代码
Alt+Shift+T     → 生成单元测试
```

## Cursor 工作流详解

### 写代码流程

```
1. 新建文件 → 输入功能描述注释
   // 实现用户登录接口：
   // - POST /api/login 接收 username + password
   // - 验证通过返回 JWT token
   // - 验证失败返回 401
   
2. Ctrl+K → 选中注释 → "实现这个登录接口"
   → Cursor 生成完整代码

3. 阅读并修改生成的代码：
   - 删掉不必要的 try-catch
   - 修改密码加密方式为你项目用的
   - 添加业务日志

4. Ctrl+K → 选中方法体 → "优化这段代码的可读性"
```

### 调试流程

```
1. 遇到报错 → Ctrl+L → 粘贴错误信息
   → "这个错误是什么原因？怎么修？"

2. Cursor Chat 回答后 → 点击 Apply → 代码自动修改

3. 如果改了还不行 → 粘贴新的错误信息
   → "上次的修改没解决，新的错误是...请重新诊断"
```

### 重构流程

```
1. 选中整个文件 → Ctrl+I → "重构这个类：
   - 提取公共逻辑到 private 方法
   - 将 if-else 改为策略模式
   - 给所有 public 方法加参数校验"

2. Composer 生成新版本 → 对比原文件 → 接受或拒绝每个改动
```

### 单元测试生成

```
1. 打开 Service 类 → Ctrl+I
   → "为 UserService 的所有 public 方法生成单元测试：
   - 使用 JUnit 5 + Mockito
   - 覆盖正常路径 + 异常路径 + 边界条件
   - Mock 所有外部依赖（Repository/RedisTemplate）"

2. 检查生成的测试 → 补充业务特有的边界条件
```

## 终端 AI 快捷命令

### 在 ~/.bashrc 或 PowerShell Profile 中添加

```bash
# Bash/Zsh
alias ai="cursor"                    # 快速在 AI IDE 打开
alias explain="cursor --explain"     # 解释代码
alias refactor="cursor --refactor"   # 重构代码

# 用 AI 解释命令行错误
function explain-error() {
    local last_error=$(fc -ln -1 2>&1)
    echo "解释以下命令的错误：" > /tmp/ai-query.txt
    echo "$last_error" >> /tmp/ai-query.txt
    cat /tmp/ai-query.txt | pbcopy  # macOS 复制到剪贴板
    echo "错误已复制，粘贴到 Cursor Chat (Ctrl+L)"
}
```

## 多设备协同方案

### 设备分工

| 设备 | 用途 | 核心工具 | AI 集成 |
|------|------|---------|--------|
| 笔记本/台式机 | 主力编码 + 深度学习 | VSCode/Cursor + ChatGPT | 全流程 |
| 手机 | 碎片时间学习 + 紧急查资料 | Perplexity + ChatGPT App | 快速问答 |
| 平板 | 笔记整理 + 算法手写 | Notability + AI 思维导图 | 知识整理 |

### 笔记同步方案

```
方案：Obsidian + Git + GitHub 自动同步

1. 本地用 Obsidian 管理所有 Markdown 笔记
2. 笔记库就是当前 Git 仓库（D:/.../Java-AI-LLM-Learning-Records）
3. AI 生成的内容直接保存为 .md 到对应目录
4. Git commit + push → 所有设备 pull 同步

优点：
- 纯文本，跨平台
- Git 版本控制，不丢数据
- AI 可以直接读写你的笔记库
```

## Git 自动化：学习记录沉淀

### 每日自动提交脚本

```bash
# auto_commit.sh
cd /d/Desktop/MyLoacalReposity/Java-AI-LLM-Learning-Records

# 拉取最新
git pull --rebase

# 添加所有笔记
git add "06-AI与大模型/" "01-JavaSE/" "03-Spring生态/" "leetcode/"

# 提交（如果有变更）
if ! git diff --cached --quiet; then
    git commit -m "daily learning update: $(date +%Y-%m-%d)"
    git push
fi
```

Windows Task Scheduler 设置每日 23:00 自动运行，确保学习记录不丢失。
