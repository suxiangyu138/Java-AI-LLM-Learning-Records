# 专属 AI 学习工作流 —— 每日/每周节奏设计

## 为什么需要固定的工作流？

大脑是习惯机器。固定时间做固定事 = 降低启动阻力 + 形成神经回路 + 进入心流更快。

以下工作流针对 **Java 后端 + AI 大模型** 技术栈设计。

---

## 日节奏

### 早晨：技术知识速通（30 分钟）

```
07:30-08:00
├── 5 分钟：Perplexity 搜索
│   └── "2026年 [目标领域] 最新动态"
│       例："Spring Boot 3.x 最新特性"
│
├── 10 分钟：ChatGPT 生成学习计划
│   └── "列出今天我该学的 3 个知识点，每个 1 句话说明为什么重要"
│
└── 15 分钟：Claude 深度学习 1 个核心概念
    └── 用结构化模板深度提问（参考 [[02-知识点速通理解]]）
```

**产出**：每日 1 个知识卡片（Markdown 笔记）

### 白天：项目实战编码

```
09:00-18:00（穿插使用 AI）
├── 写代码前
│   └── 先用纸笔（或白板）画业务流程图
│       → AI 不参与设计，只参与实现
│
├── 编码中
│   ├── GitHub Copilot：CRUD 模板代码，Tab 补全
│   ├── Cursor：复杂逻辑，Ctrl+K 生成初版
│   └── ⚠️ 关键业务逻辑：自己手写，不用 AI
│
├── 遇到 Bug
│   ├── 先看错误栈 2 分钟
│   ├── 无法定位 → Cursor Chat 或 ChatGPT 诊断
│   └── 参考 [[03-代码调试与错误排查]]
│
└── 代码提交前
    └── Cursor → "Review 这段代码，找出潜在的 Bug 和性能问题"
```

### 晚上：算法刷题 + 复盘（2 小时）

```
20:00-22:00
├── 1 小时：LeetCode 3 道题
│   ├── 前 10 分钟/题：自己写
│   └── 卡住的题 → 参考 [[04-算法题高效刷题]] AI 教练模式
│
├── 30 分钟：让 AI 出变种题巩固
│   └── "基于今天做的 3 道题，各出 1 道变种，不给答案"
│
└── 30 分钟：今日复盘
    └── 用 AI 整理今日笔记（粘贴零散记录 → AI 结构化整理）
```

## 周节奏

| 时间 | 活动 | AI 角色 |
|------|------|--------|
| 周一复盘 | 回顾上周学习，规划本周 | AI 生成周计划 |
| 周二~周五 | 按日节奏执行 | AI 全程辅助 |
| 周六上午 | **集中编码半日**：做一个 Mini 项目 | Cursor 结对编程 |
| 周六下午 | **技术博客写作** | AI 辅助写作 |
| 周日上午 | **源码阅读半日** | Claude 导读（[[05-源码阅读加速]]） |
| 周日下午 | **自由探索**：逛 GitHub Trending / 看技术视频 | Perplexity 延展调研 |

### 周末重点：技术总结输出

```
周六下午流程：
1. 回顾本周笔记（AI 已整理好的 Markdown）
2. 选 1 个最有价值的主题
3. ChatGPT → "基于以下笔记，生成技术博客大纲"
4. Cursor → 写初稿
5. ChatGPT → "请 review 这篇文章，指出逻辑漏洞和表述不清的地方"
6. 修改后发布到 GitHub Pages / 掘金 / 博客园
```

**博客价值**：简历加分 + 知识检验 + 被动人脉（面试官搜到你写的文章）

## 月节奏

| 活动 | 时间 | 说明 |
|------|------|------|
| 月度技术总结 | 月末周末 | 用 AI 生成月度学习报告 |
| 技术栈查漏 | 月末 | "基于我的学习记录，哪些技术点还没覆盖？" |
| 下月规划 | 月末 | "基于 2026 年 Java 后端趋势，下月我该重点学什么？" |
| GitHub 绿点检查 | 每周日 | 确保每周有 3+ 次 commit |

### 月度学习报告模板

```
让 AI 基于你的笔记生成：

本月掌握的新技术点：[列表]
本月解决的典型 Bug：[列表 + 根因]
刷题进度：Easy [N] / Medium [N] / Hard [N]
项目进展：[完成功能 / 遇到的问题 / 架构改进]
下月重点：基于能力短板，AI 推荐 3 个学习方向
```

---

## 关键原则

1. **固定时间做固定事**：降低启动阻力
2. **AI 做知识整理，人做知识消化**：笔记 AI 写，但人必须读一遍
3. **输出倒逼输入**：周末必须产出一篇博客或一个 Demo
4. **每周检查 GitHub 绿点**：绿点 = 学习习惯的可视化反馈
