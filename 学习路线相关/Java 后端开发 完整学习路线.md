# Java后端开发 完整学习路线
## 一、筑基阶段
### 1. Java 核心基础
- 语法基础：变量、数据类型、运算符、流程控制、数组
- 面向对象：类与对象、封装/继承/多态、接口、抽象类、内部类
- 核心API：String、集合（List/Set/Map）、异常、IO流、泛型
- 高级基础：多线程、反射、注解、JVM基础、枚举、Lambda&Stream
### 2. 计算机基础
- 计算机网络：HTTP/HTTPS、TCP/IP、三次握手四次挥手、请求响应流程
- 操作系统：进程/线程、内存、IO模型基础
- 数据结构：数组、链表、栈队列、哈希、二叉树、基础排序

---

## 二、Web 开发核心
### 1. 前端基础（后端必备最小集）
HTML、CSS、JavaScript 基础，了解Vue/React基础使用即可
### 2. Java Web 原生
- Servlet、Filter、Listener
- Cookie、Session、会话管理
- Tomcat 服务器、请求转发/重定向
### 3. 数据库核心
- MySQL：DDL/DML/DQL、多表查询、联合查询、子查询
- 数据库设计：三大范式、索引、事务、MVCC、锁机制
- JDBC 原生操作、连接池（Druid/HikariCP）

---

## 三、主流框架栈（企业开发标配）
### 1. 持久层框架
- MyBatis：动态SQL、映射文件、关联查询、一级/二级缓存
- MyBatis-Plus：CRUD封装、条件构造器、分页、逻辑删除
### 2. 核心框架
- Spring：IOC、AOP、Bean生命周期、依赖注入、事务管理
- Spring MVC：MVC架构、请求映射、参数绑定、拦截器、全局异常
- **Spring Boot**：自动配置、起步依赖、配置文件、内嵌容器、快速开发

---

## 四、进阶中间件 & 技术栈（实习/校招加分核心）
### 1. 缓存技术
- Redis：五种数据结构、持久化、过期策略、缓存击穿/穿透/雪崩、分布式锁
### 2. 消息队列
- RabbitMQ：交换机、队列、死信队列、消息可靠投递、异步解耦
### 3. 微服务基础
- Spring Cloud 核心组件：Nacos、Gateway、Feign、Sentinel、Seata
- 服务注册发现、网关路由、熔断降级、分布式事务
### 4. 搜索引擎
- ElasticSearch：倒排索引、分词、DSL查询、海量数据检索

---

## 五、工程化 & 运维部署（开发必备）
1. 版本控制：Git 常用命令、GitHub/Gitee 协作、分支管理
2. 构建工具：Maven / Gradle 依赖管理、打包、生命周期
3. 接口开发：Postman、Swagger/Knife4j、RESTful 接口规范
4. 容器化：Docker 基础、镜像/容器、Docker Compose 部署项目
5. 服务器：Linux 常用命令、云服务器部署、Nginx 反向代理

---

## 六、高级底层 & 性能优化（进阶天花板）
1. JVM 深度：内存模型、GC算法、类加载、调优参数、内存泄漏排查
2. 并发进阶：线程池、CAS、AQS、JUC并发工具、并发安全
3. MySQL 优化：慢查询优化、索引优化、分库分表、读写分离
4. 设计模式：单例、工厂、代理、策略、观察者等常用设计模式
5. 分布式理论：CAP、BASE、最终一致性、分布式ID

---

## 七、项目实战路线（由浅入深）
1. 入门项目：个人博客、图书管理系统（SpringBoot + MyBatis + MySQL）
2. 进阶项目：权限管理系统（RBAC）、前后端分离项目
3. 高级项目：电商秒杀、分布式博客、RAG知识库系统（结合AI）
4. 开源项目：阅读优秀开源后端源码，积累简历亮点

---

## 八、算法 & 面试（校招关键）
1. 算法：LeetCode 热题100、数组/链表/树/动态规划/哈希高频题
2. 八股文：Java基础、JVM、MySQL、Redis、Spring、分布式高频面试题
3. 简历：项目亮点量化、技术栈匹配岗位、突出实战能力

---

## 九、学习时间规划（适配在校生）
1. 基础阶段：1～2个月（Java基础 + MySQL + 计算机网络）
2. 框架阶段：2个月（SpringBoot + MyBatis 全家桶）
3. 中间件阶段：1.5个月（Redis + MQ + 微服务入门）
4. 项目+算法+面试：长期同步推进
