# Java 高并发必做项目清单（从基础 → JDK 底层 → 框架级 → 企业级实战）

---

## 一、入门必做（JDK 基础并发）

### 1. 线程基础与线程池实战

**核心知识点**  
- `Thread`、`Runnable`、`Callable`、`Future` 使用与区别  
- 线程生命周期、状态切换（NEW / RUNNABLE / BLOCKED / WAITING 等）  
- `ThreadPoolExecutor` 七大参数、拒绝策略  
- 常见线程池：Fixed / Cached / Scheduled / Single  

**核心功能**  
- 自定义线程池  
- 提交任务、获取结果、异步回调  
- 简单定时任务调度  

**预计耗时**：1–2 天  

---

### 2. 锁机制深度实战

**核心知识点**  
- `synchronized` 底层：对象头、偏向锁 → 轻量级锁 → 重量级锁  
- `Lock` / `ReentrantLock`，公平锁 / 非公平锁  
- `ReadWriteLock`、`StampedLock`  
- 自旋锁、锁粗化、锁消除等优化思路  

**核心功能**  
- 解决典型线程安全问题（计数器、库存扣减等）  
- 对比不同锁实现的性能与适用场景  

**预计耗时**：2 天  

---

### 3. 并发工具类实战

**核心知识点**  
- 同步工具：`CountDownLatch`、`CyclicBarrier`、`Semaphore`、`Phaser`  
- 交换工具：`Exchanger`  
- 线程通信：`wait/notify`、`LockSupport`  

**核心功能**  
- 多线程协同执行（如多个子任务完成再汇总）  
- 限流控制（并发数限制）  
- 复杂任务分阶段执行  

**预计耗时**：1–2 天  

---

## 二、进阶必做（内存模型 + 并发容器）

### 4. Java 内存模型与 volatile

**核心知识点**  
- JMM：主内存 / 工作内存概念  
- `volatile` 的可见性、禁止指令重排  
- 单例模式：DCL（双重检查锁）+ `volatile` 正确写法  
- `happens-before` 规则与常见案例  

**核心功能**  
- 解决多线程可见性问题  
- 手写线程安全单例、多线程计数等示例  

**预计耗时**：2 天  

---

### 5. 并发容器源码级实战

**核心知识点**  
- `ConcurrentHashMap`：分段思想、CAS + synchronized、红黑树、扩容机制  
- `CopyOnWriteArrayList`、`ConcurrentLinkedQueue` 使用与特性  
- 阻塞队列：`ArrayBlockingQueue`、`LinkedBlockingQueue`、`PriorityBlockingQueue`  

**核心功能**  
- 高并发场景下安全读写共享数据  
- 对比普通容器（`HashMap` / `ArrayList`）在并发下的问题  

**预计耗时**：2–3 天  

---

### 6. 原子类与 CAS

**核心知识点**  
- CAS 原理、ABA 问题、自旋重试  
- `AtomicInteger`、`AtomicLong`、`LongAdder`  
- 原子引用类、带版本号的原子类应用  

**核心功能**  
- 无锁并发计数器（高并发统计）  
- 简单乐观锁实现  

**预计耗时**：1 天  

---

## 三、核心必做（异步编程 + 并发设计模式）

### 7. CompletableFuture 异步编程

**核心知识点**  
- 异步任务创建：`supplyAsync` / `runAsync`  
- 链式调用：`thenApply`、`thenCompose`  
- 任务组合：`thenCombine`、`allOf`、`anyOf`  
- 异常处理：`exceptionally`、`handle`  
- 自定义线程池 + 超时控制  

**核心功能**  
- 多任务并行执行、结果聚合  
- 编排复杂异步流程（如同时调多个服务并汇总结果）  

**预计耗时**：2 天  

---

### 8. 生产者–消费者模式

**核心知识点**  
- 基于阻塞队列实现生产者–消费者  
- 基于锁 / 条件变量实现等待–通知  
- 使用 CAS / 原子类优化控制变量  

**核心功能**  
- 解耦生产与消费、削峰填谷  
- 支撑异步任务处理流水线  

**预计耗时**：1–2 天  

---

### 9. 线程池自定义与调优

**核心知识点**  
- 核心线程数估算：CPU 密集 / IO 密集任务区分  
- 队列类型选择（有界 / 无界）  
- 自定义拒绝策略（降级 / 记录日志 / 延迟重试）  
- 监控线程池状态（活跃线程数、队列长度、任务耗时）  

**核心功能**  
- 针对不同业务场景设计高性能线程池  
- 避免 OOM、任务堆积等问题  

**预计耗时**：2 天

## 四、企业级必做（分布式高并发）

### 10. 分布式锁（Redisson）

**核心知识点**  
- 可重入锁、公平锁、读写锁实现方式  
- Redisson 红锁思想、多节点锁  
- 锁超时、自动续期、看门狗机制  
- 防误删锁（value 校验）  

**核心功能**  
- 秒杀库存扣减  
- 防重复提交、接口幂等  
- 关键业务操作加锁保护  

**预计耗时**：2 天  

---

### 11. 分布式限流

**核心知识点**  
- 计数器、滑动窗口、漏桶、令牌桶算法  
- Redis + Lua 实现分布式限流  
- Gateway + Sentinel 网关限流策略（按 IP / 用户 / 接口）  

**核心功能**  
- 高并发下接口限流、防止恶意刷接口  
- 保障核心服务稳定性  

**预计耗时**：2–3 天  

---

### 12. 分布式幂等设计

**核心知识点**  
- 唯一索引、业务唯一号、Token 机制  
- 防重表记录请求 ID  
- 幂等与本地事务、分布式事务结合  
- 幂等与 MQ 消费（去重表 / 消费日志）  

**核心功能**  
- 解决重复下单、重复支付、重复回调等问题  
- 提升系统在异常重试场景下的正确性  

**预计耗时**：2 天  

---

### 13. 秒杀系统高并发设计

**核心知识点**  
- 页面静态化、CDN 加速、接口下沉  
- 缓存预热、请求限流、队列削峰  
- 库存预扣、异步下单、结果轮询  
- 分布式锁 + 限流 + 幂等 综合应用  

**核心功能**  
- 支撑高并发秒杀场景（万级 QPS）  
- 完整链路：下单 → 支付 → 状态回查  

**预计耗时**：3–4 天
