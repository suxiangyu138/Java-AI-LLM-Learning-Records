# LangGraph 必做实战项目（从入门到企业级）

---

## 一、入门级（夯实基础语法与状态流）

> 目标：吃透 State 定义、节点 / 边、顺序 / 分支 / 循环，覆盖 90% 基础工作流场景

### 1. 顺序式文本处理流水线

**功能**  
- 输入长文本  
- 依次执行：内容总结 → 关键词提取 → 情感分析  
- 输出结构化结果（JSON 或表格）  

**核心知识点**  
- `StateGraph` / `AgentState` 基础状态定义  
- 顺序节点编排（从 START → 节点链 → END）  
- Prompt 串联与多步 LLM 调用  

---

### 2. 条件分支问答机器人

**功能**  
- 根据用户问题自动路由：  
  - 常识问题：直接调用 LLM 回答  
  - 时效性问题：调用搜索工具后再回答  
  - 复杂问题：拆解为子问题后再汇总  

**核心知识点**  
- 条件边（conditional edges）、动态路由  
- 分支决策逻辑（基于模型输出或规则判断）  
- 不同分支共享 / 更新统一 State  

---

### 3. 基础循环式反思 Agent

**功能**  
- 第一步生成初版答案  
- 第二步进行自我评估与反思  
- 不符合质量标准则回到生成节点重试，直到满足阈值或到达最大轮数  

**核心知识点**  
- 有向循环图的设计  
- 迭代执行与状态中的「尝试次数」计数  
- 终止条件判断（质量评分、最大循环次数）  

---

### 4. 带持久化记忆的聊天机器人

**功能**  
- 支持多轮对话  
- 会话隔离（按 thread / user 分开）  
- 重启服务后依然保留历史对话与长期记忆  

**核心知识点**  
- `MessagesState` 与消息追加模式  
- SQLite / Redis 等持久化后端接入  
- 线程 / 会话 ID 设计与管理  

---

## 二、进阶级（Agent 核心，企业高频场景）

> 目标：掌握工具调用、ReAct、人在回路、RAG，贴合真实业务 Agent 开发

### 5. ReAct 智能搜索 Agent

**功能**  
- 自主判断是否需要联网搜索  
- 调用搜索引擎获取实时信息  
- 整合并回答，附带引用来源  

**核心知识点**  
- 工具节点（ToolNode）与工具注册  
- 基于思考–行动–观察循环的 ReAct 推理模式  
- `tools_condition` 等条件控制工具调用  

---

### 6. 人在回路审批 Agent

**功能**  
- 执行高危操作（文件修改、数据库更新、发邮件、执行代码）前自动暂停  
- 将待执行操作展示给人工审核  
- 人工确认后继续执行 / 拒绝并给出反馈  

**核心知识点**  
- Human-in-the-loop：中断点、人工恢复执行  
- 状态持久化（thread_id + graph 版本）  
- 状态回滚或分支处理拒绝情况  

---

### 7. RAG 智能问答助手

**功能**  
- 文档解析 → 分块 → 嵌入入库 → 检索 → 拼接上下文 → 回答  
- 回答中标注引用内容与来源位置  

**核心知识点**  
- LangGraph + RAG 工作流编排  
- 检索节点与生成节点的组合  
- 多轮问答场景下的检索优化（如基于历史问题调整 Query）  

---

### 8. 教育内容自动生成系统

**功能**  
- 输入课程主题  
- 生成整体章节大纲  
- 按章节生成知识点、练习题、答案与解析  
- 导出为 Markdown / HTML 文档  

**核心知识点**  
- 多节点串联（大纲 → 每章内容 → 题目 → 答案）  
- 批处理 / 扇出扇入模式（对多个章节并行生成）  
- 本地文件 IO 与结构化输出  

---

## 三、高阶实战（多智能体，多角色协作）

> 目标：Supervision 多智能体、分工协作、任务拆解、并行执行，是简历与面试高价值模块

### 9. 主管调度式多智能体系统

**功能**  
- 主管 Agent 接收复杂需求  
- 拆解任务并分配给：搜索专家、代码专家、文案专家等  
- 汇总各子 Agent 结果并输出统一答案  

**核心知识点**  
- Supervisor 模式与多 Agent 拓扑结构  
- 任务分发策略与角色分工  
- Agent 间通信与结果聚合  

---

### 10. 并行式深度研究 Agent

**功能**  
- 将研究主题拆解为若干子问题  
- 启动多个子 Agent 并行查询 / 分析  
- 对多来源结果进行交叉验证  
- 输出结构化深度研究报告  

**核心知识点**  
- 并行节点与并发执行配置  
- 去重 / 冲突检测 / 一致性校验逻辑  
- 大量信息的摘要与多源整合  

---

### 11. NL2SQL 数据分析智能体

**功能**  
- 自然语言 → 生成 SQL 查询  
- 执行 SQL → 拿到结果  
- 自动生成可视化描述 / 图表说明 / 分析结论  

**核心知识点**  
- 自定义工具：数据库查询工具、图表生成工具  
- SQL 语法纠错与安全（简单防注入）  
- 错误重试与回退策略  

---

### 12. 旅行规划一站式 Agent

**功能**  
- 解析用户出行需求（城市、日期、预算、偏好）  
- 调用机票 / 酒店 / 地图等 API 获取数据  
- 自动生成多日行程安排  
- 将行程以邮件或文档形式导出发送  

**核心知识点**  
- 多第三方 API 工具串联  
- 复杂业务流程编排与状态管理  
- 多模态输出（文本 + 时间表 + 地图链接）  

---

## 四、企业级生产项目（容错 + 可观测 + 部署）

> 目标：对标大厂生产级 Agent 应用：容错、监控、扩展性、人与系统配合

### 13. 电商客服智能分流系统

**功能**  
- 自动识别用户咨询类型（售后、物流、退款、咨询）  
- 路由到对应专业 Agent（售后 Agent、物流 Agent 等）  
- 自动回复 + 人工兜底处理  

**核心知识点**  
- 动态路由策略（基于意图 / 标签）  
- 业务规则编排（优先级、SLA）  
- 并发会话管理、Redis 状态缓存  

---

### 14. 代码自动化测试生成 Agent

**功能**  
- 解析现有代码  
- 识别分支与边界情况  
- 自动生成单元测试代码  
- 执行测试并汇总测试报告  

**核心知识点**  
- 代码解析工具接入（AST、静态分析）  
- 用例生成策略与边界覆盖  
- 错误处理与测试失败分析  

---

### 15. 邮件智能处理 Agent

**功能**  
- 自动收取邮件  
- 按主题 / 发件人 / 内容进行分类与优先级排序  
- 自动生成回复草稿 / 自动回复  
- 归档整理与异常告警  

**核心知识点**  
- 邮件协议对接（IMAP / SMTP）  
- 多轮决策与规则引擎（自动回复 vs 人工确认）  
- 基于 LangGraph 的长流程处理与错误恢复  

---

### 16. 金融风控决策 Agent

**功能**  
- 收集用户信息与行为数据  
- 计算多种风险指标  
- 多 Agent 交叉审核结果  
- 生成可审计的风控报告  

**核心知识点**  
- 状态加密与敏感数据处理  
- 强容错与回滚设计  
- 多活部署与审计追踪  

---

## 五、练手路线建议（适配你 Java + AI 方向）

1. **入门阶段**  
   - 顺序文本流水线  
   - 循环反思 Agent  
   - 持久化聊天机器人  
   3 天左右吃透基础语法与状态流转。  

2. **进阶核心阶段**  
   - ReAct 搜索 Agent  
   - RAG 智能问答助手  
   掌握 80% 企业 Agent 开发能力，确定 LangGraph 思维方式。  

3. **简历顶配阶段**  
   - 主管多智能体系统  
   - 并行深度研究 Agent  
   这两个可以作为「多智能体调度」王牌项目写进简历。  

4. **生产延伸（与 Java 后端强结合）**  
   - NL2SQL 数据分析智能体  
   - 代码自动化测试生成 Agent  
   将结果通过 SpringBoot 暴露 API，由 Java 体系做网关、鉴权、监控与部署，形成「Java 后端 + LangGraph 智能体」一体化方案。
