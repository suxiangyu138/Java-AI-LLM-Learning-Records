# MongoDB 实战项目清单

## 一、核心能力

MongoDB 是文档型 NoSQL 数据库，核心应用场景：

- 灵活数据结构存储
- 高并发读写
- 海量日志 / 内容管理
- 实时数据分析

---

## 二、技术能力拆解

- 存储层：文档 / 集合 / 嵌套数组
- 查询层：条件过滤 / 正则 / 分页排序
- 索引层：单字段 / 复合 / TTL / 唯一索引
- 聚合层：$match / $group / $sort / $lookup
- 事务层：原子更新 / 多文档事务
- 优化层：索引调优 / 分片 / 软删除

## 五、必练核心语法

### 基础操作
```javascript
insertOne() / insertMany()
find() / findOne()
updateOne() / updateMany()
deleteOne() / deleteMany()
```

### 查询条件
```javascript
$gt / $lt / $gte / $lte  // 大于/小于
$in / $nin               // 包含/不包含
$ne                      // 不等于
$regex                   // 正则匹配
skip() / limit()         // 分页
sort()                   // 排序
```

### 聚合管道
```javascript
$match    // 过滤
$group    // 分组
$sort     // 排序
$project  // 投影
$lookup   // 联表
$unwind   // 数组拆分
```

### 索引优化
```javascript
createIndex({ field: 1 })           // 单字段索引
createIndex({ f1: 1, f2: -1 })      // 复合索引
createIndex({ createdAt: 1 }, { expireAfterSeconds: 3600 })  // TTL索引
createIndex({ email: 1 }, { unique: true })  // 唯一索引
```

### 原子更新
```javascript
$inc      // 自增
$set      // 设置
$push     // 数组追加
$pull     // 数组删除
$addToSet // 数组去重追加
```

## 九、MongoDB vs MySQL 选型

| 特性 | MongoDB | MySQL |
|------|---------|-------|
| 数据模型 | 文档型（灵活） | 关系型（结构化） |
| Schema | 动态 | 固定 |
| 扩展性 | 水平扩展（分片） | 垂直扩展为主 |
| 事务 | 支持（4.0+） | 强事务 |
| 适用场景 | 内容管理 / 日志 / 实时数据 | 财务 / 订单 / 强一致性 |
