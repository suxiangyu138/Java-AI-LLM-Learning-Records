# AI 大模型落地式学习路线（6-8 个月）

> **面向人群**：Java 后端开发者，目标转型 AI 大模型方向或构建 Java + AI 复合竞争力
> **核心原则**：边学边做，每阶段输出可提交简历的实战项目，拒绝纯理论堆砌
> **预计耗时**：在校学生（每天 2-3 小时）6-8 个月；全职学习 4-5 个月；在职转型 8-12 个月

---

## 总览

| 阶段 | 主题 | 周期 | 核心产出 |
|------|------|------|----------|
| 一 | Python 基础 + 大模型 API 实践 | 1-1.5 月 | 智能聊天机器人 |
| 二 | RAG 知识库应用开发 | 1.5-2 月 | 技术文档问答系统 |
| 三 | Agent 智能体开发 | 1.5-2 月 | 智能运维 Agent |
| 四 | 大模型微调与部署 | 1-1.5 月 | Java 代码审查助手 |
| 五 | 多模态大模型应用 | 1 月（可选）| 智能简历生成器 |
| 六 | 企业级工程实践 | 持续 | Java + AI 融合企业应用 |

## 阶段一：Python 基础 + 大模型 API 实践（1-1.5 个月）

### 核心目标
快速掌握 Python 语法，调用大模型 API 构建第一个智能应用，获得正反馈。

### 技术清单

| 模块 | 内容 | 参考文档 |
|------|------|----------|
| Python 速通 | 变量/数据类型/控制流/函数/类/模块 | `07-Python与数据处理/Python语言/Python基础/` |
| 大模型 API 调用 | OpenAI / DeepSeek / 通义千问 API，HTTP POST、JSON 解析、流式输出 | `08-AI开发工具与产品/AI开发工具/LLM-API/` |
| Prompt Engineering | Zero-shot / Few-shot / CoT 思维链，成本最低回报最高的技能 | `06-AI与大模型/Prompt工程/` |

### 实战项目：智能聊天机器人
- 调用 DeepSeek API 实现多轮对话
- 添加上下文记忆功能
- 使用 Flask / Gradio 部署到 Web 界面

### 工具推荐
- **IDE**：VSCode + Python 插件
- **API 平台**：DeepSeek（低成本）/ 智谱 AI / 通义千问（免费额度充足）
- **学习资源**：Datawhale《动手学大模型应用开发》

---

## 阶段二：RAG 知识库应用开发（1.5-2 个月）

### 核心目标
让 AI 拥有私域知识库，解决大模型"幻觉"和知识过时问题——企业级应用刚需。

### 技术清单

| 模块 | 内容 | 参考文档 |
|------|------|----------|
| 向量数据库 | Chroma / FAISS / Milvus，Embedding 向量化、相似度检索 | `06-AI与大模型/Embedding与向量数据库/` |
| LangChain 框架 | Document Loaders / Text Splitters / Retrieval / Chain | `06-AI与大模型/LangChain与框架/` |
| 文档处理 | PDF 解析 / Markdown 解析 / 网页爬取 | `06-AI与大模型/RAG技术/` |

### 实战项目：个人技术文档问答系统
- 上传 Java 学习笔记 / Spring 官方文档
- 构建智能检索问答助手
- 支持多轮对话 + 引用溯源

### 进阶方向
- 混合检索（关键词 + 向量）
- Rerank 重排序优化
- 文档更新自动同步

---

## 阶段三：Agent 智能体开发（1.5-2 个月）

### 核心目标
让 AI 拥有自主解决问题的能力——调用工具、规划任务、迭代优化。2025 年是 Agent 元年。

### 技术清单

| 模块 | 内容 | 参考文档 |
|------|------|----------|
| LangChain Agent | ReAct 模式 / Function Calling / Tool Use | `06-AI与大模型/Agent与MCP/Agent/` |
| LangGraph 框架 | 状态图管理、条件路由、多 Agent 协作 | `06-AI与大模型/Agent与MCP/Agent/` |
| 工具集成 | 搜索引擎 / 数据库查询 / API 调用 / 代码执行器 | `06-AI与大模型/Agent与MCP/` |

### 实战项目：智能运维助手
- 输入"分析服务器日志找出异常"
- Agent 自动执行：读取日志 → 正则提取错误 → 查询 StackOverflow → 生成修复方案

### 企业级方向
- 多 Agent 协作（开发 Agent + 测试 Agent + 运维 Agent）
- 人机协同审核机制
- 成本控制与监控

---

## 阶段四：大模型微调与部署（1-1.5 个月）

### 核心目标
掌握私有化部署和垂直领域微调，降低成本、保护数据隐私。

### 技术清单

| 模块 | 内容 | 参考文档 |
|------|------|----------|
| 本地部署 | Ollama 快速部署开源模型，量化原理（GGUF/GPTQ） | `06-AI与大模型/Ollama与本地部署/` |
| Fine-Tuning | LoRA / QLoRA 参数高效微调，数据集准备、训练、评估 | `06-AI与大模型/模型微调/` |
| 模型评估 | BLEU / ROUGE 指标，人工评测流程设计 | `06-AI与大模型/模型微调/` |

### 实战项目：Java 代码审查助手
- 使用 Java 项目代码微调 Qwen 模型
- 实现代码质量检测、性能优化建议、安全漏洞扫描

### 工具推荐
- **Ollama**：一键部署本地大模型
- **Transformers**：Hugging Face 生态
- **ModelScope / Hugging Face**：开源模型社区
