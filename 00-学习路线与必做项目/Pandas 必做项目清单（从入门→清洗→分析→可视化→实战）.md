# Pandas 实战项目清单

## 五、必练核心知识点

### 1. 数据读写
```python
pd.read_csv()
pd.read_excel()
pd.read_json()
pd.read_sql()
df.to_csv()
df.to_excel()
```

### 2. 数据选择
```python
df.loc[]
df.iloc[]
df[condition]
df.query()
```

### 3. 数据清洗
```python
df.dropna()
df.fillna()
df.drop_duplicates()
df.astype()
df.replace()
```

### 4. 分组聚合
```python
df.groupby().agg()
df.pivot_table()
df.resample()
```

### 5. 多表操作
```python
pd.merge()
pd.concat()
df.join()
```

### 6. 时间序列
```python
pd.to_datetime()
df.set_index()
df.resample()
df.rolling()
df.shift()
```

## 九、Pandas vs SQL 选型

| 特性 | Pandas | SQL |
|------|--------|-----|
| 数据源 | 文件 / API / 内存 | 数据库 |
| 灵活性 | 高（Python 生态） | 中（SQL 语法限制） |
| 学习曲线 | 平缓 | 陡峭（复杂查询） |
| 性能 | 中小数据集优秀 | 大数据集优秀 |
| 适用场景 | 数据分析 / 预处理 / 探索 | 数据存储 / 查询 / 事务 |
