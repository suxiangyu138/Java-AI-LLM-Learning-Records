# Linux 必做项目清单（从入门 → 运维 → 服务部署 → 生产级实战）

---

## 一、入门必做（Linux 基础命令与系统操作）

### 1. Linux 核心命令实战

**核心知识点**  
- 文件操作：`ls`、`cd`、`cp`、`mv`、`rm`、`mkdir`、`touch`  
- 查看命令：`cat`、`more`、`less`、`head`、`tail`、`grep`  
- 权限管理：`chmod`、`chown`、`chgrp`  
- 进程管理：`ps`、`top`、`htop`、`kill`  
- 网络命令：`ping`、`ifconfig` / `ip`、`netstat`、`ss`  

**核心功能**  
- 熟练操作文件、权限、进程、网络  
- 解决常见服务器基础问题  

**预计耗时**：1 天  

---

### 2. Vim 编辑器精通

**核心知识点**  
- 模式切换：普通模式、插入模式、命令模式  
- 光标移动、复制、粘贴、删除、撤销、查找替换  
- `.vimrc` 个性化配置  

**核心功能**  
- 纯命令行高效编辑配置文件、脚本、日志  

**预计耗时**：1–2 天  

---

### 3. 用户与权限体系实战

**核心知识点**  
- 用户 / 用户组管理：`useradd`、`userdel`、`groupadd`  
- `sudo` 权限配置与最小权限原则  
- 文件权限、目录权限、特殊权限（SUID / SGID / Sticky）  

**核心功能**  
- 多用户管理、权限隔离、安全管控  

**预计耗时**：1 天  

---

## 二、进阶必做（软件安装、网络、磁盘、日志）

### 4. 软件包管理与环境搭建

**核心知识点**  
- 包管理器：`yum` / `dnf` / `apt`  
- 源码编译安装、环境变量配置  
- JDK、MySQL、Redis、Nginx 的基础安装与启动  

**核心功能**  
- 从零搭建 Java 后端运行环境  

**预计耗时**：2 天  

---

### 5. 磁盘管理与文件系统

**核心知识点**  
- 磁盘分区、格式化、挂载  
- `df`、`du`、`fdisk`、`lsblk`、`mkfs`  
- 磁盘扩容、swap 分区配置  

**核心功能**  
- 处理服务器磁盘占满、挂载异常、扩容问题  

**预计耗时**：1–2 天  

---

### 6. 日志管理与排查

**核心知识点**  
- 系统日志与应用日志查看  
- `tail -f` 实时追踪日志  
- `grep` / `awk` / `sed` 做日志过滤与统计  
- `journalctl` 查看 systemd 服务日志  

**核心功能**  
- 快速定位服务报错、系统异常、程序崩溃问题  

**预计耗时**：1 天

## 三、核心必做（Shell 脚本 + 定时任务 + 自动化）

### 7. Shell 脚本编程实战

**核心知识点**  
- 变量、条件判断、循环、函数  
- 字符串处理、数组、文件读写  
- 脚本传参、日志输出、错误处理  

**核心功能**  
- 编写自动化脚本：备份、清理、部署、巡检、监控  

**预计耗时**：2–3 天  

---

### 8. Crontab 定时任务系统

**核心知识点**  
- 定时表达式  
- 用户级 / 系统级定时任务  
- 任务日志记录、失败重试思路、权限控制  

**核心功能**  
- 定时备份数据库  
- 定时清理日志 / 临时文件  
- 定时执行巡检脚本  

**预计耗时**：1 天  

---

### 9. 服务器安全加固

**核心知识点**  
- 防火墙：`firewalld` / `iptables` 基础配置  
- SSH 密钥登录、关闭密码登录  
- 禁止 root 远程登录  
- 端口暴露最小化、基础安全策略  

**核心功能**  
- 降低暴力破解和恶意访问风险  
- 打造可用于线上部署的安全服务器基础环境  

**预计耗时**：2 天

## 四、Java 后端必做（服务部署、调优、排障）

### 10. Java 项目生产级部署

**核心知识点**  
- JDK 环境配置、环境变量管理  
- SpringBoot Jar 包部署与后台运行  
- `nohup` 与 `systemd` 的区别与使用  
- systemd 服务托管、开机自启、失败重启  
- 启动脚本、停止脚本、日志切割  

**核心功能**  
- 实现 Java 服务稳定运行、自动拉起、日志管理  

**预计耗时**：2 天  

---

### 11. Nginx 反向代理与负载均衡

**核心知识点**  
- Nginx 安装与配置文件结构  
- 反向代理、负载均衡、动静分离  
- SSL 证书配置、跨域处理、限流基础配置  

**核心功能**  
- 部署前后端分离项目  
- 多个 Java 服务实例负载均衡  
- 实现 HTTPS 访问入口  

**预计耗时**：2–3 天  

---

### 12. 服务器性能排查实战

**核心知识点**  
- CPU 飙高、内存异常、磁盘 IO 过高排查  
- 工具：`top`、`vmstat`、`iostat`、`sar`、`free`、`ss`  
- 结合 JVM 工具定位 Java 服务问题（如 `jps`、`jstack`、`jmap`）  

**核心功能**  
- 快速定位线上服务器性能瓶颈  
- 形成“系统层 + JVM 层”联合排查能力  

**预计耗时**：2 天
