# Java 必做项目清单（入门 → 进阶 → 企业级实战 → 高阶架构）

---

## 一、入门必做（夯实 Java 基础 + 面向对象）

> 适合刚学完 Java SE：语法、OOP、集合、IO、异常、多线程

### 1. 控制台图书管理系统

**核心要点**  
- 类与对象建模（图书 / 用户 / 管理员）  
- 封装、构造方法、成员方法  
- 使用集合存储图书信息（List / Map）  
- 新增 / 删除 / 修改 / 查询图书  
- 文本文件持久化（IO 读写）  

---

### 2. 简易 ATM 银行系统

**核心要点**  
- 账户类设计（余额、密码、交易记录）  
- 继承、多态（普通账户 / VIP 账户）  
- 取款 / 存款 / 转账 / 查询流水  
- 异常处理（余额不足、非法输入）  
- 菜单驱动的控制台交互逻辑  

---

### 3. 学生成绩管理系统

**核心要点**  
- Student 类设计，存储多科成绩  
- 数组 / 集合存储学生列表  
- 排序（总分 / 单科）、查找（按学号 / 姓名）  
- 统计分析（平均分、最高分、最低分）  

---

### 4. 贪吃蛇（Java Swing）

**核心要点**  
- Swing GUI 编程（窗口、面板、绘图）  
- 定时器驱动蛇移动（`Timer` / 线程）  
- 键盘监听控制方向  
- 碰撞检测（墙体、身体）  
- 面向对象拆分：地图、蛇、食物、控制器  

---

### 5. 简易计算器

**核心要点**  
- 控制台或 Swing 版本  
- 基础四则运算、异常捕获  
- 输入校验、方法拆分与复用  

---

## 二、Web 基础项目（Java Web 核心能力）

> 衔接 Java SE → Spring，掌握 Servlet / JSP / MVC / 数据库交互

### 1. JSP + Servlet 个人博客

**核心要点**  
- MVC 模式（Servlet 控制层 + JSP 视图）  
- JDBC 连接 MySQL，完成文章 CRUD  
- Cookie / Session 登录状态管理  
- 文章列表分页、详情页展示  
- 简单评论功能  

---

### 2. 简易留言板

**核心要点**  
- 表单提交留言内容  
- Servlet 接收、校验、存库  
- JSP 页面渲染留言列表  
- 请求转发 / 重定向使用  

---

### 3. 用户权限管理系统

**核心要点**  
- 用户 / 角色 / 权限表设计  
- 过滤器实现登录拦截  
- 简单 RBAC（基于角色的访问控制）  
- 不同角色访问不同菜单和页面  

---

## 三、SSM 框架实战（Spring + SpringMVC + MyBatis）

> 校招基础必备，打通传统三件套

### 1. SSM 校园二手商城

**核心要点**  
- Spring 管理 Bean、事务控制  
- SpringMVC 路由 / 参数绑定 / 表单处理  
- MyBatis 映射、分页、条件查询  
- 商品发布 / 下架 / 浏览 / 搜索  
- 文件上传（商品图片）  

---

### 2. SSM 员工管理系统

**核心要点**  
- 多表联查（员工 / 部门 / 职位）  
- MyBatis 动态 SQL（if / where / foreach）  
- 拦截器实现登录 / 权限拦截  
- 全局异常处理与统一返回结构  

---

### 3. 在线考试系统

**核心要点**  
- 题库管理（单选 / 多选 / 判断）  
- 组卷策略（随机组卷 / 固定组卷）  
- 考试计时、自动交卷  
- 自动判分、成绩统计与分析

## 四、SpringBoot 核心必做（现代 Java 后端标准）

> 企业 90% 项目统一技术栈，必须熟练

### 1. 个人博客系统（SpringBoot + Thymeleaf）

**核心要点**  
- SpringBoot 自动配置、启动流程  
- 集成 MyBatis-Plus，简化 CRUD  
- 后台文章管理 + 前台展示  
- 评论系统、简单权限控制（管理员 / 普通用户）  

---

### 2. 在线图书商城

**核心要点**  
- 商品管理（图书信息、库存）  
- 购物车、订单提交、支付流程（可先模拟）  
- 订单状态变更（待支付 / 已支付 / 已发货 / 已完成）  
- 事务保证库存扣减与订单一致性  

---

### 3. 后台管理系统（SpringBoot + Vue）

**核心要点**  
- 前后端分离，RESTful API 设计  
- JWT 登录认证与鉴权  
- RBAC 权限模型（用户 / 角色 / 菜单）  
- 接口统一返回格式与错误码设计  

---

### 4. 文件上传下载系统

**核心要点**  
- 本地文件存储或对接阿里云 OSS / MinIO  
- 大文件分片上传、断点续传  
- 文件类型校验、白名单限制  
- 下载权限控制与限速

## 五、中间件实战项目（企业级必备技能）

> Redis、MQ、MySQL 优化，高并发、缓存、异步问题解决

### 1. Redis 秒杀系统

**核心要点**  
- 秒杀前缓存预热商品信息  
- 抢购接口限流、防止超卖  
- Redis 分布式锁 / Lua 脚本扣减库存  
- 异步下单，削峰填谷  

---

### 2. RabbitMQ 消息异步通知

**核心要点**  
- 订单创建后异步发送邮件 / 短信通知  
- 可靠消息投递、确认机制  
- 死信队列、延迟队列（如订单超时未支付自动关闭）  
- 消息重试与幂等性设计  

---

### 3. MySQL 电商订单系统

**核心要点**  
- 表结构设计（订单 / 订单项 / 支付记录）  
- 索引设计与优化、慢查询排查  
- 事务隔离级别、锁机制  
- 分表 / 分库初级实践  

---

### 4. Redis 分布式 Session 共享

**核心要点**  
- 分布式部署下 Session 共享问题  
- 使用 Redis 存储登录态  
- 缓存击穿 / 穿透 / 雪崩防护方案  
- Session 续期与注销  

---

## 学习路线建议（适配你当前规划）

1. **基础阶段**  
   Java SE → Java Web → SSM → SpringBoot 基础项目  
   - 目标：把 CRUD、事务、登录权限、简单架构打牢  

2. **中间件阶段**  
   Redis / MQ / MySQL 优化项目  
   - 目标：解决高并发、缓存、异步、慢查询等企业高频问题  

3. **AI 阶段（你的差异化重点）**  
   SpringBoot + AI 大模型项目（Java + Ollama、RAG、智能客服）  
   - 目标：在 Java 简历里体现「后端 + AI 应用」复合能力  

4. **架构阶段**  
   微服务 / 分布式 / 高并发项目  
   - 目标：对标中大厂实习 / 校招生架构理解要求
