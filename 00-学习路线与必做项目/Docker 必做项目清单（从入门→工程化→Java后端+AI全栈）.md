# Docker 必做项目清单（从入门 → 工程化 → Java 后端 + AI 全栈）

---

## 一、入门必做（吃透 Docker 核心基础）

### 1. 常用服务容器化部署

**技术栈**  
Docker

**核心知识点**  
- 镜像拉取、容器创建 / 启动 / 停止 / 删除  
- 端口映射、数据卷挂载、容器网络  
- 日志查看、进入容器、环境变量配置  

**核心功能**  
- 一键部署 MySQL、Redis、Nginx、RabbitMQ 等基础服务  

**预计耗时**：1 天  

---

### 2. 自定义镜像构建（Dockerfile）

**技术栈**  
Docker + Dockerfile

**核心知识点**  
- 基础镜像选择、分层构建、指令优化  
- 多阶段构建、镜像瘦身、缓存优化  
- `ENTRYPOINT`、`CMD`、`WORKDIR` 等核心指令  

**核心功能**  
- 封装 Java 后端、Python 脚本的自定义镜像  

**预计耗时**：2 天  

---

## 二、进阶必做（Docker Compose 服务编排）

### 3. 单体项目一键部署（SpringBoot）

**技术栈**  
Docker + Docker Compose

**核心知识点**  
- Compose 配置文件编写、服务依赖  
- 多服务联动、环境变量统一管理  
- 启动顺序控制、重启策略  

**核心功能**  
- 一键启动 SpringBoot + MySQL + Redis 完整后端环境  

**预计耗时**：2 天  

---

### 4. 多服务集群编排

**技术栈**  
Docker Compose

**核心知识点**  
- 服务扩容、负载均衡、网络隔离  
- 持久化数据卷、配置文件挂载  

**核心功能**  
- 多实例应用集群、中间件集群一键部署  

**预计耗时**：3 天
