# RabbitMQ 实战项目清单

## 一、核心能力

RabbitMQ 是 Java 后端消息中间件核心组件，必须掌握：

- 消息收发模型
- 三大交换机模式
- 消息可靠性保障
- 死信与延迟队列
- 高并发削峰解耦
- 幂等与最终一致性

---

## 二、技术能力拆解

- 基础层：生产者 / 消费者 / 队列 / 交换机 / 绑定
- 路由层：Fanout / Direct / Topic
- 可靠性层：ACK / NACK / 重试 / Confirm / Return
- 容错层：死信队列 / 延迟队列 / 异常告警
- 高并发层：削峰填谷 / 异步下单 / 流量缓冲
- 一致性层：幂等设计 / 本地消息表 / 最终一致性
- 运维层：队列监控 / 堆积排查 / 性能调优

---

## 九、RabbitMQ vs Kafka 选型

| 特性 | RabbitMQ | Kafka |
|------|----------|-------|
| 消息模型 | 队列 + 路由灵活 | 日志流 |
| 延迟队列 | 强 | 弱 |
| 路由能力 | 强 | 弱 |
| 高吞吐 | 中 | 强 |
| 适用场景 | 业务消息 / 延迟任务 / 解耦 | 日志流 / 大数据 / 实时计算 |
