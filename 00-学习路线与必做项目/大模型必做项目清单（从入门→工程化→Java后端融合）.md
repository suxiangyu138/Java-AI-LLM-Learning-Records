# 大模型必做项目清单（入门 → 工程化 → Java 后端融合）

结合你的 Java 后端 + 大模型应用开发职业路线，所有项目聚焦：

- 私有化部署
- RAG 落地
- Agent 工程化
- 后端架构整合

避开纯学术与微调弯路，全部为企业高频落地场景，可直接写入简历。

---

## 一、入门必做（掌握大模型调用与基础能力）

### 1. 本地大模型私有化部署

- 技术栈：Ollama / Docker
- 耗时：1 天

#### 核心知识点

- 开源模型选型（通义千问、Llama3、GLM、CodeLlama）
- 模型拉取、参数调优（Temperature、TopP、上下文窗口）
- 本地 API 服务启动、跨域配置

#### 核心功能

- 本地私有化对话
- 模型参数可控
- 无网络依赖

### 2. 多轮对话系统

- 技术栈：Python / SpringBoot + Ollama
- 耗时：2～3 天

#### 核心知识点

- 对话上下文管理、历史消息压缩
- 流式输出（SSE）、打字机效果
- 会话隔离、异常重试

#### 核心功能

- 多轮问答
- 上下文记忆
- 流式实时回复

### 3. Prompt 工程实战

- 技术栈：任意大模型
- 耗时：2 天

#### 核心知识点

- 零样本 / 少样本提示
- 思维链（CoT）
- 角色扮演、格式约束（JSON / Markdown）
- 专项 Prompt：代码生成、文档总结、翻译改写

#### 核心功能

- 结构化输出
- 专业角色对话
- 复杂问题推理

## 二、核心必做（RAG 检索增强，企业刚需）

### 4. 轻量化 PDF 知识库问答

- 技术栈：LangChain / Spring AI + Ollama + Milvus + PDF 解析
- 耗时：3～4 天

#### 核心知识点

- 文档解析、文本分块
- 向量化嵌入
- 向量库存储、相似度检索
- 引用溯源

#### 核心功能

- 私有 PDF 文档导入
- 精准问答
- 答案标注文档来源

### 5. 网页实时 RAG 问答

- 技术栈：爬虫 + 向量库 + 大模型
- 耗时：3 天

#### 核心知识点

- 网页正文提取
- 内容清洗去噪
- 临时向量库构建

#### 核心功能

- 输入 URL
- 基于网页内容实时问答

### 6. 企业级混合检索 RAG

- 技术栈：SpringBoot + Milvus + Elasticsearch
- 耗时：4～5 天

#### 核心知识点

- 向量 + 关键词混合检索
- 重排序优化
- 文档权限管理
- 批量导入、问答日志统计

#### 核心功能

- 多用户隔离知识库
- 高精准检索
- 企业级权限控制

- 自动拆解复杂需求
- 生成执行方案
