# Prompt Engineering 实战项目清单

## 一、核心能力

Prompt Engineering 不只是“会写提示词”，而是要掌握：

- 指令清晰化
- 角色设定
- 输出格式约束
- Few-shot / CoT / ReAct 等主流范式
- RAG / Agent / 工程化落地
- 安全对齐与提示词管理

---

## 二、技术能力拆解

- 基础层：角色设定 / 任务描述 / 输出约束
- 范式层：Few-shot / CoT / Self-Consistency / ReAct
- 应用层：信息提取 / 翻译改写 / 代码生成 / NL2SQL
- RAG 层：上下文注入 / 引用约束 / 幻觉控制
- Agent 层：任务拆解 / 工具调用 / 状态管理 / 反思优化
- 工程层：版本管理 / A/B 测试 / 自动评测 / 安全防护

---

## 三、必做项目（求职优先级）

### 1. 结构化信息提取器
**技术栈**：Ollama / OpenAI API + Python / SpringBoot

**实现**：
- 输入自由文本
- 自动提取姓名、时间、金额、地址、事件等字段
- 强制输出 JSON
- 缺失字段返回空值
- 格式错误自动重试

**核心技巧**：
- 角色定义
- 字段说明
- JSON 格式强约束
- 示例引导

**产出**：
- 通用结构化抽取 Prompt 模板

**耗时**：1天

---

### 2. 通用翻译与润色提示词
**技术栈**：Ollama / OpenAI API

**实现**：
- 中英互译
- 学术润色
- 口语化改写
- 公文风格改写
- 指定语气 / 风格输出

**核心技巧**：
- 风格控制
- 语气控制
- 场景化指令
- 少样本示例

**产出**：
- 多场景翻译改写 Prompt 库

**耗时**：1天

---

### 3. RAG 检索增强专用提示词
**技术栈**：Ollama + LangChain / Spring AI

**实现**：
- 输入检索上下文 + 用户问题
- 仅基于上下文回答
- 无答案时明确拒答
- 输出引用来源
- 避免幻觉扩写

**核心技巧**：
- 上下文优先级
- 禁止幻觉指令
- 边界兜底
- 引用格式约束

**产出**：
- 高可靠 RAG Answer Prompt

**耗时**：2天

---

### 4. Java 代码生成与审查提示词
**技术栈**：Ollama / OpenAI API + SpringBoot

**实现**：
- 输入需求生成 Java / Python 代码
- 约束代码规范
- 要求异常处理与边界判断
- 自动补充测试用例
- 对已有代码做审查与优化建议

**核心技巧**：
- 资深工程师角色设定
- 代码规范约束
- 输出结构模板
- 审查清单设计

**产出**：
- 代码生成 + 代码审查双 Prompt 模板

**耗时**：2天

---

### 5. NL2SQL 专用提示词
**技术栈**：SpringBoot + MySQL + Ollama / OpenAI API

**实现**：
- 输入表结构 + 自然语言问题
- 生成可执行 SQL
- 自动限制只使用给定表字段
- 防止 SQL 注入风险
- 失败后进行错误重试
- 输出 SQL + 解释说明

**核心技巧**：
- Schema 约束
- SQL 语法约束
- 错误重试
- 安全限制

**产出**：
- 企业级 NL2SQL Prompt 方案

**耗时**：3天

---

### 6. LangGraph Agent 系统提示词
**技术栈**：LangGraph + Ollama + Python / Java 后端

**实现**：
- 复杂任务输入
- 自动任务拆解
- 规划执行顺序
- 工具调用规则设计
- 状态流转提示词
- 汇总最终答案

**核心技巧**：
- 任务分解思维
- 规划链
- 状态追踪
- Agent 系统提示词设计

**产出**：
- Agent 工作流核心 Prompt 体系

**耗时**：3~4天
