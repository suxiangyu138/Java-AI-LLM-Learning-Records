# Navicat 核心知识点

## 一、概述

Navicat 是 PremiumSoft 公司推出的数据库管理 GUI 工具，支持 MySQL、PostgreSQL、Oracle、SQL Server、MongoDB 等多种数据库。它以 **界面友好、操作直观** 著称，是团队数据库管理和协作的常用工具。

**核心定位：** 面向团队的数据库可视化管理工具，功能全面，多数据库支持。

**官网：** https://www.navicat.com

## 二、核心功能

### 2.1 功能总览

| 功能模块 | 说明 |
|----------|------|
| **数据管理** | 表/视图/存储过程/函数的可视化增删改查 |
| **查询编辑器** | SQL 编辑器，支持语法高亮、自动补全、查询历史 |
| **数据模型设计** | ER 图可视化设计，正向/逆向工程 |
| **数据同步** | 不同数据库间的表结构和数据同步 |
| **备份/恢复** | 可视化备份调度、SQL 转储备份 |
| **数据传输** | 跨数据库/跨服务器的数据迁移 |
| **报表生成** | 基于查询结果生成图表和报表 |
| **计划任务** | 定时执行备份、同步、查询等批处理任务 |

### 2.2 支持的数据库

| 产品版 | 支持数据库 |
|--------|-----------|
| **Navicat Premium** | MySQL、PostgreSQL、SQLite、Oracle、SQL Server、MariaDB、MongoDB、Redis |
| **Navicat for MySQL** | MySQL / MariaDB 专用 |
| **Navicat for PostgreSQL** | PostgreSQL 专用 |
| **Navicat Data Modeler** | 独立的数据建模工具 |

## 三、核心功能详解

### 3.1 数据模型设计（ER 图）

```
正向工程：ER 图 → 自动生成 CREATE TABLE SQL
逆向工程：已有数据库 → 自动生成 ER 图
可视化操作：
  - 拖拽创建表、字段
  - 连线定义外键关系
  - 一键导出 SQL / 图片 / PDF
```

### 3.2 数据同步

```
源数据库 ←→ 目标数据库
  ├── 结构同步（对比表结构差异，生成 ALTER SQL）
  └── 数据同步（增量/全量同步表数据）
```

### 3.3 查询编辑器

| 功能 | 说明 |
|------|------|
| 代码片段 | 自定义 SQL 模板 |
| 查询历史 | 自动保存，支持搜索 |
| 结果导出 | Excel / CSV / JSON / HTML |
| 多标签 | 同时编辑多个查询 |

### 3.4 SSH/SSL 隧道

```
本地 Navicat → SSH 隧道 → 跳板机 → 数据库服务器
  支持：SSH、SSL/TLS、HTTP 代理
```

## 五、Navicat vs DataGrip

| 维度 | Navicat | DataGrip |
|------|---------|----------|
| 界面风格 | **传统桌面应用风格** | IDE 风格（JetBrains 统一） |
| 多数据库支持 | 多产品版覆盖 | **单工具支持所有** |
| SQL 智能补全 | 基础 | **强大**（类似 IDEA） |
| ER 图设计 | **可视化拖拽** | 只读视图 |
| 数据同步 | **内置** | 需额外工具 |
| IDE 集成 | 独立应用 | **JetBrains IDE 无缝** |
| 价格 | 付费 | JetBrains 订阅 |
| 学习曲线 | **低** | 中等 |

## 六、适用场景

1. **数据库管理员（DBA）**：全面管理工具，数据同步/备份/迁移
2. **全栈开发者**：多数据库统一管理界面
3. **数据分析师**：查询编辑器 + 结果导出 + 报表
4. **新手友好**：可视化 ER 图设计，降低数据库设计门槛

## 七、总结

Navicat 的核心竞争力在于 **全面的数据库管理功能**（特别是数据同步、ER 图设计、备份）和 **友好的界面**。对于需要跨多种数据库进行日常管理的场景，Navicat 比 DataGrip 更便捷。但若已使用 JetBrains IDE，DataGrip 的无缝集成是更大的优势。
