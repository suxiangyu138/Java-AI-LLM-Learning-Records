计算机「四大件」终极模块化精编
一、操作系统 Operating System（OS）  
1. 进程与线程
   1.1 进程三态：就绪、运行、阻塞；+挂起态、僵尸态。
   1.2 PCB 六大信息：PID、状态、程序计数器、寄存器、内存指针、I/O 状态。
   1.3 线程模型：用户级、内核级、混合；轻量级线程 LWP。
   1.4 经典问题：生产者-消费者、读者-写者、哲学家就餐。
   1.5 易错：死锁四必要条件缺一不可；线程共享地址空间≠共享栈。
   1.6 口诀：互斥、占有、非剥夺、循环等待——死锁四字诀。  
2. CPU 调度
   2.1 批处理：FCFS、SJF、HRRN。
   2.2 交互式：RR、多级反馈队列、CFS。
   2.3 实时：EDF、RMS。
   2.4 指标：周转时间、响应时间、吞吐率、CPU 利用率。
   2.5 易错：时间片过大退化为 FCFS；SJF 可导致饥饿。  
3. 内存管理
   3.1 连续分配：单一连续、固定分区、动态分区。
   3.2 离散分配：分页、分段、段页式；页表级数 2/3/4 级。
   3.3 虚拟内存：按需调页、页面置换算法 FIFO、LRU、CLOCK。
   3.4 快表 TLB：命中率计算；缺页中断流程。
   3.5 易错：页面大小 4 KB→12 位页内偏移；逻辑地址拆分位数算反。  
4. 文件与 I/O
   4.1 文件逻辑结构：流式、记录式；物理结构：连续、链式、索引。
   4.2 目录实现：FCB、索引节点 inode；硬链接 vs 软链接。
   4.3 磁盘调度：FCFS、SSTF、SCAN、C-SCAN；旋转延迟公式。
   4.4 缓存：Buffer Cache、Page Cache；写回 vs 写通。
   4.5 易错：inode 不存文件名；硬链接计数为 0 才真正删除。  
5. 同步机制
   5.1 信号量：整型、记录型；PV 操作成对出现。
   5.2 互斥锁、读写锁、自旋锁、乐观锁。
   5.3 管程 Monitor、条件变量。
   5.4 经典算法：Dekker、Peterson、面包店算法。
   5.5 易错：PV 操作顺序颠倒成死锁；使用自旋锁不关闭中断。  
    二、计算机组成原理 Computer Organization（CO）  
    1. 数据的表示
   1.1 进位制：2→10→16 互化；小数部分乘权求和。
   1.2 编码：原码、反码、补码；补码加减溢出判断。
   1.3 浮点：IEEE754 格式；阶码移码 127(+127)；规格化隐含 1。
   1.4 校验：奇偶、CRC、海明码距离 3 纠 1 位。
   1.5 易错：补码 1000 0000 表示 −128；浮点精度 EPSILON。  
2. 运算方法与 ALU
   2.1 加法器：串行、并行先行进位 CLA。
   2.2 乘除法：BOOTH 一位乘、恢复余数除法。
   2.3 逻辑运算：与、或、非、异或；位运算技巧清 0 置 1 反转。
   2.4 易错：BOOTH 编码 0→+1, 1→−1；除法余数符号同被除数。  
3. 存储系统
   3.1 层次结构：寄存器→Cache→主存→辅存；速度容量价格反比。
   3.2 Cache 映射：直接、全相联、组相联；替换 LRU；写策略写回/写通。
   3.3 地址映射：主存地址＝Tag+Index+Offset；命中率公式。
   3.4 虚拟存储：页表基址寄存器 PTBR；快表缺失两级页表。
   3.5 易错：Cache 行大小 64 B→Offset 6 位；组相联路数 2^Index。  
4. 指令系统
   4.1 指令格式：定长/变长；操作码扩展技术。
   4.2 寻址方式：立即、直接、间接、寄存器、相对、基址、变址。
   4.3 CISC vs RISC：指令条数、周期数 CPI 比较。
   4.4 易错：相对寻址 PC+Offset；基址与变址区别“谁可变”。  
5. CPU 结构与流水线
   5.1 五段流水：IF-ID-EX-MEM-WB；数据相关 RAW/WAR/WAW；控制相关。
   5.2 冒险解决：前递(forwarding)、气泡(bubble)、延迟分支。
   5.3 超标量：多发射端口；动态调度 Tomasulo。
   5.4 易错：流水线时钟周期=最慢段延时；吞吐率公式。  
    三、计算机网络 Computer Networks（CN）  
    1. 网络分层模型
   1.1 OSI 七层 vs TCP/IP 四层；PDU 名称：比特、帧、包、段、数据。
   1.2 封装与解封装：每层加首部；MTU 1500 B。  
2. 数据链路层
   2.1 成帧：字符计数、字节填充、比特填充 HDLC。
   2.2 差错控制：CRC-32 多项式模 2 除；ARQ 停等、GBN、SR。
   2.3 流量控制：滑动窗口大小=2ⁿ−1；信道利用率 U=1/(1+2a)。
   2.4 MAC 协议：CSMA/CD 冲突检测；CSMA/CA 无线；二进制指数退避。
   2.5 以太网帧格式：7B前导+1B定界+14B首部+46-1500B数据+4B CRC。
   2.6 易错：CRC 校验和不能纠错；CSMA/CD 最小帧长 64 B。  
3. 网络层
   3.1 IP 地址：IPv4 32 位点分十进制；子网掩码与 CIDR /24。
   3.2 路由算法：距离向量 RIP（最大跳数 15）、链路状态 OSPF、路径向量 BGP。
   3.3 NAT：私有地址 192.168.x.x；端口映射 PAT。
   3.4 ICMP：ping 回显请求/应答；Traceroute TTL 递增。
   3.5 IPv6：128 位，冒号十六进制，零压缩。
   3.6 易错：子网划分借位后主机位=32−掩码；全 0 全 1 地址不可用。  
4. 运输层
   4.1 UDP：无连接、首部 8 B；应用 DNS、DHCP、流媒体。
   4.2 TCP：可靠传输、三次握手、四次挥手、流量控制(滑动窗口)、拥塞控制(慢开始、拥塞避免、快重传、快恢复)。
   4.3 序号与确认号：SYN=1 消耗一个序号；RTT 估算 Karn 算法。
   4.4 易错：TCP 窗口大小单位字节；慢开始阈值 ssthresh 减半。  
5. 应用层
   5.1 HTTP：请求报文结构、状态码 1xx-5xx；HTTPS 握手 TLS。
   5.2 DNS：递归查询、迭代查询；A 记录、CNAME、MX。
   5.3 FTP：控制连接端口 21，数据连接端口 20/随机。
   5.4 Email：SMTP 发 25/587，POP3 收 110，IMAP 收 143。
   5.5 易错：HTTPS 在 TCP 之上；DNS 基于 UDP 53。  
    四、数据结构与算法 Data Structure & Algorithm（DSA）  
    1. 线性结构
   1.1 数组：随机访问 O(1)，插入/删除 O(n)；动态数组扩容 ×2。
   1.2 链表：单链表、双链表、循环链表；哨兵节点简化边界。
   1.3 栈：后进先出 LIFO；括号匹配、表达式求值；单调栈。
   1.4 队列：普通队列、循环队列、双端队列；滑动窗口最大值。
   1.5 易错：链表空指针；队列判空/判满 (rear+1)%size==front。  
2. 树与二叉树
   2.1 遍历：前序、中序、后序、层序；递归+迭代栈。
   2.2 二叉搜索树：插入、删除、查找 O(h)；极端退化链表。
   2.3 平衡树：AVL 旋转 LL/LR/RL/RR；红黑树五特性。
   2.4 堆：大顶堆、小顶堆；建堆 O(n)，堆排序 O(nlogn)。
   2.5 Trie 树：字符串前缀统计；压缩 Trie 基数树。
   2.6 易错：递归深度导致栈溢出；AVL 删除后回溯平衡因子。  
3. 图
   3.1 存储：邻接矩阵 O(n²)、邻接表 O(n+e)。
   3.2 遍历：DFS 栈/递归，BFS 队列；拓扑排序（入度表）。
   3.3 最短路径：Dijkstra（非负权）、SPFA（可负权）、Floyd 多源。
   3.4 最小生成树：Prim 加点、Kruskal 加边并查集。
   3.5 关键路径：AOE 网最长路径；拓扑+动态规划。
   3.6 易错：DFS 判环需三色标记；Dijkstra 不能负权。  
4. 哈希与字符串
   4.1 哈希函数：除留余数法、MAD、随机数法；冲突解决链地址、开放寻址。
   4.2 字符串匹配：BF、KMP next 数组、BM Sunday。
   4.3 易错：哈希表装载因子>0.75 需扩容；KMP next[-1]=-1 边界。  
5. 查找与排序
   5.1 查找：顺序、折半、插值、斐波那契、分块、哈希。
   5.2 排序：插排、希尔、冒泡、快排、归并、堆排、基数。
   5.3 复杂度口诀：
       O(nlogn) 快归堆，
       O(n²) 插冒选，
       O(n) 基数桶。
   5.4 易错：快排 pivot 选首元素最坏 O(n²)；归并空间 O(n)。  
6. 动态规划
   6.1 背包：0-1、完全、多重、分组；状态转移方程模板。
   6.2 区间 DP：石子合并、矩阵连乘；记忆化搜索。
   6.3 线性 DP：LIS、LCS、编辑距离。
   6.4 树形 DP：树上最大独立集、换根 DP。
   6.5 易错：状态未包含全部维度；边界初始化 0/-∞ 错用。  
7. 贪心与分治
   7.1 贪心：活动安排、Huffman 编码、最小生成树 Prim/Kruskal。
   7.2 分治：归并排序、快速幂、棋盘覆盖、最近点对。
   7.3 易错：贪心需证明最优子结构；分治递归出口漏写。  
8. 高级主题
   8.1 并查集：路径压缩+按秩合并；带权并查集判奇环。
   8.2 线段树：点更新、区间更新 lazy tag；离散化。
   8.3 树状数组：单点更新区间求和；二维树状数组。
   8.4 易错：线段树区间 [l,r] 闭区间；lazy tag 下传顺序。  
    易错速记口诀
    OS：互斥占有非剥夺，循环等待死锁决。
    CO：补码加减溢位看最高进位异或。
    CN：三次握手 SYN-SYN/ACK-ACK，四次挥手 FIN-ACK-FIN-ACK。
    DSA：快排不稳归并稳，哈希冲突链开放。
