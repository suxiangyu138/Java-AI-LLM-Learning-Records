## 1. 线性结构

### 1.1 数组（Array）

**核心特性：**
- 连续内存存储，支持 O(1) 随机访问
- 插入/删除 O(n)——需要移动元素
- Java 中对应 `int[]`、`ArrayList`（动态数组）

**关键考点：**
- 双指针技巧（快慢指针、左右指针）
- 前缀和数组（快速区间求和）
- 差分数组（快速区间增减）
- 二分查找的边界处理

**ArrayList 扩容机制（Java 源码）：**
```java
// ArrayList.add() 触发扩容时核心逻辑
// 默认容量 10，扩容因子 1.5 倍
int newCapacity = oldCapacity + (oldCapacity >> 1);
```

### 1.2 链表（Linked List）

**核心特性：**
- 非连续存储，插入/删除 O(1)，查找 O(n)
- Java 中对应 `LinkedList`（双向链表）

**关键考点：**
- 反转链表（迭代 + 递归）
- 环形链表检测（Floyd 判圈算法）
- 合并两个有序链表
- LRU 缓存实现（HashMap + 双向链表）

**手写 LRU 缓存模板：**
```java
public class LRUCache extends LinkedHashMap<Integer, Integer> {
    private int capacity;
    public LRUCache(int capacity) {
        super(capacity, 0.75f, true);
        this.capacity = capacity;
    }
    @Override
    protected boolean removeEldestEntry(Map.Entry<Integer, Integer> eldest) {
        return size() > capacity;
    }
}
```

### 1.3 栈（Stack）

**核心特性：**
- LIFO（后进先出）
- Java 中推荐用 `ArrayDeque` 代替 `Stack`（Stack 是遗留类，线程安全开销大）

**高频题：**
- 有效的括号匹配
- 单调栈（接雨水、每日温度）
- 表达式求值（中缀转后缀）

### 1.4 队列（Queue）

**核心特性：**
- FIFO（先进先出）
- `LinkedList` 和 `ArrayDeque` 均可作为队列使用

**关键变体：**
- 双端队列（`Deque`）：两端均可进出
- 优先队列（`PriorityQueue`）：二叉堆实现，默认最小堆
- 单调队列：滑动窗口最大值

### 1.5 哈希表（Hash Table）

**核心特性：**
- O(1) 查找/插入/删除（均摊）
- Java 中对应 `HashMap`、`HashSet`

**Java HashMap 底层原理（高频面试题）：**
- JDK 1.8：数组 + 链表 + 红黑树
- 链表长度 ≥8 且数组长度 ≥64 时转红黑树
- 默认负载因子 0.75，扩容为原来的 2 倍
- 使用 `(n - 1) & hash` 计算下标（等价于 hash % n，但更高效）

## 2. 树结构

### 2.1 二叉树（Binary Tree）

**遍历方式（必须能手写）：**
| 方式 | 顺序 | 递归 | 迭代 |
|------|------|------|------|
| 前序 | 根→左→右 | 简单 | 栈 |
| 中序 | 左→根→右 | 简单 | 栈 |
| 后序 | 左→右→根 | 简单 | 双栈/标记 |
| 层序 | 按层 | — | 队列 |

**通用迭代模板（前序遍历）：**
```java
public List<Integer> preorder(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    Deque<TreeNode> stack = new ArrayDeque<>();
    while (root != null || !stack.isEmpty()) {
        while (root != null) {
            res.add(root.val);
            stack.push(root);
            root = root.left;
        }
        root = stack.pop().right;
    }
    return res;
}
```

### 2.2 二叉搜索树（BST）

**核心性质：**
- 左子树所有节点 < 根 < 右子树所有节点
- 中序遍历得到有序序列

**关键操作：**
- 查找/插入：O(log n) 期望，O(n) 最坏（退化为链表）
- 删除：分三种情况（叶子/单子/双子）
- 验证 BST：递归时传递上下界

### 2.3 平衡树

| 树类型 | 平衡条件 | 应用场景 |
|--------|----------|----------|
| AVL 树 | 左右子树高度差 ≤1 | 查找密集型 |
| 红黑树 | 5 条性质（颜色约束） | Java TreeMap、HashMap |
| B 树 | 多路平衡 | 数据库索引、文件系统 |
| B+ 树 | 数据仅存叶子，叶子链表 | MySQL InnoDB 索引 |

**红黑树核心性质：**
1. 节点非红即黑
2. 根节点是黑色
3. 叶子（NIL）是黑色
4. 红色节点的子节点必为黑色
5. 任意节点到其叶子路径包含相同数量黑色节点

### 2.4 堆（Heap）

**核心特性：**
- 完全二叉树，用数组存储
- 父节点与子节点关系：`parent(i) = (i-1)/2`，`left = 2i+1`，`right = 2i+2`

**Java PriorityQueue 使用：**
```java
// 最小堆（默认）
PriorityQueue<Integer> minHeap = new PriorityQueue<>();
// 最大堆
PriorityQueue<Integer> maxHeap = new PriorityQueue<>((a, b) -> b - a);
// 自定义比较器
PriorityQueue<Node> pq = new PriorityQueue<>(Comparator.comparingInt(n -> n.val));
```

**高频题：**
- Top-K 问题（堆 vs 快排分区）
- 合并 K 个有序链表
- 数据流的中位数（大小堆）

## 3. 图论

### 3.1 图的表示

| 方式 | 空间 | 适用场景 |
|------|------|----------|
| 邻接矩阵 | O(V²) | 稠密图 |
| 邻接表 | O(V+E) | 稀疏图 |

```java
// 邻接表（最常用）
List<Integer>[] graph = new ArrayList[n];
for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
// 带权图
Map<Integer, Integer>[] weightedGraph = new HashMap[n];
```

### 3.2 DFS（深度优先搜索）

**核心模板：**
```java
boolean[] visited = new boolean[n];
void dfs(int node) {
    visited[node] = true;
    for (int next : graph[node]) {
        if (!visited[next]) dfs(next);
    }
}
```

**典型题：**
- 岛屿数量（Flood Fill）
- 拓扑排序（DFS 后序遍历取反）
- 所有可能路径（回溯）

### 3.3 BFS（广度优先搜索）

**核心模板：**
```java
Queue<Integer> q = new LinkedList<>();
boolean[] visited = new boolean[n];
q.offer(start);
visited[start] = true;
int step = 0;
while (!q.isEmpty()) {
    int size = q.size();
    for (int i = 0; i < size; i++) {
        int cur = q.poll();
        if (cur == target) return step;
        for (int next : graph[cur]) {
            if (!visited[next]) {
                visited[next] = true;
                q.offer(next);
            }
        }
    }
    step++;
}
```

### 3.4 最短路径

| 算法 | 适用范围 | 时间复杂度 |
|------|----------|------------|
| Dijkstra | 非负权 | O(E log V) |
| Bellman-Ford | 含负权（检测负环） | O(VE) |
| Floyd-Warshall | 全源最短路径 | O(V³) |
| SPFA | 含负权（队列优化） | O(VE) 期望 |

**Dijkstra 标准模板：**
```java
int[] dist = new int[n];
Arrays.fill(dist, Integer.MAX_VALUE);
dist[start] = 0;
PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[1] - b[1]);
pq.offer(new int[]{start, 0});
while (!pq.isEmpty()) {
    int[] cur = pq.poll();
    int u = cur[0], d = cur[1];
    if (d > dist[u]) continue; // 懒惰删除
    for (int[] edge : weightedGraph[u]) {
        int v = edge[0], w = edge[1];
        if (dist[u] + w < dist[v]) {
            dist[v] = dist[u] + w;
            pq.offer(new int[]{v, dist[v]});
        }
    }
}
```

### 3.5 拓扑排序

**Kahn 算法（BFS 方式）：**
```java
int[] indegree = new int[n];
// 统计入度...
Queue<Integer> q = new LinkedList<>();
for (int i = 0; i < n; i++) if (indegree[i] == 0) q.offer(i);
List<Integer> topo = new ArrayList<>();
while (!q.isEmpty()) {
    int u = q.poll();
    topo.add(u);
    for (int v : graph[u]) {
        if (--indegree[v] == 0) q.offer(v);
    }
}
// topo.size() == n → 合法拓扑序；< n → 存在环
```

## 4. 经典算法

### 4.1 排序算法

| 算法 | 平均时间 | 最坏时间 | 空间 | 稳定性 |
|------|----------|----------|------|--------|
| 快速排序 | O(n log n) | O(n²) | O(log n) | 不稳定 |
| 归并排序 | O(n log n) | O(n log n) | O(n) | 稳定 |
| 堆排序 | O(n log n) | O(n log n) | O(1) | 不稳定 |
| 插入排序 | O(n²) | O(n²) | O(1) | 稳定 |
| 冒泡排序 | O(n²) | O(n²) | O(1) | 稳定 |

**快排核心代码（双指针分区）：**
```java
int partition(int[] nums, int lo, int hi) {
    int pivot = nums[lo];
    int i = lo, j = hi + 1;
    while (true) {
        while (++i <= hi && nums[i] < pivot);
        while (--j >= lo && nums[j] > pivot);
        if (i >= j) break;
        swap(nums, i, j);
    }
    swap(nums, lo, j);
    return j;
}
```

### 4.2 二分查找

**核心要点：**
- 区间定义要一致（`[left, right]` 或 `[left, right)`）
- `mid` 计算防溢出：`mid = left + (right - left) / 2`
- 找左边界、右边界时收缩策略不同

```java
// 找左边界（第一个 ≥ target 的位置）
int leftBound(int[] nums, int target) {
    int left = 0, right = nums.length;
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] >= target) right = mid;
        else left = mid + 1;
    }
    return left;
}
```

### 4.3 动态规划（DP）

**解题框架（DP 五部曲）：**
1. 定义状态 `dp[i]` 表示什么
2. 推导状态转移方程
3. 确定初始值（base case）
4. 确定遍历顺序
5. 举例推导验证

**经典题型分类：**

| 类型 | 代表题目 |
|------|----------|
| 背包问题 | 0-1 背包 / 完全背包 / 多重背包 |
| 子序列问题 | 最长递增子序列(LIS) / 最长公共子序列(LCS) |
| 区间 DP | 戳气球 / 石子游戏 |
| 树形 DP | 打家劫舍 III |
| 状态压缩 DP | 旅行商问题(TSP) |

```java
// 0-1 背包模板（二维 → 一维优化）
for (int i = 0; i < n; i++)
    for (int j = capacity; j >= weight[i]; j--)
        dp[j] = Math.max(dp[j], dp[j - weight[i]] + value[i]);
```

### 4.4 贪心算法

**关键判断：** 局部最优 → 全局最优（需要数学证明）

**典型题：**
- 活动选择 / 会议室安排
- 跳跃游戏
- Huffman 编码

### 4.5 回溯算法

**核心模板：**
```java
void backtrack(路径, 选择列表) {
    if (满足结束条件) { result.add(路径); return; }
    for (选择 : 选择列表) {
        做选择;
        backtrack(路径, 选择列表);
        撤销选择;
    }
}
```

**典型题：**
- 全排列 / 组合 / 子集
- N 皇后
- 数独求解

### 4.6 双指针与滑动窗口

**双指针分类：**
- 左右指针：二分查找、反转数组、回文判定
- 快慢指针：环检测（Floyd 判圈）、找中点

**滑动窗口模板（变长）：**
```java
int left = 0, right = 0;
while (right < n) {
    扩大窗口（加入 right 元素）;
    while (窗口需要收缩) {
        缩小窗口（移除 left 元素）;
        left++;
    }
    更新结果;
    right++;
}
```

### 4.7 位运算

**常用技巧：**
- `n & 1`：判断奇偶
- `n & (n-1)`：消除最低位 1
- `n ^ n = 0`，`a ^ 0 = a`
- 异或用于找出现奇数次元素
