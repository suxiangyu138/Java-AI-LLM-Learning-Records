## 1. 向量与向量空间

### 1.1 向量基本概念

**几何视角：** 具有大小和方向的量（箭头）
**代数视角：** 有序的 n 元组 (v₁, v₂, ..., vₙ)

**基本运算：**
- **向量加法：** v + w = (v₁+w₁, v₂+w₂, ..., vₙ+wₙ)
- **标量乘法：** cv = (cv₁, cv₂, ..., cvₙ)
- **内积（点积）：** v·w = v₁w₁ + v₂w₂ + ... + vₙwₙ
- **模（长度）：** ||v|| = √(v·v)

### 1.2 线性相关与线性无关

**线性组合：** c₁v₁ + c₂v₂ + ... + cₙvₙ

**线性无关：** 若 c₁v₁ + c₂v₂ + ... + cₙvₙ = 0 仅在 c₁=c₂=...=cₙ=0 时成立，则向量组线性无关。

**线性相关：** 存在一组不全为零的系数使线性组合为零向量。

**直观理解：**
- 二维：两个非共线的向量线性无关（构成坐标系）
- 三维：三个不共面的向量线性无关

### 1.3 基与维数

**基（Basis）：** 向量空间 V 中一组线性无关且能生成 V 的向量。

**维数：** 基中向量的个数。

**标准基（Standard Basis）：** R³ 标准基为 e₁=(1,0,0), e₂=(0,1,0), e₃=(0,0,1)

### 1.4 向量在工程中的应用

**词向量（Word Embedding）：**
```
"king" - "man" + "woman" ≈ "queen"
```
300 维向量空间中，语义相近的词在向量空间中接近，类比关系在向量运算中成立。

**Java 向量运算库：**
```java
// 使用 Apache Commons Math
RealVector v1 = new ArrayRealVector(new double[]{1.0, 2.0, 3.0});
RealVector v2 = new ArrayRealVector(new double[]{4.0, 5.0, 6.0});
double dotProduct = v1.dotProduct(v2);    // 内积
double distance   = v1.getDistance(v2);   // 欧氏距离
double cosine     = dotProduct / (v1.getNorm() * v2.getNorm()); // 余弦相似度
```

## 2. 矩阵运算

### 2.1 矩阵基本概念

**定义：** m×n 的矩形数组
```
A = [a₁₁ a₁₂ ... a₁ₙ]
    [a₂₁ a₂₂ ... a₂ₙ]
    [ ... ... ... ... ]
    [aₘ₁ aₘ₂ ... aₘₙ]
```

### 2.2 矩阵乘法

**定义：** (AB)_{ij} = Σₖ A_{ik} × B_{kj}

**关键性质：**
- 矩阵乘法**不满足交换律**：AB ≠ BA（通常）
- 矩阵乘法**满足结合律**：(AB)C = A(BC)

```java
// 矩阵乘法的 Java 实现（三重循环）
double[][] multiply(double[][] a, double[][] b) {
    int m = a.length, n = b[0].length, k = b.length;
    double[][] c = new double[m][n];
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            for (int p = 0; p < k; p++)
                c[i][j] += a[i][p] * b[p][j];
    return c;
}
```

### 2.3 特殊矩阵

| 矩阵类型 | 定义 | 性质 |
|----------|------|------|
| 单位矩阵 I | 对角线上全为 1，其余为 0 | AI = IA = A |
| 对角矩阵 | 仅对角线上非零 | 运算简化为对角元直接运算 |
| 转置矩阵 Aᵀ | 行和列互换 | (AB)ᵀ = BᵀAᵀ |
| 对称矩阵 | A = Aᵀ | 协方差矩阵、核矩阵 |
| 正交矩阵 | AᵀA = I | 旋转矩阵、反射矩阵 |
| 逆矩阵 A⁻¹ | AA⁻¹ = A⁻¹A = I | 仅方阵且 det ≠ 0 时存在 |

### 2.4 矩阵在神经网络中的角色

```
输入层    隐藏层1    隐藏层2    输出层
x₁        h₁¹       h₁²       y₁
x₂   ──►  h₂¹  ──►  h₂²  ──► y₂
x₃        h₃¹       h₃²
x₄

每一层的计算：h = σ(Wx + b)
  W: 权重矩阵（线性变换）
  b: 偏置向量（平移）
  σ: 激活函数（引入非线性）
```

**全连接层的本质：** 矩阵乘法 Wx

## 3. 行列式

### 3.1 几何意义

**n 阶行列式的几何意义：** n 个列向量所张成的平行多面体的（有向）体积。

- 二维：2 个列向量张成的平行四边形面积
- 三维：3 个列向量张成的平行六面体体积
- det(A) = 0 → 列向量线性相关 → 退化（体积为 0）

### 3.2 基本性质

| 性质 | 说明 |
|------|------|
| det(I) = 1 | 单位矩阵行列式为 1 |
| det(AB) = det(A)·det(B) | 乘法可分离 |
| det(Aᵀ) = det(A) | 转置不改变行列式 |
| det(A⁻¹) = 1/det(A) | 逆矩阵行列式为倒数 |
| 行列互换 → 变号 | 交换两行则行列式变号 |
| 倍乘 → 扩大 k 倍 | 某行乘以 k，行列式扩大 k 倍 |

### 3.3 行列式计算

**2×2 矩阵：**
```
det([a b]) = ad - bc
    ([c d])
```

**3×3 矩阵：** 按第一行展开（余子式展开）

**n×n 矩阵：** 通常用高斯消元法化为上三角矩阵 → 行列式 = 对角元之积

## 4. 特征值与特征向量

### 4.1 定义与几何意义

**定义：** Ax = λx，其中 λ 为特征值，x（≠0）为对应的特征向量。

**几何意义：** 矩阵 A 作用于特征向量 x 上，只改变长度（λ 倍），不改变方向。

### 4.2 特征分解（谱分解）

**若 n×n 矩阵 A 有 n 个线性无关的特征向量，则：**
```
A = PDP⁻¹

其中：
  D = diag(λ₁, λ₂, ..., λₙ)  — 特征值对角矩阵
  P = [x₁  x₂  ...  xₙ]      — 特征向量矩阵
```

### 4.3 AI 中的关键应用

**PCA（主成分分析）：**
1. 计算数据协方差矩阵
2. 求协方差矩阵的特征值和特征向量
3. 取最大 k 个特征值对应的特征向量作为主成分
4. 数据投影到主成分空间实现降维

**图神经网络中的谱方法：** 利用图的拉普拉斯矩阵的特征分解进行图卷积。

## 5. 线性变换

### 5.1 核心思想

**线性变换：** 一个函数 T: V→W，满足：
- T(u + v) = T(u) + T(v)
- T(cv) = cT(v)

**矩阵表示：** 每个线性变换都可以用矩阵表示。

### 5.2 常见线性变换

| 变换 | 二维矩阵 | 效果 |
|------|----------|------|
| 缩放 | `[sₓ 0; 0 sᵧ]` | 按比例拉伸 |
| 旋转（逆时针θ） | `[cosθ -sinθ; sinθ cosθ]` | 绕原点旋转 |
| 反射 | `[-1 0; 0 1]` | 关于 y 轴镜像 |
| 剪切 | `[1 k; 0 1]` | 水平错切 |

### 5.3 奇异值分解（SVD）

**任何 m×n 矩阵 A 都可分解为：**
```
A = U Σ Vᵀ
  U: m×m 正交矩阵（左奇异向量）
  Σ: m×n 对角矩阵（奇异值，σ₁ ≥ σ₂ ≥ ... ≥ 0）
  V: n×n 正交矩阵（右奇异向量）
```

**SVD 的应用：**
- **图像压缩：** 保留前 k 个最大奇异值，压缩比极高
- **推荐系统：** 用户-物品评分矩阵的潜在因子模型
- **潜在语义分析（LSA）：** 词-文档矩阵的主题提取

## 6. 矩阵分解

### 6.1 各类分解总结

| 分解 | 公式 | 条件 | 应用 |
|------|------|------|------|
| LU 分解 | A = LU | 方阵可逆 | 解线性方程组、计算行列式 |
| 特征分解 | A = PDP⁻¹ | 方阵，有 n 个特征向量 | PCA、微分方程 |
| Cholesky 分解 | A = LLᵀ | 对称正定 | 优化问题、Monte Carlo |
| QR 分解 | A = QR | 任意矩阵 | 最小二乘、特征值计算 |
| SVD | A = UΣVᵀ | **任意矩阵** | 降维、压缩、推荐 |

### 6.2 矩阵分解在推荐系统中的应用

**协同过滤（SVD 简化版）：**
```
用户-物品评分矩阵 R ≈ P × Qᵀ
  R: m 个用户 × n 个物品（稀疏）
  P: m × k（用户潜在因子矩阵）
  Q: n × k（物品潜在因子矩阵）
  k: 潜在因子维度（k << min(m,n)）
```

## 7. AI 与后端开发关联

### 7.1 神经网络中的矩阵运算

**前向传播（全连接层）：**
```java
// 使用 DJL（Deep Java Library）或 ND4J 进行矩阵运算
INDArray input   = Nd4j.create(new float[]{0.5f, 0.3f, 0.2f}, new int[]{1, 3});
INDArray weights = Nd4j.randn(3, 64);   // 3×64 权重矩阵
INDArray bias    = Nd4j.zeros(1, 64);
INDArray output  = input.mmul(weights).add(bias);  // 矩阵乘法 + 偏置
// output = σ(output)  → 激活函数
```

### 7.2 余弦相似度与 Embedding 检索

```java
// 两个 Embedding 向量的余弦相似度
double cosineSimilarity(double[] a, double[] b) {
    double dot = 0, normA = 0, normB = 0;
    for (int i = 0; i < a.length; i++) {
        dot   += a[i] * b[i];
        normA += a[i] * a[i];
        normB += b[i] * b[i];
    }
    return dot / (Math.sqrt(normA) * Math.sqrt(normB));
}
// 用于 RAG 系统中的相似文档检索
```

### 7.3 Java 主流数值计算库

| 库 | 特点 | 适用场景 |
|------|------|----------|
| **ND4J** | NDArray，GPU 支持，类似 NumPy | 深度学习（DL4J 底层） |
| **Apache Commons Math** | 轻量级，纯 Java | 通用数学计算 |
| **EJML** | 高效 dense/sparse 矩阵库 | 矩阵密集计算 |
| **JBlas** | JNI 调用 BLAS/LAPACK | 高性能线性代数 |
| **DJL** | Amazon 的 Deep Java Library | 深度学习全栈框架 |

### 7.4 Transformer 中的线性代数

**Self-Attention 公式：**
```
Attention(Q, K, V) = softmax(QKᵀ / √dₖ) V

Q (Query):  n×dₖ  矩阵
K (Key):    n×dₖ  矩阵
V (Value):  n×dᵥ  矩阵
QKᵀ:       n×n   （注意力得分矩阵）
softmax:    对每行归一化
×V:         加权求和
```

整个过程就是矩阵乘法和 softmax 的组合——线性代数是 Transformer 的数学语言。
