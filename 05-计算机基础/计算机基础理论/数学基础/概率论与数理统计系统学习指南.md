## 1. 概率基础

### 1.1 基本概念

| 概念 | 符号 | 定义 |
|------|------|------|
| 样本空间 | Ω | 所有可能结果的集合 |
| 事件 | A ⊆ Ω | 样本空间的子集 |
| 概率 | P(A) | 事件发生的可能性度量，0 ≤ P(A) ≤ 1 |
| 条件概率 | P(A\|B) | B 发生条件下 A 发生的概率 |
| 独立事件 | P(A∩B) = P(A)P(B) | A 和 B 的发生互不影响 |

### 1.2 条件概率公式

```
P(A|B) = P(A ∩ B) / P(B)    —— B 发生条件下 A 发生的概率
```

**乘法公式：** P(A ∩ B) = P(A|B) · P(B) = P(B|A) · P(A)

### 1.3 全概率公式

**若 B₁, B₂, ..., Bₙ 是 Ω 的一个划分（互斥且穷尽），则：**
```
P(A) = Σᵢ P(A|Bᵢ) · P(Bᵢ)
```

**应用：** 当直接求 P(A) 困难时，将 A 分解到各个条件 Bᵢ 下计算。

## 2. 随机变量与分布

### 2.1 离散型 vs 连续型

| | 离散型随机变量 | 连续型随机变量 |
|------|---------------|---------------|
| 取值 | 有限或可数无限个 | 不可数无限个（区间） |
| 描述 | 概率质量函数（PMF） | 概率密度函数（PDF） |
| 概率 | P(X=k) = pmf(k) | P(a≤X≤b) = ∫ₐᵇ f(x)dx |
| 累积分布 | F(x) = P(X≤x) = Σₖ₌ₓ pmf(k) | F(x) = P(X≤x) = ∫₋∞ˣ f(t)dt |

### 2.2 常见离散分布

| 分布 | PMF | 参数 | 典型场景 |
|------|-----|------|----------|
| 伯努利（Bernoulli） | P(X=1)=p, P(X=0)=1-p | p | 硬币正反面、点击/不点击 |
| 二项（Binomial） | P(X=k)=C(n,k)·p^k·(1-p)^{n-k} | n, p | n 次试验中成功的次数 |
| 泊松（Poisson） | P(X=k)=λᵏe^{-λ}/k! | λ | 单位时间到达次数、系统故障数 |
| 几何（Geometric） | P(X=k)=(1-p)^{k-1}·p | p | 首次成功所需的试验次数 |

### 2.3 常见连续分布

| 分布 | PDF | 参数 | 典型场景 |
|------|-----|------|----------|
| 均匀（Uniform） | f(x)=1/(b-a), x∈[a,b] | a,b | 等可能性事件 |
| 正态（Normal） | f(x)=1/(σ√2π)·e^{-(x-μ)²/(2σ²)} | μ,σ² | **自然现象、测量误差、DL 中的权重初始化** |
| 指数（Exponential） | f(x)=λe^{-λx}, x≥0 | λ | 等待时间、机器寿命 |
| 伽马（Gamma） | f(x)=βᵅxᵅ⁻¹e^{-βx}/Γ(α) | α,β | 贝叶斯统计中的共轭先验 |

### 2.4 正态分布的重要性

**为什么正态分布无处不在？** → 中心极限定理（多个独立因素的叠加趋近正态分布）

**AI 中的应用：**
- 神经网络权重初始化（Xavier/He 用正态分布）
- 扩散模型中的噪声（高斯噪声添加与去除）
- VAE 中的隐变量分布

## 3. 数字特征

### 3.1 期望（Expectation）

**离散：** E[X] = Σ x · P(X=x)
**连续：** E[X] = ∫ x · f(x) dx

**线性性质：** E[aX + bY] = aE[X] + bE[Y]

### 3.2 方差（Variance）

**定义：** Var(X) = E[(X - E[X])²] = E[X²] - (E[X])²

**性质：**
- Var(aX + b) = a²·Var(X)
- 独立时：Var(X+Y) = Var(X) + Var(Y)

**标准差：** σ = √Var(X) —— 与 X 同单位

### 3.3 协方差与相关系数

**协方差：** Cov(X,Y) = E[(X-E[X])(Y-E[Y])] = E[XY] - E[X]E[Y]

**相关系数：** ρ(X,Y) = Cov(X,Y) / (σₓ·σᵧ) ∈ [-1, 1]
- ρ > 0：正相关（X 大时 Y 也大）
- ρ < 0：负相关
- ρ = 0：不相关（不一定是独立，但独立一定不相关）

### 3.4 数字特征对照表

| 分布 | E[X] | Var(X) |
|------|------|--------|
| 二项 B(n,p) | np | np(1-p) |
| 泊松 P(λ) | λ | λ |
| 均匀 U(a,b) | (a+b)/2 | (b-a)²/12 |
| 正态 N(μ,σ²) | μ | σ² |
| 指数 Exp(λ) | 1/λ | 1/λ² |

## 4. 大数定律与中心极限定理

### 4.1 大数定律（LLN）

**弱大数定律：**
```
X̄ₙ = (X₁+X₂+...+Xₙ)/n  →  E[X]  （依概率收敛）
```
当样本量足够大时，样本均值逼近总体期望。

**对 AI 的意义：** 随着训练数据增加，模型的经验风险逼近真实风险。这是机器学习中经验风险最小化（ERM）的理论基础。

### 4.2 中心极限定理（CLT）

```
(X̄ₙ - μ) / (σ/√n)  →  N(0, 1)  （分布收敛）
```
无论总体分布是什么，样本均值的分布趋近于正态分布。

**应用：**
- A/B 测试：样本量 ≥30 即可用正态近似做假设检验
- 置信区间：`X̄ ± z_{α/2} · σ/√n`
- 负载测试判断：P95/P99 延迟的统计推断

## 5. 贝叶斯定理

### 5.1 公式

```
P(H|E) = P(E|H) · P(H) / P(E)

其中：
  P(H)     = 先验概率（prior）——看到证据前的信念
  P(E|H)   = 似然（likelihood）——假设下证据出现的概率
  P(H|E)   = 后验概率（posterior）——看到证据后更新的信念
  P(E)     = 边缘似然（evidence）——归一化因子
```

### 5.2 经典例题：疾病检测

```
已知某疾病发病率 P(D)=0.01
检测灵敏度 P(+|D)=0.95
检测特异性 P(-|¬D)=0.90

问：检测为阳性时，真正患病的概率？

解：
P(+|D)=0.95, P(+|¬D)=1-0.90=0.10
P(D|+) = P(+|D)·P(D) / P(+)
       = P(+|D)·P(D) / (P(+|D)·P(D) + P(+|¬D)·P(¬D))
       = 0.95×0.01 / (0.95×0.01 + 0.10×0.99)
       = 0.0095 / 0.1085 ≈ 0.0876

→ 即使检测为阳性，真正患病的概率也只有 8.76%！
```

### 5.3 朴素贝叶斯分类器

**假设：** 给定类别下，各特征条件独立。

```
P(Cₖ|x₁,...,xₙ) ∝ P(Cₖ) · ∏ᵢ P(xᵢ|Cₖ)
```

**优点：** 简单、计算快、对小数据表现好
**应用：** 垃圾邮件分类、文本情感分析

## 6. 统计推断基础

### 6.1 点估计

**矩估计：** 用样本矩替代总体矩

**最大似然估计（MLE）：** 选择使观察数据出现概率最大的参数
```
θ̂_MLE = argmax_θ  ∏ᵢ f(xᵢ|θ)
```

**MLE 在机器学习中：** 交叉熵损失等价于分类问题中的最大似然估计。

### 6.2 假设检验

**基本步骤：**
1. 建立 H₀（原假设）和 H₁（备择假设）
2. 选择检验统计量
3. 计算 p 值（在原假设下，观测到当前或更极端结果的概率）
4. 若 p < α（显著性水平，通常 0.05），拒绝 H₀

**两类错误：**
| | H₀ 为真 | H₀ 为假 |
|------|---------|---------|
| 拒绝 H₀ | **第一类错误（α）** | 正确（统计功效 1-β） |
| 不拒绝 H₀ | 正确 | **第二类错误（β）** |

### 6.3 A/B 测试

**后端开发中的常见场景：**
- UI 变更对转化率的影响
- 推荐算法版本对比
- 缓存策略效果评估

```java
// A/B 测试的简单 Z 检验计算（独立双样本比例检验）
double zTest(double p1, int n1, double p2, int n2) {
    double pPool = (p1 * n1 + p2 * n2) / (n1 + n2);
    double se = Math.sqrt(pPool * (1 - pPool) * (1.0 / n1 + 1.0 / n2));
    return (p1 - p2) / se;  // |Z| > 1.96 表示 p < 0.05
}
```

## 7. AI 与后端开发关联

### 7.1 机器学习中的概率分布

| 模型 | 概率基础 |
|------|----------|
| 逻辑回归 | 伯努利分布 + 最大似然 |
| 朴素贝叶斯 | 贝叶斯定理 + 条件独立假设 |
| 高斯混合模型（GMM） | 多个正态分布的组合 |
| VAE | 高斯分布隐变量 + KL 散度 |
| 扩散模型（Diffusion） | 逐步加噪（前向过程）和去噪（反向过程） |
| LLM（GPT 等） | 输出是下一个 token 的**概率分布** |

### 7.2 概率在 LLM 中的体现

```
LLM 的输出本质：
P(token_t | token₁, token₂, ..., token_{t-1})

每个时间步，模型输出词汇表上的概率分布，
通过温度参数（temperature）控制分布的"尖锐程度"：
  temperature → 0：退化为贪心解码（确定性）
  temperature → 1：原始分布
  temperature → ∞：均匀分布（随机输出）
```

### 7.3 KL 散度与交叉熵

**信息量：** I(x) = -log₂ P(x)（事件越罕见，信息量越大）

**熵：** H(P) = -Σ P(x) log₂ P(x)（概率分布的不确定性）

**KL 散度：** D_{KL}(P||Q) = Σ P(x) log(P(x)/Q(x))
→ 用 Q 分布近似 P 分布时损失的"信息量"
→ 非负，非对称

**交叉熵：** H(P,Q) = H(P) + D_{KL}(P||Q) = -Σ P(x) log Q(x)
→ 深度学习中的交叉熵损失函数

### 7.4 后端监控中的统计应用

```java
// 使用 Apache Commons Math 进行统计计算
DescriptiveStatistics stats = new DescriptiveStatistics();
stats.addValue(responseTime);
double mean   = stats.getMean();
double stdDev = stats.getStandardDeviation();
double p95    = stats.getPercentile(95);
double p99    = stats.getPercentile(99);

// 计算置信区间（95%）
double margin = 1.96 * stdDev / Math.sqrt(stats.getN());
double ci_L = mean - margin;
double ci_U = mean + margin;
```
