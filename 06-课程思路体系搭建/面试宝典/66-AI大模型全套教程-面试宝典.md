## 一、基础概念速答（15题）

### Q1: 什么是大语言模型（LLM）？它与传统AI模型有什么区别？
> 大语言模型（Large Language Model, LLM）是基于Transformer架构，在海量文本数据上预训练得到的深度学习模型，能够理解和生成自然语言。

| 对比维度 | 传统AI模型 | 大语言模型 |
|---------|-----------|-----------|
| 训练数据规模 | MB~GB级，领域标注数据 | TB级，互联网大规模文本 |
| 模型参数量 | 百万~千万级 | 十亿~万亿级 |
| 任务适应性 | 单一任务，需重新训练 | 多任务通用，零样本/少样本学习 |
| 核心能力 | 模式匹配 | 涌现能力：推理、规划、代码生成 |
| 部署方式 | 轻量级，可边缘部署 | 需GPU集群，云端部署 |

### Q2: 提示词工程（Prompt Engineering）的核心原则有哪些？
- **明确性（Clarity）**：用具体、无歧义的语言描述任务
- **上下文（Context）**：提供足够的背景信息
- **格式约束（Format Constraint）**：指定输出格式（JSON、Markdown等）
- **角色设定（Role Prompting）**：给模型赋予专业角色
- **示例引导（Few-shot）**：提供输入输出示例
- **分步推理（Chain-of-Thought）**：引导模型逐步思考

### Q3: 什么是Agent？Agent的核心架构包含哪些要素？
**Agent = LLM + 记忆（Memory）+ 规划（Planning）+ 工具调用（Tool Use）**

核心要素：
| 要素 | 说明 | 典型实现 |
|------|------|---------|
| **LLM Brain** | 核心推理引擎 | GPT-4, Claude, Qwen |
| **记忆（Memory）** | 短期/长期记忆存储 | ChromaDB, Redis, Buffer |
| **规划（Planning）** | 任务分解与推理 | CoT, ReAct, Plan-and-Execute |
| **工具调用（Tool Use）** | 调用外部API/工具 | Function Calling, MCP协议 |
| **反馈循环（Feedback）** | 自我反思与修正 | Self-Ask, Reflection机制 |

### Q4: RAG的基本运行流程是什么？
> 阿里巴巴常考题：请简述RAG的工作流程。

1. **索引（Indexing）**：文档 -> 分块（Chunking） -> Embedding -> 向量库
2. **检索（Retrieval）**：用户Query -> Embedding -> 向量相似度检索 -> Top-K结果
3. **重排（Reranking）**：对检索结果进行精细排序，提升相关性
4. **生成（Generation）**：Query + 检索上下文 -> LLM -> 答案

### Q5: LangChain的核心组件有哪些？
| 组件 | 功能 | 类比 |
|------|------|------|
| **Model I/O** | LLM调用封装 | JDBC驱动 |
| **Retrieval** | 文档加载、向量存储、检索 | 数据访问层 |
| **Chain** | 任务执行链 | 工作流管道 |
| **Agent** | 智能体决策循环 | 自动驾驶决策 |
| **Memory** | 对话/状态记忆 | Session存储 |
| **Callbacks** | 日志、监控、追踪 | AOP切面 |

### Q6: LangGraph和LangChain是什么关系？
**LangGraph** 是基于 LangChain 构建的有状态图框架，专门用于编排多步骤、有循环的工作流。LangChain擅长线性的Chain，而LangGraph擅长带条件分支、循环、多Agent协作的复杂工作流。

### Q7: 什么是LCEL（LangChain Expression Language）？
LCEL是LangChain的声明式表达式语言，通过 `|` 管道符组合组件：

```python
# LCEL 声明式链
chain = prompt | model | output_parser

# 等价于命令式代码
result = output_parser.parse(model.invoke(prompt.format(query="hello")))
```

优势：自动支持流式输出、并行执行、重试、追踪。

### Q8: 什么是Embedding？常见的中文Embedding模型有哪些？
Embedding是将文本映射到稠密向量空间的技术，语义相近的文本在向量空间中距离更近。

中文Embedding模型：
| 模型 | 维度 | 特点 | 适用场景 |
|------|------|------|---------|
| **BAAI/bge-large-zh** | 1024 | 中文效果领先，MTEB排名高 | 通用RAG |
| **moka-ai/m3e-base** | 768 | 轻量级，速度较快 | 中小规模系统 |
| **text-embedding-3-small** | 1536 | OpenAI出品，多语言 | 国际化场景 |
| **text2vec-base-chinese** | 768 | 中文专项优化 | 中文文档检索 |

### Q9: 什么是重排序（Reranking）？为什么需要它？
检索阶段用轻量级向量相似度快速召回候选，重排序用更精细的Cross-Encoder模型对Top-K结果重新打分。目的是弥补向量检索的精度不足，显著提升最终答案质量。

### Q10: 微调（Fine-tuning）和RAG有什么区别？
| 维度 | RAG | 微调 |
|------|-----|------|
| 知识更新 | 实时更新，替换文档即可 | 需重新训练模型 |
| 幻觉风险 | 低（从文档中检索） | 较高（模型记忆） |
| 长尾知识 | 适合私有/低频知识 | 适合高频/模式化知识 |
| 推理能力 | 不改变模型 | 可优化模型输出格式/风格 |
| 成本 | 需部署向量数据库 | 需GPU训练，成本高 |

### Q11: 什么是Function Calling？
> 百度常考题：Function Calling的实现原理。

Function Calling让LLM能够识别何时需要调用外部函数，并返回结构化的函数调用参数。工作原理：
1. 开发者定义函数Schema（名称、参数、描述）
2. LLM根据用户意图决定是否调用及填充参数
3. 应用侧执行函数并返回结果
4. LLM基于结果生成最终回复

## 二、深度原理剖析（12题）

### Q16: Agent核心架构详解（Planing/Memory/Tool Use）
> 字节跳动常考题：请详细描述Agent的核心架构设计。

**1. Planning（规划层）**
- **任务分解**：将复杂任务拆解为子任务（CoT方式）
- **推理框架**：ReAct（Reason+Act）、Plan-and-Execute、Self-Ask
- **决策机制**：LLM根据当前状态选择下一步动作

**2. Memory（记忆层）**
```
短期记忆（Short-term）: 对话上下文窗口内的信息
   ├── Buffer Memory: 滑动窗口保留最近N轮
   ├── Summary Memory: 对历史进行摘要压缩
   └── Token Memory: 控制总Token数
长期记忆（Long-term）: 跨会话持久化存储
   ├── Vector Memory: 向量数据库语义检索
   ├── Key-Value Memory: 结构化键值存储
   └── Entity Memory: 实体信息提取与存储
```

**3. Tool Use（工具层）**
- Function Calling机制
- 工具注册与Schema定义
- 执行结果反馈与错误处理
- MCP（Model Context Protocol）统一协议

### Q17: ReAct循环的完整工作流程
> 腾讯常考题：请画出ReAct的工作流程。

```
循环过程：
Thought（思考） -> Action（行动） -> Observation（观察） -> Thought -> ...
```

```python
import json
from openai import OpenAI

def react_loop(query, tools, max_steps=5):
    """手写ReAct循环核心逻辑"""
    client = OpenAI()
    messages = [
        {"role": "system", "content": "你是一个AI助手，请逐步推理并选择工具。"},
        {"role": "user", "content": query}
    ]

    for step in range(max_steps):
        # Step 1: LLM 思考并决定行动
        response = client.chat.completions.create(
            model="gpt-4",
            messages=messages,
            tools=tools,
            tool_choice="auto"
        )
        msg = response.choices[0].message
        messages.append(msg)

        # Step 2: 检查是否直接回答
        if not msg.tool_calls:
            return msg.content

        # Step 3: 执行工具调用
        for tool_call in msg.tool_calls:
            func_name = tool_call.function.name
            args = json.loads(tool_call.function.arguments)
            result = execute_tool(func_name, args)

            # Step 4: 反馈观察结果
            messages.append({
                "role": "tool",
                "tool_call_id": tool_call.id,
                "content": json.dumps(result)
            })

    return "已达到最大步骤限制"
```

**面试要点**：ReAct的关键创新在于将推理轨迹（Thought）和行动（Action）交错进行，让模型能够"边思考边行动"，而不是一次性地生成完整计划。

### Q18: RAG全链路深度解析——Chunking策略对比
| 策略 | 方法 | 优点 | 缺点 |
|------|------|------|------|
| **Fixed Size** | 固定字符数+重叠 | 实现简单，速度快 | 可能截断语义 |
| **Recursive** | 按分隔符层级切分(\n\n -> \n -> .) | 保留语义边界 | 块大小不均匀 |
| **Semantic** | 用Embedding检测语义转折点 | 语义完整性最好 | 计算开销大 |
| **Document Specific** | 按文档结构(标题/段落) | 保留文档结构 | 通用性差 |

推荐策略：**RecursiveCharacterTextSplitter** 是最通用的方案，兼顾语义完整性和实现简易度。

### Q21: LangChain底层架构——Runnable协议与LCEL设计原理
所有LangChain组件都实现了 `Runnable` 接口：

```python
class Runnable(Generic[Input, Output]):
    async def invoke(self, input: Input) -> Output: ...
    async def stream(self, input: Input) -> Iterator[Output]: ...
    async def batch(self, inputs: List[Input]) -> List[Output]: ...

    def __or__(self, other: Runnable) -> RunnableSequence:
        """| 操作符实现链式组合"""
        return RunnableSequence(first=self, second=other)

    def pipe(self, *others) -> RunnableSequence: ...
```

**LCEL的三大设计优势：**
1. **统一接口**：所有组件（Model/Chain/Retriever）都遵循相同协议
2. **自动并行**：`batch()`自动并行处理，`map()` 分布式映射
3. **可组合性**：`|` 操作符让管道式编程成为可能

### Q22: LangGraph有状态图执行机制
> 华为常考题：LangGraph的工作机制和状态管理。

```python
from langgraph.graph import StateGraph, END
from typing import TypedDict, List

# 定义状态类型
class AgentState(TypedDict):
    messages: List[dict]
    next_agent: str
    shared_context: dict

# 构建状态图
workflow = StateGraph(AgentState)

# 节点 = 处理函数
workflow.add_node("agent_1", agent_1_func)
workflow.add_node("agent_2", agent_2_func)
workflow.add_node("router", router_func)

# 边 = 状态转移
workflow.add_edge("agent_1", "router")
workflow.add_conditional_edges(
    "router",
    lambda state: state["next_agent"],
    {"agent_2": "agent_2", "end": END}
)

app = workflow.compile()
```

**核心概念：**
- **StateGraph**：有状态图，节点间传递共享状态
- **MessageGraph**：简化版，仅传递消息列表
- **节点（Node）**：处理函数，接收状态 -> 返回更新
- **边（Edge）**：状态转移路径
- **条件边（Conditional Edge）**：根据状态动态选择路径

### Q23: 模型训练全流程：Pre-training -> SFT -> RLHF
```
┌─────────────────────────────────────────┐
│ Pre-training（预训练）                      │
│ 目标：学习语言知识                           │
│ 数据：海量互联网文本（TB级）                   │
│ 方法：Next Token Prediction                │
│ 产物：Base Model                           │
├─────────────────────────────────────────┤
│ SFT（监督微调）                              │
│ 目标：对齐指令理解能力                        │
│ 数据：人工标注的指令-回复对                   │
│ 方法：Cross-Entropy Loss                   │
│ 产物：Instruction-tuned Model              │
├─────────────────────────────────────────┤
│ RLHF（基于人类反馈的强化学习）                   │
│ 目标：对齐人类偏好                            │
│ ├── Reward Model 训练                       │
│ └── PPO/DPO 策略优化                        │
│ 产物：Align Model（如 GPT-4, Claude）        │
└─────────────────────────────────────────┘
```

**PPO vs DPO对比：**
| 维度 | PPO | DPO |
|------|-----|-----|
| 需要Reward Model | 是 | 否 |
| 训练复杂度 | 高（4个模型） | 低（2个模型） |
| 稳定性 | 需精细调参 | 更稳定 |
| 效果 | 上限更高 | 接近PPO |
| 适用场景 | 大厂资源充足 | 中小团队 |

### Q24: Transformer结构详解——Encoder-Decoder vs Decoder-only
| 架构 | 代表模型 | 特点 | 适用场景 |
|------|---------|------|---------|
| **Encoder-Decoder** | T5, BART | 双向注意力+自回归解码 | 翻译、摘要、文本生成 |
| **Encoder-only** | BERT | 双向注意力 | 分类、NER、语义理解 |
| **Decoder-only** | GPT系列, LLaMA, Qwen | 因果注意力（只关注左侧） | 对话、代码生成、通用 |

目前主流大模型几乎全部采用 **Decoder-only** 架构，优势：
- 训练效率高（可并行计算）
- 推理自回归，天然适合生成任务
- 扩展性好（如MoE、Multi-Query Attention）

### Q28: Gradio快速构建大模型交互Demo
```python
import gradio as gr
from openai import OpenAI

client = OpenAI()

def chat_with_model(message, history):
    """构建大模型对话接口"""
    messages = [{"role": "system", "content": "你是一个AI助手。"}]
    for user_msg, ai_msg in history:
        messages.append({"role": "user", "content": user_msg})
        messages.append({"role": "assistant", "content": ai_msg})
    messages.append({"role": "user", "content": message})

    response = client.chat.completions.create(
        model="gpt-4",
        messages=messages,
        stream=True
    )

    full_response = ""
    for chunk in response:
        if chunk.choices[0].delta.content:
            full_response += chunk.choices[0].delta.content
            yield full_response

demo = gr.ChatInterface(
    chat_with_model,
    title="AI对话助手",
    description="基于GPT-4构建的智能对话系统",
    theme="soft"
)

if __name__ == "__main__":
    demo.launch(server_name="0.0.0.0", server_port=7860)
```

### Q29: 使用LangChain构建智能客服Agent（带Tavily搜索）
```python
from langchain.agents import AgentExecutor, create_openai_tools_agent
from langchain_openai import ChatOpenAI
from langchain.tools import Tool
from langchain_community.tools.tavily_search import TavilySearchResults
from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder

# 1. 初始化工具
search = TavilySearchResults(max_results=3)

tools = [
    Tool(
        name="知识库查询",
        func=lambda q: f"知识库命中结果: {q}",
        description="查询企业内部知识库，输入问题返回相关文档"
    ),
    search
]

# 2. 构建Prompt
prompt = ChatPromptTemplate.from_messages([
    ("system", "你是企业智能客服助手。先用知识库查询，不足时用Tavily搜索。"),
    MessagesPlaceholder(variable_name="chat_history"),
    ("human", "{input}"),
    MessagesPlaceholder(variable_name="agent_scratchpad"),
])

# 3. 创建Agent
llm = ChatOpenAI(model="gpt-4", temperature=0)
agent = create_openai_tools_agent(llm, tools, prompt)
agent_executor = AgentExecutor(
    agent=agent,
    tools=tools,
    verbose=True,
    max_iterations=5,
    handle_parsing_errors=True
)

# 4. 执行
result = agent_executor.invoke({
    "input": "我们公司的退款政策是什么？最近有什么相关新闻？",
    "chat_history": []
})
print(result["output"])
```

### Q30: ReAct+RAG智能体构建
```python

        self.llm = llm
```

### Q37: 手写Embedding向量化流程

```python
import numpy as np
from typing import List
from openai import OpenAI

class EmbeddingService:
    """手写Embedding向量化服务"""

    def __init__(self, model: str = "text-embedding-3-small"):
        self.client = OpenAI()
        self.model = model

    def embed_text(self, text: str) -> List[float]:
        """单条文本向量化"""
        response = self.client.embeddings.create(
            model=self.model,
            input=text
        )
        return response.data[0].embedding

    def embed_batch(self, texts: List[str], batch_size: int = 16) -> List[List[float]]:
        """批量文本向量化"""
        all_embeddings = []
        for i in range(0, len(texts), batch_size):
            batch = texts[i:i + batch_size]
            response = self.client.embeddings.create(
                model=self.model,
                input=batch
            )
            # 按原始顺序返回
            sorted_data = sorted(response.data, key=lambda x: x.index)
            all_embeddings.extend([d.embedding for d in sorted_data])
        return all_embeddings

    @staticmethod
    def cosine_similarity(vec1: List[float], vec2: List[float]) -> float:
        """计算余弦相似度"""
        v1 = np.array(vec1)
        v2 = np.array(vec2)
        dot_product = np.dot(v1, v2)
        norm = np.linalg.norm(v1) * np.linalg.norm(v2)
        return float(dot_product / norm) if norm != 0 else 0.0

    def search(self, query: str, documents: List[str], top_k: int = 3) -> List[tuple]:
        """语义搜索：查询文本在文档集合中检索"""
        query_vec = self.embed_text(query)
        doc_vecs = self.embed_batch(documents)

        scores = []
        for i, doc_vec in enumerate(doc_vecs):
            score = self.cosine_similarity(query_vec, doc_vec)
            scores.append((score, documents[i]))

        scores.sort(reverse=True, key=lambda x: x[0])
        return scores[:top_k]
```

### Q38: 手写RAG分块器
```python
from typing import List, Dict, Optional
import re

class TextChunker:
    """手写RAG文本分块器"""

    def __init__(
        self,
        chunk_size: int = 500,
        chunk_overlap: int = 50,
        separators: List[str] = None
    ):
        self.chunk_size = chunk_size
        self.chunk_overlap = chunk_overlap
        self.separators = separators or ["\n\n", "\n", "。", ".", "，", " "]

    def split_text(self, text: str) -> List[str]:
        """将文本分块"""
        chunks = []

        def _split(text: str, separators: List[str]) -> List[str]:
            """递归分块"""
            if len(text) <= self.chunk_size:
                return [text] if text.strip() else []

            if not separators:
                # 没有分隔符时，强行按字符数切分
                results = []
                for i in range(0, len(text), self.chunk_size - self.chunk_overlap):
                    chunk = text[i:i + self.chunk_size]
                    results.append(chunk)
                return results

            sep = separators[0]
            parts = re.split(f"({re.escape(sep)})", text)

            result = []
            current = ""
            for part in parts:
                if len(current) + len(part) <= self.chunk_size:
                    current += part
                else:
                    if current:
                        result.append(current.strip())
                    current = part

            if current:
                result.append(current.strip())

            # 如果部分块仍然太大，递归使用更细的分隔符
            final = []
            for chunk in result:
                if len(chunk) > self.chunk_size:
                    final.extend(_split(chunk, separators[1:]))
                else:
                    final.append(chunk)

            return final

        raw_chunks = _split(text, self.separators)

        # 添加重叠
        if not raw_chunks:
            return []

        chunks = [raw_chunks[0]]
        for i in range(1, len(raw_chunks)):
            prev = chunks[-1]
            overlap = prev[-self.chunk_overlap:] if self.chunk_overlap > 0 else ""
            chunks.append(overlap + raw_chunks[i])

        return chunks

    def split_documents(self, docs: List[Dict[str, str]]) -> List[Dict]:
        """分块文档列表"""
        all_chunks = []
        for doc in docs:
            chunks = self.split_text(doc["content"])
            for i, chunk in enumerate(chunks):
                all_chunks.append({
                    "content": chunk,
                    "metadata": {
                        **doc.get("metadata", {}),
                        "chunk_index": i,
                        "total_chunks": len(chunks)
                    }
                })
        return all_chunks
```

```python
class ReActAgent:
    """手写ReAct Agent循环"""

    def __init__(self, system_prompt: str, tools: List[Dict], max_steps: int = 10):
        self.client = OpenAI()
        self.system_prompt = system_prompt

                result = func(**args)
                return json.dumps(result, ensure_ascii=False)
            except Exception as e:
                return json.dumps({"error": str(e)})
        return json.dumps({"error": f"未知工具: {name}"})

    def run(self, user_input: str) -> str:
        """执行ReAct循环"""
        messages = [
            {"role": "system", "content": self.system_prompt},
            {"role": "user", "content": user_input}
        ]

        for step in range(self.max_steps):
            print(f"\n--- Step {step + 1} ---")

            response = self.client.chat.completions.create(
                model="gpt-4",
                messages=messages,
                tools=self.tools,
                tool_choice="auto",
                temperature=0
            )

            msg = response.choices[0].message
            messages.append(msg)

            # 打印思考过程
            if msg.content:
                print(f"Thought: {msg.content[:200]}...")
            else:
                print(f"Thought: (模型选择调用工具)")

            # 检查是否已给出最终答案
            if not msg.tool_calls:
                self.memory.append({"user": user_input, "assistant": msg.content})
                return msg.content

            # 执行工具调用
            for tool_call in msg.tool_calls:
                func_name = tool_call.function.name
                func_args = json.loads(tool_call.function.arguments)
                print(f"Action: {func_name}({func_args})")

                observation = self.execute_tool(func_name, func_args)
                print(f"Observation: {observation[:200]}...")

                messages.append({
                    "role": "tool",
                    "tool_call_id": tool_call.id,
                    "content": observation
                })

        return "已达到最大执行步数"
```

```python
import numpy as np
import math

class MultiHeadAttention:
    """手写Multi-Head Self Attention"""

    def __init__(self, d_model: int, num_heads: int):
        assert d_model % num_heads == 0, "d_model必须能被num_heads整除"
        self.d_model = d_model
        self.num_heads = num_heads
        self.d_k = d_model // num_heads  # 每个头的维度

        # 初始化权重矩阵
        self.W_q = np.random.randn(d_model, d_model) * 0.01
        self.W_k = np.random.randn(d_model, d_model) * 0.01
        self.W_v = np.random.randn(d_model, d_model) * 0.01
        self.W_o = np.random.randn(d_model, d_model) * 0.01

    def split_heads(self, x: np.ndarray) -> np.ndarray:
        """将最后一维拆分为 (num_heads, d_k)"""
        batch_size, seq_len, _ = x.shape
        x = x.reshape(batch_size, seq_len, self.num_heads, self.d_k)
        return x.transpose(0, 2, 1, 3)  # (batch, heads, seq, d_k)

    def scaled_dot_product_attention(
        self, Q: np.ndarray, K: np.ndarray, V: np.ndarray,
        mask: np.ndarray = None
    ) -> tuple:
        """缩放点积注意力"""
        # Q, K, V: (batch, heads, seq, d_k)
        scores = np.matmul(Q, K.transpose(0, 1, 3, 2))  # (batch, heads, seq, seq)
        scores = scores / math.sqrt(self.d_k)

        if mask is not None:
            scores = np.where(mask == 0, -1e9, scores)

        attention_weights = np.exp(scores - np.max(scores, axis=-1, keepdims=True))
        attention_weights = attention_weights / np.sum(attention_weights, axis=-1, keepdims=True)

        output = np.matmul(attention_weights, V)  # (batch, heads, seq, d_k)
        return output, attention_weights

    def forward(self, x: np.ndarray, mask: np.ndarray = None) -> np.ndarray:
        """
        前向传播
        x: (batch_size, seq_len, d_model)
        返回: (batch_size, seq_len, d_model)
        """
        batch_size = x.shape[0]

        # 1. 线性变换
        Q = x @ self.W_q  # (batch, seq, d_model)
        K = x @ self.W_k
        V = x @ self.W_v

        # 2. 分头
        Q = self.split_heads(Q)  # (batch, heads, seq, d_k)
        K = self.split_heads(K)
        V = self.split_heads(V)

        # 3. 注意力计算
        attn_output, weights = self.scaled_dot_product_attention(Q, K, V, mask)

        # 4. 合并头
        attn_output = attn_output.transpose(0, 2, 1, 3)  # (batch, seq, heads, d_k)
        attn_output = attn_output.reshape(batch_size, -1, self.d_model)

        # 5. 输出投影
        output = attn_output @ self.W_o

        return output
```

```python
        missing = [v for v in self.input_variables if v not in kwargs]

            if placeholder in new_template:
                new_template = new_template.replace(placeholder, str(value))
                remaining_vars.remove(key)

        return PromptTemplate(new_template, remaining_vars)

    def from_messages(cls, messages: List[tuple]):
        """从元组列表创建 [(role, content), ...]"""

            for role, content in messages
```

```python
from typing import List, Dict, Optional, Any
from datetime import datetime
from collections import deque
import json

class Memory:
    """基础记忆类"""

    def __init__(self, memory_key: str = "history"):
        self.memory_key = memory_key

class BufferMemory(Memory):
    """滑动窗口记忆：保留最近N轮对话"""

    def __init__(self, max_rounds: int = 5):
        super().__init__()
        self.max_rounds = max_rounds
        self.buffer: deque = deque(maxlen=max_rounds)

    def add(self, user_input: str, ai_output: str):
        self.buffer.append({
            "user": user_input,
            "assistant": ai_output,
            "timestamp": datetime.now().isoformat()
        })

    def load_memory(self) -> List[Dict]:
        return list(self.buffer)

    def clear(self):
        self.buffer.clear()


class SummaryMemory(Memory):
    """摘要记忆：对历史对话进行摘要压缩"""

    def __init__(self, max_tokens: int = 500):
        super().__init__()
        self.max_tokens = max_tokens
        self.history: List[Dict] = []
        self.summary: Optional[str] = None

    def add(self, user_input: str, ai_output: str):
        self.history.append({
            "user": user_input,
            "assistant": ai_output,
            "timestamp": datetime.now().isoformat()
        })

    def summarize(self, llm_func: Callable) -> str:
        """调用LLM生成对话摘要"""
        recent = self.history[-3:]  # 最近3轮
        conversation = "\n".join([
            f"User: {m['user']}\nAI: {m['assistant']}"
            for m in recent
        ])

        prompt = f"""请对以下对话进行摘要，保留关键信息：
{conversation}

之前的摘要: {self.summary or '无'}
摘要:"""

        self.summary = llm_func(prompt)
        return self.summary

    def load_memory(self) -> Dict:
        return {
            "summary": self.summary,
            "recent_history": self.history[-3:] if self.history else []
        }


class VectorMemory(Memory):
    """向量记忆：通过语义检索长期记忆"""

    def __init__(self, embedding_func: Callable):
        super().__init__()
        self.memories: List[Dict] = []
        self.embeddings: List[List[float]] = []
        self.embedding_func = embedding_func

    def add(self, key: str, content: str, metadata: Dict = None):
        vector = self.embedding_func(content)
        self.memories.append({
            "key": key,
            "content": content,
            "metadata": metadata or {},
            "timestamp": datetime.now().isoformat(),
            "vector": vector
        })
        self.embeddings.append(vector)

    def search(self, query: str, top_k: int = 3) -> List[Dict]:
        """语义检索记忆"""
        query_vec = self.embedding_func(query)

        # 余弦相似度计算
        def cosine_sim(v1, v2):
            dot = sum(a * b for a, b in zip(v1, v2))
            norm1 = sum(a * a for a in v1) ** 0.5
            norm2 = sum(b * b for b in v2) ** 0.5
            return dot / (norm1 * norm2) if norm1 * norm2 > 0 else 0

        scored = []
        for i, mem in enumerate(self.memories):
            score = cosine_sim(query_vec, mem["vector"])
            scored.append((score, mem))

        scored.sort(reverse=True, key=lambda x: x[0])
        return [
            {**mem, "score": score}
            for score, mem in scored[:top_k]
        ]


class ConversationSummaryBufferMemory(Memory):
    """最常用的组合记忆：滑动窗口+摘要"""

    def __init__(
        self,
        max_rounds: int = 10,
        llm_func: Optional[Callable] = None
    ):
        super().__init__()
        self.buffer = BufferMemory(max_rounds=max_rounds)
        self.summary_memory = SummaryMemory()
        self.llm_func = llm_func or (lambda x: x)

    def add(self, user_input: str, ai_output: str):
        self.buffer.add(user_input, ai_output)
        self.summary_memory.add(user_input, ai_output)

        # 当到期时压缩
        if len(self.buffer.buffer) >= self.buffer.max_rounds:
            self.summary_memory.summarize(self.llm_func)
            # 只保留最近2轮
            recent = list(self.buffer.buffer)[-2:]
            self.buffer.buffer = deque(recent, maxlen=self.buffer.max_rounds)

    def load_memory(self) -> Dict:
        return {
            "recent": self.buffer.load_memory(),
            "summary": self.summary_memory.summary
        }

    def clear(self):
        self.buffer.clear()
        self.summary_memory = SummaryMemory()
```

```python
└──────────────────────────────────────────────┘
```

```python
# 核心流程实现
class AISearchEngine:
    """AI搜索引擎核心实现"""

    def __init__(self):
        self.query_rewriter = QueryRewriter()
        self.intent_classifier = IntentClassifier()
        self.sparse_retriever = ElasticSearchRetriever()
        self.dense_retriever = VectorRetriever()
        self.reranker = Reranker()
        self.summarizer = LLMSummarizer()

    async def search(self, query: str, user_context: dict = None):
        # 1. Query理解与改写
        rewritten_queries = self.query_rewriter.rewrite(query)
        intent = self.intent_classifier.classify(query)

        # 2. 多路检索
        sparse_results = await self.sparse_retriever.search(rewritten_queries)
        dense_results = await self.dense_retriever.search(rewritten_queries)

        # 3. 混合排序（RRF算法）
        fused_results = self.reciprocal_rank_fusion(
            sparse_results, dense_results
        )

        # 4. 重排序
        reranked = self.reranker.rerank(query, fused_results[:50])

        # 5. 生成回答
        answer = await self.summarizer.generate(
            query=query,
            contexts=reranked[:10],
            intent=intent
        )

        # 6. 返回结果
        return {
            "answer": answer,
            "sources": reranked[:10],
            "suggested_queries": self.generate_suggestions(query),
            "related_topics": self.extract_related_topics(reranked)
        }

    @staticmethod
    def reciprocal_rank_fusion(
        lists: List[List[Dict]], k: int = 60
    ) -> List[Dict]:
        """RRF混合排序"""
        scores = {}
        for rank_list in lists:
            for rank, doc in enumerate(rank_list):
                doc_id = doc["id"]
                if doc_id not in scores:
                    scores[doc_id] = {
                        "doc": doc,
                        "score": 0
                    }
                scores[doc_id]["score"] += 1.0 / (k + rank + 1)

        return sorted(
            scores.values(),
            key=lambda x: x["score"],
            reverse=True
        )
```

```python
│  │题库    │ │面试记录│ │人才库  │ │反馈库│ │
│  └────────┘ └────────┘ └────────┘ └──────┘ │
└─────────────────────────────────────────────┘
"""

# 核心实现
class InterviewSystem:
    """智能面试系统"""

    def __init__(self):
        self.llm = ChatOpenAI(model="gpt-4")
        self.question_bank = QuestionBank()
        self.evaluator = AnswerEvaluator()
        self.router = InterviewRouter()

    async def generate_interview(
        self, jd: str, resume: str, difficulty: str = "medium"
    ):
        """根据JD和简历生成个性化面试"""
        # 解析JD和简历
        skills = await self.extract_skills(jd)
        candidate_info = await self.parse_resume(resume)

        # 生成面试流程
        interview_plan = await self.router.create_plan(
            skills=skills,
            experience=candidate_info["years"],
            difficulty=difficulty
        )

        return interview_plan

    async def conduct_round(
        self, round_type: str, context: Dict
    ) -> Dict:
        """执行一轮面试"""
        # 生成问题
        questions = await self.question_bank.generate_questions(
            round_type=round_type,
            skills=context["skills"],
            previous_answers=context.get("answers", [])
        )

        results = []
        for question in questions:
            # 模拟候选人回答（实际系统中为人工输入）
            answer = context.get("answer", "")

            # 评估回答
            evaluation = await self.evaluator.evaluate(
                question=question,
                answer=answer,
                skills=context["skills"]
            )

            # 生成追问
            follow_up = await self.generate_follow_up(
                question, answer, evaluation
            )

            results.append({
                "question": question,
                "answer": answer,
                "score": evaluation["score"],
                "strengths": evaluation["strengths"],
                "weaknesses": evaluation["weaknesses"],
                "follow_up": follow_up
            })

        # 综合评分
        summary = await self.evaluator.summarize_results(results)

        return {"questions": results, "summary": summary}

    async def evaluate_answer(
        self, question: str, answer: str, expected_skills: List[str]
    ):
        """评估回答质量"""
        prompt = f"""
        问题: {question}
        候选人回答: {answer}
        期望考察技能: {', '.join(expected_skills)}

        请评估:
        1. 技术正确性 (0-100)
        2. 完整性 (0-100)
        3. 沟通表达 (0-100)
        4. 深度理解 (0-100)
        5. 具体评分理由
        6. 改进建议
        """
        response = await self.llm.ainvoke(prompt)
        return self.parse_evaluation(response.content)
```

### Q46: 设计多Agent协作的企业智能助手平台
> 华为常考题：设计一个多Agent协作的企业级平台。

```python
"""
多Agent协作平台设计

┌────────────────────────────────────────────────────────┐
│                      统一入口                           │
│          Web Portal  |  钉钉/飞书  |  API  |  App       │
├────────────────────────────────────────────────────────┤
│                   编排调度层                             │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐ │
│  │任务分解器 │ │Agent选择器│ │状态管理器│ │结果汇总器│ │
│  └──────────┘ └──────────┘ └──────────┘ └──────────┘ │
├────────────────────────────────────────────────────────┤
│                    Agent执行层                           │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐ │
│  │客服Agent │ │销售Agent │ │数据分析  │ │审批Agent │ │
│  └──────────┘ └──────────┘ └──────────┘ └──────────┘ │
├────────────────────────────────────────────────────────┤
│                   共享能力层                             │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐ │
│  │知识库RAG  │ │Function  │ │记忆服务  │ │权限服务  │ │
│  └──────────┘ └──────────┘ └──────────┘ └──────────┘ │
├────────────────────────────────────────────────────────┤
│                   基础设施层                             │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐ │
│  │LLM集群   │ │消息队列  │ │数据库    │ │监控告警  │ │
│  └──────────┘ └──────────┘ └──────────┘ └──────────┘ │
└────────────────────────────────────────────────────────┘
"""

from langgraph.graph import StateGraph, END
from typing import TypedDict, List, Optional
from enum import Enum

class AgentRole(Enum):
    CUSTOMER_SERVICE = "customer_service"
    SALES = "sales"
    DATA_ANALYST = "data_analyst"
    APPROVAL = "approval"
    SCHEDULER = "scheduler"

class AgentTask(TypedDict):
    task_id: str
    agent_role: AgentRole
    input: str
    output: Optional[str]
    status: str
    requires_approval: bool
    priority: int

class CollaborationState(TypedDict):
    user_query: str
    user_id: str
    tasks: List[AgentTask]
    current_agent: str
    shared_context: dict
    final_response: str

class EnterpriseAgentPlatform:
    """多Agent协作平台"""

    def __init__(self):
        self.agents = self._register_agents()
        self.workflow = self._build_workflow()

    def _register_agents(self):
        return {
            AgentRole.CUSTOMER_SERVICE: CustomerServiceAgent(),
            AgentRole.SALES: SalesAgent(),
            AgentRole.DATA_ANALYST: DataAnalystAgent(),
            AgentRole.APPROVAL: ApprovalAgent(),
            AgentRole.SCHEDULER: TaskScheduler()
        }

    def _build_workflow(self) -> StateGraph:
        """构建LangGraph工作流"""
        workflow = StateGraph(CollaborationState)

        workflow.add_node("task_planner", self.task_planner)
        workflow.add_node("customer_service", self.customer_service)
        workflow.add_node("sales", self.sales)
        workflow.add_node("data_analyst", self.data_analyst)
        workflow.add_node("approval", self.approval)
        workflow.add_node("result_synthesizer", self.result_synthesizer)

        workflow.set_entry_point("task_planner")

        # 动态路由
        workflow.add_conditional_edges(
            "task_planner",
            self.route_tasks,
            {
                AgentRole.CUSTOMER_SERVICE: "customer_service",
                AgentRole.SALES: "sales",
                AgentRole.DATA_ANALYST: "data_analyst",
                AgentRole.APPROVAL: "approval"
            }
        )

        # 所有Agent完成后汇总
        for agent_role in AgentRole:
            if agent_role != AgentRole.SCHEDULER:
                workflow.add_edge(agent_role.value, "result_synthesizer")

        workflow.add_edge("result_synthesizer", END)

        return workflow.compile()

    def route_tasks(self, state: CollaborationState) -> str:
        """根据任务类型路由到对应Agent"""
        next_task = self._get_next_pending_task(state["tasks"])
        return next_task.agent_role.value if next_task else END

    async def handle_request(self, user_query: str, user_id: str):
        """处理用户请求"""
        state = CollaborationState(
            user_query=user_query,
            user_id=user_id,
            tasks=[],
            current_agent="",
            shared_context={},
            final_response=""
        )
        result = await self.workflow.ainvoke(state)
        return result["final_response"]

    def _get_next_pending_task(self, tasks: List[AgentTask]) -> Optional[AgentTask]:
        """获取下一个待处理任务"""
        pending = [t for t in tasks if t["status"] == "pending"]
        if pending:
            return max(pending, key=lambda t: t["priority"])
        return None
```

### 模板3: "LangChain的LCEL是什么？有什么优势？"
```
LCEL（LangChain Expression Language）是LangChain的声明式链式编程语言。

本质上，它解决了三个问题：
1. 样板代码问题：以前需要手写Chain类，现在用 | 管道符
2. 接口统一问题：所有组件实现Runnable协议，保证invoke/batch/stream一致性
3. 编排复杂问题：自动支持并行、重试、追踪、fallback

最核心的设计是Runnable协议接口：

class Runnable:
    def invoke(self, input) -> Output  # 同步
    async def ainvoke(self, input) -> Output  # 异步
    def stream(self, input) -> Iterator[Output]  # 流式
    def batch(self, inputs) -> List[Output]  # 批处理
    
    def __or__(self, other) -> RunnableSequence  # | 管道

三大优势：
1. 声明式：代码即架构，Pipeline一目了然
2. 可组合：任何实现Runnable的组件都能组合
3. 自动优化：batch自动并行，stream自动流式

例如这个链自动支持流式、重试和追踪：
chain = prompt | model.with_retry() | parser
for chunk in chain.stream({"topic": "AI"}):
    print(chunk)

如果用传统方式写，至少需要50行管理状态的代码。
```

### 模板4: "LangGraph和LangChain是什么关系？什么场景用LangGraph？"
```
LangGraph是基于LangChain构建的有状态图框架。

关系可以这样理解：
- LangChain是基础库：Model I/O、Retrieval、Chain、Agent组件
- LangGraph是编排框架：在LangChain之上，管理有状态、有循环的工作流

LangChain适合：线性流程（A->B->C）、RAG管道
LangGraph适合：带循环的流程、条件分支、多Agent协作

具体场景举例：
1. ReAct循环：Agent思考->行动->观察->再思考，这是一个循环，LangChain的Chain无法表达
2. 多Agent协作：销售Agent->决策路由->客服Agent/数据分析Agent->汇总，有向图结构
3. 人工审批环节：Agent生成建议->等待人工审批->继续/驳回，有条件分支

从架构角度看：
- LangChain是组件层（积木块）
- LangGraph是编排层（建筑图纸）
- LCEL是组合方式（搭积木的方法）

实践建议：简单场景用LangChain Chain就够了；涉及循环、分支、状态流转、多Agent的场景，一定要上LangGraph。
```

```
- 量化指标：自动评估通过率 > 95%

总结一句话：企业落地不是技术Demo，而是要在效果、成本、延迟、安全、可迭代之间找到最佳平衡点。
```
