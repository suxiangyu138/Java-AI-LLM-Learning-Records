## 一、Pandas 最常用代码速查表
### 1. 读写数据
```python
import pandas as pd
import numpy as np

df = pd.read_csv("data.csv")
df = pd.read_excel("data.xlsx")

df.to_csv("out.csv", index=False)
df.to_excel("out.xlsx", index=False)
```

### 2. 查看数据
```python
df.head()
df.tail()
df.info()
df.describe()
df.columns
df.shape
```

### 3. 缺失值处理
```python
df.isnull()
df.isnull().sum()

df.dropna()
df.fillna(0)
df.fillna(df.mean())
```

### 4. 重复值
```python
df.duplicated()
df.drop_duplicates()
```

### 5. 条件筛选
```python
df[df["年龄"] > 18]
df[(df["性别"]=="男") & (df["分数"]>=60)]
```

### 6. 行列操作
```python
# 选列
df[["姓名","年龄"]]

# loc 标签索引
df.loc[10, "姓名"]
# iloc 位置索引
df.iloc[0:5, 0:3]

# 新增列
df["总分"] = df["语文"] + df["数学"]
```

### 7. 分组聚合
```python
df.groupby("班级")["分数"].mean()
df.groupby("性别")["金额"].sum()
```

### 8. 多表合并
```python
pd.merge(df1, df2, on="id")
pd.concat([df1, df2])
```

### 9. 透视表
```python
pd.pivot_table(df, index="地区", values="销售额", aggfunc="sum")
```

## 三、完整可运行数据分析实战模板
标准分析流程：读取→清洗→统计→可视化
```python
import pandas as pd
import matplotlib.pyplot as plt

plt.rcParams["font.sans-serif"] = ["SimHei"]
plt.rcParams["axes.unicode_minus"] = False

# 1. 读取数据
df = pd.DataFrame({
    "姓名":["张三","李四","王五","赵六"],
    "性别":["男","女","男","女"],
    "成绩":[85,92,78,90]
})

# 2. 查看基础信息
print("数据形状：", df.shape)
print("基础统计：")
print(df.describe())

# 3. 缺失值检查
print("\n缺失值统计：")
print(df.isnull().sum())

# 4. 分组统计
print("\n按性别平均成绩：")
print(df.groupby("性别")["成绩"].mean())

# 5. 可视化
df.groupby("性别")["成绩"].mean().plot(kind="bar")
plt.title("男女平均成绩对比")
plt.show()
```
