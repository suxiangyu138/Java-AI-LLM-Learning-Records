# 身体素质 — 规律健身塑形达标

> 目标：本学期减重 10kg，每周运动，养成作息，早睡不熬夜，全面提升体态、体脂、体能。

---

## 一、减重核心原理

### 1.1 能量平衡方程

```
体重变化 = 摄入热量 - 消耗热量

减重公式：摄入 < 消耗 → 制造热量缺口
增肌公式：摄入 > 消耗（需配合力量训练）
```

### 1.2 减重目标拆解

```
目标：12 周减 10kg
每周减：~0.83kg（在安全范围内 0.5-1kg/周）

每天需要制造热量缺口：
1kg 脂肪 ≈ 7700 kcal
0.83kg ≈ 6400 kcal/周 ≈ 910 kcal/天

实现方式：
├── 饮食控制：减少 500 kcal/天（主力）
└── 运动消耗：增加 400 kcal/天（辅助）

总缺口 = 900 kcal/天 × 7 = 6300 kcal/周 ≈ 0.82kg/周 ✓
```

### 1.3 基础代谢估算

```
基础代谢率 (BMR)：
男：BMR = 66 + (13.7 × 体重kg) + (5 × 身高cm) - (6.8 × 年龄)
女：BMR = 655 + (9.6 × 体重kg) + (1.8 × 身高cm) - (4.7 × 年龄)

每日总消耗 (TDEE) = BMR × 活动系数
├── 久坐（几乎不运动）：× 1.2
├── 轻度活跃（运动 1-3 天/周）：× 1.375
├── 中度活跃（运动 3-5 天/周）：× 1.55
├── 高度活跃（运动 6-7 天/周）：× 1.725
└── 极高度活跃（高强度体力劳动/每天训练）：× 1.9

减重期摄入 = TDEE - 500~600 kcal
```

## 二、饮食控制（减重的核心竞争力）

### 2.1 三大营养素配比

| 营养素 | 每克热量 | 建议占比 | 作用 |
|--------|----------|----------|------|
| **蛋白质** | 4 kcal | 30%-35% | 保护肌肉、增加饱腹感 |
| **碳水** | 4 kcal | 40%-45% | 供能主力、运动必需 |
| **脂肪** | 9 kcal | 20%-25% | 激素合成、不超即可 |

**一句话**：每餐 = 一拳主食 + 一掌蛋白质 + 两拳蔬菜

### 2.2 饮食红绿灯

```
绿灯食物（多吃，不限量）：
├── 蔬菜：西兰花、菠菜、生菜、黄瓜、西红柿、芹菜
├── 优质蛋白：鸡胸肉、鸡蛋、鱼虾、瘦牛肉、豆腐
└── 饮品：水、黑咖啡、无糖茶

黄灯食物（适量，控制份量）：
├── 碳水：糙米饭、燕麦、红薯、玉米、全麦面包
├── 水果：苹果、蓝莓、草莓、橙子、柚子（每天 ≤ 200g）
├── 脂肪：橄榄油、坚果（每天一小把 ~15g）、牛油果
└── 奶制品：纯牛奶、希腊酸奶

红灯食物（尽量不吃/极少吃）：
├── 含糖饮料：奶茶、可乐、果汁（液体的糖最可怕！）
├── 深加工零食：薯片、饼干、蛋糕、辣条
├── 油炸食品：炸鸡、油条、炸串
├── 精制碳水：白面包、方便面、肠粉（纯碳水+油）
└── 外卖高油菜：麻辣烫、麻辣香锅、黄焖鸡（油量不可控）

严禁踩的坑：
├── 不喝奶茶 = 少摄入 300-500 kcal（一杯 = 一顿饭！）
├── 不喝含糖饮料（包括"果汁"）
├── 不吃夜宵（睡前进食直接囤脂肪）
└── 不饿时不吃零食（嘴馋 ≠ 饿了）
```

### 2.3 一日三餐模板

```
早餐（7:00-8:30）~350 kcal
├── 碳水：全麦面包 1-2 片 / 燕麦粥 1 碗 / 玉米 1 根
├── 蛋白质：鸡蛋 1-2 个 / 纯牛奶 200ml / 无糖豆浆
└── 蔬菜/水果：一根黄瓜 or 一个苹果

午餐（11:30-13:00）~500 kcal
├── 主食：一拳米饭（约 150g，尽量杂粮饭）
├── 蛋白质：鸡胸肉/鱼肉/瘦牛肉/豆腐 150g
├── 蔬菜：两拳任意绿叶蔬菜
└── 烹饪方式：蒸/煮/少油炒（避开炸和红烧）

加餐（15:00-16:00）~100 kcal（可选，不饿就跳过）
├── 一个苹果 / 一把坚果（15g）/ 一杯希腊酸奶

晚餐（17:30-19:00）~350 kcal
├── 主食：半拳（比午餐少一半）/ 红薯半个 / 南瓜
├── 蛋白质：鸡蛋 1-2 个 / 鱼虾 / 豆腐
├── 蔬菜：两拳蔬菜
└── 原则：晚餐碳水减量！20:00 后不进食

全天总计：~1300-1400 kcal（减重期）
```

### 2.4 食堂生存指南

```
食堂打饭策略：
├── 米饭：主动让阿姨只打半份
├── 菜品选择：优先蒸菜/凉拌/清炒 → 避开红烧/糖醋/油炸/勾芡
├── 免费汤：喝汤！增加饱腹感
├── 酱汁说"少一点"或"不放"（酱汁的热量超乎想象）
└── 能吃多少打多少，不要因为"剩饭浪费"硬塞

附：食堂常见陷阱
├── 鱼香肉丝 = 糖 + 油（热量炸弹）
├── 番茄炒蛋 = 一个蛋 + 半锅油（食堂版本尤其）
├── 干锅/麻辣香锅 = 大量油 + 加工肉
├── 炒饭/炒面 = 纯碳水 + 油 = 一盘 800 kcal
└── 肉沫茄子 = 茄子吸油 = 超标的隐藏油脂
```

## 三、运动方案

### 3.1 每周训练安排

```
周一：力量训练（上肢 + 核心）45min + 有氧 20min
周二：有氧日（慢跑/游泳/跳绳）40-50min
周三：力量训练（下肢 + 核心）45min + 有氧 20min
周四：休息日（散步即可）
周五：力量训练（全身）45min + 有氧 20min
周六：有氧日（慢跑/游泳/球类）40-50min
周日：休息日（拉伸放松）
```

### 3.2 力量训练动作库（学校健身房或宿舍可练）

```
下肢动作：
├── 深蹲（徒手/哑铃）：15-20 次 × 3-4 组 —— 下肢之王
├── 弓步蹲（徒手/哑铃）：每条腿 12 次 × 3 组
├── 臀桥：15-20 次 × 3 组
├── 哑铃硬拉：12-15 次 × 3 组
└── 提踵：20 次 × 3 组（小腿）

上肢动作：
├── 俯卧撑：做到力竭 × 3-4 组 —— 胸+三头
├── 哑铃卧推（仰卧）：12 次 × 3 组
├── 哑铃推举（肩）：12 次 × 3 组
├── 哑铃划船（背）：12 次 × 3 组（每侧）
├── 哑铃弯举（肱二头）：12 次 × 3 组
├── 臂屈伸（肱三头）：用椅子边缘 12 次 × 3 组
└── 引体向上（如果有单杠）：力竭 × 3 组

核心动作：
├── 平板支撑：30-60s × 3 组
├── 卷腹：15-20 次 × 3 组
├── 俄罗斯转体：20 次 × 3 组
├── 仰卧举腿：15 次 × 3 组
├── 死虫式：每侧 12 次 × 3 组
└── 腹式呼吸训练（真空腹）：每天 3 组 × 10 次腹式呼吸

宿舍无器械替代方案：
├── 深蹲 / 弓步蹲 / 臀桥 / 靠墙静蹲
├── 俯卧撑（标准/宽距/窄距）
├── 平板支撑 + 各种变体
├── 椅子臂屈伸
└── Burpee 波比跳（燃脂神器）
```

### 3.3 有氧运动选择

| 运动 | 30min 消耗 | 关节负担 | 便捷度 |
|------|-----------|----------|--------|
| 慢跑 | ~250 kcal | 中等 | 随时可做 |
| 跳绳 | ~350 kcal | 中高（需缓冲）| 宿舍楼下即可 |
| 游泳 | ~300 kcal | 很低 | 需有场馆 |
| 快走 | ~150 kcal | 很低 | 随时可做 |
| 自行车 | ~250 kcal | 低 | 需有车 |
| 爬楼梯 | ~300 kcal | 中等 | 随时可做 |
| HIIT | ~350 kcal | 中高 | 15min 高效 |

**推荐组合**：慢跑为主（30-40min），每周穿插 1 次 HIIT（15min 暴汗）。

### 3.4 训练注意事项

```
训练前：
├── 热身 5-10min（动态拉伸 + 轻有氧把体温升起来）
└── 不能空腹练力量（提前 1h 吃点碳水）

训练中：
├── 动作质量 > 重量/数量（错误姿势 = 受伤 + 白练）
├── 组间休息 60-90 秒（力量训练）
├── 呼吸：发力时呼气，放松时吸气
└── 喝水！每 15-20min 少量多次

训练后：
├── 拉伸 5-10min（静态拉伸，放松目标肌群）
├── 1 小时内补充蛋白质（鸡蛋/蛋白粉/鸡胸肉）
└── 记录训练内容（重量/组数/感受）
```

## 四、作息管理

### 4.1 理想作息表

```
06:30  起床（固定时间，不赖床）
06:40  喝一杯温水 + 简单拉伸
07:00-07:30  早读单词 / 晨跑（隔天交替）
07:30-08:00  早餐
08:00-12:00  上课 / 自习
12:00-12:30  午餐
12:30-13:00  饭后散步 15min
13:00-13:40  午休（不超过 40min！超了反而越睡越困）
14:00-17:30  上课 / 自习
17:30-18:00  晚餐
18:30-19:30  运动（最好的运动时间窗）
19:30-20:00  洗漱
20:00-22:00  自习 / 编程
22:00-22:30  准备睡觉：远离屏幕 → 热水泡脚 → 回顾当天
22:30       上床，手机放桌上不要带上床
23:00       入睡

睡眠时长：6.5h（23:00-06:30 再补 30min 午休）≈ 7h 睡眠
```

### 4.2 改善睡眠的方法

```
入睡困难怎么办？
├── 睡前 1h 不碰手机屏幕（蓝光抑制褪黑素分泌）
├── 睡前热水泡脚 10-15min（促进血液循环，放松身体）
├── 睡前做 5min 腹式呼吸（4 秒吸气 → 7 秒屏息 → 8 秒呼气）
├── 下午 14:00 后不喝咖啡/茶/奶茶（咖啡因代谢半衰期 5-6h）
├── 白天有运动（身体疲劳 = 最好的安眠药）
├── 晚上不躺在床上刷视频（床 = 睡觉的地方，建立条件反射）
├── 睡不着就起来看会书，困了再躺回去（不要辗转硬躺）
└── 固定起床时间（即使睡得晚也按时起，建立稳定的生物钟）

熬夜的本质：
├── 不是"事情太多做不完"（白天效率低才是真相）
├── 不是"晚上效率高"（只是逃避白天的焦虑）
└── 是"对明天的抗拒"（不想结束今天，不想面对明天）

对抗熬夜：
├── 白天的效率提升是对熬夜最狠的打击
├── 给自己设一个"关机"仪式（比如写 3 件今天完成了的事）
├── 把手机充电器放在够不着的地方
└── 利用 App 强制锁机（如 Forest / 不做手机控）
```

### 减重进度参考

```
体重不是直线下降的，是台阶式的！波动 ±0.5kg 完全正常

第 1-2 周：掉秤最快（主要是水分）- 每周 0.5-1kg
第 3-8 周：稳定减脂期 - 每周 0.5-0.8kg
第 9-12 周：减速/平台期 - 每周 0.3-0.5kg

平台期怎么办？
├── 检查饮食（是否隐形热量多了）：重新记录 3 天饮食
├── 改变运动模式（身体适应了）：换运动类型/增加强度
├── 增加力量训练占比（肌肉提基础代谢）
└── 保证睡眠（睡眠不足 = 新陈代谢下降 = 脂肪更难减）

测量说明：
├── 每周固定时间称重：周一早上空腹排大小便后
├── 同时量腰围（体重不降但腰围降了 = 增肌减脂 = 赚了）
└── 拍正面+侧面照（肉眼变化 > 数字变化，给自己信心）
```

---

> **核心方法论**：减重 = 饮食控制 70% + 运动 30%。厨房比健身房更重要。管住嘴（控制热量缺口）+ 迈开腿（力量保住肌肉 + 有氧燃脂）+ 睡好觉（代谢和激素修复）。坚持 12 周，不是完美主义，而是大多数日子做对了。
