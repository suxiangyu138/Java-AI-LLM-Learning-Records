# 英语能力 — 六级冲刺 + 专业英语

> 目标：一次性通过六级，背完考纲单词，吃透真题阅读听力，能流畅看懂英文开发文档。

---

## 一、六级考试拆解

### 1.1 分数构成

| 模块 | 分值 | 题量 | 时间 | 目标分 |
|------|------|------|------|--------|
| **写作** | 106.5 | 1 篇 | 30 min | 80+ |
| **听力** | 248.5 | 25 题 | 30 min | 180+ |
| **阅读** | 248.5 | 30 题 | 40 min | 180+ |
| **翻译** | 106.5 | 1 段 | 30 min | 70+ |

**得分公式**：听力 + 阅读 = 360+ 就稳过，这两项是拉分主力。

### 1.2 通关关键

```
听力（提分最快） > 阅读（保底基本盘） > 写作（模板速成） > 翻译（随缘）
```

## 二、词汇（地基工程）

### 2.1 六级词汇量

| 类型 | 数量 | 策略 |
|------|------|------|
| 六级核心词 | ~2000 | 必须全掌握 |
| 四级基础词 | ~4000 | 快速复习，查漏补缺 |
| 真题高频词 | ~500 | 最高优先级，重复考 |
| 阅读认知词 | ~1500 | 看到能认就行 |
| 写作翻译词 | ~300 | 能正确拼写 |

### 2.2 每日背词计划

```
总量：2000 核心词 ÷ 时间

每日计划（建议）：
├── 新词：30-40 个/天（用 App 碎片时间）
├── 复习：APP 自动安排（艾宾浩斯曲线）
├── 时间分配：
│   ├── 早起 20min：过一遍昨天的词
│   ├── 课间 10min × 3：碎片刷 APP
│   └── 睡前 15min：复习今天所有词
└── 每周日：回顾本周所有词 + 标记顽固词
```

### 2.3 高效背词方法

```
1. 词根词缀法（举一反三）
   例：spect（看）→ inspect(检查) / respect(尊重) / prospect(前景) / spectator(观众)

2. 真题语境法（最牢固）
   从真题阅读中找出不认识的词 → 在语境中记 → 关联例句

3. 高频词优先法
   先背真题中反复出现的 500 词（这些词不背就是送分题丢分）

4. 顽固词本
   记了 3 次以上还忘的词单独整理到小本/便签，每天看一遍
```

## 三、听力（提分核心，性价比最高）

### 3.1 听力题型

| 题型 | 数量 | 特点 |
|------|------|------|
| 长对话 | 8 题 | 日常对话，相对简单 |
| 听力篇章 | 7 题 | 短文独白 |
| 讲座/讲话 | 10 题 | 最难，学术/讲座风格 |

### 3.2 训练方法

```
阶段一：泛听（0-2 周）
├── 每天 30min VOA 常速 / BBC 6 Minute English
├── 目的：磨耳朵，适应英文语音语调连读
└── 不追求听懂每个词，感受节奏

阶段二：精听（2-8 周）★ 核心方法
├── Step 1：完整听一遍，理解大意
├── Step 2：逐句听写，每句最多听 5 遍
├── Step 3：对照原文，标记没听出来的部分
├── Step 4：分析原因：
│   ├── 不认识这个词？→ 背！
│   ├── 连读/弱读没听出来？→ 跟读模仿
│   └── 反应速度不够？→ 反复听直到秒懂
├── Step 5：1.25 倍速听，逐渐提速
└── 每天 1 篇，45min

阶段三：实战（8-12 周）
├── 限时做真题听力（严格按考试时间）
├── 错题复盘 > 无脑刷量
├── 常见陷阱类型：
│   ├── 出现原词 ≠ 正确答案（同义替换才是）
│   ├── 开头第一句话经常出答案
│   └── 转折词 but/however/actually 后藏答案
└── 每天 1 套 + 全文复盘
```

### 3.3 听力技巧

```
审题黄金 30 秒（录音开始前）：
├── 扫读所有选项，划出关键词（名词/动词/数字/专有名词）
├── 选项差异处标注（A 说 increase，B 说 decrease → 听到啥选啥）
└── 预测问题类型（原因/态度/细节/主旨）

听中技巧：
├── 听到什么选什么（六级听力偏直给）
├── 同义替换才是答案（听到原词大概率是干扰项）
├── 顺序原则（题目顺序 = 听力内容顺序）
└── 没听到先跳过，不要在上一题纠结

听后处理：
├── 对答案 → 看原文 → 分析为什么错
├── 跟读难点句 3 遍
└── 积累生词进顽固词本
```

## 四、阅读（保分基本盘）

### 4.1 阅读题型

| 题型 | 数量 | 分值 | 策略 |
|------|------|------|------|
| **仔细阅读** | 10 题 | 142 分 | **重点拿分项**，正确率 ≥ 80% |
| 长篇阅读（匹配）| 10 题 | 71 分 | 抓关键词快速匹配 |
| 选词填空 | 10 题 | 35.5 分 | 放最后做，性价比低 |

### 4.2 仔细阅读 —— KLA 三步法

```
Step 1：Key Words（30s）
扫读题干，划出关键词（人名/地名/数字/专有名词/核心名词）
不看选项！看选项会被干扰

Step 2：Locate（在原文定位）
按关键词依次回原文定位对应段落
顺序出题：第 1 题对应开头，第 5 题对应结尾

Step 3：Analyze（对比分析）
找到原文定位句 → 理解句意 → 对比选项
正确选项 = 原文内容的同义改写（不是原词照搬）
排除干扰项：偷换概念、无中生有、过度推理、以偏概全
```

### 4.3 长篇阅读（信息匹配）

```
策略：先看 10 个题干 → 划关键词 → 从第一段开始速读扫关键

技巧：
├── 只读每段首尾句 + 转折处（however/but）
├── 人名/数字/专有名词最好匹配
├── 一个段落可能匹配多个题干（近年趋势）
├── 同义替换是灵魂（题干 = 段落的同义改写）
└── 10-12 分钟完成，留时间给仔细阅读
```

### 4.4 选词填空

```
策略：最后做，5-7 分钟

步骤：
1. 标注待选词的词性（n./v./adj./adv.）
2. 读文章，根据句子结构判断空格词性
3. 从对应词性中选语义匹配的
4. 选一个划掉一个

Tips：
├── 分值低（35.5/710），不要花太多时间
├── 词性分析 + 排除法是核心
├── -ly 结尾通常是 adv
├── -tion/-sion 结尾通常是 n
└── 实在不会全选 B/C，往年的经验分布
```

## 五、写作与翻译

### 5.1 写作黄金模板

```
命题类型：议论文 > 说明文 > 图表文

万能结构（三段式）：
┌─────────────────────────────────────┐
│ 开头段（2-3 句）                    │
│ 现象描述 + 观点引入                  │
│                                    │
│ 中间段（4-6 句）                    │
│ 论点 1 + 论据                       │
│ 论点 2 + 论据                       │
│ 过渡词：Firstly/Secondly/Moreover   │
│                                    │
│ 结尾段（2-3 句）                    │
│ 总结观点 + 展望/建议                 │
└─────────────────────────────────────┘

高分要素：
├── 结构清晰（三段式）（基本分）
├── 句式多变（倒装、强调、从句）（加分项）
├── 高级词汇替换（重要→significant/crucial/vital/pivotal）
├── 逻辑衔接词（However/Therefore/In addition/Furthermore）
├── 无基础语法错误（时态/主谓一致/单复数）（致命伤！）
└── 字数：150-200（写太少不够展开，太多容易暴露错误）
```

### 5.2 写作必备替换词表

| 低级词 | 替换词 |
|--------|--------|
| important | significant / crucial / vital / essential |
| many | numerous / a multitude of / a variety of |
| think | believe / hold the view / argue / assume |
| good | beneficial / advantageous / favorable |
| bad | detrimental / harmful / adverse |
| because | due to / owing to / on account of |
| very | extremely / exceedingly / remarkably |
| big | substantial / considerable / enormous |
| show | demonstrate / indicate / illustrate |
| but | however / nevertheless / nonetheless |

### 5.3 翻译策略

```
评分标准：大意对 + 句式通顺 + 少语法错误

步骤：
1. 通读全段 → 判断时态（过去/现在/将来？）
2. 确定主干（主语+谓语+宾语）
3. 修饰成分往主干上加（定语从句、状语从句）
4. 不确定的词用上位词替代（不会"针灸"→ medical treatment）

常见考点：
├── 被动语态（中文主动 → 英语被动）★
├── 定语从句（...的）
├── 状语从句（当...时/因为.../虽然...）
├── 无主句处理（加主语 it/we/people 或变被动）
└── 中国文化词（四六级翻译最爱：节日/习俗/地理/历史）
```

## 六、专业英语（阅读英文开发文档）

### 6.1 程序开发高频词

```
核心动词：
implement (实现) | invoke (调用) | execute (执行) | trigger (触发)
handle (处理) | parse (解析) | instantiate (实例化) | override (重写)
overload (重载) | inherit (继承) | dispatch (分发) | delegate (委托)
serialize (序列化) | deserialize (反序列化) | allocate (分配) | deallocate (释放)

核心名词：
dependency (依赖) | configuration (配置) | interface (接口) | class (类)
object (对象) | instance (实例) | parameter (参数) | argument (实参)
property (属性) | method (方法) | constructor (构造器) | annotation (注解)
exception (异常) | stack trace (堆栈跟踪) | thread (线程) | concurrency (并发)
repository (仓库) | middleware (中间件) | endpoint (端点) | payload (载荷)

常见缩写：
API — Application Programming Interface
JVM — Java Virtual Machine
OOP — Object-Oriented Programming
DI — Dependency Injection
AOP — Aspect-Oriented Programming
ORM — Object-Relational Mapping
IoC — Inversion of Control
    (还有很多，保持积累)

常见括号表达：
() parentheses / round brackets
[] brackets / square brackets
{} braces / curly brackets
<> angle brackets
```

### 6.2 阅读技术文档的方法

```
阅读策略：
├── 不需要逐词翻译！抓主干理解逻辑
├── 先看标题 → 小标题 → 代码示例（代码跑通了再反过来看说明）
├── 第一遍扫读：这文档在讲什么
├── 第二遍实践：照着代码示例跑起来
├── 第三遍精读：理解参数含义、边界情况
└── 配合 Google 翻译划词（不是全篇翻译）

练习路径：
├── 每天读 1 页 Spring 官方文档
├── StackOverflow 看英文回答（技术英语+问题解决 双修）
├── GitHub Issues 看英文讨论
└── YouTube 英文技术视频（听+看双输入）
```
