# 学业基础 — 大二下学期核心规划

> 目标：所有课程不挂科，核心专业课稳定绩点。

---

## 一、核心策略

```
课前预习（15min）→ 课堂专注（记要点）→ 课后复习（当天）→ 周末总结 → 考前冲刺
```

| 阶段 | 动作 | 时间 |
|------|------|------|
| 日常 | 上课坐前排、不玩手机、记课堂要点 | 每周上课时间 |
| 课后 | 当天整理笔记、完成作业、标记疑问 | 每天 1-2h |
| 周末 | 复盘本周内容、做习题、解决疑问 | 3-4h |
| 考前 2 周 | 系统复习、刷历年题、知识点串联 | 每天 4-6h |

## 二、各课程核心知识点

> 以下按大二下学期常见课程列出核心知识体系。对照自己实际课表取舍。

### 2.1 数据结构（核心中的核心）

```
线性结构
├── 数组 / 链表（单向、双向、循环）
├── 栈（表达式求值、括号匹配）
├── 队列（BFS、循环队列、双端队列）
└── 串（KMP 算法）

树形结构
├── 二叉树（遍历：前序/中序/后序/层序）
├── 二叉搜索树（插入、删除、查找）
├── 平衡二叉树（AVL、红黑树概念）
├── 堆（优先队列、堆排序、Top-K）
├── 哈夫曼树（编码压缩）
└── B 树 / B+ 树（数据库索引底层）

图形结构
├── 存储方式（邻接矩阵、邻接表）
├── 遍历（DFS、BFS）
├── 最小生成树（Prim、Kruskal）
├── 最短路径（Dijkstra、Floyd）
├── 拓扑排序（AOV 网）
└── 关键路径（AOE 网）

查找与排序
├── 查找：顺序、二分、哈希（冲突解决：开放定址/链地址）
├── 基础排序：冒泡、选择、插入  O(n²)
├── 进阶排序：快排、归并、堆排  O(n log n)
└── 特殊排序：计数、基数、桶

算法思想
├── 递归与分治（汉诺塔、归并排序）
├── 贪心（活动选择、哈夫曼编码）
├── 动态规划（背包、LCS、矩阵连乘）
└── 回溯（八皇后、图着色）
```

### 2.2 计算机组成原理

```
数据表示
├── 数制转换（二进制、八进制、十六进制）
├── 原码 / 反码 / 补码 / 移码
├── 浮点数（IEEE 754：符号位 + 阶码 + 尾数）
└── 字符编码（ASCII、Unicode、UTF-8）

运算方法与运算器
├── 定点加减法（溢出判断）
├── 定点乘除法（原码一位乘、补码一位乘）
├── 浮点运算（对阶 → 尾数运算 → 规格化 → 舍入）
└── ALU 结构

存储系统（重点）
├── 存储层次：寄存器 → Cache → 主存 → 辅存
├── Cache 映射方式：全相联 / 直接映射 / 组相联
├── Cache 替换算法：LRU、FIFO、随机
├── 虚拟存储器：页式 / 段式 / 段页式
├── TLB（快表）+ 页表（慢表）
└── 主存与 CPU 连接（位扩展、字扩展）

指令系统
├── 指令格式（操作码 + 地址码）
├── 寻址方式：立即/直接/间接/寄存器/变址/基址/相对
├── CISC vs RISC
└── 常见指令类型（数据传送、算术逻辑、转移、I/O）

CPU
├── CPU 结构：ALU + CU + 寄存器组
├── 指令周期：取指 → 间址 → 执行 → 中断
├── 微程序控制 vs 硬布线控制
├── 流水线：五级流水（IF → ID → EX → MEM → WB）
├── 流水线冲突：结构/数据/控制冲突及解决方法
└── 中断系统（中断向量、中断优先级）

I/O 系统
├── I/O 控制方式：程序查询 → 中断 → DMA → 通道
├── 总线（数据总线、地址总线、控制总线）
└── 常见接口（USB、PCIe、SATA）
```

### 2.3 操作系统

```
进程管理（核心）
├── 进程概念：PCB、进程状态转换（就绪/运行/阻塞）
├── 进程调度算法：FCFS、SJF、优先级、RR、多级反馈队列
├── 进程同步：
│   ├── 临界区、互斥、同步
│   ├── 信号量机制（P/V 操作）
│   └── 经典同步问题：生产者-消费者、读者-写者、哲学家就餐
├── 死锁：
│   ├── 四个必要条件（互斥/请求保持/不可剥夺/循环等待）
│   ├── 死锁预防（破坏四个条件之一）
│   ├── 死锁避免（银行家算法）
│   ├── 死锁检测与解除
└── 线程：用户级线程 vs 内核级线程、多线程模型

内存管理（重点）
├── 连续分配：单一连续/固定分区/动态分区（首次/最佳/最差适应）
├── 离散分配：
│   ├── 分页存储（页表、快表 TLB、多级页表）
│   ├── 分段存储（段表）
│   └── 段页式存储
├── 虚拟内存：
│   ├── 请求分页
│   ├── 页面置换算法：OPT、FIFO、LRU、CLOCK、改进 CLOCK
│   ├── 页面分配策略（固定/可变分配 + 局部/全局置换）
│   ├── 抖动现象（Thrashing）与工作集
│   └── 缺页率：Belady 异常

文件管理
├── 文件逻辑结构：无结构（流式文件）/ 有结构（记录式文件）
├── 文件物理结构：连续/链接/索引分配
├── 目录结构：单级/两级/树形/无环图
├── 文件存储空间管理：空闲表/空闲链表/位示图/成组链接
├── 文件共享与保护
└── 磁盘调度：FCFS、SSTF、SCAN、C-SCAN、LOOK

I/O 管理
├── I/O 控制方式：程序直接控制 → 中断驱动 → DMA → 通道
├── I/O 软件层次：用户层 → 独立软件层 → 驱动层 → 中断处理层
├── 缓冲区技术：单缓冲/双缓冲/循环缓冲/缓冲池
└── SPOOLing 技术（假脱机）
```

### 2.4 计算机网络

```
网络体系结构
├── OSI 七层模型：物理层 → 数据链路层 → 网络层 → 传输层 → 会话层 → 表示层 → 应用层
├── TCP/IP 四层模型：网络接口层 → 网际层 → 传输层 → 应用层
├── 每层功能与代表性协议
└── 封装过程：数据 → 段 → 包 → 帧 → 比特

物理层
├── 信号：模拟信号/数字信号
├── 编码方式：NRZ、曼彻斯特、差分曼彻斯特
├── 传输介质：双绞线、同轴电缆、光纤
├── 信道复用：频分/时分/波分/码分复用
└── 香农定理与奈氏准则

数据链路层
├── 差错检测：奇偶校验、CRC 循环冗余校验
├── 流量控制：停止-等待、滑动窗口（GBN、SR）
├── 介质访问控制：
│   ├── 信道划分：FDMA、TDMA、CDMA
│   ├── 随机访问：ALOHA、CSMA/CD（以太网）、CSMA/CA（Wi-Fi）
│   └── 轮询：令牌环、令牌总线
├── MAC 地址与 ARP 协议
├── 以太网帧格式
└── 交换机（自学习算法、广播风暴、STP 生成树）

网络层（重点）
├── IP 协议：IPv4 报文格式、分片与重组
├── IP 地址：
│   ├── 分类编址（A/B/C/D/E 类）
│   ├── 子网划分与子网掩码
│   └── CIDR 无分类编址（路由聚合）
├── NAT 网络地址转换
├── 路由协议：
│   ├── 内部网关协议：RIP（距离向量）、OSPF（链路状态）
│   └── 外部网关协议：BGP（路径向量）
├── ICMP 协议（ping、traceroute）
├── ARP 地址解析协议
├── DHCP 动态主机配置
└── IPv6：地址格式、与 IPv4 的区别

传输层（重中之重）
├── UDP：无连接、不可靠、首部 8 字节
├── TCP：
│   ├── 首部格式（端口号、序号、确认号、标志位、窗口）
│   ├── 三次握手（SYN → SYN+ACK → ACK）
│   ├── 四次挥手（FIN → ACK → FIN → ACK）
│   ├── 可靠传输：确认应答、超时重传、滑动窗口
│   ├── 流量控制：接收窗口 rwnd
│   ├── 拥塞控制：慢开始、拥塞避免、快重传、快恢复
│   └── TIME_WAIT 状态（2MSL）
└── TCP vs UDP 对比（可靠/速度/适用场景）

应用层（高频协议）
├── DNS：域名解析（递归查询/迭代查询）、DNS 缓存
├── HTTP：
│   ├── 1.0 / 1.1 / 2.0 / 3.0 (QUIC) 区别
│   ├── 请求方法（GET/POST/PUT/DELETE）、状态码
│   ├── 长连接 vs 短连接、管线化
│   └── HTTPS = HTTP + TLS（握手流程）
├── FTP：控制连接（21）+ 数据连接（20）、主动/被动模式
├── SMTP / POP3 / IMAP：邮件收发
├──  Cookie & Session
└── WebSocket（全双工通信）
```

### 2.5 数据库

```
数据库基础
├── 数据模型：层次/网状/关系
├── 三级模式结构：外模式 → 概念模式 → 内模式
├── 二级映像：外模式/模式映像、模式/内模式映像（逻辑/物理独立性）
└── DBMS：数据库管理系统组成

关系代数
├── 集合运算：并 ∪、交 ∩、差 -、笛卡尔积 ×
├── 关系运算：选择 σ、投影 π、连接 ⋈、除 ÷
├── 自然连接 vs 等值连接 vs 外连接
└── SQL 对应关系：σ = WHERE、π = SELECT、⋈ = JOIN

SQL（核心技能）
├── DDL：CREATE、ALTER、DROP（表、索引、视图）
├── DML：INSERT、UPDATE、DELETE
├── DQL：
│   ├── SELECT...FROM...WHERE...GROUP BY...HAVING...ORDER BY
│   ├── 聚合函数：COUNT/SUM/AVG/MAX/MIN
│   ├── 多表连接：INNER/LEFT/RIGHT/FULL JOIN
│   ├── 子查询：IN、EXISTS、相关子查询
│   ├── UNION / UNION ALL
│   └── 窗口函数：ROW_NUMBER/RANK/DENSE_RANK/LAG/LEAD
├── DCL：GRANT、REVOKE
└── TCL：BEGIN、COMMIT、ROLLBACK、SAVEPOINT

数据库设计（重点）
├── ER 模型：实体、属性、联系（1:1、1:n、n:m）
├── ER 图转关系模式
├── 函数依赖：部分依赖、完全依赖、传递依赖
├── 范式理论：
│   ├── 1NF：属性不可再分
│   ├── 2NF：消除非主属性对码的部分依赖
│   ├── 3NF：消除非主属性对码的传递依赖
│   ├── BCNF：消除主属性对码的部分/传递依赖
│   ├── 4NF：消除非平凡的多值依赖
│   └── 口诀：3NF 足够，BCNF 更优
└── 反范式化（适量冗余换性能）

事务与并发
├── ACID：原子性、一致性、隔离性、持久性
├── 并发问题：丢失更新、脏读、不可重复读、幻读
├── 隔离级别：READ UNCOMMITTED → READ COMMITTED → REPEATABLE READ → SERIALIZABLE
├── 锁机制：共享锁(S)/排他锁(X)、两段锁协议(2PL)
├── 意向锁（IS/IX/SIX）：解决表级锁和行级锁共存
└── MVCC 多版本并发控制（MySQL InnoDB 核心）

索引与查询优化
├── B+ 树索引（MySQL InnoDB 默认）
│   ├── 聚簇索引 vs 非聚簇索引
│   ├── 联合索引与最左前缀原则
│   └── 索引下推 (ICP)
├── 哈希索引（Memory 引擎）
├── 覆盖索引：不用回表
├── EXPLAIN 执行计划分析（type、key、rows、Extra）
├── 避免索引失效：函数操作、隐式类型转换、OR 条件、不等于、LIKE 前缀%
├── SQL 优化：小表驱动大表、避免 SELECT *
├── 慢查询日志与 SQL 调优
└── 分区表与分库分表思想

数据库三范式 + ER 图（面试高频）
```

### 2.6 高数/线代/概率论（数学类课程）

```
├── 中值定理：罗尔/拉格朗日/柯西 → 泰勒公式

└── 二重积分：直角坐标/极坐标转换

线性代数
├── 行列式：性质、展开定理、克拉默法则
├── 矩阵：运算、逆矩阵、伴随矩阵、初等变换

概率论与数理统计
├── 概率基础：条件概率、全概率公式、贝叶斯公式

├── 数字特征：期望、方差、协方差、相关系数

└── 假设检验：u 检验、t 检验、χ² 检验
```

## 三、学习方法论

### 3.1 课堂效率最大化

| 做法 | 说明 |
|------|------|
| 坐前三排 | 物理距离影响注意力，自然减少手机拿起次数 |
| 课前 5 分钟翻书 | 知道今天要讲什么，建立心理预期 |
| 笔记只记关键点 | 不要抄 PPT！记老师的强调点、补充内容、自己的疑问 |
| 课后 5 分钟 | 下课时回顾：今天讲了哪三个最重要的知识点？|
| 主动提问 | 带着问题听课，不懂就问 |

### 3.2 考前复习 SOP

```
考前 3 周：通读教材 + 整理笔记，覆盖所有知识点
考前 2 周：刷近 3 年真题，标记高频考点和薄弱环节
考前 1 周：专攻薄弱点 + 背诵核心概念
考前 1 天：看错题集 + 过一遍知识框架图
考前 30min：看核心公式/定义速记卡
```

### 3.3 避免挂科 Checklist

- [ ] 出勤率达标（缺勤警告线通常是 1/3）
- [ ] 每次作业按时交（平时分占比 30%-40%）
- [ ] 实验课/上机课不缺席
- [ ] 期中考试查漏补缺，别等期末
- [ ] 考前刷 3 套真题（很多题重复出）
- [ ] 跟学霸对一下笔记（查漏补缺最快的方式）
- [ ] 重点复习 PPT + 作业题 + 真题 = 70% 以上分数来源

---

> **一句话**：平时分拿满，考前刷三套真题，核心公式/概念烂熟于心，就能稳过且拿好绩点。
