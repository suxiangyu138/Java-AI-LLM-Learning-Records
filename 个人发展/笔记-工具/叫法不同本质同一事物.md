# 叫法不同、本质完全同一个东西

## 一、基础概念类
1. 算法 = 演算法
    大陆叫算法，台港澳叫演算法，完全同义。
2. 服务器 = 伺服器
    音译+意译区别，都是提供网络服务的计算机。
3. 缓存 = 快取
    Cache 的不同翻译，大陆叫缓存，台港澳叫快取。
4. 客户端 = 用户端
    Client 翻译差异，无任何区别。
5. 端口 = 连接埠
    Port 的不同翻译。
 
## 二、数据结构类
1. 链表 = 连结串列
    Linked List 翻译差异。
2. 队列 = 伫列
    Queue 的台港澳叫法。
3. 栈 = 堆叠
    Stack 的不同翻译。
4. 二叉树 = 二元树
    Binary Tree 翻译差异。
5. 红黑树 = 红黑搜寻树
    同一个数据结构，叫法繁简不同。
 
## 三、网络与通信类
1. 互联网 = 因特网
    Internet：互联网是意译，因特网是音译。
2. 局域网 = 区域网路
    LAN 翻译差异。
3. 网关 = 闸道
    Gateway 的不同翻译。
4. 协议 = 协定
    Protocol 翻译差异。
 
## 四、编程与开发类
1. 函数 = 方法
    面向过程叫函数，面向对象叫方法，本质都是「一段可复用代码」。
2. 变量 = 变数
    Variable 大陆/台港澳翻译差异。
3. 数组 = 阵列
    Array 翻译差异。
4. 指针 = 指标
    Pointer 的不同翻译。
5. 面向对象 = 物件导向
    OOP 的翻译差异。
6. 接口 = 介面
    Interface 翻译差异。
 
## 五、操作系统与硬件类
1. 进程 = 行程
    Process 大陆/台港澳叫法。
2. 线程 = 执行绪
    Thread 翻译差异。
3. 固件 = 韧体
    Firmware 的不同翻译。
4. 主板 = 主机板
    Mainboard 翻译差异。
 
## 六、安全与加密类
1. 加密 = 编码
    狭义场景下经常混用，本质都是「数据转换」。
2. 解密 = 解码
    对应上面的反向操作。
 
## 七、你最关心的「哈希/散列」同类补充
除了哈希=散列，还有一组高频的：
1. 散列函数 = 哈希函数
2. 散列表 = 哈希表
3. 哈希冲突 = 散列碰撞
 
## 八、一句话总结规律
绝大多数这类“同物异名”，都是两个原因：
1. 音译 vs 意译（Hash：哈希=音译，散列=意译）
2. 大陆翻译 vs 台港澳翻译
3. 编程范式不同叫法（函数/方法、进程/线程等）
    它们底层原理、功能、用途 100% 一致，只是叫法习惯不同，完全可以互相替换。
