# 最清晰、不踩坑、性价比最高的 AI 生态学习清单

## 一、必须学（找工作核心竞争力）
这些是面试必问、项目必写、工作必用的。
1. 大模型 API 调用
    - 通义千问、阿里云百炼、DeepSeek、文心一言
    - 会用 HTTP / SDK 调用
    - 会处理流式输出、异常、参数
2. RAG 检索增强生成（重中之重）
    - 文档切分、向量化、向量检索
    - 召回 + 排序 + 提示词工程
    - 能讲清楚完整流程
3. 向量数据库（会一个就行）
    - Milvus / FAISS / Chroma
    - 知道存什么、怎么查、怎么和业务结合
4. Prompt 工程
    - 角色设定、上下文、格式约束
    - 少幻觉、更稳定、更贴合业务
5. 基础 AI 产品逻辑
    - 对话记忆
    - 结构化输出（JSON）
    - 简单 Agent 思想（工具调用）
 
## 二、了解即可（加分，但不是必需）
学了更好，不学也能拿 offer。
1. LangChain / LlamaIndex
    - 知道用途、架构
    - 能搭个 Demo
    - 不用深入源码
2. 简单 Embedding 模型
    - 知道文本怎么变向量
    - 不用懂算法细节
3. 开源大模型本地部署
    - 知道 Qwen、Llama 系列
    - 会用 Ollama 跑个小模型演示
4. 基础多模态
    - 图片理解、简单文生图
 
## 三、完全不用学（对你方向没用，浪费时间）
这些千万别碰，纯消耗精力。
1. 大模型底层训练 / 炼丹
    - Transformer 手写推导
    - 预训练、SFT、DPO、RLHF
    - 千亿参数微调、分布式训练
2. 深度学习框架深入
    - PyTorch、TensorFlow 源码级
    - 算子、CUDA 优化
3. 传统 NLP 算法
    - RNN、LSTM、CRF
    - TF-IDF、Word2Vec 深入原理
4. AI 绘画 / 视频 / 音频底层技术
    - 扩散模型、VAE 原理
    - 语音合成、ASR 内部机制
5. AI 科研、论文、数学推导
    - 你是做工程，不是做算法研究员
 
## 四、给你一句最现实的总结
你是 Java 后端工程师 + AI 应用开发者，
不是大模型算法研究员。
- 必须学：怎么用 AI 做业务系统
- 不必学：怎么造 AI 模型本身
 
## 五、你最终要达到的状态（企业最喜欢）
1. 能用 Java 搭建后端服务
2. 能对接大模型 API
3. 能做 RAG 知识库
4. 能设计稳定的 AI 接口
5. 能把 AI 功能嵌入到实际项目
    这就足够进科大讯飞、阿里云合肥、华为合肥等大厂。
