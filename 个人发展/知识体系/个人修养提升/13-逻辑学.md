# 逻辑学

## 一、逻辑学的核心概念

### 1.1 演绎与归纳

| | 演绎推理（Deduction） | 归纳推理（Induction） |
|------|---------------------|--------------------|
| 方向 | 一般 → 特殊 | 特殊 → 一般 |
| 形式 | 前提真 + 推理有效 → 结论必然真 | 前提真 → 结论可能真 |
| 结论确定性 | 100% | 概率 |
| 例子 | 所有人都会死。苏格拉底是人。所以苏格拉底会死。 | 我见过的所有天鹅都是白的。下一只天鹅大概率是白的。（但黑天鹅存在） |
| 风险 | 前提错了就全错 | 永远存在反例的可能 |

**日常应用**：
- 当你用"因为...所以..."时，先停一下——你此刻用的是演绎还是归纳？如果是归纳，你的样本量有多大？样本有偏吗？
- "我们班所有同学都报了考研班" → 你得出"考研班很重要" → 这实际上是基于小样本的归纳，而且可能存在从众偏差

### 1.2 必要条件和充分条件
这是逻辑学中最实用的日常分析工具。

| 条件类型 | 含义 | 判断法 |
|---------|------|--------|
| 充分条件 | A 发生则 B 必然发生（A → B） | 有 A 必有 B |
| 必要条件 | 没有 A 则 B 不可能发生（¬A → ¬B） | 无 A 必无 B |
| 充要条件 | A 是 B 的充要条件 | 有 A 必有 B，无 A 必无 B |

**实践训练**：
- "努力就能成功" → 努力是成功的充分条件吗？不是——努力的人不一定成功。必要条件吗？很多事没有努力不行，但光有努力也不够。所以努力既不是充分条件也不是必要条件——但在某些场景下是必要条件。
- "985 学历能找到好工作" → 充分？不是。必要？也不是。只是概率上有帮助。
- 分清充要条件可以避免大量无谓争论——很多争论的双方都在用"必要条件"的逻辑去反驳对方"充分条件"的论点。

## 二、常见逻辑谬误

### 2.1 十大高频逻辑谬误

**（1）相关性 ≠ 因果性（Post Hoc / Cum Hoc）**
> "自从换了新 CEO，公司股价就涨了——新 CEO 干得好！"

两件事先后或同时发生，不代表前者导致了后者。可能：纯巧合、存在第三个共同原因、或者因果方向是反的。
反制：**"还有没有其他可能的解释？**"

**（2）稻草人谬误（Strawman）**
> A："我觉得应该适当减少课后作业量。"
> B："哦，所以你觉得学生不应该有任何作业，在学校就是在玩？"

歪曲对方的论点（把对方的观点替换成一个更容易攻击的"稻草人"），然后攻击这个歪曲后的版本。
反制：**"我刚才说的不是这个意思。"**——然后用一句话重新概括自己的立场。

**（3）滑坡谬误（Slippery Slope）**
> "如果允许学生带手机，他们就会上课玩手机，然后成绩下降，然后考不上大学，然后整个人生就毁了。"

在没有足够证据的情况下，声称 A 将导致一连串越来越极端的 B → C → D。
反制：**"请给出从 A 到 B 的证据，以及从 B 到 C 的证据。"**——每一步过渡都需要独立证明。

**（4）诉诸权威（Appeal to Authority）**
> "XX 大牛说了应该用这个技术栈，所以我们应该用。"

权威人物的观点可以是重要的参考，但不能代替独立的论证。
反制：**"他为什么这么说？他的论据是什么？"**

**（5）人身攻击（Ad Hominem）**
> "你是做前端的，你懂什么后端架构？"

攻击说话的人而不是反驳他说的话。
反制：**"我们讨论的是观点，不是人。"**

**（6）诉诸无知（Appeal to Ignorance）**
> "没有证据证明 AI 有意识" → 所以 AI 一定没有意识？
> x情况没有证据证明 → 所以 x 一定不存在/一定存在

不知道 ≠ 证据。反制：**"缺乏证据不是证据。"**

**（7）非黑即白（False Dilemma）**
> "你要么支持我们的方案，要么就是不想解决问题。"

只给两个极端选项，而实际上存在中间地带或其他选择。
反制：**"有没有第三种可能？"**

**（8）循环论证（Begging the Question）**
> "这个药能让人入睡，因为它有催眠作用。"（催眠作用就是让人入睡的能力——你在用结论当论据）

结论已经隐含在前提中。反制：**"你的论据和结论有什么不同？你是不是在用 A 证明 A？"**

**（9）以偏概全（Hasty Generalization）**
> "我认识的两个程序员都不擅长沟通，所以程序员都不擅长沟通。"

样本太少或有严重的样本偏差。
反制：**"你的样本有多大？样本有代表性吗？"**

**（10）诉诸大众（Bandwagon Fallacy）**
> "大家都在用 React，所以我们也要用 React。"

很多人相信 ≠ 是对的。
反制：**"流行的东西不总是好的，好的东西不总是流行的。"**

### 2.2 识别逻辑谬误的日常三问
在听到一个论断时，脑中自动过一遍：
1. **"这个结论的前提成立吗？"**（前提不成立 = 全盘崩塌）
2. **"从前提能推出结论吗？"**（前提虽对但推理有跳跃？）
3. **"还有没有其他可能的解释/方案？"**（过早锁定了唯一结论？）

## 三、论证与思辨

### 3.1 构成一个好论证的要素
- **前提是清晰的、可检验的**（不能是模糊的、无法验证的）
- **前提和结论之间的推理关系是有效的**
- **考虑了反方观点并给予了合理反驳**（最强的论证不是选择性挑证据，而是把自己放在反对者的位置检验自己）

### 3.2 常见的劣质论证模式
- **循环定义**："团队协作就是团队成员一起合作。"（用同义词定义自己）
- **不可证伪**："这个学习方法只对有缘分的人有效。你觉得没效果就是缘分没到。"（无论什么结果都能"自圆其说"——一个什么都可以"解释"的理论实际上什么都解释不了）
- **情感压倒逻辑**：用情感冲击替代推理——"这项政策会让多少家庭破碎！"（也许真的会，但这个表达替代了对"为什么"的讨论）

### 3.3 如何让自己不被人带偏
- 当有人用"显然"、"毫无疑问"、"众所周知"时 → 更警惕这些断言。"显然"是跳过论证的信号
- 当有人说"研究显示..."时 → 问具体什么研究？样本多大？发表在哪儿？
- 当情绪被调动起来时——愤怒、恐惧、感动——暂停一秒，问自己："把情绪拿掉，剩下的论证立得住吗？"
