# 个人理财知识

## 一、个人理财的核心原则

### 1.1 最重要的理财公式
```
收入 - 储蓄 = 支出
```
而不是：收入 - 支出 = 储蓄。

这就是"先支付给自己"（Pay Yourself First）——每次收入到账，第一件事是把固定比例（建议 10-20%）转入储蓄/投资账户，剩下的才是你可以支配的支出。

为什么这个顺序如此关键：
- "发了工资先花，月底剩多少存多少" → 每月结余 0 元
- "发了工资先存 20%，剩下的花" → 每月结余 20%

不是意志力的问题，是系统设计的问题。你不能信任自己"月底会有余钱"——让系统帮你做决定。

### 1.2 个人理财的三个层次
```
第一层：财务安全（Financial Safety）
  紧急备用金 3-6 个月生活费 + 基本保险覆盖
  → 任何时候失业/生病/发生意外，不会立刻陷入困境

第二层：财务独立（Financial Independence）
  被动收入 > 基本生活支出
  → 你可以选择不做不喜欢的工作

第三层：财务自由（Financial Freedom）
  被动收入 > 理想生活方式的支出
  → 不必为了钱而工作
```

**大多数人跳过第一层直冲第三层——没钱的时候整天研究怎么靠投资发财。这是理财最大的误区。**

理财的优先序：
1. 建立紧急备用金
2. 偿还高息债务（信用卡、网贷等年化 > 10% 的债务）
3. 配置基本保险
4. 长期投资
5. 提高生活品质/消费升级

## 二、紧急备用金与债务管理

### 2.1 紧急备用金
**金额**：3-6 个月的生活必需支出（房租、吃饭、交通、基本生活用品）
**存放**：高流动性、低风险（活期存款、货币基金），不考虑收益
**绝对不能动用的场景**：日常消费、旅游、换手机——这不是"存款"，这是"保险自留额"

### 2.2 债务管理
**区分"好债务"和"坏债务"**：

| 好债务（投资型） | 坏债务（消费型） |
|----------------|----------------|
| 用于能产生回报的投资 | 用于纯消费 |
| 利率较低（如房贷） | 利率高（如信用卡分期、网贷） |
| 月供在你的承受范围内 | 月供挤压了正常生活 |

**还债的两种策略**：
1. **雪崩法（Avalanche）**：优先还利率最高的债（数学上最优，总利息最少）
2. **滚雪球法（Snowball）**：优先还金额最小的债（心理上最优，早期正反馈更强）

两种都可以——选你能坚持下来的那个。最糟的策略是不还。

**关于信用卡**：
- 信用卡是好工具——如果你每月全额还清，等于享受 30-50 天的免息期
- 信用卡是坏主人——一旦你开始最低还款或分期，实际年化利率 15-18%+
- 永远不要只还最低还款额

## 三、投资基础

### 3.1 投资不可能三角
任何投资产品不可能同时满足三个条件：
```
        高收益
        /    \
       /      \
      /   !    \
     /          \
  高流动性 ──── 低风险
```

- 满足"高收益 + 低风险" → 一定锁死了流动性（如某些长期理财、房产）
- 满足"高收益 + 随时取" → 一定有高风险（如股票）
- 满足"低风险 + 随时取" → 一定低收益（如货币基金）

如果有人告诉你"稳赚不赔、超高回报、随时可取" → 一定是骗局。

### 3.2 基础资产类别

| 资产类别 | 预期长期收益 | 风险 | 流动性 | 适合 |
|---------|------------|------|--------|------|
| 现金/货基 | 1-2% | 极低 | 极高 | 短期要用到的钱 |
| 债券 | 3-5% | 低-中 | 中-高 | 1-3 年内会用到的钱 |
| 股票 | 7-10% | 高 | 高 | 5 年以上不用的钱 |
| 房产 | 因城市差异极大 | 中-高 | 低 | 需要具体判断 |
| 黄金 | 对冲通胀/危机 | 中-高 | 高 | 资产配置的一小部分 |

### 3.3 长期投资的核心原则

**（1）时间 > 时机**
不是"在正确的时间买入"，而是"在市场中待够时间"。
- 定投（Dollar Cost Averaging）：每月固定金额买入，不择时
- 跌了 → 买得更便宜 → 同样的钱买到更多份额
- 涨了 → 之前的份额在涨
- "在市场中度过的时光比择时更重要"

**（2）分散投资**
不要把鸡蛋放在一个篮子里——不是放在 5 个不同品牌的篮子里，而是放在 5 个不同类型的篮子里（股票、债券、房地产、现金、其他资产）。

**（3）低成本**
管理费和手续费是你无法控制的不确定风险之外，少数可以控制的成本。
- 主动基金平均年化管理费 1.5% vs 指数基金 0.1-0.3%
- 20 年间 1.2% 的费率差 = 最终收益差 30%+

### 3.4 切勿投机
| 投资 | 投机 |
|------|------|
| 基于资产本身的价值 | 基于对价格走势的猜测 |
| 长期持有 | 短期买卖 |
| 期望资产本身创造价值 | 期望有下一个买家出更高价 |
| 判断"这个公司值多少" | 判断"别人觉得这个公司值多少" |

**判断你是在投资还是投机的方法**：如果这只股票明天开始停牌三年不能买卖，你还会买吗？——不会 = 你在投机。

## 四、保险配置

### 4.1 保险的核心原则
保险是对冲小概率但大损失风险的金融工具。保险不是投资——不要期待它"回本"或"赚钱"。你买保险是为了：当你遇到无法承受的损失时，你不会因此陷入财务绝境。

### 4.2 优先级排序
| 优先级 | 险种 | 为什么 |
|--------|------|--------|
| 1 | 社会医疗保险 | 国家给的最基本的保障，覆盖所有人 |
| 2 | 意外险 | 保费极低（通常几百元/年），但保障较大的意外损失 |
| 3 | 百万医疗险 | 覆盖大病住院的高额医疗费（免赔额通常为 1 万元） |
| 4 | 重疾险 | 确诊即赔付一笔钱，弥补生病期间无法工作的收入损失 |
| 5 | 定期寿险 | 如果家庭靠你的收入，万一身故，给家人一笔经济补偿 |
| 6 | 年金/储蓄型保险 | 理财属性强——前五个配齐了再考虑 |

**先保大人，后保孩子**：如果父母的收入断了，孩子靠什么生活？大人的保障优先级高于孩子的保障。

## 五、学生/年轻人的理财步骤

### 5.1 钱不多的时候，做什么比有钱了之后更重要
理财最重要的是建立习惯和心态，而不是打理巨额资金。

**学生/刚工作的理财启动清单**：
- [ ] 每月发工资/生活费单日先转 10% 到独立储蓄账户（不要办卡方便取出——最好另一张卡/另一个支付平台）
- [ ] 养成记账习惯——不一定要记一辈子，但连续记 3 个月你就会发现自己钱去哪了（"电子支付盲区"：扫码支付的痛感远低于现金）
- [ ] 不要开信用卡/花呗为了"透支消费"（开信用卡为了建立信用记录可以，但绝对不要花超过你银行余额的钱）
- [ ] 先还清任何有息债务，再谈投资
- [ ] 投资自己的教育/技能培养 ＞ 投资任何金融产品

### 5.2 年轻人的最大财务错误
不是因为"没有早点投资"而错失了复利，而是：
1. 借消费贷（网贷、消费分期、超前消费）——高息债务是负向复利
2. 跟风投机——看别人赚钱了冲进去，在最高点买入
3. 不投资自己——在 20-25 岁，你最大的资产是你未来 40 年的收入能力，提升 10% 的年收入比任何理财产品的回报都高

### 5.3 关于钱的三种健康心态
1. **钱是工具，不是目的**：钱的终极价值是给你选择的自由（选择做不做一件事、选择和谁在一起、选择在哪里生活）
2. **比较是偷走满足感的贼**：每个人的财务阶段不同，跟你对比的人可能起步比你早 10 年或家里有支持——你不知道。关注自己的进度条
3. **知足是最大的财富放大器**：很多人赚得越来越多但越来越不满足——因为生活水平随着收入一起膨胀（生活方式通胀）。赚 3 万花 2.9 万的人比赚 1 万存 2000 的人更焦虑
