# 法律常识

## 一、法律思维的基础框架

### 1.1 法律体系的基本结构

中国的法律体系可以理解为金字塔层级：
```
宪法（根本大法）
  ↓
法律（全国人大及其常委会制定：民法典、刑法、劳动法等）
  ↓
行政法规（国务院制定）
  ↓
地方性法规、部门规章
```

**法律效力的基本原则**：
- 上位法优于下位法
- 特别法优于一般法（同样效力层级下）
- 新法优于旧法（同样效力层级下）

### 1.2 法律思维的核心原则

**权利义务对等**：法律中的每一项权利都对应着一项义务。不存在绝对、不受限制的权利。理解这一原则，日常生活中 90% 的纠纷都能找到分析框架。

**谁主张谁举证**：在民事诉讼中，提出主张的一方负有举证的义务——这就是为什么要"留痕"（合同、聊天记录、转账凭证、录音等）。口头的说辞在法律上没有说服力。

**程序正义 = 实体正义的前提**：不是"结果对就行"，而是"程序必须正确"。程序违法可以导致实体结果无效——所以"签合同"这件事的形式本身和内容同样重要。

## 二、合同法

### 2.1 合同的三个核心要素

合同的成立需要三要素：
1. **主体适格**：签合同的人有签约资格（年满 18 岁、精神正常、有授权）
2. **意思表示真实**：不是被欺诈、胁迫、重大误解下签的
3. **内容合法**：合同约定的内容不违反法律强制性规定

### 2.2 日常生活中的合同意识

**（1）口头合同也是合同**
口头约定在法律上是有效的——但问题是，你很难举证。所以在任何涉及金钱的事情上，**变成文字**（微信确认也可以）。

**（2）格式条款**
你每次点"我同意"的长篇条款——法律上叫格式条款。如果其中有"不合理地免除或减轻商家自己责任、加重你的责任、限制你的主要权利"的条款，该条款可能无效。但你在现实生活中很难主张——所以还是要尽量看核心条款。

**（3）签字前必看的三样东西**
| 条款 | 看什么 |
|------|--------|
| 违约责任条款 | 谁违约要赔多少钱？什么算违约？|
| 解除条件 | 什么情况下可以终止合同？终止后怎么处理？|
| 争议解决条款 | 打官司去哪？（写着你所在城市=对你有利；写着对方城市=对对方有利）|

### 2.3 合同的违约责任
- 违约金：通常是合同约定的赔偿金。但如果违约金"过分高于实际损失"，法院可以调低（实践中通常不会低于实际损失的 130%）
- 定金：适用"定金罚则"——给定金的一方不履行义务 = 定金不退；收定金的一方不履行义务 = 双倍返还。定金和"订金"不一样——后者没有惩罚性质
- 实际损害赔偿：损失多少赔多少（需要举证损失金额）

## 三、劳动法

### 3.1 劳动关系的基本保障

**劳动合同必须签订**
- 入职一个月内必须签订书面劳动合同
- 超过一个月不满一年不签 → 从第二个月起支付双倍工资
- 超过一年不签 → 视为已签订无固定期限合同

**试用期的法定规定**：
| 合同期限 | 试用期上限 |
|---------|-----------|
| 3 个月-1 年 | 1 个月 |
| 1-3 年 | 2 个月 |
| 3 年以上 / 无固定期限 | 6 个月 |

试用期只能约定一次，不能以"转岗"、"换部门"为由重新约定试用期。

**加班与加班费**：
| 时间 | 加班费计算 |
|------|----------|
| 工作日延长 | 工资的 150% |
| 休息日加班不补休 | 工资的 200%（安排补休则不用付） |
| 法定节假日加班 | 工资的 300% |

注意：法定节假日加班不能用补休替代加班费——必须付 300%。

### 3.2 离职与补偿

**经济补偿金（N）**：在某些情形下解除劳动合同（如公司裁员、协商一致解除、合同到期不续签但员工要求续签等），公司需要支付经济补偿金 = 在本单位工作年限 × 离职前 12 个月平均工资（不足一年按一年算，不足半年按半年算）。

**经济赔偿金（2N）**：公司违法解除劳动合同（如无故开除、不按法定程序解除）→ 双倍。这和高院指导案例相关，实践中举证困难但法律上是存在的。

**劳动者单方解除权**：劳动者提前 30 日书面通知即可解除劳动合同，无需任何理由，不需要单位同意。

### 3.3 自由职业/兼职者须知
- 劳务合同 ≠ 劳动合同：劳务合同不受劳动法保护（没有社保、没有年假、企业可以随时终止且无需补偿）
- 自由职业者在签合作协议时关注：
  - 付款节点和条件（里程碑付款 vs 月结 vs 项目结束后一次性付款）
  - 解约条件（对方可以什么理由解除？你需要提前多久通知？）
  - 知识产权归属（你开发的东西归你还是归客户？）

## 四、消费者权益保护

### 4.1 消费者基本权利
| 权利 | 内容 |
|------|------|
| 安全权 | 购买的商品/服务不能危害人身和财产安全 |
| 知情权 | 有权了解商品/服务的真实情况（成分、价格、产地、有效期等） |
| 自主选择权 | 有权拒绝搭售和强制交易 |
| 公平交易权 | 质量保障、价格合理、计量正确 |
| 求偿权 | 因购买/使用商品受到损害时有权要求赔偿 |
| 个人信息保护权 | 经营者收集使用你的个人信息需要你同意 |

### 4.2 惩罚性赔偿
- 经营者有欺诈行为 → 退一赔三（获赔金额 = 商品/服务费用的 3 倍；不足 500 元的按 500 元）
- 食品领域明知是不安全食品仍然销售 → 退一赔十（获赔金额 = 价款的 10 倍或实际损失的 3 倍，取较高者）
- 对于教培行业：虚假宣传"保过班"但没过 → 构成欺诈，可主张退一赔三

### 4.3 消费维权实操
1. 保留证据（订单截图、付款记录、聊天记录、商品照片/截图）
2. 先与商家沟通（用文字沟通，留痕，不要只打电话）
3. 商家不解决 → 12315 投诉（APP/小程序/电话）
4. 12315 解决不了 → 仲裁或诉讼（小额诉讼程序更便宜快捷）

## 五、网络与数字生活中的法律

### 5.1 个人信息保护
《个人信息保护法》赋予你以下权利：
- 知情权：平台收集你的哪些信息，用于什么目的，必须明确告知
- 同意权：敏感个人信息（生物识别、行踪轨迹、金融账户等）需要你的单独同意——不是裹在长篇条款里的默示同意
- 删除权：你注销账户后，平台应在合理期限内删除你的个人信息
- 拒绝自动化决策：如果你受到纯算法决策的"重大影响"（如纯算法评信用分决定你能否贷款），你有权拒绝

### 5.2 网络言论的法律边界
- 公开侮辱他人 → 侵犯名誉权（民事责任）
- 造谣传谣 → 可能构成寻衅滋事或诽谤
- 人肉搜索、曝光他人隐私信息 → 侵犯隐私权
- 转发谣言 → 同样需要承担责任（转发 ≠ 免责）

**实操底线**：你在网上发任何内容之前，假设这段话明天会出现在你老板/客户/家人的手机上——如果你仍然愿意发，那再发。

### 5.3 知识产权基础
在日常工作学习中，你和他人的常见权利边界：
- 你在职期间完成的工作成果（代码、设计、文档），如果属于"本职工作"或"主要利用单位资源完成"→ 著作权归单位（除非合同另有约定）
- 自由职业者为客户创作的成果 → 必须以合同明确约定知识产权归属，否则默认归受托人（创作者）
- 转载他人文章 → 需要授权，合理引用除外
- 使用开源代码 → 必须遵循其 License 条款（MIT、GPL、Apache 等区别很大，但这是另一个专题）

## 六、婚姻与家庭

### 6.1 夫妻财产
- 婚前财产：各自所有
- 婚后财产：原则上共同所有（不论谁挣的，不论登记在谁名下）
- 可以约定财产各自所有（需要书面形式）
- 婚前按揭房：婚后共同还贷的部分及对应的增值部分 = 共同财产

### 6.2 继承法基础
法定继承顺序（在没有遗嘱的情况下）：
- 第一顺序：配偶、子女、父母（平均分配）
- 第二顺序：兄弟姐妹、祖父母、外祖父母（只有在没有第一顺序继承人时才能继承）

遗嘱继承优先于法定继承——所以如果有特殊意愿，立一份自书遗嘱（亲笔书写 + 签名 + 年月日）是有法律效力的，不需要公证。

## 七、刑事法律意识

### 7.1 你不需要记住法条，但需要知道这些边界

| 行为 | 对应罪名（可能） | 说明 |
|------|----------------|------|
| 把银行卡/身份证借给别人 | 帮助信息网络犯罪活动罪 | 你的卡可能被用于洗钱/诈骗——不是开玩笑 |
| 酒后驾驶（≥80mg/100ml） | 危险驾驶罪 | 入刑标准，不是罚个款就能解决 |
| 在网上传播淫秽物品 | 传播淫秽物品罪 | 包括"发小群"——一旦传播即构成 |
| 大规模或多次泄露他人个人信息 | 侵犯公民个人信息罪 | 非法获取/出售/提供公民个人信息 |
| 网络刷单 / 虚假交易 | 非法经营罪 / 虚假广告罪 | 特别是组织化、大规模的刷单行为 |

### 7.2 遇到法律问题的基本应对
1. **保存证据是第一位**——没有证据，一切免谈
2. **不要在情绪中做决定**——冷静后再沟通
3. **咨询专业人士的时间远比你想象得早**——大多数人找律师的时间太晚了，证据已经无法挽回
4. **不要想当然**——法律中有很多"反常识"的规定，"我觉得应该是这样"在法律上往往不成立

## 八、学生群体高频法律场景

### 8.1 校园中
- 校园霸凌：学校有法定职责防止和处理——不要只找班主任，保留证据并向校领导/教育局投诉
- 考试作弊入刑：在高考等国家考试中组织作弊已被列入刑法——对代考、提供作弊设备等行为都可以追究刑事责任
- 校园贷/培训贷：诱导学生签下高息贷款合同可能构成欺诈——保留证据 + 报警 + 向金融监管部门投诉

### 8.2 实习/兼职中
- 试用期也需要签合同——哪怕是 3 天试用/试岗也有劳动关系
- 培训费/押金/扣留证件——都是违法的（劳动合同法第 9 条明确禁止）
- 口头承诺的"转正后 XX 工资"没有任何约束力——白纸黑字写进合同
