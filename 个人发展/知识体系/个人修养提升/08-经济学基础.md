# 经济学基础

## 一、经济学思维的核心

### 1.1 经济学的第一性原理
**稀缺性（Scarcity）**：人的欲望总是超过可用的资源。如果资源是无限的，经济学会消失——因为没有"选择"的必要。

稀缺性 → 必须做选择 → 每一次选择都有放弃 → 所以每一次选择都有成本。

### 1.2 机会成本——最重要的经济学概念
**机会成本就是你为了做一件事而放弃的第二好的选择的价值。**

注意：
- 机会成本不是"你付出的钱"——那叫会计成本
- 机会成本是"你本可以做但没有做的最有价值的那件事"
- 免费的东西永远不免费——你花了时间，这段时间本可以用来做别的事

**用机会成本思维做决策**：
不问你"做这件事要花多少钱/多少时间"，而问你"如果不做这件事，你的最优替代方案是什么？做这件事和做那件事相比，哪个收益更高？"

这不是一个"算大账"的问题——改变的是你如何评价一个选择的真正成本。

### 1.3 边际思维
经济学中大多数决策不是在"做 vs 不做"之间，而是在"多做一点 vs 少做一点"之间。

**边际效用递减**：你吃的第一口蛋糕和第十口蛋糕带来的满足感完全不同。几乎所有事物的边际效用都递减。

**边际成本 vs 边际收益**：
- 你该不该再学一小时？→ 问：最后一小时的收益（边际收益）大于最后一小时的疲劳（边际成本）吗？
- 软件公司该不该再加一个功能？→ 问：这一个功能带来的新增用户收入大于开发它的成本吗？

## 二、微观经济学基础

### 2.1 供给与需求
需求定律：价格上升 → 需求量下降（其他条件不变）
供给定律：价格上升 → 供给量上升（其他条件不变）

**需求变动 vs 需求量变动**：
- 需求量变动 = 价格变了，在需求曲线上移动（内生）
- 需求变动 = 价格以外的因素变了，整条需求曲线平移（外生）

影响需求变动的因素（移动整条需求曲线）：
- 收入变化（正常品 vs 劣等品）
- 替代品价格（竞品降价 → 你产品的需求下降）
- 互补品价格（汽油涨价 → 大排量车需求下降）
- 消费者偏好/潮流变化
- 预期

### 2.2 弹性
弹性衡量"一个变量对另一个变量变化的敏感程度"。

**需求价格弹性** = 需求量变动百分比 ÷ 价格变动百分比

| 弹性类别 | 含义 | 定价策略含义 |
|---------|------|------------|
| 弹性 > 1（富有弹性） | 涨价总收益下降 | 降价促销有效 |
| 弹性 < 1（缺乏弹性） | 涨价总收益上升 | 可以通过提价增收 |
| 弹性 = 1（单位弹性） | 价格变动不影响总收益 | 价格策略空间小 |

影响弹性的因素：
- 替代品越多 → 弹性越大（你涨价我就买别人）
- 必需程度越高 → 弹性越小（大米涨价你还是得吃）
- 在总支出中占比越小 → 弹性越小（盐涨价 50% 你可能根本不在乎）
- 时间越长 → 弹性越大（短期你只能忍，长期你可以换）

### 2.3 市场结构

| 市场类型 | 厂商数量 | 产品差异 | 进入壁垒 | 例子 |
|---------|---------|---------|---------|------|
| 完全竞争 | 极多 | 无 | 无 | 农产品市场 |
| 垄断竞争 | 多 | 有 | 低 | 餐馆、服装品牌 |
| 寡头垄断 | 少数几家 | 有/无 | 高 | 电信、航空、搜索 |
| 完全垄断 | 1 家 | — | 极高 | 部分公用事业 |

大部分你接触的市场是"垄断竞争"或"寡头"——不是教科书里的完全竞争。

### 2.4 市场失灵
市场不是万能的——以下情况中，自由市场无法达到最优结果：
- **外部性**：你的行为影响了他人却没有为此付费/获得补偿（污染、吸烟、教育的外溢效应）
- **公共物品**：非竞争性 + 非排他性 → 市场供给不足（灯塔、国防、基础科研）
- **信息不对称**：交易一方比另一方掌握更多信息（二手车、保健品、金融产品）
- **垄断力量**：一个卖家可以影响市场价格

## 三、宏观经济学基础

### 3.1 GDP 是什么，不是什么
GDP = 在一个国境内一定时期内生产的全部最终产品和服务的市场价值。

**GDP 不包括**：
- 二手交易（买二手手机不算）
- 金融交易（买卖股票不算——但券商收的佣金算）
- 转移支付（养老金、低保——这些是钱的转移不是价值的创造）
- 地下经济（理论上应该算，实际上统计不到）
- 自给自足（你自己种菜自己吃不算）

**GDP 告诉你什么**：一个国家的总产出规模
**GDP 不告诉你什么**：分配是否公平、环境是否在变差、人们是否幸福

### 3.2 通货膨胀
通胀 = 整体物价水平的持续上涨。

**通胀的类型**：
- 需求拉动型：经济过热 → 需求 > 供给 → 价格涨
- 成本推动型：能源/原材料/人工涨价 → 企业转嫁给消费者
- 预期自我实现型：大家都预期物价要涨 → 现在抢购 → 物价真的涨了

**通胀对普通人意味着什么**：
- 现金一直在贬值——存银行活期 = 确定性地亏钱
- 持有实物资产（房产、黄金）或生产性资产（优质公司的股票）是对冲通胀的传统方式
- 但通货膨胀是个体无法控制的外部冲击——合理分配，不要因为"钱在贬值"而冲动"投资"然后亏更多

### 3.3 货币与利率
- 央行通过调控利率来影响经济：降息 → 借钱更容易 → 消费/投资增加 → 经济升温
- 加息 → 借钱变贵 → 消费/投资减少 → 经济降温
- 利率也是所有资产定价的"基准锚"——长期利率上升，股票、债券、房产等各类资产的估值都会重新评估

## 四、行为经济学

### 4.1 前景理论（Prospect Theory）
传统经济学假设人是理性的——行为经济学说不是。

**核心发现：损失厌恶（Loss Aversion）**
失去 100 块钱的痛苦 ≈ 获得 200 块钱的快乐（损失比收益感受强约 2 倍）。

这意味着：
- 你为什么舍不得丢掉你已经不看但花了钱买的书？
- 为什么炒股会"卖了就涨，拿着就跌"——因为你更倾向于卖赚的（落袋为安）拿着亏的（不想确认损失）
- 为什么"免费试用后自动扣费"这么有效？因为试用期间你把这东西当成了"已拥有的"，取消 = 损失

### 4.2 心理账户
同样金额的钱，在不同心理账户中的价值不同：
- 中彩票的 5000 块 → 随意花掉
- 工资攒的 5000 块 → 舍不得动

在经济学上它们完全一样，在心理上完全不同。商家利用这一点：年终奖 ≠ 工资——在你的心理上区分了，所以你更愿意在年终奖到账时冲动消费。

### 4.3 锚定效应
你的判断会被你最先看到的信息"锚住"：
- 门店先标一个高得离谱的原价，再划掉，写上"折后价"。——你知道原价是假的，但你的估算还是被这个锚影响了
- 谈判时第一个出价方为自己定下了优势位置——之后所有的还价都会围绕这个锚
- 这也是为什么"首次报价"如此重要

### 4.4 选择架构与助推（Nudge）
Richard Thaler 的核心理念：你如何呈现选项极大地影响人们的选择——而设计选项的人可以"助推"人们向某个方向选择，但不限制他们的自由。

- 默认选项：退休储蓄计划——默认参与（opt-out）vs 默认不参与（opt-in）→ 参与率相差巨大
- 在餐厅把健康食品放在眼睛平视的位置 → 人们更可能选它

**思考工具**：你每天做的"选择"有多少是真选择，有多少是别人设计好的选择架构？

## 五、与日常生活相关的经济学

### 5.1 复利
复利不只是投资概念——它是一个思维框架，适用于任何"积累"的场景。

**复利的两面**：
- 正面：每天进步 1%，一年后 = 37.8 倍
- 负面：每天退步 1%，一年后 ≈ 0.03

**复利最关键的因素不是收益率——是时间**。
大部分人放弃不是因为收益率低，而是因为坚持的时间不够让复利曲线走出"看起来平"的初级阶段。

### 5.2 比较优势
为什么你应该做你最擅长的事，把其他事交给别人/外包？
- 绝对优势：你比别人做某件事快/好
- 比较优势：你在某件事上的优势远大于你在另一件事上的优势——即使你两件事都比别人强

→ **即使你在所有方面都比别人强，也应该专注于你最有比较优势的领域，用省下的时间做更多优势领域的事。**

例如：你是一个时薪 500 的程序员。自己打扫卫生花 2 小时 = 机会成本 1000 元。请保洁阿姨花 100 元 → 你赚了 900 元（虽然你打扫卫生可能也比保洁快——但你的时间在编程上的价值大于保洁上的价值，这就是比较优势）。

### 5.3 沉没成本谬误
沉没成本 = 已经发生、无法回收的成本。
理性决策应该只基于**未来的成本和收益**，而非已经花掉的钱/时间/感情。但人做不到。

- "这个电影不好看但我花了 60 块钱买票" → 你继续忍受 2 小时。这 60 块钱在你决定继续看 or 走人的那一刻已经是沉没成本了，不应该影响你的决策
- "这个专业我读了 3 年不想干了但我已经花了 3 年" → 这 3 年已经沉没了，你唯一该问的是：从今天开始，转行的未来价值高还是继续读的未来价值高

## 六、日常决策的经济学清单

面对每个重要决策，依次问：
1. 这个选择的机会成本是什么？（我的次优方案是什么？）
2. 这件事的边际收益还大于边际成本吗？（还是只是"惯性"在驱动？）
3. 我有没有被沉没成本绑架？
4. 我看到的这个"价格"有没有被锚定效应扭曲？——原价是多少？和谁比？
5. 我是真的需要还是被选择架构推向了这个决策？
