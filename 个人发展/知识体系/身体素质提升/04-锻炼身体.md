# 锻炼身体

## 一、锻炼的基本原则

### 1.1 变强的唯一原理：渐进超负荷
身体变强不是因为你"练了吧"，而是因为你**施加了略大于当前能力的刺激，身体在恢复期间适应了并覆盖了更强的能力**。

```
训练刺激 → 身体疲劳（短期能力下降）→ 恢复（超量恢复）→ 能力提升

如果你每次训练给身体的刺激和上次一样 → 身体早已适应 → 不会变强
如果你给的刺激远大于恢复能力 → 过度训练 → 能力不升反降
```

### 1.2 渐进超负荷的三个维度
| 维度 | 如何渐进 | 例子 |
|------|---------|------|
| 强度 | 增加重量、缩短休息 | 上周深蹲 40kg × 8 次 → 本周 42.5kg × 8 次 |
| 容量 | 增加组数、次数 | 上周卧推 3 组 × 8 次 → 本周 4 组 × 8 次 |
| 频率 | 增加训练次数 | 从每周 2 次 → 每周 3 次 |

**新手第一年**：优先增加重量（神经适应的初期效果被隐藏），但不要每周硬提——每 2-3 周尝试加 2.5-5kg。当无法再举起来时（技术变形严重），优先增加组数和次数（容量）。

### 1.3 坚持 > 强度
```
每周 3 次 × 45 分钟 × 1 年 = 约 70 小时
每周 1 次 × 120 分钟 × 2 个月 = 约 16 小时（然后放弃了）

长期 × 小剂量 ≫ 短期 × 大剂量
```

## 二、新手入门完整方案

### 2.1 训练前的三个准备
1. **热身（5-10 分钟）**：轻度有氧（快走/慢跑/跳绳/开合跳）+ 动态拉伸（关节活动+核心激活）
2. **确认本次训练目标**：聚焦一个主项（如"今天重点关注深蹲的膝盖稳定性"）
3. **检查装备**：穿平底鞋（不是跑步鞋——跑步鞋的软底在深蹲时让你无法稳定发力）、运动服

### 2.2 全身训练方案（每周 3 次，每次 45 分钟）

**每周一/三/五 模板**：
```
A 部分：主力量（核心动作，重点）—— 20 分钟
  动作 1：深蹲（下肢）—— 3 组 × 10 次
  动作 2：卧推（上肢推）—— 3 组 × 10 次
  动作 3：划船（上肢拉）—— 3 组 × 10 次

B 部分：辅助训练（补弱项）—— 15 分钟
  动作 4：硬拉（后链）—— 3 组 × 8 次
  动作 5：推举/侧平举（肩部）—— 3 组 × 12 次
  
C 部分：核心 + 拉伸 —— 5-10 分钟
  平板支撑：3 组，直到力竭
  静态拉伸：臀、腿、胸、背各 20 秒
```

### 2.3 动作标准（比重量更重要）

**深蹲**：
```
脚距与肩同宽或略宽，脚尖略外开
下蹲时膝盖方向和脚尖方向保持一致
背部打直（想象胸往上抬，不是往前伸）
下蹲深度：大腿至少到平行地面（或更低，看髋踝活动度）
重心全脚掌，不翘脚尖不翘脚后跟

常见错误：膝盖向内塌、上半身前倾太多、重心在前脚掌
```

**卧推**：
```
平躺在凳子上，眼睛在杠铃杆正下方
握距：杠铃下到胸口时，前臂垂直于地面
下落点在胸骨（乳头水平），推起到手臂伸直但不锁定肘关节
全程肩胛骨夹紧、下沉
脚平踩地面，膝盖不超过脚尖，臀部不离开凳面

常见错误：握距太宽（手腕痛）、肩膀往前耸（导致肩袖损伤）、杠铃推到了锁骨方向（废肩）
```

**硬拉**：
```
脚距臀部宽，杠铃在脚中上方（靠近小腿）
下蹲到手能抓杠的位置，背部打直
拉起：挺胸、背收紧、杠铃贴近小腿沿身体拉到大腿
放下：髋部后推，杠铃沿同一轨迹回到地面

常见错误：背弓着拉（必伤腰）、杠铃离身体太远（增加腰椎受力臂矩）、拉时先伸直腿导致臀位太高
```

**划船**：
```
腰部打直，上半身前倾约 45-60°
手臂自然下垂抓杠
向腹部方向拉至触腹（肘部向后飞）
慢慢地控制回落
整个动作中腰不能弯曲

常见错误：用反冲力（借力）拉、拉的位置在胸部（前臂力量不够的补偿动作）
```

### 2.4 组间休息
- 力量训练（肌肥大/力量）：60-90 秒
- 耐力训练（15+ 次）：30-60 秒
- 爆发力训练（1-3 次）：2-3 分钟

## 三、如果不想去健身房

### 3.1 自重训练方案（全身，零器械）
```
循环 3 轮，每轮间休息 2 分钟：

1. 深蹲（自重）—— 20 次
2. 俯卧撑 —— 到力竭（做不了一个标准 → 用跪姿或手放在桌子/窗台上做）
3. 弓步蹲 —— 每条腿 12 次
4. 超人式划船 —— 15 次（趴地上，手臂伸直往上抬起，模拟划船）
5. 平板支撑 —— 坚持到力竭
6. 仰卧臀桥 —— 15 次
```

### 3.2 弹力带训练（50 元以内的全套健身工具）
- 弹力带划船：踩住弹力带，双手拉起 → 替代杠铃划船
- 弹力带推举：踩弹力带，向上推 → 替代哑铃推举
- 弹力带臀桥：弹力带绕膝盖上方 → 增加臀桥阻力
- 弹力带侧步：弹力带绕脚踝 → 横向走（臀部激活最有效）

### 3.3 有氧替代
- 不一定要跑步——跳绳、爬楼梯、跟视频跳操、快的步行都是更不伤膝的选择
- 高强度短时间：20 秒全力做 + 10 秒休息 × 8 轮（Tabata）= 4 分钟，顶 20 分钟慢跑
- 但 Tabata 不是新手友好的——你必须能安全地做高速无误的动作。新手先从中低强度长时的稳态运动开始建立心肺基础

## 四、恢复与营养

### 4.1 恢复大于训练
肌肉不是在训练中变大——肌肉是在恢复期变大的。训练是刺激，恢复是生长环节。

**恢复的三要素**：
1. **睡眠**：训练日至少 7-8 小时。生长激素大多在深度睡眠中分泌
2. **营养**：训练后 1-3 小时内摄入蛋白质（约 20-30g）——不需要"必须在训练后 30 分钟内喝蛋白粉"，但尽量在 2-3 小时内完成蛋白质补充
3. **主动恢复**：休息日不完全"瘫着"——散步、轻度伸展、泡沫轴按摩皆有助于血液循环和肌肉修复

### 4.2 肌肉酸痛 ≠ 训练效果好
- 延迟性肌肉酸痛（DOMS）只是身体不适应新刺激的信号——不是你训练到位的标志
- 训练很久后仍每次都很酸 → 你可能训练频率太低、恢复不足或训练容量失衡
- 完全不酸 ≠ 没练到——身体适应了你的训练模式后酸痛减少是正常的

### 4.3 疼痛 ≠ 酸痛
| 肌肉酸痛（OK） | 关节/锐痛（STOP） |
|-------------|-----------------|
| 钝痛感，大面积 | 刺痛、局限在某个点 |
| 拉伸时会缓解（多巴胺释放） | 活动时加重、静止仍痛 |
| 通常对称（两侧都存在） | 通常单侧 |
| 2-3 天后好转 | 持续不消甚至加重 |

**关节/锐痛时**：停止该动作，找原因（动作不规范/重量超出能力/热身不充分）。反复发生 → 看医生/物理治疗师，不要硬扛——关节损伤可能需要数月恢复。
