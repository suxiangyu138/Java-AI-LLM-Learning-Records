# 注意仪容仪表

## 一、仪容仪表的第一性原理

### 1.1 别人注意到的是什么
大部分人以为别人在评判"品牌/潮流/价格"——但实际上，别人（尤其是初次见面的前 7 秒）注意到的是：

| 优先级 | 别人注意到什么 | 你可以控制什么 |
|--------|-------------|--------------|
| 1 | 是否干净整洁 | 清洁、无异味、无皱褶 |
| 2 | 是否合身 | 肩线、袖长、裤长是否合适 |
| 3 | 整体色调协调性 | 不超过 3 个主色，基础色打底 |
| 4 | 场景匹配度 | 正式/休闲/运动场合的对应着装 |
| 5 | 细节与质感 | 面料、配饰、鞋子的品质 |
| 6 | 品牌/标签 | 几乎没有人真正在意 |

**投资优先级**：合身 > 质感 > 品牌。一件 200 元但合身的衬衫效果远好于一件 2000 元但不合身的。

### 1.2 "形象管理 ≠ 虚荣"
你的着装=你在重要场合的非语言沟通。就像你不会给客户看没有排版的代码一样——你得体的着装是"我尊重这个场合，也尊重你"的表达。

## 二、基础打理

### 2.1 日常仪容 checklist
**每天**：
- [ ] 洗脸 + 保湿（男女都需要。保湿不是化妆——是防止皮肤干燥脱屑的基本手段）
- [ ] 口腔清洁（刷牙 + 用牙线/漱口水。口气是社死第一杀手）
- [ ] 头发整洁（洗/梳，不油不翘）
- [ ] 指甲干净（修剪整齐，无污垢）

**每周**：
- [ ] 修剪鼻毛/耳毛
- [ ] 修整眉毛（去掉中间的连眉，不一定要做精致眉形，但不要杂乱无章连成一片）
- [ ] 清理耳朵（轻轻清理外耳道可见的污垢，不要往深处捅）

### 2.2 气味管理
- 每天使用止汗露/除臭剂（尤其在夏天——不是"有没有狐臭"的问题，是每个人都会出汗发酵产生细菌分泌物）
- 香水/古龙水：少比多好——别人应该在你经过时闻到淡淡的，而不是你在 5 米外就宣告了你的到来
- 洗衣频率：贴身衣物（T 恤、内搭、内衣）穿一次洗一次，裤子和外套可穿 2-4 次。主要看贴肤度和出汗情况

## 三、穿搭基础

### 3.1 合身度——最核心的标准

**上装合身标准**：
| 部位 | 标准 |
|------|------|
| 肩线 | 缝线正好在肩膀的拐角处，不内缩不外掉 |
| 袖长 | 长袖衬衫：袖口到手腕骨处，抬手时袖口不回缩到前臂中间 |
| 衣长 | T 恤/衬衫下摆在裤子拉链中部或略下（不过臀） |
| 胸围 | 扣上所有扣子，能塞进 1-2 根手指 |

**下装合身标准**：
| 部位 | 标准 |
|------|------|
| 腰围 | 不系皮带也不会滑落 |
| 裤长 | 直筒裤：前裤腿刚好碰到鞋面（略垂一个小褶），后裤腿刚盖住鞋底上沿 |

### 3.2 色彩搭配入门

**三个颜色的分配**：
```
主色（60%）：大面积——外套、裤子、裙子
辅色（30%）：中等面积——上衣、衬衫
强调色（10%）：小面积——鞋子、包、领带、围巾、手表带

基础色（安全色）：黑、白、灰、海军蓝、卡其/米色
这几种颜色之间任意搭配都不会出错。
```

**最安全的搭配方案**（男女通用）：
```
方案 A：白色上衣 + 深蓝色裤子 + 白色鞋子
方案 B：黑色上衣 + 灰色裤子 + 黑色鞋子
方案 C：海军蓝上衣 + 卡其色裤子 + 棕色鞋子
方案 D：灰色上衣 + 黑色裤子 + 白色鞋子
方案 E：全黑 + 一个亮色/金属质感的配饰
```

### 3.3 必备单品清单

**男性基础衣橱**（12 件就能覆盖 90% 场景）：
```
上装：
  1. 白色牛津衬衫 × 1 → 面试、正式场合
  2. 白色 T 恤 × 2（一厚一薄）→ 打底、休闲单穿
  3. 灰色/黑色 T 恤 × 1 → 休闲
  4. 休闲衬衫（浅蓝/格子）× 1 → 日常

下装：
  5. 深蓝色牛仔裤 × 1 → 日常百搭
  6. 卡其色斜纹裤 × 1 → 商务休闲
  7. 黑色西裤 × 1 → 正式场合

外套：
  8. 灰色/海军蓝西服外套 × 1 → 正式、半正式
  9. 简约夹克/棒球服 × 1 → 日常休闲

鞋子：
  10. 白色运动鞋/板鞋 × 1 → 日常
  11. 棕色/黑色皮鞋 × 1 → 正式

配饰：
  12. 简单的皮带（和鞋子同色）
```

**女性基础衣橱**（同样简化思路）：
```
核心：
  1. 白色衬衫 × 1
  2. 质感白 T 恤 × 1
  3. 黑色小高领打底 × 1
  4. 深蓝色直筒牛仔裤 × 1
  5. 黑色直筒裤 × 1
  6. 小黑裙 × 1
  7. 西装外套 × 1（黑/灰/海军蓝）
  8. 风衣/长款外套 × 1
  9. 白色运动鞋 × 1
  10. 黑色低跟鞋/平底鞋 × 1
```

### 3.4 场景穿搭快速判断
| 场景 | 关键词 | 参考 |
|------|--------|------|
| 面试 | 正式的一点 | 宁可稍微正式过度，不要随意（西装/衬衫不会错，但西装配球鞋或 polo 衫配大 logo 太减分） |
| 上班日常 | 商务休闲 | 衬衫/简约上衣 + 直筒裤 + 干净的鞋 |
| 约会 | 干净+用心的 | 基础搭配 + 一个亮点配饰（表明你在意这次见面） |
| 聚会 | 个人风格 | 可以比日常更大胆一点的配色/风格 |
| 运动/户外 | 功能性 | 运动装就是运动装——穿得像要去运动而不是"运动风"日常穿 |

## 四、体态与外在形象

### 4.1 站姿与体态
- 从侧面看：耳朵-肩关节-髋关节-膝关节-踝关节大致在一根铅垂线上
- 改善方法：每天背靠墙站立 3 分钟——后脑勺、肩胛骨、臀部、小腿肚、脚后跟全贴墙
- 走路时：眼睛平视前方 10-15 米，不走神刷手机低头走路

### 4.2 皮肤护理（男女通用基础版）
```
早：清水/温和洁面 → 保湿乳液 → 防晒霜（SPF 30+）
晚：温和洁面 → 保湿乳液

防晒是性价比最高的抗衰单品。不是怕黑——是防止紫外线造成的光老化。
光老化的累积贯穿成年后的一生，而且只要白天出门就可以涂（包括阴天和冬天）。
```

## 五、快速改进形象的最高回报行动
如果你只有 30 分钟和一个周末来改进形象：

**今天**：
- 检查衣柜里 3 件最常穿但最不合身的衣服，拿给裁缝修改/捐掉替换
- 把衣服全部熨一次（或使用免熨喷雾/干衣机除皱）

**本周**：
- 预约一个好理发师，把头发修剪整齐
- 检查所有鞋子是否干净，不干净的擦/刷干净

**这个月**：
- 建立基础衣橱的核心单品
- 养成每日防晒 + 保湿的习惯
