# 职业伦理素养

## 一、职业伦理的核心原则

### 1.1 职业伦理不是"好人准则"
职业伦理不是关于你个人是不是好人，而是关于你在承担某个社会角色时所接受的行为准则。一个好人也可能在职业角色中犯错——因为他混淆了"对人的忠诚"和"对职业角色的尽责"。

### 1.2 利益冲突原则
**核心规则**：当你的个人利益（经济、关系、职业前途）与你的职业责任可能发生冲突时，你必须：
1. 先自我识别——这个冲突是否已经/将会发生
2. 向相关方披露——透明的告知在多数情况下可以避免后续的道德和法律问题
3. 回避决策——在你有利益冲突的事项上，不应该参与决策过程

**日常场景**：
- 你的亲戚开了一家供应商公司——你能参与选择供应商的决策吗？→ 可以推荐，但必须披露关系并回避决策
- 你在面试中发现面试官是你的前同事——他在评估你时有偏袒吗？你需要向其他面试官/HR 声明一下吗？→ 披露关系比回避更能建立信任

### 1.3 纽约时报测试法
如果你的某个决定或行为明天登上了《纽约时报》头版——你会感到不安吗？这是一个高度简化的伦理判断工具——但你面对复杂情境、没有明确规则时，直觉层面的不安是一个可信的信号源。

## 二、各职业场景中的伦理

### 2.1 教师/教育工作者的职业伦理
- **核心责任**：以学生的成长和发展为中心，不利用学生/家长的信任和信息不对称获利
- **公平义务**：对所有学生公平对待——不因个人喜好/家长送礼/学生成绩而差异化对待
- **边界意识**：师生关系是专业的，不是私人的。在社交媒体上与学生保持适当的边界（不参与学生的私人社交话题、不要求学生加你的私人账号等）
- **隐私与保密**：学生的成绩、家庭状况、个人问题——未经同意不得向第三方透露（即使是"和家长沟通"也要注意信息的边界）
- **诚实教学**：不夸大广告效果（"7 天提 50 分"）、不使用虚假的学员案例、不故意用焦虑引导学生报更贵的课程

### 2.2 技术人员的职业伦理
- **代码诚信**：不故意写留有后门的代码；不在代码中埋藏不合规的数据收集；不篡改数据或日志以掩盖错误
- **安全告知**：发现系统安全漏洞时先报告给相关方而不是公开宣扬或私下利用
- **知识产权尊重**：不使用盗版软件/代码/素材做商业产品；遵守开源协议
- **能力边界**：对自己不擅长的技术领域坦诚说明，不为了拿项目夸自己的能力——结果会反噬你和整个团队

### 2.3 职场通用伦理
- **时间与资源的诚实使用**：不虚报工时、不用公司资源做纯粹的私人项目（哪怕"没有人会发现"）
- **信息保密**：离职后不带走或使用前雇主的机密信息（文档、代码库、客户名单）
- **不进行内幕交易或利用信息不对称获取私利**——任何基于"只有我知道"的信息而做出的利益获取都需要问自己：如果别人也知道了会怎么评价？
- **职场骚扰零容忍**：任何形式的性骚扰、职场霸凌、歧视——都是职业伦理的红线，不是灰色地带
- **公平竞争**：不在面试/晋升/资源分配中利用私人关系获取不正当优势

## 三、伦理困境的处理框架

### 3.1 当两个原则冲突时
伦理困境通常不是"对 vs 错"——而是"对 vs 对"。比如：
- 诚实 vs 忠诚：你发现同事在项目中犯了一个大错，他请求你不要告诉领导
- 个体利益 vs 集体利益：不裁掉 5 个人公司就撑不下去，但这 5 个人都靠这份工作养家

**处理框架**：
1. 明确冲突的双方是什么原则——先把它们说清楚，不要笼统地说"我很难做决定"
2. 列出每种选择涉及的利益相关方（所有受影响的人）——还有谁的声音没被听到？
3. 有没有"第 3 种选择"？——很多时候困境是假困境，不需要在两个极端之间选择
4. 做决定后，你愿意公开解释你的决策理由吗？

### 3.2 组织压力下的个人伦理
当公司/领导要求你做一件你认为不道德的事情时：

- **阶梯式应对**：
  1. 先与直接上级口头沟通你的顾虑（就事论事，不攻击动机）
  2. 如果无效 → 书面（邮件）留下沟通记录
  3. 如果涉及违法 → 寻求法律咨询再做决定
  
- **避免的行动**：
  - 不要在情绪驱动下写激烈的公开邮件或社交媒体帖子
  - 不要单方面"替天行道"——内部渠道用尽之前不要认为你是唯一的正义执行者
  - 不要在没有确认事实的情况下做公开判断

### 3.3 告发（Whistleblowing）的考量
告发是伦理手段的最后手段——当内部渠道全部用尽且涉及重大公共危害时才应启动。启动前确认三点：
1. 你的信息是事实（不是推测、不是听说的）
2. 你已经给了内部机制合理的机会
3. 你做好了承担后果的心理准备（告发者有法律保护——但现实中仍然可能付出个人代价）

## 四、建立职业伦理的日常习惯

### 4.1 定期自我审视清单
- [ ] 最近有没有一件事，我在做的时候觉得"不太对劲"但我继续了？——为什么不停止？
- [ ] 有没有一个利益冲突我不确定是否应该披露？——不确定的时候就是应该披露的时候
- [ ] 我有没有利用职位/信息的不对称来获取对我不应得的利益？
- [ ] 如果有人用同样的方式对待我/我的家人，我能接受吗？

### 4.2 寻找你的伦理锚点
- 伦理决策最终需要个人锚点——外部的规则总有模糊地带
- 锚点可以是一个人（"XX 老师遇到这个情况会怎么做？"）、一个原则（"所有决定都要经得起公开检视"）、或一个场景（"如果我的孩子知道我做了这个决定..."
- 在你情绪平静的时候建立你的锚点——不要在面临伦理困境时才临时想"我的原则是什么"
