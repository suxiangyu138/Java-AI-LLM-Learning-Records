## ChatGPT 备考应用

### 场景 1：AI 批改作文

```
Prompt 模板：

"你是大学英语六级阅卷老师，请给以下作文打分（满分 15 分）并修改：

【作文题目】
[粘贴真题作文题目]

【我的作文】
[粘贴你的作文]

请按以下格式输出：
1. 评分：__/15
2. 扣分原因（3 条，按严重程度排序）
3. 每个段落的修改建议（给出修改后版本）
4. 这篇文章的高分改写（≥ 12 分水平）
5. 3 个可套用到其他作文的通用句式"
```

### 场景 2：AI 翻译校对

```
Prompt 模板：

"你是六级翻译阅卷老师，请给以下翻译打分并修改：

【原文中文】
[粘贴真题翻译原文]

【我的翻译】
[粘贴你的翻译]

请输出：
1. 核心信息是否完整（漏了哪些信息）
2. 语法错误（逐句标注）
3. 用词不当（逐词标注 + 替换建议）
4. 长句拆分建议（哪个句子应该拆成 2-3 句）
5. 修改后的完整译文"
```

### 场景 3：AI 讲阅读错题

```
Prompt 模板：

"我是六级考生，这道阅读题做错了，请帮我分析：

【原文段落】
[粘贴题目对应的原文段落]

【题目 + 选项】
[粘贴题目和所有选项]

【我的答案】C
【正确答案】A

请分析：
1. 正确选项 A 在原文中的依据是哪句话？（标出来）
2. 我选的 C 为什么错？（是偷换概念/过度推理/还是定位错误）
3. 这道题属于什么题型？（主旨/细节/推断/词义/态度）
4. 今后遇到同类题该怎么思考？"
```

### 场景 4：AI 出模拟题

```
Prompt 模板：

"请模仿英语六级考试风格，出 1 套完整的 Section C 仔细阅读：
2 篇文章，每篇 5 道题（共 10 题）

要求：
- 文章长度 350-400 词
- 主题：科技与社会（符合六级常考话题）
- 难度：中等偏上
- 题型分布：主旨题 1 道 + 细节题 3 道 + 推断题 2 道 + 词义题 1 道 + 态度题 1 道
- 每道题 4 个选项，标注正确答案
- 附详细解析（说明每个错误选项为什么错）"
```

## Claude 备考应用

### 场景 1：长难句拆解

```
Prompt 模板：

"这个英语长难句我看不懂，请帮我逐字拆解：

[粘贴长难句]

请拆解为以下格式：
1. 主句主干（主语/谓语/宾语）
2. 从句分析（定语从句/状语从句/名词性从句，修饰谁）
3. 分词结构/插入语/同位语 各自的作用
4. 整句话的逻辑关系图（用缩进表示层级）
5. 中文翻译（保留原句结构）
6. 简化版改写（用初中英语词汇表达相同意思）"
```

### 场景 2：语法专项讲解

```
Prompt 模板：

"我在六级翻译中不会用被动语态，请用以下结构教我：

1. 被动语态在六级翻译中什么时候必须用？（3 种必用场景）
2. 每种场景给出 2 个真题例句（中英对照）
3. 常见错误（3 个：漏 be 动词 / 忘过去分词 / 错用主动）
4. 5 道改错题（给我错句，让我改成被动语态，再给答案）"
```

## AI 使用注意事项

```
✅ 可以做的：
  - 让 AI 批改作文翻译（比大多数同学改得好）
  - 让 AI 分析阅读错题原因
  - 让 AI 出模拟题检验自己
  - 让 AI 讲语法（比语法书生动）
  - 让 AI 把长难句拆解成主谓宾

❌ 不要做的：
  - 让 AI 替你写作文（背不下来，考场不会）
  - 让 AI 替你翻译（你不会学到东西）
  - 完全用 AI 生成的答案代替自己思考
  - 过度依赖 AI 而减少真题练习（真题才是考试标准）

原则：AI 是你的私人英语老师，不是你的替考枪手
```

|------|------|---------|

| 出模拟题 | ChatGPT | 可以灵活定制难度和题型 |
