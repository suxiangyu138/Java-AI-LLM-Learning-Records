# 写作极简攻略 —— 106.5 分稳拿计划

## 题型速览

| 项目 | 说明 |
|------|------|
| 题型 | 议论文 / 说明文 / 应用文 |
| 字数 | 150-200 词 |
| 时间 | 30 分钟 |
| 分值 | 106.5 分（15%） |
| 建议用时 | 5 分钟构思 + 20 分钟书写 + 5 分钟检查 |

---

## 评分标准

```
阅卷老师 30 秒定档：

一档（13-15 分）：内容切题 + 结构完整 + 语言流畅 + 有高级表达
二档（10-12 分）：内容切题 + 结构完整 + 少量语法错误
三档（7-9 分）：基本切题 + 结构有缺陷 + 较多语法错误
四档（4-6 分）：偏题 / 语法错误严重 / 字数不足
五档（1-3 分）：离题 / 无法阅读

关键：不跑题 + 结构完整 = 至少 10 分（二档）
```

## 三段式万能模板

### 模板 1：议论文（How to / Why / Should）

```
┌──────────────────────────────────────────────────┐
│ 开头段（2-3 句，~40 词）                           │
├──────────────────────────────────────────────────┤
│ ① 背景引入                                       │
│ ② 引出观点                                       │
│                                                  │
│ 模板：                                           │
│ Nowadays, [话题] has become a heated topic.       │
│ There is no doubt that [观点].                   │
│ From my perspective, the reasons are as follows.  │
├──────────────────────────────────────────────────┤
│ 主体段（6-8 句，~100 词）                         │
├──────────────────────────────────────────────────┤
│ ③ 论点 1 + 支撑 + 举例                           │
│ ④ 论点 2 + 支撑 + 举例                           │
│ ⑤ 论点 3 + 支撑 + 举例                           │
│                                                  │
│ 衔接词：                                         │
│ First and foremost, ...                          │
│ Furthermore / Moreover, ...                      │
│ Last but not least, ...                          │
├──────────────────────────────────────────────────┤
│ 结尾段（2-3 句，~30 词）                          │
├──────────────────────────────────────────────────┤
│ ⑥ 总结观点                                       │
│ ⑦ 展望/建议                                      │
│                                                  │
│ 模板：                                           │
│ In conclusion, [复述观点] is of great significance.│
│ Only by doing so can we [展望未来].               │
└──────────────────────────────────────────────────┘
```

### 模板 2：图表作文

```
开头：As is vividly shown in the chart/graph, [描述数据趋势].
      The figure reveals that [提取核心信息].

主体：There are several factors accounting for this phenomenon.
      Firstly, ... Secondly, ... Thirdly, ...

结尾：From what has been discussed above, we can predict that [趋势预测].
```

### 模板 3：应用文（书信/邮件）

```
Dear [称呼],

I am writing to [写信目的].

[主体内容 3-4 句]

I would appreciate it if you could [期望行动].
I am looking forward to your early reply.

Yours sincerely,
[署名]
```

## 高级词汇替换表

| 基础词 | → 高级替换 | 使用场景 |
|--------|-----------|---------|
| important | crucial / significant / vital | 表达重要性 |
| many | numerous / a great many | 表达数量 |
| more and more | increasingly / a growing number of | 表达趋势 |
| think | hold the view that / from my perspective | 表达观点 |
| good | beneficial / favorable / positive | 正面评价 |
| bad | harmful / detrimental / negative | 负面评价 |
| because | due to / owing to / on account of | 表达原因 |
| but | however / nevertheless / whereas | 表达转折 |
| should | be supposed to / it is advisable to | 表达建议 |
| very | extremely / remarkably / considerably | 程度强化 |
| help | contribute to / facilitate | 表达帮助 |
| want | intend to / be inclined to | 表达意愿 |
| solve | address / tackle / cope with | 解决问题 |
| use | utilize / adopt / employ | 表达使用 |

## 高频衔接词

```
# 顺序
Firstly / First and foremost
Secondly / Furthermore / Moreover
Thirdly / Last but not least

# 转折
However / Nevertheless / Nonetheless
On the contrary / In contrast
Whereas / While

# 因果
Therefore / Consequently / As a result
Due to / Owing to / On account of
Hence / Thus / Accordingly

# 举例
For instance / For example
A case in point is ...
Such as / Take ... as an example

# 总结
In conclusion / To sum up / In summary
All in all / On the whole
Briefly stated / In a nutshell
```

## 时间分配

```
分钟 0-5：审题 + 列提纲
  - 圈出题目的关键词
  - 决定用哪个模板
  - 列出 3 个论点（只需关键词，不用写完整句子）

分钟 5-25：写作
  - 开头 5 分钟
  - 主体 12 分钟（每个论点 4 分钟）
  - 结尾 3 分钟

分钟 25-30：检查
  - 拼写错误（your/you're, their/there）
  - 主谓一致（he do → he does）
  - 时态一致性
  - 单复数
  - 冠词（a/an/the）
```

## 避坑清单

```
❌ 跑题：看到熟悉的词就套模板，结果写偏了
   ✅ 先读懂题目，圈关键词，确保模板方向正确

❌ 字数不够：写到 120 词就卡住了
   ✅ 模板自带 60-80 词，你只需要再写 80-100 词

❌ 全是短句：I think. It is good. We should.
   ✅ 每段至少 1 句复合句（定语从句 / 状语从句）

❌ 卷面脏乱：大量涂改
   ✅ 想好再写，发现错词用一条横线划掉即可

❌ 用不熟悉的词：为了高级而用生僻词结果拼错
   ✅ 用有把握的词，语法正确 > 词汇华丽
```

