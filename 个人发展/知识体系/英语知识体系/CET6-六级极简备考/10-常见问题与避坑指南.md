# 常见问题与避坑指南 —— 少走弯路的 20 条经验

## 高频 FAQ

### Q1：裸考能过吗？

```
四级 ≥ 500 分 → 裸考可能飘过 425（但不稳）
四级 < 500 分 → 裸考几乎不可能，需备考 30-60 天
四级刚好 425 → 必须系统备考，60 天起步

建议：不管四级多少分，至少做 1 套真题感受难度，
     再来判断自己需不需要备考。
```

### Q2：单词背了又忘怎么办？

```
核心原因：你在用"意志力"而不是"算法"背单词

解决方案：
1. 用墨墨背单词（艾宾浩斯曲线自动安排复习）
2. 每天新词 ≤ 100 个（超过会记不住）
3. 坚持 21 天才能看到效果（前 21 天都在"补欠账"）
4. 不要用单词书（书本不会自动安排复习间隔）

记忆规律：
  1 天后遗忘 60% → 复习 1 次 → 保留 7 天
  7 天后遗忘 50% → 复习 2 次 → 保留 30 天
  30 天后遗忘 30% → 复习 3 次 → 保留 90 天+
```

### Q3：听力完全听不懂怎么办？

```
诊断：
  完全听不懂 = 一个词都抓不到？
  → 词汇量不足 3000，先背单词

  能抓到几个词但连不成句子？
  → 需要精听训练（参考[[03-听力理解精练]] 5 步法）

  能听懂大意但不会做题？
  → 需要练预判 + 推理技巧

急救方案：
  精听 10 篇真题（每篇 5 步法完整执行）
  10 篇后正确率通常从 30% → 55%
  20 篇后通常达到 65%+
```

### Q4：阅读做不完怎么办？

```
原因诊断：
  阅读速度慢？
  → 练扫读技巧（只看首尾句找关键词）
  → 计时训练（每篇仔细阅读从 15 分钟压缩到 10 分钟）

  选词填空花太多时间？
  → 战略性放弃，最后做，剩几分钟蒙几个

  纠结某个题太久？
  → 2 分钟做不出就选一个标记，回头有时间再看
  → 不要在一个题上花 5 分钟

做题顺序：
  仔细阅读（20 分钟）→ 长篇阅读（10 分钟）→ 选词填空（10 分钟）
```

### Q5：作文写不出高级句式？

```
真相：六级作文不需要高级句式，只需要"语法正确 + 结构完整"

急救方案：
1. 背熟 3 个模板（议论文/图表/应用文）→ 见 [[02-写作极简攻略]]
2. 每段开头用 1 句复合句（定语从句 / 状语从句）
3. 用高级词汇替换基础词（important → crucial）

不要做的事：
- 用你不确定的生僻词（拼错扣分 > 高级词加分）
- 写超过 3 行的长句（容易出语法错误）
- 套用网上的"高分句型"但不理解含义
```

### Q6：考前 1 周怎么冲刺？

```
Day 7-5：每天 1 套完整真题（15:00 严格模拟）
Day 4：默写作文模板 3 个 + 翻译高频词 50 个
Day 3：复习错题本（只看红字标注的错误原因）
Day 2：重听 3 篇精听过的真题（1.5 倍速，找回听力感觉）
Day 1：下午去考场踩点，检查耳机，晚上 22:00 前睡觉
当天：午饭后只背作文模板，不刷题（保存精力）
```

## 考场避坑指南

### 致命错误 Top 5

```
🔴 错误 1：听力听完再涂卡
   后果：答题卡 1 被收走，听力 0 分（= 直接出局）
   纠正：边听边涂，没听清的选一个涂上，不回头改

🔴 错误 2：耳机没电 / 坏了
   后果：听力全蒙，35% 分值靠运气
   纠正：考前 1 天换新电池，带 1 副有线备用耳机
         提前 5 分钟调到指定频率试音

🔴 错误 3：作文先打草稿
   后果：草稿写完没时间誊写
   纠正：列提纲（3 分钟）→ 直接写在答题卡上

🔴 错误 4：阅读纠结某一题
   后果：10 分钟耗在 1 道题，后面 9 道题全蒙
   纠正：2 分钟无解 → 标记后跳过 → 做完全部再回头

🔴 错误 5：翻译一个字一个字扣
   后果：30 分钟只翻了 60%
   纠正：先快速通篇翻完（宁可粗糙），再回头润色
         不会的词写简单的替代词，不要留白
```

### 时间管理表

```
带上考场的手表（非智能手表）：

15:00  作文开始
       ├── 15:03 审题+提纲完成
       ├── 15:20 作文正文完成
       └── 15:25 检查完成

15:10  听力开始
       → 边听边涂卡，不犹豫不纠结
       → 15:40 交答题卡 1

15:40  阅读开始
       ├── 16:00 仔细阅读 2 篇完成（20 分钟）
       ├── 16:10 长篇阅读完成（10 分钟）
       ├── 16:20 选词填空完成（10 分钟）
       └── 16:20-16:40 翻译（20 分钟）
           如果翻译晚了，从选词填空借时间

16:40-17:25  检查答题卡 2
       □ 涂卡是否完整
       □ 翻译是否有明显语法错误
       □ 选词填空检查一遍词性
```

## 心态管理

### 考前焦虑破解

```
1. 做最坏打算：最坏结果是没考过，下次再考。
   六级可以无限考（不像考研一年一次），心态放平。

2. 目标分层：设 3 个目标
   底线目标 425（无论如何要达到）
   理想目标 500（正常发挥能达到）
   冲刺目标 550（超常发挥）

3. 不要和别人比：有人裸考 600，有人三次没考过。
   你的目标是"考过"，不是"比谁分高"。

4. 考前一天：下午去考场踩点 → 轻运动 → 洗澡 → 22:00 睡觉
   不要熬夜复习（考场上犯困 = 全盘皆输）
```

### 考试当天

```
午餐：7 分饱，不喝太多水
时间：14:15 到达考场（留 25 分钟缓冲）
必带：准考证 + 身份证 + 学生证 + 耳机 + 备用电池 + 2B 铅笔×2 + 橡皮
心态：我准备了 60 天，比 90% 的人准备得充分
```
