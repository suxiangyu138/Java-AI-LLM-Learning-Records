## 听力变速播放方案

### 工具：每日英语听力 App / VLC / PotPlayer

```
阶段一（Day 1-20）：1.0x 正常速度精听
阶段二（Day 21-35）：1.0x 精听 + 1.25x 泛听
阶段三（Day 36-45）：1.25x 精听真题
阶段四（Day 46-60）：1.5x 真题模拟

效果：1.5x 练习惯了，考场 1.0x 就像慢放一样
      每个单词都听得很清楚
```

## 单词背诵工具配置

### 墨墨背单词最佳配置

```
词书选择：
  "六级词汇闪过" → 选"高频词"+"中频词"（~2000 词）

每日设置：
  新学 100 个 + 复习系统自动计算（通常 50-80 个）
  每天实际背诵量 ≈ 150-180 词
  用时 ≈ 30 分钟

复习模式：
  "看英文回忆中文" 模式（六级不考拼写，只考认识）
  写作翻译词汇建议额外用"看中文回忆英文"模式

关键设置：
  打开"自动播放发音"（建立音-义连接，对听力有帮助）
```

## 备考笔记模板

### 错题记录格式

```markdown
## 2026.06 真题 - 听力 Section B Passage 2

### 错题统计
- 总题数：7
- 正确：4
- 错误：3
- 错误类型：词汇 1 / 语音 1 / 推理 1

### 错题详情

| 题号 | 错误类型 | 原因 | 纠正 |
|------|---------|------|------|
| 3 | 词汇 | phenomenon 不认识 | 现象 = phenomenon |
| 5 | 语音 | consequence 连读没听出 | 跟读 3 遍 |
| 7 | 推理 | 过度推断，原文只说"可能" | 原文用 may，答案也选 may |
```

## 免费资源利用

```
充分利用学校资源：

1. 图书馆：
   - 真题集借阅（不需要每本都买）
   - 英语学习期刊（China Daily / 英语世界）

2. 英语角 / 口语社团：
   - 练习口语，对听力也有帮助

3. 学校购买的数据库：
   - 新东方在线课程（很多学校买了使用权）

4. 学长学姐：
   - 借/买二手真题和词汇书（便宜 + 有笔记）
```
