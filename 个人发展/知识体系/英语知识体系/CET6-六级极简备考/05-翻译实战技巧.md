---

## 评分标准

```
阅卷老师关注的三个维度：

1. 内容完整度（最关键）
   - 核心信息是否传递到位
   - 不能漏掉重要内容
   
2. 语法准确性
   - 时态、语态、单复数
   - 主谓一致、从句结构
   
3. 表达地道度（加分项）
   - 高级词汇（不勉强）
   - 句式多样性

关键认知：翻译不是写作，不需要文采，只需要"说清楚"
```

---

## 核心翻译策略

### 策略 1：长句拆短 —— 最实用的技巧

```
原则：中文重意合（一个句子可以很长），英文重形合（需要断句）

❌ 直译：
中国是一个拥有五千年历史的文明古国，创造了灿烂的文化，
为世界文明发展做出了重要贡献。

✅ 拆译：
China is a country with 5,000 years of history. 
It has created a splendid culture. 
It has also made significant contributions to world civilization.

法则：中文用逗号的地方，英文考虑用句号断开
```

### 策略 2：主语补全

```
中文：可以省略主语（"要发展经济"）
英文：必须有主语 → 补充为 "We should develop the economy"

中文：无主语句 → 用被动语态
"已经采取了一系列措施" → "A series of measures have been taken"

中文：抽象主语 → 用 it 形式主语
"学好英语很重要" → "It is important to learn English well"
```

### 策略 3：不会的词用"降级表达"

```
遇到不会的专有名词，不掉进"死抠"的坑：

"春运" → 不会 Chunyun
  ✅ Spring Festival travel rush
  ✅ the peak travel season during Chinese New Year

"一带一路" → 不会 Belt and Road Initiative
  ✅ the Silk Road cooperation project
  ✅ 至少写成 BRI（首字母缩写也有分）

"雾霾" → 不会 haze/smog
  ✅ air pollution
  ✅ polluted air

原则：宁可写简单但正确的词，不写高级但拼错的词
```

## 5 种必会句式

```
句式 1：被动语态
中文："人们认为..." / "据报道..." / "应该..."
英文：It is believed that... / It is reported that... / ...should be done

句式 2：定语从句
中文："...的..."（前置定语）
英文：...which/that...

例："中国是一个拥有悠久历史的国家"
 → China is a country which/that has a long history.

句式 3：with 复合结构
中文："随着..." / "具有..."
英文：with + n. + adj./doing/done

例："随着经济发展" → with the economy developing
例："中国是一个具有五千年历史的国家"
 → China is a country with a history of 5,000 years.

句式 4：it 形式主语
中文："...是...的"（强调句型）
英文：It is ... that ...

例："正是改革开放改变了中国"
 → It was the reform and opening-up that changed China.

句式 5：not only...but also... 倒装
中文："不仅...而且..."
英文：Not only does ..., but it also ...

例："互联网不仅改变了购物方式，还改变了社交方式"
 → Not only has the Internet changed shopping, 
   but it has also changed social interaction.
```

## 时间分配

```
分钟 0-2：通读全文
  理解整体意思，标记不会翻的词

分钟 2-5：口头/草稿逐句拆解
  长句拆短句，确定每句的主语

分钟 5-25：逐句翻译
  每句翻译完检查：主谓宾完整？时态正确？单复数正确？

分钟 25-30：全文检查
  重点查：时态一致性 / 单复数 / 拼写错误
```

---

## 翻译自检清单

```
□ 每句英文都有主语吗？（中文可以省略，英文不行）
□ 时态统一吗？（全篇用一般现在时或现在完成时，不混用）
□ 被动语态用对了吗？（be + 过去分词）
□ 定语从句关系词对了吗？（人用 who，物用 which/that）
□ 单复数对了吗？（可数名词注意加 s）
□ 冠词加了吗？（a/an/the 该加的地方）
□ 不会的词用简单词替代了吗？（不要留白）
```
