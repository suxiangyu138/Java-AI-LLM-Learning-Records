# CET-6 考试概览与分数构成

## 基础信息速览

| 项目 | 内容 |
|------|------|
| 考试时间 | 每年 **6 月**、**12 月** 第三周周六 15:00-17:25 |
| 报名时间 | 考前 2-3 个月，`cet-bm.neea.edu.cn` |
| 报名条件 | CET-4 ≥ 425 分，本校报名 |
| 满分 | 710 分 |
| 及格线 | **425 分**（实际无官方及格概念，≥220 发放成绩单） |
| 口试 | 可选，笔试前一个月单独报名 |

---

## 分数构成

```
CET-6 总分 710
├── 写作    15%  = 106.5 分  (30 分钟)
├── 听力    35%  = 248.5 分  (30 分钟)
├── 阅读    35%  = 248.5 分  (40 分钟)
└── 翻译    15%  = 106.5 分  (30 分钟)
```

### 得分权重分析

```
听力 + 阅读 = 70% = 497 分  ← 核心拉分项
写作 + 翻译 = 30% = 213 分  ← 性价比高（投入少产出稳）

策略：听力阅读保下限，写作翻译提上限
```

## 考试流程时序图

```
14:40 ─────────────────────────────────────────── 进场，调试耳机
14:45 ───────────────────── 发答题卡 1 + 试题册
15:00 ───── 作文开始（30min）──────────────────── 写作
15:10 ───── 发答题卡 2
15:10 ───── 听力开始（30min）──────────────────── 边听边涂卡！
15:40 ───── ⚠️ 立即收答题卡 1（作文+听力答案）
15:40 ───── 阅读 + 翻译（70min）────────────────── 自由分配时间
16:40 ───── 翻译建议完成
17:25 ───── 收答题卡 2，考试结束
```

### 致命陷阱

```
┌──────────────────────────────────────────────────────────┐
│  ⚠️ 听力结束立即收答题卡 1，不给你时间誊写                  │
│                                                          │
│  正确做法：边听边涂卡，听完一题涂一题                         │
│  错误做法：先写在试卷上等听完再涂 → 答题卡被收走，0 分          │
└──────────────────────────────────────────────────────────┘
```

## 答题卡说明

```
答题卡 1（15:40 收）：
├── Part I  Writing   作文
└── Part II Listening  听力（涂卡）

答题卡 2（17:25 收）：
├── Part III  Reading   选词填空 + 长篇阅读 + 仔细阅读
└── Part IV   Translation  翻译
```

## 目标分数策略

| 目标分 | 听力目标 | 阅读目标 | 写作翻译目标 | 适用场景 |
|--------|---------|---------|------------|---------|
| 425（压线） | 150 | 150 | 125 | 保毕业 |
| 500（良好） | 175 | 175 | 150 | 求职简历 |
| 550（优秀） | 195 | 195 | 160 | 保研/外企 |
| 600+（顶尖） | 210 | 210 | 180 | 英语相关岗位 |

### 425 分底线公式

```
单词量 5000 × 真题 20 套 × 听力精听 20 篇 × 写作模板 3 个 = 稳过 425

各题型最低正确率：
  听力 ≥ 55%（撑住基本盘）
  阅读 ≥ 60%（仔细阅读必保，选词填空可放）
  写作 ≥ 60%（模板套用不出错）
  翻译 ≥ 55%（关键词写对，语法少错）
```

## 分数报告解读

成绩单会显示：
- **总分**（710 分制）
- **各单项分**（听力/阅读/写作和翻译）
- **百分位**（你在全国考生中的排名百分比）

企业/学校关注的分数线：
- **425**：毕业/学位证门槛
- **500**：好企业简历筛选线
- **550**：保研加分线
- **600**：英语相关岗位竞争力
