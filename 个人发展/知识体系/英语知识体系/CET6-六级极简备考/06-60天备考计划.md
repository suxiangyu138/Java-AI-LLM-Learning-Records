# 60 天 CET-6 备考计划 —— 可执行的时间表

## 总体规划

```
目标：425 分（保毕业） → 500 分（好简历） → 550 分（保研）
总时长：60 天
总学时：425 分需 ~60h，550 分需 ~120h

投入产出比排序：
听力精听 > 阅读真题 > 翻译高频词 > 写作模板 > 背单词
```

---

## 阶段一：基础突破（Day 1-30）

### 目标：词汇 5000+ + 吃透听力

### 每日时间表（2 小时）

```
┌────────────────────────────────────────────┐
│ 早晨 30 分钟：单词                           │
│   每天背 100 个六级核心词                     │
│   用墨墨背单词 App（艾宾浩斯自动复习）          │
│                                              │
│ 下午/晚上 90 分钟：                           │
│   听力精听 1 篇（40 分钟）                     │
│     → 5 步法完整执行                          │
│   仔细阅读 2 篇（30 分钟）                     │
│     → 做完后精读，标注生词                     │
│   翻译高频词 5 个（10 分钟）                    │
│     → 每天背 5 个并默写                        │
│   复习昨日单词（10 分钟）                       │
│     → App 自动推送，跟着复习即可                │
└────────────────────────────────────────────┘
```

### 阶段一里程碑

```
Day 7： 完成第 1 套真题听力（不计分，只感受难度）
Day 14：词汇量测试 ≥ 3500
Day 21：精听准确率从 Day1 的 30% → 50%
Day 30：完整做 1 套真题（不限时），记录各题型得分
```

---

## 阶段二：真题强化（Day 31-50）

### 目标：做透近 10 年真题（20 套）

### 每日时间表（3 小时）

```
┌────────────────────────────────────────────┐
│ 每隔 1 天做 1 套完整真题                      │
│                                              │
│ 真题日（2.5 小时）：                           │
│   下午 15:00 严格按照考试流程模拟              │
│   作文 30min → 听力 30min → 阅读 40min → 翻译 30min│
│   听力必须边听边涂卡                           │
│                                              │
│ 分析日（3 小时）：                             │
│   听力：精听错题部分（40 分钟）                 │
│   阅读：分析每道错题原因（40 分钟）              │
│     → 词汇 / 定位 / 同义替换 / 推理             │
│   翻译：对照范文修改（30 分钟）                  │
│   作文：默写模板 + 总结范文亮点（30 分钟）        │
│   整理错题本（30 分钟）                         │
│   背单词（30 分钟）                             │
└────────────────────────────────────────────┘
```

### 错题分析方法

```
每道错题标注错误类型：

听力错题：
  □ 词汇不认识
  □ 认识但没听出来（语音问题）
  □ 听出来了但选错了（推理问题）
  □ 走神漏听

阅读错题：
  □ 词汇不认识
  □ 定位错误（找错段落）
  □ 同义替换没识别
  □ 过度推理
  □ 粗心（看错选项/看错题号）

统计各类错误占比 → 针对性强化薄弱类型
```

### 阶段二里程碑

```
Day 35：第一套计时真题得分 ___ 分（记录基线）
Day 40：得分趋势上升还是持平？
Day 45：听力正确率 ≥ 55%，阅读正确率 ≥ 60%
Day 50：计时真题稳定 ≥ 425 分
```

---

## 阶段三：冲刺模拟（Day 51-60）

### 目标：稳定得分 + 模板背诵 + 状态调整

### 每日时间表（2 小时）

```
Day 51-52：第 1 次全真模拟
  15:00 严格模拟 → 分析错题 → 针对性复习薄弱点

Day 53-54：第 2 次全真模拟
  15:00 严格模拟 → 重点复习作文模板和翻译高频词

Day 55-56：第 3 次全真模拟
  15:00 严格模拟 → 调整做题节奏和心态

Day 57-58：查漏补缺
  重点复习错题本
  默写作文模板 3 个
  默写翻译高频词 50 个
  背一遍最高频的 300 个听力词汇

Day 59-60：考前准备
  复习错题本（只看红字部分）
  重听 2-3 篇精听过的真题（1.5 倍速）
  准备考试用具：耳机、2B 铅笔、橡皮、准考证、身份证
  晚上 22:00 前睡觉
```

## 每日最小执行清单（太忙时）

```
如果一天只有 1 小时：

□ 单词复习 15 分钟（App 自动推送，必须完成）
□ 听力精听 25 分钟（1 篇真题的 1 段）
□ 阅读真题 15 分钟（1 篇仔细阅读）
□ 翻译/作文 5 分钟（背 5 个高频词或默写 1 段模板）

如果一天只有 30 分钟：
□ 单词 15 分钟
□ 听力 15 分钟

如果一天只有 10 分钟：
□ 单词（这是唯一不能停的，停了会前功尽弃）
```
