# 高频词汇速记 —— 从 4000 到 6000 词的高效路径

## 核心认知

```
六级 6000 词不是均匀分布的，按频率分：

高频词（~800 个）  → 占真题出现率 70%  → 必须滚瓜烂熟
中频词（~1200 个） → 占真题出现率 20%  → 认识即可
低频词（~4000 个） → 占真题出现率 10%  → 蒙+猜，不必死记

策略：高频词 100% 掌握 → 中频词 80% → 低频词随缘
```

## 背词高效方法

### 方法 1：间隔重复

```
不靠意志力，靠算法：

Day 1：学 100 个新词
Day 2：系统自动复习 Day1 的词 + 学 100 个新词
Day 4：系统再推 Day1 的词（间隔 2 天）
Day 8：系统再推 Day1 的词（间隔 4 天）
Day 16：系统再推 Day1 的词（间隔 8 天）
...
每次复习都选"认识"或"模糊"
"不认识"的词会高频推送直到记住

工具：墨墨背单词 自动执行，不需要你手动排期
```

### 方法 2：语境记忆

```
❌ 孤立背词：abandon = 放弃
   7 天后只记得 abandon 在词汇书第一页

✅ 语境记忆：
   Many people abandon their New Year's resolutions by February.
   很多人到二月份就放弃了自己的新年计划。

   记住句子 > 记住单词（大脑更擅长记忆有意义的上下文）
```

### 方法 3：输出倒逼输入

```
被动背词（app 推送 → 看词选义）→ 只能做到"认识"
主动用词（写作/翻译中真正使用）→ 才能做到"会用"

每天写作翻译训练 = 最高效的词汇巩固方式
```
