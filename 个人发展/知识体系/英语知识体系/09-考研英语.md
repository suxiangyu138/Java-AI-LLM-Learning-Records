# 考研英语

## 一、考研英语的特殊性

### 1.1 考研英语 vs 四六级的本质区别
| 维度 | 四六级 | 考研英语 |
|------|--------|---------|
| 考试性质 | 水平测试（达标即可） | 选拔性考试（排名竞争） |
| 词汇要求 | 4500 / 5500 | 5500+，但考察深度远超范围 |
| 核心能力 | 语言应用能力 | 逻辑推理 + 长难句分析 |
| 最难题型 | 听力 | 阅读理解（尤其是推理题） |
| 长难句 | 较少，1-2 层从句 | 普遍，2-3 层从句嵌套 |
| 熟词生义 | 偶尔 | 高频考点 |

### 1.2 考研英语一 vs 英语二
| 维度 | 英语一 | 英语二 |
|------|--------|--------|
| 适用专业 | 学硕、大部分专业 | 专硕、部分专业 |
| 难度 | 较高 | 相对较低 |
| 阅读 | 更学术化、长难句更多 | 偏社会生活、经济管理 |
| 翻译 | 英译汉（5 画线句） | 英译汉（整段 150 词） |
| 写作 | 图画作文（漫画） | 图表作文（数据图） |
| 新题型 | 三种（排序/七选五/小标题） | 两种（小标题/多项对应） |

## 二、词汇：考研词汇的深度打法

### 2.1 考研词汇三阶分层
```
一阶词汇（约 2000 词）：基础词汇，四六级已覆盖
  策略：快速复习，发现漏洞就补

二阶词汇（约 2000 词）：考研核心词汇，高频出现在阅读中
  策略：深度掌握——熟词生义、词性变化、搭配关系

三阶词汇（约 1500 词）：超纲词/低频词
  策略：不刻意背，在阅读中遇到再记
```

### 2.2 考研熟词生义 —— 高频丢分点

考研阅读中最致命的不是生词（你可以猜），而是熟词生义（你不知道你不知道）。

| 单词 | 常见义 | 考研常考义 | 真题语境 |
|------|--------|-----------|---------|
| address | 地址 | 解决、处理 | address the problem |
| argue | 争论 | 主张、认为 | The author argues that... |
| bill | 账单 | 法案 | pass a bill |
| board | 板 | 董事会，委员会 | the board of directors |
| climate | 气候 | 氛围，风气 | economic climate |
| community | 社区 | 群体，界 | the scientific community |
| discipline | 纪律 | 学科 | academic disciplines |
| even | 甚至 | 均匀的、对等的 | an even distribution |
| figure | 数字 | 人物 | a public figure |
| institution | 机构 | 制度 | social institutions |
| interest | 兴趣 | 利益；利息 | vested interests |
| measure | 测量 | 措施 | take measures |
| novel | 小说 | 新颖的 | a novel approach |
| practice | 练习 | 惯例，实践 | common practice |
| reason | 原因 | 推理，理性思考 | the power of reason |
| school | 学校 | 学派，流派 | the Austrian school of economics |
| sentence | 句子 | 判决 | life sentence |

### 2.3 完形填空高频搭配（考研特有）
考研完形对固定搭配的考察远超四六级：

| 搭配 | 含义 |
|------|------|
| be subject to | 受...支配；易受...影响 |
| in the wake of | 随着...而来，在...之后 |
| at the mercy of | 任凭...摆布 |
| on the grounds that | 理由是... |
| take ... for granted | 认为...理所当然 |
| in the light of | 根据，考虑到 |
| at odds with | 与...不一致 |
| in parallel with | 与...同时 |
| be bound to | 一定会 |
| in the company of | 在...的陪伴下 |

## 三、长难句：考研英语的核心壁垒

### 3.1 长难句拆解三步法

```
Step 1: 找谓语动词 → 确定从句数量
  一个句子的从句数 = 谓语动词数 - 1

Step 2: 标从句边界 → 括号法
  （定语从句从关系词开始到第一个谓语结构结束）
  [状语从句从连词开始到（下一个连词/句末）]
  
  常见从句边界标志词：
  定语从句引导词：which, who, that, whose, when, where, why
  状语从句引导词：when, while, before, after, if, unless, because, although
  名词从句引导词：that, whether, what, how, when, where, why

Step 3: 剥离修饰 → 找主干
  去掉所有括号里的内容，剩下的是主干（主+谓+宾/表）
  然后按逻辑关系逐层把修饰加回去理解
```

### 3.2 长难句拆解实操

**原句（考研阅读真题风格）**：
```
The fact that an unprecedented number of middle-class families,
who had previously been able to rely on a single income to support
a comfortable lifestyle, are now finding themselves struggling to
make ends meet has led many economists to question the fundamental
assumptions upon which modern economic policy has been based.
```

**拆解过程**：
```
Step 1 - 找谓语动词：
  had been, are finding, has led, has been based → 4 个谓语 = 1 个主句 + 3 个从句

Step 2 - 标从句边界：
  The fact [that ... families, (who had previously been able to...lifestyle),
  are now finding themselves struggling to make ends meet] has led many
  economists to question the fundamental assumptions [upon which modern
  economic policy has been based].

Step 3 - 找主干：
  去掉从句后 → The fact ... has led many economists to question the
  fundamental assumptions.
  翻译：这个事实让许多经济学家开始质疑基本的假设。

  再补回从句层：
  - 什么事实？that 引导同位语从句：空前数量的中产家庭现在入不敷出
  - 这些家庭之前是怎样的？who 引导定语从句：之前能靠一份收入舒适生活
  - 什么假设？upon which 引导定语从句：现代经济政策建立于其上的假设

  组合理解：
  「空前数量的中产家庭（他们之前能靠一份收入维持舒适生活）现在发现
   自己入不敷出——这个事实让许多经济学家开始质疑现代经济政策一直
   以来所建立的基本假设。」
```

### 3.3 长难句训练计划
- **阶段一（基础）**：每天拆解 2 句，用括号法标注结构，逐层翻译
- **阶段二（提速）**：每天拆解 3 句，不写括号但脑中划分，限时 3 分钟/句
- **阶段三（熟练）**：每天 1 句，直接视译（看到英文直接说出中文，不经过笔译）

## 四、阅读理解：考研的决胜题型

### 4.1 考研阅读的选材特征
- 来源：The Economist, Scientific American, The Guardian, Nature, The Atlantic
- 题材：社会科学（经济学、法学、教育学）> 自然科学 > 人文学科
- 典型特征：逻辑严密，有明确论点论据结构，常有对立观点出现

### 4.2 考研阅读五步精读法（每篇 40-60 分钟）

```
第一步（5 min）：限时做题
  严格按照考试节奏做 5 道题（约 15-18 min），做完不对答案

第二步（10 min）：逐句翻译
  不查词典，把文章的每一句翻译成中文写下来
  翻不出来的地方标记（这就是你的阅读盲区）

第三步（8 min）：查词典修正
  查生词，看看之前翻不出来的地方查完能不能理解
  修正你的翻译

第四步（8 min）：结构分析
  画出文章的逻辑结构图：
  - 全文核心论点是什么？
  - 每段的论点和支撑细节是什么？
  - 段与段之间是什么关系（并列/递进/转折/例证）？

第五步（10 min）：题目复盘
  现在重做 5 道题：
  - 有没有改答案的？→ 改了说明语境理解有问题
  - 对照标准答案，无论对错，都问：正确选项在原文哪里？干扰选项干扰了什么？
```

### 4.3 阅读陷阱分类与应对

**陷阱 1：偷换概念**
- 原文：Most experts agree that...
- 选项：All experts agree that...
- 应对：范围词（all, most, some, none）必须和原文一一对应

**陷阱 2：因果颠倒**
- 原文：A causes B
- 选项：B causes A
- 应对：画箭头标注因果关系方向

**陷阱 3：无端比较**
- 原文：A is important. B is also important.
- 选项：A is more important than B.
- 应对：原文没有比较级，选项中出现比较级必为错

**陷阱 4：张冠李戴**
- 原文：Tom believes X. Jerry believes Y.
- 选项：Tom believes Y.
- 应对：每个观点必须对应正确的人/机构

**陷阱 5：过度推断**
- 原文：Studies suggest a possible link between A and B.
- 选项：A definitely causes B.
- 应对：原文用什么程度的词汇（may, suggest, possible），选项必须匹配

**陷阱 6：非黑即白**
- 原文：描述了某个复杂现象的利弊
- 选项：该现象完全好 / 完全坏
- 应对：考研文章基本没有绝对好/坏的观点——注意原文的限定词

### 4.4 阅读新题型专项

**排序题（英语一）**：
- 利用逻辑连接词推断顺序（firstly...secondly, one...another, on the one hand...on the other hand）
- 利用代词指代：上一段末尾出现 a new theory，下一段开头可能是 This theory/The approach
- 利用时间线索：chronological order

**七选五/小标题**：
- 先读选项，划关键词
- 段落首句和尾句往往包含了段落主旨
- 选项中的词在段落中出现（或其同义词）→ 可能是匹配项

## 五、翻译（英译汉）

### 5.1 考研翻译的特殊性
考研翻译考察的不是"翻对了没有"，而是"翻得通不通顺"——很多考生翻出来自己都读不懂。

### 5.2 翻译四步法
```
Step 1：拆句
  把英文长句按意群拆成 2-3 个短句

Step 2：译主干
  先翻译主谓宾核心结构

Step 3：加修饰
  把定语/状语加到合适的位置（注意中文的修饰语通常前置）

Step 4：润色
  让中文读起来像中文——去掉翻译腔
  "there is/are" → 不翻译
  英文被动 → 中文主动
  英文长定语 → 中文短定语或独立短句
```

### 5.3 翻译高频失分点
- 代词指代不清：英文用 it/they/this 很自然，中文必须明确指代对象
- 从句嵌套太深：先把内层从句拎出来独立成句，再翻译外层
- 生词卡住：不要空着不写——根据上下文大胆猜测，语境推测的准确率远高于随机

## 六、写作

### 6.1 考研写作评分核心
高分作文的共同特征：
1. **结构完整**：三段式，逻辑清晰
2. **语言准确**：低级语法错误极少（主谓一致、时态、冠词）
3. **内容充实**：有具体原因/例子，不是空话连篇
4. **衔接自然**：段与段、句与句之间过渡流畅

### 6.2 大作文模板框架

**图画作文（英语一）：**

```
第一段：描述图画 + 点出寓意（3-4 句）
As is vividly depicted in the cartoon, ...
The picture conveys a thought-provoking message that ...
Simple as the picture is, the symbolic meaning behind it is profound.

第二段：分析现象/原因/影响（5-6 句）
From my perspective, several factors can account for this phenomenon.
First and foremost, ...
Furthermore, ...
Last but not least, ...

第三段：提出建议/总结展望（3-4 句）
From what has been discussed above, we may safely draw the conclusion
that ...
It is high time that we took effective measures to ...
Only by doing so can we ...
```

**图表作文（英语二）：**

```
第一段：描述数据（3-4 句）
As is illustrated in the chart/table, ...
The number/percentage of ... increased/decreased from ... to ...
Meanwhile, ... witnessed a similar/opposite trend.

第二段：分析原因（5-6 句）
There are several reasons behind this trend.
To begin with, ...
In addition, ...

第三段：总结/预测（3-4 句）
In conclusion, ...
Considering the current trend, we have every reason to believe that ...
```

### 6.3 小作文（应用文）要点
- 格式是送分项——信函、通知、备忘录、报告，每种格式烂熟于心
- 内容覆盖所有要点（题目里列出的每一条都必须回应）
- 语言不求华丽，但求准确和恰当（正式/半正式的语气要匹配收信人）

## 七、全年备考节奏

| 阶段 | 时间 | 核心任务 |
|------|------|---------|
| 基础期 | 3-6 月 | 词汇 5500 一刷 + 长难句每日 2 句 + 阅读精读每周 3 篇 |
| 强化期 | 7-8 月 | 近 10 年真题阅读精做（重点） + 写作模板整理 |
| 提升期 | 9-10 月 | 真题第 2 轮（分题型专项） + 完形/翻译/新题型专项 |
| 冲刺期 | 11-12 月 | 近 3 年真题全真模拟 + 大小作文背诵 + 错题总复盘 |

**每日时间分配参考**：
- 单词：30 min（一直持续到考前）
- 长难句：15 min（基础期重点，后期可减）
- 阅读精读：60 min（最核心的投入）
- 写作：后期 30 min/天
