# 初高中英语听说读写教学法

## 一、语言教学的核心理论

### 1.1 四大理论基础

**（1）输入假说（Krashen, 1982）**
可理解输入（Comprehensible Input）是语言习得的充分必要条件。只有当学习者接触到"i+1"级别的语言材料（略高于现有水平），习得才会发生。

**教学启示**：教师在课堂上应该提供大量学生能基本理解但包含新语言点的输入材料，而非花大部分时间讲语法规则。

**（2）输出假说（Swain, 1985）**
输出（说和写）不是习得的结果也是推动习得的手段。输出有三大功能：注意功能（发现差距）、假设检验功能（尝试表达）、元语言反思功能（思考语言本身）。

**教学启示**：课堂必须给学生说的机会——不只是机械跟读，而是有真实交际目的的口语输出。

**（3）互动假说（Long, 1983）**
语言习得的最佳途径是在有意义的互动中进行意义协商（Negotiation of Meaning）——当沟通出现障碍时，双方调整语言以达成理解。

**教学启示**：设计需要学生之间合作完成的任务（信息差任务），让学生在真实沟通中练习语言。

**（4）社会文化理论（Vygotsky）**
学习发生在最近发展区（ZPD）内，借助更有能力的他人（教师/同伴）提供的脚手架（Scaffolding）。

**教学启示**：教师的角色不是"讲透"，而是提供刚好够的支撑，学生能做到后逐步撤除支撑。

### 1.2 四技能关系图
```
        输入侧                  输出侧
    [听 Listening]          [说 Speaking]
         \                      /
          \                    /
           [内化 Internalizing]
          /                    \
         /                      \
    [读 Reading]            [写 Writing]

四技能互相促进，不应被当作四门独立科目来教。
听和读是"原料"输入，说和写是"产品"输出——原料不足，产品必然匮乏。
```

## 二、听力教学法

### 2.1 听力教学三阶段框架（Pre-While-Post）

**Pre-listening（听前阶段）—— 激活背景知识，降低认知负荷**
- 介绍话题背景（用图片、标题预测内容）
- 预教关键障碍词（选择 3-5 个影响全局理解的生词）
- 布置听力任务（让学生带着目的去听，而非"听懂所有"）
- 激活已有知识："关于这个话题，你已经知道什么？"

**While-listening（听中阶段）—— 任务驱动，分层理解**
- 第一遍：获取主旨大意（Gist Listening）—— 回答 1-2 个综合性问题
- 第二遍：获取具体信息（Detailed Listening）—— 回答细节问题、填空、判断正误
- 第三遍（可选）：聚焦语言形式（Language Focus）—— 关注某个语言点的表达方式

**Post-listening（听后阶段）—— 从输入到输出的过渡**
- 口语延伸：角色扮演、讨论话题、复述内容
- 写作延伸：写对话摘要、写自己的观点
- 语言聚焦：回顾听力中出现的重点表达

### 2.2 听力微技能训练
| 微技能 | 训练方法 |
|--------|---------|
| 辨音 | 最小对立体听辨，抓音近词的区别 |
| 抓关键词 | 听句子找出承载核心意思的词 |
| 预测 | 根据标题/图片/上文预测即将听到的内容 |
| 推断 | 听对话推断说话人的关系、态度、位置 |
| 笔记 | 听报告/讲座记录关键信息点 |
| 语块识别 | 把听到的句子按意群切分 |

### 2.3 各学段听力教学重点
- **初中**：辨音能力、基础对话理解、简单信息提取
- **高中**：长对话理解、讲座/独白、推理判断、态度识别

## 三、口语教学法

### 3.1 口语教学的三种课堂活动类型

**（1）控制性活动（Controlled Practice）—— 聚焦准确性**
- 句型操练（Drill）：跟读、替换、转换（但不超过 5 分钟，否则无聊）
- 对话背诵 + 替换关键信息
- 目的：建立口腔肌肉记忆和语言基础框架

**（2）半控制性活动（Guided Practice）—— 聚焦流利性**
- 信息差任务（Information Gap）：两人各持不完整信息，通过对话补全
- 看图编故事（Picture Cued Storytelling）：提供连续图片，学生叙述
- 角色扮演（Role Play）：给定场景和角色卡，即兴对话
- 问卷调查（Survey）：用目标句型采访同学并汇报

**（3）自由产出活动（Free Practice）—— 聚焦交际**
- 小组讨论/辩论（Discussion/Debate）
- 做一个小演讲（Mini Presentation）
- 解决问题任务（Problem-solving Task）：小组合作解决一个开放性问题
- "两分钟即兴说"（Impromptu Speaking）：给一个话题，准备 30 秒，说 2 分钟

### 3.2 口语纠错策略
| 错误类型 | 纠错时机 | 纠错方式 |
|---------|---------|---------|
| 系统性语法错误 | 活动中先记录，结束后集中反馈 | 教师将错误写在黑板上，让学生自己找出并改正 |
| 影响理解的发音错误 | 即时纠正 | 给出正确示范，让学生再说一遍 |
| 表达不地道 | 活动后 | 给出更地道的说法，让学生体会差异 |
| 口误 | 不纠正 | 母语者也常口误，不影响交际 |

**纠错黄金原则**：不要打断学生的流利表达去纠错——流利性和自信比准确性更珍贵。记录错误，活动结束后集中处理。

### 3.3 口语课堂的常见问题与对策

**问题一：学生不敢开口**
- 对策：先 pair work（两人对话），再 small group（4 人小组），最后才在全班面前说
- 对策：允许使用"过渡语"（Can you say that again? How do you say ... in English?）
- 对策：多表扬努力，少批评错误；创造"可以犯错"的安全氛围

**问题二：学生用中文讨论**
- 对策：任务难度降低一点（学生用中文 = 任务超过语言能力）
- 对策：分配"语言警察"角色（一位组员负责监督只用英文）
- 对策：提供关键表达提示卡（贴在桌面/黑板上）

**问题三：口语活动喧闹无效果**
- 对策：任务指令必须极其清晰（用 ICQ——教学指令检查问题："你第一件事做什么？跟你说还是写？"）
- 对策：设定明确的时间和产出要求（"3 分钟后，每组要说出至少 3 条建议"）

## 四、阅读教学法

### 4.1 阅读教学的三个层次

**Level 1：字面理解（Literal Comprehension）**
- 能找出明确写在文中的信息
- 对应：中考大部分阅读题 / 高考基础阅读题

**Level 2：推断理解（Inferential Comprehension）**
- 能根据字里行间的暗示做合理推断
- 对应：中考部分题 / 高考大部分阅读题

**Level 3：评价理解（Evaluative Comprehension）**
- 能评价作者的观点、写作手法、论据有效性
- 对应：高考较高难度的观点态度题

### 4.2 阅读教学实用方法

**（1）KWL 阅读法**
| K（Know） | W（Wonder） | L（Learned） |
|-----------|-------------|--------------|
| 关于这个主题，我已经知道了什么？ | 关于这个主题，我想知道什么？ | 读完这篇文章，我学到了什么？ |

操作：阅读前填 K 和 W 列 → 阅读文章 → 阅读后填 L 列

**（2）SQ3R 阅读法**
```
Survey（浏览）：30 秒快速扫读标题、段落首句、插图
Question（提问）：把每个标题转换为问题
Read（阅读）：带着问题细读文章
Recite（复述）：关上书，口头复述你读到的内容
Review（回顾）：24 小时后回顾重点内容
```

**（3）拼图阅读（Jigsaw Reading）**
- 把文章切成 3-4 部分
- 每组成员先读自己那部分（专家阅读）
- 打散重组为"专家组"，每个专家向新组员介绍自己读的部分
- 全组拼出完整信息

**（4）任务型阅读（Task-based Reading）**
- 不是"读完回答问题"，而是"为完成一个任务而阅读"
- 例如：读三篇酒店介绍 → 为某个家庭选出最适合的酒店并说明理由
- 目的：让阅读活动有真实的交际目的

### 4.3 阅读策略显性教学
不要假设学生"自然就会阅读策略"，必须**显性地教**：

| 策略 | 怎么教 |
|------|--------|
| 预测 | "看这个标题，你觉得文章会讲什么？为什么？"（教师 think aloud 示范推理过程） |
| 略读（Skimming） | 限时 30 秒找出文章主旨，"你看了哪些部分？" |
| 寻读（Scanning） | 限定 20 秒找出某个具体信息（"文章里提到了几个原因？"） |
| 猜词义 | "这个词不认识，但你能从句子里猜出意思吗？哪些线索帮助了你？" |
| 推断 | "作者没有直接说，但你能感觉到他的态度是什么吗？你的线索是什么？" |
| 总结 | "用一句话说出这篇文章的核心观点" |

## 五、写作教学法

### 5.1 过程写作法（Process Writing）—— 写作教学的金标准

**传统写作教学的问题**：教师布置题目 → 学生回家写 → 教师批改语法错误 → 发回给学生（学生只看分数，不读反馈）

**过程写作法的五个阶段**：

```
阶段 1：Prewriting（写前构思）
  活动：头脑风暴（brainstorming）、思维导图（mind map）、列提纲（outlining）
  目标：产生想法、组织思路，不急着写

阶段 2：Drafting（初稿写作）
  活动：根据提纲写初稿
  目标：把想法变成文字，重心在内容而非形式，不纠结语法

阶段 3：Revising（修改——内容层面）
  活动：自评 + 同伴互评（peer review）
  检查：内容是否完整？逻辑是否清晰？论点有没有支撑？
  目标：改善文章的内容和结构

阶段 4：Editing（编辑——语言层面）
  检查：语法、拼写、标点、用词是否恰当
  目标：打磨语言形式

阶段 5：Publishing（发布/展示）
  形式：贴在教室墙上、班级作文集、课上朗读、上传学习平台
  目标：让写作有真实的读者，提升写作动力
```

### 5.2 同伴互评（Peer Review）的操作指南

**给学生明确的反馈清单**：
```
同伴互评清单：
□ 文章有清晰的开头、中间、结尾三部分吗？
□ 每个段落都有主题句吗？
□ 你能找到支持论点的例子吗？
□ 你能找到至少一个可以换一种说法让它更清楚的句子吗？
□ 你最喜欢的句子是哪一句？为什么？
```

**培训学生使用反馈语言**：
- 不用："This is bad."
- 而用："I like how you ..., but I wonder if you could ..."
- 训练口诀：Star + Star + Wish（两个优点 + 一个建议）

### 5.3 教学写作的"脚手架"策略

**（1）范文支架**：提供优秀范文，分析结构和语言，然后学生仿写
**（2）提纲支架**：教师提供详细提纲（甚至是半成品的段落首句），学生补充内容
**（3）句型支架**：提供本次写作可以用到的高分句型，鼓励学生在合适的地方使用
**（4）词汇支架**：提供本次写作可以用到的关键词汇，让学生在语境中运用

**脚手架的关键原则**：**随着学生能力增长逐步撤除**——第一次提供完整提纲，第二次只给段落主题，第三次完全由学生自己写。

### 5.4 分学段写作教学要点

**初中写作教学**：
- 目标：能写出结构正确、意思基本清楚的 80-100 词短文
- 重点：五大基本句型的正确使用，基本的时态一致性，简单的连接词
- 常见问题：时态混乱、Chinglish 表达、缺少连接词

**高中写作教学**：
- 目标：能写出结构完整、逻辑清晰、语言有变化的 100-120 词短文
- 重点：复杂句的准确使用、词汇搭配的恰当性、段落衔接与连贯
- 常见问题：为了用难词而用难词（滥用不认识的高级词）、省略连接词、缺少细节支撑

## 六、听说读写整合教学

### 6.1 话题驱动型整合教学（Topic-based Integrated Teaching）

以话题为中心，四技能围绕话题展开：

```
示例：话题 "环境保护"

第 1 课时（输入为主）：
  - 读：读一篇关于塑料污染的文章（通过阅读输入主题词汇和信息）
  - 听：听一段关于环境保护的采访（通过听力输入不同观点）

第 2 课时（输出为主）：
  - 说：小组讨论"学校可以做哪些事减少塑料使用"（基于输入的口语输出）
  - 写：给校长写一封信建议学校推行环保措施（综合输出）
```

### 6.2 任务驱动型教学（Task-based Language Teaching, TBLT）

任务型教学的流程：
```
Pre-task（任务前）
  → 介绍话题和任务目标
  → 提供必要的语言输入（读/听相关材料）

Task Cycle（任务环）
  → Task：学生结对/分组完成任务（用目标语言交流）
  → Planning：各组准备向全班汇报
  → Report：各组汇报任务成果

Language Focus（语言聚焦）
  → Analysis：教师分析学生语言使用中的典型问题
  → Practice：针对薄弱语言点的练习
```

### 6.3 课堂语言使用策略
- 教师输入：尽量使用英语，但关键指令可以中英文各说一遍
- 课堂用语标准化：每节课用的课堂指令保持一致（Open your book to page... / Work with your partner / Time's up）
- "英语时段"设置：从 5 分钟"只能说英语"开始，逐渐延长
- 不要中英互译教学：用图片、动作、英语释义，而不是直接给中文翻译
