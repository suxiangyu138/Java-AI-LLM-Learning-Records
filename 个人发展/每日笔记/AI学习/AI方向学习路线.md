# AI 方向学习路线（Java 后端 → AI 应用开发）
分成 4 个阶段，你按顺序学就行，每天 6 小时，3～6 个月就能成为稀缺的 Java+AI 双栈人才。
 
阶段1：AI 基础认知（1～2 周）
不用学数学推导，只需要懂概念。
必须掌握：
- 大模型是什么（LLM）
- 提示词工程（Prompt Engineering）
- 上下文、温度 top_p、token 是什么
- 有哪些主流大模型：
- 国内：通义千问、文心一言、讯飞星火、豆包、混元
- 开源：Llama 3、Qwen、GLM、Mistral
- 什么是 RAG、Agent、Fine-tune（微调）
- 向量数据库是什么
    目标：
    能听懂别人聊 AI，不会被忽悠。
 
阶段2：大模型 API 开发（核心！后端最容易上手）
这是你最核心竞争力，Java 后端天然适合做这个。
必须学：
1. 调用大模型 HTTP API
    - 通义千问 API
    - 百度千帆 API
    - 字节/豆包 API
    - OpenAI 格式接口（几乎所有模型都兼容）
2. 用 Java 对接大模型
    - 用 RestTemplate / Feign / OkHttp 调用
    - 流式返回（SSE，实时打字效果）
    - 异步处理
    - 异常重试、熔断、限流
3. Prompt 工程实战
    - 角色设定
    - 输出格式约束（JSON）
    - 少样本学习（Few-shot）
    - 思维链（CoT）
    能做的项目：
    - AI 问答机器人
    - AI 写作助手
    - 智能客服
    - 智能内容审核
    - 智能翻译、总结
    这部分学会，你已经超过 80% 后端。
 
阶段3：RAG 企业级知识库（面试大杀器）
RAG = 检索增强生成，是企业 AI 最主流落地方式。
你需要学：
1. 文本分片（Chunk）
2. 向量 embedding
    - 通义 embedding
    - BGE
3. 向量数据库
    - Milvus（企业主流）
    - Chroma（轻量）
    - FAISS（学习用）
4. 检索 + 提示词拼接
5. Java 对接向量库
6. 文档解析
    - PDF、Word、Excel、图片文字识别
    落地项目：
    - 企业内部知识库
    - 智能简历解析
    - 法律/医疗文档问答
    - 课程智能答疑
    RAG 写进简历，直接拉开差距。
 
阶段4：AI Agent 智能体（进阶，高薪方向）
不用学复杂算法，学使用就行。
内容：
- 工具调用（Function Calling）
- 任务规划
- 记忆机制
- 工作流编排
    可以学框架：
- LangChain（Java 也有版）
- Spring AI（非常适合你）
- AutoGPT 类简单流程
    落地项目：
- 智能日程助手
- AI 数据分析
- 自动化客服
- 多步骤决策机器人
 
阶段5：模型部署（Java 后端优势巨大）
你学过 Docker、K8s，这部分你比纯AI专业的人强太多。
内容：
- 开源大模型本地部署（Qwen、GLM）
- Ollama 快速部署
- vLLM 加速推理
- Docker 打包模型服务
- K8s 部署模型集群
- Prometheus + Grafana 监控模型服务
    这是未来 3 年最稀缺能力：AI 部署工程化。
 
阶段6：进阶（可选，想深入再学）
- 微调（LoRA）
- 多模态（图片+文本）
- 知识图谱 + LLM
- AI 安全、内容过滤
- 模型评测
 
最终你会成为什么角色？
Java 后端 + LLM 应用开发 + RAG + Agent + 模型部署
这种人在市场上非常稀缺，薪资比普通后端高 30%～100%。
 
最精简必学清单（只学这些就够）
1. 大模型 API 调用（Java）
2. SSE 流式返回
3. Prompt 工程
4. RAG + 向量数据库
5. Spring AI / LangChain
6. 模型 Docker 部署
7. Function Call（Agent）
 
你每天 6 小时学习节奏（最舒服）
- 2 小时：Java 后端巩固
- 3 小时：AI API + RAG 开发
- 1 小时：算法题保持手感
    坚持 3 个月，你就是准全栈 AI 后端工程师。
