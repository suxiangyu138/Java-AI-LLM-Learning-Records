# 每日训练计划
卷腹 50 个
俯卧撑 50 个
骑行 4 公里
平板支撑 3 组
韧带拉伸
坚持 3 个月效果
腹部
核心力量显著增强，腹部紧致，小肚子明显缩小，腹肌轮廓初步显现，腰腹稳定性提升，久坐不易腰酸。
胸肩手臂
胸肌、肱三头肌、三角肌更饱满，手臂线条清晰，上肢力量提升，日常发力更轻松，穿衣更有支撑感。
心肺耐力
心肺功能大幅提升，心率稳定，耐力增强，爬楼、跑步不易气喘，精力更充沛，疲劳感减少。
体态气质
核心强化改善含胸驼背、骨盆前倾，站姿坐姿更挺拔，整体气质更精神、更有活力。
柔韧性
关节活动度提升，柔韧性增强，运动不易拉伤，日常活动更舒展灵活。
体型体脂
体脂下降，身材更紧致，腰围、臂围等围度变化明显，体重变化不大但体型更匀称好看。
精神状态
多巴胺分泌提升，情绪稳定，焦虑减少，专注力增强，睡眠质量改善，整体活力提升。
