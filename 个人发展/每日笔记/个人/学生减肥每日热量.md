# 【学生减肥·每日热量】
男生减脂：1600～1800 大卡
想快一点：1500～1600 大卡
【三餐模板】
早餐：鸡蛋+无糖奶+粗粮
午餐：瘦肉+大量蔬菜+一拳主食
晚餐：蛋白+蔬菜，少吃或不吃主食
加餐：黄瓜/番茄/无糖酸奶/小份水果
【放心吃】
鸡胸肉 牛肉 鱼肉 虾
鸡蛋 豆腐 无糖酸奶
所有绿叶蔬菜 黄瓜 番茄
玉米 红薯 燕麦 全麦面包
苹果 橙子 柚子 草莓
【绝对不能吃】
奶茶 果汁 可乐
辣条 薯片 饼干 糖果
炸鸡 薯条 油条 烧烤
蛋糕 甜品 巧克力
方便面 麻辣烫 重油外卖
【减肥黄金4条】
1. 少油少糖少油炸
2. 每餐7分饱，不饿不吃
3. 每天喝够1500ml水
4. 不熬夜、不暴饮暴食
