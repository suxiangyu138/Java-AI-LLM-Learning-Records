# Vim编辑器极速入门
Vim核心是模式化编辑，掌握3种模式切换+高频命令，10分钟即可上手，完全适配终端开发场景。

## 一、核心：三种模式（必记）
Vim所有操作围绕3种模式展开，Esc是万能返回键，任何模式按Esc回到普通模式。
1. 普通模式（默认）
    打开文件自动进入，键盘按键为命令，负责光标移动、删除、复制、粘贴。
2. 插入模式
    仅用于输入文字，普通模式按以下键进入：
    -  i ：光标前插入
    -  a ：光标后插入
    -  o ：光标下新建行插入
    -  O ：光标上新建行插入
    -  I ：行首插入、 A ：行尾插入
3. 底行模式
    普通模式按 : 进入，负责保存、退出、搜索、配置。

## 二、文件打开/保存/退出（最常用）
```bash
# 打开文件（文件不存在则新建）
vim 文件名
底行模式命令（按 : 后输入，回车执行）：
-  :w  保存文件
-  :q  退出（未修改）
-  :wq / :x  保存并退出
-  :q!  强制退出（不保存修改）
-  :w!sudo tee %  管理员权限强制保存（解决只读文件）
```

## 三、普通模式核心操作
1. 光标移动（不用方向键，效率最高）
    - 基础移动： h 左、 j 下、 k 上、 l 右
    - 单词移动： w 下一词、 b 上一词、 e 词尾
    - 行跳转： 0 行首、 $ 行尾、 gg 文件开头、 G 文件末尾
    - 翻页： Ctrl+f 下一页、 Ctrl+b 上一页
    - 精准跳转： :n  跳转到第n行（例 :10 到第10行）
2. 删除/复制/粘贴
    - 删除字符： x 删除光标字符、 nx 删除n个字符
    - 删除整行： dd 删除当前行、 ndd 删除n行
    - 范围删除： dG 删到文件末尾、 dk 删当前+上一行、 dj 删当前+下一行
    - 复制： yy 复制整行、 nyy 复制n行
    - 粘贴： p 光标下粘贴、 P 光标上粘贴
3. 搜索与替换
    - 搜索： /关键词  向下搜索， n 下一个、 N 上一个
    - 忽略大小写： :set ignorecase 
    - 全局替换： :%s/旧内容/新内容/g  全文件替换

## 四、可视模式（批量选中文本）
普通模式按以下键进入：
-  v ：字符选择
-  V ：整行选择
-  Ctrl+v ：块选择
    选中后可执行删除、复制、缩进等批量操作。

## 五、新手必避坑
1. 打开文件直接打字乱码？先按i进入插入模式
2. 不知道在哪种模式？狂按Esc回到普通模式
3. 改完文件退不出？ :wq 保存退出， :q! 强制退出
4. 想显示行号？底行模式输入 :set nu
