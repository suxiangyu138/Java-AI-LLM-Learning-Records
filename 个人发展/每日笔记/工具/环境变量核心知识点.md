# 环境变量 核心知识点

## 一、什么是环境变量
环境变量是操作系统/进程中全局生效的键值对，用于存储系统、软件、进程运行所需的配置信息、路径、参数，是系统与程序沟通的「全局配置字典」。
- 本质： key=value  键值对
- 作用：解耦配置与程序，不用改代码，通过修改变量即可改变程序行为
 
## 二、环境变量的3个层级（优先级从低到高）
1. 系统级环境变量
    - 作用范围：全系统、所有用户
    - Windows：需要管理员权限修改
    - Linux/macOS：对所有用户生效，配置在  /etc  目录下
2. 用户级环境变量
    - 作用范围：仅当前登录用户
    - 权限：普通用户可修改，不影响其他用户
3. 进程级环境变量
    - 作用范围：仅当前终端/当前进程，关闭即失效
    - 优先级最高，临时测试专用
    优先级：进程级 > 用户级 > 系统级
 
## 三、核心用途（必记）
1. PATH 路径配置
    系统执行命令时，会在  PATH  变量的目录里查找程序，不用写完整路径就能直接运行。
    - 例：配置Java、Python、Maven、Git到PATH，任意终端直接敲命令
2. 软件运行配置
    JAVA_HOME、MAVEN_HOME、PYTHON_HOME 等，软件通过变量找到自身安装目录
3. 开发环境区分
     ENV=dev/prod/test ，程序根据变量切换开发/生产/测试环境
4. 敏感信息存储
    密钥、Token、数据库密码，不硬编码到代码里，通过环境变量注入
5. 系统全局配置
    语言、编码、临时目录、默认程序等
 
## 四、Windows 核心操作
1. 查看所有环境变量
```cmd
set
```
 
2. 查看单个变量
```cmd
echo %变量名%
:: 例
echo %JAVA_HOME%
echo %PATH%
```
 
3. 临时设置（仅当前cmd）
```cmd
set 变量名=值
:: 例
set ENV=dev
```
 
4. 永久设置（图形界面）
    此电脑 → 右键属性 → 高级系统设置 → 环境变量
    - 上方：用户变量（当前用户）
    - 下方：系统变量（全系统）
 
## 五、Linux/macOS 核心操作
1. 查看所有环境变量
```bash
env
# 或
printenv
```
 
2. 查看单个变量
```bash
echo $变量名
# 例
echo $PATH
echo $JAVA_HOME
```
 
3. 临时设置（仅当前终端）
```bash
export 变量名=值
# 例
export ENV=prod
```
 
4. 永久设置
    - 用户级：写入  ~/.bashrc  /  ~/.zshrc 
    - 系统级：写入  /etc/profile 
```bash
# 写入后生效
source ~/.bashrc
```
 
 
## 六、开发高频环境变量清单
变量名 作用 
 PATH  系统命令查找路径 
 JAVA_HOME  Java安装根目录 
 MAVEN_HOME  Maven安装目录 
 PYTHONPATH  Python模块搜索路径 
 HOME  /  USERPROFILE  用户主目录 
 TEMP  /  TMP  系统临时目录 
 ENV  /  SPRING_PROFILES_ACTIVE  环境标识 
 
## 七、开发必懂核心原理
1. 为什么要配置环境变量？
    让程序解耦配置，实现「一处配置，全局生效」，适配不同环境、不同机器。
2. PATH 变量核心逻辑
    执行命令时，系统从左到右遍历  PATH  里的目录，找到第一个匹配的程序就执行。
3. 环境变量 vs 配置文件
    - 环境变量：适合全局、敏感、环境区分配置
    - 配置文件：适合项目专属、复杂、结构化配置
4. 容器/云原生中的环境变量
    Docker、K8s 中，环境变量是注入配置、区分环境的标准方式，是云开发基础。
 
## 八、高频踩坑点
1. 改完环境变量不生效：关闭终端重新打开，或执行  source  刷新
2. Windows 中用户PATH和系统PATH重复，导致命令执行异常
3. 变量值带空格，没加引号，导致解析错误
4. 敏感信息硬编码，不用环境变量，存在安全风险
 
一句话总结：
环境变量就是系统/程序的全局配置中心，核心是PATH路径配置+软件根目录配置，开发中用来解耦环境、隐藏敏感信息、统一全局配置。
