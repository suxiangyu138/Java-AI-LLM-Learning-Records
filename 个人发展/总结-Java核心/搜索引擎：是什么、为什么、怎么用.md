# 搜索引擎：是什么、为什么、怎么用

## 一、是什么（What）

搜索引擎是对互联网信息进行爬取、解析、建立索引，并根据用户查询快速返回相关结果的系统。

**核心三阶段：**

1. 爬取（爬虫）：从网页抓取数据
2. 建立索引：分词 → 构建倒排索引
3. 查询检索：解析关键词 → 匹配 → 排序 → 展示结果

**核心数据结构：** 倒排索引（词 → 文档ID）

## 二、为什么（Why）

1. 信息爆炸：网页海量，人工查找效率极低
2. 快速定位：通过索引实现毫秒级检索
3. 按相关性排序：把最有用的结果放前面
4. 统一入口：一站式获取全网/全站信息

## 三、怎么用（How）——从实现/原理角度

### 1. 爬虫怎么用

- 爬取网页 HTML
- 解析标题、正文、链接
- 去重（如 SimHash）
- 增量更新

### 2. 分词怎么用

- 对文本做中文分词
- 去掉停用词（的、了、是）
- 为建索引做准备

### 3. 倒排索引怎么用

- 对每个词，记录出现的文档ID、位置、频次
- 支持快速查找：包含某个词的所有文档

### 4. 查询流程怎么用

1. 用户输入关键词
2. 对查询分词
3. 通过倒排索引找到候选文档
4. 用 TF-IDF / BM25 / PageRank 打分排序
5. 返回Top-N结果

### 5. 实际技术怎么用

- 分词：IKAnalyzer、HanLP
- 检索引擎：Lucene、Solr、Elasticsearch
- 爬虫：Jsoup、WebMagic
- 存储：ES、MySQL、Redis

## 极简背诵版（适合简答题）

- 是什么：爬取、建索引、检索信息的系统。
- 为什么：解决海量信息查找慢、乱、难的问题。
- 怎么用：爬虫抓数据 → 分词 → 建倒排索引 → 查询匹配 → 排序返回。
