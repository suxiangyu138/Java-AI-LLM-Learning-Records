FinalShell 核心知识点（开发必备、极简干货）
定位：Windows 免费终端+SFTP 文件管理器，Java后端/AI服务部署、Linux 操作首选，替代 Xshell、Putty。
一、核心功能
1. SSH 远程连接 Linux 服务器
2. SFTP 可视化文件传输（拖拽上传/下载）
3. 内置命令行、窗口多开、保存主机、记住密码
4. 自带字体优化、防乱码、后台保活
 
二、新建连接 & 核心参数
1. 连接类型
    - 名称：自定义（如「阿里云-测试」）
    - 主机：服务器公网 IP
    - 端口：默认 22
    - 账号： root  或 业务普通用户
    - 密码/密钥：二选一
2. 两种登录方式
    1. 密码登录：最简单，新手常用
    2. 密钥登录：更安全，企业线上环境标配
 
三、高频实用操作
1. 窗口管理
    - 右键会话：复制会话、重命名、分组管理
    - 多标签：同时连多台服务器，切换方便
2. SFTP 文件管理（最强功能）
    - 左侧：本地Windows文件
    - 右侧：Linux 服务器目录
    - 操作：
    - 拖拽：直接上传/下载
    - 右键：权限修改、删除、解压、新建文件夹
    - 直接编辑：双击服务器文件，改完自动保存
3. 常用快捷键
    -  Ctrl + L ：清屏
    -  Ctrl + C ：终止当前运行程序
    -  Tab ：命令/路径自动补全
    - 鼠标右键：快速粘贴
 
四、关键配置（避坑必看）
1. 防止中文乱码
    设置 → 终端 → 编码选择：UTF-8
2. 断开自动重连
    会话属性 → 高级 → 开启：
    - 心跳检测
    - 断开自动重连
    解决长时间闲置掉线问题
3. 终端字体/大小
    可自定义字体、行距，代码和日志阅读更舒服
 
五、开发高频使用场景
1. Java 项目部署
    上传 Jar 包 → 授权权限 → 命令启动服务
2. 配置文件修改
    直接编辑  yml / .properties / nginx  配置，无需额外工具
3. 日志查看
    终端执行  tail -f 日志文件  实时看运行日志
4. 中间件部署
    上传 Docker 脚本、安装包、快速管理服务器文件
 
六、常见问题 & 解决
1. 连接超时/拒绝连接
    - 服务器防火墙未放行 22 端口
    - IP 错误、端口错误、服务器未开机
2. 密码正确但登录失败
    - 服务器限制 root 远程登录
    - 密钥/登录方式选错
3. 文件上传失败
    - 文件夹权限不足，执行： chmod 755 目录名 
 
七、极简总结（背诵版）
1. FinalShell = SSH远程连接 + SFTP可视化文件传输
2. 核心价值：拖拽传文件、在线改配置、多服务器管理
3. 必配：UTF-8编码、心跳保活防掉线
4. 后端/AI部署刚需：上传Jar、修改配置、查看日志、管理服务
