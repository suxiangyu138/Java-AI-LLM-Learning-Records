C盘清理极简流程
全程照着做即可，无复杂操作，优先做安全项，不碰系统核心文件。
 1. 系统自带磁盘清理（必做）
1. 打开「此电脑」→ 右键 C盘 → 【属性】
2. 点击【磁盘清理】，等待扫描
3. 点击【清理系统文件】，再次扫描
4. 勾选所有可清理项（临时文件、更新缓存、回收站、缩略图等）
5. 点击【确定】删除
2. 迁移微信/QQ/钉钉文件（核心清空间）
    1. 打开微信 → 【设置】→ 【文件管理】
    2. 修改存储位置到D盘目录，确认迁移
    3. QQ、钉钉重复上述操作，迁移文件存储路径
3. 迁移桌面/下载/文档文件夹
    1. 打开「此电脑」→ 右侧找到【桌面】文件夹
    2. 右键 → 【属性】→ 【位置】→ 【移动】
    3. 选择D盘新建文件夹，确认迁移
    4. 【下载】【文档】文件夹执行相同迁移操作
4. 关闭系统休眠（一键释放空间）
    1. 以管理员身份打开CMD
    2. 执行命令：
    cmd
    powercfg -h off
 
3. 回车即可删除休眠文件
5. 浏览器下载路径修改
    1. 打开Chrome/Edge设置
    2. 找到【下载内容】
    3. 将默认下载路径改为D盘文件夹
6. 卸载C盘无用软件
    1. 打开【设置】→ 【应用】→ 【已安装应用】
    2. 筛选C盘安装的软件
    3. 卸载长期不用、非系统必需的软件
7. 定期维护（每月1次）
    1. 重复步骤1的磁盘清理
    2. 检查微信/QQ缓存是否堆积，定期清理
    3. 确认下载文件夹无无用大文件
