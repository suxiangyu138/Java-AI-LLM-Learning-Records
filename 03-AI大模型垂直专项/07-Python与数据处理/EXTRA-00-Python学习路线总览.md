# Python 学习路线总览

> **适用人群**：Java 主力开发者 / 计算机本科在读 · 方向：Java 后端 + AI 大模型应用
> **学习策略**：工具语言路线 — 快速语法速通 → 常用库熟练 → 聚焦 AI/数据方向，不走全栈大而全
> **预计周期**：语法 3–7 天 + 生态库 2–4 周 + 项目实战 2–4 周

---

## 📌 路线定位

对 Java 主力选手而言，Python 不需要像 Java 那样走"完整后端生态路线"。你更适合：

> **把 Python 当"工具语言 + AI 与数据生态入口"来学**

| 维度 | Java（主业） | Python（工具/AI 辅助） |
|------|-------------|----------------------|
| 定位 | 后端主力语言 | AI/数据/脚本语言 |
| 学习策略 | 系统深入（JVM、并发、框架） | 按需深入（够用即走） |
| 工程化 | Spring Boot、Maven、微服务 | venv/pip、FastAPI、脚本 |
| 核心场景 | 接口网关、权限、业务逻辑 | Embedding、向量检索、数据预处理 |

## ⚠️ Java 开发者常见陷阱

| 陷阱 | Java 习惯 | Python 实际 |
|------|----------|------------|
| 变量作用域 | 块级作用域 | **函数级作用域**（for/if 内变量外部可见） |
| 默认参数 | 不支持 | 支持，但**可变默认参数是坑**（只初始化一次） |
| 私有成员 | `private` 关键字 | **命名约定** `_name`（无真正私有的概念） |
| 多线程 | JVM 真并行 | **GIL 限制**（CPU 密集用多进程） |
| 字符串 | `String` 不可变 | `str` 不可变，`+=` 创建新对象 |
| 方法重载 | 支持 | **不支持**（用默认参数/可变参数替代） |
| 接口 | `interface` 关键字 | **鸭子类型**（只要对象有该行为就算） |

## 📊 时间投入建议

> 按"Java 主力 + Python 工具辅助"定位，建议总共投入 **6–10 周** 达到实用水平。

```
Week 1:   语法速通（与 Java 对比学习，快速过差异点）
Week 2-3: 进阶 + 标准库（重点：venv、文件操作、subprocess）
Week 4-5: NumPy + Pandas（数据处理能力）
Week 6-7: AI 生态入门（PyTorch 基础 + FastAPI）
Week 8-10: 项目实战（Java + Python 联动小项目，写入简历）
```

> **核心理念**：Python 是你 Java 后端开发的"外挂"，不是替代品。把精力集中在它能帮你扩展的能力边界上——AI、数据处理、自动化。
