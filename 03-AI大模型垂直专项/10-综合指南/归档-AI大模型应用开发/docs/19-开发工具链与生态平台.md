## 1. 低代码 AI 应用平台

### 1.1 平台对比

| 平台 | 定位 | 特点 | 适合 |
|------|------|------|------|
| **Dify** | AI 应用开发平台 | 拖拽式工作流、RAG、Agent、可视化管理 | 快速原型、非开发者 |
| **FastGPT** | 知识库问答平台 | 中文优化、知识库管理、流程编排 | 企业知识库 Q&A |
| **Flowise** | 低代码 LLM 流程 | 节点拖拽、LangChain 底层 | 技术团队快速原型 |
| **LangFlow** | LangChain 可视化 | 拖拽构建 LangChain 流程 | LangChain 用户 |
| **Coze (扣子)** | 字节 AI Bot 平台 | 零代码、集成飞书/微信 | 营销/客服 Bot |
| **百度千帆 AppBuilder** | 百度 AI 应用平台 | 百度生态、模型+应用 | 百度生态用户 |
| **阿里百炼** | 阿里 AI 应用平台 | 百炼模型+应用搭建 | 阿里云生态用户 |

**Dify 在企业中的定位**：

```
Dify 适合：
  ✅ 快速验证 AI 应用 idea（几小时出原型）
  ✅ 非开发人员构建 AI 工具（运营/产品/业务）
  ✅ 中小团队快速上线 AI 功能
  ✅ 企业内 AI 应用统一管理平台

Dify 不适合：
  ❌ 复杂定制逻辑 → 用 Java 自研
  ❌ 超高并发场景 → 自研服务 + vLLM
  ❌ 深度企业系统集成 → API + 自研

推荐策略：Dify 做原型/简单应用 + Java 做核心复杂功能
```

### 2.2 Java 集成 LangFuse

```java
// application.yml
langfuse:
  host: https://cloud.langfuse.com    # 或自部署地址
  public-key: ${LANGFUSE_PUBLIC_KEY}
  secret-key: ${LANGFUSE_SECRET_KEY}

// Spring AI Advisor 集成
@Component
public class LangfuseAdvisor implements CallAroundAdvisor {

    private final Langfuse langfuse;

    @Override
    public AdvisedResponse aroundCall(AdvisedRequest request,
                                       CallAroundAdvisorChain chain) {
        // 创建 Trace
        var trace = langfuse.newTrace()
            .name("chat")
            .userId(request.userId())
            .input(request.userText())
            .build();

        // 创建 Generation
        var generation = trace.generation()
            .name(request.model())
            .model(request.model())
            .input(request.userText())
            .start();

        long start = System.currentTimeMillis();
        AdvisedResponse response = chain.nextAroundCall(request);
        long latency = System.currentTimeMillis() - start;

        // 记录完成
        generation.end()
            .output(response.response())
            .usage(new Usage(response.inputTokens(), response.outputTokens()))
            .completionStartTime(Instant.ofEpochMilli(start));

        trace.update().output(response.response());

        return response;
    }
}
```

## 4. 本地模型工具

### 4.1 Ollama

```bash
# 核心命令速查
ollama pull qwen2.5:7b         # 拉取模型
ollama pull deepseek-r1:7b     # 拉取推理模型
ollama list                     # 查看本地模型
ollama run qwen2.5:7b          # 交互式运行
ollama serve                    # 启动 API 服务 (端口 11434)

# Modelfile：自定义模型配置
FROM qwen2.5:7b
SYSTEM "你是一个 Java 后端专家"
PARAMETER temperature 0.7
PARAMETER num_ctx 4096

ollama create my-assistant -f Modelfile
ollama run my-assistant
```

## 5. Agent 开发框架

```
Agent 框架选型指南：

LangGraph (Python)：
  ✅ 有状态图，支持循环/分支
  ✅ LangChain 生态
  ✅ Checkpoint 和 Human-in-the-Loop
  ❌ Java 无原生支持（需 HTTP/gRPC 调用）

CrewAI (Python)：
  ✅ 角色扮演式多 Agent
  ✅ 简单易用
  ❌ 灵活性有限
  ❌ Java 无原生支持

AutoGen (Python)：
  ✅ 微软出品，对话式多 Agent
  ✅ 代码生成和执行
  ❌ 学习曲线陡
  ❌ Java 需 HTTP 调用

LangChain4j (Java)：
  ✅ Java 原生，Spring 集成好
  ✅ AI Services 声明式 Agent
  ✅ 功能全面
  ❌ Agent 编排能力不如 LangGraph

Spring AI (Java)：
  ✅ Spring 原生，零学习成本
  ✅ Tool 注解简单
  ✅ 适合简单 Agent
  ❌ 多 Agent 协作需自研
```
