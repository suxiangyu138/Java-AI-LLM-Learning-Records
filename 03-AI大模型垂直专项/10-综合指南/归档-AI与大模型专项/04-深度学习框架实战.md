# 深度学习框架实战

## 📌 定位
**课外自学 | 第二梯队 | AI开发必备工具**

PyTorch是AI开发的第一语言(框架)——无论学术论文还是工业应用，PyTorch生态已经一统天下。从张量操作到模型训练到部署，这是AI开发的"双手"。

## 🎯 核心章节

### 1. PyTorch 基础
- **Tensor（张量）**：N维数组，可在GPU上运算——`torch.tensor/torch.from_numpy`
  - 数据类型(dtype)、设备(device: cpu/cuda)、形状(shape)
  - reshape/view/squeeze/unsqueeze/permute——张量变换
- **自动求导（Autograd）**：`loss.backward()`——计算图自动构建+链式法则自动求梯度

### 2. 模型构建
- **nn.Module**：所有模型的基类——`__init__`定义层, `forward`定义前向传播
- **常用层**：`nn.Linear`(全连接)、`nn.Conv2d`(卷积)、`nn.LSTM`、`nn.Transformer`
- **激活函数**：`nn.ReLU`、`nn.GELU`(Transformer)、`nn.Softmax`
- **损失函数**：`nn.CrossEntropyLoss`(分类)、`nn.MSELoss`(回归)

### 3. 训练循环（⭐ 核心模板）
```python
model = MyModel().to(device)
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)
for epoch in range(epochs):
    for x, y in dataloader:     # DataLoader：批量加载+shuffle+多线程
        pred = model(x.to(device))
        loss = criterion(pred, y.to(device))
        optimizer.zero_grad()   # 清空梯度！
        loss.backward()         # 反向传播
        optimizer.step()        # 更新参数
```

### 4. 模型微调（Fine-tuning）
- **迁移学习**：加载预训练权重(HuggingFace Hub/torchvision)→替换分类头→全量微调/部分冻结
- **LoRA（Low-Rank Adaptation）**：只训练低秩矩阵——显存省80%、训练快——大模型微调标配
- **PEFT库**：LoRA/P-Tuning/Prefix Tuning——参数高效微调的统一接口

### 5. 模型部署
- **ONNX**：通用模型交换格式——PyTorch→ONNX→任意推理框架
- **TensorRT**：NVIDIA推理加速——FP16/INT8量化
- **TorchScript**：PyTorch→可独立运行的静态图
- **vLLM**：大模型高性能推理——PagedAttention实现高吞吐

## ✅ 学习建议
- 必做：从头写一个MNIST手写数字分类训练→fine-tune一个BERT分类模型
- HuggingFace的Trainer API是最快上手的训练工具
- 关注vLLM——Java后端调用大模型时它是最主流的推理框架
