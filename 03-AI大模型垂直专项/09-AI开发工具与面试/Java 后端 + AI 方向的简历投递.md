# Java 后端 + AI 方向的简历投递

> **核心摘要**：从投递渠道、简历撰写、投递策略到面试准备的全流程指南。核心原则：内推 + 精准匹配 + 1 个 Java+AI 项目 + 量化成果。

---

## 一、投递渠道（优先级从高到低）

| 渠道 | 效果 | 操作方式 |
|------|------|---------|
| **内部推荐** | 最强 | 找学长/脉脉/牛客网内推码 |
| **官方招聘官网** | 主阵地 | 字节/阿里/腾讯/百度等官网投递 |
| **招聘平台** | 辅助海投 | 牛客网/BOSS 直聘/猎聘 |
| **校园渠道** | 补充 | 宣讲会、双选会 |

## 二、简历怎么写

### 2.1 技能栏（精准匹配 JD）

**Java 后端**（必写）：Java、Spring Boot、Spring Cloud、MySQL、Redis、MyBatis-Plus、MQ、分布式、JVM、Git

**AI 方向**（必须写）：大模型 API 调用、RAG、向量数据库（Milvus/FAISS）、Prompt 工程、LangChain、AI Agent

**格式示例**：
- 熟练：Java、Spring Boot、MySQL、Redis、RAG、大模型 API
- 了解：LangChain、Milvus、Spring Cloud

### 2.2 项目经历（重中之重）

**STAR 法则 + 数据量化**：

```
项目名：基于 Spring Boot + 大模型的智能问答系统
技术栈：Java、Spring Boot、MySQL、Redis、Qwen API、RAG、Milvus
职责：负责后端开发、RAG 流程实现、接口设计
成果：
- 支持 1000+ 并发请求，响应时间 < 300ms
- 文档问答准确率达 90%+
- 减少人工客服重复咨询 40%
```

> **重点**：必须有 1 个 Java + AI 结合项目。反例：图书管理系统、纯 CRUD、没有 AI、没有数据。

## 三、投递策略

### 3.1 时间窗口

| 阶段 | 时间 |
|------|------|
| 提前批 | 6 月开始（一定要参加，竞争小） |
| 秋招（最重要） | 7-10 月 |
| 春招（补录） | 2-4 月 |

### 3.2 投递节奏

- 每周 5-8 家，不要一天投几十家
- 同一公司间隔 7-14 天再投
- 海投 = 全沉；精准投 = 高通过率

### 3.3 岗位选择

优先搜索：后端开发（Java）、大模型应用开发、AI 工程/平台开发、RAG 开发、智能系统研发

**Base 优先**：北京、上海、深圳、杭州、广州、成都、合肥

## 四、投递后怎么做

1. 问内推人简历状态
2. 每天刷牛客看面经
3. 集中刷题：LeetCode 热题 100 + Java 集合/JVM/并发 + AI 技术栈
4. 准备项目讲稿：做什么、用了什么技术、你负责什么、难点怎么解决、量化结果

## 核心要点回顾

- 内部推荐效果最强，一定要走内推渠道
- 简历一页纸、PDF、排版干净、关键词密集
- 必须有至少 1 个 Java + AI 结合的项目，用 STAR 法则 + 数据量化
- 技能栏将 AI 方向单独列出，精准匹配 JD 关键词
- 提前批 6 月就开始，竞争小务必参加
- 不要海投、不要 Word 乱码、不要技能写"精通一切"
