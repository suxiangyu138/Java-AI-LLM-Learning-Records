## 6. 企业级能力与私有化部署

### 6.1 私有化部署方案

| 部署方式 | 说明 | 适用场景 |
|---------|------|---------|
| **一体机** | 软硬一体交付，开箱即用 | 中小型企业快速部署 |
| **私有云** | 基于阿里云私有云（Apsara Stack） | 大型企业/金融机构 |
| **混合云** | 推理在本地，训练在云上 | 数据敏感+需要云上训练能力 |
| **信创适配** | 适配国产CPU/GPU/OS | 政府/军工/央企 |

### 6.2 数据安全与合规

| 措施 | 说明 |
|------|------|
| **数据不出域** | 模型推理在本地完成，数据不离开企业内网 |
| **算法备案** | 已通过国家算法备案 |
| **等保合规** | 通过等保三级认证 |
| **审计日志** | 所有API调用记录可审计 |
| **角色权限** | 基于RBAC的细粒度权限管理 |
| **数据脱敏** | 自动识别并脱敏敏感信息（身份证/手机号等） |

### 6.3 典型案例

```
🏦 银行案例：
   某股份制银行使用通义千问私有化部署
   场景：信贷审批辅助、合规文档审查、客服知识库
   要求：数据不出银行内网、等保三级、审计日志完整

🏛️ 政府案例：
   某省级政务服务平台
   场景：政策咨询、办事指南、工单分类
   要求：信创适配、私有化部署、内容安全过滤
```

### 12.1 通义千问API（DashScope）

```java
// 阿里云灵积DashScope API
// 依赖：com.alibaba:dashscope-sdk-java:latest

import com.alibaba.dashscope.aigc.generation.Generation;
import com.alibaba.dashscope.aigc.generation.GenerationParam;
import com.alibaba.dashscope.aigc.generation.GenerationResult;
import com.alibaba.dashscope.common.Message;
import com.alibaba.dashscope.common.Role;
import com.alibaba.dashscope.utils.Constants;

public class TongyiDemo {
    public static void main(String[] args) {
        Constants.apiKey = System.getenv("DASHSCOPE_API_KEY");

        Generation gen = new Generation();
        GenerationParam param = GenerationParam.builder()
            .model("qwen3-max")
            .message(Message.builder()
                .role(Role.USER.getValue())
                .content("用Java写一个Spring Boot的全局异常处理器")
                .build())
            .temperature(0.7f)
            .maxTokens(2048)
            .build();

        GenerationResult result = gen.call(param);
        System.out.println(result.getOutput().getChoices()
            .get(0).getMessage().getContent());
    }
}
```
