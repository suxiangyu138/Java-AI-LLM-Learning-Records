## 3. 核心功能详解

### 3.1 文本对话

| 功能 | 说明 |
|------|------|
| **日常问答** | 百科知识、生活常识、学习辅导、情感咨询 |
| **创意写作** | 小红书文案、短视频脚本、公众号文章、朋友圈文案、小说 |
| **专业写作** | 工作汇报、商业计划书、项目方案、PPT大纲 |
| **翻译** | 中英日韩等主要语言互译 |
| **代码辅助** | 代码生成、Bug修复、代码解释（基础编程需求） |
| **角色扮演** | 可选择不同AI角色进行对话（学霸/职场精英/知心朋友等） |

### 3.2 AI搜索

| 特性 | 说明 |
|------|------|
| **实时联网** | 支持联网获取最新信息 |
| **内容来源** | 整合字节系内容（今日头条、抖音百科）+ 全网公开信息 |
| **结果呈现** | 结构化展示，含来源引用 |

### 3.3 文件处理

| 文件类型 | 支持操作 |
|---------|---------|
| **PDF** | 上传并提问，自动总结、关键信息提取 |
| **Word/PPT** | 上传并分析，生成摘要、改进建议 |
| **Excel** | 上传表格数据，自动分析趋势、生成图表 |
| **图片** | 上传图片，识别内容、提取文字、分析描述 |
| **长文本** | 支持较长文本输入（但不如Kimi单次20万字） |

### 3.4 语音对话

- **实时语音输入**：App端支持语音输入转文字
- **语音输出（TTS）**：AI回复可以用语音播报，多种音色可选
- **语音克隆**：支持创建个人专属AI声音（需录制样本）

## 12. Java开发者使用指南

### 12.1 豆包API调用

```java
// 豆包API（通过火山引擎方舟平台接入）
// 依赖：com.volcengine:volcengine-java-sdk-ark:latest

import com.volcengine.ark.runtime.Ark;
import com.volcengine.ark.runtime.model.completion.chat.*;

public class DoubaoDemo {
    public static void main(String[] args) {
        Ark ark = Ark.builder()
            .apiKey(System.getenv("VOLCENGINE_API_KEY"))
            .baseUrl("https://ark.cn-beijing.volces.com/api/v3")
            .build();

        ChatCompletion completion = ark.chat().completions().create(
            ChatCompletionCreateParams.builder()
                .model("doubao-pro-128k")
                .addUserMessage("用Java实现线程安全的单例模式")
                .temperature(0.7)
                .maxTokens(2048)
                .build()
        );

        System.out.println(
            completion.choices().get(0).message().content());
    }
}
```

### 12.2 Spring AI 集成豆包

```java
// application.yml
// spring.ai.openai.base-url=https://ark.cn-beijing.volces.com/api/v3
// spring.ai.openai.api-key=${VOLCENGINE_API_KEY}
// spring.ai.openai.chat.options.model=doubao-pro-128k

// 豆包API兼容OpenAI格式，可直接用Spring AI的OpenAI客户端
@RestController
public class DoubaoController {

    private final ChatClient chatClient;

    public DoubaoController(ChatClient.Builder builder) {
        this.chatClient = builder
            .defaultSystem("你是一个Java后端开发助手")
            .build();
    }

    @GetMapping("/doubao/chat")
    public String chat(@RequestParam String question) {
        return chatClient.prompt()
            .user(question)
            .call()
            .content();
    }
}
```
