# 人工智能导论（高阶）

> **优先级**：🟡 中优先级 | **类型**：校内提升专业课 | **方向**：AI 能力拔高

## 课程定位

**提升点**：搜索算法深度、逻辑推理体系、知识图谱构建与推理、Agent 架构、规划与决策

**适用人群**：AI 方向——做 AI Agent、知识库问答、智能决策系统

**学习目标**：能设计搜索和规划算法，理解知识表示和推理机制，能构建简单的智能 Agent

---

# 第一章：智能体（Agent）
- PEAS 模型：Performance × Environment × Actuators × Sensors
- Agent 分类：简单反射→基于模型→基于目标→基于效用→学习型
- 环境特性：完全可观察/部分可观察、确定性/随机性、离散/连续、单/多Agent
- 大模型 Agent：LLM 作为推理引擎，工具调用(Function Calling)，规划+记忆

# 第二章：搜索算法
- 无信息搜索：BFS(完备+最优，空间O(b^d))、DFS(不完备，空间O(bd))、迭代加深(结合两者优势)
- 启发式搜索：A* f(n)=g(n)+h(n)，h 可采纳(不高估)→A* 最优；h 一致→不会重复展开
- 启发式设计：松弛问题、子问题模式数据库、从经验学习
- 局部搜索：爬山法(局部最优)、模拟退火(概率跳出)、遗传算法(种群进化)、禁忌搜索(记忆)
- 对抗搜索：Minimax → Alpha-Beta剪枝(不改变结果的加速)——围棋/象棋 AI 基础

# 第三章：约束满足问题（CSP）
- 三要素：变量 X、域 D、约束 C
- 回溯搜索 + 约束传播(Forward Checking/Arc Consistency)
- 启发式：MRV(最小剩余值)、最少约束值、度启发式

# 第四章：知识表示与推理
- 逻辑基础：命题逻辑→一阶谓词逻辑→归结原理(反证法证明)
- 本体与语义网：RDF(主谓宾三元组)→OWL→知识图谱
- 产生式系统：IF-THEN规则→Rete算法高效匹配——专家系统
- 不确定性推理：贝叶斯网络(有向图+CPT)、D-S证据理论

# 第五章：知识图谱
- 构建流程：实体识别→关系抽取→实体链接→图谱补全→质量评估
- 知识推理：基于规则(resource description framework)、基于嵌入(TransE—平移不变性)、基于路径
- 知识图谱与大模型的融合：GraphRAG——实体级检索增强生成

# 第六章：规划（Planning）
- 经典规划：STRIPS 表示(状态→动作→新状态)、PDDL 语言
- 规划算法：状态空间搜索(前进/后退)、偏序规划(POP)、图规划(GraphPlan)
- 分层规划：HTN（层级任务网络）——分解高层任务为低层动作
- LLM + 规划：ReAct(Thought-Action-Observation交替)、Plan-and-Execute

# 第七章：多 Agent 系统
- 通信：言语行为理论(告知/请求/承诺)、KQML/FIPA ACL、黑板(共享内存)
- 协调：合同网协议(招标-投标-中标)、拍卖机制
- 博弈论基础：纳什均衡、囚徒困境、零和/非零和

# 第八章：AI 伦理与安全
- 价值对齐(Alignment)：RLHF→宪法AI(Constitutional AI)→可扩展监督
- 公平性：数据集偏见、模型歧视、公平指标
- 可解释性(XAI)：LIME(局部线性近似)、SHAP(博弈论Shapley值)、注意力可视化
