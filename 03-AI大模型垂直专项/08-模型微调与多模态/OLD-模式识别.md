# 模式识别

> **优先级**：🔴 高优先级（必选）| **类型**：校内提升专业课 | **方向**：AI 能力拔高

## 课程定位

**提升点**：贝叶斯决策理论体系、线性和非线性分类器设计、特征提取与降维方法、聚类分析、序列模式识别基础

**适用人群**：AI 方向必选——衔接传统机器学习与深度学习，多模态大模型(图文识别/语义匹配)的前置

**学习目标**：掌握从特征提取→分类器设计→结果评估的完整模式识别流程，能独立完成一个识别的完整项目

# 第一章：绪论
- 模式识别定义：用计算机实现人对事物/现象的自动分类和识别
- 系统框架：传感器→预处理→特征提取→分类/回归→后处理
- 模式识别 vs 机器学习 vs 深度学习的关系——三者互有重叠，PR 更侧重"识别任务"

# 第二章：贝叶斯决策理论
- 基于概率的决策：选择后验概率最大的类别——P(ω_i|x) = P(x|ω_i)P(ω_i)/P(x)
- 最小错误率决策 → 最小风险决策（不同错误代价不同，引入损失函数）
- 判别函数 g_i(x)：两类分类器——g(x)=g_1(x)-g_2(x)=0 即决策面
- 正态分布下的判别函数：协方差矩阵的形状（球形/相等/任意）决定分类器类型（线性/二次）

# 第三章：概率密度估计
- 参数估计：已知密度函数形式
  - 最大似然估计（MLE）：θ* = argmax Σlog P(x_k|θ)
  - 贝叶斯估计：θ 也是随机变量，P(θ|D) ∝ P(D|θ)P(θ)——最大后验（MAP）
- 非参数估计：不假设密度形式
  - Parzen 窗法：核函数叠加——h 过大（过平滑）vs h 过小（过噪声）
  - k 近邻估计：固定样本数 k，调整体积 V
- 高斯混合模型（GMM）与 EM 算法：E 步（计算后验）→ M 步（最大化似然）→ 迭代

# 第四章：线性分类器
- 线性判别函数：g(x) = wᵀx + w₀，w 决定方向，w₀ 决定位置
- 感知器准则：错分样本的损失函数最小化——线性可分时收敛，不可分时震荡
- Fisher 线性判别：寻投影使类间散度大 + 类内散度小——J(w)=|m₁-m₂|²/(s₁²+s₂²)
- MSE 准则与伪逆解：a = Y⁺b——与 Fisher 判别等价（两类时）

# 第五章：非线性分类器
- 分段线性分类器：每类多个原型，用最近原型分类
- KNN：直接投票——懒惰学习，无训练过程，但预测慢
- 决策树：递归划分空间——每个内部节点是一个坐标轴平行分割
- SVM（回顾）：核方法 + 最大间隔——从低维线性不可分→高维线性可分

# 第六章：特征提取与选择
- PCA（主成分分析）：K-L 变换，最大方差投影 → 降维 + 去噪
- LDA（线性判别分析）：有监督降维，Fisher 准则最大化
- 特征选择：Filter(方差/互信息)→ Wrapper(递归消除)→ Embedded(L1正则化)

# 第七章：聚类分析
- K-Means：类内平方和最小——本质是 EM，初始中心敏感
- 层次聚类：最小距离(单连接)/最大距离(完全连接)/平均距离
- DBSCAN：密度可达+密度相连——能发现任意形状、自动识别噪声
- 聚类有效性指标：轮廓系数、Davies-Bouldin 指数

# 第八章：序列与结构模式识别
- 动态时间规整（DTW）：对齐两个时间序列的最优路径——语音识别的经典方法
- 隐马尔可夫模型（HMM）：解码（Viterbi）、评估（前向-后向）、学习（Baum-Welch）
- 从 HMM 到 RNN/LSTM：深度学习方法取代传统序列模型的历程
