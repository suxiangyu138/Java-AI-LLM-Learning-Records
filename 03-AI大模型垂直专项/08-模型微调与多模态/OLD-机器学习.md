# 第一章：机器学习概述
- **定义**：Tom Mitchell——对于任务 T 和性能度量 P，计算机程序从经验 E 中学习，在 T 上的性能 P 随 E 提高
- **三大范式**：监督学习（有标签→分类/回归）、无监督学习（无标签→聚类/降维）、强化学习（奖惩信号）
- **三要素**：模型（假设空间 H）= 策略（损失函数/目标函数）+ 算法（优化方法）
- **归纳偏置（Inductive Bias）**：算法对假设空间的偏好——没有偏置无法从有限样本泛化

# 第二章：模型评估与选择
- **偏差-方差分解**：E[(y-f̂)²] = Bias² + Variance + 不可约误差——欠拟合(高偏差) vs 过拟合(高方差)
- **评估方法**：留出法（Hold-out）、交叉验证（K-Fold，K=5/10）、自助法（Bootstrap，小数据集）
- **性能度量**：
  - 分类：准确率(Acc)、精确率(P)、召回率(R)、F1(调和平均)、ROC-AUC、PR曲线
  - 回归：MSE、MAE、R²
- **比较检验**：交叉验证 t 检验、McNemar 检验——新模型是否显著优于旧模型？

# 第三章：线性模型
- **线性回归**：y = wᵀx + b，MSE 损失，解析解 w* = (XᵀX)⁻¹Xᵀy（需 XᵀX 可逆）
  - 梯度下降：w = w - α∇J(w)，α为学习率——特征缩放（标准化）很重要
- **Logistic 回归**：ŷ = σ(wᵀx+b)，σ(z)=1/(1+e⁻ᶻ)，交叉熵损失
  - 推导：从 MLE 出发，负对数似然即交叉熵——不是回归，是分类！
- **Softmax 回归**：多分类，输出概率分布，损失 = 交叉熵
- **正则化**：L1(Lasso，稀疏解，特征选择) → L2(Ridge，权重衰减，防过拟合) → Elastic Net

# 第四章：决策树与集成学习
- **决策树**：
  - 划分选择：ID3(信息增益，偏好取值多的特征) → C4.5(信息增益率) → CART(基尼系数/平方误差)
  - 剪枝：预剪枝(划分前判断，欠拟合风险) vs 后剪枝(建完后剪，开销大但效果好)
  - 连续值处理：二分法——找最优划分点
- **Bagging**：自助采样 → 并行训练多个模型 → 投票/平均——降低方差（Random Forest）
- **Boosting**：串行训练——每轮关注前一轮的错分样本——降低偏差
  - AdaBoost：指数损失，调整样本权重
  - GBDT：拟合上一轮的负梯度（残差近似）
  - XGBoost：二阶导展开 + 正则项 + 列采样 + 稀疏感知——工程优化的集大成者
  - LightGBM：直方图 + GOSS(单边采样) + EFB(互斥特征绑定)——更快
- **Stacking**：多模型输出作为新特征，用次级学习器组合

# 第五章：支持向量机（SVM）
- **线性可分 SVM**：最大化间隔（Margin）= 2/|w|——凸二次规划，全局最优解
- **对偶问题**：引入拉格朗日乘子 α，KKT 条件——支持向量 = α_i > 0 的样本
- **软间隔**：松弛变量 ξ，惩罚参数 C——C 越大越不能容忍误分类
- **核技巧（Kernel Trick）**：xᵀx' → K(x, x')——在原始空间计算等价于高维空间的内积
  - 线性核、多项式核、RBF(高斯)核——K(x,z) = exp(-γ|x-z|²)
- **SMO 算法**：每次优化两个 α 变量——高效求解

# 第六章：贝叶斯分类器
- **贝叶斯决策论**：选择后验概率最大的类别——最小化期望损失
- **朴素贝叶斯**：P(x|y) = ∏P(x_i|y)（属性条件独立假设——"朴素"的来源）
  - 虽假设强但实践中效果常出奇地好
- **半朴素贝叶斯**：SPODE / TAN——放松独立性假设，考虑部分属性间的依赖

# 第七章：聚类
- **K-Means**：EM 思想——E 步分配，M 步更新中心——收敛到局部最优
  - K 值选择：肘部法（SSE 曲线拐点）、轮廓系数
  - K-Means++：改进初始中心——距离越远被选中的概率越大
- **高斯混合模型（GMM）**：软聚类——每个样本属于每个簇的概率
- **DBSCAN**：密度聚类——基于 ε 邻域 + minPts 核心点 → 密度可达 → 簇
- **层次聚类**：AGNES（自底向上凝聚）vs DIANA（自顶向下分裂）

# 第八章：降维
- **PCA（主成分分析）**：协方差矩阵特征分解 → 选最大特征值对应的特征向量——最大方差方向投影
  - 本质：最近重构性（点到投影面距离最小）⟺ 最大可分性（投影点方差最大）
- **LDA（线性判别分析）**：有监督降维——最大化类间散度/最小化类内散度
- **t-SNE**：非线性降维，适合可视化——保持局部结构、数据点相似度用 t 分布
