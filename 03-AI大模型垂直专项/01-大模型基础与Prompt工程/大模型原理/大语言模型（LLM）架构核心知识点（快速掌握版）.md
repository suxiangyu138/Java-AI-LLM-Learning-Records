## 1. 核心基础：Transformer 架构

**核心地位**：LLM 的架构基石，彻底替代了传统的循环神经网络（RNN）和长短期记忆网络（LSTM）。目前全球所有主流大语言模型（GPT 系列、LLaMA 系列、文心一言等）均以 Transformer 为基础进行优化迭代。

**核心设计**：整体采用"编码器-解码器（Encoder-Decoder）"或"仅解码器（Decoder-Only）"两种结构。

> **重点**：仅解码器结构凭借生成式任务的适配优势，成为 GPT 系列、LLaMA 系列等主流 LLM 的首选架构。

## 2. 两大核心结构

### 2.1 仅解码器（Decoder-Only）架构（主流 LLM 首选）

| 维度 | 说明 |
|------|------|
| **适用场景** | 生成式任务：对话、文案写作、代码生成、小说续写 |
| **典型代表** | GPT-3、GPT-4、LLaMA 系列、ChatGLM 系列 |
| **核心逻辑** | 基于输入内容，按照语言时序逐 token 生成后续内容，依赖**自回归机制**——生成每个 token 时都参考前面所有已生成的 token |
| **关键优化** | 叠加**因果掩码（Causal Mask）**，屏蔽后续 token 信息，确保生成时不会提前看到后续内容 |

### 2.2 编码器-解码器（Encoder-Decoder）架构

| 维度 | 说明 |
|------|------|
| **适用场景** | 有明确"输入-输出"对应关系的任务：机器翻译、文本摘要、问答匹配、文本改写 |
| **典型代表** | T5（Google）、BART（Facebook） |
| **核心逻辑** | 编码器负责"理解输入内容"，将输入转化为语义向量；解码器负责"生成目标输出"，持续参考编码器输出的语义向量 |

## 3. Transformer 核心模块

所有 LLM 的架构本质上都是对以下 Transformer 核心模块的堆叠、组合与优化：

| 模块 | 核心作用 | 关键说明 |
|------|---------|---------|
| **多头注意力机制（Multi-Head Attention）** | 让模型同时关注输入文本的不同位置，精准捕捉文本内部关联关系。"多头"设计让模型同时捕捉语法、语义、逻辑等多维度特征 | Transformer 核心中的核心 |
| **前馈神经网络（FFN）** | 对注意力输出的语义向量进行非线性转换，强化特征提取能力，帮助模型学习更复杂的语言规律 | 两层线性变换+激活函数 |
| **层归一化（Layer Normalization）** | 稳定训练过程，避免梯度消失或梯度爆炸。正是有了层归一化，LLM 才能实现数十层乃至上百层的深度堆叠 | 每个注意力层、FFN 层后均需加入 |
| **残差连接（Residual Connection）** | 将每层输入直接传递到输出端，形成残差路径，让梯度顺利传递到深层网络，解决深度模型训练困难问题 | 与层归一化相互配合 |

## 4. 架构核心逻辑

LLM 架构的本质可以概括为：

> **N 层 Transformer 核心模块堆叠 + 输入/输出处理模块**

其核心工作逻辑是：通过**注意力机制**精准捕捉语言内部的关联关系，结合**自回归机制**或**编码-解码机制**实现语言的理解与生成。模型的层数、注意力头数、参数量直接决定 LLM 的能力上限。

## 5. 关键补充

### 参数量

模型的参数量由**注意力头数、Transformer 层数量、隐藏层维度**三个核心参数共同决定。例如 GPT-4 的参数量达到千亿级。通常参数量越大，模型拟合人类语言规律的能力越强，但训练和推理成本也随之大幅提升。

### 改进方向

所有 LLM 的架构优化本质上都是对 Transformer 核心模块的调整与升级：

- 优化注意力机制以提升效率
- 加入 **MoE（混合专家架构）** 以降低计算成本
- 轻量化设计以适配端侧设备

> **重点**：所有改进的核心目标都是在提升模型能力的同时，降低训练和推理成本，增强生成内容的质量和连贯性。

## 核心要点回顾

- Transformer 是所有主流 LLM 的架构基石
- Decoder-Only 架构是当前主流 LLM 的首选
- 四大核心模块：多头注意力、FFN、层归一化、残差连接
- 参数量由注意力头数、层数、隐藏层维度共同决定
- 架构改进方向：提升效率、降低成本、适配端侧
