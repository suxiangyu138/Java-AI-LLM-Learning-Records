## 1. 基础核心概念

### 1.1 大语言模型（LLM）

基于 **Transformer 架构**、海量文本数据预训练的大规模深度神经网络，具备理解、生成、推理、记忆等通用语言能力。当前主流 LLM 参数规模从数十亿到万亿级不等。

### 1.2 参数规模

模型参数是能力核心指标。参数越多，泛化能力、上下文理解能力、复杂任务处理能力越强，但同时算力和推理成本也越高。

### 1.3 生成式 AI

大模型核心范式，通过**概率采样**逐字生成文本，属于自回归生成模式。模型每次生成一个 token，并将其作为下一步生成的输入。

### 1.4 上下文窗口

模型单次可接收并理解的最大输入与输出 token 总长度，直接决定了长文本和长对话的处理能力。常见窗口大小从 4K 到 128K token 不等。

## 2. 底层核心架构：Transformer

### 2.1 两大核心模块

| 模块 | 功能 | 代表任务 |
|------|------|----------|
| **编码器（Encoder）** | 理解输入语义 | 语义理解、分类、抽取 |
| **解码器（Decoder）** | 负责内容生成 | 文本生成（主流 LLM 首选纯 Decoder 架构） |

### 2.2 关键机制

- **自注意力机制（Self-Attention）**：捕捉文本长距离依赖，计算字词间的关联权重，是 Transformer 的核心创新。
- **多头注意力（Multi-Head Attention）**：将注意力拆分为多个子空间，多维度并行捕捉语义、语法、逻辑特征。
- **位置编码（Positional Encoding）**：由于 Transformer 无时序感知能力，需通过位置编码注入文本顺序信息。
- **前馈神经网络（FFN）**：对注意力输出进行非线性特征转换，强化模型表达能力。

## 3. 训练全流程

### 3.1 预训练（Pre-training）

- **数据**：海量无标注通用文本（书籍、网页、论文、代码等）
- **目标**：**语言建模**，预测下一个 token，学习通用语法、常识、世界知识、逻辑
- **特点**：自监督学习，奠定模型基础能力；训练成本最高，通常需要数周至数月

### 3.2 微调（Fine-tuning）

- **数据**：少量高质量有标注垂直数据
- **作用**：适配特定场景（客服、代码、医疗、教育），缩小通用模型与业务场景的差距

### 3.3 对齐训练（人类偏好对齐）

| 方法 | 说明 |
|------|------|
| **SFT（有监督微调）** | 使用高质量人工对话数据，教会模型遵循指令 |
| **RLHF（基于人类反馈的强化学习）** | 依据人类打分优化输出偏好（合规、有用、简洁） |
| **RLAIF（AI 反馈强化学习）** | 用 AI 替代人类评分，降低对齐成本，主流轻量化方案 |

## 4. 关键技术名词

- **Token**：模型最小处理单元。中文约 1 个汉字 ≈ 2 token，英文以单词或子词拆分。Token 是计费和上下文限制的基础单位。
- **嵌入层（Embedding）**：将文字、符号转化为低维稠密向量，将语义转化为模型可计算的数值。
- **推理（Inference）**：模型接收输入、计算并生成内容的过程，分为本地部署推理和 API 云端推理。
- **量化（Quantization）**：压缩模型参数精度（FP16→INT8/INT4），降低显存占用并提升推理速度，是本地部署的核心技术。
- **稀疏模型 / 混合专家（MoE）**：不激活全部参数，仅调用部分专家模块参与计算，实现"大参数、低推理成本"，主流超大模型标配。

## 5. 主流应用技术栈

### 5.1 提示词工程（Prompt Engineering）

通过优化指令格式、逻辑、示例，零成本提升模型输出质量。包含零样本（Zero-shot）、少样本（Few-shot）、思维链（Chain-of-Thought, CoT）等方法。

### 5.2 RAG（检索增强生成）

核心公式：**私有知识库检索 + 大模型生成**。解决大模型知识滞后、幻觉、无法使用私有数据的痛点。典型流程为：用户查询 → 向量检索相关知识片段 → 将检索结果拼接为提示词 → 大模型生成回答。

### 5.3 Agent（智能体）

模型具备**规划、工具调用、记忆、反思**能力，可自主完成复杂任务（联网搜索、代码执行、工具联动）。Agent 是 LLM 从"被动回答"走向"主动执行"的关键形态。

### 5.4 大模型微调

分为全量微调、**LoRA**（低秩适应）轻量化微调、**QLoRA**（量化低秩适应）低资源本地微调，适配个性化、垂直场景需求。

## 6. 核心痛点与局限

1. **幻觉**：生成虚假事实、错误数据、编造论据，是落地应用的首要解决问题。
2. **知识时效性**：预训练数据存在时间截断，无法获取实时新闻和动态信息。
3. **上下文限制**：超长文本处理成本高，长对话易遗忘前文关键信息。
4. **算力与成本**：训练、部署、推理对 GPU 显存和算力要求高，企业级落地存在成本门槛。
5. **安全与合规**：易生成违规、偏见、有害内容，需建立内容过滤和安全对齐机制。

## 7. 模型分类

| 分类 | 代表模型 | 特点 |
|------|----------|------|
| **闭源大模型** | GPT-4、文心一言、通义千问 | 能力强、开箱即用 |
| **开源大模型** | LLaMA、Qwen、DeepSeek、GLM | 可本地部署、二次开发 |
| **垂直领域大模型** | Code Llama、BioBERT、FinBERT | 代码、医疗、教育等专属场景 |

## 8. 多模态大模型

融合文本、图片、音频、视频的模型形态，核心能力包括：
- 图文理解与生成
- 语音对话
- 视频内容解析

底层架构在 Transformer 基础上新增**视觉编码器**和**音频编码器**，实现对多模态输入的统一表征。代表模型包括 GPT-4V、Qwen-VL、Gemini 等。

## 核心要点回顾

- LLM 的核心是基于 Transformer 架构、通过海量文本预训练获得的大规模语言模型
- 训练三阶段：预训练（奠定基础）→ 微调（适配任务）→ 对齐（符合人类偏好）
- 主流应用技术栈：提示词工程、RAG、Agent、微调
- 核心竞争力指标：参数规模、上下文窗口长度、对齐质量
- 核心痛点：幻觉、知识时效性、上下文限制、算力成本、安全合规
