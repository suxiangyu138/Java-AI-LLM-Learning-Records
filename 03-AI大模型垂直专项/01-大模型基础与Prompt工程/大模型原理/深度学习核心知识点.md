## 1. 深度学习基础概念

### 1.1 神经网络基本组成

- **神经元**、**感知机**、**多层感知机（MLP）**
- **输入层**、**隐藏层**、**输出层**
- 核心参数：权重 $W$、偏置 $b$

### 1.2 非线性能力

单纯线性层叠加仍为线性变换，**激活函数**引入非线性是深层网络的核心能力来源。

### 1.3 超参数

| 参数 | 说明 |
|------|------|
| **学习率** | 控制参数更新的步长 |
| **批次大小（batch_size）** | 每次训练使用的样本数 |
| **迭代轮数（epoch）** | 完整遍历训练集的次数 |
| **网络层数** | 模型的深度 |
| **隐藏层维度** | 每层神经元的数量 |

## 2. 激活函数（LLM 高频）

| 函数 | 公式 | 用途 |
|------|------|------|
| **ReLU** | $\text{ReLU}(x) = \max(0, x)$ | 解决梯度消失，计算简单，通用基础激活函数 |
| **GELU** | — | LLaMA、Qwen、GPT 系列默认激活，平滑非线性，收敛效果更好 |
| **Sigmoid / Tanh** | — | 二分类、早期 NLP 模型，易梯度消失，大模型极少使用 |
| **Swish** | — | 高阶大模型、MoE 结构常用 |

> **重点**：GELU 是当前主流大模型的默认激活函数。

## 3. 损失函数与优化

### 3.1 核心损失函数

| 损失函数 | 用途 | 说明 |
|----------|------|------|
| **交叉熵损失（Cross-Entropy）** | 分类任务、LLM 预训练/微调**标配损失** | 衡量预测分布与真实分布的差距 |
| **均方误差（MSE）** | 回归任务 | 不用于大模型 |

### 3.2 优化器

| 优化器 | 说明 |
|--------|------|
| **SGD** | 随机梯度下降，基础优化器 |
| **Adam / AdamW** | 大模型训练、SFT 微调**主流优化器**，自适应学习率、动量机制，收敛更快更稳 |

### 3.3 梯度核心理论

- **前向传播**：输入数据逐层计算，得到预测值
- **反向传播**：基于**链式法则**计算损失对所有参数的梯度
- **梯度下降**：更新参数以最小化损失

$$
\theta \leftarrow \theta - \eta \nabla L
$$

- **常见问题**：梯度消失、梯度爆炸导致深层网络无法训练

## 4. 正则化与泛化能力

### 4.1 过拟合与欠拟合

| 问题 | 表现 | 原因 |
|------|------|------|
| **过拟合** | 训练集效果极好，测试/业务场景效果差 | 模型过于复杂，记住了训练数据噪声 |
| **欠拟合** | 训练和测试效果都差 | 模型能力不足，未捕捉到数据规律 |

### 4.2 解决方案

| 方法 | 说明 |
|------|------|
| **L1 / L2 正则化** | 限制权重大小，防止过拟合 |
| **Dropout** | 训练时随机失活部分神经元 |
| **早停（Early Stopping）** | 验证集性能不再提升时停止训练 |
| **数据增广** | 扩展训练数据多样性 |

### 4.3 归一化

| 归一化方法 | 说明 |
|-----------|------|
| **LayerNorm** | Transformer 标配，稳定深层网络训练 |
| **BatchNorm** | 多用于计算机视觉，LLM 基本不用 |

## 5. 经典网络结构（NLP 演进线）

| 结构 | 说明 | 状态 |
|------|------|------|
| **RNN / LSTM / GRU** | 传统序列模型，解决文本时序依赖 | 被 Transformer 淘汰 |
| **Encoder-Decoder 架构** | 早期机器翻译架构 | Transformer 沿用此结构思想 |
| **Transformer** | 彻底解决长文本依赖，支持并行训练 | 所有现代 LLM 底层架构 |

## 6. Transformer 核心模块

| 模块 | 说明 |
|------|------|
| **自注意力机制（Self-Attention）** | 建模文本全局上下文，每个词与全局所有词计算关联度 |
| **缩放点积注意力** | $\text{Attention}(Q,K,V) = \text{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$。$Q$ 为查询、$K$ 为键、$V$ 为值；$\sqrt{d_k}$ 缩放防止内积过大导致 softmax 饱和 |
| **多头注意力（Multi-Head Attention）** | 拆分多组 Q/K/V，并行捕捉不同语义特征，增强表达能力 |
| **位置编码（Positional Encoding）** | 注意力本身无序，通过三角函数/可学习位置编码注入序列顺序信息 |
| **前馈网络（FFN）** | 每层独立非线性变换，提升模型表征能力 |

## 7. 预训练与微调范式

| 阶段 | GPT 系列 | BERT 系列 |
|------|---------|----------|
| **预训练** | 自回归语言建模，预测下一个 token | 掩码语言建模，双向语义 |
| **微调** | **SFT** 监督微调，注入对话和指令遵循能力；**LoRA / QLoRA** 轻量微调，仅训练少量参数，低成本落地 |
| **对齐** | **RLHF / RLAIF**：解决大模型有害输出、回答不可控问题 |

## 8. 嵌入与向量表示（RAG 底层）

| 概念 | 说明 |
|------|------|
| **词嵌入（Embedding）** | 将离散文字映射为高维稠密向量，实现文本数字化 |
| **向量语义** | 语义相近的文本在向量空间距离近，是 RAG 检索的核心原理 |
| **相似度计算** | 余弦相似度、欧氏距离，向量数据库召回底层逻辑 |

## 9. 深度学习工程基础

| 概念 | 说明 |
|------|------|
| **张量（Tensor）** | 深度学习统一数据格式（多维数组） |
| **计算图** | 自动求导的底层实现，框架自动完成反向传播 |
| **混合精度训练** | FP16/FP8，降低显存占用、加速训练 |
| **模型量化** | 4bit/8bit，本地部署和私有化推理必备 |

## 10. 学习优先级

| 级别 | 内容 |
|------|------|
| **必学** | 激活函数、交叉熵、反向传播、梯度下降、LayerNorm、Transformer 注意力机制、Embedding |
| **进阶** | 优化器 AdamW、过拟合、位置编码、SFT 微调原理 |
| **高阶（选学）** | MoE 混合专家、模型蒸馏、量化压缩、分布式训练 |

## 核心要点回顾

- 神经网络的核心三要素：权重参数、激活函数（非线性）、损失函数（优化目标）
- 主流 LLM 使用 GELU 激活函数、AdamW 优化器、交叉熵损失
- LayerNorm 是 Transformer 的标配归一化方案
- Transformer 核心五件套：自注意力、多头注意力、缩放点积、位置编码、FFN
- 预训练 + 微调 + 对齐是 LLM 的完整训练范式
- Embedding 向量化是 RAG 检索的底层基础
