## 1. 主流大模型分类与核心特性

### 1.1 通用基础大模型（基座模型 / Base Model）

| 维度 | 说明 |
|------|------|
| **代表模型** | Llama3、Qwen 基座、DeepSeek 基座、GLM 基座 |
| **核心特性** | 海量文本预训练，擅长续写、补全、基础常识；无对话对齐，语气生硬，不能直接聊天；上下文长、知识库广，适合二次微调 |
| **定位** | 原材料，不直接面向用户 |

### 1.2 对话大模型（Chat 对齐模型）

| 维度 | 说明 |
|------|------|
| **代表模型** | GPT-3.5/4、通义千问、GLM-4、DeepSeek-Chat、豆包、星火 |
| **核心特性** | 在基座基础上做 SFT 人类对齐，懂对话、懂规则、拒绝有害内容；逻辑问答、代码、文案、解释能力强；自带角色扮演、多轮上下文记忆 |
| **定位** | 直接聊天、业务问答、日常 AI 服务 |

### 1.3 代码大模型

| 维度 | 说明 |
|------|------|
| **代表模型** | CodeLlama、DeepSeek-Coder、Qwen-Code |
| **核心特性** | 专攻代码生成、查 Bug、写 SQL、写 Java/Python；理解主流框架（SpringBoot、Docker、Redis、MQ 等） |
| **定位** | 后端开发、算法刷题、项目脚手架生成 |

### 1.4 多模态大模型（文本 + 图像）

| 维度 | 说明 |
|------|------|
| **代表模型** | GPT-4V、Qwen-VL、GLM-4V |
| **核心特性** | 识图、读图、解析截图、公式识别、图表分析 |

### 1.5 垂直领域大模型

| 维度 | 说明 |
|------|------|
| **代表模型** | 金融、医疗、法律、教育专属模型 |
| **核心特性** | 行业术语精准，通用能力弱，企业私有化常用 |

## 2. 大模型三种部署方式

### 2.1 公有云 API 调用（最简单，企业最常用）

| 维度 | 说明 |
|------|------|
| **代表平台** | 阿里百炼、智谱、DeepSeek、百度文心 |
| **特点** | 无需显卡、无需部署、一行代码调用；按量计费、开箱即用、稳定性强；数据走外网，隐私敏感业务不适用 |
| **适用场景** | 个人开发、ToC 业务、快速上线 |

### 2.2 本地私有化部署（个人 / 内网项目）

| 维度 | 说明 |
|------|------|
| **工具** | Ollama（首选）、LM Studio、Text Generation WebUI |
| **硬件门槛** | 7B 小模型：CPU 可跑，无需显卡；14B+：需要 N 卡独显（显存 >= 8GB） |
| **特点** | 完全离线、数据不外泄、免费；自带 OpenAI 兼容接口，对接 RAG/Java 极其方便 |

> **重点**：Ollama 是本地部署的首选工具，支持一键部署主流开源大模型。

### 2.3 企业级私有化部署（高性能）

| 维度 | 说明 |
|------|------|
| **框架** | vLLM、TensorRT、FastGPT |
| **硬件** | 专业 GPU 服务器、显存集群 |
| **特点** | 高并发、低延迟、可微调、内网隔离 |
| **适用场景** | 政府、国企、金融、涉密系统 |

## 3. AI 大模型 vs Agent 区别与联系

### 3.1 AI 大模型（LLM）

**本质**：一个"会说话、会推理、有知识"的语言大脑。

| 能力 | 局限 |
|------|------|
| 阅读理解 | 没有主动行动能力 |
| 逻辑推理 | 不能联网、不能操作软件 |
| 写代码 | 不能查数据库、不能定时任务 |
| 常识问答 | 只会"被动回答"，不会主动规划 |
| 文本生成 | — |

> **一句话总结**：大模型 = 大脑，只有思考能力，没有手脚。

### 3.2 AI Agent（智能代理）

**本质**：以 LLM 为大脑，搭配"规划 + 工具 + 记忆 + 行动"的完整智能体。

| 核心组件 | 说明 |
|----------|------|
| **LLM 大脑** | 负责思考、决策、拆解任务 |
| **工具调用** | 联网搜索、查数据库、调用 API、运行代码、操作文件 |
| **任务规划** | 复杂问题分步拆解、多步骤执行 |
| **长期记忆** | 记住历史任务、用户偏好、业务上下文 |

> **一句话总结**：Agent = 大模型 + 手脚 + 执行力 + 规划能力。

## 4. 直白对比

| 维度 | 普通大模型（LLM） | AI Agent |
|------|------------------|----------|
| **核心能力** | 被动问答、文本生成 | 主动规划、自主完成复杂任务 |
| **行动能力** | 无，只能文字回答 | 可调用工具、联网、操作服务 |
| **任务复杂度** | 简单单步问题 | 多步骤复杂目标 |
| **示例** | "解释 RabbitMQ"、"写一段 Java 代码" | "帮我完成一份后端学习计划 + 搜资料 + 整理 MD 笔记 + 生成目录" |
| **依赖** | 纯模型本身 | LLM + 工具集 + 调度框架 |

## 5. 二者联系与层级关系

### 5.1 LLM 是 Agent 的基础与唯一大脑

没有大模型的理解、推理、思考，Agent 无法进行任何决策。

### 5.2 Agent 是 LLM 的能力扩展

给大模型安装上工具调用、任务拆解、记忆管理三大能力，让大模型从"只会聊天"变成"能干实事"。

### 5.3 层级关系

```
大模型 (LLM)
    ↓ 作为核心
AI Agent（智能体）
    ↓ 上层应用
RAG 知识库、自动化办公、智能助手、业务机器人
```

## 6. 技术栈组合

未来完整的 AI 应用闭环：

| 组件 | 方案 |
|------|------|
| **LLM** | 本地 Ollama 部署 / 公有 API 调用 |
| **RAG** | Milvus 向量库 + 文档检索 |
| **Agent** | 工具调用、任务编排、对接后端服务 |

## 核心要点回顾

- 大模型分五类：基座、对话、代码、多模态、垂直行业模型
- 部署分三种：公有 API（最简单）、本地离线（Ollama）、企业集群（vLLM）
- LLM = 纯思考大脑，被动应答
- Agent = 以 LLM 为核心，带工具、规划、行动的智能体
- 关系：LLM 是基础，Agent 是增强形态，落地复杂 AI 应用全靠 Agent
