## 1. 核心本质

**Prompt** = 给大模型的"指令说明书"。大模型没有自主意识，提示词写得越清楚，结果越精准。提示词工程的本质是学会规范、约束和引导大模型输出。

---

## 2. 万能黄金公式

所有场景通用的 Prompt 结构：

```
1. 身份设定（你是谁）
2. 任务目标（要做什么）
3. 输入素材（给什么内容）
4. 规则约束（禁止/要求）
5. 输出格式（怎么呈现）
6. 补充细节（语气、长度、风格）
```

套用此结构，可覆盖 90% 以上的通用提问场景。

## 3. 五大核心基础技巧

### 3.1 角色设定法（效果最强）

给模型绑定专业身份，直接提升输出专业性：

```text
你是一名 5 年经验的 Java 后端开发工程师，精通 SpringBoot、RabbitMQ、ES。
请用通俗易懂、结构化的方式回答问题，不要废话。
```

### 3.2 明确约束与边界

限制模型不乱答、不发散：

- 禁止编造数据
- 只回答给定材料内的内容（RAG 必备）
- 禁止过度拓展
- 指定回答精简或详细

### 3.3 结构化输出要求

强制指定输出格式：

```text
回答必须使用 Markdown 格式，分点罗列，关键内容加粗，代码使用代码块包裹。
```

### 3.4 少样本引导（Few-shot）

提供 1-2 个示例，让模型模仿格式。适合格式固定、文案撰写、数据处理等场景。

### 3.5 思维链（CoT）

复杂问题必用，准确率可翻倍：

```text
请一步步拆解思考，分步推导，最后给出最终答案。
```

## 4. 四种高阶经典框架

### 4.1 CRISPE 通用框架

| 要素 | 说明 |
|------|------|
| **C**ontext | 背景 |
| **R**equirement | 要求 |
| **I**nformation | 已知信息 |
| **S**tyle | 风格 |
| **P**ersona | 身份 |
| **E**xample | 示例 |

### 4.2 RTA 极简框架（日常最快）

| 要素 | 说明 |
|------|------|
| **R**ole | 角色 |
| **T**ask | 任务 |
| **A**nswer | 输出要求 |

### 4.3 CoT 思维链（逻辑推理）

适用于算法、数学、原理推导、系统设计等场景。

### 4.4 RAG 专用 Prompt

```text
请严格仅基于下方参考资料回答用户问题，
禁止编造、禁止知识库外内容，
资料不足时直接说明"资料有限，无法回答"。
参考资料：
{{context}}
用户问题：
{{question}}
```

## 5. 高频场景现成模板

### 5.1 技术学习/知识点总结

```text
你是计算机专业资深讲师，帮我总结以下知识点：
1. 内容精简，只保留核心考点
2. 使用 Markdown 分级标题+列表
3. 难点单独加粗标注
4. 不要冗余废话

知识点内容：
【粘贴内容】
```

### 5.2 写代码

```text
你是资深 Java 后端工程师，完成以下需求：
- 代码规范、加必要注释
- 时间复杂度、空间复杂度简要说明
- 只输出核心代码，拒绝冗余
- 如有多种方案，给出最优解

需求：
```

### 5.3 优化文案/笔记

```text
帮我优化这段文字：
- 逻辑梳理通顺
- 精简压缩，去除口水话
- 保持原意不变
- 适合作为学习笔记存档
```

### 5.4 Agent 任务约束

```text
你是智能 Agent，需遵循：
1. 复杂任务自动分步拆解
2. 需要外部信息时主动说明
3. 严格按顺序执行任务
4. 不擅自拓展无关操作
```

## 6. 新手最容易犯的错误

| 错误 | 错误示例 | 正确做法 |
|------|----------|----------|
| 问题太笼统 | "介绍 Docker" | "用大白话+结构化，介绍 Docker 核心作用、概念和场景" |
| 不给背景 | 无任务场景说明 | 明确用途（考试、开发还是背诵） |
| 不限制格式 | 输出杂乱无章 | 明确 Markdown、列表、表格等格式 |
| 不限制幻觉 | 模型瞎编数据 | 加"禁止编造事实，无依据内容禁止输出" |

## 7. 大模型幻觉克制方法

在 Prompt 中固定添加一句话：

```text
所有内容必须有据可依，不确定内容直接说明，禁止编造专业术语、数据、案例。
```

---

## 8. 极简记忆总结

1. **基础四件套**：定身份 + 说需求 + 给材料 + 限格式
2. **复杂问题加**：分步思考（CoT）
3. **固定格式用**：少样本示例（Few-shot）
4. **RAG 必加**：知识库约束，禁止编造
5. **一切 AI 应用（LLM+RAG+Agent）**，都靠高质量 Prompt 兜底

---

## 9. 核心要点回顾

- Prompt 的本质是给大模型的指令说明书，写得越清楚结果越精准
- 万能公式：身份 + 任务 + 素材 + 约束 + 格式 + 细节
- 五大核心技巧：角色设定、明确约束、结构化输出、Few-shot、CoT
- CRISPE 框架适合复杂场景，RTA 框架适合日常快速任务
- RAG 场景必须在 Prompt 中加入知识库约束以防止幻觉
- 新手常见四大错误：问题笼统、不给背景、不限制格式、不限制幻觉
