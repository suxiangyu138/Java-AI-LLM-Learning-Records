## 1. 线性代数（大模型根基）

### 1.1 向量与矩阵

- **向量**：词向量、Embedding、隐藏层向量，LLM 中所有数据本质都是高维向量
- **矩阵**：模型权重矩阵、参数存储、线性变换
- **维度**：$d_{model}$ 模型维度、多头注意力维度、Embedding 维度

### 1.2 向量核心运算

**点积（内积）**：

$$
\boldsymbol{a} \cdot \boldsymbol{b} = \sum_{i=1}^n a_i b_i
$$

> **重点**：点积是注意力打分和向量相似度计算（RAG 召回核心）的基础运算。

**余弦相似度**：

$$
\cos(\boldsymbol{a}, \boldsymbol{b}) = \frac{\boldsymbol{a} \cdot \boldsymbol{b}}{\|\boldsymbol{a}\| \|\boldsymbol{b}\|}
$$

作用：RAG 文本相似度匹配、Embedding 检索。

### 1.3 矩阵运算

| 运算 | 作用 |
|------|------|
| **矩阵乘法** | Transformer 全连接层、权重计算核心 |
| **转置、逆矩阵、秩** | 模型参数压缩、**低秩适应（LoRA 微调核心）** |
| **特征分解** | 预训练模型特征提取、降维 |

### 1.4 范数

| 范数 | 作用 |
|------|------|
| **L2 范数** | 向量长度归一化：Embedding 归一化、防止梯度爆炸 |
| **矩阵范数** | 权重正则化 |

## 2. 微积分与优化理论（训练/微调核心）

### 2.1 基础导数与偏导数

- **多元函数偏导**：神经网络参数更新的基础
- **链式法则**：**反向传播核心公式**

### 2.2 梯度与梯度下降

- **梯度**：损失函数对权重的偏导集合，指向损失上升的方向
- **梯度下降公式**：

$$
\theta = \theta - \eta \nabla L(\theta)
$$

其中 $\eta$ 为学习率，是 LLM 微调和 SFT 训练必须理解的参数。

### 2.3 激活函数导数（LLM 高频）

| 函数 | 用途 |
|------|------|
| Sigmoid、Tanh | 早期 NLP |
| **ReLU / GELU / Swish** | 现代大模型主流激活函数，引入非线性 |

### 2.4 极值与凸优化

- **局部最优 / 全局最优**：大模型预训练面临的高维优化困境
- **正则化（L1/L2）**：防止过拟合，在微调小数据集时必备

## 3. 概率与信息论（NLP/LLM 本质）

### 3.1 基础概率

| 概念 | 作用 |
|------|------|
| **条件概率、联合概率** | 语言建模条件分布的基础 |
| **最大似然估计（MLE）** | 预训练任务的优化目标 |

### 3.2 语言建模核心分布

- **自回归建模（GPT）**：$P(x_n | x_1, x_2, ..., x_{n-1})$
- **掩码建模（BERT）**：双向条件概率

### 3.3 信息论（重中之重）

**熵（信息熵）**：

$$
H(X) = -\sum p(x) \log p(x)
$$

衡量文本的不确定性和混乱程度。

**交叉熵**：

$$
\text{CE} = -\sum p_i \log q_i
$$

> **重点**：交叉熵是 LLM 训练的标配损失函数，用于预测 token 的分类损失。

**KL 散度**：衡量两个概率分布的差异，是**蒸馏、对齐、RLHF** 的核心工具。

### 3.4 采样概率

**Softmax**（注意力权重、输出层 token 概率归一化）：

$$
\text{softmax}(z_i) = \frac{e^{z_i}}{\sum_j e^{z_j}}
$$

**温度系数（temperature）**：控制生成随机性，温度越高，输出越多样化。

## 4. Transformer 专属数学

### 4.1 缩放点积注意力

$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
$$

- $\sqrt{d_k}$ 缩放：防止高维点积值过大导致 softmax 饱和，梯度消失

### 4.2 位置编码（三角函数形式）

$$
\begin{align}
PE_{(pos, 2i)} &= \sin\left(\frac{pos}{10000^{2i/d_{model}}}\right) \\
PE_{(pos, 2i+1)} &= \cos\left(\frac{pos}{10000^{2i/d_{model}}}\right)
\end{align}
$$

作用：给模型注入序列顺序信息，使模型能感知 token 的位置关系。

### 4.3 多头注意力

将 Q/K/V 分割为多组，并行计算注意力，融合多维度语义特征，增强模型的表达能力。

## 5. RAG 数学核心（应用开发刚需）

| 概念 | 说明 |
|------|------|
| **向量检索** | 余弦相似度、欧氏距离、曼哈顿距离 |
| **向量归一化** | 统一 Embedding 空间分布，提升召回精度 |
| **向量量化** | 乘积量化、标量量化，是 Milvus / FAISS 底层压缩算法 |

## 6. 微调与高效计算数学

| 技术 | 数学原理 |
|------|---------|
| **低秩分解（LoRA）** | 大权重矩阵 $W$ 分解为两个低秩小矩阵 $A, B$，仅训练小矩阵，大幅降低显存开销 |
| **量化** | 32/16 位浮点 → 8/4 位整型映射，vLLM / QLoRA 推理加速核心 |
| **混合精度计算** | FP16/FP8 降低显存占用，加速训练和推理 |

## 7. 高频公式速记

| 公式 | 说明 |
|------|------|
| $\text{Softmax}\left(\dfrac{QK^\top}{\sqrt{d}}\right)V$ | 缩放点积注意力 |
| $\dfrac{\boldsymbol{a} \cdot \boldsymbol{b}}{\|\boldsymbol{a}\|\|\boldsymbol{b}\|}$ | 余弦相似度 |
| $-\sum p \log q$ | 交叉熵损失 |
| $\theta \leftarrow \theta - \eta \nabla L$ | 梯度下降更新 |

## 8. 学习优先级

| 优先级 | 内容 |
|--------|------|
| **第一优先级（立刻学）** | 向量内积、余弦相似度、Softmax、交叉熵、缩放注意力 |
| **第二优先级（进阶必备）** | 梯度下降、信息熵、KL 散度、位置编码 |
| **第三优先级（高阶优化）** | 低秩分解、量化数学、特征分解、凸优化 |

## 核心要点回顾

- 线性代数是 LLM 的根基：向量点积是注意力机制和 RAG 召回的核心运算
- 微积分支撑训练：链式法则（反向传播）、梯度下降（参数更新）
- 信息论定义目标：交叉熵（损失函数）、KL 散度（分布差异度量）
- Transformer 专属数学：缩放点积注意力、三角函数位置编码
- 高效微调依赖低秩分解（LoRA）和量化技术
