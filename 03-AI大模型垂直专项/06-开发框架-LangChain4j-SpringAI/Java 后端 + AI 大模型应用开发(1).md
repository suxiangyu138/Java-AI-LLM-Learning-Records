 Java 后端 + AI 大模型应用开发
一、必须会的「基础辅助技能」（简历必写）
1. Linux 熟练使用
    - 常用命令、文件操作、权限、进程、日志查看
    - 简单服务器部署、环境搭建
    → 后端和 AI 模型部署都离不开
2. Git + 协作开发
    - 提交、分支、合并、解决冲突
    - GitHub/Gitee 放项目
    → 大厂标配，不会基本面试直接减分
3. SQL 精通
    - MySQL 索引、事务、联表、子查询、执行计划
    - 后期做 RAG、数据清洗、埋点统计都要用
    → 比很多框架还重要
4. Python 基础 + 常用库
    - 爬虫、数据处理、脚本工具
    - 对接大模型 API、写数据 pipeline
    → 不学 Python，AI 大模型很难玩起来
    二、AI 大模型方向必备辅助技能（核心加分）
    1. 向量数据库
    - Milvus / Chroma / FAISS 至少会一个
    → 做 RAG 知识库必备，不会等于不会大模型应用
2. RAG 全流程
    - 文档加载 → 分块 → 向量化 → 检索 → 生成回答
    → 企业 90% 的大模型落地都是 RAG
3. Prompt 工程 + 函数调用（Function Call）
    - 让大模型输出 JSON、执行工具、调用接口
    → 做 AI 助手、智能体必备
4. 简单模型部署能力
    - 用 Ollama / FastAPI 跑开源大模型
    - 了解量化、本地部署
    → 面试非常加分
    三、Java 后端工程化辅助技能（进大厂必需）
    1. Redis
    - 缓存、分布式锁、限流
    → 后端标配，AI 接口也需要限流缓存
2. Docker
    - 打包项目、跑环境、部署模型服务
    → 现在开发不离 Docker
3. 常见中间件
    - RabbitMQ / RocketMQ 消息队列
    - Elasticsearch（检索、RAG 也能用）
    → 大厂后端标准技术栈
4. 接口文档 & 测试
    - Swagger/Postman
    → 写项目、面试演示必备
    四、能显著拉开差距的高阶辅助技能（ optional，但强推）
    1. 简单爬虫 + 数据清洗
    - 爬公开文章、构建知识库
    → 做 AI 项目直接有数据源
2. 极简前端（Vue/React 任选一个）
    - 能写简单页面展示 AI 对话界面
    → 一个人就能做完整 AI 项目，简历直接亮眼
3. API 开发规范 & 设计模式
    - 后端代码优雅、可维护
    → 面试评价会很高
4. AI Agent 基础
    - 让 AI 调用工具、查数据库、联网搜索
    → 未来 3 年主流方向
    五、哪些不用学（避免浪费时间）
    - 深度学习底层原理、PyTorch 炼丹、训大模型
    - 复杂前端、小程序、游戏开发
    - 机器学习算法竞赛（除非你想转算法）
    - 网络安全、渗透、逆向（和你方向无关）
    六、给你一句最现实的总结
    你走 Java 后端 + AI 大模型应用
    只要把下面这套辅助技能配齐：
    Linux + Git + MySQL + Redis + Docker + Python + 爬虫/数据清洗 + RAG + 向量库 + Prompt
    你就是校招里非常能打的选手，合肥本地优质企业、中大厂都能冲。
