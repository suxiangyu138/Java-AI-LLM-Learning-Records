## 1. Java 后端基本功

| 层级 | 技术栈 |
|------|--------|
| **基础** | 集合、多线程、JVM、异常、IO、反射、注解、泛型 |
| **框架** | Spring Boot / Spring MVC / Spring Cloud |
| **ORM** | MyBatis / MyBatis-Plus |
| **数据库** | MySQL（索引、事务、锁、执行计划、SQL 优化、分库分表） |
| **中间件** | Redis（缓存、分布式锁）、MQ（RabbitMQ/RocketMQ）、Elasticsearch |

**展示方式**：一个完整后端项目（管理系统/商城/博客），突出：

| 能力点 | 实现 |
|--------|------|
| RESTful 接口 | Controller 层规范 |
| 全局异常处理 | `@RestControllerAdvice` |
| JWT 登录 | Spring Security 集成 |
| AOP | 日志/权限切面 |
| 线程池 | 异步任务 |
| Redis 缓存 | 热点数据缓存 |
