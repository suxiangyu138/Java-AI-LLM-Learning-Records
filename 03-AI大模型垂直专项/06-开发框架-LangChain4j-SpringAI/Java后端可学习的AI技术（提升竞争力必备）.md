## 1. 基础必备：AI 接入与工程化

### 1.1 大模型 API 调用与封装

| 能力 | 工具 | 落地场景 |
|------|------|----------|
| 调用大模型 API（OpenAI/通义千问/文心一言） | OkHttp、RestTemplate、**Spring AI** | 接口参数校验、文案生成、日志异常分析 |
| Prompt 工程基础（角色设定/CoT/格式约束） | — | 提升模型响应精度 |
| 封装可复用微服务组件 | Spring Boot | 快速集成到现有系统 |

### 1.2 向量数据库应用

| 能力 | 工具 | 落地场景 |
|------|------|----------|
| 向量嵌入、存储与检索 | Milvus / Pinecone / Chroma Java SDK | 企业文档检索、商品语义推荐 |
| 结合 Embedding 实现 RAG | Spring AI + 向量数据库 | 金融合同匹配、知识库问答 |

### 1.3 AI 模型 Java 端推理

| 工具 | 特点 |
|------|------|
| **DJL**（Deep Java Library） | 加载 PyTorch/TensorFlow 预训练模型，推理延迟比 Python 低 30% |
| **ONNX Runtime** | 跨框架模型部署，统一推理接口 |

## 2. 进阶提升：企业级 AI 系统集成

### 2.1 RAG 技术栈

| 环节 | 工具 | 说明 |
|------|------|------|
| RAG 框架 | **LangChain4j**（Java 生态首选） | 文档解析→向量嵌入→检索匹配→LLM 生成 |
| 系统集成 | Spring Boot 微服务 | 封装 RAG 为标准化服务，对接 ERP/CRM |

### 2.2 Function Calling

> 让 AI 调用 Java 后端服务：查询订单、修改用户、生成报表。

```text
AI 模型 → 识别意图 → 调用 Java 接口（Function Calling）→ 返回结果 → AI 整合回答
```

### 2.3 AI 模型部署与监控

| 能力 | 工具 |
|------|------|
| 容器化部署 | Docker + K8s |
| 监控告警 | Prometheus + Grafana |
| 性能优化 | JDK Vector API（SIMD 加速）、模型量化 |

## 4. 学习路线与避坑

### 学习路线

| 阶段 | 时间 | 内容 |
|:----:|:----:|------|
| **第一阶段** | 1-1.5 月 | 大模型 API 调用 + Spring AI + 向量数据库基础 → 完成第一个 AI 小需求 |
| **第二阶段** | 1.5-3 月 | RAG（LangChain4j）+ 私有知识库 + Function Calling |
| **第三阶段** | 3-6 月 | AI 模型部署监控 + 分布式 AI + AI Agent（按需深入） |

### 避坑指南

| ❌ 误区 | ✅ 正确 |
|--------|--------|
| 深入学 Python 算法训练 | Java 核心价值是 **AI 工程化落地**，非模型研发 |
| 学所有 AI 技术 | 聚焦与自身行业（金融/电商/制造）相关的落地技术 |
| 只看不练 | 每学一个技术，落地一个小项目 |
