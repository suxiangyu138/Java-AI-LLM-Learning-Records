## 1. 动手任务一：跨平台改造

### 改造目标

把阶段 3 的技能改成跨平台（一份 SKILL.md 多处可跑）。

### 改造清单（05 篇四规则）

| 检查 | 你的技能 | 状态 |
|---|---|---|
| 只用核心 frontmatter | name/description（专属字段去掉或标注） | ☐ |
| 不写 agent 专属工具名 | 写"结果"（运行 pnpm test 而非 Bash 工具） | ☐ |
| 项目根相对路径 | 无绝对路径 | ☐ |
| 正文 ≤8KB | Codex 上限内 | ☐ |

### 改造步骤

```
① 检查 frontmatter（专属字段处理）
② 检查正文（工具名/路径/大小）
③ 放到 .agents/skills/（通用总线）
④ 备份原平台目录（Symlink 或删除）
```

## 3. 动手任务三：分发准备

### 分发决策

```

   安全优先 → Skills.sh（Snyk）或 ClawHub（审查）
   数量曝光 → SkillsMP
② 是否发布：技能达到发布标准？（评分 ≥75）
③ 版本：SemVer + changelog
```

### 发布前检查（06 篇清单）

- [ ] 规范评分 ≥75（skill-test-skill）
- [ ] 跨平台至少两平台测试通过

- [ ] description 触发词有效
- [ ] 版本号 + changelog

### 参考答案（简版）

1. Claude/Codex GA（.claude/.codex）、Copilot/Gemini 预览（.github/.gemini）、Cursor Nightly（.cursor）、OpenCode 原生（.opencode）
2. Claude Code
3. $ 符号调用；8KB 硬上限
4. @ 附加；每日 1,000 次免费
5. 开启 chat.useAgentSkills 设置
6. Claude Code 80.9% / Codex 77.3% / Cursor 73%
7. 一格式多目录（重复维护）
8. 所有 agent 读取（备援路径）——放一份全平台可用
9. 核心 frontmatter/通用写法/相对路径/双平台测
10. 静默不生效（安全与行为风险）
11. 通用总线/Symlink/分发工具
12. 主平台 + 第二验证 + 降级清单
13. 8KB（Codex 上限）
14. 发布/安装/版本/依赖对齐 npm
15. SkillsMP 数量无扫描/Skills.sh 83K 带 Snyk/ClawHub 3.2K 强制审查
16. 完成→测试→版本→市场→维护
17. 写明工具名/用途/输出（不实现工具）
18. 技能白名单/MCP 最小权限/流程审批
19. 功能 Claude/终端 Codex/VS Code Copilot/免费 Gemini/开源 OpenCode
