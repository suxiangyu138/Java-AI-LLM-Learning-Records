## 1. 本阶段定位

五阶段路径的"生态落地"一站——理解六大平台的支持现状与差异，学会写"一份 SKILL.md 到处跑"的跨平台技能：

```
阶段1 概念 → 阶段2 第一个 Skill → 阶段3 进阶开发 → 阶段4 框架实践（本阶段）→ 阶段5 工程
```

| 对比项 | 阶段 3 | 阶段 4 |
|---|---|---|
| 焦点 | 技能本身（结构/质量） | 技能生态（平台/分发） |
| 视角 | 作者 | 使用与发布者 |
| 关键 | 可靠性 | **可移植性** |
| 新概念 | 脚本/评估 | 平台差异/通用总线/Marketplace |

### 阶段 4 的核心问题

```
技能写好了，但：
在哪些工具能用？（平台支持矩阵）
怎么写才能跨工具？（跨平台设计）
怎么让别人用？（分发与市场）
——从"我的技能"到"生态的技能"
```

## 3. 与阶段 3 的衔接

| 阶段 3 产物 | 阶段 4 的用法 |
|---|---|
| 多文件技能 | 跨平台测试（至少两个 agent） |
| allowed-tools 配置 | 注意：仅部分平台支持（降级） |
| 评估数据 | 跨平台对比（每个平台跑一遍） |
| 版本管理 | 发布到 Marketplace（版本化） |

> 关键提醒：阶段 3 的 allowed-tools 等进阶字段**跨平台会静默降级**——阶段 4 的 05 篇专门处理。

## 4. 平台支持总览

| 工具 | 状态 | 技能目录 | 特点 |
|---|---|---|---|
| Claude Code | GA | .claude/skills/ | 功能最全（标准原创者） |
| Codex CLI | GA | .codex/skills/ | 简单易用、8KB 正文上限 |
| GitHub Copilot | 预览 | .github/skills/ | VS Code 零配置 |
| Gemini CLI | 预览 | .gemini/skills/ | 免费档、@ 附加 |
| Cursor | Nightly | .cursor/skills/ | 尚不稳定 |
| OpenCode | 原生 | .opencode/skills/ | 开源 |

### 通用总线（关键）

```
每个 agent 都读取 .agents/skills/ 作为备援路径
→ 跨 agent 写技能放那里（05 篇详述）
```

## 5. 学习计划与目标

### 三天计划

| 天 | 内容 | 目标 |
|---|---|---|
| Day 1 | 01-04 平台支持 | 能说出六平台差异 |
| Day 2 | 05 跨平台 + 06 分发 | 会写跨平台技能、知道分发路径 |
| Day 3 | 07 组合 + 08 实战自测 | 跨平台技能落地 + 毕业 |

### 动手任务（贯穿三天）

```
① 把阶段 3 技能改成跨平台（核心 frontmatter + 通用写法）
② 放到 .agents/skills/（通用总线）
③ 在两个 agent 上测试
④ 选择一个 Marketplace 了解发布流程
```

## 6. 毕业标准

- [ ] 能画出六平台支持矩阵（状态/目录/特点）

## 7. 常见疑问快答与关键数据

### 常见疑问

| 疑问 | 回答 |
|---|---|
| 阶段 4 与 3 的核心区别？ | 阶段 3 技能本身，阶段 4 技能生态 |
| 跨平台技能必须吗？ | 要分发/换工具就需要（四规则） |

| 分发难吗？ | 选市场 + 发布流程（像 npm 发布） |
