## 1. 本阶段定位

Agent Skill 五阶段路径的第一站——建立完整、正确的概念地基：

| 阶段 | 名称 | 核心任务 | 产出 |
|---|---|---|---|
| 1 | 基础理解（本阶段） | 概念、规范、生态、安全 | 能讲清 Skill 是什么 |
| 2 | 动手写第一个 Skill | SKILL.md + 简单技能 | 跑通一个技能 |
| 3 | 进阶 Skill 开发 | 多文件/工具/质量 | 生产级技能 |
| 4 | 框架实践 | 各平台/框架落地 | 多平台技能 |
| 5 | 工程落地 | 团队/仓库/CI | 技能体系治理 |

> 本阶段零代码，但概念必须深——SKILL.md 规范、渐进式披露、与 MCP 的边界，这些理解不到位，后面动手全是返工。

## 4. 与 MCP 学习体系的分工

同级 `MCP学习/` 已有完整阶段体系（基础认知→动手入门→进阶实战→项目实战），本体系与其**互补不重复**：

| 内容 | 归属 |
|---|---|
| MCP 协议、服务器/客户端开发 | MCP学习体系 |
| Agent Skills 规范、技能开发 | 本体系 |
| **两者关系** | 05 篇专章（工具 vs 知识） |

> 学习建议：可以先学 MCP 再学 Skill（工具先于知识），也可以并行——两套体系在 05 篇交叉。

## 6. 核心概念速查

| 概念 | 一句话速记 |
|---|---|
| Agent Skills | 把任务知识打包为可移植 SKILL.md 文件夹的开放标准 |
| SKILL.md | 技能的核心文件（frontmatter 元数据 + 使用说明正文） |
| 发起方 | Anthropic（2025-10 发布，2025-12 开放标准） |
| 采用 | OpenAI/Google/Copilot/Cursor 等约 40 平台 |
| 渐进式披露 | 三级加载：元数据→正文→配套文件（按需） |
| L1 元数据 | 启动只加载 name+description（发现与匹配） |
| L2 正文 | 任务触发才加载 SKILL.md 全文 |
| L3 配套 | 执行中按需读 scripts/references/assets |
| 发现路径 | 项目级 → 用户级 → 插件级 |
| allowed-tools | 限定技能可调用的工具范围 |
| 与 MCP 关系 | MCP=可调用工具（functions），Skills=使用知识（know-how） |
| ToxicSkills | 2026 安全审计：36% 技能有缺陷 |
| 隐藏指令劫持 | 通过 SKILL.md 藏指令攻击 Agent 的攻击面 |

## 7. 常见疑问快答

| 疑问 | 回答 |
|---|---|
| 与 MCP 学哪个先？ | 都行——本体系与 MCP 体系互补（05 篇交叉） |
| 需要会写代码吗？ | 阶段 1 不需要；阶段 2 起需要基础 Python/Markdown |
| Skill 只能 Claude 用吗？ | 不是——40+ 平台支持（Codex/Gemini CLI/Copilot） |
| 技能与脚本什么区别？ | 脚本是零件，技能是"脚本+使用说明"的打包 |
| 技能会过时吗？ | 会——平台实现差异/规范演进（锁版本） |
| 从哪找现成技能？ | anthropics/skills 官方库 + 社区（注意安全审查） |
