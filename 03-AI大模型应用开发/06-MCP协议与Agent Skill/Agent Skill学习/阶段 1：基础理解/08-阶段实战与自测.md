## 1. 概念串讲演练

### 三分钟讲稿模板

```
第 1 句（定义）：Agent Skills 是把任务知识打包成 SKILL.md 文件夹的开放标准
——Anthropic 发起，40+ 平台采用。

第 2 句（为什么）：模型天生会推理但不会你的业务；
技能给 Agent"上岗手册"：何时用、怎么用、按什么顺序。

第 3 句（结构）：一个文件夹 = SKILL.md（frontmatter 元数据 + 正文）
+ scripts/references/assets 可选配套。

第 4 句（机制）：渐进式披露三级加载——
启动只读元数据（发现），触发才读正文（执行），按需取配套（细节）。

第 5 句（关系）：与 MCP 互补——MCP 是工具（能做什么），
Skill 是知识（怎么做）；工具是零件，技能是装配图。

第 6 句（安全）：技能是供应链——ToxicSkills 审计 36% 有缺陷，
安装要像审查软件依赖一样严格，allowed-tools 最小权限。
```

### 演练评分

| 维度 | 满分表现 |
|---|---|
| 完整度 | 六句框架齐全 |
| 流畅度 | 无卡壳 |
| 深度 | 能接追问（如"与 MCP 什么区别"） |
| 时长 | 2-3 分钟 |

## 3. 20 道自测题

### 概念与起源（1-6）

1. Agent Skills 是什么？谁发起？
2. 开放标准化的时间线？（2025-10 发布 / 2025-12 开放）
3. 解决什么痛点？
4. 与 Prompt 的区别？
5. 心智模型是什么？（上岗手册：简历/手册/工具手册）
6. 为什么开放成标准？

### 规范与机制（7-13）

7. Skill 目录结构？哪些必需？
8. frontmatter 两个必填字段及规则？
9. description 为什么重要？
10. 正文行数限制？细节放哪？
11. allowed-tools 作用？
12. 发现路径三级？
13. 渐进式披露三级各自加载什么？

### 生态与关系（14-17）

14. 多少平台支持？举 4 个。
15. 跨工具可移植性要注意什么？（确认实现文档）
16. 与 MCP 的核心区别？
17. 三层架构？（Skills/Agent/Commands）

### 安全与边界（18-20）

18. ToxicSkills 审计数据？
19. 隐藏指令劫持原理？
20. 适合做 Skill 的三个特征？

### 参考答案（简版）

1. 任务知识打包为 SKILL.md 的开放标准；Anthropic
2. 2025-10-16 发布 → 2025-12-18 开放 → 2026-05 established
3. 模型不懂业务知识——可复用可移植的技能包
4. Prompt 是"怎么说"，Skill 是"怎么做"
5. description（简历）/正文（手册）/配套（工具手册）
6. 生态共赢（40+ 平台采用）
7. SKILL.md 必需 + scripts/references/assets 可选
8. name（≤64 小写连字符，与目录一致）+ description（≤1024）
9. 任务匹配的唯一依据（写触发场景和关键词）
10. ≤500 行（约 5000 tokens）；references/assets
11. 限定工具范围（最小权限安全）
12. 项目级 → 用户级 → 插件级
13. L1 元数据（启动）/L2 正文（触发）/L3 配套（按需）
14. 约 40 个：Claude Code/Codex/Gemini CLI/Copilot
15. 仅对已发布实现文档的工具确认
16. MCP=可调用工具（functions），Skill=使用知识（know-how）
17. Skills 知识/Agent 身份/Commands 编排
18. 3984 个技能 36% 有缺陷（2026-02）
19. description 伪装 + 正文藏恶意指令诱导 Agent
20. 可复用 × 有流程 × Agent 该会
