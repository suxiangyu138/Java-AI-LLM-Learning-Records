## 1. 综合实战：天气查询 Server

**任务**：实现一个"城市天气查询" MCP Server——两个工具（按城市查天气、按温度建议穿衣），跑通 stdio + Streamable HTTP 双传输，接入 Claude Code。

### 1.1 Server 代码（weather_server.py）

```python
from fastmcp import FastMCP

mcp = FastMCP("weather-server")

# 模拟数据源（真实项目换成 API 调用，见阶段 3）
WEATHER = {
    "beijing":   {"temp": 32, "condition": "晴"},
    "shanghai":  {"temp": 35, "condition": "多云"},
    "guangzhou": {"temp": 29, "condition": "小雨"},
}

@mcp.tool
def get_weather(city: str) -> str:
    """查询指定城市的天气（city 支持拼音，如 beijing/shanghai/guangzhou）。"""
    data = WEATHER.get(city.lower())
    if not data:
        return f"错误：未收录城市 {city}，可选：{', '.join(WEATHER.keys())}"
    return f"{city}：{data['temp']}°C，{data['condition']}"

@mcp.tool
def dress_advice(temp: int) -> str:
    """根据气温给出穿衣建议（temp 为摄氏度整数）。"""
    if temp >= 33:  return "高温预警：短袖短裤，注意防晒补水"
    if temp >= 26:  return "短袖短裤即可，体感舒适"
    if temp >= 18:  return "建议长袖或薄外套"
    return "建议厚外套或羽绒服，注意保暖"

if __name__ == "__main__":
    mcp.run()   # stdio 模式（HTTP 模式改为 transport="http", port=8080）
```

### 1.2 客户端验证（client.py）

```python
import asyncio
from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client

async def main():
    params = StdioServerParameters(command="uv", args=["run", "python", "weather_server.py"])
    async with stdio_client(params) as (read, write):
        async with ClientSession(read, write) as session:
            await session.initialize()
            tools = await session.list_tools()
            print("工具:", [t.name for t in tools.tools])          # get_weather, dress_advice

            r1 = await session.call_tool("get_weather", {"city": "beijing"})
            print("北京天气:", r1.content[0].text)

            r2 = await session.call_tool("dress_advice", {"temp": 35})
            print("穿衣建议:", r2.content[0].text)

if __name__ == "__main__":
    asyncio.run(main())
```

### 1.3 接入 Claude Code

```bash
claude mcp add weather-server -- uv run python weather_server.py
claude mcp get weather-server   # 期望 Connected
```

### 答案速查

| 题 | 答案 |
|---|---|
| 1 | fastmcp 3.x；它基于官方 mcp SDK 的高层封装 |
| 2 | 参数名+类型注解→properties；默认值→default；docstring→description |
| 3 | TS 拆分为 server/client 两个包；Python FastMCP 改名为 MCPServer |
| 4 | stderr；stdout 是协议流，print 会污染 JSON-RPC 通信 |
| 5 | 无会话头、无握手；每请求独立处理、请求级版本协商 |
| 6 | 状态作为工具参数显式传递（Server 签发句柄，SEP-2567） |
| 7 | stdio；`mcp.run(transport="http", host=..., port=...)` |
| 8 | command、args、env（StdioServerParameters） |
| 9 | name（工具名）与 arguments（参数对象） |
| 10 | UI 6274；代理 6277 |
| 11 | 真实客户端（如 Claude Code）对 Server 的调用流量 |
| 12 | 项目级（.mcp.json）；加 --scope user 才是全局 |
| 13 | `~` 不展开，导致找不到命令 |
| 14 | Content-Type: application/json 与 Accept: application/json, text/event-stream |
| 15 | 检查 Server 启动日志：注册代码是否执行、入口是否跑对 |
| 16 | 客户端与服务端协议版本不匹配（检查 SDK 代际） |
| 17 | curl 先手测（隔离 Client 与 Server 问题） |
| 18 | 返回了非文本对象（dict/对象），需转字符串或按 content 结构解析 |
| 19 | Inspector v0.21+ Windows 已知问题：换 HTTP/SSE 传输或升级 Node |
| 20 | 配置差异：路径/参数/环境变量——用 Inspector 导出配置替换手写配置 |
