## 1. 本阶段定位

MCP 四阶段路径的第二站——从"概念会说"到"代码能跑"：

| 阶段 | 名称 | 核心任务 | 产出 |
|---|---|---|---|
| 1 | 基础认知 | 概念、架构、原语、安全 | 能讲清 MCP 是什么 |
| 2 | 动手入门（本阶段） | 跑通最小 Server/Client | 本地 MCP 对话 |
| 3 | 进阶实战 | 生产级 Server/认证/传输 | 可部署的 MCP |
| 4 | 项目实战 | 完整项目集成 | 项目级 MCP 应用 |

> 本阶段的目标不是写生产级代码，而是**亲手走通完整链路**：写 Server → 客户端连接 → 调试 → 接入 Claude Code。链路走过一遍，后面阶段所有概念才有落点。

## 5. 学习计划与目标

### 三天计划

| 天 | 内容 | 目标 |
|---|---|---|
| Day 1 | 01 + 02 | 本地跑起第一个 Server（stdio） |
| Day 2 | 03 + 04 | Client 能调 Server；HTTP 远程跑通 |

### 毕业标准（阶段 2 检查单）

- [ ] 从零搭好环境，知道各 SDK 的版本与选型（fastmcp vs 官方 mcp）
- [ ] 独立写出最小 Server（stdio）并验证工具可被调用
- [ ] 独立写出最小 Client，完成一次"客户端 → 工具"调用
- [ ] 能部署 Streamable HTTP 模式并用 curl 手测
- [ ] 会用 Inspector 调试（tools/list → tools/call → 错参验证）
- [ ] 能在 Claude Code 中配置并调用自己写的 Server
- [ ] 能独立排查 5 类以上常见报错
- [ ] 20 道自测题正确率 ≥ 80%

## 6. 核心概念速查

| 概念 | 一句话速记 |
|---|---|
| fastmcp | Python 高层框架（3.x，2026-02），一行装饰器注册工具 |
| mcp（官方 SDK） | Python 官方 SDK（1.26），底层 Server/Client 类 |
| @modelcontextprotocol/sdk | TS 官方 SDK（1.27.1），McpServer + Zod |
| stdio | 本地传输：子进程 stdin/stdout 走 JSON-RPC |
| Streamable HTTP | 远程传输：POST /mcp 端点，无状态（2026-07-28 规范） |
| MCP Inspector | 官方调试工具：`npx @modelcontextprotocol/inspector`，UI 6274/代理 6277 |
| claude mcp add | Claude Code 添加 MCP Server 的命令 |
| mcp.json | MCP 配置文件（全局 `~/.config/claude/mcp.json`） |
| 工具 Schema | 由函数签名+docstring 自动生成的 JSON Schema |
| 版本协商 | 每请求 `_meta` 携带协议版本，不匹配报 UnsupportedProtocolVersionError |
| v2 迁移 | 2026-07-28 规范配套：TS 拆包 server/client；Python FastMCP→MCPServer |
