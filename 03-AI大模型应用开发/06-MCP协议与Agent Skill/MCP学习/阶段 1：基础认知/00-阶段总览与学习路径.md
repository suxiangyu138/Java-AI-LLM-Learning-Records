## 6. 核心概念速查

| 概念 | 一句话速记 |
|---|---|
| MCP | Model Context Protocol：模型与外部工具/数据/提示的开放协议 |
| 发起 | Anthropic（2024-11 开源），开放治理 |
| Host | 宿主应用（Claude Code/IDE 等），用户交互入口 |
| Client | 连接服务器、处理请求（Host 内嵌） |
| Server | 提供工具/资源/提示的进程（本地或远程） |
| Tools | 可执行函数（模型调用） |
| Resources | 可读数据（上下文注入） |
| Prompts | 可复用提示模板（用户选择） |
| stdio | 本地传输（标准输入输出） |
| Streamable HTTP | 远程传输（推荐，无状态） |
| 无状态 | 2026-07-28 规范核心：移除会话与握手 |
| server/discover | 新规范的显式发现机制 |
| 分代 | modern（2026-07+）/legacy（2025-11-）/dual-era |
| 与 Agent Skill | MCP=工具（functions），Skill=知识（know-how） |

## 7. 常见疑问快答与关键数据

### 常见疑问

| 疑问 | 回答 |
|---|---|
| 与 Agent Skill 学哪个先？ | 并行——两体系互补（05 篇交叉） |
| MCP 与 API 冲突吗？ | 不冲突——服务对象不同（模型 vs 程序） |
| 必须会用吗？ | AI 应用开发必修（工具标准） |
| 2026 规范要记住什么？ | 无状态革命（移除会话握手） |
| 安全重要吗？ | 工具越强大风险越大（防护必学） |

### 关键数据速记

| 数据 | 数值 |
|---|---|
| 发起 | 2024-11（Anthropic） |
| 最新规范 | 2026-07-28 |
| 三原语 | Tools/Resources/Prompts |
| 传输 | stdio/Streamable HTTP/HTTP+SSE 废弃 |
| 会话 | 2026-07 起移除（无状态） |
| 分代 | modern/legacy/dual-era |
| 采用 | 行业广泛（大厂跟进） |
| 双标准 | MCP 工具 + Skill 知识 |
