## 4. 双标准：MCP 与 Agent Skills

### 双标准互补

```
MCP：工具标准（functions——能做什么）
Agent Skills：知识标准（know-how——怎么做）
两者同源（Anthropic 发起）+ 互补
```

| 维度 | MCP | Agent Skills |
|---|---|---|
| 定位 | 工具协议 | 知识格式 |
| 回答 | 有什么能力 | 怎么用能力 |
| 类比 | 工具箱 | 使用手册 |
| 采用 | 行业广泛 | 约 40 平台 |
| 学习位置 | 本体系 | Agent Skill 学习体系 |

### 组合是标配

```
Agent 完整能力 = 工具（MCP）+ 知识（Skills）：
技能指导调用哪些 MCP 工具、按什么顺序
工具提供实际执行能力
——2026 年 Agent 能力扩展的标配组合
```

### 学习建议

```
两套体系并行：
MCP 学习（工具怎么开发）——本路径
Agent Skill 学习（知识怎么打包）——同级体系
——双标准齐备 = Agent 能力扩展全图景
```

## 5. 生态演进趋势

### 常见误区

| 误区 | 真相 |
|---|---|
| "MCP 会取代 Agent Skills" | 互补（工具 vs 知识） |
| "生态已饱和" | 四层生态持续生长 |
| "只有 Python 生态" | 主流语言都有 SDK |
| "规范定了就稳定" | 持续演进（版本日期标识） |
| "学了 MCP 够了" | 双标准齐备才是全图景 |

### 趋势一：无状态化

```
2026-07 规范：REST 风格（水平扩展/serverless）
——企业部署友好（运维门槛降低）
```

### 趋势二：标准融合

```
MCP（工具）+ Agent Skills（知识）+ A2A（Agent 间）：
三个标准各管一段（能力/知识/协作）
——标准生态成形
```

### 趋势三：企业化

```
企业就绪指南（Stacklok）/ 官方 SDK v2：
从实验到生产（认证/治理/可观测）
——MCP 进入企业主流
```
