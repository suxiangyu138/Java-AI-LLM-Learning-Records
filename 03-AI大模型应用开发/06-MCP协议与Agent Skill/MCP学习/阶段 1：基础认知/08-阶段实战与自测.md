## 1. 概念串讲演练

### 三分钟讲稿模板

```
第 1 句（定义）：MCP 是模型与外部能力的开放协议
——AI 应用的 USB-C（统一连接标准）。

第 2 句（为什么）：没有它之前每个应用×每个工具单独集成（N×M）；
有了它工具实现一次任何应用都能用（N+M）。

第 3 句（架构）：三要素——Host（应用交互）、
Client（协议连接）、Server（能力提供）。

第 4 句（原语）：三种能力——Tools（模型调用的函数）、
Resources（注入上下文的数据）、Prompts（用户选择的模板）。

第 5 句（传输）：本地 stdio、远程 Streamable HTTP（推荐）；
2026-07-28 规范移除会话与握手（无状态革命），HTTP+SSE 废弃。

第 6 句（生态）：Anthropic 发起、OpenAI/Google/微软跟进；
与 Agent Skills 构成双标准（工具 vs 知识）。
```

### 演练评分

| 维度 | 满分表现 |
|---|---|
| 完整度 | 六句框架齐全 |
| 流畅度 | 无卡壳 |
| 深度 | 能接追问（如"无状态革命是什么"） |
| 时长 | 2-3 分钟 |

### 参考答案（简版）

1. 模型与外部能力的开放协议；AI 的 USB-C
2. 集成碎片化（N×M → N+M）
3. Anthropic（2024-11）
4. Host 交互/Client 连接/Server 能力
5. JSON-RPC 2.0
6. Client 内嵌于 Host（协议内核）
7. Tools 模型/Resources 模型用户/Prompts 用户
8. MCP Tools 是开放协议版
9. 只读数据、上下文注入、URI 寻址
10. 用户选择、模板化
11. stdio 本地/Streamable HTTP 远程推荐/HTTP+SSE 废弃
12. 移除会话与握手（无状态）
13. _meta 协议版本 + 客户端能力
14. modern/legacy/dual-era（自动回退）
15. Anthropic 发起、大厂跟进、行业广泛
16. MCP 工具 vs Skill 知识（互补）
17. 注入/恶意工具/滥用/泄露/供应链
18. 授权/隔离/最小权限
19. 模型要用/多处复用/标准价值
20. API 给程序（写死）vs MCP 给模型（自主）
