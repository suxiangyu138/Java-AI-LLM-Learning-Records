## 6. 核心概念速查

| 概念 | 一句话速记 |
|---|---|
| lifespan | FastMCP 生命周期钩子：启动初始化/关闭清理，替代模块级全局变量 |
| Depends | 依赖注入：工具参数从生命周期上下文取值（如数据库连接） |
| 中间件 | 请求管道拦截：认证/限流/日志/改造，FastMCP 3.x 内建 |
| 组合/代理 | 多 Server 合并为一个面；代理包装已有 Server 加能力 |
| ToolResult(is_error) | 工具返回结构化错误而非抛异常（可带 structured_content） |
| OAuth 2.1 | 2026 认证主线：MCP Server=资源服务器（RFC 9728），独立授权服务器发令牌 |
| 六 SEP | 2468(iss)/2352(凭证绑定)/837(application_type)/2207(刷新)/2350(增量 scope)/2351(well-known) |
| CIMD | OAuth Client ID Metadata Documents：HTTPS URL 即客户端 ID，取代 DCR（12 个月弃用窗） |
| 无状态 | 2026-07-28 规范核心：移除 initialize/initialized 与 Mcp-Session-Id |
| server/discover | 新规范的显式发现 RPC：协议版本/能力/身份 |
| MRTR | 多轮往返请求（SEP-2322）：服务器要输入时返回 input_required，客户端再带 inputResponses 重发 |
| resultType | 每个结果必带（complete / input_required） |
| Mcp-Method/Mcp-Name | 强制 HTTP 头（SEP-2243）：LB 不用看 body 即可路由 |
| 双代兼容 | modern(2026-07+) / legacy(≤2025-11) / dual-era 并存，SDK 显式请求无状态 |
| tasks 扩展 | 长任务离开核心，成为 io.modelcontextprotocol/tasks 扩展（SEP-2133） |
| code mode | FastMCP 3.1：沙箱 Python 执行代替逐个工具调用，工具列表 token 降 99.9% |
| mcp-publisher | 官方发布 CLI：登录→发布→版本化（不可变） |
| server.json | 官方注册表清单文件：名称/描述/包或远端端点/版本 |
| 命名空间 | io.github.<org>/<server>（OIDC 验证）或 com.<domain>（DNS 验证） |
| 官方注册表 | registry.modelcontextprotocol.io：元数据注册表（不放代码），API freeze v0.1 |
| 提示注入 | 工具返回数据中夹带指令的威胁：所有外部输入不可信 |
| SSRF | 服务端请求伪造：URL 类工具的 36.7% 带此漏洞（2026-03 扫描） |
| 无状态红利 | 无会话 → 普通轮询负载均衡/Serverless 可用，无需粘性会话 |
