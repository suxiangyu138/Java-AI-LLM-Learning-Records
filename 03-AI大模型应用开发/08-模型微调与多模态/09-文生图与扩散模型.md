# 09 - 文生图与扩散模型

> 🎯 扩散模型 = 加噪→去噪 — Stable Diffusion 和 DALL-E 都是扩散模型。这是 2022 年以来生成模型的主流范式

## 扩散模型原理

```text
扩散模型 = 正向加噪 + 反向去噪

  正向过程（训练时）：逐步加噪
    x₀(清晰图) → x₁(加一点噪) → x₂(更多噪) → ... → x_T(纯噪声)
    
  反向过程（推理时）：逐步去噪
    x_T(纯噪声) → x_{T-1}(去一点) → ... → x₀(清晰图)
    
  训练目标：让模型学会"从嘈杂版本预测清晰版本"

  Text-to-Image：把文本 Prompt 作为条件注入去噪过程
    → "一只猫在太空" → 引导去噪方向 → 生成对应图片
```

## Stable Diffusion

### 本地部署

```python
from diffusers import StableDiffusionPipeline
import torch

pipe = StableDiffusionPipeline.from_pretrained(
    "runwayml/stable-diffusion-v1-5",
    torch_dtype=torch.float16
).to("cuda")

prompt = "A modern Java developer workspace, digital art style, 4k"
negative_prompt = "blurry, low quality, ugly, distorted"

image = pipe(
    prompt=prompt,
    negative_prompt=negative_prompt,
    num_inference_steps=25,   # 去噪步数（越多越精细）
    guidance_scale=7.5,       # Prompt 引导强度
    height=512, width=768
).images[0]
image.save("java_dev.png")
```

### 关键参数

| 参数 | 说明 | 推荐 |
|------|------|:---:|
| num_inference_steps | 去噪步数 | 20-50 |
| guidance_scale | 遵循 Prompt 的程度 | 7-9 |
| negative_prompt | 排除的元素 | 必设 |
| scheduler | 去噪调度器 | DPM++ 2M Karras |

## ControlNet — 精准控制

```python
# ControlNet = 用边缘/深度/姿态控制生成
from diffusers import StableDiffusionControlNetPipeline, ControlNetModel

controlnet = ControlNetModel.from_pretrained(
    "lllyasviel/sd-controlnet-canny"
)
pipe = StableDiffusionControlNetPipeline.from_pretrained(
    "runwayml/stable-diffusion-v1-5",
    controlnet=controlnet
).to("cuda")

# 提供 canny 边缘图 → 生成内容遵循边缘轮廓
image = pipe(prompt="a beautiful house", image=canny_edge).images[0]
```
