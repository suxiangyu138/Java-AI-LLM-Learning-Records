# 06 - 微调评估与迭代

> 🎯 微调不是训完就完了 — 评估、对比、迭代三次才能逼近最优。过拟合检测 + A-B测试 = 科学微调

## 评估维度

| 维度 | 指标 | 方法 |
|------|------|------|
| **准确率** | 任务完成度 | 自动评测(分类F1/生成BLEU) + 人工 |
| **通用能力** | 是否会做其他事 | MMLU/HumanEval 基准 |
| **安全性** | 有害输出比例 | 红队测试 |
| **一致性** | 相同输入输出稳定 | 多次采样对比 |
| **效率** | 推理延迟/Token消耗 | 基准对比 |

## 过拟合检测

```python
def detect_overfitting(train_losses, val_losses):
    """过拟合三信号"""
    signals = []
    
    # 信号1：Train Loss 降、Val Loss 升
    if val_losses[-1] > val_losses[0] * 1.05:
        signals.append("Val Loss 上升 > 5%")
    
    # 信号2：Train-Val Gap 持续扩大
    gap_start = train_losses[0] - val_losses[0]
    gap_end = train_losses[-1] - val_losses[-1]
    if gap_end > gap_start * 3:
        signals.append("Train-Val 差距扩大 > 3x")
    
    # 信号3：训练集准确率 100% → 背答案
    if train_losses[-1] < 0.01:
        signals.append("Train Loss 接近 0 → 可能背答案")
    
    return signals
```

## 评估集构建

```text
评估集应当：
  ① 从未在训练中出现过（严格隔离）
  ② 覆盖所有目标任务类型
  ③ 包含边界 Case（空输入/超长/多语言）
  ④ 包含"不应该回答"的 Case（测安全性）
  ⑤ 规模 50-200 条

GPT-4 辅助评测：
  → 用 GPT-4 对比微调前后输出
  → 打分维度：准确性/流畅度/完整性/安全性
```

## A-B 测试

```python
class ABTestRunner:
    def __init__(self, model_a, model_b, test_set):
        self.a = model_a
        self.b = model_b
        self.test = test_set
    
    def run(self):
        results = {"a_wins": 0, "b_wins": 0, "tie": 0}
        for case in self.test:
            resp_a = self.a.generate(case["input"])
            resp_b = self.b.generate(case["input"])
            winner = gpt4_judge(case, resp_a, resp_b)  # GPT-4 评判
            results[winner] += 1
        return results
```

## 迭代流程

```text
微调迭代 SOP：
  ① V1 基线：基座模型 + 初始数据 → LoRA 微调
  ② 评估：找最差的 20 个 Case → 分析根因
  ③ 数据增强：针对弱项补充数据 / 修正错误标注
  ④ V2 优化：新数据 + 调整超参 → 重新微调
  ⑤ A-B 测试：V2 vs V1 → 显著提升 → 上线
  ⑥ 持续：用户反馈 → 补充 Bad Case → V3...
```
