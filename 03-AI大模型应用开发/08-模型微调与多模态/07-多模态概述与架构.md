# 07 - 多模态概述与架构

> 🎯 多模态 = 在 LLM 上加"眼睛"和"耳朵" — ViT 看图片、Whisper 听声音、投影层对齐语义。一个架构看懂所有多模态模型

## 通用架构

```text
所有多模态 LLM 的通用架构：

  图片/音频/视频 → 编码器 → 投影层 → LLM → 文本输出
                    ↑        ↑        ↑
                  ViT      MLP/      LLaMA/
                 Whisper   Q-Former  Qwen

三步走：
  ① 专用编码器：将非文本数据转为特征向量
  ② 投影层：将特征向量映射到 LLM 的语义空间
  ③ LLM：统一处理文本+多模态特征 → 生成文本
```

## 视觉编码器

| 编码器 | 架构 | 参数量 | 使用模型 |
|--------|------|:---:|------|
| ViT-L/14 | Vision Transformer | 300M | LLaVA-1.5 |
| SigLIP | ViT 改进 | 400M | LLaVA-1.6 |
| ViT-bigG | 更大 ViT | 1.8B | Qwen-VL |
| InternViT | 自研 | 6B | InternVL-2 |

## 投影层方案

```text
① MLP 投影（最简单，LLaVA 使用）：
   视觉特征 → 2层 MLP → LLM 输入空间

② Q-Former（BLIP-2 使用）：
   可学习的 Query → Cross-Attend 视觉特征 → 压缩输出

③ 线性投影（Qwen-VL 使用）：
   视觉特征 → 单层 Linear → LLM 输入空间

选择：MLP（通用）vs Q-Former（需要压缩）vs Linear（最快）
```

## 主流多模态模型

| 模型 | 视觉编码 | LLM | 特点 |
|------|----------|-----|------|
| **GPT-4o** | 自研 | GPT-4 | 全能(图文音) |
| **Qwen-VL** | ViT-bigG | Qwen | 中文OCR最强 |
| **LLaVA-1.6** | SigLIP | LLaMA | 开源标杆 |
| **GLM-4V** | ViT | GLM-4 | 中文优化 |
| **InternVL2** | InternViT | InternLM | 多尺寸(1B-76B) |
| **Claude 3.5** | 自研 | Claude | 图表/文档强 |

## 多模态的挑战

| 挑战 | 说明 | 当前方案 |
|------|------|----------|
| **分辨率限制** | 高分辨率图 → token 爆炸 | 动态分辨率/分块编码 |
| **时间对齐** | 视频帧间关系 | 时间注意力 |
| **跨模态幻觉** | 描述图中不存在的内容 | 更强的对齐训练 |
| **训练成本** | 图文对齐需要大量数据 | 两阶段训练(预训练+指令微调) |
