# 11 - 微调与多模态面试题

## 微调面试题

**Q1: LoRA 为什么能大幅减少训练参数？**
```text
核心假设：微调时的权重更新 ΔW 是低秩的
ΔW(d×d) ≈ B(d×r) × A(r×d)，r<<d
参数从 d² 降到 2dr → 4096²(16.8M) → 2×4096×8(65K) = 减少 256×
```

**Q2: QLoRA 的三大技术创新？**
```text
① NF4：专为正态分布权重设计的 4-bit 格式
② 双重量化：量化常数量化 → 再省 0.4 bit/参数
③ 分页优化器：梯度峰值溢到 CPU → 避免 OOM
```

**Q3: 全量微调和 LoRA 选哪个？**
```text
数据 > 10000 条 + GPU 充足 → 全量微调（效果上限高）
数据 < 10000 条或 GPU 有限 → LoRA（省资源+天然抗遗忘）
大部分场景推荐 LoRA（性价比最高）
```

**Q4: SFT 和 RLHF 的区别？**
```text
SFT：学"怎么做" — 用标注数据让模型学会遵循指令
RLHF：学"人类喜欢什么" — 用偏好数据+P PO 让输出符合人类偏好
时间线：预训练 → SFT → RLHF → Chat Model
```

**Q5: 微调数据的关键原则？**
```text
① 质量 > 数量（1000条高质量 > 10万条噪声）
② 多样性（覆盖各种任务+边界Case）
③ 格式统一（全部 Alpaca 或全部 ShareGPT）
④ 包含 5-10% 通用数据（防灾难性遗忘）
```

## 多模态面试题

**Q6: VLM 的通用架构是什么？**
```text
图片 → 视觉编码器(ViT) → 投影层(MLP/Q-Former) → LLM → 文本
三步：编码→对齐→理解
```

**Q7: 扩散模型原理？**
```text
正向加噪(训练) + 反向去噪(推理)
推理时从纯噪声开始，逐步去噪 → 得到清晰图片
Text-to-Image：把 Prompt 作为条件注入去噪过程
```

**Q8: GPT-4o 语音为什么快？**
```text
传统级联(语音→文本→LLM→文本→语音) 延迟 2-5s
GPT-4o 端到端 → 直接语音入→语音出 → 232ms
```
