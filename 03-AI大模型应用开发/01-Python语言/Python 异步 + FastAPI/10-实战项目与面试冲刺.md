## 1. 综合项目：异步商品服务 API（端到端）

**需求**：商品查询服务——JWT 认证、异步 PostgreSQL 存储、Redis 缓存、定时从爬虫数据源导入商品（呼应阶段 6）、结构化日志 + 追踪、压测验证。

### 1.1 架构设计（面试能讲清的图）

```text
Nginx（TLS） → Uvicorn（4 workers, uvloop+httptools）
                 ├── Router: /auth（JWT 登录） /products（CRUD+搜索）
                 ├── Depends: get_db（AsyncSession）/ get_current_user（JWT）
                 ├── Middleware: 追踪 ID → 计时 → 异常兜底
                 ├── lifespan: AsyncClient / Redis 池 / 引擎 创建与关闭
                 └── 后台任务: 导入爬虫数据（阶段 6 产出的数据）
数据层：PostgreSQL（SQLAlchemy async, 池 20+10）
        Redis（缓存: product:{id}, 热榜: zset）
可观测：OTel（FastAPI/httpx/SQLAlchemy 自动埋点）+ JSON 日志（trace_id）
```

```python
    model_config = {"env_file": ".env", "env_prefix": "API_"}


settings = Settings()
```

```python
# app/core/db.py —— 引擎 + 会话（07 章模板）
from sqlalchemy.ext.asyncio import create_async_engine, async_sessionmaker, AsyncSession
from app.core.config import settings

engine = create_async_engine(
    settings.database_url,
    pool_size=20, max_overflow=10,
    pool_pre_ping=True, pool_recycle=1800, pool_timeout=30,
)
AsyncSessionLocal = async_sessionmaker(engine, class_=AsyncSession, expire_on_commit=False)


async def get_db():
    async with AsyncSessionLocal() as session:
        try:
            yield session
            await session.commit()
        except Exception:
            await session.rollback()
            raise
```

```python
# app/core/lifespan.py —— 全局资源（04/08 章）
from contextlib import asynccontextmanager
import httpx, redis.asyncio as aioredis
from fastapi import FastAPI


@asynccontextmanager
async def lifespan(app: FastAPI):
    app.state.http = httpx.AsyncClient(timeout=httpx.Timeout(5, read=15))
    app.state.redis = aioredis.from_url(settings.redis_url, decode_responses=True)
    yield
    await app.state.http.aclose()
    await app.state.redis.aclose()
```

```python
# app/models.py —— 商品模型（07 章：lazy="raise" 防 N+1）
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column, relationship
from sqlalchemy import String, Numeric


class Base(DeclarativeBase): pass


class Product(Base):
    __tablename__ = "products"
    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str] = mapped_column(String(128), index=True)
    price: Mapped[float] = mapped_column(Numeric(10, 2))
    category: Mapped[str] = mapped_column(String(32), index=True)
    source: Mapped[str] = mapped_column(String(64), default="")   # 爬虫来源标识
```

```python
# app/routers/products.py —— 核心业务（05/06/07 章组合）
from fastapi import APIRouter, Depends, HTTPException, Query
from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession
from app.core.db import get_db
from app.security import get_current_user

router = APIRouter(prefix="/products", tags=["商品"])


@router.get("/{product_id}", response_model=ProductOut)     # 05 章：response_model 白拿 Rust 序列化
async def get_product(
    product_id: int,
    db: AsyncSession = Depends(get_db),
    user: User = Depends(get_current_user),                 # 06 章：认证依赖
):
    # 缓存优先（03/08 章）
    cached = await app.state.redis.get(f"product:{product_id}")
    if cached:
        return ProductOut.model_validate_json(cached)
    product = await db.get(Product, product_id)
    if product is None:
        raise HTTPException(404, "商品不存在")
    await app.state.redis.set(f"product:{product_id}",
                              ProductOut.model_validate(product).model_dump_json(), ex=300)
    return product


@router.get("", response_model=list[ProductOut])
async def search_products(
    q: str = Query("", max_length=64),
    category: str | None = Query(None),
    page: int = Query(1, ge=1),
    size: int = Query(20, ge=1, le=100),
    db: AsyncSession = Depends(get_db),
    _: User = Depends(get_current_user),
):
    stmt = select(Product)
    if q: stmt = stmt.where(Product.name.ilike(f"%{q}%"))
    if category: stmt = stmt.where(Product.category == category)
    stmt = stmt.order_by(Product.id).offset((page - 1) * size).limit(size)
    return (await db.execute(stmt)).scalars().all()
```

```python
# app/main.py —— 组装（04/08 章）
from fastapi import FastAPI
from app.core.lifespan import lifespan
from app.core.middleware import RequestIdMiddleware
from app.routers import auth, products
from app.core.exceptions import register_exception_handlers

register_exception_handlers(app)                # 统一错误契约（08 章）
app.include_router(auth.router, prefix="/auth")
app.include_router(products.router)
```

### 1.3 验收指标

| 指标 | 通过线 |
|------|--------|
| 功能链路 | 登录 → 带 token 查商品 → 缓存命中 → 404 正确 |
| 安全 | 无 token 401；他人资源 403；日志无敏感字段 |
| 压测 | 1000 并发下 P99 < 300ms（缓存命中场景），无错误率 |
| 可观测 | 每行日志带 trace_id；OTel 能看到 DB/缓存 span |
| 优雅性 | kill 主进程 → 在途请求完成 → 资源关闭无报错 |

> 🎯 **核心要点**：项目把 04-09 章全部串起来了——**lifespan 管资源、依赖管会话认证、response_model 管性能安全、中间件管追踪、探针管发布**。验收不是"能跑"，是"安全 + 可观测 + 扛压 + 优雅"。

## 5. 高频面试题与答题范式

**Q1：Python 异步的原理？为什么能扛高并发？**
> 范式：事件循环单线程模型 → await 让出 + 回调就绪 → epoll 监听 IO → "等待时间交给别人"。强调并发 ≠ 并行；IO 密集收益、CPU 密集用进程。

**Q2：async def 和 def 端点区别？**
> 范式：def 自动进线程池（安全但不快）、async def 进事件循环（高吞吐）；**用异步库必须 async def，用同步库必须 def**——混用是事故根源。

**Q3：FastAPI 为什么快？（三句话）**
> 范式：① Starlette 轻量 ASGI 核心（纯 Python + anyio）；② Pydantic v2 Rust 校验 + 0.130 起响应序列化也走 Rust（2 倍+）；③ Uvicorn uvloop/httptools C 实现。再加一句：正确配置连接池才快。

**Q4：数据库会话怎么管理？（经典场景题）**
> 范式：lifespan 建引擎 → get_db yield 依赖（提交/回滚）→ 每请求独立会话 → 池参数五个 → 多 worker 乘法 → N+1 治理（lazy="raise" + selectinload）。

**Q5：JWT 认证实现 + 安全问题？**
> 范式：OAuth2PasswordBearer + encode/decode + 401 头；基线：环境变量密钥、短有效期、固定算法、载荷最小、HTTPS；可撤销用 Redis 黑名单/版本号。

**Q6：接口慢怎么排查？**
> 范式：OTel 拆 span（DB/下游/序列化/代码）→ 对症：伪异步（同步库阻塞）、N+1、没缓存、没超时 → 压测 P99 验证。

**Q7：多 worker 部署注意什么？**
> 范式：进程模型（每 worker 一事件循环）→ 共享状态放 Redis → 连接池 × worker 不超 DB 上限 → 优雅停机 + 就绪探针。
