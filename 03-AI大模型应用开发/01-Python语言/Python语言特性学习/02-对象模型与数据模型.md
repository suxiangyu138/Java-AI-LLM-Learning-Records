## 1. 对象三要素：id / type / value

每个 Python 对象都由三部分组成，其中前两个终身不变：

| 要素 | 获取方式 | 是否可变 | 说明 |
|------|---------|:-------:|------|
| **身份 id** | `id(obj)` | ❌ 不变 | CPython 里是内存地址 |
| **类型 type** | `type(obj)` | ❌ 不变 | 决定支持哪些操作 |
| **值 value** | 对象本身 | 视类型 | 可变对象能改，不可变对象不能 |

```python
x = [1, 2, 3]
print(id(x), type(x))     # 140... <class 'list'>
x.append(4)               # 值变了
print(id(x))              # 140... 同一个 id —— 还是同一个对象

x = [1, 2, 3, 4]          # 这才是换了对象
print(id(x))              # 不同的 id
```

CPython 层面，每个对象头部都有 `PyObject` 结构：

```c
typedef struct _object {
    Py_ssize_t ob_refcnt;      // 引用计数 → 见 11-内存管理
    PyTypeObject *ob_type;     // 类型指针 → type(obj) 就是读它
} PyObject;
```

> 💡 所以 `sys.getsizeof(1)` 是 28 字节而不是 4 字节——一个「小整数」也要背着引用计数和类型指针。

## 2. 变量是名字绑定，不是存储盒子

这是 Java 转 Python 第一个必须扭转的认知。

```python
a = [1, 2, 3]
b = a              # b 和 a 是贴在同一个 list 上的两个标签
b.append(4)
print(a)           # [1, 2, 3, 4] —— a 也变了

b = [9]            # 只是把 b 这个标签撕下来贴到新对象上
print(a)           # [1, 2, 3, 4] —— a 不受影响
```

```text
赋值 b = a 的真相：

     ┌───┐
  a ─┤   ├──→ ┌─────────────┐
     └───┘    │ list 对象    │  refcnt = 2
     ┌───┐    │ [1, 2, 3]   │
  b ─┤   ├──→ └─────────────┘
     └───┘

Java 的 int a = 1; int b = a; 是把值复制进另一个盒子
Python 永远是「多个名字指向同一对象」
```

| 操作 | Python 语义 | 对应 Java |
|------|------------|-----------|
| `a = obj` | 名字绑定（rebinding） | 引用赋值（对象类型时相同） |
| `a.attr = v` | 修改对象内部状态 | 相同 |
| `del a` | 解除绑定，引用计数 -1 | 无对应（`a = null` 近似） |
| `a += 1`（int） | 创建新对象再绑定 | 原地修改栈上的值 |
| `a += [1]`（list） | 原地扩展（调 `__iadd__`） | 相同 |

```python
# += 对可变/不可变类型行为不同，这是经典考点
a = (1, 2)
b = a
a += (3,)          # tuple 不可变 → 新建对象
print(a, b)        # (1, 2, 3) (1, 2)

a = [1, 2]
b = a
a += [3]           # list 可变 → 原地 extend
print(a, b)        # [1, 2, 3] [1, 2, 3] ← b 也变了！
```

## 3. 可变对象与不可变对象

| 类别 | 类型 | 可哈希 | 能做字典 key |
|------|------|:------:|:-----------:|
| **不可变** | `int` `float` `bool` `str` `bytes` `tuple` `frozenset` `None` | ✅ | ✅ |
| **可变** | `list` `dict` `set` `bytearray` 普通自定义类实例 | ⚠️ 默认可哈希但语义危险 | 不推荐 |

```python
# 不可变 ≠ 内容绝对不变：tuple 里可以装可变对象
t = ([1, 2], "a")
t[0].append(3)          # 合法！tuple 存的是引用，引用没变
print(t)                # ([1, 2, 3], 'a')
print(hash(t))          # TypeError: unhashable type: 'list'
#                         → 「可哈希」要求所有元素都可哈希
```

```python
# 字符串不可变：所有「修改」都是新建对象
s = "hello"
print(id(s))
s = s.replace("h", "j")   # 新对象
print(id(s))              # 不同

# 因此循环拼接字符串是 O(n²)，应该用 join（对照 Java StringBuilder）
# ❌ for w in words: s += w
# ✅ s = "".join(words)
```

> 🎯 判断标准：**能不能在不改变 `id` 的前提下改变值**。可变对象能，不可变对象不能。

## 4. 参数传递机制

Python 的传参既不是「传值」也不是「传引用」，官方术语是 **call by object reference（传对象引用）** 或 call by sharing：

```python
def modify(lst, num, s):
    lst.append(4)      # 原地修改 → 影响调用方
    num += 1           # 重新绑定局部名字 → 不影响调用方
    s += "!"           # 同上，str 不可变
    lst = [99]         # 重新绑定 → 后续不影响调用方

data, n, text = [1, 2, 3], 10, "hi"
modify(data, n, text)
print(data, n, text)   # [1, 2, 3, 4] 10 hi
```

判定规则只有一条：

```text
函数内对参数做了什么？
├── 调用了修改自身状态的方法/操作（append / [i]= / .attr=）
│      → 可变对象：调用方可见
│      → 不可变对象：根本做不到（没有这类方法）
└── 用 = 重新绑定了这个名字
       → 只影响函数内的局部命名空间，调用方永远不可见
```

## 5. is 与 == 的区别

| 运算符 | 比较内容 | 底层 | 可否重载 |
|--------|---------|------|:-------:|
| `is` | 身份（是否同一对象） | 比较 `id()` | ❌ 不可 |
| `==` | 值（是否相等） | 调 `__eq__` | ✅ 可 |

```python
a = [1, 2, 3]
b = [1, 2, 3]
print(a == b)   # True   值相同
print(a is b)   # False  两个不同对象

c = a
print(a is c)   # True   同一对象
```

铁律：**只有和 `None` / `True` / `False` 以及枚举单例比较时用 `is`，其余场景用 `==`**。

```python
# ✅ 正确
if x is None: ...
if flag is True: ...        # 更常见的写法是 if flag:

# ❌ 危险
if x == None: ...           # 若 x 重载了 __eq__，行为不可控
if name is "admin": ...     # 依赖字符串驻留，3.8+ 会给 SyntaxWarning
```

```python
# 自定义 __eq__ 时的完整契约（详见 09-魔术方法）
class Point:
    def __init__(self, x, y): self.x, self.y = x, y
    def __eq__(self, other):
        if not isinstance(other, Point): return NotImplemented
        return (self.x, self.y) == (other.x, other.y)
    def __hash__(self):                 # 定义了 __eq__ 必须同步定义 __hash__
        return hash((self.x, self.y))   # 否则实例变成 unhashable
```

> ⚠️ 只要重写 `__eq__` 而不写 `__hash__`，Python 会把 `__hash__` 置为 `None`，实例无法放进 `set`/`dict`。这与 Java 的「equals 和 hashCode 要一起重写」是同一个约定，只是 Python 强制得更狠。

## 6. 对象缓存机制

CPython 为性能做了若干缓存，导致 `is` 的结果有时「反直觉」。**这些都是实现细节，不要依赖**。

### 6.1 小整数池

```python
a, b = 256, 256
print(a is b)      # True   —— [-5, 256] 预先缓存
a, b = 257, 257
print(a is b)      # True   —— 同一行编译期常量折叠，共享常量表

def f():
    x = 257
    y = 257
    return x is y
print(f())         # True  —— 同一 code object 内的常量被合并

a = int("257")     # 绕过编译期优化
b = int("257")
print(a is b)      # False  —— 这才是真实情况
```

### 6.2 字符串驻留（interning）

```python
a = "hello"
b = "hello"
print(a is b)                  # True  —— 标识符样式的字符串自动驻留

a = "hello world!"
b = "hello world!"
print(a is b)                  # True（同模块常量折叠）
print("".join(["he","llo"]) is "hello")   # False —— 运行时构造不驻留

import sys
s = sys.intern("hello world!")  # 手动驻留：大量重复字符串比较时可省内存
```

| 缓存类型 | 范围 | 触发条件 |
|---------|------|---------|
| 小整数池 | `-5` ~ `256` | 解释器启动时预建 |
| 常量折叠 | 同一 code object | 编译期可确定的字面量 |
| 字符串驻留 | 类标识符字符串（字母/数字/下划线） | 编译期自动 或 `sys.intern()` |
| `None`/`True`/`False` | 全局唯一单例 | 语言保证 |

> 🎯 面试常问「`a = 256; b = 256; a is b` 为什么是 True」。正确答法是先说小整数池，再补一句「但这是 CPython 实现细节，判断相等永远用 `==`」——后半句才是加分项。

## 7. 浅拷贝与深拷贝

```python
import copy

original = [[1, 2], [3, 4]]

ref      = original                 # 0 层拷贝：同一对象
shallow  = copy.copy(original)      # 浅拷贝：新外层，内层共享
shallow2 = original[:]              # 切片也是浅拷贝
shallow3 = list(original)           # 构造器也是浅拷贝
deep     = copy.deepcopy(original)  # 深拷贝：递归复制所有层

original[0].append(99)
print(shallow)   # [[1, 2, 99], [3, 4]]  ← 受影响
print(deep)      # [[1, 2], [3, 4]]      ← 不受影响
```

```text
        original ──→ ┌────────┐
                     │ 外层list│
                     └───┬─┬──┘
             ┌───────────┘ └──────────┐
             ▼                        ▼
        ┌────────┐               ┌────────┐
        │ [1,2]  │               │ [3,4]  │
        └────────┘               └────────┘
             ▲                        ▲
             └──────┬─────────────────┘
   shallow ──→ ┌────────┐   ← 新外层，指向同样的内层对象
               │ 外层list│
               └────────┘

   deep ─────→ 全新外层 + 全新的 [1,2] 和 [3,4]
```

| 方式 | 外层 | 内层 | 开销 | 适用 |
|------|:----:|:----:|:----:|------|
| `b = a` | 共享 | 共享 | 0 | 只是取别名 |
| `copy.copy(a)` / `a[:]` / `dict(a)` | 新建 | 共享 | 低 | 单层容器 |
| `copy.deepcopy(a)` | 新建 | 新建 | 高 | 嵌套结构、需完全隔离 |

```python
# 自定义拷贝行为
class Node:
    def __init__(self, val, conn=None):
        self.val, self.conn = val, conn
    def __copy__(self):                        # 供 copy.copy 调用
        return Node(self.val, self.conn)
    def __deepcopy__(self, memo):              # 供 copy.deepcopy 调用
        return Node(copy.deepcopy(self.val, memo),
                    copy.deepcopy(self.conn, memo))
```

> 💡 `deepcopy` 用 `memo` 字典记录已拷贝对象，能正确处理循环引用；代价是慢（涉及大量递归和字典操作）。性能敏感场景可考虑 `pickle.loads(pickle.dumps(obj))`（更快但要求可序列化），或者干脆重新设计成不可变数据结构。

## 8. 数据模型：协议优先的设计

Python 的「数据模型」指的是：**内置语法/函数通过调用对象的特殊方法来工作**。你实现了对应的特殊方法，对象就自动支持对应语法。

```text
你写的代码           Python 实际调用的方法
──────────────────────────────────────────
len(obj)         →   obj.__len__()
obj[k]           →   obj.__getitem__(k)
obj + other      →   obj.__add__(other)
for x in obj     →   obj.__iter__()
with obj:        →   obj.__enter__() / __exit__()
obj()            →   obj.__call__()
print(obj)       →   obj.__str__()
obj.attr         →   obj.__getattribute__('attr')
k in obj         →   obj.__contains__(k)
```

```python
# 实现协议 → 自动获得语法支持
class Playlist:
    def __init__(self, songs): self._songs = list(songs)
    def __len__(self):         return len(self._songs)
    def __getitem__(self, i):  return self._songs[i]
    def __contains__(self, s): return s in self._songs
    def __repr__(self):        return f"Playlist({self._songs!r})"

p = Playlist(["a", "b", "c"])
print(len(p))          # 3            ← __len__
print(p[1])            # b            ← __getitem__
print("a" in p)        # True         ← __contains__
for s in p: pass       # 可迭代！      ← 只有 __getitem__ 也能迭代（旧协议）
print(p[::-1])         # ['c','b','a'] ← 切片自动透传
```

这就是「协议优先」：**不需要继承任何基类，实现方法即接入语言**。对照 Java 需要 `implements Iterable<T>`、`implements Comparable<T>`。

| Java 接口 | Python 协议（无需继承） |
|-----------|----------------------|
| `Iterable<T>` | `__iter__` |
| `Iterator<T>` | `__iter__` + `__next__` |
| `Comparable<T>` | `__lt__` `__eq__`（+ `functools.total_ordering`） |
| `AutoCloseable` | `__enter__` + `__exit__` |
| `toString()` | `__str__` / `__repr__` |
| `equals()` + `hashCode()` | `__eq__` + `__hash__` |
| `Function<T,R>` | `__call__`（或直接传函数） |

> 🎯 完整的 80+ 魔术方法清单见 [09-魔术方法全景](./09-魔术方法全景.md)。这里要记住的是**思维方式**：在 Python 里定义「类型能做什么」，靠的是实现协议方法，不是声明继承关系。

## 9. 核心要点回顾

- 对象三要素 **id / type / value**，前两个终身不变
- 变量是**贴在对象上的名字**，赋值 = 重新绑定，不是复制值
- **可变性**判定：能否在 `id` 不变的前提下改值；不可变对象的「修改」都是新建
- `+=` 对 list 是原地 `extend`，对 tuple/int/str 是新建对象后重新绑定
- 传参是 **call by sharing**：原地修改调用方可见，重新绑定调用方不可见
- `is` 比身份、`==` 比值；**只对 None/True/False/单例用 is**
- 小整数池 `[-5, 256]`、字符串驻留、常量折叠都是 **CPython 实现细节**，别依赖
- 重写 `__eq__` 必须同步重写 `__hash__`
- 拷贝三层次：**别名 → 浅拷贝 → 深拷贝**，`deepcopy` 靠 `memo` 处理循环引用
- **数据模型 = 协议优先**：实现特殊方法即接入语言语法，无需继承
