## 1. 函数是一等公民

「一等公民」意味着函数能做普通对象能做的一切事：

```python
def greet(name): return f"Hello, {name}"

# ① 赋值给变量
f = greet
print(f("A"))                      # Hello, A

# ② 作为参数传递
print(list(map(greet, ["A", "B"])))

# ③ 作为返回值
def make_greeter(prefix):
    def inner(name): return f"{prefix}, {name}"
    return inner
print(make_greeter("Hi")("B"))     # Hi, B

# ④ 存进容器
registry = {"greet": greet, "upper": str.upper}
print(registry["greet"]("C"))

# ⑤ 挂载属性
greet.call_count = 0
greet.__doc__ = "打招呼"

# ⑥ 嵌套定义
def outer():
    def inner(): return 1
    return inner()
```

| 能力 | Python | Java |
|------|:------:|------|
| 赋值给变量 | ✅ 原生 | 需 `Function<T,R>` / 方法引用 |
| 作为参数 | ✅ 原生 | 需函数式接口 |
| 挂载属性 | ✅ | ❌ |
| 运行时创建 | ✅ `exec` / `types.FunctionType` | 需字节码生成 |
| 独立于类存在 | ✅ 模块级函数 | ❌ 必须在类里 |

> 💡 正是因为函数是对象，装饰器才能写成「接受函数、返回函数」的普通函数（详见 [07-装饰器与元编程](./07-装饰器与元编程.md)）。

## 2. 五种参数类型与完整签名

Python 3 的完整函数签名形式：

```python
def f(pos_only, /, standard, *args, kw_only, **kwargs):
    ...
#      ↑         ↑     ↑        ↑       ↑         ↑
#   仅位置    分隔符  标准   可变位置  仅关键字  可变关键字
```

| 类型 | 写法 | 传参方式 | 引入版本 |
|------|------|---------|:-------:|
| 仅位置（positional-only） | `/` 之前 | 只能按位置 | 3.8 (PEP 570) |
| 标准（positional-or-keyword） | 普通形参 | 位置或关键字都行 | — |
| 可变位置 | `*args` | 收集多余的位置参数 → tuple | — |
| 仅关键字（keyword-only） | `*` 之后 | 必须写参数名 | 3.0 (PEP 3102) |
| 可变关键字 | `**kwargs` | 收集多余的关键字参数 → dict | — |

```python
def demo(a, b, /, c, d, *, e, f):
    print(a, b, c, d, e, f)

demo(1, 2, 3, 4, e=5, f=6)       # ✅
demo(1, 2, c=3, d=4, e=5, f=6)   # ✅ c/d 可用关键字
# demo(a=1, b=2, ...)            # ❌ TypeError: a,b 是仅位置参数
# demo(1, 2, 3, 4, 5, 6)         # ❌ TypeError: e,f 必须用关键字
```

### 2.1 为什么需要这两个限定符

```python
# 仅位置 / ：保留改参数名的自由，避免调用方依赖内部命名
def divide(a, b, /):        # 以后改成 (x, y, /) 不会破坏任何调用方
    return a / b
# 内置函数大量使用：len(obj, /)、abs(x, /)

# 仅关键字 * ：强制调用点自解释，防止布尔陷阱
def create_user(name, *, admin=False, verified=False):
    ...
create_user("Tom", admin=True)          # ✅ 一眼看懂
# create_user("Tom", True, False)       # ❌ 被禁止，避免了「True 是什么？」
```

> 🎯 工程建议：**布尔开关和可选配置一律放到 `*` 之后**。这条规则能显著提升 API 的可读性，也是很多主流库（pandas、requests、PyTorch）的做法。

### 2.2 参数绑定顺序

```python
def f(a, b=2, *args, c, d=4, **kwargs):
    print(f"{a=} {b=} {args=} {c=} {d=} {kwargs=}")

f(1, c=3)
# a=1 b=2 args=() c=3 d=4 kwargs={}
f(1, 20, 30, 40, c=3, d=40, x=9)
# a=1 b=20 args=(30, 40) c=3 d=40 kwargs={'x': 9}
```

```python
import inspect
print(inspect.signature(f))     # (a, b=2, *args, c, d=4, **kwargs)
bound = inspect.signature(f).bind(1, c=3)
bound.apply_defaults()
print(bound.arguments)          # {'a': 1, 'b': 2, 'args': (), 'c': 3, 'd': 4, 'kwargs': {}}
```

## 3. *args 与 **kwargs

### 3.1 定义端：收集参数

```python
def f(*args, **kwargs):
    print(type(args), args)        # <class 'tuple'>
    print(type(kwargs), kwargs)    # <class 'dict'>

f(1, 2, x=3, y=4)
# (1, 2)
# {'x': 3, 'y': 4}
```

### 3.2 调用端：解包参数

```python
def point(x, y, z): return x + y + z

coords = [1, 2, 3]
print(point(*coords))              # 6   —— * 解包序列到位置参数

d = {"x": 1, "y": 2, "z": 3}
print(point(**d))                  # 6   —— ** 解包字典到关键字参数
```

> 💡 `*` / `**` 的含义取决于位置：**在 def 里是「收集」，在调用里是「解包」**。这是很多人混淆的点。

### 3.3 典型用途：透明转发

```python
# 装饰器必须用 *args/**kwargs 才能包装任意签名的函数
import functools

def log(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):        # 接受一切
        print(f"call {func.__name__}")
        return func(*args, **kwargs)     # 原样转发
    return wrapper
```

```python
# 子类扩展父类参数（AI 框架里极常见）
class BaseModel:
    def __init__(self, hidden_size=768, dropout=0.1):
        self.hidden_size, self.dropout = hidden_size, dropout

class MyModel(BaseModel):
    def __init__(self, num_labels, **kwargs):   # 新增自己的参数
        super().__init__(**kwargs)              # 其余透传给父类
        self.num_labels = num_labels

m = MyModel(num_labels=3, hidden_size=1024)
```

### 3.4 通用解包（PEP 448，3.5+）

```python
# 合并容器
a, b = [1, 2], [3, 4]
print([*a, *b])                    # [1, 2, 3, 4]
print({**{"x":1}, **{"y":2}})      # {'x': 1, 'y': 2}
print({*a, *b})                    # {1, 2, 3, 4}

# 多次解包
def f(*args, **kw): print(args, kw)
f(*a, *b, **{"p":1}, **{"q":2})    # (1,2,3,4) {'p':1,'q':2}

# 星号赋值解包（PEP 3132）
first, *middle, last = [1, 2, 3, 4, 5]
print(first, middle, last)         # 1 [2, 3, 4] 5
```

## 4. 默认参数可变陷阱

**Python 最著名的陷阱**，排名与闭包延迟绑定并列：

```python
def append_to(item, target=[]):        # ❌ 危险
    target.append(item)
    return target

print(append_to(1))     # [1]
print(append_to(2))     # [1, 2]  ← 不是 [2]！
print(append_to(3))     # [1, 2, 3]
```

根因：**默认值在函数定义时求值一次，之后所有调用共享同一个对象**。

```python
def f(target=[]): pass
print(f.__defaults__)          # ([],)  ← 默认值存在函数对象上，只有一份
f.__defaults__[0].append(99)   # 能直接改到它
print(f.__defaults__)          # ([99],)
```

```text
定义时：
   append_to.__defaults__ ──→ ┌──────────┐
                              │ list []  │  ← 只创建这一次！
                              └──────────┘
每次调用不传 target 时，都绑定到这同一个 list
```

正确写法：

```python
# ✅ 用 None 哨兵 + 函数内创建
def append_to(item, target=None):
    if target is None:
        target = []
    target.append(item)
    return target

# ✅ 需要「可选但不可变」时，用不可变默认值
def f(items=()):                      # tuple 不可变，安全
    return list(items)

# ✅ 类型提示配合
from typing import Optional
def g(cache: Optional[dict] = None) -> dict:
    cache = {} if cache is None else cache
    return cache
```

同类陷阱的其他形态：

```python
# 陷阱变体 1：默认值调用了函数（求值时机问题）
import datetime
def log(msg, ts=datetime.datetime.now()):    # ❌ ts 永远是模块导入时刻
    print(ts, msg)
# ✅ def log(msg, ts=None): ts = ts or datetime.datetime.now()

# 陷阱变体 2：类属性作为「实例默认值」
class Basket:
    items = []                  # ❌ 类属性，所有实例共享
    def add(self, x): self.items.append(x)
b1, b2 = Basket(), Basket()
b1.add("a"); print(b2.items)    # ['a'] ← 串了

class Basket2:
    def __init__(self): self.items = []      # ✅ 实例属性
```

| 默认值类型 | 是否安全 | 原因 |
|-----------|:-------:|------|
| `int` `str` `tuple` `frozenset` `None` `True/False` | ✅ | 不可变，无法被修改 |
| `list` `dict` `set` | ❌ | 可变，跨调用共享状态 |
| 函数调用结果 `f()` | ⚠️ | 只在定义时求值一次 |
| `datetime.now()` | ❌ | 时间戳被冻结在导入时刻 |

> 🎯 记忆口诀：**默认值只算一次**。可变默认值一律改成 `None` 哨兵。ruff/pylint 的 `B006` 规则能自动检出这类问题，建议开启。

## 5. 高阶函数与函数式三件套

**高阶函数** = 接受函数作为参数、或返回函数的函数。

| 函数 | 作用 | 返回 | Pythonic 替代 |
|------|------|------|--------------|
| `map(f, it)` | 逐元素变换 | 迭代器（惰性） | 推导式 `[f(x) for x in it]` |
| `filter(f, it)` | 按条件筛选 | 迭代器（惰性） | 推导式 `[x for x in it if f(x)]` |
| `functools.reduce(f, it, init)` | 累积折叠 | 单值 | `sum` / `math.prod` / 显式循环 |
| `sorted(it, key=f)` | 排序 | list | — （没有替代，就用它） |
| `min/max(it, key=f)` | 极值 | 单值 | — |
| `any/all(it)` | 短路判断 | bool | — |

```python
nums = [1, 2, 3, 4, 5]

print(list(map(lambda x: x**2, nums)))          # [1, 4, 9, 16, 25]
print(list(filter(lambda x: x % 2, nums)))      # [1, 3, 5]

from functools import reduce
print(reduce(lambda a, b: a * b, nums, 1))      # 120

# 官方更推荐推导式（可读性更好）
print([x**2 for x in nums])                     # 同 map
print([x for x in nums if x % 2])               # 同 filter
```

```python
# sorted 的 key 是最实用的高阶函数用法
data = [{"name": "b", "age": 30}, {"name": "a", "age": 25}]
print(sorted(data, key=lambda d: d["age"]))         # 按年龄
print(sorted(data, key=lambda d: (-d["age"], d["name"])))  # 多级+倒序

from operator import itemgetter, attrgetter
print(sorted(data, key=itemgetter("age")))          # 比 lambda 快，C 实现
# 对象场景：sorted(objs, key=attrgetter("age"))
```

> 💡 `map`/`filter` 返回**惰性迭代器**，只遍历一次就耗尽。需要多次使用时必须 `list()` 固化。这与 Java Stream 的一次性消费语义一致。

## 6. lambda 与 partial

### 6.1 lambda 的限制

```python
add = lambda a, b: a + b       # 只能是单个表达式
# lambda x: (y = 1; x + y)     # ❌ 不能有语句、赋值、return
```

| 维度 | `lambda` | `def` |
|------|---------|-------|
| 函数体 | 单个表达式 | 任意语句块 |
| 名字 | `<lambda>` | 真实函数名 |
| 文档字符串 | ❌ | ✅ |
| 类型注解 | ❌ | ✅ |
| 可调试性 | 差（traceback 里看不出是哪个） | 好 |

```python
# ❌ PEP 8 明确反对把 lambda 赋值给名字
f = lambda x: x * 2
# ✅ 直接用 def
def f(x): return x * 2

# ✅ lambda 的正确用途：一次性的短回调
sorted(data, key=lambda d: d["age"])
button.on_click(lambda: handler(user_id))
df["col"].apply(lambda x: x.strip())
```

### 6.2 functools.partial

固定部分参数，生成新函数——比 lambda 更清晰，且可 pickle（能跨进程传递）：

```python
from functools import partial

def power(base, exp): return base ** exp

square = partial(power, exp=2)
cube   = partial(power, exp=3)
print(square(5), cube(2))            # 25 8

print(square.func, square.keywords)  # <function power> {'exp': 2}
```

```python
# 实战：统一配置的 API 调用器
import requests
post_json = partial(requests.post,
                    headers={"Content-Type": "application/json"},
                    timeout=30)
# post_json(url, json={...})

# 实战：多进程场景（lambda 不能 pickle，partial 可以）
from multiprocessing import Pool
def process(item, factor): return item * factor
with Pool(4) as p:
    result = p.map(partial(process, factor=10), range(5))   # ✅
    # p.map(lambda x: process(x, 10), range(5))             # ❌ PicklingError
```

## 7. 函数对象的内省

```python
def greet(name: str, greeting: str = "Hello") -> str:
    """打招呼。"""
    return f"{greeting}, {name}"

print(greet.__name__)         # greet
print(greet.__doc__)          # 打招呼。
print(greet.__defaults__)     # ('Hello',)
print(greet.__annotations__)  # {'name': <class 'str'>, 'greeting': ..., 'return': ...}
print(greet.__module__)       # __main__
print(greet.__qualname__)     # greet（类方法时是 Cls.method）
print(greet.__code__.co_varnames)   # ('name', 'greeting')
```

| 属性 | 内容 | 常见用途 |
|------|------|---------|
| `__name__` / `__qualname__` | 函数名 / 限定名 | 日志、装饰器 |
| `__doc__` | 文档字符串 | 帮助文档、CLI 生成 |
| `__defaults__` / `__kwdefaults__` | 位置/关键字默认值 | 框架读取默认配置 |
| `__annotations__` | 类型注解 | Pydantic / FastAPI 的核心机制 |
| `__closure__` | 闭包 cell | 调试闭包 |
| `__code__` | Code Object | 深度内省、字节码分析 |
| `__wrapped__` | 被装饰的原函数（`wraps` 设置） | 穿透装饰器 |

```python
import inspect
print(inspect.signature(greet))          # (name: str, greeting: str = 'Hello') -> str
print(inspect.getsource(greet))          # 源码文本
print(inspect.isfunction(greet), inspect.isgeneratorfunction(greet))
```

> 🎯 FastAPI 能仅凭函数签名自动生成 OpenAPI 文档、做参数校验，全靠 `__annotations__` + `inspect.signature`。这是 Python 内省能力最漂亮的应用之一。

## 8. 递归与调用栈限制

```python
import sys
print(sys.getrecursionlimit())      # 1000（默认）

def f(n): return 1 if n <= 1 else n * f(n - 1)
# f(3000)  → RecursionError: maximum recursion depth exceeded

sys.setrecursionlimit(10000)        # 可调，但有真实栈溢出风险（段错误）
```

**Python 没有尾调用优化**（Guido 明确拒绝过，理由是会破坏 traceback）。因此：

```python
# ❌ 深递归在 Python 里不可靠
def sum_list(lst):
    return 0 if not lst else lst[0] + sum_list(lst[1:])

# ✅ 改成迭代
def sum_list(lst):
    total = 0
    for x in lst: total += x
    return total

# ✅ 或用显式栈模拟（树/图遍历）
def walk(root):
    stack = [root]
    while stack:
        node = stack.pop()
        yield node
        stack.extend(reversed(node.children))
```

```python
# 记忆化：把指数级递归降到线性（但深度问题仍在）
from functools import lru_cache

@lru_cache(maxsize=None)
def fib(n): return n if n < 2 else fib(n-1) + fib(n-2)
print(fib(100))          # 瞬间完成
print(fib.cache_info())  # CacheInfo(hits=98, misses=101, ...)
```

| 场景 | 建议 |
|------|------|
| 树/图遍历（深度可控，如 AST、JSON） | 递归可以，清晰 |
| 链表/大列表处理 | 改迭代 |
| 分治算法（快排、归并） | 递归可以（深度 O(log n)） |
| 动态规划 | `lru_cache` 递归 或 自底向上迭代 |
| 深度不确定的用户输入驱动 | 必须迭代 + 显式深度上限 |

## 9. 核心要点回顾

- 函数是**一等公民**：可赋值、传递、返回、挂属性、进容器——装饰器的基础
- 完整签名 `f(pos, /, std, *args, kw_only, **kwargs)`，五种参数类型
- **`/` 保留改参数名的自由，`*` 强制关键字调用**——布尔开关都放 `*` 之后
- `*`/`**` 在 def 里是**收集**，在调用里是**解包**
- **默认值只在定义时求值一次** → 可变默认值必须改用 `None` 哨兵
- `map`/`filter` 返回惰性迭代器且一次性；推导式通常更 Pythonic
- lambda 只能是单表达式，**别赋值给名字**；`partial` 更清晰且可 pickle
- 函数内省（`__annotations__` + `inspect.signature`）是 FastAPI/Pydantic 的基石
- Python **无尾调用优化**，默认递归深度 1000；深递归改迭代，DP 用 `lru_cache`
