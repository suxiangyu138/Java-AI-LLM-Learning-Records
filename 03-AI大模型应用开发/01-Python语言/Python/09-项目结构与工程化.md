# 09 - 项目结构与工程化

> 🎯 Python 项目不是"一个脚本写完就行" — 合理的项目布局、打包、测试、CI 让 AI 服务从 Demo 走向生产

## 标准项目布局

```text
my-llm-project/
├── pyproject.toml          # 项目元数据+依赖+工具配置
├── src/
│   └── myllm/
│       ├── __init__.py
│       ├── api/
│       │   ├── server.py   # FastAPI 服务
│       │   └── routes.py
│       ├── core/
│       │   ├── llm.py      # LLM 调用封装
│       │   └── config.py   # 配置管理
│       ├── rag/
│       │   ├── loader.py   # 文档加载
│       │   ├── embedder.py # Embedding
│       │   └── retriever.py
│       └── utils/
│           └── cache.py
├── tests/
│   ├── test_llm.py
│   └── test_rag.py
├── scripts/
│   └── index_docs.py       # 离线脚本
└── Dockerfile
```

## pyproject.toml

```toml
[project]
name = "my-llm"
version = "0.1.0"
requires-python = ">=3.11"
dependencies = ["fastapi", "openai", "langchain"]

[project.optional-dependencies]
dev = ["pytest", "black", "ruff", "mypy"]

[tool.ruff]
line-length = 100
[tool.pytest.ini_options]
testpaths = ["tests"]
```

## 测试

```python
# tests/test_llm.py
import pytest
from myllm.core.llm import LLMClient

def test_chat():
    client = LLMClient(model="gpt-4o-mini")
    resp = client.chat("Hello")
    assert len(resp) > 0

def test_error_handling():
    with pytest.raises(RateLimitError):
        client.chat("test" * 10000)  # token 超限
```

```bash
pytest -v --cov=src/myllm --cov-report=html
```

## CI (GitHub Actions)

```yaml
name: Python CI
on: [push]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: { python-version: '3.11' }
      - run: pip install -e '.[dev]'
      - run: ruff check .
      - run: pytest -v
```
