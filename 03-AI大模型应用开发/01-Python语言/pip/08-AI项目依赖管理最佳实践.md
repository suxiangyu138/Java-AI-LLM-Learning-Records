## 1. AI 项目依赖特点

```text
AI 项目 vs 普通 Python 项目：

普通项目：
  依赖数: 5-20
  关键依赖: Django / FastAPI
  安装时间: 1-2 分钟
  环境大小: 100-300 MB

AI 项目：
  依赖数: 30-100+
  关键依赖: PyTorch + CUDA + transformers + 各种加速库
  安装时间: 5-15 分钟
  环境大小: 2-10 GB (含 CUDA)
```

## 2. LLM 项目模板

### conda 方案（推荐）

```yaml
# environment.yml — LLM 项目标准环境
name: llm-project
channels:
  - pytorch
  - nvidia
  - conda-forge
  - defaults
dependencies:
  - python=3.11
  # GPU
  - pytorch=2.4.0
  - pytorch-cuda=12.1
  - torchvision
  # LLM 核心
  - pip
  - pip:
    - transformers==4.44.0
    - datasets==2.20.0
    - accelerate==0.33.0
    - peft==0.12.0              # LoRA/QLoRA 微调
    - bitsandbytes==0.43.0      # 4bit 量化
    - sentencepiece==0.2.0      # tokenizer
    - protobuf                   # 模型加载
    # 推理
    - vllm==0.5.4
    # API
    - fastapi==0.112.0
    - uvicorn==0.30.0
    # 工具
    - wandb==0.17.0             # 实验追踪
    - python-dotenv==1.0.0
```

### pip 方案

```text
# requirements.in
torch>=2.4.0,<2.5.0
transformers>=4.44
datasets>=2.20
accelerate>=0.33
peft>=0.12
bitsandbytes>=0.43

# pip-compile requirements.in → requirements.txt
```

## 4. 依赖管理原则

### 4.1 六大原则

```text
1. 分层锁定
   environment.yml (conda 环境) → PyTorch + CUDA
   requirements.in (pip 直接依赖) → 核心技术栈
   requirements.txt (pip 完整锁定) → 生产部署

2. GPU 和 CPU 分开
   requirements-gpu.txt  → GPU 训练
   requirements-cpu.txt  → CPU 推理/轻量测试

3. 版本下限不禁上限
   transformers>=4.44  ✅
   transformers==4.44.0 ❌（太死）
   transformers>=4.44,<5.0  ✅（最佳）

4. 避免版本冲突的包组合
   numpy<2.0     vs    很多包还依赖 numpy 1.x
   triton>=2.2   vs    Linux only

5. 平台兼容
   bitsandbytes  → Linux only (Windows 用 bitsandbytes-windows-webui)

6. CI 中 pin 死版本
   生产 Dockerfile 中: pip install -r requirements.txt（完整锁定）
```

### 4.2 最小依赖原则

```bash
# 检查可以删除的依赖
pip install pipdeptree
pipdeptree | grep -v "^-" | wc -l   # 总依赖数

# 找引用但未声明的隐式依赖
pip install pip-check
pip-check

# 找未使用的包
pip install pip-autoremove
pip-autoremove <pkg> -y
```

## 核心要点回顾

- AI 项目三层依赖：conda 管 CUDA + pip 管包 + lock 文件锁定
- PyTorch + CUDA 用 conda，其他包用 pip（pip 装 conda 环境里）
- 版本约束：灵活设下限 + 合理上限 + lock 文件锁定精确版本
- LLM 项目核心依赖：PyTorch + transformers + accelerate + peft/vLLM
- RAG 项目核心依赖：PyTorch + langchain + chromadb + unstructured
