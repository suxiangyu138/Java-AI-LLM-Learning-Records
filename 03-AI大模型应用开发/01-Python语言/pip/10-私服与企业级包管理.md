## 1. 国内镜像源配置

| 华为云 | `https://repo.huaweicloud.com/repository/pypi/simple/` | ⭐⭐⭐ |

### 配置方式

```bash
# 方式一：命令行临时指定
pip install -i https://mirrors.aliyun.com/pypi/simple/ <pkg>

# 方式二：全局配置（推荐）
pip config set global.index-url https://mirrors.aliyun.com/pypi/simple/
pip config set global.trusted-host mirrors.aliyun.com

# 方式三：环境变量
export PIP_INDEX_URL=https://mirrors.aliyun.com/pypi/simple/
export PIP_TRUSTED_HOST=mirrors.aliyun.com
```

## 2. 搭建私有 PyPI

### DevPI（最简方案，5 分钟搭建）

```bash
# 安装
pip install devpi-server devpi-client

# 启动服务
devpi-init
devpi-server --host=0.0.0.0 --port=4040

# 客户端配置
pip config set global.index-url http://your-server:4040/root/pypi/+simple/
pip config set global.trusted-host your-server

# 上传私有包
devpi use http://your-server:4040
devpi login root
devpi upload /path/to/my-package-0.1.0.tar.gz
```

### 自建镜像缓存（简化方案）

```bash
# pip2pi：把 PyPI 包缓存到本地
pip install pip2pi
mkdir /data/pypi-packages

# 下载包到本地
pip download -d /data/pypi-packages -r requirements.txt

# 生成索引
dir2pi /data/pypi-packages

# 用 nginx 暴露静态目录
# nginx config:
# location /pypi/ { alias /data/pypi-packages/; autoindex on; }

# 使用
pip install -i http://internal-server/pypi/simple <pkg>
```

## 3. pip.conf 企业级配置

```ini
# /etc/pip.conf (全局，所有用户生效)
[global]
index-url = http://internal-pypi.company.com/simple/
extra-index-url = https://mirrors.aliyun.com/pypi/simple/
trusted-host = internal-pypi.company.com mirrors.aliyun.com
timeout = 120
retries = 5

[install]
# 只允许二进制包（避免内网编译问题）
only-binary = :all:
```

> 🎯 `index-url` 指向私有 PyPI（主源），`extra-index-url` 指向公共镜像（兜底）

## 4. 安全与合规

```bash
# 1. 扫描已知漏洞
pip install pip-audit
pip-audit

# 2. 检查许可证合规
pip install pip-licenses
pip-licenses --summary                     # 许可证总览
pip-licenses --filter="GPL"               # 过滤 GPL（可能有合规风险）

# 3. 包的哈希校验
pip install --require-hashes -r requirements.txt
# requirements.txt:
# torch==2.4.0 \
#     --hash=sha256:abc123...

# 4. 内网离线安装
pip download -r requirements.txt -d offline-packages/
# 拷贝到内网：
pip install --no-index --find-links=offline-packages/ -r requirements.txt
```

## 核心要点回顾

- 国内开发 → 配清华/阿里云镜像（ping 选最快的）
- 企业内网 → DevPI（5 分钟搭建）或 nginx + pip2pi
- pip.conf 分层：`index-url`（私有主源）+ `extra-index-url`（公共兜底）
- 安全三件套：`pip-audit`（漏洞）+ `pip-licenses`（许可证）+ `--require-hashes`（防篡改）
- 离线方案：`pip download` → 拷贝 → `pip install --no-index`
