## 4. 工具栈速查

| 工具 | 用途 | 推荐场景 |
|------|------|---------|
| **Requests** | HTTP 请求库 | 简单网页抓取 |
| **BeautifulSoup** | HTML 解析 | 静态页面提取 |
| **lxml / XPath** | 高性能解析 | 大量数据提取 |
| **Scrapy** | 爬虫框架 | 中大型爬虫项目 |
| **Selenium** | 浏览器自动化 | JS 动态渲染 |
| **Playwright** | 现代浏览器自动化 | 复杂 SPA 页面 |
| **aiohttp** | 异步 HTTP | 高并发抓取 |
| **httpx** | 现代 HTTP 客户端 | 同步+异步双模式 |
