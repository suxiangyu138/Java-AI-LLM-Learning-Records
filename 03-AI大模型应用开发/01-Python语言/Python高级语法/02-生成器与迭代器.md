## 1. 迭代器协议

```python
# 可迭代对象 (Iterable): 有 __iter__()，返回迭代器
# 迭代器 (Iterator): 有 __next__()，逐个产出元素

class CountDown:
    def __init__(self, start):
        self.current = start

    def __iter__(self):
        return self

    def __next__(self):
        if self.current <= 0:
            raise StopIteration
        self.current -= 1
        return self.current + 1

for num in CountDown(3):
    print(num)   # 3, 2, 1
```

## 2. 生成器 yield

```python
# 生成器 = 写起来像函数，行为像迭代器
def countdown(n):
    while n > 0:
        yield n    # ← yield 暂停、保存状态、返回
        n -= 1

for num in countdown(3):
    print(num)   # 3, 2, 1

# yield from：委托给子生成器
def chain(*iterables):
    for it in iterables:
        yield from it  # ← 等价于 for x in it: yield x
```

### 生成器 vs 列表

```python
# ❌ 列表：一次性加载到内存（100MB 文件 = 100MB 内存）
lines = [line.strip() for line in open("big_file.txt")]

# ✅ 生成器：逐行处理（内存恒定 < 1MB）
lines = (line.strip() for line in open("big_file.txt"))

# 生成器的核心价值：惰性求值——只在需要时才计算下一个值
```

### send() 与双向通信

```python
def accumulator():
    total = 0
    while True:
        value = yield total        # 接收外部发送的值
        if value is None:
            break
        total += value

acc = accumulator()
next(acc)              # 启动生成器
print(acc.send(10))    # 10
print(acc.send(5))     # 15
acc.send(None)         # 停止
```

## 3. 生成器表达式与管道

```python
# 生成器管道：前一个的输出 = 后一个的输入（内存恒定）
nums = (x for x in range(1_000_000))             # 生成器 1
evens = (x for x in nums if x % 2 == 0)           # 生成器 2
squared = (x**2 for x in evens)                   # 生成器 3
result = sum(squared)  # 一次遍历全部管道，内存恒定！

# 等同于：
result = sum(x**2 for x in range(1_000_000) if x % 2 == 0)
```

def stream_dataset(dataset, batch_size=32):
    """分批加载，不一次性读入内存"""
    for i in range(0, len(dataset), batch_size):
        yield dataset[i:i + batch_size]

## 核心要点回顾

- 迭代器协议：`__iter__`(返回self) + `__next__`(StopIteration终止)
- `yield` = 暂停+返回值+保存状态，比 return 多了"恢复"能力
- 生成器表达式 `(x for x in ...)` = 惰性求值版列表推导式
- `yield from` 委托子生成器，避免嵌套循环
- AI 三大场景：流式数据加载、流式 LLM 输出、无限数据生成
