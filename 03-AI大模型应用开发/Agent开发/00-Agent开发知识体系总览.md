## 4. 核心概念速查

| 概念 | 一句话解释 |
|------|-----------|
| **Agent** | 感知-规划-行动-记忆闭环的自主系统（≠ 大模型 + API 调用） |
| **P-A-M-E** | Perception-Action-Memory-Planning 四层架构 |
| **ReAct** | 思考→行动→观察循环，最基础的 Agent 模式 |
| **H-V-R** | 2026 新范式：假设→验证→反思（解决 ReAct 无自我纠错） |
| **Function Calling** | 模型输出结构化调用指令，由程序执行 |
| **MCP** | 模型上下文协议，工具调用的行业标准（v2.0） |
| **Guardrails** | 独立小模型守卫：检测恶意指令/提示词泄露/异常调用 |
| **HITL** | Human-in-the-Loop 人机协同：关键决策强制人工审批 |
| **轨迹对齐度** | 执行路径与最优路径的编辑距离，Agent 评估硬指标 |
| **因果链追踪** | 通过 trace_id 查看决策全链路，定位失败根因 |

## 5. 一图看懂：Agent 开发代际变迁

| 维度 | 2024 | 2025 | **2026** |
|------|------|------|---------|
| 范式 | Prompt + 工具调用 | 有状态图控编程 | **系统工程** |
| 代表 | LangChain Chain | LangGraph/AutoGen | Agent 平台 + Harness |
| 致命缺陷 | 无状态、线性、无法干预 | 编排有了，治理缺位 | 治理/评估/安全成为标配 |
| 记忆 | 无 | 有（Checkpointer） | 持久化 + 双写策略 |
| 协作 | 无 | 多 Agent 雏形 | 去中心化共识 |
| 开发模式 | 脚本编排 | 图编程 | **开发 + 评估 + 治理一体化** |
