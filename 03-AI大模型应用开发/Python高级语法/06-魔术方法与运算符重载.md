## 1. 对象表示

```python
class Vector:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __repr__(self):
        return f"Vector({self.x}, {self.y})"  # 给开发者看 (eval 可还原)

    def __str__(self):
        return f"({self.x}, {self.y})"        # 给用户看 (print)

    def __len__(self):
        return 2                               # len(obj)

    def __bool__(self):
        return self.x != 0 or self.y != 0      # if obj:
```

## 2. 运算符重载

```python
    def __add__(self, other):       # self + other
        return Vector(self.x + other.x, self.y + other.y)

    def __sub__(self, other):       # self - other
        return Vector(self.x - other.x, self.y - other.y)

    def __mul__(self, scalar):      # self * scalar
        return Vector(self.x * scalar, self.y * scalar)

    def __eq__(self, other):        # self == other
        return self.x == other.x and self.y == other.y

    def __hash__(self):             # hash(self) → 可放入 set/dict key
        return hash((self.x, self.y))

    def __lt__(self, other):        # self < other
        return self.magnitude() < other.magnitude()

    def __abs__(self):              # abs(self)
        return self.magnitude()
```

## 3. 容器模拟

```python
class PromptTemplate:
    """像 dict 一样使用的 Prompt 管理器"""
    def __init__(self):
        self._slots = {}

    def __getitem__(self, key):          # template["user"]
        return self._slots[key]

    def __setitem__(self, key, value):   # template["user"] = "..."
        self._slots[key] = value

    def __contains__(self, key):         # "user" in template
        return key in self._slots

    def __iter__(self):                  # for k in template:
        return iter(self._slots)
```

## 4. 可调用对象

```python
class ModelInference:
    """让对象可以像函数一样调用"""
    def __init__(self, model, tokenizer):
        self.model = model
        self.tokenizer = tokenizer

    def __call__(self, prompt, **kwargs):
        """model("Hello") → 自动推理"""
        inputs = self.tokenizer(prompt, return_tensors="pt")
        return self.model.generate(**inputs, **kwargs)

# 使用
llm = ModelInference(model, tokenizer)
result = llm("Explain Python")   # 像调用函数一样！
```

### 全量魔术方法速查

| 类别 | 方法 | 触发 |
|------|------|------|
| 表示 | `__repr__` `__str__` `__format__` | `repr()` `str()` `f"{obj}"` |
| 比较 | `__eq__` `__lt__` `__gt__` `__hash__` | `==` `<` `>` `hash()` |
| 算术 | `__add__` `__sub__` `__mul__` | `+` `-` `*` |
| 容器 | `__getitem__` `__setitem__` `__len__` | `obj[k]` `len()` |
| 调用 | `__call__` | `obj()` |
| 上下文 | `__enter__` `__exit__` | `with obj:` |
| 迭代 | `__iter__` `__next__` | `for x in obj` |

## 核心要点回顾

- `__repr__` = 开发者视角（调试），`__str__` = 用户视角
- `__call__` = 对象变函数（AI 模型推理的最佳模式）
- 运算符重载谨慎用——遵守直觉，不要重载成反直觉行为
- 容器模拟(= dict 风格 API)比普通方法调用更 Pythonic
