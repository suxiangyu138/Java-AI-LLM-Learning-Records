## 1. 描述符协议

```python
# 描述符 = 实现了 __get__ / __set__ / __delete__ 的类
class Descriptor:
    def __get__(self, instance, owner):
        """读取属性时调用: instance.attr"""
        pass

    def __set__(self, instance, value):
        """设置属性时调用: instance.attr = value"""
        pass

    def __delete__(self, instance):
        """删除属性时调用: del instance.attr"""
        pass

# 关键：描述符必须作为类属性（不是实例属性）
class MyClass:
    attr = Descriptor()     # ✅ 类属性，描述符生效
```

## 2. @property 源码揭秘

```python
# @property 的底层就是一个描述符类！
class Property:
    def __init__(self, fget=None, fset=None, fdel=None):
        self.fget = fget
        self.fset = fset
        self.fdel = fdel

    def __get__(self, instance, owner):
        if instance is None: return self
        return self.fget(instance)

    def __set__(self, instance, value):
        if self.fset is None:
            raise AttributeError("can't set attribute")
        self.fset(instance, value)

    def setter(self, fset):
        self.fset = fset
        return self

# 所以 @property 的标准用法本质是描述符！
```

## 3. 实战：类型校验器

```python
class Typed:
    """属性类型校验描述符"""
    def __init__(self, name, expected_type):
        self.name = name
        self.expected_type = expected_type

    def __get__(self, instance, owner):
        if instance is None: return self
        return instance.__dict__.get(self.name)

    def __set__(self, instance, value):
        if not isinstance(value, self.expected_type):
            raise TypeError(f"{self.name} 期望 {self.expected_type}, 得到 {type(value)}")
        instance.__dict__[self.name] = value

class Person:
    name = Typed("name", str)     # 描述符作为类属性
    age = Typed("age", int)

    def __init__(self, name, age):
        self.name = name           # → Typed.__set__()
        self.age = age

Person("Alice", 25)               # ✅
Person("Bob", "25")               # ❌ TypeError: age 期望 int
```

class ModelConfig:

class LlamaConfig(BaseModel):

## 核心要点回顾

- 描述符协议：`__get__`(读) / `__set__`(写) / `__delete__`(删)
- `@property` = 描述符的语法糖
- 描述符必须是**类属性**（实例属性不触发协议）
- 应用：ORM字段、类型校验、延迟加载、缓存属性
