## 1. API 安全加固

### 1.1 Ollama 鉴权方案

```text
Ollama 默认无鉴权 ⚠️ 任何人可调用

方案一：反向代理 + API Key (推荐)
方案二：防火墙 IP 白名单
方案三：内网部署 + VPN
```

#### Nginx 反向代理 + API Key

```nginx
# nginx.conf
server {
    listen 443 ssl;
    server_name ai.internal.com;

    ssl_certificate     /etc/nginx/certs/server.crt;
    ssl_certificate_key /etc/nginx/certs/server.key;

    location / {
        # API Key 校验
        if ($http_x_api_key != "sk-your-secret-key-here") {
            return 401 '{"error": "Unauthorized"}';
        }

        proxy_pass http://127.0.0.1:11434;
        proxy_set_header Host $host;
        proxy_read_timeout 300s;

        # 限流：每 IP 每分钟 60 次
        limit_req zone=api_limit burst=20 nodelay;
    }
}

limit_req_zone $binary_remote_addr zone=api_limit:10m rate=60r/m;
```

### 1.2 Java 客户端安全调用

```java
@Configuration
public class SecureOllamaConfig {

    @Bean
    public RestClient secureOllamaClient(
        @Value("${ollama.api-key}") String apiKey,
        @Value("${ollama.base-url}") String baseUrl
    ) {
        return RestClient.builder()
            .baseUrl(baseUrl)
            .defaultHeader("X-API-Key", apiKey)  // 每次请求携带
            .defaultHeader("User-Agent", "MyApp/1.0")
            .requestInterceptor((req, body, exec) -> {
                // 请求日志（不记录 body，可能含敏感信息）
                log.info("Ollama API: {} {}", req.getMethod(), req.getURI());
                return exec.execute(req, body);
            })
            .build();
    }
}
```

## 2. 网络安全

### 2.1 防火墙规则

```bash
# UFW (Ubuntu)
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow from 192.168.1.0/24 to any port 11434  # 仅内网
sudo ufw enable

# iptables
iptables -A INPUT -p tcp --dport 11434 -s 192.168.1.0/24 -j ACCEPT
iptables -A INPUT -p tcp --dport 11434 -j DROP
```

### 2.2 Docker 网络隔离

```yaml
# docker-compose.yml — 仅暴露必要端口
services:
  ollama:
    image: ollama/ollama
    ports:
      - "127.0.0.1:11434:11434"   # ← 仅绑定 localhost
    networks:
      - ai_network

  nginx:
    image: nginx:alpine
    ports:
      - "443:443"                   # ← 对外只暴露 Nginx
    networks:
      - ai_network
    volumes:
      - ./nginx.conf:/etc/nginx/nginx.conf

networks:
  ai_network:
    driver: bridge
    internal: false
```

### 3.2 请求审计中间件

```python
# Flask/FastAPI 审计中间件
import time, json, logging

class AuditMiddleware:
    def __init__(self, app):
        self.app = app

    async def __call__(self, scope, receive, send):
        start = time.time()
        path = scope.get("path", "")
        client = scope.get("client", ("unknown", 0))[0]

        # 记录请求
        logger.info(json.dumps({
            "type": "request",
            "client": client,
            "path": path,
            "time": start
        }))

        async def send_wrapper(message):
            if message["type"] == "http.response.start":
                status = message["status"]
                elapsed = time.time() - start
                logger.info(json.dumps({
                    "type": "response",
                    "client": client,
                    "path": path,
                    "status": status,
                    "elapsed_ms": round(elapsed * 1000)
                }))
            await send(message)

        await self.app(scope, receive, send_wrapper)
```

### 4.2 自定义健康监控脚本

```python
#!/usr/bin/env python3
"""Ollama 健康检查 + 告警"""

import requests, time, smtplib
from email.mime.text import MIMEText

OLLAMA_URL = "http://localhost:11434"
CHECK_INTERVAL = 60  # 秒
ALERT_THRESHOLD = 3  # 连续失败次数

failures = 0

def check_health():
    try:
        # 1. 服务存活
        resp = requests.get(f"{OLLAMA_URL}/", timeout=5)
        if resp.status_code != 200:
            return False

        # 2. 模型加载状态
        resp = requests.get(f"{OLLAMA_URL}/api/tags", timeout=5)
        models = resp.json().get("models", [])
        if not models:
            return False

        # 3. 推理测试
        resp = requests.post(
            f"{OLLAMA_URL}/api/generate",
            json={"model": models[0]["name"], "prompt": "ping"},
            timeout=30
        )
        return resp.status_code == 200

    except requests.RequestException:
        return False

def send_alert(message):
    msg = MIMEText(message)
    msg["Subject"] = "⚠️ Ollama Service Alert"
    msg["From"] = "monitor@company.com"
    msg["To"] = "admin@company.com"

    with smtplib.SMTP("smtp.company.com") as server:
        server.send_message(msg)

while True:
    if check_health():
        failures = 0
    else:
        failures += 1
        if failures >= ALERT_THRESHOLD:
            send_alert(f"Ollama service DOWN for {failures} consecutive checks!")
            # 尝试自动重启
            import subprocess
            subprocess.run(["docker", "restart", "ollama"])

    time.sleep(CHECK_INTERVAL)
```

### 4.3 关键监控指标

| 指标 | 来源 | 告警阈值 |
|------|------|:---:|
| **服务存活** | HTTP GET `/` | 连续 3 次失败 |
| **模型就绪** | GET `/api/tags` | 无模型 > 5 min |
| **GPU 利用率** | `nvidia-smi` | > 95% 持续 30 min |
| **GPU 显存** | `nvidia-smi` | > 90% |
| **API 延迟 P95** | Nginx 日志 | > 5s |
| **API 错误率** | Nginx 日志 | > 5% |
| **磁盘使用率** | `df -h` | > 80% |
| **模型下载** | `/api/pull` 日志 | 下载速度 < 1MB/s |

## 5. 备份与恢复

```bash
# 1. 备份 Ollama 模型和配置
tar -czf ollama-backup-$(date +%Y%m%d).tar.gz \
  ~/.ollama/models/ \
  ~/.ollama/history \
  *.Modelfile \
  docker-compose.yml

# 2. 备份到远程
rsync -avz ollama-backup-*.tar.gz backup-server:/backups/ollama/

# 3. 恢复
tar -xzf ollama-backup-20260727.tar.gz -C ~/
ollama list  # 验证模型恢复

# 4. 自动备份 cron
# 0 2 * * * /home/user/backup-ollama.sh
```

## 核心要点回顾

- Ollama 默认无鉴权 → Nginx 反向代理 + API Key + HTTPS
- 网络：防火墙白名单 + 仅绑定 127.0.0.1 + Docker 内网隔离
- 审计：记录请求时间/来源/路径/状态码/耗时
- 监控：存活 + 模型就绪 + GPU + 延迟 + 错误率 + 磁盘
- 告警：连续 3 次失败 → 邮件 + 自动重启
- 备份：定期备份 models/ + Modelfile + compose 文件
