# 多模态微调的常见问题

> 多模态微调特有的失败：融合破坏（第一风险）、感知退化、对齐漂移、灾难性遗忘多模态版、模态失衡——"多模态微调的第一风险不是没提升，是破坏已有能力"

## 1. 融合破坏：多模态微调的第一风险

**视觉-语言融合破坏**：微调后模型"看图的能力"退化——**"大多数多模态模型的编码微调会破坏预训练学到的视觉-语言融合"**（2026 实证）——症状：**图像描述质量下降**（看图答得泛泛/答非所问）、**视觉定位退化**（"指出来"变差）、**跨模态引用错乱**（`多模态/多模态常见问题与缺陷/06-跨模态对齐与语言先验.md` 的对齐问题在微调后被放大）。

**机制**：视觉-语言融合主要编码在语言塔的**下半层**（视觉特征注入的早期层）——微调全层语言塔时，下半层被任务数据改写 → 融合路径被破坏（03 篇的层选择性 LoRA 由此而来）。

**检测**：**融合能力回测**——微调前后跑同一组"纯视觉理解"任务（图像描述质量/定位/跨模态引用——与底座逐位对比——**gemma4-31B 实证的"图像描述质量逐位一致"是融合零破坏的检验标准**）；**检测时机**：每轮微调后必跑（不是验收时才跑——融合破坏在训练中就能发现，`大模型微调知识体系/完整微调工程流程/07-训练过程监控与干预.md` 的监控纪律）。

**缓解**：**层选择性 LoRA**（下半层冻结——编码类微调的默认选项，03 篇）；**低 lr**（保护已有能力——2e-5 量级）；**通用数据混入**（微调数据混入通用图文数据保持对齐能力——`多模态/多模态数据集/02-图文对数据.md` 的"对齐保持剂"）；**融合回测进门禁**（09 篇的验收含融合维度）。

## 2. 感知退化与对齐漂移

**感知退化**：微调后模型的感知能力下降（计数更差/小物体更看不清）——与融合破坏相关但独立（感知在视觉塔、融合在语言塔下半层）——机制：**训练数据偏斜**（指令数据以"行为"为主，感知任务样本少——模型把容量花在行为上，感知被"挤出"——`大模型微调知识体系/基础概念/06-训练循环Epoch-Batch-Step.md` 的容量竞争）——**检测**：感知专项回测（HoloCount 类计数/小物体——`多模态/多模态常见问题与缺陷/02-视觉感知缺陷.md`）——**缓解**：数据平衡（指令数据混入感知类样本——计数/定位类指令——`多模态/多模态数据集/03-多模态指令数据.md` 的配比调整）。

**对齐漂移**：微调后图文对齐能力下降（`多模态/多模态常见问题与缺陷/06-跨模态对齐与语言先验.md`）——机制：**对齐依赖的投影层/语言塔被行为数据改写**——检测：对齐专项测试（图文矛盾/引用准确性——06 篇的评估）——缓解：**投影层低 lr 或冻结**（对齐敏感任务）、图文对混入（保持剂）。

## 3. 灾难性遗忘的多模态版

**多模态的灾难性遗忘**（`大模型微调知识体系/基础概念/09-评估基础损失曲线与过拟合.md` 03 节的多模态版）——三种形态：

**语言能力遗忘**（同文本）：微调后通用语言能力退化（`大模型微调知识体系/微调常见问题/05-训练问题过拟合遗忘与震荡.md` 的通用回测）——多模态微调的遗忘检测要**加模态维度**；**视觉能力遗忘**：微调后视觉理解退化（感知退化的一部分——看图能力回测）；**多模态能力遗忘**：图文联合能力退化（融合破坏——跨模态回测）——**"多模态遗忘 = 三通道回测"**（语言/视觉/跨模态各测一组——缺一个就是残缺评估）。

**缓解**（与文本同构 + 多模态版）：低 epoch（1-2）、通用数据混入（图文对 + 通用指令）、低 lr、LoRA（冻塔天然保护视觉能力——**多模态微调用 LoRA 的额外理由：保护视觉塔**）。

## 4. 模态失衡

**模态失衡**：训练数据/训练过程中模态间的不平衡——两类：

**数据失衡**：训练数据以文本为主、图像样本少（指令数据里"看图"问题占比低）——模型"变成文本模型"（视觉能力闲置——`多模态/多模态数据集/03-多模态指令数据.md` 的配比——**指令数据的视觉样本占比要监控**）；**训练失衡**：batch 里图像样本与文本样本的比例（模态长度分组采样——04 篇——也解决失衡：图像样本独立 batch 保证每步都"看到图"）。

**检测**：数据配比统计（视觉样本占比）；模态专项评估（纯视觉任务 vs 纯文本任务 vs 跨模态任务的分数对比——**"文本分高、视觉分低" = 模态失衡**）。**缓解**：数据配比调整（视觉样本占比升）、采样策略（保证每步有图像）。

## 5. 多模态过拟合与幻觉放大

**多模态过拟合**（与文本同构——训练 loss 降但验证背离——`大模型微调知识体系/基础概念/09-评估基础损失曲线与过拟合.md` 02 节）——**多模态的过拟合信号**：训练样本的"看图回答"被背下来（复读训练图的描述）——**背题的多模态形态：图到文的记忆**（见过这张图就背出训练答案——`大模型微调知识体系/微调常见问题/05-训练问题过拟合遗忘与震荡.md` 的复读探测多模态版：用训练图测试）。

**幻觉放大**：微调数据含幻觉（`多模态/多模态数据集/03-多模态指令数据.md` 的幻觉污染）→ 模型幻觉变本加厉——**"微调是幻觉的放大器"**（数据里的幻觉被权重固化）——**数据质量是微调幻觉的第一防线**（`多模态/多模态数据集/03-多模态指令数据.md` 的生产五查）——缓解：数据过滤 + 引用强制提示 + 幻觉专项评估（`多模态/多模态常见问题与缺陷/03-视觉幻觉.md`）。

## 6. 排查方法论

多模态微调问题的排查（`大模型微调知识体系/微调常见问题/01-问题全景与排查方法论.md` 的多模态版）：**三通道定位**（语言/视觉/跨模态各测一组——问题在哪个通道）；**组件消融**（换冻结策略对比——
"放开视觉塔后视觉变好 = 之前塔冻结的限制"）；**数据消融**（数据配比/质量的调整对比）；**基线对比**（与底座/微调前对比——"变差"是微调引入的——**"微调前的基线回测是排查的锚"**（`大模型微调知识体系/完整微调工程流程/03-评估先行基线建立.md` 的 eval-first 在多模态的落地——**多模态微调尤其要 eval-first**：融合/感知/对齐三条基线先测，微调后对比）。

> 🎯 **核心要点**：融合破坏是第一风险（编码微调破坏视觉-语言融合——下半层冻结是解法——"图像描述逐位一致"是零破坏标准——每轮微调后必跑融合回测）；感知退化与对齐漂移（数据偏斜挤出感知/投影层被改写——感知专项回测 + 对齐测试 + 数据平衡）；灾难性遗忘三形态（语言/视觉/跨模态——三通道回测缺一不可——LoRA 冻塔是保护视觉的额外理由）；模态失衡（数据配比 + 采样保证每步有图——模态专项分数对比检测）；多模态过拟合（图到文背题）+ 幻觉放大（微调是幻觉放大器——数据质量第一防线）；排查——三通道定位 + 组件消融 + 数据消融 + 基线回测（eval-first 在多模态尤其重要：融合/感知/对齐三基线先测）。
