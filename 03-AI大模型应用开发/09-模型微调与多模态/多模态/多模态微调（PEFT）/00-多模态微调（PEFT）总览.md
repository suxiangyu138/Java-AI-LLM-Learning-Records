## 3. 为什么必须学透多模态微调

1. **多模态微调与文本微调有本质差异**：VLM 有三个组件（视觉塔/投影层/语言塔）——"微调哪里"的选择比文本模型复杂得多——**默认"冻视觉塔 + LoRA 语言塔"（0.1-0.6% 可训练参数）**，但 2026 出现两个新方向（层选择性 LoRA 保护多模态融合、塔/连接器 LoRA 适配专门视觉域）——本体系 02/03 篇给完整地图。
2. **配方有成熟的两阶段范式**：LLaVA 类两阶段（对齐 1e-3 → SFT 2e-5——**阶段间学习率差 50 倍**）、LLaVA-NeXT 三阶段（+DPO）——**多模态微调是"配方科学"**（阶段/冻结/学习率的组合），本体系 04 篇给全套。
3. **多模态微调最容易破坏"多模态融合"**：**"大多数多模态模型的编码微调会破坏预训练学到的视觉-语言融合"**（2026 实证：冻结下半层堆栈保融合、编码 pass@1 +15.9 点且图像描述质量逐位不变）——**多模态微调的第一风险不是"没提升"是"破坏已有能力"**（06 篇）。
4. **多模态 DPO 是 2026 对齐主流**：LLaVA-RLHF/RLAIF-V/VLFeedback 三类偏好数据、DPO 显著改善幻觉基准（POPE）、Omni-Reward 全模态奖励建模——**"对齐从 RLHF 走向 DPO、从人类反馈走向 AI 反馈"**（07 篇）。
5. **与微调知识体系互补**：`大模型微调知识体系/PEFT 参数高效微调（面试高频）/` 讲 LoRA 原理（本体系假设已懂），本体系讲"LoRA 在 VLM 上的特殊用法"——**先懂通用 PEFT 再学多模态版**。

## 4. 核心概念速查

### 4.1 核心概念

| 概念 | 一句话 | 关键数字 |
|------|--------|---------|
| 三组件 | 视觉塔/投影层/语言塔 | 冻结策略按组件定 |
| 默认配方 | 冻视觉塔 + LoRA 语言塔 | 0.1-0.6% 可训练 |
| 两阶段 | 对齐（只训投影）→ SFT | lr 1e-3 → 2e-5 |
| 层选择性 LoRA | 只微调上半层栈 | 0.20% 参数、编码 +15.9 |
| 塔 LoRA | 视觉塔也训（专门视觉域） | 显微镜 0.58% |
| 模态长度分组 | 图像/文本样本分 batch | 减少 padding 浪费 |
| 投影层 lr | mm_projector_lr 独立 | 四组优化器参数 |
| 多模态 DPO | 偏好对齐 | POPE 幻觉显著改善 |
| 感知退化 | 微调后视觉能力下降 | 冻结消融 38.2 vs 56.8 |
| VLA | 视觉-语言-动作微调 | ICLR 2026 |

### 4.2 冻结策略消融（LLaVA-1.6，MM-Bench）

| 配置 | 可训练参数 | 准确率 |
|------|:---:|:---:|
| 全冻 + 只训投影 | ~7M | 38.2 |
| 冻视觉塔 + LoRA 语言塔 | 64M | 56.8 |
| 视觉塔放开 + LoRA 语言塔 | 124M | 58.4 |
| 全量微调 | 7.5B | 60.1 |

### 4.3 常见误区速查

- "微调视觉塔一定更好" → 错：默认冻视觉塔（破坏对齐/浪费适配器），专门视觉域才训
- "一个 lr 走全程" → 错：两阶段 lr 差 50 倍（对齐 1e-3 / SFT 2e-5）
- "编码微调不伤多模态" → 错：会破坏视觉-语言融合（下半层冻结是 2026 解法）
- "多模态微调 = 文本微调 + 图" → 错：三组件/模态长度分组/投影层 lr 都是多模态特有

## 6. 学习路线推荐

**路线一：面试速成（半天，对应模块 01-04 + 10）**
全景 → 结构 → LoRA 应用 → 配方 → 面试题；掌握"三组件冻结策略 + 两阶段配方 + 0.1-0.6%"三大考点。

**路线二：工程入门（1-2 天，对应模块 02-05 + 08）**
结构 → LoRA → 配方 → 类型 → 工程；配合一次 QLoRA 视觉指令微调实践。

**路线三：对齐与生产（对应模块 07 + 09 + 06）**
DPO → 评估 → 常见问题；面向生产对齐与质量保障。

> 🎯 **核心要点**：多模态微调的学习终点 = "**懂结构**（三组件——视觉塔/投影层/语言塔）、**懂默认**（冻视觉塔 + LoRA 语言塔 0.1-0.6%）、**懂新趋势**（层选择性 LoRA 保融合/塔 LoRA 适配视觉域）、**懂配方**（两阶段 1e-3→2e-5/三阶段+DPO）、**懂对齐**（多模态 DPO 与偏好数据）、**懂工程**（显存/分组采样/部署）、**懂评估**（能力+缺陷双评估）"——七件事覆盖多模态微调全貌；记住"**多模态微调的第一风险是破坏已有的视觉-语言融合**"——保护融合比追求提升更重要。
