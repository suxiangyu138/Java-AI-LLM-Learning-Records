# 多模态微调的类型

> 按任务类型分类的多模态微调全景：视觉指令微调（LLaVA 类）、文档理解/OCR、音频/视频微调、VLA 具身微调（2026 前沿）——"任务类型决定组件与配方"

## 1. 视觉指令微调（主流）

**视觉指令微调（Visual Instruction Tuning）**：让 VLM 学会"按指令看图回答"——LLaVA 类——**多模态微调的基本盘**（配方见 04 篇）。

**适用**：通用视觉对话（看图问答/描述/推理）、垂直领域的视觉行为校准（客服看图回答产品问题、医疗影像描述格式）——**数据**（`多模态/多模态数据集/03-多模态指令数据.md` 的 LLaVA 三类）；**组件**（默认冻塔 + LoRA 语言塔——通用任务的默认档）；**关键**：数据质量（对齐/幻觉——`多模态/多模态数据集/03-多模态指令数据.md` 的生产五查）与评估（能力 + 缺陷双评估，09 篇）。

## 2. 文档理解与 OCR 微调

**文档理解微调**：让 VLM 擅长文档任务（OCR/版面/表格/图表）——**领域视觉的典型**——组件选择：**文档任务的感知依赖高**（细粒度文字/表格——`多模态/多模态常见问题与缺陷/04-OCR与文档理解缺陷.md` 的字形感知弱）——**塔 LoRA 或高分辨率输入**是选项（03 篇的"专门视觉域训塔"——文档是典型专门视觉域）。

**数据**：文档数据集（版面标注/表格标注/图文关系标注——`多模态/多模态数据集/07-数据格式与处理.md` 04 节的结构化标注）；**配方特化**：**高分辨率训练**（文档细节——分辨率预处理，`多模态/多模态数据集/07-数据格式与处理.md` 01 节）；**OCR 专项评估**（数字/日期抽验——`多模态/多模态常见问题与缺陷/04-OCR与文档理解缺陷.md` 05 节——**文档微调的验收是"数字必对"**）。

**与 RAG 的分工**：文档问答的**知识部分**（"合同第 3 页写了什么"）归多模态 RAG（`多模态/多模态 RAG/`）——文档微调管**行为部分**（"按公司格式输出提取结果"）——**"检索归 RAG、格式归微调"**（01 篇的边界在文档场景的落地）。

## 3. 音频与视频微调

**音频微调**：让 VLM（音频版）擅长音频任务（语音理解/音频事件/音乐理解）——**数据**（`多模态/多模态数据集/04-视频与音频数据集.md` 的音频文本——转写形态）；**组件**（音频编码器 + 投影 + 语言塔的三组件同构——音频塔默认冻结）；**配方**（与视觉微调同构——对齐阶段 + 指令阶段）。

**视频微调**：让模型理解视频（时序理解/视频问答）——**数据**（视频-文本对——`多模态/多模态数据集/04-视频与音频数据集.md` 的时间对齐）；**配方特化**：**帧采样策略进配方**（训练帧数与推理一致——`多模态/多模态数据集/07-数据格式与处理.md` 02 节——"训练 8 帧推理 32 帧"错配）；**时间对齐评估**（时序类任务的专项指标——`多模态/多模态常见问题与缺陷/07-上下文与工程缺陷.md` 的视频缺口）。

## 4. VLA 具身微调（2026 前沿）

**VLA（Vision-Language-Action）微调**：让 VLM 输出动作指令（机器人/具身智能）——**2026 前沿**——**InstructVLA（ICLR 2026）的 VLA-IT**：联合优化具身推理与动作生成——标准 VLM 语料 + 65 万样本 VLA-IT 数据集 + **MoE 适配**——SimplerEnv 上比 SpatialVLA 提升 33.3% 且保持 VLM 推理能力。

**VLA 的微调特征**：**动作空间是新的输出形态**（动作 token——语言塔输出扩展）；**数据**（视觉-语言-动作三元组——动作标注是核心成本）；**评估**（具身模拟器 + 真实环境——`多模态/多模态常见问题与缺陷/` 的缺陷评估在具身场景的放大——**感知错误的代价是物理动作错误**）。

## 5. 领域视觉微调

**领域视觉微调**（医学/显微镜/遥感/工业检测）：垂直领域的视觉行为校准——**塔 LoRA 的主场**（03 篇：专门视觉域的感知需求超出通用塔——MicroLens 显微镜实证）——**配方要点**：**感知验证先行**（底座在领域任务上的感知表现——`多模态/多模态常见问题与缺陷/01-问题全景与诊断方法论.md` 的感知验证——"底座看不清 → 塔 LoRA 或换底座"）；**数据**（领域图文对 + 领域指令数据——`多模态/多模态数据集/` 的领域数据构建）；**评估**（领域专项基准——`多模态/多模态常见问题与缺陷/09-评估与缺陷检测.md` 的缺陷画像）。

**领域微调的"安全敏感"**：医学/法律类领域的错误代价高——**幻觉专项评估必做**（`多模态/多模态常见问题与缺陷/03-视觉幻觉.md` 的幻觉率是独立维度——领域微调的验收比通用更严）。

## 6. 类型选型总结

| 任务类型 | 组件 | 配方特化 | 关键评估 |
|---------|------|---------|---------|
| 视觉指令（通用） | 默认（冻塔 + LoRA） | 标准两阶段 | 能力 + 缺陷 |
| 文档/OCR | 考虑塔 LoRA + 高分辨率 | 分辨率预处理 | 数字必对 |
| 音频 | 音频塔冻结 | 转写数据 | WER 相关 |
| 视频 | 视频塔冻结 | 帧采样一致 | 时序对齐 |
| VLA 具身 | 语言塔 + 动作扩展 | MoE 适配 | 模拟器 + 物理 |
| 领域视觉 | 塔 LoRA 主场 | 感知验证先行 | 领域专项 + 幻觉 |

**共性**：**"任务类型 → 组件选择 → 配方特化 → 评估特化"四步**是类型选型的主线——每种类型的差异都在"感知需求"（要不要训塔）与"输出形态"（要不要扩展输出）。

**类型的"需求-方案"映射速查**：**看图说话** → 视觉指令（默认配方）；**看文档出结构** → 文档 OCR（塔 LoRA + 高分辨率 + 数字校验）；**听音转写理解** → 音频（转写数据 + WER 评估）；**看视频答问题** → 视频（帧采样一致 + 时序评估）；**看环境做动作** → VLA（动作扩展——前沿）；**看医学图出报告** → 领域视觉（塔 LoRA + 幻觉必评）——**"一个需求对应一个配方模板"**（模板是起点、任务验证是终点——`大模型微调知识体系/训练关键超参 & 显存优化技术/01-超参全景与调参方法论.md` 的复验纪律）。

> 🎯 **核心要点**：六种类型——视觉指令（主流，默认配方）/文档 OCR（塔 LoRA 候选 + 高分辨率 + 数字必对——检索归 RAG 格式归微调）/音频（塔冻转写数据）/视频（帧采样一致 + 时序评估）/VLA 具身（动作输出扩展 + MoE——2026 前沿 ICLR）/领域视觉（塔 LoRA 主场 + 感知验证先行 + 安全敏感幻觉必评）；共性主线——"任务类型 → 组件选择 → 配方特化 → 评估特化"四步——差异在感知需求（要不要训塔）与输出形态（要不要扩展）；领域微调的安全敏感——错误代价高的领域幻觉专项评估必做。
