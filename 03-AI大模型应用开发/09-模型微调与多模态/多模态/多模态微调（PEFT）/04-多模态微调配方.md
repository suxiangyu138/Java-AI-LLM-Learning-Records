# 多模态微调配方

> 多模态微调的"菜谱"：LLaVA 两阶段（对齐 1e-3 → SFT 2e-5——阶段间 lr 差 50 倍）、LLaVA-NeXT 三阶段（+DPO）、冻结消融数据、模态长度分组采样——配方是"阶段 × 冻结 × 学习率"的组合科学

## 1. 两阶段配方：LLaVA 范式

多模态微调的标准配方（LLaVA 类，2026 仍是基准）：

**阶段一：特征对齐预训练（Vision-Language Alignment）**——**只训 MLP 投影层**（~20M 参数），语言塔与视觉塔冻结——数据：55.8 万图文对（LAION-CC-SBU/CC3M 子集——`多模态/多模态数据集/02-图文对数据.md` 的图文对）——**lr 1e-3**（高——投影层从零学对齐，大步快跑）、cosine、batch 32、ZeRO-2、8×A100 约 12-20 小时——产出 `mm_projector.bin`（阶段二加载）。

**阶段二：视觉指令微调（SFT）**——**放开语言塔**（与投影层联合训练），视觉塔冻结——数据：66.5 万指令样本（llava_v1_5_mix665k）——**lr 2e-5**（低——保护既有语言能力，`大模型微调知识体系/基础概念/05-优化器与梯度更新.md` 的"底座已收敛"逻辑）、batch 16、ZeRO-3、**1 epoch**、cosine + 0.03 warmup、bf16——loss 只算 assistant token（user 掩码 -100，`大模型微调知识体系/基础概念/04-损失函数与训练目标.md`）。

**阶段间 lr 差 50 倍的原因**：阶段一投影层从零学（大 lr 快收敛）；阶段二语言塔已有能力（小 lr 保护——**"同一个模型的两个阶段，学习率是两个世界"**——多模态微调配方的第一要点。

**两阶段可以合并吗**：**可以（简化配方）**——如果底座已有对齐好的投影层（新模型自带 mm_projector——`多模态/LLaVA 类多模态大模型核心架构（面试必背）/` 的现代 VLM 出厂即对齐），**跳过阶段一**直接 SFT（加载底座自带的投影层）——**"阶段一只在自建模型/换投影层时需要"**——用现成底座做微调时（企业常态），两阶段简化为"单阶段 SFT"（4 篇配方的工程简化——省 12-20 小时对齐训练）；**阶段一仍需要的场景**：自定义视觉塔（换编码器）、自定义投影层、从头组装的 VLM——**"阶段的选择由底座的对齐状态决定"**。

## 2. 三阶段配方：LLaVA-NeXT（+DPO）

**LLaVA-NeXT 三阶段**：预训练对齐（55.8 万图文对）→ 指令微调（100 万+ 指令数据）→ **DPO 偏好对齐**（偏好数据——`07-多模态偏好对齐DPO.md`）——**2026 多模态对齐的"预训练 → SFT → DPO"三阶段模式**（与文本对齐流水线同构——`大模型微调知识体系/基础概念/02-大模型训练三阶段范式.md` 的多模态版）。

**三阶段 lr 配置参考**（LLaVA-NeXT）：pretrain_lr 1e-4、finetune_lr 5e-5、rl_lr 1e-6、warmup 2000 步、cosine——**lr 逐阶段递减（1e-4 → 5e-5 → 1e-6）**——"越靠近行为校准，步长越小"——与文本微调的两阶段 lr 逻辑一致（`大模型微调知识体系/基础概念/02-大模型训练三阶段范式.md` 的 SFT→DPO lr 递减）。

## 3. 冻结策略的配方地位

冻结策略是配方的核心变量（02 篇的组件选择在配方中的落地）：

**冻结消融数据**（LLaVA-1.6，MM-Bench，00 篇速查）：全冻只训投影 38.2 / **冻视觉塔 + LoRA 语言塔 56.8（默认）** / 视觉塔放开 58.4 / 全量 60.1——**配方的默认档**："冻视觉塔 + LoRA 语言塔 + 投影层可训 + lr 2e-5 + 1 epoch"。

**教程级建议**：**小数据（<1M）冻语言塔**（只训投影或浅 LoRA——小数据全量语言塔过拟合）；**连接器类型（MLP/transformer/linear）显著影响性能**（配方里连接器不是细节）；**QLoRA 配方**（`大模型微调知识体系/PEFT 参数高效微调（面试高频）/06-QLoRA深潜.md` 的多模态版——4bit 底座 + LoRA——**视觉塔量化注意**（03 篇 05 节））。

## 4. 模态长度分组采样

**LLaVATrainer 的配方特化**：**模态长度分组采样（modality-length-grouped sampling）**——把**图像样本与纯文本样本分成不同 batch**（而不是混批）——**理由**：图像样本的序列长度差异大（图像 token 数百到上千，`多模态/多模态常见问题与缺陷/07-上下文与工程缺陷.md` 的 token 账本）——混批的 padding 浪费严重（图像样本和文本样本拼一个 batch，短的被 pad 到长的）——**分批减少 padding 浪费、提升训练效率**（`大模型微调知识体系/基础概念/06-训练循环Epoch-Batch-Step.md` 06 节的 packing 思想多模态版）。

**投影层独立学习率**：`mm_projector_lr`——**四组优化器参数组**（语言塔 lr / 投影层 lr / 视觉塔（若训）lr / 权重衰减）——**"不同组件不同 lr"是配方的高级形态**（投影层可以比语言塔学得快——对齐校准不需要保护已有能力）。

## 5. 配方参数的完整清单

多模态微调配方参数（生产参考）：**阶段**（两阶段 SFT / 三阶段 +DPO）；**冻结**（塔冻/塔训/层选择性）；**lr**（SFT 2e-5、对齐 1e-3、DPO 1e-6——按阶段）；
**epoch**（1-2——SFT 惯例，`大模型微调知识体系/训练关键超参 & 显存优化技术/04-Epoch与早停.md`）；**batch**（16-32 + 梯度累积）；**调度**（cosine + warmup 0.03）；**精度**（bf16——VLM 训练的默认，`大模型微调知识体系/完整微调工程流程/06-训练配置与启动.md`）；**采样**（模态长度分组）；**评估**（每阶段的门禁——09 篇）。

**配方的"迁移纪律"**：抄配方必须带验证集复验（`大模型微调知识体系/训练关键超参 & 显存优化技术/01-超参全景与调参方法论.md` 的"默认值是起点不是终点"——多模态配方的组合空间更大（阶段 × 冻结 × lr），**复验更重要**）。

**配方与数据规模的关系**：配方参数不是固定的——**数据量决定配方档位**——小数据（<10 万条）：冻语言塔/浅 LoRA + 1 epoch（防过拟合）；中数据（10-100 万）：默认档（LoRA 语言塔 + 1-2 epoch）；大数据（100 万+）：可放开更多（训塔/多 epoch/全量微调候选）——**"配方的档位与数据量联动"**（`大模型微调知识体系/边界判断（非常关键，面试必问）/07-数据量与质量阈值判断.md` 的阈值思想多模态版——先定数据档位再选配方档位）。

## 6. 配方的调参顺序

多模态配方调参的分层顺序（`大模型微调知识体系/训练关键超参 & 显存优化技术/01-超参全景与调参方法论.md` 的多模态版）：**1) 定阶段**（要不要 DPO——按需求）；**2) 定冻结**（默认档起步——
塔冻 + LoRA 语言塔；按任务调整）；**3) 调 lr**（SFT 2e-5 起步——最影响质量）；**4) 调 LoRA r/α**（r=8 起步）；**5) 精调**（投影层 lr/epoch/warmup）——**"先结构后参数"**（组件的选择比 lr 的微调影响更大——消融数据：冻结策略的差距（38 vs 57）远大于 lr 微调的差距）。

> 🎯 **核心要点**：两阶段配方——对齐（只训投影 1e-3 高 lr）→ SFT（语言塔放开 2e-5 低 lr）——**阶段间 lr 差 50 倍是配方第一要点**（从零学 vs 保护已有）；三阶段（+DPO）——lr 逐阶段递减（1e-4 → 5e-5 → 1e-6）；冻结消融——LoRA 语言塔 56.8 是默认档（vs 全量 60.1）、小数据冻语言塔、连接器类型影响性能；模态长度分组采样（图像/文本分 batch 减 padding）+ 投影层独立 lr（四组优化器参数）——多模态配方特化；完整清单（阶段/冻结/lr/epoch/batch/精度/采样/评估）；调参顺序——先结构（冻结策略）后参数（lr）——"组件的选择比 lr 微调影响更大"。
