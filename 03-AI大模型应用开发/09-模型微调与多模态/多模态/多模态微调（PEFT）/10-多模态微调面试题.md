# 多模态微调面试题

> 面试考点："VLM 微调和文本微调的区别、三组件怎么冻、两阶段配方、多模态 DPO、微调后视觉变差怎么办"——每题带 2026 实证，背熟即得分

## 1. 必问基础 8 题

### Q1：多模态微调与文本微调的根本区别？

**答案**：对象不同——文本模型只有语言塔，VLM 是**三组件系统**（视觉塔/投影层/语言塔）——"微调哪里"多了一层选择：**视觉塔管感知、投影层管对齐、语言塔管行为**——文本微调的"r/alpha/lr"问题之上，多模态还要问"哪个组件"。**默认策略**：冻视觉塔 + LoRA 语言塔（+ 投影层可训）——0.1-0.6% 可训练参数——两个理由：**浪费适配器**（视觉塔冻结时塔 LoRA 白改——特征不会变）与**破坏对齐**（视觉塔是对齐模型，动它 = 动对齐基础）。消融实证（LLaVA-1.6 MM-Bench）：LoRA 语言塔 56.8 vs 全量 60.1（差 3.3 点——PEFT 性价比同样惊人）、只训投影层 38.2（最弱——行为校准必须在语言塔）。

### Q2：VLM 微调的冻结策略怎么选？

**答案**：按"任务需要哪层能力"——**通用行为校准**（格式/风格/指令遵循）→ 默认（冻塔 + LoRA 语言塔）；**编码/知识密集**（代码/数学/工具）→ **层选择性 LoRA**（语言塔下半层冻结保融合、上半层微调改行为——gemma4-31B 实证：图像描述质量与底座逐位一致、编码 pass@1 +15.9、0.20% 参数——"融合在下、行为在上"）；**专门视觉域**（医学/显微镜/遥感）→ **塔 LoRA**（补感知——MicroLens 显微镜 0.58% 可训练——"通用任务冻塔、专门视觉域训塔"）。**判断**：先测底座在任务的感知表现（`多模态/多模态常见问题与缺陷/01-问题全景与诊断方法论.md` 的感知验证）——底座看不清才训塔。

### Q3：多模态微调的第一风险是什么？

**答案**：**视觉-语言融合破坏**——"大多数多模态模型的编码微调会破坏预训练学到的视觉-语言融合"（2026 实证）——症状：图像描述质量下降、视觉定位退化、跨模态引用错乱。**机制**：融合编码在语言塔**下半层**（视觉特征注入的早期层）——全层微调改写下半层 = 破坏融合路径。**检测**：**融合回测**——微调前后跑纯视觉理解任务与底座逐位对比（"图像描述逐位一致"是零破坏标准）——**每轮微调后必跑**。**缓解**：层选择性 LoRA（下半层冻结）、低 lr（2e-5）、通用图文数据混入、融合回测进门禁——"能力提升 + 融合不破"是成功的双条件。

### Q4：多模态微调的配方是什么（LLaVA 两阶段）？

**答案**：**阶段一：特征对齐预训练**——只训 MLP 投影层（~20M 参数），语言塔与视觉塔冻结——55.8 万图文对——**lr 1e-3**（高——投影层从零学对齐）——产出 mm_projector.bin；**阶段二：视觉指令微调（SFT）**——放开语言塔（与投影层联合），视觉塔冻结——66.5 万指令样本——**lr 2e-5**（低——保护既有语言能力）、1 epoch、cosine + 0.03 warmup、bf16——loss 只算 assistant token（user 掩码 -100）。**阶段间 lr 差 50 倍**是配方第一要点（从零学 vs 保护已有）。三阶段版（LLaVA-NeXT）加 **DPO**（lr 逐阶段递减 1e-4 → 5e-5 → 1e-6）。

### Q5：多模态微调的训练特化（采样/学习率）？

**答案**：**模态长度分组采样**——图像样本与文本样本分 batch（LLaVATrainer 特化）——理由：图像 token 数百到上千、混批 padding 浪费严重——分组减少浪费、提升效率；**投影层独立学习率**（mm_projector_lr——四组优化器参数组：语言塔/投影层/视觉塔/权重衰减——"不同组件不同 lr"——投影层可以比语言塔学得快）。**显存特化**：图像 token 激活值是瓶颈（QLoRA 注意视觉塔量化精度、梯度检查点最大受益者是图像激活）。

### Q6：多模态 DPO 是什么？效果怎么样？

**答案**：多模态 DPO = 用偏好对（chosen/rejected——差异常在"与图的对应"上）直接优化——**2026 多模态对齐主流**（LLaVA-NeXT/Qwen2-VL/InternVL 2/MiniCPM-V 都采用）——**效果：显著改善幻觉基准（POPE）**、回答质量更接近 GPT-4V——**多模态 DPO 的独特价值：直接改善"看图说错"类缺陷**（偏好对教模型"引用图正确的回答 > 编造的回答"）。偏好数据三来源——**人类反馈**（LLaVA-RLHF 金标）、**AI 反馈**（RLAIF-V/VLFeedback——GPT-4V 生成、规模化、继承教师偏差）——趋势："对齐从 RLHF 走向 DPO、从人类反馈走向 AI 反馈"；Omni-Reward（ICLR 2026）提供全模态奖励基准（九任务）与 24.8 万偏好对。

### Q7：微调后模型视觉能力变差了（看图答得泛泛），怎么排查？

**答案**：按三通道定位（语言/视觉/跨模态各测一组——`06-多模态微调的常见问题.md`）：**融合破坏**（跨模态类退化——图像描述与底座对比——层选择性 LoRA/低 lr/混通用数据）；**感知退化**（感知类退化——计数/小物体回测——数据偏斜挤出感知——指令数据混入感知类样本）；**对齐漂移**（图文对齐类退化——投影层被改写——投影层低 lr 或冻结 + 图文对混入）；**基线对比**（与底座/微调前对比确认"变差"是微调引入——eval-first：能力/缺陷/融合三基线先测）。

### Q8：多模态微调的评估和验收？

**答案**：**双评估集**（能力测上限/缺陷测下限——单看能力提升会隐藏缺陷恶化）；**能力基准**（MM-Bench/MM-Vet/MMMU——按任务选）、**缺陷基准**（POPE 幻觉/HoloCount 感知/PerceptionBench 原子能力——防退化）；**融合回测**（门禁特项——与底座逐位对比）；**四线门禁**——能力线（提升达标）、缺陷线（幻觉/感知/对齐不增）、融合线（不破）、工程线（显存/吞吐/三一致/合并完整/多 LoRA 兼容/服务路径评估）——**失败线决定回炉方向**（能力不达查数据配方/缺陷恶化查数据或加 DPO/融合破坏降 lr 或层选择性）。

## 2. 微调决策场景题

**场景一**："公司要微调 VLM 做发票文档理解（提取金额/日期），怎么配？"——文档是专门视觉域 + 行为校准混合：**组件**——塔 LoRA 考虑（细粒度文字感知——`多模态/多模态常见问题与缺陷/04-OCR与文档理解缺陷.md`）+ LoRA 语言塔（提取格式）；**配方**——高分辨率预处理（文档细节）+ 文档指令数据（版面/表格标注——`多模态/多模态数据集/07-数据格式与处理.md` 04 节）+ 两阶段（对齐 + SFT）；**验收**——数字必对（金额/日期抽验）+ 幻觉评估 + 融合回测；**与 RAG 分工**——"合同第几页写了什么"归多模态 RAG、提取格式归微调。

**场景二**："微调后编码能力涨了但看图问答崩了，怎么办？"——**融合破坏**（编码微调破坏视觉-语言融合——2026 实证的典型场景）：立即融合回测确认（图像描述 vs 底座逐位对比）→ **层选择性 LoRA**（下半层冻结保融合、上半层微调改行为——gemma4-31B 实证：编码 pass@1 +15.9 且图像描述逐位一致）→ 低 lr + 通用图文数据混入 → 融合回测进门禁（每轮微调后必跑）——"编码类微调优先层选择性"是 2026 的默认答案。

**场景三**："想用 24GB 单卡微调 7B VLM 做通用看图问答，方案怎么给？"——**QLoRA**（语言塔 4bit——视觉塔保持 bf16 或更高位宽——感知精度）+ 冻视觉塔 + LoRA 语言塔（r=8/α=16——通用任务默认）+ 投影层可训；配方——两阶段（对齐用现成 mm_projector 或小数据重训 + SFT lr 2e-5/1 epoch）；数据——通用视觉指令数据（LLaVA 类精选——`多模态/多模态数据集/03-多模态指令数据.md` 的生产五查）；工程——模态长度分组 + 图像 token 激活值预算（降 batch）+ 梯度检查点；验收——能力（MM-Bench 类）+ 缺陷（POPE/感知）+ 融合三线。

## 3. 答题范式总结

多模态微调题标准答题结构（四步）：**讲差异**（三组件——微调哪里多一层）→ **给默认**（冻塔 + LoRA 语言塔 0.1-0.6% + 两个理由）→ **讲配方**（两阶段 1e-3→2e-5/三阶段+DPO）→ **划风险**（融合破坏是第一风险——
层选择性 LoRA/融合回测）——**"差异 → 默认 → 配方 → 风险"四件套**；进阶追问导向 LLaVA 类架构（结构）与多模态数据集（数据）——多模态微调答得稳，证明既懂 VLM 又懂微调。

> 🎯 **核心要点**：多模态微调面试 = 8 题全覆盖（差异/冻结策略/第一风险/配方/训练特化/DPO/排查/评估）+ 3 场景题（文档/融合破坏/单卡方案）；答题四步 = 差异→默认→配方→风险；2026 数字弹药——0.1-0.6%（可训练参数）、1e-3→2e-5（两阶段 lr 差 50 倍）、56.8 vs 60.1（消融）、+15.9 点（层选择性编码）、0.20%（层选择性参数）、38.2（只训投影层）——多模态微调是"VLM 结构 + PEFT 原理"的交汇点：结构决定怎么冻、原理决定怎么训。
