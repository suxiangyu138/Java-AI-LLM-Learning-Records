# 问题全景与诊断方法论

> 排障手册的总纲：六类问题分类、感知/推理/生成三层定位、与文本模型的根本差异（感知是新引入的不可靠层）——先定位"错在哪层"，再谈修复

## 1. 六类问题分类

多模态模型的问题按"出错的环节"分六类（每类有典型症状）：

| 类别 | 典型症状 | 章节 |
|------|---------|------|
| 感知缺陷 | 数错、看不清小物体、OCR 读错 | 02/04 |
| 视觉幻觉 | 描述不存在的物体/属性/位置 | 03 |
| 推理缺陷 | 空间关系、图理解、抽象推理错 | 05 |
| 跨模态对齐 | 图文矛盾、引用错、模态冲突 | 06 |
| 工程缺陷 | 超长、延迟、多图失败 | 07 |
| 安全缺陷 | 被图里指令操纵、越权输出 | 08 |

**分类的价值在定位优先**：看到症状先归类——"数错"查感知、"编造"查幻觉、"图文矛盾"查对齐——**分类决定排查方向**（与 `大模型微调知识体系/微调常见问题/01-问题全景与排查方法论.md` 的问题地图同构，多模态版）。

## 2. 三层定位：感知 / 推理 / 生成

多模态错误的**根因定位**分三层（诊断的核心框架）：

**感知层**（模型"看到了什么"）：视觉编码器把像素转成表征——错误形态：**没看见**（小物体/密集场景）、**看错了**（字符形状/颜色/数量）——**感知错误的特征**：无论怎么提示都错（输入处理层的问题）。

**推理层**（模型"想得对不对"）：基于感知表征的推理——错误形态：**感知对但推理错**（数对了物体但集合运算错——"感知-推理脱节"，02 篇）、空间关系推断错——**特征**：换提示词/换表述可能改善。

**生成层**（模型"说得对不对"）：从推理结果到输出的语言化——错误形态：**感知推理对但输出错**（格式错、引用错、幻觉性补充）——**特征**：与语言模型的问题重叠。

**三层定位的方法**：同问题换三种问法（直接问/引导推理/强制引用）——三层都错 = 感知问题；直接问错但引导对 = 推理问题；都对但输出错 = 生成问题——**"先定位再修复"是排障第一纪律**（感知错修提示词没用，得换模型/增强输入；推理错才值得换提示策略）。

## 3. 与文本模型问题的根本差异

多模态模型比文本模型多了一个**不可靠的感知层**——这是两者的根本差异：

**文本模型**：输入就是 token（无感知问题）——错误集中在推理与生成（幻觉是"编造不存在的事实"）。

**多模态模型**：输入先过视觉编码器（感知）——**错误多了一个来源：模型"看到的"可能就不是真实的图**（感知失败/注意力衰减）——**"编造"在多模态里分两种：语言幻觉（同文本）与感知幻觉（看图看错了导致）**（03 篇）。

**推论**：**多模态模型的"流畅回答"可能建立在脆弱的感知上**（PerceptionBench 的核心发现："强语言可以掩盖弱视觉"——模型用语言先验补感知缺口，回答流畅但感知是猜的）——**排查多模态错误时，第一问不是"模型怎么答错的"，而是"模型到底看到了什么"**（感知层的验证手段：计数测试、区域引用测试——"指出来"比"说出来"更能暴露感知错误）。

## 4. 诊断工具与方法

多模态排障的四个标准动作：

**感知验证**：让模型"指出"而不是"说出"（区域引用/边界框定位——"指出错误"暴露感知失败，"说出错误"可能被语言先验掩盖）；**计数/定位测试**（用 HoloCount 类小样本验证感知基线——模型数不数得清是感知健康度的快检）。

**输入检查**：图像质量（分辨率/遮挡/噪声——`多模态/多模态 RAG/04-文档解析与预处理.md` 的"像素质量是地基"）；**提示差异测试**（同图不同提示——感知错误与提示无关、推理错误与提示相关）。

**机制验证**（2026 新方法）：注意力可视化（Halo effect 的观察——模型注意力在物体簇外缘而非中心）；**熵监控**（生成后期注意力熵上升 = 语言接管信号，02 篇）。

**消融对比**：换模型/换编码器对比（同输入不同模型——错误是否模型特有）；文本替代对比（把图转文本描述再问——"文本版答对、图像版答错" = 感知/对齐问题，"两版都错" = 推理/知识问题）——**"图文消融"是定位感知问题的利器**。

**诊断的"先易后难"顺序**：输入检查（免费）→ 提示差异（免费）→ 图文消融（低成本）→ 感知验证（中成本）→ 机制验证（高成本，研究级）——**从便宜的开始**：多数多模态问题在输入检查与提示差异两步就能定位（图像质量差/提示不清是最高频的"伪缺陷"）——机制验证留给"修了还没好"的疑难案例（与 `大模型微调知识体系/微调常见问题/01-问题全景与排查方法论.md` 的"便宜前置"纪律同构）。

## 5. 诊断的纪律

与文本排障同构的纪律（`大模型微调知识体系/微调常见问题/01-问题全景与排查方法论.md` 的五步法在此复用）：**先复现**（固定输入与提示——多模态的随机性更高，温度与采样要固定）；**再隔离**（图文消融/输入检查）；
**假设验证**（一次一个变量）；**记录**（失败样本存档——多模态缺陷样本是评估集与训练集的宝贵素材，09 篇）；**"先诊断再动手"**——多模态的错误"看着像幻觉"可能是感知失败，"看着像感知失败"可能是对齐问题——**不定位就修，修的是错的地方**。

> 🎯 **核心要点**：六类问题（感知/幻觉/推理/对齐/工程/安全）先归类再排查；三层定位（感知→推理→生成）——"先定位再修复"是总纪律（感知错修提示没用，得换模型/增强输入）；与文本模型差异——多模态多一个不可靠的感知层，"编造"分语言幻觉与感知幻觉；"强语言掩盖弱视觉"——第一问是"模型到底看到了什么"；四诊断动作——感知验证（指出 vs 说出）、输入检查、机制验证（注意力/熵）、图文消融（文本替代对比）；五步法 + 失败样本存档。
