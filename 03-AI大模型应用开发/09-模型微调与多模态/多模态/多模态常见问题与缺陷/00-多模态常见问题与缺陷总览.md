## 3. 为什么必须学透多模态缺陷

1. **2026 实证：多模态模型在基本视觉任务上仍不可靠**——PerceptionBench（3000 题、10 项原子能力）**没有模型超过 60%**（GPT-5.6 级 59.7%）；计数基准 HoloCount 显示高密度场景开源模型 <10%——**"看得见"不等于"看见"**，感知层是新引入的不可靠层。
2. **缺陷不是分辨率问题，是机制问题**：2026 研究揭示计数失败的**时空注意力衰减**（Halo effect + 语言接管——生成后期从"看"退化为"猜"）、幻觉源于**集成阶段限制**（多图时保持物体表征失败）——**理解机制才能设计缓解**，本体系 02/03 篇给机制。
3. **安全攻击面翻倍**：图像是新的注入通道——Text-DJ（OCR 分心攻击，2026）绕过文本过滤与守卫模型、INFER（信息过载，88.6% 攻击成功率）——**多模态系统的安全基线完全不同**，本体系 08 篇给完整攻击面与防御八条。
4. **选型与部署要"缺陷画像"**：同分数的模型缺陷分布截然不同（一个擅长定位但幻觉抵抗差）——**单一 leaderboard 分数不足以做部署决策**——本体系 09 篇给"按缺陷画像选型"的方法。
5. **与 RAG/微调体系互补**：多模态 RAG（`多模态/多模态 RAG/`）用检索缓解缺陷（检索到正确证据降低幻觉）、微调（`大模型微调知识体系/`）用训练缓解——**本体系回答"模型哪里会错"，RAG/微调回答"怎么补"**——先懂缺陷再谈缓解。

## 4. 核心概念速查

### 4.1 核心概念

| 概念 | 一句话 | 关键数字 |
|------|--------|---------|
| 感知-推理脱节 | 计数原子任务 85% 但集合运算 35% | InternVL3.5-38B |
| Halo effect | 注意力聚焦物体簇外缘而非中心 | 空间衰减 |
| 语言接管 | 生成后期从视觉退化为语言猜测 | 注意力熵上升 |
| 空目标悖论 | 数不存在的物体：小模型 96% 大模型 55% | 过度自信 |
| PerceptionBench | 10 项原子能力基准 | 无模型 >60% |
| 语言先验冲突 | 图与常识矛盾时信常识 | 龙虾两钳 20-40% |
| Math Blind | 符号图感知接近失效 | 细粒度定位近零 |
| Text-DJ | OCR 分心注入攻击 | 绕过守卫模型 |
| 模态不对称 | 安全训练偏文本 | 视觉防线稀疏 |
| 缺陷画像 | 按类别缺陷分布选模型 | 同分不同缺陷 |

### 4.2 缺陷分类地图（症状 → 章节）

| 症状 | 第一嫌疑 | 章节 |
|------|---------|------|
| 数错物体 | 感知缺陷（Halo/密度） | 02 |
| 描述不存在的物体 | 视觉幻觉 | 03 |
| 读错文档文字 | OCR 感知弱 | 04 |
| 位置/空间答错 | 空间推理缺陷 | 05 |
| 图文矛盾 | 跨模态对齐 | 06 |
| 多图答错/超长 | 上下文工程 | 07 |
| 被图里指令操纵 | 提示注入 | 08 |

### 4.3 常见误区速查

- "分辨率够了就能看清" → 错：机制问题（注意力衰减/集成失败）不是分辨率问题
- "分数高的模型什么都好" → 错：同分模型缺陷分布截然不同，要缺陷画像
- "安全过滤文本就够" → 错：图里藏指令绕过文本过滤（Text-DJ）
- "多模态=文本+视觉的简单叠加" → 错：跨模态交互引入新失败模式

## 5. 与周边知识的关系

```text
                    ┌── 基础概念/ —— 原理层（模型为什么这样工作）
多模态体系         ├── LLaVA 类多模态大模型核心架构/ —— 架构层（缺陷的架构根源）
                    ├── 多模态 RAG/ —— 缓解层（检索补感知）
                    ├── 多模态微调（PEFT）/ —— 缓解层（训练补缺陷）
                    ├── 本体系 —— 缺陷层（哪里会错、为什么错）
                    └── 推理部署工程/ —— 工程层（延迟/成本约束）
```

**本体系与周边知识的分工**：`基础概念` 与 `LLaVA 类架构` 讲"模型怎么工作"（原理），本体系讲"模型在哪里不可靠"（缺陷）——**原理是"应该怎样"，缺陷是"实际怎样"**；`多模态 RAG` 与 `多模态微调` 是缓解层（检索补知识、训练补行为），本体系是诊断层（先知道哪里错，才能选缓解手段）。读法建议：先原理（基础概念/LLaVA）→ 再缺陷（本体系）→ 最后缓解（RAG/微调）——**诊断在前，缓解在后**。

## 6. 学习路线推荐

**路线一：面试速成（半天，对应模块 01-03 + 08 + 10）**
问题全景 → 感知缺陷 → 幻觉 → 安全 → 面试题；掌握"计数失败/幻觉机制/注入攻击"三大考点。

**路线二：工程排障（1 天，对应模块 01-07）**
全景 → 感知 → 幻觉 → OCR → 空间 → 对齐 → 工程；配合一次多模态应用的缺陷排查实践。

**路线三：安全与选型专家（对应模块 08-09）**
攻击面 → 评估与缺陷画像；面向生产选型与安全加固。

> 🎯 **核心要点**：多模态缺陷的学习终点 = "**懂分类**（感知/理解/推理/对齐/工程/安全六类）、**懂机制**（注意力衰减/语言接管/集成失败——不是分辨率问题）、**懂实证**（PerceptionBench <60%、HoloCount 高密度 <10%、坐标 9%）、**懂安全**（图像是注入通道、模态不对称）、**懂检测**（专项基准 + 缺陷画像 + 回归测试）"——五件事建立"多模态模型哪里不可靠"的完整认知；记住"**强语言可以掩盖弱视觉**"——流畅的推理可能建立在脆弱的视觉地基上。
