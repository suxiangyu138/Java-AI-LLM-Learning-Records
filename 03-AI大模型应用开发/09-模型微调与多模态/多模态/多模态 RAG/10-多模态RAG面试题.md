# 多模态 RAG 面试题

> 面试考点："多模态 RAG 和文本 RAG 的区别、ColPali 原理、什么时候该建、怎么评估"——每题带 2026 实证，背熟即得分

## 1. 必问基础 8 题

### Q1：多模态 RAG 和文本 RAG 的区别？什么时候该建？

**答案**：多模态 RAG = 检索或生成阶段使用多模态的系统——检索单元从"文本块"扩展到"页面图像/图表/表格/音频/视频"——方法论继承文本 RAG（分块/嵌入/检索/重排），检索单元升级。**决策门槛四条件**：>25% 文档含信息关键的视觉元素（企业文档 60% 含图表混排，文本 RAG 在这些内容上召回 <40%）、有真实生产失败、文本基线已经很强、团队有带宽——**四条件全过才建**，先诊断再建。

### Q2：ColPali 的原理是什么？为什么比 OCR 管线好？

**答案**：ColPali 是**后期交互（late interaction）视觉文档检索模型**——不 OCR 不转文本，直接把 PDF 页面图像作为检索单元——页面进视觉编码器产出 ~700-1024 个 patch 级嵌入（128 维），查询 token 向量与页面 patch 向量做 **MaxSim**（每个查询向量找最相似 patch 求和）——**查询的一个词总能匹配页面上最相关的视觉区域**。比 OCR 好的原因：OCR 先转文本丢失图表/布局/视觉分组（复杂页面召回 <40%），ColPali 直接看像素——"检索的是像素里有什么，而不是 OCR 认为写了什么"。**后期交互的含义**：图文先独立编码（文档侧离线预计算）、相似度后期计算（查询侧轻量）——可规模化。

### Q3：ColPali 的成本和规模化问题？2026 怎么解决？

**答案**：成本——每页 ~1000 个 128 维向量（vs 单向量 bi-encoder 的 8-10 倍存储）、摄入 $0.01-0.05/页（vs OCR $0.001/页）、2-5 秒/页——百万页 ≈ 10 亿向量，**全量视觉化不是默认**。2026 解法：**选择性视觉化**（版面分析分类页面——纯文本页走 OCR/文本索引、图表页走 ColPali——混合索引成本降一个数量级）；**训练无关池化**（Visual RAG Toolkit：patch 嵌入滑窗平均池化 → 每页 13-32 向量 + 全局向量——存储降 8-10 倍）；**多阶段检索**（池化向量预取 Top-K → 完整 patch 向量精确重排，Qdrant prefetch+query）——吞吐提升 ~4 倍、ViDoRe v2 精度损失极小、单消费卡可跑。

### Q4：多模态 RAG 的架构怎么设计？

**答案**：五个组件——**摄入路由**（按文件类型分流：PDF→ColPali、图片→CLIP、音频→Whisper、表格→结构解析——按页面复杂度选择性视觉化）；**查询路由**（意图分类：文本主导/视觉主导/混合——路由错了检索全错）；**多通道检索**（混合查询并行跑文本+视觉通道——**先路由后融合，别直接混合不同模型的分数**）；**跨模态重排**（BGE-reranker 类交叉编码器统一排序——分数不可比的解法）；**证据图**（原始资产→派生单元的关联图：坐标/解析器版本/权限全记录——可审计重建、权限传播、区域定位）。核心原则："路由优先、融合在后"。

### Q5：表格和图表在 RAG 里怎么处理？

**答案**：表格两条铁律——**原子单元**（绝不跨块切分，切碎 = 检索到半张表）与**整表进上下文**（Markdown 保结构交给 LLM 行列推理）；解析三层（检测 Table Transformer → 结构 → 序列化 Markdown）——验收标准结构无损。图表**类型化提取**（柱状/饼图→VLM 描述+数据表、流程图→节点边、散点图→趋势+数据）；**双表示策略**——文本描述进文本索引（"描述用于检索"）+ 原图 CLIP 嵌入进视觉索引（"原图用于回答"）——文本查询与视觉查询都能命中同一图表。

### Q6：音频和视频 RAG 怎么做？

**答案**：音频**转写优先**是默认（Whisper，干净英文 WER<5%）——转写文本分块进文本 RAG，**带说话人标签与词级时间戳**（补回转写丢失的"谁说的"）；检索命中后返回**原音频片段**（时间戳引用）给原生音频 LLM（GPT-4o 类）推理——"转写用于检索、原音频用于推理"；原生音频检索（WavRAG 类波形直嵌）2026 未产品化。视频——帧抽取+CLIP 检索（找画面）+ 转写检索（找内容）+ 双塔（Wav2Vec2+ViT）——**关键缺口：时间线信息被忽略**（时序依赖丢失，"变化过程"类查询答不了——2026 前沿方向）。

### Q7：多模态 RAG 怎么评估？

**答案**：**检索先行**是第一纪律——证据没被召回，再强的 VLM 也答不对——分层评估（检索层→生成层→端到端，前层不过后层无意义）。三类基准：**ViDoRe**（检索标准，V3 BEIR 格式 nDCG@10+QPS）、**WebQA/MultiModalQA**（图文联合 QA）、领域定制（图表三查：趋势/数值/结构）。**按查询类型分层评估**（文本→文本/文本→视觉/视觉→视觉——单一全库指标会掩盖视觉查询的低召回）；**检索生成四象限**（检索对错 × 生成对错——定位问题在检索还是生成）。

### Q8：多模态 RAG 的失败模式和幻觉？

**答案**：失败模式——**模态解耦**（图文语义空间异构，跨模态对齐失败）、**结构化丢失**（表格图表被压平，摄入期损失查询期暴露）、**时序缺失**（视频时间线被忽略）、**上下文碎片**（多跳证据分散 + 证据冲突——Agentic 检索-验证-再检索解决）。幻觉新形态——**看图编数**（VLM 报出不存在的数值：数值类问题强制数据表提取而非看图直答）、**跨模态张冠李戴**（引用错误图表：证据引用追踪验证）。**安全**——每个模态都是提示注入通道（图里藏指令/OCR 注入/音频注入）——权限传播 + 注入检测 + 输出隔离。

## 2. 架构与选型场景题

**场景一**："公司有 50 万页金融报告库（大量图表），问"2024 年营收增长"类问题答不好，怎么建多模态 RAG？"——四条件确认（>25% 图表 ✓ 有失败 ✓）→ **选择性视觉化**：版面分析分类页面（图表页 ColPali、纯文本页 OCR/文本索引——成本降一个数量级）；摄入路由 + 查询路由 + 双通道 + 跨模态重排 + 证据图（坐标定位答案区域）；**表格原子单元**（报告里的利润表整表索引）；图表双表示（描述+原图）；评估——ViDoRe 格式本地基准 + 图表三查（趋势/数值/结构）——"2024 营收"类查询的分层召回先达标再谈回答质量。

**场景二**："想给 10 万小时客服录音做 QA（'客户投诉最多的问题是什么'），方案怎么给？"——**转写优先**：Whisper 转写 + 说话人标签 + 词级时间戳 → 文本分块索引 + 原音频引用；查询路由（"投诉问题"→文本通道）→ 检索转写块 → 回答带时间戳引用（可回放证据）；**注意**：转写质量先行（WER 评估——转写错了检索全错）；合规（录音数据的权限传播与脱敏——多模态内容都是敏感数据，`../大模型微调知识体系/数据集体系（非常重要）/09-数据版本管理与合规治理.md` 的方法论适用）。

**场景三**："纯文本 RAG 已经上线，但用户问'图 3 的趋势'答不了，要不要上 ColPali？"——先量化：**图 3 类查询占比**（日志统计——如果 <25% 视觉查询，先别上全量）；**选择性视觉化**（只把含图表的页面走 ColPali——不是整个库）；查询路由升级（检测"图 N"类查询 → 视觉通道）；**评估**：视觉查询的分层召回（现基线 vs ColPali 对比——用 ViDoRe 格式本地基准）；成本核算（仅图表页的 ColPali 成本 vs 收益）——**"局部视觉化"是比"全量上 ColPali"更务实的第一步**。

## 3. 答题范式总结

多模态 RAG 题标准答题结构（四步）：**讲区别**（vs 文本 RAG——检索单元升级）→ **讲原理**（ColPali 后期交互/MaxSim/不 OCR 看像素）→ **给架构**（路由 + 双通道 + 重排 + 证据图）→ **算成本**（$0.01-0.05/页、选择性视觉化、池化压缩）。

**"区别 → 原理 → 架构 → 成本"四件套**是满分结构；进阶追问导向文本 RAG 体系（基础方法论）与多模态基础概念（VLM 原理）——多模态 RAG 答得稳，证明既懂检索又懂多模态。

> 🎯 **核心要点**：多模态 RAG 面试 = 8 题全覆盖（区别与门槛/ColPali 原理/成本规模化/架构/表格图表/音视频/评估/失败与安全）；答题四步 = 区别→原理→架构→成本；2026 数字弹药——召回 <40%（复杂页面）、$0.01-0.05/页 vs $0.001、每页 ~1000 向量、吞吐 4 倍（池化）、WER<5%（Whisper）、+1.5-3s（延迟）——多模态 RAG 是"检索 + 多模态"两个知识面的交汇点：检索方法论（文本 RAG 体系）+ 多模态能力（基础概念体系）双线支撑。
