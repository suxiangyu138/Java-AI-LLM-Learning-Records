## 3. 为什么必须学透多模态 RAG

1. **文档密集型场景的刚需**：企业文档 60% 以上含图表与文本混排（金融报告、法律文书、医疗记录）——传统文本 RAG 在这些内容上召回率不足 40%（2026 实测）——**纯文本 RAG 在真实文档场景"不够用"**，多模态 RAG 是补齐方案。
2. **ColPali 是 2026 检索革命**：后期交互（late interaction）视觉文档检索——不 OCR、直接以页面像素为检索单元——在布局复杂页面（图表/表格/多语言）上显著超越传统管线，ViDoRe 成为标准评测（V3 leaderboard 公开排名）——**面试与工程都绕不开 ColPali 家族**。
3. **架构比模型更重要**：多模态 RAG 的落地形态是"路由 + 双通道 + 重排 + 证据图"的系统架构（摄入按文件类型路由、查询按意图路由、检索后跨模态重排）——本体系 05 篇给完整设计，08 篇给工程实现（成本、工具链、规模化）。
4. **成本与选型要算清楚**：ColPali 摄入 $0.01-0.05/页（vs OCR $0.001/页）、每页 ~1000 个 128 维向量（vs 单向量 8-10 倍存储）——"全量视觉化"不是默认，**按页面复杂度选择性路由**才是生产答案——本体系 08 篇给成本账。
5. **评估与安全有新增维度**：检索先行评估（证据没召回，再强的 VLM 也答不对）；多模态提示注入（文本/OCR/像素都可能藏注入）——本体系 09 篇覆盖。

## 4. 核心概念速查

### 4.1 核心概念

| 概念 | 一句话 | 关键数字 |
|------|--------|---------|
| 多模态 RAG | 检索或生成用多模态 | 文档 60% 含图表 |
| ColPali | 后期交互视觉文档检索 | 每页 ~700-1024 个 patch 向量 |
| MaxSim | 查询-页面 patch 级最大相似度 | ColBERT 式评分 |
| ViDoRe | 视觉文档检索标准基准 | V3 公开 leaderboard |
| 摄入路由 | 按文件类型分流 | PDF→ColPali、图→CLIP、音频→Whisper |
| 证据图 | 原始资产 → 派生单元链接 | 坐标/模态/来源全记录 |
| 表格原子单元 | 表格不跨块切分 | 整表单 chunk |
| 双表示 | 图表存文本描述 + 图像嵌入 | 双通道可检索 |
| 转写优先 | 音频先 ASR 再文本 RAG | Whisper WER <5% |
| 检索先行 | 先评检索再评生成 | 证据没召回 VLM 答不对 |

### 4.2 检索方法对比

| 方法 | 检索单元 | 适用 | 成本 |
|------|---------|------|------|
| 文本 RAG | 文本块 | 纯文本 | 低 |
| OCR 管线 | OCR 文本 + 坐标 | 扫描件 | 低 |
| CLIP 双塔 | 整图向量 | 自然图像 | 中 |
| ColPali 后期交互 | 页面 patch 向量 | 布局复杂文档 | 高（8-10 倍存储） |

### 4.3 常见误区速查

- "多模态 RAG = 看图回答问题" → 错：核心是文档/图表检索，不是视觉对话
- "OCR 就够用" → 错：图表/布局信息 OCR 丢失，复杂页面召回 <40%
- "全量用 ColPali" → 错：成本 8-10 倍，按页面复杂度选择性路由
- "多模态越多越好" → 错：>25% 视觉关键内容才值得建（决策门槛）

## 6. 学习路线推荐

**路线一：面试速成（半天，对应模块 01-03 + 05 + 10）**
全景定位 → 视觉检索基础 → ColPali → 架构设计 → 面试题；掌握"ColPali + ViDoRe + 路由架构"三大考点。

**路线二：工程入门（1-2 天，对应模块 01-08）**
全景 → 视觉检索 → ColPali → 解析 → 架构 → 表格图表 → 音频视频 → 工程实现；配合一次 PDF 文档库的多模态 RAG 实践。

**路线三：生产专家（对应模块 05 + 08-09）**
架构 → 工程 → 评估挑战；面向生产交付（成本控制、规模化、安全）。

> 🎯 **核心要点**：多模态 RAG 的学习终点 = "**懂定位**（三种形态 + 决策门槛）、**懂检索**（CLIP 双塔 vs ColPali 后期交互）、**懂基准**（ViDoRe V3）、**懂解析**（PDF/OCR/版面/表格）、**懂架构**（路由 + 双通道 + 证据图）、**懂工程**（成本账 + 工具链）、**懂评估**（检索先行 + 多模态安全）"——七件事覆盖多模态 RAG 从原理到生产；记住"检索是地基"：证据没召回，再强的多模态模型也答不对。
