# 多模态 RAG 架构设计

> 生产级架构的五个组件：摄入路由、查询路由、多通道检索、跨模态重排、证据图——"路由优先、融合在后"是架构的第一原则

## 1. 架构全景

2026 生产级多模态 RAG 的标准架构（ACL 2026 调研与生产实践的一致形态）：

```text
摄入侧：文档 → 摄入路由 → ColPali 索引（PDF 页）│ CLIP 索引（图片）│ 文本索引（文本块）│ Whisper（音频）→ 证据图
查询侧：查询 → 查询路由（意图分类）→ 并行检索（多通道）→ 重排（跨模态融合）→ 证据组装 → VLM 回答
```

两个路由 + 一个图是架构的骨架：**摄入路由**（入库时按文件类型分流）、**查询路由**（查询时按意图分流）、**证据图**（贯穿两侧的资产关联）——其余组件（检索/重排/生成）是标准 RAG 的多模态化。

## 2. 摄入路由：按文件类型分流

入库时的路由决策（04 篇解析管线的入口）：

| 文件类型 | 处理 | 索引 |
|---------|------|------|
| PDF（布局复杂） | 页面图像 + ColPali | 多向量索引 |
| 图片（自然图像） | CLIP/SigLIP | 图像向量索引 |
| 表格/电子表格 | 结构解析 → Markdown | 文本索引（整表单） |
| 音频 | Whisper 转写 + 说话人标签 | 文本索引 + 音频引用 |
| DOCX/纯文本 | 文本提取 + 内嵌图片抽取 | 文本索引 + 图片索引 |

**路由的关键**：**不是所有 PDF 都走 ColPali**——按页面复杂度选择性视觉化（纯文本页走文本索引省 8-10 倍成本，图表页走 ColPali——08 篇的成本优化"选择性视觉化"在此落地）；**摄入路由的决策要可配置**（文件类型 → 管线的映射表，改动走配置）。

## 3. 查询路由：按意图分流

查询时的意图分类（三选一或组合）：

- **文本主导**（查询是纯文本语义问题）→ 文本通道检索。
- **视觉主导**（查询涉及图表/图像/布局，如"图 3 显示什么趋势"）→ 视觉通道检索。
- **混合**（"2024 年营收和利润表的对比"）→ 双通道并行检索 + 融合。

**路由的实现**：小模型分类器（意图分类）或 LLM 路由（few-shot 判定）；**路由错误的代价**：文本查询误入视觉通道（检索不到）或反之——**路由质量影响检索上限**（路由错了，后续全错——与摄入路由同样的"决策前置"原则）。

**路由的降级设计**：路由不是"二选一"而是"概率加权"——**不确定的查询双通道都跑**（多花一点检索成本、保召回不丢）——"文本主导查询也顺带跑视觉通道"（视觉命中是额外收益）；**路由的评估**：路由准确率（分类错误的查询占比——用标注的测试查询集测）+ **路由错误的实际影响**（错入通道的查询最终召回率——路由错了但双通道兜住了 = 影响可控）——**"路由要测，但别为路由完美过度投入"**（双通道兜底是路由错误的缓冲）。

## 4. 多通道检索与跨模态重排

**多通道并行**：混合查询同时跑文本通道（BM25 + 文本向量）与视觉通道（ColPali/CLIP）——**"先路由后融合"**：各通道内先排序，跨通道再融合——**不要直接混合不同模型的分数**（向量空间不可比，09 篇失败模式）。

**重排（rerank）**：跨通道候选合并后，用**跨模态交叉编码器**（BGE-reranker-v2、Cohere Rerank 3 类）重排——交叉编码器同时看查询与候选（含视觉内容），比双塔的分数更准——**重排是"分数不可比"问题的标准解法**：各通道先各出 Top-K（分数可比性差），合并后统一重排（分数可比性由同一重排器保证）。

**证据组装**：重排后的 Top-N 证据（页面/图表/文本块混合）组装成 VLM 上下文——**保留证据的原始形态**（图表以图像进上下文、表格以 Markdown 进、页面以图像进——`多模态/LLaVA 类多模态大模型核心架构/` 的 VLM 输入能力决定组装方式）。

## 5. 证据图：贯穿两侧的资产关联

**证据图（Evidence Graph）**：不把源文件"扁平化"成文本（信息损失，04 篇），而是**存储"原始资产 → 派生单元"的关联图**：

- **节点**：页面图像、文本块（带坐标框）、表格/图表区域、OCR 文本、描述文本、嵌入向量。
- **边**：派生关系（页面 → 文本块 → OCR；图表 → 描述 → 嵌入）。
- **元数据**：document_id、区域坐标、模态、来源 URI、内容哈希、**解析器版本**、访问权限——**每个索引单元都带元数据**。

**证据图的价值**：**可审计重建**（解析器升级了 → 按图重建受影响单元，不重解析全库）；**权限传播**（文档级权限 → 派生单元自动继承——多模态 RAG 的安全基础，09 篇）；**区域定位**（ColPali 命中页面 → 沿图找到页面内的答案区域坐标——"页面级命中 + 区域级定位"二级漏斗的落地形态）。

## 6. 架构的演进形态

**Graph/Agentic RAG（2026 前沿）**：证据图升级为知识图——**MAGE-RAG**（多粒度自适应图证据）：把列表/表格/图像/图表/公式/代码块建模为图节点，页面节点作入口，长文档 QA 沿图推理；**Agentic 多模态 RAG**：检索-验证-再检索循环（第一轮证据不足 → 改写查询/换通道 → 再检索——`03-AI大模型应用开发/03-Agent与MCP协议/` 的 Agent 方法论在多模态检索上的应用）——**架构的下一步是"检索会思考"**（路由 + 迭代 + 证据评分），本体系给静态架构基础，Agentic 扩展在 Agent 体系。

## 7. 架构设计检查清单

生产架构的验收：**路由决策可配置**（摄入/查询两类路由的映射表）；**通道隔离**（各通道独立索引、独立排序）；**融合可解释**（重排器固定、分数记录——"为什么返回这个证据"可查）；**证据图完整**（每个索引单元有元数据）；**权限传播**（多模态内容的访问控制生效）；**可重建**（解析器升级后增量重建跑通）——六项全过，架构才"生产级"。

> 🎯 **核心要点**：架构骨架 = 摄入路由（文件类型分流，按页面复杂度选择性视觉化）+ 查询路由（意图分类，文本/视觉/混合）+ 多通道检索（先路由后融合，别混分数）+ 跨模态重排（交叉编码器统一排序）+ 证据图（原始资产→派生单元，坐标/版本/权限全记录）；二级漏斗（ColPali 命中页面 → 坐标定位区域）；证据组装保留原始形态（图像进上下文）；演进——知识图（MAGE-RAG）+ Agentic 循环；六项检查（路由可配置/通道隔离/融合可解释/图完整/权限传播/可重建）。
