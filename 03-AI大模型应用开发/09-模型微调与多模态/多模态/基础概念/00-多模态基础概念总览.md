## 3. 为什么必须学透多模态基础概念

1. **一切多模态知识的结构基础**：VLM 的三组件（视觉编码器/投影层/语言塔）是 `多模态微调（PEFT）` 的冻结策略、`多模态 RAG` 的检索模型、`多模态常见问题与缺陷` 的缺陷根源的共同地基——**"结构决定一切"**：感知缺陷的根源在视觉编码器（patch 粒度）、对齐问题的根源在投影层与对比学习、融合破坏的根源在特征注入位置——本体系把"为什么"讲透。
2. **2026 架构在演进**：SigLIP-2 取代 CLIP 成为主流视觉骨干（Qwen3-VL）、Interleaved-MRoPE（多维旋转位置编码）解决视频与文档定位、DeepStack 跨层融合取代单点注入（显存 -37%/延迟 -29%）、原生统一架构（NEO-ov）挑战模块化范式——**概念层不更新，读新模型论文会迷路**。
3. **token 是算账的货币**：336×336 图像在 patch 14 下产出 **576 个视觉 token**——`多模态常见问题与缺陷/07-上下文与工程缺陷.md` 的 token 账本、`多模态微调（PEFT）/08-多模态微调工程实践.md` 的显存瓶颈都从这 576 开始——**"懂 token 才懂成本"**。
4. **对齐是贯穿多模态的主线**：CLIP 的对比学习（图文对齐）→ 投影层的桥接 → 微调的冻塔策略 → RAG 的 CLIP 分数过滤——**"对齐"是本体系的主题词**（与 `多模态/多模态数据集/01-多模态数据集全景与定位.md` 的"对齐是第一质量维度"呼应）。
5. **面试的结构基础**：多模态面试的第一题常是"VLM 怎么工作"——本体系 02/04/05 篇给完整答案（视觉编码器 → 投影 → 语言塔的流水线 + 576 token 数字 + 架构家族）。

## 4. 核心概念速查

### 4.1 核心概念

| 概念 | 一句话 | 关键数字 |
|------|--------|---------|
| 三组件 | 视觉编码器/投影层/语言塔 | 模块化 VLM 标准 |
| 视觉 token | patch 级特征向量 | 336×336@14 = 576 token |
| CLIP | 对比学习图文对齐 | InfoNCE + 温度 τ |
| SigLIP | sigmoid 损失替代 InfoNCE | 训练更稳 |
| 投影层 | 视觉特征 → 语言嵌入空间 | MLP/Q-Former/LDPNet |
| DeepStack | 多层视觉特征跨层注入 | 显存 -37%/延迟 -29% |
| MRoPE | 多维旋转位置编码 | 时间/高度/宽度三轴 |
| NEO-ov | 原生统一（无外部编码器） | 挑战模块化 |
| MM-DiT | 扩散 Transformer 多模态 | 生成统一 |
| BSQ | 二值球面量化视觉 tokenizer | 32× 压缩 |

### 4.2 视觉编码器家族

| 编码器 | 损失 | 使用者 | 特点 |
|--------|------|--------|------|
| CLIP | InfoNCE | LLaVA/InternVL/GPT-4V | 细粒度理解 |
| SigLIP | sigmoid | PaliGemma/LLaVA-NeXT | 更稳更高效 |
| SigLIP-2 | 鲁棒对比 | Qwen3-VL | 零样本/局部语义/遮挡鲁棒 |
| Pixtral-ViT | — | Pixtral | 变分辨率 1B |
| MetaCLIP | InfoNCE | Llama 3.2 90B Vision | 数据驱动 |

### 4.3 常见误区速查

- "多模态模型 = 文本模型 + 图像分类器" → 错：三组件 + 对比学习对齐的完整系统
- "图像 token 和文本 token 一样" → 错：视觉 token 计算成本数倍于文本 token
- "CLIP 已经过时" → 错：仍是视觉骨干主流（SigLIP 是其改进）
- "原生统一一定更好" → 错：2026 原生仍落后于成熟模块化（NEO-ov 自述）

## 5. 与周边知识的关系

```text
                    ┌── 大模型微调知识体系/ —— 语言模型原理（语言塔的基础）
多模态体系         ├── LLaVA 类多模态大模型核心架构/ —— 架构深潜（本体系的展开）
                    ├── 多模态 RAG/ —— 检索应用（编码器/对齐的应用）
                    ├── 多模态微调（PEFT）/ —— 训练应用（三组件的冻结）
                    ├── 多模态常见问题与缺陷/ —— 缺陷（结构根源在此）
                    ├── 多模态数据集/ —— 数据（对齐的数据基础）
                    └── 本体系 —— 概念层（原理地基）
```

**本体系与周边知识的分工**：本体系是**原理层**（模型怎么工作——编码器/对齐/桥接/架构）；`LLaVA 类核心架构` 是**架构深潜**（具体模型族的细节——本体系的展开）；其余体系是**应用层**（RAG/微调/排障/数据——本体系的原理被它们消费）。读法建议：先本体系（概念地基）→ LLaVA 类架构（深潜）→ 应用体系（RAG/微调/排障）——**"原理 → 架构 → 应用"三层递进**。

## 6. 学习路线推荐

**路线一：面试速成（半天，对应模块 01-05 + 10）**
全景 → 编码器 → 对齐 → 投影 → VLM 架构 → 面试题；掌握"三组件流水线 + 576 token + CLIP/SigLIP"三大考点。

**路线二：原理入门（1 天，对应模块 01-07）**
全景 → 编码器 → 对齐 → 投影 → 架构 → token → 推理；配合读一篇 Qwen3-VL 技术报告实践。

**路线三：生成与前沿（对应模块 08 + 05 + 09）**
生成模型 → 架构演进 → 评估；面向生成与统一模型方向。

> 🎯 **核心要点**：多模态基础概念的学习终点 = "**懂结构**（三组件——编码器/投影/语言塔）、**懂 token**（patch → 576 token——算账的货币）、**懂对齐**（CLIP 对比学习——贯穿多模态的主线）、**懂桥接**（投影层与特征注入）、**懂架构**（LLaVA 模块化 → Qwen3-VL 演进 → 原生统一）、**懂生成**（DiT/统一模型）、**懂评估**（能力-缺陷-感知三轴）"——七件事建立多模态模型的完整概念地基；记住"**结构决定一切**"——感知缺陷在编码器、对齐问题在投影、融合破坏在注入位置。
