# 指令遵循与多模态推理

> VLM 的"智能层"：视觉指令遵循（SFT 的产物）、多模态 CoT 与推理模型、grounding（坐标输出）、多模态 Agent——"看图回答问题"到"看图做事情"

## 1. 视觉指令遵循

**视觉指令遵循（Visual Instruction Following）**：模型按指令看图回答——"描述这张图""图里有什么颜色""根据图表推断趋势"——**VLM 的 SFT 产物**（`多模态/多模态微调（PEFT）/04-多模态微调配方.md` 的阶段二）——**"会看图 + 会听话"的组合能力**——LLaVA 类指令数据（`多模态/多模态数据集/03-多模态指令数据.md` 的描述/对话/复杂推理三类）训练出的核心能力。

**指令遵循的层次**：**直接指令**（"描述这张图"——简单遵循）；**多轮指令**（"先描述再对比"——对话式遵循——`多模态/多模态数据集/03-多模态指令数据.md` 的对话类）；**复杂指令**（"结合图与文字信息推理"——复合遵循——复杂推理类）——**"指令遵循的深度 = 训练数据的复杂度"**（数据配比决定能力——`多模态/多模态数据集/03-多模态指令数据.md` 的三类配比）。

**指令遵循的评估**：MM-Bench（多模态指令遵循基准——`多模态/多模态微调（PEFT）/09-多模态微调评估.md` 的能力基准）——**"指令遵循是 VLM 可用性的核心指标"**（模型再好、不听指令 = 不可用——`多模态/多模态常见问题与缺陷/` 的"格式不稳定"类缺陷的正面能力）。

## 2. 多模态 CoT

**多模态思维链（Multimodal CoT）**：模型"先想后答"——在图文背景下逐步推理（"先看图的左侧，再比较右侧……"）——**与文本 CoT（`大模型微调知识体系/基础概念/` 的推理模式）同构，多模态版**——**为什么多模态 CoT 重要**：**强制视觉接地**（中间步骤引用图像区域——对抗"语言先验覆盖"——`多模态/多模态常见问题与缺陷/06-跨模态对齐与语言先验.md`；对抗感知缺陷的"语言接管"——`多模态/多模态常见问题与缺陷/02-视觉感知缺陷.md` 04 节——**HoloCount 实证：思考模式计数 +10-15 点**——多模态 CoT 是感知缺陷的提示侧缓解）。

**多模态推理模型（2026）**：推理模型（`大模型微调知识体系/基础概念/02-大模型训练三阶段范式.md` 的 Reasoning 类）的多模态版——**RLVR（可验证奖励）扩展到视觉任务**（图表数学/视觉推理——`多模态/多模态微调（PEFT）/` 的 VLA 关联）——前沿方向。

## 3. Grounding：坐标输出

**Grounding（视觉接地）**：模型输出图像中的**坐标**（bbox/点/多边形）——"指出图里的猫在哪"——**2026 主流能力**（Qwen2.5-VL/Molmo/CogVLM2-Grounding/Florence-2/Kosmos-2 都支持）——**坐标作为输出 token**（特殊 token 体系的一部分——`多模态/多模态微调（PEFT）/06-多模态token与输入处理.md` 04 节）。

**Grounding 的意义**：**"指出 vs 说出"**（`多模态/多模态常见问题与缺陷/01-问题全景与诊断方法论.md` 的感知验证——坐标输出是感知能力的可验证形态）；**Agent 能力的基础**（UI 自动化/计算机使用——"点击这个按钮"需要坐标——`多模态/多模态微调（PEFT）/` 的 Agent 场景）；**文档定位**（`多模态/多模态 RAG/04-文档解析与预处理.md` 的区域定位——坐标进 RAG 的答案引用）。

**Grounding 的局限**：**坐标提示定位弱**（`多模态/多模态常见问题与缺陷/05-空间与关系推理缺陷.md` 的 9%——符号空间描述转像素失败——但视觉提示（画框）的 grounding 好得多——**"输出坐标 vs 输入坐标的不对称"**——模型能输出坐标（grounding）但读坐标弱）。

## 4. 多模态 Agent

**多模态 Agent**：VLM + 工具 + 循环（`03-AI大模型应用开发/03-Agent与MCP协议/` 的 Agent 方法论多模态版）——**"看图做事情"**：看屏幕 → 决策 → 操作（点击/输入）——**计算机使用/UI Agent**（2026 热点——Anthropic/OpenAI/各家的 computer use）——能力基础：**grounding（坐标）** + **指令遵循** + **工具调用**（`大模型微调知识体系/基础概念/08-指令数据与对话格式基础.md` 的工具数据多模态版——工具调用轨迹含截图）。

**多模态 Agent 的注意**：**感知错误的代价放大**（`多模态/多模态常见问题与缺陷/01-问题全景与诊断方法论.md` 的缺陷在 Agent 场景——看错按钮 = 点错操作——**Agent 的感知要求高于对话**）；**视觉注入攻击**（`多模态/多模态常见问题与缺陷/08-多模态安全与攻击面.md`——网页截图藏指令——Agent 被劫持）；**上下文管理**（截图是重 token——`多模态/多模态微调（PEFT）/07-多模态token与输入处理.md` 的 token 账本——Agent 的每轮截图消耗）。

## 5. 推理能力的评估

多模态推理能力的评估（`多模态/多模态基础概念/09-多模态能力评估与基准.md` 的推理维度）：**MMMU（大学多模态理解）**——知识推理型；**MathVista**（视觉数学）；**ChartQA**（图表推理）；**RefCOCO**（指代理解——grounding 评估）——**"推理评估按任务分型"**（知识/数学/图表/指代各测各的——单一推理分数掩盖类型差异——`多模态/多模态常见问题与缺陷/09-评估与缺陷检测.md` 的分层评估）。

## 6. 从"看"到"做"的能力阶梯

多模态能力的阶梯（本体系的能力地图）：**感知**（看见——编码器——02 篇）→ **对齐**（看懂——投影——03/04 篇）→ **理解**（指令遵循——语言塔）→ **推理**（CoT——想通）→ **接地**（指出——
坐标输出）→ **行动**（Agent——做事情）——**"每上一层依赖下一层"**（推理依赖理解、接地依赖感知——`多模态/多模态常见问题与缺陷/` 的缺陷在阶梯上的位置——感知缺陷拉低上层一切）——**"能力阶梯是排查与训练的定位工具"**（问题在阶梯哪层、训练补哪层）。

> 🎯 **核心要点**：视觉指令遵循 = VLM 的 SFT 产物（"会看图 + 会听话"——深度由数据配比决定）；多模态 CoT——"先想后答"强制视觉接地（对抗语言先验/语言接管——思考模式计数 +10-15 点实证——推理模型扩展到视觉 RLVR 是前沿）；Grounding = 坐标输出（2026 主流——Qwen2.5-VL 等——"指出 vs 说出"的感知验证形态 + Agent 基础——输出坐标 vs 读坐标的不对称（输出好读弱 9%））；多模态 Agent——看图做事情（computer use——感知错误代价放大/视觉注入攻击/截图 token 重）；推理评估按任务分型（MMMU/MathVista/ChartQA/RefCOCO）；能力阶梯——感知→对齐→理解→推理→接地→行动——每层依赖下层——"阶梯是排查与训练的定位工具"。
