# 多模态基础概念面试题

> 面试第一关："VLM 怎么工作、CLIP 是什么、视觉 token 怎么算、DeepStack 解决什么"——每题带 2026 架构实证，背熟即得分

## 1. 必问基础 8 题

### Q1：VLM 是怎么工作的？（架构流水线）

**答案**：模块化 VLM 的标准流水线（2026 主流——GPT-4V/LLaVA/Qwen-VL 一致）：**视觉编码器 → 投影层 → 语言塔**——图像切成 patch（如 14×14）→ ViT 编码器产出 patch 特征（视觉 token）→ 投影层把视觉特征翻译进语言嵌入空间（MLP/Q-Former 类）→ 与文本 token 拼接成输入序列（`<img>视觉token</img> 文本`）→ decoder-only 语言塔生成回答。**三组件职责**：视觉塔管感知（看见）、投影层管对齐（看懂）、语言塔管行为（回答）——`多模态/多模态微调（PEFT）/02-VLM结构与可微调部件.md` 的组件视角在此。

### Q2：图像怎么变成 token？token 数怎么算？

**答案**：图像切 patch → 每个 patch 线性投影成向量 → Transformer 处理 → patch 级特征就是**视觉 token**——**token 数 = (H/patch) × (W/patch)**——336×336 图像、patch 14 → **24×24 = 576 个视觉 token**（1024² 约 5329 个）。视觉 token 的三特性：**不可切断**（图像是整体——打包/切分时是原子单元）；**计算成本高**（1 个图像 token ≈ 数个文本 token 的计算）；**不参与 loss**（视觉 token 是输入不是输出——交叉熵只算文本 token）。**patch 粒度决定感知上限**（14×14 内的小物体被压缩——`多模态/多模态常见问题与缺陷/02-视觉感知缺陷.md` 的感知缺陷结构根源）。

### Q3：CLIP 是什么？对比学习怎么工作？

**答案**：CLIP（Contrastive Language-Image Pretraining）——图文对齐的开创模型——**对比学习**：从图文对数据学"配对图文相似度高、不配对低"——**InfoNCE 对比损失**：batch 内 N 个图文对——对每个图像，配对文本是正样本、其余 N-1 个是负样本（双交叉熵）——**温度 τ（0.07）**缩放 logits——训练出"图像编码器 + 文本编码器"双塔（`多模态/多模态 RAG/02-视觉检索基础.md` 的双塔就是 CLIP 产物）。**直觉**："认亲训练"——模型必须学会 batch 内哪张图配哪句话——自监督无标签对齐。**SigLIP 改进**：sigmoid 逐对损失替代 InfoNCE（不依赖大 batch 负样本——训练更稳）——SigLIP-2（Qwen3-VL 骨干）鲁棒对齐。

### Q4：投影层有哪几种？token 压缩是什么？

**答案**：三种——**MLP**（两层 MLP 直接映射——LLaVA/Qwen-VL——576 token 不压缩）；**Q-Former**（12 层 transformer 把 patch 压缩成 32 个查询 token——BLIP-2/Qwen-VL-Max——强压缩需对齐训练）；**LDPNet-V2**（2026——144 token 达到 576 token 效果——MM-Bench 81.4% 最佳——比 MLP 少 4-5 倍 token 还更好）。**token 压缩的意义**：上下文节省（多图场景 token 预算）、计算节省（视觉 token 成本——`多模态/多模态微调（PEFT）/08-多模态微调工程实践.md` 的吞吐）——**"压缩 vs 感知的权衡"**（压缩丢细节——感知敏感任务慎压缩）。

### Q5：DeepStack 跨层融合是什么？解决什么问题？

**答案**：DeepStack（Qwen3-VL 2026）——**ViT 多个抽象层的特征（如 1/3/5 层）注入语言塔的前几层**（cross-attention + 自适应门控）——解决单点注入的两个问题：**浅层注入的注意力坍缩**（视觉 token 全堆开头——注意力集中在视觉区）与**顶层注入的语义扭曲**（融合不充分）——**实证：显存 -37%、推理延迟 -29%、VQA/RefCOCO/TextCaps 提升**——**"注入位置是融合质量的架构决定"**（与 `多模态/多模态微调（PEFT）/06-多模态微调的常见问题.md` 的融合破坏呼应——融合编码在语言塔下半层）。

### Q6：Interleaved-MRoPE 是什么？

**答案**：**多维旋转位置编码**（Qwen3-VL）——位置编码在**时间/高度/宽度三轴交错**（x/y 空间坐标 + 帧序号 t）——视频与文档定位的改进：**帧间位置（第几帧）与帧内位置（帧内哪里）同时编码**——解决"视频帧只知道内容不知道位置、文档只知道文字不知道区域"的定位问题——配套**显式时间戳 token**（视频时序推理）——**"位置编码从 1D 文本到 3D 多模态"**（`多模态/多模态常见问题与缺陷/05-空间与关系推理缺陷.md` 的坐标定位问题在架构侧的缓解）。

### Q7：原生统一架构（NEO-ov）是什么？和模块化比怎么样？

**答案**：NEO-ov（2026）——**消除所有外部编码器、适配器、事后融合**——单一 monolithic decoder-only transformer——图像通过轻量卷积 patch 嵌入层（两层卷积）直接变成视觉 token（`<img>` 包裹）与文本 token 联合处理——单模型支持单图/多图/视频/空间推理。**与模块化对比**：模块化（编码器→投影→语言塔）的优势是**组件可替换/分阶段训练/生态成熟**；原生的优势是**无对齐层/无桥接损失**——**2026 现状：原生在统一感知任务上仍落后于成熟模块化**——"原生是方向、模块化是现实"。

### Q8：多模态生成模型的主流架构？

**答案**：**DiT（Diffusion Transformer）**——扩散骨干从 U-Net 换 Transformer（SD 3/4、Sora 类共同基础——加噪去噪 + 条件生成）；**MM-DiT**——图文 token 同序列 + 联合多头自注意力（模态标签——四块交互区——图文互相条件化）——已知问题：**token 失衡**（视觉 token 远多——softmax 抑制跨模态注意力——TACA 温度缩放解决）与二次方注意力成本；**统一生成（2026）**——UniAR（ICML 2026：BSQ 视觉 tokenizer 32× 压缩——一个 Transformer 做理解+生成+编辑——"统一的关键是视觉 tokenizer"）、Archon（全模态数字人——任意到任意）——**"生成与理解在 2026 走向统一"**。

## 2. 架构理解场景题

**场景一**："面试官问'多模态模型为什么比文本模型贵/慢'，怎么答？"——三个层面：**token 数量**（一张图 576 个视觉 token ≈ 顶几千字——上下文与成本）；**token 计算成本**（视觉 token 走完整视觉-语言处理路径——1 个图像 token ≈ 数个文本 token 计算——`多模态/多模态微调（PEFT）/08-多模态微调工程实践.md` 的吞吐 1/2-1/4）；**编码器开销**（图像先进视觉编码器——额外的模型前向）——"贵在视觉处理"一句话总结。

**场景二**："要选一个开源 VLM 做文档理解，怎么选？"——按能力维度与缺陷画像（`多模态/多模态常见问题与缺陷/09-评估与缺陷检测.md`）：**能力**（文档任务基准——OCRBench/DocVQA——NVLM 92% 类分数）；**感知**（高分辨率支持——文档细粒度——变分辨率编码器（Pixtral）或动态分辨率（Qwen-VL 系））；**缺陷**（幻觉/对齐分数）；**工程**（显存/开源许可/微调生态）——"家族 → 能力 → 缺陷 → 资源"四层选型（`多模态/多模态微调（PEFT）/01-多模态模型全景与定位.md` 05 节）。

**场景三**："为什么模型能输出坐标（grounding）但读坐标（坐标提示）很弱？"——**不对称的机制**：**输出坐标**（grounding）是训练过的任务（坐标作为输出 token——Qwen2.5-VL 等——`多模态/多模态微调（PEFT）/07-指令遵循与多模态推理.md` 03 节）；**读坐标**（"x∈[100,300]"的符号空间描述转像素）需要**符号-空间翻译**（`多模态/多模态常见问题与缺陷/05-空间与关系推理缺陷.md` 的 9%——模型的空间理解是视觉化的）——**工程缓解：坐标画框再问**（把符号坐标翻译成模型擅长的视觉形态——画框/高亮）。

## 3. 答题范式总结

多模态基础概念题标准答题结构（四步）：**讲流水线**（编码器 → 投影 → 语言塔——先给完整框架）→ **给数字**（576 token/patch 14/τ 0.07/32 token Q-Former/144 LDPNet）→ **讲机制**（对比学习/注意力注入/位置编码——
数字背后的为什么）→ **划演进**（CLIP→SigLIP-2/MLP→DeepStack/模块化→原生——2026 方向）——**"流水线 → 数字 → 机制 → 演进"四件套**；进阶追问自然导向微调（组件冻结）与缺陷（结构根源）——概念答得稳，多模态面试的地基就稳了。

> 🎯 **核心要点**：多模态基础概念面试 = 8 题全覆盖（流水线/token 计算/CLIP 对比学习/投影与压缩/DeepStack/MRoPE/原生统一/生成架构）+ 3 场景题（贵的原因/选型/grounding 不对称）；答题四步 = 流水线→数字→机制→演进；2026 数字弹药——576（336²@14）、τ=0.07、32（Q-Former）、144（LDPNet）、-37% 显存（DeepStack）、32× 压缩（BSQ）、MMMU 72.5（Gemini）——多模态概念是"结构 + 数字 + 机制"的三角：结构给框架、数字给量级、机制给深度。
