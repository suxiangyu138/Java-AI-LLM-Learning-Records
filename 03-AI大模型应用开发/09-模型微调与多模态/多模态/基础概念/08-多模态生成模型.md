# 多模态生成模型

> 多模态的"创作家族"：DiT/MM-DiT 架构、图像/视频生成、统一生成模型（UniAR/Archon）、生成-理解统一——"生成与理解在 2026 走向统一"

## 1. DiT：扩散 Transformer

**DiT（Diffusion Transformer）**：把扩散模型（`03-AI大模型应用开发/深度学习/` 的扩散概念）的骨干从 U-Net 换成 **Transformer**——图像生成的主流架构（Stable Diffusion 3/4、Sora 类视频生成的共同基础）——**Transformer 的优势**：统一架构（与 LLM 同族——`大模型微调知识体系/基础概念/03-Transformer与参数基础.md`）、可扩展（scaling law）、多模态天然（注意力处理多模态 token）。

**生成流程一句话**：**加噪 → 去噪**（训练时把图像逐步加噪、模型学去噪；推理时从纯噪声逐步去噪出图像——`03-AI大模型应用开发/深度学习/` 的扩散训练）——DiT 在去噪过程中用 Transformer 处理"带噪图像 token + 条件 token（文本/图）"。

**DiT 与理解模型的"同一族"关系**：DiT 的 Transformer 骨干与 LLM 同族（`大模型微调知识体系/基础概念/03-Transformer与参数基础.md`）——**"生成与理解共享 Transformer 是 2026 统一的前提"**（UniAR 的统一自回归、NEO-ov 的统一解码都是这个前提的延伸——05/08 篇的统一主线）——面试答"生成与理解怎么统一"时先答这个共同祖先。

## 2. MM-DiT：多模态扩散

**MM-DiT（Multimodal Diffusion Transformer）**：视觉与文本 token **拼接进同一序列 + 联合多头自注意力**——**每 token 带模态标签**——注意力矩阵分解为四块交互区（视觉-视觉/视觉-文本/文本-视觉/文本-文本）——**"图文在同一注意力空间互相条件化"**（文本条件指导图像生成——文生图的核心机制）。

**MM-DiT 的已知问题与解法**：**token 失衡**（视觉 token 远多于文本——softmax 抑制跨模态注意力——FLUX/SD 3.5 的问题——**TACA 框架**：门控 + 时间步相关温度缩放跨模态 logits）；**二次方注意力成本**（长序列——头部方向注意力/缓存/线性压缩注意力——DiTFastAttnV2 省 68% FLOPs）——**"多模态生成的工程瓶颈 = token 失衡与注意力成本"**。

**token 失衡的普遍性**：token 失衡不止出现在生成模型——**理解模型的注意力同样受视觉 token 数量影响**（`多模态/多模态微调（PEFT）/06-多模态token与输入处理.md` 的 token 压缩动机——`多模态/多模态常见问题与缺陷/02-视觉感知缺陷.md` 的 Halo effect——注意力被大量视觉 token 稀释）——**"跨模态注意力失衡是理解与生成共享的架构问题"**（TACA 的解决方案（温度缩放）与理解侧的缓解（token 压缩）是同一问题的两条路）。

## 3. 视频生成

**视频生成（2026）**：DiT 扩展到时间维度——Sora 类（时空 patch——3D patch）——**LoomVideo（2026-06）**：5B 参数统一多模态输入的视频生成/编辑——**用多模态 LLM 替代文本编码器**（MLLM 特征 + DeepStack 注入对齐 DiT）+ **Scale-and-Add 条件化**（零开销——避免 token 拼接翻倍序列长度、注意力成本 4 倍）+ **负时间 RoPE**（多参考图）——推理提速 5.41×+——**"视频生成的架构 = 图像生成 + 时间维度 + 多模态条件"**。

**视频生成的挑战**：长时一致性、运动控制、音频对齐（音视频联合生成是开放问题——`多模态/多模态基础概念/06-多模态token与输入处理.md` 的音频 token 不成熟）。

**生成模型的"知识库定位"**：本体系（`多模态/多模态基础概念/`）给生成模型的概念基础（DiT/MM-DiT/统一生成）——**生成模型的工程体系（部署/微调/评估）是知识库的后续方向**（`多模态/推理部署工程/` 覆盖推理侧——生成模型的图像/视频部署在其延伸）——**"生成家族的概念在概念层、工程在推理部署工程"**（当前知识库的理解家族工程体系完整、生成家族待建设——`多模态/多模态微调（PEFT）/01-多模态模型全景与定位.md` 的"家族分工"在此落地）。

## 4. 统一生成模型：UniAR

**UniAR（ICML 2026，Qwen 团队）**：**统一自回归模型**——一个 Transformer 同时做图像理解、生成、编辑——核心：**单一离散视觉 tokenizer（BSQ——二值球面量化）**——共享上下文桥接理解与生成（模型理解自己生成的视觉 token——不需要重新编码）——**32× 视觉压缩**（1024² 图像只需 256 个自回归 token）+ DiT 视觉解码器（SD3-medium transformer 重建高保真图像）——**"生成-理解统一的关键是视觉 tokenizer"**（共享 token 让理解与生成在一个序列里互相作用）。

**统一的意义**：**多模态生成的"语言化"**（图像像文本一样被生成——自回归——与 LLM 同范式）；**编辑/对话式生成**（理解与生成交替——"看这张图，改成红色"——一个模型完成）。

## 5. 统一数字人：Archon

**Archon（2026）**：全模态数字人生成——**任意模态到任意**（描述/脚本/语音/动画/语义视频/图像/视频——理解 + 生成 + 编辑在一个生成框架）——**"全模态统一的代表"**——与 `多模态/多模态微调（PEFT）/05-多模态微调的类型.md` 的 VLA（动作）不同——Archon 是"内容创作"的统一（生成家族）。

**统一模型的格局**：**理解统一**（NEO-ov——`多模态/多模态微调（PEFT）/05-视觉语言模型VLM架构.md` 04 节——无编码器）；**生成统一**（UniAR/Archon）；**理解-生成全统一**（前沿目标——`多模态/多模态常见问题与缺陷/` 的"多模态 Agent"是应用侧的统一）——**"2026 的统一是多条线的收敛"**。

## 6. 生成模型的评估

生成模型的评估（与理解模型不同——`多模态/多模态基础概念/09-多模态能力评估与基准.md` 的生成维度）：**质量**（FID/IS——图像分布质量）；**对齐**（图文一致性——CLIP 分数/人工）；
**真实性**（Deepfake 检测——生成内容的真实性评估）；**视频**（运动质量/时间一致性）——**"生成评估的难点：质量的主观性"**（FID 是分布指标、人工评测是最终裁判——`多模态/多模态常见问题与缺陷/` 的幻觉在生成的对应——**"生成模型也会幻觉（编造不存在的细节）"**）。

> 🎯 **核心要点**：DiT——扩散骨干换 Transformer（图像生成主流——Sora 类视频生成共同基础——加噪去噪 + 条件）；MM-DiT——图文 token 同序列联合注意力（模态标签——四块交互区——图文互相条件化——token 失衡（TACA 温度缩放）与注意力成本是工程瓶颈）；视频生成——图像生成 + 时间维度 + 多模态条件（LoomVideo——MLLM 条件 + DeepStack + Scale-and-Add 提速 5.41×）；UniAR——统一自回归（BSQ 视觉 tokenizer 32× 压缩——共享上下文桥接理解生成——"统一的关键是视觉 tokenizer"）；Archon——全模态数字人（任意到任意）；统一格局——理解统一（NEO-ov）/生成统一（UniAR）/全统一前沿；生成评估——质量（FID）/对齐/真实性——"生成模型也会幻觉"。
