# 数据格式与处理

> 多模态数据的"接口层"：图像预处理（分辨率/裁剪）、视频帧采样、多模态 chat template、OCR 增强与打包——格式与预处理决定"模型看到了什么"，训练与推理必须一致

## 1. 图像预处理

图像进模型的预处理（`多模态/多模态常见问题与缺陷/07-上下文与工程缺陷.md` 的 token 成本在此落地）：

**分辨率与缩放**：训练分辨率（模型支持的最高分辨率——Qwen-VL 类 1024×1024 级）——**缩放策略**（保持宽高比的 resize + pad；或直接拉伸——按模型要求）；**分辨率与感知的权衡**（`多模态/多模态常见问题与缺陷/02-视觉感知缺陷.md` 的小物体 <32px——低分辨率预处理会放大感知缺陷——**"预处理是感知缺陷的放大器/缩小器"**：细节任务用高分辨率/分块）。

**裁剪**：**随机裁剪（训练增强）vs 中心裁剪（推理固定）**——训练推理一致性（`大模型微调知识体系/基础概念/` 的渲染一致性纪律的多模态版：**图像预处理与推理一致**——"训练 512 推理 1024"的错配 = 模型看到不同的图）；**去边**（空白边缘裁剪——token 成本优化，`多模态/多模态常见问题与缺陷/07-上下文与工程缺陷.md`）。

**增强**：翻转/色彩抖动（训练增强——注意**语义不变增强**（翻转改变文本方向——OCR 任务禁用翻转）——**按任务选增强**（分类可翻转、OCR 不可）。

## 2. 视频帧采样

视频数据的帧处理（04 篇的采样策略在此展开）：**采样策略三选**——**均匀采样**（固定间隔取帧——简单但可能错过关键帧）；**关键帧采样**（场景切换/运动峰值——信息密度高但实现复杂）；**随机采样**（训练增强——多样性）；**训练与推理一致**（"训练 8 帧、推理 32 帧"错配的后果——模型没见过推理形态）。

**帧数与 token 预算**：每帧 ≈ 数百 token（`多模态/多模态常见问题与缺陷/07-上下文与工程缺陷.md` 的图像 token 账本）——**视频的 token 预算 = 帧数 × 每帧 token**（10 秒视频 8 帧 = 数千 token——上下文与成本的第一约束）；**分段处理**（长视频切段——`多模态/多模态 RAG/07-音频与视频RAG.md` 的时间戳分段）。

## 3. 多模态 chat template

多模态数据的对话格式（03 篇的 messages 形态在此展开）：**图像在 content 数组中的位置与多图**（"先图后文"vs"图文交替"——渲染顺序是模板的一部分）；**特殊 token 与图像占位**（模型的图像 token 标记——`<image>` 占位符——训练与推理必须同模板，`大模型微调知识体系/基础概念/08-指令数据与对话格式基础.md` 的模板铁律多模态版）。

**模板一致性检查**（多模态版渲染 diff，`大模型微调知识体系/基础概念/08-指令数据与对话格式基础.md` 03 节）：**训练渲染 vs 推理渲染逐 token 对比**（图像占位位置/数量/顺序——"训练时图在第二张，推理时图在第一张" = 模型错乱）；**多图模板**（图 1 图 2 的编号与顺序——`多模态/多模态常见问题与缺陷/07-上下文与工程缺陷.md` 的逐图标注在模板层的落地）。

## 4. OCR 增强与文档数据

**OCR 增强**（文档类数据的预处理）：**超分辨率**（低分辨率文档图放大——感知边界外推）；**二值化/对比度增强**（扫描件——`多模态/多模态常见问题与缺陷/04-OCR与文档理解缺陷.md` 的扫描质量敏感）；**倾斜校正**（透视/旋转矫正——OCR 的版面前提）。

**文档数据的结构化**：**版面标注**（区域框——训练版面理解的标注数据，`多模态/多模态 RAG/04-文档解析与预处理.md` 的布局层）；**表格标注**（行列结构——Table Transformer 类训练数据）；**图文关系标注**（图表与文中引用的对应——`多模态/多模态 RAG/06-表格与图表RAG.md` 的图表引用——文档 QA 训练的关键标注）。

## 5. 打包与存储

**打包（packing）**（`大模型微调知识体系/基础概念/06-训练循环Epoch-Batch-Step.md` 06 节的多模态版）：**图像不能跨样本打包**（图像是整体——packing 只作用于文本部分）；**视频的打包**（帧序列是整体）；**等长序列的打包注意**（文本块拼接——图像 token 是"不可分割单元"——**打包器的多模态约束**：图像与视频的 token 序列不可切断）。

**存储格式**：**图像引用 vs 内嵌**（数据文件存图像 ID/路径——训练时按 ID 加载——内嵌 base64 体积爆炸）；**数据格式选择**（WebDataset 类流式格式——多模态数据量大，流式读取是标配——`大模型微调知识体系/` 的 JSONL 在多模态的替代：WebDataset/Parquet 类）；**manifest 元数据**（每条的图像分辨率/来源/对齐分数——`大模型微调知识体系/数据集体系（非常重要）/09-数据版本管理与合规治理.md` 的 manifest 多模态版）。

## 6. 处理管线的验收

多模态预处理的验收：**训练-推理一致性测试**（同一图走训练预处理与推理预处理——输出图像应一致（除训练增强）——**"预处理一致性"是渲染 diff 的图像版**）；**token 预算检查**（每样本的图像 token 数——
超预算样本标记/压缩）；**增强有效性**（增强后的样本仍是有效训练样本——翻转后的 OCR 文本方向检查）；**加载性能**（图像加载是数据管线瓶颈——WebDataset 流式 + 预取——`大模型微调知识体系/训练关键超参 & 显存优化技术/09-训练性能优化.md` 的 dataloader 瓶颈多模态版）——**"预处理决定模型看到了什么"**——处理的每步都影响感知与成本。

> 🎯 **核心要点**：图像预处理——分辨率缩放/裁剪（训练推理一致性——"训练 512 推理 1024"错配 = 看到不同的图）/按任务选增强（OCR 禁翻转）；视频帧采样——均匀/关键帧/随机三选 + 训练推理一致 + token 预算（帧数×每帧）；多模态模板——图像在 content 数组的位置/占位符/多图编号——模板一致性检查（渲染 diff 图像版）；OCR 增强（超分/二值化/倾斜校正）+ 文档结构化标注（版面/表格/图文关系）；打包约束——图像视频 token 不可切断（packing 只作用于文本）；存储——引用而非内嵌/WebDataset 流式/manifest 元数据；验收——预处理一致性测试/token 预算/加载性能——"预处理决定模型看到了什么"。
