# 多模态数据集全景与定位

> 多模态数据的类型地图、与文本数据的根本差异（对齐是新维度）、模态分布与规模——先懂"多模态数据特殊在哪"，再学怎么建

## 1. 类型全景

多模态训练数据的五大类型（2026 全景）：

**图文对（Image-Text Pairs）**：图像 + 文本描述的最小单元——预训练（CLIP 类对比学习）的主粮——LAION-5B（58.5 亿对）、ALIGN（18 亿对）、DataComp（组合竞赛池）——**规模最大、噪声最大**（02 篇）。

**多模态指令数据（Instruction Data）**：图 + 指令 + 回答——微调（SFT）的主粮——LLaVA 类（描述/对话/复杂推理三类）——**质量最敏感**（03 篇）。

**视频-文本对（Video-Text）**：视频片段 + 字幕/描述——视频理解与生成——OpenVid-1M、PE-Video（Meta，100 万视频 + 12 万人工验证字幕）、ViMix-14M——**时间维度是新对齐轴**（04 篇）。

**音频-文本（Audio-Text）**：音频 + 转写/描述——语音与音频理解——AudioSet（200 万片段/632 类）、WavCaps（40 万弱标注）、CapSpeech（1000 万机器 + 36 万人工）、Emilia（10 万+ 小时多语言语音）——**转写是主要形态**（04 篇）。

**3D 与科学数据**：3D 场景-描述、科学图表-解析文本（S1-MMAlign：250 万论文 → 1550 万图文对）——**垂直领域的多模态数据**（05 篇）。

## 2. 与文本数据的根本差异：对齐

文本数据（`大模型微调知识体系/数据集体系（非常重要）/`）只有"质量"一个维度——多模态数据多了一个维度：**对齐（Alignment）**——图与文是否描述同一内容：

**对齐的三层含义**：**语义对齐**（图的内容与文本语义一致——"图是猫、文说狗" = 不对齐）；**细粒度对齐**（局部对应——"图中的红色汽车"与文本"红色汽车"的像素级对应——CLIP 类全局对比学习缺乏局部对应是已知局限）；**时序对齐**（视频帧与字幕、音频与转写的时刻对应——04 篇）。

**为什么对齐是"第一质量维度"**：不对齐的样本**主动污染模型**——对比学习把"图猫配文狗"拉近 = 教模型混淆猫狗（比噪声更毒：噪声是无效信息，错位是错误信息）——**"图文对不上，文本再漂亮也是毒数据"**是 00 篇的第一原则。

## 3. 模态分布与规模

千万级多模态数据集的模态分布参考（2026 行业实践）：图文对 52%、视频-字幕 18%、音频-转写 12%、3D-描述 8%、科学图表 10%——**分布不是拍脑袋**：按模型的目标能力配比（通用助手图文为主、语音助手音频占比升、多模态 Agent 加 3D/视频）。

**规模量级**：预训练（图文对）十亿级（LAION 58.5 亿）、指令数据十万-百万级（LLaVA 类 60-160 万）、视频百万级（OpenVid-1M）、音频十万-千万级（CapSpeech 1000 万）——**与文本数据集的量级规律同构**（预训练海量、指令精选——`大模型微调知识体系/数据集体系（非常重要）/01-数据角色与质量第一性原理.md` 的质量>数量原则在多模态同样成立，且有 DataComp 实证，02 篇）。

**模态的"能力-数据"映射**：每个模态的训练数据对应一种能力——图文对 → 跨模态对齐（CLIP 类）；指令数据 → 多模态对话/推理（LLaVA 类）；视频 → 时序理解；音频 → 语音/音频理解——**"想训练什么能力，就准备什么数据"**——多模态数据规划的第一步是**能力清单**（目标模型要会什么），第二步才谈数据（`多模态/多模态微调（PEFT）/` 体系的训练目标在这里定）。

**数据规模与成本的"能力预算"**：每种模态数据的单位成本不同——图文对（抓取便宜、过滤贵）、指令数据（生成贵、需要强模型）、视频（存储与处理重资产）、音频（转写便宜、人工验证贵）——**"能力预算 = 每种能力的成本 × 规模"**——预算有限时按"目标能力的优先级"分配（`大模型微调知识体系/数据集体系（非常重要）/08-数据平衡与多样性.md` 的配比方法论多模态版：配比 = 能力预算，预算给错能力 = 模型在错误方向"偏科"）。

## 4. 多模态数据的"质量-规模"权衡

多模态的质量-规模权衡比文本更尖锐：**规模上限高**（互联网图像 10 亿级可抓）但**噪声上限也高**（抓取的图文对大量不对齐/低质）——**DataComp 实证**（02 篇）：精选 14 亿对胜过原始池——**"规模红利需要过滤兑现"**：原始池的规模优势只有在对齐过滤后才是真实收益。

**2026 的趋势**：**"精选 + 增强"取代"海量 + 生吞"**——MM-LIMA（less is more，03 篇）、VLM-powered 过滤（保留 18% 高精样本）、重标注（recaptioning 提升对齐，05 篇）——**数据管线的重心从"收集"转向"筛选与增强"**——与文本数据体系（`大模型微调知识体系/数据集体系（非常重要）/` 的种子-合成-过滤）同构，多模态版。

**"对齐"与"缺陷"的双向关系**：数据对齐质量与模型缺陷互为因果——**对齐差的数据 → 模型对齐能力弱 → 更多跨模态错误**（`多模态/多模态常见问题与缺陷/06-跨模态对齐与语言先验.md` 的缺陷被数据放大）；**模型的缺陷样本 → 回流为数据**（失败样本库是负样本与评估集素材，08 篇）——**"数据与缺陷是闭环"**：数据管线要消费缺陷反馈（`多模态/多模态常见问题与缺陷/09-评估与缺陷检测.md` 的失败样本库——本体系的评估反馈阶段），缺陷修复靠数据迭代——两个体系在此交汇。

## 5. 多模态数据的生命周期

多模态数据的生命周期（与文本数据体系的版本治理同构，09 篇展开）：**收集 → 清洗（对齐/质量/安全过滤）→ 标注/增强（重标注/合成）→ 格式处理 → 版本化入库 → 评估反馈（缺陷数据回流）**——
每阶段有产物与验收（`大模型微调知识体系/数据集体系（非常重要）/09-数据版本管理与合规治理.md` 的 manifest 方法论在多模态的落地——**多模态 manifest 增加模态字段**（图像来源/分辨率/对齐分数））——**"数据生命周期"是本体系的骨架**（02-08 篇按阶段展开，09 篇管治理）。

> 🎯 **核心要点**：五大类型——图文对（预训练主粮，最大最噪）/指令数据（微调主粮，最敏感）/视频文本（时间对齐轴）/音频文本（转写形态）/3D 与科学（垂直）；与文本数据根本差异——**对齐是新维度**（语义/细粒度/时序三层——不对齐是错误信息比噪声更毒）；模态分布按目标能力配比；规模规律同构（预训练海量、指令精选）；质量-规模权衡更尖锐——DataComp 实证"规模红利需要过滤兑现"；2026 趋势"精选+增强"取代"海量+生吞"；生命周期（收集→清洗→标注→格式→版本→评估）是体系骨架，manifest 增加模态字段。
