# 多模态指令数据

> 多模态微调的主粮：LLaVA 类三类构成（描述/对话/复杂推理）、MM-LIMA 的"less is more"质量指标（响应长度权重 58.6%）、VLM-powered 过滤——指令数据的质量决定微调效果

## 1. 三类构成：LLaVA 范式

多模态指令数据（SFT 主粮）的 LLaVA 范式——三类数据构成：

**描述类（Captioning）**：图 → 详细描述（"描述这张图的场景"）——教会模型"看图说话"——规模最大、最容易生成（MLLM 批量生成）——**质量风险**：描述泛泛（"一张照片里有几个人"——缺乏细节 = 低信息量样本）。

**对话类（Conversation）**：图 + 多轮问答（"图里有什么颜色？""那个人在做什么？"）——教会模型"看图对话"——**质量风险**：问题与图无关（通用问题模板硬套图）——对齐检查的必要性（01 篇的对齐维度）。

**复杂推理类（Complex Reasoning）**：图 + 推理问题（"根据图中的数据推断趋势"）——教会模型"看图推理"——最贵最难（需要人工或强模型生成）——**质量风险**：推理与图脱节（模型"看着图编推理"——`多模态/多模态常见问题与缺陷/03-视觉幻觉.md` 的感知缺口问题在数据侧的体现）。

**三类配比**：描述 50-60%、对话 30%、复杂推理 10-20%——**推理类占比越高，模型推理能力越强但数据成本越高**（按目标能力配比，01 篇的模态分布原则）。

## 2. 指令数据的生成方式

**生成路线**（2026 实践）：**MLLM 生成 + 过滤**（主流）——用强 MLLM（GPT-4V 类）看图生成指令-回答对（LLaVA 的原始路线）→ 过滤（质量/对齐）→ 人工抽验；**人工标注**（小规模高质量——金标评估集与种子集，`大模型微调知识体系/数据集体系（非常重要）/03-数据获取三大路径.md` 的人工种子方法论）；**复用改写**（现有数据集改写为指令形态）。

**生成的质量陷阱**：**模板化**（同模板批量生成 → 模型学会模板而非看图——与文本合成数据的模板陷阱同构，`大模型微调知识体系/数据集体系（非常重要）/03-数据获取三大路径.md` 04 节）；**自说自话**（MLLM 生成的问题-回答自洽但与图无关——对齐检查必须）；**幻觉污染**（生成描述含幻觉内容 → 教模型幻觉——`多模态/多模态常见问题与缺陷/` 的幻觉问题在数据侧源头）。

## 3. MM-LIMA：less is more 的质量指标

**MM-LIMA**（2026，多模态版 LIMA）：用**熵权法聚合多个指标**选择高质量多模态指令数据——在 ALLaVA 数据集上的指标权重实证：

| 指标 | 权重 |
|------|:---:|
| 响应长度 | 58.6% |
| 奖励分数（reward score） | 16.2% |
| 幻觉分数 | 13.1% |
| CLIP 分数（图文对齐） | 7.1% |
| 困惑度 | 5.0% |

**读法**：**响应长度/类人度是最有影响力的质量信号**（58.6%——与文本 LIMA"长而具体"的结论一致）；**幻觉分数与图文对齐是补充信号**（13.1% + 7.1%——多模态特有维度）；**局限**（论文自述）：只处理图像描述类数据，不覆盖 OCR/图像定位类（`多模态/多模态 RAG/` 的任务类型提醒——质量指标要按数据类型适配）。

**"less is more"的多模态结论**：精选的小型高质量指令集优于大规模泛数据（与文本 LIMA 同构，`大模型微调知识体系/数据集体系（非常重要）/01-数据角色与质量第一性原理.md` 的 1000 条实证）——**指令数据是"宁缺毋滥"最严格的类型**。

## 4. VLM-powered 过滤：模型打分级裁判

**VLM-powered 过滤**（2026）：用紧凑 VLM（如微调过的 Qwen2-VL-2B）做**打分级裁判**——教师模型提供连续分数（s∈[1,10] + 理由）训练裁判 VLM → 裁判对图文对打分 → **高精度阈值（s≥9）保留 ~18%** 的候选——过滤后子集的 CLIP 相似度更高（0.313 vs 0.298）、困惑度更低（137.2 vs 170.2）、**下游模型效果优于全量/随机集**。

**工程价值**：轻量 VLM 推理（H100 上 ~100-200 对/秒）——**规模化过滤可行**；与文本体系的 LLM judge（`大模型微调知识体系/数据集体系（非常重要）/07-数据质量评估与筛选.md`）同构——**"打分级裁判"从文本扩展到多模态**；**注意**：裁判质量（教师分数的一致性、裁判与教师的对齐——定期抽验，`大模型微调知识体系/数据集体系（非常重要）/07-数据质量评估与筛选.md` 03 节的 judge 校准纪律）。

## 5. 指令数据的格式

多模态指令数据的标准格式（与文本 messages 格式的多模态扩展，`大模型微调知识体系/基础概念/08-指令数据与对话格式基础.md`）：

```json
{"messages": [
  {"role": "user", "content": [
     {"type": "image", "image": "图的位置/URL/base64"},
     {"type": "text", "text": "描述这张图"}
  ]},
  {"role": "assistant", "content": "这是一张……"}
]}
```

**关键点**：**图像在消息内容里的位置**（与文本并列——多模态 chat template 的渲染顺序，07 篇）；**多图消息**（内容数组多个 image 条目——`多模态/多模态常见问题与缺陷/07-上下文与工程缺陷.md` 的多图集成）；**图像标识**（文件名/ID 而非内嵌 base64 存数据——存储与传输成本）；**对齐标注**（每条数据的 CLIP 分数/来源/生成模型版本进元数据——`大模型微调知识体系/数据集体系（非常重要）/09-数据版本管理与合规治理.md` 的 manifest 多模态版）。

## 6. 指令数据的生产检查

多模态指令数据的验收（`大模型微调知识体系/数据集体系（非常重要）/07-数据质量评估与筛选.md` 的多模态版）：**对齐抽验**（随机 50 条人工看图对文——"描述与图一致吗"——第一检查）；**模板多样性**（同模板样本占比——
模板化检测）；**幻觉抽验**（描述中的具体断言与图核对——"图里真有这个吗"）；**推理与图的相关性**（复杂推理样本的推理是否基于图）；**配比检查**（三类数据占比 vs 目标）——**五项全过才进训练**（与文本数据体系的"规则查规则、人查感觉"同构——`多模态/多模态常见问题与缺陷/01-问题全景与诊断方法论.md` 的图文消融在数据验收的复用）。

> 🎯 **核心要点**：LLaVA 三类——描述（看图说话，最大最易）/对话（看图问答）/复杂推理（看图推理，最贵最易脱节）——配比按目标能力；生成路线——MLLM 生成+过滤主流（模板化/自说自话/幻觉污染三陷阱）；MM-LIMA 熵权指标——响应长度 58.6% 主导（与文本 LIMA 同构）、幻觉 13.1% + CLIP 对齐 7.1% 是多模态特有维度、"less is more"在指令数据最严格；VLM-powered 过滤——裁判 VLM 打分（s≥9 保留 18%、下游效果实证更优、H100 百对/秒规模化可行）；格式——多模态 messages（图像与文本并列在 content 数组）、对齐标注进元数据；生产五查——对齐抽验/模板多样性/幻觉抽验/推理相关性/配比。
