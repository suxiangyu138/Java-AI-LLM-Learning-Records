# 构建管线与合成数据

> 多模态数据从"收集"到"可用"的完整管线：多阶段构建、重标注（recaptioning 的质量跃迁）、合成数据、知识图谱结构化、人工标注——2026 年管线重心从"收集"转向"筛选与增强"

## 1. 多阶段构建管线

多模态数据的标准构建管线（与 `大模型微调知识体系/数据集体系（非常重要）/01-数据角色与质量第一性原理.md` 的流水线思想同构，多模态版）：

```text
原始收集（抓取/现有库）→ 基础过滤（语言/尺寸/格式）→ 对齐过滤（CLIP 分数）
→ 质量过滤（VLM 裁判/12 维评分）→ 安全与隐私过滤（NSFW/人脸模糊）
→ 去重 → 重标注/增强 → 格式处理 → 版本化入库（manifest）
```

**管线的工程化纪律**（与文本体系一致）：**每步有产物与统计**（剔除比例/原因分布）；**可重跑**（脚本化——数据迭代重跑管线）；**增量更新**（新数据只走变更路径）——`大模型微调知识体系/数据集体系（非常重要）/04-数据清洗.md` 的规则库方法论在此复用（多模态的规则库增加：图像质量规则/对齐阈值/模态特定规则）。

## 2. 重标注（Recaptioning）：质量跃迁

**重标注**是 2026 多模态数据最重要的质量手段：**用 MLLM 重新生成图文对/视频/音频的描述**（替代或增强原始 alt-text/字幕）。

**为什么重标注有效**：原始描述（alt-text/字幕）是"网页语境"的（SEO 堆砌/上下文相关但图无关）——**MLLM 重标注是"看图说话"**（描述与图内容直接对齐）——**S1-MMAlign 实证**（2026-01）：250 万论文 → 1550 万图文对（MLLM 从摘要与引用上下文重标注科学图表）——降低伪困惑度、提升 CLIP 对齐、改善零样本科学描述与视觉指令微调。

**重标注的实践要点**：**教师模型选择**（强 MLLM 生成、弱 MLLM 兜底——教师偏差继承，`大模型微调知识体系/数据集体系（非常重要）/03-数据获取三大路径.md` 的合成数据三坑在多模态的对应）；**描述粒度**（简要 + 详细双粒度——VideoUFO 范式）；**重标注验证**（抽验重标注描述与原图的对应——`大模型微调知识体系/数据集体系（非常重要）/07-数据质量评估与筛选.md` 的 judge 校准）。

## 3. 合成数据

多模态合成数据的三条路线（2026）：

**图生成文**（主流）：MLLM 看图生成指令/描述——LLaVA 类指令数据的主来源（03 篇）；**文生图再配文**（反路线）：生成图像 + 描述（可控场景/长尾概念补充——合成图的质量与真实性是风险）；**受控生成**（研究级）：潜变量 DAG/流模型生成**互信息可解析计算**的数据——基准测试的精确控制。

**合成数据的三坑**（`大模型微调知识体系/数据集体系（非常重要）/03-数据获取三大路径.md` 的多模态版）：**教师偏差继承**（合成数据继承生成模型的感知局限——"教师看不见小物体，学生也学不会"——`多模态/多模态常见问题与缺陷/02-视觉感知缺陷.md` 的缺陷通过数据继承）；**模式坍缩**（合成分布窄——真实分布覆盖不足）；**幻觉污染**（生成描述含幻觉——教模型幻觉，03 篇）——**合成数据必须过滤 + 真实数据锚定**（与文本体系同构）。

## 4. 知识图谱结构化

**知识图谱结构化**（2026 趋势）：把多模态数据组织进知识图谱（UKnow 类）——五种关系：**图内**（图像内部元素关系）、**文内**（文本内部）、**跨图**（多图对应）、**跨文**（多文档对应）、**图文接地**（image-text grounding——图与文的元素级对应）——**从"图文对"升级到"图文关系图"**——支撑多跳推理与检索（`多模态/多模态 RAG/05-多模态RAG架构设计.md` 的证据图思想在数据侧的落地）。

**工程价值**：**图结构数据是检索与推理的基础设施**（多模态 RAG 的证据图直接消费）；**构建成本高**（关系抽取是额外标注任务）——**适合强结构化场景**（科学文献/法律文档——S1-MMAlign 类的领域）。

## 5. 人工标注的角色

多模态数据的人工标注在 2026 的位置：**不是规模来源，是质量锚点**——三类锚点任务：**金标评估集**（人工编写/审核——`大模型微调知识体系/完整微调工程流程/03-评估先行基线建立.md` 的评估集方法论，08 篇展开）；
**抽验集**（人工抽验自动管线的输出——对齐/质量抽验——"规则查规则、人查感觉"）；**种子集**（人工编写的少量高质量样本——合成生成的种子，`大模型微调知识体系/数据集体系（非常重要）/03-数据获取三大路径.md` 的种子方法论）——**"人工标注的 ROI 在锚定不在规模"**（2026 共识）。

## 6. 管线验收与迭代

管线的验收（构建完成后）：**分布检查**（模态占比 vs 目标）；**质量抽验**（对齐/质量/安全三抽验）；**下游验证**（小模型/小步数训练对比——"管线产出 → 训练效果"的闭环验证，`大模型微调知识体系/完整微调工程流程/` 的冒烟方法论）；
**迭代**（下游验证暴露的缺陷 → 回管线补规则——"数据管线的成熟度 = 迭代轮数"，`大模型微调知识体系/数据集体系（非常重要）/07-数据质量评估与筛选.md` 05 节的闭环）——**"管线是活的"**（每轮迭代都在补盲区）。

> 🎯 **核心要点**：多阶段管线（收集→基础过滤→对齐过滤→质量过滤→安全→去重→重标注→格式→版本）——每步产物与统计、可重跑、增量；重标注是 2026 最重要的质量手段（S1-MMAlign 实证：250 万论文 → 1550 万对、CLIP 对齐提升）——"原始 alt-text 只是起点"；合成三路线（图生成文主流/文生图补长尾/受控生成研究级）+ 三坑（教师偏差继承/模式坍缩/幻觉污染）——必须过滤 + 真实锚定；知识图谱结构化（UKnow 五关系——从图文对到图文关系图）；人工标注是质量锚点不是规模来源（金标/抽验/种子三类）；管线验收（分布/抽验/下游验证）+ 迭代闭环——"管线是活的"。
