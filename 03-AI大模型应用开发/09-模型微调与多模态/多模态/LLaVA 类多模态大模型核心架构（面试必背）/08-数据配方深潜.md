# 数据配方深潜

> LLaVA 家族的数据配方：三类指令数据（描述/对话/推理）、665K 构成（158K 对话/50K GQA 等）、760K → 5.2M 规模演进、GPT-4 合成数据的开创——"数据是 LLaVA 的第三遗产"

## 1. 三类指令数据

LLaVA 家族的指令数据分类（`多模态/多模态数据集/03-多模态指令数据.md` 的 LLaVA 范式源头——三类构成）：

**描述类（Captioning）**：图 → 详细描述——教会"看图说话"——规模最大、最易生成（GPT-4 批量生成——`多模态/多模态数据集/03-多模态指令数据.md` 的 MLLM 生成）；**对话类（Conversation）**：图 + 多轮问答——教会"看图对话"——158K（1.5 的对话量——`多模态/多模态数据集/03-多模态指令数据.md` 的对话类）；**复杂推理类（Complex Reasoning）**：图 + 推理问题——教会"看图推理"——最贵最难——1.5 的推理任务样本——**"三类配比决定能力分布"**（`多模态/多模态数据集/03-多模态指令数据.md` 01 节的配比——描述 50-60%/对话 30%/推理 10-20% 的雏形）。

## 2. 665K 的构成

LLaVA 1.5 的 665K 指令数据构成（`多模态/多模态数据集/03-多模态指令数据.md` 的数据构成源头）：**158K 对话**（GPT-4 生成的多轮视觉对话——
LLaVA 1.0 的开创）；**50K GQA 风格 QA**（视觉问答——`多模态/多模态基础概念/09-多模态能力评估与基准.md` 的 GQA 基准风格）；
**推理任务**（复杂推理类）；**其余**（描述类/其他 QA——llava_v1_5_mix665k 的混合集——`多模态/多模态微调（PEFT）/04-多模态微调配方.md` 01 节的 665K 引用）——**"665K = 对话（行为）+ QA（理解）+ 推理"**（覆盖 VLM 的核心行为——`多模态/多模态基础概念/07-指令遵循与多模态推理.md` 的能力阶梯）。

**数据构成的启示**：**"指令数据的配比 = 能力的配比"**（`多模态/多模态数据集/08-数据平衡与多样性.md` 的配比方法论——模型会什么 = 数据教了什么——`多模态/多模态基础概念/01-多模态模型全景与定位.md` 的"能力上限 ×"中的行为维度）。

**数据配比的评估验证**：配比的效果可测——**数据配比 → 评估集的对应能力分数**（`多模态/多模态基础概念/09-多模态能力评估与基准.md` 的能力维度——对话类数据多 → MM-Bench 对话类分数高；推理类数据少 → 推理类分数低——**"配比与能力分数的对账"**（`多模态/多模态微调（PEFT）/09-多模态微调评估.md` 的双评估集——能力分数暴露配比缺口——`多模态/多模态常见问题与缺陷/03-数据类问题.md` 的偏科漏斗定位——LLaVA 的数据配比演进（推理类占比上升）与基准推理分数提升对应）。

## 3. 760K → 5.2M：规模演进

LLaVA 家族的数据规模演进（`多模态/多模态基础概念/01-LLaVA家族演进史.md` 的数据主线）：**760K（1.5）→ 4M+（NeXT 的 Stage-1.5 扩展）→ 5.2M（OneVision——3.2M 单图指令 + 1.6M OneVision 多场景（含 0.35M 视频）+ Stage-1 的 558K + Stage-1.5 的 4M 知识）**——**"数据规模 × 结构化（多阶段课程）双演进"**。

**规模演进的含义**：**"更多数据 + 更结构化的数据"**（`多模态/多模态数据集/01-多模态数据集全景与定位.md` 的"精选 + 增强"趋势——OneVision 的 5.2M 是数据规模化的代表——`多模态/多模态数据集/05-构建管线与合成数据.md` 的重标注/合成方法论——OneVision 的 350 万自标注图 + 110 万 OCR——`多模态/多模态数据集/03-多模态指令数据.md` 的 VLM-powered 过滤）。

**规模演进与"质量优先"的张力**：数据规模的增长是否违背"质量 > 数量"（`多模态/多模态数据集/01-多模态数据集全景与定位.md` 的 DataComp 实证）？——不违背：5.2M 是"多阶段结构化"的（对齐 → 知识 → 指令——每阶段有质量门槛——`多模态/多模态数据集/03-多模态指令数据.md` 的质量过滤）——"规模是结构化的规模"（原始堆积 vs 课程化——OneVision 是后者——数量增长的同时质量机制同步——规模与质量的正确关系不是非此即彼）。

## 4. GPT-4 合成数据的开创

**LLaVA 1.0 的开创**（数据路线的里程碑）：**用 GPT-4 生成指令数据**（GPT-4 看图 → 生成描述/对话/推理——`多模态/多模态数据集/03-多模态指令数据.md` 的 MLLM 生成 + 过滤路线）——**"开源模型的训练数据可以来自闭源模型生成"**——**影响**：合成指令数据成为 2026 主流的源头（`多模态/多模态数据集/03-多模态指令数据.md` 的生成路线——LLaVA 验证了可行性——后续 Qwen-VL 类都沿用）。

**合成数据的注意**（`多模态/多模态数据集/03-多模态指令数据.md` 的生成三陷阱）：**模板化**（GPT-4 生成的模板痕迹——`多模态/多模态数据集/03-多模态指令数据.md` 02 节）；**教师偏差**（GPT-4 的感知局限被继承——`多模态/多模态数据集/05-构建管线与合成数据.md` 的教师偏差继承）；**幻觉污染**（生成描述含幻觉——`多模态/多模态数据集/03-多模态指令数据.md` 的幻觉污染——**"LLaVA 的合成数据路线也要过滤"**（`多模态/多模态数据集/06-数据清洗与质量评估.md` 的 VLM 裁判过滤——2026 的过滤手段是 1.0 时代的补强）。

## 5. 数据与效果的对应

LLaVA 数据配方的效果验证（`多模态/多模态基础概念/09-多模态能力评估与基准.md` 的基准）：**1.5 的 760K → VQA/GQA/ScienceQA/TextVQA/POPE SOTA**（`多模态/多模态基础概念/02-LLaVA1.5经典配方.md` 04 节）；
**NeXT 的数据混合消融**（`多模态/多模态基础概念/03-LLaVA-NeXT动态分辨率.md` 03 节——数据配比的效果差异）；**OneVision 的 5.2M → 多场景基准**（视频/多图/交错）——**"数据规模的提升可测"**（每个版本的数据变化对应基准变化——`多模态/多模态数据集/08-多模态评估数据.md` 的评估集演进）。

## 6. 面试必答：LLaVA 数据三问

面试的 LLaVA 数据三问：**1) 数据怎么来**（GPT-4 生成 + 现成数据集混合——`多模态/多模态数据集/03-多模态指令数据.md` 的生成路线）；
**2) 三类构成与配比**（描述/对话/推理——配比决定能力）；**3) 规模怎么演进**（158K → 760K → 5.2M——规模 × 结构化）——**"数据三问 = 来源 → 构成 → 演进"**（与 `多模态/多模态基础概念/` 的数据方法论呼应——LLaVA 是数据配方的实证案例）。

> 🎯 **核心要点**：三类指令数据——描述（看图说话）/对话（看图问答）/推理（看图推理）——配比决定能力分布；665K 构成——158K 对话 + 50K GQA + 推理 + 描述混合（llava_v1_5_mix665k）——"模型会什么 = 数据教了什么"；规模演进——760K → 4M+ → 5.2M（多阶段课程——规模 × 结构化双演进）；GPT-4 合成数据的开创（LLaVA 1.0——"开源模型的训练数据可以来自闭源模型生成"——2026 主流的源头——但三陷阱（模板化/教师偏差/幻觉污染）要过滤）；效果可测（每版本数据变化对应基准变化）；面试数据三问——来源 → 构成 → 演进。
