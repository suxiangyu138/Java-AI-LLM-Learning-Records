# LLaVA 1.5：经典配方

> 开源 VLM 的"标准答案"：三组件（CLIP ViT-L/336 + MLP 投影 + Vicuna）、两阶段训练（558K 对齐 1e-3 → 665K SFT 2e-5）、760K 数据——"frozen 编码器 + MLP + LLM 微调"成为领域默认起点

## 1. 三组件架构

LLaVA 1.5 的架构（2023-10，经典配方的定型）：

**视觉编码器**：**CLIP ViT-L/336**（`多模态/多模态基础概念/02-视觉编码器与图像tokenization.md` 的 CLIP——对比学习预训练——336² 分辨率——576 视觉 token）——**冻结**（训练不动——`多模态/多模态微调（PEFT）/02-VLM结构与可微调部件.md` 的冻塔理由）；**投影层**：**两层 MLP（Linear → GELU → Linear）**（替换 1.0 的单层线性——更强的视觉-语言映射——`多模态/多模态基础概念/04-投影层与视觉语言桥接.md` 的 MLP 投影）；**语言塔**：**Vicuna-7B/13B**（LLaMA 微调的对话模型——`多模态/多模态基础概念/` 的语言塔）——**预训练 LLM（微调）**——**融合机制**：视觉 token 与文本 token 拼接后由 **LLM 的自注意力统一处理（无交叉注意力适配器）**——"所有跨模态混合由 LLM 自注意力完成"——**"三组件 + LLM 自注意力融合 = LLaVA 范式的核心"**。

**组件职责**（`多模态/多模态微调（PEFT）/02-VLM结构与可微调部件.md`）：编码器管感知（冻结）、投影管对齐（阶段一训练）、语言塔管行为（阶段二微调）——**"1.5 把三组件的分工固定为默认"**。

**架构的"组合创新"本质**：LLaVA 1.5 的组件都是现成的（CLIP 编码器/MLP/LLM——`多模态/多模态微调（PEFT）/01-多模态微调全景与定位.md` 的模块化优势）——**创新在"组合与配方"而非"新组件"**——**"架构的价值 = 组件的正确组合 + 训练的正确配方"**（`多模态/多模态基础概念/05-视觉语言模型VLM架构.md` 的模块化——组件可替换的验证——1.5 证明了"不需要新架构、需要正确的组合"——这是 LLaVA 对领域最重要的方法论贡献（组合 > 创新）。

## 2. 两阶段训练

LLaVA 1.5 的两阶段（`多模态/多模态微调（PEFT）/04-多模态微调配方.md` 的配方源头）：

**阶段一：特征对齐预训练**——**只训 MLP 投影层**（~20M 参数），编码器与语言塔冻结——**558K 图文对**（LAION-CC-SBU 子集——`多模态/多模态数据集/02-图文对数据.md`）——**lr 1e-3**（高——投影层从零学对齐）——产出 mm_projector.bin；**阶段二：视觉指令微调（SFT）**——**放开语言塔**（与投影联合训练），编码器冻结——**665K 指令样本**（`多模态/多模态数据集/03-多模态指令数据.md` 的 LLaVA 指令数据）——**lr 2e-5**（低——保护语言能力）、1 epoch、cosine + 0.03 warmup、bf16——loss 只算 assistant token（-100 掩码）。

**阶段间 lr 差 50 倍的原因**（`多模态/多模态微调（PEFT）/04-多模态微调配方.md` 01 节）：阶段一投影从零学（大步快跑）；阶段二语言塔已有能力（小步保护）——**"同一个模型的两个阶段，学习率是两个世界"**——面试必答。

## 3. 760K 数据构成

LLaVA 1.5 的训练数据（760K 总量，`多模态/多模态数据集/03-多模态指令数据.md` 的 LLaVA 三类构成源头）：
**558K 图文描述**（阶段一——LAION-CC-SBU 子集）；**158K 对话**（GPT-4 生成的多轮视觉对话——LLaVA 1.0 开创的数据形态）；**50K GQA 风格 QA**（视觉问答）；**推理任务**（复杂推理类）——**"760K = 描述（对齐）+ 对话（行为）+ QA（理解）+ 推理"**——三类构成（描述/对话/推理）的配比雏形（`多模态/多模态数据集/03-多模态指令数据.md` 01 节）。

**数据的意义**：**GPT-4 生成的指令数据**（LLaVA 1.0 的开创——用强模型生成训练数据——`多模态/多模态数据集/03-多模态指令数据.md` 的 MLLM 生成 + 过滤——**"LLaVA 验证了合成指令数据的可行性"**（开源模型的训练数据可以来自闭源模型生成——2026 仍是主流路线）。

## 4. SOTA 影响

LLaVA 1.5 的影响（2023-10 发布时）：**VQA/GQA/ScienceQA/TextVQA/POPE 达 SOTA**（`多模态/多模态基础概念/09-多模态能力评估与基准.md` 的基准——
POPE 幻觉基准在 1.5 时代即为评估项）；**13B 规模接近 GPT-4V**（`多模态/多模态基础概念/` 的闭源对比——开源追赶的里程碑）；**配方成为领域默认**（后续 VLM（含 Qwen-VL/InternVL 的早期）普遍遵循"frozen 编码器 + MLP + LLM 微调"——**"1.5 定义了开源多模态的默认起点"**）。

**影响的本质**：**不是某一个创新（组件都是现成的——CLIP/MLP/LLM），而是组合的验证**——"把已有的对齐模型 + 投影 + LLM 用两阶段配方组合，能达到接近 GPT-4V 的效果"——**"LLaVA 1.5 是'组合创新'的典范"**（`多模态/多模态基础概念/01-多模态模型全景与定位.md` 的模块化优势——组件可替换的验证）。

**影响的工程意义**：**组合创新让后来者受益**——"不需要从零发明，按配方组装"（`多模态/多模态微调（PEFT）/08-多模态微调工程实践.md` 的"组装而非造轮子"——LLaVA 验证了组装路线的可行性——企业/研究者用现成组件 + LLaVA 配方快速搭建 VLM——**"1.5 的遗产是'组装路线'的合法化"**（在 1.5 之前，多模态模型多是"从零设计"；1.5 之后"组件组装 + 配方"成为默认——`多模态/多模态基础概念/01-多模态模型全景与定位.md` 的生态——开源 VLM 的快速迭代建立在组装路线上）。

## 5. 面试必答：LLaVA 1.5 为什么重要

面试"LLaVA 1.5 为什么是里程碑"的完整答案：**架构定型**（三组件 + LLM 自注意力融合——后续 VLM 的骨架）；**配方验证**（两阶段 + lr 50 倍差——训练方法论的基准）；**数据验证**（GPT-4 合成指令数据可行——数据路线的标杆）；**效果验证**（13B 接近 GPT-4V——开源追赶的证明）——**"四个验证"结构**（架构/配方/数据/效果——覆盖面试官想听的全部维度）。

## 6. 1.5 的局限与后续

LLaVA 1.5 的局限（驱动后续演进）：**固定分辨率**（336²——文档/图表细粒度不足——NeXT 的 AnyRes 动机）；
**单图**（不支持多图/视频——OneVision 的动机）；**数据规模**（760K——后续 5.2M）；**底座**（Vicuna——后续 Qwen 系）——**"1.5 的每个局限对应后续版本的一个创新"**（`多模态/多模态基础概念/01-LLaVA家族演进史.md` 的缺陷驱动——演进史与 1.5 局限一一对应）。

> 🎯 **核心要点**：三组件——CLIP ViT-L/336（冻结）+ 两层 MLP（阶段一训）+ Vicuna-7B/13B（阶段二微调）——"所有跨模态混合由 LLM 自注意力完成（无交叉注意力）"；两阶段——对齐（只训投影 558K 1e-3）→ SFT（放开语言塔 665K 2e-5——lr 差 50 倍——loss 只算 assistant）；760K 数据——558K 描述 + 158K 对话 + 50K GQA + 推理——GPT-4 合成指令数据的开创；影响——四验证（架构/配方/数据/效果）——13B 接近 GPT-4V、配方成领域默认——"组合创新的典范"；局限——固定分辨率/单图/760K——每个局限对应后续一个创新。
