# 训练配方深潜

> LLaVA 家族的训练配方：两阶段 lr 体系（1e-3/2e-5——差 50 倍）、LLaVATrainer 特化（模态长度分组/投影层独立 lr）、分离 lr（视觉 2e-6/语言 1e-5）、冻结策略——"配方是 LLaVA 家族的第二遗产"

## 1. 两阶段 lr 体系

LLaVA 家族的 lr 配方（`多模态/多模态微调（PEFT）/04-多模态微调配方.md` 的配方源头——面试必答）：

**阶段一（对齐）lr 1e-3**：只训投影层（~20M 参数）——**从零学对齐**（投影是全新组件——大步快跑——`大模型微调知识体系/基础概念/05-优化器与梯度更新.md` 的 lr 逻辑）；**阶段二（SFT）lr 2e-5**：放开语言塔——**保护已有能力**（`大模型微调知识体系/基础概念/05-优化器与梯度更新.md` 的"底座已收敛"——`多模态/多模态微调（PEFT）/06-多模态微调的常见问题.md` 的融合保护）——**lr 差 50 倍的机制**："阶段一学新组件（大 lr）、阶段二保旧能力（小 lr）"——**"同一个模型的两个阶段，学习率是两个世界"**。

**OneVision 的分离 lr**（`多模态/多模态基础概念/04-LLaVA-OneVision统一多场景.md` 05 节）：视觉 2e-6、语言 1e-5——**视觉 lr 比语言低 5 倍**——**"视觉更脆弱"**（动一点就破坏对齐——`多模态/多模态微调（PEFT）/02-VLM结构与可微调部件.md` 的破坏对齐理由——分离 lr = 不同组件不同保护等级——视觉塔若训必须极小步）。

## 2. LLaVATrainer 特化

**LLaVATrainer**（LLaVA 的 Trainer 扩展——`多模态/多模态微调（PEFT）/04-多模态微调配方.md` 04 节的工程特化源头）：

**模态长度分组采样（modality-length-grouped sampling）**：图像样本与文本样本分 batch（`多模态/多模态微调（PEFT）/04-多模态微调配方.md` 04 节——图像 token 数百到上千——混批 padding 浪费——分批减少浪费、提升效率）——**注意**：分组是"按模态分批"而非"模态隔离"（每批内仍可有图有文——只是长度相近的组在一起——`多模态/多模态微调（PEFT）/08-多模态微调工程实践.md` 的批处理思想——训练侧的模态长度分组与推理侧的按 token 预算批处理（`多模态/多模态推理部署工程/04-多模态服务架构.md` 03 节）是同一原则的两个应用——"按 token 成本分组"）；**投影层独立学习率（mm_projector_lr）**：四组优化器参数组（语言塔 lr/投影层 lr/视觉塔 lr/权重衰减——`多模态/多模态微调（PEFT）/04-多模态微调配方.md` 04 节——"不同组件不同 lr"的框架支持）；**自定义 checkpoint 保存**（mm_projector.bin 单独保存——`多模态/多模态微调（PEFT）/08-多模态微调工程实践.md` 的 non_lora_trainables 实践）——**"LLaVATrainer 把多模态配方固化为代码"**（`多模态/多模态微调（PEFT）/` 的工程化——配方的可复现载体）。

## 3. 冻结策略

LLaVA 家族的冻结策略（`多模态/多模态微调（PEFT）/02-VLM结构与可微调部件.md` 的组件策略在 LLaVA 的落地）：
**阶段一全冻（只训投影）**；**阶段二冻编码器 + 训语言塔（+投影）**——**"编码器全程冻结"**（1.5/NeXT/OneVision 都保持——`多模态/多模态微调（PEFT）/02-VLM结构与可微调部件.md` 的冻塔两理由——浪费适配器/破坏对齐）；**OneVision 的视觉塔解冻**（视觉 lr 2e-6——极小步——`多模态/多模态微调（PEFT）/03-LoRA在多模态上的应用.md` 的"专门视觉域才训塔"——OneVision 是"解冻但极小步"的中间态）。

**冻结与 LoRA 的关系**（`多模态/多模态微调（PEFT）/03-LoRA在多模态上的应用.md`）：微调 LLaVA 系的默认 = 冻塔 + LoRA 语言塔（0.1-0.6%）——**"LLaVA 的架构天然适配 LoRA"**（编码器冻结省显存——`多模态/多模态微调（PEFT）/08-多模态微调工程实践.md` 的显存账本——冻塔省视觉塔梯度与状态——"LLaVA + LoRA = 单卡微调的标准组合"）。

## 4. 配方参数完整清单

**配方的"知识库地位"**：LLaVA 配方是 `多模态/多模态微调（PEFT）/04-多模态微调配方.md` 的源头——**"微调体系的配方章节以 LLaVA 配方为原型"**（两阶段/lr 差 50 倍/模态分组/投影独立 lr——微调体系的每个配方概念都对应 LLaVA 的一个设计）——**"学 LLaVA 配方 = 学微调配方的原型"**（面试答微调配方时带出 LLaVA 原型——深度加分——"LLaVA 是 VLM 的 LIMA"——配方同样）。

LLaVA 家族配方参数（`多模态/多模态微调（PEFT）/04-多模态微调配方.md` 05 节的清单在 LLaVA 的落地）：
**阶段**（两段/三段（+Stage-1.5）/OneVision 三段课程）；**lr**（阶段一 1e-3、阶段二 2e-5、视觉 2e-6）；**epoch**（1——SFT 惯例——`多模态/多模态微调（PEFT）/` 的 1 epoch）；**batch**（16-32 + 累积）；**调度**（cosine + 0.03 warmup）；**精度**（bf16）；**采样**（模态长度分组）；**loss**（只算 assistant——-100 掩码——`大模型微调知识体系/基础概念/04-损失函数与训练目标.md`）——**"配方清单 = 可复现的 LLaVA 训练"**。

## 5. 配方与微调的映射

LLaVA 配方的微调应用（`多模态/多模态微调（PEFT）/` 的实践）：**企业微调 LLaVA 系**（用现成底座——
跳过阶段一——`多模态/多模态微调（PEFT）/04-多模态微调配方.md` 06 节的两阶段可合并——
直接 SFT lr 2e-5）；**QLoRA 单卡**（`多模态/多模态微调（PEFT）/08-多模态微调工程实践.md` 的组合——视觉塔保持高位宽）；**层选择性**（编码类微调——`多模态/多模态微调（PEFT）/03-LoRA在多模态上的应用.md` 02 节——下半层冻结保融合——gemma4 实证——LLaVA 系同样适用）。

**"配方是死的、应用是活的"**（LLaVA 的原始配方是起点——企业按场景调整——`多模态/多模态微调（PEFT）/01-超参全景与调参方法论.md` 的复验纪律——抄配方带验证集复验——LLaVA 的 1e-3/2e-5 是"起点不是终点"）。

## 6. 面试必答：两阶段训练

面试"LLaVA 为什么两阶段"的标准答案：**阶段一解决"对齐"**（投影从零学——编码器特征与语言嵌入的映射——图文对数据——
`多模态/多模态基础概念/03-跨模态对齐与对比学习.md` 的对齐）；**阶段二解决"行为"**（指令微调——`多模态/多模态微调（PEFT）/` 的 SFT——语言塔学指令遵循）——**"先对齐后行为"**（没有对齐，行为微调无从谈起——视觉特征没翻译好，语言塔学的是"错的内容"——`多模态/多模态微调（PEFT）/06-多模态微调的常见问题.md` 的对齐漂移——**"两阶段 = 先让模型看懂图，再教它按指令说"**——面试一句话总结）。

> 🎯 **核心要点**：两阶段 lr——1e-3（投影从零学）/2e-5（语言塔保护——差 50 倍）——"同一个模型两个世界"；OneVision 分离 lr——视觉 2e-6/语言 1e-5（视觉更脆弱——动一点破坏对齐——不同组件不同保护等级）；LLaVATrainer 特化——模态长度分组（减 padding）/mm_projector_lr（四组优化器参数）/mm_projector.bin 单独保存——"配方固化为代码"；冻结——编码器全程冻结（冻塔两理由）→ OneVision 极小步解冻（2e-6）；LLaVA 天然适配 LoRA（冻塔省显存——单卡标准组合）；完整清单（阶段/lr/epoch 1/batch/cosine/bf16/分组采样/-100 掩码）；面试一句话——"两阶段 = 先让模型看懂图，再教它按指令说"。
