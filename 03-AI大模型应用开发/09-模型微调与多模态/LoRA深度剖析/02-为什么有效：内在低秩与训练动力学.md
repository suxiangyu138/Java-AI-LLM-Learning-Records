# 02-为什么有效：内在低秩与训练动力学

> 定位：LoRA 能用千分之一参数逼近全参微调，靠的不是"碰运气"，而是两个被反复验证的事实——预训练模型的微调变化天然低秩，且低秩约束下 SGD 恰好能找到接近全参解的方向。

## 内在低秩假设

LoRA 的根基是内在维度假设（Intrinsic Dimension，Aghajanyan et al. 2021 的系统性实验）：**微调一个预训练模型到目标任务，真正需要的可训练参数维度远小于参数空间总维数**。他们用随机低维子空间投影训练 GPT-3（175B），发现只需约 1000 维就能在 GLUE 上逼近全参微调效果。LoRA 论文在此基础上给出直接证据：对 GPT-3 175B 做全参微调后，将权重的变化量 ΔW 做奇异值分解，其有效秩（能解释 90% 以上谱能量的奇异值个数）极低——全参微调本身就在低秩子空间内移动。

这解释了一个反直觉现象：为什么 r=16 的 LoRA（每层 16 维）能追上 175B 全参微调。因为全参微调实际只在一个约 1000 维的低维流形上移动，而 LoRA 逐层提供低秩旁路，恰好覆盖这个流形。全参微调的"全部参数可训练"大部分是浪费的——它只是把低维解嵌入高维空间的冗余表达。

## 训练动力学：为什么低秩约束不损失效果

### 子空间重叠实验：最强证据

LoRA 原文最有力的实验是子空间重叠分析：用不同随机种子训练同一任务的多个 LoRA，再测量它们学到的 ΔW 子空间（对 ΔW 做 SVD 取前 r 个左奇异向量张成的子空间）之间的余弦相似度。结果：**同任务不同种子的 LoRA 子空间高度重叠**，且与全参微调的 ΔW 主方向也显著重叠；而不同任务的 LoRA 子空间重叠度低。这直接证明：LoRA 不是"碰巧找到某个低秩解"，而是任务本身定义了一个低维适配方向，任何合理的初始化与优化过程都会收敛到它附近——低秩约束丢掉的是冗余方向，不是有效信息。



仅证明"变化低秩"还不够，还需回答：在 ΔW 被硬限制为秩 ≤ r 时，SGD 找到的解为什么接近无约束全参解？

- **最优解常在低秩投影附近**。若全参微调的最优解 ΔW* 的有效秩为 k，而 r ≥ k，则 LoRA 的最优解空间包含 ΔW* 本身，约束不损失理论上限。实践中 r 常取 8-64，而单任务适配所需有效秩通常 ≤ 20。
- **梯度方向的结构性**。注意力层与 FFN 层的梯度长期被主奇异方向主导，低秩投影恰好保留最大梯度分量，损失了噪声分量反而稳定训练。
- **初始化决定收敛域**。B=0 使训练从预训练点出发，LoRA 的轨迹是"预训练点附近小半径内的路径"，而全参微调也在同一区域移动（证据：微调后权重变化小，近似线性化），两个过程的收敛域高度重叠。

LoRA+ 的发现补充了动力学视角：A、B 两矩阵的更新幅度天然不对称——B 靠近输出，作用被放大，应给 B 更高学习率（LoRA+ 建议 B 为 A 的 4-16 倍）。这解释了许多变体的增益其实来自学习率再平衡，而非结构创新。

## 微调线性化视角：为什么小改动就够

另一个支撑性视角来自"微调近似线性化"研究：现代预训练模型的微调过程可以在权重空间做一阶泰勒展开近似（LoRA 论文的贡献者后续实验验证：微调使输出变化近似等于权重变化的一阶项，二阶项贡献可忽略）。这意味着微调实际是在做"预训练点附近的线性移动"，而低秩约束只是把移动限制在一个低维子空间——线性移动 + 低维子空间，恰好匹配"任务适配是低复杂度操作"的直觉。

这同时解释了 LoRA 的两个经验规律：一是**小学习率更好**——线性近似在更新幅度大时失效，所以 LoRA 的 LR 通常比全参低一两个量级（SFT 2e-4 vs 全参 1e-5 量级因模型而异，关键在于别让单步更新跳出近似区）；二是**训练很快**——线性区域内的优化问题接近凸，千级样本、1-3 epoch 足够，超长时间训练收益趋零甚至遗忘。

## 与全参微调的定量对照

LoRA 论文给出了三个常被引用的数字：GPT-3 175B 上，LoRA（r=4，全部注意力层）的可训练参数约为全参微调的 **0.0055%**（4.7M vs 175B），而在 WikiSQL 等下游任务上效果与全参微调持平或更好；r=4 与 r=64 的效果差距在多数任务上 <1%，印证"超过内在维度后秩收益趋零"；而将 LoRA 应用在不同层（只训 QKV vs 全部层）的效果差异可达数个点，说明"挂哪"比"挂多大"更重要。2026 年的 RLVR 研究补充了反面：全参微调（44.9%）被 DoRA（46.6%）反超，说明全参微调"高维空间里浪费的表达"在 RL 这种高频迭代场景中反而引入噪声。定量对照的结论：**LoRA 与全参的差距不是固定值，而是任务函数**——表示复用型任务差距趋零，需求高维交互的任务差距放大。

## 低秩与遗忘的关系

灾难性遗忘的经典解释是"新任务更新破坏了旧表示"。LoRA 的结构性优势在于：更新幅度被低秩约束限制在小子空间内，且 B 零初始化保证起点不变，所以对旧表示的扰动天然小于全参。但"参数少"不等于"不会遗忘"——2026 年实践共识是 LoRA 也会遗忘，只是门槛更高：数据里混入的分布外样本、过高的学习率、过长的训练都会突破低秩的保护。防遗忘手段按优先级排列：数据去重与质量清洗 > 保守的学习率与 epoch > dropout（0.05-0.1）> 提秩（反而增加遗忘面）。把 dropout 当成"防遗忘正则"而非"防过拟合正则"，是 LoRA 调参观的一次重要修正。

## 2026 年的祛魅：Learning Rate Matters

NTU/IBM 的 2026 研究给"变体军备竞赛"泼了冷水：对 vanilla LoRA、DoRA、PiSSA、MiLoRA 等做**逐一学习率网格搜索**后，它们在数学/代码任务上的差距收缩到 1-2% 以内。此前报道的 3-5 个点的增益，相当部分来自基线未调学习率。结论是务实的：先对 vanilla LoRA 做学习率扫描（SFT 约 2e-4 起步、DPO/GRPO 约 5e-6），再考虑引入复杂变体；变体只在特定场景有价值（DoRA 在 RL 中、PiSSA 在快速收敛中）。

## 什么时候 LoRA 不够用

低秩假设不是免费午餐，失效场景是理解它价值的上限：

| 场景 | 失效原因 | 应对 |
|---|---|---|
| 复杂多步推理 | 需要的高维交互超过 r 容量 | 提秩到 64-128 或全参 |
| 全新知识注入 | 知识不在预训练子空间内 | 全参 SFT 或先灌数据 |
| RL 训练（PiSSA） | 主分量方向与 RL 优化需求错位，谱坍缩 | 换 DoRA/vanilla |
| 极低秩（r≤4） | 容量不足以建模风格任务 | r≥8 起步 |

## 与 Adapter/Prompt 的本质差异

LoRA 与 Adapter 同样冻结底座，但改动的位置不同：Adapter 改变的是**网络拓扑**（插入层），LoRA 改变的是**权重取值**（旁路增量）。权重视角的好处是最终能 merge 回原模型——训练产物是一组"加法"，可以在任意部署框架中还原，不依赖训练框架；而 Adapter 是结构性的，推理必须带着结构。这也是 LoRA 成为生态标准、Adapter 逐渐边缘化的深层原因：可合并性让"训练框架"与"推理框架"解耦。

> 🎯 **核心要点**：LoRA 有效的完整链条是"预训练压缩了表示空间 → 微调变化落在低秩子空间 → 低秩约束不损伤最优解 → B=0 初始化保证与全参收敛域重叠"。2026 年的关键修正：大部分变体增益可被调好的学习率抹平，选型应"先调 vanilla，再谈变体"。
