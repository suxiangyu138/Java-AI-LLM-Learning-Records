## 4. 端到端项目

综合验收（毕业核心）：独立完成一次端到端微调——建议选题（三选一）：**客服话术微调**（行为校准——格式/语气）；**文档抽取微调**（结构化输出——JSON）；**领域问答微调**（代码/法律/医疗——结合 RAG 边界）。

**项目流程**（按工程流程九阶段）：

```text
1. 需求分析（任务定义 + 指标——客服：格式解析率 + 话术命中率）
2. 评估先行（金标评估集 100-200 条 + 基线评估 + 门禁预设）
3. 方案设计（QLoRA SFT——r/alpha/lr/epoch + 底座选型）
4. 环境搭建（单卡 QLoRA——配置可复现）
5. 数据准备（种子集 + 合成 + 清洗 + 去重 + manifest）
6. 训练配置（冒烟 → 正式——监控三件套）
7. 训练监控（loss/验证/早停——融合回测）
8. 模型验收（三线对照——门禁判定：上线/回炉）
9. 部署与报告（合并/服务冒烟/验收报告）
```

**交付物**：验收报告（能力分数 vs 基线/缺陷回测/门禁判定——`完整微调工程流程/08-模型评估与验收.md` 的报告格式）+ 项目复盘（成功/失败/改进——`完整微调工程流程/09-导出部署与上线运维.md` 的迭代闭环）。

**验收判据**：门禁通过（自定义评估集提升 >3% 且标准基准回归 <1%——`完整微调工程流程/03-评估先行基线建立.md` 的门禁标准）——"门禁没过 = 项目没毕业（回炉一次也是收获）"。

## 5. 56 题面试验收

7 篇面试题的必问 8 题（共 56 题）——**按各篇答题范式自答**：

| 层 | 面试题篇 | 答题范式 |
|:---:|---------|---------|
| 决策层 | 边界判断/10 | 诊断 → 排序 → 定量 → 组合 |
| 概念层 | 基础概念/10 | 原理 → 数字 → 对比 → 边界 |
| 数据层 | 数据集/10 | 差异 → 管线 → 数字 → 合规 |
| 配置层 | 超参/10 | 量级 → 机制 → 决策链 → 实证 |
| 方法层 | PEFT/10 | 原理 → 数字 → 对比 → 边界 |
| 流程层 | 流程/10 | 流程 → 顺序 → 数字 → 边界 |
| 排障层 | 常见问题/10 | 症状 → 诊断 → 根因 → 预防 |

**面试验收方法**：**录音自答**（模拟面试——每题 2 分钟自答后回放，对照答案补漏）——**"录音自答是面试准备的最高效方法"**（发现口头表达的盲区——`05-综合输出-面试冲刺/` 的面试方法论）。

## 6. 毕业检查单

模块 1 毕业检查单（全部打勾 = 毕业）：

- ☐ 70 题知识自测全过（7 层各 10 题）
- ☐ 七项能力实践产出物完整（决策单 → 诊断报告）
- ☐ 端到端项目完成（验收报告 + 门禁判定）
- ☐ 56 题面试验收按范式自答（录音回放）
- ☐ 项目复盘记录（成功/失败/改进——进入迭代闭环）

**毕业后的去向**：进入**模块 2：多模态大模型**（`../模块 2：多模态大模型/`——文本微调扩展到多模态——概念/架构/RAG/缺陷/部署）——**"模块 1 的 PEFT 原理与决策框架是模块 3（多模态微调）的直接基础"**（`00-模块1课程总览.md` 的模块衔接表）。

> 🎯 **核心要点**：模块 1 毕业 = 四件套（70 题自测/七项实践/端到端项目/56 面试题）——"能独立交付一个微调项目"是唯一标准；端到端项目按九阶段走、门禁过才算毕业（回炉也是收获）；实践库是面试作品集；毕业后进模块 2（多模态）——模块 1 的决策/原理/PEFT 直接服务后续。
