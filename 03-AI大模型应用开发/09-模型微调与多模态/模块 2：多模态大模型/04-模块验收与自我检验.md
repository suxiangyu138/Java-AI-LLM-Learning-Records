## 4. 多模态应用项目

综合验收（毕业核心）：独立完成一个多模态应用——建议选题（三选一）：**文档问答**（多模态 RAG——ColPali 检索 + VLM 回答）；**看图客服**（多模态微调——QLoRA 行为校准 + 产品图库）；**多模态 Agent 原型**（截图感知 + grounding + 工具调用——`多模态/推理部署工程/07-多模态Agent部署.md`）。

**项目流程**（多模态版九阶段——`多模态/多模态微调（PEFT）/09-多模态微调评估.md` 的评估链路）：

```text
1. 需求分析（任务 + 指标——文档问答：检索召回 + 回答正确率）
2. 评估先行（金标评估集（图文 QA）+ 基线（底座直接答 vs RAG） + 门禁）
3. 方案设计（RAG 还是微调——决策门槛 >25% 视觉内容 + 缺陷画像）
4. 数据准备（文档入库（解析/分块/索引）或 指令数据构建）
5. 检索/训练（RAG 管线或 QLoRA 微调——冒烟 + 监控）
6. 缺陷回测（感知/幻觉/对齐三线——量化放大感知缺陷的检查）
7. 性能压测（token 膨胀/延迟预算——阶段分解）
8. 验收（功能 + 缺陷 + 性能三线门禁）
9. 部署与报告（vLLM 服务 + 验收报告）
```

**交付物**：验收报告（功能指标 + 缺陷回测 + 性能数据——`多模态/推理部署工程/09-多模态推理评估与压测.md` 的压测报告格式）+ 项目复盘。

**验收判据**：功能门禁（任务指标达标——如检索召回 ≥ 目标）+ 缺陷门禁（幻觉/感知不劣化）+ 性能门禁（P95 延迟在预算内——`多模态/推理部署工程/09-多模态推理评估与压测.md` 的 SLA）——"三门禁全过 = 项目毕业"。
