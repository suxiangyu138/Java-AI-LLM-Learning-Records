## 4. 多模态微调项目

综合验收（毕业核心）：独立完成一个**多模态微调端到端项目**——建议选题（三选一）：**看图客服**（QLoRA 行为校准 + 产品图库——最常见的入门项目）；**文档理解微调**（图表/表格理解微调 + 缺陷回测）；**领域 VLM 微调**（如植物病害/工业质检——领域视觉塔 LoRA 候选——`多模态/多模态微调（PEFT）/05-多模态微调的类型.md`）。

**项目流程**（九阶段 + 多模态特化——`大模型微调知识体系/完整微调工程流程/00-完整微调工程流程总览.md` 的九阶段 × `多模态/多模态微调（PEFT）/09-多模态微调评估.md` 的评估链路）：

```text
1. 需求分析（任务 + 指标——看图客服：回答正确率 + 幻觉率）
2. 评估先行（金标评估集 + 三基线（底座直接答/文本 OCR+RAG/VLM 微调）+ 门禁预定义）
3. 方案设计（微调 vs RAG 决策 + 冻结策略（冻塔 + LoRA 语言塔 + 投影可训））
4. 数据准备（指令数据构建（三类配比）+ 对齐过滤 + manifest）
5. 训练（QLoRA 两阶段或单阶段——冒烟 + loss 监控 + 图像样本可视化）
6. 缺陷回测（感知/幻觉/对齐三线——量化放大感知缺陷的检查）
7. 融合回测（任务指标 + 图文一致性——能力提升 + 融合不破）
8. 验收（四线门禁：能力/缺陷/融合/性能）
9. 部署与报告（合并（含投影层）+ vLLM 服务 + 验收报告）
```

**交付物**：微调后的模型/适配器 + 验收报告（四线门禁数据——`多模态/多模态微调（PEFT）/09-多模态微调评估.md` 的门禁格式）+ 项目复盘。

**验收判据**：能力门禁（任务指标达标）+ 缺陷门禁（幻觉/感知不劣化）+ 融合门禁（图文一致性不破）+ 性能门禁（P95 延迟在预算内——`多模态/推理部署工程/09-多模态推理评估与压测.md` 的 SLA）——**"四门禁全过 = 项目毕业"**——项目产出是模块 4（工程落地）的输入素材。

## 5. 16 题面试验收

两套面试题（共 16 题）——**结合范式自答：先答文本原理、再答多模态差异**：

| 套 | 面试题篇 | 答题范式 |
|:---:|---------|---------|
| PEFT 8 题 | [大模型微调知识体系/PEFT/10-PEFT面试题](../大模型微调知识体系/PEFT%20参数高效微调（面试高频）/10-PEFT面试题.md) | 原理 → 配置 → 选型 → 边界 |
| 多模态微调 8 题 | [多模态/多模态微调（PEFT）/10-多模态微调面试题](../多模态/多模态微调（PEFT）/10-多模态微调面试题.md) | 差异 → 默认 → 配方 → 风险 |

**高频结合题示例**（每题都按"文本版 + 多模态版"答）：
- "LoRA 用在多模态模型上有什么不同？"——原理相同（低秩近似），差异在目标模块（排除视觉塔）、投影层处理、层选择性
- "多模态微调为什么默认冻结视觉塔？"——两个理由（浪费适配器 + 破坏对齐）+ 2026 实证（LLM-only LoRA 最优）
- "微调后模型变笨了/图文对不上了怎么排查？"——三通道回测 + 通用能力回测（过拟合/遗忘的多模态版）

**面试验收方法**（同模块 1/2）：**录音自答**（每题 2 分钟——回放补漏——`05-综合输出-面试冲刺/` 的面试方法论）。
