## 4. 毕业项目：微调模型部署上线

综合验收（五模块毕业核心）：**把模块 3 的微调模型部署上线**——交付一个生产级多模态微调应用（如"看图客服"）：

**项目流程**（部署九步——`多模态/推理部署工程/00-多模态推理部署工程总览.md` 的生命周期闭环）：

```text
1. 制品准备（微调模型合并（含投影层）+ 组件版本矩阵（模型/编码器/缓存））
2. 量化选型（FP8 默认/混合精度——视觉塔高位宽——验收三件套）
3. 服务部署（vLLM 起服务 + 并发批处理按 token 预算 + 缓存策略）
4. 接口封装（OpenAI 兼容端点/网关 + 鉴权）
5. 压测（请求分层 + 并发梯度 + 图像占比负载——SLA 按模态分层）
6. 成本账（每 token 账本——自托管 vs API 盈亏点）
7. 灰度上线（金丝雀 10-30-60-100 + A-B 模态专项评估）
8. 监控（阶段延迟/图像占比/缓存命中率/VRAM 余量——DCGM + /metrics）
9. 验收报告（功能 + 性能 + 成本三门禁数据）
```

**交付物**：生产服务（可访问的端点）+ 验收报告（三门禁数据——`多模态/推理部署工程/09-多模态推理评估与压测.md` 的压测报告格式）+ 部署复盘。

**验收判据**：功能门禁（任务指标达标——与模块 3 的验收指标一致）+ 性能门禁（P95 延迟/TTFT 在 SLA 内）+ 成本门禁（每 token 成本在预算内）——**"三门禁全过 = 毕业项目完成 = 五模块课程毕业"**。

## 5. 16 题面试验收

两套面试题（共 16 题）——**对比范式自答：先给结论（什么时候用什么）再给理由**：

| 套 | 面试题篇 | 答题范式 |
|:---:|---------|---------|
| 边界判断 8 题 | [边界判断/10-边界判断面试题](../大模型微调知识体系/边界判断（非常关键，面试必问）/10-边界判断面试题.md) | 诊断 → 排序 → 定量 → 止损 |
| 推理部署 8 题 | [模型推理与部署/10-推理部署面试题精选](../../07-模型部署与工程化/模型推理与部署/10-推理部署面试题精选.md) | 差异 → 数字 → 顺序 → 边界 |

**高频对比题示例**（每题都按"结论 + 理由"答）：
- "知识缺口该用 RAG 还是微调？"——结论：RAG 主场（成本低/可更新）；理由：微调的知识不更新/幻觉风险
- "多模态场景什么时候不用多模态 RAG？"——结论：视觉关键内容 ≤25% 或文本基线已强；理由：成本/复杂度不划算
- "模型上线先量化还是先压测？"——结论：先压测建立基线再量化对比；理由：量化是优化手段、压测是度量衡
- "服务延迟不达标先调什么？"——结论：先压 token（多模态是图像 token）再量化；理由：token 膨胀是第一问题

**面试验收方法**（同模块 1-3）：**录音自答**（每题 2 分钟——回放补漏——`05-综合输出-面试冲刺/` 的面试方法论）。
