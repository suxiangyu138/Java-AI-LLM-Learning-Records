## 1. 章节定位

章节三解决毕业总测的第三关：**"项目做得出吗、讲得清吗"**——把模块 1-4 的 28 项能力实践（4 模块 × 7 项）与 4 大项目组织成综合答辩——**先检查实践库、再串讲项目、最后毕业答辩**——本章节是模块 5 的"项目关"（知识表达都过关了，最终要看能不能做——`00-模块5课程总览.md` 的考区顺序）。

## 2. 考区三：项目答辩

**答辩构成**：28 项实践产出物逐项检查（模块 1-4 各 7 项）+ 4 大项目串讲（文本微调/多模态应用/多模态微调/毕业项目）+ 1 次毕业答辩（15 分钟——`04-模块验收与自我检验.md` 的毕业总测）。

**答辩方法**：**先自查后串讲**——产出物不齐的实践回读对应篇补做；项目按"背景-方案-数据-训练-评估-部署-复盘"七段式串讲（第 4 节）。

## 3. 28 项实践检查单

| 模块 | 7 项实践（产出物） | 检查标准 |
|:---:|------|---------|
| 模块 1 | 决策单 / 配置原理解释 / 数据清洗报告+manifest / QLoRA 配置 / 九阶段清单 / 排障演练 / 端到端项目 | 产出物文件齐全（`../模块%201：大模型微调体系/04-模块验收与自我检验.md` 第 3 节） |
| 模块 2 | token 计算+三组件图 / 技术报告拆解 / 数据清洗 / QLoRA 方案 / RAG 方案+成本 / 三层定位诊断 / vLLM 服务+压测 | 产出物文件齐全（`../模块%202：多模态大模型/04-模块验收与自我检验.md` 第 3 节） |
| 模块 3 | 90/10 对照 / 冻结策略 / 数据 manifest / QLoRA 配置 / 九阶段清单 / 排障演练 / 门禁设计 | 产出物文件齐全（`../模块%203：结合：多模态模型微调/04-模块验收与自我检验.md` 第 3 节） |
| 模块 4 | 决策单 / 横评报告 / 混合方案 / 服务设计 / 上线方案 / 压测报告 / 总结三件套 | 产出物文件齐全（`../模块%204：工程落地%20%26%20对比总结/04-模块验收与自我检验.md` 第 3 节） |

**检查方法**：逐项对照检查单（产出物在"实践库"目录归档——四个模块的产出物合并为**四作品集**：文本微调 + 多模态 + 多模态微调 + 生产交付）。

**实践库归档规范**：产出物按"模块X-实践Y-名称"命名归档（如"模块3-实践四-QLoRA配置.md"），同一项目的产出物放入同名子目录——**归档本身就是一次复习**（整理产出物 = 重走一遍项目——第 4 节的七段式）；面试前按四作品集重读一遍——**"归档规范 = 面试的素材库规范"**（简历上的每个项目都能翻出原始产出物）。

## 4. 4 大项目串讲

**项目一：文本微调项目**（模块 1——端到端微调文本模型）——九阶段 + 门禁判定。

**项目二：多模态应用项目**（模块 2——文档问答/看图客服/多模态 Agent 原型三选一）——三门禁（功能/缺陷/性能）。

**项目三：多模态微调项目**（模块 3——看图客服/文档理解/领域 VLM 微调三选一）——四门禁（能力/缺陷/融合/性能）。

**项目四：毕业项目**（模块 4——把项目三的微调模型部署上线）——部署九步 + 三门禁（功能/性能/成本）——**这是五模块课程的毕业项目**。

**串讲方法**（七段式，每个项目 5 分钟）：

```text
1. 背景（任务 + 指标——为什么做这个）
2. 方案（选型——为什么 RAG/微调/混合——对比了什么）
3. 数据（来源 + 清洗 + 配比——质量怎么保证）
4. 训练（配方 + 冻结策略 + 监控——遇到什么问题）
5. 评估（评估集 + 门禁——指标多少、差在哪）
6. 部署（服务 + 压测 + 成本——上线指标多少）
7. 复盘（成功/失败/改进——下次怎么做更好）
```

**串讲要点**：**四个项目串起来 = "选型-微调-落地"一条线**（项目一学会微调、项目二学会多模态、项目三微调多模态、项目四上线交付——面试讲项目时按这条线讲）。

## 5. 毕业答辩流程

**毕业答辩**（1 次，15 分钟——毕业前最后一场）：

```text
1. 开场（2 分钟——一句话定位 + 四作品集展示）
2. 主项目深讲（8 分钟——毕业项目：背景/方案/数据/训练/评估/部署/复盘——重点讲"失败与改进"）
3. 追问（3 分钟——面试官视角：为什么选这个方案 / 指标怎么定的 / 缺陷回测怎么做的 / 成本多少）
4. 收尾（2 分钟——五模块知识地图 + 未来改进方向）
```

**答辩方法**：录音 + 回放——按评分表自评（项目真实性/技术深度/数据准确性/表达结构/复盘质量五维，各 20 分，≥80 分通过）。

**高频追问清单**（面试官视角自问自答——毕业答辩的追问环节从这里抽）：为什么选 QLoRA 而不是全量微调（成本/数据量）；冻结策略怎么定的（冻塔两理由）；数据怎么保证质量（对齐过滤/清洗 12 维）；训练遇到什么问题（loss 不降/融合破坏——**失败经验比成功更值钱**）；评估集怎么建的（能力/缺陷双评估集）；门禁怎么定的（四线门禁阈值依据）；部署成本多少（每 token 账本）；下次改进什么（复盘三问）——**"能答追问 = 项目是真实做过的"**（编的项目经不起追问——真实性是答辩第一关）。

**答辩通过 = 五模块课程毕业在望**（最后一张检查单在 `04-模块验收与自我检验.md` 第 2 节）。

## 6. 章节验收

**验收标准**：28 项实践产出物全部齐备 + 4 大项目七段式串讲完成 + 毕业答辩 ≥80 分。

**验收方法**：逐项检查实践库 → 每天串讲 1 个项目（4 天）→ 毕业答辩（录音回放 + 五维评分）——**"实践全齐 + 项目讲得清 + 答辩 ≥80 = 章节三通过"**（项目关过关）。

> 🎯 **核心要点**：章节三 = 项目关——28 项实践检查（四作品集）+ 4 大项目串讲（七段式——背景/方案/数据/训练/评估/部署/复盘）+ 毕业答辩（15 分钟——五维评分 ≥80）；四项目一条线 = "选型-微调-落地"；验收 = 实践全齐 + 串讲完成 + 答辩通过——**"做得出、讲得清 = 项目关过关"**。
