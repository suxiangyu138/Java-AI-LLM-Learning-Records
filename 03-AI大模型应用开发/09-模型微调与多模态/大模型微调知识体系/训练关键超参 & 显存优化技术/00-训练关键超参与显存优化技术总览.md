## 3. 为什么必须学透超参与显存

1. **超参是"经验科学"中的可量化部分**：2026 年 Baseten 后训练科学用受控扫描（Qwen3/Llama，0.6B-235B，LoRA 与全量）给出了关键结论——**LoRA 学习率跨两个数量级模型规模保持稳定**、**batch size 更像成本杠杆而非质量杠杆**、**LoRA 恢复全量微调收益的中位数 98%**——超参选择从"背默认值"升级为"懂原理"。
2. **显存是微调的第一物理约束**：单卡能跑什么模型、用什么技术组合——显存账本（权重/梯度/优化器状态/激活四部分）是一切决策的依据；梯度检查点（省 ~30%）、FlashAttention（长序列必备）、8bit 优化器（状态砍半）等技术的收益与代价，本体系 06 篇一次讲清。
3. **2026 量化格局在变**：QLoRA NF4 是标准配方（13B 单卡 18GB），NVFP4/MXFP4 新兴（MoE 大模型单卡训练/服务成为可能），QAT 解决量化损伤（恢复 45-70% 损失）——本体系 07 篇覆盖全图谱。
4. **分布式选择有"10B 规则"**：10B 以下 FSDP 快（7B 4×A100 实测 3159 vs 3095 tokens/s）、10B 以上 DeepSpeed ZeRO-3 的 offload 能力成为刚需；LoRA 混合分片（ZeRO-3+FSDP）实测通信量 ↓89%、吞吐 2.7×——分布式不再是"全量微调专属"。
5. **面试高频区**："学习率怎么定""显存不够怎么办""单卡能训多大模型"——本体系 10 篇把 2026 实证数字（2e-4、3% warmup、98%、10B 规则、2.7×）全部备好。

## 4. 核心概念速查

### 4.1 核心概念

| 概念 | 一句话 | 关键数字 |
|------|--------|---------|
| 学习率 | 最重要的超参 | LoRA 2e-4 起点、跨规模稳定 |
| batch 杠杆 | 成本权衡非质量杠杆 | 每卡 1-2 + 累积 |
| 有效 batch | 每卡 × 卡 × 累积 | 稳定梯度估计 |
| 梯度检查点 | 重算换显存 | 省 ~30% 费 ~20% |
| FlashAttention | 分块 + 重算 | 长序列必备 |
| 8bit 优化器 | 优化器状态砍半 | QLoRA 标配 |
| QLoRA NF4 | 4bit 量化微调 | 13B 单卡 ~18GB |
| NVFP4 | NVIDIA FP4（2026） | MoE 大模型单卡 |
| QAT | 量化感知训练 | 恢复 45-70% |
| 10B 规则 | 分布式选型阈值 | <10B FSDP、>10B ZeRO-3 |

### 4.2 超参起点速查（2026）

| 超参 | 全量微调 | LoRA/QLoRA |
|------|---------|-----------|
| 学习率 | 1e-5 ~ 2e-5 | 2e-4 起点（1e-5~1e-3 搜索） |
| epoch | 1-3 | 1-3 |
| warmup | 3% 步数 | 3% 步数 |
| 调度 | cosine + min_lr_ratio 0.1 | 同左 |
| weight decay | 0.1 | 0.1 |
| LoRA r/alpha | — | r=16-64、alpha=2×r（保守用 =r） |

### 4.3 常见误区速查

- "batch 越大越好" → 错：质量上差异小，是算力成本权衡（Baseten 2026）
- "默认值抄就完事" → 错：超参是经验问题，要带验证集复验（Baseten 核心信息）
- "显存不够就换小模型" → 错：先按账本逐项省（检查点/优化器/量化），换模型是最后手段
- "多卡一定更快" → 错：通信开销在 PCIe 环境可能吃掉线性加速

## 6. 学习路线推荐

**路线一：面试速成（半天，对应模块 01-02 + 04 + 10）**
超参全景 → 学习率 → epoch → 面试题；掌握 2026 实证数字（2e-4、3%、98%、1-3 epoch）。

**路线二：单卡微调实战（1 天，对应模块 02-03 + 06-07）**
学习率 → batch → 显存账本 → 量化；配合一次 QLoRA 单卡微调，把省显存套餐配齐。

**路线三：规模化训练（对应模块 08-09 + 05）**
分布式四策略 → 性能优化 → 正则化；面向多卡/大模型场景，10B 规则与通信优化是重点。

> 🎯 **核心要点**：超参与显存的学习终点 = "**懂实证**（Baseten 结论：lr 稳定/batch 是成本杠杆/LoRA 98%）、**会起点**（全量 1e-5、LoRA 2e-4、cosine+3% warmup、epoch 1-3）、**会搜索**（粗扫→细扫/进化/语言引导贝叶斯）、**会算账**（显存四部分）、**会省**（检查点/FlashAttention/8bit/QLoRA/量化分层）、**会分布**（10B 规则/LoRA 混合分片）"——六件事把超参从"背默认值"升级为"懂原理 + 有数据"；记住"超参是经验问题，不是信仰问题"。
