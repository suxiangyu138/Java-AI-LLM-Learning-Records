# 学习率与调度

> 最重要的单个超参：全量与 LoRA 的量级差异、warmup 与余弦退火的标准配方、scheduler 选型表——学习率定了，训练就定了一半

## 1. 学习率的量级地图

学习率是影响微调质量最大的单个超参，量级随方法与场景分三档：

**全量微调**：1e-5 ~ 2e-5（AllenAI open-instruct 扫描范围约 1e-6 ~ 2e-5）；继续预训练 1e-5 ~ 3e-5（比原始预训练低 10-100 倍——底座已收敛，大步长破坏已有权重）。**全量微调为什么低**：所有参数都动，等效更新幅度大，必须小步走。

**LoRA/QLoRA**：2e-4 是常用默认（AlphaEvolve 种子 5e-5，搜索范围 1e-5 ~ 1e-3）；Baseten 2026 实证最优 LoRA lr **跨 0.6B-235B 模型规模保持稳定**——2e-4 量级可以跨模型迁移。**LoRA 为什么可以高**：只更新低秩增量，等效更新幅度小（见 `../基础概念/05-优化器与梯度更新.md` 03 节）。

**关键规则**：**全量微调适用的学习率不一定适合适配器**（反之亦然）——换训练方法必须重新校准 lr；保守场景（保护底座能力、小数据）用低一档（5e-5 量级），快速见效场景用 2e-4 起步。**lr 的"方向性"**：lr 偏低的代价是"慢"（可加时间补），lr 偏高的代价是"毁"（发散/破坏底座，`../微调常见问题/04-训练问题loss不降NaN与发散.md` 02 节）——**不确定时取低不取高**，先跑通再微调。

## 2. warmup：为什么必须、配多少

warmup（预热）让学习率从极小值线性升到峰值，两个机制原因（`../基础概念/05-优化器与梯度更新.md` 04 节）：训练初期激活/梯度不稳定，直接上大 lr 会打爆；Adam 的二阶矩估计需要数据积累，预热给足时间。

**2026 标准配比**：warmup_ratio ≈ 0.03（3% 的步数）——6000 步训 180 步左右；继续预训练用几百步的短线性预热。**warmup 不是越多越好**：占比超 10% 会浪费早期步数（lr 还没到峰值，学得慢）；极短训练（<300 步）可降到 2-3 步甚至跳过（短跑场景 warmup 收益小，`../基础概念/05-优化器与梯度更新.md` 04 节）。

## 3. 余弦退火：为什么是默认

warmup 之后的学习率形态，2026 年事实标准是**余弦退火**（cosine decay）：lr 从峰值按余弦曲线平滑衰减到峰值的 ~10%（min_lr_ratio = 0.1）。

机制价值：**前期慢降稳住收敛**（大 lr 的探索能力保留更久），**后期快降帮助落入更优最小值**（更平坦的极小点 → 更好的泛化，`../基础概念/05-优化器与梯度更新.md` 04 节）。与线性衰减相比，余弦在"探索-收敛"平衡上更优——**绝大多数微调任务 cosine 是默认**。

## 4. Scheduler 选型表

| 调度器 | 适用场景 | 说明 |
|--------|---------|------|
| cosine | 大多数微调任务（默认） | 平滑衰减，泛化好 |
| linear | 短训练跑 | 线性衰减，简单直接 |
| constant_with_warmup | 极短训练（<200 步）或 lr 已最优 | warmup 后恒定 |
| cosine_with_restarts | 长训练周期性探索 | 重启期重新探索 |

选型逻辑：**训练越短，调度越简单**（短跑没时间给余弦的后半段）；训练越长，cosine 的收益越明显。

**调度器的落地检查**：训练日志里确认 lr 曲线形态符合预期（warmup 线性爬升 → cosine 衰减——`../完整微调工程流程/07-训练过程监控与干预.md` 02 节的 lr 监控项）；**scheduler 与优化器的绑定**（PyTorch 的 `get_cosine_schedule_with_warmup` 类 API 按 step 数计算——总步数变化时调度器要重新生成，断点恢复时 scheduler 从保存的 step 继续，`../完整微调工程流程/06-训练配置与启动.md` 04 节）；min_lr_ratio 配 0.1 防 lr 衰减到零（极低 lr 阶段训练基本停滞，保留 10% 保持微调能力）。

## 5. 学习率与相邻超参的耦合

学习率不是独立变量，与三个超参耦合：

**与 batch 耦合**：等效 lr = lr × batch 放大倍数（梯度累积/多卡放大了每步样本数）——**改有效 batch 应该同步缩放 lr**（batch ×2 → lr ×2 附近，线性缩放规则）；但 Baseten 2026 提示 batch 对质量影响小，实际中"改 batch 不动 lr"也常见（质量差异在噪声内）。

**与 warmup 耦合**：warmup 步数是总步数的比例——总步数变了（数据量/epoch 变），warmup 步数跟着变；改 lr 不改 warmup 是安全的，改 epoch 必须重新算 warmup。

**与权重衰减耦合**：weight decay 与 lr 同向放大权重收缩——大 lr 场景 wd 相对影响更大（wd=0.1 是 AdamW 标准，`../基础概念/05-优化器与梯度更新.md` 02 节）。

**实操结论**：调参顺序"先 lr（独立精调）→ 再配 warmup 比例（固定 3%）→ 最后微调 wd（默认 0.1 极少动）"——**lr 是唯一值得反复精调的超参**（`../基础概念/05-优化器与梯度更新.md` 05 节的实操三步：定起点 → 短试 → 对数网格）。

**学习率与训练曲线的对应关系**（诊断用）：lr 过高 → loss 前期震荡/发散（`../微调常见问题/04-训练问题loss不降NaN与发散.md` 02 节）；lr 过低 → loss 平滑但极慢（200 步几乎不动）；lr 合适 → loss 快速下降后进入稳定衰减——**从曲线形态反推 lr 方向**是调参的第一技能：发散降 3-5 倍、不动升 3-5 倍、平滑下降保持。

**多阶段训练的学习率**（进阶）：SFT → DPO 的两阶段流水线（`../基础概念/07-微调方法全景图谱.md` 07 节）中，**每个阶段独立配 lr**——DPO 的 lr 通常比 SFT 低一档（偏好优化是精细调整，大步长会破坏 SFT 学到的行为）；继续预训练用最低档（1e-5~3e-5）——"一套 lr 走全程"是常见错误。

## 6. 2026 研究动态

**Baseten**：lr 跨规模稳定（本章第 1 节），且 LoRA 与全量的最优 lr 不同——研究明确提示"为适配器单独校准 lr"。**AlphaEvolve** 的搜索中 lr 被识别为**最具影响力的超参**（搜索范围 1e-5 ~ 1e-3，种子 5e-5）。**ICML 2026 语言引导贝叶斯**把 lr 纳入文本化配置空间联合搜索。共识：**lr 的优先级在所有超参之上**——调参预算的 70% 应该花在学习率上。

**学习率的对数直觉**：lr 的最佳值在"一个数量级内的某个点"（5e-5、1e-4、2e-4、5e-4……）——**搜索用对数刻度而非线性刻度**（1e-4 与 2e-4 的差距远小于 2e-4 与 3e-4 的感受，对数间距才均匀）；"2e-4"不是魔法数字，是"1e-4 ~ 3e-4 区间的合理代表"——**理解对数刻度后，调参直觉就从"背数字"升级为"找区间"**。

> 🎯 **核心要点**：lr 量级三档——全量 1e-5~2e-5（继续预训练同档）、LoRA 2e-4 起点（跨规模稳定，Baseten 实证）、保守 5e-5；换训练方法必须重新校准 lr；warmup 3% 步数标准配比（短跑可跳过）；cosine + min_lr_ratio 0.1 是默认（前期探索后期收敛）；scheduler 选型——训练越短调度越简单；lr 与 batch/warmup/wd 三处耦合（等效 lr 随 batch 放大）；调参预算 70% 花在 lr——"学习率定了，训练就定了一半"。
