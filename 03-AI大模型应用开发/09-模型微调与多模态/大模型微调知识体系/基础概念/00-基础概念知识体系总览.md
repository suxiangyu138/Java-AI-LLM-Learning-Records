## 3. 为什么必须学透基础概念

1. **微调不是魔法，是"继续训练"**：很多入门者把微调当黑盒——丢数据、跑脚本、看 loss。不理解"权重、梯度、交叉熵、epoch"，就永远只能抄别人的配置，参数一调就崩。本体系把原理层补齐，让"为什么这样配"有答案。
2. **面试的第一个问题是概念题**：面试官几乎必问"微调的本质是什么""SFT 和 RLHF 的区别""交叉熵损失怎么算""为什么 epoch 不能太多"——本体系 04-06 篇直接给出标准答案。
3. **2026 年训练范式在演进**：经典"预训练→SFT→RLHF"三段论已被扩展为"SFT→偏好优化（DPO）→RL（GRPO/PPO）→RLVR（可验证奖励强化）"——基础概念不更新，读新论文会直接迷路。
4. **概念层是其他体系的公共依赖**：PEFT 体系讲 LoRA 原理（依赖 03 篇参数与权重）、数据集体系讲数据（依赖 08 篇格式）、超参体系讲调参（依赖 05-06 篇原理）——基础概念是微调知识体系的"函数签名"，先看懂它，其他体系才读得动。
5. **概念错误代价高**：把"epoch 越多越好"当默认、把"loss 下降"当成功、不知道 chat template 错了模型直接输出垃圾——这些全是可以靠基础概念避免的学费级错误。

## 4. 核心概念速查

### 4.1 核心概念

| 概念 | 一句话 | 关键数字 |
|------|--------|---------|
| 微调 | 在预训练权重上继续训练 | 本质 = 改权重 |
| SFT | 指令数据监督微调 | epoch 1-3 |
| 交叉熵 | 预测分布 vs 真实 token | 初始 loss ≈ log(vocab) |
| 困惑度 PPL | exp(loss) | 现代模型 6-10 |
| AdamW | LLM 标准优化器 | lr 1e-4~3e-4（7B） |
| 梯度累积 | 模拟大 batch | 典型 4 |
| DPO | 直接偏好优化 | 无需奖励模型 |
| RLHF | 奖励模型 + PPO | 成本高、在线更新 |
| chat template | 角色消息 → token 序列 | system/user/assistant |
| prompt masking | user token 不参与损失 | label = -100 |

### 4.2 训练三阶段（2026 扩展版）

| 阶段 | 数据 | 目标 | 成本量级 |
|------|------|------|---------|
| 预训练 | 万亿级 web 语料 | next-token 预测 | 极高（企业不做） |
| SFT | 千-百万级指令对 | 教格式与行为 | 高（可裁剪） |
| 偏好优化 DPO/RLHF | 偏好对/人类反馈 | 教"什么是好的" | 中 |
| RLVR（前沿） | 可验证奖励 | 推理/数学/代码 | 前沿实验室 |

### 4.3 常见误区速查

- "epoch 越多越好" → 错：SFT 1-3 epoch 惯例，3+ 开始记忆化过拟合
- "loss 降就是好" → 错：训练 loss 可欺骗，验证 loss 才是准绳
- "微调能注入知识" → 错：知识缺口是 RAG 主场（见边界判断体系）
- "聊天格式随便写" → 错：chat template 错了模型输出垃圾

## 5. 与周边知识的关系

```text
                    ┌── 边界判断（非常关键，面试必问）/ —— 决策层：要不要微调
大模型微调知识体系 ├── 基础概念/ —— 概念层（本体系）：是什么、为什么
                    ├── PEFT / 数据集 / 超参 / 流程 / 常见问题 / —— 执行层：怎么做
                    ├── 03-AI.../深度学习/ —— 算法原理（反向传播/梯度下降深潜）
                    └── 03-AI.../模型推理与部署/ —— 推理与部署约束
```

**本体系与同级子体系的分工**：`边界判断` 是决策层（先判断做不做），`基础概念` 是概念层（理解原理），PEFT/数据集/超参/流程/常见问题是执行层（动手做）。读法建议：**边界判断（要不要）→ 基础概念（是什么）→ 执行层（怎么做）**——决策、原理、执行三层递进，本体系是承上启下的中间层。

## 6. 学习路线推荐

**路线一：面试速成（半天，对应模块 01-04 + 07 + 10）**
微调本质 → 三阶段 → Transformer 参数 → 损失函数 → 方法图谱 → 面试题；覆盖面试概念题 80% 考点，答得出"本质/损失/三阶段/DPO vs RLHF"。

**路线二：工程入门（1-2 天，对应模块 03-09）**
参数基础 → 损失 → 优化器 → 训练循环 → 数据格式 → 评估；建立"看懂训练日志、看懂别人配置、能判断好坏"的动手前知识储备，然后进执行层体系。

**路线三：原理深潜（对应模块 02-05 + 深度学习体系）**
三阶段范式 → 损失与优化器原理 → 反向传播深潜；适合要读论文、做训练优化的人，2026 研究（batch 调度、TimeScaling、RLVR）从这里延伸。

> 🎯 **核心要点**：基础概念的学习终点 = "**懂本质**（微调=改权重）、**懂范式**（预训练→SFT→对齐的 2026 全景）、**懂计算**（交叉熵/AdamW/epoch 公式与惯例）、**懂格式**（chat template 与掩码）、**懂评估**（验证 loss/过拟合/遗忘）"——五件事撑起微调从原理到落地的全部概念地基；读完本体系再进 PEFT 与数据集，执行层文档全部可读。
