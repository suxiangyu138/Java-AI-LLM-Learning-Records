# 微调的定义与本质

> 概念层的总纲：微调 = 在预训练权重上继续训练——理解"改权重"这一个本质，就理解了微调的一切

## 1. 微调是什么

微调（Fine-tuning）是指在**预训练模型已有的权重基础上**，用特定任务的标注数据继续训练，使模型在特定领域或任务上的表现符合预期。一句话定义：**用任务数据接着练，把通用模型变成专用模型**。

它与三个相关概念的关系需要先分清：

**预训练**（Pretraining）：在万亿级互联网语料上做 next-token 预测（自监督），学出语言与世界的通用能力——这是"通用底座"，成本极高，企业一般不碰。

**推理**（Inference）：模型在推理时**只做前向传播**，权重不变——你平时调用 GPT/DeepSeek 接口，服务器上跑的推理不会改模型一个数字。

**微调**（Fine-tuning）：在预训练底座上继续训练，**权重被更新**——微调产出的是一个新的模型文件，之后用这个新权重做推理。

三者的关系是一条流水线：预训练造底座 → 微调塑专用 → 推理做服务。企业 99% 的微调场景落在"拿现成开源底座（如 Qwen、Llama）+ 自己的数据 → 产出专用模型"这一段。

## 2. 本质：改变权重

微调与 Prompt 工程、RAG 的根本区别只有一个：**改不改权重**。

- Prompt 工程：只改输入文本，权重不变——零风险，改文字即可回滚。
- RAG：在推理时挂检索管道，权重不变——知识实时、可溯源。
- 微调：**更新模型内部的参数矩阵**——行为被固化进权重，但也因此"改错要重训"。

这个本质推导出微调的一切特性：**有效**（行为固化，格式 99% 稳定、可省掉每请求的长指令）；**昂贵**（要数据、算力、评估、治理闭环）；**危险**（改错方向要重训，训练数据成为受治理产物）；**不可逆于单次调用**（Prompt 可以每条都改，微调模型的行为对全体请求生效）。

边界判断体系（`../边界判断（非常关键，面试必问）/00-边界判断知识体系总览.md`）的整个决策框架就是围绕这个本质展开的：既然微调是唯一改权重的杠杆，它就应该是**最后手段**——先试不改权重的方案（Prompt → RAG → Tools），仍有关键缺口才动权重。

## 3. 为什么微调有效：迁移学习

微调有效的底层原理是**迁移学习**（Transfer Learning）：预训练权重不是随机初始化，而是已经在万亿级语料上收敛过的参数——它已经"懂语言、懂世界、懂推理"。微调不是从零学，而是**在已有能力上做局部校准**。

这带来两个关键推论：

**第一，小数据也能见效。** 因为底层能力（语法、常识、推理）已被预训练学好，微调只需要教会"输出形态"——格式、语气、领域术语。这就是为什么 1,000 条高质量指令对就能做出可用模型，而从头训练需要百万级数据（见 `08-指令数据与对话格式基础.md` 的数据量级参考）。

**第二，能力天花板由底座决定。** 微调改变的是行为分布，不凭空创造能力——底座不会的数学，微调也教不会（这正是知识缺口该交给 RAG 的原因，见边界判断体系 03 篇）。2026 年的共识表述是：**后训练（post-training）塑造"可用性"，预训练决定"能力上限"**。

## 4. 微调到底改了什么

2026 年对指令微调（SFT）的研究表明，微调在权重上的实际改变集中在**行为层面**：

- **输出格式**：学会 JSON/表格/固定结构——把"续写文本"变成"按格式输出"。
- **指令遵循**：学会"按 user 的要求做"，而不是继续自由续写。
- **对话角色**：学会 assistant 角色，用 system 约束行为。
- **拒答模式**：学会对越权请求说"不"。

值得强调的是：SFT 阶段教的是"模仿示范行为"，**不保证对齐价值观**——对齐需要偏好优化阶段（RLHF/DPO）完成（见 `02-大模型训练三阶段范式.md`）。很多入门者以为"SFT 完就安全了"，这是对微调能力的常见误判。

## 5. 微调的类型与规模

按"改多少权重"分，微调家族分为全量微调与参数高效微调（PEFT）两大类：

**全量微调**（Full Fine-tuning）：更新所有参数矩阵。能力上限最高（每层都校准），但代价是显存约等于模型权重的 4-5 倍（权重 + 梯度 + AdamW 优化器状态，账本算法见 `../训练关键超参 & 显存优化技术/` 体系）。数据量 50k+ 时才值得与 PEFT 竞争（阈值判断见边界判断体系 06 篇）。

**参数高效微调**（PEFT）：冻结底座权重，只训练少量新增参数——LoRA 只训低秩补丁（通常占全量 0.1%-1%），QLoRA 再加 4-bit 量化底座。效果接近全量微调（2026 年大量实证），存储与显存成本低一个量级，是 1k-50k 数据量的默认选择。实现细节在 `../PEFT 参数高效微调（面试高频）/` 体系，此处先建立"方法差异 = 更新多少权重"的概念。

按"训练起点"分，还有两种实施形态：**拿开源底座自己训**（Qwen/Llama/DeepSeek 权重 + 本地 GPU，可控、可离线、成本透明）与**调用平台 API 微调**（OpenAI 等平台的 fine-tuning API，零运维、自带基础设施，但权重在供应商侧）。2026 年两者并存：强监管/私有数据场景倾向自训，快速验证倾向 API。

两个常见误区需要排除：微调**不是**从零训练（底座能力全部保留，见第 3 节迁移学习）；微调**不是**"高级提示词"（提示词不改变权重，改了权重就要为行为负责——改错要重训）。

## 6. 微调的本质边界：知识

微调最容易被误用的方向是"注入知识"。研究（Ovadia 2023）表明在事实性内容上微调**反而增加幻觉**——模型开始"自信地编造"。原因就在本节 2 点的本质里：**权重固化的是训练时点的信息**，训练后的新知识、私有事实、需要溯源的内容，权重里根本没有，模型只能编。

所以知识类缺口（事实、时效、私有数据）的正确方案是 RAG，微调的正确疆域是**行为**（格式、风格、流程）。这个边界是微调知识体系最重要的一个判断，完整论述在边界判断体系的 01/03 篇，此处只需记住结论：**微调改的是"怎么输出"，不是"知道什么"**。

> 🎯 **核心要点**：微调 = 在预训练权重上继续训练；与 Prompt/RAG 的根本区别是改不改权重；有效源于迁移学习（小数据校准已有能力）；改的是行为不改知识上限；知识注入是微调的本质误区——"微调是最后手段"由此而来。
