# 优化器与梯度更新

> 损失函数告诉我们"错多少"，优化器决定"怎么改权重"：AdamW 为什么是 LLM 标准、学习率怎么定、warmup 为什么必需——微调超参的第一课

## 1. 梯度下降直觉

训练的过程是**最小化损失**：把损失看作参数空间的曲面，每次沿梯度（损失上升最快的方向的反方向）迈一小步，曲面就低一点。一次"前向传播算 loss → 反向传播算梯度 → 更新权重"构成一个训练步（step）。

**反向传播**（Backpropagation）是算梯度的机制：用链式法则从输出层逐层往回，算出每个参数对损失的贡献。它的显存代价很关键——**每个参数的梯度要占用一份显存**（FP16 下每个参数 2 字节），这是全量微调显存约等于"3-4 份模型"的原因之一（权重 + 梯度 + AdamW 优化器状态，详见 `../训练关键超参 & 显存优化技术/` 体系）。

反向传播还有第二个显存黑洞：**激活值**。链式法则需要前向传播时每层的输入激活值，激活值显存随序列长度线性增长——长上下文训练显存激增的根源就在这里。这就是 gradient checkpointing（梯度检查点，重算前向换显存，省 50-70%）与 FlashAttention（省去完整注意力矩阵）成为长序列训练标配的原因。

梯度下降的核心超参是**学习率**（learning rate）：迈步大小。太大一步跨过最优解（loss 发散），太小训练极慢。LLM 训练的全部技巧（AdamW、warmup、余弦退火、梯度裁剪）本质都是"把步子迈得更稳"。

## 2. AdamW：LLM 的标准优化器

Adam 及其改进版 AdamW 是 LLM 训练事实上的标准。Adam 的核心思想是**逐参数自适应学习率**：为每个参数维护一阶矩（梯度均值，动量）和二阶矩（梯度平方均值，控制步长），参数更新幅度与其梯度历史成反比——平坦区域（梯度小）迈大步，陡峭区域（梯度大）迈小步。

AdamW 相对 Adam 的关键修改是**解耦权重衰减**（decoupled weight decay）：权重衰减（L2 正则，让权重别太大，抑制过拟合）不再加进梯度里，而是**直接作用于权重本身**。标准配置（2026 惯例）：

| 超参 | 预训练常用 | 说明 |
|------|-----------|------|
| β₁ | 0.9 | 一阶矩衰减 |
| β₂ | 0.95（Adam 默认 0.999） | 二阶矩衰减，LLM 训练更敏感 |
| ε | 1e-8 | 数值稳定 |
| weight decay | 0.1 | 解耦权重衰减 |

## 3. 学习率：量级与选择

学习率是最重要的训练超参，量级参考（2026）：

- **预训练 7B**：1e-4 ~ 3e-4；模型越大通常越低。
- **全量微调**：一般低于预训练，常用 5e-5 量级——底座已收敛，大步长会破坏已有能力。
- **LoRA/QLoRA 微调**：2e-4 是常用起点（适配器是低秩增量，可以比全量微调激进一些）；5e-5 量级用于保守场景（更保护预训练知识）。

微调常见的学习率搜索范围是 5e-6 ~ 2e-4。选型的完整方法论（网格搜索、日志分析）在 `../训练关键超参 & 显存优化技术/` 体系，本篇记住量级即可。

## 4. warmup 与学习率调度

**warmup（预热）**：训练最开始用很小的学习率，逐步线性升到峰值。为什么必需，两个原因：一是训练初期模型处于不稳定的激活/梯度状态，直接上大学习率会把训练打爆；二是 Adam 的二阶矩估计（v）需要数据"填充"，预热给了它时间积累出合理估计再放大大更新。惯例：线性 warmup 约占总步数 1-2%（如 6000 步训 200 步），或 warmup_ratio 0.03。

**余弦退火**（cosine decay）：warmup 之后学习率按余弦曲线从峰值衰减到峰值的 ~10%。为什么余弦：前期慢降稳住收敛，后期快降帮助落入更优的最小值（更平坦的极小点，泛化更好）。2026 惯例：**微调任务 cosine 调度最通用**——长训练用 cosine_with_restarts，极短训练用 constant_with_warmup（warmup 后恒定），线性调度适合短跑。

配套的**梯度裁剪**（gradient clipping，如 max norm 1.0）：把梯度的范数限制住，防止个别异常 batch 造成灾难性更新——它与 warmup 并称 LLM 训练的两道"保险丝"。

显存受限时还可以用 **8-bit 优化器**（bitsandbytes，优化器状态压缩到 8 位）：优化器状态是 AdamW 显存大头，8-bit 化直接砍掉一半以上，是 QLoRA 方案的标配之一。

## 5. 学习率实操：从哪开始、怎么调

学习率的调试有固定的操作路径（配合 `../训练关键超参 & 显存优化技术/` 体系的方法论）：

**第一步，定起点**。按微调类型取量级：LoRA/QLoRA 从 2e-4 起步、全量微调从 5e-5 起步、不确定时取 1e-4 中间值。不要从 1e-3 这种"看起来很整"的数字开始——LLM 微调的学习率几乎总在 5e-6 ~ 2e-4 区间内。

**第二步，跑短试**。用一个小跑（几百步）观察前 1/3 步数的曲线：训练 loss 发散或震荡剧烈 → 学习率过高，降 3-5 倍；训练 loss 几乎不动、grad norm 极小 → 学习率过低，升 3-5 倍；曲线平滑下降 → 进入第三步。

**第三步，定调区间**。在起点附近做对数网格搜索（如 1e-4、2e-4、4e-4），各跑小训练到 10-20% 步数，用验证 loss 对比，选最优者做完整训练。**注意梯度范数**（grad norm）：训练中段异常飙升（>10 且持续）多半是数据问题（脏样本/重复样本）而非学习率问题——先查数据再调参。

**2026 提醒**：Baseten 后训练科学的研究结论是"大多数超参仍要为每个新模型新数据重新摸索"——所以**抄别人的配置必须带着验证集复验**，平台默认值（如各类 Trainer 的默认 lr）也只为通用场景设计，不是最优解。

## 6. 2026 研究动态

两件值得关注的事：**Baseten 后训练科学（2026-06）** 系统测量了学习率、batch size 等超参随模型规模/家族/数据的迁移规律，结论是"大多数超参仍要为每个新模型新数据重新摸索"——即超参选择目前仍是经验科学，抄别人配置要带警惕。

**ICLR 2026 的 batch 调度研究**（Fast Catch-up, Late Switching）发现：简单任务 batch 可以全程递增，困难任务应先用小 batch 后期再切大 batch——训练策略正从"固定配置"走向"动态调度"，但企业微调阶段用固定配置 + 监控即可。

> 🎯 **核心要点**：训练 = 前向算 loss → 反向算梯度 → 优化器更新权重；AdamW = 自适应学习率 + 解耦权重衰减（β₁=0.9/β₂=0.95/wd=0.1）；学习率量级：全量微调 5e-5、LoRA 2e-4 起点、7B 预训练 1e-4~3e-4；warmup（1-2% 步数）+ 余弦退火是标准调度；梯度裁剪 1.0 兜底——超参是经验科学，抄配置要警惕。
