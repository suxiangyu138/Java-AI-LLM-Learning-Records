# 边界判断面试题

> 面试必问 8 题与答题范式——"定位 → 原理 → 边界 → 量化"四段式，把边界判断答成送分题

## 1. 面试必问 8 题

**Q1：什么时候该微调，什么时候不该？**
答：先做缺口诊断——**知识缺口（事实/时效/私有数据）→ RAG；行为缺口（格式/风格/一致性）→ Prompt 先试，失败才微调**。决策顺序是 Prompt → RAG → Tools → 微调，层层递进，微调是最后手段。不该微调的六类：知识注入、快速变化需求、无 ML 团队、当捷径、强监管、数据不足。企业最贵的错误是用微调解决知识问题（微调注入事实反而增加幻觉）。

**Q2：微调 vs RAG 怎么选？**
答：知识缺口是 RAG 主场（实时、可溯源、无幻觉放大、成本与数据量解耦）；微调注入知识把事实冻结在训练时点且增加幻觉（Ovadia 研究）。2026 实证研究（5 月地理学刊）发现无普遍最优：低复杂度召回 RAG 优、多步推理相当、创意综合微调优——边界按任务复杂度移动。生产默认是"RAG 管事实 + 微调/Prompt 管形式"分层。

**Q3：数据量多少才值得微调？**
答：数据量阶梯——<1000 例 Prompt 更优（匹配或超越微调）；1k-50k PEFT 默认；50k+ 全量可竞争；500k+ 继续预训练候选。两个修正：先查 token 重叠（>70% 模型已内化，提示词即可）；chat-tuned 基座需求降 5-10×。SFT 常用 1000-10000 高质量指令对，质量严格优先（一致性/正确性/覆盖性/去重）。

**Q4：LoRA 和全量微调怎么选？**
答：数据量决定——1k-50k LoRA 默认（参数少 10000×、显存 1/3、遗忘小、推理无延迟惩罚）；50k+ 全量可竞争（LoRA 低秩容量可能成瓶颈）。显存决定——7B 全量 ≈ 56GB+（优化器状态占大头）、LoRA 单卡、QLoRA（4-bit）48GB 单卡训 65B。LoRA 三边界：低秩容量/质量差距/遗忘仍可能。

**Q5：什么是灾难性遗忘？怎么防？**
答：微调把所有权重推向窄任务，预训练知识被覆盖——**高危组合：<1000 例 + 7B+ 模型 + 多 epoch，2 epoch 即可能发生**（任务 99% 准确但基础问题答不出）。检测：预训练任务 held-out 集逐 epoch 评估 + 通用 perplexity 对比 epoch-0。防：LoRA（权重改动受限）、低 lr（1e-5）、EWC、replay 混合通用数据；小而同质数据上的激进全量微调无法完全消除遗忘。

**Q6：训练 loss 降但效果差，为什么？**
答：过拟合的经典形态——训练 loss 持续降、验证 loss 平台或升（loss 背离）；loss 曲线可欺骗（50 例训 35 epoch 训练 loss 仍降但生产失败）——**验证集必须 held-out 且跨时段/来源**。2026 研究补充：同质数据 SFT 有效窗口只有前几百到 1000 步，之后重新学习噪声且损失差距不可见——要监控任务指标 + 通用能力双线。

**Q7：长上下文模型出现后，微调还有用吗？**
答：边界迁移但没消灭微调——"放得下"的知识进上下文（提示缓存降成本）、"放不下但找得到"用 RAG、"又大又高频且行为固定"才是微调候选。微调仍管：一致性结构化输出、风格人格、领域格式、蒸馏小模型化、评估标准化——**行为内化 vs 上下文携带的边界是"稳定高频"**。

**Q8：实际项目里你们最终怎么组合的？**
答：生产默认是混合分层（微软公式）——**fine-tune for form（微调管格式/风格）、retrieve for facts（RAG 管事实/溯源）、prompt to orchestrate（Prompt 管会话策略/守卫）**；单一策略达标就单选（混合是过度工程）；ROI 判断（请求量 × 冗余 token vs 训练摊销，百万级日请求微调回本、千级 Prompt 完胜）；强监管场景治理闭环（数据/评估/发布/审计）。

## 2. 场景判断题（快速自测）

1. 客服需要最新产品知识 + 固定回复格式 → 知识 RAG + 格式微调/Prompt（分层）。
2. 500 条历史邮件要学回复风格 → 先重叠检查；高重叠 → few-shot；低重叠 → LoRA 500 例试训。
3. 金融合规需要 JSON 输出 99.9% 合规 → Prompt 95% → LoRA 微调（行为缺口 + 数据可攒）。
4. 内部工具千级请求要品牌语气 → Prompt + 缓存完胜，不微调（ROI 不过）。
5. 医疗病历抽取 + 术语表 → RAG 术语 + PEFT 格式 + 治理闭环（强监管）。

## 3. 答题范式：四段式

**定位 → 原理 → 边界 → 量化**：

1. **定位**：先给决策框架（知识 vs 行为、决策顺序）——面试官要的是框架不是结论。
2. **原理**：讲机制（微调注入知识增加幻觉、遗忘的权重覆盖机制、SFT 去噪窗口）——有原理才有深度。
3. **边界**：给条件（数据量阶梯、重叠度、基座类型、请求量 ROI）——边界是判断力的体现。
4. **量化**：给数字（<1000 例、1k-50k、50k+、500k+、2 epoch、1000 步、缓存 10%）——数字让答案可信。

**常见失分点**：只答"看情况"（无框架）；只答"RAG 比微调好"（过时认知，2026 实证是随任务切换）；只答微调优点（无成本与风险）；答不出数据量数字（边界判断的量化是核心）。

## 4. 记忆口诀

- 诊断：**"不知道" → RAG；"不守规矩" → Prompt 先试**。
- 顺序：**Prompt → RAG → Tools → 微调**（最后手段）。
- 数据：**1000 / 50k / 500k 三线**（Prompt / 全量 / 继续预训练）。
- 止损：**2 epoch 遗忘、1000 步窗口、loss 会骗人**。
- 组合：**form / facts / orchestrate**（微调管形、检索管实、提示管策）。

> 🎯 **核心要点**：8 题覆盖决策框架/知识边界/数据阈值/方式选择/失败止损/趋势迁移/混合架构全维度；答题四段式（定位→原理→边界→量化）把"看情况"升级为"有框架有数字"；记忆口诀五条是面试现场的最后防线。
