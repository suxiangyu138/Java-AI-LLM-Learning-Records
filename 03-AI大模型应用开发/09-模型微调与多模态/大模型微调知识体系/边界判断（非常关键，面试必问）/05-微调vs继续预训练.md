# 微调 vs 继续预训练

> 500k+ 领域数据的阈值、Finetuner's Fallacy（2026）与 SPT 策略、继续预训练与 SFT 的分工

## 1. 能力层级：预训练 > 继续预训练 > 微调

模型能力的注入有三个层级，边界判断先分清楚：

| 层级 | 干什么 | 数据量级 | 成本 |
|------|--------|---------|------|
| 预训练 | 从零学语言与世界知识 | 万亿 token | 极高 |
| 继续预训练 | 向已有模型注入领域知识与词汇 | 亿级 token | 高 |
| 微调（SFT） | 学行为模式（指令跟随/格式） | 千-万级样本 | 低 |

判断口诀：**"学领域知识 + 领域词汇" → 继续预训练候选；"学行为模式" → 微调**。SFT 不是"小号预训练"——它教的不是知识而是"怎么回应"；用 SFT 硬灌知识是边界错位（幻觉风险见 03 篇）。

## 2. 数据量阈值：500k+ 是继续预训练的入场线

数据量阶梯（2026 共识）：**<500-1000 例** → Prompt；**1k-50k** → PEFT 微调；**50k+** → 全量微调可竞争；**500k+ 领域样本** → 继续预训练值得认真考虑。阈值的逻辑：**继续预训练要改变权重里的知识分布，需要足够样本形成统计信号**——万级样本对万亿级预训练分布是噪声，百万级才开始有信号。

继续预训练 + SFT 的经典组合（领域模型的完整路径）：**继续预训练（注入领域语料）→ SFT（对齐指令行为）→（可选）RLHF**——知识在预训练层注入，行为在 SFT 层对齐，两层各司其职。边界判断：**只有领域知识且行为基座已够好** → 单做继续预训练；**知识 + 行为都要** → 两段式。

继续预训练的实操注意事项：**语料质量与去重**（领域语料的噪声与重复会被放大——预训练对数据量的胃口大，质量门槛同样高）；**词汇扩展**（新领域术语进 tokenizer——词表扩展要同步调整 embedding 层，是继续预训练独有的工程点）；**评估基线**（继续预训练前跑通用基准，训练后对比——通用能力下降是继续预训练的常见代价，下降幅度决定"值得不值得"）；**算力预算**（继续预训练的成本高于微调一个量级——500k 门槛的本质是"数据量要撑得起算力投入"）。

## 3. Finetuner's Fallacy（2026）：领域数据前置的悖论

2026 年 3 月的论文（arXiv 2603.16177）提出"微调者的谬误"：**在稀缺领域数据上微调，同时冒着领域过拟合与通用知识遗忘的风险**——微调前的模型本可以用领域数据做得更好。

核心发现与策略：**专用预训练（SPT）**——把领域 token 按 0.1-10% 的比例混入通用预训练流，能：降低领域测试损失、缓解微调后的灾难性遗忘、**减少最多 1.75× 的预训练 token 需求**。论文还推导了**过拟合缩放定律**（overfitting scaling laws），指导给定算力预算下的最优领域数据重复次数。

工程含义：**有大量领域语料 + 有预训练算力** → SPT 混合（数据前置）比"通用预训练 + 事后微调"更优；**只有微调算力**（大多数团队）→ 领域数据前置不可行，微调仍是务实路径，但要接受遗忘风险（08 篇止损）。面试答"为什么微调会遗忘"时引 SPT 的机制解释，就是 2026 深度。

## 4. SFT 的定位修正：去噪而非注入

2026 年 6 月的论文（arXiv 2605.17967，"Reconciling Contradictory Views on the Effectiveness of SFT"）修正了 SFT 的定位：**在高度同质的数据上，SFT 主要起"去噪"作用，且只在训练的前几百到约 1000 步有效**——之后模型重新学习噪声交互模式，测试性能不再提升，这是损失差距中不可见的过拟合。

```text
SFT 有效窗口示意：
训练步数 → 0-1000 步：去噪（有效提升）
         1000 步+：重新学习噪声（无效甚至有害）
```

三个工程推论：**SFT 不是"训练越久越好"**（有效窗口窄，early stopping 是纪律不是选项，08 篇细讲）；**数据质量 > 数据量**（噪声模式会在窗口后被重新学习——脏数据在 SFT 的代价被放大）；**同质数据的小模型微调**（如领域对话）尤其要控制步数——1000 步附近就该验证。

## 5. 边界判断实战：领域模型的完整决策

"要不要继续预训练"的决策树：

```text
领域语料 ≥ 500k 样本？
├── 否 → 微调（PEFT）足够——领域知识少，SFT 行为对齐即可
├── 是 → 有预训练/继续预训练算力？
│        ├── 是 → 评估 SPT（数据前置）或继续预训练 + SFT 两段式
│        └── 否 → 微调 + 接受遗忘风险（08 篇止损），或考虑 API 领域模型
```

实战案例判断：**医疗领域模型**——病历语料千万级 + 有算力 → 继续预训练 + SFT；**客服风格模型**——行为为主、知识靠 RAG → 纯 SFT（PEFT）；**法律合同抽取**——格式行为 + 少量术语 → PEFT + RAG 术语表。三个案例覆盖"继续预训练 / 纯微调 / 微调+检索"三种形态——**边界判断的输出不是"微调 or not"，是"哪一层注入什么"**。

成本视角的补充判断（继续预训练 vs 微调的最后一关）：**算力差一个量级**（继续预训练 7B 也要多卡 × 多天，微调单卡 × 小时级）；**数据门槛差两个量级**（500k+ vs 1k-50k）；**基座选择可替代**（很多"想继续预训练"的诉求，换成更强的基座 + 微调就能满足——**先问"换基座行不行"再问"继续预训练行不行"**）。落点：继续预训练是"有领域语料 + 有算力 + 基座不够"三条件的交集，缺一就退回微调 + RAG 组合——成本账是最后的裁判。面试答"领域模型怎么做"时按"先换基座 → 再微调 → 最后继续预训练"的升级顺序答，比直接说"继续预训练"成熟一个量级——**升级顺序本身就是边界判断的体现**。

> 🎯 **核心要点**：能力三层级（预训练/继续预训练/SFT）各管知识与行为；500k+ 是继续预训练入场线；Finetuner's Fallacy（2026）揭示领域数据前置（SPT）更优——有算力时数据前置、没算力时接受遗忘风险；SFT 是去噪不是注入，有效窗口在前几百到 1000 步；决策输出是"哪层注入什么"而非"微调 or not"。
