## 3. 为什么必须学透边界判断

1. **面试必问的送分题与送命题**：面试官 100% 会问"什么时候微调、什么时候 RAG"——答"看情况"是送命，答"知识缺口 vs 行为缺口 + 决策顺序"是送分，本体系给完整答题范式。
2. **企业 AI 最贵的错误是"用微调解决知识问题"**：研究（Ovadia 2023）表明在事实性内容上微调**反而增加幻觉**——边界判断错了，钱、算力、时间全打水漂，这是工程决策的学费最贵处。
3. **2026 年边界在移动**：长上下文模型兴起（上下文放得下更多知识）、提示缓存降价（缓存读成本约输入 10%）、2026 实证研究（无普遍最优策略，随任务复杂度切换）——**老教程的"RAG vs 微调"二元认知已不完整**。
4. **混合是生产默认**：微软 2026 指导是"**fine-tune for form, retrieve for facts, prompt to orchestrate**"——边界判断的终点不是单选，而是分层组合，面试答出这层就是深度。
5. **止损能力是工程成熟度标志**：过拟合、灾难性遗忘、SFT 窄有效窗口——会判断"什么时候该停"比会"跑起来"更值钱。

## 4. 核心概念速查

### 4.1 核心概念

| 概念 | 一句话 | 关键数字 |
|------|--------|---------|
| 知识缺口 | 模型不知道/信息过时/私有数据 | → RAG，不是微调 |
| 行为缺口 | 格式/风格/语气/结构化输出 | → Prompt 先试，微调兜底 |
| 决策顺序 | Prompt → RAG → Tools → 微调 | 层层递进 |
| PEFT | 参数高效微调（LoRA 等） | 1k-50k 数据默认 |
| QLoRA | 4-bit 量化微调 | 单卡 48GB 训 65B |
| 灾难性遗忘 | 小数据+大模型 2 epoch 即发 | <1000 例高危 |
| SFT 窄窗口 | 前几百到 1000 步有效 | 之后是过拟合 |
| 混合默认 | form/facts/orchestrate 分层 | 生产标准 |

### 4.2 数据量阈值阶梯（时效性重点）

| 数据量 | 推荐策略 |
|:------:|---------|
| <500-1000 例 | Prompt/few-shot 匹配或超越微调 |
| 1k-50k | **PEFT（LoRA）默认** |
| 50k+ | 全量微调可竞争 |
| 500k+ | 继续预训练值得认真考虑 |

### 4.3 已知误区速查（面试与工程都必避）

- "微调能注入知识" → 错：知识缺口是 RAG 主场，微调注入增加幻觉
- "数据越多越好" → 错：质量优先，1000-10000 高质量指令对是 SFT 常用量
- "训练 loss 降就是好" → 错：loss 曲线可欺骗，验证集要 held-out 且跨时段
- "微调是捷径" → 错：最快、最贵、治理最重的杠杆，应最后动用

## 5. 与周边知识的关系

```text
                    ┌── 大模型微调知识体系/ —— 微调本体（PEFT/QLoRA/数据集/超参）
                    ├── 03-AI.../02-RAG检索增强生成/ —— RAG 方法论（知识缺口的方案）
                    ├── 02-大模型基础与Prompt工程/ —— Prompt 工程（行为缺口的第一方案）
                    ├── 01-大模型基础/ —— 预训练与模型能力边界
                    └── 05-模型部署与工程化/ —— 推理成本与部署约束
```

**本体系与同级子体系的分工**：`PEFT 参数高效微调`、`训练关键超参`、`数据集体系` 讲"微调怎么做"；本体系讲"**要不要微调、什么时候停**"——是微调体系的决策层，也是面试的入口层。读法建议：先读本体系（决策），再进 PEFT/数据集（执行）——**先判断做不做，再学怎么做**。

## 6. 学习路线推荐

**路线一：面试速成（半天，对应模块 01-03 + 10）**
决策框架 → Prompt 边界 → RAG 边界 → 面试题；掌握"知识 vs 行为"诊断 + 决策顺序 + 答题范式，面试最常考的部分全覆盖。

**路线二：工程决策深化（2-3 天，对应模块 04-08）**
上下文/工具边界 → 继续预训练边界 → PEFT 边界 → 数据阈值 → 失败信号；建立完整的"该不该微调 + 什么时候停"判断能力。

**路线三：生产决策者（对应模块 09-10）**
成本收益量化 → 混合策略 → 面试题；用 ROI 计算与治理边界支撑真实选型，混合架构是生产标配。

> 🎯 **核心要点**：边界判断的学习终点 = "**会诊断（知识 vs 行为）、会排序（Prompt→RAG→Tools→微调）、会定量（数据阈值/成本 ROI）、会止损（失败信号/early stopping）、会组合（form/facts/orchestrate）**"——五件事覆盖从面试到生产的全部决策场景；记住"微调是最后手段"是贯穿始终的第一原则。
