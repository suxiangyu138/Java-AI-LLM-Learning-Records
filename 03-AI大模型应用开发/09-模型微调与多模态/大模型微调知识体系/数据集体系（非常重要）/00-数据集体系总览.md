## 3. 为什么必须学透数据集体系

1. **数据是微调的唯一杠杆**：模型底座（Qwen/Llama）选好之后，微调效果几乎完全由数据决定——2026 年实证反复证明"335 条干净数据胜过 1576 条噪声数据"（微软）、"约 1000 条专家数据可匹敌 5 万条泛数据"（LIMA）——**调参调不动数据质量的差距，先数据后模型**。
2. **面试高频区**：面试官爱问"数据怎么来""怎么保证质量""怎么去重""合成数据怎么用"——本体系 03/05/07 篇直接给答案，且都带 2026 最新方法（SDGT、MinHash 三级去重、LLM judge）。
3. **2026 年是合成数据的转折年**：合成数据已从"补数量"升级为"定质量"——reference-level feedback（EACL 2026）解决"合成数据无法超过生成模型"的质量天花板；同时合成数据的三个坑（教师偏差、模式坍缩、许可限制）必须有对策。
4. **治理已立法化**：EU AI Act 2026 年 8 月起执行（Article 10 要求可审计的训练数据记录）——数据版本、血缘、PII 处理不再是"加分项"而是"合规义务"，本体系 09 篇给落地清单。
5. **踩坑代价最高**：数据错误是微调最贵的错误——污染（benchmark 泄漏）让评估全假、重复样本伪造 eval loss、PII 泄漏让模型背出客户电话——本体系的每篇都在帮你避免学费级事故。

## 4. 核心概念速查

### 4.1 核心概念

| 概念 | 一句话 | 关键数字 |
|------|--------|---------|
| 质量 > 数量 | 干净小数据胜噪声大数据 | 335 vs 1576（微软实证） |
| 种子集 | 人工手写的数据标准 | 150-200 条起步 |
| 合成数据 | LLM 生成训练数据 | 底部 10-20% 由 judge 淘汰 |
| 三级去重 | MD5 → MinHash → 语义聚类 | Jaccard ≥ 0.8 |
| 污染检测 | 训练集 vs benchmark 重叠检查 | 命中即拒（hard reject） |
| DPO 偏好对 | prompt/chosen/rejected | chosen 质量是主导因素 |
| LLM judge | 大模型给数据打分 | 与人工一致性需抽检 |
| 记忆化 | 模型背出训练数据 | 稀有+重复样本最高危 |
| 数据版本 | SHA256 + 版本绑定模型 | 每次训练前建版 |
| EU AI Act | 训练数据可审计 | 2026-08 开始执法 |

### 4.2 数据量级阶梯（与边界判断 07 篇呼应）

| 数据量 | 用途 | 说明 |
|:------:|------|------|
| 150-200 条 | 种子集 + 金标评估集 | 人工手写 |
| 1k-5k | 研究原型 | 质量全检 |
| 10k-50k | 生产 v1 | 清洗+去重+评估流水线 |
| 50k-200k | 多轮生产 v2 | 平衡 + 版本治理 |

### 4.3 常见误区速查

- "数据越多越好" → 错：质量优先，噪声数据稀释学习信号
- "合成数据随便生成" → 错：有质量天花板，需要 reference-level 引导
- "去重只做精确去重" → 错：改一个字就漏掉，需三级联动
- "评估集随手切" → 错：必须做污染检测，否则评估结果全假

## 5. 与周边知识的关系

```text
                    ┌── 基础概念/ —— 概念层（数据格式/掩码基础，见 08 篇）
大模型微调知识体系 ├── 边界判断/ —— 决策层（数据量阈值判断，见 07 篇）
                    ├── 数据集体系/ —— 执行层·数据（本体系：怎么做数据）
                    ├── PEFT / 超参 / 流程 / 常见问题 / —— 执行层·训练
                    └── 03-AI.../02-RAG检索增强生成/ —— 知识注入的另一路径（数据边界）
```

**本体系与同级子体系的分工**：`基础概念` 08 篇讲"数据长什么样"（概念），本体系讲"数据怎么做出来、做干净、管起来"（工程）；`边界判断` 07 篇讲"多少数据该用什么策略"（决策），本体系讲"数据在选定策略下如何构建"（执行）。读法建议：**基础概念（格式是什么）→ 本体系（数据怎么做）→ 边界判断（多少才够）→ PEFT/超参（怎么训）**。

## 6. 学习路线推荐

**路线一：面试速成（半天，对应模块 01-03 + 07 + 10）**
质量第一性原理 → 类型全景 → 获取三路径 → 质量评估 → 面试题；覆盖面试数据题 80% 考点。

**路线二：数据工程入门（1-2 天，对应模块 01-08）**
从"数据怎么做出来"到"怎么做干净、做平衡"全链路，配合一次真实微调的数据准备实践。

**路线三：治理与规模化（对应模块 05 + 09）**
去重/污染检测 → 版本/合规；面向生产与强监管场景，EU AI Act 2026 执法是刚需。

> 🎯 **核心要点**：数据集体系的学习终点 = "**懂原理**（数据决定天花板，质量>数量）、**会获取**（人工种子 + 合成 + 公开三路径）、**会清洗**（格式/内容/完整性）、**会去重**（三级联动 + 污染检测）、**会评估**（红旗清单 + LLM judge）、**会平衡**（配比 + 聚类 + 防遗忘）、**会治理**（版本 + 血缘 + 合规）"——七件事覆盖数据从出生到退役的全生命周期。
