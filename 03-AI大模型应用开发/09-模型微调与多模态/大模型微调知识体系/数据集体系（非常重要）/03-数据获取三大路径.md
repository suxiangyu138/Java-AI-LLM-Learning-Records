# 数据获取三大路径

> 数据从哪来：公开数据集（捡现成）、人工种子集（定标准）、合成数据（扩规模）——2026 年生产标准是三条路组合而非单选

## 1. 路径总览与组合原则

数据获取有三条路径，各有分工：

- **公开数据集**：已有社区数据（Alpaca、ShareGPT、UltraFeedback、LMSYS-Chat-1M 等）——便宜快速，但**与业务场景天然错位**，只能做通用能力基座，不能直接当业务数据。
- **人工种子集**：专家手写 150-200 条示例——**定义质量标准与格式规范**，同时充当金标评估集，是三条路径的"锚"。
- **合成数据**：用大模型（teacher）生成训练数据——**规模化扩数据的唯一可行路径**，2026 年已从"凑数量"升级为"控质量"。

微软 2026 工作流明确建议三路组合：**人工定标准 → LLM 扩写 → judge 过滤**（路径先后顺序即优先级：种子集先行、合成居中、公开数据殿后）。纯用公开数据（场景错位）、纯靠人工（规模不够）、纯用合成（质量天花板 + 模式坍缩）都是单腿走路——三条路的组合是生产标准。完整六步流程见 07 篇（评估与筛选）。

## 2. 路径一：公开数据集

捡现成的三个注意点：

**来源与许可**：Alpaca（单轮指令，开源）、ShareGPT（多轮对话，注意其使用条款与去重问题）、UltraFeedback（偏好数据，GPT-4 打分）、LMSYS-Chat-1M/WildChat（真实用户对话，隐私与清洗成本高）。**每个来源先查许可**——部分数据集的条款禁止用于训练竞争模型或商用（03 篇末的许可红线在 09 篇展开）。

**自带偏差**：UltraFeedback 的 GPT-4 打分系统性偏好"更长、更结构化"的回答——用它做偏好数据，模型会学出"话痨"倾向；ShareGPT 质量参差（用户提问口语化、回答好坏混杂）。**上游筛选不等于可信**——必须过自己的清洗/去重/评估流水线。

**与业务错位**：公开数据覆盖的是通用指令分布，业务场景（客服话术、行业术语、产品格式）几乎为零。2026 共识：公开数据只当"通用能力保持剂"（混入少量防遗忘，见 08 篇），业务能力必须靠种子集 + 合成。

常用公开数据清单（按用途选）：**Alpaca**（5 万+ 通用单轮指令，入门基座）、**Dolly-15k**（通用指令遵循，人工编写更干净）、**GSM8K**（数学推理，可重排为思考格式）、**ShareGPT**（真实多轮对话，需拆分与清洗）、**UltraFeedback**（偏好数据）、**LMSYS-Chat-1M/WildChat**（真实用户对话，隐私与清洗成本高）。

选型要点：先查许可（商用条款）、再看源头质量报告（部分数据集 README 自带缺陷说明）、最后必须过自己的流水线——**上游筛选不等于可信**。

## 3. 路径二：人工种子集

人工手写不是"写数据"，而是**定标准**：150-200 条（微软建议起步 10-20 条建立质量标准与格式一致性，再扩展到 150-200）覆盖任务类型与边界案例（质量四维见 01 篇）。种子集的双重身份：**训练数据的模板**（LLM 扩写/合成的种子）与**金标评估集**（模型好坏的唯一裁判）。

写作要点：覆盖每个任务类型的正常案例 + 边界案例（拒答、模糊、极端格式）；格式完全一致（同一套 system/user/assistant 结构）；每条都要经过人工评审（双人互检或领域专家把关）——种子集的质量错误会沿着"种子 → 合成 → 训练"链条放大，是最高杠杆的检查点。

## 4. 路径三：合成数据（2026 重点）

合成数据的三步基本盘：**定义类别 → 生成 prompt → 生成回答 → LLM judge 过滤 → 拆训练/验证**。2026 年的三个方法升级值得掌握：

**种子驱动增长（SDGT）**：用极少种子示例 + GPT-4 类大模型扩展生成多样化高质量数据——实验显示 SDGT 数据训练的模型达到人工数据得分的 88%-114%。限制：依赖种子质量、算力成本、继承教师偏差。

**分解式合成（DecIF，ACL 2026）**：把数据合成流水线分解为细粒度步骤，分别控制质量与多样性——从零生成高精度指令遵循数据（SFT 与 RL 都适用）。

**参考级反馈（Reference-Level Feedback，EACL 2026）**：解决合成数据最大的天花板问题——"模型训练数据无法超过生成它的模型"。做法：从人工参考样本提取"理想特征"，引导合成过程逼近参考水平——REFED 数据集（1 万对）在 AlpacaEval 2.0 上以 Llama-3.1-8B 获得 43.96% 长度控制胜率，超过样本级反馈方法。**这是 2026 年合成数据最重要的质量突破**。

合成数据三坑：**教师偏差继承**（学生学教师的怪癖——混合多个教师模型缓解）；**模式坍缩**（纯合成训练在真实用户长尾输入上退化——真实用户问题更短、更模糊、更敏感，务必在合成热身后补一轮真实数据微调）；**许可限制**（前沿模型 ToS 常禁止用其输出训练竞争模型——商用前查条款）。

## 5. 偏好数据的获取特化

偏好数据的三元组（prompt/chosen/rejected）获取有三条特化路径：

**真实反馈**：线上赞踩/评分日志——最可靠（真实用户偏好），但噪声高（要清洗 + 二重标注）、覆盖窄（只覆盖线上出现过的 prompt）。法语文化部背书的 Compar:IA 数据集（2026）就是"真实人类投票 → 清洗为 chosen/rejected 对"的范例。

**合成偏好对**：同一 prompt 让大模型生成多个回答，judge 打分选最好/最差组成对（EQ-DPO 的做法：5 个不同温度回答 + 对裁判置信度 margin > 0.15 的保留）。2026 多语言偏好数据的三种架构（全翻译/翻译 prompt 重生成/生成后翻译 rejected）验证了"重生成优于全翻译"。

**复用与重组**：Anthropic HH-RLHF、UltraFeedback 等标准偏好数据 + 自己的 judge 重打分。注意 NeurIPS 2025 的结论始终适用：**精力花在保证 chosen 质量**，chosen 是主导变量。

> 🎯 **核心要点**：三路组合是生产标准——种子集定标准（150-200 条，兼当评估集）、合成数据扩规模（SDGT/DecIF/参考级反馈破质量天花板）、公开数据当通用保持剂；合成三坑（教师偏差/模式坍缩/许可）必须设防；偏好数据坚持"chosen 质量主导"原则；真实数据收尾是合成路线的必选项。
