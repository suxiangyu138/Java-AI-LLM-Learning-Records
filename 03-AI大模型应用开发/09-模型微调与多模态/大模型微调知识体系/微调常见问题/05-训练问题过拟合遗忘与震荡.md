# 训练问题（下）：过拟合、遗忘与震荡

> 训练"成功"后的三类隐形失败：过拟合（背题）、灾难性遗忘（变笨）、loss 震荡（不稳定）——2026 年新增"摩擦签名"监控法：in-task loss 会穿过坍缩不告警

## 1. 过拟合：背题而不学规律

**症状**（三信号，`../基础概念/09-评估基础损失曲线与过拟合.md` 02 节）：训练 loss 逼近 0、验证 loss 背离；模型复读训练样本（问"你好"背出训练数据原句）；验证指标在某个 checkpoint 后下滑。

**诊断**：train-eval gap 持续拉大；背题探测（用训练集样本做推理，看是否逐字复读）；**2026 新方法——摩擦签名（friction signature）**：in-task 验证 loss 会"直穿坍缩而不告警"（loss 照降、推理能力已崩），可靠的预警信号在输出分布里——**per-token 熵方差与 lag-1 自相关**在窄微调侵蚀通用推理时提前上升（在 Qwen2.5-1.5B、Phi-3.5-mini、SmolLM2-1.7B 三个家族复现）；该监控**自我校准**（相对每次运行自身的开局基线触发，无全局阈值），且在三个坍缩家族中全部提前预警。

**修复**（按序）：early stopping（验证 loss 连续 2-3 点不降即停）→ 降 epoch（3→1-2）→ 降学习率 → 加正则（注意 LoRA dropout 在短训练里作为正则不可靠，`../基础概念/06-训练循环Epoch-Batch-Step.md` 03 节）。

**过拟合与数据的关系**：过拟合本质是"模型容量 > 数据信息量"——同一份数据，7B 模型比 1B 更容易过拟合（容量大、记忆空间足）；**小数据 + 大模型的过拟合信号出现得极早**（几百条数据 2 个 epoch 就可能开始背题）——小数据场景的默认姿势是低 epoch（1-2）+ 早停，而不是堆正则。

## 2. 灾难性遗忘：微调后"变笨"

**症状**：目标任务变好，但通用能力退化——普通对话变怪、通用知识问答变差、标准基准（MMLU 类）回归（回归 >1-2% 即确认，`../完整微调工程流程/03-评估先行基线建立.md` 04 节门禁）。2026 实锤案例：微调后的模型在**它专门训练的任务**（ARC）上比未训练基线还差，HellaSwag 掉 4.8%——专门化直接摧毁了通用推理。

**2026 机制研究**：持续训练中的**神经元替换/剪枝**是遗忘的元凶之一——领域偏移实验中，启用替换的模型平衡训练后掉 8.34%，禁用替换与剪枝（只增不改，神经元按梯度幅度阈值积累而非竞争）后掉 0.00%（注意力/嵌入/LM 头冻结，只扩 FFN）。另一方向（TMLR 2026）：把 token 分为"正 token"（正常训练）与"负 token"（无语义/误导——**显式遗忘**），显式遗忘负 token 在多基准、多架构上一致提升。

**检测**：通用能力回测（微调前后跑同一组通用题）；标准基准回归检查；**回测是评估矩阵的必选项**（只测任务不测通用 = 残缺评估，`../完整微调工程流程/08-模型评估与验收.md` 01 节）。

**遗忘的"早发现"**：遗忘不是训练后期才发生——小数据 + 大模型在 2 个 epoch 就可能出现（`../边界判断（非常关键，面试必问）/08-失败信号与止损边界.md`）——**通用回测要"训练中"跑**（训练 10-20% 处首次回测，后续每 20-30% 复测），而不是等训练完验收时才发现；回测发现遗忘早期信号（通用分开始下滑）时，还有机会降 epoch 止损，训完才发现只能重来。

**修复**（按序）：降 epoch（1-2 是低遗忘区间）→ 混入 ~10% 通用数据（`../数据集体系（非常重要）/08-数据平衡与多样性.md` 05 节）→ 低学习率（5e-5 量级保护旧权重）→ LoRA（冻结底座天然免疫大部分遗忘）→ 评估加回测（修复的前提是能测到）。

## 3. loss 震荡：不稳定但不一定是错

**症状**：loss 曲线锯齿状波动。三种形态与处置：**正常波动**（小振幅锯齿——batch 间数据差异，正常，看趋势别看单点）；**周期性尖峰**（每 N 步出现——查 dataloader（shuffle 失效/数据顺序异常）、查 eval 与 train 混看（评估 loss 和训练 loss 叠加在一条曲线里被误读）；**持续加剧的震荡**（振幅随时间放大——发散前兆，04 篇第 3 节止损处理）。

**处置**：先确认"哪种震荡"（趋势线 + 振幅统计）；正常波动不动；周期性尖峰查数据顺序与日志配置；加剧震荡按发散处理。**另一个常见误读**：把 eval loss 与 train loss 画在一条曲线里看（评估步与训练步刻度不同，看起来像"震荡"——分开画）。

**震荡的幅度基准**：微调初期（warmup 阶段）震荡大是正常的（学习率爬升 + Adam 状态冷启动，`../基础概念/05-优化器与梯度更新.md` 04 节）；训练中后段振幅应收敛——**振幅不收敛反而增大才是风险信号**，看"振幅趋势"而非"有无振幅"。

## 4. 三类问题的区分诊断

三个症状容易混淆，先区分再修复：

| 症状 | 关键信号 | 方向 |
|------|---------|------|
| 过拟合 | train→0、eval 背离、复读 | 减容量（epoch/lr/正则） |
| 遗忘 | 通用基准回归、对话变怪 | 减训练量 + 混通用数据 |
| 震荡 | 振幅趋势 | 看形态（正常/周期/加剧） |

**一个模型可以同时过拟合和遗忘**（数据少 + epoch 多 + 全业务数据——背了业务题、丢了通用能力）——此时修复方向冲突（降 epoch 两者都缓解），先降 epoch 再评估，**一次只改一个变量**的纪律在这里尤其重要。

## 5. 预防：把"健康信号"加进监控

三类问题的共同教训：**in-task loss 不是健康信号**（摩擦签名实证：loss 穿过坍缩不告警）——把"输出分布信号"加进监控（熵方差/自相关，2026 新方法）或至少把**通用能力回测**作为定期监控项（不只验收时测）；训练早期（10-20% 处）就做首次回测（`../基础概念/09-评估基础损失曲线与过拟合.md` 05 节），后续每 20-30% 复测——**"训练好"的定义要同时包含任务指标与通用指标**，缺一个就是残缺验收。

> 🎯 **核心要点**：过拟合三信号 + 摩擦签名（熵方差/自相关，loss 会穿过坍缩不告警——2026 新监控）；遗忘 = 神经元替换/剪枝机制（只增不改实验 0.00% vs 8.34% 掉点）+ TMLR 2026 显式遗忘负 token；震荡先分形态（正常/周期/加剧）再处置，别把 eval/train 混画；三类先区分再修（可同时存在，降 epoch 是共同缓解）；预防 = 健康信号进监控（输出分布 + 通用回测定期跑）——任务指标与通用指标缺一不可。
