## 3. 为什么必须学透常见问题

1. **面试的必考区是"踩坑"**：面试官几乎必问"你微调时踩过什么坑、怎么排查的"——本体系把 2026 年最高频的坑全部整理成"症状→诊断→修复"卡片，背熟即得分。
2. **微调 90% 的时间在排障**：真正训练只占很少时间——数据格式错、模板不匹配、loss 不降、OOM、效果变差，每个坑都可能耗掉几天。排障手册是把"别人用几天换来的教训"压缩成十分钟的查表。
3. **2026 年最贵的坑有了新名字**：**chat template 不匹配是"第一大静默杀手"**（训练/推理渲染不一致，任何组件单独看都对，组合起来模型直接崩）；**train-serve 精度不匹配**让"benchmark 明星"上线变差（8B 模型 BF16 训、INT4 服务，胜率 23:2 翻转为 2:23）；**PPL 掩盖量化损伤**（PPL 只动 0.04，任务完成率掉 7 点）——这些 2026 实证案例本体系全部收录。
4. **排障纪律本身就是工程能力**：先诊断再动手（不掩盖 bug）、最小复现、nonce 测试（4 样本不可能标签快测）、修复进 git——本体系 01 篇给完整方法论，后面各篇按此执行。
5. **与执行层其他体系互补**：本体系是"症状索引"（出问题查哪），其他体系是"原理答案"（为什么）——排障时两本对照，效率最高。

## 4. 核心概念速查

### 4.1 核心概念

| 概念 | 一句话 | 关键数字 |
|------|--------|---------|
| 排查五步法 | 复现→隔离→假设→验证→记录 | 先诊断再动手 |
| nonce 测试 | 4 样本 + 不可能标签快测 | 训不出 = 链路有问题 |
| 模板不匹配 | 训练/推理渲染不一致 | 2026 第一大静默杀手 |
| 渲染 diff | 训练与推理的 token 序列对比 | 必做检查 |
| train-serve 错配 | BF16 训、INT4 服务 | 胜率 23:2 → 2:23 |
| PPL 掩盖 | PPL 0.04、任务 -7 点 | 领域评估才是硬门禁 |
| 摩擦签名 | 熵方差+自相关监控过拟合 | 自我校准 |
| destroyed weights | 训练后权重被毁（非格式问题） | 原始输出探测 |
| OOM 五步 | QLoRA→降 batch→检查点→降长→换小 | 按序执行 |

### 4.2 问题分类地图（症状 → 章节）

| 症状 | 第一嫌疑 | 章节 |
|------|---------|------|
| 输出垃圾/格式全错 | 模板不匹配 | 02 |
| loss 不降/发散 | 数据或学习率 | 04 |
| 训练好评估差 | 过拟合/同源泄漏 | 03/05 |
| 上线变差 | train-serve 错配 | 07/08 |
| 微调后变笨 | 灾难性遗忘 | 05 |
| 显存爆炸 | OOM 五步 | 06 |
| 莫名报错 | 版本矩阵 | 09 |

### 4.3 常见误区速查

- "报错就重装" → 错：先看错误最后一行 + 完整 traceback
- "loss 降了就是好" → 错：摩擦签名显示 loss 可穿过坍缩不告警
- "PPL 没变就没事" → 错：量化损伤 PPL 看不见
- "每个组件都对就行" → 错：组合才出问题（模板案例）

## 5. 与周边知识的关系

```text
                    ┌── 基础概念/ —— 原理答案（loss/epoch/模板为何如此）
大模型微调知识体系 ├── 数据集体系/ —— 数据问题深潜（泄漏/去重/质量）
                    ├── 完整微调工程流程/ —— 流程与门禁（排障发生在哪阶段）
                    ├── PEFT / 超参 / —— 配置问题深潜（LoRA/显存细节）
                    └── 本体系 —— 症状索引（出问题查哪、怎么查）
```

**本体系与同级子体系的分工**：本体系是**症状驱动的查表手册**（"出 X 现象 → 查 Y 篇 → 按 Z 步骤修"）；其他体系是**原理驱动的知识库**（"为什么这样、正确做法是什么"）。读法建议：遇到问题先查本体系定位，再进对应子体系补原理；面试答题"踩坑"时，用本体系的案例 + 其他体系的原理组合回答最有深度。

## 6. 学习路线推荐

**路线一：面试速成（半天，对应模块 01-02 + 07 + 10）**
排查方法论 → 模板问题 → 效果问题 → 面试题；覆盖面试"踩坑题"80% 考点。

**路线二：实战排障（1-2 天，对应模块 01-09）**
方法论 → 七类问题逐个过；建议配合一次真实微调，把每类问题对照自己的经验复盘。

**路线三：生产排障专家（对应模块 01 + 05 + 07-08）**
方法论 + 遗忘/效果/部署深潜；面向生产环境的复杂故障（组合型问题）。

> 🎯 **核心要点**：常见问题的学习终点 = "**会定位**（问题分类地图）、**会诊断**（五步法 + nonce 测试 + 渲染 diff）、**会修复**（每类问题的标准动作）、**会预防**（2026 教训：模板渲染必查、训练服务精度对齐、领域评估做硬门禁）"——排障手册的价值不在背答案，在建立"症状→根因"的映射直觉；记住"先诊断再动手"是贯穿全部排障的第一纪律。
