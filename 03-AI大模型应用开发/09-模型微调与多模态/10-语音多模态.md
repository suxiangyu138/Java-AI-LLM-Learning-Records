# 10 - 语音多模态

> 🎯 GPT-4o 将语音延迟降到 232ms — 从"语音→文本→LLM→文本→语音"的级联变成端到端。语音 LLM 是下一个战场

## Whisper 语音转文字

```python
from openai import OpenAI
client = OpenAI()

# 语音转文字
with open("meeting.mp3", "rb") as f:
    transcript = client.audio.transcriptions.create(
        model="whisper-1", file=f,
        language="zh", response_format="text"
    )
print(transcript)
```

```python
# 本地 Whisper（免费离线）
import whisper
model = whisper.load_model("large-v3")
result = model.transcribe("audio.mp3", language="zh")
print(result["text"])
```

## GPT-4o 端到端语音

```text
传统级联方案（延迟 2-5s）：
  语音 → STT(Whisper) → 文本 → LLM → 文本 → TTS → 语音
  问题：丢失语气/情感/停顿、延迟高、每个环节可能出错

GPT-4o 端到端（延迟 ~232ms）：
  语音 → 统一多模态模型 → 语音
  优势：保留语气/情感、接近人类对话速度
```

## 语音合成 TTS

```python
# OpenAI TTS
with client.audio.speech.with_streaming_response.create(
    model="tts-1", voice="alloy",
    input="你好，我是 AI 助手"
) as response:
    response.stream_to_file("output.mp3")
```

## 语音 Agent 架构

```text
全语音 Agent 流水线：

  用户语音 → VAD(静音检测) → ASR(语音识别) → NLU(意图理解)
  → Agent(决策+工具调用) → NLG(生成回复) → TTS(语音合成) → 播放

  实时语音 Agent 的挑战：
    → 打断(Barge-in)：用户在 AI 说话时可以打断
    → VAD 准确率：噪音环境下误触发
    → 首字延迟：用户说完到 AI 开始回复的间隔
```
