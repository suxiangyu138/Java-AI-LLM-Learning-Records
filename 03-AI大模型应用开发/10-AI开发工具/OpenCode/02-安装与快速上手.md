## 1. 安装（五平台）

```bash
# ① 官方脚本安装（推荐）
curl -fsSL https://opencode.ai/install | bash

# ② npm 安装
npm i -g opencode-ai@latest

# ③ Homebrew（macOS）
brew install opencode

# ④ Windows（Scoop / Choco）
scoop install opencode
choco install opencode

# ⑤ Linux（pacman）
sudo pacman -S opencode

# 验证安装
opencode --version
```

**Windows 注意：** 需要 Windows 10+，TUI 在 Windows Terminal 中体验最佳。

## 2. 认证登录与模型配置

```bash
# ① 交互式登录（支持 75+ 模型提供商）
opencode auth login
# 选择提供商：Anthropic / OpenAI / Google / DeepSeek / GLM / GitHub Copilot...
# 浏览器授权 或 粘贴 API Key

# ② 在 TUI 中连接
/connect

# ③ 查看已登录的提供商
opencode auth list

# ④ 指定默认模型（在 opencode.json 中配置）
opencode.json → {"model": "anthropic/claude-sonnet-4-5"}

# ⑤ 运行时指定模型
opencode run --model deepseek/deepseek-chat "任务描述"
```

**模型命名格式：** `提供商/模型名` — 如 `anthropic/claude-sonnet-4-5`、`openai/gpt-5-turbo`、`deepseek/deepseek-chat`、`ollama/qwen3`。

## 4. 快捷键速查

| 快捷键 | 功能 |
|--------|------|
| `Tab` | **切换 Plan/Build 模式**（核心操作） |
| `Ctrl+L` | 清屏 |
| `Ctrl+C` | 中断当前任务 |
| `/` | 打开命令菜单（slash commands） |
| `@` | 提及 Agent / 附加文件 |
| `Esc` | 退出菜单/取消 |
| `Ctrl+E` | 打开编辑器（查看/编辑文件） |
| `/undo` | 回滚上一次工具操作 |
| `/init` | 生成项目 AGENTS.md |

---

## 5. 第一个任务实操

```bash
# ① 进入一个测试项目目录
mkdir demo && cd demo
git init

# ② 启动 TUI
opencode

# ③ 输入第一个任务
# "创建一个简单的计算器 CLI，支持加减乘除，用 Go 实现"

# ④ AI 会自主执行：
#    - 读取项目结构（空项目）
#    - 创建 main.go
#    - 执行 go build 验证
#    - 展示 diff

# ⑤ 使用 /undo 回滚任何不满意的修改
# ⑥ /init 生成 AGENTS.md（项目行为准则）
```

**新手三个建议：**
1. **先 Plan 后 Build** — 复杂任务先在 Plan 模式讨论方案，再切 Build 执行
2. **审查每个 diff** — AI 会犯错，`/undo` 是后悔药
3. **AGENTS.md 是重中之重** — 告诉 AI 你的代码规范，减少无效修改
