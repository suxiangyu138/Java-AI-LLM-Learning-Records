## 1. 界面总览（三栏布局）

```
┌─────────────┬──────────────────────┬─────────────┐
│ 左侧栏       │ 中间（主区域）         │ 右侧栏       │
│             │                      │             │
│ 项目文件树   │ 任务对话区            │ Git 图谱     │
│ 任务视图     │ （Agent 消息流）      │ 状态看板     │
│ 文件搜索     │                      │ 目标/进度    │
│             │                      │ Token 用量   │
└─────────────┴──────────────────────┴─────────────┘
```

| 区域 | 内容 | 作用 |
|---|---|---|
| 左侧栏 | 项目文件树、任务视图、Git 变更文件 | 组织与定位 |
| 中间 | 任务对话区（Agent 消息流） | 主战场 |
| 右侧栏 | Git 分支图谱、状态看板、目标面板 | 监控与反馈 |

## 2. 任务工作区三视图

左侧边栏任务视图支持三种组织方式：

| 视图 | 组织方式 | 适用场景 |
|---|---|---|
| 分组 | 自定义分组（7 种颜色，拖拽排序） | 多任务并行管理（默认） |
| 工作区 | 按项目平铺 | 同时开多个项目 |
| 时间线 | 按时间倒序 | 找历史任务 |

任务管理能力：

- 拖拽折叠、跨区迁移（如从"进行中"拖到"已完成"）
- 批量暂停/恢复多个任务
- 已完成任务按保留期自动归档（3/7/14/30 天可选）
- 任务对话区支持文件单击预览、拖拽文件到对话框引用

> 🎯 核心要点：ZCode 的任务模型是"多 Agent 并行 + 分组管理"，一个任务 = 一个独立的 Agent 会话，互不干扰。修 Bug 和写测试可以开两个任务并行跑。

## 3. 快捷符号体系

输入框内使用符号精确定位上下文（比纯自然语言省 token、省歧义）：

| 符号 | 功能 | 示例 |
|---|---|---|
| `@` | 引用工作区文件 | `@src/main/java/OrderService.java 这个文件重构一下` |
| `#` | 关联历史对话 | `# 上次那个订单超时问题，继续排查` |
| `/` | 调用已保存的命令（Command） | `/commit-message 生成提交信息` |
| `$` | 调用技能（Skill） | `$code-review 审查刚才的改动` |
| `+` | 上传附件 | 图片、文档、白板截图 |

附件智能适配：

- 图片：设计稿截图按图生成前端
- 文件路径：直接解析项目内文件
- 文档/链接：自动解析融入上下文

## 4. 快捷键速查

| 快捷键 | 功能 |
|---|---|
| `⌘N`（Win: Ctrl+N） | 新建任务 |
| `⌘O`（Win: Ctrl+O） | 打开工作区 |
| `Shift+Tab` | 快速切换执行模式（输入框聚焦时） |
| 思考图标 | 开关深度思考（推理强度） |

> 💡 Shift+Tab 是最高频快捷键：输入框聚焦时循环切换"变更前确认 → 自动编辑 → 计划模式 → 完全访问"四种模式，见 05 篇。

## 5. 状态监控看板

右侧栏看板聚合四类信息：

| 面板 | 内容 | 价值 |
|---|---|---|
| 对话摘要 | 当前任务进展的一句话摘要 | 多任务切换时快速恢复 |
| 任务进度 | 百分比进度条 | 长任务预期管理 |
| 模型用量 | Token 消耗图表 | 额度成本监控（配合 03 篇计费规则） |
| 上下文占用 | 上下文窗口占用提醒 | **快满时提醒，避免写到一半溢出** |

上下文占用提醒是最容易被忽视的功能：1M 上下文虽大，但长程任务累积数小时后仍会逼近上限，提前收到提醒可以主动 `/compact`（见 07 篇）。

## 6. 内置预览浏览器

ZCode 内置实时预览浏览器：

- 前端任务完成后一键预览效果
- 元素选择器：点选页面元素定位对应代码
- 开发者工具：控制台、网络面板
- 多设备视口切换：手机/平板/桌面尺寸验证响应式布局

适用场景：前端任务（页面开发、样式调整）的闭环验证——Agent 改完代码，预览浏览器刷新即可验收，不用切到外部浏览器。

## 7. Git 图谱与文件管理

### Git 集成

- 可视化分支拓扑图：一眼看清分支结构
- 快捷切换分支
- **AI 自动生成标准提交信息**：符合 Conventional Commits 规范的 commit message
- 文件变更统计（如 `+734 -7`）
- Release Bot 自动化：changelog 生成、GitHub Release 草稿、tag 校验、版本号同步、release note 预览（详见 08 篇）

### 文件树功能

- 搜索文件
- 一键只看 Git 变更文件
- 单击预览
- 拖拽到对话框引用
