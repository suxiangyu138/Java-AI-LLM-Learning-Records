## 1. 12 大避坑清单

### 安装配置类

1. **macOS 无法打开**：Gatekeeper 隔离，`xattr -dr com.apple.quarantine /Applications/ZCode.app`
2. **Coding 端点填错**：Coding Plan Key 必须用 `https://open.bigmodel.cn/api/coding/paas/v4`，填通用端点额度不通
3. **安装路径用中文**：保持默认安装路径，避免启动异常

### 额度成本类

4. **高峰期硬碰硬**：14:00-18:00 按 3 倍扣费，重任务挪到非高峰（限时 1 倍活动期内更是 3 倍差距）
5. **免费体验期当永久**：5 天后需订阅或 BYOK，提前规划，别在任务中途断额度
6. **深度思考常开**：简单任务开深度思考纯浪费 token，按任务复杂度切换

### 任务执行类

7. **并行任务改同一文件**：Agent 间无文件锁，按目录/模块划分并行任务边界
8. **不用 AGENTS.md**：不写项目约定，Agent 每次靠猜，错误率最高
9. **复杂任务不用 Goal 模式**：多轮对话喊"继续"不如 `/goal` 一次设好验收标准
10. **上下文膨胀不管**：出现占用提醒不及时 `/compact`，写到一半溢出

### 安全类

11. **完全访问配高危操作**：删文件、改生产配置必须回退到"变更前确认"
12. **工作区 MCP 配置带密钥提交**：`<项目>/.zcode/config.json` 含敏感信息，不要进 Git

## 2. 与 Claude Code 对比

| 维度 | ZCode | Claude Code |
|---|---|---|
| 形态 | 桌面应用（图形化） | 终端 CLI |
| 默认模型 | GLM-5.2（1M 上下文） | Claude Opus/Sonnet 系列 |
| 生态（MCP/技能） | 可导入，社区小 | 生态最成熟，插件丰富 |
| 复杂推理 | 日常开发够用，大型重构偏弱 | 复杂架构推理领先 |
| 定价 | 免费 5 天 + ¥49/月起 | 订阅制，较贵 |
| 网络 | 国内直连、免翻墙 | 需海外网络 |
| Hooks/可编程性 | 无完整 hook 系统 | 完整 hooks/自动化 |
| 企业能力 | 无审计日志/SSO | 企业版成熟 |
| 上下文 | 1M 真实可用 | 模型窗口视版本而定 |

结论：**"能用"层面 ZCode 已站稳**；Claude Code 赢在生态、复杂推理与企业级能力。预算敏感、中文日常开发选 ZCode。

## 3. 与 Cursor 对比

| 维度 | ZCode | Cursor |
|---|---|---|
| 范式 | ADE：Agent 主导、你验收 | AI 编辑器：你主导、AI 补全 |
| 典型交互 | 任务工作区 + 对话框 | Tab 补全 + 编辑器内联 |
| 适合人群 | 想放手让 AI 干活 | 想保留精细控制 |
| 模型 | GLM-5.2 + BYOK | GPT/Claude 等多模型 |
| 免费程度 | 5 天免费 + 便宜订阅 | 免费版有限额，Pro 付费 |

结论：**范式差异大于功能差异**——习惯逐行控制选 Cursor，想"当项目经理"选 ZCode。

## 4. 与 Trae（字节）对比

| 维度 | ZCode（智谱） | Trae（字节跳动） |
|---|---|---|
| 核心模型 | GLM-5.2 | 豆包 Seed Code + 多国产模型 |
| 价格 | 应用免费 + 额度订阅 | 完全免费（非限时） |
| 上下文 | 1M | 视模型而定 |
| 差异化 | 自研 Agent 内核、Goal、Zread | SOLO 智能体、Builder 模式 |
| 编程基准 | GLM-5.2 工具调用优化 | 豆包 SWE-bench 58.1%（低于 Cursor Composer 2.5 的 72.4%） |
| 商业模式 | 订阅制 | 免费获客 |

结论：预算绝对敏感选 Trae；要 1M 长上下文 + 自研 Agent 能力选 ZCode。

## 5. 与 Codex 对比

| 维度 | ZCode | OpenAI Codex |
|---|---|---|
| 形态 | 桌面 ADE | CLI + IDE 集成 |
| 模型 | GLM-5.2 | GPT-5.x 系列 |
| 网络/支付 | 国内直连免绑卡 | 需海外访问 |
| 定位 | GLM 生态官方环境 | OpenAI 生态官方工具 |

结论：国产化/无海外网络场景，ZCode 是 Codex 的实际平替选择。

## 6. 选型决策树

```
需要 AI 编程工具？
├─ 需要海外最强模型生态（Claude/GPT）→ Claude Code / Cursor / Codex
├─ 需要国内直连 + 预算敏感
│   ├─ 想完全免费 → Trae（字节）
│   ├─ 想 Agent 自主干活 + 1M 上下文 → ZCode（智谱）
│   └─ 想编辑器内补全体验 → Cursor 替代品（通义灵码等）
├─ 已有存量 API Key（DeepSeek 等）→ 任意工具 BYOK / ZCode BYOK
└─ 信创/私有化部署要求 → ZCode 生态（GLM 开源可私有化）
```

## 7. 面试速记

1. ZCode 是**智谱 AI**的桌面端 ADE（Agent 驱动开发环境），深度适配 GLM-5.2（1M 上下文），不是字节产品（字节对应 Trae）。
2. 3.0 核心变化：**自研 ZCode Agent 内核**、分组式任务工作区、Goal 目标模式、Zread 项目知识库、子智能体（3.2）。
3. 商业模式：应用免费 + GLM Coding Plan（Lite ¥49/Pro ¥149/Max ¥469）+ BYOK；高峰期 3 倍扣费、ZCode 内 150% 配额。
4. 四种执行模式（变更前确认/自动编辑/计划/完全访问）类比：权限粒度从"每次确认"到"放手"，Shift+Tab 切换。
5. 对比定位：生态不如 Claude Code、补全不如 Cursor，但国产直连、免费额度大、1M 上下文真实可用，是中文场景的 Claude Code 平替。
