## 1. 产品定位：ADE 到底是什么

ZCode 官方定位是 **ADE（Agentic Development Environment，Agent 驱动开发环境）**，由智谱 AI 推出，是 GLM-5.2 的官方开发环境。

- 交互范式：用户用自然语言描述目标，Agent 自主拆解为任务列表 → 逐个执行 → 验证 → 收尾
- 形态：桌面端原生应用（非终端 CLI、非浏览器插件），安装包约 250-300MB
- 平台支持：macOS 12+（Apple Silicon 原生，Intel 兼容）、Windows 10 19041+（x64）、Linux（Beta 内测）
- 核心卖点：国产、免翻墙、免绑卡、每天 300-500 万 Token 免费额度、1M 上下文可用

> 🎯 核心要点：ZCode 不是"给编辑器加个 AI 助手"，而是"AI 自己干活、你负责验收"。产品理念从 IDE（人写代码 AI 补全）跳到 ADE（AI 写代码人指挥）。

## 2. 与 IDE / AI 编辑器的本质区别

| 维度 | 传统 IDE（VS Code） | AI 编辑器（Cursor） | Agent 工具（Claude Code） | **ZCode（ADE）** |
|---|---|---|---|---|
| 主导者 | 人写代码，工具辅助 | 人写代码，AI 补全/改写 | AI 自主执行，终端交互 | AI 自主执行，图形化工作区 |
| 交互入口 | 编辑器/终端 | 编辑器内嵌 AI 面板 | 终端 CLI | 桌面应用 + 任务面板 |
| 执行单元 | 编辑操作 | 编辑操作 | 多步任务（计划→执行→验证） | 多步任务 + 多任务并行分组 |
| 典型产物 | 代码文件 | 代码文件 | 完整功能/修复 | 完整功能 + 项目知识库 + Release |
| 权限模型 | 用户操作 | 用户操作 | 确认/自动 | 四档执行模式（确认/自动/计划/全访问） |
| 是否 Agent | 否 | 半（Tab 补全+聊天） | 是（单 Agent） | 是（主 Agent + 子智能体 + 多任务） |

ZCode 与 Claude Code 同属"Agent 工具"阵营，区别在形态：Claude Code 是终端 CLI + 文本交互，ZCode 是**图形化 ADE**——分组式任务工作区、Git 分支图谱、Token 用量图表、上下文占用提醒都是桌面应用才有的能力。

## 3. 与 GLM-5.2 的深度耦合

ZCode 不是通用 Agent 壳，而是为 GLM-5.2 量身打造：

- **1M 上下文真实可用**：长程任务（Long Horizon Task）在同一条上下文里完成"理解需求 → 拆解计划 → 写代码 → 测试验证 → 代码审查"全流程，连续编码数小时不掉链子
- **推理强度分级**：思考开关 Off（直答最快）/ On（最深思考，适合复杂架构设计、疑难 Bug 排查）
- **工具调用优化**：针对 GLM-5.2 的工具调用链路做了执行层优化，任务工作区、文件引用、执行模式、Git 状态全部作为 Agent 的可读上下文
- **长程推理专精**：3.0 官方宣传重点是"长程推理、工具调用和大型工程执行链路"，即不是单次问答，而是多小时级工程任务

> 💡 这意味着 ZCode 的体验上限由 GLM 模型能力决定：日常开发（写页面、修 Bug、补测试）表现优秀；大型架构重构等超复杂推理场景仍是短板（见 09 篇对比）。

## 4. 版本演进时间线（2026 基准）

| 版本 | 发布时间 | 关键变化 |
|---|---|---|
| v2.13.0 | 2026-05-29 | 通用技能（Skill）支持、对话中直接显示 Markdown 图片 |
| **3.0** | **2026-06-13** | **全面切换自研 ZCode Agent 内核，深度适配 GLM-5.2**；分组式任务工作区；Zread；Git 图谱；状态看板；Goal 模式；远程控制；五权限模式 |
| v3.2.0 | 2026-06-29 | 新增**子智能体（Sub-agents，测试版）**，每子代理可独立配置模型供应商 |
| **v3.2.2** | **2026-07-01** | 当前最新稳定版（changelog 口径），修复与稳定性更新 |

版本观察：

- 3.0 是分水岭：之前 ZCode 更像"套壳聚合多 Agent CLI"，之后是**自研 Agent 内核**的自主产品
- 3.2.x 表明产品进入快速迭代期：从"单 Agent 干活"走向"多 Agent 团队协作"
- 国内版（bigmodel.cn）与海外版（zcode.z.ai）同源，海外版接入 Z.ai 服务

## 5. 3.0 核心变化详解

### 5.1 自研 ZCode Agent 内核

- 不再依赖第三方 Agent 框架，自研执行内核针对 GLM-5.2 优化
- 代价：3.0 后不再维护第三方 Agent 适配，未来高度绑定 GLM 生态（但 BYOK 仍可接入其他模型）

### 5.2 分组式任务工作区

- 多 Agent 任务并行、独立分组：任务可拖拽折叠、跨区迁移、批量暂停/恢复
- 支持"修 Bug"与"写单元测试"并行互不干扰

### 5.3 新增能力清单

| 能力 | 说明 |
|---|---|
| Zread 智能项目知识库 | 自动读取项目生成结构化文档：目录结构、模块依赖可视化、进度监测 |
| 可视化 Git 分支图谱 | 快捷切分支、AI 自动生成提交信息、变更统计 |
| 可定制聊天交互 | 流式渲染开关、思考过程展示开关、性能模式 |
| 状态监控看板 | 聊天摘要、任务进度、模型用量图表、上下文占用提醒 |
| 多类型附件 | 图片、文件路径、白板截图自动解析 |
| Goal 目标模式 | `/goal` 设置目标，Agent 自主迭代到完成 |
| 远程控制 | 手机扫码远程查看进度、补充需求、确认动作 |
| 五权限模式 | Default / Confirm Before Changes / Auto Edit / Plan / Full Access |

## 6. 产品归属与生态位

- **归属**：智谱 AI（Z.ai），国内开放平台 bigmodel.cn，海外 zcode.z.ai
- **竞品生态位**：中文语境下的 Claude Code 平替——免翻墙、免绑卡、免费额度大、供应链安全
- **在智谱生态中的位置**：ZCode + GLM Coding Plan + GLM-5.2 = 智谱的"AI 编程全家桶"，对标 OpenAI（Codex + ChatGPT 订阅）与 Anthropic（Claude Code + Claude 订阅）
- **不是**：字节跳动产品（字节对应 Trae）、阿里产品（对应通义灵码）
