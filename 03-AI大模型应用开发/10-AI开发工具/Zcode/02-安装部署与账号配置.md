## 1. 系统要求与安装

| 平台 | 最低要求 | 安装包大小 | 下载方式 |
|---|---|---|---|
| macOS | macOS 12+，Apple Silicon 原生，Intel 兼容 | 约 300MB | 官网下载拖入 Applications |
| Windows | Windows 10 19041+（2020-05 后），x64 | 约 250MB | 官网下载运行安装向导 |
| Linux | 内测（Beta）阶段 | — | 加官方群获取内测包 |

下载地址：官网 `zcode.z.ai/cn`（国内）或 `zcode.z.ai`（海外）。

安装流程对比 Claude Code 等终端工具简单得多：

1. 官网下载对应平台安装包
2. macOS：拖入 Applications；Windows：运行安装向导
3. 打开应用 → 登录账号即可使用

> 💡 **不需要配 npm、不需要设 API Key**——这是 ZCode 与 Claude Code 最大的上手差异：Claude Code 需要 Node.js 环境 + Anthropic 账号，ZCode 是原生桌面应用，登录即用。

## 2. 常见安装踩坑与修复

| 现象 | 原因 | 修复 |
|---|---|---|
| macOS 提示"已损坏无法打开" | Gatekeeper 隔离属性 | 终端执行 `xattr -dr com.apple.quarantine /Applications/ZCode.app` |
| Windows 被防火墙/杀软拦截 | 首次运行触发安全检测 | 加入白名单（ZCode 有正规数字签名，放心放行） |
| 安装后无法启动/异常 | 安装路径含中文 | 安装路径保持默认，不要用中文路径 |
| Linux 无安装包 | Linux 仍在内测 | 加入官方内测群获取 Beta 包 |

## 3. 账号登录与免费体验

1. 支持**手机号注册**（建议绑定微信）或**微信扫码登录**
2. 登录后**新用户 5 天免费体验**：每天 500 万 Token（GLM-5.2 300 万 + GLM-5-Turbo 200 万）
3. 每日 0 点清零、不累计；免费通道走基础资源，高峰期可能排队
4. 无需绑卡即可体验；体验期过后需订阅 GLM Coding Plan 或接入 BYOK

免费体验额度明细：

| 项目 | 数值 |
|---|---|
| 免费期 | 首次使用起 5 天 |
| 每日总额度 | 500 万 Token |
| GLM-5.2 每日 | 300 万 Token |
| GLM-5-Turbo 每日 | 200 万 Token |
| 清零规则 | 每日 0 点清零、不累计 |

## 4. 首次配置三件事

打开 ZCode 后依次完成：

1. **确认任务工作区**：默认是"文档/用户目录"，建议在设置中改为你的项目文件夹——Agent 的所有文件操作默认发生在工作区内
2. **熟悉分组任务面板**：左边项目文件树、中间任务对话区、右边 Git 图谱和状态看板（布局见 04 篇）
3. **确认自动审批设置**：默认对文件修改和命令执行需确认；初期建议保持手动确认，熟悉 Agent 行为后再放宽

## 5. 连接模型三入口

首次启动欢迎页、对话框点模型名、设置面板——三个入口都能切换模型。

| 连接方式 | 适用人群 | 说明 |
|---|---|---|
| 连接 BigModel（国内） | 新手推荐 | 授权登录直接绑定智谱账号，不用填 Key |
| 连接 Z.ai（海外版） | 海外用户 | 智谱海外服务 |
| 第三方 API Key（BYOK） | 已持有其他模型 Key | 支持 Anthropic、OpenAI、OpenRouter、Moonshot、MiniMax、小米 MiMo，及任意兼容 Anthropic/OpenAI 协议的自定义端点（如 DeepSeek） |

> ⚠️ **Coding 专用端点陷阱**：用智谱 Coding Plan 的 API Key 时，OpenAI 兼容端点**必须填** `https://open.bigmodel.cn/api/coding/paas/v4`，填通用端点 `open.bigmodel.cn/api/paas/v4` 会导致额度不通用或调用失败。

### 模型切换要点

- 会话级切换：对话框点模型名即可切换当前会话模型
- 子智能体可独立配置模型（v3.2.0+）：把"查资料、读代码"的活交给 DeepSeek 等低价模型，主任务留给 GLM-5.2（详见 06 篇）
- BYOK 接入的模型不受智谱生态限制，适合有存量 API Key 的用户降本

## 6. 跑通第一个任务

官方推荐入门任务：创建一个网页计数器（一个 HTML 文件 + 计数器按钮）。

标准流程（ZCode Agent 的典型执行闭环）：

1. 在对话框输入需求："创建一个网页计数器，点击按钮数字加一"
2. ZCode **先生成执行计划**：创建哪个文件、写什么代码、放哪个目录
3. 审批通过后开始执行（默认需确认文件修改）
4. 完成后告诉你文件路径，可直接打开验证

### 验收清单（第一个任务）

- [ ] 计划里文件路径正确（在项目工作区内，而非默认文档目录）
- [ ] 审批弹窗出现（默认模式应为"变更前确认"）
- [ ] 执行完成后文件真实存在于磁盘
- [ ] 浏览器打开验证功能正常
