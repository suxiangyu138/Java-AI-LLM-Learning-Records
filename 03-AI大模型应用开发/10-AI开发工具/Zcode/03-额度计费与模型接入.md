## 1. 计费模型总览

| 路径 | 费用 | 说明 |
|---|---|---|
| 免费体验 | 0 元 | 新用户 5 天，每天 500 万 Token |
| GLM Coding Plan | ¥49-469/月 | 订阅制固定额度，无超量自动扣费 |
| BYOK | 按各模型 API 价格 | 自带 Key 接入任意兼容端点 |

三条路径的关系：

- 免费体验期结束后，**要么订阅 Coding Plan，要么接 BYOK**，二选一即可继续用
- Coding Plan 是官方推荐路径：额度制封顶、无需关心 Token 单价
- BYOK 是弹性路径：适合已有 DeepSeek/OpenAI 等存量 Key 的用户，或想绕开智谱套餐锁定的用户

## 2. GLM Coding Plan 三档订阅

### 国内版（bigmodel.cn）

| 档位 | 价格 | 相对 Lite 额度 |
|---|---|---|
| Lite | ¥49/月（连续包季约 ¥44.1/月） | 基准 |
| Pro | ¥149/月 | 5 倍 |
| Max | ¥469/月 | 20 倍 |

### 海外版（zcode.z.ai）

| 档位 | 月付 | 年付（约 7 折） |
|---|---|---|
| Lite | $16.20/月 | 约 $151.20/年（$12.60/月） |
| Pro | $64.80/月 | 约 $604.80/年（$50.40/月） |
| Max | $144/月 | 约 $1,344/年（$112/月） |

所有档位均包含 GLM-5.2（旗舰）、GLM-5-Turbo、GLM-4.7、GLM-4.5-Air 等模型。

> 🎯 核心要点：**固定额度制，无超量自动扣费**——额度用完就等重置，不会像 API 按量计费那样产生账单惊吓。额度按滚动 5 小时窗口和每周周期重置。

## 3. 额度消耗规则

| 规则 | 系数 | 时间段 |
|---|---|---|
| 高峰期 | 3 倍扣费 | 北京时间每天 14:00–18:00 |
| 非高峰期 | 2 倍扣费 | 其余时段 |
| 限时福利（2026-09 底前） | 非高峰期按 **1 倍** | 相当于打五折 |
| 高峰期福利（2026-07-31 截止） | 高峰期从 3 倍降至 2 倍 | ZCode 内 Coding Plan 订阅用户 |

关键理解：

- 扣费系数针对**模型调用**（不是页面浏览）；Coding Plan 的"额度"本质是折扣后 Token 量的抽象
- 高峰期避开 14:00-18:00，或把重任务安排在非高峰，额度消耗可差 3 倍
- 免费体验通道（5 天 500 万/天）走基础资源，高峰期可能排队、响应不稳定

## 4. ZCode 内的配额加成

Coding Plan 订阅用户在 ZCode 内享有**约 1.5 倍有效配额（150%）**：

- 例：Pro 用户原本每天约 500 次 prompt，ZCode 内约 750 次
- 来源：高峰期 3 倍 → 2 倍（ZCode 内专属），非高峰期的 1 倍福利叠加
- 2026-07-31 后高峰期加成是否延续以官方为准，但 150% 配额是官方长期口径

> 💡 省钱口诀：**高峰期算账用 3 倍，非高峰用 1-2 倍；能排队就别抢高峰，ZCode 内永远比裸 API 划算。**

## 5. BYOK 多模型接入

### 支持的供应商

| 类型 | 供应商 |
|---|---|
| 官方直连 | BigModel（国内）/ Z.ai（海外） |
| 第三方预设 | Anthropic、OpenAI、OpenRouter、Moonshot、MiniMax、小米 MiMo |
| 自定义端点 | 任意兼容 Anthropic / OpenAI 协议的地址（如 DeepSeek、本地 vLLM） |

### 配置要点

1. 设置面板 → 模型 → 添加供应商 → 粘贴 API Key
2. 智谱 Coding Plan Key 必须用 Coding 专用端点：`https://open.bigmodel.cn/api/coding/paas/v4`（不是通用 `/api/paas/v4`）
3. 第三方 Key 走各自供应商端点，按各自协议（Anthropic 兼容 / OpenAI 兼容）
4. 会话级、子智能体级均可独立选模型

### BYOK 的价值

- 不被锁死在智谱套餐：5 天免费期后仍可继续用 ZCode 客户端
- 成本优化：子智能体跑"查资料、读代码"类任务时切低价模型（如 DeepSeek），主 Agent 保留 GLM-5.2
- 国产化/信创场景：可接私有化部署端点

## 6. 模型矩阵与选型

| 模型 | 定位 | 适用场景 | 备注 |
|---|---|---|---|
| GLM-5.2 | 旗舰，1M 上下文 | 主 Agent 长程任务 | ZCode 默认模型，深度适配 |
| GLM-5-Turbo | 快速通道 | 简单任务、高频小改 | 免费体验期每日 200 万 |
| GLM-4.7 | 上一代旗舰 | 兼容存量习惯 | 已在 Coding Plan 内 |
| GLM-4.5-Air | 轻量低价 | 批量机械任务 | 成本敏感场景 |
| DeepSeek 等 BYOK | 外部模型 | 子智能体分工、成本优化 | 需自备 Key |

选型建议：

- 主 Agent 默认 GLM-5.2：1M 上下文 + 工具调用优化是 ZCode 体验基线
- 简单机械任务（格式化、补注释、批量重命名）切 GLM-5-Turbo 或 Air 省额度
- 复杂推理场景（大型重构）若 GLM 力不从心，BYOK 切 Claude/DeepSeek 作为兜底（注意 09 篇的"模型混用代码风格不一致"坑）
