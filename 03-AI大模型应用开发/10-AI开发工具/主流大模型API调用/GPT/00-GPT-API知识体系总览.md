## 5. 核心概念速查

| 概念 | 一句话 |
|------|--------|
| GPT-5.6 Sol | 旗舰（$5/$30），~1.05M 上下文，最强推理 |
| GPT-5.6 Terra | 均衡（$2.50/$15），**GPT-5.5 半价**，默认替代 |
| GPT-5.6 Luna | 轻量（$1/$6），最快最便宜 |
| Responses API | `v1/responses` — 新一代端点（工具/多智能体/推理上下文） |
| reasoning.effort | 六档：none/low/medium/high/xhigh/max |
| Ultra 模式 | Sol 默认协调 4 个子智能体，最高 16 个 |
| Max 模式 | 更深层推理（更久思考检查） |
| 编程式工具调用 | 模型编写 JS 在隔离 V8 中编排工具（新能力） |
| gpt-5.6 裸别名 | 路由到 Sol（⚠️ 注意账单翻倍） |
