## 1. 多模态全景：四件套分工

| 模型 | 模态 | 定位 | 状态（2026-08） |
|------|------|------|------|
| Seedream 5.0 Pro | 图像 | 创作、编辑、文字生成 | 即将上线 |
| Seedance 2.5 | 视频 | 生成、局部编辑、3D 预演 | 2026-07 已上线 |
| Seed-Audio 1.0 | 音频 | 影视级音轨、零样本参考 | 邀请制内测 |
| Seed Vision（1.6 Vision） | 理解 | 视觉深度思考、GUI 理解 | 已开放 |

理解层的视觉模型与生成层的创作模型是两回事：Seed 1.6 Vision / Seed 2.x VLM 负责"看懂图片"（输入图→输出文本），Seedream/Seedance 负责"画出/生成视频"（输入文本→输出媒体）。选型先分清你的任务方向。字节做"全家桶"而非单点模型的底气在于底层统一：四件套共享同一套数据基础设施与评测体系，且都通过火山方舟一套 API 对外，调用方无需为每个模态单独接供应商、单独管账单——这是多模态产品选型时容易被低估的工程价值。

## 2. Seedream 5.0 Pro：图像创作与编辑

2026-06 亮相的图像创作模型，四项核心能力：

- **交互式精准编辑**：画箭头、圈选区域、自然语言描述空间关系（"把圈选区域放大并替换为木纹"），编辑指令按用户意图精准执行
- **多图层分离**：单图可递归拆分为多个独立图层，底板自动智能填充，直接输出可编辑的分层设计文件——设计师工作流的模型化
- **高密度信息表达**：单张图可承载整页 PPT 级信息密度
- **原生多语种文字生成**：支持英文、西班牙语、阿拉伯语、日语等 10 余种语言文字，中文海报/电商图直接出文字

与 Seedance 2.5 联用可打通"图像→视频"完整生产链路：Seedream 生成分镜图 → Seedance 转动态视频，适合广告、电商、影视前期。

## 3. Seedance 2.5：视频生成

2026-07 上线的视频生成模型，三项全球第一：

- **30 秒原生直出**：单段最长 30 秒原生视频直接生成（同类产品多数 15-20 秒，含 GPT-5.5 生态的视频模型），避免多次拼接的画面断裂
- **50 个全模态素材联合**：最多 50 个图片/视频/文字素材一起作为生成条件，全球最高——复杂运镜与多人场景的素材控制力
- **局部视频编辑**：保持画面一致性的局部修改（换背景、改物体），非整段重生成

另新增 **3D 白模预演**能力（影视前期预演）与原生 4K 输出（Seedance 2.0 起支持）。已在具身智能、工业制造、智能驾驶等领域落地。价格与调用方式以火山方舟控制台为准（2026-08 未公布公开单价，按量计费）。

视频生成选型的工程要点与文本模型完全不同：首要是**时长与素材数约束**（单段 30 秒、50 素材是否满足你的分镜需求），其次是**一致性控制**（跨镜头人物/场景是否保持，局部编辑是否破坏整体），最后才是画质（4K 是锦上添花，多数业务 1080P 已够）。Seedance 2.5 的"局部编辑"能力值得单独评估——它是"改一条不重拍"的关键，直接决定后期返工成本。生产接入时还要注意生成任务的异步模式：视频生成耗时长（分钟级），一般走任务提交 + 轮询结果，而非同步等待。

## 4. Seed-Audio 1.0：音频生成

2026-06 亮相、邀请制内测的音频生成模型，核心能力：

- **零样本多模态参考**：根据文本自动推理角色声音特征，无需预先录制音色样本
- **影视级音轨合成**：一次生成包含多角色对白、情绪表达、方言口音、背景音乐、环境氛围音、拟音特效的完整音轨
- **单次约 2 分钟音频**：角色音色一致不漂移

输入可以是文本、图片、音频任一模态参考——"给一张角色设定图 + 一段台词文本，直接出该角色口播"。适合短剧、广告、有声内容生产。

## 5. 视觉理解：Seed Vision 与 VLM

理解侧能力：Seed 1.6 Vision（视觉深度思考模型）与 Seed 2.x 的 VLM 能力，覆盖：

- **复杂视觉推理**：图表解读、文档 OCR、UI 截图分析（MMMU-Pro 大学级多模态推理全球前列）
- **小时级长视频分析**：Seed 2.1 支持长视频内容理解
- **GUI 操作理解**：理解屏幕状态，为 Agent 环境操作（OSWorld/MobileWorld）提供视觉输入

```python
import base64
with open("screenshot.png", "rb") as f:
    img_b64 = base64.b64encode(f.read()).decode()

response = client.chat.completions.create(
    model="doubao-seed-1-6-vision-250815",
    messages=[{
        "role": "user",
        "content": [
            {"type": "text", "text": "这个页面的布局有什么问题？"},
            {"type": "image_url",
             "image_url": {"url": f"data:image/png;base64,{img_b64}"}}
        ]
    }]
)
print(response.choices[0].message.content)
```

视觉模型价格（Seed 1.6 Vision）：输入 0.8 元/百万 tokens、输出 8 元/百万 tokens，上下文 256K，最大输出 32K-64K——视觉深度思考的性价比之选。

## 6. 全模态工作流：图像→视频生产链路

豆包四件套的价值在于**组合成生产链路**，而非单点能力：

```
电商广告生产链路：
① Seedream 5.0 Pro：生成商品海报（含文字、多图层）
② Seedance 2.5：海报转 30 秒动态视频（局部编辑换场景）
③ Seed-Audio 1.0：生成配音 + 音乐 + 音效音轨
④ Seed 2.1（文本/视觉）：审核文案一致性、生成投放文案

短剧生产链路：
① Seedream 分镜 → ② Seedance 运镜生成（50 素材控场）
→ ③ Seed-Audio 角色对白 → ④ 2.1 VLM 审片
```

字节的布局逻辑：**理解模型（Seed/VLM）+ 生成模型（Seedream/Seedance/Seed-Audio）共用火山方舟一套 API**，多模态产品的调用成本与工程复杂度远低于拼装多家供应商。
