## 1. Doubao 是什么：字节的模型战略

Doubao（豆包）是字节跳动 2023 年起推出的 AI 大模型家族，2024 年 5 月火山引擎 FORCE 大会正式开放 API。它的定位与 OpenAI/Anthropic 有本质差异：字节不是一个纯模型公司，而是**"模型 + 平台 + 应用"三位一体**——模型服务（火山方舟）、Agent 平台（扣子 Coze）、AI 编程（TRAE）、视频创作（即梦）、对话助手（豆包 App）全部自研且互相打通。

这一战略的直接结果是：**模型迭代速度极快**。从 2024 年的 1.0 到 2026 年 6 月的 Seed 2.1，两年完成四代大版本升级，且每次升级都同步开放 API、同步降价。截至 2026 年 6 月，豆包大模型日均 Token 调用量突破 180 万亿，火山引擎在中国公有云 MaaS 市场以 49.5% 份额位居第一，超 110 万企业和个人使用火山方舟服务。对开发者而言，这意味着豆包是国内"最容易跑通 + 最便宜跑起来"的模型之一。

版本演进的主线值得单独梳理，因为每一代都对应一个明确的商业动作：

- **豆包 1.0（2024-05）**：首发即走低价路线，输入低于当时市场均价一个量级，确立"价格屠夫"定位
- **Seed 1.6（2025-06）**：首次使用 Seed 品牌，thinking/综合/flash 三形态 + 256K 上下文，开放深度思考能力
- **Seed 2.0（2026-02）**：pro/lite/mini/code 四款分层，官方称推理成本较业界顶尖降一个数量级
- **Seed 2.1（2026-06）**：Pro/Turbo 在编程与 Agent 基准对标 GPT-5.5，进入"生产级质变点"

演进规律：**每次升级 = 能力上一个台阶 + 价格下探一档 + 模型线更细**。开发者可以按这个规律规划接入节奏——大版本发布后 1-2 个月再升级生产环境，避开首批稳定性风险。

## 2. 火山方舟：不只是豆包的 API 入口

火山方舟（Volcengine Ark）是豆包 API 的官方平台，但它比"豆包 API 网关"大得多——它同时托管 DeepSeek、GLM、Kimi、Qwen 等第三方国产模型，本质是**国产大模型的"模型市场"**：

- **模型推理**：在线推理、批量推理、接入点（endpoint）管理
- **模型开发**：微调（豆包系列）、预训练（Seed 系列）、评测
- **应用服务**：Bot 应用 API、Coding Plan 套餐、AI 加速网关（DCDN）
- **治理能力**：API Key 管理、子账号 + IAM 权限、TPM/RPM 限流、数据驻留

理解这一点对开发很关键：同一个 base_url、同一套鉴权，切换 model 参数即可在豆包/DeepSeek/GLM 之间切换，**多模型降级方案的成本极低**。火山方舟与阿里百炼、百度千帆是直接竞品，但因其自研模型能力最强，是国内云平台 MaaS 市场份额第一。

方舟的完整能力栈对开发者分层开放：**推理层**（在线推理、批量推理、接入点管理、Coding Plan）面向 API 调用；**开发层**（微调、评测、Bot 编排）面向模型定制；**应用层**（扣子、TRAE、即梦）面向产品落地。三层的共性收益是治理统一——API Key、限流、账单、数据驻留都在同一套控制台完成，企业做多模型管理时不需要跨平台维护多套凭证。

### Seed 2.1 系列（2026-06 旗舰，当前最新）

| 模型 | 定位 | 价格（元/百万 tokens，输入/输出） |

- **Seed 2.0 Lite**：全面优于 1.8 的性价比款
- **Seed 2.0 Mini**：速度与成本优先，能力媲美 1.6 Pro，输入 0.2/输出 2 元

## 4. 模型 ID 命名规则

火山方舟的模型 ID 带日期后缀，格式有规律：`doubao-seed-{大版本}-{小版本}-{发布日期}` 或 `doubao-seed-{大版本}-{小版本}-{能力}-{日期}`。

- `doubao-seed-2-1-pro-260623`：Seed 2.1 Pro，2026-06-23 发布
- `doubao-seed-2-1-turbo-260628`：Seed 2.1 Turbo，2026-06-28
- `doubao-seed-1-6-thinking-250715`：Seed 1.6 Thinking，2025-07-15
- `doubao-seed-1-6-251015`：Seed 1.6 标准版，2025-10-15

实际调用时用两种方式之一：**直接填 Model ID**（推荐，如 `doubao-seed-2-1-pro-260623`），或创建**推理接入点**后填 `ep-xxxxxxxx`（支持高级功能与版本切换）。注意：模型 ID 随版本更新会变，正式接入以控制台「在线推理 → 模型 → API 调用」页实时列表为准，不要照搬文档示例硬编码。

## 5. 五个边界

- **不提供开源权重**：豆包系列全部闭源，只有 API 与平台能力
- **不自建 GPU 集群**：官方不提供裸算力，训练/推理都在火山方舟内完成
- **不是纯模型公司**：模型与 App/扣子/TRAE 深度绑定，部分能力（如扣子编排）只在平台内开放
- **不支持预训练自建**：火山方舟仅开放豆包模型微调与 Seed 系列预训练，自定义基座需要走训练专区申请
- **部分模型有地域/合规限制**：数据驻留国内，跨境场景需评估数据合规
