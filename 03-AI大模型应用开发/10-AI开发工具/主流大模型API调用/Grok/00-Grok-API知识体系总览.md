## 5. 核心概念速查

| 概念 | 一句话 |
|------|--------|
| Grok 4.5 | 旗舰：$2/$6，500K 上下文 |
| Grok 4.1 Fast | 极低价：$0.20/$0.50，**2M 上下文** |
| Grok 4.20 | Multi-Agent：一次请求调度 4 个子智能体 |
| 实时 X 数据 | 原生访问 X 全量公开数据流（独有差异化） |
| 2M 上下文 | 约 150 万词，业界最大生产级上下文之一 |
| Prompt Caching | 自动生效，命中省 75-90% |
| GenAI.mil | 五角大楼平台，Grok 被采用（300 万用户） |
| 免费额度 | 新用户 $25 + Data Sharing 每月最高 $150 |

> 🎯 **核心要点**：Grok 的三大差异化 — **① 实时 X/Twitter 数据（独家）② 2M 超长上下文（整库加载无需 RAG）③ Multi-Agent 架构（4 子智能体交叉验证）**。2026 年定位：实时信息 + 超长上下文的"信息型"旗舰。价格极具竞争力（4.1 Fast 比 DeepSeek 同级还低）。
