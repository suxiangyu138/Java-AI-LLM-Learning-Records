## 2. Opus 4.7：旗舰推理引擎

| 维度 | 详情 |
|------|------|
| 模型 ID | `claude-opus-4-7` |
| **独有特性** | `effort: "xhigh"`（最高推理深度）、**移除采样参数**（temperature/top_p/top_k → 400 报错） |
| 思考模式 | **仅 adaptive thinking**（`budget_tokens` 模式 → 400 报错） |
| 任务预算 | 支持 `task_budget`（beta：为整个 Agent 循环预设 Token 预算） |
| 适用 | 多步骤推理、大型代码库分析、Agent 工作流、高风险决策 |
| 成本 | $5/$25/MTok（标准），$2.50/$12.50（Batch），$30/$150（Fast mode） |

**Opus vs Sonnet 实测差异：** Sonnet 对 98% 的任务足够，Opus 在那 2% 的"极其困难的推理/分析"上更可靠。

## 4. Haiku 4.5：轻量高吞吐

| 维度 | 详情 |
|------|------|
| 模型 ID | `claude-haiku-4-5-20251001` |
| 速度 | ~95 tokens/秒（极快） |
| 思考模式 | 支持 extended thinking（需用 budget_tokens 语法，非 adaptive） |
| 适用 | 分类/提取/路由、高量低延迟管道、客服分流、简单分析 |
| 成本 | $1/$5/MTok（Sonnet 的 1/3、Opus 的 1/5） |

**Haiku 的边界：** 简单分析/分类/路由 → OK；复杂代码/多步推理/长文档 → 降级（换 Sonnet/Opus）。

## 5. 价格全景与选型矩阵

### 5.1 完整价格表（美元/百万 Token）

| 模型 | 标准输入 | 标准输出 | Batch 输入 | Batch 输出 | Cache 读 | Fast 模式输入 | Fast 模式输出 |
|------|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| Opus 4.7 | $5 | $25 | $2.50 | $12.50 | $0.50 | $30 | $150 |
| Sonnet 4.6 | $3 | $15 | $1.50 | $7.50 | $0.30 | — | — |
| Haiku 4.5 | $1 | $5 | $0.50 | $2.50 | $0.10 | — | — |

**长上下文溢价（>200K 输入 Tokens）：** Sonnet 4.6 → $6/$22.50；Opus 4.6 → $10/$37.50。

### 5.2 按任务选模型

| 任务 | 首选 | 理由 |
|------|------|------|
| 日常编程/代码审查 | **Sonnet 4.6** | Opus 98% 性能、1/5 价格 |
| 大型代码库分析/重构 | Opus 4.7 | 长上下文 + 最强推理 |
| 分类/提取/路由管道 | **Haiku 4.5** | 快（95 tok/s）+ 便宜（$1/$5） |
| 复杂多步 Agent 任务 | Opus 4.7（xhigh） | 最强推理 + task_budget 预算 |
| 用户聊天/客服 | Sonnet + Haiku 分层 | 简单→Haiku、复杂→Sonnet |
| 批量离线处理 | Batch API（任何模型） | 50% 折扣 |
| 低延迟要求 | Haiku 4.5 或 Opus Fast | 95 tok/s 或 Fast 模式 |

### 5.3 成本最优组合

```text
日常量大的简单任务（>80%）→ Haiku 4.5（$1/$5）
日常量中的中等任务（15%）→ Sonnet 4.6（$3/$15）
极难的推理任务（<5%）→ Opus 4.7（$5/$25）
Batch 批量任务 → 一律 Batch API（半价）

预估月成本（1000 万 Token/天）：
全 Haiku  → ~$180
全 Sonnet → ~$540
全 Opus   → ~$900
智能分层  → ~$270（节省 50-70%）
```

---

> 🎯 **核心要点**：模型选型三句话 — **① 默认用 Sonnet 4.6（98% 任务足够 + $3/$15 可接受）② 高量管道用 Haiku 4.5（$1/$5 + 极快）③ 极难推理用 Opus 4.7（$5/$25 + xhigh effort）**。成本最优 = 80% Haiku + 15% Sonnet + 5% Opus。
