# 11 - AI 编码面试题与效率量化

## 面试题

**Q1: GitHub Copilot 怎么实现代码补全？**
```text
FIM(Fill-in-the-Middle)训练 → 上下文收集(当前文件+相邻文件+元数据)
→ Prompt构建 → 云端推理 → 后处理(去重/语法检查) → 展示
```

**Q2: Cursor Agent 模式和 Copilot 的区别？**
```text
Copilot：补全为主（行-方法级），被动响应
Cursor Agent：自主编辑多文件 + 终端操作 + 循环迭代
Agent = 思考→编辑→读取→验证→循环
```

**Q3: FIM 训练和普通自回归训练的区别？**
```text
自回归：只看上文 → P(next_token | previous_tokens)
FIM：看上文+下文 → P(middle_tokens | prefix, suffix)
代码补全场景天然需要 FIM（光标前后都有代码）
```

**Q4: AI 代码安全风险有哪些？怎么防？**
```text
风险：SQL注入/密钥泄露/依赖漏洞/训练数据污染
防护：AI初审+SAST+SCA+人工复核 四道防线
```

**Q5: 怎么评估 AI 编码工具的效果？**
```text
① 接受率（补全被接受的百分比）
② 留存率（接受后未被撤销的比例）
③ 开发时间对比（同类任务 AI vs 无AI）
④ 代码质量（Bug密度/测试覆盖率）
```
