## 1. 系统要求

| 平台 | 要求 |
|---|---|
| macOS | 支持（brew / npm / 预编译包） |
| Windows | 支持（预编译包 .exe，v1.18 起强化代码签名流程） |
| Linux | 支持（预编译包 .deb/.tar.gz） |
| Node.js | npm 安装需要 Node 20.10+（部分来源称 22+） |

分发形态：CLI 为 Go 单二进制（`CGO_ENABLED=0` 构建，一条命令交叉编译六个目标平台）；桌面客户端为 Tauri 构建（内置 Node 运行时，无需预装 Node）。

## 2. 三种安装方式

| 方式 | 命令 | 适用 |
|---|---|---|
| npm 全局 | `npm i -g reasonix` | 任何系统（需 Node） |
| Homebrew | `brew install esengine/reasonix/reasonix` | macOS |
| 预编译包 | GitHub Releases 下载 | darwin/linux/windows × amd64/arm64 |

桌面客户端：官网/GitHub Releases 下载 macOS（.dmg/.zip）、Windows（.exe）、Linux（.deb/.tar.gz）。

VS Code 扩展：扩展市场搜索 `SivanLiu.reasonix-agent`（需先安装 CLI，通过 ACP 协议连接）。

## 3. API Key 三处配置位置

| 位置 | 说明 |
|---|---|
| 环境变量 | `export DEEPSEEK_API_KEY=your-key-here`（最常用） |
| `~/.reasonix/config.json` | `{"apiKey": "..."}` 全局配置 |
| `reasonix.toml` | 项目级配置文件内声明（推荐，随仓库走） |

> ⚠️ 安全注意：把 API Key 写进 `reasonix.toml` 意味着进 Git 仓库——建议用环境变量或 `.gitignore` 排除，或使用 DeepSeek 的配置管理约定（key 与配置分离）。

## 4. 环境健康检查

```bash
reasonix doctor
```

检查项：

| 检查项 | 内容 |
|---|---|
| Node 版本 | 是否满足最低要求 |
| API Key | 有效性、能否连通 DeepSeek API |
| 网络 | 与 DeepSeek 端点的连通性 |
| 配置语法 | `reasonix.toml` / `config.json` 语法正确性 |
| MCP 接线 | 已挂载的 MCP server 是否可用 |

> 💡 新手排错第一步永远是 `reasonix doctor`——环境问题（Key 失效、Node 版本、网络）都能在这里暴露。

## 5. 首次启动向导

```bash
cd your-project
reasonix code
```

首次运行会弹出配置向导，完成三件事：

1. 粘贴 DeepSeek API Key（或选择已有配置）
2. 选择预设：
   - fast V3：默认 Flash 路由，快而省
   - smart R1：Reasoner 模式，深度思考
   - max R1 + 3 路分支：最强模式（多路并行探索）
3. 勾选要挂载的 MCP server

> 💡 预设只影响默认模型路由，会话内随时可切换（`/pro` 临时升级、`/preset` 换预设）。

## 6. 四种运行模式

| 模式 | 命令 | 能力 | 适用 |
|---|---|---|---|
| 编码模式（默认） | `reasonix code` | 完整文件系统访问：读写、执行终端命令、建 checkpoint | 日常开发 |
| 纯聊天 | `reasonix chat` | 无文件系统/Shell 工具 | 问答、头脑风暴 |
| 一次性执行 | `reasonix run "任务"` | 结果输出 stdout，支持管道输入 | CI/CD、脚本化 |
| 健康检查 | `reasonix doctor` | 环境体检 | 排错 |

一次性模式示例（管道）：

```bash
echo "给这段代码写单元测试" | reasonix run "对 stdin 的代码生成测试"
```

run 模式适合：CI 门禁、批量任务脚本、与 shell 工具链组合。

## 7. 卸载与升级

| 操作 | 命令 |
|---|---|
| npm 安装卸载 | `npm uninstall -g reasonix` |
| brew 安装卸载 | `brew uninstall reasonix` |
| 升级 | `npm update -g reasonix` 或 `brew upgrade reasonix` |

桌面版：v1.18 起提供 Preview 与 Stable 双发布渠道，应用内自动更新（v1.20 修复了更新卡死问题）。

> 🎯 核心要点：Reasonix 的安装链路是所有 Coding Agent 里最轻的之一——不依赖海外网络、不强制绑卡，配好 DeepSeek Key 即用，两分钟内进入 `reasonix code`。
