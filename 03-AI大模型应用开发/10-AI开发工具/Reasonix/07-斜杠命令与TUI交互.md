## 1. TUI 界面与信息层次

Reasonix 的终端 TUI 由 Ink（React 的终端渲染库）构建，信息层次设计是它"高颜值"口碑的来源：

| 信息层 | 展示内容 |
|---|---|
| 顶层 | 会话状态、当前模型、成本/缓存/token 计量 |
| 中层 | Agent 思考过程（R1 思维链可视） |
| 下层 | 工具调用、文件操作、命令执行 |
| 反馈层 | 确认请求、错误、统计 |

可以看到的东西：

- Agent 的思考（`<think>` 内容可视化）
- 工具调用过程（调了什么、参数是什么）
- 执行操作（改了什么文件、跑了什么命令）
- 实时成本计量（底部 cost/cache/token 表）

## 2. 斜杠命令全览

| 命令 | 功能 | 使用场景 |
|---|---|---|
| `/plan` | 先审后改的计划模式 | 大型重构、陌生项目——未批准前不允许写入 |
| `/init` | 扫描项目生成说明文件 | 新项目首次接入 |
| `/skill new` | 创建技能 | 沉淀可复用流程 |
| `/mcp` | MCP 扩展市场/管理 | 挂载外部工具 |
| `/memory` | 查看/更新持久记忆 | 管理项目约定 |
| `/compact` | 手动压缩上下文 | 长会话接近上限 |
| `/stats` | 查看 token 消耗与缓存命中率 | 成本复盘 |
| `/pro` | 下一轮切 v4 pro | 困难任务单轮升级 |
| `/preset` | 切换预设（fast/smart/max） | 会话级模型策略 |

## 3. 三级执行权限模式

| 模式 | 权限 | 适用 |
|---|---|---|
| review | 每个操作需确认 | 生产环境、高危操作 |
| AUTO | 自动执行（默认） | 日常开发 |
| YOLO | 完全放手 | 目标明确、低风险任务 |

模式选型：

| 场景 | 推荐模式 |
|---|---|
| 首次使用 / 不熟的项目 | review |
| 日常功能开发 | AUTO |
| 改配置、补注释 | YOLO |
| 涉及删文件/改生产 | review（无论何时） |

> ⚠️ review 模式的底线价值：结合 `/plan` 使用形成"计划门禁 + 操作确认"双保险——未批准前 Agent 不能写入文件（只读审计门），这是生产环境的安全基线。

## 4. 常用工作流

### 工作流一：新项目接入

```bash
reasonix code            # 启动
/init                    # 扫描项目生成说明文件
/plan 实现用户注册功能    # 先出计划
（审查计划 → 批准）       # 批准后执行
```

### 工作流二：困难任务升级

```bash
（任务失败 2-3 次）
/pro                    # 单轮升级 v4 pro
（继续当前任务）
/stats                  # 查看命中率与成本
```

### 工作流三：长会话维护

```bash
（上下文接近上限）
/compact                # 手动压缩（保留摘要追加）
/memory 记录当前架构决策  # 决策沉淀为记忆
```

## 5. 桌面版交互

桌面版（Tauri 构建，内置 Node 运行时）与 CLI 的差异：

| 维度 | CLI/TUI | 桌面版 |
|---|---|---|
| 形态 | 终端内 | 原生窗口 |
| 多会话 | 多开终端 | 多标签页 |
| 成本展示 | /stats | 底部实时 cost/cache/token 表 |
| 任务监视器 | CLI 支持 | 原生任务监视器（v1.20）：生命周期语义、会话范围摘要视图 |
| 子代理进度 | 文本 | 嵌套生命周期卡片渲染 |

v1.20 起桌面端支持 SSH 远程会话（打开每主机原生 Web 子窗口），并简化了远程访问流程。
