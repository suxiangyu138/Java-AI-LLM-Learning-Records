## 1. MCP 插件机制

MCP（Model Context Protocol）外部工具服务器，通过 stdio JSON-RPC 子进程运行。

### 一行挂载

```bash
reasonix code --mcp "name=cmd args"
```

### 配置挂载（reasonix.toml）

```toml
[mcp.servers.github]
command = "npx"
args = ["-y", "@modelcontextprotocol/server-github"]
```

| 维度 | 说明 |
|---|---|
| 协议 | stdio JSON-RPC 子进程 |
| 配置位置 | `--mcp` 参数（临时）或 reasonix.toml（持久） |
| 适用 | GitHub、Postgres 等外部服务工具 |
| 管理 | `/mcp` 命令查看/管理扩展市场 |

## 2. VS Code 扩展

| 维度 | 说明 |
|---|---|
| 扩展 ID | `SivanLiu.reasonix-agent` |
| 前置条件 | 需先安装 CLI |
| 连接协议 | **ACP 协议**（Agent Client Protocol） |
| 能力 | 在 VS Code 内使用 Reasonix 编码 Agent，复用编辑器上下文 |

ACP 协议的意义：CLI 与 IDE 通过标准化协议连接，同一 Agent 内核在不同宿主复用——对应 v1.20 的"统一扩展内核"方向。

## 3. 桌面版（Tauri）

| 维度 | 说明 |
|---|---|
| 构建 | Tauri（Rust 壳 + Web 前端） |
| 运行时 | 内置 Node runtime（无需预装 Node） |
| 平台 | macOS（.dmg/.zip）、Windows（.exe）、Linux（.deb/.tar.gz） |
| 特点 | 多标签页会话、底部 cost/cache/token 计量表 |
| 渠道 | v1.18 起 Preview 与 Stable 双发布渠道 |

v1.20 桌面版增强：

- 原生任务监视器：任务生命周期语义 + 会话范围摘要视图
- 子代理进度嵌套卡片渲染
- SSH 远程会话（每主机原生 Web 子窗口）
- 稳定性修复：更新卡死、macOS 别名启动崩溃、输入区溢出

## 4. Kimi K3 多模型支持

v1.18.0（2026-07-27）新增 **Kimi K3** 支持：

| 维度 | Kimi K3 |
|---|---|
| 接入方式 | 官方 Kimi 国内版、全球版 API、OpenCode Go |
| 上下文 | 104.8 万 token |
| 视觉 | 原生视觉（图片输入） |
| 推理档位 | 低 / 高 / 最高三级 |

意义：Reasonix 虽以 DeepSeek 为核心，但 v1.18 开始扩展模型矩阵——"DeepSeek 原生"不等于"只能 DeepSeek"，Kimi K3 的 104.8 万上下文与视觉能力补上了原短板（此前无图片输入）。

## 5. 版本演进时间线

| 版本 | 时间 | 关键内容 |
|---|---|---|
| 早期 | 2025 末-2026 初 | 缓存优先架构确立，GitHub 开始走红 |
| — | 2026-05-31 | 14.8k stars；第三方（无矩 AI）实测成本数据公开 |
| v1.18.0 | 2026-07-27 | Kimi K3 支持（104.8 万上下文/视觉/三级推理）；桌面版 Preview/Stable 双渠道；Windows 代码签名强化 |
| — | 2026-08-04 | 突破 30K GitHub stars |
| **v1.20.0** | **2026-08-05** | **统一扩展内核 + Extension Protocol v1**、原生任务监视器、Goal 完成安全停止、简化 SSH 远程访问、MiMo 与 DashScope 协议对齐、基准测试成本报告 |

### v1.20.0 重点拆解

| 更新 | 内容 |
|---|---|
| 统一扩展内核 | Extension Protocol v1：不可变运行时快照、故障原子重载、Plugin Manifest v1（提示词/主题/完全信任代码运行时）、JSON-RPC 边车协议、拦截器调度、流式提供者适配器、Go SDK |
| 原生任务监视器 | CLI 与桌面端原生监控代理任务 |
| 有界子代理进度 | 转发 task/parallel_tasks/fleet 结构化进度，桌面渲染嵌套生命周期卡片 |
| Goal 完成安全停止 | `update_goal` 工具 + 纪元范围每轮报告替换自由格式页脚标记 |
| 消融子系统开关 | 共享词汇关闭子系统（规划器/子代理/检索/证据/压缩）做受控实验 |
| 基准测试成本报告 | 报告每任务成本、token、中位墙钟时间、失败类别 |

升级说明：v1.20 无需手动迁移，当前无已知风险。

## 6. 生态分支与社区

| 分支 | 说明 |
|---|---|
| `reasonix-legacy` | 纯 CLI/TUI TypeScript fork，保留 QQ、Telegram、微信三种远程通道 |

社区生态：

- GitHub 30k+ stars，Discord 社区活跃
- Oosmetrics LLM 速度榜前三
- DeepSeek 官方文档收录（启动方式、配置路径、模型升级方式）
- Cocos 论坛等垂直社区有实战分享（"让 DeepSeek 在终端里给你写 Cocos 代码"）

> 🎯 核心要点：v1.20 的"统一扩展内核"是生态分水岭——从"为 DeepSeek 优化的单 Agent"走向"可插拔扩展的 Agent 平台"（插件清单、边车协议、SDK），同时任务监视器与 Goal 安全停止把长程任务的可观测性与安全边界补上了。
