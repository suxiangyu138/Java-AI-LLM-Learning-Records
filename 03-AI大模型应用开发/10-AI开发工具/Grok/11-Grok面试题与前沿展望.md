## 1. 基础认知题（5 题）

### Q1：Grok 4.5 是什么？何时发布？

**标准回答**：Grok 4.5 是 SpaceXAI（原 xAI）于 **2026 年 7 月 8 日** 发布的最新旗舰 AI 模型。1.5T MoE 参数、500K 上下文、与 Cursor 联合训练。核心竞争力是 **Token 效率——完成同等任务只需竞品 1/4 的 Token**。

### Q2：xAI 为什么变成了 SpaceXAI？

2026 年 6 月，SpaceX 以 $600B 估值收购 xAI，同时收购 Cursor（AI IDE），三者整合为 SpaceXAI。这是 Musk 构建"AI + 航天 + 社交 + IDE"超级生态的战略布局。

### Q3：Grok 4.5 与 Cursor 联合训练意味着什么？

训练数据不再只是网页文本和代码库——而是 **数万亿 Token 的真实开发者会话数据**：调试轨迹、多文件编辑、Agent 纠错反馈。这让 Grok 4.5 在代码任务上有了"实战经验"，而非"纸上谈兵"。

### Q4：Grok 4.5 的核心竞争优势是什么？

```text
三大差异化优势：

1. Token 效率（最大杀器）
   SWE Bench Pro 上只需 Opus 4.8 的 1/4 Token
   实际成本降低 94%+

2. SWE Marathon 全球第一 (29.0%)
   长时间 Agent 编程任务的可靠性最高
   超越 Opus 4.8 (26.0%) 和 Fable 5 (24.0%)

3. Cursor 原生集成
   IDE 内无需 API Key，开箱即用
   Agent 模式 + 补全 + Chat 三合一
```

### Q5：Grok 4.5 是"最强"代码模型吗？

**不是。** Grok 4.5 不是所有基准的第一——SWE-bench Pro (64.7%) 落后于 Claude Opus 5 (79.2%)。
**但是**，Grok 4.5 是"最具经济效益的旗舰模型"——在 A-CODE-LLM Agent 性价比上全球第一 (0.732)。

### 6.2 AI 产业的"效率革命"

```text
Grok 4.5 开启的"效率军备竞赛"将改变整个 AI 产业：

1. Token 效率成为新指标
   不再只看"多少分"，更看"每美元的分数"
   Grok 4.5 证明：4.2× 效率差距 = 结构性的商业模式差异

2. 旗舰模型价格锚点下移
   当 Grok 4.5 以 $2/$6 提供接近 Opus 的性能时，
   $15/$75 的定价体系面临结构性挑战

3. Agent 编程的"成本墙"被打破
   Agent 任务需要大量 Token → Token 贵 = Agent 不可行
   Grok 4.5 的 Token 效率让高频 Agent 自动化成为可能
```
