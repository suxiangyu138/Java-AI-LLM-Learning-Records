## 1. 环境要求与安装

```bash
# 硬件要求（极低）
├── CPU：任意（树莓派可运行）
├── 内存：最低 2GB，推荐 4GB+
├── 磁盘：10GB 空闲空间
└── 网络：需访问模型 API（或本地 Ollama）

# 软件要求
└── Node.js ≥ 22.x LTS（★ 硬性要求，低版本报错）

# 安装（3 步）
# ① 安装 Node.js 22+
# ② 全局安装 OpenClaw
npm install -g openclaw

# ③ 引导配置（交互式）
openclaw onboard
# → 选择默认模型 → 配置 API Key → 选择渠道 → 创建 MEMORY.md
# 完成后自动启动 Gateway

# 启动
openclaw dashboard     # Web UI（端口 18790）+ Gateway（端口 18789）
openclaw start         # 仅启动 Gateway（无 Web UI）
```

## 2. 核心配置：openclaw.json

```json
{
  "gateway": {
    "port": 18789,                    // Gateway 监听端口
    "host": "127.0.0.1",             // ★ 远程访问改 0.0.0.0
    "auth": {
      "token": "${OPENCLAW_GATEWAY_TOKEN}",  // Gateway 访问令牌
      "enabled": true
    }
  },
  "models": {
    "default": "claude-sonnet",       // 默认模型
    "providers": {
      "claude-sonnet": {
        "type": "anthropic",
        "apiKey": "${ANTHROPIC_API_KEY}",
        "model": "claude-sonnet-4-5"
      },
      "deepseek": {
        "type": "openai-compatible",
        "baseUrl": "https://api.deepseek.com/v1",
        "apiKey": "${DEEPSEEK_API_KEY}",
        "model": "deepseek-chat"
      }
    }
  },
  "channels": {
    "whatsapp": { "enabled": true },
    "telegram": {
      "enabled": true,
      "botToken": "${TELEGRAM_BOT_TOKEN}"
    }
  },
  "skills": {
    "autoLoad": true,                  // 自动加载 skills/ 目录
    "loadPath": ["~/.openclaw/skills"]
  },
  "memory": {
    "path": "~/.openclaw/memory",
    "maxContextTokens": 100000
  },
  "logging": {
    "level": "info",                   // debug|info|warn|error
    "logRetentionDays": 30
  }
}
```

**关键配置速查：**

| 配置 | 说明 | 默认值 |
|------|------|--------|
| `gateway.port` | Gateway 监听端口 | 18789 |
| `gateway.host` | 绑定 IP（远程用 0.0.0.0） | 127.0.0.1 |
| `models.default` | 默认模型 ID | — |
| `skills.autoLoad` | 自动加载 Skills | true |
| `memory.maxContextTokens` | 上下文 Token 上限 | 100000 |

## 3. 常用管理命令

```bash
openclaw dashboard              # 启动 Web UI + Gateway
openclaw start                  # 仅启动 Gateway
openclaw gateway stop           # 停止 Gateway
openclaw gateway restart        # 重启 Gateway
openclaw gateway status         # 查看运行状态
openclaw onboard                # 重新运行引导配置
openclaw logs                   # 查看日志

# 设备管理
openclaw devices list           # 列出已连接设备
openclaw devices approve <id>   # 批准设备
openclaw devices reject <id>    # 拒绝设备

# 后台运行
nohup openclaw dashboard &
```

## 4. 开机自启（三平台）

### Linux（systemd）— 推荐

```ini
# /etc/systemd/system/openclaw.service
[Unit]
Description=OpenClaw Gateway
After=network.target

[Service]
Type=simple
User=<your-user>
ExecStart=/usr/bin/openclaw dashboard
Restart=always
RestartSec=10
Environment=NODE_ENV=production

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable openclaw
sudo systemctl start openclaw
sudo systemctl status openclaw    # 检查状态
```

### macOS（launchd）

```xml
<!-- ~/Library/LaunchAgents/com.openclaw.gateway.plist -->
<dict>
    <key>Label</key><string>com.openclaw.gateway</string>
    <key>ProgramArguments</key>
    <array><string>/usr/local/bin/openclaw</string><string>dashboard</string></array>
    <key>RunAtLoad</key><true/>
    <key>KeepAlive</key><true/>
</dict>
```

### Windows（任务计划程序）

```powershell
# 以管理员运行
schtasks /create /tn "OpenClaw" /tr "openclaw dashboard" /sc onstart /ru <user>
```

## 5. 远程访问配置

```bash
# ① openclaw.json：host 改为 0.0.0.0
"gateway": { "host": "0.0.0.0" }

# ② 防火墙开放端口
# Linux
sudo ufw allow 18789
# Windows
netsh advfirewall firewall add rule name="OpenClaw" dir=in action=allow protocol=TCP localport=18789

# ③ 远程访问
openclaw --host <server-ip> --token <gateway-token> status

# 互联网访问需要：公网 IP + 路由器端口映射 + Nginx 反向代理（推荐）
```

## 6. Docker 部署

```dockerfile
# 官方 Dockerfile 参考
FROM node:22-alpine
RUN npm install -g openclaw
EXPOSE 18789 18790
VOLUME ["/root/.openclaw"]
CMD ["openclaw", "dashboard"]
```

```bash
docker run -d \
  --name openclaw \
  -p 18789:18789 -p 18790:18790 \
  -v ~/.openclaw:/root/.openclaw \
  -e OPENCLAW_GATEWAY_TOKEN=your-token \
  -e ANTHROPIC_API_KEY=sk-ant-xxx \
  ghcr.io/openclaw/openclaw:latest
```

> 🎯 **核心要点**：OpenClaw 部署最简三步 — **① Node.js 22+ ② `npm install -g openclaw` ③ `openclaw onboard`**。生产部署关键配置：`host: "0.0.0.0"`（远程访问）+ systemd service（开机自启 + 自动重启）+ `OPENCLAW_GATEWAY_TOKEN`（访问安全）。配置文件修改后需重启 Gateway。
