## 4. 核心概念速查

| 概念 | 一句话解释 | 详见 |
|------|-----------|------|
| **Dify** | 开源 LLM 应用开发平台，对标 Coze/Dify 的"AI 应用工厂" | 模块01 |
| **App** | Dify 中的应用单元（聊天助手/文本生成/Agent/工作流） | 模块03 |
| **Dataset** | 知识库，存储文档 + 向量化后的索引 | 模块04 |
| **Workflow** | 可视化编排的多步骤 AI 任务流程（节点+连线） | 模块05 |
| **Agent** | 具备工具调用能力的智能体（ReAct/Function Call） | 模块05 |
| **Knowledge Retrieval** | 从知识库中检索相关片段的节点 | 模块04/05 |
| **Model Provider** | 模型供应商（OpenAI/DeepSeek/Ollama...） | 模块02 |
| **Embedding** | 将文本转为向量的模型，用于语义搜索 | 模块04 |
| **Rerank** | 对检索结果进行二次排序，提高相关性 | 模块04 |
| **Jinja2 模板** | Dify 中变量和提示词的模板引擎 | 模块05 |
| **Webhook** | HTTP 回调触发工作流执行 | 模块06 |
