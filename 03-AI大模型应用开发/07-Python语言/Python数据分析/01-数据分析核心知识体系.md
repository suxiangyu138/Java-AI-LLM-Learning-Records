## 一、数据分析整体流程

> **重点**：固定流程，所有项目都按这个来。数据清洗最耗时，占 70% 工作量。

1. 明确业务目标
2. 数据采集
3. 数据清洗（最耗时，占 70% 工作量）
4. 数据预处理、特征处理
5. 描述性统计、多维分析
6. 可视化出图
7. 结论 + 业务建议

## 二、必备工具栈

### 2.1 Python 核心库

| 库 | 用途 |
|----|------|
| `numpy` | 数值计算、数组、矩阵 |
| `pandas` | 表格数据分析（核心中的核心） |
| `matplotlib` / `seaborn` | 基础可视化 |
| `pyecharts` | 交互式图表 |

### 2.2 辅助工具

- Excel：透视表、函数、图表
- SQL：取数、多表关联、分组统计
- 思维导图/PPT：报告输出

## 三、NumPy 核心知识点

1. 数组创建：`array`、`arange`、`zeros`、`ones`
2. 数组属性：维度、形状、元素个数、数据类型
3. 切片索引、布尔索引、花式索引
4. 形状变换：`reshape`、`flatten`、`transpose`
5. 广播机制、矩阵运算、聚合函数（均值、方差、最值）

## 四、Pandas 重中之重

### 4.1 两大核心结构

- `Series`：一维带索引数组
- `DataFrame`：二维表格（行 + 列 + 索引）

### 4.2 核心操作速查

| 操作 | 方法 |
|------|------|
| 数据读取 | `read_csv` / `read_excel` / `read_sql` |
| 基础查看 | `head()` / `info()` / `describe()` |
| 缺失值 | `isnull` / `dropna` / `fillna` |
| 重复值 | `duplicated` / `drop_duplicates` |
| 异常值 | 箱线图 / 3σ 原则 / 阈值筛选 |
| 索引 | `loc`（标签）/ `iloc`（位置）|
| 分组聚合 | `groupby` + `sum/mean/count` |
| 多表合并 | `merge` / `concat` |
| 透视表 | `pivot_table` |
| 时间序列 | 日期转换、时间切片、重采样 |

## 五、数据分析统计学基础

- **描述统计**：均值、中位数、众数、方差、标准差、四分位数
- **分布**：正态分布、均匀分布
- **相关性**：皮尔逊相关系数、热力图
- **进阶**：抽样、置信区间、假设检验

## 六、数据可视化核心

| 图表类型 | 适用场景 |
|---------|---------|
| 折线图 | 时间趋势、变化走势 |
| 柱状图/条形图 | 分类对比 |
| 饼图 | 占比结构 |
| 散点图 | 相关性、分布 |
| 直方图 | 数据分布区间 |
| 箱线图 | 异常值、四分位 |
| 热力图 | 变量相关性 |

## 七、SQL 数据分析必备

1. 基础查询 `select`、`where`、`order by`、`limit`
2. 分组统计 `group by` + `having`
3. 多表联查 `join`
4. 子查询、临时表
5. 窗口函数（排名、累加、环比同比）

## 八、业务分析常用模型

| 模型 | 说明 |
|------|------|
| 二八分析法 | 重点抓头部 20% 核心用户/商品 |
| RFM 用户分层 | 最近消费、消费频率、消费金额 |
| 维度拆解 | 时间、地区、品类、渠道、用户层级 |
| 对比分析 | 同比、环比、目标达成率 |
| 漏斗分析 | 转化流失环节定位 |

## 核心要点回顾

- 数据分析 70% 时间花在数据清洗上
- Pandas 是数据分析核心工具，重点掌握分组聚合和合并操作
- 可视化选择：趋势用折线图、对比用柱状图、分布用直方图
- 业务分析模型将数据转化为可落地的商业洞察
