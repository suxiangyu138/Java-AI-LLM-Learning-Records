## 1. 描述性统计

### 1.1 集中趋势

```python
import pandas as pd
import numpy as np
from scipy import stats

data = df["amount"]

# 均值（受异常值影响大）
mean = data.mean()

# 中位数（稳健，推荐）
median = data.median()

# 众数
mode = data.mode().iloc[0]

# 切尾均值（去掉两端极端值后的均值）
trimmed_mean = stats.trim_mean(data.dropna(), 0.05)  # 去掉各 5%
```

### 1.2 离散程度

```python
# 极差
range_val = data.max() - data.min()

# 四分位距 IQR
Q1, Q3 = data.quantile(0.25), data.quantile(0.75)
iqr = Q3 - Q1

# 方差与标准差
variance = data.var()         # 方差
std = data.std()              # 标准差
cv = data.std() / data.mean() # 变异系数（去量纲比较）

# 偏度与峰度
skewness = data.skew()        # > 0 右偏（长尾在右）
kurtosis = data.kurtosis()    # > 0 比正态分布更尖
```

## 3. 假设检验

### 3.1 检验流程

```text
1. 提出假设：H₀（原假设/无差异） vs H₁（备择假设/有差异）
2. 选择检验方法 → 计算检验统计量
3. 计算 p 值
4. 决策：p < 0.05 → 拒绝 H₀（差异显著）
```

### 3.2 常用检验速查

| 检验方法 | 适用场景 | Python |
|---------|---------|--------|
| **T 检验（单样本）** | 样本均值 vs 已知值 | `stats.ttest_1samp()` |
| **T 检验（独立样本）** | 两组均值对比（如 A/B 测试） | `stats.ttest_ind()` |
| **T 检验（配对）** | 同组前后对比 | `stats.ttest_rel()` |
| **卡方检验** | 类别变量独立性 | `stats.chi2_contingency()` |
| **ANOVA** | 多组均值对比 | `stats.f_oneway()` |
| **Mann-Whitney U** | 非参数两组对比 | `stats.mannwhitneyu()` |

### 3.3 T 检验示例

```python
from scipy import stats

# A/B 测试：新版页面 vs 旧版页面，转化率有差异吗？
group_a = np.random.normal(100, 15, 500)  # 旧版 500 人，均值 100
group_b = np.random.normal(108, 15, 500)  # 新版 500 人，均值 108

t_stat, p_value = stats.ttest_ind(group_a, group_b)

print(f"T 统计量: {t_stat:.3f}")
print(f"P 值: {p_value:.6f}")

if p_value < 0.05:
    print("✅ 差异显著！新版效果更好")
    # 效应量（Cohen's d）
    pooled_std = np.sqrt((group_a.std()**2 + group_b.std()**2) / 2)
    cohens_d = (group_b.mean() - group_a.mean()) / pooled_std
    print(f"效应量 (Cohen's d): {cohens_d:.2f}")
else:
    print("❌ 差异不显著，可能是随机波动")
```

## 4. 相关性分析

```python
# 1. Pearson 相关系数（线性相关，需正态分布）
r, p = stats.pearsonr(df["price"], df["amount"])
print(f"Pearson r = {r:.3f}, p = {p:.4f}")

# 2. Spearman 秩相关（单调相关，不要求正态，更稳健） ← 推荐
r, p = stats.spearmanr(df["price"], df["amount"])
print(f"Spearman ρ = {r:.3f}, p = {p:.4f}")

# 3. 全表相关性矩阵
corr_matrix = df.corr(method="spearman", numeric_only=True)

# 4. 相关性解读
# |r| > 0.7  → 强相关
# 0.3 < |r| < 0.7 → 中等相关
# |r| < 0.3 → 弱相关
# p < 0.05 → 统计上显著
```

> ⚠️ **相关性 ≠ 因果性**。冰淇淋销量和溺水人数高度相关，不是因为冰淇淋导致溺水，而是两者都受"天气热"这一混杂因素影响。

## 5. 实战：A/B 测试分析

```python
# 模拟 A/B 测试数据
np.random.seed(42)
n_a, n_b = 10000, 10000

# 对照组的转化率 10%，实验组 12%
conversions_a = np.random.binomial(1, 0.10, n_a)
conversions_b = np.random.binomial(1, 0.12, n_b)

# 1. 转化率
rate_a = conversions_a.mean()
rate_b = conversions_b.mean()
lift = (rate_b - rate_a) / rate_a
print(f"A 组转化率: {rate_a:.2%}")
print(f"B 组转化率: {rate_b:.2%}")
print(f"提升: {lift:.1%}")

# 2. 显著性检验（卡方检验）
from scipy.stats import chi2_contingency
contingency = [[sum(conversions_a), n_a - sum(conversions_a)],
               [sum(conversions_b), n_b - sum(conversions_b)]]
chi2, p, dof, _ = chi2_contingency(contingency)
print(f"P 值: {p:.6f} {'✅ 显著' if p < 0.05 else '❌ 不显著'}")

# 3. 置信区间（95% CI for the lift）
import math
se = math.sqrt(rate_a*(1-rate_a)/n_a + rate_b*(1-rate_b)/n_b)
ci_lower = (rate_b - rate_a) - 1.96 * se
ci_upper = (rate_b - rate_a) + 1.96 * se
print(f"提升 95%CI: [{ci_lower:.3%}, {ci_upper:.3%}]")
```

## 核心要点回顾

- 描述统计三要素：集中趋势（中位数最稳健）、离散程度（IQR）、分布形状（偏度/峰度）
- 假设检验标准流程：H₀/H₁ → 选检验 → 算 p 值 → p<0.05 拒绝 H₀
- p 值 < 0.05 ≠ 效应大，还需看效应量（Cohen's d）
- Spearman > Pearson：不要求正态分布，更稳健
- 相关性 ≠ 因果性——永远警惕混杂变量
- A/B 测试三件套：转化率差异 + p 值 + 置信区间
