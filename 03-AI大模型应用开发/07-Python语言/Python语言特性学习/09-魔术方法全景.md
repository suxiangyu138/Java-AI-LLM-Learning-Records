## 2. 构造与销毁

### 2.1 `__new__` vs `__init__`

```python
class Demo:
    def __new__(cls, *args, **kwargs):
        print("① __new__：分配内存，返回实例")
        instance = super().__new__(cls)      # 注意：不传 args
        return instance                      # ← 必须 return，否则 __init__ 不执行

    def __init__(self, value):
        print("② __init__：初始化属性")
        self.value = value

d = Demo(42)
# ① __new__：分配内存，返回实例
# ② __init__：初始化属性
```

| 维度 | `__new__` | `__init__` |
|------|----------|-----------|
| 类型 | 静态方法（隐式） | 实例方法 |
| 首参 | `cls` | `self` |
| 职责 | **创建**并返回实例 | **初始化**已有实例 |
| 返回值 | 必须返回实例（否则 `__init__` 不调） | 必须 `None` |
| 何时重写 | 继承不可变类型、单例、实例缓存 | 绝大多数场景 |

```python
# 场景 1：继承不可变类型必须用 __new__
class PositiveInt(int):
    def __new__(cls, value):
        if value <= 0: raise ValueError("必须为正")
        return super().__new__(cls, value)   # int 的值在创建时就定了
        # 在 __init__ 里改 self 是不可能的——int 不可变

print(PositiveInt(5) + 1)      # 6

class UpperStr(str):
    def __new__(cls, value): return super().__new__(cls, value.upper())
print(UpperStr("abc"))         # ABC
```

```python
# 场景 2：实例缓存 / 享元模式
class Color:
    _cache = {}
    def __new__(cls, name):
        if name not in cls._cache:
            obj = super().__new__(cls)
            obj.name = name
            cls._cache[name] = obj
        return cls._cache[name]

print(Color("red") is Color("red"))    # True
```

> ⚠️ `__new__` 返回的**不是本类实例**时，`__init__` 不会被调用。这是一个常见的「为什么我的初始化没生效」的原因。

### 2.2 `__del__` 的陷阱

```python
class Resource:
    def __del__(self):
        print("清理")           # 不保证何时执行，也不保证一定执行
```

| 问题 | 说明 |
|------|------|
| 时机不确定 | 依赖引用计数归零，循环引用时要等 GC |
| 解释器退出时可能不执行 | 全局变量销毁顺序不确定 |
| 内部异常被忽略 | 只打印警告到 stderr |
| 会拖延循环引用回收 | 3.4 后已能回收，但仍不推荐 |

> 🎯 **不要依赖 `__del__` 释放资源**。用 `with`（上下文管理器）或显式 `close()`。`__del__` 最多用来打个「资源没被正确关闭」的警告日志。

## 3. 字符串表示协议

```python
class Point:
    def __init__(self, x, y): self.x, self.y = x, y

    def __repr__(self):                        # 面向开发者：无歧义、可复现
        return f"Point(x={self.x}, y={self.y})"

    def __str__(self):                         # 面向用户：可读
        return f"({self.x}, {self.y})"

    def __format__(self, spec):                # f-string 格式化
        if spec == "polar":
            import math
            return f"r={math.hypot(self.x, self.y):.2f}"
        return str(self) if not spec else format(str(self), spec)

p = Point(1, 2)
print(repr(p))          # Point(x=1, y=2)
print(str(p))           # (1, 2)
print(p)                # (1, 2)         ← print 用 __str__
print([p])              # [Point(x=1, y=2)]  ← 容器内用 __repr__
print(f"{p}")           # (1, 2)
print(f"{p:polar}")     # r=2.24
print(f"{p!r}")         # Point(x=1, y=2)   ← !r 强制 repr
```

| 场景 | 调用的方法 |
|------|-----------|
| `print(obj)` / `str(obj)` / `f"{obj}"` | `__str__`（无则回退 `__repr__`） |
| `repr(obj)` / 交互式回显 / `f"{obj!r}"` | `__repr__` |
| 容器内的元素（`[obj]`、`{k: obj}`） | **`__repr__`** |
| `f"{obj:spec}"` / `format(obj, spec)` | `__format__` |
| 日志 `logging.info("%s", obj)` | `__str__` |

> 💡 **只实现一个就实现 `__repr__`**——它能兜底 `__str__`，而且调试时最有用。理想的 `__repr__` 满足 `eval(repr(obj)) == obj`。这是 Python 社区的强约定，`dataclass` 自动生成的就是这种形式。

## 4. 比较与哈希契约

### 4.1 六个比较方法

```python
from functools import total_ordering

@total_ordering                     # 只需写 __eq__ 和 __lt__，自动补全其余四个
class Version:
    def __init__(self, s):
        self.parts = tuple(int(x) for x in s.split("."))
    def __eq__(self, other):
        if not isinstance(other, Version): return NotImplemented
        return self.parts == other.parts
    def __lt__(self, other):
        if not isinstance(other, Version): return NotImplemented
        return self.parts < other.parts
    def __hash__(self):
        return hash(self.parts)
    def __repr__(self):
        return f"Version({'.'.join(map(str, self.parts))!r})"

vs = [Version("1.10.0"), Version("1.2.0"), Version("2.0.0")]
print(sorted(vs))       # [Version('1.2.0'), Version('1.10.0'), Version('2.0.0')]
print(max(vs))          # Version('2.0.0')
```

**返回 `NotImplemented` 而不是 `False`**：这让 Python 去尝试反射操作（问右操作数），失败才抛 `TypeError`。返回 `False` 会让 `Version("1") == "字符串"` 静默得到错误答案。

```python
# Python 自动推导的关系
# a != b       → not a.__eq__(b)（默认，除非重写 __ne__）
# a > b        → b.__lt__(a)（反射）
# a >= b       → b.__le__(a)
```

### 4.2 哈希契约

```text
   三条铁律：
   ① a == b  ⟹  hash(a) == hash(b)        （相等的对象哈希必须相同）
   ② hash(a) == hash(b)  ⇏  a == b        （允许哈希冲突）
   ③ 对象生命周期内 hash 必须不变          （所以可变对象不该可哈希）
```

```python
# 重写 __eq__ 会自动把 __hash__ 置为 None
class A:
    def __eq__(self, o): return True
# hash(A())     # TypeError: unhashable type: 'A'
print(A.__hash__)   # None

# 三种正确做法
class B:                                 # ① 同时定义（可哈希、可作 key）
    def __init__(self, k): self.k = k
    def __eq__(self, o): return isinstance(o, B) and self.k == o.k
    def __hash__(self): return hash(self.k)

class C:                                 # ② 明确声明不可哈希（可变对象）
    __hash__ = None

from dataclasses import dataclass
@dataclass(frozen=True)                  # ③ frozen dataclass 自动生成两者
class D:
    k: int
print(len({D(1), D(1)}))                 # 1 —— 正确去重
```

| 类型 | `__eq__` | `__hash__` | 能否作 dict key |
|------|:--------:|:----------:|:--------------:|
| 默认（都不重写） | 按 id 比较 | 按 id 哈希 | ✅（但语义是「同一对象」） |
| 只重写 `__eq__` | 自定义 | **自动变 None** | ❌ |
| 都重写 | 自定义 | 自定义 | ✅ |
| `@dataclass` | 自动生成 | `None` | ❌ |
| `@dataclass(frozen=True)` | 自动生成 | 自动生成 | ✅ |

> ⚠️ 把可变对象放进 `set`/`dict` 后再修改它，会导致**永久找不到**（哈希桶位置已经错了）。这与 Java 里修改 HashMap key 字段的后果完全一致。

### 4.3 `__bool__` 与真值判断

```python
class Playlist:
    def __init__(self, songs): self.songs = list(songs)
    def __len__(self): return len(self.songs)
    # 没有 __bool__ → 回退到 __len__() != 0

print(bool(Playlist([])))       # False
print(bool(Playlist(["a"])))    # True

class Config:
    def __init__(self, d): self.d = d
    def __bool__(self): return bool(self.d.get("enabled"))   # 自定义真值语义
```

真值判断顺序：`__bool__` → `__len__` → 默认 `True`。

## 5. 运算符重载

### 5.1 三组算术方法

```python
class Vec:
    def __init__(self, *comps): self.c = tuple(comps)
    def __repr__(self): return f"Vec{self.c}"

    def __add__(self, other):                    # self + other
        if isinstance(other, Vec):
            return Vec(*(a + b for a, b in zip(self.c, other.c)))
        return NotImplemented

    def __mul__(self, k):                        # self * k
        if isinstance(k, (int, float)):
            return Vec(*(a * k for a in self.c))
        return NotImplemented

    def __rmul__(self, k):                       # k * self  ← 反射
        return self.__mul__(k)

    def __iadd__(self, other):                   # self += other（原地）
        if isinstance(other, Vec):
            self.c = tuple(a + b for a, b in zip(self.c, other.c))
            return self                          # ← 必须返回 self
        return NotImplemented

    def __neg__(self): return Vec(*(-a for a in self.c))   # -self
    def __abs__(self):
        import math
        return math.hypot(*self.c)                          # abs(self)

v1, v2 = Vec(1, 2), Vec(3, 4)
print(v1 + v2)      # Vec((4, 6))
print(v1 * 3)       # Vec((3, 6))     ← __mul__
print(3 * v1)       # Vec((3, 6))     ← __rmul__（int 不知道怎么乘 Vec）
print(-v1, abs(v2)) # Vec((-1, -2)) 5.0
```

```text
   a + b 的求值流程：
   
   ① 若 type(b) 是 type(a) 的子类且重写了 __radd__ → 先试 b.__radd__(a)
   ② 试 a.__add__(b)
      └─ 返回 NotImplemented → ③
   ③ 试 b.__radd__(a)
      └─ 返回 NotImplemented → ④
   ④ 抛 TypeError: unsupported operand type(s)
```

| 组别 | 形式 | 语义 | 返回 |
|------|------|------|------|
| 正向 | `__add__` | `a + b` | **新对象** |
| 反射 | `__radd__` | `b + a`，当 b 不支持时 | **新对象** |
| 增量 | `__iadd__` | `a += b` | **`self`**（原地修改） |

```python
# 不定义 __iadd__ 时，a += b 退化为 a = a + b（创建新对象后重新绑定）
class NoIadd:
    def __add__(self, o): return NoIadd()
x = NoIadd(); before = id(x)
x += NoIadd()
print(id(x) == before)      # False —— 换了对象
```

### 5.2 `@` 矩阵乘法运算符

# PEP 465 专门为科学计算引入 @ 运算符
class Matrix:
    def __init__(self, data): self.data = data
    def __matmul__(self, other):        # A @ B
        return Matrix([[sum(a * b for a, b in zip(row, col))

## 6. 容器协议

实现不同组合的方法，对象就成为不同级别的容器：

| 想要 | 需实现 | 对应 ABC |
|------|-------|---------|
| `len(x)` | `__len__` | `Sized` |
| `x[k]` | `__getitem__` | — |
| `x[k] = v` / `del x[k]` | `__setitem__` / `__delitem__` | `MutableMapping` |
| `k in x` | `__contains__`（无则回退遍历） | `Container` |
| `for i in x` | `__iter__` | `Iterable` |
| `reversed(x)` | `__reversed__`（无则用 `__len__`+`__getitem__`） | `Reversible` |
| 完整序列 | `__len__` + `__getitem__` | `Sequence` |
| 完整映射 | `__len__` + `__iter__` + `__getitem__` | `Mapping` |

```python
class TokenSequence:
    def __init__(self, tokens): self._t = list(tokens)

    def __len__(self):  return len(self._t)
    def __getitem__(self, i):
        if isinstance(i, slice):
            return TokenSequence(self._t[i])       # ✅ 切片返回同类型
        return self._t[i]
    def __setitem__(self, i, v):     self._t[i] = v
    def __delitem__(self, i):        del self._t[i]
    def __contains__(self, v):       return v in self._t
    def __iter__(self):              return iter(self._t)
    def __reversed__(self):          return reversed(self._t)
    def __repr__(self):              return f"TokenSequence({self._t})"

ts = TokenSequence(["Hello", ",", "world"])
print(len(ts), ts[0], ts[1:], "world" in ts)
# 3 Hello TokenSequence([',', 'world']) True
print(list(reversed(ts)))            # ['world', ',', 'Hello']
ts[0] = "Hi"; del ts[1]
print(ts)                            # TokenSequence(['Hi', 'world'])
```

```python
# 用 collections.abc 白拿一堆方法
from collections.abc import Sequence

class Deck(Sequence):                # 只需实现 __len__ 和 __getitem__
    def __init__(self, cards): self._c = list(cards)
    def __len__(self): return len(self._c)
    def __getitem__(self, i): return self._c[i]

d = Deck(["A", "K", "Q"])
print(d.index("K"), d.count("A"))    # 1 1  ← 免费获得
print("Q" in d, list(reversed(d)))   # True ['Q','K','A']  ← 也是免费的
```

### 6.2 `__getitem__` 与切片

```python
class Sliceable:
    def __init__(self, data): self.data = data
    def __getitem__(self, key):
        print(f"key 类型: {type(key).__name__}, 值: {key}")
        if isinstance(key, slice):
            print(f"  start={key.start} stop={key.stop} step={key.step}")
            print(f"  indices={key.indices(len(self.data))}")   # 处理负数/越界
            return self.data[key]
        if isinstance(key, tuple):                     # 支持 x[1, 2] 多维索引
            return [self.data[k] for k in key]
        return self.data[key]

s = Sliceable([0,1,2,3,4,5])
s[2]           # key 类型: int
s[1:5:2]       # key 类型: slice, indices=(1, 5, 2)
s[1, 3]        # key 类型: tuple  ← NumPy 的 arr[i, j] 就是这个机制
```

## 7. 可调用与属性访问

### 7.1 `__call__`：让实例像函数

```python
class Pipeline:
    """带状态的可调用对象——比闭包更易调试和扩展"""
    def __init__(self, *steps): self.steps, self.calls = steps, 0

    def __call__(self, data):
        self.calls += 1
        for step in self.steps:
            data = step(data)
        return data

p = Pipeline(str.strip, str.lower, lambda s: s.replace(" ", "_"))
print(p("  Hello World  "))      # hello_world
print(p.calls)                   # 1
print(callable(p))               # True
```

| 方案 | 状态 | 可调试 | 适用 |
|------|:----:|:-----:|------|
| 普通函数 | 无 | ✅ | 纯逻辑 |
| 闭包 | 有（隐藏） | 较难 | 简单工厂 |
| `__call__` 类 | 有（显式属性） | ✅ | 需要配置 + 状态 + 可检视 |

> 💡 PyTorch 的 `nn.Module` 就是 `__call__` 的教科书用例：`model(x)` 实际调 `__call__`，它在调 `forward(x)` 前后插入了 hook 处理。这也是「为什么不该直接调 `model.forward(x)`」的原因。

### 7.2 属性访问四方法

```python
class Tracked:
    def __init__(self):
        object.__setattr__(self, "_data", {})     # 绕过自定义 __setattr__

    def __getattr__(self, name):                 # 仅常规查找失败时
        try: return self._data[name]
        except KeyError: raise AttributeError(name) from None

    def __setattr__(self, name, value):          # 每次赋值都触发
        print(f"设置 {name} = {value}")
        self._data[name] = value                 # ← 不能写 self.name = value（无限递归）

    def __delattr__(self, name):
        self._data.pop(name, None)

    def __dir__(self):                           # 自定义 dir() / IDE 补全
        return list(self._data) + list(super().__dir__())

t = Tracked()
t.x = 1                # 设置 x = 1
print(t.x)             # 1
```

| 方法 | 触发范围 | 递归风险 | 安全写法 |
|------|---------|:-------:|---------|
| `__getattribute__` | **所有**属性读取 | 极高 | `super().__getattribute__(name)` |
| `__getattr__` | 仅查找失败后 | 低 | 直接写 |
| `__setattr__` | 所有赋值 | 高 | `object.__setattr__(self, n, v)` 或 `self.__dict__[n] = v` |
| `__delattr__` | 所有删除 | 中 | `object.__delattr__(self, n)` |

```python
# 实用场景：不可变对象
class Frozen:
    def __init__(self, **kw):
        for k, v in kw.items(): object.__setattr__(self, k, v)
    def __setattr__(self, n, v):
        raise AttributeError(f"{type(self).__name__} 是不可变的")

f = Frozen(a=1)
print(f.a)          # 1
# f.a = 2           # AttributeError
```

## 8. 其他实用协议

```python
# ① 序列化：控制 pickle 行为（多进程/缓存必备）
class Model:
    def __init__(self): self.weights, self._conn = [1,2,3], "db-connection"
    def __getstate__(self):                       # 挑出可序列化的部分
        state = self.__dict__.copy()
        del state["_conn"]                        # 连接不能 pickle
        return state
    def __setstate__(self, state):                # 反序列化后重建
        self.__dict__.update(state)
        self._conn = "重新连接"

import pickle
m2 = pickle.loads(pickle.dumps(Model()))
print(m2.weights, m2._conn)          # [1, 2, 3] 重新连接
```

# ② __class_getitem__：让自己的类支持泛型下标

    def __class_getitem__(cls, item): return f"Batch[{item.__name__}]"

```python
# ③ __instancecheck__ / __subclasshook__：自定义 isinstance 行为
from abc import ABCMeta, abstractmethod
class Drawable(metaclass=ABCMeta):
    @classmethod
    def __subclasshook__(cls, C):
        if cls is Drawable:
            return any("draw" in B.__dict__ for B in C.__mro__)
        return NotImplemented

class Circle:
    def draw(self): pass
print(isinstance(Circle(), Drawable))    # True ← 没有继承却通过检查
```

# ④ 数值转换协议
class Money:
    def __init__(self, cents): self.cents = cents
    def __int__(self):   return self.cents // 100
    def __float__(self): return self.cents / 100
    def __index__(self): return self.cents        # 用于切片/bin()/hex()
    def __round__(self, n=0): return round(self.cents / 100, n)

m = Money(12345)
print(int(m), float(m), round(m, 1))     # 123 123.45 123.5
print([0,1,2,3][Money(2):])              # 需要 __index__ 才能做索引

## 9. 完整实战：向量类

把本篇的协议串起来，做一个「用起来像内置类型」的类：

```python
import math
from functools import total_ordering

@total_ordering
class Vector:
    """N 维向量：完整实现表示、比较、算术、容器、哈希协议"""
    __slots__ = ("_c",)                              # 省内存（见 05 章）

    def __init__(self, *components):
        self._c = tuple(float(x) for x in components)

    # ---------- 表示 ----------
    def __repr__(self):  return f"Vector({', '.join(map(str, self._c))})"
    def __str__(self):   return f"({', '.join(f'{x:g}' for x in self._c)})"
    def __format__(self, spec):
        if spec.endswith("p"):                       # 极坐标格式
            return f"<{abs(self):.2f}, {math.atan2(self._c[1], self._c[0]):.2f}rad>"
        return f"({', '.join(format(x, spec) for x in self._c)})"

    # ---------- 容器 ----------
    def __len__(self):   return len(self._c)
    def __getitem__(self, i):
        return Vector(*self._c[i]) if isinstance(i, slice) else self._c[i]
    def __iter__(self):  return iter(self._c)
    def __contains__(self, v): return v in self._c

    # ---------- 比较与哈希 ----------
    def __eq__(self, o):
        return self._c == o._c if isinstance(o, Vector) else NotImplemented
    def __lt__(self, o):
        return abs(self) < abs(o) if isinstance(o, Vector) else NotImplemented
    def __hash__(self):  return hash(self._c)
    def __bool__(self):  return any(self._c)

    # ---------- 算术 ----------
    def __add__(self, o):
        if isinstance(o, Vector) and len(o) == len(self):
            return Vector(*(a + b for a, b in zip(self._c, o._c)))
        return NotImplemented
    __radd__ = __add__

    def __sub__(self, o):  return self + (-o)
    def __neg__(self):     return Vector(*(-a for a in self._c))
    def __abs__(self):     return math.hypot(*self._c)

    def __mul__(self, k):
        return Vector(*(a * k for a in self._c)) if isinstance(k, (int, float)) else NotImplemented
    __rmul__ = __mul__

    def __matmul__(self, o):                          # 点积：v1 @ v2
        if isinstance(o, Vector) and len(o) == len(self):
            return sum(a * b for a, b in zip(self._c, o._c))
        return NotImplemented

    def __truediv__(self, k):
        return self * (1 / k) if isinstance(k, (int, float)) else NotImplemented

    # ---------- 业务方法 ----------
    def normalized(self):
        n = abs(self)
        if n == 0: raise ValueError("零向量无法归一化")
        return self / n

    def cosine_similarity(self, o):                   # RAG 里的核心运算
        d = abs(self) * abs(o)
        return (self @ o) / d if d else 0.0


v1, v2 = Vector(3, 4), Vector(1, 2)
print(repr(v1), str(v1), f"{v1:.2f}", f"{v1:p}")
# Vector(3.0, 4.0) (3, 4) (3.00, 4.00) <5.00, 0.93rad>
print(v1 + v2, v1 - v2, v1 * 2, 2 * v1, v1 / 2)
print(v1 @ v2)                          # 11.0  点积
print(abs(v1), len(v1), v1[0], v1[:1])  # 5.0 2 3.0 Vector(3.0)
print(sorted([v1, v2]))                 # 按模长排序
print(len({Vector(1,2), Vector(1,2)}))  # 1   可哈希、能去重
print(f"{v1.cosine_similarity(v2):.4f}")# 0.9839
print(v1.normalized(), bool(Vector(0,0)))
```

> 🎯 这个类完全没有继承任何基类，却支持 `+ - * / @ abs len [] in for == < hash bool f-string sorted set`——**这就是「协议优先」设计的威力**。Java 要达到同等效果需要实现 `Comparable`、`Iterable`、重写 `equals/hashCode/toString`，且运算符根本无法重载。

## 10. 核心要点回顾

- 魔术方法**不用背，记分类**；高频的只有十来个
- `__new__` 创建实例（继承不可变类型、单例必用），`__init__` 初始化；`__new__` 不返回本类实例则 `__init__` 不执行
- **不要用 `__del__` 释放资源**，用 `with` 或显式 `close()`
- 只实现一个表示方法就选 **`__repr__`**（能兜底 `__str__`，且容器内用的是它）
- 比较方法不匹配时**返回 `NotImplemented`**，不是 `False`
- 哈希契约：**`a == b` 必须 `hash(a) == hash(b)`**；重写 `__eq__` 会把 `__hash__` 置 `None`
- 真值判断顺序：`__bool__` → `__len__` → `True`
- 算术三组：正向 `__add__` / 反射 `__radd__`（左操作数不支持时）/ 增量 `__iadd__`（**必须 return self**）
- 容器协议按需组合；继承 `collections.abc.Sequence` 能免费拿到一堆方法
- `__setattr__` 里必须用 `object.__setattr__` 避免无限递归
- `__call__` 让实例像函数——`nn.Module` 的 `model(x)` 就是它
