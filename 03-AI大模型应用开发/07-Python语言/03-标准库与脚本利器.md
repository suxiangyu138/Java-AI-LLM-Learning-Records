# 03 - 标准库与脚本利器

> 🎯 Python 的标准库 = Java 的 commons-lang + guava + jdk — 数据处理、文件操作、命令行参数一行搞定

## 常用标准库速查

| 库 | 用途 | Java 类比 |
|------|------|----------|
| `os` / `pathlib` | 文件路径 | `java.nio.file.Path` |
| `json` | JSON 处理 | Jackson/Gson |
| `re` | 正则 | `java.util.regex` |
| `argparse` | CLI 参数 | picocli |
| `subprocess` | 执行系统命令 | `ProcessBuilder` |
| `logging` | 日志 | SLF4J/Logback |
| `concurrent.futures` | 线程池 | `ExecutorService` |
| `dataclasses` | 数据类 | Lombok @Data |
| `typing` | 类型提示 | Java 类型系统 |
| `functools` | 函数工具 | Guava/Stream |
| `itertools` | 迭代器工具 | Stream API |
| `collections` | 高级集合 | Guava |

## pathlib 文件操作

```python
from pathlib import Path

# 目录遍历 → 批量处理
for pdf in Path("docs").rglob("*.pdf"):
    print(pdf.name, pdf.stat().st_size)

# 路径拼接
config = Path.home() / ".config" / "myapp" / "settings.json"

# 读写
text = Path("file.txt").read_text(encoding="utf-8")
Path("output.json").write_text(json.dumps(data), encoding="utf-8")
```

## 自动发邮件 / 通知

```python
import smtplib
from email.mime.text import MIMEText

def send_alert(subject, body):
    msg = MIMEText(body)
    msg["Subject"] = subject
    with smtplib.SMTP("smtp.example.com", 587) as s:
        s.starttls()
        s.login("user", "pass")
        s.send_message(msg)

# 模型训练完成后自动通知
send_alert("训练完成", "Loss: 0.15, 用时 2h30m")
```
