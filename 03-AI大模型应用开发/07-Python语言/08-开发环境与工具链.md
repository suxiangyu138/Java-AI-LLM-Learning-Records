# 08 - 开发环境与工具链

> 🎯 Conda 管环境、poetry 管依赖、VSCode 写代码、Jupyter 做实验 — Python 工具链四件套

## Conda 虚拟环境

```bash
# 创建环境
conda create -n llm python=3.11
conda activate llm

# 安装包
conda install pytorch torchvision torchaudio pytorch-cuda=12.4 -c pytorch -c nvidia
pip install transformers openai langchain

# 导出/恢复
conda env export > environment.yml
conda env create -f environment.yml
```

## uv / poetry 依赖管理

```bash
# uv (最快，Rust 实现，推荐)
pip install uv
uv pip install transformers openai  # 比 pip 快 10-100×

# poetry (最流行)
poetry init
poetry add transformers openai
poetry add --group dev pytest black
```

## VSCode 配置

```json
{
  "python.defaultInterpreterPath": "~/miniconda3/envs/llm/bin/python",
  "python.linting.enabled": true,

  "python.formatting.provider": "black",

    "editor.formatOnSave": true,
    "editor.codeActionsOnSave": {
      "source.organizeImports": true

  }

```

## Jupyter 配置

```bash
pip install jupyterlab ipywidgets
jupyter lab --no-browser --port=8888

# 常用扩展
pip install jupyterlab-code-formatter  # 代码格式化
pip install jupyterlab-git             # Git 集成
```

## 常用开发工具速查

| 工具 | 用途 | 命令 |
|------|------|------|
| **black** | 代码格式化 | `black .` |
| **ruff** | Lint+格式化(快) | `ruff check .` |
| **mypy** | 类型检查 | `mypy src/` |
| **pytest** | 测试 | `pytest -v` |
| **pre-commit** | Git hooks | `pre-commit install` |
