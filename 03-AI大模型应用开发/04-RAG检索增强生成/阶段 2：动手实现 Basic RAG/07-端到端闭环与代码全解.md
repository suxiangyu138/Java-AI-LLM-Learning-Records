## 1. 完整代码（rag.py）

```python
"""Basic RAG：文档 → 切片 → 向量化 → FAISS → 检索 → DeepSeek 生成"""
import json
import os
import re
import numpy as np
from pathlib import Path

from sentence_transformers import SentenceTransformer
from openai import OpenAI
import faiss

# ---------- 配置 ----------
MODEL_NAME = "BAAI/bge-large-zh-v1.5"   # 中文 Embedding
DIM = 1024                              # 必须与模型维度一致
CHUNK_SIZE, CHUNK_OVERLAP = 400, 80
TOP_K = 5
DATA_DIR = Path("data")

# ---------- 1. 加载与清洗 ----------
def load_clean(path: Path) -> str:
    text = path.read_text(encoding="utf-8")
    text = re.sub(r"\s+", " ", text)
    text = re.sub(r"\n{3,}", "\n\n", text)
    return text.strip()

# ---------- 2. 切片 ----------
def fixed_chunk(text: str) -> list[str]:
    chunks, start = [], 0
    while start < len(text):
        chunks.append(text[start:start + CHUNK_SIZE])
        start += CHUNK_SIZE - CHUNK_OVERLAP
    return chunks

# ---------- 3. 建库 ----------
def build_index(model):
    index = faiss.IndexHNSWFlat(DIM, 32)
    chunks = []  # 与向量 id 一一对应
    for path in DATA_DIR.iterdir():
        if path.suffix.lower() not in (".txt", ".md"):
            continue
        for c in fixed_chunk(load_clean(path)):
            chunks.append({"text": c, "meta": {"title": path.stem}})
    vecs = model.encode([c["text"] for c in chunks], normalize_embeddings=True)
    index.add(np.array(vecs, dtype=np.float32))
    return index, chunks

# ---------- 4. 检索 ----------
def retrieve(model, index, chunks, query, k=TOP_K):
    qv = model.encode([query], normalize_embeddings=True)
    _, ids = index.search(np.array(qv, dtype=np.float32), k)
    return [chunks[i] for i in ids[0] if i != -1]

# ---------- 5. 生成 ----------
client = OpenAI(api_key=os.environ["DEEPSEEK_API_KEY"], base_url="https://api.deepseek.com")

def ask(model, index, chunks, query):
    results = retrieve(model, index, chunks, query)
    context = "\n\n".join(
        f"[资料{i+1}]（来源：{r['meta']['title']}）\n{r['text']}" for i, r in enumerate(results)
    )
    prompt = f"""请严格依据【参考资料】回答问题，不要编造；资料中没有则回答"知识库中没有相关内容"。

【参考资料】
{context}

【用户问题】
{query}"""
    resp = client.chat.completions.create(
        model="deepseek-chat", temperature=0.3,
        messages=[{"role": "user", "content": prompt}],
    )
    return resp.choices[0].message.content

# ---------- 主流程 ----------
if __name__ == "__main__":
    model = SentenceTransformer(MODEL_NAME)
    index, chunks = build_index(model)
    print(f"建库完成：{len(chunks)} 个切片，索引大小 {index.ntotal}")
    while True:
        q = input("\n提问（输入 exit 退出）: ").strip()
        if q in ("exit", "quit"):
            break
        print(ask(model, index, chunks, q))
```

## 2. 代码逐段讲解

| 主流程 | — | 先建库（一次性）再交互问答 |

| 验证项 | 预期 | 失败检查 |
|---|---|---|
| 建库输出 | "建库完成：N 个切片" | data/ 目录有文档；模型路径正确 |
| 提问"文档内的事实" | 回答正确且有依据 | 检索 Top-K 是否命中（先加打印） |
| 提问"文档外的问题" | 回答"知识库中没有" | Prompt 约束是否生效 |
| 提问"同义改写" | 仍能命中 | 中文 BGE 的语义能力（04 篇实测） |

验证顺序：**先看检索（Top-K 对不对）→ 再看生成（Prompt 用没用）**——问题一定先定位到层。

## 4. Java 对照：Spring AI 最小实现

```java
@Configuration
public class RagConfig {
    // Embedding：BGE 通过 Ollama 或 API 提供；此处以 Ollama 为例
    @Bean
    public EmbeddingModel embeddingModel() {
        return new OllamaEmbeddingModel(OllamaApi.builder()
            .baseUrl("http://localhost:11434")
            .build(), "bge-m3");
    }

    // 向量库：pgvector（需先建 extension vector）
    @Bean
    public VectorStore vectorStore(JdbcTemplate jdbc, EmbeddingModel emb) {
        return new PgVectorStore(jdbc, emb);
    }

    // ChatClient + RAG Advisor：自动完成检索增强
    @Bean
    public ChatClient chatClient(ChatModel chatModel, VectorStore vs) {
        return ChatClient.builder(chatModel)
            .defaultAdvisors(QuestionAnswerAdvisor.builder(vs).build())
            .build();
    }
}
```

```java
@RestController
public class AskController {
    private final ChatClient chatClient;

    @PostMapping("/ask")
    public String ask(@RequestBody String question) {
        return chatClient.prompt()
            .user(question)
            .call()
            .content();   // QuestionAnswerAdvisor 自动：检索 Top-K → 增强 Prompt → 生成
    }
}
```

```yaml
spring:
  ai:
    openai:
      api-key: ${DEEPSEEK_API_KEY}
      base-url: https://api.deepseek.com
      chat:
        options: { model: deepseek-chat, temperature: 0.3 }
    vectorstore:
      pgvector:
        index-type: HNSW
        distance-type: COSINE_DISTANCE
        dimensions: 1024
```

对照理解：Java 的 `QuestionAnswerAdvisor` 自动完成了 Python 版手写的"检索 + Prompt 组装"——**原理完全相同，框架替你封装**。阶段 3 起两种栈并行理解。

## 5. 常见报错排查表

| 报错 | 原因 | 修复 |
|---|---|---|
| `Dimension mismatch` | 索引 DIM 与向量维度不符 | 统一为 1024（或改模型时同步） |
| `RuntimeError: Model not found` | 模型下载失败 | HF_ENDPOINT 镜像或本地下载（01 篇） |
| `API key not found` | 环境变量未设置 | export DEEPSEEK_API_KEY |
| `401 Unauthorized` | Key 无效 | 检查 Key 与 base_url |
| 中文乱码 | 文件编码 | 读取指定 encoding="utf-8" |
| 检索全返回 -1 | 索引为空/查询维度错误 | 检查 add 是否成功、DIM |
| 回答不基于资料 | 检索没命中 | 先打印 Top-K 调试检索层 |
| 内存不足 | 切片过多 | 缩小 batch 或换 IndexFlatIP |
