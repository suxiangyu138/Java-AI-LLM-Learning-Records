## 3. 动手任务三：加相似度阈值与溯源

```python
def retrieve(model, index, chunks, query, k=TOP_K, threshold=0.45):
    qv = model.encode([query], normalize_embeddings=True)
    D, ids = index.search(np.array(qv, dtype=np.float32), k)
    results = []
    for dist, idx in zip(D[0], ids[0]):
        if idx == -1 or float(dist) < threshold:   # 阈值过滤
            continue
        results.append({**chunks[idx], "score": float(dist)})
    return results
```

验证：

- 用"知识库外问题"测试：阈值过滤后结果为空 → Prompt 走"知识库中没有相关内容"分支
- 在生成回答里打印"参考了哪些文档、相似度多少"——形成**溯源输出**

### 阈值调优方法

```
1. 跑 10 个库内问题 + 5 个库外问题
2. 打印所有 Top-K 分数分布
3. 找"库内最低分"与"库外最高分"之间的分界 → 取阈值
4. 调低 → 覆盖率升；调高 → 误答率降（08 篇 07 的取舍）
```

### 参考答案（简版）

1. sentence-transformers + faiss-cpu + numpy；隔离依赖防冲突
2. 1024；报错或静默错位
3. 扫描件无文本层；需 OCR
4. 空白统一/去控制字符/去零宽/去多余空行
5. doc_id/title/section/page；溯源与过滤
6. 感知不到语义边界，可能切断句子
7. 优先段落→句子→标点逐级断开
8. 粒度粗、噪音多、浪费上下文窗口
9. 相邻块边界语义连续，避免切断后信息丢失
10. 归一化后 |A|=|B|=1，内积即余弦相似度
11. 语义空间必须一致，否则检索随机
12. HNSW 图索引近似最近邻，避免全量暴力比较
13. 向量 id 与 chunks 列表下标一一对应
14. pip 即用无部署，索引机制可见
15. 5 左右；太大引入噪音、费上下文
16. 过滤低相似度结果，触发拒答
17. 只依据资料/缺失明说/标注来源/中文回答
18. 忠实引用检索内容，避免发散编造
19. 检索层（先看 Top-K 再调生成）
20. Ollama 本地模型（OpenAI 兼容端点）
