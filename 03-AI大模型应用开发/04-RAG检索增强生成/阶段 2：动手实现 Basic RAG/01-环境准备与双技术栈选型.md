## 1. Python 环境准备

### 1.1 创建虚拟环境

```bash
# Python 3.12+ 建议用 uv（快 10 倍+）
uv venv rag-env
# 或传统方式
python -m venv rag-env

# 激活（Windows）
rag-env\Scripts\activate
# 激活（macOS/Linux）
source rag-env/bin/activate
```

> 💡 虚拟环境是铁律：避免依赖冲突污染全局 Python（详见本仓库 `03-AI.../Python虚拟环境/` 体系）。

### 1.2 安装依赖

```bash
pip install sentence-transformers faiss-cpu numpy
# 可选（阶段 3 会用）：
pip install langchain langchain-community langchain-huggingface
```

| 依赖 | 版本基线（2026） | 用途 |
|---|---|---|
| sentence-transformers | 3.x | Embedding 与 Reranker 模型加载 |
| faiss-cpu | 1.x | 向量索引与检索 |
| numpy | 2.x | 向量运算 |
| torch | 2.x（随 sentence-transformers 自动装） | 模型推理后端 |
| transformers | 4.x（自动依赖） | BGE 模型底座 |

## 3. Embedding 模型下载与离线

### 3.1 模型选择

| 模型 | 维度 | 体积 | 适用 |
|---|---|---|---|
| BAAI/bge-small-zh-v1.5 | 512 | 约 100MB | 轻量、CPU 快 |
| BAAI/bge-large-zh-v1.5 | 1024 | 约 1.3GB | 中文效果好（本阶段推荐） |
| BAAI/bge-m3 | 1024 | 约 2.2GB | 多语言+多功能（阶段 3） |

> 为什么中文选 BGE：实验数据——"退款申请"与"申请退款"这类近义词，通用多语言模型相似度约 0.72，BGE 中文模型 0.95+；BGE-large-zh 1024 维比 1536 维通用模型存储降低 44%、检索提速 35%。

### 3.2 提前下载（离线部署关键）

```bash
huggingface-cli download BAAI/bge-large-zh-v1.5 \
  --local-dir ./models/bge-large-zh-v1.5 \
  --local-dir-use-symlinks False
```

代码中强制离线：

```python
import os
os.environ["TRANSFORMERS_OFFLINE"] = "1"
os.environ["HF_HUB_OFFLINE"] = "1"
os.environ["TOKENIZERS_PARALLELISM"] = "false"

from sentence_transformers import SentenceTransformer
model = SentenceTransformer("./models/bge-large-zh-v1.5")  # 本地路径
```

## 4. 验证环境就绪

```python
# check_env.py
import faiss, numpy as np
from sentence_transformers import SentenceTransformer

model = SentenceTransformer("BAAI/bge-large-zh-v1.5")
v = model.encode(["验证环境"], normalize_embeddings=True)
index = faiss.IndexFlatIP(len(v[0]))
index.add(np.array(v, dtype=np.float32))
D, I = index.search(np.array(v, dtype=np.float32), 1)
print("环境 OK，维度:", len(v[0]), "相似度:", D[0][0])
```

预期输出：`环境 OK，维度: 1024 相似度: 1.0`（自问自答相似度应为 1）。

## 5. 常见安装坑

| 坑 | 现象 | 解法 |
|---|---|---|
| faiss 安装失败 | ModuleNotFoundError / 编译报错 | `pip install faiss-cpu`（不要装 faiss）；Windows 用官方 wheel |
| 模型下载超时 | HF 连接失败 | 镜像 `export HF_ENDPOINT=https://hf-mirror.com` 或提前本地下载 |
| torch 巨大 | 安装 2GB+ | CPU 版 `pip install torch --index-url https://download.pytorch.org/whl/cpu` |
| 版本冲突 | sentence-transformers 与 transformers 版本不兼容 | 用虚拟环境 + `pip install -U` 对齐 |
| Java 启动报维数错误 | pgvector dimensions 与实际不符 | yml 中 dimensions 必须等于模型维度（bge-large-zh = 1024） |

> 🎯 核心要点：环境搭建的目标是"一次成功"——虚拟环境隔离 + 模型提前下载（离线模式）+ faiss-cpu 三件事做好，后面所有报错基本只剩代码逻辑问题。
