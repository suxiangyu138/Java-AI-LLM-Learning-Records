## 1. 支持的格式与加载方式

| 格式 | 加载库 | 示例 |
|---|---|---|
| TXT / MD | 内置 open() | 最简单 |
| PDF | pypdf / pdfplumber | 合同、报告 |
| Word | python-docx | 内部文档 |
| HTML | BeautifulSoup | 网页、帮助中心 |
| CSV/JSON | csv/json | 结构化数据 |

### 代码示例：多格式统一加载

```python
from pathlib import Path

def load_text(path: Path) -> str:
    """统一入口：按扩展名分派加载器，返回纯文本"""
    suffix = path.suffix.lower()
    if suffix in (".txt", ".md"):
        return path.read_text(encoding="utf-8")
    elif suffix == ".pdf":
        from pypdf import PdfReader
        reader = PdfReader(str(path))
        return "\n".join(page.extract_text() or "" for page in reader.pages)
    elif suffix == ".docx":
        from docx import Document
        return "\n".join(p.text for p in Document(str(path)).paragraphs)
    elif suffix == ".html":
        from bs4 import BeautifulSoup
        return BeautifulSoup(path.read_text(encoding="utf-8"), "html.parser").get_text()
    else:
        raise ValueError(f"不支持的格式: {suffix}")
```

> ⚠️ PDF 提取的坑：扫描件（图片型 PDF）extract_text 返回空——需要 OCR（阶段 3 处理）；表格型 PDF 提取后结构丢失（金融研报类注意）。

## 2. 文本清洗

清洗四步（核心代码）：

```python
import re

def clean_text(text: str) -> str:
    """四步清洗：统一空白 → 去控制字符 → 去多余空行 → 去行内噪音"""
    text = re.sub(r"\s+", " ", text)              # 1. 多空白统一为单空格
    text = re.sub(r"[\x00-\x08\x0b\x0c\x0e-\x1f]", "", text)  # 2. 去控制字符
    text = re.sub(r"\n{3,}", "\n\n", text)        # 3. 多余空行压缩
    text = re.sub(r"[​‎‏﻿]", "", text)   # 4. 去零宽字符/BOM
    return text.strip()
```

| 清洗项 | 处理内容 | 为什么 |
|---|---|---|
| 空白统一 | 全角/半角空格、制表符 | 切片边界稳定 |
| 控制字符 | \x00 等不可见字符 | 向量化前必须去除 |
| 零宽字符 | BOM、​ | 隐藏字符污染相似度 |
| 页眉页脚 | "第 X 页 / 公司内部资料" | 检索噪音（简单场景可手动正则去） |
| 超链接/图片说明 | markdown 链接语法 | 保留标题、去掉链接噪音 |

## 3. 元数据设计

元数据 = 每个切片附带的结构化标签，检索后用于溯源与过滤：

```python
from dataclasses import dataclass

@dataclass
class Chunk:
    text: str           # 切片文本（向量化的对象）
    doc_id: str         # 所属文档 ID
    title: str          # 文档标题
    page: int           # 页码（PDF）
    section: str        # 章节
```

| 字段 | 用途 |
|---|---|
| doc_id | 溯源：答案指向哪份文档 |
| title / section | 引用标注：显示来源 |
| page | 定位：人工复核跳转 |
| updated_at | 增量更新判断 |

> 💡 元数据是"免费的可解释性"——本阶段就带上，阶段 3 的过滤检索、溯源引用全部依赖它。

## 4. 数据组织与工程目录

```
rag-project/
├── data/               # 原始文档（放你的知识文档）
│   ├── 产品说明.md
│   └── FAQ.pdf
├── corpus/             # 预处理后的干净文本
├── docs_meta.json      # 切片+元数据（可持久化）
├── check_env.py        # 01 篇环境验证
└── rag.py              # 07 篇完整链路
```

命名约定：

- 原始文档放 `data/` 不修改；预处理结果放 `corpus/` 可重建
- 元数据与切片持久化为 JSON，避免重复解析大文档

> 🎯 核心要点：**文档加载与清洗是 RAG 里最"脏"但最决定质量的环节**——解析失败、清洗不干净，后面切片和检索都会放大问题。宁可加载慢一点，不要脏数据进库。
