## 1. 本阶段定位

阶段 1 建立了概念地基，本阶段的目标是**亲手跑通最小闭环**：

```
阶段1 概念地基 → 阶段2 最小闭环（本阶段）→ 阶段3 调优 → 阶段4 高级
```

| 对比项 | 阶段 1 | 阶段 2 |
|---|---|---|
| 任务 | 理解 RAG 是什么 | 亲手实现一个能回答问题的 RAG |
| 产出 | 概念图、自测 | 本地可跑的代码 + 问答 Demo |
| 技术 | 零代码 | Python（主）+ Java（对照） |
| 验收 | 20 自测 ≥80% | 提问真实文档，答案有依据 |

### 本阶段解决的问题

| 阶段 1 留下的疑问 | 阶段 2 的回答 |
|---|---|
| "检索"到底怎么实现？ | 05 篇 FAISS 检索 + 06 篇查询链路 |
| 切片参数怎么定？ | 03 篇三组实验 + 自检法 |
| Prompt 怎么约束模型？ | 06 篇四原则 + 07 篇完整代码 |
| 报错了怎么办？ | 07 篇 8 项排查表 + 08 篇动手任务 |

### 毕业标准（先看目标再动手）

- [ ] 能用中文文档（如一篇产品说明）建库并正确问答
- [ ] 能讲清自己写的每一行代码在链路中的角色
- [ ] 能通过调 chunk_size / Top-K 观察回答质量变化
- [ ] 常见报错（模型下载/中文乱码/维度不符）能独立排查

## 3. 双技术栈说明

| 维度 | Python（主） | Java（对照） |
|---|---|---|
| 组件 | sentence-transformers + FAISS | Spring AI 2.0 + pgvector |
| 适用 | 原型快、AI 生态全 | 已有 Java 后端、企业生产 |
| LLM | DeepSeek API（OpenAI 兼容） | DeepSeek（OpenAI 兼容）+ QuestionAnswerAdvisor |
| 本阶段重点 | 全流程动手，理解每一步 | 看架构映射，掌握 Spring AI 的 RAG 自动装配 |

> 建议：**以 Python 为主理解原理**（每行代码都可见），Java 作为对照掌握企业实现（阶段 3/4 及生产以 Java 为主）。

### 为什么 Python 更适合学原理

| 理由 | 说明 |
|---|---|
| 每层可见 | FAISS 建索引、检索都是显式调用，无框架魔法 |
| 依赖轻 | 3 个 pip 包即可跑通 |
| 社区教程多 | 排错资料最丰富 |
| 与 AI 生态同源 | 后续学 LangChain/LlamaIndex 无缝 |

### 为什么还要看 Java

| 理由 | 说明 |
|---|---|
| 你是 Java 后端 | 生产环境大概率用 Java |
| Spring AI 官方支持 | 与 Spring Boot 生态无缝集成 |
| 企业级能力 | 事务、监控、多实例这些 Python 原型没有 |

## 5. 常见疑问快答

| 疑问 | 回答 |
|---|---|
| 必须用 GPU 吗？ | 不需要。BGE-small 在 CPU 上几十秒完成千级文档索引，问答秒级 |
| 必须用向量数据库吗？ | 本阶段 FAISS（内存库）足够；pgvector 在 05 篇作对照 |
| 必须连大模型 API 吗？ | 检索部分不需要；生成部分可先用免费/本地模型替代 |
| 为什么用 BGE 不用通用模型？ | 中文近义词相似度 0.72 → 0.95+（详见 04 篇数据） |
| 学完能直接上生产吗？ | 不能——本阶段是"最小闭环"，阶段 3 的混合检索/重排/评估才是生产必需 |
| 代码报错了没答案？ | 07 篇排查表 + 08 篇动手任务，绝大多数坑都覆盖了 |

### 常见学习误区

| 误区 | 正解 |
|---|---|
| 复制粘贴跑通就算会 | 逐行敲 + 能讲清每段作用 |
| 直接上 LangChain | 先零框架理解原理，再上框架 |
| 参数随便填 | 做 08 篇实验，理解每个参数的意义 |
| 跑通了就跳过 08 篇 | 实战任务才是"真的会了"的标志 |

## 7. 常见失败画像与预防

| 失败画像 | 现象 | 预防（本阶段内） |
|---|---|---|
| 环境劝退型 | 装了一天装不上 | 01 篇基线核对表 + 坑表，先过再动手 |
| 复制粘贴型 | 代码跑通但讲不出原理 | 逐行手敲 + 07 篇逐段讲解对照 |
| 参数玄学型 | 乱改参数看运气 | 03 篇实验模板：一次只改一个参数并记录 |
| 检索不看型 | 回答不对只会换 Prompt | 06 篇 debug_retrieve：先看 Top-K |
| 一步登天型 | 跳过实战任务直接"学完了" | 08 篇四个任务必做，任务四是挑战加分项 |

### 防失败三原则

1. **环境先行**：不把环境问题拖进代码环节（01 篇核对表）
2. **手敲代码**：复制粘贴 ≠ 学会（07 篇讲解当复习）
3. **实验留痕**：每次调参记录"改了什么→结果如何"（08 篇记录表）
