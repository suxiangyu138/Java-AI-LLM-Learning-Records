## 1. 故障排查方法论

### 四步排查法

```
① 现象确认：什么故障？影响多大？（先止血）
② 分层定位：应用/检索/模型/数据/基础设施哪层？
③ 根因分析：为什么坏？（不是表面现象）
④ 修复与预防：修好 + 防复发（监控/告警）

先止血，再定位，后根治
```

### 现象到层的映射

| 现象 | 先查哪层 |
|---|---|
| 请求超时 | 应用层 → 模型层（LLM 慢） |
| 检索无结果 | 检索层 → 数据层（索引/模型） |
| 答案质量差 | 质量评估 → 检索/生成（阶段 3 定位法） |
| 内存暴涨 | 基础设施 → 应用层（泄漏） |
| 部分用户不可用 | 网络/限流 → 网关 |

### 排查工具链

| 层 | 工具 |
|---|---|
| 基础设施 | kubectl/docker stats、Prometheus |
| 应用 | 日志（结构化）、OTel 追踪 |
| LLM | Langfuse（回放单次调用） |
| 检索 | 直接调检索服务验证 |
| 数据 | 向量库健康检查、索引状态 |

## 2. 常见故障速查表

| 故障 | 常见原因 | 快速处置 |
|---|---|---|
| 检索延迟飙升 | 向量库 ef 过大/未分片/慢查询 | 查向量库指标，调 ef/扩分片 |
| 生成超时 | LLM 供应商慢/配额满 | 查 Langfuse 延迟，降级/换供应商 |
| 错误率上升 | 依赖故障/模型版本变更 | 查错误分类，回滚发布 |
| 缓存命中率下降 | 知识库更新频繁/Key 设计差 | 查失效策略，调 TTL |
| 内存泄漏 | 连接池未关闭/向量库客户端 | 压测定位，修连接管理 |
| 维度报错 | Embedding 换模型未重建索引 | 维度检查清单（05 篇） |
| 中文乱码 | 编码不一致（GBK/UTF-8） | 统一 UTF-8（阶段 2） |
| 答案变差 | 知识库 stale/模型切换 | Ragas 评估定位，治理（阶段 3） |

### 排障黄金顺序

```
1. 看监控（指标有没有异常）
2. 看日志（错误栈/上下文）
3. 看 Langfuse（LLM 调用细节）
4. 复现（最小化复现用例）
5. 定位到层（再修）
```

## 3. 检索质量类故障

### 质量退化的排查（阶段 3 方法在生产）

| 信号 | 排查 | 对策 |
|---|---|---|
| Ragas 指标下降 | 看是检索还是生成指标降 | 分层定位 |
| 特定类型问题变差 | 建库/查询模型一致性 | 检查 Embedding 变更 |
| 新文档搜不到 | 摄取是否完成/增量状态 | 查摄取 worker 日志 |
| 老文档答错 | 文档过期/被覆盖 | 版本管理 + 治理（阶段 3） |
| 全部变差 | 模型切换/配置变更 | 回滚或重新验证 |

### 质量故障的恢复流程

```
① Ragas 每日评估发现退化
② 对比基线（回滚到上次正常版本验证）
③ 定位变更（模型/数据/配置哪个变了）
④ 修复 + 重新评估确认
⑤ 更新监控阈值（防再犯）
```

## 4. 安全与合规基线

### 安全基线清单

| 类别 | 措施 |
|---|---|
| 网络 | 命名空间隔离 + default-deny（01 篇） |
| 身份 | 工作负载身份联邦（非长期密钥） |
| 数据 | KMS 加密（客户托管密钥） |
| 限流 | 全路由限流（slowapi + Redis） |
| 审计 | 谁调了什么模型/什么数据 |
| 密钥 | Secret 管理（非 ConfigMap） |

### 数据合规

```
数据主权场景（医疗/金融/政务）：
- 数据不出内网（本地模型 + 私有化向量库）
- 遵守本地合规（NESA/CBUAE/ADGM 等）
- 日志脱敏（用户数据不进日志）
- 审计留存（评估与调用记录）
```

### 模型安全

```
提示注入防护：检索内容可能含恶意指令
对策：Prompt 隔离（明确检索内容边界）
敏感内容过滤：输入输出双向过滤
图谱安全：提取攻击防御（阶段 4 的 02 篇）
```

### 参考答案（简版）

1. 应用（路由/缓存）/检索（Embedding+向量库）/模型（LLM 网关）——独立扩展
2. 多副本/弹性扩缩/高可用/多环境需求出现时
3. 默认拒绝 + 显式允许——安全基线，审计认可
4. startup 启动/readiness 接流量/liveness 存活
5. 自定义 QPS 指标 + 30% 余量 + 冷却 + min 保护
6. 目标 QPS → 每层基准 → 副本数 × 1.3
7. 持久化（PG/S3）/滚动发布/迁移先行/摄取退避
8. 模型常驻/独立扩容/热切换/语言无关
9. HuggingFace Embedding 推理服务；max-batch-tokens 等
10. 统一 API/多供应商/密钥管理/成本追踪
11. 模型输出维度 = 向量库维度；换模型全链路验证 + 重建索引
12. 指标/看板/LLM 可观测/链路追踪/质量评估
13. 分层（P0-P3）/可执行动作/防抖/防疲劳
14. Dify 编排/FastGPT 知识库/RAGFlow 文档解析
15. 4000 字符默认上限，超长硬截断语义丢失——改 .env
16. 现象确认→分层定位→根因→修复预防
17. Ragas 对比基线 → 定位变更 → 修复 → 重评
18. 网络隔离/身份联邦/KMS/限流/审计/密钥管理
19. 私有化 + 本地模型 + 数据不出内网
20. 质量/性能/成本/数据/部署/安全/监控/评估
