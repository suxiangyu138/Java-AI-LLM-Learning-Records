## 1. 演进主线总览

```
Naive RAG（2023 基线）→ Advanced RAG（加优化模块）→ Modular RAG（任意编排）
                                                    → Agentic RAG（自主决策）
                                                    → 2026 前沿：GraphRAG / 多模态 / 流式 / RAG 2.0
```

演进动因一句话：**每个阶段都在解决上一阶段暴露的痛点**——Naive 的检索质量差 → Advanced 加模块；模块多了流程僵化 → Modular 任意编排；静态流程不能应对复杂问题 → Agentic 自主决策。

## 2. Naive RAG（朴素 RAG）

架构：查询解析 → 文档检索 → 答案生成（检索一次、生成一次，无反馈）

三大瓶颈（阶段 1 必须背）：

| 瓶颈 | 说明 |
|---|---|
| 语义鸿沟 | BM25 等关键词检索难以处理"语义相同、用词不同"（问"怎么退款"vs 文档写"退费流程"） |
| 上下文碎片化 | 召回片段缺乏连贯性，拼凑答案逻辑断裂——**检索结果超过 3 个独立文档时，连贯性评分下降 42%** |
| 动态知识滞后 | 知识库离线更新，无法及时捕获最新事件 |

其他问题：检索精度低、上下文冗长、生成质量不稳定。

## 3. Advanced RAG（高级 RAG）

在 Naive 基础上增加优化模块，分三个环节：

| 环节 | 优化模块 | 代表技术 |
|---|---|---|
| 查询侧 | 查询重写 | HyDE、Query2Doc（把模糊查询改写为精准检索式） |
| 检索侧 | 混合检索 / 多路召回 | BM25 + Dense 融合、父子文档索引、多向量索引 |
| 排序侧 | 重排序 / 上下文压缩 | BGE-Reranker、Cohere Rerank；LongLLMLingua 去冗余 |

另有两类工程优化：

- **查询理解增强**：多模态查询解析、查询重写机制
- **检索策略升级**："粗选-精选"分层检索（效率提升 3 倍、保持 92% 召回率）；增量更新使知识延迟控制在分钟级
- **生成控制优化**：动态上下文窗口管理、答案三重校验

> 本仓库根目录 12-22 深化体系对上述模块均有专题深潜（如 14 篇查询优化、15 篇重排序），阶段 3 会系统实操。

## 4. Modular RAG（模块化 RAG）

核心思想：把 RAG 拆成**可自由编排的模块**（检索、路由、重排、验证、记忆等），按任务需求组装流程：

| 流程模式 | 说明 |
|---|---|
| 线性 | 检索→生成（基础） |
| 条件分支 | 按问题类型走不同路径（如简单问题直答、复杂问题检索） |
| 分支并行 | 多路检索同时进行 |
| 循环 | 检索→生成→评估→再检索（反思循环） |

意义：从"固定流水线"走向"可编程流程"——为 Agentic RAG 提供了结构基础。

## 5. Agentic RAG（智能体 RAG）

把 AI Agent 的决策能力引入 RAG：

| 能力 | 说明 |
|---|---|
| 路由决策 | 自动判断问题类型，选择合适知识库或工具 |
| 工具调用 | 检索之外还能调 API、数据库、计算工具 |
| 多 Agent 协作 | 多个专业 Agent 分别检索不同领域再整合 |
| 反思验证 | Self-RAG：评估检索结果是否足够，不足主动再检索 |
| 迭代优化 | 多轮"检索-生成-验证"循环直到满意 |

典型差异：

| 维度 | 传统 RAG | Agentic RAG |
|---|---|---|
| 检索次数 | 固定一次 | 按需多轮 |
| 流程 | 静态 | 动态决策 |
| 成本 | 低 | 高（多轮调用） |
| 复杂问题能力 | 弱 | 强 |

## 6. 2026 前沿方向

| 方向 | 核心思想 | 代表 |
|---|---|---|
| Adaptive RAG | 按问题复杂度动态决定是否检索、检索次数、数据源 | 准确率提升 40%，同时降本 |
| GraphRAG | 知识图谱显式建模实体与关系，支持多跳推理 | 微软 GraphRAG 框架（"公司 CEO 的母校"类链式问题） |
| MiA-RAG | 检索前先为长文档生成全局摘要（全局视图）指导检索 | — |
| 实时流式 RAG | 监听数据库变更日志（CDC）实现知识秒级同步 | 金融行情、物流、工单 |
| 多模态 RAG | 检索/生成扩展到图像、音频、视频，CLIP 等统一向量空间 | 医疗影像、电商多模态问答 |
| RAG 2.0 | 检索器与生成器**端到端联合训练** | 复杂问题准确率 +31%、事实一致性 2.3 倍 |

演进总结（2026 视角）：RAG 已从"向量检索+生成"的简单管线，演化为**自适应、图结构、多模态、流式化的智能知识系统**——但无论多复杂，底层仍是"检索增强生成"三步链路。

> 🎯 核心要点：背诵演进脉络时不要死记名词，记"**痛点→解法**"：语义鸿沟→查询改写；碎片化→重排压缩；僵化→模块化编排；静态→Agentic 决策；单文档→Graph/多模态。面试按这个逻辑讲，碾压背名词。
