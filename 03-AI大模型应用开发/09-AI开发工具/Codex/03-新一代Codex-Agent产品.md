# 03 - 新一代 Codex：Agent 产品

> 🎯 2025 年的 Codex 是独立产品，不再是 Copilot 的引擎。从代码补全到全流程自主开发——这是质的飞跃

---

## 1. 产品定位

新一代 Codex 是 OpenAI 独立产品线，**端到端 AI 软件工程智能体**。搭载 GPT-5/GPT-5.3-Codex 专用代码模型，通过自然语言完成从需求到 PR 交付的全流程。

**核心本质**：不只是代码补全，而是能独立完成完整开发任务的 AI 工程师。

---

## 2. 产品矩阵

| 入口 | 形态 | 典型场景 |
|------|------|----------|
| **Codex CLI** | 开源终端工具 | 本地项目重构、批量文件编辑、脚本自动化 |
| **Codex Web** | 云端网页端 | 独立开发、无需本地环境、并行多任务 |
| **ChatGPT 内置** | Plus/Pro/Enterprise | 对话式开发、结合 GPT-4o 多模态能力 |
| **API** | OpenAI Responses API | 企业自建工具集成、CI/CD 流水线嵌入 |

---

## 3. 核心技术特性

### 云端独立沙箱

每个 Codex 任务运行在云端隔离沙箱中：
- 独立文件系统（不污染用户本地环境）
- 可安装依赖（pip/npm/apt）、联网搜索
- 自动编译、运行测试、输出结果截图
- 任务完成后沙箱销毁

### Agent 全流程闭环

```text
① 接收自然语言需求
② 读取关联代码仓库、分析依赖架构
③ 生成代码变更 diff
④ 云端沙箱执行单元测试/编译
⑤ 迭代修改代码直至测试通过
⑥ 生成可提交 Pull Request，附带修改说明
```

## 5. 使用渠道对比

| 渠道 | 优势 | 局限 |
|------|------|------|
| CLI | 本地 git 集成、开源免费 | 需本地安装配置 |
| Web | 可视化、并行任务、资源足 | 不与本地 IDE 联动 |
| ChatGPT | 与现有对话无缝衔接、多模态 | Agent 能力不如专用端 |
| API | 嵌入企业工具链 | 需二次开发 |
