## 1. 对比维度说明

```text
评估维度
├── 🧠 通用推理能力      ← MMLU / HumanEval / GSM8K
├── 🔧 Function Calling  ← 工具调用的易用性、准确性、生态
├── 📋 结构化输出         ← JSON 稳定性、Schema 遵循度
├── 🎭 可控性            ← System Prompt 遵从度、角色扮演
├── 🔓 开放性            ← 许可证、审查程度、可修改性
├── 💰 成本             ← 部署成本、API 价格、硬件需求

└── 🚀 部署灵活性         ← 本地/云端/边缘端适配
```

> 🎯 **核心差异总结**：
> - Hermes vs GPT-4：Hermes 胜在**无审查 + 本地部署 + Function Calling 专用训练**；GPT-4 胜在**通用推理天花板 + 多语言**
> - Hermes vs Claude：Hermes 胜在**开源 + 自由部署**；Claude 胜在**安全性 + 长上下文（200K）+ Computer Use**
> - Hermes vs Qwen：Hermes 胜在**Function Calling 和工具调用生态**；Qwen 胜在**中文 + Apache 2.0 宽松许可**
> - Hermes vs DeepSeek V3：Hermes 胜在**轻量化 + 无审查**；DeepSeek 胜在**通用推理 + MoE 架构成本优势**
> - Hermes vs Llama：**Hermes 就是 Llama 的 Function Calling 增强版**

## 3. Function Calling 专项对比

| 能力 | Hermes 3 | GPT-4o | Claude 4 | Qwen 2.5 |

## 5. 选型决策树

```text
你的核心需求是什么？
│
├── 🔧 "我要做 Agent / Function Calling"
│   ├── 必须本地部署 → Hermes 3 ⭐⭐⭐⭐⭐
│   ├── 必须最高准确率 → Claude 4 Sonnet
│   └── 折中 → GPT-4o
│
├── 🌐 "我需要处理中文内容"
│   ├── 本地 + 工具调用 → Hermes 3 + 翻译 layer
│   ├── 纯中文 → Qwen 2.5 / DeepSeek V3
│   └── API → GPT-4o
│
├── 🎭 "我在做角色扮演/创意写作"
│   └── Hermes 3 ⭐⭐⭐⭐⭐（无审查 + 内心独白）
│
├── 💰 "预算有限，想本地跑"
│   ├── GPU 12GB+ → Hermes 3 8B
│   ├── GPU 24GB+ → DeepHermes 3 24B
│   ├── 只有 CPU → Hermes 3 3B GGUF
│   └── 有几块钱 API → DeepSeek V3 API（最便宜）
│
├── 🔓 "我要求完全无审查"
│   └── Hermes 3（定位就是 uncensored）
│
└── 🏢 "企业级高并发服务"
    ├── 高准确率 + 钱够 → GPT-4o / Claude API
    ├── 高吞吐 + 可控成本 → Hermes 3 70B (vLLM)
    └── 超高吞吐 + 弹性 → Together AI (Hermes 3 Serverless)
```

### 一句话选型

| 场景 | 推荐 | 理由 |
|------|------|------|
| "我要做 Agent 原型" | **Hermes 3 8B + Ollama** | 零成本、5 分钟跑通 |
| "我要做生产级 Agent 服务" | **Hermes 3 70B + vLLM** | 高吞吐、FP8 量化省钱 |
| "我要做推理密集型应用" | **DeepHermes 3 24B** | 一键切换推理模式 |
| "我要中英文都强" | Qwen 2.5 或 GPT-4o | Hermes 中文相对弱 |
| "我只要最好的，不在乎钱" | Claude 4 Sonnet | Agent 能力最强 + 200K 上下文 |

## 核心要点回顾

- Hermes 的核心优势三角：**无审查 × Function Calling × 完全本地化**
- Function Calling 能力：Hermes 3 ≈ Claude ≈ GPT-4o > Qwen > DeepSeek ≈ Llama
- 成本优势：Hermes 8B 可在 $300 的 RTX 3060 上运行，无 API 费用
- 中文能力是 Hermes 的相对弱点，但可通过系统提示词或翻译层缓解
- DeepHermes 3 是唯一支持"直觉/推理"一键切换的开源模型
- 生态差异：Hermes 在 Function Calling 工具链（Hermes-Function-Calling 库）上有独特优势
