## 1. 内置工具集全景

| 工具 | 能力 | 场景 |
|------|------|------|
| `read` | 读取文件内容 | 理解代码 |
| `write` | 写入文件（全量覆盖） | 创建/重写文件 |
| `edit` | 精确编辑（patch） | 局部修改 |
| `diff` | 查看修改差异 | 审查 AI 修改 |
| `bash` | 执行 shell 命令 | 构建/测试/git |
| `grep` | 正则搜索 | 查找代码 |
| `glob` | 模式匹配文件 | 找文件 |
| `webfetch` | 抓取网页 | 查文档/资料 |
| `lsp` | 语言服务器 | 错误定位/跳转 |
| `mcp__*` | MCP 服务器工具 | 外部系统集成 |
| `subagents` | 子 Agent 管理 | 并行任务 |
| `session_spawn` | 创建子会话 | 任务分派 |

**AI 自主完成的典型流程：**
```text
"修复登录功能的 bug"
→ grep 搜索 login 相关代码
→ read 读取认证逻辑
→ bash 跑测试复现 bug
→ edit 修复代码
→ bash 跑测试验证
→ 展示 diff 等待确认
```

## 2. 多 Agent 协作架构

### 2.1 内置一级 Agent（Tab 切换）

| Agent | 权限 | 用途 |
|-------|------|------|
| **plan** | edit/bash → ask（只分析） | 读代码、设计方案、审查 diff |
| **build** | 完整权限 | 实现、重构、跑测试 |

### 2.2 自定义 Agent（`.opencode/agents/NAME.md`）

```markdown
---
name: reviewer
description: 代码审查专家，检查代码质量和潜在 bug
tools:
  - read
  - grep
  - bash
model: anthropic/claude-sonnet-4-5    # 可指定独立模型
permissions:
  edit: deny                          # 审查 Agent 不修改代码
  bash: ask
---

你是资深代码审查专家。审查流程：
1. 读取变更文件
2. 检查：逻辑错误/安全问题/性能问题/代码规范
3. 输出：按严重程度排序的 Review 报告
```

### 2.3 多 Agent 并行协作

```text
主 Agent（Orchestrator）负责拆解调度：
├── Researcher（研究）→ 搜索资料/API 文档
├── Implementer（实现）→ 写代码
├── Reviewer（审查）→ 检查实现质量
└── 结果汇总 → 主 Agent 整合输出

典型场景：一个 Agent 查资料、一个 Agent 写代码、一个 Agent 审查
```

## 3. 会话管理与存储

```bash
# 会话管理命令
opencode session list                  # 列出所有会话
opencode session show <id>             # 查看会话详情
opencode stats --days 30 --models      # 使用统计（按模型）
opencode export <id> --sanitize        # 导出会话（脱敏）
opencode import session.json           # 导入会话

# 多会话并行：同一项目多个独立会话
# TUI 中 /sessions 查看，Tab+箭头切换

# 会话特性
# ✅ 会话搜索
# ✅ 历史回放
# ✅ 一键回滚（/undo）
# ✅ 分享链接（--share）
# ✅ 分支会话（--fork 或 /fork）
```

**存储位置（本地优先）：**

| 平台 | 路径 |
|------|------|
| Linux/macOS | `~/.local/share/opencode/` |
| Windows | `%APPDATA%\opencode\` |
| 格式 | SQLite（会话 + 记录） |
| 特点 | **全部本地存储，不上传云端** |

## 4. LSP 与错误定位

```text
OpenCode 内置 LSP（Language Server Protocol）支持：

能力：
├── 语法错误实时检测
├── 类型错误定位（错误定位准确率超 90%）
├── 符号跳转（Go to Definition）
├── 自动修复建议
└── 与编辑工具的联动（发现错误 → 自动定位到文件行号）

支持的常见 LSP：
├── TypeScript/JavaScript（typescript-language-server）
├── Go（gopls）
├── Python（pyright / pylsp）
├── Java（jdtls）
└── 通过 .opencode/lsp 配置自定义
```

## 5. 模型切换与多模型路由

```bash
# ① 会话中切换模型（TUI）
/models                       # 打开模型选择
# 或 Ctrl+M 快捷切换

# ② 命令行指定
opencode run --model anthropic/claude-haiku-4-5 "审计 src/ 目录"
opencode run --model deepseek/deepseek-chat "写单元测试"

# ③ opencode.json 配置多模型
{
  "model": "anthropic/claude-sonnet-4-5",       // 默认模型
  "models": {
    "reviewer": "anthropic/claude-haiku-4-5",   // 审查用轻量模型
    "cheap": "deepseek/deepseek-chat"           // 简单任务用便宜模型
  }
}
```

**多模型路由策略：** 简单任务（重构/补注释）→ 便宜模型（Haiku/DeepSeek）；复杂任务（跨文件重构/调试）→ 强模型（Sonnet/Opus）。省 70%+ Token 成本。

## 6. 与 Claude Code 核心差异

| 维度 | OpenCode | Claude Code |
|------|----------|-------------|
| 模型 | 75+ 自由切换 | 仅 Claude |
| 存储 | 本地 SQLite | 混合 |
| 开源 | MIT | 闭源 |
| 多 Agent | ✅ 内置 + 自定义 | ⚠️ subagent 有限 |
| LSP | ✅ 内置 | ⚠️ 无（依赖外部工具） |
| 价格 | 免费 + BYOK | Pro $20/月 |
| Plan/Build | ✅ Tab 切换 | plan mode |

---

> 🎯 **核心要点**：OpenCode 的核心能力四件套 — **① 内置工具链（read/write/edit/bash/grep/LSP 全自主）② Plan/Build 双模式 + 自定义 Agent ③ SQLite 本地存储（隐私安全）④ 75+ 模型自由切换（多模型路由省成本）**。最值得配置的三件事：AGENTS.md（项目规则）、自定义 Agent（reviewer）、多模型路由（省钱）。
