## 1. ChatGPT 是什么

ChatGPT 是 OpenAI 基于 GPT 系列模型构建的对话式 AI 产品。通过 RLHF（基于人类反馈的强化学习）对齐，将"只会续写"的基座模型变成"能聊天、会干活"的智能助手。

**核心本质**：GPT 基座模型 + SFT 指令微调 + RLHF 人类对齐 = ChatGPT。

## 2. 完整进化史

### GPT-1 (2018.06) — 证明范式

- 117M 参数，12 层 Decoder-Only
- 论文：《Improving Language Understanding by Generative Pre-Training》
- 核心创新：预训练（无标注文本）→ 微调（有标注任务），显著提升各 NLP 任务
- **被淘汰原因**：参数太小，无 Few-Shot 能力

### GPT-2 (2019.02) — Zero-Shot 震惊学界

- 1.5B 参数，48 层
- 初始因"太危险"未完整开源（引发全球 AI 安全大讨论）
- 核心发现：更大模型 + 更多数据 → 涌现 Zero-Shot 能力
- **遗留问题**：不会对话，只能续写文本

### GPT-3 (2020.06) — API 商业化

- 175B 参数，96 层，12288 维
- **Few-Shot Learning**：给几个示例就能学会新任务
- 开放 API：从此任何开发者都可以调用 LLM
- **遗留问题**：输出不可控、有害内容、不会拒绝

### InstructGPT (2022.01) — RLHF 诞生

- 在 GPT-3 上首次引入 RLHF
- 论文：《Training language models to follow instructions with human feedback》
- 核心创新：SFT（学指令）+ RM 训练（学打分）+ PPO 优化（学偏好）
- **RLHF 三阶段从此成为行业标准**

### ChatGPT (2022.11) — 爆发

- 基于 GPT-3.5 + RLHF
- 5 天 100 万用户，2 个月 1 亿用户（史上最快增长产品）
- 意义：LLM 从学术圈走进大众生活

### GPT-4 (2023.03) — 质变

- ~1.8T 参数（MoE, 8×220B），激活 ~280B
- 首次支持图片理解（多模态）
- HumanEval 代码能力：GPT-3.5 67% → GPT-4 87%
- 128K 上下文（约 300 页文档）

### GPT-4o (2024.05) — 端到端多模态

- "o" = "omni"（全能）：统一处理文本+图片+音频
- 语音延迟 ~232ms（接近人类对话速度）
- 速度比 GPT-4 快 2×，价格只有一半
- **首次免费向所有用户开放**

## 3. 核心突破技术

| 技术 | 首次引入 | 解决了什么 |
|------|:---:|------|
| **预训练+微调** | GPT-1 | NLP 任务不再需要从零训练 |
| **Zero-Shot** | GPT-2 | 不给示例也能做任务 |
| **Few-Shot** | GPT-3 | 给几个示例 → 学会模式 |
| **RLHF** | InstructGPT | 输出安全、有用、符合人类偏好 |
| **MoE 架构** | GPT-4 | 万亿参数 + 可控推理成本 |
| **端到端多模态** | GPT-4o | 图文音统一、延迟极低 |

## 5. ChatGPT 的历史意义

```text
对行业的三大根本改变：

① 技术民主化：AI 能力不再需要博士学历，普通人用自然语言即可调用
② 产品范式：从"训练专用模型"到"Prompt 通用模型"，NLP 任务边界消失
③ 产业加速：引发全球 AI 军备竞赛，Google/Anthropic/Meta 全面转向 LLM

ChatGPT 不是第一个大模型，但是第一个"让全世界每个人都想用"的 AI。
```

> 🎯 GPT-1 证范式 → GPT-2 惊学界 → GPT-3 商业化 → InstructGPT 会对齐 → ChatGPT 爆大众 → GPT-4 质变 → GPT-4o 全模态统一。
