## 2. Enterprise 安全特性

Enterprise 版独有的企业级安全能力：

- 数据加密（静态存储 + 传输中）
- SAML SSO 单点登录（对接企业身份系统）
- 使用统计仪表盘（谁在用、用什么模型、消耗多少 Token）
- 用量配额管理（按用户/部门分配额度）
- 自定义数据保留策略（对话历史保留天数可配置）
- 审计日志（所有操作可追溯）
- 优先客户支持（SLA 保证）

**数据承诺**：Enterprise API 和企业版对话数据完全不用于模型训练。

## 3. 选型建议

```text
Free → 个人偶尔使用、基础问答。GPT-4o-mini 已足够好

Plus → 日常开发主力。强烈推荐 Java 开发者升级：
       GPT-4o 代码能力质的飞跃（vs GPT-4o-mini）
       DALL-E 生成配图、数据分析上传 CSV
       每月 $20 的投资回报远超这个数

Team → 小型团队（5-50 人）。共享 GPTs、数据不训练

Enterprise → 金融/医疗/政府等严格合规行业
            需要 SSO + 审计 + 数据完全隔离

Java 开发者最佳选择：Plus（$20/月）
```
