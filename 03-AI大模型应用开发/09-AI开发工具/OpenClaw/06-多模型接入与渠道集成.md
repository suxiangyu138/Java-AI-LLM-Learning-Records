## 2. 云模型配置

```json
// openclaw.json — models.providers 示例
{
  "models": {
    "default": "claude-sonnet",
    "providers": {
      // ① Claude（Anthropic 原生）
      "claude-sonnet": {
        "type": "anthropic",
        "apiKey": "${ANTHROPIC_API_KEY}",
        "model": "claude-sonnet-4-5"
      },

      // ② GPT（OpenAI 原生）
      "gpt5-turbo": {
        "type": "openai",
        "apiKey": "${OPENAI_API_KEY}",
        "model": "gpt-5-turbo"
      },

      // ③ DeepSeek（OpenAI 兼容格式）
      "deepseek": {
        "type": "openai-compatible",
        "baseUrl": "https://api.deepseek.com/v1",
        "apiKey": "${DEEPSEEK_API_KEY}",
        "model": "deepseek-chat"
      },

      // ④ 通义千问（阿里云百炼 — OpenAI 兼容）
      "qwen": {
        "type": "openai-compatible",
        "baseUrl": "https://dashscope.aliyuncs.com/compatible-mode/v1",
        "apiKey": "${DASHSCOPE_API_KEY}",
        "model": "qwen3-plus"
      },

      // ⑤ 豆包（火山引擎）
      "doubao": {
        "type": "openai-compatible",
        "baseUrl": "https://ark.cn-beijing.volces.com/api/v3",
        "apiKey": "${VOLCENGINE_API_KEY}",
        "model": "doubao-pro"
      },

      // ⑥ Google Gemini
      "gemini-flash": {
        "type": "gemini",
        "apiKey": "${GEMINI_API_KEY}",
        "model": "gemini-3.5-flash"
      }
    }
  }
}
```

## 3. 本地模型（Ollama）配置

```bash
# ① 安装 Ollama
brew install ollama           # macOS
# 或访问 ollama.com 下载 Windows/Linux 版

# ② 拉取模型
ollama pull qwen3:latest      # 通义千问 3
ollama pull deepseek-r1:7b    # DeepSeek R1 推理模型
ollama pull llama4:latest     # Meta Llama 4

# ③ 测试本地模型
ollama run qwen3:latest "Hello"
```

```json
// ④ openclaw.json 配置本地模型
{
  "models": {
    "providers": {
      "local-qwen3": {
        "type": "ollama",
        "baseUrl": "http://localhost:11434",
        "model": "qwen3:latest"
      },
      "local-deepseek": {
        "type": "ollama",
        "baseUrl": "http://localhost:11434",
        "model": "deepseek-r1:7b"
      }
    }
  }
}
```

**本地 vs 云模型选择：**

| 场景 | 推荐 | 理由 |
|------|------|------|
| 敏感数据/离线环境 | **Ollama 本地** | 数据不出本机 |
| 日常聊天/简单任务 | **Ollama 本地** | 零成本（有 GPU 的话） |
| 复杂推理/编程 | Claude/GPT（云端） | 本地 7B 模型能力不够 |
| 低成本高并发 | DeepSeek API | 成本极低 + 兼容 OpenAI |

## 4. 模型自动降级与回退链

```json
// 配置回退链（主模型故障时自动切换）
{
  "models": {
    "default": "claude-sonnet",
    "fallbackChain": [
      "claude-sonnet",     // ① 首选 Claude
      "gpt5-turbo",        // ② Claude 挂了 → GPT-5
      "deepseek",          // ③ 都挂了 → DeepSeek
      "local-qwen3"        // ④ 最后 → 本地模型兜底
    ]
  }
}
```

**Auth Profile 熔断机制：** 一个模型连续失败 N 次 → 自动标记为"熔断" → 跳过 N 秒 → 半开试探 → 恢复或继续熔断。

## 5. 消息渠道集成

```json
// openclaw.json — channels 配置
{
  "channels": {
    "whatsapp":   { "enabled": true },
    "telegram":   { "enabled": true, "botToken": "${TELEGRAM_TOKEN}" },
    "slack":      { "enabled": true, "botToken": "${SLACK_TOKEN}", "signingSecret": "${SLACK_SECRET}" },
    "discord":    { "enabled": true, "botToken": "${DISCORD_TOKEN}" },
    "signal":     { "enabled": true },
    "imessage":   { "enabled": true },
    "feishu":     { "enabled": true, "appId": "${FEISHU_APP_ID}", "appSecret": "${FEISHU_APP_SECRET}" },
    "dingtalk":   { "enabled": true },
    "wechat":     { "enabled": true },       // 企业微信
    "matrix":     { "enabled": true },
    "zalo":       { "enabled": true }
  }
}
```

**渠道自动适配：** Gateway 根据 Channel Plugin 的 capabilities 声明自动调整行为 — 不支持图片的渠道隐藏图片生成、不支持流式的渠道退化为普通文本。

## 6. 多模型成本对比与选型建议

| 模型 | 输入价格（$/百万Token） | 输出价格 | 适用场景 |
|------|:---:|:---:|------|
| Claude Sonnet 4.5 | $3 | $15 | **复杂编程/Agent**（首选） |
| GPT-5 Turbo | $1 | $2 | 通用对话、结构化输出 |
| DeepSeek V3 | **$0.28** | **$1.12** | 高并发 API、成本敏感 |
| 豆包 Pro | **$0.06** | **$0.06** | C 端中文产品、极致性价比 |
| Gemini 3.5 Flash | $0.10 | $0.40 | 多模态、长文档 |
| Ollama 本地 | **$0** | **$0** | 离线/敏感数据/简单任务 |

**推荐组合：**
```text
日常简单任务 → Ollama 本地（免费）
高频 API 调用 → DeepSeek（便宜、质量不错）
复杂编程/Agent → Claude Sonnet（业界最强）
中文 C 端产品 → 豆包（最便宜 + 中文最好）
多模态/长文档 → Gemini Flash（便宜 + 原生多模态）
兜底保障 → 本地 Ollama（云端全挂了也能用）
```

---

> 🎯 **核心要点**：模型配置三步 — **① 在 openclaw.json 的 models.providers 中声明 ② type 选 anthropic/openai/openai-compatible/ollama/gemini ③ 国产模型一律用 openai-compatible 类型（改 baseUrl 即可）**。生产必配：fallbackChain（Claude→GPT→DeepSeek→本地）+ Auth Profile 熔断，保证云端全挂时本地 Ollama 兜底。
