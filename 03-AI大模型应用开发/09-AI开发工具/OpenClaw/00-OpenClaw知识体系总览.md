## 4. 核心概念速查

| 概念 | 一句话 |
|------|--------|
| Gateway | 单一长驻进程，默认 127.0.0.1:18789，所有消息的路由中枢 |
| Agent Loop | 基于 ReAct（Reasoning→Acting→Observation）的异步执行流水线 |
| Skill | 以 `SKILL.md` 文件存在的知识/指令包，"写文档=扩展AI能力" |
| Pi-embedded | 运行在本地的执行端，真正执行 Shell/浏览器/Cron 等操作 |
| Channel Plugin | 消息渠道插件接口（WhatsApp/飞书/Telegram...），声明式接入 |
| ClawHub | Skills 社区市场，4.4 万个 Skills 可一键安装 |
| NO_REPLY | 模型输出该 token 时框架过滤不下发，实现"沉默"语义 |
| Auth Profile | 多模型凭证管理，支持熔断轮换和模型回退链 |
