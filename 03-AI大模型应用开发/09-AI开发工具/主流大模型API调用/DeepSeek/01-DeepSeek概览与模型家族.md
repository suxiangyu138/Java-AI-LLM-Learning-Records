> - **V4**（2026.04）：1.6T MoE + 1M 上下文，Codeforces 3206 分，开源模型首次在代码/Agent 领域全面超越闭源

## 2. 核心团队与研究哲学

### 2.1 团队特点

| 特点 | 说明 |
|------|------|
| **精英小团队** | 研究团队规模远小于 OpenAI/Google（数十人级别核心团队） |
| **全栈能力** | 从底层硬件优化到上层算法全链路自研 |
| **量化基因** | 高效资源利用、成本控制的工程文化 |
| **开源驱动** | 始终坚持开源，模型权重、技术报告全面公开 |
| **学术界出身** | 大量清北等顶尖高校博士 |

### 2.2 研究哲学

> 🎯 **DeepSeek 的核心理念**：用极致的工程优化，以远低于行业的成本，达到甚至超越 SOTA 性能，并通过开源推动 AGI 民主化。

**四个关键原则**：

1. **效率优先**：不追求参数量，追求每参数效率最大化
2. **架构创新**：MoE + MLA 的自研架构路线
3. **全链路优化**：从训练框架(HAI-LLM)到推理部署的全栈自研
4. **开放科学**：技术报告详尽，模型权重完全开放

## 5. 开源策略与行业影响

### 5.1 开源策略

| 维度 | DeepSeek 的做法 |
|------|----------------|
| **模型权重** | 完全开放，支持商业使用 |
| **技术报告** | 完整公开训练细节、超参数、失败经验 |
| **代码** | 部分核心训练推理代码开源 |
| **许可证** | MIT 协议，最宽松的开源许可 |
| **更新频率** | 持续迭代，社区反馈驱动的更新模式 |

### 5.2 行业震动

> ⚠️ **"DeepSeek Moment"**：2024年12月26日 DeepSeek-V3 发布当天，AI 圈引发地震——一家中国初创公司仅用 $5.5M 训练成本、2048 块 H800 GPU，就造出了对标 GPT-4o 的模型。NVIDIA 股价当日下跌 17%，市值蒸发近 $600B。

**核心争议与讨论**：

| 话题 | 分析 |
|------|------|
| **算力效率** | DeepSeek 的 H800 虽受出口管制，但通过极致的架构优化和 FP8 训练，实现了超高的算力利用率 |
| **蒸馏疑虑** | 有质疑 V3 是否蒸馏了 GPT-4，但技术报告详细说明了独立训练过程 |
| **生态冲击** | 打破了"参数军备竞赛"，引导行业从拼算力转向拼效率 |
| **开源 vs 闭源** | 证明开源模型可以追平闭源，加速了 AI 民主化进程 |

## 6. 总结与展望

> 🎯 **DeepSeek 的核心叙事**：以工程卓越对抗算力优势，以开源对抗封闭，以效率对抗规模。它证明了在 AI 领域，聪明的架构设计比盲目堆算力更重要。

**关键启示**：

1. **效率比规模更重要**：671B MoE 模型以 37B 激活达到 GPT-4o 性能
2. **架构创新是关键壁垒**：MLA 的 KV Cache 压缩是革命性的
3. **开源是战略而非情怀**：开源加速生态建设，获取社区反馈
4. **成本优势可转化为护城河**：API 价格远低于竞品
5. **小团队 + 极致工程**：精英化、全栈自研、深度优化
