## 1. 架构核心参数

| 参数 | GLM-4.7 | GLM-5 | 变化 |
|------|:---:|:---:|:---:|
| 总参数量 | 355B | **744B** | +110% |
| 激活参数 | 32B | **40B** | +25% |
| 预训练数据 | — | **28.5T** | 大幅提升 |
| 上下文 | — | 200K（输出 128K） | 提升 |
| 架构 | MoE | **MoE + DSA** | 新增稀疏注意力 |

```text
MoE 的核心思想（GLM-5 延续）：
├── 总参数 744B = 知识容量
├── 激活 40B = 推理成本（每次只激活 40B）
├── 专家分工：不同 token 走不同专家
└── 性价比：40B 的成本获得 744B 的知识
```

## 2. DSA 稀疏注意力机制

**DSA（Dynamic Sparse Attention，动态稀疏注意力）是 GLM-5 的核心创新：**

```text
传统全注意力：
  token 与上下文所有 token 计算注意力 → O(n²) 计算成本
  长上下文时成本爆炸

DSA 稀疏注意力：
  token 只与"相关的" token 计算注意力 → O(n) 线性成本
  相关性动态判断（不固定窗口，动态选择）
  长上下文（200K）下依然高效

带来的收益：
├── Token 效率提升（相同成本处理更长上下文）
├── Agent 能力提升（长程任务的上下文管理更好）
└── 推理成本降低（稀疏计算）
```

**与 MiMo 的 SWA（滑动窗口注意力）对比：** 滑动窗口是"固定窗口"（只看相邻 N 个 token）；DSA 是"动态稀疏"（按相关性动态选择关注点）— DSA 更灵活但实现更复杂。

## 3. 异步强化学习

```text
传统 RL（同步）：
  策略更新 → 收集数据 → 更新 → 收集数据（串行，效率低）

异步强化学习（GLM-5）：
  多个 Actor 并行收集经验 + 一个 Learner 持续更新
  → 训练效率大幅提升
  → 能处理更复杂的 Agent 任务轨迹

对 Agent 能力的意义：
├── 更长的 Agent 轨迹可以训练（4000+ 步任务）
├── 工具调用更稳定（Toolathlon 类基准提升）
└── 长程决策更优（8 小时自主任务）
```

## 5. 国产芯片与部署

```text
GLM-5 的部署优势：
├── 支持国产芯片推理（华为昇腾/寒武纪等）
├── 开源版本可私有化部署（GLM-5.2 MIT）
├── 40B 激活 → 单机可部署（相对 744B 总参）
└── 适配国产算力 = 合规 + 成本优势

部署方式：
├── open.bigmodel.cn（官方 API）
├── 开源权重 + vLLM 自部署
├── 国产芯片 + 自研推理框架
└── OpenClaw 等框架接入（OpenAI 兼容）
```

> 🎯 **核心要点**：GLM-5 三大技术支柱 — **① 744B/40B MoE（大知识容量 + 可控推理成本）② DSA 稀疏注意力（长上下文高效）③ 异步强化学习（长程 Agent 训练）**。这些技术合力支撑了"Agent 长程任务开源 SOTA"（BrowseComp/MCP-Atlas/τ-Bench 全部第一）。部署上支持国产芯片是它的独特合规优势。
