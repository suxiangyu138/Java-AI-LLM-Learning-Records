## 1. Prompt Caching：最长前缀缓存

```python
# 缓存工作流：标记缓存点 → 写入缓存 → 后续请求命中 → 省 90% 输入成本

# ① 标记缓存点（system prompt 或前几条消息中）
response = client.messages.create(
    model="claude-sonnet-4-6",
    system=[
        {"type": "text", "text": "你是 Java 专家...（大量稳定的系统提示）",
         "cache_control": {"type": "ephemeral"}}  # ★ 缓存点标记
    ],
    messages=[...]
)
# usage.cache_creation_input_tokens → 缓存写入量
```

**缓存定价与 ROI：**

| 缓存类型 | 写入价 | 读取价 | ROI |
|----------|:---:|:---:|:---:|
| 5 分钟缓存 | 1.25× 标准输入 | **0.1× 标准输入** | 1 次读取即回本 |
| 1 小时缓存 | 2× 标准输入 | 0.1× 标准输入 | 2 次读取回本 |

**缓存最大化策略：**
```text
① System Prompt 放最长稳定前缀（Docs/规则/角色定义）
② 静态知识库片段放前面（用户动态内容放后面）
③ 检查 usage.cache_read_input_tokens 确认命中
④ 相同前缀同一小时内多次请求 → 缓存持续有效
```

## 2. Batch API：半价异步处理

```python
# ① 创建批量任务
batch = client.messages.batches.create(
    requests=[{
        "custom_id": f"task-{i}",        # ★ 自定义 ID（关联结果）
        "params": {
            "model": "claude-haiku-4-5-20251001",
            "max_tokens": 1024,
            "messages": [{"role": "user", "content": text}]
        }
    } for i, text in enumerate(texts)]
)
print(f"Batch ID: {batch.id}")

# ② 轮询结果（24 小时内完成）
import time
while True:
    status = client.messages.batches.retrieve(batch.id)
    if status.processing_status == "ended":
        break
    time.sleep(60)  # 每分钟查一次

# ③ 读取结果
for result in client.messages.batches.results(batch.id):
    if result.result.type == "succeeded":
        print(f"[{result.custom_id}] {result.result.message.content[0].text}")
    else:
        print(f"[{result.custom_id}] Error: {result.result.error}")
```

**Batch 适用场景：** 批量分类/评价/翻译/嵌入（离线、异步、不紧急）。**半价！**

## 3. 多模型智能路由

```python
class SmartRouter:
    """按任务复杂度智能路由，省 50-70% 成本"""

    def __init__(self):
        self.haiku = Anthropic()  # Haiku 4.5（$1/$5，便宜）
        self.sonnet = Anthropic() # Sonnet 4.6（$3/$15，主力）
        self.opus = Anthropic()   # Opus 4.7（$5/$25，难题）

    def route(self, task_type: str, messages: list) -> str:
        if task_type in ("classify", "extract", "simple"):
            model, client = "claude-haiku-4-5-20251001", self.haiku
        elif task_type in ("code", "analysis", "chat"):
            model, client = "claude-sonnet-4-6", self.sonnet
        elif task_type in ("debug", "architecture", "complex_agent"):
            model, client = "claude-opus-4-7", self.opus
        else:
            model, client = "claude-sonnet-4-6", self.sonnet

        return client.messages.create(model=model, messages=messages, ...)
```

**推荐路由分配：**
```text
日常 80% 请求 → Haiku（简单任务）→ 省 5 倍
复杂 15% 请求 → Sonnet（编程/分析）→ 主力
极难 5% 请求 → Opus（架构/安全）→ 保质量
全面启用 Batch → 再省 50%
```

## 4. 限流与错误处理

### 4.1 限流处理

```python
import time
from anthropic import RateLimitError

def call_with_retry(messages, max_retries=5):
    """指数退避重试"""
    for attempt in range(max_retries):
        try:
            return client.messages.create(
                model="claude-sonnet-4-6",
                max_tokens=4096,
                messages=messages
            )
        except RateLimitError as e:
            if attempt == max_retries - 1:
                raise
            wait = 2 ** attempt + random.uniform(0, 1)  # 指数退避 + 抖动
            time.sleep(wait)
```

### 4.2 错误速查

| 错误码 | 含义 | 处理 |
|--------|------|------|
| 400 | 参数错误（thinking/temperature 不支持等） | 检查模型兼容性 |
| 401 | API Key 无效 | 检查环境变量 |
| 413 | 请求体过大 | 截断上下文或分批 |
| **429** | **限流** | 指数退避 + 考虑升级 Tier |
| 529 | 服务过载 | 指数退避重试 |
| 500/503 | 服务端错误 | 重试 |

## 5. 安全最佳实践

| 实践 | 说明 |
|------|------|
| **API Key 环境变量** | 绝不硬编码，用密钥管理服务（KMS/AWS Secrets Manager） |
| **用户数据隔离** | `metadata.user_id` 标注用户，审计谁调了什么 |
| **Prompt 注入防御** | System Prompt 开头声明不容覆盖的规则 |
| **工具白名单** | Agent 循环只允许执行白名单工具 |
| **输出校验** | LLM 输出过校验层（格式/长度/敏感词）后再给用户 |
| **审计日志** | 记录每次调用的 user_id、model、tokens、prompt 摘要 |
| **数据脱敏** | 用户输入中的手机号/身份证脱敏后再发给 Claude |
