# 05 - 国产 AI 编码工具

> 🎯 通义灵码免费且中文友好、CodeGeeX 开源可自建、DeepSeek Coder API 成本极低 — 国产 AI 编码工具的差异化打法

## 1. 基础定义

国产 AI 编码工具是中国厂商推出的 AI 辅助编程产品，涵盖 IDE 插件、独立 IDE、API 服务三种形态。

## 2. 溯源历史

- 2022 — CodeGeeX（智谱）首个国产开源代码大模型
- 2023.10 — 通义灵码（阿里）发布，免费面向个人
- 2024.03 — DeepSeek Coder V2 发布，开源代码能力接近 GPT-4
- 2024.08 — 通义灵码支持 VS Code/JetBrains

## 3. 底层原理

与 Copilot 类似的 FIM 训练 + 代码语料预训练。差异化在于：
- 通义灵码：基于 Qwen 系列 + 阿里内部代码库训练
- CodeGeeX：基于 ChatGLM + 开源代码训练
- DeepSeek Coder：从头训练的代码专用模型 + Fill-in-Middle

### DeepSeek Coder API

```python
# DeepSeek Coder — 代码生成性价比之王
from openai import OpenAI
client = OpenAI(
    api_key="sk-xxx", base_url="https://api.deepseek.com"
)
resp = client.chat.completions.create(
    model="deepseek-coder",
    messages=[{"role":"user","content":"用Java写一个线程安全的单例模式"}],
    temperature=0  # 代码生成建议 temperature=0
)
```
