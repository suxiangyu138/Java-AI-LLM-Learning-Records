## 1. 人工智能概述

### 1.1 基本知识

**人工智能（AI）** 是模拟人类智能的理论、方法、技术及应用系统的总称。核心研究领域包括：

- 机器学习与深度学习
- 自然语言处理
- 计算机视觉
- 知识表示与推理
- 机器人学

### 1.2 发展先驱

| 时期 | 里程碑 |
|---|---|
| 古代 | 传说中的人工智能、人偶尝试 |
| 近代 | 机械化推理、计算机科学奠基 |
| 影视文化 | 《终结者》《黑客帝国》《机器人瓦力》等作品塑造 AI 公众认知 |

## 2. 四个时代发展脉络

| 时代 | 时期 | 核心特征 | 关键事件 |
|---|---|---|---|
| 1.0 计算推理 | 1956-1974 | 符号主义、逻辑推理 | 达特茅斯会议（1956）、图灵测试、Checkers 程序 |
| 2.0 知识表示 | 1970s-1993 | 专家系统、知识工程 | 搜索式推理、自然语言处理、两次 AI 寒冬 |
| 3.0 机器学习 | 1993-2006 | 统计学习、联结主义 | 互联网兴起、联结主义回归、躯体化理论 |
| 4.0 深度学习 | 2006-至今 | 深度神经网络、大数据 | 深蓝（1997）、AlphaGo（2016）、大语言模型 |

### 关键里程碑

- **1956 达特茅斯会议**：AI 学科正式诞生
- **1997 深蓝**：AI 首次击败国际象棋世界冠军
- **2016 AlphaGo**：深度学习战胜围棋世界冠军李世石
- **2022 ChatGPT**：LLM 引爆全球 AI 应用浪潮

## 3. 核心技术概览

| 技术 | 说明 | 应用场景 |
|---|---|---|
| **自然语言处理（NLP）** | 语音识别、语义理解、自动翻译 | 智能客服、机器翻译、语音助手 |
| **计算机视觉（CV）** | 图像识别、目标检测、人脸识别 | 安防监控、自动驾驶、医疗影像 |
| **模式识别** | 文字识别、指纹识别、3D 技术 | 考勤系统、生物识别、3D 打印 |
| **知识表示** | 知识图谱、语义网络 | 专家系统、智能问答 |
| **自动推理** | 逻辑推理、规划调度 | 决策支持、机器人控制 |

## 4. 商业模式分析

### 4.1 五大商业模式

| 模式 | 说明 | 代表企业 |
|---|---|---|
| **生态构建模式** | 打造平台+生态，开放 API | 百度、阿里、腾讯 |
| **技术驱动模式** | 核心技术授权和技术服务 | 科大讯飞、商汤科技 |
| **应用聚焦模式** | 专注特定场景的 AI 应用 | 旷视科技（Face++） |
| **垂直领域领先模式** | 深耕医疗/金融/教育等垂直行业 | 多个创业公司 |
| **基础设施切入模式** | AI 芯片/算力/云服务 | 英伟达、华为昇腾 |

### 4.2 三种盈利模式

1. **卖技术**：API 调用、SDK 授权、技术解决方案
2. **卖产品**：AI 硬件（智能音箱、无人机）、SaaS 产品
3. **卖知识产权**：专利授权、算法许可

## 5. 热门领域实战应用

| 领域 | 典型应用 | 关键技术 |
|---|---|---|
| **工业** | 机器视觉质检、工业机器人 | 计算机视觉、机器人学 |
| **医疗** | 医学影像分析、智能诊断 | 深度学习、NLP |
| **安防** | 智能监控、人脸识别 | 计算机视觉、模式识别 |
| **社交** | 智能聊天机器人、内容推荐 | NLP、推荐系统 |
| **机器人** | 工业机器人、服务机器人 | 感知+决策+控制 |
| **无人驾驶** | 环境感知、路径规划 | 计算机视觉、传感器融合 |
| **金融** | 智能投顾、风控、反欺诈 | NLP、知识图谱 |
| **法律** | 智能合同审查、法律预判 | NLP、知识表示 |

## 6. 工业 4.0 与智能时代

### 6.1 工业 4.0 本质

- **智能工厂**：数字化、网络化、智能化
- **智能生产**：柔性制造、个性化定制
- **智能物流**：自动化仓储、AGV 调度

### 6.2 案例分析

| 案例 | 领域 | 技术应用 |
|---|---|---|
| 西门子工业自动化 | 制造 | 数字孪生、工业物联网 |
| 亚马逊云服务 | 云计算 | AI PaaS / SaaS |
| 智慧城市（北京） | 城市管理 | 物联网 + 大数据 + AI |
| 农业物联网 | 农业 | 环境监测、自动控制 |

## 核心要点回顾

- AI 从符号主义到深度学习历经四个时代，每次突破都伴随着应用场景的扩展
- 核心技术栈涵盖 NLP、CV、模式识别、知识表示与推理
- 五大商业模式和三种盈利模式构成 AI 商业化的基本框架
- 工业、医疗、安防、金融、法律等领域是 AI 落地的主力场景
- 工业 4.0 推动智能制造和智慧城市发展，AI 成为核心驱动力
