## 5. 核心术语速查

| 术语 | 含义 |
|------|------|
| **JTBD** | Jobs To Be Done — 用户"雇佣"产品完成的任务 |
| **数据飞轮** | 数据 → 模型 → 体验 → 用户 → 更多数据 的正循环 |
| **PMF** | Product-Market Fit — 产品与市场的匹配度 |
| **AARRR** | Acquisition-Activation-Retention-Revenue-Referral 增长模型 |
| **RAG** | Retrieval-Augmented Generation — 检索增强生成 |
| **AI Agent** | 具备自主决策+多步执行能力的 AI 智能体 |
| **Prompt 注入** | 恶意输入诱导模型绕过安全限制 |
| **主动学习** | 优先标注模型最不确定的样本，提升标注效率 |
| **单位经济学** | Unit Economics — 单用户/单次调用的收入与成本分析 |
