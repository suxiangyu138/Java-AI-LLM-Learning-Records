## 3. 学习路线

### 🟢 L1：理解 Skill 概念（20 分钟）

```
01-核心概念 → 02-类型与设计模式
产出：理解 Skill = 工具 + 知识 + 流程，区分 Skill/Tool/Plugin
```

### 🔵 L2：掌握机制（40 分钟）

```
03-描述与注册 → 04-组合与编排
产出：能设计 Skill Schema、懂注册发现、会编排 Skill 工作流
```

### 🟣 L3：框架实战（40 分钟）

```
05-框架实现对比
产出：掌握至少 2 种框架的 Skill 实战，能跨框架迁移
```

### 🟡 L4：生产落地（30 分钟）

```
06-实战最佳实践 → 07-安全与测试
产出：能写出生产级 Skill、覆盖安全测试
```
