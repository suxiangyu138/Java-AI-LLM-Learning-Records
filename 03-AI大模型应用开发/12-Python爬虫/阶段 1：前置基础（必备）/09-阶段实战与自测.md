## 1. 综合实战：抓取并解析一个页面

> ⚠️ 实战建议：用**公开新闻/文档站**练手（尊重 robots.txt、低频访问）；以下代码在本地验证。

```python
"""
实战任务：抓取一个静态页面的新闻列表（标题 + 链接 + 日期）
完整流程：环境验证 → 请求 → 状态码检查 → 解析 → 提取
"""
import requests
from bs4 import BeautifulSoup

# ① 环境验证（爬虫三件套）
assert all(__import__(m) for m in ["requests", "bs4", "lxml"])

# ② 礼貌请求（UA 标识 + 超时）
headers = {"User-Agent": "StudyCrawler/1.0 (learning purpose)"}
resp = requests.get("https://example.com/news", headers=headers, timeout=10)

# ③ 状态码判定（先看码再处理）
if resp.status_code != 200:
    raise SystemExit(f"请求失败: {resp.status_code}")

# ④ 编码处理（乱码急救）
if resp.encoding and resp.encoding.lower() != "utf-8":
    resp.encoding = resp.apparent_encoding

# ⑤ 解析（lxml 后端）
soup = BeautifulSoup(resp.text, "lxml")

# ⑥ 选择器提取（泛化后的稳定锚点）
items = soup.select("ul.news-list li")
if not items:
    raise SystemExit("未找到列表项——检查选择器（F12 验证）")

# ⑦ 逐条提取 + 清洗
for item in items:
    a = item.select_one("a.news-title")
    date = item.select_one("span.date")
    title = a.text.replace("\xa0", " ").strip()     # \xa0 清洗
    url = a.get("href")
    print(f"[{date.text.strip()}] {title} -> {url}")
```

## 2. 实战进阶：定位并请求数据接口

```python
"""
实战任务：发现 JS 渲染页面的数据接口并直接请求（黄金法则）
流程：F12 五步法 → 复刻接口请求 → 解析 JSON
"""
import requests

# ① F12 Network 筛 Fetch/XHR → 找到接口（见 07 五步法）
# 假设找到：GET https://example.com/api/news?page=1

# ② 复刻接口请求（带浏览器 Headers）
session = requests.Session()
session.headers.update({
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
                  "AppleWebKit/537.36 Chrome/126.0.0.0 Safari/537.36",
    "Referer": "https://example.com/news",   # 接口校验来源
    "Accept": "application/json",
})
resp = session.get("https://example.com/api/news", params={"page": 1}, timeout=10)

# ③ JSON 解析（结构：data.list[]）
data = resp.json()
for item in data.get("data", {}).get("list", []):
    print(item["id"], item["title"])
```

| 对比 | 页面解析（§1） | 接口直取（§2） |
|------|:---:|:---:|
| 速度 | 慢（解析 HTML） | **快 10 倍**（JSON 直取） |
| 稳定性 | 依赖页面结构 | 依赖接口契约 |
| 反爬风险 | 中 | 高（接口更常被防护） |
| 适用 | 无接口/需要渲染数据 | **有接口时优先** |
