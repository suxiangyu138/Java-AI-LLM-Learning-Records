## 5. 核心概念速查

| 概念 | 一句话 |
|------|--------|
| HTTP 请求 | 浏览器/爬虫向服务器要数据说的话 |
| HTTP 响应 | 服务器回的话（状态码 + 头 + 内容） |
| 状态码 | 200 成功 / 301-302 跳转 / 403 拒绝 / 404 没有 / 429 太频繁 |
| Header | 请求头（UA/Referer/Cookie）——服务器识别"你是谁" |
| Cookie | 会话凭证（登录态），爬虫要"学会带" |
| HTML | 网页结构语言（标签树） |
| CSS 选择器 | 按类名/ID/属性定位元素的语法 |
| XPath | XML/HTML 的路径定位语法（更强大） |
| DOM | 浏览器内存中的网页对象树 |
| JSON | 接口返回的数据格式（Python 字典的亲戚） |
| 字符编码 | UTF-8（现代标准）/ GBK（老中文站）——乱码根源 |
| 正则表达式 | 从文本中按模式提取内容的工具 |
| F12 开发者工具 | 看网页结构的放大镜 |
| robots.txt | 网站声明"允许/禁止"爬取的协议文件 |
| 礼貌爬虫 | 频率控制 + UA 标识 + 尊重 robots |
