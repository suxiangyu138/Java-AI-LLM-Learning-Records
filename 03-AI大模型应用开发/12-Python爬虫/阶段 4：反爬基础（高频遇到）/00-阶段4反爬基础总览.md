## 5. 核心概念速查

| 概念 | 一句话 |
|------|--------|
| 反爬 | 站点阻止非人类访问的手段集合 |
| 403 | 身份校验没过（UA/头/风控） |
| 429 | 频率超限（限流信号） |
| UA 池 | 多浏览器 UA 随机切换 |
| 完整浏览器头 | 不止 UA：Accept/Referer/Cookie 全套 |
| 随机延迟 | 请求间隔随机化（防模式识别） |
| 代理 | 换出口 IP（隧道/动态） |
| 验证码 | 图形/滑块/点选（人机验证） |
| 登录态 | Cookie 携带会话（Session 保持） |
| 设备指纹 | 浏览器特征组合（Canvas/WebGL/时区） |
| JS 检测 | 站点用 JS 探测"是否真浏览器" |
| 风控信号 | 频率/行为/指纹综合评分 |
| robots.txt | 站点声明（阶段 1，此处回顾） |
