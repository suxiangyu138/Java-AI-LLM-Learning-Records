## 1. 为什么需要代理

```text
IP 封禁的两种形态：
  ① 临时封：速率超限 → 等几分钟解封
  ② 永久封：同 IP 总量超限/行为恶劣 → 换 IP 才能继续

什么时候该用代理：
  · 同 IP 访问量超过站点容忍（总量维度）
  · 分布式采集需要多出口（不同 IP 分散）
  · 被封后需要"新身份"继续

什么时候不该用：
  · 频率问题（03 章解决）→ 先降速，不是换 IP
  · 小量采集 → 一个 IP 够用（代理增加复杂度）
```

> 🎯 认知：**"代理解决'IP 维度'的限制，不解决'频率维度'的限制"**——频率超限换 IP 治标不治本（新 IP 照样被限）。先降速，再谈代理。

## 2. 代理类型与原理

```text
代理类型：
  ① 普通代理（共享 IP）：多人共用出口（慢/易被封）
  ② 独享代理：独占 IP（贵/稳定）
  ③ 隧道代理：每次请求换 IP（动态/轮换）
  ④ 高匿代理：隐藏"代理特征"（最佳）

原理：
  客户端 → 代理服务器 → 目标站
              （目标站看到的是代理 IP，不是你的 IP）

代理的关键指标：
  匿名度（透明/普匿/高匿）
  稳定性（存活率）
  速度（延迟）
  纯净度（IP 是否被目标站标记）
```

| 代理类型 | 匿名度 | 速度 | 价格 | 适用 |
|---------|:---:|:---:|:---:|------|
| 免费 | 低 | 差 | 免费 | 学习/测试 |
| 普通共享 | 中 | 中 | 低 | 批量采集 |
| 独享 | 高 | 快 | 高 | 重要任务 |
| 隧道/动态 | 高 | 中 | 中 | 轮换需求 |

> ⚠️ **高匿 ≠ 免费**：免费代理多为"透明代理"（目标站能识别是代理）——用于学习可以，生产采集要用付费高匿。

## 3. 免费代理的坑

```text
免费代理的真实情况（2026）：
  · 存活率低：10 分钟死一半
  · 速度慢：跨国中转，延迟 5-10 倍
  · 匿名度差：透明代理居多（暴露代理特征）
  · 安全风险：免费代理可能抓取你的流量！
  · IP 被标记：免费代理 IP 常被目标站封禁（黑名单）

结论：免费代理只适合"学习验证"，
      生产采集必须付费（或自建代理池）
```

```python
# ═══ 免费代理的正确用法：边测边用 ═══
def test_proxy(proxy: str, test_url="https://httpbin.org/ip") -> bool:
    """验证代理可用性（返回是否能用）"""
    try:
        resp = requests.get(test_url,
                            proxies={"http": proxy, "https": proxy},
                            timeout=5)
        return resp.status_code == 200 and "origin" in resp.text
    except requests.RequestException:
        return False

# 用法：候选代理批量测试 → 只留能用的
candidates = ["http://ip:port", ...]          # 免费列表
valid = [p for p in candidates if test_proxy(p)]
print(f"免费代理存活率: {len(valid)}/{len(candidates)}")
```

> ⚠️ 免费代理安全红线：**① 别用免费代理传登录凭据**（代理能看到你的流量——HTTPS 站点加密了 body 但目标地址可见）；**② 免费代理列表多为"过期池"**（别人用过的被封 IP）；**③ 生产采集=付费，这是常识不是建议**。

## 4. 付费代理与 API

```text
付费代理的形态（2026）：
  · 按量/按时间计费
  · 提供代理 IP 池 API（动态获取可用 IP）
  · 隧道代理（一个入口，自动轮换出口 IP）

典型流程（隧道代理）：
  requests → 隧道入口（proxy.example.com:port）→ 自动换 IP → 目标站
  客户端配置一次，出口 IP 每次/每 N 请求自动变化

API 型代理池（获取 IP 列表）：
  GET https://api.proxy.com/get?num=20
  → 返回 [{ip, port, expire}, ...]（有效期内的 IP 列表）
```

```python
# ═══ 隧道代理使用（最简单，推荐）═══
PROXY_HOST = "proxy.example.com"
PROXY_PORT = 8888
PROXY_USER = "your-username"
PROXY_PASS = "your-password"

proxies = {
    "http": f"http://{PROXY_USER}:{PROXY_PASS}@{PROXY_HOST}:{PROXY_PORT}",
    "https": f"http://{PROXY_USER}:{PROXY_PASS}@{PROXY_HOST}:{PROXY_PORT}",
}
resp = requests.get(url, proxies=proxies, timeout=10)
print("出口 IP:", resp.json().get("origin"))    # 验证 IP 是否变化

# ═══ API 型代理池（动态获取）═══
def fetch_proxies(num=10):
    resp = requests.get(f"https://api.proxy.com/get?num={num}", timeout=10)
    return [f"http://{p['ip']}:{p['port']}" for p in resp.json()["data"]]
```

> 🎯 隧道 vs API 选型：**隧道代理省心**（一个配置自动轮换，适合中小采集）；**API 型可控**（自己管理池子，适合分布式/精细控制）。本阶段先用隧道理解原理，阶段 6 做代理池工程化。

## 5. requests 代理配置

```python
import requests

# ═══ 方式一：请求级代理 ═══
proxies = {"http": "http://ip:port", "https": "http://ip:port"}
resp = requests.get(url, proxies=proxies, timeout=10)

# ═══ 方式二：Session 级（会话内统一）═══
session = requests.Session()
session.proxies.update(proxies)
resp = session.get(url, timeout=10)

# ═══ 方式三：环境变量（全局，脚本外配置）═══
# export HTTP_PROXY=http://ip:port
# export HTTPS_PROXY=http://ip:port
# requests 自动读取

# ═══ 代理认证 ═══
proxies = {"https": "http://user:pass@ip:port"}

# ═══ 禁用代理（本地/内网请求）═══
resp = requests.get(local_url, proxies={"http": None, "https": None}, timeout=10)

# ═══ 验证出口 IP（确认代理生效）═══
resp = requests.get("https://httpbin.org/ip", proxies=proxies, timeout=10)
print("当前出口:", resp.json()["origin"])
```

| 配置方式 | 场景 |
|---------|------|
| 请求级 | 单次请求换 IP |
| Session 级 | 会话统一出口 |
| 环境变量 | 脚本外部配置（部署灵活） |
| 验证 | `httpbin.org/ip` 确认出口变化 |

> ⚠️ 代理验证是铁律：**"配了代理必须验证出口 IP"**——配错/代理失效时，请求可能"裸奔"（用你真实 IP）或被拒。`httpbin.org/ip` 一行验证，别省。

## 6. 简单代理池设计

```python
"""简单代理池（本阶段版：API 获取 + 验证 + 轮换）"""
import random
import threading
import time
import requests


class SimpleProxyPool:
    """代理池：获取 → 验证 → 轮换"""

    def __init__(self, fetch_api=None, min_valid=3):
        self.pool = []                     # 可用代理列表
        self.fetch_api = fetch_api
        self.min_valid = min_valid
        self.lock = threading.Lock()

    def refresh(self):
        """从 API 拉取并验证（定时调用）"""
        try:
            candidates = self._fetch_from_api()
            valid = [p for p in candidates if self._test(p)]
            with self.lock:
                self.pool = valid
            print(f"代理池刷新: {len(valid)} 个可用")
        except Exception as e:
            print(f"代理刷新失败: {e}")

    def get(self):
        """取一个可用代理（随机）"""
        with self.lock:
            if not self.pool:
                self.refresh()
            return random.choice(self.pool) if self.pool else None

    def _fetch_from_api(self):
        # 从代理 API 获取候选（按服务商文档）
        resp = requests.get(self.fetch_api, timeout=10)
        return [f"http://{p['ip']}:{p['port']}" for p in resp.json().get("data", [])]

    def _test(self, proxy):
        try:
            r = requests.get("https://httpbin.org/ip",
                             proxies={"http": proxy, "https": proxy}, timeout=5)
            return r.status_code == 200
        except requests.RequestException:
            return False


# 使用
pool = SimpleProxyPool(fetch_api="https://api.proxy.com/get?num=20")
pool.refresh()                               # 初始化
for url in urls:
    proxy = pool.get()
    if not proxy:
        print("代理池空了，等待刷新")
        time.sleep(60)
        continue
    resp = requests.get(url, proxies={"http": proxy, "https": proxy}, timeout=10)
```

| 代理池要素 | 说明 |
|-----------|------|
| 获取 | API 拉候选（隧道代理则免池） |
| 验证 | 使用前测试（存活率过滤） |
| 轮换 | 随机/顺序取用（分散请求） |
| 刷新 | 定时刷新（IP 有有效期） |
| 兜底 | 池空等待/告警 |

> 🎯 本阶段代理池定位：**"够用即可"**——理解"获取-验证-轮换"三要素即可；生产级代理池（去重/健康检查/并发分配）在阶段 6 工程化章节展开。

## 7. 代理使用规范

```text
代理使用自查：
  □ 先解决频率问题，再考虑代理（别本末倒置）
  □ 生产用付费高匿代理（免费=安全+质量风险）
  □ 配了代理验证出口 IP（防裸奔）
  □ 代理失效有兜底（超时/降级/告警）
  □ 会话与 IP 一致性（别一会一个 IP 一会一个 UA，见 02 §5）
  □ 合规（代理不改变"该不该爬"的答案，见 07）

代理哲学的提醒：
  代理是"技术手段"，不是"隐身斗篷"
  该停的数据（付费墙/隐私/条款禁止）用代理也停
```

> 🎯 本章小结：**"代理 = 换出口 IP 解决 IP 维度限制"**——隧道代理（简单）/ API 池（可控）二选一，配好验证与兜底。下一关是"登录"（[05-Cookie 与登录态](05-Cookie与登录态.md)）——很多数据要登录才能看，登录态是"身份的通行证"。
