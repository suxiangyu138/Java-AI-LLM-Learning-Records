## 4. 阶段定位与核心策略

```text
核心策略（本阶段第一原则）：
  动态页面 ≠ 必须渲染！

  ① 先找接口（F12 Network）→ 有接口直取（快 10 倍）
  ② 无接口或接口加密 → 浏览器渲染（Playwright）
  ③ 渲染也搞不定 → 评估放弃/换源（阶段 4 §7 边界）

与主体系 05-动态渲染与Selenium实战.md 的分工：
  主体系 = 速查版（Selenium 全览）
  本阶段 = 课程执行版（接口优先策略 + Selenium + Playwright 双线）
```

> 🎯 认知起点：**"动态页的第一解法不是 Selenium，是 F12"**——大多数"动态页面"其实是"空壳 HTML + 接口渲染"，接口直取比渲染快 10 倍、稳 10 倍。本阶段 02 章讲透这条最优路线。

## 5. 核心概念速查

| 概念 | 一句话 |
|------|--------|
| 动态页面 | 数据由 JS 加载（HTML 是空壳） |
| SSR | 服务端渲染（数据在 HTML，静态爬虫可拿） |
| CSR | 客户端渲染（数据靠 JS 拉接口） |
| 接口直取 | 直接请求数据接口（最优） |
| WebDriver | 浏览器自动化驱动（Selenium 核心） |
| 显式等待 | 等某个条件成立（元素出现） |
| 隐式等待 | 全局轮询（找不到就等） |
| headless | 无头模式（无界面运行） |
| Playwright | 现代浏览器自动化（2026 新项目首选） |
| route() | Playwright 请求拦截（拿接口数据） |
| stealth | 反检测插件（隐藏自动化特征） |
| 渲染后解析 | 浏览器渲染完 → 取 DOM 解析 |
