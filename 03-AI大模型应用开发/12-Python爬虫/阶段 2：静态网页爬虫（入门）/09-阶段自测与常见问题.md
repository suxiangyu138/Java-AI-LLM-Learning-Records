## 1. 常见报错排查表

| 报错/现象 | 根因 | 解法 |
|---------|------|------|
| `requests.exceptions.ConnectTimeout` | 连接超时（网络/地址错） | 检查 URL/网络；加长 connect 超时 |
| `requests.exceptions.ReadTimeout` | 响应慢 | 加长 read 超时（15→30s） |
| `Max retries exceeded` | 底层连接失败 | 见 ConnectTimeout；检查代理 |
| **中文乱码** | 编码推断错 | `resp.encoding = resp.apparent_encoding` 或 `content.decode("gbk")`（阶段 1 §5） |
| `AttributeError: 'NoneType' object has no attribute 'text'` | **select_one 返回 None** | 判空：`el = select_one(...); text = el.text if el else ""` |
| 解析结果为空列表 | 选择器写错/结构变了 | F12 验证选择器（Console `$$()`）；容器先行 |
| 403 Forbidden | UA 被拦/风控 | 换浏览器 UA；检查 Cookie/Referer；降频 |
| 429 Too Many Requests | 频率超限 | 等待 Retry-After；降低节奏（06 §4） |
| `json.JSONDecodeError` | 接口没返回 JSON（反爬/参数错） | 先 print(resp.text) 看实际返回 |
| `sqlite3.OperationalError: no such table` | 建表未执行 | 建表语句在连接后立即执行 |
| CSV 打开乱码 | 编码非 utf-8-sig | 写入用 `encoding="utf-8-sig"` |
| 详情页爬不到内容 | 数据在 JS 里（动态页） | 本阶段先跳过；阶段 5 处理（找接口/渲染） |
| 偶发失败（时好时坏） | 网络抖动/服务器不稳定 | 加重试（02 §3）；记录失败清单 |

> 🎯 最高频的三个：**NoneType 错误（没判空）、乱码（编码）、403/429（身份/频率）**——本阶段 90% 的报错都在这三族里。

## 2. 排查方法论：三层定位

```text
跑不通时按层排查（别乱试）：

① 请求层（先验证"拿没拿到"）：
   print(resp.status_code, len(resp.text))
   curl 先试 URL → 通了再继续
   拿不到 → 网络/URL/UA/封禁

② 解析层（再验证"拿对没有"）：
   F12 看实际 HTML 结构（class 名对不对）
   Console 验证选择器命中数量（阶段 1 §7）
   解析不到 → 选择器/结构/数据在 JS

③ 存储层（最后验证"存好没有"）：
   print(rows) 看数据
   存完打开文件看（Excel 乱码/空行/重复）

铁律：一次只改一个变量，改完重跑看输出
```

> 🎯 排查心法：**"先确认拿到（请求层），再确认拿对（解析层），最后确认存好（存储层）"**——自上而下，每层用最小验证（print 一行）确认，别同时怀疑所有环节。

## 3. 自测题 20 道

### A 组：Requests（每题 1 分）

1. `requests.get(url, params={"page": 1})` 和手拼 `?page=1` 的区别？
2. `data={}` 和 `json={}` 分别对应什么 Content-Type？
3. Session 对象解决了什么问题？为什么登录爬虫要用它？
4. `raise_for_status()` 是干嘛的？不调用会怎样？
5. `timeout=(3, 15)` 的两个数字分别是什么？

### B 组：解析（每题 1 分）

6. `BeautifulSoup(html, "lxml")` 为什么推荐 lxml？
7. `find_all("a", class_="x")` 里为什么是 `class_`？
8. `select_one` 找不到元素返回什么？直接 `.text` 会怎样？
9. 提取属性用 `a["href"]` 和 `a.get("href")` 哪个安全？为什么？
10. 写出"容器先行"模式的伪代码（容器 + 逐项提取）。

### C 组：清洗与数据（每题 1 分）

11. `\xa0` 是什么？清洗时怎么处理？
12. `"12,345 次"` 转成 int 的步骤？
13. 相对链接 `/news/1.html` 怎么补全成完整 URL？
14. 去重的两种手段（代码级 + 数据库级）？
15. CSV 写入为什么要 `encoding="utf-8-sig"`？

### D 组：流程与合规（每题 1 分）

16. 翻页遍历的四个终止条件是什么？
17. 遇到 429 应该怎么做？
18. 全站爬虫的标准两层架构是什么？
19. SQL 拼接字符串为什么危险？正确姿势？
20. 写出本阶段"礼貌爬虫"的三条规范（节奏/UA/robots）。
