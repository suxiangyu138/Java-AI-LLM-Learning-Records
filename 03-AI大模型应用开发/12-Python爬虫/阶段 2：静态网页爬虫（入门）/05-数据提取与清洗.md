## 1. 提取的三层模式

```text
爬虫提取的本质：HTML 文本 → 结构化数据

三层提取模式：
  ① 元素层：select/xpath 定位节点（03/04 已学）
  ② 内容层：text/属性取值（03 §5）
  ③ 清洗层：空白/编码/类型处理（本文件）

标准流程：
  容器 → 逐项 → 取文本 → 清洗 → 类型转换 → 结构化 dict
```

```python
# 提取函数的标准骨架（清洗内嵌）
def extract_article(item):
    """从一条文章项提取结构化数据"""
    # ① 定位 + 取值（判空）
    title_el = item.select_one("h2.title")
    # ② 清洗：strip + \xa0 处理
    title = title_el.get_text(strip=True).replace("\xa0", " ") if title_el else ""
    # ③ 类型转换
    views_el = item.select_one("span.views")
    views = int(views_el.text.replace(",", "")) if views_el else 0
    # ④ 结构化输出
    return {"title": title, "views": views}
```

> 🎯 核心思想：**"提取 = 定位 + 取值 + 清洗 + 转换"四步合一**——每步都有判空兜底，产出永远是可用的 Python 类型（str/int/float/datetime）。

## 2. 清洗规则：空白与特殊字符

```python
import re

# ═══ 高频清洗规则 ═══
def clean_text(raw: str) -> str:
    """统一文本清洗：空白/特殊字符/多余空格"""
    if not raw:
        return ""
    text = raw.replace("\xa0", " ")          # ① 不换行空格 → 普通空格（阶段 1 §5）
    text = text.replace("　", " ")       # ② 全角空格 → 半角
    text = text.replace("\r", "").replace("\n", " ")  # ③ 换行/回车 → 空格
    text = re.sub(r"\s+", " ", text)         # ④ 连续空白 → 单个空格
    return text.strip()                      # ⑤ 首尾去空白

# ═══ 常见脏数据形态 ═══
"标题\n 详情"            # 内嵌换行
"价格：￥1,234.50"       # 全角符号 + 千分位
"浏览量 12,345 次"       # 单位/中文夹杂
"  \xa0 空白 \xa0 "      # 不换行空格
```

| 脏数据 | 清洗 |
|--------|------|
| `\xa0`（不换行空格） | `replace("\xa0", " ")` |
| `　`（全角空格） | `replace("　", " ")` |
| 换行/回车 | `\n`/`\r` → 空格 |
| 连续空白 | `re.sub(r"\s+", " ", text)` |
| HTML 实体残留 | `html.unescape(text)`（阶段 1 §6） |

> ⚠️ **`strip()` 清不掉 `\xa0`**（它不是空白字符的 Python 视角？实际 `\xa0` 在 `str.strip()` 里**会被去掉**——但 `re.sub(r"\s+")` 不一定）——稳妥做法是显式 replace 再 strip（上面的 `clean_text` 顺序）。`\xa0` 是爬虫清洗第一坑（阶段 1 §6 已埋点）。

## 3. 类型转换：字符串到正确类型

```python
import re
from datetime import datetime

# ═══ 数字转换 ═══
def to_int(raw: str, default: int = 0) -> int:
    """'12,345 次' → 12345；失败返回默认值"""
    if not raw:
        return default
    digits = re.sub(r"[^\d.-]", "", raw)      # 只留数字/负号/小数点
    try:
        return int(float(digits))
    except ValueError:
        return default

# ═══ 日期转换 ═══
def to_date(raw: str) -> str:
    """'2026-08-08 12:30' → '2026-08-08'；多种格式兼容"""
    for fmt in ("%Y-%m-%d %H:%M:%S", "%Y-%m-%d", "%Y/%m/%d"):
        try:
            return datetime.strptime(raw.strip(), fmt).strftime("%Y-%m-%d")
        except ValueError:
            continue
    return raw.strip()      # 解析失败保留原文（别静默丢数据）

# ═══ 价格/百分比 ═══
price = to_float("￥1,234.50")       # 1234.5
pct = to_float("85.5%")              # 85.5
```

| 转换场景 | 规则 |
|---------|------|
| 数字 | 去非数字字符（保留 `-`/`.`）→ int/float |
| 日期 | 多格式尝试（strptime） |
| 布尔 | `'是'/'true'/'1'` → True |
| 枚举 | 原文映射（dict） |
| 失败策略 | **返回默认值或原文**（别抛异常中断整批） |

> 🎯 转换哲学：**"清洗不丢数据"**——解析失败的字段返回默认值/原文，而不是报错中断；错误率记入日志（`print(f"解析失败: {raw}")`），事后修规则。

## 4. 链接处理：相对路径补全

```python
from urllib.parse import urljoin, urlparse

BASE_URL = "https://example.com"

# ═══ 相对链接 → 绝对链接（必做！）═══
href = item.select_one("a").get("href", "")
full_url = urljoin(BASE_URL, href)
# 示例：
#   href="/news/1001.html"       → https://example.com/news/1001.html
#   href="news/1001.html"        → https://example.com/news/1001.html（相对当前）
#   href="https://other.com/x"   → https://other.com/x（完整 URL 原样）

# ═══ 链接过滤（只留本站/特定域）═══
def is_same_site(url: str, base: str = BASE_URL) -> bool:
    return urlparse(url).netloc == urlparse(base).netloc

# ═══ 去重规范（见 §5）═══
```

| 链接形态 | urljoin 结果 |
|---------|-------------|
| `/news/1001.html` | `https://example.com/news/1001.html` |
| `news/1001.html` | 相对当前路径拼接 |
| `#top` | 锚点（过滤掉） |
| `javascript:void(0)` | 伪链接（**过滤掉**） |
| 完整 URL | 原样 |

> ⚠️ **相对链接不补全 = 爬虫最常见的数据缺陷**——存进 CSV 的 `/news/1001.html` 无法直接访问。`urljoin` 一行解决；同时过滤 `javascript:` 伪链接与 `#` 锚点。

## 5. 去重与去噪

```python
# ═══ 内存去重（URL 集合）═══
seen = set()

def is_duplicate(url: str) -> bool:
    if url in seen:
        return True
    seen.add(url)
    return False

# 使用（翻页/列表去重）
for url in urls:
    if is_duplicate(url):
        continue          # 已抓过，跳过
    crawl(url)

# ═══ 内容去重（相同标题/摘要）═══
# 简单版：标题集合
seen_titles = set()
for item in items:
    title = item["title"]
    if title in seen_titles:
        continue
    seen_titles.add(title)

# ═══ 去噪规则 ═══
# 过滤：广告/导航/版权行（按关键词或 class）
NOISE_KEYWORDS = ["广告", "置顶", "推广", "©", "版权所有"]

def is_noise(item_text: str) -> bool:
    return any(kw in item_text for kw in NOISE_KEYWORDS)
```

| 去重层级 | 手段 | 场景 |
|---------|------|------|
| URL 去重 | URL 集合 | 列表页防重复爬取 |
| 内容去重 | 标题/指纹（hash） | 详情页内容重复 |
| 跨会话去重 | 文件/数据库持久化 | 增量爬取（阶段 3/6） |

> 🎯 去重是爬虫的"防重复劳动"机制——**不去的重，同一 URL 会被反复爬**（浪费流量 + 触发反爬）。本阶段先会用内存集合；跨重启的持久化去重在阶段 3（SQLite/DB）与阶段 6（增量策略）展开。
