## 5. 核心概念速查

| 概念 | 一句话 |
|------|--------|
| requests.get | 发送 GET 请求拿响应 |
| Session | 自动管理 Cookie 的会话对象 |
| 超时 | 每个请求必设（`timeout=10`） |
| 异常体系 | ConnectionError/Timeout/HTTPError——爬虫必须处理 |
| 重试机制 | 临时故障自动重试（指数退避） |
| 代理 | 换 IP 出口（阶段 4 重点，本阶段了解） |
| BeautifulSoup | HTML 解析库（find/select） |
| lxml | 高速解析器（bs4 后端 / XPath） |
| XPath | 路径式定位语法 |
| 提取模式 | 容器选择器 + 子元素提取 |
| 去重 | 已抓 URL 集合（防重复爬取） |
| 爬取节奏 | 请求间隔控制（礼貌） |
| CSV/JSON | 文件级数据存储 |
| robots.txt | 合规前置检查（阶段 1 已学） |
