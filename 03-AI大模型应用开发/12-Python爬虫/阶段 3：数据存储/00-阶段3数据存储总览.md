## 5. 核心概念速查

| 概念 | 一句话 |
|------|--------|
| pymysql | Python 连接 MySQL 的驱动（纯 Python） |
| 连接池 | 复用数据库连接（别每次新建） |
| 表设计 | 字段类型/长度/约束（爬虫数据的"表格"） |
| UNIQUE 约束 | 数据库级去重（url 唯一） |
| INSERT IGNORE | 重复插入静默跳过 |
| ON DUPLICATE KEY | 重复则更新（幂等 upsert） |
| 批量写入 | executemany（一次写 N 条，快 10 倍） |
| 参数化 | `?` 占位符（防注入） |
| pymongo | Python 连接 MongoDB 的驱动 |
| 文档模型 | 一个文档 = 一个 JSON（灵活嵌套） |
| 去重指纹 | 内容哈希（标题/URL/正文 hash） |
| 增量抓取 | 只抓新的（按时间/ID/状态） |
| 抓取状态 | 已抓/待抓/失败 状态管理 |
| pandas | 数据分析库（清洗/转换/导出） |
| DataFrame | pandas 的表格对象 |
