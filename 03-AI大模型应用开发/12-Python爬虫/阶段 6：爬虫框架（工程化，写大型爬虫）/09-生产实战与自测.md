## 1. 综合项目：新闻站全量抓取（端到端）

**需求**：抓取某新闻站全部栏目新闻（列表分页 + 详情页），存 MySQL，支持每日增量，反爬保护（限速 + UA 池），可水平扩展。**目标站自建或用 `https://news.ycombinator.com` 类公开站练手（本示例 URL 按实际替换）**。

### 1.1 设计决策（面试能讲清的架构）

```text
┌─ 列表页（原生下载）───────┐
│  parse_list: 详情链接+下一页 │→ yield Request(详情, meta={栏目})
└──────────────────────────┘
            │
┌─ 详情页（原生下载，个别动态页 meta playwright 开关）┐
│  parse_detail: yield ArticleItem                  │
└───────────────────────────────────────────────────┘
            │
    Item Pipeline（顺序 = 编号）
    100 ValidatePipeline   必填/格式校验
    200 CleanPipeline      清洗/标准化
    300 MysqlPipeline      UPSERT 入库（幂等）
            │
    下载中间件：UA 池(100) → 代理池(200) → 内置重试(550)
    调度：AUTOTHROTTLE + 单域并发限制
```

@dataclass
class ArticleItem:
    url: str                      # 唯一键（入库 UPSERT 依据）
    title: str

```python
# spiders/news_spider.py
import scrapy


class NewsSpider(scrapy.Spider):
    name = "news"
    allowed_domains = ["news.example.com"]
    start_urls = ["https://news.example.com/news/1"]

    custom_settings = {
        "ITEM_PIPELINES": {          # 本 Spider 独立管道（其他 Spider 不受影响）
            "news.pipelines.ValidatePipeline": 100,
            "news.pipelines.CleanPipeline": 200,
            "news.pipelines.MysqlPipeline": 300,
        },
        "CONCURRENT_REQUESTS_PER_DOMAIN": 6,
        "AUTOTHROTTLE_ENABLED": True,
    }

    def parse(self, response):
        """列表页：详情链接 + 下一页（回调链模式，02 章）"""
        for a in response.css("h2.entry-title a"):
            yield scrapy.Request(
                url=response.urljoin(a.css("::attr(href)").get()),
                callback=self.parse_detail,
                meta={"category": response.css("span.cat::text").get()},
                priority=10,                    # 详情优先于后续列表
            )
        next_page = response.css("a.next::attr(href)").get()
        if next_page:
            yield scrapy.Request(response.urljoin(next_page), callback=self.parse)

    def parse_detail(self, response):
        yield ArticleItem(
            url=response.url.split("#")[0],                     # 去 fragment 保幂等
            title=response.css("h1::text").get() or "",
            category=response.meta.get("category") or "",
            content=" ".join(response.css("div.post-content p::text").getall()),
            publish_time=response.css("time::attr(datetime)").get() or "",
        )

    async def start_requests(self):
        """增量模式：种子 URL 来自 Redis 队列（07 章），无任务时回退 start_urls"""
        for url in self.start_urls:
            yield scrapy.Request(url, callback=self.parse)
```

```python
# pipelines.py —— 三层管道
import pymysql
from scrapy.exceptions import DropItem
from scrapy.utils.item import ItemAdapter


class ValidatePipeline:
    """① 校验：必填 + 格式（03 章 §6 清单）"""
    def process_item(self, item, spider):
        adapter = ItemAdapter(item)
        if not adapter.get("url"):
            raise DropItem("url 为空")
        if not adapter.get("title"):
            raise DropItem(f"title 为空: {adapter.get('url')}")
        if not adapter.get("content"):
            raise DropItem(f"正文为空，疑似反爬兜底页: {adapter.get('url')}")
        return item


class CleanPipeline:
    """② 清洗：统一编码/去空白/标准化"""
    def process_item(self, item, spider):
        adapter = ItemAdapter(item)
        adapter["title"] = adapter["title"].replace("\xa0", " ").strip()
        adapter["content"] = " ".join(adapter["content"].split())
        adapter["category"] = adapter["category"].strip()
        return item


class MysqlPipeline:
    """③ 入库：UPSERT 幂等（04 章 §3）"""
    def open_spider(self, spider):
        self.conn = pymysql.connect(
            host=spider.settings.get("MYSQL_HOST"),
            user=spider.settings.get("MYSQL_USER"),
            password=spider.settings.get("MYSQL_PASSWORD"),
            database=spider.settings.get("MYSQL_DB"),
            charset="utf8mb4",
        )
        self.conn.autocommit(True)
        self._init_table()

    def _init_table(self):
        with self.conn.cursor() as cur:
            cur.execute(
                "CREATE TABLE IF NOT EXISTS articles ("
                "  url VARCHAR(512) PRIMARY KEY,"
                "  title VARCHAR(512) NOT NULL,"
                "  category VARCHAR(64) DEFAULT '',"
                "  content MEDIUMTEXT,"
                "  publish_time VARCHAR(64) DEFAULT '',"
                "  crawled_at DATETIME DEFAULT CURRENT_TIMESTAMP"
                ") ENGINE=InnoDB DEFAULT CHARSET=utf8mb4"
            )

    def process_item(self, item, spider):
        a = ItemAdapter(item)
        sql = (
            "INSERT INTO articles (url, title, category, content, publish_time) "
            "VALUES (%s, %s, %s, %s, %s) "
            "ON DUPLICATE KEY UPDATE "
            "title=VALUES(title), content=VALUES(content), "
            "category=VALUES(category), crawled_at=NOW()"
        )
        with self.conn.cursor() as cur:
            cur.execute(sql, (a["url"], a["title"], a["category"], a["content"], a["publish_time"]))
        return item

    def close_spider(self, spider):
        self.conn.close()
```

# middlewares.py —— 反爬中间件（05 章 §2-§3 组合）
import random


class RandomUaMiddleware:
    UA_POOL = [
        "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 "
        "(KHTML, like Gecko) Chrome/136.0.0.0 Safari/537.36",
        "Mozilla/5.0 (X11; Linux x86_64; rv:138.0) Gecko/20100101 Firefox/138.0",
    ]

    def process_request(self, request, spider):
        request.headers.setdefault(b"User-Agent", random.choice(self.UA_POOL))
        request.headers.setdefault(b"Accept-Language", "zh-CN,zh;q=0.9")

### 1.3 验收指标（本项目）

| 指标 | 通过线 |
|------|--------|
| 全量跑通 | 列表→详情→入库链路无 ERROR |
| 幂等 | 重跑一遍，`count(*)` 不变 |
| 数据质量 | content 空值 = 0，title 无首尾空白 |
| 反爬 | 无 403/429 风暴（429 占比 < 5%） |
| 增量 | 第二天再跑只新增/更新 |

> 🎯 **核心要点**：项目验收不是"跑出 JSON"，是**幂等 + 数据质量 + 反爬平稳 + 增量可续**四件事全过——这就是本阶段全部能力的收口。

## 6. 高频面试题与答题范式

**Q1：Scrapy 的架构与数据流？**
> 范式：五组件一句话职责 + 八步流（出队→下载→响应→进 Spider→解析出 Request/Item→分别回流） + 强调"yield 契约与两个队列决定终止"。

**Q2：中间件 vs Pipeline 的区别？**
> 范式：中间件是**请求/响应/异常**的横切面（改头、换代理、重试），在下载链路两侧；Pipeline 是 **Item** 的有序处理（校验清洗入库）。一个管"网络层"，一个管"数据层"。

**Q3：动态页面怎么处理？**
> 范式：接口直取优先 → 渲染兜底（scrapy-playwright 是 Download Handler，meta 按需开，PageMethod 编排动作，2026 可接 camoufox 反检测内核）；scrapy-splash 已弃用。

**Q4：如何做分布式？**
> 范式：先单机调优 → scrapy-redis 换 Scheduler/DupeFilter 两组件 + RedisSpider + PERSIST；断点续爬、布隆去重（1000 万 URL 2GB+ → 100-200MB）；停维护但稳定；强任务状态需求换 Celery/Kafka。两层幂等必答。

**Q5：反爬怎么办？**
> 范式：UA 池 + 代理池 + 随机延迟 + AutoThrottle（中间件横切面统一治理）+ 429 边界探测 + 合规边界（阶段 4 §7）；渲染指纹问题用 camoufox。

**Q6：数据一致性/增量怎么保证？**
> 范式：URL 唯一键 + UPSERT + crawled_at 时间戳；去重集保留 + 种子队列注入；调度幂等三保险。
