## 1. DeepSeek

### 1.1 概览

| 属性 | 说明 |
|------|------|
| 兼容端点 | `https://api.deepseek.com/beta` |
| 文档 | [DeepSeek API Docs](https://platform.deepseek.com/api-docs) |
| 兼容起步 | V3 模型开始支持 |
| 认证方式 | `Authorization: Bearer <key>` |

### 1.2 可用模型

| 模型名 | 说明 | Anthropic 兼容 |
|--------|------|:--------------:|
| `deepseek-chat` | DeepSeek V4 Pro / V4 | ✅ |
| `deepseek-reasoner` | DeepSeek R1（推理模型） | ✅ |

### 1.3 请求示例

```bash
curl https://api.deepseek.com/beta/v1/messages \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $DEEPSEEK_API_KEY" \
  -d '{
    "model": "deepseek-chat",
    "max_tokens": 1024,
    "messages": [
      {"role": "user", "content": "Hello"}
    ]
  }'
```

### 1.4 Python SDK 示例

```python
from anthropic import Anthropic

client = Anthropic(
    base_url="https://api.deepseek.com/beta",
    api_key="sk-xxxxxxxxxxx"
)

response = client.messages.create(
    model="deepseek-chat",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Hello!"}]
)
print(response.content[0].text)
```

### 1.5 注意事项

| 差异点 | 说明 |
|--------|------|
| `system` 参数 | DeepSeek 支持，映射为 system prompt |
| `thinking` block | `deepseek-reasoner` 支持，兼容格式 |
| 流式格式 | 基本兼容，但 `content_block_delta` 的 `thinking` 使用 `reasoning_content` |
| Token 计数 | `usage` 字段格式需注意 `completion_tokens` vs `output_tokens` |
| Base URL 路径 | 需使用 `/beta` 路径（非正式版） |

## 2. OpenAI

### 2.1 概览

OpenAI 官方不提供 Anthropic 兼容接口，但 OpenAI 的 API 格式也可以通过以下方案实现兼容：

| 方案 | 说明 |
|------|------|
| **OpenAI → Anthropic 转换代理** | one-api / lite-llm 等网关自动转换 |
| **兼容 SDK** | 部分社区 SDK 支持自动格式映射 |

### 2.2 建议方案

**使用 one-api 网关转换**：

```
用户 → Anthropic SDK → one-api (格式转换) → OpenAI API
```

配置 one-api 渠道时，选择「OpenAI」类型，返回格式选择「Anthropic Compatible」。

## 3. Google Gemini

### 3.1 概览

Google 通过 **Vertex AI** 和 **Gemini API** 提供 Anthropic 兼容格式：

| 属性 | 说明 |
|------|------|
| 兼容端点 | `https://xxx-aiplatform.googleapis.com/v1/...` |
| 认证方式 | Google OAuth / API Key |
| 支持模型 | Gemini 1.5 Pro / 2.0 Flash 等 |

### 3.2 兼容实现

Google 在 Gemini API 上新增了 Anthropic 兼容层：

```python
client = Anthropic(
    base_url="https://{region}-aiplatform.googleapis.com/v1/projects/{project}/locations/{region}/publishers/google/models/{model}:anthropic",
    api_key="..."
)
```

### 3.3 注意事项

- 需要 Google Cloud 项目配置
- 流式支持有限
- Tool Use 需要通过 Gemini 原生格式转换

**支持的模型示例**：

### 4.2 阿里云百炼 (Alibaba Cloud Bailian)

## 6. 功能支持矩阵

| 功能 | Anthropic | DeepSeek | OpenAI\* | Gemini\* | 硅基流动 |
|------|:---------:|:--------:|:--------:|:--------:|:--------:|
| Messages API | ✅ | ✅ | 🔄 | ✅ | ✅ |
| System Prompt | ✅ | ✅ | 🔄 | ✅ | ✅ |
| Stream (SSE) | ✅ | ✅ | 🔄 | 有限 | ✅ |
| Tool Use | ✅ | ✅ | 🔄 | ❌ | 有限 |
| Vision/Image | ✅ | ✅(V4+) | 🔄 | ✅ | 有限 |
| Thinking | ✅ | ✅(R1) | ❌ | ❌ | ❌ |
| Prompt Caching | ✅ | ❌ | 🔄 | ❌ | ❌ |
| 多模态输入 | ✅ | ✅(V4+) | 🔄 | ✅ | 有限 |

> \* 经网关转换后可达兼容。✅ = 原生支持，🔄 = 网关转换后支持，剩余表格同上。

> 🎯 **核心要点**：目前支持原生 Anthropic 兼容格式的服务商主要是 **DeepSeek**（/beta 端点）和 **硅基流动**（部分模型）。其他服务商（OpenAI、Gemini 等）可通过 **one-api** 等网关实现协议转换。选择兼容服务商时，核心考量是：功能覆盖度（Tool Use、Stream、Vision）、延迟、成本和稳定性。
