## 2. PDF 解析

### 2.1 策略对比

| 方法 | 适用 | 优势 | 劣势 |
|------|------|------|------|
| **PyPDF2** | 纯文本 PDF | 轻量快速 | 表格/图片丢失 |
| **pdfplumber** | 含表格的 PDF | 表格提取强 | 速度慢 |
| **Unstructured** | 复杂布局 | 版面分析强 | 依赖多 |
| **OCR (Tesseract)** | 扫描件/图片 PDF | 唯一选择 | 慢且可能出错 |

```python
# 策略 1：简单文本 PDF → PyPDF2
from langchain_community.document_loaders import PyPDFLoader
loader = PyPDFLoader("report.pdf")
pages = loader.load()

# 策略 2：含表格 PDF → pdfplumber
import pdfplumber
with pdfplumber.open("report.pdf") as pdf:
    for page in pdf.pages:
        text = page.extract_text()
        tables = page.extract_tables()

# 策略 3：复杂 PDF → Unstructured
from unstructured.partition.pdf import partition_pdf
elements = partition_pdf("complex.pdf", strategy="hi_res")
```

### 2.2 PDF 常见陷阱

```text
① 换行断裂：PDF 每行独立 → "自然语言\n处理" → 应该合并为"自然语言处理"
② 页眉页脚混入：页码、标题重复出现 → 干扰检索
③ 表格变成乱序文本 → 需要保留表格结构
④ 双栏排版 → 阅读顺序错乱
⑤ 扫描件 → 需要 OCR → 错误率高

解决方案：
  → 换行修复：检测中文/英文段落 → 合并断裂行
  → 页眉页脚：正则匹配 "第X页"、页码 → 删除
  → 表格：用 pdfplumber 单独提取
```

## 3. 多格式处理

### 3.1 HTML 清洗

```python
from bs4 import BeautifulSoup

def clean_html(html_content):
    soup = BeautifulSoup(html_content, 'html.parser')
    # 移除无用标签
    for tag in soup(['script', 'style', 'nav', 'footer', 'header']):
        tag.decompose()
    # 提取纯文本
    text = soup.get_text(separator='\n')
    # 合并多余空行
    text = '\n'.join(line.strip() for line in text.splitlines() if line.strip())
    return text
```

### 3.2 代码文件特殊处理

```python
# 对代码文件：保留完整函数/类，不做切片
def load_code_file(filepath):
```

## 4. 元数据提取

```python
def extract_metadata(filepath, content):
    """提取文档元数据 → 检索时做过滤"""
    return {
        "source": filepath,                    # 来源文件
        "file_type": filepath.split('.')[-1],  # 文件类型
        "title": extract_title(content),       # 文档标题
        "created_at": os.path.getctime(filepath),
        "chunk_index": None,  # 切片时填充

    }
```

```text
元数据的作用：
  ✅ 检索后按来源过滤（"只搜索技术文档"）
  ✅ 展示引用来源（"答案来自《员工手册》第3页"）
  ✅ 知识更新（"删除 2024 版本的文档"）
```

## 5. 文档解析最佳实践

```text
生产级文档解析 Checklist：

  □ PDF 用 pdfplumber（保留表格）+ PyPDF2（纯文本）
  □ HTML 用 BeautifulSoup 去标签 + 去导航栏/广告
  □ 代码文件单独索引（不分块，保留完整函数上下文）
  □ 图片中的文字用 OCR（Tesseract/阿里云 OCR）
  □ 保留元数据（来源文件、页码、章节标题）
  □ PDF 做换行修复（合并断裂的文本行）
  □ 页眉页脚正则清洗
```

## 核心要点回顾

- LangChain 提供 80+ 种文档加载器，一行代码加载常见格式
- PDF 解析：纯文本用 PyPDF2，含表格用 pdfplumber，复杂用 Unstructured
- HTML：BeautifulSoup 去标签 + 去导航栏广告
- 元数据是检索后过滤和来源追溯的关键
- PDF 换行修复和页眉页脚清洗是生产必做
