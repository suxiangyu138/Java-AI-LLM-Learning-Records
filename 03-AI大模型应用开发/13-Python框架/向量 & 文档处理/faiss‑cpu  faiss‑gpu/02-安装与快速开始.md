## 1. 安装与验证

```bash
pip install faiss-cpu==1.14.3    # 2026-08 基线，CPU 官方轮子
```

GPU 场景走 conda（`conda install faiss-gpu -c pytorch`）或社区轮子（faiss-gpu-cu11/cu12）——**PyPI 的 faiss-gpu 已停更，别 pip 它**（09 篇详讲）。Linux/macOS/Windows 均有官方 CPU 轮子，macOS 上 1.14 起 Apple Silicon 默认启用 Metal GPU 后端（同一份代码自动加速）；Windows 轮子由官方 faiss-cpu 项目提供（历史版本曾滞后，锁 1.14.x 较稳）。

```python
import faiss, numpy as np
print(faiss.__version__)           # 1.14.3
index = faiss.IndexFlatL2(384)     # 能建索引即安装成功
```

**锁版本的理由**：FAISS 迭代快（GitHub 已出 1.15.0），且索引文件格式与版本相关——"锁住版本才锁住索引兼容性"。

**装完立刻验证**：`faiss.IndexFlatL2(384)` 能建、`faiss.write_index/read_index` 能往返（见第 4 节示例）、`faiss.normalize_L2` 可调用——三个探针都过，环境就绪——"**安装验证三件套：建索引、落盘、归一化**"。

## 2. float32 铁律

FAISS 只吃 **float32 的 numpy 数组**——这是新手第一大坑：

```python
xq = xq.astype('float32')   # 任何来源的向量，入库前统一转
```

**为什么**：FAISS 底层是 C++ SIMD 计算，float32 是硬编码的精度单位；float64 传入**会报错或静默截断**（不同接口行为不一）。**规则**：`dtype != 'float32'` 一律 `astype('float32')`；连续内存（`np.ascontiguousarray`）在异常场景也顺手保证。"**float32 是 FAISS 的第一条铁律：向量进库之前，先过 astype**"。

## 3. 第一个索引：IndexFlatL2

```python
import faiss, numpy as np

d = 384                                    # 向量维度（嵌入模型的输出维度）
index = faiss.IndexFlatL2(d)               # ① 建索引：指定维度

vectors = np.random.rand(10000, d).astype('float32')   # ② 10K 条向量
index.add(vectors)                          # ③ 入库
print(index.ntotal)                         # 10000，总数检查

query = np.random.rand(1, d).astype('float32')  # ④ 查询（也可多行批量）
D, I = index.search(query, k=5)             # ⑤ 检索 top-5
print(I)    # [[4312 7788 9034 2109 6677]]   命中的行号（0 起）
print(D)    # [[5.12 5.31 ...]]             距离（L2 越小越相似）
```

**返回结构是 FAISS 的标志性设计**：`search` 一次返回两个矩阵——**`D`（距离矩阵，形状 (Q, k)）与 `I`（命中的向量行号，形状 (Q, k)）**；`Q` 是查询条数，多行查询一起算（批量检索免费获得）。**注意**：`I` 里的"4312"是**添加顺序的行号**，不是业务 ID——业务 ID 要 IndexIDMap 包装（08 篇）。**距离语义**：IndexFlatL2 返回的是**平方 L2 距离**，越小越相似——"0 代表完全相同的向量"。

**IndexFlatIP 只有一行之差**：`faiss.IndexFlatIP(d)` 换内积度量——**IP 是"越大越相似"**（归一化后 = 余弦，04 篇详讲）——"**选索引类 = 选'相似'的定义，L2 看小、IP 看大，两者方向相反**"。**内存直觉**：IndexFlatL2 把全部向量原样放进内存——10 万条 384 维 ≈ 1.5GB（1536B/条）——"Flat 的代价是内存，收益是精确与简单"（09 篇内存账本）。

## 4. 完整示例

```python
import faiss, numpy as np

# 模拟"文本 → 向量"（真实场景嵌入模型产出的 384 维向量）
d = 384
vectors = np.random.rand(100000, d).astype('float32')   # 10 万条
queries = np.random.rand(10, d).astype('float32')       # 10 个查询

# 精确检索：Flat 全量扫描（小库最快，10 万条毫秒级）
flat = faiss.IndexFlatL2(d)
flat.add(vectors)
D, I = flat.search(queries, k=10)
print(f"Flat: {D.shape}, {I.shape}")     # (10, 10), (10, 10)

# 保存与加载（08 篇详讲）
faiss.write_index(flat, "flat.index")
loaded = faiss.read_index("flat.index")
print(loaded.ntotal)                     # 100000，加载即用
```

**这个例子的意义**：FAISS 的最小闭环 = **建索引 → add → search → write/read**，全部 5 行核心 API；10 万条 × 384 维的精确检索在普通笔记本上毫秒级——**"Flat 在小库上的表现常被低估：10 万条以内根本不需要近似索引"**（03 篇选型表会讲这条）。

**接入真实嵌入**：上面用的 `np.random.rand` 只是占位——真实场景把嵌入模型输出（如 OpenAI text-embedding-3-small 的 1536 维、bge-m3 的 1024 维、all-MiniLM 的 384 维）直接喂给 `add` 即可，**只要 float32 且维度与索引一致**——"FAISS 不管向量从哪来，只管存与查——嵌入环节与 chromadb 04 篇同源"。

## 5. 快速调试三步

**第一步：看总量**——`index.ntotal` 确认入库条数；add 后立刻检查，"数量不对先查 add 批次"。

**第二步：还原单条**——`index.reconstruct(i)` 取出第 i 条向量（IndexIDMap2 上支持按业务 ID）——"库里存的到底是不是你要的向量，reconstruct 说话"（08 篇）。

**第三步：检索冒烟**——`search` 返回的 `I` 里**最相似的一定是查询向量本身**（如果查询向量在库里）：`D[0][0]` 应接近 0、`I[0][0]` 指向它自己——"用'自查'验证索引没建错，这是 FAISS 最便宜的冒烟测试"。

**三分钟排障流程**：报错先看 dtype/维度（前两条铁律），结果不对先查 `ntotal` 与自查冒烟，再疑归一化与度量——**"按'数据对没对 → 索引建没建对 → 语义对不对'的顺序排查，九成问题在三分钟内定位"**——这套流程在后续所有索引类型（IVF/HNSW/PQ）上通用。**记住：快速开始的终点不是"跑通"，而是"跑通 + 会排查"——两个能力一起到手，后面每篇的实操都站在同一套流程上。**

## 6. 常见坑

1. **float64 直接喂**——报错或静默截断；`astype('float32')` 是进库前必过的一关。
2. **维度不一致**——IndexFlatL2(384) 传 768 维向量直接报错；维度 = 嵌入模型输出维度（04 篇与 chromadb 同源）。
3. **`search` 的 k 大于库总量**——返回的矩阵会填 -1（无此邻居），先 `min(k, ntotal)`。
4. **以为 I 是业务 ID**——I 是行号；业务 ID 用 IndexIDMap（08 篇）。
5. **L2 距离当欧氏距离用**——返回的是**平方距离**；要欧氏距离开根号。
6. **小库上近似索引反而慢**——10 万条以内 Flat 就是最优解，别急着上 IVF（03 篇）。
7. **查询向量没归一化就期望余弦语义**——cosine 场景统一先 `faiss.normalize_L2`（04 篇）。
8. **把 D 值当"相似度百分比"**——L2 是平方距离、数值与维度强相关（1536 维的 0.5 和 384 维的 0.5 完全不等价）；**同库同模型内部比大小，跨库跨维度别比数值**。
9. **忘了 `import numpy`**——FAISS API 深度绑定 numpy 数组，`np` 缺失是新手第一报错；导入 `faiss, numpy as np` 是标配开头。
