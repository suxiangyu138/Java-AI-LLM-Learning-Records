## 3. 与主体系的分工

**本体系与 HuggingFace 体系（`../../../02-大模型基础与Prompt工程/HuggingFace/`）的分工**：HuggingFace 体系是全链路（拿模型-加载-微调-部署），本体系是**bitsandbytes 单库的"了解即可"**——**"HuggingFace 是全景地图，本体系是'量化'这一站的路牌"**——深度定位：**知道能干什么、怎么用、什么时候用——不深挖源码**（目录名即定位）。

**量化体系的分工**：量化是 AI 模型工程的大主题（`../../模型推理与部署/` 体系有量化章节），本体系聚焦 **bitsandbytes 这一库**——**"本体系是'量化专题'的一个库的说明书——其他方案（GPTQ/AWQ/GGUF）在 09 篇对比"**。

**2026-08 基线**：bitsandbytes **0.49.2**（2026-02-16 发布）；要求 Python 3.10+ / PyTorch 2.4+；QLoRA 4bit 支持 Linux/Windows CUDA、ROCm、XPU、CPU——**"版本意识：量化库版本敏感——锁版本是第一纪律"**。

**"了解即可"的深度边界**（本体系的写作原则）：**① 能干什么**——省多少显存、解决什么问题（数字讲清）；**② 怎么用**——配置怎么写、流程怎么走（代码给全）；**③ 何时用**——什么场景选它、什么场景换人（选型讲透）；**不深挖**——CUDA 内核实现、码本构造细节、梯度流数学——**"知道'存算分离'的直觉即可，不读论文"**——这是"了解即可"与"强烈推荐"（`../强烈推荐（做项目必用，简历加分）/`）体系的深度分界。

## 5. 核心概念速查

| 概念 | 一句话 | 对应篇 |
|------|--------|:---:|
| 量化 | 用更少的位存权重（FP16→INT4 = 省 4 倍显存） | 02 |
| 显存账本 | 模型显存 ≈ 参数 × 每参字节 | 02 |
| INT8 | 8bit 量化（省一半显存） | 03 |
| NF4 | 4bit 量化格式（正态分布优化——QLoRA 标配） | 04 |
| QLoRA | 4bit 底座 + LoRA 适配器（单卡微调大模型） | 05 |
| BitsAndBytesConfig | 量化配置对象（新版唯一入口） | 06 |
| 计算精度 | 反量化后的运算精度（bf16 推荐） | 07 |
| 运行时量化 | 加载时动态量化（权重文件不变） | 09 |

## 6. 常见误区

**误区一：量化 = 精度崩**——"4bit 一定变笨"——**正确：NF4 精度损失约 1.7%（PPL）——感知上接近全精度**（09 篇实测——"量化的精度损失远小于你的想象"）。

**误区二：量化文件变小**——"量化后模型文件变小了？"——**正确：bitsandbytes 是运行时量化（文件不变）；变小的是 GPTQ/AWQ/GGUF（预量化）**（09 篇——"训练用 NF4、推理用 GPTQ/AWQ/GGUF"）。

**误区三：量化只能推理**——"量化 = 推理省显存"——**正确：bitsandbytes 的独门绝技是'量化后还能训练'（QLoRA）**（05 篇——"唯一支持梯度更新的量化方案"）。

**误区四：4bit 加载 = 万事大吉**——"load_in_4bit=True 就完事"——**正确：计算精度（bf16）、双重量化、device_map 都有讲究**（06/07 篇——"配置四件套是标准姿势"）。

**误区五：所有量化都一样**——"量化选一个就行"——**正确：bitsandbytes vs GPTQ vs AWQ vs GGUF 各有主场**（09 篇决策树——"选型由部署栈决定，没有万能方案"）。

## 7. 三天学习计划示例

| 天 | 学习内容 | 动手任务 | 验收 |
|:---:|---------|---------|------|
| 第 1 天 | 01 是什么 + 02 概念 | 显存账本计算（7B/13B 模型各需多少） | 账本会算 |
| 第 2 天 | 03 INT8 + 04 NF4 + 06 集成 | 8bit 和 4bit 各加载一次模型（对比显存） | 两次加载成功 |
| 第 3 天 | 05 QLoRA + 07 权衡 + 09 选型 | 跑通一次 QLoRA 微调（小模型）+ 选型表 | 微调跑通 |

**计划纪律**：每天 2-3 小时；**动手优先**（bitsandbytes 是"跑出来"的知识）；卡住查 08 篇报错速查——"产出物齐 = 毕业"。

**学习环境准备**（动手前先备齐）："**① 显卡**——加载实验 4GB 显存起步、QLoRA 微调 8GB 起步（无 GPU 用 CPU 跑加载实验——慢但能验证配置）；**② 环境**——Python 3.10+ / PyTorch 2.4+ / bitsandbytes 最新版（venv 隔离——08 篇环境纪律）；**③ 模型**——从 1.5B 小模型起步（下载快、显存低——Qwen2.5-1.5B 是 2026 年练习首选）——**'环境三件套（显卡/venv/小模型）备齐，三天计划才跑得动'"**——**预判常见卡点**："加载报错先看版本（08 篇）；显存不够换更小模型（1.5B → 0.5B）；配置没生效看显存数字——**'第一天把环境三件套备齐 + 跑通一次加载，本体系的 80% 就算过了'"**。
