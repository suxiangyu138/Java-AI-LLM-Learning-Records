## 1. 核心心智：缩进即结构

YAML 的第一原则：**用缩进（空格）表达嵌套层级，不用括号**。两个硬规则：**层级用空格缩进，禁止 Tab**（Tab 直接报错）；**同一层级的缩进必须一致**（2 空格是社区惯例，4 空格合法但不统一——**全项目统一缩进风格**是第一工程规范）。

```yaml
server:
  host: 127.0.0.1      # server 下的一层
  port: 8080           # 与 host 同级
logging:               # 回到顶层
  level: INFO
```

**与 JSON 的映射心智**：`键: 值`（冒号后必须有空格）对应 JSON 的键值对；缩进层级对应 JSON 的嵌套大括号——**"YAML 把括号换成了缩进，把逗号换成了换行"**。读 YAML 的思维：**先看缩进找层级，再看冒号找键值，再看横杠找列表项**。

## 2. 映射与序列

**映射（字典）**：`键: 值` 形式，值可以是任意类型：

```yaml
database:
  host: localhost
  port: 5432
  options:
    pool_size: 10
```

**序列（列表）**：`- ` 横杠开头，每项一行：

```yaml
models:
  - gpt-4o
  - claude-sonnet
  - deepseek-v4
```

**组合姿势**——列表里嵌映射（最常见形态，配置的骨架）：

```yaml
servers:
  - name: auth
    port: 9001
  - name: gateway
    port: 9002
```

**flow 风格**：`[1, 2, 3]` 与 `{a: 1, b: 2}` 是 JSON 风格的紧凑写法，等价于 block 风格——**手写配置用 block（可读），程序生成用 flow（紧凑）**（06 篇 dump 相关）。

## 3. 标量类型与引号

YAML 自动推断标量类型（与 JSON 不同——**YAML 不要求引号**）：

```yaml
age: 30              # 整数
price: 19.99         # 浮点
enabled: true        # 布尔（true/false/yes/no/on/off 都认）
nothing: null        # 空（null/~）
title: Milvus 入门    # 字符串（无引号）
path: "C:\temp"      # 双引号：转义生效
literal: 'It''s ok'  # 单引号：不转义，'' 表示单引号
```

**引号何时必须**：字符串**以特殊字符开头**（`- `、`*`、`&`、`!`、`{`、`[`、`:` 后跟空格、`#`）、**含冒号空格**（`key: value` 会被当映射）、**数字要当字符串**（`"007"`）、**含 `#` 注释符**。**踩坑高发**：时间字符串 `12:30` 裸写会被解析成秒数——**"看起来是字符串的结果变成数字"是 YAML 最经典的意外**，解决：加引号。**布尔陷阱**：`yes/no/on/off` 在 YAML 1.1 是布尔（PyYAML 遵循 1.1）——**配置里写 `flag: no` 得到的是 False 不是字符串**；新版 YAML 1.2 只认 true/false，但 PyYAML 默认 1.1——**知道这个差异能救你于"配置怎么变布尔了"的困惑**。

## 4. 多行字符串

大段文本（提示词、SQL、描述）是 YAML 的高频场景，三种写法：

```yaml
summary: >
  折叠风格：换行被折叠成空格，
  第二行拼接进同一段。适合长段落。

code: |
  块风格：保留换行，
  多行代码原样输出。适合缩进敏感的文本。

trailing: |-
  块风格加横杠：去掉末尾换行。
  （|+ 则保留所有末尾空行）
```

**`>` 折叠（段落）与 `|` 保留（代码）**是核心区分：**提示词/描述用 `>`，代码/日志模板用 `|`**。嵌套缩进的文本块里，**内容缩进必须比键深**（多缩进至少一级），否则报错。

## 5. 锚点别名与合并

**锚点（`&名`）定义复用片段，别名（`*名`）引用它**——配置去重的核心武器：

```yaml
defaults: &db_defaults
  host: localhost
  port: 5432
  pool_size: 10

dev:
  <<: *db_defaults      # 合并键：继承 defaults 全部字段
  pool_size: 20         # 覆盖其中一个

prod:
  <<: *db_defaults
  host: prod-db.internal   # 覆盖 host
```

**`<<:` 合并键**把锚点的映射并入当前映射（可覆盖）——**"默认值 + 覆盖"的配置模式在 YAML 里是原生语法**。注意：safe_load 支持锚点/合并（纯数据结构操作，无安全问题）；**合并只作用于映射键，列表不能合并**（要合并列表用 `- *item` 展开）。

## 6. 多文档与标签

**一个综合示例**（把前五节的知识串起来——**能完整读懂这段，语法就毕业了**）：

```yaml
# 综合示例：服务部署配置
defaults: &app_defaults            # 锚点：公共片段
  replicas: 2
  image: registry.example.com/app:latest

services:                          # 映射 → 序列 → 映射 嵌套
  - name: api
    <<: *app_defaults              # 合并键：继承 + 覆盖
    replicas: 3
    env:
      APP_ENV: !env APP_ENV        # 自定义标签（05 篇讲安全姿势）
    health_check: |
      curl -f http://localhost:8080/health   # 块字符串：保留换行
  - name: worker
    <<: *app_defaults
    replicas: 1

deploy_note: >                     # 折叠字符串：长段落
  这是折叠风格的说明文字，换行会被折叠成空格，
  适合写人类可读的段落说明。
```

**多文档流**：`---` 分隔多个 YAML 文档（`...` 可选收尾），`safe_load_all` 逐个读取：

```yaml
---                     # 文档一：模型配置
model: gpt-4o
temperature: 0.7
---                     # 文档二：工具配置
tools:
  - search
  - calculator
```

**标签（tag）**：`!!类型` 显式标注类型——**安全的分水岭就在这**：`!!str`、`!!int`、`!!map`、`!!seq` 是基础类型标签（safe_load 支持）；**`!!python/object`、`!!python/name`、`!!python/object/apply` 是 Python 对象构造标签（safe_load 拒绝，unsafe 才执行）**——**"看见 `!!python/` 前缀，脑子里就该响起 RCE 警报"**（04 篇详讲）。自定义应用标签（如 `!config`）配合自定义 Loader 使用（05 篇）。

## 7. 常见语法坑

**坑一：Tab 缩进**——直接 `ScannerError`；**编辑器设置"Tab 转空格"是 YAML 开发第一配置**。

**坑二：冒号后没空格**——`host:localhost` 解析成字符串 `"host:localhost"`；**冒号后必须有空格**（URL 例外——`http://` 里的冒号后不是空格，安全）。

**坑三：`12:30` 时间字符串变数字**——被当性别解析；**含冒号的值加引号**。

**坑四：yes/no 变布尔**——YAML 1.1 布尔陷阱；**需要字符串时加引号**（`"no"`）。

**坑五：多行文本缩进错位**——块文本内容必须比键缩进更深；**用 linter（yamllint）在 CI 里兜底**（09 篇）。

**坑六：锚点定义在子节点**——锚点必须定义在要被引用的节点位置（`&` 跟着值走），别写在键名上。

**语法速查表**（写文件前扫一眼，90% 的语法问题都在表里）：

| 语法元素 | 写法 | 常见错误 |
|---------|------|---------|
| 缩进层级 | 2 空格（统一） | Tab、层级不一致 |
| 键值 | `key: value` | 冒号后没空格 |
| 列表项 | `- item` | 横杠后没空格 |
| 字符串 | 裸写或引号 | 特殊字符开头忘引号 |
| 时间值 | `"12:30"` | 裸写变数字 |
| 布尔 | `true/false` | `yes/no` 1.1 陷阱 |
| 注释 | `# 注释` | `#` 前没空格被当字符串 |
| 多行段落 | `> ` | 内容缩进不足 |
| 多行代码 | `\| ` | 与 `>` 混淆 |
| 锚点引用 | `&a` / `*a` | 锚点没定义就引用 |
| 合并键 | `<<: *a` | 合并列表（不支持） |
| 文档分隔 | `---` | 与注释混淆 |

**"写之前查表，报错后对表"**——语法问题 90% 是表里的某一行。

> 🎯 **核心要点**：YAML 语法 = **缩进即结构（禁 Tab）+ 映射/序列/标量（引号防陷阱）+ 多行三写法（段落用 > 代码用 \|）+ 锚点合并（默认值覆盖）+ 多文档与标签（!!python 是红线）**——"读不懂语法就调不了 bug"，这是 PyYAML 一切 API 的地基。
