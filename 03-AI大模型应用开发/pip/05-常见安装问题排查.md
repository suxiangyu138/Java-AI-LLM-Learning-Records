## 1. 编译类错误

### 错误速查

| 错误信息 | 原因 | 解决 |
|---------|------|------|
| `error: command 'gcc' failed` | 缺少 C 编译器 | `apt install build-essential` |
| `fatal error: Python.h: No such file` | 缺少 Python 开发头文件 | `apt install python3-dev` |
| `Could not find a version that satisfies` | 版本不存在或平台不兼容 | 检查 Python 版本 + 平台 + 架构 |
| `No matching distribution found` | 同上，或包名拼错 | 去 pypi.org 确认包名 |
| `legacy-install-failure` | sdist 构建失败 | 尝试 `--only-binary :all:` |

### 通用编译修复

```bash
# Ubuntu/Debian 完整编译环境
sudo apt install build-essential python3-dev

# 安装特定库的编译依赖
sudo apt install libssl-dev libffi-dev     # cryptography
sudo apt install libxml2-dev libxslt-dev   # lxml
sudo apt install libjpeg-dev zlib1g-dev    # Pillow

# macOS
xcode-select --install                      # 安装命令行工具
```

## 2. CUDA / GPU 相关

### 最常见 CUDA 错误

```text
错误1: torch.cuda.is_available() → False
  原因：装的 CPU 版 PyTorch，或者 CUDA 版本不匹配
  解决：去 pytorch.org 选正确的 CUDA 版本

错误2: CUDA driver version is insufficient
  原因：nvidia-smi 显示驱动太旧
  解决：升级 NVIDIA 驱动（>= 525 for CUDA 12）

错误3: libcudnn.so.8 not found
  原因：cuDNN 未安装或版本不对
  解决：conda install cudnn
```

### CUDA 版本矩阵

```text
PyTorch 2.4.0  ← 需要 CUDA 12.1 或 12.4
PyTorch 2.3.0  ← 需要 CUDA 11.8 或 12.1
PyTorch 2.0.0  ← 需要 CUDA 11.7 或 11.8

查看当前 CUDA:
  nvidia-smi               # 右上角 CUDA Version
  nvcc --version           # CUDA toolkit 版本
  python -c "import torch; print(torch.version.cuda)"

安装正确的 PyTorch:
  # 必须从 pytorch.org 获取对应 CUDA 版本的安装命令
  pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
```

## 3. 网络与权限

```bash
# 1. 超时/网络慢
pip install --default-timeout=300 <pkg>
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple <pkg>  # 国内镜像

# 2. SSL 证书错误
pip install --trusted-host pypi.org --trusted-host files.pythonhosted.org <pkg>

# 3. 权限错误
# Permission denied: '/usr/lib/python3.x/...'
pip install --user <pkg>              # 安装到用户目录（推荐）
# 永远不要用 sudo pip install！

# 4. 磁盘空间不足
pip cache purge                       # 先清缓存
TMPDIR=/path/to/large/disk pip install <pkg>

# 5. pip 版本太旧
pip install --upgrade pip
```

## 4. 排查工具与方法论

```bash
# 1. 详细信息
pip install --verbose <pkg>
# 看哪一步失败了：解析？下载？编译？安装？

# 2. 预检查
pip install --dry-run <pkg>
# 模拟安装，不实际执行

# 3. 分步安装
pip download <pkg> -d tmp/            # 只下载
pip install --no-deps <pkg>           # 跳过依赖
pip install <pkg>                     # 正常安装

# 4. 环境对比
pip freeze > env.txt                  # 导出成功环境
# 对比两个环境的差异

# 5. 完整诊断脚本
cat > diagnose.sh << 'EOF'
echo "=== Python ==="
python --version
echo "=== pip ==="
pip --version
echo "=== OS ==="
uname -a
echo "=== GPU ==="
nvidia-smi 2>/dev/null || echo "No GPU"
echo "=== PyTorch CUDA ==="
python -c "import torch; print(f'CUDA available: {torch.cuda.is_available()}')" 2>/dev/null || echo "torch not installed"
EOF
```

## 核心要点回顾

- 编译错误 → `build-essential` + `python3-dev`，优先找 wheel
- CUDA 版本不匹配 → `nvidia-smi` 看驱动 → pytorch.org 选对应版本
- 国内速度慢 → 清华/阿里云镜像
- 权限问题 → `--user`，永远不要 `sudo pip`
- 排查套路：`--verbose` → 分步执行 → 环境对比
