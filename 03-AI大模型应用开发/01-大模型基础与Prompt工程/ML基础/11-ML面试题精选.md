## 1. 概念理解题

### Q1: 偏差和方差的区别？怎么判断模型是高偏差还是高方差？

```text
偏差 Bias：模型预测期望与真实值的差距 → 欠拟合 → 模型太简单
方差 Variance：模型对训练数据扰动的敏感度 → 过拟合 → 模型太复杂

判断方法：
  高偏差（欠拟合）：Train Error 高 + Val Error 高 + 两者接近
  高方差（过拟合）：Train Error 低 + Val Error 高 + 两者差距大

解决：
  高偏差 → 加复杂度（更多层/特征）、减正则化
  高方差 → 加数据、加正则化（L1/L2/Dropout）、减复杂度、Early Stopping
```

### Q2: L1 和 L2 正则化的区别？

```text
L1 (Lasso)：
  Loss += λ Σ|w|  → 产生稀疏解（大量权重=0）
  → 自动特征选择
  → 不可导（w=0 处）

L2 (Ridge / Weight Decay)：
  Loss += λ Σ w² → 权重趋近 0 但不为 0
  → 所有特征保留，权重缩小
  → 处处可导
  → LLM 标配！

选哪个？
  → 需要自动特征选择 → L1
  → 防止过拟合、保持所有特征 → L2（绝大多数场景）
```

### Q3: 准确率 Accuracy 有什么陷阱？

```text
类别不平衡时，高准确率 ≠ 好模型

例：100 样本中 95% 是正类
  模型全部预测正类 → 准确率 95%
  → 但对负类 Recall = 0

正确做法：
  ✅ 类别不均衡 → 看 Precision/Recall/F1/AUC
  ✅ 关注少数类的指标（负类的 Recall）
  ✅ 用混淆矩阵全面分析
```

### Q4: AUC 的含义是什么？为什么比 Accuracy 好？

```text
AUC = 随机抽一个正样本和一个负样本，模型给正样本打分高于负样本的概率

  AUC=0.5 → 和随机猜一样
  AUC=0.8 → 不错
  AUC=0.95 → 优秀

为什么比 Accuracy 好？
  ✅ 对类别不平衡不敏感
  ✅ 不依赖具体阈值选择
  ✅ 衡量的是模型的"排序能力"
```

## 2. 算法对比题

### Q5: Bagging 和 Boosting 的区别？

| 维度 | Bagging | Boosting |
|------|---------|----------|
| **训练方式** | 并行（各树独立） | 串行（后一棵修正前一棵） |
| **降低什么** | **方差** | **偏差** |
| **代表** | Random Forest | XGBoost、AdaBoost |
| **适用** | 高方差（过拟合） | 高偏差（欠拟合） |
| **鲁棒性** | 对噪声不敏感 | 对噪声敏感（会学噪声） |

### Q6: XGBoost 为什么比 GBDT 好？

```text
GBDT 的改进：
  ✅ 二阶泰勒展开（GBDT 只用一阶）→ 梯度信息更丰富
  ✅ 显式正则化（控制树复杂度）→ 防过拟合
  ✅ 列采样（类似随机森林）→ 降方差
  ✅ 并行计算（分裂点计算并行）→ 更快
  ✅ 缺失值自动处理
  ✅ 叶子节点生长策略优化
```

### Q7: SVM 的核函数是做什么的？

```text
核函数 = 将数据从低维空间映射到高维空间，在高维中线性可分

  二维中 XOR 不可分 → 核映射到三维 → 在三维中截断面分开

常用核：
  RBF (高斯核)：最常用、通用、映射到无穷维
  线性核：高维稀疏特征（如文本 TF-IDF）
  多项式核：已知多项式关系时
```

## 3. 场景应用题

### Q8: 模型线上效果远差于线下，可能原因？

```text
① 训练-线上数据分布不一致（Data Drift）
   → 例：训练用去年数据，线上是今年的

② 特征穿越（Feature Leakage）
   → 训练用了"未来信息"（如用"是否还款"预测"是否逾期"）

③ 过拟合
   → Train 集上完美，测试集还行，线上差

④ 线上线下特征处理不一致
   → 标准化参数不同、缺失值处理不同

⑤ 数据泄露
   → 测试集/验证集信息泄露到了训练过程
```

### Q9: 样本不均衡怎么处理？

```text
数据层面：
  ① 过采样（SMOTE）：合成少数类样本
  ② 欠采样：减少多数类样本
  ③ 数据增强：文本回译、图像变换

算法层面：
  ④ 类别权重：class_weight='balanced'
  ⑤ 代价敏感学习：不同类别 misclassification 代价不同
  ⑥ Focal Loss：降低易分类样本的权重 → 聚焦难样本

评估层面：
  ⑦ 不用 Accuracy → 用 F1/AUC/PR-AUC
```

## 4. 手撕代码题

### Q10: 手写交叉熵损失

```python
import numpy as np

def cross_entropy_loss(y_true, y_pred):
    """
    y_true: (N,) 真实类别索引
    y_pred: (N, C) 预测概率（softmax 后）
    """
    N = len(y_true)
    # 取正确类别的预测概率
    correct_probs = y_pred[np.arange(N), y_true]
    # 加小量防 log(0)
    loss = -np.mean(np.log(correct_probs + 1e-8))
    return loss
```

### Q11: 手写 K-Means 聚类

```python
import numpy as np

def kmeans(X, k, max_iters=100):
    # 随机初始化中心点
    centroids = X[np.random.choice(len(X), k, replace=False)]
    
    for _ in range(max_iters):
        # ① 分配每个点到最近的中心
        distances = np.sqrt(((X[:, None] - centroids) ** 2).sum(axis=2))
        labels = np.argmin(distances, axis=1)
        
        # ② 更新中心点
        new_centroids = np.array([
            X[labels == i].mean(axis=0) for i in range(k)
        ])
        
        # ③ 检查收敛
        if np.allclose(centroids, new_centroids):
            break
        centroids = new_centroids
    
    return labels, centroids
```

### Q12: 手写 Softmax

```python
def softmax(x, axis=-1):
    """数值稳定的 Softmax"""
    x_max = np.max(x, axis=axis, keepdims=True)
    exp_x = np.exp(x - x_max)  # 减去最大值防溢出
    return exp_x / exp_x.sum(axis=axis, keepdims=True)
```

## 5. 深度学习基础题

### Q13: 梯度消失和梯度爆炸的原因及解决方案？

```text
原因：
  深层网络反向传播时，梯度通过链式法则逐层连乘
  梯度 < 1 → 连续乘 → 指数衰减 → 梯度消失
  梯度 > 1 → 连续乘 → 指数增长 → 梯度爆炸

解决方案：
  激活函数：ReLU/GELU（替代 Sigmoid/Tanh）
  归一化：BatchNorm/LayerNorm（稳定每层输出范围）
  残差连接：梯度可以跳过层直通（Transformer 标配）
  梯度裁剪：限制梯度最大值
  权重初始化：Xavier/He 初始化控制初始方差
```

### Q14: Dropout 在训练和推理时的区别？

```text
训练时：每个神经元以概率 p 被随机"关闭"（输出=0）
  实际训练的是不同的"子网络"

推理时：所有神经元都激活
  但输出要乘以 (1-p)（补偿训练时的丢弃）
  → 或除以 (1-p) 在训练时做（Inverted Dropout，PyTorch 默认）

本质：相当于训练了大量子网络的集成，推理时近似求平均
```

### Q15: BatchNorm 和 LayerNorm 的区别？为什么 Transformer 用 LayerNorm？

```text
BatchNorm：对 batch 维度归一化（同一特征，不同样本）
  → 依赖 batch_size → batch 小 → 统计不稳定
  → NLP 序列长度不同，padding 破坏了统计
  → 训练/推理行为不一致

LayerNorm：对 feature 维度归一化（同一样本，不同特征）
  → 不依赖 batch_size → batch=1 也不影响
  → 序列长度变化不影响
  → 训练/推理行为一致
  → ✅ Transformer/LLM 标配！
```

## 核心要点回顾

- 偏差=欠拟合、方差=过拟合 → 学习曲线判断
- L1 产生稀疏、L2 缩小权重 → LLM 用 L2 (Weight Decay)
- 样本不均衡 → F1/AUC + class_weight + SMOTE
- 梯度消失/爆炸 → GELU + LayerNorm + 残差连接
- LayerNorm vs BatchNorm = NLP 必须用 LayerNorm
