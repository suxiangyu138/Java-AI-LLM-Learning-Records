## 1. 决策树

### 1.1 核心原理

```text
决策树 = 一系列 if-else 规则组成的树状结构

示例：判断是否适合打网球

        天气？
       /     \
     晴      雨
     /        \
  湿度？      风？
  /   \      /  \
 高   低    强   弱
 →否  →是   →否  →是

每一步选择最优分裂特征，使子节点尽可能"纯"
```

### 1.2 分裂标准

| 标准 | 公式直觉 | 特点 |
|------|----------|------|
| **信息增益 (ID3)** | 分裂后熵减少越多越好 | 偏向多值特征 |
| **增益率 (C4.5)** | 信息增益 / 特征固有信息 | 修正 ID3 的偏向 |
| **Gini (CART)** | $1 - \sum p_k^2$ | 计算快，分类回归通用 |

```text
Gini 不纯度：
  → 节点全是同一类 → Gini = 0（最纯）
  → 节点各类均匀 → Gini ≈ 0.5（最不纯）
  
  分裂目标：选择使子节点 Gini 加权和最小的特征
```

### 1.3 决策树的优缺点

| 优势 | 劣势 |
|------|------|
| 可解释性强（可视化规则） | 容易过拟合（树太深） |
| 无需特征归一化 | 不稳定（数据小变化→树大变） |
| 处理缺失值 | 对线性关系拟合差 |
| 天然支持多分类 | 预测精度不如集成方法 |

## 2. 随机森林

### 2.1 Bagging + 随机特征

```text
随机森林 = 多棵决策树的"投票"

两步随机化：
  ① 数据随机：每棵树用 Bootstrap 采样（有放回抽样 ~63% 数据）
  ② 特征随机：每次分裂只考虑随机子集特征（如 √n 个）

为什么有效？
  → 单棵决策树方差大（不稳定）
  → 多棵不同树 → 各自过拟合方向不同 → 平均后消除 → 方差降低
```

```python
from sklearn.ensemble import RandomForestClassifier

# 随机森林 — sklearn 三行代码
rf = RandomForestClassifier(
    n_estimators=100,      # 100 棵树
    max_depth=10,           # 限制深度防过拟合
    max_features='sqrt',   # 每次分裂考虑 √n 个特征
    random_state=42
)
rf.fit(X_train, y_train)
print(f"准确率: {rf.score(X_test, y_test):.3f}")

# 特征重要性
for name, imp in zip(feature_names, rf.feature_importances_):
    print(f"{name}: {imp:.4f}")
```

## 3. GBDT 与 XGBoost

### 3.1 Boosting 原理

```text
Boosting = 串行训练弱学习器，后面的修正前面的

AdaBoost：提高被错分样本的权重
GBDT：每棵新树拟合前一步的"残差"（梯度）

直观类比：
  老师出题 → 学生 A 做错一部分 → 学生 B 专注于 A 的错题
  → 学生 C 专注于 A+B 的错题 → ... → 最终集成所有学生
```

### 3.2 XGBoost — Boosting 的工程巅峰

```text
XGBoost = GBDT 的极致工程优化

核心创新：
  ✅ 二阶泰勒展开（比 GBDT 的一阶更精确）
  ✅ 正则化项（控制树复杂度，防过拟合）
  ✅ 列采样（类似随机森林的随机特征）
  ✅ 并行化（分裂点计算并行，树仍是串行）
  ✅ 缺失值自动处理（学习最优分裂方向）
  ✅ 剪枝策略（从底向上 + 最大深度限制）

实战表现：
  → Kaggle 竞赛中 50%+ 的冠军方案用了 XGBoost
  → 表格数据上仍能击败深度学习
```

```python
import xgboost as xgb

# XGBoost 三行代码
model = xgb.XGBClassifier(
    n_estimators=100,
    max_depth=6,
    learning_rate=0.1,
    subsample=0.8,         # 行采样
    colsample_bytree=0.8,  # 列采样
    random_state=42
)
model.fit(X_train, y_train)
print(f"准确率: {model.score(X_test, y_test):.3f}")
```

### 3.3 GBDT 家族对比

| 库 | 特点 | 速度 | 适用 |
|------|------|:---:|------|
| **XGBoost** | 功能最全、社区最大 | ⭐⭐⭐⭐ | 通用首选 |
| **LightGBM** | 叶子优先生长、超快 | ⭐⭐⭐⭐⭐ | 大数据+高维 |
| **CatBoost** | 原生类别特征支持 | ⭐⭐⭐ | 大量类别特征 |

## 4. 三大集成方法

| 方法 | 原理 | 代表 | 降低什么 |
|------|------|------|:---:|
| **Bagging** | 并行训练、投票/平均 | Random Forest | **方差** |
| **Boosting** | 串行训练、逐步修正 | XGBoost、AdaBoost | **偏差** |
| **Stacking** | 多模型输出→元学习器 | 竞赛中用 | 偏差+方差 |

```text
选型口诀：
  高方差（过拟合）→ Bagging (Random Forest)
  高偏差（欠拟合）→ Boosting (XGBoost)
  追求极致 → Stacking + 调参
```

## 5. 与深度学习的对比

| 维度 | 决策树/集成 | 深度学习 (LLM) |
|------|:---:|:---:|
| **数据量** | 几百~几万条 | 百万~万亿级 |
| **特征工程** | 需要人工 | 自动提取 |
| **可解释性** | 高（可视化规则） | 低（黑盒） |
| **训练速度** | 快（CPU 分钟级） | 慢（GPU 天/周级） |
| **表格数据** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ |
| **图像/NLP** | ⭐⭐ | ⭐⭐⭐⭐⭐ |
| **部署成本** | 低（CPU） | 高（GPU） |

> 🎯 对 Java 后端 + LLM 开发者：XGBoost 用于表格数据场景（风控/推荐），深度学习用于 NLP/CV — 两者不是替代关系。

## 核心要点回顾

- 决策树 = if-else 规则树，可解释性最强
- 随机森林 = 多棵树的 Bagging → 降低方差
- XGBoost = 梯度 Boosting 的工程极致 → 降低偏差
- Bagging 降方差、Boosting 降偏差
- 表格数据用 XGBoost，文本/图像用深度学习
