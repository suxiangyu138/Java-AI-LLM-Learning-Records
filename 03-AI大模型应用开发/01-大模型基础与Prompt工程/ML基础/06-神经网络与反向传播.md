## 1. 神经元与多层感知机

### 1.1 单神经元 = 逻辑回归

```text
一个神经元：
  y = f(w₁x₁ + w₂x₂ + ... + wₙxₙ + b)
     └── 线性组合 ──┘   └ 激活函数 ──┘

  f = Sigmoid → 逻辑回归
  f = ReLU   → 现代神经网络
  f = 无     → 线性回归
```

### 1.2 多层感知机 MLP

```text
MLP = 多个神经元分层堆叠

  输入层      隐藏层1     隐藏层2     输出层
   x₁ ───→ ● ───→ ● ───→ ● ───→ y₁
   x₂ ───→ ● ───→ ● ───→ ● ───→ y₂
   x₃ ───→ ● ───→ ● ───→ ●

  每一层 = Linear(Wx + b) + Activation
  层间全连接

关键：
  → 没有激活函数：多层 = 单层（线性变换的复合仍是线性）
  → 有激活函数：引入非线性 → 可以拟合任意函数（万能近似定理）
```

### 1.3 参数量计算

```python
# MLP 参数量
input_dim, hidden1, hidden2, output_dim = 784, 256, 128, 10

# Layer 1: 784 × 256 + 256 = 200,960
# Layer 2: 256 × 128 + 128 = 32,896
# Layer 3: 128 × 10  + 10  = 1,290
# Total: 235,146 参数
```

## 2. 激活函数全景

| 函数 | 公式 | 导数 | 使用场景 |
|------|------|------|----------|
| **Sigmoid** | $\frac{1}{1+e^{-x}}$ | $\sigma(1-\sigma)$ | 输出层二分类 |
| **Tanh** | $\frac{e^x-e^{-x}}{e^x+e^{-x}}$ | $1-\tanh^2$ | 早期 RNN |
| **ReLU** | $\max(0, x)$ | 0 or 1 | CNN、通用 |
| **Leaky ReLU** | $\max(0.01x, x)$ | 0.01 or 1 | 解决 Dead ReLU |
| **GELU** | $x\Phi(x)$ | $\Phi(x)+x\phi(x)$ | **LLM 标配** |
| **SiLU/Swish** | $x\sigma(x)$ | Self-gated | LLaMA |
| **Softmax** | $\frac{e^{z_i}}{\sum e^{z_j}}$ | $q_i(1-q_i)$ | 多分类输出层 |

```text
GELU vs ReLU：
  ReLU: x<0 → 输出=0, 梯度=0 → Dead Neuron
  GELU: x<0 → 有小概率输出 → 神经元不会"死"
        → 处处可导 → 训练更稳定 → LLM 标配
```

## 3. 反向传播手推

### 3.1 一个 Step 的完整计算

```python
import numpy as np

# 极简网络：输入(2) → 隐藏(2) → 输出(1)
x = np.array([1.0, -2.0])
W1 = np.array([[0.5, -0.3], [0.2, 0.8]])
b1 = np.array([0.1, -0.2])
W2 = np.array([0.4, -0.5])
b2 = 0.1
y_true = 1.0

# === Forward ===
z1 = W1 @ x + b1           # 线性
a1 = np.maximum(0, z1)     # ReLU
z2 = W2 @ a1 + b2          # 线性
y_pred = z2
loss = 0.5 * (y_pred - y_true)**2  # MSE

print(f"Pred: {y_pred:.4f}, Loss: {loss:.4f}")

# === Backward（链式法则！）===
dL_dy = y_pred - y_true                         # ∂L/∂y
dL_dW2 = dL_dy * a1                             # ∂L/∂W2
dL_db2 = dL_dy                                   # ∂L/∂b2
dL_da1 = dL_dy * W2                             # ∂L/∂a1
dL_dz1 = dL_da1.copy(); dL_dz1[z1 <= 0] = 0     # ReLU backward
dL_dW1 = np.outer(dL_dz1, x)                    # ∂L/∂W1
dL_db1 = dL_dz1                                  # ∂L/∂b1

# === Update ===
lr = 0.01
W1 -= lr * dL_dW1; b1 -= lr * dL_db1
W2 -= lr * dL_dW2; b2 -= lr * dL_db2

# Verify loss decreased
z1 = W1 @ x + b1; a1 = np.maximum(0, z1)
new_loss = 0.5 * (W2 @ a1 + b2 - y_true)**2
print(f"New Loss: {new_loss:.4f}")
```

### 3.2 PyTorch 自动微分

```python
import torch

# PyTorch 版本 — 不需要手写 backward！
x = torch.tensor([1.0, -2.0], requires_grad=False)
y_true = torch.tensor([1.0])

W1 = torch.tensor([[0.5, -0.3], [0.2, 0.8]], requires_grad=True)
W2 = torch.tensor([[0.4, -0.5]], requires_grad=True)

# Forward
y_pred = W2 @ torch.relu(W1 @ x)
loss = 0.5 * (y_pred - y_true).pow(2).sum()

# Backward — 一行！
loss.backward()

# Update
with torch.no_grad():
    W1 -= 0.01 * W1.grad
    W2 -= 0.01 * W2.grad
    W1.grad.zero_()
    W2.grad.zero_()
```

## 4. 梯度下降变体

| 优化器 | 核心改进 | 适用 |
|------|----------|------|
| **SGD** | 纯梯度方向 | Baseline |
| **SGD + Momentum** | 惯性 → 加速 + 平滑 | CNN |
| **Adam** | 自适应 lr + 动量 | 通用 |
| **AdamW** | 解耦权重衰减 | **LLM 标配** |
| **LION** | 只用梯度符号 | 实验性 |

```text
AdamW 为什么是 LLM 标配？

  Adam 问题：L2 正则化与自适应学习率耦合 → 权重衰减效果被稀释
  AdamW 解决：将权重衰减从自适应机制中解耦

  W = W - η × (m̂/(√v̂+ε) + λ×W)
                    └── 自适应方向 ──┘ └ 独立权重衰减 ─┘

  → 更好的泛化性能，LLM 训练/微调事实标准
```

## 5. 损失函数全景

| 损失函数 | 公式 | 任务 | LLM 中使用 |
|----------|------|------|:---:|
| **MSE** | $(y-\hat{y})^2$ | 回归 | ❌ |
| **Binary CE** | $-[y\log\hat{y}+(1-y)\log(1-\hat{y})]$ | 二分类 | ❌ |
| **Categorical CE** | $-\sum y_k\log\hat{y}_k$ | 多分类 | ✅ **LLM 标配** |
| **KL Divergence** | $\sum p\log(p/q)$ | 分布差异 | ✅ RLHF |
| **Triplet Loss** | $\max(0, d_a-d_b+m)$ | 度量学习 | ✅ Embedding |

```text
LLM 训练的损失函数 = Cross Entropy Loss

  词表大小 = 32000~128000 类 → 超大多分类问题
  每一步：模型预测下一个 token → 计算 CE Loss → 反向传播

  Loss = -log P(correct_token | context)
       = CrossEntropy(model_output_logits, correct_token_id)
```

## 6. 从 MLP 到 Transformer

```text
MLP → RNN → LSTM → Transformer：神经网络的进化

  MLP (1986)：
    → 全连接 → 无序列感知 → 不能处理变长文本

  RNN/LSTM (1997)：
    → 循环结构 → 有记忆 → 但有梯度消失/爆炸

  Transformer (2017)：
    → 自注意力替代循环 → 并行处理 → 长距离依赖
    → 所有现代 LLM 的基础

核心跃迁：
  循环（串行、慢）→ 注意力（并行、快、长距离）
```

## 核心要点回顾

- 神经网络 = 线性层 + 激活函数的逐层堆叠
- 反向传播 = 链式法则的自动实现（PyTorch 的 `loss.backward()`）
- GELU 是 LLM 默认激活函数（优于 ReLU）
- AdamW 是 LLM 训练事实标准优化器（解耦权重衰减）
- 交叉熵是 LLM 训练的损失函数（超大词表多分类）
