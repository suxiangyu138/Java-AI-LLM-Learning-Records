## 1. 过拟合与欠拟合

### 1.1 三种状态

```text
欠拟合 (Underfitting)：
  → Train Error 高 + Test Error 高
  → 模型太简单，没学到数据规律
  → 解决方案：增加复杂度 / 加特征 / 减正则化

过拟合 (Overfitting)：
  → Train Error 极低 + Test Error 高
  → 模型记住了训练数据噪声，泛化差
  → 解决方案：加正则化 / 加数据 / 减复杂度

刚好 (Good Fit)：
  → Train Error 低 + Test Error 低
  → 两者的 gap 小 → 泛化好
```

### 1.2 学习曲线诊断

```text
学习曲线 = 训练集大小 vs 误差

过拟合的典型曲线：
  Error
   ↑     ╲  Val（高高在上）
   │  ╱──╲
   │ ╱    ╲___ Train（很低）
   │╱
   └──────────→ Samples

欠拟合的典型曲线：
  Error
   ↑     ╱╲  Val（也高）
   │   ╱   ╲
   │ ╱     ╲ Train（也高）
   │╱
   └──────────→ Samples
```

## 2. Bias-Variance 深度解析

### 2.1 数学分解

```text
期望泛化误差 = Bias² + Variance + Irreducible Error

  Bias²：模型预测的期望与真实值的偏差（系统性误差）
  Variance：模型对训练数据变化的敏感度
  Irreducible Error：数据本身的噪声（无法消除）

模型复杂度 ↑ → Bias ↓, Variance ↑
模型复杂度 ↓ → Bias ↑, Variance ↓
```

### 2.2 在 LLM 中的体现

```text
LLM 的偏差-方差：
  
  高 Bias（小模型）：
    → Qwen-0.5B：很多问题根本不会，但输出稳定
    → 解决：增大模型

  高 Variance（过拟合微调）：
    → 在 100 条数据上微调 10 个 epoch → 背下答案
    → 解决：减少 epoch、加正则化、用 LoRA
```

## 3. L1 与 L2 正则化

### 3.1 原理

```text
L2 正则化（Ridge / 权重衰减）：
  Loss = Original_Loss + λ × Σ w²

  效果：权重趋近于 0 但不会为 0 → 所有特征都保留
  几何：约束在圆心在原点的圆内

L1 正则化（Lasso）：
  Loss = Original_Loss + λ × Σ |w|

  效果：大量权重变为 0 → 自动特征选择
  几何：约束在菱形内 → 角点处权重=0
```

### 3.2 LLM 中的 L2（权重衰减）

```text
LLM 训练几乎只用 L2 正则化（称为 Weight Decay）

AdamW 中：
  W = W - η × (m̂/(√v̂ + ε) + λ × W)
                              └── L2 正则化（权重衰减）

λ 典型值：0.01 ~ 0.1
作用：防止权重过大 → 数值稳定 + 泛化好
```

## 4. Dropout

### 4.1 原理

```text
Dropout：训练时随机"丢弃"一部分神经元

  每个训练 step：
    → 每个神经元以概率 p 被"关闭"（输出=0）
    → 实际在训练一个"子网络"
    → 不同的 step 训练不同的子网络

  推理时：
    → 所有神经元激活，但输出×p（补偿训练时的丢弃）

为什么有效？
  → 相当于训练了大量不同网络的集成
  → 神经元不能依赖特定同伴 → 学到更鲁棒的特征
```

```python
import torch.nn as nn

# Dropout 用法
model = nn.Sequential(
    nn.Linear(768, 256),
    nn.ReLU(),
    nn.Dropout(0.3),     # 30% 神经元随机丢弃
    nn.Linear(256, 10)
)

# LLM 中 Dropout 的使用：
# 预训练 → Dropout 0.1（常用）
# SFT 微调 → Dropout 0.05 或不用
# LoRA 微调 → LoRA 自带 Dropout (lora_dropout=0.05)
```

## 5. Early Stopping

### 5.1 原理

```text
Early Stopping：验证集 Loss 不再下降时停止训练

  Loss
   ↑
   │  Train Loss（持续下降）
   │     ╲
   │      ╲____
   │           ╲___
   │  Val Loss        ╲___ ← 最低点！在此停止
   │      ╲___    ╱
   │          ╲_╱
   └────────────────→ Epochs
         ↑
     停止训练！

为什么有效？
  → 训练太久 → 模型开始记噪声 → 泛化下降
  → 在泛化最好时停下
```

```python
# PyTorch Early Stopping
class EarlyStopping:
    def __init__(self, patience=3, min_delta=0):
        self.patience = patience
        self.min_delta = min_delta
        self.counter = 0
        self.best_loss = float('inf')
    
    def __call__(self, val_loss):
        if val_loss < self.best_loss - self.min_delta:
            self.best_loss = val_loss
            self.counter = 0
            return False  # 不停止
        else:
            self.counter += 1
            if self.counter >= self.patience:
                return True  # 停止
            return False
```

## 6. 数据增强与更多方法

| 方法 | 原理 | LLM 中使用 |
|------|------|:---:|
| **数据增强** | 扩充训练数据多样性 | ✅ 回译、同义改写 |
| **BatchNorm/LayerNorm** | 稳定每层输入分布 | ✅ LayerNorm 标配 |

| **Label Smoothing** | 标签软化（不要求 100%） | ✅ 0.1 常用 |
| **权重初始化** | Xavier/He/Kaiming | ✅ 预训练已定 |

## 7. LLM 中的过拟合防控

```text
LLM 训练各阶段的过拟合风险与对策：

预训练（万亿 token）：
  风险：极低（数据量太大，不可能过拟合）
  对策：基本不需要

SFT 微调（万~十万条）：
  风险：中等 — 数据量小容易背答案
  对策：epoch=1~3、小学习率、Early Stopping

LoRA 微调（少量数据）：
  风险：较高 — 参数量少但仍可能过拟合
  对策：r=8~16、lora_dropout=0.05、epoch=1~2

RLHF 对齐：
  风险：Reward Hacking（利用 RM 缺陷"作弊"）
  对策：KL 散度约束（防止策略跑偏）
```

## 核心要点回顾

- 过拟合 = Train Loss 低、Val Loss 高 → 泛化差
- L1 产生稀疏权重、L2 缩小所有权重 → LLM 只用 L2（Weight Decay）
- Dropout = 训练中随机关闭神经元 → 相当于训练集成模型
- Early Stopping = Val Loss 不再下降时停止 → 最简单有效的防过拟合
- LLM 预训练几乎不过拟合，微调需要防范（小 epoch + 正则化）
