## 1. 语言模型演进

### 1.1 什么是语言模型

> 语言模型（Language Model, LM）是计算文本序列出现概率的模型。给定序列 $w_1, w_2, ..., w_n$，语言模型计算 $P(w_1, w_2, ..., w_n)$。

```text
核心任务：
  "我吃饭" → 概率高 ✅
  "饭吃我" → 概率低 ❌
  "今天天气很好，我打算去" → 预测下一个词："公园"、"散步"...
```

### 1.2 三代演进

| 代际 | 代表 | 核心方法 | 优势 | 局限 |
|------|------|----------|------|------|
| **统计语言模型** | N-gram | 统计词频共现 | 简单快速 | 数据稀疏、无语义理解 |
| **神经语言模型** | RNN/LSTM/GRU | 循环网络记忆上文 | 捕捉长短依赖 | 串行训练慢、梯度消失 |
| **预训练语言模型** | Transformer/BERT/GPT | 自注意力+海量预训练 | 并行、长距离、通用 | 计算复杂度 $O(n^2)$ |

### 1.3 N-gram → RNN → Transformer 关键跳跃

```text
N-gram（1990s）：
  P(公园|我打算去) ≈ count("去公园") / count("去")
  → 只能看前 N-1 个词，毫无语义

RNN/LSTM（2000s）：
  h_t = f(W·x_t + U·h_{t-1})
  → 能记忆上文，但串行训练，100 词句子要算 100 步

Transformer（2017）：
  Attention(Q, K, V) = softmax(QK^T/√d_k)V
  → 每个词同时看所有词，一次矩阵运算完成
```

## 2. 神经网络基础

### 2.1 核心组件

```text
一个神经元：y = f(Wx + b)

多层堆叠：
  输入层 → 隐藏层1 → 隐藏层2 → ... → 输出层
  每层 = 线性变换(Wx+b) + 激活函数(非线性)
```

| 概念 | 说明 |
|------|------|
| **权重 W** | 学习的核心参数 |
| **偏置 b** | 偏移量，增加模型灵活性 |
| **激活函数** | 引入非线性，否则多层=单层 |
| **前向传播** | 输入 → 逐层计算 → 输出 |
| **反向传播** | 基于链式法则计算每层梯度 |
| **梯度下降** | $\theta \leftarrow \theta - \eta \nabla L$ |

### 2.2 关键超参数

| 参数 | 说明 | 典型值 |
|------|------|--------|
| **learning_rate** | 参数更新步长 | 1e-5 ~ 1e-3 |
| **batch_size** | 每次训练的样本数 | 32 ~ 512 |
| **epoch** | 完整遍历数据集的次数 | 1 ~ 10（LLM 微调） |
| **hidden_dim** | 隐藏层维度 | 768（BERT-base）~ 8192（LLaMA-70B） |
| **num_layers** | Transformer 层数 | 12（BERT）~ 80（LLaMA-70B） |

## 3. 激活函数

### 3.1 大模型常用激活函数

| 函数 | 公式 | 使用场景 |
|------|------|----------|
| **ReLU** | $\max(0, x)$ | 传统 CNN/RNN，简单高效 |
| **GELU** | $x \cdot \Phi(x)$ | **LLM 标配**：BERT/GPT/LLaMA/Qwen |
| **SwiGLU** | $x \cdot \sigma(xW_1) \cdot (xW_2)$ | LLaMA-2+、PaLM 等新一代 |
| **Sigmoid** | $\frac{1}{1+e^{-x}}$ | 二分类输出层，LLM 内部不用 |
| **Tanh** | $\frac{e^x - e^{-x}}{e^x + e^{-x}}$ | 早期 RNN，已被替代 |

### 3.2 为什么 GELU 成为主流

```text
ReLU 的问题：
  x < 0 时梯度为 0 → 神经元"死亡"
  不可导点（x=0）→ 理论不优雅

GELU 的优势：
  ✅ 处处可导，平滑非线性
  ✅ 对负值有小概率激活（正则化效果）
  ✅ 实验证明：收敛更快，效果更好

GELU 本质 = 输入 × 标准正态 CDF = 按概率"门控"激活
```

## 4. 损失函数与优化器

### 4.1 损失函数

| 损失函数 | 公式 | 用途 |
|----------|------|------|
| **交叉熵 (Cross-Entropy)** | $-\sum y_i \log \hat{y}_i$ | **LLM 训练标配**：分类、next-token 预测 |
| **MSE** | $\frac{1}{n}\sum(y_i - \hat{y}_i)^2$ | 回归任务（LLM 不用） |

```text
LLM 训练的核心：给定上文，预测下一个 token 的概率分布

  Loss = CrossEntropy(predicted_probs, actual_token)

本质是多分类问题，类别数 = 词表大小（通常 32000~128000）
```

### 4.2 优化器

| 优化器 | 说明 | 使用场景 |
|--------|------|----------|
| **SGD** | 基础梯度下降 | 学术实验、baseline |
| **Adam** | 自适应学习率 + 动量 | 通用训练 |
| **AdamW** | Adam + 解耦权重衰减 | **LLM 训练/微调标配** |

```text
AdamW vs Adam：
  Adam 的 L2 正则化 = 权重衰减与自适应学习率耦合
  AdamW 解耦 → 更好的泛化性能

大模型微调几乎都用 AdamW(lr=1e-5~2e-4)
```

## 5. 正则化与归一化

### 5.1 过拟合与解决方案

| 方法 | 说明 | 大模型使用情况 |
|------|------|:---:|
| **Dropout** | 训练时随机丢弃神经元 | 预训练常用，微调少用 |
| **L2 正则化** | 限制权重大小 | AdamW 内置 |
| **Early Stopping** | 验证集不再提升时停止 | SFT 微调常用 |
| **数据增强** | 扩充训练数据 | 数据层面 |

### 5.2 归一化：LayerNorm vs BatchNorm

| 方法 | 归一化维度 | 大模型使用 |
|------|-----------|:---:|
| **BatchNorm** | 对 batch 维度归一化 | ❌ LLM 不用 |
| **LayerNorm** | 对 feature 维度归一化 | ✅ Transformer 标配 |
| **RMSNorm** | LayerNorm 简化版（去均值） | ✅ LLaMA 系列使用 |

```text
为什么 LayerNorm 而不是 BatchNorm？
  → NLP 序列长度不固定，batch 统计不稳定
  → LayerNorm 不依赖 batch size，训练/推理一致
  → RMSNorm 更简单更快，LLaMA/T5 等新一代模型首选
```

## 6. 生成式 vs 判别式

| 维度 | 生成式模型 | 判别式模型 |
|------|-----------|-----------|
| **代表** | GPT 系列、LLaMA | BERT 系列 |
| **核心能力** | 基于前文预测下一个 token | 对输入进行分类/判断 |
| **数学本质** | 建模 $P(x)$ 或 $P(x_t\|x_{<t})$ | 建模 $P(y\|x)$ |
| **架构** | Decoder-Only（单向） | Encoder-Only（双向） |
| **任务** | 文本生成、对话、补全 | 分类、情感分析、NER |
| **当前地位** | 主流（ChatGPT 效应） | 小众（被生成式替代趋势） |

> 🎯 2024+：Decoder-Only 架构一统天下，BERT 类模型主要用于 Embedding 和特定分类任务。

## 7. 核心概念速查表

| 概念 | 一句话 |
|------|--------|
| Token | 模型最小处理单元，中文 ≈ 0.5~2 token/字 |
| Embedding | 将离散 token 映射为稠密向量 |
| 自注意力 | 每个词关注所有词，计算关联权重 |
| 自回归 | 逐 token 生成，每次基于前文 |
| 交叉熵 | 衡量两个概率分布差异，LLM 训练损失 |
| GELU | 大模型默认激活函数 |
| AdamW | 大模型训练/微调标配优化器 |
| LayerNorm/RMSNorm | 稳定深层网络训练的核心组件 |
| 梯度消失/爆炸 | 深层网络反向传播时梯度趋零或发散 |

---

## 核心要点回顾

- 语言模型进化路线：N-gram → RNN/LSTM → Transformer
- 神经网络三要素：权重+激活函数（非线性）+ 损失函数（优化目标）
- LLM 标配：GELU 激活 + AdamW 优化器 + 交叉熵损失 + LayerNorm
- 生成式（GPT/Decoder-Only）已成主流，判别式（BERT）退居二线
- 理解这些基础概念 = 理解 LLM 的"零件清单"
