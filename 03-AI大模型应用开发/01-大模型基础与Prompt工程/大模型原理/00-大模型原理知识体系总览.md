## 3. 精通级学习路线

### 🟢 L1：打地基（1天）

```
01-语言模型与深度学习基础 → 02-Transformer架构深度解析
产出：理解 Attention 公式、会用 numpy 手写 Self-Attention
```

### 🔵 L2：懂训练（1天）

```
03-预训练与训练范式 → 04-主流架构对比 → 05-大模型分类
产出：能讲清楚 RLHF 四步流程、BERT vs GPT 的架构级差异
```

### 🟣 L3：能落地（1天）

```
06-模型微调与高效适配 → 07-模型部署与推理优化
产出：能用 LoRA 微调 Qwen-7B、用 Ollama 本地部署模型
```

### 🟡 L4：前沿拓展（半天）

```
08-多模态大模型 → 09-模型编辑与持续学习
产出：理解多模态原理、掌握模型编辑方法
```
