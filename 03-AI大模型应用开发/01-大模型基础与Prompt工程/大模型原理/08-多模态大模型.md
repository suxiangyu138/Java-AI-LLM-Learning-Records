## 1. 多模态概述

### 1.1 什么是多模态

```text
单模态模型：文本 → 文本（传统 LLM）
多模态模型：文本+图像+音频+视频 → 文本/图像/音频

核心能力矩阵：
  Text → Text   : 对话、翻译、总结（LLM 基本能力）
  Text → Image  : 文生图（DALL-E, Stable Diffusion）
  Image → Text  : 图像理解（GPT-4V, Qwen-VL）
  Image + Text → Text : 多模态理解（图表分析、UI 审查）
  Text → Video  : 文生视频（Sora）
  Speech → Text : 语音转文字（Whisper）
```

### 1.2 多模态架构共性

```text
几乎所有多模态模型的架构：

┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│ 视觉编码器     │    │  投影层/适配器 │    │   LLM 骨干    │
│ (ViT/CLIP)   │───→│  (MLP/Q-Former)│───→│ (LLaMA/Qwen) │
└──────────────┘    └──────────────┘    └──────────────┘
      ↑                                       │
   图片输入                              文本输出

核心思路：
  ① 用预训练的视觉编码器提取图像特征
  ② 用投影层将视觉特征映射到 LLM 的语义空间
  ③ LLM 将视觉+文本信息统一处理 → 生成文本
```

## 2. 视觉语言模型 VLM

### 2.1 关键组件

| 组件 | 作用 | 代表 |
|------|------|------|
| **视觉编码器** | 将图片转为特征向量 | ViT, SigLIP |
| **投影层** | 对齐视觉和文本语义空间 | MLP, Q-Former (BLIP-2) |
| **LLM 骨干** | 融合信息、生成回答 | LLaMA, Qwen |

### 2.2 主流 VLM

| 模型 | 视觉编码器 | LLM | 特点 |
|------|-----------|-----|------|
| **GPT-4o** | 自研 | GPT-4 | 综合最强 |
| **Qwen-VL** | ViT-bigG | Qwen | 中文OCR强 |
| **LLaVA** | CLIP-ViT | LLaMA | 开源标杆 |
| **Gemini** | 自研 | Gemini | 原生多模态 |
| **GLM-4V** | ViT | GLM-4 | 中文优化 |
| **Claude 3.5** | 自研 | Claude | 图表/文档强 |

### 2.3 多模态处理流程

```text
用户上传一张 Java 架构图 + 问题："这个架构有什么瓶颈？"

① 视觉编码器（ViT）处理图片
   图片 (224×224×3) → ViT → [CLS] token → 视觉特征向量 (1024 维)

② 投影层对齐
   视觉特征 (1024) → MLP → 文本语义空间 (4096 维)

③ LLM 融合
   Input = [Image Tokens] + "这个架构有什么瓶颈？"
   → LLM 统一处理 → 生成回答
```

## 3. 文生图 Text-to-Image

### 3.1 两大流派

| 维度 | DALL-E 3 | Stable Diffusion |
|------|----------|------------------|
| **架构** | 自回归 + VQ-VAE | 扩散模型 (Diffusion) |
| **部署** | 仅 API | 可本地部署 |
| **质量** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ |
| **可控性** | 低 | 高（ControlNet等） |
| **成本** | $0.04~0.12/张 | 免费（电费） |
| **速度** | 快（~5s） | 中（~10~30s） |

### 3.2 Stable Diffusion 本地部署

```python
from diffusers import StableDiffusionPipeline
import torch

model_id = "runwayml/stable-diffusion-v1-5"
pipe = StableDiffusionPipeline.from_pretrained(
    model_id,
    torch_dtype=torch.float16
)
pipe = pipe.to("cuda")

# 生成图片
prompt = """
A modern Java backend architecture diagram showing microservices,
API gateway, message queue, and database connections,
clean technical illustration style, blue and purple gradient
"""
negative_prompt = "blurry, low quality, distorted, watermark, text"

image = pipe(
    prompt=prompt,
    negative_prompt=negative_prompt,
    num_inference_steps=25,
    guidance_scale=7.5,
    height=512,
    width=768
).images[0]

image.save("java-architecture.png")
```

### 3.3 文生图 Prompt 五要素

```text
高质量 Prompt 公式：
  [主体] + [风格] + [构图] + [光线] + [画质]

示例：
  主体：A Java developer working at modern desk
  风格：anime style, flat illustration
  构图：front view, medium shot
  光线：soft studio lighting, warm tones
  画质：4k, high quality, detailed

负面 Prompt（排除不良元素）：
  blurry, ugly, extra fingers, bad anatomy, watermark, text
```

## 4. 图像理解 Image Understanding

### 4.1 GPT-4o 视觉 API

```python
import base64
from openai import OpenAI

client = OpenAI()

def encode_image(path):
    with open(path, "rb") as f:
        return base64.b64encode(f.read()).decode("utf-8")

def analyze_image(image_path, prompt):
    base64_image = encode_image(image_path)
    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[{
            "role": "user",
            "content": [
                {"type": "text", "text": prompt},
                {"type": "image_url", "image_url": {
                    "url": f"data:image/png;base64,{base64_image}"
                }}
            ]
        }]
    )
    return response.choices[0].message.content

# 实际场景
# 1. 代码截图转文字
code = analyze_image("code-screenshot.png",
    "提取图片中的 Java 代码，找出所有 bug 并给出修复方案")

# 2. 架构图分析
analysis = analyze_image("architecture.png",
    "分析这个微服务架构图，指出潜在的单点故障和性能瓶颈")

# 3. 错误日志解读
root_cause = analyze_image("error-stack.png",
    "分析错误堆栈，给出根因和修复步骤")
```

### 4.2 Qwen-VL 本地推理

```python
from transformers import Qwen2VLForConditionalGeneration, AutoProcessor
from qwen_vl_utils import process_vision_info

model = Qwen2VLForConditionalGeneration.from_pretrained(
    "Qwen/Qwen2-VL-7B-Instruct",
    torch_dtype="auto",
    device_map="auto"
)
processor = AutoProcessor.from_pretrained("Qwen/Qwen2-VL-7B-Instruct")

def analyze(image_path, question):
    messages = [{
        "role": "user",
        "content": [
            {"type": "image", "image": image_path},
            {"type": "text", "text": question}
        ]
    }]
    text = processor.apply_chat_template(messages, tokenize=False)
    image_inputs, video_inputs = process_vision_info(messages)
    inputs = processor(
        text=[text], images=image_inputs, videos=video_inputs,
        padding=True, return_tensors="pt"
    ).to(model.device)
    
    generated_ids = model.generate(**inputs, max_new_tokens=256)
    generated_ids_trimmed = [
        out_ids[len(in_ids):]
        for in_ids, out_ids in zip(inputs.input_ids, generated_ids)
    ]
    return processor.batch_decode(
        generated_ids_trimmed, skip_special_tokens=True, clean_up_tokenization_spaces=False
    )[0]
```

## 5. 语音多模态

### 5.1 GPT-4o 语音模式

```text
GPT-4o 是端到端的多模态模型：

传统流程：
  语音 → STT(Whisper) → 文本 → LLM → 文本 → TTS → 语音
  （级联方式，延迟高，丢失语气/情感信息）

GPT-4o 流程：
  语音 → 统一多模态模型 → 语音
  （端到端，延迟 ~232ms，保留语气、情感、停顿）

平均响应时间：232ms（接近人类对话速度）
```

### 5.2 Whisper 语音转文字

```python
from openai import OpenAI

client = OpenAI()

# 语音转文字
audio_file = open("meeting.mp3", "rb")
transcript = client.audio.transcriptions.create(
    model="whisper-1",
    file=audio_file,
    language="zh",          # 指定语言
    response_format="text"
)
print(transcript)
```

## 6. 多模态开发实战

### 6.1 开发要点

| 要点 | 说明 |
|------|------|
| **图像预处理** | 控制分辨率（512-1024px），压缩大小降低 API 延迟 |
| **成本控制** | 图像 token 消耗大，一张图 ≈ 500-1000 tokens |
| **隐私注意** | 图像可能含敏感信息（人脸、定位），优先本地模型 |
| **模型选择** | 英文场景 GPT-4o，中文 OCR 选 Qwen-VL |
| **批量处理** | 多张图 → 异步并发，避免串行 |

### 6.2 典型应用场景

```text
后端开发场景：
  ✅ 架构图分析 → 自动识别瓶颈和改进建议
  ✅ UI 截图上 Bug → 自动定位代码问题
  ✅ 错误堆栈截图 → 自动分析根因和修复
  ✅ 数据库 ER 图 → 自动生成建表 SQL
  ✅ API 文档截图 → 自动生成 Java DTO 代码
```

## 核心要点回顾

- 多模态架构共性 = 编码器（视觉/音频）+ 投影层 + LLM 骨干
- VLM 主流：GPT-4o（最强）、Qwen-VL（中文 OCR）、LLaVA（开源标杆）
- 文生图：DALL-E 3（API 质量高）、Stable Diffusion（本地免费可控）
- 端到端语音：GPT-4o 延迟 ~232ms，接近人类对话速度
- 图像理解的核心应用：代码截图转文字、架构图分析、错误分析
- 生产注意：图片 token 消耗大、隐私敏感图用本地模型
