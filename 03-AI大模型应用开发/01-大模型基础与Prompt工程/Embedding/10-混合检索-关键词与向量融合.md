## 1. 为什么单一检索不够

```text
场景一：专有名词查询
  查询："Spring Boot 3.2 的虚拟线程配置"
  
  Dense 向量检索 → 返回 "Spring 并发处理"、"多线程优化" 等近似内容
  → 但用户要的是精确的 "3.2" 和 "虚拟线程"！
  
  Sparse 关键词检索 → "3.2" 和 "虚拟线程" 精准命中 ✅

场景二：语义查询
  查询："怎么让 Java 应用启动更快"
  
  Sparse 检索 → 找不到 "启动更快" 这几个字 → 空结果！
  
  Dense 检索 → "启动优化"、"减少启动时间" 等语义相关 ✅

结论：Dense 和 Sparse 是互补的 — 没有一方能通吃
```

## 2. Dense 检索 vs Sparse 检索

| 维度 | Dense（稠密向量） | Sparse（稀疏向量/关键词） |
|------|:---:|:---:|
| **原理** | 语义 Embedding → 向量相似度 | 词频统计 → TF-IDF/BM25 打分 |
| **优势** | 理解同义词、近义表达 | 专有名词、精确匹配、可解释 |
| **劣势** | 对生僻词/数字/代码弱 | 不理解语义变化 |
| **典型方法** | BGE-M3 Dense、text-embedding-3 | BM25、TF-IDF、BGE-M3 Sparse |
| **存储** | 1024 维浮点向量 | 词→权重字典（极小） |
| **适用** | 模糊/语义查询 | 精确/代码/术语查询 |

## 3. BM25 关键词检索

### 3.1 BM25 原理

```text
BM25 = 改进版 TF-IDF，搜索引擎标配

  BM25(d, q) = Σ IDF(q_i) × (TF(q_i, d) × (k1 + 1)) / (TF(q_i, d) + k1 × (1 - b + b × |d|/avgdl))

  TF: 词频 — 词在文档中出现次数
  IDF: 逆文档频率 — 词有多罕见（罕见词权重高）
  k1: 词频饱和度参数（默认 1.5）
  b:  文档长度归一化（默认 0.75）
```

### 3.2 使用 Elasticsearch 的 BM25

```python
from elasticsearch import Elasticsearch

es = Elasticsearch("http://localhost:9200")

# 索引文档（自动使用 BM25）
def index_for_bm25(doc_id, text):
    es.index(index="documents", id=doc_id, body={"text": text})

# BM25 检索
def bm25_search(query, size=10):
    resp = es.search(index="documents", body={
        "query": {
            "match": {
                "text": query
            }
        },
        "size": size
    })
    return [
        {"id": hit["_id"], "text": hit["_source"]["text"],
         "score": hit["_score"]}
        for hit in resp["hits"]["hits"]
    ]
```

### 3.3 纯 Python BM25

```python
import numpy as np
from collections import Counter
import math

class SimpleBM25:
    """最简 BM25 实现 — 理解原理用"""
    
    def __init__(self, k1=1.5, b=0.75):
        self.k1 = k1
        self.b = b
        self.docs = []
        self.doc_lens = []
        self.avgdl = 0
        self.df = Counter()  # 文档频率
        self.N = 0
    
    def add(self, doc_id, text):
        words = text.lower().split()
        self.docs.append((doc_id, words))
        self.doc_lens.append(len(words))
        # 更新文档频率（每个词只算一次/文档）
        for word in set(words):
            self.df[word] += 1
        self.N += 1
        self.avgdl = sum(self.doc_lens) / self.N
    
    def search(self, query, top_k=5):
        query_words = query.lower().split()
        scores = []
        
        for i, (doc_id, words) in enumerate(self.docs):
            score = 0
            doc_len = self.doc_lens[i]
            tf = Counter(words)
            
            for qw in query_words:
                if qw not in self.df:
                    continue
                # IDF
                idf = math.log((self.N - self.df[qw] + 0.5) / 
                               (self.df[qw] + 0.5) + 1)
                # TF (BM25 变体)
                tf_qw = tf.get(qw, 0)
                score += idf * (tf_qw * (self.k1 + 1)) / (
                    tf_qw + self.k1 * (1 - self.b + self.b * doc_len / self.avgdl)
                )
            
            scores.append((doc_id, score))
        
        scores.sort(key=lambda x: x[1], reverse=True)
        return scores[:top_k]
```

## 4. 混合检索的实现

### 4.1 双路检索架构

```python
class HybridSearcher:
    """混合检索器：Dense 向量 + BM25 关键词"""
    
    def __init__(self, dense_index, bm25_index):
        self.dense = dense_index   # FAISS/HNSW 索引
        self.bm25 = bm25_index     # BM25 索引
    
    def search(self, query, top_k=10):
        """双路检索"""
        # ① Dense 检索
        dense_results = self.dense.search(query, top_k=20)
        
        # ② Sparse 检索
        sparse_results = self.bm25.search(query, top_k=20)
        
        # ③ 融合排序
        merged = self._reciprocal_rank_fusion(
            dense_results, sparse_results, k=60
        )
        
        return merged[:top_k]
    
    def _reciprocal_rank_fusion(self, list_a, list_b, k=60):
        """RRF（倒数排名融合）— 最常用的混合检索融合算法"""
        scores = {}
        
        # Dense 排名 → RRF 分数
        for rank, item in enumerate(list_a, 1):
            doc_id = item["id"]
            scores[doc_id] = scores.get(doc_id, 0) + 1.0 / (k + rank)
        
        # Sparse 排名 → RRF 分数
        for rank, item in enumerate(list_b, 1):
            doc_id = item["id"]
            scores[doc_id] = scores.get(doc_id, 0) + 1.0 / (k + rank)
        
        # 按融合分数排序
        sorted_ids = sorted(scores.items(), key=lambda x: x[1], reverse=True)
        return [{"id": doc_id, "score": score} for doc_id, score in sorted_ids]
```

## 5. 融合排序策略

### 5.1 三种融合方法

| 方法 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| **RRF（推荐）** | 排名倒数求和 | 无需调参、鲁棒 | 可能稀释高分结果 |
| **加权求和** | α×Dense + (1-α)×Sparse | 灵活可调 | 需手动调 α |
| **两阶段** | Sparse 粗筛 → Dense 精排 | 速度快 | 可能遗漏 |

### 5.2 RRF 详解

```python
def reciprocal_rank_fusion(result_lists, k=60):
    """
    RRF 融合多个检索结果
    
    k=60 是经验最优值（来自 RR'FuSE 论文）
    k 越大 → 排名靠后的结果权重越大
    k 越小 → 只关注排名最靠前的结果
    """
    scores = {}
    
    for results in result_lists:
        for rank, item in enumerate(results, 1):
            doc_id = item.get("id") or item.get("text")
            scores[doc_id] = scores.get(doc_id, 0) + 1.0 / (k + rank)
    
    sorted_items = sorted(scores.items(), key=lambda x: x[1], reverse=True)
    return [{"id": doc_id, "rrf_score": score} for doc_id, score in sorted_items]
```

### 5.3 加权融合

```python
def weighted_fusion(dense_results, sparse_results, alpha=0.7):
    """
    加权融合
    
    alpha: Dense 向量的权重（0.7 = Dense 更重要）
    """
    # 归一化各自的分数到 [0, 1]
    dense_norm = normalize_scores(dense_results)
    sparse_norm = normalize_scores(sparse_results)
    
    combined = {}
    for r in dense_norm:
        combined[r["id"]] = {"score": alpha * r["score"], **r}
    for r in sparse_norm:
        if r["id"] in combined:
            combined[r["id"]]["score"] += (1 - alpha) * r["score"]
        else:
            combined[r["id"]] = {"score": (1 - alpha) * r["score"], **r}
    
    sorted_items = sorted(
        combined.values(), key=lambda x: x["score"], reverse=True
    )
    return sorted_items
```

## 6. 完整混合检索示例

```python
# ===== 混合检索完整示例 =====
import numpy as np
import faiss
from rank_bm25 import BM25Okapi

class ProductionHybridSearch:
    """生产级混合检索"""
    
    def __init__(self, embed_fn, dim=1024):
        self.embed_fn = embed_fn
        self.dense_index = faiss.IndexFlatIP(dim)
        self.texts = []
        
        # BM25
        self.bm25 = None
        self.tokenized_corpus = []
    
    def index(self, documents):
        """索引文档"""
        # Dense 索引
        vectors = self.embed_fn([d["text"] for d in documents])
        vectors = np.array(vectors).astype('float32')
        faiss.normalize_L2(vectors)
        self.dense_index.add(vectors)
        
        # Sparse 索引
        self.tokenized_corpus = [
            d["text"].lower().split() for d in documents
        ]
        self.bm25 = BM25Okapi(self.tokenized_corpus)
        
        self.texts = documents
    
    def search(self, query, top_k=5):
        """混合检索"""
        q_vec = np.array(self.embed_fn(query)).astype('float32').reshape(1, -1)
        faiss.normalize_L2(q_vec)
        
        # Dense
        d_scores, d_indices = self.dense_index.search(q_vec, 20)
        
        # Sparse
        s_scores = self.bm25.get_scores(query.lower().split())
        s_indices = np.argsort(s_scores)[::-1][:20]
        
        # RRF 融合
        scores = {}
        for rank, idx in enumerate(d_indices[0], 1):
            scores[idx] = scores.get(idx, 0) + 1.0 / (60 + rank)
        for rank, idx in enumerate(s_indices, 1):
            scores[idx] = scores.get(idx, 0) + 1.0 / (60 + rank)
        
        top_ids = sorted(scores.items(), key=lambda x: x[1], reverse=True)[:top_k]
        
        return [
            {"text": self.texts[idx]["text"], "score": s}
            for idx, s in top_ids
        ]
```

## 核心要点回顾

- Dense（语义） + Sparse（关键词）= 混合检索 → 精度天花板最高
- RRF 是最常用的融合算法（无需调参，鲁棒性强）
- BM25 是关键词检索的事实标准
- 混合检索的核心价值：弥补 Dense 对专有名词/数字/代码的短板
- BGE-M3 一个模型同时输出 Dense + Sparse → 实现成本最低
