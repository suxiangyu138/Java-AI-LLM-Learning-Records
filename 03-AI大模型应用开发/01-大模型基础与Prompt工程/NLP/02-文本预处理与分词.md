## 1. 文本预处理管线

```text
标准 NLP 预处理管线：

  原始文本 → 清洗 → 分词 → 去停用词 → 词形还原/词干提取 → 向量化

各步骤说明：
  ① 清洗：去除 HTML/特殊符号/URL/表情符号
  ② 分词：将连续文本切分为词语单元
  ③ 去停用词：移除"的/了/是/the/a/an"等无意义高频词
  ④ 词形还原：把变形词还原为原形（running→run, 更好→好）
  ⑤ 向量化：将词转为数字（TF-IDF/Word2Vec/Embedding）
```

## 2. 中文分词

### 2.1 为什么中文分词更难

```text
英文：单词天然以空格分隔 → "I love NLP" → ["I", "love", "NLP"]
中文：连续书写，无分隔符 → "我爱自然语言处理" → 怎么切？

  可能切法：
    "我/爱/自然/语言/处理"
    "我/爱/自然语言/处理"
    "我爱/自然语言/处理"

  哪种对？→ 需要分词算法判断
```

### 2.2 jieba 分词

```python
import jieba

text = "我爱北京天安门"

# 精确模式（最常用）
words = jieba.lcut(text)
print(words)  # ['我', '爱', '北京', '天安门']

# 全模式（所有可能词）
words = jieba.lcut(text, cut_all=True)
print(words)  # ['我', '爱', '北京', '天安', '天安门']

# 搜索引擎模式
words = jieba.lcut_for_search(text)
print(words)  # ['我', '爱', '北京', '天安', '天安门']

# 自定义词典
jieba.add_word("自然语言处理")
jieba.suggest_freq("自然语言", tune=True)
```

### 2.3 分词算法原理

| 算法 | 原理 | 特点 |
|------|------|------|
| **最大匹配法** | 从左到右匹配最长词 | 简单快速 |
| **HMM** | 用隐马尔可夫模型标注 B/M/E/S | jieba 默认 |
| **CRF** | 条件随机场序列标注 | 精度更高 |
| **深度学习** | BiLSTM-CRF / BERT | 当前 SOTA |

## 3. 英文分词与词形还原

### 3.1 英文分词

```python
import nltk
from nltk.tokenize import word_tokenize, sent_tokenize

text = "Hello, world! NLP is amazing. Let's learn it."

# 分句
sentences = sent_tokenize(text)
# ['Hello, world!', 'NLP is amazing.', "Let's learn it."]

# 分词
words = word_tokenize(text)
# ['Hello', ',', 'world', '!', 'NLP', 'is', 'amazing', '.', 
#  'Let', "'s", 'learn', 'it', '.']
```

### 3.2 词干提取 vs 词形还原

```python
from nltk.stem import PorterStemmer, WordNetLemmatizer

# 词干提取（粗暴截断）
stemmer = PorterStemmer()
print(stemmer.stem("running"))    # run
print(stemmer.stem("studies"))    # studi（不一定是真词！）

# 词形还原（查词典，返回真词）
lemmatizer = WordNetLemmatizer()
print(lemmatizer.lemmatize("running", pos="v"))   # run
print(lemmatizer.lemmatize("better", pos="a"))    # good
```

| 方法 | 原理 | 速度 | 准确度 | 使用 |
|------|------|:---:|:---:|:---:|
| **词干提取** | 规则截断后缀 | 快 | 低 | 信息检索 |
| **词形还原** | 查词典+词性 | 慢 | 高 | **NLP 推荐** |

## 4. 停用词与文本清洗

```python
import re
from nltk.corpus import stopwords

# 中文停用词
chinese_stopwords = {'的', '了', '是', '在', '我', '有', '和', '就',
                     '不', '人', '都', '一', '一个', '上', '也', '很',
                     '到', '说', '要', '去', '你', '会', '着', '没有'}

def clean_text(text, lang='zh'):
    """通用文本清洗"""
    # 去除 URL
    text = re.sub(r'https?://\S+', '', text)
    # 去除 HTML 标签
    text = re.sub(r'<[^>]+>', '', text)
    # 去除特殊字符（保留中英文和数字）
    text = re.sub(r'[^一-鿿\w\s]', '', text)
    # 合并多余空格
    text = re.sub(r'\s+', ' ', text).strip()
    return text

def remove_stopwords(words, lang='zh'):
    """去停用词"""
    stop_set = chinese_stopwords if lang == 'zh' else set(stopwords.words('english'))
    return [w for w in words if w not in stop_set]
```

## 5. 子词分词 BPE

### 5.1 为什么需要子词分词

```text
传统分词的问题：
  → 词表有限 → OOV（Out-of-Vocabulary）问题
  → "transformer" 在词表中，"transformers" 不在 → 变成 [UNK]

BPE (Byte Pair Encoding) 的解决：
  → 用子词（subword）组合表示任意词
  → "transformers" → ["transform", "ers"]
  → 不存在 OOV 问题！

LLM 全部使用子词分词：
  GPT: BPE → 词表 50K~100K
  LLaMA: BPE → 词表 32K
```

### 5.2 BPE 训练过程

```text
BPE 训练（简化）：

① 初始词表 = 所有字符
② 统计相邻字符对出现频率
③ 合并最高频的字符对 → 新 token 加入词表
④ 重复 ②③ 直到达到目标词表大小

示例：
  初始："low" "lower" "newest" "widest"
  Step 1: 最高频 "e"+"s" → "es"
  Step 2: 最高频 "es"+"t" → "est"
  Step 3: 最高频 "l"+"o" → "lo"
  ...
  
  最终词表：包含 "low", "er", "est", "wid", "new", ...
```

### 5.3 Tokenizer 使用

```python
from transformers import AutoTokenizer

# GPT-2 的 BPE Tokenizer
tokenizer = AutoTokenizer.from_pretrained("gpt2")

text = "I love natural language processing!"
tokens = tokenizer.tokenize(text)
print(tokens)
# ['I', 'Ġlove', 'Ġnatural', 'Ġlanguage', 'Ġprocessing', '!']

ids = tokenizer.encode(text)
print(ids)  # [40, 1842, 4189, 3303, 8255, 0]
```

## 6. LLM 时代的预处理

```text
传统 NLP 预处理（LLM 之前）：
  清洗 → 分词 → 去停用词 → 词形还原 → 向量化
  → 步骤多、容易出错、损失信息

LLM 时代的预处理：
  原始文本 → Tokenizer → Token IDs
  → 几乎无需预处理！
  → BPE Tokenizer 自动处理分词/未知词/大小写

仍需注意：
  ✅ 特殊字符清理（某些模型对特殊字符敏感）
  ✅ 长度截断（超过 context window 需截断）
  ⚠️ 不需要去停用词！（停用词提供语法信息）
  ⚠️ 不需要词形还原！（BPE 能处理变形）
```

## 核心要点回顾

- 中文分词用 jieba，英文用 NLTK/spaCy
- 词形还原（lemmatization）优于词干提取（stemming）
- BPE 子词分词是现代 LLM 的标准，解决了 OOV 问题
- LLM 时代预处理极度简化：原始文本 → Tokenizer → Token IDs
- 不需要去停用词和词形还原（LLM 需要完整语法信息）
