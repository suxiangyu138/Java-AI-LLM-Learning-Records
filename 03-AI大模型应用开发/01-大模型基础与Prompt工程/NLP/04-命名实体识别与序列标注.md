## 1. 什么是 NER

```text
NER = Named Entity Recognition = 命名实体识别

输入："马云于1999年在杭州创立了阿里巴巴"

输出：
  马云     → PER (人名)
  1999年   → TIME (时间)
  杭州     → LOC (地名)
  阿里巴巴 → ORG (组织机构)

常见实体类型：
  PER (人名) / LOC (地名) / ORG (机构)
  TIME (时间) / DATE (日期) / MONEY (金额)
  领域特定：DRUG (药品)、LAW (法律条款)
```

## 2. 序列标注范式

### 2.1 IOB2 标注体系

```text
序列标注 = 给文本中的每个 token 打一个标签

IOB2 (Inside-Outside-Beginning) — 最常用的标签体系：

  B-PER：人名开始
  I-PER：人名内部
  B-LOC：地名开始
  I-LOC：地名内部
  O：非实体

示例：
  马    云    于    1999    年    在    杭州    创立
  B-PER I-PER O    B-TIME I-TIME O    B-LOC  O

标注规则：
  → 实体的第一个 token = B-XXX
  → 实体内部的 token = I-XXX
  → 单 token 实体也用 B-XXX
  → 非实体全部 = O
```

### 2.2 其他序列标注任务

| 任务 | 标签类型 | 示例 |
|------|----------|------|
| **NER** | PER/LOC/ORG... | 人名/地名/机构 |
| **POS 标注** | 名词/动词/形容词... | 词性标注 |
| **分词** | B/M/E/S | 中文分词 |
| **Chunking** | NP/VP/PP... | 短语识别 |

## 3. CRF 条件随机场

### 3.1 原理

```text
CRF (Conditional Random Field) = 序列标注的经典概率模型

核心思想：不仅考虑每个位置的"发射概率"，还考虑相邻标签间的"转移概率"

例如：B-PER 后面极大概率是 I-PER，不可能是 B-LOC
  → CRF 学习这种约束 → 输出合法标签序列

CRF 的数学：
  P(y|x) = exp(Σ 特征分数) / Z(x)
  
  特征分两类：
    发射特征：token_i → 标签_i（这个词更可能是人名？）
    转移特征：标签_{i-1} → 标签_i（前一标签到后一标签的可能性）
```

### 3.2 传统 CRF 的局限

```text
CRF 需要人工设计特征 → 特征工程工作量大
  → 用双向 LSTM 自动提取特征 → BiLSTM-CRF
  → 用 BERT 提取更深层特征 → BERT-CRF/BERT-NER
```

## 4. BiLSTM-CRF

### 4.1 架构

```text
BiLSTM-CRF = 双向 LSTM + CRF 层

  输入: "马云在杭州创立阿里巴巴"
    ↓
  Embedding 层（Word2Vec/Glove）
    ↓
  双向 LSTM（前向+后向 → 融合上下文）
    ↓
  CRF 层（约束标签转移 → 保证输出合法）
    ↓
  输出: B-PER I-PER O B-LOC O B-ORG I-ORG I-ORG I-ORG
```

### 4.2 为什么 BiLSTM-CRF 有效

```text
LSTM 负责：捕捉上下文 → "马云"后面是"创立" → 更像人名
CRF 负责：  学习标签约束 → I-PER 不能在 B-LOC 之后
两者互补 → 2017 年之前 NER 的 SOTA
```

## 5. BERT-NER

### 5.1 BERT 微调 NER

```python
from transformers import AutoTokenizer, AutoModelForTokenClassification
from transformers import pipeline

# 方法 1：使用 HuggingFace pipeline（最简单）
ner = pipeline("ner", model="dslim/bert-base-NER")

text = "马云于1999年在杭州创立了阿里巴巴"
results = ner(text)

for r in results:
    print(f"{r['word']}: {r['entity']} ({r['score']:.2f})")
# 马云: B-PER, 杭州: B-LOC, 阿里巴巴: B-ORG

# 方法 2：手动微调 BERT-NER

)
tokenizer = AutoTokenizer.from_pretrained("bert-base-chinese")

# 训练同标准分类任务，标签是 token 级别而非句子级别
```

### 5.2 BERT-NER vs BiLSTM-CRF

| 维度 | BiLSTM-CRF | BERT-NER |
|------|:---:|:---:|
| **Embedding** | 静态 (Word2Vec) | 上下文相关 (BERT) |
| **特征提取** | LSTM | Transformer Self-Attention |
| **标签约束** | CRF | CRF（通常也加上） |
| **OOV 处理** | 可能 [UNK] | BPE 子词 → 无 OOV |
| **F1 分数** | ~90% | ~94%+ |

## 6. LLM 时代的 NER

```text
传统 NER：训练专用模型 → 只能识别预定义的实体类型
LLM NER：Prompt → 可以识别任意类型，无需训练！

示例 Prompt：
  "从以下文本中提取所有人名、地名和组织机构名，用 JSON 格式返回：
  '马云于1999年在杭州创立了阿里巴巴'"

LLM 输出：
  {"PER": ["马云"], "LOC": ["杭州"], "ORG": ["阿里巴巴"], "TIME": ["1999年"]}

优势：
  ✅ 无需训练数据 → 零样本学习
  ✅ 可识别任意实体类型 → "找出所有技术名词"
  ✅ 可处理嵌套/模糊实体 → "阿里巴巴"既可以是公司也可以是故事名

局限：
  ⚠️ 速度慢（大模型推理 vs BERT 毫秒级）
  ⚠️ 可能不稳定（同样 Prompt 不同次可能输出不同）
  ⚠️ 成本高（API 调用费 vs 本地 BERT 免费）
```

---

## 核心要点回顾

- NER = 从文本中抽取命名实体（人名/地名/机构/时间）
- IOB2 标注 = 序列标注的标准格式（B-XXX / I-XXX / O）
- CRF 学习标签转移约束 → 保证输出合法标签序列
- BERT-NER 微调是传统 NER 的 SOTA（F1 94%+）
- LLM 时代：Prompt 即可做 NER，无需训练 → 灵活性大幅提升
