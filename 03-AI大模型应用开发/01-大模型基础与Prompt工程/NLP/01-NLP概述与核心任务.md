## 1. 什么是 NLP

```text
NLP = Natural Language Processing = 自然语言处理

交叉学科：计算机科学 + AI + 语言学

核心目标：让计算机能够
  ① 读懂人类语言（理解）
  ② 写出人类语言（生成）
  ③ 在不同语言间转换（翻译）
  ④ 从文本中提取结构化信息（抽取）
```

### NLP 的两大分支

| 分支 | 全称 | 核心能力 | 示例 |
|------|------|----------|------|
| **NLU** | Natural Language Understanding | 理解文本含义 | 分类、情感分析、NER |
| **NLG** | Natural Language Generation | 生成自然语言 | 摘要、翻译、对话 |

```text
传统 NLP：NLU 和 NLG 是分开的任务，需要不同模型
LLM 时代：一个 Decoder-Only 模型同时搞定 NLU + NLG
  → "总结这篇文章" = NLU(理解文章) + NLG(生成摘要) → 一个模型完成
```

## 2. NLU 自然语言理解

### 2.1 核心任务

| 任务 | 说明 | 输入 → 输出 | 示例 |
|------|------|------------|------|
| **文本分类** | 给文本打标签 | 文本 → 类别 | 垃圾邮件检测、新闻分类 |
| **情感分析** | 判断情感倾向 | 文本 → {正,负,中} | 商品评论分析 |
| **命名实体识别** | 抽取人名/地名/机构名 | 文本 → 实体列表 | "马云在杭州创立了阿里巴巴" → 马云(PER),杭州(LOC),阿里巴巴(ORG) |
| **关系抽取** | 识别实体间关系 | 文本 → 三元组 | "马云创办阿里巴巴" → (马云, 创办, 阿里巴巴) |
| **语义相似度** | 判断两段文本是否同义 | 文本对 → 相似度分数 | "怎么退款" vs "如何退货" → 高相似 |
| **自然语言推理** | 判断前提能否推出假设 | 前提+假设 → {蕴含,矛盾,中立} | NLI 任务 |

### 2.2 文本分类详解

```python
# 传统方式：TF-IDF + 分类器
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import LogisticRegression

texts = ["这个产品真好用", "太差了，后悔买", "一般般吧"]
labels = [1, 0, 1]  # 1=正面, 0=负面

vectorizer = TfidfVectorizer()
X = vectorizer.fit_transform(texts)
model = LogisticRegression().fit(X, labels)
```

## 3. NLG 自然语言生成

| 任务 | 说明 | 示例 |
|------|------|------|
| **文本摘要** | 长文本 → 短摘要 | 新闻自动摘要 |
| **机器翻译** | 语言 A → 语言 B | 中→英、英→中 |
| **对话生成** | 上下文 → 回复 | 聊天机器人 |
| **文本改写** | 同义改写/风格转换 | 正式→口语化 |
| **代码生成** | 自然语言 → 代码 | "写一个排序函数"→Python 代码 |

## 5. NLP 的挑战

| 挑战 | 说明 | LLM 时代的缓解程度 |
|------|------|:---:|
| **歧义性** | "我喜欢吃苹果"=水果还是公司？ | ⭐⭐⭐⭐（上下文理解强） |
| **指代消解** | "他把它放在了那里" — 谁？什么？哪里？ | ⭐⭐⭐⭐ |
| **长距离依赖** | 段落开头的主语，段落末尾还能不能对上 | ⭐⭐⭐⭐（Self-Attention） |
| **多语言** | 不同语言的语法、分词、文化差异 | ⭐⭐⭐（多语言 LLM） |
| **常识推理** | "下雨天要带伞" — 机器不知道什么是下雨 | ⭐⭐⭐（仍会出错） |
| **数据稀疏** | 长尾语言/领域的数据不够 | ⭐⭐⭐（迁移学习） |

## 核心要点回顾

- NLP = NLU（理解）+ NLG（生成），LLM 将两者统一
- NLU 核心任务：文本分类、情感分析、NER、语义相似度
- NLG 核心任务：摘要、翻译、对话、代码生成
- LLM 通过 Prompt 统一了所有 NLP 任务 — 不再需要为每个任务训练专用模型
- NLP 的最大挑战：歧义性、常识推理、长距离依赖
