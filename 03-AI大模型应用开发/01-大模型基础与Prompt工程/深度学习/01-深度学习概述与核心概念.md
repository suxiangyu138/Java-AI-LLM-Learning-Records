## 1. 什么是深度学习

```text
深度学习 (Deep Learning) = 使用多层神经网络的机器学习方法

"深度" = 网络的层数多（数十到数百层）

核心优势：自动学习特征层次结构
  → 浅层：边缘、纹理
  → 中层：形状、部件
  → 深层：语义、概念

不需要人工设计特征 — 这是深度学习革命性的原因
```

---

## 2. 三大驱动力

```text
深度学习爆发的三大驱动力：

  ① 大数据（Big Data）
    ImageNet (1400万张图片) / 互联网文本 / 用户行为数据
    → 浅层模型在数据量增大时性能饱和
    → 深层模型随数据增加持续提升

  ② 大算力（GPU）
    NVIDIA CUDA (2006) → GPU 并行计算 → 训练速度提升 10-100×
    → AlexNet 是第一个用 GPU 训练的深度网络

  ③ 算法突破（Algorithms）
    ReLU 激活函数 → 解决梯度消失
    Dropout / BatchNorm → 防止过拟合
    ResNet 残差连接 → 训练 100+ 层网络
    Adam 优化器 → 加速收敛
```

## 3. 关键里程碑

| 年份 | 事件 | 意义 |
|:---:|------|------|
| 1986 | 反向传播算法提出 | 多层网络训练的理论基础 |
| 1998 | LeNet-5 (LeCun) | 第一个成功的 CNN，手写数字识别 |
| 2006 | Deep Belief Network (Hinton) | "深度学习"术语诞生 |
| **2012** | **AlexNet 赢得 ImageNet** | **深度学习爆发元年！** 错误率从 26%→16% |
| 2014 | GAN (Goodfellow) | 生成模型新范式 |
| 2015 | ResNet (He et al.) | 152 层网络，超越人类水平 |
| 2017 | Transformer | NLP 的 ImageNet 时刻 |
| 2018 | BERT / GPT | 预训练时代开启 |
| 2022 | ChatGPT | LLM 走向大众 |

## 4. 深度学习 vs 传统 ML

| 维度 | 传统 ML | 深度学习 |
|------|---------|----------|
| **特征工程** | 人工设计（关键！） | 自动学习 |
| **数据需求** | 几百~几万 | 几万~亿级 |
| **硬件** | CPU | GPU/TPU |
| **可解释性** | 高（决策树/逻辑回归） | 低（黑盒） |
| **训练时间** | 秒~分钟 | 小时~月 |
| **擅长领域** | 表格数据 | 图像/语音/文本 |
| **代表算法** | SVM/XGBoost/RF | CNN/RNN/Transformer |

## 5. 训练全景

```text
深度学习训练的三要素：

  ① 模型架构（Architecture）
    → CNN（图像）/ RNN（序列）/ Transformer（通用）
    → 决定"模型能表示什么"

  ② 损失函数（Loss Function）
    → 分类：CrossEntropy / 回归：MSE
    → 决定"模型在优化什么"

  ③ 优化算法（Optimizer）
    → SGD / Adam / AdamW
    → 决定"怎么更新参数"

训练循环：
  for epoch in range(N):
      for batch in dataloader:
          pred = model(batch)          # 前向
          loss = criterion(pred, y)    # 计算损失
          loss.backward()              # 反向传播
          optimizer.step()             # 更新参数
```

## 核心要点回顾

- 深度学习 = 多层神经网络 + 自动特征学习
- 三大驱动力：大数据 + GPU + 算法突破
- 2012 AlexNet = 深度学习爆发元年
- DL vs ML：DL 不需要人工特征工程，但需要更多数据和算力
- 训练三要素：架构 + 损失函数 + 优化器
