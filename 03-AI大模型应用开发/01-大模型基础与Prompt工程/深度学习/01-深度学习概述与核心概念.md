## 1. 什么是深度学习

```text
深度学习 (Deep Learning) = 使用多层神经网络的机器学习方法

"深度" = 网络的层数多（数十到数百层）

核心优势：自动学习特征层次结构
  → 浅层：边缘、纹理
  → 中层：形状、部件
  → 深层：语义、概念

不需要人工设计特征 — 这是深度学习革命性的原因
```

---

## 2. 三大驱动力

```text
深度学习爆发的三大驱动力：

  ① 大数据（Big Data）
    ImageNet (1400万张图片) / 互联网文本 / 用户行为数据
    → 浅层模型在数据量增大时性能饱和
    → 深层模型随数据增加持续提升

  ② 大算力（GPU）
    NVIDIA CUDA (2006) → GPU 并行计算 → 训练速度提升 10-100×
    → AlexNet 是第一个用 GPU 训练的深度网络

  ③ 算法突破（Algorithms）
    ReLU 激活函数 → 解决梯度消失
    Dropout / BatchNorm → 防止过拟合
    ResNet 残差连接 → 训练 100+ 层网络
    Adam 优化器 → 加速收敛
```

## 4. 深度学习 vs 传统 ML

| 维度 | 传统 ML | 深度学习 |
|------|---------|----------|
| **特征工程** | 人工设计（关键！） | 自动学习 |
| **数据需求** | 几百~几万 | 几万~亿级 |
| **硬件** | CPU | GPU/TPU |
| **可解释性** | 高（决策树/逻辑回归） | 低（黑盒） |
| **训练时间** | 秒~分钟 | 小时~月 |
| **擅长领域** | 表格数据 | 图像/语音/文本 |
| **代表算法** | SVM/XGBoost/RF | CNN/RNN/Transformer |

## 5. 训练全景

```text
深度学习训练的三要素：

  ① 模型架构（Architecture）
    → CNN（图像）/ RNN（序列）/ Transformer（通用）
    → 决定"模型能表示什么"

  ② 损失函数（Loss Function）
    → 分类：CrossEntropy / 回归：MSE
    → 决定"模型在优化什么"

  ③ 优化算法（Optimizer）
    → SGD / Adam / AdamW
    → 决定"怎么更新参数"

训练循环：
  for epoch in range(N):
      for batch in dataloader:
          pred = model(batch)          # 前向
          loss = criterion(pred, y)    # 计算损失
          loss.backward()              # 反向传播
          optimizer.step()             # 更新参数
```

## 6. 前向传播与反向传播

```text
训练的两个阶段（面试必画）：

前向传播（Forward）：
  x → 第一层 → 第二层 → ... → 输出 y_hat
  每层：z = W·x + b → a = activation(z)
  最后：计算损失 loss = L(y_hat, y_true)

反向传播（Backward）—— 链式法则：
  从输出层往回，逐层计算损失对各参数的梯度：
    ∂L/∂Wₗ = ∂L/∂aₗ × ∂aₗ/∂zₗ × ∂zₗ/∂Wₗ
  梯度 = 损失对参数的"影响方向" → 更新：W ← W - lr × ∂L/∂W

为什么"深"难训：
  深层梯度是各层梯度的连乘 → 层数越多越容易消失/爆炸
  → 这是 ReLU/残差/归一化存在的原因（贯穿本体系的线索）
```

**训练循环的标准形态**（PyTorch）：

```python
for epoch in range(N):
    for x, y in dataloader:
        pred = model(x)              # 前向
        loss = criterion(pred, y)    # 损失
        loss.backward()              # 反向传播（自动微分）
        optimizer.step()             # 参数更新
        optimizer.zero_grad()        # 梯度清零（防累积）
```

## 7. 激活函数与损失函数家族

**激活函数（引入非线性）**：

| 函数 | 公式 | 特点 | 使用 |
|------|------|------|------|
| ReLU | max(0, x) | 简单快、缓解消失；缺点：死亡神经元 | CNN 标配 |
| LeakyReLU | 负区间小斜率 | 防死亡 | 变体场景 |
| GELU | 平滑近似 ReLU | 平滑、LLM 标准 | **Transformer 标配** |
| SwiGLU | 门控线性单元 | 更强表达（LLaMA 使用） | 现代 LLM |
| Sigmoid/Tanh | S 形 | 梯度易消失 | 门控/归一化内部 |

**损失函数（优化目标）**：

| 任务 | 损失 | 说明 |
|------|------|------|
| 分类 | CrossEntropy | LLM 预训练/微调标配 |
| 回归 | MSE/MAE | 连续值预测 |
| 对比学习 | InfoNCE | 向量表征（Embedding） |
| 对齐 | RLHF 的 PPO 目标 | 奖励 + KL 惩罚 |

> 🎯 **核心要点**：激活函数看"梯度特性"（消失/死亡）、损失函数看"任务语义"——**从 ReLU 到 GELU/SwiGLU 的演进就是 LLM 架构史的一角**；反向传播是深度学习的一切基础（手推公式见 `ML基础/`）。

## 8. 过拟合与正则化

**过拟合 = 训练集表现好、测试集差**——深度学习头号问题：

| 正则化手段 | 原理 | 使用时机 |
|-----------|------|---------|
| 更多数据/增强 | 数据分布更完整 | **最优先** |
| Dropout | 随机丢弃神经元（防共适应） | 全连接层标配 |
| Weight Decay（L2） | 权重向 0 收缩 | AdamW 内建 |
| BatchNorm/LayerNorm | 归一化层输入（稳定性） | 架构标配 |
| 早停（Early Stopping） | 验证集不升即停 | 万能兜底 |

```python
# PyTorch 组合（标准配置）
model = nn.Sequential(
    nn.Linear(128, 64),
    nn.ReLU(),
    nn.Dropout(0.3),            # 丢弃率 0.3
)
optimizer = torch.optim.AdamW(model.parameters(), lr=1e-3, weight_decay=1e-4)
# 判断过拟合：训练 loss 降、验证 loss 升 → 加正则化/数据
```

> 🎯 **核心要点**：过拟合的处理顺序 = **先加数据（增强），不够加正则化（Dropout/WeightDecay），最后简化模型**——正则化是手段不是目的，别一上来就堆（详见 `08-训练技巧与调参实战.md`）。
