## 1. CNN 相关

### Q1: 卷积层和全连接层有什么区别？

```text
全连接：每个输出神经元连接所有输入神经元
  → 参数量巨大（W×H×C× neurons）
  → 丢失空间结构

卷积层：局部连接 + 权重共享
  → 参数量小（kernel²× channels）
  → 保留空间结构、平移不变性

举例：224×224×3 → 1000 个神经元
  全连接：224×224×3×1000 = 1.5 亿参数
  卷积(3×3, 64核)：3×3×3×64 = 1728 参数
```

### Q2: 1×1 卷积有什么用？

```text
① 升降维：改变通道数而不改变空间尺寸
② 跨通道信息融合：学习通道间的线性组合
③ 减少参数量：在 3×3 之前先用 1×1 降维 → 参数量大幅减少
④ 增加非线性：1×1 Conv + ReLU = 额外的非线性变换

Inception/ResNet 中大量使用 1×1 卷积
```

### Q3: BatchNorm 的原理和作用？

```text
BatchNorm = 对每个特征在 batch 维度做归一化

  μ = mean(x_batch)
  σ² = var(x_batch)
  x̂ = (x - μ) / √(σ² + ε)
  y = γ × x̂ + β  (γ,β 可学习)

作用：
  ✅ 加速收敛（梯度更稳定）
  ✅ 允许更大学习率
  ✅ 轻微正则化效果
  ✅ 减少对初始化的敏感度

LLM 不用 BatchNorm → 用 LayerNorm（不依赖 batch_size）
```

## 2. RNN/LSTM 相关

### Q4: 标准 RNN 有什么问题？LSTM 怎么解决的？

```text
RNN 问题：梯度消失/爆炸
  → 反向传播时梯度跨时间步连乘
  → tanh 导数 < 1 → 连续乘 → 趋零 → 长距离依赖丢失

LSTM 解决：门控机制 + 细胞状态
  → 遗忘门：控制丢弃哪些旧信息
  → 输入门：控制加入哪些新信息
  → 输出门：控制输出哪些信息
  → 细胞状态 Cₜ：信息可以无损直通（fₜ≈1 时）

  Cₜ 的存在让梯度可以跨越数百时间步 → 解决长距离依赖
```

### Q5: LSTM 和 GRU 的区别？

```text
LSTM：3 个门（遗忘/输入/输出）+ 细胞状态
GRU：2 个门（重置/更新）+ 无独立细胞状态

GRU 优势：参数少、训练快、小数据上常优于 LSTM
LSTM 优势：表达能力强、大数据上更可靠

选择：不确定时先用 LSTM，追求效率用 GRU
```

## 3. GAN 相关

### Q6: GAN 的训练过程是什么？为什么难训练？

```text
训练交替进行：
  ① 训练 D：真样本→高分，假样本→低分
  ② 训练 G：生成假样本→让 D 打高分
  → 博弈 → 纳什均衡

难训练的原因：
  → 无稳定收敛保证（博弈不一定有均衡）
  → 模式崩塌（G 只学会少数模式）
  → 梯度消失（D 太强 → G 梯度为零）
  → 震荡（G 和 D 互相追赶）

改善方法：WGAN（Wasserstein距离）、梯度惩罚、谱归一化
```

### Q7: 什么是模式崩塌 (Mode Collapse)？

```text
模式崩塌 = G 只学会生成训练数据中的少数模式

  训练数据：猫、狗、鸟、马的图片（4 种模式）
  崩塌后：G 只生成猫（1 种模式）

原因：G 找到一个能骗过 D 的模式后就"躺平"了
      D 还没来得及学会识破 → G 已经固定在这个模式

解决：Minibatch Discrimination / Unrolled GAN / WGAN
```

## 4. 训练技巧相关

### Q8: 学习率太大/太小会怎样？

```text
太大：震荡/发散 → Loss 不降反升 → 参数越更新越远
太小：收敛太慢 → 训练到天荒地老 → 可能陷入局部最优

经验法则（LLM 微调）：
  全量微调：1e-5 ~ 5e-5
  LoRA 微调：1e-4 ~ 5e-4
  从零训练：1e-3 ~ 1e-4

调参方法：先用大范围搜索（1e-5, 1e-4, 1e-3）→ 找到最优区间 → 细调
```

### Q9: 为什么要用 Warmup？

```text
训练初期参数随机 → 梯度方向不可靠
大 lr 可能导致训练初期的剧烈震荡

Warmup：前 N 步 lr 从 0 线性增加到目标值
  → 让模型先"站稳脚跟"
  → 再加速训练

LLM 训练必用 Warmup（预训练 2000-4000 step，微调 100-500 step）
```

### Q10: 过拟合有哪些迹象？怎么解决？

```text
迹象：
  → Train Loss 持续下降，Val Loss 上升（经典信号）
  → Train-Val 差距越来越大
  → 模型在训练集上完美，新数据上一塌糊涂

解决方案（优先级从高到低）：
  ① 加数据（数据增强/收集更多数据）
  ② 加正则化（Dropout/L2/Label Smoothing）
  ③ Early Stopping
  ④ 减少模型复杂度
  ⑤ 加噪声（输入噪声/权重噪声）
```

## 高频追问速答（10 条）

| 追问 | 速答 |
|------|------|
| 为什么 ReLU 比 sigmoid 好？ | 缓解梯度消失（导数恒 1）+ 计算快 + 稀疏激活；缺点：死亡神经元（负区间梯度 0）→ LeakyReLU/GELU |
| BatchNorm 的作用？ | 归一化层输入 → 加速收敛 + 缓解内部协变量偏移；注意：LLM 用 LayerNorm（BN 对序列/变长不友好） |
| 过拟合先做什么？ | 加数据 > 数据增强 > 正则化（dropout/weight decay）> 简化模型——按成本顺序 |
| 学习率怎么定？ | Warmup 起步 + Cosine 衰减；太大发散、太小收敛慢；学习率是最重要的超参数 |
| 梯度消失的本质？ | 反向传播连乘 <1 → 深层梯度趋 0；解法：残差连接 + 归一化 + 合适激活 |
| 混合精度为什么快？ | bf16/fp16 计算与显存减半 + 张量核加速；bf16 动态范围大（LLM 首选） |
| 为什么 LLM 用 AdamW 不用 SGD？ | 自适应学习率（每参数）+ 解耦权重衰减；SGD 需要精细调参（大模型不现实） |
| 微调和从零训练学习率差多少？ | 10-100 倍——微调小 lr（2e-5~2e-4），防灾难性遗忘 |
| 模型"不会了"（遗忘）怎么办？ | 小 lr + 早停 + LoRA（只更新少量参数）+ 回放旧数据 |
| 训练不收敛先查什么？ | ① loss 是否下降 ② 梯度范数是否爆炸（clip）③ 数据/标签是否正确 ④ 学习率是否合适 |

> 💡 十问覆盖面试官"随口追问"——每题一句话定性，展开细节对应本体系各模块。

## 核心要点回顾

- CNN：卷积+池化 → 局部性+平移不变性 → CV 基础
- LSTM：门控+细胞状态 → 解决梯度消失 → 启发了残差连接
- GAN：生成器+判别器博弈 → 训练不稳定 → 已被扩散模型取代
- Warmup + Cosine LR + Gradient Clip = LLM 训练三件套
- 过拟合先加数据，不够再加正则化
