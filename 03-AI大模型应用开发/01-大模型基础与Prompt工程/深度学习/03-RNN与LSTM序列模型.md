## 1. 为什么需要 RNN

```text
传统神经网络（MLP/CNN）的局限：
  → 输入和输出长度固定
  → 不同位置的输入独立处理 → 无法捕捉序列中的前后依赖

RNN 的核心创新：引入"隐藏状态"，携带之前的信息

  输入序列：x₁ → x₂ → x₃ → ... → xₜ
  隐藏状态：h₀ → h₁ → h₂ → h₃ → ... → hₜ
                       ↑ 每个 h 融合了当前输入和历史的 h
```

## 2. 基础 RNN

### 2.1 公式

```text
RNN 的核心公式：

  hₜ = tanh(W_h × hₜ₋₁ + W_x × xₜ + b)

  当前隐藏状态 = 前一步的隐藏状态（历史信息）+ 当前的输入

所有时间步共享同一组权重 → 参数不随序列长度增长
```

### 2.2 致命问题：梯度消失/爆炸

```text
反向传播时，梯度通过时间步连乘：

  ∂L/∂h₁ = ∂L/∂hₜ × ∏(∂hᵢ/∂hᵢ₋₁)

  如果 |∂hᵢ/∂hᵢ₋₁| < 1 → 连乘趋 0 → 梯度消失 → 长距离依赖丢失
  如果 |∂hᵢ/∂hᵢ₋₁| > 1 → 连乘趋 ∞ → 梯度爆炸

  实际中 tanh 的导数 < 1 → 梯度几乎总是消失
  → 标准 RNN 只能记住 ~10 步以内的信息
```

## 3. LSTM 长短期记忆

### 3.1 核心思想：门控机制

```text
LSTM (Hochreiter & Schmidhuber, 1997)：
  用"门"来控制信息的流动 — 记住什么、忘记什么、输出什么

三个门 + 一个细胞状态：

  遗忘门：fₜ = σ(W_f × [hₜ₋₁, xₜ])
    → 决定丢弃细胞状态中的哪些信息

  输入门：iₜ = σ(W_i × [hₜ₋₁, xₜ])
    → 决定将哪些新信息存入细胞状态

  输出门：oₜ = σ(W_o × [hₜ₋₁, xₜ])
    → 决定输出哪些信息作为隐藏状态

  细胞状态 Cₜ = fₜ × Cₜ₋₁ + iₜ × C̃ₜ
    → 长期记忆通道（梯度可以无损直通！）
```

### 3.2 为什么 LSTM 解决了梯度消失

```text
细胞状态 Cₜ 的更新：

  Cₜ = fₜ × Cₜ₋₁ + iₜ × C̃ₜ

  如果 fₜ ≈ 1（遗忘门打开）：
    → Cₜ ≈ Cₜ₋₁ → 梯度可以近乎无损地跨时间步传播
    → 这就是 LSTM 能处理长序列的关键！
  
  这一设计直接启发了 Transformer 的残差连接
```

### 3.3 LSTM 的局限

```text
LSTM 的问题 → 直接催生了 Transformer：

  ❌ 串行处理：必须等 hₜ₋₁ 算完才能算 hₜ → 无法并行
  ❌ 长序列仍然吃力（>100 步后梯度还是会衰减）
  ❌ 训练慢（BPTT 展开 N 步 = N 次串行计算）

  Transformer 的替代：用 Self-Attention 一步计算所有位置的关系
```

## 4. GRU 门控循环单元

```text
GRU (Gated Recurrent Unit) = LSTM 的简化版

  → 只有两个门（重置门 + 更新门）
  → 合并细胞状态和隐藏状态
  → 参数更少，训练更快
  → 小数据集上常优于 LSTM
```

| 维度 | RNN | LSTM | GRU |
|------|:---:|:---:|:---:|
| 门数量 | 0 | 3 | 2 |
| 长期记忆 | ❌ | ✅ | ✅ |
| 参数量 | 少 | 多 | 中 |
| 训练速度 | 快 | 慢 | 中 |

## 5. 双向 RNN 与堆叠

```text
双向 RNN (BiRNN / BiLSTM)：
  → 一层读正向序列 + 一层读反向序列
  → 每个位置同时拥有上文和下文信息
  → NER、文本分类标配

堆叠 RNN (Stacked RNN)：
  → 多层 RNN 堆叠 → 学更深层特征
  → 每层的输出作为下一层的输入
  → 2-4 层常见
```

## 6. 从 RNN 到 Transformer

```text
RNN → LSTM → Attention → Transformer：一条清晰进化线

  RNN：序列建模 → 梯度消失
  LSTM：门控 → 缓解但不根治
  Seq2Seq + Attention：注意力补充 → 部分并行
  Transformer：纯注意力 → 完全并行 ✅

核心跃迁：
  RNN 的核心循环 hₜ = f(hₜ₋₁, xₜ)（串行）
  替换为 Attention(Q, K, V) = softmax(QKᵀ/√d)V（并行）

LLM 时代 RNN 的遗产：
  → LSTM 的门控思想 → 启发了 GELU/SwiGLU 激活函数
  → 细胞状态 Cₜ 的直通设计 → 启发了残差连接
  → RNN 是理解"序列模型"的思维起点
```

---

## 核心要点回顾

- RNN = 隐藏状态传递历史信息，但梯度消失/爆炸致命
- LSTM = 三个门 + 细胞状态 → 信息可以跨时间步直通
- LSTM 的串行处理催生了 Transformer 的并行 Self-Attention
- 理解 RNN 的痛点 = 理解 Transformer 为什么是革命
- LSTM 的门控思想 + 细胞状态直通 → 现代架构的灵感源泉
