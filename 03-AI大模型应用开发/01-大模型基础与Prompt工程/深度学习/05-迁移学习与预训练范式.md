## 1. 什么是迁移学习

```text
迁移学习 (Transfer Learning)：
  将源任务/源领域学到的知识，迁移到目标任务/目标领域

传统 ML：每个任务从零训练
  任务 A → 模型 A（从零训练）
  任务 B → 模型 B（从零训练）

迁移学习：先学通用知识，再适配
  大规模源数据 → 预训练模型 → 适配任务 A（微调）
                            → 适配任务 B（微调）
                            → 适配任务 C（微调）
```

### 为什么有效

```text
深度学习的层次化特征：
  
  浅层特征（通用）：边缘、纹理、基本语法
    → 在不同任务间可以共享

  深层特征（专用）：物体部件、语义、任务特定模式
    → 需要针对具体任务调整

迁移学习 = 复用浅层通用特征，微调深层专用特征
```

## 2. 三种迁移策略

### 2.1 策略对比

| 策略 | 做法 | 适用场景 |
|------|------|----------|
| **Feature Extraction** | 冻结预训练模型，只训练新分类头 | 目标任务数据很少（<1000） |
| **Fine-Tuning** | 用预训练权重初始化，全部参数参与训练 | 目标任务数据充足（>5000） |
| **Progressive Unfreezing** | 逐层解冻，先训顶层再训底层 | 数据量居中，平衡效果和速度 |

### 2.2 Feature Extraction

```python
import torch.nn as nn
from transformers import AutoModel

# 冻结预训练模型，只训练分类头
model = AutoModel.from_pretrained("bert-base-chinese")

# 冻结所有参数
for param in model.parameters():
    param.requires_grad = False

# 添加新的分类头（可训练）
classifier = nn.Sequential(
    nn.Linear(768, 256),
    nn.ReLU(),
    nn.Dropout(0.3),
    nn.Linear(256, num_classes)
)

# 只有 classifier 的参数会被更新
```

### 2.3 Fine-Tuning（BERT 微调 = 迁移学习）

```python
# 全部参数参与训练，但用很小的学习率
model = AutoModelForSequenceClassification.from_pretrained(
    "bert-base-chinese", num_labels=3
)

# 不同层用不同学习率（Discriminative Fine-Tuning）
optimizer = AdamW([
    {'params': model.bert.encoder.layer[:8].parameters(), 'lr': 1e-5},
    {'params': model.bert.encoder.layer[8:].parameters(), 'lr': 2e-5},
    {'params': model.classifier.parameters(), 'lr': 5e-5},
])
```

## 3. 微调策略详解

### 3.1 学习率选择

```text
迁移学习的黄金法则：学习率应该比从零训练小 10-100×

  原因：预训练权重已经在一个"好位置"
        太大的学习率会破坏预训练学到的知识

  典型学习率：
    特征提取（只训分类头）：1e-3 ~ 1e-4
    全量微调：1e-5 ~ 5e-5
    LoRA 微调：1e-4 ~ 5e-4
```

### 3.2 灾难性遗忘

```text
灾难性遗忘（Catastrophic Forgetting）：
  在新任务上微调后，模型丢失了预训练学到的通用能力

防控手段：
  ✅ 使用小学习率
  ✅ 混合回放（训练数据中混入 5-10% 通用数据）
  ✅ Early Stopping（epoch=1~3）
  ✅ LoRA（冻结基座权重，从根本上避免）
```

## 4. 领域自适应

```text
领域自适应 (Domain Adaptation) = 训练数据和测试数据分布不同时的迁移

  源域（有标注）：新闻文章 → 已标注情感
  目标域（无/少标注）：产品评论 → 没标注但要做情感分析

方法：
  → 对抗训练：让模型学"领域无关"的特征
  → 渐进式微调：先在大规模目标域无标注数据上继续预训练
  → 数据增强：让源域数据更像目标域

LLM 的优势：预训练覆盖了极广的领域 → 天然的领域自适应能力
```

## 5. 迁移学习 = LLM 的底座

```text
LLM 的训练流程 = 迁移学习的终极形态：

  预训练（万亿 token 通用数据）
    → 学到通用语言能力
    ↓
  SFT 微调（万条指令数据）
    → 迁移到指令遵循任务
    ↓
  RLHF 对齐（人类偏好数据）
    → 迁移到对齐人类偏好

每一步都是迁移学习！

LLM Prompt = 零样本迁移学习：
  不给训练数据，只靠 Prompt 描述任务
  → 模型的预训练知识直接迁移到新任务
```

## 6. 预训练范式的完整演进

```text
预训练范式的三阶段（理解 LLM 时代的迁移学习全貌）：

① 经典预训练（2018-2022）：BERT/GPT-1/2
   预训练（无监督）→ 微调（下游任务）
   范式特点：每个下游任务都要微调一份模型

② 指令微调（2022-2023）：InstructGPT / ChatGPT
   预训练 → SFT（指令数据）→ RLHF（对齐）
   范式特点：一个模型通吃多种任务（指令遵循）

③ 大模型原生（2023+）：GPT-4 / Claude / DeepSeek
   预训练（强化）→ 多阶段对齐 → 推理时学习（RAG/工具/上下文）
   范式特点：微调不再是唯一迁移手段 —— Prompt/RAG 成为主流
```

**参数高效微调（PEFT）——LLM 时代的微调主流**：

| 方法 | 原理 | 参数量 | 适用 |
|------|------|:------:|------|
| 全量微调 | 更新全部参数 | 100% | 领域差距大/资源充足 |
| **LoRA** | 低秩分解增量矩阵 | **~1%** | **最主流（消费级 GPU 可跑）** |
| QLoRA | LoRA + 4bit 量化 | ~0.1% | 单卡微调 70B 模型 |
| Adapter | 插入小适配层 | ~2-5% | 多任务场景 |

```python
# LoRA 微调（PEFT 库，一行切换）
from peft import LoraConfig, get_peft_model

lora = LoraConfig(r=8, lora_alpha=32, target_modules=["q_proj", "v_proj"])
model = get_peft_model(base_model, lora)    # 只训练 LoRA 增量
```

> 💡 **面试题**："迁移学习在 LLM 时代还重要吗？"——**重要且更复杂了**：LoRA 微调（参数级迁移）+ Prompt（零样本迁移）+ RAG（检索式迁移）三线并存，传统"微调"只是其中之一（详见 `LLM/05-预训练与微调技术.md` 与 `01-大模型基础与Prompt工程/Prompt工程/`）。

## 核心要点回顾

- 迁移学习 = 复用预训练知识，适配新任务
- 三种策略：特征提取（冻结）/ 微调（全参）/ 逐层解冻（折中）
- 微调学习率 = 从零训练的 10-100× 更小
- 灾难性遗忘的解法：小 lr + 早停 + LoRA
- LLM 的训练流程（预训练→SFT→RLHF）= 多阶段迁移学习
