## 1. 高频面试题

### Q1（⭐⭐⭐⭐⭐）: Transformer 的 Self-Attention 是怎么计算的？

> Self-Attention 分四步：
> 1. 输入 X 通过 W_Q/W_K/W_V 投影得到 Q, K, V
> 2. 计算 Q 和 K 的点积，除以 √d_k（防梯度消失）
> 3. Softmax 得到注意力权重
> 4. 用权重加权求和 V
>
> 公式：`Attention(Q,K,V) = Softmax(QKᵀ/√d_k)·V`

### Q2: RLHF 的完整流程？

> 1. **SFT**：用人工撰写的指令-回答对微调基础模型
> 2. **训练奖励模型 (RM)**：收集偏好数据（人工选更好的回答），训练 RM 给回答打分
> 3. **PPO 强化学习**：用 RM 的分数优化模型，加 KL 惩罚防止偏离太远
> 4. **DPO 替代方案**：跳过 RM+PPO，直接从偏好数据优化（更简单稳定）

### Q3: LoRA 的原理？和全参数微调的区别？

> LoRA：冻结原模型，旁路插入低秩矩阵 A·B，只训练 A 和 B
> - 训练参数：原模型的 0.1%-1%
> - 7B LoRA 只需 4GB 显存（全参数要 56GB）
> - QLoRA = LoRA + 4-bit 量化 → 单卡微调 70B

### Q4: KV Cache 是什么？为什么重要？

> - 生成每个新 token 时，不用重算之前所有 token 的 K,V
> - 直接读缓存，计算量从 O(N²) 降到 O(N)
> - 长上下文的显存瓶颈：不是模型权重，是 KV Cache
> - GQA（分组查询注意力）= 多个 Q 头共享 K/V → 减少 KV Cache

### Q5: RAG 和微调怎么选？

| 维度 | RAG | 微调 |
|------|-----|------|
| 知识更新 | 实时（改向量库） | 需重新训练 |
| 知识来源 | 可溯源（有文档依据） | 融入模型，不可溯源 |
| 幻觉控制 | 更好 | 一般 |
| 成本 | 低 | 中-高 |
| 适用 | 知识库问答 | 风格/格式/术语定制 |
| 推荐 | 两者结合：微调定制风格 + RAG 注入知识 |

### Q6: 怎么评估一个 LLM 好不好？

> 1. 基准测试：MMLU（知识）+ HumanEval（代码）+ GSM8K（数学）
> 2. Arena 排名：真实用户偏好投票
> 3. 自建评估集：20-50 条覆盖核心业务场景
> 4. 多维评估：准确性 + 格式遵循 + 安全性 + 延迟 + 成本

### Q7: 模型幻觉怎么解决？

> 1. **RAG**：给模型外挂知识库，查到的才说（最好）
> 2. **Prompt**：明确说"不知道就说不知道"
> 3. **微调**：用"拒绝回答"的数据做 SFT
> 4. **后处理**：事实性校验（用搜索引擎验证关键事实）
> 5. **选模型**：推理模型（DeepSeek R1/GPT-5.5）幻觉率更低
