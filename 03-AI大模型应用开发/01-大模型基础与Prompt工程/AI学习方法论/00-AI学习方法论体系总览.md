## 3. 推荐阅读顺序

### 🟢 入门（先建立正确认知）

```

产出：知道怎么用 AI 是对的、怎么用是错的
```

### 🔵 核心方法（每天都要用的）

```
02-结构化提问 → 07-Prompt工程技巧 → 03-调试 → 04-刷题 → 05-源码阅读
产出：5 种高频场景的 AI 辅助方法论
```

### 🟣 工具与效率（提升系统化能力）

```
06-工具组合 → 11-环境配置 → 08-工作流 → 10-效率量化 → 12-进阶玩法
产出：完整的 AI 辅助学习系统
```

> 🎯 核心公式：**学习效率 = 输入质量 × 输出频率 × 迭代速度**。AI 放大的是后两个因子。
