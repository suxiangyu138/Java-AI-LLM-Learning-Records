## 1. 矩阵与向量基础

### 1.1 向量：AI 中的数据原子

```text
向量 = 一组有序数字，是 AI 中最基本的数据单元

在 LLM 中：
  词向量（Embedding）："猫" → [0.23, -0.45, 0.78, ..., 0.12]  (768~4096 维)
  隐藏状态：     Transformer 每层的输出 → 同等维度的向量
  注意力权重：   一个 token 对所有 token 的关注度 → 非负向量

向量运算是 LLM 运算的基本单位：
  → 点积：计算两个 token 的相似度（Attention 打分）
  → 加法：残差连接（x + Sublayer(x)）
  → 缩放：LayerNorm（(x-μ)/σ）
```

### 1.2 向量运算

| 运算 | 公式 | 几何意义 | LLM 应用 |
|------|------|----------|----------|
| **加法** | $a + b = [a_1+b_1, ..., a_n+b_n]$ | 向量平移 | 残差连接 |
| **数乘** | $ca = [ca_1, ..., ca_n]$ | 向量拉伸/缩短 | 学习率缩放 |
| **点积** | $a \cdot b = \sum a_i b_i = \|a\|\|b\|\cos\theta$ | 相似度 | Attention(Q·K) |
| **L2 范数** | $\|a\|_2 = \sqrt{\sum a_i^2}$ | 向量长度 | Embedding 归一化 |
| **余弦相似度** | $\cos(a,b) = \frac{a\cdot b}{\|a\|\|b\|}$ | 方向相似度 | RAG 向量检索 |

### 1.3 矩阵：AI 中的权重容器

```text
矩阵 = 二维数字表格，AI 中存储所有可学习参数

LLM 中的矩阵：
  ┌──────────────────────────────────────────────────────┐
  │  Embedding 矩阵:   vocab_size × d_model              │
  │    30522 × 768 = 23.4M 参数（BERT-base）             │
  │                                                      │
  │  Q/K/V 投影矩阵:   d_model × d_k                     │
  │    768 × 64 × 3 × 12头 = 1.8M 参数                   │
  │                                                      │
  │  FFN 权重矩阵:      d_model × d_ff (通常 d_ff=4×d_model)│
  │    768 × 3072 × 2 × 12层 = 56.6M 参数               │
  └──────────────────────────────────────────────────────┘

矩阵元素 = 模型参数 → 矩阵的维度直接决定了参数量！
```

## 2. 矩阵运算全解

### 2.1 基础运算

```text
矩阵乘法（最重要的运算）：

  A(m×n) × B(n×p) = C(m×p)
  C[i][j] = Σ A[i][k] × B[k][j]  （A 的第 i 行 与 B 的第 j 列的点积）

关键性质：
  ✅ 结合律: (AB)C = A(BC)
  ❌ 不满足交换律: AB ≠ BA（绝大多数情况）
  ✅ 分配律: A(B+C) = AB + AC
  
  矩阵乘法 = Transformer 的每一层都在做的事：
    → Q = X × W_Q    （seq_len × d_model）×（d_model × d_k）
    → Score = Q × K^T  （seq_len × d_k）×（d_k × seq_len）
    → Output = Score × V
```

### 2.2 转置

```text
矩阵转置 A^T：行变列、列变行

  ┌     ┐T   ┌         ┐
  │ a b │    │ a  c  e │
  │ c d │  = │ b  d  f │
  │ e f │    └         ┘
  └     ┘

LLM 中的关键应用：
  QK^T → 实现 seq_len × d_k 和 d_k × seq_len 的乘法
  结果矩阵 [i][j] = 第 i 个 token 的 Q 与第 j 个 token 的 K 的点积
```

### 2.3 逆矩阵

```text
逆矩阵 A⁻¹：满足 A × A⁻¹ = A⁻¹ × A = I（单位矩阵）

存在条件：方阵 + 行列式 ≠ 0（满秩）

直觉：逆矩阵"撤销"原矩阵的变换
  向量 x 被 A 变换成 Ax
  再乘以 A⁻¹ → A⁻¹(Ax) = x  回到原位

LLM 中：不直接求逆（计算太贵），但理解逆矩阵有助于理解：
  → 为什么权重初始化很重要（不能初始化成不可逆的矩阵）
  → LoRA 为什么可以合并（W + BA 仍是可逆的）
```

### 2.4 行列式

```text
行列式 det(A)：一个标量，表示矩阵变换对空间的"缩放因子"

  det(A) = 0 → 矩阵不可逆 → 变换将空间"压扁"（降维）
  det(A) > 0 → 保持方向
  det(A) < 0 → 翻转方向

直观理解（2×2）：
  det ┌     ┐
      │ a b │ = ad - bc
      │ c d │
      └     ┘
  
  = 矩阵列向量围成的平行四边形的"有向面积"
```

**LLM 中的应用：**
- 权重初始化要避免行列式为 0（否则信息丢失不可逆）
- Xavier/Glorot 初始化就是为了保持每层输出的方差 ≈ 输入的方差

## 3. 线性方程组与秩

### 3.1 线性方程组

```text
线性方程组：Ax = b

  A 是系数矩阵，x 是未知向量，b 是结果向量

三类解的情况：
  ① 唯一解：   A 满秩，det(A) ≠ 0
  ② 无穷多解： A 秩不足，有多余的自由变量
  ③ 无解：     b 不在 A 的列空间中
```

### 3.2 秩

```text
矩阵的秩 rank(A) = 矩阵中线性无关的行（或列）的最大数量

直观：
  3×3 满秩矩阵 → 3 个独立方向 → 可表示 3 维空间任意点
  
  3×3 秩=2 矩阵 → 只有 2 个独立方向 → 实际是 2 维平面

秩与 LoRA：
  LoRA 的 ΔW 假设是低秩的（rank=r, r<<d）
  满秩 ΔW(4096×4096) → LoRA 分解 B(4096×r) × A(r×4096)
  参数从 16.8M 降到 65K（r=8）
```

### 3.3 向量空间与子空间

```text
四个基本子空间（每个矩阵都有）：

  ┌─────────────────────────────────────────┐
  │  列空间 Col(A)：Ax 能到达的所有位置      │
  │  零空间 Null(A)：Ax=0 的所有解           │
  │  行空间 Row(A)：A^T 的列空间             │
  │  左零空间 Null(A^T)                     │
  └─────────────────────────────────────────┘

列空间维度 = 秩 → 模型能表示的"模式多样性"
零空间 ≠ {0} → 不同输入可能映射到相同输出 → 信息丢失
```

## 4. 特征值与特征向量

### 4.1 定义

```text
特征方程：Av = λv

  A：方阵
  v：特征向量（方向不变的特殊向量）
  λ：特征值（在这个方向上被拉伸的倍数）

直觉：
  矩阵 A 对大多数向量会改变方向
  但特征向量在被 A 作用后，方向不变，只被拉伸 λ 倍
```

### 4.2 在 AI 中的意义

| 应用 | 说明 |
|------|------|
| **PCA 降维** | 取最大的 k 个特征值对应的特征向量 → 保留主要信息 |
| **权重矩阵分析** | 特征值分布 → 判断矩阵"条件数" → 训练数值稳定性 |
| **谱归一化** | 用最大特征值约束权重 Lipschitz 常数 → 稳定 GAN 训练 |
| **矩阵分解初始化** | SVD 分解预训练权重分析 |

### 4.3 特征分解

```text
特征分解：A = VΛV⁻¹

  V：特征向量组成的矩阵
  Λ：特征值组成的对角矩阵

  只有可对角化的方阵才能做特征分解！

  ┌     ┐   ┌          ┐ ┌        ┐ ┌           ┐
  │ 3  1 │   │ v₁ v₂   │ │ λ₁ 0  │ │ v₁ v₂ ⁻¹  │
  │ 0  2 │ = │ |   |   │ │ 0  λ₂ │ │ |   |     │
  └     ┘   └          ┘ └        ┘ └           ┘
```

## 5. SVD 奇异值分解

### 5.1 定义与公式

```text
SVD（Singular Value Decomposition）— "矩阵分解的瑞士军刀"

  A = U Σ V^T

  A (m×n) — 任意矩阵，不要求方阵！
  U (m×m) — 左奇异向量（正交矩阵）
  Σ (m×n) — 奇异值对角矩阵（Σ ≥ 0，从大到小排列）
  V (n×n) — 右奇异向量（正交矩阵）

为什么 SVD 比特征分解更通用？
  ✅ 适用于任意形状的矩阵（不需要方阵）
  ✅ 永远存在（任何矩阵都有 SVD）
  ✅ 数值计算更稳定
```

### 5.2 奇异值的含义

```text
Σ = diag(σ₁, σ₂, ..., σᵣ, 0, ..., 0)

  奇异值 σᵢ 表示该"方向"上的"重要性"
  
  σ₁ 最大 → 第一个方向包含最多的"能量"/"信息"
  奇异值衰减越快 → 矩阵越"低秩"
  
  低秩近似：取前 k 个奇异值
    A_k = U_k Σ_k V_k^T  → 用最少的秩保留最多的信息
```

### 5.3 SVD 在 LLM 中的应用

```text
① LoRA 的理论基础：
    ΔW 的 SVD 揭示其真正的"有效秩"
    r=8 意味着保留前 8 个最大的奇异值 → 90%+ 的信息

② 模型压缩：
    对权重矩阵做 SVD → 去掉小奇异值 → 压缩模型

③ Embedding 分析：
    对词向量矩阵做 SVD → 发现语义方向（如"性别"方向）

④ 推荐系统：
    SVD 矩阵分解 → 用户-物品交互矩阵降维 → 协同过滤
```

## 6. PCA 主成分分析

### 6.1 原理

```text
PCA = 用 SVD 实现的降维方法

目标：将高维数据投影到低维空间，最大化保留方差

步骤：
  ① 数据中心化：X = X - mean(X)
  ② 计算协方差矩阵：C = X^T X / (n-1)
  ③ 对 C 做特征分解：C = VΛV^T
  ④ 取前 k 个最大特征值 → 对应的特征向量 v₁..v_k
  ⑤ 投影：X_new = X × [v₁, ..., v_k]

可视化理解：
  3 维数据散布在一个"平面"附近
  → PCA 找到这个平面 → 降维到 2 维
  → 信息损失 = 被丢弃的维度上的方差
```

### 6.2 PCA 与 LLM

| 应用 | 说明 |
|------|------|
| **Embedding 可视化** | 将 768 维词向量降到 2 维 → 散点图 |
| **LoRA 秩选择**** | 对 ΔW 做 SVD → 看奇异值衰减 → 确定 r |
| **知识定位** | 对隐藏状态做 PCA → 发现"知识存储方向" |
| **异常检测** | 重构误差大的样本 → 可能是有害/异常输入 |

## 7. 正交矩阵与最小二乘法

### 7.1 正交矩阵

```text
正交矩阵 Q：Q^T Q = Q Q^T = I

性质：
  ✅ 列向量互相正交（垂直）且长度=1
  ✅ Q^{-1} = Q^T（逆=转置，计算极其简单）
  ✅ 不改变向量长度：|Qx| = |x|
  ✅ 不改变点积：(Qx)·(Qy) = x·y

LLM 中的应用：
  → 权重正交初始化（减少梯度消失）
  → RoPE 旋转位置编码（用正交旋转矩阵注入位置）
```

### 7.2 最小二乘法

```text
问题：Ax = b（方程数 > 未知数 → 通常无精确解）

最小二乘解：x̂ = argmin |Ax - b|²

解：x̂ = (A^T A)^{-1} A^T b

应用：
  ✅ 线性回归：找到最优拟合直线
  ✅ 神经网络最后一层（线性层+平方损失≈最小二乘）
  ✅ 注意力权重的"最优"投影
```

## 8. LLM 中的线性代数实例

### 8.1 一个 Transformer 前向传播的线性代数

```python
import numpy as np

# 模拟一次 Attention 计算
seq_len, d_model, d_k = 10, 768, 64

X = np.random.randn(seq_len, d_model)         # 输入 (10, 768)
W_Q = np.random.randn(d_model, d_k)            # Q 投影矩阵 (768, 64)
W_K = np.random.randn(d_model, d_k)            # K 投影矩阵
W_V = np.random.randn(d_model, d_k)            # V 投影矩阵
W_O = np.random.randn(d_k, d_model)            # 输出投影矩阵

# ① 线性投影（矩阵乘法）
Q = X @ W_Q   # (10, 64)
K = X @ W_K   # (10, 64)
V = X @ W_V   # (10, 64)

# ② 注意力分数（点积 + 转置）
scores = Q @ K.T / np.sqrt(d_k)  # (10, 10) — 每对 token 的相似度

# ③ 因果掩码（下三角保留，上三角 -inf）
mask = np.triu(np.ones((seq_len, seq_len)) * -1e9, k=1)
scores = scores + mask

# ④ Softmax（概率归一化）
attn = np.exp(scores) / np.exp(scores).sum(axis=-1, keepdims=True)

# ⑤ 加权求和
output = attn @ V  # (10, 64)

# ⑥ 输出投影
output = output @ W_O  # (10, 768)

# 整个过程中，每一步都是线性代数运算！
```

### 8.2 LoRA 的参数计算

```python
# LoRA: 原始权重 W(d,d) → B(d,r) × A(r,d)

d = 4096  # LLaMA-7B 的隐藏维度
r = 8     # LoRA rank

W_params = d * d                      # 16,777,216
BA_params = d * r + r * d             # 65,536

print(f"压缩比: {W_params / BA_params:.0f}x")  # 256x
print(f"参数占比: {BA_params / W_params * 100:.2f}%")  # 0.39%
```

## 核心要点回顾

| 概念 | 一句话 | LLM 关联 |
|------|--------|----------|
| 点积 | 两个向量的"相似度" | Attention 打分 Q·K |
| 矩阵乘法 | 线性变换的核心操作 | Transformer 每一层 |
| 秩 | 矩阵中独立信息维度 | LoRA 低秩假设 |
| 特征分解 | $A = V\Lambda V^{-1}$ | PCA 降维 |
| SVD | $A = U\Sigma V^T$（任意矩阵） | LoRA/压缩/Embedding 分析 |
| 正交矩阵 | $Q^T Q = I$，保长保角 | RoPE 位置编码 |
