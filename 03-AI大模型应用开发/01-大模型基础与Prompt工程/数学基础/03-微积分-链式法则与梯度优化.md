## 1. 导数与微分

### 1.1 导数的定义

```text
导数 f'(x) = lim(h→0) [f(x+h) - f(x)] / h

  几何：曲线在点 x 处的切线斜率
  物理：f 在 x 处变化的"瞬时速率"

计算 f(x) = x² 的导数：
  f'(x) = lim(h→0) [(x+h)² - x²] / h
        = lim(h→0) [x² + 2xh + h² - x²] / h
        = lim(h→0) [2x + h] = 2x

直观理解：x² 在 x=3 处的变化速率 = 2×3 = 6
  → x 增加 0.1 → f(x) 约增加 6×0.1 = 0.6
```

### 1.2 常用导数公式

| 函数 f(x) | 导数 f'(x) | LLM 中用到的地方 |
|-----------|-----------|-----------------|
| $x^n$ | $nx^{n-1}$ | 多项式损失项 |
| $e^x$ | $e^x$ | Softmax 分子 |
| $\ln x$ | $1/x$ | 交叉熵的 log |
| $\sigma(x) = \frac{1}{1+e^{-x}}$ | $\sigma(1-\sigma)$ | Sigmoid 激活 |
| $\max(0,x)$ | 0 (x<0), 1 (x>0) | ReLU 反向传播 |
| $\tanh(x)$ | $1 - \tanh^2(x)$ | 早期 RNN |

### 1.3 导数的核心直觉

```text
f'(x) > 0 → 函数在上升 → 要减小 Loss → 让 x 减小
f'(x) < 0 → 函数在下降 → 要减小 Loss → 让 x 增大

  梯度下降：x ← x - η × f'(x)

  f'(x) 的正负号告诉你方向，f'(x) 的大小告诉你步长
```

## 2. 链式法则：反向传播的数学基础

### 2.1 链式法则公式

```text
一元链式法则：
  y = f(u), u = g(x)  →  dy/dx = dy/du × du/dx

多元链式法则：
  z = f(u, v), u = g(x), v = h(x)
  → dz/dx = ∂z/∂u × du/dx + ∂z/∂v × dv/dx

多"路径"求导 → 同时通过 u 和 v 两条路径影响 z
```

### 2.2 链式法则为什么是反向传播的核心

```text
神经网络 = 函数的嵌套：

  output = f_n(f_{n-1}(...f_2(f_1(input))...))

要更新 W₁（第一层的权重）：
  ∂Loss/∂W₁ = ∂Loss/∂output × ∂output/∂h_{n-1} × ... × ∂h₁/∂W₁
               └──────── 从第 n 层"链式"乘回到第 1 层 ────────┘

这就是反向传播！
```

### 2.3 一个完整的链式求导示例

```text
假设一个极简网络：
  z = wx + b    （线性层）
  a = σ(z)      （Sigmoid 激活）
  L = (a - y)²  （平方损失）

求 ∂L/∂w：

  ∂L/∂w = ∂L/∂a × ∂a/∂z × ∂z/∂w
         └─┬──┘   └─┬──┘   └─┬──┘
          2(a-y)   σ(1-σ)    x

每一步都是求一个简单函数的导数，然后连乘！
```

## 3. 多元微积分：偏导、梯度、雅可比、海森

### 3.1 偏导数

```text
多元函数 f(x₁, x₂, ..., xₙ) 的偏导数：

  ∂f/∂x₁ = 把 x₂...xₙ 当常数，对 x₁ 求导

例子：f(x, y) = x² + xy + y³
  ∂f/∂x = 2x + y    （y 当常数）
  ∂f/∂y = x + 3y²   （x 当常数）
```

### 3.2 梯度

```text
梯度 ∇f = [∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂xₙ]^T

梯度 = 所有偏导数组成的向量

关键性质：
  ✅ 梯度指向函数增长最快的方向
  ✅ 负梯度 = 函数下降最快的方向 → 参数更新方向
  ✅ 梯度为零 → 可能是极值点（最小值/最大值/鞍点）

梯度下降公式：
  θ ← θ - η × ∇L(θ)
  
LLM 每次训练 Step：
  ① 前向传播 → 计算 Loss
  ② 反向传播 → 计算 ∇L(θ)（每个参数 Wᵢ 的 ∂L/∂Wᵢ）
  ③ 参数更新 → θ = θ - lr × ∇L(θ)
```

### 3.3 雅可比矩阵

```text
雅可比矩阵 J：向量值函数对向量输入的导数

  y = f(x)  其中 x∈R^n, y∈R^m

  J[i][j] = ∂y_i / ∂x_j

  雅可比矩阵是 m×n 矩阵，每一行是 y_i 对 x 的梯度

LLM 中的应用：
  → 每一层都是一个向量→向量的函数
  → 反向传播就是逐层乘以雅可比矩阵的转置
```

### 3.4 海森矩阵

```text
海森矩阵 H：梯度对参数的二阶导数

  H[i][j] = ∂²L / ∂θ_i ∂θ_j

海森矩阵告诉我们：
  → Loss 曲面的"曲率" — 梯度变化有多快
  → 特征值 > 0 → 局部极小值
  → 特征值 < 0 → 鞍点

为什么 LLM 训练中很少直接算海森矩阵？
  ❌ 计算量太大：n 个参数 → n×n 矩阵
  ❌ 700M 参数 → 无法存储 700M² 的矩阵
  
替代方案：
  → Adam 用梯度平方的指数移动平均 (v) 近似二阶信息
  → 牛顿法 (Newton's Method) 需要海森逆矩阵 → LLM 不用
```

## 4. 积分基础

### 4.1 定积分与不定积分

```text
不定积分（反导数）：
  ∫ f(x) dx = F(x) + C  → F'(x) = f(x)

定积分（面积）：
  ∫ₐᵇ f(x) dx = F(b) - F(a) = 曲线下面积

在 LLM 中直接积分运算不多见，但理解积分有助于：
  ✅ 概率密度 → 积分求概率（连续分布）
  ✅ 期望值计算：E[f(x)] = ∫ f(x)p(x) dx
  ✅ Area Under Curve → ROC-AUC 评估指标
```

### 4.2 多重积分

```text
二重积分：∫∫ f(x, y) dx dy  → 曲面下的体积

在 AI 中的应用：
  → 高维概率分布的归一化常数
  → 贝叶斯推断中的边缘化
```

## 5. 极值与凸函数

### 5.1 极值条件

```text
一阶必要条件：∇f = 0（梯度为零）
二阶充分条件：
  海森矩阵正定 → 局部极小值
  海森矩阵负定 → 局部极大值
  海森矩阵不定 → 鞍点

LLM 训练中的现实：
  高维空间中的驻点几乎全是鞍点，不是极小值
  → 不用担心"卡在局部最优"（维度越高，鞍点越多）
  → 真正要担心的是：鞍点周围梯度很小 → 收敛慢
```

### 5.2 凸函数

```text
凸函数：连线在函数上方

  f(λx + (1-λ)y) ≤ λf(x) + (1-λ)f(y)，∀λ∈[0,1]

凸函数的优良性质：
  ✅ 局部最小值 = 全局最小值（没有鞍点困扰）
  ✅ 梯度下降一定能收敛到最优解
  ✅ 优化理论的最核心假设

LLM Loss 是凸函数吗？
  ❌ 不是！深度神经网络的 Loss 曲面高度非凸
  → 但实践表明 SGD 仍能找到很好的解
  → 这是深度学习的"经验奇迹"
```

## 6. 从公式到代码：手写反向传播

### 6.1 极简两层网络

```python
import numpy as np

# 网络结构：Input(2) → Linear(2→3)+ReLU → Linear(3→1) → MSE Loss
x  = np.array([1.0, 2.0])        # 输入
W1 = np.array([[0.5, 0.2],       # 第一层权重 (3,2)
               [0.3, 0.8],
               [0.1, 0.4]])
b1 = np.array([0.1, 0.2, 0.3])   # 第一层偏置 (3,)
W2 = np.array([0.4, 0.6, 0.2])   # 第二层权重 (1,3)
b2 = 0.5                          # 第二层偏置
y_true = 1.0                      # 真实标签

# ===== ① 前向传播 =====
z1 = W1 @ x + b1                  # (3,)  — 矩阵乘法 + 偏置
a1 = np.maximum(0, z1)            # (3,)  — ReLU 激活
z2 = W2 @ a1 + b2                 # (1,)  — 第二层
y_pred = z2                       # 输出
loss = 0.5 * (y_pred - y_true)**2 # MSE Loss

print(f"Pred: {y_pred:.4f}, Loss: {loss:.4f}")

# ===== ② 反向传播（链式求导！） =====
# Layer 2: ∂L/∂y_pred → ∂L/∂W2 → ∂L/∂b2 → ∂L/∂a1
dL_dy = y_pred - y_true                # ∂L/∂y_pred = (y_pred - y_true)
dL_dW2 = dL_dy * a1                    # ∂L/∂W2 = ∂L/∂y_pred × ∂y_pred/∂W2
dL_db2 = dL_dy                          # ∂L/∂b2 = ∂L/∂y_pred
dL_da1 = dL_dy * W2                    # ∂L/∂a1 = ∂L/∂y_pred × ∂y_pred/∂a1

# Layer 1: ReLU 的导数 + ∂L/∂W1 → ∂L/∂b1
dL_dz1 = dL_da1.copy()
dL_dz1[z1 <= 0] = 0                    # ReLU 导数：>0 时传梯度，≤0 时截断
dL_dW1 = np.outer(dL_dz1, x)           # ∂L/∂W1 = ∂L/∂z1 × ∂z1/∂W1
dL_db1 = dL_dz1                         # ∂L/∂b1 = ∂L/∂z1

# ===== ③ 参数更新 =====
lr = 0.01
W1 -= lr * dL_dW1
b1 -= lr * dL_db1
W2 -= lr * dL_dW2
b2 -= lr * dL_db2

# 验证 Loss 下降
z1 = W1 @ x + b1
a1 = np.maximum(0, z1)
y_pred = W2 @ a1 + b2
new_loss = 0.5 * (y_pred - y_true)**2
print(f"After update — Pred: {y_pred:.4f}, Loss: {new_loss:.4f}")
```

### 6.2 关键观察

```text
观察 1：梯度是逐层"回传"的
  dL_dW2 ← 用到 dL_dy
  dL_da1 ← 用到 dL_dy 和 W2
  dL_dW1 ← 用到 dL_da1（经过 ReLU 截断）

观察 2：ReLU 的"梯度截断"效应
  z1 ≤ 0 → dL_dz1 = 0 → 梯度无法继续回传！
  → 这就是"Dead ReLU"问题的根源
  → GELU 没有这个问题（负值也有小梯度）

观察 3：矩阵乘法的梯度
  Forward:  z = Wx
  Backward: dL/dW = dL/dz ⊗ x（外积）
            dL/dx = W^T × dL/dz（转置乘法）
```

## 核心要点回顾

| 概念 | 公式/直觉 | LLM 中的角色 |
|------|----------|------------|
| 导数 | f'(x) = 瞬时变化率 | 参数更新方向 |
| 链式法则 | dz/dx = dz/dy × dy/dx | **反向传播的核心** |
| 梯度 | ∇f = [∂f/∂θ₁, ...] | 参数更新的方向和大小 |
| 梯度下降 | θ ← θ - η∇L | 训练的根本算法 |
| 雅可比矩阵 | J[i][j] = ∂y_i/∂x_j | 层间梯度传递 |
| 海森矩阵 | H[i][j] = ∂²L/∂θᵢ∂θⱼ | 二阶优化（LLM 中不用） |
| 凸函数 | 连线在函数上方 | 理论保证（LLM 不具备） |
