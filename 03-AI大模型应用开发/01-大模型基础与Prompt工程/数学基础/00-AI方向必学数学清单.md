## 1. 底层基础数学（三件套，必修）

> 不学这三门，无法看懂任何模型推导 — 这是 AI 入门的硬门槛。

### 1.1 线性代数（AI 第一核心数学）

| 模块 | 必学内容 | AI 直接用途 |
|------|----------|------------|
| **矩阵与向量** | 矩阵乘法、转置、逆矩阵、行列式 | 神经网络权重存储、全连接层计算 |
| **线性空间** | 线性方程组、秩、向量空间、特征空间 | 理解模型参数空间的维度 |
| **特征分解** | 特征值 & 特征向量、SVD 奇异值分解 | PCA 降维、LoRA 低秩分解核心 |
| **正交与投影** | 正交矩阵、投影、最小二乘法 | 回归、拟合、Attention 矩阵性质 |

> 📂 详见：[01-线性代数-向量矩阵与Attention数学.md](01-线性代数-向量矩阵与Attention数学.md)

### 1.2 概率论与数理统计（模型训练、损失、概率建模基础）

| 模块 | 必学内容 | AI 直接用途 |
|------|----------|------------|
| **基础概率** | 条件概率、贝叶斯公式 | 朴素贝叶斯、贝叶斯神经网络 |
| **随机变量与分布** | 均匀、高斯正态、伯努利、二项、泊松、指数分布 | 参数初始化、噪声建模、LLM 概率采样 |
| **数字特征** | 期望、方差、协方差、协方差矩阵 | 数据分布分析、BatchNorm 理解 |
| **参数估计** | 极大似然估计 MLE、最大后验估计 MAP | 损失函数的概率解释 |
| **采样** | 蒙特卡洛采样、重要性采样 | LLM 解码策略、Top-p/Top-k 采样 |
| **推断** | 假设检验、置信区间 | 模型 AB 测试、效果评估 |

> 📂 详见：[03-概率与信息论-从Softmax到交叉熵.md](03-概率与信息论-从Softmax到交叉熵.md)

### 1.3 微积分（梯度下降的灵魂）

| 模块 | 必学内容 | AI 直接用途 |
|------|----------|------------|
| **一元微分** | 导数、链式法则 | 反向传播的核心！全靠链式求导 |
| **多元微分** | 偏导数、梯度、雅可比矩阵、海森矩阵 | 梯度下降更新方向 |
| **积分** | 定积分、不定积分、多重积分 | 概率积分计算、期望值 |
| **极值与凸性** | 极值、凸函数、凸优化基础 | 理解 Loss 面、收敛性 |

> 📂 详见：[02-微积分与优化-梯度下降与反向传播.md](02-微积分与优化-梯度下降与反向传播.md)

## 2. AI专用进阶数学

### 2.1 凸优化（机器学习优化理论）

| 必学内容 | AI 直接用途 |
|----------|------------|
| 凸集、凸函数、凸优化问题定义 | 理解训练收敛、损失函数优化 |
| 拉格朗日乘数法、KKT 条件 | SVM 支持向量机、约束优化 |
| 梯度下降、随机梯度 SGD、牛顿法 | 优化器选择与调参 |

### 2.2 信息论（大模型 NLP 核心数学）

| 必学内容 | AI 直接用途 |
|----------|------------|
| 熵、联合熵、条件熵 | 理解模型的不确定性、文本信息量 |
| 交叉熵 | **LLM 训练标配损失函数** |
| KL 散度（相对熵） | **RLHF 对齐约束**、模型蒸馏、分布对齐 |
| 互信息 | 特征选择、表示学习 |

> 📂 详见：[03-概率与信息论-从Softmax到交叉熵.md](03-概率与信息论-从Softmax到交叉熵.md)

### 2.3 离散数学（算法、图神经网络、编码基础）

| 必学内容 | AI 直接用途 |
|----------|------------|
| 集合、逻辑命题、布尔代数 | 决策树、规则系统 |
| 图论：图、有向图、邻接矩阵、最短路径 | GNN 图神经网络、知识图谱 |
| 组合数学、排列组合、计数 | 搜索算法、离散编码 |

## 4. 学习路线（从易到难）

```text
阶段一：基础三件套（必修，所有人必学）
  微积分 → 线性代数 → 概率论数理统计
  用时：2-4 周（计算机专业已有基础的可缩短到 1 周复习）
  产出：能看懂 Transformer 论文中的公式

阶段二：机器学习进阶
  凸优化 + 信息论
  用时：1-2 周
  产出：能理解 Loss 收敛、RLHF 的 KL 约束

阶段三：工程落地
  离散数学 + 数值分析
  用时：1 周
  产出：理解 GPU 矩阵运算、数值稳定性

阶段四：细分拓展（按需）
  图论（GNN）、随机过程（RL）、傅里叶（CV）
  用时：按需投入
```

## 5. Java后端+大模型定位的学习取舍

### 必须吃透（面试、开发、看懂 LLM 源码）

| 知识点 | 为什么必须 |
|--------|-----------|
| 微积分链式求导 | 反向传播就是链式法则 |

| 交叉熵 + KL 散度 | 损失函数 + RLHF 约束 |
| 梯度下降优化 | 训练的根本方法 |

| 知识点 | 了解程度 |

| 马尔可夫过程 | 知道 RL 中的状态转移 |
| 离散数学/图论 | 知道图的基本概念 |
