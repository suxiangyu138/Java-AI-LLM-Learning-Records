## 1. 傅里叶分析概述

### 1.1 核心思想

```text
傅里叶分析：任何信号都可以分解为一系列正弦波的叠加

时域信号 → 傅里叶变换 → 频域表示
  波形         FT        频谱

直观类比：
  就像把一杯混合果汁分解为"多少苹果汁 + 多少橙汁 + 多少西瓜汁"
  傅里叶变换把复杂信号分解为"多少 Hz 的正弦波成分"
```

### 1.2 为什么在 AI 中需要

```text
① 图像处理：
   图片 = 空间域 → 傅里叶变换 → 频率域
   高频 = 边缘、细节 | 低频 = 平滑区域
   JPEG 压缩就是傅里叶变换的应用

② 音频处理：
   语音 → 频谱图 → CNN/Transformer 处理
   Whisper 等语音模型的底层输入

③ 时序分析：
   时间序列 → 频域 → 发现周期性模式
   用于预测、异常检测
```

## 2. 离散傅里叶变换 DFT

### 2.1 公式

```text
DFT（计算机中的傅里叶变换）：

  X[k] = Σ x[n] × e^{-j2πkn/N}

  x[n]：时域信号（N 个采样点）
  X[k]：频域响应（N 个频率分量）
  k：频率索引（0 到 N-1）

复杂度：O(N²) → FFT 加速到 O(N log N)
```

### 2.2 在 AI 中的应用

| 应用 | 说明 | 与 LLM 的关系 |
|------|------|:---:|
| **语音转文字** | 语音→STFT→频谱图→Whisper→文本 | ⭐⭐⭐ |
| **图像卷积加速** | 用 FFT 加速大卷积核 | ⭐ |
| **时序预测** | 频域特征提取 | ⭐⭐ |
| **位置编码的灵感** | Transformer 的 Sinusoidal PE | ⭐⭐⭐ |

```python
import numpy as np

# 简单 DFT 示例
def dft(x):
    N = len(x)
    X = np.zeros(N, dtype=complex)
    for k in range(N):
        for n in range(N):
            X[k] += x[n] * np.exp(-2j * np.pi * k * n / N)
    return X

# 信号：50Hz 正弦 + 120Hz 正弦
t = np.linspace(0, 1, 500)
signal = np.sin(2 * np.pi * 50 * t) + 0.5 * np.sin(2 * np.pi * 120 * t)
freqs = dft(signal[:128])
# → |freqs| 在 50Hz 和 120Hz 处出现峰值!
```

## 3. 卷积定理与 CNN

### 3.1 卷积定理

```text
卷积定理（傅里叶分析的重要结论）：

  时域卷积 = 频域相乘

  f * g = F⁻¹(F(f) × F(g))

  即：时域中做卷积 = 频域中做逐元素乘法

为什么重要？
  大卷积核在时域计算慢 → 转到频域只需逐元素乘法 → 再用逆变换回来
  → 对大卷积核（如大感受野），FFT 加速明显
```

### 3.2 CNN 中的卷积

```text
CNN 图像卷积：

  输入 224×224×3
  卷积核 3×3×3×64
  
  每个位置做 27 次乘法 → 总计算量巨大

为什么 CNN 不直接用 FFT 加速？
  ✅ 3×3 的核太小 → FFT 开销比直接计算大
  ✅ 现代 GPU 对小卷积核已有高度优化（cuDNN）
  ❌ FFT 加速对大卷积核（如 11×11）才有优势
```

## 4. 马尔可夫链

### 4.1 定义

```text
马尔可夫链：下一个状态只依赖当前状态，不依赖历史

  P(s_{t+1} | s_t, s_{t-1}, ..., s_1) = P(s_{t+1} | s_t)

转移矩阵 P：
  P[i][j] = 从状态 i 转移到状态 j 的概率
  
  每一行之和 = 1

例子 — 天气模型：
  晴天 → 晴天：0.8   晴天 → 雨天：0.2
  雨天 → 晴天：0.4   雨天 → 雨天：0.6

  转移矩阵：┌          ┐
            │ 0.8 0.2 │
            │ 0.4 0.6 │
            └          ┘
```

### 4.2 平稳分布

```text
平稳分布 π：π × P = π

  含义：系统运行足够长时间后，各状态的概率趋于稳定
  → 与初始状态无关

对上面的天气模型：
  π = [0.667, 0.333]
  → 长期来看，67% 时间晴天，33% 雨天

验证：π × P = [0.667×0.8+0.333×0.4, ...] = [0.667, 0.333] ✅
```

### 4.3 马尔可夫链 LLM 解码的关系

```text
LLM 的自回归生成本质是马尔可夫过程：

  P(token_t | token_1, ..., token_{t-1}) ≈ P(token_t | token_{t-1})
  
  但由于 Transformer 的 Self-Attention 可以看到所有历史 token
  所以 LLM 生成不是严格的马尔可夫链，而是"非马尔可夫"过程

但！采样策略仍然有马尔可夫性质：
  每次采样只取决于上一个 token 的输出分布 → 局部马尔可夫性质
```

## 5. 马尔可夫决策过程 MDP

### 5.1 MDP 五元组

```text
MDP = (S, A, P, R, γ)

  S：状态空间（所有可能的状态）
  A：动作空间（所有可能的动作）
  P：转移概率 P(s' | s, a)
  R：奖励函数 R(s, a)
  γ：折扣因子 (0~1)，平衡短期 vs 长期奖励
```

### 5.2 MDP 与强化学习

```text
RL 的核心：在 MDP 框架下学习最优策略

策略 π(a|s)：在状态 s 下选择动作 a 的概率

目标：最大化累积奖励
  max E[Σ γᵗ R(s_t, a_t)]

  γ=0：只看即时奖励（贪心）
  γ≈1：看长远奖励

RLHF 中的 MDP：
  → 状态：对话历史
  → 动作：生成下一个 token
  → 奖励：RM（奖励模型）的评分
  → γ：均衡短期连贯性和长期回答质量
```

### 5.3 与 LLM 的关系

```text
RLHF 就是 LLM 在对话 MDP 上的强化学习：

  S = {所有可能的对话上下文}
  A = {词表中所有 token}
  P = Transformer 输出分布（被 RL 策略调整）
  R = Reward Model 评分 + KL 惩罚

即：每次选择 token 不只是"最大概率"，还要考虑"Reward Model 喜欢"
```
