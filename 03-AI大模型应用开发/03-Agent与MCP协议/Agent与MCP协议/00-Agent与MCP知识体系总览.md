## 3. 核心概念速查

### 3.1 Agent 四大组件

| 组件 | 职责 | 核心问题 |
|------|------|---------|
| 规划 Planning | 拆解任务、决定步骤 | 拆得对不对、顺序合理吗 |
| 记忆 Memory | 保持上下文与知识 | 记得住吗、记得对吗 |
| 工具 Tool | 连接外部系统 | 选得对吗、调得稳吗 |
| 行动 Action | 执行与反馈闭环 | 成功了吗、失败怎么恢复 |

### 3.2 Agent 与周边概念

| 概念 | 一句话 |
|------|--------|
| LLM | 单次推理、无状态、被动响应 |
| Agent | 循环推理（Observe-Think-Act）、有状态、主动执行 |
| Skill | 面向场景的提示词+工具封装（轻量） |
| Tool | 可调用的外部能力（函数/API） |
| MCP | Agent 连接工具的标准化协议（垂直） |
| A2A | Agent 间通信协议（水平，2025 v1.0） |

### 3.3 MCP 核心原语

| 原语 | 作用 | 类比 |
|------|------|------|
| Tools | 可执行操作（Agent 调用） | 函数 |
| Resources | 可读取数据（Context 注入） | 文件 |
| Prompts | 预置提示模板 | 宏 |
| **Tasks（2026 转正）** | 长时异步任务（可恢复句柄） | 作业系统 |

## 4. 2026 生态现状速查

**MCP 协议（时效性重点，2026-08 检索核实）**：

| 维度 | 现状 |
|------|------|
| 治理 | 2025-12 捐赠 **Linux 基金会 AAIF**（240+ 成员，Anthropic/微软/OpenAI/谷歌/亚马逊共同维护） |
| 规模 | SDK 周下载 **~2.5 亿次**（半年翻倍）；**60%+ 财富 500 强**作为内部 AI 连接标准 |
| **2026-07-28 规范大更新** | **无状态架构**（单请求调用、可负载均衡）、12 个月弃用政策、OAuth issuer 强制校验、**MCP Apps/Tasks 转正** |
| 生态 | 钉钉/飞书/用友等平台原生 MCP Server；LangChain/LlamaIndex/AutoGen 全支持 |
| **A2A 协议** | Agent 间通信 v1.0 稳定，150+ 组织生产使用，与 MCP 分层共存 |
| 安全现实 | 492 个公网服务器无认证、~37% 存在 SSRF、50+ 漏洞（13 高危） |
| 2026 增长面 | **编程 Agent**（Claude Code/Cursor 等）、端侧 MCP（AI PC） |

> ⚠️ 老教程注意：2025 年之前的 MCP 教程基于"有状态双向协议"——**2026-07 规范已转向无状态**，部署与鉴权方式有重大变化（详见 09 号文件与深化 12 号文件）。

## 5. 学习路线

**路线一：基础入门（2~3 天，01-03）**
Agent 概念 → 架构四组件 → ReAct 与 Function Calling；重点理解"LLM 如何变成 Agent"（循环 + 工具）。

**路线二：系统深入（1 周，04-09）**
工具系统 → 记忆 → 规划 → 多 Agent（含 A2A）→ 框架 → MCP 协议；用 LangChain4j/Spring AI 搭一个带工具的 Agent 练手。

**路线三：生产与面试（10-11 + 深化）**
安全评估 → 生产实战；结合 2026 生态现状（无状态 MCP/A2A/编程 Agent）补齐时效性。

> 🎯 **核心要点**：Agent 学习的终点 = "**会设计（四组件 + 设计模式）、会接入（MCP）、会协作（多 Agent/A2A）、会生产（安全/评估/可观测）**"——2026 年竞争焦点在"连接能力"（MCP 生态），不在模型本身。

## 6. 常见误区

| 误区 | 真相 |
|------|------|
| "Agent = 会调 API 的 LLM" | Agent 的核心是**循环 + 状态**（Observe-Think-Act），不只是工具调用 |
| "多 Agent 一定比单 Agent 好" | 复杂度爆炸是过度设计——**先单后多**（能单 Agent 解决就不要多） |
| "MCP 就是新的 API 封装" | MCP 是**协议**（标准化互操作），不是某个库——2026 已是行业标准 |
| "MCP 和 A2A 是一回事" | **MCP 管工具（垂直）、A2A 管 Agent 协作（水平）**——分层共存 |
| "工具描述随便写" | 描述质量决定 ToolSelectionAccuracy——2026 有专门优化器提升 10-25 个百分点 |
| "记忆 = 存对话历史" | 记忆要**管理生命周期**（重要性过滤/更新/过期/合规删除） |
| "自研 Agent 框架更可控" | 框架已成熟（状态/检查点/可观测）——自研 = 重复造轮子（反模式） |
| "安全是上线后的事" | 工具投毒/间接注入是**设计期**就要防御的（白名单/审批门） |

> 💡 误区清单 = 面试"观点题"素材——能指出流行认知的偏差，就是深度。
