> 🎯 共 **12 篇**，从单 Agent 循环到多 Agent 协作、从推理到训练、从工程化到面试

## 4. 七大循环速查

| 循环类型 | 核心公式 | 一句话 |
|------|------|------|
| **ReAct** | Think → Act → Observe → Repeat | Agent 执行的基本单元 |
| **Function Calling** | User Query → Tool Call → Result → Answer | 工具调用的标准范式 |
| **CoT/ToT** | 分解 → 推理 → 验证 → 综合 | 深度思考的循环结构 |
| **Reflexion** | 执行 → 评估 → 反思 → 改进 | 自我纠错的进化循环 |
| **Multi-Agent** | Agent₁ ↔ Agent₂ ↔ ... ↔ Agentₙ | 多智能体协作循环 |
| **Data Flywheel** | 数据 → 模型 → 用户 → 更多数据 | 产品增长的飞轮 |
| **RLHF** | SFT → 偏好收集 → 奖励建模 → PPO | 人类偏好的对齐循环 |
