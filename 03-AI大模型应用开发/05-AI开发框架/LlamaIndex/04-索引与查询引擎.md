## 1. 四种索引详解

### VectorStoreIndex（向量索引）

```python
index = VectorStoreIndex.from_documents(documents)
# 或从节点构建
index = VectorStoreIndex(nodes, embed_model=Settings.embed_model)
```

| 特点 | 说明 |
|---|---|
| 机制 | 向量相似度检索 |
| 存储 | 内存/30+ 向量库（Qdrant/ES/Milvus...） |
| 适用 | **通用 RAG 默认** |

### SummaryIndex（摘要索引）

```python
from llama_index.core import SummaryIndex
index = SummaryIndex.from_documents(documents)
```

| 特点 | 说明 |
|---|---|
| 机制 | 全部节点顺序进上下文（类似长上下文） |
| 适用 | 小文档全局理解 |
| 限制 | 大文档 token 爆炸 |

### KeywordTableIndex（关键词索引）

```python
from llama_index.core import KeywordTableIndex
index = KeywordTableIndex.from_documents(documents)
```

| 特点 | 说明 |
|---|---|
| 机制 | 关键词 → 节点映射 |
| 适用 | 精确词查询（型号/人名） |
| 限制 | 语义能力弱 |

### KnowledgeGraphIndex（知识图谱索引）

```python
from llama_index.core import KnowledgeGraphIndex
index = KnowledgeGraphIndex.from_documents(
    documents, llm=Settings.llm, max_triplets_per_chunk=10,
)
```

| 特点 | 说明 |
|---|---|
| 机制 | LLM 提取实体关系三元组 |
| 适用 | 多跳推理（对应 RAG 阶段 4 的 GraphRAG） |
| 代价 | 建索引贵（LLM 抽取） |

## 2. 索引选型决策

```
通用问答 → VectorStoreIndex（默认）
多跳/实体关系 → KnowledgeGraphIndex
精确关键词 → KeywordTableIndex
小文档全局 → SummaryIndex
生产托管 → LlamaCloud Index（托管索引+增量同步）
```

### 组合使用

```
多索引联合：不同数据用不同索引 → 查询路由
（对应阶段 4 的混合路由思想）
```

## 3. QueryEngine 工作机制

### 内部流程

```
query → 检索（retriever）→ 上下文组装（retriever 节点）
→ Prompt 构建 → LLM 生成 → 响应（含来源）
```

### 定制查询引擎

```python
# 1. 自定义检索器
retriever = index.as_retriever(similarity_top_k=5)

# 2. 自定义提示词（强约束，阶段 2 纪律）
from llama_index.core.prompts import PromptTemplate
qa_template = PromptTemplate("""严格依据上下文回答，不要编造。

【上下文】
{context_str}

【问题】
{query_str}
【回答】""")

# 3. 组装引擎
from llama_index.core.query_engine import RetrieverQueryEngine
query_engine = RetrieverQueryEngine.from_args(
    retriever=retriever,
    text_qa_template=qa_template,
)
```

### 响应对象

```python
response = query_engine.query("问题")
response.response          # 答案文本
response.source_nodes      # 来源（可溯源）
response.metadata          # 元数据
```

## 4. 内置检索优化

### 层级分块（父子索引）

```python
from llama_index.core.node_parser import HierarchicalNodeParser
from llama_index.core.storage.docstore import SimpleDocumentStore

# 多级粒度：父块（上下文） + 子块（检索）
node_parser = HierarchicalNodeParser.from_defaults(
    chunk_sizes=[2048, 512, 128],
)
nodes = node_parser.get_nodes_from_documents(documents)
```

```
检索子块 → 返回父块（精度 + 完整兼得）
= RAG 阶段 3 的 05 篇父子文档索引（内置）
```

### 混合搜索

```python
# 向量 + BM25（需存储支持，如 ES）
# LlamaCloud Index 内置混合检索
from llama_index.core.retrievers import QueryFusionRetriever

retriever = QueryFusionRetriever(
    [vector_retriever, bm25_retriever],
    mode="reciprocal_rerank",      # RRF 融合（阶段 3）
    num_queries=1,
)
```

### 子问题分解

```python
# 多文档查询：复杂问题拆解为子问题分别检索
from llama_index.core.query_engine import SubQuestionQueryEngine

engine = SubQuestionQueryEngine.from_defaults(query_engine_tools=tools)
```

```
适用：跨文档综合（对应阶段 4 的 deep research 思想）
```

## 6. 检索调优实践

### 调优流程（阶段 3 方法论）

```
① 固定测试集（问题 + 参考答案）
② 改一个参数 → 评估 → 记录
③ 累积提升表（只留正收益层）
```

### LlamaIndex 调优点位

| 调优 | 参数/组件 |
|---|---|
| Top-K | similarity_top_k |
| 分块 | NodeParser（size/overlap/层级） |
| 混合 | QueryFusionRetriever（RRF） |
| 重排 | SentenceTransformerRerank |
| 提示词 | text_qa_template（强约束） |
| 评估 | 内置评估器（07 篇） |

### 内置评估器快速用

```python
from llama_index.core.evaluation import FaithfulnessEvaluator, RelevancyEvaluator

evaluator = FaithfulnessEvaluator()
result = evaluator.evaluate_response(response=response)
print(f"忠实度：{result.passing} ({result.score:.2f})")
```

## 8. 检索管道完整示例

```python
"""生产标准检索：层级分块 + 混合检索 + 重排 + 评估"""
from llama_index.core import VectorStoreIndex, Settings
from llama_index.core.node_parser import HierarchicalNodeParser
from llama_index.core.retrievers import QueryFusionRetriever
from llama_index.core.postprocessor import SentenceTransformerRerank
from llama_index.core.evaluation import FaithfulnessEvaluator

# 1. 层级分块（父子索引：子块检索、父块上下文）
parser = HierarchicalNodeParser.from_defaults(chunk_sizes=[2048, 512])
nodes = parser.get_nodes_from_documents(documents)

# 2. 建索引
index = VectorStoreIndex(nodes)

# 3. 混合检索（向量 + BM25 → RRF）
hybrid = QueryFusionRetriever(
    [index.as_retriever(similarity_top_k=20), bm25_retriever],
    mode="reciprocal_rerank",
)

# 4. 重排精排
rerank = SentenceTransformerRerank(model="BAAI/bge-reranker-base", top_n=5)

# 5. 组装查询引擎
query_engine = index.as_query_engine(
    retriever=hybrid,
    node_postprocessors=[rerank],
)

# 6. 评估
evaluator = FaithfulnessEvaluator()
result = evaluator.evaluate_response(
    response=query_engine.query("问题"),
)
print(f"忠实度：{result.score:.2f}")
```

### 示例解读

```
管道 = 阶段 3 调优全组件化：
层级分块（父子）→ 混合检索（RRF）→ 重排（精排）→ 评估（忠实度）
每步都是阶段 3 学过的方法，LlamaIndex 给现成组件
```

## 9. 常见误区

| 误区 | 真相 |
|---|---|
| "只有向量索引" | 四种索引（图谱/关键词/摘要） |
| "混合检索要自建" | QueryFusionRetriever 内置（RRF） |
| "评估要另搭平台" | FaithfulnessEvaluator 内置 |
| "高级策略自己写" | HyDE/Self-RAG/RAPTOR 有组件 |
| "封装深 = 黑盒" | 组件可定制（检索器/提示词/后处理） |

> 🎯 核心要点：四种索引（向量默认/图谱多跳/关键词精确/摘要全局）；QueryEngine = 检索到响应的封装（可定制检索器/提示词/重排）；层级分块/混合检索/子问题分解全部内置；HyDE/Self-RAG/RAPTOR 等高级策略有现成组件；调优方法论与手写 RAG 完全一致——原理在前，框架给实现；完整管道示例六步走。
