## 1. nn.Module 体系

### 是什么

```
nn.Module = 所有模型的基类：
① 参数管理（parameters()/named_parameters()）
② 前向传播（forward 方法）
③ 子模块组合（嵌套）
```

### 核心机制

```python
import torch.nn as nn

class MyModel(nn.Module):
    def __init__(self):
        super().__init__()
        # 子模块（自动注册参数）
        self.fc1 = nn.Linear(784, 128)
        self.fc2 = nn.Linear(128, 10)

    def forward(self, x):
        # 前向传播（唯一必须实现的方法）
        x = torch.relu(self.fc1(x))
        return self.fc2(x)
```

### 自动注册

```
__init__ 中赋值 nn.Module → 自动注册（parameters 可见）
普通 tensor 不会注册（需 nn.Parameter 包装）
```

## 2. 常用网络层

| 层 | 用途 | 说明 |
|---|---|---|
| nn.Linear(in, out) | 全连接 | 最基础 |
| nn.Conv2d(cin, cout, k) | 卷积 | 图像特征 |
| nn.Conv1d | 卷积 | 序列 |
| nn.LSTM/GRU | 循环 | 序列建模 |
| nn.Embedding | 词嵌入 | 词向量 |
| nn.Dropout(p) | 正则化 | 防过拟合（训练开验证关） |
| nn.BatchNorm2d | 归一化 | 稳定训练 |
| nn.LayerNorm | 层归一化 | Transformer 用 |
| nn.TransformerEncoder | Transformer | LLM 基础 |

### 示例：CNN 块

```python
class ConvBlock(nn.Module):
    def __init__(self, cin, cout):
        super().__init__()
        self.conv = nn.Conv2d(cin, cout, 3, padding=1)
        self.bn = nn.BatchNorm2d(cout)
        self.pool = nn.MaxPool2d(2)

    def forward(self, x):
        return self.pool(torch.relu(self.bn(self.conv(x))))
```

## 3. 激活函数与损失函数

### 激活函数

| 激活 | 特点 | 适用 |
|---|---|---|
| ReLU | 默认（快/简单） | 隐藏层默认 |
| LeakyReLU | 防神经元死亡 | ReLU 效果差时 |
| Sigmoid | 0-1 输出 | 二分类输出 |
| Softmax | 概率分布 | 多分类输出 |
| GELU | Transformer 标配 | LLM |

### 损失函数

```python
# 分类
nn.CrossEntropyLoss()        # 多分类（内置 softmax，别重复加）
nn.BCEWithLogitsLoss()       # 二分类

# 回归
nn.MSELoss()                 # 均方误差
nn.L1Loss()                  # 平均绝对误差
```

### 使用

```python
criterion = nn.CrossEntropyLoss()
loss = criterion(logits, labels)   # logits: (batch, classes) 未过 softmax
```

## 4. 自定义模型

### 完整示例：MLP

```python
import torch
import torch.nn as nn

class MLP(nn.Module):
    def __init__(self, input_dim=784, hidden=128, num_classes=10, dropout=0.3):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(input_dim, hidden),
            nn.ReLU(),
            nn.Dropout(dropout),
            nn.Linear(hidden, num_classes),
        )

    def forward(self, x):
        x = x.view(x.size(0), -1)      # 展平（batch, 784）
        return self.net(x)

model = MLP()
out = model(torch.randn(8, 1, 28, 28))   # (8, 10)
```

### 自定义层（有参数）

```python
class MyLinear(nn.Module):
    def __init__(self, in_f, out_f):
        super().__init__()
        # 可训练参数必须 nn.Parameter
        self.weight = nn.Parameter(torch.randn(in_f, out_f) * 0.1)
        self.bias = nn.Parameter(torch.zeros(out_f))

    def forward(self, x):
        return x @ self.weight + self.bias
```

### 设计原则

```
① forward 只做前向（不要在里面 backward）
② 子模块用 nn 模块（自动注册）
③ 可训练参数用 nn.Parameter
④ 模型要可打印（print(model) 看结构）
```

## 5. Sequential 与组合

### nn.Sequential（顺序模型）

```python
model = nn.Sequential(
    nn.Linear(784, 128),
    nn.ReLU(),
    nn.Linear(128, 10),
)
```

| 方式 | 适用 |
|---|---|
| Sequential | 纯顺序网络（快速） |
| 自定义 Module | 分支/残差/复杂结构 |
| ModuleList/ModuleDict | 动态层列表 |

### 残差示例（分支结构必须自定义）

```python
class ResidualBlock(nn.Module):
    def __init__(self, dim):
        super().__init__()
        self.fc = nn.Linear(dim, dim)

    def forward(self, x):
        return x + torch.relu(self.fc(x))    # 残差连接
```

## 6. 参数管理与模型操作

### 参数访问

```python
for name, param in model.named_parameters():
    print(name, param.shape, param.requires_grad)

model.parameters()          # 所有参数（优化器用）
model.state_dict()          # 参数字典（保存用）
```

### 模型常用操作

```python
model.train()      # 训练模式（Dropout/BatchNorm 生效）
model.eval()       # 评估模式（确定性）
model.to(device)   # 移动设备（cpu/cuda）
model.cuda()       # 快捷方式
```

### 模式切换的坑

```
eval() 忘切 → Dropout 随机性导致验证结果不稳定
评估前必须 model.eval() + torch.no_grad()
```

## 7. 面试高频问法

| 问题 | 回答要点 |
|---|---|
| nn.Module 核心？ | 参数管理 + forward（唯一必须实现） |
| 可训练参数怎么定义？ | nn.Parameter（普通 tensor 不注册） |
| CrossEntropyLoss 注意？ | 内置 softmax（logits 直接传） |
| train/eval 区别？ | Dropout/BatchNorm 行为变化 |
| Sequential 局限？ | 无分支——分支要自定义 Module |
| 自定义模型步骤？ | init 定义层 + forward 定义计算 |

### 面试加分表达

> "nn.Module 的核心是'自动注册'：init 里赋值的子模块自动进 parameters，forward 是唯一必须实现的——这保证了参数管理、保存加载、to(device) 都是统一的。两个易错点：可训练参数必须 nn.Parameter 包装；CrossEntropyLoss 内置 softmax（logits 直接传，别重复加）。"

## 8. 模型调试与常见错误

| 错误 | 原因 | 排查 |
|---|---|---|
| 维度不匹配 | forward 形状算错 | 打印每层输出形状 |
| 参数为 0 | 忘 nn.Parameter | 检查 named_parameters |
| 梯度为 None | requires_grad=False | 检查叶子节点 |
| 验证结果飘 | 忘 eval() | 模式切换（Dropout 随机） |
| 无法保存 | 含不可序列化对象 | 只存 state_dict |
| 前向报错 | 结构逻辑错 | 单步调试 forward |

### 调试技巧

```
① 小输入跑通：用 batch=1 小 tensor 验证形状
② 打印形状：每层后 print(x.shape)
③ 检查梯度：loss.backward() 后看 param.grad
④ 数值检查：输出 NaN 查 loss/学习率
```

## 9. 常见误区

| 误区 | 真相 |
|---|---|
| "模型必须继承 nn.Module" | 是——参数管理全靠它 |
| "forward 里能 backward" | 前向只做计算（反向在循环里） |
| "Sequential 够用" | 分支/残差必须自定义 Module |
| "Dropout 一直开" | 训练开、评估关（eval()） |
| "损失函数随便选" | 分类/回归要匹配（CE/MSE） |

> 🎯 核心要点：nn.Module（参数管理 + forward）；可训练参数 nn.Parameter；常用层按用途选（Linear/Conv/LSTM/Transformer）；CrossEntropyLoss 内置 softmax；train/eval 模式切换（Dropout/BatchNorm）；Sequential 用于纯顺序、分支用自定义 Module；调试三板斧（小输入/打印形状/查梯度）；残差/复杂结构自定义。
