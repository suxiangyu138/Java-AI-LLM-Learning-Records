## 1. 数据管道总览

```
原始数据 → Dataset（索引取样本）→ DataLoader（批量/乱序/并行）→ 模型
                 ↑
            transforms（预处理）
```

| 组件 | 职责 | 类比 |
|---|---|---|
| Dataset | 样本索引（len + getitem） | 菜谱 |
| transforms | 预处理（归一化/增强） | 洗菜切菜 |
| DataLoader | 批量/打乱/多进程 | 上菜流水线 |

## 2. Dataset 自定义

### 标准模板

```python
from torch.utils.data import Dataset

class MyDataset(Dataset):
    """必须实现 __len__ 和 __getitem__"""

    def __init__(self, data, labels, transform=None):
        self.data = data
        self.labels = labels
        self.transform = transform

    def __len__(self):
        return len(self.data)

    def __getitem__(self, idx):
        x = self.data[idx]
        y = self.labels[idx]
        if self.transform:
            x = self.transform(x)
        return x, y
```

### 使用

```python
dataset = MyDataset(data, labels, transform=ToTensor())
x, y = dataset[0]        # 取单样本
len(dataset)             # 样本数
```

### 设计要点

| 要点 | 说明 |
|---|---|
| 惰性加载 | getitem 时读数据（不要 init 全加载大文件） |
| transform 在 getitem | 每个样本独立预处理（可增强） |
| 返回 tensor | 统一输出 torch 张量 |

## 3. DataLoader 配置

### 核心参数

```python
from torch.utils.data import DataLoader

loader = DataLoader(
    dataset,
    batch_size=32,      # 批量大小
    shuffle=True,       # 打乱（训练 True/验证 False）
    num_workers=4,      # 并行加载进程数
    pin_memory=True,    # GPU 训练加速（锁页内存）
    drop_last=False,    # 丢弃不完整批次
)
```

### 参数选择

| 参数 | 建议 | 说明 |
|---|---|---|
| batch_size | 32-256（按显存） | 影响训练稳定性与速度 |
| num_workers | CPU 核数的一半 | 数据加载并行 |
| shuffle | 训练 True | 防顺序偏差 |
| pin_memory | GPU 训练 True | 传输加速 |

### 迭代

```python
for epoch in range(3):
    for batch_x, batch_y in loader:
        # batch_x: (batch, ...) 批量张量
        ...
```

## 4. transforms 预处理

### 常用 transforms

```python
from torchvision import transforms

transform = transforms.Compose([
    transforms.Resize((224, 224)),        # 缩放
    transforms.RandomHorizontalFlip(),    # 数据增强（翻转）
    transforms.RandomRotation(15),        # 随机旋转
    transforms.ToTensor(),                # PIL → Tensor（0-1 归一化）
    transforms.Normalize(mean=[0.5], std=[0.5]),  # 标准化
])
```

### 分类

| 类别 | 例子 |
|---|---|
| 几何 | Resize/CenterCrop/RandomCrop/Flip/Rotate |
| 色彩 | ColorJitter/灰度 |
| 张量转换 | ToTensor/Normalize/ConvertImageDtype |
| 自定义 | Lambda（函数式） |

### 训练 vs 验证的 transforms

```
训练：增强（随机翻转/旋转）——泛化
验证/测试：只做基本处理（Resize/ToTensor/Normalize）——确定性
```

## 6. 性能优化实践

### 数据加载瓶颈

```
训练慢的常见原因：GPU 等数据（数据加载是瓶颈）
现象：GPU 利用率低（nvidia-smi 看）
```

### 优化手段

| 手段 | 效果 |
|---|---|
| num_workers 调大 | 并行读取（CPU 核数一半起步） |
| pin_memory=True | GPU 传输加速 |
| 持久化 worker | persistent_workers=True（减少重启开销） |
| 内存映射/缓存 | 大数据集预读 |
| 预取 | prefetch_factor 调大 |

### 排查数据瓶颈

```
① 单独测 loader 速度（不训练只迭代）
② GPU 利用率（nvidia-smi）低 → 数据慢
③ 逐步调 num_workers 观察吞吐
```

### 常见坑

| 坑 | 现象 | 对策 |
|---|---|---|
| Windows num_workers>0 报错 | 多进程保护 | if __name__ == "__main__" 包裹 |
| shuffle 忘记 | 训练偏差 | 训练 loader shuffle=True |
| 增强过度 | 训练集失真 | 增强适度 |
| 数据不平衡 | 模型偏向多数类 | 加权采样（WeightedRandomSampler） |
| 内存爆 | 数据集全载入 | 惰性读取/内存映射 |

## 7. 面试高频问法

| 问题 | 回答要点 |
|---|---|
| Dataset 必须实现什么？ | __len__ + __getitem__ |
| DataLoader 作用？ | 批量/乱序/并行加载 |
| num_workers 怎么调？ | CPU 核数一半起步，GPU 利用率低就调大 |
| pin_memory？ | GPU 传输加速（锁页内存） |
| 训练/验证 transform 区别？ | 训练增强、验证确定性 |
| 数据加载慢怎么排查？ | 单独测 loader + GPU 利用率 |
| 类不平衡怎么办？ | 加权采样/过采样 |

### 面试加分表达

> "数据管道我按三件事调优：num_workers 配 CPU 核数一半、pin_memory 开（GPU 训练）、训练/验证 transform 分离（训练增强、验证确定性）。排数据瓶颈先看 GPU 利用率——利用率低大概率是数据加载慢，单独测 loader 定位。"

> 🎯 核心要点：Dataset（len+getitem）+ DataLoader（批量/乱序/并行）+ transforms（预处理/增强）；训练增强、验证确定性；数据瓶颈三优化（workers/pin_memory/持久化）；惰性加载防内存爆；Windows 多进程要 main 包裹；类不平衡用加权采样。
