## 1. 训练四步循环

### 标准四步

```python
for epoch in range(num_epochs):
    for x, y in train_loader:
        optimizer.zero_grad()      # ① 清梯度（防累加）
        logits = model(x)          # ② 前向
        loss = criterion(logits, y) # ③ 损失
        loss.backward()            # ④ 反向（算梯度）
        optimizer.step()           # ⑤ 更新参数
```

### 每步的作用

| 步 | 作用 | 易错 |
|---|---|---|
| zero_grad | 清上一轮梯度 | 忘记 = 梯度累加 |
| forward | 前向计算 | no_grad 会断梯度 |
| backward | 反向求导 | 只能一次（动态图） |
| step | 参数更新 | 必须在 backward 后 |

## 2. 优化器

### 常用优化器

| 优化器 | 特点 | 适用 |
|---|---|---|
| SGD | 简单/带动量 | 经典（需调 lr） |
| Adam | 自适应学习率 | 通用默认 |
| AdamW | Adam + 权重解耦 | **LLM/Transformer 标准** |

### 使用

```python
import torch.optim as optim

# SGD（动量）
optimizer = optim.SGD(model.parameters(), lr=0.01, momentum=0.9)

# AdamW（推荐默认，尤其 LLM）
optimizer = optim.AdamW(model.parameters(), lr=1e-4, weight_decay=0.01)
```

### 优化器选择

```
小模型/经典 → SGD（可调）
通用 → Adam（lr 1e-3）
Transformer/LLM → AdamW（lr 1e-4~3e-5，weight_decay 0.01）
```

## 3. 学习率调度

### 为什么需要调度

```
学习率太大：震荡不收敛
学习率太小：收敛慢/卡局部最优
调度 = 先大后小（快速前进 → 精细收敛）
```

### 常用调度器

```python
# 余弦退火（推荐）
scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=50)

# 阶梯下降
scheduler = optim.lr_scheduler.StepLR(optimizer, step_size=10, gamma=0.5)

# 预热（LLM 常用）
from transformers import get_linear_schedule_with_warmup
scheduler = get_linear_schedule_with_warmup(
    optimizer, num_warmup_steps=1000, num_training_steps=50000,
)
```

### 调度器使用

```python
for epoch in range(50):
    train_one_epoch(...)
    scheduler.step()        # 每 epoch 更新学习率
```

## 4. 完整训练脚本

```python
"""完整训练流程：模型+数据+训练+验证"""
import torch
import torch.nn as nn
from torch.utils.data import DataLoader

def train_model(model, train_loader, val_loader, epochs=10, lr=1e-3, device="cuda"):
    model.to(device)
    criterion = nn.CrossEntropyLoss()
    optimizer = torch.optim.AdamW(model.parameters(), lr=lr)
    scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=epochs)

    for epoch in range(epochs):
        # ── 训练 ──
        model.train()
        total_loss, correct, total = 0, 0, 0
        for x, y in train_loader:
            x, y = x.to(device), y.to(device)
            optimizer.zero_grad()
            logits = model(x)
            loss = criterion(logits, y)
            loss.backward()
            optimizer.step()

            total_loss += loss.item()
            correct += (logits.argmax(1) == y).sum().item()
            total += y.size(0)
        scheduler.step()

        # ── 验证 ──
        val_acc = evaluate(model, val_loader, device)
        print(f"Epoch {epoch+1}: loss={total_loss/len(train_loader):.4f} "
              f"acc={correct/total:.4f} val_acc={val_acc:.4f}")

def evaluate(model, loader, device):
    model.eval()
    correct, total = 0, 0
    with torch.no_grad():                    # 推理不建图
        for x, y in loader:
            x, y = x.to(device), y.to(device)
            correct += (model(x).argmax(1) == y).sum().item()
            total += y.size(0)
    return correct / total
```

### 脚本要点

| 要点 | 说明 |
|---|---|
| model.train/eval | 训练验证模式切换 |
| no_grad 验证 | 省内存不建图 |
| to(device) | 数据和模型都移动 |
| 指标记录 | loss/acc 每轮打印 |
| 调度器 | epoch 后 step |

## 5. 验证与早停

### 早停（防过拟合）

```python
best_val, patience, counter = 0, 5, 0
for epoch in range(epochs):
    val_acc = evaluate(model, val_loader, device)
    if val_acc > best_val:
        best_val = val_acc
        torch.save(model.state_dict(), "best.pt")   # 存最优
        counter = 0
    else:
        counter += 1
        if counter >= patience:
            print("早停触发")
            break
```

### 检查点保存（恢复训练）

```python
torch.save({
    "model": model.state_dict(),
    "optimizer": optimizer.state_dict(),
    "epoch": epoch,
}, "checkpoint.pt")

# 恢复
ckpt = torch.load("checkpoint.pt", weights_only=True)   # 安全加载（防任意代码执行）
model.load_state_dict(ckpt["model"])
optimizer.load_state_dict(ckpt["optimizer"])
```

> ⚠️ 安全铁律：`torch.load()` 默认 `weights_only=False` 会反序列化任意 Python 对象（任意代码执行风险）——**只加载张量/简单结构时务必 `weights_only=True`**（或设环境变量 `TORCH_FORCE_WEIGHTS_ONLY_LOAD=1`）；只信任自己生成的模型文件，绝不加载来源不明的 .pt/.bin。

## 6. torch.compile 接入

### 一行接入

```python
model = torch.compile(model)    # 训练/推理通用

# 带配置（可选）
model = torch.compile(model, mode="max-autotune")  # 或 reduce-overhead
```

### 模式选择

| mode | 适用 |
|---|---|
| 默认 | 通用平衡 |
| reduce-overhead | 小 batch 减少开销 |
| max-autotune | 最大性能（编译慢） |

### 注意事项

```
① 编译有首次开销（预热）——评估用编译后模型
② 动态 shape 支持（2.x 成熟）
③ aot_compile 预编译可消除生产冷启动（07 篇）
④ 与 AMP/DDP 兼容（06 篇）
```

## 7. 训练常见问题

| 问题 | 原因 | 对策 |
|---|---|---|
| loss 为 NaN | 学习率大/数值不稳定 | 降 lr/加归一化 |
| loss 不降 | 学习率小/数据问题 | 调 lr/检查数据 |
| 过拟合（train 好 val 差） | 模型大/数据少 | 正则/增强/早停 |
| 欠拟合（都差） | 模型小/epochs 少 | 加容量/加轮次 |
| 梯度爆炸 | 大模型/RNN | 梯度截断 |
| GPU OOM | batch 大 | 降 batch/AMP（06 篇） |

### 排查思路

```
① loss 曲线看趋势（不降/震荡/NaN）
② 训练 vs 验证差距（过拟合判断）
③ 先小数据跑通（代码正确性）
④ 再调超参（一次一个）
```

## 8. 面试高频问法

| 问题 | 回答要点 |
|---|---|
| 训练四步？ | zero_grad/forward/backward/step |
| AdamW vs Adam？ | 权重解耦正则（LLM 标准） |
| 学习率调度为什么？ | 先大后小（快速+精细收敛） |

| 过拟合对策？ | 正则/增强/早停/降容量 |

### 面试加分表达

> "训练循环四步是死的（清零/前向/反向/更新），活的在超参：AdamW + 余弦退火是通用起点，LLM 用 warmup。两个工程关键：检查点要存 model+optimizer+epoch（可恢复训练）、eval 必须 no_grad+eval()。torch.compile 一行接入，训练提速 30-50%。"
