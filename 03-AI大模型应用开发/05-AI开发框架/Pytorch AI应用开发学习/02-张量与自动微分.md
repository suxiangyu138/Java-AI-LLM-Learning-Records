## 1. Tensor 基础

### 什么是 Tensor

```
Tensor = 多维数组（numpy 的深度学习版）：
0 维：标量     1 维：向量
2 维：矩阵     3+ 维：批量数据（batch, channel, H, W）
支持 GPU 加速 + 自动梯度
```

### 与 NumPy 的关系

```python
import torch
import numpy as np

# numpy ↔ tensor 互转
arr = np.array([1, 2, 3])
t = torch.from_numpy(arr)          # numpy → tensor（共享内存）
back = t.numpy()                   # tensor → numpy

# tensor 转 torch 张量（拷贝）
t2 = torch.tensor([1, 2, 3])
```

### 核心属性

```python
t = torch.randn(3, 4)
t.shape        # torch.Size([3, 4])
t.dtype        # torch.float32
t.device       # cpu / cuda:0
t.requires_grad  # 是否需要梯度（False 默认）
```

## 2. 创建与运算

### 常用创建

```python
torch.tensor([1, 2, 3])        # 从数据
torch.zeros(2, 3)              # 全零
torch.ones(2, 3)               # 全一
torch.randn(2, 3)              # 标准正态随机
torch.arange(10)               # 0-9
torch.linspace(0, 1, 5)        # 等间隔
torch.randint(0, 10, (2, 3))   # 整数随机
```

### 常用运算

```python
# 算术（逐元素）
a + b / a * b / torch.add(a, b)
# 矩阵乘
torch.matmul(a, b) / a @ b
# 激活与规约
torch.relu(x) / torch.sigmoid(x)
x.mean() / x.sum() / x.max()
# 广播（numpy 同规则）
a = torch.randn(3, 1); b = torch.randn(1, 4)
a + b   # 广播为 (3, 4)
```

### 数据类型（重要）

```python
# 默认 float32；显式指定
t = torch.tensor([1], dtype=torch.float32)
t.half()    # FP16（混合精度用）
t.long()    # int64（标签用）
```

## 3. 索引/视图/形状操作

### 索引与切片

```python
t = torch.randn(3, 4)
t[0]            # 第一行
t[:, 1]         # 第二列
t[1:, :2]       # 子区域
t[t > 0]        # 条件索引（掩码）
```

### 视图 vs 拷贝

```python
# view：共享内存（不复制，高效）——要求连续内存
v = t.view(4, 3)
# reshape：可能复制（更安全）
r = t.reshape(4, 3)
# 转置（返回视图）
tr = t.t()
```

```
视图（view）共享底层数据 → 修改互相影响
拷贝（clone）独立 → 安全
转置/非连续张量 view 会报错 → 先 contiguous()
```

### 形状操作

```python
t.unsqueeze(0)    # 加维度（(3,)→(1,3)）
t.squeeze(1)      # 去维度
t.permute(0, 2, 1)  # 重排维度（转置高维）
t.flatten()       # 展平
t.transpose(0, 1) # 交换维度
```

## 4. 自动微分（autograd）

### 核心用法

```python
# 1. 需要梯度的张量
x = torch.randn(3, requires_grad=True)
w = torch.randn(3, requires_grad=True)

# 2. 前向计算
loss = (x * w).sum()

# 3. 反向传播
loss.backward()

# 4. 查看梯度
print(w.grad)    # d(loss)/dw
```

### 梯度计算示例

```python
x = torch.tensor(2.0, requires_grad=True)
y = x ** 2 + 3 * x          # y = x² + 3x
y.backward()
print(x.grad)               # 2x + 3 = 7 ✅
```

### 不求梯度的三种方式

```python
# 推理/冻结层时（省内存省算力）
with torch.no_grad():
    out = model(x)

torch.inference_mode()       # 更激进（推理推荐）
x.requires_grad_(False)      # 就地关闭
```

## 5. 计算图机制

### 动态图

```
PyTorch = 动态计算图：
前向执行时"边算边建图"
每个算子记录：输入 + 如何反向
backward() 沿图反向传播
```

### 图的组成

```
节点：张量（data + grad）
边：运算（记录反向函数）
叶子：requires_grad 的输入（梯度累积在叶子）

例：loss = (x*w).sum()
x ──┐
    ├─ mul → sum → loss
w ──┘
backward：loss → sum → mul → 梯度到 x 和 w
```

### 动态图 vs 静态图

| 维度 | 动态图（PyTorch） | 静态图（TF1 时代） |
|---|---|---|
| 建图时机 | 运行时（边算边建） | 先建后跑 |
| 灵活性 | 高（if/循环随意） | 低（图固定） |
| 调试 | 友好（Python 栈） | 难 |
| 性能 | compile 补齐 | 原生快 |

## 6. 梯度控制与实战

### 梯度清零（重要）

```python
# 梯度是累加的！每轮必须清零
optimizer.zero_grad()
loss.backward()
optimizer.step()
```

### 梯度截断（RNN/大模型）

```python
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
```

### 冻结参数（迁移学习）

```python
for param in model.parameters():
    param.requires_grad = False
# 只训练最后层
for param in model.fc.parameters():
    param.requires_grad = True
```

### 常见坑

| 坑 | 现象 | 对策 |
|---|---|---|
| 梯度累加 | loss 异常 | zero_grad 每轮 |
| 原地修改 | autograd 报错 | 用 clone/新变量 |
| 忘记 no_grad | 推理爆内存 | 推理用 no_grad |
| 视图误改 | 数据被意外修改 | 用 clone |
| dtype 不匹配 | 计算报错 | 显式转换 |

## 7. 面试高频问法

| 问题 | 回答要点 |
|---|---|
| Tensor 是什么？ | 多维数组 + GPU + 梯度 |
| 动态图？ | 边算边建图，灵活可调试 |
| backward 怎么算梯度？ | 沿计算图链式法则反向传播 |
| 为什么梯度要清零？ | autograd 累加梯度（每轮清零） |
| view vs clone？ | 共享内存 vs 独立拷贝 |
| no_grad 何时用？ | 推理/冻结层（省内存） |
| 叶子节点？ | requires_grad 的输入，梯度累积处 |

### 面试加分表达

> "PyTorch 的地基是动态计算图：前向边算边建图，每个算子记录反向函数，backward 沿图链式求导。三个工程要点：梯度是累加的必须每轮清零、推理必须 no_grad（省内存）、原地修改会破坏 autograd——这些坑踩过一次就记住了。"

> 🎯 核心要点：Tensor = 多维数组 + GPU + 梯度（与 numpy 互转/视图共享内存）；autograd = 动态计算图 + 反向传播；梯度三纪律（清零/no_grad/防原地修改）；动态图灵活可调试（compile 补齐性能）；dtype/device 管理是常见坑源。
