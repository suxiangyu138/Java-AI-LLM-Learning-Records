## 1. OpenAI — 全能标杆

| 维度 | 详情 |
|------|------|
| 核心模型 | GPT-5.2/5.4/5.5、o3-pro（推理）、GPT-5 Turbo（性价比） |
| 最大上下文 | 100 万 Token（GPT-5.4） |
| 核心优势 | 数学/科学顶尖、生态最完善（插件+GPTs+API 工具链）、函数调用成熟 |
| API 方式 | `api.openai.com`，Python/Node.js 官方 SDK |
| 参考价格 | GPT-5.4 输入 $5/百万 Token；GPT-5 Turbo 输入 $1/百万 Token |
| 中文能力 | 中上，不如国产头部自然 |
| 国内访问 | 需代理 |
| 最佳场景 | 通用对话、结构化输出、复杂推理、多步 Agent |

**追问：** GPT-5 Turbo vs GPT-5.4 怎么选？→ 90% 的场景 Turbo 足够且成本低 5 倍；只在极端复杂科研推理、数学证明时选 5.4/5.5。

## 2. Anthropic — 编程与 Agent 首选

| 维度 | 详情 |
|------|------|
| 核心模型 | Claude Opus 4.6/4.7、Sonnet 4.5、Haiku 3.5 |
| 最大上下文 | 100 万 Token |
| 核心优势 | **SWE-bench 72.7%**（代码能力业界标杆）、Computer Use（操作电脑）、Extended Thinking（长推理） |
| API 方式 | `api.anthropic.com`，Messages API |
| 参考价格 | Opus $15/$75；Sonnet $3/$15（每百万 Token，输入/输出） |
| 中文能力 | 中上，偏学术翻译腔 |
| 国内访问 | 需代理 |
| 最佳场景 | 复杂代码重构、遗留系统分析、Agent 自主任务、安全敏感应用 |

**追问：** Claude vs ChatGPT 2026 怎么选？→ 代码/Agent/长文档用 Claude；通用对话/生态集成/图像生成用 ChatGPT。编程领域 Claude 已是公认首选。

## 3. Google DeepMind — 多模态与上下文之王

| 维度 | 详情 |
|------|------|
| 核心模型 | Gemini 3.1 Pro/Ultra、3.5 Flash（极致性价比） |
| 最大上下文 | **200 万 Token**，有效上下文 950K（ECL 业界第一） |
| 核心优势 | 原生多模态（视频/音频/图像/文本）、与 Search/Maps/Workspace 生态整合 |
| API 方式 | `generativelanguage.googleapis.com`，Google AI Studio 免费试用 |
| 参考价格 | Flash $0.10/$0.40（极低）；Pro $1.25/$5（每百万 Token） |
| 中文能力 | 中等（偏翻译腔） |
| 国内访问 | 受限（API 需代理） |
| 最佳场景 | 多模态理解（视频/图片分析）、长文档批处理、需要 Google 生态联动 |

## 4. Meta — 开源领袖

| 维度 | 详情 |
|------|------|
| 核心模型 | Llama 4 Maverick（400B MoE）开源、Llama 4 Scout（109B）轻量、Muse Spark（闭源旗舰） |
| 最大上下文 | 100 万 Token |
| 核心优势 | 完全开放权重可商用、FB/IG/WhatsApp 社交生态内置 AI |
| API 方式 | Meta AI 内嵌 Meta 产品；开源版需自行部署 |
| 参考价格 | 开源免费下载（需自行部署 GPU） |
| 中文能力 | 一般（非重点优化语言） |
| 国内访问 | 开源版可下载使用 |
| 最佳场景 | 需要私有化部署的通用模型、研究对比基线、Meta 社交生态内 |

## 5. xAI / Mistral — 差异化力量

| 厂商 | 差异化 | 最佳场景 |
