## 5. 核心概念速查

| 概念 | 一句话 |
|------|--------|
| 模型 API | 调用远程大模型能力（GPT/Claude/DeepSeek），按 Token 计费 |
| AI 应用平台 | 零代码/低代码搭建 AI 应用（知识库、Agent、工作流） |
| AI 编程工具 | IDE 插件/终端 Agent，用 AI 辅助写代码、重构、调试 |
| 模型托管部署 | 将开源/微调模型的权重部署为 API（替代直接调闭源） |
| 向量数据库 | 存储嵌入向量 + 相似性搜索，RAG 的核心基础设施 |
| Token 上下文 | 模型单次能"看到"的最大文本量（2026 主流 100 万+） |
| Agent | 能调用工具、执行多步骤任务、自主规划的 AI 应用 |
| 多模型组合 | 不同任务切换不同模型（日常用免费国产、深度切 Claude/GPT） |

> 🎯 **核心要点**：2026 年 AI 平台选择的黄金法则 — **没有唯一最佳，只有场景最优**。日常聊天用豆包（免费）、编程用 DeepSeek（性价比）或 Claude（复杂工程）、长文档用 Kimi/Claude、多模态用 Gemini。多模型组合是"最聪明用法"。
