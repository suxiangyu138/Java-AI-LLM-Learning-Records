HumanEval (代码生成) 得分：

## 3. 场景化选型指南

```text
通用开发/对话 → GPT-4o 或 Claude 3.5 Sonnet
  差异：GPT-4o 多模态更强/更快；Claude 代码推理略优/长文理解好

代码主力 → GPT-4o 或 Claude 3.5 Sonnet（两者都顶级）

高性价比/批量 → DeepSeek-V3
  1/10 的价格，80%+ 的能力，适合大规模 API 调用

中文私有化 → Qwen-72B（开源可本地部署，中文能力第一梯队）

超长文档分析 → Gemini 1.5 Pro（1M 上下文，可放整本书）

创意写作/头脑风暴 → Claude 3.5 Sonnet（文笔最优，推理最深）
```
