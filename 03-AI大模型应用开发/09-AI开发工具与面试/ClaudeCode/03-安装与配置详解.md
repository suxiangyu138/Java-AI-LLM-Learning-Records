# Claude Code 安装与配置详解

> **核心摘要**：Claude Code CLI 安装配置速查，涵盖 macOS/Linux/Windows 安装方式、配置文件体系、settings.json 详解、CLAUDE.md 项目指令、多模型配置等。

---

## 1. 安装

### macOS / Linux

```bash
# 方式一：npm 全局安装（推荐）
npm install -g @anthropic-ai/claude-code

# 方式二：直接运行（无需安装）
npx @anthropic-ai/claude-code

# 验证安装
claude --version
```

### Windows

```powershell
# 需要 Node.js 18+ 环境
npm install -g @anthropic-ai/claude-code

# 通过 WSL（推荐）：在 WSL2 Ubuntu 中执行 Linux 安装命令
```

### 认证

```bash
# 首次运行会引导 OAuth 登录
claude

# 或使用 API Key
export ANTHROPIC_API_KEY="sk-ant-xxx"
claude
```

## 2. 配置文件体系

```
项目根目录/
├── CLAUDE.md                    # 项目级 Agent 指令（自动加载）
├── .claude/
│   ├── settings.json            # 项目级设置
│   ├── settings.local.json      # 本地覆盖设置（不提交 Git）
│   ├── memory/                  # 项目记忆文件
│   ├── hooks/                   # 项目级 Hook 脚本
│   └── worktrees/               # 临时工作树
用户目录 ~/
├── .claude/
│   ├── settings.json            # 全局设置
│   ├── credentials.json         # 认证凭据
│   ├── history.jsonl            # 对话历史
│   └── keybindings.json         # 自定义快捷键
```

## 3. settings.json 详解

### 3.1 常用配置项

| 配置项 | 说明 |
|--------|------|
| `model` | 默认模型（Opus/Sonnet/Haiku） |
| `theme` | 终端主题（dark/light） |
| `permissions.allow` | 自动允许的工具调用 |
| `permissions.deny` | 禁止的工具调用 |
| `env` | 注入到 Claude Code 运行环境的变量 |
| `hooks` | 事件钩子（pre/post tool use） |

### 3.2 权限配置最佳实践

```json
{
  "permissions": {
    "allow": [
      "Read(*)", "Grep(*)", "Glob(*)",
      "Bash(git *)", "Bash(ls *)", "Bash(cd *)",
      "Bash(npm *)", "Bash(mvn *)", "Bash(node *)", "Bash(python *)"
    ],
    "deny": [
      "Bash(rm -rf *)", "Bash(> *)", "Bash(git push*)",
      "Bash(curl *)", "Bash(wget *)"
    ]
  }
}
```

## 4. CLAUDE.md 项目级指令

```bash
# 快速初始化
claude --init
# 或手动创建
touch CLAUDE.md
```

**内容模板**：

```markdown
# 项目：xxx 管理系统

## 技术栈
- 后端：Spring Boot 3.x + MyBatis Plus + MySQL 8.x + Redis 7.x
- 前端：Vue 3 + Element Plus
- 部署：Docker + Nginx

## 编码规范
- Java 使用阿里巴巴规范
- Controller → Service → Mapper 三层架构
- 统一返回 Result<T> 包装类
```

## 5. 多模型配置

| 模型 | 适用场景 |
|------|---------|
| `claude-opus-4-7` | 复杂推理、架构设计 |
| `claude-sonnet-4-6` | 日常开发（默认） |
| `claude-haiku-4-5` | 快速简单任务 |

```json
{
  "model": "claude-sonnet-4-6",
  "modelOverrides": {
    "fast": "claude-haiku-4-5",
    "agent": "claude-sonnet-4-6"
  }
}
```

## 核心要点回顾

- 安装用 `npm install -g @anthropic-ai/claude-code`
- 认证用 OAuth 登录或 `ANTHROPIC_API_KEY` 环境变量
- CLAUDE.md 放在项目根目录，自动加载为 Agent 指令
- `.claude/settings.json` 管理权限、钩子、环境变量
- 权限系统分三级：allow（自动运行）+ deny（禁止）+ 默认（询问）
