# Claude Code 核心概念与架构

> **核心摘要**：Claude Code 是 Anthropic 官方推出的终端级 AI 编程代理，不是 IDE 插件，而是一个直接运行在终端里的自主编程伙伴。本文深度解析其架构、运行模式和与竞品的本质区别。

---

## 1. Claude Code 是什么

**核心定位对比**：

| 工具 | 交互模式 | 哲学 |
|------|---------|------|
| GitHub Copilot | 被动建议 | 副驾驶（帮你扶着方向盘） |
| Cursor | 对话 + 编辑 | 升级版编辑器 |
| **Claude Code** | **自主执行** | **副司机（你把需求说清楚，它自己开车）** |

## 2. Claude Code 架构

```
用户终端（Terminal）→ 自然语言 / 斜杠命令
       ↓
Claude Code CLI 核心引擎
  ┌──────────┬──────────┬──────────┬────────┐
  │ 消息处理  │ 上下文   │ 工具执行  │ 记忆   │
  │ 模块     │ 管理     │ 引擎     │ 系统   │
  └──────────┴──────────┴──────────┴────────┘
  工具集：Read / Write / Edit / Bash / Grep / Glob / Agent...
       ↓          ↓          ↓
  ┌────────┐ ┌────────┐ ┌────────────┐
  │文件系统 │ │ Shell  │ │ 网络/Git    │
  └────────┘ └────────┘ └────────────┘
       ↑          ↑          ↑
  ┌────────────────────────────────────┐
  │        权限系统（Sandbox）           │
  │  每步操作需用户批准或自动允许          │
  └────────────────────────────────────┘
```

## 3. 核心能力矩阵

| 能力 | 具体表现 |
|------|---------|
| 代码理解 | 读取整个项目结构、理解依赖关系、识别代码规范 |
| 代码生成 | 批量创建多文件、完整功能模块、测试用例 |
| 代码修改 | 精准编辑、复杂重构、跨文件修改 |
| 命令执行 | 跑终端命令、安装依赖、启动服务、运行测试 |
| Git 操作 | 查看日志、创建分支、提交代码、创建 PR |
| 自主规划 | 拆解任务、创建计划、分步执行、自我修正 |

## 4. 运行模式

| 模式 | 命令 | 适用场景 |
|------|------|---------|
| 交互模式（默认） | `claude` | 日常开发对话 |
| 一次性模式 | `claude -p "解释项目架构"` | 快速查询 |
| 管道模式 | `cat error.log \| claude -p "分析"` | 分析输出 |
| 非交互模式 | `claude --print "修复文件" --output-format stream-json` | 自动化集成 |

## 5. 上下文管理机制

```
1. 系统层（System Prompt）：工具定义、运行规则、安全约束
2. 项目层（CLAUDE.md）：项目级自定义指令
3. 会话层（Conversation Context）：对话历史和工具调用结果
4. 按需加载：Agent 读取的文件才进入上下文
```

## 6. 面试核心要点

1. **Claude Code 是什么形态？** CLI 命令行工具，非 IDE 插件
2. **和 Copilot 最大区别？** Claude Code 是自主代理（主动执行），Copilot 是被动补全
3. **怎么给项目上下文？** CLAUDE.md + 自动读取文件 + Agent 搜索
4. **能做 Git 操作吗？** 能，直接操作 Git（commit/branch/push/PR）
5. **权限怎么控制？** 沙箱系统，每步操作可批准/拒绝/设置自动允许

## 核心要点回顾

- Claude Code = 终端里的 AI 编程代理，不是补全而是自主干活
- 架构 = 消息处理 + 上下文管理 + 工具引擎 + 记忆系统 + 权限沙箱
- 对比：Copilot 是副驾，Claude Code 是代驾
- 四种模式：交互 / 一次性 (-p) / 管道 (stdin) / 非交互 (--print)
