# 01 - Codex 概述：两代区分

> 🎯 面试最高频考点——"Codex 和 Copilot 什么关系？"答不出一代/二代区分直接扣分

---

## 1. 两层概念区分（极易混淆）

### 初代 Codex（2021，代码大模型）

基于 GPT-3 微调的**代码专用 Transformer 大模型**，`code-cushman`/`code-davinci` 系列。是**初代 GitHub Copilot 的底层引擎**，仅提供代码生成/解释 API，无自主工程能力。

- 发布时间：2021 年 6 月
- 参数量：12B（code-cushman）、175B（code-davinci-002）
- 训练数据：5400 万 GitHub 公开仓库（159GB Python 代码）
- 退役时间：2023 年 3 月 API 关闭，2024 年 1 月完全下线
- 最终去向：被 GPT-3.5/GPT-4 取代

### 新一代 Codex（2025 至今，软件工程 Agent 产品）

OpenAI 独立产品线，**端到端 AI 软件工程智能体**。搭载 GPT-5/GPT-5.3-Codex 专用代码模型，支持云端沙箱、多文件仓库读写、自动测试、提交 PR、CI/CD 运维全流程。内置 CLI、Web 端、ChatGPT 内置入口。

- 首次发布：2025 年 4 月（Codex CLI 开源）
- 产品形态：CLI 终端工具 + Web 云端 + ChatGPT 内置入口 + API
- 核心模型：GPT-5-Codex（2025.9）、GPT-5.3-Codex（2026.2）
- 核心能力：全流程自主开发——读仓库、改多文件、跑测试、提交 PR

---

## 2. 核心本质

- **初代 Codex**：代码专用 Transformer 模型 = 会写代码的 GPT-3
- **新一代 Codex**：端到端软件工程 Agent = 能自主完成开发任务的 AI 工程师

**本质跃迁**：从"代码补全工具"到"独立完成完整开发任务的 AI 工程师"。

---

## 3. 边界范围

### 支持（擅长）

- Java、Python、JS/TS、Go、Rust、SQL、Shell 等数十种语言
- 项目重构、Bug 修复、单元测试、代码审查
- 脚本自动化、多语言代码迁移
- CRUD 样板代码、配置文件生成

### 不擅长（局限）

- 超大型百万行级复杂架构设计
- 高度私有内部框架
- 底层硬件驱动
- 强行业合规加密代码
