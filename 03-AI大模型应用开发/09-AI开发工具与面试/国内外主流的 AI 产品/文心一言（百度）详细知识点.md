### 2.2 ERNIE知识增强架构

```
传统LLM训练：
  海量文本 → 自监督学习 → 语言模型
  （只学到统计规律，缺少结构化知识）

ERNIE知识增强训练：
  海量文本 + 知识图谱 → 联合训练 → 知识增强语言模型
  （学到统计规律 + 实体关系 + 逻辑推理）
  
  举例：ERNIE知道"李白"不仅是一个词，
        而是{人物→朝代:唐朝→职业:诗人→代表作:静夜思→好友:杜甫}
        这样的结构化知识网络
```

## 11. Java开发者使用指南

### 11.1 百度千帆API

```java
// 百度智能云千帆大模型平台API
// 依赖：com.baidubce:bce-java-sdk

import com.baidubce.BceClientConfiguration;
import com.baidubce.auth.BceCredentials;
import com.baidubce.services.qianfan.QianfanClient;
import com.baidubce.services.qianfan.model.ChatRequest;
import com.baidubce.services.qianfan.model.ChatResponse;

public class WenxinDemo {
    public static void main(String[] args) {
        BceClientConfiguration config = new BceClientConfiguration()
            .withCredentials(new BceCredentials() {
                public String getAccessKeyId() {
                    return System.getenv("BAIDU_ACCESS_KEY");
                }
                public String getSecretAccessKey() {
                    return System.getenv("BAIDU_SECRET_KEY");
                }
            });

        QianfanClient client = new QianfanClient(config);

        ChatRequest request = new ChatRequest()
            .model("ernie-5.0-max")
            .addUserMessage("用Java实现一个二分查找算法")
            .temperature(0.7f)
            .maxOutputTokens(2048);

        ChatResponse response = client.chat(request);
        System.out.println(response.getResult());
    }
}
```

### 11.3 Spring AI 集成

```java
// application.yml
// spring.ai.openai.base-url=https://qianfan.baidubce.com/v1
// spring.ai.openai.api-key=${QIANFAN_API_KEY}
// spring.ai.openai.chat.options.model=ernie-5.0-max

@RestController
public class WenxinController {

    private final ChatClient chatClient;

    public WenxinController(ChatClient.Builder builder) {
        this.chatClient = builder
            .defaultSystem("你是一个精通中国传统文化和历史的学者")
            .build();
    }

    @GetMapping("/wenxin/history")
    public String history(@RequestParam String topic) {
        return chatClient.prompt()
            .user("请详细讲述" + topic + "的历史背景和文化意义")
            .call()
            .content();
    }
}
```

## 核心要点回顾

- **定位**：中文知识库最全的古文/教育/国风专家，不是通用全能型
- **核心壁垒**：百度搜索索引+百度百科+文心一格国风生图，20年中文数据积累
- **三大杀手场景**：古文传统文化（行业第一）、K12教育（中高考专项）、国风图文创作
- **知识增强架构**：ERNIE将知识图谱融入训练，结构化知识理解力更强
- **实时资讯**：百度搜索分钟级索引，中文信息时效性最好
- **最大短板**：代码能力弱、逻辑推理弱、创意写作弱
- **不适合**：编程开发、复杂逻辑推理、英文场景、长文档深度分析
- **Java集成**：百度千帆API + OpenAI兼容格式 + Spring AI
