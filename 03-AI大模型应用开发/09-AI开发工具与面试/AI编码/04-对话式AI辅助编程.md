# 04 - 对话式 AI 辅助编程

> 🎯 ChatGPT/Claude 不只是聊天工具 — 它们是最好的"即时代码顾问"。好的 Prompt 能让代码质量和开发速度同时翻倍

## 1. 基础定义

对话式 AI 编程指通过自然语言对话，让 LLM 完成代码生成、解释、调试、重构、翻译等任务。

**核心本质**：用自然语言替代搜索引擎和文档阅读，直接获得可运行的代码方案。

## 2. 溯源历史

- 2022.12 ChatGPT → 首次让开发者用自然语言获取代码
- 2023.03 GPT-4 → 代码理解能力质的飞跃（HumanEval 67%→87%）
- 2024.06 Claude 3.5 Sonnet → 代码生成能力超越 GPT-4
- 2025 — 多模型协作成主流（不同任务用不同模型）

## 3. 底层原理

LLM 代码生成 = 基于海量代码训练的自回归 Token 预测。GitHub 代码是主要训练来源。

**为什么 LLM 能写代码？**

① 训练数据包含数十亿行开源代码

② 代码有严密的语法规则 → 比自然语言更容易学习

③ Self-Attention 捕捉长距离依赖（函数调用/变量引用）

## 5. 价值与应用

### Java 后端高频 Prompt 模板

```text
【代码生成】
"用 Spring Boot 3 + MyBatis Plus 写一个带分页和条件查询的用户管理接口。
包含：Entity/DTO/Controller/Service/Mapper。要求参数校验和全局异常处理。"

【Bug 修复】
"以下代码在并发场景下偶尔出现 NPE，请分析原因并给出修复方案：
[贴代码]"

【代码审查】
"审查这段代码的并发安全性、异常处理和性能问题。按阿里巴巴 Java 规范打分。"

【重构】
"把这个 Service 类拆成两个：UserQueryService 和 UserCommandService（CQRS 模式）"

【从 SQL 生成代码】
"根据以下建表语句生成完整的 MyBatis Plus Entity + Mapper：
CREATE TABLE orders (...)"
```

## 6. 性能与代价

- Token 成本：中等复杂度任务约 2000-5000 tokens/次
- GPT-4o 单次对话约 $0.02-0.05
- 使用建议：简单问题用 DeepSeek(省钱)，复杂问题用 Claude/GPT-4o

## 7. 拓展延伸

**前置知识**：熟悉目标语言的语法和框架
**后置衍生**：Agent 模式（对话+自主执行）、Function Calling
**跨领域联动**：对话式编程 + IDE 补全 = 全场景覆盖

## 8. 实操验证

```text
验证 GPT-4o vs Claude 的差异：
  任务：用 Java 实现带过期时间的 LRU 缓存
  GPT-4o：给出标准实现（LinkedHashMap）
  Claude：给出三种方案 + 线程安全讨论 + JMH 基准测试建议
  → Claude 的代码方案更工程化
```

## 9. 核心口诀

> 对话式编程 = 自然语言输入 + 高质量 Prompt + 人工审查输出。Prompt 决定下限，审查决定上限。
