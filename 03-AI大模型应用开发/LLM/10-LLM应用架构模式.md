## 1. RAG 检索增强生成

### 1.1 为什么需要 RAG

```text
LLM 的三大知识局限：
  ❌ 知识截止（训练到某天，不知道之后的事）
  ❌ 私有数据（不知道你公司的内部文档）
  ❌ 幻觉（不知道时可能编造）

RAG 的解决方案：
  查询 → 检索相关文档 → 把文档+查询一起给 LLM → 基于文档回答
```

### 1.2 RAG 架构

```text
离线阶段：
  文档 → 分块 → Embedding → 向量数据库

在线阶段：
  用户查询 → Embedding → 向量检索 Top-K → Prompt组装 → LLM生成

提示词模板：
  "根据以下参考资料回答问题。如果资料中没有，就说不知道。
  参考资料：{retrieved_docs}
  用户问题：{query}"
```

### 1.3 RAG 进阶：Agentic RAG

```text
基础 RAG：一次检索 → 一次生成
Agentic RAG：多次检索 + 反思 + 修正

流程：
  查询 → 检索 → LLM 评估检索质量
    → 不够好？改写查询 → 重新检索
    → 需要更多信息？生成子问题 → 多次检索
    → 够了？综合生成最终答案
```

## 2. Agent 智能体架构

### 2.1 Agent 核心循环

```text
Agent 循环 (ReAct / Tool-use loop)：

while 任务未完成:
    1. Think  → LLM 分析当前状态，决定下一步
    2. Act    → 执行工具（搜索/计算/API调用）
    3. Observe → 获取工具执行结果
    4. Reflect → 是否需要调整计划？
```

### 2.2 Agent 架构模式

| 模式 | 描述 | 适用 |
|------|------|------|
| **单 Agent + 工具** | 一个 Agent 调用多个工具 | 简单任务 |
| **Router Agent** | 先分类，再路由到不同 Agent | 多类型请求 |
| **Multi-Agent 协作** | 多个 Agent 分工协作 | 复杂项目 |
| **Plan-Execute** | 先规划再执行，中间可调整 | 长流程任务 |
| **Human-in-the-Loop** | 关键步骤需要人类确认 | 高风险任务 |

### 2.3 Agent 的关键组件

```text
┌────────────────────────────────────┐
│              Agent                 │
├────────────────────────────────────┤
│ LLM (推理核心)                      │
│ Memory (短期+长期记忆)               │
│ Tools (外部能力)                     │
│ Planning (任务分解+调度)             │
│ Guardrails (安全护栏)               │
└────────────────────────────────────┘
```

## 3. 多模态融合架构

```text
多模态 LLM = 文本 + 图片 + 音频 + 视频 统一处理

主流架构：
├── 共享嵌入空间（CLIP风格）
│   图片 → Vision Encoder → 图片Token → 和文本Token一起送给LLM
│   (GPT-4V, Claude Vision, Qwen-VL)
│
└── 原生多模态（从头训练）
    文本+图片+音频 → 统一的Transformer → 统一输出
    (Gemini, GPT-4o)
```

## 4. 选型指南

```text
你的任务？
│
├── 需要外部知识（实时/私有）？
│   └── RAG ✅
│
├── 需要多步操作（查库→计算→发邮件）？
│   └── Agent ✅
│
├── 输入包含图片/音频？
│   └── 多模态模型 ✅
│
├── 只是对话/生成/翻译...
│   └── 纯 LLM ✅（不需要架构）
│
└── 复杂：既需要知识库，又需要操作工具？
    └── Agentic RAG ✅（RAG + Agent 结合）
```

## 核心要点回顾

- RAG = 检索 + 生成，解决幻觉和知识过期
- Agent = LLM + 工具 + 记忆 + 规划，自主完成多步任务
- Multi-Agent = 多 Agent 分工协作，适合复杂项目
- 多模态 = 视觉/音频 Encoder → LLM 统一理解
- 选型：知识→RAG，操作→Agent，多媒体→多模态
