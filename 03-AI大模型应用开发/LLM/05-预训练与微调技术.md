## 1. 预训练概述

```text
预训练 (Pre-training) = 在大规模语料上学习语言的通用知识

输入: 数万亿 Token 的文本（网页/书籍/代码/论文）
输出: 一个能"续写"文本的基础模型
成本: Llama 3 405B ~$60M, GPT-4 ~$100M+

预训练后的模型：
  ✅ 知道世界上有什么（知识）
  ✅ 理解语言结构（语法/逻辑）
  ✅ 能写代码/翻译/推理
  ❌ 不知道"如何对话"（只会续写）
  ❌ 不会遵循指令
  ❌ 可能输出有害内容
```

## 2. SFT 监督微调

```text
SFT (Supervised Fine-Tuning) = 在人工撰写的问答对上训练

训练数据示例：
  {"instruction": "把以下句子翻译成英文", "input": "你好世界", "output": "Hello world"}
  {"instruction": "写一段Python快速排序", "input": "", "output": "def quicksort(arr):..."}
  ...

效果：
  ✅ 学会"对话模式"（Q&A 而非续写）
  ✅ 学会遵循指令
  ✅ 学会特定格式输出

数据量：1万-10万条高质量指令
成本：几小时 GPU，$100-1000
```

### SFT 的关键技巧

```text
1. 数据质量 > 数据数量
   1000 条高质量 > 10000 条低质量

2. 多样性覆盖
   翻译/代码/推理/创意/格式 → 每种至少 100 条

3. 格式一致
   统一使用 ChatML/Llama Chat 等标准格式

4. 长度分布
   包含短回答（1-2句）和长回答（多段），匹配实际使用场景
```

## 3. LoRA 与 QLoRA

### 3.1 核心思想

```text
全参数微调：更新模型的所有参数
  → 70B 模型需要 ~140GB 显存（训练时 4x = 560GB）
  → 需要 8×A100

LoRA (Low-Rank Adaptation)：
  → 冻结原模型 → 旁路插入小矩阵 → 只训练旁路
  → 训练参数：原模型的 0.1%-1%
  → 7B LoRA 只需要 4GB 显存（RTX 3060 就能训！）

LoRA 的数学：
  W' = W + A·B
  其中 W 冻结(n×n)，A 和 B 是低秩矩阵(n×r, r×n)，r << n 且 r=8-64
```

### 3.2 QLoRA = LoRA + 4-bit 量化

```text
QLoRA = 把原模型量化到 4-bit + 旁路 LoRA 训练

效果：
  70B 模型的 QLoRA 训练仅需 ~48GB 显存
  → 单个 A6000 就能微调 70B！
  质量几乎不损失（< 1%）

关键创新（QLoRA 论文）：
  - NF4 (NormalFloat4)：专门为正态分布权重设计的 4-bit 量化
  - Double Quantization：量化常数再量一次，再省 0.4 bit
  - Paged Optimizers：利用统一内存避免 OOM
```

### 3.3 代码示例

```python
from peft import LoraConfig, get_peft_model
from transformers import AutoModelForCausalLM

model = AutoModelForCausalLM.from_pretrained(
    "meta-llama/Llama-3.1-8B",
    load_in_4bit=True,         # QLoRA
)

lora_config = LoraConfig(
    r=16,                      # LoRA 秩（越大越强，越慢越吃显存）
    lora_alpha=32,             # 缩放因子
    target_modules=["q_proj", "k_proj", "v_proj", "o_proj"],  # 目标层
    lora_dropout=0.05,
    task_type="CAUSAL_LM",
)

model = get_peft_model(model, lora_config)
model.print_trainable_parameters()
# trainable params: 8,388,608 || all params: 8,038,768,640 || trainable%: 0.1043%
```

## 4. 微调策略选择

```text
你的场景？
│
├── 💰 预算 < $100，一台 3060 12GB
│   └── QLoRA 7B/8B 模型 ← 4-6GB 显存就够
│
├── 💰 预算 < $1000，一台 4090 24GB
│   ├── QLoRA 70B（可以！48GB 才够？4090 24GB 用 QLoRA 也可以 70B）
│   └── 或者全参数微调 7B/8B
│
├── 💰 预算 $1000-5000，一台 A6000 48GB
│   ├── QLoRA 70B/405B ← 最推荐
│   └── LoRA 70B
│
├── 💰 预算充足，8×A100
│   └── 全参数微调 70B ← 效果最好但贵
│
└── 🎯 只想改风格/格式（不改知识）
    └── LoRA rank=8-16 就够（极轻量）
```

| 方法 | 显存(7B) | 显存(70B) | 训练时间 | 质量 |
|------|:---:|:---:|:---:|:---:|
| 全参数 | 56GB | 560GB | 慢 | ⭐⭐⭐⭐⭐ |
| LoRA (FP16) | 16GB | 160GB | 较快 | ⭐⭐⭐⭐ |
| **QLoRA (4bit)** | **6GB** | **48GB** | 较快 | **⭐⭐⭐⭐** |
| Prompt Tuning | 2GB | 8GB | 最快 | ⭐⭐⭐ |

## 核心要点回顾

- 预训练 = 海量语料学知识 + 语言能力（成本数千万到数亿＄）
- SFT = 指令问答对训练对话能力（成本数百到数千＄）
- LoRA = 冻结原模型 + 旁路低秩矩阵，只训练 0.1% 参数
- QLoRA = LoRA + 4-bit = 单卡微调 70B（革命性！）
- 选型：显存不够 → QLoRA，预算充足 → 全参数，改风格 → LoRA rank=8
