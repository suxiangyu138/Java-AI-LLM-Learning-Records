## 1. AI 应用评估为什么这么难？

| 传统软件 | AI 应用 |
|----------|--------|
| 输入→输出确定 | 相同 prompt 每次输出可能不同 |
| 测试 = assert 等值 | 没有"正确回答"的唯一标准 |
| 回归测试自动化 | 需要 LLM 当裁判（LLM-as-Judge） |
| 失败 = 报错/崩溃 | 失败 = 幻觉、不相关、但看起来没问题 |

**2026 年答案：** 指标化评估 + LLM-as-Judge + 回归测试集 = 可重复的 AI 质量体系。

## 2. RAGAS：RAG 应用标准评估框架

**四个核心指标：**

| 指标 | 衡量什么 | 计算方式 |
|------|----------|----------|
| **Answer Relevancy** | 回答是否切题 | 对回答生成反向问题，与原始问题比较相似度 |
| **Context Precision** | 检索到的上下文是否相关 | 相关片段在检索结果中的排名 |
| **Context Recall** | 相关上下文是否被检索到 | 检索到的相关内容 / ground truth 相关内容 |
| **Faithfulness** | 回答是否忠实于上下文 | 将回答分解为断言，检查每个断言是否被上下文支持 |

```python
from ragas import evaluate
from ragas.metrics import answer_relevancy, faithfulness

result = evaluate(
    dataset,                          # 包含 question/answer/contexts
    metrics=[answer_relevancy, faithfulness]
)
print(result)  # {'answer_relevancy': 0.89, 'faithfulness': 0.94}
```

**追问：** 什么时候用 RAGAS？→ RAG 管道的**回归测试** — 改了分块策略/检索参数/模型 → 跑一遍 RAGAS 看指标有没有掉。

## 3. DeepEval：单元测试式 LLM 评估

```python
from deepeval import assert_test
from deepeval.test_case import LLMTestCase
from deepeval.metrics import AnswerRelevancyMetric, HallucinationMetric

# 像写 pytest 一样写 LLM 测试
def test_rag_quality():
    test_case = LLMTestCase(
        input="退货政策是什么？",
        actual_output=rag.query("退货政策是什么？"),
        retrieval_context=["30天内无条件退货..."]
    )
    assert_test(test_case, [
        AnswerRelevancyMetric(threshold=0.7),
        HallucinationMetric(threshold=0.5),
    ])
```

| DeepEval 指标 | RAGAS 指标 | 关系 |
|---------------|-----------|------|
| AnswerRelevancyMetric | answer_relevancy | 同义 |
| FaithfulnessMetric | faithfulness | 同义 |
| ContextualPrecisionMetric | context_precision | 同义 |
| ContextualRecallMetric | context_recall | 同义 |

## 4. 可观测性：LangSmith / Phoenix / OpenTelemetry

| 工具 | 定位 | 核心能力 | 适用 |
|------|------|----------|------|
| **LangSmith** | LangChain 官方平台 | 全链路 Trace、数据集管理、A/B 测试、人工标注 | LangChain 生态 |

| **OpenTelemetry** | 通用标准 | 跨语言标准、与 Micrometer 结合 | Java/Python/Go |

## 5. 评估选型速查

| 场景 | 推荐 | 理由 |
|------|------|------|
| RAG 管道评估 | **RAGAS** | 四指标专为 RAG 设计 |
| CI 集成单元测试 | **DeepEval** | pytest 风格，assert 断言 |
| LangChain 全链路 | **LangSmith** | 官方平台 |
| 多框架可观测 | **Phoenix** | 自动埋点、可视化强 |
| 跨语言标准 | **OpenTelemetry** | Java/Python 统一 |
