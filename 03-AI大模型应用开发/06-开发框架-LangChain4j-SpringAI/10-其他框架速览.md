# 10 - 其他框架速览

> 🎯 Spring AI 和 LangChain4j 之外的 Java AI 框架 — LlamaIndex、Google Genkit、Microsoft Semantic Kernel。各有所长，按需选择

## 1. LlamaIndex (Python + 社区 Java)

```text
LlamaIndex = 专注数据索引和检索的框架

核心优势：
  → 丰富的数据连接器（100+）
  → 高级索引结构（树/图/关键词表）
  → 查询引擎（Router/SubQuestion/SQL）

Java 支持：有非官方的 llama-index-java 移植，但不如 Python 版成熟
推荐：Python 项目首选 LlamaIndex，Java 项目用 LangChain4j/Spring AI
```

## 2. Google Genkit

```java
// Google Genkit = Firebase 生态的 AI 框架
// 支持 Java/TypeScript/Go

// 定义 Flow（类似 Chain）
Flow<String, String> jokeFlow = ai.defineFlow("tellJoke",
    input -> ai.prompt("Tell a joke about {topic}", input)
);

// 本地开发 UI
// npx genkit start → 浏览器可视化调试
```

```text
Genkit 特色：
  ✅ Google 官方（Gemini/Firebase 深度集成）
  ✅ 本地可视化调试 UI
  ✅ 插件生态（向量库/监控）
  ❌ Google 生态绑定
  ❌ 社区 < Spring AI / LangChain4j

适用：Google Cloud / Firebase 用户
```

## 3. Microsoft Semantic Kernel

```java
// Semantic Kernel = Microsoft 的 AI 编排框架
// 支持 Java/C#/Python

Kernel kernel = SKBuilders.kernel()
    .withOpenAIChatCompletion("gpt-4o", apiKey)
    .build();

// 定义 Plugin
@DefinePlugin
public class WeatherPlugin {
    @KernelFunction("获取天气")
    public String getWeather(String city) { ... }
}

// 自动编排
kernel.invokeAsync("北京天气怎么样？").block();
```

```text
Semantic Kernel 特色：
  ✅ Microsoft 官方（Azure OpenAI 原生）
  ✅ Plugin 机制（类似 Function Calling）
  ✅ C# 生态最强
  ❌ Java 版不如 C# 版成熟

适用：.NET/Azure 技术栈
```
