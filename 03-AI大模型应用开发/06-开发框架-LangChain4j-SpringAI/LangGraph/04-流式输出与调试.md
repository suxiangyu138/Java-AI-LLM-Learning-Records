## 1. Stream Mode 全景图

```text
graph.stream(input, config, stream_mode="...")

五种模式：
┌──────────┬─────────────────────────────────────────────┐
│  mode     │ 你收到什么                                   │
├──────────┼─────────────────────────────────────────────┤
│ values   │ 每个 superstep 结束后的完整 State             │
│ updates  │ 每个 superstep 的增量（哪个节点改了哪些字段） │
│ messages │ LLM Node 产生的 token 流 + metadata          │
│ custom   │ 你在 Node 中手动 yield 的任意数据             │
│ debug    │ 最详细：每个 Node 的输入 + 输出 + 图决策      │
└──────────┴─────────────────────────────────────────────┘
```

### 1.1 快速对比

```python
# 假设图：agent → tools → agent → END（3 个 superstep）

# values：收到 3 个事件（每步结束时的完整 State）
for event in graph.stream(input, config, stream_mode="values"):
    # event = 完整 State（所有字段）
    print(f"消息数: {len(event['messages'])}")

# updates：收到 3 个事件（每步的增量）
for event in graph.stream(input, config, stream_mode="updates"):
    # event = {"agent": {"messages": [AIMessage(...)]}}
    # event = {"tools": {"messages": [ToolMessage(...)]}}
    print(event)

# messages：收到 N 个 LLM token 事件
for event in graph.stream(input, config, stream_mode="messages"):
    # event = (AIMessageChunk, metadata_dict)
    print(event[0].content, end="", flush=True)

# debug：收到 M 个详细事件
for event in graph.stream(input, config, stream_mode="debug"):
    # 极其详细，包括路由决策、时间戳等
    print(event)
```

## 2. values 模式：每一步的完整状态

### 2.1 行为

```python
# stream_mode="values" 返回每个 superstep 结束时的完整 State
# 包括输入（initial state）

for step_num, state in enumerate(
    graph.stream(
        {"messages": [HumanMessage("Hi")]},
        config,
        stream_mode="values"
    )
):
    print(f"=== Step {step_num} ===")
    print(f"  消息数: {len(state['messages'])}")
    # state 是完整的 State 字典
```

```text
输出：
=== Step 0 ===      ← 输入状态
  消息数: 1          [HumanMessage("Hi")]
=== Step 1 ===      ← agent 执行完毕
  消息数: 2          [HumanMessage, AIMessage(含 tool_calls)]
=== Step 2 ===      ← tools 执行完毕
  消息数: 3          [..., ToolMessage]
=== Step 3 ===      ← agent 再次执行完毕
  消息数: 4          [..., AIMessage(最终回答)]
```

### 2.2 适用场景

```text
✅ 前端展示整个对话历史
✅ 保存每一步的完整快照
✅ 不需要区分是哪个节点产生的变化
❌ 不能流式输出 LLM token（values 是 step 级别的）
```

## 3. updates 模式：增量更新

### 3.1 行为

```python
# stream_mode="updates" 返回每个 Node 的增量输出
# 格式：{node_name: {field_key: new_value}}

for event in graph.stream(
    {"messages": [HumanMessage("北京天气")]},
    config,
    stream_mode="updates"
):
    node_name = list(event.keys())[0]
    update = event[node_name]
    print(f"Node [{node_name}] 更新了: {list(update.keys())}")
```

```text
输出：
Node [agent] 更新了: ['messages', 'current_step']
  → messages: [AIMessage(content=None, tool_calls=[...])]
  → current_step: "acting"

Node [tools] 更新了: ['messages']
  → messages: [ToolMessage(content="北京, 35°C, 晴天")]

Node [agent] 更新了: ['messages', 'current_step']
  → messages: [AIMessage(content="北京今天35°C，晴天")]
  → current_step: "done"
```

### 3.2 适用场景

```text
✅ 需要知道"哪个节点产生了什么变化"
✅ 前端展示"Agent 正在执行 [tools]..."
✅ 只关心变化，不需要完整 State
```

## 4. messages 模式：LLM Token 级别流

### 4.1 行为

```python
# stream_mode="messages" 只在 LLM Node 中产生事件
# 返回 (message_chunk, metadata) 元组

for chunk, metadata in graph.stream(
    {"messages": [HumanMessage("讲个笑话")]},
    config,
    stream_mode="messages"
):
    # chunk = AIMessageChunk（单个 token）
    # metadata = {
    #     "langgraph_step": 1,        # 第几个 superstep
    #     "langgraph_node": "agent",  # 哪个 LLM 节点
    #     "langgraph_triggers": ["agent"],
    #     ...
    # }

    if chunk.content:
        print(chunk.content, end="", flush=True)
        # → 逐字打印"从前有个程序员..."
```

### 4.2 适用场景

```text
✅ ChatGPT 式的逐字输出（最高优先级场景）
✅ 展示 Tool Call 的第一个 token（TTFT 监控）
✅ 用户感知延迟优化
```

### 4.3 处理 Tool Call 的流

```python
for chunk, metadata in graph.stream(input, config, stream_mode="messages"):
    # 文本 token
    if chunk.content:
        yield {"type": "text", "content": chunk.content}

    # Tool Call token
    if hasattr(chunk, "tool_call_chunks") and chunk.tool_call_chunks:
        for tc in chunk.tool_call_chunks:
            yield {
                "type": "tool_call",
                "name": tc.get("name"),
                "args": tc.get("args"),
                "id": tc.get("id")
            }
```

## 5. custom 模式：自定义数据流

### 5.1 在 Node 中写入 StreamWriter

```python
from langgraph.config import get_stream_writer

def my_node(state: AgentState) -> dict:
    # 获取 StreamWriter
    writer = get_stream_writer()

    # 自定义写入任意数据
    writer("正在分析用户需求...")          # 进度提示
    analysis = analyze(state)

    writer({"progress": 30, "status": "analyzing"})  # 结构化进度
    result = process(analysis)

    writer({"progress": 80, "status": "generating"})  # 再次通知
    output = generate(result)

    writer({"progress": 100, "status": "done"})
    return {"output": output}


# 消费端
for event in graph.stream(input, config, stream_mode="custom"):
    # event 就是 writer() 写入的任意数据
    if isinstance(event, str):
        print(f"[提示] {event}")
    elif isinstance(event, dict):
        print(f"[进度] {event['progress']}% - {event['status']}")
```

### 5.2 适用场景

```text
✅ 自定义进度通知（"正在搜索 3/5 个数据源..."）
✅ 中间结果透传（不通过 State）
✅ 非 LLM 节点的执行状态推送
```

## 6. debug 模式：排查利器

### 6.1 输出结构

```python
for event in graph.stream(input, config, stream_mode="debug"):
    # event 类型：
    # - "task": 开始执行一个任务
    # - "task_result": 任务执行结果
    # - "checkpoint": checkpoint 写入

    print(f"[{event['type']}] ", end="")

    if event["type"] == "task":
        print(f"开始执行节点: {event['payload']['name']}")
        print(f"  输入: {event['payload']['input']}")

    elif event["type"] == "task_result":
        print(f"节点完成: {event['payload']['name']}")
        print(f"  输出: {event['payload']['result']}")
        print(f"  触发: {event['payload']['intermediate']}")
```

### 6.2 适用场景

```text
✅ 开发调试（"为什么我的 Agent 没有调用工具？"）
✅ 理解 LangGraph 内部执行机制
❌ 不要在生产中开启（日志量巨大）
```

## 7. 多模式组合使用

### 7.1 同时使用多个模式

```python
# 传入 mode 列表，同时获取多种流
for mode, event in graph.stream(
    input, config,
    stream_mode=["updates", "messages", "custom"]
):
    # mode = "updates" | "messages" | "custom"
    # event 根据 mode 不同而不同

    if mode == "updates":
        # 结构：{node_name: update_dict}
        node = list(event.keys())[0]
        print(f"[Node] {node} 完成")

    elif mode == "messages":
        # 结构：(message_chunk, metadata)
        chunk, meta = event
        if chunk.content:
            print(chunk.content, end="", flush=True)

    elif mode == "custom":
        # 结构：任意 writer 写入的数据
        print(f"[Custom] {event}")
```

### 7.2 典型组合

```python
# 组合 1：前端 Agent UI（状态 + 文字流）
# stream_mode=["updates", "messages"]
# → updates 用于更新 UI 状态栏
# → messages 用于打字机效果

# 组合 2：监控仪表盘
# stream_mode=["custom", "updates"]
# → custom 用于进度、指标上报
# → updates 用于关键状态变更记录
```

## 9. Astream + FastAPI 集成

### 9.1 FastAPI SSE 端点

```python
from fastapi import FastAPI
from fastapi.responses import StreamingResponse
import json

app = FastAPI()

@app.post("/agent/stream")
async def stream_agent(message: str, thread_id: str):
    """SSE 端点：将 LangGraph 流式输出转为 SSE"""

    async def event_generator():
        config = {"configurable": {"thread_id": thread_id}}
        input_state = {"messages": [HumanMessage(content=message)]}

        async for mode, event in graph.astream(
            input_state, config,
            stream_mode=["updates", "messages"]
        ):
            if mode == "messages":
                chunk, metadata = event
                if chunk.content:
                    yield f"data: {json.dumps({'type': 'token', 'content': chunk.content})}\n\n"

                # Tool call 通知
                if hasattr(chunk, "tool_call_chunks") and chunk.tool_call_chunks:
                    for tc in chunk.tool_call_chunks:
                        if tc.get("name"):
                            yield f"data: {json.dumps({'type': 'tool_start', 'name': tc['name']})}\n\n"

            elif mode == "updates":
                node = list(event.keys())[0]
                yield f"data: {json.dumps({'type': 'node_complete', 'node': node})}\n\n"

        yield "data: [DONE]\n\n"

    return StreamingResponse(
        event_generator(),
        media_type="text/event-stream"
    )
```

### 9.2 前端消费

```javascript
// 使用 EventSource
const eventSource = new EventSource('/agent/stream', {
    // 注意：POST 不支持 EventSource，需用 fetch + ReadableStream
});

// 更推荐：fetch + ReadableStream
const response = await fetch('/agent/stream', {
    method: 'POST',
    headers: {'Content-Type': 'application/json'},
    body: JSON.stringify({message: '你好', thread_id: '123'})
});

const reader = response.body.getReader();
const decoder = new TextDecoder();

while (true) {
    const {done, value} = await reader.read();
    if (done) break;

    const text = decoder.decode(value);
    const lines = text.split('\n');

    for (const line of lines) {
        if (line.startsWith('data: ')) {
            const data = JSON.parse(line.slice(6));
            switch(data.type) {
                case 'token':
                    appendToChat(data.content);  // 打字机效果
                    break;
                case 'tool_start':
                    showToolIndicator(data.name);  // 显示工具调用
                    break;
                case 'node_complete':
                    updateProgressBar(data.node);  // 更新进度
                    break;
            }
        }
    }
}
```
