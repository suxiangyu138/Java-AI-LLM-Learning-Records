## 1. 项目背景与问题卡

**背景**：泰坦尼克号沉没，891 名乘客（训练集）的生还记录——经典入门数据集（`../阶段%203：数据来源（数据从哪里来）/02-公开数据集与数据平台.md` 的 Kaggle/seaborn 双渠道）。

**问题卡（七步闭环第 ① 步——先问问题再看数据）**：

```text
问题卡
- 核心问题：什么因素影响生还率？
- 子问题 1：性别、舱位、年龄与生还率的关系？
- 子问题 2：哪个因素影响最大？
- 不做的事：预测具体某人生还（那是 09 篇 ML 项目的事）
```

**问题卡心智**：**"一个项目只回答一个问题，子问题是它的拆解"**——问题卡写清"不做的事"，防止分析跑偏（做预测模型就是 09 篇的活——**"问题边界是项目质量的隐形指标"**）。

```python
import seaborn as sns

df.to_csv("data/raw/titanic_raw.csv", index=False, encoding="utf-8-sig")  # 原始底片归档

# 四连击体检（阶段 2 的开场白——每份数据的第一动作）
df.shape        # (891, 15)
df.head()       # 长啥样
df.info()       # 类型与缺失：age 有 177 个缺失、deck 大量缺失
```

**体检心智**：**"四连击回答'我读对了吗'"**——`df.info()` 直接暴露第一轮清洗目标：**age 缺失 177（19.9%）、deck 缺失 688（77%）**——**"体检先于清洗——清洗计划是体检写出来的"**（阶段 1 的"先体检后处理"纪律）。

## 3. 清洗流水线

**清洗四道工序，每步留理由**（阶段 2 的清洗课完整落地——`../阶段%202：核心三大库（必学）/Pandas%20—%20数据分析主力库/03-数据清洗.md`）：

```python
# ① 缺失处理：deck 缺失 77%——信息量太低，删列（不是删行！）
df = df.drop(columns=["deck"])

# ② 缺失处理：age 缺失 19.9%——按性别-舱位组中位数填补（写理由：同组乘客年龄相似）
df["age"] = df.groupby(["sex", "class"])["age"].transform(lambda s: s.fillna(s.median()))

# ③ 类型校准：sex/class 转 category（有序分类——性能 + 语义）
df["sex"]  = df["sex"].astype("category")
df["class"] = df["class"].astype("category")

# ④ 异常检查：fare 有 0 值？查看多少、什么人群（0 可能是船员票——保留并注明）
print(df[df["fare"] == 0]["who"].value_counts())
```

**清洗心智**：**"每步清洗都有理由、都留痕"**——删列因为"缺失 77% 没分析价值"、填中位数因为"同组相似性"——**"清洗报告写清理由，面试讲项目才经得起追问"**；**删列 vs 删行的判断**：缺失 >50% 的列优先删列，<5% 的行删行，中间值按业务判断——**"清洗决策 = 缺失率 × 业务意义"**。

## 4. 分组探索

**核心问题拆成三个分组对比**（groupby 三件套——`../阶段%202：核心三大库（必学）/Pandas%20—%20数据分析主力库/04-分组聚合groupby.md`）：

```python
# 子问题 1a：性别 × 生还率
df.groupby("sex")["survived"].mean()      # 女 0.74 / 男 0.19——女性生还率 3.9 倍

# 子问题 1b：舱位 × 生还率
df.groupby("class")["survived"].mean()    # 头等 0.63 / 二等 0.47 / 三等 0.24——梯度明显

# 子问题 1c：年龄 × 生还率（分箱——连续变量变分组）
df["age_band"] = pd.cut(df["age"], bins=[0, 18, 40, 80], labels=["儿童", "青年", "中老年"])
df.groupby("age_band")["survived"].mean() # 儿童 0.58 / 青年 0.40 / 中老年 0.31

# 子问题 2：哪个因素影响最大？（对比效应量——不做假设检验，看分组差异幅度）
summary = df.groupby("sex")["survived"].agg(["mean", "count"])
summary["diff"] = summary["mean"] - df["survived"].mean()   # 距总体生还率 0.38 的偏移
```

**分组心智**：**"分组维度 = 业务假设"**——"性别可能影响生还"是假设，groupby 是验证——**"分组前先写假设，分组后看结果"**；**连续变量（年龄）先分箱再分组**（`pd.cut`——阶段 2 的分箱思路）；**对比不要孤值**——"女性生还率 74%"要和总体 38% 比才有意义（阶段 2 的"对比不要孤值"纪律）。

## 5. 可视化：一图一结论

**每个图表只讲一个结论**（可视化课的核心纪律——`../阶段%202：核心三大库（必学）/Matplotlib%20%20Seaborn%20—%20数据可视化/`）：

```python
import matplotlib.pyplot as plt
import seaborn as sns

# 图 1：性别生还对比（柱状图——图题直接写结论！）
sns.barplot(data=df, x="sex", y="survived", errorbar=None)
plt.title("女性生还率（74%）是男性（19%）的 3.9 倍")
plt.savefig("fig1_sex.png", dpi=300, bbox_inches="tight")   # 交付图 300dpi

# 图 2：舱位梯度（柱状 + 数值标注）
ax = sns.barplot(data=df, x="class", y="survived", errorbar=None)
for i, p in enumerate(ax.containers[0]):
    ax.annotate(f"{p.get_height():.0%}", (p.get_x() + p.get_width()/2, p.get_height()))
plt.title("舱位越高生还率越高：头等 63% → 三等 24%")
```

**图的心智**：**"图题写结论、坐标带单位、保存 300dpi"**三件套（`../阶段%202：核心三大库（必学）/Matplotlib%20%20Seaborn%20—%20数据可视化/08-图表交付与规范.md`）——**"探索图自己看，交付图给人看——给图起结论性标题是第一步"**；每张图在报告里配一句话解读——"图不是成果，解读才是"。

## 6. 结论三段式报告

**最终报告（Markdown 交付——结论三段式）**：

```markdown
# 泰坦尼克生还因素分析报告

## 一、背景
泰坦尼克沉没 891 名乘客中 38% 生还，本报告分析"什么因素影响生还率"。

## 二、数据与方法
数据：seaborn 内置 titanic（891×15），deck 列缺失 77% 删除，
age 按性别-舱位组中位数填补；分析方法：分组对比 + 可视化。

## 三、结论（三段式）
1. 现象：女性生还率 74%、男性 19%；头等 63%、三等 24%；儿童 58%。
2. 原因：救生艇分配优先妇女儿童（妇女儿童优先原则）……
3. 建议：应急逃生规则需明确优先级；分析视角：性别是首要因素。

## 四、局限
数据只含部分乘客（训练集）；未控制变量（舱位与性别可能交织）；
结论是相关性，不是因果。
```

**报告心智**：**"结论三段式 = 现象 → 原因 → 建议"**——面试讲项目、报告给老板都是这个结构；**"局限"必须写**——"写局限不是露怯，是可信度"（01 篇——**"有局限的报告比完美的报告更可信"**）；**报告里每个数字可溯源**（图表编号/代码位置——"数字别飘着，要有出处"）。
