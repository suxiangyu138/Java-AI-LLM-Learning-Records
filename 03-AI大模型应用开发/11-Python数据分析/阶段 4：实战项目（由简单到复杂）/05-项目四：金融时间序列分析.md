## 3. 数据清洗与时序基建

```python
# 清洗四步
df["trade_date"] = pd.to_datetime(df["trade_date"])
df = df.drop_duplicates(subset="trade_date")          # ① 去重（接口偶尔重复）
df = df.sort_values("trade_date")                     # ② 排序铁律（时序第一纪律）
df = df.set_index("trade_date")                       # ③ 设时间索引（时序分析前提）
df = df[df["close"] > 0]                              # ④ 异常剔除（close 不为正）

# 体检
print(df.index.min(), df.index.max(), df.isna().sum())
df["ret"] = df["close"].pct_change()                  # 日收益率（时序核心派生列）
```

**清洗心智**：**"时序清洗四步：解析 → 去重 → 排序 → 设索引"**（`../阶段%202：核心三大库（必学）/Pandas%20—%20数据分析主力库/07-时间序列Pandas版.md` 的排序铁律——**"不排序的时间序列是坏的时间序列"**）；**`set_index` 把日期变索引**是时序分析的前提（rolling/resample 都靠索引）；**`pct_change()` 是收益率的标准算法**（当日/昨日-1——"收益率是金融分析的货币"）；**复权（qfq）是回测必须**——不除权的价格有分红跳变，均线会被假信号骗——**"回测用错价格，结论全是噪音"**。

## 4. 技术指标计算

```python
# 移动平均（rolling——阶段 2 时序课的标准武器）
df["ma5"]  = df["close"].rolling(5).mean()
df["ma20"] = df["close"].rolling(20).mean()

# 波动率（20 日滚动标准差——风险度量）
df["vol20"] = df["ret"].rolling(20).std()

# 金叉死叉信号：MA5 上穿 MA20 → 买入信号；下穿 → 卖出信号
df["signal"] = (df["ma5"] > df["ma20"]).astype(int)   # 1 = 在均线上方（持仓）
df["cross"]  = df["signal"].diff().fillna(0)          # 1 = 金叉（新买），-1 = 死叉（新卖）
print(df[df["cross"] != 0].head(10))
```

**指标心智**：**"技术指标 = 原始价格的'加工品'"**——MA（趋势）/波动率（风险）/信号（交易规则）三件套是入门必备；**信号生成是"规则到数据"的翻译**（"MA5 在 MA20 上方就持仓" → `signal` 列）——**"策略的本质：把一句话规则变成一列 0/1"**；**`diff()` 找交叉点**（信号从 0→1 的瞬间）——"金叉不是'均线在上方'，是'刚刚上穿'"——**"指标算错一个，策略全错——每个指标写出来先 print 验证"**。

## 5. 均线策略回测

**回测 = 按信号模拟买卖，算策略收益**：

```python
# 策略收益：持仓日吃涨跌，空仓日吃 0（简化版：不考虑手续费滑点）
df["strategy_ret"] = df["signal"].shift(1) * df["ret"]   # shift(1)：今天按昨天信号执行
df["buyhold_ret"]  = df["ret"]                           # 基准：买入持有

# 累计收益（cumprod 复利累乘）
df["strategy_cum"] = (1 + df["strategy_ret"]).cumprod()
df["buyhold_cum"]  = (1 + df["buyhold_ret"]).cumprod()

# 评估指标：总收益 / 年化 / 最大回撤 / 胜率
total_s, total_b = df["strategy_cum"].iloc[-1] - 1, df["buyhold_cum"].iloc[-1] - 1
days = (df.index[-1] - df.index[0]).days
ann_s = (1 + total_s) ** (365 / days) - 1
max_dd = (df["strategy_cum"] / df["strategy_cum"].cummax() - 1).min()
wins = (df["strategy_ret"].dropna() > 0).mean()
print(f"策略 {total_s:.1%} vs 持有 {total_b:.1%} | 年化 {ann_s:.1%} | 最大回撤 {max_dd:.1%} | 胜率 {wins:.1%}")
```

**回测心智**：**"`shift(1)` 是回测的灵魂"**——今天的信号昨天就决定（**防止未来函数——用今天的收盘信号买卖今天，等于作弊**——"回测第一铁律：信号必须滞后一天执行"）；**评估四件套：总收益、年化、最大回撤、胜率**——"只看总收益是外行——回撤 50% 的策略再赚钱也没人拿得住"；**对比基准必须有**（vs 买入持有——"策略不跟基准比，等于白回测"）。

## 6. 结论与局限

**报告结论**：

```markdown
# 双均线策略回测报告（上证指数 2021-2026）

## 结论
1. 现象：策略累计收益 X% vs 买入持有 Y%——均线策略 5 年跑赢/跑输基准。
2. 原因：震荡市金叉死叉频繁被"打脸"（假信号）；趋势市能吃到主升段。
3. 建议：该策略在 A 股指数上"胜率不高、回撤不小"——实盘不推荐；
    若要继续研究：加过滤条件（只在 20 日波动率低时交易）或换标的验证。

## 局限（重要）
① 未计手续费与滑点（A 股双边约千 2-3——高频交易后收益大幅缩水）；
② 单标的单参数验证——过拟合风险（换 5 个标的可能结论不同）；
③ 幸存者偏差/选择性偏差——选了这个指数可能因为"它看起来有效"；
④ 回测通过 ≠ 未来盈利（市场结构会变）；本项目为学术练习，非投资建议。
```

**局限心智**：**"金融回测的局限是最该写的部分"**——手续费（**"策略一年交易 50 次，手续费吃掉 10% 收益——不算手续费的回测是自欺"**）、过拟合（参数 5/20 换 10/60 呢？）、幸存者偏差（"指数还活着所以数据完整"）——**"回测报告 = 一半结论 + 一半局限"**；**"非投资建议"是合规底线**（`../阶段%201：前置基础/08-数据素养与伦理.md` 的素养——**"分析师输出观点要带免责边界"**）。
