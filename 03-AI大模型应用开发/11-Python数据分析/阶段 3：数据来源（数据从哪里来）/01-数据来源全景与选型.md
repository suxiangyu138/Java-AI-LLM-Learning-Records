## 1. 六路来源地图

**数据分析的问题 90% 不是"不会算"，而是"没有数据"**——而"没有数据"多半是"不知道去哪找"。数据来源可以穷举成六路：

```text
数据来源六路
├── ① 本地文件：CSV/Excel/JSON/Parquet（别人给你、下载来的）
├── ② 数据库：SQLite/MySQL/PostgreSQL（公司系统里躺着）
├── ③ 接口 API：REST API 返回 JSON（业务系统/开放平台）
├── ④ 网页采集：网页上的表/页面数据（静态抓取）
├── ⑤ 公开数据集：Kaggle/UCI/天池/统计局（现成的"菜市场"）
└── ⑥ 模拟生成：numpy 随机/Faker 合成（无中生有）
```

**六路心智**：**先想"数据本来住在哪"，再想"怎么搬"**——每路都是一条管道：**源头 → 管道 → DataFrame**——本阶段的每一篇都在讲一条管道——**"01 篇给你地图，02-08 篇给你交通工具"**。

## 2. 逐路拆解

**① 本地文件——最省心的一路**：数据已躺在磁盘上，`pd.read_*` 一行就读进来（`../../阶段%201：前置基础/05-数据读写与文件格式.md` 的最小闭环；本阶段 03 篇讲生产级读法）。**适合**：下载的现成数据、同事发的报表、公开数据集的落地形态——**"文件是最常见的数据包装，所有其他路最终都落成文件"**。

**② 数据库——公司数据的"水龙头"**：业务系统把数据存在库里，用 SQL 取——**"SQL 是分析师和数据库之间的普通话"**（04 篇）。**适合**：公司内部数据、需要按条件筛选的数据、持续更新的数据——**"库里取数讲纪律：只取需要的列，别 SELECT *"**。

**③ API 接口——实时数据的"高速公路"**：开放平台（天气/股票/地图）和业务系统都提供 API，返回 JSON——**"API 是 2026 年最主流的数据交换方式"**（05 篇）。**适合**：实时/高频数据、跨系统数据、要自动化更新的数据。

**④ 网页采集——最后一招**：没有文件、没有 API、只有网页——**"能 API 就不爬"是铁律**，但网页上有大量表格只有抓取能拿到（06 篇，与爬虫课程分工——买菜 vs 打猎）。

**⑤ 公开数据集——先逛菜市场再下地**：Kaggle/UCI/天池/国家统计局有大量现成数据集（02 篇）——**"你想要的 80% 数据，别人已经整理好了"**——下载 → 读入 → 开工，是性价比最高的一路。

**⑥ 模拟生成——没有数据时的最后退路**：测试、演练、缺数据时用 numpy 随机数 + Faker 合成（08 篇）——**"合成数据跑通流程，真实数据换上就能跑"**。

## 3. 选型决策树

拿到一个"要数据"的需求，按这个顺序问自己：

```text
Q1 数据已经存在吗？（别人给过/下载过？） ──有──→ ① 本地文件（03 篇）
      ↓没有
Q2 公司/开放平台有数据库吗？ ──────────有──→ ② 数据库 read_sql（04 篇）
      ↓没有
Q3 提供方有 API 吗？ ──────────────────有──→ ③ API 调用（05 篇）
      ↓没有
Q4 网页上有这数据吗？ ──────────────────有──→ ④ 静态抓取（06 篇）
      ↓没有
Q5 别人整理成数据集了吗？ ────────────────有──→ ⑤ 公开数据集（02 篇）
      ↓都没有
Q6 能模拟/合成吗？ ─────────────────────→ ⑥ 模拟生成（08 篇）
```

**决策树心智**：**"越往下的路越贵"**——文件免费、API 省事、爬虫费时、合成费脑——**"选数据来源 = 选成本"**；同时注意顺序并非机械：**公开数据集（Q5）其实应该提前到 Q1.5 去搜**——先逛菜市场再决定要不要下地——**"正确的开场是搜公开数据集，而不是立刻写爬虫"**。

**决策树的两个反例**（规则都有例外，知道例外才算真懂）：**"时效性反例"**——做"今天的气温"分析，公开数据集永远不会有今天的数据，直接走 API（Q3）；**"所有权反例"**——公司内部的销售数据不存在"公开数据集"这回事，直接走数据库（Q2）——**"决策树不是机械流水线，是帮你把'该走哪条'想清楚的脚手架——特殊情况特殊走，但要知道自己为什么跳过"**。

## 4. 来源五问

选好路之后，动笔拿数据之前，**对来源做五问体检**（09 篇会展开成数据质量体系）：

1. **可用吗**——能合法拿到吗？下载要注册/审核吗？爬取在许可范围内吗？（`../../阶段%201：前置基础/08-数据素养与伦理.md` 的合规底线）
2. **有许可吗**——MIT/CC/商用授权？数据许可是"能不能用于分析/发布"的合同（02 篇——**"许可问题在下载时就该看，而不是发表时"**）
3. **新鲜吗**——数据是什么时候的？截止 2026-08 的电商数据对"上月销售分析"毫无用处
4. **贵吗**——时间成本（爬一个页面 3 秒）和金钱成本（API 免费额度/付费套餐）都要算
5. **可信吗**——来源是谁？统计局的数据比自媒体爬的可靠——**"来源的可信度决定分析结论的含金量"**

**五问心智**：**"拿到数据的瞬间，先打五个勾"**——五问全过才进入读入环节——**"来源没体检的数据，清洗做得再好也是垃圾进垃圾出"**（GIGO——垃圾进垃圾出——数据领域第一定律）。

## 6. 本节验收

**验收动作**：① 画出六路来源地图（默写）；② 对"分析北京二手房价格"这个需求走一遍决策树，写出每一步的答案；③ 用五问检查一个你想用的数据来源——**"地图 + 决策树 + 五问 = 选型能力"**——**练习纪律**：每题写清"为什么"而不是只写"是哪路"——"选型题考的是顺序心智，不是答案本身"。

> 🎯 **核心要点**：数据来源六路（文件/库/API/采集/公开数据集/模拟）——决策树按"越往下越贵"选路，公开数据集优先搜（先逛菜市场）；来源五问（可用/许可/新鲜/贵/可信）是拿数据前的体检——**"数据 90% 的问题是没有数据，没有数据的 90% 是不知道去哪找"**——本阶段每一篇 = 一条管道 = 源头 → 管道 → DataFrame。
