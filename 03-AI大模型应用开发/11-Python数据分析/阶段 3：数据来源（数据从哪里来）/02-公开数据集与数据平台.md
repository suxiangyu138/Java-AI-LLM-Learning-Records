## 1. 四大平台地图

**公开数据集 = 别人整理好、挂出来、让你用的数据**——本阶段性价比最高的一路（01 篇 Q5）。2026 年主流平台四大阵营：

```text
公开数据集四大平台
├── Kaggle（kaggle.com）：全球最大竞赛平台——数据集+Notebook+社区
├── UCI（archive.ics.uci.edu）：最老经典仓库——学术基准
├── 阿里云天池（tianchi.aliyun.com）：国内业务场景——中文
└── 国家统计局（data.stats.gov.cn）：官方权威——政策与宏观数据
```

**平台心智**：**"平台选型 = 场景选型"**——国际对比实验找 Kaggle、中文业务场景找天池、学术基准找 UCI、官方宏观数据找统计局——**"先想清楚要分析什么，再决定去哪逛"**。除了四大平台，还有 Hugging Face Datasets（`../../02-大模型基础与Prompt工程/HuggingFace/` 里 150 万+ 模型生态的数据集仓库，LLM 训练数据多）、和鲸社区/DataFountain（国内竞赛渠道）、GitHub 上的数据集仓库（配合 `git clone` 直接拉）——**"平台不止四个，但四大的心智够用"**。

## 2. 平台选型

**Kaggle——国际数据竞赛的"世贸中心"**：数据极丰富（泰坦尼克生存预测、信用卡欺诈检测都是经典教学数据），内置 Notebook 支持"一键下载+在线训练"闭环，社区讨论和配套分析代码多——**"练手找思路，Kaggle 是首选"**——代价是国内直连下载慢、全英文、部分数据要审核、版权条款复杂。

**UCI——机器学习的老牌粮仓**：1987 年起维护的经典仓库，学术背书强、引用格式规范、**免注册直接下载**、体量轻量（多数 <100MB）——**"做基准对照实验，UCI 够用且省心"**——代价是字段定义偏老旧、规模小——"老"不是缺点而是优点：**经典数据集让不同研究可比**。

**阿里云天池——中文业务场景的"主场"**：赛题贴近国内互联网真实业务（电商转化率预测、用户流失预警、用户行为日志、城市交通流、工业质检图像），中文描述、阿里云高速下载、有免费数据集板块和常年新手赛道，深度集成 PAI 可视建模与 MaxCompute，**"数据沙箱"实现数据可用不可见**——**"中文业务分析，天池是首选"**——代价是赛题数据可能赛后下架、字段文档不全。

**国家统计局——官方权威的"数据台"**：GDP/CPI/人口/就业等宏观数据，权威性无可替代——**"引官方数字，统计局是唯一来源"**——2026 新版接口采用**时间分片机制**：同一指标（如 CPI）按 5 年或统计制度周期拆成多个 cid，拉长历史数据要分段请求再本地拼接（月度 `YYYYMM`、季度 `YYYYQ`、年度 `YYYY` 编码）——GitHub 有现成封装（如 `cn-stats` 包）——**"官方数据拿去分析不踩雷，但接口自己啃成本高——先找现成封装"**。

## 3. 数据集评估五看

平台上下载前，**五看评估**（01 篇来源五问的数据集版）：

1. **看许可**——数据集页的 License 字段：CC0/CC-BY 可自由用、MIT 商用友好、**"仅学术"标记得看是不是你真要的用途**——"许可在下载时看，而不是发表时哭"
2. **看文档**——有 README/数据字典/字段说明吗？**"没有文档的数据集是半成品"**——字段含义全靠猜的数据，清洗成本大于自己造
3. **看版本与时间**——数据集更新到什么时候？有版本号吗？**"2021 年的用户行为数据回答不了 2026 年的问题"**
4. **看规模**——多大？几十 MB 直接读，几 GB 要走分块（03 篇）——**"先看 size 再定读取策略"**
5. **看口碑**——下载量、点赞数、评论区有没有人喊坑——**"前人的吐槽是最便宜的经验"**

**五看心智**：**"下载前五看，下载后体检"**——五看过了才点下载，下载完用阶段 1 的四连击体检（shape/head/info/describe——`../../阶段%202：核心三大库（必学）/Pandas%20—%20数据分析主力库/01-Series与DataFrame心智.md`）——**"公开数据不等于干净数据——平台只负责提供，不负责洗"**。

## 4. 下载与落地

**三种下载方式**：

```python
# 1. 浏览器手动下载（最省事——小数据集首选）
#    Kaggle 网页 Dataset 页 → Download → 解压到 data/ 目录

# 2. kagglehub（Kaggle 官方 Python 库——代码化下载）
import kagglehub
path = kagglehub.dataset_download("saurabhshahane/twitter-annotation")
# 返回本地路径，直接 pd.read_csv(path + "/数据文件.csv")

# 3. 直接 curl 公开 URL（统计局/政府开放数据常见）
# !curl -O https://example.gov.cn/data.csv
```

**加速与镜像**：国内访问 Kaggle 慢是常态——官方加速镜像（如 kaggle-cn.com 类站点）实测比国际直连快 3-8 倍——**"下载慢先找镜像，别硬等"**。

**内置数据集——最懒的姿势**：`seaborn` 自带一批经典数据集（`../../阶段%202：核心三大库（必学）/Matplotlib%20%20Seaborn%20—%20数据可视化/05-Seaborn统计可视化.md` 用到的 iris/tips/titanic 等），一行加载零下载：

```python
import seaborn as sns
df = sns.load_dataset("titanic")   # 泰坦尼克——阶段 1/2 的常客
```

**落地纪律**：下载后**统一归档**到 `data/` 目录（raw 原文 + processed 处理后分开放——09 篇的数据管理）；**记录来源**（哪下的、什么版本、什么时候下的——写进 README 或文件名 `titanic_v1_kaggle_20260810.csv`）——**"数据的出处不记，三个月后就是无主数据"**。
