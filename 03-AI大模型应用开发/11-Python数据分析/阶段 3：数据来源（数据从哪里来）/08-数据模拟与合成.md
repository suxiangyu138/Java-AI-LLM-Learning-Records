## 1. 合成数据的价值与边界

**合成数据 = 用程序造出来的数据**——不是真实观测，但结构像真实数据。**什么时候用**：

```text
合成数据用武之地
├── 学习练习：没数据可学时造一份练手（本课全部场景）
├── 流程演练：分析管道/报告模板先跑通
├── 测试验证：函数/报表接假数据验证正确性
├── 隐私保护：真实数据脱敏后替换（阶段 1 的脱敏概念落地）
└── 补缺填充：缺字段时按分布合理补全
```

**边界心智（重要）**：**"合成的结论只对合成的数据有效"**——用模拟数据跑出的"用户流失率 30%"不代表真实业务（**"假数据得出的真数字，是分析最大的自欺"**）；**合成数据可以练流程、不可以下结论**——"练手可以，交差不行"；**能拿真实数据（哪怕小样本）就别纯合成**——真实数据是唯一能产生真实结论的原料（02 篇公开数据集永远先试）。

## 2. numpy 随机数：数值模拟

**数值型数据的模拟是 numpy 的主场**（`../../阶段%202：核心三大库（必学）/NumPy%20—%20数值计算底层库/08-与Pandas协作与性能.md` 的随机数章节正式上场）：

```python
import numpy as np
import pandas as pd

rng = np.random.default_rng(42)          # 固定种子 → 结果可复现（铁律！）

n = 10_000
df = pd.DataFrame({
    "age":     rng.integers(18, 65, n),            # 均匀整数：年龄
    "salary":  rng.normal(8000, 2000, n).round(2), # 正态：薪资（均值 8000 标准差 2000）
    "score":   rng.uniform(0, 100, n).round(1),    # 均匀：分数
    "is_vip":  rng.choice([0, 1], n, p=[0.8, 0.2]),# 分类：80% 非 VIP
})
```

**随机模拟心智**：**"`default_rng(种子)` 是一切模拟的第一步"**——固定种子 = 每次运行结果相同 = 可复现（**"没有种子的随机数是不可复现的随机数——等于没有记录"**）；**分布选型**：年龄/件数用 `integers`、薪资/误差用 `normal`、比率用 `choice` 带概率——**"先想真实数据的形状，再选分布"**；**模拟也要"像真的"**：真实薪资不会均匀分布（正态更像）、真实年龄有边界（18-65 的截断）——**"模拟的质量 = 对现实形状的还原度"**。

## 3. Faker：像人的数据

**Faker 40.x（2026-07 最新 40.28.1）专门生成"像人"的数据**——名字/地址/邮箱/电话/日期一应俱全：

```python
from faker import Faker
import pandas as pd

fake = Faker("zh_CN")          # 中文场景（还可 en_US/ja_JP 等 60+ 地区）
Faker.seed(42)                 # 种子——注意是类方法（不是实例方法！）

rows = []
for _ in range(1000):
    rows.append({
        "name":    fake.name(),                # 中文姓名
        "email":   fake.email(),               # 邮箱
        "city":    fake.city(),                # 城市
        "phone":   fake.phone_number(),        # 电话
        "birth":   fake.date_of_birth(minimum_age=18, maximum_age=65),
        "company": fake.company(),
    })

df = pd.DataFrame(rows)
```

**Faker 心智**：**"Faker 生成的是'格式像'的数据，不是'逻辑对'的数据"**——`fake.name()` 不会和 `fake.email()` 对应（邮箱里的名字和姓名是两套随机）——**"Faker 管格式，业务逻辑自己补"**；**`Faker.seed()` 是类方法**（`fake.seed()` 会报错——新手的第一个坑）；**`fake.unique.email()` 保证唯一**（生成不重复值——测试主键场景用，耗尽会抛 `UniquenessException`）；**locale 控制语言风格**——中文分析用 `zh_CN`——**"数据的气质跟 locale 走"**；**Faker 与真实数据的差距**：真实数据有异常值、缺失、长尾分布——Faker 数据太"干净"（**"太干净的数据本身就是一种假"**——模拟完可以故意掺点脏数据练清洗）。

## 4. 业务场景模拟

**更高一级的模拟：带业务逻辑**——不止字段像，关系也要像：

```python
import pandas as pd
import numpy as np

rng = np.random.default_rng(7)

# 第一步：造主体表（用户 1000 人）
users = pd.DataFrame({
    "user_id": range(1, 1001),
    "age": rng.integers(18, 70, 1000),
    "city": rng.choice(["北京", "上海", "广州"], 1000),
})

# 第二步：造订单表（引用主体——一对多）
n_orders = 5000
order_user = rng.integers(1, 1001, n_orders)          # 订单关联用户
amount = rng.normal(200, 80, n_orders).clip(1, None).round(2)  # 金额有下限
orders = pd.DataFrame({
    "order_id": range(1, n_orders + 1),
    "user_id": order_user,
    "amount": amount,
})

# 第三步：验证关联（user_id 全在 users 里——外键检查）
assert orders["user_id"].isin(users["user_id"]).all()
```

**业务模拟心智**：**"主体表 + 关联表 + 外键检查"**是业务模拟的三件套——先造主体（用户/商品），再造流水（订单/行为）引用主体（一对多——`../../阶段%202：核心三大库（必学）/Pandas%20—%20数据分析主力库/05-合并与连接.md` 的 merge 场景）；**模拟的数据也要体检**——`orders["amount"].describe()` 看一眼分布合理吗；**金额要 `clip` 下限**（正态会生成负数金额——"负数订单在真实世界不存在"）——**"模拟是写代码，不是摇骰子——业务规则要编码进生成逻辑"**。

## 5. 时间序列模拟

**时间数据的模拟 = 趋势 + 周期 + 噪声**（`../../阶段%202：核心三大库（必学）/Pandas%20—%20数据分析主力库/07-时间序列Pandas版.md` 的分析素材来源）：

```python
import numpy as np
import pandas as pd

rng = np.random.default_rng(11)
dates = pd.date_range("2026-01-01", periods=365, freq="D")

trend  = np.linspace(0, 50, 365)                    # 上升趋势（业务在增长）
season = 20 * np.sin(2 * np.pi * np.arange(365) / 7)  # 周周期（周末高）
noise  = rng.normal(0, 8, 365)                       # 随机噪声

df = pd.DataFrame({
    "date": dates,
    "sales": (100 + trend + season + noise).clip(lower=0).round(0),
})
df.to_csv("sales_sim.csv", index=False, encoding="utf-8-sig")
```

**时序模拟心智**：**"趋势 + 周期 + 噪声 = 像真的时序"**——纯随机数的时序不像业务（业务有趋势有周期）；周期用正弦（`sin(2πt/7)` 是 7 天一周期的星期效应）；**模拟好的时序直接是 07 篇 resample/rolling 练习的完美素材**——**"模拟数据的最大价值：给后续技能当练习场"**；落 CSV/Parquet 存档——**"模拟数据也是数据，也要归档记录来源"**（文件名带 `sim_` 前缀，别和真实数据混——09 篇）。

**进阶方向：模拟"脏"数据**——真实数据的常态是脏，练完干净模拟可以主动掺脏：**随机删 2% 的行**（练缺失处理）、**重复 1% 的行**（练去重）、**把一部分数值写成字符串**（练类型校准）——**"先造干净数据练流程，再造脏数据练清洗——两套都练过，真实数据到手才不慌"**（清洗训练场：`../../阶段%202：核心三大库（必学）/Pandas%20—%20数据分析主力库/03-数据清洗.md`）。
