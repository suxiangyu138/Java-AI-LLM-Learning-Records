## 1. 与爬虫课程的分工

**本课是"买菜"，爬虫课程是"打猎"**（00 总览的分工）：分析师拿数据是为了**分析**，爬虫工程师攻坚是为了**采集工程**——**"我们追求'够用就停'，他们追求'全都要'**"：

```text
分析师（本课）          爬虫工程师（12-Python爬虫 课程）
├── 静态页面表格         ├── 反爬对抗（UA 池/代理/验证码）
├── 几十页以内           ├── 千万级 URL 调度
├── 够用即停             ├── 框架工程化（Scrapy/Playwright）
└── 30 分钟搞定分析素材   └── 分布式采集系统
```

**分工心智**：**"分析师的爬虫止步于静态表格"**——遇到 JS 渲染、登录墙、反爬升级，判断"这数据值不值得打猎"——值得就去爬虫课程系统学，不值得就换数据源（01 篇的决策树——**"爬虫的成本在收益面前才是合理的"**）。

## 2. 最小闭环四步

**静态网页取数的最小闭环**：

```python
import requests
from bs4 import BeautifulSoup

# 第一步：请求页面
resp = requests.get("https://example.com/data.html",
                    headers={"User-Agent": "Mozilla/5.0 ..."},
                    timeout=(3, 15))
resp.raise_for_status()
resp.encoding = resp.apparent_encoding          # 中文页面编码探测（乱码三步法）

# 第二步：解析 HTML 结构
soup = BeautifulSoup(resp.text, "lxml")         # lxml 解析器（比 html.parser 快）

# 第三步：提取数据（下面 3/4 节展开）
# 第四步：落地 DataFrame → 存文件
```

**四步心智**：**"请求 → 解析 → 提取 → 落地"**四步是爬虫的最小骨架（爬虫阶段 2 同款——`../../12-Python爬虫/阶段%202：静态网页爬虫（入门）/01-Requests库实战.md`）；**中文页面先设 `resp.encoding`**（乱码是编码问题不是请求问题——`../../阶段%201：前置基础/05-数据读写与文件格式.md` 的乱码三步法在网页场景同样成立）；**先看页面再写代码**——F12 打开开发者工具确认数据在 HTML 里还是接口里（**接口里有 JSON 就别解析 HTML——API 优先原则**——`../../12-Python爬虫/阶段%205：动态网页爬虫（难点）/01-动态页面原理与定位.md` 的四步定位法）。

## 3. 表格提取利器 pd.read_html

**网页上最常见的"数据"就是表格——pandas 一行搞定**：

```python
import pandas as pd

# 直接读网页里的所有 <table>（内部自动用 BeautifulSoup/lxml）
tables = pd.read_html("https://example.com/stats.html")
# 返回 DataFrame 列表——一页可能有多个表格

df = tables[0]                 # 第 0 个表格
df = pd.read_html(url, match="销量")   # 只保留标题含"销量"的表
```

**read_html 心智**：**"网页表格 = 现成的 DataFrame"**——`pd.read_html` 自动处理表头、行列、多表格返回列表，**"浏览器里看着是表格，代码里读出来就是表"**——这是分析师最省事的网页取数方式；注意**数字可能带着千分位逗号/百分号**（"1,234" 读成字符串——清洗时 `to_numeric` 处理——`../../阶段%202：核心三大库（必学）/Pandas%20—%20数据分析主力库/03-数据清洗.md`）；**一页多表用 `match` 参数精准选**。

## 4. 解析与提取

**表格之外的结构化数据（列表/详情页）用 CSS 选择器提取**：

```python
from bs4 import BeautifulSoup

soup = BeautifulSoup(resp.text, "lxml")

# 按标签/类名/属性提取（CSS 选择器——爬虫阶段 1 的选择器课）
rows = soup.select("div.product-list > div.item")
for row in rows:
    name  = row.select_one("h3.name").get_text(strip=True)   # 提取文本
    price = row.select_one("span.price").get_text(strip=True)
    data.append({"name": name, "price": price})

df = pd.DataFrame(data)
```

**提取心智**：**"先定位容器，再定位字段"**——两层 `select`（先选列表容器，再选每项字段）；`get_text(strip=True)` 去掉多余空白；**选择器写"稳"的**：`class` 比标签稳、`id` 比 `class` 稳（爬虫阶段 1 的"稳定锚点"概念）；**先提取 3 条验证，再全量提取**——"先跑 3 条看结构对不对，别 3000 条全错"——**"提取代码写错时，跑得越快错得越多"**。

## 5. 静态与动态页面

**静态页面：数据在 HTML 里**（`resp.text` 直接有）——本课处理范围。

**动态页面：数据是 JS 加载的**（`resp.text` 里没有，浏览器渲染后才出现）——**判断方法：F12 → Network → 找 XHR/JS 请求**——数据往往在接口里（`https://api.xxx.com/data` 返回 JSON——**那直接按 05 篇调接口**，比渲染网页快 10 倍）。

**动态页面的正确姿势**（按顺序）：**① 找接口直取**（05 篇——首选）→ **② 交给 Playwright/Selenium 渲染**（爬虫阶段 5 的主场——`../../12-Python爬虫/阶段%205：动态网页爬虫（难点）/`）→ **③ 评估值不值得**（01 篇决策树）——**"动态页面不是不能爬，是分析师不该在这里恋战"**。

## 6. 合规边界

**爬网页有边界——三条底线**（`../../阶段%201：前置基础/08-数据素养与伦理.md` + 爬虫课程的合规课）：

1. **看 robots.txt**——`https://example.com/robots.txt` 明说哪些不能爬——**"站方写明的边界，别去碰"**
2. **控制频率**——请求间隔 1-3 秒，别把对方服务器打崩——**"礼貌爬虫三不：不快、不重、不绕"**（不绕过登录验证、不绕过频率限制）
3. **数据合规**——个人信息/受版权保护的商业数据**爬下来也不能随意发布**（`../../12-Python爬虫/阶段%204：反爬基础（高频遇到）/08-合规边界与对抗伦理.md` 的个保法映射）——**"爬得到 ≠ 能用得"**

**边界心智**：**"合规问题不是技术问题，是'要不要做'的问题"**——爬取前先过一遍"该不该爬"（数据是否公开、站方是否禁止、用途是否正当）——**"技术让一切皆有可能，合规让一切有边界——分析师的工作在边界内"**。
