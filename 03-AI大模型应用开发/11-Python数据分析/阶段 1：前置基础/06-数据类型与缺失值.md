## 1. 为什么类型和缺失是第一课

`02-数据分析全流程与心智模型.md` 说过：问题定义决定成败 50%——**数据质量决定剩下的 30%**——类型错了（"100" 是字符串不是数字）、缺失没处理（mean() 变 NaN），**后面的所有统计和图表都是错的**——**"脏数据进、脏结论出"**——这是清洗（阶段 2 主体系 `../06-数据清洗与预处理.md`）的认知前提，本课先把概念立起来。

## 2. Pandas 类型体系

| 类型 | 含义 | 例子 | 注意 |
|------|------|------|------|
| int64 | 整数 | 年龄 22 | 缺失会变 float64 |
| float64 | 浮点 | 票价 29.9 | 计算主力 |
| object | 文本/混合 | 姓名/性别 | 字符串的"默认袋" |
| bool | 布尔 | True/False | 筛选的原料 |
| category | 分类 | 舱位 C/Q/S | 省内存、排序有序（阶段 2） |
| datetime64 | 时间 | 2026-08-10 | 时间分析基础（阶段 3 时序篇） |

**查看类型**：`df.dtypes`（每列类型）、`df["age"].dtype`（单列）——**拿到数据先 `df.info()` 看类型**（info 的输出里 object 列要警惕：是文本还是"伪装成文本的数字"）。

## 3. NaN 与 None

```python
import pandas as pd
df["age"] = df["age"].replace(0, pd.NA)   # 把 0 标记为缺失（0 可能是"没填"）

df.isna().sum()        # 每列缺失计数（第一检查动作！）
df["age"].isna().mean() # 缺失比例（>5% 要处理，>30% 要考虑删列）
```

**NaN 的本质**：`NaN`（Not a Number）是 float 的"缺失标记"——**NaN 传染**：`mean()` 遇到 NaN 返回 NaN（必须 `skipna` 或先处理）；**NaN 不等于任何值**：`df[df.age == float("nan")]` 查不到（要用 `isna()`）——**判断缺失只用 `isna()`/`isnull()`，永远不用 `==`**。

**NaN vs None 对比**：NaN 是数值型的缺失（float64 出现 NaN——计算会传染）；None 是 Python 的"空"（object 列出现 None）；**读 CSV 时空单元格 → pandas 自动变 NaN**（这是 read_csv 的默认行为——`05-数据读写与文件格式.md`）。

## 4. 类型转换与陷阱

```python
df["price"] = df["price"].astype(float)        # 正常转换
df["age"] = pd.to_numeric(df["age"], errors="coerce")   # 脏转数值：转不了的变 NaN（推荐！）
df["date"] = pd.to_datetime(df["date"], errors="coerce")  # 时间转换同理
```

**三大陷阱**：

| 陷阱 | 现象 | 解法 |
|------|------|------|
| 文本数字 | `"100"` 是字符串——`mean()` 直接报错或乱算 | `to_numeric(errors="coerce")`——**转不了的变 NaN**（先看错再补） |
| 中文数字/单位 | `"100元"`/`"1,000"` | 先 `str.replace` 去单位/逗号再转 |
| 混合脏数据 | 一列里有数字有文本 | `to_numeric(coerce)` 后按缺失处理 |

**转换纪律**：**先 `errors="coerce"` 看转换失败比例**（转不了的 = 脏数据线索——不是直接报错）；**转换是"显式行为"**——不转换就计算 = 默认把脏带进结论。

## 5. 缺失值三处理

| 处理 | 做法 | 适用 |
|------|------|------|
| 删行 | `df.dropna()` | 缺失少（<5%）且该行其他列有用 |
| 删列 | `df.drop(columns=["col"])` | 某列缺失 >30% 或该列不重要 |
| 填充 | `df.fillna(value)` | 缺失中等——按业务填（均值/中位数/0/前值） |

**填充的心智**（阶段 2 深潜，本课立概念）：**填充是"编数据"——必须写明为什么**（均值 = "用总体水平代替"、0 = "视为无"、前值 = "视为不变"）；**不同列不同策略**（年龄用中位数、票价用 0 或均值、性别用众数）——**"没有'默认填充'，只有'说明理由的填充'"**——`fillna(0)` 一行代码谁都会写，**"为什么填 0"才是分析师的价值**。

## 6. 异常值：数据质量的第二杀手

**类型错、缺失、异常——脏数据三兄弟**（异常 = 数值不在合理范围：年龄 -5、票价 99999、分数 150）：

```python
df["age"].describe()          # 看 min/max——先发现明显异常
df[df["age"] < 0]             # 找出负年龄（可疑行）
df["age"].quantile(0.99)      # 99 分位——找极端值参考
```

**异常值三处理**（与缺失同构——先"体检发现"再"处理"）：

| 处理 | 做法 | 适用 |
|------|------|------|
| 删除 | `df = df[df["age"] >= 0]` | 明显录入错误（负年龄） |
| 保留 | 不处理 | 合理的长尾（票价 500 是真实头等舱） |
| 封顶/替换 | 超 99 分位设成 99 分位 | 极值扭曲均值时（阶段 2 深潜） |

**异常值心智**：**"异常≠错误"**——票价 512 是真实值、年龄 -5 才是错误——**处理前先判断"这是真的还是录入错"**（领域知识 + 上下文——`08-数据素养与伦理.md` 的"先怀疑再处理"）；**处理要留痕**（notebook 里写明"删除了 3 行负年龄"——复盘可查）。

## 7. describe 六指标解读

**`df.describe()` 是数值列的"体检报告"**（06 篇的配套——看分布先看它）：

| 指标 | 含义 | 解读要点 |
|------|------|---------|
| count | 非空计数 | 与总行数对比 = 缺失数 |
| mean | 平均值 | 受极端值影响大（异常值 99999 会把均值拉飞） |
| std | 标准差 | 波动大小——std 大 = 数据散 |
| min / max | 最小/最大 | **先看这两个——异常值第一现场** |
| 25%/50%/75% | 四分位数 | 中位数（50%）比均值抗异常——**分布看分位数** |

**解读纪律**：**先看 count 再看 min/max**（缺失与异常——`06` 篇的体检）；**均值 vs 中位数对比**（两者差很多 = 分布偏斜或有极端值——"平均工资"骗人的原因）；**describe 是"描述性分析"的第一输出**（`02` 篇——"发生了什么"先答这个）。

## 8. 一个追问：为什么 NaN 是 float

**因为 IEEE 754 浮点标准预留了 NaN 位模式**（整数没有"非数"编码）——**这正是"缺失让整列变 float"的根源**：int 列出现缺失 → pandas 自动升级为 float64（`age` 显示 float64 但你知道年龄是整数——大概率有缺失）。

**推论（实战判断技巧）**：**"类型异常变 float = 缺失的报警信号"**——看到 `df.info()` 里应该是整数的列变成 float64，第一反应是 `df["age"].isna().sum()` 查缺失（而不是困惑"为什么是小数"）——**"类型变化是 pandas 在向你报告数据问题"**——这是 `06` 篇"体检先于处理"的具体化。
