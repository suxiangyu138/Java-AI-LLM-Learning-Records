## 2. 实战：泰坦尼克 EDA

**第 1 步 定义问题**（先写问题卡——02 课）：

> 问题：泰坦尼克上什么样的人更可能幸存？——需要列：Survived（0/1）、Pclass（舱位）、Sex、Age、Fare——验证方式：分组幸存率对比。

**第 2 步 获取数据**（05 课）：

```python
import pandas as pd
df = pd.read_csv("titanic.csv")
df.head()          # 看长相
df.info()          # 结构与缺失：Age/Cabin/Embarked 有缺失
```

**第 3 步 清洗数据**（06 课——先体检再处理）：

```python
df["Age"] = pd.to_numeric(df["Age"], errors="coerce")   # 类型确认
df.isna().sum()                                          # 缺失：Age 177、Cabin 687、Embarked 2
# 三处理方案：Age 用中位数填充（写明理由）；Cabin 缺失太多（68%）删列；Embarked 用众数填充
df["Age"] = df["Age"].fillna(df["Age"].median())
df["Embarked"] = df["Embarked"].fillna(df["Embarked"].mode()[0])
df = df.drop(columns=["Cabin"])
```

**第 4 步 探索分析**（04/06 课——分组对比——阶段 2 深潜，先会用基础版）：

```python
df.groupby("Sex")["Survived"].mean()        # 女性幸存率 vs 男性（差多少？）
df.groupby("Pclass")["Survived"].mean()     # 头等舱 vs 三等舱
df["AgeGroup"] = pd.cut(df["Age"], bins=[0, 18, 40, 100], labels=["少年", "中年", "老年"])
df.groupby("AgeGroup")["Survived"].mean()   # 年龄组幸存率
```

**第 5 步 可视化**（07 课——图即证据）：

```python
import matplotlib.pyplot as plt
%matplotlib inline
df.groupby("Pclass")["Survived"].mean().plot(kind="bar", title="各舱位幸存率")
plt.ylabel("幸存率")                          # 坐标轴从 0 开始（08 课纪律）
plt.show()
```

**第 6 步 得出结论**（回答第 1 步的问题）：

> 结论（示例）：女性幸存率约 74%、男性约 19%（差 4 倍）；头等舱约 63%、三等舱约 24%——**"性别与舱位是幸存率最强的两个特征"**（证据：分组均值 + 柱状图）。

**第 7 步 汇报呈现**（07 课交付纪律）：`Restart & Run All` 跑通 → 导出 HTML → 每个图表后写解读（`08` 课的批判清单过一遍：样本 891 是全量吗——是（数据集本身））。

**七步复盘**：每一步的产出物（问题卡/清洗方案/分组表/图/结论）就是你的**EDA 报告**——**"报告的价值 = 七步每一步都有痕迹"**。

## 4. 常见报错速查

| 报错 | 原因 | 解法 |
|------|------|------|
| `ModuleNotFoundError: No module named 'pandas'` | 库没装/装错环境 | `pip install pandas`——先确认环境激活（01） |
| `FileNotFoundError` | 路径不对 | 绝对路径或 chdir 到数据目录（05） |
| `UnicodeDecodeError` | 编码不对 | `encoding="gbk"` 或 `"utf-8"`（05） |
| `KeyError: 'xxx'` | 列名不存在 | `df.columns` 看真实列名（含空格/大小写） |
| 图不显示 | 没执行 `%matplotlib inline` | 魔法命令先行（07） |
| `TypeError: 'NoneType'...` | append 等原地操作当返回值用 | 原地操作无返回值（03） |
| `NameError: 'xxx' not defined` | 变量没定义/单元格没运行 | 检查单元格运行顺序（07 内核状态） |

**排错纪律**：**报错信息是最小线索**——先读完整报错（最后一行）再动手；**按上表对号入座**；解决不了就 `Restart & Run All` 重跑（很多"灵异报错"是运行顺序导致的）。
