## 2. 变量与数据类型

```python
price = 29.9        # float 浮点（价格/指标）
count = 100         # int 整数
name = "titanic"    # str 字符串（文本）
is_passenger = True # bool 布尔（True/False）
```

**关键认知**：**Python 变量是"贴标签"**（`a = 1` 是把名字 a 贴到值 1 上——不是盒子）——**动态类型**（同一个变量可换类型——但数据分析建议"一个变量一个用途"）；**f-string 是主力**（格式化输出——数据分析日志的主角）：

```python
print(f"平均票价 {price:.2f} 元，共 {count} 名乘客")   # 平均票价 29.90 元，共 100 名乘客
```

## 3. 四大容器

| 容器 | 特点 | 数据分析用途 | 例子 |
|------|------|-------------|------|
| list 列表 | 有序、可改、可重复 | 一列数据（最常用） | `ages = [22, 35, 41]` |
| tuple 元组 | 有序、不可改 | 固定配对（坐标/键值） | `pt = (x, y)` |
| dict 字典 | 键值对、无序、查得快 | 映射（名称→值） | `sales = {"a": 100, "b": 200}` |
| set 集合 | 无序、去重 | 去重/交集差集 | `uniq = set(ages)` |

**数据分析高频操作**：

```python
ages = [22, 35, 41, 35, 22]
len(ages)                # 5 长度
ages[0], ages[-1]        # 22, 22 索引（-1 = 最后一个）
sum(ages) / len(ages)    # 31.0 平均值（手算）
sorted(set(ages))        # [22, 35, 41] 去重排序
sales = {"a": 100, "b": 200}
sales["c"] = 300         # 新增键
for k, v in sales.items(): print(k, v)   # 遍历键值
```

**易错点**：`ages[1:3]` 是**左闭右开**（取索引 1、2——不含 3）；字典的键**不可变**（list 不能当键、tuple 可以）；`ages.append(50)` 是原地修改（没有返回值——新手常写成 `ages = ages.append(50)` 得到 None）。

## 4. 流程控制与函数

```python
if count > 100:                  # 条件
    print("大样本")
elif count > 10:
    print("小样本")
else:
    print("太少")

for age in ages:                 # 遍历
    if age > 30:
        print(f"{age} 偏大")

def avg(nums):                   # 函数——"起好名字的代码块"
    """计算平均值（docstring 说明用途）"""
    return sum(nums) / len(nums)

print(avg(ages))                 # 31.0
```

**函数纪律**：**一函数一职责** + **起名动宾**（`calc_avg` 好过 `f`）+ **docstring 写用途**——数据分析脚本的函数是"可复用步骤"（清洗函数/统计函数——阶段 2 会大量用到）。

## 5. 列表推导式

**列表推导式 = 一行循环**——Python 数据分析的"招牌语法"（快 + 可读）：

```python
ages = [22, 35, 41, 35, 22]
adults = [a for a in ages if a >= 30]      # [35, 41, 35] 过滤
double = [a * 2 for a in ages]             # [44, 70, ...] 变换
labels = ["成人" if a >= 30 else "青年" for a in ages]   # 条件变换
```

**心智**：`[表达式 for 元素 in 数据 if 条件]`——读法："对数据里的每个元素，满足条件就做表达式"——**能写推导式 = 会数据变换**（Pandas 的 apply/筛选本质同理——阶段 2 的思维预演）。

## 6. 异常与读文件

```python
try:
    price = float("abc")         # 会抛 ValueError
except ValueError as e:
    print(f"转换失败: {e}")      # 转换失败: could not convert string to float: 'abc'
finally:
    print("无论如何都执行")
```

**读文件**（数据分析第一入口——但记住：**日常用 pandas 读**（`05-数据读写与文件格式.md`），原生 open 只在处理非表格文件时用）：

```python
with open("data.csv", encoding="utf-8") as f:   # with = 自动关闭（铁律）
    for line in f:
        print(line.strip())
```

**异常纪律**：**预测性异常才 try**（读文件/类型转换——一定会遇到的）；**逻辑错误不 try**（bug 要让它炸出来——藏起来更难查）；`with open` **必须用**（不写 with = 文件句柄泄漏）。

## 7. 字符串与高频内置函数

**字符串操作**（数据分析里文本列的日常）：

```python
name = "  titanic.csv  "
name.strip()                 # "titanic.csv" 去首尾空白（清洗第一动作）
name.split(".")              # ["  titanic", "csv"] 按分隔符拆
"titanic".upper()            # "TITANIC" / .lower() 小写
",".join(["a", "b"])         # "a,b" 拼接（写 CSV 行）
"100元".replace("元", "")     # "100" 去单位（05/06 篇清洗前置）
"abc123".isdigit()           # False 判断是否数字字符
```

**高频内置函数**：

```python
len / sum / max / min / sorted / round    # 统计基础
zip(["a","b"], [1,2])        # 配对 → [("a",1), ("b",2)]（造字典常用）
list(enumerate(["x","y"]))   # [(0,"x"), (1,"y")]（遍历要序号时）
dict(zip(keys, values))      # 两个列表合成字典（列优先字典的造法！）
```

**易错点**：字符串**不可变**（`s.upper()` 不改变 s——要重新赋值）；`"10" + 1` 报 TypeError（字符串与数字不能直接加——先 `int()`）。

## 8. dict 常用方法与函数参数

**dict 的高频方法**（数据分析里字典是"列优先表"的骨架——04 篇）：

```python
d = {"a": 100, "b": 200}
d.get("c", 0)              # 0 —— 取不到给默认值（比 d["c"] 安全——不报 KeyError）
d.setdefault("c", 300)     # 有则取、无则设默认——初始化惯用法
d.items()                  # 键值对列表（遍历用）
d.keys() / d.values()      # 键/值视图
{k: v * 2 for k, v in d.items()}   # 字典推导式（变换整张字典）
```

**函数参数**（够用的三种形态）：

```python
def calc(sales, rate=0.1, *extra):     # 默认参数（rate）——不传就用默认
    total = sum(sales)
    return total * (1 - rate), extra    # 多返回值用元组

s, e = calc([100, 200], rate=0.2)      # 240.0 关键字参数（可读性好——推荐）
```

**参数纪律**：**默认参数写在必选参数后面**（`def f(a, b=1)` 合法、`def f(a=1, b)` 报错）；**调用时用关键字参数**（`rate=0.2` 比 `0.2` 可读——代码即注释）。

## 9. 布尔逻辑与筛选心智

**布尔与逻辑判断**（筛选的心智预演——阶段 2 的 `df[df.age > 30]` 就是布尔筛选）：

```python
age = 35
age > 30 and age < 40       # True —— 且（两个都满足）
age < 18 or age > 60        # False —— 或（满足一个即可）
not (age == 35)             # False —— 非（取反）

ages = [22, 35, 41, 18]
[a > 30 for a in ages]      # [False, True, True, False] —— 布尔列表（筛选的原料！）
any([False, True, False])   # True —— 任一真
all([True, True, False])    # False —— 全部真
```

**布尔纪律**：`and/or/not` 用于**单个条件**（if/筛选条件）；`any/all` 用于**列表整体判断**；**"列表的 and/or 没有逐元素语义——要用推导式生成布尔列表"**（这是阶段 2 筛选/掩码的思维预演——`df[df.age > 30]` 本质就是"布尔列表选行"）。

**过滤 vs 掩码**（两个概念的第一次区分）：`[a for a in ages if a > 30]` = **过滤**（结果里只有满足的）；`[a > 30 for a in ages]` = **掩码**（结果长度不变、每格 True/False）——**"过滤取走满足的、掩码标记满足的——阶段 2 的 `df[布尔列表]` 用的就是掩码"**——先分清这两个，Pandas 筛选就不迷路。

**一句话记住**：`and/or` 问单条件、`any/all` 问列表、推导式造掩码——**"筛选的思维 = 条件 + 布尔列表"**（阶段 2 的 `df[df.age > 30]` 就是这两样的合体）。
