## 1. AI 与分析的融合趋势

**2026 年数据分析的最大变量：AI 从"辅助工具"变"协作伙伴"**——三条趋势线：

```text
2026 三大趋势
├── ① 从 ChatBI 到 Data Agent：自然语言问数 → AI 自动执行分析任务全流程
├── ② 指标平台成 AI 地基：NL2Metrics 依赖语义层（07 篇——指标不统一 AI 答不对）
└── ③ 价值从"生成内容"到"洞察-决策-行动"闭环：
     AI 发现异常 → 解释原因 → 提出建议 → 衔接流程 → 跟踪结果
    ——"AI 分析的价值评价变了：不是'报告写得好不好'，是'决策推动了没有'"
```

**趋势心智**：**"2026 年分析师的 AI 定位：'AI 是分析师的实习生——干得快，但判断要你拍板'"**（方向 A 08 篇 AI 协作边界的高阶版）；**三个时代的对照**——"工具时代（Excel）→ 平台时代（BI/数仓）→ **智能时代（AI 全流程）**——"每个时代都淘汰了一批'只会上一时代工具'的人，也放大了一批'会用新时代工具'的人"；**AI 分析成熟度分级**（2026 报告）——"深度研究 Agent/Coding Agent 最成熟、数据分析 Agent 快速追赶、高风险领域（网安/供应链）实验性——**'数据分析 Agent 已能辅助完成查询/可视化/初步洞察——准确率显著提升'"**——"2026 年的正确姿势：把 AI 当'并肩作战的同事'，不是'玩具'"。

## 2. LLM 辅助分析工作流

**LLM 辅助分析的具体姿势——人定问题，AI 加速执行**：

```text
LLM 辅助分析五场景（2026 分析师日常）
├── SQL 生成：说需求 → AI 写 SQL 初稿 → 人审逻辑（"AI 写代码，人审语义"）
├── 代码提速：清洗/特征代码 AI 生成（方向 B 02 篇特征工程的加速器）
├── 报告初稿：结论人写、框架 AI 铺（方向 A 09 篇 SCQA 的 AI 辅助）
├── 方法建议："这个业务问题有什么分析方法"（方法库的加速器）
└── 异常初判：数据异常 → AI 给假设清单 → 人去验证（"AI 出题，人解题"）
    ——"AI 的价值在'省时间'，不在'替思考'——五个场景都是'人定方向，AI 填土'"
```

```python
# 示例：AI 辅助的"人机闭环"（简化版）
# ① 人：定义问题卡（阶段 4 02 篇）——"7 月 GMV 环比 -8%，帮我拆解原因"
# ② AI：生成拆解代码/假设清单（量价拆解 + 渠道维度 + 用户维度）
# ③ 人：审代码、跑数据、验证假设（AI 的假设要过数据检验）
# ④ AI：汇总结果生成初稿（结论三段式——方向 A 04 篇）
# ⑤ 人：定稿 + 加业务解读 + 加局限（AI 不懂业务，局限人写）
```

**工作流心智**：**"LLM 辅助的黄金规则：'AI 生成的任何东西都要过人的三关——跑通、验证、理解'"**（方向 A 08 篇"AI 代码过三关"的完整版——**"'AI 写对了'不是'你懂了'——用 AI 的前提是你本来就会"**）；**提示词的质量 = 业务理解的质量**——"帮我分析销售"→"用量价拆解分析 7 月 GMV 环比下降，数据是 sales.csv，输出归因表格和建议"——**"喂给 AI 的问题越具体，AI 的产出越可用——问题定义（阶段 4 01 篇）在 AI 时代更重要"**；**AI 的边界清单**——"AI 不背结论（口径/业务判断/建议责任是人）、AI 不懂你的数据（幻觉——数据细节要人确认）、AI 不替代批判（AI 说'显著'你要问'样本量多少'）——**"AI 是加速器，不是方向盘"**。

## 3. Data Agent：从 ChatBI 到全流程

**Data Agent = 2026 年数据智能的核心形态——从"问答"到"执行"**：

```text
ChatBI vs Data Agent（进化对照）
├── ChatBI（2023-2025）：自然语言 → SQL → 图表（只解决"Ask"环节）
└── Data Agent（2026）：拆解目标 → 找数据 → 查数据 → 检查结果 →
     生成洞察 → 提出建议 → 推动行动（Ask → Model → Deliver 全流程）
    ——"ChatBI 是'智能取数机'，Data Agent 是'自动驾驶的分析师'"
```

```text
Data Agent 落地五痛点 → 五解法（2026 工程实践）
├── 找表不准 → 元数据 + 语义检索（数据目录——08 篇）
├── SQL 语义错误 → 指标语义层（07 篇——NL2Metrics）
├── SQL 语法错误 → Multi-Agent 分工 + 沙箱执行
├── 交互体验差 → 用户画像 + 记忆
└── 评测缺失 → Agent 质量评估体系
    ——"Data Agent 靠谱的前提：指标平台 + 数据目录 + 权限体系（07/08 篇的地基）"
```

**Data Agent 心智**：**"Data Agent 的分工架构：Supervisor（拆任务）→ 专业子 Agent（取数/分析/画图各司其职）→ Human-in-loop（关键节点人确认）"**——**"'两层 Human-in-loop'：任务启动前确认需求、结论交付前确认结果——AI 自主 + 人工把关"**（2026 主流架构——"Agent 不是全自动，是'人机协同的自动化'"）；**业界产品参考**——"帆软 Dora（数位员工：数据分析师/日报推送秘书/风险预警官）、Google Agentic Data Cloud（Data Engineering Agent 自动建管道）、NotebookLM 升级研究代理人（自动产出报告/PPT）——**'2026 年主流平台都在'从问数走向执行'"**；**分析师的应对**——"把 Data Agent 当'自动化管道'管理：喂它好数据（治理）、给它好问题（定义）、审它的产出（批判）——**'会管理 AI 的分析师 = 2026 年最稀缺的人才'"**。

## 4. 人机协作三原则

**2026 Data Agent 落地报告提出的人机分工三原则**（本课核心）：

```text
人机协作三原则（谁来做）
├── ① 决策问责场景：人类为责任主体（AI 可以辅助，责任是人扛）
│    —— "AI 建议拒单，人是最终签字的人——问责永远在人"
├── ② 认知推理场景：适配 Data Agent（拆解/归纳/生成——AI 擅长的）
│    —— "查数据、写初稿、找模式——交给 AI（快且全）"
└── ③ 规则明确场景：确定性自动化（不要 AI 参与——规则系统更稳更可审计）
    —— "报表生成/权限校验——用规则系统，别用大模型（大模型不可预测）"
    ——"三原则的总结：AI 干'认知活'，系统干'规则活'，人干'决策活'"
```

**协作心智**：**"三原则的落地：把分析工作拆成三类活"**——**"认知活（找原因/写结论初稿）→ AI 辅助；规则活（定时报表/权限校验）→ 自动化系统；决策活（拍板/担责/业务判断）→ 人"**——"**会拆活的人，才配指挥 AI**"；**AI 时代分析师的护城河**（三件事 AI 短期替代不了）——**① 业务理解**（懂行业/懂用户——AI 不懂你们的业务）；**② 批判性思维**（审 AI 的结论——数据素养的 AI 版）；**③ 责任与信任**（敢拍板、能兜底——"AI 没有'信用'，人有"）——"**AI 淘汰的是'只做认知活'的分析师（AI 也能做），留下的是'认知+决策+责任'的分析师**"。

## 5. AI 融合实践

**AI 融合的落地清单（本课验收的实战版）**：

```python
# 实践 1：AI 辅助 SQL（日常最高频）
# 提示词模板：把需求讲清（五问——方向 A 01 篇）+ 表结构 + 口径
# "表 orders（order_id, user_id, amount, date, channel），GMV 按支付时间口径，
#  写 SQL：7 月各渠道 GMV 和环比" → AI 出 SQL → 人对口径、跑通、验证

# 实践 2：AI 辅助归因（认知活——人审）
# "用量价拆解 + 渠道/用户维度，分析 GMV 环比 -8%，给假设清单"
# → AI 出假设 → 人跑数据验证 → 结论人写（AI 的假设是"出题"，数据是"批改"）

# 实践 3：AI 辅助报告（方向 A 09 篇 SCQA）
# "按 SCQA 结构写月报摘要：GMV -8% 主因新客减少 20%（数据已验证）"
# → AI 铺结构 → 人填业务解读 + 局限 + 建议
```

**实践心智**：**"AI 融合的落地 = 把 AI 嵌入'分析流水线'的固定环节"**——**"不是'想到了用一下'，是'每个环节都有 AI 的用法'（取数/清洗/归因/报告/审校）——嵌入工作流的 AI 才是生产力"**；**AI 产出的质量守门**——"AI 报告的三查：数字查源（AI 会编数字——'幻觉'）、口径查对（AI 不知道你的口径）、建议查可行性（AI 的建议可能是空话）——**'AI 产出的终审权永远在人'"**（08 篇"AI 合规"的日常版——"审计 AI 产出 = 2026 年分析师的日常"）；**持续学习**——"AI 工具月度更新（模型/产品都在迭代）——**'2026 年数据人的学习曲线：技能 + AI 工具的双轨更新'"**（"每季度盘点一次'我的工作流哪些环节可以 AI 化'"）。
