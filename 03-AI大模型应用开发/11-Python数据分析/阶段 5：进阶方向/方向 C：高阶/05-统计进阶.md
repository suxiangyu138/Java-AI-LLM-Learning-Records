## 1. 统计进阶的定位

**统计进阶 = 从"工具使用者"到"思维拥有者"**——本课三块拼图：

```text
统计进阶三块拼图
├── 置信区间：结果的不确定性怎么表达（点估计 vs 区间估计）
├── 贝叶斯思维：概率是"信念"还是"频率"？（两种世界观）
└── 回归诊断：模型假设被违反了吗？（线性回归的体检）
    ——"假设检验问'显著吗'，置信区间问'多大'，贝叶斯问'多信'，诊断问'合法吗'"
```

**定位心智**：**"阶段 4 08 篇的 A/B 测试用了假设检验（p 值）——本课补上它的'前后文'"**——"p 值之前要算置信区间（效应多大），p 值之后要问先验（贝叶斯视角），模型输出前要过诊断（假设合法吗）"——**"统计进阶 = 让每个数字都有'不确定性'的标注"**；**2026 年统计实践的趋势**：**效应量与置信区间成为报告标配**（阶段 4 08 篇已铺垫——"p 值是守门员，效应量是裁判"）、**贝叶斯方法进入主流**（PyMC 生态成熟——复杂问题用贝叶斯建模）、**假设检验的"改革"**（美国统计学会对 p 值的误用警告——"p 值不是真理，是证据的一部分"）。

## 2. 置信区间

**置信区间 = 估计值的不确定性范围——"效应有多大（±多少）"**：

```python
# 例：A/B 测试里实验组转化率 22.1% vs 对照组 20.0%
# 点估计：绝对提升 2.1pp——但"2.1"只是样本的运气
# 区间估计：95% CI [0.5%, 3.7%]——"真实提升大概率落在这个范围"

from statsmodels.stats.proportion import confint_proportions_2indep
lo, hi = confint_proportions_2indep(1105, 5000, 1000, 5000)   # 实验组/对照组
print(f"提升 95% CI: [{lo:.2%}, {hi:.2%}]")    # CI 不含 0 = 显著且有可信范围

# CI 的正确解读（经典易错点）：
# ✅ "我们有 95% 的把握（重复实验视角），真实提升落在 [0.5%, 3.7%]"
# ❌ "真实提升有 95% 的概率落在 [0.5%, 3.7%]"（频率派视角：真实值是固定常数）
```

**置信区间心智**：**"点估计是'赌一个数'，区间估计是'给一个可信范围'——CI 是诚实的不确定性"**——**"报告任何效应都要带 CI——没有 CI 的效应量是没标误差的测量"**（阶段 4 08 篇"报告三件套"的深化）；**CI 的宽度决定结论的可用性**——"CI [1.9%, 2.3%]（窄——结论可靠）vs [0.1%, 4.1%]（宽——只知道'可能有点用'"——**"CI 宽 = 样本不够或噪声大——决策要等更窄的 CI"**（样本量 power analysis 的动机之一）；**CI 与 p 值的关系**——"CI 不含 0 ⟺ p < 0.05（二分类/回归系数场景）——**'CI 是 p 值的'可视化版'"**（"看 CI 比看 p 值信息量大——CI 给了范围，p 值只给结论"）。

## 3. 贝叶斯思维

**贝叶斯思维 = 概率是"信念的更新"（不是频率）**——两种世界观的对比：

```text
频率派 vs 贝叶斯派（2026 年双轨并存）
├── 频率派：概率 = 长期频率（"抛 1 万次硬币，正面 ≈ 50%"）——p 值/CI 的世界
└── 贝叶斯派：概率 = 信念程度（"这个客户违约概率 0.7"——先验 + 数据 → 后验）
    ——"频率派问'如果重复 1000 次会怎样'，贝叶斯问'看完数据我该多信'"
```

```text
贝叶斯公式（思维核心）
P(假设 | 数据) = P(数据 | 假设) × P(假设) / P(数据)
   后验（看完数据的信念） = 似然（数据支持假设的程度）× 先验（之前的信念）/ 归一化
   ——"先验 + 数据 = 后验——信念被数据更新——贝叶斯是'学习的数学'"
```

```python
# 贝叶斯实战（PyMC——2026 贝叶斯生态主流）——A/B 测试的贝叶斯版
import pymc as pm

with pm.Model():
    p_a = pm.Beta("p_a", alpha=2, beta=2)         # 先验：Beta 分布（转化率常见先验）
    p_b = pm.Beta("p_b", alpha=2, beta=2)
    pm.Bernoulli("obs_a", p=p_a, observed=conv_a) # 似然：数据
    pm.Bernoulli("obs_b", p=p_b, observed=conv_b)
    diff = pm.Deterministic("diff", p_a - p_b)    # 后验：提升的完整分布
    trace = pm.sample(1000, progressbar=False)

p_better = (trace.posterior["diff"] > 0).mean()
print(f"B 优于 A 的后验概率: {p_better:.1%}")      # 贝叶斯版的"结论"（更直观！）
```

**贝叶斯心智**：**"贝叶斯的核心价值：输出'直接可用的答案'"**——**"'B 优于 A 的概率 96.5%'比 'p=0.034' 好懂一百倍——业务方秒懂"**（2026 年 A/B 测试的贝叶斯补充越来越常见——"频率派给 p 值，贝叶斯给概率——决策者爱概率"）；**先验是双刃剑**——"合理的先验让小样本结论更稳（借用行业知识），乱设的先验是偏见——**'先验要能辩护：为什么 Beta(2,2)？因为行业转化率在 10-30%'"**；**贝叶斯的代价**——计算重（MCMC 采样慢）+ 概念门槛（"数据少/时间紧用频率派（快），数据少/结论重要用贝叶斯（稳）"——**"频率派是快车道，贝叶斯是全景路线——选哪个看你要速度还是要视角"**。

## 4. 回归诊断

**回归诊断 = 线性回归的"体检"——模型假设被违反了吗**：

```text
线性回归四大假设（诊断 = 检查假设）
├── 线性：Y 与 X 的关系是线性的 → 残差 vs 拟合值图（散点无模式）
├── 独立：样本相互独立 → 时序/聚类数据的相关性检查
├── 同方差：残差方差恒定 → 残差图（喇叭形 = 异方差）
└── 正态：残差近似正态 → QQ 图（直线 = 正态）
    ——"假设被违反 = 系数/区间不可信——诊断是'用之前先体检'"
```

```python
import statsmodels.api as sm
import matplotlib.pyplot as plt

model = sm.OLS(y, sm.add_constant(X)).fit()
print(model.summary())                    # 系数/标准误/p 值/R²（统计推断的完整报告）

# 残差诊断四图
fig, axes = plt.subplots(2, 2, figsize=(10, 8))
sm.graphics.plot_regress_exog(model, X.columns[0], fig=fig)   # 残差系列图
# ① 残差 vs 拟合值：无模式 = 线性假设成立
# ② QQ 图：点贴直线 = 正态假设成立
```

**诊断心智**：**"诊断的价值：发现'模型的病'——'R² 很高但残差有模式 = 模型漏了非线性项/交互项'"**——**"残差是模型的'尸检报告'——模式藏在残差里"**（"残差有喇叭形 = 异方差——加权最小二乘/对数变换；残差有曲线 = 缺非线性项——加平方项/交互"）；**统计推断 vs 预测的差别**——"线性回归的统计推断（p 值/CI——本课）要求假设成立；**纯预测（方向 B）假设不那么严格**（树模型不假设线性）——"**'要解释系数，先过诊断；只要预测，树模型更省心'"**（"statsmodels 管推断、sklearn 管预测——工具选择的背后是目标不同"）；**多重共线性**——"X 之间高度相关 → 系数不稳定——VIF（方差膨胀因子）>10 警告"（方向 B 02 篇特征共线性的统计版）。

## 5. 统计推断 vs 机器学习

**两条路线的分工（2026 年数据人的完整视角）**：

```text
统计推断 vs 机器学习（不是竞争是分工）
├── 统计推断（本课）：问"关系是什么"——系数/CI/显著性——解释优先
├── 机器学习（方向 B）：问"预测有多准"——AUC/误差——预测优先
└── 因果推断（03 篇）：问"干预会怎样"——效应/反事实——决策优先
    ——"三者的组合 = 完整的数据科学：统计给理解、ML 给预测、因果给决策"
```

**分工心智**：**"数据科学的三个问题三套工具"**——**"'为什么'用统计（解释系数）、'会怎样'用 ML（预测模型）、'做了会怎样'用因果（DID/DoWhy）"**（"用错工具回答错问题是最贵的错误——'用 ML 的 AUC 回答因果问题 = 答非所问'"）；**进阶分析师的标志**——"能在三个范式间切换：要解释用 statsmodels、要精度用 LightGBM、要因果用 DoWhy——**'工具箱的完整度 = 职业的层级'"**；**统计素养的稀缺性**（2026）——"AutoML 让'跑模型'变简单，但'这个结果意味着什么、可信吗'的统计判断依然稀缺——**'AI 时代统计思维更值钱：因为 AI 的结论更需要人来审'"**（方向 A 08 篇 AI 协作边界的统计版）。
