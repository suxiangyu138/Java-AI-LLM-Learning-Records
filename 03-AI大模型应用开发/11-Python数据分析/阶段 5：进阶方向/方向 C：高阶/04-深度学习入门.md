## 1. 深度学习的定位与边界

**深度学习（神经网络）的用武之地——"数据形态决定模型选型"**：

```text
数据形态 → 模型选型（2026 共识）
├── 表格数据 → GBDT（LightGBM——方向 B 05 篇——依然王者）
├── 图像/音频 → CNN（卷积网络——深度学习的绝对主场）
├── 文本 → Transformer（LLM 家族——深度学习的主场）
└── 序列 → RNN/LSTM/Transformer（时序——深度学习与统计之争）
    ——"深度学习的'主场'：高维非结构化数据（像素/文字/音频）——表格数据很少赢 GBDT"
```

**边界心智**：**"表格数据上深度学习很少赢 GBDT 的三个原因"**——**① 表格特征异构稀疏**（类别+数值混合——树模型天然处理）；**② 数据量**（深度学习要海量数据——表格通常只有万级样本）；**③ 成本**（训练慢/调参难/部署重——"杀鸡用牛刀且杀不好"）（方向 B 10 篇面试题的深化）；**深度学习的三个真主场**——图像（卷积——"像素是深度学习喂大的"）、文本（LLM——`../../../03-AI大模型应用开发/02-大模型基础与Prompt工程/` 的模型生态）、高维序列（音频/视频）——**"本课的目标：入门 PyTorch + 知道边界——深入的图像/文本深度学习在 `../../../03-AI大模型应用开发/深度学习/` 体系"**。

## 2. 神经网络基础

**神经网络 = 多层"加权求和 + 非线性激活"的堆叠**：

```text
神经网络三件套
├── 神经元：y = 激活(Σ wᵢxᵢ + b)——权重 w 是模型要学的参数
├── 层：输入层 → 隐藏层（多层） → 输出层——"层数深 = 模型容量大"
├── 训练：损失函数（预测与真实的差距）→ 反向传播（误差倒推）→ 梯度下降（更新权重）
    ——"训练的本质：不断调整 w 让损失变小——和 GBDT 拟合残差异曲同工"
```

```python
# 激活函数（非线性的来源——没有激活函数，多层 = 一层）
# ReLU（默认首选）：max(0, x)——快、缓解梯度消失
# Sigmoid（输出 0-1 概率）；Softmax（多分类概率归一化）

# 损失函数（任务决定）
# 回归：MSE；二分类：BCE（二元交叉熵）；多分类：CrossEntropy
```

**神经网络心智**：**"神经网络的一切都是'权重'"**——**"输入是固定的（数据），输出是固定的（标签），唯一在变的是 w——训练 = 找一组让损失最小的 w"**；**"深"的意义**——"浅层学'简单模式'（线条/词义），深层学'复杂模式'（物体/语义）——**'深度 = 抽象能力的层级'"**；**反向传播的直觉**——"误差从输出层逐层回传，每个 w 知道自己该往哪调——'误差是信使，梯度是命令'"；**和 GBDT 的对照**——"GBDT 串行拟合残差（加法模型），神经网络并行学习特征表示（表示学习）——**'GBDT 学的是'怎么加权特征'，深度学习学的是'特征本身怎么表示'"**。

## 3. PyTorch 基础

**PyTorch（2026 最新 2.13.0——2026-07-08 发布，双月迭代）——深度学习框架的事实标准**：

```python
import torch

# 张量（tensor）= 多维数组（numpy 的深度学习版 + GPU 加速）
x = torch.tensor([[1.0, 2.0], [3.0, 4.0]])       # 2×2 张量
y = torch.randn(3, 4, requires_grad=True)         # 自动求导开关（训练的核心！）

# 自动求导（autograd）：算梯度不用手写——训练循环的发动机
loss = (y ** 2).mean()
loss.backward()                                    # 反向传播——自动算梯度
print(y.grad)                                      # y 每个元素的梯度（2*y/12）

# GPU 加速（有 GPU 时一行切换）
device = "cuda" if torch.cuda.is_available() else "cpu"
x = x.to(device)                                   # 张量搬家
```

**PyTorch 心智**：**"PyTorch 的核心三件套：张量（数据）+ autograd（自动求导）+ nn（网络模块）"**——**"张量 = numpy + GPU + 自动求导"**（"numpy 算梯度要手写，torch 一行 `backward()`——这就是训练代码能写出来的原因"）；**版本纪律**（2026 重要）：**PyTorch 2026 年改双月发布**（2.11 三月/2.12 五月/2.13 七月）——**"版本节奏变快 = 锁版本更重要（requirements.txt 锁 torch==2.13.0）"**；**2.13 的新能力**（本课够用）：FlexAttention 加速、`nn.LinearCrossEntropyLoss` 融合（大模型训练省 4 倍显存）——"入门不追新特性，但要知道版本在快速演进"；**CPU vs GPU**——"入门/小模型 CPU 够跑（慢 10-50 倍），大模型才需要 GPU——**'先 CPU 跑通逻辑，再上 GPU 加速'"**。

## 4. 完整训练流程

**一个完整的 MLP 训练（PyTorch 标准七步）**：

```python
import torch.nn as nn
import torch.optim as optim

# ① 数据（张量化）
X_t = torch.tensor(X.values, dtype=torch.float32)
y_t = torch.tensor(y.values, dtype=torch.float32)

# ② 定义模型（nn.Module——层堆叠）
model = nn.Sequential(
    nn.Linear(X.shape[1], 32), nn.ReLU(),      # 输入层 → 隐藏层 32 个神经元
    nn.Linear(32, 16), nn.ReLU(),
    nn.Linear(16, 1), nn.Sigmoid(),            # 输出层（二分类概率）
)

# ③ 损失函数 + ④ 优化器（Adam——2026 默认首选）
criterion = nn.BCELoss()                        # 二分类交叉熵
optimizer = optim.Adam(model.parameters(), lr=0.001)

# ⑤ 训练循环（epoch：过一遍数据；batch：一批一批喂）
for epoch in range(100):
    optimizer.zero_grad()                       # 清空上轮梯度
    pred = model(X_t).squeeze()                 # 前向传播（预测）
    loss = criterion(pred, y_t)                 # 算损失
    loss.backward()                             # 反向传播（自动梯度）
    optimizer.step()                            # 更新权重
    if epoch % 20 == 0:
        print(f"epoch {epoch}: loss = {loss.item():.4f}")
```

**训练流程心智**：**"训练七步的固定骨架：数据 → 模型 → 损失 → 优化器 → 循环（前向→损失→反向→更新）"**——**"七步是深度学习的'hello world'——背下来，一切模型都是它的变体"**（CNN 换网络结构、LLM 换数据规模——骨架不变）；**训练循环的三个细节**——**`zero_grad()` 必须**（不清梯度会累加——"忘掉 zero_grad 是最常见的入门 bug"）、**batch 的概念**（一批一批喂——大数据的必然——"一次喂全部 = 内存爆炸；一次喂一个 = 慢且震荡"）、**epoch 数**（过几遍数据——"epoch 太少欠拟合、太多过拟合——和 GBDT 的 n_estimators 同理"）；**调训练超参的优先级**（05 篇调参方法论的学习版）——**学习率第一**（lr 0.001 默认——"学习率不对，其他都白调——lOSS 不降先查 lr"）、批次大小、网络宽度深度——"**先让 loss 降下来，再谈精度**"。

## 5. 训练调试

**训练不收敛/效果差时的排查手册**：

```text
训练调试四查
├── ① loss 不降：学习率问题（太大震荡/太小龟速——试 0.01/0.001/0.0001）
├── ② 训练 loss 降但测试差：过拟合（数据少/模型大——加 Dropout/正则/减层）
├── ③ loss 是 NaN：数值问题（lr 太大/数据没归一化——特征标准化必做）
└── ④ 速度慢：检查是否用上了 GPU（device 设置——cpu 跑大模型是自虐）
    ——"深度学习的调试顺序：数据 → 学习率 → 模型容量——和 GBDT 调试同构"
```

**调试心智**：**"深度学习调试的第一工具：画 loss 曲线"**——"训练 loss 和验证 loss 画在一起——差距大 = 过拟合、都不降 = 学习率/数据问题、都降 = 正常训练中"——**"loss 曲线是深度学习的'心电图'——不画曲线调参 = 闭眼开车"**；**复现纪律**（方向 B 铁律延续）——"`torch.manual_seed(42)` + `random.seed` + `np.random.seed` 三件套——**'深度学习有 GPU 并行的不确定性——种子固定是可复现的前提'"**；**和方向 B 的衔接**——"深度学习调参 = GBDT 调参的'更贵版本'（一次训练分钟级 vs 秒级——**'先用小数据/小模型验证思路，再全量训练'"**——"烧钱的实验设计：先小后大"）。
