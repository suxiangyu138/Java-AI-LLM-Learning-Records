## 1. 因果推断的定位

**因果推断 = 用观察数据（没有实验）证明"X 导致 Y"**——2026 年数据科学的核心前沿：

```text
为什么需要因果推断
├── 实验不可行：很多场景不能做 A/B（政策/医学/伤害性干预——不能随机分配"失业"）
├── 观察数据泛滥：业务数据都是观察数据（谁买什么——不是随机分配的）
├── 决策需要因果：投放预算给谁、政策要不要推——需要"做了会怎样"而非"相关怎样"
    ——"相关回答'一起出现'，因果回答'因为所以'——决策需要后者"
```

**定位心智**：**"因果推断 = 从'看到了什么'推断'如果没发生会怎样'（反事实）"**——**"因果问题的本质是反事实：'用户领了券多买了'——那'如果没领券呢'？"**（没领券的对照组是我们永远看不到的——因果推断就是"补全反事实"的统计学）；**与实验的关系**——**"A/B 测试（阶段 4 08 篇）是因果的黄金标准（随机分配 = 完美反事实），因果推断是'没有实验时的替补'"**——"有实验做实验，没实验做因果推断——两者思路同源（对照组）"；**2026 工具生态**（成熟可生产）：**DoWhy**（四步框架——本课主角）、EconML（双重机器学习）、CausalML（uplift 建模）——"**2026 年因果推断已从论文走进生产管线**"。

## 2. 因果与混杂

**观察数据证明因果的最大障碍：混杂变量（confounder）**：

```text
混杂结构（三角）
        Z（混杂：如"年龄"）
       / \
      ↓   ↓
    X（处理：买保险）→ Y（结果：寿命长）
"买保险的人寿命长"——真的是保险的功劳吗？
还是"买保险的人本来就年轻/有钱/健康"（Z 同时影响 X 和 Y）？
    ——"相关性 = 因果 + 混杂——因果推断的任务：把混杂从相关里拆出来"
```

**混杂心智**：**"混杂变量 = 同时影响'处理'和'结果'的第三变量"**——**"年龄/收入/健康意识是健康数据里永恒的混杂"**（"控制混杂 = 比较'除了处理，其他都相似'的人群"）；**三个经典解决方案**：**① 随机实验**（随机分配 = 混杂被随机化抹平——A/B 的原理）；**② 匹配/加权**（倾向得分——让处理组和对照组的"画像"相似）；**③ 利用结构**（DID——用"时间差"消掉不随时间变的混杂——本课第 4 节）——"**方法的选型 = 你对混杂结构的了解程度**"；**因果图（DAG）**——"画图说明'你认为谁影响谁'——**'因果推断的第一步不是算，是画图'**（DoWhy 的 Model 步骤——假设显性化——"把隐藏假设画出来，是科学性的第一步"）。

## 3. DoWhy 四步 API

**DoWhy（PyWhy 项目——2026 成熟版 v0.14）——因果分析的四步框架**：

```python
import dowhy
from dowhy import CausalModel

# ① Model（建模）：画因果图——声明你的假设（混杂结构）
model = CausalModel(
    data=df,
    treatment="insurance",            # 处理变量（X）
    outcome="life_expectancy",        # 结果变量（Y）
    common_causes=["age", "income", "health_awareness"],  # 混杂（Z）
)

# ② Identify（识别）：从因果图推导"要估计什么"（识别策略）
identified = model.identify_effect()

# ③ Estimate（估计）：选估计器算效应（倾向得分匹配/线性回归/双重机器学习）
from dowhy.causal_estimators import PropensityScoreMatchingEstimator
estimate = model.estimate_effect(identified, method_name="backdoor.propensity_score_matching")
print(f"处理效应: {estimate.value:.3f}")     # 保险使寿命平均增加 X 年

# ④ Refute（反驳）：敏感性检验——"换个角度推翻它"（DoWhy 的灵魂！）
refutation = model.refute_estimate(identified, estimate, method_name="placebo_treatment_refuter")
print(f"安慰剂检验 p={refutation.new_effect}, 原效应 {refutation.original_effect:.3f}")
# 安慰剂检验：把处理变量换成随机数重算——如果"假处理"也有效应 = 模型有问题
```

**DoWhy 心智**：**"四步的灵魂：Model 画假设、Identify 定目标、Estimate 选算法、Refute 做检验"**——**"Refute 是 DoWhy 区别于'跑个回归'的关键——因果结论必须过'反驳关'"**（安慰剂检验/随机混杂检验/数据子集检验——"**能撑过反驳的因果，才是站得住的因果**"）；**识别（estimand）与估计（estimator）分离**——"先明确'要估计什么量'（estimand），再选'怎么估计'（方法）——**'先想清楚问题，再选工具——这是因果推断与 ad-hoc 回归的分水岭'**"（2026 实践共识）；**估计器选型**——倾向得分匹配（经典）、线性回归（简单）、**DML 双重机器学习（EconML——高维混杂场景 2026 主流）**——"数据维度低用匹配/回归，维度高用 DML"。

## 4. 双重差分 DID

**DID（双重差分）= 用"时间差 × 组别差"消掉混杂——政策评估的标配**：

```text
DID 逻辑（政策评估案例：某地区 2025 年实施新政策，评估效果）
       处理组（政策区）  对照组（无政策区）
政策前     Y_pre_t         Y_pre_c
政策后     Y_post_t        Y_post_c
第一差（组内前后差）：Δ处理组 = Y_post_t - Y_pre_t（含政策 + 时间趋势）
                      Δ对照组 = Y_post_c - Y_pre_c（只有时间趋势）
第二差（组间差分）：  政策效应 = Δ处理组 - Δ对照组（时间趋势被减掉！）
    ——"对照组吃掉'时间趋势'，剩下的就是政策效应——双重差分的精髓"
```

```python
# PyFixest 实现 DID（2026 主流：一行公式）
import pyfixest as pf

did = pf.feols("y ~ treat * post | id + time", data=df)
did.summary()                          # 核心系数：treat:post = 政策效应
```

**DID 心智**：**"DID 的核心假设：平行趋势（parallel trends）"**——**"没有政策时，两组的变化趋势应该平行——对照组是处理组的'镜像世界'"**（"政策前两组走势一致，政策后差异 = 政策效应"）；**平行趋势的检验**——**事件研究图（event study plot）**："政策前各期两组无显著差异（系数 ≈ 0）——如果有差异，平行趋势假设被违反，DID 结论不可信"——**"DID 报告必备：事件研究图 + 假设陈述"**（2026 实践："每一个因果估计都要陈述识别假设 + 稳健性检验"）；**DID 的进阶形态**——交错采用（各州不同时间实施政策——Callaway-Sant'Anna 估计量 2026 标配）、合成控制（找不到对照组时造一个）——"经典 DID 是入门，交错/合成是进阶"；**DID vs 匹配**——"DID 用时间结构消混杂，匹配用画像相似消混杂——**'数据里有什么结构，就利用什么结构'"**。

## 5. 因果推断的陷阱

**因果推断最容易翻车的四个地方（写进报告的检查清单）**：

```text
因果推断四陷阱
├── ① 未观测混杂：因果图没画到的 Z 仍然存在（"条件可忽略性"是最常违反的假设）
│    —— 处理：敏感性分析（E-value——"要多大未观测混杂才能推翻结论"）
├── ② 选择偏差：样本本身不是随机选的（"买保险的人"和"不买的人"不可比）
│    —— 处理：倾向得分 + 共同支撑检查（两组画像重叠度）
├── ③ 反向因果：X 导致 Y 还是 Y 导致 X？（"抑郁的人睡得差"还是"睡得差导致抑郁"）
│    —— 处理：时间先后（DID/滞后变量——原因必须发生在结果之前）
└── ④ 过度推广：结论只在样本范围内成立（"电商用户"推广到"所有人"）
    —— 处理：结论写明适用范围
```

**陷阱心智**：**"因果推断的可信度 = 假设的透明 + 反驳的严格"**——**"每个因果结论三件套：识别假设（画出来的图）、稳健性检验（DoWhy Refute）、适用范围（样本边界）"**——"没有三件套的因果结论 = 高级的相关性"；**"因果 vs 预测的界限"**（方向 B 09 篇重申）：模型学相关（预测）、因果推断做干预（决策）——"预测模型说'买保险的人寿命长'（预测准确），因果推断才回答'买保险导致寿命长吗'（干预决策）"——**"因果推断是'敢拍板'的分析——拍板就要扛反驳"**；**业务落地**——"因果结论给决策：政策效应 +2.1% 月收入（DID）——建议推广"——"**因果推断的价值 = 决策有了'因为所以'的底气**"（方向 A 09 篇"建议可执行"的因果版）。
