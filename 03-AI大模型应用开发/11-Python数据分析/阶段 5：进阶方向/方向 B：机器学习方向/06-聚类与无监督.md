## 1. 无监督的定位

**无监督学习 = 没有标签（答案），让模型发现数据里的结构**——两类主力：

```text
无监督两大类
├── 聚类：把样本分群（用户分群/商品分组/异常识别——KMeans/DBSCAN）
└── 降维：把高维变低维（可视化/去噪/特征压缩——PCA/UMAP）
    ——"监督学习有'标准答案'，无监督是'考古'——发现数据里本来就有但没人标注的结构"
```

**定位心智**：**"无监督在业务里的三大用途"**——**① 分群**（用户分群运营——方向 A 05 篇 RFM 的 ML 版："让聚类自动发现用户群"）；**② 异常检测**（DBSCAN 的噪声点 = 异常——风控/监控）；**③ 降维前置**（高维数据先降维再聚类/可视化——"先看清再分析"）——**"无监督的输出不是'答案'，是'结构'——结构怎么用，业务说了算"**；**无监督的评估难题**（没有标签——本课第 4 节专讲）——"没有标准答案 = 评估是'看起来合不合理'而不是'对不对'"。

## 2. KMeans：距离聚类

**KMeans = 按距离分群（每个点到最近的中心点）**——最经典、最常用：

```python
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

# ① 标准化必做！（KMeans 按距离——量纲不同的特征会支配距离）
X_scaled = StandardScaler().fit_transform(X[["age", "amount", "frequency"]])

# ② 选 K：肘部法则（惯性随 K 下降——下降变缓的"拐点"）
import matplotlib.pyplot as plt
inertias = [KMeans(n_clusters=k, n_init=10, random_state=42).fit(X_scaled).inertia_
            for k in range(2, 11)]
plt.plot(range(2, 11), inertias, marker="o")
plt.xlabel("K"); plt.ylabel("惯性（簇内距离和）")
# 拐点在 K=4 → 选 4 类

# ③ 聚类（n_init=10：多次随机初始化取最优——KMeans 对初始点敏感）
km = KMeans(n_clusters=4, n_init=10, random_state=42)
labels = km.fit_predict(X_scaled)
```

**KMeans 心智**：**"KMeans 的三个前提：标准化、选 K、数值特征"**——**标准化不做，'金额'会支配'次数'的距离**（"量纲不同 = 距离失真"——聚类第一坑）；**选 K 三招**：肘部法则（惯性拐点）、轮廓系数（本课第 4 节）、业务需求（"运营就要 4 类——K 是业务参数"）——**"肘部法则是启发式不是真理——拐点不明显时靠业务定"**；**KMeans 的假设**：球形簇 + 大小均匀（数据是长条/环形时失效——换 DBSCAN）；**KMeans 的局限**：对噪声敏感（一个离群点会拉偏中心）——"KMeans 没有'噪声'概念，每个点都必须归一个簇"。

## 3. DBSCAN：密度聚类

**DBSCAN = 按"密度"聚类——密度高的区域成簇，稀疏区域是噪声**：

```python
from sklearn.cluster import DBSCAN

# 参数：eps（邻域半径——多大的圈算"邻居"）、min_samples（多少邻居算"核心点"）
db = DBSCAN(eps=0.5, min_samples=10)
labels = db.fit_predict(X_scaled)        # 标签 -1 = 噪声（不属于任何簇！）

print(pd.Series(labels).value_counts())  # 簇 0/1/2... + 噪声 -1
```

**DBSCAN 心智**：**"DBSCAN vs KMeans：不用指定 K、能发现任意形状、自带噪声检测"**——三个优势对应三个场景：**不知道几类**（先 DBSCAN 探结构）、**形状不规则**（环形/长条——KMeans 会切碎）、**要剔除异常**（-1 噪声点 = 异常名单——风控/监控场景）；**DBSCAN 的代价**：两个超参（eps/min_samples）难调（"eps 太小全是噪声、太大全是一类——调参靠领域知识 + 尝试"）；**eps 的估计**（k-距离图——到第 k 近邻距离的拐点）；**DBSCAN 对密度不均敏感**（有的簇密有的疏——一个 eps 顾此失彼——"密度差异大的数据换 HDBSCAN（层次版）"）；**业务对照**："KMeans 是'划地盘'，DBSCAN 是'圈部落'——地盘规则均匀，部落按聚集程度自然形成"。

## 4. 聚类评估：没有标签怎么打分

**聚类没有"正确答案"——评估分两类**（有真实标签 vs 无标签）：

```python
# ① 无标签：轮廓系数（同一个簇内近、不同簇间远——-1 到 1）
from sklearn.metrics import silhouette_score
s = silhouette_score(X_scaled, labels)
print(f"轮廓系数: {s:.3f}")        # >0.5 良好；<0.2 簇重叠严重（换 K 或换算法）

# ② 有真实标签（罕见但可评估）：ARI/NMI（调整兰德指数/互信息）
from sklearn.metrics import adjusted_rand_score
ari = adjusted_rand_score(y_true, labels)   # 1 = 和真实分群完全一致

# ③ 业务评估（最重要）：每个簇的特征画像是否"讲得通"
profile = df.groupby("cluster").agg(avg_age=("age", "mean"),
                                     avg_amount=("amount", "mean"),
                                     count=("user_id", "count"))
print(profile)   # "簇 0 是年轻高消费、簇 1 是年长低消费..."——讲得通才是好聚类
```

**评估心智**：**"聚类评估的终极标准：业务讲得通"**——"轮廓系数 0.6 但 4 个簇长得一模一样 = 没用；轮廓系数 0.3 但每个簇都有鲜明画像 = 有用"——**"聚类的'对错'由业务定义——簇画像（每个簇的平均特征）是评估的第一产品"**；**评估的顺序**：先业务画像（讲得通吗）→ 再轮廓系数（分离度如何）→ 有标签时 ARI（与真值一致吗）；**聚类结果的稳定性检查**——"换个随机种子簇还一样吗"（n_init=10 多次初始化——不稳定 = 数据没有清晰结构——"聚类不稳说明数据本身就是连续分布的，硬分是自欺"）。

## 5. PCA 降维

**PCA（主成分分析）= 找数据方差最大的方向，把高维压缩**：

```python
from sklearn.decomposition import PCA

# ① 可视化：100 维 → 2 维（聚类结果画出来）
pca = PCA(n_components=2)
X_2d = pca.fit_transform(X_scaled)
plt.scatter(X_2d[:, 0], X_2d[:, 1], c=labels, cmap="viridis", alpha=0.6)
plt.xlabel("PC1"); plt.ylabel("PC2"); plt.title("聚类结果可视化（PCA 降维）")

# ② 解释方差：选多少个主成分（累计解释 80-90% 即可）
explained = pca.explained_variance_ratio_
print(f"前 2 个主成分解释 {explained.sum():.0%} 的方差")
```

**PCA 心智**：**"PCA 的两大用途：可视化（降到 2/3 维画出来）和压缩（降维去噪）"**——**"高维聚类/看数据分布，先 PCA 到 2 维画出来——'眼见为实'是无监督的第一工具"**；**"解释方差"是选维度的尺子**——"累计解释 80-90% 就够——再加维度边际收益小"；**PCA 的代价：可解释性丢失**（主成分是原始特征的线性组合——"PC1 是'综合因子'，不是某个业务字段"——**"PCA 用于探索和预处理，不用于业务解释"**）；**PCA 前的标准化**（和 KMeans 同理——方差最大的特征会支配主成分——"不标准化 = 主成分被量纲绑架"）；**进阶**：UMAP（非线性降维——聚类可视化更好，2026 年流行——"PCA 是线性快，UMAP 是非线性美——探索用 UMAP，流程化用 PCA"）。

## 6. 聚类选型与业务应用

**聚类选型决策表**：

| 场景 | 推荐 | 理由 |
|------|------|------|
| 用户分群/商品分组（球形数据） | KMeans | 简单快、可解释、业务常用 |
| 形状不规则/带噪声/未知 K | DBSCAN | 任意形状 + 自动噪声 |
| 层级结构（大群套小群） | 层次聚类 | 画出树状图看层级 |
| 高维先看结构 | PCA/UMAP + 聚类 | 降维前置 |
| 电商用户分群（业务落地） | KMeans + 画像 | 分群 → 画像 → 策略（方向 A 05 篇闭环） |

**应用心智**：**"聚类业务的完整闭环：分群 → 画像 → 策略 → 追踪"**（方向 A 05 篇分层运营的 ML 版——"KMeans 分出 4 群，画像定义每群，策略分派每群，追踪看策略效果"）；**聚类与监督的衔接**——"聚类发现的群可以当'伪标签'训监督模型"（半监督思路——"先用聚类探索，再建分类器自动化分群"）；**聚类的常见失败**：特征选错（把无关特征塞进去——"聚类结果垃圾，先怀疑特征不是算法"）、不标准化、K 拍脑袋——**"聚类失败 80% 是预处理问题，不是算法问题"**。

## 8. 本节验收

**验收动作**：① 标准化 + KMeans 用户分群（肘部法则选 K）；② DBSCAN 对比（记录噪声点数量与形状差异）；③ 每群做画像（平均特征表格）+ 轮廓系数；④ PCA 降到 2 维画聚类图——**"KMeans + DBSCAN + 评估 + PCA = 无监督能力"**——**练习纪律**：聚类后必做两件事——画像（讲得通吗）和种子稳定性检查（换种子还一样吗）——"没画像的聚类是黑盒，不稳定的聚类是碰运气"。

> 🎯 **核心要点**：无监督 = 发现结构（分群/异常/降维）；**KMeans（标准化必做 + 肘部法则 + 球形假设）**；**DBSCAN（免 K/任意形状/自带噪声——eps 调参是功夫）**；**聚类评估（业务画像讲得通是终极标准——轮廓系数辅助——种子稳定性检查）**；**PCA（可视化 + 压缩——先标准化——探索用 UMAP 流程用 PCA）**；选型决策表 + 业务闭环（**分群→画像→策略→追踪**）——"聚类失败 80% 是预处理问题，不是算法问题"。
