## 1. 模型家族地图

**选模型先看"家族"——四大家族各擅其长**（2026 表格数据视角）：

```text
模型家族地图
├── 线性族：逻辑回归/线性回归/岭回归——小样本/可解释性/基线
├── 树族：决策树 → 随机森林（Bagging）→ GBDT（LightGBM/XGBoost——表格王者）
├── 核族：SVM——中样本/非线性边界（表格数据上已被树族盖过）
└── 神经网络：MLP/深度学习——大数据/图像文本（表格数据很少赢树族）
    ——"表格数据默认路线：线性基线 → 随机森林 → LightGBM → 够了"
```

```python
# 模型对比标准流程（基线先行——01 篇纪律）
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import cross_val_score

models = {
    "逻辑回归基线": LogisticRegression(max_iter=1000, random_state=42),
    "随机森林":     RandomForestClassifier(n_estimators=200, random_state=42),
    "LightGBM":     LGBMClassifier(random_state=42, verbose=-1),
}
for name, model in models.items():
    score = cross_val_score(model, X_train, y_train, cv=5).mean()
    print(f"{name}: {score:.3f}")
```

**选型心智**：**"选型的四个依据：样本量、特征类型、可解释性需求、业务指标"**——小样本线性（抗过拟合）、表格大样本 LightGBM（默认王者）、要解释选线性或树（SHAP 配合）、业务要概率输出全部行（都能给）——**"没有'最好的模型'，只有'最适合场景的模型'"**；**选型不是一次定死**——"先跑 3 个代表（线性/树/GBDT）各 5 折 CV 看差距，差距 <2% 选简单的（可解释、好维护）——**"模型选择的黄金法则：够用就好，简单优先"**（复杂度是负债——上线后每一点复杂度都要运维费）。

## 2. 交叉验证选型

**交叉验证不是"一种"——按数据形态选型**（入门教了 5 折，本课讲什么时候不能用）：

```python
# ① 标准 K 折：独立同分布数据（默认——99% 的场景）
# ② 分层 K 折（StratifiedKFold）：分类不平衡必用（每折类别比例一致）
from sklearn.model_selection import StratifiedKFold, GroupKFold, TimeSeriesSplit

# ③ 分组 K 折（GroupKFold）：同一用户多行——用户的数据不能跨折！
#    泄漏型错误：同一用户的 3 行分散在训练和测试 → 模型"见过这个人"
# ④ 时序切分（TimeSeriesSplit）：时间序列——滚动窗口（07 篇详讲）
```

**CV 心智**：**"交叉验证选型三问：样本独立吗（分组）、类别平衡吗（分层）、是时序吗（滚动）"**——**"分组数据不分组验证 = 最隐蔽的过拟合"**（用户行为数据 90% 是分组数据——同一用户多次行为——"把同一用户的记录拆到训练和测试，模型在'作弊'——它认识这个人"）；**CV 的作用不仅是评估，是"选型依据"**（用 CV 平均分选模型/选参数——"单次切分的分数有运气，CV 平均才是成绩"）；**CV 的坑：分数差异大（std 高）说明数据异质**——先查分组结构（"CV 标准差 0.05 以上 = 模型在部分数据上崩——先查泄漏和分组"）。

## 3. 调参策略：三种搜索

**调参三策略——按参数数量与预算选**：

```python
# ① 网格搜索（GridSearchCV）：小参数空间穷举——直觉但慢
from sklearn.model_selection import GridSearchCV

param_grid = {"n_estimators": [100, 200], "max_depth": [5, 7, 9]}
grid = GridSearchCV(RandomForestClassifier(random_state=42),
                    param_grid, cv=5, scoring="f1", n_jobs=-1)
grid.fit(X_train, y_train)
print(grid.best_params_, grid.best_score_)

# ② 随机搜索（RandomizedSearchCV）：大空间随机撒点——比网格省 10 倍时间
from sklearn.model_selection import RandomizedSearchCV

# ③ 贝叶斯优化（optuna——2026 主流：用历史尝试指导下一步）
import optuna
def objective(trial):
    params = {
        "n_estimators": trial.suggest_int("n_estimators", 100, 500),
        "max_depth":    trial.suggest_int("max_depth", 3, 10),
        "learning_rate": trial.suggest_float("learning_rate", 0.01, 0.3, log=True),
    }
    model = LGBMClassifier(**params, random_state=42)
    return cross_val_score(model, X_train, y_train, cv=3, scoring="f1").mean()

study = optuna.create_study(direction="maximize")
study.optimize(objective, n_trials=50)
print(study.best_params, study.best_value)
```

**搜索心智**：**"搜索策略选型：网格（参数 <5 个）、随机（参数多、没经验）、贝叶斯（预算充足、要最优）"**——**"Optuna 是 2026 年调参的事实标准"**（比网格/随机省 10-100 倍尝试）；**搜索的预算观**——"调参不是无限跑，是'每 100 次尝试边际收益递减'——记录调参日志（参数/分数/耗时——01 篇的复现纪律），**边际收益 <1% 就收手**"——**"调参的终点不是最优，是'够用且记录清楚'"**；**先粗后细**（粗搜索定范围 → 细搜索定精度）——"一上来细网格等于大海捞针"。

## 4. 调参方法论

**调参不是碰运气——是有序的探索**：

```text
调参方法论（以 LightGBM 为例）
├── 第 0 步：确认问题（是欠拟合还是过拟合？先看训练 vs 测试分数差距）
├── 第 1 步：粗调结构参数（树数量/深度/叶子——决定模型容量）
├── 第 2 步：细调学习参数（学习率/正则化——决定收敛质量）
├── 第 3 步：调完复验（完整 CV + 测试集最终确认）
└── 纪律：一次只变一个方向（结构 OR 学习——不要同时乱动）
    ——"欠拟合（训练分低）：加容量；过拟合（训练高测试低）：加正则/减容量"
```

**方法论心智**：**"调参的本质是控制'容量'与'正则'的平衡"**——**"欠拟合加容量、过拟合加正则——一句话的调参哲学"**；**先诊断再动手**——"训练 0.6 测试 0.6（欠拟合——模型太弱）vs 训练 0.99 测试 0.7（过拟合——模型太强）——两个问题的调参方向完全相反"（**"不诊断就调参 = 不看体温就开药"**）；**重要参数优先**（LightGBM：`n_estimators/learning_rate/max_depth/num_leaves` 是四大天王——调参从它们开始）；**调参的复现**——固定 random_state + 记录每次尝试（MLflow——09 篇）——"调了 50 次不知道哪次最好 = 白调"。
