## 1. 商品分析的定位

**商品分析回答四个问题：卖什么（结构）、谁贡献大（ABC）、货够不够（库存）、价格对不对（定价）**：

```text
商品分析四大问题
├── 结构：品类/价格带/生命周期（新品-爆品-滞销）
├── ABC：少数商品贡献多数销售（二八法则的库存版）
├── 库存：周转快不快、缺货/积压（资金占用）
└── 定价：价格带分布、毛利、促销效率
    ——"用户分析管'人'，商品分析管'货'——人货匹配是生意的本质"
```

**定位心智**：**"商品分析的终点是'商品决策'——进货、淘汰、定价、促销"**——"分析说某品类动销差"的下一步是"减少采购/降价清仓"——**"商品分析是供应链的'眼睛'"**；本课与阶段 4 03 篇的帕累托衔接（那里是"TOP 商品贡献度"的销售视角，本课是"ABC 分层管理"的库存视角）——**"同一方法，销售视角看贡献，供应链视角看管理"**。

## 2. ABC 分析

**ABC 分析 = 帕累托在库存管理中的应用——按累计贡献分三层**：

```python
import pandas as pd

# 商品贡献度排序 + 累计占比
sku = df.groupby("sku")["amount"].sum().sort_values(ascending=False)
sku_cum = sku.cumsum() / sku.sum()

# ABC 分层（经典规则）
def abc_class(cum_share):
    if cum_share <= 0.7: return "A"      # TOP 70% 销售额（通常只占 10-20% 的 SKU）
    if cum_share <= 0.9: return "B"      # 其次 20%
    return "C"                            # 尾部 10%

sku_class = sku_cum.apply(abc_class)
print(sku_class.value_counts(normalize=True))     # A 类 SKU 占比通常很小
```

**ABC 心智**：**"ABC 分层的管理意义：分层管理、资源分级"**——**A 类（核心）**：重点管控（安全库存高、不断货、质量严控）；**B 类（一般）**：常规管理；**C 类（长尾）**：最小库存或"以销定采"——**"给 A 类商品断货是事故，给 C 类商品压库存是浪费"**；**ABC 按销售额还是毛利分**（高销低毛利 vs 低销高毛利——**"按贡献目标选口径"**——毛利优先是 2026 商品管理的共识）；**ABC 是动态的**（季度重排——"上季 A 类这季可能变 C 类"——商品生命周期在 ABC 里的体现）。

## 3. 商品结构分析

**商品结构 = 商品的"生态"——健康的结构应该是金字塔**：

```text
商品结构金字塔
├── 引流款（少量）：低价高频——拉流量（毛利低没关系）
├── 利润款（主力）：主力 SKU——赚利润（毛利健康）
├── 形象款（少量）：高质高价——拉品牌调性（走量少）
└── 长尾款（大量）：覆盖需求——丰富选择（库存风险高）
    ——"结构健康 = 各款职责清晰、比例合理"
```

```python
# 结构体检指标（每月跟踪）
metrics = {
    "动销率": 有销售 SKU / 总 SKU,          # 低于 60% 说明滞销严重
    "TOP10 集中度": top10_gmv / total_gmv,   # 过高（>70%）风险集中
    "新老品占比": 新品 GMV / 老品 GMV,       # 新品断档是增长隐患
    "价格带分布": 各价格带销量占比,          # 判断客群定位
}
```

**结构心智**：**"动销率是商品结构的第一体检指标"**——**"铺了 1000 个 SKU 只有 500 个在卖 = 一半库存是死的"**；**集中度是双刃剑**——TOP10 贡献 80% 说明单品策略清晰，也说明**风险集中**（爆品出事全盘皆输——"鸡蛋和篮子"）；**新品断档预警**——老品衰退、新品没接上 = 未来下滑的"定时炸弹"——**"商品结构的分析价值：提前看到 3 个月后的风险"**；**价格带分布回答"客群对不对"**（主力价格带 100-200 元 vs 目标客群购买力——"价格带错位 = 人货不匹配"）。

## 4. 库存健康度分析

**库存 = 资金占用——库存分析是"钱"的分析**：

```python
# 库存核心指标（供应链视角）
import datetime
today = pd.Timestamp("2026-08-10")

# 周转天数 = 库存金额 / 日均销售金额（越低越好）
inventory_value = 5_000_000                     # 当前库存金额
daily_sales = df["amount"].sum() / 180          # 近 180 天日均销售
turnover_days = inventory_value / daily_sales
print(f"库存周转天数: {turnover_days:.0f} 天")    # 40 天以下健康，以上警惕

# 缺货（该有货没有）与滞销（有货没人买）
out_of_stock = sku[sku["stock"] == 0]           # 有销量的 SKU 缺货 = 丢单
slow_mover   = sku[sku["stock_days"] > 90]      # 库存能卖 90 天以上 = 积压
```

**库存心智**：**"库存分析的两个极端都是病：缺货丢生意、积压吞资金"**——**"缺货损失的是当下销售，积压损失的是资金与仓储成本"**——平衡点靠周转天数监控；**"有销量的 SKU 缺货"是最该报警的**（需求存在、供给断了——"缺货率 × 该 SKU 日均销售 = 每天在丢的钱"）；**滞销 = 折扣清仓或淘汰**（"滞销 90 天还不处理，继续压资金"）；**库存与销售联动**——补货建议 = 日均销售 × 采购周期 + 安全库存（"A 类商品的安全库存是 C 类的 3 倍"——ABC 与库存的结合）；2026 供应链趋势：**库存周转与现金流**（"利润可以做出来，现金流不会说谎"——经营分析 15 模型的金句）。

## 5. 定价与促销分析

**定价分析回答"价格对不对"——促销分析回答"打折值不值"**：

```python
# 价格带分析：销量 × 价格带（找到"甜蜜点"）
df["price_band"] = pd.cut(df["price"], bins=[0, 50, 100, 200, 500, 10000])
band = df.groupby("price_band", observed=True).agg(
    sales=("amount", "sum"), orders=("order_id", "nunique"))
band["aov"] = band["sales"] / band["orders"]
print(band)                                # 主力价格带 + 各带客单价

# 促销分析：促销期 vs 日常（同环比 + 增量判断）
promo = df[df["is_promo"]]["amount"].sum()
normal_daily = df[~df["is_promo"]]["amount"].sum() / normal_days
promo_daily = promo / promo_days
lift = promo_daily / normal_daily - 1
print(f"促销日均销售提升 {lift:.0%}")        # 提升 < 折扣率 → 促销"增收不增利"
```

**定价促销心智**：**"促销的真相：折扣率 20% 只带来 15% 的增量 = 促销亏了"**——**"增量提升要跑赢折扣率，促销才划算"**（A/B 实验思维——阶段 4 08 篇的对照组想法：促销期 vs 非促销期本身就是天然对照）；**促销的类型差异**：满减（抬客单）、折扣（冲销量）、赠品（保毛利）——"促销工具的选择 = 促销目标的翻译"；**定价的锚点**——价格带分析看"甜蜜点"（销量最集中的价格带）+ 竞品对比（对标——03 篇）——"定价不是拍脑袋，是价格带 + 毛利 + 竞品的三角"；**毛利是底线**——"促销价低于毛利线的活动，数据上就要亮红灯"。
