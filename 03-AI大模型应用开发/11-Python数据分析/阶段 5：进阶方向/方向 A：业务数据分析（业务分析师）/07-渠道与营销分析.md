## 1. 营销分析的定位

**营销分析回答三个问题：钱花哪了（渠道）、带来什么（效果）、值不值（ROI）**：

```text
营销分析三问
├── 渠道：各渠道带来多少用户、成本多少（CAC——获客成本）
├── 效果：这些用户值多少钱（LTV——客户终身价值）
└── 决策：LTV/CAC 健康吗？预算往哪放？（单位经济模型）
    ——"营销分析的通用语言是'钱'——每一分投放都要算回报"
```

**定位心智**：**"营销分析是分析师离'钱'最近的工作"**——预算分配是营销分析的核心输出（"下季度 500 万预算按什么比例分渠道"——**"会算 ROI 的分析师，老板愿意听"**）；**本课与阶段 4 08 篇衔接**（A/B 测试验证营销动作——"营销分析看'花了钱有没有用'，实验验证'这个动作到底有没有用'"）；**口径先行**（"新客"按注册还是首购？"成本"含不含素材制作？——02 篇指标字典在营销场景的落地——**"营销口径的坑：两家供应商报的 ROI 没法比"**）。

## 2. 渠道归因

**归因 = 把转化功劳分给渠道**——用户可能点了 5 个渠道的广告才下单，功劳归谁？

```text
归因模型（按业务选型）
├── 末次点击归因：功劳归"最后点的渠道"（简单，偏袒转化渠道）
├── 首次点击归因：功劳归"第一次触达的渠道"（偏袒种草渠道）
├── 线性归因：功劳均分给所有触点（折中）
└── 数据驱动归因：按统计模型分（2026 大厂主流——建模分配）
    ——"归因模型没有绝对对错，'和业务口径一致'才是对的"
```

```python
# 渠道效率对比（简化版：末次点击口径）
channel = df.groupby("channel").agg(
    cost=("cost", "sum"), new_users=("user_id", "nunique"))
channel["CAC"] = channel["cost"] / channel["new_users"]      # 获客成本
channel["revenue_30d"] = ...                                  # 30 日收入
channel["ROI"] = channel["revenue_30d"] / channel["cost"]
print(channel.sort_values("ROI", ascending=False))
```

**归因心智**：**"归因模型的选型 = 业务目标的选型"**——品牌广告（种草）用首次点击才能看到价值、效果广告（转化）用末次点击——**"归因模型选错，渠道价值全算错——用错归因的渠道对比是伪结论"**；**渠道对比三件套：CAC（成本）、转化率（效率）、LTV（质量）**——"CAC 低的渠道用户质量可能也低"（贪便宜的渠道来的羊毛党）——**"单看 CAC 会误判，CAC + 留存一起看"**；**渠道健康度检查**（样本量失配的渠道版）：渠道成本突涨/转化骤降先查"是不是平台改版"——"渠道数据异常先对口径再归因"。

## 3. LTV/CAC 单位经济模型

**LTV/CAC = 营销分析的"体检报告"——单位经济模型**：

```text
核心公式
├── LTV（客户终身价值）= 客单价 × 毛利率 × 复购次数 × 客户生命周期
│   简化：LTV = 月均订单额 × 毛利率 × 平均留存月数
├── CAC（获客成本）= 总营销费用 ÷ 新增客户数
└── 健康线：LTV > 3 × CAC（可持续）；LTV < CAC（危险——每拉一个新客都在亏钱）
    ——"LTV/CAC = 3 是'可持续与可规模化'的分界线"
```

```python
# LTV/CAC 测算（2026 电商实践——留存驱动的单位经济）
CAC = 120                                   # 每新客获客成本（渠道总费用/新客数）
aov = 300                                   # 客单价
margin = 0.4                                # 毛利率
months = 8                                  # 平均留存月数（Cohort 分析得出）
LTV = aov * margin * months                 # = 300 × 0.4 × 8 = 960
print(f"LTV {LTV:.0f} / CAC {CAC:.0f} = {LTV/CAC:.1f} 倍 —— {'健康' if LTV/CAC > 3 else '亚健康'}")

# 回本周期：CAC / 月均毛利（低于 12 个月才可持续）
monthly_margin = aov * margin * (1 / months)
print(f"回本周期约 {CAC / monthly_margin:.1f} 个月")
```

**LTV/CAC 心智**：**"LTV/CAC 回答'这个生意能不能持续'"**——**"LTV/CAC = 1 意味着每拉一个新客，赚的刚好等于花的——规模越大亏得越多"**（2026 DTC 案例：健康品牌 LTV/CAC 3.4-3.8 倍、危险品牌 2.1 倍原地奔跑）；**LTV 的坑：口径与数据量**——"留存月数 8 个月"要有 Cohort 数据支撑（阶段 4 07 篇），新业务没历史数据就"待验证"——**"LTV 是估算不是精算——报告里写清假设"**；**回本周期是现金流的视角**（"利润可以做出来，现金流不会说谎"）——"CAC 120 元、月毛利 48 元——回本 2.5 个月"——**"投放的钱能不能扛到回本，是营销预算的生死线"**。

## 4. 营销活动分析

**活动分析回答"这次大促值不值"——增量 vs 透支**：

```text
活动效果三问
├── 增量：活动期间多卖了多少？（活动期 vs 活动前基线——不是活动期全部！）
├── 透支：活动把未来的购买提前了？（活动后 2 周销量是否塌陷）
└── 利润：增量 × 毛利 vs 活动成本（满减/折扣是成本！）
    ——"只看活动期 GMV 是外行——增量、透支、利润三件套才完整"
```

```python
# 增量与透支（简化版）
pre_base   = daily_sales[活动前 4 周日均]          # 基线
promo_daily = daily_sales[活动期日均]
post_daily = daily_sales[活动后 2 周日均]
increment = (promo_daily - pre_base) * 活动天数     # 增量 GMV
cannibal = (pre_base - post_daily) * 14             # 透支 GMV（活动后低于基线）
profit = increment * margin - 活动成本
print(f"增量 {increment:,.0f} / 透支 {cannibal:,.0f} / 净利 {profit:,.0f}")
```

**活动心智**：**"活动分析的第一动作：建基线"**——活动期 GMV 全部算增量是自欺（**"没有基线的活动分析是看烟花——热闹但没账"**——阶段 4 08 篇对照组的营销版）；**透支检测**（"618 透支了 7 月需求"——活动后两周低于基线就是透支信号）；**满减折扣是成本**——"GMV 1 亿的 8 折活动，成本 2000 万——利润视角才是老板视角"；**活动复盘三件套**：增量（做了多少）、透支（代价）、净利（值不值）——**"活动复盘报告是下个活动预算的依据"**。

## 5. 2026 趋势：从买流量到养留存

**2026 年电商营销的核心变化：从"付费流量驱动"转向"留存与社区驱动"**（DTC 品牌实践数据）：

```text
2026 趋势（数据为证）
├── 案例 1：Chamberlain Coffee——社区获客 + 流失预测 → CAC -29%、12 个月留存 68%
├── 案例 2：Topicals——社区密度策略（植入高意图社群）→ LTV/CAC 2.1 → 3.4-3.8 倍
└── 案例 3：Necessaire——订阅重构 + 流失分层挽留 → CAC 68→48 美元、月流失 8.2%→5.4%
    ——"留存是唯一随时间推移而变得更便宜的增长杠杆"
```

**趋势心智**：**"2026 营销分析的视角升级：单看'获客效率'不够，要看'留存架构'"**——核心新指标：**流失预测评分**（提前识别将流失用户——Necessaire 案例：高风险客户个性化挽留率 14%→41%）、**推荐 K 因子**（被推荐客户 LTV 是付费获客的 1.4 倍）、**社区活跃度**（Discord/社群互动 → 留存）；**分析师的新技能**：把"预测流失"和"分层挽留"做成数据产品（阶段 4 09 篇 ML 的营销落地）——**"2026 的营销分析师 = 单位经济分析师 + 留存工程师"**；**LTV/CAC 的分层视角**——"不是所有渠道都要 LTV/CAC > 3——品牌种草渠道看 LTV 的长期贡献（品牌资产），效果渠道看即时 ROI"——**"指标的适用边界和指标本身一样重要"**。

## 7. 本节验收

**验收动作**：① 选一种归因口径做渠道对比（CAC/转化/LTV 三件套）；② 用 Cohort 数据算 LTV/CAC 并判定健康度；③ 复盘一次模拟大促（增量/透支/净利三件套）；④ 给"流失风险用户"设计分层挽留策略——**"归因 + 单位经济 + 活动复盘 = 营销分析能力"**——**练习纪律**：所有营销结论带"钱"单位——"营销分析不说钱的结论，等于没说"。

> 🎯 **核心要点**：营销分析 = 钱的账本——渠道归因（模型选型 = 业务目标 + CAC/转化/LTV 三件套对比）；**LTV/CAC 单位经济（3 倍健康线 + 回本周期 + LTV 是估算写清假设）**；活动分析三件套（**增量 vs 透支 vs 净利——没有基线的活动分析是看烟花**）；**2026 趋势：从买流量到养留存（流失预测 + 分层挽留 + 社区获客——留存是最便宜的增长杠杆）**——"营销分析的通用语言是钱"。
