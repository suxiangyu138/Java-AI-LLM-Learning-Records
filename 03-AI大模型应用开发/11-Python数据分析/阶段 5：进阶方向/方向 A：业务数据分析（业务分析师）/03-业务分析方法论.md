## 1. 方法地图：一题一法

**业务分析问题就四类，每类配方法**（2026 经营分析 15 个模型精选核心五个）：

```text
业务问题 → 方法
├── "好不好"（现状）→ 对比分析：同比/环比/对标（和谁比）
├── "为什么"（归因）→ 拆解分析：量价拆解/连环替代/漏斗
├── "结构怎样"（构成）→ 结构分析：占比/帕累托/波士顿矩阵
├── "趋势如何"（走向）→ 趋势分析：移动平均/同环比序列
└── "健康不健康"（体检）→ 杜邦分析：利润率×周转×杠杆
    ——"先定问题类型，再选方法——方法不对，再努力也是白算"
```

**方法心智**：**"方法不是越多越好，是'匹配问题'才有效"**——"为什么降"用拆解、"哪个环节差"用漏斗（阶段 4 04 篇）、"该重点做谁"用帕累托——**"分析师的方法论 = 一题一法的匹配能力"**；**方法之间要组合**（2026 经营分析主流路径）：**先用对比定位差距 → 再用拆解追溯原因 → 最后用 LTV/CAC 等单位经济模型量化健康度**——"单一方法给线索，组合方法给结论"。

## 2. 对比分析

**"好不好"的问题永远要"和谁比"**——三个对比对象：

```python
# 三种对比（阶段 4 03 篇"对比不要孤值"的体系化）
同比：今年 7 月 vs 去年 7 月（消除季节性）      # GMV 同比 +12%
环比：7 月 vs 6 月（看近期变化）               # GMV 环比 -8%
对标：我们 vs 行业/竞品（看相对位置）          # 增速 12% vs 行业 20%——我们在丢份额

# 对比的铁律：口径可比
# 去年 7 月不含运费、今年含 → 同比全是错 → 先对齐口径（02 篇指标字典）
```

**对比心智**：**"同比看趋势、环比看变化、对标看位置——三个对比回答三个问题"**；**可比性是第一铁律**——口径（含不含运费）、范围（渠道变了）、周期（去年 7 月有大促）——**"对比错在对口径，是最冤的分析事故"**；**增速对比的陷阱**："公司增长 20%"听起来很好——行业平均 50%？——**"增长 20% 在行业 50% 面前是衰退——对标才能定位真实处境"**；对比的深化：**波士顿矩阵**（份额×增速四象限——明星/金牛/问号/瘦狗——选品与资源分配的结构方法）。

## 3. 量价拆解与连环替代

**"为什么降/为什么涨"的标准答案：量价拆解**——**收入 = 量 × 价**，再加深一层**结构**：

```python
# 量价结构拆解（连环替代法思路：依次固定其他因素，看每个因素的单独影响）
# 收入 = 销量（量）× 单价（价）× 高毛利产品占比（结构）

import pandas as pd
# 上月 vs 本月
prev = {"销量": 100_000, "单价": 80, "高毛利占比": 0.4}
curr = {"销量": 90_000,  "单价": 82, "高毛利占比": 0.45}

# 连环替代（简化版：每个因素单独变化带来的收入变化）
rev = lambda d: d["销量"] * d["单价"] * d["高毛利占比"]
delta_total = rev(curr) - rev(prev)                    # 总变化
delta_qty   = rev({**curr, "销量": prev["销量"]}) - rev(prev)   # 销量影响
delta_price = rev({**curr, "单价": prev["单价"]}) - rev({**curr, "销量": prev["销量"]})
print(f"总变化 {delta_total:,.0f} = 销量影响 {delta_qty:,.0f} + 价影响 {delta_price:,.0f} + 结构影响 ...")
```

**拆解心智**：**"拆解回答'谁干的'——每个因素单独背多少责任"**——"收入降 100 万：销量降背 80 万、单价涨补回 10 万、结构变好补回 30 万"——**"归因到因素，才归因到部门"**（销量找运营、单价找商品、结构找品类）；**连环替代的顺序有讲究**（按重要性/因果顺序替换——顺序不同结果略不同，报告里写清替代顺序）；**"虚胖 vs 强壮"的判断**：量增价跌（虚胖——促销冲量）vs 价稳量增（强壮——真实需求）——**"量价联动是增长质量的试金石"**。

## 4. 杜邦分析

**杜邦分析 = 财务分析黄金法则——把一个 ROE 拆成三个可控因子**：

```text
杜邦公式
ROE（净资产收益率）= 净利润率 × 总资产周转率 × 权益乘数（杠杆）
        赚不赚钱（盈利）    转得快不快（效率）    借得多不多（风险）
```

**杜邦心智**：**"同一 ROE，不同来路，不同健康度"**——两家公司都 ROE 15%：A 靠高净利率（品牌溢价——健康），B 靠高杠杆（高负债——经济下行时亏损放大）——**"杜邦的价值：拆开看 ROE 是'赚出来的'还是'借出来的'"**；两种经营思路识别：**薄利多销型**（低净利率×高周转——沃尔玛）vs **厚利慢销型**（高净利率×低周转——奢侈品）——**"模式没有好坏，匹配行业才健康"**；**电商小杜邦（本方向必会）**：把 ROE 思路搬到业务——**GMV = UV × 转化率 × 客单价 × 连带率**，再按渠道/新老客拆——**"小杜邦让'GMV 波动'变成'环节定位'——每个环节对应责任部门"**（站外流量差找推广、站内转化差找运营、客单低找商品——02 篇 KPI 树的财务版）。

## 5. 趋势分析与结构分析

**趋势分析——"往哪走"**：同环比序列、移动平均（平滑噪声）、线性回归（定斜率）——**"趋势分析三看：方向、斜率（加速还是减速）、拐点（什么时候变向）"**——拐点分析要结合事件（大促/改版/政策——"趋势拐点 = 事件簿的对照表"）。

**结构分析——"谁占大头"**：占比拆解 + **帕累托（二八法则）**：

```python
# 帕累托：TOP 20% 商品贡献多少 GMV？（阶段 4 03 篇的正式版）
gmv_by_product = df.groupby("product")["amount"].sum().sort_values(ascending=False)
cum_share = gmv_by_product.cumsum() / gmv_by_product.sum()
top20_count = int(len(gmv_by_product) * 0.2)
print(f"TOP20% 商品（{top20_count} 个）贡献 {cum_share.iloc[top20_count-1]:.0%} 的 GMV")
# 接近 80%？→ 二八法则成立 → 库存/资源向头部集中
```

**结构心智**：**"帕累托回答'资源往哪放'"**——头部商品决定库存策略（保供）与尾部清仓策略——**"结构分析是资源配置的依据"**；**结构与趋势结合**："品类占比没变但总量涨了"（均衡增长）vs"占比变了"（结构迁移——发现新增长点）——**"结构 + 趋势 = 增长归因的双轮"**；波士顿矩阵是结构分析的高阶（份额×增速四象限）——**"结构分析的终点是'下一步资源怎么分配'"**。

## 6. 方法选型决策表

**方法选型速查（写报告前先查）**：

| 业务问题 | 方法 | 输出 | 对应篇 |
|---------|------|------|:---:|
| 现状好不好 | 同比/环比/对标 | 差距定位 | 本课 2 节 |
| 为什么降/涨 | 量价拆解/连环替代 | 因素归因 | 本课 3 节 |
| 哪里在漏 | 漏斗/路径分析 | 环节诊断 | 阶段 4 04 篇 |
| 谁是大头 | 帕累托/占比 | 资源配置 | 本课 5 节 |
| 健康不健康 | 杜邦/单位经济 | 模式体检 | 本课 4 节 / 07 篇 |
| 该不该做 | 实验/假设检验 | 因果证据 | 阶段 4 08 篇 |

**选型心智**：**"方法选型 = 问题翻译"**——"老板问'生意好不好'"→ 对比；"为什么降"→ 拆解；"哪个环节最差"→ 漏斗；"该重点做哪个品"→ 帕累托——**"把业务问题翻译成方法问题，是分析师的核心技能"**；**方法输出要落到"下一步动作"**——对比找差距 → 拆解找原因 → 建议找动作——"方法论不是终点，决策是终点"（01 篇决策导向）。

## 8. 本节验收

**验收动作**：① 用对比分析回答一个"现状"问题（三个对比对象各做一次）；② 用量价拆解归因一次"收入变化"（写出三因素各自影响）；③ 用电商小杜邦拆 GMV 并定位责任环节；④ 做一次帕累托分析——**"对比 + 拆解 + 杜邦 + 结构 = 方法论四件套"**——**练习纪律**：每个分析先写"问题类型 → 方法 → 输出"再动手——"先选方法再写代码，方法选错等于白跑"。

> 🎯 **核心要点**：方法论 = 一题一法匹配——对比（同比/环比/对标——口径可比第一铁律）→ 量价拆解（归因到因素再到部门——虚胖 vs 强壮试金石）→ 杜邦（ROE 三因子 + 电商小杜邦 GMV 环节定位）→ 趋势结构（帕累托资源配置）；组合路径（**对比定位差距 → 拆解追溯原因 → 单位经济量化健康度**）——"单一方法给线索，组合方法给结论"。
