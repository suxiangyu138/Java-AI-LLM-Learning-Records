## 1. 用户分析的定位

**用户分析回答三连问：用户是谁（画像）、走到哪了（生命周期）、怎么对待（分层）**——它是运营动作的"导航"：

```text
用户分析的三大价值
├── 画像：知道用户是谁——产品/运营做决策的依据（"我们的用户是 25-35 都市女性"）
├── 生命周期：知道用户处在哪一阶段——不同阶段不同策略（新客拉活/老客促复购/流失客召回）
└── 分层：知道谁值得投入——资源向高价值用户倾斜（RFM 分层——阶段 4 07 篇）
    ——"画像定方向，生命周期定节奏，分层定资源"
```

**定位心智**：**"用户分析的终点是'运营动作'，不是'用户报告'"**——"画像说 60% 用户是女性"的下一步是"商品和视觉往女性倾斜"——**"没有动作的用户分析是自嗨"**；本课深化阶段 4 已学的方法（RFM/Cohort——`../阶段%204：实战项目（由简单到复杂）/07-项目六：经营分析%20Dashboard.md`），把"会算"变成"会用"——"阶段 4 教你算 RFM，本课教你 RFM 之后运营怎么办"。

## 2. 用户画像

**画像三件套：属性（谁）、行为（干什么）、价值（值多少）**：

```python
import pandas as pd

# 属性画像：人群结构（性别/年龄/城市/职业——注册与订单数据）
users = pd.read_csv("data/users.csv")
print(users.groupby("age_band")["user_id"].nunique(normalize=True))   # 年龄段占比
print(users.groupby("city_tier")["user_id"].nunique(normalize=True))  # 城市层级

# 行为画像：RFM 基础 + 品类偏好（阶段 4 07 篇 RFM 的"行为"补全）
# 价值画像：LTV 分层（07 篇展开）——高价值/中价值/低价值
```

**画像心智**：**"画像三件套的优先级：价值画像 > 行为画像 > 属性画像"**——"知道用户值多少钱"（价值）比"知道用户住哪"（属性）更能指导运营——**"属性画像用于'理解'，行为画像用于'运营'，价值画像用于'投入'"**；**画像的颗粒度**：面向大众的产品画像粗（年龄层），垂直产品画像细（"备孕妈妈"）——**"画像颗粒度跟着产品场景走"**；**画像的更新**：用户会变（学生变上班族）——**"画像不是一次性的，是持续更新的"**（季度刷新）；2026 趋势：画像与推荐/搜索结合（CTR/CVR 分析——画像成为算法特征源）。

## 3. 用户生命周期

**生命周期 = 用户与产品关系的"旅程"**——五阶段模型：

```text
用户生命周期
引入（新注册）→ 成长（首次付费/活跃）→ 成熟（高频高价值）
→ 衰退（频次下降）→ 流失（不再回来）
    ——"每个阶段的用户策略不同：引入期要激活、成熟期要防流失、流失期要召回"
```

```python
# 生命周期阶段判定（简化版：按最近购买与频次）
def lifecycle_stage(row):
    if row["is_new"]: return "引入期"                      # 注册 30 天内
    if row["recent_days"] > 90: return "流失期"            # 90 天没买
    if row["recent_days"] > 45: return "衰退期"            # 45 天没买
    if row["freq"] >= 3: return "成熟期"                   # 高频
    return "成长期"

users["stage"] = users.apply(lifecycle_stage, axis=1)
print(users["stage"].value_counts(normalize=True))         # 各阶段占比
```

**生命周期心智**：**"生命周期分析的产出 = 阶段结构 + 迁移规律"**——"新客 100 人中 30 人 30 天内流失"（迁移规律——新客留存差）→ 策略：新客首单礼包——**"看结构知道现状，看迁移知道问题"**；**阶段定义要有业务共识**（"多久没买算流失"是口径问题——和运营对齐——02 篇指标字典）；**生命周期 × 价值的矩阵**（高价值成熟期 = 核心用户要重点维护；低价值衰退期 = 不投入）——"生命周期定策略对象，价值定投入力度"。

## 4. AARRR 增长分析

**AARRR = 增长分析的五个环节（海盗指标）**——2026 年增长分析师的核心框架：

```text
AARRR 增长漏斗（阶段 4 04 篇漏斗的"全链路版"）
├── Acquisition 拉新：新增用户（渠道投放——07 篇归因）
├── Activation 激活：完成核心动作（首购/注册完成）——"下载不等于激活"
├── Retention 留存：持续回来（次日/次月留存——Cohort 分析）
├── Revenue 变现：付费转化（ARPU/LTV——07 篇）
└── Referral 传播：分享推荐（K 因子——推荐带来多少新客）
    ——"五个环节串起来 = 增长全链路——每环都能定位瓶颈"
```

```python
# AARRR 各环节指标（简化版）
metrics = {
    "拉新":    new_users,                    # 新增注册
    "激活":    activated / new_users,        # 首购转化率
    "留存":    retention_30d,                # 30 日留存
    "变现":    revenue / active_users,       # 人均收入 ARPU
    "传播":    referrals / new_users,        # K 因子（每用户带来几个新客）
}
```

**AARRR 心智**：**"AARRR 的价值：把'增长'从口号变成可定位的环节"**——"增长不好"是五个环节哪里不好？——**"逐环看数据，瓶颈自然浮现"**（2026 增长分析范式：目标拆解 → 转化分析 → A/B 实验全流程评估 → ROI/LTV 测算）；**环节之间是漏斗关系**（拉新 10000 → 激活 3000 → 留存 800 → 变现 200——**"上一环的漏，下一环补不回来"**——拉新质量差，后面全白费）；**各环节的重点指标**：拉新看 CAC（成本）、激活看首购率、留存看次月留存、变现看 LTV、传播看 K 因子——**"每环一个核心指标，环环有数"**。

## 5. 用户分层运营

**分层 = 把用户分组、分组施策**——RFM（阶段 4 07 篇）是最经典的价值分层，本课把它变成运营策略：

```python
# RFM 分层 → 运营策略映射（分层不是终点，策略才是）
SEGMENT_STRATEGY = {
    "高价值（高频高额近期）":   "专属客服 + 会员权益 + 新品内测",
    "流失风险（高频高额但近期没买）": "定向召回券 + 大促提醒",     # 最值得救的群体
    "潜力（高频低额）":       "客单价提升（满减/加购推荐）",
    "新客（首购）":          "复购引导（7 天二次购买券）",
    "低价值（低频低额）":      "不做投入，靠活动自然转化",
}
```

**分层心智**：**"分层的核心不是'怎么分'，是'分了之后怎么办'"**——**每个分层配一套策略 = 分层闭环**（阶段 4 07 篇只教到"分"，本课补上"策"）；**"流失风险"层是运营的金矿**——高价值用户即将流失，召回 ROI 最高（召回一个成熟用户的成本远低于获取一个新客——07 篇 LTV 视角）；**分层要动态**（用户会迁移——低价值→高价值是被运营动作激活的）——**"分层报表 + 分层策略 + 效果追踪 = 分层运营闭环"**（策略上线后看层间迁移率——阶段 4 08 篇的实验思维）。

## 7. 本节验收

**验收动作**：① 给模拟用户数据做画像三件套（属性/行为/价值各一个分析）；② 判定生命周期阶段结构 + 找一条迁移规律；③ 算 AARRR 五环节指标并定位瓶颈环节；④ 做 RFM 分层 + 每层配运营策略——**"画像 + 生命周期 + AARRR + 分层 = 用户分析能力"**——**练习纪律**：每个分层必须配"策略 + 预期效果"——"只分不策 = 只诊断不开药"。

> 🎯 **核心要点**：用户分析四大武器——画像（三件套：属性/行为/价值——价值优先）；生命周期（五阶段 + 迁移规律——阶段定义与业务对齐）；**AARRR（五环节全链路定位瓶颈——拉新看 CAC/激活看首购/留存看次月/变现看 LTV/传播看 K 因子）**；**分层运营闭环（RFM 分层 + 每层策略 + 效果追踪——流失风险层是金矿）**——"画像定方向，生命周期定节奏，分层定资源——终点是运营动作"。
