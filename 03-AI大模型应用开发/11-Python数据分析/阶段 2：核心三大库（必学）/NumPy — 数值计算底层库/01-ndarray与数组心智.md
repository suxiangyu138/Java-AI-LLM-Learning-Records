## 1. NumPy 定位与版本

**NumPy = Python 数值计算的底层引擎**——几乎所有数值库（Pandas/Matplotlib/科学计算）的地基——**"Pandas 的每一列、Matplotlib 的每个数组，底层都是 ndarray"**——学会 NumPy = 理解 Python 数据科学的底层。2026-08 基线：**NumPy 2.5.1**（2.5.0 起支持 Python 3.12-3.14——`numpy.sort` 新增 `descending=True`、distutils 彻底移除——老教程里的 distutils 代码已失效）。

**NumPy 的快来自两层**：**C 语言实现**（数组运算编译成机器码——不经过 Python 解释器）与 **BLAS 优化**（矩阵运算用 OpenBLAS 等——`../../阶段 1：前置基础/01-Python环境与数据分析工具箱.md` 的底层说明）——**"快不是魔法，是 C + BLAS"**。

## 2. ndarray：N 维数组

**ndarray（N-dimensional array）= 同质的多维数组**——两个关键词：

- **同质**：所有元素**同一类型**（dtype——04 篇）——这是快的根源（内存连续、定长）
- **多维**：一维（向量）/二维（矩阵）/三维+（张量）——**"Pandas 的表是二维的，NumPy 的数组可以是 N 维"**

```python
import numpy as np

a1 = np.array([1, 2, 3, 4])        # 一维数组（向量）
a2 = np.array([[1, 2], [3, 4]])    # 二维数组（矩阵——行×列）
```

**心智**：**数组不是列表的"加强版"，是"整组数据"的容器**——列表是"多个独立的东西"（每个可以是不同类型）、数组是"一个整体"（同类型、一起算）——**"列表管'多'，数组管'整'"**——这是本课最重要的心智转变。

## 3. 向量化心智

**向量化 = 整组运算代替循环**（NumPy 的灵魂）：

```python
# 循环版（慢——Python 逐元素）
ages = [22, 35, 41, 28]
adult_flags = []
for a in ages:
    adult_flags.append(a >= 30)

# 向量化版（快 100 倍 + 代码短 5 倍）
ages_arr = np.array(ages)
adult_flags = ages_arr >= 30       # 整组比较——一次 C 运算
```

**向量化心智**：**"对数组的每个元素做什么，就对整个数组做什么"**——`arr * 2`（整组乘 2）、`arr >= 30`（整组比较）、`arr.sum()`（整组求和）——**"循环是逐个问、向量化是整组问"**——速度差距：Python 循环约百万次/秒、向量化约亿次/秒（100 倍级）——**"能向量化就不循环"是 NumPy 第一纪律**（08 篇的性能对比实测）。

## 4. 数组 vs 列表

| 维度 | Python 列表 | ndarray |
|------|-----------|---------|
| 元素类型 | 可混（int/str/对象） | 必须同质（dtype） |
| 内存 | 指针数组（分散） | 连续内存（紧凑） |
| 运算 | 逐个手写循环 | 整组向量化 |
| 速度 | 百万级/秒 | 亿级/秒 |
| 用途 | 通用容器 | 数值计算 |

**易错点**：**混类型会"自动降级"**——`np.array([1, "a", 3])` 全变字符串（dtype 同质化——01 篇陷阱）；**空列表不能直接 array**（`np.array([])` 类型未知——先 `np.empty` 或指定 dtype）。

## 5. 五种创建方法

```python
np.array([1, 2, 3])              # 1. 从列表转（最常用）
np.zeros((2, 3))                 # 2. 全 0（占位——形状 (2行, 3列)）
np.ones(5)                       # 3. 全 1
np.arange(0, 10, 2)              # 4. 等差序列（0,2,4,6,8——左闭右开）
np.linspace(0, 1, 5)             # 5. 等分 5 个点（0, 0.25, 0.5, 0.75, 1——含端点）
np.random.rand(100)              # 6. 随机数（0-1 均匀——阶段 3 预演）
```

**创建心智**：**`zeros/ones` 是"先占位后填"**（大数组比 append 快 1000 倍——07 篇）；**`arange` vs `linspace`**（arange 定步长、linspace 定个数——**"要几个点用 linspace，要隔几步用 arange"**）；**形状参数是元组**（`(2, 3)` = 2 行 3 列——行数在前——和 Excel 习惯一致）。

## 7. 创建场景速查与先建后算

**五种创建方法的场景选择**（什么时候用哪个）：

| 方法 | 场景 | 例子 |
|------|------|------|
| `np.array(列表)` | 已有数据转数组（最高频） | 读入的列表/元组转数组 |
| `np.zeros/np.ones` | 先占位后填（大数组） | 100 万元素的计数器 |
| `np.arange` | 定步长的等差序列 | 0-100 隔 5 取数 |
| `np.linspace` | 定个数的等分（画图 x 轴） | 0-1 均分 100 点画曲线 |
| `np.random.*` | 随机数据（实验/测试） | 造 1000 个测试数据 |

**"先建后算"纪律**（数组性能第一原则的创建版）：**大数组禁止循环 append**（每次 append 全量复制——O(n²) 噩梦）——**正确姿势**：`np.zeros(n)` 占位 → 循环里按索引填 → 或**先列表 append 再一次性转数组**（`np.array(list)`——列表的动态性 + 数组的运算力——两全其美）——**"小数组随意、大数组先建后算"**（08 篇性能纪律的预演）。

**数组思维的三个迁移**（从列表思维升级的完整清单）：**从"逐个"到"整组"**（`for x in arr` → `arr * 2`——运算的粒度变了——这是最根本的迁移）；**从"类型自由"到"同质"**（列表可以混、数组必须同——dtype 是纪律不是限制——04 篇）；**从"动态长度"到"定长形状"**（append 随意 → 形状固定——变形靠函数——07 篇）——**"数组思维 = 整组、同质、定形——三个迁移完成，NumPy 就算入门了"**——09 篇实战就是检验这三条迁移是否完成。

**常见疑问**："数组和列表都要学吗？"——**都要**：列表是通用容器（杂数据/动态）、数组是数值计算（同质/快）——**数据分析的日常：列表收集、数组计算**（`np.array(列表)` 一步切换）；"什么时候用 Pandas 不用 NumPy？"——**有列名/标签/分组需求用 Pandas**（阶段 2 Pandas 篇）、**纯数值运算用 NumPy**（本体系）——**"列表管收集、数组管计算、Pandas 管表格——各管一段，配合使用"**。

**进阶预告**：二维数组（矩阵）是阶段 3 的基础（线性代数/矩阵运算 `@`——本课没讲的 `np.dot` 留给阶段 3）——**"一维会了，二维是加一个逗号"**（`arr[行, 列]`——02 篇）——本课的向量化心智在任意维度都成立——**"数组思维一次学会、任意维度通用"**。
