## 2. 实战：泰坦尼克 numpy 版

**第一步：读入并数组化**（Pandas 读 → numpy 转）：

```python
import pandas as pd, numpy as np

df = pd.read_csv("titanic.csv")
age = df["Age"].to_numpy()          # 数组化（含 nan——先体检）
fare = df["Fare"].to_numpy()
survived = df["Survived"].to_numpy()
sex = df["Sex"].to_numpy()

np.isnan(age).sum()                 # 缺失体检：177 个 nan（阶段 1 已知）
```

**第二步：筛选与统计**（掩码 + 聚合——05/06 篇）：

```python
# 幸存者年龄统计（掩码筛选——注意 nan 传染）
alive = survived == 1
age_alive = age[alive]
print(f"幸存者平均年龄: {np.nanmean(age_alive):.1f}")       # nanmean 忽略缺失
print(f"幸存者年龄中位数: {np.nanmedian(age_alive):.1f}")
print(f"幸存者年龄标准差: {np.nanstd(age_alive):.1f}")

# 对比：未幸存者（结论要对比才有意义）
age_dead = age[~alive]
print(f"未幸存者平均年龄: {np.nanmean(age_dead):.1f}")

# 票价分析（无缺失——直接统计）
print(f"票价均值 {fare.mean():.1f} / 中位数 {np.median(fare):.1f} / 75 分位 {np.percentile(fare, 75):.1f}")
# 均值 vs 中位数差距大 = 右偏（阶段 1 describe 解读的数组版）
```

**第三步：分组统计**（掩码组合——`&` 逻辑）：

```python
# 性别 × 幸存率（unique 计数——06 篇）
sex_alive_rate = {}
for s in np.unique(sex):
    mask = (sex == s) & (survived == 1)
    total = (sex == s).sum()
    sex_alive_rate[s] = mask.sum() / total
print(sex_alive_rate)               # {'female': 0.74, 'male': 0.19}（阶段 1 结论复现）

# 年龄分层幸存率（np.where 打标签——05 篇）
age_group = np.where(age < 18, "少年", np.where(age < 40, "中年", "老年"))
for g in np.unique(age_group):
    mask = (age_group == g) & (survived == 1)
    rate = mask.sum() / (age_group == g).sum()
    print(f"{g}幸存率: {rate:.2f}")
```

**第四步：结论**（数字 + 解释——阶段 1 的三段式）：

> 结论：女性幸存率 74% vs 男性 19%（差 4 倍——与阶段 1 Pandas 版完全一致）；票价右偏（均值 32 vs 中位数 14——均值被头等舱拉高）；年龄对幸存率影响小于性别——**"NumPy 与 Pandas 算同一份数据、得到同一结论——工具不同、证据一致"**。

**第五步：性能对比**（08 篇——本次实战的彩蛋）：

```python
%time df["Age"].apply(lambda a: np.nan if pd.isna(a) else a * 2)   # apply 版
%time age * 2                                                       # 向量化版（忽略 nan 语义差异）
```

## 4. 常见报错速查

| 报错/现象 | 原因 | 解法 |
|----------|------|------|
| `ValueError: operands could not be broadcast` | 形状不匹配 | 打印 shape → 对齐 → reshape 补 1（03 篇） |
| `truth value of an array is ambiguous` | 用 and/or 连接数组 | 改 `&`/`|` + 括号（05 篇） |
| `'numpy.ndarray' object has no attribute 'append'` | 数组没有 append 方法 | `np.append(arr, x)`（07 篇） |
| `'numpy.ndarray' object has no attribute 'median'` | median 是 np. 函数 | `np.median(arr)`（06 篇） |
| 改了切片原数组也变 | 视图共享内存 | `.copy()`（02 篇） |
| 统计结果全 nan | nan 传染 | `np.nanmean/nansum` 或先筛 nan（06 篇） |
| `float 不能转 int 报错` | astype 遇到脏值 | 先清洗/`np.where` 替换（04/05 篇） |
| `MemoryError` | 数组太大 | 降 dtype/分块（04/08 篇） |
| 随机数每次不同 | 没设 seed | `np.random.seed(42)`（08 篇） |

## 6. 面试问答 3 题

**Q1：NumPy 和 Pandas 什么关系？**——答："Pandas 建立在 NumPy 之上——每列底层是 ndarray——Pandas 管表（标签/分组）、NumPy 管数组（向量化运算）——日常协作是'Pandas 清洗、NumPy 算、回表'"（08 篇）。

**Q2：切片为什么改了原数组？**——答："切片返回视图——共享底层内存——省内存是设计意图——要独立数据用 `.copy()`"（02 篇——答出"设计意图"是加分项）。

**Q3：怎么给 100 万元素数组筛选 + 统计？**——答："掩码筛选（`arr[arr > 30]`）+ 向量化统计（mean/std）——不写循环——`%time` 测量验证"（05/06/08 篇——答出"测量"显示工程素养）。

**面试纪律**：**NumPy 面试题考"机制"**（视图/广播/axis）——答机制时先讲"为什么"再讲"怎么用"——**"视图是为了省内存、广播是为了免循环——机制即设计意图"**——**"同一份数据、三种工具、一个结论——这是阶段 2 毕业的样子"**（Pandas 看表、NumPy 算数、Matplotlib 画图——三库互证 = 结论可信）。
