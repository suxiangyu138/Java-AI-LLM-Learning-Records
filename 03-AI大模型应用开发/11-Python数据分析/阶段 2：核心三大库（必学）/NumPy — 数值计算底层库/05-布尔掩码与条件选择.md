## 1. 比较运算与布尔数组

**比较运算（`>` `<` `>=` `<=` `==` `!=`）逐元素返回布尔数组**——这是 NumPy 筛选的起点：

```python
ages = np.array([22, 35, 41, 18, 28])

ages >= 30        # [False  True  True False False] 布尔数组
ages == 35        # [False  True False False False]
ages != 22        # [False  True  True  True  True]
```

**心智**：**"比较 = 画地图"**——`ages >= 30` 得到的不是"哪些值满足"（那是筛选——第 2 节），而是**"每个位置是否满足"的 True/False 地图**——**"先画地图、再按地图取数"**——这是掩码的两步。

## 2. 掩码筛选

**掩码 = 用布尔数组当"取数索引"**：

```python
ages = np.array([22, 35, 41, 18, 28])
mask = ages >= 30          # [False  True  True False False]

ages[mask]                 # [35 41] —— 只取 True 的位置（副本！）
ages[ages >= 30]           # 一步写法（掩码不落变量——高频）
ages[(ages >= 20) & (ages <= 30)]   # 区间筛选（& 组合——第 3 节）

# 二维掩码：按行条件取行
m = np.array([[1, 2], [3, 4], [5, 6]])
m[m[:, 0] > 2]             # [[3 4] [5 6]] —— 取"第一列 >2"的行
```

**掩码心智**：**`arr[mask]` 返回副本**（改了不影响原数组——和切片视图相反——02 篇对照）；**筛选 = 掩码 + 索引**（`arr[条件]` 一步）；**二维"按行条件选行"是最常用模式**（`m[m[:, 列号] 条件]`——Pandas 的 `df[df.col > x]` 就是它的表版——`../../阶段 1：前置基础/03-Python速成（数据分析子集）.md` 的布尔筛选预演在这里落地）。

## 3. 逻辑组合

**数组的 `and/or` 没有——用位运算符号**（NumPy 第一易错点）：

```python
ages = np.array([22, 35, 41, 18, 28])

(ages >= 20) & (ages <= 30)     # 且（与）—— 两边都要括号！
(ages < 20) | (ages > 40)       # 或 —— 括号必加
~(ages == 22)                   # 非（取反）—— ~ 是波浪号
```

**易错点（高频报错）**：

```python
ages >= 20 and ages <= 30       # ValueError！数组不能用 and/or
# 正确：&（与）|（或）~（非）——而且每个条件必须加括号（运算符优先级）
```

**逻辑心智**：**`& | ~` 是逐元素的位运算（当逻辑用）**；**`and/or` 是 Python 逻辑（只接受单个布尔）——数组是多个布尔 → 报错"truth value ambiguous"**；**括号是铁律**（`(a > 1) & (b < 2)`——不括会因优先级出错）；**判断"任何/所有"**：`arr.any()`（任一 True）、`arr.all()`（全部 True）——mask 的汇总（阶段 1 的 any/all 数组版）。

## 4. np.where 三态选择

**`np.where(条件, 真值, 假值)` = 数组版三元表达式**（按条件逐元素选值）：

```python
ages = np.array([22, 35, 41, 18, 28])

labels = np.where(ages >= 30, "成年", "未成年")
# ['未成年' '成年' '成年' '未成年' '未成年']

# 只给条件（返回满足的索引——第二常用）
idx = np.where(ages >= 30)       # (array([1, 2]),) —— 索引元组
ages[idx]                        # [35 41]

# 数据修复场景（阶段 1 清洗的数组版）
prices = np.array([29.9, 0, 45.0, 0])          # 0 = 缺失
prices = np.where(prices == 0, np.nan, prices) # 0 → nan
```

**where 心智**：**三态选择 = "每格问一遍'条件成立吗'，成立取真值、不成立取假值"**——**常用于清洗**（异常值替换/缺失标记——`../../阶段 1：前置基础/06-数据类型与缺失值.md` 的三处理在数组里的实现）；**`np.where(条件)` 单参数版返回索引**（等价于"满足条件的位置在哪"——排序/查找预演）。

## 5. 花式索引

**花式索引 = 用索引数组取数**（和掩码互补——掩码用条件、花式用位置）：

```python
arr = np.arange(10)

arr[[0, 2, 5]]          # [0 2 5] —— 指定位置（返回副本！）
arr[[-1, -2]]           # [9 8] —— 负索引也支持
idx = np.array([3, 1, 3])   # 索引可重复
arr[idx]                # [3 1 3]

# 二维：行 + 列组合
m = np.arange(12).reshape(3, 4)
m[[0, 2], [1, 3]]       # [1 11] —— (0,1) 和 (2,3) 两个位置（成对取）
```

**花式索引心智**：**花式索引返回副本**（和掩码一致、和切片相反——02 篇三对照：切片视图/花式副本/掩码副本）；**索引数组可重复**（`[[3,1,3]]` 合法——抽样/重排预演）；**二维成对取**（`m[[行列表], [列列表]]` 是成对位置不是笛卡尔积——易错点）。

## 7. 三种选择方式对照

**掩码/where/花式索引——三种"选数据"的完整对照**（本课收口）：

| 方式 | 语法 | 选什么 | 返回 |
|------|------|--------|------|
| 掩码筛选 | `arr[条件]` | 满足条件的值 | 副本（一维结果） |
| np.where 三态 | `np.where(条件, 真, 假)` | 逐元素替换/打标签 | 同形状数组 |
| 花式索引 | `arr[[位置们]]` | 指定位置的值 | 副本（任意顺序） |

**选型心智**（什么时候用哪个）：

- **只要满足条件的值** → 掩码（`arr[arr > 30]`——最常用）
- **要保留原形状做替换/标记** → where（清洗：0→nan、打年龄段标签——`np.where` 是三态之王）
- **要按指定位置/顺序取** → 花式索引（抽样/重排：`arr[np.random.choice(idx, 5)]`）
- **要"位置"不是"值"** → `np.where(条件)` 或 `np.argwhere(条件)`（找索引）

**组合场景**（分析的日常）：**掩码筛行 + where 打标 + 花式抽样**——三件套组合覆盖 90% 的"选数据"需求——**"掩码选行、where 换值、花式抽位置"**——09 篇实战就是三件套的完整演练。

**掩码与 Pandas 的对应**（数组的知识在表里的复用——`../../阶段 1：前置基础/04-数据容器与表格思维.md` 的整列思考）：**`arr[arr > 30]` ↔ `df[df["age"] > 30]`**（完全同构——Pandas 的筛选本质就是掩码）；**`np.where(cond, a, b)` ↔ `df["col"].where/mask` 或 `np.select`**（同思路——条件替换）；**`(a > 1) & (b < 2)` ↔ Pandas 同样用 `&`**（括号纪律一致）——**"学 NumPy 的掩码 = 学 Pandas 筛选的一半"**——09 篇实战用数组重做阶段 1 的分析时，每一步都对应回 Pandas 版本——**"两种工具、同一套思维——互相印证"**（面试答"Pandas 筛选原理"时可以说"底层是 numpy 布尔掩码"——深度加分）。

**面试题**："Pandas 筛选和 NumPy 掩码什么关系？"——答：**"Pandas 的 df[df.col > 30] 底层就是 numpy 布尔掩码——比较运算生成布尔数组、布尔数组作为索引取 True 位置——理解掩码就理解了筛选的原理"**；"数组为什么不能用 and/or？"——答：**"and/or 是 Python 逻辑运算符——要求单个布尔值——数组是多个布尔值的集合——会报 truth value ambiguous——用位运算 & | ~ 逐元素组合，且每个条件要加括号"**——"底层原理答出来 = 深度分"（表面用法 vs 底层机制——面试考的是后者）。

## 8. 本节验收

**验收动作**：① 造 20 个随机年龄（`np.random.randint(10, 60, 20)`）——用掩码筛出 30-50 岁；② `& | ~` 组合两个条件各一次；③ `np.where` 三态打标签（未成年/成年/老年三档用嵌套 where 或 where+掩码）；④ 把 0 值替换成 nan（清洗场景）——**"筛选/组合/三态全过 = 选择层通过"**——**练习纪律**：组合条件必须手写括号——**"括号是铁律——漏括号 = 优先级 bug"**——`& | ~` 每题跑一遍确认（"and 报错"的报错信息要亲眼见过一次）。

> 🎯 **核心要点**：比较 → 布尔数组（先画地图再取数）；掩码筛选（`arr[条件]` 返回副本——二维按行条件选行是高频）；逻辑组合（**数组没有 and/or——用 & | ~ 且必须加括号**——any/all 汇总）；np.where 三态（清洗场景：0→nan/异常替换）；花式索引（位置取数返回副本——成对取易错）——**"掩码 = 用条件画 True/False 地图，再按地图取数"**。
