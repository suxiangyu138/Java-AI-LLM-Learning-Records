## 1. 逐元素运算

**数组的加减乘除默认逐元素**（对每个元素做同样的运算）：

```python
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

a + b            # [5 7 9]（对应位置相加）
a * 2            # [2 4 6]（标量乘——广播的简单版）
a ** 2           # [1 4 9]（平方）
a / 2            # [0.5 1. 1.5]（除法自动变 float——04 篇）
a // 2           # [0 1 1]（整除）
```

**运算心智**：**`+ - * / **` 全部逐元素**（不是矩阵运算——**矩阵乘法是 `@` 或 `dot`**——阶段 3 预演）；**同形状数组对应位置运算**；**标量与数组运算 = 广播的最简形式**（第 3 节）。

## 2. ufunc 通用函数

**ufunc（universal function）= 逐元素的数学函数**——`np.xxx()` 直接作用于整个数组：

```python
arr = np.array([1.2, 2.7, -3.5])

np.round(arr)     # [1. 3. -4.] 四舍五入
np.abs(arr)       # [1.2 2.7 3.5] 绝对值
np.sqrt(arr)      # 开方（负数报错——返回 nan——04 篇）
np.exp(arr)       # 指数 e^x
np.log(arr)       # 自然对数（负数 → nan）
np.sin(arr)       # 三角函数（阶段 3 预演）
```

**ufunc 心智**：**"数学函数都是 ufunc"**（np.round/np.abs/np.sqrt/np.log...——**不用写循环**）；**两个数组也可以做 ufunc**（`np.maximum(a, b)` 逐元素取大——比 `np.where` 快的场景）；**nan 传播**（sqrt 负数 → nan——nan 会传染——`../../阶段 1：前置基础/06-数据类型与缺失值.md` 的 NaN 认知在数组里同样成立——`np.nanmean` 忽略 nan）。

## 3. 广播机制

**广播 = 形状不同的数组自动对齐运算**（NumPy 的魔法——也是最大难点）：

```python
a = np.array([[1, 2, 3], [4, 5, 6]])   # 形状 (2, 3)
b = np.array([10, 20, 30])             # 形状 (3,)
a + b
# [[11 22 33]                          # b 被"广播"到每一行
#  [14 25 36]]

# 另一种：列广播
c = np.array([[10], [20]])             # 形状 (2, 1)
a + c
# [[11 12 13]                          # c 被"广播"到每一列
#  [24 25 26]]
```

**广播规则**（从右往左对齐维度）：**两个形状的每个维度：相等 → 直接运算；一个是 1 → 扩展成另一个；都不等且不是 1 → 报错**——**"维度对齐从右边开始，1 可以扩展"**：

```python
(2, 3) 与 (3,)    → (2, 3) 与 (1, 3) → 对齐 → 广播成功
(2, 3) 与 (2,)    → (2, 3) 与 (2,) → 从右对齐：(3,) vs (2,) → 不匹配且非 1 → 报错
```

**广播心智**：**"形状从右对齐、1 可以扩展成任意"**——想广播成功，要么形状相等、要么某维度是 1——**"把要广播的数组 reshape 成 (n, 1) 或 (1, n) 是万能技巧"**（列广播/行广播——`reshape(-1, 1)` 高频）。

## 4. 广播的报错

**广播失败 = 最常见的 NumPy 报错**：

```python
a = np.array([[1, 2, 3], [4, 5, 6]])   # (2, 3)
b = np.array([1, 2])                   # (2,)
a + b
# ValueError: operands could not be broadcast together with shapes (2,3) (2,)
```

**排查三步**：**打印两个 shape**（`print(a.shape, b.shape)`——第一动作）；**从右往左对齐**（找哪个维度不匹配）；**reshape 补 1**（`b.reshape(2, 1)` 或 `b[:, np.newaxis]`——`newaxis` 是补维度的正式写法）——**"广播报错 = 形状没对齐——对齐了就通了"**（报错信息里的形状是唯一线索——先看它）。

## 5. 聚合与 axis

**聚合 = 整组数据算一个数**（sum/mean/max——但**带 axis 就是"沿某方向聚合"**）：

```python
m = np.array([[1, 2, 3], [4, 5, 6]])

m.sum()            # 21 全部元素和
m.mean()           # 3.5 全局均值
m.max() / m.min()  # 6 / 1

m.sum(axis=0)      # [5 7 9] 沿轴 0 聚合 = 折叠行 = 按列求和（每列的和）
m.sum(axis=1)      # [6 15] 沿轴 1 聚合 = 折叠列 = 按行求和（每行的和）
m.mean(axis=0)     # [2.5 3.5 4.5] 每列均值
```

**axis 心智（不背）**：**axis = "沿哪个轴折叠"**——`axis=0` 折叠第 0 维（行）→ 剩下的是列 → **按列算**；`axis=1` 折叠第 1 维（列）→ 剩下的是行 → **按行算**——**"axis=0 是'竖着折'（按列）、axis=1 是'横着折'（按行）"**——不要背"0 是列 1 是行"（那是二维的特例——三维就失效）——**"折叠思维"在任意维度都成立**（06 篇深潜）。

## 7. ufunc 速查与广播图解

**ufunc 高频速查**（数据分析用得上的数学函数）：

| 函数 | 作用 | 注意 |
|------|------|------|
| `np.abs / np.round / np.sqrt` | 绝对值/四舍五入/开方 | sqrt 负数 → nan |
| `np.exp / np.log` | 指数/自然对数 | log 0/负数 → -inf/nan |
| `np.power / np.mod` | 幂/取余 | `np.power(a, 2)` = a² |
| `np.maximum / np.minimum` | 逐元素取大/取小 | 比 where 快的两数组操作 |
| `np.clip(a, lo, hi)` | 裁剪到区间 | 异常值封顶（阶段 1 三处理） |
| `np.sign` | 符号（-1/0/1） | 判断正负 |

**广播的"铺开"图解**（文字版——理解"1 怎么扩展"）：

```text
(2, 3)  和  (3,)：
    [1 2 3]      [10 20 30]
    [4 5 6]  +   [10 20 30]     ← b 被"复制"成 (2,3) 再逐元素加
    ─────────────────────
    [11 22 33]
    [14 25 36]

(2, 3)  和  (2, 1)：
    [1 2 3]      [10]           ← c 被"复制"成 (2,3)
    [4 5 6]  +   [20]
    ─────────────────────
    [11 12 13]
    [24 25 26]
```

**图解心智**：**"广播 = 自动复制小数组到对齐形状——省的是你手写复制的代码"**——`(n,)` 行向量自动铺成每行、`(n,1)` 列向量自动铺成每列——**"看形状想铺法：右边的沿行铺、竖着的沿列铺"**——`newaxis`（`arr[:, np.newaxis]`）就是手动说"我要竖着铺"。

**向量化的边界**（什么时候向量化失效——知道边界才是真懂）：**逐元素逻辑依赖**（`if x > 0: 做A else: 做B` 且 A/B 复杂——用 `np.where` 表达（05 篇）；更复杂的多步分支用掩码分段）；**字符串处理**（`np.char` 家族能力有限——字符串分析去 Pandas——阶段 2 Pandas 篇）；**需要中间状态**（依赖前一步结果的递推——先查 `np.cumsum/cumprod/diff` 有没有向量化版——**递推类的向量化宝藏**——阶段 3 时序预演）——**"先查向量化函数库（np.xxx 有没有现成的）、再 where/掩码、最后才循环"**——向量化的边界 = 三选一的顺序。

**广播的面试题**（高频）："解释 NumPy 的广播机制"——标准答法：**"广播是形状不同的数组自动对齐运算的机制——规则是：维度从右往左对齐，要么相等、要么某维度为 1（1 可以扩展成任意大小）、否则报错——例如 (2,3) 与 (3,) 广播成功（(3,) 扩展成 (2,3)）、(2,3) 与 (2,) 报错"**——答题结构：**机制 → 规则 → 例子（成功 + 失败）**——"能举失败例子 = 真懂"（只会举成功的 = 背的——失败例子暴露了规则边界）。

**一句话记住**：`+ - * /` 逐元素、`@` 是矩阵乘法（阶段 3）——**"广播 = 形状对齐——从右对齐、1 可扩展——报错先打 shape"**——ufunc 是数学函数免循环（nan 传染用 nan* 家族——04 篇）——**"能向量化就不循环"是本章第一纪律（01 篇的落地）**。

## 8. 本节验收

**验收动作**：① 造 (3,4) 数组做四则运算 + 3 个 ufunc；② 行广播（加 (4,)）与列广播（加 (3,1)）各一次并打印结果；③ 故意制造广播报错并完成排查三步；④ `sum/mean/max` 各用 axis=0/1 算一遍并打印形状——**"运算全过 + 广播自己讲清 = 计算层通过"**——**练习纪律**：广播题先"预测再运行"（先想答案再跑——预测错 = 规则没懂——**"预测 vs 运行对比是数组学习的最高效方法"**——**"能预测对广播结果 = 广播真懂"**）——**广播规则三句话背下来：从右对齐 / 相等或 1 / 否则报错**——形状不对先打印两边 shape（第一动作）。

> 🎯 **核心要点**：逐元素运算（`+ - * /`——矩阵乘法是 `@`）；ufunc = 数学函数免循环（nan 传染——nanmean）；**广播 = 形状从右对齐、1 可扩展**（(n,1)/(1,n) 万能技巧——`newaxis`）；报错三步（打 shape → 对齐 → reshape 补 1）；axis = 折叠思维（0 竖着折按列、1 横着折按行——不背特例）——**"广播是魔法也是重灾区——形状对齐一切通"**。
