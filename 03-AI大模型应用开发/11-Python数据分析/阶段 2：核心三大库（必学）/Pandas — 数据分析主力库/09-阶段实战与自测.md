## 2. 实战：泰坦尼克完整报告

**第一步：读入 + 体检**（05 篇读写 + 03 篇清洗）：

```python
import pandas as pd, numpy as np

df = pd.read_csv("titanic.csv")
df.info(memory_usage="deep")          # 结构 + 内存体检（08 篇）
df.isna().sum() / len(df)             # 缺失比例（Age 20%/Cabin 77%/Embarked 0.2%）
df.duplicated().sum()                 # 重复检查
```

**第二步：清洗流水线**（03 篇——每步写理由）：

```python
# Cabin 缺失 77% → 删列（信息量不足）
df = df.drop(columns=["Cabin"])
# Age 缺失 20% → 中位数填充（理由：总体水平代替——按舱位分组填更准）
df["Age"] = df["Age"].fillna(df.groupby("Pclass")["Age"].transform("median"))
# Embarked 缺失 2 行 → 众数填充
df["Embarked"] = df["Embarked"].fillna(df["Embarked"].mode()[0])
# 类型校准 + 列名规范化
df["Age"] = pd.to_numeric(df["Age"], errors="coerce")
df.columns = [c.strip().lower().replace(" ", "_") for c in df.columns]
# 异常值：票价 clip 99 分位（理由：极值扭曲均值——08-素养的极端值处理）
df["fare"] = df["fare"].clip(upper=df["fare"].quantile(0.99))
```

**第三步：分组分析**（04 篇——三件套 + 透视 + 时序）：

```python
# 性别 × 舱位 × 幸存率（透视表——06 篇热力图原料）
pivot = df.pivot_table(index="pclass", columns="sex", values="survived", aggfunc="mean")
# 年龄分层（np.where 打标——06 篇）
df["age_group"] = np.where(df["age"] < 18, "少年", np.where(df["age"] < 40, "中年", "老年"))
df.groupby("age_group")["survived"].mean().reset_index()
# 类别计数（value_counts——05 篇）
df["embarked"].value_counts(normalize=True)
```

**第四步：三库合练**（阶段 2 的收口动作）：

```python
import matplotlib.pyplot as plt
import seaborn as sns
sns.set_theme(style="whitegrid")

fig, axes = plt.subplots(2, 2, figsize=(12, 8), constrained_layout=True)
sns.barplot(data=df, x="pclass", y="survived", ax=axes[0, 0])
axes[0, 0].set_title("舱位越高幸存率越高（头等舱 63%）")
sns.boxplot(data=df, x="pclass", y="fare", ax=axes[0, 1])
axes[0, 1].set_title("票价随舱位骤降（中位数 60 → 8）")
sns.histplot(data=df, x="age", hue="survived", kde=True, ax=axes[1, 0])
axes[1, 0].set_title("年龄分布：20-30 岁最多")
sns.heatmap(pivot, annot=True, fmt=".2f", cmap="RdYlGn", ax=axes[1, 1])
axes[1, 1].set_title("幸存率矩阵：头等舱女性 0.97 最高")
fig.savefig("output/titanic_dashboard.png", dpi=300, bbox_inches="tight")
```

**第五步：结论**（阶段 1 三段式——证据 + 数字 + 局限）：

> 结论：性别与舱位是幸存率最强的两个特征（女性 74% vs 男性 19%；头等舱 63% vs 三等舱 24%——头等舱女性组合 97% 最高）；年龄影响弱于性别舱位；票价分布右偏（均值 32 vs 中位数 14）——局限：891 人为数据集全量，不代表真实沉船全体。

## 4. 常见报错速查

| 报错/现象 | 原因 | 解法 |
|----------|------|------|
| `SettingWithCopyWarning` | 链式赋值 | 改 `df.loc[条件, 列] = 值`（02 篇） |
| `KeyError: 'xxx'` | 列名不存在 | `df.columns` 看真实列名（含空格/大小写） |
| `ValueError: truth value ambiguous` | and/or 连条件 | 改 `&`/`|` + 括号（02 篇） |
| `FutureWarning: 'M' is deprecated` | 旧频率符号 | `"ME"`（月末——07 篇） |
| `TypeError: unsupported operand` | 类型没转就运算 | `to_numeric` 先校准（03 篇） |
| merge 行数爆炸 | 没写 on/键不唯一 | 写 on + 查重复（05 篇） |
| `AttributeError: 'Series' object has no attribute 'append'` | append 已移除 | `pd.concat`（05 篇） |
| groupby 结果操作怪异 | 没 reset_index | 三件套补第 3 步（04 篇） |
| `MemoryError` | 表太大 | 三步曲：usecols/dtype/chunksize（08 篇） |
| `NaT` 混进分析 | 时间解析失败 | `errors="coerce"` + isna 检查（07 篇） |
