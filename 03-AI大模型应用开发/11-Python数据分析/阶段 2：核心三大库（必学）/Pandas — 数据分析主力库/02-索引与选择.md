## 1. 双轨制：loc 与 iloc

**Pandas 有两套定位系统——必须分清**：

```python
df = pd.DataFrame({"age": [22, 35, 41], "fare": [7.25, 71.28, 8.05]},
                  index=["a", "b", "c"])

df.loc["b"]           # 按行标签（名字）—— age=35, fare=71.28
df.iloc[1]            # 按行位置（序号）—— 同上
df.loc["a":"b"]       # 标签切片（含两端！）
df.iloc[0:2]          # 位置切片（左闭右开——和 NumPy 一致）
df.loc[:, "age"]      # 所有行 × age 列（逗号分隔——二维定位）
df.iloc[1, 0]         # 第 1 行第 0 列 = 35
df.loc[["a", "c"], ["age"]]   # 行子集 × 列子集
```

**双轨心智**：**"loc 找名字（标签）、iloc 找序号（位置）"**——两个关键差异：**切片含不含尾**（loc 含 `"a":"b"` 含 b；iloc `0:2` 不含 2——**标签切片是闭区间、位置切片是左闭右开**——第一易错点）；**loc 可以按布尔/标签列表、iloc 只能位置**——**"读表先想：我用名字还是序号？"**（有 index 语义用 loc、纯位置用 iloc）。

## 2. 布尔筛选

**布尔筛选 = NumPy 掩码的表版**（`../NumPy — 数值计算底层库/05-布尔掩码与条件选择.md` 的知识直接迁移）：

```python
df[df["age"] > 30]                     # 筛选行（掩码——返回副本）
df[(df["age"] > 20) & (df["fare"] < 10)]  # 组合条件（& 加括号——铁律）
df[df["sex"].isin(["男", "未知"])]       # 值在列表里（isin——高频）
df[df["age"].isna()]                   # 筛缺失行（阶段 1 的 isna 用法）
df.query("age > 30 and fare < 10")     # 字符串查询（进阶——可读性好）
```

**筛选心智**：**`df[布尔Series]` 筛行**（和 `arr[mask]` 同构——返回副本）；**`& | ~` 组合条件 + 括号铁律**（数组的纪律原样延续——`and/or` 同样报错）；**`isin` 是列表筛选的正式姿势**（`df["col"] == "a" | == "b"` 的替代——多值筛选用 isin——高频）。

## 3. 筛选后取列的正确姿势

**"筛行 + 取列"的组合**（分析最高频操作——写法有讲究）：

```python
# 正确：df.loc[行条件, 列名]
df.loc[df["age"] > 30, ["age", "fare"]]

# 错误（能跑但反模式）：df[df["age"] > 30]["age"]  ← 链式

# 取单列的正确姿势：
df.loc[df["age"] > 30, "age"]          # Series（单列名不带括号）
df.loc[df["age"] > 30, ["age"]]        # DataFrame（列名列表）
```

**姿势心智**：**"筛行取列一步到位：`df.loc[行条件, 列名]`"**——这是 Pandas 最高频的"标准姿势"（**筛选 → 取列 → 计算**一条链）；**`df[条件][列]` 链式写法能跑但警告**（第 4 节——**"能跑 ≠ 正确"**——loc 一步到位是唯一正确姿势）。

## 4. 链式赋值之坑

**Pandas 第一坑：链式赋值**（SettingWithCopyWarning）：

```python
# 坑：筛选后再赋值
df[df["age"] > 30]["label"] = "adult"     # Warning！可能没写进去（或改了副本）

# 正确：loc 一步到位
df.loc[df["age"] > 30, "label"] = "adult"   # 明确"在哪个位置写什么值"
```

**为什么是坑**：`df[条件]` 可能返回**视图也可能返回副本**（Pandas 内部决定——不可控）——链式 `[条件][列] = 值` 写在"不确定的对象"上——**可能改到原表、可能改到临时副本（原表没变）**——Pandas 发出 Warning 提醒你——**"链式赋值 = 结果不确定——loc 一步到位 = 结果确定"**。

**排查**：看到 `SettingWithCopyWarning` → 找到链式赋值 → 改成 loc——**"警告不是噪音，是 Pandas 在提醒你'你可能写错了'"**（忽略警告 = 埋雷）。

## 5. 索引的常见操作

```python
df.set_index("id")              # 把某列设为行索引（返回新表）
df.reset_index()                # 行索引变回列（groupby 后高频——04 篇）
df.reset_index(drop=True)       # 丢弃旧索引（重置 0,1,2...）
df.sort_index()                 # 按索引排序
df.rename(columns={"age": "Age"})   # 改列名（列名规范——阶段 1 04 篇）
```

**索引操作心智**：**`set_index/reset_index` 是"索引 ↔ 列"的双向开关**（groupby 结果、透视表都靠它整理——04 篇的标配）；**`reset_index(drop=True)` 防旧索引混入**（重排后不想留旧编号）；**`rename` 改列名是清洗第一步**（列名规范——`../../阶段 1：前置基础/04-数据容器与表格思维.md` 的下划线规范落地）。

## 7. 选择方法速查与面试题

**选择方法速查表**（本课收口——"读表四式"）：

| 需求 | 写法 | 返回 |
|------|------|------|
| 按标签取行 | `df.loc["a"]` | Series |
| 按位置取行 | `df.iloc[0]` | Series |
| 按标签取行子集 | `df.loc[["a","c"]]` | DataFrame |
| 按位置切片 | `df.iloc[1:3]` | DataFrame（左闭右开） |
| 按标签切片 | `df.loc["a":"c"]` | DataFrame（**含尾**） |
| 布尔筛选行 | `df[df.age > 30]` | DataFrame（副本） |
| 筛行取列 | `df.loc[条件, ["a","b"]]` | DataFrame |
| 条件改值 | `df.loc[条件, "列"] = 值` | 原地修改（安全） |

**面试题**："loc 和 iloc 的区别？"——答：**"loc 按标签（行名/列名）定位、iloc 按位置（整数序号）定位——关键差异在切片：loc 的标签切片是闭区间（含尾）、iloc 的位置切片左闭右开——筛选后取列/赋值必须用 loc（iloc 不能传布尔条件）"**——**答题结构：定义 → 切片差异 → 场景分工**——"补一句'链式赋值要用 loc 一步到位'显示防坑意识"。

**练习延伸**：`df.loc[df.a > 1, "b"] = 2` 和 `df[df.a > 1]["b"] = 2` 的区别？（确定 vs 不确定——02 篇第 4 节）。

**实战场景**（本课知识在真实分析里的位置）：**"筛行取列是分析的第一高频操作"**——从"看看数据"到"回答问题的第一刀"都是它：**筛选目标人群**（`df.loc[df.age > 60, "name"]`——老年客户名单）、**按条件改标签**（`df.loc[df.fare > 100, "vip"] = "是"`——高消费标记）、**组合条件圈定**（`df.loc[(df.age > 30) & (df.sex == "女"), ["age", "fare"]]`）——**"90% 的分析从一行 loc 筛选开始"**——面试讲项目时"我用 loc 筛出目标群体再分组对比"是标准动作。

**视图 vs 副本的实战提醒**（02 篇第 4 节的延伸）：**"筛选返回副本、loc 赋值修改原表"**——想保留筛选结果用中间变量（`sub = df.loc[条件]`——副本——后续随便改不污染原表）；**"探索阶段筛副本、生产阶段改原表——两个世界分清"**——链式赋值的坑就是"分不清在改谁"（`SettingWithCopyWarning` 是 Pandas 的善意提醒——**"警告不是噪音，是防雷"**）。

**一句话记住**：loc 找名字/iloc 找序号（标签切片含尾）——**"筛行取列用 `df.loc[条件, 列]` 一步到位——链式赋值是坑"**——`&` 组合条件加括号——**"能跑 ≠ 正确——loc 一步到位 = 结果确定"**。

## 8. 本节验收

**验收动作**：① loc/iloc 各五种取法（标签/位置/切片/行子集/二维）；② 布尔筛选三连（单条件/组合/isin）；③ 筛行取列 loc 一步到位（对比链式看警告）；④ set_index + reset_index 来回一次——**"双轨 + 筛选 + 防坑 = 索引层通过"**——**练习纪律**：链式赋值的警告必须亲眼触发一次再修复——"见过坑才记得坑"。

> 🎯 **核心要点**：loc 找名字/iloc 找序号（标签切片含尾、位置切片左闭右开——第一易错点）；布尔筛选 = 掩码表版（`&` 加括号铁律、isin 多值）；筛行取列标准姿势 `df.loc[行条件, 列名]`；**链式赋值 = Pandas 第一坑**（SettingWithCopyWarning——loc 一步到位）；索引 ↔ 列双向开关（set_index/reset_index）——**"标签找名字、位置找序号——能跑 ≠ 正确"**。
