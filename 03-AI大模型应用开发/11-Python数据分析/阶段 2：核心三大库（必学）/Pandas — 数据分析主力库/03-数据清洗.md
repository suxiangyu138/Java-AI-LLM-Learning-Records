## 2. 缺失处理

```python
df.isna().sum()                    # 体检：每列缺失计数（第一动作！）
df.isna().mean()                   # 缺失比例（>5% 处理、>30% 考虑删列）

# 三处理（阶段 1 概念的代码化）
df.dropna()                        # 删行（默认删"有缺失"的行）
df.dropna(subset=["age"])          # 按指定列删（常用！不误删其他列）
df.drop(columns=["cabin"])         # 删列（缺失 68% 的列）
df["age"] = df["age"].fillna(df["age"].median())   # 填充（写理由！）
df.fillna({"age": 0, "sex": "未知"})               # 按列填不同值（推荐姿势）
df["age"] = df["age"].ffill()      # 前值填充（时间序列专用——07 篇）
```

**缺失心智**：**先体检后处理**（`isna().sum()` 是读表后的第二动作——阶段 1 纪律）；**填充必须写理由**（中位数 = "用总体水平代替"、0 = "视为无"——没有默认填充）；**`dropna(subset=)` 指定列是防误删的关键**（默认删整行会误伤其他列有价值的行）；**按列填不同值用字典**（`fillna({...})`——一列一策略）。

## 3. 重复处理

```python
df.duplicated()                    # 每行是否重复（返回布尔）
df.duplicated(subset=["id"])       # 按指定列判断重复（常用！）
df.drop_duplicates()               # 删重复行（默认保留第一条）
df.drop_duplicates(subset=["id"], keep="last")   # 按列去重 + 保留最后一条
```

**重复心智**：**"重复"的定义要明确**——全行重复 vs 按关键列重复（`subset` 参数——**"两行 id 相同 = 重复，哪怕其他列不同"**）；**keep 参数选保留哪条**（first 第一条/last 最后一条/False 全删）；**去重前先看**（`duplicated().sum()` 数一下再删——**"删数据前先知道删多少"**）。

## 4. 类型校准

```python
df["age"] = pd.to_numeric(df["age"], errors="coerce")    # 文本数字 → 数值（阶段 1 六篇）
df["date"] = pd.to_datetime(df["date"], errors="coerce") # 文本日期 → 时间（07 篇）
df["fare"] = df["fare"].astype(float)                    # 强制类型
df["sex"] = df["sex"].astype("category")                 # 类别化（08 篇省内存）
df["price_clean"] = df["price"].str.replace("元", "").astype(float)  # 去单位再转
```

**类型心智**：**`to_numeric/to_datetime` 带 `errors="coerce"`**（转不了的变 NaN——先看失败比例再处理——阶段 1 纪律）；**`str` 访问器是字符串列的前置处理**（`df["col"].str.xxx`——去单位/去空格——`../../阶段 1：前置基础/03-Python速成（数据分析子集）.md` 的字符串操作的表版）；**astype 要赋值才生效**（`df["col"] = df["col"].astype(...)`——忘了赋值 = 白转——NumPy 同款纪律）。

## 5. 异常值

```python
df.describe()                      # 体检：min/max 看明显异常（阶段 1 六指标）
df[df["age"] < 0]                  # 找可疑行（负年龄）
df["age"].quantile(0.99)           # 99 分位（极端值参考）

# 三处理（阶段 1 概念代码化）
df = df[df["age"] >= 0]                              # 删（录入错误）
df["fare"] = df["fare"].clip(upper=df["fare"].quantile(0.99))   # 封顶（clip——NumPy 表版）
df["fare"] = df["fare"].replace(0, np.nan)           # 标记（0 → 缺失再处理）
```

**异常心智**：**"异常 ≠ 错误"**（票价 512 真实、年龄 -5 错误——先判断再处理——`../../阶段 1：前置基础/08-数据素养与伦理.md` 的"先怀疑再处理"）；**`clip` 是封顶的正式函数**（`../NumPy — 数值计算底层库/03-向量化计算与广播.md` 的 clip 表版）；**处理要留痕**（notebook 里写明"删了 3 行负年龄"——复盘可查——09 篇报告格式）。

## 6. 列名与规范化

```python
# 列名规范化（阶段 1 04 篇规范落地——一行搞定）
df.columns = [c.strip().lower().replace(" ", "_").replace("？", "") for c in df.columns]

# 或显式改名
df.rename(columns={"Age": "age", "Fare(USD)": "fare_usd"}, inplace=False)

# 列顺序/子集
df = df[["id", "age", "fare"]]     # 只留需要的列（最小化——08 篇省内存）
df.sort_values("age", ascending=False)   # 按列排序（分析常用）
```

**规范化心智**：**"列名是表的 API"**（小写 + 下划线 + 无空格——所有后续代码引用列名——`../../阶段 1：前置基础/04-数据容器与表格思维.md` 的规范）；**只留需要的列**（少读少算少风险——最小化原则）；**排序是探索的第一步**（`sort_values`——找最大最小先看头尾）。

## 8. 清洗流水线模板与面试题

**清洗流水线模板**（每份数据的标准动作——直接复制改列名）：

```python
# 1. 体检
df.info(memory_usage="deep")          # 结构 + 类型 + 内存
df.isna().sum() / len(df)             # 缺失比例
df.duplicated().sum()                 # 重复数
df.describe()                         # 数值分布（min/max 找异常）

# 2. 处理（每步写理由——notebook 里注释）
df = df.drop(columns=["col_77%缺失"])                     # 删列（信息不足）
df["num_col"] = pd.to_numeric(df["num_col"], errors="coerce")  # 类型校准
df = df.drop_duplicates(subset=["id"])                    # 按键去重
df["num_col"] = df["num_col"].fillna(df["num_col"].median())   # 填缺失（写理由）

# 3. 留痕
print(f"清洗前 {rows_before} 行 → 清洗后 {len(df)} 行")     # 前后对比
```

**面试题**："数据清洗你做了什么？"——答：**"先体检（缺失/重复/类型/异常四查）再处理——每步写理由：Age 缺失 20% 用分组中位数填充（舱位影响分布）、Cabin 缺失 77% 删列、类型 to_numeric 校准、异常值 clip——留痕（前后行数对比）可复盘"**——**答题结构：体检 → 处理（带理由）→ 留痕**——"每步有理由"是标准答案的灵魂（没有理由的清洗 = 瞎处理）。

**练习延伸**：填充的三种理由各是什么？（均值 = 总体水平代替/0 = 视为无/前值 = 视为不变——阶段 1 六篇）。

**实战场景**（本课知识在真实分析里的位置）：**"清洗是每份数据的必修课——真实数据没有干净的"**——三个最常见的真实场景：**业务系统的"脏"**（用户表里手机号有空、年龄有 -5、性别有"未知"——清洗第一步是"认识业务怎么填的"）；**爬虫数据的"脏"**（`../../12-Python爬虫/` 抓下来的价格带"元"字、日期是"2026年8月10日"——`str.replace` + `to_datetime` 是爬虫数据的日常）；**多表合并的"脏"**（两表同一字段类型不同——一个 str 一个 int——merge 前先统一——05 篇）——**"清洗不是一次性的，是每份数据都要过的关卡"**——清洗报告（处理了什么/为什么/前后行数）是分析的可信度凭证（09 篇报告格式）。

## 9. 本节验收

**验收动作**：对泰坦尼克数据做完整清洗流水线——① 体检（缺失/类型/重复/异常四查）；② 缺失三处理（删列/填中位数/按列填——每步写理由）；③ 去重（按 id）；④ 类型校准（to_numeric + 日期）；⑤ 异常处理（负年龄删/票价封顶）；⑥ 列名规范化——**产出"清洗报告"（每步处理 + 理由 + 前后行数）**——**"四道工序 + 报告 = 清洗层通过"**（报告格式见 09 篇）。
