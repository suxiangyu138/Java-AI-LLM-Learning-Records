## 1. 美学为理解服务

**图的最终目标是"10 秒看懂"**——美学（颜色/样式/标签）不是装饰，是**理解的结构**：颜色分组让对比一目了然、标签让图自解释、样式统一让多图可比较——**"美的图是读得快的图"**——本课的顺序：先颜色（语义）→ 再样式（统一）→ 后标签（自解释）→ 终中文（落地）。

## 2. 颜色体系

**三种颜色用法**（由简到繁）：

```python
ax.plot(x, y, color="red")              # 1. 命名色（约 140 个：red/blue/green...）
ax.plot(x, y, color="#2E86AB")          # 2. 十六进制（精确控制——生产常用）
ax.bar(x, y, color=["#2E86AB", "#E86A92"])   # 3. 列表（逐条指定）
```

**默认色板 Tab10**（Matplotlib 默认 10 色循环——类别 ≤10 直接用默认即可）。

**颜色语义（2026 数据可视化共识）**：

- **红坏绿好**是直觉约定（上涨/下跌、通过/失败）——不要反着用
- **类别色**：彼此区分度高（Tab10/Set2）——不用相近色表示不同类别
- **连续色**：单色渐变（深浅表示大小——热力图）——不用彩虹
- **色盲友好**：红绿搭配最危险（红绿色盲 8% 男性）——用色盲安全板（`plt.style.use("tableau-colorblind10")`）
- **颜色少即是多**：一图 ≤5 色，超出用分面/标签替代（`../../阶段 1：前置基础/08-数据素养与伦理.md` 的颜色纪律）

## 3. 样式与风格

```python
plt.style.use("ggplot")                 # 风格一：ggplot（类 R 风格）
plt.style.use("seaborn-v0_8-whitegrid") # 风格二：浅色网格（Seaborn 风格——展示友好）
plt.style.use("tableau-colorblind10")   # 风格三：色盲安全
plt.rcParams["figure.dpi"] = 100        # 全局默认：显示 dpi
```

**风格纪律**：**风格要统一**（一个报告/一个 notebook 用一种风格——多图可比较）；**`plt.style.use` 是全局的**（在 notebook 开头设置一次——不要在中间反复切换）；**Seaborn 的 set_theme 是更完整的统一方案**（05 篇——Seaborn 0.13 起 `set_style/set_palette` 已废弃，统一用 `set_theme`）。

**rcParams**（全局默认参数——风格的本质）：`plt.rcParams["font.size"]`、`["axes.labelsize"]`、`["figure.figsize"]`——**"风格 = 一组 rcParams 的预设"**——自定义风格就是改 rcParams（中文三坑也在 rcParams 里解决——第 5 节）。

**样式选择的场景**（style 不是喜好是场景）：**探索阶段**用 whitegrid（浅色网格——读刻度方便——06 篇探索图的主力）；**交付报告**用 white/whitegrid + 统一字体（打印友好——08 篇规范）；**PPT/深色背景**用 darkgrid 或自定义深色（深色配亮色文字）；**多图对比**全报告一种风格（风格统一 = 可比较——`02` 篇子图对比的前提）——**"风格 = 场景 + 统一"**——`sns.set_theme(style="whitegrid")` 一处设置全 notebook 生效（05 篇）——**"风格不是装饰，是'读者注意力的管理'"**（浅色网格引导读刻度、深色背景聚焦内容）。

## 4. 标签：图的另一半

**"标签是图的另一半"**——没有标签的图是"未完成的图"（读者不知道轴是什么、线是什么、结论是什么）：

```python
fig, ax = plt.subplots(figsize=(8, 5))
ax.plot(dates, sales, label="销量")
ax.set_title("2026 上半年销量趋势", fontsize=14, fontweight="bold")  # 标题：一句话结论更好
ax.set_xlabel("月份"); ax.set_ylabel("销量（万元）")
ax.legend(loc="best")            # 图例（label 与 legend 配对——漏了就不显示）
ax.grid(alpha=0.3)               # 网格（浅色即可）
ax.annotate("促销开始", xy=(4, 18), xytext=(2, 20), arrowprops=dict(arrowstyle="->"))
```

**标签完整清单**（画完自查）：**标题**（最好是一句话结论——"销量 4 月触底后回升"比"销量趋势"强）、**轴标签 + 单位**（"销量（万元）"——单位是防误解第一要素）、**图例**（多条线/多分组必有）、**注释**（关键点标注——`annotate` 或 `text`——"图的重点要指给读者看"）。

**标题即结论**：**报告图的标题写结论**（"头等舱幸存率最高（63%）"）——读者 10 秒抓到重点——探索图标题写问题（"票价分布如何？"）——**"标题从问题变成结论 = 从探索图变成交付图"**（08 篇）。

## 5. 中文三坑

**Matplotlib 默认无中文字体 → 中文显示为方块**——这不是 bug，是字体配置问题——三行解决：

```python
plt.rcParams["font.sans-serif"] = ["Microsoft YaHei", "SimHei", "Arial Unicode MS"]  # 指定中文字体（按系统选）
plt.rcParams["axes.unicode_minus"] = False    # 负号显示为方块 → 用 ASCII 负号
# （可选）plt.rcParams["font.family"] = "sans-serif"
```

**中文三坑**：

| 坑 | 现象 | 解法 |
|----|------|------|
| 中文方块 | 标题/标签全是 □□ | `font.sans-serif` 指定中文字体（Windows：Microsoft YaHei/SimHei） |
| 负号方块 | 坐标轴 -1 显示成 □ | `axes.unicode_minus = False` |
| 字体警告 | "findfont: Font family not found" | 字体名写错/没装——`matplotlib.font_manager` 查可用字体 |

**中文字体纪律**：**字体配置放 notebook 开头**（和 `%matplotlib inline` 一起——`../../阶段 1：前置基础/07-Jupyter Notebook 实战.md` 的开头规范）；**换机器字体可能不同**（Windows 用雅黑、Mac 用苹方/Heiti、Linux 用文泉驿/Noto——写兼容列表）；**导出 PDF 矢量图时字体要嵌入**（08 篇——不然换个机器打开就乱）。

## 6. 标签完整检查表

**画完一张图，按表逐项检查**（标签的"完整度清单"）：

| 元素 | 检查 | 缺失后果 |
|------|------|---------|
| 标题 | 写了结论吗（报告图）？ | 读者不知道图在说什么 |
| x 轴标签 | 写了吗（含单位）？ | "月份"还是"年份"靠猜 |
| y 轴标签 | 写了吗（含单位）？ | "万元"还是"元"差 1 万倍 |
| 图例 | 有多条线/多个分组吗？ | 颜色代表的含义丢失 |
| 注释 | 关键点标注了吗？ | 重点靠读者自己找 |
| 刻度 | 重叠了吗？旋转了吗？ | 黑块 = 读不了 |
| 数据来源 | 图上/图注注明了吗？ | 可信度打折（08 篇证据链） |

**检查心智**：**"把图发给一个不懂数据的朋友——他能独立看懂吗？"**——不能 = 标签没补齐——**"标签是图的另一半——缺标签的图是半成品"**（本课标题的落地检查法）。
