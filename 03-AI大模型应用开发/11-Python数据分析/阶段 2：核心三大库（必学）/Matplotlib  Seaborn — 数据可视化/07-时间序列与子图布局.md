## 1. 时间序列图的地位

**时间序列是业务数据的"第一主角"**（销量/流量/收入——都要看时间变化）——`../../阶段 1：前置基础/03-Python速成（数据分析子集）.md` 之后、阶段 3 的统计与时序主体系（`../../08-时间序列分析.md`）之前，本课解决**画时间趋势图**的工程问题——**"先会画时间图，再学时间分析"**。

**时间序列图的三个坑**（80% 报错/错图都在这）：**日期没解析**（是字符串不是日期——x 轴乱序）；**顺序不对**（字符串排序 "10月" < "2月"）；**缺失日期**（没数据的日期凭空"连过去"——误导）。

## 2. 日期解析与日期轴

```python
import pandas as pd

df = pd.read_csv("sales.csv", parse_dates=["date"])   # 读时解析（推荐——05 篇参数）
# 或事后解析：
df["date"] = pd.to_datetime(df["date"], errors="coerce")   # 解析失败变 NaT

df = df.sort_values("date")        # 时间序列第一动作：按日期排序（防乱序坑）
```

**日期解析心智**：**`to_datetime` 认识常见格式**（`2026-08-10`/`2026/08/10`/`2026-08` 自动判断）——**不认识的格式先 `errors="coerce"` 看失败比例**（和 `to_numeric` 同款纪律——`../../阶段 1：前置基础/06-数据类型与缺失值.md`）；**解析失败 = NaT**（Not a Time——缺失的日期——`isna()` 检查）。

**画图时 x 轴自动变日期轴**（刻度智能稀疏化）：

```python
fig, ax = plt.subplots(figsize=(10, 5))
ax.plot(df["date"], df["sales"])
fig.autofmt_xdate(rotation=30)     # 日期标签旋转——防重叠（高频！）
```

**日期轴心智**：**日期刻度自动选**（跨度大 → 按年/月稀疏）；**`autofmt_xdate` 是高频必用**（不旋转 → 标签叠成黑块）；**缩放格式**：`ax.xaxis.set_major_formatter(mdates.DateFormatter("%Y-%m"))`（精确控制刻度格式——进阶）。

## 3. 趋势图规范

**趋势图 = 折线 + 规范**（画时间趋势的四条规范）：

```python
fig, ax = plt.subplots(figsize=(10, 5))
ax.plot(df["date"], df["sales"], linewidth=2, marker="o", markersize=4)
ax.set_title("2026 上半年销量：4 月触底后回升", fontweight="bold")   # 标题写结论
ax.axvline(pd.Timestamp("2026-04-01"), color="red", ls="--", label="促销开始")  # 事件标记
ax.fill_between(df["date"], df["sales"].min(), df["sales"], alpha=0.15)  # 面积强调
ax.legend(); fig.autofmt_xdate(rotation=30)
```

**趋势图四规范**：

| 规范 | 为什么 | 做法 |
|------|--------|------|
| 从 0 起或标注截断 | 防视觉误导（08-素养） | y 轴默认即可——特殊情况标注 |
| 事件标记（axvline） | 趋势转折要归因 | 促销/改版/事故画竖线 + 注释 |
| 单线加粗、多线可辨 | 读者聚焦 | linewidth=2、多线用语义色 |
| 标题写结论 | 读者 10 秒看懂 | "4 月触底后回升"优于"销量趋势" |

**趋势图纪律**：**"时间图必有事件标注"**（趋势转折的原因要画在图上——不然读者自己猜——猜错 = 误导）；**缺失日期要处理**（周末无数据的业务——`resample` 重采样是阶段 3 的活——本课先"缺失日期的图要标注或剔除"，绝不静默连线）。

## 4. 多序列对比

**多条趋势线 = 多序列对比**（同图 or 分图？）：

```python
# 同图：量纲相近 + 序列少（≤4）——直接叠加
for col in ["华东", "华南", "华北"]:
    ax.plot(df["date"], df[col], label=col, linewidth=2)
ax.legend()

# 分图：量纲差异大 或 序列多——sharex 分面子图（02 篇）
fig, axes = plt.subplots(3, 1, figsize=(10, 10), sharex=True)
for ax, col in zip(axes, ["华东", "华南", "华北"]):
    ax.plot(df["date"], df[col])
    ax.set_ylabel(col)
fig.autofmt_xdate(rotation=30)
```

**多序列心智**：**同图对比要求"量纲相近 + 序列少"**（量纲差 100 倍同图 = 小序列被压成直线——双轴是误导——`../../阶段 1：前置基础/08-数据素养与伦理.md`）；**序列多/量纲异 → 分面子图 + sharex**（刻度对齐——一眼对比）；**对比的关键是"趋势形态"不是"数值大小"**（同涨同跌 vs 背离——背离是重点——结论写在标题）。

## 5. subplots 布局实战

**多子图布局三形态**（本体系 02 篇 subplots 的实战收口）：

```python
# 形态一：上下堆叠（时间序列对比首选——sharex）
fig, axes = plt.subplots(2, 1, figsize=(10, 7), sharex=True, constrained_layout=True)

# 形态二：网格（多指标总览——dashboard 雏形）
fig, axes = plt.subplots(2, 2, figsize=(12, 8), constrained_layout=True)

# 形态三：手动布局（GridSpec——进阶——不等宽/跨行）
fig = plt.figure(figsize=(12, 6))
gs = fig.add_gridspec(1, 2, width_ratios=[2, 1])   # 左宽右窄
ax_big = fig.add_subplot(gs[0]); ax_small = fig.add_subplot(gs[1])
```

**布局纪律**：**constrained_layout=True 常开**（防标题/标签重叠——02 篇）；**时间序列对比必 sharex**；**dashboard 思维**：多子图 = 一个报告页（左上总览/右上细分/下排详情——读者扫一眼拿全貌）——**"多子图不是拼图，是排版——先想读者先看哪"**。

**时间序列的聚合口径**（画图前的数据准备）：业务数据通常按日记录，画月度趋势先聚合——**"趋势图的粒度 = 问题的粒度"**（看全年趋势按月、看活动效果按日——粒度错 = 结论错）；聚合函数按业务语义选（销量用 sum、单价用 mean、库存用 last——**不是默认 mean**——`resample` 深潜留到阶段 3 时序主体系 `../../08-时间序列分析.md`，本课先立"画图前先聚合"的概念）。

**业务时间序列的三个常见问题**（画图时遇到）：**周末无数据**（电商/办公业务——折线在周末"断崖"——处理：标注"周末无数据"或聚合到周）；**节假日效应**（春节/双十一——趋势尖峰要标注节日——不然读者以为是异常）；**时区**（跨时区数据统一到同一时区再画）——**"业务时间图 = 数据 + 日历"**（事件/节日/周期都画上去——本课"时间图必有事件标注"的扩展）。

## 6. 练习 5 题（自测）

1. 时间序列图的三个坑是什么？各怎么防？
2. `parse_dates` 和事后 `to_datetime` 各在什么时候用？
3. `fig.autofmt_xdate` 解决什么问题？
4. 多序列同图 vs 分图的选择标准是什么？

**练习纪律**：第 4 题要能说出两个标准（量纲相近 + 序列 ≤4 同图；否则 sharex 分图）——**"能说标准 + 能写代码 = 时间序列可视化过关"**。

**一句话总结**：时间图三坑（解析/乱序/缺失）+ 四规范（事件/从 0/加粗/结论）+ 聚合口径（粒度 = 问题粒度）——**"先聚合再画、先排序再画、先标注再画"**。

## 7. 本节验收

**验收动作**：造/找一个带日期的数据（销售/气温）——① `parse_dates` 解析 + 排序（并故意展示"不排序的乱序坑"）；② 一张规范趋势图（标题结论 + 事件标记 + autofmt_xdate）；③ 三序列对比（同图一版 + sharex 分图一版——说明什么时候用哪个）；④ 一张 `2×2` dashboard（四个指标各一格）——**"四步全做 = 时间序列可视化通过"**。

> 🎯 **核心要点**：时间图三坑（类型没解析/乱序/缺失——排序 + to_datetime + 缺失处理）；日期轴（autofmt_xdate 高频必用）；趋势四规范（事件标注/从 0 起/加粗/标题结论）；多序列（同图限量纲近、分图 sharex——看形态不看数值）；布局（constrained_layout + sharex + dashboard 排版）——**"时间图 = 折线 + 规范——'时间图必有事件标注'"**。
