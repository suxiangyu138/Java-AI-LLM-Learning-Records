## 1. 分组结论的可视化

阶段 1 的分组分析止步于数字：`df.groupby("Sex")["Survived"].mean()` 输出 `女 0.74 / 男 0.19`——**数字是结论，图是证据**——本课把"分组 → 数字"升级为"分组 → 数字 → 图 → 结论"——**"分组分析没画图 = 结论没有证据"**（`../../阶段 1：前置基础/02-数据分析全流程与心智模型.md` 的图即证据）。

**分组可视化的问题**：只看均值会漏掉分布（两组均值相同但分布天差地别——一组整齐一组两极）——**"比均值更重要的是分布的形状"**——这就是箱线图/密度图的舞台。

## 2. 箱线图深读

```python
sns.boxplot(data=df, x="Pclass", y="Fare", hue="Survived")
```

**箱线图五要素**（读图的必备能力）：

```text
    离群点 o（超过须的极端值——1.5×IQR 之外）
   ┌───┐  上须（75% + 1.5×IQR）
   │ ─ │  上四分位（75%）
   │ ─ │  中位数（50%——箱里的横线）
   │ ─ │  下四分位（25%）
   └───┘  下须（25% - 1.5×IQR）
     o     离群点
```

**箱线图心智**：**中位数看中心、箱子看集中度（IQR）、须看范围、点看离群**——**中位数 vs 均值对比**（图中箱线位置 vs 均值——差很多 = 偏斜，`../../阶段 1：前置基础/06-数据类型与缺失值.md` 的 describe 解读）；**离群点是线索不是垃圾**（票价 512 是真实头等舱——`06` 篇的"异常≠错误"）；**箱线图是"分布对比之王"**（多组并排一眼比——`03` 篇选型树）。

## 3. 分布对比三件套

**三张图看分布**（单变量分布的不同侧面）：

```python
# 1. 直方（看形状——bins 调粒度）
sns.histplot(data=df, x="Age", bins=30, hue="Sex")

# 2. 密度图（平滑版——多组叠加对比首选）
sns.kdeplot(data=df, x="Age", hue="Sex", fill=True, alpha=0.3)

# 3. 小提琴（箱线 + 密度二合一——分布形状完整呈现）
sns.violinplot(data=df, x="Pclass", y="Fare", hue="Survived", split=True)
```

**三件套心智**：**直方看轮廓**（分布形态——偏斜/双峰）、**密度看对比**（多组叠加平滑——填充 + alpha 半透明防遮挡）、**小提琴看细节**（分布形状 + 中位数——比箱线更完整但更复杂）——**"先直方、再密度、复杂场景小提琴"**。

**读分布的四问**（每组分布都问）：中心在哪（中位数/众数）？形状对称吗（偏斜）？有几个峰（单峰/双峰）？离群在哪？

## 4. 分组 → 图 → 结论

**"分组 → 图 → 结论"三段式**（本课的核心方法——每个分组分析都这么做）：

```text
第 1 步 分组（Pandas）：df.groupby(...) 算指标——先有数字
第 2 步 画图（Seaborn）：同分组画图——数字变证据
第 3 步 结论（一句话）：图 + 数字 → 结论——"证据是什么 + 局限是什么"
```

```python
# 第 1 步：分组数字
surv_rate = df.groupby("Sex")["Survived"].mean()    # 女 0.74 / 男 0.19

# 第 2 步：同分组画图（hue 表达第二维度）
fig, ax = plt.subplots(figsize=(8, 5))
sns.barplot(data=df, x="Sex", y="Survived", ax=ax)

# 第 3 步：结论（标题即结论——04 篇）
ax.set_title("女性幸存率（74%）是男性（19%）的 4 倍")
```

**三段式纪律**：**结论必须引用数字**（"74% vs 19%"——图 + 数字双证据）；**结论写局限**（"样本 891 人为数据集全量——不代表真实沉船全体"——`../../阶段 1：前置基础/08-数据素养与伦理.md` 的批判清单）；**图与数字不矛盾**（图是数字的可视化——两者对不上 = 画错了——自查）。

## 5. 多维分组实战

**三维分组的可视化**（hue + 分组柱状——`05` 篇的 hue 语义实战）：

```python
# 问题：性别 × 舱位 × 幸存率——哪个组合幸存率最高？
fig, ax = plt.subplots(figsize=(10, 6))
sns.barplot(data=df, x="Pclass", y="Survived", hue="Sex", ax=ax)
ax.set_title("头等舱女性幸存率最高（约 97%）——舱位与性别双因素")

# 透视表 + 热力图（二维分组全览）
pivot = df.pivot_table(index="Pclass", columns="Sex", values="Survived", aggfunc="mean")
sns.heatmap(pivot, annot=True, fmt=".2f", cmap="RdYlGn", ax=ax)
```

**多维分组心智**：**两个分组维度用 hue、三个用 col/row 分面**（`05` 篇——`relplot(col=..., row=...)`）；**透视表 + 热力图是"二维分组矩阵"的最优表达**（一眼看到最大/最小格子——`03` 篇热力）；**多维结论按"因素分解"讲**（"性别影响最大——各舱位女性都高于男性；舱位其次——同性别内头等舱更高"——结论分层讲）。

**"幸存者画像"**（阶段 1 扩展任务三的可视化版）：`head(1)` 的组合 = "头等舱女性"——**"画像 = 多维分组 + 图 + 一句话"**（面试讲项目时：先数字后图——"我是用分组 + 箱线 + 热力三张图定位出来的"）。

**分布读图的商业场景**（为什么"比均值更重要的是分布"）：**定价**——票价分布右偏，均值被头等舱拉高，**中位数才是"典型乘客"**（箱线图让均值骗局显形）；**库存**——销量分布双峰，两拨客户需求不同，单均值订货两头缺（直方图告诉你"不是一个市场"）；**风控**——还款金额分布的长尾，极端值才是风险焦点（密度图让长尾可见）——**"商业决策看分布、不看均值"**——`../../阶段 1：前置基础/06-数据类型与缺失值.md` 的均值 vs 中位数对比，这里从"数字认知"变成"决策能力"。
