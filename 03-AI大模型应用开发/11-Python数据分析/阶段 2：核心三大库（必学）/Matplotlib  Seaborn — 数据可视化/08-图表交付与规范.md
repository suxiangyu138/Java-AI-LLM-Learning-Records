## 1. 交付是图的终点

**"图能显示 ≠ 图能交付"**——notebook 里显示得挺好，截图发出去糊了/被裁了/换机器乱码了——**图的终点是"出现在报告/PPT/网页里还能保持清晰和完整"**——本课解决交付的三件事：**导出**（高清/裁剪/格式）、**规范**（十条——交付前自查）、**证据链**（图怎么组织成报告）。

## 2. savefig 高清导出

```python
fig, ax = plt.subplots(figsize=(8, 5))
# ... 画图 ...
fig.savefig(
    "output/销量趋势.png",      # 路径（放到 output/——07 篇三区纪律）
    dpi=300,                    # 高清（显示 100/打印 300/印刷 600）
    bbox_inches="tight",        # 自动裁剪留白（高频必用！）
    transparent=False,          # 透明背景（PPT 深色背景才用 True）
)
```

**导出三件套**（`dpi=300 + bbox_inches="tight" + 完整路径`——本体系的高频组合）：

| 参数 | 作用 | 默认陷阱 |
|------|------|---------|
| `dpi=300` | 像素密度——高清 | 默认 100 够显示不够打印 |
| `bbox_inches="tight"` | 裁掉多余留白 | 不裁 = 四周白边巨大 |
| `format="pdf"/"svg"` | 矢量格式（无限缩放） | PNG 是像素——放大糊 |

**格式选型**：**报告/论文用 PDF/SVG（矢量）**（缩放不糊——字体嵌入）；**PPT/网页用 PNG**（300dpi）；**数据交换用 PNG**（通用）——**"矢量给正式交付、像素给快速分享"**。

**导出纪律**：**路径进 output/**（`../../阶段 1：前置基础/07-Jupyter Notebook 实战.md` 三区纪律——原始数据/notebook/输出分离）；**导出前 `plt.close(fig)`**（释放内存——循环批量出图必做——不然内存暴涨）。

## 3. 探索图 vs 交付图

| 维度 | 探索图 | 交付图 |
|------|--------|--------|
| 目的 | 自己看图找规律 | 读者看证据信结论 |
| 速度 | 快（糙一点无所谓） | 精（每条线/每个标签都查过） |
| 标题 | 问题（"票价分布如何？"） | 结论（"票价右偏，多数低于 30 美元"） |
| 检查 | 差不多就行 | 规范十条全过 |
| 数量 | 一次画几十张 | 一份报告 5-10 张 |

**两阶段心智**：**探索和交付是同一张图的两个版本**——先探索（快糙——找规律），选定关键图后**升级为交付版**（精修：标题改结论、补注释、调颜色、导出高清）——**"探索图是草稿、交付图是定稿——中间隔着规范十条"**。

## 4. 图表规范十条

**交付前自查清单**（每次交付一张图过一遍）：

1. **一图一主题**（03 篇）——这张图只回答一个问题
2. **标题写结论**（04 篇）——读者 10 秒知道"这张图说了什么"
3. **坐标轴带单位**（04 篇）——"销量（万元）"——单位是防误解第一要素
4. **坐标轴从 0 起或标注截断**（素养课）——不误导
5. **图例完整且不挡数据**（04 篇）——`loc="best"` 或手动摆放
6. **颜色语义 + ≤5 色 + 色盲友好**（04 篇）——红坏绿好、不彩虹
7. **关键点有注释**（04 篇）——重点指给读者看（annotate）
8. **字体统一 + 中文正常**（04 篇）——全图一个字体族
9. **导出高清 + 裁剪**（第 2 节）——300dpi + tight
10. **图后必写解读**（阶段 1）——图不是成果、解读才是（`../../阶段 1：前置基础/07-Jupyter Notebook 实战.md`）

**规范心智**：**十条 = 读者视角的 10 个问题**（"我看得懂吗/被误导吗/重点在哪"）——**"交付图 = 让一个不懂数据的读者 10 秒看懂"**（`../../阶段 1：前置基础/08-数据素养与伦理.md` 素养 10 问的可视化版）。

## 5. 图表即证据链

**报告里的图不是孤立的——是证据链**（结论 → 图 → 数据 → 方法）：

```text
结论（标题写）→ 支撑图（一张或多张）→ 数据来源（注明）→ 方法说明（分组口径/时间范围）
```

**证据链四要素**（每张交付图都配）：**结论**（标题——这张图证明什么）、**数据**（来源 + 范围——"泰坦尼克 891 人全量"）、**方法**（口径——"幸存率 = 分组均值"）、**局限**（"不含真实沉船全体"）——**"缺一个要素 = 图可以被质疑"**——**"证据链 = 图可信的底座"**：数据来源写进图注（"数据：泰坦尼克 891 人，Kaggle"）、方法写进口径（"幸存率 = 分组均值"）——**"一张没有来源的图，等于一张没有签名的合同"**（面试讲图时主动报来源——可信度直接拉满）。

**报告组织**（多图叙事）：**先总览**（dashboard——全貌）→ **再重点**（关键结论的深图）→ **后附件**（补充图）——**"图是论据，报告是论点——图服务结论不是堆砌"**（`09-阶段实战与自测.md` 的可视化报告按此组织）。

**交付物矩阵**（图在什么场景以什么形态交付）：

| 场景 | 形态 | 规格 |
|------|------|------|
| 报告（PDF/网页） | 嵌入图 | PNG 300dpi 或 PDF 矢量 |
| PPT | 独立图 | PNG 300dpi（深色背景用 transparent） |
| 网页 dashboard | 交互图 | Plotly/交互后端（阶段 5 预告） |
| 团队协作 | notebook + 图 | notebook 留代码、图归档 output/ |
| 自动化报表 | 脚本定时出图 | savefig 循环批量（阶段 4 实战） |

**交付心智**：**"先问图去哪儿，再决定怎么导出"**——同一张图在不同场景规格不同（报告要矢量、PPT 要 300dpi、网页要交互）——**"交付 = 图 × 场景 × 规格"**——`savefig` 参数按场景矩阵选（第 2 节的格式选型 + 本表）。

## 6. 练习 5 题（自测）

1. 导出高清图的三件套是什么？各解决什么问题？
2. PNG 和 PDF/SVG 各适合什么场景？
3. 探索图标题和交付图标题的差别？
4. 规范十条里"坐标轴带单位"为什么重要？
5. 证据链四要素是哪四个？缺一个会怎样？

**练习纪律**：第 5 题要能举出例子（"缺数据来源——读者质疑'这数哪来的'"）——**"能说规范 + 能举反例 = 交付层过关"**。

**一句话总结**：交付 = 三件套（300dpi/tight/路径）+ 规范十条 + 证据链四要素——**"图能显示 ≠ 图能交付——交付是图的终点"**。

## 7. 本节验收
