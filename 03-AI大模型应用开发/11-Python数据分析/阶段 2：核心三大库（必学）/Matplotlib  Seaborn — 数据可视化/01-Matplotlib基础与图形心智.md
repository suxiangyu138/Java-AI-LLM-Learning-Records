## 1. 图即证据

**图不是装饰，是结论的证据**——数据分析里的图只有两个用途：**探索**（自己看图找规律）与**证明**（给读者看结论的依据）——`../../阶段 1：前置基础/02-数据分析全流程与心智模型.md` 说过"图即证据"是 EDA 七步的第 5 步——本体系把它变成能力：**"画不出图 = 结论没有证据"**。

**图的三个层次**（本体系的进阶主线）：**会画图**（工具——01-04 篇）→ **画对图**（选型——03 篇）→ **交付图**（规范——08 篇）——大多数人的问题不是不会画，是**画完不解释、选了不合适的图、交付糊图**——本体系按"心智 → 对象 → 选型 → 美学 → 统计 → 交付"逐层解决。

## 2. Matplotlib 定位与版本

**Matplotlib = Python 最底层的绘图引擎**——几乎所有 Python 绘图库（Seaborn/Plotly 的静态后端/Pandas 的 plot）底层都是它——**"学会 Matplotlib = 理解所有 Python 图的地基"**。2026-08 基线：**Matplotlib 3.10.x**（长期稳定线）。

**Matplotlib 的设计哲学**（来自 MATLAB 的启发）：**"把数学画成图"**——它的心智是"画布 + 坐标系 + 元素"（02 篇对象模型），不是"模板"——**"Matplotlib 不给现成模板，给的是积木"**（所以它灵活但繁琐——繁琐正是 Seaborn 存在的理由——05 篇）。

## 3. pyplot 心智：第一张图

**pyplot = Matplotlib 的"快捷模式"**（`import matplotlib.pyplot as plt`——直接画、自动管理画布）：

```python
import matplotlib.pyplot as plt

# 第一张图：销量趋势
sales = [10, 15, 13, 18, 22, 21]
plt.plot(sales)                # 画折线
plt.title("每月销量")           # 标题
plt.ylabel("销量（万元）")      # 轴标签
plt.show()                     # 显示（notebook 里可省略——inline 自动显示）
```

**pyplot 心智**（三个"自动"）：**自动建画布**（没指定就用"当前图"）、**自动叠加**（连续 plot 画在同一张图）、**自动管理**（plt.title 作用于当前图）——**简单但"隐式"**：多图/精细控制时会混乱——这正是 02 篇 OO API 要解决的。

**三个自动的代价**（pyplot 的隐式坑——遇到再回头读）：**自动建画布**——不调用 plt.figure 也有"当前图"，多次运行旧图残留（notebook 里越画越乱）；**自动叠加**——连续 plot 画同一张图，想开新图必须 plt.figure()（忘了 = 两张图叠成一张）；**自动管理**——plt.title 永远作用于"当前图"，多图时容易改错图——**"草图用 pyplot、工程用 OO"**（02 篇）——先会用 pyplot 建立"图"的概念，再升级到显式管理。

**图即证据的展开**（本体系第一概念的落地）：**探索图**（给自己看——快糙、一次几十张、找规律——06 篇三件套是探索主力）；**证明图**（给别人看——精选、精修、一张顶十句——08 篇规范十条是证明标准）——**"同一张图先探索后证明"**：先在 notebook 快速画出所有相关图（探索），选中最有说服力的 1-2 张精修成交付版（证明）——**"探索要广、证明要精"**——09 篇的可视化报告就是"探索 20 张、精选 7 张"的成品。

**第一阶段的最短路径**：`plt.plot / plt.scatter / plt.bar / plt.hist`（四种高频）+ `title/xlabel/ylabel`（三种标签）——先会这七行，再学对象模型。

## 4. 图的三大组成

**一张图的三大组成**（理解任何图的第一步）：

| 组成 | 是什么 | 代码 |
|------|--------|------|
| 画布 Figure | 整张图（含所有子图） | `plt.figure(figsize=(8, 5))` |
| 绘图区 Axes | 一个坐标系（实际画图的地方） | `plt.subplots()` 产生 |
| 元素 Artist | 线/点/柱/标签/图例——图上的每个对象 | `plot/bar/text/legend` |

**一句话**：**"Figure 是纸、Axes 是格子、Artist 是画上去的东西"**——pyplot 帮你在"当前格子"里画——02 篇讲怎么显式管理这三层（OO API）。

**查看图的元信息**（画完必做）：`plt.gcf()`（当前画布）、`plt.gca()`（当前坐标区）——"gcf/gca"是排查"图改错地方了"的第一工具。

## 6. pyplot 常用函数速查

**第一阶段最短路径的完整版**（先会这些，再学对象模型）：

| 函数 | 作用 | 高频参数 |
|------|------|---------|
| `plt.plot(x, y)` | 折线图 | `label/color/lw/linestyle` |
| `plt.scatter(x, y)` | 散点图 | `s（点大小）/alpha（透明度）` |
| `plt.bar(x, height)` | 柱状图 | `color/width` |
| `plt.hist(x)` | 直方图 | `bins（分箱数——关键参数）` |
| `plt.boxplot(数据列表)` | 箱线图 | 06 篇深讲 |
| `plt.title / xlabel / ylabel` | 三类标签 | `fontsize` |
| `plt.legend()` | 图例 | `loc`（位置） |
| `plt.grid(alpha=0.3)` | 网格 | 浅色即可 |
| `plt.xticks(rotation=45)` | 刻度旋转 | 标签重叠时用 |
| `plt.figure(figsize=(8,5))` | 画布尺寸 | 先想"图放哪"再定 |

**速查心智**：**先记"函数 → 画什么"的映射**（五个画图函数 + 三个标签函数 + 图例网格）——**"速查表是地图，练多了就不用看"**。
