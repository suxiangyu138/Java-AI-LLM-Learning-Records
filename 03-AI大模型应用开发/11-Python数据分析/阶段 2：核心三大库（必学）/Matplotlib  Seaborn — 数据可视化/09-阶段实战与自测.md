## 2. 实战：泰坦尼克可视化报告

**报告结构**（08 篇证据链组织——先总览再重点）：

**图一：年龄分布（直方 + 密度）**——回答"乘客年龄怎么分布"：

```python
import pandas as pd, matplotlib.pyplot as plt, seaborn as sns
plt.rcParams["font.sans-serif"] = ["Microsoft YaHei", "SimHei"]   # 中文三坑之一（04 篇）
plt.rcParams["axes.unicode_minus"] = False
sns.set_theme(style="whitegrid")                                   # 05 篇统一风格

df = pd.read_csv("titanic.csv")
fig, ax = plt.subplots(figsize=(8, 5))
sns.histplot(data=df, x="Age", bins=30, kde=True, ax=ax)
ax.set_title("年龄分布：20-30 岁乘客最多（右偏分布）")
fig.savefig("output/01_age.png", dpi=300, bbox_inches="tight")
```

**图二：性别 × 幸存率（分组柱状）**——"性别影响多大"（`hue` 或分组柱）：

```python
fig, ax = plt.subplots(figsize=(8, 5))
sns.barplot(data=df, x="Sex", y="Survived", ax=ax)
ax.set_title("女性幸存率（74%）是男性（19%）的约 4 倍")   # 标题写结论
```

**图三：舱位 × 票价箱线**——"舱位与票价的关系"（箱线五要素解读）：

```python
fig, ax = plt.subplots(figsize=(8, 5))
sns.boxplot(data=df, x="Pclass", y="Fare", ax=ax)
ax.set_title("票价随舱位骤降：头等舱中位数约 60 元、三等舱约 8 元")
```

**图四：年龄 × 票价散点（hue 幸存）**——"票价贵的更可能幸存吗"：

```python
fig, ax = plt.subplots(figsize=(8, 5))
sns.scatterplot(data=df, x="Age", y="Fare", hue="Survived", alpha=0.6, ax=ax)
ax.set_title("高票价乘客幸存率高——票价与幸存正相关（相关≠因果）")
```

**图五：票价分布对比（kde 分组）**——"幸存者与非幸存者票价分布差异"：

```python
fig, ax = plt.subplots(figsize=(8, 5))
sns.kdeplot(data=df, x="Fare", hue="Survived", fill=True, alpha=0.3, ax=ax)
ax.set_title("幸存者票价分布整体更高（右移）")
```

**图六：舱位 × 性别幸存率热力**——"多维画像——谁最可能幸存"：

```python
pivot = df.pivot_table(index="Pclass", columns="Sex", values="Survived", aggfunc="mean")
fig, ax = plt.subplots(figsize=(7, 5))
sns.heatmap(pivot, annot=True, fmt=".2f", cmap="RdYlGn", ax=ax)
ax.set_title("幸存率矩阵：头等舱女性 0.97 最高、三等舱男性 0.14 最低")
```

**图七：多子图总览（dashboard）**——报告封面图：

```python
fig, axes = plt.subplots(2, 2, figsize=(12, 8), constrained_layout=True)
sns.histplot(data=df, x="Age", bins=30, ax=axes[0, 0])
sns.barplot(data=df, x="Pclass", y="Survived", ax=axes[0, 1])
sns.boxplot(data=df, x="Sex", y="Fare", ax=axes[1, 0])
sns.scatterplot(data=df, x="Age", y="Fare", hue="Survived", alpha=0.5, ax=axes[1, 1])
fig.savefig("output/07_dashboard.png", dpi=300, bbox_inches="tight")
```

## 4. 常见报错速查

| 报错/现象 | 原因 | 解法 |
|----------|------|------|
| 图不显示 | 没执行 `%matplotlib inline` | notebook 开头加（01 篇） |
| 中文方块 □□ | 无中文字体 | `font.sans-serif` 指定（04 篇三行） |
| 负号方块 | unicode_minus | `axes.unicode_minus=False`（04 篇） |
| findfont 警告 | 字体名不对 | `matplotlib.font_manager` 查可用字体 |
| 图例重复/不显示 | label 忘写/legend 没调 | label 与 legend 配对（04 篇） |
| `AttributeError: AxesSubplot has no attribute 'plot'` | ax 写错（如把 axes 当 figure） | 检查 `fig, ax = plt.subplots()` 解包 |
| 多图覆盖 | pyplot 隐式"当前图" | 全部改用 OO API（02 篇） |
| 导出图白边巨大 | 没 bbox_inches | `bbox_inches="tight"`（08 篇） |
| `TypeError: 'numpy.ndarray' object is not callable` | 变量名覆盖了函数（如 `ax = ax(...)`） | 检查变量名——别叫 plt/ax/sns |
