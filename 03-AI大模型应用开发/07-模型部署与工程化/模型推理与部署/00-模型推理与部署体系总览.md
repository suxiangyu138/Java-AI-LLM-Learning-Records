## 3. 核心概念速查

### 3.1 推理性能指标

| 指标 | 含义 | 优化手段 |
|------|------|---------|
| TTFT | 首 token 延迟 | 前缀缓存/批处理/小模型 |
| TPOT | 每 token 生成时间 | 投机采样/算子优化 |
| 吞吐（tok/s） | 总生成量 | 连续批处理/量化 |
| KV 显存 | 注意力缓存占用 | PagedAttention/KV 量化/限长 |

### 3.2 四大优化技术

| 技术 | 解决 | 收益 |
|------|------|:----:|
| 连续批处理 | 吞吐（等待浪费） | 2-4x |
| PagedAttention | KV 显存碎片 | 显存利用率 95%+ |
| 前缀缓存 | 重复计算（共享前缀） | 长上下文显著 |
| 投机采样 | 单请求生成延迟 | 2-3x |

### 3.3 量化方案

| 方案 | 适用 | 2026 状态 |
|------|------|:---------:|
| FP8 | H100 推理 | ✅ 生产标配 |
| FP4 | Blackwell（B200） | ✅ 新支持 |
| INT4（AWQ/GPTQ） | 显存极限 | ✅ 成熟 |
| GGUF Q4 | 本地/边缘 | ✅ 本地标准 |

## 7. 常见误区

| 误区 | 真相 |
|------|------|
| "优化就是换更快引擎" | **部署配置（批处理/量化/前缀缓存）影响往往更大** |
| "KV 显存和权重一样" | 长上下文场景 **KV 是显存大头**（8K×32 并发 > 7B 权重） |
| "量化必掉精度" | FP8 动态范围大（无需校准）；INT4 需黄金集验证 |
| "平均延迟够用" | **必须看 P95**（长尾被平均掩盖） |
| "投机采样万能" | 只适合生成长文本（短输出草稿开销 > 收益） |
| "弹性伸缩和普通服务一样" | GPU 模型加载慢（分钟级）→ HPA 用排队指标 |
| "TGI 还能用" | **已进维护模式（2026-03）**——新项目用 vLLM/SGLang |
| "自研优化引擎更快" | 引擎已内置全部主流优化——自研 = 重复造轮子 |
