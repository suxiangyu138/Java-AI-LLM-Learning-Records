# 10 - 推理部署面试题精选

> 🎯 KV Cache 怎么算、PagedAttention 为什么好、投机采样为什么无损 — 推理优化的核心面试题

## 高频面试题

**Q1: KV Cache 是什么？显存占多少？**
```text
自回归生成时缓存历史 Key/Value，避免重复计算。
size = 2 × layers × hidden × seq_len × bytes × batch
Qwen2-7B(8K,8并发)=~34GB → 比模型权重(14GB)还大！
```

**Q2: PagedAttention 解决什么问题？**
```text
解决 KV Cache 显存碎片化。传统预分配→利用率~30%；分页按需分配→~90%
从"静态预分配"变成"动态页式管理"→ 同显存下支持更多并发
```

**Q3: 投机采样为什么"无损"？**
```text
小模型猜 K 个 token → 大模型验证 → 大模型用自己的概率分布拒绝错误的
最终输出分布 = 大模型原始分布 → 精度零损失
```

**Q4: 连续批处理 vs 静态批处理的区别？**
```text
静态：等 batch 所有请求完成后一起返回 → 快等慢
连续：完成的请求立即踢出，新请求立即加入 → 槽位永不空等
```

**Q5: FP16 vs BF16 vs INT8 vs INT4 怎么选？**
```text
训练：BF16（动态范围大）
GPU推理：FP16/BF16（精度无损）或 INT8（几乎无损）
本地部署：INT4/Q4_K_M（效果损失<3%，显存减4×）
```

**面试答题框架（推理优化类）**：

```text
"LLM 推理怎么优化？"
① 定位：先定义工作负载（交互/批处理/长上下文）
② 批处理：连续批处理（引擎标配）—— 吞吐基础
③ 显存：KV Cache 优化（PagedAttention/前缀缓存/量化 KV）
④ 延迟：投机采样（长文本）+ 流式（感知）
⑤ 量化：FP8（H100）—— 显存与吞吐双赢
⑥ 验证：黄金集质量 + P95 压测
—— 六段式覆盖"定位→优化→验证"完整链路
```
