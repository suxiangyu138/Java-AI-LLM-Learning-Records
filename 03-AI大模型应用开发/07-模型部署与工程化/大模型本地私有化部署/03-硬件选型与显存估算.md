# 03 硬件选型与显存估算

> 硬件选型的全部秘密是一条公式：模型权重显存 ≈ 参数量 × 位宽 / 8，再叠加 KV 缓存与并发余量。公式会算，选型就不会翻车。

## 1. 显存估算公式

推理显存由三部分组成：

```text
总显存 ≈ 模型权重 + KV 缓存 + 运行余量

模型权重 = 参数量(B) × 位宽(bit) / 8
  FP16：7B → 14GB；32B → 64GB；70B → 140GB
  INT4：7B → 3.5GB；32B → 16GB；70B → 35GB

KV 缓存 ≈ 每层 2 × 隐藏维 × 层数 × 上下文长度 × 位宽（随并发 × 倍数）
  7B 模型生成 1024 token 时约额外占 8-10GB
```

两条实战铁律：

1. **量化比选引擎影响更大**：Q4 量化 8B 模型权重约 4.5GB，FP16 需约 14GB——同一个模型，量不量化决定你 8GB 卡够不够用。
2. **显存要留 KV 与并发余量**：模型权重只是起点，长上下文 + 多并发会把 KV 缓存推到与权重同量级。估算公式建议：**实际所需 = 权重 × 1.5-2**。

| 层级 | 硬件 | 模型量级 | 并发 | 预算参考 |

| POC 试点 | 1×24-48GB GPU | dense ≤32B | 1-5 人 | 4千-1.5万美元 |

> ⚠️ 2026 年两个现实约束：DRAM 价格因厂商产能转向 AI 卡而大幅上涨，服务器到货价可能明显高于账面报价；完全无 GPU 预算的团队，可用带矩阵运算加速指令的新一代服务器 CPU 跑 MoE 模型（支持交互式单流对话）——体验够用但不适合并发。

## 4. 多卡与互联

多卡部署的三个决策点：

| 决策 | 建议 |
|---|---|
| NVLink 还是 PCIe？ | 优先 NVLink（多卡通信效率数倍差异），大模型张量并行严重依赖卡间带宽 |
| 张量并行还是流水线并行？ | 单模型拆层用张量并行（TP，需 NVLink）；多模型共存用流水线/实例隔离 |
| 显存不足怎么凑？ | 量化 > 拆层并行 > 外存卸载（速度依次下降，先量化再上卡） |

经验值：8×80GB（A100/H800 级）是跑 671B 级 MoE 的最低门槛；普通企业 32B 量化 + 1-2 卡即可满足 80% 的知识库/客服场景——**算力利用率是成本关键，满血模型 ≠ 最优解**。

## 5. 国产信创算力

数据不出域 + 信创合规的国产方案已成熟（2026-05 起量产）：

| 方案 | 硬件 | 定位 |
|---|---|---|
| 卡莱特 LS910 | 昇腾 Atlas 300I A2（910B），单卡 64GB HBM，鲲鹏 920 主控 | 信创推理服务器：Qwen3.6-27B 私有化，128K 上下文，单路 25-45 tok/s，OpenAI 兼容 API |
| 中科可控 Suma 平台 | 天阔 W50X 工作站，32 核 64 线程 + 128GB 显存，液冷 | 软硬一体交付：预置百亿级模型，数据离线处理全程不触网，交付小时级 |

国产路线的选择要点：昇腾方案需适配 CANN/MindSpore 软件栈（模型需转换）；OpenAI 兼容 API 保证应用层零改动；弹性版本（1 卡/4 卡/8 卡）对应部门→全公司分级。

### 5.1 选型落地步骤

硬件选型不建议"一步到位买最贵"，而是按四步走：第一步用现有设备（笔记本/工作站）跑 8B 量化模型，验证业务场景对开源模型能力的接受度——这一步零硬件投入，却回答了"模型够不够用"这个最关键的问题；第二步按验证结果定模型规模（32B 还是 70B），用公式反推显存需求与卡型；第三步按并发预期放大显存（KV 缓存随并发线性增长，10 并发可能把需求翻倍）；第四步才下单，并预留 20% 显存余量应对上下文加长。

这条路径的价值在于**用最小成本先证伪"模型能力不够"**——很多团队跳过第一步直接买 8 卡，结果发现业务瓶颈在模型能力而非算力，几十万硬件变成鸡肋。

### 5.2 CPU 与无 GPU 场景

完全没有 GPU 预算时并非无解：新一代服务器 CPU 普遍带矩阵运算加速指令（AVX-512 级），配合量化模型可以跑交互式单流对话；Ollama/llama.cpp 都支持纯 CPU 运行，7B-14B 量化模型在主流服务器 CPU 上可达 5-15 tok/s——知识库问答这类非实时场景体验可用。判断标准：单用户、非实时、模型 ≤14B 量化，CPU 方案可行；要并发或要实时，GPU 是必须的。混合折中方案是 CPU 起步验证业务价值，验证通过后再申请 GPU 预算——用"先跑起来"的结果说服决策层，比 PPT 有效得多。

## 6. 本模块小结

> 🎯 **核心要点**：显存公式（权重 = B×位宽/8，实需 ×1.5-2 留 KV 与并发）是硬件选型的起点；量化比选引擎影响更大；四层硬件配置对应 POC→前沿四档预算；多卡优先 NVLink；信创合规选昇腾/国产软硬一体方案，数据不出域 + OpenAI 兼容 API 双保证。普通企业的最优解：32B 量化 + 1-2 张大显存卡，覆盖绝大多数知识库/客服场景。
