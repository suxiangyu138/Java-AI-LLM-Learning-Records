# 01 为什么需要私有化部署

> 私有化不是"上不上 AI"的问题，是"AI 放哪"的问题。先想清楚五类驱动场景与四条合规红线，再谈技术选型——决策错了，部署得再漂亮也是浪费。

## 1. 五类驱动场景

| 场景 | 典型行业 | 核心诉求 |
|---|---|---|
| 强监管数据 | 金融反欺诈、政务、军工 | 数据不得出域的法规强制 |
| 敏感业务数据 | 医疗病历、企业合同、研发代码 | 泄露即事故，云端不可接受 |
| 低延迟实时 | 工业质检、交易风控 | 延迟须控制在 100ms 级 |
| 高频高成本 | 内部知识库、客服、代码辅助 | 云端按量计费持续烧钱 |
| 离线隔离环境 | 军工内网、生产网络 | 物理隔离，无外网可用 |

其中"合规强制"是最硬的驱动力：金融、医疗、政务等行业的监管要求数据不得出域，调用公有云 API 从合规上就不成立——这不是成本问题，是能不能做的问题。

## 2. 与云端 API 的六维对比

| 维度 | 云端 API | 私有化部署 |
|---|---|---|
| 数据安全 | 数据出域，受服务商条款约束 | 数据不出域，完全自控 |
| 初始成本 | 零硬件，按量付费 | 硬件一次性投入（数万-数百万） |
| 边际成本 | 每 token 持续付费 | 电费 + 运维，用得越多越划算 |
| 延迟 | 公网往返 + 服务商排队 | 内网直连，可控 |
| 模型能力 | 前沿大模型（闭源最强） | 开源模型为主，落后 1-2 代 |
| 定制能力 | 无（或有限微调） | 可微调、可私有数据训练 |

关键洞察：**成本曲线是交叉的**。低用量时云端便宜，高用量时私有化摊薄硬件成本后更优。粗略分界：持续日调用量达到数十万 token 级别、且模型能力要求不高（开源够用）的场景，私有化开始划算。

## 3. 合规红线：数据不出域

"数据不出域"是私有化部署的立身之本，落地上有三条不可妥协的边界：

1. **数据面不出域**：业务数据只进内网模型服务，不流向任何外部 API；嵌入式模型（RAG 向量化）也必须本地跑。
2. **模型面可控**：模型权重文件从可信来源下载并校验哈希，防止供应链投毒（警惕 pickle 格式——可执行任意代码）。
3. **行为面可审计**：所有推理调用有日志、有权限记录，能回答"谁在什么时候把什么数据喂给了模型"。

> ⚠️ 常见误区：本地部署 ≠ 自动安全。模型服务默认无认证、日志可能记录提示词与响应、文件权限可能过宽——安全责任全部转移到企业自己身上，这是私有化的隐藏成本。

## 4. 私有化的真实代价

| 代价 | 说明 |
|---|---|
| 硬件投入 | 单卡 24GB 消费级到 8×80GB 集群，跨度巨大 |
| 模型能力降级 | 开源模型在复杂推理上弱于闭源前沿模型，需业务适配 |
| 工程人力 | 部署、调参、监控、升级、排障都需要专人 |
| 硬件折旧与电费 | 7×24 运行的电费与散热成本长期存在 |
| 更新滞后 | 新模型发布后需重新评估、重新量化、灰度上线 |

所以"先问是不是，再问怎么部署"：不是所有企业都需要私有化。**决策错误的最常见形态是"为了私有化而私有化"**——业务数据本身不敏感、用量又不高，却花了数十万买硬件，结果模型能力还不如 API。

## 5. 四问决策框架

```text
① 数据敏感吗？
   敏感（合规强制/泄露事故级）→ 私有化 ✅
   不敏感 → 看第②问
② 用量够大吗？
   持续高用量（数十万 token/日+）→ 私有化可摊薄成本
   低用量/实验 → 先用云端 API，别买硬件
③ 开源模型够用吗？
   够用（知识库/客服/代码辅助）→ 私有化可行
   需要顶尖推理能力 → 云端闭源，或混合架构（敏感走私有化+不敏感走云端）
④ 有运维能力吗？
   有（或可外包）→ 上生产级
   没有 → 先上轻量方案（Ollama），验证价值再升级
```

四问全过再谈硬件与选型——这也是 02 篇的入口。

### 5.1 混合架构：多数企业的实际答案

私有化与云端并非二选一。2026 年的主流实践是混合架构：敏感数据与核心业务走私有化模型，非敏感场景与需要顶尖能力的任务继续用云端 API。典型拆分：客服与知识库问答（涉及内部资料）走本地 32B 模型；复杂代码生成、长文档推理等开源模型力不从心的任务走云端前沿模型。网关层按路由规则分流（按模型名/按调用方），调用方无感知。

混合架构的现实价值在于**用私有化守住合规底线、用云端补齐能力上限**，同时给模型能力演进留出缓冲——开源模型代际提升后，云端占比可以逐步收缩，架构不用推倒重来。

## 6. 本模块小结

> 🎯 **核心要点**：私有化部署的决策本质是"数据安全 × 用量规模 × 模型能力 × 运维能力"四变量的权衡。合规强制是最硬的理由；成本曲线交叉点决定经济性；开源模型能力上限决定可行性。本地部署 ≠ 自动安全，安全责任随部署一起转移。四问决策框架（敏感/用量/够用/运维）是任何私有化项目的立项第一步。
