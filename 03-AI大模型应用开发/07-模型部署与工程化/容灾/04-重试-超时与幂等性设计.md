# 04 - 重试、超时与幂等性设计

> 🎯 网络抖动、API 限流、临时故障 — 这些问题重试就能解决，但错误的首次重试可能让问题雪上加霜

---

## 1. 指数退避重试

```python
import asyncio
import random

async def retry_with_backoff(func, max_retries=3, base_delay=1, max_delay=30):
    """指数退避 + 随机抖动"""
    for attempt in range(max_retries + 1):
        try:
            return await func()
        except RetryableError as e:
            if attempt == max_retries:
                raise
            # 指数退避：1s, 2s, 4s, 8s...
            delay = min(base_delay * (2 ** attempt), max_delay)
            # 随机抖动：避免惊群效应（所有客户端同时重试）
            jitter = random.uniform(0, delay * 0.3)
            await asyncio.sleep(delay + jitter)

class RetryableError(Exception):
    """可重试错误：网络超时、限流、5xx"""
    pass

class NonRetryableError(Exception):
    """不可重试错误：参数错误、认证失败、4xx（非429）"""
    pass
```

## 2. 超时控制

```text
超时传播链：
  用户 → API Gateway(30s) → LLM Service(25s) → OpenAI API(20s)
  
  每一层超时 < 上一层超时 → 确保快速失败向上传播
  避免：底层超时 30s，上层超时 10s → 上层先超时 → 浪费底层资源

LLM 场景的超时建议：
  OpenAI API: 30s（复杂推理） / 15s（简单对话）
  vLLM 本地: 10s
  Embedding API: 5s
  RAG 检索: 2s
```

```python
import asyncio

async def llm_call_with_timeout(messages, timeout=30):
    try:
        return await asyncio.wait_for(
            openai_client.chat(messages),
            timeout=timeout
        )
    except asyncio.TimeoutError:
        # 超时不一定是永久故障 → 可以重试
        raise RetryableError("LLM 调用超时")
```

## 3. 幂等性设计

```text
LLM 幂等问题：
  "帮我发一封邮件给老板" → LLM 生成邮件 → 发送
  → 网络超时 → 客户端重试 → LLM 又生成一封 → 又发送 → 老板收到两封！

解决方案：
  ① 客户端生成幂等 Key（如 UUID）
  ② 发送请求时带上 idempotency_key
  ③ 服务端记录 (key → result) → 相同 Key 返回缓存结果
```

```python
import hashlib
import redis

class IdempotentLLMService:
    def __init__(self, llm_func, redis_client):
        self.llm = llm_func
        self.redis = redis_client
    
    def chat(self, messages, idempotency_key=None):
        if idempotency_key is None:
            # 自动生成：消息内容 Hash + 时间戳
            content = str(messages)
            ts = int(time.time() / 60)  # 每分钟去重
            idempotency_key = hashlib.md5(
                f"{content}{ts}".encode()
            ).hexdigest()
        
        # 查缓存
        cached = self.redis.get(f"llm:{idempotency_key}")
        if cached:
            return json.loads(cached)
        
        # 调用 LLM
        result = self.llm(messages)
        
        # 存缓存（1 小时过期）
        self.redis.setex(
            f"llm:{idempotency_key}",
            3600,
            json.dumps(result)
        )
        return result
```

## 4. 重试风暴防范

```text
重试风暴 = 上游超时→重试→下游压力增大→更多超时→更多重试→正反馈崩溃

防范：
  ① 客户端 jitter（随机抖动 → 分散重试时间）
  ② 服务端限流（保护自己不被重试风暴打死）
  ③ 最大重试次数限制（默认 3 次）
  ④ 重试预算（每分钟最多重试 N 次）
```

```python
class RetryBudget:
    def __init__(self, max_retries_per_minute=100):
        self.budget = max_retries_per_minute
        self.window = []
    
    def can_retry(self):
        now = time.time()
        self.window = [t for t in self.window if now - t < 60]
        return len(self.window) < self.budget
    
    def consume(self):
        self.window.append(time.time())
```
