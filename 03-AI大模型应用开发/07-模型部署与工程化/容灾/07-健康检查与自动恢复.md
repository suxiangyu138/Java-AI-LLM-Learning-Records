# 07 - 健康检查与自动恢复

> 🎯 挂了不可怕，挂了没人知道才可怕 — 三层探针 + 自愈机制，让故障恢复从"人工救火"变成"自动愈合"

---

## 1. 三层探针

```text
K8s 健康检查三兄弟：

  Startup Probe (启动探针)：
    → 模型加载可能需要 2-5 分钟 → READY 之前先通过 Startup
    → 通过后不再检查（避免长启动被当做不健康）
    
  Liveness Probe (存活探针)：
    → 进程还活着吗？挂了 → 重启 Pod
    → 轻量检查：进程存在 / 端口监听
    
  Readiness Probe (就绪探针)：
    → 能处理请求吗？不能 → 从 Service 摘除
    → 重量检查：模型加载完成 + GPU 可用 + 能做一次推理
```

```yaml
# vLLM Deployment 探针配置
startupProbe:
  httpGet:
    path: /health
    port: 8000
  failureThreshold: 30   # 最多等 30×10=300s
  periodSeconds: 10

livenessProbe:
  httpGet:
    path: /health
    port: 8000
  initialDelaySeconds: 0
  periodSeconds: 30

readinessProbe:
  httpGet:
    path: /health/ready   # 自定义就绪检查
    port: 8000
  initialDelaySeconds: 0
  periodSeconds: 10
```

## 2. 应用层健康检查

```python
from fastapi import FastAPI
import torch
import time

app = FastAPI()
model_loaded = False

@app.on_event("startup")
async def load_model():
    global model_loaded
    # 加载模型（可能需要几分钟）
    model = load_llm_model()
    model_loaded = True

@app.get("/health")
async def health():
    return {"status": "alive"}

@app.get("/health/ready")
async def ready():
    if not model_loaded:
        raise HTTPException(503, "模型加载中")
    
    # GPU 健康检查
    if torch.cuda.is_available():
        try:
            mem = torch.cuda.memory_allocated() / 1e9
            total = torch.cuda.get_device_properties(0).total_memory / 1e9
            if mem / total > 0.97:
                raise HTTPException(503, "GPU 显存不足")
        except:
            raise HTTPException(503, "GPU 不可用")
    
    # 推理可用性检查
    try:
        model.generate("ping", max_tokens=1)
    except:
        raise HTTPException(503, "模型推理失败")
    
    return {"status": "ready", "model_loaded": model_loaded,
            "gpu_memory_used": f"{mem:.1f}GB"}
```

## 3. 自愈机制

```text
自动恢复流程：

  ① Liveness 检查失败 → K8s 自动重启 Pod（30s 内完成）
  ② Readiness 检查失败 → Service 摘除 Pod（10s 内完成）
  ③ OOM Kill → Pod 自动重启 + 内存限制上调
  ④ GPU 故障 → Node Problem Detector 检测 → 驱逐 Pod → 调度到健康 GPU 节点

人工介入的触发条件：
  → 同一 Pod 重启超过 5 次/小时
  → 所有 Pod 同时 Readiness 失败（可能是配置错误）
  → GPU 节点全部不可用
```

## 4. 优雅关闭

```python
import signal
import asyncio

class GracefulShutdown:
    def __init__(self, server):
        self.server = server
        self.shutdown_event = asyncio.Event()
    
    async def setup(self):
        loop = asyncio.get_event_loop()
        for sig in (signal.SIGTERM, signal.SIGINT):
            loop.add_signal_handler(sig, self._handle_signal)
    
    def _handle_signal(self):
        logger.info("收到关闭信号，开始优雅关闭...")
        asyncio.create_task(self._shutdown())
    
    async def _shutdown(self):
        # ① 停止接收新请求
        self.server.stop_accepting()
        logger.info("已停止接收新请求")
        
        # ② 等待现有请求完成（最多 30s）
        try:
            await asyncio.wait_for(
                self.server.wait_for_pending_requests(), timeout=30
            )
        except asyncio.TimeoutError:
            logger.warning("超时，强制关闭")
        
        # ③ 释放资源
        self.model = None
        torch.cuda.empty_cache()
        
        self.shutdown_event.set()
```
