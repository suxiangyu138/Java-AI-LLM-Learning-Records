## 2. 防线一：检索接地（代码）

```python
"""agent/retrieval.py — 带接地保证的检索工具"""
from langchain_core.tools import tool
from langchain.embeddings import OpenAIEmbeddings
from langchain_community.vectorstores import FAISS
from langchain.retrievers import ContextualCompressionRetriever
from langchain.retrievers.document_compressors import LLMChainExtractor


def build_grounded_retriever(vectorstore, reranker_model):
    """检索接地三件套：召回 → 重排 → 截断"""
    base = vectorstore.as_retriever(search_kwargs={"k": 20})   # ① 召回 20（宁多勿少）
    compressor = LLMChainExtractor.from_llm(reranker_model)    # ② 重排压缩（语义过滤）
    return ContextualCompressionRetriever(
        base_compressor=compressor, base_retriever=base
    )


@tool
def search_knowledge(query: str, retriever=None) -> str:
    """检索知识库。当用户询问业务知识时使用。返回带 [D编号] 引用的结果。"""
    docs = retriever.invoke(query)
    # ③ 引用编号注入：每个文档带稳定 ID（幻觉防线二的地基）
    chunks = []
    for i, doc in enumerate(docs[:5], start=1):     # 5 个高相关 > 20 个勉强
        chunks.append(f"[D{i}] {doc.page_content}")
    return "\n".join(chunks)
```

| 接地纪律 | 代码体现 |
|---------|---------|
| 信息密度优先 | `docs[:5]`（5 个高相关 > 20 个勉强） |
| 引用可追溯 | `[D{i}]` 编号与检索结果一一对应 |
| 重排过滤 | LLMChainExtractor（或纯 reranker） |

## 3. 防线二：强制引用（代码）

```python
"""agent/citation.py — 引用强制与伪造检测"""
import re

ALLOWED_PREFIX = "D"    # 引用编号必须来自系统注入的集合


def check_citations(output: str, allowed_ids: set[str]) -> tuple[bool, str]:
    """检查输出中的引用是否全部来自允许集合"""
    cited = set(re.findall(r"\[(D\d+)\]", output))
    fake = cited - allowed_ids
    if fake:
        return False, f"发现伪造引用 {sorted(fake)}，请重写并只使用给定引用"
    # 事实句无引用检查（简化：长度 > 20 的句子必须有引用）
    sentences = re.split(r"[。！？]", output)
    missing = [s for s in sentences if len(s) > 20 and not re.search(r"\[D\d+\]", s)]
    if missing:
        return False, "以下陈述缺少引用，请补充：\n" + "\n".join(missing[:3])
    return True, ""
```

## 4. 防线三：生成约束（prompt 纪律）

```python
SYSTEM_PROMPT = """你是企业知识助手。回答规则（铁律）：
1. 只基于给定文档回答，每个事实性陈述必须带引用 [D编号]。
2. 文档中没有答案时，直接回答"知识库中未找到相关信息"，不要编造。
3. 不确定时明确标注"（不确定）"。
4. 引用只能来自检索结果提供的编号，禁止自造。
5. 不要推断文档之外的信息。"""
```

| 纪律 | 作用 |
|------|------|
| 无据拒答 | 阻断编造（"未找到"是合法回答） |
| 引用强制 | 与防线二联动 |
| 置信度标注 | 暴露不确定性（Verbosity Signal 联动） |

> 💡 prompt 纪律是"软约束"——所以必须配防线二/四的"硬校验"。软硬结合，缺一不可。

```python
"""agent/verifier.py — 规则验证 + 可选多Agent验证"""
def rule_verify(output: str, retrieved: list, allowed: set[str]) -> dict:
    """零成本规则验证：返回各维度结果"""
    return {
        "fake_citation": not check_citations(output, allowed)[0],
        "has_unsupported_fact": has_unsupported_fact(output, retrieved),  # 语义级，用嵌入相似度
        "length_signal": len(output) > 2000 and "[D" not in output,       # 超长无引用 = 高嫌疑
    }


def should_deep_verify(rule_result: dict) -> bool:
    """规则验证不通过 → 触发深度验证（只对高风险子集花钱）"""
    return any(rule_result.values())
```

**深度验证（多 Agent 信息不对称，MARCH 模式）**：

```text
Solver   → 生成回答
Proposer → 拆解为原子命题（"北京温度是22℃"）
Checker  → 只看证据库 + 命题，不看 Solver 输出（隔离确认偏差）
         → 每个命题：证据支持 / 证据反对 / 无证据
```

## 7. Agent 循环中的落点

```text
用户请求
  → [工具层] 检索工具：召回 → 重排 → [D编号] 注入
  → [生成层] 模型（prompt 含无据拒答 + 引用纪律）
  → [循环层] 终止判断（无工具调用）
  → [验证层] 规则校验（引用/长度）→ 失败则重写 ≤2 次
  → [评估层] 高风险样本深度验证（多Agent 隔离）
  → [落库] 回答 + 引用 + 原始检索结果
  → [采样] 5-10% 进评估管线（USR/引用 F1，06 篇）
```

> 🎯 **核心要点**：幻觉治理工程 = 五道防线**各归其位**的代码。检查你的 Agent：检索工具带重排吗？回答强制引用吗？引用可回查吗？校验失败会重写吗？指标在跑吗？五问全"是"，幻觉治理才算落地。
