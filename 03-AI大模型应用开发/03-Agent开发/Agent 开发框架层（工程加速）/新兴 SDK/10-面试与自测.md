## 1. 面试题（10 题带答案范式）

> 面试高频题集中在三块：**轻量哲学**、**前沿范式**、**协议新进展**——新兴 SDK 的考察重点是"认知广度 + 判断力"。

### Q1：2026 年新兴 Agent 框架的核心趋势是什么？

**答案范式（从 prompt chains 到 execution runtimes）**：
```text
三个趋势：
① 重心从提示词链转向执行运行时——状态/检查点/可恢复执行成为一等公民
② 轻量哲学对抗重型框架——百行核心（PocketFlow）、sub-MB 运行时（Sulala）、
   <1K 行（smolagents），零依赖多语言移植
③ 安全/持久化/互操作从开发者自建变为运行时默认（策略内建/检查点内建/
   MCP+A2A 原生）
```

### Q2：轻量框架两派是什么？各自代表与选择？

**答案范式（代码执行 vs 配置驱动）**：
```text
代码执行派：smolagents（<1K 行，Agent 写 Python 执行）——能力上限高，
           需沙箱（E2B/Docker），适合多步推理/复杂逻辑
配置驱动派：@huggingface/tiny-agents（~50 行，JSON 配置 + MCP）——
           秒级上手、无沙箱（MCP 隔离即边界），适合快速 demo/简单自动化
选择：先配置驱动出 demo，需要代码执行/多步推理时升级代码执行派
```

### Q3：怎么评估一个新出现的 Agent 框架？

**答案范式（五问五查）**：
```text
五问（功能）：差异化真实吗？有生产证据吗？边界在哪？
             兼容（MCP/A2A/provider）如何？治理（沙箱/策略/检查点）内建吗？
五查（工程）：star/commit/issue 活跃度、许可证（商用红线）、
             安全审计、维护者（bus factor）、文档质量
警惕：刷星陷阱、基准宣称无独立验证、单人维护、轻量≠生产就绪
```

### Q4：Deer-Flow 2.0 是什么？为什么火？

**答案范式（字节 + 中间件链）**：
```text
字节跳动开源，2026 年 35.3k stars、24h 登顶 GitHub Trending
基于 LangGraph 的模块化多 Agent 编排：
单一主 Agent + 11 层中间件链（可插拔）+ 动态子 Agent（按需创建销毁）
+ 长期记忆 + 三档沙箱（本地/Docker/K8s）
火的原因：把多 Agent 编排问题"中间件化"，与主流框架差异化明显
生态信号：主流框架之上叠框架成为趋势
```

### Q5：什么是自进化 Agent（RLM）？Prime Agent 是什么？

**答案范式（Continual Harness）**：
```text
RLM = 递归语言模型：提示词/技能/记忆/子 Agent 是模型可 CRUD 的运行时状态
→ Agent 在任务循环中自我改进（成功方法写回技能库）
Prime Agent（Prime Intellect 开源）：持久 IPython REPL + Continual Harness
  + 后台守护（跨会话小时/天级）；宣称 ARC-AGI-3 95.5%（有争议，方向性参考）
判断：2026 属研究前沿——生产慎用；可借鉴"技能沉淀"思想
安全警告：模型可改自身提示词 = 攻击面扩展，无护栏不得投产
```

### Q6：2026 年"三协议栈"是什么？各自作用？

**答案范式（MCP/A2A/UCP 分工）**：
```text
MCP = Agent↔工具（纵向集成，事实标准，97M+ 月下载）
A2A = Agent↔Agent（横向集成，v1.0 稳定，150+ 组织，三云支持）
UCP = Agent 商务层（定价/计费/结算，成熟度低，观察）
分工一句话：MCP 管"够到系统"，A2A 管"Agent 间协作"，UCP 管"怎么付费"
```

### Q7：A2A v1.0 有什么关键进展？

**答案范式（里程碑 + 核心机制）**：
```text
进展：Linux Foundation 治理；与 IBM ACP 合并消除竞争标准；
      150+ 支持组织；三云原生（Azure/AWS Bedrock/Vertex）；
      生产部署（供应链/金融/保险/IT 运维）；v1.0 稳定规范
核心机制：Agent Card 发现（/.well-known/agent.json）+ JSON-RPC 2.0
          + Task 生命周期（submitted→working→completed/failed + input-required）
          + 类型化消息；v1.0 新增 Agent Card 加密签名与 gRPC
```

### Q8：百炼 CLI 是什么？它和 Claude Code 是什么关系？

**答案范式（平台能力工具化）**：
```text
百炼 CLI（modelstudioai/cli，2026-05-29 开源）= 阿里云平台能力 CLI 化：
一行命令接入 150+ 模型 + 知识库/记忆/联网搜索/应用编排
原生支持 Claude Code、Qoder、OpenClaw、Hermes 等 Agent 框架
与 Claude Code 的关系：不是替代，是"能力供给方"——
Claude Code 管编排，百炼 CLI 供能力（模型/知识库/搜索）
2026 趋势：本地 CLI Agent = 客户端，云平台 = 能力服务器
```

### Q9："策略内建"是什么意思？代表项目？

**答案范式（治理从包装到运行时）**：
```text
策略内建 = 护栏作为运行时组件，而非外层包装：
CUGA（IBM Research）：Intent Guard / Tool Approval / Tool Guide /
  Playbook / Output Formatter 内建于 harness
趋势同向：沙箱一等公民（Flue）、检查点默认（LangGraph/CrewAI 2026）、
          协议原生（MAF/ADK）
含义：安全/持久化/互操作从"开发者自建"变为"运行时默认"
```

### Q10：新兴框架那么多，怎么避免踩坑？

**答案范式（六坑清单）**：
```text
① 刷星陷阱：高 star 无实质维护 → 看 commit/issue 响应
② 宣称迷信：基准分数当生产证据 → 独立复现 + 真实工作流
③ 单人依赖：核心维护者退出即停更 → 评估 bus factor
④ 体量迷信："100 行"当"生产就绪" → 轻量≠可靠
⑤ 生态错觉：框架火=生态全 → 确认集成真实存在
⑥ 无许可：不能商用 → 商用前逐条确认
总原则：生产主干默认主流框架，新框架用于学习/试点/借鉴
```

### 自测答案速查

2. 代码执行派（smolagents）/ 配置驱动派（tiny-agents）
3. 100 行零依赖零锁定；7 种语言（TS/Java/C++/Go/Rust/PHP 等）
4. JSON 配置（agent.json：model/provider/MCP）；`npx @huggingface/tiny-agents run`
5. CodeAgent（写代码执行）+ ToolCallingAgent（JSON 工具调用）
6. 单一主 Agent + 11 层中间件链 + 动态子 Agent（+ 长期记忆/三档沙箱）
7. 2026-05-29；modelstudioai/cli
8. Google（2025-04，50+ 参与方）；Linux Foundation
9. Recursive Language Model：提示词/技能/子 Agent 成为模型可 CRUD 的运行时状态
10. 持久 IPython REPL + Continual Harness（+ 后台守护）
11. 方向性参考：基准设置与独立验证存疑，用真实任务验证
12. MCP=工具（纵向）、A2A=协作（横向）、UCP=计费（商务）
13. Agent Card 发现 / JSON-RPC 2.0 / Task 生命周期 / 类型化消息（+ 签名与 gRPC）
14. UCP=统一计费协议（成熟度低，观察）；OSSA=Agent 清单规范 v0.4（部署时声明）
15. 差异化真实吗/生产证据/边界/兼容/治理内建
16. 活跃度/许可证/安全审计/维护者/文档质量
17. < 3.5 不采用；3.5-4 试用；≥4 可立项
18. 主流的补充：学习/试点/借鉴机制；生产主干默认主流框架
19. 刷星/宣称迷信/单人依赖/体量迷信/生态错觉/无许可

## 4. 核心要点

> 🎯 **核心要点**：
> 1. 面试主战场：**趋势判断**（execution runtimes）、**轻量哲学**（两派）、**协议进展**（A2A v1.0/三协议栈）
> 2. 判断力是加分项：ARC-AGI 宣称方向性参考、刷星陷阱、轻量≠生产就绪
> 3. 国产动态要会说：Deer-Flow 2.0、百炼 CLI、Coze 3.0 本地 Agent 接入
> 4. 本模块毕业标准：**能建立"雷达 + 评估"心智——关注新兴生态但不被噪音带走，生产决策回到主流框架与真实验证**
