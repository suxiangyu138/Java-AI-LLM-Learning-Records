## 1. 面试题：框架选择档

> 考察点：有没有"选型思维"——答"为什么选"比答"用了什么"重要。每题 30-60 秒。

| # | 题目 | 答题要点 |
|:---:|------|---------|
| 1 | 2026 主流单 Agent 框架有哪些？各自范式是什么？ | 五大：LangGraph（状态机）、OpenAI Agents SDK（轻量原语）、Smolagents（代码执行）、Pydantic AI（类型安全）、Claude Agent SDK（完整 harness）（01 篇） |
| 2 | 什么场景选 LangGraph？ | 复杂状态流、分支循环、暂停恢复（HITL）、持久化；"第 7 步挂了怎么办"有原生答案（02 篇） |
| 3 | 什么场景选 Pydantic AI？ | 结构化输出/类型安全优先、40+ 供应商可移植、原生 MCP；多 Agent 编排薄是短板（05 篇） |
| 4 | Smolagents 的代码执行范式解决什么问题？ | 多步任务省 ~30% 步数与调用；代码可读可审计；代价是沙箱安全责任（04 篇） |
| 5 | OpenAI Agents SDK 为什么是"轻量"的？ | 最小原语集（Agent/Handoffs/Guardrails/Sessions/Tracing），复杂流程自编排；Assistants API 已弃用（03 篇） |
| 6 | Claude Agent SDK 与 API Tool Runner 的区别？ | SDK 是 Claude Code 打包为库（内置工具+完整 harness）；Tool Runner 是 Client SDK 的 beta 循环辅助（无内置工具）（06 篇） |
| 7 | 选框架先看什么？ | 范式匹配 > 框架名气；再比四维能力深度（HITL/持久化/可观测/MCP）（01/08 篇） |
| 8 | 2026 框架选型共识是什么？ | 无单一赢家；生产多框架组合；MCP/A2A 协议让切换成本下降（01 篇） |

## 2. 面试题：机制深潜档

> 考察点：真用过。回答要求"机制 → 为什么这么设计 → 坑在哪"。

| # | 题目 | 答题要点 |
|:---:|------|---------|
| 1 | LangGraph checkpointing 怎么工作？生产用哪个后端？ | 每节点转移保存状态（thread_id 索引）；InMemory 开发/Sqlite 低量/PostgresSaver 生产；resume 必须同 config+thread_id；状态合并不是替换（02 篇） |
| 2 | LangGraph 的 HITL 四决策是什么？ | approve/reject/edit/respond；interrupt() 传 JSON payload，Command(resume=...) 恢复（02 篇） |
| 3 | OpenAI Agents SDK 的 Sessions 有哪些后端？ | SQLite/Redis/SQLAlchemy/加密/托管；Redis 多实例共享；sessions 管连续性不管长期记忆（03 篇） |
| 4 | Guardrails 的 tripwire 机制？ | 护栏触发 → 抛异常中止运行；输入护栏可 run_in_parallel；是第二道防线非安全替代（03 篇） |
| 5 | Smolagents 本地沙箱的五层防护？ | import 白名单/函数白名单/dunder 保护/操作数 1000 万上限/循环 100 万上限；AST 解释不用 eval；沙箱非自动（04 篇） |
| 6 | Pydantic AI v2 的 Capability 是什么？ | 工具+hooks+指令+模型设置打包成可插拔类；AgentSpec/from_file；Thinking/WebSearch/MCP/Durability 等 40+（05 篇） |
| 7 | Claude Agent SDK 的权限六模式？ | default/acceptEdits/plan/dontAsk/auto/bypassPermissions；allowed/disallowed_tools 协同（06 篇） |
| 8 | ResultMessage 的 subtype 有哪些？ | success/error_max_turns/error_max_budget_usd/error_during_execution/error_max_structured_output_retries；result 只在 success 有（06 篇） |
| 9 | 框架的上下文管理共识？ | 窗口内不重置；前缀缓存；自动压缩；工具按需加载；子 Agent 隔离（07 篇） |
| 10 | 五框架的终止条件都怎么配？ | 正常 end_turn + max_turns/max_budget + refusal + pause_turn；生产必须设上限（07 篇） |

## 3. 面试题：架构设计档

> 考察点：组合与迁移。追问"为什么不用另一个框架"。

| # | 题目 | 答题要点 |
|:---:|------|---------|
| 1 | 设计一个需要人工审批的退款 Agent，选什么框架？ | LangGraph（interrupt 一等公民）或 Claude Agent SDK（PreToolUse hook + canUseTool）；审批门只拦高影响（02/06/08 篇） |
| 2 | 现有 LangChain 老项目怎么迁移到新框架？ | 五步：抽象工具层 → 评估基线 → shadow → canary 5% → 全量+热备；无基线不迁移（09 篇） |
| 3 | 怎么做到"换框架不换业务代码"？ | 工具 MCP 化 + 业务进确定性代码 + 适配器模式（ADR）；框架只管循环（09 篇） |
| 4 | 多框架组合怎么设计？ | 编排层/工具层/输出层异构：LangGraph 编排 + Pydantic AI 结构化输出 + MCP 工具（09 篇） |
| 5 | 框架选型怎么记录决策？ | ADR：现状痛点/候选对比/理由与代价/迁移路径/验收标准（09 篇） |
