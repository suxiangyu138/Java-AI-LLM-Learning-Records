## 4. 核心概念速查

| 概念 | 一句话定义 |
|---|---|
| 搜索（Search） | 用关键词/语义查询从互联网检索相关信息，返回候选链接与摘要 |
| 抓取（Fetch/Extract） | 获取搜索结果页面的原始内容并解析为 LLM 可用文本（Markdown/纯文本） |
| Grounding | 把模型输出锚定到可验证来源（URL/引用），降低幻觉 |
| 查询改写（Query Rewriting） | 把 Agent 的子任务意图改写为搜索引擎友好的查询串 |
| SERP | 搜索引擎结果页；SERP API = 返回 Google/Bing 结果 JSON 的接口 |
| 独立索引 | 不依赖 Google/Bing 的自建网页索引（Brave ~300 亿页） |
| 语义搜索 | 基于 Embedding 相似度而非关键词匹配的检索（Exa 为代表） |
| 动态过滤 | 搜索工具自动写代码过滤结果，只把相关内容送进上下文（Claude 2026-02 新特性） |
| 深度研究（Deep Research） | 多轮搜索+抓取+验证+写作的自主研究 Agent 模式 |
| 提示注入（网页） | 网页中隐藏指令篡改 Agent 行为；2026 年已出现大规模武器化（恶意负载 32% 激增） |
| SEO 投毒 | 攻击者优化恶意页面排名，让 Agent 检索到带注入指令的内容 |
| 元搜索（Metasearch） | 聚合多个搜索引擎结果（SearXNG 聚合 70+ 引擎） |
| 内容信任评分 | 对来源可信度打分（域名权威/交叉验证/时新性），决定采信权重 |

## 5. 2026 生态基准

> 📅 基准窗口：2026-08。版本与事实以各模块【参考来源】为准。

- **市场剧变**：Bing Search API 2025-08-11 退役（Azure AI Foundry "Grounding with Bing" 替代，~$35/千次）；Tavily 被 Nebius 收购（2026-02-10，~$2.75 亿）；Google 2025-12 起诉 SerpApi（DMCA）。
- **原生搜索工具**：Claude `web_search_20260209`/`web_search_20260318`（动态过滤 + response_inclusion 降本）；OpenAI Responses API 内建 `web_search`；Gemini Grounding（dynamic retrieval + EnterpriseWebSearch + Parallel Web Search）。
- **动态过滤基准**：Claude Sonnet 4.6 BrowseComp 33.3%→46.6%、DeepsearchQA F1 52.6%→59.4%，**准确率 +11%、输入 token -24%**。
- **深度研究榜单**（DeepResearch Bench RACE）：Tavily 52.44 > Gemini 2.5 Pro 49.71 > OpenAI 46.45 > Claude 45；成本上 Perplexity Sonar Deep Research 最优（~$0.06/次、70.5% DRACO、3 分钟）。
- **安全态势**：间接提示注入已大规模武器化（Google Threat Intel：恶意 IPI 负载 2025-11 至 2026-02 增 32%）；Unit 42 归纳 7 类攻击意图；"LLM SEO"记忆投毒成为新攻击面。
- **开源自建**：SearXNG（聚合 70+ 引擎）+ 多个 MCP server（searxng-mcp 生态活跃）；search 与 extract 分离成为推荐架构（Brave+Firecrawl / Exa+Jina Reader 组合）。
