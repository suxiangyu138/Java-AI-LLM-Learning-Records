# 搜索工具集成实战

> 教程：把搜索能力接入 Agent——LangChain/LangGraph 工具、MCP server、原生工具，附代码与生产规范。写完可直接落地。

## 1. 接入路径总览

```text
路径 A：原生工具（推荐）——Claude web_search / OpenAI web_search / Gemini grounding
路径 B：框架工具——LangChain TavilySearchResults / ExaSearch / BraveSearch
路径 C：MCP server——Claude Desktop websearch / searxng-mcp / Tavily MCP
路径 D：自研封装——requests + 搜索 API + 提取（Firecrawl/Jina Reader）
```

## 2. LangChain 集成（Python）

```python
from langchain_community.tools import TavilySearchResults, BraveSearch, ExaSearchResults
from langchain_openai import ChatOpenAI
from langchain.agents import create_openai_functions_agent, AgentExecutor

# Tavily：LLM-ready 默认
search = TavilySearchResults(max_results=5, search_depth="basic")

# 组合两个供应商（生产推荐双供应商）
tools = [
    search,
    BraveSearch.from_api_key(api_key="...", search_kwargs={"count": 5}),
]

agent = create_openai_functions_agent(ChatOpenAI(model="gpt-5"), tools)
executor = AgentExecutor(agent=agent, tools=tools, verbose=True)
print(executor.invoke({"input": "2026 年最流行的 Java 版本是什么？"}))
```

## 3. MCP 集成（一行接入 Claude 系）

```bash
# Claude Desktop / Claude Code：内置 websearch MCP（支持 Brave/Tavily/Exa/自定义）
claude mcp add websearch --  # 内置 server

# SearXNG 自建（隐私优先）
claude mcp add searxng -- npx -y searxng-mcp \
  --searxng-url http://localhost:8080

# Tavily 官方 MCP
claude mcp add tavily -- npx -y tavily-mcp --api-key $TAVILY_API_KEY
```

MCP 工具命名（searxng-mcp 系列常见）：`search`（单查）、`search_many`（并行扇出）、`search_and_fetch`（搜索+抓取一步）、`fetch_url`（抓取）、`research`（多轮研究）。

## 4. 自研封装模板（search 与 extract 分离）

```python
import httpx, time, hashlib, json

SEARCH_API = "https://api.tavily.com/search"
EXTRACT_API = "https://api.jina.ai/reader"   # 提取层独立

def agent_search(query: str, domain_filter: list[str] | None = None) -> dict:
    """带缓存的搜索+提取封装"""
    cache_key = hashlib.sha256(query.encode()).hexdigest()
    if cached := redis.get(cache_key):
        return json.loads(cached)             # 1. 缓存优先

    r = httpx.post(SEARCH_API, json={
        "query": query, "search_depth": "basic",
        "max_results": 5, "include_answer": True,
        "include_domains": domain_filter,     # 2. 域名白名单
    }, timeout=10)
    results = r.json()

    extracted = []
    for item in results.get("results", [])[:3]:       # 3. 只提取前 3 条
        try:
            page = httpx.get(f"{EXTRACT_API}/{item['url']}", timeout=15)
            extracted.append({"url": item["url"], "content": page.text[:4000]})
        except Exception:
            extracted.append({"url": item["url"], "content": item.get("content", "")})

    payload = {"answer": results.get("answer"), "sources": extracted}
    redis.set(cache_key, json.dumps(payload), ex=300)  # 4. 5 分钟缓存
    return payload
```

## 5. 原生工具接入（Claude Messages API）

```python
# Claude 原生 web_search（多步研究模式：pause_turn 续跑）
import anthropic

client = anthropic.Anthropic()
messages = [{"role": "user", "content": "调研 2026 年 RAG 向量数据库选型"}]

for _ in range(10):                       # max_uses 上限内的循环
    resp = client.messages.create(
        model="claude-sonnet-4-6",
        max_tokens=4096,
        tools=[{"type": "web_search_20260209"}],
        messages=messages,
    )
    messages.append(resp.model_dump(exclude_none=True))  # encrypted_content 原样回传
    if resp.stop_reason != "pause_turn":
        break
```

## 6. 生产规范清单

| 项 | 规范 |
|---|---|
| 缓存 | 结果级缓存（Redis，TTL 按新鲜度：新闻 5min/稳定 24h）；`external_web_access: cached` 优先 |
| 限流 | 服务端配额独立于模型配额；429 退避重试（指数+抖动），客户端重试无效时停手 |
| 并发 | 多查询并行（asyncio.gather / ToolNode），单任务搜索上限（Claude `max_uses`） |
| 域名策略 | `allowed_domains` 白名单 + `blocked_domains` 黑名单；两者勿同用（400） |
| 内容信任 | 提取前过滤：已知恶意域/可疑 TLD；提取后交叉验证（多源一致才采信） |
| Token | 只把"相关片段"入上下文（动态过滤/`response_inclusion="excluded"`）；引用不计 token |
| 超时 | 搜索 10s / 提取 15s 超时；总任务超时上限 |
| 审计 | 记录查询、来源、采信决策；Otel/SIEM |

## 7. 易错点

- 把 SERP 摘要当答案：摘要可能已过期或被 SEO 污染——**必须 fetch 原文**
- 无限重试 `too_many_requests`：服务端配额，重试无效，退避等待
- 多轮会话丢 `encrypted_content`：必须原样回传
- 单供应商：索引/限流/失败模式单一，一挂全挂
- 结果直接入上下文不过滤：投毒页面直接进 prompt（见 [08](08-搜索安全与内容信任.md)）
- 忽略 robots.txt/隐私：自建爬虫要有礼貌（robots、限速、可识别 UA）

## 面试速记

1. 四条接入路径：原生工具（推荐）/框架工具/MCP/自研封装。
2. 生产模板六步：缓存→白名单→只提取 top-N→多源交叉验证→截断入上下文→审计。
3. LangGraph 四节点：rewrite → search（并行）→ verify → answer。
4. MCP 一行接入：`claude mcp add websearch` / searxng-mcp / tavily-mcp。
5. 易错三件套：SERP≠答案、服务端限流别重试、多轮必回传 encrypted_content。
