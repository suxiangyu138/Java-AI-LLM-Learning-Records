## 4. 核心概念速查

| 概念 | 一句话定义 |
|---|---|
| 沙盒（Sandbox） | 将不可信代码与宿主隔离的执行环境，限制文件/网络/进程/资源访问 |
| 信任边界 | 数据/代码可信度发生变化的边界；沙盒就是 Agent 体系最重要的信任边界 |
| 纵深防御 | 多层隔离叠加：OS 原语 + 沙箱 + 网络策略 + 权限 + 审计，单层失效不致命 |
| 最小权限 | 沙盒只授予完成任务所需的最小能力（白名单路径、白名单域名、配额内资源） |
| namespace | 七种进程视图隔离（mount/PID/net/UTS/IPC/user/time），"看不见" |
| cgroup | 资源配额（内存/CPU/PID/IO），"用不完" |
| seccomp-bpf | 系统调用门禁，需 `NO_NEW_PRIVS`，"不许调" |
| LSM | 强制访问控制（AppArmor/SELinux/Landlock），"不许碰" |
| 容器隔离 | namespace+cgroup 共享宿主内核，启动 <1s，内核漏洞即逃逸面 |
| gVisor | 用户态内核（Sentry）拦截系统调用，隔离强于容器、轻于 VM，启动 50-100ms |
| 微虚拟机 | Firecracker 等 KVM 微VM，每沙箱独立内核，启动 ~125ms、内存开销 ~5MB |
| 语言级沙箱 | WASM/QuickJS/Pyodide 等解释器层隔离，微秒级启动，能力受限 |
| 冷启动/温池 | 沙箱创建耗时 / 预创建沙箱池消除冷启动 |
| 快照恢复 | 冻结沙箱内存+磁盘状态，之后秒级恢复 |
| 提示注入 | 恶意输入（文件/网页/工具输出）篡改 Agent 指令，是沙箱攻防的通用入口 |
| 沙箱逃逸 | 沙箱内代码突破隔离边界获得宿主权限 |
| DNS 隧道 | 用 DNS 查询把数据编码外传的隐蔽外泄通道，常被网络策略漏掉 |

## 5. 2026 生态基准

> 📅 基准窗口：2026-08。关键技术动态与版本号以各模块【参考来源】为准。

- **行业共识**：共享内核容器不足以承载 LLM 生成代码——"超大规模厂商都拿最强隔离原语对准 AI，没有一家选容器"；2026-05 微软 Semantic Kernel 披露提示注入达宿主级 RCE。
- **隔离光谱**：Docker/容器（弱）→ gVisor 用户态内核（中）→ Firecracker 微VM（强，业界默认）→ 机密计算（前沿未实用）。
- **主流产品线**：E2B（Firecracker，1B+ 沙箱）、Modal（gVisor+GPU）、Daytona（有状态容器）、Vercel Sandbox（Firecracker）、Cloudflare（容器+边缘）、AWS Lambda MicroVMs（2026-06-22 发布）。
- **Agent 平台侧**：Claude Code 多级沙箱（sandboxed Bash/sandbox-runtime/容器/VM）；OpenAI Codex 三策略（read-only/workspace-write/danger-full-access）+ Windows 自研沙箱；Claude Managed Agents 自托管沙箱 2026-05-19 公测 + MCP Tunnels。
- **2026 高频漏洞**：Claude Code SOCKS5 空字节注入与符号链接逃逸（CVE-2026-39861）、AWS AgentCore DNS 隧道、OpenClaw 四连环（CVSS 9.6）、Copilot 远程提示执行（CVE-2026-32193）、JupyterLab 扩展白名单绕过（CVE-2026-42266）。
- **开源自建**：OpenSandbox（阿里，CNCF Landscape，批量 100 沙箱 0.92s）、kubernetes-sigs/agent-sandbox（CRD + WarmPool）、agent-sandbox/agent-sandbox（E2B 协议兼容）。
