# 安全攻防案例与加固基线

> 2026 年沙箱漏洞的规律：提示注入是万能入口，过滤器语法绕过与 DNS 外泄是高频漏洞形态——隔离声明必须按信道验证。

## 1. 攻击链通用模型

```text
恶意输入（网页/文件/工具输出）
  → 间接提示注入篡改 Agent 意图
  → 沙箱内执行恶意代码/命令
  → [逃逸] 突破隔离边界
  → 凭据窃取 / 数据外泄（DNS 隧道等）
```

**2026 规律**：漏洞不在"沙箱有没有"，而在"沙箱的哪个信道漏了"——文件系统、网络过滤器、DNS、进程、MCP IPC 每一条都是独立攻击面。

## 2. 2026 典型漏洞案例

| 漏洞 | 载体 | 根因 | 修复 |
|---|---|---|---|
| **Claude Code SOCKS5 空字节注入** | 网络沙箱 | 出站白名单代理被 `\x00` 截断 hostname 绕过（暴露 2025-10-20 ~ 2026-03-31，约 5.5 个月） | v2.1.88 静默修复，无 CVE |
| **Claude Code 符号链接逃逸（CVE-2026-39861，High）** | 文件沙箱 | 沙箱内可建指向区外 symlink，宿主进程跟随写入（可经提示注入触发） | 2.1.64 自动更新 |
| **AWS AgentCore DNS 隧道** | 网络策略 | 允许出站 DNS → 把 SSN 逐字符编码为 DNS 子域查询外泄（**零点击**，间接注入触发） | 已修复 |
| **OpenClaw 四连环** | 链式利用 | TOCTOU 写逃逸（CVE-2026-44112，9.6）+ heredoc 环境变量泄露（CVE-2026-44115，8.8）+ MCP loopback 提权（CVE-2026-44118，7.8）+ symlink 读逃逸（CVE-2026-44113，7.7）；6.5 万-18 万公网实例暴露 | 2026-04 全部修复 |
| **Snowflake Cortex CLI 进程替换** | 命令校验 | `<( )` 进程替换表达式未校验绕过审批；间接注入设标志 → **沙箱外**执行恶意软件（下载+运行，用受害者活跃凭据） | v1.0.25（2026-02-28） |
| **Copilot 远程提示执行（CVE-2026-32193，8.8）** | 链式利用 | 隐形 Word 注入文本 → 绕过护栏提权 → AKS 路径穿越 → `LD_PRELOAD` 逃逸宿主 → 双向交互 shell | 路径穿越已修，RPE 漏洞类未根除 |
| **Langroid eval() 清洗不全（CVE-2026-54769）** | 语言级 | `__builtins__` 未从 globals 清除 → `__import__('os').system()` RCE | >0.65.1 |
| **SGLang ZMQ 无鉴权（CVE-2026-3059/3060）** | 服务暴露 | broker 绑全接口无认证，crafted pickle 消息 RCE，泄露模型权重与训练数据 | 修复（曾数月无人理会披露） |
| **JupyterLab 扩展白名单绕过（CVE-2026-42266，8.8）** | 扩展管理 | PyPI 扩展管理器绕过 allow-list 装任意包执行代码 | 4.5.7 |
| **Flowise 无沙箱 eval（CVE-2026-41265）** | 语言级 | Airtable_Agents 类执行 LLM 生成脚本无沙箱 → 提示注入 RCE | 3.1.0 |
| **LangSmith baseUrl 校验缺失（CVE-2026-25750）** | 配置注入 | 未校验 baseUrl 参数 → 凭据外泄信道 | 0.12.71 |

## 3. 高频模式总结

| 模式 | 本质 | 防御 |
|---|---|---|
| 过滤器被语法绕过 | SOCKS5 空字节、进程替换 `<( )`、heredoc 展开 | 过滤逻辑用**规范化 parser**，不只正则；枚举参数形态 |
| 符号链接逃逸 | 文件系统语义（TOCTOU/symlink swap） | 可写区禁 symlink；跟随前 resolve+校验；`openat2` 等原子操作 |
| DNS 外泄 | 网络信道遗漏（"完全隔离"声明外的信道） | DNS 出站过滤（Route53 Resolver Firewall/Azure DNS 防火墙）；ML 隧道检测（实测 F1 99.7%）；异常 DNS 入 SIEM |
| 链式利用 | 单点修复≠安全 | 纵深防御 + 最小权限 + 凭据短时化 + 行为审计 |
| 语言级清洗不全 | 黑名单不完备（`__builtins__` 等） | **不可信代码不上语言级沙箱**（见 [05](05-WASM与语言级沙箱.md)） |
| 元数据端点 SSRF | 云网络（169.254.169.254 / 100.100.100.200） | iptables/安全组显式丢弃；断网沙箱天然免疫 |
| MCP/IPC 提权 | 沙箱外 IPC 通道 | MCP server 沙箱化（Wassette）；loopback 端口最小化 |

## 4. 加固基线（生产七件事）

1. **网络**：出站默认拒绝；白名单域名 + 代理桥接（规范化 parser 过滤）；**DNS 出站过滤**；丢弃云元数据端点
2. **权限**：最小权限 IAM；无宽泛 S3/Secrets 读；**canary 凭据 + honey 路径**；凭据短时化、网络边界注入、沙箱内不落盘
3. **文件**：只读根 + 白名单可写；保护路径递归只读（`.git`/凭据目录）；**禁符号链接**；大文件流式
4. **资源**：内存/PID/CPU 配额绑定会话（`pids.max` 512 防 fork 炸弹）
5. **审计**：OTel 全量日志（prompt、工具调用、执行结果、网络 allow/deny 事件）；审计进 SIEM；**异常 DNS 告警**
6. **补丁**：沙箱组件升级即补丁（Claude Code ≥2.1.88、JupyterLab ≥4.5.7、Flowise ≥3.1.0、Langroid >0.65.1、Cortex ≥1.0.25）
7. **人审**：高风险操作人工确认；确认-执行模式（一次性令牌）；免密模式（dangerously-skip-permissions）必须套容器/VM 层隔离

## 5. 监控信号

| 信号 | 含义 |
|---|---|
| 异常 DNS 查询（高熵子域/长串） | DNS 隧道嫌疑 |
| 沙箱内进程尝试读 `/proc/1/root`、`/etc/shadow` | 逃逸侦察 |
| 出站连接至未知地域 IP | 数据外传 |
| 沙箱外进程被沙箱进程 ptrace | 横向渗透 |
| 同一账号沙箱批量创建后立即销毁 | 挖矿/清洗行为 |

## 面试速记

1. 2026 漏洞三规律：提示注入万能入口、过滤器语法绕过、DNS 是常漏信道。
2. 经典链：间接注入 → 沙箱执行 → 逃逸 → 凭据 → DNS 外泄。
3. 加固七件事：出站白名单+DNS 过滤、最小权限+短时凭据、只读根+禁 symlink、资源配额、OTel 审计、及时补丁、人审高险。
4. 隔离声明按信道验证——"完全隔离"通常指文件系统，不代表 DNS/网络。
5. 2026 明星案例：Claude Code SOCKS5 空字节（过滤器绕过）、AWS AgentCore DNS 隧道（信道遗漏）、OpenClaw 四连环（链式）。
