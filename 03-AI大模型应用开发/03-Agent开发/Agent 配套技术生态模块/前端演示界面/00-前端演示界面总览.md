## 4. 核心概念速查

| 概念 | 一句话定义 |
|---|---|
| 演示界面（Demo UI） | 把 Agent 的能力以可交互形式呈现给用户/评审/客户的最小界面 |
| SSE（Server-Sent Events） | HTTP 上的单向服务端推送；LLM 流式输出的事实标准协议 |
| WebSocket | 全双工长连接；仅当需要"客户端中途回写"（取消/审批/语音）时才值得升级 |
| 打字机效果 | 逐 token 渲染回复，由后端流式 + 前端增量渲染共同实现 |
| 渐进式披露（Progressive Disclosure） | 默认只显示结论，工具调用/思考过程折叠一层、点击展开 |
| Agent 流事件 | 结构化流事件：token / thinking / tool_call / error / done，而非裸文本块 |
| AG-UI 协议 | 跨框架的 Agent 流事件标准（REASONING_* / TOOL_CALL_* / STATE_*，走 SSE） |
| 工具调用卡片 | 显示工具"执行中/成功/失败+耗时"的状态卡，替代原始 JSON |
| 思考块（Thinking Block） | 与最终答案区分渲染的模型推理过程，可折叠、可隐藏 |
| 控制平面（Control Plane） | UI 不只是聊天记录，还能中断、审批、回放、分支（HITL） |
| RAG 引用（Citation） | 答案中标出的可点击来源，是 RAG 界面的信任核心 |
| rerun 模型（Streamlit） | 脚本自上而下重跑渲染 UI，状态靠 session_state 保存 |
| Chat Profile | Chainlit 中同一界面切换不同模型/提示词配置的入口 |
| 会话分叉（Fork） | 从历史某条消息分出新对话分支探索，Open WebUI 0.11 主打能力 |
| 成品 UI | 开箱即用的完整聊天界面产品（Open WebUI/LobeChat），无需写前端 |

## 5. 2026 生态基准

> 📅 基准窗口：2026-08。版本与事实以各模块【参考来源】为准。

- **协议层**：SSE 是 LLM 流式默认（OpenAI/Anthropic/Gemini 全线 text/event-stream）；WebSocket 仅双向需求（取消/审批/语音/多 Agent 协调）；生产推荐"SSE 读 + HTTP POST 写"混合模式。缓冲是 SSE 第一大坑（X-Accel-Buffering: no）。
- **Python 三件套**：Streamlit 1.59.0（2026-07-06，chat_input 新增 submit_mode 与文件粘贴、st.write_stream 支持 OpenAI Responses API、实验性 st.App ASGI 入口）；Gradio 6.20.0（6.x 重写 Svelte 前端、MCP 集成、HTML 组件可自定义 UI）；Chainlit 2.11.1（2026-04-22，2025-05 起社区维护，copilot 侧边栏、MCP 需 2.7+ 显式开启）。
- **Agent 过程可视化成为标配**：AG-UI 协议跨框架统一（Java/Flutter/Vercel 均有实现）；LangChain 前端按 channels/namespaces 订阅类型化流事件；@ant-design/agentic-ui、agentkit-ui 等组件库提供现成"工具卡片/思考链/任务列表"。
- **成品 UI 大版本潮**：Open WebUI 0.11（2026-08，"最大版本"：子 Agent 后台并行、会话分叉、界面全面改版）；LobeChat v2.1.x（多 Agent 编排、Bot 平台支持微信）；Dify 1.16.0/1.16.1（2026-07-19：原生 Agent + Linux 沙箱、Agent v2 节点、DSL 0.7.0、GPT-5.6 默认 Responses API）；Marimo 0.23.12（2026-07-01，marimo pair 让 Agent 直接驻进笔记本）。
- **前端框架**：Vercel AI SDK 7（DirectChatTransport 直连 Agent、useChat 工具审批流、DevTools 本地调试）；React 19/Next.js 15 为事实标准，Vue/Svelte 有官方适配。
- **共识**：Agent 界面"透明 vs 简洁"之争已收敛为渐进式披露；前端定位从"聊天记录渲染器"升级为"控制平面"（中断/检查点/分支/审批）。
