# 生产实践与面试冲刺

> 收官篇：把 01-09 收敛成可执行的落地清单与面试弹药。2026 生产基线：**五 rail 全覆盖、分类器专用化、评测用 LODO、治理走四支柱、权限零常设**——护栏是确定性控件，但安全是系统行为。

## 1. 生产落地清单（上线前逐项打勾）

### 1.1 拦截点覆盖

| 检查项 | 标准 |
|---|---|
| Input rail | 注入检测 + PII 脱敏，热路径 5-15ms |
| Retrieval rail | 检索块源验证 + 隔离标记 |
| Execution rail | 工具授权 + 参数校验 + 风险分级（Tool 08 篇衔接） |
| Output rail | 幻觉 + 毒性 + 格式 + 输出 PII |
| Dialog rail | 话题边界 + 流程控制（对话型 Agent） |
| 记忆护栏 | 写入防投毒 + 读出查注入 |

### 1.2 分类器与阈值

| 检查项 | 标准 |
|---|---|
| 分类器选型 | 专用分类器（Llama Guard 3/ShieldGemma/Aegis）；弃通用毒性过滤 |
| 间接注入防线 | 架构隔离优先（源验证/工具校验），分类器兜底 |
| 阈值校准 | 目标分布 heldout 数据校准，非默认 0.5 |
| 延迟分层 | 规则 → 轻分类器 → 模型判断，成本递增 |
| 数据边界 | 先定"能否出内网"再选自托管 vs 托管 API |

### 1.3 编排与语义

| 检查项 | 标准 |
|---|---|
| 护栏进循环 | 一等执行逻辑，所有边界覆盖 |
| 执行语义 | 静默/回退/Tripwire/人工四态按风险选 |
| 护栏即反馈 | 检测→修正回喂→重检，上限 2-3 次 |
| 预算 | 全栈护栏只给不可逆动作 |
| 记忆集成 | 写入读出双检查 |

### 1.4 评测与治理

| 检查项 | 标准 |
|---|---|
| 评测协议 | LODO/heldout 评估，三件套同报 |
| 逃逸闭环 | 线上样本 → 评测集 → 重训 → CI 回归 |
| 权限治理 | 零常设 + JIT + 毒性组合排查 |
| 审计 | 动作/交接/system prompt 修改全留痕 |
| 合规 | EU AI Act Article 50 透明度义务已落实 |
| 红队 | 构建期对抗样本集进 CI |

## 2. 十二大避坑

| # | 坑 | 后果 | 解法 |
|---|---|---|---|
| 1 | 只做输入输出两闸 | Agent 中间动作逃逸 | 五 rail 全覆盖（01 篇） |
| 2 | 通用毒性过滤凑合 | 礼貌越狱全漏 | 专用分类器（05 篇） |
| 3 | 输入路径用 LLM 判断 | 延迟炸弹 | 规则/轻分类器热路径（02 篇） |
| 4 | 默认阈值 0.5 | 工作点非业务最优 | 分布校准（08 篇） |
| 5 | 只报拦截率 | 高 FPR 毁产品不自知 | 三件套同报（08 篇） |
| 6 | 信任厂商基准 | AUC 虚高 8.4 点 | LODO/heldout 验证（08 篇） |
| 7 | 检测后继续循环 | 攻击借后续步骤完成 | Tripwire 中断语义（07 篇） |
| 8 | 拦截=终点 | 用户拿到空响应 | 护栏即反馈（03 篇） |
| 9 | 记忆不设防 | 投毒跨会话生效 | 写入读出双检查（07 篇） |
| 10 | 权限先宽后收 | 爆炸半径失控 | 先收缩再部署（09 篇） |
| 11 | 护栏无遥测 | 无法改进与审计 | 决策全留痕（07 篇） |
| 12 | 评测一次管一年 | 攻击进化后护栏失效 | 逃逸闭环持续（08 篇） |

> 🎯 核心要点：12 坑的根因是三个——**覆盖不全（1-2、9-10）、决策粗糙（3-6、8）、反馈缺失（7、11-12）**。按 01/05/07/08/09 篇规范做，12 坑自动消失。

## 3. 指标体系

| 指标 | 计算 | 目标 |
|---|---|---|
| 绕过率 | 攻击通过/攻击总数 | 按风险级定（高危趋 0） |
| FPR | 良性误拦/良性总数 | <2%（高频场景更严） |
| 延迟开销 | 护栏增加均时 | 输入 <15ms；输出按场景 |
| 拦截率 | 被拦调用/调用总数 | 分原因跟踪（授权/参数/风险） |
| 误拦率 | 良性工具调用被拦比 | 必须跟踪——护栏杀手 |
| 修复成功率 | 回退后模型修正成功比 | 高 |
| 逃逸率 | 应拦未拦（红队样本） | 趋 0 |
| 确认触发率 | 人工确认占 DANGEROUS 比 | 覆盖 100% DANGEROUS |
| 审计覆盖率 | 留痕动作/总动作 | 100% |

> 💡 最该盯的两个：**FPR**（护栏的隐性成本，毁产品于无形）与**逃逸率**（应拦未拦才是安全指标，拦截率是努力指标）。

## 4. 面试题（14 题 + 答题范式）

### 4.1 基础（必答）

**Q1：护栏是什么？输入输出护栏区别？**
> 运行时策略控制层，拦截点在输入/输出/检索/工具调用。输入护栏（Pre-LLM）快而确定（PII/注入，5-15ms）；输出护栏（Post-LLM）成本刻意（幻觉/毒性/格式/PII，按风险开关）。

**Q2：五 rail 是什么？**
> Input（输入入模型前）/ Dialog（多轮流）/ Retrieval（检索块入上下文前）/ Execution（工具执行前）/ Output（输出送达前）——NeMo Guardrails 提出，Agent 必须多层覆盖。

**Q3：护栏三种修复策略？**
> Refrain（拒绝给后备）/ Fix（自动修正如脱敏）/ Reask（回喂模型重答，上限 2-3 次）——"护栏即反馈"把拦截变质量保障。

### 4.2 进阶（加分）

**Q4：为什么通用毒性过滤不够？**
> 为社媒设计：礼貌式越狱漏判、粗分类法、误伤敏感话题。专用分类器（Llama Guard 3 多标签 / ShieldGemma 概率阈值 / Aegis 上下文感知）是标配。

**Q5：2026 分类器盲区？**
> Prompt Guard 2 与 Llama Guard 3 对间接注入/工具攻击检测率仅 7-37%——扁平文本无结构边界 + 聊天模板不支持 tool 角色。激活探针（残差流探针）达 99%，但需自托管。间接注入防线在架构隔离（源验证/工具校验）。

**Q6：Guardrails AI 与 NeMo 区别？**
> Guardrails AI 管输出形状与安全（验证器 + RAIL/Pydantic + refrain/fix/reask）；NeMo 管对话流与话题边界（Colang 五 rail + jailbreak/fact-check rail）——互补，分层组合是推荐架构。

**Q7：工具护栏查什么？**
> 工具选择授权、参数校验、动作风险分级、调用序列模式四道（ToolSafe ACL 2026：有害调用减少 65%）。执行语义：静默/回退/Tripwire/人工。

**Q8：护栏评测为什么不可信厂商数据？**
> 同源切分虚高——LODO 实证 AUC 高估 8.4 点（单数据集 1-25%）。生产三件套：绕过率 + FPR + 延迟，直接/间接分开报。

### 4.3 架构与治理（拉开差距）

**Q9：为什么内容护栏对 Agent 不够？**
> 攻击发生在提示与提示之间：Agent 自提示、链式行动、记忆篡改。邮件摘要攻击链全程"合法"——无恶意提示无违禁输出，意图被劫持。内容过滤必须与行为监控（意图建模 + 偏离检测）组合。

**Q10：企业四支柱？**
> 盘点（2500 个 Agent 案例）→ 识别爆炸半径（毒性组合）→ 检测（确定性运行时护栏）→ 动作点执行。先知道有什么，再知道危险在哪。

**Q11：零常设与 JIT？**
> Agent 启动无权限，任务级临时授予自动回收——与人类零信任同构。治理顺序：盘点→分级→收缩→护栏→监控→审计。

**Q12：EU AI Act 对 Agent 的要求？**
> Article 50 透明度义务 2026-08-02 生效（告知用户在与 AI 对话）；风险分级（minimal/limited/high/unacceptable）；审计义务（动作/交接/system prompt 修改全记录）。护栏提供可审计痕迹，不自动合规。

**Q13：Tripwire 与普通拦截区别？**
> 普通拦截拦"这一下"，Tripwire 停"整台机器"——检测到攻击特征继续循环本身就是风险。高危事件用 tripwire 语义，普通违规用结构化回退。

**Q14：护栏评测到生产的闭环？**
> 基准层（LODO 选型）→ 构建层（红队 + CI 对抗样本回归）→ 运行层（监控 + 逃逸样本收集）→ 样本入评测集 → 重训 → 灰度上线。阈值按目标分布 heldout 校准。

### 4.4 答题范式

| 原则 | 说明 |
|---|---|
| 结构优先 | 定义 → 机制 → 实证 → 落地（四段式） |
| 带数据 | "7-37% 盲区""8.4 点虚高""65% 减少"——实证碾压空谈 |
| 说权衡 | "0 绕过是 FPR 换的""延迟分层是成本换覆盖" |
| 落工程 | 补一句"生产上我怎么做"（阈值校准/shadow 灰度/逃逸闭环） |
| 提边界 | 何时不做：低危高频不搞全栈护栏；内容护栏解决不了行为攻击 |

## 6. 面试速记（终极压缩）

1. **覆盖五 rail**：输入/检索/工具/输出/对话——每个数据跨越系统边界处都是一道闸。
2. **分类器专用化**：Llama Guard 3/ShieldGemma/Aegis 替代通用过滤；间接注入 7-37% 盲区靠架构隔离。
3. **评测看三件套**：绕过率 + FPR + 延迟；LODO 证基准虚高 8.4 点；阈值按分布校准。
4. **护栏即反馈**：检测 → 定向修正回喂 → 重检（上限 2-3）——把拦截变质量保障。
5. **治理升级行为安全**：内容护栏挡不住意图劫持——四支柱 + 零常设 + JIT + 全审计。
