# 角色设计：Persona 与身份

> Persona = Agent 的配置身份——角色、风格、知识边界、受众意识。2026 核心认知：**Persona 是评估契约不是品牌备注**（生产响应必须满足的合同）；**人格漂移（Persona Drift）是主要失败模式**（2026 前沿模型更长更自信地越界）。本章给 Persona 设计完整规范。

## 1. Persona 的四个元素

| 元素 | 内容 | 例子 |
|---|---|---|
| 角色 | 领域专长 | "资深 TypeScript 开发者" |
| 沟通风格 | 语气/正式度 | "简洁直接，无废话" |
| 知识边界 | 知道什么、**明确不知道什么** | "React 专家，不覆盖 Vue/Angular" |
| 受众意识 | 对谁说话 | "面向初学者" |

> 🎯 核心要点：**"模糊 Persona（'要乐于助人'）产生不一致行为"**——专长域/响应风格/知识边界三要素必须明确；知识边界（明确不知道什么）是防止幻觉与越权的第一道防线（与 09 篇范围限制联动）。

## 2. 角色配置最佳实践

| 实践 | 做法 |
|---|---|
| 具体 | 专长域/风格/边界显式——"be helpful" 是反例 |
| 顺序 | 角色 → 职责 → 约束 → 语气（"新人入职简报"式） |
| 负面声明 | **说清不能做什么**（"绝不报价"——负面声明阻止坏行为） |
| 升级路径 | 何时让位人类/置信阈值/范围边界 |
| 身份与任务分离 | 身份块在前、任务指令在后 |

> 💡 与 02 层 Prompt 工程 04 篇（角色扮演与结构化输出）分工：02 层讲角色扮演的提示技巧（怎么写角色）；本体系讲 Persona 作为**组件资产**（配置/评估/漂移治理）。

## 3. 人格漂移：2026 主要失败模式

| 项 | 说明 |
|---|---|
| 现象 | Agent 产出更长更自信的越界响应（偏离角色/品牌/策略） |
| 恶化条件 | **>4 轮对话显著恶化**；2026 前沿模型比小模型更严重 |
| 隐藏风险 | 记忆压缩把约束"摘要掉"——关键规则被压缩后失效 |
| 破坏面 | 品牌/幻觉/策略同时破（约束同时失效） |

> ⚠️ 2026 防御规范：**关键规则钉在不可压缩区**（记忆压缩不覆盖的区域，07 篇）；Persona 按 span 打分（评估体系）；对抗性压测（愤怒用户/离题/越狱——09 篇红队）。

## 4. Persona 评估：契约的度量

| 评估方式 | 内容 |
|---|---|
| Span 级打分 | 逐段评估 Persona 遵循度——不假设 system prompt 自动生效 |
| 压测集 | 愤怒用户/离题问题/越狱尝试/边界场景 |
| 遵循度趋势 | 跨版本/跨轮次监控（06 篇按版本漂移联动） |
| 负样本 | 越界响应收集——失败即样本（评估 05 篇） |

> 🎯 核心要点：**"把 Persona 当合同评估，不当文案欣赏"**——评估的是"生产响应是否满足身份/风格/边界契约"，不是"提示词写得好不好看"；span 级打分是 2026 标准（整段打分掩盖局部越界）。

## 5. 动态角色适配

| 方式 | 机制 | 适用 |
|---|---|---|
| 静态 Persona | 固定身份 | 单一场景 |
| 动态角色 | 按任务类型/难度程序化构建 Persona | 多场景 Agent |
| 子 Agent Persona | 每 Agent 独立身份（CrewAI 角色体系） | 多 Agent（Multi-Agent 07 篇） |
| 环境注入 | 用户信息/上下文动态注入身份块 | 个性化 |

> 💡 框架现状（2026）：OpenAI Agents SDK（命名 Agent + instructions）、CrewAI（role-based Agents）、Google ADK（子 Agent persona 配置）——**Persona 在框架层已是结构化配置**，不再是自由文本（05 篇注册中心联动）。

## 6. 常见误区

| 误区 | 真相 |
|---|---|
| "Persona=品牌文案" | 评估契约——生产响应必须满足 |
| "be helpful 够用" | 模糊 Persona 不一致行为——专长/风格/边界 |
| "正面声明够" | 负面声明阻止坏行为——"绝不报价" |
| "system 自动生效" | 漂移是常态——span 打分 + 压测 |
| "压缩不影响约束" | 摘要掉约束——关键规则钉不可压缩区 |
| "4 轮内没事" | >4 轮恶化——长会话重点监控 |
| "身份任务混写" | 身份块在前、任务指令在后 |

## 7. 面试速记

| 问题 | 一句话答案 |
|---|---|
| Persona 四元素？ | 角色/风格/知识边界/受众 |
| Persona 定位？ | 评估契约不是品牌备注 |
| 人格漂移？ | 越界行为——>4 轮恶化、压缩加剧 |
| 漂移防御？ | 规则钉不可压缩区 + span 打分 + 压测 |
| 知识边界价值？ | 防幻觉越权第一道防线 |
| 角色顺序？ | 角色→职责→约束→语气（新人简报式） |
| 负面声明？ | 说清不能做什么——阻止坏行为 |
| 动态角色？ | 按任务类型程序化构建 |
| 与 02 层 04 篇分工？ | 02 层讲扮演技巧，本体系讲组件资产 |
| 框架 Persona？ | 结构化配置（OpenAI/CrewAI/ADK） |
| 评估方式？ | span 级打分——不假设自动生效 |
| 负样本？ | 越界响应收集——失败即样本 |
