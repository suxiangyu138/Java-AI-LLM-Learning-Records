# 生产冲刺：落地清单与面试

> 收官篇：把 01-09 收敛成可执行清单与面试弹药。2026 生产基线：**宪法式设计（六段+CARE+约束层级）、Persona 是评估契约、渐进披露紧凑化、PromptOps（版本化+秒级回滚）、prevent-detect-prove 注入防御**——提示词是 Agent 唯一稳定部分，也是生产事故的隐蔽源头。

## 1. 生产落地清单（上线前逐项打勾）

### 1.1 设计层

| 检查项 | 标准 |
|---|---|
| 六段解剖 | 身份/能力/约束/格式/示例/行为规则齐全 |
| 位置原则 | 重要内容靠前（attention 权重） |
| Persona 三要素 | 专长/风格/知识边界显式 |
| 约束层级 | 安全 > system > user > 示例 > 默认，写进提示词 |
| 硬约束 | 少而精——每条能回答"违反会怎样" |
| 升级路径 | 转人工/降级出口显式 |
| 紧凑性 | <2000 token；渐进披露（100 token 元数据 + Skill） |

### 1.2 管理层

| 检查项 | 标准 |
|---|---|
| 注册中心 | 提示词独立于代码、按名引用 |
| 版本化 | 不可变 + 语义化 + **完整执行上下文**（模型/参数/工具/检索） |
| 环境标记 | prod 固定已审版本——绝不浮动 latest |
| 评估门禁 | 回归 + A/B + 比在线的强才上 |
| 漂移检测 | trace 带 prompt.id/version/variant/template_hash |
| 回滚 | 注册中心指针秒级 + 审计留痕 |

### 1.3 集成与防御层

| 检查项 | 标准 |
|---|---|
| 工具规则 | 使用规则在 system、契约在 tools |
| 规则钉扎 | 关键规则在记忆不可压缩区 |
| 结构隔离 | 指令与数据不混字符串 |
| 动态注入 | 变量校验 + 静态前动态后 |
| 分层防御 | 结构隔离 + Guardian + 输出扫描 + 护栏 |
| 可披露仍工作 | 提示词无秘密 |
| 红队 | 安全声明配攻击用例（持续） |

## 2. 十二大避坑

| # | 坑 | 后果 | 解法 |
|---|---|---|---|
| 1 | 细节全塞 system | >4000 token 注意力稀释 | 渐进披露（03 篇） |
| 2 | 模糊 Persona | 行为不一致 | 专长/风格/边界（02 篇） |
| 3 | 不设负面声明 | 坏行为不阻止 | MUST NOT 显式（04 篇） |
| 4 | 约束冲突不审计 | 行为随机 | 冲突审计五查（04 篇） |
| 5 | 提示词内联代码 | 无追踪不可回滚 | 注册中心（05 篇） |
| 6 | 只版本化文本 | 行为不可复现 | 完整执行上下文（05 篇） |
| 7 | 生产浮动 latest | 未验证上线 | 环境标记固定（05 篇） |
| 8 | 无按版本漂移 | 回归不可归因 | prompt.version 必填（06 篇） |
| 9 | 回滚走重部署 | 30 分钟 vs 3 秒 | 指针变更（06 篇） |
| 10 | 指令数据混拼 | 注入正门 | 结构隔离（09 篇） |
| 11 | 秘密进提示词 | 提取即泄漏 | 可披露仍工作（09 篇） |
| 12 | 无评估就优化 | 盲人摸象 | 版本化+评估前提（08 篇） |

> 🎯 核心要点：12 坑根因是三个——**设计粗糙（1-4）、管理缺失（5-9）、防御单薄（10-12）**。按 03/04/05/06/09 篇规范做，12 坑自动消失。

## 3. 指标体系

| 指标 | 计算 | 目标 |
|---|---|---|
| 遵循度 | span 级 Persona/约束遵循分 | 高 + 趋势监控 |
| 漂移回归 | 每版本滚动均值 rubric | 无突发下降 |
| 回滚 MTTR | 检测到回滚完成时间 | 秒级（指针） |
| 注入拦截率 | 红队样本被拦比例 | 分层防御覆盖 |
| 间接注入漏检 | 间接注入穿透比例 | 趋 0（架构隔离） |
| 提示词 token | system prompt 大小 | <2000 |
| 版本覆盖 | trace 带 prompt.version 比例 | 100% |
| 优化净收益 | 优化后 vs 前遵循度 | 正向 + 回归通过 |

> 💡 最该盯的两个：**遵循度趋势**（角色契约是否在漂移）与**版本覆盖**（无版本属性 = 无法归因任何问题）。

## 4. 面试题（14 题 + 答题范式）

### 4.1 基础（必答）

**Q1：系统提示词六段？**
> 身份/能力/约束/输出格式/示例/行为规则——重要内容靠前（模型权重偏早）；CARE 结构（Context/Ask/Rules/Examples）是稳定行为模板；"入职第一天向新人简报"式顺序。

**Q2：Persona 为什么是评估契约？**
> 不是品牌备注——生产响应必须满足的合同：角色/风格/知识边界/受众四元素；模糊 Persona（"be helpful"）产生不一致行为；知识边界（明确不知道什么）防幻觉越权。

**Q3：约束层级？**
> 安全 > system > user > 示例 > 默认——冲突时模型按层级裁决；层级要显式写进提示词；硬约束（MUST）少而精管安全关键、软约束（SHOULD）管风格；安全约束执行层兜底。

### 4.2 进阶（加分）

**Q4：人格漂移？**
> 越界行为（品牌/幻觉/策略同时破）——2026 前沿模型更长更自信地越界；>4 轮恶化；记忆压缩把约束"摘要掉"——关键规则钉不可压缩区；span 级打分 + 对抗压测。

**Q5：渐进披露？**
> ~100 token 元数据常驻 + Skill 文件按需加载（10K+ 知识）——提示词版动态工具发现（Tool 05 篇同源）；<2000 token 纪律；瘦身六技巧（去版本标签/去重复/软化标记/动态外置/精选示例/细节外移）。

**Q6：Prompt 版本化？**
> 提示词一等工件：不可变版本（发布后不原地改）+ 语义化版本（major 行为契约）+ **版本化完整执行上下文**（prompt+模型+参数+工具+检索——否则不可复现）；应用按名引用；环境标记 prod 固定不浮动 latest。

**Q7：按版本漂移检测？**
> 每版本滚动均值 rubric（聚合告警漏回归）；trace 必带 prompt.id/version/variant/template_hash（无 version 其他不工作）；template_hash 抓同版本内容漂移；Cohort 切片（版本/变体/地区）防全局掩盖。

**Q8：秒级回滚？**
> 注册中心指针重指向旧版本——非代码重部署；下一次调用即生效；自动（灰度评估回归）+ 手动；MTTR -70%；Git 标签 production-2026-04-07 是"哪天跑了什么"证据。

### 4.3 优化与安全（拉开差距）

**Q9：SePO 与自动优化？**
> 自我指涉——提示词 Agent 优化任务 Agent 也优化自己（5 基准 +4.49 点，$37 摊销）；GEPA 反思式进化（读轨迹懂为何失败，ICLR 2026 Oral）；Hermes $2-10/次无 GPU 训练；**优化工具只在有版本化对象时有用**；护栏：全测试+语义保持+人审 PR。

**Q10：五攻击模式与分层防御？**
> 提取/覆盖/角色劫持/工具外泄/间接注入（最难——输入永不出自用户）；分层：结构隔离（地基）→边界标记→Guardian 模型→输出扫描→最小权限→运行时护栏→红队；提示词级防御可被绕过——架构防御。

**Q11：Prevent-Detect-Prove？**
> 自动红队（动态探测）+ 运行时护栏（确定性拦截）+ 形式化验证（TLA+/Dafny 证明状态机不可达非法状态）——三层递进，2026 企业收敛；形式化验证是 Agent 安全与经典安全的分水岭。

**Q12：Twin Agent 特权分离？**
> Explore Agent（探索）+ Safe Agent（特权执行）分离——Explore 只发紧凑提示（上下文残差压缩）；攻破探索 ≠ 攻破执行；与意图-执行分离（Orchestrator 05 篇）同源。

**Q13：结构隔离？**
> 指令与数据不混一个字符串（Chat API 角色/函数调用分离）——注入防御地基；输入边界标记（`--- USER DATA START ---`）次级防线；动态值注入 system 前必须校验；间接注入防线在架构隔离。

**Q14：提示词与工具/记忆/护栏分工？**
> system 讲行为策略、tools 讲能力契约；关键规则钉记忆不可压缩区；护栏保护提示词（提示词约束护栏——双向）；trace 带版本+评估+护栏三信号汇合。

### 4.4 答题范式

| 原则 | 说明 |
|---|---|
| 结构优先 | 定义 → 机制 → 实证 → 工程（四段式） |
| 带数据 | "+4.49 点""MTTR -70%""<2000 token"——实证碾压空谈 |
| 说权衡 | "硬约束少而精（硬化降遵循）""紧凑靠分层不靠删减" |
| 落工程 | 补一句"生产上我怎么做"（注册中心/钉扎/结构隔离） |
| 提边界 | 何时不做：小 Agent 不必渐进披露；自动优化需版本化+评估前提 |

## 6. 面试速记（终极压缩）

1. **宪法式设计**：六段 + CARE + 约束层级（安全>system>user>示例>默认）——重要内容靠前。
2. **Persona 是契约**：角色/风格/知识边界——漂移 >4 轮恶化、压缩加剧——钉不可压缩区 + span 打分。
3. **PromptOps**：一等工件版本化（完整执行上下文）+ 环境标记 + 按版本漂移 + 秒级回滚（MTTR -70%）。
4. **紧凑渐进**：100 token 元数据 + Skill 按需——<2000 token；优化工具的前提是版本化对象。
5. **注入防御架构化**：五攻击 + 分层 + Prevent-Detect-Prove + Twin Agent——"提示词被披露后仍应工作"。
