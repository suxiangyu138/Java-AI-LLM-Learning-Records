# 自动优化：从手动到自我进化

> 自动优化 = 让优化器（LLM/进化算法）替人迭代提示词。2026 前沿：**SePO 自我进化**（提示词 Agent 优化任务 Agent 也优化自己，+4.49 点）、**GEPA 反思式进化**（读轨迹懂"为何失败"，ICLR 2026 Oral）；前提铁律：**优化工具只在有版本化对象时有用**（05 篇）。本章给自动优化全景与工程规范。

## 1. 为什么自动优化

| 手动优化的问题 | 自动优化 |
|---|---|
| 凭直觉改提示词 | 数据驱动（评估分数/轨迹） |
| 一次改一处 | 进化搜索（多候选） |
| 专家瓶颈 | 优化器（LLM/算法）替代 |
| 不可复现 | 版本化 + 评估门禁 |

> 🎯 核心要点：**自动优化的前提是"可度量的目标"**——没有评估体系（Feedback & Evaluation），优化器就是盲人摸象；**"优化工具只在有版本化对象时有用"**——版本化注册中心（05 篇）是优化的落地前提。

## 2. SePO：自我进化提示词 Agent（2026-06）

| 项 | 说明 |
|---|---|
| 缺口 | 既有优化方法把"优化器"本身固定——SePO 连优化器一起进化 |
| 设计 | 自我指涉：单一提示词 Agent 同时改进任务 Agent 提示词**与自己的提示词** |
| 训练 | 两阶段：预训练（多任务池进化自己的 system prompt）→ 微调（复用优化任务特定提示词） |
| 效果 | 5 基准（AIME'25/ARC-AGI-1/GPQA/MBPP/Sudoku）**超 Manual-CoT +4.49 点** |
| 成本 | Generalist 变体 $37 预训练摊销——比 Specialist 便宜且更准 |
| 泛化 | 优化技能泛化超训练混合——非记忆任务特定提示词 |

> 💡 SePO 的进化产物：**防御性规则（防 CoT 截断）+ 任务特定程序脚手架**——自动优化产出不只是"更好的措辞"，还有结构性的防御（与 04 篇约束设计联动）。

## 3. GEPA / Hermes：反思式进化（ICLR 2026 Oral）

| 项 | 说明 |
|---|---|
| GEPA | 遗传-Pareto 提示进化——**读执行轨迹理解"为何失败"**（不只"失败了"）→ 定向突变 |
| Hermes | DSPy + GEPA 落地：优化技能文件/工具描述/system prompt/代码 |
| 成本 | 无 GPU 训练——API 调用 $2-10/次 |
| **护栏** | 必须过全测试套件/大小限制/缓存兼容/语义保持/**人类 PR 审查** |
| 定位 | 反思式进化超越 RL 作为推理时搜索策略（2026 研究结论） |

> ⚠️ Hermes 的工程启示：**自动优化的"自动"到人审为止**——进化提案必须过全测试 + 语义保持 + 人类 PR 审查才提交；自动生成与人工把关的分界线是 2026 共识（评估 09 篇人审签字同源）。

## 4. 其他路线

| 方法 | 机制 | 效果 |
|---|---|---|
| PromptEvo | 轨迹频繁模式挖掘 + LLM 重写注入 | StarCraft II +17.4% 胜率 |
| 环境接地优化 | 观测-动作管道分解 + LLM 进化环（环境回报引导） | 游戏 Agent |
| EvoTool | 自我进化 blame-aware 突变 | 工具使用策略 |
| RePrompt | 类梯度下降逐步指令优化 | 分步指令 |
| ProTeGi/GEPA/随机搜索 | 经典优化器（05 篇提及） | 需版本化对象 |

> 🎯 核心要点：**路线谱系 = 目标函数 × 搜索机制**——目标函数（评估分数/环境回报/轨迹模式）与搜索机制（进化/梯度/挖掘）自由组合；2026 主流 = 进化 + 反思（GEPA 系）。

## 5. 自动优化的工程护栏

| 护栏 | 内容 |
|---|---|
| 版本化前提 | 优化结果落地为可回滚版本（05 篇） |
| 评估门禁 | 候选过 CI（minPassRate，评估 09 篇） |
| 语义保持 | 优化不改变核心身份/约束（Hermes） |
| 人审 PR | 自动生成、人工提交 |
| 回归 | 历史 trace 重放验证（06 篇） |
| 漂移监控 | 优化后遵循度趋势（06 篇） |

> 💡 **自动优化 ≠ 无人优化**——2026 的正确姿势是"机器生成候选、评估筛选、人类签字、版本落地"；全自动提交是危险区（语义保持不可自动验证）。

## 7. 常见误区

| 误区 | 真相 |
|---|---|
| "优化器不用优化" | SePO 证明优化器本身也进化（+4.49 点） |
| "自动=无人" | 人审 PR——机器生成人工提交 |
| "无评估也能优化" | 盲人摸象——可度量目标是前提 |
| "无版本化也能优化" | 优化工具只在有版本化对象时有用 |
| "优化=措辞" | 产出防御性规则/程序脚手架 |
| "进化贵" | Hermes $2-10/次——无 GPU 训练 |
| "全自动提交" | 语义保持不可自动验证——危险区 |
