# 与工具-记忆-护栏-观测集成

> 集成 = 系统提示词不是孤岛——它与工具声明、记忆系统、护栏、观测四个组件咬合。2026 关键接口：**system 讲行为、tools 讲能力**（04 篇协议分工）；**关键规则钉在记忆不可压缩区**（02 篇漂移防御）；**结构隔离**（指令与数据不混字符串——注入防御基础，09 篇）。本章给四接口完整设计。

## 1. 与工具声明的分工

| 层 | 管什么 | 例子 |
|---|---|---|
| System prompt | 行为规则：何时调、调完怎么用 | "查询订单先查缓存" |
| Tools 声明 | 能力契约：三要素（Tool 03 篇） | 工具描述/schema |
| 边界 | 工具依赖与顺序放 system；工具形态放 tools | — |

> 🎯 核心要点：**system 讲"策略"，tools 讲"能力"**——工具使用规则（何时调/依赖顺序/错误处理）放 system；工具本身（描述/schema）放 tools（04 篇协议分工）；放错层 = 规则丢失或 schema 膨胀。

## 2. 与记忆系统的接口

| 接口 | 机制 |
|---|---|
| 关键规则钉扎 | 安全/身份规则放**不可压缩区**（记忆压缩不覆盖）——防"摘要掉"（02 篇） |
| 记忆读入校验 | 记忆内容注入前检查（Guardrails 07 篇记忆护栏） |
| 身份一致性 | 记忆中的历史行为不得偏离身份（span 打分联动） |
| 写入纪律 | 记忆写入遵循提示词约束（Memory 05 篇写入纪律） |

> ⚠️ 2026 实证：**记忆压缩把约束"摘要掉"是人格漂移的隐藏放大器**——"关键规则必须钉在不可压缩区"（02 篇）；提示词与记忆的接口 = "规则钉扎 + 读入校验"双保险。

## 3. 与护栏的接口：结构隔离

| 机制 | 内容 |
|---|---|
| 结构隔离 | **指令与数据不混一个字符串**——Chat API 角色/函数调用分离 system 指令与用户数据 |
| 输入边界标记 | 显式边界符（`--- USER DATA START ---`）——次级防线 |
| Guardian 模型 | 小快模型扫注入模式（PIGuard 类：覆盖/角色劫持/编码指令/多轮操纵） |
| 输出扫描 | 检测成功注入与 system 泄漏（09 篇） |
| 多层拦截 | 输入/工具调用/工具响应/输出四表面（Guardrails 04 篇 execution rail） |

> 🎯 核心要点：**结构隔离是注入防御的"地基"**——单一字符串拼接指令与数据 = 给注入开正门（09 篇）；Guardian 模型是 2026 低误报检测的标配（PIGuard ACL 2025）。

## 4. 与观测的接口：版本属性

| 属性 | 值 |
|---|---|
| prompt.id/version/variant/template_hash | 06 篇漂移检测 |
| 模型版本 | 模型漂移归因 |
| 遵循度分数 | span 级 Persona 打分（02 篇） |
| 干预记录 | 护栏触发与提示词关系（04 篇） |

> 💡 集成的数据流：**trace 带 prompt 版本 + 评估分数 + 护栏干预——三个信号在 span 上汇合**——"提示词回归/注入攻击/护栏拦截"在一条 trace 上可归因（观测 06 篇）。

## 5. 动态注入：提示词与上下文的装配

| 方式 | 机制 |
|---|---|
| 静态段 | 身份/约束（常驻，03 篇） |
| 动态段 | 用户信息/环境/截止时间（实时源，03 篇） |
| 装配顺序 | 静态在前、动态在后（缓存纪律，感知 08 篇） |
| 变量校验 | 动态值注入前校验（防注入变量） |

> ⚠️ 动态注入的安全点：**动态值（用户数据）注入 system 前必须校验/隔离**——"把用户数据拼进 system 段"= 绕过角色约束的通道（结构隔离 §3 联动）。

## 6. 集成检查单

| 检查 | 标准 |
|---|---|
| 工具规则 | 依赖/顺序/错误处理在 system？ |
| 关键规则 | 钉在不可压缩区？ |
| 结构隔离 | 指令与数据不混字符串？ |
| 版本属性 | trace 带 prompt.version？ |
| 动态注入 | 变量校验 + 装配顺序对？ |
| 护栏覆盖 | 四表面拦截 + Guardian 模型？ |

> 🎯 核心要点：**六项检查是"提示词不是孤岛"的落地**——每项都是与其他组件的接口契约；集成是双向的（提示词约束护栏，护栏保护提示词）。

## 7. 常见误区

| 误区 | 真相 |
|---|---|
| "工具规则放 tools" | 使用规则放 system——tools 只管三要素 |
| "记忆压缩无影响" | 摘要掉约束——钉不可压缩区 |
| "拼接最方便" | 指令数据混字符串 = 注入正门 |
| "动态值直接拼" | 变量校验 + 隔离 |
| "版本属性可选" | trace 必带——归因前提 |
| "护栏与提示词无关" | 双向——约束护栏、护栏保护 |
| "注入只防 user" | 检索/工具内容也注入（间接注入 09 篇） |

| 结构隔离？ | 指令数据不混字符串——注入防御地基 |

| 间接注入？ | 检索/工具内容——不只 user |
