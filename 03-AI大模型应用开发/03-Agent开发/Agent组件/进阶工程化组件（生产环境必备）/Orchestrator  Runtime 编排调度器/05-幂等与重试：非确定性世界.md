# 幂等与重试：非确定性世界

> 重试与幂等 = 运行时可靠性的"刹车系统"。2026 核心认知：**"重试是为确定性世界构建的"**——LLM 每次重试推理不同，重试的操作不是原操作；经典重试逻辑在 Agent 上失效（$847 双收费事故）。本章给非确定性世界的重试与幂等完整设计。

## 1. 重试的经典假设 vs Agent 现实

| 经典假设 | Agent 现实 |
|---|---|
| 重试返回相同结果 | 不同 token 采样/工具选择/动作序列 |
| 重试安全 | 工具副作用可能重复（非幂等） |
| 失败模式单一 | 推理失败是主要错误模式（不是网络） |

> ⚠️ 2026 实证事故：**Agent 给测试客户双收费 $847**——Stripe API 调用超时 → 重试逻辑没查首次是否到账 → 二次扣款。经典"超时重试"在 Agent 上直接产生财务事故。

## 2. 两种重试：相反的处理

| 类型 | 触发 | 期望 | 处理 |
|---|---|---|---|
| Transient 重试 | 网络抖动/超时/限流 | **同样结果** | 重试原操作（幂等包装） |
| Sampling 重试 | 输出质量差/推理错 | **不同结果** | 重新生成（新采样）——不是重放 |

> 🎯 核心要点：**两种重试要相反处理**——transient 要"同结果"（重放/重试工具调用）、sampling 要"不同结果"（重新推理）；混为一谈 = 要么重复副作用、要么永远同错。LangGraph 2026 把 NodeTimeoutError 默认设为可重试，同时警告非幂等副作用需 opt-out——"默认重试"本身是风险。

## 3. 幂等键模式：标准解

| 项 | 说明 |
|---|---|
| 机制 | 每操作唯一键（Stripe 模式）——服务端见同键返回缓存结果 |
| Agent 化 | 工具调用边界哈希：workflow ID + 工具名 + 参数 → 去重键 |
| 实现 | agent-ledger（哈希去重 + 重放存储结果不重执行）、SafeAgent（SQLite guard：tool_name + input hash + session_id） |
| 实测 | SafeAgent 在真实交易中拦截 6 次重复动作（含崩溃后重复 $452 买入） |

> 💡 幂等键是"恰好一次"（02 篇义务二）的工程实现——**记录意图 → 幂等包装执行 → 成功后持久收据**（Zylos 模式）；收据 = 可查证"这个操作做过了"。

## 4. 意图-执行分离：架构级答案

```text
推理与执行分离：
  推理层（非确定）：Agent 提出意图（intent）
    ↓
  执行层（确定）：校验 + 幂等包装 + 执行
    ↓
  收据（持久）：操作完成记录（可重放查证）
```

| 层 | 确定性 | 职责 |
|---|---|---|
| 推理 | 非确定 | 提出意图（Agent） |
| 执行 | 确定 | 校验/幂等/执行（运行时） |
| 收据 | 持久 | 恰好一次证据 |

> ⚠️ 权衡（2026）：这个"缰绳"约束了 Agent 的即兴灵活性——"OS 内核边界"（无特权推理 vs 特权状态修改）的代价是灵活度；生产副作用场景必须上，纯信息场景可省。

## 5. 重试预算：防重试风暴

| 预算项 | 说明 |
|---|---|
| 全局重试预算 | 嵌套重试层（框架/工具/网络）之上的总预算——防风暴 |
| 分层重试 | 不同失败类不同退避（provider 5xx vs 工具超时——不同背压） |
| 重试尾 | **重试尾支配 p99 支出**（选型成本投影，08 篇） |
| 停止条件 | 达到预算 → 结构化失败（Tool 06 篇） |

> 🎯 核心要点：**重试是分层嵌套的（框架层+工具层+网络层）——没有全局预算 = 指数风暴**；重试尾（长尾重试）是成本与延迟的隐藏支配项；预算 + 分类退避是标准治理。

## 6. 幂等设计清单

| 检查项 | 标准 |
|---|---|
| 危险操作幂等键 | 支付/部署/写操作必带 |
| 键生成 | workflow ID + 工具名 + 参数哈希 |
| 收据持久化 | 成功后记录——可查证 |
| 人工确认键 | approve/deny 绑定幂等键 + 意图哈希（防"批了别的"） |
| 版本关联 | 幂等键含工具 schema 版本（防版本漂移误判） |
| 重放跳过 | 重放时查收据——有收据不重执行（02 篇） |

> ⚠️ 人工确认的持久性（Zylos 警示）：**持久审批必须记录"谁批的、看了什么产物、审批是否在重放后仍有效"**——重放后审批失效 = 操作在无人批准下执行。

## 7. 常见误区

| 误区 | 真相 |
|---|---|
| "超时重试安全" | $847 双收费——重试前查首次是否落地 |
| "重试=重放" | transient 重放、sampling 重生成——相反处理 |
| "默认重试无害" | 非幂等副作用 opt-out——默认重试是风险 |
| "幂等是框架的事" | 工具边界幂等键——agent-ledger/SafeAgent 模式 |
| "重试预算多余" | 嵌套重试风暴——全局预算必需 |
| "审批重放有效" | 记录谁批/看什么/重放后是否有效 |
| "幂等键随意" | 含版本哈希——防版本漂移误判 |
