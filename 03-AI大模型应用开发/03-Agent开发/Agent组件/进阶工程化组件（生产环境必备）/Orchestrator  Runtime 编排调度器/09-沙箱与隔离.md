# 沙箱与隔离

> 隔离 = 运行时对"未信任 LLM 生成代码/动作"的最后防线。2026 标准：**安全沙箱默认拒绝**（GKE Sandbox/Kata + 默认拒绝网络姿态）、**硬件级强制**（TDX 无沙箱内提权路径）、**每 Agent 最小权限**（创建时配置）。本章给沙箱与隔离完整设计。

## 1. 为什么沙箱是运行时刚需

| 威胁 | 机制 |
|---|---|
| LLM 生成代码 | 工具执行的是模型输出的代码——不可信输入（Tool 06 篇） |
| 越权副作用 | Agent 被诱导执行危险操作 |
| 恶意内容传播 | 攻击经工具结果传播（Multi-Agent 08 篇级联） |

> 🎯 核心要点：**沙箱的哲学——"未信任代码默认无能力"**——不是"过滤坏动作"，是"没有网络、没有写权限、没有系统访问，除非显式授予"；默认拒绝是 2026 安全沙箱的标志（Agent Executor）。

## 2. 安全沙箱技术

| 层 | 机制 | 特点 |
|---|---|---|
| 容器沙箱 | GKE Sandbox（gVisor）/Kata Containers | 内核隔离、兼容 OCI |
| 网络默认拒绝 | 沙箱内默认无网络 | 未授予不可外连 |
| 文件系统隔离 | 只读根 + 显式挂载 | 写权限显式授予 |
| 硬件强制 | TDX（可信域扩展） | **无沙箱内提权路径** |

> 💡 2026 组合标准：**GKE Sandbox/Kata（隔离）+ 默认拒绝网络（Agent Executor）+ TDX 硬件（最小权限沙箱）**——三层覆盖：容器隔离防逃逸、网络拒绝防外连、硬件防提权。

## 3. 每 Agent 最小权限

| 项 | 说明 |
|---|---|
| 创建时配置 | 沙箱权限在创建时确定（非运行时授予） |
| 例子 | 只读日志沙箱 vs 部署凭据沙箱（需人工批准） |
| 硬件执行 | TDX 层强制——沙箱内无提权路径 |
| 动态收紧 | 任务完成回收权限（Guardrails 09 篇 JIT 联动） |

> 🎯 核心要点：**最小权限 = "能力在创建时定死，运行中不可扩"**——沙箱内 Agent 无论怎么被诱导都拿不到未授予能力；这是"运行时可干预"（Multi-Agent 08 篇）的隔离侧配套。

## 4. 并行放大攻击面

| 问题 | 说明 |
|---|---|
| 并行 Agent | 每个沙箱一个攻击面——并行数 × 面 |
| 共享资源 | 沙箱共享的缓存/存储是横向移动通道 |
| 凭据集中 | 单凭据服务被攻破 = 全体 |
| 治理 | 并行部署前最小权限审查（Multi-Agent 08 篇） |

> ⚠️ 2026 警示（Orgn）：**并行把攻击面乘起来**——"多 Agent 隔离"不等于"多 Agent 安全"；每 Agent 最小权限 + 共享资源隔离 + 凭据分散是并行安全三件套。

## 5. 沙箱与恢复的配合

| 场景 | 机制 |
|---|---|
| 沙箱崩溃 | 隔离重启——不波及其他沙箱 |
| 沙箱 checkpoint | DeltaBox 毫秒级快照/回滚（03 篇） |
| 污染恢复 | 回滚到干净快照（Guardrails 09 篇分级 IR 联动） |
| 证据保留 | 沙箱内取证（审计） |

> 🎯 核心要点：**沙箱 + checkpoint = "可回滚的信任"**——检测到污染回滚干净快照，审计从沙箱取证；隔离与恢复是一对（03 篇 DeltaBox 正是沙箱 checkpoint）。

## 6. 隔离的观测

| 观测点 | 内容 |
|---|---|
| 沙箱事件 | 逃逸尝试/权限拒绝/网络请求拦截 |
| 权限审计 | 每沙箱授权清单变化 |
| 资源隔离 | CPU/内存/存储上限执行 |
| 恢复事件 | 回滚次数/原因 |

> 💡 与观测体系联动：**沙箱拒绝事件是安全遥测的高价值信号**（Guardrails 08 篇行为异常检测联动）——"沙箱内 Agent 尝试外连"是注入的早期特征。

## 7. 常见误区

| 误区 | 真相 |
|---|---|
| "沙箱=容器" | 容器只是第一层——网络默认拒绝 + 硬件强制是标配 |
| "过滤危险命令够" | 默认拒绝能力——不是过滤动作 |
| "沙箱内权限可扩" | 创建时定死——运行中不可扩（无提权路径） |
| "并行=隔离=安全" | 并行乘攻击面——三件套 |
| "污染就重启" | 回滚干净快照 + 取证——重启留证据丢失 |
| "沙箱只防代码" | 工具动作/网络/写都隔离 |
| "沙箱无观测" | 拒绝事件是高价值遥测 |

## 8. 面试速记

| 问题 | 一句话答案 |
|---|---|
| 沙箱哲学？ | 未信任代码默认无能力——默认拒绝 |
| 三层组合？ | 容器隔离（Kata）+ 网络拒绝 + 硬件（TDX） |
| TDX？ | 硬件可信域——无沙箱内提权路径 |
| 最小权限？ | 创建时定死、运行中不可扩 |
| 并行攻击面？ | 并行数×面——三件套（最小权限/资源隔离/凭据分散） |
| DeltaBox？ | 毫秒级沙箱 checkpoint/回滚（03 篇） |
| 污染恢复？ | 回滚干净快照 + 取证 |
| 与 JIT 联动？ | 任务完成回收权限（Guardrails 09） |
| 沙箱事件观测？ | 逃逸/拒绝/网络拦截——注入早期特征 |
| 与 Guardrails 分工？ | 护栏拦截动作，沙箱限制能力——互补 |
| 沙箱崩溃？ | 隔离重启——不波及其他 |
| 与 08 篇 Multi-Agent 联动？ | 信任边界 + 沙箱 = 纵深 |
