# 生产冲刺：落地清单与面试

> 收官篇：把 01-09 收敛成可执行清单与面试弹药。2026 生产基线：**运行时与框架分层、持久执行（事件日志+快照）、程序级调度、幂等键、单写者、默认拒绝沙箱**——"持久性、编排与可恢复性是企业生产 Agent 的真正阻碍"，运行时是生产与 demo 的分水岭。

## 1. 生产落地清单（上线前逐项打勾）

### 1.1 运行时架构

| 检查项 | 标准 |
|---|---|
| 分层 | 框架（逻辑）+ 运行时（生存）分离（08 篇） |
| 引擎选型 | 五测试通过（持久/重试/扇出/观测/成本） |
| 持久执行 | 事件日志 + 快照 + 重放语义（02 篇） |
| checkpoint | 事件级粒度 + 混合恢复（03 篇） |
| 治理第三层 | 策略/审批/审计独立层（08 篇） |

### 1.2 调度与并发

| 检查项 | 标准 |
|---|---|
| 程序级调度 | 按 session 分组 + 工具边界暂停恢复（04 篇） |
| OS 原语 | 准入/AIMD 背压/令牌预算/优先级 |
| 队列 | 车道感知 FIFO + 全局 cap + 溢出策略 |
| DAG 并行 | 拓扑遍历 + 故障隔离 |
| 生命周期 | trajectory_final 标记 + 衰减自愈 |

### 1.3 可靠性与一致性

| 检查项 | 标准 |
|---|---|
| 幂等键 | 危险操作必带（workflow+工具+参数哈希） |
| 重试分类 | transient 重放 / sampling 重生成 |
| 重试预算 | 全局预算防风暴 |
| 单写者 | 会话状态单写者 + 车道双保险 |
| SecretRef | 凭据不进上下文 |

### 1.4 隔离与安全

| 检查项 | 标准 |
|---|---|
| 沙箱 | 容器隔离 + 默认拒绝网络 + 硬件强制 |
| 最小权限 | 创建时定死、运行中不可扩 |
| 并行安全 | 每 Agent 最小权限 + 资源隔离 + 凭据分散 |
| 污染恢复 | 回滚干净快照 + 取证 |

## 2. 十二大避坑

| # | 坑 | 后果 | 解法 |
|---|---|---|---|
| 1 | 框架当运行时 | Pod 重启丢状态 | 运行时分层（01 篇） |
| 2 | checkpoint=持久 | 无自动恢复/重复执行 | 事件日志重放（02 篇） |
| 3 | 快照够恢复 | 陈旧/损坏状态 | 重放优先（02 篇） |
| 4 | 请求级调度 | 缓存爆炸+无背压 | 程序级调度（04 篇） |
| 5 | 超时无脑重试 | $847 双收费 | 幂等键+查首次（05 篇） |
| 6 | 重试不分类型 | 重复副作用或永远同错 | transient/sampling 分离（05 篇） |
| 7 | 并发写会话 | 会话损坏 | 单写者+车道（06 篇） |
| 8 | 明文凭据进上下文 | 三通道泄漏 | SecretRef（06 篇） |
| 9 | 全部上 Temporal | 过度成本 | 30s 规则（08 篇） |
| 10 | 文档选型 | 生产翻车 | 五测试（08 篇） |
| 11 | 沙箱=容器 | 逃逸后无防线 | 网络拒绝+硬件强制（09 篇） |
| 12 | 无重试预算 | 重试风暴 | 全局预算（05 篇） |

> 🎯 核心要点：12 坑根因是三个——**持久化缺失（1-3）、可靠性粗糙（4-6、12）、隔离不足（7-9、11）**。按 02/04/05/08/09 篇规范做，12 坑自动消失。

## 3. 指标体系

| 指标 | 计算 | 目标 |
|---|---|---|
| 恢复成功率 | 崩溃后自动恢复比例 | 100% |
| 恢复时延 | 崩溃到恢复时间 | 按 SLA（毫秒-秒级） |
| 重复副作用率 | 幂等键拦截数/操作总数 | 趋 0 |
| 重试率 | 重试调用占比 | <5%（Tool 06 篇同规） |
| 重试尾 | p99 重试贡献 | 成本投影内 |
| 并发违规 | 同会话并发写事件 | 0（单写者） |
| 沙箱拒绝事件 | 权限拒绝/网络拦截 | 跟踪（注入特征） |
| 簿记泄漏 | 未终止会话占比 | 趋 0 |
| checkpoint 完整度 | 事件级 checkpoint 覆盖率 | >95% |

> 💡 最该盯的两个：**重复副作用率**（可靠性底线——$847 事故的直接指标）与**恢复成功率**（持久执行的承诺兑现度）。

## 4. 面试题（14 题 + 答题范式）

### 4.1 基础（必答）

**Q1：框架、编排器、运行时三层分工？**
> 框架管 Agent 行为建模（图/角色/路由）；编排器管任务流程；运行时管执行生存（持久化/调度/恢复/隔离）。"框架管 Agent 是什么，运行时管 Agent 怎么活"——生产失败大多在运行时层。

**Q2：持久执行是什么？为什么难？**
> 崩溃/重启后从精确断点恢复——事件日志+快照双机制。难在 Agent 非确定性打破经典假设：重试不同结果、checkpoint 不可精确重放、幂等不天然——"持久性/编排/可恢复性是生产 Agent 的真正阻碍"。

**Q3：重放语义？**
> 重放事件日志重建状态（不信任快照）；重放跳过已完成 LLM/工具调用（防重复计费与副作用）；非确定性有重放边界——LLM 调用被记录成确定性事件，重放只回放记录。

### 4.2 进阶（加分）

**Q4：程序级调度？**
> 以整个 Agent 程序（LLM 轮→工具→轮）为调度单位（按 session 分组），状态 (REASONING|ACTING)×(ACTIVE|PAUSED)——解决请求级路由看不见的缓存占用爆炸与工具边界背压；暂停是逻辑的（在途完成再挂起），恢复贪心打包 + 防饥饿超时。

**Q5：重试为什么在 Agent 失效？**
> "重试为确定性世界构建"——LLM 每次重试推理不同。区分 transient（要同样结果——重放/重试工具）与 sampling（要不同结果——重新生成）；$847 双收费事故 = 超时重试没查首次是否落地；幂等键 + 全局重试预算。

**Q6：幂等键怎么落地？**
> 工具调用边界哈希（workflow ID+工具名+参数）→ 去重键；同键返回缓存结果（Stripe 模式）；记录意图→幂等包装执行→持久收据；SafeAgent 实测拦截 6 次重复动作（含崩溃后重复 $452 买入）。

**Q7：单写者一致性？**
> 同会话同时一个写者（Agent Executor 内建）+ 调度层每会话车道——双保险防并发写破坏；存储三模式：事件存储（发生了什么）/命名空间向量库（怎么找回）/文档快照+版本引用（当前是什么，消读写不一致）。

**Q8：checkpoint 六义务？**
> 前缀延续（不重跑已完成）/效果恰好一次/fork 确定性/checkpoint 有效性/消费一次/恢复确定性（remit-contract，机器可检查）——框架 checkpoint ≠ 持久执行（MAF：手动 resume/无失败检测/无重复防护）。

### 4.3 架构与选型（拉开差距）

**Q9：Temporal vs LangGraph？**
> 互补分层——"像比较 React/PostgreSQL/nginx"。LangGraph 管 Agent 逻辑（图/工具路由）、Temporal 管持久执行（事件历史+确定性重放，LLM 封装 Activities）；2026 形态"框架在引擎内"（Temporal LangGraph 插件：图节点为 Activity）；选型条件：>30s/3+ 系统/生产副作用。

**Q10：运行时选型五测试？**
> 持久性（杀 worker 验证恢复）/重试分类（5xx vs 工具超时不同退避）/并行扇出（100-1000）/可观测（每步 span）/成本投影（重试尾支配 p99）——不跑五测试的选型是猜。

**Q11：Google Agent Executor 与 Catalyst？**
> Agent Executor（2026-05 开源）：事件日志+快照持久、默认拒绝沙箱、单写者、轨迹分支、Agent Substrate 计算层；Catalyst 2.0（2026-07）：加密历史签名+执行血统+工作流证明——可验证执行（合规链），支持 8 大框架。

**Q12：沙箱与最小权限？**
> 未信任 LLM 代码默认无能力——容器隔离（GKE Sandbox/Kata）+ 默认拒绝网络 + 硬件强制（TDX 无沙箱内提权路径）；权限创建时定死运行中不可扩；并行乘攻击面——每 Agent 最小权限+资源隔离+凭据分散。

**Q13：SecretRef？**
> 只传占位符执行时解析——凭据不进 Agent 上下文；明文注入 = 工具输出/日志/下游 Agent 三通道泄漏；与 Guardrails 08（凭据环境变量）衔接。

**Q14：治理第三层？**
> 框架+引擎不执行策略/审批门/审计轨迹——高风险副作用要独立治理层（Cordum 类 + OPA/Cedar 内核）；运行时解决"怎么活"，治理解决"该不该"。

## 6. 面试速记（终极压缩）

1. **运行时是分水岭**：框架管行为、运行时管生存——"持久性/编排/可恢复性是生产 Agent 的真正阻碍"。
2. **持久执行三件套**：事件日志+快照（重放不重跑）+ 恰好一次（幂等键）+ 重放边界（非确定性封装）。
3. **程序级调度**：整个 Agent 循环是调度单位——工具边界暂停/恢复、OS 五原语、车道队列、DAG 并行。
4. **可靠性与隔离**：单写者防并发破坏、SecretRef 防凭据泄漏、默认拒绝沙箱 + TDX——并行乘攻击面。
5. **分层选型**：LangGraph 逻辑 + Temporal 持久（30s 规则）+ 治理第三层；五测试实测——不跑是猜。
