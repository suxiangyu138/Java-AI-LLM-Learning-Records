# 评估数据集：从黄金集到生产种子

> 数据集 = 评估的"试题册"——2026 共识：**黄金集（golden sets）有结构性局限**（生产流量不像测试集、真实对话无 ground truth）；**生产种子是正解**——失败 trace 转测试用例，ground truth 必须包含工具调用与推理步骤。本章给数据集构建完整设计。

## 1. 黄金集的结构性局限

| 局限 | 机制 |
|---|---|
| 分布漂移 | 生产流量不像测试集（用户真实提问 vs 精心设计的用例） |
| 无 ground truth | 大多数真实对话没有标准答案 |
| 质量老化 | 模型升级后"好答案"的定义变了 |
| 覆盖盲区 | 手写用例漏长尾/对抗场景 |

> 🎯 核心要点：**黄金集是起点不是终点**——它测"精心设计的任务上表现如何"，测不出"真实流量上的退化"。2026 的答案：黄金集打底 + 生产种子持续注入。

## 2. 生产种子：失败 trace 转测试用例

| 步骤 | 做法 |
|---|---|
| 捕获 | 生产失败 trace（低分/错误/用户负反馈——观测体系采样） |
| 转化 | 失败 trace → 测试用例，**修正后的轨迹为 ground truth** |
| Ground truth 内容 | **期望的工具调用 + 推理步骤，不只是期望答案** |
| 注入 | 用例入离线评估集 + CI 回归（09 篇） |
| 频率 | 周更——防止数据集老化（Error Feed 模式） |

> ⚠️ 2026 关键细节：**Agent 的 ground truth ≠ 文本答案**——"期望的工具调用和推理步骤"才是 Agent 评估的地面真值（03 篇轨迹评估联动）；只存答案的测试用例测不出轨迹错误。

## 3. 三类用例组织

| 类别 | 内容 | 例子 |
|---|---|---|
| Happy path | 正常主流程 | 标准查询 → 正确工具链 |
| 边界 | 边缘输入/状态 | 空输入、超长输入、边界参数 |
| 对抗性 | 攻击与诱导 | 提示注入、离题请求、工具滥用（04 篇红队联动） |

> 💡 三类用例的比例没有固定答案——**按生产分布校准**（生产种子天然带分布信息）；对抗性用例从红队演练产出（Guardrails 08 篇红队构建期联动）。

## 4. 合成数据：冷启动与扩展

| 方式 | 框架 | 用途 |
|---|---|---|
| 合成测试数据 | Ragas 合成生成 | RAG 冷启动（无真实数据时） |
| 多轮合成 goldens | DeepEval v3.9.7（2025-12） | 多轮评估集冷启动 |
| Simulator | 人设 + 用户行为模型 | 多轮场景生成（04 篇） |
| 代理状态模拟 | LLM 状态追踪器（ACL 2026） | 无后端成本的多轮数据（03 篇） |

> ⚠️ 合成数据的边界：**合成 ≠ 真实**——合成集测"能力基线"，生产种子测"真实表现"；只靠合成的评估在真实流量上会虚高（与 00 篇 LODO 教训同源：分布不同 = 数字撒谎）。

## 5. 数据集治理

| 治理项 | 规范 |
|---|---|
| 版本化 | 变更时 tag + hash——回归可追溯 |
| 门禁 | 数据集变更触发全量回归（防"换题"假提升） |
| 去重 | 生产种子注入前去重（防单一失败模式虚增） |
| 分布标注 | 记录来源分布（golden/生产/合成占比） |
| 老化管理 | Error Feed 周更——不更新的评估集 6 个月后失真 |

> 🎯 核心要点：**数据集是活的资产不是静态文件**——版本化、去重、分布标注、周更；"换数据集刷分"与"模型升级刷分"同样要防（数据集门禁）。

## 6. 与相邻体系的分工

| 体系 | 分工 |
|---|---|
| 观测（采样/样本闭环） | 观测提供失败 trace 原料；本体系把它变成测试用例 |
| Guardrails（逃逸闭环） | 护栏逃逸样本入评估集——安全维度（08 篇同构） |
| Reflection 08（评测） | 反思评测测组件价值；数据集方法论同源 |

> 💡 三个闭环共享同一方法论：**失败 → 样本 → 评测集 → 回归**——观测的 trace、护栏的逃逸、评估的数据集是同一飞轮的三环（08 篇评估飞轮）。

## 7. 常见误区

| 误区 | 真相 |
|---|---|
| "黄金集够用" | 生产流量不像测试集——生产种子必加 |
| "ground truth=答案" | Agent 的 ground truth 含工具调用与推理步骤 |
| "合成数据=真实" | 合成测能力基线，生产种子测真实表现 |
| "数据集静态" | 周更 Error Feed——老化即失真 |
| "数据集不用版本化" | 换题刷分要防——tag/hash/门禁 |
| "失败 trace 直接当用例" | 修正后的轨迹才是 ground truth（原轨迹是错的） |
| "20 条用例够" | 20-50 场景起步 + 生产种子持续 |

## 8. 面试速记

| 问题 | 一句话答案 |
|---|---|
| 黄金集局限？ | 分布漂移/无 ground truth/老化/覆盖盲区 |
| 生产种子？ | 失败 trace 转用例，修正轨迹为 ground truth——周更 |
| Agent ground truth？ | 期望工具调用 + 推理步骤，不只答案 |
| 三类用例？ | happy path/边界/对抗性 |
| 合成数据边界？ | 测能力基线——生产种子测真实 |
| Error Feed？ | 失败样本周更入集——防老化 |
| 数据集版本化？ | tag/hash/门禁——防换题刷分 |
| 分布标注？ | golden/生产/合成占比记录 |
| 三个闭环共享？ | 失败→样本→评测集→回归（观测/护栏/评估同构） |
| 去重原因？ | 防单一失败模式虚增 |
| 合成框架？ | Ragas 合成/DeepEval 多轮 goldens/Simulator |
| 与观测分工？ | 观测给原料，评估变用例 |
