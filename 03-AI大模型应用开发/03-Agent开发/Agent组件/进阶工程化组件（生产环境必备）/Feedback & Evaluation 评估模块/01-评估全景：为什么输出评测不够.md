# 评估全景：为什么输出评测不够

> 评估 = 回答"Agent 做得好不好"的工程层。2026 核心反转：**输出评测（只评最终答案）不够**——"正确输出可以掩盖错误的推理"；**轨迹是评估单位**（工具选对了吗、参数对吗、顺序对吗）。本章立起全景：评估定位、输出 vs 轨迹、评估的四类度量。

## 1. 评估的定位

| 项 | 说明 |
|---|---|
| 定义 | 系统化度量 Agent 输出/行为/决策质量的工程 |
| 与评测（Benchmark） | 基准测"模型能力"；评估测"你的 Agent 在真实任务上表现" |
| 与可观测 | 观测记录"发生了什么"；评估判断"好不好"（观测 06 篇） |
| 与测试 | 单元测试测确定性代码；评估测概率性系统——两者互补 |

> 🎯 核心要点：评估回答三个问题——**"现在好吗"（离线评估）、"上线后好吗"（在线评估）、"在变好还是变坏"（持续评估）**——三问缺一，评估是摆设。

## 2. 输出评测为什么不够

| 输出评测的问题 | 轨迹评测的答案 |
|---|---|
| 只评最终答案 | 检查工具选择/参数化/顺序（TRAJECT-Bench） |
| 标准 pass/fail 漏 65-93% 安全问题 | 多维评估捕获静默失败 |
| "答对了"掩盖"过程错" | "正确输出可以掩盖错误的推理" |
| 看不到重试/检索遗漏/循环 | 轨迹暴露过程缺陷 |

> ⚠️ 2026 实证：**标准 pass/fail 指标漏掉 65-93% 的安全问题**（MorphLLM 2026）——"答案对"与"过程对"是两个维度；合规领域（需审计轨迹）轨迹评估是刚需。

## 3. 评估的四类度量

| 度量 | 对象 | 例子 |
|---|---|---|
| 输出度量 | 最终响应质量 | 相关性、忠实度、语气 |
| 轨迹度量 | 工具调用序列 | Tool Correctness、Argument Correctness、Step Efficiency |
| 会话度量 | 跨轮目标达成 | Conversation Completeness、Knowledge Retention |
| 系统度量 | 成本/延迟/安全 | 成本/样本、通过率、注入率 |

> 🎯 核心要点：四类度量是**递进关系**——输出度量管"答得怎样"、轨迹度量管"做得怎样"、会话度量管"成没成"、系统度量管"值不值"。2026 的评估设计从"选一个度量"走向"四层组合"。

## 4. 评估 vs 相邻概念

| 概念 | 区别 |
|---|---|
| 可观测（观测体系） | 观测记录"做了什么"（trace）；评估判断"好不好"（打分）——评估消费 trace |
| 护栏（Guardrails） | 护栏在线拦截（主动）；评估离线/采样判分（被动）——护栏触发率是评估输入 |
| 反思评测（Reflection 08） | 测反思组件的价值；本体系测 Agent 整体质量 |
| RAG 评估（RAG 08） | 测检索/生成质量；本体系覆盖含工具调用的完整 Agent |
| 单元测试 | 测确定性逻辑；评估测概率行为——CI 里并存 |

> 💡 一句话分工：**trace 是证据、护栏是闸门、评估是裁判、反思是教练**——裁判（评估）看录像（trace）判分，教练（反思）看录像提改进。

## 5. 评估的三种形态

| 形态 | 时机 | 用途 | 成本 |
|---|---|---|---|
| 离线评估 | 部署前 | 数据集跑分、选型、门禁 | 可控（固定集） |
| 在线评估 | 生产中 | 采样判分、漂移检测 | 采样 10-20%（05 篇） |
| 持续评估 | 全周期 | 回归、趋势、闭环（08 篇） | 自动化 |

> ⚠️ 2026 时态认知：**"上个月通过的 eval 说明不了这周"**（Vercel）——模型/工具/流量在变，评估必须是持续流水线（09 篇 CI 门禁）。

## 6. 评估质量的前提

| 前提 | 说明 |
|---|---|
| 数据集真实 | 生产流量种子化（05 篇）——golden 集不够 |
| Judge 可靠 | 混合模型 + 分解 rubric + 锁定版本（02 篇） |
| 指标定义一致 | 同名指标不可互换——锁定实现（06 篇） |
| 评估与生产同构 | 同一 evaluator 跑离线/CI/在线——防漂移 |
| 反馈闭环 | 人工纠正当 ground truth（08 篇） |

> 🎯 核心要点：**评估工程是"数据 × 裁判 × 指标 × 闭环"四件事**——任何一个薄弱，评估分数都是幻觉。2026 大量团队卡在"judge 好用但数据集是编的"。

## 7. 常见误区

| 误区 | 真相 |
|---|---|
| "评最终答案就行" | 漏轨迹/工具/会话问题——正确输出掩盖错误推理 |
| "通过率 95% 就是好" | 可能漏了 65-93% 安全问题——多维评估 |
| "评估=评测" | 基准测模型能力，评估测你的 Agent 表现 |
| "评估一次管一年" | 持续流水线——上个月过的说明不了这周 |
| "数据集手写几条" | 20-50 场景 + 生产种子——golden 不够 |
| "评分器随便用" | judge 有偏见——混合+锁定+校准 |
| "评估是上线前动作" | 离线/在线/持续三形态——全周期 |
