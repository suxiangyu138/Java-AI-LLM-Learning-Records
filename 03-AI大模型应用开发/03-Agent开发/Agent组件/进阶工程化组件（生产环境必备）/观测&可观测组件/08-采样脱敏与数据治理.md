# 采样、脱敏与数据治理

> 数据治理 = 观测数据（含全量 prompt/完成）本身就是风险资产。2026 三件套：**tail-based 采样**（失败稀有且高价值，head-based 是错误默认）、**collector 层脱敏**（策略集中不污染插桩代码）、**保留分层**（hot/warm/cold）。本章给观测数据治理完整设计。

## 1. 为什么 head-based 采样是错误默认

| 采样方式 | 机制 | LLM 系统问题 |
|---|---|---|
| Head-based | 发出时按比例丢弃 | **失败稀有且高价值**——随机丢弃会丢错 |
| Tail-based | collector 侧按特征决定保留 | 100% 保留错误/低分/高成本 + 1-10% 干净 |

> 🎯 核心要点：**采样目标是"保留诊断价值"，不是"减少存储"**——LLM 系统的失败（注入攻击、幻觉、循环失控）占比小但价值高；随机丢弃 = 丢证据。

## 2. Tail-based 采样规则（2026 标准）

| 保留类 | 规则 |
|---|---|
| 错误 | 100% 保留（所有错误 trace） |
| 低分 | 100% 保留（评估分低于阈值） |
| 高成本 | 100% 保留（>95 百分位成本） |
| 干净 | 1-10% 保留（趋势数据） |
| 开发/预发 | 100% 采样（MLflow 建议） |

> 💡 双轨采样：dev/staging 全量（训练评估集）、生产 tail-based（保诊断）——**评估集素材来自 dev 全量 + 生产错误/低分**。

## 3. Collector 层脱敏：策略集中化

| 项 | 说明 |
|---|---|
| 原则 | **在 collector 脱敏，不在应用脱敏** |
| 理由 | 插桩代码保持干净；策略集中一处可审计 |
| 手段 | collector 规则：正则/实体识别/字段丢弃 |
| 联动 | 输入护栏（Guardrails 02 篇）先拦应用侧，collector 兜底存储侧 |

> ⚠️ 2026 警示（Fiddler）：**捕获全量 prompt/completions 暴露客户数据/PII**——没有采样+脱敏+保留策略的观测平台是数据泄漏装置。合规场景（EU AI Act 09 篇联动）审计义务要求明确数据流向。

## 4. 保留分层

| 层 | 存储 | 周期 |
|---|---|---|
| Hot | ClickHouse 类 | 14-30 天（在线查询） |
| Warm | 列式 | 90 天 |
| Cold | 对象存储 | 1-7 年（合规要求时） |

> 🎯 核心要点：**热层只放"高诊断价值"**——hot 14-30 天足够在线排障；warm/cold 按合规保留。分层决策 = 查询需求 × 合规义务 × 成本（05 篇成本治理联动）。

## 5. 数据治理风险清单

| 风险 | 机制 | 治理 |
|---|---|---|
| PII 泄漏 | 全量 prompt/completions 入库 | 采样 + collector 脱敏 |
| 多轮上下文丢失 | 每轮新 trace（会话关联缺失） | conversation.id 传播（02 篇） |
| Span 爆炸 | 多 Agent 系统单请求数百 span | 采样 + 层级压缩（子 Agent 摘要） |
| 存储膨胀 | trace 嵌套大 | 保留分层 + 属性裁剪 |
| 治理合规 | 欧盟/行业数据义务 | 保留策略 + 审计（09 篇） |

> ⚠️ **Span 爆炸是 Agent 特有治理问题**：单请求到多 Agent 系统可产生数百 span——不做层级压缩（子 Agent 只存摘要）存储会失控；这与感知 08 篇"子 Agent 预算隔离"同构（隔离+摘要双管齐下）。

## 6. 采样与评估的联动

| 联动 | 机制 |
|---|---|
| 低分保留 → 评估样本 | tail-based 低分 100% 保留 = 评估的负样本来源 |
| 采样率影响质量统计 | 质量指标是采样集上的估计——标注采样率 |
| dev 全量 → 评估集 | 预发全量是训练/校准评估器的素材库 |
| 样本闭环 | 失败样本入评测集（Guardrails 08 篇同构） |

> 🎯 核心要点：**采样策略同时决定"能查什么"与"能评估什么"**——采样是观测与评估的共享基础设施；采样率变化要显式记录（评估结果跨采样率不可比）。

## 7. 常见误区

| 误区 | 真相 |
|---|---|
| "head-based 省事" | 随机丢 = 丢失败证据——失败稀有且高价值 |
| "应用层脱敏就够" | collector 集中脱敏——策略可审计、插桩干净 |
| "全量存储保完整" | 存储膨胀 + 合规风险——分层 + 采样 |
| "采样只是省钱" | 采样决定可诊断性——tail 保证据 |
| "单请求 span 不多" | 多 Agent 数百 span——层级压缩 |
| "多轮自动关联" | 每轮新 trace 是默认——conversation.id 要显式传播 |
| "数据治理是安全的事" | 观测数据流向是合规审计的一部分（EU AI Act） |
| "采样率不用记录" | 跨采样率评估不可比——必须显式记录 |
