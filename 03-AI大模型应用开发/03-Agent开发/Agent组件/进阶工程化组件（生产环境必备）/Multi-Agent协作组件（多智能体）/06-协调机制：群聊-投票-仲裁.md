# 协调机制：群聊-投票-仲裁

> 协调 = 多个 Agent 如何达成一致：群聊（讨论）、投票（决策）、仲裁（分歧解决）。2026 现状：**群聊最流行也最贵**（管理器重读历史税）；**协调机制是 token 消耗大户**，选型要看"共识价值 vs 往返成本"。本章给协调机制全景与工程规范。

## 1. 三种协调机制

| 机制 | 模式 | 共识方式 | 成本 |
|---|---|---|---|
| 群聊（Group Chat） | 多 Agent 对话共享上下文 | 讨论趋同 | 高（历史重读） |
| 投票（Voting） | 独立决策聚合 | 多数/加权 | 中（并行独立） |
| 仲裁（Arbitration） | 分歧 → 裁判判定 | 裁判权威 | 低（只在分歧时） |

> 🎯 核心要点：**协调成本与分歧概率挂钩**——分歧少用仲裁（按需触发），分歧多用群聊/投票（前置消解）；"全体参与每轮"是最大浪费。

## 2. 群聊机制深潜

| 项 | 说明 |
|---|---|
| 模式 | 共享会话 + 管理器调度发言 |
| 优点 | 信息共享充分、多视角 |
| 缺点 | **历史重读税**（AutoGen RoundRobinGroupChat 每轮重读全历史）；发言顺序偏见（位置偏见，评估 02 篇同源） |
| 适用 | 需要多视角的任务（头脑风暴/方案评审） |
| 治理 | 发言轮次上限 + 主题约束（防九日循环，02 篇） |

> ⚠️ 群聊的工程约束：**广播 vs 定向要选**——全员参与（广播）适合共识型，定向 @ 适合任务型（05 篇交接）；默认广播的群聊 = token 乘数的放大器。

## 3. 投票机制深潜

| 维度 | 说明 |
|---|---|
| 模式 | 各 Agent 独立决策 → 聚合 |
| 聚合 | 多数/加权（信任分加权，ACP 声誉联动 04 篇）/模型权重 |
| 优点 | 并行独立、无顺序偏见 |
| 缺点 | 独立偏见同源（自判偏见，评估 02 篇）；无讨论信息共享 |
| 适用 | 分类/选型/事实判定 |
| 实证 | 多评委（MARS 类）反馈多样性提升（Reflection 03 篇联动） |

> 💡 投票与 judge 混合是 2026 常见组合：**投票选"哪个好" + judge 评"好在哪"**——决策与理由分离；跨家族模型投票可打破自判偏见。

## 4. 仲裁机制深潜

| 项 | 说明 |
|---|---|
| 模式 | 分歧提交 → 裁判 Agent 判定（带理由） |
| 触发 | 争议检测（结果分歧/置信低）——不是每次都仲裁 |
| 裁判选择 | 独立模型/更强模型（评估 02 篇 tier 3） |
| 优点 | 按需触发成本可控 |
| 缺点 | 裁判本身可能错（单一权威） |
| 治理 | 仲裁可申诉/人工升级（Guardrails 09 篇人工路径联动） |

> 🎯 核心要点：**仲裁是"争议时裁判"不是"每次都裁判"**——争议检测机制（置信度/分歧度阈值）决定仲裁触发率；仲裁与人工升级的衔接是合规场景的出口。

## 5. 冲突解决：协调的兜底

| 冲突类型 | 解决机制 |
|---|---|
| 结果分歧 | 仲裁（§4） |
| 资源竞争 | 锁/优先级（乐观并发，Tool 体系联动） |
| 目标冲突 | 优先级链/人工裁决 |
| 信息矛盾 | 来源链验证（观测 06 篇遥测契约） |

> ⚠️ 资源竞争是协调的暗面：**两个 Agent 操作同一资源**（并发写）——无锁的多 Agent 写 = 数据竞争；乐观锁 + 冲突重试是标准解（与 Tool 06 篇并行纪律同源）。

## 6. 协调机制的选型

| 场景 | 机制 |
|---|---|
| 多视角方案 | 群聊（定向 + 轮次上限） |
| 分类/选型 | 投票（并行独立） |
| 高利害分歧 | 仲裁（独立裁判 + 人工升级） |
| 明确子任务 | 不协调——交接（05 篇） |
| 松散耦合 | 事件（编排舞，02 篇） |

> 🎯 核心要点：**协调是最后手段**——能交接的不群聊、能仲裁的不全员投、能定向的不广播；协调机制的选择 = 共识价值 × 往返成本 × 分歧概率的三维权衡。

## 7. 常见误区

| 误区 | 真相 |
|---|---|
| "群聊最民主" | 历史重读税 + 顺序偏见——能定向不广播 |
| "投票一定准" | 独立偏见同源——跨家族 + 加权 |
| "每次仲裁" | 争议触发仲裁——不是每轮裁判 |
| "协调免费" | 协调是 token 大户——选型看共识价值 |
| "全体参与" | 明确任务用交接——协调是最后手段 |
| "多 Agent 写无竞争" | 资源竞争——锁/优先级 |
| "裁判权威无限" | 仲裁可申诉——人工升级出口 |

## 8. 面试速记

| 问题 | 一句话答案 |
|---|---|
| 三机制？ | 群聊（讨论）/投票（聚合）/仲裁（裁判） |
| 群聊缺点？ | 历史重读税 + 顺序偏见 |
| 投票优点？ | 并行独立、无顺序偏见——跨家族破自判 |
| 仲裁触发？ | 争议检测——不是每轮裁判 |
| 仲裁治理？ | 可申诉 + 人工升级 |
| 冲突四类？ | 结果/资源/目标/信息——各自机制 |
| 资源竞争解？ | 乐观锁 + 冲突重试 |
| 选型第一原则？ | 协调是最后手段——能交接不群聊 |
| 广播 vs 定向？ | 共识型广播、任务型定向 |
| 与评估 02 联动？ | 位置偏见/自判偏见同源 |
| 与 ACP 联动？ | 信任分加权投票——声誉系统 |
| 最贵机制？ | 群聊（每轮重读）——AutoGen 税案例 |
