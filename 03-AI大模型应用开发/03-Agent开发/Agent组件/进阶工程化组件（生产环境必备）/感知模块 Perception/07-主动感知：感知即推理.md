# 主动感知：感知即推理

> 主动感知 = Agent 按当前推理需求**选择性请求信息**，而非全量摄入——感知本身成为推理循环的一部分。2026 实证：预推理感知同准确率 token 减 **57.1%**；有界观察 **2-3 轮最优**（超限引入噪声）。本章给主动感知的机制、工程化与代价。

## 1. 为什么需要主动感知

| 被动感知的问题 | 主动感知的解法 |
|---|---|
| 长输入全量进窗口（token 爆炸） | 只观察与任务相关的片段 |
| 无关信息稀释信号（03 篇噪声实证） | 按推理需求过滤感知目标 |
| 视频/传感器数据无限增长 | 自适应采样密度 |
| 感知与推理脱节（感知完才推理） | 感知-推理交织循环 |

> 🎯 核心要点：主动感知的本质——**"感知也是决策"**：Agent 决定看什么、何时看、看到什么程度。感知从机械前置步骤变成推理循环的一部分（01 篇趋势第二条）。

## 2. Perceive Before Reasoning：预推理感知（2026）

| 项 | 说明 |
|---|---|
| 出处 | arXiv 2606.03236（主动移动 Agent 框架） |
| 机制 | 感知函数 + 干预门（intervention gate）：推理前先按任务感知，门控决定是否深入 |
| 效果 | token 消耗减 **~57.1%**，准确率保持 50.5% 不变 |
| 意义 | 实证"少感知反而更准/更省"——感知的边际收益递减，全量是浪费 |

> ⚠️ 关键细节：**干预门是主动感知的核心工程件**——不是"感知函数越多越好"，而是"何时触发/跳过感知"由门控逻辑决定（类似 Guardrails 07 篇的按风险开关）。

## 3. AOP-Agent：observe-reflect-replan 循环

| 循环 | 动作 |
|---|---|
| Observe | 主动选择要检查的音视频证据片段 |
| Reflect | 反思已观察到的是否足够回答 |
| Replan | 决定下一轮观察什么或终止 |

| 实证发现 | 数据 |
|---|---|
| Planner+Reflector 优于直接推理 | MOV-Bench 多跳音视频推理稳定提升 |
| **有界观察 2-3 轮最优** | 过度观察引入噪声，性能回退 |
| 局限 | 推理开销、幻觉/错误传播、非流式记忆限制实时应用 |

> 🎯 核心要点：**有界观察 = 主动感知的停止规则**——与 Reflection 04 篇（反思轮次控制 2-3 轮）同源思想：循环类机制都要"第几轮必须停"的硬规则，否则边际收益变负。

## 4. ToolScope：把 Perceive 做成工具（ACL 2026）

| 项 | 说明 |
|---|---|
| 架构 | Global Navigator（全局规划）+ Agentic Executor（局部执行） |
| 感知机制 | Search/Code/Perceive 三个工具——Perceive 是"局部多模态感知"工具 |
| 动机 | 长程 VQA 任务中视觉上下文退化——按需局部感知缓解 |
| 意义 | **感知工具化**：感知不再藏在管道里，而是 Agent 可主动调用的工具 |

> 💡 感知工具化的启发：把"看"变成工具后，感知获得三个能力——**可调度**（规划器决定何时看）、**可预算**（工具调用有次数上限）、**可审计**（工具调用有日志）。这与 Tool 体系完全同构。

## 5. 自适应采样：感知的密度调节

| 场景 | 采样策略 | 数据 |
|---|---|---|
| 长视频 | 密度随时长下降 | OmniAgent：16.9 → 5.7 轮/段，准确率保持 |
| 流式音频 | VAD 门控 | 无声不编码（05 篇） |
| 高噪界面 | 渐进聚焦 | DRS-GUI：Focus/Shift/Scatter 感知动作（04 篇） |

> 🎯 核心要点：**采样密度与信息增益挂钩，不是与输入长度挂钩**——输入越长，每单位感知的信息增量越低，密度就该下降。这是感知压缩（02 篇 Resampling 法族）的动态版。

## 6. 主动感知的代价清单

| 代价 | 说明 | 治理 |
|---|---|---|
| 推理开销 | 观察-反思循环每轮一次推理 | 轮次上限（2-3） |
| 错误传播 | 观察错误被后续推理放大 | Reflector 验证 |
| 非流式记忆 | 记忆不支持流式 → 实时受限 | 记忆架构升级 |
| 调度复杂性 | 何时感知/跳过由 Agent 决定 | 干预门 + 预算 |

> ⚠️ 2026 结论：主动感知不是"免费午餐"——**省 token 用推理复杂度换**。短任务/低噪场景被动感知更简单可靠；长输入/高噪/多模态场景主动感知收益才显著。

## 7. 常见误区

| 误区 | 真相 |
|---|---|
| "感知越多越准" | 有界观察实证：超 2-3 轮性能回退 |
| "主动感知永远省 token" | 用推理复杂度换 token——短任务被动更简单 |
| "观察-反思无限循环" | 必须轮次上限——Reflection 04 同源 |
| "Perceive 工具是插件" | 感知工具化带来可调度/可预算/可审计 |
| "全量采样最稳" | 自适应密度：输入越长密度越低，准确率保持 |
| "主动感知是研究话题" | 2026 已工程化：-57.1% token 实证、工具化落地 |
| "感知与推理分开" | 主动感知下感知-推理交织——感知即决策 |
