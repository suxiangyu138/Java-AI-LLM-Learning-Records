# 生产实践与面试冲刺

> 收官篇：把 01-09 收敛成可执行的落地清单与面试弹药。2026 生产基线：**管道四段解耦、被动→主动感知、装配按 U 型策略、评测三层闭环**——感知的产出是上下文，感知的 KPI 是信噪比。

## 1. 生产落地清单（上线前逐项打勾）

### 1.1 管道与处理

| 检查项 | 标准 |
|---|---|
| 管道解耦 | 连接器/嵌入/特征提取/装配四段独立演进 |
| 连接器规范 | 统一抽象 + 增量 + 最小鉴权 + 来源标记 |
| 文本清洗 | 编码/格式/噪声/脱敏四类规则就位 |
| 结构化 | 只结构化影响决策的部分（够用原则） |
| 压缩 | 感知压缩四法族已评估，**精度账已算**（非免费） |

### 1.2 多模态与视觉

| 检查项 | 标准 |
|---|---|
| 视觉接入 | 图像/GUI 场景 grounding 机制明确（解析工具/视觉标记） |
| 视觉上下文 | 按需 zoom-in，不高分辨率全图进窗口 |
| Omni 选型 | 双轨验证：Agent 基准 + 多模态基准（防 omni 税） |
| 延迟预算 | 视觉 112ms/音频 98ms/文本 17ms 对照 |
| 全双工 | 打断管理 + VAD 门控（语音场景） |

### 1.3 主动感知与装配

| 检查项 | 标准 |
|---|---|
| 主动感知 | 有界观察（2-3 轮上限）+ 干预门 |
| 装配位置 | 关键约束在首尾、参考资料在中间（U 型） |
| 装配预算 | JIT 加载 + 子 Agent 隔离 + 分层压缩 |
| 装配体检 | 五失败模式检查单（毒化/分心/混淆/冲突/腐烂） |
| turn-level | 每轮五选一决策机制（continue/rewind/clear/compact/delegate） |
| 缓存纪律 | 静态在前变化在后；机器上下文移出 system prompt |

### 1.4 评测与治理

| 检查项 | 标准 |
|---|---|
| 三层评测 | 元素级 + 任务级 + 组件级 |
| grounding 基准 | ScreenSpot-Pro 类基准对照 + 生产 heldout 集 |
| 失败分类 | 推理/感知/grounding 分类学监控 |
| 样本闭环 | 感知失败 → 分类 → 评测集 → 组件改进 → CI |
| 环境感知 | 时间注入 + 权限探测 + 环境判断 |

## 2. 十二大避坑

| # | 坑 | 后果 | 解法 |
|---|---|---|---|
| 1 | 原始文本全量进窗口 | 噪声稀释（8.0% vs 23.6%） | 清洗 + 去噪（03 篇） |
| 2 | 上下文堆到 80% | 精度 94%→61% | 装配预算治理（08 篇） |
| 3 | 关键内容放中段 | 比不检索更糟（U 型实证） | 首尾策略（08 篇） |
| 4 | 高分辨率全图给模型 | token 爆炸 + 注意力稀释 | zoom-in 按需（04 篇） |
| 5 | grounding 全靠模型 | 39.5% 天花板 | OmniParser/视觉标记/区域搜索（04 篇） |
| 6 | 被动全量感知 | token 浪费 + 噪声 | 主动感知 + 干预门（07 篇） |
| 7 | 观察循环无上限 | 超 2-3 轮性能回退 | 有界观察（07 篇） |
| 8 | 不注入当前时间 | 模型不知道今天几号 | 时间放窗口首部（06 篇） |
| 9 | 权限假设有 | 被拒浪费一轮 | 探测优先（06 篇） |
| 10 | 感知压缩免费 | 源码压缩 SWE-bench 50%→38% | 精度账先算（02 篇） |
| 11 | 只测端到端 | 感知弱点被掩盖 | 三层评测（09 篇） |
| 12 | 拼装多模态 | 延迟/碎片/成本三座大山 | Omni 统一入口（05 篇） |

> 🎯 核心要点：12 坑的根因是三个——**信号治理缺失（1-3、8、10）、感知形态落后（4-6、12）、评测反馈缺失（7、9、11）**。按 03/04/07/08/09 篇规范做，12 坑自动消失。

## 3. 指标体系

| 指标 | 计算 | 目标 |
|---|---|---|
| 信噪比 | 高信号 token/窗口总 token | 高（装配 KPI） |
| 感知精度 | 元素级命中率（分类型） | 按模态定 |
| Grounding 成功率 | 动作定位像素容差内比例 | 越高越好（基线对照基准） |
| 感知成本 | 每模态 token/延迟 | 预算对照（112/98/17ms） |
| 信号利用率 | 装配内容被引用比例 | 高（低=装配冗余） |
| 压缩比 | 原始量 vs 窗口量 | 跟踪 + 精度对照 |
| 失败分布 | 推理/感知/grounding 占比 | 趋势监控 |
| 观察轮次 | 主动感知平均轮次 | ≤3 |

> 💡 最该盯的两个：**信噪比**（装配质量总纲）与**感知成本**（感知是 token 大户，成本失控 = 产品亏损）。

## 4. 面试题（14 题 + 答题范式）

### 4.1 基础（必答）

**Q1：感知模块是什么？四段管道？**
> Agent 的感官接口：环境原始输入→结构化上下文。四段：连接器（数据接入）→嵌入（向量化）→特征提取（模式识别）→上下文装配（组装窗口）。感知与推理/记忆/行动/反馈组成连续循环。

**Q2：被动 vs 主动感知？**
> 被动全量摄入 vs 按需观察。Perceive Before Reasoning 实证：同准确率 token 减 57.1%——长输入/多模态场景主动感知是主流。

**Q3：上下文装配的实证基础？**
> U 型注意力：关键内容放中段比不检索更糟（GPT-3.5 第 10/20 文档 52.9% < 无文档 56.1%）。铁律：预载是预算、先切噪声体积。

### 4.2 进阶（加分）

**Q4：噪声与体积的实证？**
> 纯噪声 8.0% vs 不检索 23.6%（噪声比没有更差）；40%→80% 填充精度 94%→61%（体积是敌人）。小窗口+对的信息 > 大窗口+全的信息。

**Q5：GUI grounding 怎么做？**
> 三路：训练法（SeeClick/ShowUI）、训练免费区域搜索（DRS-GUI +14%）、视觉标记（HiViG +5.8-9.0%）。OmniParser 把截图解析成结构化元素（V2 39.5% ScreenSpot Pro）。

**Q6：Omni 感知是什么？为什么取代拼装？**
> 单一模型统一视觉+音频+语言。拼装三痛：延迟叠加/上下文碎片/成本叠加。Nemotron 3 Nano Omni（9x 吞吐）、MiMo-V2-Omni（无 omni 税）。时间对齐是统一入口的关键。

**Q7：主动感知的停止规则？**
> 有界观察 2-3 轮最优（AOP-Agent 实证，超限引入噪声）——与 Reflection 04 篇轮次控制同源：循环机制都要停止规则。

**Q8：五失败模式？**
> 毒化（错误信息当真理）/分心（历史淹没推理）/混淆（无关工具选错）/冲突（同窗矛盾）/腐烂（填满后退化）——每次装配前五个"否"体检。

### 4.3 架构与前沿（拉开差距）

**Q9：感知评测三层？**
> 元素级（哪里错，ScreenSpot Pro）/任务级（影响多大，OSWorld）/组件级（换哪个）。CUA-Suite 的像素级因果密集监督是 2026 分水岭。

**Q10：感知失败怎么定位？**
> CUADebug 分类学：推理/感知/grounding 三类不同病不同药——"点击错按钮"要查是 OCR 识别错（感知）还是坐标定位错（grounding）。

**Q11：装配工程策略？**
> JIT 加载（预载通用+按需条件）、子 Agent 预算隔离、分层压缩（卸载→摘要）、state-carry（O(n²)→O(n)）、缓存纪律（静态在前变化在后）、KI 预计算（-3.6x 成本 +29 点精度）。

**Q12：环境感知为什么重要？**
> 行动的许可证：时间注入（模型不知道今天几号）、权限探测优先（防浪费轮次）、时序新鲜度。ContextAgent 的感知-预判-主动是最高形态。

**Q13：感知压缩的代价？**
> JSON→TOON 省 27% 精度回归 9-14 点；源码压缩省 42% SWE-bench 50%→38%——省 token 前先算精度账，压缩不是免费的。

**Q14：感知与相邻组件的关系？**
> RAG 是感知的检索子通道；护栏是感知管道上的拦截点（外部输入先拦后处理）；记忆管跨轮存储（感知管窗口入口）；Output Parser 是输出侧对称组件。

### 4.4 答题范式

| 原则 | 说明 |
|---|---|
| 结构优先 | 定义 → 管道 → 实证 → 工程（四段式） |
| 带数据 | "-57.1% token""8.0% vs 23.6%""39.5% grounding"——实证碾压空谈 |
| 说权衡 | "主动感知省 token 用推理复杂度换""压缩省 token 有精度税" |
| 落工程 | 补一句"生产上我怎么做"（装配体检/三层评测/样本闭环） |
| 提边界 | 何时不做：短任务被动更简单；低噪场景不搞主动感知 |

## 6. 面试速记（终极压缩）

1. **感知是感官接口**：连接器→嵌入→特征→装配四段；产出是上下文不是数据；KPI 是信噪比。
2. **主动感知主流**：按需观察（-57.1% token）、有界 2-3 轮、Perceive 工具化——感知即决策。
3. **装配按实证**：U 型注意力（关键放首尾）、五失败体检、JIT/隔离/分层压缩、KI 预计算。
4. **视觉/GUI 工程化**：OmniParser + 视觉标记 + 区域搜索；39.5% grounding 是天花板不是终点。
5. **评测三层闭环**：元素/任务/组件三层 + 失败分类学 + 样本闭环——评测指导工程。
