# 面试冲刺

> 深化篇：LLM 大脑的 10 题面试冲刺——覆盖本组件全部知识点，可直接背诵。

## Q1：LLM 大脑在 Agent 中的定位？

> Agent 的推理决策核心——"想什么、怎么想、做什么决定"。它不执行工具（决策-执行分离）、不保存记忆（记忆组件）、不感知原始输入（感知模块）；输入是感知装配的上下文 + 记忆召回，输出是行动指令（工具调用/计划/回复）。

## Q2：ReAct 循环是什么？2026 状态？

> Thought→Action→Observation 循环（2022 提出）——想、做、看、循环直到最终回答。2026 状态：原生工具调用内建在每款前沿模型（GPT-5.5/Claude Opus 4.7/Gemini 3.1 Pro），文本式 ReAct 提示格式已成历史，**底层循环不变**——"正是现代 Agent 的工作方式"。

## Q3：thinking tokens 是什么？为什么重要？

> 推理模型的内部思考（起草→核对→修订→输出）——隐藏但计费。重要性：**推理质量的新计算轴**（test-time compute）；收益递减（no→medium 陡、high→max 平，Snell 计算最优）——"有正确的思考量"，路由与旋钮是成本控制正解。

## Q4：推理模型与普通模型怎么选？

> 多步可验证任务（数学/代码/规划/工具排序）→ 推理模型；查找/摘要/高量分类 → 快速模型。混合：推理模型决策轮 + 快速模型执行轮（按轮路由）；GPT-5 实时路由自动降档省 50-80% 输出 token。

## Q5：thinking 能调试吗？

> 厂商 API 不可见（服务端内部）——只看到最终输出；开源模型可见（DeepSeek-R1 完整轨迹、Trinity/Mellum2 `<think>` 块）。调试替代方案：记录输入/输出 + 评估决策质量（Trace 带模型版本与思考参数）。

## Q6：推理模型是完整 Agent 吗？

> 不是——**只提高每步决策质量，不消除 Agent 循环**（"如果计划需要多次工具调用，你仍然需要循环"）；且推理模型**无内置持久记忆**（跨请求即忘）——生产 Agent 必须接外部记忆层（Mem0 类）。

## Q7：决策质量怎么评估？

> 四维：选择正确性（ToolSelectionAccuracy）/参数正确性（FunctionCallAccuracy）/时机正确性（irrelevance 与 missing-tool 桶）/顺序正确性（轨迹评估）。BFCL v3：前沿 88-94%，头部差距小，**差距在 irrelevance 与 missing-tool**。

## Q8：2026 推理模型家族？

> OpenAI o 系列/GPT-5 thinking（实时路由）、Claude thinking（budget_tokens）、Gemini thinking（thinkingBudget/Deep Think 1M+）、DeepSeek-R1（开源完整轨迹）、Trinity-Large-Thinking（398B MoE，PinchBench 91.9% #2，比 Opus-4.6 便宜 96%）、Nemotron 3 Super（MTP 3x 加速）、MAI-Thinking-1（256K，无记忆）。

## Q9：大脑的成本怎么控？

> 三旋钮：思考量（budget_tokens/effort 按任务难度）+ 路由（简单任务快速模型省 50-80%）+ 蒸馏（推理轨迹蒸馏给小模型）。递减收益提醒：高思考档位几乎无增益——"花在思考上的钱过了拐点就是浪费"。

## Q10：2026 大脑架构前沿？

> SR²AM 三系统（反应/模拟推理/自调节——RL 后规划视野 +22.8%）、ACTS 推理转向（控制器观 reasoning trace 发转向指令，MDP 建模）、AgentFlow 四模块流内优化（7B 超 GPT-4o +14.9%）、ComAgent 感知-规划-行动-反思闭环。
