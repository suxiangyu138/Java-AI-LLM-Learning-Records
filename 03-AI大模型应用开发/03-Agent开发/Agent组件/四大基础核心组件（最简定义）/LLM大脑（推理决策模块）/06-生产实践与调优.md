# 生产实践与调优

> 深化篇：LLM 大脑的生产落地——路由、思考旋钮、监控、调优清单。生产级细节见 [Function Calling 09 篇](..%2F..%2F..%2F..%2F02-大模型基础与Prompt工程%2FFunction%20Calling%20函数调用【Agent%20基石】%2F09-生产实践与成本优化.md)。

## 1. 路由：大脑的"分诊台"

| 路由策略 | 机制 | 收益 |
|---|---|---|
| 模型内路由 | GPT-5 实时路由（fast/deep 自动选） | 省 50-80% 输出 token |
| 应用层路由 | 按任务类型分发（推理模型/快速模型） | 成本精准 |
| 按轮路由 | 决策轮推理模型 + 执行轮快速模型 | 混合最优（05 篇） |
| 动态降级 | 高负载降级快速模型 | 吞吐保障 |

> 🎯 核心要点：**路由是 2026 成本控制的第一杠杆**——"用推理模型做多步可验证任务，用快速模型做查找摘要"（03 篇选型）；路由错误 = 要么贵要么错。

## 2. 思考旋钮调优

| 旋钮 | 调法 | 适用 |
|---|---|---|
| budget_tokens（Claude） | 8k-16k 起步，按任务复杂度调 | 规划/多步任务 |
| reasoning_effort（OpenAI） | low/medium/high 三档 | 按任务难度分档 |
| thinkingBudget（Gemini） | 长上下文开 Deep Think | 长文档推理 |
| 关闭思考 | 简单任务关 thinking | 查找/格式轮 |

> ⚠️ 递减收益铁律：**"高思考"档位收益趋平（high→max 几乎无增益）**——调优顺序：先确认任务该用推理模型（路由）→ 再调思考档位（旋钮）→ 最后看成本账（03 篇）。

## 3. 监控指标

| 指标 | 信号 |
|---|---|
| 思考成本占比 | 思考 token / 总 token——超预期说明路由错 |
| 决策正确率 | ToolSelectionAccuracy 趋势——模型/提示回归 |
| 思考时长 | 每决策延迟——P99 监控 |
| 模型漂移 | 同提示不同决策率——模型升级后必查 |
| 路由分布 | 推理/快速模型调用比——成本结构 |

> 💡 与观测体系联动：**trace 必须带模型版本 + 思考参数**——决策漂移归因的第一步（PromptOps 06 篇）；"模型升级后行为漂移"是 2026 高频事故（观测 09 篇闭环）。

## 4. 调优清单

| 检查 | 动作 |
|---|---|
| 路由正确吗 | 简单任务是否误用推理模型（成本账） |
| 思考档位对吗 | 高思考收益是否趋平（递减收益） |
| 提示词匹配吗 | 模型升级后提示词回归（PromptOps） |
| 记忆接了吗 | 推理模型跨请求即忘（Mem0 类） |
| 评估在跑吗 | 决策质量采样判分（Evaluation 06 篇） |
| 成本有账吗 | 思考 token 计入 Trust Tax（评估 09 篇） |
| 降级预案 | 高负载降级快速模型 |

## 5. 常见生产问题

| 问题 | 根因 | 解法 |
|---|---|---|
| 成本爆炸 | 全部任务用推理模型 | 路由 + 思考档位 |
| 决策漂移 | 模型升级/提示词变化 | 版本回归 + 评估 |
| 长会话失忆 | 推理模型无记忆 | 外部记忆层（Memory 组件） |
| 思考不可调试 | 厂商 API 隐藏轨迹 | 开源模型 / 记录输入输出 |
| 延迟超标 | 高思考档 + 长上下文 | 降档 + 缓存（PromptOps 缓存纪律） |

## 6. 面试速记

| 问题 | 一句话答案 |
|---|---|
| 路由第一杠杆？ | 推理模型做多步可验证、快速模型做查找摘要 |
| 按轮路由？ | 决策轮推理 + 执行轮快速 |
| 旋钮调优顺序？ | 先路由确认 → 再调思考档 → 后看成本 |
| 思考成本占比？ | 超预期 = 路由错 |
| 模型漂移？ | 同提示不同决策——升级后必查 |
| 调优清单首项？ | 路由正确吗（成本账） |
| 长会话失忆？ | 外部记忆层——推理模型跨请求即忘 |
| 与观测联动？ | trace 带模型版本 + 思考参数 |
| 降级预案？ | 高负载降级快速模型 |
| 与评估联动？ | 决策质量采样判分 + Trust Tax |
