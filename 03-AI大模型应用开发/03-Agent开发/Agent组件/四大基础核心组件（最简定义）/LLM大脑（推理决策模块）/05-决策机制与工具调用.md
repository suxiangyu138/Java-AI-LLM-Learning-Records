# 决策机制与工具调用

> 深化篇：大脑"怎么输出决策"——决策形态、tool_calls 机制、决策质量评估。协议细节见 [Function Calling 体系](..%2F..%2F..%2F..%2F02-大模型基础与Prompt工程%2FFunction%20Calling%20函数调用【Agent%20基石】%2F00-FunctionCalling知识体系总览.md)。

## 1. 决策的三种输出形态

| 形态 | 机制 | 例子 |
|---|---|---|
| 文本回复 | 直接回答 | 查询结果汇报 |
| 工具调用 | 结构化请求（tool_calls） | `{"name": "get_order", "arguments": {...}}` |
| 计划 | 多步行动方案（Plan-Execute） | "先查库存 → 再算运费 → 最后下单" |

> 🎯 核心要点：**决策形态决定下游动作**——文本给用户、工具调用给执行器、计划给规划组件（Planner 01 篇）；"决策 = 形态选择 + 内容生成"两个层面。

## 2. tool_calls 机制（决策→执行的桥）

```text
决策到执行：
  LLM 输出 tool_calls（决策）
    → 宿主解析 arguments（JSON 字符串，需 parse）
    → 校验（schema + 授权）
    → 执行（模型不碰真实世界）
    → 结果回注（tool 消息 + tool_call_id 配对）
    → LLM 继续推理（消化结果）
```

| 环节 | 关键点 |
|---|---|
| 参数解析 | OpenAI arguments 是 JSON 字符串（Anthropic 直接是对象） |
| 配对 | tool 消息必须引用已存在的 tool_call_id |
| 顺序 | tool_calls 消息先追加、结果后追加（协议要求） |
| 并行 | parallel_tool_calls 默认开——有依赖时关掉 |

> ⚠️ 2026 铁律（Tool 06 篇）：**模型输出不可信**——校验/授权/审计全在执行层；arguments 是字符串要 parse，parse 失败要给结构化错误返回（invalid_arguments）而非静默。

## 3. 决策质量的四维

| 维度 | 问题 | 度量 |
|---|---|---|
| 选择正确性 | 调对工具了吗 | ToolSelectionAccuracy |
| 参数正确性 | 参数有效吗 | FunctionCallAccuracy |
| 时机正确性 | 该调时调了吗（irrelevance/missing） | BFCL 桶分析 |
| 顺序正确性 | 依赖顺序对吗 | 轨迹评估（Evaluation 03 篇） |

> 💡 2026 评估实证（BFCL v3）：前沿模型 88-94%——**头部差距小，差距在 irrelevance（不该调时调）与 missing-tool（该调没调）**；决策质量评估不能只看"调用了没"，要看"该不该调、调得对不对"（03 篇三大误区联动）。

## 4. 推理模型在决策链中的位置

```text
决策链（2026 生产形态）：
  推理模型（规划/决策轮）——思考充分：选工具/定顺序/拆步骤
    → 快速模型（执行/格式轮）——高效执行：格式化/摘要/简单调用
    → 反思（关键步骤后）——质量把关（Reflection 02 篇）
```

| 轮次 | 模型 | 理由 |
|---|---|---|
| 决策轮 | 推理模型 | 多步可验证决策需要思考 |
| 执行轮 | 快速模型 | 确定性动作无需过度思考 |
| 反思轮 | 独立评判器 | 打破同模型盲区（Reflection 02 篇） |

> 🎯 一句话：**"大脑也是分层架构"**——推理模型想大事、快速模型干小事、评判器把质量关；单模型走天下的时代结束（2026 生产共识）。

## 5. 决策失败与恢复

| 失败 | 机制 | 恢复 |
|---|---|---|
| 参数错误 | schema 不符 | 结构化错误回传 → 模型修正（Tool 06 篇） |
| 工具不存在 | unknown_tool | 提示工具列表 |
| 决策漂移 | 同任务不同决策 | 评估 + 回滚（PromptOps 06 篇） |
| 循环决策 | 重复相同调用 | 断路器 + 轮次预算（Orchestrator 05 篇） |

> ⚠️ 2026 关键：**"决策失败要可观测"**——每次决策（含 rejected）留痕：trace 带决策输入/输出/拒绝原因（观测 02 篇）；不可观测的决策层是事故黑洞。

| 决策可观测？ | 每次决策留痕——trace 带输入输出 |
