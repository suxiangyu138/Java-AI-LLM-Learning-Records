# 推理模型家族与选型

> 深化篇：LLM 大脑的"硬件选型"——2026 推理模型谱系、选型决策与成本模型。完整版见 [LLM-API 体系](..%2F..%2F..%2F..%2F02-大模型基础与Prompt工程%2FLLM-API%2F00-LLM%20API知识体系总览.md)。

## 1. 推理模型家族（2026）

| 家族 | 模型 | 思考暴露方式 | 特点 |
|---|---|---|---|
| OpenAI | o 系列 / GPT-5 thinking | reasoning_effort（low/med/high）+ 实时路由 | 路由自动选 fast/deep——省 50-80% 输出 token |
| Anthropic | Claude thinking | budget_tokens（min 1024，8k-16k 起步） | 跨工具调用交错思考 |
| Google | Gemini 2.5 thinking | thinkingBudget（Deep Think 1M+ 上下文） | 长上下文推理 |
| 开源 | DeepSeek-R1 | 完整推理轨迹（可见） | 开源权重、RL 训练 |
| 开源 | Trinity-Large-Thinking | `<think>` 块 | 398B MoE（13B 激活）、PinchBench 91.9%（#2）、比 Opus-4.6 便宜 96% |
| 开源 | Nemotron 3 Super | MTP 多 token 预测 | Mamba-Transformer MoE、内建投机解码（3x 加速） |
| 微软 | MAI-Thinking-1 | 推理循环 + 可解释轨迹 | 256K 上下文；**无内置持久记忆**（生产需外部记忆层） |

> 🎯 关键趋势：**"thinking 是旋钮，不是固定模式"**——所有主流实验室都暴露可调思考量；路由（按任务难度选快/深）是 2026 成本控制的正解（03 篇成本三旋钮）。

## 2. 选型决策

```text
推理模型选型：
├─ 任务可验证性：多步/可验证（数学/代码/规划）→ 推理模型
├─ 任务性质：查找/摘要/高量分类 → 快速模型
├─ 思考暴露：需要可见轨迹（调试/审计）→ 开源（R1/Trinity）
├─ 成本敏感：推理量大 → Trinity 类（便宜 96%）
├─ 上下文长：→ Gemini Deep Think / MAI-Thinking-1（256K）
├─ 生态绑定：→ 厂商原生（o 系列/Claude/Gemini）
└─ 本地部署：→ 开源权重（R1/Trinity/Mellum2）
```

| 决策维度 | 问题 |
|---|---|
| 任务形态 | 多步可验证还是单步查找？ |
| 可见性 | 需要思考轨迹（调试/审计）吗？ |
| 成本 | 推理 token 预算多少？（Trinity 便宜 96%） |
| 上下文 | 需要多长？（Deep Think 1M+/MAI 256K） |
| 部署 | 云 API 还是本地？（开源权重） |

## 3. 成本模型：递减收益的量化

| 思考档位 | 收益 | 成本 |
|---|---|---|
| 无思考 | 基线 | 最低 |
| 中思考 | **收益最陡**（no→medium 大幅提升） | 中 |
| 高思考 | 收益趋平 | 高 |
| 最大思考 | **几乎无增益**（high→max 平） | 最高 |

> ⚠️ Snell 计算最优结论：**"花在思考上的钱过了拐点就是浪费"**——推理模型的预算分配 = 按任务难度选思考档，不是无脑开最大。2026 实证：GPT-5 实时路由在简单任务自动降档，省 50-80% 输出 token。

## 4. 成本对比速查（2026）

| 模型 | 相对成本 | 定位 |
|---|---|---|
| Opus-4.6 级 | 基准（最贵） | 最高质量 |
| GPT-5.x 级 | ~89% 成本 | 生态综合 |
| Trinity-Large | **Opus 的 4%**（便宜 96%） | 开源高性价比 |
| DeepSeek-R1 | 低价 | 开源基线 |
| 快速模型 | 最低 | 简单任务路由目标 |

> 💡 混合策略（2026 生产主流）：**推理模型做"规划/决策"轮、快速模型做"执行/格式"轮**——按轮路由（Router 组件联动）；评估 09 篇的 Trust Tax 同样适用于推理模型（每轮思考都计费）。

## 5. 常见问题

| 问题 | 答案 |
|---|---|
| 推理模型能替代普通模型吗？ | 不能——查找/摘要用推理模型是浪费（递减收益） |
| 思考轨迹能审计吗？ | 厂商 API 不可见；开源模型可见（`<think>` 块） |
| 推理模型需要循环吗？ | 需要——推理提高单步质量，多步仍要 ReAct 循环 |
| 记忆缺失怎么办？ | 外部记忆层（Mem0 类）——推理模型跨请求即忘 |
| 模型升级会漂移吗？ | 会——提示词/评估要随模型版本回归（PromptOps 06 篇） |
