# 推理与决策机制

> 概念速记：大脑怎么工作——决策循环与推理模型。循环深潜见 [主流 Agent 范式 03-ReAct](..%2F..%2F..%2F主流%20Agent%20范式%2F03-ReAct范式.md)，推理模型前沿见 [范式 06-Agentic Reasoning](..%2F..%2F..%2F主流%20Agent%20范式%2F06-Agentic-Reasoning与模型原生范式.md)。

## 决策循环：Thought-Action-Observation

```text
ReAct 循环（2022 提出，2026 仍是现代 Agent 工作方式）：
  Thought（想：分析现状，决定下一步）
    → Action（做：调用工具/输出）
    → Observation（看：读取结果）
    → 循环 → 直到最终回答
```

| 环节 | 例子 |
|---|---|
| Thought | "需要查订单状态才能回答" |
| Action | 调用 get_order(id) |
| Observation | "订单已发货，预计明天到达" |
| 终止 | 信息足够 → 最终回答 |

> 💡 2026 状态：**原生工具调用内建在每款前沿模型**（GPT-5.5/Claude Opus 4.7/Gemini 3.1 Pro）——文本式 ReAct 提示格式已成历史，底层循环不变。

## 推理模型：thinking tokens

| 项 | 说明 |
|---|---|
| 机制 | 回答前内部循环：起草→核对目标→修订→满意才输出 |
| thinking tokens | 中间步骤（隐藏但计费）——推理质量的新计算轴 |
| 时长 | 5-60+ 秒（真实内部工作） |
| 收益递减 | no→medium 陡、high→max 平（Snell 计算最优）——**有正确的思考量** |

| 暴露方式（2026） | 模型 |
|---|---|
| budget_tokens（8k-16k 建议起步） | Claude thinking |
| reasoning_effort（low/medium/high） | OpenAI o 系列 |
| 实时路由（fast/deep 自动选） | GPT-5 thinking（省 50-80% 输出 token） |
| thinkingBudget（Deep Think 1M+ 上下文） | Gemini 2.5 |
| 完整推理轨迹（开源） | DeepSeek-R1/Trinity/Mellum2（`<think>` 块） |

## 推理模型作为规划大脑

- **机制**：行动前内部计算——探索路径、卡住回溯、再输出计划（"GPS 后台算完全程再给一条指令"）。
- **thinking 不传给 Agent**：服务端内部——无法日志/调试内部推理，只看到最终输出。
- **规划形态**：推理模型输出的是文本计划/行动，不是预结构化"计划字段"——要解析文本（Planner 04 篇衔接）。

## 决策机制前沿（2026）

| 方向 | 机制 |
|---|---|
| SR²AM 三系统 | 反应（快）+ 模拟推理（世界模型预演）+ 自调节（何时规划）——RL 后规划视野 +22.8% |
| ACTS 推理转向 | 控制器观 reasoning trace 发转向指令（MDP 建模）——省 token 保质量 |
| AgentFlow | planner/executor/verifier/generator 四模块 + 流内优化（7B 超 GPT-4o +14.9%） |
