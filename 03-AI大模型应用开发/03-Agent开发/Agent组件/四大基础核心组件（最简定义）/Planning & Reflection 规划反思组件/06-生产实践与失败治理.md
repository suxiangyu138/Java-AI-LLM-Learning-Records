# 生产实践与失败治理

> 深化篇：规划反思的生产落地——失败治理、重规划、护栏。完整版见 [Planner 06 篇](..%2F..%2F..%2FAgent%20子组件专项学习%2FPlanner%20规划器%2F06-规划器的失败模式与治理.md)。

## 1. 规划失败治理（PlanBench-XL 实证 → 防御）

| 失败模式 | 防御 |
|---|---|
| Irrecoverable Drift（部分进展后偏离，>70% GPT-4o 失败） | 轨迹检查点 + 定期回溯验证 + 最佳路径保留 |
| 静默失败/Value Contamination（无错误信号的错误值） | **工具输出验证** + 怀疑心提示（Tool 06 篇联动） |
| 工具选择瓶颈（过度依赖最近检索的工具） | 工具相关性排序（按任务目标而非新近） |
| 阻塞崩溃（关键工具不可用） | 重规划机制（§2）+ 备用工具链 |

> ⚠️ 2026 关键：**"Agent 缺乏验证工具输出的怀疑心"**——value contamination 的本质是"把工具返回当真理"；防御 = 执行层验证（数据库状态/测试）+ 提示层怀疑心（"验证输出合理性"）。

## 2. 重规划机制：计划会过期

```text
重规划触发链：
  执行失败（显式错误/静默失败/阻塞）
    → 检测（轨迹 vs 计划偏差）
    → 诊断（哪个假设失效）
    → 修订（局部改 vs 全量重规划）
    → 继续执行（或人工升级）
```

| 触发 | 响应 |
|---|---|
| 显式错误 | 局部重规划（换工具/换路径） |
| 静默失败 | 验证 + 重规划（最险——先怀疑再改） |
| 阻塞 | 备用工具链/人工升级 |
| 多轮无进展 | 全量重规划 + 反思（05 篇） |

> 🎯 核心要点：**"计划是假设，执行是验证"**——重规划是规划的标配纠错机制（Plan-Execute 的"计划会过期"由重规划兜底）；重规划频率监控是规划健康的信号（04 篇轮次联动）。

## 3. 生产护栏清单

| 护栏 | 内容 |
|---|---|
| 步数预算 | max_steps（一次无界查询可级联数百次调用 $5-50） |
| 成本上限 | 反思/重规划计入预算（Orchestrator 05 篇） |
| 检查点 | 长任务可回滚（Orchestrator 03 篇） |
| 高风险计划 | 人工批准（Guardrails 确认模式） |
| 破坏动作 | 可逆优先 |
| 上下文窗口 | 长任务防上下文耗尽（丢 system prompt 失连贯——感知 08 篇） |

## 4. 混合模式工程化

| 场景 | 模式 | 2026 权衡 |
|---|---|---|
| 简单/探索 | ReAct | 默认——控制流未知 |
| 复杂长任务 | Plan-Execute | 全局结构清晰，计划会过期（需重规划） |
| 关键步骤后 | Reflect | 稳质量，加成本延迟 |
| 失败 | 触发重规划 | 恢复正确性 |
| 高风险 | 人工确认 | 合规底线 |

> 💡 混合原则：**"Reflect 是叠加件不是默认件"**——只在关键步骤后加；Reflect 无退出机制会过度打磨（2026 实证）——退出条件（轮次/成本/收敛）先设计。

## 5. 生产检查单

| 检查 | 标准 |
|---|---|
| 模式选择 | 从最简单开始（谱系渐进，04 篇） |
| 计划验证 | 结构化输出 + 编排验证（04 篇） |
| 工具验证 | 输出验证 + 怀疑心（§1） |
| 重规划 | 触发链配置 + 频率监控 |
| 反思 | oracle 前提 + 轮次上限 + 最佳回滚（05 篇） |
| 预算 | max_steps + 成本上限 |
| 人工出口 | 高风险计划/多轮无进展 |

## 6. 面试速记

| 问题 | 一句话答案 |
|---|---|
| 规划失败防御？ | 检查点/输出验证/工具排序/重规划 |
| Value Contamination？ | 工具返回当真理——执行层验证 |
| 重规划触发？ | 显式错误/静默失败/阻塞/无进展 |
| 重规划频率？ | 监控——规划健康信号 |
| 护栏六件？ | 步数/成本/检查点/人工/可逆/上下文 |
| 混合模式？ | ReAct 简单/Plan-Exec 复杂/Reflect 关键步 |
| Reflect 退出？ | 轮次/成本/收敛——先设计 |
| 计划是假设？ | 执行是验证——重规划兜底 |
| 上下文耗尽？ | 丢 system prompt 失连贯 |
| 与 Guardrails 联动？ | 高风险计划人工确认 |
