# 面试冲刺

> 深化篇：Planning & Reflection 的 10 题面试冲刺——覆盖本组件全部知识点，可直接背诵。

## Q1：规划组件定位？

> 行动前决定"分几步、按什么顺序、用什么工具"——多步路线。与 LLM 大脑分工：大脑想单步（这一步做什么决定），规划想整条路（整体分几步、依赖顺序）；两种模式：ReAct（边想边做，控制流未知默认）vs Plan-Execute（先计划后执行，多步依赖任务）。

## Q2：生产模式谱系与原则？

> Prompt chaining → Routing → Parallelization → Orchestrator-Workers → Evaluator-Optimizer → 全自主 Agent。原则："从最简单模式开始，穷尽确定性替代后才毕业到 Agent"——过度规划是成本复杂度浪费；2026 生产主流是混合（简单 ReAct、复杂 Plan-Execute、关键步骤后 Reflect）。

## Q3：任务分解怎么做？

> 图式规划（2026）：自然语言目标 → LLM 分解子任务 → 局部优先级 → 全局依赖图（DAG）→ 按依赖执行 + 子结果比对触发自我修正。分解质量四维：原子性/依赖清晰/可验证/规模适中——"分解质量决定规划质量，分解失败后续全部失真"。

## Q4：反思组件定位？

> 做后复盘——评估输出、分析错因、改进后重试。**反思 ≠ 重试**（重试原样再跑，反思先评再改）；Reflexion（语言化自我批评，HumanEval 91% vs 80%）奠基；2026 认知反转：自我反思不可信（同模型同盲区）——可靠评估必须外部化。

## Q5：oracle 前提？

> **"只有可验证标准（测试/编译器/ground truth）才加反思"**——无 oracle 时批评退化为自证偏见；代码/检索验证类任务适合，开放写作不适合；评判器独立性：规则 > 独立模型 > 自我（同盲区）；"自我反思不能作为自己的评判器"。

## Q6：轮次控制？

> 复盘 2-3 轮（第 1 轮捕获 70-80% 改进，第 5 轮过优化）、精化 3-5 轮、硬上限计入 max_iterations（反思是预算内循环）、最佳版本回滚（防过度修正把对的改错）、级联反思（便宜检查先过省 50-80%）。

## Q7：规划失败模式与防御？

> PlanBench-XL：Irrecoverable Drift（部分进展后偏离，GPT-4o >70% 失败——检查点+回溯验证）；静默失败/Value Contamination（无错误信号的错误值被当真理——工具输出验证+怀疑心）；工具选择瓶颈（过度依赖最近检索——按任务目标排序）；阻塞崩溃（GPT-5.4 51.90%→11.36%——重规划+备用工具链）。

## Q8：重规划机制？

> 触发链：执行失败（显式/静默/阻塞）→ 检测（轨迹 vs 计划偏差）→ 诊断（哪个假设失效）→ 修订（局部改 vs 全量重规划）→ 继续或人工升级。"计划是假设，执行是验证"——重规划是 Plan-Execute 计划过期的兜底；重规划频率监控是规划健康信号。

## Q9：生产护栏？

> 步数预算（max_steps，一次无界查询 $5-50）、成本上限（反思/重规划计入）、检查点（长任务可回滚）、高风险计划人工批准、破坏动作可逆优先、上下文窗口防耗尽（丢 system prompt 失连贯）。

## Q10：2026 规划反思前沿？

> SPIRAL（AAAI 2026：Planner/Simulator/Critic 三 Agent 进 MCTS，DailyLifeAPIs 83.6% +16 点）；AdaPlanBench（隐藏约束逐步揭示，最好仅 67.75%——自适应规划仍是开放问题）；AgentFlow（四模块流内优化，7B 超 GPT-4o）；反思成本画像（内隐 2x/外部 3-4x/蒸馏最小）——收益与成本都要报。

## 答题范式

| 原则 | 说明 |
|---|---|
| 结构优先 | 定位 → 机制 → 实证 → 治理 |
| 带数据 | "91% vs 80%""51.90%→11.36%""+16 点"——实证碾压空谈 |
| 说权衡 | "反思 2-3 轮（第 5 轮过优化）""Plan-Execute 结构清但计划会过期" |
| 落工程 | 补一句"生产上我怎么做"（检查点/重规划/级联反思） |
| 提边界 | 何时不规划：简单任务 ReAct 即可；何时不反思：无 oracle |
