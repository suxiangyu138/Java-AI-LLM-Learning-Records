# 反思机制与轮次控制

> 深化篇：反思的工程细节——机制、评判器、轮次控制与成本。完整版见 [Reflection 反思模块 02-04 篇](..%2F..%2F..%2FAgent%20子组件专项学习%2FReflection%20反思模块%2F02-反思机制：从Reflexion到变体.md)。

## 1. 反思机制谱系

| 机制 | 反馈来源 | 特点 |
|---|---|---|
| Reflexion | 外部反馈（测试/工具）+ 语言化批评 | 无权重更新（verbal RL）——奠基 |
| Self-Refine | 模型自己的批评 | 同模型同盲区（2026 不推荐单独用） |
| CRITIC | 外部知识批评 | 用检索/工具验证 |
| LATS | MCTS 树搜索 + 反思 | 搜索空间探索 |
| Self-RAG | 反思 token | 检索决策内建 |

> 🎯 核心要点：**"反思的可靠性 = 反馈来源的外部性"**——Reflexion（外部反馈）> Self-Refine（自我批评）；2026 共识：自我反思不可信（同模型同盲区），可靠评估必须外部化（Reflection 01 篇）。

## 2. 评判器设计（谁来评估）

| 评判器 | 独立性 | 成本 | 适用 |
|---|---|---|---|
| 规则/测试 | 最高（外部） | 最低 | 可验证任务（oracle） |
| 独立模型 | 高（不同家族） | 中 | 主观质量 |
| 自我评判 | 低（同盲区） | 低 | 格式/表层 |
| 人工 | 最高 | 最高 | 疑难/合规 |

> ⚠️ 2026 铁律：**"自我反思不能作为自己的评判器"**——同模型同盲区（GSM8K 实证自我修正成绩下降）；独立评判器（不同模型家族）是生产标准；无 oracle 时批评退化为自证偏见（02 篇）。

## 3. 轮次控制的工程化

| 控制项 | 值 | 理由 |
|---|---|---|
| 复盘轮次 | 2-3 轮 | 第 1 轮捕获 70-80% 改进，第 5 轮过优化 |
| 精化轮次 | 3-5 轮 | 解空间探索（更贵） |
| 硬上限 | 计入 max_iterations | 反思也是预算内循环（Orchestrator 联动） |
| 最佳版本回滚 | 保留每轮最佳 | 防过度修正把对的改错 |
| 级联反思 | 便宜检查先过 | 省 50-80% 成本 |

> 🎯 一句话：**"反思是预算内的循环，不是无限的自省"**——轮次上限 + 最佳版本回滚 + 级联（便宜先查）三件套是生产标准（Reflection 04 篇）。

## 4. 反思的成本画像（2026）

| 模式 | 推理开销 | 准确率提升 |
|---|---|---|
| 内隐提示词反思 | ~2x | +2-13% |
| 外部评判器/工具 | ~3-4x | +3-23% |
| 微调蒸馏 | 最小 | +10-30% |

> ⚠️ 2026 评测要求：**收益与成本都要报**——"+4 分但 8% 正确改错 + 延迟 3 倍"与"+2 分干净提升"不是同一系统（Reflection 08 篇三指标）；反思的 ROI = 净提升 - 成本 - 过度修正损失。

## 5. 反思的失败模式速查

| 模式 | 机制 | 防御 |
|---|---|---|
| 过度修正 | 把对的改错 | 轮次上限 + 最佳回滚 |
| 自证偏见 | 无 oracle 自我确认 | oracle 前提 + 外部评判器 |
| 谄媚批评 | 弱评判器"看起来不错" | 强评判器 + 校准 |
| 结构税 | 强制结构化反思降准确率（50%→38%） | 不强制结构（Qwen3 实证） |
| 进度幻影 | 自评"接受一切"真实停滞 | out-of-band 评估（外部信号） |

## 6. 面试速记

| 问题 | 一句话答案 |
|---|---|
| 反思谱系？ | Reflexion/Self-Refine/CRITIC/LATS/Self-RAG |
| 可靠性公式？ | 反馈来源外部性——Reflexion > Self-Refine |
| 评判器独立性？ | 规则>独立模型>自我>人工（成本反比） |
| 轮次控制？ | 2-3 复盘/3-5 精化 + 最佳回滚 |
| 级联反思？ | 便宜检查先过——省 50-80% |
| 成本画像？ | 2x（内隐）~3-4x（外部）——收益成本都报 |
| 结构税？ | 强制结构化反思 50%→38% |
| 进度幻影？ | 自评全接受——out-of-band 外部评估 |
| 与预算联动？ | 反思计入 max_iterations |
| 与 03 篇关系？ | 失败模式 → 生产护栏 |
