## 2. 四组件协作循环

```text
Agent 协作循环（一图速记）：
  感知输入 ──→ Memory 召回（记）
    → LLM 大脑推理（想）──→ Planning 规划路线（规划）
    → Tools 执行动作（做）──→ 结果回注
    → Reflection 复盘（反思）──→ 改进 → 循环
```

| 环节 | 组件 | 关键问题 |
|---|---|---|
| 想 | LLM 大脑 | 这一步做什么决定？ |
| 记 | Memory | 之前知道什么？这次要记住什么？ |
| 规划 | Planning | 整条路怎么走？走错怎么办？ |
| 反思 | Reflection | 做得好吗？下次怎么改？ |
| 做 | Tools | 用什么动作碰世界？ |

> 🎯 核心要点：**五环节缺一，Agent 不完整**——只有大脑=聊天机器人；只有工具=API 封装；只有记忆=数据库；规划反思让 Agent"像人一样工作"（2026 生产共识：反思/工具/规划/协作是四大构建块）。
