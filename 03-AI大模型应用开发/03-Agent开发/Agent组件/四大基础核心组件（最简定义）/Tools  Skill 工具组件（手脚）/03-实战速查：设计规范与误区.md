# 实战速查：设计规范与误区

> 概念速记：工具的生产红线。深潜见 [Tool 03 篇](..%2F..%2F..%2FAgent%20子组件专项学习%2FTool%20工具开发与注册%2F03-工具定义：JSON-Schema契约设计.md)（契约）与 [Tool 08 篇](..%2F..%2F..%2FAgent%20子组件专项学习%2FTool%20工具开发与注册%2F08-工具安全：权限-注入与治理.md)（安全）。

## 设计规范（工具 = 正式契约）

| 规范 | 内容 |
|---|---|
| 命名 | 清晰无歧义（from_account_id 而非 from） |
| 描述 | 1-3 句讲"何时用"——描述比实现重要（含示例 +25%） |
| 参数 | 枚举替代自由文本、数值 min/max、每参数一句话、additionalProperties:false |
| 输出 | 文档化输出 schema（尤其错误状态） |
| 数量 | **>30-50 工具选择准确率线性下降**——按组路由不全部暴露 |
| 原子性 | 工具不重叠——描述出现"或"= 两个工具 |

## 鲁棒性六件套

| # | 机制 |
|---|---|
| 1 | 输入校验（调用前）+ 输出验证（调用后形状/合理性） |
| 2 | 显式超时 + 分级重试（指数退避） |
| 3 | 幂等设计（Agent 侧重试安全） |
| 4 | 类型化错误返回（非裸堆栈——模型才能推理失败） |
| 5 | 顺序默认、并行后置（并行加冲突/失败复杂度） |
| 6 | 断路器（同一工具三连败熔断）+ 日志不可谈判（名/参/果/时延/错） |

## 安全治理

| 机制 | 内容 |
|---|---|
| 外部内容不可信 | 输入消毒 + allowlist 权限 |
| 危险工具预护栏 | 删除/支付/预订前置人工确认（Guardrails 确认模式） |
| 风险分级 | 只读检索/幂等写/破坏性写/代码执行/浏览器/子 Agent/付费 API 分级评估 |
| Skill 护栏 | SKILL.md 写"未完成步骤 1-2 绝不批退款"——执行层兜底 |

## 评估

| 指标 | 测什么 |
|---|---|
| ToolSelectionAccuracy | 选对工具没 |
| FunctionCallAccuracy | 名称/参数/类型有效没 |
| JSONValidation | schema 符合没 |
| 失败模式 | irrelevance（无工具适用时乱调）与 missing-tool（漏调）是 2026 主要差距 |

> 💡 BFCL v3 基线（2026-05）：前沿 88-94%（GPT-5.x ~89%/Claude Opus 4.7 ~87%/Gemini 3 Pro ~85%）——**头部分数接近，差距在 irrelevance 与 missing-tool 桶**。

## 五大误区

| 误区 | 真相 |
|---|---|
| "工具越多越强" | >30-50 准确率线性降——按组路由 |
| "描述随便写" | 描述比实现重要——模糊描述选错工具 |
| "并行总是更快" | 顺序默认、并行后置——并行加复杂度 |
| "重试免费" | 必须幂等 + 断路器——防重复副作用（Orchestrator 05 篇） |
| "MCP 取代 Skills" | 生产 use both——一个管动作一个管判断 |

## 面试速记

| 问题 | 一句话答案 |
|---|---|
| 工具数量红线？ | >30-50 准确率线性下降 |

| 鲁棒性六件套？ | 校验/超时重试/幂等/类型化错误/顺序默认/断路器 |
| 断路器？ | 同一工具三连败熔断 |
| 风险分级？ | 只读/幂等写/破坏性写/代码/浏览器/子 Agent/付费 |
| 评估三指标？ | Selection/FunctionCall/JSONValidation |
| BFCL v3？ | 前沿 88-94%——差距在 irrelevance/missing |
| 日志？ | 不可谈判——名/参/果/时延/错 |
| 与 Guardrails 联动？ | 危险工具预护栏 + 人工确认 |
