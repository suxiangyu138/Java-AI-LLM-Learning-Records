# 工具执行与安全

> 深化篇：执行循环与安全红线——模型输出不可信的执行层。完整版见 [Tool 06/08 篇](..%2F..%2F..%2FAgent%20子组件专项学习%2FTool%20工具开发与注册%2F06-工具执行：执行器与调用循环.md)。

## 1. 执行器五步

```text
执行循环：
  解析（arguments JSON）→ 校验（schema）→ 授权（权限/确认）
    → 执行（超时/预算）→ 回传（结构化结果）
```

| 步骤 | 关键点 |
|---|---|
| 解析 | 坏 JSON 单独标记，不中断整轮 |
| 校验 | 结构校验先行、业务校验后置 |
| 授权 | 每调用独立决策（不批量授权） |
| 执行 | 并行只给独立只读；危险工具串行+确认 |
| 回传 | 每调用恰好一个结果（循环不变量） |

> 🎯 核心要点：**执行器第一原则——"模型输出是不可信输入"**（Tool 06 篇）——当外部用户输入处理：校验、授权、限流、审计一个不能少。

## 2. 结构化错误返回

```jsonc
// 错误也是工具结果（observation）——让模型自我纠正
{ "status": "error", "code": "invalid_arguments",
  "message": "labels 必须是枚举值之一：bug/feature/docs",
  "hint": "检查 labels 取值后重试；其他参数保持原样" }
```

| 规范 | 说明 |
|---|---|
| 永远返回、不抛异常 | 抛异常 = 循环崩溃；返回字符串 = 模型可恢复 |
| 错误码+信息+提示 | 模型按提示修比按报错修准 |
| 坏调用不 abort 整轮 | 标记失败、跳过、补错误结果 |
| 结果字符串化 | 模型处理文本不处理对象 |

## 3. 超时与重试分类

| 失败 | 是否重试 | 回传 |
|---|---|---|
| 参数错误 | ❌（重试同样错） | invalid_arguments |
| 业务失败 | ❌ | 业务错误信息 |
| 基础设施故障 | ✅ 指数退避 | 可重试错误 |
| 权限拒绝 | ❌（转人工） | 拒绝原因 |

> ⚠️ 2026 铁律：**"重试只针对安全失败（基础设施）"**——重试率 >5% 修契约不堆重试（Tool 06 篇）；重试风暴防全局预算（Orchestrator 05 篇）。

## 4. 安全五道防线

| 防线 | 内容 |
|---|---|
| 注册期静态校验 | 描述/参数/来源检查（防 tool poisoning） |
| 执行前授权 | 最小权限 + 角色过滤 + 确认模式（危险工具） |
| 参数安全 | 白名单 + 参数化执行（绝不拼接 SQL/Shell/路径） |
| 行为检测 | 调用风暴/跨域异常/序列异常 |
| 审计 | 全量留痕（每次调用：参数/结果/授权/耗时） |

> 💡 与 [Guardrails](..%2F..%2F进阶工程化组件（生产环境必备）%2F安全护栏%20Guardrails%2F00-安全护栏Guardrails总览.md) 分工：Guardrails 管运行时五 rail 拦截；本体系管工具本体的安全设计——两者接口在 execution rail（Tool 08 篇）。

## 5. 危险工具确认模式

| 风险级 | 执行策略 |
|---|---|
| 只读 | 自动执行 |
| 写（可逆） | 自动 + 节流 + 审计 |
| 危险（不可逆） | **强制确认模式**（不可关闭——CVE-2025-53773 教训） |
| 特权 | 人工接管 + 双人复核 |

> ⚠️ 2026 教训：**auto-approve 配置移除了人工确认 → 注入直通危险工具**——危险级工具确认模式不可被配置关闭（Tool 08 篇）。

## 6. 面试速记

| 问题 | 一句话答案 |
|---|---|
| 执行五步？ | 解析→校验→授权→执行→回传 |
| 执行器第一原则？ | 模型输出不可信——当外部输入处理 |
| 结构化错误？ | 错误码+信息+提示——模型可恢复 |
| 重试规则？ | 只重试基础设施故障 |
| 五道防线？ | 注册校验/授权/参数/行为/审计 |
| 确认模式？ | 危险级强制确认——不可关闭 |
| 循环不变量？ | 每调用恰好一个结果 |
| 并行原则？ | 独立只读并行，危险串行 |
| 与 Guardrails 分工？ | 护栏运行时拦截，本体系工具本体设计 |
| 重试率红线？ | >5% 修契约不堆重试 |
