# 工具契约设计

> 深化篇：工具定义 = 正式契约——模型只看到契约，看不到实现。完整版见 [Tool 03 篇](..%2F..%2F..%2FAgent%20子组件专项学习%2FTool%20工具开发与注册%2F03-工具定义：JSON-Schema契约设计.md)。

## 1. 契约三要素

| 要素 | 职责 | 质量红线 |
|---|---|---|
| name | 唯一标识、模型引用 | 动词开头、camelCase、绝不重名、禁 do_xxx 泛名 |
| description | 决策依据：何时用/怎么用/边界 | 1-3 句 + 示例（含示例 +25% 准确率） |
| parameters | 参数契约 | 全参数描述、枚举、约束、additionalProperties:false |

> 🎯 核心要点：**模型永远看不见实现——只看到 name/描述/schema**（Tool 01 篇）；描述决定"该不该调"、schema 决定"参数怎么填"；两处写到位 = 契约质量的一半以上。

## 2. 描述黄金法则

| 法则 | 做法 | 收益 |
|---|---|---|
| 讲清何时用 | 触发场景 + 反例 | 减少无谓调用 |
| 讲清何时不用 | 与其他工具边界 | 减少选错 |
| 给示例 | 调用格式直接写 | 准确率 +25% |
| 给约束 | 输入格式/长度限制 | 减少幻觉参数 |
| 给前置条件 | 依赖其他工具先执行 | 减少顺序错误 |

> 💡 描述自测三连：① 换个 LLM 只看描述能正确调用吗？② 两工具描述对调会选错吗？③ 有具体例子吗？——任一"否"重写（Tool 03 篇）。

## 3. Schema 设计规范

| 维度 | 规范 | 反模式 |
|---|---|---|
| 扁平化 | 顶层属性优先 | 深嵌套（token 高、易错） |
| 全参数描述 | 每 property 有 description | 模型猜参数名 |
| 参数数量 | 最小化 | 每多一个参数多一分幻觉 |
| 封闭值集 | enum | 自由发挥字符串 |
| 数值边界 | min/max | 无界数字 |
| 结构 | required + additionalProperties:false | 松散对象（那不是 schema） |

> ⚠️ 反模式警示：`{"type": "object"}` 无 properties = 没约束；`dict[str, Any]` = "自由写作许可证"——**Schema 的使命是收窄可能空间**（Tool 03 篇）。

## 4. 工具数量治理

| 数据点 | 值 |
|---|---|
| 单工具定义成本 | 100-200 token/个 |
| 工具总数红线 | <20 建议、30 硬拒绝（Tool 05 篇） |
| 单上下文准确率边界 | 10-15 个（Haiku 级模型） |
| 超限解法 | namespace/动态发现（tool_search）或按组路由 |

> 🎯 一句话：**"工具列表不是越多越好，而是越精越好"**——>30-50 工具选择准确率线性下降（2026 实证）；数量治理目标 = 让模型每次只面对可分辨的候选集。

## 5. 契约的版本治理

| 治理项 | 内容 |
|---|---|
| 语义化版本 | major：行为契约变更（参数/语义） |
| 兼容性 | 参数新增默认值兼容；破坏性变更升 major |
| 灰度 | 新契约 10% 流量观察调用成功率 |
| 废弃 | 先禁用 → 观察无调用 → 删除 |
| 冲突检测 | 注册期 fail-fast（重名/描述重叠/schema 冲突） |

> 💡 与 PromptOps 05 篇联动：**工具契约与提示词一样是一等版本化工件**——契约变更 = 行为变更；"工具描述改了但模型不知道"是隐性问题（版本进 trace，PromptOps 06 篇）。

## 6. 面试速记

| 问题 | 一句话答案 |
|---|---|
| 契约三要素？ | name/description/parameters——模型只见这三样 |
| 描述价值？ | 决定何时调——示例 +25% |
| schema 反模式？ | 空 object/dict[str,Any]——没约束 |
| 工具数量红线？ | <20 建议、30 硬拒绝、10-15 准确率边界 |
| 描述自测三连？ | 换模型能用吗/对调会选错吗/有示例吗 |
| 契约版本？ | major 行为契约——破坏性变更升 major |
| 废弃流程？ | 禁用→观察→删除 |
| 与 PromptOps 联动？ | 契约与提示词同一等工件 |
| 参数最少化？ | 每多一个参数多一分幻觉 |
| 原子性？ | 描述出现"或"= 两个工具 |
