# 生产实践与评估

> 深化篇：工具的生产落地——评估指标、可观测、Skills 工程化。完整版见 [Tool 10 篇](..%2F..%2F..%2FAgent%20子组件专项学习%2FTool%20工具开发与注册%2F10-生产实践与面试冲刺.md)。

## 1. 工具评估三指标（独立失败模式）

| 指标 | 测什么 | 数据（BFCL v3，2026-05） |
|---|---|---|
| ToolSelectionAccuracy | 选对工具没 | 前沿 88-94%（GPT-5.x ~89%） |
| FunctionCallAccuracy | 名称/参数/类型有效没 | Claude Opus 4.7 ~87% |
| JSONValidation | schema 符合没 | Gemini 3 Pro ~85% |
| 桶分析 | irrelevance/missing-tool | **头部差距所在** |

> 🎯 核心要点：**工具评估必须分指标**——"选对但参数错"与"参数对但选错"是不同病（评估 03 篇轨迹指标联动）；头部模型分数接近，**差距在 irrelevance（不该调时调）与 missing-tool（该调没调）**——两个桶是工具治理的重点。

## 2. 工具可观测

| 观测 | 内容 |
|---|---|
| 调用 span | OTel tool_call：工具名/call id/参数/结果/耗时（观测 02 篇） |
| 指标 | 校验通过率、重试率（<5%）、失败模式分布 |
| 循环检测 | 重复相同调用（读同一文件 1000 次——有 trace 特征） |
| 成本 | 每工具 token/调用量（观测 05 篇） |
| 门禁 | 工具契约测试进 CI（LLM 模拟调用回归） |

> ⚠️ 2026 标准：**"工具要'用 LLM 测试'，不只是单元测试"**——契约测试（LLM 模拟调用验证描述/schema 有效）进 CI 门禁；观测与评估共享同一数据平面（评估 09 篇）。

## 3. Skills 工程化

| 环节 | 内容 |
|---|---|
| 渐进披露 | ~100 token 元数据常驻 + SKILL.md 按需加载（防 90+ schema 每轮全载） |
| 版本化 | Skill 变更走 Git + 评估门禁（PromptOps 05 篇） |
| 护栏 | SKILL.md 写"未完成步骤 1-2 绝不批退款"——执行层兜底 |
| 测试 | Skill 编排的工具链要端到端测试 |
| 组合 | Skill 可组合（Tools 02 篇交接模式） |

> 💡 2026 实证：**Supabase 评测——MCP+Skills 组合在安全关键任务 100% 成功率**（基线 0%、纯 MCP 会"猜"工具组合）；Arize 评测——正确性窄带但 MCP 贵 6x 慢 5x——**"use both"是生产答案**（Tools 02 篇）。

## 4. 生产检查单

| 检查 | 标准 |
|---|---|
| 契约 | 三要素齐全 + 描述自测三连（04 篇） |
| 数量 | <20 工具、10-15 单上下文（04 篇） |
| 执行 | 五步 + 结构化错误（05 篇） |
| 安全 | 五道防线 + 危险确认（05 篇） |
| 评估 | 三指标 + 桶分析 + CI 门禁 |
| Skills | 渐进披露 + 版本化 + 护栏 |
| 观测 | tool_call span + 循环检测 |

## 5. 常见生产问题

| 问题 | 根因 | 解法 |
|---|---|---|
| 选错工具 | 描述模糊/工具重叠 | 描述重写 + 冲突检测（04 篇） |
| 幻觉参数 | 缺参数描述 | 全参数描述 + 枚举 |
| 重试风暴 | 重试无分类 | 只重试基础设施 + 预算（05 篇） |
| 循环调用 | 无循环检测 | 断路器 + trace 循环模式（观测） |
| Skill 失效 | 无版本管理 | Git + 评估门禁 |

## 6. 面试速记

| 问题 | 一句话答案 |
|---|---|
| 评估三指标？ | Selection/FunctionCall/JSONValidation |
| BFCL 差距？ | irrelevance 与 missing-tool 桶 |
| 工具怎么测试？ | LLM 模拟调用——不只单元测试 |
| 循环检测？ | 重复相同调用 trace 特征 |
| Skills 渐进披露？ | 100 token 元数据 + 按需加载 |
| Skill 护栏？ | SKILL.md 写规则 + 执行层兜底 |
| use both？ | MCP+Skills——Supabase 100% 安全成功率 |
| 选错工具根因？ | 描述模糊/重叠——重写+冲突检测 |
| 幻觉参数？ | 缺参数描述 |
| 契约测试进 CI？ | LLM 模拟调用回归 |
