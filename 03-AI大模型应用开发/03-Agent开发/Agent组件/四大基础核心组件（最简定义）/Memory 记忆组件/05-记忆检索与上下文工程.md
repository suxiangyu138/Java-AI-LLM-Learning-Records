# 记忆检索与上下文工程

> 深化篇：记忆怎么"被用起来"——检索算子、上下文注入、充分性循环。完整版见 [Memory 记忆系统 06 篇](..%2F..%2F..%2FAgent%20子组件专项学习%2FMemory%20记忆系统%2F06-记忆召回：检索与注入.md)。

## 1. 检索算子栈：超越 top-k（2026）

```text
检索流水线（2026 标准）：
  候选生成（混合：dense + sparse/BM25 + 符号过滤）
    → 图算子（BFS 邻域扩展 / 激活传播 / 节点距离重排）
    → 时间算子（有效性区间 / 发生区间重叠 / 新近加权 / 时间层选择）
    → 融合 + 重排（RRF + 交叉编码器）
```

| 算子族 | 解决 | 代表 |
|---|---|---|
| 混合候选 | 语义+关键词+符号互补 | dense+BM25+过滤 |
| 图算子 | 关系型记忆的邻域扩展 | Zep/Hindsight/AriGraph |
| 时间算子 | 时效性与失效 | Zep（有效性区间）/Hindsight（重叠）/Memoria（新近） |
| 融合重排 | 多路分数合并 | RRF + cross-encoder |

> 🎯 核心要点：**向量 top-k 是 2026 检索的"起点"不是"终点"**——语义相似 ≠ 任务相关（"检索到最相似的记忆 ≠ 最有用的记忆"）；算子栈让检索按结构/时间/关系多维度精确。

## 2. 上下文注入：召回结果怎么进窗口

| 环节 | 做法 |
|---|---|
| 预算打包 | 记忆注入有 token 预算（ENGRAM 证据预算/Hindsight 预算 API） |
| 排序 | 相关 + 新近加权（如 0.6×相关 + 0.4×新近，30 天语义/7 天情景） |
| 隔离 | 记忆内容与指令分层标记（Guardrails 04 篇结构隔离联动） |
| 版本 | 记忆带来源（谁写的/何时）——可信度信号 |

> ⚠️ 2026 铁律：**记忆注入 = 间接注入面**（Guardrails 05 篇 7-37% 盲区联动）——检索出的记忆可能是投毒内容（03 篇防御）；注入前隔离标记 + 注入后验证是双保险。

## 3. 充分性循环：检索不足怎么办

| 机制 | 做法 |
|---|---|
| EverMemOS | 验证上下文"必要且充分"——不足则重写查询 |
| HiMem | 先试便宜抽象记忆（笔记）→ 不足回退情节记忆 |
| 多轮检索 | 首轮结果引导第二轮查询（查询改写） |

> 💡 充分性循环 = **"检索也是决策"**（与感知 07 篇主动感知同源）——不是"一次检索全用"，是"按需检索直到充分"；预算控制防无限检索（Orchestrator 04 篇调度联动）。

## 4. 整合：记忆的"定期大扫除"

| 整合机制 | 做法 |
|---|---|
| 层次整合 | TiMem（段→会话→天→周→画像）/HiMem（事件→笔记） |
| 再巩固 | HiMem 笔记随情节更新；A-Mem 笔记"进化"；ReMe 修剪过时 |
| 延迟批量合成 | StructMem 周期性跨事件巩固——**省 18x 写入 token**（vs 即时知识图） |
| 冲突处理 | 保留历史呈现冲突（04 篇）——不删除不覆盖 |

> 🎯 一句话：**"写入时少加工、后台定期巩固"**——即时构建知识图贵（写时成本），延迟批量合成把成本从写时移到后台（成本工程）；整合是记忆质量的生命线（07 篇 Memory 08 篇治理联动）。

## 5. 检索评估

| 指标 | 测什么 |
|---|---|
| 召回准确率 | 检索到的记忆是否任务相关 |
| 注入预算命中 | 记忆注入 token 占比 |
| 信号利用率 | 注入记忆被实际引用比例（感知 02 篇联动） |
| 陈旧率 | 检索到过期记忆比例 |

> ⚠️ 2026 未解问题：**记忆陈旧检测**——"高度检索的记忆何时变得自信地错误"尚无成熟方案（MintMCP 2026 开放问题）；生产用定期审计 + 有效性窗口缓解。

## 6. 面试速记

| 问题 | 一句话答案 |
|---|---|
| 检索超越 top-k？ | 混合候选+图算子+时间算子+融合重排 |
| 为什么 top-k 不够？ | 语义相似≠任务相关 |
| 注入预算？ | 记忆注入有 token 预算（ENGRAM/Hindsight） |
| 记忆注入风险？ | 间接注入面——隔离+验证双保险 |
| 充分性循环？ | 不足重写查询——检索也是决策 |
| 延迟批量合成？ | StructMem 省 18x 写入 token |
| 整合时机？ | 写入少加工、后台定期巩固 |
| 陈旧检测？ | 2026 未解——审计+有效性窗口缓解 |
| 信号利用率？ | 注入记忆被引用比例 |
| 与感知 07 同源？ | 按需检索直到充分——主动感知思想 |
