# 面试冲刺

> 深化篇：Memory 记忆组件的 10 题面试冲刺——覆盖本组件全部知识点，可直接背诵。

## Q1：记忆组件在 Agent 中的定位？

> Agent 的存储层——跨轮/跨会话保留信息（事实/偏好/历史/经验）。与 LLM 大脑分工：大脑管当下推理（工作台），记忆管跨轮/跨会话（仓库）；"短时记忆=上下文窗口（单会话）、长时记忆=跨会话持久"；生产系统必须显式管道提取沉淀（不会自动发生）。

## Q2：七类记忆怎么分？

> 工作（当前任务临时，=上下文窗口）/会话（对话消息）/语义（稳定事实，跨会话）/情景（事件记录，追加+摘要）/程序（怎么做，SKILL.md）/实体（具体人/账号/项目）/摘要（压缩要点）。关键：语义（覆盖+有效性窗口）vs 情景（追加+历史保留）分库。

## Q3：记忆工作流三段？

> 写入（提取沉淀，类型化存储）→ 召回（检索注入，混合算子）→ 整合（巩固压缩，层次摘要）。决策树五问：持久吗→跨会话吗→事实还是事件→怎么召回→检索策略——按信息类别判，不按 Agent 判；常见错误=信息与生命周期错配。

## Q4：检索为什么超越 top-k？

> 语义相似≠任务相关。2026 算子栈：混合候选（dense+BM25+符号过滤）→ 图算子（BFS/节点距离）→ 时间算子（有效性区间/新近加权）→ RRF+交叉编码器重排；类型化对象（ENGRAM/Hindsight/MemInsight）是检索精确的前提。

## Q5：记忆投毒为什么比注入危险？

> 投毒持久化进长时存储——原始内容删除后仍跨会话生效（延迟+重复失效）。Sleeper 投毒 GPT-5.5 99.8% 注入率；MAFIA 证明写时审计+检索时检测不足；向量注入 100% 持久——"LLM 无法可靠区分指令与数据，进上下文的检索记忆可被读成命令"。

## Q6：记忆投毒怎么防御？

> 九条：外部内容不可直接授权写入（显式确认）/来源标记/按用户会话隔离/写入前验证/检索后验证（高影响动作门控当前会话意图）/指令层级（system>记忆）/用户可见控制/定期审计/CI 红队（Garak/Promptfoo/PyRIT）。核心：**单点不足，组合防御**。

## Q7：记忆治理三件套？

> 来源与版本（时间戳/提取方法/置信度 + 可回滚）+ 范围与隔离（私有/团队/组织/客户 + RBAC + 目录层租户隔离）+ 保留与审计（分层策略 + 定期纠正）——**Git 式记忆工作流**（公司所有、可审、可移植）；"把记忆当向量库问题是陷阱"（检索不告诉你权威/过期/租户）。

## Q8：记忆成本怎么控？

> 四项成本：存储/嵌入/检索/整合；收益：结构化记忆减少重复全上下文提示（省 token）。优化：延迟批量合成（StructMem 省 18x 写入 token）、摘要修剪、预算打包（注入有 token 预算）——"记忆是省 token 的投资，按省了多少重复调用算账"。

## Q9：2026 记忆架构前沿？

> 类型化对象（ENGRAM/Hindsight/MemInsight）、检索算子栈（图+时间+融合）、层次整合（TiMem 时间层级/HiMem 事件→笔记，LoCoMo 80.71% vs Mem0 68.74%）、延迟批量合成（StructMem）、充分性循环（EverMemOS/HiMem 先笔记后情节）；未解问题：记忆陈旧检测、多 Agent 共享记忆一致性、成本预测框架。

## Q10：记忆与相邻组件接口？

> 与大脑：推理消费记忆召回；与感知：感知管当前输入、记忆管跨会话；与工具：工具结果可写入（结果即经验）；与护栏：记忆读写拦截（投毒防御）；与 Prompt：关键规则钉不可压缩区（防压缩摘要掉约束）；与运行时：会话状态（运行时）vs 记忆（跨任务知识）分层。

## 答题范式

| 原则 | 说明 |
|---|---|
| 结构优先 | 定位 → 类型 → 机制 → 治理 |
| 带数据 | "99.8%""80.71% vs 68.74%""18x"——实证碾压空谈 |
| 说权衡 | "写入少加工后台巩固（成本）""top-k 简单但相关不足" |
| 落工程 | 补一句"生产上我怎么做"（分库/确认/审计） |
| 提边界 | 何时不建记忆层：自包含信息（决策树第一问） |
