# 记忆组件是什么

> 概念速记：Agent 的存储层。完整版见 [Memory 记忆系统 01 篇](..%2F..%2F..%2FAgent%20子组件专项学习%2FMemory%20记忆系统%2F01-记忆系统全景：Agent的分水岭.md)。

## 核心定义

记忆组件 = Agent 中负责"存"的部分：跨轮/跨会话保留信息——事实、偏好、历史、经验。它与 [LLM 大脑](..%2FLLM大脑（推理决策模块）%2F00-LLM大脑最简定义总览.md)（只管当下推理）分工：**大脑是工作台，记忆是仓库**。

| 分工 | 大脑（LLM） | 记忆（Memory） |
|---|---|---|
| 当下 | ✅ 当前轮推理 | ❌ |
| 跨轮 | ❌（窗口内） | ✅ 会话内保留 |
| 跨会话 | ❌ | ✅ 持久存储 |
| 形态 | 上下文窗口 | 外部存储（向量库/知识图/文件） |

## 七类记忆速查

| 类型 | 内容 | 例子 |
|---|---|---|
| 工作记忆 | 当前任务临时信息（= 上下文窗口） | 正在处理的订单 |
| 会话记忆 | 对话消息记录 | 前几轮对话 |
| 语义记忆 | 持久事实（跨会话） | 客户订阅等级 |
| 情景记忆 | 事件记录（何时/做了什么/结果） | 上次投诉的处理过程 |
| 程序记忆 | 怎么做（流程/规则） | 退款流程步骤 |
| 实体记忆 | 具体人/账号/项目的事实 | 项目 X 的负责人 |
| 摘要记忆 | 压缩的上下文要点 | 长会话的要点总结 |

> 🎯 一句话：**短时记忆 = 上下文窗口（单会话）；长时记忆 = 跨会话持久**——生产系统必须显式管道把短时信息提取沉淀进长时存储（Memory 05 篇写入纪律）。

## 与相邻组件分工

| 组件 | 分工 |
|---|---|
| 大脑（LLM） | 推理决策——只消费记忆的召回结果 |
| 感知模块 | 当前输入的入口——记忆是跨轮/跨会话的入口 |
| 工具体系 | 工具结果可写入记忆（结果即经验） |
| 护栏 | 记忆读写拦截（投毒防御，03 篇） |

> 💡 2026 定位：**"把记忆当基础设施建，不是事后附加"**（SitePoint）——记忆架构决定 Agent 能否成为"同事"（AI Coworker）而非"对话机器人"。

## 面试速记

| 问题 | 一句话答案 |
|---|---|
| 记忆组件是什么？ | Agent 的存储层——跨轮/跨会话保留信息 |
| 与大脑分工？ | 大脑管当下推理，记忆管跨轮/跨会话 |
| 七类记忆？ | 工作/会话/语义/情景/程序/实体/摘要 |
| 短时 vs 长时？ | 上下文窗口 vs 跨会话持久 |
| 生产要点？ | 显式管道提取沉淀——不是自动发生 |
| 2026 定位？ | 记忆是基础设施，不是事后附加 |
| 与感知分工？ | 感知管当前输入，记忆管跨会话入口 |
| 与护栏分工？ | 护栏拦截记忆读写（防投毒） |
