# 记忆类型深潜

> 深化篇：七类记忆的工程细节——每类"存什么、怎么存、怎么用"。完整版见 [Memory 记忆系统 02-04 篇](..%2F..%2F..%2FAgent%20子组件专项学习%2FMemory%20记忆系统%2F02-工作记忆：上下文窗口管理.md)。

## 1. 七类记忆的工程速查

| 类型 | 存什么 | 存储形态 | 生命周期 |
|---|---|---|---|
| 工作记忆 | 当前任务临时信息 | 上下文窗口 | 单轮（滚动） |
| 会话记忆 | 对话消息 | 会话缓冲（裁剪/摘要） | 单会话 |
| 语义记忆 | 持久事实 | 结构化记录/知识图/向量库 | 跨会话 |
| 情景记忆 | 事件记录（何时/做了什么/结果） | 日志（累积+摘要修剪） | 跨会话 |
| 程序记忆 | 怎么做（流程/规则） | 技能/SKILL 文件 | 长期 |
| 实体记忆 | 具体人/账号/项目事实 | 结构化记录 | 跨会话 |
| 摘要记忆 | 压缩上下文要点 | 摘要存储 | 滚动 |

> 🎯 核心要点：**"短时记忆是上下文窗口（单会话），长时记忆跨会话持久"**——生产系统必须显式管道把短时信息提取沉淀进长时存储（02 篇工作流），不会自动发生。

## 2. 语义 vs 情景：事实与事件的区分

| 维度 | 语义记忆 | 情景记忆 |
|---|---|---|
| 内容 | 稳定事实 | 演进事件 |
| 例子 | "客户订阅企业版" | "上次投诉处理过程" |
| 更新 | 覆盖/版本（**有效性窗口**） | 追加 + 旧条目摘要/修剪 |
| 冲突 | 新事实失效旧事实（Zep 知识图有效性窗口） | 事件保留历史（可呈现冲突） |

> ⚠️ 2026 关键：**"事实与事件要分库"**——把事件当事实存（追加变覆盖）会丢历史；把事实当事件存（日志膨胀）检索困难；Zep 的有效性窗口让"被取代的事实失效而非静默矛盾"。

## 3. 类型化记忆对象（2026 架构）

| 方案 | 类型划分 | 价值 |
|---|---|---|
| ENGRAM | 情景/语义/程序三分 | "最小高杠杆"类型化 |
| Hindsight | 世界/经验/观察/观点（认识论类型） | 证据 vs 信念显式 |
| MemInsight | 派生属性（事件/时间/话题/意图） | 检索按稳定字段过滤 |

> 🎯 一句话：**"强类型让检索精确"**——自由文本记忆 = 检索靠猜；类型化记忆 = 检索有约束（02 篇算子栈的前提）。

## 4. 程序记忆与 Skill

| 项 | 说明 |
|---|---|
| 形态 | SKILL.md（流程/规则/护栏）+ 脚本/参考 |
| 与语义记忆区别 | 语义是"是什么"，程序是"怎么做" |
| 2026 定位 | Skills 是"手的使用方法"（Tools Skill 02 篇） |
| 更新 | 版本化（PromptOps 05 篇） |

> 💡 程序记忆与 Tools Skill 组件的接口：**程序记忆沉淀"流程知识"，Skill 是它的工程形态**——"退款流程步骤"既是程序记忆也是 SKILL.md（Tools 组件 02 篇联动）。

## 5. 记忆类型选型（决策树五问实操）

| 场景 | 判定 | 类型 |
|---|---|---|
| 用户当前提问 | 不需跨轮持久 | 不建层（自包含） |
| 本会话对话 | 仅会话内 | 会话缓冲（裁剪/摘要） |
| 客户订阅等级 | 稳定事实跨会话 | 语义记忆 |
| 投诉处理历史 | 演进事件 | 情景记忆（日志+摘要） |
| 退款流程 | 怎么做 | 程序记忆（Skill） |

> ⚠️ 常见错误（2026 实证）：**信息与生命周期错配**——把会话级状态当永久（存储膨胀+污染），或给只存在于会话的数据建持久基础设施（浪费）。

## 6. 面试速记

| 问题 | 一句话答案 |
|---|---|
| 七类记忆？ | 工作/会话/语义/情景/程序/实体/摘要 |
| 语义 vs 情景？ | 稳定事实（覆盖+有效性窗口）vs 演进事件（追加+摘要） |
| 类型化对象？ | ENGRAM/Hindsight/MemInsight——检索精确的前提 |
| 程序记忆形态？ | SKILL.md——"怎么做" |
| 与 Skill 接口？ | 程序记忆是流程知识，Skill 是工程形态 |
| 选型第一问？ | 需要跨当前轮持久吗 |
| 事实更新？ | 有效性窗口失效旧事实——非静默矛盾 |
| 常见错误？ | 信息与生命周期错配 |
