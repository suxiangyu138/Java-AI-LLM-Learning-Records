# 记忆工作流：写入-召回-整合

> 概念速记：记忆的三段流水线。深潜见 [Memory 记忆系统 05-06-07 篇](..%2F..%2F..%2FAgent%20子组件专项学习%2FMemory%20记忆系统%2F05-记忆写入：提取与沉淀.md)。

## 三段工作流

```text
记忆流水线：
  写入（提取沉淀）→ 召回（检索注入）→ 整合（巩固压缩）
  ① 从会话提取事实/经验 → 类型化存入长时
  ② 按当前任务检索相关记忆 → 注入上下文
  ③ 定期巩固：摘要/合并/淘汰过时
```

| 阶段 | 做什么 | 2026 要点 |
|---|---|---|
| 写入 | 提取事实/偏好/经验 → 类型化存储 | **外部内容不可直接授权写入**（防投毒，03 篇）；类型化对象让检索精确 |
| 召回 | 检索相关记忆注入上下文 | 超越 top-k：混合候选 + 图算子 + 时间算子 + 融合重排 |
| 整合 | 摘要/巩固/淘汰 | 层次整合（时间层级/场景层级）；延迟批量合成省 18x 写入 token |

## 决策树五问（按信息类别，不按 Agent）

| 问题 | 答案导向 |
|---|---|
| 1. 需要跨当前轮持久吗？ | 不需要 → 不建记忆层（自包含信息） |
| 2. 需要跨会话吗？ | 仅会话内 → 会话缓冲（裁剪/摘要）；跨会话 → 持久存储 |
| 3. 稳定事实还是演进事件？ | 稳定事实 → 语义记忆；演进事件 → 情景记忆（日志 + 摘要/修剪） |
| 4. 怎么召回？ | 小存储全量读（Anthropic memory tool）；大存储需搜索 |
| 5. 检索策略？ | 按存储大小/结构/增长率选（向量/图/混合） |

> ⚠️ 常见设计错误：**信息与生命周期错配**——把会话级状态当永久，或给只存在于会话的数据建持久基础设施（MachineLearningMastery）。

## 2026 架构要点

| 架构件 | 内容 |
|---|---|
| 类型化对象 | ENGRAM（情景/语义/程序三分）、Hindsight（认识论类型：世界/经验/观察/观点）、MemInsight（派生属性过滤） |
| 检索算子栈 | 混合候选（dense+sparse+符号过滤）→ 图算子（BFS/节点距离重排）→ 时间算子（有效性区间/失效）→ RRF+交叉编码器重排 |
| 层次整合 | TiMem（段→会话→天→周→画像）、HiMem（事件→笔记，LoCoMo 80.71% vs Mem0 68.74%） |
| 冲突呈现 | 保留历史才能"把冲突呈现为冲突"——删除/覆盖系统做不到 |
| 充分性循环 | 检索不足 → 重写查询（EverMemOS/HiMem 先笔记后情节） |

> 🎯 一句话：**2026 记忆工作流 = 类型化写入 + 混合检索 + 层次整合**——成功不靠更大窗口，靠治理架构。

## 面试速记

| 问题 | 一句话答案 |
|---|---|
| 三段工作流？ | 写入（提取沉淀）→ 召回（检索注入）→ 整合（巩固压缩） |
| 决策树第一问？ | 需要跨当前轮持久吗——不需要就不建层 |
| 事实 vs 事件？ | 稳定事实→语义记忆；演进事件→情景记忆 |
| 类型化对象？ | ENGRAM/Hindsight——检索精确的前提 |
| 检索超越 top-k？ | 混合+图+时间算子+融合重排 |
| HiMem？ | 层次整合——LoCoMo 80.71% vs Mem0 68.74% |
| 冲突呈现？ | 保留历史才能呈现冲突——删除系统做不到 |
| 常见错误？ | 信息与生命周期错配 |
