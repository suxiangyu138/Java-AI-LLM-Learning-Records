## 1. 治理五道防线总览

幻觉治理 = 让模型"无据不答" + 让系统"有据可查"：

```text
第一道：检索接地    —— 只给相关证据（召回质量是地基）
第二道：引用溯源    —— 强制输出带证据编号，可回查
第三道：生成约束    —— prompt 纪律：无证据即拒绝/明说不知道
第四道：验证层      —— 生成后独立校验（规则 + 多Agent）
第五道：评估指标    —— 用 USR/引用F1 等量化治理效果
```

> 🎯 **核心要点**：五道防线的正确顺序是先修"输入"（检索），再管"输出"（约束+验证）。在检索污染严重的系统上做再多 prompt 约束都是徒劳。

## 2. 防线一：检索接地

### 2.1 检索质量决定幻觉上限

| 检索问题 | 幻觉后果 | 修复手段 |
|---------|---------|---------|
| 召回无关内容 | 模型被迫硬答 | 重排器（reranker）过滤噪声 |
| 召回矛盾内容 | 模型选错来源 | 冲突检测、来源投票 |
| 该召回没召回 | 模型脑补 | 多路召回、查询分解 |
| 块粒度不当 | 上下文支离破碎 | 块切分调优、上下文压缩到块内 |

### 2.2 2026 有效技术

| 技术 | 机制 | 效果 |
|------|------|------|
| 查询分解（QDRAG，AAAI 2026） | 把问题拆成原子子问题，识别隐含实体 | 减少过度引用、提升多跳场景引用忠实度 |
| 双查询检索 + LLM 重排（SemEval-2026 方案） | 会话历史只用于意图消解，检索结果作为**唯一事实来源** | nDCG@5 +17.7%，词法忠实度 ROUGE-L F1 0.7692 |
| 分层 RAG（Robust-GAP） | 动态因果抽取 + schema 引导锚点验证 + 溯源金字塔传播 | 强噪声下 0.0% 幻觉率、100% 引用 F1 |
| 结构化证据记忆（MERMAIDS） | 证据存结构化记忆 + 跨任务复用缓存 | 冲突检测精度 >81% |
| 信息密度优先 | 5 个高相关块 > 20 个勉强块 | 直接降低上下文幻觉 |

### 2.3 角色分离原则（关键）

```text
会话历史 ──→ 只用于：意图理解、指代消解
检索结果 ──→ 唯一事实接地源（prompt 明确声明）
```

> ⚠️ **最常见的错误**：把对话历史与检索结果混在一起当"背景材料"——模型会优先使用看似权威的历史内容，而历史本身可能是幻觉的。

## 3. 防线二：引用溯源

### 3.1 强制引用（Citation-Enforced Prompting）

在 prompt 中硬性要求：每个事实性陈述必须带检索文档编号引用 `[D12]`，无引用即视为不合格输出。

**PARROT AI 实证（Applied Sciences 2026）**：强制引用提示在 MedQA 基准上取得最高可验证接地率与来源遵循度（跨 6 种模型架构）。

### 3.2 引用锚点设计

| 设计要素 | 要求 | 反例 |
|---------|------|------|
| 文档编号稳定 | 编号与检索结果一一对应 | 模型自造编号 `[D99]` |
| 引用不可伪造 | 编号必须是系统传入的 | 允许模型自编引用 |
| 落库可回查 | 引用 → 原始 chunk → 原始文档 | 引用了但不给原文 |
| 无引用即拒绝 | 找不到证据就明说"无据可答" | 硬编一个引用凑数 |

**工程实现**：

```python
# 伪代码：引用必须来自系统注入的检索结果集合
allowed_citations = {doc.doc_id for doc in retrieved_docs}

def validate_citations(output, allowed_citations):
    cited = re.findall(r"\[(D\d+)\]", output)
    fake = [c for c in cited if c not in allowed_citations]
    if fake:
        return False, f"发现伪造引用: {fake}，请重写并只使用给定引用"
    return True, None
```

### 3.3 引用质量指标

| 指标 | 定义 | 用途 |
|------|------|------|
| Citation F1 | 引用与事实匹配程度 | Robust-GAP 在噪声场景达 100% |
| 过度引用率 | 引用了但内容不支持 | QDRAG 针对此问题 |
| USR（Unsupported Sentence Ratio） | 无支持句子的比例 | 核心幻觉指标 |
| 引用可回查率 | 引用能否回溯到原文 | 生产审计必备 |

## 4. 防线三：生成约束

### 4.1 Prompt 纪律

| 约束 | 写法示例 | 作用 |
|------|---------|------|
| 无据不答 | "只基于给定文档回答；文档没有答案时，直接回答'文档中未找到'，不要编造" | 阻断编造 |
| 置信度标注 | "不确定时明确标注'猜测'" | 暴露不确定性 |
| 禁止越界推断 | "不要推断文档之外的信息" | 控制推理幻觉 |
| 限定引用集合 | "引用只能来自 [D1]-[D12]" | 防伪造引用 |

### 4.2 边界策略：拒答（Refusal）优于硬答

高利害场景的默认策略——**宁可说"不知道"，不可编造**：

| 策略 | 行为 | 适用 |
|------|------|------|
| 硬拒答 | 无证据直接拒绝回答 | 医疗、金融、法律 |
| 带源拒答 | 无证据但给出"相关但不足以回答"的内容 | 通用 |
| 降级回答 | 给出置信度低的"参考"并明示 | 客服等低利害 |
| 升级人工 | 触发人工介入 | 高利害 + 关键决策 |

## 5. 防线四：验证层

### 5.1 规则验证（零成本、先做）

| 规则 | 判定 | 触发动作 |
|------|------|---------|
| 引用存在性 | 引用编号不在允许集合 → 失败 | 重写一次 |
| 引用完整性 | 事实句无引用 → 失败 | 重写一次 |
| 长度信号 | 回答超长且无引用 → 高嫌疑 | 标记待人工 |
| 矛盾检测 | 与检索内容明显矛盾 → 失败 | 重新检索 + 重写 |

### 5.2 多 Agent 信息不对称验证（MARCH，ACL 2026）

```text
Solver   → 生成回答
Proposer → 将回答拆解为原子命题（claim-level）
Checker  → 只看证据库，逐命题判定"证据支持/反对/无证据"
          （刻意隔离：不给 Checker 看 Solver 的回答，消除确认偏差）
```

**多 Agent 验证的三个工程要点**：

1. **隔离是关键**：验证者的 prompt 只含"证据 + 命题"，不含被验证者输出
2. **原子命题粒度**：拆成"单事实单句"，避免模糊判定
3. **成本控制**：只对高风险回答（长度异常、无引用、涉金额/时间/名称）触发验证

### 5.3 语义能量检测等前沿手段

2026 年出现的新型检测信号（Digital-Nervous 抗幻觉技能栈）：Semantic Energy（检测 token 概率分布的异常能量）、SinkTrack（长上下文信号追踪）、TokenShapley 归因（把输出归因到具体输入 token）。属于实验性技术，生产参考为主。

## 6. 防线五：评估指标

| 指标 | 计算方式 | 目标 |
|------|---------|------|
| USR | 无支持句子数 / 总句数 | < 5%（高利害场景 < 1%） |
| Citation F1 | 引用召回与精确度的调和均值 | > 90% |
| 幻觉率 | 含幻觉的回答 / 总回答 | 追踪随版本波动 |
| 拒答率 | 拒答次数 / 无证据问题数 | 不应为 0（该拒不拒=高风险） |
| 检索命中率 | 检索结果被实际引用的比例 | 检查检索有效性 |

> 💡 **评估必须落到指标，不能只靠感觉**：模型升级、prompt 改动、检索调整都跑同一套幻觉指标集，做回归对比。

## 7. 分层防御决策树

```text
场景是否高利害（医疗/金融/法律/安全）？
├─ 是 → 硬拒答 + 强制引用 + 多Agent验证 + 人工抽查 + 引用落库审计
└─ 否 → 场景的检索噪声水平？
        ├─ 高 → 重排过滤 + 引用强制 + 规则验证（重写一次）
        └─ 低 → 基础 RAG + 引用建议 + 抽样人工巡检
```

**成本与效果排序（性价比）**：

```text
检索质量修复（重排/过滤）  ⭐⭐⭐⭐⭐  最便宜、收益最大
引用强制 + 落库            ⭐⭐⭐⭐   可审计，防编造
规则验证（重写循环）        ⭐⭐⭐     零额外模型成本
多Agent验证                ⭐⭐       贵，只对高风险子集
前沿检测（Semantic Energy等）⭐       实验性，先观望
```

> 🎯 **核心要点**：治理幻觉的第一性原理是**"可验证"而不是"不犯错"**——让每个事实都有出处、每个无据输出都被拒绝。做到"可验证"，幻觉就从"潜伏炸弹"变成"可拦截的显式错误"。
