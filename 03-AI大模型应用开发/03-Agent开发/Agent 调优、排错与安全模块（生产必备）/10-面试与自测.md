## 4. 答题范式：调优/排错/安全

### 范式一：调优回答结构（MOI）

```text
M - Measure  先测量（基线数据）
O - Optimize 按收益排序优化（先免费杠杆）
I - Iterate  评估门禁 + 版本化迭代
```

**示范："如何优化 Agent 延迟？"**

> **M**：先测四维基线——TTFT/成本/质量/可靠性，确认瓶颈在推理段（工具 I/O 只占 ~9%）。
> **O**：按收益排序——①Prompt Caching 前缀冻结（TTFT -50-70%）；②自托管则缓存感知路由（最高 57×，轮询是敌人）；③流式体验（感知延迟）；④并行工具（-1.6-1.8×）。
> **I**：每项改动金丝雀验证 + 评估门禁，质量不回归才全量；版本化 + 回滚就绪。

### 范式二：排错回答结构（TCDR）

```text
T - Trace     先拿完整 trace（不猜）
C - Compare   找成功对照组（46.2% 数据）
D - Diff      对齐变更清单（prompt/模型/配置）
R - Repair    最小修复 + 补评估用例
```

### 范式三：安全回答结构

```text
原则先行："模型负责想，系统负责批"
输入面：内容降权 + 注入检测
执行面：策略引擎 + 分级 + 熔断
输出面：白名单 + 敏感检测 + 金丝雀
审计：全动作留痕 + 告警有接收者
```
