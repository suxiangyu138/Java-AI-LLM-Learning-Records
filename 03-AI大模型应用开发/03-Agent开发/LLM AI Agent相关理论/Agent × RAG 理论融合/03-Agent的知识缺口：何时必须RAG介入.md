# Agent 的知识缺口：何时必须 RAG 介入

> 理论篇：Agent 不是万能的——**知识缺口四类**（幻觉/知识截止/私有数据/外部状态）、Agent 的知识四条来源、以及"2026 生产 Agent 默认外置知识层"的实证（推理模型无内置持久记忆）。与 [记忆组件（面试必背）](..%2F四大核心组件（面试必背）%2F04-记忆组件：短中长时（面试必背）.md) 呼应：知识缺口与记忆组件共用同一套检索基础设施。

## 1. Agent 的知识缺口四类（理论分类）

| 缺口 | 机制 | 例子 | RAG 介入方式 |
|---|---|---|---|
| **幻觉** | 模型生成不存在的"事实" | "这家公司 2025 年营收 12 亿"（编的） | 检索真实数据 → grounded 生成 |
| **知识截止** | 参数记忆有时间边界 | 问 2026-07 刚发布的新规 | 检索最新文档 |
| **私有数据** | 训练数据没有企业文档 | 内部制度、产品手册、代码库 | 企业知识库检索 |
| **外部状态** | 世界在变，参数记忆是静态的 | "当前库存/汇率/订单状态" | 检索/API 实时数据 |

> 🎯 核心要点（背诵版）：**Agent 的推理能力解决"怎么答"，不解决"答什么对"**——事实性内容必须来自外部供给；没有知识供给的 Agent 会"自信地胡说"（幻觉 + 权威语气 = 最危险组合）。

## 2. Agent 的知识四条来源（理论框架）

| 来源 | 机制 | 时效 | 成本 | 适用 |
|---|---|---|---|---|
| 参数记忆 | 模型权重内化 | 截止时间点 | 零增量成本 | 常识、通用知识 |
| 上下文注入 | 用户/系统把资料放进窗口 | 会话内 | token 成本 | 少量关键资料 |
| **RAG 检索** | 按需从外部知识库取 | **可随时更新（改索引即可）** | 检索+注入成本 | **事实/时效/私有数据（2026 默认）** |
| 微调 | 训练更新权重 | 更新后持续 | 高（训练+维护） | 行为风格定型（不是加知识的正解） |

> ⚠️ 2026 共识（面试必答）：**"微调加知识是最普遍的误用"**——模型会自信地幻觉更新后的信息（Form vs Fact：微调改行为、RAG 改事实）；加知识的第一选择永远是 RAG。详见 [区分概念 08](..%2F区分概念（面试容易混淆）%2F08-RAG-vs-微调-vs-长上下文-vs-Agent.md)。

## 3. 2026 实证：推理模型没有持久知识

| 事实 | 含义 |
|---|---|
| MAI-Thinking-1（2026 开源推理模型）**无内置持久记忆** | 推理再强也不自带"记忆库"——生产 Agent 必须外部记忆/知识层 |
| 推理模型把"思考"内建，但没有改变"知识供给"问题 | **thinking 提高怎么答，RAG 解决答什么**——正交互补 |
| 长上下文模型（1M+）能"带得多"，但 context rot 98%→64% | 全量塞入 ≠ 精准供给——按需检索仍必要 |

> 💡 理论结论：**推理模型时代，RAG 不是被淘汰了，而是职责更清晰——思考归模型（test-time compute），知识归检索（RAG），行动归循环（Agent）**。三者正交，各管一段。

## 4. "何时必须 RAG 介入"判定表（面试答题框架）

| 信号 | 判定 | 介入形态 |
|---|---|---|
| 回答涉及具体事实/数字 | 必须检索 | RAG 检索注入 |
| 知识更新频繁（法规/价格/政策） | 必须检索 | RAG（改索引即更新） |
| 涉及企业私有数据 | 必须检索 | 企业知识库 RAG |
| 需要实时状态 | 必须检索/API | RAG + 工具 |
| 通用常识、无需精确 | 不需要 | 参数记忆（别过度检索） |
| 目标是改风格/格式 | 不需要 | 微调（RAG 不解决） |

## 5. 知识缺口导致的 Agent 失败模式（面试避坑）

| 失败模式 | 表现 | 修复 |
|---|---|---|
| 自信幻觉 | 权威语气编造事实 | RAG + faithfulness 校验（Self-RAG 思路） |
| 知识过时 | 用旧政策答新问题 | RAG 时效索引 + 时间戳过滤 |
| 检索不可达 | 需要的事实不在知识库 | 多源检索（Web/内部/DB 并列工具） |
| 知识无界 | 什么都知道一点、都不准 | 明确知识边界 + 不知道就说不知道 |

## 6. 面试速记

| 问题 | 一句话答案 |
|---|---|
| Agent 的知识缺口？ | 幻觉 / 知识截止 / 私有数据 / 外部状态——四类事实性问题 |
| 知识四条来源？ | 参数记忆 / 上下文注入 / RAG 检索（2026 默认）/ 微调 |
| 微调能加知识吗？ | 不能——微调是 Form（行为），RAG 是 Fact（事实）——最普遍误用 |
| 推理模型有知识吗？ | 无内置持久记忆（MAI-Thinking-1 实证）——思考归模型、知识归检索 |
| 何时必须 RAG？ | 事实/时效/私有/实时——常识才用参数记忆 |
| 与记忆组件关系？ | 技术同构（混合检索/图记忆）——见 07 篇"知识库即记忆" |
