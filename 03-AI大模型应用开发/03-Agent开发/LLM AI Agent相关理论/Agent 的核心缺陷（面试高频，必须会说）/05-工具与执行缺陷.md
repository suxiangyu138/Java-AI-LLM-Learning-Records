# 工具与执行缺陷

> 背诵篇：**Agent 的"手"会出错——工具调用与执行层的缺陷**：payload 幻觉 38%、工具误路由、多轮编排掉点、幻觉式恢复。机制深潜见 [工具组件（面试必背）05 篇](..%2F四大核心组件（面试必背）%2F05-工具组件：Function-Calling（面试必背）.md)。

## 1. 30 秒背诵卡

| 概念 | 背诵版一句话 |
|---|---|
| Payload 幻觉 | 模型凭记忆重建深层嵌套 schema 出错——**~38% 生产 Agent 失败根源** |
| 工具误路由 | 语义查询选了 BM25 等错误检索器——工具选择是"选择问题"不是"生成问题" |
| 多轮编排掉点 | BFCL V4：多轮工具编排比单轮掉 **30-60pp**（最强 68%，最差 14.8%） |
| 顺序选工具瓶颈 | 瓶颈是序列决策，不是模型智能——每一步都可能选错 |
| 幻觉式恢复 | Agent 编造补偿（伪造表单数据）代替停下来求助 |
| 沉默执行失败 | 工具执行错了但"看起来成功"——89% 无告警 |
| 执行层瓶颈 | ACL 2026：低级执行是主要瓶颈（不只高级推理） |
| 治理四件套 | 契约化 schema / 结构化错误回传 / 幂等 / 断路器 |

## 2. 面试高频问题（背诵版）

**Q1. Agent 的工具调用为什么会失败？**
> 答：四类——① **Payload 幻觉**：模型凭记忆重建深层嵌套参数（~38% 生产失败根源——schema 越复杂越容易错）；② **选择错误**：工具多时选错（>30-50 个工具选择精度线性下降；语义查询跑 BM25 这类误路由）；③ **多轮编排退化**：BFCL V4 显示多轮编排比单轮掉 30-60 个百分点（最强 68%）——顺序选工具是序列决策问题；④ **执行层落地**：工具返回的结构/语义与预期不符，模型无法正确消化（低级执行是 ACL 2026 认定的主瓶颈）。

**Q2. 为什么"多轮调用工具"比"单轮调用"难这么多？**
> 答：单轮 = 一次"看到工具列表→选一个→填参"；多轮 = 每一步都要**记住前几步的状态、判断下一步依赖、避免重复与冲突**——是序列决策问题。掉点 30-60pp 的实证说明：**瓶颈不在模型智能，在序列一致性**（上一步的结果正确理解 + 下一步不基于错误前提）。对策：代码抽象层/组合工具（复杂工作流 token 减 9 倍、轮次 3.9→2.0）+ 每轮校验。

**Q3. 工具执行失败时 Agent 会怎么"补救"？有什么风险？**
> 答：风险行为是**幻觉式恢复**——Agent 编造一个"看起来成功"的替代（伪造表单数据、假装 API 返回了预期值）而不是停下来求助。危险：① 错误被当作成功继续（触发后续错误行动）；② 无告警（89% 案例）；③ 人看到"已完成"不会复查。对策：**结构化错误回传**（error_code + recoverable + suggested_action 让模型诚实上报）+ **失败阈值升级**（连续失败 → 转人工）+ 禁止"编造补偿"的提示约束。

**Q4. 怎么度量工具层是否可靠？**
> 答：三指标分离——**JSONValidation**（schema 符合性）/ **FunctionCallAccuracy**（名称/结构/类型/语义综合质量）/ **ToolSelectionAccuracy**（"JSON 对但工具选错"——工具丰富环境必测）；加执行结果校验（pre-call 参数校验 + post-call 形状校验）；全部挂 OTel span 统一追踪（详见 [工具组件 05 篇](..%2F四大核心组件（面试必背）%2F05-工具组件：Function-Calling（面试必背）.md)）。

## 3. 工具缺陷的根因链（理论图）

```text
工具调用链的五次出错机会：
  ① schema 设计差（嵌套深/描述含糊）→ ② 模型选错工具（目录大）
  → ③ 参数填错（payload 幻觉）→ ④ 执行失败（网络/权限/数据）
  → ⑤ 结果消化错（结构不符/语义误解）
  每环都有失败率——复合错误（01 篇）在工具层同样成立
```

| 环节 | 失败率放大因素 | 对策 |
|---|---|---|
| schema 设计 | 嵌套层级、oneOf、无描述 | 扁平化 + 枚举 + 描述规范（契约化） |
| 工具选择 | 目录 >20-30 个 | 检索 + 两级选择 + 合并操作 |
| 参数生成 | 深层嵌套凭记忆重建 | 少嵌套 + 代码抽象层 |
| 执行 | 网络/权限/限流 | 超时 + 退避 + 断路器 |
| 结果消化 | 结构不符、空结果 | 结果校验 + 结构化错误回传 |
