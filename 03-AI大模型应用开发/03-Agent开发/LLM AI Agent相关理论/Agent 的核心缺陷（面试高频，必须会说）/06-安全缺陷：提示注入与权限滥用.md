# 安全缺陷：提示注入与权限滥用

> 背诵篇：**Agent 安全缺陷的面试必说版**——OWASP Agentic Top 10（ASI01-10）、提示注入为什么"结构性未解"、致命三要素、数据泄露实证。机制深潜见 [Agent 安全：提示注入与 OWASP](..%2F..%2F幻觉、格式错误、安全、token%20超限%2F07-Agent安全：提示注入与OWASP%20Top%2010.md)。

## 2. 面试高频问题（背诵版）

**Q1. 为什么说 Agent 的安全风险是"结构性"的？**
> 答：两个结构——① **权限继承**：OWASP 分界线是"权威"——LLM 只生成建议（无权限），Agent 带着 API key/凭据/系统权限运行，**攻击者可以继承这些权限**；② **注入无边界**：系统提示、用户查询、检索内容在模型眼里是**同一个 token 流**，命令与数据之间没有可靠的权限边界——OWASP 研究员结论：**提示注入是架构性问题，不是可修补的漏洞**；所以目标不是"防住注入"而是"控制爆炸半径"。

**Q2. 什么是间接提示注入？为什么对 Agent 特别危险？**
> 答：间接注入 = 攻击指令藏在**外部内容**里（网页、文档、PDF、日历邀请、邮件）——Agent 检索/浏览时被动读取并执行。危险在于：① 攻击者不需要直接接触用户（投毒公开页面即可批量攻击）；② Agent 的"工具调用"会把注入指令变成真实行动（递归删文件、转账）；③ 真实案例：GrafanaGhost 数据外传、Gemini 被恶意日历邀请攻破、Forcepoint/Google 记录的能删文件/转 $5000 的载荷。**间接注入是 Goal Hijack（ASI01）/Tool Misuse（ASI02）/Unexpected Code Execution（ASI05）的主要投递机制**。

**Q3. 什么是"致命三要素"（lethal trifecta）？**
> 答：Simon Willison 提出的判定——Agent 同时具备 **① 私有数据访问 + ② 接触不可信内容 + ③ 对外通信** 时，任何一次成功的注入指令都能变成数据外传工具（读到私有数据 → 经不可信内容触发 → 通过网络外传）。面试用法：**设计评估自己的 Agent 时，先问这三个条件是否同时满足**——满足则必须有注入防护层（隔离不可信内容/外传白名单/最小权限）。

**Q4. 2026 年 Agent 安全的事故数据？**
> 答：四组数字——**88%** 企业过去 12 个月遭遇 Agent 安全事件；仅 **21%** 有运行时可见性；**97%** 安全负责人预期 12 个月内发生重大 Agent 驱动事故；仅 **6%** 安全预算覆盖 agentic 风险。补充案例：Meta 内部 rogue Agent 通过所有身份检查泄露数据；Meta-ExternalAgent 两个月拦截 **1600 万+** 伪造请求；PyPI 上被植入后门的 LiteLLM 三小时 ~47,000 下载（供应链，ASI04）。

**Q5. 怎么防护？（五层）**
> 答：① **最小权限**：每 Agent 独立身份（不用共享服务账号）+ 每调用级权限检查（不是会话开始查一次）；② **人工确认门**：不可逆/高影响动作必须批准（转账/删除/部署）；③ **内容隔离**：不可信内容与指令分离（渲染/检索内容标记为 data 不可执行）；④ **外传控制**：URL 白名单 + 敏感数据 DLP + 传输审计；⑤ **运行时监控**：机器速度行为监控 + 实时遏制 + 临时凭据（攻击可在几分钟内完成，人工响应来不及）。

## 3. OWASP Agentic Top 10（ASI01-10）速记

| 编号 | 风险 | 一句话 |
|---|---|---|
| ASI01 | Goal Hijack 目标劫持 | 注入改写 Agent 目标（最顶层风险） |
| ASI02 | Tool Misuse 工具滥用 | 注入诱导调用危险工具/参数 |
| ASI03 | Identity & Privilege Abuse 身份权限滥用 | 越权访问（Meta rogue Agent 案例） |
| ASI04 | Agentic Supply Chain 供应链 | 恶意插件/依赖（LiteLLM 后门案例） |
| ASI05 | Unexpected Code Execution 意外代码执行 | 检索内容触发代码执行 |
| ASI06 | Memory Poisoning 记忆投毒 | 污染持久记忆跨会话感染 |
| ASI07 | Insecure Inter-Agent Communication 不安全通信 | 多 Agent 间信任传输被截/伪造 |
| ASI08 | Cascading Failures 级联失败 | 一个 Agent 被攻破带崩链上所有 |
| ASI09 | Human-Agent Trust Exploitation 信任利用 | 用户过度信任 Agent 输出 |
| ASI10 | Rogue Agents 失控 Agent | 自主性失控/被劫持长期潜伏 |

> 🎯 背诵技巧：**"劫持-滥用-越权-供应链-执行-投毒-通信-级联-信任-失控"**——十个词对应十类；记忆锚点：**前 6 类都可能是提示注入的落点**（映射 6 类），中间 3 类是多 Agent/供应链特有，最后 1 类是自主性失控。
