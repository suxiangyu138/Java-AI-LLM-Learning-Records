# 上下文与记忆缺陷

> 背诵篇：**Agent 长任务的慢性病——上下文退化与记忆污染**：context rot、lost-in-the-middle、中途遗忘、记忆投毒。机制深潜见 [token 超限与上下文管理](..%2F..%2F幻觉、格式错误、安全、token%20超限%2F05-Token超限：上下文窗口机制.md)。

## 1. 30 秒背诵卡

| 概念 | 背诵版一句话 |
|---|---|
| Context rot（上下文腐化） | 长任务中早期信息被稀释/遗忘，模型对"自己到哪了"失去正确模型 |
| Lost-in-the-middle | 模型对上下文**中间位置**的信息利用率显著低于开头/结尾 |
| 实证 | 长上下文基准 context rot：98% → 64%（越长越"健忘"） |
| 更多上下文 ≠ 更好 | 2026 实证："给更多上下文可能让问题更糟"（干扰增加） |
| 中途遗忘 | 早期错误进入上下文后**污染**模型的任务模型（01 篇级联根源之一） |
| 记忆投毒（Memory Poisoning） | 攻击/污染写入持久记忆——跨会话感染（OWASP ASI06） |
| 记忆污染 | 静态索引直接当记忆用：旧偏好答新问题（见 [知识库即记忆](../Agent%20×%20RAG%20理论融合%2F07-知识库即记忆：RAG与记忆组件融合.md)） |
| 治理三件套 | 压缩（摘要）/ 截断（窗口管理）/ 记忆治理（时间戳+遗忘+防投毒） |

## 2. 面试高频问题（背诵版）

**Q1. 什么是 context rot？对 Agent 有什么影响？**
> 答：Context rot（上下文腐化/上下文坍缩）——长任务中上下文不断增长，早期关键信息被稀释、互相干扰，模型对"我在哪、做到哪、目标是什么"的正确模型逐渐丢失。影响：**任务越做越差而不是越做越好**——早期错误会污染后续所有决策（01 篇错误传播的温床）。实证：长上下文基准从 98% 腐化到 64%；**给更多上下文反而可能让 Agent 更差**（干扰项增加，"inverse scaling under noise"）。

**Q2. Agent 的"记忆"为什么靠不住？**
> 答：三个层面——① **窗口级记忆**（工作记忆）：容量有限 + context rot——长会话必然丢信息；② **外部记忆**：长期记忆如果像文档一样静态存，会**时效污染**（用旧偏好答新问题）——记忆是"会变的状态"需要时间戳化+遗忘（见 [知识库即记忆](../Agent%20×%20RAG%20理论融合%2F07-知识库即记忆：RAG与记忆组件融合.md)）；③ **记忆投毒**：外部内容写入持久记忆后**跨会话感染**——被污染的"记忆"比没有记忆危害更大（OWASP Agentic Top 10 的 ASI06 Memory Poisoning）。

**Q3. 上下文越长越好吗？**
> 答：不是——**"更多上下文 ≠ 更好决策"**。三个证据：① lost-in-the-middle——中间位置信息利用率显著低于两端；② context rot 实证——98%→64%；③ 2026 Berlin Buzzwords 论文："更好的检索反而让 Agent 更差"（相关但具干扰性的上下文被提升进行动）。正确姿势：**不是塞得多，是选得准**——注入预算纪律 + 相关性过滤 + 压缩（注入多少比存多少重要）。

**Q4. 怎么治理上下文退化？（工程三件套）**
> 答：① **压缩**：定期把历史摘要成"任务状态卡"（关键事实/已完成/下一步——防止中途遗忘）；② **截断**：窗口管理（滚动截断 + 关键信息外置记忆）；③ **重新接地（re-grounding）**：每 ~9 步把任务目标/约束重新注入一次——2026 实证：re-grounding 可减少 80% 累积失真；④ **记忆治理**：时间戳化 + 遗忘 + 写入校验（防投毒）。

## 3. 记忆缺陷的三种污染（理论图）

| 污染类型 | 机制 | 后果 |
|---|---|---|
| 上下文污染 | 早期错误结论留在上下文中持续影响 | 每步决策都被"错误前提"带偏 |
| 记忆时效污染 | 旧事实当新事实用（静态索引无时间戳） | 用去年的政策答今年的问题 |
| 记忆投毒 | 恶意/错误内容写入持久记忆 | 跨会话感染——所有后续会话被污染（ASI06） |

```text
投毒传播链（OWASP ASI06）：
  恶意网页/文档 → 检索注入 Agent 上下文 → 模型"记住"恶意指令
  → 写入长期记忆 → 后续所有会话带着恶意指令运行 → 持续渗透
  无写入校验 = 记忆层是攻击者的"持久化后门"
```
