# 缺陷应对框架：防护与治理

> 理论篇：**面对已知缺陷的系统性对策**——校验门、断路器 Agent、确定性外壳、人工在环、Agentic SRE、权限治理。面试"你怎么防这些缺陷"的框架答案。生产落地见 [Agent 调优、排错与安全模块](..%2F..%2FAgent%20调优、排错与安全模块（生产必备）%2F00-总览：Agent%20调优、排错与安全模块（生产必备）.md)。

## 1. 应对总纲：三层防线

```text
第一层 预防：把错误挡在产生之前
  ——契约化工具 / 最小权限 / 接地检索 / 终止条件
第二层 检测：让错误看得见
  ——步骤级追踪 / 四层指标 / 断路器 Agent / SLO 告警
第三层 遏制：让错误不扩大
  ——校验门（不传未验证状态）/ 隔离沙箱 / 回滚 / 人工接管
2026 核心原则：注入与错误无法根治——目标是控制爆炸半径
```

> 🎯 核心要点（背诵版）：**Agent 缺陷的应对不是"消除错误"，而是"让错误便宜"**——错误不可避免（模型概率性），但可以：预防（少犯）、检测（早发现）、遏制（不扩大）。三层防线对应三个问题：怎么不犯、怎么看见、怎么止损。

## 2. 六大战术（面试必说）

| 战术 | 机制 | 治什么缺陷 |
|---|---|---|
| **校验门（Validation Gates）** | Agent/步骤间不传递未验证状态——每次交接校验输出 | 复合错误（01）、级联失败 |
| **断路器 Agent** | 1B-3B 小模型监控"Agent 网球"（互相争论 >3 轮）、停滞、**礼貌螺旋**（过度礼貌=逻辑循环信号）→ 停机 | 循环失控（03） |
| **确定性外壳** | 模型推理限制在代码驱动的阶段内——能代码化就代码化（步骤从模型驱动移到代码驱动） | 非确定性、复合错误 |
| **重新接地（re-grounding）** | 每 ~9 步重新注入目标/约束/关键状态（-80% 累积失真） | 上下文退化（04） |
| **检查点-验证** | 每成功一步存状态，从最后安全点续跑而非重来 | 长任务失败、成本 |
| **人工在环** | 高影响动作确认门 + 失败阈值转人工 + 不知道就求助（禁幻觉式恢复） | 安全（06）、幻觉（02） |

## 3. 编排模式：怎么搭才不放大缺陷

| 编排方式 | 机制 | 可靠性 |
|---|---|---|
| 无编排自由链 | Agent 随意互调 | 基线（错误自由传播） |
| **正式编排框架** | 层级结构 + 校验门 | **失败率降低 3.2×**（2026 实证） |
| Planner-Worker-Judge | 规划 + 执行 + 独立验证 Agent | 验证环节兜底（防单一盲区） |
| 层级编排 | 单一编排者 + 视觉验证输出 | 复杂任务可控 |
| 并行 swarm | 隔离任务域 + 独立作用域 | 并行效率（防交叉污染） |

> ⚠️ 2026 判断（面试加分）：**复杂度不是复杂度**——"一个带计算机控制的强 Agent 常常打败一条脆弱的五 Agent 链"；确定性脚手架（校验门/代码阶段）比信任自主性可靠。MIT 95% 试点失败的教训：**先最简形态 + 验证边界，再谈扩展**。

## 4. Agentic SRE：把 Agent 当非确定性微服务管

| 维度 | 量化 SLO | 告警阈值 |
|---|---|---|
| 成功率 | 任务级成功率 | <95% 告警 |
| 交接延迟 | 步骤/Agent 间交接时间 | >30s 红旗 |
| 工具保真度 | 工具调用-结果匹配率 | 下降即查 |
| 成本 | 单成功产出成本（cost per successful outcome） | 成本 > 价值 → 降自主度 |

| 事故响应层级 | 动作 |
|---|---|
| 隔离 | 撤销写权限、只读沙箱、暂停 Agent |
| 快照 | 保存状态与轨迹（回放复盘） |
| 回滚 | 回滚提示词/RAG 索引/工具配置 |
| 复盘 | 四层评估定位病灶（检索/轨迹/生成/路由） |

> 💡 2026 新指标：**"cost per successful outcome"（单成功产出成本）**——如果一次运行的成本超过它产出的价值，它就不该自主运行——把成本与可靠性放进同一个决策。

## 5. 安全治理五件套（与 06 篇呼应）

| 手段 | 内容 |
|---|---|
| 最小权限 | 每 Agent 独立身份 + 每调用级校验 + 临时凭据 |
| 内容隔离 | 不可信内容与指令分离（检索内容标 data） |
| 外传控制 | URL 白名单 + DLP + 传输审计 |
| 人工确认门 | 不可逆动作必须批准 |
| 运行时监控 | 机器速度行为监控 + 实时遏制（攻击分钟级完成） |

| 六大战术？ | 校验门 / 断路器 Agent / 确定性外壳 / re-grounding / 检查点 / 人工在环 |
