# 2026 行业共识：官方定义盘点

> 理论篇：**"什么是 Agent"在 2026 年已从营销词变为可判定的工程定义**——Anthropic / OpenAI / Gartner / Hugging Face / WAIC 的官方口径盘点，以及 MCP 标准化、Loop 工程共识。面试"各家怎么定义 Agent"的标准答案。

## 1. 各方定义总表（面试背诵版）

| 机构 | 定义 | 关键词 |
|---|---|---|
| **Anthropic** | LLM 动态掌控自身流程与工具使用，在环境反馈循环中工作，可在检查点暂停征求人工反馈，设停止条件维持控制 | 动态掌控、ground truth、人工介入 |
| **OpenAI** | "能智能完成任务（intelligently accomplish tasks）"的系统——从简单工作流到开放目标 | 任务智能、开放目标 |
| **Gartner** | AI 助手进化为**任务型自主系统**——独立执行端到端复杂任务，无需人工介入 | 任务专门化、独立运行 |
| **Hugging Face（工程师口径）** | Agent = Model + Scaffolding + Harness——裸模型 + 模型所见 + 循环引擎 | 三层拆解 |
| **社区共识（WAIC 2026）** | 以 LLM 为认知核心，工具连接外部世界，感知-思考-行动-观察的自主闭环推进目标 | 运行范式、闭环执行 |

> 🎯 核心要点：**各家定义的重合区 = 行业共识**——① 模型自主决策（不是代码写死）；② 用工具与环境交互；③ 闭环迭代直到完成；④ 有边界（停止条件/人工介入）。面试答"什么是 Agent"按共识区答，再按需引各家。

## 2. Anthropic 定义详解（工程界最常用）

| 特征 | 原文要点 | 面试翻译 |
|---|---|---|
| 自主规划与执行 | 以人类指令开始，明确任务后独立规划执行 | 给目标，自己拆自己干 |
| 工具反馈循环 | 基于环境反馈循环使用工具 | 每步拿 ground truth 校准 |
| 检查点人工介入 | 可暂停征求人类反馈/判断 | 该问就问，不是闷头干 |
| 灵活终止 | 目标达成或停止条件触发（最大迭代/时限） | 有刹车，不烧钱 |
| 适用边界 | 无法预测所需步骤数、无法硬编码路径的开放问题 | Workflow 的反面 |

**配套三原则**（Anthropic《Building Effective Agents》）：

| 原则 | 内容 |
|---|---|
| 简单性 | 找到最简单的方案，只有实证能改进结果才加复杂度 |
| 透明性 | 显式展示 Agent 的规划步骤（用户可理解可干预） |
| 精心设计 ACI | Agent-Computer Interface：工具文档与测试要和提示词一样认真 |

## 3. OpenAI 定义详解（Agents SDK 口径）

OpenAI 对 Agent 的组件清单（2025 官方口径，2026 沿用）：

| 组件 | 内容 |
|---|---|
| **Models** | 推理、决策、处理多种模态 |
| **Tools** | 托管工具（hosted tools）/ 函数工具 / 其他 Agent |
| **Knowledge & Memory** | 外部或持久知识 |
| **CUA** | Computer-Using Agents——用视觉语言模型操作计算机界面 |
| **Guardrails** | 输入/输出校验，保证安全与相关性 |
| **Orchestration** | 多 Agent 的工作流管理与任务委派 |

> 💡 与 Lilian Weng 四元组对照：OpenAI 官方清单把"工具/记忆/模型"原样保留，**新增 CUA（操作计算机）与 Guardrails（安全护栏）**——反映了 2025-26 定义从"能力"向"可控性"的扩展。

## 4. WAIC 2026 共识：评价标准变了

2026 世界人工智能大会（WAIC）的行业共识——**衡量 AI 价值的标尺不再是 Benchmark 跑分，而是其在真实业务流中自主规划、工具调用及闭环执行的成功率**。

| 旧标准（2023-25） | 新标准（2026） |
|---|---|
| Benchmark 跑分（MMLU/HumanEval…） | 真实业务流闭环执行成功率 |
| 模型参数规模竞赛 | Agent 工程化落地 |
| "模型有多聪明" | "系统有多可靠" |

> ⚠️ 面试用法：被问"2026 年 Agent 行业怎么看"——"产业重心从参数规模竞赛转向 Agent 工程化落地；评价从跑分转向闭环执行成功率；工具连接靠 MCP 标准化；可靠性靠 Loop 工程与护栏"。

## 5. MCP 与 Loop 工程：2026 的两大基础设施共识

| 共识 | 内容 | 解决什么 |
|---|---|---|
| **MCP 成为事实标准** | Anthropic 发起的 Model Context Protocol，统一 JSON-RPC 接口把"工具"抽象为即插即用资源 | "AI-工具连接碎片化"——每家一种工具协议的时代结束 |
| **Loop 工程成为主流** | Addy Osmani 系统提出概念；Anthropic 公开 Claude Code 四种 loop 原语（回合制/目标驱动/定时触发/主动式） | "模型怎么持续干活"——从 Prompt 工程到 Loop 工程 |

**2026 一句话（面试金句）**：**"Agent 是大模型 + Harness 的系统工程——Prompt 决定模型怎么答，Harness/Loop 决定系统怎么干活，MCP 决定工具怎么接，Guardrails 决定边界怎么设。"**
