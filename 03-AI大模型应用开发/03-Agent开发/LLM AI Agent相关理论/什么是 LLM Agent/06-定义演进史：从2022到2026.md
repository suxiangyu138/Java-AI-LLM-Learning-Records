# 定义演进史：从 2022 到 2026

> 理论篇：**"Agent 的定义"本身也在演进**——从 2022 年的 ReAct 论文，到 2023 年 AutoGPT 热潮与 Lilian Weng 综述，再到 2025 年官方定义齐备、2026 年"Agent 时刻"。面试"Agent 概念从哪来、现在到哪了"的标准时间线。

## 1. 演进时间线（面试可背）

| 年份 | 里程碑 | 对"定义"的贡献 |
|---|---|---|
| 2022 | **ReAct 论文**（Yao 等） | 首次把"推理+行动交织循环"形式化——Agent 的机制原型 |
| 2023 | AutoGPT / BabyAGI 热潮 | 首次引爆"自主 Agent"大众认知（自己定目标→自己拆→自己干）——也暴露了不可靠 |
| 2023 | **Lilian Weng 综述**（OpenAI） | 给出四元组解剖（规划/记忆/工具/LLM）——**定义开始收敛为"结构"而非"口号"** |
| 2023 | OpenAI 官方文档定义 | "模型指挥工具完成任务的系统"——官方口径雏形 |
| 2024 | Anthropic《Building Effective Agents》 | **Workflows vs Agents 二分法**——边界定义（流程谁说了算） |
| 2025 | OpenAI Agents SDK 发布（2025.03） | "能智能完成任务的系统"官方定义 + 六大组件清单 |
| 2025 | Gartner 预测发布（2025.08） | 40% 企业应用 2026 内置任务型 Agent + **agentwashing 警告** |
| 2025-26 | 推理模型成熟（o 系列/R1/Claude thinking） | 定义重心从"模型能力"转向"系统可靠性" |
| 2026 | WAIC / Loop 工程 / MCP 标准化 | 共识定型：价值=闭环执行成功率；Agent = Model + Harness |

> 🎯 演进主线（面试背这条）：**口号期（AutoGPT，2023）→ 结构期（四元组，2023）→ 边界期（vs Workflow，2024）→ 官方定义期（2025）→ 工程共识期（2026）**——"什么是 Agent"从营销词变成了可判定的工程定义。

## 2. 三个关键转折点

### 转折一：AutoGPT 热潮与退潮（2023）

| 阶段 | 现象 | 教训 |
|---|---|---|
| 热潮 | 自主 Agent 火遍全网，人人讨论"通用 Agent" | 大众认知"Agent=给自己定目标的超级 AI" |
| 退潮 | 幻觉累积、循环失控、成本不可控，多数项目搁浅 | **"自主"必须有边界、有终止、有评估**——催生了工程化定义 |

### 转折二：Anthropic 的边界定义（2024）

- 之前：Agent 与"用 LLM 的应用"混为一谈。
- 之后：**Workflows（代码预定义路径）vs Agents（模型动态掌控流程与工具）**——定义从"成分"（有没有用模型）变成"控制权"（流程归谁）。
- 影响：RAG 管道、提示链被明确排除在 Agent 之外，**agentwashing 有了判定工具**。

### 转折三：2026 "Agent 时刻"

Gartner 用三组数据定义了这个时刻：

| 数据 | 含义 |
|---|---|
| 2026 年 40% 企业应用内置任务型 Agent（2025 年 <5%） | 采纳拐点——从"聊到用" |
| 2035 年 Agentic AI 驱动 ~30% 全球企业应用软件收入（超 $4500 亿，2025 年 2%） | 商业化爆发 |
| 2026 CIO 调查：仅 17% 组织已部署，60%+ 预计两年内落地 | 所有新兴技术中最激进的采纳曲线 |
| 首个《2026 Hype Cycle for Agentic AI》：Agentic AI 处于**期望膨胀峰值** | 热度 vs 成熟度失衡——完全自主 Agent "对多数企业场景尚未就绪" |

> ⚠️ 面试谈趋势的完整姿势：**先说 Gartner 的乐观数据（40%/4500 亿），再补 Hype Cycle 的冷静面（期望峰值、未就绪、治理/安全/成本三大悬顶问题）**——显示你既知道趋势也知道风险。

## 3. Gartner 五阶段演进路线图

| 阶段 | 时间 | 形态 | 关键特征 |
|---|---|---|---|
| 1 | 2025 底 | 每个应用的 AI 助手 | 嵌入应用、简化交互、**依赖人工输入**（不是真 Agent） |
| 2 | 2026 | 任务型 Agent 应用 | 可独立执行端到端复杂任务（40% 预测的落点） |
| 3 | 2027 | 应用内协作 Agent | 1/3 实现是不同技能 Agent 组合，从实时数据学习 |
| 4 | 2028 | 跨应用 Agent 生态 | 专业 Agent 网络跨应用动态协作；1/3 用户体验从原生 App 转向 Agent 化前端 |
| 5 | 2029 | 新常态 | ≥50% 知识工作者学会使用/治理/创建 Agent；标准化协议互通 |

> 💡 背诵要点：**2025 助手 → 2026 任务型 → 2027 协作 → 2028 生态 → 2029 新常态**。面试问"Agent 未来三年怎么走"直接按这张表讲，最后落到"治理、安全、成本是贯穿的使能器"。

## 4. 定义演进的驱动力

```text
模型能力（推理内建、长上下文）→ 定义从"模型强不强"转向"系统稳不稳"
工具生态（Function Calling→MCP 标准化）→ 定义从"能不能调用"转向"连接成不成体系"
工程实践（Loop 工程、评估体系）→ 定义从"能不能动"转向"能不能可靠交付"
```

| 驱动力 | 2023 的定义侧重 | 2026 的定义侧重 |
|---|---|---|
| 模型 | 用最强的模型 | 模型同质化——差异在 Harness |
| 工具 | 能调 API 就新鲜 | MCP 即插即用是标配 |
| 评估 | 跑分（Benchmark） | 真实业务流闭环执行成功率（WAIC 2026） |
| 边界 | 模糊（AI 应用≈Agent） | 清晰（自主闭环 + 动态控制 + agentwashing 警惕） |

## 5. 面试速记

| 问题 | 一句话答案 |
|---|---|
| Agent 概念起源？ | ReAct（2022）首次形式化"推理+行动交织"；AutoGPT（2023）引爆大众认知 |
| 定义收敛的关键节点？ | Lilian Weng 四元组（2023 结构期）→ Anthropic vs Workflow（2024 边界期）→ 官方定义（2025） |
| Anthropic 边界定义？ | 工作流=代码预定义路径；Agent=模型动态掌控流程与工具 |
| 什么是 Agent 时刻？ | 2026 年 40% 企业应用内置任务型 Agent 的采纳拐点（Gartner） |
| Gartner Hype Cycle 2026 怎么看 Agent？ | 处于期望膨胀峰值；完全自主 Agent 对企业多数场景尚未就绪 |
| 五阶段演进？ | 助手(2025)→任务型(2026)→协作(2027)→生态(2028)→新常态(2029) |
| 定义演进的驱动力？ | 模型→工具→工程：从"模型强不强"到"系统稳不稳" |
| 2026 对 Agent 的评价标准？ | 真实业务流中自主规划+工具调用+闭环执行成功率，而非跑分 |
