# 四大能力组件：规划-记忆-工具-反思

> 理论篇：Agent 的"解剖学"——Lilian Weng（OpenAI）2023 年综述的四元组（规划/记忆/工具/LLM 大脑），2026 年的五层工程结构，以及组件如何协作成闭环。组件深潜见 [Agent 四大核心组件](../..%2FAgent%20四大核心组件%2F00-Agent四大核心组件总览.md)（11 篇）。

## 1. 四元组：社区公认的 Agent 解剖

业界最常引用的拆解来自 **Lilian Weng（OpenAI，2023）《LLM Powered Autonomous Agents》**——Agent 由四块组成：

| 组件 | 职责 | 面试举例 |
|---|---|---|
| **规划（Planning）** | 把大目标拆成可执行子步骤；必要时反思修正 | "订机票"→查航班→比价→下单 |
| **记忆（Memory）** | 短期记当前上下文；长期存历史与知识 | 对话历史 / 向量库中的偏好 |
| **工具（Tools）** | 调用搜索、代码执行、数据库、API 弥补模型短板 | 天气 API、计算器、SQL |
| **LLM 大脑** | 推理与决策的核心控制器 | 理解目标、选择行动、判断完成 |

> 🎯 核心要点：**四元组的"分工逻辑"——LLM 大脑负责"想"，规划负责"拆"，工具负责"做"，记忆负责"记"**。任何 Agent 都能在这张表里找到归属；面试答"Agent 由哪些部分组成"直接背这四块（有的版本把反思并入规划，见下）。

## 2. 反思：被单独列出的第五能力

Lilian Weng 原文把反思（Reflection）归入规划部分，但 2025-26 社区普遍把它单列——**因为"自我批评-修正"循环已成为 Agent 可靠性的关键组件**：

| 定位 | 内容 |
|---|---|
| 规划内的反思 | 执行中发现自己走偏 → 修正计划（re-plan） |
| 独立反思组件 | 对已产生的结果做批判性评估 → 生成改进指令 → 重新生成 |
| 2026 状态 | Reflexion（2023）范式成熟；反思组件化（详见 [Agent 四大核心组件 04-反思组件](../..%2FAgent%20四大核心组件%2F04-反思组件：自我评估与纠错.md)） |

## 3. 五层工程结构：从最小循环到完整系统（2026）

| 层 | 内容 | 回答的问题 |
|---|---|---|
| ① 目标与指令 | Goal + Instructions | 要完成什么？不能做什么？ |
| ② 模型与决策 | Model + Planning | 如何理解并决定下一步？ |
| ③ 上下文与记忆 | Context + Memory | 当前决策需要哪些信息？ |
| ④ 工具与执行环境 | Tools + Skills + Execution + Environment | 如何真正采取行动？ |
| ⑤ 反馈、评估与安全 | Observation + Feedback + Evaluation + Guardrails | 行动是否正确？如何证明完成？ |

> 💡 这五层是从"最小循环（①②→⑤）"到"工程化系统"的渐进——最小 Agent 只需要 ①②④⑤（目标+大脑+工具+反馈）；加上记忆（③）才谈得上长任务；加上 Guardrails（⑤ 扩展）才能进生产。面试答"完整 Agent 系统长什么样"按这五层展开。

## 4. 组件协作循环：完整 Agent 运行时

```text
用户目标（① 目标与指令）
    │
    ▼
LLM 大脑（② 模型与决策：理解+规划）
    │ 产出子步骤
    ▼
   ┌─ 需要外部信息？──► 记忆查询（③）/ 工具调用（④）
   │                        │
   │                        ▼
   │               Observation 反馈（⑤：结果回填）
   │                        │
   └── 目标完成？ ◄─────────┘
        │ 否：修正规划（反思）→ 继续循环
        ▼ 是
  最终结果交付
```

| 协作要点 | 机制 |
|---|---|
| 每轮的信息流 | 上下文 = 历史 + 记忆检索 + 工具观察结果（一次注入） |
| 规划的落点 | 规划产出的是"下一步行动"而非一次性长计划（ReAct 风格） |
| 反思的触发 | 反馈异常 / 无进展 / 完成自检时启动 |
| 记忆的写入时机 | 关键事实、完成结果、失败教训——在循环中持续写入 |

## 6. 面试速记

| 问题 | 一句话答案 |
|---|---|
| Agent 由哪几部分组成？ | LLM 大脑 + 规划 + 记忆 + 工具（Lilian Weng 四元组）；反思常被单列为第五能力 |
| 四元组的分工逻辑？ | 大脑想、规划拆、工具做、记忆记 |
| 反思组件干什么？ | 对结果批判性评估→生成改进指令→重新生成（Reflexion 范式） |
| 2026 五层工程结构？ | 目标指令→模型决策→上下文记忆→工具环境→反馈评估安全 |
| 最小 Agent 需要哪几层？ | 目标+大脑+工具+反馈（①②④⑤）；记忆与安全是工程化扩展 |
| 规划产出什么？ | "下一步行动"而非一次性长计划（ReAct 风格，动态迭代） |
