# 规划组件：任务分解（面试必背）

> 背诵篇：四大核心组件之「规划组件」——30 秒背诵卡 + 4 个面试高频题 + 规划失败模式。深化见 [Agent 四大核心组件 03 篇](..%2F..%2FAgent%20四大核心组件%2F03-规划组件：任务分解与行动编排.md)，速记见 [Planning & Reflection 最简定义](..%2F..%2FAgent组件%2F四大基础核心组件（最简定义）%2FPlanning%20%26%20Reflection%20规划反思组件%2F00-PlanningReflection规划反思组件最简定义总览.md)。

## 1. 30 秒背诵卡

| 概念 | 背诵版一句话 |
|---|---|
| 规划组件 | 把大目标拆成可执行子步骤，必要时反思修正——Agent 的"参谋部" |
| 规划产出 | "下一步行动"（ReAct 风格动态规划）或"完整计划"（Plan-Execute 风格） |
| 两种范式 | Plan-and-Execute（先全计划后执行）/ 自适应规划（部分计划+执行中重规划） |
| 规划的价值 | 复杂任务分解后可执行——无规划则模型每步短视（myopic） |
| re-plan 门 | 计划脆弱——执行偏离时必须能触发重规划，否则计划失效 |
| 2026 升级 | 前瞻反思（执行前批判计划）+ 动态扩充行动空间（CAR） |
| 关键实证 | ACL 2026：低级执行是主要瓶颈（不只高级推理）；PDDL 计划优于自然语言计划 |
| 与反思分工 | 规划管"怎么拆"，反思管"拆得对不对/执行得对不对" |

## 2. 面试高频问题（背诵版）

**Q1. Agent 为什么要规划？不规划行不行？**
> 答：复杂任务"一次性生成"不可行——模型单次输出无法可靠完成多步任务（任务分解后每步可验证、可反馈）。不规划的表现是**短视行为**：模型逐反应付，忘记全局目标（goal drift），在局部反复重试。规划把"做对"变成"每一步都朝向目标"。实证：Plan-and-Execute 对比 ReAct 完成率 +27%、工具调用 -42%、时间 -35%（但计划脆弱，需 re-plan 门兜底）。

**Q2. Plan-and-Execute 和自适应规划（Adaptive Planning）怎么选？**
> 答：按**任务结构是否可知**选——① 结构可知（步骤稳定、依赖清晰）：Plan-and-Execute，先全计划后执行，可预测、省轮次；② 结构不可知（中途可能偏离、需要反馈修正）：自适应规划（部分计划→执行→重评估→续计划），灵活但轮次多。2026 实证：PDDL 结构化计划比自然语言计划更简洁目标导向；但**执行层才是主瓶颈**——计划再好，执行落地弱也白搭。

**Q3. 计划失败/执行偏离时怎么办？**
> 答：三层机制——① **re-plan 门**：监测执行偏离（反馈异常/无进展），触发重新规划；② **反思联动**：反思组件评估结果，决定"继续/重试/重规划"——重规划是反思的三大出口之一；③ **2026 升级：前瞻式规划修复**——PreFlect 在执行前批判计划本身（从历史轨迹提炼成败模式）；CAR 遇到工具缺失时**动态合成新工具**扩充行动空间（元工具合成器），而不是卡在"工具不够用"。

**Q4. 规划组件最常见的失败模式？**
> 答：① 计划幻觉——拆出不可执行步骤（没有对应工具/数据）；② 计划过细/过粗——过细浪费轮次、过粗等于没规划；③ **缺乏 re-plan**——计划失效后继续硬执行（myopic 重试死循环）；④ 上下文无预算——记忆灌满窗口后规划退化；⑤ 目标漂移（goal drift）——执行器忘了原目标。ACL 2026 分层框架：高层规划/低级执行/重规划三层失败要分开诊断——**多数失败在低级执行**（感知落地与自适应控制），不只是推理问题。

## 3. 避坑与易混点

| 坑 | 澄清 |
|---|---|
| "规划 = 一次性长计划" | 2026 主流是动态规划——规划产出"下一步行动"，ReAct 风格 |
| "计划写了就执行到底" | 计划是假设——偏离时必须 re-plan（计划脆弱是实证结论） |
| "规划器越强越好" | 执行层是瓶颈——先保证工具/感知落地，再优化规划 |
| "规划组件 = 反思组件" | 规划拆解（怎么拆），反思评估（对不对）——分工但联动（重规划） |

## 4. 面试速记

| 问题 | 一句话答案 |
|---|---|
| 规划干什么？ | 大目标 → 可执行子步骤，必要时修正（参谋部） |
| 两种规划范式？ | Plan-Execute（结构可知）/ 自适应（结构不可知）——按任务选 |
| 计划偏离怎么办？ | re-plan 门 + 反思联动（继续/重试/重规划） |
| 2026 新机制？ | 前瞻反思 PreFlect（先批计划）、CAR 动态合成工具 |
| 最大失败模式？ | 计划幻觉 / 缺乏 re-plan / 目标漂移 / 执行层瓶颈 |
| 与反思分工？ | 规划管拆、反思管评——反思结论驱动重规划 |
