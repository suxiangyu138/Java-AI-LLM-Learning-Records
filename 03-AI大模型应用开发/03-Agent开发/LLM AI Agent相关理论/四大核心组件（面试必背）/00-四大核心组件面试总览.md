## 3. 四大组件一图背熟

```text
Agent = LLM 大脑 + 规划反思 + 记忆 + 工具行动
         （想）      （拆与评）    （记）      （做）

用户目标
  │
  ▼
LLM 大脑：下一步做什么、怎么想            ← 推理模型（thinking）提高决策质量
  ├─→ 规划组件：目标 → 步骤列表          ← Plan-Execute 或自适应规划
  ├─→ 记忆组件：检索历史/偏好 → 注入上下文  ← 工作记忆=上下文窗口
  └─→ 行动组件：调工具执行 → 收集观察      ← Function-Calling + 环境反馈
  │
  └─→ 反思组件：结果评估 → 继续/重试/重规划  ← 独立批评者，防自我确认偏差
      │
      └─→ 记忆回写：新事实/结果 → 长期记忆
```

| 组件 | 角色 | 类比 | 回答的问题 | 2026 关键升级 |
|---|---|---|---|---|
| LLM 大脑 | 推理决策核心 | 大脑 | 下一步做什么 | 推理模型内建思考；按难度路由成本 |
| 规划反思 | 拆解与评估 | 参谋部 | 任务怎么拆、做得对不对 | 前瞻式反思（PreFlect）；重规划机制 |
| 记忆 | 跨轮信息保持 | 海马体 | 我记住了什么 | 混合检索（BM25+向量+RRF）；图记忆 |
| 工具行动 | 连接外部世界 | 手和脚 | 怎么执行、效果如何 | schema 契约化；<20 工具；MCP 标准化 |

## 5. 2026 生态基准

> 📅 基准窗口：2026-08。版本与事实以各模块【参考来源】为准。

- **LLM 大脑**：推理模型把思考内建（thinking tokens 隐藏但计费，Agent 通常多发 2-5 倍 token）；收益递减（no→medium 陡、high→max 平，Snell 计算最优）；**按任务难度路由是成本正解**（客服场景 70/25/5 分流省 60% 无质量回退）；OpenAI GPT-5 内建路由（省 50-80% 输出 token）、Claude budget_tokens、Gemini thinkingBudget——**thinking 从固定模式变成"旋钮"**。
- **规划**：2026 研究从"事后纠错"转向"执行前前瞻"——PreFlect（前瞻反思，先批计划再执行）、CAR（动态扩充行动空间 + 反射式重规划）、Devil's Advocate（预演批判减 45% 计划返工）；ACL 2026 关键发现：**低级执行是主要瓶颈**（不只高级推理）；Plan-and-Execute vs 自适应规划按任务结构可知性选。
- **反思**：反思循环（生成-批评-改进）要求**独立批评者**（独立 prompt 或独立模型）+ 显式迭代上限；oracle 前提（Reflexion 每轮一次调用）——成本高，高价值任务才值；前瞻反思（批判计划本身）优于事后纠错。
- **记忆**：四层记忆架构收敛（工作记忆=上下文窗口/短期=会话缓冲/长期=语义+情景+程序/归档=永久）；**纯向量检索不够**——DMR 基准向量 RAG 仅 60-70% vs 时序知识图谱 94.8%；生产标配**混合检索**（BM25+向量+RRF 融合）；TencentDB Agent Memory（2026-04 开源）短时基准 +51.52% 成功率/-61.38% token。
- **工具**：schema 是契约不是代码——enums 优于自由串、`additionalProperties:false` 收口、oneOf 谨慎（弱模型常选错分支）；**活动工具集 <20 个**（>30-50 选择精度线性下降）；BFCL V4 多轮工具编排精度比单轮掉 30-60pp（顺序选工具是瓶颈）；**~38% 生产 Agent 失败源于 payload 幻觉**；工具描述是准确度第一大因素；三指标分开度量（JSON 校验/调用准确率/工具选择准确率）。
- **行动**：结构化错误回传（error_code + recoverable + suggested_action）让模型能自行修复；写操作必须幂等（idempotency key）；BFCL v3 模型基线：GPT-5.x ~89%、Claude Opus 4.7 ~87%（无关性检测最强）、Gemini 3 Pro ~85%。
- **与体系分工**：[Agent 四大核心组件](..%2F..%2FAgent%20四大核心组件%2F00-Agent四大核心组件总览.md) 管解剖学深潜（机制原理）；[四大基础核心组件（最简定义）](..%2F..%2FAgent组件%2F四大基础核心组件（最简定义）%2FLLM大脑（推理决策模块）%2F00-LLM大脑最简定义总览.md) 管 3 分钟概念速记；[什么是 LLM Agent](..%2F什么是%20LLM%20Agent%2F00-什么是LLM%20Agent总览.md) 管 Agent 定义与边界；本体系管**面试表述与背诵**。
