# 记忆组件：短中长时（面试必背）

> 背诵篇：四大核心组件之「记忆组件」——30 秒背诵卡 + 5 个面试高频题 + 检索架构与 2026 图记忆。深化见 [Agent 四大核心组件 05 篇](..%2F..%2FAgent%20四大核心组件%2F05-记忆组件：短中长时记忆架构.md)，速记见 [Memory 最简定义](..%2F..%2FAgent组件%2F四大基础核心组件（最简定义）%2FMemory%20记忆组件%2F00-Memory记忆组件最简定义总览.md)。

## 1. 30 秒背诵卡

| 概念 | 背诵版一句话 |
|---|---|
| 记忆组件 | 跨轮信息保持——短期记当前上下文，长期存历史与知识（Agent 的"海马体"） |
| 四层架构 | 工作记忆（上下文窗口）/ 短期（会话缓冲）/ 长期（语义+情景+程序）/ 归档（永久） |
| 核心流程 | 写入 → 召回 → 整合（写入=记录/压缩，召回=检索，整合=注入决策上下文） |
| 召回评分 | 相关性（cosine）+ 新鲜度（时间衰减）+ 重要性（Generative Agents 三因子） |
| 混合检索 | BM25 关键词 + 向量语义 + RRF 融合——2026 生产标配 |
| 图记忆 | 时序知识图谱解决"关系 + 时效"——DMR 基准 94.8% vs 向量 RAG 60-70% |
| 记忆管理 | Agent 自主决定读写（MemGPT 内循环）；或外部管理器（Mem0） |
| 记忆治理 | 遗忘、去重、更新、防投毒——记忆污染比没有记忆更糟 |

## 2. 面试高频问题（背诵版）

**Q1. Agent 的记忆分哪几层？每层用什么实现？**
> 答：四层——① **工作记忆** = 模型上下文窗口（零延迟、容量有限、易失）：最近工具输出、中间计划、任务状态；② **短期记忆** = 会话持久、可搜索（会话缓冲按 thread/session 键控，Redis 缓存毫秒级）；③ **长期记忆** = 跨会话持久（语义记忆存事实/策略、情景记忆存历史交互、程序记忆存学会的工作流；向量库/知识图谱检索，100-300ms 可接受）；④ **归档记忆** = 永久可查询存储。MemGPT 的三层经典版：核心记忆（~2K token 常驻上下文，Agent 用 append/replace 自管理）+ 召回记忆（外部可搜索历史）+ 归档记忆（无限、语义检索）。

**Q2. 记忆的"写入-召回-整合"工作流是什么？**
> 答：① **写入**：对话/结果/失败教训落库（原始存情景层，定期压缩/摘要提升到语义层）；② **召回**：按相关性+新鲜度+重要性评分取回（Generative Agents 三因子：recency 指数衰减、importance、relevance 余弦相似）；③ **整合**：召回结果注入决策上下文（记忆管理器决定注入多少——上下文预算纪律，防记忆灌满窗口）。2026 生产加**合并与遗忘**：周期性反思进程把短期日志的关键事实/决策/错误摘要进长期库（短压长凝的闭环审计）。

**Q3. 为什么说"纯向量检索不够"？**
> 答：向量库会丢两类信息——**关系**（"客户 X 买了产品 Y"能检索，但"产品 Y 的其他买家还买了什么"无法遍历）与**时效**（无法区分"现在的职务"和"去年的职务"）。实证（DMR 基准）：向量 RAG 召回准确率仅 60-70%，而 Zep 时序知识图谱 94.8%、MemGPT 93.4%（递归摘要最差 35.3%）。2026 趋势：**图记忆 + 混合检索**（BM25+向量+RRF 融合 + 时间戳过滤），向量库保留为粗召回层。

**Q4. 长期记忆怎么防止"记忆污染"？**
> 答：治理四原则——① **更新**：事实变更要时间戳化（valid from/until），保留"当前值 vs 历史值"；② **去重与合并**：同名实体/重复事实合并，防冗余膨胀；③ **遗忘**：低重要性/过期记忆定期清理（记忆有界才可控）；④ **防投毒**：外部来源内容不可信，写入前校验与权限隔离（记忆投毒是 2026 安全重点——恶意指令注入记忆库）。白盒可调试：TencentDB Agent Memory 把 L2/L3 层存为可读 Markdown，防"黑盒记忆"。

**Q5. 记忆组件和上下文、知识库有什么区别？**
> 答：三个概念别混——**上下文** = 当前请求窗口里的全部信息（工作记忆的载体）；**记忆** = Agent 自己的跨轮状态（用户偏好、历史轨迹、中间结论），由 Agent 生命周期管理；**知识库** = 外部静态知识（公司文档、产品手册），一般通过 RAG 注入、不随交互变化。一句话：上下文是"这轮看什么"，记忆是"我记住了什么"，知识库是"我能查什么"。深度辨析见 [区分概念 04-记忆-vs-上下文-vs-知识库](../区分概念（面试容易混淆）/04-记忆-vs-上下文-vs-知识库.md)。

## 3. 避坑与易混点

| 坑 | 澄清 |
|---|---|
| "记忆 = 向量数据库" | 2026 结论：向量只解决语义相似，关系与时效要图/混合检索 |
| "上下文越长记忆越好" | 记忆注入要有上下文预算——灌满窗口规划退化（注入多少比存多少重要） |
| "记住一切 = 好 Agent" | 记忆是有成本的（检索延迟+token）——按需召回 + 主动遗忘 |
| "记忆写入随便存" | 写前校验、时间戳化、防投毒——脏记忆比无记忆危害更大 |
| "长期记忆 = RAG" | RAG 是外部知识检索；记忆含 Agent 自身状态（偏好/轨迹/结论） |
