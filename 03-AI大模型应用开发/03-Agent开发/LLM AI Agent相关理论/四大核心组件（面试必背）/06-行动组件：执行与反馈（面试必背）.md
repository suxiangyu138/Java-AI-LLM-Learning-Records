# 行动组件：执行与反馈（面试必背）

> 背诵篇：四大核心组件之「行动组件」——30 秒背诵卡 + 4 个面试高频题 + 错误回传与幂等。深化见 [Agent 四大核心组件 07 篇](..%2F..%2FAgent%20四大核心组件%2F07-行动组件：执行与反馈闭环.md)。

## 1. 30 秒背诵卡

| 概念 | 背诵版一句话 |
|---|---|
| 行动组件 | 执行工具调用并收集环境反馈，把"决策"变成"结果"——Agent 的"执行器" |
| 执行闭环 | 工具调用 → 结果校验 → 观察回填 → 模型再决策（循环的 Action/Observation 位） |
| 反馈类型 | 工具返回 / 代码执行结果 / 环境状态变更——循环的 ground truth |
| 错误回传 | 结构化错误（error_code + message + recoverable + suggested_action）让模型能自修复 |
| 幂等铁律 | 写操作必须幂等（idempotency key）——Agent 重试、网络失败、二次调用都是常态 |
| 超时与退避 | 双层超时（单次调用 + 整循环）+ 指数退避吸收瞬时故障 |
| 断路器 | 失败超阈值 → 停止调用并告知模型"该工具不可用" |
| 安全边界 | 高影响动作人工确认 / 沙箱 / 最小权限（"绝不让模型做未经验证的状态变更"） |

## 2. 面试高频问题（背诵版）

**Q1. 行动组件和工具组件有什么区别？**
> 答：工具组件是"能力声明"（定义有什么工具、schema 是什么）；行动组件是"执行与反馈"（真正调用、收集结果、判断成败）。分工：工具管"手有什么"，行动管"怎么用、结果如何"。对应循环位置：Action（行动组件的调用）+ Observation（行动组件的反馈回填）——二者合起来才是"手和脚"的完整角色（深潜版把工具+行动分两篇，面试答"工具行动组件"一体即可）。

**Q2. 工具执行失败时怎么让 Agent 自己恢复？**
> 答：核心是**结构化错误回传**——别返回空结果，返回带语义的错误对象：`error_code`（机器可读，模型据此分支）+ `message`（人类可读）+ `recoverable`（能否重试）+ `suggested_action`（下一步建议）。例：`{"error": "rate_limited", "retry_after": 30}` 模型就知道"等 30 秒重试"而不是瞎猜。配套：① 瞬时故障（网络抖动/限流）在工具层用**指数退避**吸收，不把原始错误抛给推理循环；② **断路器**——失败超阈值后停止调用并明确告知模型工具不可用（模型必须知道工具何时失效）；③ 预调用校验（validate_json）+ 结果形状校验。实证：工具错误转 JSON 回传可消除约 80% 卡死。

**Q3. 为什么写操作必须幂等？**
> 答：Agent 循环天然会重复调用——① Agent 重试（超时后重发）；② 网络失败但服务器已处理（客户端不知道）；③ LLM 循环可能因确认未达发第二次。非幂等操作（重复转账、重复建单）会造成灾难。解法：写操作带 **idempotency key**（幂等键），服务端按键去重；设计上让"调用两次 = 调用一次"（状态机/唯一约束）。面试延伸：这是 Agent 工程与普通 API 开发的最大差异之一——**把重试当常态设计**。

**Q4. 行动层怎么控制安全与成本？**
> 答：四层——① **权限最小化**：按行动类别定价与授权（读免费、提交需确认——2026 位置论文"边际 token 分配经济学"）；② **人工确认门**：高影响/破坏性动作（退款、删除、部署）必须人工批准（检查点模式）；③ **沙箱**：代码执行放隔离环境（VM/容器），失败可回滚；④ **预算护栏**：轮次/成本上限（终止条件六件套之一）。金句：**"never let a reasoning model make unvalidated state changes"**——高影响状态变更必须有验证与批准路径。

## 3. 避坑与易混点

| 坑 | 澄清 |
|---|---|
| "执行失败 = 任务失败" | 结构化错误回传 + 重试机制下，执行失败是"可恢复事件" |
| "空结果 = 没错误" | 空数组比结构化错误更糟——模型没有推理依据 |
| "幂等 = 重试一次" | 幂等是服务端语义（调用两次=一次），不是客户端重试策略 |
| "错误都抛给模型" | 瞬时故障工具层吸收（退避），语义错误才回传模型 |
| "模型失败就怪模型" | 约 38% 失败源于工具侧（payload 幻觉/schema）——先查工具工程 |

## 4. 面试速记

| 问题 | 一句话答案 |
