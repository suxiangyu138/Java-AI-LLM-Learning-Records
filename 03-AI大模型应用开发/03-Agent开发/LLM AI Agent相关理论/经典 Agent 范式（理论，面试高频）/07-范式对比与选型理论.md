# 范式对比与选型理论

> 理论篇：范式选择的决策框架——对比矩阵、五生产形态、选型决策树（面试高频）。

## 1. 四大范式对比矩阵（面试背诵版）

| 维度 | ReAct | Plan-Execute | Reflexion | CoT |
|---|---|---|---|---|
| 本质 | 推理+行动交织 | 先计划后执行 | 批评+记忆 | 中间步骤推理 |
| 年份 | 2022 | 2023 | 2023 | 2022 |
| 全局视图 | ❌ | ✅ | — | — |
| 外部动作 | ✅（工具） | ✅（执行） | 叠加（在 ReAct 上） | ❌（纯推理） |
| 失败模式 | 无限循环 | 计划脆弱 | 过度修正 | 浅链/承诺错误 |
| 成本画像 | 每步强模型 | 1×强+N×便宜 | 每轮+1 调用 | 线性链 |
| 适用 | 信息收集/未知流 | 长程可分解 | 高价值可重复 | 小模型/可审计 |

> 🎯 核心要点：**面试答对比的四条线——本质/失败模式/成本/适用**——别背参数，讲清"什么时候它是最优解"。

## 2. 五生产形态（2026 架构）

| 形态 | 结构 | 适用 |
|---|---|---|
| 单 Agent ReAct | 一个循环 | 起步默认（简单） |
| Plan-and-Execute | Planner+Executor | 长程可分解 |
| 层级监督 | supervisor 路由专家 | 多域任务（Multi-Agent 02 篇） |
| Maker-Checker | 行动者+验证者 | **降幻觉**（制作+检查分离） |
| 网络/Swarm | 对等共享 scratchpad | 协作任务（Multi-Agent 01 篇） |

> 💡 Maker-Checker 值得单记：**行动者生成 + 验证者检查 = 幻觉的结构性防御**——与 Reflexion 的"外部评判器"同源但架构化（02 篇大脑分层联动）。

## 3. 选型决策树（2026 理论）

```text
范式选型：
├─ 任务可分解且长程？
│   ├─ 是 → Plan-and-Execute（+re-plan 门）
│   └─ 否 → 控制流未知？
│       ├─ 是 → ReAct（信息收集）
│       └─ 否 → 简单任务 → Direct/CoT（推理内建）
├─ 高价值可重复任务？ → 加 Reflexion（有 oracle 时）
├─ 幻觉敏感（maker-checker）？ → 行动者+验证者
└─ 不确定选哪个？ → 评估集跑范式对比（范式路由，06 篇）
```

| 决策问题 | 答案 |
|---|---|
| 长程可分解？ | Plan-Execute |
| 控制流未知？ | ReAct |
| 高价值可重复 + oracle？ | 加 Reflexion |
| 幻觉敏感？ | Maker-Checker |
| 简单任务？ | 直接/CoT（不浪费） |
| 不确定？ | 评估驱动范式对比（路由） |

## 4. 成本模型对比

| 范式 | 成本公式 | 场景账 |
|---|---|---|
| ReAct | N 步 × 强模型 | 每步重决策（浪费） |
| Plan-Execute | 1×强 + N×便宜 | 强思考压缩到计划 |
| Reflexion | 基数 + R 轮 × 评判器 | 高价值才值（+3-23%） |
| ToT | 3-30x token | 探索付费（三 yes 才上） |
| 推理模型 | 思考 token 计费 | 路由+旋钮（LLM 大脑 06 篇） |

> ⚠️ 2026 理论：**"选对范式 > 选对模型"**——范式匹配度决定大部分收益（06 篇 Select-then-Solve）；成本账按"范式效率"算（-42% 工具调用的 Plan-Execute vs 每步重决策的 ReAct）。

## 5. 生产建议（2026 共识）

| 建议 | 内容 |
|---|---|
| 起步 | 单 Agent ReAct——多范式只在基线暴露失败时加 |
| 混合 | 前沿规划 + 便宜执行（成本质量平衡） |
| 防循环 | 按工具调用上限（不只全局步数——"verifier stall"） |
| re-plan | 每 K 步/低置信触发（Plan-Execute 标配） |
| 可观测 | 每 span 插桩 + 评估（范式效果数据说话） |
| 安全 | API 边界护栏（Guardrails 联动） |

> 🎯 一句话：**"范式选型 = 任务特征 × 成本模型 × 失败模式"**——三维决策（07 篇决策树）；2026 默认混合（范式路由 + 融合）。

## 6. 面试速记

| 问题 | 一句话答案 |
|---|---|
| 四范式对比？ | 本质/失败模式/成本/适用四条线 |
| 五生产形态？ | ReAct/Plan-Execute/层级/Maker-Checker/Swarm |
| Maker-Checker？ | 行动者+验证者——幻觉结构性防御 |
| 选型决策树？ | 长程→Plan/未知流→ReAct/高价值→Reflexion/简单→直接 |
| 成本模型？ | 1×强+N×便宜 vs 每步强模型 |
| 选对范式 vs 模型？ | 范式匹配度决定大部分收益 |
| 防循环？ | 按工具调用上限（verifier stall） |
| 起步建议？ | 单 Agent ReAct——失败再升级 |
| 不确定选哪个？ | 评估集跑对比（范式路由） |
| 2026 默认？ | 混合——路由+融合 |
