# 记忆 vs 上下文 vs 知识库

> 辨析篇：三种"知识/信息"形态——**存储位置不同，生命周期不同**。深潜见 [Memory 记忆组件](..%2F..%2FAgent组件%2F四大基础核心组件（最简定义）%2FMemory%20记忆组件%2F00-Memory记忆组件最简定义总览.md) 与 [RAG 体系](..%2F..%2F..%2F04-RAG检索增强生成%2F00-RAG知识体系总览.md)。

## 1. 三形态对比

| 维度 | 上下文（Context） | 记忆（Memory） | 知识库（Knowledge Base） |
|---|---|---|---|
| 本质 | 当前窗口内容 | Agent 自身状态/经验 | 外部事实/文档集合 |
| 位置 | 上下文窗口（瞬态） | Agent 存储层（跨会话） | 外部系统（检索源） |
| 生命周期 | 单轮/单会话 | 跨会话（长时） | 长期（组织级） |
| 谁写 | 装配（感知 08 篇） | Agent 提取沉淀 | 业务/文档流程 |
| 谁读 | 模型直接 | 召回注入 | 检索（RAG） |
| 类比 | 工作台 | 私人笔记本 | 公司图书馆 |

> 🎯 核心要点：**"上下文是窗口、记忆是 Agent 的、知识库是组织的"**——三者不是大小关系是归属关系；面试最容易混淆的是"记忆 vs 知识库"（都跨会话，但一个自产自销、一个外部权威）。

## 2. 混淆点 1：上下文 vs 记忆

| 问题 | 上下文 | 记忆 |
|---|---|---|
| 存什么 | 当前任务的装配内容 | 跨轮沉淀的事实/经验 |
| 谁控制 | 装配层（感知 08 篇） | 记忆组件（写入纪律） |
| 丢失 | 窗口滚动即失 | 持久（有治理） |
| 关系 | 记忆召回结果注入上下文 | 上下文被整合成记忆（Memory 02 篇工作流） |

> 💡 面试表述：**"上下文是记忆的消费场，记忆是上下文的沉淀池"**——装配注入（感知）与提取沉淀（记忆）是同一循环的两半（Memory 01 篇）。

## 3. 混淆点 2：上下文 vs 知识库

| 维度 | 长上下文 | 知识库（RAG 检索） |
|---|---|---|
| 机制 | 全量塞进窗口 | 按需检索注入 |
| 适用 | <50K-100K 稳定语料 | 大型/动态语料 |
| 成本 | 每 token 付费（全量） | 检索 + 注入相关块 |
| 风险 | context rot（98%→64%）、lost-in-the-middle | 检索质量（#1 失败点） |
| 引用 | 弱（注意力不均） | ✅（来源可追溯） |

> ⚠️ 2026 选型：**"语料 <50K-100K 且稳定 → 长上下文（省 RAG 基建）；大型/动态 → RAG"**——In-Context RAG（<100K 全塞 + prompt 缓存）是中间带（便宜 90%）。

## 4. 混淆点 3：记忆 vs 知识库

| 维度 | 记忆 | 知识库 |
|---|---|---|
| 来源 | Agent 交互沉淀（自产） | 组织文档/数据库（外部） |
| 可信度 | 需治理（可能错/被投毒） | 需检索质量（可能过时） |
| 更新 | 写入纪律 + 确认 | 业务更新流程 |
| 典型 | 用户偏好/任务经验 | 产品文档/法规 |
| 面试例 | "客户上次投诉的处理过程" | "退货政策第 3 条" |

> 🎯 一句话：**"记忆回答'这个用户/这个任务的历史'，知识库回答'世界/组织的知识'"**——一个个性化一个通用；RAG 是把知识库接进 Agent 的标准通道（Agentic RAG = 模型决定检索哪些工具/索引）。

## 5. 三形态协作（2026 生产）

```text
协作循环：
  知识库（外部）--RAG 检索--> 上下文装配（窗口）
  记忆（Agent）--召回注入--> 上下文装配
  上下文（当前）--提取沉淀--> 记忆（跨会话）
  上下文（长会话）--压缩--> 摘要记忆
```

> 💡 与感知体系联动：**三形态都在"感知管道 + 装配层"汇合**（感知 01 篇）——检索（知识库）、召回（记忆）、装配（上下文）是一条链。

## 6. 面试速记

| 问题 | 一句话答案 |
|---|---|
| 三形态判据？ | 归属：窗口/Agent/组织 |
| 上下文 vs 记忆？ | 消费场 vs 沉淀池——同一循环两半 |
| 上下文 vs 知识库？ | 全量塞入 vs 按需检索 |
| 记忆 vs 知识库？ | 个性化历史 vs 组织知识 |
| 长上下文适用？ | <50K-100K 稳定语料 |
| context rot？ | 98%→64%——全量塞入的衰减 |
| RAG 失败点？ | 检索质量（#1） |
| In-Context RAG？ | <100K 全塞+缓存——中间带 |
| Agentic RAG？ | 模型决定检索哪些工具 |
| 协作链？ | 知识库检索→装配→沉淀记忆→召回 |
