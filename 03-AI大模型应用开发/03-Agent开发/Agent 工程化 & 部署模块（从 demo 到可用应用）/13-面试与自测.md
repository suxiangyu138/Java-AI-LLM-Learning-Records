## 1. 面试题：基础概念档

> 考察点：是否真的理解"Agent 工程化在解决什么问题"。每题 30-60 秒回答，能讲清"为什么"才算过。

| # | 题目 | 答题要点 |
|:---:|------|---------|
| 1 | Demo 和生产环境的本质区别是什么？ | 可行性 vs 可靠性：输出不确定性的放大效应（级联失败）、成本/安全/审计/演进缺一不可（01 篇） |
| 2 | 什么是 LLM + 确定性代码的混合架构？ | LLM 管感知/推理/意图，代码管事务/计算/二进制正确性；"错一次要赔钱的逻辑不给 LLM"（02 篇） |
| 3 | 为什么 Agent 要拆职责单一的子 Agent？ | 调试复杂度、并行提速（团队实测 1 小时→10 分钟）、独立评估（02 篇） |
| 4 | 密钥为什么不能进 prompt？ | LLM07：prompt 必然泄漏（输出/日志/trace）；安全策略要代码强制而非模型遵守（03/08 篇） |
| 5 | 传统 APM 为什么观测不了 Agent？ | 无法解析 prompt/token/工具调用/质量分；LLM 可观测看 trace 与 eval（04 篇） |
| 6 | 什么是 OTel GenAI 语义约定？ | 跨厂商 LLM trace 字段标准（gen_ai.*）；按标准埋点可自由换后端（04 篇） |
| 7 | 测试和评估的分工是什么？ | 测试管"代码没写错"（确定性、便宜），评估管"Agent 没变笨"（质量、统计）；CI 禁真实 API（05/06 篇） |
| 8 | 为什么评估用统计回归门禁而不是固定阈值？ | 固定阈值对噪声敏感；t-test + 效果量 + 滚动基线分离信号与方差（06 篇） |
| 9 | LLM-as-Judge 有什么失败模式？ | 长度偏见、成本/延迟（5-50¢/次）、方差（CI flaky）；为方差设计 + 校准（06 篇） |
| 10 | Agent 评估和 LLM 评估有什么区别？ | 评估单元是轨迹（工具选择/参数/结果利用/错误恢复）；执行验证端状态（06 篇） |
| 11 | Prompt Caching 为什么是成本第一杠杆？ | 成本=轮数×全量上下文×单价；缓存省输入成本 85-90%、TTFT 降 50-70%（07 篇） |
| 12 | 缓存感知路由解决什么问题？ | 盲轮询把相同前缀打散到不同 KV 缓存，命中率可跌至 8%，TTFT p90 差 57 倍（07 篇） |
| 13 | 提示注入为什么无解？ | 指令与数据同信道；解法是把输出当不可信 + 权限在模型外强制（08 篇） |
| 14 | 什么是过度自主权（LLM06）？ | 权限过大 + 一次注入 = 真实破坏；最小权限 + 审批门 + 循环上限（08 篇） |
| 15 | 异步 Agent 与流式怎么选？ | "盯着屏幕就流式，回头再来就用队列"；三形态可并存（09 篇） |
| 16 | SSE 重连如何保证事件不丢？ | Last-Event-ID/游标回放 + 事件持久化（Redis Streams）（09 篇） |
| 17 | 模型网关做什么？ | 统一协议、路由、fallback、per-key 预算、成本归因（09 篇） |
| 18 | Prompt 为什么要版本化注册表？ | 变更可比、可回滚（label 指针）、可审计；prompt 与代码解耦（10 篇） |
| 19 | 回滚的缓存陷阱是什么？ | 回滚不清缓存 → 旧版指纹的缓存幽灵服务新版本；回滚=指针+清缓存（10 篇） |
| 20 | 质量漂移告警与延迟告警什么区别？ | 延迟抓基础设施，eval 分数漂移抓行为退化（模型无声升级）；缺一不可（11 篇） |

## 2. 面试题：工程实践档

> 考察点：做过没。回答要求"我遇到过 → 怎么定位 → 怎么修 → 怎么防"。

| # | 题目 | 答题要点 |
|:---:|------|---------|
| 1 | 你的 Agent 卡死循环（同一工具调用 40 次）怎么排查和修复？ | trace 看循环长度与错误标记 → `retry: false` 结构化错误 → 收紧 max_tool_calls → 错误回传让模型自救（04/05 篇） |
| 2 | 模型升级后回答风格突变，怎么发现和归因？ | 版本快照（prompt+model+code）入 trace → eval 分数漂移告警 → 金丝雀 + 回滚（10/11 篇） |
| 3 | 怎么在 CI 里评估 Agent 而不烧钱？ | Mock LLM 三层（回放/契约/fake）+ 三层级联门禁（确定性→NLI→judge 只判模糊样本）（05/06 篇） |
| 4 | 长任务用户关网页了怎么办？ | 执行与连接解耦：队列 + 事件持久化，重连靠游标回放；任务状态终态兜底（09 篇） |
| 5 | 退款这类写操作怎么防止重复执行？ | 幂等键 + 审批门 + 审计；工具契约幂等/无状态（02/08 篇） |
| 6 | 供应商 429 限流怎么处理？ | Provider 层退避重试 → 网关 fallback 备用供应商 → 限流保护下游 → 高影响排队人工（09/11 篇） |
| 7 | 怎么给 Agent 做成本归因？ | trace 每轮 token+单价 → 按用户/租户/Agent/模型聚合 → 预算三层 + 周报复盘（04/11 篇） |
| 8 | 怎么把生产失败案例变成评估用例？ | 在线采样 eval → 失败样本脱敏入 golden set → 版本化 → 进 CI 回归门禁（06 篇） |

## 3. 面试题：架构设计档

> 考察点：设计权衡。面试官会追问"为什么不用另一个方案"。

| # | 题目 | 答题要点 |
|:---:|------|---------|
| 1 | 设计一个生产级客服 Agent 的整体架构 | 分层 + 混合架构 + 三形态 + 网关 + 审批门 + 评估门禁 + 金丝雀（直接引用 12 篇案例） |
| 2 | 10 个 Agent 的多 Agent 系统如何治理？ | 职责单一拆分、交接 payload 可检查、每子 Agent 独立评估、共享基建（trace/预算/身份）（02/11 篇） |
| 3 | 如何设计"改 prompt 不影响代码"的发布体系？ | 注册表 + label + shadow/canary/promote + eval 门禁 + 回滚含缓存失效（10 篇） |
| 4 | 如何在成本和体验之间取舍？ | 缓存第一 → 语义缓存 → 路由 → 预算闭环；每步量化收益与代价（07/11 篇） |
| 5 | 如何让 Agent 具备"人类审批"能力且不拖慢体验？ | 审批门只拦不可逆/高影响；自动放行低风险；审计 approved_by（08 篇） |
| 6 | 如何设计可迁移的评估体系（不怕换工具）？ | judge/rubric 与工具解耦；同一套 judge 在 CI/在线/金丝雀三处复用；数据可导出（06 篇） |
