## 1. 项目需求：多 Agent 研究团队

**"研究助手"**：用户给主题 → Supervisor 派研究员（搜索 + MCP 工具）→ 派写手成文 → 审查 Agent 质检。

| 角色 | 职责 | 工具 | 模型 |
|------|------|------|------|
| Supervisor | 任务分解、路由、协调 | 子 Agent 工具 | pro（强推理） |
| 研究员 | 搜索、信息收集 | 搜索工具 + **MCP 天气/新闻工具** | flash（省钱） |
| 写手 | 报告成文 | 无（只收材料） | pro |
| 审查员 | 质检（引用/完整性） | 校验规则 | 规则 + flash |

**验收场景**：

```text
> 研究"2026 年 MCP 协议的最新变化"并写一篇 500 字报告
> 研究"北京今天天气适合出游吗"（触发 MCP 天气工具）
```

## 2. 架构设计

```text
用户请求
  → Supervisor（create_agent，工具 = 子 Agent）
      ├── research_topic → 研究员 Agent（create_agent）
      │                      └── 工具：web_search + MCP 工具（load_mcp_tools）
      ├── write_report → 写手 Agent（create_agent，无工具）
      └── review_report → 审查 Agent（规则校验，返回 PASS/问题列表）
  → 最终报告（含审查意见）

生产化挂件（阶段 4 全套）：
├─ 熔断：整树预算（监督者 + 3 子 Agent 共享）
├─ 评估：路由准确率 + 报告质量（judge）
├─ 可观测：层级 trace（监督者 span + 子 Agent span）
└─ MCP 安全：白名单源 + 输出降权
```

## 3. 核心代码

```python
"""research_team.py — 多 Agent 研究团队（Supervisor 工具包裹版）"""
import asyncio
from langchain.agents import create_agent
from langchain_core.tools import tool
from langchain_openai import ChatOpenAI
from langgraph.checkpoint.memory import InMemorySaver

MODEL_BASE = {"base_url": "https://api.deepseek.com", "api_key": "sk-..."}

# ─── MCP 接入（05 篇）────────────────────────────────────
async def load_mcp_search_tools():
    from langchain_mcp_adapters.tools import load_mcp_tools
    from mcp import ClientSession, StdioServerParameters
    from mcp.client.stdio import stdio_client
    server = StdioServerParameters(command="python", args=["news_server.py"])
    read, write = await stdio_client(server).__aenter__()
    session = await ClientSession(read, write).__aenter__()
    await session.initialize()
    return await load_mcp_tools(session)

# ─── 子 Agent ─────────────────────────────────────────────
async def build_team():
    mcp_tools = await load_mcp_search_tools()      # 研究员额外带 MCP 工具

    researcher = create_agent(
        model=ChatOpenAI(model="deepseek-v4-flash", **MODEL_BASE),
        tools=[web_search_tool, *mcp_tools],        # 本地 + MCP 混合
        system_prompt="你是研究员：搜索并总结信息，输出带来源的要点。",
        checkpointer=InMemorySaver(),
    )
    writer = create_agent(
        model=ChatOpenAI(model="deepseek-v4-pro", **MODEL_BASE),
        tools=[],
        system_prompt="你是写手：基于研究材料写结构化报告，不超过 500 字。",
    )
    reviewer = create_agent(
        model=ChatOpenAI(model="deepseek-v4-flash", **MODEL_BASE),
        tools=[review_rules_tool],
        system_prompt="你是审查员：检查报告完整性、引用、事实性，输出问题清单或 PASS。",
    )

    # ─── 工具包裹（02 篇官方迁移路径）──────────────────
    @tool
    def research_topic(topic: str) -> str:
        """研究一个主题。当需要最新信息、事实核查时调用研究员。"""
        r = researcher.invoke({"messages": [("user", f"研究：{topic}")]})
        return r["messages"][-1].content

    @tool
    def write_report(material: str) -> str:
        """基于研究材料写报告。当材料齐备需要成文时调用写手。"""
        r = writer.invoke({"messages": [("user", f"材料：\n{material}\n请写报告")]})
        return r["messages"][-1].content

    @tool
    def review_report(report: str) -> str:
        """审查报告质量。报告完成后调用审查员。"""
        r = reviewer.invoke({"messages": [("user", f"审查：\n{report}")]})
        return r["messages"][-1].content

    # ─── Supervisor ─────────────────────────────────────
    supervisor = create_agent(
        model=ChatOpenAI(model="deepseek-v4-pro", temperature=0.2, **MODEL_BASE),
        tools=[research_topic, write_report, review_report],
        system_prompt=(
            "你是研究团队主管。流程：研究 → 写作 → 审查（必要时循环修改）。\n"
            "严格按工具职责分工，不要替子 Agent 做事。"
        ),
        checkpointer=InMemorySaver(),
        recursion_limit=30,
    )
    return supervisor

async def main():
    supervisor = await build_team()
    q = input("研究主题 > ")
    result = supervisor.invoke(
        {"messages": [("user", q)]},
        config={"configurable": {"thread_id": "team-1"}},
    )
    print("\n===== 最终报告 =====\n")
    print(result["messages"][-1].content)

if __name__ == "__main__":
    asyncio.run(main())
```

> ⚠️ 以上为结构示范——完整代码需补：web_search_tool/review_rules_tool 定义、MCP 服务器（news_server.py）、生产化挂件（熔断/评估/遥测）、错误处理（子 Agent 失败回传）。

## 4. 八项验收标准

| # | 验收项 | 判定 |
|:---:|--------|------|
| 1 | Supervisor 分工正确 | "研究→写→审"全流程自动完成 |
| 2 | 子 Agent 即工具 | 监督者通过 3 个工具委托（无手工路由） |
| 3 | MCP 工具可用 | 触发天气/新闻 MCP 工具并返回真实数据 |
| 4 | 上下文不串扰 | 研究员中间过程不出现在最终报告（只传摘要） |
| 5 | 循环可控 | 审查不通过时修改 ≤2 轮即收敛 |
| 6 | 熔断生效 | 整树预算（人为调低后触发） |
| 7 | 可观测 | 层级 trace：监督者 → 子 Agent → 工具全链可见 |
| 8 | MCP 安全基线 | 白名单源 + 工具输出按不可信处理（代码审查） |
