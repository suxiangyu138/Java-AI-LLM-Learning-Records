## 4. 面试答题范式

### 范式一：通用回答结构（PRDS，阶段 4 版）

```text
P - Problem  问题/概念本质
R - Risk     不处理的代价（量化）
D - Defense  分层防御/方案（至少三层）
S - System   落地：监控/评估/治理
```

### 范式二："如何保证 Agent 输出可靠"示范

> **P**：LLM 输出是概率采样——格式、事实、行为都可能偏离预期；且四大失败互相诱发（格式坏→重试风暴→成本爆炸）。
> **R**：解析类失败占生产故障 ~38%（AgentFixer）；死循环可一夜烧 3 倍预算；注入可致数据外泄。
> **D**：四层防御——①格式：strict/约束解码（99.5%+）；②幻觉：检索接地+强制引用+验证层；③循环：三重熔断+recursion_limit；④安全：策略引擎+分级授权+输出白名单。
> **S**：评估五模式进 CI 门禁（回归>1% 阻断）；OTel 追踪+成本标签；在线采样 5-10% + 失败回流；HITL 兜高危。

### 范式三："为什么 Agent 比普通软件难做"示范

> 三个不可回避特性（LangChain Deep Agent）：**非确定性**（9/10 成功 → 批量+统计显著）、**错误传播**（第 3 步错污染下游 → 分层评估）、**创造性解法**（正确但没按你想的走 → 只门禁核心行为）。所以 Agent 工程 = 心智（协议）+ 效率（框架）+ 治理（评估/熔断/可观测）三件套，缺一不可。
