## 1. 本阶段在五阶段路径中的位置

```text
阶段 1：手写极简 Function-call Agent ──── 协议与循环心智
    ↓
阶段 2：原生 OpenAI-style Function-call ── 原生能力（strict/并行/流式/Responses）
    ↓
阶段 3：LangChain Agent ──────────────── 框架效率（create_agent/LangGraph）
    ↓
阶段 4：问题调优与工程化 ──────────────── 生产化（熔断/评估/可观测/HITL）
    ↓

    │     ① 多 Agent 编排：Supervisor / Handoffs / 层级
    │     ② MCP 协议：工具接入标准化 + 安全
```

## 2. 学习目标与验收标准

| 目标 | 说明 |
|------|------|

## 7. 2026 版本窗口

> 本阶段以 2026-08 为基准：
>
> - **多 Agent**：Supervisor 是 2026 企业最常用模式；`langgraph-supervisor` 包已停止维护 → 官方迁移路径：`create_agent` + 工具包裹子 Agent；Paperclip 模式（2026-03）为前沿层级模型；Gartner 预测 2026 年底 40% 企业应用带 Agent
> - **MCP**：2025-12 捐赠 Linux 基金会 Agentic AI Foundation（AAIF）；**2026-07-28 最大协议修订**——无状态请求中心架构、MCP Apps/Tasks、弃用 Sampling/Roots/Logging/HTTP+SSE（12 个月弃用窗口）、OAuth 2.1 强制 iss 校验
> - **MCP 安全**：OX Security 披露 STDIO RCE（≥10 个 CVE），约 20 万服务器实例暴露；Anthropic 拒绝修补（"by design"立场）；注册表无审查（9/11 接受恶意包）
> - **Streamable HTTP 传输**取代 STDIO 成为云端部署标准；互联网 MCP 服务器已超 7000 个公网 IP
> - 本阶段代码：LangGraph 1.0 + Python MCP SDK（新旧协议过渡期双支持）
