## 1. 知识库类型与选择

### 1.1 三种知识库对比

| 类型 | 数据格式 | 检索方式 | 适用场景 | 更新频率 |
|------|---------|---------|---------|:---:|
| **文档知识库** | PDF/Word/TXT/Markdown/网页 | 语义搜索（向量匹配） | 产品手册、技术文档 | 按需上传 |
| **问答对** | Q&A 成对数据 | 精确/模糊匹配 | FAQ、客服脚本 | 手动维护 |
| **表格数据** | Excel/CSV | 结构化查询 | 价格表、SKU 信息 | 覆盖上传 |

### 1.2 选择决策

```text
你的知识长什么样？
├── 长文档（手册/指南/规范） → 文档知识库
├── 标准的问答列表 → FAQ 问答对
├── 结构化表格数据（规格/价目表） → 表格知识库
└── 都有 → 混合使用（一个 Bot 可关联多个知识库）
```

## 2. 文档知识库

### 2.1 创建与管理

```text
知识库 → 创建知识库 → 文档类型

步骤：
1. 命名知识库：如 "产品帮助文档 v2.1"
2. 上传文档：
   ├── 支持格式：PDF、DOCX、TXT、MD、HTML、CSV
   ├── 单文件 ≤ 20MB
   ├── 批量上传
   └── 在线网页导入（输入 URL 自动抓取）

3. 处理设置：
   ├── 分段策略：智能分段（推荐）/ 自定义
   ├── 分块大小：500-1500 字符（默认 800）
   └── 分段重叠：10-25%

4. 开始处理：
   └── Coze 自动分段 → Embedding → 存入向量库 → 立即可查
```

### 2.2 支持的数据源

| 来源 | 说明 | 适合场景 |
|------|------|---------|
| **本地上传** | PDF/Word/TXT/MD/HTML/CSV | 企业文档、技术手册 |
| **在线网页** | 输入 URL 爬取内容 | 在线帮助中心、Wiki |
| **飞书文档** | 授权后同步飞书文档 | 飞书企业知识库 |
| **Notion** | 授权后同步 Notion 页面 | 团队知识管理 |
| **API 导入** | 通过 API 批量导入 | 系统间自动化同步 |

### 2.3 分段与清洗

```text
Coze 自动处理流程：

文档上传
  │
  ▼
格式解析 → 提取纯文本
  │
  ▼
分段策略：
├── 智能分段：识别标题、段落、列表等结构边界
│   → 优先在自然段落边界切分
│   → 保留文档层级结构信息
└── 固定长度：按字符数+重叠窗口
    → 简单粗暴，但可能切断语义
  │
  ▼
文本清洗：
├── 移除页眉页脚
├── 移除重复空白
├── 保留表格结构（转 Markdown 表格）
└── OCR 识别（PDF 中的图片文字）
  │
  ▼
向量化 (Embedding) → 豆包 Embedding 模型
  │
  ▼
写入向量数据库 → 立即可检索
```

### 2.4 文档管理维护

```text
知识库 → 文档列表 → 操作：

├── 📄 查看详情：分段数量、字符数、处理状态
├── 🔄 重新处理：修改分段策略后重新向量化
├── ✏️ 在线编辑：直接修改文档内容
├── 👁️ 启用/禁用：暂不使用的文档可禁用
├── 🗑️ 删除：从知识库中移除
├── 📊 统计：各文档被检索次数
└── 🔗 关联：查看此文档被哪些 Bot 使用
```

## 3. 问答对（FAQ）知识库

### 3.1 为什么需要 FAQ 知识库

```text
文档知识库的问题：
  用户问："退款需要多久？"
  文档片段："退款流程：登录→我的订单→申请退款→填写原因→提交→3-5个工作日..."
  → 检索到了，但不够精准

FAQ 知识库的优势：
  Q："退款需要多久？"
  A："审核通过后 3-5 个工作日退款到原支付账户"
  → 精确匹配，答案直接、精准
```

### 3.2 创建 FAQ

```text
知识库 → 创建知识库 → 问答对类型

添加方式：

1. 逐条手动添加
   Q：如何修改收货地址？
   A：未发货的订单可在"我的订单"中直接修改；已发货的订单请联系客服...

2. 批量导入
   格式：Excel/CSV
   列：问题 | 答案 | 分类 | 标签
   └── 适合从旧系统迁移

3. AI 自动生成
   从文档知识库自动提取 QA 对
   └── Coze AI 阅读文档 → 生成潜在问答 → 人工审核
```

### 3.3 FAQ 最佳实践

```text
FAQ 编写原则：

✅ 一条 FAQ 只回答一个具体问题
❌ 一个 QA 里塞 5 个问题的答案

✅ 问题用用户的口吻（他们怎么问就怎么写）
❌ 问题用专业术语（用户不一定知道术语）

✅ 答案简洁直接（100-300 字最佳）
❌ 长篇大论（用户只想知道答案）

✅ 问题变体都要覆盖：
   - "怎么退款" / "退款流程" / "如何申请退款" / "退钱怎么操作"
   → 同一个答案，多个问法 → 全部收录
```

## 4. 表格数据知识库

### 4.1 适用场景

```text
表格知识库适合结构化数据查询：

├── 产品价格表：型号→价格→库存→规格
├── 员工信息表：姓名→部门→职位→邮箱
├── API 接口表：接口→方法→参数→返回值
├── 城市信息表：城市→省份→邮编→区号
└── SKU 对照表：SKU→名称→品牌→规格→条码
```

### 4.2 上传与配置

```text
1. 准备 Excel/CSV 文件
   第一行 = 列名（Coze 用列名做字段匹配）
   第二行起 = 数据

2. 上传到知识库
   表格类型 → 上传文件

3. Coze 自动处理：
   ├── 识别列名和数据类型
   ├── 建立结构化索引
   └── 生成自然语言查询接口

4. 配置查询提示词：
   "当用户询问产品价格时，查询表格中的price列，返回产品名称和价格"
```

### 4.3 表格查询 vs 文档检索

```text
场景：用户问 "iPhone 15 Pro 256G 多少钱？"

文档知识库：
  在文档中搜索 "iPhone 15 Pro 256G 价格"
  → 可能返回长篇产品介绍，用户需要从段落中找价格

表格知识库：
  解析查询 → 找到 SKU 对应行 → 直接返回 price 列的值
  → "iPhone 15 Pro 256G 当前价格：¥8,999"
```

## 5. 搜索策略与调优

### 5.1 搜索配置

```text
Bot → 技能 → 知识库 → 搜索设置

关键参数：
├── 搜索方式：
│   ├── 语义搜索 (向量匹配) — 适合概念性问题
│   ├── 关键词搜索 — 适合精确查询
│   └── 混合搜索 — 兼得两者优势（推荐）
│
├── Top-K：返回最相关的 K 个片段 (推荐 3-5)
│   └── 太大会引入噪声，太小信息不足
│
├── 相似度阈值：0.5-0.75
│   └── 低于此分数的结果被丢弃
│
├── 搜索范围：
│   ├── 全部知识库
│   └── 指定知识库（多个知识库时）
│
└── 优先级：
    ├── FAQ 优先 → 精确匹配优先返回
    └── 文档补充 → FAQ 没命中时搜索文档
```

### 5.2 搜索效果调优

```text
搜索效果不理想的诊断流程：

用户问 → Bot 答非所问？

1. 查看 Bot 回复底部的"引用来源"
   ├── 没有引用 → 知识库没命中
   │   ├── 文档中真的没有相关内容 → 补充文档
   │   └── 相关内容没被检索到 → 调优参数
   │
   ├── 有引用但不对 → 检索到了错误内容
   │   ├── 相似度阈值太低 → 提高阈值
   │   ├── 关键词污染（搜索了无关词）→ 偏重语义搜索
   │   └── 文档分段太粗 → 细化分段
   │
   └── 有引用且正确但回答不好 → 不是搜索问题
       └── 优化 Bot 的人设和 Prompt

3. 使用 Coze 搜索测试工具：
   知识库 → 搜索测试 → 输入问题
   → 查看搜索命中了哪些片段，分数如何
   → 快速验证搜索效果
```

### 5.3 搜索提示词增强

```text
在人设中引导 Bot 正确使用知识库：

你的回答必须遵守以下规则：
1. 优先从知识库中寻找答案
2. 如果知识库中有明确答案，直接引用，不要自由发挥
3. 如果知识库中有部分相关信息但不完整，先给出已知信息，再说明"如需更详细信息，请联系人工客服"
4. 如果知识库中完全没有相关信息，回复"抱歉，我目前的知识库中暂未收录此信息。建议您联系人工客服获取帮助。"
5. 引用知识库内容时，告知用户信息来源（如"根据产品手册第3章..."）
```
