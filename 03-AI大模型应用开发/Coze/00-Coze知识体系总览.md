## 4. 核心概念速查

| 概念 | 一句话解释 | 详见 |
|------|-----------|------|
| **Bot（智能体）** | Coze 的核心单元，= 人设 + 技能 + 知识库 + 模型 | 模块02 |
| **人设 (Persona)** | Bot 的角色设定，System Prompt 的可视化编写 | 模块02 |
| **技能 (Skill)** | Bot 的能力：插件 + 工作流 + 知识库 | 模块02/05 |
| **插件 (Plugin)** | 可复用的工具单元，官方市场 + 自定义 | 模块05 |
| **工作流 (Workflow)** | 可视化编排的多步骤任务流程 | 模块04 |
| **知识库 (Knowledge)** | Bot 的知识来源：文档 + FAQ + 表格 | 模块03 |
| **发布渠道 (Channel)** | Bot 部署目的地：豆包/飞书/微信/Web/API | 模块06 |
| **多 Agent 模式** | 多个 Bot 协作完成任务（协作/辩论） | 模块07 |
| **Coze 国内版 vs 国际版** | 国内版 = 字节模型免费 + 国内渠道；国际版 = GPT/Claude + 海外渠道 | 模块01 |
