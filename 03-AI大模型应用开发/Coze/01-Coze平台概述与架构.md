## 1. Coze 是什么

### 1.1 一句话定位

```text
Coze (扣子) = 字节跳动出品的一站式 AI Bot 开发平台

核心能力：
├── 🧠 智能体编排：人设 + 模型 + 技能 = 智能 Bot
├── 🔀 可视化工作流：拖拽节点编排复杂 AI 任务
├── 🧩 丰富插件生态：官方 + 社区 1000+ 插件
├── 📚 知识库管理：文档/FAQ/表格，开箱即用 RAG
├── 📤 一键多渠道发布：豆包/飞书/微信/掘金/Web/API
└── 🆓 免费额度：国内版使用豆包模型完全免费
```

### 1.2 发展里程碑

| 时间 | 里程碑 |
|------|--------|
| 2023.12 | Coze 国际版发布 (coze.com)，基于 GPT-4/Claude |
| 2024.02 | Coze 国内版发布 (coze.cn)，基于豆包大模型 |
| 2024.06 | 工作流功能上线、插件市场开放 |
| 2024.09 | 多 Agent 模式上线、知识库增强 |
| 2025.01 | Bot 发布飞书/微信客服渠道 |
| 2026.06 | 超过 200 万开发者，1000+ 官方插件 |

## 2. 国内版 vs 国际版

### 2.1 核心差异

| 维度 | **Coze 国内版 (coze.cn)** | **Coze 国际版 (coze.com)** |
|------|:---:|:---:|
| **默认模型** | 豆包大模型（免费） | GPT-4o / Claude（付费） |
| **可用模型** | 豆包系列（含 Doubao-1.5-pro） | GPT-4o/Claude/Gemini/DeepSeek 等 |
| **收费模式** | 基础免费，高级付费 | Token 消耗制 |
| **发布渠道** | 豆包/飞书/微信客服/掘金 | Discord/Telegram/Slack/Messenger |
| **插件市场** | 国内生态（飞书/淘宝/抖音/高德...） | 国际生态（Google/Notion/GitHub...） |
| **语言** | 中文为主 | 多语言 |
| **合规** | 中国数据合规 | 国际数据合规 |
| **注册方式** | 手机号 / 抖音账号 | Google / GitHub 账号 |

### 2.2 选版指南

```text
选国内版 (coze.cn)：
✅ 国内团队、中文场景
✅ 要发布到飞书/微信/豆包
✅ 使用国内服务（高德/淘宝/抖音等插件）
✅ 免费额度优先

选国际版 (coze.com)：
✅ 海外业务、英文场景
✅ 需要 GPT-4o/Claude 模型
✅ 发布到 Discord/Telegram/Slack
✅ 使用国际服务（Google/Notion/GitHub 插件）
```

## 4. Coze vs Dify vs GPTs 全面对比

### 4.1 核心对比表

| 维度 | Coze | Dify | GPTs (OpenAI) |
|------|:---:|:---:|:---:|
| **出品方** | 字节跳动 | 开源社区 (LangGenius) | OpenAI |
| **开源** | ❌ 闭源 | ✅ Apache 2.0 | ❌ 闭源 |
| **私有化部署** | ❌ (仅 SaaS) | ✅ | ❌ |
| **免费模型** | ✅ 豆包全系免费 | ❌ 需自己提供 API Key | ❌ 需 ChatGPT Plus |
| **插件数量** | ✅ 1000+ (含国内生态) | ⚠️ 较少（社区驱动） | ✅ 丰富（国际） |
| **知识库** | ✅ 文档+FAQ+表格 | ✅ 全功能 RAG | ⚠️ 文件上传 |
| **工作流** | ✅ 可视化编排 | ✅ 高级编排 | ❌ 基础 Actions |
| **多 Agent** | ✅ 协作/辩论模式 | ⚠️ 需通过工作流实现 | ❌ |
| **国内发布** | ✅ 飞书/微信/豆包/掘金 | ❌ 需自建 | ❌ |
| **API 集成** | ✅ Bot API | ✅ Service API | ✅ Assistants API |
| **RAG 能力** | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ |
| **学习曲线** | ⭐ 极低 | ⭐⭐⭐ 中等 | ⭐⭐ |
| **Java 后端集成** | REST API | REST API | OpenAI SDK |
| **使用成本** | 🆓 免费额度大 | 💰 模型+部署成本 | 💰💰 按 Token |
| **最适合** | 国内业务快速落地 | 私有化/高度定制 | 海外/个人 |

### 4.2 选型决策树

```text
需要私有化部署？
├── 是 → Dify（开源，Docker 自行部署）
└── 否 →
    主要面向国内用户？
    ├── 是 → Coze 国内版（免费模型 + 国内渠道）
    └── 否 →
        追求极致 RAG 质量？
        ├── 是 → Dify（分段/检索/Rerank 更灵活）
        └── 否 → Coze 国际版 或 GPTs
```

## 5. 适用场景与选型建议

### 5.1 Coze 最佳场景

```text
✅ 最适合 Coze 的场景：

├── 企业微信/飞书 AI 客服 Bot
│   └── 结合飞书文档知识库 + 自动回复

├── 豆包平台 AI 应用
│   └── 免费流量入口，字节生态曝光

├── 快速原型验证
│   └── 30 分钟搭建一个可用的 AI Bot

├── 内容创作助手
│   └── 结合抖音/头条数据插件

├── 电商 AI 导购
│   └── 结合商品知识库 + 淘宝/京东插件

├── 内部效率工具
│   └── 结合飞书审批/日历/文档插件

└── 低代码 AI 应用教学
    └── 上手极快，适合培训
```

### 5.2 Coze 的局限

```text
⚠️ Coze 不适合的场景：

├── 需要私有化部署 → 选 Dify
├── 需要极致 RAG 质量调优 → 选 Dify（自定义分段/Embedding/Rerank）
├── 大量外部 API 编排 → 选 Dify（HTTP 节点更灵活 + 代码沙箱）
├── 需要嵌入现有 Java 后端深度定制 → Dify API 更成熟
├── 海外合规（GDPR 等）→ Coze 国际版 或 Dify
└── 离线/内网环境 → Dify + Ollama 本地部署
```

> 🎯 **核心总结**：Coze = 国内 AI 应用落地的最快路径；Dify = 深度定制 + 私有化部署的首选。两者互补，不是一个非此即彼的选择。
