## 1. 逻辑命题与布尔代数

### 1.1 命题逻辑

```text
命题：可以判断真假的陈述句

  基本运算：
    ∧（与/AND）：同真才真
    ∨（或/OR）：有一真即真
    ¬（非/NOT）：取反
    →（蕴含）：除非前真后假，否则为真
    ↔（等值）：同真同假

真值表：
  P  Q  | P∧Q | P∨Q | P→Q | P↔Q
  ──────┼─────┼─────┼─────┼─────
  T  T  |  T  |  T  |  T  |  T
  T  F  |  F  |  T  |  F  |  F
  F  T  |  F  |  T  |  T  |  F
  F  F  |  F  |  F  |  T  |  T
```

### 1.2 在编程和 AI 中的应用

| 概念 | 编程应用 | AI 应用 |
|------|----------|--------|
| 布尔代数 | `if-else`、`&&`、`\|\|` | 决策树分叉条件 |
| 命题逻辑 | 数据库 WHERE 条件、断言 | Rule-based 推理系统 |
| 逻辑等价变换 | 代码简化、条件合并 | Prompt 逻辑结构化 |
| 德摩根律 | `!(a&&b)≡!a\|\|!b` | 条件取反优化 |

### 1.3 逻辑与 LLM

```text
LLM 本身不显式使用命题逻辑，但：
  ✅ Chain-of-Thought 推理本质是命题逻辑链
  ✅ Prompt "Let's think step by step" 诱导逻辑推理
  ✅ ReAct Agent 的决策 = 条件判断树
  ✅ 符号逻辑是 LLM 推理能力的"基准测试"之一
```

## 2. 集合论基础

### 2.1 核心运算

```text
并集 A∪B：  在 A 或在 B 中的元素
交集 A∩B：  同时在 A 和 B 中的元素
差集 A-B：   在 A 但不在 B 中的元素
补集 Aᶜ：    不在 A 中的元素
子集 A⊆B：   A 的所有元素都在 B 中
幂集 P(A)：  A 的所有子集的集合
```

### 2.2 编程中的集合

```java
// Java 集合框架就是集合论的直接实现
Set<String> A = new HashSet<>(Set.of("a", "b", "c"));
Set<String> B = new HashSet<>(Set.of("b", "c", "d"));

// 并集
Set<String> union = new HashSet<>(A);
union.addAll(B);                    // {a, b, c, d}

// 交集
Set<String> inter = new HashSet<>(A);
inter.retainAll(B);                 // {b, c}

// 差集
Set<String> diff = new HashSet<>(A);
diff.removeAll(B);                  // {a}
```

## 3. 图论：图、路径与邻接矩阵

### 3.1 基本定义

```text
图 G = (V, E)
  V：顶点/节点集合（Vertex）
  E：边集合（Edge）

有向图：边有方向 A→B
无向图：边无方向 A─B
权重图：边有数值权重

基本概念：
  → 度 Degree：与节点相连的边数
  → 路径 Path：连续的边序列
  → 连通图：任意两节点间存在路径
  → 环 Cycle：首尾相连的路径
```

### 3.2 图的表示

```text
邻接矩阵 A：
  A[i][j] = 1（有边 i→j）或 0（无边）

  无向图的邻接矩阵是对称的：A[i][j] = A[j][i]

  图的矩阵表示 → 可用线性代数分析图！

邻接表（更省空间）：
  A: [B, C]
  B: [A, D]
  C: [A, D]
  D: [B, C]
```

### 3.3 最短路径算法

| 算法 | 适用 | 复杂度 | 应用 |
|------|------|:---:|------|
| **Dijkstra** | 非负权重，单源 | O(V²) | 导航、网络路由 |
| **Bellman-Ford** | 可有负权，单源 | O(VE) | 套汇检测 |
| **Floyd-Warshall** | 全源最短路径 | O(V³) | 小图全对计算 |
| **A*** | 启发式搜索 | O(V) | 游戏 AI 寻路 |

## 4. 图在 AI 中的应用：GNN 入门

### 4.1 什么是 GNN

```text
GNN（图神经网络）= 在图结构数据上做深度学习

传统神经网络：处理网格结构（图像）或序列结构（文本）
GNN：处理任意图结构（社交网络、分子结构、知识图谱）

核心思想：每个节点聚合邻居节点的信息来更新自己的表示

消息传递框架：
  h_v^(l+1) = UPDATE(h_v^(l), AGGREGATE{h_u^(l) : u∈Neighbors(v)})

  ① 聚合邻居信息
  ② 和自己的信息融合
  ③ 逐层传递（l 层 = 看 l 步邻居）
```

### 4.2 GNN 应用场景

| 场景 | 图结构 | 任务 |
|------|--------|------|
| **社交网络** | 用户=节点，关注=边 | 好友推荐、社区发现 |
| **分子预测** | 原子=节点，化学键=边 | 药物性质预测 |
| **知识图谱** | 实体=节点，关系=边 | 链接预测、问答推理 |
| **推荐系统** | 用户+物品=节点，交互=边 | 协同过滤增强 |
| **代码理解** | AST 语法树 | Bug 检测、代码摘要 |

### 4.3 LLM 时代 GNN 的地位

```text
GNN 不再是独立的主流路线，但图的思想仍然重要：

  ✅ 知识图谱 + LLM → GraphRAG（图增强检索）
  ✅ 代码 AST 解析 → 静态分析
  ✅ 社交推荐 → 特征工程

对于 Java 后端 + LLM 开发者：
  → 知道 GNN 是干什么的即可
  → 不要求手动实现 GNN
  → 重点关注 GraphRAG 等应用层
```

## 5. 组合数学与排列组合

### 5.1 基本公式

```text
排列 P(n, k) = n! / (n-k)!     ← 顺序有关
组合 C(n, k) = n! / (k!(n-k)!) ← 顺序无关

例子：从 5 人中选 3 人
  → 排列 P(5,3) = 5×4×3 = 60（谁当队长、副队长、秘书）
  → 组合 C(5,3) = 10（选 3 个人，不管角色）
```

### 5.2 在 AI 中的应用

| 概念 | AI 应用 |
|------|--------|
| **排列** | Beam Search 搜索路径、序列生成 |
| **组合** | 特征选择：从 N 个特征中选 K 个 |
| **二项式系数** | 神经网络剪枝：计算剪枝方案数 |
| **Catalan 数** | 解析树数量（句法分析） |

### 5.3 LLM 中的组合爆炸

```text
Token 采样空间：词表大小 32000~128000
序列长度：100 tokens
所有可能的序列数 = 32000¹⁰⁰ → 宇宙级

→ Beam Search 只探索最优的 B 条路径
→ Top-K/Top-P 采样缩小搜索空间
→ 组合数学告诉我们：枚举所有路径是不可能的
```

## 6. 计数在算法分析中的应用

### 6.1 时间复杂度中的对数

```text
对数 log₂(n) 在算法分析中的直觉：

  log₂(1000) ≈ 10    → 1000 个元素，二分查找只需约 10 步
  log₂(1,000,000) ≈ 20 → 100万个元素，只需约 20 步！

  对数的增长极其缓慢 → O(log n) 算法极其高效

LLM 中的对数：
  → log 出现在交叉熵中（log likelihood）
  → log PPL = 交叉熵均值（对数困惑度）
```

### 6.2 大 O 表示法速查

| 复杂度 | 名称 | n=1000 时 | 例子 |
|:---:|------|:---:|------|
| O(1) | 常数 | 1 | Embedding 查表 |
| O(log n) | 对数 | 10 | 二分查找、Token 索引 |
| O(n) | 线性 | 1000 | 单层遍历 |
| O(n log n) | 线性对数 | 10,000 | 排序、Beam Search |
| O(n²) | 平方 | 1,000,000 | **Attention（seq_len 平方）** |
| O(2ⁿ) | 指数 | ≈10³⁰¹ | 穷举搜索（不可行） |

## 核心要点回顾

- 离散数学对 Java 后端 + LLM 开发者属于"简单了解，用到再深挖"
- 图论的核心概念（节点、边、邻接矩阵）是理解 GNN 的基础
- GNN 不再是 AI 主流路线，但图的思想在 GraphRAG 等场景中延续
- 组合数学揭示为什么 LLM 不能枚举所有可能的输出
