## 1. 基础概率与贝叶斯

### 1.1 概率基础

```text
样本空间 Ω：所有可能结果的集合
事件 A：Ω 的子集
概率 P(A)：事件 A 发生的可能性, 0 ≤ P(A) ≤ 1

联合概率：P(A, B) = A 和 B 同时发生的概率
条件概率：P(A | B) = 在 B 已发生的前提下，A 发生的概率
          P(A | B) = P(A, B) / P(B)

独立性：P(A, B) = P(A) × P(B)  → A 和 B 互不影响
```

### 1.2 贝叶斯定理

```text
贝叶斯公式（概率论最重要的公式之一）：

            P(B | A) × P(A)
  P(A | B) = ───────────────
                 P(B)

  后验概率 = (似然 × 先验) / 证据

直觉：
  → P(A)：先验 — 看到新证据之前，对 A 的信念
  → P(B|A)：似然 — 如果 A 为真，观察到证据 B 的可能性
  → P(A|B)：后验 — 看到证据 B 后，更新后的信念
  
类比：医生诊断
  先验 P(得感冒) = 人群中感冒的比例
  似然 P(发烧|得感冒) = 感冒的人发烧的概率
  后验 P(得感冒|发烧) = 发烧了，到底有多大可能是感冒？
```

### 1.3 贝叶斯在 AI 中的应用

| 应用 | 说明 |
|------|------|
| **朴素贝叶斯分类器** | 垃圾邮件过滤、文本分类 |
| **贝叶斯神经网络** | 权重不是定值，而是概率分布 → 自带不确定性估计 |
| **LLM 推理** | P(答案|问题) 本质就是后验概率 |
| **贝叶斯优化** | 超参数调优（如 learning rate, batch size） |

## 2. 随机变量与概率分布

### 2.1 离散分布

| 分布 | 公式 | 场景 | LLM 中的应用 |
|------|------|------|------------|
| **伯努利** | $P(X=1)=p, P(X=0)=1-p$ | 二选一结果 | Token 是否被采样 |
| **二项** | $P(X=k)=C_n^k p^k(1-p)^{n-k}$ | n 次伯努利中成功 k 次 | Top-k 采样 |
| **泊松** | $P(X=k)=\frac{\lambda^k e^{-\lambda}}{k!}$ | 单位时间事件发生次数 | 请求到达速率 |
| **类别分布** | $P(X=i)=p_i, \sum p_i=1$ | 从 N 个类别中选一个 | **Token 采样（核心！）** |

### 2.2 连续分布

| 分布 | 公式 | 场景 | LLM 中的应用 |
|------|------|------|------------|
| **均匀分布** | $f(x)=\frac{1}{b-a}$ | 完全随机 | 随机初始化权重 |
| **高斯（正态）分布** | $f(x)=\frac{1}{\sigma\sqrt{2\pi}}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ | **最核心的分布** | 权重初始化、LayerNorm、噪声建模 |
| **指数分布** | $f(x)=\lambda e^{-\lambda x}$ | 等待时间 | 请求超时建模 |

### 2.3 为什么高斯分布如此重要

```text
中心极限定理：
  大量独立同分布随机变量的均值，趋近于正态分布
  → 自然界中几乎所有"聚合"现象都呈正态分布

LLM 中的正态分布：
  ① 权重初始化：Xavier/Glorot 用 N(0, 2/(n_in + n_out))
     或 He 初始化用 N(0, 2/n_in)

  ② LayerNorm 后：输出近似 N(0, 1)
     → 后续层接收稳定的数值范围 → 深层网络可训练

  ③ 扩散模型：每一步加高斯噪声 → 逐步破坏结构 → 反向去噪

  ④ 贝叶斯推断：假设先验为正态分布 → 数学上易处理
```

### 2.4 多变量高斯分布

```text
多变量高斯 N(μ, Σ)：
  μ: 均值向量
  Σ: 协方差矩阵

概率密度：
  f(x) = (2π)^{-d/2} |Σ|^{-1/2} exp(-½(x-μ)^T Σ^{-1}(x-μ))

在 Embedding 空间：
  词向量服从某种多变量分布
  → 相似的词在空间中聚集
  → 协方差矩阵 Σ 描述了词义的方向性"拉伸"
```

## 3. 期望、方差、协方差

### 3.1 期望

```text
期望 E[X] = Σ x_i P(x_i)  （离散）
期望 E[X] = ∫ x f(x) dx    （连续）

含义：随机变量的"平均值"或"中心位置"

LLM 应用：
  → 生成文本的长度期望
  → Token 概率加权的"平均 Embedding"
```

### 3.2 方差与标准差

```text
方差 Var(X) = E[(X - E[X])²] = E[X²] - (E[X])²
标准差 σ = √Var(X)

含义：数据离均值的"离散程度"

LLM 应用：
  → Xavier 初始化：保持每层输出的方差稳定
  → BatchNorm/LayerNorm：将方差归一化到 1
  → 温度采样：T 控制 logits 的"有效方差"
     T 大 → 方差大 → 输出多样
     T 小 → 方差小 → 输出确定
```

### 3.3 协方差与协方差矩阵

```text
协方差 Cov(X, Y) = E[(X-E[X])(Y-E[Y])]

  Cov > 0 → X 和 Y 正相关（X 大则 Y 也大）
  Cov < 0 → X 和 Y 负相关
  Cov = 0 → 线性无关（但不一定独立！）

协方差矩阵 Σ（多变量）：
  Σ[i][j] = Cov(X_i, X_j)
  对角元素 = 各变量方差
  非对角元素 = 两两协方差

LLM 应用：
  → PCA：对协方差矩阵做特征分解 → 找"最大方差方向"
  → 权重矩阵的协方差分析 → 发现冗余 → 指导剪枝
  → Attention 的 QK^T 矩阵 ≈ 某种相似度协方差矩阵
```

## 4. 极大似然估计 MLE 与最大后验 MAP

### 4.1 MLE 极大似然估计

```text
核心问题：给定观测数据，什么参数最可能产生这些数据？

MLE：选择使观测数据出现概率最大的参数

  θ̂_MLE = argmax P(Data | θ)
              θ

例子：抛硬币
  抛 10 次，7 次正面，3 次反面
  问：硬币正面概率 p 是多少？

  P(7正|p) = C(10,7) × p^7 × (1-p)^3
  求导 → p̂ = 7/10 = 0.7

MLE 与 LLM 训练：
  LLM 的 Next-Token-Prediction 本质就是 MLE
  对每个训练样本，最大化 P(正确token | 上文)
  等价于 最小化 -log P（即交叉熵损失）
```

### 4.2 MAP 最大后验估计

```text
MAP：在 MLE 的基础上，加入先验知识 P(θ)

  θ̂_MAP = argmax P(θ | Data) = argmax P(Data | θ) × P(θ)
              θ                       θ

MLE vs MAP：
  MLE: 只看数据，不管先验 → 数据少时容易过拟合
  MAP: 结合先验，数据少时靠先验"兜底"

例子：抛硬币，但先知道"大部分硬币是公平的"
  MLE: 10 次 7 正 → p̂ = 0.7（可能被少数试验误导）
  MAP: 先验 Beta(10,10) + 数据 → p̂ ≈ 0.57（更接近 0.5）

LLM 中的应用：
  → 权重衰减（L2 正则化）= 高斯先验的 MAP
  → 贝叶斯微调：用预训练权重作为先验
```

### 4.3 MLE 的局限性

| 问题 | 说明 | LLM 中的体现 |
|------|------|------------|
| **过拟合** | 数据少时完美拟合训练集 | 微调小数据集时 Loss→0 但泛化差 |
| **点估计** | 只给一个值，无不确定性 | 模型不知何时该说"我不确定" |
| **偏见** | 数据有偏 → MLE 有偏 | 训练数据偏见被模型放大 |

## 5. 采样方法

### 5.1 为什么需要采样

```text
LLM 生成 Token 时，不是简单地选概率最大的，而是在概率分布上采样

原因：
  ✅ 避免重复枯燥的文本（始终选最高概率 → 循环重复）
  ✅ 增加输出多样性
  ✅ 模拟创造性

LLM 中常用的文本生成解码策略：
  → Greedy（贪心）：总是选概率最高的 Token → 确定但无趣
  → Temperature 采样：调整分布的"锐度"
  → Top-K 采样：只从前 K 个最高概率的 Token 中采样
  → Top-P 采样（Nucleus）：从前 p 概率质量的 Token 中采样（推荐）
```

### 5.2 蒙特卡洛采样

```text
蒙特卡洛方法：用随机采样来近似计算

核心公式：
  E[f(x)] ≈ (1/n) Σ f(x_i)  其中 x_i ~ P(x)

应用：
  ✅ 强化学习中的策略梯度估计
  ✅ 贝叶斯推断中的 MCMC
  ✅ LLM 评估：多次采样 → 统计指标
  ✅ Dropout：每次前向传播随机采样一个子网络
```

### 5.3 重要性采样

```text
问题：想从 P 采样，但 P 很难采样 → 从简单的 Q 采样，然后调整权重

  E_P[f(x)] ≈ (1/n) Σ (P(x_i)/Q(x_i)) × f(x_i)  x_i ~ Q

权重 w_i = P(x_i)/Q(x_i) → 用 Q 采样，用 w 修正

LLM 中的应用：
  → RLHF 中的 PPO：用旧策略采样，但按新策略重新加权
  → 重要性采样纠正训练数据分布偏差
```

## 6. 假设检验与置信区间

### 6.1 为什么需要

```text
AI 实验中的核心问题：
  "模型 A 的准确率 85%，模型 B 的 83%，A 真的更好吗？"
  → 可能只是随机波动 → 需要统计学方法判定
```

### 6.2 假设检验

```text
步骤：
  ① 零假设 H₀：A 和 B 没有真正差异
  ② 备择假设 H₁：A 显著优于 B
  ③ 选显著性水平 α = 0.05（接受 5% 的假阳性率）
  ④ 计算 p-value
  ⑤ p < 0.05 → 拒绝 H₀ → A 显著优于 B ✅
     p ≥ 0.05 → 无法拒绝 H₀ → 差异不显著

LLM 应用：
  → A/B 测试 Prompt 效果
  → 比较不同微调策略
  → 评估模型版本迭代
```

### 6.3 置信区间

```text
置信区间：参数真值有 95% 概率落在的区间

  "准确率 85% ± 2%" → 置信区间 [83%, 87%]

LLM 应用：
  → 报告模型指标时写 "85.3% (95%CI: 83.1%-87.5%)"
  → 而不是只写一个点估计
```

## 7. LLM 中的概率论应用

### 7.1 Token 生成 = 从类别分布采样

```python
import numpy as np

logits = np.array([3.2, 1.5, -0.5, 2.8, 0.1])  # 5 个候选 token

# ① Greedy（贪心）
greedy = np.argmax(logits)  # → 0

# ② Softmax → 概率
probs = np.exp(logits) / np.exp(logits).sum()
# [0.533, 0.097, 0.013, 0.357, 0.024]

# ③ Temperature 采样
T = 0.7
probs_t = np.exp(logits / T) / np.exp(logits / T).sum()
sampled = np.random.choice(5, p=probs_t)

# ④ Top-K 采样
K = 3
top_k_idx = np.argpartition(logits, -K)[-K:]
# 只从 top 3 中采样

# ⑤ Top-P (Nucleus) 采样
P = 0.9
sorted_idx = np.argsort(probs)[::-1]
cumsum = np.cumsum(probs[sorted_idx])
top_p_idx = sorted_idx[cumsum <= P]
# 只从累计概率 90% 的 token 中采样
```

### 7.2 LLM 训练 = MLE

```text
LLM 的训练目标：最大化训练数据的似然

  给定语料 D = {w₁, w₂, ..., w_N}
  
  模型参数 θ 的 MLE：
    θ̂ = argmax Π P(w_t | w_{<t}; θ)
    
  取对数 → 避免下溢：
    θ̂ = argmax Σ log P(w_t | w_{<t}; θ)
    
  取负数 → 变成最小化问题：
    Loss = -Σ log P(w_t | w_{<t}; θ)  ← 这就是交叉熵！
```

## 核心要点回顾

| 概念 | 直觉 | LLM 应用 |
|------|------|----------|
| 贝叶斯定理 | 先验信念 + 新证据 → 更新信念 | 推理不确定性 |
| 高斯分布 | 自然界最常见的分布 | 权重初始化、LayerNorm |
| 类别分布 | 从 N 个选项中抽一个 | **Token 采样** |
| MLE | 选最可能产生数据的参数 | LLM 训练目标 |
| 蒙特卡洛 | 用采样来近似复杂计算 | RLHF 梯度估计 |
| 假设检验 | 客观判断"A 是否真的比 B 好" | 模型 AB 测试 |
