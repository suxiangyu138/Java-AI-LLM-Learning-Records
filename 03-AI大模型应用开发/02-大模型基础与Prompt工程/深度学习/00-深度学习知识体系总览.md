## 3. 核心概念速查

### 3.1 六大网络家族

| 家族 | 一句话定位 | 核心机制 | 典型应用 |
|------|-----------|---------|---------|
| CNN | 图像特征提取 | 卷积（局部+共享）+ 池化 | 分类/检测/分割 |
| RNN/LSTM | 序列建模 | 隐藏状态 + 门控 | 文本/时序 |
| Transformer | 通用序列（LLM 底座） | Self-Attention（并行） | **大语言模型** |
| GAN | 对抗生成 | 生成器 vs 判别器 | 图像生成（已被扩散取代） |
| 扩散模型 | 逐步去噪生成 | 加噪-去噪 | SD/DALL-E/Sora |
| RL 智能体 | 试错学习 | 奖励信号 + 策略优化 | 游戏/RLHF |

### 3.2 训练三要素速查

| 要素 | 关键点 | LLM 时代标准 |
|------|--------|-------------|
| 架构 | 深度/宽度/连接 | Transformer + 残差 + LayerNorm |
| 损失函数 | 分类 CE / 回归 MSE | 预训练 CE、对齐 RLHF |
| 优化器 | SGD/Adam/AdamW | **AdamW + Cosine 衰减 + Warmup** |

### 3.3 高频概念一句话

| 概念 | 一句话 |
|------|--------|
| 反向传播 | 链式法则从后向前算梯度 |
| 梯度消失 | 连乘 <1 → 深层梯度趋 0 → 残差/归一化解决 |
| 过拟合 | 学太多训练集噪声 → 加数据/正则化 |
| 微调 | 小学习率（10-100 倍小）适配新任务 |
| LoRA | 低秩增量矩阵 → 只训 ~1% 参数 |
| 量化 | FP32→INT8/INT4 → 显存省 4-8 倍 |
| 蒸馏 | 大模型教小模型（软标签） |

## 4. 学习路线推荐

**路线一：入门夯实（2~3 天，对应模块 01-03）**
概述与核心概念 → CNN → RNN/LSTM；重点建立"架构解决什么问题"的直觉（CNN 管空间、RNN 管序列、Transformer 管并行序列）——不需要推公式，先懂机制。

**路线二：进阶深化（1 周，对应模块 04-08）**
GAN 与生成模型 → 迁移学习（重点 LoRA）→ 强化学习与 RLHF → 模型压缩 → 训练技巧；对照 LLM 的实际流程（预训练→SFT→RLHF→量化部署）理解每个专题的落点。

**路线三：面试冲刺（对应模块 09-10 + 大模型原理）**
框架演进与选型（PyTorch 2.12 现状）→ 面试题精选；然后进入 `大模型原理/` 与 `Transformer/` 补齐 LLM 架构深度。

> 🎯 **核心要点**：深度学习学习的终点 = "**每个架构能说出：解决什么问题 + 核心机制 + 为什么被替代/保留**"——带着 LLM 的视角学 DL（每个专题都问"这和 GPT 有什么关系"），效率最高。

## 6. LLM 时代对照表（本体系每个专题的 LLM 落点）

| 本体系专题 | 核心概念 | LLM 时代的落点 |
|-----------|---------|---------------|
| 01 概述 | 反向传播/正则化 | LLM 训练同样依赖（规模放大版） |

## 7. 常见误区

| 误区 | 真相 |
|------|------|
| "深度学习 = 神经网络，都一样" | 架构差异巨大：CNN 管空间、RNN 管序列、Transformer 管并行序列——每个解决不同问题 |
| "层数越多越好" | 无残差/归一化时深层退化（ResNet 之前 152 层是极限，之后千层可行） |
| "LSTM 能处理任意长序列" | 串行 + 长序列梯度衰减——这正是 Transformer 诞生的原因 |
| "GAN 是生成模型的主流" | 图像/视频生成已转向扩散模型（SD/DALL-E/Sora）；GAN 退居实时/专用场景 |
| "微调 = 从零训练" | 学习率差 10-100 倍；灾难性遗忘是微调特有风险（LoRA 缓解） |
| "量化就是精度损失" | INT8 几乎无损、INT4 损失 2-3%——显存省 4-8 倍，性价比极高 |
| "PyTorch 和 JAX 差不多" | 权重生态决定一切：LLM 权重都是 PyTorch 格式，PyTorch 是事实标准 |
| "RLHF 是锦上添花" | 对齐（RLHF/DPO）是 LLM 能力的关键组成部分——"会但不说"与"不会"的区别 |
| "学 DL 要先把数学推一遍" | 先懂机制（架构解决什么问题）→ 用到再补数学——推公式是工程进阶，不是入门前提 |
| "GPU 越多训练越快" | 数据并行有通信开销拐点——小模型单卡最佳，大模型才需要 ZeRO/张量并行 |
| "量化只影响小模型" | 量化对 LLM 更关键——显存/带宽是 LLM 部署的主要瓶颈（GPTQ/GGUF 是标配） |

> 💡 误区清单 = 面试"观点题"的素材——能指出流行认知的偏差，就是深度。
