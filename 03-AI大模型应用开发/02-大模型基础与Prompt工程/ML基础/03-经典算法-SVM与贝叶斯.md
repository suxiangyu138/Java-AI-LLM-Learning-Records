## 1. 支持向量机 SVM

### 1.1 核心思想

```text
SVM 的目标：找到一个超平面，使两类数据点到平面的"最小距离"最大化

这个最小距离 = Margin（间隔）

              ○  ○              ↖ Margin
           ○    ○    ○          ← 最大间隔超平面
        ●  ●  ●  ●  ●            ↙ Margin
           ●    ●
              ●  ●

  支持向量 = 离超平面最近的那些点（决定了超平面位置）
  其他点即使移动也不影响超平面 → SVM 由少数支持向量决定
```

### 1.2 硬间隔 vs 软间隔

```text
硬间隔 SVM（线性可分数据）：
  要求所有点都在正确一侧 → 超平面严格分离

软间隔 SVM（实际使用）：
  允许少数点跨过 Margin（引入松弛变量 ξ）
  → 容忍噪声和异常点
  → 参数 C 控制惩罚力度：
    C 大 → 严格分类 → 可能过拟合
    C 小 → 容忍误分 → 更平滑
```

## 2. 核技巧

### 2.1 为什么需要核

```text
问题：以下数据线性不可分

    ○     ●
      ○ ●
    ●     ○
      

核技巧：映射到更高维空间 → 在高维中线性可分

  二维不可分 → 映射到三维 → 三维中有截断面 → 可分！

  核函数 K(x, y) = 高维空间中的内积
  → 无需显式计算高维坐标，只需算核函数
```

### 2.2 常用核函数

| 核 | 公式 | 适用 |
|------|------|------|
| **线性核** | $x^T y$ | 线性可分、高维稀疏（文本） |
| **RBF 核** | $\exp(-\gamma\|x-y\|^2)$ | **默认首选**，通用 |
| **多项式核** | $(x^T y + c)^d$ | 已知多项式关系时 |

```python
from sklearn.svm import SVC

# RBF 核 SVM
svm = SVC(kernel='rbf', C=1.0, gamma='scale')
svm.fit(X_train, y_train)

# 支持向量数量
print(f"支持向量数: {len(svm.support_)}")
```

## 3. 朴素贝叶斯

### 3.1 原理

```text
朴素贝叶斯 = 贝叶斯定理 + "特征独立"假设

  P(类别 | 特征) = P(特征 | 类别) × P(类别) / P(特征)

"朴素"假设：各特征之间相互独立
  
  例：判断邮件是否垃圾
    特征：包含 "免费"、包含 "中奖"、包含 "点击"
    
    朴素假设：这三个词是否出现相互独立（实际不独立，但工程上还行）
```

### 3.2 三种变体

| 变体 | 假设特征分布 | 适用 |
|------|------------|------|
| **GaussianNB** | 正态分布 | 连续特征 |
| **MultinomialNB** | 多项式分布 | 文本分类（词频） |
| **BernoulliNB** | 伯努利分布 | 二值特征（词出现/不出现） |

```python
from sklearn.naive_bayes import MultinomialNB
from sklearn.feature_extraction.text import CountVectorizer

# 文本分类 — 朴素贝叶斯的经典场景
vectorizer = CountVectorizer()
X = vectorizer.fit_transform(texts)

nb = MultinomialNB()
nb.fit(X, labels)
```

## 4. 逻辑回归

### 4.1 原理

```text
逻辑回归 = 线性回归 + Sigmoid → 输出概率

  P(y=1) = σ(wx + b) = 1 / (1 + e^{-(wx+b)})

名字有"回归"但用于分类 — 输出是 0~1 的概率

为什么不用线性回归做分类？
  → 线性回归输出无界（可能 >1 或 <0）
  → Sigmoid 将输出压缩到 [0, 1] → 可解释为概率
```

### 4.2 与 LLM 的关系

```text
逻辑回归的 Sigmoid + 交叉熵损失：
  → LLM 输出层的 Softmax = 多分类版 Sigmoid
  → LLM 损失函数 = 多分类版逻辑回归损失

逻辑回归 = 最简单的"神经网络"（单层 + Sigmoid）
LLM = 逻辑回归堆了 80 层 + 换成 Transformer
```

## 5. 算法对比与选型

| 算法 | 可解释性 | 训练速度 | 大数据 | 非线性 | LLM 时代地位 |
|------|:---:|:---:|:---:|:---:|:---:|
| **逻辑回归** | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ❌ | 文本分类 baseline |
| **SVM** | ⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐ | ✅(核) | 小数据强 baseline |
| **朴素贝叶斯** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ❌ | 文本分类（快速） |
| **决策树** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐ | ✅ | 可解释场景 |
| **XGBoost** | ⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐⭐ | ✅ | 表格数据王者 |
| **深度学习** | ⭐ | ⭐ | ⭐⭐⭐⭐⭐ | ✅ | LLM/NLP/CV |

```text
对 Java 后端 + LLM 开发者的选型建议：
  → 表格数据（风控/推荐）→ XGBoost
  → 快速文本分类 → 朴素贝叶斯 或 逻辑回归 + TF-IDF
  → 小样本分类 → SVM (RBF)
  → NLP/生成/CV → 深度学习/LLM
```

---

## 核心要点回顾

- SVM = 最大化 Margin 的分类器，核技巧处理非线性
- 朴素贝叶斯 = 贝叶斯 + 特征独立假设，文本分类利器
- 逻辑回归 = 线性 + Sigmoid = 最简"神经网络"
- 逻辑回归的交叉熵 → LLM 的 Softmax + CE → 一脉相承
