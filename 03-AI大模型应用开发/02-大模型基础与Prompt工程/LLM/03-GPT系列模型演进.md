## 2. 各代架构对比

| 维度 | GPT-1/2 | GPT-3 | GPT-4 | GPT-4o+ |
|------|:---:|:---:|:---:|:---:|
| 架构 | Decoder-Only | Decoder-Only | **MoE** (8×220B) | MoE |
| 上下文 | 512/1024 | 2048-4096 | 8K-128K | 128K |
| 注意力 | MHA | MHA | **GQA** | GQA |
| 激活函数 | GELU | GELU | SwiGLU | SwiGLU |
| 位置编码 | Learned | Learned | **RoPE** | RoPE |
| 训练框架 | 单机 | 分布式 | 超大集群 | 超大集群 |
| 多模态 | ❌ | ❌ | ✅ 图文 | ✅ 原生多模态 |
| 对齐 | ❌ | ❌ | RLHF | RLHF+DPO |

### 关键架构创新

```text
1. GQA (Grouped Query Attention)
   → 多个 Q 头共享一组 K/V 头
   → 显著减少 KV Cache（推理显存砍半）
   → Llama 2/3、GPT-4 均采用

2. SwiGLU 激活函数
   → Swish(xW₁) ⊙ (xW₂)
   → 比 ReLU/GELU 训练更稳定
   → 现代 LLM 标配

3. RoPE 位置编码
   → 旋转位置编码，相对位置
   → 天然支持上下文外推

4. MoE (Mixture of Experts)
   → 每次激活部分专家（不是全参数）
   → GPT-4: 8 个专家 × 220B，每次激活 2 个
   → DeepSeek V3: 也是 MoE，训练成本大幅降低
```

## 3. 关键能力跃迁

### 3.1 GPT-3 → In-Context Learning

```text
GPT-3 的革命性发现：
  不需要微调！给几个示例放在 Prompt 里，模型就能做新任务

Zero-shot:  "翻译成英文：你好" → "Hello"
One-shot:   "翻译：苹果→apple\n翻译：你好→"
Few-shot:   "翻译：苹果→apple\n狗→dog\n猫→cat\n你好→"

→ 这彻底改变了 NLP 范式：从"训练特定模型"到"设计好 Prompt"
```

### 3.2 GPT-4 → 推理飞跃 + 多模态

```text
GPT-4 的核心提升：
├── 推理能力：复杂逻辑推理接近人类专家
├── 多模态：看懂图片（图表/手写/截图）
├── 代码能力：HumanEval 67% → 87%
├── 安全性：事实性提升 40%，违规率降低 82%
└── 长上下文：8K → 128K
```

## 4. 训练规模与成本

| 模型 | 参数量 | 训练数据 | GPU | 训练时间 | 估算成本 |
|------|:---:|------|------|:---:|:---:|
| GPT-1 | 117M | 5GB | 8×V100 | 1 月 | ~$1,000 |
| GPT-2 | 1.5B | 40GB | 256×TPU v3 | 数周 | ~$50,000 |
| GPT-3 | 175B | 570GB | 10,000×V100 | 数月 | ~$12M |
| GPT-4 | ~1.8T(MoE) | 未公开 | ~25,000×A100 | ~3 月 | **~$100M+** |
| Llama 3.1 405B | 405B | 15T tokens | 16,000×H100 | ~2 月 | ~$60M |

> 🎯 GPT-4 的训练成本估计 > 1 亿美元——这也是为什么能训练顶级模型的公司屈指可数

## 核心要点回顾

- GPT-1→2→3→4 每次迭代：参数 ×10 + 数据 ×10 + 能力跃迁
- GPT-3 的革命：In-Context Learning（不需要微调！）
- GPT-4 三大创新：MoE 架构 + GQA 注意力 + 多模态
- 现代 LLM 标配：Decoder-Only + RoPE + SwiGLU + GQA + MoE(可选)
- 训练成本：GPT-3 ~$12M → GPT-4 ~$100M+ → 指数增长
