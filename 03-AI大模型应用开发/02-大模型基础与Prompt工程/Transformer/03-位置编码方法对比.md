## 1. 为什么需要位置编码

```text
Attention 是置换不变性 (Permutation Invariant)：

  输入 [A, B, C] → 输出 [a', b', c']
  输入 [C, A, B] → 输出 [c', a', b']  ← 只是位置变了，值没变

但自然语言中，顺序极其重要：
  "狗咬人" ≠ "人咬狗"

位置编码的解决方案：
  → 给每个位置的 token 添加唯一的位置信号
  → 让模型能区分"位置 1 的 '狗'"和"位置 3 的 '狗'"
```

## 2. Sinusoidal (原始方案)

```python
import numpy as np

def sinusoidal_pe(seq_len, d_model):
    PE = np.zeros((seq_len, d_model))
    for pos in range(seq_len):
        for i in range(0, d_model, 2):
            # 不同的维度用不同的频率
            freq = 10000 ** (2 * i / d_model)
            PE[pos, i]     = np.sin(pos / freq)
            PE[pos, i + 1] = np.cos(pos / freq)
    return PE

# 输入 = Token_Embedding + PE
```

```text
优点：
  ✅ 无需训练（固定函数）
  ✅ 理论上可外推任意长度
  ✅ 相对位置关系可通过三角函数性质推导

缺点：
  ❌ 外推能力实践上有限
  ❌ 不如可学习的位置编码灵活

→ 已被现代 LLM 取代（GPT-1/2/3 用过 Learned PE）
```

## 3. Learned Positional Encoding

```text
做法：位置编码也是可学习的参数矩阵
  PE = nn.Embedding(max_seq_len, d_model)

GPT-1/2/3 使用
  → 训练时学习到 max_seq_len 的位置向量
  → 推理时不能超过训练时的 max_seq_len

优点：灵活，能学到任务特定的位置模式
缺点：无法外推（没见过位置 2049，就无法推理 >2048 的序列）

→ 外推需求 → RoPE 应运而生
```

## 4. RoPE (现代标配)

### 4.1 核心思想

```text
RoPE (Rotary Position Embedding)：
  → 不改变 embedding 的值
  → 而是根据位置旋转 Q 和 K 向量

数学：对第 m 个位置的向量 q，应用旋转矩阵 R_m
  q' = R_m · q

旋转矩阵 R_m：
  R_m = [[cos(m·θ₀), -sin(m·θ₀)],
         [sin(m·θ₀),  cos(m·θ₀)]]

旋转角度 θᵢ = 1 / (10000^(2i/d))  ← 与 Sinusoidal 相同的频率

关键性质：
  两个向量的内积 = 只与它们的相对位置 (m-n) 有关
  Q_m · K_n = f(内容相似度, m-n)
  → RoPE 是相对位置编码，天然支持外推！
```

### 4.2 RoPE 的外推魔法

```text
训练时 2K → 推理时 32K（外推 16x！）

原因：
  RoPE 编码的是相对位置 (m-n)，不是绝对位置 m
  训练时见过的相对距离 ≤ 2K
  推理时遇到 32K 的相对距离 → 线性插值 → 也能处理
  （虽然没训练过那么远的距离，但 RoPE 的旋转性质让模型能"内插"）
```

### 4.3 使用 RoPE 的模型

```text
✅ Llama 1/2/3
✅ Qwen 1/2
✅ Mistral
✅ DeepSeek V2/V3
✅ Gemma 2
✅ GPT-NeoX, Falcon, MPT

→ 2024+ 几乎所有新 LLM 都使用 RoPE
```

## 5. ALiBi (简化方案)

```text
ALiBi (Attention with Linear Biases)：
  → 不加位置编码
  → 而是在 Attention 分数上加一个与距离成正比的偏置

Scores[i][j] = Q_i · K_j - m · |i - j|

m 是每个头独立的斜率

优点：
  ✅ 极简：不加任何参数
  ✅ 外推能力实测最强（2K 训练 → 10K+ 推理）

缺点：
  ❌ 绝对位置信息丢失
  ❌ 表达能力不如 RoPE

→ BLOOM 使用，但未成为主流
```

### 五方案对比

| 方案 | 可学习 | 外推能力 | 计算开销 | 使用模型 |
|------|:---:|:---:|:---:|------|
| Sinusoidal | ❌ | ⭐⭐⭐ | 极低 | 原版 Transformer, BERT |
| Learned | ✅ | ❌ | 极低 | GPT-1/2/3 |
| **RoPE** | **❌** | **⭐⭐⭐⭐⭐** | **中** | **Llama/Qwen/Mistral** |
| ALiBi | ❌ | ⭐⭐⭐⭐⭐ | 零 | BLOOM |
| NoPE | — | — | 零 | 无（实验性） |

## 核心要点回顾

- 位置编码解决 Attention 的置换不变性问题
- Sinusoidal = 固定函数，理论可外推，实践一般
- Learned = 灵活但不支持外推
- **RoPE = 旋转位置编码，相对位置 + 强外推 → 现代 LLM 标配**
- ALiBi = 偏置替代编码，外推最强，但表达能力受限
