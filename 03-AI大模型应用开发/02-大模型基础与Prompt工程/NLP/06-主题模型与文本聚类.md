## 1. LDA 主题模型

### 1.1 原理

```text
LDA (Latent Dirichlet Allocation) = 从文档集合中自动发现潜在主题

核心假设：
  ① 每篇文档是多个主题的混合（如 30% 体育 + 50% 政治 + 20% 娱乐）
  ② 每个主题是词的概率分布（如"体育"主题 → {"比赛":0.15, "球员":0.10, ...}）

生成过程（反向思考）：
  写一篇文档 → 先选主题分布 → 对每个词，从主题中采样一个词

LDA 做的事：
  给定文档集合，反推出主题和每篇文档的主题分布
```

### 1.2 使用

```python
from sklearn.decomposition import LatentDirichletAllocation
from sklearn.feature_extraction.text import CountVectorizer

# ① 向量化（LDA 需要词频，非 TF-IDF）
vectorizer = CountVectorizer(max_features=5000, stop_words='english')
X = vectorizer.fit_transform(docs)

# ② 训练 LDA
lda = LatentDirichletAllocation(n_components=5, random_state=42)
lda.fit(X)

# ③ 查看每个主题的 Top 词
for i, topic in enumerate(lda.components_):
    top_words = [vectorizer.get_feature_names_out()[j]
                 for j in topic.argsort()[-10:]]
    print(f"主题 {i}: {', '.join(top_words)}")

# ④ 查看文档的主题分布
doc_topics = lda.transform(X)  # 每篇文档的 5 个主题权重
```

### 1.3 LDA 的局限

```text
❌ 主题数需手动指定（K=？）
❌ 词袋模型 → 忽略词序
❌ 短文本效果差（一条微博 → 信息太少）
❌ 中文需先分词

LLM 替代方案：
  "总结这 1000 篇文档讨论了哪些主题" → LLM 直接分析
```

## 2. NMF 非负矩阵分解

```python
from sklearn.decomposition import NMF
from sklearn.feature_extraction.text import TfidfVectorizer

# NMF 比 LDA 更快、对短文本效果更好
vectorizer = TfidfVectorizer(max_features=5000)
X = vectorizer.fit_transform(docs)

nmf = NMF(n_components=5, random_state=42)
nmf.fit(X)

# 查看主题
for i, topic in enumerate(nmf.components_):
    top_words = [vectorizer.get_feature_names_out()[j]
                 for j in topic.argsort()[-8:]]
    print(f"主题 {i}: {', '.join(top_words)}")
```

## 3. TextRank 关键词提取

### 3.1 原理

```text
TextRank = PageRank 在文本上的应用

  ① 将文本中的词看作图的节点
  ② 如果两个词在窗口内共现 → 节点连边
  ③ 运行 PageRank 算法 → 高分节点 = 关键词

特点：
  ✅ 无监督（不需要标注数据）
  ✅ 语言无关（不需要词典）
  ✅ 适合单文档关键词提取
```

```python
import jieba.analyse

text = """自然语言处理是人工智能的一个重要分支。
它研究如何让计算机理解和生成人类语言。
近年来深度学习极大地推动了NLP的发展。"""

# TextRank 关键词提取
keywords = jieba.analyse.textrank(
    text, topK=5, withWeight=True
)
for word, weight in keywords:
    print(f"{word}: {weight:.4f}")
# 自然语言处理: 0.xxx, 深度学习: 0.xxx, ...
```

## 4. 文本聚类

```python
from sklearn.cluster import KMeans
from sklearn.feature_extraction.text import TfidfVectorizer

# ① 文本 → TF-IDF 向量
vectorizer = TfidfVectorizer(max_features=5000)
X = vectorizer.fit_transform(docs)

# ② K-Means 聚类
kmeans = KMeans(n_clusters=5, random_state=42)
labels = kmeans.fit_predict(X)

# ③ 查看每个簇的代表文档
for cluster_id in range(5):
    cluster_docs = [docs[i] for i in range(len(docs)) if labels[i] == cluster_id]
    print(f"簇 {cluster_id}: {len(cluster_docs)} 篇文档")
```

### 使用 Embedding 做语义聚类

```python
# 用 Embedding 取代 TF-IDF → 语义聚类 → 效果更好
from sentence_transformers import SentenceTransformer

model = SentenceTransformer('BAAI/bge-small-zh')
embeddings = model.encode(docs)

kmeans = KMeans(n_clusters=5)
labels = kmeans.fit_predict(embeddings)
```

## 6. LLM 时代的无监督文本分析

| 传统方法 | LLM 替代方案 | 何时用传统 |
|----------|------------|-----------|
| LDA 主题模型 | "总结这些文档的主题" | 文档量 > 10 万（API 成本太高） |
| TextRank 关键词 | "提取关键词" | 离线批量处理 |
| K-Means 聚类 | LLM + Embedding 聚类 | 超大规模无标注语料 |
| 抽取式摘要 | 生成式摘要 | 不希望改写原文（法律/合同） |

```text
传统方法的持续价值：
  ✅ 离线、免费、可扩展到百万级文档
  ✅ 确定性输出（不像 LLM 可能不一致）
  ✅ 适合作为特征输入到下游 ML 模型

LLM 的优势：
  ✅ 零样本、理解语义
  ✅ 可处理复杂指令（"找出抱怨物流速度的评论"）
```

## 核心要点回顾

- LDA = 文档-主题-词三层概率模型，自动发现文本中的潜在主题
- TextRank = PageRank 用于文本 → 无监督关键词提取
- 聚类用 Embedding 取代 TF-IDF → 语义聚类效果大幅提升
- LLM 可以做所有无监督文本分析 → 成本是唯一瓶颈
- 传统方法在超大规模离线处理时仍有价值
