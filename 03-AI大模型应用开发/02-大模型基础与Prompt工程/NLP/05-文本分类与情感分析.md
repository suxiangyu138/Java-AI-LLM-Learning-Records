## 1. 文本分类概述

```text
文本分类 = 输入一段文本 → 输出一个或多个类别标签

典型场景：
  垃圾邮件检测：    邮件内容 → {spam, ham}
  情感分析：        商品评论 → {正面, 负面, 中性}
  新闻分类：        新闻文章 → {体育, 科技, 娱乐, 财经...}
  意图识别：        用户问题 → {投诉, 咨询, 购买, 退换}
  多标签分类：      一篇文档 → {科技, AI, 创业}（可多个标签）
```

## 2. 传统 ML 方法

### 2.1 TF-IDF + 分类器

```python
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import Pipeline

# 经典 pipeline
pipeline = Pipeline([
    ('tfidf', TfidfVectorizer(
        max_features=5000,
        ngram_range=(1, 2),       # Unigram + Bigram
        stop_words='english'
    )),
    ('clf', LogisticRegression(
        C=1.0,
        class_weight='balanced'   # 处理类别不均衡
    ))
])

pipeline.fit(train_texts, train_labels)
preds = pipeline.predict(test_texts)
probs = pipeline.predict_proba(test_texts)  # 获取概率
```

### 2.2 传统方法的优缺点

| 优势 | 劣势 |
|------|------|
| 训练快（CPU 分钟级） | 不捕捉语义（只统计词频） |
| 可解释（看 TF-IDF 权重） | 对否定词/语序不敏感 |
| 小数据效果好 | "不好"和"好"可能被当成相似 |

## 3. 深度学习文本分类

### 3.1 TextCNN

```python
import torch.nn as nn

class TextCNN(nn.Module):
    """经典文本分类 CNN"""
    def __init__(self, vocab_size, embed_dim, num_classes,
                 filter_sizes=[3, 4, 5], num_filters=100):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.convs = nn.ModuleList([
            nn.Conv2d(1, num_filters, (fs, embed_dim))
            for fs in filter_sizes
        ])
        self.fc = nn.Linear(len(filter_sizes) * num_filters, num_classes)
        self.dropout = nn.Dropout(0.5)
    
    def forward(self, x):
        x = self.embedding(x).unsqueeze(1)  # (B, 1, seq_len, embed_dim)
        x = [torch.relu(conv(x)).squeeze(3) for conv in self.convs]
        x = [torch.max_pool1d(c, c.size(2)).squeeze(2) for c in x]
        x = torch.cat(x, 1)
        return self.fc(self.dropout(x))
```

### 3.2 BiLSTM + Attention

```text
BiLSTM-Attention = 双向 LSTM + 注意力池化

  输入 → Embedding → BiLSTM → Attention Pooling → FC → Softmax

  Attention 的作用：学习哪些词对分类最重要
  → "这台手机真的太**垃圾**了" → "垃圾"权重最高
```

## 4. BERT 微调分类

### 4.1 标准微调

```python
from transformers import AutoModelForSequenceClassification, Trainer

# ① 加载预训练 BERT
model = AutoModelForSequenceClassification.from_pretrained(
    "bert-base-chinese",
    num_labels=3  # 3 分类
)

# ② 准备数据（文本 + 标签）
from datasets import Dataset
dataset = Dataset.from_dict({
    'text': texts,
    'label': labels
})

def tokenize_fn(examples):
    return tokenizer(
        examples['text'],
        padding='max_length',
        truncation=True,
        max_length=128
    )

dataset = dataset.map(tokenize_fn, batched=True)

# ③ 训练
trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=dataset,
)
trainer.train()
```

### 4.2 BERT 微调要点

| 要点 | 建议 |
|------|------|
| **max_length** | 128~256，文本分类通常够用 |
| **learning_rate** | 2e-5 ~ 5e-5 |
| **epochs** | 3~5（数据量<1万时） |
| **batch_size** | 16~32 |
| **[CLS] token** | BERT 用 [CLS] 位置的输出做分类 |

## 5. LLM 零样本分类

```python
from openai import OpenAI

client = OpenAI()

def zero_shot_classify(text, labels):
    """零样本分类 — 无需训练数据"""
    prompt = f"""将以下文本分类为以下类别之一：{', '.join(labels)}

文本：{text}

类别："""
    
    resp = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[{"role": "user", "content": prompt}],
        temperature=0  # 分类任务→确定性输出
    )
    return resp.choices[0].message.content.strip()
```

## 6. 方法对比与选型

| 方法 | 需要数据 | 准确率 | 速度 | 成本 | 适用 |
|------|:---:|:---:|:---:|:---:|------|
| TF-IDF + LR | 几百条 | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 免费 | 快速 baseline |
| TextCNN | 几千条 | ⭐⭐⭐ | ⭐⭐⭐⭐ | 免费 | 中等数据 |
| BERT 微调 | 几千~几万条 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ | 免费 | **传统 SOTA** |
| LLM 零样本 | 0 | ⭐⭐⭐⭐ | ⭐⭐ | 付费 | 快速验证 |
| LLM Few-Shot | 几条 | ⭐⭐⭐⭐⭐ | ⭐⭐ | 付费 | 最优 |

```text
推荐策略：
  → 有标注数据 → BERT 微调（精度最高、成本最低）
  → 无标注数据 → LLM 零样本验证 → 积累数据 → BERT 微调
  → 追求精度 → LLM Few-Shot + Chain-of-Thought
```

## 核心要点回顾

- 文本分类 pipeline = 向量化 + 分类器
- TF-IDF + 逻辑回归是快速 baseline（省时省力）
- BERT 微调是传统 SOTA（F1 90%+，需要几千条标注数据）
- LLM 零样本分类无需训练数据 → 适合快速验证和低频场景
- 情感分析是文本分类的子集，方法完全通用
