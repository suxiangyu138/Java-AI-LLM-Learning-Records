## 1. 凸集与凸函数

### 1.1 凸集

```text
凸集：集合内任意两点的连线完全在集合内

凸集 ✅                   非凸集 ❌
┌────────┐               ┌────────┐
│  ●──●  │               │  ●  ╲  │
│        │               │   ╲  ● │
└────────┘               └────────┘
```

### 1.2 凸函数

```text
凸函数的定义：
  f(λx + (1-λ)y) ≤ λf(x) + (1-λ)f(y)，∀λ∈[0,1]

直观：函数图像上任意两点连线在函数图像上方

凸函数 ✅                 非凸函数 ❌
  ⌒                           ╭─╮
  │ ●──●                      │●  ●│
  │                           ╰───╯
```

**凸函数的黄金性质：**
- ✅ 局部最小值 = 全局最小值
- ✅ 梯度下降一定能找到全局最优
- ✅ 没有鞍点困扰

## 2. 凸优化问题

### 2.1 标准形式

```text
凸优化问题（标准形式）：

  min  f(x)       目标函数是凸函数
  s.t. g_i(x) ≤ 0  不等式约束是凸函数
       Ax = b      等式约束是仿射的

如果目标 + 约束都满足凸性 → 问题可高效求解
```

### 2.2 LLM 训练的 Loss 是凸的吗？

```text
❌ 不是！

LLM 的 Loss 曲面是高度非凸的：
  → 有无数局部最小值、鞍点、平坦区域
  → 理论上梯度下降可能陷入局部最优

实践中的"经验奇迹"：
  → SGD 在实践中仍然能取得很好的效果
  → 高维空间中的"局部最小值"大多是鞍点
  → 鞍点虽多，但 SGD 的噪声能帮助"跳出"
  → 过度参数化的网络更容易找到全局最优

理论解释（尚不完全）：
  → 过度参数化使优化 Landscape 变得更"友好"
  → Neural Tangent Kernel (NTK) 理论：无限宽网络的优化等效于凸优化
```

## 3. 梯度下降的收敛性

### 3.1 收敛条件

```text
对于凸函数 f，梯度下降的收敛保证：

  f(x_k) - f(x*) ≤ |x₀ - x*|² / (2ηk)

即：经过 k 步后，误差与 1/k 成正比

要求：
  ✅ f 是凸的
  ✅ f 的梯度是 Lipschitz 连续的（|∇f(x)-∇f(y)| ≤ L|x-y|）
  ✅ 学习率 η ≤ 1/L
```

### 3.2 三种梯度下降的收敛对比

| 方法 | 每次用多少数据 | 收敛速度 | 内存 | LLM 使用 |
|------|:---:|:---:|------|:---:|
| **BGD** 批量梯度下降 | 全部 N | 线性收敛（确定） | 极高 | ❌ |
| **SGD** 随机梯度下降 | 1 条 | 次线性收敛（噪声大） | 极低 | ❌ |
| **Mini-Batch SGD** | m 条 | 折中 | 可控 | ✅ |

```text
LLM 使用 Mini-Batch SGD + AdamW：
  batch_size: 4 ~ 512（取决于显存）
  大 batch → 梯度估计准确 → 收敛更稳定
  小 batch → 噪声大 → 可能泛化更好（隐式正则化）
```

### 3.3 学习率对收敛的影响

```text
学习率 η 如何影响收敛：

η 太小 → 收敛慢
  │  ●
  │   ↘ ●
  │      ↘ ●
  │         ↘ ●
  │            ● ★
  └────────────────

η 太大 → 震荡/发散
  │  ●
  │   ↘●
  │  ●   ●
  │ ●     ●
  │●       ●  ★ (永远到不了)
  └────────────────

η 刚好 → 快速平稳收敛
  │  ●
  │   ●
  │    ●
  │     ●
  │      ★
  └────────────────

AdamW 之所以好：自适应地调整每个参数的有效学习率
  → 陡峭方向用小步（避免震荡）
  → 平缓方向用大步（加速收敛）
```

## 4. 拉格朗日乘数法

### 4.1 等式约束优化

```text
问题：min f(x, y)  s.t.  g(x, y) = 0

拉格朗日函数：
  L(x, y, λ) = f(x, y) + λ × g(x, y)
               └─目标─┘   └── 约束项 ──┘

必要条件：∇L = 0
  ∂L/∂x = 0, ∂L/∂y = 0, ∂L/∂λ = 0 → g(x,y)=0

直觉：在约束边界上，目标函数的梯度与约束函数的梯度平行
  → ∇f = -λ∇g  → 无法在约束上再移动来减小 f
```

### 4.2 经典例子

```text
问题：求周长为 2 的矩形的最大面积

  max xy  s.t.  2x + 2y = 2 → x + y = 1

拉格朗日：L = xy + λ(1 - x - y)
  ∂L/∂x = y - λ = 0    → y = λ
  ∂L/∂y = x - λ = 0    → x = λ
  ∂L/∂λ = 1 - x - y = 0 → x + y = 1

  → x = y = 0.5 → 正方形面积最大

AI 中的应用类比：
  → 有约束的损失函数优化（如加正则化项）
  → SVM 的 margin 最大化（约束：所有点正确分类）
```

## 5. KKT 条件

### 5.1 KKT 是什么

```text
KKT（Karush-Kuhn-Tucker）条件：
  同时有等式和不等式约束时的最优性必要条件

问题：min f(x)  s.t.  g_i(x) ≤ 0,  h_j(x) = 0

KKT 条件（4条）：
  ① 稳定性：  ∇f + Σ λ_i ∇g_i + Σ μ_j ∇h_j = 0
  ② 原始可行：g_i(x) ≤ 0,  h_j(x) = 0
  ③ 对偶可行：λ_i ≥ 0
  ④ 互补松弛：λ_i × g_i(x) = 0  ← 核心！

互补松弛的含义：
  如果 g_i(x) < 0（约束不活跃，"松的"）→ λ_i = 0（这个约束不重要）
  如果 λ_i > 0（约束重要）→ g_i(x) = 0（约束恰好"绑紧"）
```

### 5.2 KKT 与 SVM

```text
SVM 的优化问题：

  min (1/2)|w|²   s.t.  y_i(w·x_i + b) ≥ 1

  约束条件：每个样本点都在 margin 外或边界上

互补松弛在 SVM 中：
  λ_i > 0 → y_i(w·x_i + b) = 1 → 该点在 margin 边界上 → 它是支持向量！
  λ_i = 0 → y_i(w·x_i + b) > 1 → 该点在 margin 外 → 不重要

  → 只有支持向量决定最终模型 → 稀疏性！
```

### 5.3 LLM 中需要懂 KKT 吗？

```text
对于 Java 后端 + 大模型开发：
  ✅ 知道 KKT 条件的大致含义（"约束优化"的理论基础）
  ✅ 知道互补松弛条件（理解为什么有些约束"不活跃"）
  ❌ 不需要手动推导 KKT（面试基本不考推公式）
  ❌ 不需要实现 KKT 求解器

实际工程中：
  → PyTorch/TF 的优化器已经封装好了
  → 约束优化直接用拉格朗日惩罚项
  → 深度学习中的约束很少用 KKT，更多用软约束（加正则项）
```

## 6. 常见优化算法对比

| 算法 | 公式/特点 | 适用场景 | LLM 使用 |
|------|----------|------|:---:|
| **SGD** | $W = W - \eta g$ | 简单任务 | ❌ |
| **SGD + Momentum** | $v = \beta v + \eta g, W = W - v$ | 加速收敛 | ❌ |
| **Adam** | $v = \hat{m}/(\sqrt{\hat{v}}+\epsilon)$ | 通用 | ⚠️ 老版本用 |
| **AdamW** | Adam + 解耦权重衰减 | **LLM 标配** | ✅ |
| **AdaFactor** | 节省显存的 Adam 变体 | 超大模型预训练 | ⚠️ |
| **LION** | 只用梯度符号 | 新方向，实验性 | ⚠️ |

### AdamW vs Adam

```text
Adam 的问题：
  → L2 正则化 与 自适应学习率 耦合
  → 权重衰减效果被"自适应"稀释

AdamW 的改进：
  → 将权重衰减从梯度的自适应调整中解耦
  → W = W - η × (m̂/(√v̂ + ε) + λ × W)
                               └── 独立的权重衰减 ──┘
  → 泛化性能明显优于 Adam
```

## 7. LLM 中的优化实践

### 7.1 微调中的优化器选择

| 场景 | 优化器 | 典型学习率 |
|------|--------|:---:|
| **全量微调** | AdamW | 1e-5 ~ 5e-5 |
| **LoRA 微调** | AdamW | 1e-4 ~ 5e-4 |
| **QLoRA** | AdamW (paged) | 2e-4 |
| **预训练** | AdamW / AdaFactor | 递减 schedule |

### 7.2 学习率调度

```text
余弦退火（Cosine Annealing）：

  lr(t) = lr_min + 0.5(lr_max - lr_min)(1 + cos(πt/T))

优势：
  → 开始大 lr 快速探索 → 逐渐减小精细调整
  → 平滑衰减比阶梯衰减更好

Warmup（预热）：
  → 前 N 步 lr 从 0 线性增加到目标值
  → 避免训练初期的不稳定
  → LLM 训练必备（尤其是从零预训练）
```

| 概念 | 一句话 | 与 LLM 的关系 |
|------|--------|-------------|
| 凸函数 | 局部最优=全局最优 | LLM Loss 不是凸的（但 SGD 仍有效） |
| 梯度下降收敛 | 凸函数上保证收敛，速率 O(1/k) | 实践中收敛性好 |

| KKT 条件 | 不等式约束的通用最优条件 | 知道即可，不用手推 |
| AdamW | Adam + 解耦权重衰减 | **LLM 训练的事实标准** |
