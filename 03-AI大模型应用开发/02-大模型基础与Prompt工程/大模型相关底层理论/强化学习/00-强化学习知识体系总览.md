# 强化学习知识体系总览

> 强化学习解决的是"没有标准答案、只有奖励信号"时的决策问题。对大模型而言，它从 RLHF 的 PPO 一路演进到 2026 年的 GRPO + RLVR，成为后训练阶段改变模型行为的核心手段。本体系从 MDP 的数学框架讲到 GRPO 家族的工程落地，目标是能推导目标函数、能解释算法取舍、能判断什么任务该用 RL。

```text
01 定位与框架
  → 02 MDP 与 Bellman（理解 V/Q 与优势函数）

  → 10 选型与面试
```

跳过值函数方法与动态规划细节，重点放在"策略梯度 → PPO → GRPO"这条主线。

### 3.2 算法研究路线

```text
01 → 02 → 03 → 04 → 05 → 06 → 08 → 09
```

补齐动态规划、值函数方法、Actor-Critic 的数学推导，再进入大模型后训练。

```text

```

## 4. 核心概念速查

| 概念 | 符号 | 一句话解释 |
|------|:---:|-----------|
| 状态 | $s$ | 环境当前的情况 |
| 动作 | $a$ | Agent 的选择 |
| 策略 | $\pi(a\mid s)$ | 在状态 $s$ 下选动作 $a$ 的概率 |
| 回报 | $G_t$ | 从 $t$ 时刻起的折扣累积奖励 |
| 状态价值 | $V^\pi(s)$ | 从 $s$ 出发按 $\pi$ 行动的期望回报 |
| 动作价值 | $Q^\pi(s,a)$ | 从 $s$ 执行 $a$ 后按 $\pi$ 行动的期望回报 |
| 优势函数 | $A^\pi(s,a)$ | $Q^\pi(s,a)-V^\pi(s)$，动作比平均好多少 |
| 折扣因子 | $\gamma$ | 未来奖励的折现率 |
| 探索率 | $\epsilon$ | $\epsilon$-greedy 中随机动作的概率 |
| On-policy | — | 用当前策略采样的数据更新当前策略 |
| Off-policy | — | 用其他策略（如行为策略）的数据更新 |
| 重要性采样 | $\rho$ | 用行为策略数据估计目标策略期望 |
| KL 散度 | $D_{KL}$ | 两个策略分布的差异 |
| 奖励模型 | $r_\phi$ | 学习人类偏好的打分函数 |
| 参考模型 | $\pi_{ref}$ | KL 约束的锚点，通常是 SFT 模型 |
| 组相对优势 | $\hat{A}_i$ | GRPO 中用组内奖励标准化得到的优势 |
| RLVR | — | 用可验证奖励（答案对错、测试通过）做 RL |

## 5. 版本与时效基准

| 项目 | 2026-10 现状 |
|------|-------------|
| 后训练主流范式 | SFT → 偏好优化（DPO 家族）→ RLVR |
| LLM RL 默认优化器 | GRPO 及其变体（DAPO/GSPO/Dr.GRPO） |
| 推理模型 | RLVR + 可验证奖励（数学、代码、工具调用）成为标准 |
| 代表工作 | DeepSeek-R1 系列、Qwen3 的 GSPO、DeepSeek V3.2 的 zero-KL 与自验证 |
| 训练框架 | TRL（最成熟）、verl（R1/Qwen 复现事实标准）、OpenRLHF、NeMo-RL、axolotl |
| 算法趋势 | 奖励稠密化（过程奖励）、分类视角重构（REAL）、优势塑形（GVPO/StepPO） |
| 论文来源 | ICLR 2026、arXiv 2026 的 RLVR/GRPO 变体持续活跃 |

> **提示**：本体系以 2026 年的 GRPO 家族为主线，同时保留 PPO/DPO 的完整推导。PPO 仍是理解策略梯度的最佳入口，GRPO 是当前工程默认。
