# 03-动态规划与无模型预测

> 动态规划假设"环境模型已知"，用 Bellman 方程迭代算出价值；但真实环境往往不知道转移概率，于是有了蒙特卡洛与时序差分。这一篇是"从有模型到无模型"的桥梁，也是理解 TD 误差、GAE、优势估计的必经之路。

## 1. 动态规划的适用条件

动态规划（DP）求解 MDP 需要两个前提：

```text
① 环境模型已知：知道 p(s',r|s,a)
② 状态空间有限且不太大：可以遍历所有状态

满足时，DP 可以精确算出 V* 与 π*
不满足时，只能采样估计 → 蒙特卡洛 / TD
```

DP 的核心思想是"用 Bellman 方程做自举（bootstrapping）"：

```text
自举：用当前对价值的估计，去更新另一个价值的估计

V(s) ← 用 V(s') 的当前估计更新 V(s)
      ↑ 自己更新自己，不需要等真实回报
```

---

## 2. 策略评估

**目标**：给定策略 $\pi$，计算 $V^\pi$。

**方法**：把 Bellman 期望方程当成迭代更新式。

$$V_{k+1}(s) = \sum_a \pi(a\mid s)\sum_{s',r}p(s',r\mid s,a)\left[r + \gamma V_k(s')\right]$$

初始值 $V_0$ 任意（通常全 0），迭代到 $\max_s|V_{k+1}(s)-V_k(s)|<\theta$ 为止。

### 2.1 收敛性证明

定义 Bellman 算子 $T^\pi$：

$$(T^\pi V)(s) = \sum_a \pi(a\mid s)\sum_{s',r}p(s',r\mid s,a)\left[r + \gamma V(s')\right]$$

对任意两个价值函数 $V, U$：

$$
\begin{aligned}
\|T^\pi V - T^\pi U\|_\infty
&= \max_s \left|\sum_a \pi(a\mid s)\sum_{s'}p(s'\mid s,a)\gamma\left(V(s')-U(s')\right)\right| \\
&\le \gamma \max_s \sum_a \pi(a\mid s)\sum_{s'}p(s'\mid s,a)\left|V(s')-U(s')\right| \\
&\le \gamma \|V-U\|_\infty
\end{aligned}
$$

因为 $\gamma<1$，$T^\pi$ 是压缩映射。由 Banach 不动点定理：

```text
① 存在唯一不动点 V^π
② 从任意初值迭代都收敛到 V^π
③ 收敛速度是几何级数（每轮误差至少缩小 γ 倍）
```

这解释了为什么策略评估一定能收敛，以及 $\gamma$ 越小收敛越快。

## 3. 策略改进

**目标**：给定 $V^\pi$，构造一个不差于 $\pi$ 的新策略 $\pi'$。

**做法**：对每个状态选当前看起来最好的动作。

$$\pi'(s) = \arg\max_a Q^\pi(s,a) = \arg\max_a \sum_{s',r}p(s',r\mid s,a)\left[r+\gamma V^\pi(s')\right]$$

**策略改进定理**：如果 $\pi'$ 是按上式得到的贪心策略，则对所有状态：

$$V^{\pi'}(s) \ge V^\pi(s)$$

### 3.1 证明思路

对任意状态 $s$：

$$
\begin{aligned}
V^\pi(s)
&\le \max_a Q^\pi(s,a) \\
&= Q^\pi(s,\pi'(s)) \\
&= \mathbb{E}\left[r + \gamma V^\pi(S_{t+1})\mid S_t=s, A_t=\pi'(s)\right] \\
&\le \mathbb{E}\left[r + \gamma V^{\pi'}(S_{t+1})\mid S_t=s, A_t=\pi'(s)\right] \\
&\le V^{\pi'}(s)
\end{aligned}
$$

第三步用了归纳：每一步都换成 $\pi'$，价值不减；最后一步展开成无穷级数即得。严格的完整证明需要对迭代次数做归纳。

## 4. 策略迭代

把评估与改进交替进行：

```text
初始化 π0
重复：
  ① 策略评估：算 V^{π_k}（迭代到收敛）
  ② 策略改进：π_{k+1}(s) = argmax_a Q^{π_k}(s,a)
  直到 π_{k+1} = π_k（策略稳定）
```

性质：

```text
每轮改进后策略不退化（策略改进定理）
有限 MDP 下策略数量有限
→ 有限步内收敛到最优策略
```

代价：

```text
每轮评估都要迭代到收敛 → 计算量大
策略评估是策略迭代的瓶颈
```

---

## 5. 值迭代

把"评估"和"改进"合并成一步：

$$V_{k+1}(s) = \max_a \sum_{s',r}p(s',r\mid s,a)\left[r + \gamma V_k(s')\right]$$

这就是 Bellman 最优方程的迭代形式。

```text
与策略迭代的区别：
  策略迭代：先评估到收敛，再改进
  值迭代：每轮都直接取 max（等价于只评估一步就改进）

收敛后：
  V_k → V*
  π*(s) = argmax_a Q*(s,a)
```

值迭代的收敛性同样来自压缩映射：Bellman 最优算子是 $\gamma$-压缩。

---

## 6. 广义策略迭代

广义策略迭代（GPI）是策略迭代与值迭代的统一视角：

```text
评估 ⇄ 改进 的循环

  评估：让 V 更接近 V^π
  改进：让 π 更贪心于 V

两者互相拉扯，最终停在"π 对 V 贪心，V 是 π 的价值"的不动点
→ 即最优策略与最优价值
```

几乎所有 RL 算法都是 GPI 的变体：

| 算法 | 评估方式 | 改进方式 |
|------|---------|---------|
| 策略迭代 | 迭代到收敛 | 完全贪心 |
| 值迭代 | 一步 | 完全贪心 |
| Q-Learning | 一步 TD | 完全贪心（off-policy） |
| SARSA | 一步 TD | $\epsilon$-贪心（on-policy） |
| Actor-Critic | Critic 估 V | Actor 按梯度改进 |
| PPO | GAE 估优势 | 裁剪的策略梯度 |

## 7. 从有模型到无模型

DP 的致命限制是"需要 $p(s',r\mid s,a)$"。真实问题里：

```text
LLM 的奖励模型：不知道"给定回答，奖励的分布"
机器人：不知道"给定动作，下一状态的精确概率"
推荐系统：用户反应不可建模

→ 只能通过采样获得 (s, a, r, s') 的经验
```

无模型方法的两条路线：

```text
蒙特卡洛（MC）：
  跑完整个回合，用真实回报 G_t 估计 V
  无偏，但方差大，必须等回合结束

时序差分（TD）：
  走一步就用"即时奖励 + 下一状态估计"更新
  有偏（自举），但方差小，可在线学习
```

---

## 8. 蒙特卡洛预测

**目标**：估计 $V^\pi(s)$。

**做法**：按 $\pi$ 采样多个回合，对每个状态取回报的平均。

### 8.1 首次访问 vs 每次访问

```text
首次访问 MC（First-visit）：
  每个回合中，状态 s 只在第一次出现时计入

每次访问 MC（Every-visit）：
  每次出现都计入

两者都收敛到 V^π（大数定律）
首次访问的证明更简单（样本独立同分布）
```

### 8.2 增量更新

不必保存所有回报，用增量平均：

$$V(S_t) \leftarrow V(S_t) + \alpha\left[G_t - V(S_t)\right]$$

其中 $\alpha$ 是步长。当 $\alpha$ 随访问次数递减（如 $1/N$）时，等价于算术平均。

### 8.3 特点

```text
优点：
  无偏（G_t 是 V^π 的无偏样本）
  不需要环境模型
  不需要马尔可夫性（多看一步历史也行）

缺点：
  必须等回合结束
  方差大（回报是很多随机量的和）
  回合很长时学习慢
```

## 9. 时序差分 TD(0)

TD 用"一步奖励 + 下一状态的估计"替代完整回报：

$$V(S_t) \leftarrow V(S_t) + \alpha\left[R_{t+1} + \gamma V(S_{t+1}) - V(S_t)\right]$$

括号里的量叫 **TD 误差**：

$$\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t)$$

### 9.1 TD 目标

```text
MC 目标：G_t（真实回报）
TD 目标：R_{t+1} + γV(S_{t+1})（自举估计）

TD 目标 = 真实回报的估计
  → 有偏（因为 V 不准确）
  → 但方差小（只含一步随机性）
```

### 9.2 TD(0) 的性质

```text
① 在线：每走一步就能更新
② 自举：用估计更新估计
③ 有偏：收敛到 V^π 的前提是步长满足 Robbins-Monro 条件
④ 方差小：只依赖一步转移
⑤ 对马尔可夫性敏感：状态不完整时效果差
```

Robbins-Monro 条件：

$$\sum_{t=1}^{\infty}\alpha_t = \infty,\qquad \sum_{t=1}^{\infty}\alpha_t^2 < \infty$$

直观含义：步长要足够大（能走到任何地方），又要足够小（最终能稳定）。

## 10. MC 与 TD 的偏差方差权衡

| 维度 | 蒙特卡洛 | TD(0) |
|------|---------|-------|
| 目标 | 真实回报 $G_t$ | 自举目标 $R+\gamma V$ |
| 偏差 | 无偏 | 有偏 |
| 方差 | 大 | 小 |
| 更新时机 | 回合结束 | 每一步 |
| 是否需要模型 | 否 | 否 |
| 对马尔可夫性 | 不敏感 | 敏感 |
| 收敛速度 | 慢（方差大） | 通常快 |
| 适用 | 回合短、状态可完全观测 | 持续任务、在线学习 |

偏差-方差分解：

$$
\mathbb{E}\left[(G_t - V(s))^2\right]
= \underbrace{\left(\mathbb{E}[G_t]-V(s)\right)^2}_{\text{偏差}^2}
+ \underbrace{\mathrm{Var}(G_t)}_{\text{方差}}
$$

```text
MC：偏差 0，方差大（G_t 含 T 步随机性）
TD：偏差非 0（V 不准），方差小（只含一步随机性）

取舍原则：
  状态表示准确、马尔可夫性强 → TD 更好
  状态表示粗糙、回合短 → MC 更稳
```

## 11. n-step TD 与 TD(λ)

### 11.1 n-step TD

在 MC 与 TD(0) 之间插值：

$$G_t^{(n)} = R_{t+1} + \gamma R_{t+2} + \cdots + \gamma^{n-1}R_{t+n} + \gamma^n V(S_{t+n})$$

```text
n=1：TD(0)
n→∞：MC
n 越大 → 偏差越小、方差越大
```

### 11.2 TD(λ) 与资格迹

TD(λ) 对所有 n-step 回报做几何加权平均：

$$G_t^\lambda = (1-\lambda)\sum_{n=1}^{\infty}\lambda^{n-1}G_t^{(n)}$$

- $\lambda=0$：退化为 TD(0)
- $\lambda=1$：退化为 MC

资格迹（eligibility trace）是它的在线实现：记录每个状态"最近被访问的程度"，更新时按迹衰减。

> **要点**：GAE（广义优势估计）就是 TD(λ) 在优势函数上的版本。PPO 用的 $\lambda$ 通常在 0.95 左右，就是在"偏差"与"方差"之间取折中。

## 12. 代码实现

### 12.1 策略迭代（网格世界）

```python
import numpy as np

GRID = 4
GAMMA = 0.9
ACTIONS = [(0, 1), (0, -1), (1, 0), (-1, 0)]
TERMINAL = {(0, 0), (GRID - 1, GRID - 1)}


def step(state, action):
    row, col = state
    dr, dc = action
    next_row = min(max(row + dr, 0), GRID - 1)
    next_col = min(max(col + dc, 0), GRID - 1)
    next_state = (next_row, next_col)
    reward = 0.0 if next_state in TERMINAL else -1.0
    return next_state, reward


def policy_evaluation(policy, theta=1e-6):
    values = np.zeros((GRID, GRID))
    while True:
        delta = 0.0
        for row in range(GRID):
            for col in range(GRID):
                state = (row, col)
                if state in TERMINAL:
                    continue
                action = policy[row, col]
                next_state, reward = step(state, action)
                new_value = reward + GAMMA * values[next_state]
                delta = max(delta, abs(new_value - values[row, col]))
                values[row, col] = new_value
        if delta < theta:
            return values


def policy_improvement(values):
    policy = np.zeros((GRID, GRID), dtype=int)
    for row in range(GRID):
        for col in range(GRID):
            state = (row, col)
            if state in TERMINAL:
                continue
            action_values = []
            for action in ACTIONS:
                next_state, reward = step(state, action)
                action_values.append(reward + GAMMA * values[next_state])
            policy[row, col] = int(np.argmax(action_values))
    return policy


def policy_iteration():
    policy = np.zeros((GRID, GRID), dtype=int)
    for _ in range(100):
        values = policy_evaluation(policy)
        new_policy = policy_improvement(values)
        if np.array_equal(policy, new_policy):
            return policy, values
        policy = new_policy
    return policy, values
```

### 12.2 TD(0) 预测

```python
def td_zero(env, policy, episodes=5000, alpha=0.1, gamma=0.9):
    values = {}
    for _ in range(episodes):
        state = env.reset()
        done = False
        while not done:
            action = policy(state)
            next_state, reward, done = env.step(action)
            values.setdefault(state, 0.0)
            values.setdefault(next_state, 0.0)
            target = reward + (0.0 if done else gamma * values[next_state])
            values[state] += alpha * (target - values[state])
            state = next_state
    return values
```

## 13. 与 LLM 后训练的关系

动态规划与无模型预测看似离 LLM 很远，但三个概念直接贯穿后训练：

```text
① 自举与 TD 误差 → GAE
   PPO 用 GAE 估计优势，本质是 TD(λ)：
   A_t = Σ (γλ)^l δ_{t+l}
   → 理解 TD 误差才知道 λ 在调什么

② 偏差-方差权衡 → 采样组大小
   GRPO 用一组样本估计基线
   组越大 → 基线越准（偏差小）、计算越贵
   组越小 → 方差大、优势噪声大

③ GPI 视角 → 后训练迭代
   奖励模型评估 → 策略改进 → 重新采样
   多轮 RLHF/RLVR 就是多轮 GPI
```

一个容易混淆的点：

```text
LLM 的 RL 通常不做"价值函数自举"（GRPO 没有 Critic）
而是用"组内平均值"作为基线
→ 用采样代替 Critic，降低实现复杂度
→ 代价是采样成本上升

这不算违背 TD 思想，而是"用蒙特卡洛基线替代自举基线"的取舍
```

## 14. 小结

| 问题 | 答案 |
|------|------|
| DP 的前提 | 模型已知、状态有限 |
| 策略评估 | 迭代 Bellman 期望方程，压缩映射保证收敛 |
| 策略改进 | 对 $Q^\pi$ 贪心，策略不退化 |
| 策略迭代 | 评估与改进交替，有限步收敛 |
| 值迭代 | 每步取 max，直接逼近 $V^*$ |
| GPI | 所有 RL 算法的统一框架 |
| MC | 用完整回报，无偏但方差大 |
| TD(0) | 用一步奖励 + 自举，方差小但有偏 |
| n-step / TD(λ) | 偏差与方差的连续调节 |
| 与 LLM 的关系 | GAE、组基线、多轮 GPI |
