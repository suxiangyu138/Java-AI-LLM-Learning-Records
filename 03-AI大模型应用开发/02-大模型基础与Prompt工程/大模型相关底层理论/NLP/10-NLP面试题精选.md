## 1. 基础概念题

### Q1: NLP 中 NLU 和 NLG 的区别？

```text
NLU (Natural Language Understanding)：理解 → 分类、NER、情感分析
NLG (Natural Language Generation)：生成 → 摘要、翻译、对话

传统 NLP：两者需要不同模型
LLM 时代：Decoder-Only 模型同时搞定 NLU + NLG
```

### Q2: 中文分词为什么比英文难？主流方法有哪些？

```text
英文天然空格分隔，中文连续书写无分隔符。

方法：
  ① 最大匹配法（词典匹配）
  ② HMM/CRF 序列标注（jieba 默认）
  ③ BiLSTM-CRF（深度学习）
  ④ BPE 子词分词（LLM 使用）
```

### Q3: 什么是 OOV 问题？怎么解决？

```text
OOV (Out-of-Vocabulary)：测试时遇到训练词表中没有的词 → 变成 [UNK]

解决方案：
  ① BPE 子词分词（LLM 标准方案）→ 用子词组合未知词
  ② FastText（子词 n-gram）→ 用字符级信息推断
  ③ 增大词表 + 低频词替换为 [UNK]
```

## 2. 文本表示题

### Q4: TF-IDF 的原理？它解决了 BoW 的什么问题？

```text
TF-IDF = TF × IDF

TF：词在本文档中的频率（局部重要性）
IDF：log(总文档数/包含该词的文档数)（全局区分度）

解决了 BoW 的问题：
  BoW 对"的、是、了"等高频词给了过高的权重
  TF-IDF 通过 IDF 压低在所有文档中都出现的高频词
```

### Q5: Word2Vec 的 CBOW 和 Skip-gram 区别？哪个更好？

```text
CBOW：上下文 → 预测中心词（快，适合小数据）
Skip-gram：中心词 → 预测上下文（慢但效果好，适合大数据）

Skip-gram 更好：对罕见词的学习效果更好
实践：数据量大用 Skip-gram，数据量小用 CBOW
```

### Q6: Word2Vec 和 BERT Embedding 的根本区别？

```text
Word2Vec：静态向量 → "苹果"永远同一个向量 → 不能区分多义词
BERT：上下文相关 → "吃苹果"和"苹果手机"的"苹果"向量不同

根本区别：Word2Vec 只看词本身，BERT 看词+上下文
```

## 3. 模型与架构题

### Q7: Seq2Seq + Attention 解决了什么问题？

```text
传统 Seq2Seq：Encoder 把整个输入压缩成一个固定长度向量 → 信息瓶颈
  → 长句子的开头信息在压缩中丢失

Seq2Seq + Attention：Decoder 每步动态关注 Encoder 不同位置
  → 不依赖单一固定向量 → 长句翻译质量大幅提升
  → Attention 是 Transformer 的前身
```

### Q8: CRF 在序列标注中起什么作用？

```text
CRF 学习标签之间的转移约束：

  → B-PER 后面大概率是 I-PER（不会突然变成 B-LOC）
  → O 后面可以接任何标签
  → 防止输出非法标签序列

没有 CRF：BiLSTM 可能输出 "B-PER, B-LOC, I-ORG, O" → 非法序列
有 CRF：学习转移矩阵 → 约束输出 → 合法序列
```

### Q9: BERT 的 [CLS] token 是做什么的？

```text
[CLS] 是 BERT 在每个输入序列开头加的特殊 token

分类任务：[CLS] 位置的输出向量 → 作为整个句子的"聚合表示" → 输入分类器

为什么用 [CLS] 而不是平均所有 token？
  → [CLS] 通过 Self-Attention 聚合了所有 token 的信息
  → BERT 的训练目标之一就是让 [CLS] 学到句子级别的语义
```

## 4. LLM 时代新题

### Q10: 传统 NLP 和 LLM 的根本区别是什么？

```text
传统 NLP：每个任务一个专用模型 → 数据收集→标注→训练→部署
LLM：一个通用模型做所有任务 → Prompt 切换任务

核心转变：
  → 从"训练模型"到"写 Prompt"
  → 从"需要标注数据"到"零样本/Few-Shot"
  → 从"固定任务"到"任意自然语言指令"
```

### Q11: 为什么 LLM 能零样本做 NLP 任务？

```text
LLM 在预训练阶段已经学到了：
  ✅ 语言的语法和语义规律
  ✅ 各种 NLP 任务的"模式"（分类、NER、摘要...）
  ✅ 从指令中理解"要做什么"的能力（Instruct 微调）

因此：
  "判断以下评论的情感" → 模型理解这是分类任务 → 输出类别
  "提取人名和地名" → 模型理解这是 NER → 输出实体
```

### Q12: BERT 微调和 LLM Prompt 怎么选？

```text
选 BERT 微调：
  ✅ 有足够标注数据（>1000 条）
  ✅ 任务固定不变
  ✅ 需要低延迟/低成本（BERT 推理比 LLM 快 100×）
  ✅ 不需要生成式输出（纯分类/NER）

选 LLM Prompt：
  ✅ 零/少量标注数据
  ✅ 任务经常变化
  ✅ 需要灵活的指令（"用幽默风格..."）
  ✅ 生成式输出（摘要、改写、创作）
```

## 5. 场景设计题

### Q13: 设计一个垃圾邮件检测系统

```text
方案 1（传统 NLP）：
  ① 收集 5000+ 标注邮件
  ② TF-IDF 向量化
  ③ 逻辑回归/朴素贝叶斯分类
  → 准确率 ~95%，部署成本低

方案 2（BERT 微调）：
  ① 收集 5000+ 标注邮件
  ② BERT-base 微调
  → 准确率 ~98%，需 GPU

方案 3（LLM Prompt）：
  ① 零标注数据
  ② "判断以下邮件是否是垃圾邮件"
  → 准确率 ~97%，API 成本，延迟高

推荐：方案 1 做 baseline，方案 2 做生产
```

### Q14: 设计一个客服意图识别系统

```text
要求：识别用户意图（投诉/咨询/购买/退换/其他）

方案：
  ① 收集 2000+ 条历史客服对话，人工标注意图
  ② BERT 微调做 5 分类
  ③ 置信度 < 0.7 → 降级到 LLM（GPT-4o-mini）判断
  → BERT 处理 90% 简单 case（快+免费）
  → LLM 兜底 10% 疑难 case（慢但准确）
  → 两者结合 = 最优性价比
```

### Q15: 多语言场景下 NLP 系统怎么设计？

```text
方案 1：多语言 BERT（mBERT / XLM-RoBERTa）
  → 一个模型支持 100+ 语言
  → 各语言共享参数 → 自动跨语言迁移
  
方案 2：翻译 + 单语言模型
  → 所有文本翻译成英文 → 英文 NLP 处理
  → 简单但翻译误差会传播

方案 3：LLM
  → GPT-4/Claude 天然多语言 → 无需额外处理
  → 成本高但效果最好
  
推荐：数据量大且语言固定 → 方案 1；灵活场景 → 方案 3
```

## 核心要点回顾

- NLU/NLG 是 NLP 的两大分支，LLM 将两者统一
- Word2Vec 是静态向量，BERT 是上下文向量 → 多义词处理的关键差异
- CRF 约束标签转移 → 序列标注不可省略的一层
- LLM 零样本的分类/NER 能力源于预训练阶段学到了任务模式
- BERT 微调 vs LLM Prompt：有数据用 BERT（快+免费），无数据用 LLM（灵活）
