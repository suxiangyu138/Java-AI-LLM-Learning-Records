## 1. 学习率调度

### 1.1 Warmup

```text
Warmup (预热) = 训练初期学习率从 0 逐渐增加到目标值

为什么需要？
  → 训练初期模型参数是随机的 → 梯度方向不可靠
  → 大学习率可能导致训练初期的"震荡"
  → Warmup 让模型先"站稳"，再加速

LLM 训练必须使用 Warmup：
  预训练：前 2000-4000 step 从 0 → 目标 lr
  微调：前 100-500 step 从 0 → 目标 lr
```

```python
from torch.optim.lr_scheduler import LambdaLR

def warmup_scheduler(optimizer, warmup_steps):
    def lr_lambda(step):
        if step < warmup_steps:
            return step / warmup_steps  # 线性增长
        return 1.0
    return LambdaLR(optimizer, lr_lambda)
```

### 1.2 Cosine 衰减

```python
from torch.optim.lr_scheduler import CosineAnnealingLR

scheduler = CosineAnnealingLR(optimizer, T_max=total_steps, eta_min=1e-6)
# lr 从 max → min 余弦衰减 → 比线性衰减更平滑
```

### 1.3 学习率调度对比

| 调度 | 曲线 | 适用 |
|------|------|------|
| **Step** | 阶梯式下降 | 传统 CV |
| **Cosine** | 平滑下降 | **LLM 标配** |
| **Linear** | 线性下降 | 简单任务 |
| **Constant** | 不变 | 微调小数据集 |

## 2. 正则化技巧

### 2.1 Label Smoothing

```text
Label Smoothing = 不要求模型 100% 确定，允许"软化"标签

  硬标签：[1, 0, 0] → 模型被强制学到极端置信度
  软标签：[0.9, 0.05, 0.05] → 模型更"谦虚" → 泛化更好

  公式：y_smooth = (1 - ε) × y_hard + ε / K

  ε = 0.1 → LLM 训练常用值
```

```python
# PyTorch 中 CrossEntropyLoss 自带 label_smoothing
criterion = nn.CrossEntropyLoss(label_smoothing=0.1)
```

### 2.2 Gradient Clipping

```python
# 防止梯度爆炸 — LLM 训练必备
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
```

### 2.3 Stochastic Depth

```text
Stochastic Depth = 随机丢弃整层（训练时）
  → 类似 Dropout 但是层级 → 让深层网络"不依赖"所有层
  → 推理时所有层激活
```

## 3. 数据增强

| 方法 | 原理 | 适用 |
|------|------|------|
| **Mixup** | 两张图按比例混合 → 标签也混合 | CV / 也用于 NLP Embedding |
| **CutMix** | 一张图的一块替换为另一张 | CV |
| **回译** | 原文→翻译→回译→增强文本 | **NLP / LLM 训练** |
| **随机删除** | 随机删词/换词 | NLP |
| **RandAugment** | 随机组合多种增强 | CV |

```python
# NLP 回译增强
def back_translation_augment(text, target_lang='en'):
    # 中→英→中 → 生成同义但不同表述的文本
    en = translator.zh_to_en(text)
    zh = translator.en_to_zh(en)
    return zh
```

## 4. 初始化策略

| 方法 | 公式 | 适用 |
|------|------|------|
| **Xavier** | $W \sim U(-\sqrt{6/(n_{in}+n_{out})})$ | Sigmoid/Tanh |
| **He/Kaiming** | $W \sim N(0, \sqrt{2/n_{in}})$ | **ReLU / GELU** |
| **Normal** | $W \sim N(0, \sigma^2)$ | 通用 |

```text
为什么初始化很重要？
  初始化太大 → 激活值太大 → 梯度爆炸
  初始化太小 → 激活值太小 → 梯度消失
  好的初始化 → 每层输出的方差保持一致 → 训练稳定

LLM 训练：He 初始化 + 预训练权重（微调时用预训练权重初始化）
```

## 6. 训练实验管理与复现

**训练实验的三大纪律**（大模型训练/微调的标准实践）：

```text
① 固定随机种子（可复现）
   seed = 42
   random.seed(seed); np.random.seed(seed)
   torch.manual_seed(seed); torch.cuda.manual_seed_all(seed)
   注意：多卡训练 + 数据并行 shuffle 需要更细致的种子控制

② 实验记录（对比调参的前提）
   → WandB / MLflow / TensorBoard 至少用一种
   → 必记字段：超参数全量、数据版本、代码 commit、指标曲线
   → "调参不可复现"= 白调（最常见失败原因）

③ 评估协议固定
   → 同一验证集、同一指标、同一 seed 下对比
   → 早停依据固定（val loss 还是 val metric？）
```

**分布式训练基础**（LLM 训练的必备认知）：

| 方式 | 原理 | 适用 |
|------|------|------|
| **DDP**（数据并行） | 每卡一份模型副本，梯度 all-reduce | 模型能放进单卡时（默认首选） |
| **ZeRO**（DeepSpeed） | 模型状态分片（优化器/梯度/参数） | 大模型单机多卡（主流） |
| 张量并行（TP） | 单层矩阵切分到多卡 | 超大模型（70B+） |
| 流水线并行（PP） | 层分段到多卡 | 超大模型 |

```bash
# DeepSpeed ZeRO-2 微调 7B 模型（单机 4 卡示例）
deepspeed train.py --deepspeed ds_config.json \
  --model 7B-model --per_device_train_batch_size 1 --gradient_accumulation_steps 16
```

> 💡 面试衔接："训练 70B 模型需要什么"标准答链 = **ZeRO 分片 + 张量并行 + 混合精度（bf16）+ 梯度累积 + 检查点（offload）**——五件套缺一不可（详见 `05-模型部署与工程化/` 与 `08-模型微调与多模态/`）。
