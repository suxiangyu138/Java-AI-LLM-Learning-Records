## 1. 什么是强化学习

```text
强化学习 (Reinforcement Learning)：
  Agent 在环境中试错 → 根据奖励/惩罚 → 学习最优策略

核心循环：
  状态 S → 动作 A → 奖励 R → 新状态 S' → ...

类比：训练狗
  → 坐下（动作）→ 给零食（奖励）→ 学会坐下
  → 乱叫（动作）→ 不给零食（惩罚）→ 停止乱叫

关键挑战：延迟奖励
  → 当前动作的后果可能在很久之后才体现
  → 如何给当前动作分配"功劳"？
```

## 2. 核心概念

| 概念 | 符号 | 说明 |
|------|:---:|------|
| **状态 (State)** | S | 环境当前的情况 |
| **动作 (Action)** | A | Agent 可以做的选择 |
| **奖励 (Reward)** | R | 环境对动作的即时反馈 |
| **策略 (Policy)** | π(a\|s) | 在状态 s 下选择动作 a 的概率 |
| **价值 (Value)** | V(s) | 从状态 s 开始，预期能获得的累积奖励 |
| **Q 值** | Q(s,a) | 在状态 s 做动作 a 后，预期能获得的累积奖励 |
| **折扣因子** | γ | 未来奖励的折现率 (0~1) |

```text
MDP = (S, A, P, R, γ) — 强化学习的数学框架

  → Agent 的目标：找到最优策略 π*，使期望累积奖励最大化
  → 累积奖励 = R₀ + γR₁ + γ²R₂ + ...
  → γ 越小 → 越重视即时奖励（短视）
  → γ 越接近 1 → 越重视未来奖励（远见）
```

## 3. DQN：深度学习 + RL

### 3.1 核心思想

```text
DQN (Deep Q-Network) = 用神经网络近似 Q 函数

传统 Q-Learning：用表格存储每个 (s,a) 的 Q 值
  → 状态空间太大（如 Atari 游戏的像素）→ 表格不可行

DQN：用 CNN 输入游戏画面 → 输出每个动作的 Q 值
  → 解决了"状态空间爆炸"问题
```

### 3.2 两大创新

```text
① 经验回放 (Experience Replay)：
   存储 (s, a, r, s') 经验 → 随机采样训练
   → 打破样本间的相关性 → 训练更稳定

② 目标网络 (Target Network)：
   用两个网络：Q 网络（训练）+ Target 网络（固定，周期性更新）
   → 避免"追着自己尾巴跑"的不稳定

2013 年 DQN 在 Atari 游戏上超越人类 → RL 的转折点
```

## 4. Policy Gradient

### 4.1 与 DQN 的区别

```text
DQN：学习 Q(s,a) → 间接得到策略（选 Q 值最大的动作）
  → 适合离散动作空间（左/右/跳/射击）

Policy Gradient：直接学习策略 π(a|s)
  → 输出动作的概率分布
  → 适合连续动作空间（方向盘转角、机器人关节角度）

核心公式：
  ∇J = E[∇log π(a|s) × R]
  → 好动作（R 大）→ 增大其概率
  → 坏动作（R 小）→ 减小其概率
```

### 4.2 Actor-Critic

```text
Actor-Critic = Policy Gradient + Value Function

  Actor（策略网络 π）：决定做什么动作
  Critic（价值网络 V）：评判动作好坏

  → Actor 根据 Critic 的"评价"来改进策略
  → Critic 根据实际奖励来改进评估

这是 PPO 的前身 → PPO 是 RLHF 的优化算法
```

## 5. 从 RL 到 RLHF

```text
RLHF = RL 在人类偏好上的应用

  RL 框架          →  RLHF 对应
  ─────────────────────────────────
  Agent            →  LLM（生成回答）
  Action           →  选择下一个 token
  State            →  对话上下文
  Reward           →  人类偏好（Reward Model 评分）
  Policy Gradient  →  PPO 算法

RLHF 的核心：
  ① 训练 Reward Model（用人类偏好数据）
  ② 用 Reward Model 给 LLM 输出打分
  ③ 用 PPO 更新 LLM → 输出更符合人类偏好的文本
```

## 6. RL 算法家族对比

```text
强化学习算法三大流派（理解 RLHF 为什么选 PPO）：

① 值函数方法（Value-based）：DQN 系列
   学习"状态-动作"的价值 Q(s,a) → 选价值最高的动作
   适合：离散动作空间（游戏）
   代表：DQN / Double DQN / Rainbow

② 策略梯度方法（Policy-based）：REINFORCE / PPO
   直接学习策略 π(a|s) → 用奖励调整策略方向
   适合：连续动作空间（机器人控制）
   代表：REINFORCE / PPO / TRPO
   ⚠️ LLM 输出是"离散 token 序列"——策略梯度 + 大模型 = 天然匹配

③ Actor-Critic 混合：A2C / A3C / PPO
   Actor 学策略 + Critic 学价值（降低方差）
   PPO = Actor-Critic + 裁剪目标（更新不过猛）→ RLHF 的标准选择
```

| 算法 | 类型 | 核心机制 | 代表应用 |
|------|------|---------|---------|
| DQN | 值函数 | 经验回放 + 目标网络 | Atari 游戏 |
| REINFORCE | 策略梯度 | 奖励加权梯度 | 基础教学 |
| **PPO** | Actor-Critic | **裁剪目标 + 重要性采样** | **RLHF（LLM 对齐）** |
| SAC | 最大熵 | 熵正则 + 软更新 | 机器人控制 |

> 💡 为什么 RLHF 用 PPO 不用 DQN：LLM 的动作空间是词表（数十万 token）——值函数方法需要评估每个动作的价值，不现实；策略梯度直接优化生成策略，PPO 的裁剪防止"奖励黑客"（模型钻奖励模型空子）。

## 7. RL 三要素与马尔可夫决策过程

```text
强化学习的形式化框架（RLHF 理解的基础）：

三要素：
  Agent（智能体）：做决策的主体（如 LLM 策略）
  Environment（环境）：Agent 交互的对象（如用户/评分器）
  Reward（奖励）：环境对动作的反馈信号（如人类评分）

马尔可夫决策过程（MDP）：
  状态 S → 动作 A → 奖励 R → 新状态 S'
  马尔可夫性：下一状态只依赖当前状态与动作（不依赖历史）
  → RL 的目标：找到策略 π 使累计奖励最大化
  → 折扣因子 γ：未来奖励的折扣（γ<1，越远越不重要）

与监督学习的本质区别：
  监督学习：有正确答案（标签）→ 直接学映射
  强化学习：只有奖励信号 → 试错中探索（探索-利用权衡）
```

**RLHF 的完整链路（强化学习在 LLM 中的落地）**：

```text
① 收集人类偏好数据：同一 prompt 多个模型回答 → 人类排序
② 训练奖励模型（RM）：学习"哪个回答更好"的评分器
   → 本质 = 一个二分类/排序模型（GAN 判别器的思想！）
③ 用 RM 做奖励，PPO 微调 LLM：
   → 生成文本 → RM 打分 → 更新策略（PPO 裁剪防止更新过猛）
   → 加 KL 惩罚：防止模型偏离参考模型太远（避免"刷分"）
④ 结果：模型输出更符合人类偏好（对齐 Alignment）
```

> 💡 **面试衔接**：GAN 的判别器 → RLHF 的奖励模型，都是"评判者"角色——**对抗/评分的思路贯穿生成模型与对齐技术**（详见 `LLM/06-RLHF与对齐技术.md`）。

- 强化学习 = Agent 与环境交互 → 试错中学习最优策略

- PPO = Actor-Critic 的改进 → RLHF 的核心算法
