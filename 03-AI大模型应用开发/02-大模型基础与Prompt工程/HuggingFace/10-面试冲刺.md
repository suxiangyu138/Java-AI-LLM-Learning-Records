## 1. 20 道自测题

**A. 概念题（快速过）**

1. Transformers v5.0.0 发布节点与三大主题？（2026-01-27；模块化/统一分词/动态权重加载 + 互操作定位）
2. v5 取消了什么？只保留哪个后端？（Fast/Slow 双轨 → 统一 Rust；仅 PyTorch）
3. v5 加载时能做什么优化？（fuse_qkv/fuse_moe/量化/注意力，from_pretrained 一步到位）
4. 为什么用 safetensors 而不是 .bin？（防 pickle 恶意代码）
5. gated 模型怎么下载？（同意许可 + token + login / HF_TOKEN）
6. HF_ENDPOINT 什么时候设置？为什么？（任何 import 之前——只读一次）
7. 缓存变量 v4→v5 变化？（TRANSFORMERS_CACHE → HF_HOME）
8. LoRA 的原理一句话？（冻结原权重，训练低秩增量 W'=W+BA）

**B. 场景题（写代码/配置）**

9. 写出加载 7B 对话模型的标准三件套代码（AutoModelForCausalLM + device_map + torch_dtype）。
10. 24G 卡微调 7B 模型的完整方案？（QLoRA：4bit NF4 + LoRA r=16 lr=1e-4）
11. 写出 chat template 调用的正确姿势（v5 返回 BatchEncoding 直接喂）。
12. apply_chat_template 与手写模板的区别？（模型格式自动适配，换模型零改动）
13. 训练数据去重与清洗三件套？（deduplicate + 长度 filter + 抽查）
14. 训练中途断了怎么办？（resume_from_checkpoint=True）
15. LoRA 训练完怎么部署？（合并 merge_and_unload → 完整模型 → transformers serve）
16. 70B 模型下载到国内服务器的最快方式？（hfd.sh -x 16 多线程 + HF_ENDPOINT）

**C. 排查题（给现象找原因）**

17. 下载卡死/ConnectionError？（镜像没配 / gated 没登录）
18. 加载成功但 generate 报错？（AutoModel 用错类——对话必须 CausalLM）
19. 训练 loss 不降？（lr 太低 / 数据太脏 / LoRA 没生效）
20. 微调后通用能力崩了？（灾难性遗忘——训练数据混 10-20% 通用数据）

> 💡 自测标准：A 全对 + B 能写出来 + C 能定位 = 本体系毕业；B 卡壳回对应章节，C 卡壳回 03/05/06/09 章。

## 3. 高频面试题与答题范式

**Q1：Transformers v5 有哪些重大变化？**
> 范式：版本节点（2026-01-27，五年首个大版本）→ 三大重构（模块化架构 + 统一 Rust 分词 + 动态权重加载）→ 新能力（serve/连续批处理/分页注意力/量化一等公民）→ 破坏性变更（仅 PyTorch、HF_HOME、chat template 返回类型）。结尾带一句定位：互操作中枢。

**Q2：怎么在 24G 单卡上微调 7B 模型？**
> 范式：QLoRA 三步（4bit NF4 底座 + LoRA r=16 + lr=1e-4）→ 显存公式（约 10GB）→ Trainer 集成（等效 batch = 4×8）→ 合并部署。强调"效果 85-90%、成本低两个量级"。

**Q3：LoRA 与全量微调的取舍？**
> 范式：原理（低秩增量 W'=W+BA）→ 对比表（参数 0.1% / 显存 / 时间 / 效果 90%+）→ 场景（领域任务 LoRA、能力分布重建才全量）→ 多任务热切换（adapter 即产品）。

**Q4：模型加载有哪些坑？**
> 范式：Auto 类选错 → device_map/dtype → 量化（4bit NF4 单卡 70B）→ 镜像/token（国内必踩）→ v5 加载即优化（fuse/attention/量化一体）。给显存公式（参数×字节 + KV）。

**Q5：微调效果不好怎么排查？**
> 范式：数据优先（去重/清洗/质量 > 数量）→ 训练指标（loss 不降 = lr/冻结检查）→ 评估（前后对比 + 通用能力回测）→ 过拟合（eval 上升后下降）→ 灾难性遗忘（混通用数据）。核心观点：90% 是数据问题。

**Q6：推理部署怎么选型？**
> 范式：场景分档（开发 serve / 小流量 serve / 生产 vLLM / 边缘 llama.cpp）→ 优化顺序（量化 → Flash → 引擎）→ 协议统一（OpenAI 兼容，引擎切换无感）。提到 v5 的 continuous batching/paged_attention 已进标准库。

**Q7：国内环境怎么用 HuggingFace？**
> 范式：HF_ENDPOINT 镜像（import 前设置）→ hfd.sh 多线程 → gated token 透传 → ModelScope 备选 → 团队内网缓存。给实测数据（70B：直连 4 小时失败 vs 镜像 38 分钟）。

**Q8：怎么把模型做成产品？**
> 范式：完整链路（Hub 拿模型 → QLoRA 领域化 → Gradio Demo/Spaces → FastAPI 生产 API）→ 每层选型依据 → 成本与显存账。体现"从模型到产品"的全栈视角。
