## 1. json — JSON 序列化

```python
import json

# ① 基础用法（AI API 通信最常用）
data = {"model": "qwen3", "messages": [{"role": "user", "content": "hello"}]}
json_str = json.dumps(data, ensure_ascii=False)  # 中文不转义
parsed = json.loads(json_str)

# ② 文件读写
with open("config.json", "w") as f:
    json.dump(config, f, indent=2)       # 美化输出

# ③ 自定义序列化（datetime/dataclass 等不可直接序列化）
class CustomEncoder(json.JSONEncoder):
    def default(self, obj):
        if isinstance(obj, datetime):
            return obj.isoformat()
        return super().default(obj)
json.dumps(data, cls=CustomEncoder)
```

## 2. collections — 特殊容器

| 容器 | 用途 | AI 场景 |
|------|------|---------|
| `defaultdict` | 访问不存在的 key 自动创建默认值 | 按类别分组数据 |
| `Counter` | 计数统计 | Token 频率统计 |
| `deque` | 双端队列（两端 O(1)） | 滑动窗口（最近 N 轮对话） |
| `OrderedDict` | 保持插入顺序（Python 3.7+ dict 已默认有序） | 兼容老代码 |
| `namedtuple` | 轻量不可变对象 | 数据记录 |

```python
from collections import defaultdict, Counter, deque

# defaultdict：自动创建默认值
by_model = defaultdict(list)
for item in results:
    by_model[item["model"]].append(item)       # 无需先检查 key 是否存在

# Counter：计数
token_counts = Counter(tokens)
top10 = token_counts.most_common(10)

# deque：高效滑动窗口
recent = deque(maxlen=20)                      # 固定大小窗口
for msg in stream:
    recent.append(msg)                         # 自动丢弃最旧的
```

## 3. itertools — 高效迭代器

```python
from itertools import islice, chain, groupby

# 批量处理（AI 场景：分批调用 LLM，避免一次发太多）
batches = [list(islice(data, i, i+10)) for i in range(0, len(data), 10)]

# 扁平化嵌套列表
nested = [["a", "b"], ["c", "d"]]
flat = list(chain.from_iterable(nested))       # ['a', 'b', 'c', 'd']

# 按条件分组
sorted_data = sorted(data, key=lambda x: x["category"])
for cat, items in groupby(sorted_data, key=lambda x: x["category"]):
    print(f"{cat}: {len(list(items))}")
```

## 4. functools — 高阶函数工具

```python
from functools import lru_cache, partial, reduce

# ① @lru_cache：缓存函数结果（AI 场景：缓存 embedding）
@lru_cache(maxsize=10000)
def get_embedding(text: str) -> list[float]:
    return model.encode(text)                  # 相同文本只算一次

# ② partial：冻结部分参数
from functools import partial
call_gpt = partial(call_llm, model="gpt-5-turbo")  # 固定 model 参数

# ③ wraps：保留被装饰函数的元信息
from functools import wraps
def retry(max_times=3):
    def decorator(func):
        @wraps(func)                           # 保留 func.__name__/__doc__
        def wrapper(*args, **kwargs):
            for i in range(max_times):
                try: return func(*args, **kwargs)
                except Exception:
                    if i == max_times - 1: raise
            return None
        return wrapper
    return decorator
```

## 5. re — 正则表达式

```python
import re

# AI 文本处理常用模式
text = "Error: API timeout after 30.5 seconds"

re.findall(r"\d+\.?\d*", text)                 # 提取数字：['30.5']
re.sub(r"<[^>]+>", "", html)                   # 去除 HTML 标签
re.split(r"\s+", text)                         # 按空白分割

# 提取 Markdown 代码块（AI 输出解析常见需求）
code = re.findall(r"```python\n(.*?)```", response, re.DOTALL)

# 编译后复用（多次使用比直接调用快）
URL_PATTERN = re.compile(r"https?://\S+")
urls = URL_PATTERN.findall(text)
```

## 6. datetime / hashlib / csv 速览

```python
# datetime：时间处理（AI 日志/Token 配额的时间维度）
from datetime import datetime, timedelta
now = datetime.now()
next_hour = now + timedelta(hours=1)
now.isoformat()                    # '2026-08-01T17:30:00'

# hashlib：哈希（内容去重、缓存键）
import hashlib
cache_key = hashlib.md5(prompt.encode()).hexdigest()

# csv：表格数据读写
import csv
with open("eval_results.csv") as f:
    for row in csv.DictReader(f):
        print(row["model"], row["score"])
```
