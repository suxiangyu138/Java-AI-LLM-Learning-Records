## 1. os — 操作系统交互

```python
import os

# 环境变量（AI 项目最常用：API Key、模型路径等）
api_key = os.getenv("OPENAI_API_KEY")          # 安全读取
os.environ["MODEL_PATH"] = "/models/qwen3"      # 设置（仅当前进程）

# 路径操作（推荐用 pathlib 替代，见 3 节）
os.path.join("data", "images", "cat.jpg")       # data/images/cat.jpg
os.path.exists("config.yaml")                   # 文件是否存在
os.path.basename("/path/to/file.txt")           # file.txt

# 目录操作
os.makedirs("output/models", exist_ok=True)     # 递归创建
os.listdir("data")                              # 列出目录内容

# 进程信息
pid = os.getpid()                               # 当前进程 ID
```

## 2. sys — Python 解释器交互

```python
import sys

# 命令行参数（AI 脚本最常用）
# python train.py --epochs 10 --lr 0.001
args = sys.argv          # ['train.py', '--epochs', '10', '--lr', '0.001']

# Python 版本与平台
sys.version_info         # sys.version_info(major=3, minor=12, micro=0)
sys.platform             # 'linux' / 'win32' / 'darwin'

# 退出程序
sys.exit(0)              # 0=成功，非0=错误

# 递归深度（处理深层嵌套 JSON 时可能需要调大）
sys.setrecursionlimit(2000)

# sys.modules — 所有已加载模块
import json
sys.modules['json']      # <module 'json' from '...'>
```

**os vs sys 一句话：** os 管操作系统、sys 管 Python 解释器本身。

## 3. pathlib — 现代路径操作（推荐）

```python
from pathlib import Path

# ★ 新项目优先用 pathlib，比 os.path 更面向对象
data_dir = Path("data") / "images"              # 用 / 拼接路径！
config = Path("config.yaml")

# 读写
text = config.read_text(encoding="utf-8")       # 一行读文件
config.write_text("key: value")                  # 一行写文件
data = Path("data.bin").read_bytes()             # 读二进制

# 判断与遍历
config.exists()                                  # 是否存在
data_dir.is_dir()                                # 是否目录
list(data_dir.glob("*.jpg"))                    # 通配符匹配
list(data_dir.rglob("*.py"))                     # 递归匹配

# 路径信息
Path(__file__).parent                           # 当前文件所在目录
Path.home()                                     # 用户主目录
```

**AI 场景：** `model_path = Path.home() / ".cache" / "models" / "qwen3"`

## 4. subprocess — 外部命令执行

```python
import subprocess

# ① 执行命令并获取输出
result = subprocess.run(
    ["git", "rev-parse", "HEAD"],
    capture_output=True, text=True, check=True
)
print(result.stdout.strip())    # commit hash

# ② 管道（用 vLLM 启动模型服务）
proc = subprocess.Popen(
    ["vllm", "serve", "Qwen/Qwen3-7B", "--port", "8000"],
    stdout=subprocess.PIPE, stderr=subprocess.STDOUT
)

# ⚠️ 永远用列表传参（不用字符串），防 shell 注入
# ❌ subprocess.run("rm -rf " + user_input, shell=True)  # 危险！
# ✅ subprocess.run(["rm", "-rf", user_input])
```

## 5. shutil + tempfile — 高级文件操作

```python
import shutil, tempfile

# shutil：高级文件操作
shutil.copy("src.txt", "dst.txt")              # 复制
shutil.copytree("src_dir", "dst_dir")          # 递归复制目录
shutil.rmtree("old_models")                     # 递归删除
shutil.make_archive("backup", "zip", "data")    # 打包
shutil.disk_usage("/")                          # 磁盘空间

# tempfile：临时文件（AI 场景：临时存储中间结果）
with tempfile.TemporaryDirectory() as tmpdir:   # 自动清理！
    tmp_path = Path(tmpdir) / "intermediate.npy"
    # 处理... 退出 with 后自动删除
```

## 6. argparse — 命令行参数解析

```python
# AI 训练/推理脚本的标准参数解析方式
import argparse

parser = argparse.ArgumentParser(description="模型训练脚本")
parser.add_argument("--epochs", type=int, default=10)
parser.add_argument("--lr", type=float, default=0.001)
parser.add_argument("--model", required=True, help="模型路径")
parser.add_argument("--debug", action="store_true")    # 开关

args = parser.parse_args()
print(f"Training {args.model} for {args.epochs} epochs")
```

## 7. logging — 日志系统

```python
import logging

# 基础配置（AI 项目最简方式）
logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s [%(levelname)s] %(message)s"
)
logger = logging.getLogger(__name__)

logger.info(f"模型加载完成：{model_name}")     # 信息
logger.warning("Token 使用量超过预期")        # 警告
logger.error(f"API 调用失败：{e}")             # 错误

# ⚠️ AI 项目常见错误：用 print 而不是 logging
# print 无法控制级别、没有时间戳、无法重定向到文件
```

## 8. 模块速查总表

| 需求 | 模块 | 首选 API |
|------|------|----------|
| 读环境变量 | os | `os.getenv("KEY")` |
| 拼接路径 | **pathlib** | `Path("a") / "b"` |
| 读文件 | pathlib | `Path(p).read_text()` |
| 执行外部命令 | subprocess | `subprocess.run([...])` |
| 临时文件 | tempfile | `TemporaryDirectory()` |
| 打包/递归删除 | shutil | `copytree()` / `rmtree()` |
| 命令行参数 | argparse | `ArgumentParser()` |
| 打日志 | logging | `logging.getLogger(__name__)` |

---

> 🎯 **核心要点**：AI 项目的"胶水层"标准组合 — **pathlib 处理路径 + os.getenv 读配置 + subprocess 启动推理服务 + argparse 传参数 + logging 打日志**。永远用 pathlib 替代 os.path，用 subprocess 替代 os.system。
