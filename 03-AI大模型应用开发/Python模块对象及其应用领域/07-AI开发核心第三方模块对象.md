## 1. numpy.ndarray — 多维数组

```python
import numpy as np

# ① 创建数组
arr = np.array([1, 2, 3])                    # 从列表创建
zeros = np.zeros((3, 4))                     # 全零
rand = np.random.randn(100, 768)             # 随机（模拟 100 条 embedding）

# ② 核心属性
arr.shape       # (100, 768)   — 形状
arr.dtype       # float32      — 数据类型
arr.ndim        # 2            — 维度数

# ③ 核心操作（全部向量化，无 Python 循环 — 快 10-100 倍）
arr * 2                     # 广播：每个元素 ×2
arr @ arr.T                 # 矩阵乘法
arr.mean(axis=0)            # 按列求均值
arr.reshape(10, 10)         # 变形

# ④ AI 场景：embedding 运算
embeddings = np.array(model.encode(texts))        # (N, 768)
similarities = embeddings @ embeddings.T          # 余弦相似度矩阵
top_k = np.argsort(similarities[0])[-5:]           # 最相似的 5 个
```

## 2. pandas.DataFrame — 表格数据

```python
import pandas as pd

# ① 创建
df = pd.DataFrame({
    "model": ["gpt-5", "claude-sonnet", "qwen3"],
    "score": [0.92, 0.89, 0.85],
    "tokens": [1500, 1200, 900]
})

# ② AI 场景：评估结果分析
df.head()                    # 前 5 行
df["score"].mean()           # 平均分
df[df["score"] > 0.9]        # 筛选
df.sort_values("score", ascending=False)  # 排序
df.groupby("model")["tokens"].sum()       # 按模型分组统计 Token

# ③ 读写（AI 评测结果的存储格式）
df.to_csv("eval_results.csv", index=False)
df.to_json("results.json", orient="records")
df = pd.read_csv("eval_results.csv")

# ④ Series：单列数据（DataFrame 的列就是 Series）
df["score"].describe()       # count/mean/std/min/max 汇总统计
```

## 3. torch.Tensor — GPU 加速+自动微分

```python
import torch

# ① 创建（与 numpy 几乎相同的 API）
t = torch.tensor([1.0, 2.0, 3.0])
t = torch.randn(32, 768)                     # 随机张量

# ② GPU 加速（一行迁移）
t_gpu = t.to("cuda")                         # 移到 GPU
t_cpu = t_gpu.to("cpu")                      # 移回 CPU

# ③ 自动微分（训练的核心）
x = torch.tensor([2.0], requires_grad=True)
y = x ** 2                                   # y = x²
y.backward()                                 # 自动计算 dy/dx = 2x = 4
print(x.grad)  # tensor([4.])   ✅

# ④ AI 场景：模型推理
model = AutoModel.from_pretrained("qwen/Qwen3-7B")
input_ids = tokenizer("Hello", return_tensors="pt").to("cuda")
with torch.no_grad():                        # 推理不需要梯度
    output = model(**input_ids)

# ⑤ 保存/加载
torch.save(model.state_dict(), "model.pt")   # 保存权重
model.load_state_dict(torch.load("model.pt")) # 加载权重
```

## 4. PIL.Image — 图像处理

```python
from PIL import Image

# ① 基本操作
img = Image.open("cat.jpg")
img = img.resize((512, 512))                 # 缩放
img = img.convert("RGB")                     # 统一格式
img.save("processed.png")

# ② AI 场景：多模态模型的图像预处理
from transformers import AutoProcessor
processor = AutoProcessor.from_pretrained("Qwen/Qwen-VL")
# PIL Image → 模型输入
inputs = processor(images=img, text="描述这张图", return_tensors="pt")
```

## 5. 对象互转换速查

```text
numpy.ndarray ←→ torch.Tensor：
  tensor = torch.from_numpy(ndarray)
  ndarray = tensor.numpy()                    # ⚠️ 仅 CPU tensor

numpy.ndarray ←→ PIL.Image：
  img = Image.fromarray(ndarray.astype('uint8'))
  ndarray = np.array(img)

pandas.DataFrame ←→ numpy.ndarray：
  ndarray = df.to_numpy()
  df = pd.DataFrame(ndarray, columns=['...'])

pandas.DataFrame → list[dict]（JSON API 常用）：
  records = df.to_dict(orient='records')      # [{col: val, ...}, ...]
```

**AI 数据流的常见路径：**
```text
原始数据 → pandas 清洗/分析 → numpy 数组化 → torch 张量化 → GPU 模型推理
JSON API 响应 → dict → pandas DataFrame → 统计分析/可视化
```
