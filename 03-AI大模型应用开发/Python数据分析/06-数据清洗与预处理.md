## 1. 缺失值处理

### 1.1 检测缺失值

```python
import pandas as pd
import numpy as np

# 缺失值全景
df.isnull().sum()                    # 每列缺失计数
df.isnull().sum() / len(df)          # 每列缺失比例
df.isnull().sum(axis=1).value_counts()  # 每行缺失列数分布

import missingno as msno
msno.matrix(df)  # 缺失值可视化矩阵
```

### 1.2 处理策略

```python
# 策略 1：删除（缺失率 > 50% 的列）
threshold = 0.5
df = df.dropna(axis=1, thresh=int((1 - threshold) * len(df)))

# 策略 2：填充
df["age"].fillna(df["age"].median(), inplace=True)          # 中位数
df["category"].fillna("未知", inplace=True)                  # 固定值
df["amount"].fillna(df.groupby("category")["amount"]        # 分组均值
                    .transform("mean"), inplace=True)
df["next"].fillna(method="ffill", inplace=True)             # 前向填充（时间序列）
df["prev"].fillna(method="bfill", inplace=True)             # 后向填充

# 策略 3：插值（时间序列最常用）
df["value"].interpolate(method="linear", inplace=True)       # 线性插值
df["value"].interpolate(method="time", inplace=True)         # 时间插值

# 策略 4：标记缺失
df["age_is_missing"] = df["age"].isnull().astype(int)        # 保留缺失信号
df["age"].fillna(-1, inplace=True)
```

## 2. 异常值检测与处理

### 2.1 检测方法

```python
# 方法 1：Z-Score（适用：正态分布）
from scipy import stats
z_scores = np.abs(stats.zscore(df["amount"].dropna()))
outliers_z = df[z_scores > 3]

# 方法 2：IQR（适用：有偏分布）
Q1 = df["amount"].quantile(0.25)
Q3 = df["amount"].quantile(0.75)
IQR = Q3 - Q1
lower = Q1 - 1.5 * IQR
upper = Q3 + 1.5 * IQR
outliers_iqr = df[(df["amount"] < lower) | (df["amount"] > upper)]

# 方法 3：百分位数
lower_percentile = df["amount"].quantile(0.01)   # 1% 分位
upper_percentile = df["amount"].quantile(0.99)   # 99% 分位

# 可视化检测
import seaborn as sns
sns.boxplot(data=df, y="amount")
sns.histplot(data=df, x="amount", bins=50)
```

### 2.2 处理策略

```python
# 裁剪（capping）：最安全的方式
df["amount_capped"] = df["amount"].clip(
    lower=df["amount"].quantile(0.01),
    upper=df["amount"].quantile(0.99)
)

# 标记 + 保留
df["is_outlier"] = ((df["amount"] < lower) | (df["amount"] > upper)).astype(int)

# 替换（如果确定是错误）
df.loc[df["age"] < 0, "age"] = np.nan
df.loc[df["age"] > 120, "age"] = np.nan
```

## 3. 数据类型转换

```python
# 字符串 → 数字
df["price"] = df["price"].str.replace("¥", "").str.replace(",", "")
df["price"] = pd.to_numeric(df["price"], errors="coerce")  # coerce=转换失败变NaN

# 字符串 → 日期
df["date"] = pd.to_datetime(df["date"])
df["date"] = pd.to_datetime(df["date"], format="%Y年%m月%d日", errors="coerce")

# 分类变量
df["category"] = df["category"].astype("category")  # 更省内存

# 类型优化（减少内存）
df["int_col"] = pd.to_numeric(df["int_col"], downcast="integer")
df["float_col"] = pd.to_numeric(df["float_col"], downcast="float")

# 内存使用报告
print(df.memory_usage(deep=True) / 1024**2)  # MB
```

## 4. 重复值处理

```python
# 检测
df.duplicated().sum()                        # 完全重复行数
df.duplicated(subset=["user_id"]).sum()      # 某列值重复

# 定位
df[df.duplicated(subset=["user_id"], keep=False)]  # 所有重复行（包括首条）

# 处理
df.drop_duplicates(subset=["user_id"], keep="first", inplace=True)
df.drop_duplicates(subset=["user_id"], keep="last", inplace=True)  # 保留最后一条
```

## 5. 特征编码与标准化

### 5.1 编码

```python
# 1. Label Encoding（有序类别）
df["education_level"] = df["education"].map({
    "小学": 1, "初中": 2, "高中": 3, "本科": 4, "硕士": 5
})

# 2. One-Hot Encoding（无序类别）
df = pd.get_dummies(df, columns=["category", "region"], drop_first=True)

# 3. Frequency Encoding（高基数类别）
freq = df["city"].value_counts(normalize=True)
df["city_freq"] = df["city"].map(freq)
```

### 5.2 标准化与归一化

```python
from sklearn.preprocessing import StandardScaler, MinMaxScaler

# 标准化（Z-Score）：均值为 0，标准差为 1 → 适合大多算法
scaler = StandardScaler()
df[["age", "income"]] = scaler.fit_transform(df[["age", "income"]])

# 归一化（MinMax）：缩放到 [0, 1] → 神经网络/距离计算
scaler = MinMaxScaler()
df["score"] = scaler.fit_transform(df[["score"]])
```

## 核心要点回顾

- 缺失值：先看比例 → >50% 删列 → 数值用中位数/分组均值 → 类别用"未知" → 时间序列插值
- 异常值：先检测（Z-Score/IQR/百分位）→ 首选裁剪 > 标记 > 替换
- IQR 比 Z-Score 更稳健（不受极端值影响）
- 类型转换：`pd.to_numeric(errors="coerce")` 是最安全的方式
- 编码：有序用 Label，无序用 One-Hot，高基数用 Frequency
- 标准化 = 几乎所有 ML 模型的必做步骤
