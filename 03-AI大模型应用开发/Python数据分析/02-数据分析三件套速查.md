> **核心摘要**：Pandas、NumPy、Matplotlib 是 Python 数据分析的三大核心库。本文提供常用代码速查表、最简学习路线和完整可运行的实战模板。

## 一、Pandas 最常用代码速查表

### 1.1 读写数据

```python
import pandas as pd
import numpy as np

df = pd.read_csv("data.csv")
df = pd.read_excel("data.xlsx")
df.to_csv("out.csv", index=False)
df.to_excel("out.xlsx", index=False)
```

### 1.2 查看数据

```python
df.head()      # 前 5 行
df.tail()      # 后 5 行
df.info()      # 基本信息
df.describe()  # 描述性统计
df.columns     # 列名
df.shape       # 形状
```

### 1.3 缺失值处理

```python
df.isnull().sum()
df.dropna()
df.fillna(0)
df.fillna(df.mean())
```

### 1.4 条件筛选

```python
df[df["年龄"] > 18]
df[(df["性别"] == "男") & (df["分数"] >= 60)]
```

### 1.5 分组聚合

```python
df.groupby("班级")["分数"].mean()
df.groupby("性别")["金额"].sum()
```

### 1.6 多表合并

```python
pd.merge(df1, df2, on="id")
pd.concat([df1, df2])
```

### 1.7 透视表

```python
pd.pivot_table(df, index="地区", values="销售额", aggfunc="sum")
```

6. 做 2-3 个实战项目：销售分析、学生成绩、用户消费分析

## 三、完整可运行实战模板

```python
import pandas as pd
import matplotlib.pyplot as plt

plt.rcParams["font.sans-serif"] = ["SimHei"]
plt.rcParams["axes.unicode_minus"] = False

# 1. 读取数据
df = pd.DataFrame({
    "姓名": ["张三", "李四", "王五", "赵六"],
    "性别": ["男", "女", "男", "女"],
    "成绩": [85, 92, 78, 90]
})

# 2. 查看基础信息
print("数据形状：", df.shape)
print(df.describe())

# 3. 缺失值检查
print(df.isnull().sum())

# 4. 分组统计
print(df.groupby("性别")["成绩"].mean())

# 5. 可视化
df.groupby("性别")["成绩"].mean().plot(kind="bar")
plt.title("男女平均成绩对比")
plt.show()
```
