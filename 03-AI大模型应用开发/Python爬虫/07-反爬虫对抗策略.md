## 1. 反爬手段全景

| 反爬层级 | 技术手段 | 对抗方案 |
|------|------|---------|
| **L1 请求层** | UA 检测 / Referer 校验 | Headers 伪装 |
| **L2 频率层** | 429 限流 / IP 封禁 | IP 代理池 + 延迟 |
| **L3 行为层** | 验证码 / 鼠标轨迹 | 验证码识别 / 模拟操作 |
| **L4 指纹层** | JS 指纹 / TLS 指纹 | Stealth 方案 / 降级 |
| **L5 数据层** | 字体反爬 / CSS 偏移 / 图片化 | OCR / 逆向分析 |

> 🎯 层级越高，对抗成本越大。大部分场景在 L1-L2 就能解决

## 3. IP 代理策略

### 3.1 代理来源

| 来源 | 质量 | 成本 | 适用 |
|------|:---:|------|------|
| 免费代理 | ⭐ | 免费 | 学习测试 |
| 收费代理 API | ⭐⭐⭐⭐ | ¥0.01-0.1/IP | 中小项目 |
| 住宅代理 | ⭐⭐⭐⭐⭐ | ¥1-10/IP | 严格反爬网站 |
| 自建代理池 | ⭐⭐⭐ | 服务器成本 | 大规模爬虫 |
| ADSL 拨号 | ⭐⭐⭐⭐ | 宽带费 | 换 IP 最频繁 |

### 3.2 代理池架构

```python
import random
import requests
import threading
import time

class ProxyPool:
    """简易代理池"""

    def __init__(self):
        self._proxies = []
        self._lock = threading.Lock()

    def fetch_proxies(self, api_url: str):
        """从代理 API 拉取"""
        resp = requests.get(api_url)
        self._proxies = resp.json()["data"]

    def get(self) -> str:
        with self._lock:
            if not self._proxies:
                return None
            return random.choice(self._proxies)

    def remove(self, proxy: str):
        with self._lock:
            if proxy in self._proxies:
                self._proxies.remove(proxy)

    def validate(self, test_url="https://httpbin.org/ip", timeout=5):
        """验证代理可用性"""
        valid = []
        for proxy in self._proxies:
            try:
                r = requests.get(test_url, proxies={"https": proxy}, timeout=timeout)
                if r.status_code == 200:
                    valid.append(proxy)
            except Exception:
                pass
        self._proxies = valid
        print(f"有效代理: {len(valid)}/{len(self._proxies) + len(valid)}")

    def auto_refresh(self, api_url, interval=300):
        """定时刷新"""
        def _refresh():
            while True:
                self.fetch_proxies(api_url)
                self.validate()
                time.sleep(interval)
        threading.Thread(target=_refresh, daemon=True).start()
```

## 4. 验证码识别

### 4.1 方案对比

| 方案 | 准确率 | 速度 | 成本 | 适用 |
|------|:---:|:---:|------|------|
| 打码平台（2Captcha） | 95%+ | 5-15s | $0.5-3/1000次 | 通用 |
| OCR (Tesseract/ddddocr) | 70-85% | <1s | 免费 | 简单验证码 |
| 深度学习模型 | 95%+ | <1s | 训练成本 | 定制场景 |
| 人工打码 | 99%+ | 10-30s | ¥5-20/1000次 | 复杂验证码 |

### 4.3 打码平台集成

```python
# 2Captcha 示例
import requests
import time

API_KEY = "your-2captcha-key"

# 提交验证码
resp = requests.post("http://2captcha.com/in.php", data={
    "key": API_KEY,
    "method": "base64",
    "body": base64.b64encode(open("captcha.png","rb").read()).decode(),
    "json": 1
})
captcha_id = resp.json()["request"]

# 轮询结果
for _ in range(20):
    time.sleep(3)
    r = requests.get("http://2captcha.com/res.php", params={
        "key": API_KEY, "action": "get", "id": captcha_id, "json": 1
    })
    if r.json()["status"] == 1:
        print(f"识别结果: {r.json()['request']}")
        break
```

## 5. 浏览器指纹与 TLS 指纹

### 5.1 主流反指纹方案

| 方案 | 原理 | 推荐度 |
|------|------|:---:|
| **curl_cffi** | 模拟浏览器 TLS 指纹（Python） | ⭐⭐⭐⭐⭐ |
| **Playwright Stealth** | 修补 navigator/webdriver 等 JS 属性 | ⭐⭐⭐⭐ |
| **Selenium Undetected** | 深度修补 Chromedriver | ⭐⭐⭐ |
| **Scrapy + curl_cffi** | 在 Scrapy 中使用 curl_cffi 下载器 | ⭐⭐⭐⭐ |

### 5.2 curl_cffi 使用

```python
# pip install curl_cffi
from curl_cffi import requests

# 模拟 Chrome 120 的 TLS 指纹（Cloudflare 验证能过！）
resp = requests.get(
    "https://example.com",
    impersonate="chrome120",       # ← 模拟浏览器 TLS 指纹
    headers={"User-Agent": "..."}
)

# 可用 impersonate 值：
# chrome99/100/101/104/107/110/116/119/120/123/124
# safari15_3/15_5/17_0
# edge99/101
```

> 🎯 `curl_cffi` 是 2024-2025 年反爬领域最实用的 Python 库——直接绕过 Cloudflare 和大多数 WAF 的 TLS 指纹检测

## 核心要点回顾

- 反爬层级：L1 Headers → L2 频率 → L3 验证码 → L4 指纹 → L5 数据加密
- Headers 完整复制浏览器（包括 Sec-* 系列）
- 代理池 = 拉取 → 验证 → 使用 → 失效移除 → 定时刷新
- 验证码：简单用 ddddocr（免费），通用用 2Captcha（便宜），定制用 DL 模型
- TLS 指纹：**curl_cffi 是当前最佳方案**，模拟浏览器指纹过 Cloudflare
- 反爬成本每升一级涨 5-10x，优先从最低成本方案开始
