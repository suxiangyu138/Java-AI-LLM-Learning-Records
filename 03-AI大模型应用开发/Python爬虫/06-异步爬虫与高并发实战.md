## 1. 同步 vs 异步原理

```text
同步（串行）—— 100 个请求
请求1 ████████░░ 等待 I/O ░░
      请求2 ████████░░ 等待 ░░
            请求3 ████████░░ 等待 ░░
总时间：100 × 1s = 100s

异步（并发）—— 100 个请求
请求1 ████░░
请求2 ████░░
请求3 ████░░
...
请求100 ████░░
总时间：~1s（取决于并发数）
```

> 🎯 爬虫 99% 的时间在等待网络 I/O。异步让 CPU 在等待 A 的响应时去处理 B 的请求

## 2. asyncio 基础

### 2.1 核心概念

```python
import asyncio

# async def = 协程函数
async def fetch(url: str) -> str:
    print(f"开始: {url}")
    await asyncio.sleep(1)     # 模拟 I/O（用 await 释放控制权）
    print(f"完成: {url}")
    return f"data from {url}"

# 并发运行
async def main():
    urls = [f"https://page{i}.com" for i in range(10)]

    # 方式一：asyncio.gather（并发执行，等全部完成）
    results = await asyncio.gather(*[fetch(u) for u in urls])

    # 方式二：asyncio.create_task（更灵活的任务管理）
    tasks = [asyncio.create_task(fetch(u)) for u in urls]
    for task in asyncio.as_completed(tasks):     # 完成一个处理一个
        result = await task
        print(f"获得: {result}")

asyncio.run(main())
```

### 2.2 协程 vs 线程

| 维度 | 协程 (asyncio) | 线程 (threading) |
|------|:---:|:---:|
| 切换开销 | 极低（用户态） | 较高（内核态） |
| 内存占用 | ~1KB/协程 | ~1MB/线程 |
| 适合场景 | I/O 密集（爬虫！） | CPU 密集 |
| 并发上限 | 10,000+ | 100-1000 |
| GIL 影响 | 无（单线程） | 有 |

## 3. aiohttp 异步请求

### 3.1 基础用法

```python
# pip install aiohttp
import aiohttp
import asyncio

async def fetch(session: aiohttp.ClientSession, url: str) -> str:
    async with session.get(url) as resp:
        return await resp.text()

async def main():
    # 创建 Session（复用连接池）
    async with aiohttp.ClientSession(
        headers={"User-Agent": "Mozilla/5.0 ..."},
        timeout=aiohttp.ClientTimeout(total=10)
    ) as session:
        urls = [f"https://httpbin.org/delay/1" for _ in range(10)]
        tasks = [fetch(session, url) for url in urls]
        results = await asyncio.gather(*tasks, return_exceptions=True)

        for i, result in enumerate(results):
            if isinstance(result, Exception):
                print(f"请求 {i} 失败: {result}")
            else:
                print(f"请求 {i} 成功: {len(result)} bytes")

asyncio.run(main())
```

### 3.2 Session 配置

```python
session = aiohttp.ClientSession(
    headers={"User-Agent": "..."},
    timeout=aiohttp.ClientTimeout(
        total=30,        # 整体超时
        connect=5,       # 连接超时
        sock_read=10     # 读取超时
    ),
    connector=aiohttp.TCPConnector(
        limit=50,                    # 全局并发连接数
        limit_per_host=10,           # 单主机并发数
        ttl_dns_cache=300,           # DNS 缓存（秒）
        use_dns_cache=True,
    ),
    cookie_jar=aiohttp.CookieJar(),  # Cookie 自动管理
    trust_env=True,                  # 使用系统代理设置
)
```

### 4.2 速率限制（Token Bucket）

```python
import time

class RateLimiter:
    """令牌桶限速器"""

    def __init__(self, rate: int, per: float = 1.0):
        self.rate = rate          # 令牌产生速率（个/秒）
        self.per = per            # 时间窗口
        self.allowance = rate     # 当前令牌数
        self.last_check = time.monotonic()

    async def wait(self):
        while True:
            now = time.monotonic()
            elapsed = now - self.last_check
            self.last_check = now
            self.allowance += elapsed * (self.rate / self.per)
            if self.allowance > self.rate:
                self.allowance = self.rate
            if self.allowance >= 1:
                self.allowance -= 1
                return
            await asyncio.sleep(0.01)

# 使用：每秒最多 5 个请求
limiter = RateLimiter(rate=5, per=1.0)

async def fetch(url):
    await limiter.wait()
    async with session.get(url) as resp:
        return await resp.text()
```

## 5. 完整异步爬虫模板

```python
import asyncio
import aiohttp
from bs4 import BeautifulSoup

class AsyncCrawler:
    def __init__(self, concurrency=10, rate_limit=20):
        self.sem = asyncio.Semaphore(concurrency)
        self.limiter = RateLimiter(rate_limit)
        self.results = []

    async def fetch(self, session, url):
        await self.limiter.wait()
        async with self.sem:
            try:
                async with session.get(url, timeout=aiohttp.ClientTimeout(10)) as r:
                    if r.status == 200:
                        return await r.text()
                    print(f"[{r.status}] {url}")
            except Exception as e:
                print(f"[ERR] {url}: {e}")
            return None

    async def parse(self, html, url):
        """子类重写此方法"""
        soup = BeautifulSoup(html, "lxml")
        return soup.title.text if soup.title else ""

    async def worker(self, session, url):
        html = await self.fetch(session, url)
        if html:
            data = await self.parse(html, url)
            self.results.append(data)

    async def run(self, urls):
        conn = aiohttp.TCPConnector(limit=50, limit_per_host=10)
        async with aiohttp.ClientSession(
            headers={"User-Agent": "Mozilla/5.0 ..."},
            connector=conn
        ) as session:
            tasks = [self.worker(session, u) for u in urls]
            await asyncio.gather(*tasks)
        return self.results

# 使用
crawler = AsyncCrawler(concurrency=10, rate_limit=20)
urls = [f"https://example.com/page/{i}" for i in range(100)]
results = asyncio.run(crawler.run(urls))
print(f"完成: {len(results)} 条数据")
```

## 核心要点回顾

- 异步核心：协程用 `await` 释放控制权 → asyncio 调度其他协程
- `asyncio.Semaphore(10)` 控制并发数，比线程池更轻量
- `aiohttp.ClientSession` 复用连接池，全局只创建一次
- 限速：Semaphore（并发上限）+ RateLimiter（速率上限）双控
- 协程并发上限 10,000+ vs 线程 100-1000，爬虫场景协程完胜
