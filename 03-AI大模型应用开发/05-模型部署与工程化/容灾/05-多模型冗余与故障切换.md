## 1. 冗余架构设计

```text
三级冗余模型：

  ┌────────────────────────────────────────┐
  │  Tier 1: 主模型 (Primary)              │
  │  GPT-4o (OpenAI)                  90%  │
  ├────────────────────────────────────────┤
  │  Tier 2: 同级别备选 (Hot Standby)      │
  │  Claude Sonnet (Anthropic)         7%  │
  ├────────────────────────────────────────┤
  │  Tier 3: 轻量兜底 (Warm Standby)       │
  │  Qwen-7B (自建 vLLM)               3%  │
  └────────────────────────────────────────┘

切换策略：
  主模型故障 → 自动切 Tier 2 (<1s) → Tier 2 故障 → 切 Tier 3
  主模型恢复 → 自动切回 Tier 1
```

## 2. 故障检测与切换

```python
import asyncio
from typing import Optional

class MultiModelRouter:
    """多模型路由器 — 带健康检查和自动切换"""
    
    def __init__(self):
        self.models = [
            {"name": "gpt-4o", "provider": "openai", 
             "health_url": "https://status.openai.com/api/v2/status.json",
             "priority": 1, "healthy": True},
            {"name": "claude-sonnet", "provider": "anthropic",
             "health_url": "https://status.anthropic.com/api/v2/status.json",
             "priority": 2, "healthy": True},
            {"name": "qwen-7b", "provider": "self-hosted",
             "health_url": "http://localhost:8000/health",
             "priority": 3, "healthy": True},
        ]
        self._health_check_task = None
    
    async def start_health_check(self, interval=10):
        """定期健康检查"""
        async def check_loop():
            while True:
                for model in self.models:
                    model["healthy"] = await self._check_health(model)
                await asyncio.sleep(interval)
        self._health_check_task = asyncio.create_task(check_loop())
    
    async def _check_health(self, model):
        try:
            resp = await asyncio.wait_for(
                http_get(model["health_url"]), timeout=5
            )
            return resp.status == 200
        except:
            return False
    
    def get_model(self):
        """获取当前最优可用模型"""
        available = [m for m in self.models if m["healthy"]]
        if not available:
            raise AllModelsUnavailableError("所有模型不可用！")
        return min(available, key=lambda m: m["priority"])
```
