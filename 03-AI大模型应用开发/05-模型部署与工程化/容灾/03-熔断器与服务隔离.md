## 1. 熔断器原理

```text
熔断器 (Circuit Breaker) = 电气保险丝在软件中的实现

核心思想：当依赖服务连续失败时，直接"熔断" — 快速失败而非等待超时

没有熔断器：
  调用 LLM API → 超时(30s) → 线程阻塞 30s → 线程池耗尽 → 整个服务挂掉

有熔断器：
  调用 LLM API → 超时 → 记录失败 → 连续失败 5 次 → 熔断打开
  → 后续请求直接返回 fallback（<1ms）→ 不阻塞线程 → 保护系统
```

## 2. 三态状态机

```text
         ┌─────────────────────────────────────┐
         │           熔断器状态机               │
         │                                      │
         │    ┌──────────┐   失败达到阈值       │
         │    │  CLOSED   │ ─────────────────→  │
         │    │ (正常)    │                      │
         │    └──────────┘   成功重置计数        │
         │         ↑                ↓            │
         │         │           ┌──────────┐     │
         │         │           │   OPEN    │     │
         │         │           │ (熔断)    │     │
         │         │           └──────────┘     │
         │         │                ↓            │
         │         │      等待 sleep_window      │
         │         │                ↓            │
         │    ┌──────────┐   ┌──────────┐       │
         │    │  CLOSED   │ ← │ HALF-OPEN│       │
         │    │ (恢复正常) │   │ (探测)   │       │
         │    └──────────┘   └──────────┘       │
         │         ↑               ↓             │
         │         └── 探测成功 ───┘             │
         │              探测失败 → 回到 OPEN     │
         └─────────────────────────────────────┘

CLOSED：正常调用，统计失败次数
OPEN：直接快速失败，不调用依赖
HALF-OPEN：放少量请求探测，成功→CLOSED，失败→OPEN
```

## 3. LLM 熔断器实现

```python
import time
import threading
from enum import Enum
from collections import deque

class CircuitState(Enum):
    CLOSED = "closed"
    OPEN = "open"
    HALF_OPEN = "half_open"

class LLMCircuitBreaker:
    """LLM 专用熔断器 — 按模型粒度"""
    
    def __init__(self, 
                 failure_threshold=5,      # 连续失败 N 次 → 熔断
                 success_threshold=3,       # 探测成功 N 次 → 恢复
                 timeout=30,                # 调用超时
                 half_open_max_requests=3,  # 半开状态最多放行数
                 sleep_window=60):          # 熔断后休眠时间(秒)
        
        self.state = CircuitState.CLOSED
        self.failure_count = 0
        self.success_count = 0
        self.last_failure_time = None
        self.failure_threshold = failure_threshold
        self.success_threshold = success_threshold
        self.timeout = timeout
        self.half_open_max_requests = half_open_max_requests
        self.sleep_window = sleep_window
        self.half_open_requests = 0
        self.lock = threading.Lock()
        self.recent_latencies = deque(maxlen=20)  # 最近延迟
    
    def call(self, func, *args, **kwargs):
        """带熔断保护的调用"""
        with self.lock:
            if self.state == CircuitState.OPEN:
                if self._should_try_half_open():
                    self.state = CircuitState.HALF_OPEN
                    self.half_open_requests = 0
                else:
                    raise CircuitBreakerOpenError(
                        f"熔断器 OPEN，已熔断 {self._open_duration():.0f}s"
                    )
            
            if self.state == CircuitState.HALF_OPEN:
                if self.half_open_requests >= self.half_open_max_requests:
                    raise CircuitBreakerOpenError("半开状态请求数已达上限")
                self.half_open_requests += 1
        
        # 执行调用
        try:
            start = time.time()
            result = func(*args, **kwargs)
            elapsed = time.time() - start
            self._on_success(elapsed)
            return result
            
        except Exception as e:
            self._on_failure()
            raise e
    
    def _on_success(self, latency):
        with self.lock:
            self.recent_latencies.append(latency)
            self.failure_count = 0
            
            if self.state == CircuitState.HALF_OPEN:
                self.success_count += 1
                if self.success_count >= self.success_threshold:
                    self.state = CircuitState.CLOSED
                    self.success_count = 0
    
    def _on_failure(self):
        with self.lock:
            self.failure_count += 1
            self.last_failure_time = time.time()
            
            if self.state == CircuitState.HALF_OPEN:
                self.state = CircuitState.OPEN  # 探测失败 → 重新熔断
            elif (self.state == CircuitState.CLOSED and 
                  self.failure_count >= self.failure_threshold):
                self.state = CircuitState.OPEN
                logger.error("熔断器 OPEN！")
    
    def _should_try_half_open(self):
        return time.time() - self.last_failure_time > self.sleep_window
    
    def _open_duration(self):
        if self.last_failure_time:
            return time.time() - self.last_failure_time
        return 0
```

## 4. 舱壁隔离模式

```text
舱壁 (Bulkhead) = 把资源隔离开，一个舱进水不沉整艘船

LLM 舱壁隔离：

  ┌─────────────────────────────────────────────┐
  │              请求入口                         │
  │        ┌──────┬──────┬──────┐               │
  │        │舱壁A  │舱壁B  │舱壁C  │               │
  │        │GPT-4o │Claude │Qwen  │               │
  │        │pool:50│pool:30│pool:20│              │
  │        └──────┴──────┴──────┘               │
  └─────────────────────────────────────────────┘

  舱壁A 线程池满了 → B 和 C 不受影响 → 服务降级但不崩溃
```

## 5. 线程池与信号量隔离

```java
// Java 舱壁隔离示例
public class LLMBulkhead {
    
    // 每个模型独立的线程池
    private final ExecutorService gpt4Executor = 
        new ThreadPoolExecutor(10, 50, 60L, TimeUnit.SECONDS,
            new LinkedBlockingQueue<>(100),
            new ThreadPoolExecutor.CallerRunsPolicy());  // 满了降级
    
    private final ExecutorService qwenExecutor = 
        new ThreadPoolExecutor(5, 20, 60L, TimeUnit.SECONDS,
            new LinkedBlockingQueue<>(50),
            new ThreadPoolExecutor.CallerRunsPolicy());
    
    public CompletableFuture<String> callWithBulkhead(
            String model, String prompt) {
        ExecutorService executor = "gpt-4o".equals(model) 
            ? gpt4Executor : qwenExecutor;
        
        return CompletableFuture.supplyAsync(
            () -> callLLM(model, prompt), executor
        ).orTimeout(30, TimeUnit.SECONDS);
    }
}
```

## 6. Java 熔断实战

```java
// 使用 Resilience4j 熔断器
@Bean
public CircuitBreaker llmCircuitBreaker() {
    CircuitBreakerConfig config = CircuitBreakerConfig.custom()
        .failureRateThreshold(50)          // 失败率 > 50% → 熔断
        .slowCallRateThreshold(50)         // 慢调用 > 50% → 熔断
        .slowCallDurationThreshold(Duration.ofSeconds(10))
        .slidingWindowSize(20)             // 滑动窗口 20 次
        .minimumNumberOfCalls(5)           // 最少 5 次才计算
        .waitDurationInOpenState(Duration.ofSeconds(60))
        .permittedNumberOfCallsInHalfOpenState(3)
        .build();
    
    return CircuitBreaker.of("llm-api", config);
}

// 使用熔断器
@CircuitBreaker(name = "llm-api", fallbackMethod = "fallback")
public String chat(String prompt) {
    return openaiClient.chat(prompt);  // 可能失败
}

public String fallback(String prompt, Throwable t) {
    logger.warn("LLM 熔断降级: {}", t.getMessage());
    return "服务繁忙，请稍后重试";  // 兜底
}
```
