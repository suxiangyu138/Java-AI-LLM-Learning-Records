# 09 - 监控告警与日志

> 🎯 部署只是开始，持续监控才是运维 — GPU 利用率、推理延迟 P99、Token 消耗、模型漂移四大核心指标

### 核心监控指标

```text
GPU 指标：
  → GPU 利用率 > 80% → 需扩容
  → 显存使用 > 90% → 需要更大显存/量化
  
推理指标：
  → QPS (每秒请求数)
  → P50/P95/P99 延迟
  → 首 Token 延迟 (TTFT)
  → Token 生成速度 (tokens/s)

业务指标：
  → 请求成功率
  → 平均 Token 消耗/请求
  → 用户满意度 (👍/👎)
  → 模型输出分布变化 (漂移检测)
```

### 告警规则

```yaml
groups:
  - name: llm_alerts
    rules:
      - alert: HighLatency
        expr: histogram_quantile(0.99, llm_latency_seconds) > 5
        annotations:
          summary: "P99 延迟超过 5 秒"
      - alert: HighErrorRate
        expr: rate(llm_errors[5m]) / rate(llm_requests[5m]) > 0.05
        annotations:
          summary: "错误率超过 5%"
```

### 模型漂移检测

```python
# 监控 Embedding 输出分布变化
def detect_drift(recent_outputs, baseline_outputs, threshold=0.1):
    recent_mean = np.mean(recent_outputs, axis=0)
    baseline_mean = np.mean(baseline_outputs, axis=0)
    drift = cosine_similarity(recent_mean, baseline_mean)
    if drift < (1 - threshold):
        alert("检测到模型输出分布漂移！")
```
