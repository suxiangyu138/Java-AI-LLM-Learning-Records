# 10 - 灰度发布与 A/B 测试

> 🎯 新模型直接全量上线 = 赌博 — 灰度发布渐进验证、A/B 测试科学决策、一键回滚兜底

### 三种发布策略

| 策略 | 做法 | 风险 | 回滚 |
|------|------|:---:|:---:|
| **金丝雀 (Canary)** | 5%→20%→100% 渐进 | 低 | 秒级 |
| **蓝绿 (Blue-Green)** | 新老两套全量切换 | 中 | 秒级 |
| **A/B 测试** | 按用户分流 | 低 | 实时 |

### K8s 金丝雀发布

```yaml
# 金丝雀：10% 流量到 v2
apiVersion: v1
kind: Service
spec:
  selector:
    app: llm
    # version 标签由两个 Deployment 各自提供
---
# v2 金丝雀 Deployment (1 个副本)
apiVersion: apps/v1
kind: Deployment
metadata:
  name: llm-v2-canary
spec:
  replicas: 1  # 10% 流量
  template:
    metadata:
      labels:
        app: llm
        version: v2
---
# v1 稳定版 Deployment (9 个副本)
apiVersion: apps/v1
kind: Deployment
metadata:
  name: llm-v1-stable
spec:
  replicas: 9  # 90% 流量
```

### A/B 测试框架

```python
class ABTestRouter:
    def route(self, user_id, request):
        bucket = hash(user_id) % 100
        if bucket < 10:          # 10% 用户 → 实验组
            return model_v2.generate(request)
        else:                    # 90% 用户 → 对照组
            return model_v1.generate(request)
```
