# 04 - 日志管理与分析

> 🎯 LLM 日志不只是"系统日志" — 每次对话的 Prompt、Response、Token 消耗、模型版本都需要记录。这些日志是优化和审计的金矿

## 1. 结构化日志规范

```python
import structlog
import time

logger = structlog.get_logger()

# LLM 调用日志 — 结构化！
def log_llm_call(user_id, model, messages, response, duration, tokens):
    logger.info("llm_call",
        user_id=user_id,
        model=model,
        model_version="v3.2.1",
        prompt_hash=hash(str(messages)),
        prompt_length=len(str(messages)),
        response_length=len(response),
        duration_ms=duration,
        tokens_prompt=tokens["prompt"],
        tokens_completion=tokens["completion"],
        tokens_total=tokens["total"],
        cost_usd=tokens["total"] * 0.000002,  # GPT-4o-mini
        first_token_latency_ms=tokens["ttft"],
        finish_reason="stop",
    )
```

## 2. 日志采集架构

```text
应用 → stdout/stderr → Fluentd/Vector → Elasticsearch/Loki → Grafana

  LLM 日志量估算：
  日均 10 万次对话 × 500 tokens/次 ≈ 50M tokens
  日志大小 ≈ 500MB/天（结构化JSON）
  
  保留策略：
  → 热数据（7天）：Elasticsearch → 快速查询
  → 冷数据（90天）：S3 → 低成本归档
  → 审计日志（1年+）：合规要求
```

## 3. 审计日志

```python
# 不可篡改的审计日志
class AuditLogger:
    def __init__(self):
        self.chain = []  # 可用于区块链防篡改
    
    def log(self, event_type, user_id, details):
        entry = {
            "timestamp": time.time(),
            "event_type": event_type,
            "user_id": user_id,
            "details": details,
            "prev_hash": self.chain[-1]["hash"] if self.chain else "genesis"
        }
        entry["hash"] = hashlib.sha256(json.dumps(entry).encode()).hexdigest()
        self.chain.append(entry)
        # 同时写入不可修改的日志存储（如 AWS CloudTrail）
```

## 4. 关键日志查询

```text
常用 ELK 查询：

  # 某个用户的最近对话
  user_id:"user_123" AND event:"llm_call" | sort @timestamp desc | head 20

  # 延迟异常的请求（P99 以上）
  duration_ms > 10000 | stats count by model

  # 某时间段 Token 消耗 Top 10 用户
  stats sum(tokens_total) as total by user_id | sort total desc | head 10

  # 错误率趋势（5分钟窗口）
  event:"llm_call" | stats count as total, count(error) as errors 
  by date_histogram("5m") | eval error_rate = errors / total
```
