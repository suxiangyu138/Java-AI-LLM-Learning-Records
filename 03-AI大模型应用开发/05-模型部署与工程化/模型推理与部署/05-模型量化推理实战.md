# 05 - 模型量化推理实战

> 🎯 量化 = 推理部署的第一优化 — INT8 几乎无损缩小 2×，INT4 轻微损失缩小 4×

## 量化方法对比

| 方法 | 精度 | 需校准 | 显存节省 | 推理引擎 |
|------|:---:|:---:|:---:|------|
| **GPTQ** | INT4 | ✅ | 4× | vLLM/TRT-LLM |
| **AWQ** | INT4 | ✅ | 4× | vLLM/TRT-LLM |
| **GGUF** | Q4_K_M | ❌ | 4× | llama.cpp/Ollama |
| **BitsAndBytes** | INT4/INT8 | ❌ | 2-4× | HuggingFace |

## GPTQ vs AWQ

```text
GPTQ：逐层最优脑手术量化
  → 精度高、速度慢（需几小时校准）
  → GPU 推理首选

AWQ：激活感知量化
  → 保护重要通道（激活值大的通道）
  → 比 GPTQ 快、精度相当
  → 新项目推荐 AWQ
```

## 5. 量化方案速查（2026）

**量化方案全景**：

| 方案 | 位宽 | 适用 | 2026 状态 |
|------|:----:|------|:---------:|
| FP8 | 8 位浮点 | **H100 推理（首选）** | ✅ 生产标配 |
| FP4 | 4 位浮点 | Blackwell（B200） | ✅ 新支持 |
| INT8（W8A8） | 8 位整型 | 通用 GPU | ✅ 成熟 |
| INT4（AWQ/GPTQ） | 4 位整型 | 显存受限 | ✅ 成熟 |
| GGUF Q4 | 4 位（llama.cpp） | 本地/边缘 | ✅ 本地标准 |

**FP8 vs INT8 vs INT4 选择**：

```text
FP8：动态范围大（LLM 友好）—— 2026 全方位赢家（吞吐↑显存↓延迟↓）
INT8：需校准数据（W8A8 量化）—— 成熟但 FP8 更优
INT4：显存省最多（4 倍）—— 效果损失需验证（2-3%）
选择：H100 → FP8；显存极限 → INT4；边缘/本地 → GGUF

量化验证铁律：黄金集精度对比（掉点 >1% 回退）
```

**量化实践速查**：

```text
① 权重量化（W8A8）：离线完成，推理无感
② KV 量化（FP8）：长上下文关键（省 KV 显存 50%）
③ 激活量化：动态（复杂）vs 静态（需校准）
④ 混合精度：敏感层 FP16 + 其余量化（精度/显存平衡）
⑤ 工具：vLLM --quantization fp8 / AWQ / GPTQ / llama.cpp GGUF
```

> 🎯 **核心要点**：量化 2026 = "**FP8 首选（H100）+ INT4 极限（显存）+ GGUF 本地**"三档——**FP8 是全方位赢家**（无需校准、动态范围大）；所有量化上线前必须黄金集验证（掉点 >1% 回退）。

## 6. 量化实践速查

**vLLM 量化启用**：

```bash
# FP8（H100 首选）
vllm serve Qwen/Qwen2.5-7B-Instruct --quantization fp8

# AWQ（INT4，显存极限）
vllm serve Qwen/Qwen2.5-7B-Instruct --quantization awq

# GPTQ（INT4，需量化权重）
vllm serve Qwen/Qwen2.5-7B-Instruct --quantization gptq

# KV 量化（长上下文）
vllm serve ... --kv-cache-dtype fp8
```

**量化验证流程**（铁律）：

```text
① 黄金集精度对比：量化 vs FP16（掉点 >1% 回退）
② 显存与吞吐实测：量化前后对比（确认收益）
③ 长上下文测试：量化 KV 在长上下文的稳定性
④ 压测确认：真实负载下 P95

常见问题：
  掉点明显 → 敏感层保留 FP16（混合精度）
  显存收益不符 → 检查是否真的加载量化权重
  KV 量化掉点 → 回退 FP16 KV（权重量化保留）
```

> 🎯 **核心要点**：量化实践 = "**一行参数启用（fp8/awq/gptq）+ 黄金集验证（掉点>1% 回退）+ 混合精度兜底**"——**"量化后不验证 = 质量事故源"**是 2026 最常强调的铁律。

## 8. 量化面试题补充

| # | 追问 | 速答 |
|:-:|------|------|
| 1 | 为什么 FP8 免校准？ | 浮点动态范围大（INT8 需校准集定尺度） |
| 2 | 权重和激活量化区别？ | 权重离线可量化；激活动态（复杂/需校准） |
| 3 | 量化掉点怎么定位？ | 分层对比（敏感层保留 FP16 混合精度） |
| 4 | GGUF 和 AWQ 区别？ | GGUF llama.cpp 系（本地）；AWQ 感知激活（GPU 服务） |
| 5 | KV 量化为什么重要？ | 长上下文 KV 是大头——省 50% 显存 |
| 6 | 量化后吞吐提升多少？ | 显存省 → 批更大 → 吞吐提升（量级 1.5-3x） |

> 🎯 **核心要点**：量化追问六题 = "**FP8 免校准（动态范围）+ 混合精度（掉点定位）+ GGUF vs AWQ（场景）+ KV 量化（长上下文）**"——**"FP8 为什么免校准"是 2026 最高频追问**。
