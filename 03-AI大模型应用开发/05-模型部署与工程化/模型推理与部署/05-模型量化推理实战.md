# 05 - 模型量化推理实战

> 🎯 量化 = 推理部署的第一优化 — INT8 几乎无损缩小 2×，INT4 轻微损失缩小 4×

## 量化方法对比

| 方法 | 精度 | 需校准 | 显存节省 | 推理引擎 |
|------|:---:|:---:|:---:|------|
| **GPTQ** | INT4 | ✅ | 4× | vLLM/TRT-LLM |
| **AWQ** | INT4 | ✅ | 4× | vLLM/TRT-LLM |
| **GGUF** | Q4_K_M | ❌ | 4× | llama.cpp/Ollama |
| **BitsAndBytes** | INT4/INT8 | ❌ | 2-4× | HuggingFace |

## GPTQ vs AWQ

```text
GPTQ：逐层最优脑手术量化
  → 精度高、速度慢（需几小时校准）
  → GPU 推理首选

AWQ：激活感知量化
  → 保护重要通道（激活值大的通道）
  → 比 GPTQ 快、精度相当
  → 新项目推荐 AWQ
```

## 量化推理

```bash
# GGUF (Ollama 自动量化)
ollama pull qwen2:7b  # 自动使用 Q4_K_M

# GPTQ/AWQ (vLLM)
python -m vllm.entrypoints.openai.api_server \
    --model Qwen/Qwen2-7B-Instruct-AWQ  # 直接加载 HF 上的量化版
```
