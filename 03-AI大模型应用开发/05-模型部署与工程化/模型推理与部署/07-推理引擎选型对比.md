## 选型决策树

```text
GPU 服务器？
  ├── NVIDIA GPU → vLLM (通用首选)
  │              → TensorRT-LLM (追求极致)
  └── Apple/Metal → llama.cpp

CPU 服务器？
  └── llama.cpp / Ollama

快速原型/本地？
  └── Ollama (一行命令)

研究/实验？
  └── HF Transformers (生态最全)

生产 API 服务？
  └── vLLM (OpenAI兼容+最高吞吐)
```

## 推荐组合

| 场景 | 引擎 | 原因 |
|------|------|------|
| 生产 API (NVIDIA) | vLLM | 吞吐最高+OpenAI兼容 |
| 极致性能 (NVIDIA) | TensorRT-LLM | 延迟最低 |
| 本地开发 | Ollama | 一行启动 |
| CPU 部署 | llama.cpp | CPU优化极致 |
| Mac 开发 | Ollama | Metal 加速 |
