## 成本优化策略

```text
① 分层模型：简单问题用便宜模型(mini)，复杂问题用贵模型(pro)
② 缓存：相同问题不重复推理 → Redis/Memcached
③ 量化：INT4/INT8 让单卡承载更多并发
④ 批处理：合并请求减少 GPU 空闲
⑤ Spot 实例：非实时任务用抢占式实例 (节省 60-80%)
⑥ 模型选择：Qwen2-7B 够用就别上 72B
```

```python
# 分层路由
def smart_route(query):
    if is_simple(query):      # 简单问候/常识 → mini
        return gpt4o_mini(query)
    elif needs_reasoning(query):  # 复杂推理 → pro
        return gpt4o(query)
    else:
        return local_qwen(query)  # 本地模型
```

## 5. 成本优化速查（2026）

**成本构成全景**：

```text
LLM 推理成本 = 硬件（GPU 折旧/租赁）+ 电力 + 运维 + API 调用（若用云）

按规模的决策：
  低负载（<1K 请求/天）→ API（OpenAI/DeepSeek）更便宜
  中负载 → 自建小模型（7B-14B）+ 量化
  高负载（>100K 请求/天）→ 自建大模型（70B）+ 优化

关键：算 TCO（总拥有成本）——GPU 成本 vs API 成本 + 运维人力
```

**成本优化五板斧**（按收益排序）：

| 手段 | 收益 | 代价 |
|------|------|------|
| 批处理（连续） | 吞吐 2-4x | 无（引擎标配） |
| 量化（FP8/INT4） | 显存省 2-4x | 精度验证 |
| 缓存（语义缓存） | 重复请求零成本 | 缓存建设 |
| 模型分级（小模型处理简单任务） | 成本降 70%+ | 路由建设 |
| 弹性伸缩 | 空闲期省钱 | 预热复杂度 |

**成本监控指标**：

```text
每千次请求成本（核心 KPI）
GPU 利用率（目标 >60%）
缓存命中率（目标 >30%）
token 成本（输入/输出分开看）
→ 与 RAG/Agent 成本模型联动（见 RAG 深化 21 号）
```

> 🎯 **核心要点**：成本优化 = "**TCO 决策（自建 vs API）+ 五板斧（批处理/量化/缓存/分级/弹性）**"——**"模型分级"是 2026 最高性价比手段**（简单任务用小模型省 70%+）；每千次请求成本是核心 KPI。

## 6. 成本决策速查

**API vs 自建的决策矩阵**：

| 场景 | 选择 | 理由 |
|------|------|------|
| 低负载（<1K 请求/天） | API | 自建 GPU 闲置成本高 |
| 中负载 + 合规要求 | 自建小模型 | 数据不出域 |
| 高负载（>100K/天） | 自建大模型 | 规模摊薄 GPU 成本 |
| 突发负载 | API 兜底 + 自建基线 | 弹性混合 |

**成本模型示例**（决策用）：

```text
自建 7B（单卡 A100）：
  硬件 ~$1-2/小时 → 月 ~$1000-1500
  吞吐 ~2000 tok/s → 月可服务 ~5000 万 token（饱和）
  → 月请求 < 阈值时 API 更便宜（算每 token 成本对比）

API（DeepSeek 等国内低价模型）：
  每 token 成本极低 → 低负载场景必然更优
  → "先 API 后自建"是 2026 通用路径（负载增长后再迁移）
```

**成本优化 KPI 体系**：

```text
每千次请求成本（核心）
GPU 利用率（目标 >60%，低于 = 缩容/混合负载）
缓存命中率（>30% 时缓存建设已回本）
模型分级占比（小模型处理比例 >50% = 分级成功）
→ 四指标月度复盘（成本优化的持续机制）
```

> 🎯 **核心要点**：成本决策 = "**先 API 后自建（负载门槛）+ 混合（自建基线 + API 兜底）+ 四 KPI 复盘**"——**"模型分级占比"是 2026 最具杠杆的成本指标**（简单任务小模型省 70%+）。

```text
成本核心记忆：

  五板斧：批处理 / 量化 / 缓存 / 模型分级 / 弹性
```

> 🎯 **核心要点**：成本总结 = "**先 API 后自建 + 五板斧 + 模型分级最高性价比**"——**"模型分级"是 2026 最高杠杆手段**；与 RAG 深化 21 号（性能缓存成本）联动形成完整成本认知。
