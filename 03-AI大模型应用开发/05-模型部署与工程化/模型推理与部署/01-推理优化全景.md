# 01 - 推理优化全景

> 🎯 LLM 推理是三维优化问题 — 显存、延迟、吞吐，三者互相制约。优化之前先画"雷达图"，明确核心瓶颈

## 三大优化维度

```text
显存 (Memory)：能不能跑？
  → 模型权重 + KV Cache + 中间激活
  → 优化：量化(INT4/INT8)、PagedAttention、CPU Offload

延迟 (Latency)：快不快？（单次请求）
  → Prefill(输入编码) + Decode(逐token生成)
  → 优化：投机采样、FlashAttention、CUDA Graph

吞吐 (Throughput)：能处理多少？（并发请求）
  → QPS = 并发 / 平均延迟
  → 优化：连续批处理、动态Batching、Tensor Parallelism
```

## 模型加载的显存占用

```python
# 加载 Qwen2-7B 的显存计算
params = 7_000_000_000
bytes_per_param_fp16 = 2
model_weight_gb = params * bytes_per_param_fp16 / 1e9  # 14 GB

# KV Cache 显存
# = 2 × layers × hidden_dim × max_seq_len × bytes × batch
kv_cache_gb = 2 * 32 * 4096 * 8192 * 2 * 8 / 1e9  # ~34 GB (8并发,8K上下文)

print(f"模型权重: {model_weight_gb:.1f} GB")
print(f"KV Cache:  {kv_cache_gb:.1f} GB")
print(f"总计:      {model_weight_gb + kv_cache_gb:.1f} GB")
# 总显存 ≈ 14 + 34 = 48 GB → 需要 A100 (80GB) 或双卡！
```

## 优化技术全景

| 技术 | 优化维度 | 收益 | 代价 |
|------|:---:|:---:|------|
| **FlashAttention** | 显存+速度 | 2-4× | 无 |
| **PagedAttention** | 显存利用率 | 2-4× | 无 |
| **INT8 量化** | 显存 | 2× | <0.5%精度 |
| **INT4 量化** | 显存 | 4× | <3%精度 |
| **投机采样** | 延迟 | 2-3× | 需小模型 |
| **连续批处理** | 吞吐 | 5-10× | 无 |
| **Tensor Parallelism** | 显存(分片) | N× | 通信开销 |

## 优化决策树

```text
显存不够？→ 量化(INT4/INT8) + PagedAttention
延迟太高？→ 投机采样 + FlashAttention + CUDA Graph
吞吐太低？→ 连续批处理 + Tensor Parallelism
三者都要？→ vLLM/TensorRT-LLM（开箱即用以上所有）
```
