## 请求队列与背压

```python
import asyncio
from collections import deque

class RequestQueue:
    def __init__(self, max_size=1000, timeout=30):
        self.queue = asyncio.Queue(maxsize=max_size)
        self.timeout = timeout
    
    async def enqueue(self, request):
        try:
            await asyncio.wait_for(
                self.queue.put(request), timeout=self.timeout
            )
        except asyncio.TimeoutError:
            raise HTTPException(503, "服务繁忙，请稍后重试")
    
    async def dequeue(self):
        return await self.queue.get()
```

## 弹性伸缩策略

```text
基于 GPU 利用率的 HPA：
  → GPU 利用率 > 70% 持续 2 分钟 → 扩容 +1
  → GPU 利用率 < 30% 持续 5 分钟 → 缩容 -1

基于请求队列：
  → queue_size > 100 → 扩容
  → queue_size < 10 → 缩容

冷启动优化：
  → 预加载模型到 GPU（常驻）
  → 预热请求（启动后自动发几个请求）
  → 模型缓存到本地 SSD（避免每次从 HF 下载）
```
