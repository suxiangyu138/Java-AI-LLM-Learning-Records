# 06 - 推理性能基准与压测

> 🎯 没压测就上线 = 盲飞 — TTFT、TPOT、QPS、P99 延迟四大指标，locust/wrk/k6 三大工具

## 四大核心指标

| 指标 | 含义 | 目标 |
|------|------|:---:|
| **TTFT** | Time To First Token 首Token延迟 | <1s |
| **TPOT** | Time Per Output Token 每Token生成时间 | <50ms |
| **QPS** | 每秒处理请求数 | >50 |
| **P99 延迟** | 99%请求的端到端延迟 | <5s |

## vLLM 自带压测

```bash
# vLLM benchmark
python -m vllm.entrypoints.openai.run_batch \
    --model Qwen/Qwen2-7B \
    --max-model-len 8192 \
    --num-prompts 1000 \
    --request-rate 10  # 每秒 10 个请求

```

## 优化 CheckList

```text
□ 延迟高 → 投机采样 + FlashAttention
□ 吞吐低 → 连续批处理 + Tensor Parallelism
□ 显存满 → KV Cache 量化 + PagedAttention
□ 首Token慢 → Prefix Caching + 模型预热
□ 长文本慢 → FlashAttention + RoPE插值
```
