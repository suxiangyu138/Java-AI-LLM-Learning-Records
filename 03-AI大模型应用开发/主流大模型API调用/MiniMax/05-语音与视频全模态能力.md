## 2. Speech-2.8 语音能力

### 2.1 模型矩阵

| 模型 | 价格 | 特性 |
|------|:---:|------|
| **speech-2.8-hd** | $100/百万字符 | 情绪渲染、语气词融合、异步最长 100 万字符 |
| **speech-2.8-turbo** | $60/百万字符 | 极致生成速度 |
| **音色设计** | $3.00/音色 | 自定义音色（Voice Design） |
| **快速复刻** | $1.50/音色 | 10 秒声音克隆（Voice Cloning） |

**计费说明：** 按输入字符数计费（1 个汉字算 2 字符）；支持 **40+ 种语言**。

### 2.2 语音合成示例

```python
# 语音合成（TTS）
import requests

resp = requests.post(
    "https://api.minimaxi.com/v1/t2a_v2",
    headers={"Authorization": f"Bearer {os.getenv('MINIMAX_API_KEY')}"},
    json={
        "model": "speech-2.8-hd",
        "text": "欢迎使用 MiniMax 语音合成，支持 40 多种语言和情感渲染。",
        "voice_setting": {
            "voice_id": "male_qn-qingse",       # 预设音色
            "speed": 1.0
        },
        "audio_setting": {"sample_rate": 32000, "format": "mp3"}
    }
)
audio_base64 = resp.json()["data"]["audio"]      # 保存为音频文件

# 音色克隆（10 秒声音克隆）
# ① 上传 10 秒参考音频 → ② 创建自定义音色 → ③ 用该音色合成
```

### 3.2 视频生成示例

```python
# 文生视频
resp = requests.post(
    "https://api.minimaxi.com/v1/video_generation",
    headers={"Authorization": f"Bearer {os.getenv('MINIMAX_API_KEY')}"},
    json={
        "model": "Hailuo-2.3",
        "prompt": "一只橘猫在阳光下的窗台上伸懒腰，背景是花园，电影质感",
        "resolution": "1080p",
        "duration": 6
    }
)
task_id = resp.json()["data"]["task_id"]
# 轮询任务状态 → 完成后下载视频

# 图生视频（Hailuo 2.3 Fast）
resp = requests.post(
    "https://api.minimaxi.com/v1/video_generation",
```

## 4. M3 多模态理解与 Computer Use

```python
# M3 图片理解（Anthropic 协议）
import base64

with open("screenshot.png", "rb") as f:
    img_b64 = base64.b64encode(f.read()).decode()

response = client.messages.create(
    model="MiniMax-M3",
    max_tokens=4096,
    messages=[{
        "role": "user",
        "content": [
            {"type": "text", "text": "分析这个页面布局的问题"},
            {"type": "image", "source": {
                "type": "base64",
                "media_type": "image/png",
                "data": img_b64
            }}
        ]
    }]
)
```

## 5. 全模态应用场景

| 场景 | 模态组合 | 方案 |
|------|----------|------|
| **AI 数字人客服** | 文本 + 语音 + 视频 | M3 理解 + Speech 合成 + Hailuo 视频形象 |
| **智能语音助手** | 语音 + 文本 | Speech 识别 + M3 推理 + Speech 回复 |
| **视频内容分析** | 视频 + 文本 | M3 视频理解 + 总结报告 |
| **营销视频生成** | 文本 + 视频 | M3 写脚本 + Hailuo 生成 + Speech 配音 |
| **AI 桌面助手** | 截图 + 文本 | M3 Computer Use 自动操作 |
