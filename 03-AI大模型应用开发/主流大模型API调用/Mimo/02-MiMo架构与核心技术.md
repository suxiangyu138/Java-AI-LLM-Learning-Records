## 2. SWA 混合注意力

**SWA（Sliding Window Attention，滑动窗口注意力）：**

```text
传统全注意力：
  token 与所有 token 计算 → O(n²) 成本
  1M 上下文的计算量爆炸

SWA 滑动窗口注意力：
  token 只与相邻窗口内的 token 计算 → O(n) 线性成本
  窗口大小可配置（如 64K 窗口）

混合注意力（Hybrid）：
├── 近处：SWA 滑动窗口（精确）
├── 远处：全局注意力采样（概览）
└── 兼顾效率与质量

与 GLM DSA 的区别：
├── DSA：动态稀疏（按相关性动态选择）
├── SWA：固定窗口（只看相邻 N 个）
└── SWA 实现更简单、长文本稳定性好
```
