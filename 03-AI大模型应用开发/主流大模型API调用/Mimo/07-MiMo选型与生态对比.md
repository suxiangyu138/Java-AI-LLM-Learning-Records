## 1. MiMo vs DeepSeek 对比

| 对比 | MiMo-V2.5 Pro | DeepSeek V4-Pro |
|------|:---:|:---:|
| 输入价格 | $1.00 | **$0.435** |
| 输出价格 | $3.00 | **$0.87** |
| 上下文 | **1M** | 128K |
| 长文本 | **800K 检索 95%** | — |
| 开源 | ✅ | ✅ |
| 单 Token 成本 | 贵约 2.3-3.5 倍 | **更便宜** |

**结论：** 按单 Token 计算 DeepSeek 更便宜（约 2-3 倍）；但 MiMo 的 **1M 上下文**是差异化 — 长文本场景总成本反而更低（无需分块 + 缓存命中极便宜）。

**场景分水岭：**
```text
短文本高频 → DeepSeek（单 Token 便宜 2-3 倍）
长文本场景 → MiMo（1M 上下文 + 缓存命中 ¥0.025）
```
