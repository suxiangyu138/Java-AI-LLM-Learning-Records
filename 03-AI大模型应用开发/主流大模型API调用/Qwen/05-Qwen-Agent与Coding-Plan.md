## 2. 草图转前端：标志性能力

```text
场景：产品经理手绘界面草图 → 直接生成可运行前端代码

流程：
① 拍照/上传手绘草图（登录页/表单/仪表盘...）
② Qwen3.5 原生多模态理解：
   - 布局结构（标题/按钮/输入框位置）
   - UI 元素（类型/样式/交互）
   - 页面逻辑（跳转/校验）
③ 生成前端代码（HTML/CSS/JS）
④ 直接可用（或微调）

这是"多模态理解 + 代码生成"组合能力的体现
也是 AI Agent 从"对话"到"视觉到代码"的标志性进步
```
