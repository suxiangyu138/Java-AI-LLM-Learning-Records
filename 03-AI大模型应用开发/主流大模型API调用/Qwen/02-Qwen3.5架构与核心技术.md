## 2. 极致稀疏 MoE

```text
MoE 演进（Qwen 系列）：

Qwen1 时代：稠密模型（所有参数参与计算）
Qwen2 时代：MoE（Top-K 路由）
Qwen3.5：极致稀疏 MoE（激活比例 <5%）

极致稀疏的含义：
├── 397B 总参 → 每次只激活 17B（<5%）
├── 更多专家 → 知识分工更细
├── 路由更高效 → 低激活成本
└── 单卡部署成为可能（35B-A3B 等中尺寸）

收益：
├── 训练成本降 90%
├── 部署显存占用降 60%（vs Qwen3-Max）
└── 最大推理吞吐量提升 19 倍
```

## 3. 混合注意力与门控机制

### 3.1 混合注意力

```text
混合注意力架构：
├── 近处：滑动窗口注意力（精确局部）
├── 远处：全局注意力采样（长程依赖）
└── 兼顾效率与长上下文质量（1M）

与其他稀疏方案的对比：
├── vs DSA（GLM）：动态稀疏选择
├── vs SWA（MiMo）：固定窗口
├── vs MSA（MiniMax）：两阶段 Top-k 块
└── Qwen3.5：混合注意力 + 门控
```

### 3.2 注意力门控机制（NeurIPS 2025 最佳论文）

```text
注意力门控（Attention Gating）：
├── 训练时动态控制注意力头的重要性
├── 让模型学习"哪些注意力头重要"
├── 剪枝/跳过不重要的计算
└── 训练成本降 90% 的核心技术

这是 NeurIPS 2025 最佳论文技术 — 学术认可 + 工程落地
```

## 4. 原生多 Token 预测

