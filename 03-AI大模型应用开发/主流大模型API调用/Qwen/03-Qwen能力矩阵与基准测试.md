### 4.2 201 种语言（全球唯一）

| 指标 | 数据 |
|------|:---:|
| 语言覆盖 | **201 种**（首次全覆盖） |
| 词表 | 150k → **250k** |
| 小语种编码效率 | +60% |

```text
201 种语言的意义：
├── 全球唯一（其他模型一般 30-100 种）
├── 小语种（泰语/越南语/阿拉伯语等）编码效率 +60%
├── 出海业务的唯一选择
└── 词表 250k = 更高效的 token 表示
```
