## 3. 推理与办公能力

| 能力 | 详情 |
|------|------|
| **结构化推理** | 数学、形式推理、金融分析、法律摘要、科学推理（智谱主打的"思维链质量"） |
| **办公文件代理** | 可代理式处理 .docx / .pdf / .xlsx |
| **国产芯片** | 支持昇腾/寒武纪等国产芯片推理 |
| **上下文** | 200K（GLM-5.2 达 1M） |

**智谱的差异化定位（逆势涨价的原因）：**
```text
2026 价格战主流：降价抢市场份额
智谱的回应：GLM-5 涨价 50%
逻辑：不追最便宜，在"结构化推理和思维链任务中表现最强"
适合：数学、形式推理、金融分析、法律摘要、科学推理
不适合：成本敏感的高并发简单任务
```
