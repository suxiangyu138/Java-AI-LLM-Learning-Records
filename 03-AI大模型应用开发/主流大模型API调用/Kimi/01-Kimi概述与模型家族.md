## 3. K2.6：开源编程旗舰

**2026.04.20 发布并开源** — 被称为"上市前第一场路演"。

| 维度 | 详情 |
|------|------|
| 架构 | MoE：总参数 ~1T、激活 32B、256 专家、Top-K=8 |
| 上下文 | 256K（262,144 tokens，输入=输出） |
| 输入 | 文本、图片、视频 |
| 模式 | 思考模式（可开关）+ 非思考模式 |
| 开源 | ✅ HuggingFace: `moonshotai/Kimi-K2.6` |
| 定位 | **编程 + Agent 任务开源第一** |
| 核心能力 | 13 小时连续编码、300 子 Agent 集群、5 天自主运行 |
| 基准 | SWE-Bench Pro **58.6**（> GPT-5.4 的 57.7） |

**K2.6 vs K2.5 提升：**

| 基准 | K2.5 | K2.6 | 提升 |
|------|:---:|:---:|:---:|
| SWE-Bench Pro | 50.7 | **58.6** | +15.6% |
| Terminal-Bench 2.0 | — | **66.7** | +31.3% |
| Toolathlon | — | — | **+79.9%** |
| Kimi Code Bench | — | — | ~+20% |
| Agent 并发数 | 100 子 Agent | **300 子 Agent** | 3 倍 |

| 维度 | 详情 |

## 5. K3：全能新旗舰

| 维度 | 详情 |
|------|------|
| 参数 | **2.8T**（K2.6 的 2.8 倍） |
| 上下文 | **1M tokens** |
| 视觉 | ✅ 原生视觉（图片/视频） |
| 思考 | **默认开启**（`reasoning_effort` 实测仅支持 max 档） |
| 工具 | Function Calling（最多 128 个工具）、tool_choice 支持 required |
| 缓存 | 自动上下文缓存（命中成本降 ~9 倍） |
| 结构化 | JSON Schema 严格模式 |
| 推荐度 | 官方建议**默认从 kimi-k3 开始** |

**K3 的注意点：**
- 思考默认开启且不可关闭 → 长任务耗时极高（实测单文件 HTML 生成 2541 秒，思考 token 占 73%）
- 多轮对话必须**原样回传含 `reasoning_content` 的 assistant 消息**
- 采样参数固定（temperature=1.0、top_p=0.95）→ 请求中省略

## 6. 产品形态矩阵

| 形态 | 入口 | 说明 |
|------|------|------|
| **Web 对话** | kimi.com | 对话/智能体模式 |
| **Kimi Code** | IDE 插件 | 编程助手（K2.7 Code） |
| **Kimi API** | platform.kimi.com | 开发者接入（OpenAI 兼容） |
| **本地部署** | HuggingFace 权重 | K2 系列开源可自部署 |
| **第三方平台** | 腾讯云 TokenHub / 360 智脑 / 京东云 / 阿里云百炼 | 一个 Key 多平台调用 |
