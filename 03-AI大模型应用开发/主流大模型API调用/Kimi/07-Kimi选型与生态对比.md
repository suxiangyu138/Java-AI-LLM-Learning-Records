## 1. Kimi 家族内部选型

| 场景 | 推荐 | 理由 |
|------|------|------|
| **长链路 Agent 任务**（调研/自主长跑） | **K2.6** | 300 子 Agent/5 天自主/工具调用最稳 |
| **纯代码编写/IDE** | **K2.7 Code** | 编码专用优化 |
| **全能旗舰**（预算允许） | **K3** | 2.8T 参数/1M 上下文/视觉/思考 |
| **通用便宜** | K2.5 | 预算敏感 |
| **思考模型** | kimi-k2-thinking | 需要强推理 |

**官方建议：** 默认从 `kimi-k3` 开始；K3 成本敏感时降级 K2.6。

**选型建议：**
```text

组合方案：80% DeepSeek + 20% Kimi（Agent 关键任务用 Kimi）
```

## 5. 按场景选型矩阵

| 场景 | 首选 | 备选 | 理由 |
|------|------|------|------|
| **长链路 Agent**（调研/运维/文档） | **Kimi K2.6** | Claude Sonnet | 300 子 Agent + 5 天自主，开源最佳 |
| **复杂编程/大重构** | Claude Sonnet | **K2.6** | Claude 综合最强；K2.6 开源性价比 |
| **IDE 编码** | **K2.7 Code** | Copilot | 编码专用 |
| **高并发 API** | DeepSeek | Kimi K2.5 | 便宜 6 倍 |
| **深度调研**（搜索+推理） | **K2.6** | Gemini | DeepSearchQA 92.5 大幅领先 |
| **纯数学/逻辑推理** | Claude Opus | GPT-5.5 | HLE-Full 领先 5 分 |
| **中文 C 端产品** | 豆包 | Kimi K3 | 豆包最便宜+中文最自然 |
| **本地离线部署** | K2.6（开源） | Llama 4 | MoE 32B 激活可单卡 |
| **全能旗舰** | Kimi K3 | GPT-5.5 | 2.8T/1M/视觉/思考 |

**最终推荐组合（AI 产品团队）：**
```text
Agent 任务（长链路）→ Kimi K2.6（$0.95 输入）
高频简单调用 → DeepSeek（$0.28 输入）
复杂编程/推理 → Claude Sonnet（按需）
本地兜底 → K2.6 开源部署（Ollama/vLLM）
```

---

> 🎯 **核心要点**：Kimi 选型三句话 — **① 家族内部：Agent 长任务→K2.6、纯编码→K2.7 Code、全能→K3 ② 横向对比：Agent/编程任务领先开源，纯推理落后闭源 ③ 成本定位：介于国产便宜与海外旗舰之间，Agent 场景"性价比最优解"**。与 DeepSeek 是互补关系而非替代：简单高并发用 DeepSeek、复杂 Agent 用 Kimi。
