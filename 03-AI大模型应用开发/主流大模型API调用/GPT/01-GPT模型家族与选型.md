## 1. GPT-5.6 命名革命

```text
旧命名（GPT-5.x 时代）：Pro / Mini / Turbo 按"能力档"命名
新命名（GPT-5.6）：Sol / Terra / Luna 按"天体"命名

三档共享全量功能集：
├── reasoning effort（六档）
├── Pro 模式（质量优先）
├── 显式缓存
└── Responses API 全部特性
层级选择 = 纯粹的价格与深度权衡
```

| 模型 | 含义 | 定位 | 输入 | 输出 | 缓存读取 |
|------|------|------|:---:|:---:|:---:|
| **GPT-5.6 Sol** | 太阳 | 旗舰·最强推理 | $5.00 | $30.00 | $0.50 |
| **GPT-5.6 Terra** | 地球 | 均衡·默认替代 | $2.50 | $15.00 | $0.25 |
| **GPT-5.6 Luna** | 月亮 | 轻量·最快最便宜 | $1.00 | $6.00 | $0.10 |

## 2. Sol：旗舰太阳

| 维度 | 详情 |
|------|------|
| 模型 ID | `gpt-5.6-sol` |
| 上下文 | ~1.05M tokens |
| 最大输出 | 128K tokens |
| 知识截止 | 2026.02.16 |
| 独有能力 | **Ultra 模式**（4-16 子智能体并行）、**Max 模式**（更深推理） |
| 性能 | Terminal-Bench 2.1：Sol 88.8%、**Sol Ultra 91.9%**、ExploitBench 73.5（vs GPT-5.5 的 47.9） |
| 短板 | SWE-Bench Pro 64.6%（落后 Claude Fable 5 的 80%） |
| 价格 | $5/$30（与 GPT-5.5 同价但更强） |

> ⚠️ **gpt-5.6 裸别名路由到 Sol**（而非 Terra）— 用别名做低成本任务会账单翻倍。

## 3. Terra：均衡地球

| 维度 | 详情 |
|------|------|
| 模型 ID | `gpt-5.6-terra` |
| 定位 | **GPT-5.5 的默认替代方案** |
| 价格 | $2.50/$15 — **全套计费恰为 GPT-5.5 的一半** |
| 上下文 | 100 万（与 GPT-5.5 硬件规格完全对齐） |
| 最大输出 | 128K |
| 兼容 | OpenAI 标准协议，迁移只需替换模型 ID 字符串 |
| 性能 | Terminal-Bench 2.1：84.3%（与 Claude Fable 5 持平，超 GPT-5.5 的 83.4%） |
| 注意 | 未公布官方独立编码基准 → 自行 A/B 测试 |

**迁移成本：** Terra 与 GPT-5.5 硬件规格完全对齐 → 换模型 ID 即可，但官方建议按"调优过程"处理。

## 5. GPT-5.5 与 5.5 Pro 的定位

| 模型 | 输入 | 输出 | 定位 |
|------|:---:|:---:|------|
| GPT-5.5 | $5.00 | $30.00 | 上一代旗舰基线（"经济性已过时"） |
| **GPT-5.5 Pro** | $30.00 | $180.00 | 当前最贵模型（研究级） |

## 6. 价格全景与选型矩阵

### 6.1 完整价格表（$/百万 tokens）

| 模型 | 输入 | 输出 | 缓存读取 | 上下文 |
|------|:---:|:---:|:---:|:---:|
| GPT-5.6 Sol | $5.00 | $30.00 | $0.50 | ~1.05M |
| GPT-5.6 Terra | $2.50 | $15.00 | $0.25 | 1M |
| GPT-5.6 Luna | $1.00 | $6.00 | $0.10 | — |
| GPT-5.5 | $5.00 | $30.00 | $0.50 | 200K |
| GPT-5.5 Pro | $30.00 | $180.00 | — | — |

**长上下文溢价：** 输入 >272K → 全请求 2× 输入 / 1.5× 输出（Sol）。

### 6.2 选型矩阵

| 场景 | 首选 | 理由 |
|------|------|------|
| **默认主力** | **Terra** | GPT-5.5 半价、规格对齐 |
| **复杂科研/网络安全** | Sol | ExploitBench 73.5、Ultra 模式 |
| **最高质量（不计成本）** | Sol Ultra | 16 子 Agent 并行 |
| **高并发简单任务** | Luna | 1/5 价格、82.5% 仍强 |
| **研究级难题** | GPT-5.5 Pro | $180/百万输出 |
| **分层路由** | 80% Luna + 15% Terra + 5% Sol | 成本最优 |
