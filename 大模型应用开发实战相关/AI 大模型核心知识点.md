# AI大模型核心知识点
## 一、基础核心概念
1. **大语言模型（LLM）**
基于**Transformer架构**、海量文本数据预训练的大规模深度神经网络，具备理解、生成、推理、记忆等通用语言能力。
2. **参数规模**
模型参数（数十亿~万亿级）是能力核心指标，参数越多，泛化、上下文理解、复杂任务处理能力越强，但算力、推理成本越高。
3. **生成式AI**
大模型核心范式，通过**概率采样**逐字生成文本，属于自回归生成模式。
4. **上下文窗口**
模型单次可接收并理解的最大输入+输出token长度，决定长文本、长对话处理能力。

## 二、底层核心架构：Transformer
1. **两大核心模块**
- **编码器Encoder**：理解输入语义，擅长语义理解、分类、抽取类任务。
- **解码器Decoder**：负责内容生成，LLM主流仅使用**纯Decoder**架构。
2. **关键机制**
- **自注意力机制Self-Attention**：捕捉文本长距离依赖，计算字词间关联权重。
- **多头注意力Multi-Head Attention**：多维度并行捕捉语义、语法、逻辑特征。
- **位置编码Positional Encoding**：Transformer无时序感知，通过位置编码注入文本顺序信息。
- **前馈神经网络FFN**：非线性特征转换，强化模型表达能力。

## 三、训练全流程
### 1. 预训练（Pre-training）
- 数据：海量无标注通用文本（书籍、网页、论文、代码等）。
- 目标：**语言建模**，预测下一个token，学习通用语法、常识、世界知识、逻辑。
- 特点：无监督学习，奠定模型基础能力。

### 2. 微调（Fine-tuning）
- 数据：少量高质量有标注垂直数据。
- 作用：适配特定场景（客服、代码、医疗、教育），缩小通用模型与业务场景差距。

### 3. 对齐训练（人类偏好对齐）
- **SFT 有监督微调**：用高质量人工对话数据，教会模型遵循指令。
- **RLHF 基于人类反馈强化学习**：依据人类打分，优化输出偏好（合规、有用、简洁）。
- **RLAIF AI反馈强化学习**：用AI替代人类打分，降低对齐成本，主流轻量化方案。

## 四、关键技术名词
1. **Token**
模型最小处理单元，中文约1个汉字=2token，英文以单词/子词拆分，是计费、上下文限制的基础单位。
2. **嵌入层Embedding**
将文字、符号转化为低维稠密向量，把语义转化为模型可计算的数值。
3. **推理Inference**
模型接收输入、计算并生成内容的过程，分为本地部署推理、API云端推理。
4. **量化Quantization**
压缩模型参数精度（FP16→INT8/INT4），降低显存占用、提升推理速度，是本地部署核心技术。
5. **稀疏模型/混合专家MoE**
不激活全部参数，仅调用部分专家模块参与计算，实现**大参数、低推理成本**，主流超大模型标配。

## 五、主流应用技术栈
1. **提示词工程 Prompt Engineering**
通过优化指令格式、逻辑、示例，零成本提升模型输出质量，包含：零样本、少样本、思维链CoT。
2. **RAG 检索增强生成**
核心：**私有知识库检索 + 大模型生成**
解决痛点：大模型知识滞后、幻觉、无法使用企业/个人私有数据。
3. **Agent 智能体**
模型具备规划、工具调用、记忆、反思能力，可自主完成复杂任务（联网搜索、代码执行、工具联动）。
4. **大模型微调**
分为全量微调、LoRA轻量化微调、QLoRA低资源本地微调，适配个性化、垂直场景需求。

## 六、核心痛点与局限
1. **幻觉**
生成虚假事实、错误数据、编造论据，是落地首要解决问题。
2. **知识时效性**
预训练数据存在时间截断，无法获取实时新闻、动态信息。
3. **上下文限制**
超长文本处理成本高，长对话易遗忘前文关键信息。
4. **算力与成本**
训练、部署、推理对GPU显存、算力要求高，企业级落地存在成本门槛。
5. **安全与合规**
易生成违规、偏见、有害内容，需内容过滤、安全对齐。

## 七、模型分类
1. **闭源大模型**：能力强、开箱即用（文心一言、通义千问、GPT系列）。
2. **开源大模型**：可本地部署、二次开发（Llama、Qwen、DeepSeek、GLM）。
3. **垂直领域大模型**：代码大模型、医疗大模型、教育大模型、多模态大模型。

## 八、多模态大模型
融合文本、图片、音频、视频，核心：
- 图文理解、图文生成、语音对话、视频内容解析；
- 底层在Transformer基础上新增视觉编码器、音频编码器。
