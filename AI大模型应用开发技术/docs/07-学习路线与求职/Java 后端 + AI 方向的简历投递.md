Java 后端 + AI 方向的简历投递
一、投递渠道（优先级从高到低）
1. 内部推荐（最强，必走）
- 效果：跳过部分筛选、优先被看见、可查进度、通过率最高。
- 怎么找：
- 学长/学姐/同学/老乡在目标公司
- 脉脉、牛客网、知乎、小红书搜「XX公司内推」
- 微信搜「XX招聘」公众号，常有内推入口
- 操作：
- 找内推人要 内推码/内推链接
- 简历命名： 姓名-学校-Java后端AI开发-可到岗时间 
- 发简历时附一句：目标岗位、base、可实习/入职时间
2. 官方招聘官网（主阵地）
- 字节：https://job.bytedance.com/
- 阿里/阿里云：https://talent.alibaba.com/
- 腾讯：https://careers.tencent.com/ 
- 百度：https://talent.baidu.com/
- 美团/快手/拼多多/网易：直接搜「公司名 + 招聘」
- 要点：
- 注册账号，完整填信息（教育、项目、技能）
- 选 Java 开发 / 后端开发 / 大模型应用 / AI 工程 岗
- 同一公司 最多投 2–3 个岗位（别海投）
3. 招聘平台（辅助海投）
- 牛客网：校招/实习最准，有内推区、真题、进度
- BOSS 直聘：聊得快，适合找部门直招
- 猎聘：适合有 1–3 年经验
- 智联/前程无忧：大厂岗位少，优先级低
4. 校园渠道
- 宣讲会、双选会、就业网
- 部分大厂现场可免筛直接笔试/面试
 
二、简历怎么写（Java + AI 岗必看）
一页纸、PDF、排版干净、关键词密集
1. 技能栏（精准匹配 JD）
- Java 后端：
Java、Spring Boot、Spring Cloud、MySQL、Redis、MyBatis-Plus、MQ、分布式、高并发、JVM、Git、Linux
- AI 方向（必须写）：
大模型 API 调用、RAG、向量数据库（Milvus/FAISS）、Prompt 工程、LangChain、AI Agent、LLaMA/Qwen 等开源模型
- 格式：
熟练：Java、Spring Boot、MySQL、Redis、RAG、大模型API
了解：LangChain、Milvus、Spring Cloud
2. 项目经历（重中之重）
2–3 个项目，1 个必须是 Java + AI 结合
- 结构（STAR+数据）：
- 项目名：基于 Spring Boot + 大模型的智能问答系统
- 技术栈：Java、Spring Boot、MySQL、Redis、Qwen API、RAG、Milvus
- 职责：负责后端开发、RAG 流程实现、接口设计
- 成果（量化）：
- 支持 1000+ 并发请求，响应时间 < 300ms
- 文档问答准确率达 90%+
- 减少人工客服重复咨询 40%
反例：做了图书管理系统、纯 CRUD、没 AI、没数据。
 
三、投递策略（时间+节奏）
1. 时间窗口
- 秋招（最重要）：7–10 月
- 春招（补录）：2–4 月
- 提前批：6 月就开始（一定要参加，竞争小）
2. 投递节奏
- 每周 5–8 家，别一天投几十家
- 同一公司间隔 7–14 天再投
- 海投 = 全沉；精准投 = 高通过率
3. 岗位选择（Java+AI）
优先搜这些关键词：
- 后端开发（Java）
- 大模型应用开发
- AI 工程/平台开发
- RAG 开发
- 智能系统研发
- 云原生 + AI
- 搜索/推荐/广告后端
base 优先：北京、上海、深圳、杭州、广州、成都、合肥
 
四、投递后怎么做
1. 问内推人：简历状态？是否进入笔试/面试？
2. 每天刷牛客：看笔经面经、AI 真题
3. 集中刷题：
- 算法：LeetCode 热题 100、剑指 Offer
- Java：集合、JVM、并发、Spring
- AI：RAG、Prompt、向量库、大模型调用原理
4. 准备项目讲稿：
- 清晰讲：做什么、用了什么技术、你负责什么、难点怎么解决、数据结果
 
五、避坑提醒
- ❌ 不要海投、乱投、重复投
- ❌ 不要Word 乱码、简历超 2 页、无 AI 项目
- ❌ 不要技能写“精通一切”、项目没数据、空话
- ✅ 一定要内推 + 精准匹配 + 1 个 Java+AI 项目 + 量化成果
