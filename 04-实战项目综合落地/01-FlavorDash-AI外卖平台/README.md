# Flavor Dash AI 外卖平台

> 单体 SpringBoot 架构 + AI 六大模块 | 复习第 11 天

---

## 项目概述

Flavor Dash 是一个融合 AI 能力的智能外卖平台，采用 **SpringBoot 单体架构**，在传统外卖业务基础上集成了 6 大 AI 模块。

## 技术架构

```
┌─────────────────────────────────────────┐
│           SpringBoot 单体应用             │
├─────────────────────────────────────────┤
│  Controller → Service → Mapper → DB      │
├─────────────────────────────────────────┤
│  MySQL │ Redis │ RabbitMQ │ ES           │
├─────────────────────────────────────────┤
│  微信支付 │ JWT认证 │ SSE流式              │
└─────────────────────────────────────────┘
```

## 基础能力

| 组件 | 用途 |
|------|------|
| MySQL | 用户/订单/商品持久化，索引优化 |
| Redis | 热点数据缓存、Session管理 |
| RabbitMQ | 订单异步处理、消息通知 |
| Elasticsearch | 商品/店铺全文检索 |
| 微信支付 | 支付回调、退款流程 |

## AI 六大模块

1. **智能客服** — 多轮对话，意图识别，FAQ自动应答
2. **评价情感分析** — NLP情感分类，准确率 **91%**
3. **智能调度** — 骑手-订单匹配优化
4. **NL2SQL 运营看板** — 自然语言转SQL，动态报表
5. **个性化推荐** — 用户画像 + 协同过滤
6. **智能补货预测** — 销量预测 → 库存建议

## 核心技术难点

| 难点 | 解决方案 |
|------|----------|
| 多模型统一网关 | 抽象工厂模式，支持 OpenAI / 千问 / 文心多厂商切换 |
| SSE 流式输出 | Spring Boot SSE + 前端 EventSource |
| 缓存一致性 | Cache Aside + 延迟双删 |
| 情感分析准确率 | Fine-tune BERT 模型，91% 准确率 |
| 高并发 | 线程池隔离 + 限流 |

## 面试口述要点

1. **架构**：单体 SpringBoot，分层清晰，为什么选择单体而非微服务
2. **AI 亮点**：6 大 AI 模块的设计思路和业务价值
3. **量化指标**：情感分析 91%、推荐点击率提升 X%
4. **难点攻克**：多模型网关设计、SSE 流式方案
