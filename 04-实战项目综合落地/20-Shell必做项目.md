## 五、必练核心知识点

### 1. 变量与数组
```bash
# 变量
name="admin"
echo $name

# 数组
arr=(1 2 3 4 5)
echo ${arr}
echo ${arr[@]}
```

### 2. 循环与条件
```bash
# for 循环
for i in {1..10}; do
  echo $i
done

# if 条件
if [ $a -gt $b ]; then
  echo "a > b"
fi
```

### 3. 函数
```bash
function backup() {
  echo "开始备份"
  # 备份逻辑
}

backup
```

### 4. grep / sed / awk
```bash
# grep 过滤
grep "error" log.txt

# sed 替换
sed 's/old/new/g' file.txt

# awk 统计
awk '{sum+=$1} END {print sum}' file.txt
```

### 5. 定时任务
```bash
# 每天 2 点执行备份
0 2 * * * /path/to/backup.sh
```

## 九、Shell vs Python 自动化选型

| 特性 | Shell | Python |
|------|-------|--------|
| 学习曲线 | 平缓 | 陡峭 |
| 系统调用 | 强 | 中 |
| 复杂逻辑 | 弱 | 强 |
| 跨平台 | 弱 | 强 |
| 适用场景 | Linux 运维 / 简单脚本 | 复杂逻辑 / 跨平台 |

**建议**：
- 系统运维优先 Shell
- 复杂逻辑优先 Python
- 两者结合使用
