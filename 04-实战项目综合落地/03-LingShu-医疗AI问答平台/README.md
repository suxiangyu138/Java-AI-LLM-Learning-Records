# LingShu 医疗 AI 问答平台

> 14 步医疗 RAG 管线 + ReAct Agent + 多层安全护栏 | 复习第 13 天

---

## 项目概述

LingShu 是一个面向医疗场景的 AI 智能问答平台，核心是 **14 步完整 RAG 管线** 和 **ReAct 医疗 Agent**，对安全性和准确性要求极高。

## 14 步医疗 RAG 管线

```
数据采集 → PHI脱敏 → 文档解析 → 智能切片
    → Embedding 向量化 → Milvus 向量入库
    → 用户Query → Query改写 → 多路召回(BM25+向量)
    → RRF 融合 → MMR 重排序 → LLM 生成
    → 幻觉检测 → 安全审核 → 最终输出
```

## 核心技术点

### 1. 数据处理层
| 步骤 | 技术 |
|------|------|
| 数据采集 | Python 爬虫采集医学文献、药品说明书 |
| PHI 脱敏 | 正则 + NER 识别姓名/身份证/电话并脱敏 |
| 智能切片 | 按段落+语义分块，保留上下文重叠 |
| Embedding | 中文医疗领域微调模型 |

### 2. 检索增强层
- **多路召回**：BM25 关键词 + 向量语义检索
- **RRF 融合**：Reciprocal Rank Fusion 合并两路结果
- **MMR 重排序**：最大边际相关性，保证结果多样性

### 3. ReAct 医疗 Agent

```
Thought → Action → Observation → Thought → ... → Final Answer
```

5 大业务技能（YAML 热加载）：
- `symptom_check` — 症状自查
- `drug_query` — 药品查询
- `medical_knowledge` — 医学知识问答
- `appointment_guide` — 就医指导
- `emergency_triage` — 急救分诊

### 4. 多层安全护栏

```
输入校验 → 敏感词过滤 → PHI脱敏
    → 医疗合规审核 → 幻觉检测
    → 免责声明追加 → 输出
```

- **幻觉抑制**：答案溯源 + 置信度评分 + 拒答机制
- **合规要求**：医疗免责声明、超出能力范围拒答

## 面试口述要点

1. **14 步管线**：每个环节的设计初衷和解决的问题
2. **RAG vs 微调**：为什么选择 RAG 而非微调（可控性、时效性、幻觉可控）
3. **安全护栏**：医疗场景的特殊安全要求，多层校验的必要性
4. **Agent 设计**：ReAct 循环 + Skill 热加载的架构优势
