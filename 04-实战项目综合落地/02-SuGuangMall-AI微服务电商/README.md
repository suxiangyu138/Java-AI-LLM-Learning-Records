# SuGuangMall AI 微服务电商

> Spring Cloud Alibaba 微服务 + Multi-Agent 购物管家 + 高并发秒杀 | 复习第 12 天

---

## 项目概述

SuGuangMall 是一个全功能的 AI 微服务电商平台，采用 **Spring Cloud Alibaba** 微服务架构，核心亮点是 **Multi-Agent 购物管家** 和 **高并发秒杀系统**。

## 微服务架构

```
┌──────────────────────────────────────────────────┐
│                  Gateway (网关)                    │
├────────┬────────┬────────┬────────┬──────────────┤
│ 用户服务 │ 商品服务 │ 订单服务 │ 秒杀服务 │ AI购物管家  │
├────────┴────────┴────────┴────────┴──────────────┤
│  Nacos(注册/配置) │ Sentinel(限流/熔断)             │
├──────────────────────────────────────────────────┤
│  MySQL │ Redis │ RocketMQ │ Seata(分布式事务)      │
└──────────────────────────────────────────────────┘
```

## 核心技术栈

| 组件 | 作用 |
|------|------|
| Nacos | 服务注册发现 + 配置中心 |
| Gateway | 统一入口、JWT鉴权、路由转发 |
| OpenFeign | 服务间 RPC 调用 |
| Sentinel | 限流、熔断、降级 |
| Seata | 分布式事务（AT模式） |
| Dubbo | 高性能 RPC（部分服务） |

## Multi-Agent 购物管家

```
用户意图 → 意图路由 Agent → ┬→ 商品推荐 Agent
                            ├→ 比价 Agent
                            ├→ 优惠券 Agent
                            └→ 售后 Agent
                                   ↓
                            Planner 规划 → 汇总回复
```

- **召回率提升 40%**：RAG 导购链路（BM25 + 向量检索 + RRF 融合）

## 高并发秒杀完整链路

```
Nginx 限流 → Gateway → Sentinel QPS限流
    → Redis Lua 原子扣库存
    → RocketMQ 异步下单
    → 延迟队列 30min 未支付关单
    → 零超卖保证
```

### 秒杀防超卖方案
1. **Nginx 层**：IP 限流 + 令牌桶
2. **网关层**：Sentinel 热点参数限流
3. **业务层**：Redis Lua 脚本原子扣库存（`DECR + 判断`）
4. **补偿层**：定时任务对账，兜底回滚

## 面试口述要点

1. **微服务拆分原则**：按业务域拆分，服务边界清晰
2. **Multi-Agent 设计**：意图路由 → 多 Agent 并行 → Planner 汇总
3. **秒杀全链路**：从前到后逐层限流/削峰，零超卖
4. **RAG 导购**：召回率提升 40% 的原因（多路召回 + RRF）
