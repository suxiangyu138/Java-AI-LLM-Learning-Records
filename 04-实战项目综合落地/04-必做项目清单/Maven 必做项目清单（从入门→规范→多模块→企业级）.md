# Maven 必做项目清单（从入门 → 规范 → 多模块 → 企业级）

---

## 一、入门必做（吃透 Maven 基础核心）

### 1. 单模块 Java 项目从零构建

**核心知识点**  
- Maven 三大生命周期与常用阶段：`clean`、`compile`、`test`、`package`、`install`、`deploy`  
- `pom.xml` 基础结构：坐标（groupId/artifactId/version）、依赖、打包方式、JDK 版本  
- 标准目录结构：`src/main/java`、`src/main/resources`、`src/test/java`  

**核心功能**  
- 从空目录手写 `pom.xml`  
- 完成编译、测试、打包、本地仓库安装全流程  

**预计耗时**：1 天  

---

### 2. 依赖管理与冲突解决实战

**核心知识点**  
- 依赖范围：`compile` / `test` / `provided` / `runtime`  
- 依赖传递、`exclusions` 依赖排除  
- 版本锁定：`dependencyManagement`  
- 使用 `mvn dependency:tree` 分析依赖树与冲突  

**核心功能**  
- 解决常见 Jar 包版本冲突与重复依赖问题  

**预计耗时**：1–2 天  

---

### 3. 自定义属性与资源过滤

**核心知识点**  
- `pom.xml` 自定义属性（`<properties>`）与引用  
- 资源文件过滤、`${}` 占位符替换  
- Profile 多环境配置（`dev` / `test` / `prod`）  

**核心功能**  
- 一套代码适配多环境  
- 打包时自动替换配置（数据库、域名等）  

**预计耗时**：1 天  

---

## 二、进阶必做（工程规范 + 插件体系）

### 4. 整合常用插件体系

**核心知识点**  
- 编译插件：`maven-compiler-plugin`（JDK 版本、编码）  
- 打包插件：`maven-jar-plugin` / `maven-war-plugin`  
- 单元测试插件：`maven-surefire-plugin`  
- 代码规范与质量插件：`checkstyle`、`spotbugs`  

**核心功能**  
- 标准化项目构建流程  
- 在构建阶段强制执行代码规范与静态检查  

**预计耗时**：2 天  

---

### 5. SpringBoot 项目 Maven 工程化

**核心知识点**  
- 继承 SpringBoot 父工程（`spring-boot-starter-parent`）  
- starter 依赖机制与版本对齐  
- `spring-boot-maven-plugin` 一键打包与运行  
- 可执行 Jar 打包、外部配置文件加载  

**核心功能**  
- 规范 SpringBoot 项目的依赖与构建  
- `mvn package` 直接产出可执行 Jar  

**预计耗时**：1 天  

---

### 6. 单元测试与测试覆盖率

**核心知识点**  
- JUnit 5 整合与测试用例编写  
- 覆盖率插件：`jacoco-maven-plugin`  
- 跳过测试、指定模块 / 用例执行  

**核心功能**  
- 在构建流程中自动执行测试  
- 输出覆盖率报告，保证基础测试质量  

**预计耗时**：1 天  

---

## 三、核心必做（多模块项目，企业级架构刚需）

### 7. 父子多模块聚合项目

**核心知识点**  
- 父 POM：统一管理版本、依赖、插件、编码、JDK  
- 子模块继承父 POM，模块间互相依赖  
- 聚合模块与独立构建：`<modules>` + 并行构建  

**项目场景**  
- `common` 公共模块、`service` 业务模块、`web` 接口模块拆分  

**预计耗时**：2 天  

---

### 8. 自定义公共依赖组件

**核心知识点**  
- 编写通用工具类、异常类、通用配置类  
- 独立模块打包为 Jar，发布至本地 / 私服仓库  
- 多个项目通过 Maven 依赖统一复用  

**核心功能**  
- 提升代码复用率  
- 统一团队基础组件与规范  

**预计耗时**：2 天  

---

### 9. 多环境打包与配置分离

**核心知识点**  
- Maven Profile + SpringBoot 多环境配置文件  
- 不同环境资源的包含 / 排除  
- 一套 POM 支持多环境构建  

**核心功能**  
- 一键打出 `dev` / `test` / `prod` 对应的包  
- 方便按环境部署与回滚  

**预计耗时**：1–2 天  

---

## 四、高阶必做（私服、插件、部署一体化）

### 10. 搭建 Maven 私服（Nexus）

**核心知识点**  
- Nexus 安装与基础配置  
- 仓库类型：`hosted` / `proxy` / `group`  
- 项目配置私服镜像，上传 / 下载制品  
- 私服权限与仓库分组管理  

**核心功能**  
- 企业级依赖管理  
- 私有组件托管、加速依赖下载  

**预计耗时**：2–3 天  

---

### 11. 自定义 Maven 插件开发

**核心知识点**  
- 编写 Mojo（插件目标），使用注解定义参数  
- 插件绑定到生命周期阶段（如 `generate-sources`）  
- 插件参数配置与在 POM 中复用  

**核心功能**  
- 开发自定义构建工具，如代码生成、资源预处理、配置检查等  

**预计耗时**：3 天  

---

### 12. Maven + Docker 一体化打包

**核心知识点**  
- 使用 `docker-maven-plugin` 或 `jib-maven-plugin`  
- 构建镜像并推送到私有镜像仓库  
- 多阶段构建、镜像瘦身策略  

**核心功能**  
- `mvn package` / `mvn deploy` 时自动生成 Docker 镜像  
- 打通 Java 构建与容器化部署链路  

**预计耗时**：2 天  

---

## 五、工程化必做（CI/CD、版本规范）

### 13. Maven + GitHub Actions 自动化流水线

**核心知识点**  
- Push / PR 触发自动构建、测试、打包  
- 缓存 Maven 仓库加速流水线  
- 制品上传（如 Release 产物、Jar 包、镜像）  

**核心功能**  
- 提交代码后自动执行：编译 → 测试 → 打包  
- 可选自动发布到私服或容器仓库  

**预计耗时**：2 天  

---

### 14. 版本号规范与发布管理

**核心知识点**  
- `maven-release-plugin` 使用  
- SNAPSHOT 与 Release 版本切换  
- 自动打 Tag、更新 POM 版本号  

**核心功能**  
- 规范版本管理与发布节奏  
- 标准化项目发布流程（发布准备 → 发布 → 回滚）  

**预计耗时**：2 天  

---

1. 单模块 Java 项目从零构建  
2. 依赖管理与冲突解决实战  
3. SpringBoot 项目 Maven 工程化  
4. 父子多模块聚合项目

6. Maven + Docker 一体化打包

## 七、项目落地标准（可直接写进简历）

1. 所有项目 `pom.xml` 尽量手写与精简配置，不依赖 IDE 默认生成。  
2. 熟练掌握并能在项目中体现：  
   - 生命周期与常用命令  
   - 依赖管理、传递、排除、冲突解决  
   - 多模块聚合、父子 POM 继承  
   - 插件使用与基础配置  
   - 私服上传 / 下载配置  

3. GitHub README 建议包含：  
   - 构建命令示例（`mvn clean package` / `mvn deploy`）  
   - 环境 / Profile 说明  
   - 多模块结构图  
   - 与 Docker / CI/CD 的整合说明  

4. 能独立处理以下常见问题：  
   - Jar 冲突导致的 `ClassNotFound` / `NoSuchMethodError`  
   - 构建失败（插件配置错误、JDK 版本不一致等）  
   - 多环境配置切换  
   - 私服认证 / 上传失败
