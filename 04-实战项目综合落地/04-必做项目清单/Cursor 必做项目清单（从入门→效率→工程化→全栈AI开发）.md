# Cursor 必做项目清单（从入门 → 效率 → 工程化 → 全栈 AI 开发）

---

## 一、入门必做（吃透 Cursor 基础能力）

### 1. 单文件极速开发：Java 工具类生成

**核心能力**  
- 自然语言生成完整 Java 代码  
- 自动补全、语法纠错、注释生成  
- 代码格式化、命名规范优化  

**项目场景**  
- 时间工具类、加密工具类、JSON 工具类、文件工具类  
- 要求：企业级注释、异常处理、单元测试  

**Prompt 示例**  
- 帮我写一个 Java 的 MD5 加密工具类，要求：静态方法、参数校验、异常捕获、完整注释、JUnit 单元测试  

**预计耗时**：0.5 天  

---

### 2. 代码 Debug 与 Bug 修复实战

**核心能力**  
- 选中报错代码，一键定位 Bug 并自动改写  
- 分析堆栈信息，给出修复方案  
- 解释错误原因与预防方式  

**项目场景**  
- 空指针、数组越界、并发安全问题、SQL 语法错误  
- 要求：不仅修复，还要生成“错误原因说明 + 避免方式”文档  

**预计耗时**：0.5 天  

---

### 3. 代码重构与风格统一

**核心能力**  
- 一键重构：变量命名、函数拆分、逻辑精简  
- 统一代码风格、消除冗余  
- 旧代码现代化改造  

**项目场景**  
- 把混乱 Java 代码改成面向对象 + 设计模式风格  
- 把 Python 脚本改成模块化 + 类型注解规范代码  

**预计耗时**：1 天  

---

## 七、Cursor 核心高效 Prompt 公式

1. 代码生成  
   - 角色 + 需求 + 技术栈 + 规范 + 输出格式  

2. 代码重构  
   - 选中代码 + 指令：简化逻辑 / 优化性能 / 统一风格 / 拆分函数  

3. Debug 修复  
   - 粘贴报错 + 指令：定位 Bug、解释原因、提供修复代码、增加防御性判断  

4. 架构设计  
   - 描述业务需求 + 指令：设计项目架构、分层结构、技术选型、模块划分  

---

## 八、项目落地标准（真正发挥 Cursor 价值）

1. 尽量让 Cursor 负责重复代码生成，自己负责审查与关键决策  
2. 使用全文件上下文能力，让 Cursor 理解整个项目结构  
3. 生成代码必须包含：异常处理、参数校验、注释、单元测试  
4. 建议给项目编写 `.cursorrules`，固化开发规范与架构规则
