# Ollama 实战项目清单

## 一、核心能力

Ollama 是本地私有化大模型部署方案，核心应用场景：

- 企业数据隐私保护
- 本地知识库问答
- 智能体开发
- Java 后端整合

---

## 二、技术能力拆解

- 部署层：模型拉取 / 运行 / 参数调优
- 接口层：RESTful API / 流式输出 / 上下文管理
- 工程层：Java 封装 / 异常处理 / 并发控制
- RAG 层：文档解析 / 向量化 / 检索增强
- Agent 层：工具调用 / 任务规划 / 记忆管理
- 架构层：网关 / 限流 / 容器化 / 集群

---

## 三、必做项目（求职优先级）

### 1. 本地大模型部署与基础对话
**技术栈**：Ollama + 终端 / Postman

**实现**：
- 安装 Ollama
- 拉取 / 运行 / 卸载模型
- 基础对话测试
- 温度系数 / TopP 参数调优
- RESTful API 调用
- 流式 SSE 输出

**核心知识点**：
- Ollama 基础命令
- 参数调优控制回答风格
- API 接口结构
- 流式与非流式输出区别

**产出**：
