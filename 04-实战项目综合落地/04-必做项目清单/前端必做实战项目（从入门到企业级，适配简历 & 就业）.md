# 前端必做实战项目清单（入门 → 企业级 → 全栈AI融合）

> 适配方向：Java后端 + AI大模型 + 全栈开发  
> 核心目标：原生基础 → Vue3工程化 → 前后端联调 → AI应用融合  
> 简历定位：打造「前端+后端+AI」三位一体差异化竞争力  
> 落地标准：所有项目可本地跑通，提供源码 + 部署文档

## 一、入门级：原生 HTML/CSS/JS（夯实基本功）

**目标**：吃透盒模型、Flex/Grid、DOM操作、异步、ES6+，不依赖框架，理解前端底层逻辑[web:11]

### 1. 个人静态简历网页
**核心功能**
- 响应式布局（PC + 移动端）
- 轮播图（自动切换 + 手动切换）
- 导航栏（锚点跳转 + 吸顶效果）
- 技能展示（进度条动画）
- 联系表单（校验 + 提交）
- CSS 动画过渡

**核心技术**
- HTML5 语义化标签
- CSS3 动画（transition / animation）
- Flex / Grid 布局
- 媒体查询（@media）

**交付标准**
- 适配至少 3 种屏幕尺寸
- 支持暗黑模式切换

**预计耗时**：2~3 天

### 2. ToDoList 待办事项

### 14. AI 智能对话 Web 端 ⭐⭐⭐
**核心功能**
- 对话气泡（用户 / AI 区分）
- 打字机动画（逐字显示）
- 历史会话管理（新建 / 删除 / 切换）
- 上下文记忆（多轮对话）
- Markdown 代码高亮（代码块渲染）
- 流式渲染（SSE / WebSocket）[web:17][web:20]

**核心技术**
- Vue3 Composition API
- SSE（Server-Sent Events）流式数据接收[web:17]
- Markdown-it 渲染

- 对接 SpringBoot + Spring AI 后端

**Java 后端联动**
- SpringBoot 提供 SSE 流式接口
- 对接 Ollama / OpenAI API
- Redis 存储会话历史

**交付标准**
- 流畅的打字机效果
- 支持代码块复制
- 完整的错误处理

**预计耗时**：6~7 天
