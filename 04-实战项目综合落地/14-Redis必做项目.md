# Redis 实战项目清单

## 一、核心能力

Redis 是 Java 后端必备的高性能缓存与数据存储中间件，必须掌握：

- 五大数据结构
- 缓存三大问题
- 分布式锁
- 限流与防刷
- 高并发场景应用
- 持久化与高可用

---

## 二、技术能力拆解

- 基础层：String / List / Hash / Set / ZSet
- 缓存层：缓存穿透 / 击穿 / 雪崩 / 更新策略
- 并发层：分布式锁 / 原子操作 / Lua 脚本
- 限流层：计数器 / 滑动窗口 / 令牌桶
- 队列层：消息队列 / 延迟队列
- 高可用层：主从复制 / 哨兵 / 集群
- 优化层：慢查询 / 内存优化 / 持久化

## 五、必练核心知识点

### 1. 五大数据结构
```bash
# String
SET key value
GET key
INCR key
EXPIRE key seconds

# Hash
HSET key field value
HGET key field
HGETALL key

# List
LPUSH key value
RPUSH key value
LRANGE key 0 -1

# Set
SADD key member
SMEMBERS key
SINTER key1 key2

# ZSet
ZADD key score member
ZRANGE key 0 -1 WITHSCORES
ZREVRANGE key 0 9
```

### 2. 分布式锁
```java
// 加锁
SET lock_key unique_value NX EX 30

// Lua 脚本解锁
if redis.call("get", KEYS) == ARGV then
    return redis.call("del", KEYS)
else
    return 0
end
```

### 3. 限流
```java
// 计数器限流
INCR rate_limit:user_id
EXPIRE rate_limit:user_id 60
```

### 4. 缓存更新
```java
// Cache Aside
// 1. 删除缓存
// 2. 更新数据库
// 3. 读取时查数据库并回写缓存
```

## 九、Redis vs Memcached 选型

| 特性 | Redis | Memcached |
|------|-------|-----------|
| 数据结构 | 丰富（5 种） | 单一（String） |
| 持久化 | 支持 | 不支持 |
| 分布式锁 | 支持 | 不支持 |
| 单线程 | 是 | 多线程 |
| 适用场景 | 复杂业务 / 持久化 | 纯缓存 |
