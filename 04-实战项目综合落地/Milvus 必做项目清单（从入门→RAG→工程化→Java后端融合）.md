# Milvus 实战项目清单

## 一、核心能力

Milvus 是企业级分布式向量数据库，核心应用场景：

- RAG 检索增强生成
- 语义搜索
- 推荐系统
- 多模态检索

---

## 二、技术能力拆解

- 存储层：Collection / Schema / Field / Partition
- 索引层：FLAT / IVF_FLAT / HNSW
- 检索层：L2 / IP / COSINE
- 调优层：分片 / 副本 / 负载均衡
- 工程层：Java SDK / 权限隔离 / 高并发

---

## 三、必做项目（求职优先级）

### 1. Milvus 本地部署 & 向量 CRUD
**技术栈**：Docker Compose + Milvus + Python SDK

**实现**：
- Collection 创建与管理
- 向量插入 / 查询 / 删除
- 索引构建（FLAT / IVF_FLAT / HNSW）
- 距离计算（L2 / IP / COSINE）

**产出**：
- 基础向量数据库操作能力

**耗时**：1~2天

---

### 2. PDF 文档 RAG 问答系统
**技术栈**：LangChain + Milvus + Ollama + PyPDFLoader

**实现**：
- PDF 加载 → 文本分块 → 向量化
- Milvus 持久化存储
- 向量检索 + 大模型生成
- 答案溯源（引用原文）

**产出**：
- 私有知识库问答系统

**耗时**：3天

---

### 3. 多文档混合知识库系统
**技术栈**：Milvus + LangChain

**实现**：
- 批量文档加载（PDF / TXT / MD）
- Partition 分区管理
- 增量向量入库
- 跨文档检索 + 去重

**产出**：
- 企业级多源文档知识库

**耗时**：3天

---

### 4. 混合检索 RAG（向量 + 关键词）
**技术栈**：Milvus + Elasticsearch

**实现**：
- 稠密向量检索（Milvus）
- 稀疏关键词检索（ES）
- RRF 融合排序
- 重排序优化

**产出**：
- 高精度混合检索系统

**耗时**：4天

---

### 5. SpringBoot 整合 Milvus 企业级 RAG
**技术栈**：SpringBoot + Spring AI + Milvus Java SDK

**实现**：
- Milvus Java SDK 封装
- 向量插入 / 检索 / 分页
- 统一异常处理
- RESTful API 设计

**产出**：
- Java 后端 RAG 服务

**耗时**：4天

---

### 6. 大模型知识库管理后台
**技术栈**：SpringBoot + Milvus + MySQL + Vue

**实现**：
- 用户 / 角色 / 权限管理
- 文档上传 → 分块 → 入库
- 检索接口 + 问答记录
- 日志统计 + 监控

**产出**：
- 可上线的企业级知识库平台

**耗时**：5~6天
