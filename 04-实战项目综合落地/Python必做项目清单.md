# Python 实战项目清单

## 一、核心能力

Python 必须掌握的主线能力：

- 基础语法与编程思维
- 自动化脚本开发
- 爬虫与数据获取
- 数据分析与可视化
- Web 后端开发
- AI / 机器学习应用
- 工程化与部署能力

---

## 二、技术能力拆解

- 基础层：变量 / 循环 / 函数 / 面向对象 / 文件操作
- 脚本层：批处理 / 定时任务 / PDF / Excel / 邮件自动化
- 爬虫层：静态抓取 / 动态抓取 / 异步并发 / 反爬处理
- 分析层：Pandas / NumPy / Matplotlib / Pyecharts
- Web 层：Flask / Django / FastAPI
- AI 层：sklearn / PyTorch / Transformers / RAG / Ollama
- 工程层：MySQL / Redis / Docker / JWT / 日志 / 部署
