# HTML + CSS + JavaScript 必做项目清单（原生无框架，从入门到高阶）

---

## 一、入门级（语法巩固：静态 + 简单交互）

> 目标：掌握 HTML 语义化、CSS 布局、基础 JS 与 DOM 操作

### 1. 个人介绍静态网页

**功能**  
- 顶部导航栏（锚点跳转：简介 / 技能 / 项目 / 联系）  
- 个人信息展示（头像、简介、教育背景）  
- 技能卡片（栅格展示、不同颜色标签）  
- 联系表单（姓名、邮箱、留言）  
- 响应式适配（移动端单列、PC 多列）  

**核心知识点**  
- HTML5 语义化标签：`header` / `nav` / `main` / `section` / `footer`  
- CSS 基础选择器、层级选择器、伪类  
- Flex 布局、简单栅格布局  
- 媒体查询实现移动端适配  

---

### 2. 精美登录 / 注册页面

**功能**  
- 登录 / 注册切换（tab 或卡片翻转）  
- 表单布局（输入框、记住密码、多选框）  
- 输入校验（必填、长度、格式）  
- 密码显示 / 隐藏切换  
- 简单动画过渡（淡入淡出、滑动切换）  

**核心知识点**  
- 表单标签与表单属性  
- CSS 伪类：`:focus`、`:hover`、`:valid`、`:invalid`  
- JS 表单校验、`input` / `submit` 事件监听  
- 简单过渡动画：`transition` / `transform`  

---

### 3. 轮播图组件

**功能**  
- 自动轮播（定时切换）  
- 左右箭头手动切换  
- 底部指示器（圆点切换）  
- 鼠标悬停暂停、离开继续  

**核心知识点**  
- `setInterval` / `clearInterval` 定时器控制  
- DOM 元素切换，类名切换控制当前激活项  
- 位移动画（`translateX` + 过渡）  
- 事件绑定与解绑  

---

### 4. 简单倒计时

**功能**  
- 输入目标时间，显示剩余天 / 时 / 分 / 秒  
- 倒计时结束展示提示文案  
- 可以快速重置倒计时  

**核心知识点**  
- `Date` 对象、时间差计算  
- `setInterval` 周期更新  
- 字符串格式化（补零、拼接）  

---

## 二、进阶级（DOM + 本地存储 + 异步请求）

> 目标：吃透 DOM 增删改查、事件委托、本地存储、Fetch/Ajax、基本算法逻辑

### 1. TodoList 待办清单

**功能**  
- 新增 / 删除 / 勾选完成待办事项  
- 按状态筛选：全部 / 已完成 / 未完成  
- 使用 `localStorage` 持久化（刷新不丢数据）  
- 一键清空全部待办  

**核心知识点**  
- DOM 动态渲染列表（`createElement` / `innerHTML`）  
- 事件委托处理列表项点击事件  
- `localStorage` 存取 JSON 数据  
- 数组操作：`map` / `filter` / `forEach`  

---

### 2. 计算器

**功能**  
- 基础四则运算：加 / 减 / 乘 / 除  
- 退格、清空、支持小数点  
- 防止连续运算符、除零等非法输入  

**核心知识点**  
- 按钮点击事件处理与按键映射  
- 字符串处理与表达式构建  
- 运算逻辑与边界情况判断  

---

### 3. 天气查询应用

**功能**  
- 输入城市名称查询天气  
- 展示温度、湿度、天气状况、风速等  
- 错误处理：城市不存在 / 网络错误提示  

**核心知识点**  
- `fetch` 异步请求、`Promise` 基础  
- JSON 数据解析与 DOM 渲染  
- 简单跨域概念（了解浏览器限制与常见方案）  
- 加载中状态与错误提示 UI  

---

### 4. 贪吃蛇小游戏

**功能**  
- 键盘方向键控制蛇移动  
- 随机生成食物、吃到食物加长、得分统计  
- 撞墙 / 撞到自身后游戏结束  

**核心知识点**  
- 定时器驱动游戏循环  
- 方向键监听与方向状态管理  
- 二维坐标 / 数组维护蛇身体位置  
- 碰撞检测算法（边界、身体）  

---

## 三、高阶实战（动画 + 性能 + 复杂交互）

> 目标：掌握 CSS3 动画、JS 高级特性、防抖节流、懒加载、复杂组件封装

### 1. 音乐播放器

**功能**  
- 播放 / 暂停、上一首 / 下一首  
- 进度条拖拽、音量调节  
- 显示当前播放时间 / 总时长  
- 简单歌词同步（行高亮）  

**核心知识点**  
- `audio` 标签及其 API（`play` / `pause` / `currentTime` / `volume`）  
- 进度条拖拽事件与百分比计算  
- 时间格式化显示  
- 播放状态与 UI 同步更新  

---

### 2. 图片懒加载 + 瀑布流布局

**功能**  
- 页面滚动时懒加载图片（首屏快、后续按需加载）  
- 瀑布流自适应布局（不同高度图片自动排布）  
- 防止滚动卡顿  

**核心知识点**  
- `IntersectionObserver` 监听元素进入视口  
- 滚动事件节流处理（手写节流函数）  
- 瀑布流布局算法（列高度管理）  

---

### 3. 在线时钟

**功能**  
- 模拟指针时钟（时针、分针、秒针实时旋转）  
- 数字时钟显示当前时间  
- 昼夜模式背景切换  

**核心知识点**  
- 利用 `Date` 对象获取当前时间  
- 三角函数 / 角度计算（时间 → 旋转角度）  
- CSS `transform: rotate()` 动画  
- 定时器精度与性能考虑  

---

### 4. 暗黑模式切换网页

**功能**  
- 一键切换亮色 / 暗色主题  
- 使用 `localStorage` 记住主题偏好  
- 全局样式随主题切换而变化  

**核心知识点**  
- CSS 变量（`--color-bg` 等）管理主题色  
- 类名切换或 `data-theme` 属性切换  
- `localStorage` 持久化主题设置  

---

## 四、创意趣味项目（练手 + 简历小亮点）

### 1. 打字练习器

**功能**  
- 随机展示练习文本  
- 实时统计：输入字符数、正确率、打字速度（字数 / 分钟）  
- 支持倒计时模式 & 自由练习模式  

**核心知识点**  
- 键盘事件监听与输入捕获  
- 文本逐字符比对、错误标记  
- 简单性能统计与 UI 实时刷新  

---

### 2. 随机点名器

**功能**  
- 导入 / 编辑姓名列表  
- 随机滚动展示人名，一键停止抽取  
- 记录已点到的人，避免重复  

**核心知识点**  
- 数组打乱、随机算法（如 Fisher-Yates 洗牌）  
- 定时器实现“滚动”动画  
- 使用 `localStorage` 存储名单与历史记录  

---

### 3. 手绘画板

**功能**  
- 鼠标按下拖拽绘制线条  
- 切换画笔颜色、粗细  
- 一键清空画布  

**核心知识点**  
- `canvas` 基础 API（`moveTo` / `lineTo` / `stroke`）  
- 鼠标事件坐标计算（`clientX` / `clientY` → 画布坐标）  
- 状态机：按下 / 移动 / 松开  

---

### 4. 表单验证大全

**功能**  
- 手机号 / 邮箱 / 密码 / 身份证等正则校验  
- 输入实时提示错误原因  
- 不通过校验禁止提交  

**核心知识点**  
- 正则表达式基础与常见规则编写  
- 表单提交事件拦截与校验逻辑封装  
- 错误提示组件化（统一样式与位置）  

---

   - 天气查询应用  
   - 贪吃蛇小游戏  

3. **第三阶段：复杂交互与性能**  
   - 音乐播放器  
   - 图片懒加载 + 瀑布流布局
