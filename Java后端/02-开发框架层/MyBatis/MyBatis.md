MyBatis
以下是几本适合学习 MyBatis 的中文书籍推荐：
1.《MyBatis核心技术全解与项目实战》
• 作者：赖帆（@谷哥的小弟）
• 内容简介：这本书从实际项目出发，详细介绍了 MyBatis 的开发环境、基本操作、运行原理、关联映射、动态 SQL、缓存机制、注解开发、插件技术、逆向工程以及 MyBatis-Plus。最后一章结合 Spring Boot 技术，详细介绍了 MyBatis 在项目实战中的应用。
• 适用人群：适合初学者和有一定经验的开发者。
2.《Spring+Spring MVC+MyBatis从零开始学（视频教学版）（第3版）》
• 作者：杨章伟
• 内容简介：这本书全面讲解了使用 SSM（Spring+Spring MVC+MyBatis）进行 JavaEE Web 开发的技术，以“学生选课管理系统”为主线，涵盖 MyBatis 基础、核心配置、动态 SQL、关联映射等内容，并提供了丰富的实战案例。
• 适用人群：适合 SSM 框架初学者、Java Web 应用开发初学者以及高等院校学生。
3.《MyBatis从入门到精通》
• 作者：刘增辉
• 内容简介：这本书系统性地讲解了 MyBatis 的使用技巧和最佳实践，内容涵盖基础操作、高级特性、源码解析以及与 Spring 的整合。作者刘增辉是 MyBatis 分页插件 PageHelper 和通用 Mapper 的原作者，对 MyBatis 有深入研究。
• 适用人群：适合从入门到进阶的开发者。
这些书籍内容丰富，既有理论讲解，又有实战案例，能够帮助你系统地学习 MyBatis。
