# 命令行速查大全（Java 后端开发版）

> **定位**：Windows CMD + PowerShell + Linux Bash 三合一速查手册
> **原则**：按开发场景组织，不按系统分类，用的时候能立刻找到

---

## 一、三大 Shell 一句话定位

| Shell | 定位 | 在哪用 |
|---|---|---|
| **CMD** | Windows 原生，简单直接 | 本地开发、跑脚本 |
| **PowerShell** | Windows 高级 Shell，对象管道 | 自动化运维、批量处理 |
| **Bash** | Linux/Mac 默认，生态最广 | 服务器、Docker、Git Bash |

## 二、文件与目录（最高频）

| 场景 | CMD | PowerShell | Bash | 口诀 |
|---|---|---|---|---|

| 列出文件 | `dir` | `ls` / `Get-ChildItem` | `ls -la` | list |

| 创建目录 | `mkdir name` | `mkdir name` | `mkdir -p a/b/c` | make directory |
| 删除目录 | `rmdir /s name` | `rm -r name` | `rm -rf name` | ⚠️ -rf 是核武器 |
| 创建文件 | `echo > file.txt` | `New-Item file.txt` | `touch file.txt` | 三个系统三个写法 |
| 复制文件 | `copy a b` | `Copy-Item a b` | `cp a b` | |

## 三、文本处理三剑客（Bash 独有，日志分析利器）

### 3.1 grep — 内容过滤

```bash
# 找日志中的 ERROR
grep 'ERROR' app.log

# 找 ERROR 并显示前后 3 行
grep -B3 -A3 'ERROR' app.log

# 不区分大小写
grep -i 'error' app.log

# 反向匹配（排除）
grep -v 'DEBUG' app.log | grep -v 'INFO'

# 统计出现次数
grep -c 'NullPointerException' app.log

# 正则匹配
grep -E 'ERROR|WARN|FATAL' app.log

# 递归搜索目录
grep -r 'TODO' src/
```

### 3.2 awk — 列处理

```bash
# 取第 1、3 列
awk '{print $1, $3}' data.txt

# 按逗号分隔
awk -F',' '{print $2}' data.csv

# 条件过滤：第 3 列 > 100 的行
awk '$3 > 100' data.txt

# 统计总和
awk '{sum+=$2} END {print sum}' data.txt

# 日志分析：统计每个 IP 的请求数
awk '{print $1}' access.log | sort | uniq -c | sort -rn | head -10
```

### 3.3 sed — 流编辑

```bash
# 替换（全局）
sed 's/old/new/g' file.txt

# 删除空行
sed '/^$/d' file.txt

# 删除第 1 行
sed '1d' file.txt

# 只打印第 5-10 行
sed -n '5,10p' file.txt

# 原地修改（-i）
sed -i 's/8080/9090/g' application.yml
```

## 五、网络诊断（排查必备）

| 场景 | CMD | PowerShell | Bash |
|---|---|---|---|
| 查看 IP | `ipconfig` | `Get-NetIPAddress` | `ip addr` / `ifconfig` |
| 查看 IP 详情 | `ipconfig /all` | `Get-NetIPConfiguration` | `ip addr show` |
| 测试联通 | `ping baidu.com` | `Test-Connection baidu.com` | `ping -c 4 baidu.com` |
| 路由追踪 | `tracert baidu.com` | `Test-NetConnection -TraceRoute` | `traceroute baidu.com` |
| DNS 查询 | `nslookup baidu.com` | `Resolve-DnsName baidu.com` | `nslookup baidu.com` / `dig` |
| 端口占用 | `netstat -ano \| findstr 8080` | `netstat -ano \| Select-String 8080` | `netstat -tunlp \| grep 8080` / `ss -tunlp` |
| HTTP 请求 | `curl url` | `Invoke-WebRequest url` | `curl url` |
| 下载文件 | ❌ | `Invoke-WebRequest -OutFile` | `wget url` |

| 场景 | CMD | PowerShell | Bash |
|---|---|---|---|
| 查看所有进程 | `tasklist` | `Get-Process` | `ps aux` |
| 找 Java 进程 | `tasklist \| findstr java` | `Get-Process java` | `ps -ef \| grep java` |

| 杀进程 | `taskkill /PID 1234 /F` | `Stop-Process -Id 1234 -Force` | `kill -9 1234` |
| 杀所有 Java | `taskkill /F /IM java.exe` | `Stop-Process -Name java` | `pkill -9 java` |

## 七、权限与用户（Linux）

```bash
# 查看权限
ls -la                        # drwxr-xr-x 型
stat file                     # 详细权限信息

# 修改权限（r=4 w=2 x=1）
chmod 755 script.sh           # 所有者读写执行，其他人读执行
chmod +x script.sh            # 加执行权限

# 修改所有者
chown user:group file

# 切换到 root
sudo -i
sudo command                  # 单次提权

# 查看所有用户
cat /etc/passwd
```

## 九、管道与重定向

```bash
# Bash 管道：前一个命令的输出 → 后一个命令的输入
ps -ef | grep java | wc -l

# 输出重定向
command > file.txt      # 覆盖写入
command >> file.txt     # 追加写入

# 错误重定向
command 2> error.log    # 错误输出到文件
command 2>&1            # 错误合并到标准输出
command > all.log 2>&1  # 全部输出到一个文件

# 丢弃输出
command > /dev/null 2>&1  # Linux
command > NUL 2>&1        # Windows CMD
```

```powershell
# PowerShell 管道：传对象而非文本
Get-Process | Where-Object { $_.CPU -gt 100 } | Sort-Object CPU -Descending

# 等价 Bash 的做法
ps aux --sort=-%cpu | awk '$3 > 10'
```

## 十、组合拳速查

```bash
# --- 日志分析 ---
# 找最近 100 条错误
tail -100 app.log | grep ERROR

# 统计每小时的请求量
awk '{print substr($4,2,14)}' access.log | sort | uniq -c | sort -rn

# 找 500 错误的请求
grep ' 500 ' access.log | awk '{print $7}' | sort | uniq -c | sort -rn

# --- 端口与进程 ---
# 查谁占了 8080
lsof -i :8080
# 杀这个进程
kill -9 $(lsof -t -i :8080)

# 查所有 Java 进程内存使用
ps aux --sort=-%mem | grep java | head -5

# --- 磁盘 ---
# 找出大文件（>100M）
find . -type f -size +100M -exec ls -lh {} \;
# 找出大目录
du -sh * | sort -rh | head -10

# --- 批量操作 ---
# 批量改后缀
for f in *.txt; do mv "$f" "${f%.txt}.md"; done
# 批量删除 .class
find . -name "*.class" -delete
```
