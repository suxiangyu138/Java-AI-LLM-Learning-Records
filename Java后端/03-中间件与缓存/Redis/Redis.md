Redis
以下是几本由外国作者撰写且已被翻译成中文的 Redis 学习书籍推荐：
1.《Redis实战》
• 原名：Redis in Action
• 作者：Josiah L.Carlson
• 译者：黄健宏
• 内容简介：这本书深入浅出地介绍了 Redis 的 5 种数据类型，并通过多个实用示例展示了 Redis 的用法。书中还讲述了 Redis 的优化方法以及扩展方法，适合 Redis 新手以及有一定经验的使用者。
2.《Redis入门指南（第2版）》
• 原名：Redis for Beginners
• 作者：Karl Seguin
• 译者：未知（但有中文翻译版本）
• 内容简介：这是一本简洁的 Redis 入门书籍，适合初学者快速了解 Redis 的基本概念和操作。
3.《Redis 4.x Cookbook中文版》
• 原名：Redis 4.x Cookbook
• 作者：未知（原书作者为多位 Redis 专家）
• 译者：黄鹏程、王左非
• 内容简介：本书通过 80 多个实战案例，全面系统地讲解了 Redis 的技术应用，适合开发与运维人员参考。
4.《Redis深度历险：核心原理与应用实践》
• 原名：Redis Deep Dive
• 作者：未知（原书作者为 Redis 专家）
• 译者：钱文品
• 内容简介：适合有 Redis 基础的中高级开发者，书中深入讲解了 Redis 的核心原理和应用实践。
