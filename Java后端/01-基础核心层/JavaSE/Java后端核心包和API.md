Java后端核心包和API
Java后端核心API均来自JDK内置包，无需额外引入依赖，是后端开发的“基本功”。以下按功能分类，梳理最常用的核心包及对应高频API，兼顾实用性和易理解性，覆盖日常开发80%以上的基础场景。
一、核心基础包（java.lang，无需手动导入）
该包包含Java语言最基础的类和接口，是所有Java程序的基础，JVM会自动导入，无需手动写import语句。
核心类及API：
String：字符串操作核心类，高频方法：equals()（字符串比较）、length()（获取长度）、substring()（截取字符串）、replace()（替换内容）、split()（分割字符串）。
包装类（Integer、Long、Double、Boolean等）：对应基本数据类型，高频方法：valueOf()（基本类型转包装类）、parseXxx()（字符串转基本类型，如Integer.parseInt()）、toString()（转字符串）。
Object：所有类的根类，高频方法：equals()（对象比较）、hashCode()（获取哈希值）、toString()（对象转字符串）、wait()/notify()（线程通信）。
Thread/Runnable：线程相关，高频用法：继承Thread类或实现Runnable接口，重写run()方法，调用start()启动线程。
System：系统相关工具，高频方法：out.println()（控制台输出）、currentTimeMillis()（获取当前时间戳）、arraycopy()（数组复制）。
核心用途：定义Java语言的基础语法、数据类型、线程基础，是所有后端代码的“底层支撑”。
二、工具类集合包（java.util，高频使用）
该包包含大量实用工具类，覆盖集合、日期、随机数、比较器等，是后端开发中使用频率最高的包之一。
集合相关（核心中的核心）：
集合接口：List（有序可重复）、Map（键值对）、Set（无序不可重复）。
常用实现类及API：
ArrayList：List接口的主要实现类，高频方法：add()（添加元素）、get()（获取元素）、remove()（删除元素）、size()（获取长度）、forEach()（遍历）。
HashMap：Map接口的主要实现类，高频方法：put()（添加键值对）、get()（根据键取值）、containsKey()（判断键是否存在）、keySet()（获取所有键）、entrySet()（遍历键值对）。
HashSet：Set接口的主要实现类，高频方法：add()（添加元素）、contains()（判断元素是否存在）、remove()（删除元素）。
日期时间相关（JDK8+ 推荐）：
核心类：LocalDate（日期）、LocalTime（时间）、LocalDateTime（日期时间）、DateTimeFormatter（日期格式化）。
高频方法：now()（获取当前日期/时间）、of()（创建指定日期/时间）、format()（格式化日期）、parse()（字符串转日期）、plusDays()/minusDays()（日期增减）。
其他实用工具：
Optional：空值处理工具，避免空指针异常，高频方法：ofNullable()（创建实例）、isPresent()（判断非空）、orElse()（空值默认值）、ifPresent()（非空执行逻辑）。
Random：随机数生成，高频方法：nextInt()（生成整数随机数）、nextDouble()（生成小数随机数）。
Collections：集合工具类，高频方法：sort()（排序）、reverse()（反转）、emptyList()（空集合）。
三、IO/文件操作包（java.io + java.nio）
用于文件读写、流操作，是后端处理文件（如配置文件、日志文件）、网络流的核心包，java.nio是java.io的升级版本，性能更优。
java.io（传统IO）：
核心类：File（文件/目录操作）、BufferedReader（字符流读取）、BufferedWriter（字符流写入）、InputStream/OutputStream（字节流）。
高频方法：
File：exists()（判断文件是否存在）、createNewFile()（创建文件）、delete()（删除文件）、listFiles()（获取目录下文件）。
BufferedReader：readLine()（逐行读取）、close()（关闭流，JDK7+可使用try-with-resources自动关闭）。
java.nio（NIO，非阻塞IO）：
核心类：ByteBuffer（缓冲区）、FileChannel（文件通道）、Charset（字符编码）。
高频用途：大文件读写、网络通信（如Socket编程），性能优于传统IO，适合高并发场景。
四、数据库操作包（java.sql）
用于JDBC编程，是Java后端操作数据库的基础（MyBatis、JPA等框架均基于此封装），核心是实现与数据库的连接、SQL执行、结果集处理。
核心类/接口及API：
DriverManager：加载数据库驱动、获取数据库连接，高频方法：getConnection()（传入URL、用户名、密码，获取Connection对象）。
Connection：数据库连接对象，高频方法：createStatement()（创建Statement对象）、prepareStatement()（创建预编译Statement，防止SQL注入）、close()（关闭连接）。
PreparedStatement：预编译SQL语句，高频方法：setXxx()（设置SQL参数，如setInt()、setString()）、executeQuery()（执行查询SQL，返回ResultSet）、executeUpdate()（执行增删改SQL，返回影响行数）。
ResultSet：查询结果集，高频方法：next()（移动到下一条记录）、getXxx()（获取字段值，如getString()、getInt()）。
五、网络编程包（java.net）
用于实现网络通信（TCP/UDP/HTTP），是后端开发中网络相关功能（如接口调用、Socket通信）的基础。
核心类/接口及API：
Socket：TCP客户端，高频方法：getOutputStream()（获取输出流）、getInputStream()（获取输入流）、close()（关闭连接）。
ServerSocket：TCP服务器端，高频方法：accept()（监听客户端连接，返回Socket对象）、close()（关闭服务器）。
URL：统一资源定位符，高频方法：openStream()（获取网络资源输入流）、getProtocol()（获取协议，如HTTP）、getPath()（获取资源路径）。
六、核心API使用注意事项
所有IO流、数据库连接、Socket连接等资源，使用后必须关闭，避免资源泄露（JDK7+推荐使用try-with-resources自动关闭）。
String类是不可变的，频繁修改字符串建议使用StringBuilder（非线程安全）或StringBuffer（线程安全）。
集合操作中，遍历集合时不要直接修改集合（如ArrayList遍历中remove元素），避免ConcurrentModificationException异常。
JDK8+ 优先使用新日期API（LocalDateTime等），替代旧的Date、Calendar类（线程不安全、API繁琐）。
PreparedStatement优先于Statement，可防止SQL注入，提升执行效率（预编译）。
总结：以上核心包及API是Java后端开发的基础，无需额外依赖，掌握这些内容，就能完成基础的业务开发、文件操作、数据库交互和网络通信。后续框架（如Spring、MyBatis）均基于这些核心API封装，因此熟练掌握它们是成为合格Java后端开发者的前提。
