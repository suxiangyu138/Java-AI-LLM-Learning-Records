# 五子棋 (Gomoku)

> Java Swing 双人对战五子棋游戏，Maven 构建

## 项目概述

基于 Java Swing 开发的经典五子棋（Gomoku）双人对战游戏。在 15×15 棋盘上，黑白双方轮流落子，率先在横、竖、斜任意方向连成五子者获胜。项目采用 Maven 标准目录结构管理构建。

## 技术栈

| 技术 | 说明 |
|------|------|
| Java | JDK 24 |
| Swing / AWT | 棋盘绘制、鼠标事件处理 |
| Maven | 项目构建与依赖管理 |
| Java 2D | Graphics 绘图、棋子渲染 |

## 游戏规则

- 棋盘：15 × 15 交叉点
- 执黑先行，双方交替落子
- 横、竖、斜任意方向先连成五子者获胜
- 棋盘满而未分胜负则为平局

## 功能特性

- 15×15 标准棋盘绘制（网格线 + 星位标记）
- 黑白双方轮流落子
- 鼠标点击落子（计算最近交叉点）
- 五子连珠胜负判定（四方向扫描）
- 获胜提示与重新开始
- 防止重复落子

## 快速开始

```bash
# 编译
mvn compile

# 打包
mvn package

# 运行
java -cp target/classes <主类全限定名>
```

## 核心知识点

| 知识点 | 应用 |
|--------|------|
| Swing JPanel | 自定义棋盘面板，重写 paintComponent |
| Graphics | 绘制网格线、棋子（实心圆）、星位标记 |
| MouseListener | 鼠标点击坐标 → 交叉点映射 |
| 胜负判定算法 | 四方向（水平/垂直/主对角线/副对角线）连续计数 |
| Maven | 项目结构标准化、编译打包 |
| 状态管理 | 当前落子方、棋盘状态二维数组 |

## 注意事项

- 棋盘坐标系统：屏幕像素坐标 → 棋盘逻辑坐标的转换
- 绘制顺序：先网格线 → 再棋子，确保棋子覆盖在网格线上
- 胜负判定需从落子位置向四个方向各扫描 4 个位置
