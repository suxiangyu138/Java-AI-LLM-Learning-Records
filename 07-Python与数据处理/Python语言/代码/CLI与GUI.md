# CLI 基础概念
**CLI = Command Line Interface，中文叫「命令行界面」**。
简单说：**用文字命令（敲键盘）和电脑交互的方式**，而不是用鼠标点图标（GUI）。

## 一、CLI vs GUI（对比）
- **CLI（命令行）**
  - 黑框/终端，纯文字输入输出
  - 例子：Windows 的 `cmd`、PowerShell；Linux/macOS 的 `Terminal`
  - 特点：**高效、可脚本自动化、省资源**；但要记命令

- **GUI（图形界面）**
  - 窗口、图标、按钮、鼠标点击
  - 例子：Windows 桌面、macOS 桌面、手机 App
  - 特点：**直观易学**；复杂/批量操作慢、难自动化

## 二、举个例子（同一件事两种做法）
目标：把桌面上的 `a.txt` 移到 `Documents` 文件夹

- **GUI 做法**：
  1. 打开文件资源管理器
  2. 进桌面 → 选中 `a.txt`
  3. 鼠标拖到 Documents 文件夹

- **CLI 做法（一行命令）**：
```bash
mv ~/Desktop/a.txt ~/Documents/
```

## 三、CLI 一般用在什么地方
服务器 / 云主机管理（Linux 基本全用 CLI）
开发 / 编译 / 部署（npm、git、docker、mvn 等）
批量处理 / 自动化脚本（备份、日志分析、爬虫）
资源受限设备（路由器、嵌入式系统）


## 四、一句话总结
CLI 就是「敲命令操作电脑」的黑框界面，专业人员用来高效、精准、自动化地干活，和我们平时用的 “点图标” 图形界面（GUI）正好相对。
