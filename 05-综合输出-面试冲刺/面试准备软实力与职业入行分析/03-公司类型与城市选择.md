## 1. 第一份工作的选择逻辑

### 最重要的原则

```
第一份工作的核心目标不是赚钱，是"为第二份工作积累筹码"

成长空间 > 技术氛围 > 平台背书 > 薪资 > 公司名气
```

> ⚠️ **常见误区：** 很多人冲着"大厂光环"去，结果进了一个边缘部门，一年下来什么都没学到。跳槽时面试官问"你做了什么"，只能回答"修了几个Bug"——那这个大厂光环就是负资产。

### 影响你选择的三个核心问题

| 问题 | 为什么重要 |
|------|-----------|
| 你能学到什么？ | 毕业前3年是技术积累最快的阶段，浪费了就很难补回来 |
| 你跟谁一起工作？ | 你的技术上限很大程度上由你的同事和leader决定 |
| 你做了什么事情？ | 3年后跳槽，面试官看的是你的项目，不是你的公司名 |

## 2. 大厂：光环背后的真实代价

### 大厂的核心优势

| 优势 | 具体表现 |
|------|---------|
| 平台背书 | 简历上有BAT/字节的1-2年经历，跳槽时更容易过简历关 |
| 技术基建 | 内部自研的中间件、发布系统、监控体系，能接触到工业级最佳实践 |
| 规范流程 | Code Review、线上OnCall、灰度发布、技术评审——养成好的工程习惯 |
| 同事质量 | 能进大厂的人至少经过筛选，能学到的东西下限较高 |
| 薪资上限 | SSP和其他档次的差距在大厂最大，优秀的人回报更高 |

### 大厂的真实代价

| 代价 | 说明 |
|------|------|
| 螺丝钉化 | 很多大厂员工的工作范围极窄——"负责某个服务的一个模块"，一年接触不到全局 |
| 卷文化 | 工时不可控，OnCall很正常，peer pressure极大 |
| 边缘部门陷阱 | 核心部门招人少且门槛高，大量HC在边缘部门，进去了很难有成长 |
| 上线压力 | 线上故障的代价巨大，对心理承受力要求高 |
| 晋升不确定性 | 晋升不完全取决于你的技术能力，和运气、老板、项目都有关 |

### 什么情况建议冲大厂

- 你技术基础扎实、算法能力不错（具备竞争力）
- 你能接受高强度工作和一定的不确定性
- 你想在3-5年内积累足够的技术资本和人脉
- 你对公司名字带来的背书价值有需求（未来想创业/融资/转管理）

### 什么情况建议慎重

- 你更看重生活质量和WLB
- 你能拿到的岗位在明显边缘的部门
- 你技术基础还很薄弱（进去容易跟不上，试用期有风险）
- 你已经拿到了一个不错的中厂核心岗位

## 3. 中厂与独角兽：被低估的选择

中厂指的是：美团（部分部门）、快手、小红书、B站、得物、Soul、米哈游、猿辅导、Shopee等。独角兽指的是估值10亿美元以上的未上市公司。

### 中厂/独角兽的核心优势

| 优势 | 具体表现 |
|------|---------|
| 话语权更大 | 不像大厂那么螺丝钉，新人有机会独立负责模块甚至项目 |
| 成长更快 | 人手不够→你被迫做更多事→快速积累经验 |
| 技术氛围不差 | 很多中厂的核心团队不比大厂差，且没有大厂的繁文缛节 |
| 转正率高 | 实习生转正通常比大厂容易 |
| 薪资可能更高 | 独角兽的期权+薪资 package 对有经验的人很有吸引力 |
| 进可攻退可守 | 干两年后跳大厂的路径非常通畅 |

### 中厂的缺点

| 缺点 | 说明 |
|------|------|
| 流程不规范 | 测试、CR、发布流程可能不如大厂健全，新人养成坏习惯的风险 |
| 稳定性差 | 独角兽可能死掉，比大厂风险大 |
| 品牌背书弱 | 不如BAT响亮，但大部分技术圈内是认的 |
| 文档/基建差 | 内部工具和文档可能比较粗糙 |

### 什么情况下中厂是更好的选择

> 🎯 **推荐场景：** 你拿到了一个中厂**核心业务的核心团队**的offer，和一个大厂**边缘部门**的offer。这种情况下，中厂往往更有利于个人成长。

## 4. 国企与银行科技岗

### 适合谁

- 追求稳定和WLB，不希望35岁面临裁员风险
- 家庭在二三线城市，想回去发展
- 对技术没有极强的追求，把编程当成一份稳定的工作
- 讨厌内卷和加班文化

### 真实情况（不是想象的那样）

| 你以为的 | 实际情况 |
|---------|---------|
| 轻松不加班 | 不一定。有些银行软开加班也不少，尤其上线前 |
| 技术老旧 | 确实。很多银行还在用SSM甚至更老的框架 |
| 薪资低 | 一线城市总包15-22w，二线10-15w，加上福利还行，但天花板低 |
| 稳定铁饭碗 | 本质上是，但近年来也在推"末位淘汰"的变体 |
| 适合躺平 | 更适合"平稳发展"，不是"什么都不干" |

### 如何判断要不要去国企/银行

- ✅ 你更在乎"确定性"和"生活质量"，而非"技术成长"和"薪资上限"
- ✅ 你想在城市A定居，而城市A的大厂机会很少
- ✅ 你是硕士（银行软开基本卡硕士学历）
- ❌ 你希望3-5年内技术能力大幅提升，年薪翻倍
- ❌ 你对新技术有强烈兴趣，受不了技术停滞

> 💡 **一个务实建议：** 国企/银行的招聘窗口和互联网不太一样（更偏向春秋季、流程更慢）。如果对这方面有兴趣，记得提前了解目标银行/国企的招聘时间。

## 5. 外企的现状与机会

### 当前在中国还在招聘的外企

| 公司 | 业务 | 校招情况 |
|------|------|---------|
| 微软 | Azure/Office/Bing | 有校招，竞争激烈 |
| 亚马逊 | AWS/电商 | 有校招，主要是SDE |
| Zoom | 视频会议 | 有中国研发中心 |
| SAP | 企业管理软件 | 上海/北京有研发岗 |
| ThoughtWorks | 咨询+开发 | 有校招，文化独特 |
| Canva | 设计工具 | 中国有研发团队 |
| Shopify | 电商SaaS | 少量岗位 |

### 外企的优势

| 优势 | 说明 |
|------|------|
| WLB | 绝大多数外企比国内互联网好太多 |
| 英语环境 | 提升英语能力，未来有更多国际机会 |
| 流程规范 | 工程实践通常是国际标准 |
| 尊重个体 | 普遍比国内公司更尊重工程师 |

### 外企的劣势

| 劣势 | 说明 |
|------|------|
| 坑位极少 | 在整个中国市场占比很小 |
| 薪资竞争力下降 | 和国内大厂比，外企的package吸引力在下降 |
| 业务边缘化 | 很多外企在中国的团队做的是非核心业务 |
| 地缘政治风险 | 不确定性增加 |

> 🎯 **判断标准：** 如果你英语好、追求WLB、对薪资要求不高，外企是很好的选择。但如果你追求快速的薪资增长和技术深度，国内的互联网大厂/中厂可能更适合。

## 6. 创业公司：高风险高回报

### 给大三学生的创业公司判断清单

作为第一份工作，创业公司要非常慎重。如果考虑创业公司，必须满足以下条件：

- [ ] 创始人/CTO有成功的技术背景（大厂技术负责人级别，不是"前XX公司员工"）
- [ ] 公司已经过了B轮（有资本验证，不是天使轮画饼）
- [ ] 技术团队规模至少30人以上（有基本的技术氛围）
- [ ] 你进去有明确的mentor或能跟一个技术很强的人
- [ ] 薪资不低于市场中间水平（不是"用梦想换取降薪"）
- [ ] 做的是技术产品，不是外包/项目制公司

> ⚠️ **红线：** 不要为"股权/期权"接受低于市场价的薪资，不要进"全公司只有3个开发"的早期创业公司，不要相信"公司明年就上市"的故事。第一份工作最重要的是学习和成长，不是赌运气。

## 7. 城市选择：不只是薪资的差异

### 主要互联网城市的横评

| 城市 | 大厂机会 | 薪资水平 | 生活成本 | 一句话总结 |
|------|:------:|:------:|:------:|---------|
| 北京 | 🟢 最高 | 🟢 最高 | 🔴 高 | 机会最多，压力也最大 |
| 上海 | 🟢 高 | 🟢 高 | 🔴 高 | 外企/金融+互联网 |
| 深圳 | 🟢 高 | 🟢 高 | 🟡 中高 | 腾讯系/硬件/创业 |
| 杭州 | 🟡 中高 | 🟡 中高 | 🟡 中 | 阿里系/电商 |
| 广州 | 🟡 中 | 🟡 中 | 🟢 中低 | 性价比最高的一线 |
| 成都 | 🟡 中 | 🟡 中偏低 | 🟢 低 | 生活质量优先 |
| 武汉/南京/西安 | 🟡 中偏少 | 🔴 偏低 | 🟢 低 | 房价友好，离家近优先 |

### 真实可支配收入对比

> 以下为估算：一线城市年薪25万 vs 二线城市年薪16万

| 项目 | 一线城市（北京） | 二线城市（成都） | 差额 |
|------|:-----------:|:-----------:|:---:|
| 年薪（税前） | 250,000 | 160,000 | — |
| 月薪（税前） | 20,833 | 13,333 | — |
| 税后月薪 | ~16,000 | ~11,000 | — |
| 房租（月） | -3,500（合租单间） | -1,500（整租/合租主卧） | -2,000 |
| 生活费（月） | -3,000 | -2,000 | -1,000 |
| 每月可存 | ~9,500 | ~7,500 | +2,000 |

> 💡 一线城市每月多存2000元，但代价可能是每天通勤2小时+、房租3倍、竞争压力翻倍。选择城市不是简单的数学题。

### 城市选择的建议

| 你的情况 | 建议 |
|---------|------|
| 想冲最高薪、不怕卷 | 北京/上海/深圳 |
| 想进阿里系 | 杭州 |
| 想性价比+发展兼顾 | 广州/成都 |
| 家里能支持首付 | 优先离家近+有互联网产业的城市 |
| 完全靠自己买房 | 二线城市更现实，一线靠互联网薪资买房极难 |
| 还不确定长期在哪 | 先去一线干2-3年，积累资本后再决定 |

## 8. 决策矩阵：综合评估框架

当手里有Offer时，用这个表格给每个选项打分（1-5分），加权求和：

| 维度 | 权重 | 你的打分(1-5) |
|------|:--:|:-----------:|
| 技术成长空间 | 30% | |
| 团队/Leader质量 | 20% | |
| 公司品牌背书 | 15% | |
| 薪资与福利 | 15% | |
| WLB/生活质量 | 10% | |
| 城市匹配度 | 10% | |
| **加权总分** | 100% | |

> 🎯 **权重说明：** 对于第一份工作，"技术成长"和"跟谁干"占50%的权重。3年后你跳槽，面试官看的是你做了什么事、解决了什么问题——而不是你公司在哪个园区。

### 三个优先级递减原则

```
1. 跟对人（好leader/好mentor）>>> 去对公司
   一个愿意带你的leader，比一个响亮的公司名有价值100倍

2. 做核心业务 >>> 去大公司
   在小公司做核心业务 > 在大公司做边缘业务

3. 能写代码 > 能开会
   第一份工作最重要的就是写足够多的代码、踩足够多的坑
```

---

> 🎯 **最后的话：** 大三的你可能觉得"先进大厂再说"，但请记住——第一份工作的选择权在你手上，不是只有一条路。选错了没关系，选对了会加速你3-5年的职业发展。所以花点时间想清楚，而不是随大流。
