## 1. 实习生的合法权益

### 权利清单

| 权益 | 你该知道的 |
|------|-----------|
| **薪资** | 大厂日薪200-400元，中厂150-250元。无薪实习极少，遇到要警惕 |
| **工时** | 标准每周不超过40小时，加班应有补偿或调休 |
| **离职** | 提前3天通知即可走人，不需要像正式员工提前30天 |
| **mentor** | 公司应指定专人带你，不是丢给你文档就不管 |
| **实习证明** | 离职时公司必须开具，盖公章的正式证明 |
| **三方协议** | 你和学校、公司的就业意向书，毁约通常赔3000-5000元 |

> ⚠️ 实习生和公司是**劳务关系**而非劳动关系，不适用《劳动法》全部条款。但这不意味着你可以被随意对待。

### 六条绝对红线

以下任何一条出现，不要犹豫，立刻准备离开：

1. 拖欠或克扣工资
2. 要求缴纳"押金""培训费""保证金"（正规公司绝不会收）
3. 强制加班到深夜且无任何补偿
4. 工作内容和面试时承诺的完全不同
5. 人身攻击、人格侮辱、职场霸凌
6. 要求你从事违法违规的事情

## 2. 面试时就能察觉的16个危险信号

面试不只是公司面你，也是你面公司。以下信号出现3个以上，请谨慎。

### 关于公司和岗位

| 信号 | 意味着什么 |
|------|-----------|
| 说不清楚你入职后具体做什么 | 你会被当万能补丁，到处打杂 |
| 面试流程极简（一面直接发Offer） | 极度缺人或极其不正规 |
| 过度画饼（"明年就上市""期权值几百万"） | 用空头支票替代实在的承诺 |
| 办公地点在居民楼或偏僻郊区 | 公司实力有限，随时可能倒闭 |

### 关于团队和技术

| 信号 | 意味着什么 |
|------|-----------|
| 没有Code Review、没有技术分享 | 各自为战，新人学不到东西 |
| 面试官对你的技术提问都说"没问题" | 要么不关心技术，要么缺人到饥不择食 |
| 面试中贬低其他公司或前同事 | 团队文化有毒 |
| 团队全是新人，老员工极少 | 留不住人，大概率有问题 |

### 关于加班和文化

| 信号 | 意味着什么 |
|------|-----------|
| 反复试探你"能不能接受加班" | 加班文化严重，不是偶尔上线那种 |
| 说出"我们是一个大家庭" | 大概率要你无私奉献，边界模糊 |
| 面试官迟到超过30分钟且不解释 | 不尊重人，入职后更不会尊重你 |
| "我们团队很扁平"但面试官一个人说了算 | 实为"一言堂"，缺乏规范流程 |

### 面试中的"反向筛选"问题

这些问题帮你挖出真实情况。面试官的表情和语气比回答内容更说明问题：

| 问谁 | 怎么问 | 关注什么 |
|------|--------|---------|
| HR | "实习生有指定的mentor吗？培养机制是怎样的？" | 如果含糊其辞，大概率没人带你 |
| HR | "去年暑期实习生转正率大概多少？" | 如果极低或避而不答，HC紧张或体验差 |
| 技术面 | "团队有Code Review和技术分享吗？" | 没有CR = 团队缺乏工程规范 |
| 技术面 | "入职前三个月的期望是什么？" | 说不清楚 = 没有培养计划 |

## 3. 三方协议避坑指南

### 三方协议的本质

> 三方协议 = 你 + 学校 + 公司的就业意向书。有法律效力但不是卖身契，毁约赔3000-5000元违约金。

### 四个必须确认的点

| 确认项 | 为什么重要 |
|--------|-----------|
| 岗位名称是否和Offer一致 | 防止入职后被调岗（"Java开发"变成"技术支持"） |
| 薪资是否和Offer数字一致 | 口头承诺不算数，落在纸上才算 |
| 违约金是否在3000-5000范围 | 高于1万的不合理，可以协商 |
| 工作地点是否明确 | "服从公司调配" = 可能被发配到不想去的城市 |

### 常见坑

- **"先签三方，具体岗位入职再定"** → 大概率被分到没人愿意去的组
- **"Offer上的薪资是包含绩效的"** → 底薪可能很低，绩效说扣就扣
- **学校催你快点签** → 学校要就业率数据，别为交差乱签
- **公司说"这两天不签就作废"** → 制造紧迫感的套路，正规公司不会这样

> 💡 **一句话原则：Offer上没写的，就是不存在的。** 所有承诺——薪资、岗位、地点、福利——必须落到纸面上。

## 4. 入职后：被压榨的6个红色信号

| 信号 | 具体情况 |
|------|---------|
| **只做杂活** | 标记数据、整理文档、反复手动测试——一周正常，超过一个月不正常 |
| **不让你碰代码** | 面试说做后端，入职在处理Excel或写PPT |
| **没人管你** | 丢给你一堆文档就消失了，问问题已读不回 |
| **无实质性成长** | 超过一个月还在做第一天入职就能做的事 |
| **薪资远低于行情** | 以"学习机会"为借口压低日薪到100元以下 |
| **专门接盘烂活** | 正式员工不愿意做的边角料全部甩给你 |

### 三��应对

1. **先沟通：** 找mentor/leader认真谈一次——"我希望参与更多核心开发，有什么我可以负责的吗？"很多人不是故意压榨你，是不知道你有这个诉求。
2. **设底线：** 沟通后1-2周没改善 → 立刻开始找下家。
3. **果断走：** 不要因为"才来一个月不好意思走"而硬熬。实习期总共就2-3个月，浪费一个月等于浪费了三分之一的机会。

## 5. 职场PUA的识别与应对

### 什么是职场PUA

> 通过持续否定你的价值，摧毁你的自信，让你接受不合理的要求。核心套路就一个——**让你觉得自己不配提任何要求。**

### 6句经典PUA话术及其拆解

| 对方说 | 真实意图 | 你该想 |
|--------|---------|--------|
| "你能来这里实习是你的运气" | 你应该感恩戴德，少提条件 | 公司招我是因为我有价值，双向选择 |
| "现在的年轻人一点苦都吃不了" | 你应该无偿加班 | 吃苦 ≠ 被剥削。拒绝不合理安排不是娇气 |
| "我这是在培养你，别不知好歹" | 你就该接受我的一切安排 | 真正的培养有反馈有成长，不是随意使唤 |
| "别人都能做到为什么你不行" | 你应该羞愧，然后更拼命 | 每个人的情况和资源不同，无意义比较是操控 |
| "你的能力还差得远，别想太多" | 你不配提任何要求 | 我的水平我自己评估，不被别人的评价绑架 |
| "外面大环境不好，有份工作就烧高香吧" | 别想了，老实待着别跳槽 | 环境好坏不影响我判断这份工作值不值得 |

### 如何分辨"严格要求"和"精神打压"

| | 严格要求 | 精神打压 |
|------|---------|---------|
| 方式 | 指出具体问题 + 给出改进方向 | 否定你这个人 + 没有具体指导 |
| 目的 | 让你变得更强 | 让你变乖、变小 |
| 感受 | 有压力但有方向 | 只有挫败和自我怀疑 |
| 结果 | 你确实在进步 | 你只是在忍受 |

### 应对策略

- **保留证据：** 聊天记录、邮件全部截图保存。关键时刻这是你的护身符。
- **建立外部参照系：** 多和同学聊天、多看面经——你会知道正常的职场是什么样的。
- **学会说不：** "这个时间节点我确实做不完，能不能调整一下？""这个方向我不熟悉，需要有人带一下。"——表达不是顶撞，是沟通。

## 6. 如何体面地离开一家坑公司

### 离职五步走

1. **先拿Offer再提离职**——不要裸辞，不要裸辞，不要裸辞。
2. **提前3天书面通知** mentor和HR（实习生只需3天）。
3. **做好交接**——代码、文档、未完成事项列清楚。离职时的态度决定了你在行业里的口碑。
4. **索要实习证明**——纸质或电子版，盖公章。离职当天办好。
5. **核对薪资**——确认最后一笔工资全额到账。

### 离职时怎么说

> 🎯 **核心原则：说"中性且不可辩驳"的理由，别说实话，别教别人做人。**

```text
✅ 安全话术（选一个）：

"经过这段时间的尝试，我发现自己不太适应目前的节奏，
 想调整一下方向。感谢这段时间的照顾。"

"学校课程安排有变化，需要回去处理，没办法继续实习了。"

"家里有些事情需要我回去一段时间，可能没法继续了。"

❌ 绝对不要说（哪怕这是事实）：
"我觉得在这里学不到东西。"
"团队氛围太差了。"
"你们这就是在压榨实习生。"
```

### 离职后

- 确认薪资全额结清
- 拿回实习证明
- **不要在社交媒体上吐槽前公司。** 互联网行业比你想象的小，你永远不知道谁认识谁。
- 如果实习期太短（<1个月）或者经历太负面，这段经历可以不出现在简历上。

## 7. 第一份工作，什么比钱重要

### 优先级的正确排序

```
成长空间 > 团队质量 > 技术栈匹配 > 平台背书 > 薪资 > 公司名气
```

### 逐项解释

| 维度 | 为什么比钱重要 | 最坏情况 |
|------|-------------|---------|
| **成长空间** | 前3年决定你的技术天花板 | 3年后简历写不出亮点，跳槽都拿不到面试 |
| **团队质量** | 你跟谁一起工作决定了你的上限 | 每天上班如上坟，熬不过试用期 |
| **技术栈匹配** | 做的东西和未来方向一致，经验才不白费 | 1年经验换下一份工作时用不上 |
| **平台背书** | 下一份工作的敲门砖 | 跳槽时别人不认识你的公司，要多花功夫证明 |
| **薪资** | 起点差3k，3年后能力差的人可能差3w | 为了多2k进了一个学不到东西的地方 |
| **公司名气** | 大厂边缘部门不如中厂核心部门 | 名气大但做的事情在面试时讲不出来 |

### 判断公式

> **问自己：** 3年后我想跳槽，这段经历会让我的简历变得更好还是更差？
>
> 变好 → 值得去，哪怕薪资低一些。
> 变差 → 再高薪也要三思，你在消耗未来的竞争力。

---

> 🎯 **最后的话：** 保护自己不是"事多"或"娇气"。善良和边界感不矛盾——你可以做个好相处的人，同时守住底线。记住：任何需要你牺牲尊严或健康来换取的机会，都不值得。
