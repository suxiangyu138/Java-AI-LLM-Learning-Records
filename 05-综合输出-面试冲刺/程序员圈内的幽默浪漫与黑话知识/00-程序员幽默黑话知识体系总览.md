## 4. 核心概念速查

| 概念 | 一句话解释 |
|------|-----------|
| **黑话** | 程序员圈的「圈内语言」——沟通效率 + 身份认同 |
| **口头禅** | 「嘶~不应该啊」「在我电脑上正常的啊」——高频场景标签 |
| **水货鉴别** | 通过黑话使用判断真伪（https 是 http 复数？） |
| **Jeff Dean Facts** | 谷歌传奇工程师的「造神」梗文化（2008 起） |
| **TODO 永恒** | 注释梗：TODO 永远在——程序员式幽默 |
| **玄学定律** | 「一个 bug 是 bug，一堆 bug 能 work」——调试哲学 |
| **内存泄漏** | 情话梗：「爱上一个人就是内存泄露」 |
| **私有变量** | 情话梗：「女朋友是私有变量，只有我能调用」 |
| **互联网八股文** | 抽象词汇包装简单概念的「黑话」（赋能/闭环/赛道） |
| **岗位潜台词** | 「需求很简单」=「怎么实现我不管」 |
| **AI 梗** | 2026 新文化：调侃 AI 代码逻辑/黑话戏弄 AI |
| **递归与爱** | 「有些爱，越深陷越无法自拔」——技术隐喻 |
