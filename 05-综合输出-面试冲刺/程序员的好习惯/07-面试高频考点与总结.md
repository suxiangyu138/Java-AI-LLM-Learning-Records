## 1. 面试高频题与答题框架

### 1.1 效率与时间类

**Q1：你平时怎么安排工作优先级？**

```text
① 方法：优先级算法（紧急 0.4 + 重要 0.4 + 个人价值 0.2）
② 每日：TOP 3 原则（一天真正做好 3 件大事）
③ 对齐：与上级确认「本周最重要的三件事」一致
④ 例子：生产事故（9.0 分）> 核心功能（7.5）> 技术债（6.0）> 优化（2.6）
⑤ 加分：结合业务价值说明「为什么这个优先级」
```

**Q2：项目很忙，怎么保护自己的专注时间？**

```text
① 认知：被打断需 15-20 分钟重回状态——保护专注 = 保护交付
② 方法：日历屏蔽专注时段 + 通知管理 + IM 状态信号
③ 团队约定：紧急才打断，非紧急批量回复
④ 双终端 + 时间盒：工作与探索空间分离，任务设起止
⑤ 结果导向：专注时段交付的核心产出翻倍
```

**Q3：你如何估算任务时间？**

```text
① 方法：拆解任务（小块可见）+ 三点估算 + 20-30% 缓冲
② 教训：项目最后 10% 需要 90% 时间（预留 2-3 倍缓冲）
③ 诚实沟通：报估算附依据与波动范围
④ 复盘校准：周复盘对比估算 vs 实际，持续改进
```

### 1.2 协作与沟通类

**Q4：怎么和产品/非技术人员沟通技术方案？**

```text
① 技术翻译公式：工期 + 影响（「两周，搜索速度提升 3 倍」）
② 翻译心法：商业方关心「要多久/花多少/得到什么/什么风险」
③ 结论先行 + 用数据说话
④ 例子：技术债重构 →「消除未来 3 个月维护成本 + 修复 2 个安全漏洞」
```

**Q5：遇到不合理的需求或安排怎么办？**

```text
① 拒绝公式：先说结论 + 诚实原因 + 替代方案 + 约定时间
② 让决策者决策：给出选项和影响（「要 A 就要推迟 B」）
③ 边界声明：权责对等（没资源的「负责人」= 背锅侠）
④ 留痕：关键对齐用邮件/IM 记录
⑤ 不内耗：清晰表达后不纠结
```

**Q6：和同事有技术分歧怎么办？**

```text
① 情绪管理：10 分钟冷却（不因情绪拒绝合理方案）
② 事实优先：用数据/测试/基准说话，不用资历压人
③ 决策隔离：技术决策讲取舍，让决策者决策
④ 对事不对人：分歧在方案不在人
⑤ 升级路径：无法对齐 → 找共同负责人（不私下僵持）
```

### 1.3 文档与沉淀类

**Q7：你怎么看待写文档？**

```text
① 文档先行：写码前写设计文档（暴露缺陷 + 减少返工）
② 五问模板：痛点/接口/输入输出/边缘情况
③ 边做边记：看板化记录 → 周报 10 分钟完成
④ 知识管理：bug 复现/决策原因/审查反馈三类必记
⑤ 价值：把「人肉问答」升级为「知识库问答」
```

**Q8：讲讲你的复盘习惯？**

```text
① 每日：晨会 3 行日志（昨天/今天/隐患）+ 晚间复盘
② 每周：周复盘四问（有效做法/超时原因/卡住事项/下周 TOP3）
③ 项目：技术复盘（决策回顾/质量分析/经验沉淀）
④ 成长：技能矩阵季度更新 + 技术成长日志
⑤ 例子：从一次事故沉淀出幂等机制 + 测试补全 + 规范更新
```

### 1.4 成长与边界类

**Q9：你最近学了什么新技术？怎么学的？**

```text
① 学习闭环：入门 → 实践 → 精通 → 输出
② 具体例子：xx 技术（学了什么/做了什么项目/解决了什么问题）
③ 输出验证：给团队分享过/写进知识库（费曼学习法）
④ 时间投入：每天 2-3 分精力（小额高频）
⑤ 与工作结合：学的东西解决工作中的实际问题
```

**Q10：你怎么持续保持成长？**

```text
① 技能矩阵：领域/当前/目标/路径四维管理
② 每年 1 个深度领域（入门→实践→精通→输出闭环）
③ 支持系统：导师定期反馈 + 开源社区 + 关键任务主动承担
④ 复利资产：知识库/作品集/分享记录
⑤ AI 时代：拥抱新范式（Agent 开发等），保持学习加速度
```

**Q11：遇到过最大的失败/挫折是什么？怎么应对的？（高频！）**

```text
① 真实案例（不编造）：线上事故/项目延期/技术选型失误
② 复盘框架：发生了什么 → 根因分析 → 当时错在哪 → 怎么补救
③ 沉淀：制定了什么预防措施（测试/门禁/规范/流程）
④ 结果：同类问题不再发生（数据佐证）
⑤ 升华：失败是成长最快的时候——这次让我建立了 xx 习惯
```

**Q12：为什么选择我们公司/团队？（考察价值观匹配）**

```text
① 结合自己的习惯体系：看重「围绕价值做事」的文化
② 具体判断依据：技术氛围/成长机会/团队协作方式
③ 反问题：「团队怎么组织技术评审和复盘？」
④ 匹配点：我的习惯（文档先行/复盘/边界管理）与团队文化契合
```

## 2. 行为面试 STAR 法则

> 🎯 行为面试通用框架：**S（情境）→ T（任务）→ A（行动）→ R（结果）**——所有行为题都用它组织：

```text
STAR 答题模板
S 情境：项目背景（规模/时间/团队）
T 任务：你的具体职责（对齐目标）
A 行动：你的做法（习惯的具体体现：拆解/工具/复盘）
R 结果：量化成果（数据/节省时间/事故率）

示例（Q11 事故题）：
S：订单系统上线后出现并发重复退款事故
T：作为模块负责人，负责止损与根因定位
A：先快速隔离（暂停退款接口）→ 根因分析（幂等缺失）
   → 修复（幂等键）→ 补测试 → 复盘沉淀为规范
R：事故率归零；幂等机制推广到 3 个模块；
   复盘产出 1 条团队规范 + 5 个测试用例
→ 注意：A 要体现「习惯」（复盘/测试/沉淀），不是只有技术动作
```

## 3. 习惯自检清单

```text
日常自检（每周五过一遍）
[ ] 效率：重复操作自动化了？快捷键在用？双终端在坚持？
[ ] 时间：每天有 TOP3？时间盒用了？深度工作时段被保护？
[ ] 精力：加班超 22 点了吗？睡眠够吗？运动做了吗？
[ ] 沟通：汇报结论先行？拒绝过不合理的需求？带方案汇报？
[ ] 记录：晨会日志写了？看板更新了？知识库有本周新条目？
[ ] 复盘：周复盘做了？周报是拉取而非回忆？
[ ] 成长：技能矩阵有进展？本周学了什么并实践了？
[ ] 边界：责任边界清晰？有背锅的迹象吗？流程留痕了吗？
```

## 4. 五大常见误区

| # | 误区 | 真相 |
|---|------|------|
| 1 | 「把时间排满 = 高效」 | 效率 = 消除摩擦力，不是塞满时间 |
| 2 | 「技术强自然有发展」 | 沟通/表达/边界感同样决定上限 |
| 3 | 「周报靠周五回忆」 | 边做边记——周报是记录的自然产物 |
| 4 | 「做过 = 会了」 | 不复盘的经验不会变成能力 |
| 5 | 「加班 = 负责」 | 稳定输出 > 偶尔爆发；断路器保护长期状态 |

## 5. 90 天习惯养成路线

| 阶段 | 时间 | 目标 | 检验标准 |
|------|------|------|---------|
| **觉醒** | 1-15 天 | 记录与评估 | 晨会日志 + 晚间复盘 + 时间记录（知道时间去哪了） |
| **改造** | 16-45 天 | 效率与专注 | 自动化 5 个操作 + 双终端 + 日历屏蔽专注时段 |
| **巩固** | 46-70 天 | 复盘与沉淀 | 周复盘 4 次 + 知识库 10 条 + 技能矩阵建立 |
| **输出** | 71-90 天 | 分享与边界 | 1 次技术分享 + 边界声明 3 次实战 + 完整自检清单通过 |

> 🎯 养成秘诀：**习惯不能同时养成多个**——90 天只主攻「记录→效率→复盘→输出」四波，每波一个核心习惯，其他靠清单提醒。**习惯是复盘的错误长出来的**：每次事故对应一条习惯，写进清单，让清单成为自动导航。

## 6. 一句话总结全系列

```text
01 高效工作：效率 = 消除摩擦力——自动化/双终端/批量/深度工作
02 时间精力：精力管理 > 时间管理——优先级算法/时间盒/断路器
03 沟通协作：技术翻译公式 + 拒绝公式 + 情绪管理三习惯
04 文档知识：文档先行（5 问设计）+ 边做边记 + 晨会 3 行日志
05 复盘成长：复盘是经验变能力的唯一通道 + 技能矩阵 + 费曼
06 职业边界：围绕价值做事 + 权责对等 + AI 时代责任边界
07 面试：12 题框架 + STAR 法则 + 90 天养成路线
```

> 🎯 **系列总结**：程序员的好习惯 = 一套「**让自己可持续地高效、靠谱地协作、复利地成长**」的职业操作系统——效率让产出快，协作让人可信，记录让经验留存，复盘让经历变能力，边界让状态可持续。与《写代码的好习惯》互为表里：**写代码的好习惯让代码活，程序员的好习惯让人活**——两者合起来，就是一个可信赖、能成长、走得远的工程师的完整画像。
