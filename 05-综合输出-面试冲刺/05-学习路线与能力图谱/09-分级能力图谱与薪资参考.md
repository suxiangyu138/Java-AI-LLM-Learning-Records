# 分级能力图谱与薪资参考 —— 职业发展路线图

> **原则：知道自己在哪，知道下一步去哪，知道怎么去。**
> Level 1→2→3 的每一步，都有明确的技能清单和量化指标。

---

## 一、Level 1：初级→中级（1-3 年）

### 定位：独立完成 CRUD 业务开发

### 技能清单与掌握度

| 技能 | 要求程度 | 检验标准 |
|------|---------|---------|
| Java SE 基础 | 60 分（会用） | 能区分 ArrayList/LinkedList 使用场景，了解 HashMap 原理 |
| Spring Boot | 熟练 | 能独立搭建项目，配置数据源/Redis/MQ |
| MyBatis / MP | 熟练 | 能写动态 SQL、复杂 ResultMap 映射 |
| MySQL | 会写 SQL | CRUD 没问题，知道建索引 |
| Redis | 基本使用 | String/Hash 类型缓存，Session 共享 |
| Git | 日常操作 | commit/push/pull/branch/merge |
| Linux | 基本命令 | cd/ls/tail/grep/ps |

### 该阶段的常见面试题

```
- "HashMap 的 put 过程"
- "Spring Boot 怎么配置多数据源"
- "Redis 缓存怎么用的，过期时间设多少"
- "MySQL 索引优化做过哪些"
- "项目中最难的一个 Bug 怎么解决的"
```

## 二、Level 2：中级→高级（3-5 年）⭐ 你的当前目标

### 定位：理解原理，能优化性能，能独立设计方案

### 技能清单

| 领域 | 必须掌握的技能 | 检验标准 |
|------|-------------|---------|
| Java SE 深度 | 集合源码 + 多线程 + JVM 模型 | 能手写简化版 HashMap，画出 JVM 内存结构 |
| 并发编程 | AQS 原理 + 线程池 + volatile | 能解释 ConcurrentHashMap 的 CAS + synchronized |
| Spring 全家桶 | IoC 生命周期 + AOP 原理 + Boot 自动配置 | 能画出 Bean 生命周期 13 个步骤 |
| Spring Cloud | Nacos + Gateway + Feign + Sentinel | 用全家桶搭建过完整微服务项目 |
| MySQL 深度 | B+ 树 + 索引优化 + MVCC + 锁机制 | 能分析 EXPLAIN 执行计划，优化慢查询 |
| Redis 深度 | 5 数据结构底层 + 缓存三大问题 + 分布式锁 | 实现过分布式锁（Redisson），解决过缓存穿透 |
| 消息队列 | RabbitMQ / Kafka 至少一种 | 保证过消息不丢失 + 消费幂等 |
| JVM 调优 | GC 收集器 + 参数调优 + 问题排查 | 排查过线上 OOM/Full GC 问题 |
| Docker | Dockerfile + Docker Compose | 项目能 Docker 化部署 |
| 系统设计 | 秒杀系统 / 高并发优化方案 | 能画出秒杀系统完整架构图 |

### 量化指标

```
技术深度：
□ 阅读过 1 个以上框架核心源码（Spring IoC / MyBatis）
□ 排查过 3 次以上线上问题（OOM / 死锁 / 慢查询 / CPU 飙升）
□ 写过 1 篇以上技术博客（被阅读 > 1000 次）

项目经验：
□ 参与过 QPS > 1000 的项目的性能优化
□ 设计过 3 个以上微服务模块（含服务拆分 + 接口设计）
□ Code Review 100+ 次，带过 2 名以上初级开发

面试能力：
□ 能讲清楚 Spring IoC 容器初始化完整流程
□ 能画图解释 JVM 内存模型和 GC 过程
□ 能设计一个秒杀系统的完整方案
```

## 三、Level 3：高级→资深/架构师（5 年+）

### 定位：技术深度 + 架构视野 + 团队影响力

### 额外技能

| 领域 | 技能 | 说明 |
|------|------|------|
| 分布式理论 | CAP/BASE/一致性 Hash/Paxos/Raft | 能解释原理，能根据场景选型 |
| 中间件源码 | Dubbo/Netty/ShardingSphere | 不只会用，还读过核心源码 |
| 大数据 | Hadoop/Spark/Flink | 了解基本概念，能对接数据团队 |
| 全链路调优 | JVM + MySQL + Nginx + 网络 | 能从端到端优化系统性能 |
| 技术选型 | 框架对比/技术评审/风险评估 | 能写出有说服力的技术方案 |
| 团队管理 | 技术规划/技术培训/招聘面试 | 能带 5 人以上团队 |

## 五、能力体检表（每季度自评）

```
评分标准：1=不了解，2=了解概念，3=会使用，4=理解原理，5=能教给别人

Java 基础：
□ 集合框架源码（HashMap/ConcurrentHashMap/ArrayList）    [1-5]
□ 多线程（synchronized/Lock/AQS/线程池）                  [1-5]
□ JVM（内存模型/GC/调优）                                 [1-5]
□ 设计模式（至少 10 种）                                   [1-5]

Spring 生态：
□ IoC 容器（生命周期/循环依赖）                             [1-5]
□ AOP/事务                                                [1-5]
□ Spring Boot 自动配置                                     [1-5]
□ Spring Cloud Alibaba（Nacos/Gateway/Sentinel）          [1-5]

数据存储：
□ MySQL（索引/事务/锁/慢查询优化）                          [1-5]
□ Redis（数据结构/缓存问题/分布式锁/持久化）                [1-5]
□ 消息队列（RabbitMQ/Kafka 至少一种）                      [1-5]

架构与运维：
□ 微服务架构设计                                          [1-5]
□ 分布式事务（AT/TCC/MQ 方案）                             [1-5]
□ 系统设计（秒杀/高并发/高可用）                            [1-5]
□ Docker + CI/CD                                          [1-5]
□ Linux + 线上问题排查                                     [1-5]

软技能：
□ 代码质量（Clean Code/单元测试/重构）                      [1-5]
□ 技术文档/方案评审                                        [1-5]
□ 技术分享/技术博客                                        [1-5]
```

**目标**：每季度每项至少提升 1 分，一年后达到 4 分以上（理解原理级别）的项 ≥ 80%。
