# 🚀 Agent 实战项目全路线（Java后端 + AI方向）

> 适配技术栈：Java / SpringBoot / MySQL / Redis / Ollama / LangGraph / RAG  
> 目标：从入门 → 企业级落地，打造可写入简历的高含金量项目体系

---

# 一、入门级：单智能体（理解核心机制）

> 🎯目标：吃透 Agent 三要素「感知 → 思考 → 行动」

## 1. 带记忆的对话 Agent
**核心能力**
- 多轮对话
- 长短期记忆
- 会话隔离
- 重启不丢上下文

**关键技术**
- Short-Term Memory / Long-Term Memory
- 消息压缩（Token优化）
- Session管理（Redis）

---

## 2. 自我反思纠错 Agent
**核心能力**
- 初始回答生成
- 自我批判分析
- 自动修正迭代
- 达标停止

**关键技术**
- CoT（Chain of Thought）
- Self-Reflection
- 循环终止机制（Max Iter / Score阈值）

---

## 3. 工具调用 Agent（ReAct入门）
**核心能力**
- 判断是否调用工具
- 调用外部API（天气/计算器）
- 结果整合输出

**关键技术**
- Tool Schema定义
- 参数解析
- ReAct基础流程

---

## 4. 任务拆解 Agent
**核心能力**
- 拆分复杂任务
- 子任务排序
- 分步执行

**关键技术**
- Planning能力
- 状态机（State Management）
- 简单工作流

---

# 二、进阶级：Agent + 工具链 + RAG

> 🎯目标：覆盖80%企业AI应用场景

## 1. ReAct联网搜索 Agent
**核心能力**
- 自动判断是否联网
- 获取实时信息
- 引用来源防幻觉

**关键技术**
- ReAct循环
- 搜索API（Serper / Tavily）
- Source Grounding

---

## 2. RAG智能问答 Agent ✅（必做）
**核心能力**
- 文档解析（PDF/MD/HTML）
- 向量检索
- 精准回答 + 引用

**技术栈建议**
- 向量库：Milvus / FAISS
- Embedding：bge-large / text-embedding
- 本地模型：Ollama

---

## 3. 代码执行 Agent
**核心能力**
- 自动生成代码
- 执行代码（Python / Shell）
- 错误修复

**关键技术**
- 沙箱执行（Docker隔离）
- 自动调试（Retry机制）
- 输出解析

⚠️ 注意：必须做权限隔离，防止危险命令执行

---

## 4. 人在回路 Agent（HITL）
**核心能力**
- 高风险操作暂停
- 请求人工确认
- 审批后继续执行

**关键技术**
- 状态暂停（Checkpoint）
- 人工交互接口（Web UI）
- 回滚机制

---

## 5. NL2SQL 数据分析 Agent ✅（强烈推荐）
**核心能力**
- 自然语言 → SQL
- 自动查询数据库
- 输出分析报告

**关键技术**
- Schema理解
- SQL自动纠错
- 防SQL注入
- 可视化（ECharts）

---
