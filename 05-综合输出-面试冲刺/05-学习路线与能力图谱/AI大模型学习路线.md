## 4. 阶段三：核心实战（2-3 月）

### 4.1 RAG 检索增强生成（1.5 月，重中之重）

```text
文档加载 → 文本分割 → 向量化 → 向量存储 → 检索 → 重排序 → LLM 生成
```

| 环节 | 工具/技术 |
|------|----------|
| 文档加载 | PDF/Word/Markdown/网页 |
| 分割 | 递归分割，块大小 512-1024，重叠 50-100 |
| 向量化 | text-embedding-ada-002、bge、m3e |
| 向量存储 | **Chroma**（本地）、**Milvus**（工业级）、FAISS |
| 检索优化 | HyDE、重排序（Cross-Encoder）、多路召回 |
| 评估 | **RAGAS**（上下文相关性、答案忠实度） |

### 4.2 Agent 智能体（1 月）

| 核心能力 | 工具 |
|----------|------|
| 规划 | ReAct / Plan-and-Step |
| 工具调用 | 搜索、计算器、代码解释器、数据库查询、API |
| 框架 | LangChain Agent、LlamaIndex Agent、AutoGPT、MetaGPT |

### 4.3 多模态（0.5 月，加分项）

| 方向 | 模型 |
|------|------|
| 图文理解 | GPT-4V、Qwen-VL、LLaVA |
| 文生图 | Stable Diffusion、Midjourney API |

## 5. 阶段四：工程化与进阶（1-2 月）

### 5.1 模型微调（1 月）

| 技术 | 特点 | 框架 |
|------|------|------|
| **LoRA**（低秩适应） | 主流，省钱高效，仅训练少量参数 | PEFT、Transformers |
| **QLoRA** | 4/8 位量化 + LoRA，消费级 GPU 可跑 | TRL、Axolotl |
| 全量微调 | 成本高，适合大公司 | — |

### 5.2 私有化部署

| 框架 | 特点 |
|------|------|
| **vLLM** | 高吞吐推理 |
| TensorRT-LLM | NVIDIA 加速 |
| Docker + K8s | 容器化部署 |

### 5.3 性能优化

| 优化方向 | 手段 |
|----------|------|
| 推理 | 量化（4/8bit）、KV 缓存、批处理、流式输出 |
| 检索 | Prompt 优化、检索优化、缓存、异步 |
| 监控 | 响应时间、吞吐量、错误率、成本 |
| 安全 | 输入过滤、输出脱敏、权限控制、审计日志 |
