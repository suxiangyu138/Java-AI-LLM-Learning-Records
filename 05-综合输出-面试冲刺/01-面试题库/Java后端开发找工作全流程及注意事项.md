## 1. 求职准备

### 技术栈梳理

| 层级 | 核心技术 | 重点掌握 |
|------|----------|----------|
| **基础** | Java 集合、多线程、JVM、IO/NIO | HashMap、线程池、GC |
| **框架** | Spring Boot、Spring Cloud | Boot 自动配置、Nacos/Feign/Sentinel |
| **数据库** | MySQL | 索引、事务、SQL 优化 |
| **中间件** | Redis、RabbitMQ/Kafka | 缓存三大问题、消息可靠性 |
| **工具** | Maven、Git、Linux 常用命令 | — |

### 项目经验打磨

| 要点 | 说明 |
|------|------|
| 数量 | 2-3 个高质量项目 |
| 描述格式 | 背景→核心需求→个人职责→技术选型原因→遇到的问题+解决方案 |
| 量化成果 | "SQL 优化后响应时间从 500ms → 80ms" |
| 应届生 | 做 1-2 个实战项目（商城后端/管理系统），避免 Demo 级 |

### 简历规范

| 要素 | 要求 |
|------|------|
| 长度 | 应届生 1 页，社招 1-2 页 |
| 格式 | PDF，文件名 "姓名-Java后端-年限-电话" |
| 技能 | 分"熟练掌握"和"了解"，不夸大 |
| 项目 | 按"职责+技术+成果"格式 |

## 2. 简历投递

| 原则 | 做法 |
|------|------|
| **匹配优先** | 对照 JD 匹配技术栈，不盲目海投 |
| **数量控制** | 每天 10-15 家，质量 > 数量 |
| **黄金时段** | 工作日 9:30-11:30、14:30-16:30 |
| **跟进** | 2-3 天无回复可礼貌询问 |
| **内推优先** | 通过率远高于公开投递 |

## 3. 面试环节

### 面试前准备

- 了解企业主营业务和技术栈
- 针对 JD 复习高频考点
- 准备 1-2 分钟自我介绍
- 线上面试提前测试网络/摄像头

### 面试四类题型

| 类型 | 考察内容 | 示例 |
|------|----------|------|
| **基础题** | Java 基础 | HashMap 原理、线程池参数 |
| **框架题** | 框架使用+原理 | Spring IoC/AOP、Boot 自动配置 |
| **项目题** | 项目深度 | 最大技术难点？为什么选 Redis？ |
| **拓展题** | 技术思维 | 如何设计高并发接口？慢查询如何优化？ |

### 反问环节（建议 2-3 个）

| 推荐问题 |
|----------|
| 团队技术栈和开发模式？ |
| 岗位核心职责和 1-2 年成长空间？ |
| 团队目前在做的项目难点？ |

### 面试后跟进

- 当天发感谢消息
- 3-5 天未回复可礼貌询问进度

## 4. 谈薪与 Offer 选择

### 谈薪技巧

| 步骤 | 做法 |
|:---:|------|
| 1 | 提前了解市场薪资范围 |
| 2 | HR 问预期 → 反问"贵公司薪资范围是多少" |
| 3 | 低于预期 → 礼貌说明"结合能力希望达到 XX 范围" |

### Offer 评估五维度

| 维度 | 评估点 |
|------|--------|
| 薪资福利 | 基本工资、绩效、年终、五险一金、补贴 |
| 企业发展 | 行业前景、规模、盈利状况 |
| 岗位匹配 | 工作内容、技术栈、是否"打杂岗" |
| 工作环境 | 加班强度、团队氛围、领导风格 |
| 成长空间 | 培训、晋升、核心项目机会 |

## 5. 入职准备

- 提前准备入职材料（身份证/学历/银行卡/离职证明）
- 不熟悉的技术栈花 1-2 天快速了解
- 主动请教同事，快速熟悉业务和开发规范

## 6. 核心注意事项

### 技术层面

| ❌ 错误 | ✅ 正确 |
|--------|--------|
| 死记硬背概念 | 结合实际场景说明原理 |
| 简历夸大技能 | 只写真正掌握的技术 |
| 只学不练 | 手写代码（单例/线程池/SQL） |

### 简历层面

| ❌ 错误 | ✅ 正确 |
|--------|--------|
| 虚构项目/经验 | 真实项目，可被追问细节 |
| 冗长杂乱 | 只写 Java 后端相关内容 |
| Word 格式 | PDF 格式 |

### 面试层面

- 不会就说不会，不要狡辩
- 回答突出重点，不要冗长
- 离职原因不说前公司坏话，说"个人成长"
- 警惕培训贷/虚假岗位
