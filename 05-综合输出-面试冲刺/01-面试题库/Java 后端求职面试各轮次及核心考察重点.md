## 1. 笔试环节

> 绝大多数企业 1 轮笔试，大厂可能 2 轮。

| 轮次 | 内容 | 形式 |
|:----:|------|------|
| 初筛笔试 | Java 基础、SQL、简单算法 | 线上（牛客网/企业平台）/ 线下 |
| 复筛笔试（大厂/少数） | 编程题、项目场景题 | 线上 |

## 2. 面试环节

### 按企业规模分层

| 企业 | 轮次 | 流程 |
|------|:----:|------|
| **中小企业** | 2-3 轮 | 技术面（基础+项目）→ HR 面（职业规划+薪资） |
| **中大型/互联网** | 3-4 轮 | 技术一面（基础）→ 技术二面（深度+手写代码）→ 综合面（技术视野）→ HR 面 |
| **大厂**（字节/阿里/腾讯） | 4-5 轮 | 笔试 → 3-4 轮技术面（基础→深度→架构→综合）→ HR 面 |

### 各轮次考察重点

| 轮次 | 时长 | 考察内容 |
|------|:---:|----------|
| **技术一面**（基础面） | 1h | Java 基础、框架使用、项目概况 |
| **技术二面**（深度面） | 1-1.5h | 技术原理、项目难点、解决方案、手写代码 |
| **综合面/终面** | 1h | 技术视野、业务理解、团队协作 |
| **HR 面** | 30-40min | 职业规划、稳定性、薪资谈判、文化匹配 |

### 补充说明

| 人群 | 特点 |
|------|------|
| 应届生 | 笔试 + 2-3 轮面试，内推可免笔试 |
| 社招 | 多数免笔试，凭项目经验直接面试 |
| 轮次间隔 | 中小企业 1-2 天，大厂 3-7 天 |
