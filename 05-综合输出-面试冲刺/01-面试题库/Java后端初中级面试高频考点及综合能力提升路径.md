| 模块 | 占比 | 核心考点 |

## 3. 综合备考建议

| 原则 | 做法 |
|------|------|
| **优先级排序** | 先必考点（HashMap/Spring IOC/Redis/MySQL索引）→ 再拉分点（JVM调优/SQL优化/Docker+K8s） |
| **理论+实操绑定** | 每个考点动手验证，面试时能结合实操经验 |
| **刷题+复盘** | 错题整理成册，明确答题逻辑，举一反三 |
| **项目赋能** | 将所学融入个人项目，面试时举例说明 |
| **问题排查方法论** | 形成"定位问题→分析原因→解决方案→验证效果"四步模板 |
