## 1. Java 基础语法

### 三大特性

| 特性 | 核心 | 关键词 |
|------|------|--------|
| **封装** | 隐藏内部细节，get/set 暴露接口 | `private` + getter/setter |
| **继承** | 子类继承父类非私有成员，可重写 | `extends`，单继承多实现 |
| **多态** | 父类引用指向子类对象，同一方法不同实现 | 重载（编译时）+ 重写（运行时） |

### 重载 vs 重写

| 维度 | 重载（Overload） | 重写（Override） |
|------|:--:|:--:|
| 范围 | 同一类 | 父子类之间 |
| 参数列表 | 必须不同 | 必须相同 |
| 返回值 | 无关 | 子类 ≤ 父类 |
| 修饰符 | 无关 | 子类 ≥ 父类 |
| 确定时机 | 编译时 | 运行时 |

### 关键字速查

| 关键字 | 修饰类 | 修饰方法 | 修饰变量 |
|--------|:-----:|:------:|:------:|
| `final` | 不可继承 | 不可重写 | 常量 |
| `static` | — | 类方法（无 this） | 类变量（全局唯一） |
| `abstract` | 不可实例化 | 无方法体，子类必重写 | — |

### String / StringBuffer / StringBuilder

| 类型 | 可变性 | 线程安全 | 性能 | 场景 |
|------|:---:|:------:|:---:|------|
| String | ❌ | — | 低 | 少量不频繁修改 |
| StringBuffer | ✅ | ✅（synchronized） | 中 | 多线程拼接 |
| StringBuilder | ✅ | ❌ | 高 | 单线程拼接（首选） |

## 2. Java 集合框架

### List

| 实现类 | 底层 | 查询 | 增删 | 线程安全 | 扩容 |
|--------|------|:--:|:--:|:------:|------|
| ArrayList | 动态数组 | O(1) | O(n) | ❌ | 1.5 倍 |
| LinkedList | 双向链表 | O(n) | O(1) | ❌ | — |
| Vector | 动态数组 | O(1) | O(n) | ✅ | 2 倍 |

### Set

| 实现类 | 底层 | 有序 | 去重原理 |
|--------|------|:--:|----------|
| HashSet | HashMap 的 key | ❌ | hashCode + equals |
| LinkedHashSet | LinkedHashMap 的 key | ✅（插入序） | 同 HashSet |
| TreeSet | 红黑树 | ✅（排序） | Comparable/Comparator |

### Map

| 实现类 | 底层（JDK 8+） | 线程安全 | key/null |
|--------|------|:------:|:------:|
| HashMap | 数组+链表+红黑树 | ❌ | 允许 |
| ConcurrentHashMap | CAS + synchronized 节点锁 | ✅ | ❌ |
| HashTable | 哈希表 + synchronized | ✅ | ❌ |
| TreeMap | 红黑树 | ❌ | ❌ |

## 3. JVM

### 内存结构（JDK 8+）

| 区域 | 存储内容 | 线程 | 异常 |
|------|----------|:--:|------|
| **堆** | 对象实例、数组，GC 主战场 | 共享 | OOM |
| **方法区**（元空间） | 类信息、常量池、静态变量 | 共享 | OOM |
| 虚拟机栈 | 栈帧（局部变量表/操作数栈） | 私有 | StackOverflow / OOM |
| 程序计数器 | 字节码行号 | 私有 | ❌ |
| 本地方法栈 | Native 方法 | 私有 | StackOverflow |

### GC 算法

| 算法 | 优点 | 缺点 | 适用 |
|------|------|------|------|
| 标记-清除 | 简单 | 内存碎片 | — |
| 复制 | 无碎片、高效 | 内存利用率 50% | 年轻代 |
| 标记-整理 | 无碎片、利用率高 | 耗时 | 老年代 |
| 分代收集 | 兼顾 | — | JVM 实际使用 |

### 类加载

```text
加载 → 验证 → 准备 → 解析 → 初始化（5 步，不可逆）
```

| 加载器 | 加载范围 |
|--------|----------|
| Bootstrap | JDK 核心类（rt.jar） |
| Extension | jre/lib/ext |
| Application | classpath 下项目类 |

## 4. Java 多线程

### 线程池核心参数

| 参数 | 说明 |
|------|------|
| `corePoolSize` | 核心线程数 |
| `maximumPoolSize` | 最大线程数 |
| `keepAliveTime` | 临时线程空闲存活时间 |
| `workQueue` | 任务队列 |
| `handler` | 拒绝策略 |

### synchronized vs Lock

| 维度 | synchronized | Lock |
|------|:-----------:|:----:|
| 释放 | 自动 | 手动（finally） |
| 中断 | ❌ | ✅ |
| 超时 | ❌ | ✅ |
| 公平锁 | ❌ | ✅ |

## 5. Spring 框架

### IOC

> 控制反转：对象创建和依赖注入交给 Spring 容器管理。

| Bean 作用域 | 说明 |
|------------|------|
| singleton | 单例（默认） |
| prototype | 每次获取新建 |
| request/session | Web 环境 |

### AOP

> 面向切面：日志/事务/权限等横切逻辑与业务代码分离。

| 通知类型 | 时机 |
|----------|------|
| `@Before` | 方法执行前 |
| `@After` | 方法执行后（无论异常） |
| `@AfterReturning` | 正常返回后 |
| `@AfterThrowing` | 异常时 |
| `@Around` | 环绕（最灵活） |

## 7. 分布式

### 分布式事务方案

| 方案 | 优点 | 缺点 |
|------|------|------|
| 2PC | 简单 | 阻塞、单点故障 |
| TCC | 无阻塞、高可用 | 开发成本高 |
| SAGA | 高可用 | 最终一致性 |
| 本地消息表 | 实现简单 | 耦合度高 |
| 事务消息（RocketMQ） | 解耦、高可用 | 依赖 MQ |

### 分布式锁

| 方案 | 优点 | 缺点 |
|------|------|------|
| Redis（SET NX EX + Lua） | 高性能 | 需处理锁超时/重入 |
| ZooKeeper | 高可靠、可重入 | 性能略低 |
| 数据库 | 实现简单 | 性能低、易死锁 |
