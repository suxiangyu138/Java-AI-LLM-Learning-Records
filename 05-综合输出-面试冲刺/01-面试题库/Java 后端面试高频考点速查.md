# Java 后端面试高频考点速查

> 校招 + 实习面试，快速过一遍用的速查表。每个考点展开是一整本书，这里只列最可能被问到的核心点。

## Java 基础

- **== vs equals**：== 比引用地址，equals 比内容（String 重写了 equals）
- **String 不可变性**：`final class`，`final byte[]`，任何修改都返回新对象。好处：线程安全、字符串常量池、Hash 缓存
- **ArrayList vs LinkedList**：前者数组（O(1)随机访问），后者双向链表（O(1)头尾插入）
- **HashMap 原理**：数组 + 链表 + 红黑树（JDK 8+），put 流程：hash → 找桶 → 链表尾插 / 红黑树插入 → 超过阈值扩容（×2）
- **ConcurrentHashMap**：JDK 7 分段锁，JDK 8 CAS + synchronized 锁桶头节点

## 并发

- **synchronized vs ReentrantLock**：前者自动释放、不可中断、非公平；后者手动释放、可中断、可公平、可绑多个 Condition
- **volatile**：保证可见性（修改后立即刷回主存）和有序性（禁止指令重排），不保证原子性
- **线程池参数**：核心线程数 → 阻塞队列 → 最大线程数 → 拒绝策略
- **ThreadLocal**：线程私有变量副本，用完后必须 `remove()` 防内存泄漏

## JVM

- **内存结构**：堆（对象）、方法区/元空间（类信息）、虚拟机栈（方法调用）、本地方法栈、程序计数器
- **GC 算法**：标记-清除（碎片）、标记-复制（年轻代）、标记-整理（老年代）
- **GC 判断**：引用计数法（有循环引用问题）、可达性分析（GC Roots）
- **类加载**：加载 → 验证 → 准备 → 解析 → 初始化。双亲委派：先问父加载器，父加载不了才自己加载

## Spring

- **IOC**：控制反转，对象的创建和管理交给 Spring 容器，通过 DI（依赖注入）拿到依赖
- **AOP**：面向切面编程，在不修改源码的情况下增强方法（日志、事务、权限）。JDK 动态代理（接口） vs CGLib（类）
- **Bean 生命周期**：实例化 → 属性赋值 → 初始化 → 使用 → 销毁
- **事务传播**：REQUIRED（有则加入，无则新建）、REQUIRES_NEW（总是新建，挂起当前）
- **循环依赖**：三级缓存解决。A 依赖 B，B 依赖 A：先创建 A 的半成品（提前曝光），再创建 B（注入 A 的半成品），最后完成 A

## MySQL

- **索引结构**：B+Tree，所有数据在叶子节点，叶子节点双向链表连接，适合范围查询
- **聚集索引 vs 二级索引**：聚集索引叶子存完整行（通常主键），二级索引叶子存主键值（需要回表）
- **覆盖索引**：查询列全在索引中，不回表
- **最左前缀**：联合索引 `(a, b, c)`，查询条件必须包含 a 才能用索引（`a`、`a,b`、`a,b,c`）
- **事务隔离**：读未提交 → 读已提交 → 可重复读（MySQL 默认） → 串行化
- **MVCC**：多版本并发控制，通过 undo log + Read View 实现非锁定读，解决脏读/不可重复读/幻读

## Redis

- **数据结构**：String、Hash、List、Set、ZSet。底层：SDS、ziplist、skiplist 等
- **过期策略**：定期删除（随机抽一批删） + 惰性删除（访问时检查）
- **淘汰策略**：LRU、LFU、TTL、随机。生产用 `allkeys-lru`
- **缓存三问题**：穿透（布隆过滤器 / 缓存空值）、击穿（互斥锁 / 永不过期）、雪崩（随机过期时间 / 多级缓存）
- **持久化**：RDB（快照，可能丢数据）、AOF（追加写，文件大）、混合（Redis 4.0+）

## 网络 & 操作系统

- **TCP 三次握手**：SYN → SYN+ACK → ACK。为什么不是两次？防止历史连接
- **TCP 四次挥手**：FIN → ACK → FIN → ACK。TIME_WAIT 等 2MSL
- **进程 vs 线程**：进程是资源分配单位，线程是 CPU 调度单位。线程共享堆、方法区，独享栈、PC
- **死锁四条件**：互斥、持有并等待、不可剥夺、循环等待。破一个即可

## 系统设计（给校招准备）

- **如何设计一个短链系统**：发号器（雪花/DB自增）→ Base62编码 → 302重定向 → Redis缓存热门短链
- **如何设计一个排行榜**：Redis ZSet。日榜/周榜合并用 ZUnionStore。亿级用户分层+近似
- **如何设计接口幂等**：前端防重（按钮置灰） + 唯一索引 + Token机制（先拿Token，提交时校验+删除Token）
- **秒杀系统核心**：限流 → Redis预扣库存（Lua原子） → MQ异步下单 → 最终一致性
