## 1. Java 后端技术栈是什么

```
Java 后端 = 服务端业务系统的完整技术集合

企业级技术栈九大块：
  ① Java 语言（基础/并发/JVM）
  ② Spring 生态（IoC/AOP/Boot/Cloud）
  ③ 数据层（MySQL/Redis/MyBatis/JPA）
  ④ 中间件（MQ/ES/搜索引擎）
  ⑤ 微服务（注册/网关/分布式）
  ⑥ 工程化（Maven/Git/CI-CD）
  ⑦ 性能（JVM 调优/缓存/压测）
  ⑧ 安全（认证授权/防护）
  ⑨ 运维（监控/日志/告警）

⚠️ 面试必答：
"Java 后端 = 语言 + 框架 + 数据 +
 中间件 + 微服务 + 工程化的完整体系——
 不是单点技术，而是'能独立交付企业级系统'的能力。"
```

## 2. 技术栈分层地图

```
请求全链路分层（企业视角）：
  ① 接入层：Nginx、网关
  ② 应用层：Spring Boot/Spring MVC
  ③ 服务层：Service + 事务
  ④ 数据层：MySQL + Redis + ES
  ⑤ 消息层：RabbitMQ/Kafka（异步解耦）
  ⑥ 分布式层：注册中心/配置中心/分布式锁
  ⑦ 基础设施：Docker/K8s
  ⑧ 治理层：监控/日志/告警

⚠️ 面试必答：
"技术栈八层——接入/应用/服务/数据/
 消息/分布式/基础设施/治理；
 每层一个生态位、层层配合。"
```

## 3. 技术演进史

| 时代 | 技术 | 特点 |
|------|------|------|
| 基础时代 | JDBC + JSP + Servlet | 原始方式 |
| SSH 时代 | Struts + Spring + Hibernate | 分层启蒙 |
| SSM 时代 | Spring MVC + MyBatis | 轻量替代 |
| Boot 时代 | Spring Boot + 前后端分离 | 开箱即用 |
| 微服务时代 | Spring Cloud + Docker | 分布式 |
| 云原生时代 | K8s + Serverless + AI | 弹性与智能 |

```
⚠️ 面试必答：
"演进主线——SSH → SSM → Boot →
 微服务 → 云原生；
 当前主流 = Spring Boot 3/4 + 微服务 + 云原生。"
```

## 4. 就业技能树

```
Java 后端工程师技能分级：
  初级：Java 基础 + Spring Boot + MySQL + Redis 基础
  中级：并发/JVM + 分布式 + 消息 + 微服务
  高级：架构设计 + 性能调优 + 稳定性 + 团队
  专家：技术选型 + 系统设计 + 新技术（AI 集成）

⚠️ 面试必答：
"技能树三级——会用（初级）、
 懂原理（中级）、能架构（高级）；
 企业面试逐级考察。"
```
