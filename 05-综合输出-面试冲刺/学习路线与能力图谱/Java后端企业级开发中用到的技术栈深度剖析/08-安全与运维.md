## 1. 安全体系全景

```
企业安全四层：
  ① 代码层：参数校验、防注入、安全编码
  ② 构建层：依赖扫描、镜像扫描
  ③ 部署层：密钥管理、最小权限
  ④ 运行层：WAF、审计、监控

⚠️ 面试必答：
"安全四层——代码/构建/部署/运行，
 安全左移（越早发现越便宜）；
 核心威胁：注入、越权、XSS。"
```

## 2. 认证授权方案

### 2.1 方案演进

```
认证演进：
  Session（服务端状态）
  → JWT（无状态）
  → OAuth2/OIDC（第三方授权）
  → SSO（统一登录）

⚠️ 面试必答：
"认证四代——Session/JWT/OAuth2/SSO；
 企业标准 OAuth2 + JWT。
 授权模型 RBAC（用户-角色-权限）。"
```

### 2.2 方案选型

| 方案 | 适用 | 特点 |
|------|------|------|
| Session | 传统 Web | 可立即失效 |
| JWT | 微服务/移动端 | 无状态 |
| OAuth2 | 第三方/开放平台 | 授权标准 |
| Spring Security | Java 全家 | 框架整合 |

```
⚠️ 面试必答：
"'能否立即失效'是 Session/JWT 分界；
 Spring Security + JWT + RBAC
 是 Java 标准组合。"
```

## 3. 安全基线清单

```
企业安全基线（自查清单）：
  ① 密码：BCrypt 哈希（不存明文）
  ② 传输：HTTPS 全链路（TLS 1.2+）
  ③ 密钥：Vault/KMS（不进代码）
  ④ 参数：输入校验 + 限流
  ⑤ 依赖：持续漏洞扫描（Trivy）
  ⑥ 权限：最小化 + 审计
  ⑦ 日志：不记敏感信息
  ⑧ 更新：及时打补丁（CVE）

⚠️ 面试必答：
"安全基线八条——密码/传输/密钥/校验/
 依赖/权限/日志/补丁；
 按清单自查是企业安全落地方式。"
```

## 4. 监控告警体系

### 4.1 监控分层

```
监控三支柱：
  Metrics：Prometheus + Grafana（指标看板）
  Logs：ELK/Loki（日志检索）
  Traces：OTel + Jaeger（链路追踪）

⚠️ 面试必答：
"监控三支柱——指标（趋势）、
 日志（细节）、链路（路径）；
 排查流程：指标发现 → 链路定位 → 日志确认。"
```

### 4.2 告警设计

```
告警四原则：
  ① 少而准（每告警必有行动）
  ② 分级（P0 立即/P1 当日/P2 本周）
  ③ 防风暴（聚合/抑制）
  ④ 带处置文档（runbook）

⚠️ 面试必答：
"告警少而准 + 分级 + 防风暴——
 告警疲劳比没告警更危险；
 告警必须可执行（带处置步骤）。"
```

## 5. 日志与链路

### 5.1 日志规范

```
日志规范五条：
  ① 结构化（JSON）
  ② 带 traceId（链路关联）
  ③ 分级（DEBUG/INFO/WARN/ERROR）
  ④ 禁敏感信息
  ⑤ 事件流采集（stdout → 日志系统）

⚠️ 面试必答：
"日志规范 = JSON + traceId + 分级 +
 禁敏感 + 流采集；
 traceId 贯穿是全链路排查的关键。"
```

### 5.2 全链路追踪

```
链路追踪三要素：
  traceId（整条链路 ID）
  spanId（单次调用 ID）
  上下文传播（跨服务传递）

⚠️ 面试必答：
"链路三要素——traceId/spanId/传播；
 OTel 是事实标准（统一 SDK）。"
```

## 6. 容器与云运维

### 6.1 K8s 运维要点

```
K8s 运维三件事：
  ① 部署：Deployment 滚动更新（优雅关闭）
  ② 伸缩：HPA 自动扩缩（指标驱动）
  ③ 探针：存活/就绪（健康检查）

⚠️ 面试必答：
"K8s 运维 = 滚动更新 + HPA 伸缩 +
 探针健康检查；
 优雅关闭（先拒新请求等存量完成）。"
```

### 6.2 云原生运维

```
云原生运维能力：
  可观测（指标/日志/链路统一采集）
  弹性（HPA 按指标伸缩）
  自动化（GitOps：声明式交付）
  容灾（多可用区/备份恢复）

⚠️ 面试必答：
"云原生 = 容器 + 编排 + 可观测 + 弹性——
 运维从'人盯机器'到'声明式自动化'。"
```

---

> 🎯 **核心要点**：安全运维 = **四层安全**（代码/构建/部署/运行）+ **认证四代**（Session/JWT/OAuth2/SSO）+ **安全基线八条** + **监控三支柱**（指标/日志/链路）+ **告警四原则** + **云原生运维**（滚动/伸缩/探针/GitOps）。"安全左移 + 可观测 + 自动化"是企业运维三趋势。
