## 3. 学习路线推荐

### 🟢 初级 → 中级（0-2年经验）

```
01-Java核心 → 03-Spring生态 → 04-数据库 → 07-网络与安全
```

### 🟡 中级 → 高级（2-5年经验）

```
02-JVM → 06-中间件 → 08-设计模式 → 05-分布式 → 09-DevOps
```

### 🔴 高级 → 架构师（5年+）

```
05-分布式(深入) → 10-性能调优 → 08-架构设计(DDD) → 全栈贯通
```

| 等级 | 标志性能力 | 需掌握模块 |
