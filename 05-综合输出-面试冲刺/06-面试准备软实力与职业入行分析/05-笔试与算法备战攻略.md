## 1. 校招笔试到底考什么

不同公司的笔试结构不同，但基本是以下几种的组合：

| 题型 | 占比 | 说明 | 代表公司 |
|------|:--:|------|---------|
| **算法题** | 50-100% | 2-4道编程题，LeetCode中等为主 | 几乎所有大厂 |
| **选择题** | 0-40% | OS、网络、数据库、Java基础、数据结构 | 美团、京东、网易 |
| **行测题** | 0-30% | 逻辑推理、数字规律、图表分析 | 字节、腾讯（部分岗位） |
| **性格测试** | 0% | 不计分但可能影响HR面，极端性格可能挂 | 华为、阿里、字节 |

### 各公司笔试特点（2024-2025年）

| 公司 | 结构 | 难度 | 特点 |
|------|------|:--:|------|
| 字节跳动 | 4道算法题 | 🔴 较难 | 算法为主，常有动态规划，时间紧 |
| 阿里巴巴 | 2道算法 + 选择 | 🟡 中等 | 算法+Java基础选择 |
| 腾讯 | 3-4道算法 | 🟡 中等偏难 | 算法为主 |
| 美团 | 3道算法 + 20道选择 | 🟡 中等 | 选择覆盖面广 |
| 快手 | 3-4道算法 | 🟡 中等偏难 | 算法为主 |
| 京东 | 2道算法 + 选择 | 🟢 中等偏易 | 较友好 |
| 网易 | 2道算法 + 选择 | 🟡 中等 | 选择偏基础 |
| 拼多多 | 3-4道算法 | 🔴 较难 | 算法为主，时间紧 |
| 华为 | 2道算法 + 性格测试 | 🟢 中等偏易 | 算法难度不高 |

> ⚠️ **核心认知：** 大厂笔试的通过率一般在10%-30%。大部分挂掉的人不是因为不会，而是因为**时间不够**或者**没准备非算法部分**。

## 2. 算法题：刷多少、刷什么、怎么刷

### 刷多少题才够

| 目标 | 题量 | 说明 |
|------|:--:|------|
| 能过大部分笔试 | 100-150题 | 覆盖核心题型，中等难度能独立做 |
| 面试中算法不拖后腿 | 150-200题 | 手写代码不慌，常见题型熟练 |
| 算法成为优势 | 200-300题 | 大多数面试算法题秒杀 |

> 💡 **不要追求题量，追求覆盖度。** 刷100题但每种类型都覆盖到，远胜过刷300题但只做自己擅长的类型。面试见到没见过的题型，比见到不会做的题目好得多——至少你知道往哪个方向想。

### 刷什么：按模块优先级排序

| 优先级 | 模块 | 重要程度 | 校招考察频率 |
|:----:|------|:------:|:----------:|
| 1 | **数组与字符串** | 基础中的基础 | 🟢 极高 |
| 2 | **哈希表** | 空间换时间 | 🟢 极高 |
| 3 | **链表** | 基础操作 | 🟢 高 |
| 4 | **二叉树/二叉搜索树** | 递归思想 | 🟢 高 |
| 5 | **栈与队列** | 单调栈/优先队列 | 🟡 中高 |
| 6 | **排序算法** | 快排/归并/堆排 | 🟡 中高 |
| 7 | **二分查找** | 变形二分 | 🟡 中高 |
| 8 | **双指针/滑动窗口** | 子串/子数组 | 🟡 中 |
| 9 | **DFS/BFS** | 图/树/矩阵遍历 | 🟡 中 |
| 10 | **动态规划** | 最难的模块 | 🟡 中 |
| 11 | **贪心** | 区间/跳跃类 | 🟡 中低 |
| 12 | **回溯** | 排列组合/子集 | 🟡 中低 |
| 13 | **并查集/前缀树** | 高级数据结构 | 🔴 低 |

### 每个模块必刷的题（核心50题）

```text
数组(8题):
  两数之和、三数之和、最大子数组和、合并区间、
  下一个排列、旋转图像、除自身以外数组的乘积、缺失的第一个正数

字符串(5题):
  最长回文子串、字符串相加、字符串相乘、最小覆盖子串、字母异位词分组

链表(5题):
  反转链表、环形链表II、合并K个升序链表、删除链表的倒数第N个节点、LRU缓存

哈希表(3题):
  最长连续序列、字母异位词分组、和为K的子数组

二叉树(8题):
  前中后序遍历(迭代)、层序遍历、二叉树的最大深度、对称二叉树、
  二叉树的最近公共祖先、验证二叉搜索树、路径总和III、从前序与中序遍历构造二叉树

栈与队列(4题):
  有效的括号、每日温度、滑动窗口最大值、最小栈

二分查找(4题):
  搜索旋转排序数组、在排序数组中查找元素的第一个和最后一个位置、
  寻找峰值、搜索二维矩阵

动态规划(7题):
  爬楼梯、打家劫舍、最长递增子序列、最长公共子序列、
  零钱兑换、编辑距离、最大正方形

DFS/BFS/回溯(6题):
  岛屿数量、全排列、组合总和、括号生成、单词搜索、课程表
```

> 💡 这50题是一个基准线。能独立写出这50题，大部分公司的笔试就能过。之后就是刷高频题和巩固弱项。

### 怎么刷：三轮刷题法

```
第一轮：按类型刷（1-2个月）
├── 每个模块先看经典题解 → 自己写一遍 → 对比最优解
├── 一个模块刷5-10题后，总结这个模块的套路模板
└── 目标：每个模块都有"肌肉记忆"，看到题型就知道用什么方法

第二轮：随机刷（2-4周）
├── 打乱顺序，模拟真实笔试的"不知道是什么类型"的感觉
├── 限制时间：简单题15分钟、中等题25分钟
└── 目标：培养题型识别能力，看到题目能快速判断解法方向

第三轮：高频题+错题（1-2周）
├── 刷牛客/LeetCode的"公司高频题"
├── 重做之前做错的题，确保不再犯同样的错
└── 目标：针对目标公司的出题风格专项训练
```

> 🎯 **核心方法：** 每道题做完后，不要立刻做下一题。花3分钟总结：这道题属于什么类型？关键思路是什么？有没有写过类似的题？如果有题解比你的方法更好，好在哪里？

### 刷题时的常见错误

| 错误 | 为什么错 | 正确做法 |
|------|---------|---------|
| 想不出来就看答案 | 养成依赖，面试时没有"答案按钮" | 至少思考15分钟再看答案 |
| 只看不写 | 眼睛会了手不会 | 必须自己敲出来，submit通过才算过 |
| 追求一次AC | 自己给自己压力 | 第一次做能做出来就行，AC是追求不是要求 |
| 题海战术不总结 | 做一题忘一题 | 每5题停下来总结这一类型的套路 |
| 只刷简单题 | 笔试中等题占比最高 | 70%中等 + 20%简单 + 10%困难 |

## 3. 选择题：基础知识覆盖面

### 选择题考什么

| 知识板块 | 高频考点 | 备考方式 |
|----------|---------|---------|
| **数据结构** | 各种结构的特点、时间复杂度、适用场景 | 复习408+做选择题专项 |
| **操作系统** | 进程线程、死锁、内存管理、文件系统、I/O | 看面经高频+408选择 |
| **计算机网络** | TCP/UDP、HTTP/HTTPS、DNS、三次握手四次挥手、OSI七层 | 牛客选择题专项 |
| **数据库** | SQL语句、索引、事务隔离级别、MVCC、三大范式 | 牛客SQL实战+面经 |
| **Java基础** | 集合类、多线程、JVM内存模型、异常、反射 | Java面试指南的选择题 |
| **设计模式** | 单例、工厂、代理、观察者（偶尔考） | 了解常见模式的UML和代码 |

### 选择题准备策略

```
优先级：先保算法（占比最大），再用碎片时间补选择

推荐：牛客网的选择题题库 → 按模块刷 → 错题标记 → 考前集中过一遍
时间：每天刷20道选择，一个月能刷600道，覆盖大部分考点
```

## 4. 行测与性格测试

### 行测题

部分公司（字节、腾讯）校招笔试含行测题，主要是：

| 类型 | 说明 | 应对 |
|------|------|------|
| 图形推理 | 找规律，选下一个图形 | 刷50道找感觉即可 |
| 数字规律 | 给一串数字找规律 | 常见规律：等差、等比、平方、斐波那契 |
| 图表分析 | 给图表算增长率/占比 | 细心即可，小学数学水平 |
| 逻辑推理 | 谁说了真话/假话 | 画表格排除法 |
| 语文类 | 阅读理解、语句排序 | 不需要特别准备 |

> 💡 **行测不重要但别忽视。** 一般占总分10-30%，大多数人裸考就行。但如果你的算法和选择已经没问题了，考前花2-3小时刷50道行测，可以多拿几分。

### 性格测试

性格测试一般不筛人，但两类极端可能被标记：

```
❌ 可能被标记的回答倾向：
  - 所有问题都选"非常同意"或"非常不同意"（撒谎/不认真）
  - 前后矛盾的答案（有测谎题在里面）
  - 极端不合群（"我不喜欢和人合作"）
  - 极端不负责任（"拖延是正常的"）

✅ 安全策略：
  - 大多数选中间偏正面或偏负面
  - 保持前后一致（同样意思的题会出现多次）
  - 不需要"表演"一个完美的人，正常回答即可
```

## 5. 笔试答题策略

### 时间分配（以2小时4道算法题为例）

```
0-5分钟：   快速浏览所有题目，标记难度判断
5-25分钟：  做最简单的第一题（保底分）
25-55分钟： 做中等难度的一题（拿稳分数）
55-80分钟： 做剩下的较难题（争取分数）
80-90分钟： 优化前面代码、检查边界条件
90-120分钟：攻克最难的一题，或回头补前面的题

如果还有选择题：
90-100分钟：快速做选择（1分钟/道）
100-120分钟：继续算法题
```

### 拿分策略

| 情况 | 策略 |
|------|------|
| 一道题完全没思路 | 写暴力解，哪怕O(n²)，过部分测试用例也有分 |
| 思路有但写不完整 | 先把框架和关键逻辑写了，空着不写=0分 |
| 时间不够了 | 判断哪道题性价比高（简单、分多），优先完成 |
| 一道题卡了太久（>30分钟） | 跳过，先做下一题，有时间再回来 |

> ⚠️ **笔试不是ACM。** ACM要全AC，笔试过线就行。一道题写不出最优解，暴力法能过60%的用例，依然可能过线。完美主义是笔试最大的敌人。

## 6. ACM模式 vs 核心代码模式

校招笔试的两种输入输出模式：

| 模式 | 说明 | 常见平台 |
|------|------|---------|
| **核心代码模式** | 只需实现核心函数，输入输出框架已给 | LeetCode、部分公司 |
| **ACM模式** | 需要自己处理输入输出（Scanner/BufferedReader） | 牛客、大部分公司笔试 |

> ⚠️ **关键提醒：** LeetCode刷惯了核心代码模式的人，第一次见ACM模式很容易懵——不知道怎么读输入、不知道怎么输出。至少要在牛客网的ACM模式下练习10道题！

### ACM模式快速上手（Java）

```java
import java.util.*;

// 常见输入模式
public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        // 1. 读取一行一个整数
        int n = sc.nextInt();

        // 2. 读取一行一个字符串
        String s = sc.next();

        // 3. 读取一行多个整数（用空格分隔）
        int a = sc.nextInt();
        int b = sc.nextInt();

        // 4. 读取一个数组（先给长度n，再给n个元素）
        int[] arr = new int[n];
        for (int i = 0; i < n; i++) {
            arr[i] = sc.nextInt();
        }

        // 5. 读取一整行字符串（包含空格）
        sc.nextLine(); // 先消耗换行符
        String line = sc.nextLine();

        // 6. 循环读取直到EOF
        while (sc.hasNext()) {
            String word = sc.next();
            // ...
        }

        // 输出
        System.out.println(result);
    }
}
```

> 💡 **建议：** 牛客网 → 题库 → 在线编程 → 选"ACM模式"练习。至少把字符串处理、数组输入、多行输入这几种模式练熟。

## 7. 笔试后的复盘

每次笔试后24小时内做这件事：

| 复盘项 | 具体操作 |
|--------|---------|
| 哪些题做出来了 | 标记"已掌握" |
| 哪些题有思路但没写完 | 分析是速度问题还是思路不清晰，补充练习 |
| 哪些题完全没思路 | 标记知识点空白，添加到学习计划 |
| 时间花在哪了 | 是卡在某一题太久，还是整体太慢 |
| 选择题部分 | 哪些知识点答不出，添加到基础补课清单 |

> 🎯 **复盘的价值：** 一次笔试的复盘 > 盲目刷30题。知道自己哪里弱，才能精准用力。

## 8. 刷题工具与资源推荐

| 工具/资源 | 用途 | 推荐度 |
|----------|------|:----:|
| LeetCode | 核心刷题平台，题解最全 | ⭐⭐⭐⭐⭐ |
| 牛客网 | ACM模式练习 + 公司真题 + 选择题 | ⭐⭐⭐⭐⭐ |
| 代码随想录 | 刷题路线图，按类型分 | ⭐⭐⭐⭐⭐ |
| LeetCode Hot 100 | 高频考题合集 | ⭐⭐⭐⭐ |
| 牛课题霸 + 剑指Offer | 适合刚开始刷题的入门 | ⭐⭐⭐⭐ |
| B站算法讲解 | 看视频理解思路比看文字快 | ⭐⭐⭐ |
| labuladong的算法小抄 | 模板化思路，套路清晰 | ⭐⭐⭐⭐ |

> 🎯 **推荐刷题路线：** 剑指Offer(入门) → 代码随想录(按类型) → LeetCode Hot 100(高频) → 牛客公司真题(冲刺)

---

> 🎯 **最后的话：** 算法刷题没有捷径，但有方法。最怕的是两种极端：一种是"我要刷500题才去面试"（永远准备不好），另一种是"我不刷题，靠临场发挥"（笔试直接挂）。正确的姿势是：先定一个最低目标（比如能过大部分笔试的100-150题），达到后就去面，在面试反馈中继续刷题、越刷越准。
