## 3. 面试考什么

> 实习面试难度低，基本 4 样。

| # | 考察项 | 内容 | 难度 |
|:--:|--------|------|:--:|
| 1 | **Java 基础** | 集合、String、异常、面向对象 | 低 |
| 2 | **数据库** | MySQL 增删改查、索引简单说 | 低 |
| 3 | **框架** | SpringBoot 是什么、REST 接口、注解 | 低 |
| 4 | **算法题** | 两数之和、反转链表、二分、有效括号、滑动窗口 | 简单 |

### AI 方向加分项

| 能说清 | 直接加分 |
|--------|:------:|
| 大模型是什么 | ✅ |
| 怎么调用 API | ✅ |
| RAG 是什么 | ✅ |

## 4. 提高通过率

### 你的优势

| 优势 | 说明 |
|------|------|
| 安大计算机 | 安徽本地认可度高 |
| 大二 | 时间多、学习能力强 |
| Java + AI 方向 | 非常吃香 |

### 只需做到三点

| 要点 | 做法 |
|------|------|
| 简历有项目，不空 | 至少 1 个完整项目 + 1 个 AI 项目 |
| 基础题能答上来 | 集合、MySQL、SpringBoot 高频面试题 |
| 态度积极、愿意学习 | 不会的坦诚说"正在学" |
