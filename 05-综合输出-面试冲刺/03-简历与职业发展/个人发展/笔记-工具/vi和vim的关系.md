# vi 与 Vim 的关系

## 概述

**一句话总结**：`vi` 是 Unix 系统的标准文本编辑器，而 `Vim`（Vi IMproved）是 `vi` 的增强版本，完全兼容 `vi` 的所有操作，并在其基础上大幅扩展了功能。

---

## 1. 定义对比

| 工具 | 定位 | 特点 |
|------|------|------|
| **vi** | Unix/Linux 原生自带的最基础文本编辑器 | 极简设计、无语法高亮、无配色方案、功能精简 |
| **Vim** | 基于 vi 的增强版（Vi IMproved） | 语法高亮、插件系统、配色主题、多窗口、代码折叠、扩展快捷键 |

---

## 2. 系统实际行为

在现代 Linux 系统中，执行 `vi` 命令时，系统实际上运行的往往是 Vim：

```bash
# 许多发行版中的软链接关系
vi 文件名     # 实际指向 vim
vim 文件名    # 直接调用 vim
```

这是因为主流发行版（如 Ubuntu、CentOS）默认将 `vi` 作为 `vim` 的符号链接（symlink），用户键入 `vi` 时调用的底层程序仍然是 Vim。

---

## 3. 核心功能差异

| 维度 | vi | Vim |
|------|----|-----|
| 语法高亮 | ❌ 不支持 | ✅ 支持 |
| 配色方案 | ❌ 不支持 | ✅ 支持 |
| 多级撤销 | ❌ 仅单级 | ✅ 无限级撤销树 |
| 插件系统 | ❌ 不支持 | ✅ 丰富的插件生态 |
| 多窗口/分屏 | ❌ 不支持 | ✅ 支持水平/垂直分屏 |
| 代码折叠 | ❌ 不支持 | ✅ 支持 |
| 可视化选择 | ❌ 不支持 | ✅ 支持可视模式 |
| 宏录制 | ❌ 不支持 | ✅ 支持 |
| 系统兼容性 | 所有 Unix/Linux 必带 | 需额外安装（部分发行版预装） |

## 4. 设计理念与历史背景

### 4.1 起源

- **vi** 诞生于 1976 年，由 Bill Joy 为 BSD Unix 系统开发，设计目标是在**纯终端、无鼠标、拨号上网**的环境下高效编辑文本。
- **Vim** 诞生于 1991 年，由 Bram Moolenaar 基于 Amiga 平台开发，旨在为 vi 添加现代编辑器特性。

### 4.2 模式编辑哲学

vi/Vim 作为模式编辑器（Modal Editor）的鼻祖，引入了以下核心设计：

- **Normal Mode（普通模式）**：默认模式，用于浏览、复制、删除等操作
- **Insert Mode（插入模式）**：按 `i`/`a`/`o` 等键进入，用于输入文本
- **Visual Mode（可视模式）**（Vim 新增）：用于选择文本块
- **Command Mode（命令行模式）**：按 `:` 进入，执行保存、退出等命令

> 注：这套模式切换机制与当代图形化编辑器的"所见即所得"范式截然不同，对初学者存在较高的学习曲线。但熟练掌握后，纯键盘操作无需频繁切换至鼠标，可显著提升编辑效率。

## 5. 使用建议

| 场景 | 推荐选择 | 原因 |
|------|---------|------|
| 日常开发 | Vim | 插件生态、语法高亮、代码折叠等功能大幅提升开发体验 |
| 远程服务器维护 / 紧急修复 | 任意（vi 或 Vim） | 即使系统环境损坏，vi 也一定可用 |
| 容器 / 最小化系统 | vi | 无需额外安装，开箱即用 |
| Linux 新手入门 | Vim | 语法高亮降低阅读代码的门槛 |

> **实用建议**：在日常使用中，大多数情况下可以将 `vi` 和 `vim` 视为同一工具，无需刻意区分。二者操作逻辑完全一致，Vim 只是 `vi` 的超集。

## 6. 常用命令速查

### 基本操作

| 命令 | 说明 |
|------|------|
| `i` | 进入插入模式（光标前） |
| `a` | 进入插入模式（光标后） |
| `Esc` | 退出插入模式，返回普通模式 |
| `:w` | 保存文件 |
| `:q` | 退出编辑器 |
| `:wq` / `ZZ` | 保存并退出 |
| `:q!` | 不保存强制退出 |

### 光标移动

| 命令 | 说明 |
|------|------|
| `h` / `j` / `k` / `l` | 左 / 下 / 上 / 右 移动 |
| `w` / `b` | 下一个 / 上一个单词词首 |
| `0` / `$` | 行首 / 行尾 |
| `gg` / `G` | 文件开头 / 文件结尾 |

### 编辑操作

| 命令 | 说明 |
|------|------|
| `dd` | 删除（剪切）当前行 |
| `yy` | 复制当前行 |
| `p` / `P` | 粘贴到下一行 / 上一行 |
| `u` / `Ctrl+r` | 撤销 / 重做 |
| `/pattern` | 搜索文本，`n` / `N` 跳转匹配项 |
