# 哈希&散列 核心知识点总结

## 一、哈希与散列的关系
1. 哈希、散列完全等价，都是英文 Hash 的翻译：
    - 哈希：音译叫法，常见于工程开发、算法竞赛、密码学领域；
    - 散列：意译叫法，常见于教材、数据结构理论讲解；
2. 二者指代的思想、技术、应用场景完全一致，无任何本质区别。

## 二、哈希的核心本质
1. 核心思想：映射压缩，把任意长度、任意格式的数据（数字、字符串、对象、文件等），通过固定算法，转换成固定长度、固定范围的数值（哈希值/散列值）；
2. 核心目标：实现快速查找、数据压缩、唯一标识，是哈希表、加密算法、数据校验的底层基础。

## 三、哈希与求模运算的关系
1. 基础层面：求模运算是哈希最原始、最核心的实现方式，最简单的哈希函数就是  h(x) = x % n ，直接将大范围数字压缩到有限索引区间；
2. 进阶层面：现代哈希不等于单纯求模。纯求模易产生哈希冲突、数据分布不均，因此现代哈希会在求模前叠加位运算、异或、乘法、移位、随机扰动等操作，打散数据后再取模，大幅降低冲突概率；
3. 底层逻辑不变：无论算法多复杂，哈希的最终逻辑仍依托“大范围→小范围”的压缩映射，求模是该逻辑最直观的数学载体。

## 四、哈希的核心关键概念
1. 哈希函数：实现数据映射的算法，分为基础哈希、通用哈希、密码学哈希；
2. 哈希冲突：不同输入经过哈希计算，得到相同哈希值的情况，是哈希技术的核心痛点；
3. 冲突解决：常见方案有链地址法、开放寻址法、再哈希法；
4. 核心特性：高效性、压缩性、单向性（密码学哈希）、抗碰撞性。

## 五、常见应用场景
1. 数据结构：哈希表/HashMap、HashSet，实现O(1)级别的增删查改；
2. 加密领域：MD5、SHA系列，用于密码加密、文件完整性校验；
3. 工程开发：对象哈希值计算、分布式缓存、数据分片、负载均衡；
4. 算法竞赛：字符串哈希，快速判断字符串相等、子串匹配。
