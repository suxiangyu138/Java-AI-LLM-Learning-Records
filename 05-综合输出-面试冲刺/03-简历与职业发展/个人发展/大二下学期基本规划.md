## 总体目标

围绕 **学业、技术、英语、身体、财务** 五个维度，系统化推进个人能力建设，确保学业稳定输出、技术达到春招实习面试标准、英语通过六级、身体素质与财务习惯同步养成。

## 一、学业基础

**目标**：课程零挂科，核心专业课稳定绩点。

| 行动项 | 具体措施 |
|--------|----------|
| 课堂学习 | 认真听讲，不缺席，课后当天整理笔记 |

| 考前复习 | 系统性复盘整学期内容，按知识点梳理思维导图 |
| 核心专业课 | 重点关注与考研/就业直接相关的课程，保持高绩点 |

## 二、计算机基础

**目标**：搭建完整的 CS 基础体系，能熟练口述核心原理。

| 模块 | 内容 | 产出要求 |
|------|------|----------|
| **计算机网络** | TCP/IP 协议栈、HTTP/HTTPS、DNS、路由与交换 | 能画出协议交互流程，口述三次握手/四次挥手 |
| **操作系统** | 进程线程、内存管理、文件系统、IO 模型 | 能解释进程调度算法、虚拟内存机制 |
| **计算机组成原理** | 冯诺依曼结构、CPU 执行流程、存储层次 | 能画出 CPU 流水线简图 |
| **数据库** | SQL 语法、索引原理、事务与锁、范式设计 | 能手写复杂 SQL，解释 B+ 树索引 |
| **数据结构与算法** | 数组/链表/树/图/哈希表，排序/搜索/DP/贪心 | LeetCode 高频题刷完，能独立分析时空复杂度 |

> **学习路径**：教材精读 → 思维导图整理 → 口述输出 → 面试题检验

---

## 三、Java 后端 + AI 大模型

**目标**：技术栈达到可面试水平，完成一个可上简历的项目，具备春招实习面试能力。

### 3.1 技术栈

| 层级 | 技术 | 掌握程度 |
|------|------|----------|
| 核心语言 | Java SE（集合、并发、IO、JVM） | 原理级理解 + 手写代码 |
| 框架层 | Spring Boot、Spring MVC、MyBatis | 能独立搭建项目、配置、调优 |
| 数据层 | MySQL、Redis | 能设计表结构、编写优化 SQL、使用 Redis 缓存 |
| 工具链 | Git、Maven、Linux 基本操作 | 日常工作流无障碍 |
| AI 方向 | LLM 基础原理、Prompt Engineering、RAG | 了解主流模型特性，能在项目中集成 AI 能力 |

### 3.2 项目规划

- 完成 **1 个完整后端项目**（如：社区论坛 / 电商 / 管理系统），包含 CRUD、权限、缓存、日志
- 技术栈覆盖 Spring Boot + MyBatis + MySQL + Redis，可选集成 AI 功能
- 项目产出：GitHub 源码 + 接口文档 + 部署方式说明

### 3.3 算法刷题

- 目标题量：高频 **150~200 题**
- 按专题推进：数组 → 链表 → 栈/队列 → 哈希 → 树 → 图 → 回溯 → DP
- 每天 **2~3 题**，周末集中复习 + 重做错题
- 使用 LeetCode / 牛客网 + 本地笔记系统记录题解思路

## 四、英语能力

**目标**：一次性通过英语六级，能流畅阅读英文开发文档。

| 模块 | 计划 |
|------|------|
| **词汇** | 背完六级考纲单词，使用 Anki/墨墨背单词每日打卡 |
| **阅读** | 精做近 5 年真题阅读，逐篇分析长难句和出题逻辑 |
| **听力** | 每日 30 分钟泛听（英文技术播客/VOA）+ 真题精听训练 |
| **专业英语** | 每周阅读 1~2 篇英文技术文档/博客（Spring 官方文档、Stack Overflow），积累专业术语 |

> **原则**：量变引起质变，每天稳定投入比突击更有效。

## 五、身体素质

**目标**：减重 10 kg，养成规律运动作息习惯。

| 维度 | 计划 |
|------|------|
| **减重** | 本学期从当前体重减掉 10 kg，采用热量缺口 + 运动结合方式 |
| **运动** | 每周 4~5 次，每次 40~60 分钟（有氧 + 力量交替） |
| **作息** | 固定 23:30 前睡觉，7:00 起床，午休不超过 30 分钟 |
| **饮食** | 控制精制碳水，增加蛋白质摄入，戒含糖饮料 |

## 六、理财能力

**目标**：建立储蓄习惯，具备基础财商认知。

| 行动项 | 具体措施 |
|--------|----------|
| **储蓄** | 每月固定存下收入的 20%~30%，先存后花 |
| **记账** | 使用记账 App 记录每一笔支出，月度分类复盘 |
| **理性消费** | 大额消费前冷静 48 小时，区分"需要"和"想要" |
| **理财基础** | 了解货币基金/指数基金/国债逆回购等低风险工具的基本逻辑 |
