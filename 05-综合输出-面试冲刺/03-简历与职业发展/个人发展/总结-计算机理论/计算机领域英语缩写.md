# 计算机领域英语缩写
计算机相关知识汇总
·计算机基础
• CPU：Central Processing Unit，中央处理器
• OS：Operating System，操作系统
• RAM：Random Access Memory，内存
• ROM：Read-Only Memory，只读存储器
• I/O：Input/Output，输入输出
• IP：Internet Protocol，网络协议
• LAN：Local Area Network，局域网
• WAN：Wide Area Network，广域网
开发 & 后端
• API：Application Programming Interface，应用程序接口
• SDK：Software Development Kit，开发工具包
• IDE：Integrated Development Environment，集成开发环境
• OOP：Object-Oriented Programming，面向对象编程
• AOP：Aspect-Oriented Programming，面向切面编程
• IoC：Inversion of Control，控制反转
• DI：Dependency Injection，依赖注入
• CRUD：Create, Read, Update, Delete，增删改查
• REST：Representational State Transfer，软件架构风格
• JSON：JavaScript Object Notation，数据格式
• JWT：JSON Web Token，令牌
• URL：Uniform Resource Locator，网址
• URI：Uniform Resource Identifier，资源标识符
• HTTP：HyperText Transfer Protocol，超文本传输
• HTTPS：HTTP Secure，安全超文本传输
• TCP：Transmission Control Protocol，传输控制协议
• UDP：User Datagram Protocol，用户数据报协议
• DNS：Domain Name System，域名系统
数据库 & MySQL
• DB：Database，数据库
• DBMS：Database Management System，数据库管理系统
• SQL：Structured Query Language，结构化查询语言
• PK：Primary Key，主键
• FK：Foreign Key，外键
• JDBC：Java Database Connectivity，Java 数据库连接
• ORM：Object Relational Mapping，对象关系映射
• ACID：事务四大特性（原子、一致、隔离、持久）
Spring 全家桶
• Spring Boot（SB）：常直接说 Boot
• Spring Cloud（SC）
• MVC：Model-View-Controller，模型 - 视图 - 控制器
• JPA：Java Persistence API，Java 持久层 API
大数据 & 中间件
• MQ：Message Queue，消息队列
• Redis：直接读，无缩写
• HDFS：Hadoop Distributed File System，分布式文件系统
• K8s：Kubernetes，容器编排
• Docker：直接读
• QPS：Queries Per Second，每秒查询数
• TPS：Transactions Per Second，每秒事务数
人工智能 / 机器学习
• AI：Artificial Intelligence，人工智能
• ML：Machine Learning，机器学习
• DL：Deep Learning，深度学习
• NN：Neural Network，神经网络
• CNN：Convolutional Neural Network，卷积神经网络
• RNN：Recurrent Neural Network，循环神经网络
• LSTM：Long Short-Term Memory，长短期记忆
• GAN：Generative Adversarial Network，生成对抗网络
• CV：Computer Vision，计算机视觉
• NLP：Natural Language Processing，自然语言处理
• GPU：Graphics Processing Unit，图形处理器
• CUDA：直接读
测试 & 运维 & 通用
• DEV：Development，开发环境
• TEST：Testing，测试环境
• UAT：User Acceptance Testing，用户验收
• PROD：Production，生产环境
• CI/CD：Continuous Integration / Continuous Deployment，持续集成/部署
• Git：直接读
• Bug：错误
• Debug：调试
