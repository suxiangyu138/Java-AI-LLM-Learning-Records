# Java 后端技术体系学习路线

## 概述

本文按十大部分系统梳理 Java 后端开发从基础到高级的完整学习路线，覆盖 **Java 基础、高级特性、Web 开发、主流框架、分布式微服务、DevOps、大数据、项目实战、面试、源码**，标注优先级与学习建议。

---

## 学习路线全景图

```
第一部分        第二部分          第三部分        第四部分          第五部分
Java 基础   →  Java 高级    →   Java Web   →   主流框架     →   分布式微服务
 语法/集合      并发/JVM/算法     前端/后端       Spring 全家桶      中间件/搜索引擎
  IO/反射       设计模式          Tomcat        数据库/项目管理      日志监控

第六部分        第七-八部分         第九部分         第十部分
DevOps     →   大数据/项目    →   高频面试    →    底层源码
 K8s/CI/CD      实战练习           大厂真题          内核研究
```

## 第一部分：Java 基础

| 模块 | 核心内容 | 优先级 |
|------|---------|:---:|
| **基础语法** | 变量、控制结构（顺序/分支/循环）、OOP（封装/继承/多态）、数组 | 🔴 必学 |
| **Java API** | 常用类库（String/Math/System 等） | 🔴 必学 |
| **异常处理** | try-catch-finally、throw/throws、自定义异常 | 🔴 必学 |
| **集合框架** | List/Set/Queue/Map 体系、队列、栈、链表、树、散列、堆、图 | 🔴 必学 |
| **泛型** | 泛型类/方法、通配符、类型擦除 | 🟡 重要 |
| **IO** | 字节流/字符流、缓冲流、文件操作 | 🟡 重要 |
| **反射** | Class 获取、动态创建对象/调用方法 | 🟡 重要 |
| **网络通信** | Socket 编程基础、TCP/UDP | 🟡 重要 |

## 第二部分：Java 高级

### 2.1 并发编程

| 模块 | 核心内容 | 优先级 |
|------|---------|:---:|
| **并发基础** | 线程创建、生命周期、指令重排 | 🔴 必学 |
| **锁机制** | synchronized（锁升级）、volatile（可见性/有序性）、Lock（ReentrantLock） | 🔴 必学 |
| **线程池** | ThreadPoolExecutor 七大参数、工作流程、拒绝策略 | 🔴 必学 |
| **并发容器** | ConcurrentHashMap、CopyOnWriteArrayList、BlockingQueue | 🟡 重要 |
| **JUC 工具** | CountDownLatch、CyclicBarrier、Semaphore | 🟡 重要 |

### 2.2 数据结构与算法

| 类别 | 核心内容 | 优先级 |
|------|---------|:---:|
| **排序** | 冒泡/选择/插入/希尔/快速/归并/堆/基数排序（8 种） | 🔴 必学 |
| **查找** | 二分查找、线性查找 | 🔴 必学 |
| **算法思想** | 分治、动态规划（背包问题）、回溯（骑士周游）、贪心 | 🔴 必学 |
| **图算法** | Prim（最小生成树）、Kruskal、Dijkstra（最短路径）、Floyd | 🟡 重要 |
| **字符串** | KMP 算法 | 🟡 重要 |

### 2.3 设计模式

| 类别 | 核心模式 | 优先级 |
|------|---------|:---:|
| **高频** | 单例、工厂、代理、观察者、模板方法、适配器、装饰者、职责链 | 🔴 必学 |
| **进阶** | 组合、桥接、原型、外观、享元、策略、命令、状态 | 🟡 重要 |

### 2.4 JVM

| 模块 | 核心内容 | 优先级 |
|------|---------|:---:|
| **JVM 体系** | 内存模型（堆/栈/方法区）、类加载过程、双亲委派机制、沙箱安全机制 | 🔴 必学 |
| **JMM** | Java 内存模型、happens-before 原则 | 🔴 必学 |
| **字节码** | 字节码执行过程与机制 | 🟡 重要 |

## 第五部分：分布式、微服务与中间件

### 5.1 微服务核心组件

| 技术 | 功能 | 优先级 |
|------|------|:---:|
| **Spring Boot** | 微服务基础框架 | 🔴 必学 |
| **Spring Cloud** | 微服务全家桶 | 🔴 必学 |
| **Nacos** | 服务注册发现 + 配置管理 | 🔴 必学 |
| **OpenFeign** | 服务间声明式 HTTP 调用 | 🔴 必学 |
| **Gateway** | API 网关（路由/限流/日志/鉴权） | 🔴 必学 |
| **Sentinel** | 流量控制、熔断降级、系统负载保护 | 🟡 重要 |
| **Seata** | 分布式事务中间件 | 🟡 重要 |
| **Dubbo** | 高性能 RPC 框架 | 🟡 重要 |
| **Netty** | 高性能 NIO 网络框架 | 🟡 重要 |

### 5.2 消息中间件

| 技术 | 特点 | 优先级 |
|------|------|:---:|
| **RabbitMQ** | 可靠性高、路由灵活 | 🟡 重要 |
| **Kafka** | 高吞吐、流处理 | 🟡 重要 |
| **ActiveMQ** | 传统 JMS 实现（已少用） | ⚪ 了解 |

### 5.3 搜索引擎

| 技术 | 特点 | 优先级 |
|------|------|:---:|
| **Elasticsearch** | 分布式搜索与分析引擎（主流） | 🟡 重要 |
| **Solr** | 传统搜索引擎（已少用） | ⚪ 了解 |

### 5.4 数据库中间件

| 技术 | 功能 | 优先级 |
|------|------|:---:|
| **MyCat** | 数据库分库分表中间件 | 🟡 了解 |
| **ShardingSphere** | 分布式数据库中间件（推荐） | 🟡 重要 |

### 5.5 日志与监控

| 技术 | 功能 | 优先级 |
|------|------|:---:|
| **Elasticsearch + Logstash + Kibana**（ELK） | 日志收集/分析/可视化 | 🟡 重要 |
| **Docker** | 应用容器引擎 | 🔴 必学 |

## 学习阶段规划

```
第一阶段（1-2 月）      第二阶段（3-4 月）         第三阶段（5-6 月）
Java 基础 + 高级     Spring Boot + MyBatis    Spring Cloud + 中间件
                       MySQL + Redis + Linux    Docker + 项目实战

第四阶段（7-8 月）      第五阶段（9-12 月）
DevOps + K8s + 监控    算法冲刺 + 源码 + 面试
ELK + CI/CD             大厂面试准备
```
