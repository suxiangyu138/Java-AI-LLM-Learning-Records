# 常用接口测试工具

## 一、Postman（接口调试）

### 1. 下载安装

- 官网：https://www.postman.com/downloads/
- 选择对应系统（Windows/Mac/Linux）下载安装包，双击安装即可

### 2. 基础配置

#### （1）注册/登录

- 打开 Postman，注册账号（企业推荐团队账号），登录后可同步数据、协作

#### （2）环境变量配置

- 点击左侧「Environments」→「+」新建环境
- 配置变量：如 `baseUrl`（dev: http://localhost:8080，prod: https://api.xxx.com）
- 切换环境：右上角选择对应环境，请求中用 `{{baseUrl}}` 引用

#### （3）集合管理

- 点击左侧「Collections」→「+」新建集合，分类存放接口（如用户模块、订单模块）
- 右键集合可导出/导入（分享给团队）

### 3. 基础使用

#### （1）发送请求

- 新建请求：选择请求方式（GET/POST/PUT/DELETE）
- 输入 URL：如 `{{baseUrl}}/user/getById`
- 配置参数：
  - GET：Params 填写查询参数
  - POST：Body 选择「raw」→「JSON」填写请求体
- 点击「Send」发送请求，查看响应结果

#### （2）自动化测试

- 切换到「Tests」标签，编写测试脚本（JavaScript）
- 示例：校验响应状态码

```javascript
pm.test("响应状态码为200", function () {
    pm.response.to.have.status(200);
});
```

- 运行集合：右键集合→「Run collection」，批量执行接口并生成测试报告

#### （3）Mock 服务

- 点击「Mock Servers」→「+」新建 Mock
- 配置请求路径、响应数据，生成 Mock 地址供前端调用

## 二、Apifox（一站式接口工具）

### 1. 下载安装

- 官网：https://www.apifox.cn/
- 下载对应系统安装包，双击安装（支持 Windows/Mac/Linux）

### 2. 基础配置

#### （1）新建项目

- 打开 Apifox，点击「新建项目」，填写项目名称、描述
- 选择「接口管理」模式，支持导入 Postman/Swagger 数据

#### （2）环境配置

- 点击顶部「环境」→「管理环境」，新建环境（dev/test/prod）
- 配置变量：如 `baseUrl`、`token`，请求中用 `{{变量名}}` 引用

#### （3）团队协作

- 点击「成员」→「邀请成员」，设置权限（编辑/只读）
- 接口修改实时同步，支持评论、版本管理

### 3. 核心功能使用

#### （1）接口调试

- 新建接口：选择模块→「新建接口」，填写请求方式、URL
- 配置参数：自动解析请求参数、响应数据，支持表单/JSON/文件上传
- 发送请求：点击「发送」，查看响应、响应头、Cookie

#### （2）接口文档生成

- 接口调试完成后，自动生成文档（含请求参数、响应示例、字段说明）
- 支持分享文档链接（公开/私有），导出为 Markdown/PDF

#### （3）Mock 服务

- 新建 Mock：接口→「Mock」→「启用 Mock」
- 自定义响应数据：支持随机数据、模板语法，自动生成 Mock 地址

#### （4）自动化测试

- 新建测试用例：选择接口→「测试用例」，配置断言（状态码、字段值）
- 批量运行：测试集合→「运行」，生成测试报告，支持定时任务

## 三、Swagger/Knife4j（接口文档）

### 1. Swagger 配置（SpringBoot 集成）

#### （1）引入依赖

```xml
<!-- Swagger 核心依赖 -->
<dependency>
    <groupId>io.springfox</groupId>
    <artifactId>springfox-boot-starter</artifactId>
    <version>3.0.0</version>
</dependency>
```

#### （2）配置类

```java
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import springfox.documentation.oas.annotations.EnableOpenApi;
import springfox.documentation.spi.DocumentationType;
import springfox.documentation.spring.web.plugins.Docket;
@Configuration
@EnableOpenApi // 开启 Swagger
public class SwaggerConfig {
    @Bean
    public Docket docket() {
        return new Docket(DocumentationType.OAS_30)
                .select()
                // 扫描接口包路径
                .apis(RequestHandlerSelectors.basePackage("com.example.controller"))
                .paths(PathSelectors.any())
                .build();
    }
}
```

#### （3）访问地址

- 启动项目，访问：http://localhost:8080/swagger-ui/index.html
- 在线调试接口：点击接口→「Try it out」→填写参数→「Execute」

### 2. Knife4j 配置（Swagger 增强版）

#### （1）引入依赖

```xml
<dependency>
    <groupId>com.github.xiaoymin</groupId>
    <artifactId>knife4j-spring-boot-starter</artifactId>
    <version>3.0.3</version>
</dependency>
```

#### （2）配置类（同 Swagger，无需额外修改）

#### （3）访问地址

- 启动项目，访问：http://localhost:8080/doc.html
- 优势：界面更简洁、支持文档导出、全局参数配置、接口排序

#### （4）常用注解

```java
@RestController
@RequestMapping("/user")
@Api(tags = "用户管理模块") // 模块说明
public class UserController {
    @GetMapping("/{id}")
    @ApiOperation("根据ID查询用户") // 接口说明
    @ApiImplicitParam(name = "id", value = "用户ID", required = true) // 参数说明
    public User getById(@PathVariable Long id) {
        return userService.getById(id);
    }
}
```

## 四、工具对比与选择建议

1. Postman：适合个人调试、简单测试，生态成熟，跨平台
2. Apifox：企业级首选，全链路覆盖（调试+文档+Mock+测试），团队协作强
3. Knife4j：后端开发必备，自动生成文档，在线调试，集成简单
