# 本科阶段为进入互联网大厂的准备指南

## 概述

本科阶段进入互联网大厂，需要在 **基础知识、后端技术栈、开发实践、软实力** 四个维度做系统准备。本文提供结构化的能力清单与分阶段准备路线，适用于大一开始规划、大三冲刺校招的学生。

---

## 一、基础知识

### 1.1 编程语言与数据结构

| 领域 | 核心内容 | 面试重要性 |
|------|---------|:---:|
| **Java 语言基础** | 基本语法、OOP（封装/继承/多态）、集合框架、异常处理、IO/NIO | 🔴 必考 |
| **数据结构** | 链表、树（二叉树/红黑树/B+树）、堆、栈、队列、哈希表、图 | 🔴 必考 |
| **算法** | 排序（快排/归并/堆排）、搜索（二分/DFS/BFS）、动态规划、贪心、回溯 | 🔴 必考 |

### 1.2 计算机基础

| 领域 | 核心内容 | 面试重要性 |
|------|---------|:---:|
| **数据库** | MySQL（SQL/索引/事务/锁/MVCC）、非关系型（MongoDB 基础） | 🔴 必考 |
| **操作系统** | 进程/线程管理、内存管理、文件系统、Linux 常用命令 | 🟡 高频 |
| **计算机网络** | TCP/IP 协议栈、HTTP/HTTPS、TCP 三次握手/四次挥手、Socket 编程 | 🔴 必考 |

---

## 二、Java 后端开发技术栈

| 领域 | 核心内容 | 掌握程度 |
|------|---------|:---:|
| **核心框架** | Spring（IoC/AOP）、Spring Boot（自动配置）、Spring MVC（请求链路）、MyBatis（动态 SQL/缓存） | 🔴 精通 |
| **多线程与并发** | 线程创建与管理、synchronized/Lock、线程池（ThreadPoolExecutor）、JUC 工具类 | 🔴 精通 |
| **JVM** | 内存模型（堆/栈/方法区）、GC 算法与回收器（CMS/G1/ZGC）、类加载机制（双亲委派）、JVM 调优基础 | 🟡 深入理解 |
| **中间件** | Redis（缓存策略/分布式锁）、RabbitMQ/Kafka（消息模型/可靠性）、Nginx（反向代理/负载均衡） | 🟡 熟练使用 |
| **分布式系统** | CAP/BASE 理论、分布式锁、分布式事务、RPC（Dubbo/Feign）、服务注册与发现 | 🟡 理解原理 |

## 五、分阶段准备路线

### 全景图

```
大一（探索期）      大二（构建期）       大三（冲刺期）       大四（收获期）
    │                   │                   │                   │
 Java 语法基础      Spring Boot      分布式/微服务        秋季校招
 数据结构入门       MySQL/Redis       算法集中刷题         春季补录
 CS 基础课程        Git/Maven         完整项目            实习转正
                   第一份实习          暑期实习
```

### 各阶段详细计划

| 阶段 | 核心任务 | 具体目标 | 产出物 |
|:----:|---------|---------|--------|
| **大一** | 打好基础、确定方向 | Java SE 熟练掌握、数据结构与算法入门、操作系统/网络基础了解 | 1~2 个小型控制台/Web 项目 |
| **大二上** | 学习核心框架 | Spring Boot + MyBatis + MySQL + Redis，能独立开发 CRUD 项目 | 1 个完整的后台管理系统 |
| **大二下** | 深入中间件与项目 | 中间件实战（MQ/缓存）、Git/Maven 工程化、争取第一份实习 | GitHub 项目 + 实习经历 |
| **大三上** | 分布式 + 算法强化 | Spring Cloud 微服务、分布式基础、LeetCode 高频 150 题 | 微服务项目 + 刷题记录 |
| **大三下** | 暑期实习 + 校招准备 | 大厂暑期实习（3~6 月）、简历打磨、模拟面试 | 实习 Offer + 面试题库 |
| **大四** | 秋招 + 春招 | 参加秋招（8~10 月）和春招补录（次年 3~4 月） | 正式 Offer |

## 六、大厂面试重点分布

| 考察维度 | 占比 | 典型问题 |
|---------|:---:|---------|
| **算法题** | 30% | 链表/树/DP/贪心现场手撕，白板编程 |
| **Java 基础 + JVM** | 20% | HashMap 原理、ConcurrentHashMap、GC 流程、类加载 |
| **数据库** | 15% | MySQL 索引优化、事务隔离级别、MVCC、慢查询分析 |
| **框架原理** | 15% | Spring IoC/AOP、事务传播、Boot 自动配置 |
| **分布式/高并发** | 10% | Redis 缓存策略、分布式锁、MQ 可靠性、限流熔断 |
| **项目深挖** | 10% | 项目难点、技术选型、性能优化、异常处理 |
