## 1. 编程语言与基础

| 书名 | 适合人群 | 核心内容 |
|------|----------|----------|
| 《Java 编程思想》 | Java 初学者/中级 | Java 核心概念和编程思想 |
| **《Effective Java》** ⭐ | 有基础者 | Java 开发最佳实践 |
| **《深入理解 Java 虚拟机》** | 进阶 | JVM 原理、性能优化 |
| 《Java 并发编程实战》 | 进阶 | 多线程、高并发权威指南 |
| 《Python 编程：从入门到实践》 | Python 初学者 | 基础语法 + Web 开发 |
| 《Go 语言实战》 | Go 初学者 | 高并发、分布式 |

## 8. 学习顺序建议

```text
① 基础语言（Java / Python / Go 入门）
  ↓
② 数据库（SQL + 一种 NoSQL）
  ↓
③ Web 框架（Spring Boot / Flask）
  ↓
④ 系统设计与架构（高可用、高性能）
  ↓
⑤ 性能优化与调优
  ↓
⑥ 网络与操作系统
```

> ⭐ 标注为必读经典，建议优先阅读。
