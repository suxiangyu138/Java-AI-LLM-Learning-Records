## 1. 系统磁盘清理

| 步骤 | 操作 |
|:----:|------|
| 1 | 此电脑 → 右键 C 盘 → **属性** |
| 2 | 点击 **磁盘清理**，等待扫描 |
| 3 | 点击 **清理系统文件**，再次扫描 |
| 4 | 勾选所有可清理项（临时文件、更新缓存、回收站、缩略图等） |
| 5 | 点击 **确定** 删除 |

---

## 2. 迁移大文件目录

### 2.1 微信/QQ/钉钉（核心清空间）

| 软件 | 操作路径 |
|------|----------|
| 微信 | 设置 → 文件管理 → 修改存储位置到 D 盘 → 确认迁移 |
| QQ | 同上 |
| 钉钉 | 同上 |

### 2.2 桌面/下载/文档（批量迁移）

| 步骤 | 操作 |
|:----:|------|
| 1 | 此电脑 → 右侧找到 **桌面** 文件夹 |
| 2 | 右键 → **属性** → **位置** → **移动** |
| 3 | 选择 D 盘新建文件夹，确认迁移 |
| 4 | **下载**、**文档** 文件夹执行相同操作 |

### 2.3 浏览器下载路径

| 浏览器 | 操作 |
|--------|------|
| Chrome / Edge | 设置 → 下载内容 → 默认路径改为 D 盘 |

## 3. 系统优化

| 操作 | 命令 / 路径 | 效果 |
|------|------------|------|
| **关闭休眠** | `powercfg -h off`（管理员 CMD） | 删除休眠文件，释放数 GB |
| **卸载无用软件** | 设置 → 应用 → 已安装应用 → 筛选 C 盘 → 卸载 | 释放程序占用空间 |

---

## 4. 定期维护（每月 1 次）

| 序号 | 操作 |
|:----:|------|
| 1 | 重复磁盘清理 |
| 2 | 检查微信/QQ 缓存是否堆积，定期清理 |
| 3 | 确认下载文件夹无无用大文件 |

---

> 🎯 **释放空间预估**：磁盘清理 2-5GB + 微信迁移 10-30GB + 休眠关闭 4-16GB + 个人文件夹迁移 5-20GB。总计可释放 **20-70GB**。
