# Java 后端开发必做练习项目

## 概述

练习项目是 Java 后端学习的核心输出环节，能串联所有知识点（框架、数据库、缓存、中间件、分布式）。本文按 **入门 → 进阶 → 高阶** 三个阶段规划 6 个必做项目，每个项目标注核心技术点和实现目标，可直接按顺序推进。

---

## 项目全景总览

| 阶段 | 项目 | 核心价值 | 建议耗时 |
|:---:|------|---------|:---:|
| 入门 | ① 用户管理系统 | 建立 CRUD 与项目规范意识 | 1~2 周 |
| 入门 | ② 个人博客系统 | 前后端联调 + Redis 缓存入门 | 2~3 周 |
| 进阶 | ③ 电商后台系统 | 覆盖 80% 后端业务场景 | 3~4 周 |
| 进阶 | ④ 任务调度系统 | 中间件最佳实践 | 1~2 周 |
| 高阶 | ⑤ 微服务版电商系统 | 分布式架构全栈能力 | 4~6 周 |
| 高阶 | ⑥ 秒杀系统 | 高并发面试王牌项目 | 2~3 周 |

---

## 第一阶段：入门级

> **目标**：掌握 CRUD、接口开发、基础数据库操作，建立完整项目思维。
> **前置要求**：学完 SSM / Spring Boot 基础。

### 项目一：用户管理系统

| 维度 | 内容 |
|------|------|
| **核心知识点** | Spring Boot、MyBatis-Plus、MySQL、统一返回封装、全局异常处理、Lombok、Maven |
| **定位** | 入门必做——建立后端项目的完整骨架认知 |

#### 功能清单

| # | 功能模块 | 具体实现 |
|:--:|---------|---------|
| 1 | 用户注册/登录 | 密码 BCrypt 加密存储、登录 Token 返回 |
| 2 | 用户 CRUD | 增删改查完整接口 |
| 3 | 分页与条件查询 | MyBatis-Plus 分页插件 + 动态条件拼接 |
| 4 | 接口文档 | Knife4j / Swagger 自动生成 |

#### 亮点要求

| 亮点 | 涉及知识点 |
|------|-----------|
| 参数校验 | Spring Validation（`@Valid` + 自定义校验注解） |
| 基础权限控制 | 拦截器 + 角色枚举（ADMIN / USER） |
| 日志记录 | SLF4J + AOP 切面日志 |

## 第二阶段：进阶级

> **目标**：吃透缓存、事务、高并发基础、中间件，解决真实业务问题。
> **前置要求**：掌握 Spring Boot + Redis 基础。

### 项目三：电商后台系统

> ⭐ **核心必做项目**，覆盖 80% 后端业务场景，面试中最重要的项目经历。

| 维度 | 内容 |
|------|------|
| **核心知识点** | MySQL 事务与索引优化、Redis 缓存策略、分布式锁、支付流程模拟 |
| **定位** | 后端业务能力集大成者 |

#### 功能模块

| 模块 | 核心功能 |
|------|---------|
| **商品模块** | 商品列表、详情、库存管理、上下架 |
| **用户模块** | 收货地址管理、用户中心 |
| **订单模块** | 创建订单 → 支付流程 → 订单状态流转（待支付/已支付/已发货/已完成/已取消） |
| **购物车** | 登录态购物车、商品数量修改、选中结算 |

#### 技术亮点（面试核心考点）

| 亮点 | 实现方案 | 面试对应考点 |
|------|---------|-------------|
| 缓存热点商品 | Redis 缓存 + 过期时间随机化 | 缓存穿透/击穿/雪崩 |
| 防止库存超卖 | Redis 分布式锁（Redisson / SET NX） | 并发安全 |
| SQL 性能优化 | 索引优化 + 分页优化 + 联表查询优化 | MySQL 调优 |
| 订单状态机 | 状态枚举 + 事件驱动流转 | 系统设计 |

### 项目四：任务调度系统

| 维度 | 内容 |

#### 功能清单

| # | 功能 | 具体实现 |

```
电商项目（订单模块） → 下单时记录创建时间
                      ↓
任务调度系统 → 定时扫描超时订单 → 自动取消并释放库存
```

## 第三阶段：高阶/面试级

> **目标**：掌握分布式架构、微服务生态、高并发解决方案，适配大厂面试。
> **前置要求**：熟练 Spring Boot + 完成进阶项目。

### 项目五：微服务版电商系统

> ⭐ **终极实战项目**，覆盖全栈后端核心能力。

| 维度 | 内容 |
|------|------|
| **核心知识点** | Spring Cloud Alibaba（Nacos / Sentinel / Gateway / OpenFeign / Seata）、Redis 集群、RabbitMQ、Docker |
| **定位** | 分布式架构能力全面展示 |

#### 微服务模块拆分

| 服务 | 核心职责 | 关键技术点 |
|------|---------|-----------|
| **用户服务** | 注册、登录、JWT 鉴权 | Spring Security + JWT |
| **商品服务** | 商品 CRUD、库存管理 | MySQL + Redis 缓存 |
| **订单服务** | 订单创建、支付回调、状态同步 | 分布式事务（Seata AT） |
| **搜索服务** | 商品全文检索 | Elasticsearch |
| **网关服务** | 路由转发、权限校验、限流 | Spring Cloud Gateway |

#### 核心技术能力

| # | 能力 | 技术方案 |
|:--:|------|---------|
| 1 | 微服务通信 | OpenFeign 声明式远程调用 |
| 2 | 服务注册与配置 | Nacos（注册中心 + 配置中心） |
| 3 | 分布式事务 | Seata AT 模式（订单 + 库存跨服务一致性） |
| 4 | 限流熔断降级 | Sentinel（QPS 限流 + 熔断兜底策略） |
| 5 | 消息异步解耦 | RabbitMQ（订单创建 → 库存扣减 → 日志记录异步化） |
| 6 | 容器化部署 | Docker + Docker Compose 一键部署 |

---

### 项目六：秒杀系统

> ⭐ **高并发面试王牌项目**，大厂高频考点集中地。

| 维度 | 内容 |
|------|------|
| **核心知识点** | Redis、Lua 脚本、令牌桶限流、消息队列、MySQL 行级锁、JMeter 压测 |
| **定位** | 高并发场景的系统设计与优化能力证明 |

#### 核心链路

```
用户请求 → 令牌桶限流 → Redis + Lua 预扣库存
                            ↓
                    RabbitMQ 异步下单
                            ↓
                    MySQL 订单落库 + 库存扣减
                            ↓
                    异步通知秒杀结果
```

#### 功能与亮点

| 功能 | 实现方案 | 面试考点 |
|------|---------|---------|
| 库存控制 | Redis + Lua 脚本原子扣减，防止超卖/少卖 | 原子性、并发安全 |
| 接口限流 | 令牌桶算法（RateLimiter / Sentinel） | 限流算法对比 |
| 防刷 | 用户 ID + 活动 ID 频率限制、验证码 | 安全防护 |
| 异步下单 | Redis 预扣 → MQ 异步 → DB 落库 | 削峰填谷 |
| 结果通知 | MQ 异步回调 / WebSocket 推送 | 异步通信 |
| 性能验证 | JMeter 压测，优化至万级 QPS | 性能调优 |

## 四、通用项目规范

所有项目必须遵守以下规范，养成工程化习惯：

| 规范类别 | 具体要求 |
|---------|---------|
| **代码规范** | 遵循阿里巴巴 Java 开发手册；统一包结构（controller/service/mapper/entity/config）；类/方法/变量命名规范；关键逻辑加注释 |
| **分层架构** | Controller → Service → Mapper/DAO → Entity；统一返回结果类（`Result<T>`）；全局异常处理器（`@RestControllerAdvice`） |
| **版本控制** | Git 初始化 + `.gitignore` 配置；功能分支开发；有意义的 Commit Message |
| **构建工具** | Maven 依赖管理；多模块项目结构（微服务项目） |
| **单元测试** | JUnit 5 + MockMvc 接口测试；核心 Service 层测试覆盖率 > 60% |
| **文档** | 每个项目写 README（项目简介/技术栈/运行方式/接口说明）；核心接口写 Swagger 文档 |
| **部署** | 本地可运行（`java -jar`）；Docker 部署（Dockerfile + Docker Compose） |
