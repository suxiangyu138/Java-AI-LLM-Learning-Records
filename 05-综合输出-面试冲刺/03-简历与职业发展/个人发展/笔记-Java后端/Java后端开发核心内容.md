## 一、Java 基础（刻进 DNA 级别）
- 集合框架：HashMap、ConcurrentHashMap、ArrayList、LinkedList、HashSet
    原理、线程安全、扩容、红黑树、使用场景
- JVM 内存模型：堆、栈、方法区、垃圾回收、GC 算法
- 异常体系：Exception / RuntimeException 区别，try-catch-finally
- 多线程 & 并发：
    Thread、Runnable、Callable、Future、线程池
    synchronized、volatile、Lock、AQS、CAS、ThreadLocal
- 泛型、反射、注解、Lambda、Stream

## 二、Spring 全家桶（后端灵魂）
- Spring IOC / AOP 原理
- Spring Bean 生命周期
- Spring 事务传播机制、隔离级别
- Spring MVC 完整流程
- Spring Boot 自动配置原理
- 常用注解背到肌肉记忆：
     @Controller   @Service   @Repository   @Component 
     @Autowired   @Qualifier   @Value   @Configuration 
     @Transactional   @RestController   @RequestMapping 
     @GetMapping   @PostMapping   @RequestParam   @RequestBody 

## 三、MyBatis / MyBatis-Plus（CRUD 永生）

- 一级缓存、二级缓存
- 分页、批量插入、逻辑删除、乐观锁

## 四、MySQL（后端吃饭家伙）

- explain 执行计划
- 慢查询优化
- 事务 ACID、隔离级别
- MVCC 原理
- 常用 SQL 必须随手写：
    多表联查、子查询、分组、去重、排序、limit

## 五、Redis（缓存必学）
