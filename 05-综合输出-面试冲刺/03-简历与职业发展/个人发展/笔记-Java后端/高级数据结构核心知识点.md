## 1. 平衡二叉树与优化树形结构

| 结构 | 平衡方式 | 复杂度 | 特点 | Java / 工程应用 |
|------|----------|:----:|------|----------------|
| **AVL 树** | 严格平衡，高度差 ≤ 1 | O(log n) | 查询极快，插入删除旋转频繁 | — |
| **红黑树** | 颜色规则+旋转，弱平衡 | O(log n) | 综合效率最高 | `TreeMap`、`TreeSet`、Nginx 定时器 |
| **B 树** | 多路平衡，节点存数据 | O(log n) | 减少磁盘 IO | 文件系统 |
| **B+ 树** | 数据仅叶子，叶子链表 | O(log n) | 范围查询高效 | **MySQL InnoDB 索引** |

### B 树 vs B+ 树

| 维度 | B 树 | B+ 树 |
|------|------|------|
| 数据存储 | 所有节点存数据 | 仅叶子存数据 |
| 叶子链接 | 无 | ✅ 有序链表 |
| 范围查询 | 需回溯 | ✅ 高效遍历 |
| 应用 | — | 数据库索引标准 |

## 2. 堆与优先队列扩展

| 结构 | 操作复杂度 | 用途 |
|------|:--------:|------|
| **二叉堆**（大顶/小顶） | 插入/删除 O(log n)，取极值 O(1) | 堆排序、优先队列、任务调度 |
| **可合并堆**（左偏树/斜堆） | 合并 O(log n) | 频繁合并优先队列 |
| **索引堆** | 可动态修改优先级 | Dijkstra 高效实现 |

## 3. 哈希结构扩展

| 结构 | 核心能力 | 典型应用 |
|------|----------|----------|
| **布隆过滤器** | 空间极省，判断"一定不存在"或"可能存在" | 缓存穿透防护、黑名单、URL 去重 |
| **一致性哈希** | 节点增减时最少数据迁移 | 分布式缓存、负载均衡 |
| **跳表（SkipList）** | 多层索引，O(log n)，并发友好 | **Redis ZSet**、LevelDB、RocksDB |

### 哈希冲突解决

| 方式 | 原理 |
|------|------|
| 链地址法 | 链表连接冲突元素 |
| 开放寻址法 | 探测寻找空位 |

## 4. 并查集

> 管理分组与连通关系，支持快速合并与查询。

| 操作 | 说明 |
|------|------|
| Find | 判断元素所属集合 |
| Union | 合并两个集合 |

| 优化 | 效果 |
|------|------|
| 路径压缩 | 接近 O(1) |
| 按秩合并 | 接近 O(1) |

**应用**：无向图连通性、朋友圈问题、Kruskal 最小生成树、集群节点管理。
