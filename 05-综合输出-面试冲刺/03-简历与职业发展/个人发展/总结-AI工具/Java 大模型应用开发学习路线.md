# Java 大模型应用开发学习路线
 总体思路
- 以 Java + Spring Boot 工程能力 为主，把大模型当成外部服务/组件来用。
- 先会“用”，再会“组合”，最后会“工程化上线”。
- 不急着学算法，先能做出可运行的 AI 功能。
    阶段 1：打基础（1-2 周）
    目标：能写 Java 程序，能调通大模型 API，跑出第一个 AI 功能。
    1. Java & Spring Boot 复习
   - 集合、IO、异常处理
   - Spring Boot 项目创建、REST API 编写
    2. 大模型基础概念
   - 知道什么是 LLM、Token、上下文长度、温度等
   - 了解常见模型：GPT、通义千问、文心一言、DeepSeek 等
    3. 调用大模型 API
   - 用 
    "HttpClient" / OkHttp 发 POST 请求
   - 用 Spring Boot 封装一个 
    "/chat" 接口
    4. 小项目
   - 做一个“智能聊天接口”或“代码生成小助手”，前端用 Postman 测试
    ✅ 产出：能调通 API 的 Spring Boot 服务，可返回模型回答
    阶段 2：RAG 检索增强生成（2-4 周）
    目标：让模型能基于你自己的数据回答问题，解决“知识过期”和“胡说八道”问题。
    1. 文档处理
   - 用 Apache PDFBox 等库读 PDF/Word/Markdown
    2. 文本分块
   - 按长度/句子切分，保证每块能放进模型上下文
    3. 向量化 (Embedding)
   - 调用 Embedding API 将文本转成向量
    4. 向量存储
   - 用 FAISS / Milvus / pgvector 存向量
    5. 检索 + 生成
   - 用户提问 → 向量检索相关文档 → 拼接 prompt → 调模型生成答案
    6. 小项目
   - “公司制度问答机器人” 或 “产品文档智能助手”
    ✅ 产出：能根据本地文档回答问题的 RAG 系统
    阶段 3：Function / Tool Calling（2-4 周）
    目标：让模型能调用你写的 Java 方法，完成实际业务动作。
    1. 理解 Tool Calling 机制
   - 在 prompt 里定义工具（函数描述）
   - 模型决定调用哪个工具，返回调用信息
    2. Java 实现工具方法
   - 如：查天气、查航班、查数据库、发邮件
    3. 解析模型返回的工具调用请求
   - 提取函数名 + 参数，用反射或 Map 找到对应方法执行
    4. 将结果回传给模型
   - 得到最终回答
    5. 小项目
   - “旅行规划助手”：查天气、查酒店、查航班，再综合给出方案
    ✅ 产出：能自动调用外部工具的 Agent 型应用
    阶段 4：工程化与系统整合（持续）
    目标：让 AI 服务稳定、可扩展、可上线。
    1. 容器化
   - 用 Docker 打包你的 Spring Boot + 向量库
    2. 编排与服务发现
   - 了解 Kubernetes 基本概念（Deployment、Service）
    3. 性能优化
   - 缓存 Embedding 结果
   - 批量请求模型 API
   - 异步处理耗时任务
    4. 高可用
   - 多模型路由（主模型挂了切备用）
   - 限流、熔断、重试
    5. 接入现有系统
   - 比如把 AI 问答嵌入 OA、CRM、客服系统
    ✅ 产出：可在生产环境运行的 AI 微服务
    阶段 5：进阶（可选）
    目标：能微调模型、优化推理性能，竞争力更强。
    1. Python 基础（能看懂/改脚本）
    2. PyTorch / TensorFlow 入门
    3. 模型微调（LoRA / PEFT）
    4. 高性能推理（vLLM / TGI）
    5. 模型量化 / 剪枝
    🛠 路线总览表
    阶段 主要内容 产出
    1 Java + Spring Boot + API 调用 可调通的聊天接口
    2 RAG（文档处理→向量化→检索→生成） 文档问答机器人
    3 Tool Calling（模型调用Java方法） 自动化助手/Agent
    4 Docker/K8s + 性能优化 + 高可用 生产级 AI 微服务
    5 Python + 微调 + 推理优化 定制化模型能力
