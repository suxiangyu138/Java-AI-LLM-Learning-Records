# AI 方向学习黑名单

## 概述

> **定位前提**：本文面向 **Java 后端开发 + AI 应用落地** 方向，目标是成为能集成 AI 能力的后端工程师，而非算法研究员或 AI 框架开发者。

明确"不学什么"与"学什么"同等重要。以下列出五类无需投入时间的方向，帮助聚焦核心技能，节省至少 90% 的试错成本。

---

## 一、纯算法与科研类

**适用人群**：算法岗、博士、AI 研究员。与 Java 后端 + AI 应用落地方向无关。

| 无需学习的内容 | 原因 |
|--------------|------|
| 深度学习底层数学推导（微积分、梯度下降、反向传播） | 应用层调用模型，不需要推导训练过程 |
| PyTorch / TensorFlow 模型训练 | 使用已有模型或 API，不从事模型训练工作 |
| 大模型架构公式推导（Transformer、Attention） | 理解高层原理即可，不需要数学推导 |
| 大模型预训练（Pre-training） | 预训练需要海量算力和专业团队，个人无意义 |
| 复杂微调技术（全参数微调、深度 LoRA 实验） | 应用开发不需要模型定制到这种粒度 |
| 多模态底层算法、扩散模型 | 属于 AI 生成方向的基础研究 |
| 传统 NLP 算法（HMM、CRF、LSTM 原理细节） | 大模型时代已覆盖这些传统方法的能力 |

> **原则**：会用模型，不需要会造模型。

---

## 二、底层工程与基础设施

**适用人群**：深度学习框架工程师、AI 芯片工程师、系统架构师。不属于后端应用开发范畴。

| 无需学习的内容 | 原因 |
|--------------|------|
| CUDA 编程 | GPU 底层并行计算开发 |
| GPU 内核优化 | 硬件级别的性能调优 |
| 算子开发与算子融合 | 深度学习框架底层实现 |
| 分布式训练架构（Megatron、DeepSpeed） | 大模型训练基础设施，非应用层 |

> **原则**：AI 基础设施 ≠ AI 应用开发，二者技能树完全不同。

---

## 三、非核心 AI 风口方向

这些方向要么与后端开发关联度低，要么投入产出比低，不建议跟风。

| 无需学习的内容 | 原因 |
|--------------|------|
| AI 绘画底层（Stable Diffusion 模型修改） | 与后端开发无关，属于图像生成独立领域 |
| AI 视频生成 / 换脸技术 | 非企业级应用主流方向 |
| 本地部署各类小型开源模型 | 低价值重复劳动，真正工作场景使用企业级方案 |
| AI 自动化脚本 / 非正规用途爬虫 | 不属于正统技术能力积累 |
| 各类 AI 工具网站的操作技巧 | 使用者层面的技巧不重要，重要的是集成开发能力 |

---

## 四、过于前沿、尚未落地的方向

这些方向技术尚在学术探索阶段，企业级应用中暂未普及。

| 无需学习的内容 | 原因 |
|--------------|------|
| AGI（通用人工智能）理论 | 学术界前沿课题，对应用开发无直接帮助 |
| 复杂 AI Agent 框架深度定制（如 crewAI 重度使用） | Agent 框架快速迭代，当前深度定制可能很快过时 |
| 大模型安全 / 对齐（Alignment）/ 红队攻防 | 大模型厂商和安全公司的专业领域 |
| 知识图谱深度构建 / 图神经网络 | 企业级后端场景极少涉及 |

---

## 五、与 Java 后端定位不匹配的技能

**核心原则**：你是一个 Java 后端工程师，不是数据分析师或算法工程师。AI 技能的学习应围绕"如何在 Java 后端系统中集成 AI 能力"展开。

| 无需学习的内容 | 原因 |
|--------------|------|
| Python 全栈 AI 开发 | 编程语言以 Java 为主，Python 作为辅助工具即可 |
| 大量 Python 机器学习库（scikit-learn 等） | 传统 ML 库的使用场景与 LLM 应用开发交集有限 |
| Jupyter Notebook 重度使用 | 数据分析/算法工程师的工具，非后端工程师日常 |
| 数据挖掘 / 特征工程 | 属于数据科学岗位的技能范畴 |

---

## 六、最终聚焦：7 项核心技能

排除以上五类后，Java 后端 + AI 应用开发方向只需聚焦以下 7 项技能。

| # | 技能 | 说明 |
|:--:|------|------|
| **1** | 大模型 API 调用 | HTTP 接口 / 官方 SDK 的调用与封装，掌握请求重试、熔断降级、多模型切换 |
| **2** | 流式输出（SSE） | 在 Spring Boot 中实现 Server-Sent Events，完成 LLM 回答的流式返回 |
| **3** | 提示词工程（Prompt Engineering） | Few-shot、Chain-of-Thought、角色设定、结构化输出等核心技巧 |
| **4** | RAG 检索增强生成 | 文档加载 → 文本切分 → Embedding 向量化 → 向量库检索 → Prompt 组装 → LLM 生成的完整链路 |
| **5** | 向量数据库 | Milvus / FAISS 等向量库的基本使用与检索策略 |
| **6** | Spring AI / LangChain | 框架的基本使用方法，不深入框架源码级定制 |
| **7** | 模型部署与基本运维 | Docker 容器化部署大模型服务，基本的健康检查与日志监控 |

> 掌握以上 7 项，即可具备"Java 后端 + AI 应用"的复合竞争力，满足校招与实习岗位的 AI 方向技术要求。
