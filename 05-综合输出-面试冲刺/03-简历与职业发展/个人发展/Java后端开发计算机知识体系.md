# Java 后端开发计算机知识体系

## 概述

本文按 12 个知识领域系统梳理 Java 后端开发工程师需要掌握的完整计算机知识体系，覆盖 **基础理论、开发技术、架构与工程化、综合素养** 四大板块，适用于体系化学习规划与能力自检。

## 一、基础理论

| 领域 | 核心内容 | 重要性 |
|------|---------|:---:|
| **数据结构与算法** | 数组/链表/栈/队列/哈希/树/图；排序/搜索/DP/贪心/回溯/分治 | 🔴 核心 |
| **计算机组成原理** | CPU 执行流程、存储层次（Cache/内存/磁盘）、指令集、冯诺依曼结构 | 🟡 重要 |
| **操作系统** | 进程/线程管理、内存管理、文件系统、IO 模型 | 🔴 核心 |
| **计算机网络** | TCP/IP 协议栈、HTTP/HTTPS、DNS、Socket 编程 | 🔴 核心 |
| **数据库原理与设计** | 关系模型、范式设计、ER 模型、索引原理、事务与并发控制 | 🔴 核心 |

## 二、Java 语言

| 模块 | 核心内容 | 重要性 |
|------|---------|:---:|
