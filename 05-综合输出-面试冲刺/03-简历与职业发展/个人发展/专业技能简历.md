| 技能项 | 具体内容 | 掌握程度 |

## 六、技能熟练度汇总

| 等级 | 含义 | 对应技能 |
|:----:|------|---------|
| **熟练掌握** | 能独立完成开发任务，理解底层原理，可面试对答 | Java SE、JUC、JVM、Spring Boot、MySQL、Redis、RAG 架构、Prompt Engineering、Python |
| **熟练使用** | 可独立完成日常开发，了解核心原理 | MyBatis、RabbitMQ、ES、设计模式、大模型 API 接入、Agent 编排、Git、Maven、Linux |
| **熟悉** | 了解原理并有实践经验，查阅文档后可独立工作 | Spring Cloud Alibaba、Spring Security、多轮对话管理、向量数据库 |
| **了解** | 了解概念和基本用法，有学习或简单实践经验 | Docker、CI/CD、可观测性、幻觉抑制 |
