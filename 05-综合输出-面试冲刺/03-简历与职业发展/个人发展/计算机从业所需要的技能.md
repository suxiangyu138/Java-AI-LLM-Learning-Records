# 计算机从业所需要的技能

## 概述

计算机从业者需要掌握的技能体系涵盖 **编程语言、前后端技术、数据库、中间件、分布式系统、基础理论、AI/数据、软实力** 八大领域。本文提供结构化的技能清单，便于能力自检与学习规划。

---

## 一、编程语言

| 语言 | 主要应用领域 | 优先级 |
|------|------------|:---:|
| **Java** | 企业级后端开发、Android、大数据 | 🔴 核心 |
| **JavaScript** | Web 前端、Node.js 后端 | 🟡 重要 |
| **TypeScript** | 大型前端项目、全栈开发 | 🟡 重要 |
| **Python** | AI/ML、数据分析、脚本工具 | 🔴 核心（AI 方向） |

---

## 二、前端技术

| 技术 | 层级 | 说明 |
|------|:----:|------|
| **HTML / CSS** | 基础 | Web 页面结构与样式，所有前端技术的地基 |
| **React** | 框架 | Meta 出品，生态最大，国内大厂主流 |
| **Vue.js** | 框架 | 尤雨溪出品，中文友好，中小项目首选 |
| **Ant Design** | UI 组件库 | 蚂蚁集团出品，企业级中后台 UI 解决方案 |

---

## 三、后端技术

| 技术 | 定位 | 说明 |
|------|------|------|
| **Spring Boot** | 快速开发框架 | Java 后端事实标准，自动配置 + 内嵌服务器 |
| **Spring Cloud** | 微服务全家桶 | 分布式系统解决方案（注册/配置/网关/熔断） |
| **MyBatis** | ORM 框架 | SQL 可控的持久层框架，国内主流 |
| **Dubbo** | RPC 框架 | 阿里开源，高性能 Java RPC 框架 |

---

## 四、数据库技术

### 4.1 关系型数据库

| 数据库 | 特点 | 适用场景 |
|--------|------|---------|
| **MySQL** | 开源、高性能、社区活跃 | 互联网公司首选，中小型到大型项目通用 |
| **PostgreSQL** | 功能丰富、扩展性强、符合 SQL 标准 | 对数据完整性要求高的场景 |
| **Oracle** | 功能强大、商业支持完善 | 金融、政务等大型企业级应用 |
| **SQL Server** | 微软生态、集成度高 | .NET 技术栈企业 |

### 4.2 非关系型数据库

| 数据库 | 类型 | 核心用途 |
|--------|------|---------|
| **Redis** | 键值存储 | 缓存、分布式锁、排行榜、消息队列 |
| **MongoDB** | 文档存储 | 非结构化数据、日志存储、快速原型 |
| **HBase** | 列存储 | 大数据场景下的海量结构化存储 |

---

## 五、消息中间件

| 中间件 | 特点 | 典型场景 |
|--------|------|---------|
| **Kafka** | 超高吞吐、持久化、分区并行 | 日志采集、流处理、大数据管道 |
| **RocketMQ** | 阿里开源、事务消息、顺序消息 | 电商交易、金融场景 |
| **RabbitMQ** | 可靠性高、路由灵活、社区成熟 | 业务解耦、异步处理 |

---

## 六、分布式系统与基础理论

| 领域 | 核心内容 |
|------|---------|
| **分布式系统** | CAP 定理、BASE 理论、一致性协议（Paxos/Raft）、分布式锁、分布式事务、分布式 ID |
| **操作系统** | Linux 常用命令、进程/线程管理、内存管理、文件系统、Shell 脚本 |
| **网络编程** | TCP/IP 协议栈、HTTP/HTTPS、Socket 编程、Netty 框架 |
| **版本控制** | Git（分支管理、冲突解决、Git Flow）、GitHub/GitLab 协作 |
| **构建工具** | Maven / Gradle 依赖管理与项目构建 |

---

## 七、架构设计与设计模式

| 领域 | 核心内容 |
|------|---------|
| **软件架构** | 单体架构 vs 微服务架构、分层架构、事件驱动架构、DDD 领域驱动设计 |
| **设计模式** | 创建型（单例/工厂/建造者）、结构型（代理/装饰者/适配器）、行为型（策略/观察者/模板方法） |
| **架构原则** | SOLID 原则、KISS、DRY、YAGNI、高内聚低耦合 |

---

## 八、数学与算法基础

| 领域 | 核心内容 | 在计算机中的应用 |
|------|---------|----------------|
| **概率论与数理统计** | 概率分布、假设检验、贝叶斯定理 | 机器学习模型评估、A/B 测试、数据推断 |
| **线性代数** | 矩阵运算、特征值与特征向量、向量空间 | 计算机图形学、ML 模型（神经网络矩阵运算）、推荐系统 |
| **微积分** | 导数、偏导数、梯度 | 深度学习反向传播、优化算法 |
| **数据结构** | 数组/链表/栈/队列/哈希/树/图 | 所有程序设计的基础 |
| **算法** | 排序/搜索/DP/贪心/回溯/分治 | 性能优化、面试必考 |

## 十、软实力

| 能力维度 | 核心要求 | 提升方式 |
|---------|---------|---------|
| **沟通与协作** | 跨角色高效沟通，需求对齐 | 主动同步进度、参与技术评审、练习非暴力沟通 |
| **问题解决** | 系统性分析问题，定位根因 | 培养结构化思维，积累排错经验 |
| **持续学习** | 跟踪技术动态，快速上手新技术 | 阅读官方文档、参与开源、输出技术博客 |
| **责任心** | 对代码和交付物负责，主动承担 | 写出可维护的代码，线上问题不逃避 |
| **技术领导力** | 技术方案设计、团队指导、技术决策 | 从模块负责人起步，逐步承担更大技术职责 |
| **项目管理** | 敏捷开发、Scrum、进度与风险管控 | 使用 Jira/Trello 管理任务、学习 PMBOK 框架 |
