# 后端开发工程师技术学习路线

## 概述

后端开发工程师需要掌握的技术体系跨度广、深度高。本文以 **Java 后端**为默认技术栈，按 **编程语言 → 框架 → 数据库 → 网络通信 → 系统运维 → 安全 → 性能优化 → 工程化 → 基础素养** 九大板块系统梳理学习内容，并提供优先级建议。

---

## 一、编程语言

### 1.1 主语言：Java

| 阶段 | 学习内容 | 优先级 |
|:----:|---------|:---:|
| 语法基础 | 基本语法、数据类型、控制结构、OOP 三大特性（封装/继承/多态） | 🔴 必学 |
| 核心进阶 | 集合框架、异常处理、泛型、反射、注解、IO/NIO、Lambda/Stream | 🔴 必学 |
| 并发编程 | 线程与线程池、synchronized/volatile/Lock、AQS/CAS、ThreadLocal、JUC 工具类 | 🔴 必学 |
| JVM | 内存模型、类加载机制、GC 算法与调优、JVM 参数 | 🔴 必学 |

### 1.2 辅助语言

| 语言 | 用途 | 掌握程度 |
|------|------|:---:|
| Python | AI 大模型应用开发、脚本工具 | 熟练使用 |
| Go | 高性能服务、云原生中间件开发（可选） | 了解 |
| Shell | Linux 运维脚本、自动化部署 | 熟练使用 |

## 二、开发框架

### 2.1 核心框架（Java 生态）

| 框架 | 核心能力 | 掌握程度 |
|------|---------|:---:|
| **Spring Framework** | IoC 容器、AOP、事务管理 | 🔴 掌握底层原理 |
| **Spring Boot** | 自动配置、Starter、Actuator | 🔴 独立搭建项目 |
| **Spring MVC** | DispatcherServlet、拦截器、RESTful API | 🔴 熟练使用 |
| **MyBatis / MyBatis-Plus** | 动态 SQL、Mapper 代理、分页、缓存 | 🔴 熟练使用 |
| **Spring Cloud Alibaba** | Nacos、Sentinel、Gateway、OpenFeign、Seata | 🟡 熟悉微服务组件 |
| **Spring Security** | 认证授权、JWT、OAuth2、RBAC | 🟡 熟悉安全框架 |

### 2.2 框架原理深度要求

| 知识点 | 面试常问 |
|--------|---------|
| Spring IoC 容器启动流程 | ✅ |
| Spring Bean 生命周期 | ✅ |
| Spring AOP 底层实现（JDK 动态代理 vs CGLIB） | ✅ |
| Spring 事务传播机制（7 种）与失效场景 | ✅ |
| Spring Boot 自动配置原理（`@SpringBootApplication` + SPI） | ✅ |
| MyBatis Mapper 代理与插件机制 | ✅ |

## 三、数据库技术

### 3.1 关系型数据库（MySQL）

| 阶段 | 学习内容 | 面试要求 |
|:----:|---------|---------|
| 基础 | SQL 语法（增删改查、多表联查、子查询、聚合函数、窗口函数） | 能手写复杂 SQL |
| 进阶 | 索引原理（B+Tree）、最左前缀、覆盖索引、EXPLAIN 执行计划分析 | 能口述原理 + 实战优化 |
| 高级 | 事务 ACID、隔离级别、MVCC 原理、锁机制（行锁/间隙锁/临键锁） | 面试高频，必须精通 |
| 架构 | 分库分表策略、读写分离、主从同步 | 了解原理与常见方案 |

### 3.2 非关系型数据库

| 组件 | 用途 | 核心知识点 | 优先级 |
|------|------|---------|:---:|
| **Redis** | 缓存、分布式锁、计数器、排行榜 | 五种数据结构、缓存策略（穿透/击穿/雪崩）、分布式锁、过期与淘汰策略 | 🔴 必学 |
| **Elasticsearch** | 全文搜索、日志分析 | 倒排索引原理、分词器、聚合查询、索引优化 | 🟡 重要 |
| **MongoDB** | 文档存储、非结构化数据 | 文档模型、索引、聚合管道 | ⚪ 了解 |

## 四、网络与通信

| 领域 | 核心内容 | 优先级 |
|------|---------|:---:|
| **网络基础** | TCP/IP 四层模型、三次握手与四次挥手、TCP vs UDP 适用场景 | 🔴 必学 |
| **HTTP/HTTPS** | 请求方法与状态码、HTTPS 握手流程（TLS/SSL）、HTTP/1.1 vs HTTP/2 | 🔴 必学 |
| **RESTful API** | 资源命名规范、HTTP 方法语义、统一返回格式、接口版本管理 | 🔴 必学 |
| **消息队列** | RabbitMQ / Kafka / RocketMQ 选一种精通（异步解耦、削峰、消息可靠性） | 🟡 重要 |
| **RPC 框架** | gRPC（Protobuf）、Dubbo 等基本概念与使用场景 | ⚪ 了解 |

## 六、安全性

| 安全领域 | 具体内容 | 优先级 |
|---------|---------|:---:|
| **常见漏洞防护** | SQL 注入、XSS、CSRF、SSRF、文件上传漏洞 | 🔴 必知必会 |

| **接口安全** | 接口防刷（限流）、参数签名校验、重放攻击防护 | 🟡 重要 |

## 七、性能优化

| 优化层面 | 具体手段 |
|---------|---------|
| **代码层面** | 多线程并发优化、异步处理（CompletableFuture / 消息队列）、避免不必要的对象创建、合理使用连接池 |
| **数据库层面** | SQL 优化（EXPLAIN 分析）、索引优化、读写分离、分库分表、连接池调优 |
| **缓存层面** | Redis 多级缓存、缓存预热、热点数据预处理、穿透/击穿/雪崩防护 |
| **架构层面** | CDN 加速、负载均衡、服务无状态化、异步解耦 |
| **JVM 层面** | GC 调优、堆内存配置、dump 分析、内存泄漏排查 |

## 十、学习路线建议

### 按阶段推进

| 阶段 | 时长 | 学习重点 | 产出 |
|:----:|------|---------|------|
| **入门** | 1~2 个月 | Java SE 核心 + MySQL 基础 + Spring Boot CRUD | 完成一个单体 Web 项目 |
| **进阶** | 2~3 个月 | JUC 并发 + JVM + Redis + MQ + 微服务基础 | 接口 QPS 优化、项目引入缓存与 MQ |
| **高级** | 2~3 个月 | 分布式系统（事务/锁/一致性）+ 源码阅读 + 性能调优 | 完成微服务项目、技术博客输出 |
| **面试冲刺** | 1 个月 | 算法刷题 + 八股复习 + 项目复盘 + 模拟面试 | 达到面试对答流利状态 |

### 优先级图标说明

| 图标 | 含义 |
|:---:|------|
| 🔴 | **必学**：面试必问、工作必用，不掌握无法胜任 |
| 🟡 | **重要**：常见面试考点，提升竞争力 |
| ⚪ | **了解**：知道概念和用途，需要时可快速上手 |
