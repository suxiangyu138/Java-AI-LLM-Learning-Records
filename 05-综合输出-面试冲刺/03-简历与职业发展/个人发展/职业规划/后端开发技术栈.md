# 后端开发技术栈

## 概述

本文梳理 Java 后端开发工程师的完整技术栈，按学习优先级分为 **当前必学** 和 **进阶扩展** 两层，并列出已过时无需投入时间的技术清单。

---

## 一、当前必学技术栈

### 1.1 后端核心

| 技术 | 说明 | 重要程度 |
|------|------|:---:|
| **Java 基础** | Java SE 核心语法、集合框架、IO/NIO、多线程与 JUC 并发、JVM | 🔴 根基 |
| **Spring Boot** | 快速开发框架，自动配置、内嵌服务器、Starter 生态 | 🔴 核心 |
| **MySQL** | 关系型数据库，SQL 编写、索引优化、事务与锁、慢查询调优 | 🔴 核心 |
| **MyBatis / MyBatis-Plus** | ORM 框架，动态 SQL、Mapper 代理、分页、代码生成器 | 🔴 核心 |
| **Redis** | 缓存数据库，五种数据结构、缓存策略、分布式锁、过期与淘汰 | 🔴 核心 |

### 1.2 前端基础（后端工程师必备）

| 技术 | 说明 | 掌握程度 |
|------|------|:---:|
| **HTML / CSS** | 页面结构与样式基础 | 能看懂、能简单修改 |
| **JavaScript** | 前端交互逻辑 | 基础语法掌握 |
| **Vue** | 前端框架 | 能配合后端完成前后端联调 |

### 1.3 运维与工具

| 技术 | 说明 | 掌握程度 |
|------|------|:---:|
| **Linux** | 服务器操作系统，常用命令、日志查看、进程管理、Shell 脚本 | 🔴 熟练操作 |
| **Docker** | 容器化技术，镜像构建、容器运行、Docker Compose 编排 | 🟡 默认掌握 |
| **Git** | 版本控制，分支管理、冲突解决、团队协作 | 🔴 熟练使用 |
| **Maven / Gradle** | 项目构建与依赖管理 | 🔴 熟练使用 |

## 二、进阶扩展（有条件后进阶）

以下技术在具备当前必学基础后逐步深入，用于提升架构能力和竞争力。

| 技术方向 | 具体内容 | 适用场景 |
|---------|---------|---------|
| **微服务分布式** | Spring Cloud Alibaba（Nacos / Sentinel / Gateway / OpenFeign / Seata）、分布式事务、分布式锁 | 中大型项目拆分为多个独立服务 |
| **消息队列** | RabbitMQ / Kafka / RocketMQ | 异步解耦、流量削峰、最终一致性 |
| **高并发** | JUC 并发编程深度、线程池调优、缓存多级架构、限流熔断、读写分离 | 高流量系统（电商、秒杀、社交） |
| **大数据** | Hadoop / Spark / Flink 基础概念、数据仓库、OLAP | 数据密集型业务 |
| **AI 大模型应用** | 大模型 API 调用、RAG 检索增强、向量数据库、Prompt Engineering | AI 赋能传统业务系统 |
| **容器编排** | Kubernetes（Pod / Service / Deployment / Ingress） | 大规模微服务部署与管理 |

## 四、已过时技术清单（无需学习）

以下技术曾在历史上流行，但目前已不推荐在新项目中学习和使用。

| 已过时技术 | 当年用途 | 为什么不再学 | 现代替代方案 |
|-----------|---------|-------------|-------------|
| **Struts** | MVC Web 框架 | 设计陈旧、漏洞频发、社区消亡 | Spring MVC / Spring Boot |
| **Hibernate** | 全自动 ORM | 过度封装、SQL 不可控、性能调优困难 | MyBatis / MyBatis-Plus / JPA（轻量使用） |
| **Spring MVC（单独学习）** | Web 开发框架 | 已被 Spring Boot 内嵌，无需单独配置 | Spring Boot 自动集成 |
| **jQuery** | DOM 操作与 AJAX | 原生 JS + Fetch API 已全面替代，前端框架（Vue/React）成为主流 | 原生 JavaScript / Vue / React |
| **Layui** | 前端 UI 框架 | 已停止更新，生态凋零 | Element Plus / Ant Design / Naive UI |
| **JSP** | 服务端页面渲染 | 前后端分离已成主流，JSP 维护成本高 | Vue / React（前后端分离）+ RESTful API |
| **Servlet（直接裸写）** | 底层 HTTP 处理 | Spring MVC 已完全封装，无需手动处理 | Spring Boot 内嵌容器 |

> **判断准则**：如果一个技术在 2018 年后没有活跃更新、中文社区鲜有讨论、主流招聘 JD 不再提及——大概率已过时，无需投入时间。

## 五、学习优先级总结

| 优先级 | 技术 | 行动建议 |
|:---:|------|---------|
| 🔴 第一优先 | Java 基础 + Spring Boot + MySQL + MyBatis + Redis | 立即开始，深度投入，达到独立开发水平 |
| 🔴 第一优先 | Git + Maven + Linux + Docker | 边学边用，工具类技能融入日常 |
| 🟡 第二优先 | 前端基础（HTML/CSS/JS/Vue） | 掌握到能联调程度，不过度深入 |
| ⚪ 第三优先 | 微服务 + 消息队列 + 高并发 + AI | 核心基础扎实后再扩展 |
| ❌ 不学 | Struts / Hibernate / JSP / jQuery / Layui | 完全不投入时间 |
