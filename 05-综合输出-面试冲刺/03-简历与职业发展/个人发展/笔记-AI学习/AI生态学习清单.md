# AI 生态学习清单

## 概述

> **定位**：Java 后端工程师 + AI 应用开发者。目标是将 AI 能力集成到业务系统中，而非从事大模型算法研究。

本文按优先级将 AI 生态中的学习内容分为三个层级：**必须学**（核心竞争力）、**了解即可**（加分项）、**完全不用学**（与方向无关），帮助合理分配学习精力。

---

## 一、必须学：核心竞争力层

面试必问、项目必写、工作必用。以下为优先级最高的核心技能。

### 1.1 大模型 API 调用

| 技能点 | 具体要求 |
|--------|---------|
| 平台接入 | 通义千问、阿里云百炼、DeepSeek、文心一言等主流平台 |
| 调用方式 | HTTP 接口调用、官方 SDK 使用 |
| 进阶能力 | 流式输出处理、请求重试机制、参数调优、异常处理 |

### 1.2 RAG 检索增强生成（重中之重）

> RAG 是当前 AI 应用开发的核心架构，必须能完整讲清流程并独立实现。

| 步骤 | 操作 | 关键点 |
|:--:|------|--------|
| 1 | 文档切分 | 选择合适的切分策略（按段落/按语义/固定长度） |
| 2 | 向量化 | 调用 Embedding 模型将文本片段转为向量 |
| 3 | 向量检索 | 在向量数据库中进行相似度搜索，召回相关片段 |
| 4 | 排序与筛选 | 对召回结果做相关性排序，截取 Top-K |
| 5 | Prompt 组装 | 将检索到的上下文拼入 Prompt 模板 |
| 6 | LLM 生成 | 调用大模型基于增强后的 Prompt 生成回答 |

### 1.3 向量数据库

| 技能点 | 具体要求 |
|--------|---------|
| 工具选型 | Milvus / FAISS / Chroma，熟练掌握其中一种即可 |
| 核心操作 | 数据存入、相似度检索、索引管理 |
| 业务结合 | 理解向量库在 RAG、推荐、搜索等场景中的定位 |

### 1.4 Prompt Engineering

| 技能点 | 具体要求 |
|--------|---------|
| 角色设定 | 设定 AI 的身份、专业领域、回答风格 |
| 上下文管理 | 有效传递背景信息，控制上下文窗口 |
| 格式约束 | 要求模型输出 JSON、Markdown、表格等结构化内容 |
| 质量控制 | 减少幻觉、提升稳定性、贴合业务场景 |

### 1.5 AI 产品基础逻辑

| 技能点 | 具体要求 |
|--------|---------|
| 对话记忆 | 多轮对话的上下文管理与历史消息存储 |
| 结构化输出 | 要求 LLM 返回 JSON 等结构化数据，用于后续业务流程 |
| Agent 思想 | 理解工具调用（Function Calling）的基本模式 |

## 二、了解即可：加分项层

学了对面试和项目有加分，但不学也不会影响拿到 Offer。

| 技能 | 了解程度 | 不建议做的事 |
|------|---------|-------------|
| LangChain / LlamaIndex | 知道用途和基本架构，能搭建 Demo | 深入源码级研究 |
| Embedding 模型 | 了解文本到向量的转换过程，会用即可 | 深究算法细节 |
| 开源大模型本地部署 | 了解 Qwen、Llama 系列，会用 Ollama 跑演示 | 投入大量时间做深度定制 |
| 基础多模态 | 了解图片理解、文生图的基本使用方式 | 深入底层模型结构 |

---

## 三、完全不用学：排除层

以下内容与 Java 后端 + AI 应用开发方向无关，投入时间产出比趋近于零。

### 3.1 大模型底层训练

| 无需学习 |
|---------|
| Transformer 架构手写推导 |
| 预训练（Pre-training） |
| 监督微调（SFT）、DPO、RLHF |
| 千亿参数模型微调、分布式训练 |

### 3.2 深度学习框架深入

| 无需学习 |
|---------|
| PyTorch / TensorFlow 源码级使用 |
| 算子开发、CUDA 优化 |

### 3.3 传统 NLP 算法

| 无需学习 |
|---------|
| RNN / LSTM / CRF 原理推导 |
| TF-IDF / Word2Vec 深入原理 |

### 3.4 AI 音视频/多模态底层

| 无需学习 |
|---------|
| 扩散模型（Diffusion Model）/ VAE 原理 |
| 语音合成（TTS）/ 语音识别（ASR）内部机制 |

### 3.5 AI 科研与数学

| 无需学习 |
|---------|
| AI 学术论文深入研读 |
| 复杂数学公式推导 |

> **判断准则**：工程应用定位，不是算法研究员。学"怎么用 AI 做业务系统"，不学"怎么造 AI 模型本身"。

## 四、三层能力模型总览

| 层级 | 内容 | 投入策略 |
|:----:|------|---------|
| 🔴 **必须学** | API 调用、RAG、向量数据库、Prompt、AI 产品逻辑 | 深度投入，达到独立开发水平 |
| 🟡 **了解即可** | LangChain、Embedding、本地部署、多模态 | 理解概念，能搭 Demo，不深挖 |
| ⚪ **不用学** | 模型训练、框架源码、传统 NLP、音视频底层、科研 | 完全不投入时间 |

## 五、目标能力画像

完成以上学习后，应达到以下状态——这也是企业招聘 AI 应用方向后端工程师的核心期待：

| # | 能力要求 |
|:--:|---------|
| 1 | 能用 Java（Spring Boot）搭建完整的后端服务 |
| 2 | 能对接主流大模型 API，处理流式输出与异常场景 |
| 3 | 能独立搭建 RAG 知识库系统 |
| 4 | 能设计稳定、规范的 AI 接口（RESTful API） |
| 5 | 能将 AI 功能嵌入实际业务项目中，形成完整闭环 |

> 掌握以上五大能力，即具备 AI 应用方向后端岗位的核心竞争力。
