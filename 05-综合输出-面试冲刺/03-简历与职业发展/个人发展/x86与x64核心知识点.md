# x86 与 x64 核心知识点

## 一、基础定义
1. x86
    - 全称：Intel 8086 架构，32位 处理器架构
    - 寻址能力：最大支持 4GB 内存
    - 别名：IA-32
    - 系统：Windows 32位、Linux i386
2. x64
    - 全称：x86-64，64位 处理器架构
    - 寻址能力：理论支持 16EB 内存，实际硬件限制 TB 级
    - 别名：AMD64（AMD 主导设计，Intel 兼容）
    - 系统：Windows 64位、Linux x86_64
 
## 二、核心底层区别（最关键）
1. 寄存器数量 & 位数
    x86（32位）
    - 通用寄存器：8个（EAX、EBX、ECX、EDX、ESI、EDI、EBP、ESP）
    - 寄存器宽度：32位
    x64（64位）
    - 通用寄存器：16个（RAX、RBX、RCX、RDX、RSI、RDI、RBP、RSP + R8~R15）
    - 寄存器宽度：64位
    - 兼容模式：可直接运行 x86 32位指令
2. 内存寻址能力
    - x86：32位地址总线 → 寻址范围 2^{32} = 4294967296\ \text{Byte} \approx 4\ \text{GB}
    - x64：64位地址总线 → 寻址范围 2^{64} = 18446744073709551616\ \text{Byte} \approx 16384\ \text{EB}
3. 调用约定
    x86
    - 常用：cdecl、stdcall
    - 传参：栈传递，寄存器少，频繁压栈出栈，性能差
    x64
    - Windows：Microsoft x64 Calling Convention
    - Linux：System V AMD64 ABI
    - 前 4~6 个参数用寄存器传递，剩余用栈，性能大幅提升
4. 指令集与性能
    - x86：指令少，寄存器少，内存访问频繁
    - x64：更多寄存器、SIMD 指令、更大寻址空间，多线程、大内存场景性能碾压
 
## 三、操作系统 & 软件兼容
1. 向下兼容
    - x64 CPU 可以跑 x86 系统和 32位软件
    - x86 CPU 不能跑 x64 系统和 64位软件
2. 进程寻址
    - 32位程序：最大 4GB 虚拟内存
    - 64位程序：虚拟内存空间极大，可使用大内存、大缓存
 
## 四、高频面试/考点
1. x86 为什么最大只能用 4GB 内存？
    32位地址总线，地址总数为 2^{32}，每个地址对应1字节，上限就是 4GB。
2. x64 为什么寄存器翻倍？
    减少内存访问，把更多变量放在寄存器里，减少CPU与内存的IO开销，提升运行效率。
3. 为什么现在全是 x64？
    - 软件越来越吃内存（Java、AI、数据库）
    - 多线程、并发场景需要更多寄存器
    - 32位 4GB 内存早已无法满足现代应用
4. x86-64 和 ARM64 的区别？
    - x86-64：复杂指令集 CISC，PC、服务器主流
    - ARM64：精简指令集 RISC，手机、平板、苹果M系列
 
## 五、一句话总结
- x86：32位、寄存器少、寻址4GB、栈传参、老架构、兼容旧软件
- x64：64位、寄存器翻倍、超大内存寻址、寄存器传参、现代主流、性能更强
 
## 六、补充：日常区分
- 系统：此电脑 → 属性 → 系统类型（32位操作系统=x86，64位=x64）
- 软件：下载时 x86=32位包，x64=64位包
- 编程：C/C++/Java 编译时区分 32/64位，指针大小不同（x86指针4字节，x64指针8字节）
