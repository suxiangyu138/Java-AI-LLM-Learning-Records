## 1. 典型应用场景

### 1.1 四大黄金场景

| 场景 | 技术组合 | 说明 |
|------|---------|------|
| 企业知识库问答 | RAG + Embedding + 向量库 | 最高频场景 |
| 智能客服 | RAG + 工具调用 + 工单对接 | 降本增效 |
| 业务决策助手 | 结构化输出 + BI 集成 | 数据解读 |
| 文档智能处理 | 解析 + 抽取 + 分类 | 流程自动化 |

### 1.2 场景架构示例（知识库问答）

```
企业知识库问答架构：
  Web 前端（聊天界面）
    → Spring Boot（ChatClient + Advisor）
      → RAG：Embedding → Milvus/ES 检索
      → LLM：通义千问/DeepSeek
    → 权限：部门文档过滤（元数据）
    → 审计：全调用日志

⚠️ 面试必答：
"知识库问答 = RAG 标准架构——
 文档入库（ETL）+ 检索增强 + 权限过滤
 （部门级文档隔离）+ 审计。"
```

## 3. 实战避坑清单

```
⚠️ 七大避坑（2026 实战共识）：
  ① 不迷信"一个通用大模型解决所有问题"
     → 模块化：不同环节用不同模型/工具
  ② Prompt 有天花板（20-30%）
     → 架构（RAG/Agent）提升 3-5 倍
  ③ RAG 不是终点
     → 业务复杂升级 Agentic RAG
  ④ 先 PoC 验证业务价值再建平台
  ⑤ 人工接管设计成产品能力（不是故障兜底）
  ⑥ RAG 效果差先查文档质量（不是模型/Prompt）
  ⑦ 框架选型先看 JDK 版本和技术栈约束

⚠️ 面试必答：
"'先架构后 Prompt、先文档后调参、
 先 PoC 后平台'——三个先后的顺序
 是 Java AI 落地的实战经验。"
```

## 4. Java AI 面试题精选

**Q1: Java 在 AI 时代的定位？**
```
Java 不做模型训练、做 AI 工程化落地——
LLM 接入/RAG/Agent/MCP 全部在 Spring 生态内完成；
Python 验证、Java 落地是行业共识。
```

**Q2: 三大框架怎么选？**
```
Spring Boot 团队 → Spring AI（零摩擦 + MCP 完整）
框架中立/生态广 → LangChain4j（@AiService 声明式）
Java 8 遗留 → Solon AI（唯一支持）
```

**Q3: RAG 的原理和流程？**
```
检索增强生成——离线 ETL（解析/分块/向量化/入库）
+ 在线检索（向量化 → TopK → 拼 Prompt → 生成）；
检索质量决定回答质量。
```

**Q4: RAG 效果不好怎么排查？**
```
① 文档质量（第一责任人）
② 分块策略（大小/重叠）
③ 检索参数（TopK/阈值/过滤）
④ 查询改写/混合检索/Rerank
⑤ 升级 Agentic RAG
```

**Q5: 什么是 MCP？对 Java 的意义？**
```
模型上下文协议（AI 的 USB-C）——
统一模型连接外部工具/数据的标准；
Java 把现有服务封装成 MCP Server，
权限/审计在 Java 层做、任意模型可调用。
```

**Q6: Agent 三种模式？**
```
ReAct（80%，边想边做）、
Plan-and-Execute（15%，先计划后执行）、
Multi-Agent（5%，多角色协作）；
复杂度渐进，能简单不复杂。
```

**Q7: 怎么防 Prompt 注入？**
```
输入过滤 + 工具权限最小化（核心防线）+
输出过滤 + 高危操作人工接管；
权限最小化比输入过滤更重要（注入成功也做不了坏事）。
```

**Q8: 工具调用怎么保证安全？**
```
工具鉴权 + 参数校验 + 幂等（LLM 会重试）+
审计日志 + 高危人工确认；
资金类工具必须幂等（Redis 幂等键）。
```

**Q9: LLM 调用怎么保证可靠性？**
```
重试（指数退避）+ 熔断（Resilience4j）+
模型降级（旗舰 → 小模型）+ 预设兜底；
LLM 是外部依赖，按外部依赖治理。
```

**Q10: AI 应用怎么控制成本？**
```
模型路由（简单任务小模型）+ 精简 Prompt +
历史摘要压缩 + RAG 精选 + 缓存；
推理模型成本高 3-10 倍需异步化。
```

**Q11: AI 应用的可观测性？**
```
常规指标（延迟/错误）+ AI 专属
（Token/成本/幻觉率/用户反馈）；
三段链路（HTTP/LLM/Tool）埋点，
定位慢在哪、错在哪、钱花在哪。
```

**Q12: 金融场景 AI 怎么合规？**
```
PII 脱敏（进 Prompt 前）+ 投资建议拦截 +
全调用审计 + 私有化部署（模型/向量库内网，
数据不出域）+ 高危人工接管。
```

> 🎯 **核心要点**：落地体系 = **四大场景**（知识库/客服/决策/文档）+ **头部实践**（私有化金融、公有云电商）+ **七大避坑**（先架构后 Prompt、先文档后调参、先 PoC 后平台）+ **面试十二问**（定位/选型/RAG/注入/可靠性/成本是最高频）。Java AI 技术栈 = Spring 生态 + LLM + RAG + 工具 MCP + Agent + 工程化——**模型只是引擎，工程才是价值**。
