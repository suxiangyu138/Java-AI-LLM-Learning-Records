## 1. 自测规则说明

自测不是笔试，是**口试模拟**：每道题限时 60 秒，**对着镜子或录音说**，不许心里默念——说出口和想明白是两回事。评分三档：**A 档**（60 秒内要点完整、结构清晰）、**B 档**（能说出大部分要点但卡壳或漏点）、**C 档**（说不出来或错误）。**C 档题是回炉重点，B 档题是背诵重点**，A 档题过一遍即可。全程约 30-40 分钟，建议模拟面试时段（上午或面试前）完成。

自测的进阶用法是**乱序混测**：按模块顺序自测容易"顺着记忆走"，打乱顺序（比如按 05-03-08-01 抽题）才能暴露真实掌握度——面试官可不会按你的笔记顺序提问。也可以请同伴/录音回放抽查：听自己 60 秒的回答，找"嗯…那个…"卡壳点，卡壳处就是背诵最薄弱处，标 C 档回炉。每轮自测后把 C 档题记录成一张"回炉卡"（题目 + 薄弱原因 + 回炉日期），三天后再测一遍同一批题——**回炉后的复测才是自测闭环的最后一环**。

## 3. 四档答题模板

不同提问方式套不同模板，60 秒内把结构说满：

| 提问类型 | 识别特征 | 模板 | 时长分配 |
|----------|----------|------|----------|
| 基础概念 | "讲讲/是什么" | 定义 → 一句话原理 → 一个反例 | 定义 20s / 原理 25s / 反例 15s |
| 原理深挖 | "为什么/底层怎么实现" | 现象 → 机制 → 设计权衡（为什么这样设计） | 现象 10s / 机制 35s / 权衡 15s |
| 工程实践 | "遇到过吗/怎么排查" | 我遇到过 → 怎么定位 → 怎么修 → 怎么防（四段式） | 每段 15s |
| 架构设计 | "怎么设计/怎么选" | 需求分析 → 方案对比 → 选型理由 → 代价与兜底 | 分析 10s / 对比 25s / 选型 15s / 兜底 10s |

模板核心：**基础题给反例、原理题给权衡、工程题给故事、架构题给对比**——这四件事是"背答案"和"会答题"的分界线。练习方法：每道自测题先按模板说一遍，再倒着说一遍（先结论后展开），直到两遍都流畅。

## 4. 追问应对：答完怎么办

面试官追问的目的只有一个：**验证你是真懂还是背的**。三类高频追问与应对：

**"为什么"追问**（如"为什么树化阈值是 8"）：追问的答案往往在权衡里——泊松分布概率、空间与时间平衡、性能实测。应对：答题时主动留出"权衡钩子"（答完主动说"这里有个权衡……"），把追问抢答掉。

**"如果…会怎样"追问**（如"如果锁过期了业务没跑完"）：考察边界与异常意识。应对：先答主路径，再主动补边界（"主方案之外还有两个边界情况……"），覆盖异常就是加分。

**"换一个方案"追问**（如"不用 Redis 锁呢"）：考察知识广度与选型能力。应对：备好每个主方案的"竞争者清单"——数据库乐观锁、ZooKeeper 锁、本地锁，并说清各自适用场景。**答不出追问不可怕，可怕的是沉默**——先给思路（"如果让我设计，我会从……考虑"），再逐步展开。

## 5. 薄弱点定位与回炉清单

自测完成后按 C 档题统计薄弱模块，对照回炉：

| 薄弱模块 | 常见根因 | 回炉动作 |
|----------|----------|----------|
| 01 语法 | 细节记混 | 重读该模块 + 反例部分，做 5 道配套题 |
| 02 集合 | 源码流程没串成线 | 手动画 put/扩容流程图，对图复述 |
| 03 并发 | 概念堆叠没理解 | 画锁升级与线程池流程图，讲给同伴听 |
| 04 JVM | 区域与机制割裂 | 用对象生命周期串起内存区域与 GC |
| 05 MySQL | 原理与场景脱节 | 每个原理配一个真实慢 SQL 案例 |
| 06 Redis | 方案记混 | 三大问题与锁用对比记忆法（各自一句话场景） |
| 07 Spring | 生命周期记不住 | 用"出生-养-用-死"叙事法重背十二步 |
| 08 网络 | 时序记不住 | 手画三次握手四次挥手时序图 |
| 09 分布式 | 方案谱系混乱 | 按"强一致→最终一致"排序重背方案链 |

**回炉铁律：同一题连续两次 A 档才算出关**，否则继续循环——自测的意义不是测出分数，是测出回炉清单。

## 6. 七天复盘计划

| 天数 | 内容 | 验收 |
|------|------|------|
| Day 1 | 01 语法 + 02 集合 | 每篇读完做笔记，睡前口述 3 道自测题 |
| Day 2 | 03 并发 + 04 JVM | 画锁升级/GC 流程图，口述 6 道自测题 |
| Day 3 | 05 MySQL 全文 | 慢 SQL 分析一个真实案例 |
| Day 4 | 06 Redis 全文 | 三大问题与锁各写一个场景方案 |
| Day 5 | 07 Spring + 08 网络 | 生命周期十二步默写 + 握手挥手画图 |
| Day 6 | 09 分布式 + 10 自测题全刷 | 30 题口试一遍，标记 C 档 |

每天 2 小时，最后一天模拟一轮 30 分钟口试。**复盘节奏建议：每篇"读 40 分钟 + 说 20 分钟"**——说比读重要，输出倒逼输入。若时间不足，按"01→02→03→04"保命顺序优先，其余看剩余时间。

## 7. 毕业检查单
