## 1. 限时自测：30 题通关卷

自测方法：每题 60 秒内口述要点（先背结论 → 再讲原理 → 补充数据与边界），讲不全的题号记入薄弱点清单。**基础档（1-12 题，每题 30-60 秒）**：

1. 讲讲 Transformer 的注意力机制是怎么工作的？
2. 大模型的预训练、SFT、对齐三个阶段各解决什么问题？
3. 什么是 KV Cache？为什么长上下文推理贵？
4. MoE 是什么？为什么 2026 年千亿模型都用它？
5. 什么是幻觉？成因和缓解手段有哪些？
6. 提示词、RAG、微调怎么选型？
7. OpenAI 兼容协议和 Responses API 的关系？
8. 流式响应怎么实现？工具参数怎么跨块拼接？
9. Prompt Caching 的原理和工程纪律？
10. Function Calling 是什么？模型和代码怎么分工？
11. 工具调用循环怎么设计？怎么防死循环？
12. 工具结果为什么要当不可信输入？

**进阶档（13-22 题，每题 60-90 秒）**：

13. RAG 五步架构是什么？分块怎么分？
14. 召回后为什么要重排？TopK 取多少？
15. RAG 效果差怎么排查？三板斧是什么？
16. 长上下文时代 RAG 会消失吗？
17. 向量检索为什么快？HNSW 原理与参数？
18. 混合检索是什么？什么时候必须用？
19. Embedding 模型的使用铁律有哪些？
20. 工作流和 Agent 的边界是什么？怎么选？
21. 主流 Agent 范式有哪些？为什么别一上来就多 Agent？
22. MCP 是什么？和 Function Calling 什么关系？

**生产档（23-30 题，每题 60-90 秒）**：

23. LLM 应用怎么测试？传统测试为什么失效？
24. LLM-as-Judge 的三大偏见是什么？怎么缓解？
25. RAGAS 四指标是什么？为什么要拆两段评估？
26. Agent 为什么要"测路径不止测终点"？
27. Golden Set 怎么建？为什么每季度刷新？
28. 微调什么时候用？LoRA 原理与关键参数？
29. 为什么"先合并 LoRA 再量化"？
30. AI 应用的安全三防线是什么？

评分标准：基础档答不出 ≥ 2 题 → 回炉 01-04 篇；进阶档答不出 ≥ 2 题 → 回炉 05-07 篇；生产档答不出 ≥ 2 题 → 回炉 08-09 篇。全部 60 秒内答出 → 进入第 5 节准备故事素材。

## 2. AI 题答题模板：结论-原理-数据-反例

AI 题与基础题最大的不同是"工程颗粒度"——满分答案四件套：**结论**（一句话下判断：如"RAG 不会消失"）→ **原理**（机制一句话：如"检索保证找得准，窗口只保证装得下"）→ **数据**（一个量化支撑：如"1M 上下文也装不下亿级知识库，且成本线性涨"）→ **反例/边界**（一个反例或边界条件：如"单文档问答确实直接用长上下文更简单"）。四件套缺一即扣档：只答结论是"背概念"档，答到原理是"及格"档，补上数据是"良好"档，数据加反例是"优秀"档——2026 年面试官对 AI 题的判断标准就是"有没有工程直觉"，数据与反例正是工程直觉的外显。

套用示范："MCP 和 Function Calling 什么关系？"——结论（分层互补不替代）→ 原理（FC 管意图表达、MCP 管传输治理）→ 数据（MCP 9700 万月下载、18000+ 服务器，FC 是模型层协议）→ 反例（说"MCP 取代 FC"是错的，模型输出意图还是要 FC 协议表达）。

## 3. 追问应对：三类必杀追问

AI 题的追问总是顺着你的结论往下挖，三类高频：**① 深挖机制型**（"HNSW 为什么快""LoRA 为什么有效"）——用"原理一句话 + 一个类比"顶住：HNSW 像"地图先到城市再到街道"，LoRA 像"在成品上贴补丁而不是重造"。**② 追问数据型**（"量化损失多少""缓存省多少"）——背过就答数据，没背过答区间与量级（"4bit 领域场景损失 1-3 个点""组合缓存降 50-90%"），绝不编造精确值。**③ 场景迁移型**（"换一个场景你会怎么做"）——用决策树迁移：先归因类型（知识/行为/流程），再套对应方案，最后补一句"还要考虑 XX 边界"——这个"边界意识"是面试官最想听的。应对铁律：**答不上来就说"这个我记不清准确值，但原理上是……"然后讲原理**——AI 面试官接受"讲原理"远多于接受"沉默"。

## 4. 高频错误说法 vs 正确说法

面试官最敏感的是"背了半吊子概念"——把 2026 年常见的错误说法与正确说法对照背一遍，答错时自己就能察觉：

| # | 错误说法（扣分） | 正确说法（加分） |
|---|-----------------|------------------|
| 1 | "上下文大了 RAG 没用了" | 窗口解决装得下，不解决找得准与付得起，两者互补 |
| 2 | "MCP 会取代 Function Calling" | 分层互补：FC 管意图表达、MCP 管传输治理 |
| 3 | "多 Agent 最先进，什么场景都该用" | 90% 场景单 Agent 加工具够，多 Agent 最后选 |
| 4 | "微调能给模型补知识" | 微调学行为不学知识，知识靠训练数据与 RAG |
| 5 | "Prompt Caching 是供应商自动的" | 前缀字节级稳定才命中，工具排序一变就全 miss |
| 6 | "模型输出可以信任，直接用" | 模型输出与工具返回都当不可信输入，三层校验 |
| 7 | "Agent 答对就验收通过" | 测路径不止测终点，轨迹快照与不变量断言 |
| 8 | "量化直接上，无损" | 校准集必须同分布，量化后 holdout 回归测试 |
| 9 | "换了 Embedding 模型直接生效" | 向量空间变了，必须全量重索引 |
| 10 | "LLM 评估用 BLEU/ROUGE 就够了" | 语义评估靠 Judge + 确定性检查 + 人工抽样三层 |

记忆方法：这 10 条就是每篇"核心要点"的反面——把错误说法当"判断题"，能一眼指出错在哪，说明那篇的原理真的懂了；说不清错在哪的条目，对应模块就是回炉目标。

## 5. 薄弱点清单与回炉路线

自测后的回炉按"模块优先级 × 场景命中率"排序：**第一优先**（必问且必深挖）：04 函数调用循环、05 RAG 排查三板斧、07 工作流-vs-Agent 与 MCP——这三个是 2026 年 AI 面试命中率最高的深度题，务必练到"追问任意一层都能接"；**第二优先**（必问但可浅）：01 原理三连（Transformer/训练/KV Cache）、03 流式与缓存——背到能口述即可；**第三优先**（加分项）：08 微调部署、09 评估安全——答出"合并后量化""三偏见"这类细节即是亮点，答不全不致命。回炉方法不用重读全文：**只背每篇末尾的"核心要点"与"追问速查"**，然后找人对练或自问自答三次（第一次看稿、第二次半看、第三次脱稿）——AI 题是"说出来的"，不是"看会的"。

## 6. AI 技术亮点：带进阶段三的故事素材

阶段二的产出不只是知识，而是 **2-3 个能讲 10 分钟的深度主题**——阶段三讲项目时，这些就是你的技术弹药。挑选标准：① 你自测里答得最顺的模块；② 有真实或可构想的落地场景；③ 能串起"原理-实现-数据-权衡"完整故事。建议默认三选一：**RAG 知识库问答**（最好讲——五步架构 + 混合检索 + 评估门禁，故事线完整）；**Agent 客服**（最加分——工作流骨架 + Agent 节点 + 工具权限 + 防幻觉动作）；**Prompt Caching 优化**（最显功力——稳定前缀工程 + 命中率监控 + 成本数据 50-90%）。每个故事按四件套组织：背景问题 → 方案选型（为什么不是别方案）→ 实现要点（2-3 个技术细节）→ 结果数据（性能/成本/质量指标）——这就是阶段三项目描述的骨架，现在就把草稿写下来。

## 7. 考前 48 小时冲刺清单

考前两天只看高命中：**第一天**：背 04 函数调用循环 + 05 RAG 三板斧 + 07 工作流-vs-Agent 与 MCP（三篇"核心要点"），口述第 1 节的 1-12 题；**第二天上午**：背 03 Prompt Caching 纪律 + 09 评估三件套（三偏见/四指标/三防线），口述 13-30 题；**第二天下午**：过一遍"追问速查"里标记的 18 条必背（每篇 3 条），并把你选好的技术亮点故事讲两遍；**考前 2 小时**：只读 00 总览的"核心概念速查"表——30 秒一个模块快速唤醒。冲刺纪律：**宁可少背一个方案，也要把每篇末尾的"核心要点"背透**——那是面试官实际会听到的部分。

> 🎯 **核心要点**：阶段二的检验标准不是"看过多少"，而是"能讲出多少"——30 题限时自测找出薄弱模块，四件套模板统一答题姿势，18 条追问速查守住深挖关。带着"2-3 个能讲 10 分钟的 AI 故事"进入阶段三，你的差异化优势就落地了。
