## 1. 大模型的三层心智：参数-上下文-能力

面试官问"什么是大模型"，30 秒答案三层递进：**规模层**（百亿到万亿参数的神经网络，2026 年 DeepSeek V4-Pro 达 1.6 万亿总参数）、**训练层**（海量文本上预测下一个词，学到的是统计规律而非检索）、**能力层**（涌现出理解、生成、推理、工具调用等能力）。追问常是"参数和智能的关系"——参数决定知识容量与能力上限，但能力发挥依赖训练范式与上下文工程，不是参数越大越好，2026 年的务实路线是"同样的架构靠后训练与 Agent 工程提升真实任务能力"（DeepSeek V4-Flash 0731 不换架构、纯后训练，Agent 能力反超 Pro 预览版即是例证）。

## 2. Transformer 与注意力机制

一句话背熟：**Transformer 是"全位置对全位置的注意力 + 前馈网络"的堆叠，注意力是它唯一的'内容交互'机制**。自注意力三步：每个 token 通过线性变换生成 Q（查询）、K（键）、V（值）；用 Q 与所有 K 点积得到注意力分数，除以 √d 缩放（防 softmax 饱和）；softmax 归一化后加权求和 V，得到融合了全局上下文的新表示。多头注意力（MHA）把 Q/K/V 切成多份并行计算，让每个头关注不同关系（语法、指代、语义），再拼接合并。

面试加分点：注意力权重是"软检索"——它和后面 RAG 的"硬检索"形成对照；缩放因子 √d 的原因（维度大时点积方差大，softmax 梯度消失）；2026 年长上下文靠稀疏注意力破局（DeepSeek V4 的 DSA 动态压缩注意力，把百万级上下文的算力与显存开销大幅压低）。追问"为什么需要位置编码"——注意力本身没有顺序概念，必须注入位置信息（RoPE 旋转位置编码是 2026 事实标准，外推性好）。

## 3. 三步训练范式：预训练-SFT-对齐

训练主线三步，每一问对应一个训练阶段：**预训练**（海量文本自监督预测下一个词，得到"知识底座"，成本最高）；**SFT 监督微调**（用人工标注的"提问-优质回答"对齐格式，学会听话）；**对齐阶段**（RLHF 人类反馈强化学习，2026 年主流是 DPO 直接偏好优化与 GRPO——GRPO 不需要单独的价值模型，DeepSeek 系列是其代表作，成本与稳定性全面优于经典 PPO）。追问常是"三个阶段各解决了什么"——预训练解决"会不会"、SFT 解决"听不听话"、对齐解决"价值观与偏好"，缺一不可。

2026 加分视角：**后训练（SFT+对齐）是模型能力的倍增器**——DeepSeek V4-Flash 正式版与预览版结构参数完全相同，仅重做后训练，Agent 能力从落后变为全面反超，验证了"架构定上限、后训练定下限"的工程路线；推理模型（reasoning model）的"先想后答"（CoT 思维链）也是后训练出来的，不是架构突变。

## 4. MoE 稀疏专家架构

2026 年千亿级模型的事实标准是 **MoE（混合专家）**：把 Transformer 的前馈层换成 N 个"专家"子网络，每个 token 只激活其中 K 个专家。收益一句话：**总参数大（知识容量）而激活参数小（计算便宜）**——DeepSeek V4-Pro 总参数 1.6 万亿、每次推理只激活 64 个专家（约 49B 激活参数）；V4-Flash 总 2840 亿、激活仅 130 亿，专为高频低成本场景设计。对比传统 Dense 模型（所有参数全激活）的"总参=激活参"，MoE 用路由网络（router）决定 token 去哪个专家，训练时加负载均衡损失防"专家贫富分化"。

追问链：MoE 的缺点——显存占用仍按总参数算（推理部署成本高），路由存在专家坍缩风险；为什么小模型不用 MoE——专家分片对通信要求高，小模型收益不划算；Dense 与 MoE 怎么选——追求单 token 成本低、并发高的在线服务选 MoE，追求部署简单选 Dense。

## 5. 推理原理：自回归与 KV Cache

生成是**自回归**：逐 token 生成，把已生成的内容拼回输入再预测下一个。由此引出两个必考点：**采样参数**（temperature 控制随机性、top_p 截断低概率、max_tokens 限制长度、seed 可复现）；**KV Cache**——每个新 token 的注意力都要重算历史 token 的 K/V，把历史 K/V 缓存下来避免重复计算，是推理速度与显存的核心矛盾：**上下文越长，KV Cache 越大，长上下文推理的显存成本按长度线性增长**（70B 模型 128K 上下文时 KV 可达百 GB 级）。

2026 加分点：vLLM 的 PagedAttention 把 KV Cache 切成块管理（像操作系统的虚拟内存分页），显存浪费减少 30% 以上、吞吐提升 2-3 倍；推理模型会先输出"思考过程"再输出答案，思考 token 也占用 KV，这就是推理模型贵的原因之一；DSpark 推测解码（2026 年 DeepSeek 发布）用小模型猜多个 token 再大模型验证，推理速度最高提升 85%。

## 6. 上下文窗口与 Token 经济

上下文窗口决定"一次能看多少内容"，2026 年已进入百万级时代（DeepSeek V4 全系 1M、Claude 5 系与 GPT-5.x 均支持长上下文）。三个必懂的点：**Token 不是字**（中文约 1 字 ≈ 1-2 token，1M 上下文 ≈ 80-100 万字中文，按 token 计费）；**长上下文 ≠ 全用得好**（模型对中间位置内容记忆衰减，即"lost in the middle"，关键内容放开头结尾）；**上下文是成本与延迟的放大器**（每次请求把全部上下文送给模型，Prompt Caching 正是为此而生，见 03 篇）。

面试角度：上下文窗口越来越大，RAG 是否过时是 2026 年高频争议题——答案是否定的：1M 上下文解决"能否装下"，但解决不了"检索精度与成本"——文档库 10 亿 token 时塞不下、塞得下也贵、检索精确信息仍然要 RAG（详见 05 篇）。

## 7. 2026 模型全景速览

面试官会问"你平时用什么模型"——答不上版本是硬伤。2026-08 基准：**DeepSeek V4 系列**（国产开源旗舰：Pro 1.6T MoE 与 Flash 284B/13B 激活双版本，1M 上下文，Agentic Coding 开源榜第一，原生支持 OpenAI Responses API，兼容 Claude Code 等 Agent 框架）；**Claude 5 家族**（Anthropic，MCP 协议发起方，长上下文与工具调用标杆）；**GPT-5.x**（OpenAI，引入 tool_search 工具发现）；**Qwen 系列**（阿里开源生态，Qwen3-VL 等多模态）。选型逻辑一句话：**闭源看质量与生态，开源看可控与成本；Agent 场景看工具调用与协议兼容，推理任务看 reasoning 能力**。

### 追问速查

挑 3 条背熟：缩放因子为什么 √d（点积方差随维度增大，softmax 饱和）；DeepSeek V4 三创新（DSA 稀疏注意力 / Engram 记忆模块降幻觉 / mHC 稳定训练）；MoE 激活参数怎么算（总参 1.6T ÷ 激活 49B，路由决定）。

> 🎯 **核心要点**：原理题满分答案 = 一句话机制 + 一个数据 + 一个工程落点。如 KV Cache："缓存历史键值避免重算（机制）→ 显存随上下文线性涨（数据：128K 下百 GB 级）→ 所以 vLLM 用分页管理、Agent 要管上下文（落点）"。背熟这个结构，原理关必过。
