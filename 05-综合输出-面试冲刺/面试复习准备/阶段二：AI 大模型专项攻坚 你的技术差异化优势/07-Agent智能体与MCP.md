## 1. Agent 是什么：模型+工具+循环

Agent 一句话定义：**以 LLM 为决策大脑，自主规划、调用工具、观察结果、迭代执行直到完成任务的系统**。三个组成缺一不可：**模型**（决策中枢——选什么模型决定能力上限与成本）；**工具**（手脚——通过 Function Calling/MCP 接 API、数据库、文件系统）；**循环**（决策-执行-观察的迭代，是 Agent 与单次 API 调用的本质区别）。核心心智：**Agent 的智能不是模型的，是"模型 + 上下文 + 工具 + 循环"系统的**——同样一个模型，配上好的工具与循环工程，完成任务能力天差地别（DeepSeek V4-Flash 不换架构纯靠后训练与 Harness 工程 Agent 能力大涨即是例证）。追问"单次调用和 Agent 什么区别"——单次是"问一次答一次"，Agent 是多轮"计划→执行→观察→再计划"的闭环，有状态、有目标、有退出条件。

## 2. 工作流 vs Agent：边界与选型

2026 年最高频的概念辨析题，一句话边界：**工作流是预先编排好的固定步骤，Agent 是模型自主决定步骤**。工作流（workflow）：步骤固定、可控、可预期、便宜——适合稳定业务（固定流程审批、模板化报表）；Agent：步骤动态、灵活、能应对意外——适合开放任务（自由咨询、多工具组合排查）。选型决策树：**流程确定、输入格式稳定 → 工作流；任务开放、工具多、需要多轮决策 → Agent；混合形态是 2026 主流 → 工作流骨架 + Agent 节点**（比如客服系统：意图识别用固定路由，复杂工单进 Agent 处理）。面试官爱问"为什么不用 Agent 解决一切"——答三个代价：**成本**（多轮调用 token 累积）、**不可控**（模型自主步骤可能跑偏，必须有护栏）、**延迟与失败**（每轮一次 API 调用，失败点增多）——"确定性用工作流、不确定性用 Agent"是 2026 年生产共识。

## 3. 主流范式：ReAct-规划-反思-多Agent

四大范式一句话各背一句：**ReAct**（Reasoning + Acting 交替——"想一步、做一步、看结果、再想"，最经典、最通用，适合工具调用类 Agent）；**Plan-and-Execute**（先整体规划任务清单，再逐项执行——长任务省 token 省轮次，但计划错了难中途修正，2026 年主流生产范式之一）；**反思 Reflective**（执行后自我批判再重做——提高质量但多花一轮成本，适合写作、代码审查类）；**多 Agent**（多个角色 Agent 协作：Planner-执行者-审查者，或主管-子 Agent——各司其职效果好，但编排复杂、成本翻倍、调试难，2026 年落地趋势是"能不拆就不拆"，单 Agent + 工具优先）。答题姿势：先给范式谱系，再给选型——**90% 的业务场景一个 ReAct/规划型 Agent 加好工具就够了，多 Agent 是最后的选择**，这个"反直觉的克制"反而最加分。

## 4. Agent 循环工程：上下文与终止

Agent 生产化的核心工程，三件事：**上下文管理**——每轮把全部历史发给模型，长会话 token 爆炸，2026 年三件套：窗口裁剪（只保留最近 N 轮）、摘要压缩（旧历史总结成一段，显式触发不静默做）、关键信息外置（状态与中间结果写外部存储，不占上下文）；**终止条件**——正常出口（任务完成声明）+ 强制上限（轮数 8-12、时间、token 预算）双保险，防死循环挂死；**失败处理**——工具错误转回传让模型自行调整（见 04 篇）、重试与回退（降级为固定工作流或人工兜底）、全程留痕（每轮的决策、工具、结果都要可追溯，这是评估与排障的基础）。追问"Agent 怎么防跑偏"——工具权限最小化 + 关键动作二次确认（退款、删除类）+ 输出护栏（敏感动作触发人工审批）——2026 年企业 Agent 落地最看重的就是"可控"。

## 5. MCP 协议：AI 的 USB-C 接口

MCP（Model Context Protocol）一句话：**AI 应用与外部工具/数据源之间的标准化接入协议，让 Agent 接入任何 MCP Server 的工具像插 USB-C 一样即插即用**。2026 年已是事实标准：Anthropic 发起、捐赠给 Linux 基金会（OpenAI/Google/Microsoft/AWS 全加入），**月 SDK 下载量 9700 万、社区服务器 18000+**，写进企业 RFP 的正式要求。架构三要素：**MCP Client**（AI 应用侧）、**MCP Server**（工具提供侧，暴露 tools/resources/prompts 三类能力）、**传输**（stdio 本地进程、Streamable HTTP——2025 年 3 月统一双端点为单 /mcp 端点，可像 REST 一样负载均衡、无需粘滞会话，2026 年企业部署标准）。价值一句话：**从"每个 Agent 对接每个系统写一套集成"变成"一次实现、处处复用"**——集成成本降 90%、开发时间最多省 30%。

## 6. MCP vs Function Calling vs A2A

2026 年协议分层题，三层各管一段：**Function Calling（模型层）**——模型输出调用意图的协议能力，管"怎么表达"；**MCP（工具层）**——工具接入与治理的标准化，管"接什么、怎么发现、怎么鉴权"（2026 年分层事实标准，两者是互补不是替代：FC 管意图表达、MCP 管传输治理，企业 120 个 REST 服务映射 MCP 工具 + 模型 FC 调用是标准组合）；**A2A（Agent 层）**——Agent 之间的协作协议（任务委托、结果交换，150+ 组织参与，Linux 基金会），管"Agent 怎么互相找、怎么分工"。三层记忆法：**模型→工具→Agent 纵向三层，FC/MCP/A2A 各管一层**。追问"MCP 的安全问题"——2026 年研究显示 2614 个 MCP 实现中 82% 存在路径遍历漏洞、67% 暴露代码注入面——所以 Agent 权限最小化、非人类身份（NHI）治理、策略即代码是 2026 企业标配话题。

## 7. Agent 生产实践：评估-安全-可观测

Agent 上生产的三大支柱：**评估**——单轮问答的指标不够，要测"路径"不只测"终点"：轨迹快照测试（固定输入断言工具调用序列）、不变量断言（没调用禁用工具、没跳过审批）、任务级评分（整个任务的完成度与路径合理性）；**安全**——提示注入（工具返回内容夹带指令）、越权（Agent 权限永远小于背后 API 权限）、幻觉动作（模型误触发有副作用的工具——关键动作加确认）三防线；**可观测**——OpenTelemetry GenAI 语义约定打 span（模型、token、成本、工具调用），LangSmith/Langfuse 做全链路 trace，结构化 JSONL 日志是"飞行记录仪"。2026 加分词汇：**AgentDevOps**（Agent 也走 CI/CD：提示词与工具版本化、金丝雀发布、混沌测试）、**AI SRE**（Agent 故障定位与根因分析成为新工种）。面试一句话：**"Agent 上线不是模型的胜利，是评估、安全、可观测三件套的胜利"**。
