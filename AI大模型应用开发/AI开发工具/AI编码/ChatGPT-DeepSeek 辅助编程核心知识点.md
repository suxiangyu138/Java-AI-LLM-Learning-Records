# ChatGPT / DeepSeek 辅助编程 核心知识点

## 一、概述

ChatGPT（OpenAI）和 DeepSeek 是通用大语言模型（LLM），虽非专用编程工具，但在 **代码审查、复杂逻辑推演、架构设计、Bug 调试** 等场景有不可替代的价值。2026 年，它们与 IDE 内嵌 AI 工具（Copilot/通义灵码）形成互补关系。

**核心定位：** 编程中的"高级顾问"——不是实时补全代码的工具，而是解决复杂问题的参谋。

## 二、与 IDE 内嵌 AI 的分工

| 场景 | IDE 内嵌 AI（Copilot 等） | 通用 LLM（ChatGPT/DeepSeek） |
|------|---------------------------|------------------------------|
| 代码补全 | **擅长**（行内实时补全） | 不适用（需手动粘贴） |
| 简单方法生成 | **擅长** | 一般 |
| 复杂业务逻辑设计 | 一般 | **擅长**（多轮讨论） |
| 架构方案评估 | 不适用 | **擅长** |
| Bug 根因分析 | 一般 | **擅长** |
| 跨文件重构方案 | 不适用 | **擅长** |
| 新技术选型建议 | 不适用 | **擅长** |

## 三、核心编程场景

### 3.1 代码审查与优化

```
Prompt 示例：
"请审查以下 Java 代码，关注线程安全、性能、异常处理三个维度，
给出问题和修改建议：\n[粘贴代码]"
```

审查维度建议：线程安全 > 空指针风险 > 资源泄露 > SQL 注入 > 性能隐患

### 3.2 复杂算法与业务逻辑

```
Prompt 示例：
"我们需要实现一个订单超时取消功能：
- 订单创建后 30 分钟未支付自动取消
- 需支持 10w+ 并发订单
- 取消后需恢复库存
请给出方案对比（延迟队列 vs Redis 过期回调 vs 定时扫表），并推荐最佳方案"
```

### 3.3 Bug 调试

```
Prompt 示例：
"Spring Boot 应用间歇性出现 OutOfMemoryError，以下是堆栈信息：
[粘贴堆栈]
当前：JVM -Xmx2g, 使用 Spring Data JPA
请分析可能的原因和排查步骤"
```

### 3.4 技术方案与选型

```
Prompt 示例：
"Java 后端集成大模型能力，LangChain4j vs Spring AI 怎么选？
考虑：团队 Spring 经验丰富、需要 Agent 多步推理、需要私有化部署"
```

## 四、ChatGPT vs DeepSeek 对比

## 五、高效使用技巧

### 5.1 提示词（Prompt）技巧

| 原则 | 示例 |
|------|------|
| **设定角色** | "你是一位资深 Java 架构师，10 年微服务经验..." |
| **明确约束** | "请使用 Java 17、Spring Boot 3.x、不引入第三方库" |
| **分步要求** | "先分析问题，再给出方案对比，最后给出推荐代码" |
| **提供上下文** | "当前项目使用 MyBatis-Plus，Java 17，MySQL 8.0" |

### 5.2 上下文工程

- **粘贴关键代码**：不是整个文件，而是相关方法 + 类签名
- **说明数据库表结构**：贴 CREATE TABLE 语句
- **给出接口定义**：说明入参、出参、异常

### 5.3 结果验证流程

```
AI 生成代码 → 人工审查（安全/性能/空指针）
     ↓
粘贴入 IDE → 修复编译错误 → 运行单元测试
     ↓
补充边界测试 → 集成测试 → 合并
```

## 六、局限性

1. **训练数据截止日期**：不了解最新框架版本 API 变化
2. **幻觉风险**：可能编造不存在的 API 或依赖
3. **缺乏项目上下文**：不了解现有代码库的约定和架构
4. **数据安全**：不要粘贴生产环境密钥、真实用户数据
5. **需手动操作**：复制粘贴，效率低于 IDE 内置 AI

## 七、工作流建议

```
日常编码（90%）
  → 使用 Copilot / 通义灵码（IDE 内实时补全）

复杂问题（10%）
  → 描述问题 + 贴关键代码到 ChatGPT / DeepSeek
  → 获得方案 + 代码骨架
  → 回到 IDE 手动实现核心逻辑
  → Copilot 辅助填充细节
```

## 八、总结

ChatGPT 和 DeepSeek 不是 IDE 内嵌 AI 的替代品，而是 **互补品**。它们的价值在于处理 Copilot 搞不定的复杂场景：架构设计、多方案权衡、疑难 Bug 排查。2026 年 DeepSeek 的 1M 长上下文和极低价格使其成为代码库级分析的强力工具。
