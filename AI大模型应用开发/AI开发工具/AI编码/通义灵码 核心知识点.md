# 通义灵码核心知识点

> **核心摘要**：通义灵码是阿里云推出的免费 AI 编程助手，基于通义大模型，针对中文开发场景深度优化。2026 年国内开发者的高性价比 AI 编程方案。

## 一、概述

通义灵码是阿里云推出的免费 AI 编程助手，基于通义大模型，针对中文开发场景深度优化。提供代码生成、补全、解释、注释生成、单元测试等能力，支持主流 IDE 集成。

**核心定位**：国内开发者友好的免费 AI 编程工具，中文理解与代码生成兼具。

## 二、核心能力

### 2.1 功能矩阵

| 功能 | 说明 |
|------|------|
| 行内代码补全 | 基于上下文的实时代码续写 |
| 代码生成 | 通过自然语言描述生成完整方法/类 |
| 代码解释 | 选中代码块，用中文解释逻辑 |
| 注释生成 | 自动为方法生成规范 Javadoc 注释 |
| 单元测试生成 | 选中方法，自动生成 JUnit 测试用例 |
| 代码翻译 | 不同编程语言间的代码转译 |
| 代码优化 | 识别代码异味并给出改进建议 |
| 代码审查 | 发现问题代码并给出修改建议 |

## 三、核心操作

### 3.1 行内补全

```java
// 输入注释，通义灵码自动生成后续代码
// 创建一个查询用户订单的方法，支持分页和状态过滤
// AI 自动生成 ↓
public Page<Order> queryUserOrders(Long userId, OrderStatus status, Pageable pageable) {
    return orderRepository.findByUserIdAndStatus(userId, status, pageable);
}
```

## 五、最佳实践

1. **写详细注释胜过简短描述**：注释越详细，生成质量越高
2. **项目上下文预热**：打开后先浏览几个关键文件，让其建立项目上下文
3. **与 Copilot 互补使用**：复杂业务逻辑用 Copilot，注释/文档/中文交互用通义灵码
4. **审查生成的测试用例**：AI 生成的测试覆盖正常路径多，建议补充边界和异常场景
