## 1. 阶段一：入门 —— 学会"指挥"AI（2-3周）

### 🎯 学习目标

- 能熟练调用至少 2 个主流大模型 API
- 掌握 Prompt Engineering 的核心技巧
- 能用 AI 辅助日常编码和调试

### 📚 学习内容

| 周次 | 主题 | 具体内容 | 实践任务 |
|------|------|---------|---------|
| **第1周** | API 调用入门 | 注册 OpenAI / 阿里云百炼 / DeepSeek 账号，获取 API Key；掌握 Chat Completion 接口 | 用 Python/Java 调用 API 实现一个命令行聊天机器人 |
| **第2周** | Prompt Engineering | 角色扮演、Few-Shot、CoT、结构化输出；学习 System Prompt 设计 | 设计 5 个不同场景的高质量 Prompt，对比效果 |
| **第3周** | AI 辅助开发 | 用 AI 调试代码、解释源码、写单元测试、生成文档 | 用 AI 修复 3 个真实 Bug，写 5 个单元测试 |

### 🔑 核心技能

```
✅ 能用 curl / Python / Java 调用大模型 API
✅ 理解 temperature、top_p、max_tokens 等参数的含义
✅ 能写出包含角色 + 任务 + 约束 + 格式的高质量 Prompt
✅ 能用 Few-Shot 和 CoT 提升复杂任务准确率
✅ 能用 AI 辅助代码 Debug、重构和文档生成
```

## 2. 阶段二：进阶 —— 搭建 RAG 应用（3-4周）

### 🎯 学习目标

- 理解 RAG 的完整技术链路
- 能独立搭建一个基于私有知识库的问答系统
- 掌握向量数据库的基本使用

### 📚 学习内容

| 周次 | 主题 | 具体内容 | 实践任务 |
|------|------|---------|---------|
| **第4周** | RAG 基础 | RAG 的原理；文档解析（PDF/Word/Markdown）；文本切分策略 | 解析 10 篇技术文档，切分成合理大小的 chunks |
| **第5周** | 向量化与检索 | Embedding 模型选型；向量数据库（Milvus/Chroma）搭建；语义检索 | 搭建 Chroma 向量库，导入上一步的 chunks |
| **第6周** | 检索优化 | 混合检索（语义+关键词）；Reranker 重排序；Query 重写 | 优化检索精度，对比优化前后的召回率 |
| **第7周** | 完整 RAG 应用 | LangChain/LlamaIndex 框架；流式输出；引用标注 | **项目：个人技术文档问答系统** |

### 🔑 核心技能

```
✅ 能独立完成文档解析 → 切分 → 向量化 → 检索 → 生成的全链路
✅ 能根据场景选择合适的切分策略（chunk_size/chunk_overlap）
✅ 能搭建和使用 Chroma/Milvus 向量数据库
✅ 能用 Reranker 优化检索结果
✅ 能用 LangChain 或 LlamaIndex 搭建完整的 RAG 应用
```

### 🏗️ 阶段项目：个人知识库问答系统

```markdown
需求：
1. 支持上传 PDF/Word/Markdown 文档
2. 自动解析、切分、向量化文档内容
3. 支持自然语言提问，返回带引用来源的答案
4. Web UI 界面（Gradio/Streamlit）

技术栈建议：
- 文档解析：PyMuPDF + python-docx
- 向量模型：BGE-M3（中文最佳）
- 向量数据库：Chroma（入门）/ Milvus（进阶）
- LLM：DeepSeek-V3（性价比）/ Qwen-Max（中文优化）
- Web 框架：Gradio（5 分钟出原型）/ FastAPI（生产级）
- 可选框架：LangChain / LlamaIndex
```

## 3. 阶段三：深入 —— 模型微调与 Agent（3-4周）

### 🎯 学习目标

- 理解 LoRA/QLoRA 微调原理并能实际操作
- 理解 Agent 的架构模式（ReAct / Plan-Execute）
- 能用 MCP 协议接入外部工具

### 📚 学习内容

| 周次 | 主题 | 具体内容 | 实践任务 |
|------|------|---------|---------|
| **第8周** | LoRA 微调 | LoRA 原理；数据准备；QLoRA 在消费级 GPU 上微调 | 用 500 条数据微调 Qwen-7B 的代码风格 |
| **第9周** | Agent 基础 | ReAct 模式；Function Calling；工具系统设计 | 实现一个能调用搜索引擎 + 计算器的 Agent |
| **第10周** | MCP 协议 | MCP Server/Client 开发；MCP 市场；工具标准化 | 开发一个 MCP Server 封装数据库操作 |
| **第11周** | 多 Agent 协作 | LangGraph 状态图；多 Agent 编排；A2A 协议 | **项目：多 Agent 协作的代码审查系统** |

### 🔑 核心技能

```
✅ 能准备微调数据集（格式转换、质量检查）
✅ 能用 QLoRA 在单张消费级 GPU 上微调 7B 模型
✅ 能实现 ReAct 模式的基础 Agent 循环
✅ 能设计 Function Calling 的 Tool Schema
✅ 能开发简单的 MCP Server 和 Client
✅ 能用 LangGraph 编排多 Agent 工作流
```

### 🏗️ 阶段项目：智能代码审查 Agent

```markdown
需求：
1. CodeAgent：分析用户提交的代码
2. ReviewAgent：审查代码质量和安全性
3. FixAgent：根据审查意见修复代码
4. 三个 Agent 通过 LangGraph 编排协作
5. 通过 MCP 协议接入 Git 仓库和 CI/CD 系统

技术栈建议：
- Agent 框架：LangGraph / CrewAI
- LLM：Qwen-7B（微调版）/ Claude Sonnet（API）
- MCP：自建 MCP Server 封装 Git 操作
- 向量库：存储历史代码审查记录
```

## 4. 阶段四：工程化 —— 部署与运维（3-4周）

### 🎯 学习目标

- 能用 Docker + K8s 部署 AI 服务
- 能建立完善的监控和告警体系
- 能进行成本优化和安全防护

### 📚 学习内容

| 周次 | 主题 | 具体内容 | 实践任务 |
|------|------|---------|---------|
| **第12周** | 服务封装与部署 | FastAPI 封装；Docker 容器化；NVIDIA Container Toolkit | 将 RAG 应用打包成 Docker 镜像 |
| **第13周** | K8s 编排 | Deployment/Service/HPA 配置；GPU 节点调度；滚动更新 | 在 K8s 集群上部署 AI 服务（minikube 也可） |
| **第14周** | 监控体系 | Prometheus + Grafana；延迟/吞吐/Token 消耗监控；告警规则 | 搭建完整的 AI 服务 Dashboard |
| **第15-16周** | 优化与安全 | Prompt 注入防御；成本优化（缓存、路由、量化）；降级策略 | **最终项目：生产级 AI 服务部署** |

### 🔑 核心技能

```
✅ 能编写优化的 Dockerfile（多阶段构建、GPU 支持）
✅ 能编写 K8s 的 Deployment/Service/HPA 配置
✅ 能搭建 Prometheus + Grafana 监控 AI 服务的延迟、吞吐和 Token 消耗
✅ 能实施至少 3 层安全防护（注入检测、内容过滤、输出验证）
✅ 能通过模型路由和 Prompt 缓存将 API 成本降低 40%+
✅ 能设计多层降级方案（大模型 → 小模型 → 静态回复）
```

### 🏗️ 最终项目：生产级 AI 服务平台

```markdown
需求：
1. 统一 API 网关、支持多模型路由
2. Docker + K8s 部署、HPA 自动扩缩
3. Prometheus + Grafana 监控大盘
4. 成本追踪 + 每日费用上限告警
5. Prompt 缓存（Redis）、降低重复调用成本
6. 安全防护（注入检测 + 内容过滤 + 输出验证）
7. 多层降级（大模型 → 小模型 → 缓存 → 静态回复）
8. 流式输出（SSE）支持

技术栈：
- Web 框架：FastAPI
- 推理引擎：vLLM
- 容器编排：Docker + Kubernetes
- 监控：Prometheus + Grafana
- 缓存：Redis
- 消息队列：RabbitMQ（异步推理）
```

## 学习建议

> **重点**：学习大模型应用开发的关键是**实践驱动**，而非埋头啃理论。每个阶段的实战项目是整个学习路径中最重要的部分——知识是别人的，只有动手做过的才是自己的。

| 原则 | 说明 |
|------|------|
| **20% 理论 + 80% 实战** | 看完文档立刻动手，不要追求"完全理解再开始" |
| **先跑通再优化** | 第一个版本只要能跑就行，别追求完美 |
| **多模型对比** | 同一问题用不同模型测试，建立模型选型的直觉 |
| **记录踩坑** | 每次遇到的问题和解决方案都记录下来 |
| **拥抱 AI 辅助** | 用 AI 帮你写代码、解释概念、调试 Bug——这就是你在学的技术 |

## 核心要点回顾

- **12-16 周**的学习路径，分四个阶段：入门 → 进阶 → 深入 → 工程化
- 每个阶段都有明确的**学习目标、实战项目和检查点**
- **阶段二（RAG）的项目**是整条路径的核心——它串联了 API 调用、Prompt、向量检索等核心技能
- **微调是最后一招**，先用 Prompt + RAG 做到极致
- **工程化能力**是区分"会调 API"和"能落地"的关键分水岭
