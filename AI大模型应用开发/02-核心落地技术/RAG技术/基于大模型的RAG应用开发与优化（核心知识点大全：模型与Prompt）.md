## 一、RAG 应用中的大模型选型与适配

### 1.1 大模型分类

**按部署方式**：

| 类型 | 优势 | 劣势 | 适用场景 |
|------|------|------|----------|
| **公有云大模型** | 无需部署、迭代快 | 数据隐私风险、累计成本高 | 初创企业、快速验证 |
| **私有部署大模型** | 数据安全可控、无调用成本上限 | 需投入算力和维护 | 中大型企业、金融/医疗 |
| **混合部署** | 兼顾成本与隐私 | 架构较复杂 | 企业级 RAG 主流方案 |

**按能力等级**：

| 类型 | 代表 | 特点 |
|------|------|------|
| **基础大模型** | Llama 3 70B、GPT-4 | 通用能力强，部署成本高 |
| **轻量化大模型** | Llama 3 8B、Qwen 7B | 推理快、成本低、复杂推理略弱 |
| **微调大模型** | 基于基础模型微调 | 行业适配性强，企业核心优化方向 |

### 1.2 企业级选型核心指标（按优先级）

| 指标 | 说明 | 推荐标准 |
|------|------|----------|
| **上下文窗口长度** | 决定输入最大长度 | ≥ 128k |
| **推理速度** | 影响用户体验 | ≥ 50 Token/s |
| **事实性与准确性** | RAG 核心价值 | 幻觉率低 |
| **成本可控性** | API 调用或算力投入 | 按日均查询量测算 |
| **可扩展性** | 支持微调、插件扩展 | 对接数据库和检索引擎 |

### 1.3 模型适配技巧

| 场景 | 推荐方案 |
|------|----------|
| 敏感场景（内部知识库） | 私有部署轻量化模型 + 企业数据微调 |
| 高并发场景（电商客服） | 混合部署，普通查询用公有云 API |
| 低延迟场景（实时问答） | 轻量化模型（Llama 3 8B、Qwen 7B） |

## 二、Prompt 工程

### 2.1 核心原则

| 原则 | 说明 |
|------|------|
| **明确指令** | 清晰告知"要做什么、不做什么" |
| **上下文关联** | 检索结果与 Prompt 紧密关联 |
| **格式规范** | 统一输出格式（表格、要点） |
| **幻觉抑制** | 强制基于检索结果生成 |
| **角色赋能** | 赋予明确角色，贴合业务场景 |

### 2.2 RAG 专属 Prompt 结构（通用模板）

```
【角色】你是 XX 企业的知识库问答助手
【指令】1. 仅使用下方检索到的内容回答
        2. 回答简洁明了，分要点呈现
        3. 无相关信息时回复"暂无相关信息"
        4. 严禁编造信息
【检索上下文】{片段1} {片段2} {片段3}
【用户查询】{用户问题}
```

### 2.3 Prompt 优化技巧

**检索结果嵌入优化**：
- 去重降噪后嵌入 Prompt
- 最相关片段放在最前面
- 添加来源标注（如"来源：产品手册第 3 章"）

**指令精细化**：
- 避免模糊表述（"回答要详细"改为"包含 3 个核心要点"）
- 增加约束条件（"禁止出现竞品名称"）
- 多轮对话适配（加入历史对话上下文）

**幻觉抑制**（关键）：
- 强制引用：每个核心观点标注检索来源
- 否定式指令："禁止猜测不确定的内容"
- 示例引导：加入正确/错误示例

**行业适配**：
- 金融：合规约束、"不提供投资建议"
- 医疗：严谨约束、"仅供参考，不构成诊断建议"
- 企业内：权限约束、"暂无查看权限"

### 2.4 常见问题与解决方案

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 回答偏离检索结果 | Prompt 指令不明确 | 强化"仅使用检索内容"指令 |
| 生成幻觉 | 无幻觉抑制约束 | 添加"禁止编造"指令，要求标注来源 |
| 格式不统一 | 未明确格式要求 | 明确格式并加入示例 |
| 多轮衔接不畅 | 未包含历史对话 | 嵌入历史对话片段 |
| 行业不专业 | 未赋予角色 | 添加行业角色和约束 |

## 三、模型与 Prompt 的协同优化

| 问题 | 优先优化方向 |
|------|--------------|
| 幻觉率高 | Prompt 抑制指令 → 更换事实性更强的模型 |
| 回答偏离检索结果 | Prompt 指令清晰度 → 微调模型 |
| 推理速度慢 | 更换轻量化模型 → 优化 Prompt 精简上下文 |
| 行业适配性差 | 优化 Prompt 角色 → 用私有数据微调模型 |

### 优化工具

- **Prompt 调试**：LangChain、PromptLayer
- **模型微调**：Llama Factory、LoRA（轻量化微调）
- **评估指标**：相关性、准确性、速度、用户满意度

---

## 核心要点回顾

- 模型选型：平衡隐私、成本、效果，敏感场景私有部署，高并发混合部署
- Prompt 核心：明确指令 + 关联上下文 + 抑制幻觉 + 规范格式
- 幻觉抑制三招：强制引用、否定指令、示例引导
- 协同优化：模型是基础，Prompt 是关键，通过"监测-分析-优化-迭代"闭环持续提升
