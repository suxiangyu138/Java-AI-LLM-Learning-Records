# AI 大模型应用开发技术

> 面向 Java 后端工程师的 AI/LLM 应用开发知识体系 —— 涵盖理论、实战、工程化全链路。

## 项目结构

```
AI大模型应用开发技术/
├── docs/                          # 学习文档（按主题域组织）
│   ├── 01-理论基础/               # AI 理论根基
│   ├── 02-大模型应用技术/         # LLM 核心技术栈
│   ├── 03-工程实践/               # 落地与工程化
│   ├── 04-编程语言/               # Python & Java AI 集成
│   ├── 05-数据分析与爬虫/         # 数据采集与分析
│   ├── 06-产品与商业/             # AI 产品思维
│   ├── 07-学习路线与求职/         # 职业发展指南
│   └── 08-书籍与参考资料/         # 经典书籍笔记
│
└── code/                          # 实战代码
    ├── python-basics/             # Python 基础
    ├── python-oop/                # Python 面向对象
    ├── algorithms/                # 排序算法 & 数学验证
    ├── machine-learning/          # 机器学习实验
    ├── ai-demos/                  # ChromaDB / Milvus / Embedding
    ├── scraping/                  # 爬虫实战
    ├── data-analysis/             # 数据分析
    └── misc/                      # 小工具 & 游戏
```
