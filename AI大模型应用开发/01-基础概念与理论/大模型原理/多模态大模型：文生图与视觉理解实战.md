## 1. 多模态概述

### 什么是多模态

多模态 AI 能同时处理多种类型的数据：

```
单模态（传统 LLM）：  文本 → 文本
多模态：
  - 文本 → 图像（文生图）
  - 图像 → 文本（图像理解）
  - 文本 + 图像 → 文本（多模态理解）
  - 文本 → 音频/视频
```

### 主流模型

| 模型 | 能力 | 接入方式 |
|------|------|----------|
| GPT-4o | 文本 + 图像理解 | OpenAI API |
| Qwen-VL | 图像理解、OCR | 本地 / API |
| Stable Diffusion | 文生图 | 本地部署 |
| DALL-E 3 | 文生图 | OpenAI API |
| Sora | 文生视频 | OpenAI（预览） |

### 2.2 Stable Diffusion 本地部署

```python
from diffusers import StableDiffusionPipeline
import torch

# 加载模型
model_id = "runwayml/stable-diffusion-v1-5"
pipe = StableDiffusionPipeline.from_pretrained(
    model_id,
    torch_dtype=torch.float16,
    safety_checker=None
)
pipe = pipe.to("cuda")

# 生成图片
prompt = """
a tech blog hero image, Java programming, AI neural network background,
blue and purple gradient, clean modern design, 8k quality, digital art
"""
negative_prompt = "blurry, low quality, distorted"

image = pipe(
    prompt=prompt,
    negative_prompt=negative_prompt,
    num_inference_steps=25,
    guidance_scale=7.5,
    height=512,
    width=768,
).images[0]

image.save("java_ai_hero.png")
```

## 3. 图像理解（Image Understanding）

### 3.1 GPT-4o / GPT-4V 视觉理解

```python
from openai import OpenAI
import base64

client = OpenAI(api_key="sk-xxx")

def encode_image(path):
    with open(path, "rb") as f:
        return base64.b64encode(f.read()).decode("utf-8")

def analyze_image(image_path, prompt):
    """分析图像内容"""
    base64_image = encode_image(image_path)

    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[{
            "role": "user",
            "content": [
                {"type": "text", "text": prompt},
                {"type": "image_url", "image_url": {
                    "url": f"data:image/png;base64,{base64_image}"
                }}
            ]
        }]
    )
    return response.choices[0].message.content

# 使用场景

# 1. 图表/架构图解读
result = analyze_image("architecture.png", "分析这个Java微服务架构图，指出潜在瓶颈和改进建议")

# 2. 代码截图转文字
result = analyze_image("screenshot.png", "提取图片中的 Java 代码，并找出语法错误")

# 3. UI 审查
result = analyze_image("ui_mock.png", "审查这个前端页面的设计，给出 5 条改进建议")

# 4. 错误日志解读
result = analyze_image("error_stack.png", "分析错误堆栈，给出根因和修复方案")
```

### 3.2 Qwen-VL 本地部署

```python
from transformers import Qwen2VLForConditionalGeneration, AutoProcessor
from qwen_vl_utils import process_vision_info
import torch

model = Qwen2VLForConditionalGeneration.from_pretrained(
    "Qwen/Qwen2-VL-7B-Instruct",
    torch_dtype=torch.bfloat16,
    device_map="auto"
)
processor = AutoProcessor.from_pretrained("Qwen/Qwen2-VL-7B-Instruct")

def analyze_with_qwen_vl(image_path, question):
    messages = [{
        "role": "user",
        "content": [
            {"type": "image", "image": image_path},
            {"type": "text", "text": question}
        ]
    }]

    text = processor.apply_chat_template(messages, tokenize=False)
    image_inputs, video_inputs = process_vision_info(messages)

    inputs = processor(
        text=[text], images=image_inputs, videos=video_inputs,
        padding=True, return_tensors="pt"
    ).to(model.device)

    generated_ids = model.generate(**inputs, max_new_tokens=256)
    generated_ids_trimmed = [
        out_ids[len(in_ids):]
        for in_ids, out_ids in zip(inputs.input_ids, generated_ids)
    ]
    return processor.batch_decode(
        generated_ids_trimmed,
        skip_special_tokens=True
    )[0]

# 使用
print(analyze_with_qwen_vl("architecture.png", "描述这张架构图中的技术组件"))
```

## 5. 多模态开发实践要点

| 要点 | 说明 |
|------|------|
| 图像预处理 | 控制分辨率（通常 512-1024px），压缩大小 |
| 成本控制 | 图像 token 消耗巨大（一幅图 ≈ 500-1000 tokens） |
| 隐私注意 | 图像可能包含敏感信息（人脸、位置等） |
| 模型选择 | 英文用 GPT-4o，中文 OCR 优先 Qwen-VL |
| 本地优先 | 敏感图片使用本地模型，避免上传到云端 |
