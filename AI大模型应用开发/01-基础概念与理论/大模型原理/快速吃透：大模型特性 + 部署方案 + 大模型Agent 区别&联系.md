快速吃透：大模型特性 + 部署方案 + 大模型/Agent 区别&联系
一、主流大模型 分类 & 核心特性（必记）
1. 通用基础大模型（基座模型 Base Model）
    - 代表：Llama3、Qwen基座、DeepSeek基座、GLM基座
    - 特性：
    1. 海量文本预训练，擅长续写、补全、基础常识
    2. 无对话对齐，语气生硬，不能直接聊天
    3. 上下文长、知识库广，适合二次微调
    - 定位：原材料，不直接面向用户
2. 对话大模型（Chat 对齐模型）
    - 代表：GPT-3.5/4、通义千问、GLM-4、DeepSeek-Chat、豆包、星火
    - 特性：
    1. 在基座基础做SFT人类对齐，懂对话、懂规则、拒绝有害内容
    2. 逻辑问答、代码、文案、解释能力强
    3. 自带角色扮演、多轮上下文记忆
    - 定位：直接聊天、业务问答、日常AI服务
3. 代码大模型
    - 代表：CodeLlama、DeepSeek-Coder、Qwen-Code
    - 特性：
    1. 专攻代码生成、查Bug、写SQL、写Java/Python
    2. 理解框架：SpringBoot、Docker、Redis、MQ 等
    3. 适合后端开发、算法刷题、项目脚手架生成
    4. 多模态大模型（文+图）
    - 代表：GPT-4V、Qwen-VL、GLM-4V
    - 特性：
    识图、读图、解析截图、公式识别、图表分析
5. 垂直领域大模型
    - 金融、医疗、法律、教育专属
    - 行业术语精准，通用能力弱，企业私有化常用
 
二、大模型 三种部署方式（从易到难）
1. 公有云 API 调用（最简单｜企业最常用）
    - 代表：阿里百炼、智谱、DeepSeek、百度文心
    - 特点：
    1. 无需显卡、无需部署、一行代码调用
    2. 按量计费、开箱即用、稳定性强
    3. 数据走外网，隐私敏感业务不能用
    - 适用：个人开发、ToC业务、快速上线
2. 本地私有化部署（个人/内网项目）
    - 工具：Ollama（首选）、LM Studio、Text Generation WebUI
    - 硬件门槛：
    - 7B小模型：CPU 就能跑，无显卡也行
    - 14B+：需要 N 卡独显（显存≥8G）
    - 特点：
    1. 完全离线、数据不外泄、免费白嫖
    2. 自带 OpenAI 兼容接口，对接 RAG/Java 极其方便
    - 你必学：Ollama 一键部署本地大模型
3. 企业级私有化部署（高性能）
    - 框架：vLLM、TensorRT、FastGPT
    - 硬件：专业GPU服务器、显存集群
    - 特点：高并发、低延迟、可微调、内网隔离
    - 适用：政府、国企、金融、涉密系统
 
三、核心重点：AI大模型 vs Agent 区别 & 联系
1. 定义分开
    ① AI 大模型（LLM）
    本质：一个「会说话、会推理、有知识」的语言大脑
    - 能力：阅读理解、逻辑推理、写代码、算数、常识问答、文本生成
    - 局限：
    1. 没有主动行动能力
    2. 不能联网、不能操作软件、不能查数据库、不能定时任务
    3. 只会「被动回答」，不会主动规划、拆解任务
    - 一句话：
    大模型 = 大脑，只有思考能力，没有手脚
    ② AI Agent（智能代理）
    本质：以 LLM 为大脑，搭配「规划+工具+记忆+行动」的完整智能体
    Agent 四大核心组件：
    1. LLM 大脑：负责思考、决策、拆解任务
    2. 工具调用：联网搜索、查数据库、调用API、运行代码、操作文件
    3. 任务规划：复杂问题分步拆解、多步骤执行
    4. 长期记忆：记住历史任务、用户偏好、业务上下文
    一句话：
    Agent = 大模型 + 手脚 + 执行力 + 规划能力
 
四、直白对比（秒懂）
维度 普通大模型 LLM AI Agent 
核心能力 被动问答、文本生成 主动规划、自主完成复杂任务 
行动能力 无，只能打字回答 可调用工具、联网、操作服务 
任务复杂度 简单单步问题 多步骤复杂目标 
举例 解释RabbitMQ、写一段Java代码 「帮我完成一份后端学习计划+搜资料+整理MD笔记+生成目录」 
依赖 纯模型本身 LLM+工具集+调度框架 
 
五、二者联系（必考+理解核心）
1. LLM 是 Agent 的基础 & 唯一大脑
    没有大模型的理解、推理、思考，Agent 无法决策。
2. Agent 是 LLM 的能力扩展
    给大模型装上：
    - 工具调用（联网、API、数据库）
    - 任务拆解
    - 记忆管理
    让大模型从「只会聊天」变成「能干实事」。
3. 层级关系
    plaintext
    大模型(LLM)
     ↓ 作为核心
    AI Agent（智能体）
     ↓ 上层应用
    RAG知识库、自动化办公、智能助手、业务机器人
 
4. 你未来技术栈组合
    - LLM：本地Ollama部署 / 公有API调用
    - RAG：Milvus向量库 + 文档检索
    - Agent：工具调用、任务编排、对接后端服务
    → 完整 AI 应用闭环
 
六、最简总结背诵版
1. 大模型分：基座、对话、代码、多模态、行业模型；
2. 部署分：公有API、本地离线(Ollama)、企业集群部署；
3. LLM = 纯思考大脑，被动应答；
4. Agent = 以LLM为核心，带工具、规划、行动的智能体；
5. 关系：LLM是基础，Agent是增强形态，落地复杂AI应用全靠Agent。
