快速学会「预训练模型」
一、什么是预训练模型（核心一句话）
预训练模型 = 先在海量通用数据上「提前学好基础知识」，再拿来干细分任务的AI模型。
类比：
- 普通人：从零学做题
- 预训练模型：先读完全网书本、学会语言逻辑、常识、语法，再去写作业/做题
 
二、为什么要有「预训练」？
早期AI（传统机器学习）痛点：
1. 做一个任务，就要从零训练一个专属模型
2. 需要海量标注数据，成本极高
3. 泛化差，换个场景就废
    预训练模型 解决：
    1. 通用能力提前练好（语言理解、逻辑、语法、常识）
    2. 下游任务只需「小幅微调/直接使用」
    3. 极大降低数据、算力、开发成本
 
三、两段式核心流程（必背）
1. 预训练阶段（Pre-training）
    - 数据：无标注海量原始数据
    全网文本、书籍、网页、文章、代码
    - 目标：
    学会语言规律、上下文逻辑、知识、语法、语义
    - 特点：
    量大、无人工标注、算力要求极高
    - 产出：基座模型（Base Model）
2. 下游适配阶段
    两种路线：
    1. Prompt 直接使用（现在主流，大模型、Embedding 都是）
    不用改模型参数，靠提示词让模型干活
2. 微调 Fine-tune
    用少量专属数据，小幅修改模型权重，适配垂直场景
 
四、你日常接触的 3 类预训练模型
1. 大语言模型 LLM（文本生成预训练）
    代表：Qwen、DeepSeek、Llama、GLM
    - 预训练任务：文本续写、完形填空
    - 能力：聊天、推理、写代码、文案、逻辑
    - 形态：
    - 基座 Base：只会续写，生硬
    - 对话 Chat：在基座上做对齐微调，适合人机对话
2. Embedding 嵌入模型（语义预训练）
    代表：BGE-M3、Qwen-Embedding、Sentence-BERT
    - 预训练任务：语义相似度、对比学习
    - 核心作用：文本转向量、语义匹配
    - 直接决定 RAG 检索精度
3. 多模态预训练模型
    文+图+音频一起预训练
    代表：Qwen-VL、GPT-4V
    - 既能读文字，也能看懂图片、图表、截图
 
五、核心关键概念（极简理解）
1. 基座模型 Base Model
    纯预训练产物，无对话对齐，适合二次开发、微调
2. SFT 监督微调
    用高质量人机对话数据，把基座改成「会聊天」的对话模型
3. 对比学习
    Embedding 模型核心训练方式：
    相似文本向量拉近、不相似拉远
4. 上下文窗口 Context Window
    预训练时决定模型能「看多长远的文字」，决定长文本处理能力
 
六、预训练模型 vs 传统模型 区别
维度 传统小模型 预训练大模型 
学习方式 单任务从零训练 通用知识先预训练，再适配任务 
数据需求 大量标注数据 预训练无标注+下游少量数据 
泛化能力 差 极强，一通百通 
使用方式 单独训练部署 直接调用API / 本地部署 
 
七、和你学过的技术 串联打通
1. **RAG
    **
    依赖：Embedding预训练模型 做语义向量检索
2. Agent
    依赖：LLM预训练模型 做思考、任务拆解、工具决策
3. LangChain
    只是调度框架，底层全部依赖各类预训练模型
4. 向量数据库
    专门用来存放「预训练Embedding输出的向量」
 
八、预训练模型 三种使用方式
1. 公有云API调用
    阿里、智谱、DeepSeek，开箱即用，不用显卡
2. 本地私有化部署
    Ollama 运行 Qwen、Llama、BGE-M3，离线免费
3. 二次微调
    企业专属场景，用私有数据微调基座模型
 
九、最简背诵总结
1. 预训练 = 海量通用数据提前打底学习
2. 流程：预训练基座 → 微调/提示词适配业务
3. LLM、Embedding、多模态 全是预训练模型
4. LLM 负责思考生成，Embedding 负责语义向量
5. 现在所有AI应用：全部建立在预训练模型之上
 
十、一句话终极理解
预训练模型，就是AI的「通识基础教育」；
你做的RAG、Agent、AI问答，都是它的「专业课应用」。
