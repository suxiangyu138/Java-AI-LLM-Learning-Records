# 🧠 快速学会「预训练模型」

## 1. 什么是预训练模型

**预训练模型（Pre-trained Model）** 是指先在海量通用数据上"提前学好基础知识"，再拿来干细分任务的 AI 模型。

**类比理解**：
- **传统方式（普通人）**：从零学做题
- **预训练模型**：先读完全网书本，学会语言逻辑、常识、语法，再去写作业做题

## 2. 为什么要有预训练

传统机器学习存在三个核心痛点：

| 痛点 | 说明 |
|------|------|
| **从零训练** | 做一个任务就要从零训练一个专属模型 |
| **标注成本高** | 需要海量标注数据，成本极高 |
| **泛化差** | 换个场景就失效 |

预训练模型通过以下方式解决：

- 通用能力提前练好（语言理解、逻辑、语法、常识）
- 下游任务只需小幅微调或直接使用
- 极大降低数据、算力、开发成本

## 3. 两段式核心流程

### 3.1 预训练阶段（Pre-training）

| 维度 | 说明 |
|------|------|
| **数据** | 无标注海量原始数据：全网文本、书籍、网页、文章、代码 |
| **目标** | 学会语言规律、上下文逻辑、知识、语法、语义 |
| **特点** | 数据量大、无人工标注、算力要求极高 |
| **产出** | 基座模型（Base Model） |

### 3.2 下游适配阶段

两种路线：

| 路线 | 说明 |
|------|------|
| **Prompt 直接使用**（当前主流） | 不修改模型参数，靠提示词引导模型工作，适用于 LLM 和 Embedding 模型 |
| **微调（Fine-tune）** | 用少量专属数据小幅修改模型权重，适配垂直场景 |

## 4. 日常接触的 3 类预训练模型

### 4.1 大语言模型 LLM（文本生成预训练）

| 维度 | 说明 |
|------|------|
| **代表模型** | Qwen、DeepSeek、Llama、GLM |
| **预训练任务** | 文本续写、完形填空 |
| **能力** | 聊天、推理、写代码、文案、逻辑 |
| **形态** | 基座 Base（只会续写）→ 对话 Chat（对齐微调，适合人机对话） |

### 4.2 Embedding 嵌入模型（语义预训练）

| 维度 | 说明 |
|------|------|
| **代表模型** | BGE-M3、Qwen-Embedding、Sentence-BERT |
| **预训练任务** | 语义相似度、对比学习 |
| **核心作用** | 文本转向量、语义匹配，直接决定 RAG 检索精度 |

### 4.3 多模态预训练模型

| 维度 | 说明 |
|------|------|
| **代表模型** | Qwen-VL、GPT-4V |
| **能力** | 既读文字，也看懂图片、图表、截图 |

## 5. 核心关键概念

| 概念 | 说明 |
|------|------|
| **基座模型（Base Model）** | 纯预训练产物，无对话对齐，适合二次开发、微调 |
| **SFT（监督微调）** | 用高质量人机对话数据，将基座改成"会聊天"的对话模型 |
| **对比学习** | Embedding 模型核心训练方式：相似文本向量拉近，不相似拉远 |
| **上下文窗口** | 预训练时决定模型能"看多长远的文字"，决定长文本处理能力 |

## 6. 预训练模型 vs 传统模型

| 维度 | 传统小模型 | 预训练大模型 |
|------|-----------|-------------|
| **学习方式** | 单任务从零训练 | 通用知识预训练，再适配任务 |
| **数据需求** | 大量标注数据 | 预训练无标注 + 下游少量数据 |
| **泛化能力** | 差 | 极强，一通百通 |
| **使用方式** | 单独训练部署 | 直接调用 API / 本地部署 |

## 7. 与已有技术栈的关联

| 技术 | 与预训练模型的关系 |
|------|-------------------|
| **RAG** | 依赖 Embedding 预训练模型做语义向量检索 |
| **Agent** | 依赖 LLM 预训练模型做思考、任务拆解、工具决策 |
| **LangChain** | 只是调度框架，底层全部依赖各类预训练模型 |
| **向量数据库** | 专门存放预训练 Embedding 输出的向量 |

## 8. 预训练模型的三种使用方式

| 方式 | 说明 |
|------|------|
| **公有云 API 调用** | 阿里、智谱、DeepSeek，开箱即用，无需显卡 |
| **本地私有化部署** | Ollama 运行 Qwen、Llama、BGE-M3，离线免费 |
| **二次微调** | 企业专属场景，用私有数据微调基座模型 |

## 核心要点回顾

- 预训练 = 海量通用数据提前打底学习
- 核心流程：预训练基座 → 微调/提示词适配业务
- LLM、Embedding、多模态模型全是预训练模型
- LLM 负责思考生成，Embedding 负责语义向量
- 当前所有 AI 应用全部建立在预训练模型之上
