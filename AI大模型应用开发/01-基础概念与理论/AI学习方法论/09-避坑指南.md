# 避坑指南 —— AI 使用禁忌与正确姿势

## 核心原则

> **用 AI 做你不会的事，不用 AI 做你会的事。**
> —— 黄仁勋

---

## 六大错误用法（导致能力退化）

### 错误 1：完全依赖 AI 写代码

```
❌ 场景：Cursor Ctrl+K → "实现用户登录功能" → 全部 AI 生成 → 提交
后果：3 个月后面试，手写一个简单的登录接口都写不出来
     AI 生成的异常处理你可能不理解，生产环境出 Bug 定位不到

✅ 正确：AI 生成初版 → 你逐行阅读并修改 → 删掉多余代码 → 自己加异常处理
    核心业务逻辑（交易/支付/权限）必须自己写
```

### 错误 2：不验证直接复制

```
❌ 场景：AI 给了 Spring 配置 → 直接粘贴 → 项目跑不起来
原因：AI 训练数据可能包含旧版本/不同版本混用的配置
     比如 Spring Boot 2.x 和 3.x 的配置方式完全不同

✅ 正确：AI 生成的配置 → 查官方文档验证关键参数 → 本地跑通 → 提交
    至少跑一遍单元测试确认功能正常
```

### 错误 3：用 AI 做简单事

```
❌ 用 AI 写 HelloWorld / 简单 CRUD / if-else 逻辑
→ 浪费时间且无成长，大脑处于被动接收状态

✅ 简单的自己写（巩固基础），复杂的让 AI 教（拓展边界）
```

### 错误 4：AI 说"用 X 就够了"就停止思考

```
❌ AI："用 synchronized 就够了" → 你就真的用了
→ 没有追问"为什么不用 ReentrantLock？什么场景下 ReentrantLock 更好？"

✅ 对 AI 的每个建议追问：
   - "为什么选这个而不是那个？"
   - "什么情况下这个方案会失效？"
   - "有没有性能更好的替代方案？"
```

### 错误 5：只用 1 个 AI 工具

```
❌ 只用 ChatGPT，把它当唯一真理来源
→ ChatGPT 有幻觉，可能一本正经地胡说八道
→ 没有交叉验证的方案可能隐藏致命漏洞

✅ 至少 2 个 AI 交叉验证（参考 [[07-Prompt Engineering核心技巧#技巧4]]）
```

### 错误 6：用 AI 代替记忆基础知识

```
❌ 每次写 SQL 都用 Copilot 生成，自己不记语法
→ 面试被问"写一个多表联查"写不出来

✅ 基础语法必须记在脑子里
   AI 帮你省的是查文档的时间，不是记忆的时间
   面试场景没有 AI 辅助，基础知识必须扎实
```

## 六大正确用法（认知能力倍增）

### 正确 1：用 AI 学不会的

| 你的水平 | 应该问 AI 的 | 不应该问 AI 的 |
|---------|------------|-------------|
| 应届生 | 微服务架构设计 / 分布式事务原理 | for 循环怎么写 |
| 1-3 年 | JVM 调优 / 系统设计 / 源码阅读 | Spring Boot 怎么配数据源 |
| 3-5 年 | 技术方案对比 / 行业最佳实践 | CRUD 代码怎么生成 |

### 正确 2：AI 是教练不是保姆

```
算法题：先自己写 10 分钟 → AI 纠正思路 → 再做变种
源码：先看 30 分钟摸索 → AI 画架构图 → 对照源码验证
项目：先自己设计 → AI critique → 修改方案
```

### 正确 3：批判性接收

```
AI 的每个输出都要经过"批判性三问"：
1. 这个答案的前提假设是什么？（如果假设不成立，答案就错了）
2. 有没有相反的观点？（让 AI 自我反驳再审查）
3. 在实践中验证过吗？（跑个 Demo 确认可行）
```

### 正确 4：AI 做催化剂，不做替代品

```
你的角色：思考者、决策者、验证者
AI 的角色：信息收集者、方案建议者、代码草稿生成者

最终决策永远是你来做。
```

### 正确 5：间隔重复 + AI 回顾

```
今日用 AI 学完 Spring AOP → 生成笔记
3 天后 → ChatGPT："上次学的 Spring AOP，出 3 道题考我"
7 天后 → 看笔记 + 自己写一个 AOP 切面 Demo
```

### 正确 6：把 AI 当面试模拟器

```
创建"Java 后端面试官" GPT：
- 模拟真实面试流程
- 追问底层原理
- 对口述回答打分
- 指出薄弱点

每周模拟面试 1 次，提前适应面试节奏
```

## 自查清单（每周核对）

```
□ 本周有多少代码是自己写的 vs AI 生成的？（目标：≥60% 自己写）
□ 遇到简单问题有没有先自己想 2 分钟再问 AI？
□ AI 给的方案有没有验证过（至少跑通测试）？
□ 有没有用至少 2 个 AI 工具交叉验证关键方案？
□ 有没有对 AI 的推荐方案追问"为什么"？
□ 基础知识（SQL/Java 语法/Spring 配置）有没有定期手写巩固？
```
