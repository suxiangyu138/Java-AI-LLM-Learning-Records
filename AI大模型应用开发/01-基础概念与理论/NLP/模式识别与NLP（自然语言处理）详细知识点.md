## 1. 模式识别核心知识点

### 1.1 基础概念与系统框架

**模式识别**是人工智能、计算机科学与信号处理交叉的核心领域，目标是让机器自动从数据中发现规律、识别对象并做出判断。

**系统核心流程**（5 个关键步骤）：

```
数据采集 → 预处理 → 特征提取/选择 → 分类/聚类 → 后处理
```

**方法分类**：

| 类别 | 核心思路 | 典型方法 |
|------|----------|----------|
| 统计模式识别 | 基于概率统计模型 | 贝叶斯决策、KNN、SVM |
| 结构/句法模式识别 | 基于形式语言理论 | 句法分析、文法推理 |
| 模糊模式识别 | 基于模糊集理论 | 模糊聚类、模糊分类 |
| 神经网络模式识别 | 模拟神经元结构 | MLP、CNN、RNN |

**核心挑战**：维数灾难（特征维度过高导致性能下降）、数据噪声干扰。

### 1.2 核心理论与经典算法

#### 1.2.1 统计模式识别

**贝叶斯决策理论**：核心是贝叶斯公式与后验概率计算，分为最小错误率决策和最小风险决策。需掌握正态分布下的判别函数及错误率分析。

**概率密度函数估计**：

- **参数估计**：假设数据服从已知分布，通过最大似然估计（ML）或贝叶斯估计（MAP）估计参数
- **非参数估计**：无需假设数据分布，如 Parzen 窗方法、核密度估计
- **辅助算法**：EM 算法（含隐变量估计）、HMM（时序数据建模）

#### 1.2.2 非参数方法与近邻分类器

**K 近邻（KNN）**：通过计算测试样本与训练样本的距离（欧氏距离、马氏距离、余弦距离），选取最近的 K 个样本，按多数投票确定类别。

- **K 值影响**：K 越小模型越敏感（易过拟合），K 越大模型越平滑（易欠拟合）
- **改进方法**：剪辑近邻、压缩近邻

#### 1.2.3 线性分类器设计

| 方法 | 核心思想 |
|------|----------|
| **感知器算法** | 梯度下降最小化准则函数，适用于线性可分数据 |
| **Fisher 线性判别（LDA）** | 最大化类间散度、最小化类内散度，兼顾降维与分类 |
| **最小二乘法（MSE）** | 处理线性不可分场景的近似分类 |

#### 1.2.4 特征提取与选择

| 方法 | 说明 |
|------|------|
| **PCA（主成分分析）** | 正交变换保留方差最大方向，实现降维 |
| **LDA（Fisher 判别）** | 兼顾降维与分类性能 |
| **核 PCA** | 通过核技巧处理非线性数据 |

#### 1.2.5 支持向量机（SVM）

基于**结构风险最小化**原则：

| 场景 | 方法 |
|------|------|
| 线性可分 | 硬间隔最大化，寻找支持向量 |
| 线性不可分 | 引入软间隔与松弛变量 |
| 非线性 | 核技巧（多项式核、高斯核）映射到高维空间 |

#### 1.2.6 神经网络与深度学习

| 阶段 | 模型 | 特点 |
|------|------|------|
| 传统 | 单层感知器、MLP、BP 算法 | 基础结构，适用于简单任务 |
| 经典 | RBF、SOM、Hopfield、自编码器 | 适用于特定场景 |
| 深度学习 | CNN（局部特征）、RNN（时序数据） | 现代主流方法 |

#### 1.2.7 聚类分析

| 算法 | 特点 |
|------|------|
| **K-Means** | 迭代更新聚类中心，对初始值敏感 |
| **Fuzzy C-Means** | 支持样本属于多个聚类（隶属度划分） |
| **层次聚类** | 构建聚类树，适用于层次关系场景 |
| **谱聚类** | 基于图论的聚类方法 |

#### 1.2.8 模型选择与性能评估

**核心指标**：

| 指标 | 公式 | 说明 |
|------|------|------|
| 准确率 | (TP+TN)/(TP+TN+FP+FN) | 整体正确率 |
| 精确率 | TP/(TP+FP) | 阳性预测值的准确性 |
| 召回率 | TP/(TP+FN) | 真实阳性被识别出的比例 |
| F1 分数 | 2x(PrecisionxRecall)/(Precision+Recall) | 精确率和召回率的调和平均 |
| ROC/AUC | - | 分类器在不同阈值下的性能 |

**模型选择原则**：偏差-方差权衡、交叉验证（K 折交叉验证）、集成学习（Bagging、Boosting、Stacking）。

## 2. NLP 自然语言处理详细知识点

### 2.1 基础概念与发展历史

**定义**：NLP 通过融合计算语言学、统计建模和深度学习，使计算机能够识别、理解、生成和处理人类文本与语音数据。

**发展阶段**：

| 时期 | 特征 | 代表技术 |
|------|------|----------|
| 1950s-1960s | 规则导向 | 手工编写语法规则 |
| 1970s-1980s | 统计+语料库 | HMM、最大熵、CRF |
| 1990s-2000s | 知识+混合方法 | 规则+统计结合 |
| 2010s | 深度学习端到端 | CNN、RNN/LSTM |
| 2018 至今 | 预训练+Transformer | BERT、GPT 系列 |
| 2023-2026 | 大语言模型主导 | GPT-4o、Llama-4、Claude-3 |

### 2.2 理论与数学基础

**语言学基础**：

| 分支 | 研究对象 | 应用 |
|------|----------|------|
| 语音学 | 发音、声学特性 | 语音识别、合成 |
| 形态学 | 词的构成和变化 | 词形还原、词干提取 |
| 句法学 | 句子结构 | 句法分析、分词 |
| 语义学 | 词句含义 | 词义消歧、语义相似度 |
| 语用学 | 语境含义 | 对话系统 |
| 篇章分析 | 段落与篇章结构 | 文本摘要 |

**概率统计基础**：贝叶斯定理、马尔可夫链、n-gram 语言模型、数据平滑（Laplace、Kneser-Ney）、条件随机场（CRF）。

### 2.3 文本预处理与语料库处理

预处理是 NLP 工程中最耗时（占比 50%-70%）但最关键的一步。

**核心步骤**：

1. **分词（Tokenization）**：
   - 英文：基于空格和标点 + BPE/WordPiece/SentencePiece 子词分词
   - 中文：Jieba、THULAC、PKUSeg，解决分词歧义和新词发现

2. **词形处理**：
   - 词干提取（Stemming）：简单截取词干（Porter 算法）
   - 词形还原（Lemmatization）：结合语法还原为标准形态

3. **停用词与低频词移除**：降低计算复杂度

4. **语料库标注**：词性标注（POS）、命名实体标注（BIO/BIOES 格式）、语义角色标注、情感标注

### 2.4 文本表示与特征工程

#### 2.4.1 传统文本表示

| 方法 | 原理 | 特点 |
|------|------|------|
| **One-Hot 编码** | 每个词映射为独热向量 | 维度高、稀疏、无语义 |
| **Bag-of-Words (BoW)** | 统计词频构建向量 | 忽略顺序和语义 |
| **TF-IDF** | 词频 x 逆文档频率 | 降低常用词权重，应用广泛 |
| **N-gram** | 连续 N 个词的组合 | 捕捉部分上下文，维度指数增长 |

#### 2.4.2 现代词嵌入方法

**静态词嵌入**（词向量固定）：

| 方法 | 特点 |
|------|------|
| **Word2Vec** | CBOW（上下文预测中心词）/Skip-gram（中心词预测上下文） |
| **GloVe** | 基于全局词频统计，兼顾局部上下文 |
| **FastText** | 支持子词嵌入，处理未登录词 |

**动态/上下文嵌入**（词向量随语境变化）：

| 方法 | 特点 |
|------|------|
| **ELMo** | 基于双向 LSTM，上下文相关 |
| **BERT** | 基于 Transformer Encoder，Masked LM + NSP 预训练 |
| **RoBERTa** | 优化 BERT 预训练策略 |
| **ALBERT** | 轻量化 BERT，降低计算复杂度 |

### 2.5 经典 NLP 任务与传统方法

#### 2.5.1 词法分析

| 任务 | 方法 | 说明 |
|------|------|------|
| **词性标注（POS）** | HMM、CRF、BiLSTM-CRF | 标注词性（名词、动词等） |
| **命名实体识别（NER）** | CRF、BERT-CRF | 识别实体（人名、地名、组织），BIO 标注 |

#### 2.5.2 句法分析

- **依存句法解析**：分析词间依存关系（主谓、动宾），输出依存树
- **成分句法解析**：分析短语结构，生成成分树

#### 2.5.3 语义分析

| 任务 | 说明 |
|------|------|
| 词义消歧（WSD） | 确定多义词的具体含义 |
| 语义角色标注（SRL） | 标注谓词的施事、受事等角色 |
| 语义相似度 | 计算词/句/文档的语义相似程度 |

#### 2.5.4 信息抽取（IE）

- **实体抽取**：即 NER
- **关系抽取（RE）**：提取实体间关系（如"张三-工作于-XX公司"）
- **事件抽取**：提取事件触发词、参与者、时间等

#### 2.5.5 其他基础任务

| 任务 | 方法 | 本质 |
|------|------|------|
| 文本分类/情感分析 | NB、SVM、FastText、深度学习 | 模式识别的分类任务 |
| 文本聚类 | K-Means、层次聚类、谱聚类 | 模式识别的聚类任务 |
| 主题建模 | LDA、PLSA、BERTopic | 从文本中提取核心主题 |

### 2.6 深度学习基础模型

#### 2.6.1 序列模型

| 模型 | 特点 | 局限 |
|------|------|------|
| **RNN** | 循环结构捕捉时序依赖 | 梯度消失/爆炸，难处理长文本 |
| **LSTM** | 遗忘门、输入门、输出门 | 解决梯度消失，适合长文本 |
| **GRU** | 简化版 LSTM | 计算更快，效果接近 LSTM |
| **BiLSTM** | 双向处理，捕捉双向上下文 | NER、序列标注的核心模型 |

#### 2.6.2 TextCNN

通过不同尺寸的卷积核提取文本的局部语义特征，适用于文本分类和情感分析。

#### 2.6.3 注意力机制

| 机制 | 说明 |
|------|------|
| **Self-Attention** | 计算词间关联权重，捕捉全局上下文 |
| **Multi-Head Attention** | 多个注意力头捕捉不同维度的关联 |
| **Scaled Dot-Product Attention** | 标准化注意力得分 |

#### 2.6.4 Transformer 架构

| 结构 | 特点 | 代表模型 |
|------|------|----------|
| **Encoder** | 多层 Self-Attention + FFN，双向上下文 | BERT、RoBERTa |
| **Decoder** | Masked Self-Attention + Encoder-Decoder Attention | GPT 系列 |
| **Encoder-Decoder** | 序列到序列 | T5、BART |

### 2.7 预训练语言模型与大语言模型

#### 2.7.1 预训练范式

- **自监督预训练**：Masked LM（BERT）、Next Token Prediction（GPT）
- **指令微调**：通过指令数据提升多任务适配能力
- **人类对齐**：RLHF、DPO 使输出符合人类偏好

#### 2.7.2 代表性模型

| 模型家族 | 架构 | 代表 |
|----------|------|------|
| **BERT 系列** | Encoder-only | RoBERTa、DistilBERT、DeBERTa |
| **GPT 系列** | Decoder-only | ChatGPT、GPT-4o |
| **开源 LLM** | 多种架构 | Llama-2/3/4、Mistral、Qwen、DeepSeek |
| **其他** | Text-to-Text | T5、UL2、Claude |

#### 2.7.3 高效微调与前沿技术

| 技术 | 说明 |
|------|------|
| **LoRA/QLoRA** | 参数高效微调（PEFT），大幅降低计算成本 |
| **MoE（混合专家）** | 不同任务调用不同专家模块 |
| **长上下文处理** | 支持 32K-1M tokens |
| **多模态融合** | CLIP、LLaVA、GPT-4V 实现文本与图像/音频交互 |
| **RAG** | 检索增强生成，调用外部知识提升准确性 |
| **Agent** | 结合工具使用和 ReAct 框架实现复杂任务自动化 |

### 2.8 高级应用任务

| 任务 | 说明 | 核心模型 |
|------|------|----------|
| **机器翻译** | 跨语言文本转换 | 神经 MT（Transformer） |
| **文本生成** | 摘要、故事、代码生成 | GPT 系列、T5 |
| **问答系统** | 抽取式/生成式 QA | BERT、GPT |
| **对话系统** | 任务型/开放域 | ChatGPT、专用模型 |
| **语音任务** | 语音识别/合成 | ASR、TTS |

### 2.9 评估指标

| 指标 | 适用任务 | 说明 |
|------|----------|------|
| **Perplexity** | 语言模型 | 值越低越好 |
| **BLEU** | 机器翻译 | 衡量与参考文本的 n-gram 重叠 |
| **ROUGE** | 文本摘要 | 衡量摘要的重叠度 |
| **EM / F1** | 问答 | 精确匹配与部分匹配 |
| **Precision/Recall/F1** | NER、分类 | 基于实体级别评估 |

## 3. 模式识别与 NLP 的关联与融合

| 关联维度 | 说明 |
|----------|------|
| **技术支撑** | 分类（文本分类）、特征提取（NER）、聚类（文本聚类）、神经网络（Transformer） |
| **数据共性** | 均处理非结构化数据，需解决噪声和维数灾难 |
| **融合应用** | 语音识别（时序+文本）、OCR（图像+文本）、多模态大模型（GPT-4V） |
| **共同前沿** | 深度学习、注意力机制、预训练模型、小样本学习 |

## 4. 学习建议与核心工具

### 4.1 学习建议

1. **基础先行**：掌握概率论、线性代数、矩阵论
2. **理论体系**：先学模式识别（贝叶斯、特征提取、SVM、神经网络），再学 NLP 语言学基础与核心任务
3. **实践落地**：通过编程实现核心算法，使用真实数据集进行实战

## 5. 核心要点回顾

- 模式识别核心流程：数据采集 -> 预处理 -> 特征提取 -> 分类/聚类 -> 后处理
- NLP 发展经历了规则、统计、深度学习、预训练大模型四个阶段
- 文本表示从 One-Hot、TF-IDF 演进到静态词嵌入（Word2Vec）再到动态上下文嵌入（BERT）
- Transformer 架构是当前大模型的基础，Encoder（BERT）擅长理解，Decoder（GPT）擅长生成
- 模式识别为 NLP 提供分类、聚类、特征提取等核心技术支撑
- 预训练+微调范式显著降低了 NLP 任务的标注数据需求
- 当前前沿方向包括大语言模型、RAG、Agent、多模态融合
