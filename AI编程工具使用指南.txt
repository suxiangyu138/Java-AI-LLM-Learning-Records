1. Claude Code（已安装，当前正在使用）
─────────────────────────────────────
  类型：终端原生 AI Agent
  安装位置：全局（D:\npm-global\）
  版本：v2.1.158

  ▸ 启动方式
    在终端中直接输入：
      claude

    或者在项目目录下：
      cd 你的项目目录
      claude

  ▸ 核心功能
    - 直接读写文件、执行命令
    - Git 操作（commit、push、PR）
    - 多 Agent 编排（Workflow）
    - MCP 协议扩展（连接数据库、浏览器等外部服务）
    - 支持 Skills（技能模块）

  ▸ 常用命令
    /help              查看帮助
    /clear             清除对话上下文
    /compact           压缩上下文（释放 token）
    /review            代码审查当前改动
    /simplify          简化/优化代码
    /init              为新项目创建 CLAUDE.md
    /config            修改设置
    /workflows         查看运行中的工作流

  ▸ 配置 API Key
    Claude Code 使用 Anthropic API，需要设置 key：
    方式一：环境变量
      set ANTHROPIC_API_KEY=sk-ant-xxx
    方式二：配置文件
      ~/.claude/settings.json 中添加

  ▸ 常用场景
    - "帮我分析这个项目结构"
    - "修复这个 bug"
    - "给这个函数写单元测试"
    - "解释这段代码的逻辑"
    - "重构这个文件"


2. Cursor（AI-first IDE）
─────────────────────────
  类型：桌面 IDE（基于 VS Code）
  安装位置：D:\cursor\Cursor.exe
  启动：双击 Cursor.exe 或终端输入 cursor

  ▸ 核心功能
    - Tab 键补全（比 Copilot 更激进，能预测多行）
    - Cmd/Ctrl+K → 选中代码，用自然语言编辑
    - Cmd/Ctrl+L → 打开 Chat 面板
    - Cmd/Ctrl+I → Composer（Agent 模式，可跨文件编辑）
    - 支持 Claude、GPT-4o、Gemini 等多种模型切换

  ▸ 推荐设置（Settings → Models）
    - 默认模型选 Claude Opus（最强推理）
    - 快速补全选 Claude Haiku（速度快、便宜）
    - Agent 模式选 Claude Sonnet（平衡）

  ▸ 使用技巧
    - Composer 模式（Cmd+I）：描述需求，它能自动创建/修改多个文件
    - @ 符号引用：@file 引用文件，@folder 引用目录，@web 搜索网页
    - Rules：在 .cursorrules 文件里写项目规则，AI 会严格遵守
    - 代码库索引：Cursor 会自动索引整个项目，回答关于代码库的问题

  ▸ 快捷键速查
    Ctrl+K          行内编辑选中代码
    Ctrl+L          AI Chat 面板
    Ctrl+I          Composer（Agent 多文件编辑）
    Ctrl+Shift+I    Composer 内新建对话
    Tab             AI 补全接受


3. Windsurf（Codeium 出品）
───────────────────────────
  类型：桌面 IDE（基于 VS Code）
  安装位置：D:\Windsurf\Windsurf.exe
  启动：双击 Windsurf.exe

  ▸ 核心功能
    - Cascade：上下文感知的 AI 对话，能理解整个项目
    - Flow 模式：Agent 自主多文件协作编辑
    - Supercomplete：智能代码补全
    - 免费额度较大方

  ▸ 与 Cursor 的区别
    - Windsurf 免费额度更多，适合预算敏感
    - Cascade 对大型代码库的上下文理解更强
    - Cursor 的 Composer 更激进，Windsurf 更保守稳定

  ▸ 快捷键
    Ctrl+I          Cascade 面板
    Ctrl+K          行内编辑
    Tab             补全接受

7. Aider（终端 AI 结对编程）
────────────────────────────
  类型：命令行 Agent
  版本：0.86.2
  启动：aider

  ▸ 核心功能
    - 在终端里与 AI 结对编程
    - 自动 git commit（每个改动都有清晰的 commit message）
    - 支持多文件编辑
    - 可以添加/移除文件到上下文
    - 自动生成 .aider* 配置文件

  ▸ 基础用法
    # 启动（当前目录）
    aider

    # 指定模型
    aider --model claude-sonnet-4-6

    # 添加文件到上下文
    aider src/main.py tests/test_main.py

    # 使用快捷命令
    aider --4o           # 用 GPT-4o
    aider --sonnet       # 用 Claude Sonnet

  ▸ 对话内命令
    /add 文件名        添加文件到上下文
    /drop 文件名       从上下文移除文件
    /read-only 文件名  只读方式添加文件
    /commit            手动提交
    /diff              查看改动
    /undo              撤销上次改动
    /clear             清除对话
    /model 模型名      切换模型
    /map               查看代码库地图
    /run 命令          执行 shell 命令

  ▸ 配置 API Key
    set ANTHROPIC_API_KEY=sk-ant-xxx
    set OPENAI_API_KEY=sk-xxx

  ▸ 配置文件位置
    项目级：.aider.conf.yml
    全局：~/.aider.conf.yml


8. OpenAI Agents SDK
────────────────────
  类型：Python Agent 框架
  版本：0.10.5
  导入：import agents

  ▸ 用途
    - 构建自定义 AI Agent 应用
    - 多 Agent 编排（handoff 模式）
    - 工具定义与调用
    - 追踪（Tracing）

  ▸ 快速开始
    from agents import Agent, Runner

    print(result.final_output)

9. LangChain（LLM 应用框架）
────────────────────────────
  类型：Python 框架
  版本：1.3.11
  导入：import langchain

  ▸ 核心概念
    - Chain：将多个步骤串联
    - Tool：给 LLM 绑定工具（搜索、计算器等）
    - Agent：LLM 自主决定使用哪些工具
    - Memory：对话记忆

  ▸ 快速开始
    from langchain.agents import create_agent
    from langchain.chat_models import init_chat_model

    model = init_chat_model("claude-sonnet-4-6")
    agent = create_agent(model, tools=[...])
    result = agent.invoke({"messages": [{"role": "user", "content": "你好"}]})


10. LangGraph（Agent 工作流编排）
─────────────────────────────────
  类型：Python 框架
  版本：1.2.6
  导入：import langgraph

  ▸ 用途
    - 构建有状态的、多步骤的 Agent 工作流
    - 图（Graph）结构定义流程
    - 条件分支、循环、人工审批节点
    - 与 LangChain 无缝集成

  ▸ 快速开始
    from langgraph.graph import StateGraph, START, END

    graph = StateGraph(MyState)
    graph.add_node("analyze", analyze_func)
    graph.add_node("execute", execute_func)
    graph.add_edge(START, "analyze")
    graph.add_conditional_edges("analyze", decide, {"yes": "execute", "no": END})
    app = graph.compile()


11. CrewAI（多 Agent 协作）
───────────────────────────
  类型：Python 框架
  版本：0.95.0
  导入：import crewai

  ▸ 核心概念
    - Agent：定义角色（如"架构师"、"测试工程师"）
    - Task：定义任务
    - Crew：一组 Agent + 一组 Task
    - Process：执行顺序（sequential 或 hierarchical）

  ▸ 快速开始
    from crewai import Agent, Task, Crew

    分析师 = Agent(role="数据分析师", goal="分析数据并给出洞察", backstory="...")
    写手 = Agent(role="报告写手", goal="生成专业报告", backstory="...")

    分析任务 = Task(description="分析销售数据", agent=分析师)
    写作任务 = Task(description="生成分析报告", agent=写手)

    team = Crew(agents=[分析师, 写手], tasks=[分析任务, 写作任务])
    result = team.kickoff()

13. Pydantic AI（结构化 Agent）
───────────────────────────────
  类型：Python Agent 框架
  版本：1.22.0
  导入：import pydantic_ai

  ▸ 特点
    - 类型安全：用 Pydantic 模型定义输入输出
    - 结构化输出：Agent 返回强类型数据
    - 支持多模型：Claude、GPT、Gemini 等
    - 依赖注入：Agent 可以注入服务

  ▸ 快速开始
    from pydantic_ai import Agent
    from pydantic import BaseModel

    class Result(BaseModel):
        summary: str
        score: int

    agent = Agent("claude-sonnet-4-6", result_type=Result)
    result = agent.run_sync("分析这段文字")

================================================================================
常见问题
================================================================================

Q: 这些工具都需要 API Key 吗？
A: 不全是。Cursor/Windsurf/Copilot 自带 key（订阅制）。
   Claude Code/Aider/LangChain 需要自己提供 Anthropic/OpenAI key。
   通义灵码需要阿里云账号。

Q: 哪个免费？
A: Windsurf 免费额度最多。通义灵码基础版免费。
   Cursor 有免费试用期。Copilot 有学生免费计划。

Q: 多个 AI 同时开会冲突吗？
A: 不同工具不冲突。但同一个 VS Code 里不建议同时开多个补全插件
   （如 Copilot + 通义灵码 + Augment 的补全功能可能会互相干扰，
    建议只开一个补全，其他只保留 Chat 功能）。

Q: 如何卸载某个工具？
A: Python：pip uninstall 包名
   Node：npm uninstall -g 包名
   VS Code：code --uninstall-extension 扩展ID
   IDE：控制面板 → 卸载程序
