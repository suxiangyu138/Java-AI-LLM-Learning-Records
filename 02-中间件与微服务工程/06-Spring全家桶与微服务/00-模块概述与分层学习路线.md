## 1. 模块定位与知识全景

### 1.1 知识定位
归属 **Spring全家桶组件 + 微服务生态 + 调优运维**，是我知识体系的第二层"中间件与微服务工程"的核心模块。

### 1.2 本模块完整知识树

```
Spring全家桶与微服务
├── 层级1：Spring Framework 核心（P0，全家桶根基）
│   ├── 01-IoC容器：Bean生命周期、DI、循环依赖三级缓存、作用域、JavaConfig
│   ├── 02-AOP：切面/切点/通知、JDK动态代理 vs CGLIB、代理失效场景
│   ├── 03-事务管理：ACID、隔离级别、传播行为、@Transactional失效全场景
│   └── 04-资源/校验/事件：ResourceLoader、Validator、事件发布监听机制
│
├── 层级2：Spring全家桶核心组件（P0+P1，后端开发必备）
│   ├── 05-Spring MVC：DispatcherServlet流程、RESTful、拦截器/过滤器、全局异常
│   ├── 06-Spring Boot：自动装配原理、Starter机制、配置文件、Actuator监控
│   ├── 07-Spring Data：JPA/Redis/MongoDB、Repository、分页排序
│   ├── 08-Spring Security：认证授权、RBAC、OAuth2/JWT、PasswordEncoder
│   └── 09~16-Spring Cloud全套：Nacos/Feign/Gateway/Sentinel/Seata/SkyWalking/分布式锁
│
├── 层级3：微服务配套中间件（P1，工程落地必备）
│   ├── 17-消息队列整合：RabbitMQ/RocketMQ/Kafka + Spring
│   ├── 18-缓存与分库分表：Redis分布式缓存、缓存三大问题、Sharding-JDBC
│   └── 19-分布式定时任务：Spring Task、XXL-JOB
│
└── 层级4：微服务运维调优高级（P2，高级开发/架构师）
    ├── 20-容器化部署：Docker打包、Docker Compose、K8s基础
    ├── 21-性能调优：JVM/Tomcat/连接池/Feign调优
    ├── 22-线上故障排查：循环依赖/事务失效/内存泄漏/GC频繁
    └── 23-高可用架构：多集群、异地多活、限流降级兜底、接口幂等
```

## 3. P0/P1/P2 三级分级标准

| 级别 | 定义 | 包含内容 | 适用场景 |
|------|------|----------|----------|

## 4. 三条分层学习路线

### 🟢 路线一：入门业务路线（后端基础开发）
> 目标：实现单体项目CRUD开发

**学习范围**：仅 P0 内容
- 01-Spring IoC → 02-Spring AOP → 03-Spring事务 → 05-Spring MVC → 06-Spring Boot → 07-Spring Data

**预计时间**：2-3周
**产出**：可独立开发SpringBoot单体RESTful API项目

### 🔵 路线二：求职就业路线（微服务后端）
> 目标：掌握SpringCloud全套组件，覆盖90%企业面试与业务需求

**学习范围**：P0 + P1 全部内容
- 路线一全部 + 08-Security + 09~16-Spring Cloud全套 + 17~19-中间件整合

**预计时间**：6-8周
**产出**：具备独立开发分布式微服务系统的能力，通过中大厂后端面试

### 🟣 路线三：架构精通路线（高级开发/架构师）
> 目标：独立搭建、运维、调优分布式微服务架构

**学习范围**：P0 + P1 + 全部P2内容
- 路线二全部 + 20-容器化部署 + 21-性能调优 + 22-故障排查 + 23-高可用架构

**预计时间**：10-12周
**产出**：具备微服务架构设计、性能调优、生产故障排查能力
