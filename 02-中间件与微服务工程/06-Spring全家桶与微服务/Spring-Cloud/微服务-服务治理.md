# 微服务 - 服务治理

> **定位**：服务治理 = 解决微服务拆分后的协同难题。不治理 = 服务多了必乱、必崩。

---

## 1. 治理模块速览

```text
服务注册发现 → 负载均衡 → 熔断降级 → 配置中心 → 网关路由 → 监控追踪
     │              │          │          │          │          │
  Nacos/Eureka   Ribbon    Sentinel   Nacos/Config  Gateway  SkyWalking
```

---

## 2. 六大核心模块

### 2.1 服务注册与发现

| 组件 | 选型建议 |
|------|----------|
| **Nacos** ⭐ | 国内主流，注册+配置一体 |
| Eureka | 仅 Spring Cloud 原生老项目 |
| Consul | 跨语言、强一致性需求 |

### 2.2 负载均衡

| 组件 | 算法 |
|------|------|
| **Ribbon** | 轮询（默认）/ 权重 / 随机 / 重试 |
| **Spring Cloud LoadBalancer** | 新一代替代 Ribbon |

### 2.3 熔断与降级

| 组件 | 特点 |
|------|------|
| **Sentinel** ⭐ | 控制台可视化 + 动态配置 |
| Hystrix | ❌ 已停更 |
| Resilience4j | 轻量无依赖 |

### 2.4 配置中心

| 组件 | 动态更新 | 选型 |
|------|:----:|------|
| **Nacos Config** ⭐ | ✅ | 国内首选 |
| Apollo | ✅ | 中大型企业 |
| Spring Cloud Config | 需 Bus | 中小型 |

### 2.5 网关路由

| 组件 | 架构 | 推荐 |
|------|------|:--:|
| **Spring Cloud Gateway** | WebFlux 异步非阻塞 | ⭐ |
| Zuul | Servlet 同步阻塞 | ❌ |

### 2.6 监控与追踪

| 领域 | 工具 |
|------|------|
| 链路追踪 | SkyWalking / Zipkin |
| 系统监控 | Prometheus + Grafana |
| 日志聚合 | ELK（ES + Logstash + Kibana） |

---

## 3. 落地流程

| 步骤 | 操作 |
|:----:|------|
| 1 | 部署 Nacos Server（注册+配置） |
| 2 | 搭建 Gateway 网关 |
| 3 | 部署 SkyWalking + Prometheus + ELK |
| 4 | 微服务集成 Nacos Discovery + Config + Sentinel + Feign |
| 5 | 制定规范（命名/配置/接口/熔断规则） |
| 6 | 压力测试 + 故障演练 + 持续优化 |

---

## 4. 常见问题

| 问题 | 方案 |
|------|------|
| 注册失败 | 检查注册中心地址 + 服务名唯一 + 防火墙端口 |
| 熔断过度 | 核心 50% / 非核心 30% + 最小请求数 |
| 网关转发失败 | 路由 `lb://服务名` + Path 匹配正确 |
| 监控缺失 | Agent 配置 + Actuator 暴露端点 + 日志采集 |
