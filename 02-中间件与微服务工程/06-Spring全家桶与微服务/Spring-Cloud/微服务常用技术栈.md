## 1. 服务开发框架

| 语言 | 框架 | 特点 |
|------|------|------|
| **Java** ⭐ | Spring Boot + Spring Cloud | 最成熟，生态最完善 |
| Go | Gin + Kitex/Go-Micro | 高并发、轻量 |
| Python | FastAPI + Sanic | 快速迭代、AI 场景 |
| Node.js | Express + NestJS | 前后端联动、BFF 层 |

---

## 2. 注册发现

| 组件 | 架构 | 特点 | 推荐度 |
|------|:----:|------|:------:|
| **Nacos** | AP/CP 双模 | 注册+配置一体，国内主流 | ⭐⭐⭐ |
| **Consul** | CP | 强一致性，跨语言 | ⭐⭐ |
| Eureka | AP | 已停维护 | ⭐ |
| ZooKeeper | CP | 更多用于大数据 | ⭐ |

---

## 3. API 网关

| 组件 | 特点 | 适用 |
|------|------|------|
| **Spring Cloud Gateway** | 异步非阻塞，Spring 生态 | Java 微服务首选 |
| **APISIX** | 云原生，高性能 | K8s 容器化 |
| **Kong** | Nginx+Lua，跨语言 | 多语言混合 |
| Zuul | 同步阻塞，已停维护 | 仅老项目 |

---

## 4. 配置中心

| 组件 | 动态更新 | 多环境 | 适用 |
|------|:----:|:----:|------|
| **Nacos** ⭐ | ✅ | ✅ | 国内主流 |
| **Apollo** | ✅ | ✅ | 中大型企业 |
| Spring Cloud Config | 需配合 Bus | ✅ | 中小型 |
| Consul | ✅ | ✅ | 强一致性 |

---

## 5. 服务治理

| 领域 | 主流组件 | 替代 |
|------|----------|------|
| **熔断降级** | Sentinel | Hystrix(停更) / Resilience4j |
| **链路追踪** | SkyWalking | Zipkin / Jaeger |
| **监控** | Prometheus + Grafana | ELK |

---

## 6. 数据存储

| 类型 | 产品 | 适用场景 |
|------|------|----------|
| 关系型 | **MySQL** / PostgreSQL | 用户/订单/商品核心数据 |
| 缓存 | **Redis** | 热点数据、分布式锁 |
| 文档 | MongoDB | 非结构化数据 |
| 搜索 | Elasticsearch | 全文检索 |
| 分库分表 | Sharding-JDBC / MyCat | 千万级+数据 |

---

## 7. 消息队列

| 产品 | 特点 | 适用 |
|------|------|------|
| **RabbitMQ** | 轻量、可靠 | 中小型通用 |
| **RocketMQ** | 高吞吐、事务消息 | 电商/金融 |
| **Kafka** | 超高吞吐 | 日志/大数据 |

---

## 8. 容器化部署

| 工具 | 作用 |
|------|------|
| **Docker** | 容器化打包 |
| **Kubernetes** | 编排、扩缩容、自愈 |
| Jenkins/GitLab CI | CI/CD 自动化 |
| Helm | K8s 包管理 |

---

## 9. 技术栈组合推荐

| 规模 | 组合 |
|------|------|
| **中小型（Java）** | Spring Boot + Nacos + Gateway + Sentinel + MySQL + Redis + RabbitMQ + Docker |
| **中大型（企业级）** | Spring Cloud Alibaba + Apollo + APISIX + Seata + RocketMQ + K8s + SkyWalking |
| **Go 高并发** | Gin + Kitex + Nacos + APISIX + Kafka + K8s |
| **轻量级** | FastAPI/NestJS + Nacos + Gateway + MySQL + Redis + RabbitMQ |
