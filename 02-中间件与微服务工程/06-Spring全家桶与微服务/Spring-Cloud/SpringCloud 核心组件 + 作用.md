# Spring Cloud 核心组件 + 作用

> **记忆口诀**：Nacos 登记注册 → Feign 互相调用 → Gateway 统一入口 → Sentinel 保安限流 → Ribbon 负载均衡 → Seata 保证事务。

---

## 八大核心组件

| 组件 | 作用 | 解决什么问题 |
|------|------|------------|
| **Nacos** | 注册中心 + 配置中心 | 服务发现 + 统一配置管理 |
| **OpenFeign** | 声明式远程调用 | 像调本地方法一样调远程服务 |
| **Gateway** | 微服务网关统一入口 | 路由转发、鉴权、跨域、限流 |
| **Sentinel** | 限流、熔断、降级 | 防止服务雪崩 |
| **Ribbon** | 客户端负载均衡 | 多实例自动均匀分发请求 |
| **Seata** | 分布式事务 | 跨服务操作同时成功/回滚 |
| **Sleuth + Zipkin** | 链路追踪 | 追踪跨服务调用链路、定位慢/错 |
| **Spring Cloud Config** | 统一配置中心 | 集中管理配置，动态刷新 |

---

## 完整调用链路

```text
客户端 → Gateway（鉴权/路由）→ Nacos（服务发现）→ Feign（远程调用）
                                           ↓
                                     Sentinel（限流熔断兜底）
                                           ↓
                                     Seata（分布式事务）
```

---

## 面试标准回答

> Spring Cloud 核心组件主要有：**Nacos** 注册配置中心、**OpenFeign** 远程调用、**Gateway** 网关、**Sentinel** 限流熔断、**Ribbon** 负载均衡、**Seata** 分布式事务、**Sleuth** 链路追踪。它们分别解决微服务的服务发现、服务调用、统一入口、流量保护、负载均衡、分布式事务和链路监控问题。
