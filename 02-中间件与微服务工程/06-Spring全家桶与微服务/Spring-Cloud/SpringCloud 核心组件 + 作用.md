SpringCloud 核心组件 + 作用
1. Nacos（最核心）
    作用：注册中心 + 配置中心
    - 服务启动时把自己注册进来
    - 服务之间互相查找地址
    - 统一管理所有服务配置文件
2. OpenFeign
    作用：服务远程调用
    - 像调用本地方法一样调用别的服务
    - 底层自动发 HTTP 请求
    - 集成负载均衡
 3. Spring Cloud Gateway
    作用：微服务网关、统一入口
    - 所有请求先经过网关
    - 路由转发、负载均衡
    - 统一跨域、认证、日志、限流
4. Sentinel
    作用：限流、熔断、降级
    - 限制每秒请求数（限流）
    - 下游服务挂了，切断调用（熔断）
    - 出错返回友好提示（降级）
    - 防止服务雪崩
5. Ribbon
    作用：负载均衡
    - 一个服务启多个实例
    - 自动把请求均匀分发
    - 轮询、随机等策略
6. Seata
    作用：分布式事务
    - 保证跨服务操作：要么都成功，要么都失败
    - 例：创建订单 + 扣库存，必须同时成功/回滚
7. Sleuth + Zipkin
    作用：链路追踪
    - 一个请求经过了哪些服务
    - 哪一步慢、哪一步报错
    - 快速定位问题
8. SpringCloud Config
    作用：统一配置中心
    - 集中管理所有服务配置
    - 修改配置不用重启服务
    最简单记忆口诀（背这个）
    - Nacos 登记注册
    - Feign 互相调用
    - Gateway 统一入口
    - Sentinel 保安限流
    - Ribbon 负载均衡
    - Seata 保证事务
 
面试标准回答（你直接照着说）
SpringCloud 核心组件主要有：
Nacos 注册配置中心、OpenFeign 远程调用、Gateway 网关、Sentinel 限流熔断、Ribbon 负载均衡、Seata 分布式事务、Sleuth 链路追踪。
它们分别用来解决微服务的服务发现、服务调用、统一入口、流量保护、负载均衡、分布式事务和链路监控问题。
