# Dubbo

> **定位**：Apache Dubbo 是高性能 Java RPC 框架，主要用于微服务架构下的服务治理与通信。

---

## 1. 核心功能

| 功能 | 说明 |
|------|------|
| **服务发现** | 通过 Nacos/ZK/Consul 注册+发现服务 |
| **负载均衡** | 加权随机、加权轮询、最少活跃调用数优先 |
| **流量治理** | 超时、重试、限流降级、金丝雀发布、A/B 测试 |
| **监控可视化** | Dubbo Admin + Prometheus + Grafana |

---

## 2. 架构

```text
控制面：注册中心 + 流量管控 + Dubbo Admin
数据面：Provider（提供服务）←→ Consumer（消费服务） via RPC
```

---

## 3. 优势

| 优势 | 说明 |
|------|------|
| **高性能** | 默认协议在高并发场景表现出色 |
| **服务治理** | 发现/负载均衡/限流/链路追踪全功能 |
| **多语言** | 官方 Java + Golang SDK |
| **云原生** | 支持 K8s + Service Mesh 集成 |

---

## 4. 最佳实践

| 实践 | 说明 |
|------|------|
| 注册中心选型 | ZK 适合稳定场景，Nacos 适合动态配置 |
| 超时重试 | 配置合理超时 + 重试策略，避免雪崩 |
| 实时监控 | Dubbo Admin 关注服务运行状态 |
| 熔断降级 | Sentinel/Hystrix 为服务设置熔断 |
