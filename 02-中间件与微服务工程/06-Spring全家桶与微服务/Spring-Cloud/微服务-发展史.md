# 微服务 - 发展史

> **定位**：微服务发展史 = Java 技术栈演进史 = 从单体聚合到分布式拆分的思维变革史。

---

## 四个阶段

| 阶段 | 时间 | 核心特征 | Java 生态 |
|------|------|----------|-----------|
| **起源** | 2000 年前 | 单体困境、Socket 分布式尝试 | JSP + Servlet + JDBC |
| **萌芽** | 2000-2010 | SOA 架构（ESB + WebService） | Struts/SpringMVC + Hibernate/MyBatis |
| **兴起** | 2011-2015 | 微服务概念确立 | Spring Boot + Spring Cloud 发布 |
| **成熟** | 2016 至今 | 云原生融合、国产化 | Spring Cloud Alibaba + K8s + Docker |

---

## 1. 起源阶段（2000 年前）

| 特征 | 说明 |
|------|------|
| 架构 | 小型单体应用（JSP + Servlet + JDBC） |
| 痛点 | 代码耦合严重，修改一处影响全局 |
| 尝试 | Socket 手动通信实现模块交互（原始分布式） |

---

## 2. 萌芽阶段（2000-2010）

| 特征 | 说明 |
|------|------|
| 架构 | SOA（面向服务架构）+ ESB 服务总线 |
| 通信 | SOAP 协议、WebService |
| Java 突破 | Spring 崛起（IOC/AOP）、ORM（MyBatis/Hibernate） |

### SOA vs 微服务

| 维度 | SOA | 微服务 |
|------|-----|--------|
| 中心化 | ESB 服务总线 | 去中心化 |
| 服务粒度 | 较大 | 极细（单一职责） |
| 通信协议 | SOAP（复杂） | HTTP/JSON（简单） |

---

## 3. 兴起阶段（2011-2015）

| 里程碑 | 时间 | 意义 |
|--------|------|------|
| 微服务概念提出 | 2011 | Martin Fowler 定义 |
| **Spring Boot** | 2014 | 自动配置+内嵌容器，降低单个服务开发成本 |
| **Spring Cloud** | 2015 | 完整微服务治理方案（Eureka+Ribbon+Hystrix+Config） |
| Dubbo 开源 | 2012 | 阿里高性能 RPC 框架 |

---

## 4. 成熟阶段（2016 至今）

| 趋势 | 技术 |
|------|------|
| **云原生融合** | Docker + K8s（容器编排 + 自动扩缩） |
| **国产化替代** | Spring Cloud Alibaba（Nacos + Sentinel + Seata） |
| 链路追踪 | SkyWalking / Zipkin |
| 监控 | Prometheus + Grafana |
| 日志 | ELK |
| CI/CD | Jenkins + GitLab CI |
| 标准化 | RESTful / gRPC + DDD 领域驱动设计 |

---

## 核心启示

| 启示 | 说明 |
|------|------|
| **业务驱动** | 单体→SOA→微服务，每次升级都因业务痛点 |
| **生态支撑** | Spring Boot/Cloud 是微服务落地的核心前提 |
| **持续迭代** | 微服务不是终点，云原生+智能治理是未来方向 |
