# 微服务 - 服务注册与发现

> **定位**：微服务体系的"基石"——没有它，拆分后的微服务无法协同工作。核心：自动注册 + 按服务名发现 + 心跳续约。

---

## 1. 核心流程

```text
① 注册：微服务启动 → 向注册中心注册（服务名+IP+端口）
② 发现：调用方 → 通过服务名查询注册中心 → 获取可用实例列表
③ 续约：定期心跳 → 无心跳则剔除
```

---

## 2. Eureka vs Nacos

| 维度 | Eureka | Nacos |
|------|--------|-------|
| 功能 | 仅注册发现 | 注册+配置中心 |
| 架构 | AP（固定） | AP/CP 双模 |
| 性能 | 中小规模 | 大规模（上百服务） |
| 社区 | ❌ 已停更 | ✅ 持续更新 |
| 选型 | Spring Cloud 原生项目 | **国内主流首选** |

## 3. Nacos 实操

### 部署 Nacos Server

```bash
# 下载启动（默认端口 8848）
startup.cmd -m standalone
# 控制台：http://localhost:8848/nacos  nacos/nacos
```

### 微服务集成

```xml
<dependency>
    <groupId>com.alibaba.cloud</groupId>
    <artifactId>spring-cloud-starter-alibaba-nacos-discovery</artifactId>
</dependency>
```

```yaml
# bootstrap.yml
spring:
  application:
    name: order-service
  cloud:
    nacos:
      discovery:
        server-addr: localhost:8848
        namespace: dev
server:
  port: 8082
```

### Feign 调用

```java
@FeignClient(name = "user-service")
public interface UserFeignClient {
    @GetMapping("/user/{id}")
    User getUserById(@PathVariable("id") Long id);
}
```

## 4. 常见问题

| 问题 | 方案 |
|------|------|
| 注册失败 | 检查 server-addr + 服务名 + 端口 + 防火墙 |
| 调用失败 | 集成 Ribbon/LoadBalancer + 服务名大小写一致 |
| 下线后仍显示 | 正常 kill（非 kill -9）+ 缩短心跳超时 |
| 配置生效但注册失败 | 检查 `nacos-discovery` 依赖是否遗漏 |
