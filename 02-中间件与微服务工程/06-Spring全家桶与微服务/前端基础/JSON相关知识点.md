## 一、JSON 核心定义

JSON（JavaScript Object Notation，JavaScript 对象表示法）是一种轻量级、跨语言、纯文本的数据交换格式，并非编程语言。

**核心特点**：

| 特点 | 说明 |
|------|------|
| **简洁性** | 语法简洁，易于阅读和编写 |
| **可读性强** | 文本格式，人类和机器都易于理解 |
| **跨平台兼容** | 几乎所有主流编程语言都支持 JSON 的解析与生成 |
| **占用带宽小** | 相比 XML 更简洁，传输效率更高 |
| **广泛应用** | 接口数据传输、配置文件编写等场景 |

## 二、JSON 基本语法规则

JSON 语法严格，错误的语法会导致解析失败。

| 规则 | 说明 | 错误示例 | 正确示例 |
|------|------|----------|----------|
| **整体结构** | 对象 `{}` 或数组 `[]`，可嵌套 | — | `{}`、`[]` |
| **键值对规则** | 键（key）必须用双引号包裹 | `{name: "张三"}` | `{"name": "张三"}` |
| **分隔规则** | 多个元素用逗号 `,` 分隔 | `{"a":1,"b":2,}` | `{"a":1,"b":2}` |
| **符号规则** | 所有符号均为英文半角 | `{"name"："张三"}` | `{"name": "张三"}` |
| **注释限制** | JSON 不支持注释 | `{"name": "张三" // 姓名}` | 不允许注释 |

> **重要**：最后一个元素后不能加逗号（trailing comma），这是最常见的 JSON 解析错误。

## 三、JSON 数据类型

JSON 的值（value）仅支持以下 6 种数据类型：

### 类型速查

| 类型 | 说明 | 示例 |
|------|------|------|
| **字符串** `string` | 双引号包裹，支持转义字符 | `"name": "张三"` |
| **数字** `number` | 整数、浮点数，不支持 NaN/Infinity | `"age": 20`、`"score": 98.5` |
| **布尔值** `boolean` | 仅 `true` / `false`（小写） | `"isStudent": true` |
| **空值** `null` | 表示无值（小写，不是 undefined） | `"avatar": null` |
| **对象** `object` | `{}` 包裹，可嵌套 | `"user": {"name": "李四"}` |
| **数组** `array` | `[]` 包裹，值类型可混合 | `"hobbies": ["读书", "运动"]` |

### 示例

```json
{
  "name": "张三",
  "age": 20,
  "isStudent": true,
  "avatar": null,
  "scores": [98, 85, 92],
  "address": {
    "city": "上海",
    "area": "浦东"
  }
}
```

## 四、JSON 与 JavaScript 对象的区别

| 对比维度 | JSON | JavaScript 对象 |
|----------|------|----------------|
| **本质** | 纯文本（字符串），用于数据交换 | 编程语言中的对象，用于代码逻辑操作 |
| **键（key）** | 必须用双引号包裹 | 可省略引号，可用单引号、双引号 |
| **值（value）** | 仅 6 种 JSON 数据类型，无 `undefined` | 支持所有 JS 数据类型（含 `undefined`、函数） |
| **注释** | 不支持 | 支持 `//` 单行注释、`/* */` 多行注释 |
| **结尾逗号** | 不允许（报错） | 允许（ES6+） |

## 五、JSON 的解析与序列化

JSON 的核心使用场景是"数据交换"，常需要在 JSON 字符串和编程语言对象之间转换。

### 1. 序列化（对象 → JSON 字符串）

将 JavaScript 对象转换为 JSON 字符串，用于传输（如接口请求）。

```javascript
const user = { name: "张三", age: 20, isStudent: true };
const jsonStr = JSON.stringify(user);
// 输出：{"name":"张三","age":20,"isStudent":true}

// 格式化输出（便于阅读）
const jsonStrFormat = JSON.stringify(user, null, 2);
// 第三个参数表示缩进空格数
```

### 2. 解析（JSON 字符串 → 对象）

将接收的 JSON 字符串转换为 JavaScript 对象，用于代码操作（如渲染页面）。

```javascript
const jsonStr = '{"name":"张三","age":20,"isStudent":true}';
const user = JSON.parse(jsonStr);
console.log(user.name); // 输出：张三
```

> **⚠️ 注意**：解析时 JSON 字符串必须符合语法规则，否则抛出语法错误。

## 六、常见错误与注意事项

| 错误 | 错误示例 | 正确示例 |
|------|----------|----------|
| 键未用双引号 | `{name: "张三"}` | `{"name": "张三"}` |
| 使用单引号 | `{'name': '张三'}` | `{"name": "张三"}` |
| 结尾加逗号 | `{"name": "张三",}` | `{"name": "张三"}` |
| 不支持的类型 | `{"func": function(){}}` | JSON 不支持函数 |
| 使用 NaN | `{"num": NaN}` | `{"num": 0}` |
| 中文乱码 | 编码不正确 | 确保编码为 UTF-8 |

## 七、JSON 的常见应用场景

| 场景 | 说明 | 示例 |
|------|------|------|
| **接口数据传输** | 前后端交互的核心格式 | 前端请求 → 后端返回 JSON → 前端解析渲染 |
| **配置文件** | 项目配置 | `package.json`、`vue.config.json` |
| **数据存储** | 本地存储 | `localStorage` 存储序列化的 JSON 字符串 |
| **跨语言数据交换** | 不同语言之间传递数据 | Java 后端 ↔ Python 脚本 ↔ 前端 JS |
