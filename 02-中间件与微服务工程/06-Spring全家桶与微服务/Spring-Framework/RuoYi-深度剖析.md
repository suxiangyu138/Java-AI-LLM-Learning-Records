## 1. 版本体系

| 版本 | 后端 | 前端 | 架构 | 适用 |
|------|------|------|------|------|
| **经典版** | Spring Boot + MyBatis | Vue 2 + Element UI | 单体半分离 | 快速开发、新手友好 |
| **Vue3 版** | Spring Boot + MyBatis-Plus | Vue 3 + Element Plus | 完全分离 | Vue3 新特性 |
| **Cloud 版** | Spring Cloud Alibaba | Vue 2 + Element UI | 微服务 | 分布式、大型系统 |
| **分离版** | Spring Boot + MyBatis | Vue | 前后端独立部署 | 前后端并行开发 |

## 2. 核心架构

### 2.1 后端分层

```text
接口层（Controller）
    │
核心业务层（system/generator/quartz/file）
    │
框架支撑层（framework）
    │
通用基础层（common）
```

| 模块 | 职责 |
|------|------|
| `ruoyi-common` | 通用工具类、异常处理、注解、常量 |
| `ruoyi-framework` | 框架核心：数据源、权限、安全、拦截器 |
| `ruoyi-system` | 核心业务：用户/角色/菜单/部门管理 |
| `ruoyi-generator` | 代码生成（可移除） |
| `ruoyi-admin` | 项目入口，集成所有模块 |

### 2.2 前端结构

| 目录 | 职责 |
|------|------|
| `api/` | 接口请求封装 |
| `components/` | 全局公用组件 |
| `directive/` | 权限指令 |
| `layout/` | 页面布局（侧边栏+顶部导航） |
| `router/` | 路由管理+动态路由 |
| `store/` | Vuex/Pinia 全局状态 |
| `views/` | 页面视图（按模块划分） |
| `utils/` | 工具类（request.js 封装 axios） |

### 2.3 登录交互流程

```text
前端提交登录 → Controller → Service 认证 → BCrypt 密码校验
→ 生成 JWT Token → 用户/权限信息存入 Redis → 返回 Token
→ 前端存储 Token → 每次请求携带 → permission.js 路由拦截校验
```

## 3. 核心技术栈

| 层级 | 技术 |
|------|------|
| **后端框架** | Spring Boot |
| **权限** | Spring Security / Shiro |
| **ORM** | MyBatis / MyBatis-Plus |
| **缓存** | Redis |
| **数据库** | MySQL（5.7+/8.0+）、PostgreSQL |
| **连接池** | Druid |
| **前端框架** | Vue 2/3 |
| **UI 库** | Element UI / Element Plus |
| **路由** | Vue Router |
| **状态管理** | Vuex / Pinia |
| **HTTP** | Axios |

## 4. 核心特性

### 4.1 RBAC 权限体系

```text
用户 → 角色 → 菜单 + 按钮权限
```

| 能力 | 说明 |
|------|------|
| 用户管理 | 增删改、禁用、关联部门/角色 |
| 角色管理 | 分配菜单权限 + 按钮权限 |
| 菜单管理 | 多级树形菜单，路由+图标配置 |
| 数据权限 | 按部门/角色过滤数据 |
| 安全增强 | 验证码 + 密码加密 + Token + 操作日志 |

### 4.2 代码生成器

| 能力 | 说明 |
|------|------|
| 多数据源 | MySQL/Oracle/PostgreSQL |
| 全链路生成 | Entity → Mapper → Service → Controller → Vue 页面 |
| 自定义配置 | 模块选择、命名规范、逻辑删除、分页 |
| 效率提升 | 基础编码时间缩短 80%+ |

### 4.3 系统监控

| 监控项 | 内容 |
|--------|------|
| 系统监控 | CPU/内存/磁盘/网络实时+历史 |
| 接口监控 | 调用地址/耗时/状态/参数 |
| 日志监控 | Logback 分级归档，后台直接查看搜索 |
| 在线用户 | 实时展示+强制踢出 |
| 缓存监控 | Redis 键值/命中率/手动清除 |

## 5. 优劣势与选型

### 优势

| 优势 | 说明 |
|------|------|
| 开箱即用 | 内置用户/权限/监控/代码生成 |
| 中文文档完善 | 社区活跃，issue 响应及时 |
| 权限体系完善 | RBAC 按钮级+数据权限 |
| 技术栈主流 | Spring Boot + Vue |
| 免费开源 | Apache License 2.0 |

### 局限性

| 局限 | 说明 |
|------|------|
| 过度封装 | 高度自定义需改底层 |
| 大型项目瓶颈 | Cloud 版存在，但更适合中小型 |
| 样式固化 | Element UI 风格固定 |

### 版本选型

| 场景 | 推荐版本 |
|------|----------|
| 新手、中小型、快速原型 | 经典版 |
| 追求 Vue3 新特性 | Vue3 版 |
| 分布式、大型系统 | Cloud 版 |
| 前后端独立部署 | 分离版 |
