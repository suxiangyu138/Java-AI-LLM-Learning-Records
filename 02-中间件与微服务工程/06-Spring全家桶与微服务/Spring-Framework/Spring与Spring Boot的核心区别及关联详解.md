# Spring 与 Spring Boot 的核心区别及关联详解

> **一句话**：Spring 是核心引擎，Spring Boot 是让引擎一键启动的加速器。不是替代关系，是从属+增强关系。

---

## 1. 核心定义

| 框架 | 定位 | 类比 |
|------|------|------|
| **Spring Framework** | 底层核心框架，提供 IoC/DI/AOP 基础能力 | 地基+核心建材 |
| **Spring Boot** | 快速开发脚手架，简化搭建和配置 | 精装房套餐（拎包入住） |

---

## 2. 10 个关键维度对比

| 维度 | Spring Framework | Spring Boot |
|------|-----------------|-------------|
| **本质** | 底层核心框架 | 快速开发工具 |
| **配置** | 大量 XML + 注解混合 | 约定优于配置，零 XML |
| **依赖管理** | 手动管理，版本冲突风险 | Starter 自动引入+统一版本 |
| **部署** | 外部 Tomcat，打 WAR | 内嵌服务器，打 JAR `java -jar` |
| **搭建效率** | 几十分钟以上 | 几分钟 |
| **学习门槛** | 高 | 低 |
| **扩展性** | 高度灵活 | 自动配置+自定义覆盖 |
| **适用规模** | 深度定制的大型项目 | 微服务、快速迭代（当前主流） |
| **生产准备** | 手动集成监控 | Actuator 开箱即用 |
| **核心目标** | 解决耦合和复杂性 | 简化开发流程 |

---

## 3. 关联关系

| 关系 | 说明 |
|------|------|
| **Spring Boot 依赖 Spring** | 底层仍是 Spring Framework |
| **Spring Boot 增强 Spring** | 自动装配 + Starter + 内嵌容器 |
| **可脱离 Boot 用 Spring** | ✅ 原生 Spring 独立开发 |
| **不能脱离 Spring 用 Boot** | ❌ Boot 必须引入 Spring 核心依赖 |

---

## 4. 常见误区

| 误区 | 纠正 |
|------|------|
| Boot 是 Spring 的新版本 | ❌ 不是替代，是封装增强工具 |
| Boot 项目不用学 Spring | ❌ 核心逻辑仍是 Spring（IoC/AOP/事务） |
| Boot 不能用 XML | ✅ 支持，只是不推荐 |
