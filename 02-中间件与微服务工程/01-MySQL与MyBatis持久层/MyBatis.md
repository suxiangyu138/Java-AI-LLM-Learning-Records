## 推荐书籍

### 1. 《MyBatis 核心技术全解与项目实战》

| 维度 | 详情 |
|------|------|
| **作者** | 赖帆（@谷哥的小弟） |
| **内容简介** | 从实际项目出发，详细介绍 MyBatis 开发环境、基本操作、运行原理、关联映射、动态 SQL、缓存机制、注解开发、插件技术、逆向工程以及 MyBatis-Plus。最后一章结合 Spring Boot 技术，详细介绍了 MyBatis 在项目实战中的应用 |
| **适合人群** | 初学者和有一定经验的开发者 |

### 2. 《Spring + Spring MVC + MyBatis 从零开始学（第 3 版）》

| 维度 | 详情 |
|------|------|
| **作者** | 杨章伟 |
| **内容简介** | 全面讲解使用 SSM 进行 JavaEE Web 开发，以"学生选课管理系统"为主线，涵盖 MyBatis 基础、核心配置、动态 SQL、关联映射等内容，提供丰富的实战案例 |
| **适合人群** | SSM 框架初学者、Java Web 应用开发初学者、高等院校学生 |

### 3. 《MyBatis 从入门到精通》

| 维度 | 详情 |
|------|------|
| **作者** | 刘增辉（PageHelper 分页插件和通用 Mapper 原作者） |
| **内容简介** | 系统性讲解 MyBatis 的使用技巧和最佳实践，涵盖基础操作、高级特性、源码解析以及与 Spring 的整合 |
| **适合人群** | 从入门到进阶的开发者 |

---

## 总结与学习路径

| 阶段 | 推荐书籍 |
|------|----------|
| **入门** | 《MyBatis 核心技术全解与项目实战》 |
| **进阶** | 《MyBatis 从入门到精通》 |
| **SSM 全栈** | 《Spring + Spring MVC + MyBatis 从零开始学》 |

> **建议**：入门阶段打好 CRUD、动态 SQL、关联映射基础；进阶阶段深入缓存、插件、源码层面。
