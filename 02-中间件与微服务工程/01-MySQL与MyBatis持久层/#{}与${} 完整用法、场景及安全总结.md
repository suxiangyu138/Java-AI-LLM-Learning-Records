# #{} 与 ${} 完整用法、场景及安全总结

## 1. 核心区别对比

| 对比维度 | `#{}` | `${}` |
|----------|-------|-------|
| **底层实现** | `PreparedStatement`（预编译，`?` 占位） | `Statement`（字符串拼接） |
| **参数处理** | ✅ 自动识别类型、加引号、转义特殊字符 | ❌ 原样拼接，不加引号、不转义 |
| **核心用途** | 传递 SQL 中的**字段值**（WHERE/INSERT/UPDATE） | 拼接 SQL **结构**（表名、列名、ORDER BY） |
| **SQL 注入** | ✅ 无风险，自带防护 | ❌ 有风险，需手动防护 |
| **使用优先级** | ⭐⭐⭐ 优先使用 | ⚠️ 仅必要时使用 |

## 2. #{} 核心用法

> 底层通过 `PreparedStatement` 实现，**先预编译 SQL 再传参**，自带防注入。

### 单个参数

```xml
<select id="selectById" resultType="User">
    SELECT * FROM user WHERE id = #{id}
</select>
```

> 传入 `id=1` → `WHERE id = 1`；传入 `name='张三'` → `WHERE name = '张三'`（自动加引号）

### 多个参数（@Param）

```xml
<select id="selectByNameAndAge" resultType="User">
    SELECT * FROM user WHERE name = #{name} AND age = #{age}
</select>
```

```java
User selectByNameAndAge(@Param("name") String name, @Param("age") Integer age);
```

### 适用场景

| 场景 | 示例 |
|------|------|
| WHERE 条件值 | `WHERE id = #{id}` |
| INSERT 值 | `VALUES(#{name}, #{age})` |
| UPDATE 值 | `SET name = #{name}` |
| 所有传递具体参数值的场景 | 安全、通用 |

## 3. ${} 核心用法

> 底层通过 `Statement` 实现，**直接将参数原样拼接到 SQL**。

### 必用场景（仅 `${}` 可实现）

| 场景 | 示例 | 原因 |
|------|------|------|
| **动态表名** | `SELECT * FROM ${tableName}` | `#{}` 会加引号导致表名报错 |
| **动态列名** | `SELECT ${columns} FROM user` | 同上 |
| **动态排序** | `ORDER BY ${sortCol} ${dir}` | `#{}` 会转为字符串常量，排序失效 |

### 代码示例

```xml
<!-- 动态表名 -->
<select id="selectByTable" resultType="User">
    SELECT * FROM ${tableName} WHERE status = 1
</select>

<!-- 动态排序 -->
<select id="selectOrderBy" resultType="User">
    SELECT * FROM user ORDER BY ${sortCol} ${dir}
</select>
```

## 4. 安全注意事项

### ${} 的三重防护

| 防护措施 | 说明 |
|----------|------|
| **参数可控** | `${}` 的参数必须由后端逻辑生成，禁止直接使用用户原始输入 |
| **白名单过滤** | 对动态参数（排序字段、表名）设置白名单，非法用默认值替代 |
| **特殊字符转义** | 若必须接收用户输入，手动转义 `'`、`;`、`OR` 等 |

### #{} 无需额外防护

> 预编译 + 自动转义，直接使用，注意参数名与 Mapper 接口对应即可。

---

## 5. 核心使用原则

```text
① 优先使用 #{}：所有传递"具体字段值"的场景，一律用 #{}
② 谨慎使用 ${}：仅动态 SQL 结构时使用，且必须做好安全防护
③ 禁止滥用 ${}：不要用 ${} 传字段值（防注入）
④ 禁止用 #{} 拼结构：不要用 #{} 拼表名/列名（会加引号报错）
```
