# 数据库原理实验

## 课程概述
- **课程性质**：专业核心必修课（配套实验课）
- **适用专业**：计算机类各专业
- **开课学期**：与数据库原理理论课同步
- **考核方式**：实验报告 + 上机考核 + 综合项目

## 核心知识点

### 实验一：数据库与表的创建（DDL）
- 创建数据库
  - CREATE DATABASE 数据库名 CHARACTER SET utf8mb4（支持中文和emoji）
  - 字符集与排序规则(COLLATE)的选择
- 创建表与约束
  - 数据类型选择：INT/VARCHAR(N)/DATE/DECIMAL(M,D)/TEXT
  - 主键约束：PRIMARY KEY（自动NOT NULL + UNIQUE + 聚簇索引）
  - 外键约束：FOREIGN KEY(col) REFERENCES 父表(主键) ON DELETE CASCADE/SET NULL/RESTRICT
  - 唯一约束：UNIQUE（允许一个NULL，MySQL中允许多个NULL）
  - 非空约束：NOT NULL
  - 默认值：DEFAULT
  - CHECK约束：CHECK (age >= 0 AND age <= 150)（MySQL 8.0.16+强制）
  - AUTO_INCREMENT自增列
- 修改表结构
  - ALTER TABLE ADD/DROP/MODIFY/CHANGE 列名
  - ALTER TABLE ADD/DROP 约束（PRIMARY KEY/FOREIGN KEY/INDEX）
- 创建与删除索引
  - CREATE INDEX idx_name ON table(col)
  - CREATE UNIQUE INDEX（唯一索引）
  - 复合索引：CREATE INDEX ON table(col1, col2)
  - DROP INDEX idx_name

### 实验二：单表查询（DQL基础）
- 基本SELECT
  - SELECT 列名1, 列名2 FROM 表名
  - SELECT * FROM 表名（生产环境避免*，明确列出需要的列）
  - DISTINCT去重
  - AS别名（列别名和表别名）
- WHERE条件过滤
  - 比较运算符：=, <>, !=, >, <, >=, <=
  - 范围过滤：BETWEEN a AND b（闭区间[a,b]）
  - 集合过滤：IN (值1, 值2, ...)
  - 模糊匹配：LIKE（%匹配任意字符，_匹配单个字符）
  - 空值判断：IS NULL / IS NOT NULL（不能用=判断NULL）
  - 逻辑组合：AND（优先级高于OR，善用括号明确优先级）
- ORDER BY排序
  - ASC升序（默认），DESC降序
  - 多列排序：ORDER BY col1 DESC, col2 ASC
- 聚合函数与分组
  - COUNT（统计行数：COUNT(*)全部行，COUNT(列)忽略NULL）
  - SUM（求和）、AVG（平均）、MAX、MIN
  - GROUP BY分组（写在WHERE之后，HAVING之前）
  - HAVING对分组结果过滤（WHERE过滤行，HAVING过滤组）
  - SELECT执行顺序：FROM→WHERE→GROUP BY→HAVING→SELECT→ORDER BY→LIMIT

### 实验三：多表查询（DQL进阶）
- 连接查询
  - 内连接(INNER JOIN)：只返回两表匹配的行
    - 等值连接：ON a.id = b.id
    - 非等值连接：ON a.score BETWEEN b.low AND b.high（如分数对应等级）
  - 外连接
    - LEFT JOIN：左表全部行 + 右表匹配行（右表无匹配填NULL）
    - RIGHT JOIN：右表全部行 + 左表匹配行
    - FULL OUTER JOIN（MySQL不支持，用UNION + LEFT JOIN + RIGHT JOIN模拟）
  - 多表连接：JOIN链式连接多张表
  - 自连接：同一张表用不同别名连接（如员工表和上级，上级也在同一张员工表中）
- 子查询
  - 标量子查询：返回单值(SELECT MAX(score) FROM ...)
  - 列子查询：返回一列多个值(SELECT id FROM ... WHERE ...)
  - 行子查询：返回一行多列
  - 表子查询：FROM子句中使用子查询结果作为临时表
  - 相关子查询(EXISTS/NOT EXISTS)：外层每行传入内层执行
  - IN vs EXISTS的选择：内层结果集大用EXISTS，外层结果集大用IN
  - ALL/ANY/SOME：与比较运算符配合（>ALL、>ANY）
- 集合查询
  - UNION（合并去重）、UNION ALL（合并不去重，更快）
  - INTERSECT（交集，MySQL用INNER JOIN或IN模拟）
  - EXCEPT（差集，MySQL用LEFT JOIN...WHERE IS NULL或NOT IN模拟）

### 实验四：数据更新与视图（DML+DCL）
- INSERT插入
  - 单行插入：INSERT INTO 表(列1,列2) VALUES (值1,值2)
  - 多行插入：INSERT INTO 表 VALUES (值1,值2), (值3,值4), ...
  - INSERT...SELECT将查询结果插入另一表
  - INSERT IGNORE（忽略主键/唯一键冲突）
- UPDATE更新
  - UPDATE 表 SET 列=新值 WHERE 条件
  - 多表更新：UPDATE t1 JOIN t2 ON ... SET t1.col = t2.col WHERE ...
  - 安全更新模式：WHERE必须包含索引列（防止误全表更新）
- DELETE删除
  - DELETE FROM 表 WHERE 条件
  - TRUNCATE TABLE（快速清空整表，不可回滚，重置自增计数器）
  - DELETE与TRUNCATE的区别（DELETE是DML可回滚，TRUNCATE是DDL）
- 视图操作
  - 创建视图：CREATE VIEW 视图名 AS SELECT...
  - 视图的优点：简化复杂查询、提供安全层（隐藏敏感列）、逻辑数据独立性
  - 可更新视图的限制：单表、不含聚合函数/DISTINCT/GROUP BY/子查询
  - WITH CHECK OPTION：确保通过视图更新的数据满足视图的WHERE条件

### 实验五：权限管理与事务
- 用户与权限管理
  - 创建用户：CREATE USER '用户名'@'主机' IDENTIFIED BY '密码'
  - 授权：GRANT SELECT,INSERT ON 数据库.表 TO 用户
  - 撤销：REVOKE 权限 ON 数据库.表 FROM 用户
  - 查看权限：SHOW GRANTS FOR 用户
  - 角色管理（MySQL 8.0+）：CREATE ROLE → GRANT 权限 TO 角色 → GRANT 角色 TO 用户
- 事务操作
  - 事务开启：START TRANSACTION 或 BEGIN
  - 设置保存点：SAVEPOINT savepoint_name
  - 回滚：ROLLBACK（回滚整个事务）或 ROLLBACK TO savepoint_name
  - 提交：COMMIT（确认所有修改）
  - 事务的ACID特性验证实验
  - 脏读/不可重复读/幻读的演示（通过设置不同隔离级别）

### 实验六：数据库应用开发
- 编程语言连接数据库
  - Python + PyMySQL/MySQL Connector
    - 建立连接：pymysql.connect(host, user, password, database)
    - 创建游标：conn.cursor()
    - 执行SQL：cursor.execute(sql, params)（参数化防注入）
    - 获取结果：fetchone() / fetchall() / fetchmany(n)
    - 提交和关闭：conn.commit() / conn.close()
  - Java + JDBC
    - 加载驱动：Class.forName("com.mysql.cj.jdbc.Driver")
    - 建立连接：DriverManager.getConnection(url, user, password)
    - 预编译语句：PreparedStatement pstmt = conn.prepareStatement(sql)
    - 设置参数：pstmt.setString(1, value)
    - 执行查询/更新：executeQuery() / executeUpdate()
  - ORM框架（MyBatis/JPA/SQLAlchemy）基础使用
- SQL注入防护
  - 参数化查询/预编译语句（核心防御手段）
  - 输入校验与过滤
  - 最小权限原则
