## 1. 核心特性

| 特性 | 说明 |
|------|------|
| **极致性能** | 内存操作 + 单线程模型，QPS 10 万+ |
| **丰富数据结构** | 5 种基础 + 4 种扩展 |
| **原子性** | 所有命令原子，天然防并发 |
| **持久化** | RDB（快照）+ AOF（日志）可组合 |
| **高可用** | 主从 → 哨兵 → Cluster 三级递进 |
| **轻量** | C 语言开发，无依赖，低资源占用 |

## 2. 数据结构与应用场景

### 基础类型

| 类型 | 底层 | 核心命令 | 典型场景 |
|------|------|----------|----------|
| **String** | SDS | `SET/GET/INCR/SETNX` | 缓存、计数、分布式锁 |
| **Hash** | ziplist/dict | `HSET/HGET/HMSET` | 用户信息、商品详情 |
| **List** | ziplist/linkedlist | `LPUSH/RPUSH/BRPOP` | 消息队列、最新列表 |
| **Set** | intset/dict | `SADD/SINTER/SUNION` | 去重、标签、共同关注 |
| **ZSet** | zskiplist+dict | `ZADD/ZREVRANGE/ZINCRBY` | 排行榜、延迟队列 |

### 扩展类型

| 类型 | 核心命令 | 典型场景 |
|------|----------|----------|
| **Bitmap** | `SETBIT/BITOP` | 签到、在线状态 |
| **HyperLogLog** | `PFADD/PFCOUNT` | UV 统计（12KB 存千万级） |
| **GEO** | `GEOADD/GEORADIUS` | 附近的人/门店 |
| **Stream** | `XADD/XREADGROUP/XACK` | 高可靠性消息队列 |

## 3. 高级特性

| 特性 | 说明 |
|------|------|
| **事务** | `MULTI/EXEC/WATCH`，不支持回滚 |
| **Lua 脚本** | 原子执行多命令，减少网络开销 |
| **发布订阅** | `PUBLISH/SUBSCRIBE`，广播模式 |
| **管道** | 批量发送命令，减少 RTT |
| **内存淘汰** | `allkeys-lru`（推荐）/ `volatile-lru` / `noeviction` |

## 4. 高可用架构

```text
主从复制 → 哨兵模式 → Redis Cluster（递进关系）
  │           │              │
数据备份     自动故障转移    水平扩展+分片
```

| 架构 | 解决问题 | 适用 |
|------|----------|------|
| **主从复制** | 数据备份 + 读写分离 | 中小型 |
| **哨兵模式** | 自动故障转移 | 中型 |
| **Redis Cluster** | 水平扩展 + 海量数据 | 大型 |

## 5. 常见问题与解决方案

| 问题 | 方案 |
|------|------|
| **缓存穿透** | 布隆过滤器 + 空值缓存 + 参数校验 |
| **缓存击穿** | 互斥锁（SETNX）/ 永不过期 / 逻辑过期 |
| **缓存雪崩** | 随机过期时间 + 缓存预热 + 多级缓存 + 熔断 |
| **数据一致性** | 先更新 DB 再删缓存 / Canal binlog 异步同步 |
| **密码安全** | 复杂密码 + bind 限制 + 禁危险命令 |
