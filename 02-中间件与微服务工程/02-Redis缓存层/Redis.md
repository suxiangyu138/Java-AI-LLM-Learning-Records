# Redis 学习书籍推荐

| # | 书名 | 原名 | 作者 | 适合人群 |
|---|------|------|------|----------|
| 1 | **《Redis 实战》** | Redis in Action | Josiah L. Carlson | 新手 + 有经验者 |
| 2 | 《Redis 入门指南（第 2 版）》 | Redis for Beginners | Karl Seguin | 初学者 |
| 3 | 《Redis 4.x Cookbook 中文版》 | Redis 4.x Cookbook | 多位 Redis 专家 | 开发与运维 |
| 4 | **《Redis 深度历险》** | Redis Deep Dive | 钱文品 | 中高级开发者 |

> 《Redis 实战》：深入浅出 5 种数据类型 + 优化 + 扩展方法，最推荐的全能型教材。
