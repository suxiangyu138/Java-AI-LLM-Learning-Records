## 1. Docker 快速启动

```bash
# 单机
docker run -d --name zookeeper -p 2181:2181 \
  zookeeper:3.9

# 验证
echo stat | nc localhost 2181
```

### Docker Compose 集群

```yaml
version: '3'
services:
  zk1:
    image: zookeeper:3.9
    ports: ["2181:2181"]
    environment:
      ZOO_MY_ID: 1
      ZOO_SERVERS: server.1=zk1:2888:3888;2181 server.2=zk2:2888:3888;2181 server.3=zk3:2888:3888;2181
  zk2: ...
  zk3: ...
```

## 2. 二进制单机部署

```bash
wget https://archive.apache.org/dist/zookeeper/zookeeper-3.9.0/apache-zookeeper-3.9.0-bin.tar.gz
tar -xzf apache-zookeeper-3.9.0-bin.tar.gz -C /opt
cd /opt/apache-zookeeper-3.9.0-bin

# 配置文件
cp conf/zoo_sample.cfg conf/zoo.cfg

# zoo.cfg
dataDir=/var/lib/zookeeper
clientPort=2181
tickTime=2000
initLimit=10
syncLimit=5

# 启动
bin/zkServer.sh start
bin/zkServer.sh status     # standalone / leader / follower
```

## 3. 集群部署

```bash
# ⚠️ 生产集群必须是奇数台（≥3 台）— 过半存活原则

# 每台节点配置 myid
echo 1 > /var/lib/zookeeper/myid   # zk1
echo 2 > /var/lib/zookeeper/myid   # zk2
echo 3 > /var/lib/zookeeper/myid   # zk3
```

```properties
# zoo.cfg（三台相同，除了 myid）
tickTime=2000
dataDir=/var/lib/zookeeper
clientPort=2181
initLimit=10
syncLimit=5

# ⭐ 集群节点配置
server.1=zk1:2888:3888
server.2=zk2:2888:3888
server.3=zk3:2888:3888

# 端口说明：
#   2181: Client 连接端口
#   2888: Follower ↔ Leader 通信端口
#   3888: 选举通信端口
```

```bash
# 依次启动
bin/zkServer.sh start
bin/zkServer.sh status
# Mode: leader   (zk1)
# Mode: follower (zk2, zk3)
```

## 4. zoo.cfg 核心参数

| 参数 | 说明 | 推荐值 |
|------|------|:---:|
| `tickTime` | 基本时间单位（ms） | 2000 |
| `initLimit` | Follower 初始同步超时 = tickTime × N | 10（20s） |
| `syncLimit` | Follower 同步超时 = tickTime × N | 5（10s） |
| `dataDir` | 快照存储目录 | — |
| `dataLogDir` | 事务日志目录（⭐ 建议独立磁盘） | — |
| `clientPort` | 客户端连接端口 | 2181 |
| `maxClientCnxns` | 单 IP 最大连接数 | 60 |
| `autopurge.snapRetainCount` | 保留快照数量 | 3 |
| `autopurge.purgeInterval` | 自动清理间隔（小时） | 1 |

```bash
# ⭐ 快照与事务日志分离（提升性能）
dataDir=/data/zookeeper/snapshot         # 快照
dataLogDir=/data/zookeeper/translog      # 事务日志（独立磁盘！）
```

## 5. systemd 服务化

```ini
# /etc/systemd/system/zookeeper.service
[Unit]
Description=Apache ZooKeeper
After=network.target

[Service]
Type=forking
User=zookeeper
ExecStart=/opt/zookeeper/bin/zkServer.sh start
ExecStop=/opt/zookeeper/bin/zkServer.sh stop
Restart=on-failure
LimitNOFILE=65535

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload
systemctl enable --now zookeeper
```

### 常用运维命令

```bash
echo stat | nc localhost 2181      # 节点状态（leader/follower/client数）
echo mntr | nc localhost 2181      # 监控指标（Prometheus 可采集）
echo srvr | nc localhost 2181      # 服务器详细信息
echo conf | nc localhost 2181      # 配置信息
```

> 🎯 生产铁律：集群 ≥3 奇数台、事务日志独立磁盘、myid 必须正确、定期清理快照（`autopurge` 开启）。
