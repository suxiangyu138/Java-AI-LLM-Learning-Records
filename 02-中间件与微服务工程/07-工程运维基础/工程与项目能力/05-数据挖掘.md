# 数据挖掘

## 📌 定位
**课内选修 | 第二~三梯队 | 数据分析·用户画像·推荐系统**

数据挖掘是"从数据中淘金"的技术——关联规则、聚类分析、异常检测。它是大数据与AI之间的桥梁，推荐系统、用户画像、风控都离不开。

## 🎯 核心章节

### 1. 数据预处理（整个流程80%的工作量）
- **数据清洗**：缺失值(均值填充/删除/模型预测)、异常值(箱线图/IQR/3σ)、重复值
- **数据集成**：多源数据合并→相关性分析(剔除冗余属性)
- **数据变换**：归一化(min-max)、标准化(z-score)、离散化(分箱)、One-Hot编码
- **数据规约**：维度规约(PCA)+数量规约(采样/聚类质心)

### 2. 关联规则挖掘（⭐ 经典）
- **频繁项集**：支持度 Support(A) = 包含A的交易数/总交易数
- **关联规则**：置信度 Confidence(A→B) = Support(A∪B)/Support(A)
  - 提升度 Lift = Confidence(A→B)/Support(B) —— >1正相关、<1负相关
- **Apriori算法**：先验原理——频繁项集的子集也是频繁的→逐层搜索剪枝
- **FP-Growth**：FP-Tree压缩存储+分治——比Apriori快一个数量级
- **应用**：购物篮分析(啤酒和尿布)、推荐系统(看了A的人也看了B)

### 3. 分类
- **决策树**：信息增益(ID3)→增益率(C4.5)→基尼系数(CART)
- **随机森林**：Bagging+随机特征选择——抗过拟合利器
- **GBDT/XGBoost/LightGBM**：竞赛三件套——表格数据的王者
- **评估**：混淆矩阵→Precision/Recall/F1→ROC-AUC

### 4. 聚类
- **K-Means**：快速但需预设K——用肘部法/轮廓系数选K
- **DBSCAN**：密度聚类，自动发现任意形状——调参ε和minPts
- **层次聚类**：谱系图(Dendrogram)可视化——适合先探索数据再选聚类数

### 5. 推荐系统（⭐ 最实用的应用）
- **协同过滤**：
  - User-Based：相似用户喜欢的东西→推荐给你
  - Item-Based：和这个东西相似的东西→推荐（Amazon经典方案，更稳定）
- **矩阵分解（MF）**：SVD——User矩阵 × Item矩阵 = 评分矩阵
- **FM（因子分解机→DeepFM）**：融合特征交互+深度学习

### 6. 异常检测
- **统计方法**：3σ原则、箱线图(IQR)
- **孤立森林（Isolation Forest）**：异常点极易被孤立→随机切分找路径短的
- **应用**：信用卡欺诈检测、工业设备故障预警

## ✅ 学习建议
- 数据挖掘课内选修课优先选——直接衔接你的AI方向
- 重点学习：数据预处理+关联规则+推荐系统+分类评估
- 推荐教材：《数据挖掘：概念与技术》(Han&Kamber)——领域经典
- Kaggle是实践数据挖掘能力的最佳平台——Titanic入门，House Prices晋级
