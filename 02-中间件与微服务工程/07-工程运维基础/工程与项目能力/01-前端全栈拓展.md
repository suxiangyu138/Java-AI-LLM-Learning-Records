# 前端全栈拓展

## 📌 定位
**课外自学 | 第四梯队 | 后端+前端=独立开发能力**

后端工程师懂前端不是为了抢饭碗——而是能独立开发完整项目、与前端高效沟通、理解全链路性能优化。

## 🎯 核心章节

### 1. 现代前端框架选一个
- **React**（推荐）：Facebook出品，生态最大——JSX语法+函数组件+Hooks
- **Vue**：尤雨溪出品，中文友好——模板语法+响应式
- 后端选手推荐Vue——学习曲线更平缓，模板语法直觉
- 看团队用什么选什么——两个都差不多

### 2. Vue 3 核心概念（快速入门）
- **响应式数据**：`ref()`/`reactive()`——数据变了，UI自动更新
- **组件化**：`.vue` 单文件组件——template+script+style
- **生命周期**：onMounted(挂载后，发API请求)→onUnmounted(销毁前，清理定时器)
- **路由**：Vue Router——`/users/:id` → UserDetail组件
- **状态管理**：Pinia——替代Vuex，全局共享状态

### 3. 后端需要会的前端技能
- **HTTP 请求**：axios/fetch——发API请求、处理响应
- **表单处理**：输入校验、提交、错误提示
- **组件库**：Element Plus(Vue)/Ant Design(React)——直接用现成的
- **浏览器 DevTools**：Network抓包看API请求、Console.debug、Element检查DOM

### 4. 全栈项目能力
- **前后端分离项目**：Vue前端 + Spring Boot后端 + REST API + JWT认证
- **API 文档**：Swagger/ Knife4j——自动生成接口文档，前后端协作的依据
- **跨域配置**：后端CORS配置——开发时的标准配置
- **打包与部署**：Vue `npm run build` → 静态文件放Nginx，后端打jar包

## ✅ 学习建议
- 不需要深入学习前端——会用Vue/React写基本的CRUD页面即可
- 重点：能跑通前后端联调 + Network面板分析API调用
- 做一个完整项目：管理后台(Vue+Spring Boot+MySQL)——CRUD全栈闭环
