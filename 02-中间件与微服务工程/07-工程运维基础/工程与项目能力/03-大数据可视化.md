# 大数据可视化

## 📌 定位
**课外自学 | 第四梯队 | 数据分析展示·报表·AI结果呈现**

AI模型的结果需要"被看见"——训练曲线、特征分布、模型解释，这些都离不开可视化。同时数据分析报表也是很多业务的刚需。

## 🎯 核心章节

### 1. 可视化基础理论
- **视觉通道**：位置(Most effective)→长度→角度→面积→颜色→纹理(Least effective)
- **图表选型原则**：
  - 趋势→折线图、比较→柱状图、占比→饼图(≤5类)/堆叠柱状图
  - 分布→直方图/箱线图/小提琴图、关系→散点图/气泡图
  - 多维→平行坐标/雷达图/热力图
- **减少图表垃圾（Chartjunk）**：Tufte原则——数据墨水比最大化

### 2. Python 可视化（AI/数据分析用）
- **Matplotlib**：底层绘图库——一切可视化的基础
- **Seaborn**：统计图表——一行代码出漂亮的分布图/相关性热力图
- **Plotly**：交互式图表——可缩放、可hover、可导出HTML

### 3. Web 端可视化
- **ECharts（推荐）**：百度出品，Apache开源——配置式API、中文文档好
  - 折线图/柱状图/饼图/地图/仪表盘——几乎覆盖所有需求
- **D3.js**：数据驱动的SVG操作——灵活度最高但学习曲线陡
- **AntV/G2**：蚂蚁出品——图形语法，比ECharts更灵活

### 4. 大数据场景可视化
- **Grafana**：时序数据监控——Prometheus数据源+告警
- **Kibana（ELK）**：日志可视化——ES数据源
- **Superset**：BI报表工具——SQL查询→图表→Dashboard

### 5. AI 相关的可视化
- **TensorBoard**：训练曲线(loss/accuracy)、模型结构图、Embedding降维可视化
- **特征重要性图**：SHAP值瀑布图/蜂群图——解释模型为什么做这个预测
- **混淆矩阵热力图**：分类结果的直观展示

## ✅ 学习建议
- 最低要求：Excel/Matplotlib能做基本的数据探索可视化
- 主要精力放ECharts——Java后端出报表、大屏展示都用它
- 训练模型时TensorBoard/Weights&Biases是标配
