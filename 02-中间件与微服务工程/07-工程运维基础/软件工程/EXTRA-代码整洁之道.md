## 全书核心思想

| 原则 | 说明 |
|------|------|
| **童子军军规** | 让营地比来时更干净 — 每次签入都比签出更整洁 |
| **别重复自己（DRY）** | 重复是万恶之源，消除重复是第一重构目标 |
| **单一权责（SRP）** | 每个函数、每个类、每个模块只有一个修改理由 |
| **表达力** | 好代码读起来像好文章，意图清晰，不言自明 |
| **简单设计** | 通过测试 → 消除重复 → 表达意图 → 最少元素 |
