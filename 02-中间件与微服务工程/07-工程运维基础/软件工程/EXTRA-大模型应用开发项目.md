# 大模型应用开发项目

> 一份从入门到企业级的大模型应用开发项目清单，覆盖 **Java 后端 + 大模型（LangChain、RAG、Agent）**，全部贴合 Java、Spring Boot、Linux、Shell、Maven 技术栈，可直接落地做作品集。

---

## 项目分级概览

| 级别 | 周期 | 项目数 | 定位 |
|------|------|--------|------|
| 🟢 入门级 | 1～3 天 | 3 | 练手、理解核心概念 |
| 🟡 进阶级 | 1～2 周 | 3 | 企业级可用 |
| 🔴 企业级 | 2～4 周 | 3 | 毕设 / 作品集 |
| 🟣 高级 | 按需 | 2 | 创业级 / 实习项目 |

---

## 一、入门级（1～3 天完成）

适合快速上手，理解大模型应用开发的核心流程。

### 1.1 智能问答机器人（RAG 基础版）

| 维度 | 说明 |
|------|------|
| **功能** | 上传文档 → 向量化 → 检索 → 大模型回答 |
| **技术栈** | Spring Boot、LangChain4j、本地向量库（FAISS）、通义千问 / 豆包 API |
| **学习目标** | 理解 RAG 核心流程 |

### 1.2 代码助手（Java 代码生成 / 解释）

| 维度 | 说明 |
|------|------|
| **功能** | 输入需求 → 生成 Java 代码、解释代码、查找 Bug |
| **技术栈** | Spring Boot、大模型 API、Prompt 工程 |
| **学习目标** | 快速体验大模型调用与 Prompt 设计 |

### 1.3 智能简历解析器

| 维度 | 说明 |
|------|------|
| **功能** | 上传 PDF → 提取姓名、学历、技能、项目经历 |
| **技术栈** | Spring Boot、PDF 解析、大模型结构化输出 |
| **学习目标** | 掌握结构化数据提取，适合做简历筛选工具 |

---

## 二、进阶级（1～2 周完成）

具备企业级可用性，适合深入学习后端架构与 AI 集成。

### 2.1 企业知识库问答系统（完整 RAG）⭐

| 维度 | 说明 |
|------|------|
| **功能** | 文档管理、自动分片、向量化、检索增强、流式输出 |
| **技术栈** | Spring Boot、LangChain4j、Redis / MySQL、向量数据库（Milvus）、阿里云 / 腾讯云大模型 |
| **涉及领域** | 后端开发、微服务、缓存、数据库 |

### 2.2 智能客服系统（多轮对话 + 意图识别）

| 维度 | 说明 |
|------|------|
| **功能** | 用户提问 → 识别意图 → 查询知识库 → 自动回复 |
| **技术栈** | Spring Boot、Redis 会话管理、RAG、大模型 |
| **适用场景** | 电商 / 平台客服 |

### 2.3 任务执行 Agent（简单自动化）

| 维度 | 说明 |
|------|------|
| **功能** | 让模型调用工具（查数据库、调接口、执行 Shell） |
| **技术栈** | Spring Boot、LangChain4j、Tool Calling |
| **学习目标** | 理解 Agent 工作原理与工具调用机制 |

---

## 三、企业级（2～4 周完成）

适合作为毕业设计或作品集核心项目。

### 3.1 智能运维助手（Linux + Shell + 大模型）⭐

| 维度 | 说明 |
|------|------|
| **功能** | 自然语言查询服务器状态、日志分析、执行运维命令、告警通知 |
| **技术栈** | Spring Boot、Shell 调用、大模型、监控接口 |
| **亮点** | 深度贴合 Linux / Shell 技术栈，差异化优势明显 |

### 3.2 电商智能导购（商品推荐 + 问答）

| 维度 | 说明 |
|------|------|
| **功能** | 用户询问商品 → 检索商品库 → 生成推荐理由 |
| **技术栈** | Spring Boot、MySQL、RAG、大模型 |
| **适用场景** | 电商项目 |

### 3.3 智能家教（数学 / 编程答疑）

| 维度 | 说明 |
|------|------|
| **功能** | 题目拍照 / 输入 → 生成解题步骤 + 知识点讲解 |
| **技术栈** | Spring Boot、OCR、RAG、大模型 |
| **适用场景** | 在线教育方向 |

## 五、强烈推荐的 3 个项目

根据技术栈匹配度（Java、Spring Boot、Linux、Shell），以下三个项目最适合优先入手：

| 优先级 | 项目 | 推荐理由 |
|--------|------|----------|
| 🥇 | **企业知识库问答系统（RAG）** | 覆盖后端全栈能力：微服务、缓存、数据库、向量检索 |
| 🥈 | **智能运维助手** | 深度结合 Linux / Shell 技能，差异化竞争优势 |
| 🥉 | **任务执行 Agent** | 理解 Agent 核心原理，把握未来技术趋势 |
