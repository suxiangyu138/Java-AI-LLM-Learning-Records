# 软件工程概论

## 课程概述
- **课程性质**：专业核心必修课
- **适用专业**：计算机类各专业
- **开课学期**：大三学年
- **考核方式**：考试（闭卷）+ 实验 + 课程设计

## 课程目标
1. 掌握软件工程的基本概念和开发流程
2. 理解传统的结构化开发方法和面向对象开发方法
3. 了解软件项目管理的基本知识
4. 培养团队协作开发的能力

## 核心知识点

### 第一章：软件工程概述
- 软件危机及其原因
- 软件的定义与特点
- 软件工程三要素：方法、工具、过程
- 软件生命周期：问题定义→可行性研究→需求分析→概要设计→详细设计→编码→测试→维护

### 第二章：软件过程模型
- 瀑布模型：阶段间具有顺序性和依赖性，适合需求明确的项目
- 原型模型：快速构建可运行的原型以获取用户反馈
- 增量模型：分批逐步交付
- 螺旋模型：加入风险分析的迭代模型
- 敏捷开发：Scrum、极限编程(XP)、看板
- DevOps与持续集成/持续交付(CI/CD)

### 第三章：需求分析
- 需求获取方法：访谈、问卷调查、用例分析
- 结构化分析方法：
  - 数据流图(DFD)
  - 数据字典(DD)
  - 加工说明
- 面向对象分析方法：
  - 用例图（Use Case Diagram）
  - 用例描述

### 第四章：软件设计
- 概要设计（总体设计）：
  - 模块化设计（高内聚低耦合）
  - 面向数据流的设计方法：变换流与事务流
- 详细设计：
  - 结构化设计工具：程序流程图、盒图(N-S图)、PAD图
  - 面向对象设计：
    - 类图（Class Diagram）
    - 时序图（Sequence Diagram）
    - 设计原则（SOLID）：单一职责、开闭原则、里氏替换、接口隔离、依赖倒置
- 设计模式简介（23种GoF模式概述）

### 第五章：软件编码与实现
- 编程语言的选择
- 编码规范与代码审查
- 版本控制（Git基础）
- 持续集成（CI）

### 第六章：软件测试
- 测试的层次：单元测试→集成测试→系统测试→验收测试
- 白盒测试：
  - 逻辑覆盖（语句覆盖、判定覆盖、条件覆盖、路径覆盖）
  - 基本路径测试（控制流图、圈复杂度）
- 黑盒测试：
  - 等价类划分（有效等价类、无效等价类）
  - 边界值分析
  - 决策表测试
- 单元测试框架（JUnit/pytest等）
- 自动化测试与回归测试

### 第七章：软件维护
- 维护的类型：
  - 改正性维护（修bug）
  - 适应性维护（适应新环境）
  - 完善性维护（增加新功能）
  - 预防性维护（预防问题）
- 维护的困难与成本
- 软件再工程

### 第八章：软件项目管理
- 项目估算方法：
  - 代码行(LOC)估算
  - 功能点(FP)估算
  - COCOMO模型
- 进度计划：甘特图、PERT图（关键路径法）
- 人员组织与团队管理
- 风险管理（风险识别、风险分析、风险应对）
- 软件配置管理

## 重点难点
- **重点**：软件生命周期模型、需求分析方法、软件测试方法、设计模式
- **难点**：将理论应用于实际项目开发、设计模式的恰当选择

## 学习方法与建议
1. 结合实际项目学习（课程设计/大作业）
2. 学习使用UML工具（如PlantUML、StarUML）
3. 阅读经典书籍和开源项目设计文档
4. 团队合作中实践敏捷开发方法
