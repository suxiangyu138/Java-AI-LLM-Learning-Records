GitHub 常用核心词汇（必背）
一、仓库相关 Repository
- Repository (repo)：仓库（代码存放地）
- Public：公开
- Private：私有
- Fork：复制别人仓库到自己账号（不改原项目）
- Star：点赞/收藏
- Watch：关注（接收更新通知）
- Clone：克隆代码到本地
- Branch：分支
- Tag：版本标签
    二、代码提交相关
- Commit：提交（一次代码保存）
- Commit message：提交说明
- Push：推送到远程
- Pull：拉取代码
- Pull Request (PR)：提交合并请求（给原作者）
- Merge：合并代码
- Conflict：冲突
- Resolve：解决
- Revert：撤销提交
- Checkout：切换分支
    三、协作与讨论
- Issue：问题、bug、需求、讨论
- Open：创建/开启
- Closed：关闭（已解决）
- Comment：评论
- Review：代码审查
- Approved：通过审核
- Request changes：要求修改
- Assign：指派负责人
- Mention (@)：@某人
- Subscribe：订阅
- Unsubscribe：取消订阅
    四、项目文档与状态
- README：项目说明（最重要）
- License：开源协议
- Release：正式发布版本
- Draft：草稿
- Stable：稳定版
- Beta：测试版
- Latest：最新版
- Update：更新
- Fix：修复bug
- Feature：新功能
- Refactor：重构（不改功能）
- Docs：文档
- Style：格式/风格
- Test：测试
- Chore：杂项
    五、仓库管理
- Main/Master：主分支
- Develop：开发分支
- Origin：远程仓库默认名
- Upstream：源仓库（你fork的原项目）
- Contributor：贡献者
- Collaborator：协作者
- Owner：仓库所有者
- Organization：组织/团队
- Dependency：依赖
- Vulnerability：安全漏洞
    六、动作/状态动词
- Create：创建
- Delete：删除
- Edit：编辑
- Rename：重命名
- Search：搜索
- Filter：筛选
- Sort：排序
- Enable：启用
- Disable：禁用
- Protect：保护（分支保护）
- Hidden：隐藏
    七、常见缩写（GitHub必懂）
- PR = Pull Request
- WIP = Work In Progress 开发中
- LGTM = Looks Good To Me 没问题
- SGTM = Sounds Good To Me 同意
- TBD = To Be Determined 待定
- TODO：待做
- FIXME：待修复
- CI = Continuous Integration 持续集成
- CD = Continuous Deployment 持续部署
 
最常见句子翻译（一看就懂）
- This branch has no conflicts：分支无冲突
- Merge pull request：合并请求
- Close issue：关闭问题
- Signed commit：已验证提交
- Your branch is up to date：分支已是最新
- Can you review this PR?：能帮我审查这个PR吗？
- LGTM, merge it：没问题，合并吧
- Fix #123：修复第123号Issue
- Closes #123：关闭Issue 123
