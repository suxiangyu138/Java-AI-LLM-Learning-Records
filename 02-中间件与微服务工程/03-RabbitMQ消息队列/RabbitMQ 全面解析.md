## 1. 核心架构与组件

```text
Producer → Connection → Channel → Exchange → Queue → Consumer
                                          ↑
                                      Binding
                                          │
                                    Virtual Host
```

### 六大核心组件

| 组件 | 说明 |
|------|------|
| **Broker** | RabbitMQ 服务实例，接收/存储/转发消息 |
| **Producer** | 生产者，通过 Channel 发送消息到 Exchange |
| **Consumer** | 消费者，监听队列（推/拉模式） |
| **Exchange** | 路由器，四种类型适配不同场景 |
| **Queue** | 存储容器，FIFO，可配置持久化/排他/自动删除 |
| **Virtual Host** | 多租户隔离，独立命名空间 |

### 关键辅助组件

| 组件 | 说明 |
|------|------|
| **Connection** | TCP 连接，开销大，建议连接池 |
| **Channel** | 轻量信道，一个 Connection 多 Channel 复用 |
| **Binding** | 交换机↔队列关联规则 |

## 2. 消息流转机制

### 生产者侧

```text
建立 Connection → 创建 Channel → 声明 Exchange/Queue/Binding
→ 封装 Message → 指定 Exchange + RoutingKey → 发送
→ 匹配成功 → 队列存储
→ 无匹配 → 丢弃（或死信队列）
```

### 消费者侧

```text
建立 Connection → 创建 Channel → 监听队列
→ Broker 推送消息 → 业务处理 → ACK（删除消息）
→ 处理失败 → NACK（重新投递或死信）
```

### 三层确认机制

| 机制 | 保障范围 | 模式 |
|------|----------|------|
| **Publisher Confirm** | 生产者→Broker | 单条/批量确认 |
| **Publisher Return** | 无匹配队列时退回 | 感知消息无声丢弃 |
| **Consumer ACK** | 消费者→Broker | 自动确认/手动确认（生产必须手动） |

### 全链路持久化

| 层级 | 配置 | 说明 |
|------|------|------|
| 交换机 | `durable=true` | 元数据不丢失 |
| 队列 | `durable=true` | 队列+消息不丢失 |
| 消息 | `deliveryMode=2` | 写入磁盘 |

### 死信触发条件

| 条件 | 说明 |
|------|------|
| 消费者拒绝且不重新投递 | `NACK + requeue=false` |
| 消息 TTL 过期 | 到达过期时间未被消费 |
| 队列满 | 新消息挤掉旧消息 |

## 3. 交换机类型

| 类型 | 匹配方式 | 场景 |
|------|----------|------|
| **Direct** | `RoutingKey = BindingKey` 精确匹配 | 一对一、订单回调 |
| **Topic** ⭐ | `*`（单词）`#`（多词）模糊匹配 | 日志收集、多服务订阅 |
| **Fanout** | 无视 RoutingKey，全队列广播 | 公告推送、缓存刷新 |
| Headers | 消息头匹配 | 几乎不用 |

## 4. 优缺点

### 优点

| 优点 | 说明 |
|------|------|
| 高可靠 | 持久化+三层确认+死信，全链路不丢 |
| 灵活 | 四种交换机 + 插件化扩展 |
| 多协议 | AMQP + STOMP + MQTT |
| 多语言 | 几乎所有主流语言 SDK |
| 易管理 | Web 管理界面 + 命令行 |

### 缺点

| 缺点 | 说明 |
|------|------|
| 系统复杂度 | 需处理丢失/重复/顺序性/死信 |
| 可用性风险 | MQ 故障影响全链路 |
| 吞吐量 | 单机万级，不如 Kafka |
| Erlang 门槛 | 源码排查困难 |

## 5. 应用场景

| 场景 | 说明 |
|------|------|
| **服务解耦** | 订单→库存→物流→积分 异步联动 |
| **异步通信** | 注册后异步发邮件/短信 |
| **流量削峰** | 秒杀请求缓冲 |
| **分布式任务** | 批量处理、数据导出 |
| **IoT** | 设备状态上报，断网时本地缓存 |
