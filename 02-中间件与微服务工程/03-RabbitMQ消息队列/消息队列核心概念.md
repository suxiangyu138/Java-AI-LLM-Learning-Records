# 消息队列核心概念

> 消息队列 15 个核心术语速查。

| # | 概念 | 说明 |
|---|------|------|
| 1 | **生产者** | 发送消息的应用或服务 |
| 2 | **消费者** | 接收消息并处理的服务 |
| 3 | **Broker** | MQ 服务端，接收/存储/转发消息 |
| 4 | **消息** | 传输的数据载体（文本/JSON/对象） |
| 5 | **队列** | 点对点模式，FIFO，一条消息一个消费者 |
| 6 | **主题** | 发布订阅模式，一条消息多个消费者 |
| 7 | **交换机** | RabbitMQ 组件，按规则路由消息到队列 |
| 8 | **分区** | Kafka 并发单元，一个主题可分多个分区 |
| 9 | **偏移量** | Kafka 消费位置标记 |
| 10 | **确认机制** | 消费者处理后向 Broker 发 ACK |
| 11 | **持久化** | 消息存磁盘，防重启丢失 |
| 12 | **死信队列** | 无法正常消费的消息存放队列 |
| 13 | **延迟队列** | 指定时间后才可被消费 |
| 14 | **高可用** | 集群/主从/多副本，防单点故障 |
| 15 | **幂等性** | 重复消费结果只生效一次 |
