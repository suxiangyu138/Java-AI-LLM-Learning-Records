# 中间件专项

## 📌 定位
**课外自学 | 第一梯队 | 后端开发日常标配**

中间件是后端系统的"标准组件"——消息队列解耦、缓存提速、网关统一入口、ES支撑搜索。大厂面试必问，日常开发必用。

## 🎯 核心章节

### 1. Redis（⭐ 最重要的缓存中间件）
- **5 种基本数据结构 + 3 种高级**：
  - String：SDS动态字符串、embstr编码、incr原子操作——分布式锁
  - List：quicklist(3.2+)——消息队列、最新列表
  - Hash：dict+ziplist——对象存储
  - Set：无序去重——共同好友
  - ZSet：跳表(跳跃表)+dict——排行榜
  - HyperLogLog：UV统计，12KB存2^64去重
  - Bitmap：签到统计，极省空间
  - Geo：LBS附近的人
- **缓存三大问题+解决方案**：穿透(布隆过滤器)→击穿(互斥锁/逻辑过期)→雪崩(随机TTL/多级缓存)
- **持久化**：RDB(快照，fork子进程后台写)+AOF(操作日志，fsync策略)+混合持久化(4.0+)
- **高可用架构**：主从复制→哨兵(Sentinel，故障转移)→集群(Cluster，16384槽+去中心化Gossip)

### 2. 消息队列（MQ）
- **Kafka（⭐ 大数据/日志场景首选）**：
  - Topic→Partition→Segment(顺序写)——百万QPS的秘密
  - ISR(In-Sync Replica)+HW(High Watermark)——一致性保障
  - Consumer Group：同组内Partition独占——天然有序消费
  - 零拷贝：sendfile——数据从磁盘到网卡不经用户态
- **RocketMQ**：阿里系——事务消息(半消息+回查)+延迟消息+顺序消息
- **RabbitMQ**：AMQP标准——Exchange(交换器)+Queue+Binding(绑定)——灵活路由
- **MQ选型**：高吞吐→Kafka，事务/延迟→RocketMQ，路由灵活→RabbitMQ

### 3. Nginx / OpenResty
- **反向代理 + 负载均衡**：轮询/加权/IPHash/最少连接
- **静态资源 + 动静态分离**：动静分离，静态CDN直接返回
- **Lua 脚本（OpenResty）**：在Nginx层面做鉴权/限流/WAF——不经过后端服务
- **常用配置**：`location/upstream/proxy_pass/rewrite/return`

### 4. Elasticsearch（搜索引擎）
- **倒排索引**：Term→Posting List(文档ID列表)——搜索高效的根本
- **核心概念**：Index≈Database, Type(7.x废弃), Document≈Row, Field≈Column
- **分词器**：ik_max_word(细粒度索引)/ik_smart(粗粒度搜索)
- **查询DSL**：match(全文)、term(精确)、range、bool(must/should/must_not)
- **聚合分析**：bucket(分组)+metric(统计)——替代GROUP BY
- **ES+ Kibana+Logstash=ELK**：日志采集+存储+可视化分析

### 5. ZooKeeper / etcd（协调服务）
- **核心能力**：分布式锁+配置中心+服务注册发现+选主
- **数据模型**：类似文件系统的树形ZNode(持久/临时/顺序)
- **Watcher机制**：一次性的异步通知——数据变更时触发
- **ZooKeeper vs etcd**：Java生态→ZooKeeper(Dubbo/Hadoop依赖)，容器/K8s→etcd(Go语言+Raft更简洁)

### 6. 网关（API Gateway）
- **功能**：统一入口+鉴权+限流+路由+协议转换+日志
- **Spring Cloud Gateway**：WebFlux+非阻塞——Spring生态首选
- **Kong**：基于OpenResty+Nginx——插件丰富
- **Zuul**：Netflix老牌网关——1.x阻塞(已过时)，2.x非阻塞但已停更

## ✅ 学习建议
- Redis和Kafka是最重要的两个中间件——源码阅读从核心数据结构开始
- 搭建一个完整的中间件Demo项目：Spring Boot+Redis+Kafka+ES+Nginx
- 每个中间件回答三个问题：解决什么问题？核心原理？怎么保证高可用？
