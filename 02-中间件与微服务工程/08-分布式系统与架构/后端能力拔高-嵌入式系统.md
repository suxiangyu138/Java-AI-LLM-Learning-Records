# 嵌入式系统

> **优先级**：🟢 拓展选修 | **类型**：校内提升专业课 | **方向**：后端能力拔高·兴趣拓展

## 课程定位

**提升点**：嵌入式开发流程、交叉编译、RTOS 实时内核、资源受限环境编程、硬件抽象层设计

**适用人群**：对 IoT/边缘计算/端侧 AI 感兴趣、想理解软硬件协同、拓展技术广度

**学习目标**：能基于 ARM Cortex-M 开发嵌入式应用，理解 FreeRTOS 的任务调度和 IPC

---

# 第一章：嵌入式系统概述
- **定义与特点**：专用、资源受限（功耗/体积/内存）、高可靠性、实时性强
- **嵌入式系统组成**：处理器 + 存储器 + 外设接口 + 嵌入式软件（裸机/OS）
- **应用领域**：IoT、汽车电子（ECU）、工业控制（PLC）、消费电子、医疗器械
- **与通用计算机的区别**：单一任务 vs 多任务、ROM vs 硬盘、MCU vs CPU

# 第二章：嵌入式处理器
- **ARM Cortex-M 系列**：M0/M0+（超低功耗）→ M3/M4（DSP指令）→ M7（高性能）
- **ARM Cortex-A 系列**：A7/A53/A72——应用处理器，能跑 Linux
- **RISC-V**：开源指令集，国产替代重要方向
- **MCU vs MPU**：MCU（单片机，含 Flash+SRAM，跑 RTOS/裸机）vs MPU（应用处理器，需外接 DDR，跑 Linux）

# 第三章：嵌入式软件开发
- **交叉编译工具链**：arm-none-eabi-gcc / arm-linux-gnueabihf-gcc
- **裸机开发**：启动文件(Reset_Handler) + 链接脚本(.ld) + 寄存器操作——无 OS
- **HAL（硬件抽象层）**：STM32Cube HAL——屏蔽寄存器操作，提供统一 API
- **中断服务程序（ISR）**：响应快、尽量短，标志位通知主循环处理

# 第四章：RTOS 实时操作系统
- **FreeRTOS 核心**：
  - 任务调度：抢占式（高优先级就绪立即调度）+ 时间片轮转（同优先级轮流）
  - 任务状态：Running / Ready / Blocked / Suspended
  - 队列（Queue）：任务间通信——发送方放入，接收方取出，可阻塞等待
  - 信号量：Binary（互斥）/ Counting（资源计数）/ Mutex（含优先级继承防反转）
  - 软件定时器：在定时器服务任务中回调
- **uC/OS-III**：商业 RTOS，抢占式多任务、丰富的中间件

# 第五章：外设与接口
- **GPIO**：通用输入输出——LED、按键、继电器
- **UART/I2C/SPI**：串行通信三件套
- **ADC/DAC**：模数/数模转换——传感器数据采集
- **PWM**：脉宽调制——电机控制、LED 调光
- **DMA**：内存到外设的直接传输——释放 CPU

# 第六章：嵌入式 Linux
- **Buildroot / Yocto**：定制 Linux 根文件系统
- **设备树（Device Tree）**：描述硬件板级信息——`compatible` 字符串匹配驱动
- **字符设备驱动框架**：file_operations（open/read/write/ioctl）→ register_chrdev → 生成 /dev 节点

# 第七章：低功耗与可靠性
- **休眠模式**：Sleep → Stop → Standby 逐级降低功耗
- **看门狗（Watchdog）**：程序跑飞自动复位
- **双冗余（Dual-Bank）**：升级过程中保留旧版本，失败回滚
