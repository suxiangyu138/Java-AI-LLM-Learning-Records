## 3. 精通级学习路线

### 🟢 L1：理解分布式为什么难（半天）

```
01-分布式理论基石 → 分布式八大谬误
产出：能说清 CAP 是什么、为什么网络分区不可避免、BASE 如何妥协
```

### 🔵 L2：掌握核心算法与事务（1天）

```
01-一致性模型 → 02-共识算法(Raft) → 03-分布式事务
产出：理解 Leader 选举原理、能选型分布式事务方案
```

### 🟣 L3：熟悉基础设施组件（半天）

```
04-分布式协调 → 05-消息队列
产出：能用 ZooKeeper/etcd 实现分布式锁、理解 Kafka 架构
```

### 🟡 L4：架构设计能力（半天）

```
06-微服务架构 → 07-API网关与服务网格
产出：能设计微服务拆分方案、选型网关和服务网格
```
