# 第一章：网络安全基础

### 1.1 安全核心概念
- **CIA 三要素**：机密性（Confidentiality）、完整性（Integrity）、可用性（Availability）
- **AAA 框架**：认证（Authentication）+ 授权（Authorization）+ 审计（Accounting）
- **威胁建模 STRIDE**：伪装、篡改、否认、信息泄露、拒绝服务、权限提升
- **纵深防御（Defense in Depth）**：多层安全防护——不依赖单一防线

### 1.2 安全策略与模型
- **最小权限原则**：每个实体只拥有完成其任务所需的最小权限
- **职责分离**：关键操作需多人参与——防内部作恶
- **贝尔-拉帕杜拉模型（BLP）**：军事安全模型——不下读、不上写
- **Biba 模型**：完整性模型——不上读、不下写

# 第二章：密码学基础

### 2.1 对称加密
- **分组密码**：AES（128/192/256 位）——SPN 结构（字节代替→行移位→列混合→轮密钥加）
- **加密模式**：
  - ECB（电子密码本）：相同明文→相同密文，不安全
  - CBC（密文分组链接）：需随机 IV，前一个密文块 XOR 当前明文再加密
  - CTR（计数器模式）：计数器加密后 XOR 明文 → 可并行、可预计算
  - GCM：CTR + GMAC 认证——"认证加密"模式，最推荐
- **流密码**：ChaCha20——移动端和 TLS 1.3 推荐

### 2.2 非对称加密
- **RSA**：基于大整数分解——公钥(n,e)，私钥(n,d)，加密 C=M^e mod n
- **ECC（椭圆曲线）**：256位 ECC ≈ 3072位 RSA 安全性——移动端首选
- **混合加密**：非对称加密传递对称密钥 + 对称加密传输数据——HTTPS 的做法

### 2.3 哈希函数
- **SHA-256 / SHA-3**：单向、抗碰撞、雪崩效应
- **HMAC**：带密钥的哈希——`HMAC-SHA256(key, message)`——API 签名核心
- **密码哈希**：bcrypt / scrypt / Argon2——故意慢、自带盐——防彩虹表暴力破解

### 2.4 数字签名与证书
- **数字签名**：私钥签名 → 公钥验签——防否认 + 完整性校验
- **PKI（公钥基础设施）**：CA → 中间 CA → 终端证书——信任链
- **证书格式 X.509**：包含主体、颁发者、有效期、公钥、签名

# 第三章：Web 安全

### 3.1 OWASP Top 10 深度解析

**A01: 访问控制失效（Broken Access Control）**
- 水平越权：同权限用户查看/操作他人数据
- 垂直越权：低权限用户执行高权限操作
- 防御：每次请求验证操作者身份 + 资源归属

**A02: 加密失效（Cryptographic Failures）**
- 明文传输敏感数据、使用弱加密算法（MD5/SHA1/DES）
- 防御：TLS 1.2+ 全站加密、敏感数据 AES-256-GCM、密码 bcrypt 存储

**A03: 注入（Injection）**
- SQL 注入：拼接 SQL 字符串 → 参数化查询 / ORM
- 命令注入：拼接系统命令 → 不使用 shell 执行 / 白名单过滤
- LDAP/XML/NoSQL 注入同理

**A04: 不安全的设计（Insecure Design）**
- 缺少速率限制（暴力破解）、缺少输入校验
- 防御：威胁建模前置、安全设计 Review

**A05: 安全配置错误（Security Misconfiguration）**
- 默认密码未修改、错误信息泄露堆栈、不必要的功能开启
- 防御：安全基线、自动化配置检查

### 3.2 XSS（跨站脚本攻击）
- **反射型 XSS**：恶意脚本在 URL 中 → 立即反射执行
- **存储型 XSS**：恶意脚本存入数据库 → 其他用户浏览时执行
- **DOM 型 XSS**：客户端 JS 拼接用户输入
- **防御**：输出编码（HTML 实体转义）、CSP、HttpOnly Cookie

### 3.3 CSRF（跨站请求伪造）
- **攻击原理**：受害者已登录 A 网站 → 点击恶意链接 → 以受害者身份向 A 发请求
- **防御**：CSRF Token、SameSite Cookie（Strict/Lax）、Referer/Origin 校验

### 3.4 SSRF（服务端请求伪造）
- **攻击原理**：服务端根据用户输入发起请求 → 攻击内网
- **防御**：URL 白名单、禁止内网 IP（127.0.0.1/10.x/172.16-31/192.168）、禁用 file:// 等协议

# 第四章：认证与授权

### 4.1 认证（Authentication）
- **知识因素**：密码（弱密码检测 + 错误次数限制 + bcrypt 存储）
- **拥有因素**：OTP（TOTP/HOTP）、硬件 Token
- **生物因素**：指纹、面部——不可变更（泄露后麻烦大）
- **多因素认证（MFA）**：至少两个不同因素

### 4.2 OAuth 2.0 与 OIDC
- **四种授权模式**：授权码（最安全，服务端应用）、隐式（已废弃）、密码（自家前端）、客户端凭证（M2M）
- **OIDC（OpenID Connect）**：OAuth 2.0 之上的身份认证层——带 id_token（JWT 格式）
- **JWT 的安全注意事项**：Payload 不加密（只是 BASE64）、短有效期 + Refresh Token、签名算法防降级攻击

### 4.3 单点登录（SSO）
- **CAS 协议**：票据（TGT+ST）机制
- **SAML 2.0**：基于 XML 的安全断言标记语言——企业级 SSO

# 第五章：网络安全与协议安全

### 5.1 TLS/SSL
- **TLS 握手（ECDHE）**：ClientHello → ServerHello + 证书 → 密钥交换 → 加密通信
- **证书链验证**：证书签名验签链直到根 CA
- **TLS 1.2 vs 1.3**：1.3 简化握手（1-RTT）、去除不安全算法（RSA 密钥交换、CBC 模式）

### 5.2 DDoS 攻击与防御
- **SYN Flood**：半连接队列耗尽 → SYN Cookie
- **UDP 放大攻击**：DNS/NTP/Memcached 放大因子 50-50000+ → 源 IP 验证
- **HTTP Flood**：应用层资源耗尽 → WAF + CC 防护 + 速率限制

### 5.3 DNS 安全
- **DNS 劫持/投毒** → DNSSEC（签名验证） + DNS over HTTPS（DoH）
- **DNS 隧道**：通过 DNS 泄露数据——需监控 DNS 流量异常

# 第六章：数据安全与隐私

### 6.1 数据安全生命周期
- **创建 → 存储 → 使用 → 共享 → 归档 → 销毁**
- 每个阶段需考虑：分类分级（公开/内部/秘密/机密）、加密、访问控制、审计

### 6.2 数据脱敏
- **静态脱敏**：测试环境中替换真实数据
- **动态脱敏**：运行时根据权限决定脱敏程度——管理员看全量、客服看脱敏
- **脱敏方式**：替换、遮蔽（138****1234）、偏移取整

### 6.3 安全编码规范
- 永远不要信任用户输入
- 使用参数化查询（JDBC PreparedStatement / MyBatis #{} 而非 ${}）
- 敏感信息不入日志、不写死代码（KMS/环境变量）
- 最小权限（DB 账号只给需要的 CRUD 权限）
