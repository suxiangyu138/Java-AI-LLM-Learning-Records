# 第一章：实时系统基础
- **定义**：系统的正确性不仅依赖计算的逻辑结果，还依赖结果产生的时间
- **硬实时 vs 软实时**：硬实时（超时=失败，如刹车系统）vs 软实时（超时=质量下降，如视频播放）
- **时间约束类型**：周期任务（固定间隔）、偶发任务（最小间隔）、非周期任务（无规律）
- **WCET（最坏情况执行时间）**：任务在无中断情况下最长执行时间

# 第二章：实时调度理论

### 2.1 时钟驱动调度
- 预定义调度表——静态配置、简单、确定性强
- 适用于任务集固定且已知的场景

### 2.2 优先级驱动调度
- **RM（Rate Monotonic，速率单调）**：周期越小优先级越高——静态优先级中最优
  - 可调度性充分条件（Liu-Layland, 1973）：∑(C_i/T_i) ≤ n(2^(1/n)-1)，n→∞ 时利用率上限≈0.693
- **EDF（Earliest Deadline First）**：截止期越早优先级越高——动态优先级中最优
  - 可调度性充要条件：∑(C_i/T_i) ≤ 1.0（处理器利用率可达100%）
- **RM vs EDF**：RM 实现简单（固定优先级），EDF 利用率更高但截止期变化时需要重新计算

### 2.3 资源访问控制
- **优先级反转（Priority Inversion）**：高优任务等低优任务释放资源——Mars Pathfinder 经典事故
- **优先级继承协议（PIP）**：持有资源期间继承等待者的最高优先级
- **优先级天花板协议（PCP）**：给每把锁设置"天花板优先级"=所有可能请求该锁的任务的最高优先级
- **即时优先级天花板协议（IPCP）**：获取锁即提升到其天花板优先级——防死锁+防阻塞链

# 第三章：实时操作系统（RTOS）分析
- **任务调度**：抢占式 vs 非抢占式、Tick 中断驱动
- **中断延迟**：关中断最大时间 + 中断服务入口时间
- **调度延迟**：从中断返回到用户任务开始执行的时间
- **FreeRTOS 延迟分析**：configMAX_SYSCALL_INTERRUPT_PRIORITY 以上中断不被 OS 延迟

# 第四章：实时编程技术
- **避免不可预测的操作**：动态内存分配（malloc 时间不确定）、GC（STW）、虚拟内存（缺页中断）
- **锁无关数据结构**：RCU（Read-Copy-Update）、无锁队列——避免优先级反转
- **CPU 亲和性 + 中断亲和性**：把实时任务绑定到独占 CPU 核、隔离中断

# 第五章：实时网络与分布式实时系统
- **TSN（时间敏感网络）**：确定性以太网——IEEE 802.1Qbv 时间感知调度
- **分布式实时调度**：端到端截止期分解为各节点子截止期
- **FLINK/Apache Storm**：低延迟流处理——虽然不是硬实时，但在软实时大数据领域广泛使用

# 第六章：低延迟系统实践
- **内存屏障 + False Sharing 消除**
- **Busy-Wait 替代 Block-Wait**：关键路径上自旋而非上下文切换
- **大页（Huge Page）**：减少 TLB Miss
- **RDMA（远程直接内存访问）**：旁路 CPU 和内核，直接读写远端内存
