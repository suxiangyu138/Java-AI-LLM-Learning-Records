# 第一章：微型计算机基础

### 1.1 微型计算机系统组成
- **五大部件**：运算器（ALU） + 控制器（CU） + 存储器 + 输入设备 + 输出设备
- **三总线结构**：地址总线（AB，单向）、数据总线（DB，双向）、控制总线（CB）
- **微处理器（CPU）、微型计算机（CPU+存储器+I/O接口）、微型计算机系统（+外设+软件）**

### 1.2 数制与编码
- 二进制/十六进制间的快速转换
- 有符号数表示：原码 → 反码 → 补码（现代计算机统一使用）
- BCD 码（8421 码）、ASCII 码、奇偶校验码

### 1.3 计算机工作过程
- **取指→译码→执行** 循环
- 程序计数器（PC）→ 地址寄存器（MAR）→ 存储器 → 数据寄存器（MDR）→ 指令寄存器（IR）→ 控制器译码

# 第二章：微处理器体系结构

### 2.1 8086/8088 CPU 内部结构
- **EU（执行单元）**：ALU、通用寄存器（AX/BX/CX/DX）、标志寄存器（FLAGS）
- **BIU（总线接口单元）**：段寄存器（CS/DS/SS/ES）、IP（指令指针）、指令队列（6字节，流水线雏形）
- **分段机制**：物理地址 = 段基址 × 16 + 偏移地址（实模式下）

### 2.2 8086 寄存器组
- **通用寄存器**：AX（累加）、BX（基址）、CX（计数）、DX（数据）——均可拆分为 H/L
- **指针寄存器**：SP（栈指针）、BP（基址指针）
- **变址寄存器**：SI（源变址）、DI（目的变址）
- **段寄存器**：CS（代码段）、DS（数据段）、SS（堆栈段）、ES（附加段）
- **标志寄存器 FLAGS**：CF（进位）、PF（奇偶）、AF（辅助进位）、ZF（零）、SF（符号）、OF（溢出）、IF（中断允许）、DF（方向）、TF（陷阱）

### 2.3 现代 CPU 扩展
- **80286**：保护模式引入（寻址 16MB）
- **80386**：32位、虚拟 8086 模式、分页机制
- **x86-64（AMD64）**：64位扩展、16个通用寄存器

# 第三章：指令系统与汇编语言

### 3.1 寻址方式
- **立即寻址**：操作数在指令中——`MOV AX, 1234H`
- **寄存器寻址**：操作数在寄存器中——`MOV AX, BX`
- **直接寻址**：EA = 位移量——`MOV AX, [2000H]`
- **寄存器间接寻址**：EA = 寄存器内容——`MOV AX, [BX]`
- **基址+变址+位移**：`MOV AX, [BX+SI+100]`——最复杂最灵活的 x86 寻址

### 3.2 8086 指令集分类
- **数据传送**：MOV, PUSH, POP, XCHG, XLAT, LEA, LDS
- **算术运算**：ADD, SUB, MUL, DIV, INC, DEC, CMP, NEG
- **逻辑运算**：AND, OR, XOR, NOT, TEST, SHL/SHR（移位）
- **串操作**：MOVS, STOS, LODS, CMPS, SCAS + REP 前缀
- **控制转移**：JMP, JCC（条件跳转，共 18 条）, LOOP, CALL, RET, INT, IRET
- **处理器控制**：CLC/STC（清/置进位）, CLI/STI（关/开中断）

### 3.3 子程序与调用约定
- **CALL → 压栈返回地址 → 跳转**；RET → 弹栈返回地址 → 跳回
- **参数传递**：寄存器传参（快但数量有限）/ 栈传参（x86 cdecl/stdcall）

# 第四章：存储器系统

### 4.1 半导体存储器
- **SRAM**（静态）：6 个晶体管存 1 位——快但贵——用作 Cache
- **DRAM**（动态）：1 晶体管 + 1 电容——需要周期性刷新（2ms）——用作内存
- **ROM / EPROM / EEPROM / Flash**（非易失）

### 4.2 存储器与 CPU 的连接
- **存储芯片的地址线和数据线**与 CPU 地址总线/数据总线的连接
- **片选（Chip Select）**：高位地址线 + 译码器——选中不同的存储芯片
- **字扩展（地址线）vs 位扩展（数据线）vs 字位同时扩展**

### 4.3 Cache 基本原理
- **局部性原理**：时间局部性 + 空间局部性
- **地址映射**：直接映射（1路组相联）、全相联、组相联
- **替换策略**：LRU、FIFO、随机

# 第五章：输入输出与中断

### 5.1 I/O 接口
- **I/O 端口**：独立编址（x86 IN/OUT 指令）vs 存储器映射 I/O（ARM）
- **I/O 接口的结构**：数据寄存器 + 状态寄存器 + 控制寄存器

### 5.2 数据传送方式
- **无条件传送**：随时读/写——适用于简单设备（LED/开关）
- **程序查询**：CPU 不断读状态寄存器，直到设备就绪——CPU 利用率低
- **中断方式**：设备就绪时发中断 → CPU 响应 → 执行中断服务程序——CPU 无需等待
- **DMA（直接存储器存取）**：DMA 控制器接管总线，直接在设备和内存间传数据——CPU 只在开始/结束参与

### 5.3 中断系统详解
- **中断类型**：外部中断（INTR：可屏蔽，NMI：不可屏蔽）vs 内部中断（除法错误、INT n 指令）
- **中断向量表**：实模式下固定在 00000H，每个向量 4 字节（IP:CS）
- **中断响应过程**：完成当前指令 → 取中断类型号 n → FLAGS/CS/IP 入栈 → 关中断（IF=0）→ (n×4) 取向量 → 转入中断服务程序 → IRET 返回
- **中断优先级**：除法错 > INT n > NMI > INTR > 单步

### 5.4 常用可编程接口芯片
- **8259A（中断控制器）**：管理 8 级中断，可级联（两片=15 级）
- **8253/8254（定时/计数器）**：3 通道 16 位计数器——系统时钟、DRAM 刷新定时
- **8255A（并行接口）**：3 个 8 位端口——打印口
- **8251A/16550（串行接口）**：UART——RS-232 串口通信（COM 口）

# 第六章：总线技术

### 6.1 总线基础
- **系统总线**：数据总线 + 地址总线 + 控制总线
- **总线仲裁**：集中式（菊花链轮询/计数器定时/独立请求）vs 分布式
- **总线性能指标**：宽度（位数）× 频率 = 带宽

### 6.2 常见总线标准
- **ISA → PCI → PCI Express（PCIe）**：并行→串行点对点，PCIe ×16 带宽 = 16 × 8GT/s（Gen3）
- **USB**：通用串行总线，热插拔，树形拓扑
- **I2C**：双线（数据+时钟），低速板级通信
- **SPI**：四线（MOSI/MISO/CLK/CS），高速全双工
