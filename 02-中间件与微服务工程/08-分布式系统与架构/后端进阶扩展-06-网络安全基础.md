# 网络安全基础

## 📌 定位
**课外自学 | 第一~二梯队 | 每个后端开发的必备安全意识**

安全不是附加功能——从SQL注入到XSS到数据泄露，一个漏洞可能毁掉整个系统。理解常见攻击方式和防御手段是写出安全代码的前提。

## 🎯 核心章节

### 1. Web 安全（OWASP Top 10）
- **SQL注入（#1, ⭐）**：永远用参数化查询，绝不要拼字符串
- **XSS（跨站脚本）**：输出编码+HttpOnly Cookie+CSP策略
- **CSRF（跨站请求伪造）**：CSRF Token+SameSite Cookie+Referer校验
- **SSRF（服务端请求伪造）**：URL白名单+禁止内网IP+禁用file://协议
- **文件上传漏洞**：扩展名白名单+MIME校验+文件内容检测+存储隔离+病毒扫描
- **越权漏洞**：水平越权(同角色看别人数据)/垂直越权(低权限调用高权限接口)→每个接口校验操作者身份

### 2. 认证与授权
- **JWT（JSON Web Token）**：
  - 三段式：Header(BASE64) + Payload(BASE64) + Signature(HMAC-SHA256)
  - 注意：Payload不加密(只是BASE64)，绝不放敏感信息
  - 无状态→无法主动失效→配合黑名单/短有效期+Refresh Token
- **OAuth 2.0**：授权码模式(最安全)→隐式模式(已不推荐)→密码模式(自家里端)
- **SSO（单点登录）**：CAS(OAuth+票据)、JWT——一次登录多系统通行

### 3. 接口安全
- **签名校验**：防篡改——参数排序+拼接+MD5/HMAC+时间戳(防重放)
- **加密传输**：HTTPS(TLS 1.2+)全站加密——HSTS强制HTTPS
- **限流防刷**：接口级(验证码接口1分钟5次)+IP级+用户级——Sentinel/Redis实现
- **敏感数据脱敏**：手机号(138****1234)、身份证、银行卡——日志中也要脱敏

### 4. 密码学实战
- **密码存储**：绝对不要用MD5/SHA直接存！→bcrypt/scrypt/Argon2（自带盐+慢哈希）
- **AES加密**：GCM模式(认证加密)——密钥管理用KMS(云厂商/自建)
- **HTTPS原理**：证书链验证—公钥加密对称密钥—对称加密传输

### 5. DDoS 防御
- **SYN Flood**：SYN Cookie——不分配资源直到三次握手完成
- **HTTP Flood**：WAF+CC防护+iP频控+验证码
- **DNS放大攻击**：关闭DNS递归查询(非授权DNS)

## ✅ 学习建议
- 理解每类攻击的原理比看懂防御代码更重要——从攻击者角度思考
- 在GitHub上搜"OWASP WebGoat"——安全的靶场项目
- 密码存储用bcrypt，敏感配置放环境变量/KMS，接口加限流——三个最实用的习惯
