# 第7章 MyBatis 缓存配置
## 7.1 缓存概述
### 7.1.1 什么是 MyBatis 缓存
缓存就是**将查询结果临时存储**，下次查询相同条件数据时，**不再访问数据库**，直接从缓存读取，提升查询性能、减少数据库压力。

### 7.1.2 MyBatis 缓存分类
1. **一级缓存（本地缓存）**
- 默认开启，不可关闭
- 生命周期：**同一个 SqlSession** 内有效
- 级别：会话级缓存

2. **二级缓存（全局缓存）**
- 默认关闭，需手动配置开启
- 生命周期：**同一个 Mapper 命名空间** 下，跨 SqlSession 共享
- 级别：映射文件级缓存

---

## 7.2 一级缓存（默认开启）
### 7.2.1 工作机制
1. 第一次查询：发送 SQL 访问数据库，结果存入**一级缓存**
2. 同 SqlSession 、相同查询条件：第二次直接读缓存，不查库
3. 缓存 key：`sql语句 + 参数 + 分页条件` 组合唯一标识

### 7.2.2 一级缓存失效场景
满足任意一种，一级缓存清空、失效：
1. 执行 **增 / 删 / 改** 操作（本会话所有缓存清空）
2. 手动调用 `sqlSession.clearCache()` 清空缓存
3. 关闭、提交、回滚 SqlSession
4. 查询条件发生变化

### 7.2.3 代码演示
```java
// 同一个 SqlSession
SqlSession session = MyBatisUtil.getSqlSession(true);
UserMapper mapper = session.getMapper(UserMapper.class);

// 第一次：查数据库，存入一级缓存
User u1 = mapper.findById(1);
// 第二次：不走数据库，直接读取一级缓存
User u2 = mapper.findById(1);

System.out.println(u1 == u2); // true，同一个对象
```

## 7.3 二级缓存（全局缓存）
### 7.3.1 使用步骤
#### 步骤1：全局配置开启二级缓存
在 `mybatis-config.xml` 中配置：
```xml
<settings>
    <!-- 开启二级缓存总开关，默认true，显式配置便于理解 -->
    <setting name="cacheEnabled" value="true"/>
</settings>
```

#### 步骤2：在 Mapper XML 中开启当前命名空间缓存
在 **UserMapper.xml** 根标签下添加：
```xml
<!-- 开启当前Mapper二级缓存 -->
<cache/>
```

#### 步骤3：实体类实现序列化接口
二级缓存需要将对象序列化存储，实体类必须实现：
```java
public class User implements Serializable {
    // 字段、get/set、构造方法
}
```

### 7.3.2 工作机制
1. 第一次查询：查库，数据存入**二级缓存**
2. **关闭当前 SqlSession** 后，缓存数据生效
3. 不同 SqlSession 访问同一 Mapper、相同条件，共享二级缓存
4. 二级缓存存储在**命名空间级别**，不同 Mapper 缓存隔离

### 7.3.3 二级缓存失效场景
1. 当前命名空间下执行 **增删改**，自动清空该 Mapper 二级缓存
2. 手动清空缓存
3. 刷新、清空全局缓存

---

## 7.4 缓存执行顺序
查询执行优先级：
**二级缓存 → 一级缓存 → 数据库**
1. 先查二级缓存
2. 二级没有，再查一级缓存
3. 一级没有，最终访问数据库

---

## 7.5 一级缓存 VS 二级缓存

| 对比项 | 一级缓存 | 二级缓存 |
|--------|----------|----------|
| 生效范围 | 单个 SqlSession | 跨 SqlSession，同 Mapper 共享 |
| 默认状态 | 默认开启 | 默认关闭，手动配置 |
| 生命周期 | 会话关闭即销毁 | 长期共享，增删改刷新 |
| 存储位置 | 内存 | 内存/磁盘（序列化） |
| 适用场景 | 单次会话重复查询 | 多会话、高频重复查询 |

---

## 7.6 缓存使用注意事项
1. **频繁修改的数据 禁用二级缓存**
   如订单、库存、金额类数据，实时性要求高，缓存易造成数据脏读。
2. 二级缓存必须实现 `Serializable` 序列化
3. 增删改操作会自动刷新缓存，保证基础数据一致性
4. 多表关联复杂查询，不建议使用二级缓存
5. 企业开发中，**一级缓存默认使用，二级缓存很少手动开启**，一般用 Redis 做分布式缓存替代

---

## 7.7 本章核心知识点总结
1. MyBatis 缓存分为：**一级缓存、二级缓存**
2. 一级缓存：SqlSession 级别、默认开启、同会话共享
3. 一级缓存失效：增删改、手动清空、会话关闭
4. 二级缓存：Mapper 命名空间级别、需手动开启+序列化
5. 查询顺序：二级缓存 → 一级缓存 → 数据库
6. 实时性高的业务避免使用二级缓存
