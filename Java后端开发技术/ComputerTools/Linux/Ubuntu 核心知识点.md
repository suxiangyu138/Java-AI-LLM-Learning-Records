# Ubuntu 核心知识点
## 一、基础概述
1. **系统定位**
Ubuntu 基于 **Debian** 的开源 Linux 发行版，桌面/服务器双场景通用，默认内核为 Linux Kernel。
2. **核心特点**
免费开源、稳定安全、软件生态丰富、命令行+图形化双模式、权限隔离严格。
3. **用户体系**
- `root`：超级管理员，权限最高，默认禁止直接登录
- 普通用户：需`sudo`临时提权
- 组机制：多用户归属不同用户组，实现权限管控

## 二、文件系统结构（Linux 统一标准）
Ubuntu 遵循 Linux 树形根文件系统，根目录 `/` 为顶层：
- `/home`：普通用户家目录，个人文件存放
- `/root`：超级管理员家目录
- `/etc`：系统全局配置文件（核心）
- `/bin /sbin`：系统核心命令
- `/usr`：应用软件、库文件、帮助文档
- `/var`：动态文件（日志、缓存、数据库数据）
- `/tmp`：临时文件，重启自动清空
- `/dev`：硬件设备文件（磁盘、网卡、外设）
- `/mnt /media`：手动/自动挂载目录

## 三、权限管理（重中之重）
### 1. 权限格式
文件权限分为三类角色：**所有者(u)、所属组(g)、其他用户(o)**
权限：`r`读(4)、`w`写(2)、`x`执行(1)

### 2. 核心命令
```bash
# 修改文件权限
chmod 755 filename
# 修改文件所有者
chown 用户:组 文件名
# 临时管理员权限
sudo 命令
# 切换root
sudo su
```
### 3. 特殊权限
- 只读文件、目录执行权限（进入目录必需x权限）

## 四、核心常用命令
### 1. 文件操作
`ls`查看目录、`cd`切换目录、`pwd`查看当前路径
`mkdir`创建文件夹、`rm`删除、`cp`复制、`mv`移动/重命名
`touch`新建空文件、`cat`查看文件内容

### 2. 文本处理
`vim/nano`编辑器、`grep`内容搜索、`echo`输出内容

### 3. 系统信息
`uname -a`查看内核信息
`df -h`磁盘占用、`free -h`内存占用
`top`实时进程监控

### 4. 进程管理
`ps`查看进程、`kill`终止进程、`&`后台运行程序

### 5. 网络命令
`ip addr`查看网卡IP
`ping`网络连通性测试

## 五、软件包管理（APT 体系）
1. **包管理器**：`apt`（Ubuntu 标准）
2. 核心仓库配置：`/etc/apt/sources.list`
3. 常用操作
```bash
# 更新软件源索引
sudo apt update
# 升级所有已安装软件
sudo apt upgrade
# 安装软件
sudo apt install 软件名
# 卸载软件
sudo apt remove 软件名
```

## 六、服务与进程
1. 新版 Ubuntu 使用 **Systemd** 管理服务
2. 服务操作命令：
```bash
# 启动/停止/重启服务
systemctl start/stop/restart 服务名
# 设置开机自启
systemctl enable 服务名
```
常见服务：`ssh`、`mysql`、`nginx`

## 七、磁盘与挂载
1. 外接硬盘、U盘需要**挂载**才能访问
2. 手动挂载示例：
```bash
sudo mount /dev/sdb1 /mnt/usb
sudo umount /mnt/usb
```
3. 磁盘分区：`fdisk`

## 八、网络配置
1. 静态IP / 动态DHCP 双配置
2. 配置文件/图形化网络设置均可修改IP、网关、DNS
3. 远程连接：
- 开启 `openssh-server` 后，可通过 Xshell、FinalShell 远程登录

## 九、环境变量与脚本
1. 全局环境变量：`/etc/profile`
2. 用户个人环境变量：`~/.bashrc`
3. 可编写 **Shell 脚本** 实现自动化操作，后缀 `.sh`

## 十、日志与故障排查
- 系统日志默认存放：`/var/log/`
- 权限不足、命令不存在、网络不通、软件依赖缺失为高频问题
- 修复依赖：`sudo apt -f install`

## 十一、Ubuntu 关键特性补充
1. **桌面版 / 服务器版区别**
- 桌面版：带图形界面，占用资源高
- 服务器版：纯命令行，轻量化，生产环境首选
2. **防火墙**
默认`ufw`简易防火墙，可手动开启/放行端口
3. **镜像源**
默认国外源，国内需替换清华/阿里镜像源提升下载速度
