# DFS / BFS 核心总结 + Java通用模板
## 一、核心本质
1. **DFS（深度优先）**
一路到底，碰壁回溯；纵向搜索，**栈**（递归/手动栈）。
适合：枚举所有方案、连通块、回溯、树前后序、暴力搜索。
**缺点**：不保证最短路径，深度大易栈溢出。

2. **BFS（广度优先）**
层层扩散，按层遍历；横向搜索，**队列**。
适合：无权图**最短路径**、最少步数、层序遍历、多源扩散。
**优点**：首次到达终点就是最优解。

## 二、关键对比
| 特性 | DFS | BFS |
| :--- | :--- | :--- |
| 数据结构 | 栈（递归/Stack） | 队列（Queue） |
| 搜索顺序 | 深度优先 | 层次优先 |
| 最短路径 | 不保证 | 一定保证 |
| 访问标记 | 递归进入标记，回溯撤销 | 入队立即标记 |
| 代表题型 | 岛屿、子集、排列、回溯 | 单词接龙、迷宫、层序遍历 |

## 三、Java 通用模板
### 1. DFS 递归模板（最常用）
```java
// 伪代码框架
void dfs(int x, int y) {
    // 1. 边界终止条件
    if (越界 / 不合法) return;
    // 2. 标记已访问
    visited[x][y] = true;

    // 3. 遍历所有方向/邻接节点
    for(方向) {
        int nx = x + dx[i];
        int ny = y + dy[i];
        if(合法且未访问) {
            dfs(nx, ny);
        }
    }
    // 4. 回溯（需要枚举所有方案时才撤销）
    visited[x][y] = false;
}
```

### 2. DFS 迭代（手动栈，防溢出）
```java
Stack<Node> stack = new Stack<>();
stack.push(起点);
visited[起点] = true;

while(!stack.isEmpty()){
    Node cur = stack.pop();
    // 处理当前节点
    for(邻接节点 : 集合){
        if(合法且未访问){
            visited[邻接] = true;
            stack.push(邻接);
        }
    }
}
```

### 3. BFS 标准模板（最短路径专用）
```java
Queue<Node> queue = new LinkedList<>();
queue.offer(起点);
visited[起点] = true;
int step = 0;

while(!queue.isEmpty()){
    // 按层遍历
    int size = queue.size();
    for(int i = 0; i < size; i++){
        Node cur = queue.poll();
        // 到达终点，直接返回步数
        if(cur == 终点) return step + 1;

        for(邻接节点 : 集合){
            if(合法且未访问){
                visited[邻接] = true;
                queue.offer(邻接);
            }
        }
    }
    // 一层遍历完，步数+1
    step++;
}
```

## 四、刷题选择口诀
- 求**最短、最少步数、最小次数** → 无脑 BFS
- 求**所有方案、组合、排列、连通块** → 无脑 DFS
- 矩阵/网格类：两种都可，求最短用 BFS
- 数据量大、递归深度深 → 用迭代 DFS / BFS，避免栈溢出


## 五、深度优先搜索 DFS 应用场景

核心：一路走到底、回溯、穷举所有可能

**树与二叉树遍历**
前序、中序、后序遍历；二叉树路径总和、寻找根到叶子路径。

**连通性问题**
岛屿数量、封闭岛屿、最大连通面积、网格连通块统计。

**回溯类问题（高频）**
全排列、组合总和、子集、分割回文串、N 皇后、括号生成。

**图论问题**
无向图 / 有向图遍历、判断环、拓扑排序、寻找所有可达路径。

**暴力搜索 / 枚举**
所有可行方案枚举、迷宫全部路径查找。

**特殊场景**
深拷贝、文件系统深度遍历（遍历所有子文件夹）。


## 六、广度优先搜索 BFS 应用场景
核心：按层扩散、求最短、最少步数

**最短路径问题（核心优势）**
无权图最短路径、迷宫最短出口、单词接龙最短转换序列。

**树的层序遍历**
二叉树层序遍历、二叉树最大 / 最小深度、锯齿层序遍历。

**最少操作次数**
最小交换次数、最小变换步数、破解最少步骤类题目。

**多源扩散问题**
腐烂的橘子、地图多起点同时扩散、洪水填充。

**圈层 / 距离问题**
每个节点到起点的最短距离、01 矩阵距离、最近陆地。

**拓扑排序（广度写法）**
课程表、入度表拓扑排序，解决有向图依赖问题。
