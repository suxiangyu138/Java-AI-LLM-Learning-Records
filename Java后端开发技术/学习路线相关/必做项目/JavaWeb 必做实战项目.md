## 六、练手路线建议

1. **入门阶段**  
   - 先做原生 JavaWeb 项目  
   - 重点搞懂 Servlet 生命周期、请求转发 / 重定向、Session / Cookie、Filter 拦截链  

2. **进阶阶段**  
   - 吃透 SSM 整合  
   - 理解 IOC、AOP、事务、MyBatis 映射与动态 SQL  

3. **高阶阶段**  
   - 主攻 SpringBoot 前后端分离项目  
   - 掌握 RESTful API 设计、JWT、统一异常处理、权限控制、缓存  

4. **差异化阶段**  
   - 最后做 JavaWeb + AI 项目  
   - 把 Java 后端能力和 AI 应用能力整合到一个项目里
