# 大模型部署必做项目清单（入门 → 单机 → 分布式 → 工程化）

> 面向方向：Java后端开发 + 大模型应用工程  
> 核心目标：私有化部署、低成本落地、企业级工程能力  
> 覆盖能力：单机部署 → 容器化 → 推理加速 → API服务化 → 分布式集群

---

## 一、入门阶段（单机轻量化部署）

### 1. Ollama 本地大模型部署
**技术栈**：Ollama、CPU/GPU  

**核心知识点**
- 模型选型：Qwen / Llama3 / GLM / CodeLlama
- 模型拉取与版本管理
- 参数调优（temperature、context）
- 本地 API 调用（REST / SSE 流式）
- 跨域配置（CORS）

**核心能力**
- 一键私有化部署
- 本地对话 + API 服务
- 完全离线运行

**产出要求**
- 提供 API 调用 Demo（Java / curl）
- 支持流式输出

**预计耗时**：1 天

---

### 2. Transformers 原生推理部署
**技术栈**：Python、Transformers  

**核心知识点**
- AutoModel / AutoTokenizer 加载流程
- 权重下载与设备映射（CPU / GPU）
- 推理流程与生成参数控制
- 批量推理

**核心能力**
- 理解大模型底层运行机制
- 脱离封装框架完成推理

**预计耗时**：2 天

---

## 二、进阶阶段（容器化部署）

### 3. Docker 单模型部署
**技术栈**：Docker、Ollama / Transformers  

**核心知识点**
- Dockerfile 构建与分层优化
- 多阶段构建
- 数据卷挂载模型权重
- 端口映射与环境变量配置
- 日志与健康检查

**核心能力**
- 模型镜像化
- 环境隔离 + 跨机器迁移

**交付物**
- Dockerfile
- 启动脚本

**预计耗时**：2 天

---

### 4. Docker Compose 多模型部署
**技术栈**：Docker Compose  

**核心知识点**
- 多服务编排
- 服务依赖管理
- 网络隔离
- 持久化存储

**核心能力**
- 一键启动多个模型（通用 + 代码 + 向量）

**交付物**
- docker-compose.yml

**预计耗时**：2 天
