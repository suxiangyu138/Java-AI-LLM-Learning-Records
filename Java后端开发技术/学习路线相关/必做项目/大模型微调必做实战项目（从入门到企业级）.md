## 一、入门级：SFT 监督微调基础（夯实全流程）

### 1. 通用对话模型微调
**基座选型**：Qwen2.5 / Llama 3 / Mistral  
**微调方法**：LoRA（低秩适配）  

**核心知识点**
- 数据集格式：ShareGPT / Alpaca
- 数据清洗（去重 / 长度过滤 / 质量筛选）
- LoRA 参数配置（rank / alpha / target_modules）
- 训练超参调优（learning_rate / epoch / batch_size）
- 模型推理与对比测试

**实战目标**
- 微调后模型流畅中文对话
- 理解 SFT 完整流程（数据 → 训练 → 评估 → 部署）

**工具推荐**：LLaMA Factory 可视化界面[web:1]  
**预计耗时**：2~3 天

---

### 2. 单轮指令跟随微调
**任务类型**：翻译 / 摘要 / 改写 / 信息提取  

**核心知识点**
- 指令数据集构建（instruction / input / output）
- 少样本数据增强（GPT-4 辅助生成）
- 指令模板工程化
- 任务准确率评估

**实战目标**
- 精准执行用户指令
- 输出格式可控（JSON / Markdown）

**预计耗时**：2 天

---

### 3. Java/Python 代码生成微调
**基座推荐**：CodeQwen / DeepSeek-Coder  

**核心知识点**
- 代码数据集筛选（LeetCode / GitHub / Stack Overflow）
- 代码指令数据构造（问题 → 代码 → 注释）
- Pass@k 评估指标
- 代码补全 vs 生成任务区分

**实战目标**
- 生成可执行 Java/Python 代码
- 理解代码注释、调试能力微调

**预计耗时**：3 天

## 二、进阶级：高效微调 + 领域适配（企业高频场景）

### 4. 垂直领域知识微调（法律/医疗/教育）
**微调方法**：QLoRA（4bit 量化 + LoRA）  

**核心知识点**
- 领域语料爬取与清洗
- 4bit / 8bit 量化微调（降低显存需求）
- 领域术语词典构建
- 避免知识遗忘（Catastrophic Forgetting）

**实战目标**
- 输出专业术语准确
- 小样本场景高效训练

**预计耗时**：3~4 天

### 5. 企业私有知识库微调

**实战目标**
