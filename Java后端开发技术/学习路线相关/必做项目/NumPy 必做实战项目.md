# NumPy 实战项目清单

## 一、核心定位

NumPy 是 Python 科学计算与 AI 数据处理的底层基础库，核心能力集中在 **ndarray 多维数组、广播机制、向量化计算、统计分析、随机采样、线性代数**，这些也是后续 Pandas、机器学习、深度学习常用能力的底座。[web:17][web:23][web:22]  
结合你的路线，NumPy 不需要学成“数据分析专家”，而是要重点吃透 **数据预处理 + 矩阵运算 + 手写算法**，为后续机器学习、深度学习、Embedding、RAG 数据链路打基础。[cite:4][cite:9]

## 二、必做项目（求职优先级）

### 1. 数组基础操作工具集
**目标**：吃透 NumPy 最核心语法，建立数组思维。[web:17]

**实现**：
- 一维 / 二维数组创建
- `arange` / `linspace` / `zeros` / `ones` / 随机数组
- 索引 / 切片 / 布尔索引
- `reshape` / `flatten` / `transpose`
- 数组合并与拆分：`concatenate` / `stack` / `split`

**核心知识点**：
- `ndarray` 的 `shape`、`ndim`、`dtype`、`size`
- 广播机制
- 视图与拷贝
- 维度变换

**产出**：
- NumPy 基础操作能力

**耗时**：1~2天
