# JVM 必做项目清单（基础 → 内存模型 → 调优 → 故障排查 → 企业级实战）

---

## 一、入门必做（吃透 JVM 基础架构）

### 1. JVM 内存区域划分实战

**核心知识点**  
- 堆、栈、方法区 / 元空间、本地方法栈、程序计数器  
- 各区域作用与典型内存溢出场景  
- 虚拟机栈帧结构：局部变量表、操作数栈、常量池引用  

**核心功能**  
- 通过示例代码分别触发：堆 OOM、栈溢出、元空间 OOM  
- 可视化展示对象与栈帧的内存分布  

**预计耗时**：1 天  

---

### 2. 类加载机制与双亲委派模型

**核心知识点**  
- 类加载过程：加载 → 链接（验证 / 准备 / 解析）→ 初始化  
- 双亲委派模型原理、破坏双亲委派的典型场景  
- 自定义类加载器实现流程  

**核心功能**  
- 手写自定义 ClassLoader，加载指定路径 class  
- 打破双亲委派，实现特定类的自定义加载 / 热加载  

**预计耗时**：2 天  

---

### 3. 对象创建与内存布局

**核心知识点**  
- 对象创建完整流程（new → 分配 → 初始化）  
- 对象内存布局：对象头、实例数据、对齐填充  
- 指针压缩、对象大小计算  
- 逃逸分析、栈上分配、标量替换  

**核心功能**  
- 使用工具查看不同对象的内存布局与大小  
- 对比不同 JVM 参数（如关闭压缩指针）下对象内存占用  

**预计耗时**：1–2 天  

---

## 二、进阶必做（垃圾回收 + 内存模型）

### 4. 垃圾回收算法与 GC 种类对比

**核心知识点**  
- 标记–清除、标记–复制、标记–整理算法  
- 分代回收：年轻代 / 老年代 / 元空间  
- 常见 GC：Serial、Parallel、CMS、G1、ZGC 的核心原理与适用场景  

**核心功能**  
- 切换不同垃圾收集器运行同一程序  
- 观察和对比 GC 日志中的停顿时间、吞吐量  

**预计耗时**：2 天  

---

### 5. GC 日志分析实战

**核心知识点**  
- GC 日志参数配置与格式理解  
- Minor GC / Full GC 触发条件  
- 吞吐量、停顿时间、GC 频率分析方法  

**核心功能**  
- 通过 GC 日志定位垃圾回收瓶颈  
- 初步判断内存泄漏 / 内存溢出的风险  

**预计耗时**：2 天  

---

### 6. JMM 内存模型与 volatile 深度实战

**核心知识点**  
- 主内存 / 工作内存、内存屏障  
- volatile 的可见性与禁止指令重排语义  
- DCL 单例模式正确实现  
- happens-before 规则  

**核心功能**  
- 手写 demo 验证 volatile 可见性与重排序问题  
- 实现线程安全的单例与计数场景  

**预计耗时**：2 天  

---

## 三、核心必做（JVM 调优实战）

### 7. JVM 参数调优实战

**核心知识点**  
- 堆内存参数：`-Xms`、`-Xmx`、`-Xmn`  
- 元空间、栈内存、直接内存配置  
- GC 相关参数、逃逸分析、指针压缩开关  

**核心功能**  
- 针对具体业务（如 Web 服务）设计适合的 JVM 参数组合  
- 在压测下比较不同参数对 GC 停顿与吞吐量的影响  

**预计耗时**：2–3 天  

---

### 8. 内存泄漏排查实战

**核心知识点**  
- 内存泄漏常见场景：集合静态持有、大量缓存、不关闭资源、线程不退出等  
- 不同类型 OOM（堆、元空间、直接内存）的排查思路  
- `jmap`、`MAT` 等工具分析堆转储  

**核心功能**  
- 手工制造内存泄漏（如不断向静态集合添加对象）  
- 通过堆快照定位泄漏对象与引用链  

**预计耗时**：3 天  

---

### 9. 高并发下 JVM 调优

**核心知识点**  
- 高并发场景下的对象分配、TLAB、栈上分配  
- 锁升级路径：偏向锁 → 轻量级锁 → 重量级锁  
- 线程栈溢出、死锁排查与优化  

**核心功能**  
- 在压测环境下调节 JVM 与 GC，提升吞吐、降低停顿  
- 通过工具分析锁竞争与线程状态  

**预计耗时**：3 天  

---

## 四、企业级必做（线上故障排查 + 性能优化）

### 10. 线上 CPU 飙高排查实战

**核心知识点**  
- Linux 命令：`top`、`ps`、`jps`、`jstack`、`jstat` 等组合使用  
- 线程 Dump 分析方法  
- 死锁、死循环、热点代码定位  

**核心功能**  
- 模拟 CPU 飙高场景（死循环 / 频繁 GC）  
- 用工具一步步定位到具体问题代码  

**预计耗时**：2 天  

---

### 11. 频繁 Full GC 故障排查

**核心知识点**  
- 引起频繁 Full GC 的常见原因：大对象、堆太小、元空间溢出、内存泄漏等  
- 新生代向老年代晋升过快的根因  
- GC 参数不合理导致的频繁 Full GC  

**核心功能**  
- 通过 GC 日志 + 监控定位 Full GC 根因  
- 调整堆、对象分配策略、缓存策略给出优化方案  

**预计耗时**：2–3 天  

---

### 12. 接口响应慢全链路排查（JVM 视角）

**核心知识点**  
- GC 停顿、内存抖动  
- 线程阻塞（锁、IO）、线程池耗尽  
- 结合 Arthas 等工具实时观察 JVM 状态  

**核心功能**  
- 模拟接口慢 / 超时报错  
- 从 JVM 角度给出性能瓶颈定位与优化路径  

**预计耗时**：3 天  

---

### 13. 线上 JVM 监控体系搭建

**核心知识点**  
- 使用 Prometheus + Grafana 采集与展示 JVM 指标  
- 关键指标：堆 / 非堆使用、GC 次数与耗时、线程数、类加载数等  
- 告警策略：内存使用率、Full GC 次数、GC 停顿时间  

**核心功能**  
- 搭建完整 JVM 监控 dashboard  
- 根据监控数据提前发现问题趋势并预警  

**预计耗时**：3 天  

---

## 五、高阶必做（底层原理 + 新特性）

### 14. ZGC / Shenandoah 低延迟 GC 实战

**核心知识点**  
- ZGC 关键机制：染色指针、读屏障、并发压缩  
- Shenandoah 概念：并发标记与并发压缩  
- 低延迟 GC 参数配置与适用场景  

**核心功能**  
- 搭建使用 ZGC / Shenandoah 的运行环境  
- 对比 G1GC 与 ZGC 在延迟敏感场景下的停顿时间差异  

**预计耗时**：3 天  

---

### 15. JVM 字节码实战

**核心知识点**  
- 使用 `javap` 查看字节码与理解指令集  
- `synchronized`、`volatile`、`try-catch` 在字节码层面的实现  
- 方法调用（虚方法表、invokevirtual / invokestatic 等）  

**核心功能**  
- 对比不同写法在字节码层面的差异  
- 从字节码角度理解 JVM 执行逻辑与性能差异  

**预计耗时**：2 天

   - 平均响应时间 / P95 / P99  
4. 项目描述中突出：  
   - 线上故障排查能力  
   - 内存泄漏与 GC 调优经验
