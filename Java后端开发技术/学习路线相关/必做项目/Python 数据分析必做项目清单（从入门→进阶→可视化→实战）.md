## 五、必练核心知识点

### 1. Pandas 数据读写
```python
pd.read_csv()
pd.read_excel()
df.to_csv()
df.to_excel()
```

### 2. 数据清洗
```python
df.dropna()
df.fillna()
df.drop_duplicates()
df.astype()
df.replace()
```

### 3. 分组聚合
```python
df.groupby().agg()
df.pivot_table()
df.resample()
```

### 4. 时间序列
```python
pd.to_datetime()
df.set_index()
df.resample()
df.rolling()
```

### 5. 可视化
```python
# Matplotlib
plt.plot()
plt.bar()
plt.hist()
plt.scatter()

# Seaborn
sns.heatmap()
sns.boxplot()
sns.violinplot()
sns.pairplot()

# Pyecharts
from pyecharts.charts import Bar, Line, Pie, Map
```
