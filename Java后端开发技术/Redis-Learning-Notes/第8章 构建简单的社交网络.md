# 基于 Redis + Java 快速构建「极简社交网络」
定位：轻量社交核心能力，**完全依赖 Redis 做底层存储**，搭配 SpringBoot，实现：
用户注册、关注/取关、粉丝列表、好友列表、动态发布、时间线流、首页信息流
适合课程设计、练手项目、轻社交组件，**无ES、无复杂中间件**。

---

## 一、技术选型 & Redis 设计思想
### 核心技术
- SpringBoot + Redis
- 全部社交关系、动态、时间线 由 Redis 5大结构承载

### Redis 结构映射（社交核心）
| 业务功能 | Redis 结构 | Key 设计 |
|--------|-----------|----------|
| 用户信息 | Hash | `user:{userId}` |
| 我关注的人(关注列表) | Set | `follow:me:{userId}` |
| 我的粉丝 | Set | `fans:me:{userId}` |
| 发布动态 | List/String | `feed:content:{动态id}` |
| 个人时间线(自己+关注人动态) | ZSet/List | `timeline:{userId}` |

### 3. Redis 序列化配置
```java
@Configuration
public class RedisConfig {
    @Bean
    public RedisTemplate<String, Object> redisTemplate(RedisConnectionFactory factory) {
        RedisTemplate<String, Object> template = new RedisTemplate<>();
        template.setConnectionFactory(factory);
        StringRedisSerializer sk = new StringRedisSerializer();
        GenericJackson2JsonRedisSerializer jk = new GenericJackson2JsonRedisSerializer();
        template.setKeySerializer(sk);
        template.setHashKeySerializer(sk);
        template.setValueSerializer(jk);
        template.setHashValueSerializer(jk);
        return template;
    }
}
```

## 四、社交网络核心组件（完整可直接用）
### 1. 用户模块（Hash 存储）
```java
@Component
public class UserService {
    @Resource
    private RedisTemplate<String, Object> redisTemplate;

    // 注册/保存用户
    public void saveUser(User user) {
        String key = "user:" + user.getUserId();
        redisTemplate.opsForHash().put(key,"userId",user.getUserId());
        redisTemplate.opsForHash().put(key,"username",user.getUsername());
        redisTemplate.opsForHash().put(key,"avatar",user.getAvatar());
    }

    // 查询用户
    public Map<Object,Object> getUser(Long userId) {
        return redisTemplate.opsForHash().entries("user:" + userId);
    }
}
```

### 2. 关注 & 粉丝模块（Set 去重）
```java
@Component
public class FollowService {
    @Resource
    private RedisTemplate<String, Object> redisTemplate;

    // A 关注 B
    public void follow(Long userId, Long targetUserId) {
        // 我关注列表添加对方
        redisTemplate.opsForSet().add("follow:me:" + userId, targetUserId);
        // 对方粉丝列表添加我
        redisTemplate.opsForSet().add("fans:me:" + targetUserId, userId);
    }

    // A 取关 B
    public void unFollow(Long userId, Long targetUserId) {
        redisTemplate.opsForSet().remove("follow:me:" + userId, targetUserId);
        redisTemplate.opsForSet().remove("fans:me:" + targetUserId, userId);
    }

    // 获取我的关注列表
    public Set<Object> getFollowList(Long userId) {
        return redisTemplate.opsForSet().members("follow:me:" + userId);
    }

    // 获取我的粉丝列表
    public Set<Object> getFansList(Long userId) {
        return redisTemplate.opsForSet().members("fans:me:" + userId);
    }

    // 是否已关注
    public boolean isFollow(Long userId, Long target) {
        return Boolean.TRUE.equals(redisTemplate.opsForSet().isMember("follow:me:" + userId, target));
    }
}
```

### 3. 动态发布 + 时间线流（ZSet 按时间排序）
```java
@Component
public class FeedService {
    @Resource
    private RedisTemplate<String, Object> redisTemplate;

    // 发布动态
    public void publishFeed(Feed feed) {
        long time = System.currentTimeMillis();
        feed.setCreateTime(time);
        // 1. 保存动态详情
        redisTemplate.opsForValue().set("feed:content:" + feed.getFeedId(), feed);
        // 2. 写入自己的时间线
        redisTemplate.opsForZSet().add("timeline:" + feed.getUserId(), feed.getFeedId(), time);
    }

    // 拉取个人首页时间线（自己+关注人动态，按时间倒序）
    public Set<ZSetOperations.TypedTuple<Object>> getTimeline(Long userId, int limit) {
        return redisTemplate.opsForZSet()
                .reverseRangeWithScores("timeline:" + userId, 0, limit - 1);
    }

    // 获取单条动态详情
    public Feed getFeedInfo(Long feedId) {
        return (Feed) redisTemplate.opsForValue().get("feed:content:" + feedId);
    }
}
```

## 五、关键社交逻辑：关注人动态联动
新增补充方法，**关注某人后，自动拉取对方历史动态到自己时间线**：
```java
// 在 FollowService 追加
public void followWithFeed(Long userId, Long targetUserId) {
    follow(userId, targetUserId);
    // 把对方最近动态同步到我的时间线
    Set<ZSetOperations.TypedTuple<Object>> targetFeed =
            redisTemplate.opsForZSet().reverseRangeWithScores("timeline:"+targetUserId,0,20);
    for (ZSetOperations.TypedTuple<Object> tuple : targetFeed) {
        Long feedId = Long.valueOf(tuple.getValue().toString());
        double score = tuple.getScore();
        redisTemplate.opsForZSet().add("timeline:"+userId, feedId, score);
    }
}
```

## 六、完整业务调用示例
```java
@RestController
@RequestMapping("/social")
public class SocialController {
    @Resource
    private UserService userService;
    @Resource
    private FollowService followService;
    @Resource
    private FeedService feedService;

    // 注册用户
    @PostMapping("/register")
    public String register() {
        userService.saveUser(new User(1L,"张三","avatar1"));
        userService.saveUser(new User(2L,"李四","avatar2"));
        return "注册成功";
    }

    // 关注
    @PostMapping("/follow")
    public String follow() {
        followService.followWithFeed(1L,2L);
        return "关注成功";
    }

    // 发布动态
    @PostMapping("/publish")
    public String publish() {
        feedService.publishFeed(new Feed(1001L,2L,"今天学习Redis社交网络",System.currentTimeMillis()));
        return "发布动态成功";
    }

    // 查看首页信息流
    @GetMapping("/timeline")
    public Set<ZSetOperations.TypedTuple<Object>> timeline() {
        return feedService.getTimeline(1L,10);
    }
}
```
