# 二、我带你做 4 个最实用的 Redis 搜索组件
全部**可直接复制到项目**

## 1. 前缀搜索（最常用：联想提示）
比如输入：`sp`
返回：`spring, springboot, redis, spark`

### 实现：Redis 有序集合 ZSet
```java
@Component
public class RedisSearchComponent {

    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    // 初始化索引（项目启动时把商品名/用户名/文章名加入）
    public void initSearchKey(String keyword) {
        redisTemplate.opsForZSet().add("search:keywords", keyword, 0);
    }

    // 前缀搜索：输入 prefix，返回最多 10 条联想词
    public List<String> prefixSearch(String prefix, int limit) {
        String key = "search:keywords";
        Set<String> set = redisTemplate.opsForZSet()
                .rangeByLex(key,
                            ZSetOperations.Range.from(prefix),
                            ZSetOperations.Range.from(prefix + "z"),
                            0, limit);
        return new ArrayList<>(set);
    }
}
```

### 使用
```java
// 初始化关键词
searchComponent.initSearchKey("redis");
searchComponent.initSearchKey("redis教程");
searchComponent.initSearchKey("redis实战");
searchComponent.initSearchKey("springboot");

// 搜索：输入 red
List<String> result = searchComponent.prefixSearch("red", 10);
// 返回：redis、redis教程、redis实战
```

## 2. 模糊搜索（包含某个词）
输入：`教`
返回：`redis教程、Java教程、MySQL教程`

用 **Redis Keys 指令 + 前缀规范** 实现简单模糊
```java
public List<String> likeSearch(String keyword) {
    Set<String> keys = redisTemplate.keys("search:item:*" + keyword + "*");
    return keys.stream().map(k -> k.replace("search:item:", "")).toList();
}
```

适合小数据量、后台管理、简单搜索。

## 3. 热搜搜索（最常见功能）
用户每搜一次，分数+1，自动排行。

```java
// 搜索一次，热搜分+1
public void addHotSearch(String keyword) {
    redisTemplate.opsForZSet().incrementScore("hot:search", keyword, 1);
}

// 获取前 10 热搜
public List<ZSetOperations.TypedTuple<String>> getHotSearch(int top) {
    return new ArrayList<>(redisTemplate.opsForZSet()
            .reverseRangeWithScores("hot:search", 0, top - 1));
}
```

## 4. 完整搜索业务（最标准用法）
**Redis 存索引 → MySQL 存详情**

```java
public List<Item> searchItem(String keyword) {
    // 1. Redis 搜索关键词（前缀/模糊）
    List<String> ids = redisSearchComponent.prefixSearch(keyword, 10);

    // 2. 根据ID查MySQL
    return itemMapper.selectBatchIds(ids);
}
```

这就是**企业最常用的 Redis 搜索架构**！

# 三、我给你整合好的「Redis 搜索工具类」
直接复制进项目就能用
```java
@Component
public class RedisSearchUtil {

    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    // 添加关键词
    public void addWord(String word) {
        redisTemplate.opsForZSet().add("search:dict", word, 0);
    }

    // 前缀搜索（联想）
    public List<String> searchPrefix(String prefix, int maxCount) {
        Set<String> set = redisTemplate.opsForZSet().rangeByLex(
                "search:dict",
                ZSetOperations.Range.from(prefix),
                ZSetOperations.Range.from(prefix + "z"),
                0, maxCount
        );
        return new ArrayList<>(set);
    }

    // 增加热搜
    public void addHot(String word) {
        redisTemplate.opsForZSet().incrementScore("hot:search", word, 1);
    }

    // 获取热搜榜
    public List<String> getHotList(int topN) {
        Set<String> set = redisTemplate.opsForZSet()
                .reverseRange("hot:search", 0, topN - 1);
        return new ArrayList<>(set);
    }
}
```

# 四、1 分钟学会 Redis 搜索核心思想（必看）
Redis 搜索本质就 2 步：

1. **把所有要搜索的词提前放进 ZSet**
   `redisTemplate.opsForZSet().add(...)`

2. **用 rangeByLex 做前缀匹配**
   输入 `red` → 匹配所有 `red` 开头的词

这就是**最快、最简单、最稳定**的搜索方案。
