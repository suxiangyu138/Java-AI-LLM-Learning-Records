# Redis 核心知识点拓展
结合你前面做的：**缓存、分布式锁、限流、社交网络、搜索**，整套串联拓展核心原理，同时对应「降低内存」底层机制。

---

## 一、Redis 核心定位与架构基础
### 1. 核心特性
1. **单线程模型**：核心命令串行执行，无锁竞争、性能极高；
   网络IO、持久化、集群异步多线程。
2. **内存数据库**：数据默认放内存，读写纳秒级；支持磁盘落盘持久化。
3. **KV 非关系型**：无表、无SQL、高灵活，适合业务高速组件。
4. **多数据结构**：不止字符串，原生支持 8+ 种高级结构，是业务组件化的核心。
5. **原子命令**：单条命令/ Lua 脚本天然原子，轻松实现锁、限流、计数。

### 2. 核心使用边界
✅ 适合：缓存、计数器、限流、分布式锁、关系链、时间线、热搜、队列
❌ 不适合：大数据持久存储、复杂事务、海量长文本、结构化复杂查询

## 二、8 大基础数据结构 + 底层编码（内存优化关键）
### 1. 常用5种（你项目全覆盖）
| 结构 | 底层压缩编码 | 典型业务 |
|------|--------------|----------|
| String | int / embstr / raw | 缓存、计数器、验证码、配置 |
| Hash | ziplist / hashtable | 用户资料、对象存储 |
| List | quicklist | 简易队列、操作日志 |
| Set | intset / hashtable | 关注/粉丝、黑名单、去重 |
| ZSet | ziplist / skiplist | 时间线、排行榜、前缀搜索 |

### 2. 3种高阶结构
- **Bitmap**：位图，亿级签到、日活、状态标记（极低内存）
- **HyperLogLog**：超低内存 UV 统计、基数去重
- **Geo**：地理位置、附近的人（社交拓展必备）

### 3. 内存压缩核心规则（你之前降内存的原理）
1. 数值很小的**纯数字字符串**：自动用 `int` 编码，内存最小
2. 短字符串、小集合：`ziplist/intset` 紧凑连续存储
3. 数据量大、复杂内容：自动升级为 `hashtable/skiplist`，内存翻倍
> 开发优化原则：**尽量存数字ID、短key、小集合**，锁住底层压缩编码。

## 三、持久化机制（断电不丢数据）
### 1. RDB 快照
- 定时全量二进制快照，体积小、恢复快
- 缺点：会丢失两次快照之间的增量数据
- 适用：冷备份、快速恢复

### 2. AOF 日志
- 记录每一条写命令日志，逐条落地
- 实时性高、数据安全；文件体积大
- 重写机制 `bgrewriteaof` 压缩日志

### 3. 生产组合方案
- 缓存业务：**关闭持久化**（丢数据不影响，自动重建）
- 核心关系数据：RDB+AOF 混合

## 四、过期策略 + 内存淘汰（你降内存必懂）
### 1. 键过期删除三种方式
1. **惰性删除**：访问时才判断过期，省CPU、占内存
2. **定期删除**：定时抽样扫描过期key，平衡CPU/内存
3. **主动TTL**：业务手动设置过期（项目最优解）

### 2. 6大内存淘汰策略（maxmemory 满了触发）
1. `allkeys-lru`：全局最近最少淘汰（**通用推荐**）
2. `volatile-lru`：只淘汰带过期的key
3. `allkeys-lfu`：按访问频次淘汰
4. 随机淘汰、TTL优先淘汰等

> 你的社交项目配置：`maxmemory + allkeys-lru + 业务TTL` 三位一体控内存。

## 五、高性能核心原理
### 1. IO 多路复用
基于 epoll/kqueue，单线程处理万级并发连接，吞吐量极高。

### 2. 管道 Pipeline
批量合并命令，减少网络往返，批量写入性能提升数倍。

### 3. Lua 脚本
- 多条命令打包原子执行
- 解决分布式锁「删锁误删」、复杂限流、组合查询

## 六、高可用与集群
### 1. 主从复制

### 2. Sentinel 哨兵

## 七、企业高频经典问题（面试+实战）
### 1. 缓存三大问题
1. **缓存穿透**：恶意查不存在key → 布隆过滤器、空值缓存
2. **缓存击穿**：热点key过期瞬间并发打库 → 互斥锁、永不过期
3. **缓存雪崩**：大批量key同时过期 → 过期时间加随机偏移、集群隔离

### 2. 分布式锁核心要点
- 必须：`NX + EX 原子命令`
- 防误删：**锁值存唯一标识**，删除前校验
- 防死锁：自动过期
- 高可用：Redlock / 红锁

### 3. 热点Key & 大Key
- 大Key：超大集合、超长字符串 → 拆分、裁剪、冷热分离
- 热点Key：并发打爆单机 → 本地缓存、集群分片

1. 单线程+内存+多结构 = 高性能组件化神器
