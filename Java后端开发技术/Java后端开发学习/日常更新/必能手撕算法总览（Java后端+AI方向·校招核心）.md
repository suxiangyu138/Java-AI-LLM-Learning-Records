必能手撕算法总览（Java后端+AI方向·校招核心）
一、最高优先级（闭眼必背，100%必考）
1. 排序类
- 快速排序：分治+分区交换，不稳定，O(n\log n)
- 归并排序：分治+有序合并，稳定，O(n\log n)
2. 链表类
- 反转链表（迭代/递归）
- 合并两个有序链表
- 链表判环 + 环入口
- 快慢指针找链表中点
3. 二叉树类
- 前/中/后序遍历（递归+迭代）
- 层序遍历（BFS）
- 二叉树最大深度
- 对称二叉树
4. 基础算法模板
- 二分查找（基础/左右边界）
- 双指针（两数之和/三数之和）
 
二、第二优先级（笔试高频，面试加分）
1. 二叉树进阶
- 二叉树最近公共祖先
- 验证二叉搜索树
2. 回溯算法
- 子集、组合、全排列
3. 动态规划基础
- 爬楼梯、打家劫舍、零钱兑换
4. 滑动窗口
- 最长无重复子串、最小长度子数组
 
三、第三优先级（大厂进阶，拔高项）
- LRU 缓存（哈希表+双向链表）
- KMP 字符串匹配
- Dijkstra 最短路径
- 堆排序
- 拓扑排序
 
四、核心记忆规则
1. 排序认准 快排、归并；链表认准 反转、合并、判环
2. 二叉树优先掌握 遍历，递归写不出来就背迭代版
3. 二分、双指针、回溯是万能解题模板，必须熟练
4. 能手撕标准：不看资料，白板一次性写出完整无 Bug 代码
