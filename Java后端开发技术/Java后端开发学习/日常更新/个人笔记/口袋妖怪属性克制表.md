二、关键规则
- 双属性叠加：伤害=对属性1×对属性2（如火打草+虫=2×2=4倍）
- STAB：本系招式×1.5（如火系用火招）
- 免疫=0倍，效果绝佳=2倍，效果不好=0.5倍
