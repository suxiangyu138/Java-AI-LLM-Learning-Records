如何成为高能量人群
想成为“高能量”的人，核心不是一直亢奋，而是让自己长期保持精力充足、情绪稳定、行动有推进感。反过来，低能量通常来自睡眠差、拖延、过度消耗和长期内耗。
更高能量的做法
• 规律睡眠，尽量固定作息。
• 每天做一点运动，哪怕只是快走 20 分钟。
• 先完成最重要的事，减少一天开始时的犹豫。
• 保持房间、桌面、手机信息流的清爽。
• 少和总是抱怨、消耗你的人待太久。
• 多接触让你有创造感的人和事。
• 饮食别太极端，少靠高糖高刺激硬撑。
• 让目标足够清晰，做事时更容易进入状态。
容易变低能量的事
• 熬夜、睡眠紊乱。
• 长时间刷短视频、碎片信息过载。
• 同时做很多事，注意力被切得很碎。
• 总是担心结果，却不开始行动。
• 长期待在让你焦虑、压抑的关系里。
• 情绪压着不处理，慢慢变成疲惫感。
• 生活缺少运动、阳光和现实互动。
一个简单判断
如果你做完一件事后，感觉自己更清楚、更轻松、更有行动力，那这件事通常在给你充电。
如果你做完后更烦、更散、更空，那它大概率在耗你。
最实用的原则
先把这三件事做好，能量通常会明显改善：
1. 睡好。
2. 动起来。
3. 少接触持续消耗你的人和信息。
