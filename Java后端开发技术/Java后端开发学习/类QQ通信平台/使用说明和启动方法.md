# QQ Chat 使用说明和启动方法

> 类QQ企业级消息交互平台 · 命令行终端版 · 用户手册

---

## 一、快速开始

### 1.1 环境要求

| 要求 | 说明 |
|------|------|
| JDK | 21 或更高版本 |
| 操作系统 | Windows / Linux / macOS 均可 |
| 其他 | 无需任何第三方依赖 |

### 1.2 检查 Java 版本

打开终端（Windows 用 CMD 或 PowerShell），输入：

```bash
java -version
```

确保输出类似 `openjdk version "21"` 或更高。

### 1.3 编译项目

进入项目根目录，执行编译命令：

```bash
cd "D:\Desktop\MyLoacalReposity\Java-AI-LLM-Learning-Records\Java后端开发技术\Java后端开发学习\类QQ通信平台"

javac -encoding UTF-8 -d out -sourcepath src src/com/qqchat/server/QQServer.java src/com/qqchat/client/QQClient.java
```

> 编译成功后会在 `out/` 目录下生成 `.class` 文件，无任何输出即为成功。

### 1.4 启动服务端

打开 **第一个终端**，执行：

```bash
java -cp out com.qqchat.server.QQServer
```

输出示例：

```
============================================
  QQ Chat Server started on port 9999
  Data directory: D:\...\类QQ通信平台\data
  Max threads: 50
============================================
```

**可选参数：**

```bash
# 自定义端口
java -cp out com.qqchat.server.QQServer 8888

# 自定义端口和数据目录
java -cp out com.qqchat.server.QQServer 8888 my_data
```

> 服务端启动后 `data/` 目录会自动创建，用于存储用户数据、消息记录等。

---

### 1.5 启动客户端

打开 **另一个终端**，执行：

```bash
java -cp out com.qqchat.client.QQClient
```

输出示例：

```
============================================
  QQ Chat Client
  Connected to localhost:9999
  Type /help for available commands
============================================

1. Login
2. Register
3. Exit
Choice:
```

**可选参数：**

```bash
# 连接远程服务器
java -cp out com.qqchat.client.QQClient 192.168.1.100 9999
```

---

### 1.6 第一个账号

以注册新用户为例：

```
Choice: 2
Username: alice
Password: 123456
Nickname: 爱丽丝

Register successful. Welcome 爱丽丝!
```

然后启动另一个终端，再注册 `bob`，就可以开始聊天了。

## 二、命令速查表

### 2.1 命令行界面说明

```
>                           ← 全局模式提示符，在此输入命令
[alice]                     ← 聊天模式提示符，正在和 alice 聊天
[g_xxx]                     ← 群聊模式提示符，正在群聊中
```

### 2.2 所有命令一览

#### 认证

| 命令 | 示例 | 说明 |
|------|------|------|
| `/quit` | `/quit` | 退出客户端 |

#### 好友管理

| 命令 | 示例 | 说明 |
|------|------|------|
| `/addfriend` | `/addfriend bob` | 添加 bob 为好友 |
| `/delfriend` | `/delfriend bob` | 删除好友 bob |
| `/friends` | `/friends` | 查看好友列表和在线状态 |

#### 私聊

| 命令 | 示例 | 说明 |
|------|------|------|
| `/msg` | `/msg bob 你好啊` | 给 bob 发一条消息 |
| `/chat` | `/chat bob` | 进入和 bob 的连续聊天模式 |
| `/exit` | `/exit` | 退出聊天模式，回到全局模式 |

#### 群组

| 命令 | 示例 | 说明 |
|------|------|------|
| `/creategroup` | `/creategroup 技术交流` | 创建名为"技术交流"的群 |
| `/joingroup` | `/joingroup g_123456_78901` | 加入指定ID的群 |
| `/leavegroup` | `/leavegroup g_123456_78901` | 离开群组 |
| `/groups` | `/groups` | 查看我的群组列表 |
| `/groupinfo` | `/groupinfo g_123456_78901` | 查看群详情和成员 |
| `/gmsg` | `/gmsg g_123456_78901 大家好` | 往群发一条消息 |
| `/gchat` | `/gchat g_123456_78901` | 进入群聊天模式 |

#### 个人

| 命令 | 示例 | 说明 |
|------|------|------|
| `/profile` | `/profile` | 查看个人资料 |
| `/setnickname` | `/setnickname 新昵称` | 修改昵称 |
| `/search` | `/search ali` | 搜索用户名或昵称含"ali"的用户 |

#### 帮助

| 命令 | 示例 | 说明 |
|------|------|------|
| `/help` | `/help` | 显示所有可用命令 |

## 三、典型使用场景

### 3.1 场景一：两人私聊

**步骤：**

1. 终端A：注册用户 `alice`
2. 终端B：注册用户 `bob`
3. 终端A：`/addfriend bob`
4. 终端B：收到通知 `alice added you as friend`
5. 终端A：`/chat bob` — 进入聊天模式
6. 终端A：直接输入 `你好Bob！` — 消息发出
7. 终端B：实时看到 `[PM] alice: 你好Bob！`

```
终端A操作流程                   终端B操作流程
─────────────────────────      ─────────────────────────
> /addfriend bob               (收到) [*] alice added you as friend
[*] Friend added: bob
> /chat bob                    ─
Entering chat with bob.        ─
[alice] 你好Bob！              (收到) [PM] alice: 你好Bob！
[alice] 周末有空吗？           (收到) [PM] alice: 周末有空吗？
[alice] /exit                  ─
Exited chat mode.
```

### 3.2 场景二：群聊

**步骤：**

1. 终端A（alice）：`/creategroup Java技术交流` — 创建群
2. 终端A：记下返回的群ID，如 `g_1715692800000_12345`
3. 终端B（bob）：`/joingroup g_1715692800000_12345` — 加入群
4. 终端A：`/gmsg g_1715692800000_12345 欢迎大家！` — 群发消息
5. 终端B：收到群消息

```
> /creategroup Java技术交流
Group created: Java技术交流 (ID: g_1715692800000_12345)

> /gchat g_1715692800000_12345
Entering group chat with g_1715692800000_12345.

[g_1715692800000_12345] 大家好，今天开始讨论Java并发编程
[g_1715692800000_12345] 有人看过《Java并发编程实战》吗？
```

### 3.3 场景三：离线消息

**步骤：**

1. 终端A（alice）：在线
2. 终端B（bob）：下线（`/quit` 或关闭终端）
3. 终端A：`/msg bob 你在吗？」` — 发消息给离线的 bob
4. 终端A：看到提示 `Message queued (user offline)`
5. 终端B：重新上线登录
6. 终端B：自动收到之前暂存的消息

```
终端A                          终端B（上线后自动收到）
─────────────────────         ────────────────────────
> /msg bob 你在吗？            > Login...
                               [PM] alice: 你在吗？
Message queued (user offline)
```

## 四、常见问题

### Q1：Windows 下中文显示乱码？

**方法一：** 启动 Java 前设置编码：

```bash
chcp 65001
java -cp out com.qqchat.client.QQClient
```

**方法二：** 使用 Windows Terminal（推荐），默认支持 UTF-8。

### Q2：如何同时运行多个客户端？

打开多个终端窗口，每个窗口独立启动一个客户端即可。也可以在一台电脑上测试多人聊天。

### Q3：端口被占用怎么办？

指定不同的端口启动服务端：

```bash
java -cp out com.qqchat.server.QQServer 8888
```

客户端连接时指定对应端口：

```bash
java -cp out com.qqchat.client.QQClient localhost 8888
```

### Q4：如何重置数据？

删除 `data/` 目录即可，重启服务端会自动创建空数据：

```bash
rm -rf data
# Windows: rmdir /s data
```

### Q5：可以连接远程服务器吗？

可以。假设服务器 IP 为 `192.168.1.100`，端口 `9999`：

```bash
# 客户端
java -cp out com.qqchat.client.QQClient 192.168.1.100 9999
```

> 注意：如果服务器有防火墙，需要开放对应端口。

### Q6：密码忘记了怎么办？

当前版本没有密码找回功能。可以删除 `data/users.json` 中对应的用户条目来重新注册，或直接删除 `data/` 目录全部重置。

## 六、快捷键和技巧

| 操作 | 说明 |
|------|------|
| `Ctrl + C` | 强制退出客户端或服务端 |
| `/exit` | 从聊天模式返回全局模式（推荐） |
| `/chat <用户>` | 进入连续聊天模式，之后直接打字即可发送 |
| 上箭头 | 部分终端支持命令历史（取决于终端） |

**小技巧：**

- 将好友加入聊天模式（`/chat`）后，无需每次输 `/msg`，直接打字即可
- 用 `/search <关键词>` 快速找到要添加的好友
- 群ID较长，建议复制粘贴
