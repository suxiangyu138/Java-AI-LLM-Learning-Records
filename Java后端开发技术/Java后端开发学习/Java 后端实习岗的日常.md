 Java 后端实习岗的日常
一、每天固定节奏（99% 公司都这样）
1. 早上 9:30 左右到公司
- 开电脑、登微信/飞书、拉代码（git pull）
- 看一眼群消息、bug 单、任务单
- 10 分钟搞定，没人管你摸不摸鱼
2. 10:00 站会/晨会（大部分小公司没有）
一般就三句话：
- 昨天做了啥
- 今天要做啥
- 遇到啥问题
全程 3～5 分钟，走个形式。
3. 上午：真正写代码的黄金时间
实习生 90% 的工作就这几类：
（1）写简单接口
- 增删改查（CRUD）
- 从 Controller → Service → Mapper 一套
- 比如：用户列表、订单查询、提交表单、修改状态
你刚才我教你的那种接口，就是实习主力工作。
（2）改 bug
- 前端说接口不对
- 字段少了、类型错了
- 分页不对、时间格式不对
- 空指针、参数没判空
都是简单但繁琐的活。
（3）写文档、写测试
- Swagger 接口注释
- Postman 测试自己的接口
- 写简单的单元测试（有些公司要）
（4）查数据、改数据
- 打开 Navicat 查 MySQL
- 帮测试/产品改几笔测试数据
- 看日志排查问题
4. 中午 12:00 吃饭 + 午休
公司一般不管，睡到 14:00 都正常。
5. 下午：继续写代码/联调
下午主要是：
- 和前端联调接口
前端：你少返回个字段
你：马上改
- 写业务逻辑
- 看别人代码，学习项目结构
- 偶尔开个小会，听需求
6. 晚上 18:30～20:00 下班
- 不忙的公司 18:30 准时走
- 忙的公司 20:00 左右也能走
- 实习生基本不会让你通宵
 
二、实习生绝对不会让你干的
- 不会让你改核心架构
- 不会让你单独上线
- 不会让你处理高并发、线上故障
- 不会让你设计复杂表结构
你就是辅助开发 + 增删改查工具人，安全得很。
 
三、用一句话总结 Java 后端实习日常
上午写 CRUD 接口，
下午改 bug、联调前端，
偶尔查数据库、看日志，
剩下时间学习项目代码。
非常简单、非常重复，但能快速让你学会真实企业开发。
