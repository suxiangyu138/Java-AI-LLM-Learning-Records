Nginx 核心知识点
---------------------------------------------------------------------------------------------------------------------------------------
---------------------------------------------------------------------------------------------------------------------------------------
一、Nginx 是什么
1. Nginx 是一款高性能的 HTTP 服务器和反向代理服务器。
2. 特点：占用内存少、并发能力强、稳定性高、配置简单。
3. 主要用途：
   静态资源服务器
   反向代理
   负载均衡
   动静分离
   HTTPS 部署
   接口缓存、限流、防盗链
---------------------------------------------------------------------------------------------------------------------------------------
二、Nginx 在 JavaWeb 项目中的作用
1. 接收用户浏览器请求，统一入口。
2. 静态资源（HTML、CSS、JS、图片、视频）直接由 Nginx 返回，速度极快。
3. 动态请求（Servlet、接口）转发给 Tomcat 处理。
4. 多台 Tomcat 时实现负载均衡，提高并发能力。
5. 隐藏后端服务器地址，提高安全性。
---------------------------------------------------------------------------------------------------------------------------------------
三、Nginx 常用功能
1. 静态资源服务
   配置 root 或 alias，直接访问前端页面、图片、文件。
   访问速度远高于 Tomcat。
2. 反向代理
   用户访问 Nginx，Nginx 转发请求到后端 Tomcat。
   用户不知道后端真实地址。
3. 负载均衡
   多台 Tomcat 同时提供服务，Nginx 按策略分发请求。
   策略：轮询、权重、IP 哈希等。
4. 动静分离
   静态资源：Nginx 处理。
   动态接口：转发给 Tomcat。
5. HTTPS 配置
   配置 SSL 证书，实现 https 访问。
6. 跨域解决
   通过配置请求头实现跨域，避免前端报错。
---------------------------------------------------------------------------------------------------------------------------------------
四、Nginx 核心配置结构
1. 全局块
   worker_processes  1;
   配置工作进程数，一般等于 CPU 核心数。
2. events 块
   配置连接数等事件模型。
3. http 块
   包含所有 HTTP 相关配置。
   可以有多个 server。
4. server 块
   一个 server 对应一个网站/服务。
   监听端口、主机名。
5. location 块
   匹配请求路径，做不同处理。
   静态资源、反向代理、负载均衡都在这里配置。
---------------------------------------------------------------------------------------------------------------------------------------
五、典型配置示例（JavaWeb 项目）
1. 反向代理 Tomcat
location / {
    proxy_pass http://localhost:8080;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
}
2. 静态资源配置
location /static/ {
    root html;
    expires 30d;
}
3. 负载均衡配置
upstream tomcats {
    server 127.0.0.1:8080;
    server 127.0.0.1:8081;
}
location / {
    proxy_pass http://tomcats;
}
---------------------------------------------------------------------------------------------------------------------------------------
六、Nginx 常用命令
1. 启动 Nginx
start nginx
2. 停止 Nginx
nginx -s stop
3. 平稳退出
nginx -s quit
4. 重新加载配置（不重启服务）
nginx -s reload
5. 查看版本
nginx -v
---------------------------------------------------------------------------------------------------------------------------------------
七、Nginx 优点
1. 高并发，单机支持几万并发连接。
2. 内存消耗低，资源占用小。
3. 配置简单、扩展方便。
4. 支持热部署，修改配置不用重启。
5. 功能强大：代理、负载均衡、动静分离、HTTPS、限流、缓存。
---------------------------------------------------------------------------------------------------------------------------------------
八、Nginx + Tomcat 经典架构
1. 用户请求 → Nginx（80端口）
2. 静态资源 → Nginx 直接返回
3. 动态请求 → 转发到 Tomcat（8080）
4. 多 Tomcat → Nginx 负载均衡
5. 优点：安全、高效、稳定、易扩展
---------------------------------------------------------------------------------------------------------------------------------------
九、总结
1. Nginx 是高性能 Web 服务器和反向代理。
2. 企业 JavaWeb 项目必备，用于前端部署、反向代理、负载均衡。
3. 核心功能：静态服务、反向代理、负载均衡、动静分离。
4. 配置清晰，使用简单，支持热加载。
5. Nginx + Tomcat 是 JavaWeb 项目最经典的部署架构。
