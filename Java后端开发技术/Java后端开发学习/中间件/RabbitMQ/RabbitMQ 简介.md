RabbitMQ 简介
RabbitMQ 是一款基于 AMQP 0-9-1 高级消息队列协议实现的开源消息中间件，由 Erlang 语言开发，核心作用是实现生产者与消费者的解耦，通过消息队列作为中间载体，完成异步通信、流量削峰、分布式任务分发等核心功能。
它轻量、稳定、易部署且生态完善，支持 Java、Go、Python、PHP 等多语言客户端，提供免费开源版本和企业级商业版本，是企业级分布式架构中最常用的消息中间件之一。
RabbitMQ 的核心架构由 Broker（服务节点）、Producer（生产者）、Consumer（消费者）、Exchange（交换机）、Queue（队列）、Virtual Host（虚拟主机）六大组件构成，各组件协同工作，实现消息从生产、路由、存储到消费的全流程。
其核心优势在于高可靠性，通过持久化、生产者/消费者确认机制、死信队列等特性，保障消息全链路不丢失；同时支持多种交换机类型，可灵活适配一对一、一对多、广播等不同业务场景，满足各类分布式系统的通信需求。
RabbitMQ 广泛应用于服务解耦、异步通信、流量削峰、分布式任务分发等场景，相比其他主流消息中间件，它更侧重消息可靠性和灵活性，适合对消息安全性要求高、并发量适中的核心业务场景。
