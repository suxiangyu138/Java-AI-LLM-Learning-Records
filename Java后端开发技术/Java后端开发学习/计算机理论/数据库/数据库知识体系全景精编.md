数据库知识体系全景精编
一、基础概念层  
1. 数据与信息
   数据（Data）是符号化记录；信息（Information）是数据在上下文中的含义。数据库（DB）是长期存储在计算机内、有组织、可共享的数据集合。  
2. 数据库管理系统（DBMS）
   功能：定义、创建、查询、更新、维护、控制、通信。
   目标：数据独立性、数据完整性、并发控制、故障恢复、安全性。  
3. 数据模型三代
   • 层次模型（树）
   • 网状模型（图）
   • 关系模型（二维表）
   • 对象-关系模型（嵌套表、引用）
   • 半结构化模型（XML、JSON、KV、文档、图）  
4. 三层模式两层映射
   外模式（视图层）⇄ 逻辑模式（概念层）⇄ 内模式（存储层）。
   逻辑/物理独立性通过“外/概念映射”和“概念/内映射”实现。  
-------------------------------------------------------------------------------------------------
二、关系理论层  
1. 关系代数
   传统 8 操作：σ 选择、π 投影、× 笛卡儿积、⋈ 连接、÷ 除、∪ 并、∩ 交、− 差。
   附加：重命名 ρ、赋值 ←、聚集 γ。  
2. 元组关系演算 & 域关系演算
   安全表达式、等价性、与代数互相转换。  
3. 范式体系
   1NF：原子性
   2NF：消除部分函数依赖
   3NF：消除传递函数依赖
   BCNF：每个决定因素都是候选键
   4NF：消除多值依赖
   5NF：消除连接依赖
   反范式：冗余换性能。  
4. 函数依赖与 Armstrong 公理
   自反、增广、传递；闭包计算、最小覆盖。  
5. 完整性约束
   域、实体、参照、用户自定义、检查子句、断言、触发器。  
------------------------------------------------------------------------------------------------
三、SQL 语言层  
1. 数据定义（DDL）
   CREATE/ALTER/DROP/RENAME DATABASE、TABLE、INDEX、VIEW、SEQUENCE。  
2. 数据操纵（DML）
   INSERT、DELETE、UPDATE、MERGE。  
3. 数据查询（DQL）
   SELECT-FROM-WHERE 框架；
   连接：INNER、LEFT/RIGHT/FULL OUTER、NATURAL、USING；
   子查询：IN/EXISTS/ANY/ALL、派生表、公共表表达式（CTE）。  
4. 集合操作
   UNION、INTERSECT、EXCEPT；ORDER BY、LIMIT/OFFSET。  
5. 聚合与窗口
   GROUP BY + HAVING；
   窗口函数：ROW_NUMBER、RANK、DENSE_RANK、LAG/LEAD、SUM() OVER(PARTITION BY … ORDER BY …)。  
6. 控制语句（TCL）
   BEGIN/START TRANSACTION、COMMIT、ROLLBACK、SAVEPOINT。  
7. 索引与优化提示
   CREATE [UNIQUE|FULLTEXT|SPATIAL] INDEX …
   HINT：USE INDEX、FORCE INDEX、IGNORE INDEX。  
------------------------------------------------------------------------------------------------
四、存储与索引层  
1. 磁盘结构
   盘面→磁道→扇区→簇；顺序 I/O vs 随机 I/O；预读、延迟写。  
2. 文件组织
   堆文件、排序文件、散列文件、聚簇文件。  
3. 索引技术
   • B+Tree：阶 m、节点填充因子 ≥ 50%，范围扫描高效。
   • Hash：静态、可扩展、线性散列；桶溢出链。
   • Bitmap、R-Tree、GiST、LSM-Tree、跳表 (Redis)。  
4. 聚簇与非聚簇
   InnoDB 主键即聚簇索引；二级索引回表。  
5. 覆盖索引与最左前缀
   联合索引 (a,b,c) 可服务 WHERE a=1 AND b=2 但不能 WHERE b=2；EXPLAIN 查看 key_len。  
6. 索引失效 8 条
   对索引列运算、LIKE '%xx'、OR 过多、隐式转换、函数、表达式、范围后失效、不等于 (!=, <>)。  
------------------------------------------------------------------------------------------------
五、事务与并发控制  
1. ACID
   Atomicity：redo/undo log；Consistency：约束+触发器；Isolation：锁+MVCC；Durability：WAL。  
2. 并发异常
   脏读、不可重复读、幻读、丢失更新、写偏斜。  
3. 隔离级别
   Read Uncommitted(0)、Read Committed(1)、Repeatable Read(2)、Serializable(3)。  
4. 锁机制
   • 粒度：表锁、页锁、行锁、元组锁、意向锁。
   • 类型：共享 S、排他 X、更新 U、意向 IS/IX。
   • 死锁检测：等待图、超时；死锁预防：一次封锁、顺序封锁。  
5. MVCC（多版本并发控制）
   隐藏列：trx_id、roll_pointer；ReadView 可见性判断；快照读 vs 当前读。  
6. 日志系统
   • Redo Log：物理日志，循环写，崩溃恢复。
   • Undo Log：逻辑日志，事务回滚。
   • Checkpoint：减少恢复时间。  
------------------------------------------------------------------------------------------------
六、故障恢复与备份  
1. 故障类型
   事务故障、系统故障、介质故障、网络故障。  
2. 恢复策略
   延迟更新、立即更新、镜像、影子分页。  
3. 备份方式
   冷备、热备、逻辑备份（mysqldump）、物理备份（xtrabackup）、增量备份、差异备份。  
4. Point-in-Time Recovery (PITR)
   全备 + 归档日志 + 时间点定位。  
------------------------------------------------------------------------------------------------
七、分布式数据库  
1. CAP 定理
   Consistency、Availability、Partition tolerance 三者不可全得。  
2. BASE 理论
   Basically Available、Soft state、Eventually consistent。  
3. 分片策略
   水平分片（Range、Hash、List）、垂直分片、混合分片。  
4. 一致级别
   强一致、线性一致、顺序一致、最终一致；Quorum NRW。  
5. 全局时钟
   物理时钟（NTP 漂移）、逻辑时钟（Lamport、向量时钟）、混合时钟（TrueTime）。  
6. 分布式事务
   2PC、3PC、TCC、Saga、Paxos/Raft 日志复制。  
------------------------------------------------------------------------------------------------
八、NoSQL 与多模型  
1. Key-Value：Redis、Riak；适用缓存、计数器。  
2. Document：MongoDB、Couchbase；JSON/BSON 嵌套。  
3. Column-Family：HBase、Cassandra；宽表、列簇。  
4. Graph：Neo4j、JanusGraph；节点+边+属性。  
5. 时序：InfluxDB、TimescaleDB；高压缩、按时间分区。  
------------------------------------------------------------------------------------------------
九、性能优化体系  
1. 查询优化流程
   • 解析→重写→生成逻辑计划→选择物理计划→执行。
   • 代价模型：CPU + I/O + 网络；选择性估算。  
2. 索引优化
   单列 vs 联合、覆盖索引、索引下推、跳跃扫描、索引合并。  
3. 查询重写
   子查询转连接、半连接反连接、物化视图、公共表表达式。  
4. 执行计划关键字
   type：ALL, index, range, ref, eq_ref, const, system。
   key_len：联合索引实际使用字节数。
   Extra：Using filesort, Using temporary, Using index condition。  
5. 配置调优
   InnoDB Buffer Pool 70% RAM；sort_buffer_size、join_buffer_size。  
6. 架构层
   读写分离、主从复制、半同步、组复制、分库分表、冷热分离、缓存层 Redis。  
------------------------------------------------------------------------------------------------
十、数据安全与治理  
1. 权限模型
   DAC、MAC、RBAC、ABAC；SQL GRANT/REVOKE。  
2. 加密与脱敏
   透明加密 TDE、列级加密、动态脱敏、静态脱敏。  
3. 审计与合规
   GDPR、CCPA、等保 2.0；审计日志、操作留痕。  
4. 数据质量
   准确性、一致性、完整性、及时性；主数据管理 MDM。
