计算机组成原理·期末突击复习提纲
一、计算机系统概述
1. 计算机的 5 大基本部件
- 运算器、控制器、存储器、输入设备、输出设备
- 运算器+控制器 = CPU
2. 冯·诺依曼计算机思想
- 采用二进制
- 存储程序、程序控制
- 由上述 5 大部件组成
3. 计算机层次
微程序 → 机器语言 → 操作系统 → 汇编 → 高级语言
 
二、数制与编码（必考）
1. 进制转换
- 二 ↔ 十 ↔ 十六
- 小数：乘2取整
2. 机器数表示
- 原码：符号位+绝对值
- 反码：正数同原码，负数符号位不变，其余取反
- 补码：正数同原码，负数 = 反码+1
- 移码：补码符号位取反（多用于浮点数阶码）
3. 定点与浮点
- 定点：整数 / 小数
- 浮点：N = M × R^E
- M：尾数
- E：阶码
- IEEE 754 浮点数（必考）
- 32位：1位符号，8位阶码，23位尾数
- 阶码用移码，尾数隐藏最高位1
 
三、运算方法与运算器
1. 补码加减法
- [A+B]补 = [A]补 + [B]补
- [A-B]补 = [A]补 + [-B]补
2. 溢出判断
- 双符号位：00正，11负，01上溢，10下溢
3. ALU 的功能
- 算术运算 + 逻辑运算
- 核心：加法器（串行/并行进位）
4. 乘法、除法
- 原码乘：符号位单独处理
- 补码乘：Booth 算法（考试常考）
 
四、存储器系统（大题重点）
1. 层次结构
寄存器 → Cache → 主存 → 辅存
2. 主存分类
- RAM：随机存取，断电丢失
- ROM：只读，不丢失
3. 存储器扩展
- 位扩展：位数不够
- 字扩展：字数不够
- 考试常给芯片，让你画连接图、算地址线
4. Cache 原理
- 目的：解决CPU 与主存速度不匹配
- 依据：局部性原理（时间局部性、空间局部性）
5. Cache 三种映射
- 直接映射：简单，冲突率高
- 全相联：冲突少，成本高
- 组相联：折中（最常用）
6. 替换算法
- FIFO
- LRU（最常考）
- 随机
 
五、指令系统
1. 指令格式
- 操作码 OP + 地址码 A
- 零地址、一地址、二地址、三地址
2. 寻址方式（必考）
- 立即寻址：A 就是数
- 直接寻址：A 是地址
- 间接寻址：A 是地址的地址
- 寄存器寻址
- 寄存器间接寻址
- 变址、基址、相对寻址
3. CISC & RISC
- CISC：复杂指令，微程序实现
- RISC：精简指令，硬布线，流水线，寄存器多
 
六、CPU 结构与功能
1. CPU 基本组成
- 运算器
- 控制器
- 寄存器组
2. 指令执行过程
取指 → 分析 → 执行
3. 控制器两种实现
- 硬布线：速度快，复杂
- 微程序：规整，易扩展，速度慢
4. 微指令格式
- 水平型：并行性强
- 垂直型：类似机器指令
 
七、流水线（必考）
1. 5 段经典流水线
IF → ID → EX → MEM → WB
2. 三种冲突
- 结构冲突
- 数据冲突
- 控制冲突
3. 解决数据冲突
- 暂停、转发（forwarding）、编译优化
 
八、总线与输入输出
1. 总线分类
- 片内总线
- 系统总线（数据、地址、控制）
- I/O 总线
2. 总线仲裁
- 集中式：链式查询、计数器、独立请求
- 分布式
3. I/O 控制方式
- 程序查询
- 程序中断
- DMA
- 通道
4. 中断过程
中断请求 → 判优 → 响应 → 保护现场 → 中断服务 → 恢复现场 → 返回
5. DMA
- 直接内存访问，不占CPU
- 常用于：磁盘、显卡等高速设备
 
九、期末最常考大题题型
1. 补码运算、溢出判断
2. IEEE 754 浮点数计算
3. 存储器位扩展/字扩展连线与地址分配
4. Cache 映射与地址划分（标记、组号、块内地址）
5. 指令寻址方式计算有效地址
6. 流水线冲突与加速比计算
