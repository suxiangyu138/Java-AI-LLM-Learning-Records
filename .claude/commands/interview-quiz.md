# 随机面试自测

对知识库中最近的面试主题（或用户指定的主题）进行随机面试自测。

## 执行流程

1. 若用户未指定主题：从 `05-综合输出-面试冲刺/` 与各知识体系的 `NN-面试与自测.md` 中随机抽取 1 个主题；若用户指定则用指定主题
2. 使用 `interview-prep` 技能的四档规范出题（基础概念/工程实践/架构设计各 2 题）
3. 先展示题目，让用户口头作答（不直接给答案）
4. 用户作答后逐题点评：要点是否覆盖、是否有追问风险
5. 最后给出标准答案要点表 + 用户薄弱点总结

## 模式

- 无参数：随机主题自测
- 带主题：`/interview-quiz Java集合` → 指定主题
- 带"严格"：模拟面试官语气，答错直接打断并追问
