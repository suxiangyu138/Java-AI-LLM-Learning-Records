# 校验最近修改的文档

对最近修改的 Markdown 文档执行质量校验（围栏/链接/锚点/表格/导航）。

## 执行流程

1. 用 `git status` 找出最近修改/新增的 `.md` 文件（未提交的）
2. 若为空，用最近 24 小时修改时间过滤知识库 `.md` 文件
3. 对每个文件运行 `doc-quality` 技能的校验脚本（围栏配对、链接目标存在、TOC 锚点、表格分隔行、导航完整性）
4. 输出问题清单（文件 → 问题 → 修复建议），自动修复能确定的（链接编码、锚点、围栏）
5. 修复后重跑校验确认通过
6. 汇总：校验了 N 篇，修复 M 处

## 注意

- 链接缺失先 `ls` 确认真实文件名/层级再修，不猜
- 只改文档，不动代码/配置
