# 高密度笔记模板

创建一个符合用户偏好（高密度、精简、可背诵、表格优先）的技术笔记文档。

## 执行流程

1. 确认主题与存放位置（默认知识库对应体系目录）
2. 先运行 `tech-research` 技能：WebSearch 最新资讯（版本/价格/2026 现状），标注版本窗口
3. 按模板输出

## 模板

```markdown
# {主题}

> 定位：一句话说明（{版本基准}）

## 📚 目录
1. [核心速查](#1-核心速查)
2. [知识要点](#2-知识要点)
3. [对比与选型](#3-对比与选型)
4. [面试题](#4-面试题)

## 1. 核心速查
| 概念 | 一句话 | 关键数字 |
|------|--------|---------|

## 2. 知识要点
（表格 + 要点清单，禁止废话段落）

## 3. 对比与选型
| 方案 | 优点 | 缺点 | 适用 |
|------|------|------|------|

## 4. 面试题
（用 interview-prep 规范生成 6-8 题，含要点）

## 【参考来源】
（每条带 URL 超链接）
```

## 规范

- 高密度：每节 ≤ 3 段文字，其余用表格/清单
- 代码块只放代码；代码简洁少注释
- 每个关键数字/版本来自检索结果
- 写完用 doc-quality 校验
