# Tech Research：最新资讯检索

写技术内容前的强制检索流程——**坚决不写过时的文档信息，以最新搜索为准**。

## 触发场景

- 用户说"写 XX 文档"、"对比 XX"、"更新 XX 体系"
- 涉及版本号、价格、市场份额、新特性的任何输出
- 知识库维护（本仓库是 2,000+ 篇技术文档的知识库，时效性文档必须标注版本窗口）

## 检索规范

1. **先搜再写**：动笔前至少 2-3 组关键词并行 WebSearch（中英文混合）
2. **多源交叉验证**：同一事实至少 2 个独立来源确认，冲突时以官方文档/官网为准
3. **版本窗口标注**：文档头部标注"（2026-08 基准）"，正文写清版本号与发布日期
4. **引用溯源**：文末【参考来源】每条带完整 URL 超链接（`[标题](URL)` 格式）
5. **稳定 vs 实验性**：区分 GA/稳定版与 beta/实验特性，实验特性必须标注

## 检索关键词模板

```text
写框架文档：  "{框架名} 2026 version features"
做对比：      "{A} vs {B} comparison 2026"
查版本：      "{框架} release notes {最新月份}"
查价格：      "{模型/服务} pricing 2026 per million tokens"
查安全：      "{主题} security vulnerability CVE 2026"
```

## 输出要求

- 正文出现的**每个关键数字/版本/日期**都要能追溯到检索结果
- 无法确认的信息明确写"待确认"，禁止编造
- 检索结果与旧知识冲突时，以检索为准并在文档中注明变化

## 禁忌

- 禁止凭训练记忆输出版本号、价格、发布日期
- 禁止无来源的关键断言
- 禁止把 beta 特性写成 GA 特性
