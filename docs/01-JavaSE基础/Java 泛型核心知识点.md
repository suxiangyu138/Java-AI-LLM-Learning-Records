# Java 泛型核心知识点
## 一、泛型基础概念
1. **定义**
泛型是**参数化类型**，在编译期约束数据类型，实现**代码复用 + 类型安全**。
2. **核心作用**
- 编译期类型检查，杜绝强制类型转换异常 `ClassCastException`
- 避免频繁强转，代码简洁
- 泛型类/方法复用，适配多种数据类型
3. **本质**
**泛型擦除**：泛型只存在于编译期，运行时全部擦除为原始类型（Object/边界类型）。

## 二、泛型使用形式
### 1. 泛型类
```java
class ClassName<T> {}
```
- `<T>`：类型形参，常见占位符：
  - `T` 类型、`E` 集合元素、`K` 键、`V` 值、`R` 返回值

### 2. 泛型接口
```java
interface InterfaceName<T> {}
```
实现类可指定具体类型、或继续保留泛型。

### 3. 泛型方法
```java
public <T> T method(T t) {}
```
- 类型参数声明在**方法返回值前**
- 普通方法、静态方法都可定义泛型（静态泛型必须单独声明）

## 三、原始类型
- 不带泛型参数的类，如 `List` 原始类型
- 兼容旧代码，**不推荐使用**，会丧失泛型类型校验

## 四、通配符 ?
### 1. 无界通配符 `<?>`
- 匹配**任意类型**
- 只能读、不能写（除null）
- 适用：只读取数据的场景

### 2. 上界通配符 `<? extends 父类>`
- 限定：**本类 + 子类**
- 规则：只读，不能添加元素
- 例：`List<? extends Number>`

### 3. 下界通配符 `<? super 子类>`
- 限定：**本类 + 父类**
- 规则：可写、读取只能为Object
- 例：`List<? super Integer>`

### 口诀
**上界只读，下界可写**

## 五、泛型上下界限定
1. **类型上界 `<T extends 类/接口>`**
限制T必须是指定类或子类
2. **类型下界**
泛型**类型参数无下界**，只有通配符有下界

## 六、泛型擦除（核心考点）
1. 编译阶段：泛型校验类型
2. 编译后：
   - 泛型类型全部擦除
   - 无边界 → 擦为 `Object`
   - 有上界 → 擦为边界类型（如Number）
3. 关键结论
- 泛型类无独立Class对象：`List<String>.class == List<Integer>.class`
- 不能用基本类型做泛型（需包装类）
- 不能定义泛型数组、不能在静态变量使用类泛型

## 七、泛型与继承
1. `List<String>` **不是** `List<Object>` 的子类
2. 泛型集合**不支持协变**，数组支持协变
3. 如需父子类兼容，必须使用通配符

## 八、常见限制
1. 不能使用基本类型：`List<int>` 非法，只能 `List<Integer>`
2. 泛型不能实例化对象：`new T()` 非法
3. 静态成员不能使用类上定义的泛型
4. 不能捕获泛型异常
5. 不能以泛型作为重载区分（擦除后方法签名一致）

## 九、PECS 原则（高频面试）
- **PECS**：Producer Extends，Consumer Super
  1. 生产者（读取数据）→ `extends` 上界
  2. 消费者（写入数据）→ `super` 下界

## 十、泛型优势总结
1. 编译期类型安全
2. 消除强制类型转换
3. 通用代码复用
4. 集合框架全部基于泛型实现
