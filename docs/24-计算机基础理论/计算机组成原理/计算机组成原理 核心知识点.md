# 计算机组成原理 核心知识点
## 一、计算机系统概述
1. **冯·诺依曼体系五大部件**
运算器、控制器、存储器、输入设备、输出设备。
2. **核心思想**
二进制存储、程序与数据存内存、顺序执行、集中控制。
3. **硬件层次**
CPU、主存、辅存、I/O；
软件层次：系统软件 + 应用软件。
4. **性能指标**
时钟周期、主频、CPI（每条指令时钟周期）、
MIPS（每秒百万指令）、FLOPS。

---

## 二、数制与编码
1. **进制转换**：二进制、八进制、十六进制、十进制互转。
2. **机器数表示**
- 原码：符号位+真值，正负唯一，运算复杂
- 反码：正数同原码，负数按位取反
- 补码：**计算机实际存储运算用补码**
  正数：原码=反码=补码
  负数：反码+1，解决负数运算、0唯一
3. **定点/浮点**
- 定点整数、定点小数
- 浮点数：阶码+尾数，遵循IEEE754
4. **校验码**
奇偶校验、海明校验、CRC循环冗余校验。

---

## 三、运算器与数据运算
1. **算术运算**
补码加减运算、溢出判断（双符号位/最高位进位）。
2. **逻辑运算**
与、或、非、异或、移位（算术移位、逻辑移位）。
3. **ALU算术逻辑单元**
核心：完成算术+逻辑运算，配合寄存器、移位器。

---

## 四、存储器系统（重点）
### 1. 存储器层次结构
CPU缓存（L1/L2/L3）→ 主存 → 辅存
速度递减、容量递增、成本递减。

### 2. 分类
- 按读写：RAM（随机读写，断电丢失）、ROM（只读，断电保留）
- 按存取：随机存取、顺序存取、直接存取

### 3. 高速缓存 Cache
- 作用：缓解CPU与主存速度差，基于**局部性原理**
- 三种映射方式
  直接映射、全相联映射、组相联映射（主流）
- 替换算法：LRU、FIFO、随机替换

### 4. 虚拟存储器
- 逻辑地址、物理地址
- 分页、分段、段页式，由硬件+操作系统协同实现

### 5. 主存芯片
位扩展、字扩展，存储器容量计算。

---

## 五、指令系统
1. **指令格式**
操作码 OP + 地址码 A。
2. **寻址方式**
立即寻址、直接寻址、间接寻址、寄存器寻址、
寄存器间接、相对寻址、基址/变址寻址。
3. **指令分类**
数据传送、算术逻辑、控制转移、I/O指令。
4. **CISC / RISC**
- CISC：复杂指令、指令多、变长、兼容强（Intel）
- RISC：精简指令、定长、单周期、效率高（ARM）

---

## 六、CPU 中央处理器
1. **CPU 组成**
- 运算器：ALU、通用寄存器、状态寄存器
- 控制器：指令寄存器IR、程序计数器PC、指令译码器、时序电路

2. **核心寄存器**
- PC：存下一条指令地址
- IR：存放当前执行指令
- MAR：存储器地址寄存器
- MDR：存储器数据寄存器

3. **指令执行流程**
取指 → 译码 → 执行 → 访存 → 写回。

4. **流水线技术**
- 目的：并行执行指令，提升吞吐
- 冲突：结构冒险、数据冒险、控制冒险
- 解决方案：停顿、数据旁路、分支预测

---

## 七、总线系统
1. **总线分类**
- 片内总线、系统总线、通信总线
- 系统总线：数据总线、地址总线、控制总线

2. **总线仲裁**
解决多设备竞争总线：链式查询、计数器定时查询、独立请求。
3. **总线特性**：机械、电气、功能、时间特性。

---

## 八、I/O 输入输出系统
1. **I/O 控制方式**
- 程序直接控制（轮询）：CPU全程等待，效率低
- 中断驱动I/O：设备就绪发中断，CPU并行
- DMA直接存储器访问：大块数据直传，少占用CPU
- 通道方式：大型机专用，独立I/O处理器

2. **中断**
- 定义：打断当前程序，转去处理异常/外设请求
- 分类：内中断（异常）、外中断（外设）
- 流程：中断请求→判优→响应→处理→返回

3. **DMA核心**
无需CPU逐字搬运，内存与外设直接高速传输。

---

## 九、时序与控制
1. **时序信号**：时钟周期、机器周期、指令周期。
2. **控制方式**
同步控制、异步控制、联合控制。

---

## 十、高频简答速记
1. 补码优势：统一加减法、零唯一、便于硬件实现。
2. 存储层次目的：速度、容量、成本三者平衡。
3. Cache原理：时间局部性 + 空间局部性。
4. 流水线瓶颈：各类冒险冲突、分支指令。
5. I/O演进：轮询 → 中断 → DMA → 通道。
