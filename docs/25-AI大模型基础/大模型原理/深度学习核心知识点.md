# 深度学习核心知识点
完全贴合**大模型应用开发、Transformer、训练/微调、RAG 底层**，剔除计算机视觉冗余内容，只保留 NLP+LLM 刚需。

## 一、深度学习基础概念
1. **神经网络基本组成**
    - 神经元、感知机、多层感知机（MLP）
    - 输入层、隐藏层、输出层
    - 参数：权重 $W$、偏置 $b$
2. **非线性能力**
    单纯线性层叠加仍为线性变换，**激活函数**引入非线性，是深层网络的核心。
3. **超参数**
    学习率、批次大小 batch_size、迭代轮数 epoch、网络层数、隐藏层维度。

---

## 二、激活函数（LLM 高频）
1. **ReLU**
    $$\text{ReLU}(x)=\max(0,x)$$
    解决梯度消失，计算简单，通用基础激活函数。
2. **GELU**
    LLaMA、Qwen、GPT 系列**默认激活**，平滑非线性，收敛效果更好。
3. **Sigmoid / Tanh**
    多用于二分类、早期 NLP 模型，易梯度消失，大模型极少使用。
4. **Swish**
    高阶大模型、MoE 结构常用。

---

## 三、损失函数与优化
### 1. 核心损失函数
- **交叉熵损失**
  分类任务、LLM 预训练/微调**标配损失**，衡量预测分布与真实分布差距。
- 均方误差 MSE：回归任务，不用于大模型。

### 2. 优化器
- SGD：随机梯度下降，基础优化器
- **Adam / AdamW**：大模型训练、SFT 微调**主流优化器**
  自适应学习率、动量机制，收敛更快更稳。

### 3. 梯度核心理论
- 前向传播：输入数据逐层计算，得到预测值
- 反向传播：**链式法则**，计算损失对所有参数的梯度
- 梯度下降：更新参数，最小化损失
  $$\theta \leftarrow \theta - \eta \nabla L$$
- 常见问题：
  梯度消失、梯度爆炸 → 导致深层网络无法训练

## 四、正则化与泛化能力
1. **过拟合 & 欠拟合**
    - 过拟合：训练集效果极好，测试集/业务场景效果差
    - 欠拟合：模型能力不足，训练、测试效果都差
2. 解决方案
    - L1/L2 正则：限制权重大小
    - Dropout：训练随机失活神经元
    - 早停、数据增广、模型轻量化
3. **归一化**
    - LayerNorm：**Transformer 标配**，稳定深层网络训练
    - BatchNorm：多用于 CV，LLM 基本不用

## 五、经典网络结构（NLP 演进线）
1. **RNN / LSTM / GRU**
    传统序列模型，解决文本时序依赖；
    缺陷：长距离依赖捕捉弱、无法并行计算，**被 Transformer 淘汰**。
2. **Encoder-Decoder 架构**
    早期机器翻译架构，Transformer 沿用该结构思想。
3. **Transformer（大模型基石）**
    彻底解决长文本依赖、支持并行训练，所有现代 LLM 底层架构。

---

## 六、Transformer 核心模块（重中之重）
1. **自注意力机制 Self-Attention**
    建模文本全局上下文，单词与全局所有单词计算关联度。
2. **缩放点积注意力**
\[
\text{Attention}(Q,K,V) = \text{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
\]
    - $Q$ 查询、$K$ 键、$V$ 值
    - $\sqrt{d_k}$ 缩放：防止内积数值过大，softmax 饱和
3. **多头注意力 Multi-Head Attention**
    拆分多组 Q/K/V，并行捕捉不同语义特征，增强表达能力。
4. **位置编码 PE**
    注意力本身无序，通过三角函数/可学习位置编码注入**序列顺序信息**。
5. **前馈网络 FFN**
    每层独立非线性变换，提升模型表征能力。

---

## 七、预训练 & 微调范式（LLM 核心）
1. **预训练 Pre-training**
    - GPT 系列：自回归语言建模，预测下一个 token
    - BERT 系列：掩码语言建模，双向语义
2. **微调 Fine-tuning**
    - SFT 监督微调：注入对话、指令遵循能力
    - LoRA/QLoRA：轻量微调，仅训练少量参数，低成本落地
3. **对齐技术**
    RLHF、RLAIF：解决大模型有害输出、回答不可控问题

---

## 八、嵌入与向量表示（RAG 底层）
1. **词嵌入 Embedding**
    将离散文字映射为**高维稠密向量**，文本数字化。
2. 向量语义：
    语义相近 → 向量空间距离近，RAG 检索的核心原理。
3. 相似度计算：
    余弦相似度、欧氏距离，向量数据库召回底层逻辑。

## 九、深度学习工程基础
1. 张量 Tensor：深度学习统一数据格式（多维数组）
2. 计算图：自动求导底层，框架自动完成反向传播
3. 混合精度训练：FP16/FP8，降低显存占用、加速训练
4. 模型量化：4bit/8bit，本地部署、私有化推理必备
