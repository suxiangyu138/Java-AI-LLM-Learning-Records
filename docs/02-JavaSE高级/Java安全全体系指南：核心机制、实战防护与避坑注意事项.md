# Java 安全全体系指南（核心机制 + 实战防护 + 避坑注意事项）

> **文档定位**：Java 后端企业级技术文档 | Java 安全全体系  
> **核心原则**：纵深防御、全程管控、最小权限

---

## 一、核心概念

### 1.1 Java 安全体系全景

```
JVM底层安全（类加载机制）
    → 代码层权限控制（修饰符 + 安全框架）
    → 数据安全（加密 + 哈希 + 签名）
    → 网络通信安全（HTTPS/TLS）
    → Web漏洞防护（XSS/CSRF/SQL注入）
    → 第三方依赖安全（漏洞扫描）
    → 生产环境安全（最小权限 + 监控审计）
```

---

## 二、底层原理

### 2.1 类加载器与双亲委派模型（第一道防线）

```
启动类加载器（Bootstrap）→ 扩展类加载器（Extension）→ 应用类加载器（Application）
        加载核心 API              加载扩展类              加载 classpath
```

**安全作用**：防止恶意类替换 JDK 核心类（如自定义 `java.lang.String`）、保证类唯一性、隔离不同来源的类。

> 自定义类加载器严禁随意打破双亲委派模型，必须严格限制加载路径和白名单校验。

### 2.2 沙箱机制与安全管理器（已废弃）

- 从 Java 11 开始 `SecurityManager` 被标记废弃，Java 17+ 彻底移除
- 现代替代：最小权限原则 + 网络隔离 + 代码签名 + 依赖管控

### 2.3 访问控制

`public` / `protected` / `private` / `final` 四大修饰符 + 包访问权限，遵循 **最小权限原则**。

## 三、代码实现

### 3.1 加密 API 体系（JCA/JCE）

JDK 内置 Java 密码体系架构（JCA）和密码扩展包（JCE），提供标准化加密、摘要、签名接口。

### 3.2 常用加密场景规范

#### 对称加密（AES）

```java
// AES-256 加密，禁止使用 DES/3DES
KeyGenerator keyGen = KeyGenerator.getInstance("AES");
keyGen.init(256);
SecretKey key = keyGen.generateKey();
Cipher cipher = Cipher.getInstance("AES/GCM/NoPadding");
```

#### 非对称加密（RSA）

- 密钥长度 ≥ 2048 位
- 公钥公开、私钥保密
- 适用于接口验签、HTTPS 证书加密

#### 密码哈希存储

| ❌ 禁用 | ✅ 推荐 |
|--------|--------|
| MD5、SHA-1 | **BCrypt、SCrypt、Argon2** |

> 慢哈希算法自带盐值，防止彩虹表破解。

#### 数字签名

- 算法：`SHA256withRSA`
- 私钥签名、公钥验签，保证数据完整性

## 四、实战要点

### 4.1 Web 漏洞防护

| 漏洞 | 原理 | 防护 |
|------|------|------|
| **XSS** | 注入恶意脚本 | HTML 转义输入、CSP 响应头 |
| **CSRF** | 伪造请求 | Spring Security CSRF 令牌、Token 鉴权 |
| **SQL 注入** | 拼接恶意 SQL | MyBatis `#{}` 参数绑定，禁止 `${}` |
| **路径穿越** | 访问任意文件 | 禁止用户输入拼接路径、文件类型校验 |
| **反序列化漏洞** | 反序列化恶意对象 | 白名单校验，禁止反序列化不可信来源数据 |

### 4.2 第三方依赖安全

- 使用 OWASP Dependency-Check、SonarQube 定期扫描
- 仅引入必需依赖，剔除无用依赖
- 及时修复 Log4j2、FastJSON、Commons-Collections 等知名漏洞

## 五、避坑总结

| 坑点 | 正确做法 |
|------|----------|
| **密钥硬编码** | 环境变量 / KMS / 配置中心加密存储 |
| **使用 ECB 模式** | 用 CBC、GCM 等安全模式 |
| **HTTP 明文传输** | 生产环境强制 HTTPS |
| **日志打印敏感信息** | 密码、身份证脱敏处理 |
| **忽略证书校验** | 生产环境必须校验证书（禁止 `trustAll`） |
| **弱密码算法** | MD5→BCrypt、DES→AES-256 |
| **root 运行应用** | 专用低权限账号运行 |

## 六、企业级最佳实践

### 6.1 生产环境安全规范

| 规范 | 说明 |
|------|------|
| **最小权限原则** | 应用账号、数据库账号、文件权限均最小化 |
| **JDK 安全更新** | 使用 LTS 版 JDK，及时更新安全补丁 |
| **关闭调试端口** | 生产环境禁用 JVM 远程调试 |
| **敏感信息加密** | 密码/密钥/连接串加密存储，配置中心加密 |
| **安全监控** | 实时监测异常请求、暴力破解、恶意访问 |
| **定期漏洞扫描** | 依赖漏洞 + 代码审计 |

### 6.2 安全开发 Checklist

- [ ] 用户输入做校验和转义
- [ ] SQL 使用 `#{}` 参数化查询
- [ ] 密码用 BCrypt 哈希存储
- [ ] 生产环境强制 HTTPS
- [ ] 第三方依赖定期漏洞扫描
- [ ] 日志敏感信息脱敏
- [ ] 应用以低权限账号运行
