# 第一章 初识Redis
## 1.1 什么是Redis
Redis（**Remote Dictionary Server**，远程字典服务） 是一款**开源、高性能、键值型（Key-Value）** 的**内存数据库**，使用 ANSI C 语言编写。

### 核心定位
- 主打**高性能读写**，数据优先存储在内存，吞吐能力极强；
- 区别于 MySQL 等磁盘关系型数据库，常作为**缓存、中间件**使用；
- 支持多种数据结构，不局限于普通字符串，功能远超普通缓存。

---

## 1.2 Redis 核心特点
1. **高性能**
   纯内存操作，单线程模型避免线程竞争，官方数据读写可达 **10W+ QPS**，延迟极低。

2. **丰富的数据类型**
   支持 9+ 常用数据结构：
    - 基础类型：String、List、Set、Hash、ZSet
    - 高级类型：Geo、BitMap、HyperLogLog、Stream 等

3. **持久化能力**
   虽然是内存数据库，支持两种持久化方案，防止断电数据丢失：
    - RDB：定时全量快照
    - AOF：实时日志追加

4. **高可用与集群**
   支持主从复制、哨兵模式、Redis Cluster 集群，满足生产高可用、分片扩容需求。

5. **功能丰富**
   自带过期淘汰、事务、Lua 脚本、发布订阅、限流、分布式锁等原生能力。

6. **跨语言兼容**
   支持 Java、Python、Go、C++ 等所有主流开发语言，生态完善。

---

## 1.3 Redis 与 MySQL 区别
| 特性 | Redis | MySQL |
|------|-------|-------|
| 存储介质 | 内存为主，磁盘持久化 | 磁盘为主 |
| 数据结构 | Key-Value 非关系型 | 表结构 关系型 |
| 读写性能 | 极高，适合高并发 | 较低，适合复杂事务查询 |
| 存储容量 | 受内存限制，容量小 | 磁盘存储，容量大 |
| 事务能力 | 弱事务，保证最终一致 | 强事务，ACID 完整支持 |
| 典型场景 | 缓存、计数器、分布式锁、限流 | 业务持久化数据存储、复杂查询 |

---

## 1.4 企业常见应用场景
1. **热点数据缓存**
   商品详情、首页数据、用户信息，减轻数据库压力。
2. **分布式锁**
   秒杀、库存扣减、定时任务防重复执行。
3. **计数器 & 限流**
   文章点赞、浏览量、接口限流、防刷。
4. **排行榜**
   直播间榜单、积分排名，利用 ZSet 有序特性。
5. **消息队列**
   List/Stream 实现简易消息队列、异步解耦。
6. **地理位置计算**
   附近的人、门店距离筛选（Geo）。
7. **会话存储**
   登录 Token、验证码临时存储。

---

## 1.5 Redis 整体架构简述
1. **单线程事件模型**
   核心读写单线程，多路复用（IO 多路复用）处理并发连接，无锁竞争。
2. **内存+磁盘结合**
   日常读写走内存，定时落盘保证数据安全。
3. **客户端-服务端模式**
   独立服务端运行，项目通过网络连接调用，天然支持分布式。

---

## 1.6 本章总结
1. Redis 是**内存级高性能 Key-Value 数据库**，核心优势是快、结构多、生态强；
2. 定位为**辅助中间件**，配合 MySQL 实现「缓存+持久化」架构；
3. 绝大多数互联网项目必备中间件，是 Java 后端开发、分布式技术栈核心组件。
