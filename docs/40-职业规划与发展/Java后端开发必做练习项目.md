Java后端开发必做练习项目
练习项目是Java后端学习的核心输出，能串联所有知识点（框架、数据库、缓存、中间件、分布式）。结合你的学习阶段，我按入门→进阶→高阶分级，每个项目标注核心知识点和实现目标，直接照着做即可。
第一阶段：入门级（夯实基础，适合学完SSM/SpringBoot后）
目标：掌握CRUD、接口开发、基础数据库操作，建立完整项目思维。
项目1：用户管理系统（入门必做）
核心知识点：SpringBoot、MyBatis-Plus、MySQL、统一返回、全局异常、Lombok、Maven
实现功能：
1. 用户注册、登录（密码加密）
2. 用户增删改查（CRUD）
3. 分页查询、条件查询
4. 接口文档（Knife4j/Swagger）
亮点要求：参数校验、权限控制（基础角色）、日志记录。
项目2：个人博客系统（前端+后端全栈）
核心知识点：SpringBoot、MySQL、Redis（缓存）、文件上传、拦截器、AOP
实现功能：
1. 文章发布、编辑、删除、列表、详情
2. 评论、点赞功能
3. 文章分类、标签管理
4. 首页文章列表缓存（Redis）
亮点要求：整合MyBatis-Plus、实现文章搜索（MySQL全文检索）。
第二阶段：进阶级（提升核心能力，适合掌握SpringBoot+Redis后）
目标：吃透缓存、事务、高并发基础、中间件，解决真实业务问题。
项目3：电商后台系统（核心必做，覆盖80%后端业务）
核心知识点：MySQL事务、索引优化、Redis缓存、分布式锁、支付模拟、购物车
实现功能：
1. 商品模块：商品列表、详情、库存管理
2. 用户模块：收货地址、用户中心
3. 订单模块：创建订单、支付流程、订单状态流转
4. 购物车：登录态购物车、商品数量修改
亮点要求：
- 缓存热点商品、解决缓存穿透/击穿/雪崩
- 分布式锁保证库存超卖
- SQL优化（索引、分页、联表查询优化）
项目4：任务调度系统（学习中间件最佳实践）
核心知识点：XXL-Job、Quartz、MySQL、定时任务、分布式任务调度
实现功能：
1. 实现定时任务：订单超时关闭、商品上架、数据统计
2. 任务分片、失败重试、任务监控
3. 分布式环境下任务幂等性处理
亮点要求：结合电商项目，实现订单超时自动取消核心场景。
第三阶段：高阶/面试级（覆盖高并发、分布式、微服务，适合求职冲刺）
目标：掌握分布式架构、微服务生态、高并发解决方案，适配大厂面试。
项目5：微服务版电商系统（终极实战，覆盖全栈后端能力）
核心知识点：SpringCloud Alibaba、Nacos、Sentinel、Feign、Gateway、Seata、Redis集群、RabbitMQ
核心模块：
1. 用户服务：用户注册、登录、鉴权（JWT）
2. 商品服务：商品管理、库存服务
3. 订单服务：订单创建、支付回调、订单状态同步
4. 搜索服务：Elasticsearch实现商品检索
5. 网关服务：路由转发、权限校验、限流
核心能力：
- 微服务通信（Feign）、网关路由
- 分布式事务（Seata AT模式）
- 服务限流、降级、熔断（Sentinel）
- 消息队列解耦（订单创建→库存扣减→日志记录异步化）
- 容器化部署（Docker+DockerCompose）
项目6：秒杀系统（高并发面试王牌项目）
核心知识点：Redis、Lua脚本、令牌桶、消息队列、MySQL行级锁、压测
实现功能：
1. 秒杀商品库存控制、超卖/少卖问题解决
2. 接口限流、防刷、缓存预热
3. 异步下单（Redis→MQ→数据库落库）
4. 秒杀结果异步通知
亮点要求：JMeter压测，优化性能至万级QPS。
必做项目的通用规范（所有项目都要遵守）
1. 代码规范：阿里开发手册、统一包结构、命名规范、注释
2. 工程化能力：Git版本控制、Maven依赖管理、单元测试（JUnit）
3. 项目结构：分层架构（Controller/Service/Dao/Entity）、统一返回结果、全局异常处理
4. 文档：编写接口文档、项目README、部署文档
5. 部署：本地部署、Docker部署，确保项目可直接运行。
学习顺序建议
1. 先做用户管理系统→熟悉基础框架
2. 再做个人博客→掌握Redis、文件上传
3. 核心做电商后台→吃透数据库、缓存、事务
4. 进阶做任务调度→掌握中间件
5. 最后做微服务电商+秒杀→冲刺求职
