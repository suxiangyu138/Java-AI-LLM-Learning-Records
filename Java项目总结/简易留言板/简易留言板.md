## 项目整体设计

- 技术栈：  
  - 后端：Spring Boot 3 + Spring Web + Spring Data JPA + MySQL（8.x）  
  - 前端：JSP（或 Thymeleaf、可选 Vue，先做 JSP 版以便写进简历“简单留言板”）  
  - 开发：Java 17 + Maven / Gradle + VS Code + Spring Boot DevTools  
- 功能：  
  - 游客/用户可发布留言（昵称、邮箱、内容）  
  - 后端保存到 `message` 表  
  - 从数据库读取留言并渲染到页面  
  - 体现“表单提交 → Controller 接收 → 业务转发 → Repository 入库 → 页面渲染”

## 1. 数据库建模（MySQL）

```sql
create table message
(
    id          bigint auto_increment primary key,
    nickname    varchar(50)  not null,
    email       varchar(100) null,
    content     text         not null,
    create_time datetime     not null default current_timestamp
);

create index idx_create_time on message (create_time desc);
```

## 2. Java 实体与 Repository（Spring Data JPA）

### Message 实体（`Message.java`）

```java
import jakarta.persistence.*;
import java.time.LocalDateTime;

@Entity
@Table(name = "message")
public class Message {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(name = "nickname", nullable = false, length = 50)
    private String nickname;

    @Column(name = "email", length = 100)
    private String email;

    @Column(name = "content", columnDefinition = "TEXT")
    private String content;

    @Column(name = "create_time", nullable = false)
    private LocalDateTime createTime;

    // 无参构造、get、set
    public Message() {}

    public Message(String nickname, String email, String content, LocalDateTime createTime) {
        this.nickname = nickname;
        this.email = email;
        this.content = content;
        this.createTime = createTime;
    }

    // 生成 getter、setter
    public Long getId() { return id; }
    public void setId(Long id) { this.id = id; }

    public String getNickname() { return nickname; }
    public void setNickname(String nickname) { this.nickname = nickname; }

    public String getEmail() { return email; }
    public void setEmail(String email) { this.email = email; }

    public String getContent() { return content; }
    public void setContent(String content) { this.content = content; }

    public LocalDateTime getCreateTime() { return createTime; }
    public void setCreateTime(LocalDateTime createTime) { this.createTime = createTime; }
}
```

### MessageRepository（`MessageRepository.java`）

```java
import org.springframework.data.jpa.repository.JpaRepository;
import org.springframework.stereotype.Repository;
import java.util.List;

@Repository
public interface MessageRepository extends JpaRepository<Message, Long> {
    List<Message> findAllByOrderByCreateTimeDesc();
}
```

## 3. Service 与 Controller 层（体现“请求转发、业务处理”）

### MessageService（`MessageService.java`）

```java
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Service;
import java.time.LocalDateTime;
import java.util.List;

@Service
public class MessageService {

    @Autowired
    private MessageRepository messageRepository;

    public void saveMessage(String nickname, String email, String content) {
        Message message = new Message();
        message.setNickname(nickname);
        message.setEmail(email);
        message.setContent(content);
        message.setCreateTime(LocalDateTime.now());
        messageRepository.save(message);
    }

    public List<Message> listAllMessages() {
        return messageRepository.findAllByOrderByCreateTimeDesc();
    }
}
```

### MessageController（`MessageController.java`）

```java
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Controller;
import org.springframework.ui.Model;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestParam;

@Controller
public class MessageController {

    @Autowired
    private MessageService messageService;

    @GetMapping("/messages")
    public String showMessages(Model model) {
        model.addAttribute("messages", messageService.listAllMessages());
        return "messages";
    }

    @PostMapping("/messages")
    public String addMessage(
            @RequestParam("nickname") String nickname,
            @RequestParam("email") String email,
            @RequestParam("content") String content
    ) {
        messageService.saveMessage(nickname, email, content);
        return "redirect:/messages";
    }
}
```

## 4. 页面渲染（JSP 版本，适合简历写“简单留言板”）

`src/main/webapp/WEB-INF/views/messages.jsp`（classpath 可用时也可用 `template` 路径下的 Thymeleaf）：

```jsp
<%@ page contentType="text/html;charset=UTF-8" language="java" %>
<%@ taglib prefix="c" uri="http://java.sun.com/jsp/jstl/core" %>
<html>
<head>
    <title>简易留言板</title>
</head>
<body>
    <h1>我的留言板</h1>

    <!-- 留言表单 -->
    <form action="/messages" method="post">
        <div>
            <label>昵称：</label>
            <input type="text" name="nickname" required />
        </div>
        <div>
            <label>邮箱：</label>
            <input type="email" name="email" />
        </div>
        <div>
            <label>内容：</label>
            <textarea name="content" rows="4" cols="40" required></textarea>
        </div>
        <button type="submit">提交留言</button>
    </form>

    <hr/>

    <!-- 留言列表 -->
    <h2>留言列表</h2>
    <c:choose>
        <c:when test="${empty messages}">
            <p>暂无留言</p>
        </c:when>
        <c:otherwise>
            <ul>
                <c:forEach items="${messages}" var="msg">
                    <li>
                        <strong>${msg.nickname}</strong> (${msg.email})<br/>
                        ${msg.content}<br/>
                        <small>${msg.createTime}</small>
                    </li>
                </c:forEach>
            </ul>
        </c:otherwise>
    </c:choose>
</body>
</html>
```

## 5. 简历写法示例

> **技术栈**：Spring Boot 3 + Spring Web + Spring Data JPA + MySQL + JSP + Maven  
> **项目描述**：  
> 开发一个轻量留言板系统，实现用户留言的提交、持久化与页面展示，覆盖完整的 Web 请求处理流程（表单提交 → Controller 接收 → 业务逻辑 → JPA 数据入库 → 页面渲染）。  
> **个人职责与技术亮点**：  
> - 设计 `message` 表结构，通过 `id`、`nickname`、`email`、`content`、`create_time` 完整表达留言数据，并建立索引提升查询性能。

> - 使用 JSP 视图层遍历 `List<Message>`，将留言列表渲染到前端页面，实现“表单提交 → 请求转发 → 数据入库 → 页面渲染”的完整闭环。  
> - 项目整体采用分层架构（Controller → Service → Repository），职责清晰，可作为学习 Spring Boot Web 开发的基础案例写入简历。 [javaguide](https://javaguide.cn/interview-preparation/resume-guide.html)
