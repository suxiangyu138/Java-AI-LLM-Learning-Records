SpringCloud 必做项目清单（入门→微服务核心→网关→分布式→生产级）
贴合你的 Java后端+大模型应用 职业路线，全部项目对标企业微服务落地标准，覆盖 SpringCloud 全家桶核心组件、分布式架构设计、高可用、可观测性，做完直接具备微服务架构开发与落地能力，是Java后端高薪岗位的核心加分项。
 
一、入门必做（微服务基础架构搭建）
1. 单体项目拆分微服务
技术栈：SpringBoot + SpringCloud
核心知识点
- 微服务拆分原则：按业务域拆分
- 服务提供者/消费者模型
- 父子Maven多模块聚合工程搭建
核心功能
将用户、订单、商品模块拆分为独立微服务，实现基础调用
预计耗时：2天
2. Nacos 注册中心与配置中心
技术栈：SpringCloud Alibaba + Nacos
核心知识点
- 服务注册、发现、健康检查
- 动态配置中心、配置热更新
- 命名空间、分组、多环境隔离
核心功能
微服务注册与统一配置管理，无需重启即可更新配置
预计耗时：2天
 
二、核心必做（微服务通信与网关）
3. OpenFeign 声明式远程调用
技术栈：OpenFeign + Nacos
核心知识点
- 接口式远程调用、负载均衡
- 超时控制、日志打印、请求拦截
- 熔断降级前置实践
核心功能
微服务之间简洁、优雅的跨服务调用
预计耗时：1天
4. SpringCloud Gateway 网关开发
技术栈：SpringCloud Gateway
核心知识点
- 路由配置、断言、过滤器
- 全局跨域、鉴权校验、限流
- 动态路由、负载均衡
核心功能
统一入口网关，实现请求路由、安全校验、流量管控
预计耗时：2~3天
5. 整合 Sentinel 熔断限流
技术栈：SpringCloud Alibaba + Sentinel
核心知识点
- 流量控制、熔断降级、热点限流
- 系统规则、授权规则
- 控制台可视化配置、持久化
核心功能
防止服务雪崩，保障高并发场景下服务稳定性
预计耗时：2天
 
三、分布式必做（企业级高频刚需）
6. 分布式事务（Seata）
技术栈：Seata + Nacos + MySQL
核心知识点
- AT模式、TCC模式原理
- 跨服务数据一致性、事务回滚
- 微服务事务协调
核心功能
跨订单、库存、支付多服务事务，保证数据零脏写
预计耗时：3天
7. 分布式登录认证（OAuth2 + JWT）
技术栈：SpringSecurity + OAuth2 + JWT
核心知识点
- 统一认证中心、令牌发放与校验
- 网关统一鉴权、权限控制
- 刷新令牌、会话管理
核心功能
微服务统一登录认证，多服务共享登录态
预计耗时：3~4天
8. 分布式锁（Redisson）
技术栈：Redisson + Redis
核心知识点
- 可重入锁、公平锁、读写锁
- 锁超时、自动续期、解锁防误删
核心功能
秒杀库存扣减、防重复提交、分布式并发安全控制
预计耗时：2天
 
四、进阶必做（消息、调度、可观测）
9. 微服务异步通信（RabbitMQ）
技术栈：SpringCloud Stream + RabbitMQ
核心知识点
- 消息生产者、消费者绑定
- 消息重试、死信队列、消息幂等
- 异步解耦、削峰填谷
核心功能
订单创建异步通知、日志异步投递、系统解耦
预计耗时：2天
10. 分布式定时任务（XXL-Job）
技术栈：XXL-Job + SpringBoot
核心知识点
- 任务注册、动态调度、分片广播
- 任务日志、失败告警、执行监控
核心功能
定时统计、定时清理、定时推送任务统一调度
预计耗时：2天
11. 链路追踪与可观测性
技术栈：SkyWalking / Sleuth + Zipkin
核心知识点
- 分布式链路追踪、调用链可视化
- 接口耗时分析、异常定位
- 日志、指标、链路三位一体监控
核心功能
快速定位跨服务接口超时、报错问题
预计耗时：3天
 
五、工程化必做（贴合Java+AI大模型方向）
12. 微服务整合大模型服务
技术栈：SpringCloud Gateway + Spring AI + Ollama
核心知识点
- 大模型服务注册到Nacos
- 网关路由大模型请求、限流
- 多模型负载均衡调用
核心功能
企业级大模型微服务化，多业务模块统一调用
预计耗时：3天
13. 微服务容器化与Docker Compose部署
技术栈：Docker + Docker Compose
核心知识点
- 微服务多阶段构建镜像
- 一键编排所有微服务、中间件
- 网络互通、数据持久化
核心功能
整套微服务一键启动，开箱即用
预计耗时：2天
14. 微服务高可用与集群部署
技术栈：Nacos集群 + Sentinel集群 + 多实例部署
核心知识点
- 注册中心集群、网关集群
- 服务多实例、故障自动剔除
- 灰度发布、蓝绿部署
核心功能
微服务集群高可用，支持不停机更新
预计耗时：4天
 
极简必做优先级（6个项目覆盖求职核心）
1. Nacos注册&配置中心
2. SpringCloud Gateway网关
3. OpenFeign远程调用 + Sentinel熔断限流
4. Seata分布式事务
5. OAuth2统一认证中心
6. 微服务整合大模型服务
 
项目落地标准（可直接写进简历）
1. 统一采用 SpringCloud Alibaba 技术栈，贴合国内企业生态
2. 每个项目必须覆盖：服务注册、调用、安全、容错、可观测
3. 代码上传GitHub，README写明：架构图、技术栈、解决的业务痛点
4. 突出微服务拆分、分布式事务、网关鉴权、大模型整合核心亮点
 
推荐技术栈
- 核心框架：SpringCloud Alibaba
- 注册&配置：Nacos
- 网关：SpringCloud Gateway
- 通信：OpenFeign
- 容错：Sentinel
- 事务：Seata
- 认证：SpringSecurity + OAuth2 + JWT
- 部署：Docker + Docker Compose
