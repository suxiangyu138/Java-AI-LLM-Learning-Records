MyBatis 必做项目清单（按「入门 → 进阶 → 企业级规范」递进）
完全贴合Java后端开发路线，所有项目直击MyBatis核心考点、面试高频、简历硬通货，做完能彻底吃透MyBatis、MyBatis-Plus、动态SQL、多表关联、性能优化等核心能力。
 
一、入门必做（吃透MyBatis基础核心）
1. 单表用户CRUD系统
技术栈：MyBatis + MySQL + Maven
核心知识点：
- 全局配置文件、映射文件、Mapper接口绑定
-  #{} 预编译、  ${} 字符串拼接区别
- 增删改查、参数绑定、返回值映射
核心功能：用户注册、登录、查询、修改、删除
预计耗时：2~3天
2. 动态SQL条件查询系统
技术栈：MyBatis + MySQL
核心知识点：
-  <if> 、 <where> 、 <choose> 、 <foreach> 
- 动态条件拼接、多条件模糊查询
核心功能：多条件组合筛选、批量删除、批量插入
预计耗时：2~3天
 
二、进阶必做（多表关联 + 复杂业务）
3. 多表关联权限管理系统
技术栈：MyBatis + MySQL
核心知识点：
- 一对一、一对多、多对多关联查询
-  association 、 collection 、嵌套查询
- 角色、用户、权限、菜单多表设计
核心功能：用户-角色-权限关联查询、菜单权限过滤
预计耗时：3~4天
4. 分页 + 模糊查询项目
技术栈：MyBatis + PageHelper + MySQL
核心知识点：
- 分页插件使用、分页参数封装
- 模糊查询、排序、总条数统计
核心功能：商品/文章列表分页、多条件搜索、排序
预计耗时：2~3天
 
三、MyBatis-Plus 必做（现代开发标配）
5. MP快速CRUD后台管理
技术栈：MyBatis-Plus + SpringBoot + MySQL
核心知识点：
- BaseMapper、IService、CRUD封装
- Lambda表达式查询、条件构造器
- 主键策略、自动填充、逻辑删除
核心功能：用户、角色、部门全量CRUD、自动填充创建/更新时间
预计耗时：2~3天
6. MP复杂条件查询 + 联表查询
技术栈：MyBatis-Plus + SpringBoot + MySQL
核心知识点：
- QueryWrapper、UpdateWrapper
- 自定义XML联表查询、MP混合原生SQL
核心功能：多表联查、复杂筛选、分组统计
预计耗时：3~4天
 
四、企业级必做（性能优化 + 实战场景）
7. 订单系统（事务 + 关联查询）
技术栈：MyBatis + Spring + MySQL
核心知识点：
- 订单-订单项一对多查询
- 事务控制、关联查询性能优化
核心功能：下单、订单详情、订单项查询、订单状态流转
预计耗时：3~4天
8. 商品库存系统（缓存 + MyBatis）
技术栈：MyBatis + SpringBoot + Redis
核心知识点：
- 库存扣减、乐观锁、版本号控制
- 避免超卖、数据一致性
核心功能：商品库存更新、并发扣减、乐观锁防超卖
预计耗时：4~5天
9. MyBatis 二级缓存 + 一级缓存实战
技术栈：MyBatis + SpringBoot
核心知识点：
- 一级缓存、二级缓存开启与失效场景
- 缓存刷新策略、序列化配置
核心功能：查询缓存复用、更新后缓存清空、性能对比
预计耗时：2~3天
