Shell 必做实战项目（从入门到企业级）
下面按难度分级整理了一套必做项目清单，覆盖 Linux 运维、自动化、系统管理、生产排障等核心场景，做完直接具备企业级 Shell 脚本开发能力，所有项目都可直接练手、放到简历里。
一、入门级（夯实基础，掌握语法+流程控制）
目标：熟练变量、数组、循环、条件判断、函数、文本处理（ grep/sed/awk ）
1. 系统信息查看脚本
- 功能：一键输出 CPU、内存、磁盘、系统版本、运行时间、网卡信息
- 核心知识点：系统变量、 free/df/uptime  命令、格式化输出
2. 批量创建用户脚本
- 功能：读取用户列表文件，批量创建 Linux 用户、设置初始密码、配置家目录权限
- 核心知识点： useradd/passwd 、循环、文件读取、权限控制
3. 日志清理脚本
- 功能：自动清理 N 天前的日志文件，支持自定义路径、保留天数、黑白名单
- 核心知识点： find  命令、时间匹配、定时任务  crontab 
4. 批量重命名文件
- 功能：批量修改文件名（后缀替换、前缀添加、序号重排）
- 核心知识点：字符串截取、 mv  批量操作、数组遍历
5. 猜数字小游戏
- 功能：随机生成数字，用户输入猜测，提示大小，统计次数
- 核心知识点： $RANDOM 、循环、条件判断、交互式输入
二、进阶级（自动化运维，企业高频场景）
目标：掌握定时任务、服务监控、备份、部署、日志分析，适配日常运维工作
1. MySQL 数据库备份脚本
- 功能：全量备份+定时压缩、自动清理过期备份、备份失败邮件告警
- 核心知识点： mysqldump 、压缩打包、邮件发送、异常捕获
2. 服务状态监控脚本
- 功能：监控 Nginx/Java/Redis 等服务，宕机自动重启，异常推送告警
- 核心知识点： ps/netstat 、进程检测、服务重启、条件判断
3. 一键部署 Nginx 环境
- 功能：自动安装依赖、编译/ yum 安装 Nginx、配置开机自启、初始化配置文件
- 核心知识点：包管理、服务管理、文件写入、权限配置
4. 磁盘空间告警脚本
- 功能：检测磁盘使用率，超过阈值自动邮件/钉钉告警
- 核心知识点： df  数据提取、数值比较、企业微信/钉钉 Webhook 推送
5. 日志错误统计分析
- 功能：分析 Nginx/Java 日志，统计 4xx/5xx 错误、接口访问量、IP 访问排行
- 核心知识点： awk  文本统计、排序、去重、格式化报表
三、高阶实战（企业级生产项目，简历加分项）
目标：掌握模块化、高可用、容错处理、分布式场景，对标企业生产环境
1. 服务器巡检一体化脚本
- 功能：CPU/内存/磁盘/网络/进程/端口/日志错误 全维度巡检，生成 Markdown 巡检报告
- 核心知识点：多模块函数、日志分级、报表生成、定时推送
2. 多服务器批量运维脚本
- 功能：通过 SSH 免密登录，批量执行命令、批量推送文件、批量重启服务
- 核心知识点： sshpass 、免密密钥、循环遍历主机列表、批量并发
3. 项目一键打包部署脚本
- 功能：Java 项目打包、停止旧服务、备份旧包、上传新包、启动服务、健康检测
- 核心知识点：进程锁、端口检测、启动日志监控、回滚机制
4. 容器环境辅助脚本（Docker）
- 功能：批量清理无用镜像/容器、容器日志轮转、一键备份容器数据
- 核心知识点： docker  命令批量操作、数据卷管理、定时清理
5. 系统安全加固脚本
- 功能：关闭不必要端口、修改 SSH 配置、禁用 root 远程登录、防火墙规则配置
- 核心知识点：防火墙、系统配置修改、安全策略、权限加固
四、极致进阶（脚本工程化，对标专业开发）
1. Shell 命令行工具开发
- 自定义命令工具，支持参数解析、帮助文档、子命令（类似  git  子命令）
2. 日志系统脚本
- 实现日志分级、日志切割、日志压缩、日志过期清理，可复用的日志模块
3. CI/CD 简易流水线脚本
- 对接 Git，代码拉取、编译、测试、部署、通知的完整自动化流程
五、练手建议
1. 入门阶段优先做日志清理、系统信息、批量用户，快速上手语法；
2. 进阶阶段锁定备份、监控、部署三大场景，覆盖 80% 企业运维需求；
3. 高阶项目直接对接工作/学习环境，比如给自己的服务器写巡检脚本、给项目写部署脚本，实战价值最高；
4. 所有脚本必须加容错处理、日志输出、注释、帮助文档，符合企业规范。
