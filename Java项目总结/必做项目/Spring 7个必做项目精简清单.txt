Spring 7个必做项目精简清单
严格遵循基础原理 → 框架实战 → 中间件整合 → 企业高并发 → AI融合的进阶路线，完全适配你的 Java后端 + AI大模型应用 职业规划，每个项目标注核心知识点、技术栈、预计耗时，可直接按顺序执行。
 
1. Spring 原生 IOC & AOP 手写实战
定位：吃透Spring底层原理，面试核心考点
- 技术栈：Java SE + 反射 + 注解
- 核心知识点：
- IOC容器：Bean定义、依赖注入、单例池、Bean生命周期
- AOP：JDK/CGLIB动态代理、切面、切点、通知
- 预计耗时：3~5天
- 产出：极简版Spring容器，实现对象创建、依赖注入、切面增强
2. SpringMVC 前后端分离基础项目
定位：掌握Web请求核心流程，夯实MVC架构
- 技术栈：SpringMVC + MySQL + Maven
- 核心知识点：
- 请求映射、参数绑定、JSON序列化
- 全局异常处理、统一返回体
- 拦截器登录鉴权、文件上传
- 预计耗时：4~6天
- 产出：用户管理系统（登录、注册、CRUD、权限拦截）
3. SpringBoot 个人博客后端
定位：入门SpringBoot，掌握现代后端开发范式
- 技术栈：SpringBoot + MyBatis-Plus + MySQL + Knife4j
- 核心知识点：
- 自动配置、约定大于配置
- ORM持久层、分页、条件查询
- 接口文档、全局异常、跨域处理
- 预计耗时：5~7天
- 产出：完整博客后端（文章、评论、标签、分类、权限）
4. SpringBoot + Redis 缓存实战项目
定位：企业级缓存能力，解决性能问题
- 技术栈：SpringBoot + Redis + MySQL
- 核心知识点：
- 缓存三大问题：穿透/击穿/雪崩
- 分布式锁、热点数据缓存、缓存更新策略
- 预计耗时：4~5天
- 产出：商品详情页系统（缓存优化、库存防超卖）
5. SpringBoot + RabbitMQ 异步消息项目
定位：掌握异步解耦，对接企业业务场景
- 技术栈：SpringBoot + RabbitMQ + MySQL
- 核心知识点：
- 交换机、队列、死信队列
- 消息可靠性、异步通知、解耦设计
- 预计耗时：4~5天
- 产出：订单异步通知系统（下单、短信/邮件推送、超时取消）
6. SpringBoot 高并发秒杀系统
定位：校招/实习简历加分核心，解决高并发场景
- 技术栈：SpringBoot + Redis + RabbitMQ + MySQL
- 核心知识点：
- 库存预扣、限流防刷、分布式锁
- 异步下单、削峰填谷、事务控制
- 预计耗时：7~10天
- 产出：完整秒杀业务（商品预热、下单、库存扣减、订单异步处理）
7. SpringBoot + Ollama 本地大模型RAG问答系统
定位：差异化竞争力，贴合Java+AI职业规划
- 技术栈：SpringBoot + Ollama + Milvus + PDF解析
- 核心知识点：
- 大模型接口封装、流式输出
- 文档向量化、检索增强、上下文对话
- 预计耗时：7~10天
- 产出：私有化知识库问答系统，支持PDF文档导入、精准问答
 
配套执行标准（保证学习效果）
1. 所有项目代码上传至 GitHub，仓库名规范，提交记录清晰
2. 每个项目编写标准  README.md ：技术栈、功能、部署步骤、核心难点
3. 严格遵循阿里巴巴Java开发手册，代码分层规范（Controller/Service/Dao/Entity）
4. 接口必须有统一返回体、全局异常处理、参数校验
