JVM 必做项目清单（从基础→内存模型→调优→故障排查→企业级实战）
结合你的 Java后端 职业方向，所有项目围绕 JVM核心原理、性能调优、线上故障排查、内存模型 展开，覆盖面试高频考点 + 企业真实落地场景，做完彻底吃透 JVM，搞定面试与线上问题。
 
一、入门必做（吃透 JVM 基础架构）
1. JVM 内存区域划分实战
核心知识点
- 堆、栈、方法区、本地方法栈、程序计数器
- 各区域作用、内存溢出场景
- 虚拟机栈帧结构、局部变量表、操作数栈
核心功能
手写代码触发不同内存区域 OOM，理解内存分布
预计耗时：1天
2. 类加载机制与双亲委派模型
核心知识点
- 类加载全过程：加载→链接→初始化
- 双亲委派模型、破坏双亲委派场景
- 自定义类加载器
核心功能
手写自定义类加载器，打破双亲委派，实现热加载
预计耗时：2天
3. 对象创建与内存布局
核心知识点
- 对象创建流程、对象头、实例数据、对齐填充
- 指针压缩、对象内存大小计算
- 逃逸分析、栈上分配、标量替换
核心功能
分析对象内存布局，对比不同JVM参数下对象大小
预计耗时：1~2天
 
二、进阶必做（垃圾回收 + 内存模型）
4. 垃圾回收算法与GC种类对比
核心知识点
- 标记清除、标记复制、标记整理
- 分代回收、年轻代/老年代/元空间
- Serial、Parallel、CMS、G1、ZGC 核心原理
核心功能
切换不同垃圾收集器，观察GC日志差异
预计耗时：2天
5. GC日志分析实战
核心知识点
- GC日志参数配置、日志解读
- Minor GC、Full GC 触发条件
- 吞吐量、停顿时间、GC频率分析
核心功能
通过日志定位GC瓶颈，判断内存泄漏、内存溢出
预计耗时：2天
6. JMM 内存模型与 volatile 深度实战
核心知识点
- 主内存、工作内存、内存屏障
- volatile 可见性、禁止指令重排
- DCL 单例模式、happens-before 规则
核心功能
手写代码验证volatile特性，实现线程安全单例
预计耗时：2天
 
三、核心必做（JVM 调优实战）
7. JVM 参数调优实战
核心知识点
- 堆内存参数： -Xms   -Xmx   -Xmn 
- 元空间、栈内存、直接内存配置
- GC参数、逃逸分析、指针压缩
核心功能
根据业务场景配置最优JVM参数，降低GC停顿
预计耗时：2~3天
8. 内存泄漏排查实战
核心知识点
- 内存泄漏常见场景：集合持有对象、静态变量、线程不退出
- 内存溢出 OOM 分类与排查思路
- jmap、jhat、MAT 工具分析堆快照
核心功能
制造内存泄漏，使用工具定位泄漏代码
预计耗时：3天
9. 高并发下 JVM 调优
核心知识点
- 高并发下内存分配、TLAB、栈上分配
- 锁升级、偏向锁、轻量级锁、重量级锁
- 线程栈溢出、死锁排查
核心功能
压测场景下优化JVM，提升吞吐量、降低停顿
预计耗时：3天
 
四、企业级必做（线上故障排查 + 性能优化）
10. 线上CPU飙高排查实战
核心知识点
- top、jps、jstack、jmap、jstat 命令组合排查
- 线程Dump分析、死锁定位、死循环代码定位
核心功能
模拟CPU飙高，一步步定位问题代码
预计耗时：2天
11. 频繁FullGC 故障排查
核心知识点
- 大对象、内存泄漏、堆内存过小、元空间溢出
- 新生代晋升老年代过快、GC参数不合理
核心功能
定位频繁FullGC根因，给出优化方案
预计耗时：2~3天
12. 接口响应慢 全链路排查
核心知识点
- GC停顿、内存抖动、线程阻塞、锁竞争
- 结合 Arthas 工具实时监控JVM状态
核心功能
定位JVM层面导致接口超时的问题
预计耗时：3天
13. 线上JVM 监控体系搭建
核心知识点
- Prometheus + Grafana 监控JVM指标
- 堆内存、非堆、GC指标、线程数、类加载数
- 告警配置：内存使用率、FullGC次数
核心功能
可视化监控JVM状态，提前预警故障
预计耗时：3天
 
五、高阶必做（底层原理 + 新特性）
14. ZGC / Shenandoah 低延迟GC实战
核心知识点
- ZGC 染色指针、读屏障、并发压缩
- 低延迟GC参数配置
- 对比G1与ZGC停顿时间
核心功能
搭建低延迟JVM环境，验证亚毫秒级GC
预计耗时：3天
15. JVM 字节码实战
核心知识点
- javap 字节码查看、指令集理解
- 同步锁、volatile、try-catch 字节码实现
核心功能
分析代码底层字节码，理解JVM执行逻辑
预计耗时：2天
 
极简必做优先级（6个项目覆盖面试+求职核心）
1. 内存区域划分 + 对象内存布局
2. 垃圾回收算法 + GC日志分析
3. JMM内存模型 + volatile实战
4. 内存泄漏排查（MAT工具）
5. 线上CPU飙高排查实战
6. 频繁FullGC故障排查
 
项目落地标准（可直接写进简历）
1. 每个项目附带 模拟场景 + 问题现象 + 排查步骤 + 优化方案
2. 熟练使用：jps / jstat / jmap / jhat / jstack / MAT / Arthas
3. 调优项目需给出 优化前后对比数据（GC停顿、吞吐量、内存占用）
4. 突出 线上故障排查、内存泄漏、GC调优、性能优化 核心亮点
 
推荐配套工具
- 命令行：jps、jstat、jmap、jhat、jstack
- 可视化：JVisualVM、MAT
- 线上排查：Arthas
- 监控：Prometheus + Grafana
- 压测：JMeter
