Spring Cloud Alibaba 必做项目（从入门到企业级，适配Java后端就业）
所有项目完全贴合企业真实开发场景，无缝衔接你已掌握的 SpringBoot、MySQL、Redis、MQ 等技术，是校招/社招后端岗位的核心加分项。
 
一、入门级：微服务基础整合（吃透核心组件，建立微服务思维）
目标：掌握 Nacos、OpenFeign、Sentinel、Gateway 四大核心组件，理解微服务拆分、注册发现、远程调用、网关路由基础逻辑
1. 微服务基础商城（极简版）
- 核心功能：用户服务、商品服务、订单服务、网关统一入口、服务注册与发现
- 核心技术：Spring Cloud Alibaba、Nacos（注册中心+配置中心）、OpenFeign、Gateway
- 核心知识点：
- 微服务业务拆分原则
- Nacos 服务注册、动态配置、配置共享
- OpenFeign 声明式远程调用、负载均衡
- Gateway 路由转发、跨域处理
2. 网关限流熔断系统
- 核心功能：接口限流、熔断降级、热点参数限流、自定义限流规则、降级策略配置
- 核心技术：Sentinel、Gateway、Nacos 持久化限流规则
- 核心知识点：
- 限流、熔断、降级的区别
- Sentinel 流量控制、熔断策略、系统自适应保护
- 网关层统一流量管控
 
二、进阶级：分布式核心能力实战（企业刚需，校招高频考点）
目标：掌握分布式事务、消息队列、分布式锁、分布式会话，解决微服务核心痛点
1. 分布式电商订单系统
- 核心功能：下单、库存扣减、订单创建、支付回调、超时关单、分布式事务一致性
- 核心技术：Seata、RabbitMQ、Redis、Nacos、MySQL
- 核心知识点：
- Seata AT 模式分布式事务
- 库存超卖问题解决、分布式锁（Redisson）
- 延时队列实现超时关单
- 本地消息表、可靠消息最终一致性
2. 分布式权限管理系统
- 核心功能：多服务统一认证、JWT 令牌、RBAC 权限、分布式会话共享、接口鉴权
- 核心技术：Spring Security、Gateway、Redis、Nacos
- 核心知识点：
- 微服务统一认证授权方案
- JWT 令牌签发、校验、刷新
- 网关层鉴权、服务内接口权限控制
- 分布式会话、Redis 共享存储
 
三、高阶实战：高并发/高可用企业级项目（简历王牌，大厂加分项）
目标：掌握高并发架构设计、缓存穿透/击穿/雪崩、异步解耦、链路追踪、性能优化
1. 秒杀系统
- 核心功能：商品秒杀、库存预热、限流防刷、异步下单、订单削峰、超卖防护
- 核心技术：Redis、RabbitMQ、Sentinel、Seata、Nacos
- 核心知识点：
- 秒杀架构设计、库存预热
- 令牌桶限流、接口防刷、黑名单机制
- 异步削峰、消息队列解耦
- 缓存穿透/击穿/雪崩解决方案
2. 分布式日志&链路追踪平台
- 核心功能：全链路日志采集、调用链追踪、异常告警、日志检索、耗时分析
- 核心技术：SkyWalking、ELK、Gateway、Nacos
- 核心知识点：
- 分布式追踪原理、TraceId 透传
- 微服务日志规范化、异常统一捕获
- 性能瓶颈定位、接口耗时优化
 
四、全栈融合项目（对接前端+AI，打造差异化竞争力）
目标：打通微服务+前后端分离+AI能力，实现全链路闭环，适配你 Java+AI 职业规划
1. 微服务化 AI 智能问答平台
- 核心功能：用户中心、知识库服务、AI对话服务、网关统一入口、限流熔断
- 核心技术：Spring Cloud Alibaba、Spring AI、Milvus、Vue3、WebSocket
- 核心知识点：
- AI能力微服务拆分
- 大模型调用限流、Token 配额管控
- 流式对话网关转发、会话分布式存储
2. 全栈智慧商城（前后端分离）
- 核心功能：首页、购物车、订单、支付、秒杀、后台管理、数据大屏
- 核心技术：Spring Cloud Alibaba、Vue3、Redis、RabbitMQ、Seata、Gateway
- 核心知识点：
- 微服务+前后端分离全链路开发
- 高并发场景优化、接口性能调优
- 生产级部署、Nginx 反向代理
 
五、结合你的方向 优先必做清单
1. 微服务基础商城（入门必做，吃透 Nacos/Feign/Gateway 核心组件）
2. 分布式电商订单系统（校招核心，掌握分布式事务、MQ、分布式锁）
3. 秒杀系统（简历王牌，体现高并发架构设计能力）
4. 微服务化 AI 智能问答平台（差异化核心，微服务+AI融合，远超普通后端）
 
六、练手路线建议
1. 入门：先做微服务基础商城，搞懂微服务拆分、注册发现、远程调用、网关路由；
2. 进阶：主攻分布式电商订单系统，吃透分布式事务、消息队列、分布式锁等企业级核心难点；
3. 高阶：完成秒杀系统，掌握高并发架构设计、限流防刷、缓存优化；
4. 差异化：落地微服务化 AI 智能问答平台，将微服务架构与 Spring AI 结合，打造专属竞争力。
