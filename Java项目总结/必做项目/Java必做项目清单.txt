Java必做项目清单
下面按 入门 → 进阶 → 企业级实战 → 高阶架构 路线，整理Java必做项目清单，完全贴合你 Java后端 + AI大模型应用 的职业规划，所有项目都是简历高频考点、面试必问、企业真实业务场景，做完直接对标校招/实习水平。
一、入门必做（夯实Java基础 + 面向对象）
适合刚学完Java SE，练语法、OOP、集合、IO、异常、多线程。
1. 控制台图书管理系统
核心：类与对象、封装、集合存储、增删改查、文件持久化
2. 简易ATM银行系统
核心：面向对象、继承、多态、异常处理、流程控制
3. 学生成绩管理系统
核心：数组/集合、排序、查找、统计分析
4. 贪吃蛇（Java Swing）
核心：GUI编程、多线程、事件监听、面向对象
5. 简易计算器
核心：逻辑运算、异常捕获、方法封装


二、Web基础项目（Java Web 核心能力）
衔接Java SE到Spring，掌握Servlet、JSP、MVC、数据库交互。
1. JSP+Servlet 个人博客
核心：MVC模式、JDBC、Cookie/Session、登录注册、分页
2. 简易留言板
核心：表单提交、请求转发、数据入库、页面渲染
3. 用户权限管理系统
核心：角色权限、过滤器、登录拦截、RBAC基础

三、SSM 框架实战（Java后端传统主流）
吃透Spring + SpringMVC + MyBatis，校招基础必备。
1. SSM 校园二手商城
核心：CRUD、文件上传、分页、条件查询、事务控制
2. SSM 员工管理系统
核心：多表联查、动态SQL、拦截器、全局异常处理
3. 在线考试系统
核心：题库管理、试卷生成、自动判分、成绩统计

四、SpringBoot 核心必做（现代Java后端标准）
企业90%项目都用SpringBoot，必须熟练掌握。
1. 个人博客系统（SpringBoot + Thymeleaf）
核心：自动配置、MyBatis-Plus、分页、评论、权限控制
2. 在线图书商城
核心：商品管理、购物车、订单、物流状态、事务
3. 后台管理系统（SpringBoot + Vue）
核心：前后端分离、JWT、RBAC权限、接口规范
4. 文件上传下载系统
核心：本地存储/阿里云OSS、断点续传、文件类型校验


五、中间件实战项目（企业级必备技能）
对接Redis、MQ、MySQL优化，解决高并发、缓存、异步问题。
1. Redis 秒杀系统
核心：缓存预热、超卖问题、分布式锁、库存扣减
2. RabbitMQ 消息异步通知
核心：异步解耦、邮件/短信推送、死信队列、消息重试
3. MySQL 电商订单系统
核心：索引优化、分表、事务隔离级别、慢查询优化
4. Redis 分布式Session共享
核心：集群登录、会话同步、缓存击穿/穿透/雪崩


六、微服务 & SpringCloud 项目（中大厂标配）
对标一线企业架构，适合实习/校招加分。
1. SpringCloud 电商微服务
技术：Nacos + Feign + Gateway + Sentinel
核心：服务注册发现、网关路由、限流熔断、配置中心
2. 分布式订单系统
核心：Seata分布式事务、库存锁定、订单超时取消
3. 微服务后台权限平台
核心：OAuth2.0、网关鉴权、统一认证中心


七、AI 大模型结合项目（贴合你的职业规划）
Java后端 + AI大模型应用，差异化竞争力核心。
1. Java + Ollama 本地大模型问答接口
核心：HTTP调用本地大模型、接口封装、参数配置
2. RAG 知识库问答系统（Java版）
技术：SpringBoot + Milvus/ES + Ollama
核心：文档解析、向量库存储、检索增强、上下文问答
3. AI 智能客服系统
核心：多轮对话、意图识别、知识库匹配、接口限流
4. AI 代码生成工具
核心：调用大模型API、代码格式化、语法校验


八、高阶架构项目（冲击大厂/高薪）
1. 分布式短链接系统
核心：URL压缩、Redis缓存、布隆过滤器、访问统计
2. 高并发直播弹幕系统
核心：Netty、WebSocket、异步推送、限流
3. 多级缓存商品详情页
核心：本地缓存 + Redis + CDN、缓存更新策略
4. 分布式定时任务平台
技术：XXL-Job
核心：任务调度、动态配置、失败重试、日志监控


九、必做开源项目（简历天花板加分）
1. 仿牛客网社区项目
核心：Redis点赞、Kafka消息、ES搜索、事务、拦截器
2. 仿抖音短视频后端
核心：分布式存储、推荐流、关注/粉丝、热点推送
3. 企业级权限管理框架（RuoYi-Vue）
学习：代码生成器、多数据源、定时任务、监控
 
学习路线建议（适配你的规划）
1. 先完成 Java SE → Java Web → SSM → SpringBoot 基础项目，把CRUD、事务、权限打牢
2. 再攻坚 Redis、MQ、MySQL优化 中间件项目，解决企业高频问题
3. 重点发力 SpringBoot + AI大模型 项目，打造差异化竞争力
4. 最后做 微服务/分布式 项目，冲击大厂实习
简历优化建议
每个项目都要做到：
- 写清 技术栈 + 核心难点 + 你的解决方案
- 代码上传 GitHub，写标准 README
- 重点突出 性能优化、高并发、AI结合 亮点
