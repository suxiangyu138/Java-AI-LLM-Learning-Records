MongoDB 必做实战项目（由浅入深，全覆盖学习考点+面试常用）
适配零基础入门、课程作业、简历项目、后端开发，每个项目附带核心知识点、功能清单、技术要点，直接照着做就能吃透 MongoDB。
一、入门级（基础CRUD+文档设计）
项目1：个人备忘录/笔记系统
核心知识点：
文档增删改查、条件查询、分页、排序、简单过滤、日期存储
核心功能
1. 笔记新增、编辑、删除、查看
2. 按标题/内容模糊搜索
3. 按创建时间排序、分页查询
4. 笔记分类标签存储
难点练习： $regex 模糊查询、 skip/limit 分页
项目2：图书信息管理系统
核心知识点：
嵌套文档、数组操作、多条件复合查询、字段投影
核心功能
1. 图书信息入库（书名、作者、价格、分类、简介）
2. 按价格区间、分类、作者筛选图书
3. 只查询指定字段（投影 project ）
4. 批量修改图书状态
难点练习：数组操作符 $push/$pull 、嵌套子文档查询
 
二、进阶级（索引+聚合+关联查询）
项目3：电商商品模块（高频面试项目）
核心知识点：
复合索引、聚合查询 aggregate 、数组筛选、分组统计、软删除
核心功能
1. 商品SKU、规格、图片数组存储
2. 商品销量统计、分类销量排行
3. 价格区间筛选、热门商品排序
4. 添加索引优化查询速度
5. 商品上下架（软删除标记）
难点练习：聚合管道、 $group/$match/$sort 、索引优化
项目4：用户评论&回复系统
核心知识点：
一对多文档设计、嵌入式文档、数组嵌套、评论分页、点赞数更新
核心功能
1. 文章绑定多条评论
2. 评论二级回复嵌套存储
3. 评论点赞、取消点赞（原子更新）
4. 筛选最新/最热评论
难点练习： $inc 原子自增、嵌套数组更新
 
三、高阶级（集群+事务+性能+实战业务）
项目5：短视频/动态发布系统
核心知识点：
大文档存储、海量数据场景、TTL过期索引、事务、唯一索引
核心功能
1. 用户发布动态、图文/视频链接存储
2. 点赞、收藏、关注关系存储
3. 过期动态自动清理（TTL索引）
4. 防止重复点赞（唯一索引）
难点练习：TTL索引、唯一约束、高并发简单优化
项目6：后台日志收集分析系统
核心知识点：
日志海量写入、聚合统计、数据分片思想、日志筛选
核心功能
1. 系统操作日志、错误日志入库
2. 按时间段、日志级别、接口地址统计错误量
3. 日志批量清理、异常日志筛选
难点练习：大数据量查询优化、聚合统计报表
 
四、综合完整项目（简历加分首选）
项目7：完整社区论坛系统（推荐必做）
全套 MongoDB 技术栈全覆盖
1. 用户模块：用户文档、密码加密、角色权限
2. 帖子模块：发帖、编辑、删除、置顶、精华
3. 互动模块：评论、回复、点赞、收藏、关注
4. 高级功能：
- 聚合统计：帖子阅读量、用户发帖数
- 索引优化：高频查询字段建索引
- 事务操作：发帖+积分变动原子执行
- 数据脱敏、批量操作
 
五、必练核心语法（做项目必用到）
1. 基础： insertOne / insertMany / find / updateOne / deleteOne 
2. 查询：条件运算符 $gt/$lt/$in/$ne 、正则、分页排序
3. 聚合： aggregate  管道分组、统计、联表
4. 优化：单字段索引、复合索引、TTL索引
5. 高阶：事务、原子更新 $inc 、软删除、文档关联设计
 
六、配套技术组合（快速落地）
- 后端：Node.js(Express/Koa) / Java(SpringBoot) / Python
- 驱动：
- Java： Spring Data MongoDB 
- Node： mongoose 
- Python： pymongo
