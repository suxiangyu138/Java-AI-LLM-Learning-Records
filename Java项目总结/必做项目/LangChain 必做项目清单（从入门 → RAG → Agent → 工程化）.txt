LangChain 必做项目清单（从入门 → RAG → Agent → 工程化）
贴合你 Java后端 + 大模型应用 的职业规划，聚焦企业落地场景，全部项目可直接写进简历，兼顾「Python快速验证」和「Java工程化复用」，覆盖LangChain核心模块：模型调用、Prompt、文档加载、文本分割、向量库、RAG、工具调用、Agent、记忆链。
 
一、入门必做（吃透LangChain基础链路）
1. 基础对话链 + 多轮记忆对话
技术栈：LangChain + Ollama
核心知识点
- ChatOpenAI / Ollama 模型封装
- PromptTemplate、ChatPromptTemplate
- 会话记忆：ConversationBufferMemory、SummaryMemory
- 链式调用：LCEL 表达式、Runnable 编排
核心功能
多轮上下文对话、对话总结记忆、自定义角色对话
预计耗时：1~2天
2. Prompt工程模块化项目
技术栈：LangChain + Ollama
核心知识点
- 少样本提示 FewShotPromptTemplate
- 动态变量注入、格式约束
- 输出解析器：PydanticOutputParser、StrOutputParser
核心功能
代码生成、结构化JSON输出、文档总结、翻译改写
预计耗时：2天
 
二、核心必做（RAG检索增强，企业刚需）
3. 单文件PDF知识库问答
技术栈：LangChain + Ollama + Chroma/Milvus
核心知识点
- 文档加载：PyPDFLoader、DirectoryLoader
- 文本分割：RecursiveCharacterTextSplitter
- 嵌入模型：BGE、m3e 中文向量
- 检索链：RetrievalQA、Stuff/MapReduce/Refine 问答链
核心功能
上传PDF，AI精准回答文档内问题、引用溯源
预计耗时：2~3天
4. 多文档混合RAG系统
技术栈：LangChain + Milvus
核心知识点
- 批量文档加载、文件夹遍历
- 持久化向量库、增量更新
- 相似度检索、TopK 召回
核心功能
多PDF/TXT文档统一知识库、跨文档问答
预计耗时：3天
5. 网页实时RAG问答
技术栈：LangChain + 爬虫 + Ollama
核心知识点
- WebBaseLoader 网页加载、正文清洗
- 临时向量库构建、实时问答
核心功能
输入网页URL，AI基于网页内容回答问题
预计耗时：2~3天
6. RAG检索优化实战
技术栈：LangChain + Milvus
核心知识点
- 混合检索：关键词+向量检索
- 重排序：CrossEncoderReranker
- 分块策略调优、重叠窗口、语义分块
核心功能
提升问答准确率、解决幻觉、精准溯源
预计耗时：3~4天
 
三、进阶必做（Agent智能体，高阶竞争力）
7. 基础工具调用Agent
技术栈：LangChain + Ollama
核心知识点
- 自定义工具、StructuredTool
- Agent 类型：ReAct、OpenAI Functions Agent
- 思考-行动-观察循环、错误重试
核心功能
计算器、文件读写、时间查询、接口调用
预计耗时：3天
8. 联网搜索Agent
技术栈：LangChain + SerpAPI/DuckDuckGo
核心知识点
- 联网搜索工具集成
- 实时信息获取、时效性问答
核心功能
回答最新热点、新闻、实时数据问题
预计耗时：2~3天
9. 多任务规划Agent
技术栈：LangChain + Ollama
核心知识点
- Plan-and-Execute 规划执行Agent
- 复杂任务拆解、分步执行、状态追踪
核心功能
拆解复杂需求、自动生成执行步骤、落地完成任务
预计耗时：4天
 
四、工程化必做（后端整合 + 业务落地）
10. 带权限的企业级RAG后台
技术栈：LangChain + FastAPI + Milvus + MySQL
核心知识点
- 用户会话隔离、文档权限管理
- 问答记录存储、日志监控
- 接口限流、异步处理
核心功能
多用户独立知识库、文档上传管理、问答溯源、后台管理
预计耗时：4~5天
11. 智能客服对话系统
技术栈：LangChain + RAG + Ollama
核心知识点
- 意图识别、知识库匹配
- 多轮对话、人工转接
- 对话情感分析、问题分类
核心功能
企业客服自动问答、工单生成、运营数据分析
预计耗时：4~5天
12. 代码生成&调试Agent
技术栈：LangChain + CodeLlama + Ollama
核心知识点
- 代码工具调用、语法校验
- 代码执行、错误修复、注释生成
核心功能
Java/Python代码生成、调试、优化、文档生成
预计耗时：3~4天
 
五、高阶必做（性能优化 + 部署）
13. LangChain 流式输出 + SSE 接口
技术栈：LangChain + FastAPI + Ollama
核心知识点
- 流式回调、StreamingResponse
- 前端打字机效果、实时输出
核心功能
大模型流式问答接口、前后端实时交互
预计耗时：2天
14. Docker 容器化部署LangChain应用
技术栈：Docker + LangChain + Milvus
核心知识点
- 多服务容器编排、环境隔离
- 一键部署、持久化向量数据
核心功能
私有化AI应用集群、快速部署、扩容
预计耗时：3天
 
极简必做优先级（只做6个就够）
1. 多轮记忆对话 + LCEL 基础
2. PDF单文件RAG问答
3. 网页实时RAG问答
4. 工具调用Agent
5. 联网搜索Agent
6. 企业级RAG后台
 
项目落地标准（可直接写进简历）
1. 代码上传GitHub，附带标准README
2. 突出 RAG检索、Agent工具调用、私有化部署、工程化封装
3. 项目必须覆盖：文档管理、问答溯源、会话记忆、异常处理
4. 优先对接 Ollama + Milvus，无缝迁移到Java SpringAI生态
 
推荐技术栈
- 大模型：Ollama
- 向量库：Chroma（入门）、Milvus（企业）
- 嵌入模型：BGE、m3e
- 后端：FastAPI / SpringAI
- 部署：Docker
