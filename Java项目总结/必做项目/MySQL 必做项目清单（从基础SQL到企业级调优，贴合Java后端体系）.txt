MySQL 必做项目清单（从基础SQL到企业级调优，贴合Java后端体系）
一、入门必做（夯实SQL基础语法）
目标：熟练CRUD、约束、函数、联表查询，写规范SQL
1. 学生信息管理系统（单表操作）
核心知识点
- DDL/DML/DCL语句
- 主键、非空、唯一、默认值约束
- 增删改查、排序、分页、聚合函数
功能
学生信息录入、修改、删除、多条件筛选、成绩统计
2. 员工部门薪资系统（多表联查）
核心知识点
- 一对一、一对多关系设计
-  INNER JOIN / LEFT JOIN / RIGHT JOIN 
- 分组统计、子查询、exists、in
功能
部门员工关联查询、薪资排名、部门人数统计、多条件组合查询
 
二、进阶必做（数据库设计规范）
目标：掌握三大范式、索引、事务、视图、存储过程，贴合真实业务
3. 电商用户权限系统（多对多设计）
核心知识点
- 三大范式、ER图设计
- 用户-角色-权限 多对多中间表
- 联合主键、外键约束、索引设计
功能
用户角色分配、权限关联、多表联合查询
4. 图书借阅管理系统（事务实战）
核心知识点
- 事务ACID、隔离级别
-  COMMIT / ROLLBACK 、手动事务控制
- 脏读、不可重复读、幻读场景模拟
功能
借书扣库存、还书恢复库存、异常回滚
5. 视图、存储过程、触发器实战
核心知识点
- 视图创建与使用
- 存储过程、函数、参数传递
- 触发器（增删改触发自动操作）
功能
统计视图、批量操作存储过程、数据变更日志触发器
 
三、企业级业务项目（和SpringBoot/MyBatis联动）
目标：对接Java后端，做真实业务表设计、SQL编写
6. 博客系统数据库设计
表结构
用户表、文章表、评论表、分类表、标签表
核心
一对多、多对多、时间戳、软删除、索引优化
7. 电商订单系统数据库
表结构
用户、商品、订单、订单项、购物车、地址
核心
- 订单状态流转、外键关联
- 库存扣减SQL、事务一致性
- 联合索引、订单号生成、分表基础
8. 秒杀系统数据库设计
核心
- 库存防超卖SQL
- 乐观锁、悲观锁、行级锁
- 秒杀订单表、防刷记录表
场景
并发扣库存、防止超卖、订单超时关闭
 
四、性能调优必做（面试高频核心）
9. MySQL索引优化实战
核心知识点
- B+树索引、聚簇/非聚簇索引
- 联合索引、最左前缀原则
- 覆盖索引、索引失效场景
实战
慢SQL分析、 EXPLAIN 执行计划、优化前后对比
10. 慢查询优化项目
核心
- 开启慢查询日志
-  EXPLAIN 分析SQL
- 优化子查询、避免全表扫描
- limit分页优化、order by优化
11. MySQL锁机制实战
核心
- 共享锁、排他锁
- 行锁、表锁、意向锁
- 死锁模拟与解决
场景
并发更新、事务隔离级别测试
 
五、高阶架构项目（大厂必备）
12. MySQL主从复制搭建
核心
- 主从同步原理
- binlog配置、读写分离
- 一主一从、一主多从搭建
13. 分库分表实战
核心
- 水平分表、垂直分表
- 分表主键设计、路由规则
- 解决大表查询性能问题
 
极简必做优先级（只做6个就够）
1. 员工部门薪资系统（联表查询）
2. 电商用户权限系统（多对多表设计）
3. 图书借阅系统（事务）
4. 博客系统数据库设计
5. 索引优化 + EXPLAIN实战
6. 电商订单系统数据库
 
项目落地标准（可写进简历）
1. 每张表都有主键、必要索引、字段注释
2. 严格遵循三大范式，合理拆分表
3. 所有业务SQL无语法错误，无索引失效问题
4. 导出SQL脚本，上传GitHub，附带表结构说明文档
