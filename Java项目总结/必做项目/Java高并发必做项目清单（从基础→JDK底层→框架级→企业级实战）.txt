Java高并发必做项目清单（从基础→JDK底层→框架级→企业级实战）
贴合你的 Java后端 求职路线，全部项目围绕面试高频考点、企业真实并发场景、性能优化展开，从JDK原生并发到分布式高并发全覆盖，做完直接吃透Java并发核心，面试高并发问题基本都能拿下。
 
一、入门必做（JDK基础并发）
1. 线程基础与线程池实战
核心知识点
- Thread、Runnable、Callable、Future
- 线程生命周期、状态流转
- ThreadPoolExecutor 七大参数、拒绝策略
- 核心线程池：Fixed、Cached、Scheduled、Single
核心功能
自定义线程池、任务提交、异步回调、定时任务
耗时：1~2天
2. 锁机制深度实战
核心知识点
- synchronized 底层：对象头、偏向锁→轻量级锁→重量级锁
- Lock、ReentrantLock、公平锁/非公平锁
- ReadWriteLock、StampedLock
- 锁优化：自旋锁、锁粗化、锁消除
核心功能
解决线程安全问题，对比不同锁的性能与适用场景
耗时：2天
3. 并发工具类实战
核心知识点
- CountDownLatch、CyclicBarrier、Semaphore
- Exchanger、Phaser
- 线程间通信：wait/notify、LockSupport
核心功能
多线程协同、任务批量等待、限流控制
耗时：1~2天
 
二、进阶必做（内存模型+并发容器）
4. Java内存模型与volatile
核心知识点
- JMM、主内存/工作内存
- volatile 可见性、禁止指令重排
- 单例模式：双重检查锁DCL、volatile正确用法
- happens-before 规则
核心功能
解决多线程可见性问题，手写线程安全单例
耗时：2天
5. 并发容器源码级实战
核心知识点
- ConcurrentHashMap 底层、分段锁、红黑树、扩容机制
- CopyOnWriteArrayList、ConcurrentLinkedQueue
- 阻塞队列：ArrayBlockingQueue、LinkedBlockingQueue
核心功能
高并发下数据安全读写，对比普通容器并发问题
耗时：2~3天
6. 原子类与CAS
核心知识点
- CAS原理、ABA问题、自旋
- AtomicInteger、AtomicLong、LongAdder
- 原子引用、带版本号原子类
核心功能
无锁并发计数、高并发统计
耗时：1天
 
三、核心必做（异步编程+高并发设计模式）
7. CompletableFuture 异步编程
核心知识点
- 链式调用、异步编排、异常处理
- thenApply、thenCombine、allOf、anyOf
- 超时控制、多任务聚合
核心功能
多任务异步并行、结果聚合、复杂异步流程编排
耗时：2天
8. 生产者-消费者模式
核心知识点
- 基于阻塞队列、锁、CAS 实现
- 缓冲区、满/空判断、线程通信
核心功能
解耦生产消费、削峰填谷
耗时：1~2天
9. 线程池自定义与调优
核心知识点
- 核心线程数计算公式
- 任务类型（IO密集/CPU密集）区分
- 拒绝策略自定义、监控线程池状态
核心功能
根据业务场景设计高性能线程池
耗时：2天
 
四、企业级必做（分布式高并发）
10. 分布式锁（Redisson）
核心知识点
- 可重入锁、公平锁、读写锁、红锁
- 锁超时、自动续期、防误删
- 看门狗机制
核心功能
秒杀库存扣减、防重复提交、分布式幂等
耗时：2天
11. 分布式限流
核心知识点
- 计数器、滑动窗口、漏桶、令牌桶
- Redis + Lua 分布式限流
- Gateway + Sentinel 网关限流
核心功能
接口限流、防刷、流量削峰
耗时：2~3天
12. 分布式幂等设计
核心知识点
- 唯一索引、Token机制、防重表
- 幂等+事务、分布式幂等
核心功能
解决重复请求、重复下单、重复支付
耗时：2天
13. 秒杀系统高并发设计
核心知识点
- 页面静态化、CDN、缓存削峰
- 库存预扣、异步下单、队列削峰
- 分布式锁+限流+幂等综合应用
核心功能
高并发秒杀，抗万级QPS
耗时：3~4天
 
五、高阶必做（性能调优+底层原理）
14. JVM并发调优实战
核心知识点
- 内存模型、逃逸分析、栈上分配
- 锁升级、JVM参数调优
- 线程Dump分析、死锁排查
核心功能
解决并发下内存溢出、死锁、CPU飙高
耗时：2~3天
15. 异步日志与高性能IO
核心知识点
- Logback 异步日志、Disruptor
- NIO、Netty 基础
核心功能
高并发下日志不阻塞业务线程
耗时：2天
 
极简必做优先级（6个项目覆盖面试+求职核心）
1. 线程池 + 锁机制实战
2. ConcurrentHashMap + CAS + 原子类
3. CompletableFuture 异步编程
4. Redisson 分布式锁
5. 分布式限流与幂等
6. 秒杀系统高并发综合项目
 
项目落地标准（可直接写进简历）
1. 每个项目手写核心代码，不依赖框架封装
2. 能讲清底层原理、优缺点、适用场景
3. 项目突出：线程安全、性能优化、高并发抗压
4. 秒杀、限流、分布式锁这类项目，一定要写出压测结果
 
推荐配套工具
- 压测：JMeter、Postman压测
- 排查：JConsole、JVisualVM、Arthas
- 分布式：Redis、Redisson、Sentinel
- 日志：Logback 异步日志
