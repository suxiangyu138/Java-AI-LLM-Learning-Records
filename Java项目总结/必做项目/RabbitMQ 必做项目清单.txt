RabbitMQ 必做项目清单
（从入门 → 企业级高并发 → Java后端实战）
 完全贴合 Java后端+AI大模型 职业路线，覆盖 RabbitMQ 核心交换机、队列、死信、可靠性、削峰解耦、延迟队列等面试高频考点，全部项目可直接写进简历，和 SpringBoot、MySQL、Redis 技术栈无缝联动。
 
一、入门必做（吃透基础模型与收发）
1. 简单模式：消息收发与可靠投递
技术栈：SpringBoot + RabbitMQ
核心知识点
- 生产者/消费者模型
- 消息确认： ACK 、 NACK 、消息重试
- 交换机、队列、绑定关系
核心功能
点对点消息发送、手动确认消费、消息丢失防护
预计耗时：2天
2. 工作模式：多消费者负载均衡
核心知识点
- 轮询分发、公平分发
-  prefetch  预取限制、消费能力均衡
核心功能
多个消费者并行处理任务，提升吞吐量
预计耗时：2天
 
二、进阶必做（交换机核心模式）
3. 发布订阅模式：Fanout 广播消息
核心知识点
- Fanout 交换机、广播机制
- 多队列同时接收同一条消息
核心功能
系统公告、日志广播、多服务同步通知
预计耗时：2天
4. 路由模式：Direct 精准匹配
核心知识点
- Direct 交换机、RoutingKey 精准路由
- 消息定向投递、分类消费
核心功能
按类型分发消息（如短信、邮件、站内信分开消费）
预计耗时：2天
5. 主题模式：Topic 模糊匹配
核心知识点
- Topic 交换机、通配符  *  /  # 
- 灵活的消息路由、多级分类匹配
核心功能
日志分级推送、业务模块消息订阅
预计耗时：3天
 
三、企业级必做（高并发场景，面试高频）
6. 订单异步通知系统
技术栈：SpringBoot + RabbitMQ + MySQL
核心知识点
- 业务解耦、异步削峰
- 下单后异步发送短信/邮件/推送
核心功能
用户下单 → MQ异步分发通知 → 多渠道消息推送
预计耗时：3~4天
7. 死信队列：消息失败兜底处理
核心知识点
- 死信交换机、死信队列
- 消息过期、被拒绝、队列满触发死信
核心功能
失败消息归档、定时重试、异常告警
预计耗时：3天
8. 延迟队列：订单超时自动取消
核心知识点
- 死信模拟延迟 / RabbitMQ 延迟插件
- 消息 TTL、定时任务解耦
核心功能
下单30分钟未支付自动关单、库存释放
预计耗时：3~4天
 
四、高并发实战项目（简历加分天花板）
9. 秒杀系统：削峰填谷异步下单
技术栈：SpringBoot + RabbitMQ + Redis + MySQL
核心知识点
- 高并发削峰、异步下单
- 流量缓冲、防止数据库压垮
核心功能
秒杀请求入队 → 消费者异步扣库存、生成订单
预计耗时：5~7天
10. 消息幂等性保证系统
核心知识点
- 重复消费问题、幂等设计
- Redis 去重、数据库唯一索引、业务状态判断
核心功能
保证同一条消息只被处理一次，避免重复下单、重复扣款
预计耗时：3天
11. 可靠消息最终一致性
核心知识点
- 本地消息表、定时任务补发
- 保证数据库事务与消息发送一致性
核心功能
分布式事务、跨服务数据一致性保障
预计耗时：4~5天
 
五、极简必做优先级（只做6个就够）
1. 简单模式 + 消息可靠投递
2. Fanout + Direct + Topic 三大交换机
3. 订单异步通知系统
4. 死信队列 + 延迟队列
5. 秒杀系统异步削峰
6. 消息幂等性设计
 
项目落地标准
1. 每个项目必须解决 业务痛点：解耦、削峰、延迟、兜底、一致性
2. 代码中必须覆盖：生产者确认、消费者手动ACK、死信兜底、幂等处理
3. 全部代码上传 GitHub，README 写明：场景 + 难点 + 解决方案
4. 熟练掌握 RabbitMQ 监控、队列堆积排查、性能调优
