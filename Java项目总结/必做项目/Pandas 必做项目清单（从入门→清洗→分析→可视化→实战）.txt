Pandas 必做项目清单（从入门→清洗→分析→可视化→实战）
完全贴合求职/练手/简历标准，覆盖 Pandas 全栈核心技能：数据读取、清洗、筛选、分组、聚合、时间序列、缺失值处理、多表合并、可视化联动，所有项目循序渐进，可直接写进简历，完美衔接数据分析、爬虫、机器学习、大模型数据预处理场景。
 
一、入门必做（夯实 Pandas 核心语法）
1. 基础数据操作：学生成绩分析
技术栈：Pandas + NumPy
核心知识点
- CSV/Excel 读写、DataFrame 基础创建
- 行列选取、条件筛选、排序、去重
- 缺失值填充、异常值检测
- 描述性统计：均值、中位数、最值、方差
核心功能
计算各科平均分、班级排名、及格率、成绩分布统计
预计耗时：1天
2. 数据清洗实战：脏数据处理
技术栈：Pandas
核心知识点
- 缺失值： dropna()  /  fillna() 
- 重复值： duplicated()  /  drop_duplicates() 
- 异常值：箱线图、IQR 过滤
- 数据类型转换、字符串清洗、格式标准化
核心功能
把一份杂乱的原始数据清洗为结构化可用数据
预计耗时：1~2天
 
二、进阶必做（分组聚合+时间序列）
3. 电商销售基础分析
技术栈：Pandas
核心知识点
- 分组聚合  groupby 、透视表  pivot_table 
- 时间序列解析、按月/日/季度重采样
- 销售额、销量、客单价、环比、同比计算
核心功能
销售趋势、热门商品、品类占比、月度业绩分析
预计耗时：2天
4. 时间序列专项：股票/基金数据分析
技术栈：Pandas
核心知识点
- 时间索引设置、滑动窗口  rolling 
- 移动平均线、收益率、波动率计算
- 重采样、时间偏移、节假日处理
核心功能
股价趋势分析、均线策略、风险指标统计
预计耗时：2天
5. 多表合并：用户-订单-商品关联分析
技术栈：Pandas
核心知识点
-  merge  多表关联、 concat  数据拼接
- 左连接、内连接、外连接
- 主键关联、数据对齐、冗余字段剔除
核心功能
整合用户、订单、商品三张表，做跨表综合分析
预计耗时：2天
 
三、企业级必做（业务场景+可视化）
6. 电商用户行为漏斗分析
技术栈：Pandas + Matplotlib/Seaborn
核心知识点
- 漏斗转化：浏览→加购→下单→支付
- 留存率、复购率、用户生命周期
- 转化率计算、问题节点定位
核心功能
分析转化瓶颈、提出运营优化建议
预计耗时：3天
7. RFM 用户分层模型
技术栈：Pandas
核心知识点
- RFM 指标：Recency、Frequency、Monetary
- 分箱、打分、用户分层
- 高价值/流失/潜力用户划分
核心功能
精准用户分层，输出差异化运营策略
预计耗时：3天
8. 短视频/APP 流量数据分析
技术栈：Pandas + Pyecharts
核心知识点
- DAU/MAU、渠道来源分析
- 热门内容特征、播放量/点赞量关联
- 多维度交叉分析
核心功能
流量趋势、渠道效果、爆款内容归因
预计耗时：3天

核心功能
评论情感分析、热点舆情洞察
