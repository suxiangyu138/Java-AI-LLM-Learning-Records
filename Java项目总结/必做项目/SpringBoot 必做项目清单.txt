SpringBoot 必做项目清单
完全贴合Java后端+AI大模型应用职业方向，所有项目均为面试高频考点、简历硬通货、企业真实业务场景，做完直接对标校招/初级后端开发水平。
 
一、入门必做（夯实SpringBoot核心基础）
目标：吃透自动配置、MVC架构、持久层整合、接口规范
1. 个人博客后端
技术栈：SpringBoot + MyBatis-Plus + MySQL + Knife4j
核心知识点：
- 自动配置、YAML配置、参数校验
- CRUD、分页、条件查询、多表联查
- 全局异常处理、统一返回体、跨域解决
核心功能：用户登录、文章发布/评论/分类/标签、权限控制
预计耗时：5-7天
2. 前后端分离权限管理系统
技术栈：SpringBoot + MyBatis-Plus + JWT + Redis
核心知识点：
- RBAC权限模型、JWT令牌认证
- 接口权限拦截、动态菜单
- 登录状态缓存、密码加密
核心功能：用户/角色/菜单/权限管理、登录鉴权、接口防刷
预计耗时：6-8天
 
二、进阶必做（整合中间件，掌握企业级核心能力）
目标：吃透缓存、异步、搜索、文件存储，解决实际业务痛点
3. Redis缓存商品详情系统
技术栈：SpringBoot + Redis + MySQL
核心知识点：
- 缓存穿透/击穿/雪崩解决方案
- 分布式锁、热点数据缓存、缓存更新策略
- Redis字符串/哈希/有序集合数据结构应用
核心功能：商品缓存、库存防超卖、首页热点数据优化
预计耗时：4-5天
4. RabbitMQ异步订单通知系统
技术栈：SpringBoot + RabbitMQ + MySQL
核心知识点：
- 交换机、队列、死信队列、消息可靠性
- 异步解耦、削峰填谷、消息重试
核心功能：下单异步推送短信/邮件、订单超时自动取消
预计耗时：4-5天
5. Elasticsearch全文检索系统
技术栈：SpringBoot + Elasticsearch + MySQL
核心知识点：
- 分词配置、高亮查询、分页聚合
- 数据同步、模糊搜索优化
核心功能：商品/文章全文检索、关键词联想、搜索记录统计
预计耗时：5-6天
6. 文件上传下载系统
技术栈：SpringBoot + 阿里云OSS/本地存储
核心知识点：
- 文件大小/类型校验、断点续传
- 云存储整合、文件访问权限控制
核心功能：图片/文档上传、预览、下载、文件管理
预计耗时：3-4天
 
三、企业级必做（高并发/分布式场景，简历加分核心）
目标：掌握高并发、分布式事务、限流熔断，对标实习/校招水平
7. 高并发秒杀系统
技术栈：SpringBoot + Redis + RabbitMQ + MySQL
核心知识点：
- 库存预扣、限流防刷、分布式锁
- 异步下单、削峰填谷、事务控制
- 接口防刷、黑名单机制
核心功能：秒杀商品预热、限时抢购、订单异步处理、库存防超卖
预计耗时：7-10天
8. 分布式定时任务平台
技术栈：SpringBoot + XXL-Job
核心知识点：
- 动态任务配置、Cron表达式
- 任务分片、失败重试、日志监控
核心功能：定时备份、定时统计、定时推送、任务可视化管理
预计耗时：4-5天
 
四、差异化必做（SpringBoot + AI大模型融合）
目标：打造Java后端+AI复合竞争力，贴合职业规划
9. 本地大模型RAG知识库问答系统
技术栈：SpringBoot + Ollama + Milvus + PDF解析
核心知识点：
- 大模型接口封装、流式输出
- 文档向量化、向量检索、检索增强生成
- 会话管理、上下文记忆
核心功能：PDF文档导入、私有化知识库、精准问答、多轮对话
预计耗时：7-10天
10. AI智能客服后端
技术栈：SpringBoot + Ollama + Redis
核心知识点：
- 意图识别、知识库匹配
- 接口限流、会话隔离
核心功能：自动回复、人工转接、对话记录统计、问题智能分类
预计耗时：5-7天
 
极简必做优先级（只做6个就够）
1. 个人博客后端
2. 前后端分离权限管理系统
3. Redis缓存商品详情系统
4. RabbitMQ异步订单通知系统
5. 高并发秒杀系统
6. RAG知识库问答系统
 
项目落地标准（保证能写进简历）
1. 代码严格分层： Controller/Service/Dao/Entity/Config/Exception 
2. 统一规范：全局异常处理、统一返回体、参数校验、接口文档
3. 所有项目上传GitHub，编写标准 README.md （技术栈+功能+部署步骤+核心难点）
4. 遵循阿里巴巴Java开发手册，代码可维护性高
