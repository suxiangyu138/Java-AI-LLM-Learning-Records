Redis 必做项目清单
一、入门必做（吃透核心数据结构）
目标：掌握Redis 5大基础结构+常用命令，能独立完成数据存取
1. 基础数据结构实战项目
技术栈：Redis + Java（SpringBoot）
核心知识点
- String、List、Hash、Set、SortedSet 五大结构
- 命令操作、过期时间、原子操作
核心功能
- String：验证码存储、计数、分布式ID
- Hash：用户信息、购物车存储
- List：消息队列、排行榜
- Set：好友列表、去重
- ZSet：排行榜、延时队列
预计耗时：2~3天
 
二、进阶必做（缓存核心场景，企业最常用）
2. 商品详情缓存系统
技术栈：SpringBoot + Redis + MySQL
核心知识点
- 缓存穿透、击穿、雪崩 全套解决方案
- 缓存更新策略：Cache Aside
- 热点数据缓存、过期时间控制
核心功能
商品详情优先查Redis，未命中查数据库并回写缓存，解决三大缓存问题
预计耗时：3~4天
3. 登录会话共享系统
技术栈：SpringBoot + Redis
核心知识点
- 分布式Session、JWT令牌存储
- 登录状态统一管理、过期自动清理
核心功能
多服务共享登录态，单点登录基础实现
预计耗时：2~3天
 
三、企业级必做（高并发核心方案，面试必问）
4. Redis分布式锁实战
技术栈：SpringBoot + Redis
核心知识点
- SETNX、Lua脚本保证原子性
- 锁超时、死锁、锁续期、可重入锁
核心功能
库存扣减、防超卖、多服务互斥操作
预计耗时：3~4天
5. 高频接口限流系统
技术栈：SpringBoot + Redis
核心知识点
- 计数器限流、滑动窗口限流
- IP限流、接口访问频率控制
核心功能
防止恶意请求、防刷、保护后端服务
预计耗时：2~3天
6. 排行榜与热度统计系统
技术栈：Redis ZSet
核心知识点
- SortedSet 排序、权重更新、分页查询
核心功能
文章点赞榜、商品销量榜、用户积分排行
预计耗时：2天
 
四、高并发实战项目（简历天花板）
7. 秒杀系统（Redis核心版）
技术栈：SpringBoot + Redis + RabbitMQ + MySQL
核心知识点
- 库存预扣、Redis缓存预热
- 分布式锁防超卖、限流削峰
- 异步下单、防止超卖
核心功能
秒杀商品上架、瞬时高并发抢购、库存精准扣减
预计耗时：5~7天
8. 布隆过滤器防穿透
技术栈：Redis + 布隆过滤器
核心知识点
- 布隆过滤器原理、误判率控制
- 拦截不存在的Key，杜绝缓存穿透
核心功能
商品ID预加载、非法请求拦截
预计耗时：2~3天
 
五、高阶特性必做（大厂加分项）
9. Redis持久化与集群实战
核心知识点
- RDB、AOF持久化配置
- 主从复制、哨兵模式、集群部署
核心功能
数据备份、故障自动切换、高可用保障
预计耗时：4~5天
10. Redis延时队列
技术栈：Redis ZSet
核心知识点
- 定时任务、订单超时关闭、消息延时消费
核心功能
订单30分钟未支付自动取消、延时消息推送
预计耗时：2~3天
 
极简必做优先级（只做6个就够）
1. 商品详情缓存系统（缓存三大问题）
2. 分布式锁实战
3. 接口限流系统
4. 登录会话共享
5. 秒杀系统
6. 延时队列
 
项目落地标准
1. 每个项目都要解决实际业务痛点，如防超卖、防穿透、限流
2. 代码中必须包含异常处理、超时控制、原子操作
3. 上传GitHub，README写明：业务场景 + 核心难点 + 解决方案
4. 熟练掌握Redis监控、慢查询分析、内存优化
