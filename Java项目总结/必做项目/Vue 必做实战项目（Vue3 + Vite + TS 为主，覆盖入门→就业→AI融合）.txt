Vue 必做实战项目（Vue3 + Vite + TS 为主，覆盖入门→就业→AI融合）
结合你的全栈+AI方向，整理一套纯Vue技术栈、可直接落地、能写进简历的必做项目，全部贴合企业开发规范，同时为你对接Java后端、AI大模型做铺垫。
 
一、入门级（Vue3 基础语法巩固）
目标：吃透组合式API、响应式、指令、组件通信、生命周期、Vue核心思想
1. TodoList 待办管理
- 功能：增删改查、状态筛选、本地存储、批量操作
- 核心知识点： ref/reactive 、计算属性、侦听器、组件拆分、 localStorage 
2. 计数器+暗黑模式
- 功能：数值增减、主题切换、主题持久化
- 核心知识点：自定义指令、CSS变量、组件通信
3. 商品购物车
- 功能：商品加减、全选反选、总价计算、数量限制
- 核心知识点：父子组件传值、 v-model 、复杂数据响应式
 
二、进阶级（Vue3 + 全家桶，企业刚需）
目标：掌握路由、状态管理、UI组件库、网络请求、工程化基础
1. Vue3 后台管理系统（极简版）
- 功能：登录页、侧边栏导航、面包屑、表格增删改查、分页、表单校验
- 核心技术：Vue3 + Vite + VueRouter + Pinia + Element Plus + Axios
2. 个人博客前台
- 功能：文章列表、详情页、分类/标签、搜索、评论、暗黑模式
- 核心技术：路由守卫、Markdown渲染、图片懒加载、封装请求
3. 音乐播放器
- 功能：播放/暂停、切歌、进度条、音量、歌词滚动、播放列表
- 核心技术：Audio API、组件封装、全局状态管理、自定义hooks
 
三、高阶实战（工程化 + TypeScript，简历王牌）
目标：TS类型约束、工程化规范、权限控制、性能优化、封装思想
1. Vue3 + TS 企业级权限管理系统
- 功能：动态路由、RBAC权限、按钮级权限、菜单管理、用户角色管理
- 核心技术：TypeScript、VueRouter动态路由、Pinia模块化、Element Plus、请求拦截、权限指令
2. 数据可视化大屏
- 功能：多维度图表、实时数据、自适应缩放、主题切换
- 核心技术：ECharts、Vue3 响应式适配、防抖节流、定时器轮询
3. 仿B站短视频页面
- 功能：无限滚动、视频懒加载、点赞评论、下拉刷新
- 核心技术： IntersectionObserver 、自定义滚动、性能优化、组件复用
 
四、全栈融合项目（对接Java后端）
目标：前后端联调、鉴权、跨域、接口规范，打通全栈链路
1. 前后端分离电商系统
- 功能：首页、商品详情、购物车、订单结算、地址管理、支付页
- 对接：SpringBoot后端、JWT登录、Redis缓存、接口联调
2. 在线考试系统前端
- 功能：登录、题库展示、在线答题、自动交卷、成绩展示
- 对接：Java后端接口、WebSocket实时计时、防作弊校验
 
五、差异化王牌（Vue + AI 融合，贴合你的职业规划）
目标：把Vue前端和你的Java+AI大模型方向深度绑定，形成独特竞争力
1. AI 对话聊天Web端
- 功能：对话气泡、打字动画、历史会话、清空会话、Markdown代码高亮
- 核心技术：Vue3、WebSocket流式输出、自定义滚动、对接Spring AI后端
2. RAG 知识库问答系统前端
- 功能：文档上传、知识库管理、问答交互、引用溯源、文件预览
- 核心技术：文件分片上传、进度条、表格管理、分页、权限控制
3. AI 绘图生成页面
- 功能：提示词输入、风格选择、图片生成、历史记录、图片下载
- 核心技术：异步请求、图片预览、请求节流、响应式布局
 
六、练手路线建议
1. 入门：TodoList + 购物车 → 巩固Vue3基础
2. 进阶：极简后台管理系统 → 掌握全家桶与企业开发规范
3. 高阶：TS企业级权限系统 → 提升工程化与类型能力
4. 差异化：AI对话Web端 + RAG前端 → 绑定你的Java+AI技术栈
