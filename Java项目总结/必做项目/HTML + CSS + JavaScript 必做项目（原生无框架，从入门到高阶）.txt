HTML + CSS + JavaScript 必做项目（原生无框架，从入门到高阶）
 
全部项目不依赖任何框架、库，纯原生三件套实现，精准夯实前端底层基本功，覆盖布局、交互、异步、DOM、存储、动画、API 调用等核心考点，做完直接吃透前端基础。
 
一、入门级（语法巩固，静态+简单交互）
目标：掌握 HTML 语义化、CSS 基础布局、JS 变量/循环/条件/DOM 基础操作
1. 个人介绍静态网页
- 功能：导航栏、个人信息展示、技能卡片、联系表单、响应式适配
- 核心知识点：HTML5 语义化标签、CSS 基础选择器、Flex 布局、媒体查询
2. 精美登录注册页面
- 功能：表单布局、输入框校验、密码显示隐藏、简单动画过渡
- 核心知识点：表单标签、CSS 伪类、JS 表单校验、事件监听
3. 轮播图组件
- 功能：自动轮播、手动切换、指示器、左右箭头、鼠标悬停暂停
- 核心知识点：定时器、DOM 切换、位移动画、事件控制
4. 简单倒计时
- 功能：时分秒倒计时、结束提示、自定义目标时间
- 核心知识点： setInterval 、时间对象、字符串格式化
 
二、进阶级（DOM 操作+本地存储+异步请求）
目标：吃透 DOM 增删改查、事件委托、本地存储、Fetch/Ajax、简单算法逻辑
1. TodoList 待办清单
- 功能：新增/删除/完成待办、筛选状态、本地存储、清空全部
- 核心知识点：DOM 动态渲染、 localStorage 、事件委托、数组方法
2. 计算器
- 功能：加减乘除运算、退格、清空、小数点、防连续运算符
- 核心知识点：表达式运算、字符串处理、边界条件判断
3. 天气查询应用
- 功能：调用公开天气 API、城市搜索、展示温度/湿度/天气状况
- 核心知识点： fetch  异步请求、JSON 解析、接口跨域、错误处理
4. 贪吃蛇小游戏
- 功能：键盘控制移动、食物生成、得分统计、撞墙/撞身结束
- 核心知识点：二维数组、定时器、键盘事件、碰撞检测算法
 
三、高阶实战（动画+性能+复杂交互，对标企业基础面试）
目标：掌握 CSS3 高级动画、JS 高级特性、防抖节流、懒加载、复杂逻辑封装
1. 音乐播放器
- 功能：播放/暂停、切歌、进度条拖拽、音量调节、歌词同步
- 核心知识点： Audio  标签、时间轴控制、拖拽事件、进度计算
2. 图片懒加载+瀑布流布局
- 功能：滚动加载图片、瀑布流自适应、懒加载防卡顿
- 核心知识点： IntersectionObserver 、滚动事件、布局算法、节流
3. 在线时钟
- 功能：模拟指针时钟、数字时钟、实时更新、昼夜切换
- 核心知识点：三角函数、CSS 旋转、定时器、日期对象
4. 暗黑模式切换网页
- 功能：一键切换亮色/暗色主题、主题本地存储、全局样式切换
- 核心知识点：CSS 变量、类名切换、 localStorage  持久化
 
四、创意趣味项目（练手+简历加分）
1. 打字练习器
- 功能：随机文本、实时正确率、打字速度统计、倒计时
- 核心知识点：键盘监听、文本比对、性能统计
2. 随机点名器
- 功能：名单导入、随机滚动、一键停止、历史记录
- 核心知识点：数组随机打乱、定时器动画、本地存储
3. 手绘画板
- 功能：鼠标手绘、颜色切换、画笔粗细、清空画布
- 核心知识点：Canvas 绘图、鼠标拖拽事件、坐标计算
4. 表单验证大全
- 功能：手机号/邮箱/密码/身份证正则校验、实时提示、提交拦截
- 核心知识点：正则表达式、表单事件、错误提示封装
 
练手路线建议
1. 先做：个人网页 + 轮播图 + TodoList，快速掌握三件套基础；
2. 再做：计算器 + 天气查询 + 贪吃蛇，吃透 JS 逻辑与异步；
3. 最后做：音乐播放器 + 瀑布流，提升动画、性能与复杂交互能力。
