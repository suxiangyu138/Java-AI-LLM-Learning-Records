Chroma 必做项目清单（入门→RAG实战→工程化）
Chroma 是轻量级本地向量数据库，上手零成本、无需额外部署，是入门RAG、学习向量检索原理的最佳工具。
下面所有项目按 循序渐进 设计，完全贴合 LangChain + Ollama 技术栈，可直接衔接企业级 Milvus 学习，适合练手、写进简历、夯实RAG底层逻辑。
 
一、入门必做（吃透Chroma核心用法）
1. 向量存储与相似度检索基础项目
技术栈：Python + Chroma + Sentence-BERT
核心知识点
- Chroma 客户端初始化、内存/持久化模式
- 文档添加、ID管理、元数据绑定
- 相似度检索、TopK召回、距离算法
核心功能
文本向量化存储、语义相似度查询、简单问答匹配
预计耗时：1天
2. 持久化向量库项目
技术栈：Python + Chroma
核心知识点
- 磁盘持久化存储、重启不丢失向量数据
- 集合（Collection）管理、增删改查
- 元数据过滤检索
核心功能
创建本地私有知识库、支持数据更新/删除、按标签筛选检索
预计耗时：1~2天
 
二、RAG 核心必做（企业最常用场景）
3. 单PDF文件RAG问答系统
技术栈：LangChain + Chroma + Ollama + PyPDFLoader
核心知识点
- PDF文档加载、递归文本分割
- 中文嵌入模型配置（BGE/m3e）
- Chroma向量库构建、RetrievalQA检索链
- 答案引用溯源
核心功能
上传PDF文档，基于文档内容精准问答、标注引用来源
预计耗时：2天
4. 多文档批量RAG系统
技术栈：LangChain + Chroma
核心知识点
- 文件夹批量加载（PDF/TXT/MD）
- 增量向量入库、重复数据去重
- 多文档跨文件语义检索
核心功能
多份文档统一知识库、跨文档问答、文档来源区分
预计耗时：2~3天
5. 网页实时RAG问答
技术栈：LangChain + Chroma + WebBaseLoader
核心知识点
- 网页正文爬取、文本清洗
- 临时向量库构建、实时问答
核心功能
输入任意URL，AI直接基于网页内容回答问题
预计耗时：2天
6. 带元数据过滤的精准RAG
技术栈：LangChain + Chroma
核心知识点
- 文档分类打标签、元数据绑定
- 结合语义相似度 + 元数据过滤检索
核心功能
限定文档范围问答（如只查某本书、某日期的文档），提升精准度
预计耗时：2天
 
三、进阶必做（检索优化+业务场景）
7. 多轮对话RAG系统
技术栈：LangChain + Chroma + Ollama
核心知识点
- 对话记忆、历史上下文压缩
- 对话感知检索（根据历史问题优化检索词）
核心功能
多轮对话问答、AI理解上下文、连贯回答
预计耗时：2~3天
8. 文档智能总结与问答
技术栈：LangChain + Chroma
核心知识点
- 大文档Map-Reduce链式总结
- 先总结文档，再基于总结+原文问答
核心功能
长文档自动生成摘要、关键点提取、基于摘要快速问答
预计耗时：2天
9. 语义相似度推荐系统
技术栈：Python + Chroma
核心知识点
- 文本语义匹配、相似度排序
核心功能
文章推荐、问题匹配、智能内容联想
预计耗时：1~2天
 
四、工程化必做（接口封装+部署）
10. FastAPI 封装RAG接口服务
技术栈：FastAPI + LangChain + Chroma
核心知识点
- 向量库接口化、文档上传接口、问答接口
- 异步处理、参数校验、异常捕获
核心功能
提供RESTful接口，支持外部系统调用RAG问答
预计耗时：3天
11. 轻量化知识库Web应用
技术栈：Streamlit + LangChain + Chroma
核心知识点
- 前端可视化、文档上传、问答交互界面
核心功能
一键启动本地知识库Web，可视化操作、问答对话
预计耗时：2~3天
12. Docker 容器化部署Chroma应用
技术栈：Docker + Chroma + LangChain
核心知识点
- 容器打包、数据卷持久化
- 一键启动私有化RAG服务
核心功能
本地私有化部署，开箱即用的知识库系统
预计耗时：2~3天
 
极简必做优先级（只做6个就够）
1. 持久化向量库基础项目
2. 单PDF文件RAG问答系统
3. 多文档批量RAG系统
4. 网页实时RAG问答
5. 多轮对话RAG系统
6. FastAPI封装RAG接口服务
 
项目落地标准（可直接写进简历）
1. 代码上传GitHub，附带清晰README
2. 突出 Chroma向量检索、RAG实现、私有化部署、接口化封装
3. 项目必须覆盖：文档加载→分块→向量化→检索→生成完整链路
4. 熟练掌握 Chroma 与 Milvus 的差异，理解轻量向量库适用场景
 
推荐配套技术栈
- 大模型：Ollama（Qwen/Llama3）
- 嵌入模型：BGE、m3e
- 框架：LangChain
- 后端：FastAPI
- 可视化：Streamlit
