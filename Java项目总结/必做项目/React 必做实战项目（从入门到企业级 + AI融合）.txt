React 必做实战项目（从入门到企业级 + AI融合）
结合你的全栈+AI职业规划，整理一套覆盖 React 基础 → Hooks → 工程化 → 全栈 → AI 融合 的必做项目，全部符合现代 React 开发规范，适配简历、校招，同时能无缝对接你的 Java 后端、大模型开发方向。
 
一、入门级（React 基础 + Hooks 巩固）
目标：吃透 JSX、组件、Props、State、Hooks、单向数据流、组件通信
1. React TodoList 待办清单
- 功能：增删改查、状态筛选、本地存储、批量操作
- 核心知识点： useState 、 useEffect 、组件拆分、Props 传参、 localStorage 
2. 计数器 + 暗黑模式
- 功能：数值增减、主题切换、主题持久化
- 核心知识点：自定义 Hooks、Context、CSS 变量、状态共享
3. 购物车
- 功能：商品数量加减、全选/反选、总价计算、数量限制
- 核心知识点：父子组件通信、状态提升、复杂数据状态管理
 
二、进阶级（React 全家桶 + 企业常用生态）
目标：掌握 React Router、Redux/Zustand、UI 库、请求封装、工程化基础
1. React 极简后台管理系统
- 功能：登录鉴权、侧边栏导航、面包屑、表格 CRUD、分页、表单校验
- 核心技术：React + Vite + React Router + Zustand + Ant Design + Axios
2. 个人博客前台
- 功能：文章列表、详情页、分类/标签、搜索、评论、暗黑模式
- 核心技术：路由守卫、Markdown 渲染、图片懒加载、请求拦截封装
3. 音乐播放器
- 功能：播放/暂停、切歌、进度条拖拽、音量调节、歌词同步
- 核心技术：Audio API、自定义 Hooks、全局状态管理、组件复用
 
三、高阶实战（TypeScript + 工程化 + 性能优化）
目标：掌握 TS 类型约束、状态管理最佳实践、权限控制、性能优化、企业级规范
1. React + TS 企业级权限管理系统
- 功能：动态路由、RBAC 权限、按钮级权限、菜单管理、角色分配
- 核心技术：TypeScript、React Router 动态路由、Zustand、Ant Design、权限指令、请求拦截
2. 数据可视化大屏
- 功能：多维度图表、实时数据刷新、自适应缩放、主题切换
- 核心技术：ECharts/Recharts、防抖节流、定时器、响应式布局
3. 仿抖音短视频页面
- 功能：无限滚动、视频懒加载、点赞、评论、下拉刷新
- 核心技术： IntersectionObserver 、虚拟列表、性能优化、自定义 Hooks
 
四、全栈融合项目（对接 Java 后端）
目标：前后端联调、JWT 鉴权、跨域、接口规范，打通全栈开发链路
1. 前后端分离电商系统
- 功能：首页、商品详情、购物车、订单结算、地址管理、支付页
- 对接：SpringBoot 后端、JWT 登录、Redis 缓存、完整接口联调
2. 在线考试系统前端
- 功能：登录、题库展示、在线答题、自动交卷、成绩统计
- 对接：Java 后端、WebSocket 实时计时、防作弊校验
 
五、差异化王牌（React + AI 融合，贴合你的职业规划）
把 React 和你的 Java 后端 + 大模型 深度绑定，打造简历独有的竞争力
1. AI 对话聊天 Web 端
- 功能：对话气泡、打字动画、历史会话、Markdown 代码高亮、流式输出
- 核心技术：React、WebSocket、SSE、自定义滚动、对接 Spring AI 后端
2. RAG 知识库问答系统前端
- 功能：文档上传、知识库管理、问答交互、引用溯源、文件预览
- 核心技术：文件分片上传、进度条、表格管理、权限控制
3. AI 绘图生成页面
- 功能：提示词输入、风格选择、图片生成、历史记录、图片下载
- 核心技术：异步请求、请求节流、图片预览、响应式布局
 
六、练手路线建议
1. 入门：TodoList + 购物车，吃透组件与 Hooks
2. 进阶：极简后台管理系统，掌握 React 全家桶与企业开发规范
3. 高阶：TS 企业级权限系统，提升类型能力与工程化思维
4. 差异化：AI 对话 Web 端 + RAG 前端，绑定你的 Java+AI 技术栈
 
补充：React 与 Vue 的选择建议
你主攻 Java 后端 + AI 应用：
- Vue 上手快、生态成熟，适合快速做业务项目；
- React 社区更开放、AI 生态更丰富（Agent、对话组件、可视化），更适配你未来做 AI 产品前端。
建议两条线都掌握，以 React 作为全栈+AI 的主力前端技术栈。
