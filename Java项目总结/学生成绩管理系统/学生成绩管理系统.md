## 设计思路

这个项目最稳的做法是：定义一个 `Student` 学生类保存学号、姓名和三科成绩，再用 `ArrayList<Student>` 作为核心容器，所有菜单操作都围绕这个集合展开。 [blog.csdn](https://blog.csdn.net/KETCC234/article/details/151835071)
系统主流程一般采用“循环菜单 + switch 分发功能”的控制台模式，而常见功能包括录入、查询、修改、删除、排序和平均分/最高分/最低分等统计，这和课程设计常见要求一致。 [cloud.tencent](https://cloud.tencent.com/developer/article/2105133)

你可以把整个程序理解成 3 层：

- `Student`：存数据。
- `StudentService`：处理业务逻辑。
- `Main`：负责菜单交互。 [cnblogs](https://www.cnblogs.com/Yu-Xing-Hai/articles/18512446/Students_Information_Management_paper)

核心实现点如下：

- 查找：按学号精确查找，遍历 `ArrayList` 即可，这是最基础也最容易讲清楚的做法。 [blog.csdn](https://blog.csdn.net/qq_40697623/article/details/144023283)
- 排序：用 `Comparator` 配合 `Collections.sort()` 或 `list.sort()`，可按总分、平均分排序。 [developer.aliyun](https://developer.aliyun.com/article/1294582)
- 统计分析：遍历集合，累计总分，更新最大值/最小值，统计及格人数。 [cnblogs](https://www.cnblogs.com/Yu-Xing-Hai/articles/18512446/Students_Information_Management_paper)
- 扩展性：后面可以把 `ArrayList` 升级成 `HashMap` + `ArrayList`，或者接 MySQL，这类升级路径在学生成绩系统中很常见。 [blog.csdn](https://blog.csdn.net/pink/article/details/151609840)

## 完整代码

按你的要求，我直接给你 **可运行、极简、无注释风格** 的 Java 控制台代码。你放到一个 `Main.java` 里就能跑。

```java
class Main {
    static class Student {
        String id;
        String name;
        double javaScore;
        double sqlScore;
        double englishScore;

        Student(String id, String name, double javaScore, double sqlScore, double englishScore) {
            this.id = id;
            this.name = name;
            this.javaScore = javaScore;
            this.sqlScore = sqlScore;
            this.englishScore = englishScore;
        }

        double total() {
            return javaScore + sqlScore + englishScore;
        }

        double avg() {
            return total() / 3.0;
        }

        public String toString() {
            return "学号：" + id +
                    "，姓名：" + name +
                    "，Java：" + javaScore +
                    "，MySQL：" + sqlScore +
                    "，英语：" + englishScore +
                    "，总分：" + String.format("%.2f", total()) +
                    "，平均分：" + String.format("%.2f", avg());
        }
    }

    static class StudentService {
        java.util.ArrayList<Student> list = new java.util.ArrayList<>();

        boolean add(Student s) {
            if (findById(s.id) != null) return false;
            list.add(s);
            return true;
        }

        Student findById(String id) {
            for (Student s : list) {
                if (s.id.equals(id)) return s;
            }
            return null;
        }

        boolean deleteById(String id) {
            Student s = findById(id);
            if (s == null) return false;
            list.remove(s);
            return true;
        }

        boolean update(String id, double javaScore, double sqlScore, double englishScore) {
            Student s = findById(id);
            if (s == null) return false;
            s.javaScore = javaScore;
            s.sqlScore = sqlScore;
            s.englishScore = englishScore;
            return true;
        }

        void showAll() {
            if (list.isEmpty()) {
                System.out.println("暂无学生数据");
                return;
            }
            for (Student s : list) {
                System.out.println(s);
            }
        }

        void sortByTotalDesc() {
            list.sort((a, b) -> Double.compare(b.total(), a.total()));
            System.out.println("已按总分降序排序");
        }

        void statistics() {
            if (list.isEmpty()) {
                System.out.println("暂无学生数据");
                return;
            }

            double sum = 0;
            double max = list.get(0).total();
            double min = list.get(0).total();
            Student maxStu = list.get(0);
            Student minStu = list.get(0);
            int passCount = 0;

            for (Student s : list) {
                double total = s.total();
                sum += total;
                if (total > max) {
                    max = total;
                    maxStu = s;
                }
                if (total < min) {
                    min = total;
                    minStu = s;
                }
                if (s.javaScore >= 60 && s.sqlScore >= 60 && s.englishScore >= 60) {
                    passCount++;
                }
            }

            System.out.println("学生总人数：" + list.size());
            System.out.println("总分平均值：" + String.format("%.2f", sum / list.size()));
            System.out.println("总分最高分：" + String.format("%.2f", max) + "，姓名：" + maxStu.name);
            System.out.println("总分最低分：" + String.format("%.2f", min) + "，姓名：" + minStu.name);
            System.out.println("三科全及格人数：" + passCount);
            System.out.println("三科全及格率：" + String.format("%.2f", passCount * 100.0 / list.size()) + "%");
        }
    }

    public static void main(String[] args) {
        java.util.Scanner sc = new java.util.Scanner(System.in);
        StudentService service = new StudentService();

        while (true) {
            System.out.println("\n====== 学生成绩管理系统 ======");
            System.out.println("1. 添加学生");
            System.out.println("2. 显示所有学生");
            System.out.println("3. 按学号查询");
            System.out.println("4. 修改成绩");
            System.out.println("5. 删除学生");
            System.out.println("6. 按总分降序排序");
            System.out.println("7. 统计分析");
            System.out.println("0. 退出系统");
            System.out.print("请选择：");

            String choice = sc.next();

            switch (choice) {
                case "1":
                    System.out.print("请输入学号：");
                    String id = sc.next();
                    System.out.print("请输入姓名：");
                    String name = sc.next();
                    System.out.print("请输入Java成绩：");
                    double javaScore = sc.nextDouble();
                    System.out.print("请输入MySQL成绩：");
                    double sqlScore = sc.nextDouble();
                    System.out.print("请输入英语成绩：");
                    double englishScore = sc.nextDouble();

                    boolean addResult = service.add(new Student(id, name, javaScore, sqlScore, englishScore));
                    System.out.println(addResult ? "添加成功" : "添加失败，学号已存在");
                    break;

                case "2":
                    service.showAll();
                    break;

                case "3":
                    System.out.print("请输入要查询的学号：");
                    String findId = sc.next();
                    Student stu = service.findById(findId);
                    System.out.println(stu == null ? "未找到该学生" : stu);
                    break;

                case "4":
                    System.out.print("请输入要修改的学号：");
                    String updateId = sc.next();
                    System.out.print("请输入新的Java成绩：");
                    double newJava = sc.nextDouble();
                    System.out.print("请输入新的MySQL成绩：");
                    double newSql = sc.nextDouble();
                    System.out.print("请输入新的英语成绩：");
                    double newEnglish = sc.nextDouble();
                    System.out.println(service.update(updateId, newJava, newSql, newEnglish) ? "修改成功" : "修改失败，学号不存在");
                    break;

                case "5":
                    System.out.print("请输入要删除的学号：");
                    String deleteId = sc.next();
                    System.out.println(service.deleteById(deleteId) ? "删除成功" : "删除失败，学号不存在");
                    break;

                case "6":
                    service.sortByTotalDesc();
                    service.showAll();
                    break;

                case "7":
                    service.statistics();
                    break;

                case "0":
                    System.out.println("系统已退出");
                    return;

                default:
                    System.out.println("输入有误，请重新选择");
            }
        }
    }
}
```

## 代码结构解释

这份代码的核心是把学生数据抽象成 `Student` 对象，再把所有学生放进 `ArrayList` 里统一管理，这正是 Java 控制台学生成绩系统里很常见的基础实现方式。 [edu.51cto](https://edu.51cto.com/video/55899.html)
而菜单驱动式交互、按学号查找、成绩排序和统计平均分/最高分/最低分，也都是这类项目的典型功能组合。 [blog.csdn](https://blog.csdn.net/2402_87028704/article/details/145847392)

你在答辩或者写实验报告时，可以这样讲：

- `Student` 类负责封装学生属性和总分、平均分计算。
- `StudentService` 类负责业务逻辑，符合面向对象“数据与操作分离”的设计思想。
- 主函数通过循环菜单调用各功能方法，形成完整的控制台管理流程。 [juejin](https://juejin.cn/post/7398748051878264872)

## 你交作业时的思路写法

你可以直接把下面这段改一下放进课程设计文档：

### 1. 系统目标
本系统用于对学生成绩信息进行基础管理，实现学生成绩的录入、查询、修改、删除、排序和统计分析等功能，提升成绩管理效率。 [developer.aliyun](https://developer.aliyun.com/article/861189)

### 2. 数据结构选择
系统采用 `ArrayList<Student>` 保存学生对象。相比普通数组，集合具有动态扩容的特点，更适合频繁进行添加和删除操作的场景。 [blog.csdn](https://blog.csdn.net/KETCC234/article/details/151835071)

### 3. 查找设计
系统通过遍历集合按学号查找学生信息。学号具有唯一性，因此适合作为查询、修改和删除的主键字段。 [blog.csdn](https://blog.csdn.net/KETCC234/article/details/151835071)

### 4. 排序设计
系统使用比较器按学生总分进行降序排序，便于查看成绩排名情况。这种方式实现简单、可扩展，后续也可以增加按单科成绩排序功能。 [developer.aliyun](https://developer.aliyun.com/article/1294582)

### 5. 统计分析设计
系统通过遍历集合计算总分平均值、最高分、最低分以及三科全及格人数和及格率，从而实现班级成绩分析。 [blog.csdn](https://blog.csdn.net/qq_40697623/article/details/144023283)
