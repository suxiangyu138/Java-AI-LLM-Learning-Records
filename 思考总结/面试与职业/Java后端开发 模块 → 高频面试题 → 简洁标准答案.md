--------------------------------------------------------------------------------------------------------------------------------------
一、Java 基础高频面试题 + 答案
--------------------------------------------------------------------------------------------------------------------------------------
1. 八种基本数据类型
byte、short、int、long、float、double、char、boolean
2. == 和 equals 的区别
== 对于基本类型比较值，对于引用类型比较地址
equals 默认比较地址，重写后比较内容
3. String、StringBuilder、StringBuffer 区别
String 不可变，线程安全，效率低
StringBuilder 可变，线程不安全，效率高
StringBuffer 可变，线程安全，效率较低
4. 装箱和拆箱
装箱：基本类型转包装类型
拆箱：包装类型转基本类型
5. 异常分类
编译时异常：必须捕获
运行时异常：RuntimeException，可不显式捕获
Error：系统级错误，程序无法处理
6. final、finally、finalize 区别
final 修饰类、方法、变量，表示不可变
finally 配合 try-catch，一定执行
finalize 是 Object 方法，垃圾回收前调用
7. 接口和抽象类区别
接口只能有方法声明，多实现
抽象类可以有属性、实现方法，单继承
8. 反射是什么
运行时获取类信息、调用方法、操作属性
常用于框架底层

二、集合框架高频面试题 + 答案
--------------------------------------------------------------------------------------------------------------------------------------
1. ArrayList 和 LinkedList 区别
ArrayList 基于数组，查询快，增删慢
LinkedList 基于链表，查询慢，增删快
2. ArrayList 扩容
默认容量10，不够时扩容为1.5倍
3. HashMap 底层
数组+链表+红黑树
JDK1.8 链表长度大于8转红黑树
4. HashMap 线程安全吗
不安全，多线程可能死链或数据覆盖
5. ConcurrentHashMap 原理
JDK1.7 分段锁
JDK1.8 CAS + synchronized
6. HashSet 底层
基于 HashMap，值存在 key 中

三、JVM 高频面试题 + 答案
--------------------------------------------------------------------------------------------------------------------------------------
1. JVM 内存区域
堆、方法区、虚拟机栈、本地方法栈、程序计数器
2. 堆和栈区别
堆存放对象，线程共享，GC回收
栈存放局部变量，线程私有
3. 垃圾回收机制
回收堆中无用对象，释放内存
4. 垃圾回收算法
标记清除、标记复制、标记整理
5. GC Roots 有哪些
栈中引用对象、静态属性、常量、本地方法引用
6. 类加载过程
加载、验证、准备、解析、初始化
7. 双亲委派
父类加载器先加载，防止重复加载，安全
8. 内存溢出和泄漏
溢出：内存不够用
泄漏：对象不用但无法回收

四、多线程与并发面试题 + 答案
--------------------------------------------------------------------------------------------------------------------------------------
1. 进程和线程
进程是资源单位，线程是执行单位
一个进程可包含多个线程
2. 创建线程的方式
继承 Thread
实现 Runnable
实现 Callable
线程池
3. start 和 run 区别
start 启动线程，run 只是普通方法
4. 线程状态
新建、就绪、运行、阻塞、终止
5. synchronized 原理
对象锁、类锁，基于 JVM 指令
6. volatile 作用
保证可见性，禁止指令重排，不保证原子性
7. 线程池参数
核心线程、最大线程、队列、拒绝策略
8. 死锁四个条件
互斥、请求保持、不可剥夺、循环等待

五、MySQL 面试题 + 答案
--------------------------------------------------------------------------------------------------------------------------------------
1. InnoDB 和 MyISAM 区别
InnoDB 支持事务、行锁、外键
MyISAM 不支持事务，表锁，查询快
2. 索引是什么
加快查询的数据结构，常用 B+ 树
3. 聚簇索引和非聚簇索引
聚簇索引：叶子存整行数据
非聚簇索引：叶子存主键
4. 最左前缀原则
联合索引从左到右匹配，跳过则失效
5. 事务 ACID
原子性、一致性、隔离性、持久性
6. 事务隔离级别
读未提交、读已提交、可重复读、串行化
7. MVCC 是什么
多版本并发控制，实现无锁读写
8. SQL 优化
建索引、避免 select *、避免模糊查询开头%、减少子查询

六、Redis 面试题 + 答案
--------------------------------------------------------------------------------------------------------------------------------------
1. Redis 数据类型
String、Hash、List、Set、ZSet
2. Redis 持久化
RDB 快照
AOF 记录命令
3. 缓存穿透
查询不存在的数据
解决方案：布隆过滤器、缓存空值
4. 缓存击穿
热点 key 过期
解决方案：互斥锁、永不过期
5. 缓存雪崩
大量 key 同时过期
解决方案：过期时间加随机值、集群
6. Redis 分布式锁
setnx + 过期时间，防止死锁
