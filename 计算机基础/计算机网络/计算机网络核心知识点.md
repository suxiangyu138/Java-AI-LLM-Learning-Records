## 一、计算机网络概述

### 计算机网络定义

将地理上分散的、具有独立功能的多台计算机，通过通信设备和通信线路连接起来，在网络操作系统、网络管理软件及通信协议的管理和协调下，实现资源共享和数据通信的系统。

### 网络的主要功能

- **资源共享**：硬件共享、软件共享、数据共享
- **数据通信**：电子邮件、文件传输、视频通话等
- **分布式处理**：将大型任务拆分为若干子任务，由不同计算机并行处理
- **提高系统可靠性**：一台计算机故障，可由其他计算机替代工作

### 网络的分类

#### 按地理范围划分

| 类型 | 覆盖范围 | 特点 | 示例 |
|------|----------|------|------|
| **局域网（LAN）** | 1km以内 | 传输速率高、延迟小、成本低 | 校园网、企业内网 |
| **城域网（MAN）** | 10~100km | 速率中等 | 城市宽带网络 |
| **广域网（WAN）** | 几百~几千公里 | 速率较低、延迟大、覆盖广 | 互联网 |

#### 按拓扑结构划分

| 拓扑类型 | 优点 | 缺点 |
|----------|------|------|
| **总线型** | 结构简单 | 总线故障导致全网瘫痪 |
| **星型** | 故障排查容易 | 中央节点故障导致全网瘫痪 |
| **环型** | 结构简单 | 任意节点故障破坏环路 |
| **树型** | 层次结构，分级管理 | 根节点故障影响大 |
| **网状** | 可靠性高 | 成本高 |

> **广播式网络**：所有节点共享一条通信信道，如总线型局域网。
> **点对点网络**：两个节点之间通过专用链路连接，如广域网中的路由器之间的链路。

### 网络性能指标

| 指标 | 说明 |
|------|------|
| **带宽** | 信道能传输的最高数据率，单位b/s |
| **吞吐量** | 单位时间内实际传输的数据量，吞吐量 ≤ 带宽 |
| **时延** | 发送时延 + 传播时延 + 处理时延 + 排队时延 |
| **时延带宽积** | 时延 × 带宽，链路的"管道容量" |
| **往返时间（RTT）** | 数据从发送到收到确认的总时间 |
| **丢包率** | 丢失数据包数量 / 总发送数据包数量 |

### 计算机网络体系结构

#### 分层的意义

> 将复杂的网络功能划分为若干层，每层实现特定的功能，层与层之间通过接口通信，降低系统复杂性，便于开发、维护和标准化。

#### 协议的三要素

- **语法**：数据与控制信息的结构或格式
- **语义**：需要发出何种控制信息，完成何种动作以及做出何种响应
- **同步**：事件实现顺序的详细说明

#### OSI七层模型

从下到上：物理层 → 数据链路层 → 网络层 → 传输层 → 会话层 → 表示层 → 应用层

#### TCP/IP四层模型

从下到上：网络接口层 → 网际层（IP层） → 传输层 → 应用层

> TCP/IP模型与OSI模型的对应关系：网络接口层对应物理层和数据链路层，网际层对应网络层，传输层对应传输层，应用层对应会话层、表示层、应用层。

## 二、物理层

### 基本功能

负责处理物理介质上的信号传输，实现计算机之间的物理连接，为数据链路层提供比特流传输服务。

### 传输介质

#### 导向传输介质

| 介质 | 特点 | 适用场景 |
|------|------|----------|
| **双绞线**（STP/UTP） | 成本低、安装方便，传输距离约100m | 局域网 |
| **同轴电缆** | 抗干扰能力强 | 有线电视、早期局域网 |
| **光纤**（单模/多模） | 抗电磁干扰、传输速率高、保密性好 | 骨干网 |

#### 非导向传输介质

| 介质 | 特点 |
|------|------|
| **无线电波** | 覆盖范围广，用于无线局域网、移动通信 |
| **微波** | 地面微波接力通信和卫星通信 |
| **红外线** | 短距离无线通信 |

### 信道的基本概念

| 信道类型 | 方向性 | 示例 |
|----------|--------|------|
| **单工信道** | 只能单向传输 | 广播 |
| **半双工信道** | 可双向，同一时刻只能单向 | 对讲机 |
| **全双工信道** | 可同时双向传输 | 电话、以太网 |

### 编码与调制

- **编码**：将数字信号转换为适合传输的数字波形（如曼彻斯特编码、差分曼彻斯特编码）
- **调制**：将数字信号转换为模拟信号，或将模拟信号转换为数字信号

### 多路复用技术

| 技术 | 原理 | 应用 |
|------|------|------|
| **频分多路复用（FDM）** | 划分频带 | 有线电视 |
| **时分多路复用（TDM）** | 划分时隙 | 电话网络 |
| **波分多路复用（WDM）** | 光的频分复用 | 光纤通信 |
| **码分多路复用（CDM）** | 码片序列 | CDMA移动通信 |

## 三、数据链路层

### 基本功能

负责将物理层接收到的比特流组织成帧，实现相邻节点之间的可靠数据传输。

### 核心功能

- **帧定界**：在比特流中标记帧的开始和结束
- **透明传输**：解决帧定界符在数据中出现时的冲突问题
- **差错检测**：循环冗余校验（CRC）
- **流量控制与差错控制**

### 流量控制与差错控制

| 协议 | 说明 |
|------|------|
| **停止-等待协议** | 发送一帧后等待确认 |
| **滑动窗口协议** | 窗口内帧可连续发送，提高效率 |
| **后退N帧ARQ** | 出错时重传所有未确认的帧 |
| **选择重传ARQ** | 仅重传出错的帧，效率更高 |

### 局域网（LAN）技术

#### 以太网工作原理（CSMA/CD）

1. 监听信道（载波监听）
2. 若信道空闲则发送数据，若忙则等待
3. 发送数据时继续监听，检测冲突
4. 检测到冲突，立即停止发送并发送干扰信号
5. 等待随机时间后重新尝试

#### 以太网帧结构

包括前导码、帧起始符、目的MAC地址、源MAC地址、类型字段、数据字段、CRC校验字段。

#### 局域网组网设备

| 设备 | 工作层次 | 特点 |
|------|----------|------|
| **集线器** | 物理层 | 共享带宽，半双工 |
| **交换机** | 数据链路层 | 根据MAC地址转发，每个端口独占带宽，全双工 |

### 点对点协议（PPP）

用于拨号上网等点对点链路，支持多种网络层协议，具有帧定界、透明传输、差错检测功能。

## 四、网络层

### 基本功能

实现分组在多个网络之间的路由选择和转发，使分组能够从源主机传输到目的主机。

### IP协议

#### IP地址结构

IPv4地址长度为32位，分为网络号和主机号两部分。

| 地址类 | 网络号位数 | 适用范围 |
|--------|-----------|----------|
| A类 | 8位 | 大型网络 |
| B类 | 16位 | 中型网络 |
| C类 | 24位 | 小型网络 |
| D类 | - | 组播 |
| E类 | - | 科研 |

#### 子网划分与CIDR

- **子网掩码**：区分网络号、子网号和主机号
- **CIDR**：使用变长的网络前缀，格式为 `IP地址/前缀长度`

#### IPv4分组结构

包含版本、首部长度、服务类型、总长度、标识、标志、片偏移、TTL、协议字段、首部校验和、源IP地址、目的IP地址等字段。

#### IP分片与重组

> 当分组长度超过数据链路层的MTU时，路由器将分组分片，重组由目的主机完成。

### IPv6协议

- 地址长度为128位
- 采用冒号十六进制表示法
- 支持即插即用、内置安全机制

### 路由选择协议

| 协议类型 | 协议 | 算法 | 适用场景 |
|----------|------|------|----------|
| **内部网关协议（IGP）** | RIP | 距离矢量 | 小型网络 |
| | OSPF | 链路状态 | 大型网络 |
| **外部网关协议（EGP）** | BGP | 路径矢量 | 互联网核心层 |

### 网络层设备

> **路由器**：工作在网络层，根据IP地址转发分组，能隔离广播域，实现异构网络互联。

## 五、传输层

### 基本功能

实现源主机和目的主机的应用程序之间的端到端通信，为应用层提供服务。

### 端口的概念

| 端口类型 | 范围 | 示例 |
|----------|------|------|
| **知名端口** | 0~1023 | HTTP(80)、FTP(21) |
| **动态端口** | 1024~65535 | 应用程序动态分配 |

### 传输控制协议（TCP）

#### TCP特点

面向连接、可靠传输、面向字节流、全双工通信、支持流量控制和拥塞控制。

#### 三次握手（连接建立）

1. 客户端发送SYN报文段，请求建立连接
2. 服务器发送SYN + ACK报文段，确认请求并同步序列号
3. 客户端发送ACK报文段，确认请求，连接建立成功

#### 四次挥手（连接释放）

1. 客户端发送FIN报文段，请求释放连接
2. 服务器发送ACK报文段，确认请求
3. 服务器发送FIN报文段，请求释放连接
4. 客户端发送ACK报文段，确认请求，连接释放成功

#### 可靠传输机制

通过序列号、确认号、重传机制、超时重传、快重传等实现可靠传输。

#### 流量控制

> 通过滑动窗口机制实现，接收方通过窗口字段告知发送方自己的接收窗口大小。

#### 拥塞控制

通过慢启动、拥塞避免、快重传、快恢复四个阶段实现。

### 用户数据报协议（UDP）

| 特性 | 说明 |
|------|------|
| 连接性 | 无连接 |
| 可靠性 | 不可靠传输 |
| 传输单位 | 面向报文 |
| 开销 | 开销小、传输速率高 |

**适用场景**：对实时性要求高、对可靠性要求低的应用，如视频通话、音频直播、DNS查询。

### TCP与UDP对比

| 维度 | TCP | UDP |
|------|-----|-----|
| 连接性 | 面向连接 | 无连接 |
| 可靠性 | 可靠 | 不可靠 |
| 开销 | 大 | 小 |
| 适用场景 | 文件传输、电子邮件 | 实时通信、多媒体传输 |

## 六、应用层

### 域名系统（DNS）

- 功能：将域名转换为对应的IP地址
- 域名结构：根域 → 顶级域 → 二级域 → 主机名
- 查询方式：递归查询、迭代查询
- 传输层协议：UDP（超过512字节则使用TCP）

### 超文本传输协议（HTTP）

#### 特点

- 无连接（HTTP/1.0每次请求后关闭连接）
- 无状态（服务器不保存客户端状态）
- HTTP/1.1支持持久连接（Keep-Alive）

#### 报文结构

**请求报文**：请求行（方法、URL、版本）+ 请求头 + 空行 + 请求体

**响应报文**：状态行（版本、状态码、状态描述）+ 响应头 + 空行 + 响应体

#### 状态码

| 范围 | 类别 |
|------|------|
| 1xx | 信息性状态码 |
| 2xx | 成功状态码（如200 OK） |
| 3xx | 重定向状态码（如301） |
| 4xx | 客户端错误状态码（如404） |
| 5xx | 服务器错误状态码（如500） |

#### HTTPS

HTTP的安全版本，在HTTP和TCP之间加入了SSL/TLS协议，实现数据的加密传输。

### 文件传输协议（FTP）

- 控制连接（端口21，基于TCP）
- 数据连接（端口20，基于TCP）
- 工作模式：主动模式、被动模式

### 电子邮件协议

| 协议 | 功能 | 端口 |
|------|------|------|
| **SMTP** | 发送邮件 | 25 |
| **POP3** | 接收邮件 | 110 |
| **IMAP** | 接收邮件（邮件存储在服务器） | 143 |

### 动态主机配置协议（DHCP）

- 功能：自动分配IP地址、子网掩码、网关地址、DNS服务器地址
- 工作过程：发现 → 提供 → 请求 → 确认
- 基于UDP协议，客户端端口68，服务器端口67

## 七、网络安全与网络管理

### 网络安全威胁

| 威胁类型 | 说明 |
|----------|------|
| **窃听** | 未经授权获取网络中的数据 |
| **篡改** | 未经授权修改网络中的数据 |
| **伪造** | 伪造数据或身份 |
| **DoS/DDoS** | 向服务器发送大量请求，导致服务不可用 |

### 网络安全技术

| 技术 | 说明 |
|------|------|
| **对称加密**（DES、AES） | 加密和解密使用相同的密钥，速度快 |
| **非对称加密**（RSA） | 公钥公开，私钥保密，适用于密钥交换和数字签名 |
| **数字签名** | 验证数据的完整性和发送方的身份 |
| **防火墙** | 包过滤防火墙（网络层）、应用层防火墙 |
| **入侵检测系统（IDS）** | 基于特征、基于异常 |

### 网络管理

- **功能**：故障管理、配置管理、性能管理、安全管理、计费管理
- **SNMP**：简单网络管理协议，基于UDP协议
