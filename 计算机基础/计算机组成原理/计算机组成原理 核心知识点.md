## 一、计算机系统概述

### 1. 冯·诺依曼体系五大部件

- 运算器、控制器、存储器、输入设备、输出设备

### 2. 核心思想

- 二进制存储、程序与数据存内存、顺序执行、集中控制

### 3. 硬件层次

| 层次 | 组成 |
|------|------|
| **硬件** | CPU、主存、辅存、I/O |
| **软件** | 系统软件 + 应用软件 |

### 4. 性能指标

| 指标 | 说明 |
|------|------|
| **时钟周期** | CPU 的最小时间单位 |
| **主频** | 时钟频率（Hz） |
| **CPI** | 每条指令所需的时钟周期数 |
| **MIPS** | 每秒百万条指令 |
| **FLOPS** | 每秒浮点运算次数 |

## 二、数制与编码

### 1. 进制转换

- 二进制、八进制、十六进制、十进制互转

### 2. 机器数表示

| 表示法 | 特点 |
|--------|------|
| **原码** | 符号位 + 真值，正负唯一，运算复杂 |
| **反码** | 正数同原码，负数按位取反 |
| **补码** | **计算机实际存储运算用补码** |

> **补码优势**：正数的原码=反码=补码；负数的反码+1，解决负数运算和 0 唯一性问题。

### 3. 定点/浮点

| 类型 | 说明 |
|------|------|
| **定点整数** | 小数点固定在最低位之后 |
| **定点小数** | 小数点固定在符号位之后 |
| **浮点数** | 阶码 + 尾数，遵循 IEEE 754 标准 |

### 4. 校验码

| 类型 | 用途 |
|------|------|
| **奇偶校验** | 检测奇数位错误 |
| **海明校验** | 可检测并纠正一位错误 |
| **CRC 循环冗余校验** | 检测多位突发错误 |

## 三、运算器与数据运算

### 1. 算术运算

- 补码加减运算、溢出判断（双符号位 / 最高位进位）

### 2. 逻辑运算

- 与、或、非、异或、移位（算术移位、逻辑移位）

### 3. ALU（算术逻辑单元）

- 核心：完成算术 + 逻辑运算，配合寄存器、移位器

## 四、存储器系统（重点）

### 1. 存储器层次结构

```
CPU缓存（L1/L2/L3） -> 主存 -> 辅存
速度递减、容量递增、成本递减
```

### 2. 分类

| 分类方式 | 类型 |
|----------|------|
| 按读写 | RAM（随机读写，断电丢失）、ROM（只读，断电保留） |
| 按存取 | 随机存取、顺序存取、直接存取 |

### 3. 高速缓存 Cache

- **作用**：缓解 CPU 与主存速度差，基于**局部性原理**
- **三种映射方式**：
  - 直接映射
  - 全相联映射
  - 组相联映射（主流）
- **替换算法**：LRU、FIFO、随机替换

### 4. 虚拟存储器

| 概念 | 说明 |
|------|------|
| **逻辑地址** | 程序使用的地址 |
| **物理地址** | 内存实际地址 |
| **分页/分段/段页式** | 由硬件 + 操作系统协同实现 |

### 5. 主存芯片

- 位扩展、字扩展，存储器容量计算

## 五、指令系统

### 1. 指令格式

```
操作码 OP + 地址码 A
```

### 2. 寻址方式

| 方式 | 说明 |
|------|------|
| **立即寻址** | 操作数直接包含在指令中 |
| **直接寻址** | 地址码为操作数的存储地址 |
| **间接寻址** | 地址码为操作数地址的地址 |
| **寄存器寻址** | 操作数在寄存器中 |
| **寄存器间接** | 寄存器存放操作数的地址 |
| **相对寻址** | PC + 偏移量 |
| **基址/变址寻址** | 基址/变址寄存器 + 形式地址 |

### 3. 指令分类

- 数据传送、算术逻辑、控制转移、I/O 指令

### 4. CISC / RISC

| 类型 | 特点 | 代表 |
|------|------|------|
| **CISC** | 复杂指令、指令多、变长、兼容性强 | Intel |
| **RISC** | 精简指令、定长、单周期、效率高 | ARM |

## 六、CPU 中央处理器

### 1. CPU 组成

| 部件 | 组成 |
|------|------|
| **运算器** | ALU、通用寄存器、状态寄存器 |
| **控制器** | IR（指令寄存器）、PC（程序计数器）、指令译码器、时序电路 |

### 2. 核心寄存器

| 寄存器 | 作用 |
|--------|------|
| **PC** | 存放下一条指令地址 |
| **IR** | 存放当前执行指令 |
| **MAR** | 存储器地址寄存器 |
| **MDR** | 存储器数据寄存器 |

### 3. 指令执行流程

```
取指 -> 译码 -> 执行 -> 访存 -> 写回
```

### 4. 流水线技术

- **目的**：并行执行指令，提升吞吐量
- **冲突类型**：
  - 结构冒险
  - 数据冒险
  - 控制冒险
- **解决方案**：停顿、数据旁路、分支预测

## 八、IO 输入输出系统

### 1. I/O 控制方式

| 方式 | 特点 | 效率 |
|------|------|------|
| **程序直接控制（轮询）** | CPU 全程等待 | 低 |
| **中断驱动 I/O** | 设备就绪发中断，CPU 可并行 | 中 |
| **DMA 直接存储器访问** | 大块数据直传，少占用 CPU | 高 |
| **通道方式** | 独立 I/O 处理器 | 最高 |

### 2. 中断

- **定义**：打断当前程序，转去处理异常/外设请求
- **分类**：内中断（异常）、外中断（外设）
- **流程**：中断请求 -> 判优 -> 响应 -> 处理 -> 返回

### 3. DMA核心

- 无需 CPU 逐字搬运，内存与外设直接高速传输

## 十、高频简答速记

1. **补码优势**：统一加减法、零唯一、便于硬件实现
2. **存储层次目的**：速度、容量、成本三者平衡
3. **Cache 原理**：时间局部性 + 空间局部性
4. **流水线瓶颈**：各类冒险冲突、分支指令
5. **I/O 演进**：轮询 -> 中断 -> DMA -> 通道
