## 一、计算机系统概述（基础必考点）

### 1.1 计算机系统层次结构

**核心层次（从下到上）**：

```
硬件层 → 微程序层 → 机器语言层 → 操作系统层 → 汇编语言层 → 高级语言层
```

> **易混点**：计算机系统 = 硬件系统 + 软件系统。硬件系统是核心，软件系统是灵魂。

### 1.2 计算机的基本组成

**冯·诺依曼体系结构核心（三大核心 + 两大特点）**：

| 核心部件 | 说明 |
|---------|------|
| 运算器 | 核心为 ALU（算术逻辑单元） |
| 控制器 | 核心为 CU（控制单元） |
| 存储器 | 分为主存（内存）和辅存（外存） |
| 输入设备 | 键盘、鼠标等 |
| 输出设备 | 显示器、打印机等 |

**两大核心特点**：
1. **存储程序**：指令和数据一起存储在存储器中，自动依次执行
2. **指令和数据采用二进制表示**

### 1.3 计算机的性能指标（高频计算题考点）

| 指标 | 定义 | 说明 |
|------|------|------|
| **字长** | 一次能处理的二进制位数 | 决定运算精度和寻址能力 |
| **主频** | 时钟周期的倒数（GHz） | 主频高 ≠ 运算速度快（需结合 CPI） |
| **CPI** | 每条指令的平均时钟周期数 | CPI 越小，指令执行效率越高 |
| **MIPS** | 每秒百万条指令 | MIPS = 主频(Hz) / (CPI × 10⁶) |

> **必考计算题**：已知主频、CPI 计算 MIPS；或已知 MIPS、主频计算 CPI。

## 二、存储器系统（重点难点）

### 2.1 存储器的分类

| 分类依据 | 类别 | 核心特点 |
|---------|------|---------|
| **存储介质** | 半导体、磁表面、光存储 | 半导体速度快、易失性；磁表面容量大、非易失性 |
| **存取方式** | RAM、顺序存取、直接存取 | RAM 随机访问（主存核心）；顺序存取按序查找 |
| **易失性** | RAM（易失）、ROM/辅存（非易失） | RAM 断电丢失；ROM 用于存储 BIOS |

### 2.2 主存储器的组成与工作原理

**核心组成**：
- 存储体（核心）
- 地址译码器
- 控制电路
- 数据缓冲寄存器（DR）
- 地址寄存器（AR）

**读写过程（必考）**：

```pseudocode
读操作：CPU 送地址到 AR → 地址译码器选中单元 → 控制电路发读命令 → 数据送入 DR → DR 送 CPU
写操作：CPU 送地址到 AR、数据到 DR → 地址译码器选中单元 → 控制电路发写命令 → DR 写入存储单元
```

> **易混点**：区分 DR（数据缓冲寄存器）和 AR（地址寄存器）的功能。

### 2.3 三级存储体系

```
Cache（高速缓冲存储器） → 主存 → 辅存
```

| 层级 | 速度 | 容量 | 成本 |
|------|------|------|------|
| Cache | 最快（接近 CPU） | 最小 | 最高 |
| 主存 | 中等 | 中等 | 中等 |
| 辅存 | 最慢 | 最大 | 最低 |

**Cache 核心考点**：

| 概念 | 说明 |
|------|------|
| **命中率** | 命中次数 / 总访问次数 |
| **直接映射** | 简单、速度快，命中率低 |
| **全相联映射** | 命中率高，结构复杂、速度慢 |
| **组相联映射** | 折中方案，最常用 |

### 2.4 辅存储器核心考点

**磁盘核心参数（计算题考点）**：

```
磁盘容量 = 磁头数 × 磁道数 × 每磁道扇区数 × 每扇区字节数
```

> **易考点**：SSD 基于闪存，无机械部件，速度快、功耗低；HDD 有磁头、电机，速度慢、功耗高。

## 三、运算器（基础重点）

### 3.1 运算器的组成

| 部件 | 功能 |
|------|------|
| **ALU** | 核心，执行算术和逻辑运算 |
| **累加器（AC）** | 存放操作数和运算结果 |
| **通用寄存器组** | 存储中间数据 |
| **状态寄存器（PSW）** | 存放标志位（CF、OF、ZF、SF） |

### 3.2 定点数运算（必考计算题）

**定点加法/减法**：

```
[X ± Y]补 = [X]补 ± [Y]补
[-Y]补 = 对[Y]补求反加 1
```

**溢出判断（高频考点）**：

| 方法 | 规则 |
|------|------|
| **符号位判断法** | 两正相加得负，或两负相加得正，即为溢出 |
| **进位判断法** | 最高位进位与次高位进位不同，即为溢出 |

### 3.3 浮点数运算（难点）

**浮点数表示**：N = 尾数 M × 基数 R^阶码 E

**浮点数加法/减法步骤（必考）**：

```
① 对阶（小阶向大阶看齐，尾数右移）
② 尾数相加/减
③ 规格化
④ 舍入（避免精度损失）
⑤ 判溢出（阶码溢出）
```

> **易混点**：浮点数溢出是阶码溢出；定点数溢出是数值本身超出表示范围。

## 四、控制器（难点核心考点）

### 4.1 控制器的组成与功能

| 部件 | 功能 |
|------|------|
| **PC（程序计数器）** | 存放当前要执行的指令地址，执行后自动加 1 |
| **IR（指令寄存器）** | 存放当前正在执行的指令 |
| **ID（指令译码器）** | 分析指令的操作类型和操作数地址 |
| **CU（控制单元）** | 产生控制信号，控制各部件执行操作 |
| **时序产生器** | 产生统一时钟信号 |

### 4.2 指令执行过程（必考）

| 阶段 | 核心操作 |
|------|---------|
| **取指令** | PC → AR → 读主存 → DR → IR，PC 自动加 1 |
| **分析指令** | ID 译码，分析操作码和地址码，获取操作数 |
| **执行指令** | CU 产生控制信号，执行运算，更新状态寄存器 |

### 4.3 控制器的控制方式

| 方式 | 特点 | 适用场景 |
|------|------|---------|
| **同步控制** | 统一时钟，控制简单速度快 | RISC 架构 |
| **异步控制** | 握手信号同步，灵活 | 外设交互 |
| **联合控制** | 结合两者优点 | 实际中最常用 |

## 五、输入输出（I/O）系统（基础考点）

### 5.1 I/O 接口的作用

连接 CPU 与 I/O 设备，解决三者问题：

- **速度不匹配**
- **信号格式不兼容**
- **时序不一致**

### 5.2 I/O 传输方式（高频考点）

| 方式 | CPU 利用率 | 适用场景 |
|------|-----------|---------|
| **程序查询（PIO）** | 极低 | 低速设备（键盘） |
| **程序中断** | 中等 | 中速设备（打印机） |
| **DMA** | 高 | 高速设备（磁盘、SSD） |
| **通道** | 最高 | 大型计算机、多外设 |

### 5.3 中断系统

**中断处理流程（必考）**：

```
中断请求 → 中断响应 → 中断判优 → 中断服务 → 中断返回
```

## 六、总线系统（基础考点）

### 6.1 总线的定义与分类

| 总线类型 | 传输信号 | 特点 |
|---------|---------|------|
| **地址总线（AB）** | 地址信号 | 单向，决定寻址空间 |
| **数据总线（DB）** | 数据信号 | 双向，与 CPU 字长一致 |
| **控制总线（CB）** | 控制信号 | 双向，协调各部件工作 |

### 6.2 总线性能指标

```
总线带宽 = 总线宽度 × 总线频率 / 8（单位：MB/s）
```

> **必考计算题**：已知总线宽度和总线频率，计算总线带宽。

## 七、高频易错点与必考题型总结

### 7.1 易错点梳理

| 易错点 | 正确理解 |
|--------|---------|
| 混淆"主存"与"Cache" | Cache 不是主存的一部分，是独立的高速缓冲存储器 |
| 补码运算的溢出判断 | 注意符号位和进位的关系 |
| PC 的变化 | 取指后 PC 自动加 1，转移指令修改 PC |
| DMA 与中断的区别 | DMA 方式 CPU 不参与数据传输；中断方式 CPU 参与 |
| 总线分类 | 地址/数据/控制总线的功能区分 |

### 7.2 必考题型汇总

**计算题**：
1. 计算机性能指标（MIPS、CPI）计算
2. 磁盘容量计算
3. 总线带宽计算
4. 定点数补码加法/减法（含溢出判断）
5. 浮点数规格化与加法/减法

**简答题**：
1. 计算机系统层次结构的组成及意义
2. 冯·诺依曼体系结构的核心特点
3. Cache 的映射方式及优缺点
4. 指令执行的完整流程
5. I/O 四种传输方式的特点及适用场景

**流程题**：
1. 主存的读写流程
2. 中断处理流程
3. 指令执行流程
