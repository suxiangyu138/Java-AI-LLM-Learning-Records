## 一、基础课程

> 基础课程为软件工程专业提供必要的数学、物理和计算机基础。

### 数学基础

| 课程名称 | 重要性说明 | 推荐教材 | 在计算机中的应用 |
|----------|-----------|---------|-----------------|
| 微积分 | 理工科数学基础工具 | 《高等数学》（同济） | 优化算法、梯度下降、数值计算 |
| 线性代数 | 机器学习、图形学必备 | 《线性代数》（同济）/ Gilbert Strang | ML/DL 核心、图形变换、推荐系统 |
| 概率论与数理统计 | 数据分析、AI 基础 | 《概率论与数理统计》（浙大） | ML 模型、A/B 测试、随机算法 |
| 离散数学 | 逻辑、集合、图论基础 | 《离散数学及其应用》（Rosen） | 算法设计、数据库理论、形式化验证 |

### 物理基础

| 课程名称 | 重要性说明 |
|----------|-----------|
| 大学物理 | 理解物理现象在工程中的应用（游戏物理引擎、仿真系统） |

### 程序设计入门

| 课程名称 | 培养目标 | 推荐教材 |
|----------|---------|---------|
| C 语言程序设计 | 培养基本编程能力，理解内存和指针 | 《C 程序设计语言》（K&R） |
| Java 程序设计 | 面向对象编程入门 | 《Java 核心技术》/《Thinking in Java》 |

### 计算机基础（"四大件"入门）

| 课程名称 | 核心内容 | 推荐教材 | 学习重点 |
|----------|---------|---------|---------|
| 计算机组成原理 | 硬件基本组成和工作原理 | 《深入理解计算机系统》（CSAPP） | 数据的表示、处理器体系结构、存储器层次 |
| 操作系统 | 操作系统原理和设计 | 《现代操作系统》 | 进程线程、内存管理、文件系统、并发 |
| 数据结构与算法 | 数据组织方式和算法设计 | 《算法导论》/《数据结构与算法分析》 | 线性结构、树、图、排序、查找、DP |
| 计算机网络 | 网络基本原理和应用 | 《计算机网络：自顶向下方法》 | TCP/IP 协议栈、HTTP、传输层 |
| 数据库原理 | 数据库设计、管理和应用 | 《数据库系统概念》 | 关系模型、SQL、事务、索引、范式 |

## 二、专业核心课程

> 专业核心课程是软件工程专业的必修内容，培养学生系统化的软件工程思维。

| 课程名称 | 内容简介 | 核心知识点 |
|----------|---------|-----------|
| 软件工程导论 | 软件工程的基本概念和方法 | 软件生命周期、开发模型（瀑布/敏捷/DevOps）、需求分析 |
| 面向对象程序设计 | 面向对象的编程思想和方法 | 封装、继承、多态、SOLID 原则、设计模式入门 |
| 软件测试 | 软件测试的基本方法和工具 | 单元测试、集成测试、TDD、自动化测试、JUnit/Selenium |
| 软件项目管理 | 软件项目的规划、组织和控制 | 敏捷/Scrum、甘特图、风险管理、版本发布 |
| 软件架构设计 | 软件架构的设计原则和方法 | MVC/微服务/事件驱动、高内聚低耦合、CAP 定理入门 |
| 软件系统建模 | 使用 UML 等工具进行软件系统建模 | 用例图、类图、时序图、状态图、活动图 |

### 专业核心课程推荐教材

| 课程 | 推荐教材 |
|------|---------|
| 软件工程导论 | 《软件工程：实践者的研究方法》（Pressman） |
| 面向对象程序设计 | 《设计模式：可复用面向对象软件的基础》（GoF） |
| 软件测试 | 《软件测试》（Ron Patton） |
| 软件架构设计 | 《软件架构设计：程序员向架构师转型之路》/《Clean Architecture》 |

## 三、专业选修课程

> 专业选修课程提供了多个技术方向的选择，学生可根据兴趣和职业规划进行选修。

| 课程名称 | 内容简介 | 适合方向 | 前置要求 |
|----------|---------|---------|---------|
| 人工智能导论 | 人工智能的基本概念和技术 | AI/ML 方向 | 概率论 + 线性代数 |
| 机器学习 | 机器学习的基本算法和应用 | AI/ML 方向 | 概率论 + 线代 + Python |
| 移动应用软件开发 | 移动应用的开发方法和工具 | 客户端方向 | Java/Kotlin/Swift |
| 嵌入式系统 | 嵌入式系统的设计和开发 | IoT/硬件方向 | C 语言 + 计算机组成 |
| 计算机图形学基础 | 计算机图形学的基本原理和应用 | 游戏/渲染方向 | 线性代数 + C++ |
| 大数据系统软件 | 大数据处理的软件工具和方法 | 数据工程方向 | Java + 数据库 + Linux |
| 人机交互 | 用户界面设计和用户体验 | 前端/产品方向 | 无特殊要求 |
| 网络安全 | 网络安全基础与攻防 | 安全方向 | 计算机网络 + OS |

## 四、实践课程

> 实践课程是软件工程教育的重要组成部分，通过实际项目训练学生的动手能力。

| 课程名称 | 实践内容 | 产出要求 | 技术栈建议 |
|----------|---------|---------|-----------|
| 程序设计实训 | 通过实际项目提高编程能力 | 独立完成一个小型应用 | C/Java，控制台或简单 GUI |
| Web 前端技术实训 | 学习 Web 前端开发技术 | 完成一个响应式网站 | HTML/CSS/JS + Vue/React |
| 专业专题训练 | 针对特定领域深入实践 | 团队完成中型项目 | 按选题自由选择 |
| 综合论文训练 | 培养科研和论文写作能力 | 毕业论文 + 答辩 | 按研究方向确定 |

## 五、课程学习顺序建议

### 推荐学习路径

```
大一上：高等数学 + 线性代数 + C 语言程序设计
大一下：大学物理 + 离散数学 + Java 程序设计 + 数据结构与算法（上）
大二上：概率论 + 计算机组成原理 + 数据结构与算法（下）+ 面向对象程序设计
大二下：操作系统 + 计算机网络 + 软件工程导论 + 程序设计实训
大三上：数据库原理 + 软件测试 + 软件项目管理 + Web 前端技术实训
大三下：软件架构设计 + 软件系统建模 + 专业选修课 + 专业专题训练
大四上：专业选修课 + 综合论文训练
大四下：毕业实习 + 毕业论文答辩
```

### 课程依赖关系

```
C 语言 ──→ 数据结构与算法 ──→ 操作系统 ──→ 软件架构设计
    │            │                 │
    └──→ Java ───┘         ┌──────┘
                           │
高等数学 → 线性代数 → 概率论 → 机器学习 / AI / 大数据
                           │
离散数学 ──→ 算法设计 ─────┘
                           │
计算机组成 ──→ 操作系统 ──→ 计算机网络 ──→ 网络安全
```

## 📖 核心要点速记

1. **数学是 AI/ML 的门槛**：线代 + 概率论 + 微积分是基础，离散数学是算法基础
2. **四大件是面试核心**：数据结构、组成原理、操作系统、网络占面试 70% 以上
3. **实践课决定动手能力**：不要只听课，每个实践课都要认真做项目
4. **选修课是方向探索**：大三前建议广泛尝试，大三后聚焦一个方向深入
5. **课程之间有依赖**：不要跳级选课，先打好基础再深入
