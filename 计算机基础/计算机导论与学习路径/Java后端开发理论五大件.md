Java后端开发理论五大件
一、计算机网络（后端核心）
1. 网络模型：TCP/IP 四层、OSI 七层（只记四层）
2. TCP：三次握手、四次挥手、可靠传输机制
3. HTTP：请求方法、状态码、Header、长连接
4. HTTPS：加密流程、证书、对称/非对称加密
5. Cookie/Session/Token 区别与流程
6. DNS 解析流程
7. 跨域 CORS 原理与解决方案
8. 常见网络问题：超时、重试、重传、限流
    二、操作系统（后端高频）
    1. 进程与线程：区别、状态、上下文切换
    2. 并发基础：锁、互斥、同步、死锁四大条件
    3. 内存管理：堆/栈、虚拟内存、分页
    4. IO 模型：BIO/NIO/AIO、阻塞/非阻塞/同步/异步
    5. Linux 常用命令：进程、网络、文件、日志排查
    6. 中断、系统调用（了解即可）
    三、数据结构与算法（面试核心）
    1. 线性结构：数组、链表、栈、队列、双端队列
    2. 树形结构：二叉树、遍历、B+树（重点）
    3. 哈希表：哈希冲突、装填因子、HashMap 原理
    4. 图：BFS、DFS（够用即可）
    5. 排序算法：快排、归并、堆排（思想+复杂度）
    6. 高频算法模板：
    - 双指针
    - 滑动窗口
    - 二分查找
    - 递归与回溯
    - 简单动态规划
    四、数据库（后端吃饭技能）
    1. SQL 基础：增删改查、多表 JOIN、子查询
    2. 索引：B+树、最左匹配、回表、覆盖索引
    3. 事务：ACID、隔离级别、MVCC
    4. 锁机制：行锁、表锁、间隙锁、临键锁
    5. 慢查询优化：explain、索引优化
    6. 主从复制、分库分表（了解）
    7. Redis 基础：数据结构、缓存、过期、分布式锁
    五、计算机组成原理（后端几乎不用深学）
    1. CPU 架构：核心、缓存、乱序执行
    2. 内存体系：寄存器、L1/L2/L3、主存
    3. 缓存一致性、MESI 协议
    4. 大小端、内存对齐
    5. 指令集、汇编（不用学）
