### 核心知识点

**进程调度算法**：

| 算法 | 特点 |
|------|------|
| 先来先服务（FCFS） | 简单，护航效应 |
| 时间片轮转（RR） | 响应快，公平 |
| 短任务优先（SJF） | 平均等待时间最小 |
| 优先级调度 | 支持抢占/非抢占 |
| 多级反馈队列 | 混合调度，现代 OS 使用 |

**死锁**：

- 4 个必要条件：互斥、持有并等待、不可剥夺、循环等待
- 预防策略：破坏任一必要条件
- 银行家算法：避免死锁的经典算法

### 页面更换算法

| 算法 | 说明 |
|------|------|
| 随机更换 | 简单但性能差 |
| FIFO | 先进先出，可能出现 Belady 异常 |
| 第二次机会 | FIFO 改进，考虑使用位 |
| Clock | 环形链表 + 使用位 |
| OPT（最优） | 置换未来最久不使用的页（理论最优） |
| LRU | 最近最少使用，性能接近 OPT |
| 工作集算法 | 基于进程工作集模型 |

## 第七篇 操作系统设计原理篇

### 第 22 章 操作系统设计之原理

| # | 哲学原理 | 核心思想 |
|---|----------|----------|
| 1 | **层次架构** | 系统分层设计，下层为上层提供服务 |
| 2 | **没有对错** | 设计决策取决于应用场景和权衡 |
| 3 | **懒人哲学** | 能不做就不做，延迟执行（如写时复制） |
| 4 | **让困于人** | 复杂问题交给用户空间处理 |
| 5 | **留有余地** | 预留资源应对未来需求 |
| 6 | **子虚乌有（虚拟化）** | 物理资源抽象为逻辑资源 |
| 7 | **时空转换** | 时间换空间（如虚拟内存）或空间换时间（如缓存） |
| 8 | **认证分离与权利分离** | 权限管理与认证分离 |
| 9 | **简单为美** | 追求设计的简洁性 |
| 10 | **适可而止** | 在复杂度和性能之间找到平衡 |
