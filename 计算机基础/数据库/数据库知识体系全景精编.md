## 一、基础概念层

### 1.1 数据与信息

> **数据（Data）** 是符号化记录；**信息（Information）** 是数据在上下文中的含义。**数据库（DB）** 是长期存储在计算机内、有组织、可共享的数据集合。

### 1.2 数据库管理系统（DBMS）

| 维度 | 说明 |
|------|------|
| 功能 | 定义、创建、查询、更新、维护、控制、通信 |
| 目标 | 数据独立性、数据完整性、并发控制、故障恢复、安全性 |

### 1.3 数据模型三代

| 模型 | 结构 | 代表 |
|------|------|------|
| 层次模型 | 树 | IMS |
| 网状模型 | 图 | IDS |
| 关系模型 | 二维表 | MySQL、Oracle、PostgreSQL |
| 对象-关系模型 | 嵌套表、引用 | PostgreSQL |
| 半结构化模型 | XML、JSON、KV、文档、图 | MongoDB、Redis、Neo4j |

### 1.4 三层模式两层映射

```
外模式（视图层） ⇄ 逻辑模式（概念层） ⇄ 内模式（存储层）
```

> **逻辑/物理独立性** 通过"外/概念映射"和"概念/内映射"实现。

## 二、关系理论层

### 2.1 关系代数

**传统 8 操作：**

| 操作 | 符号 | 说明 |
|------|------|------|
| 选择 | σ | 选取满足条件的元组 |
| 投影 | π | 选取指定列 |
| 笛卡尔积 | × | 两个关系的所有组合 |
| 连接 | ⋈ | 基于条件的连接 |
| 除 | ÷ | 包含所有值的元组 |
| 并 | ∪ | 两个关系的并集 |
| 交 | ∩ | 两个关系的交集 |
| 差 | − | 一个关系减去另一个关系 |

**附加：** 重命名 ρ、赋值 ←、聚集 γ

### 2.2 元组关系演算 & 域关系演算

- 安全表达式、等价性、与代数互相转换

### 2.3 范式体系

| 范式 | 规则 | 说明 |
|------|------|------|
| 1NF | 原子性 | 列不可再分 |
| 2NF | 消除部分函数依赖 | 非主键列完全依赖于主键 |
| 3NF | 消除传递函数依赖 | 非主键列不依赖于其他非主键列 |
| BCNF | 每个决定因素都是候选键 | 主键列之间无依赖 |
| 4NF | 消除多值依赖 | 消除非平凡多值依赖 |
| 5NF | 消除连接依赖 | 消除非平凡连接依赖 |

> **反范式：** 冗余换性能。

### 2.4 函数依赖与 Armstrong 公理

| 公理 | 说明 |
|------|------|
| 自反律 | 若 β ⊆ α，则 α → β |
| 增广律 | 若 α → β，则 αγ → βγ |
| 传递律 | 若 α → β 且 β → γ，则 α → γ |

**扩展：** 闭包计算、最小覆盖

### 2.5 完整性约束

| 约束类型 | 说明 |
|---------|------|
| 域约束 | 属性值必须满足的数据类型和范围 |
| 实体完整性 | 主键不能为空 |
| 参照完整性 | 外键值必须存在于被参照关系的主键中 |
| 用户自定义完整性 | 业务规则约束 |
| 检查子句（CHECK） | 条件约束 |
| 断言（Assertion） | 更复杂的全局约束 |
| 触发器（Trigger） | 事件驱动约束 |

## 三、SQL 语言层

```sql
CREATE / ALTER / DROP / RENAME DATABASE、TABLE、INDEX、VIEW、SEQUENCE
```

### 3.2 数据操纵（DML）

```sql
INSERT、DELETE、UPDATE、MERGE
```

```sql
SELECT-FROM-WHERE 框架
```

**子查询：** IN/EXISTS/ANY/ALL、派生表、公共表表达式（CTE）

```sql
UNION、INTERSECT、EXCEPT
ORDER BY、LIMIT/OFFSET
```

```sql

ROW_NUMBER、RANK、DENSE_RANK、LAG/LEAD
```

```sql
BEGIN / START TRANSACTION、COMMIT、ROLLBACK、SAVEPOINT
```

### 3.7 索引与优化提示

```sql

-- HINT
```

## 四、存储与索引层

### 4.1 磁盘结构

```
盘面 → 磁道 → 扇区 → 簇
```

> **顺序 I/O vs 随机 I/O；** 预读、延迟写。

### 4.2 文件组织

| 组织方式 | 说明 |
|---------|------|
| 堆文件 | 无序存储，插入快，查询慢 |
| 排序文件 | 按关键字排序，查询快，插入慢 |
| 散列文件 | 基于散列函数分布 |
| 聚簇文件 | 相关记录物理相邻存储 |

### 4.3 索引技术

| 索引类型 | 说明 | 代表数据库 |
|---------|------|-----------|
| B+ Tree | 阶 m，节点填充因子 ≥ 50%，范围扫描高效 | MySQL InnoDB |
| Hash | 静态、可扩展、线性散列；桶溢出链 | MySQL Memory |
| Bitmap | 位图索引，适合低基数列 | Oracle |
| R-Tree | 空间索引 | PostgreSQL |
| GiST | 通用搜索树 | PostgreSQL |
| LSM-Tree | 日志结构合并树 | LevelDB、RocksDB |
| 跳表 | 有序链表 + 多层索引 | Redis |

### 4.4 聚簇与非聚簇

> **InnoDB 主键即聚簇索引；** 二级索引需回表。

### 4.5 覆盖索引与最左前缀

```sql
-- 联合索引 (a, b, c) 可服务 WHERE a=1 AND b=2
-- 但不能服务 WHERE b=2
-- EXPLAIN 查看 key_len
```

### 4.6 索引失效 8 条

| 场景 | 说明 |
|------|------|
| 对索引列运算 | 函数、计算 |
| LIKE '%xx' | 前缀模糊匹配 |
| OR 过多 | OR 连接非索引列 |
| 隐式转换 | 类型不匹配 |
| 函数 | 使用函数包裹索引列 |
| 表达式 | 索引列参与表达式 |
| 范围后失效 | 联合索引范围列之后的列 |
| 不等于 | !=、<> |

## 五、事务与并发控制

### 5.1 ACID

| 特性 | 实现 |
|------|------|
| Atomicity（原子性） | redo/undo log |
| Consistency（一致性） | 约束 + 触发器 |
| Isolation（隔离性） | 锁 + MVCC |
| Durability（持久性） | WAL |

### 5.2 并发异常

| 异常 | 说明 |
|------|------|
| 脏读 | 读到未提交数据 |
| 不可重复读 | 同一行两次读取结果不同 |
| 幻读 | 同一条件两次查询行数不同 |
| 丢失更新 | 两个事务同时更新导致覆盖 |
| 写偏斜 | 基于旧值更新导致约束违反 |

### 5.3 隔离级别

| 级别 | 脏读 | 不可重复读 | 幻读 |
|------|------|-----------|------|
| Read Uncommitted | ✓ | ✓ | ✓ |
| Read Committed | ✗ | ✓ | ✓ |
| Repeatable Read | ✗ | ✗ | 部分解决 |
| Serializable | ✗ | ✗ | ✗ |

### 5.4 锁机制

**粒度：**

| 粒度 | 说明 |
|------|------|
| 表锁 | 锁定整张表 |
| 页锁 | 锁定数据页 |
| 行锁 | 锁定单行记录 |
| 元组锁 | 锁定元组 |
| 意向锁 | 表示即将在更细粒度上加锁 |

**类型：**

| 类型 | 说明 |
|------|------|
| 共享锁（S） | 允许其他事务读 |
| 排他锁（X） | 不允许其他事务读写 |
| 更新锁（U） | 防止死锁 |
| 意向共享（IS） | 准备加 S 锁 |
| 意向排他（IX） | 准备加 X 锁 |

**死锁：**
- **检测：** 等待图、超时
- **预防：** 一次封锁、顺序封锁

### 5.5 MVCC（多版本并发控制）

| 组件 | 说明 |
|------|------|
| 隐藏列 | trx_id、roll_pointer |
| ReadView | 可见性判断 |
| 快照读 | 基于 MVCC，不加锁 |
| 当前读 | 加锁，读取最新版本 |

### 5.6 日志系统

| 日志 | 说明 |
|------|------|
| Redo Log | 物理日志，循环写，崩溃恢复 |
| Undo Log | 逻辑日志，事务回滚 |
| Checkpoint | 减少恢复时间 |

## 六、故障恢复与备份

### 6.1 故障类型

| 故障类型 | 说明 |
|---------|------|
| 事务故障 | 事务执行失败 |
| 系统故障 | 系统崩溃、断电 |
| 介质故障 | 磁盘损坏 |
| 网络故障 | 网络中断 |

### 6.2 恢复策略

| 策略 | 说明 |
|------|------|
| 延迟更新 | 事务提交后才写数据库 |
| 立即更新 | 事务执行中直接写数据库 |
| 镜像 | 数据库镜像 |
| 影子分页 | 通过页表切换实现原子提交 |

### 6.3 备份方式

| 备份类型 | 说明 |
|---------|------|
| 冷备 | 关闭数据库备份 |
| 热备 | 运行时备份 |
| 逻辑备份 | mysqldump |
| 物理备份 | xtrabackup |
| 增量备份 | 只备份变化数据 |
| 差异备份 | 备份自上次全备的变化数据 |

### 6.4 Point-in-Time Recovery（PITR）

```
全备 + 归档日志 + 时间点定位
```

## 七、分布式数据库

### 7.1 CAP 定理

> Consistency（一致性）、Availability（可用性）、Partition tolerance（分区容忍性）三者不可全得。

### 7.2 BASE 理论

| 概念 | 说明 |
|------|------|
| Basically Available | 基本可用 |
| Soft state | 软状态 |
| Eventually consistent | 最终一致性 |

### 7.3 分片策略

| 策略 | 说明 |
|------|------|
| 水平分片 | Range、Hash、List |
| 垂直分片 | 按列拆分 |
| 混合分片 | 水平 + 垂直 |

### 7.4 一致级别

| 级别 | 说明 |
|------|------|
| 强一致 | 写后立即可读 |
| 线性一致 | 所有操作按实时顺序执行 |
| 顺序一致 | 所有操作按程序顺序执行 |
| 最终一致 | 一段时间后一致 |

> **Quorum NRW：** N 个副本，R 个读，W 个写，满足 R + W > N。

### 7.5 全局时钟

| 时钟类型 | 说明 |
|---------|------|
| 物理时钟 | NTP 漂移 |
| 逻辑时钟 | Lamport 时钟、向量时钟 |
| 混合时钟 | TrueTime（Google Spanner） |

### 7.6 分布式事务

| 协议 | 说明 |
|------|------|
| 2PC | 两阶段提交 |
| 3PC | 三阶段提交 |
| TCC | Try-Confirm-Cancel |
| Saga | 长事务补偿 |
| Paxos / Raft | 日志复制 |

## 九、性能优化体系

### 9.1 查询优化流程

```
解析 → 重写 → 生成逻辑计划 → 选择物理计划 → 执行
```

> **代价模型：** CPU + I/O + 网络；选择性估算

### 9.2 索引优化

| 技术 | 说明 |
|------|------|
| 单列 vs 联合 | 根据查询模式选择 |
| 覆盖索引 | 索引包含所有查询列 |
| 索引下推（ICP） | 存储引擎层过滤 |
| 跳跃扫描 | 联合索引跳过最左列 |
| 索引合并 | 多个索引合并使用 |

### 9.3 查询重写

| 技术 | 说明 |
|------|------|
| 子查询转连接 | 减少嵌套层级 |
| 半连接反连接 | 优化 EXISTS/NOT EXISTS |
| 物化视图 | 预计算结果 |
| 公共表表达式（CTE） | 递归查询 |

### 9.4 执行计划关键字

| 字段 | 值（性能从好到差） | 说明 |
|------|-------------------|------|
| type | system > const > eq_ref > ref > range > index > ALL | 访问类型 |
| key_len | — | 联合索引实际使用字节数 |
| Extra | Using index、Using filesort、Using temporary、Using index condition | 额外信息 |

### 9.5 配置调优

| 参数 | 建议 |
|------|------|
| InnoDB Buffer Pool | 70% RAM |
| sort_buffer_size | 根据排序需求调整 |
| join_buffer_size | 根据连接需求调整 |

### 9.6 架构层

```
读写分离 → 主从复制 → 半同步 → 组复制 → 分库分表 → 冷热分离 → 缓存层 Redis
```
