Navicat 手把手教程（从安装到企业级使用）

一、下载与安装
1. 下载
    - 官网：https://www.navicat.com/
    - 选择版本：Navicat Premium（支持所有数据库）
    - 选择系统：Windows/Mac/Linux
2. 安装
    - 双击安装包，一路下一步
    - 安装完成后打开，选择「试用」或「激活」
    二、连接数据库（以 MySQL 为例）
    1. 新建连接
    - 点击左上角「连接」→ 选择「MySQL」
    - 填写连接信息：
    - 连接名：自定义（如 local-mysql）
    - 主机：localhost（远程填服务器IP）
    - 端口：3306
    - 用户名：root
    - 密码：你的数据库密码
    - 点击「测试连接」→ 显示「连接成功」→ 确定
    2. 打开连接
    - 左侧双击连接名，展开数据库列表
    三、基础操作（必会）
    1. 创建数据库
    - 右键连接名 → 「新建数据库」
    - 填写：
    - 数据库名：test
    - 字符集：utf8mb4
    - 排序规则：utf8mb4_unicode_ci
    - 确定
    2. 创建表
    - 展开数据库 → 右键「表」→ 「新建表」
    - 设计表结构：
    - 字段名：id
    - 类型：INT
    - 主键：√
    - 自动递增：√
    - 点击「添加字段」继续
    - 保存 → 表名：user
3. 增删改查数据
    （1）添加数据
    - 打开表 → 点击「+」添加行 → 填写数据 → 「√」保存
    （2）修改数据
    - 直接双击单元格修改 → 「√」保存
    （3）删除数据
    - 选中行 → 点击「-」→ 确认删除
    （4）查询数据
    - 点击「查询」→ 「新建查询」
    - 输入 SQL：
    sql
    SELECT * FROM user;
 
- 点击「运行」→ 查看结果
    四、高级功能（企业级）
    1. 数据备份
- 右键数据库 → 「转储SQL文件」→ 「结构和数据」
- 选择保存路径 → 开始备份
    2. 数据恢复
- 右键数据库 → 「运行SQL文件」
- 选择备份文件 → 开始恢复
    3. 数据同步
- 工具 → 数据同步
- 选择源库和目标库 → 对比 → 同步
    4. 表结构同步
- 工具 → 结构同步
- 对比表结构 → 生成同步 SQL → 执行
    5. 导入/导出数据
    （1）导出
- 右键表 → 「导出向导」
- 选择格式：CSV/Excel/SQL
- 下一步 → 完成
    （2）导入
- 右键表 → 「导入向导」
- 选择文件 → 映射字段 → 导入
    6. 执行 SQL 脚本
- 文件 → 打开 SQL → 选择脚本 → 运行
    五、常用技巧
    1. 快捷键
- 运行 SQL：Ctrl + R
- 注释：Ctrl + /
- 格式化 SQL：Ctrl + Shift + F
    2. 保存查询
- 编写 SQL 后 → 「保存」→ 下次直接打开
    3. 筛选数据
- 打开表 → 上方「筛选」→ 输入条件（如 id > 10）
    六、企业级最佳实践
    1. 连接名规范：环境-数据库（如 dev-mysql、prod-mysql）
    2. 定期备份：生产库每日自动备份
    3. 权限控制：不同环境使用不同账号
    4. SQL 格式化：执行前格式化，避免语法错误
    5. 事务控制：重要操作使用事务，避免误删
    七、常见问题
    1. 连接失败
- 检查：IP、端口、用户名、密码、防火墙
- 远程连接：确保 3306 端口开放
    2. 中文乱码
- 数据库字符集：utf8mb4
- 连接字符集：utf8mb4
    3. 导入失败
- 检查 SQL 语法、字段类型、主键冲突
