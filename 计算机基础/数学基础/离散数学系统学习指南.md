## 1. 数理逻辑

### 1.1 命题逻辑

**基本概念：**
- **命题：** 能判断真假的陈述句
- **原子命题：** 不能再分解的简单命题
- **复合命题：** 由原子命题和逻辑联结词构成

**逻辑联结词：**

| 联结词 | 符号 | 含义 | 真值条件 |
|--------|------|------|----------|
| 否定 | ¬ | 非 | ¬P 为真 ↔ P 为假 |
| 合取 | ∧ | 且 | P∧Q 为真 ↔ P 和 Q 同时为真 |
| 析取 | ∨ | 或 | P∨Q 为真 ↔ P 或 Q 为真 |
| 蕴含 | → | 若...则... | P→Q 仅当 P=1 且 Q=0 时为假 |
| 等价 | ↔ | 当且仅当 | P↔Q 为真 ↔ P 和 Q 真值相同 |

**Java 中的对应：**
```java
// ¬ (NOT)  →  !
// ∧ (AND)  →  &&
// ∨ (OR)   →  ||
// → (IMPLIES) →  !P || Q  （蕴含消除）
boolean implies(boolean p, boolean q) { return !p || q; }
```

### 1.2 谓词逻辑

**超越命题逻辑的限制：** 命题逻辑不能表达"所有"和"存在"。

| 量词 | 符号 | 含义 |
|------|------|------|
| 全称量词 | ∀ | "for all"——所有 |
| 存在量词 | ∃ | "there exists"——存在某个 |

**量词否定规则：**
```
¬∀x P(x) ≡ ∃x ¬P(x)      "不是所有人都喜欢" ≡ "存在一个人不喜欢"
¬∃x P(x) ≡ ∀x ¬P(x)      "不存在人喜欢"     ≡ "所有人都不喜欢"
```

**数据库查询中的谓词逻辑：**
```sql
-- "所有年龄大于 20 的用户" → ∀x(用户(x) ∧ 年龄(x) > 20)
-- 对应 SQL：
SELECT * FROM users WHERE age > 20;

-- "存在一笔金额超过 1000 的订单" → ∃x(订单(x) ∧ 金额(x) > 1000)
-- 对应 SQL EXISTS 子查询
SELECT * FROM users u WHERE EXISTS (
    SELECT 1 FROM orders o WHERE o.user_id = u.id AND amount > 1000
);
```

### 1.3 推理规则

| 规则 | 形式 | 示例 |
|------|------|------|
| 假言推理（Modus Ponens） | P→Q, P ∴ Q | 若下雨则地湿，下雨了，所以地湿 |
| 拒取式（Modus Tollens） | P→Q, ¬Q ∴ ¬P | 若下雨则地湿，地不湿，所以没下雨 |
| 析取三段论 | P∨Q, ¬P ∴ Q | 咖啡或茶，不要咖啡，所以茶 |

## 2. 集合论

### 2.1 基本运算

| 运算 | 符号 | 定义 | Java 对应（Set 接口） |
|------|------|------|----------------------|
| 并集 | A ∪ B | {x \| x∈A 或 x∈B} | `set1.addAll(set2)` |
| 交集 | A ∩ B | {x \| x∈A 且 x∈B} | `set1.retainAll(set2)` |
| 差集 | A - B | {x \| x∈A 且 x∉B} | `set1.removeAll(set2)` |
| 补集 | A̅ | {x \| x∉A}（相对于全集 U） | 需构造全集 |
| 幂集 | P(A) | A 的所有子集的集合 | 需递归生成 |

### 2.2 集合恒等式

```
德摩根律：(A ∪ B)̅ = A̅ ∩ B̅           (A ∩ B)̅ = A̅ ∪ B̅
分配律：  A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
         A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)
```

**Java 中的应用：**
```java
Set<Integer> a = new HashSet<>(Set.of(1, 2, 3));
Set<Integer> b = new HashSet<>(Set.of(2, 3, 4));

// 并集
Set<Integer> union = new HashSet<>(a);
union.addAll(b);  // {1, 2, 3, 4}

// 交集
Set<Integer> intersect = new HashSet<>(a);
intersect.retainAll(b);  // {2, 3}

// 差集
Set<Integer> diff = new HashSet<>(a);
diff.removeAll(b);  // {1}
```

### 2.3 集合的基数

- **有限集：** `|A ∪ B| = |A| + |B| - |A ∩ B|`（容斥原理）
- **无限集：** 可数无限 vs 不可数无限

**容斥原理（推广到 n 个集合）：**
```
|A₁ ∪ A₂ ∪ ... ∪ Aₙ| = Σ|Aᵢ| - Σ|Aᵢ ∩ Aⱼ| + Σ|Aᵢ ∩ Aⱼ ∩ Aₖ| - ... + (-1)ⁿ⁺¹|A₁ ∩ ... ∩ Aₙ|
```

## 3. 关系与函数

### 3.1 二元关系

**定义：** A 到 B 的二元关系 R 是 A×B 的一个子集。

**关系的性质：**

| 性质 | 定义 | 示例 |
|------|------|------|
| 自反性 | ∀a∈A, aRa | =, ≤, ≥ |
| 对称性 | aRb → bRa | =, 夫妻关系 |
| 反对称性 | aRb ∧ bRa → a=b | ≤, ≥ |
| 传递性 | aRb ∧ bRc → aRc | =, ≤, 祖先关系 |

**等价关系：** 同时满足自反、对称、传递（如 =、同余关系）
**偏序关系：** 同时满足自反、反对称、传递（如 ≤、集合的 ⊆）

### 3.2 关系在数据库中的体现

数据库中的"关系"与离散数学中的"关系"是同一概念：

- 数据库表 = 关系 R 的实例（一个具体的笛卡尔积子集）
- SQL JOIN = 关系的组合运算
- 外键约束 = 参照完整性（referential integrity）

### 3.3 函数

**定义：** f: A→B，若每个 a∈A 对应唯一的 b∈B，称 f 为函数。

| 性质 | 定义 | 说明 |
|------|------|------|
| 单射（injective） | f(a₁)=f(a₂) → a₁=a₂ | 不同输入必有不同输出 |
| 满射（surjective） | ∀b∈B, ∃a∈A: f(a)=b | B 中每个元素都有原像 |
| 双射（bijective） | 同时单射和满射 | 一一对应 |

**Java 中的函数式接口：**
```java
Function<Integer, String> f = x -> "value: " + x;  // f: Z → String
// f 是单射吗？是，不同 x 给出不同 String
// f 是满射吗？否，String "hello" 没有 Integer 原像
// f 是双射吗？否
```

## 4. 图论

### 4.1 图的基本概念

| 术语 | 定义 |
|------|------|
| 简单图 | 无自环、无多重边 |
| 完全图 Kₙ | 每对不同顶点间都有边 |
| 二分图 | 顶点可分成两个不相交集合，所有边跨集合 |
| 度 | 与顶点关联的边数 |
| 握手定理 | Σdeg(v) = 2E（所有顶点度之和 = 2×边数） |

### 4.2 图的同构

两个图本质相同但画法不同 → 存在一一对应保持边的连接关系。

### 4.3 最短路径问题

| 算法 | 适用条件 | 复杂度 |
|------|----------|--------|
| Dijkstra | 非负权 | O(V²) 或 O(E log V) |
| Bellman-Ford | 含负权 | O(VE) |
| Floyd-Warshall | 全源最短路径 | O(V³) |

### 4.4 最小生成树（MST）

| 算法 | 策略 | 复杂度 |
|------|------|--------|
| Prim | 从点出发，每次加入最近的邻接点 | O(V²) 或 O(E log V) |
| Kruskal | 从边出发，每次加入最短的不形成环的边（并查集） | O(E log E) |

### 4.5 欧拉图与哈密顿图

| | 欧拉图 | 哈密顿图 |
|------|--------|----------|
| 问题 | 经过每条**边**恰好一次 | 经过每个**顶点**恰好一次 |
| 判定 | 充要条件已知（所有顶点度为偶数） | 无简单判定条件（NP-完全） |
| 算法 | Fleury 算法 O(E²) | 无多项式算法 |

### 4.6 图着色

**四色定理：** 任何平面图可用 ≤4 种颜色着色，使相邻区域颜色不同。

**应用：** 寄存器分配（编译器优化）、频道分配。

## 5. 组合数学

### 5.1 排列与组合

| 概念 | 公式 | 说明 |
|------|------|------|
| 排列 P(n,r) | n!/(n-r)! | 有序选取 r 个 |
| 组合 C(n,r) | n!/(r!(n-r)!) | 无序选取 r 个 |

```java
// 组合数计算（递推：杨辉三角）
long[][] C = new long[n+1][n+1];
for (int i = 0; i <= n; i++) {
    C[i][0] = C[i][i] = 1;
    for (int j = 1; j < i; j++)
        C[i][j] = C[i-1][j-1] + C[i-1][j];
}
```

### 5.2 鸽巢原理（Pigeonhole Principle）

**基本形式：** n+1 只鸽子放入 n 个巢，至少一个巢有 ≥2 只鸽子。

**推广形式：** k 只鸽子放入 n 个巢，至少一个巢有 ≥⌈k/n⌉ 只鸽子。

**应用：**
- 哈希冲突一定存在（键的集合 > 哈希值的集合）
- 任意 367 人中必有两人同一天生日

### 5.3 容斥原理

**两集合：** |A ∪ B| = |A| + |B| - |A ∩ B|
**三集合：** |A ∪ B ∪ C| = |A| + |B| + |C| - |A ∩ B| - |B ∩ C| - |A ∩ C| + |A ∩ B ∩ C|

**应用：** 计算 1-100 中能被 2 或 3 或 5 整除的数的个数。

### 5.4 递推关系

**经典例子：**
- **斐波那契数列：** Fₙ = Fₙ₋₁ + Fₙ₋₂, F₀=0, F₁=1
- **汉诺塔：** Tₙ = 2Tₙ₋₁ + 1 → Tₙ = 2ⁿ - 1
- **卡特兰数：** Cₙ = C₀Cₙ₋₁ + C₁Cₙ₋₂ + ... + Cₙ₋₁C₀

```java
// 斐波那契：递归 vs 迭代
// 递推（O(n), O(1) 空间）
long fib(int n) {
    if (n <= 1) return n;
    long a = 0, b = 1;
    for (int i = 2; i <= n; i++) {
        long c = a + b; a = b; b = c;
    }
    return b;
}
```

### 5.5 生成函数（母函数）

**核心思想：** 将一个序列 {aₙ} 编码为幂级数 G(x) = Σ aₙxⁿ，将组合计数问题转化为代数运算。

**应用：** 整数拆分计数、递推关系求解、组合恒等式证明。

## 6. 后端开发关联

### 6.1 数据库关系模型

- 表（Relation）= 离散数学中的关系 R ⊆ D₁×D₂×...×Dₙ
- 主键 = 关系的超键（superkey）
- JOIN = 关系代数中的连接操作（⋈）
- 约束（CHECK、FOREIGN KEY）= 谓词逻辑的应用

### 6.2 算法正确性证明

离散数学的逻辑推理是算法证明的基础：
- **循环不变式（Loop Invariant）：** 在每次循环迭代前后保持为真的谓词
- **数学归纳法：** 证明递归算法正确性的核心工具

### 6.3 图算法在工程中的应用

| 图论概念 | 工程应用 |
|----------|----------|
| 有向无环图（DAG） | 任务依赖调度（Maven 构建顺序、Spark 执行计划） |
| 拓扑排序 | Spring Bean 依赖注入顺序 |
| 最短路径 | 微服务调用链最优化 |
| 最小生成树 | 网络拓扑设计（最小化布线成本） |
| 二分图匹配 | 资源分配、任务指派 |
