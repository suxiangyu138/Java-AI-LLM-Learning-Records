## 2. 向量与向量空间

### 2.1 定义与双重视角

| 视角 | 理解 | 示例 |
|------|------|------|
| **几何视角** | 具有大小和方向的量（箭头） | 二维平面上的箭头 |
| **代数视角** | 有序的 n 元组 | `v = (v₁, v₂, ..., vₙ)` |

### 2.2 基本运算

```text
向量加法：    v + w = (v₁+w₁, v₂+w₂, ..., vₙ+wₙ)
标量乘法：    c·v  = (c·v₁, c·v₂, ..., c·vₙ)
内积（点积）：v·w  = v₁w₁ + v₂w₂ + ... + vₙwₙ
模（L2 范数）：||v|| = √(v·v) = √(Σ vᵢ²)
```

**关键性质：**

| 性质 | 公式 | 含义 |
|------|------|------|
| 内积与夹角 | `cos θ = (v·w) / (||v||·||w||)` | 内积越大 → 方向越接近 |
| 柯西-施瓦茨不等式 | `|v·w| ≤ ||v||·||w||` | 余弦相似度的理论基础 |
| 勾股定理 | 若 `v·w = 0` 则 `||v+w||² = ||v||² + ||w||²` | 正交向量的几何性质 |

### 2.3 线性相关与线性无关

```
线性组合：    c₁v₁ + c₂v₂ + ... + cₙvₙ
线性无关：    若 c₁v₁ + ... + cₙvₙ = 0 仅在所有 cᵢ=0 时成立
线性相关：    存在不全为零的系数使组合为零
```

**直观理解：**
- 二维：两个非共线的向量线性无关（张成整个平面）
- 三维：三个不共面的向量线性无关（张成整个空间）
- AI 含义：线性相关的特征包含冗余信息 → PCA 降维移除

### 2.4 基与维数

| 概念 | 定义 | 示例 |
|------|------|------|
| **基 (Basis)** | 一组线性无关且能张成整个空间的向量 | R³ 标准基：e₁=(1,0,0), e₂=(0,1,0), e₃=(0,0,1) |
| **维数** | 基中向量的个数 | Rⁿ 的维数是 n |
| **正交基** | 基向量两两正交 | 标准基是正交基 |
| **标准正交基** | 正交基且所有向量模为 1 | PCA 得到的主成分 |

### 2.5 向量在 AI 中的核心应用

**Embedding 的本质：**
```
"king"  → [0.23, -0.15, 0.87, ..., 0.42]  (300 维向量)
"queen" → [0.19, -0.11, 0.83, ..., 0.38]  (300 维向量)

"king" - "man" + "woman" ≈ "queen"
  → 向量空间中，语义关系 = 向量运算
```

**余弦相似度（RAG 系统的核心）：**
```
cos_sim(A, B) = (A·B) / (||A||·||B||)

= 1  → 方向完全相同（语义相同）
= 0  → 正交（语义无关）
= -1 → 方向相反（语义对立）
```

## 3. 矩阵运算

### 3.1 矩阵表示

```
m×n 矩阵 A：
    [a₁₁ a₁₂ ... a₁ₙ]
    [a₂₁ a₂₂ ... a₂ₙ]
    [ ... ... ... ... ]
    [aₘ₁ aₘ₂ ... aₘₙ]

记法：A ∈ R^{m×n}，表示 m 行 n 列的实矩阵
```

### 3.2 矩阵乘法

```
(AB)_{ij} = Σₖ A_{ik} · B_{kj}

条件：A 的列数 = B 的行数
结果：若 A ∈ R^{m×k}, B ∈ R^{k×n}，则 AB ∈ R^{m×n}
```

**关键性质：**

| 性质 | 说明 | AI 中的影响 |
|------|------|-----------|
| **不满足交换律** `AB ≠ BA` | 顺序重要 | 权重矩阵不能随意交换顺序 |
| **满足结合律** `(AB)C = A(BC)` | 可分批计算 | 支持 mini-batch 训练 |
| **分配律** `A(B+C) = AB + AC` | 线性性质 | 残差连接 `x + F(x)` 的理论基础 |
| **转置** `(AB)ᵀ = BᵀAᵀ` | 反转顺序 | 反向传播中的梯度传递 |

```java
// 矩阵乘法的三重循环实现（理解本质用，生产环境请用 ND4J/BLAS）
double[][] multiply(double[][] a, double[][] b) {
    int m = a.length, n = b[0].length, k = b.length;
    double[][] c = new double[m][n];
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            for (int p = 0; p < k; p++)
                c[i][j] += a[i][p] * b[p][j];
    return c;
}
// 时间复杂度：O(m·n·k)，这也是神经网络前向传播的计算复杂度来源
```

### 3.3 特殊矩阵速查

| 矩阵类型 | 定义 | 性质 | AI 中的典型应用 |
|----------|------|------|----------------|
| **单位矩阵 I** | diag(1,1,...,1) | AI = IA = A | 恒等映射 / 残差初始化 |
| **对角矩阵** | 仅对角线非零 | 运算简化为对角线直接运算 | 特征值矩阵 Λ |
| **转置矩阵 Aᵀ** | 行列互换 | (AB)ᵀ = BᵀAᵀ | 反向传播中的梯度 |
| **对称矩阵** | A = Aᵀ | 特征值均为实数 | 协方差矩阵（PCA） |
| **正交矩阵** | AᵀA = I | 保距变换 | 旋转矩阵、Householder 变换 |
| **逆矩阵 A⁻¹** | AA⁻¹ = A⁻¹A = I | 仅 det(A)≠0 时存在 | 白化变换 |
| **正定矩阵** | xᵀAx > 0 ∀x≠0 | 特征值全正 | Hessian 矩阵（凸优化保证） |
| **稀疏矩阵** | 大部分元素为零 | 存储和计算优化 | 大型稀疏参数矩阵 |

## 4. 行列式

### 4.1 几何意义

| 维度 | 几何意义 |
|------|----------|
| 二维 | 2 个列向量张成的**平行四边形面积** |
| 三维 | 3 个列向量张成的**平行六面体体积** |
| n 维 | n 个列向量张成的**平行多面体超体积** |

```
det(A) = 0  ←→  列向量线性相关  ←→  退化（面积为 0）
det(A) ≠ 0  ←→  列向量线性无关  ←→  矩阵可逆
```

### 4.2 基本性质

| 性质 | 公式 |
|------|------|
| 单位矩阵 | `det(I) = 1` |
| 乘法可分离 | `det(AB) = det(A)·det(B)` |
| 转置不变 | `det(Aᵀ) = det(A)` |
| 逆矩阵 | `det(A⁻¹) = 1/det(A)` |
| 行交换 | 交换两行 → 行列式变号 |
| 标量乘法 | 某行乘以 c → 行列式乘以 c |

> **AI 关联：** 行列式的绝对值衡量线性变换后空间的缩放因子。在正态分布的概率密度函数中，分母的 `|Σ|^{1/2}` 就是协方差矩阵行列式的平方根。

## 5. 特征值与特征向量

### 5.1 定义

```
Ax = λx

A：n×n 矩阵
λ：特征值（标量）
x：特征向量（非零向量）
```

**几何含义：** 矩阵 A 作用于特征向量 x 上，只缩放其长度（λ 倍），不改变方向。

### 5.2 特征分解（谱分解）

若 n×n 矩阵 A 有 n 个线性无关的特征向量：

```
A = PDP⁻¹

其中：
  D = diag(λ₁, λ₂, ..., λₙ)  — 特征值对角矩阵
  P = [x₁  x₂  ...  xₙ]      — 特征向量矩阵（列向量）
```

### 5.3 AI 关键应用：PCA（主成分分析）

```
PCA 计算流程：
1. 数据中心化：X̃ = X - μ
2. 计算协方差矩阵：Σ = (1/n) X̃ᵀX̃
3. 特征分解：Σ = PDPᵀ
4. 取前 k 个最大特征值对应的特征向量作为主成分
5. 降维：Z = X̃ · P_k   (P_k 是前 k 个主成分组成的矩阵)
```

**为什么取最大特征值？** → 特征值越大，对应方向上的方差越大，保留的信息越多。

## 6. 矩阵分解

### 6.1 各类分解总览

| 分解 | 公式 | 适用条件 | 核心应用 |
|------|------|----------|----------|
| **LU 分解** | `A = LU` | 方阵可逆 | 解线性方程组、计算行列式 |
| **Cholesky** | `A = LLᵀ` | 对称正定 | 优化问题、协方差矩阵采样 |
| **QR 分解** | `A = QR` | 任意矩阵 | 最小二乘、特征值计算 |
| **特征分解** | `A = PDP⁻¹` | 方阵且有 n 个特征向量 | PCA、微分方程 |
| **SVD** | `A = UΣVᵀ` | **任意矩阵** | 降维、压缩、推荐系统 |

### 6.2 SVD（奇异值分解）—— 最重要的一种

```
任何 m×n 矩阵 A 都可以分解为：

A = U Σ Vᵀ

U：m×m 正交矩阵（左奇异向量）
Σ：m×n 对角矩阵（奇异值 σ₁ ≥ σ₂ ≥ ... ≥ σ_min(m,n) ≥ 0）
V：n×n 正交矩阵（右奇异向量）
```

**SVD 的三层含义：**
1. **旋转 → 缩放 → 旋转**：任意线性变换 = 旋转 + 按奇异值缩放 + 再旋转
2. **低秩近似**：保留前 k 个最大奇异值，是最佳的 k 秩近似（Eckart-Young 定理）
3. **伪逆**：`A⁺ = VΣ⁺Uᵀ`，可用于求解不可逆方程组

### 6.3 SVD 在 AI 中的核心应用

| 应用 | 原理 | 效果 |
|------|------|------|
| **LoRA 微调** | 用两个低秩矩阵 A·B 近似全参数更新 ΔW | 参数量减少 1000× |
| **Embedding 压缩** | SVD 降维保留前 k 个奇异值 | 存储减少 10×，检索加速 |
| **推荐系统** | 用户-物品评分矩阵的潜在因子分解 | 协同过滤的核心 |
| **权重矩阵分析** | 检查权重的谱分布 | 判断模型是否过参数化 |

## 7. 线性变换与几何直觉

### 7.1 线性变换的定义

函数 T: V→W 满足两个条件时为线性变换：
- `T(u + v) = T(u) + T(v)`（可加性）
- `T(c·v) = c·T(v)`（齐次性）

**核心洞察：** 每个线性变换都对应一个矩阵，反之亦然。

### 7.2 常见线性变换的矩阵表示（二维）

| 变换 | 矩阵 | 几何效果 |
|------|------|----------|
| 缩放 | `[sₓ  0; 0  sᵧ]` | 沿坐标轴拉伸 |
| 旋转（逆时针 θ） | `[cosθ  -sinθ; sinθ  cosθ]` | 绕原点旋转 |
| 反射 | `[-1 0; 0 1]` | 关于 y 轴镜像 |
| 剪切 | `[1 k; 0 1]` | 水平错切 |
| 投影 | `[1 0; 0 0]` | 投影到 x 轴 |

### 7.3 矩阵乘法的几何含义

```
"矩阵乘法 = 复合线性变换"

先做 B 变换，再做 A 变换 = 矩阵 AB 对应的变换
→ 矩阵乘法不满足交换律的根本原因：变换顺序不可交换
```

## 8. AI 大模型中的线性代数

### 8.1 全连接层（最基础的神经网络组件）

```
前向传播：h = σ(Wx + b)

  W：权重矩阵（线性变换）  d_out × d_in
  x：输入向量              d_in × 1
  b：偏置向量（平移）       d_out × 1
  σ：激活函数（引入非线性）

理解：Wx = 线性变换，+b = 平移，σ = 弯曲空间
```

### 8.2 Transformer Self-Attention 的矩阵分解

```
Attention(Q, K, V) = softmax( QKᵀ / √dₖ ) V

逐步拆解：
  Q = X·W_Q    → X ∈ R^{n×d}, W_Q ∈ R^{d×dₖ} → Q ∈ R^{n×dₖ}
  K = X·W_K    → K ∈ R^{n×dₖ}
  V = X·W_V    → V ∈ R^{n×dᵥ}

  S = QKᵀ      → S ∈ R^{n×n} （注意力得分矩阵）
  A = softmax(S/√dₖ)  → 对每行做 softmax 归一化
  O = A·V      → O ∈ R^{n×dᵥ} （加权求和结果）

整个 Self-Attention = 三次矩阵乘法 + 一次 softmax
计算复杂度：O(n²·d)，n 为序列长度 → 长序列的瓶颈
```

### 8.3 反向传播 = 链式法则 + 矩阵转置

```
前向：h = Wx + b
      loss = L(h)

反向：
  ∂L/∂h = ... （由上游传入）
  ∂L/∂x = Wᵀ · (∂L/∂h)    ← 关键是 Wᵀ！
  ∂L/∂W = (∂L/∂h) · xᵀ
  ∂L/∂b = ∂L/∂h

注意：梯度传递需要 W 的转置
```

### 8.4 参数初始化中的线性代数

| 初始化方法 | 公式 | 线性代数依据 |
|-----------|------|------------|
| Xavier/Glorot | `W ~ N(0, 2/(n_in + n_out))` | 保证前向和反向方差一致 |
| He/Kaiming | `W ~ N(0, 2/n_in)` | 考虑 ReLU 导致的一半神经元失活 |
| 正交初始化 | `W = 正交矩阵` | 特征值均为 1，避免梯度放大/缩小 |

### 8.5 LoRA（低秩适应）的原理

```
全参数微调：  ΔW （d×d 个参数）

LoRA：       ΔW = A·B
             A ∈ R^{d×r}, B ∈ R^{r×d} （r << d）
             参数量：2dr << d²

理论依据：SVD 表明，微调时的权重更新 ΔW 具有低秩性（少数大奇异值主导）
```

### 9.2 基础运算示例（Apache Commons Math）

```java
import org.apache.commons.math3.linear.*;

// 1. 向量运算
RealVector v1 = new ArrayRealVector(new double[]{1.0, 2.0, 3.0});
RealVector v2 = new ArrayRealVector(new double[]{4.0, 5.0, 6.0});

double dotProduct = v1.dotProduct(v2);                       // 内积：32.0
double norm        = v1.getNorm();                           // L2 范数
double distance    = v1.getDistance(v2);                     // 欧氏距离
double cosine      = dotProduct / (v1.getNorm() * v2.getNorm()); // 余弦相似度

// 2. 矩阵乘法
RealMatrix a = new Array2DRowRealMatrix(new double[][]{
    {1, 2}, {3, 4}
});
RealMatrix b = new Array2DRowRealMatrix(new double[][]{
    {5, 6}, {7, 8}
});
RealMatrix c = a.multiply(b);  // [[19, 22], [43, 50]]

// 3. 矩阵求逆
RealMatrix aInv = new LUDecomposition(a).getSolver().getInverse();
```

### 9.3 深度学习中的矩阵运算（ND4J）

```java
import org.nd4j.linalg.api.ndarray.INDArray;
import org.nd4j.linalg.factory.Nd4j;

// 前向传播：h = ReLU(Wx + b)
INDArray input   = Nd4j.create(new float[]{0.5f, 0.3f, 0.2f}, new int[]{1, 3});
INDArray weights = Nd4j.randn(3, 64);   // Xavier 初始化
INDArray bias    = Nd4j.zeros(1, 64);
INDArray hidden  = input.mmul(weights).add(bias); // 矩阵乘法 + 偏置
// hidden = Nd4j.getExecutioner().exec(new ReLU(hidden)); // ReLU 激活

// 余弦相似度（批量计算 Embedding 相似度）
INDArray query    = Nd4j.randn(1, 768);    // 查询向量
INDArray docs     = Nd4j.randn(100, 768);  // 100 个文档向量

// query.mmul(docs.transpose()) → 1×100 的相似度得分矩阵
INDArray scores = query.mmul(docs.transpose()).div(
    query.norm2().mul(docs.norm2(1))
);
```

### 9.4 性能注意事项

| 场景 | 建议 |
|------|------|
| **大矩阵乘法** | 使用 ND4J + CUDA，切勿用三重循环 |
| **微小矩阵**（3×3, 4×4） | Apache Commons Math 即可，ND4J 的启动开销更大 |
| **稀疏矩阵** | EJML 或 ND4J 的 SparseNDArray，减少 90%+ 内存 |
| **向量相似度** | 提前归一化到单位向量，内积即余弦相似度 |
| **批量计算** | 将多个向量合并为矩阵，一次 `mmul` 代替循环 |

## 关键公式速记卡

| 公式 | 用途 |
|------|------|
| `cos_sim(A,B) = (A·B)/(‖A‖·‖B‖)` | Embedding 相似度检索 |
| `A = PDP⁻¹` | 特征分解 → PCA |
| `A = UΣVᵀ` | SVD → LoRA / 降维 |
