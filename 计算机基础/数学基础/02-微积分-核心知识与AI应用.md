## 2. 导数与微分

### 2.1 导数的定义

```
导数 = 函数在某点的瞬时变化率

f'(x₀) = lim_{h→0} [f(x₀ + h) - f(x₀)] / h

几何含义：函数曲线在 x₀ 处的切线斜率
物理含义：位置对时间的导数 = 速度
AI 含义：  loss 对参数的导数 = 参数应向哪个方向调整
```

### 2.2 基本求导公式

| 函数 | 导数 | AI 中的用途 |
|------|------|-----------|
| `c`（常数） | `0` | 偏置项求导 |
| `xⁿ` | `n·xⁿ⁻¹` | 多项式损失 |
| `eˣ` | `eˣ` | softmax 内部 |
| `ln(x)` | `1/x` | 交叉熵损失 |
| `1/x` | `-1/x²` | — |
| `sin(x)` | `cos(x)` | 位置编码 |
| `cos(x)` | `-sin(x)` | 位置编码 |

### 2.3 求导法则

| 法则 | 公式 | 说明 |
|------|------|------|
| **常数倍** | `(c·f)' = c·f'` | 线性性质 |
| **和差** | `(f ± g)' = f' ± g'` | 线性性质 |
| **乘积** | `(f·g)' = f'·g + f·g'` | — |
| **商** | `(f/g)' = (f'·g - f·g')/g²` | — |
| **链式法则** | `(f(g(x)))' = f'(g(x))·g'(x)` | **反向传播的理论基础** |

### 2.4 导数与函数极值

```
临界点：f'(x) = 0 的点
  → f'(x) 从正变负 = 极大值
  → f'(x) 从负变正 = 极小值
  → f'(x) 不变号      = 鞍点

AI 含义：loss 函数的极小值点 = 最优参数点
```

## 3. 偏导数与梯度

### 3.1 从单变量到多变量

```
单变量：f(x)     → f'(x) 是一个数（切线斜率）
多变量：f(x₁,...,xₙ) → ∇f 是一个向量（梯度）

偏导数：∂f/∂xᵢ = 保持其他变量不变时，f 对 xᵢ 的变化率
```

### 3.2 梯度的定义

```
梯度 ∇f = (∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂xₙ)

几何含义：梯度指向函数值增长最快的方向
        梯度的模 = 该方向上的最大增长率
关键推论：负梯度方向 = 函数值下降最快的方向
```

### 3.3 AI 中的梯度

```
神经网络的损失函数 L(W₁, W₂, ..., Wₙ)：
  参数：n 个权重/偏置（百万到千亿级）
  梯度：∇L 是一个 n 维向量
  更新：W_new = W_old - η·∇L
```

## 4. 链式法则

### 4.1 单变量链式法则

```
若 y = f(u) 且 u = g(x)，则：

dy/dx = (dy/du) · (du/dx)
      = f'(g(x)) · g'(x)
```

### 4.2 多变量链式法则

```
若 L = f(y₁, y₂, ..., yₘ) 且每个 yᵢ = gᵢ(x₁, ..., xₙ)，则：

∂L/∂xⱼ = Σᵢ (∂L/∂yᵢ) · (∂yᵢ/∂xⱼ)

写成矩阵形式：
∇ₓL = Jᵀ · ∇ᵧL

其中 J 是 Jacobian 矩阵：J_{ij} = ∂yᵢ/∂xⱼ
```

### 4.3 链式法则 = 反向传播

```text
前向传播（计算图）：
  x → W₁ → h₁ → ReLU → W₂ → h₂ → loss
  └── f₁ ──┘   └─ f₂ ─┘   └─ f₃ ─┘

反向传播（链式法则展开）：
  ∂loss/∂W₂ = (∂loss/∂h₂) · (∂h₂/∂W₂)             ← 链式法则第 3 层
  ∂loss/∂h₁ = (∂loss/∂h₂) · (∂h₂/∂h₁)             ← 链式法则第 2 层
  ∂loss/∂W₁ = (∂loss/∂h₁) · (∂h₁/∂W₁)             ← 链式法则第 1 层

核心：从后往前逐层应用链式法则，每层只需知道"上游梯度"和"本层局部梯度"
```

## 5. 梯度下降法

### 5.1 基本算法

```
输入：损失函数 L(θ)，学习率 η
输出：最优参数 θ*

while 未收敛:
    计算梯度：g = ∇L(θ)
    更新参数：θ ← θ - η·g
```

### 5.2 常见变体

| 变体 | 公式 | 特点 |
|------|------|------|
| **SGD** | `θ ← θ - η·g` | 每次一个样本，有噪声但快 |
| **Mini-batch SGD** | `θ ← θ - η·(1/|B|)·Σ gᵢ` | 折中方案，最常用 |
| **Momentum** | `v ← β·v - η·g; θ ← θ + v` | 积累历史梯度，加速收敛 |
| **Adam** | 自适应学习率 + 动量 | **当前最主流的优化器** |
| **AdamW** | Adam + 权重衰减解耦 | LLM 训练标配 |

### 5.3 学习率的影响

| 学习率 | 效果 | 诊断 |
|--------|------|------|
| **太小** | 收敛极慢，可能困在局部极小值 | loss 下降如蜗牛 |
| **合适** | 稳定收敛到最优 | loss 平滑下降 |
| **太大** | 震荡不收敛 | loss 剧烈抖动 |
| **极大** | 发散 | loss → NaN |

```
关键公式（学习率的上界——凸函数）：
  η < 2/L ，其中 L 是损失函数的 Lipschitz 常数（梯度的最大变化率）
  若 η > 2/L，梯度下降必然发散
```

### 5.4 为什么梯度下降有效（泰勒展开视角）

```
L(θ - η·g) ≈ L(θ) - η·gᵀ·g + (η²/2)·gᵀ·H·g
           ≈ L(θ) - η·‖g‖²                            （一阶近似）
           < L(θ)                                       （只要 η 足够小）

因为减去正项 η·‖g‖²，所以每步 loss 一定减小
```

## 6. 泰勒展开

### 6.1 定义

```
一阶泰勒：f(x) ≈ f(a) + f'(a)(x-a)                     （线性近似）
二阶泰勒：f(x) ≈ f(a) + f'(a)(x-a) + ½f''(a)(x-a)²     （二次近似）
n 阶泰勒：f(x) ≈ Σₖ f⁽ᵏ⁾(a)(x-a)ᵏ / k!                （高阶近似）
```

### 6.2 AI 中的泰勒展开

| 应用 | 说明 |
|------|------|
| **梯度下降的合理性** | 一阶泰勒 → 最速下降方向 |
| **牛顿法优化** | 二阶泰勒 → 同时考虑曲率，收敛更快 |
| **损失函数光滑性** | 若 f'' 有界，梯度下降收敛有保证 |
| **激活函数近似** | 用多项式近似复杂激活函数 |
| **量化感知训练** | 用泰勒展开估计量化误差 |

## 7. 积分基础

### 7.1 定积分

```
定积分 = 曲线下面积

∫ₐᵇ f(x)dx = lim_{n→∞} Σᵢ f(xᵢ*)·Δx

微积分基本定理：
  ∫ₐᵇ f(x)dx = F(b) - F(a)，其中 F'(x) = f(x)
```

### 7.2 AI 中积分的角色

| 场景 | 积分的作用 |
|------|-----------|
| **连续概率分布** | `P(a≤X≤b) = ∫ₐᵇ f(x)dx`——正态分布的累积概率 |
| **期望值计算** | `E[X] = ∫ x·f(x)dx`——连续型随机变量的期望 |
| **信息熵** | `H(X) = -∫ f(x)·ln f(x)dx`——连续分布的熵 |
| **VAE 中的 KL 散度** | `KL(P‖Q) = ∫ p(x)·ln(p(x)/q(x))dx` |
| **梯度积分** | 神经 ODE——用积分替代离散层 |

## 8. AI 大模型中的微积分

### 8.1 激活函数及其导数

| 激活函数 | f(x) | f'(x) | 导数特点 |
|----------|------|-------|---------|
| **Sigmoid** | `1/(1+e^{-x})` | `f(x)(1-f(x))` | 最大值 0.25 → 梯度消失 |
| **Tanh** | `(eˣ-e^{-x})/(eˣ+e^{-x})` | `1-f(x)²` | 最大值 1.0 → 仍可能梯度消失 |
| **ReLU** | `max(0, x)` | `0 (x<0), 1 (x>0)` | x<0 时梯度为 0 → 神经元死亡 |
| **GELU** | `x·Φ(x)` | 光滑近似 | **Transformer 标配**，处处可导 |
| **SiLU/Swish** | `x·σ(x)` | `σ(x)+x·σ(x)(1-σ(x))` | LLM 常用 |

```
为什么 ReLU 替代了 Sigmoid？

Sigmoid 梯度消失：
  深层网络中，Sigmoid 的导数最大值仅 0.25
  → 经过 10 层：0.25¹⁰ ≈ 10⁻⁶ → 梯度几乎为零

ReLU 解决：
  正半轴导数恒为 1 → 深层传递不衰减
  但负半轴导数为 0 → 引入 LeakyReLU / GELU
```

### 8.2 损失函数的梯度分析

| 损失函数 | 公式 | 梯度 | 特点 |
|----------|------|------|------|
| **MSE** | `(y-ŷ)²` | `2(ŷ-y)` | 回归任务，对异常值敏感 |
| **交叉熵（二分类）** | `-[y·ln(ŷ)+(1-y)·ln(1-ŷ)]` | `(ŷ-y)/(ŷ(1-ŷ))` | 分类任务，梯度更平滑 |
| **交叉熵（多分类）** | `-Σ yᵢ·ln(ŷᵢ)` | `ŷ - y`（配合 softmax） | **LLM 预训练标配** |

```
关键洞察：softmax + 交叉熵 → 梯度 = ŷ - y

这个简洁的梯度形式使训练极其高效，是分类问题的标准组合。
```

### 8.3 反向传播的完整推导（三层 MLP 示例）

```text
网络结构：x → Linear₁ → ReLU → Linear₂ → softmax → cross_entropy → L

前向（记录中间值）：
  z₁ = W₁·x + b₁
  a₁ = ReLU(z₁)          ← 记忆 mask₁ = (z₁ > 0)
  z₂ = W₂·a₁ + b₂
  ŷ  = softmax(z₂)
  L  = -Σ y·ln(ŷ)

反向（逐层链式法则）：
  ∂L/∂z₂ = ŷ - y                                     ← softmax + 交叉熵的简洁梯度
  ∂L/∂W₂ = (∂L/∂z₂) · a₁ᵀ                           ← 外层梯度 × 本层输入的转置
  ∂L/∂b₂ = ∂L/∂z₂
  ∂L/∂a₁ = W₂ᵀ · (∂L/∂z₂)                           ← 权重矩阵的转置！
  ∂L/∂z₁ = (∂L/∂a₁) ⊙ mask₁                          ← ReLU 反向：通过 mask 过滤
  ∂L/∂W₁ = (∂L/∂z₁) · xᵀ
  ∂L/∂b₁ = ∂L/∂z₁
```

### 8.4 梯度消失与梯度爆炸

```
问题根源（以深层全连接网络为例）：

  ∂L/∂W₁ = ∂L/∂hₙ · (Πₖ Wₖ) · x

  若 ‖Wₖ‖ < 1   → 连续相乘趋近 0    → 梯度消失（深层参数不更新）
  若 ‖Wₖ‖ > 1   → 连续相乘爆炸       → 梯度爆炸（loss → NaN）

解决方案：
  1. 残差连接：h = x + F(x) → 梯度至少为 1（短路路径）
  2. LayerNorm：稳定每层的激活值分布
  3. 梯度裁剪：‖g‖ > threshold → g ← g · threshold/‖g‖
  4. 合理的初始化：Xavier / He
```

## 9. Java 中的自动微分

### 9.1 DJL 自动微分示例

```java
import ai.djl.ndarray.NDArray;
import ai.djl.ndarray.NDManager;
import ai.djl.training.GradientCollector;

try (NDManager manager = NDManager.newBaseManager()) {
    // 创建参数（需要梯度）
    NDArray w = manager.create(new float[]{0.5f, -0.3f, 0.8f});
    w.setRequiresGradient(true);

    NDArray x = manager.create(new float[]{1.0f, 2.0f, 3.0f});

    // 前向传播（在 GradientCollector 中记录计算图）
    try (GradientCollector gc = new GradientCollector()) {
        NDArray z = w.dot(x);      // z = w·x
        NDArray y = z.getNDArrayInternal().sigmoid(); // y = σ(z)
        NDArray loss = y.sub(1.0f).square();          // L = (y-1)²

        gc.backward(loss);  // 链式法则自动计算所有梯度
    }

    NDArray grad = w.getGradient();  // ∂L/∂w 已自动计算
    System.out.println("梯度: " + grad);
}
```

### 9.2 手动实现标量自动微分

```java
// 计算图节点（简化版）
class Value {
    double data;
    double grad = 0;
    Runnable backward;

    Value(double data) { this.data = data; }

    Value add(Value other) {
        Value out = new Value(this.data + other.data);
        out.backward = () -> { this.grad += out.grad; other.grad += out.grad; };
        return out;
    }

    Value mul(Value other) {
        Value out = new Value(this.data * other.data);
        out.backward = () -> {
            this.grad += other.data * out.grad;   // ∂(a·b)/∂a = b
            other.grad += this.data * out.grad;   // ∂(a·b)/∂b = a
        };
        return out;
    }

    Value relu() {
        Value out = new Value(Math.max(0, this.data));
        out.backward = () -> { if (this.data > 0) this.grad += out.grad; };
        return out;
    }
}
```
