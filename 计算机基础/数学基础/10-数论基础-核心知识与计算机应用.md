## 2. 整除性与模运算

### 2.1 基本概念

```
a | b  表示 a 整除 b（b ÷ a 余数为 0）
a ∤ b  表示 a 不能整除 b

基本性质：
  若 a|b 且 a|c，则 a|(b+c)，a|(b-c)，a|(bc)

带余除法（欧几里得除法）：
  对任意整数 a, b (b ≠ 0)，存在唯一的 q, r 使得：
  a = bq + r，其中 0 ≤ r < |b|
  
  q = 商，r = 余数
```

### 2.2 最大公约数 (GCD)

```
定义：gcd(a, b) = 同时整除 a 和 b 的最大正整数

性质：
  gcd(a, 0) = |a|
  gcd(a, b) = gcd(b, a mod b)    ← 欧几里得算法的关键
  gcd(a, b) = gcd(a-b, b)
```

### 2.3 欧几里得算法（辗转相除法）

```text
算法：求 gcd(a, b)

while b ≠ 0:
    r = a mod b
    a = b
    b = r
return a

时间复杂度：O(log min(a, b))——极快！

示例：gcd(48, 18)
  48 = 18 × 2 + 12
  18 = 12 × 1 + 6
  12 = 6 × 2 + 0
  → gcd(48, 18) = 6
```

### 2.4 扩展欧几里得算法（Bézout 定理）

```
定理：存在整数 x, y 使得 ax + by = gcd(a, b)

算法（扩展欧几里得）：
  在求 gcd 的同时，回代求出 x 和 y

核心应用：
  ① 求模逆元：若 gcd(a, n) = 1，则 a^{-1} mod n = x
     （因为 ax + ny = 1 → ax ≡ 1 (mod n)）

  ② RSA 私钥计算：d = e^{-1} mod φ(n)
```

## 3. 素数

### 3.1 基本性质

```
定义：大于 1 且有且仅有 1 和自身两个正因子的整数

素数有无穷多个（欧几里得证明）：
  假设只有有限个素数 p₁, p₂, ..., pₙ
  构造 N = p₁·p₂·...·pₙ + 1
  N 不能被任何已知素数整除 → 要么 N 是新素数，要么有新的素因子
  → 矛盾 → 素数无穷多个
```

### 3.2 素数判定

| 方法 | 复杂度 | 适用 |
|------|--------|------|
| 试除法 | `O(√n)` | n ≤ 10¹² |
| Miller-Rabin | `O(k·log³n)` | **通用，概率正确** |
| AKS 算法 | `O(log¹²n)` | 理论价值（第一个多项式确定性算法） |

### 3.3 素数分布

```
素数定理：π(x) ~ x / ln(x)
  π(x) = 不超过 x 的素数个数

近似：
  x = 10⁶   → π(x) ≈ 78498
  x = 10⁹   → π(x) ≈ 5×10⁷（约 5%）
  x = 2¹⁰²⁴ → π(x) ≈ 2¹⁰²⁴ / (1024·ln2) ≈ 10³⁰⁵

→ RSA 用 1024-bit 素数，搜索空间巨大，暴力破解不可行
```

### 3.4 素数在计算机中的应用

```
① 哈希表：表长取素数 → 减少冲突模式
② 密码学：RSA/DH/ECC 全部依赖素数
③ PRNG：素数模长产生更长周期
④ 哈希函数：Merkle-Damgård 结构中常用素数模
```

## 4. 同余与模算术

### 4.1 基本定义

```
a ≡ b (mod m)  表示 m | (a - b)，即 a 和 b 除以 m 的余数相同

性质（同余的可运算性）：
  若 a ≡ b (mod m), c ≡ d (mod m)，则：
    a + c ≡ b + d (mod m)
    a - c ≡ b - d (mod m)
    ac ≡ bd (mod m)
```

### 4.2 模逆元

```
定义：若 a·x ≡ 1 (mod m)，则 x 称为 a 的模逆元，记作 a^{-1} mod m

存在条件：gcd(a, m) = 1（a 和 m 互素）

计算：扩展欧几里得算法求 ax + my = 1 → x 即模逆元
```

### 4.3 中国剩余定理（CRT）

```
问题：求解同余方程组
  x ≡ a₁ (mod m₁)
  x ≡ a₂ (mod m₂)
  ...
  x ≡ aₖ (mod mₖ)
  其中 mᵢ 两两互素

解：
  M = m₁·m₂·...·mₖ
  Mᵢ = M / mᵢ
  yᵢ = Mᵢ^{-1} mod mᵢ
  x = Σ aᵢ·Mᵢ·yᵢ mod M

应用：RSA 解密加速（CRT 加速 4×）
```

## 5. 欧拉定理与费马小定理

### 5.1 欧拉函数 φ(n)

```
定义：φ(n) = 小于 n 且与 n 互素的正整数个数

性质：
  φ(p) = p-1                         （p 为素数）
  φ(pᵏ) = pᵏ - pᵏ⁻¹                 （p 为素数）
  φ(ab) = φ(a)·φ(b)                   （若 gcd(a,b)=1，积性函数）
  φ(pq) = (p-1)(q-1)                  （p,q 均为素数，RSA 核心公式！）
```

### 5.2 欧拉定理

```
若 gcd(a, n) = 1，则：
  a^{φ(n)} ≡ 1 (mod n)

这是 RSA 加密解密的数学基石。
```

### 5.3 费马小定理

```
费马小定理（欧拉定理的特例，n 为素数 p）：
  a^{p-1} ≡ 1 (mod p)，其中 p ∤ a

等价形式：
  a^p ≡ a (mod p)

应用：
  ① 快速计算 a^b mod m（指数取模 φ(m)）
  ② 素数测试（Fermat 素性检验）
  ③ 模逆元：a^{-1} ≡ a^{p-2} (mod p)（仅当 p 是素数）
```

## 6. RSA 加密的数学原理

### 6.1 密钥生成

```
① 选择两个大素数 p, q
② n = p × q
③ φ(n) = (p-1)(q-1)
④ 选择公钥 e：1 < e < φ(n)，且 gcd(e, φ(n)) = 1
⑤ 计算私钥 d：d ≡ e^{-1} (mod φ(n))  ← 扩展欧几里得

公钥：(n, e)
私钥：(n, d)
```

### 6.2 加密与解密

```
加密：c = m^e mod n
解密：m = c^d mod n

正确性验证：
  c^d ≡ (m^e)^d ≡ m^{ed} ≡ m^{k·φ(n)+1} ≡ m·(m^{φ(n)})^k ≡ m·1^k ≡ m (mod n)
                                                    ↑ 欧拉定理
```

### 6.3 安全性基础

```
RSA 的安全性假设：大整数分解的困难性

已知 n = p × q，无法在合理时间内求出 p, q
  1024-bit n：最好的算法需 ≈ 2⁸⁰ 步（约合数百年计算）

量子威胁（Shor 算法）：
  量子计算机可在多项式时间内分解大整数 → RSA 将被破解
  → 后量子密码（PQC）正在标准化中
```

## 7. 数论在计算机中的其他应用

### 7.1 Diffie-Hellman 密钥交换

```
公开参数：大素数 p，模 p 的生成元 g

Alice：选私钥 a → 发送 A = g^a mod p
Bob：  选私钥 b → 发送 B = g^b mod p

共享密钥：K = B^a mod p = A^b mod p = g^{ab} mod p

安全性依赖：离散对数问题的困难性
  → 已知 g, g^a mod p，求 a 在计算上不可行
```

### 7.2 哈希表中的素数

```java
// HashMap 的容量始终为 2 的幂（便于位运算取模）
// 但如果你自己设计哈希表，用素数做表长：

// 为什么素数好？
// → 减少"键的规律"与"表长"产生共振，降低冲突
// → 坏例子：表长=8（2³），键都是 8 的倍数 → 全映射到 0
// → 素数表长没有这种问题

int primeCapacity(int minCapacity) {
    int[] primes = {53, 97, 193, 389, 769, 1543, 3079, 6151, 12289, 24593};
    for (int p : primes) if (p >= minCapacity) return p;
    return minCapacity; // fallback
}
```

### 7.3 校验和与哈希

```
CRC（循环冗余校验）：
  基于模 2 上的多项式除法（有限域 GF(2) 上的运算）
  校验位 = 数据 % 生成多项式

UUID / 随机数：
  SecureRandom 使用基于数论的 CSPRNG
```

## 8. Java 实现

### 8.1 欧几里得与扩展欧几里得

```java
import java.math.BigInteger;

public class NumberTheory {

    // 欧几里得算法：gcd(a, b)
    public static long gcd(long a, long b) {
        while (b != 0) {
            long r = a % b;
            a = b;
            b = r;
        }
        return a;
    }

    // 扩展欧几里得：返回 {gcd, x, y} 使 ax + by = gcd
    public static long[] extendedGcd(long a, long b) {
        if (b == 0) return new long[]{a, 1, 0};
        long[] result = extendedGcd(b, a % b);
        long gcd = result[0];
        long x = result[2];
        long y = result[1] - (a / b) * result[2];
        return new long[]{gcd, x, y};
    }

    // 模逆元：a^{-1} mod m（需 gcd(a,m)=1）
    public static long modInverse(long a, long m) {
        long[] result = extendedGcd(a, m);
        if (result[0] != 1) throw new ArithmeticException("不存在模逆元");
        return ((result[1] % m) + m) % m; // 确保正数
    }

    // 快速幂取模：base^exp mod mod
    public static long modPow(long base, long exp, long mod) {
        long result = 1;
        base = base % mod;
        while (exp > 0) {
            if ((exp & 1) == 1) result = (result * base) % mod;
            base = (base * base) % mod;
            exp >>= 1;
        }
        return result;
    }

    // 费马素性检验（概率算法）
    public static boolean isProbablePrime(long n, int iterations) {
        if (n < 2) return false;
        if (n == 2) return true;
        if (n % 2 == 0) return false;

        // 费马检验：若 a^{n-1} ≡ 1 (mod n) 对所有 a 成立，n 很可能是素数
        for (int i = 0; i < iterations; i++) {
            long a = 2 + (long)(Math.random() * (n - 3));
            if (gcd(a, n) != 1) return false;
            if (modPow(a, n - 1, n) != 1) return false;
        }
        return true;
    }
}
```

### 8.2 BigInteger 的密码学操作

```java
// BigInteger 内置了大多数数论操作，生产环境直接使用
BigInteger p = BigInteger.probablePrime(1024, new SecureRandom()); // 生成 1024-bit 素数
BigInteger q = BigInteger.probablePrime(1024, new SecureRandom());

// RSA 密钥生成
BigInteger n = p.multiply(q);
BigInteger phi = p.subtract(BigInteger.ONE).multiply(q.subtract(BigInteger.ONE));
BigInteger e = BigInteger.valueOf(65537);  // 常用公钥指数
BigInteger d = e.modInverse(phi);           // 私钥 = e^{-1} mod φ(n)

// 加密
BigInteger message = new BigInteger("123456789");
BigInteger cipher = message.modPow(e, n);

// 解密
BigInteger decrypted = cipher.modPow(d, n);  // ≡ message
assert decrypted.equals(message);

// CRT 加速解密（4× 加速）
BigInteger dp = d.mod(p.subtract(BigInteger.ONE));
BigInteger dq = d.mod(q.subtract(BigInteger.ONE));
BigInteger qInv = q.modInverse(p);

BigInteger m1 = cipher.modPow(dp, p);
BigInteger m2 = cipher.modPow(dq, q);
BigInteger h = qInv.multiply(m1.subtract(m2)).mod(p);
BigInteger m = m2.add(h.multiply(q));  // CRT 合并结果
```
