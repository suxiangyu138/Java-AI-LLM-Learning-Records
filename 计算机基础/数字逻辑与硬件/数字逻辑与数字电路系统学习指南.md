## 1. 数制与编码

### 1.1 进制转换

| 进制 | 基数 | 数码 | 后缀/前缀 |
|------|------|------|-----------|
| 二进制 | 2 | 0,1 | `0b` / `0B`（Java 7+） |
| 八进制 | 8 | 0-7 | `0` 前缀 |
| 十进制 | 10 | 0-9 | 默认 |
| 十六进制 | 16 | 0-9, A-F | `0x` / `0X` |

```java
int binary  = 0b1010;    // 10
int octal   = 012;       // 10（0 前缀，易错！）
int hexa    = 0xFF;      // 255
```

### 1.2 二进制补码

**为什么用补码？** 使加法器可以处理减法，简化硬件设计。

**补码计算：** 按位取反 + 1

```
+5 的 8 位二进制：0000 0101
-5 的 8 位补码：  1111 1011  （取反 1111 1010，+1 得 1111 1011）
```

**验证：** `5 + (-5) = 0000 0101 + 1111 1011 = 1 0000 0000` → 溢出位丢弃，得 `0000 0000` = 0 ✓

**Java 中溢出与回绕：**
```java
int max = Integer.MAX_VALUE;    // 2147483647
int overflow = max + 1;         // -2147483648 （补码回绕）
```

### 1.3 常用编码

| 编码 | 用途 | 特点 |
|------|------|------|
| BCD 码 | 十进制显示 | 4 位二进制表示 1 位十进制 |
| ASCII | 英文字符 | 7 位，128 个字符 |
| Unicode/UTF-8 | 多语言字符 | 变长编码 |
| Gray 码 | 旋转编码器 | 相邻码值仅 1 位不同 |

## 2. 布尔代数与逻辑门

### 2.1 基本逻辑门

| 门 | 符号 | 真值表 | 布尔表达式 |
|------|------|--------|------------|
| NOT | ╲ | 0→1, 1→0 | F = A̅ |
| AND | | 00→0, 01→0, 10→0, 11→1 | F = A·B |
| OR | | 00→0, 01→1, 10→1, 11→1 | F = A+B |
| XOR | | 00→0, 01→1, 10→1, 11→0 | F = A⊕B |
| NAND | | AND 结果取反 | F = A·B̅ |
| NOR | | OR 结果取反 | F = A+B̅ |

**NAND 或 NOR 是"完备门"**——单用一种即可实现任意逻辑函数。实际芯片中，NAND/NOR 比 AND/OR 更节省晶体管。

### 2.2 布尔代数基本定律

```
交换律：A + B = B + A             A · B = B · A
结合律：(A + B) + C = A + (B + C)
分配律：A·(B + C) = A·B + A·C    A + B·C = (A+B)(A+C)
吸收律：A + A·B = A              A·(A + B) = A
德摩根律：A̅·̅B̅ = A̅ + B̅            A̅+̅B̅ = A̅ · B̅
```

### 2.3 从真值表到逻辑表达式

**最小项之和（SOP）：** 将所有输出为 1 的行的最小项相或
**最大项之积（POS）：** 将所有输出为 0 的行的最大项相与

**卡诺图化简（K-Map）：** 2-6 变量逻辑函数的图形化化简方法。

## 3. 组合逻辑电路

### 3.1 常用组合逻辑器件

| 器件 | 功能 | 应用 |
|------|------|------|
| **编码器（Encoder）** | 2ⁿ→n 线（如键盘输入→二进制） | 输入设备编码 |
| **译码器（Decoder）** | n→2ⁿ 线（如二进制→片选信号） | 地址译码、指令译码 |
| **多路选择器（MUX）** | 多路输入选一路输出 | 数据通路选择 |
| **加法器（Adder）** | 半加器(无进位)/全加器(有进位) | ALU 核心部件 |
| **比较器** | 比较两数大小 | 条件分支判断 |

### 3.2 全加器结构

```
半加器：
  Sum = A ⊕ B
  Cout = A · B

全加器（考虑进位输入 Cin）：
  Sum  = A ⊕ B ⊕ Cin
  Cout = A·B + (A⊕B)·Cin
       = A·B + A·Cin + B·Cin    （多数表决器：三个输入中 ≥2 个为 1 则进位）
```

**行波进位加法器 vs 超前进位加法器：**
- 行波进位：结构简单，进位逐级传递，延迟大（O(n)）
- 超前进位：并行计算进位，速度快（O(log n)），现代 CPU 使用

### 3.3 ALU（算术逻辑单元）

```
         ┌────────────────┐
    操作码 ──►│                  │
         │    ALU           │── 结果
    A    ──►│                  │── 标志位（零/进位/溢出/符号）
    B    ──►│                  │
         └────────────────┘
```

**ALU 支持的操作：** 加减、AND/OR/XOR/NOT、移位、比较。

## 4. 时序逻辑电路

### 4.1 锁存器 vs 触发器

| | 锁存器（Latch） | 触发器（Flip-Flop） |
|------|----------------|---------------------|
| 触发方式 | 电平触发（如 CLK=1 时透明） | **边沿触发**（上升沿或下降沿） |
| 常见类型 | SR 锁存器、D 锁存器 | D 触发器、JK 触发器、T 触发器 |
| 用途 | 异步电路 | **同步电路（主流）** |

### 4.2 D 触发器（最常用）

**特性方程：** Q(t+1) = D  （时钟边沿到来时，输出 = 输入）

**带使能的 D 触发器：**
- EN=1：正常采样 D 输入
- EN=0：保持当前值

N 个 D 触发器组成 N 位寄存器。

### 4.3 寄存器与计数器

**寄存器：** N 个触发器的集合，存储 N 位二进制数据。

**移位寄存器：** 每个时钟周期数据移动一位（串入串出/串入并出/并入串出）。

**计数器：**
- **同步计数器：** 所有触发器共用一个时钟，速度快
- **异步计数器（行波计数）：** 逐级触发，结构简单但累积延迟

```verilog
// 4 位同步计数器（Verilog 示例）
always @(posedge clk) begin
    if (reset)  count <= 4'b0000;
    else        count <= count + 1;
end
```

### 4.4 有限状态机（FSM）

**Moore 型：** 输出仅取决于当前状态
**Mealy 型：** 输出取决于当前状态 + 当前输入

**状态编码：**
- 二进制编码：log₂(N) 个触发器，最省硬件
- 独热编码（One-Hot）：N 个触发器，每位代表一个状态，组合逻辑简单

**FSM 设计步骤：**
1. 明确输入/输出
2. 画状态转换图
3. 编码状态
4. 推导次态方程和输出方程
5. 画出电路

## 5. 存储器基础

### 5.1 存储器分类

```
存储器
├── RAM（随机存取，断电丢失）
│   ├── SRAM（静态）：6 个晶体管/位，快，贵，用作 Cache
│   └── DRAM（动态）：1 个晶体管 + 1 个电容/位，慢，需刷新，用作主存
└── ROM（只读）
    ├── PROM：一次性可编程
    ├── EPROM：紫外线擦除
    ├── EEPROM：电擦除
    └── Flash：块擦除（SSD、U 盘）
```

### 5.2 存储器扩展

**位扩展：** 增加数据线宽度（如 2 片 4 位 RAM → 8 位 RAM）
**字扩展：** 增加地址空间（如 2 片 1K RAM → 2K RAM，用译码器片选）

### 5.3 SRAM vs DRAM 深入对比

| | SRAM | DRAM |
|------|------|------|
| 存储单元 | 6 个晶体管（双稳态触发器） | 1 个晶体管 + 1 个电容 |
| 刷新 | 不需要 | 需要（~64ms 刷新一次） |
| 速度 | ~1-5ns | ~50-100ns |
| 密度 | 低 | 高（6 倍于 SRAM） |
| 功耗 | 低（待机） | 需刷新功耗 |
| 成本 | 高 | 低 |
| 应用 | CPU 缓存（L1/L2/L3） | 主存（DDR4/DDR5） |

## 6. 后端开发关联

### 6.1 位运算与布尔代数

数字逻辑中研究的布尔代数和逻辑门，在 Java 编程中直接体现为位运算：

```java
// 位运算常见应用
int flag   = 0b1010;
int mask   = 0b0100;
int result = flag & mask;         // 测试某位是否为 1
int enable = flag | mask;         // 设置某位为 1
int disable = flag & ~mask;       // 清除某位为 0
int toggle  = flag ^ mask;        // 翻转某位

// 权限模型（经典状态位应用）
int PERM_READ  = 1 << 0;  // 0001
int PERM_WRITE = 1 << 1;  // 0010
int PERM_EXEC  = 1 << 2;  // 0100
int perm = PERM_READ | PERM_WRITE;  // 0011
if ((perm & PERM_READ) != 0) { /* 允许读 */ }
```

### 6.2 加法器与 ALU

Java 中 `+` 运算符最终由 CPU ALU 的全加器电路执行。理解底层有助于理解整数溢出行为。

### 6.3 触发性与时序

时序逻辑中"时钟边沿触发"的思想，与 Java 中同步机制有概念上的对应：
- 时钟边沿 → 确保状态在确定的时刻更新
- `synchronized` 块 → 确保共享变量在确定的时刻（锁获取/释放）可见

### 6.4 Verilog/HDL 与硬件描述

虽然 Java 后端不需要写 Verilog，但了解硬件描述语言有助于理解 FPGA/ASIC 如何实现算法硬件加速（如 AI 芯片中的矩阵运算加速器）。

```verilog
// 简单 ALU 的 Verilog 描述（概念示例）
module alu(input [3:0] a, b, input [2:0] op,
           output reg [3:0] result);
    always @(*) begin
        case (op)
            3'b000: result = a + b;
            3'b001: result = a - b;
            3'b010: result = a & b;
            3'b011: result = a | b;
            default: result = 0;
        endcase
    end
endmodule
```
