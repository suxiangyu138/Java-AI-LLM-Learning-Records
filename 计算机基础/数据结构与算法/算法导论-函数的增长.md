## 一、渐近符号

### 1. Θ 记号（紧确界）

| 维度 | 说明 |
|------|------|
| **定义** | 存在正常数 c₁、c₂、n₀，当 n ≥ n₀ 时，c₁g(n) ≤ f(n) ≤ c₂g(n) |
| **后端意义** | 算法运行时间的精确上界与下界 |
| **示例** | 归并排序 Θ(n log n)、HashMap 查找 Θ(1) |

### 2. O 记号（上界）

| 维度 | 说明 |
|------|------|
| **定义** | 存在正常数 c、n₀，当 n ≥ n₀ 时，f(n) ≤ cg(n) |
| **后端意义** | 算法最坏情况运行时间上限 |
| **示例** | 快速排序最坏 O(n²)、堆排序 O(n log n) |

### 3. Ω 记号（下界）

| 维度 | 说明 |
|------|------|
| **定义** | 存在正常数 c、n₀，当 n ≥ n₀ 时，f(n) ≥ cg(n) |
| **后端意义** | 算法最好情况运行时间下限 |
| **示例** | 插入排序最好 Ω(n)、排序算法下界 Ω(n log n) |

### 4. o 记号（非紧上界）

| 维度 | 说明 |
|------|------|
| **定义** | 对任意 c > 0，存在 n₀，当 n ≥ n₀ 时，f(n) < cg(n) |
| **后端意义** | 算法增长速度严格低于 g(n) |
| **示例** | log n = o(n)、n = o(n²) |

### 5. ω 记号（非紧下界）

| 维度 | 说明 |
|------|------|
| **定义** | 对任意 c > 0，存在 n₀，当 n ≥ n₀ 时，f(n) > cg(n) |
| **后端意义** | 算法增长速度严格高于 g(n) |
| **示例** | n² = ω(n)、n log n = ω(n) |

## 二、常见函数增长阶

| 增长阶 | 名称 | Java 示例 | 后端建议 |
|--------|------|-----------|----------|
| O(1) | 常数阶 | HashMap 查找、ArrayList 随机访问 | ✅ 首选 |
| O(log n) | 对数阶 | 二分查找、红黑树操作、堆插入 | ✅ 优秀 |
| O(n) | 线性阶 | 数组遍历、链表操作、线性查找 | ✅ 可接受 |
| O(n log n) | 线性对数阶 | 归并排序、快速排序、堆排序 | ✅ 常用 |
| O(n²) | 平方阶 | 插入排序、选择排序、冒泡排序 | ⚠️ 慎用 |
| O(2ⁿ) | 指数阶 | 回溯算法、暴力枚举 | ❌ 禁用 |

## 三、函数增长的运算规则

### 1. 加法规则

```
f(n) + g(n) = O(max(f(n), g(n)))
```

**示例**：O(n) + O(log n) = O(n)

### 2. 乘法规则

```
f(n) * g(n) = O(f(n) * g(n))
```

**示例**：O(n) * O(log n) = O(n log n)

### 3. 取整规则

```
⌊f(n)⌋ = Θ(f(n))，⌈f(n)⌉ = Θ(f(n))
```

**示例**：⌊n/2⌋ = Θ(n)

## 五、函数增长对后端开发的指导意义

### 1. 算法选型

| 场景 | 推荐增长阶 | 原因 |
|------|------------|------|
| 大数据场景 | O(n log n)、O(log n) | 保证可扩展性 |
| 高并发场景 | 避免 O(n²)、指数阶 | 防止性能瓶颈 |
| 内存受限 | O(1) 空间（原地算法） | 节省内存 |

### 2. 性能优化

- 识别 O(n²) 瓶颈（如嵌套循环），替换为 O(n log n) 算法
- 用哈希表（O(1)）替代线性查找（O(n)）
- 用堆（O(log n)）解决 TopK 问题

### 3. 系统设计

| 场景 | 增长阶 | 算法/结构 |
|------|--------|-----------|
| 缓存设计 | O(1) | LRU、HashMap |
| 分布式路由 | O(log n) | Dijkstra 最短路径 |
| 任务调度 | O(V + E) | 拓扑排序 |

### 4. 复杂度评估

- 预估系统吞吐量：O(1) >> O(log n) >> O(n) >> O(n log n)
- 评估扩容影响：ArrayList 摊还 O(1)，resize 单次 O(n)

## 六、函数增长的常见误区

> ⚠️ 以下误区是后端开发中容易忽略的关键点：

| 误区 | 正确理解 |
|------|----------|
| 忽略常数项 | O(100n) = O(n)，但实际运行时间有差异 |
| 混淆最坏与平均 | 快排平均 O(n log n)，最坏 O(n²) |
| 忽视摊还复杂度 | ArrayList 单次 add 最坏 O(n)，摊还 O(1) |
| 过度优化 | 小规模数据 O(n²) 可能优于 O(n log n) |

---

## 七、总结

> 1. 函数增长是算法性能的核心指标，决定系统可扩展性
> 2. 渐近符号（Θ/O/Ω）是算法分析的基础工具
> 3. 增长阶排序：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ)
> 4. 后端开发优先选择低增长阶算法，避免性能瓶颈
> 5. 函数增长指导集合选型、算法优化、系统设计全场景
