## 一、基础概念

| 维度 | 分类 | 说明 |
|------|------|------|
| **逻辑结构** | 线性结构 | 一对一关系（数组、链表、栈、队列） |
| | 树形结构 | 一对多关系（二叉树、堆、B+树） |
| | 图形结构 | 多对多关系（有向图、无向图） |
| | 集合结构 | 元素间无特定关系（Set） |
| **存储结构** | 顺序存储 | 连续内存空间（数组） |
| | 链式存储 | 离散内存通过指针链接（链表） |
| | 索引存储 | 通过索引表定位数据 |
| | 散列存储 | 通过哈希函数映射位置 |
| **算法衡量** | 时间复杂度 | 执行时间与数据规模的关系 |
| | 空间复杂度 | 内存占用与数据规模的关系 |
| | 稳定性 | 相等元素排序前后的相对顺序是否不变 |
| | 正确性 | 算法是否产生正确结果 |
| | 可读性 | 代码是否易于理解和维护 |

## 二、线性结构

### 1. 数组

| 特性 | 说明 |
|------|------|
| **优点** | 连续内存、随机访问 O(1) |
| **缺点** | 增删效率低 O(n) |
| **核心场景** | 二分查找、滑动窗口、双指针 |

### 2. 链表

| 特性 | 说明 |
|------|------|
| **优点** | 离散存储、增删高效 O(1) |
| **缺点** | 顺序访问、随机访问 O(n) |
| **分类** | 单链表、双向链表、循环链表 |
| **高频考点** | 反转链表、快慢指针（找中点/环）、合并链表 |

### 3. 栈（LIFO）

**特点：** 先进后出，仅在栈顶操作。

```
应用场景：
├── 括号匹配
├── 表达式求值
├── 函数递归（JVM 栈帧）
└── 单调栈（Next Greater Element）
```

### 4. 队列（FIFO）

**特点：** 先进先出，队尾入队、队头出队。

```
变种：
├── 循环队列 —— 解决"假溢出"问题
├── 双端队列（Deque）—— 两端均可入队出队
└── 优先队列（堆实现）—— 按优先级出队
```

## 三、树形结构

### 1. 基础树概念

| 术语 | 说明 |
|------|------|
| 节点 | 树的基本组成单元 |
| 根节点 | 没有父节点的顶层节点 |
| 叶子节点 | 没有子节点的节点 |
| 度 | 节点的子节点数量 |
| 深度 | 根节点到当前节点的路径长度 |
| 高度 | 当前节点到最远叶子节点的路径长度 |

**遍历方式：**

```
深度优先（DFS）:
├── 前序：根 → 左 → 右
├── 中序：左 → 根 → 右
└── 后序：左 → 右 → 根

广度优先（BFS）:
└── 层序：按层级从上到下遍历
```

### 2. 二叉树

| 类型 | 定义 | 应用 |
|------|------|------|
| **满二叉树** | 每层节点全满 | 堆的基础 |
| **完全二叉树** | 除最后一层外全满，最后一层靠左 | 堆的存储结构 |
| **平衡二叉树（AVL）** | 左右子树高度差 ≤ 1 | 自平衡查找树 |

**性质公式：**

- 第 i 层最多有 `2^(i-1)` 个节点
- 深度为 k 的二叉树最多有 `2^k - 1` 个节点
- 叶子节点数 = 度为 2 的节点数 + 1

### 3. 二叉搜索树（BST）

```
        8
       / \
      3   10
     / \    \
    1   6    14
```

- **规则：** 左子树 < 根 < 右子树
- **中序遍历：** 升序序列
- **缺陷：** 极端情况退化为链表（O(n)）

### 4. 平衡树

| 类型 | 平衡条件 | 平衡方式 | 工程应用 |
|------|----------|----------|----------|
| **AVL 树** | 左右子树高度差 ≤ 1 | 左旋、右旋、双旋 | 理论模型 |
| **红黑树** | 5 条规则（弱平衡） | 染色 + 旋转 | HashMap、TreeMap |

> **红黑树**是工程中最常用的平衡树，通过弱平衡减少旋转次数，插入删除效率高于 AVL 树。

### 5. 堆

```
       大顶堆             小顶堆
        9                  1
       / \                / \
      7   8              3   2
     / \ / \            / \ / \
    5  6 3  4          5  4 6  7
```

- **结构：** 完全二叉树（数组存储）
- **类型：** 大顶堆（父 ≥ 子）、小顶堆（父 ≤ 子）
- **应用：** 优先队列、堆排序、TopK 问题

### 6. 哈夫曼树

- **定义：** 带权路径长度（WPL）最短的二叉树
- **应用：** 哈夫曼编码（无损数据压缩）

## 四、图形结构

### 1. 存储方式

| 方式 | 适用场景 | 空间复杂度 | 特点 |
|------|----------|-----------|------|
| **邻接矩阵** | 稠密图 | O(V²) | 直观、判断边存在 O(1) |
| **邻接表** | 稀疏图（主流） | O(V + E) | 节省空间、遍历高效 |

### 2. 遍历

| 算法 | 数据结构 | 应用 |
|------|----------|------|
| **DFS（深度优先）** | 栈/递归 | 拓扑排序、连通分量 |
| **BFS（广度优先）** | 队列 | 最短路径、层序遍历 |

### 3. 经典算法

| 算法 | 问题 | 复杂度 |
|------|------|--------|
| **Dijkstra** | 单源最短路径（无负权） | O((V+E) log V) |
| **Floyd** | 多源最短路径 | O(V³) |
| **Prim** | 最小生成树 | O(E log V) |
| **Kruskal** | 最小生成树 | O(E log E) |
| **拓扑排序** | 有向无环图（DAG）依赖排序 | O(V + E) |

## 五、查找

### 1. 基础查找

| 方法 | 条件 | 时间复杂度 |
|------|------|-----------|
| 顺序查找 | 无序数组 | O(n) |
| 二分查找 | 有序数组 | O(log n) |

### 2. 散列查找（哈希）

- **核心结构：** 哈希表
- **平均时间复杂度：** O(1)
- **关键问题：** 哈希函数设计、哈希冲突解决

| 冲突解决策略 | 说明 |
|-------------|------|
| **链地址法** | 冲突元素挂在同一个桶的链表上（Java HashMap） |
| **开放定址法** | 冲突时寻找下一个空桶（线性探测、二次探测） |

## 六、排序

### 1. 简单排序（O(n²)）

| 算法 | 稳定性 | 特点 |
|------|--------|------|
| 冒泡排序 | 稳定 | 相邻交换，可提前退出 |
| 选择排序 | 不稳定 | 每轮选最小值交换 |
| 插入排序 | 稳定 | 近乎有序数据效率极高 |

### 2. 高效排序（O(n log n)）

| 算法 | 稳定性 | 空间复杂度 | 特点 |
|------|--------|-----------|------|
| 快速排序 | 不稳定 | O(log n) | 平均最快，基础类型默认 |
| 归并排序 | 稳定 | O(n) | 稳定高效，对象排序默认 |
| 堆排序 | 不稳定 | O(1) | 原地排序，TopK 首选 |

### 3. 特殊排序（非比较排序）

| 算法 | 时间复杂度 | 适用场景 |
|------|-----------|----------|
| 计数排序 | O(n + k) | 整数范围集中 |
| 基数排序 | O(d(n+k)) | 多位整数/字符串 |
| 桶排序 | O(n + k) | 数据均匀分布 |

## 七、高频核心考点汇总

| 考点类别 | 关键内容 |
|----------|----------|
| **线性表** | 链表操作（反转、快慢指针、合并）、栈与队列的模拟实现 |
| **树** | 遍历递归/迭代实现、BST 增删查、堆的应用 |
| **哈希** | 冲突处理策略、HashMap 源码分析（put/get/扩容） |
| **图** | 遍历（DFS/BFS）、最短路径、拓扑排序 |
| **复杂度分析** | 常见排序/查找复杂度背诵、递归复杂度计算 |
| **工程应用** | 红黑树（TreeMap）、堆（PriorityQueue）、哈希表（HashMap）在 Java 集合框架中的落地实现 |
