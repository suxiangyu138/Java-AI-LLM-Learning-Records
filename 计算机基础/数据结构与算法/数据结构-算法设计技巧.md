## 一、算法设计核心技巧（后端开发必备）

### 1. 分治法（Divide and Conquer）

**核心思想：** 将问题拆分为子问题，递归求解，合并结果。

**适用场景：** 大规模数据处理、排序、查找、树结构。

```java
/**
 * 分治法：归并排序
 * 时间复杂度：O(n log n)
 * 空间复杂度：O(n)
 */
public class MergeSort {
    public void sort(int[] arr) {
        if (arr == null || arr.length <= 1) return;
        mergeSort(arr, 0, arr.length - 1, new int[arr.length]);
    }
    private void mergeSort(int[] arr, int left, int right, int[] temp) {
        if (left >= right) return;
        int mid = left + (right - left) / 2;
        mergeSort(arr, left, mid, temp);
        mergeSort(arr, mid + 1, right, temp);
        merge(arr, left, mid, right, temp);
    }
    private void merge(int[] arr, int left, int mid, int right, int[] temp) {
        int i = left, j = mid + 1, k = 0;
        while (i <= mid && j <= right) {
            temp[k++] = arr[i] <= arr[j] ? arr[i++] : arr[j++];
        }
        while (i <= mid) temp[k++] = arr[i++];
        while (j <= right) temp[k++] = arr[j++];
        System.arraycopy(temp, 0, arr, left, k);
    }
}
```

**后端应用：** 分布式计算、大数据分片处理、数据库分库分表。

### 2. 动态规划（Dynamic Programming）

**核心思想：** 重叠子问题 + 最优子结构，用空间换时间。

**适用场景：** 最优解问题、路径规划、状态转移。

```java
/**
 * 动态规划：最长递增子序列
 * 时间复杂度：O(n²)
 * 空间复杂度：O(n)
 */
public class LIS {
    public int lengthOfLIS(int[] nums) {
        if (nums == null || nums.length == 0) return 0;
        int[] dp = new int[nums.length];
        int maxLen = 1;
        for (int i = 0; i < nums.length; i++) {
            dp[i] = 1;
            for (int j = 0; j < i; j++) {
                if (nums[j] < nums[i]) {
                    dp[i] = Math.max(dp[i], dp[j] + 1);
                }
            }
            maxLen = Math.max(maxLen, dp[i]);
        }
        return maxLen;
    }
}
```

**后端应用：** 缓存策略、资源调度、金融收益计算。

### 3. 贪心算法（Greedy）

**核心思想：** 局部最优推导全局最优，需满足贪心选择性质。

**适用场景：** 最小生成树、单源最短路径、任务调度。

```java
/**
 * 贪心算法：活动选择
 * 时间复杂度：O(n log n)
 * 空间复杂度：O(1)
 */
import java.util.Arrays;
import java.util.Comparator;
public class ActivitySelection {
    static class Activity {
        int start, end;
        public Activity(int s, int e) { start = s; end = e; }
    }
    public int maxActivities(Activity[] acts) {
        Arrays.sort(acts, Comparator.comparingInt(a -> a.end));
        int count = 1, lastEnd = acts[0].end;
        for (int i = 1; i < acts.length; i++) {
            if (acts[i].start >= lastEnd) {
                count++;
                lastEnd = acts[i].end;
            }
        }
        return count;
    }
}
```

**后端应用：** 资源分配、负载均衡、流量调度。

### 4. 回溯法（Backtracking）

**核心思想：** 试探 + 回退，暴力枚举所有可能。

**适用场景：** 排列组合、路径搜索、约束满足。

```java
/**
 * 回溯法：全排列
 * 时间复杂度：O(n!)
 * 空间复杂度：O(n)
 */
import java.util.ArrayList;
import java.util.List;
public class Permutations {
    public List<List<Integer>> permute(int[] nums) {
        List<List<Integer>> res = new ArrayList<>();
        backtrack(nums, new boolean[nums.length], new ArrayList<>(), res);
        return res;
    }
    private void backtrack(int[] nums, boolean[] used, List<Integer> path, List<List<Integer>> res) {
        if (path.size() == nums.length) {
            res.add(new ArrayList<>(path));
            return;
        }
        for (int i = 0; i < nums.length; i++) {
            if (!used[i]) {
                used[i] = true;
                path.add(nums[i]);
                backtrack(nums, used, path, res);
                path.remove(path.size() - 1);
                used[i] = false;
            }
        }
    }
}
```

**后端应用：** 权限校验、组合查询、游戏AI。

### 5. 分支限界法（Branch and Bound）

**核心思想：** 剪枝优化，避免无效搜索。

**适用场景：** 最优路径、组合优化、约束问题。

```java
/**
 * 分支限界法：0-1背包
 * 时间复杂度：O(2ⁿ)（剪枝优化）
 * 空间复杂度：O(n)
 */
import java.util.PriorityQueue;
public class Knapsack {
    static class Node {
        int level, profit, weight;
        double bound;
        public Node(int l, int p, int w) { level = l; profit = p; weight = w; }
    }
    public int knapsack(int[] w, int[] v, int cap) {
        int n = w.length;
        PriorityQueue<Node> pq = new PriorityQueue<>((a, b) -> Double.compare(b.bound, a.bound));
        Node root = new Node(-1, 0, 0);
        root.bound = bound(root, w, v, cap);
        pq.offer(root);
        int maxProfit = 0;
        while (!pq.isEmpty()) {
            Node curr = pq.poll();
            if (curr.bound <= maxProfit) continue;
            int level = curr.level + 1;
            // 选
            Node left = new Node(level, curr.profit + v[level], curr.weight + w[level]);
            if (left.weight <= cap) {
                maxProfit = Math.max(maxProfit, left.profit);
                left.bound = bound(left, w, v, cap);
                if (left.bound > maxProfit) pq.offer(left);
            }
            // 不选
            Node right = new Node(level, curr.profit, curr.weight);
            right.bound = bound(right, w, v, cap);
            if (right.bound > maxProfit) pq.offer(right);
        }
        return maxProfit;
    }
    private double bound(Node node, int[] w, int[] v, int cap) {
        int n = w.length;
        int level = node.level + 1;
        int profit = node.profit;
        int weight = node.weight;
        while (level < n && weight + w[level] <= cap) {
            profit += v[level];
            weight += w[level];
            level++;
        }
        if (level < n) profit += (cap - weight) * (double) v[level] / w[level];
        return profit;
    }
}
```

**后端应用：** 物流路径、资源调度、最优决策。

### 6. 随机化算法（Randomized）

**核心思想：** 引入随机因素，降低最坏情况复杂度。

**适用场景：** 哈希、快速排序、负载均衡。

```java
/**
 * 随机化算法：随机快排
 * 时间复杂度：O(n log n)（期望）
 * 空间复杂度：O(log n)
 */
public class RandomQuickSort {
    public void sort(int[] arr) {
        quickSort(arr, 0, arr.length - 1);
    }
    private void quickSort(int[] arr, int left, int right) {
        if (left >= right) return;
        int pivot = randomPartition(arr, left, right);
        quickSort(arr, left, pivot - 1);
        quickSort(arr, pivot + 1, right);
    }
    private int randomPartition(int[] arr, int left, int right) {
        int rand = left + (int) (Math.random() * (right - left + 1));
        swap(arr, rand, right);
        return partition(arr, left, right);
    }
    private int partition(int[] arr, int left, int right) {
        int pivot = arr[right];
        int i = left - 1;
        for (int j = left; j < right; j++) {
            if (arr[j] <= pivot) swap(arr, ++i, j);
        }
        swap(arr, i + 1, right);
        return i + 1;
    }
    private void swap(int[] arr, int i, int j) {
        int t = arr[i]; arr[i] = arr[j]; arr[j] = t;
    }
}
```

**后端应用：** 负载均衡、缓存淘汰、分布式哈希。

## 二、算法复杂度分析（后端核心）

### 1. 时间复杂度

| 复杂度 | 对应操作 |
|--------|---------|
| O(1) | 常数操作 |
| O(log n) | 二分、堆操作 |
| O(n) | 线性遍历 |
| O(n log n) | 排序、分治 |
| O(n²) | 暴力枚举 |
| O(2ⁿ) | 回溯、递归 |

### 2. 空间复杂度

| 类别 | 空间复杂度 |
|------|-----------|
| 原地算法 | O(1) |
| 递归栈 | O(log n) ~ O(n) |
| 辅助空间 | O(n)、O(n²) |

### 3. 均摊复杂度

| 场景 | 均摊复杂度 |
|------|-----------|
| 动态数组扩容 | O(1) |
| 并查集 | O(α(n)) |

## 五、总结（Java后端核心要点）

1. **分治法**：拆分问题，递归求解，适合大规模数据
2. **动态规划**：重叠子问题 + 最优子结构，空间换时间
3. **贪心算法**：局部最优，适合满足贪心性质的问题
4. **回溯法**：暴力枚举，适合排列组合、路径搜索
5. **分支限界**：剪枝优化，提升搜索效率
6. **随机化**：降低最坏情况复杂度，提升稳定性
7. **后端应用**：数据处理、网络路由、缓存优化、任务调度
8. **面试重点**：复杂度分析、算法选择、场景适配
