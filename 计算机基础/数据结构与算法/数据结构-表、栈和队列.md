## 表（线性表）

### 1. 定义

线性表是 n 个数据元素的有限序列，元素间为 **一对一** 关系。

### 2. 分类

| 类型 | 存储方式 | 随机访问 | 插入/删除 |
|------|----------|----------|-----------|
| 顺序表（数组实现） | 连续内存 | O(1) | O(n) |
| 链表（指针实现） | 离散内存 | O(n) | O(1)（已知位置） |

### 3. Java 实现

| 实现类 | 底层结构 | 特点 | 适用场景 |
|--------|----------|------|----------|
| `ArrayList` | 动态数组 | 默认容量 10，扩容 1.5 倍 | 频繁随机访问、少量插入删除 |
| `LinkedList` | 双向链表 | 实现 List 与 Deque 接口 | 频繁头尾操作、大量插入删除 |
| `Vector` | 动态数组（同步） | 线程安全，性能低 | **已淘汰**，不推荐使用 |

### 4. 适用场景

- **ArrayList：** 频繁随机访问、少量插入删除
- **LinkedList：** 频繁头尾操作、大量插入删除

## 栈（Stack）

### 1. 定义

**后进先出（LIFO）** 线性表，仅在栈顶操作。

```
    栈顶 → |  元素3  |  ← push/pop
            |  元素2  |
    栈底 → |  元素1  |
```

### 2. 核心操作

| 操作 | 含义 | 时间复杂度 |
|------|------|-----------|
| `push()` | 入栈 | O(1) |
| `pop()` | 出栈 | O(1) |
| `peek()` | 查看栈顶 | O(1) |

### 3. Java 实现

| 实现类 | 说明 | 推荐度 |
|--------|------|--------|
| `Stack` | 继承 Vector，线程安全但性能差 | ❌ 不推荐 |
| `ArrayDeque` | 双端队列实现栈，性能最优 | ✅ **推荐** |
| `LinkedList` | 链表实现栈 | ✅ 可用 |

**推荐用法：**

```java
Deque<String> stack = new ArrayDeque<>();
stack.push("A");
stack.push("B");
String top = stack.pop();  // "B"
```

### 4. 后端应用

| 应用场景 | 说明 |
|----------|------|
| 函数调用栈 | 方法递归、JVM 栈帧管理 |
| 表达式求值 | 计算器实现、语法解析 |
| 括号匹配 | 代码校验、HTML 标签检查 |
| 单调栈 | 解决 Next Greater Element 问题 |

## 队列（Queue）

### 1. 定义

**先进先出（FIFO）** 线性表，队尾入队、队头出队。

```
出队 ← | 元素1 | 元素2 | 元素3 | ← 入队
        队头              队尾
```

### 2. 核心操作

| 操作 | 含义 | 时间复杂度 |
|------|------|-----------|
| `offer()` | 入队 | O(1) |
| `poll()` | 出队 | O(1) |
| `peek()` | 查看队头 | O(1) |

### 3. Java 实现

| 实现类 | 底层结构 | 特点 |
|--------|----------|------|
| `ArrayDeque` | 循环数组 | 性能最优，推荐使用 |
| `LinkedList` | 双向链表 | 支持双端操作 |
| `PriorityQueue` | 堆 | 优先级队列 |
| `ConcurrentLinkedQueue` | CAS 无锁 | 并发安全，非阻塞 |

### 4. 后端应用

| 应用场景 | 说明 |
|----------|------|
| 任务队列 | 线程池、消息队列 |
| 广度优先搜索（BFS） | 二叉树层序遍历、最短路径 |
| 阻塞队列 | 生产者-消费者模型（`ArrayBlockingQueue`） |
| 双端队列 | 滑动窗口、缓存设计 |

## 性能对比

### 1. 随机访问

```
ArrayList O(1)  >  LinkedList O(n)
```

### 2. 插入/删除

| 操作位置 | ArrayList | LinkedList |
|----------|-----------|------------|
| 头部 | O(n) | O(1) |
| 中间 | O(n) | O(n) |
| 尾部 | O(1)（均摊） | O(1) |

### 3. 内存占用

| 实现 | 特点 |
|------|------|
| ArrayList | 连续内存，紧凑高效 |
| LinkedList | 节点含前后指针，内存开销大 |

## Java 后端实战场景

### 1. 数据存储

- 列表数据优先使用 `ArrayList`
- 频繁修改操作使用 `LinkedList`

### 2. 算法实现

- **栈**：括号匹配、逆波兰表达式、单调栈
- **队列**：BFS、任务调度、滑动窗口

### 3. 并发场景

- 线程安全队列：`ConcurrentLinkedQueue`
- 阻塞队列：`LinkedBlockingQueue`（线程池核心）

---

## 复杂度总结

| 数据结构 | 访问 | 插入/删除（头） | 插入/删除（尾） |
|----------|------|----------------|----------------|
| ArrayList | O(1) | O(n) | O(1)（均摊） |
| LinkedList | O(n) | O(1) | O(1) |
| Stack / Queue | — | — | O(1)（基础操作） |

> **栈和队列的基本操作均为 O(1)**，性能极高。

---

## 最佳实践

1. **列表优先选 ArrayList**，尾部操作高效
2. **栈和队列优先用 ArrayDeque**，性能优于 Stack / LinkedList
3. **并发场景使用对应并发容器**，避免手动加锁同步
4. **根据操作类型选择数据结构**，合理优化系统性能
