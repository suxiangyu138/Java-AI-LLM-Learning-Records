# 深度学习核心知识点速通

> 目标：用最短路径建立深度学习的完整认知框架。每个概念只讲核心直觉 + 一句话公式。

---

## 一、基石概念：什么是深度学习

### 1.1 一句话定义

深度学习 = **多层神经网络 + 反向传播 + 大规模数据**，自动从数据中学习层次化特征表示。

### 1.2 与传统机器学习的区别

| | 传统 ML | 深度学习 |
|---|---|---|
| 特征工程 | 人工设计 | 自动学习 |
| 数据量 | 小样本可用 | 数据越多越强 |
| 可解释性 | 高 | 低（黑箱） |
| 计算需求 | CPU 够用 | 需要 GPU |
| 代表算法 | SVM、决策树、XGBoost | CNN、RNN、Transformer |

### 1.3 核心三要素

```
深度学习 = 模型（网络结构）+ 损失函数（目标）+ 优化器（如何学习）
```

## 二、数学基础速览

### 2.1 线性代数

| 概念 | 直觉 | 应用 |
|------|------|------|
| **标量/向量/矩阵/张量** | 0D/1D/2D/N 维数组 | 数据表示的基本单位 |
| **矩阵乘法** | \(\mathbf{C} = \mathbf{A} \times \mathbf{B}\) | 全连接层本质是矩阵乘法 |
| **点积** | 两向量逐元素相乘求和 | 衡量相似度（Attention 核心） |
| **特征值与特征向量** | 矩阵作用后方向不变的向量 | PCA 降维、谱聚类 |
| **SVD 分解** | 任意矩阵 = UΣV^T | 推荐系统、LoRA 微调 |

### 2.2 微积分

| 概念 | 直觉 | 应用 |
|------|------|------|
| **导数** | 函数变化率 ∂y/∂x | 梯度下降的基础 |
| **偏导数** | 多维函数对某一维求导 | 多参数模型 |
| **梯度** | 所有偏导数组成的向量 | 指向函数增长最快的方向 |
| **链式法则** | \(\frac{\partial z}{\partial x} = \frac{\partial z}{\partial y} \cdot \frac{\partial y}{\partial x}\) | **反向传播的核心** |
| **Jacobian / Hessian** | 一阶/二阶导数矩阵 | 优化理论分析 |

### 2.3 概率论

| 概念 | 直觉 | 应用 |
|------|------|------|
| **最大似然估计 (MLE)** | 找使数据出现概率最大的参数 | 大多数损失函数的源头 |
| **交叉熵** | \(H(p,q) = -\sum p(x)\log q(x)\) | **分类问题的标准损失函数** |
| **KL 散度** | 两个分布的差异 | VAE、知识蒸馏 |
| **Bayes 定理** | P(A\|B) = P(B\|A)P(A)/P(B) | 贝叶斯深度学习 |
| **信息熵** | 不确定性的度量 | 决策树分裂、熵正则化 |

## 三、神经网络基础构件

### 3.1 神经元与激活函数

```
输入 x1, x2, x3
  │   │   │
  ▼   ▼   ▼
  w1  w2  w3  ← 权重
  └───┼───┘
      ▼
  Σ(w·x) + b  ← 线性变换
      │
      ▼
  σ(·)  ← 激活函数（引入非线性）
      │
      ▼
    输出 y
```

**一句话**：`y = σ(Wx + b)` 就是神经网络一切的基础。

#### 激活函数对比

| 函数 | 公式 | 特点 | 死区 |
|------|------|------|------|
| **Sigmoid** | σ(x)=1/(1+e^{-x}) | 输出 (0,1)，二分类输出层 | 梯度饱和 |
| **Tanh** | tanh(x) | 输出 (-1,1)，零中心 | 梯度饱和 |
| **ReLU** | max(0, x) | 不饱和，简单高效，**默认首选** | x<0 梯度为 0 |
| **LeakyReLU** | max(αx, x) | 解决 ReLU 死区，α=0.01 | — |
| **GELU** | x·Φ(x) | Transformer 标配，平滑 ReLU 替代 | — |
| **Swish/SiLU** | x·σ(x) | Google 自搜索，深层网络更优 | — |
| **Softmax** | e^{x_i}/Σe^{x_j} | 多分类输出层，输出和为 1 | — |

**选型口诀**：隐藏层默认 ReLU/GELU；二分类输出 Sigmoid；多分类输出 Softmax；回归输出无激活函数。

### 3.2 损失函数

| 任务 | 损失函数 | 公式 |
|------|----------|------|
| 二分类 | Binary Cross-Entropy | \(-\frac{1}{N}\sum[y\log\hat{y}+(1-y)\log(1-\hat{y})]\) |
| 多分类 | Categorical Cross-Entropy | \(-\frac{1}{N}\sum\sum y_c \log \hat{y}_c\) |
| 回归 | MSE（均方误差） | \(\frac{1}{N}\sum(y - \hat{y})^2\) |
| 回归 | MAE（平均绝对误差） | \(\frac{1}{N}\sum|y - \hat{y}|\) |
| 排序 | Pairwise / Listwise Loss | RankNet / LambdaRank |
| 生成 | KL 散度 / 对抗损失 | VAE / GAN |

### 3.3 优化器

```
梯度下降家族进化树：

SGD → Momentum → Nesterov → AdaGrad → RMSprop → Adam → AdamW
 │                                              │
 └─ 每次更新方向 = -η·∇L(θ)                     └─ 自适应学习率 + 动量
```

| 优化器 | 核心思想 | 超参数 | 适用场景 |
|--------|----------|--------|----------|
| **SGD** | 纯梯度方向 | lr | 需要精细调参，泛化好 |
| **SGD + Momentum** | 惯性加速，越过局部最小 | lr, β=0.9 | 经典组合 |
| **Adam** | 自适应 lr + 动量 | lr=1e-3, β1=0.9, β2=0.999 | **通用首选** |
| **AdamW** | Adam + 权重衰减解耦 | lr, weight_decay | **Transformer 标配** |
| **RMSprop** | 自适应 lr，适合 RNN | lr | 序列模型 |
| **LARS / LAMB** | 大 batch 场景 | — | 大规模分布式训练 |

**口诀**：不知道用啥就用 AdamW，lr=1e-3 起步。

### 3.4 反向传播 (Backpropagation)

```
前向传播：x → 层1 → 层2 → ... → 输出 → Loss(y_true, y_pred)
                                                    │
反向传播：                                          ▼
          梯度∂L/∂w_N ← ... ← ∂L/∂w_2 ← ∂L/∂w_1 ← ∂L/∂输出
                                          (链式法则逐层传递)
```

**核心直觉**：损失对每一层的梯度 = 损失对输出的梯度 × 输出对输入的梯度 × 输入对权重的梯度（链式法则拆开）。

**关键问题与解决**：
| 问题 | 原因 | 解决 |
|------|------|------|
| 梯度消失 | Sigmoid/Tanh 饱和区梯度趋 0 | ReLU、BatchNorm、残差连接 |
| 梯度爆炸 | 深层网络梯度指数增长 | 梯度裁剪 (Gradient Clipping) |
| 检查梯度 | 验证反向传播是否正确 | 数值梯度检查 (finite differences) |

## 四、正则化：防止过拟合

| 方法 | 原理 | 一句话 |
|------|------|--------|
| **L1 正则** | 损失 + λ\|w\| | 产生稀疏权重，特征选择 |
| **L2 正则 (Weight Decay)** | 损失 + λ\|w\|² | 权重趋向小值最稳定 **最常用** |
| **Dropout** | 训练时随机丢弃神经元 | 相当于隐式集成学习，比 (p=0.5 隐藏层, p=0.2 输入层) |
| **Batch Normalization** | 对每层输入标准化 | 自带轻微正则，加速训练 |
| **Layer Normalization** | 对每个样本特征维标准化 | Transformer 标配 |
| **Early Stopping** | 验证集 loss 不降即停 | 最简单高效，配合 checkpoint |
| **Data Augmentation** | 图像翻转/裁剪/加噪 | CV 必用，提高泛化的王道 |
| **Label Smoothing** | 标签从 [0,1] 变成 [0.05, 0.95] | 防止过于自信，提升泛化 |

## 五、CNN：卷积神经网络（CV 领域）

### 5.1 核心操作

```
输入图像 (H×W×C)
    │
    ▼
卷积层 (Kernel 滑动，局部感知 + 权重共享)
    │
    ▼
激活函数 (ReLU)
    │
    ▼
池化层 (下采样，MaxPool/AvgPool)
    │
    ▼
... 重复若干次 ...
    │
    ▼
全连接层 (分类头)
```

### 5.2 三个核心思想

| 思想 | 含义 | 好处 |
|------|------|------|
| **局部连接** | 每个神经元只看局部区域 | 参数少，效率高 |
| **权重共享** | 同一 kernel 滑动全图 | 平移不变性 |
| **层次化特征** | 浅层 → 边缘，中层 → 纹理，深层 → 语义 | 自动特征提取 |

### 5.3 经典架构演进

| 模型 | 年份 | 核心创新 | 参数量 |
|------|------|----------|--------|
| LeNet-5 | 1998 | CNN 开山之作 | 60K |
| AlexNet | 2012 | ReLU + Dropout + GPU | 60M |
| VGG | 2014 | 小 kernel (3×3) 堆叠 | 138M |
| GoogLeNet (Inception) | 2014 | 多尺度并行分支 | 5M |
| **ResNet** | 2015 | **残差连接**（跨越连接），解决退化 | 25M~ |
| DenseNet | 2017 | 密集连接，每层连接所有前层 | — |
| MobileNet | 2017 | 深度可分离卷积，轻量化 | 4M |
| **EfficientNet** | 2019 | NAS 搜索最优深度/宽度/分辨率比例 | — |
| ConvNeXt | 2022 | CNN 现代化改造，逼近 Transformer | — |

### 5.4 残差连接（ResNet 核心，深度学习最重要的结构创新之一）

```
传统：x → [Weight Layer → ReLU → Weight Layer] → H(x)
残差：x → [Weight Layer → ReLU → Weight Layer] → F(x) → F(x) + x → H(x)
                                                 └─────────────────┘
                                                      残差 + 恒等映射
```

**为什么重要**：梯度可以通过恒等连接直接传递到底层，解决了深层网络的梯度消失问题，让 100+ 层网络可训练。

## 六、RNN / LSTM / GRU（序列建模）

### 6.1 RNN 核心公式

$$
h_t = \tanh(W_h h_{t-1} + W_x x_t + b)
$$
$$
y_t = W_y h_t + b_y
$$

**问题**：长序列时梯度消失/爆炸，无法捕捉长期依赖。

### 6.2 LSTM（长短期记忆网络）

```
           遗忘门              输入门             输出门
        f_t = σ(W_f·[h_{t-1}, x_t])    i_t = σ(W_i·[h_{t-1}, x_t])    o_t = σ(W_o·[h_{t-1}, x_t])
              │                              │                              │
              ▼                              ▼                              ▼
        C_t = f_t ⊙ C_{t-1}     +     i_t ⊙ tanh(W_c·[h_{t-1}, x_t])
              │
              ▼
        h_t = o_t ⊙ tanh(C_t)
```

**核心直觉**：
- **遗忘门**：决定丢掉哪些旧记忆
- **输入门**：决定写入哪些新记忆
- **输出门**：决定输出哪些记忆
- **细胞状态 \(C_t\)**：高速公路，信息无损传递

### 6.3 GRU（门控循环单元，LSTM 简化版）

- 合并遗忘门和输入门为**更新门** \(z_t\)
- 用**重置门** \(r_t\) 控制历史信息利用
- 参数更少，效果相当，训练更快

### 6.4 对比总结

| | RNN | LSTM | GRU |
|---|---|---|---|
| 门数量 | 0 | 3 | 2 |
| 长期依赖 | ❌ | ✅ | ✅ |
| 参数量 | 少 | 多 | 中 |
| 训练速度 | 快 | 慢 | 较快 |
| 现状 | 几乎不用 | 有时用 | 有时用 |

**现实**：大部分序列任务已经被 **Transformer** 替代。

## 七、Transformer（现代深度学习的基石）

> 2017 年提出，"Attention Is All You Need"，统一了 NLP → CV → 多模态。

### 7.1 整体架构

```
Encoder（编码器） × N             Decoder（解码器） × N
┌─────────────────┐              ┌─────────────────┐
│  Multi-Head      │              │  Masked Multi-   │
│  Self-Attention  │              │  Head Attention  │
│       ↓          │              │       ↓          │
│  Add & Norm      │              │  Add & Norm      │
│       ↓          │              │       ↓          │
│  Feed Forward    │              │  Cross-Attention │ ← Encoder 输出作为 K,V
│       ↓          │              │       ↓          │
│  Add & Norm      │              │  Add & Norm      │
└─────────────────┘              │       ↓          │
                                 │  Feed Forward    │
                                 │       ↓          │
                                 │  Add & Norm      │
                                 └─────────────────┘
```

### 7.2 Self-Attention（自注意力 — 核心中的核心）

```
Q = X·W_Q    K = X·W_K    V = X·W_V

Attention(Q, K, V) = softmax(Q·K^T / √d_k) · V
                        └────────┬────────┘
                            注意力分数矩阵
                            (每个词对每个词的关注度)
```

**一步一步理解**：

```
Step 1: Q·K^T → 计算相似度
    "我"和"我"的相似度，"我"和"爱"的相似度，"我"和"你"的相似度...

Step 2: /√d_k → 缩放（防止点积过大导致 softmax 梯度消失）

Step 3: softmax → 归一化为 (0,1) 权重，总和为 1

Step 4: ×V → 按权重加权求和
    输出 = 0.7×V("我") + 0.2×V("爱") + 0.1×V("你")
                    ↑"我"的表示中融入了上下文中其他词的信息
```

### 7.3 Multi-Head Attention（多头注意力）

```
输入 X
  │
  ├→ Head1: Q1,K1,V1 → Attention → output1
  ├→ Head2: Q2,K2,V2 → Attention → output2
  ├→ ...
  └→ Head8: Q8,K8,V8 → Attention → output8
                                   │
                                   ▼
                              Concat → W_O → 输出
```

**直觉**：每个 Head 关注不同的关系（语法、语义、位置、指代...），拼起来就是丰富的上下文表示。

### 7.4 Positional Encoding（位置编码）

Transformer 自身没有顺序概念，需要注入位置信息。

```
PE(pos, 2i)   = sin(pos / 10000^{2i/d})
PE(pos, 2i+1) = cos(pos / 10000^{2i/d})
```

**现代替代方案**：**RoPE**（旋转位置编码，LLaMA/Qwen 等主流 LLM 使用）、**ALiBi**（线性偏置注意力）。

### 7.5 Feed Forward Network (FFN)

```
FFN(x) = GELU(x·W₁ + b₁)·W₂ + b₂
```

本质：先升维（d_model → 4×d_model），再降维回来。给模型非线性变换能力 + 知识存储空间。

### 7.6 Transformer 变体

| 变体 | 架构 | 代表模型 |
|------|------|----------|
| Encoder-only | 只编码，双向注意力 | BERT、RoBERTa、DeBERTa |
| Decoder-only | 自回归，因果注意力 | **GPT 系列**、LLaMA、Claude |
| Encoder-Decoder | 完整编码解码 | 原始 Transformer、T5、BART |

## 八、训练技巧与调参

### 8.1 学习率调度

```python
# Warmup + Cosine Decay（Transformer 标配）
lr = min(step / warmup_steps, 1) * base_lr  # warmup 线性增长
lr = 0.5 * base_lr * (1 + cos(π * step / total_steps))  # cosine 衰减
```

| 调度策略 | 特点 |
|----------|------|
| Step Decay | 固定步数衰减，简单 |
| Exponential Decay | 指数衰减 |
| **Cosine Decay** | 平滑衰减，通用效果好 |
| **Warmup + Cosine** | 先线性增长再余弦衰减，Transformer / 大模型标配 |
| Cyclic LR | 周期性升降，跳出局部最优 |
| ReduceLROnPlateau | 监控 val loss，不降则衰减 |

### 8.2  Batch Size 影响

| batch size | 优点 | 缺点 |
|---|---|---|
| 小 (16-64) | 泛化好，正则化效果 | 训练慢，梯度噪声大 |
| 大 (256-2048) | 训练快，梯度稳定 | 泛化差，可能需要调 lr |
| 超大 (4096+) | 极致吞吐 | 需 LARS/LAMB 优化器 |

**经验**：Transformer 预训练用大 batch (512-2048)，微调用小 batch (16-64)；lr 与 batch size 大致呈线性关系（batch ×2 → lr ×2）。

### 8.3 初始化方法

| 方法 | 适用场景 |
|------|----------|
| **Xavier (Glorot)** | Sigmoid/Tanh 激活 |
| **Kaiming (He)** | ReLU 激活，**默认首选** |
| 正态分布 N(0, 0.02) | Transformer（BERT/GPT 常用） |

### 8.4 混合精度训练 (AMP)

```
FP32 权重（主副本）
    │
    ▼  自动转换
FP16 前向计算（速度快、显存省一半）
    │
    ▼
FP32 loss scaling（防止小梯度下溢）
    │
    ▼
FP16 反向传播
    │
    ▼
FP32 权重更新
```

现代框架一行代码：`torch.cuda.amp.autocast()` + `GradScaler()`

### 8.5 梯度累积

模拟大 batch 训练（显存不够时的救命技巧）：

```
每 accumulation_steps 步才更新一次权重
有效 batch_size = batch_size × accumulation_steps
```

### 8.6 分布式训练

| 策略 | 原理 | 适用规模 |
|------|------|----------|
| Data Parallel (DP) | 数据分片，每个 GPU 完整模型 | 单机多卡 |
| Distributed Data Parallel (DDP) | DP 的分布式版本，多进程 | 单机/多机多卡 |
| Model Parallel | 模型分片到不同 GPU | 超大模型 |
| Pipeline Parallel | 按层分片，流水线执行 | 超大模型训练 |
| Tensor Parallel | 单层内矩阵运算分片 | GPT 级别 |
| ZeRO (1-3) | 优化器状态/梯度/参数分片 | DeepSpeed 核心 |
| **FSDP** | PyTorch 原生 ZeRO 3 | 推荐首选 |

## 九、生成模型

### 9.1 GAN（生成对抗网络）

```
噪声 z → Generator → 假样本 ─┐
                             ├→ Discriminator → 真/假
真实数据 → 真样本 ───────────┘

Generator 目标：骗过 Discriminator
Discriminator 目标：区分真假
两者对抗训练，Generator 最终学会生成逼真数据
```

**经典变体**：DCGAN → StyleGAN (人脸生成巅峰) → CycleGAN (风格迁移) → Pix2Pix (图像翻译)

### 9.2 VAE（变分自编码器）

```
输入 x → Encoder → μ, log(σ²) → Sample z ~ N(μ, σ²) → Decoder → 重建 x̂

损失 = 重建损失 + KL(N(μ,σ²) || N(0,1))
       └─ 让输出像输入 ─┘  └─ 让隐空间规整 ─────┘
```

**核心思想**：不是学一个确定的隐变量，而是学一个分布，然后从分布中采样生成。

### 9.3 Diffusion（扩散模型 — 当前图像生成的王者）

**前向过程**（加噪）：逐渐往图片上加高斯噪声，直到变成纯噪声。
**反向过程**（去噪）：训练模型从噪声中逐步还原图片。

```
x₀ → x₁ → x₂ → ... → x_T (纯噪声)   ← 前向加噪（固定，不需要学习）
x₀ ← x₁ ← x₂ ← ... ← x_T            ← 反向去噪（学习这个！）

核心：训练一个 UNet 预测每一步添加的噪声 ε
损失：L = E[||ε - ε_θ(x_t, t)||²]
```

**代表模型**：DDPM → Stable Diffusion (Latent Diffusion，在压缩空间做扩散) → DALL·E 2/3 → Midjourney

### 9.4 三种生成模型对比

| | GAN | VAE | Diffusion |
|---|---|---|---|
| 生成质量 | 高（但容易模式坍塌） | 模糊 | **最高** |
| 生成速度 | 快（一次前向） | 快 | 慢（需多步去噪） |
| 隐空间 | 不可控 | 连续规整 | 不太规整 |
| 训练难度 | 难（对抗博弈） | 易 | 中 |
| 前沿状态 | 较少使用 | 较少单独使用 | **主流** |

## 十、Attention 进阶（现代大模型基础）

### 10.1 各种 Attention 变体

| 变体 | 核心 | 复杂度 | 使用 |
|------|------|--------|------|
| Full Attention | Q×K^T 全部计算 | O(n²) | 原始 Transformer |
| **Flash Attention** | CUDA kernel 融合，IO 优化 | O(n²) 快 5-10× | **现代 LLM 标配** |
| Sparse Attention | 只算部分位置 | O(n√n) | Longformer、BigBird |
| **GQA (Grouped Query)** | 多个 Q 头共享一组 KV | 内存 ↓ | LLaMA 2/3、Claude |
| **MQA (Multi-Query)** | 所有 Q 共享一组 KV | 内存 ↓↓ | PaLM、Gemini |
| Sliding Window | 只看前后固定窗口 | O(n×w) | Mistral |
| Linear Attention | 核技巧近似 | O(n) | 少见 |
| Ring Attention | 序列分片到多 GPU，环状通信 | O(n²) 分布式 | 超长序列 |

### 10.2 KV Cache

**问题**：Decoder 自回归生成时，每个新 token 要重新计算所有历史 token 的 K、V。

**KV Cache 方案**：把之前算好的 K、V 缓存起来，生成新 token 时只需计算新 token 的 Q。

```
第 1 步：Q₁ → Attention(Q₁, [K₁], [V₁]) → 缓存 [K₁], [V₁]
第 2 步：Q₂ → Attention(Q₂, [K₁,K₂], [V₁,V₂]) → 缓存 [K₁,K₂], [V₁,V₂]
第 3 步：Q₃ → Attention(Q₃, [K₁,K₂,K₃], [V₁,V₂,V₃]) → ...

从此每次只计算当前 token，不重新计算历史
```

**这是 LLM 推理的核心瓶颈之一**（KV Cache 随生成长度线性增长，吃显存）。

## 十一、现代 LLM 核心概念

### 11.1 训练阶段

```
Pre-training（预训练）        SFT（监督微调）            RLHF（人类对齐）
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│ 海量无标注文本    │ →   │ 高质量问答对     │ →   │ 人类偏好数据     │
│ Next Token Pred  │     │ LM Loss on Q&A  │     │ Reward Model    │
│ (自监督学习)      │     │ (监督学习)       │     │ + PPO/DPO       │
└─────────────────┘     └─────────────────┘     └─────────────────┘
   基座模型                 对话模型                 对齐模型
   (Base Model)           (Chat Model)            (Aligned Model)
```

### 11.2 关键配置参数

| 参数 | 含义 | 典型值 (7B 模型) |
|------|------|------------------|
| d_model | 隐藏维度 | 4096 |
| n_layers | Transformer 层数 | 32 |
| n_heads | 注意力头数 | 32 |
| vocab_size | 词表大小 | 32K~128K |
| max_seq_len | 最大上下文长度 | 4096~128K |
| batch_size | 一批多少 token | 4M tokens |

### 11.3 Scaling Law（扩展定律）

> 模型性能与**参数量 N、训练数据量 D、训练计算量 C** 呈幂律关系。

$$
L(N, D) = \left(\frac{N_c}{N}\right)^{\alpha_N} + \left(\frac{D_c}{D}\right)^{\alpha_D}
$$

**Chinchilla 最优**（DeepMind, 2022）：对于给定的计算预算，模型大小和训练 token 数应同步等比例增长。即 **每 1 参数 ≈ 20 个训练 token**。

### 11.4 高效微调方法

| 方法 | 原理 | 可训练参数量 | 特点 |
|------|------|-------------|------|
| Full Fine-tuning | 全参数更新 | 100% | 效果好、最贵 |
| **LoRA** | 低秩矩阵分解 ΔW = BA | ~0.1%-1% | **最流行**，即插即用 |
| QLoRA | LoRA + 4-bit 量化 | ~0.1%-1% | 单卡微调 70B |
| Adapter | 插入小模块 | ~2%-5% | 早期方法 |
| Prefix Tuning | 学可训练 prefix | <1% | Prompt 级别 |
| P-Tuning v2 | 每层加可训练 prompt | ~0.1% | NLU 任务 |

### 11.5 模型量化

将 FP32/FP16 权重压缩到低精度：

| 精度 | 每参数 bit 数 | 显存 (7B 模型) | 质量损失 |
|------|--------------|----------------|----------|
| FP32 | 32 | 28 GB | 无 |
| FP16/BF16 | 16 | 14 GB | 几乎无 |
| **INT8** | 8 | 7 GB | 极微小 |
| **INT4 / GPTQ / AWQ** | 4 | 3.5 GB | 轻微 |
| NF4 (QLoRA) | 4 | 3.5 GB | 轻微 |

### 11.6 推理优化

| 技术 | 原理 | 加速比 |
|------|------|--------|
| Greedy / Beam Search | 解码策略 | — |
| KV Cache | 缓存历史 K,V | 不重算 |
| Flash Attention | IO-aware kernel 融合 | 2-5× |
| **vLLM** | PagedAttention + 连续批处理 | 10-20× 吞吐 |
| Tensor Parallel | 多 GPU 推理 | 线性扩展 |
| Speculative Decoding | 小模型 draft，大模型验证 | 2-3× |
| Continuous Batching | 动态合并请求 | 10× 吞吐 |

## 十三、常见面试题速答

| 问题 | 一句话答案 |
|------|-----------|
| BatchNorm vs LayerNorm 区别？ | BN 对 batch 内不同样本同一特征做归一化（CV 用）；LN 对同一样本不同特征做归一化（NLP/Transformer 用） |
| 为什么 Transformer 用 LN 不用 BN？ | 序列长度不一致导致 BN 统计不稳定，LN 不依赖 batch 统计 |
| 残差连接为什么有效？ | 梯度通过恒等映射直传底层，解决梯度消失 |
| Transformer 为什么需要位置编码？ | Self-Attention 是无序的，不加位置信息会丢失词序 |
| Adam vs SGD 怎么选？ | 默认 Adam/AdamW；追求极致泛化用 SGD；大模型都用 AdamW |
| 过拟合怎么办？ | 加正则(L2/Dropout) → 数据增强 → 早停 → 减小模型 |
| 欠拟合怎么办？ | 增大模型 → 训练更久 → 降低正则 → 检查数据 |
| Attention 复杂度是 O(n²) 为什么还能用？ | Flash Attention 等 IO 优化 + KV Cache 让实际速度可接受；超长序列用稀疏/线性 Attention |
| LoRA 为什么用低秩矩阵？ | 微调时参数增量 ΔW 是低秩的（Aghajanyan et al. 证明了这一点），用 AB 矩阵分解逼近即可 |
