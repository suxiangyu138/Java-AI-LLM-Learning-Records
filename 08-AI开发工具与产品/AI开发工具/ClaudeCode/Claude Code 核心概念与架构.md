# Claude Code 核心概念与架构（实战版）

> **文档定位**：Claude Code CLI 工具深度解析
> **版本**：Claude Code 2026.x
> **核心问题**：Claude Code 到底是什么？和 GitHub Copilot、Cursor 有什么本质区别？

---

## 一、Claude Code 是什么

**Claude Code** 是 Anthropic 官方推出的**终端级 AI 编程代理**，它不是 IDE 插件，而是一个直接运行在终端里的**自主编程伙伴**：

```
传统 AI 编程工具：你在 IDE 里写代码 → AI 补全/提示（被动）
Claude Code：你描述需求 → AI 主动读代码、写文件、跑命令、调试（主动）
```

### 1.1 核心定位

| 维度 | 说明 |
|---|---|
| **形态** | CLI 命令行工具（终端运行） |
| **底层模型** | Claude Opus 4/Sonnet 4/Haiku 4 |
| **运行方式** | 交互式对话 + 自主执行 |
| **能力边界** | 读写文件、执行 Shell、操作 Git、网络搜索 |
| **核心哲学** | 给 AI 完整上下文 + 执行能力 = 全栈工程师级助手 |

## 二、Claude Code vs 其他 AI 编程工具

| 维度 | Claude Code | GitHub Copilot | Cursor | Windsurf |
|---|---|---|---|---|
| **形态** | CLI 终端工具 | IDE 插件 | 独立 IDE | 独立 IDE |
| **交互模式** | 对话 + 自主执行 | 代码补全 | 对话 + 内联编辑 | 对话 + 自动编辑 |
| **上下文** | 全项目文件读取 | 当前文件/选项卡 | 当前文件+关联文件 | 代码库索引 |
| **自主性** | ⭐⭐⭐⭐⭐ 主动执行 | ⭐⭐ 被动建议 | ⭐⭐⭐ 内联编辑 | ⭐⭐⭐ 自动编辑 |
| **终端集成** | 原生（运行命令、看日志） | 无 | 终端面板 | 终端面板 |
| **Git 操作** | 原生（commit、diff、log） | 无 | Git 面板 | Git 面板 |
| **多文件编辑** | 批量并发编辑 | 逐文件 | 逐文件 | 逐文件 |
| **定价** | API Token 计费 | 订阅制 | 订阅制 | 订阅制 |
| **适用人群** | 专业开发者 | 所有开发者 | 专业开发者 | 专业开发者 |

### 2.1 核心差异

```
GitHub Copilot = 副驾驶（帮你扶着方向盘）
Cursor = 升级版编辑器（有 AI 聊天窗口）
Claude Code = 副司机（你把需求说清楚，它自己开车）
```

## 五、Claude Code 运行模式

### 5.1 交互模式（默认）

```
$ claude
> 帮我写一个用户登录功能
```

进入对话循环，每一步可选择批准或拒绝。

### 5.2 一次性模式（-p）

```bash
$ claude -p "解释这个项目的架构"
# 输出结果后退出
```

### 5.3 管道模式

```bash
$ cat error.log | claude -p "分析这个错误日志"
$ git diff | claude -p "review 这个 diff"
```

### 5.4 非交互模式

```bash
$ claude --print "修复 src/UserService.java 中的 NPE" --output-format stream-json
```

## 六、上下文管理机制

```
Claude Code 的上下文并非一次性塞入所有文件，而是分层管理：

1. 系统层（System Prompt）
   - 工具定义、运行规则、安全约束
   - 固定不变，每次对话加载

2. 项目层（CLAUDE.md）
   - 项目级自定义指令
   - 放在项目根目录自动加载

3. 会话层（Conversation Context）
   - 当前对话历史和工具调用结果
   - 长对话会自动压缩/摘要

4. 按需加载
   - Agent 读取的文件才进入上下文
   - 不是整个项目都塞进去
```

| `/pr` | 创建 Pull Request |

## 八、面试核心要点

1. **Claude Code 是什么形态？** CLI 命令行工具，非 IDE 插件
2. **和 Copilot 最大区别？** Claude Code 是自主代理（主动执行），Copilot 是被动补全
3. **怎么给 Claude Code 项目上下文？** CLAUDE.md + 自动读取文件 + Agent 搜索
4. **Claude Code 能做 Git 操作吗？** 能，直接操作 Git（commit / branch / push / PR）
5. **权限怎么控制？** 沙箱系统，每步操作可批准/拒绝/设置自动允许

---

## 九、极简总结

```
Claude Code = 终端里的 AI 编程代理
不是补全，是自主干活（读文件→写代码→跑命令→调试→提交）
架构 = 消息处理 + 上下文管理 + 工具引擎 + 记忆系统
对比 = Copilot 是副驾，Claude Code 是代驾
模式 = 交互(-p) / 自动化(--print) / 管道(stdin)
```
