# CodeGeeX 核心知识点

## 一、概述

CodeGeeX 是智谱 AI（GLM 大模型团队）推出的免费开源 AI 编程助手，支持超过 100 种编程语言。其最大特点是 **完全免费** 且支持 **代码翻译** 功能，可在不同编程语言间转译代码。

**核心定位：** 免费、多语言、跨 IDE 的 AI 编程助手。

## 二、核心能力

### 2.1 功能列表

| 功能 | 说明 |
|------|------|
| **代码自动补全** | 基于上下文的行内和多行代码续写 |
| **代码生成** | 根据注释或自然语言描述生成代码 |
| **代码翻译** | 将代码从一种语言翻译为另一种 |
| **代码解释** | 用自然语言解释代码逻辑 |
| **注释生成** | 自动为代码块生成规范注释 |
| **智能问答** | 对话式解决编程问题 |

### 2.2 支持的语言

- **主要语言：** Java、Python、JavaScript/TypeScript、Go、C/C++、Rust、Kotlin
- **总语言数：** 100+ 种编程语言

### 2.3 支持的 IDE

| IDE | 安装方式 |

## 四、核心功能详解

### 4.1 代码翻译（核心差异功能）

将代码从一种语言翻译为另一种语言：

```java
// 输入 Java 代码
public List<String> filterUsers(List<User> users) {
    return users.stream()
        .filter(u -> u.getAge() > 18)
        .map(User::getName)
        .sorted()
        .limit(10)
        .collect(Collectors.toList());
}

// 翻译为 Python
def filter_users(users):
    return sorted(
        [user.name for user in users if user.age > 18]
    )[:10]
```

### 4.2 操作方式

| 操作 | VS Code | IntelliJ IDEA |
|------|---------|---------------|
| 触发补全 | Tab 接受建议 | Tab 接受建议 |
| 代码翻译 | 选中代码 → Ctrl+Shift+T | 选中代码 → 右键 → CodeGeeX 翻译 |
| 代码解释 | 选中代码 → 右键 → 解释代码 | 同上 |
| 智能问答 | Ctrl+Shift+G 唤起聊天 | 侧边栏 CodeGeeX 面板 |

### 4.3 多行补全

CodeGeeX 擅长跨行补全，适合生成完整方法体或循环结构。输入函数签名后，等待约 1-2 秒可获得完整方法建议。

## 五、开源模型

CodeGeeX 代码生成模型开源（基于 ChatGLM），可私有化部署：

```bash
# 使用 Hugging Face 拉取模型
git clone https://huggingface.co/THUDM/codegeex4-all-9b

# 使用 vLLM 部署推理服务
python -m vllm.entrypoints.openai.api_server \
    --model codegeex4-all-9b \
    --port 8000
```

## 七、适用场景

1. **预算敏感的个人开发者**：完全免费，功能满足日常需求
2. **多语言项目维护**：前后端分离项目（Java + Python + JS）统一使用一个助手
3. **代码翻译需求**：技术栈迁移（如 Spring Boot → Go 微服务）时提供参考
4. **私有化部署**：企业内网环境，需本地化 AI 编程服务的场景

## 八、总结

CodeGeeX 的核心竞争力在于 **完全免费 + 代码翻译 + 模型开源**。代码补全质量略低于 Copilot，但在免费工具中处于领先水平，配合私有化部署能力，适合有数据安全需求的企业场景。
