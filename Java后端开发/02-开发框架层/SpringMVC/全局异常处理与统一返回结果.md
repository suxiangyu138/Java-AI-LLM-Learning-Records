# 全局异常处理与统一返回结果

## 统一返回结果设计

```java
@Data
@NoArgsConstructor
@AllArgsConstructor
public class Result<T> {
    private int code;
    private String message;
    private T data;
    private long timestamp = System.currentTimeMillis();

    public static <T> Result<T> ok(T data) {
        return new Result<>(200, "success", data);
    }

    public static <T> Result<T> ok() {
        return ok(null);
    }

    public static <T> Result<T> fail(int code, String message) {
        return new Result<>(code, message, null);
    }

    public static <T> Result<T> fail(String message) {
        return fail(500, message);
    }
}
```

## 全局异常处理器

```java
@RestControllerAdvice
public class GlobalExceptionHandler {

    // 参数校验异常
    @ExceptionHandler(MethodArgumentNotValidException.class)
    public Result<?> handleValidation(MethodArgumentNotValidException ex) {
        String msg = ex.getBindingResult().getFieldErrors()
                .stream()
                .map(e -> e.getField() + ": " + e.getDefaultMessage())
                .collect(Collectors.joining("; "));
        return Result.fail(400, msg);
    }

    // 业务异常（自定义）
    @ExceptionHandler(BusinessException.class)
    public Result<?> handleBusiness(BusinessException ex) {
        return Result.fail(ex.getCode(), ex.getMessage());
    }

    // 兜底：未知异常
    @ExceptionHandler(Exception.class)
    public Result<?> handleUnknown(Exception ex) {
        log.error("未知异常", ex);
        // 生产环境不要暴露异常堆栈
        return Result.fail(500, "服务器内部错误");
    }
}
```

## 自定义业务异常

```java
@Getter
public class BusinessException extends RuntimeException {
    private final int code;

    public BusinessException(int code, String message) {
        super(message);
        this.code = code;
    }

    public BusinessException(String message) {
        this(500, message);
    }
}
```

## 常用异常处理清单

| 异常类型 | HTTP 状态码 | 说明 |
|----------|-------------|------|
| `MethodArgumentNotValidException` | 400 | 参数校验失败 |
| `HttpMessageNotReadableException` | 400 | 请求体无法解析（JSON格式错误） |
| `MissingServletRequestParameterException` | 400 | 缺少必填参数 |
| `HttpRequestMethodNotSupportedException` | 405 | 请求方法不对 |
| `HttpMediaTypeNotSupportedException` | 415 | Content-Type 不对 |
| `NoHandlerFoundException` | 404 | 接口不存在（需配置） |

## 响应体自动包装

如果不想每个方法都手动 `return Result.ok(data)`，可用 `ResponseBodyAdvice` 自动包装：

```java
@RestControllerAdvice
public class ResponseWrapper implements ResponseBodyAdvice<Object> {
    @Override
    public boolean supports(MethodParameter returnType, Class converterType) {
        // 避免重复包装：已是 Result 类型则跳过
        return !returnType.getParameterType().equals(Result.class);
    }

    @Override
    public Object beforeBodyWrite(Object body, MethodParameter returnType,
                                  MediaType selectedContentType,
                                  Class selectedConverterType,
                                  ServerHttpRequest request, ServerHttpResponse response) {
        if (body instanceof String) {
            // String 特殊处理（StringHttpMessageConverter 不支持直接写 Result）
            return JSON.toJSONString(Result.ok(body));
        }
        return Result.ok(body);
    }
}
```

## 日志记录

全局异常处理器是统一的日志记录点：

```java
@ExceptionHandler(Exception.class)
public Result<?> handleUnknown(HttpServletRequest request, Exception ex) {
    String params = JSON.toJSONString(request.getParameterMap());
    log.error("全局异常 | URL: {} | Method: {} | Params: {} | Msg: {}",
            request.getRequestURI(),
            request.getMethod(),
            params,
            ex.getMessage(),
            ex);  // 日志记录完整堆栈，响应不暴露
    return Result.fail(500, "服务器内部错误");
}
```
