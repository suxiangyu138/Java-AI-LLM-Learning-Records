# Java Lambda 表达式 核心知识点

## 一、Lambda 核心定位
1. Lambda 是 **Java 8** 引入的**函数式编程**语法。
2. 作用：**简化匿名内部类**写法，精简代码、支持行为参数化。
3. 本质：**行为传递**，把函数/方法当作参数传递。

---

## 二、语法格式

### 基础语法
```java
(形参列表) -> { 方法体 }
```

### 四种简写规则
1. **参数只有一个**：可省略小括号
```java
s -> System.out.println(s);
```
2. **无参数**：必须保留空括号
```java
() -> System.out.println("hello");
```
3. **方法体只有一行代码**：省略 `{}`、`;`
4. **单行有返回值**：省略 `return`
```java
(a, b) -> a + b;
```

---

## 三、使用前提（硬性条件）
**Lambda 只能作用于「函数式接口」**

### 1. 函数式接口定义
- 有且仅有 **一个抽象方法** 的接口
- 标识注解：`@FunctionalInterface`
- 允许包含：默认方法、静态方法、Object 重写方法

### 2. 常见内置函数式接口（Lambda 高频搭配）
| 接口 | 抽象方法 | 用途 |
|------|----------|------|
| `Consumer<T>` | `void accept(T t)` | 消费：入参、无返回 |
| `Supplier<T>` | `T get()` | 供给：无入参、有返回 |
| `Function<T,R>` | `R apply(T t)` | 映射：入参、返回结果 |
| `Predicate<T>` | `boolean test(T t)` | 断言：条件判断、返回布尔 |

---

## 四、Lambda 与 匿名内部类 区别
1. **this 指向不同**
   - 匿名内部类：指向当前内部类对象
   - Lambda：指向**外部类**对象
2. **编译原理不同**
   - 匿名内部类：编译生成独立 `.class` 文件
   - Lambda：底层通过 `invokedynamic` 动态生成代理类，不生成额外 class 文件
3. **作用域**：Lambda 无独立作用域

---

## 五、变量引用规则
1. **局部变量**：Lambda 中引用的局部变量，**隐式被 final 修饰**，不可二次修改
2. **成员变量**：可自由读写
3. **静态变量**：可自由读写

---

## 六、方法引用（Lambda 进阶简化）
用于进一步简化 Lambda，共 4 种写法：
1. 静态方法引用：`类名::静态方法`
2. 实例方法引用：`对象::实例方法`
3. 类实例方法引用：`类名::实例方法`
4. 构造器引用：`类名::new`

---

## 七、核心底层原理（面试高频）
1. 编译阶段：不生成新类，通过 **invokedynamic** 字节码指令。
2. 运行阶段：动态生成函数式接口实现类，执行目标方法。
3. 不会破坏面向对象，只是**语法糖**。

---

## 八、典型使用场景
1. 集合遍历、过滤、排序（配合 Stream）
2. 线程创建简化
```java
new Thread(() -> System.out.println("线程执行")).start();
```
3. 回调函数、自定义策略模式
4. 替代各类单方法匿名内部类

---

## 九、面试高频简答题
1. Lambda 表达式使用前提？
> 必须是函数式接口（仅一个抽象方法）。

2. Lambda 为什么不能修改局部变量？
> 局部变量隐式 final，保证线程安全与数据一致性。

3. Lambda 和匿名内部类 this 区别？
> Lambda 的 this 指向外部类，匿名内部类指向自身。

4. 函数式接口可以有多个方法吗？
> 抽象方法只能一个，默认/静态方法不限。
