# 命令行速查手册（开发版）

> Java 后端开发者常用 Linux & Git 命令速查。

---

## 日志排查

| 命令 | 说明 | 示例 |
|------|------|------|
| `tail -f file.log` | 实时跟踪日志尾部 | `tail -f /var/log/app/spring.log` |
| `tail -n 200 file.log` | 查看最后 N 行 | `tail -n 500 catalina.out` |
| `grep ERROR file.log` | 过滤关键字行 | `grep "OutOfMemoryError" heap.log` |
| `grep -A5 -B5 err file.log` | 匹配行上下 N 行上下文 | `grep -B2 -A2 "500" access.log` |
| `less +F file.log` | 分页查看并支持 tail 模式 | `less +F /var/log/syslog` |
| `journalctl -u nginx` | systemd 日志 | `journalctl -u app.service --since "1h ago"` |

## 端口与进程管理

| 命令 | 说明 | 示例 |
|------|------|------|
| `lsof -i :port` | 查看端口占用进程 | `lsof -i :8080` |
| `netstat -tlnp` | 列出所有监听端口及进程 | `netstat -tlnp \| grep java` |
| `ss -tlnp` | 替代 netstat（更快） | `ss -tlnp \| grep :3306` |
| `ps -ef \| grep java` | 查找 Java 进程 | `ps -ef \| grep '[j]ava'` |
| `kill -9 PID` | 强制终止进程 | `kill -9 12345` |
| `kill -15 PID` | 优雅终止进程 | `kill -15 12345` |
| `top -p PID` | 监控指定进程资源 | `top -p $(pgrep -f spring)` |

## 文件操作

| 命令 | 说明 | 示例 |
|------|------|------|
| `find . -name "*.log"` | 按名称查找文件 | `find /app -name "*.jar" -mtime -3` |
| `du -sh *` | 查看当前目录各项大小 | `du -sh --exclude=logs *` |
| `tar -czvf archive.tar.gz dir` | 打包压缩 | `tar -czvf app-backup.tar.gz /app/` |
| `tar -xzvf archive.tar.gz` | 解压 | `tar -xzvf app-backup.tar.gz` |
| `rsync -avz src/ dst/` | 增量同步文件 | `rsync -avz --delete ./target/ deploy/` |
| `scp file user@host:/path` | 远程拷贝 | `scp app.jar root@10.0.0.5:/opt/app/` |

## 系统监控

| 命令 | 说明 | 示例 |
|------|------|------|
| `top` / `htop` | 进程实时监控 | `top -o %MEM` |
| `free -h` | 内存使用情况 | `free -h` |
| `uptime` | 系统负载（1/5/15 分钟） | `uptime` |
| `vmstat 1 5` | CPU/内存/IO 统计 | `vmstat 2 10` |
| `dmesg \| tail -20` | 内核日志（OOM 等） | `dmesg \| grep -i oom` |

## 网络诊断

| 命令 | 说明 | 示例 |
|------|------|------|
| `curl -v http://host:port` | 调试 HTTP 请求 | `curl -s -o /dev/null -w "%{http_code}" http://localhost:8080/actuator/health` |
| `ping -c 4 host` | 连通性测试 | `ping -c 4 baidu.com` |
| `traceroute host` | 路由追踪 | `traceroute 10.0.0.1` |
| `nslookup domain` | DNS 解析 | `nslookup api.example.com` |
| `telnet host port` | 测试端口连通性 | `telnet db.internal 3306` |
| `nc -zv host port` | 端口扫描（单端口） | `nc -zv 10.0.0.2 22` |

## 磁盘管理

| 命令 | 说明 | 示例 |
|------|------|------|
| `df -h` | 磁盘分区使用量 | `df -h \| grep /dev/sda` |
| `du -sh /path` | 目录总大小 | `du -sh /var/log` |
| `lsblk` | 块设备列表 | `lsblk` |
| `iostat -xz 1` | 磁盘 IO 统计 | `iostat -x 1 3` |
| `iotop` | 进程级 IO 监控 | `sudo iotop -o` |

## 用户与权限

| 命令 | 说明 | 示例 |
|------|------|------|
| `who` / `w` | 当前登录用户 | `w` |
| `id` | 当前用户 UID/GID | `id` |
| `chmod 755 file` | 修改文件权限 | `chmod +x deploy.sh` |
| `chown user:group file` | 修改文件所有者 | `chown -R app:app /opt/app` |
| `sudo -u user command` | 以指定用户身份执行 | `sudo -u www-data touch /var/log/app.log` |

## Git 命令速查

| 命令 | 说明 | 示例 |
|------|------|------|
| `git log --oneline -10` | 查看最近提交 | `git log --oneline --graph -20` |
| `git diff` | 工作区 vs 暂存区差异 | `git diff --stat` |
| `git stash` | 暂存当前改动 | `git stash pop` |
| `git rebase -i HEAD~3` | 交互式变基 | `git rebase -i origin/main` |
| `git cherry-pick <hash>` | 拣选某次提交 | `git cherry-pick abc123` |
| `git reset --soft HEAD~1` | 撤销提交但不丢改动 | `git reset --hard origin/main` |
| `git revert <hash>` | 安全回退（生成新提交） | `git revert HEAD` |
| `git bisect start` | 二分查找引入 bug 的提交 | `git bisect bad; git bisect good v1.0` |
| `git tag -a v1.0 -m "msg"` | 打标签 | `git push origin --tags` |
