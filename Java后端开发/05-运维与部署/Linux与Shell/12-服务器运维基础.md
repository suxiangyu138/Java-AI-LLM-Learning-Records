# 服务器运维基础

> Java 后端开发视角：从硬件选型到系统安装、远程管理，掌握服务器运维的核心常识。

## 一、服务器硬件基础

| 组件 | 说明 | 后端开发关注点 |
|------|------|----------------|
| CPU | 主频 + 核心数决定计算能力 | 高并发服务选多核（8C+）；计算密集型选高主频 |
| 内存 | 程序运行时驻留空间 | JVM 堆 + 系统缓存 + 数据库 buffer 之和，留 20% 余量 |
| 磁盘 | 数据持久化存储 | 系统盘（SSD）+ 数据盘（HDD/SSD）；数据库建议 NVMe SSD |
| 网络 | 带宽 + 延迟 | 带宽决定吞吐上限；内网建议万兆 |

### 典型配置参考| 场景 | CPU | 内存 | 磁盘 |
|------|-----|------|------|
| 单体 Spring Boot + MySQL | 4C | 8G | 100G SSD |
| 微服务 + Redis + MQ | 8C | 16G | 200G SSD |
| 生产读写分离 + 集群 | 16C+ | 32G+ | 500G+ NVMe |

## 二、Linux 系统安装快速指南

### 2.1 发行版选型

| 发行版 | 包管理器 | 适用场景 |
|--------|----------|----------|
| CentOS Stream / Rocky Linux | `yum` / `dnf` | 生产环境，企业部署首选 |
| Ubuntu Server LTS | `apt` | 开发/测试环境，Docker/K8s 宿主 |
| Debian | `apt` | 追求极致稳定，资源占用低 |

### 2.2 安装要点

1. **分区建议**：`/boot` 1G，`/` 50G，`swap` = 内存大小（>=16G 设 4-8G），剩余挂 `/data`
2. **网络配置**：安装时设置静态 IP，或安装后配置 CentOS `/etc/sysconfig/network-scripts/` / Ubuntu `/etc/netplan/`
3. **初始化操作**：

```bash
# CentOS
yum update -y && yum install -y vim net-tools wget curl
systemctl stop firewalld && systemctl disable firewalld
# Ubuntu
apt update && apt upgrade -y && apt install -y vim net-tools wget curl
ufw disable
```

## 三、FinalShell 使用指南

FinalShell 是一款免费的 Windows SSH + SFTP 客户端，适合 Java 后端日常远程操作。

### 核心功能

- **SSH 终端**：多标签页、会话保存、记住密码/密钥
- **SFTP 文件管理**：左侧本地、右侧服务器，支持拖拽上传/下载
- **系统监控**：实时查看 CPU/内存/磁盘/网络

### 快速配置

`名称=自定义` `协议=SSH` `主机=公网IP` `端口=22` `认证=密码或密钥（生产推荐密钥）`

### 常用操作

| 操作 | 方法 |
|------|------|
| 上传文件 | 本地文件拖拽到右侧服务器目录 |
| 下载文件 | 服务器文件拖拽到左侧本地目录 |
| 编辑文件 | 双击服务器端文件，自动在本地打开编辑 |
| 复制会话 | 右键会话 -> 复制，快速创建相似连接 |
| 分组管理 | 右键 -> 新建文件夹，按项目或环境分组 |

## 四、Ubuntu 核心知识（与 CentOS 对比）

### 包管理对比

| 操作 | CentOS | Ubuntu |
|------|--------|--------|
| 更新源 | `yum update` | `apt update && apt upgrade` |
| 安装软件 | `yum install -y <pkg>` | `apt install -y <pkg>` |
| 搜索软件 | `yum search <keyword>` | `apt search <keyword>` |
| 移除软件 | `yum remove <pkg>` | `apt remove <pkg>` |
| 软件源文件 | `/etc/yum.repos.d/` | `/etc/apt/sources.list` |

### 系统管理对比

| 功能 | CentOS | Ubuntu |
|------|--------|--------|
| 防火墙 | `firewalld` | `ufw` |
| SELinux | 默认启用 | 未内置（AppArmor） |
| root 登录 | 默认允许 SSH | 默认禁止，需 `sudo` |
| 网络配置 | `/etc/sysconfig/network-scripts/ifcfg-*` | `/etc/netplan/*.yaml` |
| 服务管理 | `systemctl`（相同） | `systemctl`（相同） |

### Java 后端安装要点

```bash
# Ubuntu 安装 JDK 17
apt install -y openjdk-17-jdk
# CentOS 安装 JDK 17
yum install -y java-17-openjdk-devel
java -version
```

## 五、Unix 快速入门

- **Unix**：1970 年代贝尔实验室开发的多用户、多任务操作系统家族
- **主要分支**：AIX（IBM）、HP-UX（HP）、Solaris（Oracle）、BSD
- **Linux**：类 Unix 系统，代码完全重写，遵循 POSIX 标准，命令接口高度兼容

### 对 Java 后端的意义

| 场景 | 说明 |
|------|------|
| macOS 开发 | macOS 是认证 Unix（Darwin 内核），终端命令与 Linux 几乎一致 |
| 跨平台部署 | POSIX 标准命令（`ps`、`grep`、`awk`、`sed`）可平滑迁移 |
| 面试考核 | Unix/Linux 区别、POSIX 标准是后端面试常考概念 |

### 核心差异速记

- 命令差异较小（`ifconfig` vs `ip addr`，`service` vs `systemctl`）
- Bash 脚本在 Unix/Linux/macOS 上基本通用
- 核心概念相同：管道 `|`、重定向、进程管理、权限 `rwx`

## 六、运维速查命令（Java 后端高频）

```bash
# 系统信息
uname -a                # 内核版本
cat /etc/os-release     # 发行版
free -h                 # 内存
df -h                   # 磁盘
top / htop              # 进程

# Java 相关
ps -ef | grep java      # 查看 Java 进程
jstack <pid>            # 线程堆栈
jstat -gc <pid> 1000    # GC 每秒打印
tail -f nohup.out       # 实时查看日志

# 网络排查
netstat -tlnp           # 监听端口
curl -v http://localhost:8080/health  # 健康检查
ping <host>             # 连通性
```
