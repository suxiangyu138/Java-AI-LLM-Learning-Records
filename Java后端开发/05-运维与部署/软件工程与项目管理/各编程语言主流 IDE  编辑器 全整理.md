各编程语言主流 IDE / 编辑器 全整理
区分两类：
- 重型IDE：全量索引、内置编译/调试/重构，功能强、吃资源
- 轻量编辑器：核心文本编辑 + 插件扩展，轻快、启动快
    下面按语言整理最主流、实际工作用得最多的工具，直接照着选就行。
 
Java
- 重型IDE：IntelliJ IDEA、Eclipse、NetBeans
- 轻量编辑器：VS Code
    Python
- 重型IDE：PyCharm、Spyder
- 轻量编辑器：VS Code、Sublime、Vim/Neovim
    C / C++
- 重型IDE：Visual Studio、CLion、Code::Blocks、Dev-C++
- 轻量编辑器：VS Code、Sublime、Vim/Neovim
    JavaScript / TypeScript / 前端
- 重型IDE：WebStorm
- 轻量编辑器：VS Code（绝对主流）、Sublime
    Go
- 重型IDE：GoLand
- 轻量编辑器：VS Code、Vim/Neovim
    Rust
- 重型IDE：RustRover
- 轻量编辑器：VS Code、Vim/Neovim
    PHP
- 重型IDE：PhpStorm
- 轻量编辑器：VS Code、Sublime
    C# / .NET
- 重型IDE：Visual Studio、Rider
- 轻量编辑器：VS Code
    Swift / Objective-C（iOS/macOS）
- 唯一主流：Xcode
    Kotlin / Android 开发
- 唯一主流：Android Studio
    Ruby
- 重型IDE：RubyMine
- 轻量编辑器：VS Code、Sublime
    Lua
- 轻量为主：VS Code、Sublime、Vim/Neovim
- 重型IDE：ZeroBrane Studio
    SQL / 数据库开发
- 重型IDE：DataGrip、DBeaver
- 轻量：VS Code + 数据库插件
    Markdown / 笔记文档
- 轻量：VS Code、Obsidian、Typora
 
极简选型建议
1. 学生练手、多语言通用、追求轻快：VS Code
2. 企业级Java/Python/前端开发：JetBrains系列IDE（IDEA、PyCharm、WebStorm）
3. C# / Windows桌面开发：Visual Studio
4. iOS开发：Xcode
5. 移动端Android：Android Studio
