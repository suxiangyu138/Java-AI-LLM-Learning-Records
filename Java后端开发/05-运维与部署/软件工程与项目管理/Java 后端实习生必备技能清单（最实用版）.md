Java 后端实习生必备技能清单（最实用版）
1. Java 基础（必不能差）
    - 基本语法：变量、循环、判断、数组、集合
    - List、Map、HashMap 熟练使用
    - 异常处理  try-catch 
    - 面向对象：类、对象、接口、继承
    - 简单 IO、字符串处理
2. 数据库 + SQL（重中之重）
    - MySQL 会写：增删改查（CRUD）
    - 会  where 、 order by 、 limit 、 group by 
    - 会连表查询： join 
    - 会用 Navicat/DBeaver 连接库、查数据、改数据
    - 了解事务、索引概念就行
3. SpringBoot 开发（企业 100% 用）
    - 能独立写接口： @RestController 
    - 会  @GetMapping 、 @PostMapping 
    - 会  @Service 、 @Autowired  注入
    - 能写出完整结构：
    Controller → Service → Mapper
    - 会统一返回结果封装（Result 类）
4. MyBatis / MyBatis-Plus
    - 会写 XML 或注解 SQL
    - 会基本的查询、插入、更新
    - 会简单分页
    - 看懂别人写的 XML 语句
5. 前后端接口开发
    - 接收参数： @RequestParam 、 @RequestBody 
    - 处理 JSON 数据
    - 写接口给前端调用
    - 懂简单的接口文档 Swagger/Knife4j
6. Git 基本操作（必回）
    -  git pull  拉代码
    -  git add/commit/push 
    - 会开分支、合并代码
    - 能解决简单冲突
7. 问题排查能力（实习最加分）
    - 看控制台日志
    - 定位空指针、参数异常
    - 会用 Postman 测试接口
    - 会 debug 断点调试
8. 加分项（有就能甩开 80% 竞争者）
    - Redis 缓存基本使用
    - 简单的RAG、大模型调用（你正在学的方向）
    - Spring Security / JWT 登录
    - 了解 Linux 基本命令
    - 做过完整项目（管理系统、博客、小程序后端）
 
一句话总结
能独立用 SpringBoot + MySQL 写 CRUD 接口，
能跑通前后端联调，你在合肥就能找到实习。
